# Codeforces 排列传输（困难版） 题解

## 1. 题目概述

- **标题 / 题号**：排列传输（困难版）（Codeforces 2233E2，英文名 Permutation Transmission (Difficult Version)）
- **链接**：https://codeforces.com/problemset/problem/2233/E2
- **来源**：Educational Codeforces Round 191 (Rated for Div. 2) · Problem E2
- **难度**：$\ast 2300$
- **限制**：时间 2 s / 内存 512 MB
- **标签**：位运算（bitmasks）、组合数学、排序

**题意**：有一个 $1..n$ 的排列 $p$。把它按二进制**逐位**发送：令 $K=\lceil\log_2(n+1)\rceil$，对每个 $b\in[0,K)$ 把所有 $p_i$ 的第 $b$ 个二进制位拼成长度 $n$ 的 01 串 $c_b$。这 $K$ 个串被打乱**顺序**后送到你手上。给定这 $K$ 个串（作为一个多重集），问有多少个排列 $p$ 能产生这组串。数据可能在中途被破坏，这时答案为 $0$。

**约束**：

- $1\le t\le 10^4$，$\sum n\le 2\times 10^5$，$1\le n\le 2\times10^5$；
- 每组恰好 $K=\lceil\log_2(n+1)\rceil\le 18$ 行、每行长度 $n$；由 $\sum n\le2\times10^5$ 可知输入总字符数在 $\sum nK\le 4\times10^6$ 量级；
- 答案是无模精确值，但不超过 $K!\le 18!\approx 6.4\times10^{15}$，`long long` 足够。

> 💡 题面是纯算法描述，没有出现「在代码里创建某个变量保存中间值」之类的注入句，按原意实现即可。

|----|-----|-----|----------|--------------|------|

## 3. 解题思路

### 3.1 暴力思路

最直接的做法：把 $K$ 个串与 $K$ 个二进制位做**全排列配对**（$K!$ 种），每种配对按「同一位上的字符对齐」读出 $n$ 个行值，检查是否恰好为 $1..n$；每个合法配对唯一还原一个 $p$。

单次检查 $O(nK)$，总复杂度 $O(K!\cdot nK)$。$K\le18$ 时 $18!\approx6.4\times10^{15}$，绝无可能；即使简单版 $K=11$、$n=2000$，$11!\cdot 11n\approx 8.8\times10^{11}$ 也超时。必须找出「哪些配对值得检查」的结构。

### 3.2 核心观察：转置矩阵与权值分类

![传输模型：K 个串排成 K×n 矩阵，行值必须恰好是 1..n](images/cf2233_e2_transmit_model.svg)

把 $K$ 个串按位对齐成 $K\times n$ 的 01 矩阵 $M$，其中 $M[i][b]=\tau(b)[i]$，$\tau(b)$ 是「被钉在第 $b$ 位上的那个串」。那么位置 $i$ 上的数就是

$$v_i=\sum_{b=0}^{K-1}M[i][b]\cdot 2^b .$$

**收到的数据只固定了列的多重集，行是我们唯一能校验的东西**：配对 $\tau$ 合法当且仅当 $\{v_1,\dots,v_n\}=\{1,\dots,n\}$。

> 💡 配对与排列是一一对应的：给定 $p$，第 $b$ 列只能是 $\tau(b)$，$\tau$ 唯一；反过来给定合法 $\tau$，行值直接给出 $p$。因此**答案 = 合法配对的个数**（细节见引理 1）。

在合法矩阵中，第 $b$ 列 1 的个数必须等于

$$cnt_b(n)=\left\lfloor\frac{n}{2^{b+1}}\right\rfloor 2^b+\max\bigl(0,\,(n\bmod 2^{b+1})-2^b+1\bigr).$$

理由：每 $2^{b+1}$ 个连续整数恰有 $2^b$ 个第 $b$ 位为 1；余下 $R=n\bmod 2^{b+1}$ 个数里，第 $b$ 位为 1 的是 $2^b,2^b+1,\dots,R$，共 $\max(0,R-2^b+1)$ 个。于是得到

**必要条件**：输入串的 Hamming 权值多重集 $=\{cnt_b\}_{b=0}^{K-1}$，否则答案直接为 $0$。

### 3.3 算法流程：同权值的位可以互换

![权值分类：cnt_b 相同的位可以互换，合法性与配对无关](images/cf2233_e2_weight_classes.svg)

必要条件只把每个串限制到「权值相同的一组位」里，组内怎么配还没定。关键补丁是下面的引理 2（证明见 §5）：**若 $cnt_b=cnt_{b'}$，则交换第 $b$ 位与第 $b'$ 位的映射 $\psi$ 是 $[0,n]\to[0,n]$ 的双射。**

它的意义：权值相同的两位互换串，等价于把矩阵的每一行都做一次 $\psi$，而行值集合 $\{1..n\}$ 被 $\psi$ 整体映到自身，**合法性完全不变**。于是：

1. 把位按 $cnt$ 值分桶、串按权值分桶，两个桶必须**逐桶大小相等**，否则输出 $0$；
2. 桶内任意配对的合法性都相同 —— 要么全合法，要么全不合法；
3. 所以只需**随便取一种**权值兼容的配对，做一次 $O(nK)$ 的行校验就能定论。

校验通过时，答案就是「权值兼容配对的个数」：

$$\prod_w\frac{m_w!}{\prod_{t:\,\mathrm{wt}(t)=w}c_t!}\;=\;\frac{\prod_w m_w!}{\prod_t c_t!},$$

其中 $m_w=\#\{b:cnt_b=w\}$ 是权值桶的位数，$c_t$ 是串 $t$ 在输入中的重数（内容相同的串互换不产生新矩阵）。

**流程**：读入 $\to$ 算 $cnt_b$ $\to$ 比较权值多重集（不等输出 $0$）$\to$ 取一种配对 $\to$ 校验行值（不合法输出 $0$）$\to$ 算上式并输出。

### 3.4 示例演算

![n=4 的样例演算：权值 (2,2,1)，行值 1..4，答案 2](images/cf2233_e2_walkthrough.svg)

以第 2 组样例 $n=4$、三串 `1010`、`0001`、`0110` 为例。$cnt=(2,2,1)$，权值 $2$ 的桶有两位（$b=0,1$），权值 $1$ 的桶一位（$b=2$）：

| 位 | 串 | $i=1$ | $i=2$ | $i=3$ | $i=4$ | 位权 |
|----|----|-------|-------|-------|-------|------|
| 第 2 位 | `0001` | 0 | 0 | 0 | 1 | 4 |
| 第 1 位 | `0110` | 0 | 1 | 1 | 0 | 2 |
| 第 0 位 | `1010` | 1 | 0 | 1 | 0 | 1 |
| 行值 $v_i$ | | 1 | 2 | 3 | 4 | |

行值恰好覆盖 $1..4$，合法。三串互不相同，故答案 $=(2!\cdot1!)/1=2$。交换第 $0,1$ 位会把行值 $1\leftrightarrow2$、$3$ 与 $4$ 不动，正好得到另一组解 $[2,1,3,4]$。

第 3 组样例 $n=7$ 三串权值都是 $4$，$cnt=(4,4,4)$ 属同一个桶（大小 $3$），任取一种配对得到行值 $2,7,4,1,6,5,3$，恰好覆盖 $1..7$，答案 $=3!/1=6$。

## 4. 算法细节

1. **$K$ 的取法**：$K=\lceil\log_2(n+1)\rceil=\lfloor\log_2n\rfloor+1$，即 $n$ 的二进制位数。C++ 用 `while ((1 << K) <= n) ++K;`，Python 用 `n.bit_length()`；若写成 $\lfloor\log_2 n\rfloor$ 会在 $n=2^k$ 时少读一行。
2. **$cnt_b$ 用 64 位中间量**：$2^{b+1}$、块数乘 $2^b$ 都用 `long long`，避免 $b$ 较大时的隐式溢出。
3. **权值多重集比较**：两边的权值分别排序后逐项比较，$O(K\log K)$；也可以开桶，但 $K\le18$ 时排序更短。
4. **配对的构造**：对每个位 $b$ 线性扫描找一个未使用、权值等于 $cnt_b$ 的串，$O(K^2)$；不需要二分图匹配。
5. **行值校验**：开长度 $n+1$ 的 `seen`（`vector<char>` / `bytearray`，避免每组 `memset`），逐位置算 $v_i$，要求 $1\le v_i\le n$ 且未出现过；一旦违规立即退出。
6. **计数实现**：把 `need` 排序、把串排序，按「相同值连续段」取阶乘，答案 $=\prod(\text{need 段长}!) / \prod(\text{串段长}!)$，用 $\le 20$ 的阶乘表整除，结果是整数。
7. **答案类型**：$18!\approx6.4\times10^{15}$，C++ 必须 `long long` 且 `printf("%lld")`；不要对任何模数取模。

## 5. 正确性证明

**引理 1**：合法配对与可能的原排列 $p$ 一一对应，因此答案等于合法配对的个数。

**证明**：给定 $p$，其第 $b$ 列的内容唯一确定 $\tau(b)$，故 $\tau$ 唯一。反之给定配对 $\tau$，矩阵 $M$ 已唯一确定；若行值恰为 $1..n$，令 $p_i=v_i$，由 $M[i][b]=\tau(b)[i]$ 知 $p$ 产生的第 $b$ 列正是 $\tau(b)$。两个不同配对给出不同的标注矩阵，不可能来自同一个 $p$，故映射是双射。∎

**引理 2**：若 $b<b'$ 且 $cnt_b(n)=cnt_{b'}(n)$，则交换二进制第 $b$ 位与第 $b'$ 位的映射 $\psi$ 是 $[0,n]$ 到自身的双射。

**证明**：记 $D=2^{b'}-2^b$，$W_x(t)=\#\{v\in[0,t]:v\text{ 的第 }x\text{ 位为 }1\}$，并写 $n=Q\cdot2^{b'+1}+R$（$0\le R<2^{b'+1}$）。由于 $2^{b+1}\mid2^{b'+1}$，每个长度 $2^{b'+1}$ 的完整区间里，第 $b$ 位与第 $b'$ 位各有 $2^{b'}$ 个 1，于是

$$cnt_b(n)=Q\cdot2^{b'}+W_b(R),\qquad cnt_{b'}(n)=Q\cdot2^{b'}+W_{b'}(R),$$

从而 $cnt_b(n)=cnt_{b'}(n)\iff W_b(R)=W_{b'}(R)$。

$\psi$ 是对合，且按模 $2^{b'+1}$ 分块后块内形状完全相同：$(0,0)$、$(1,1)$ 型不动，$(1,0)$ 型整段 $J_j=[(2j+1)2^b,(2j+2)2^b)$ 平移 $+D$ 成 $(0,1)$ 型段 $I_j=[2^{b'}+2j\cdot2^b,\,2^{b'}+(2j+1)2^b)$，并反向平移，$j=0,\dots,2^{b'-b-1}-1$，且 $J_0<I_0<J_1<I_1<\cdots$。

对任意前缀 $[0,t]$，

$$W_b(t)-W_{b'}(t)=\sum_j\Bigl(\#(J_j\cap[0,t])-\#(I_j\cap[0,t])\Bigr)\ge0,$$

因为 $J_j$ 整体位于 $I_j$ 之前，前缀一旦碰到 $I_j$ 就必然已完整包含 $J_j$，故上式每项非负、总和 $\ge0$。等号成立当且仅当对每个 $j$ 都「$J_j$ 与前缀不相交」或「$J_j$ 与 $I_j$ 都被完整包含」，即没有任何 $I_j$ 被前缀切成两半。设前缀完整包含的最后一个 $(1,0)$ 段为 $J$、其像段为 $I$，则等号条件就是 $t\ge\operatorname{end}(I)-1$；而这恰好也是 $\psi$ 把 $[0,t]$ 映入自身的条件：$[0,t]$ 中最大的 $(1,0)$ 型值 $v$（若存在）经 $\psi$ 后变成 $\operatorname{end}(I)-1$，必须不超过 $t$。$\psi$ 是单射，故「映入自身」即「双射」。

最后，$\psi$ 与「加 $2^{b'+1}$」可交换，故 $\psi$ 保持 $[0,R]$ 当且仅当保持 $[0,n]$。合起来即 $cnt_b=cnt_{b'}\Rightarrow\psi$ 保持 $[0,n]$，从而保持 $\{1,\dots,n\}$。∎

**定理**：若权值多重集与 $\{cnt_b\}$ 相同，则 (i) 某一种权值兼容配对合法 与 (ii) 所有权值兼容配对都合法 等价；算法输出的计数正确。

**证明**：任意两个权值兼容配对只差一个「在每个权值桶内部交换位」的置换 $\sigma$。把 $\sigma$ 分解为若干换位 $(b,b')$，必有 $cnt_b=cnt_{b'}$，每次换位等价于对每一行施加引理 2 的 $\psi$，行值集合仍是 $\{1..n\}$，合法性不变，逐次传递得 (i)$\iff$(ii)。合法时按桶独立数双射：第 $w$ 个桶有 $m_w!$ 种，桶内内容相同的串互换不产生新矩阵，再除以 $\prod_t c_t!$，即得答案公式。∎

## 6. 复杂度分析

- **时间**：算 $cnt_b$ 为 $O(K)$，统计权值 $O(\sum_i|s_i|)=O(nK)$，排序 $O(K\log K)$，配对 $O(K^2)$，行校验 $O(nK)$，合计 $O(nK+K^2)=O(n\log n)$。对 $\sum n\le2\times10^5$，总运算量约 $\sum nK\le3.6\times10^6$。
- **空间**：每组存 $K$ 个长度 $n$ 的串，共 $O(nK)$ 字节（$n=2\times10^5,K=18$ 时约 $3.6$ MB），加 $O(n)$ 标记数组与 $O(K)$ 辅助空间；内存 512 MB 极宽松。
- **时限对照**：实测最坏数据（$n=2\times10^5$，$K=18$）C++ 约 $30$ ms、Python 约 $0.15$ s（本机），相对 2 s 有数十倍余量。若用 Python 提交，建议 PyPy。

## 7. 参考代码

### C++17

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int T;
    if (scanf("%d", &T) != 1) return 0;
    long long fact[20];
    fact[0] = 1;
    for (int i = 1; i < 20; i++) fact[i] = fact[i - 1] * i;

    vector<unsigned char> seen;
    static char buf[200005];
    while (T--) {
        int n;
        scanf("%d", &n);
        int K = 0;
        while ((1 << K) <= n) K++;          // K = ceil(log2(n+1))
        vector<string> s(K);
        for (int i = 0; i < K; i++) { scanf("%s", buf); s[i] = buf; }

        // 第 b 位在 1..n 中 1 的个数
        vector<long long> need(K), got(K);
        for (int b = 0; b < K; b++) {
            long long full = 1LL << b;
            long long blk = (long long)n >> (b + 1);
            long long rem = (long long)n & (2 * full - 1);
            need[b] = blk * full + max(0LL, rem - full + 1);
        }
        for (int i = 0; i < K; i++)
            got[i] = (long long)count(s[i].begin(), s[i].end(), '1');

        // 必要条件：权值多重集必须一致
        vector<long long> a = need, c = got;
        sort(a.begin(), a.end());
        sort(c.begin(), c.end());
        if (a != c) { puts("0"); continue; }

        // 任取一种同权值配对
        vector<int> who(K, -1);
        vector<char> used(K, 0);
        for (int b = 0; b < K; b++)
            for (int i = 0; i < K; i++)
                if (!used[i] && got[i] == need[b]) { used[i] = 1; who[b] = i; break; }

        // 校验：行值必须恰好是 1..n
        seen.assign(n + 1, 0);
        bool ok = true;
        for (int i = 0; i < n && ok; i++) {
            int v = 0;
            for (int b = 0; b < K; b++)
                if (s[who[b]][i] == '1') v |= (1 << b);
            if (v < 1 || v > n || seen[v]) ok = false;
            else seen[v] = 1;
        }
        if (!ok) { puts("0"); continue; }

        // 答案 = 各权值桶内的不同配对个数
        vector<string> t = s;
        sort(t.begin(), t.end());
        long long num = 1, den = 1;
        for (int i = 0; i < K;) {
            int j = i;
            while (j < K && a[j] == a[i]) j++;   // a 是排序后的 need
            num *= fact[j - i];
            i = j;
        }
        for (int i = 0; i < K;) {
            int j = i;
            while (j < K && t[j] == t[i]) j++;
            den *= fact[j - i];
            i = j;
        }
        printf("%lld\n", num / den);
    }
    return 0;
}
```

### Python3

```python
import sys


def main():
    data = sys.stdin.buffer.read().split()
    t = int(data[0])
    p = 1
    fact = [1] * 20
    for i in range(1, 20):
        fact[i] = fact[i - 1] * i
    out = []
    for _ in range(t):
        n = int(data[p]); p += 1
        K = n.bit_length()                      # ceil(log2(n+1))
        s = data[p:p + K]; p += K               # 每个元素是 bytes
        need = []
        for b in range(K):
            full = 1 << b
            need.append((n >> (b + 1)) * full + max(0, (n & (2 * full - 1)) - full + 1))
        got = [x.count(b'1') for x in s]

        if sorted(need) != sorted(got):
            out.append('0')
            continue

        # 任取一种同权值配对
        bucket = {}
        for i, w in enumerate(got):
            bucket.setdefault(w, []).append(i)
        used = [False] * K
        who = []
        for b in range(K):
            for i in bucket[need[b]]:
                if not used[i]:
                    used[i] = True
                    who.append(i)
                    break

        # 按列拼出行值（bytes 反转后交给 int 解析，比逐位循环快）
        rows = [int(bytes(reversed(col)), 2) for col in zip(*(s[i] for i in who))]
        rows.sort()
        if rows != list(range(1, n + 1)):
            out.append('0')
            continue

        num = den = 1
        ns, ss = sorted(need), sorted(s)
        i = 0
        while i < K:
            j = i
            while j < K and ns[j] == ns[i]:
                j += 1
            num *= fact[j - i]
            i = j
        i = 0
        while i < K:
            j = i
            while j < K and ss[j] == ss[i]:
                j += 1
            den *= fact[j - i]
            i = j
        out.append(str(num // den))
    sys.stdout.write('\n'.join(out) + '\n')


main()
```

## 8. 边界情况与易错点

1. **$n=1$**：$K=1$，唯一目标 $cnt_0=1$；输入串为 `1` 时答案 $1$，否则 $0$。
2. **$K$ 是 $\lceil\log_2(n+1)\rceil$ 而不是 $\lfloor\log_2n\rfloor$**：$n=2^k$ 时 $K=k+1$（如 $n=4$ 要读 $3$ 行）；差一会把整组数据读错位。
3. **答案会溢出 `int`**：$18!\approx6.4\times10^{15}$，必须 `long long`，且不能取模。
4. **「同权值可换」只在 $cnt$ 相同时成立**：$cnt$ 不同的两位互换会立刻破坏行权值统计；这也是为什么必须逐桶比较多重集，而不能只比较权值总和。
5. **重复串**：内容相同的串互换不产生新矩阵，答案要除以 $\prod c_t!$；而且一旦两位内容完全相同，每行这两位就相等，而 $1..n$ 中必有某个数这两位不同，行校验必然失败 —— 所以重复串通常直接导致答案 $0$。
6. **行值校验要同时判范围与去重**：只判「互不相同且 $v_i\le n$」会漏掉 $v_i=0$（例如最高位串在该位置为 $0$ 且更低位的串也被配错时）。
7. **多测重置**：`seen` 按 $n$ 重新分配，配合 $\sum n\le2\times10^5$ 保证总代价；不要用 `memset` 扫到 $2\times10^5$ 以外的更大固定上界。
