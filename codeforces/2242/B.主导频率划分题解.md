# Codeforces 主导频率划分 题解

## 1. 题目概述

- **标题 / 题号**：主导频率划分（Codeforces 2242B，英文名 Predominant Frequency Division）
- **链接**：https://codeforces.com/problemset/problem/2242/B
- **来源**：Educational Codeforces Round 192 (Rated for Div. 2) · Problem B
- **难度**：1000（$\ast 1000$）
- **限制**：时间 2 s / 内存 512 MB
- **标签**：前缀和、贪心、数学、实现（官方标签：data structures, greedy, implementation, math）

**题意**：给定一个只含 $1,2,3$ 的数组 $a$。问能否把它切成三段**连续、两两不交、都非空**的 $[1..i]$、$[i+1..j]$、$[j+1..n]$（$1 \le i < j \le n-1$），使得对第 $k$ 段（$k=1,2,3$）都满足：**段内「大于 $k$ 的元素」不超过段长的一半**。

具体到本题只有两条实质约束：

- 第 1 段：$2,3$ 的个数不超过段长的一半 ⟺ **$1$ 的个数 ≥ 其余元素的个数**；
- 第 2 段：$3$ 的个数不超过段长的一半 ⟺ **$1,2$ 的总数 ≥ $3$ 的个数**；
- 第 3 段：没有元素大于 $3$，条件恒真，**只要求非空**。

「不超过一半」按实数理解，即 $2\cdot\text{个数} \le \text{段长}$，**取等号也算合法**。多测：第一行 $t$，每组先 $n$ 再 $n$ 个 $a_i$，每组输出一行 `YES` / `NO`（大小写不敏感）。

> 💡 一句话本质：两条条件都是「某类元素的计数 ≥ 段长的一半」，而「段长」能拆成两个前缀下标之差 —— 于是全部化成**前缀量之间的比较**，剩下的只是找一个合法的下标对。

**约束**：

- $1 \le t \le 10^4$，$\sum n \le 2\times 10^5$
- $3 \le n \le 2\times 10^5$，$1 \le a_i \le 3$
- 复杂度必须每组 $O(n)$（合计 $O(\sum n)$）；枚举两个切点是 $O(n^2)$，$n=2\times10^5$ 时约 $2\times10^{10}$ 次判断，必然超时

## 3. 解题思路

### 3.1 暴力思路

直接用前缀和枚举 $i<j$，每组 $O(n^2)$：$n=2\times 10^5$ 时约 $2\times10^{10}$ 个 $(i,j)$，每个 $O(1)$ 判断也要几十秒，必然 TLE。暴力只够在 $n\le 60$ 时用来对拍。

还有一个**更隐蔽的错误做法**：从左往右找**第一个**满足 $1$ 的个数 ≥ 其余个数的位置当 $i$，再看它后面有没有可行的 $j$。这看起来很自然（左段越短越容易给中段留空间），但**是错的**：官方样例第 $8$ 组 $a=[1,3,3,1,1]$，$i=1$ 时左段 $[1]$ 合法、可它后面的最小值 $M_1=0$ 严格大于 $f_1=-1$；换成 $i=2$ 就能切成 $[1,3]\;[3,1]\;[1]$。全枚举 $n \le 10$ 的所有数组能找出 **$540$ 组**这样的反例，所以必须把所有候选 $i$ 都看一遍。

### 3.2 核心观察：两条条件化成两条 ±1 游走

![两条条件对应两条 ±1 游走](images/cf2242_b_two_walks.svg)

设 $c_1(i)$ 为前缀 $a[1..i]$ 中 $1$ 的个数，$c_3(i)$ 为前缀中 $3$ 的个数。

**左段 $[1..i]$**：段内大于 $1$ 的元素有 $i-c_1(i)$ 个，条件为 $2\bigl(i-c_1(i)\bigr)\le i$，即

$$g(i) := 2\,c_1(i) - i \ \ge\ 0 .$$

**中段 $[i+1..j]$**：段内 $3$ 有 $c_3(j)-c_3(i)$ 个，段长 $j-i$，条件为 $2\bigl(c_3(j)-c_3(i)\bigr)\le j-i$，移项即

$$f(j) := 2\,c_3(j) - j \ \le\ 2\,c_3(i) - i = f(i).$$

**右段 $[j+1..n]$**：无约束，只要求 $j\le n-1$。

于是原问题等价于：**存在 $1\le i<j\le n-1$，使 $g(i)\ge 0$ 且 $f(j)\le f(i)$。**

两个量都是「每步加减 $1$」的游走，这点非常关键：

- $g(i)-g(i-1)$：$a_i=1$ 时 $+1$，$a_i\in\{2,3\}$ 时 $-1$；
- $f(i)-f(i-1)$：$a_i=3$ 时 $+1$，$a_i\in\{1,2\}$ 时 $-1$。

注意 **$2$ 对两条游走都是 $-1$**：它对左段是「坏元素」，对中段是「好元素」，这正是本题最容易写反的地方。

### 3.3 算法流程：倒序扫描 + 后缀最小值

![固定 i 后只看后缀里 f 的最小值](images/cf2242_b_split_window.svg)

固定 $i$ 后，$i$ 只出现在右边的 $f(i)$ 里，而 $j$ 只需**存在**。于是

$$\exists\, j\in[i+1,\,n-1]:\ f(j)\le f(i)\quad\Longleftrightarrow\quad M_i:=\min_{i<j\le n-1} f(j)\ \le\ f(i).$$

$M_i$ 就是后缀最小值。把所有可能的 $i$（$1\le i\le n-2$）从右往左扫一遍即可：扫到 $i$ 时，$M_i$ 恰好等于「已经并入的 $f(i+1),f(i+2),\dots,f(n-1)$」的最小值。

1. 递推 $f(0..n)$ 与 $g(0..n)$（$f(0)=g(0)=0$，不需要存前缀计数）；
2. `mn = +∞`，$i$ 从 $n-2$ 递减到 $1$：先 `mn = min(mn, f[i+1])`，再判 `g[i] >= 0 && mn <= f[i]`；
3. 命中即输出 `YES` 并结束本组；扫完仍未命中则输出 `NO`。

> ⚠️ 一定要**先更新 `mn` 再判定**。写反的话首个可能的 $j=i+1$ 就永远进不了 `mn`；样例第 $5$、$7$ 组恰好只有 $j=i+1$ 这一个候选，会直接被判成 `NO`。

## 4. 算法细节

1. **下标范围**：$i$ 最大取 $n-2$（后面至少还剩两段），$j$ 最大取 $n-1$（右段非空）。循环写成 `for (int i = n - 2; i >= 1; --i)`，$n=3$ 时正好只跑 $i=1$。
2. **递推而非存计数**：$f,g$ 都能用「读一个数就更新一次」递推，省掉两倍空间和一次求和；但注意 $2$ 对 $g$ 是 $-1$、对 $f$ 也是 $-1$，只有把 $3$ 读成 $f$ 的 $+1$、把 $1$ 读成 $g$ 的 $+1$。
3. **`mn` 的更新顺序**：先 `mn = min(mn, f[i+1])` 再判定，`mn` 的初值取 `INT_MAX`（Python 取 `10**18`），保证第一轮一定被 $f(i+1)$ 覆盖。
4. **多测清空**：$f,g$ 每组按 $n$ 重新 `vector<int>(n+1)` / `[0]*(n+1)`，不要用固定大小 $2\times10^5$ 的全局数组反复清空（$t=10^4$ 时纯属浪费）；总计 $O(\sum n)$ 次分配。
5. **整数范围**：$f,g\in[-n,n]$，`int` 足够；本题没有乘法，不需要 `long long`，也没有负数取模问题（Python 更无所谓）。
6. **本组必须读完**：即使中途命中 `YES`，也要先把本组 $n$ 个数读完（本例是先读完、构造完 $f,g$ 再扫，天然满足）。
7. **I/O**：C++ 关同步 + `'\n'`；Python 用 `sys.stdin.buffer.read().split()` 一次读完按下标推进，$t=10^4$ 时 `join` 一次性输出。

## 5. 正确性证明

**引理 1（左段条件的等价形式）**：切点 $i$ 使左段 $a[1..i]$ 合法 $\iff g(i)\ge 0$。

**证明**：左段长 $i$，段内大于 $1$ 的元素恰为 $i-c_1(i)$。条件 $2\bigl(i-c_1(i)\bigr)\le i$ 展开即 $2c_1(i)\ge i$，亦即 $g(i)=2c_1(i)-i\ge 0$。∎

**引理 2（中段条件的等价形式）**：$[i+1..j]$ 合法 $\iff f(j)\le f(i)$。

**证明**：段内 $3$ 的个数为 $c_3(j)-c_3(i)$，段长 $j-i$，条件 $2\bigl(c_3(j)-c_3(i)\bigr)\le j-i$，即 $2c_3(j)-j\le 2c_3(i)-i$，正是 $f(j)\le f(i)$。∎

**引理 3（存在 $j$ ⟺ 后缀最小）**：对固定 $i\le n-2$，存在 $j\in[i+1,n-1]$ 使 $f(j)\le f(i)$ $\iff M_i=\min_{i<j\le n-1}f(j)\le f(i)$。

**证明**：若某 $j$ 满足，则 $M_i\le f(j)\le f(i)$；反之若 $M_i\le f(i)$，由有限集最小值必在某处取到，取该处的下标 $j$（它属于 $[i+1,n-1]$），即有 $f(j)=M_i\le f(i)$。∎

**引理 4（扫描不变量）**：倒序循环进行到 `i` 时，`mn` $=M_i$。

**证明**：对 $i$ 归纳（从 $n-2$ 递减）。$i=n-2$ 时更新前 `mn` $=+\infty$，更新后并入 $f(n-1)$，而 $M_{n-2}=f(n-1)$（窗口只有一个元素），成立。设进入 $i$ 时 `mn` $=M_{i+1}=\min\{f(i+2),\dots,f(n-1)\}$，则更新后 `mn` $=\min\{f(i+1),\dots,f(n-1)\}=M_i$，成立。∎

**定理**：算法输出 `YES` $\iff$ 存在合法的三段划分。

**证明**：

- （$\Leftarrow$）若存在合法划分，取它的切点 $i,j$。由引理 1、2 得 $g(i)\ge0$ 与 $f(j)\le f(i)$，后者由引理 3 给出 $M_i\le f(i)$。算法会枚举到 $i$（因为 $1\le i\le n-2$），此时由引理 4 判定条件全部成立，输出 `YES`。
- （$\Rightarrow$）算法输出 `YES` 时，存在某个 $i$ 使 $g(i)\ge0$ 且 $M_i\le f(i)$；由引理 3 取到相应的 $j$，再逆用引理 1、2 可知 $[1..i]$、$[i+1..j]$ 均合法，而 $j\le n-1$ 保证 $[j+1..n]$ 非空且无约束。这是一组合法的三段划分。∎

## 6. 复杂度分析

- **时间**：每组两遍线性扫描（递推 $f,g$ 与倒序判定），$O(n)$；多测合计 $O(\sum n)\le 2\times10^5$，常数是每元素 2 次加法和 1 次 `min`，远低于读入开销。
- **空间**：每组 $O(n)$，两个 `int` 数组共约 $2(n+1)$ 个整数，$n=2\times10^5$ 时约 $1.6$ MB，远低于 512 MB。也可以完全不存数组（从右往左用后缀计数反推 $f(i),g(i)$），做到 $O(1)$。
- **实测**（本机 Apple clang + libc++，含读入与输出）：$t=1,n=2\times10^5$ 约 $0.13$ s；$t=10^4$、总长 $2\times10^5$ 约 $0.16$ s；Python3 同规模约 $0.09$ s。相对 $2$ s 时限留有 $12$ 倍以上余量。

## 7. 参考代码

### C++17

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <climits>
using namespace std;

int main() {
    ios::sync_with_stdio(false);          // 关同步，2e5 个数读入更快
    cin.tie(nullptr);

    int t;
    if (!(cin >> t)) return 0;            // 空输入防护
    while (t--) {
        int n;
        cin >> n;
        // f[i] = 2*pref3[i] - i，g[i] = 2*pref1[i] - i
        vector<int> f(n + 1), g(n + 1);
        int p1 = 0, p3 = 0;
        for (int i = 1; i <= n; ++i) {
            int x;
            cin >> x;
            if (x == 1) ++p1;             // 只有 1 让 g 上升
            if (x == 3) ++p3;             // 只有 3 让 f 上升；2 让两者都下降
            f[i] = 2 * p3 - i;
            g[i] = 2 * p1 - i;
        }
        bool ok = false;
        int mn = INT_MAX;                 // mn = min(f[i+1..n-1])
        for (int i = n - 2; i >= 1; --i) { // i 最大 n-2：中段、右段都要非空
            mn = min(mn, f[i + 1]);        // 先并入 f[i+1]，再判定
            if (g[i] >= 0 && mn <= f[i]) { ok = true; break; }
        }
        cout << (ok ? "YES\n" : "NO\n");
    }
    return 0;
}
```

### Python3

```python
import sys


def main() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    pos = 0
    t = int(data[pos]); pos += 1
    out = []
    for _ in range(t):
        n = int(data[pos]); pos += 1
        f = [0] * (n + 1)
        g = [0] * (n + 1)
        p1 = p3 = 0
        for i in range(1, n + 1):
            x = int(data[pos]); pos += 1
            if x == 1:
                p1 += 1
            if x == 3:
                p3 += 1
            f[i] = 2 * p3 - i
            g[i] = 2 * p1 - i
        ok = False
        mn = 10 ** 18
        for i in range(n - 2, 0, -1):      # 倒序扫，维护后缀最小值
            if f[i + 1] < mn:              # 先并入 f[i+1]
                mn = f[i + 1]
            if g[i] >= 0 and mn <= f[i]:
                ok = True
                break
        out.append("YES" if ok else "NO")
    sys.stdout.write("\n".join(out) + "\n")


main()
```

## 8. 边界情况与易错点

1. **只试最左候选 $i$ 会错**：官方第 $8$ 组 $[1,3,3,1,1]$ 就是反例（$i=1$ 不行、$i=2$ 行），$n\le10$ 的全枚举里有 $540$ 组这样的反例。必须扫完所有 $i$。
2. **$n=3$ 只有一种切法**：$i=1,j=2$，循环只跑一轮；如 $[1,2,3]$ 输出 `YES`、$[1,3,1]$ 输出 `NO`、$[2,1,2]$ 输出 `NO`。
3. **等号必须合法**：条件是 $2\cdot\text{个数}\le\text{段长}$，即 $g(i)\ge0$、$f(j)\le f(i)$ 都带等号：样例第 $1$ 组命中时 $g(6)=0$，第 $8$ 组命中时 $M_2=f(2)=0$，写成严格不等号就会 WA。
4. **全 $3$ 数组**：$g(1)=2\cdot0-1=-1<0$，$i=1$ 就出局，必然 `NO`（左段只要有元素就失败）。反过来**全 $1$ 数组**必然 `YES`：$i=1$ 时 $g(1)=1\ge0$，且 $f(i)=-i$ 单调下降，$M_1=f(n-1)=-(n-1)\le f(1)=-1$。
5. **$j$ 的上界**：$j\le n-1$，所以 $M_i$ 只能取到 $f(n-1)$。若把窗口算成 $[i+1,n]$，会允许右段为空而误判成 `YES`。
6. **`mn` 更新顺序**：先判定后更新会漏掉 $j=i+1$ 这一项，候选窗口只剩一个元素的用例（如样例第 $5$、$7$ 组）会被错判成 `NO`。
7. **多测规模与输出**：$t$ 可达 $10^4$，每组 `vector` 按 $n$ 分配即可，别用固定 $2\times10^5$ 的数组反复全量清零；输出大小写任意但必须独立成行，C++ 用 `'\n'` 而非 `endl`，Python 用 `join` 一次写出。

**延伸思考**：

1. **统一形式**：设 $c_t$ 为前缀中「$\le t$ 的个数」，则第 $t$ 段的条件可写成 $2c_t(r)-r\ \ge\ 2c_t(l-1)-(l-1)$，其中 $[l..r]$ 是该段。左段取 $t=1,l=1$ 时它恰是 $g(i)\ge g(0)=0$；中段取 $t=2,l=i+1$ 时左边那个量正是 $-f$，于是条件化成 $-f(j)\ge -f(i)$，与本文的 $f(j)\le f(i)$ 完全一致——也就是说统一形式里要维护的是「后缀**最大**值」。由此可推广到值域 $\{1..k\}$、切 $k$ 段、第 $t$ 段要求「$>t$ 的元素不超过一半」：逐段对相应的 $c_t$ 做一次后缀最值扫描即可。
2. **要求输出方案**：命中后回退一步，把取到 $M_i$ 的那个 $j$ 记下来（再扫描一次或同步存下标），即可 $O(n)$ 输出切点，不影响复杂度。
3. **推广到 $k\ge4$ 段、或要求最优化某段长度**：前者每多一段就多一条「游走量之间的大小关系」，判定变成「是否存在下标链 $i_1<\dots<i_{k-1}$ 逐段满足不等式」，逐层后缀最值可做到 $O(kn)$；后者（例如要求中段尽量长）只需把「存在 $j$」换成「最右的可行 $j$」，靠 $f$ 的后缀最值单调性同样 $O(n)$。
