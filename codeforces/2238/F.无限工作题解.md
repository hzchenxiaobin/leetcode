# Codeforces 无限工作 题解

## 1. 题目概述

- **标题 / 题号**：无限工作（Codeforces 2238F，英文名 Infinite Work）
- **链接**：https://codeforces.com/problemset/problem/2238/F
- **来源**：Codeforces Round 1106 (Div. 2) · Problem F
- **难度**：2600（2750 分）
- **限制**：时间 2.5 s / 内存 256 MB
- **标签**：组合数学、树、贪心、数学、计数（官方标签：combinatorics, graphs, greedy, math, trees）

**题意**：公司招了 $N=10^{10^{100}}$ 个学生，编号 $1\sim N$，构成一棵完全二叉树：$i$ 的直接上级是 $\lfloor i/2\rfloor$，直接下属是 $2i$ 和 $2i+1$（编号超过 $N$ 的不存在）。最初全员在岗。接下来 $n$ 天，每天依次两个阶段：

1. **招聘**：每个在岗学生把**当前不在岗**的直接下属招回岗位（当天刚被招回的人当天不能再招人）；
2. **开除**：任选若干**在岗**学生「直接开除」，某人被直接开除时其整棵子树被「间接开除」；学生 $1$ 永远不能被开除。

附加规则：**每个学生一生最多被开除一次**（无论直接被开除还是被间接开除）；若某人被重新雇佣，之后也不得再被开除。

目标：$n$ 天后恰好剩 $k$ 人在岗，并且**直接开除的总次数最少**。求同时满足这两条的「逐日直接开除集合」序列数，模 $10^9+7$。

**约束**：

- $1 \le t \le 10^5$，多测；
- $1 \le n \le 10^9$，$1 \le k \le 2\times 10^5$；
- 学生总数 $10^{10^{100}}$ 大得离谱，但真正会接触到的深度不超过 $k+n \le 2\times10^5+10^9 \ll 10^{100}$，所以可以把它当**无限完全二叉树**处理，永远碰不到编号上界；
- 答案对 $10^9+7$ 取模。

> 💡 一句话本质：所有直接开除的节点必须构成一条**反链**；被开除的子树每天只能往下恢复一层，于是「在第 $d$ 天开除」正好折合成 $2^{n-d}$ 个节点。题目于是变成「把 $k+1$ 拆成 $t$ 个 $2$ 的幂」，用贪心确定最小的 $t$，而且取到最小时多重集唯一，剩下的只是 Catalan 数与多重集排列数。

## 3. 解题思路

### 3.1 暴力思路

直接按天枚举「今天直接开除哪些在岗学生」：第 1 天全员在岗，可选子集有 $2^{N}$ 个，$N=10^{10^{100}}$，无法枚举；即便把树截断到前 $6$ 层只模拟 $n\le 4$ 天，合法子集序列也上万，更不用说 $n=10^9$。

暴力不可行的根源在于把「在岗集合」当成了主角。实际上最终只剩 $k$ 个在岗学生，意味着除这 $k$ 人之外的所有节点都必须被某次直接开除波及——能「活到最后」的结构只有一棵有限的、含根的、父闭的树。把这个核心结构记为 $R$，它的规模不超过 $k$，状态数就从 $10^{10^{100}}$ 掉到 $O(k)$。

### 3.2 核心观察：直接开除集合恰是一棵「永不离职树」的边界

![被开除的子树与永不离职的 R、边界 S](images/cf2238_f_tree_frontier.svg)

把时刻 $0$ 到 $n$ 的「在岗集合」记为 $W_0, W_1, \dots, W_n$（$W_0$ 是全体，无限大）。

1. **每天结束后 $W_d$ 都是父闭的**：招聘只把在岗点的孩子拉回来，开除只整棵子树地砍，两者都保持「$v$ 在岗 $\Rightarrow$ 上级在岗」。
2. **所有被直接开除的节点构成一条反链**（任意两个互不为祖先）。否则若有 $s$ 是 $s'$ 的祖先且二者都被直接开除，则 $s$ 被直接开除时 $\mathrm{subtree}(s)\ni s'$ 被间接开除，之后 $s'$ 再被直接开除（或同一天被直接、间接各算一次）就违反「一生最多一次」。于是各 $\mathrm{subtree}(s)$ 两两不交，每个被开除过的节点**唯一**属于某个 $\mathrm{subtree}(s)$。
3. **令 $R$ 为从未被开除过的节点集合**。$R$ 父闭、含根 $1$、必须有限（否则最终在岗人数无穷）。于是 $S$ 恰好是 $R$ 的**边界**：

$$S=\bigl\{v:\ \mathrm{parent}(v)\in R,\ v\notin R\bigr\}, \qquad |S|=|R|+1,$$

因为 $R$ 的 $2|R|$ 个孩子位置中有 $|R|-1$ 个被 $R$ 内部占用。**总直接开除次数就是 $|S|=|R|+1$。**

4. 反过来，任给一棵有限的、含根父闭的 $R$，把边界 $S$ 上各点各自挑一天开除即是合法方案（最终留下哪些节点由各点的开除日决定）。所以合法方案与「$R$ + $S$ 上各点的一次开除日」一一对应。

### 3.3 算法流程：把「第几天」翻译成 $2$ 的幂

![天数 d 折算成 2^(n-d)，归约到拆 2 的幂](images/cf2238_f_exponent_model.svg)

固定 $R$ 与每个 $s\in S$ 的开除日 $d_s\in[1,n]$，考察第 $n$ 天结束时 $\mathrm{subtree}(s)$ 里有谁在岗：

1. $s$ 在第 $d_s$ 天之前从没被开除过，所以一直在岗；它的上级在 $R$ 中、永远不会被开除，因此 $s$ 在第 $d_s+1$ 天被重新招回，第 $l$ 层后代在第 $d_s+l+1$ 天回来。
2. 到第 $n$ 天结束时，$\mathrm{subtree}(s)$ 里在岗的恰好是高度为 $n-d_s-1$ 的满二叉子树，共 $2^{n-d_s}-1$ 个节点（$d_s=n$ 时一个也没有）。
3. 因此

$$|W_n|=m+\sum_{s\in S}\left(2^{\,n-d_s}-1\right),\qquad m=|R|,\ t=|S|=m+1 .$$

代入 $|W_n|=k$ 并记 $j_s=n-d_s$、$N=k+1$，式子化为极其干净的

$$\sum_{s\in S}2^{\,j_s}=N,\qquad j_s\in[0,\ n-1].$$

4. 直接开除次数是 $t$，要**最少**。每项上限 $M=2^{n-1}$，最少项数用贪心：先尽量放 $M$，余数按二进制拆开，

$$t=q+\mathrm{popcount}(r),\qquad q=\left\lfloor\frac{N}{M}\right\rfloor,\quad r=N\bmod M .$$

5. 取到最小 $t$ 时**多重集唯一**：$q$ 个 $M$，加上 $r$ 的每个二进制位各一个。把这 $t$ 个幂分给 $S$ 中 $t$ 个**互不相同的具体节点**，方案数是多重集排列

$$\frac{t!}{q!}.$$

因为除 $M$ 外的指数互不相同，对应的阶乘因子全是 $1$。

6. 还剩 $R$ 的形状数：大小为 $m$、含根且父闭的集合与「$m$ 个结点的有序二叉树」（左孩子 $2v$、右孩子 $2v+1$）一一对应，共 $\mathrm{Cat}(m)=\dfrac{1}{m+1}\dbinom{2m}{m}$ 种。它与天数分配完全独立，相乘即得

$$\boxed{\ \text{ans}=\mathrm{Cat}(m)\cdot\frac{t!}{q!}\bmod (10^9+7)\ }$$

7. **唯一特判**：若 $N$ 是 $2$ 的幂（$k=1,3,7,15,\dots$ 且 $n$ 足够大），贪心给出 $t=1$，但 $|S|=|R|+1\ge 2$，必须把这一项拆成两个半幂，取 $t=2$、方案数为 $1$。

### 3.4 示例演算

![六组官方样例的演算表](images/cf2238_f_walkthrough.svg)

- $n=3,k=4$：$N=5$，$M=4$，$q=1$，$r=1$，$t=2$，$m=1$，$\mathrm{Cat}(1)=1$，$t!/q! = 2$，答案 $2$。多重集是 $\{2^2,2^0\}$，即边界两个节点一个在第 $3-2=1$ 天、一个在第 $3-0=3$ 天开除——正是样例解释里的两种方案。
- $n=20,k=14$：$N=15=1111_2$，$M=2^{19}>N$，故 $q=0$、$r=15$、$t=4$、$m=3$，$\mathrm{Cat}(3)=5$，$t!/q! = 4! = 24$，答案 $120$。
- $n=10^9,k=20$：$N=21=10101_2$，$M$ 巨大所以 $q=0$、$t=3$、$m=2$，$\mathrm{Cat}(2)=2$，$3! = 6$，答案 $12$。
- 自造 $n=3,k=6$：$N=7$，$M=4$，$q=1$，$r=3=11_2$，$t=3$，$m=2$，$\mathrm{Cat}(2)=2$，$t!/q! = 3!/1! = 6$，答案 $12$。

## 4. 算法细节

1. **移位必须先判范围**：$n$ 可达 $10^9$，$1\ll(n-1)$ 是未定义行为。由于 $N\le 2\times10^5+1$，只要 $n-1\ge 18$ 就有 $M=2^{n-1}>N$，此时直接取 $q=0,\ r=N$；只有 $n\le 18$ 才真正计算 $M=2^{n-1}$。
2. **预处理阶乘与逆元**：$t\le N\le 200001$，$m=t-1\le 200000$，$2m\le 400000$，所以阶乘表开到 $400020$；Catalan 用恒等式 $\mathrm{Cat}(m)=(2m)!\cdot(m!)^{-1}\cdot\bigl((m+1)!\bigr)^{-1}$，只需一次乘法和两次逆元表查询，避免每组再求逆元。
3. **$t!/q!$ 是整数**：多重集里除 $M$ 外的指数互不相同（$r$ 的二进制位），故 $\prod_j a_j! = q!\cdot 1\cdots1 = q!$；实现上就是 `fact[t] * invfact[q] % MOD`。
4. **popcount**：C++ 用 `__builtin_popcountll`；Python 用 `bin(r).count("1")`。$r<2^{18}$，位数极少。
5. **两组因子互相独立**：$\mathrm{Cat}(m)$ 只数 $R$ 的形状，$t!/q!$ 只数天数分配，二者相乘不需要任何容斥；这也是本题能 $O(1)$ 单组的根本原因。
6. **$n=1$ 的退化**：$M=1$，所有 $j_s$ 只能是 $0$，于是 $t=N=k+1$、$q=N$、$t!/q! = 1$，答案直接是 $\mathrm{Cat}(k)$，与「一天之内把整棵树砍到只剩 $k$ 个点」的 $k+1$ 次直接开除一致。
7. **读入输出**：$t=10^5$ 组，C++ 用 `scanf/printf`，Python 一次 `read().split()` 后线性处理，单组只做一次除模与一次 popcount。

## 5. 正确性证明

**引理 1（父闭性）**：对每个 $d=0,1,\dots,n$，$W_d$ 父闭，即 $v\in W_d\Rightarrow \mathrm{parent}(v)\in W_d$。

**证明**：$W_0$ 是全体，显然。设 $W_{d-1}$ 父闭。招聘阶段只加入 $W_{d-1}$ 中节点的孩子，加入后仍父闭；开除阶段砍掉的是若干棵完整的子树，砍完后若 $v$ 仍在岗，则它的所有祖先都不在被砍子树中、且在岗，故父闭保持。∎

**引理 2（反链与不交）**：所有被直接开除的节点构成反链 $S$，且 $\{\mathrm{subtree}(s)\}_{s\in S}$ 两两不交；每个被开除过的节点恰属于其中一个。

**证明**：若 $s\ne s'$ 且 $s$ 是 $s'$ 的祖先，则 $s'\in \mathrm{subtree}(s)$。无论二者是否同日开除，$s'$ 都会先被 $s$ 那次开除间接波及、再被自己直接开除（同日则间接与直接各算一次），违反「一生最多一次」。故 $S$ 是反链，子树两两不交。另一方面任何被开除的节点都源于某次直接开除，即落在某个 $\mathrm{subtree}(s)$ 中，且不交性保证唯一。∎

**引理 3（$S$ 是 $R$ 的边界）**：令 $R$ 为从未被开除过的节点集合，则 $R$ 有限、含 $1$、父闭，且 $S=\{v:\mathrm{parent}(v)\in R,\ v\notin R\}$，从而 $|S|=|R|+1$。

**证明**：$1$ 不能被开除，故 $1\in R$；由引理 2，$v\notin R\iff v\in\bigcup_s \mathrm{subtree}(s)$。若 $v\in R$ 则其上级 $\in R$：否则上级落在某棵 $\mathrm{subtree}(s)$ 里，$v$ 作为它的后代也会被开除，与 $v\in R$ 矛盾；故 $R$ 父闭。$R$ 有限，否则最终在岗人数无穷。再看边界：若 $\mathrm{parent}(v)\in R$ 而 $v\notin R$，设 $v\in \mathrm{subtree}(s)$；若 $v\ne s$，则 $\mathrm{parent}(v)\in \mathrm{subtree}(s)$，与上级在 $R$ 矛盾，故 $v=s\in S$。反之 $s\in S$ 的上级不属于任何子树（否则 $s$ 也属于该子树，与不交性矛盾），故上级在 $R$。于是边界恰为 $S$。计数：$R$ 内部占用 $|R|-1$ 个孩子位置，剩余 $2|R|-(|R|-1)=|R|+1$ 个正是 $S$。∎

**引理 4（恢复规模）**：若 $s\in S$ 在第 $d_s$ 天被直接开除，则第 $n$ 天结束时 $\mathrm{subtree}(s)$ 中在岗节点数为 $2^{\,n-d_s}-1$（$d_s=n$ 时为 $0$）。

**证明**：由引理 3，$s$ 的上级在 $R$ 中，从未被开除、始终在岗。$s$ 在第 $d_s$ 天前从未被开除，故一直在岗；$d_s$ 天被开除后，第 $d_s+1$ 天被上级招回，此后每过一天恢复一层，第 $l$ 层后代在第 $d_s+l+1$ 天回来。到第 $n$ 天结束，返回的层数 $l\le n-d_s-1$，恰构成 $0\sim n-d_s-1$ 层的满二叉树，节点数 $\sum_{l=0}^{n-d_s-1}2^l=2^{\,n-d_s}-1$；$d_s=n$ 时无人生还，为 $0$。这些节点也不会再被开除（$S$ 是反链，$\mathrm{subtree}(s)$ 内没有别的直接开除）。∎

**引理 5（人数公式）**：设 $m=|R|$、$t=|S|=m+1$、$N=k+1$、$j_s=n-d_s$，则 $|W_n|=k\iff \sum_{s\in S}2^{j_s}=N$，且 $j_s\in[0,n-1]$。

**证明**：$W_n$ 由 $R$ 与各 $\mathrm{subtree}(s)$ 的在岗部分组成，且两块不交（$R$ 与 $\bigcup\mathrm{subtree}(s)$ 互补），由引理 4 得 $|W_n|=m+\sum_s(2^{j_s}-1)=m+\sum_s 2^{j_s}-t$。代入 $k=m+\sum 2^{j_s}-(m+1)$ 即 $\sum_s 2^{j_s}=k+1=N$。$j_s=n-d_s$ 且 $d_s\in[1,n]$，故 $j_s\in[0,n-1]$。∎

**引理 6（最少项数与唯一性）**：对 $c\ge0$ 与 $x\ge0$，用 $t$ 个形如 $2^{j}\ (0\le j\le c)$ 的幂求和为 $x$ 时，最小项数为 $h_c(x)=\lfloor x/2^c\rfloor+\mathrm{popcount}(x\bmod 2^c)$，且取到最小项数时多重集唯一。

**证明**：对 $c$ 归纳。$c=0$ 时只能用 $1$，$h_0(x)=x$，唯一。设 $c\ge1$，$M=2^c$，写 $x=qM+r\ (0\le r<M)$，设用了 $a$ 个 $M$，剩下 $x-aM$ 只能用 $\le M/2=2^{c-1}$ 的幂，由归纳假设其最少项数为 $\lfloor (x-aM)/2^{c-1}\rfloor+\mathrm{popcount}((x-aM)\bmod 2^{c-1})$。而 $x-aM=2(q-a)2^{c-1}+r$，故

$$\phi(a)=a+2(q-a)+\mathrm{bit}_{c-1}(r)+\mathrm{popcount}(r\bmod 2^{c-1})=2q-a+\mathrm{popcount}(r),$$

它在 $a\in[0,q]$ 上严格递减，最小值只在 $a=q$ 处取得，值为 $q+\mathrm{popcount}(r)$；由归纳假设余下部分的多重集唯一，故整体唯一。∎

**引理 7（天数分配数）**：在最小 $t$ 下，把指数分给 $S$ 中 $t$ 个具体节点的方案数为 $t!/q!$。

**证明**：由引理 6，多重集为「$M=2^{n-1}$ 出现 $q$ 次」加上「$r$ 的每个二进制位各一次」。$r<2^{n-1}$，故这些位对应的指数都与 $n-1$ 不同且彼此不同，重数全为 $1$。把 $t$ 个带重数的指数排给 $t$ 个互不相同的节点，方案数是多重集排列数 $\dfrac{t!}{q!\,1!\cdots1!}=t!/q!$。∎

**引理 8（$R$ 的形状数）**：大小为 $m$ 的含根父闭集合共 $\mathrm{Cat}(m)$ 个。

**证明**：把每个节点的左孩子记为 $2v$、右孩子记为 $2v+1$，则「含根父闭、大小 $m$」与「$m$ 个结点的有序二叉树（每点 $0/1/2$ 个有序孩子）」一一对应，后者个数是 Catalan 数，标准递推 $f(m)=\sum_{a+b=m-1}f(a)f(b)$ 给出 $f(m)=\frac{1}{m+1}\binom{2m}{m}$。∎

**引理 9（$t=1$ 的修正）**：最小项数公式给出 $t=1$ 时，实际可取的最小直接开除次数为 $2$，且方案数为 $1$。

**证明**：$t=1$ 意味着 $N=2^{j}$ 且 $j\le n-1$。但由引理 3，$t=|S|=|R|+1\ge2$，故 $t=1$ 不可行。$t=2$ 可行：$2^j=2^{j-1}+2^{j-1}$，且 $j-1\le n-2\le n-1$ 合法。若两项为 $2^{a}+2^{b}=2^j$ 且 $a\le b$，当 $a<j-1$ 时另一项为 $2^j-2^a=2^a(2^{j-a}-1)$，其中 $2^{j-a}-1$ 是大于 $1$ 的奇数，不是 $2$ 的幂，矛盾；故只能 $a=b=j-1$，多重集唯一，分配方案数 $2!/2! = 1$。∎

**定理**：本文算法输出的数恰为满足条件的方案数。

**证明**：由引理 1–3，任一合法方案对应唯一的 $(R,\{d_s\}_{s\in S})$，且直接开除次数为 $|S|=|R|+1$；反之任一「有限含根父闭的 $R$ + 边界各点一个开除日」都能按定义逐日执行且不违反「一生最多一次」（反链保证被砍子树互不相交、每个 $s$ 在被开除前一直在岗）。由引理 5，最终人数为 $k$ 当且仅当 $\sum_s 2^{j_s}=N$、$j_s\in[0,n-1]$。由引理 6、9，最少次数 $t$ 与对应多重集唯一确定；由引理 7 分配数为 $t!/q!$；由引理 8，$R$ 的形状数为 $\mathrm{Cat}(t-1)$。三类选择互相独立，故方案总数 $=\mathrm{Cat}(t-1)\cdot t!/q!$，与算法一致。∎

## 6. 复杂度分析

- **时间**：预处理阶乘、逆元与 Catalan 表各 $O(K)$，其中 $K=2\times10^5$（阶乘上界 $2K$），逆元用一次快速幂 $O(\log 10^9)$；每组测试只做一次除法、一次取模和一次 popcount，$O(1)$（popcount 至多 $18$ 位）。总计 $O(K+t)$。实测 $t=10^5$ 组随机数据（$n$ 随机到 $10^9$、$k$ 随机到 $2\times10^5$）C++ 用时约 $31$ ms，Python 约 $0.28$ s，相对 $2.5$ s 时限余量在 $80$ 倍以上。
- **空间**：三个长度约 $4\times10^5$ 的 `long long` 数组（阶乘、逆阶乘、Catalan），约 $10$ MB，远低于 $256$ MB；Python 三个整数列表也在限额内。
- **对照时限**：即使 $t=10^5$ 且每个 $k=2\times10^5$，也只是「一次预处理 + 线性读入 + 每组常数次运算」，不存在按 $k$ 展开的循环。

## 7. 参考代码

### C++17

```cpp
#include <bits/stdc++.h>
using namespace std;

static const long long MOD = 1000000007LL;
static const int KMAX = 200005;  // k <= 2e5, so N = k+1 <= 200001

static long long modpow(long long b, long long e) {
    long long r = 1;
    b %= MOD;
    while (e > 0) {
        if (e & 1) r = r * b % MOD;
        b = b * b % MOD;
        e >>= 1;
    }
    return r;
}

int main() {
    int LIM = 2 * KMAX + 10;
    vector<long long> fact(LIM), invfact(LIM);
    fact[0] = 1;
    for (int i = 1; i < LIM; i++) fact[i] = fact[i - 1] * i % MOD;
    invfact[LIM - 1] = modpow(fact[LIM - 1], MOD - 2);
    for (int i = LIM - 2; i >= 0; i--) invfact[i] = invfact[i + 1] * (i + 1) % MOD;

    // Catalan: cat[m] = C(2m,m)/(m+1) = (2m)! / (m! * (m+1)!)
    vector<long long> cat(KMAX + 2);
    for (int m = 0; m <= KMAX + 1; m++)
        cat[m] = fact[2 * m] * invfact[m] % MOD * invfact[m + 1] % MOD;

    int t;
    if (scanf("%d", &t) != 1) return 0;
    while (t--) {
        long long n, k;
        scanf("%lld %lld", &n, &k);
        long long N = k + 1;              // need sum of powers of two == N
        long long q, r;
        if (n - 1 >= 18) {                // 2^(n-1) > N: the per-term cap never binds
            q = 0;
            r = N;
        } else {                          // n <= 19, shift is safe
            long long M = 1LL << (n - 1);
            q = N / M;
            r = N % M;
        }
        int terms = (int)(q + __builtin_popcountll((unsigned long long)r));
        long long ways;
        if (terms == 1) {                 // N is a power of two: t >= 2, split once
            terms = 2;
            ways = 1;
        } else {
            ways = fact[terms] * invfact[q] % MOD;   // terms! / q!
        }
        int m = terms - 1;                // |R| = t - 1
        printf("%lld\n", cat[m] * ways % MOD);
    }
    return 0;
}
```

### Python3

```python
import sys

MOD = 10 ** 9 + 7
KMAX = 200005


def main() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    t = int(data[0])

    lim = 2 * KMAX + 10
    fact = [1] * lim
    for i in range(1, lim):
        fact[i] = fact[i - 1] * i % MOD
    invfact = [1] * lim
    invfact[lim - 1] = pow(fact[lim - 1], MOD - 2, MOD)
    for i in range(lim - 2, -1, -1):
        invfact[i] = invfact[i + 1] * (i + 1) % MOD

    cat = [0] * (KMAX + 2)
    for m in range(KMAX + 2):
        cat[m] = fact[2 * m] * invfact[m] % MOD * invfact[m + 1] % MOD

    out = []
    pos = 1
    for _ in range(t):
        n = int(data[pos]); k = int(data[pos + 1]); pos += 2
        N = k + 1
        if n - 1 >= 18:                     # 2^(n-1) > N
            q, r = 0, N
        else:
            M = 1 << (n - 1)
            q, r = N // M, N % M
        terms = q + bin(r).count("1")       # minimum number of powers
        if terms == 1:                      # must be at least 2
            terms = 2
            ways = 1
        else:
            ways = fact[terms] * invfact[q] % MOD
        out.append(str(cat[terms - 1] * ways % MOD))
    sys.stdout.write("\n".join(out) + "\n")


main()
```

## 8. 边界情况与易错点

1. **移位未定义行为**：$n\le10^9$，直接写 `1 << (n-1)` 在 $n-1\ge31$ 时是 UB，可能得到乱七八糟的 `q`。必须先判 $n-1\ge18$（或任何 $\ge18$ 的阈值，因为 $M>2\cdot10^5\ge N$）并走 $q=0,r=N$ 分支。
2. **$N$ 是 $2$ 的幂时忘了抬高 $t$**：$k=1,3,7,15,\dots$ 且 $n$ 足够大时贪心给 $t=1$，若直接用会得到 $m=0$、$\mathrm{Cat}(0)=1$ 的「假答案」；实际上 $|S|=|R|+1\ge2$ 恒成立，必须取 $t=2$、方案数 $1$。
3. **$n=1$ 的退化**：$M=1$，指数只能是 $0$，$t=N$、$t!/q! = 1$，答案就是 $\mathrm{Cat}(k)$。样例 1（$k=1$）与样例 4（$k=5$ 得 $42$）都是这一支。
4. **下标与位宽**：$m$ 最大到 $K$，$2m$ 到 $2K=400000$，`fact` 必须开到 $2K+2$（只开 $K$ 会越界）；`cat[m] * ways` 虽在模下也可能接近 $10^{18}$，必须 `long long`，`int` 会溢出。Python 无此问题。
5. **$k=1$**：$N=2$。$n=1$ 时 $q=2,r=0,t=2$；$n\ge2$ 时贪心 $t=1$ 需特判成 $2$。两种情况答案都是 $1$（只剩学生 $1$，必须开掉 $2,3$），不要漏掉特判分支导致输出 $0$ 或 $1$ 的错配。
6. **把 $|S|=|R|+1$ 写成 $|S|=|R|$**：边界边数是 $2m-(m-1)=m+1$，这是后面 $t=m+1$、$\sum2^{j}=k+1$ 的来源；写成 $m$ 会让整个公式偏移 $1$（可用 $n=1,k=1$ 快速自检：正确答案 $1$，偏移后会变样）。
7. **多测性能**：$t=10^5$，C++ 不要用未解绑的 `cin`，Python 不要逐行 `input()`；一次读完再线性扫描即可。

**延伸思考**：

1. **改成 $c$ 叉树**：若每个学生有 $c$ 个直接下属，恢复区块大小变成 $\frac{c^{\,n-d}-1}{c-1}$，$R$ 的形状数变成 Fuss–Catalan 数 $\frac{1}{(c-1)m+1}\dbinom{cm}{m}$，其余推导（反链、贪心拆幂、分配数）一字不改。
2. **允许开除学生 $1$**：此时 $R$ 可以为空，$|S|=|R|+1$ 变成 $|S|\ge1$，$t=1$ 的特判消失，$N$ 为 $2$ 的幂时答案直接是 $\mathrm{Cat}(0)=1$ 乘 $1!/0! = 1$。
3. **问「恰好 $T$ 次直接开除」而非最少次数**：需要对所有多重集求和，用生成函数 $\prod_{j\ge0}\bigl(1-y\,x^{2^j}\bigr)^{-1}$ 的系数做按位 DP，$t!/q!$ 的权重要在 DP 里以「已用项数」的阶乘形式携带。
4. **把完全二叉树换成任意有根树**：反链、反链子树不交、「恢复一层/天」全部照旧，但恢复区块不再是 $2^{n-d}-1$，而是「以 $s$ 为根、只保留前 $n-d$ 层」的截断子树大小，于是「拆 $2$ 的幂」的漂亮结构消失，只能对每个 $s$ 单独计数，答案变成一个二维 DP。
5. **概率/期望版**：在所有「最少次数」方案中等概率随机选一个，问某个节点最终在岗的概率——按 $\mathrm{Cat}(m)$ 的子树结构与指数多重集分别计数即可，是本题的直接组合升级。
