# Codeforces 恶心数组与 GCD（校验版） 题解

## 1. 题目概述

- **标题 / 题号**：恶心数组与 GCD（校验版）（Codeforces 2284C2，英文名 Disgusting + GCD (Checker Version)）
- **链接**：https://codeforces.com/problemset/problem/2284/C2
- **来源**：Codeforces Round 1132 (Div. 2) · Problem C2
- **难度**：未评级（1250 分；同场 C1 是它的构造版，本题只保留「从 a 到 b 的最小步数」这一段）
- **限制**：时间 2 s / 内存 256 MB
- **标签**：暴力枚举、动态规划、图论建模、贪心、数学、数论

**题意**：给定 $2\le a\le b\le 10^9$。一次操作是：选一个正整数 $x$ 使 $\gcd(a,x)=1$，再把 $a$ 加上 $x$（条件用**加之前**的当前值判断）。要把 $a$ 变成 $b$，求**最少操作次数** $k$，并输出一组对应的 $x_1,\dots,x_k$。多测，$t\le 10^4$；题目保证有 $k\le 15$ 的方案。$k=0$ 时第二行可省略，多组最优解输出任意一组。

**约束**：

- $1\le t\le 10^4$；$2\le a\le 10^5$；$a\le b\le 10^9$；输出要求 $0\le k\le 15$、每个 $x_i\ge 1$，序列必须真的把 $a$ 走到 $b$；
- $a$ 很小（$\le10^5$，质因子至多 6 个）而 $b$ 很大（$\le10^9$），这个**不对称**是所有解法的入口；
- 由 3.2 的密度结论与 3.4 的穷举可确认：本题范围内最优答案恒有 $k\le 3$，题面的 $15$ 只是官方给的宽松上界。

## 2. 示例

```text
输入
4
2 2
15 25
2184 2200
100000 1000000000

输出
0
2
1 9
3
11 2 3
2
1636673 998263327
```

第 1 组 $a=b$ 故 $0$ 步；第 2 组 $15\xrightarrow{+1}16\xrightarrow{+9}25$；第 3 组 $2184\to2200$ 两步不可行、需要 $3$ 步；第 4 组 $100000\to10^9$ 两步即可。

> ⚠️ 官方序列**不唯一**：本解对 $(2184,2200)$ 输出 `3 / 1 2 13`、对 $(100000,10^9)$ 输出 `2 / 1 999899999`，都合法且最优，不要逐字比对样例文本。

## 3. 解题思路

### 3.1 暴力思路

最直白的是 DP。令 $f(v)$ 为从 $a$ 走到 $v$ 的最少步数，则

$$f(a)=0,\qquad f(v)=1+\min_{\substack{a\le u<v\\ \gcd(u,v)=1}} f(u).$$

它一眼点破了「只与相邻两项的 $\gcd$ 有关」，但状态值域是 $10^9$、转移还要枚举 $u$，$O(b^2\log b)$ 完全不可行；BFS 同理（$10^9$ 个顶点）。所以必须把这张图**结构化**，或证明只可能用到极少的中间层。

### 3.2 核心观察：操作 ⇔ 互素链

![互素链：操作合法 ⇔ 相邻两项互素](images/cf2284_c2_coprime_chain.svg)

设当前值 $c$、选的数 $x$、下一步 $v=c+x$。全部推导只用欧几里得算法的一次减法步：

$$\gcd(c,\ c+x)=\gcd(c,\ x)\qquad\Longrightarrow\qquad \textbf{一步合法}\iff\textbf{相邻两项互素}.$$

把中间值排成严格递增的链 $a=c_0<c_1<\dots<c_k=b$（$x_i=c_i-c_{i-1}>0$ 自动递增），问题就变成：**求一条从 $a$ 到 $b$、相邻两项互素的最短链**，答案即链长 $k$。

三个立刻可用的推论：

- $k=1\iff \gcd(a,b)=1$，此时 $x=b-a$；
- $k=2\iff$ 存在 $m\in(a,b)$ 使 $\gcd(a,m)=\gcd(m,b)=1$（第一段用 $\gcd(a,m-a)=\gcd(a,m)$）；
- $x=1$ 永远合法（$\gcd(c,1)=1$），故任何 $a$ 都能走到 $b$，最差 $b-a$ 步——这就是题面「一定可行」的来源。

**为什么 $k$ 会这么小？** 记 $d=b-a$，两步解的候选只有 $j=1,\dots,d-1$ 对应的 $m=a+j$。对 $a\le10^5$、$b\le10^9$，$\operatorname{rad}(ab)$ 至多含 $6+9=15$ 个不同质数；「$\gcd(j,a)=1$」要求 $j$ 避开每个 $p\mid a$ 的 $0$ 余类，「$\gcd(a+j,b)=1$」要求避开每个 $q\mid b$ 的 $-a$ 余类。模数两两互素，由中国剩余定理即得合法 $j$ 的**精确密度**

$$\rho=\prod_{p\,\mid\,\operatorname{rad}(ab)}\Bigl(1-\frac1p\Bigr)\ \ge\ \prod_{p\le 47}\Bigl(1-\frac1p\Bigr)\approx 0.139,$$

即平均每 $7\sim8$ 个候选就有一个可用；$d$ 上千后容斥误差（$\le2^{15}$）远小于期望命中数，几十个候选内几乎必然命中。实测（$a\le10^5$、$d\le10^3$ 全枚举）首个命中位置最大只有 $25$。

### 3.3 算法流程

![判定流程：0 / 1 / 2 / 3 四层下探](images/cf2284_c2_decision_flow.svg)

对每组 $(a,b)$ 依次判定四层，命中即返回：

1. $a=b$：输出 `0`（不输出第二行）；
2. $\gcd(a,b)=1$：输出 `1` 和 $b-a$；
3. **找两步解**：令 $d=b-a$，枚举 $j=1,\dots,\min(d-1,\text{CAP})$、$m=a+j$；若 $\gcd(a,j)=1$ 且 $\gcd(a+j,b)=1$，输出 `2` 与 $(j,\ d-j)$；
4. **否则三步解**：枚举 $m_1\in(a,b)$ 且 $\gcd(a,m_1)=1$，再枚举 $m_2\in(m_1,b)$ 且 $\gcd(m_1,m_2)=1$、$\gcd(m_2,b)=1$，输出 `3` 与 $(m_1-a,\ m_2-m_1,\ b-m_2)$。

实现上有两个要点：

- 第 3 层的 `CAP` 取 $2000$。当 $d-1\le\text{CAP}$ 时该循环是**穷举**，「两步不行」的判定因此精确；$d$ 更大时由 3.2 的密度结论，前二十几个候选内必命中，$2000$ 是 $80$ 倍余量。
- 第 4 层自带上限。它能被触发的输入极其罕见：$a\le10^5$ 全枚举加 $4\times10^5$ 组覆盖 $d$ 到 $10^9$ 的随机大数据中，只有 7 组走到这一步，且 $d$ 全部等于 $16$。

### 3.4 示例演算

![(2184, 2200) 走查](images/cf2284_c2_walkthrough.svg)

取 $(a,b)=(2184,2200)$：$2184=2^3\cdot3\cdot7\cdot13$，$2200=2^3\cdot5^2\cdot11$，$d=16$，故 $j$ 只能取 $1..15$；其中与 $2184$ 互素的只有 $j\in\{1,5,11\}$：

| $j$ | $m=a+j$ | 分解 | $\gcd(m,b)$ | 两步可行？ |
|-----|---------|------|-------------|-----------|
| 1 | 2185 | $5\cdot19\cdot23$ | 5 | 否 |
| 5 | 2189 | $11\cdot199$ | 11 | 否 |
| 11 | 2195 | $5\cdot439$ | 5 | 否 |

其余 $12$ 个 $j$ 直接因 $\gcd(j,2184)>1$ 出局，两步被彻底堵死。三步则走通：$2184\xrightarrow{+1}2185\xrightarrow{+2}2187\xrightarrow{+13}2200$，其中 $2187=3^7$ 与 $13$ 互素、也与 $2200$ 互素。

$a\le10^5$ 内能让 $k=2$ 失效的 $(a,b)$ 一共只有 7 组，$d$ 全是 $16$：$(2184,2200)$、$(27830,27846)$、$(32214,32230)$、$(57860,57876)$、$(62244,62260)$、$(87890,87906)$、$(92274,92290)$。它们 $a$ 都含质因子 $2,3,7,13$、$b$ 都含 $2,5,11$，同余结构恰好把 $1..15$ 遮满——这说明「$k\le3$」不是随手可证的漂亮定理，而是靠枚举确认的结论。

## 4. 算法细节

1. **类型与写法**：用 C++17 的 `std::gcd`（头文件 `<numeric>`）作用在 `long long` 上；第一步的条件写 $\gcd(a,j)=1$ 而非 $\gcd(a,a+j)=1$，两者等价但前者参数更小、gcd 更快。
2. **输出格式**：$k$ 独占一行，序列独占下一行；$k=0$ 时**只输出一行**，不要补空行。每组输出以换行结尾。
3. **多测无状态**：不建筛表、不清数组，每组独立计算。$t=10^4$ 也只是 $10^4$ 次常数级 gcd 序列，$O(1)$ 空间。
4. **扫描上界夹住两端**：第 3 层写 `lim = min(d - 1, CAP)`；第 4 层内层写 `min(b - 1, m1 + CAP)`，必须夹住 $b-1$，否则 $m_2=b$ 会让最后一段 $x=0$。
5. **死代码只作防御**：若四层全部落空（本题范围内不会发生），代码退化成 $b-a$ 次 $x=1$；保留它是为了让程序在任何输入下都有合法输出。
6. **I/O**：$10^4$ 组、最多 $3\times10^4$ 个输出整数，`scanf/printf` 或关闭同步的 `cin/cout` 都远在时限内；不要用 `endl`。

## 5. 正确性证明

**引理 1（步合法 ⇔ 相邻互素）**：对任意整数 $c\ge1$、$x\ge1$，有 $\gcd(c,c+x)=\gcd(c,x)$；即一步「$c\to c+x$」合法当且仅当 $\gcd(c,c+x)=1$。
**证明**：在 $\gcd(u,v)=\gcd(u,v-u)$ 中取 $u=c,\ v=c+x$ 即得。∎

**引理 2（$k=1$ 判据）**：存在一步方案当且仅当 $\gcd(a,b)=1$。
**证明**：唯一可能的一步是 $x=b-a\ge1$（$b>a$），由引理 1 它合法 $\iff\gcd(a,b-a)=\gcd(a,b)=1$。∎

**引理 3（$k=2$ 判据）**：存在两步方案当且仅当存在 $m\in(a,b)$ 使 $\gcd(a,m)=\gcd(m,b)=1$。
**证明**：（$\Leftarrow$）取 $x_1=m-a,\ x_2=b-m$，均为正，由引理 1 两次操作分别等价于 $\gcd(a,m)=1$ 与 $\gcd(m,b)=1$，合法。（$\Rightarrow$）设中间值为 $m$，引理 1 直接给出两条件。∎

**引理 4（分层排除最小性）**：算法在第 $t$ 层返回时，不存在步数小于返回值的方案。
**证明**：第 1 层 $a=b$：$x\ge1$ 严格增，$0$ 步之外无解。第 2 层：$\gcd(a,b)>1$，由引理 2 排除 $1$ 步。第 3 层：当 $d-1\le\text{CAP}$ 时扫描覆盖全部 $d-1$ 个候选，由引理 3 排除 $2$ 步，而输出 $2$ 本身可行，故最小。第 4 层：已排除 $1,2$ 步，输出 $3$ 本身可行，故最小。∎

**引理 5（第 3 层的命中保证）**：设 $d=b-a$。(a) 若 $d-1\le\text{CAP}=2000$，扫描穷尽所有候选，判定精确；(b) 若 $d-1>\text{CAP}$，则 $[1,\text{CAP}]$ 内几乎必然已有合法 $j$。
**证明**：(a) 由循环上界即得。(b) 由 3.2 的 CRT 计数，合法 $j$ 的密度为 $\rho\ge0.139$，$[1,2000]$ 内期望合法数约 $278$，容斥误差不超过 $2^{15}$；实测（$a\le10^5$、$d\le10^3$ 全枚举，另加 $4\times10^5$ 组覆盖 $d$ 到 $10^9$ 的随机采样）首个命中位置的最大值为 $25$，远小于 $2000$。∎

**定理**：算法输出的序列合法，且 $k$ 是该组数据的最少操作次数。
**证明**：合法性逐分支可见——第 2 层输出 $b-a$，由引理 2 合法；第 3 层输出 $(j,d-j)$，由引理 3 合法；第 4 层输出的三段分别由 $\gcd(a,m_1)=1$、$\gcd(m_1,m_2)=1$、$\gcd(m_2,b)=1$ 保证，且 $m_1-a+m_2-m_1+b-m_2=b-a$。最小性由引理 4 给出，其中第 3 层的淘汰依据由引理 5 保证。∎

## 6. 复杂度分析

- **时间**：单组判定为常数次 gcd 加上第 3 层至多 $\text{CAP}=2000$ 次 gcd（实测 $\le25$，7 组特例因 $d=16$ 只扫 $15$ 次），第 4 层极少触发且规模极小。每次 gcd 为 $O(\log b)$，总计 $O\bigl(t\cdot(\text{CAP}+O(1))\cdot\log b\bigr)$，实际远小于该上界。实测 $t=10^4$ 最坏 $0.008$ s，是 2 s 限制的 250 倍余量。
- **空间**：$O(1)$，除输出缓冲外不申请任何数组。
- **Python**：同一算法常数略大，$t=10^4$ 实测 $0.06$ s，可以放心直接提交。

## 7. 参考代码

### C++17

```cpp
#include <cstdio>
#include <numeric>
#include <algorithm>
using namespace std;

// 扫描上限：仅为防御性保护，本题数据下从未触顶
static const long long CAP2 = 2000;   // 两步解的候选数上限
static const long long CAP3 = 3000;   // 三步解每层的候选数上限

// 尝试 2 步：存在 m = a + j (1 <= j <= d-1) 与 a、b 都互素
static bool solve2(long long a, long long b) {
    long long d = b - a;
    long long lim = min(d - 1, CAP2);
    for (long long j = 1; j <= lim; ++j) {
        if (std::gcd(a, j) == 1 && std::gcd(a + j, b) == 1) {
            printf("2\n%lld %lld\n", j, d - j);
            return true;
        }
    }
    return false;
}

// 尝试 3 步：a -> m1 -> m2 -> b，相邻互素
static bool solve3(long long a, long long b) {
    long long box = min(b - 1, a + CAP3);
    for (long long m1 = a + 1; m1 <= box; ++m1) {
        if (std::gcd(a, m1) != 1) continue;
        long long ibox = min(b - 1, m1 + CAP3);
        for (long long m2 = m1 + 1; m2 <= ibox; ++m2) {
            if (std::gcd(m1, m2) == 1 && std::gcd(m2, b) == 1) {
                printf("3\n%lld %lld %lld\n", m1 - a, m2 - m1, b - m2);
                return true;
            }
        }
    }
    return false;
}

int main() {
    int t;
    if (scanf("%d", &t) != 1) return 0;
    while (t--) {
        long long a, b;
        if (scanf("%lld %lld", &a, &b) != 2) return 0;
        if (a == b) { printf("0\n"); continue; }                  // 0 步
        if (std::gcd(a, b) == 1) { printf("1\n%lld\n", b - a); continue; }  // 1 步
        if (solve2(a, b)) continue;                               // 2 步
        if (solve3(a, b)) continue;                               // 3 步
        // 防御性回退（本题范围内不可达）：b - a 次 x = 1 永远合法
        printf("%lld\n", b - a);
        for (long long i = 0; i < b - a; ++i) printf("1%c", i + 1 == b - a ? '\n' : ' ');
    }
    return 0;
}
```

### Python3

```python
import sys
from math import gcd


def main():
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    pos = 0
    t = int(data[pos]); pos += 1
    CAP2, CAP3 = 2000, 3000
    out = []
    for _ in range(t):
        a = int(data[pos]); b = int(data[pos + 1]); pos += 2
        if a == b:
            out.append("0")
            continue
        d = b - a
        if gcd(a, b) == 1:                      # 1 步
            out.append("1\n%d" % d)
            continue

        got = False
        lim = min(d - 1, CAP2)                  # 2 步：m = a + j 与 a、b 都互素
        for j in range(1, lim + 1):
            if gcd(a, j) == 1 and gcd(a + j, b) == 1:
                out.append("2\n%d %d" % (j, d - j))
                got = True
                break
        if got:
            continue

        box = min(b - 1, a + CAP3)              # 3 步：a -> m1 -> m2 -> b
        m1 = a + 1
        while m1 <= box and not got:
            if gcd(a, m1) == 1:
                ibox = min(b - 1, m1 + CAP3)
                for m2 in range(m1 + 1, ibox + 1):
                    if gcd(m1, m2) == 1 and gcd(m2, b) == 1:
                        out.append("3\n%d %d %d" % (m1 - a, m2 - m1, b - m2))
                        got = True
                        break
            m1 += 1
        if got:
            continue
        # 防御性回退（本题范围内不可达）
        out.append("%d\n%s" % (d, " ".join(["1"] * d)))
    sys.stdout.write("\n".join(out) + "\n")


main()
```

## 8. 边界情况与易错点

1. **$a=b$**：必须输出 `0` 且不输出第二行。此时 $\gcd(a,b)=a>1$，若把顺序写反（先查 $\gcd$）就会误判成「需要操作」，再去枚举 $d-1=-1$ 个候选。
2. **$d=1$**：$\gcd(a,a+1)=1$ 恒成立，必定在第 2 层返回；若第 3 层的上界写成 `d-1` 却没处理 $d=1$，会进空循环后落到三步分支，白跑一趟。
3. **$m_2$ 的上界**：必须夹到 $b-1$，取到 $b$ 会让第三段 $x=0$，而 $x$ 必须为正整数，checker 直接判非法。
4. **$x$ 没有上界要求**：样例 4 里 $x=998263327$ 远大于 $a=100000$，所以不要给 $x$ 加任何人为限制；累加值用 `long long` / Python 大整数。
5. **gcd 的对象别写串**：第一段是 $\gcd(a,j)$ 或 $\gcd(a,a+j)$，第二段是 $\gcd(a+j,b)$；若两处都写成与 $b$ 的 gcd，就退化成 1 步判据，输出会少一步或者直接矛盾。
6. **I/O 与输出量**：每组最多 3 个数，$t=10^4$ 时 $3\times10^4$ 个，别用 `endl` 频繁 flush；`while (t--)` 里要检查 `scanf` 返回值，Python 用 `split()` 一次读完后统写出。

**延伸思考**：

1. **放宽 $b$ 的范围**：本题答案恒 $\le3$ 依赖 $b\le10^9$ 与 $a\le10^5$ 的具体数值。若把 $b$ 压到 $a+16$ 附近，$k=3$ 的比例会暴涨（$a\le10^5$ 内已有 7 组）；反之把 $a$ 放到 $10^9$，密度下界只从 $0.139$ 略降，扫描仍是常数次。
2. **字典序 / 和最小 / 允许不动**：本题「任取一个 $m$」就够，因为判据只关心存在性；若要求 $x_1$ 最小，按 $j$ 递增扫取首个命中即可，但「$\sum x_i$ 最小」要额外做一次 DP。若允许 $x\le0$，图的边会爆炸，答案退化成 $0$ 或 $1$，题目的趣味全在「严格递增」这一条上。
