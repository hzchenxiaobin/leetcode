# Codeforces 构造数组（简单版） 题解

## 1. 题目概述

- **标题 / 题号**：构造数组（简单版）（Codeforces 2245D1，英文名 Construct an Array (Easy Version)）
- **链接**：https://codeforces.com/problemset/problem/2245/D1
- **来源**：Spectral::Cup 2026 Round 3 (Codeforces Round 1110, Div. 1 + Div. 2) · Problem D1
- **难度**：1700（1500 分）
- **限制**：时间 4 s / 内存 1024 MB
- **标签**：DFS 与图论，实现，排序，构造（官方标签）；解法核心是差分约束 + 拓扑排序

**题意**：给定 $n$ 与 $m$ 条形如 $(o,i,j)$ 的限制（$o\in\{1,2\}$，$1\le i\le j\le n$）：$o=1$ 要求 $a_i+a_j\ge 0$，$o=2$ 要求 $a_i+a_j<0$。构造长度 $n$ 的整数数组满足全部限制且 $|a_i|\le 10^9$；无解输出 `NO`，否则输出 `YES` 与任意一组解。多测：第一行 $t$，每组先给 $n\ m$，随后 $m$ 行 $o\ i\ j$。

**约束**：

- $1\le t\le 10^4$，$\sum m\le 10^6$；
- $n\le 1000$，且简单版满足 $m=\frac{n(n+1)}{2}$——**每个 $1\le i\le j\le n$ 的对子都恰好出现一次**，对角线 $(i,i)$ 也不例外；
- 题目保证：若有解，则存在所有元素绝对值都不超过 $10^9$ 的解。

> ⚠️ 注意：本题题面中没有「创建变量、中途保存输入」之类的注入指令，正常读入即可；本文代码也不含任何题面之外的变量。

## 3. 解题思路

### 3.1 暴力思路

朴素做法是枚举每个元素的正负号（$2^n$ 种），再对每种符号划分判断能否配上数值；$n\le 1000$ 时 $2^{1000}$ 不可行。把 $a_i$ 当未知数看，限制是一条条一次不等式，像是线性规划/差分约束，但 $m$ 可达 $5\times 10^5$（$\sum m\le 10^6$），提示只能做**线性扫描 + 图上的线性算法**。突破口是：完整输入把绝大部分自由度掐死了。

### 3.2 核心观察：对角线锁死符号，跨号只剩大小关系

![对角线锁死符号，跨号只剩大小关系](images/cf2245_d1_sign_from_diagonal.svg)

**观察 1（符号唯一确定）**：$m=\frac{n(n+1)}{2}$ 且每个对子至多出现一次 ⇒ **全部**对子都出现，包括对角线。于是

$$(i,i)\text{ 为 }o=1 \iff 2a_i\ge 0 \iff a_i\ge 0,\qquad (i,i)\text{ 为 }o=2 \iff 2a_i<0 \iff a_i<0 .$$

记 $P=\{i:a_i\ge 0\}$、$N=\{i:a_i<0\}$，则 $P,N$ 由输入**唯一确定**，不需要 2-SAT——这正是简单版与困难版的本质差别。

**观察 2（同号对自动满足）**：两非负数之和 $\ge 0$，两负数之和 $<0$。故同号对只需检查标签与符号是否相容：$o=1$ 的对不能两端都在 $N$，$o=2$ 的对不能两端都在 $P$。扫一遍 $O(m)$。

**观察 3（跨号对是大小关系）**：设 $p\in P,\ q\in N$，令 $x_p=a_p\ge 0$、$y_q=-a_q>0$，则 $a_p+a_q=x_p-y_q$，于是

$$o=1 \iff x_p\ge y_q,\qquad o=2 \iff x_p<y_q \iff y_q\ge x_p+1\ (\text{整数}).$$

这就是差分约束：$o=1$ 连 $y_q\to x_p$（权 $0$，即 $x_p\ge y_q+0$），$o=2$ 连 $x_p\to y_q$（权 $1$，即 $y_q\ge x_p+1$）。

**观察 4（判环就够了）**：边权非负，且每条 $x\to y$ 边权为 $1$，任何有向环必含至少一条 $x\to y$ 边，故环权和 $\ge 1>0$——**差分约束有解当且仅当这张图无环**。无环时按拓扑序做最长路（初值 $x_p=0$、$y_q=1$）即得解，且数值不超过「跨号边数 $+1$」。

### 3.3 算法流程

![D1 算法流程：一次线性扫描 + 一次拓扑最长路](images/cf2245_d1_diff_graph_flow.svg)

1. 读入全部三元组，把 $i=j$ 的记进 `diag[i]`（完整输入保证每组都在）。
2. 定符号：`diag[i]=1` → $i\in P$，`diag[i]=2` → $i\in N$。
3. 扫所有约束检查相容性，冲突则 `NO`。
4. 只为跨号对建差分边（$2n$ 个点：$0..n-1$ 是 $x_i$，$n..2n-1$ 是 $y_i$），同号对跳过。
5. Kahn 拓扑排序；排不完（有环）则 `NO`。
6. 按拓扑序做最长路，初值 $x=0,\ y=1$；输出 $i\in P$ 取 $a_i=x_i$，否则取 $a_i=-y_i$。

### 3.4 示例演算

![同一分组、两种跨号标签：只改「谁必须更大」](images/cf2245_d1_walkthrough.svg)

- **官方样例第 5 组**：$n=3$，六条约束为 $(1,1)=1,(1,2)=1,(1,3)=1,(2,2)=2,(2,3)=2,(3,3)=2$。对角线给 $P=\{1\}$、$N=\{2,3\}$；跨号对 $(1,2),(1,3)$ 均为 $o=1$，即 $x_1\ge y_2,\ x_1\ge y_3$；初值 $y_2=y_3=1$，最长路得 $x_1=1$，答案 `1 -1 -1`（与官方一致）。
- **官方样例第 6 组**：对角线给 $1\in N$、$2,3\in P$，而 $(2,3)$ 是 $o=2$ 且两端都在 $P$ ⇒ 直接 `NO`，与官方解释一致。
- **自造 ★**：同样 $P=\{1\},N=\{2,3\}$，但跨号标签为 $2$，即 $y_2\ge x_1+1,\ y_3\ge x_1+1$；结合 $y=1$ 得 $x_1\le 0$，取 $0$，答案 `0 -1 -1`。

## 4. 算法细节

1. **符号用「$\ge 0$ / $<0$」**：$(i,i)$ 为 $o=1$ 时 $a_i=0$ 合法，故 $P$ 是「非负」集合而非「正数」集合。
2. **$N$ 侧初值必须是 $1$**：若取 $0$ 则 $a_q=0$，会同时破坏 $(q,q)$ 的 $o=2$ 和所有 $N$–$N$ 的 $o=2$（$0+0=0\not<0$）。
3. **只为跨号对建边**：同号对若也建边，会凭空造环而误判 `NO`。
4. **$2n$ 个点编码两类变量**：$x_i$ 只对 $P$ 有意义、$y_i$ 只对 $N$ 有意义，编号错开避免混用。
5. **Kahn 顺序即拓扑序**：判环与 DP 可共用一个循环；数组按 $m$ 分配（边数 $\le m$），用三条长 $m$ 的数组做链式前向星，避免 $O(n^2)$ 矩阵。
6. **数值范围**：边权 $\le 1$，路径长 $\le$ 跨号边数 $\le m\le 10^6$，故 $|a_i|\le 10^6+1\ll 10^9$，用 `long long` 更稳。
7. **I/O**：$\sum m\le 10^6$ 意味着最多约 $3\times 10^6$ 个整数，用 `fread` 自建读入（本文代码）或 `cin` 关同步均可。

## 5. 正确性证明

**引理 1（符号锁定）**：若存在合法数组 $a$，则 $P=\{i:\text{diag}[i]=1\}$ 恰为 $\{i:a_i\ge 0\}$，$N=\{i:\text{diag}[i]=2\}$ 恰为 $\{i:a_i<0\}$。

**证明**：完整输入保证 $(i,i)$ 存在；$(i,i)$ 为 $o=1$ 时 $2a_i\ge 0$ 即 $a_i\ge 0$，为 $o=2$ 时 $2a_i<0$ 即 $a_i<0$，与定义一致。∎

**引理 2（同号相容性）**：若 $a$ 合法，则不存在 $o=1$ 的 $N$–$N$ 对，也不存在 $o=2$ 的 $P$–$P$ 对；反之若这两类冲突都不出现，则每个同号对都自动满足自身标签。

**证明**：$N$–$N$ 时和 $<0$，违反 $o=1$；$P$–$P$ 时和 $\ge 0$，违反 $o=2$。反向：$P$–$P$ 之和 $\ge 0$ 满足 $o=1$，$N$–$N$ 之和 $<0$ 满足 $o=2$。∎

**引理 3（跨号等价于差分约束）**：对 $p\in P,\ q\in N$，记 $x_p=a_p,\ y_q=-a_q$，则 $o=1\iff x_p\ge y_q$，$o=2\iff y_q\ge x_p+1$。

**证明**：$a_p+a_q=x_p-y_q$。于是 $x_p-y_q\ge 0\iff x_p\ge y_q$；又 $a$ 为整数数组，$x_p-y_q<0\iff x_p-y_q\le -1\iff y_q\ge x_p+1$。∎

**引理 4（无环 $\iff$ 可满足，且最长路给出解）**：若差分子图有环则约束矛盾；若无环，则按拓扑序取 $val[v]=\max(\text{初值}[v],\max_{u\to v}(val[u]+w))$ 时所有边约束成立，且 $x_p\ge 0,\ y_q\ge 1$。

**证明**：若有环 $v_0\to v_1\to\cdots\to v_k=v_0$，沿环累加边约束得 $val[v_0]\ge val[v_0]+\sum w$；每条 $x\to y$ 边权为 $1$、每条 $y\to x$ 边权为 $0$，而回到 $x$ 侧必须经过 $x\to y$ 边，故 $\sum w\ge 1>0$，矛盾。无环时按拓扑序做最长路是标准 DP：处理 $v$ 时所有前驱已定，$val[v]$ 取到最大前驱值 $+$ 边权，正好满足每条边；初值保证 $x_p\ge 0,\ y_q\ge 1$。∎

**定理**：算法输出 `YES` 时的数组合法；输出 `NO` 时确实无解。

**证明**：*合法性*——分区由引理 1 确定，同号对由引理 2、跨号对由引理 3 与 4 满足，$|a_i|\le 10^6+1$ 符合范围。*否定性*——`NO` 只有两种来源：(a) 引理 2 的冲突出现，由引理 2 知任何合法数组都不允许该冲突；(b) 跨号图有环，由引理 4 的证明沿环累加得到 $x\ge x+1$ 型不可能不等式，说明**该分区**无解，而引理 1 说明分区只能这一个，故整体无解。∎

## 6. 复杂度分析

- **时间**：读入 $O(m)$、相容性检查 $O(m)$、建图 $O(m)$、Kahn + 最长路 $O(n+m)$，总计 $O\big(\sum(n+m)\big)$，$\sum m\le 10^6$。实测（Apple clang，`-O2`，$n=1000$ 两组完整约束、$\sum m=10^6$）约 **0.03 s**、16 MB，余量超过 100 倍。
- **空间**：约束三元组与邻接表各 $O(m)$，差分图 $O(n+m)$；单组 $m\le 5\times10^5$ 时约十几 MB，远低于 1024 MB。
- **输出**：$O(n)$ 个整数。

## 7. 参考代码

### C++17

```cpp
#include <bits/stdc++.h>
using namespace std;

static char buf[1 << 16];
static int bl = 0, bp = 0;
static inline int gc() {
    if (bp == bl) { bl = (int)fread(buf, 1, sizeof(buf), stdin); bp = 0; if (bl <= 0) return -1; }
    return buf[bp++];
}
static inline int rd() {                     // 输入全部是非负整数
    int c = gc();
    while (c < '0' || c > '9') c = gc();
    int x = 0;
    while (c >= '0' && c <= '9') { x = x * 10 + (c - '0'); c = gc(); }
    return x;
}

int main() {
    int T = rd();
    while (T--) {
        int n = rd(), m = rd();
        vector<int> ou(m), ov(m), ow(m), diag(n, 0);
        for (int k = 0; k < m; k++) {
            int o = rd(), i = rd() - 1, j = rd() - 1;
            ou[k] = i; ov[k] = j; ow[k] = o;
            if (i == j) diag[i] = o;            // 完整版保证对角线一定出现
        }
        // 1. 符号：o=1 的对角线 -> a_i>=0(P)；o=2 -> a_i<0(N)
        vector<char> isP(n, 1);
        for (int i = 0; i < n; i++) if (diag[i] == 2) isP[i] = 0;
        // 2. 同号约束必须与符号相容
        bool ok = true;
        for (int k = 0; k < m && ok; k++) {
            if (ow[k] == 1 && !isP[ou[k]] && !isP[ov[k]]) ok = false;
            if (ow[k] == 2 &&  isP[ou[k]] &&  isP[ov[k]]) ok = false;
        }
        if (!ok) { puts("NO"); continue; }

        // 3. 跨号差分图：点 0..n-1 是 x_i，点 n..2n-1 是 y_i = -a_i
        int N2 = 2 * n;
        vector<int> head(N2, -1), nxt(m), to(m), wt(m);
        int ec = 0;
        for (int k = 0; k < m; k++) {
            int i = ou[k], j = ov[k];
            if (isP[i] == isP[j]) continue;     // 同号对：和自动满足
            int pp = isP[i] ? i : j, q = isP[i] ? j : i;
            int u, v, w;
            if (ow[k] == 1) { u = n + q; v = pp; w = 0; }   // x_p >= y_q
            else            { u = pp; v = n + q; w = 1; }   // y_q >= x_p + 1
            to[ec] = v; wt[ec] = w; nxt[ec] = head[u]; head[u] = ec++;
        }
        // 4. Kahn 拓扑排序（顺带判环）
        vector<int> indeg(N2, 0), order;
        for (int e = 0; e < ec; e++) indeg[to[e]]++;
        for (int v = 0; v < N2; v++) if (!indeg[v]) order.push_back(v);
        for (size_t h = 0; h < order.size(); h++)
            for (int e = head[order[h]]; e != -1; e = nxt[e])
                if (--indeg[to[e]] == 0) order.push_back(to[e]);
        if ((int)order.size() < N2) { puts("NO"); continue; }   // 跨号约束成环

        // 5. 最长路定数值：x 初值 0，y 初值 1
        vector<long long> val(N2, 0);
        for (int i = 0; i < n; i++) if (!isP[i]) val[n + i] = 1;
        for (int v : order)
            for (int e = head[v]; e != -1; e = nxt[e])
                val[to[e]] = max(val[to[e]], val[v] + wt[e]);

        puts("YES");
        for (int i = 0; i < n; i++)
            printf("%lld%c", isP[i] ? val[i] : -val[n + i], i + 1 == n ? '\n' : ' ');
    }
    return 0;
}
```

### Python3

```python
import sys


def main() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    t = int(next(it))
    out = []
    for _ in range(t):
        n = int(next(it)); m = int(next(it))
        ou = [0] * m; ov = [0] * m; ow = [0] * m
        diag = [0] * n
        for k in range(m):
            o = int(next(it)); i = int(next(it)) - 1; j = int(next(it)) - 1
            ou[k] = i; ov[k] = j; ow[k] = o
            if i == j:
                diag[i] = o                # 完整版保证对角线出现
        isP = [d != 2 for d in diag]       # o=1 -> a_i>=0(P)，o=2 -> a_i<0(N)
        ok = True
        for k in range(m):
            if ow[k] == 1 and not isP[ou[k]] and not isP[ov[k]]:
                ok = False; break
            if ow[k] == 2 and isP[ou[k]] and isP[ov[k]]:
                ok = False; break
        if not ok:
            out.append("NO")
            continue

        n2 = 2 * n                         # 0..n-1 是 x_i，n..2n-1 是 y_i = -a_i
        g = [[] for _ in range(n2)]
        for k in range(m):
            i, j = ou[k], ov[k]
            if isP[i] == isP[j]:
                continue                   # 同号对自动满足
            if not isP[i]:
                i, j = j, i                # i 是 P 端，j 是 N 端
            if ow[k] == 1:
                g[n + j].append((i, 0))    # x_i >= y_j
            else:
                g[i].append((n + j, 1))    # y_j >= x_i + 1
        indeg = [0] * n2
        for v in range(n2):
            for u, _w in g[v]:
                indeg[u] += 1
        order = [v for v in range(n2) if indeg[v] == 0]
        for v in order:                    # Kahn 拓扑序（order 会边遍历边增长）
            for u, _w in g[v]:
                indeg[u] -= 1
                if indeg[u] == 0:
                    order.append(u)
        if len(order) < n2:
            out.append("NO")
            continue

        val = [0] * n2                     # x 初值 0，y 初值 1
        for i in range(n):
            if not isP[i]:
                val[n + i] = 1
        for v in order:
            bv = val[v]
            for u, w in g[v]:
                if bv + w > val[u]:
                    val[u] = bv + w
        out.append("YES\n" + " ".join(
            str(val[i] if isP[i] else -val[n + i]) for i in range(n)))
    sys.stdout.write("\n".join(out) + "\n")


main()
```

## 8. 边界情况与易错点

1. **$n=1$**：唯一约束就是对角线。$o=1$ 输出 `0`，$o=2$ 输出 `-1`；此时差分图无边，Kahn 会把两个点都排完。
2. **$N$ 侧初值写成 $0$**：会出现 $a_q=0$，既破坏 $(q,q)$ 的 $o=2$，也让 $N$–$N$ 的 $o=2$ 变成 $0+0\not<0$。初值必须取 $1$。
3. **把同号对也建边**：会凭空造环。例如所有对角线都是 $o=1$ 的数据本应输出全 $0$，错建「$x_i\to x_j$」就可能判环。
4. **对角线缺失**：本题保证 $m=\frac{n(n+1)}{2}$，不会缺。若真缺，「唯一分区」论证失效，需要困难版的 2-SAT（本文代码把缺省对角视为 $P$ 仅作防御）。
5. **输出任意解**：不要试图最小化；整数不会输出 `-0`，但别用浮点存答案。
6. **多测清空**：所有 `vector` 每轮重新 `clear/assign`，尤其 `indeg` 与 `order`，否则上一组的边会污染拓扑序。
7. **读入规模**：$\sum m\le 10^6$ 最多约 $3\times10^6$ 个整数，逐行 `getline` + `stringstream` 会超时，用 `fread` 或 `cin` 关同步。

- [LeetCode 990. 等式方程的可满足性](https://leetcode.cn/problems/satisfiability-of-equality-equations/)：把「相等 / 不等」约束化成图上的冲突检查，与本文「同号自动满足 + 检查标签是否打架」同源。
- [Codeforces 1385G Columns Swaps](https://codeforces.com/problemset/problem/1385/G)：用 2-SAT 决定每个位置是否翻转，是困难版那一步的典型练习。

**延伸思考**：

1. 若把 $o=2$ 的「$<0$」放宽成「$\le 0$」，跨号约束变成 $x_p\le y_q$，$0$ 权环不再矛盾，此时要判的是负环（例如用带势能的 SCC / SPFA），而不是「图无环」。
2. 若约束改成一般的 $a_i+a_j\ge c_{ij}$，问题就是标准差分约束，$n\le 1000$ 时 Bellman–Ford 的 $O(nm)$ 也可接受；本文能 $O(n+m)$ 的关键正是边权只有 $0/1$。
3. 简单版「简单」的本质是**完整输入把 $2^n$ 个符号假设压成唯一一个**；去掉对角线约束，就必须用困难版的 2-SAT 重新选符号——这是两版之间最值得记住的差异。
