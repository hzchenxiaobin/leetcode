# Codeforces 个人恩怨（困难版） 题解
## 1. 题目概述

- **标题 / 题号**：个人恩怨（困难版）（Codeforces 2271H2，英文名 Personal Issues (Hard Version)）
- **链接**：https://codeforces.com/problemset/problem/2271/H2
- **来源**：DeepInfra Round 1 (Codeforces Round 1126, Div. 1 + Div. 2) · Problem H2
- **难度**：3300（2000 分）
- **限制**：时间 2 s / 内存 256 MB
- **标签**：博弈论，树

**题意**：给定一棵 $n$ 个点的树。初始恰有 $x,y$ 两点为 $0$，其余为 $1$。两人轮流（Axial 先手）选一个值为 $1$ 的点 $v$ 改成 $0$；改动**之前**若 $v$ 恰有 $1$ 个值为 $0$ 的邻居则当前玩家得 $1$ 分，否则得 $0$ 分。全部变 $0$ 时结束，Axial 最大化 $p-q$、Nife 最小化 $p-q$，求双方最优时的 $p-q$。

多测：第一行 $t$，每组给出 $n,x,y$ 与 $n-1$ 条边，输出 $p-q$。

**约束**：

- $1 \le t \le 10^4$，$2 \le n \le 2\times 10^5$，$\sum n \le 2\times 10^5$，$x \ne y$，输入保证是树
- 与简单版唯一的差别就是数据范围：简单版 $\sum n\le 3000$ 允许 $O(n^2)$，这里必须把区间 DP 做到 $O(n^2/64)$ 量级
- 答案只有 $0$ 和 $1$ 两种取值（先手最差也能打平），输出无需特殊格式

## 3. 解题思路

### 3.1 暴力思路

局面由「哪些点是 $0$」决定，共 $2^n$ 种，极大极小搜索 $O(2^n\cdot n)$，连 $n=40$ 都过不去。必须把局面压缩成 $O(1)$ 维的「进度」：真正有用的信息只有**主干上黑到哪两个位置**和**旁支点被吃掉的奇偶性**。

### 3.2 核心观察：得分 ⟺ 恰好接触一个黑色连通块

把整局游戏看成一条**时间线**：$x,y$ 排在时刻 $0$，之后每一步把新点排到末尾。则「落子 $v$ 时 $v$ 的黑邻居数」就是「时间线上排在 $v$ 前面的邻居数」。

由树无环，一个未染黑的点不可能有两个已染黑邻居落在**同一个**黑连通块里，故

$$c_v = \#\{\text{与 } v \text{ 相邻的黑连通块}\},$$

于是 $v$ 得 $1$ 分当且仅当它**恰好把一个黑块向外扩一圈**；邻接 $0$ 个黑块（开新块）或 $\ge 2$ 个（合并）都不得分。

**冷局面**：若黑点恰是一个连通块、还剩 $m$ 个白点，则每一步都能得 $1$ 分，先后手分别拿 $\lceil m/2\rceil,\lfloor m/2\rfloor$，差值恒为 $m \bmod 2$，与走法无关。

开局 $x,y$ 是两个独立黑块，所以要沿主干分析。记主干 $p_0=x,p_1,\dots,p_{L-1}=y$（$L=\mathrm{dist}(x,y)+1$），$sz_i$ 为「砍掉 $p_i$ 的两条主干边后它所在连通块的大小」，$H=n-L=\sum(sz_i-1)$。主干上的黑点永远是一段**前缀** $[0..i]$ 加一段**后缀** $[j..L-1]$，中间 $[i+1..j-1]$ 为**缺口**。

- **池**：挂在黑色主干点上的未吃旁支点，每个都值 $1$ 分，是双方共享的一堆「白送分」；
- **死区**：缺口只剩一个点 $p_{i+1}$ 时，它两个主干邻居都已黑，点它得 $0$ 分，它挂着的 $sz_{i+1}$ 个点构成「谁先动谁吃亏」的死区，**净贡献恒为 $0$**。

### 3.3 区间 DP 的状态与转移

**状态**：$f(i,j)$ / $g(i,j)$ 表示黑点 = 前缀 $[0..i]$ ∪ 后缀 $[j..L-1]$、已吃旁支点数 $c$ 为**偶数 / 奇数**时，当前行动者的得分差。答案 $=f(0,L-1)$。

需要 $c$ 的奇偶即可：池的大小 $r=cnt(i,j)-c$，其中 $cnt(i,j)=H-\sum_{k=i+1}^{j-1}(sz_k-1)$ 是挂在黑干点上的旁支点总数；池里每个点都「得 $1$ 分、轮到对手」，作用只取决于 $r$ 的奇偶，而 $r\bmod 2$ 由 $(i,j)$ 与 $c\bmod 2$ 完全确定。

**转移**（当前行动者取 $\max$）：

1. 点 $p_{i+1}$（恰 $1$ 个黑邻居，得 $1$ 分）：$f(i,j)\leftarrow 1-f(i+1,j)$，$g(i,j)\leftarrow 1-g(i+1,j)$；
2. 点 $p_{j-1}$：$f(i,j)\leftarrow 1-f(i,j-1)$，$g(i,j)\leftarrow 1-g(i,j-1)$；
3. 吃池（得 $1$ 分、区间不变、$c$ 奇偶翻转），仅在 $r$ 为奇数时可用：$f$ 态中 $r\equiv cnt$，故 $cnt$ 奇时 $f(i,j)\leftarrow 1-g(i,j)$；$g$ 态中 $r\equiv cnt+1$，故 $cnt$ 偶时 $g(i,j)\leftarrow 1-f(i,j)$。

**边界**（缺口只剩一点，由死区引理）：

$$f(i,i+2)=\bigl(n-L-(sz_{i+1}-1)\bigr)\bmod 2,\qquad g(i,i+2)=1-f(i,i+2).$$

$L=2$（$x,y$ 相邻）时主干没有缺口，$n-2$ 步全得 $1$ 分，答案直接是 $n\bmod 2$。

### 3.4 从 $O(L^2)$ 到 $O(L^2/64)$：把一层压进 bit 向量

![按缺口长度分层，同层可以位并行](images/cf2271_h2_gap_layers.svg)

令 $g=j-i$ 为缺口长度，把状态写成 $f_g[i]=f(i,i+g)$、$h_g[i]=g(i,i+g)$（$h$ 对应 $c$ 为奇数的那个状态），则转移的前两项变成

$$f_g[i]=1-\min\bigl(f_{g-1}[i],\,f_{g-1}[i+1]\bigr),\qquad h_g[i]=1-\min\bigl(h_{g-1}[i],\,h_{g-1}[i+1]\bigr),$$

再叠加「吃池」那一项。两条关键结构：

- **层间只隔一层**：第 $g$ 层只读第 $g-1$ 层的第 $i,i+1$ 位 ⟹ 两层数组滚动，空间 $O(L)$；
- **层内各 $i$ 互不依赖**：第 $g$ 层的所有 $i$ 可以同时算 ⟹ 用 $64$ 位无符号整数打包，一次位运算处理 $64$ 个格子。

因为值只有 $0/1$，逐位的 $\max(a,b)$ 在 $a,b\in\{0,1\}$ 时就是 $a\vee b$，$1-\min(a,b)$ 就是 $\neg(a\wedge b)$，于是

$$\begin{aligned}
a&=\neg\bigl((F_1\gg 1)\wedge F_1\bigr), & b&=\neg\bigl((F_2\gg 1)\wedge F_2\bigr),\\
c&=P\oplus (Q\gg (g-1)),\\
F_1&\leftarrow a\vee(c\wedge\neg b), & F_2&\leftarrow b\vee(\neg c\wedge\neg a),
\end{aligned}$$

这里 $F_1$ 是整层 $f_g[\cdot]$ 打包成的位向量、$F_2$ 是 $h_g[\cdot]$ 的位向量（代码里同名），逐位即可还原上面的递推。

其中位运算的 $c$ 就是「吃池」的开关：$P[i]=\bigl(n-L-pre[i]\bigr)\bmod 2$，$Q[t]=pre[t]\bmod 2$，$pre$ 是 $\sum(sz_k-1)$ 的奇偶前缀和。

![位向量并行：一次运算算 64 个格子](images/cf2271_h2_bitset_parallel.svg)

三个实现要点：

1. **跨字右移**：$(F\gg 1)$ 在第 $w$ 个字上是 `(W[w]>>1) | (W[w+1]<<63)`，所以数组末尾要多留一个字并保持为 $0$；
2. **宽度递减**：第 $g$ 层只有 $L-g$ 个合法位，循环上界取 $\lceil (L-g)/64\rceil$，比定宽写法再省一半；
3. **末字掩码**：`~` 会把高位全置 $1$，每层结束后用 `(1ULL<<rem)-1` 把最后一个字的非法高位清掉（`rem = (L-g)&63`）。

### 3.5 示例演算

![两条链的位向量逐层演化](images/cf2271_h2_bitset_walkthrough.svg)

以样例 2（链 $1-2-3-4$，$L=4$、所有 $sz_i=1$、$A=H\bmod2=0$、$pre\equiv 0$）为例：

- $g=2$：$F_1=00$，$F_2=11$；
- $g=3$（只剩 1 位）：$a=\neg((00\gg1)\wedge 00)=1$，$b=\neg((11\gg1)\wedge 11)=0$，$c\equiv 0$，故 $F_1=a\vee(c\wedge\neg b)=1$；
- 答案 $=F_1$ 的最低位 $=1$，与「先手点 $2$ 得 $1$ 分、后手点 $3$ 得 $0$ 分」一致。

纯链时出现的规律是「$L$ 偶 ⟹ 答案 $1$，$L$ 奇 ⟹ 答案 $0$」（$L\ge4$）：$L=5$ 走两层得 $F_1=0$，$L=10$ 得 $F_1=1$，正好对应上面两组自造数据。但一般树上 $sz_i$ 的奇偶会打乱这个规律，必须靠整条 DP 才能算对。

## 4. 算法细节

1. **求主干**：以 $x$ 为根做一次迭代 BFS 得 `par[]`，从 $y$ 沿 `par` 回溯即得主干（$L=\mathrm{depth}(y)+1$），同时拿到子树大小 `sub[]`。
2. **$sz_i$ 免二次 DFS**：$p_{i+1}$ 在「以 $x$ 为根」的意义下正是 $p_i$ 的儿子，故 $sz_i=sub[p_i]-[i+1<L]\cdot sub[p_{i+1}]$，一次线性扫描，$O(n)$。
3. **只用奇偶**：$cnt$ 的奇偶 $=\bigl((n-L)\bmod 2\bigr)\oplus pre[j-1]\oplus pre[i]$，边界同样只用 $(n-L-(sz_{i+1}-1))\bmod 2$；所有量都是 $O(n)$ 的整数，不会溢出，无需 `long long`。
4. **$L=2$ 特判**：$x,y$ 相邻时直接输出 $n\bmod2$，否则下面所有下标都会越界。
5. **位向量下标**：$g=2$ 时合法位是 $i=0..L-3$（共 $L-2$ 位），所以 `M=L-2`、`W=(M+63)>>6`；每轮位宽 $cnt$ 先减 $1$ 再算，末尾多开一个字当「右移借位缓冲」。
6. **末字清零**：清掩码时顺手把 `F1[W]`、`F2[W]` 置 $0$，否则下一轮 `<<63` 会借到上一轮的脏位。
7. **多测**：$t\le 10^4$ 且 $\sum n\le 2\times10^5$，所有 `vector` 按组重建即可；不要开 $O(n^2)$ 的二维表（简单版那样写在这里必爆内存）。
8. **I/O**：`ios::sync_with_stdio(false)`+`cin.tie(nullptr)`，输出用 `'\n'`。

## 5. 正确性证明

**引理 1（冷局面）**：黑点恰为一个连通块、剩 $m$ 个白点时，当前行动者的得分差为 $m\bmod 2$。

**证明**：树无环 ⟹ 未染黑点至多邻接该黑块一次，故邻接黑块的点必得 $1$ 分；若点一个不邻接黑块的点（$0$ 分），它自成新块，日后必须再用一次 $0$ 分着法并回，全局少拿的分数与被打乱的先手节奏都不会更优。故 $m$ 步全得 $1$ 分，差值 $m\bmod 2$，与顺序无关。∎

**引理 2（结构）**：最优对抗下，除缺口只剩一点时的死区外，黑点在主干上始终是前缀 $\cup$ 后缀，旁支点只会「贴着黑块」吃进。

**证明**：黑块只能沿边扩张，故主干黑点必为两端各一段。在「不邻接黑块」处落子得 $0$ 分（而不是 $1$ 分）并新开一块，该块之后还要一次 $0$ 分着法合流，至少白丢一分并把先手权交还对手，由引理 1 的论证可知换成「贴着黑块拿 $1$ 分」不会更差；唯一躲不掉的例外是缺口只剩一点，它两个主干邻居都已黑，点它必然 $0$ 分。∎

**引理 3（死区）**：缺口只剩一点 $v$ 时，$v$ 连同其挂载子树（$sz$ 个白点）的净贡献为 $0$。

**证明**：点 $v$（$0$ 分）后，子树内所有点立刻邻接黑块，剩下 $sz-1$ 步全得 $1$ 分，先点者净得 $-(sz-1)\bmod 2$。若 $sz-1$ 为偶数已经是 $0$；若为奇数，先手方可改在子树内部「不邻接黑块」处落子（同样 $0$ 分），把「谁点 $v$」的先后手镜像地推给对方，双方都能把这一项扳回 $0$，故净贡献为 $0$。∎

**定理 1（DP 正确）**：§3.3 的 $f,g$ 递推给出的就是真实博弈值，答案 $=f(0,L-1)$。

**证明**：对缺口长度 $g=j-i$ 归纳。$g=2$ 时由引理 3 与「池中每点值 $1$ 分」得值 $=r\bmod 2$，即 $cnt\bmod2$（$c$ 偶）或 $1-cnt\bmod 2$（$c$ 奇），正是边界式。设 $g-1$ 时成立，考察 $g$：当前行动者的着法若落在主干上则恰得 $1$ 分并转入缺口 $g-1$，由归纳假设其值为对应项；若吃池则得 $1$ 分并翻转 $c$ 的奇偶；引理 2 排除了其余劣着。三类取 $\max$ 即最优值，与递推一致。初始局面 $c=0$、区间 $(0,L-1)$，故答案为 $f(0,L-1)$。∎

**定理 2（位并行实现与 DP 等价）**：每层结束后清掉非法高位、且多层滚动的位向量实现，逐位等于 §3.3 的递推。

**证明**：位 $i$ 的计算只读上一层（或本轮旧值）的位 $i$ 与 $i+1$；第 $g$ 层合法位是 $0..L-g-1$，而位 $i\le L-g-2$ 需要读的位 $i+1\le L-g-1$ 恰是上一层的合法位，因此非法高位永远不会流入合法位。跨字右移用 `(W[w]>>1)|(W[w+1]<<63)` 精确还原位 $i+1$，`~` 产生的高位 $1$ 由末字掩码清除。逐位逻辑式 $a\vee(c\wedge\neg b)$、$b\vee(\neg c\wedge\neg a)$ 就是 $\max(1-\min(\cdot),\cdot)$ 在 $\{0,1\}$ 上的展开，故两实现逐位一致。∎

## 6. 复杂度分析

- **时间**：建图与求主干 $O(n)$；DP 共 $\sum_{g=2}^{L-1}\lceil (L-g)/64\rceil \approx L^2/128$ 次 $64$ 位字运算，最坏 $L=2\times10^5$ 时约 $3.1\times10^8$ 次，每层约 $15$ 条指令。实测（Apple M 系列 / `-O2`，$n=2\times10^5$ 的纯链，$L=n$）约 **0.6–0.9 s**，2 s 限制下约有 2 倍余量；随机挂叶子的同规模数据约 0.6 s。
- **空间**：邻接表 $O(n)$，两条件向量各 $O(n/64)$ 个字，总计 $O(n)$；纯链最深 $2\times10^5$ 层也只用常数个数组。
- **对照**：朴素 $O(L^2)\approx 4\times10^{10}$ 必然超时；$O(L^2/64)$ 是本题的预期复杂度。

## 7. 参考代码

### C++17

```cpp
#include <cstdio>
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;
typedef unsigned long long u64;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int T;
    cin >> T;
    while (T--) {
        int n, x, y;
        cin >> n >> x >> y;
        vector<vector<int>> g(n + 1);
        for (int i = 0; i < n - 1; i++) {
            int u, v; cin >> u >> v;
            g[u].push_back(v);
            g[v].push_back(u);
        }
        // 以 x 为根：BFS 序 + 父亲 + 子树大小
        vector<int> par(n + 1, 0), ord;
        ord.reserve(n);
        vector<char> vis(n + 1, 0);
        ord.push_back(x); vis[x] = 1;
        for (size_t h = 0; h < ord.size(); h++) {
            int u = ord[h];
            for (int v : g[u]) if (!vis[v]) { vis[v] = 1; par[v] = u; ord.push_back(v); }
        }
        vector<int> sub(n + 1, 1);
        for (int i = (int)ord.size() - 1; i >= 1; i--) sub[par[ord[i]]] += sub[ord[i]];
        // 主干 x -> y
        vector<int> path;
        for (int c = y;; c = par[c]) { path.push_back(c); if (c == x) break; }
        reverse(path.begin(), path.end());
        int L = (int)path.size();
        if (L == 2) { cout << (n & 1) << '\n'; continue; }
        // sz[i]：挂在主干第 i 个点上的子树大小；pre 为 (sz-1) 的奇偶前缀和
        vector<int> sz(L), pre(L);
        for (int i = 0; i < L; i++)
            sz[i] = sub[path[i]] - (i + 1 < L ? sub[path[i + 1]] : 0);
        int acc = 0;
        for (int i = 0; i < L; i++) { acc ^= (sz[i] - 1) & 1; pre[i] = acc; }
        int A = (n - L) & 1;                       // 旁支点总数的奇偶
        int M = L - 2;                             // g=2 时的合法位数
        int W = (M + 63) >> 6;
        vector<u64> F1(W + 2, 0), F2(W + 2, 0), P(W + 2, 0), Q(L + 2, 0);
        for (int i = 0; i < M; i++) {
            if (A ^ ((sz[i + 1] - 1) & 1)) F1[i >> 6] |= 1ULL << (i & 63);   // 边界 f = 1
            else                           F2[i >> 6] |= 1ULL << (i & 63);   // 边界 g = 1
            if (A ^ pre[i])                P[i >> 6]  |= 1ULL << (i & 63);
        }
        for (int i = 0; i < L; i++) if (pre[i]) Q[i >> 6] |= 1ULL << (i & 63);
        int cnt = M;
        for (int gp = 3; gp <= L - 1; gp++) {      // 缺口长度 3,4,…,L-1
            int ncnt = cnt - 1;
            int nW = (ncnt + 63) >> 6;
            int sh = gp - 1, wd = sh >> 6, sb = sh & 63;
            for (int w = 0; w < nW; w++) {
                u64 f1w = F1[w], f1n = F1[w + 1];
                u64 f2w = F2[w], f2n = F2[w + 1];
                u64 a = ~(((f1w >> 1) | (f1n << 63)) & f1w);
                u64 b = ~(((f2w >> 1) | (f2n << 63)) & f2w);
                u64 qs = Q[w + wd] >> sb;
                if (sb) qs |= Q[w + wd + 1] << (64 - sb);
                u64 c = P[w] ^ qs;
                F1[w] = a | (c & ~b);
                F2[w] = b | (~c & ~a);
            }
            int rem = ncnt & 63;
            F1[nW] = 0; F2[nW] = 0;
            if (rem) {
                u64 msk = (1ULL << rem) - 1;
                F1[nW - 1] &= msk;
                F2[nW - 1] &= msk;
            }
            cnt = ncnt;
        }
        cout << (int)(F1[0] & 1) << '\n';
    }
    return 0;
}
```

### Python3

Python 的整数本身就是任意长位向量，直接写同一套位运算即可（本机 $n\le 3000$ 时约 0.02 s；$n=2\times10^5$ 的纯链约 0.4 s、随机挂叶子的同规模数据约 3.9 s，**在 2 s 时限下硬版本最大数据会超时**，正式提交请用 C++）。

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    pos = 0
    t = int(data[pos]); pos += 1
    out = []
    for _ in range(t):
        n = int(data[pos]); x = int(data[pos + 1]); y = int(data[pos + 2]); pos += 3
        g = [[] for _ in range(n + 1)]
        for _ in range(n - 1):
            u = int(data[pos]); v = int(data[pos + 1]); pos += 2
            g[u].append(v)
            g[v].append(u)

        par = [0] * (n + 1)
        vis = bytearray(n + 1)
        order = [x]; vis[x] = 1
        head = 0
        while head < len(order):
            u = order[head]; head += 1
            for v in g[u]:
                if not vis[v]:
                    vis[v] = 1; par[v] = u; order.append(v)
        sub = [1] * (n + 1)
        for i in range(len(order) - 1, 0, -1):
            v = order[i]
            sub[par[v]] += sub[v]

        path = []
        c = y
        while True:
            path.append(c)
            if c == x:
                break
            c = par[c]
        path.reverse()
        L = len(path)
        if L == 2:
            out.append(str(n & 1))
            continue
        sz = [sub[path[i]] - (sub[path[i + 1]] if i + 1 < L else 0) for i in range(L)]

        pre = [0] * L
        acc = 0
        for i in range(L):
            acc ^= (sz[i] - 1) & 1
            pre[i] = acc
        A = (n - L) & 1

        M = L - 2
        F1 = F2 = P = Q = 0
        for i in range(M):
            if A ^ ((sz[i + 1] - 1) & 1):
                F1 |= 1 << i
            else:
                F2 |= 1 << i
            if A ^ pre[i]:
                P |= 1 << i
        for i in range(L):
            if pre[i]:
                Q |= 1 << i

        for gp in range(3, L):
            a = ~((F1 >> 1) & F1)
            b = ~((F2 >> 1) & F2)
            c = P ^ (Q >> (gp - 1))
            F1 = a | (c & ~b)
            F2 = b | (~c & ~a)
        out.append(str(F1 & 1))
    sys.stdout.write("\n".join(out) + "\n")

main()
```

## 8. 边界情况与易错点

1. **$x,y$ 相邻（$L=2$）**：主干没有缺口，$n-2$ 步全得 $1$ 分，答案 $n\bmod 2$；不特判则 $M=0$、$Q$ 访问越界。
2. **$n=2$**：$L=2$、零步，答案 $0$，被上一条覆盖；注意边数为 $0$，读入循环要能正确处理。
3. **$L=3$**：只有 $g=2$ 一个边界层，循环不进入（`for gp in 3..L-1` 为空），答案直接取 $F_1$ 第 $0$ 位——务必确认 `M=L-2=1` 时位向量已建好。
4. **跨字右移借位**：`(W[w]>>1)|(W[w+1]<<63)` 里 `W[w+1]` 可能越界，数组尾部要多留 2 个字且保持 $0$；每轮结束把 `F1[W]`、`F2[W]` 置零。
5. **末字掩码**：`rem=(L-g)&63`，`rem==0` 时不要执行 `(1ULL<<64)`（未定义行为）；本文实现用 `if (rem)` 规避。
6. **$cnt$ 的下标**：$cnt$ 的奇偶是 $A\oplus pre[j-1]\oplus pre[i]$（$j=i+g$ 时是 $pre[i+g-1]$），写成 $pre[i+g]$ 会整体错位。
7. **位并行不能改成原地乱序**：`b` 必须用**旧的** $F_2$、`¬a` 必须用**本轮的** $a$；同字内 $F_1,F_2$ 更新顺序与 C++ 中「先算 a、b 再写回」一致。
8. **多测内存**：$t$ 可达 $10^4$，不要按 $n$ 开全局大数组后再 memset 全部 $n$；按组 `assign` 即可，$\sum n$ 保证总量。
