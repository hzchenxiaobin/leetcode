# Codeforces MEX游戏 题解

## 1. 题目概述

- **标题 / 题号**：MEX游戏（Codeforces 2271B，英文名 MEX Game）
- **链接**：https://codeforces.com/problemset/problem/2271/B
- **来源**：DeepInfra Round 1 (Codeforces Round 1126, Div. 1 + Div. 2) · Problem B
- **难度**：$\ast 1000$（1000 分）
- **限制**：时间 1.5 s / 内存 256 MB
- **标签**：博弈论、计数、分类讨论、构造性策略

**题意**：给定偶数 $n$、正整数 $k$ 和 $n$ 张卡片，第 $i$ 张写着 $a_i$。对多重集 $\mathcal{S}$ 定义

$$\operatorname{mex}_k(\mathcal{S})=\min\{\,x\ge 0:\ \mathcal{S}\ \text{中}\ x\ \text{的出现次数}<k\,\},$$

即最小的「出现次数不足 $k$ 次」的非负整数（$k=1$ 时就是普通 mex）。Alice 先手，两人轮流取走剩余卡片中的一张，取完后各得 $n/2$ 张，记两人手牌为 $\mathcal{A},\mathcal{B}$。若 $\operatorname{mex}_k(\mathcal{A})\ne\operatorname{mex}_k(\mathcal{B})$ 则 Alice 胜，否则 Bob 胜。双方最优博弈，问 Alice 是否必胜。多测：首行组数 $t$，每组依次给出 $n,k$ 与 $a_1,\dots,a_n$，逐组输出 `YES` 或 `NO`。

**约束**：

- $1\le t\le 10^4$，$2\le n\le 2\times 10^5$ 且 $n$ 为偶数
- $1\le k\le n$，$0\le a_i\le n$
- $\sum n\le 2\times 10^5$
- 时限 1.5 s：每组只允许 $O(n)$；$t$ 达到 $10^4$ 时不能每次清空固定大小的数组，也不能带大常数

## 2. 示例

官方解释要点：第 1 组 Alice 先取 $1$ 再取 $0$，得 $\mathcal{A}=\{0,1\}$、$\mathcal{B}=\{0,2\}$，$\operatorname{mex}_1$ 分别为 $2$ 与 $1$，Alice 胜；第 2 组 Bob 一路应对，最终 $\mathcal{A}=\mathcal{B}=\{0,1\}$，$\operatorname{mex}_1$ 都是 $2$，Bob 胜。

补一组自造数据（非官方，验证判据在 $c_g=2k-1$ 与 $c_g<2k-1$ 两侧的分野）：第一组 $c=(5,1)$、$c_0=5=2k-1$ 故 Alice 胜；第二组 $c=(4,2)$、$c_0=4<2k-1$ 故 Bob 胜。

```text

2
6 3
0 0 0 0 0 1
6 3
0 0 0 0 1 1

输出
YES
NO
```

## 3. 解题思路

### 3.1 暴力思路

把游戏当成完全信息博弈直接搜：状态是「各值剩余张数 + 轮到谁」，做极小极大搜索。状态规模是 $\prod_v (c_v+1)$ 量级，$n=2\times 10^5$ 时完全不可行；即便只对小 $n$ 打表，也得先猜出「胜负由哪些量决定」。所以第一步是找结构。

### 3.2 核心观察：2k 阈值与关键位置 g

![核心观察：g 是第一个凑不齐 2k 张的值](images/cf2271_b_threshold_concept.svg)

记 $c_v$ 为值 $v$ 在全部卡片中的出现次数（$v>n$ 时 $c_v=0$），并定义**关键位置**

$$g=\min\{\,v\ge 0:\ c_v<2k\,\}.$$

因为 $\sum_v c_v=n$ 有限，这样的 $v$ 一定存在。

**观察 1（$2k$ 是「两人同时通过」的门槛）**：一方想在值 $v$ 上「通过」，得在手里凑满 $k$ 张 $v$；两人同时通过，合计至少要 $2k$ 张 $v$。于是

- $v<g$ 时 $c_v\ge 2k$，双方**有可能**同时通过；
- $v=g$ 时 $c_g\le 2k-1$，双方**不可能**同时通过。

**观察 2（$v<g$ 上「双方同时失败」不可能）**：若 $a_v+b_v=c_v\ge 2k$ 而 $a_v<k$，则 $b_v=c_v-a_v\ge 2k-(k-1)=k+1>k$。即 $v<g$ 时只要一方没凑满 $k$ 张，另一方必然凑满了。

记 $p=\operatorname{mex}_k(\mathcal{A})$、$q=\operatorname{mex}_k(\mathcal{B})$，即两人各自的「第一个失败位置」。若 $p=q=t$，则两人在 $t$ 上都 $<k$ 张，故

$$c_t=a_t+b_t\le 2k-2.$$

而两人在 $t$ 之前都 $\ge k$ 张，故 $t$ 之前每个 $v$ 都满足 $c_v\ge 2k$ —— 这说明「第一个失败位置」不会早于 $t$，即 $t\le g$；又 $c_t\le 2k-2<2k$ 说明 $t$ 自己就是一个失败位置，即 $t\ge g$。于是 $t=g$，并且必须 $c_g\le 2k-2$。因此只有两种情况：

- **$c_g=2k-1$**：无论怎么分牌，$p=q$ 都不可能，Alice 必胜；
- **$c_g\le 2k-2$**：$p=q=g$ 在组合上「允许」出现，只需说明 Bob 能把它变成现实 —— 他那张「同值配对」的镜像策略正好做到这一点。

**结论（判据）**：Alice 必胜 $\iff c_g=2k-1$。由于 $c_g<2k$，这等价于「第一个不足 $2k$ 张的桶，恰好装了 $2k-1$ 张」。

### 3.3 算法流程

![算法流程：每组只需一次线性扫描](images/cf2271_b_flow.svg)

1. **桶计数**：读入 $a_i$，让 $c[a_i]$ 自增（桶大小 $n+2$）。
2. **找 $g$**：从 $v=0$ 递增扫描，第一个满足 $c[v]<2k$ 的 $v$ 就是 $g$。
3. **判定**：若 $c[g]=2k-1$ 输出 `YES`，否则输出 `NO`。
4. 进入下一组测试。

Bob 的镜像策略直觉上就是「你怎么拿，我就拿同值的另一张」：$v<g$ 的桶里至少 $2k$ 张，同值配对后两人各拿 $\ge k$ 张；而 $g$ 处最多 $2k-1$ 张，配对后两人都只能拿到 $<k$ 张 —— 两人的 mex 一起停在 $g$。反过来，$c_g=2k-1$ 时这张「多出来的牌」无论归谁，都会让一方的 $g$ 桶升到 $k$、另一方停在 $k-1$，两人的 mex 必然被拉开。

### 3.4 示例演算

![官方样例走查：先定位 g，再比较 c_g 与 2k−1](images/cf2271_b_walkthrough.svg)

以第 5 组（$n=8,k=2$，卡片 $0,1,1,0,0,2,0,1$）为例：$c=(4,3,1)$，$2k=4$。$c_0=4\ge 4$ 通过，$c_1=3<4$ 故 $g=1$，而 $c_1=3=2k-1$，输出 `YES`。代回博弈：Alice 只要拿到 $2$ 张 $1$，Bob 至多 $1$ 张，两人的 mex 就被拉成 $1$ 与 $\ge 2$。再看第 4 组（$n=6,k=2$，$c=(2,2,2)$）：$c_0=2<4$，于是 $g=0$，而 $c_0=2\ne 3$，输出 `NO`。这里 Bob 的镜像让两人各拿一个 $0,1,2$，mex 完全相同。

## 4. 算法细节

1. **桶的大小**：只需覆盖 $0..n$（$a_i\le n$），但数组要开到 $n+2$。理论上由 $\sum_{v=0}^{n} c_v=n<2(n+1)$ 可知 $g\le n$ 恒成立，多留一位是给「扫描到空桶」的写法兜底，避免越界读。
2. **整数范围**：$2k\le 4\times 10^5$，`int` 足够；只有把 $n$ 放大到 $10^{18}$ 量级时才需要 `long long`/`__int128`，本题不必。
3. **多测清空**：每组重新 `vector<int> c(n+2, 0)`，代价 $O(n)$、总和 $O(\sum n)$。**不要**用全局数组每次 `memset` 整个 $2\times10^5$，那在 $t=10^4$ 时退化到 $2\times 10^9$。
4. **扫描方向**：$g$ 是**最小**的失败位置，必须从 $v=0$ 严格递增地扫；只遍历「出现过的值」会漏掉 $c_v=0$ 的空洞（示例 2 的 $g=2$ 正落在空洞上，而示例 4 的 $g=0$ 虽在非空值上，也仍要从 0 开始才能取到最小）。
5. **I/O**：C++ 关同步 + `cin` 即可（总量 $2\times10^5$ 个整数）；Python 用 `sys.stdin.buffer.read().split()` 一次读完，避免 $10^4$ 次 `input()` 的开销。
6. **观察 $k>n/2$ 的特例**：此时 $2k>n\ge c_0$，必然 $g=0$，且 $c_0\le n<2k-1$，输出 `NO`。代码无需特判，但这个事实解释了「$k$ 很大时 Alice 永远赢不了」：每人只有 $n/2<k$ 张牌，双方的 $\operatorname{mex}_k$ 恒为 $0$。
7. **判据不是奇偶**：$c_g=2k-1$ 一定是奇数，但反过来不成立。例如 $n=4,k=1$、卡片 $\{0,0,0,3\}$，$c_0=3$ 是奇数，然而 $g=1$、$c_1=0\ne 1$，答案仍是 `NO`（Bob 每轮拿 $0$，两人都有 $0$，mex 都是 $1$）。

## 5. 正确性证明

**引理 1（阈值引理）**：若 $c_v\ge 2k$，则对任意划分，$a_v<k$ 蕴含 $b_v\ge k+1$；特别地「双方在 $v$ 同时失败」不可能。

**证明**：$a_v+b_v=c_v\ge 2k$，若 $a_v\le k-1$，则 $b_v=c_v-a_v\ge 2k-(k-1)=k+1>k$。双方同时失败需 $a_v+b_v\le 2k-2<c_v$，与 $a_v+b_v=c_v$ 矛盾。∎

**引理 2（平局的必要条件）**：若存在划分使 $p=q=t$，则 $c_t\le 2k-2$，且对所有 $v<t$ 有 $c_v\ge 2k$，从而 $t=g$。

**证明**：$p=q=t$ 表示两人在 $t$ 上都 $<k$ 张（故 $a_t+b_t=c_t\le 2k-2$），且在 $v<t$ 上都 $\ge k$ 张（故 $c_v\ge 2k$）。于是所有 $c_v<2k$ 的值都不小于 $t$，即 $t\le g$；又 $c_t\le 2k-2<2k$，即 $t$ 本身是一个「不足 $2k$」的位置，故 $t\ge g$。两式合并得 $t=g$。∎

**引理 3（$c_g=2k-1$ 时不可能平局）**：若 $c_g=2k-1$，则对任意划分都有 $p\ne q$。

**证明**：反设 $p=q$。由引理 2 得 $p=q=g$ 且 $c_g\le 2k-2$，与 $c_g=2k-1$ 矛盾。∎

**定理 1**：若 $c_g=2k-1$，则 Alice 必胜。

**证明**：由引理 3，任何合法的分牌结果（含双方任意策略产生的分牌）都满足 $\operatorname{mex}_k(\mathcal{A})\ne\operatorname{mex}_k(\mathcal{B})$，Alice 必胜。∎

**引理 4（Bob 的配对策略）**：若 $c_g\le 2k-2$，Bob 有策略使 $p=q=g$。

**证明**：构造一个全卡片上的配对方案。

1. 对每个 $v<g$：把 $c_v$ 张 $v$ 按同值两两配对，若 $c_v$ 为奇数则剩 $1$ 张。
2. 对 $v=g$ 与每个 $v>g$：同样同值两两配对，各剩 $c_v\bmod 2$ 张。
3. 剩下的是「每种奇数计数的值各一张」，共偶数张（因为 $\sum_v c_v=n$ 为偶数），把它们任意两两配成**跨值对**。

Bob 的策略：Alice 每取走一张牌，Bob 就取走它的配对牌。这是合法的 —— 同一对里 Alice 只可能取走一张，另一张必然还在场上；且每对恰好一人一张，最终两人各得 $n/2$ 张。统计各值的归属：同值对给两人各 $1$ 张，跨值对也只让每人各得其中一张。

- $v<g$：$c_v\ge 2k$。若 $c_v$ 为偶数，两人各得 $c_v/2\ge k$；若为奇数，则 $c_v\ge 2k+1$，两人先各得 $(c_v-1)/2\ge k$，剩下那张若通过跨值对落到某人手里，该人只增不减，仍然 $\ge k$。故**两人都通过** $v$。
- $v=g$：两人各得 $\lfloor c_g/2\rfloor$ 与 $\lceil c_g/2\rceil$。由 $c_g\le 2k-2$ 得 $\lceil c_g/2\rceil\le k-1<k$；若 $c_g$ 为奇数则 $c_g\le 2k-3$，多出的那张经跨值对再加 $1$，仍 $\le k-1$。故**两人都失败于** $g$。

于是两人的第一个失败位置都是 $g$，即 $p=q=g$。∎

**定理 2**：若 $c_g\le 2k-2$，则 Bob 必胜。

**证明**：由引理 4，Bob 能让 $\operatorname{mex}_k(\mathcal{A})=\operatorname{mex}_k(\mathcal{B})=g$，故 Alice 不胜。∎

**定理 3（充要判据）**：Alice 必胜 $\iff c_g=2k-1$。

**证明**：由 $g$ 的定义 $c_g<2k$，故 $c_g$ 要么等于 $2k-1$，要么不超过 $2k-2$，两种情形已分别由定理 1 与定理 2 覆盖。∎

## 6. 复杂度分析

- **时间**：每组 $O(n)$ 计数 + $O(n)$ 扫描（扫描最多走到 $n+1$），总 $O(\sum n)\le 2\times10^5$ 次基本操作。1.5 s 时限下余量充足：本地实测 $n=2\times10^5$ 的单组最坏约 0.2 s（含输入解析），$t=10^4$、$\sum n=2\times10^5$ 约 0.16 s。
- **空间**：$O(n)$ 的桶数组，峰值 $2\times10^5+2$ 个 `int`（约 0.8 MB），远低于 256 MB；不需要额外数据结构。
- **对照**：极小极大搜索的状态数是指数级，本题规模下完全不可行；本解法把博弈压缩成「一次扫描 + 一个等式」。

## 7. 参考代码

### C++17

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    while (cin >> T) {
        while (T--) {
            int n, k;
            cin >> n >> k;
            vector<int> c(n + 2, 0);            // 多留一位，扫描到空桶也不越界
            for (int i = 0; i < n; ++i) {
                int x;
                cin >> x;
                ++c[x];                          // 0 <= a_i <= n
            }
            int g = 0;
            while (c[g] >= 2 * k) ++g;           // 第一个不足 2k 张的值
            cout << (c[g] == 2 * k - 1 ? "YES" : "NO") << '\n';
        }
    }
    return 0;
}
```

### Python3

```python
import sys


def main() -> None:
    data = sys.stdin.buffer.read().split()
    t = int(data[0])
    p = 1
    out = []
    for _ in range(t):
        n = int(data[p])
        k = int(data[p + 1])
        p += 2
        c = [0] * (n + 2)                        # 末尾多留一位
        for i in range(p, p + n):
            c[int(data[i])] += 1
        p += n

        g = 0
        while c[g] >= 2 * k:                     # 第一个不足 2k 张的值
            g += 1
        out.append("YES" if c[g] == 2 * k - 1 else "NO")

    sys.stdout.write("\n".join(out))


main()
```

## 8. 边界情况与易错点

1. **没有 $0$ 卡（$c_0=0$）**：$g=0$、$c_0=0\ne 2k-1$ → `NO`。正确：两人的 mex 都是 $0$。
2. **$k>n/2$**：必然 `NO`，不要因为「先手有优势」就判 `YES`；此时每人只有 $n/2<k$ 张牌，双方 mex 恒为 $0$。
3. **扫描越界**：桶必须覆盖到下标 $n+1$（写 `n+2`）。虽然由 $\sum c_v=n$ 可知 $g\le n$，但少留一位就依赖了这个不显然的推论，一旦写法变动就是 UB。
4. **$a_i$ 可以等于 $n$**：桶下标上界是 $n$，别按「$a_i<n$」只开 $n$ 个位置。
5. **多测清空方式**：按 $n$ 重新分配数组；不要用固定大小数组全量 `memset`，否则 $t=10^4$ 且每组 $n$ 很小时会被常数拖死。
6. **判据勿写成奇偶**：`c[g] % 2 == 1` 是错的，奇偶只能保证 $c_g$ 是奇数，不能保证它**等于** $2k-1$。例如 $n=6,k=2$、卡片 $\{0,1,1,1,1,1\}$，$c=(1,5)$ 中 $c_0=1$ 是奇数，但 $2k-1=3$，答案 `NO`。必须写等式 `c[g] == 2*k-1`。
7. **输出格式**：多测逐行输出，最后一行也要换行；Python 用 `"\n".join(out)` 一次性写出，避免反复 `print` 刷新缓冲区。
8. **重扫描的成本**：$g$ 的 `while` 循环整体是 $O(n)$ 的（每组只前进不回退），不要在循环里再套一次统计，否则会退化成 $O(n^2)$。

**延伸思考**：

- 本题的引理 3（$c_g=2k-1$ 时任何划分都 $p\ne q$）**与先后手无关**，而引理 4 的配对策略必须由**后手**执行。这说明两个方向的强弱并不对称：若把规则改成 Bob 先手，$c_g=2k-1$ 一侧的结论不变，但 $c_g\le 2k-2$ 一侧需要重新分析 —— 此时 Alice 成了后手，她既可以镜像求平（但她不想平），也可能利用先手方多拿一张的结构反杀。建议自己推一遍。
- 若改成三人轮流取、两两比较 $\operatorname{mex}_k$，阈值会从 $2k$ 变成 $3k$，而「第一个凑不齐 $3k$ 的位置」上 $3k-1$、$3k-2$ 两档的行为不同，值得按同样的「同时失败可能性」框架分类。
- 若阈值随值变化（每个 $v$ 要求不同的 $k_v$），判据会变成前缀库存条件 $c_v\ge 2k_v$ 的第一次破裂处，本质仍是「前缀能否支撑所有玩家通过」，配对证明可以逐字沿用。
