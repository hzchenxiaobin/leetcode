# Codeforces 207B2 军事训练 题解

## 1. 题目概述

- **题目链接**：https://codeforces.com/problemset/problem/207/B2
- **比赛来源**：Abbyy Cup 2.0 - Final (unofficial) · Problem B2（UTC 2012-07-08）
- **难度**：1900
- **标签**：贪心、动态规划、倍增
- **评测类型**：普通
- **限制**：时间 3 s / 内存 256 MB

**题意**：$n$ 辆坦克排成一列，编号 $1..n$。每条消息由队首坦克发出，逐辆向右转发，直到最后一辆坦克收到；每次转发算 1 秒。若第 $i$ 个位置（$1$ 起）想把消息发给第 $j$ 个位置（$i<j$），第 $j$ 个位置上的坦克编号为 $x$，则必须满足 $i\ge j-a_x$。收到消息后，末尾那辆坦克移到队首，再发下一条消息；共 $n$ 条消息，之后队列恢复原序。求所有消息的最短总耗时。

**约束**：本版 $2\le n\le10000$；$1\le a_i\le250000$。

$O(n^2)=10^8$，需要常数很小的写法（本版代码只用一次线性扫描求 $f$ 与一次贪心跳）。

## 2. 示例与观察

官方样例一：

```text
输入：
3
2
1
1

输出：
5
```

官方样例二：

```text
输入：
5
2
2
2
2
2

输出：
10
```

**样例一走查**：三条消息的队首分别是坦克 1、3、2（队列依次为 $1,2,3$；$3,1,2$；$2,3,1$），最少跳数分别为 $2,1,2$，合计 5。

**样例二走查**：所有 $a_i=2$，每条消息只需 2 跳（$1\to3\to5$），共 $2\times5=10$。

**观察 1（每条消息独立）**：第 $m$ 条消息时队列是 $(x,x+1,\dots,n,1,\dots,x-1)$ 的循环移位，$x$ 依次取 $1,n,n-1,\dots,2$（即所有 $x$ 各一次）。因此只需对每个 $x$ 求"从位置 1 到位置 $n$ 的最少跳数"再求和。

**观察 2（跳数模型）**：位置 $p$ 上的坦克编号是 $t(p)=((x+p-2)\bmod n)+1$，定义 $L_p=p-a_{t(p)}$。位置 $i$ 能直接发给位置 $j>i$ 当且仅当 $L_j\le i$。这就是经典的"最少跳跃"问题。

**观察 3（贪心最优）**：记 $f(p)=\max\{j\le n: L_j\le p\}$（从 $p$ 一步能到的最远位置）。$f$ 单调不减且 $f(p)>p$。若 $R_0=1$、$R_{k+1}=f(R_k)$，则"$k$ 步内能到达的最远位置"恰为 $R_k$，故最少跳数 = 最小的 $k$ 使 $R_k=n$。

## 3. 解题思路

### 3.1 朴素做法与瓶颈

对每条消息做 BFS/区间枚举是 $O(n^2)$ 每条、$O(n^3)$ 总共，不能接受。用"每个位置逐个求最短跳数"的 DP 也绕不开区间最小值查询。

### 3.2 核心观察

最少跳数只需关心"最远能到哪"。$f(p)$ 可以由 $L$ 数组一遍前缀最大值求出：`bestAt[L_j] = max(..., j)`，再做前缀最大值即得 $f$（$p$ 从 1 到 $n$）。于是单条消息 $O(n)$：从 1 出发反复 $p\gets f(p)$ 直到 $p=n$。

### 3.3 算法流程

1. 对每个 $x\in[1,n]$：算出相对位置的 $L_p=p-a_{((x+p-2)\bmod n)+1}$。
2. 用 `bestAt[L_p] = max(bestAt[L_p], p)` 与前缀最大值求出 $f$。
3. 从 $p=1$ 开始贪心跳 $p\gets f(p)$，直到 $p=n$，跳数累加。
4. 输出总和。

![样例走查](../../../images/cf207B2_walk)

### 3.4 样例走查

$n=10000$ 全为 $a_i=1$ 时每条消息要 $n-1$ 跳，答案 $99990000$；随机数据答案约 $2\times10^4$。

## 4. 正确性证明

**引理 1（$f$ 的单调性）**：$p\le p'$ 时 $f(p)\le f(p')$，且 $f(p)>p$（$p<n$）。

**证明**：$\{j:L_j\le p\}\subseteq\{j:L_j\le p'\}$ 故最大值不减；又 $L_{p+1}=(p+1)-a\le p$（$a\ge1$），故 $f(p)\ge p+1$。∎

**引理 2（$R_k$ 是 $k$ 步内能到的最远位置）**：设 $R_0=1$、$R_{k+1}=f(R_k)$。则任意 $k$ 步可达的位置都 $\le R_k$，且 $R_k$ 本身 $k$ 步可达。

**证明**：归纳。$k=0$ 显然。设 $k$ 步内可达的位置集合为 $S_k$ 且 $\max S_k=R_k$。一步能到 $j$ 当且仅当存在 $i\in S_k$ 使 $L_j\le i$，即 $L_j\le\max S_k=R_k$，故 $k+1$ 步可达的最远位置为 $f(R_k)=R_{k+1}$；又 $R_k$ 可达且 $L_{R_{k+1}}\le R_k$，故 $R_{k+1}$ 可达。∎

**定理**：最少跳数等于最小的 $k$ 使 $R_k=n$。

**证明**：由引理 2，$k$ 步可达 $n$ 当且仅当 $R_k\ge n$，而位置不超过 $n$，故当且仅当 $R_k=n$。∎

## 5. 复杂度分析

- **时间**：单条消息 $O(n)$（建 $L$、前缀最大值、贪心跳），共 $n$ 条 ⇒ $O(n^2)$；$n=10000$ 最坏（全 1）0.18 s，随机 0.26 s，均在 3 s 内。
- **空间**：$O(n)$。

## 6. 参考代码

### C++17

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n;
    if (scanf("%d", &n) != 1) return 0;
    vector<int> a(n + 1);
    for (int i = 1; i <= n; ++i) scanf("%d", &a[i]);
    vector<int> rel(n + 1), M(n + 1);
    long long total = 0;
    for (int x = 1; x <= n; ++x) {
        // 相对位置 p 的坦克号 = ((x+p-2) mod n)+1，L[p] = p - a[tank]
        for (int p = 1; p <= n; ++p) rel[p] = p - a[((x + p - 2) % n) + 1];
        // M[p] = max{ j : L[j] <= p }
        for (int p = 0; p <= n; ++p) M[p] = 0;
        for (int j = 1; j <= n; ++j) {
            int L = rel[j];
            if (L < 0) L = 0;
            if (j > M[L]) M[L] = j;
        }
        for (int p = 1; p <= n; ++p) if (M[p - 1] > M[p]) M[p] = M[p - 1];
        int cur = 1, steps = 0;
        while (cur < n) { cur = M[cur]; ++steps; }
        total += steps;
    }
    printf("%lld\n", total);
    return 0;
}
```

### Python3

```python
import sys


def main() -> None:
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    a = [0] + [int(x) for x in data[1:1 + n]]
    total = 0
    M = [0] * (n + 1)
    for x in range(1, n + 1):
        for p in range(0, n + 1):
            M[p] = 0
        for p in range(1, n + 1):
            L = p - a[((x + p - 2) % n) + 1]
            if L < 0:
                L = 0
            if p > M[L]:
                M[L] = p
        for p in range(1, n + 1):
            if M[p - 1] > M[p]:
                M[p] = M[p - 1]
        cur = 1
        steps = 0
        while cur < n:
            cur = M[cur]
            steps += 1
        total += steps
    print(total)


main()
```

## 7. 边界情况与易错点

1. **$a_i\ge1$**：保证每步至少前进 1，否则会死循环；这也是 $f(p)>p$ 的依据。
2. **$L_p<0$**：$p-a\le0$ 时任何位置 $i\ge1$ 都能发给它，代码里把 $L_p$ 截断到 0 再当前缀最大值。
3. **单条消息的队首**：$x$ 依次是 $1,n,n-1,\dots,2$（共 $n$ 个），求和时顺序无所谓，别漏掉 $x=1$。
4. **相对/全局坐标**：$L_p$ 用相对位置；若改用全局下标，注意 $\pm(x-1)$ 的平移，容易差一。
5. **答案规模**：$n=250000$ 时答案可达 $n(n-1)\approx6\times10^{10}$，必须用 `long long`。
6. **$n=2$**：只有一条边，$L_2\le1$ 恒成立 ⇒ 每条消息 1 跳，总答案 2。
