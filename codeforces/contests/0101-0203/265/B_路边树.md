# Codeforces 265B 路边树（简化版）题解

## 1. 题目概述

- **题目链接**：https://codeforces.com/problemset/problem/265/B
- **比赛来源**：Codeforces Round 162 (Div. 2) · Problem B（UTC 2013-01-20）
- **难度**：1000
- **标签**：模拟、贪心
- **评测类型**：普通
- **限制**：时间 2 s / 内存 256 MB

**题意**：$n$ 棵树自西向东排列，高度 $h_i$。Liss 起初在第 1 棵树的根部（高度 0）。每秒可做一件事：在树上上/下移 1 个单位高度；吃掉当前树顶的坚果；跳到下一棵树的**相同高度**（要求该高度不超过下一棵树的高度 $h_{i+1}$）。求吃完所有坚果的最少秒数。

**约束**：$n \le 10^5$，$h_i \le 10^4$。

## 2. 示例与观察

官方样例 1：

```text
输入：
2
1
2

输出：
5
```

官方样例 2：

```text
输入：
5
2
1
2
1
1

输出：
14
```

**样例 1**：爬到 1（1s）+ 吃（1s）+ 跳到树 2 高度 1（1s）+ 爬到 2（1s）+ 吃（1s）= 5 ✓。

**样例 2**：$h = 2,1,2,1,1$：爬 2 + 吃 1 = 3；下降 1 + 跳 1 + 吃 1 = 3（共 6）；跳 1 + 爬 1 + 吃 1 = 3（9）；下降 1 + 跳 1 + 吃 1 = 3（12）；跳 1 + 吃 1 = 2（14）✓。

**观察 1（顺序固定）**：只能往东跳，所以必然按 $1,2,\ldots,n$ 的顺序吃，没有"选择顺序"的自由。

**观察 2（每段的花费可分解）**：吃完第 $i$ 棵树后位于高度 $h_i$。要到第 $i+1$ 棵树顶端：

- 先跳到下一棵树（1 秒），但要求当前高度 $\le h_{i+1}$；若 $h_i > h_{i+1}$ 必须先下到 $h_{i+1}$（$h_i - h_{i+1}$ 秒）；
- 到达后位于高度 $\min(h_i, h_{i+1})$，再爬到 $h_{i+1}$（若需要）；
- 吃坚果 1 秒。

**观察 3**：下降与上升都不如"少走冤枉路"，而上述做法已经是最少的竖直位移（必须先降到能跳的高度）✓。

## 3. 解题思路

![按树依次前进](../../../images/cf265b_move.svg)

$$
\text{ans} = (h_1 + 1) + \sum_{i=2}^{n}\Bigl(1 + \max(0, h_{i-1}-h_i) + \bigl(h_i - \min(h_{i-1}, h_i)\bigr) + 1\Bigr).
$$

其中第一项是"从根部爬到 $h_1$ + 吃"，求和里依次是"跳 1 秒 + 必要时下降 + 爬到顶 + 吃 1 秒"。

## 4. 正确性证明

**引理 1**：吃完第 $i$ 棵树后，最优解的位置必然在高度 $h_i$（树顶）。

**证明**：吃坚果必须到达树顶；吃完后若还要继续，竖直移动越少越好，所以停在树顶 ✓。∎

**引理 2**：从第 $i$ 棵树顶（高度 $h_i$）到第 $i+1$ 棵树顶吃完坚果，最少需要 $1 + \max(0, h_i - h_{i+1}) + (h_{i+1} - \min(h_i, h_{i+1})) + 1$ 秒。

**证明**：必须先跳（1 秒），而跳要求高度 $\le h_{i+1}$，故若 $h_i > h_{i+1}$ 至少要下降 $h_i - h_{i+1}$ 秒；跳跃后高度为 $\min(h_i,h_{i+1})$，要到树顶还要上升 $h_{i+1} - \min(h_i,h_{i+1})$ 秒；吃 1 秒。下界由此得；按"先降到位、跳、再升到顶"即可达到 ✓。∎

**定理**：算法输出的时间是最少时间。

**证明**：由引理 1，各段相互独立、可分别取到最小值；由引理 2 的公式逐段相加即为总时间，且每段都是下界 ⇒ 全局最优 ✓。∎

## 5. 复杂度分析

- **时间**：$O(n)$。
- **空间**：$O(n)$（可压到 $O(1)$）。
- **与时限的关系**：时限 2 s，$n = 10^5$ 实测端到端 10.4 ms。
- **数值范围**：总时间 $\le 10^5 \times (10^4 + 3) \approx 10^9$，用 64 位更稳。

## 6. 参考代码

### C++17

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n;
    if (scanf("%d", &n) != 1) return 0;
    vector<long long> h(n);
    for (int i = 0; i < n; i++) scanf("%lld", &h[i]);
    long long ans = h[0] + 1;                 // 从根爬到树 1 顶 + 吃掉
    for (int i = 1; i < n; i++) {
        ans += 1;                             // 跳到下一棵树
        if (h[i - 1] > h[i]) ans += h[i - 1] - h[i];   // 先下降
        long long at = min(h[i - 1], h[i]);
        ans += h[i] - at;                     // 再爬到顶
        ans += 1;                             // 吃掉
    }
    printf("%lld\n", ans);
    return 0;
}
```

### Python3

```python
import sys
def main() -> None:
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    h = [int(v) for v in data[1:1 + n]]
    ans = h[0] + 1
    for i in range(1, n):
        ans += 1
        if h[i - 1] > h[i]:
            ans += h[i - 1] - h[i]
        ans += h[i] - min(h[i - 1], h[i])
        ans += 1
    print(ans)
main()
```

## 7. 边界情况与易错点

1. **$n = 1$**：只需 $h_1 + 1$。
2. **高度下降**：$h_i > h_{i+1}$ 时先下降再跳，顺序不能颠倒。
3. **上升**：跳过去后可能还要上升（$h_{i+1} > h_i$）。
4. **"跳到下一棵树"要求高度不超过下一棵树**：这是唯一的方向约束。
5. **不能往回跳**：所以顺序固定。
6. **吃坚果也要 1 秒**：容易漏。
7. **起点在根部（高度 0）**：第一项是 $h_1$。
