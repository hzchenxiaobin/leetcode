# Codeforces 262A 罗马与幸运数字 题解

## 1. 题目概述

- **题目链接**：https://codeforces.com/problemset/problem/262/A
- **比赛来源**：Codeforces Round 160 (Div. 2) · Problem A（UTC 2013-01-13）
- **难度**：800
- **标签**：字符串、计数
- **评测类型**：普通
- **限制**：时间 1 s / 内存 256 MB

**题意**：幸运数字是十进制表示中只含 `4` 和 `7` 的正整数。给出 $n$ 个正整数，统计其中"**幸运数字的个数**不超过 $k$"的数有多少个（注意统计的是每个数里 `4`/`7` 出现的次数，不是"是否为幸运数"）。

**约束**：$n, k \le 100$，$a_i \le 10^9$。规模极小，把每个数当字符串逐位扫一遍即可。

## 2. 示例与观察

官方样例 1：

```text
输入：
3 4
1 2 4

输出：
3
```

官方样例 2：

```text
输入：
3 2
447 44 77

输出：
2
```

**样例 1**：三个数里 `4` 出现 1 次，其余 0 次，都不超过 $k = 4$ → 3。

**样例 2**：`447` 里有 3 个幸运数字（$> 2$）→ 不计数；`44`、`77` 各 2 个 → 计入 → 2。

**观察 1（统计对象）**：题目问的是"数字 $x$ 里字符 `4`/`7` 的**出现次数**"，所以 `4477` 算 4 个而不是 1 个。

**观察 2**：把数按字符串读入最省事（避免取模运算，也天然处理 $10^9$）。

## 3. 解题思路

![统计每个数里 4/7 的个数](../../../images/cf262a_count.svg)

1. 读入 $n, k$；
2. 对每个数按字符串扫描，统计 `s[j] == '4' || s[j] == '7'` 的个数 $c$；
3. 若 $c \le k$ 则答案 $+1$。

时间 $O(\sum |s_i|) \le 10 \times 100$。

## 4. 正确性证明

**引理**：对每个数 $x$，上述扫描得到的 $c(x)$ 恰为它的十进制表示中 `4`/`7` 的出现次数。

**证明**：十进制表示唯一，逐个字符检查即为出现次数。∎

**定理**：算法的输出等于"满足 $c(a_i) \le k$ 的 $i$ 的个数"。

**证明**：算法对每个 $i$ 计算 $c(a_i)$ 并与 $k$ 比较，满足则累加，与题意一致。∎

## 5. 复杂度分析

- **时间**：$O(n \log_{10} a_{\max})$，最多约 $10^3$ 次字符判断。
- **空间**：$O(1)$（每行一个临时字符串）。
- **与时限的关系**：时限 1 s，最大数据实测端到端 2.4 ms。

## 6. 参考代码

### C++17

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, k;
    if (scanf("%d %d", &n, &k) != 2) return 0;
    int ans = 0;
    for (int i = 0; i < n; i++) {
        char s[16];
        scanf("%s", s);
        int c = 0;
        for (int j = 0; s[j]; j++) if (s[j] == '4' || s[j] == '7') c++;
        if (c <= k) ans++;
    }
    printf("%d\n", ans);
    return 0;
}
```

### Python3

```python
import sys


def main() -> None:
    data = sys.stdin.buffer.read().split()
    n, k = int(data[0]), int(data[1])
    ans = 0
    for tok in data[2:2 + n]:
        s = tok.decode()
        c = sum(1 for ch in s if ch == '4' or ch == '7')
        if c <= k:
            ans += 1
    print(ans)


main()
```

## 7. 边界情况与易错点

1. **`k` 比数字长度大**：全部计数，不要漏。
2. **数里没有 4/7**：$c = 0 \le k$（$k \ge 1$）→ 计入。
3. **把"幸运数"理解错**：本题不是判断 $x$ 是否为幸运数，而是数出现次数（`44` 的答案是 2 个）。
4. **`4` 与 `7` 都要数**：漏掉 `7` 会错。
5. **前导零不存在**：题目保证是正整数，不用特殊处理。
6. **输入规模**：读字符串比读整数更稳（`1e9` 用 `int` 也可以）。
