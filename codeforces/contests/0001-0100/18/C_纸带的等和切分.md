# Codeforces 18C 纸带的等和切分 题解

## 1. 题目概述

- **题目链接**：https://codeforces.com/problemset/problem/18/C
- **比赛来源**：Codeforces Beta Round 18 · Problem C（2010-05-06）
- **难度**：1200
- **标签**：数据结构、实现
- **评测类型**：普通
- **限制**：时间 2 s / 内存 64 MB

**题意**：给 $n$ 个整数（可为负）排成一条纸带，问有多少个切分边界 $i$（$1\le i<n$）使左段和等于右段和。

**约束**：$n \le 10^5$，元素绝对值 $\le 10^4$，总和可达 $10^9$，用 64 位。只有一组数据。

## 2. 示例与观察

官方样例 1（输入 / 输出原样）：

```text
输入：
9
1 5 -6 7 9 -16 0 -2 2

输出：
3
```

**样例解释**：总和为 $0$，所以"左和 = 右和"等价于"左前缀和 = 0"。前缀和依次为 $1,6,0,7,16,0,0,-2$，其中第 3、6、7 个为 0 → 3 个切分点（注意第 6、7 个都算，中间那个 $0$ 元素两侧是**不同**的切法）。

官方样例 2（输入 / 输出原样）：

```text
输入：
3
1 1 1

输出：
0
```

总和 $3$ 为奇数，任何切分都做不到左右相等 → `0`。

官方样例 3（输入 / 输出原样）：

```text
输入：
2
0 0

输出：
1
```

总和 $0$，前缀和 $P_1=0$，只有在第 1、2 个元素之间切一刀满足 $2P_1=0$（只能切在元素之间，所以 $n-1$ 个位置里只有 1 个合法）→ `1`。

**观察 1**：设总和为 $S$、前缀和为 $P_i$，则左段和 $P_i$、右段和 $S-P_i$；条件即 $2P_i=S$。

**观察 2**：相邻元素为 $0$ 时，会出现多个相邻的合法切分点——它们对应不同的边界，**都要计数**（本题没有"去重"规则，样例 1 的第 6、7 个切分点就是这么来的）。

## 3. 解题思路

### 3.1 朴素做法与瓶颈

对每个 $i$ 分别求两段和是 $O(n^2)$，$n=10^5$ 时 $10^{10}$，超时。

### 3.2 核心观察：一次前缀和扫描

![前缀和扫描](../../../images/cf18c_prefix.svg)

先求总和 $S$，再从左往右维护前缀和 $P$：对 $i=1..n-1$，令 $P \mathrel{+}= a_i$，若 $2P=S$ 则答案 $+1$。$O(n)$、$O(1)$ 额外空间。

### 3.3 正确性要点

- 边界 $i$ 与 $n-i$ 都必须为正（$1\le i\le n-1$），循环范围正是如此。
- 负数不影响前缀和的性质，不需要特殊处理。
- 用 `long long` 存 $2P$ 与 $S$。

### 3.4 样例走查

样例 1：$S=0$；$i=1$ 时 $P=1$（$2P
e0$）；$i=2$ 时 $P=6$；$i=3$ 时 $P=0$ ✓；$i=4$ 时 $7$；$i=5$ 时 $16$；$i=6$ 时 $0$ ✓；$i=7$ 时 $0$ ✓；$i=8$ 时 $-2$。共 3 ✓。

## 4. 正确性证明

**引理 1**：切在 $i$ 处合法 $\iff 2P_i=S$，其中 $P_i=\sum_{j<i}a_j$。

**证明**：左段和 $=P_i$，右段和 $=S-P_i$，相等即 $2P_i=S$。∎

**定理**：算法输出的计数等于合法切分点数。

**证明**：算法对每个 $i\in[1,n-1]$ 恰好检查一次引理 1 的条件，累加即得。∎

## 5. 复杂度分析

- **时间**：$O(n)$。
- **空间**：$O(1)$（不存前缀数组）。
- **与时限的关系**：$n=10^5$ 实测约 116 ms（含进程启动与读入）。

## 6. 参考代码

### C++17

```cpp
#include <bits/stdc++.h>
using namespace std;
int main(){
    int n; cin>>n;
    vector<long long> a(n);
    long long tot=0;
    for(auto &x:a){cin>>x; tot+=x;}
    long long pre=0; int ans=0;
    for(int i=0;i<n-1;i++){ pre+=a[i]; if(pre==tot-pre) ++ans; }
    cout<<ans<<"\n";
}
```

### Python3

```python
import sys
def main():
    d=list(map(int,sys.stdin.buffer.read().split()))
    n=d[0]; a=d[1:1+n]; tot=sum(a)
    pre=0; ans=0
    for i in range(n-1):
        pre+=a[i]
        if pre==tot-pre: ans+=1
    print(ans)
main()
```

## 7. 边界情况与易错点

1. **切分边界范围**：$1 \le i \le n-1$，不能切在最左/最右（每段必须有正整数个元素）。
2. **$n=1$**：没有合法切分，输出 0。
3. **总和为奇数**：$2P=S$ 无解，输出 0（代码自然处理）。
4. **相邻 0 元素**：会产生多个相邻合法切分点，**不要**去重（样例 1 的答案 3 就包含两个相邻的 0 前缀）。
5. **负数**：前缀和可能为负，不能只考虑正数。
6. **溢出**：总和可达 $10^9$，`2P` 更大，用 `long long`。
7. **读入**：一行 $n$ 个数，用 `cin >>` 即可。
