# Codeforces 18B 平台与蚂蚱的落点 题解

## 1. 题目概述

- **题目链接**：https://codeforces.com/problemset/problem/18/B
- **比赛来源**：Codeforces Beta Round 18 · Problem B（2010-05-06）
- **难度**：1700
- **标签**：暴力、数学
- **评测类型**：普通
- **限制**：时间 2 s / 内存 64 MB

**题意**：一维世界里有 $n$ 个平台，第 $k$ 个覆盖 $[(k-1)m,\ (k-1)m+l]$（$l<m$）。蚂蚱从 $0$ 出发，每次向右跳 $d$，问它**第一次掉下去**的坐标。落在平台端点上不算掉下去。

**约束**：$n,d,m,l \le 10^6$，$l<m$。平台总跨度可达 $10^{12}$，不能逐个跳跃模拟；但平台只有 $n$ 个，逐个平台推进即可 $O(n)$。答案可能超过 `int`，用 64 位。

## 2. 示例与观察

官方样例 1（输入 / 输出原样）：

```text
输入：
2 2 5 3

输出：
4
```

平台 1 是 $[0,3]$，平台 2 是 $[5,8]$。跳跃点 $2,4,6,\dots$：$2$ 在平台 1 上，$4$ 落在空隙 $(3,5]$ 里 → 掉下去，答案 4。

官方样例 2（输入 / 输出原样）：

```text
输入：
5 4 11 8

输出：
20
```

平台 $[0,8],[11,19],[22,30],[33,41],[44,52]$；跳跃点 $4,8,12,\dots$：$4,8$ 在平台 1，$12$ 在平台 2，$16$ 在平台 2，$20$ 落在空隙 $(19,22]$ → 答案 20。

**观察 1（只需看空隙）**：蚂蚱掉下去的位置一定落在某个"空隙"里：$(平台 k 的右端,\ 下个平台左端]$，或者最后一个平台之后。

**观察 2（第一个跳跃点）**：空隙左端为 $a$ 时，里面第一个 $d$ 的倍数是 $\left(\lfloor a/d
floor+1
ight)d$。若它不超过空隙右端，它就是候选答案。

**观察 3（顺序推进）**：从 $t=d$ 开始，若 $t$ 落在某个平台上，就把 $t$ 推到该平台右端之后的第一个倍数；若 $t$ 已经小于下个平台左端，说明它落在空隙里，直接输出。

## 3. 解题思路

### 3.1 朴素做法与瓶颈

直接模拟跳跃：每次 $t \mathrel{+}= d$，直到掉下去。最坏情况平台几乎连成一片（$l=m-1$、$d=1$），需要 $n\cdot m \le 10^{12}$ 步，超时。

### 3.2 核心观察：按平台推进

![用空隙直接算](../../../images/cf18b_gap.svg)

```
t = d
for k = 1..n:
    start = (k-1)*m, end = (k-1)*m + l
    if t < start: break            // 落在空隙里
    if t <= end: t = (end/d + 1)*d // 在板上：跳到板外下一个倍数
输出 t
```

每次循环把 $t$ 推到当前平台之外，所以最多 $n$ 次迭代，$O(n)$。

### 3.3 为什么只需这样推进

$t$ 单调递增，且每次被推进到"当前平台右端之后的第一个倍数"。若推进后 $t$ 仍落在下一个平台上，循环会继续处理它；若 $t$ 落在两个平台之间，循环在下一轮的 `t < start` 处退出——那正是第一个空隙里的跳跃点，也就是答案。

### 3.4 样例走查

样例 1：$t=2$；平台 1 $[0,3]$：$2 \le 3$ → $t=4$；平台 2 起点 5：$4<5$ → 退出，输出 4 ✓。

## 4. 正确性证明

**引理 1**：循环中 $t$ 始终是"当前已考虑完的位置之后、第一个 $d$ 的倍数，且不在已处理平台上"。

**证明**：初始 $t=d$ 是第一个跳跃点。若 $t$ 在当前平台 $[s,e]$ 上，则 $(e/d+1)d$ 是严格大于 $e$ 的最小 $d$ 的倍数，也是下一个不在该平台上的跳跃点（跳跃点都是 $d$ 的倍数，中间的倍数都 $\le e$，落在平台上）。∎

**引理 2**：若某轮 `t < start`，则 $t$ 是第一个掉落点。

**证明**：由引理 1，$t$ 大于上一平台右端；又 $t$ 小于当前平台左端，故 $t$ 落在空隙里，不在任何平台上 → 掉落。而比 $t$ 小的跳跃点都在之前的平台上（都被处理过），故 $t$ 是第一个。∎

**定理**：算法输出的坐标就是第一次掉落的点。

**证明**：循环结束时要么由引理 2 退出（空隙里的第一个跳跃点），要么处理完最后一个平台后 $t$ 位于最后一个平台右端之后，同样是最小的未覆盖跳跃点。∎

## 5. 复杂度分析

- **时间**：$O(n)$，每轮至多推进一次。
- **空间**：$O(1)$。
- **与时限的关系**：$n=10^6$ 实测约 14 ms，远低于 2 s。

## 6. 参考代码

### C++17

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;
int main(){
    ll n,d,m,l; cin>>n>>d>>m>>l;
    ll t=d;
    for(ll k=1;k<=n;k++){
        ll start=(k-1)*m, endk=(k-1)*m+l;
        if(t<start) break;                    // 落在空隙里
        if(t<=endk) t=(endk/d+1)*d;           // 在板上，改到板外下一个跳跃点
    }
    cout<<t<<"\n";
}
```

### Python3

```python
import sys
def main():
    n,d,m,l=map(int,sys.stdin.buffer.read().split())
    t=d
    for k in range(1,n+1):
        start=(k-1)*m; end=(k-1)*m+l
        if t<start: break
        if t<=end: t=(end//d+1)*d
    print(t)
main()
```

## 7. 边界情况与易错点

1. **端点算安全**：$t$ 等于 $e$ 时仍在平台上，必须用 `t <= end`。
2. **空隙判断**：若 $t$ 恰好等于下个平台左端，它其实落在平台上，不能当成掉落（代码里 $t<start$ 才退出，等号留给下一轮处理）。
3. **最后一个平台之后**：循环结束后 $t$ 可能远超最后一个平台，直接输出。
4. **溢出**：$(k-1)m$ 最大约 $10^{12}$，`int` 溢出，必须 64 位。
5. **$n=1$**：只有一个平台，$t$ 被推到平台右端之后即为答案。
6. **$l=m-1$**：平台几乎连成一片，只有很窄的缝，仍能 O(n) 处理。
7. **`d` 很大**：首个跳跃点就超过所有平台，答案就是 $d$。

1. **多只蚂蚱、不同步长**：可以对每个 $d$ 分别求第一个空隙倍数，或直接对空隙求"最小未覆盖倍数"。

3. **平台不等长**：O(n) 推进仍成立，只要平台按坐标有序。
