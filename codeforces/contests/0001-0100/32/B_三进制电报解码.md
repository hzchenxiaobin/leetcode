# Codeforces 32B 三进制电报解码 题解

## 1. 题目概述

- **题目链接**：https://codeforces.com/problemset/problem/32/B
- **比赛来源**：Codeforces Beta Round 32 (Div. 2, Codeforces format) · Problem B（UTC 2010-10-02）
- **难度**：800
- **标签**：表达式解析、实现（expression parsing, implementation）
- **评测类型**：普通
- **限制**：时间 2 s / 内存 256 MB

**题意**：Berland 的三进制数字用 borze 编码表示：

- 数字 `0` 编码为 `.`；
- 数字 `1` 编码为 `-.`；
- 数字 `2` 编码为 `--`。

给定一个合法的 borze 编码字符串（长度 $1 \dots 200$），把它解码成三进制数并输出（保留前导零）。

**约束**：

- 字符串长度不超过 $200$，直接从左到右扫描即可。
- 输入保证是某个三进制数的合法编码；不需要处理非法情况。
- 数字可能有前导零，输出时**保留**它们，不能去掉。
- 只有一组数据。

## 2. 示例与观察

官方样例 1（输入 / 输出原样）：

```text
输入：
.-.--

输出：
012
```

**样例 1 解释**：从左扫描：`.` → `0`；`-.` → `1`；`--` → `2`。连起来是 `012`。

官方样例 2（输入 / 输出原样）：

```text
输入：
--.

输出：
20
```

**样例 2 解释**：`--` → `2`，`.` → `0`，输出 `20`。

官方样例 3（输入 / 输出原样）：

```text
输入：
-..-.--

输出：
1012
```

**样例 3 解释**：`-.` → `1`，`.` → `0`，`-.` → `1`，`--` → `2`，输出 `1012`。

自造样例（标注“自造”）：

| 输入 | 输出 | 说明 |
|------|------|------|
| `.` | 0 | 单个零 |
| `--` | 2 | 单个二 |
| `-.` | 1 | 单个一 |
| `...` | 000 | 三个前导零，必须保留 |
| `--.--.` | 220 | 2、2、0 |

**观察**：三种 token 的首字符只有 `.` 和 `-`：

- 若当前字符是 `.`，它只能表示数字 `0`，长度 $1$；
- 若当前字符是 `-`，它必须和下一个字符一起构成 `-.` 或 `--`，长度 $2$。

因此每个位置属于哪个 token 是**唯一确定**的，从左到右贪心扫描不会产生歧义，也不需要回溯。

## 3. 解题思路

### 3.1 编码表

![三种 token：`.`、`-.`、`--`](../../../images/cf32b_tokens.svg)

| 首字符 | token | 数字 | 前进格数 |
|--------|-------|------|----------|
| `.` | `.` | 0 | 1 |
| `-` | `-.` | 1 | 2 |
| `-` | `--` | 2 | 2 |

关键点：`-` 开头的 token 一定是两字符，且第二个字符只能是 `.` 或 `-`；不存在“一个 `-` 单独表示某个数字”的情况。

### 3.2 扫描算法

1. 读入字符串 $s$，令 $i=0$；
2. 当 $i < |s|$：
   - 若 $s[i] = `.`：输出 `0`，$i \leftarrow i+1$；
   - 否则 $s[i] = `-`$：
     - 若 $s[i+1] = `.`：输出 `1`；
     - 否则输出 `2`；
     - 无论哪种，$i \leftarrow i+2$；
3. 输出拼接得到的数字串。

由于输入合法，访问 $s[i+1]$ 时一定不会越界。

### 3.3 样例走查

![样例 1：`.-.--` → 0 1 2](../../../images/cf32b_walk.svg)

以 `.-.--` 为例：

| 位置 | 当前 token | 输出 | 新位置 |
|------|------------|------|--------|
| 0 | `.` | 0 | 1 |
| 1 | `-.` | 1 | 3 |
| 3 | `--` | 2 | 5（结束） |

输出 `012`。

`--.` 则先读 `--` 输出 `2`，再读 `.` 输出 `0`，得到 `20`。

## 4. 正确性证明

**引理 1（首字符决定 token 长度）**：在合法 borze 编码中，若当前位置字符为 `.`，则它单独构成数字 `0`；若为 `-`，则它与下一个字符共同构成数字 `1` 或 `2`。

**证明**：编码表只有三种 token，且只有 `.`、`-.`、`--`。以 `.` 开头的 token 只有 `.` 本身；以 `-` 开头的 token 都是两字符。合法编码中不会出现其他情况。∎

**引理 2（扫描不越界）**：算法每次前进 $1$ 或 $2$ 格，且当字符为 `-` 时，后面一定还有字符。

**证明**：若 `-` 是最后一个字符，它无法构成 `-.` 或 `--`，与输入是合法编码矛盾。因此 `i+1` 存在。∎

**引理 3（解码唯一）**：算法输出的数字串等于编码前原来的三进制数。

**证明**：对扫描位置归纳。每次算法读取的 token 与编码时该位置使用的 token 相同（由引理 1，首字符唯一决定 token），因此输出对应数字；扫描前进的格数也等于该 token 的长度，所以下一次读取的正是编码中下一个 token 的起点。归纳到字符串结束，拼接结果就是原数。∎

**定理**：算法在 $O(|s|)$ 时间内正确解码，并保留前导零。

**证明**：由引理 3 正确性；每次至少前进 $1$，总步数 $O(|s|)$。算法从不删除输出中的 `0`，因此前导零被保留。∎

## 5. 复杂度分析

- **时间**：$O(|s|)$，每个字符至多被读一次；$|s| \le 200$。
- **空间**：$O(|s|)$ 存输入和输出；也可以直接输出，额外空间 $O(1)$。
- **数值范围**：没有数值运算，输出长度不超过 $|s|$。
- **与时限的关系**：$|s|=200$ 时，C++ 端到端 200 次 min $2.07$ ms / avg $2.49$ ms；Python3 50 次 avg $22.1$ ms（均含进程启动），相对 2 s 余量极大。

## 6. 参考代码

### C++17

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    string s;
    cin >> s;
    string out;
    for (int i = 0; i < (int)s.size(); ) {
        if (s[i] == '.') {
            out += '0';
            ++i;
        } else if (s[i] == '-' && i + 1 < (int)s.size() && s[i + 1] == '.') {
            out += '1';
            i += 2;
        } else {
            out += '2';
            i += 2;
        }
    }
    cout << out << '\n';
    return 0;
}
```

### Python3

```python
import sys


def main() -> None:
    s = sys.stdin.readline().strip()
    out = []
    i = 0
    while i < len(s):
        if s[i] == '.':
            out.append('0')
            i += 1
        elif s[i] == '-' and i + 1 < len(s) and s[i + 1] == '.':
            out.append('1')
            i += 2
        else:
            out.append('2')
            i += 2
    print(''.join(out))


main()
```

两份代码都只依赖标准库，可原样提交。

## 7. 边界情况与易错点

1. **单个 `.`**：输出 `0`，不是空串。
2. **前导零**：`...` 必须输出 `000`，不能转成整数后输出 `0`。
3. **`-` 开头**：必须读两个字符；不要只看到 `-` 就输出某个数字。
4. **`-.` 与 `--` 的区别**：第二个字符是 `.` 还是 `-`，分别对应 1 和 2；不要写反。
5. **下标越界**：合法输入下 `-` 后必有字符，但代码仍建议写 `i + 1 < s.size()` 防御；若输入非法，else 分支会误读，但题目保证合法。
6. **输入方式**：字符串不含空格，`cin >> s` / `readline().strip()` 都可；若用 `getline` 注意去掉换行。
7. **输出不要换行分隔**：数字要连成一串输出，不能每个数字一行。
8. **长度 200**：输出字符串长度不超过 200，任何常规类型都够。
9. **只有一组数据**：没有 $t$。

**延伸思考**：

1. **如果编码不是前缀码**：例如允许 `-` 单独表示某个数字，那么从左到右可能有多种分割，需要 DP 统计方案数（类似 LeetCode 91）。
2. **如果要求输出十进制数值**：三进制串可能很长（$|s| \le 200$），需要高精度或只输出模某个数。
3. **如果输入可能非法**：需要检查 `-` 后是否有字符、是否出现其他字符，并在非法时输出错误信息。
4. **如果编码表扩展为更多 token**：只要仍是前缀码，就能用 Trie 或“首字符分支”贪心；否则要回溯/DP。
5. **如果要求保留原字符串的分组信息**：可以在输出数字的同时记录每个 token 的起止位置。
