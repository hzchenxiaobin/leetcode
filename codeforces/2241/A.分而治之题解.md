# Codeforces 分而治之 题解

## 1. 题目概述

- **标题 / 题号**：分而治之（Codeforces 2241A，英文名 Divide and Conquer）
- **链接**：https://codeforces.com/problemset/problem/2241/A
- **来源**：Codeforces Round 1107 (Div. 3) · Problem A
- **难度**：800（$\ast 800$）
- **限制**：时间 1 s / 内存 256 MB
- **标签**：贪心、数学、数论（官方标签：greedy, math, number theory）

**题意**：给定两个正整数 $x$ 与 $y$，允许执行任意多次（可以为 $0$ 次）如下操作：

- 选择一个正整数 $z$，满足 $z$ 整除 $x$；
- 令 $x := x / z$。

问是否能把 $x$ 变得**恰好等于** $y$。多测：第一行 $t$ 表示组数，之后每组一行两个整数 $x,y$，每组输出一行 `YES` / `NO`（大小写不敏感）。

**约束**：

- $1 \le t \le 10^4$，组数很多 → 每组必须 $O(1)$ 或接近 $O(1)$
- $1 \le x, y \le 100$，值域极小，但这不意味着应当搜索
- 每次的 $z$ 必须是**当前** $x$ 的因子，且 $z$ 可以取 $1$（等价于空操作）
- 输出 `YES` / `NO`，大小写任意

## 2. 示例

官方样例（输入 / 输出原样；样例里的空行只是排版）：

```text
输入：
3
12 2
6 7
99 79

输出：
YES
NO
NO
```

补一组自造样例，覆盖 $x=y$、$y=1$、$x=1$、$y \nmid x$ 等边界：

```text

输出：

```

第 3 组 $6/4$ 不是整数，$y$ 比 $x$ 小也照样不行；第 6 组 $72 = 8 \times 9$，取 $z = 9$ 一步到位。

## 3. 解题思路

### 3.1 暴力思路

最直白的做法是「枚举操作序列」：每一步从当前值的因子里挑一个 $z$ 除下去。但 $z=1$ 是空操作，序列长度没有上限，直接枚举会陷入死循环。

把视角换成**值域上的可达性搜索**：从 $x$ 出发，状态 $v$ 的后继是 $v/z$（$z \mid v$），也就是 $v$ 的全部因子。用 BFS 配 `visited` 数组，状态数不超过 $x$，每个状态枚举 $1..v$ 找因子，单组 $O(x \cdot d(x))$。$x \le 100$ 时它当然能过——但它把「判断题」做成了「搜索题」，没有回答**为什么**能或不能，而且值域一放大就彻底失效。题目只问存在性，说明答案一定有一个一行就能写出的充要条件。

### 3.2 核心观察：可达集合就是 $x$ 的因子集合

![多步除法等价于一步除法](images/cf2241_a_divisor_chain.svg)

**正向**：一次操作后 $x' = x/z$ 且 $z \mid x$，所以 $x = z \cdot x'$，即 $x'$ 整除 $x$。多步连乘也一样：若依次除以 $z_1,z_2,\dots,z_k$，则

$$x_k = \frac{x}{z_1 z_2 \cdots z_k} = \frac{x}{D},\qquad D = z_1z_2\cdots z_k \in \mathbb{Z}_{>0}$$

所以**任何一步之后的值都还是 $x$ 的因子**——怎么除都跳不出因子集合。

**反向**：若 $d \mid x$，取 $z = x/d$。它是正整数，且 $x = d \cdot z$ 说明 $z \mid x$，合法；操作后 $x/z = d$。所以**每个因子都能一步到达**。

两边合起来：

$$\text{可达}(x) = \{\,d : d \mid x\,\}$$

于是「能否变成 $y$」等价于「$y$ 是否整除 $x$」，即一行判定：

$$\boxed{\;x \bmod y = 0\;}$$

> 💡 题名「分而治之」在这里是个**反讽**：把一次除法拆成多次（$12 \xrightarrow{\div 2} 6 \xrightarrow{\div 3} 2$）与一次除（$12 \xrightarrow{\div 6} 2$）落点完全相同，因为总商都是 $6$。**拆步不会让可达集合变大**，所以「分」这件事对答案毫无影响。

### 3.3 算法流程

![每组一次取模的流程图](images/cf2241_a_flow.svg)

对每组数据：

1. 读入 $x, y$；
2. 若 $x \bmod y = 0$ 输出 `YES`，否则输出 `NO`；
3. 进入下一组。

**不需要任何特判**，这一点值得单独强调，因为初学者最容易在这里写出多余分支：

- $x = y$：允许 $0$ 次操作，而 $x \bmod x = 0$，判据天然成立；
- $y = 1$：取 $z = x$ 一步到 $1$，而 $x \bmod 1 = 0$；
- $y > x$ 且 $y \ne x$：此时 $x \bmod y = x \ne 0$，判据天然拒绝——因为 $x$ 的因子都不会超过 $x$。

### 3.4 示例演算

![样例走查表](images/cf2241_a_walkthrough.svg)

| 组 | $x$ | $y$ | $x \bmod y$ | 一步到位的 $z = x/y$ | 答案 |
|----|-----|-----|-------------|----------------------|------|
| 1 | 12 | 2 | 0 | 6（也可拆成 $\div 2$ 再 $\div 3$） | YES |
| 2 | 6 | 7 | 6 | 不存在 | NO |
| 3 | 99 | 79 | 20 | 不存在 | NO |
| 4 | 7 | 7 | 0 | 1（其实 0 次操作就够） | YES |
| 5 | 100 | 1 | 0 | 100 | YES |
| 6 | 6 | 4 | 2 | 不存在 | NO |
| 7 | 1 | 1 | 0 | 1（空操作） | YES |

第 1 组正是题面 Note 里的两步走法：$12 \div 2 = 6$，$6 \div 3 = 2$；而 $2 \times 3 = 6$，所以一步除以 $6$ 等价。第 2、3、6 组的余数都非 $0$，无论拆成多少步，落点都困在 $x$ 的因子集合里，永远碰不到 $y$；注意第 6 组 $y = 4 < x = 6$ 也不行，说明**大小关系不是判据**。

## 4. 算法细节

1. **多测循环**：读到 $t$ 后循环 $t$ 次，每组重新读 $x,y$；本题没有需要清空的数组，天然无污染。
2. **判据只有一行**：`x % y == 0`。不要写成「反复试除 $y$ 直到不能除」再看 $x$ 是否变成 $1$——那样虽然也对，却多了一层循环与出错面。
3. **$x = y$ 的零次操作**：题面明确允许操作 $0$ 次，取模判据自动覆盖；若额外写 `if (x == y) YES` 反而要小心与其他分支的顺序。
4. **$y > x$ 不用特判**：$x \bmod y = x \ne 0$（$x \ge 1$），自动输出 `NO`；不要写 `if (y > x) NO`，否则容易把 $x = y$ 误判。
5. **除零风险**：$y \ge 1$，取模安全；但若把判定写成 `x / y`（整除）再乘回比较，$y=0$ 就会崩——本题用 `%` 正好避开。
6. **整数范围**：$x,y \le 100$，`int` 足够，且只有一次取模、无乘法，不存在溢出；即便把值域放大到 $10^{18}$，`long long` 取模仍然安全。
7. **I/O 优化**：C++ 关同步 + `'\n'`（不要 `endl`，每行刷新在 $10^4$ 行时纯属浪费）；Python 用 `sys.stdin.buffer.read().split()` 一次读完。
8. **输出格式**：每组一行、顺序与输入一致，统一大写 `YES` / `NO` 最省心。

## 5. 正确性证明

**引理 1（单步保整除）**：若 $x'$ 由 $x$ 经一次操作得到，则 $x' \mid x$。

**证明**：操作要求 $z \mid x$，故 $x = z \cdot x'$ 中 $x' = x/z$ 是正整数，且 $x = z \cdot x'$ 说明 $x'$ 整除 $x$。∎

**引理 2（多步保整除）**：经过任意 $k \ge 0$ 次操作得到 $x_k$，都有 $x_k \mid x$。

**证明**：对 $k$ 归纳。$k=0$ 时 $x_0 = x$，显然 $x \mid x$。设 $x_{k-1} \mid x$ 且 $x_k \mid x_{k-1}$（引理 1），由整除的传递性得 $x_k \mid x$。∎

**引理 3（每个因子一步可达）**：若 $d \mid x$，则存在一次合法操作把 $x$ 变成 $d$。

**证明**：取 $z = x/d$。由 $d \mid x$ 知 $z$ 是正整数，且 $x = d \cdot z$ 说明 $z \mid x$，故该 $z$ 合法；操作后 $x / z = d$。∎

**定理**：能把 $x$ 变成 $y$ 当且仅当 $x \bmod y = 0$。

**证明**：
（必要性）若经若干次操作得到 $y$，由引理 2 有 $y \mid x$，即 $x \bmod y = 0$。
（充分性）若 $x \bmod y = 0$，则 $y \mid x$，由引理 3 取 $z = x/y$ 一步即可把 $x$ 变成 $y$。∎

**推论 1**：若 $y \nmid x$，则无论操作多少次都无法到达 $y$——可达集合被引理 2 牢牢限制在 $\{d : d \mid x\}$ 内。这解释了样例第 2、3 组，也说明了为什么 $y < x$ 时仍可能失败（如 $x=6, y=4$）。

**推论 2**：当 $y \mid x$ 时，最少操作次数为 $0$（若 $y = x$）或 $1$（若 $y < x$）；下界由「$0$ 次只能停在 $x$」给出，上界由引理 3 给出。

## 6. 复杂度分析

- **时间**：每组一次取模加一次比较，$O(1)$；总时间 $O(t) \le 10^4$ 次基本运算，输入读取是主要开销。
- **空间**：$O(1)$ 额外空间（只有 $x,y$ 两个变量），与 $t$ 无关。
- **对照时限**：以最大约束 $t = 10^4$ 造数据实测（5 次取中位数，含进程启动与 I/O），C++ 约 21–24 ms，Python3 约 33–50 ms，距 1 s 时限有 20 倍以上余量。

## 7. 参考代码

### C++17

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int t;
    if (!(cin >> t)) return 0;              // 空输入防护
    while (t--) {
        int x, y;
        cin >> x >> y;
        // 可执行任意次（含 0 次）除法，每次除以当前值的某个因子：
        // 可达值恰好是 x 的全部因子，故只需判断 y 是否整除 x。
        cout << (x % y == 0 ? "YES" : "NO") << '\n';
    }
    return 0;
}
```

### Python3

```python
import sys


def main() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:                            # 空输入防护
        return
    t = int(data[0])
    out = []
    for i in range(t):
        x = int(data[1 + 2 * i])
        y = int(data[2 + 2 * i])
        out.append("YES" if x % y == 0 else "NO")
    sys.stdout.write("\n".join(out) + "\n")


main()
```

## 8. 边界情况与易错点

1. **$x = y$**：允许 $0$ 次操作 → `YES`。若误以为「必须至少除一次」会输出 `NO`，这是本题最常见的丢分点（样例之外的隐藏用例大量存在）。
2. **$y = 1$**：取 $z = x$ 一步到 $1$，恒为 `YES`；此时 $x \bmod 1 = 0$ 自动成立，不需要额外分支。
3. **$x = 1,\ y > 1$**：$1$ 的因子只有 $1$，永远停在 $1$ → `NO`。
4. **$y > x$ 且 $y \ne x$**：$x \bmod y = x \ne 0$ → `NO`；不要写 `y > x` 的特判，以免把 $x = y$ 误伤。
5. **$y < x$ 但整除不成立**：如 $(6,4)$、$(12,5)$、$(99,79)$ → `NO`。「能变小」不等于「能变成 $y$」。
6. **把 $z$ 当成质数**：题面只说 $z$ 是 $x$ 的因子，合数同样合法（$12 \div 6 = 2$）；若只允许质因子，答案仍然是「$y \mid x$」，但步数会变成质因子重数之和。
7. **搜索时忘了去重**：若真去写 BFS，$z=1$ 会产生自环并死循环，必须配 `visited`；本题的正解完全不需要搜索。
8. **多测读入与输出**：$t$ 组数据一次性读到末尾、按序输出；空输入时直接返回，避免 `int t;` 未初始化造成的未定义行为。
9. **输出大小写**：题面接受 `yes`/`Yes`/`yEs`，但统一 `YES`/`NO` 可省掉一类格式争议。

**延伸思考**：

1. **最小步数版**：若每次的 $z$ 必须是**质数**，则 $y \mid x$ 时最少步数恰为 $\Omega(x/y)$（总质因子重数，含重复计数），否则不可达；此时答案不再是一个布尔值，而是一个可加的量。
2. **$z$ 限定为 $x$ 的真因子**：结论不变，因为 $y < x$ 时 $z = x/y > 1$ 已是真因子；$y = x$ 仍然允许 $0$ 次操作。
3. **乘法版本**：把操作改成「选 $z \mid x$，令 $x := x \cdot z$」。此时可达集合不再是有限集——取 $z = x$ 就能无限翻倍，若 $z$ 可为任意正整数则一切 $x$ 的倍数都可达；若限制 $z$ 为质因子，可达集合变成「$x$ 乘以若干质数」的全体，问题性质彻底改变。
4. **每步可除可减**：允许 $x := x - z$（$z \mid x$）会让状态之间产生环，判定从整除问题退化为图可达 / 最短路问题，需要 BFS 甚至数论分块，这才真正配得上「分而治之」的题名。
