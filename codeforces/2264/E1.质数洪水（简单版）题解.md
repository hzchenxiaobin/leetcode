# Codeforces 质数洪水（简单版） 题解
## 1. 题目概述

- **标题 / 题号**：质数洪水（简单版）（Codeforces 2264E1，英文名 A Prime Flood (Easy Version)）
- **链接**：https://codeforces.com/problemset/problem/2264/E1
- **来源**：Codeforces Round 1121 (Div. 2) · Problem E1
- **难度**：2200（2000 分）
- **限制**：时间 3 s / 内存 256 MB
- **标签**：组合数学、动态规划、数论

**题意**：给定长度为 $n$ 的数组 $a$（$1\le a_i\le n$）。对每个**非空子序列** $b$（按下标选取，不同下标集合算不同子序列），可以执行任意多次操作：选一个质数 $p$，把所有**当前值能被 $p$ 整除**的 $b$ 中元素同时减 $1$，其余不动。记 $f(b)$ 为操作后能让 $b$ 全部相等的**最大**整数 $x$，求所有 $2^n-1$ 个非空子序列的 $f(b)$ 之和对 $998244353$ 取模。每组测试独立，子序列也各自从初始值开始。

多测：第一行 $t$；每组给出 $n$ 与数组，输出一行。

**约束**：

- $1\le t\le 3000$，$1\le n\le 3000$，$\sum n\le 3000$
- $1\le a_i\le n$（值域与 $n$ 同阶，可直接按值域预处理）
- 目标复杂度每组 $O(n^2)$：$\sum n_i^2\le(\sum n_i)^2\le 9\times10^6$，总体可行

## 2. 示例

官方样例（输入 / 输出原样）：

```text
输入：
4
1
1
4
2 4 4 4
4
2 3 4 4
6
3 6 1 1 1 1

输出：
1
37
34
72
```

再补一组自造样例（标注为自造，用来说明"墙"的作用）：

```text
输入：
1
8
4 8 8 8 4 4 4 4

输出：
831
```

这里 $c_4=5$、$c_8=3$，$f(4,4)=4$、$f(8,8)=8$、$f(4,8)=3$（$B(4)=8$ 恰好卡住），于是 $(2^5-1)(2^3-1)\cdot3+(2^5-1)\cdot4+(2^3-1)\cdot8=651+124+56=831$。

## 3. 解题思路

### 3.1 暴力思路

枚举全部 $2^n-1$ 个子序列就有 $O(2^n)$，$n=3000$ 时不可能；而且对单个子序列还要搜索"用哪些质数、按什么顺序"才能求出 $f$。必须先弄清 $f(b)$ 由什么决定。

### 3.2 核心观察：$f(b)$ 只由最小值与最大值决定

![只有极值影响答案](images/cf2264_e1_min_max_reduce.svg)

三个小结论：

1. 操作只减不增，故 $f(b)\le\min b$；又 $x=1$ 永远可达（$1$ 不被任何质数整除，降到 $1$ 的元素再也不会被动），所以 $f(b)\ge1$。
2. **子集单调**：若某条质数序列把 $b$ 全部变成 $x$，把同一序列施加到 $b$ 的任意子多重集上，每个元素"是否被减"只取决于它自己的当前值，故子集也全部变成 $x$。于是 $f(\text{子集})\ge f(b)$，特别地
$$f(b)\le f(\min b,\max b)$$
3. **反向也成立**（§5 引理 5）：$f(b)\ge f(\min b,\max b)$。直观上极值对的贪心每一步用的质数 $p$ 都整除"当前最大值" $b_i$，把同一质数作用到整个 $b$ 上，所有元素只会被夹在 $[a_i,b_i]$ 内，最终与极值对一起落到同一个 $x$。

于是问题从 $2^n$ 个子序列压成 $O(n^2)$ 个 $(\min,\max)$ 对。

### 3.3 双元素：墙、平滑数与递归 $F$

![墙 B(u) 与平滑数 K](images/cf2264_e1_pair_recursion.svg)

记 $\operatorname{rad}(k)$ 为 $k$ 的不同质因子之积；称 $k$ 是 **$u$-平滑数**，若 $\operatorname{rad}(k)\mid\operatorname{rad}(u)$（即 $k$ 的每个质因子都整除 $u$）。称

$$B(u)=\min\{k>u:\operatorname{rad}(k)\mid\operatorname{rad}(u)\}$$

为 $u$ 的**墙**（不存在时记 $+\infty$）。

**单墙引理**：对 $u\le v$，$f(u,v)=u$ 当且仅当 $v<B(u)$。

- 若 $v<B(u)$：每个 $k\in(u,v]$ 都不是 $u$-平滑，于是有质因子 $p\mid k$、$p\nmid u$；从 $k=v$ 起逐步用这样的 $p$，$v$ 单独下降、$u$ 不动，最终停在 $u$。
- 若 $v\ge B(u)$：要最终都停在 $u$，$u$ 元素必须全程不动；但 $v$ 元素降到 $u$ 途中必经过 $B(u)$，而 $B(u)$ 的每个质因子都整除 $u$，任何能降它的质数都会把 $u$ 也降下来，矛盾。

当 $v\ge B(u)$ 时令 $K=\max\{k\le v:\operatorname{rad}(k)\mid\operatorname{rad}(u)\}$。由最大性，$(K,v]$ 中每个数都不是 $u$-平滑，$v$ 可先单独降到 $K$；而 $K$ 是 $u$-平滑的，取 $p\mid K$（于是 $p\mid u$）会把两者同时降 $1$，状态变为 $(u-1,K-1)$。由此

$$F(u,v)=\begin{cases}u, & v<B(u)\\ F(u-1,\,K-1), & v\ge B(u)\end{cases}$$

且 $f(u,v)=F(u,v)$（最优性见 §5 引理 4）。每层递归 $u$ 减 $1$，最多 $u-1$ 层。

### 3.4 计数与示例演算

![按 min,max 分组计数](images/cf2264_e1_walkthrough_table.svg)

固定 $\min=u<\max=v$：必须至少选一个值为 $u$ 的元素、至少一个值为 $v$ 的元素，严格在 $(u,v)$ 之间的元素任选，区间外不能选。设 $c_v$ 为值 $v$ 的出现次数、$S_v=\sum_{k\le v}c_k$，则

$$ans=\sum_{v=1}^{n}(2^{c_v}-1)\,v+\sum_{1\le u<v\le n}(2^{c_u}-1)(2^{c_v}-1)\,2^{\,S_{v-1}-S_u}\,F(u,v)$$

以官方样例 2（$a=[2,4,4,4]$）为例：

| $(\min,\max)$ | 子序列个数 | $f$ | 贡献 |
|---|---|---|---|
| $(4,4)$ | $2^3-1=7$ | $4$ | $28$ |
| $(2,2)$ | $1$ | $2$ | $2$ |
| $(2,4)$ | $1\times(2^3-1)=7$ | $1$ | $7$ |

合计 $28+2+7=37$。$f(2,4)=1$ 正是单墙引理的体现：$B(2)=4$，而 $4$ 唯一的质因子 $2$ 整除 $2$，降 $4$ 必然把停在 $2$ 上的元素降成 $1$。

## 4. 算法细节

1. **rad 筛**：对每个质数 $i$，把它所有倍数 $j$ 的 `rad[j]` 乘上 $i$，$O(n\log\log n)$；$\operatorname{rad}(j)\le j\le n$，用 `int` 即可。
2. **增量维护 $K$**：固定 $u$ 后按 $b=u\ldots n$ 递增扫描，若 `u % rad[b] == 0`（即 $\operatorname{rad}(b)\mid\operatorname{rad}(u)$）则 $K=b$，否则 $K$ 不变。每对 $(u,b)$ 只花 $O(1)$，无需二分。
3. **滚动数组**：$F_u[\cdot]$ 只依赖 $F_{u-1}[\cdot]$，保留两行 `prev/cur`，空间 $O(n)$。
4. **2 的幂与前缀和**：预处理 $2^0\ldots2^n$，用 $S$ 数组把 $2^{S_{v-1}-S_u}$ 降成一次查表。
5. **取模顺序**：连续乘三个 $<10^9$ 的数会溢出 `long long`，必须乘一次取一次模。
6. **多测**：每组重建 `cnt/S/prev/cur`；`rad` 与 $2$ 的幂只依赖全局最大 $n$，只预处理一次。
7. **$n=1$ 与 $a_i=1$**：前者只剩单元素子序列；后者所有含 $1$ 的子序列 $f=1$，由 $u=1$ 那一行单独处理。

## 5. 正确性证明

**引理 1（子集单调）**：若 $b'\subseteq b$，则 $f(b')\ge f(b)$。

**证明**：取把 $b$ 全部变成 $x$ 的质数序列 $p_1,\dots,p_T$。对 $b'$ 施加同一序列，每个元素是否被减只取决于它的当前值，而它在 $b$ 与 $b'$ 中的当前值始终相同，故 $b'$ 也全部变成 $x$。∎

**引理 2（单墙）**：$f(u,v)=u\iff v<B(u)$。

**证明**：即 §3.3 的两段论证：$v<B(u)$ 时"只降 $v$"可行；$v\ge B(u)$ 时 $v$ 必经过 $B(u)$，该步必然波及停在 $u$ 上的元素。∎

**引理 3（单调性）**：设 $F$ 为 §3.3 的递归，则 (a) 固定 $u$，$F(u,\cdot)$ 关于第二变元单调不增；(b) 当 $u\le v$ 时 $F(u,v)\ge F(u-1,v-1)$ 且 $F(u,v)\ge F(u-1,v)$。

**证明**：(a) 对 $u$ 归纳。$u=1$ 时恒为 $1$。设对 $u-1$ 成立，比较 $b<b'$：若 $b'<B(u)$，则 $F(u,b')=u\ge F(u,b)$；若 $b<B(u)\le b'$，则 $F(u,b)=u\ge F(u,b')$；若 $B(u)\le b$，设 $K,K'$ 为 $\le b,\le b'$ 的最大 $u$-平滑数，则 $K\le K'$，
$$F(u,b)=F(u-1,K-1)\ge F(u-1,K'-1)=F(u,b')$$
(b) 若 $v<B(u)$，则 $F(u,v)=u>u-1\ge F(u-1,v-1)$ 且 $\ge F(u-1,v)$；否则 $F(u,v)=F(u-1,K-1)$，由 $K-1\le v-1\le v$ 与 (a) 得 $F(u-1,K-1)\ge F(u-1,v-1)\ge F(u-1,v)$。∎

**引理 4（递归即最优）**：$f(u,v)=F(u,v)$。

**证明**：可行性由 §3.3 的构造给出。最优性对 $u+v$ 归纳：任意策略的第一步只有"同时降 / 只降 $v$ / 只降 $u$"三种，新状态分别为 $(u-1,v-1),(u,v-1),(u-1,v)$，最终值不超过对应 $F$；由引理 3 这三个 $F$ 都不超过 $F(u,v)$。∎

**引理 5（多重集归约）**：$f(b)=F(\min b,\max b)$。

**证明**：上界由引理 1。下界：设极值对的贪心过程为 $(a_0,b_0)=(m,M)\to\cdots\to(x,x)$，第 $i$ 步质数 $p_i$ 满足 $p_i\mid b_{i-1}$。把同一序列施加到 $b$ 上，归纳证明第 $i$ 步后所有元素落在 $[a_i,b_i]$：值为 $b_{i-1}$ 的元素必被 $p_i$ 整除，减为 $b_i$，其余不超过 $b_{i-1}-1=b_i$；被降的元素不低于 $a_{i-1}-1\ge a_i$，未降的不低于 $a_{i-1}\ge a_i$。末态 $a_T=b_T=x$，故全部元素等于 $x$。∎

**定理**：答案公式成立。

**证明**：由引理 5，每个子序列的贡献只取决于 $(\min,\max)$。$u=v$ 的组有 $2^{c_v}-1$ 个；$u<v$ 的组有 $(2^{c_u}-1)(2^{c_v}-1)2^{S_{v-1}-S_u}$ 个（两侧必选、中间任选、区间外不选）。乘法原理保证不重不漏。∎

## 6. 复杂度分析

- **时间**：筛 rad 为 $O(n\log\log n)$；每个 $u$ 扫一遍 $b$ 是 $O(n)$，共 $O(n^2)$；累加同为 $O(n^2)$。由 $\sum n_i^2\le9\times10^6$，C++ 实测 $n=3000$ 仅约 $0.03$ s。
- **空间**：$O(n)$——`rad`、$2$ 的幂、两行 DP、`cnt/S` 各一个数组。

## 7. 参考代码

### C++17

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;
const long long MOD = 998244353;

int main() {
    ios::sync_with_stdio(false); cin.tie(nullptr);
    int T; cin >> T;
    vector<vector<int>> tests(T);
    int N = 1;
    for (int t = 0; t < T; ++t) {
        int n; cin >> n; tests[t].resize(n);
        for (int i = 0; i < n; ++i) cin >> tests[t][i];
        N = max(N, n);
    }
    vector<int> rad(N + 1, 1);                    // rad[x] = 不同质因子之积
    for (int i = 2; i <= N; ++i) if (rad[i] == 1)
        for (int j = i; j <= N; j += i) rad[j] *= i;
    vector<long long> pw2(N + 2); pw2[0] = 1;
    for (int i = 1; i <= N + 1; ++i) pw2[i] = pw2[i - 1] * 2 % MOD;

    for (int t = 0; t < T; ++t) {
        int n = tests[t].size();
        vector<int> cnt(n + 2, 0), S(n + 2, 0);
        for (int x : tests[t]) ++cnt[x];
        for (int v = 1; v <= n; ++v) S[v] = S[v - 1] + cnt[v];
        long long ans = 0;
        for (int v = 1; v <= n; ++v) ans = (ans + (pw2[cnt[v]] - 1) * v) % MOD;
        long long c1 = pw2[cnt[1]] - 1;            // u = 1：F(1, v) = 1
        for (int b = 2; b <= n; ++b)
            ans = (ans + c1 * (pw2[cnt[b]] - 1) % MOD * pw2[S[b - 1] - S[1]] % MOD) % MOD;
        vector<long long> prev(n + 2, 1), cur(n + 2);
        for (int u = 2; u <= n; ++u) {
            int K = u - 1;                         // 最大的 u-平滑数 <= b
            for (int b = u; b <= n; ++b) {
                if (u % rad[b] == 0) K = b;
                cur[b] = (K <= u) ? u : prev[K - 1];   // 无墙取 u，否则转 (u-1, K-1)
            }
            long long cu = pw2[cnt[u]] - 1;
            for (int b = u + 1; b <= n; ++b)
                ans = (ans + cu * (pw2[cnt[b]] - 1) % MOD
                             * pw2[S[b - 1] - S[u]] % MOD * cur[b]) % MOD;
            prev.swap(cur);
        }
        cout << ans % MOD << '\n';
    }
    return 0;
}
```

### Python3

```python
import sys
MOD = 998244353

def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    pos = 0
    t = data[pos]; pos += 1
    tests, N = [], 1
    for _ in range(t):
        n = data[pos]; pos += 1
        tests.append(data[pos:pos + n]); pos += n
        N = max(N, n)
    rad = [1] * (N + 1)                       # rad[x]：不同质因子之积
    for i in range(2, N + 1):
        if rad[i] == 1:
            for j in range(i, N + 1, i):
                rad[j] *= i
    pw2 = [1] * (N + 2)
    for i in range(1, N + 2):
        pw2[i] = pw2[i - 1] * 2 % MOD
    out = []
    for a in tests:
        n = len(a)
        cnt = [0] * (n + 1)
        for x in a: cnt[x] += 1
        S = [0] * (n + 1)
        for v in range(1, n + 1): S[v] = S[v - 1] + cnt[v]
        ans = sum((pw2[cnt[v]] - 1) * v for v in range(1, n + 1)) % MOD
        c1 = pw2[cnt[1]] - 1
        for b in range(2, n + 1):
            ans = (ans + c1 * (pw2[cnt[b]] - 1) * pw2[S[b - 1] - S[1]]) % MOD
        prev = [1] * (n + 1)
        for u in range(2, n + 1):
            cur = [0] * (n + 1)
            K = u - 1
            for b in range(u, n + 1):
                if u % rad[b] == 0: K = b
                cur[b] = u if K <= u else prev[K - 1]
            cu = pw2[cnt[u]] - 1
            for b in range(u + 1, n + 1):
                ans = (ans + cu * (pw2[cnt[b]] - 1) * pw2[S[b - 1] - S[u]] * cur[b]) % MOD
            prev = cur
        out.append(str(ans))
    print("\n".join(out))

main()
```

## 8. 边界情况与易错点

1. **$n=1$**：没有 $u<v$ 的对，答案就是 $a_1$，代码里的双重循环自然不执行。
2. **含 $1$ 的子序列**：$\operatorname{rad}(1)=1$，任何 $k>1$ 都不满足 $\operatorname{rad}(k)\mid1$，所以 $B(1)=+\infty$、$F(1,v)=1$，必须单独初始化 $u=1$ 这一行。
3. **$K\le u$ 时必须返回 $u$**：此时无墙；若误写成 `prev[K-1]` 会读到 $u-1$ 行里下标 $K-1<u-1$ 的非法状态。
4. **下标不越界**：进入递归分支时 $K>u\ge2$，故 $K-1\ge2$，`prev[K-1]` 一定落在已算好的 $[u-1,n]$ 上。
5. **溢出与取模**：$10^9\times10^9\times10^9$ 会爆 `long long`，必须乘一次取一次模；`pw2` 的指数非负（$S$ 单调不减且 $b-1\ge u$）。
6. **多测清空**：`cur` 每轮重新分配，只写下标 $\ge u$；`cnt/S` 按每组 $n$ 重建，过期数据不会被读到。
7. **$a_i$ 与 $n$ 的关系**：题目保证 $a_i\le n$，`cnt` 只需开 $n+1$；若自行造数据把值放大，会越界。
