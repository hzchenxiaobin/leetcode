# Codeforces 穴居人 题解

## 1. 题目概述

- **标题 / 题号**：穴居人（Codeforces 2276D，英文名 Caveman）
- **链接**：https://codeforces.com/problemset/problem/2276/D
- **来源**：Educational Codeforces Round 195 (Rated for Div. 2) · Problem D
- **难度**：1400
- **限制**：时间 2 s / 内存 512 MB
- **标签**：组合数学，图论，分类讨论

**题意**：Monocarp 画了一张 $n$ 个点、$m$ 条边的无向简单图（无自环、无重边）。他要把每个点染成红色或蓝色，使得**每个点都至少有一个异色邻居**，求合法方案数；两种方案不同当且仅当存在某个点颜色不同。

他是穴居人，只认识 $1$、$2$ 和 "Many"（任何大于 $2$ 的数），不知道 $0$：方案数为 $0$ 输出 `Brain Melt`，为 $1$ 或 $2$ 输出该数字，大于 $2$ 输出 `Many`。多组数据：第一行 $t$，每组先给 $n,m$，再给 $m$ 行边，逐组输出一行。

**约束**：

- $1 \le t \le 10^4$，每组 $3 \le n \le 3\times10^5$，$0 \le m \le \min\left(\frac{n(n-1)}{2},\,3\times10^5\right)$
- $\sum n \le 3\times10^5$，$\sum m \le 3\times10^5$（因此总复杂度必须接近 $O(n+m)$）
- 图不保证连通，$m$ 可以等于 $0$（此时每个点都是孤立的）

## 2. 示例

官方样例（输入 / 输出原样）：

```text
输入：
4
3 1
1 2
3 2
1 2
1 3
3 3
1 2
2 3
1 3
4 3
1 2
2 3
3 4

输出：
Brain Melt
2
Many
Many
```

逐组说明：

- 第 1 组：只有一条边 $1-2$，点 $3$ 没有邻居，永远不可能有异色邻居 ⇒ `Brain Melt`。
- 第 2 组：$1$ 连着 $2,3$（二度点），$2,3$ 是叶子，必须与 $1$ 异色 ⇒ 恰好 $2$ 种（$1$ 红叶蓝 / $1$ 蓝叶红），即星形图 $K_{1,2}$。
- 第 3 组：三角形。只要不是三色相同，$6$ 种染色全都合法，$6>2$ ⇒ `Many`。
- 第 4 组：路径 $1-2-3-4$。点 $1,4$ 各自强制与邻居异色，$2$ 与 $3$ 之间无约束 ⇒ $2\times2=4$ 种 ⇒ `Many`（见 §3.4 的四种染色）。

自测时另外补了 $K_{1,4}$（$n=5$ 星形 ⇒ `2`）、$n=4$ 单边、五元环（$10$ 种 ⇒ `Many`）等边界小图。

## 3. 解题思路

### 3.1 暴力思路

直接枚举 $2^n$ 种染色，逐点检查是否存在异色邻居：$O(2^n\cdot m)$。$n$ 可达 $3\times10^5$，完全不可行。

但题目只要区分「$0$ / $1$ / $2$ / 很多」，这强烈暗示：**答案只取决于几个粗粒度的图参数**，而不需要真正计数。顺着这条线索做结构分析。

### 3.2 核心观察：叶子强制 + 反色对称

![叶子强制：叶子的颜色由唯一邻居确定](images/cf2276_d_leaf_forced.svg)

**观察 1（反色对称）**：把一种合法染色的红蓝全部互换，仍是合法染色，且两者在每个点上都不同。所以**合法染色数恒为偶数**：它只可能是 $0,2,4,6,\dots$。题目输出格式里那个 "1" 永远不会出现，$0$ 则需要单独刻画。

**观察 2（叶子被钉死）**：叶子的度数只有 $1$，它唯一的那条边必须异色，所以**叶子的颜色由它的邻居唯一确定**。既然叶子不需要"选择"，就把它从决策里剥掉：

- 令 $C$ 为所有**非叶子点**，$B=\{v\in C : v\text{ 的邻居全在 } C \text{ 中}\}$（没有任何叶子邻居的非叶子点）。先给 $C$ 染色，每片叶子取邻居的反色，叶子一定满足条件。
- $C\setminus B$ 中的点身边挂着叶子，而那片叶子必然是它的反色，所以它**天然**就有一个异色邻居；只有 $b\in B$ 还需要在 $C$ 内部找到一个异色邻居。

于是：**合法染色数 = $C$ 的染色中，使每个 $b\in B$ 都有异色邻居的染色数**（$C$ 的每种染色唯一延拓成整张图的染色，是个双射）。这一步把问题压缩到"核心点"上。

### 3.3 分类结论与算法流程

![分类：星形图 2 种，非星形至少 4 种](images/cf2276_d_star_vs_many.svg)

**结论**：设图连通且没有孤立点，$n\ge 3$。合法染色数 $=2$ 当且仅当这张图是**星形图** $K_{1,n-1}$；否则至少 $4$ 种。

- 星形图：所有叶子都被中心钉成反色，只剩「中心红 / 叶子蓝」与它的反色 $2$ 种。
- 非星形（无孤立点）：$B=\varnothing$ 时 $C$ 可以任意染色，直接给出 $2^{|C|}\ge 4$ 种；$B\ne\varnothing$ 时用"翻转一条边的两端"（$G[C]$ 二分）或"奇环上 4 种染色 + 最短路树延拓"（$G[C]$ 非二分）也能造出至少 $4$ 种（严格论证见 §5 引理 4）。

再考虑**多个连通分量**：条件完全是局部的，各分量独立选色、方案数相乘；只要分量里含有边，它至少贡献 $2$ 种（把每个点按到某个根的距离奇偶染色即可，见引理 2）。所以：有孤立点 ⇒ 总数为 $0$ ⇒ `Brain Melt`；没有孤立点 ⇒ 总数为 $2$ 当且仅当**全图只有一个分量且它是星形图**；其余情况乘积 $\ge 4$ ⇒ `Many`。

![算法流程：两次判断](images/cf2276_d_decision_flow.svg)

**星形图的判别**：$m=n-1$ 且 $\max_v \deg(v)=n-1$。必要性显然；充分性：若某点度数 $n-1$，它已与所有点相邻（图连通），再由 $m=n-1$ 得其余点的度数之和为 $n-1$、每点至少 $1$，故其余点度数全为 $1$，正是星形图。

于是每组数据只需统计度数：

1. 读边时累加 `deg[u]++, deg[v]++`；
2. 若存在 `deg[v] == 0` ⇒ `Brain Melt`；
3. 否则若 `m == n-1` 且 `maxdeg == n-1` ⇒ `2`；
4. 否则 ⇒ `Many`。

注意第 3 步**必须同时**判 $m=n-1$：只判 `maxdeg == n-1` 会把三角形（$K_3$，$n=3$ 时每点度数都是 $2=n-1$）误判成 $2$，而它其实有 $6$ 种。

### 3.4 示例演算

![官方样例走查](images/cf2276_d_walkthrough.svg)

| 样例 | $(n,m)$ | 度数序列 | 判定 | 输出 |
|------|---------|----------|------|------|
| 1 | $(3,1)$ | $(1,1,0)$ | 有点度数为 $0$ | `Brain Melt` |
| 2 | $(3,2)$ | $(2,1,1)$ | $m=n-1=2$ 且 $\max=n-1=2$ ⇒ 星形 | `2` |
| 3 | $(3,3)$ | $(2,2,2)$ | $m=3\ne n-1$ | `Many` |
| 4 | $(4,3)$ | $(1,2,2,1)$ | $m=n-1=3$ 但 $\max=2<n-1$ | `Many` |

第 4 组正好说明「是树」不等于「是星形」：路径 $1-2-3-4$ 的 $4$ 种合法染色为

```text
(红,蓝,红,蓝)   (红,蓝,蓝,红)   (蓝,红,红,蓝)   (蓝,红,蓝,红)
```

逐点检查都能找到异色邻居；其中第一、四种恰为反色对，另外两种不是——这正是"非星形时存在非平凡划分"的实例。

## 4. 算法细节

1. **只存度数，不存边**：读边时直接累加两端度数，读完 $m$ 条边即可回答；不需要邻接表、不需要 DFS/BFS，空间 $O(n)$、时间 $O(n+m)$。$m=0$ 时循环自然读 $0$ 条边，随后孤立点判定必然命中。
2. **多测清空**：每组重新 `vector<int> deg(n+1, 0)`（或按需 `fill`），不要复用上一组的数据，否则残留度数会破坏 `mx` 与 `mn`；$\sum n\le 3\times10^5$ 保证总分配量可接受。
3. **两次判定顺序**：先判孤立点再判星形。虽然有孤立点时不可能满足 $\max\deg = n-1$，但先判孤立点语义更清楚。
4. **星形判据写作 `m == n - 1 && mx == n - 1`**：不要只判最大度数（$n=3$ 的 $K_3$ 每点度数都是 $2=n-1$，会被误判成 `2`），也不要在每组内做 $O(n^2)$ 的"逐点检查是否连满"。
5. **输出字符串精确**：`Brain Melt`（两个单词首字母大写、中间一个空格）、`Many`（首字母大写）、数字直接输出 `2`，逐组一行。
6. **下标与读入**：顶点 $1\cdots n$，`deg` 开 $n+1$，统计最值时从 $1$ 开始扫（否则 `deg[0]` 的 $0$ 会被当成孤立点）；最多 $6\times10^5$ 个输入整数，C++ 关闭同步流、Python 用 `sys.stdin.buffer.read().split()` 整体读入。

## 5. 正确性证明

**引理 1（反色对称）**：设 $c$ 是合法染色，则 $\bar c$（红蓝互换）也是合法染色，且 $c\ne \bar c$。因此合法染色数恒为偶数，输出中的 $1$ 不会出现。

**证明**：把 $c(v)\ne c(u)$ 两边同时取反仍成立，故 $\bar c$ 满足每个点都有异色邻居；又因为每个点都满足 $\bar c(v)\ne c(v)$，两者不同。∎

**引理 2（存在性）**：若 $G$ 没有孤立点，则至少存在一种合法染色（更一般地，每个无孤立点的连通分量都至少贡献 $2$ 种）。

**证明**：在连通分量内任取一点 $r$，令 $c(v)=\operatorname{dist}(r,v)\bmod 2$。对 $v\ne r$，最短路给出邻居 $u$ 满足 $\operatorname{dist}(r,u)=\operatorname{dist}(r,v)-1$，二者奇偶不同，故 $u$ 是 $v$ 的异色邻居；对 $r$，其所有邻居距离都是 $1$（奇），而 $c(r)=0$（偶），由无孤立点知 $r$ 有邻居，故 $r$ 也有异色邻居。∎

**推论**：答案为 $0$ 当且仅当存在孤立点。孤立点显然永远没有异色邻居；反之由引理 2 至少 $2$ 种。

**引理 3（叶子归约）**：设 $L$ 为叶子集，$C=V\setminus L$，$B=\{v\in C:\ N(v)\subseteq C\}$。则"整张图的合法染色"与"$C$ 的、使每个 $b\in B$ 都有异色邻居的染色"之间存在双射。

**证明**：任取合法染色 $c$ 与叶子 $\ell$，$\ell$ 的唯一邻居 $u$ 必须与它异色，故 $c(\ell)=\overline{c(u)}$：叶子的颜色由 $c|_C$ 唯一确定。反过来，给定 $C$ 的一种染色，把每片叶子染成其邻居的反色，则：每片叶子满足条件；$a\in C\setminus B$ 有叶子邻居 $\ell$，且 $c(\ell)=\overline{c(a)}$，故 $a$ 满足条件；$b\in B$ 的邻居全在 $C$ 内，其条件恰为"在 $C$ 内有异色邻居"。两边条件完全对应，且两个方向互逆。∎

**引理 4（分类）**：设 $G$ 连通、无孤立点、$n\ge 3$。则 $f(G)=2$ 当且仅当 $G$ 是星形图 $K_{1,n-1}$。

**证明**：

($\Leftarrow$) 设 $G=K_{1,n-1}$，中心为 $c$。此时 $C=\{c\}$ 且 $B=\varnothing$（$c$ 的邻居全是叶子，故 $c\notin B$）。由引理 3，$C$ 的两种染色都合法，对应「中心红/叶子蓝」与「中心蓝/叶子红」，恰好 $2$ 种。∎

($\Rightarrow$) 用逆否命题：设 $G$ 连通、无孤立点、非星形，证 $f(G)\ge 4$。此时至少存在一条边 $(u,v)$ 满足 $\deg u\ge2$ 且 $\deg v\ge2$（否则每条边都有叶子端点：设 $a,b$ 是两个度 $\ge2$ 的点，则 $a$ 的所有邻居都是叶子、$b$ 的所有邻居都是叶子，$a,b$ 不相邻且无法连通，矛盾），所以 $|C|\ge 2$。由引理 3，只需给出 $C$ 的至少 $4$ 种染色，使每个 $b\in B$ 在 $C$ 内有异色邻居。

- **情形 1：$B=\varnothing$。** $C$ 的任意染色都满足要求，故共 $2^{|C|}\ge 4$ 种。
- **情形 2：$B\ne\varnothing$。** 取 $b\in B$，则 $\deg b\ge 2$ 且 $N(b)\subseteq C$，故 $|C|\ge 3$。
  - **(a) $G[C]$ 不连通。** 每个分量独立选色。含 $B$ 中点的分量没有孤立点（$B$ 中点在该分量内度 $\ge 1$），由引理 2 至少 $2$ 种；不含 $B$ 中点的分量无约束，可任染，至少 $2$ 种。分量数 $\ge2$，故总方案数 $\ge 4$。以下设 $G[C]$ 连通。
  - **(b) $G[C]$ 是二分图**，划分为 $X,Y$。任取一条边 $(p,q)$，$p\in X,\ q\in Y$。构造染色：$X\setminus\{p\}$ 染 $0$，$p$ 染 $1$；$Y\setminus\{q\}$ 染 $1$，$q$ 染 $0$（即"只翻转 $p,q$"）。逐类检查 $B$ 中的点：
    - $p\in B$：颜色 $1$，邻居都在 $Y$，其中 $q$ 是颜色 $0$ ⇒ 有异色邻居；
    - $q\in B$：颜色 $0$，邻居 $p$ 是颜色 $1$ ⇒ 同上；
    - $x\in X\setminus\{p\}$ 且 $x\in B$：颜色 $0$，需要 $N(x)$ 中有颜色 $1$ 的点，即 $N(x)\setminus\{q\}\ne\varnothing$；由 $\deg x\ge2$ 成立；
    - $y\in Y\setminus\{q\}$ 且 $y\in B$：颜色 $1$，需要 $N(y)\setminus\{p\}\ne\varnothing$；由 $\deg y\ge2$ 成立。

    故该染色合法；它的反色也合法。又因 $|C|\ge3$，$|X|,|Y|$ 中至少有一个含 $\ge2$ 个点，所以"只翻转 $p,q$"的染色及其反色都不会退化成二分染色，于是 $f(G)\ge 4$。
  - **(c) $G[C]$ 不是二分图。** 取其中最短的奇环 $Z=p_0p_1\cdots p_{m-1}p_0$（$m\ge3$ 为奇数）。$Z$ 上至少有 $4$ 种合法染色：令 $c(p_i)=i\bmod 2$（只有闭合边 $p_0p_{m-1}$ 单色，每个环点仍有异色邻居），再单独把 $p_0$ 翻色（此时 $p_0$ 靠 $p_{m-1}$、$p_1$ 靠 $p_2$、$p_{m-1}$ 靠 $p_{m-2}$ 得到异色邻居，其余点不变），这两种染色连同各自的反色共 $4$ 种且互不相同。对 $Z$ 的每种合法染色沿"以 $Z$ 为根的最短路树"向外延拓：对每个 $x\notin Z$，取树上父节点 $p(x)$，令 $c(x)=\overline{c(p(x))}$，则每个 $x\notin Z$ 都有异色的父节点，$Z$ 上的点由环上的边保证。不同染色限制在 $Z$ 上不同，故延拓后仍互不相同，于是 $f(G)\ge4$。∎

**定理**：算法的输出与真实方案数一致。

**证明**：若存在孤立点，由引理 2 的推论方案数为 $0$，算法输出 `Brain Melt`。否则每个分量至少贡献 $2$ 种，而"每个点有异色邻居"只涉及同一分量内的边，故方案数等于各分量方案数之**积**。由引理 4，乘积等于 $2$ 当且仅当只有一个分量且该分量是星形图，即整张图是星形图，等价于 $m=n-1$ 且 $\max\deg=n-1$（充分性见 §3.3），此时算法输出 `2`；其余情况乘积 $\ge 2\cdot 2=4$，由引理 1 为偶数故 $>2$，算法输出 `Many`。三种情形与判定完全对应。∎

## 6. 复杂度分析

- **时间**：每组读入 $m$ 条边并累加度数 $O(n+m)$，统计最值 $O(n)$；总计 $O(\sum n+\sum m)\le 6\times10^5$ 次基本操作，常数极小。
- **空间**：只需一个长度 $n+1$ 的度数数组，$O(n)$；不建邻接表，总计不超过 $3\times10^5$ 个 `int`。
- **对照时限**：$2$ s 的时限下，C++ 在本机最大数据（$n=3\times10^5$、$m=3\times10^5$，含 $10^4$ 组多测的情形）实测约 $0.4\sim0.8$ s（含 $4$ MB 输入解析），仍有 $2$ 倍以上余量；Python3 用 `sys.stdin.buffer.read()` 实测 $0.15\sim0.2$ s，同样安全。

## 7. 参考代码

### C++17

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int t;
    if (!(cin >> t)) return 0;
    while (t--) {
        int n, m;
        cin >> n >> m;
        vector<int> deg(n + 1, 0);
        for (int i = 0; i < m; i++) {
            int u, v;
            cin >> u >> v;
            deg[u]++; deg[v]++;
        }
        int mn = INT_MAX, mx = 0;
        for (int v = 1; v <= n; v++) { mn = min(mn, deg[v]); mx = max(mx, deg[v]); }
        if (mn == 0)                              cout << "Brain Melt\n";  // 有孤立点
        else if (m == n - 1 && mx == n - 1)       cout << "2\n";           // 整张图是星形图
        else                                     cout << "Many\n";        // 至少 4 种
    }
    return 0;
}
```

### Python3

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    t = int(data[0])
    pos = 1
    out = []
    for _ in range(t):
        n = int(data[pos]); m = int(data[pos + 1]); pos += 2
        deg = [0] * (n + 1)
        for _ in range(m):
            u = int(data[pos]); v = int(data[pos + 1]); pos += 2
            deg[u] += 1
            deg[v] += 1
        mn = min(deg[1:])
        mx = max(deg[1:])
        if mn == 0:
            out.append("Brain Melt")
        elif m == n - 1 and mx == n - 1:
            out.append("2")
        else:
            out.append("Many")
    sys.stdout.write("\n".join(out) + "\n")

main()
```

## 8. 边界情况与易错点

1. **孤立点优先判**：$m=0$ 或 $m$ 很小时必然有孤立点，此时答案是 `Brain Melt` 而**不是** `2`；例如 $n=5$、边只有 $1-2,3-4$ 时点 $5$ 孤立，虽然 $m=4=n-1$，答案仍是 `Brain Melt`。
2. **星形判据必须带 $m=n-1$**：$K_3$ 的每个点度数都是 $n-1=2$，只判 $\max\deg$ 会错误输出 `2`；实际三角形有 $6$ 种。
3. **「树」不等于「星形」**：$n\ge4$ 的路径、双星图、毛毛虫都是树但都有至少 $4$ 种合法染色（路径 $1-2-3-4$ 就是官方第 4 组样例）。
4. **$n=3$ 的三种小图**：单边 ⇒ `Brain Melt`；$P_3$ ⇒ `2`；三角形 ⇒ `Many`。可以用它们自测。
5. **输出字符串**：`Brain Melt` 中间有一个空格、两个单词首字母大写；`Many` 首字母大写；有的实现会误写成 `BrainMelt` / `many` 导致全错。
6. **多测污染**：`deg` 必须每组重建或清零，否则上一组的大度数会残留，破坏 `mx` 与 `mn`。
7. **不要试图输出 $1$**：由引理 1，方案数恒为偶数，$\{1\}$ 这一分支永远不会触发，写上去是死代码。
8. **性能**：$\sum n,\sum m$ 都是 $3\times10^5$，逐行 `input()` 的 Python 在 $10^4$ 组多测下可能偏慢，务必整体读入；C++ 务必关闭同步流。
9. **下标**：顶点编号 $1\cdots n$，`deg` 开 $n+1$，统计最值时从 $1$ 开始扫，避免把 `deg[0]` 的 $0$ 当成孤立点。

**延伸思考**：

1. 把条件换成"每个点**恰好**有一个异色邻居"，问题立刻变难：那是在数图的完美支配划分，一般图上是计数困难问题，不再是 $O(n+m)$ 的分类讨论。
2. 若条件改成"每个点至少有 $k$ 个异色邻居"，答案还会只依赖度数吗？小数据上试试 $k=2$：此时叶子必然不合法，$n\ge3$ 且含叶子就直接 `Brain Melt`，可见判据会更复杂，值得用暴力对拍找规律。
3. 本题最值得记住的套路：**先找对称性（反色），再找被强制的局部结构（叶子），最后只剩下一个极端情形（星形）需要单独刻画**。这种"三步走"在计数类构造题里非常常见。
