# Codeforces 湖畔小径（困难版） 题解

## 1. 题目概述

- **标题 / 题号**：湖畔小径（困难版）（Codeforces 2290G2，英文名 Lakeside Trail (Hard Version)）
- **链接**：https://codeforces.com/problemset/problem/2290/G2
- **来源**：Codeforces Round 1134 (Div. 4) · Problem G2
- **难度**：未评级（Div. 4 压轴题组，官方暂无 rating；与 G1 只差数据范围）
- **限制**：时间 4 s / 内存 256 MB
- **标签**：二分查找、动态规划、贪心、数学

**题意**：环形步道分成 $n$ 段，第 $i$ 段高 $h_i$，相邻关系按环取（第 $n$ 段与第 $1$ 段也相邻）。陡峭度是所有相邻高度差绝对值的最大值：

$$S=\max_{1\le i\le n}\lvert h_i-h_{i+1}\rvert,\qquad h_{n+1}=h_1 .$$

你手上有 $k$ 单位土，一单位土把某一段抬高 $1$（可叠加），土不能拿走，高度**只增不减**。求用完**不超过** $k$ 单位土后陡峭度的最小值。多测，每组输出一行。

**约束**：

- $1\le t\le 10^4$，$3\le n\le 10^6$，$\sum n\le 10^6$；
- $0\le k\le 10^{18}$，$1\le h_i\le 10^9$；
- 困难版把 $n,\sum n,t$ 全部拉满：答案值域 $\le10^9$ 只容得下 $\log$ 轮，每轮判定必须是纯 $O(n)$ 双扫描（约 $3\times10^7$ 次基本运算），任何带 $\log$ 或大常数的判定都会超时。

## 2. 示例

```text
输入
6
4 3
1 5 2 8
5 5
2 9 4 1 6
3 0
1 4 7
3 100
1 10 1
5 5
4 1 1 1 1
6 14
3 6 2 4 1 5

输出
5
4
6
0
2
1
```

第 1 组最优高度 $(3,5,3,8)$，用土 $2+0+1+0=3\le k$，得 $5$；第 2 组抬成 $(5,9,5,2,6)$，用土 $5$，得 $4$；第 3 组 $k=0$ 不能动土，$h_3$ 与 $h_1$ 相邻，答案为 $\lvert 7-1\rvert=6$；第 4 组把三段都抬到 $10$ 只用 $18$ 单位土，陡峭度可到 $0$；第 5 组抬成 $(4,2,1,1,2)$ 用土 $2$，得 $2$；第 6 组 $X=1$ 的最省方案 $(5,6,5,4,4,5)$ 用土 $8\le14$，而 $X=0$ 要把全部抬到 $6$ 需 $15$ 单位，故得 $1$。

## 3. 解题思路

### 3.1 暴力思路

自然的框架是「二分答案 $X$，判定能否用 $\le k$ 单位土把相邻差压到 $X$ 内」，难点全在判定：枚举最终高度向量是 $10^{9n}$ 量级；对高度做 DP 的状态值域又是 $10^9$，都不可行。常见贪心雏形是从最高段出发做 $a_{i+1}=\max(h_{i+1},a_i-X)$，在线段上它正确，但在**环**上会漏掉收口边：样例 1 取 $X=4$，从 $h_4=8$ 向右扫得 $(4,5,2,8)$，用土 $3\le k$ 看着能过，可收口边 $\lvert a_3-a_4\rvert=\lvert 2-8\rvert=6>4$，解是假的。根因是一个方向只累加了「沿这个方向」的下界，而环上每一对 $(i,j)$ 有**两条弧**。

### 3.2 核心观察：锥形下界包络

![环上的锥形下界与包络](images/cf2290_g2_cone_envelope.svg)

固定 $X$，记 $d(i,j)=\min(\lvert i-j\rvert,\ n-\lvert i-j\rvert)$ 为环上最短弧长。沿最短弧从 $j$ 走到 $i$ 共 $d(i,j)$ 步，每步高度最多降 $X$，而起点 $a_j\ge h_j$，故

$$a_i\;\ge\;h_j-X\cdot d(i,j)\quad(\forall i,j)\qquad\Longrightarrow\qquad a_i\;\ge\;E_i:=\max_{1\le j\le n}\bigl(h_j-X\cdot d(i,j)\bigr).$$

关键点：**取这族下界的逐点最大值得到的 $E$ 本身就是可行解**——对任意 $j$，锥在相邻两格上的取值只差一个 $X$，所以 $\lvert E_i-E_{i+1}\rvert\le X$；又 $E_i\ge h_i$（取 $j=i$）。既然它逐点最小，缺口之和就是最少用土量：

$$\text{needed}(X)=\sum_{i=1}^{n}\bigl(E_i-h_i\bigr).$$

于是判定退化成「算一个 max-plus 包络再求和」。注意 $d$ 是**两条弧取短**，每对 $(i,j)$ 的两个方向都得算——这正是 3.1 里单向贪心翻车的地方。

### 3.3 算法流程

![判定流程：二分 + 周期延拓 + 双扫描](images/cf2290_g2_check_flow.svg)

1. **二分** $X\in[\text{lo},\text{hi}]$：$\text{hi}$ 取初始陡峭度（用 $0$ 单位土一定可行），$\text{lo}=-1$ 作不可行哨兵，循环写 `hi - lo > 1`，收敛后输出 $\text{hi}$。
2. **延拓**：把 $h$ 周期延拓成长度 $3n$ 的数组 $b_t=h_{t\bmod n}$（$t=0\sim3n-1$）。
3. **正扫**：$\text{pre}[j]=\max\bigl(\text{pre}[j-1],\ b_j+X\cdot j\bigr)$，$j=0\sim2n-1$。
4. **逆扫**：维护 $\text{suf}=\max(\text{suf},b_i-X\cdot i)$，$i$ 从 $3n-1$ 降到 $n$；对 $i\in[n,2n)$ 取 $E_i=\max\bigl(\text{pre}[i]-X\cdot i,\ \text{suf}+X\cdot i\bigr)$。
5. **累加** $\text{cost}\mathrel{+}=E_i-b_i$，一旦 $\text{cost}>k$ 立刻返回 `false`；二分结束输出 $\text{hi}$。

为什么是 $3n$、为什么 $i\in[n,2n)$：$\text{pre}$ 覆盖所有下标 $\le i$ 的副本，$\text{suf}$ 覆盖所有 $\ge i$ 的副本；$i$ 落在中间那份时左右各有 $n$ 个副本，足以覆盖「绕另一侧的短弧」。更远的副本都被同一剩余类中更近的副本支配，多算不会出错。

### 3.4 示例演算

![样例 1 走查](images/cf2290_g2_walkthrough.svg)

样例 1（$n=4$，$k=3$，$h=(1,5,2,8)$）：

| $X$ | $E=(E_1,E_2,E_3,E_4)$ | 用土 | 结论 |
|-----|----------------------|------|------|
| $5$ | $(3,5,3,8)$ | $2+0+1+0=3$ | $3\le k$ 可行 |
| $4$ | $(4,5,4,8)$ | $3+0+2+0=5$ | $5>k$ 不可行 |

$X=5$ 时 $E_1=E_3=8-5=3$，全部由 $h_4=8$ 绕一步的锥给出；$X=4$ 时 $E_1=4$、$E_3=5-4=4$，土立刻涨到 $5$。二分单调收缩后答案 $=5$，与官方输出一致。

## 4. 算法细节

1. **二分两端**：$\text{hi}$ 用初始陡峭度（$\text{cost}=0$ 必可行），$\text{lo}=-1$ 当哨兵，这样 $X=0$ 不用特判；`hi - lo > 1` 收敛后直接输出 $\text{hi}$。
2. **64 位整数**：$X\cdot j$ 最大约 $10^9\times3\times10^6=3\times10^{15}$，$\text{cost}$ 最大约 $10^6\times10^9=10^{15}$，全部用 `long long`；用 `LLONG_MIN/4` 当负无穷，避免减法下溢。
3. **提前剪枝**：$\text{cost}>k$ 立即 `return false`，$k$ 小的数据能把每轮扫描截断到极短，是稳过 4 s 的关键之一。
4. **延拓下标**：$\text{pre}$ 只算到 $2n-1$（因 $i<2n$），但 `b` 必须开到 $3n$，否则 $i$ 接近 $2n$ 时「右侧 $n$ 个副本」会越界，包络被低估。
5. **多测**：`b`、`pre` 按当前 $n$ 重新 `resize`，判定覆盖的区间固定为 $[0,2n)$ 与 $[n,3n)$，不会残留旧值；总 $\sum n\le10^6$，整体 $O(\sum n\log V)$。
6. **I/O 与精度**：输入可达 $10^6$ 个整数，`scanf/printf` 比某些标准库的 `cin` 快数倍（用 `cin` 务必 `ios::sync_with_stdio(false)`）；判定只有加、减、乘、比较，不用除法也不用浮点，没有精度问题。

## 5. 正确性证明

**引理 1（下界）**：设 $a$ 满足 $\lvert a_i-a_{i+1}\rvert\le X$ 且 $a_i\ge h_i$，则对一切 $i,j$ 有 $a_i\ge h_j-X\cdot d(i,j)$。
**证明**：沿 $j$ 到 $i$ 的最短弧取 $j=v_0,v_1,\dots,v_L=i$，$L=d(i,j)$。每步差 $\le X$，故 $a_i\ge a_j-XL\ge h_j-X\cdot d(i,j)$。∎

**引理 2（包络合法且最小）**：$E_i=\max_j\bigl(h_j-X\cdot d(i,j)\bigr)$ 满足 $E_i\ge h_i$、$\lvert E_i-E_{i+1}\rvert\le X$，且对任意可行 $a$ 有 $E_i\le a_i$。
**证明**：取 $j=i$ 得 $E_i\ge h_i$。由三角不等式 $d(i,j)\ge d(i+1,j)-1$，对任意 $j$ 有 $h_j-X\cdot d(i,j)\le h_j-X\cdot d(i+1,j)+X\le E_{i+1}+X$；对 $j$ 取 $\max$ 得 $E_i\le E_{i+1}+X$，交换 $i,i+1$ 得另一侧，故 $\lvert E_i-E_{i+1}\rvert\le X$。再由引理 1，$E_i$ 是「任何可行解都必有的下界」的最大值，故 $E_i\le a_i$。∎

**定理**：给定 $X$，用至多 $k$ 单位土能让陡峭度 $\le X$，当且仅当 $\sum_i(E_i-h_i)\le k$。
**证明**：由引理 2，$E$ 可行且用土恰为 $\sum(E_i-h_i)$，充分性成立；任意可行 $a$ 满足 $a_i\ge E_i$，故用土 $\ge\sum(E_i-h_i)$，必要性成立。∎

**引理 3（单调性）**：$X$ 可行则 $X+1$ 可行，且 $\text{needed}(X+1)\le\text{needed}(X)$。
**证明**：同一个 $a$ 满足 $\lvert a_i-a_{i+1}\rvert\le X<X+1$；每个锥的斜率绝对值变小，故 $E^{(X+1)}_i\le E^{(X)}_i$，求和即得。∎

**引理 4（$3n$ 延拓正确）**：对 $i\in[n,2n)$，由长度 $3n$ 的 $b$、$\text{pre}$、$\text{suf}$ 算出的 $\max\bigl(\text{pre}[i]-Xi,\ \text{suf}+Xi\bigr)$ 恰为 $E_i$。
**证明**：两式合并即 $\max_{0\le t<3n}\bigl(b_t-X\lvert i-t\rvert\bigr)$。对每个剩余类 $r$，最近副本落在 $[i-n,i+n]\subseteq[0,3n)$ 内（因 $n\le i<2n$），此处线性距离恰为 $d(i,r)$；更远的副本线性距离更大、贡献更小，不影响最大值。∎

## 6. 复杂度分析

- **时间**：单次判定两遍扫描共约 $5n$ 次整数运算，$O(n)$；二分轮数 $\lceil\log_2(10^9+1)\rceil=30$，总 $O(n\log V)$。$\sum n=10^6$ 时约 $3\times10^7$ 次基本运算，实测最大数据 $0.22$ s（4 s 限制的 18 倍余量）。
- **空间**：$b$ 占 $3n$、$\text{pre}$ 占 $2n$ 个 `long long`，加上 $h$，$n=10^6$ 时峰值约 $50$ MB，远低于 256 MB。
- **Python**：同算法常数大，$n=10^6$ 实测约 $17$ s，必然超时；下文 Python 代码用于理解算法与小数据对拍，正式提交请用 C++。

## 7. 参考代码

### C++17

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int T;
    if (scanf("%d", &T) != 1) return 0;

    vector<long long> h, b, pre;
    while (T--) {
        int n; long long k;
        scanf("%d %lld", &n, &k);
        h.resize(n);
        long long maxAdj = 0;
        for (int i = 0; i < n; ++i) {
            scanf("%lld", &h[i]);
            if (i > 0) maxAdj = max(maxAdj, llabs(h[i] - h[i - 1]));
        }
        maxAdj = max(maxAdj, llabs(h[0] - h[n - 1]));

        b.resize(3 * n);                        // 周期延拓：b[t] = h[t mod n]
        for (int t = 0; t < 3 * n; ++t) b[t] = h[t % n];
        pre.resize(2 * n);
        auto feasible = [&](long long X) -> bool {
            long long best = LLONG_MIN / 4;
            for (int j = 0; j < 2 * n; ++j) {           // 正扫：左边来的锥
                long long v = b[j] + X * 1LL * j;
                if (v > best) best = v;
                pre[j] = best;
            }
            long long suf = LLONG_MIN / 4, cost = 0;
            for (int i = 3 * n - 1; i >= n; --i) {      // 逆扫：右边来的锥
                long long v = b[i] - X * 1LL * i;
                if (v > suf) suf = v;
                if (i < 2 * n) {
                    long long a = max(pre[i] - X * 1LL * i, suf + X * 1LL * i);
                    cost += a - b[i];
                    if (cost > k) return false;         // 剪枝
                }
            }
            return true;
        };

        long long lo = -1, hi = maxAdj;                 // lo：不可行哨兵
        while (hi - lo > 1) {
            long long mid = lo + (hi - lo) / 2;
            if (feasible(mid)) hi = mid; else lo = mid;
        }
        printf("%lld\n", hi);
    }
    return 0;
}
```

### Python3

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    pos = 0
    t = int(data[pos]); pos += 1
    out = []
    for _ in range(t):
        n = int(data[pos]); k = int(data[pos + 1]); pos += 2
        h = list(map(int, data[pos:pos + n])); pos += n

        hi = 0
        for i in range(n):
            d = abs(h[i] - h[(i + 1) % n])
            if d > hi: hi = d

        arr = h + h + h               # 周期延拓，长度 3n
        pre = [0] * (2 * n)
        def feasible(X):
            best = -1 << 62
            for j in range(2 * n):                  # 正扫
                v = arr[j] + X * j
                if v > best: best = v
                pre[j] = best
            suf = -1 << 62
            cost = 0
            for i in range(3 * n - 1, n - 1, -1):   # 逆扫
                v = arr[i] - X * i
                if v > suf: suf = v
                if i < 2 * n:
                    a = pre[i] - X * i
                    b = suf + X * i
                    if b > a: a = b
                    if a > arr[i]:
                        cost += a - arr[i]
                        if cost > k: return False
            return True

        lo = -1
        while hi - lo > 1:
            mid = (lo + hi) // 2
            if feasible(mid): hi = mid
            else: lo = mid
        out.append(str(hi))
    sys.stdout.write("\n".join(out) + "\n")

main()
```

## 8. 边界情况与易错点

1. **单向贪心会漏弧**：只从最高点沿一个方向扫，等价于只算一侧的锥。样例 1、$X=4$ 时它给出用土 $3\le k$ 的假解，而收口边 $\lvert 2-8\rvert=6>4$。凡是「环 + 相邻差」的题都要盯住收口边。
2. **$n$ 为偶数时的等长弧**：$n=4$ 时 $d(1,3)=2$ 两条弧一样长，取短无歧义；但用「只算 $\min$ 一侧」的写法容易漏掉 $\lvert i-j\rvert=n/2$ 的那次，用 $\max$ 直接合并两类锥最安全。
3. **$k=0$ 与全相等**：$k=0$ 时答案必须等于初始陡峭度，所以 $\text{hi}$ 要先 $O(n)$ 求出来；若所有 $h_i$ 相等，$\text{hi}=0$、$\text{lo}=-1$，循环一次都不进，直接输出 $0$。
4. **溢出**：$X\cdot j$ 是 $3\times10^{15}$ 量级、$\text{cost}$ 是 $10^{15}$ 量级，`int` 必溢出；用 `long long` 或 Python 大整数。
5. **$3n$ 数组越界**：`b` 只开 $2n$ 会让逆扫段取不到「右侧副本」，包络被低估；`pre` 开 $2n$ 即可，但下标上界必须写对。
6. **多测复用容器与下标**：`cost`、`suf`、`best` 必须是每轮重新初始化的局部变量，`b` 要在 `resize` 后完整重写；$3n$ 数组里 $i\in[n,2n)$ 对应原始下标 $i-n$（`b[i]` 本身就是 $h_{i\bmod n}$）；「不超过 $k$」是 $\text{cost}\le k$，不是 $<k$。

**延伸思考**：

1. **只增 vs 可增可减**：本题的关键在「只增」，它让最优解唯一地等于上包络 $U_i=\max_j(h_j-X\cdot d)$。「只减」把 $h_i$ 换成 $-h_i$ 即完全对称；若两者都允许，最优 $a$ 会被夹在 $U_i$ 与下包络 $L_i=\min_j(h_j+X\cdot d)$ 之间，还要在 $k$ 约束下决定每个位置填多满，变成另一类分配问题。
2. **多组 $k$ 询问与大 $k$ 短路**：由引理 3，$\text{needed}(X)$ 单调不增，且每个 $\max_j(h_j-X\cdot d(i,j))$ 都是仿射函数之$\max$，故它是凸的分段线性函数，多组询问可排序后共用同一条二分链。另外当 $k\ge\sum_i(\max_j h_j-h_i)$ 时答案必为 $0$（该和可达 $10^{15}$，用 `long long`），可在 $k=10^{18}$ 的数据上直接短路。
