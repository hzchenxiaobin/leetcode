# Codeforces 书架上的书 题解

## 1. 题目概述

- **标题 / 题号**：书架上的书（Codeforces 2290C，英文名 Books on a Shelf）
- **链接**：https://codeforces.com/problemset/problem/2290/C
- **来源**：Codeforces Round 1134 (Div. 4) · Problem C
- **难度**：未评级（Div. 4 的 C 题，官方 rating 尚未公布）
- **限制**：时间 2 s / 内存 256 MB
- **标签**：构造、贪心、排序、计数

**题意**：有 $n$ 本书排成一行，第 $i$ 本高度为 $h_i$，顺序可以任意重排。若一本书严格高于它左边的所有书，称它**从左可见**（即它是前缀严格最大值）；严格高于右边所有书则称**从右可见**（后缀严格最大值）。最左一本一定从左可见，最右一本一定从右可见。

要求输出两行：第一行是「至少从一侧可见」的书的最大数量 $k$，第二行是任意一个达到 $k$ 的排列（$n$ 个高度，必须是原多重集的一个排列）。多测：首行 $t$，每组给出 $n$ 与 $h_1,\dots,h_n$。

**约束**：

- $1 \le t \le 10^4$，$1 \le n \le 2\cdot 10^5$，$\sum n \le 2\cdot 10^5$ —— 总和受限，允许**每组独立排序**
- $1 \le h_i \le 10^9$ —— 值域大但只有相对大小有意义，且**高度可以重复**（重复是本题唯一的难点）
- 输出的是**高度**的一个排列（不是下标），且 checker 接受任意最优排列；只需 $O(n)$ 的数组

## 3. 解题思路

### 3.1 暴力思路

枚举全部 $n!$ 种排列，每种线性扫描统计可见数：$O(n\cdot n!)$。$n = 2\cdot10^5$ 时完全不可行；即便只对 $n \le 7$ 全排列暴力，也仅能用来**找规律**。把 $n \le 7$、高度取值 $1\sim3$ 的全部多重集枚举一遍会发现一个干净的事实：答案只取决于**每种高度出现了几次**，与具体数值无关。

### 3.2 核心观察：两侧各是一条严格单调链

![可见结构：升序左链 + 顶点 + 降序右链](images/cf2290_c_two_chains_concept.svg)

从左往右扫描时，「可见」意味着刷新前缀最大值，所以：

- 从左可见的书，高度沿位置**严格递增**；从右可见的书，高度沿位置**严格递减**（等价于从右往左看严格递增）。

于是**同一种高度在同一侧最多出现 1 本**：设高度 $v$ 出现 $cnt_v$ 次，它在左侧至多 1 本可见、右侧至多 1 本可见，而书总共只有 $cnt_v$ 本，故至多贡献 $\min(cnt_v,2)$ 本。对所有不同高度求和，立刻得到本题的**上界**：

$$k \le \sum_{v} \min(cnt_v,\,2)$$

两个极端可以自检：全部高度互不相同时 $cnt_v=1$，上界为 $n$（升序排列即可全部可见）；全部高度相同时 $cnt_v=n$，上界为 $2$，正好是「最左 + 最右」，与样例 3 的答案 2 吻合。

> ⚠️ 常见错误的上界是 $\min(n,\,2m-1)$（$m$ 为不同高度个数）或 $\min(n,2m)$。它们在全相同（$m=1$）时会给出 1 或 2 的摇摆结果，在 $n$ 本书中有大量三元重复时也会偏大——记住 **$k$ 只由 $\min(cnt_v,2)$ 决定**。

### 3.3 构造：升序左链 + 降序剩余副本

![构造流程：排序分块 → 升序左链 → 降序剩余副本](images/cf2290_c_construct_flow.svg)

上界是可以达到的，构造极简。设不同高度从小到大为 $v_1 < v_2 < \dots < v_m$，其中 $v_m$ 是最大值，$cnt_j = $ 高度 $v_j$ 的出现次数。

1. **排序分块**：把 $h$ 升序排序，同高度元素自然成为连续的一段。
2. **统计**：$k \leftarrow \sum_j \min(cnt_j, 2)$。
3. **第一段（左链）**：每个高度取 **1 本**，按高度升序输出，共 $m$ 本。每一本都比左边所有书高，因此全部从左可见。
4. **第二段（右链）**：按 $v = v_m, v_{m-1}, \dots, v_1$ 的顺序，把该高度**剩下的 $cnt_j - 1$ 本**紧接在末尾。
   - 块内前 $cnt_j-2$ 本左右两侧都有同高度的书，两侧都看不见；块的最后 1 本右侧全是更矮的书（块按高度降序），故从右可见。
5. **输出**：先输出 $k$，再输出拼好的排列（$m + \sum_j (cnt_j-1) = n$ 个，长度必然正确）。

可见书总数 $= m + \#\{v : cnt_v \ge 2\}$，而这恰好等于 $\sum_v \min(cnt_v,2)$：出现 1 次的高度各贡献 1、出现 $\ge 2$ 次的高度各贡献 2。所以构造**达到上界**，上界即答案。

### 3.4 示例演算

![样例 1 走查：1 2 2 3 3 3 → k = 5](images/cf2290_c_walkthrough_sample1.svg)

以样例 1 的 $h = [1,2,2,3,3,3]$ 为例：$cnt_1=1,\ cnt_2=2,\ cnt_3=3$，故 $k = 1+2+2 = 5$。排序后第一段取每个高度 1 本 → `1 2 3`；第二段补剩余副本（按高度降序）→ `3 3 2`；拼接得 `1 2 3 3 3 2`。上图的走查表逐位标出了两侧可见性：位置 1、2、3 从左可见，位置 5、6 从右可见，共 5 个 ✓，等于 $k$。

注意位置 4 的 `3`：左边有 `3`、右边也有 `3`，两侧都不可见——这正是「$cnt_3 = 3$ 只能贡献 2 本」的直观体现。

## 4. 算法细节

1. **排序 + 双指针分段**，不要用 `map` / `unordered_map` 统计频次：$t = 10^4$ 时哈希表常数开销大，而排序天然把同高度聚成一段，扫一遍即得所有 $cnt_j$。
2. **$k$ 用 `int`**：$k = \sum \min(cnt_v,2) \le \sum cnt_v = n \le 2\cdot10^5$，不会溢出，也永远不需要和 $n$ 取 min（上界本身就不超过 $n$）。
3. **第一段的判定**：排序后满足 `i == 0 || h[i] != h[i-1]` 的位置就是「每种高度的第一本」，直接顺序输出即可，无需额外存储分组信息。
4. **第二段的实现**：从右往左找连续同高度段 $[j, i]$，输出该段除最左一本（`h[j]`，已在第一段用过）以外的所有元素；因为是从最大的高度往小处理，块的顺序自动是降序。
5. **输出量控制**：总输出 $O(\sum n)$ 个整数（$\le 2\cdot10^5$ 个），`std::ios::sync_with_stdio(false)` 后 `cout` 足够；每行末尾换行、同行用单个空格分隔。
6. **不要模拟「移动书本」**：真的去交换、插入以制造可见性至少是 $O(n^2)$，本题只要**排序后拼接**，$O(n\log n)$；高度 $h_i \le 10^9 < 2^{31}$，`int` 足够，无需离散化、也无需 `long long`。

## 5. 正确性证明

**引理 1（单侧单调性）**：对任意排列，从左可见的书按位置高度严格递增；从右可见的书按位置高度严格递减。

**证明**：设 $i<j$ 且两本都从左可见。$j$ 从左可见意味着 $h_j$ 严格大于它左边的所有书，其中包含 $h_i$，故 $h_j > h_i$。右侧情形对称取 $i>j$ 即可。∎

**引理 2（上界）**：任意排列中，可见书数量不超过 $\sum_v \min(cnt_v,2)$。

**证明**：可见集合 $= L \cup R$（$L$ 为从左可见位置集，$R$ 为从右可见位置集）。由引理 1，$L$ 中高度两两不同，故高度 $v$ 在 $L$ 中至多 1 个位置；同理在 $R$ 中至多 1 个位置。而高度 $v$ 的书总共只有 $cnt_v$ 本，故高度 $v$ 的可见书不超过 $\min(cnt_v, 2)$。对全部不同高度求和即得上界。∎

**引理 3（构造达到上界）**：§3.3 的排列中可见书数量不少于 $m + \#\{v: cnt_v \ge 2\} = \sum_v \min(cnt_v,2)$。

**证明**：分两部分显式指出可见书，且两部分位置不相交（前者是前 $m$ 个位置，后者在其后）。其一，第一段第 $j$ 本高度为 $v_j$，严格大于 $v_1,\dots,v_{j-1}$，是从左可见的，共 $m$ 本。其二，对每个 $cnt_v \ge 2$ 的块，块尾那本右侧的书全部来自更小的块（或右侧没有书），高度都 $< v$，故它从右可见；而块内位于它之前的副本左侧有同高度、右侧有同高度块尾，两侧都不可见，故每块**恰好**贡献 1 本可见书。最后验证计数等式：$cnt_v = 1$ 的高度共 $m - \#\{v:cnt_v\ge2\}$ 种、各贡献 1，$cnt_v \ge 2$ 的每种贡献 2，于是 $m + \#\{v:cnt_v\ge2\} = \sum_v \min(cnt_v,2)$。∎

**定理**：本题答案是 $k = \sum_v \min(cnt_v,2)$，且 §3.3 的构造达到该值。

**证明**：引理 2 给出 $k \le \sum_v \min(cnt_v,2)$，引理 3 给出一个可见数 $\ge \sum_v \min(cnt_v,2)$ 的排列，两者夹逼即得等号成立，且该排列就是合法答案。∎

## 6. 复杂度分析

- **时间**：每组排序 $O(n\log n)$，扫描统计与拼接输出 $O(n)$，故单组 $O(n\log n)$，总计 $O\big(\sum n \log n\big)$。$\sum n \le 2\cdot10^5$ 时约 $3.6\times10^6$ 次比较量级，2 s 时限有大量余量（1 s 也够）。Python 的 `sorted` 是 C 实现，同样在时限内。
- **空间**：$O(n)$。存高度数组、输出数组各 $n$ 个 `int`（约 $1.6$ MB），远小于 256 MB；无递归、无哈希表。
- **实测**（Apple clang 21 -O2 / CPython 3.9.6，取 3 次最快）：$n=2\cdot10^5$ 全不同时 C++ $0.31$ s、Python $0.22$ s；$t=10^4$、每组 $n=20$ 时 C++ $0.17$ s、Python $0.15$ s；全相同数据 C++ $0.14$ s。均在 2 s 内，余量 $\ge 6\times$。

## 7. 参考代码

### C++17

```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int t;
    if (!(cin >> t)) return 0;
    while (t--) {
        int n;
        cin >> n;
        vector<int> h(n);
        for (int i = 0; i < n; i++) cin >> h[i];
        sort(h.begin(), h.end());

        // 统计答案 k = sum min(cnt_v, 2)：排序后同高度连续
        int k = 0;
        for (int i = 0; i < n;) {
            int j = i;
            while (j < n && h[j] == h[i]) j++;
            k += min(j - i, 2);
            i = j;
        }

        vector<int> out;
        out.reserve(n);
        // 第一段：每种高度各取 1 本，按高度升序
        for (int i = 0; i < n; i++)
            if (i == 0 || h[i] != h[i - 1]) out.push_back(h[i]);
        // 第二段：每种高度的剩余副本，按高度从大到小分块输出
        for (int i = n - 1; i >= 0;) {
            int j = i;
            while (j - 1 >= 0 && h[j - 1] == h[i]) j--;
            for (int p = j + 1; p <= i; p++) out.push_back(h[p]);
            i = j - 1;
        }

        cout << k << '\n';
        for (size_t p = 0; p < out.size(); p++) {
            if (p) cout << ' ';
            cout << out[p];
        }
        cout << '\n';
    }
    return 0;
}
```

### Python3

```python
import sys
from collections import Counter


def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    ptr = 0
    t = data[ptr]
    ptr += 1
    res = []
    for _ in range(t):
        n = data[ptr]
        ptr += 1
        h = data[ptr:ptr + n]
        ptr += n

        cnt = Counter(h)
        k = sum(min(c, 2) for c in cnt.values())

        out = []
        for v in sorted(cnt):                 # 第一段：每种高度 1 本，升序
            out.append(v)
        for v in sorted(cnt, reverse=True):   # 第二段：剩余副本，降序分块
            out.extend([v] * (cnt[v] - 1))

        res.append(str(k))
        res.append(' '.join(map(str, out)))
    sys.stdout.write('\n'.join(res) + '\n')


main()
```

## 8. 边界情况与易错点

1. **$n=1$**：$k = \min(1,2) = 1$，输出 `1` 与唯一高度；第二段为空，不要因为「剩余副本数 = 0」而漏输出第二行。
2. **全部高度相同 / 互不相同**：前者 $k=2$（$n\ge2$，任意排列都行，最容易错写成 1 或 $n$）；后者 $k=n$，构造退化为升序排列、第二段恰为空——「第二段为空」时仍要输出空行，不能少打一行。
3. **必须输出 $n$ 个数**：第二段长度恒为 $n-m$，若只输出了块尾一本（漏掉不可见的副本），排列就不是原多重集，checker 直接判 WA。
4. **多测不要复用脏数据**：每组重新 `vector<int> out`（或 `out.clear()`），并且 $k$ 每组重新置 0；本题容易在累加 $k$ 时忘记清零。
5. **答案公式唯一**：$k = \sum \min(cnt_v,2)$。不要用「不同高度数 $m$」拼公式（如 $2m-1$、$2m$），全相同或大量三重复的数据会立刻出错。
6. **高度值域 $10^9$**：无需离散化（排序即压缩），但也不要把「高度和」当答案而用 `long long` 去算本不需要的乘法。
7. **I/O 规模**：$t=10^4$ 且总输出 $2\cdot10^5$ 个整数，务必关闭 `cin` 同步或用整段读入（Python 用 `sys.stdin.buffer.read()`），否则容易被 I/O 拖慢到超时边缘。

1. 若把「至少一侧可见」改成「**两侧都可见**」，答案立刻变成 1（最大值唯一）或 0（最大值重复）——两侧都可见的书必须严格高于其余所有书。
