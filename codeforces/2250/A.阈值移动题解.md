# Codeforces 阈值移动 题解

## 1. 题目概述

- **标题 / 题号**：阈值移动（Codeforces 2250A，英文名 Threshold Movement）
- **链接**：https://codeforces.com/problemset/problem/2250/A
- **来源**：Codeforces Round 1112 (Div. 2) · Problem A
- **难度**：800（Div. 2 A，500 分）
- **限制**：时间 1 s / 内存 256 MB
- **标签**：暴力枚举，实现，数学

**题意**：一条直线有 $n+2$ 个位置 $0,1,\dots,n+1$，初始时位置 $1..n$ 各放一个重量为 $w_i$ 的元素，位置 $0$ 与 $n+1$ 为空。选定一个整数阈值 $k$ 后，**所有元素同时、且各恰好移动一次**：

- 若 $w_i<k$，位置 $i$ 的元素移到 $i-1$；
- 若 $w_i>k$，位置 $i$ 的元素移到 $i+1$；
- 若 $w_i=k$，整个移动过程立即失败。

称 $k$ 是**完美**的，当且仅当移动不失败、且结束后位置 $1..n$ 中每个位置**恰好**含有一个元素。判断完美整数是否存在，输出 `YES`/`NO`。多测：第一行 $t$，每组两行（先 $n$，再 $w_1..w_n$）。

**约束**：

- $1\le t\le 500$；$1\le n\le 100$；$1\le w_i\le 10^9$。
- $w_i$ 高达 $10^9$，因此**不能枚举 $k$**（候选阈值是 $10^9$ 量级）；$n$ 很小，$O(n)$ 或 $O(n^2)$ 都可以。
- 输出大小写任意；答案只有两种。

## 2. 示例

官方样例（6 组）：

```text
输入：
6
1
7
2
3 1
2
2 1
4
9 1 7 2
4
9 8 7 1
6
1000000000 1 9 2 8 3

输出：
NO
YES
NO
YES
NO
YES
```

- 第 1 组 $n=1$：唯一元素无论往哪走都会离开位置 1（$w_1=k$ 则直接失败），故 NO。
- 第 2 组 $k=2$：$3$ 右移、$1$ 左移，两个位置各得一个元素。
- 第 3 组两个元素要求 $1<k<2$，整数 $k$ 不存在。
- 第 4 组 $k=5$：位置 1、3 的元素右移，位置 2、4 的元素左移，$1..4$ 全被覆盖。
- 第 5 组位置 2 要左移（$k>8$），位置 3 要右移（$k<7$），两条要求打架。
- 第 6 组 $k=4$：奇数位全部右移、偶数位全部左移，$1..6$ 各被填一次。

补一组自造样例（★，覆盖"$n$ 为奇数恒失败"与"间隙只差 1"两种边界）：

```text
输入（★自造）：
3
2
5 4
4
10 8 10 8
3
5 1 5

输出（★自造）：
NO
YES
NO
```

- $[5,4]$：需 $4<k<5$，差 1 时没有整数 $k$；改成 $[10,8]$ 这样差 2 的才可行（第 2 组取 $k=9$）。
- $n=3$：元素 1 必须右移、元素 3 必须左移，两者同时挤进位置 2，位置 1 与 3 反而空着——$n$ 为奇数时无论怎么取 $k$ 都失败。

## 3. 解题思路

### 3.1 暴力思路

按定义枚举 $k$ 并模拟一遍移动：单次判定 $O(n)$，而 $k$ 的取值范围是 $[0,\max w+1]$，最坏 $10^9\cdot 100$ 次操作，直接不可行。退一步只在"关系切换点" $w_i-1,w_i,w_i+1$ 上试（至多 $3n$ 个候选），复杂度 $O(n^2)$，$t=500,n=100$ 也能通过——但这是在为结论打补丁：把"每个位置最终由谁填"写成方程后，所有约束都是线性的，答案根本不需要枚举。

### 3.2 核心观察：入度方程强制奇偶交替

记 $[P]$ 为示性函数。位置 $j\in[1,n]$ 终态收到的元素只可能来自两个邻居：

$$\text{cnt}(j)=[w_{j-1}<k]+[w_{j+1}>k],\qquad w_0,w_{n+1}\ \text{不存在}.$$

"完美"就是 $\text{cnt}(j)=1$ 对全部 $j$ 成立。把 $n$ 条方程相加：左端是总落点人数，右端按 $i$ 重新归并后等于 $n-[w_n<k]-[w_1>k]$（$n$ 即元素总数，$[w_n<k]$ 是"元素 $n$ 跑出右边界"、$[w_1>k]$ 是"元素 1 跑出左边界"）。要求左端 $=n$，于是

$$[w_1>k]=1,\qquad [w_n<k]=1,$$

即**元素 1 必右移、元素 $n$ 必左移**——直观说法是"位置 $0$ 与 $n+1$ 必须保持为空"。把它代回 $j=1$ 得 $[w_2<k]=1$；再代回 $j=2$ 得 $[w_3>k]=1$；如此向右滚动，得到

$$w_1,w_3,w_5,\dots>k,\qquad w_2,w_4,w_6,\dots<k.$$

![完美移动的等价结构：奇数位一律右移、偶数位一律左移](images/cf2250_a_movement_model.svg)

**$n$ 为奇数时立刻矛盾**：滚动链给出 $w_n>k$（$n$ 是奇数位），但元素 $n$ 本身必须左移，$w_n<k$。这也顺带解释了 $n=1$ 为何恒 NO。

$n$ 为偶数时结构自洽：奇数位右移落到偶数位、偶数位左移落到奇数位，$1..n$ 之间恰好配成 $n/2$ 对，位置 $0$ 与 $n+1$ 都收不到人。于是只剩"整数 $k$ 是否存在"一个问题：

$$\max\{w_2,w_4,\dots\}<k<\min\{w_1,w_3,\dots\}.$$

记 $mx$ 为偶数位权值最大值、$mn$ 为奇数位权值最小值，则答案为 YES 当且仅当区间 $(mx,mn)$ 内含整数，即 $mn-mx\ge 2$。

> 💡 **一句话记忆**：$n$ 必须是偶数，且"奇数位的最小值"比"偶数位的最大值"至少大 2。

### 3.3 算法流程

1. 读入 $n$ 与 $w_1..w_n$；若 $n$ 为奇数，输出 `NO`，本组结束。
2. 扫一遍求 $mn=\min(w_1,w_3,\dots)$、$mx=\max(w_2,w_4,\dots)$。
3. 输出 `YES` 当且仅当 $mn-mx\ge 2$。

![算法流程：奇数 n 直接 NO，否则只比较奇偶两组极值](images/cf2250_a_algorithm_flow.svg)

### 3.4 示例演算

样例 5（$n=4$，$w=[9,8,7,1]$）：位置 2 只能由元素 2 左移来填 ⇒ $k>8$；位置 3 只能由元素 3 右移来填 ⇒ $k<7$。用极值表述：$mn=\min(9,7)=7$、$mx=\max(8,1)=8$，$mn-mx=-1<2$ ⇒ NO，与官方一致。

样例 6（$n=6$，$w=[10^9,1,9,2,8,3]$）：$mn=\min(10^9,9,8)=8$、$mx=\max(1,2,3)=3$，$8-3=5\ge2$ ⇒ YES。取 $k=4$ 走查：

| 位置 $i$ | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| $w_i$ | $10^9$ | 1 | 9 | 2 | 8 | 3 |
| 与 $k=4$ 比较 | $>$ | $<$ | $>$ | $<$ | $>$ | $<$ |
| 落点 | 2 | 1 | 4 | 3 | 6 | 5 |

落点集合恰为 $\{1,\dots,6\}$，每个位置一次，$0$ 与 $7$ 为空，所以 $k=4$ 完美。

![样例 5 的区间为空、样例 6 的交替落点走查](images/cf2250_a_walkthrough.svg)

## 4. 算法细节

- **$n$ 为奇数必须先返回 NO**：这是结论而非剪枝。只算 $mn-mx$ 会在 $n=3,5,\dots$ 上误判，例如 $[5,1,5]$ 会得到 $mn-mx=4$ 而错误输出 YES。
- **奇偶下标要对齐题面**：题面位置是 $1$-indexed；C++ 用 `0`-indexed 存数组时，`i % 2 == 0` 对应题面的**奇数**位，`i % 2 == 1` 对应偶数位，写反会把答案整体翻转。
- **判定是 $\ge 2$ 不是 $\ge 1$**：$k$ 取整数且 $w_i=k$ 会失败，所以两端都是严格不等号；$mn-mx=1$ 时区间为 $(mx,mx+1)$，里面没有整数（样例 3 与自造样例 1 都是这种情况）。
- **数值范围**：$w_i\le10^9$，差值也在 $[-10^9,10^9]$，`int` 够用；但哨兵要写 `LLONG_MAX`、`LLONG_MIN`，用 `long long` 存权值更省心。Python 无溢出问题。
- **多测重置**：$mn$、$mx$ 必须在每组开头重新初始化；用全局变量只初始化一次是最常见的隐蔽 WA。
- **哨兵不会"空"**：走到求极值这一步时 $n$ 必为偶数且 $n\ge2$，两组都非空，不必额外判空；但若有人把 $n$ 奇数的分支删掉，就会出现 $mx$ 仍是 `LLONG_MIN` 的比较，得到错误 YES 而侥幸通过样例。
- **I/O**：$t\le500$、$\sum n\le5\cdot10^4$，`cin` 关同步足矣；C++ 用 `vector<long long>` 逐组读，Python 用 `sys.stdin.buffer.read().split()` 整块读 + 游标最稳。

## 5. 正确性证明

**引理 1（两端锁定）**：若 $k$ 完美，则 $w_1>k$ 且 $w_n<k$。

**证明**：$n$ 个元素最终全在 $1..n$ 内（每个位置恰好一个），故位置 $0$ 与 $n+1$ 终态为空。元素 1 只能去 $0$ 或 $2$，去 $0$ 就占了位置 $0$，所以只能右移，即 $w_1>k$（$w_1=k$ 时过程已失败）。同理元素 $n$ 只能去 $n-1$，即 $w_n<k$。∎

**引理 2（奇偶交替，且 $n$ 必为偶数）**：若 $k$ 完美，则一切奇数 $i$ 有 $w_i>k$、一切偶数 $i$ 有 $w_i<k$，且 $n$ 为偶数。

**证明**：位置 $j\in[1,n]$ 的入度为 $\text{cnt}(j)=[w_{j-1}<k]+[w_{j+1}>k]=1$，越界项按 $0$ 计。先看 $j=1$：$\text{cnt}(1)=[w_2<k]=1$，得 $w_2<k$。归纳地，设 $j$ 为偶数且已知 $w_{j-1}>k$，则 $\text{cnt}(j)=0+[w_{j+1}>k]=1$ 给出 $w_{j+1}>k$；设 $j$ 为奇数且已知 $w_{j-1}<k$，则 $\text{cnt}(j)=1+[w_{j+1}>k]=1$ 给出 $w_{j+1}<k$。起点 $w_1>k$ 由引理 1 提供，于是全部奇偶性得证。若 $n$ 为奇数，滚动链给出 $w_n>k$，与引理 1 的 $w_n<k$ 矛盾，故 $n$ 为偶数。∎

**引理 3（充分性）**：设 $n$ 为偶数且 $mn-mx\ge2$，取 $k=mx+1$，则 $k$ 完美。

**证明**：$k=mx+1>mx\ge$ 任一偶数位权值，故偶数位元素全部左移；$k=mx+1\le mn-1<mn\le$ 任一奇数位权值，故奇数位元素全部右移；没有元素权值等于 $k$，过程不失败。落点方面：奇数位 $i$ 落到 $i+1$（偶数位），偶数位 $i$ 落到 $i-1$（奇数位）。因 $n$ 为偶数，$1..n$ 中奇偶各占一半，$i\mapsto i+1$（奇数位）与 $i\mapsto i-1$（偶数位）合起来是 $1..n$ 上的双射；位置 $0$ 只能由元素 1 左移得到（而它右移）、位置 $n+1$ 只能由元素 $n$ 右移得到（而它左移），故两端为空。综上每个位置 $1..n$ 恰好一个元素。∎

**定理**：完美整数 $k$ 存在 $\iff$ $n$ 为偶数且 $mn-mx\ge2$。

**证明**：必要性——引理 2 给出 $n$ 为偶数，且所有奇数位 $>k$、偶数位 $<k$，即 $k<mn$ 且 $k>mx$；整数 $k$ 存在推出 $mn\ge k+1\ge mx+2$。充分性——引理 3 直接构造出 $k=mx+1$。∎

## 6. 复杂度分析

- **时间**：每组只需一次 $O(n)$ 扫描求"奇数位最小值、偶数位最大值"，总计 $O(\sum n)\le5\cdot10^4$ 次比较；1 s 时限下实测 500 组满数据（含读入）约 0.07 s，余量两个数量级以上。
- **空间**：只存一个长度 $n$ 的权值数组加两个极值变量，$O(n)$（流式读入可做到 $O(1)$ 额外空间）；$n\le100$ 时不足 1 KB。
- **对照限制**：即便用 $3n$ 个候选 $k$ 各模拟一遍的 $O(n^2)$ 暴力也只有 $10^6$ 级别操作，说明本题定位是签到题——$O(n)$ 结论的价值在于代码更短、边界更少、写起来不容易错。

## 7. 参考代码

### C++17

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int T;
    cin >> T;
    while (T--) {
        int n;
        cin >> n;
        vector<long long> w(n);
        for (auto &x : w) cin >> x;
        if (n % 2 == 1) {                 // 奇数个元素：位置 1 与位置 n 的填充需求冲突
            cout << "NO\n";
            continue;
        }
        long long mnOdd = LLONG_MAX, mxEven = LLONG_MIN;
        for (int i = 0; i < n; ++i) {
            if (i % 2 == 0) mnOdd = min(mnOdd, w[i]);   // 1-indexed 奇数位
            else            mxEven = max(mxEven, w[i]); // 1-indexed 偶数位
        }
        cout << (mnOdd - mxEven >= 2 ? "YES" : "NO") << '\n';
    }
    return 0;
}
```

### Python3

```python
import sys


def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    pos, t = 1, data[0]
    out = []
    for _ in range(t):
        n = data[pos]; pos += 1
        w = data[pos:pos + n]; pos += n
        if n % 2 == 1:                 # 奇数 n 恒无解
            out.append("NO")
            continue
        mn_odd = min(w[0::2])          # 1-indexed 的奇数位
        mx_even = max(w[1::2])         # 1-indexed 的偶数位
        out.append("YES" if mn_odd - mx_even >= 2 else "NO")
    sys.stdout.write("\n".join(out) + "\n")


main()
```

## 8. 边界情况与易错点

1. **$n$ 为奇数必须输出 NO**（含 $n=1$）：不能只比较 $mn-mx$，否则 $[5,1,5]$、$[10,1,20]$ 这类数据会被误判成 YES。
2. **间隙为 1 时 NO**：$k$ 必须是整数，$[5,4]$、$[2,1]$（样例 3）都无解；把判定写成 `mn > mx` 会多输出一批 YES。
3. **$w_i=k$ 会失败**：这正是不等式两端都严格的原因；若把 $w_i=k$ 当成"原地不动"，位置占用规则就变了，必须按新的入度方程重推（见延伸思考 1），不能直接套用 $mn-mx\ge2$。
4. **下标奇偶写反**：C++ 里 `for (int i = 0; i < n; ++i)` 的 `i % 2 == 0` 才是题面的奇数位；写反等于把两组极值互换，答案大面积翻转。
5. **多测初始化**：`mn = LLONG_MAX`、`mx = LLONG_MIN` 必须每组重置；$\sum n$ 不大，但 $t$ 可达 500，忘记重置会一路错到最后一组。
6. **输出用大写或小写都行**，但不要输出 `True`/`False`、也不要多输出一行空行以外的解释文字。
7. **读入格式**：$n$ 与 $w$ 在不同行，但 `>>` 与 `split()` 都按空白分词，天然兼容；不要假设"一行恰好一个数"之外的排版。

**延伸思考**：

1. 若改成"$w_i=k$ 的元素原地不动、不算失败"：位置 $i$ 被自己填住，相邻位置的来源随之改变，需要重写入度方程。可以验证 $n=2,w=[3,3]$ 取 $k=3$ 变得可行，而 $w=[5,4]$ 依然无解——可见本题的 $mn-mx\ge2$ 不能平移过去。
2. 计数版：$n$ 为偶数时完美 $k$ 的个数是 $\max(0,\ mn-mx-1)$，即区间 $(mx,mn)$ 内的整数个数；$n$ 为奇数时为 $0$。想输出一个具体方案时直接取 $k=mx+1$。
3. 若每个元素可以移动 $c$ 步（$c>1$）而不是 1 步：入度方程从"两项"变成"窗口和"，交替结构退化成周期为 $c$ 的块结构，充要条件需要重新推导——这是本题最有价值的推广方向。
4. 若要求"最终第 $j$ 个位置必须是某个指定元素"：问题变成二分图完美匹配，$O(n^3)$ 匈牙利或利用区间结构贪心。
