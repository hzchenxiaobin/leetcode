# Codeforces 字符串构造 题解

## 1. 题目概述

- **标题 / 题号**：字符串构造（Codeforces 2250B，英文名 String Construction）
- **链接**：https://codeforces.com/problemset/problem/2250/B
- **来源**：Codeforces Round 1112 (Div. 2) · Problem B
- **难度**：1000（Div. 2 B，750 分）
- **限制**：时间 1 s / 内存 256 MB
- **标签**：构造

**题意**：给定 $n$ 与 $k$，构造一个长度为 $n$ 的 01 串 $s$，同时满足：

1. $s$ 中 `0` 的个数与 `1` 的个数之差的绝对值不超过 $1$（即两字符数量尽量均分）；
2. $s$ 中**恰有** $k$ 对相邻且相同的字符，形式化地，恰有 $k$ 个下标 $i\in[1,n-1]$ 使 $s_i=s_{i+1}$。

若不存在这样的串输出 `-1`。多测：第一行 $t$，随后 $t$ 行每行两个整数 $n,k$；每组输出一行答案串（或 `-1`），多解输出任意一个。

**约束**：

- $1\le t\le 1000$，$2\le n\le 2\cdot 10^5$，$0\le k\le n-1$。
- $\sum n\le 2\cdot 10^5$，故每组必须是 $O(n)$ 的构造，总代价 $O(\sum n)$。
- $n\ge 2$ 保证至少存在一对相邻位置，$k=n-1$ 恰好是"全串同字符"这一极端情形。
- 输出规模本身就有 $\sum n$ 个字符，不可再做指数级搜索。

## 2. 示例

官方样例（8 组，输出不唯一）：

```text
输入：
8
5 2
4 3
6 1
5 0
7 3
4 2
3 2
7 4

输出：
01110
-1
101001
01010
0100011
0011
-1
0111000
```

- 第 1 组 `01110` 有 3 个 `1`、2 个 `0`，相同对是 $(s_2,s_3)$、$(s_3,s_4)$ 两对；第 2 组 $k=n-1$ 只能全串同字符，量差为 4，故 `-1`。
- 第 3 组官方给 `101001`，同题的 `011010` 也合法（多解）；第 6 组 $n=4,k=2$ 只有 `0011` 型与其对称形可行，没有更多自由度。

补一组自造样例（★，专门覆盖"第一段吞掉余量"与"$k=n-2$ 唯一可行"）：

```text
输入（★自造）：
4
2 0
2 1
6 4
9 7

输出（★自造，任一合法答案均可）：
01
-1
000111
000001111
```

- $n=2,k=0$ 只能是 `01`（交替串，0 对相同）；$n=2,k=1$ 则全串同字符，量差为 2，无解。
- $n=6,k=4$ 与 $n=9,k=7$ 都满足 $b=n-k=2$：只能是"一段 `0` + 一段 `1`"，余量全给首段，得 `000111` 与 `000001111`。

## 3. 解题思路

### 3.1 暴力思路

直接枚举全部 $2^n$ 个 01 串并逐位核对，单组就是 $O(2^n\cdot n)$；退一步做 DP（$dp[i][j][c]$ 表示前 $i$ 位用 $j$ 个 `1`、末位为 $c$）也要 $O(n^2)$ 状态，$n=2\cdot10^5$ 下都没戏。

症结在于 $k$ 只统计"相邻是否相同"，它是**段结构**的全局量：逐位做决策会把结构信息丢掉，而把"段"显式提出来之后，构造只剩一条公式。

### 3.2 核心观察：段数被 $k$ 钉死

把 $s$ 切成**极长的同字符段**（run），设段数为 $b$。相邻两段字符必然不同，段内相邻字符必然相同，于是

$$\#\{\text{相邻相同对}\}=(n-1)-(\text{相邻不同对})=(n-1)-(b-1)=n-b .$$

![按极长同字符段切分字符串，段数与 k 一一对应](images/cf2250_b_block_model.svg)

这条恒等式是整题的关键：**$k$ 与 $b$ 双向唯一确定**，$b=n-k$。于是"恰有 $k$ 对相同"等价于"恰好切成 $b$ 段"，我们只需要控制段数，不必逐位凑 $k$。

再看平衡条件。两字符个数尽量均分，所以 $s$ 必须含有 $\lceil n/2\rceil$ 个 `0` 与 $\lfloor n/2\rfloor$ 个 `1`（或两者的角色互换，任取一种即可）。

段交替出现，因此 `0` 段数 $A=\lceil b/2\rceil$、`1` 段数 $B=\lfloor b/2\rfloor$（以 `0` 开头）；每段长度至少 1，故 $A$ 个 `0` 段至少要 $A$ 个 `0`，$B$ 个 `1` 段至少要 $B$ 个 `1`。这里出现唯一的硬约束：

- $b=1$ 时 $B=0$，整串只能是同一种字符，个数差等于 $n\ge 2$，与平衡条件冲突；
- $b\ge 2$ 时，$\lceil n/2\rceil\ge A$ 且 $\lfloor n/2\rfloor\ge B$ 恒成立（因为 $b\le n$），余额可以任意塞进某一段，**一定有解**。

> 💡 **一句话记忆**：可行当且仅当 $k\le n-2$；可行时令段数 $b=n-k$，`0`/`1` 段数取 $\lceil b/2\rceil$ 与 $\lfloor b/2\rfloor$，把字符余额全部倒进各自的第一段。

### 3.3 算法流程

1. 读入 $n,k$，令 $b=n-k$；若 $b<2$（即 $k>n-2$）输出 `-1`，本组结束。
2. 令 $A=\lceil b/2\rceil$、$B=\lfloor b/2\rfloor$，`0` 的总数 $z=\lceil n/2\rceil$，`1` 的总数 $o=\lfloor n/2\rfloor$。
3. 第 1 个 `0` 段长度取 $z-(A-1)$，其余 `0` 段长度取 $1$；第 1 个 `1` 段长度取 $o-(B-1)$，其余取 $1$。
4. 按"`0` 段、`1` 段、`0` 段、……"交替拼接共 $b$ 段，得到答案。

![构造流程：段数定段长，首段吞掉余量](images/cf2250_b_algorithm_flow.svg)

这样的段长分配保证：每段长度 $\ge 1$（由 $\lceil n/2\rceil\ge A$、$\lfloor n/2\rfloor\ge B$ 得出），两种字符总数恰为 $z,o$（平衡），总长恰为 $n$，段数恰为 $b$（从而相同对恰为 $k$）。

### 3.4 示例演算

以 $n=7,k=4$ 为例：$b=7-4=3$，$A=2,B=1$，$z=4,o=3$。`0` 段长 $4-2+1=3$ 与 $1$；`1` 段长 $3-1+1=3$，拼出 `000` + `111` + `0` = `0001110`。核对：`0` 有 4 个、`1` 有 3 个（平衡），相同对为段内 $2+2+0=4$ 个。

| 组 | $n$ | $k$ | $b=n-k$ | $A$ | $B$ | $z$ / $o$ | 段长 | 串 | 核对 |
|---|---|---|---|---|---|---|---|---|---|
| ① | 7 | 4 | 3 | 2 | 1 | 4 / 3 | 3,3,1 | `0001110` | 4 ✓ |
| ② | 6 | 1 | 5 | 3 | 2 | 3 / 3 | 1,2,1,1,1 | `011010` | 1 ✓ |
| ③ | 4 | 3 | 1 | 1 | 0 | 2 / 2 | — | `-1` | 矛盾 ✗ |

![三组数据走查：同一条构造流水线](images/cf2250_b_walkthrough.svg)

第 ③ 组正是唯一无解形态：$b=1$ 意味着段数为 1，但平衡要求两种字符都出现，冲突。

## 4. 算法细节

- **先判 $b<2$ 再做任何除法**：$b=1$ 时 $B=\lfloor b/2\rfloor=0$，"第 1 个 `1` 段长 $=o-(B-1)$"会算出 $o+1$ 这种非法长度（甚至让拼接段数错位）。无解分支必须写在最前面，`continue` 掉。
- **`z` 用 `n - n/2`，别用 `(n+1)/2`**：整数下等价，但前者在 $n$ 为奇数时更难写错，且 `z+o=n` 一目了然。段长下界 $z-(A-1)\ge 1$ 依赖 $A\le z$（因 $A=\lceil(n-k)/2\rceil\le\lceil n/2\rceil$），故 `b>=2` 时首段必 $\ge1$，**不要** clamp 成 `max(1, ...)`，那会悄悄改变总长。
- **下标奇偶对齐**：以 `0` 开头时，第 $i$ 段（$0$ 索引）在 $i$ 为偶数时是 `0` 段、奇数时是 `1` 段；把 `i % 2` 写反会得到 `1` 开头的串——那也同样合法（`z/o` 互换即可），但**段长表和总数必须同时换**，只换一半就会长度不符。
- **多测与内存**：`string` 每轮重新构造，`reserve(n)` 避免反复扩容；不要用全局 `string` 累积而不 `clear`。总输出量 $\sum n\le 2\cdot10^5$，一次性 `cout` 即可。
- **I/O 常数**：$\sum n$ 只有 $2\cdot10^5$，`cin` 关同步足够；但千万别用 `endl`（$2\cdot10^5$ 次 flush 在 1 s 下很危险），用 `'\n'`。
- **$k=0$ 的退化情形**：$b=n$、$A=z$、$B=o$，所有段长为 1，构造退化为交替串，正好符合预期；每组恰好输出一行，`-1` 也单独成行，别加任何解释文字。

## 5. 正确性证明

**引理 1（段数与相同对）**：若 $s$ 被切成 $b$ 个极长同字符段，则相邻相同对恰有 $n-b$ 个。

**证明**：相邻位置共有 $n-1$ 对。段内相邻对（同一段内）字符相同，段与段交界处字符必然不同（否则两段可合并，与"极长"矛盾）。段内相邻对总数为 $\sum(\text{段长}-1)=n-b$，交界处 $b-1$ 对全部不同。故相同对 $=n-b$。∎

**引理 2（平衡条件钉死字符数）**：若 $|c_0-c_1|\le 1$ 且 $c_0+c_1=n$，则 $\{c_0,c_1\}=\{\lceil n/2\rceil,\lfloor n/2\rfloor\}$。

**证明**：设 $c_1\le c_0$，则 $c_0-c_1\le 1$。若 $n$ 为偶数，$c_0=c_1=n/2$；若 $n$ 为奇数，$c_0+c_1$ 为奇数，差为奇数且 $\le 1$，只能差 1，得 $c_1=(n-1)/2=\lfloor n/2\rfloor$、$c_0=(n+1)/2=\lceil n/2\rceil$。两种可能合并即 $\{c_0,c_1\}=\{\lceil n/2\rceil,\lfloor n/2\rfloor\}$。∎

**引理 3（必要性：$b\ge 2$）**：若存在合法串，则 $b=n-k\ge 2$，即 $k\le n-2$。

**证明**：设合法串的段数为 $b$。由引理 1，$k=n-b$。若 $b=1$，整串同字符，某个 $c$ 为 $n$、另一个为 $0$，差为 $n\ge 2$，违反平衡条件；又 $b\ge 1$ 恒成立，故 $b\ge 2$。∎

**引理 4（构造本身正确）**：$b\ge 2$ 时，算法输出的串段数恰为 $b$，长度恰为 $n$，`0` 有 $\lceil n/2\rceil$ 个、`1` 有 $\lfloor n/2\rfloor$ 个。

**证明**：算法显式拼接 $b$ 段，相邻两段字符由下标奇偶决定、必然不同，故这 $b$ 段就是极长段。`0` 总数为 $(z-A+1)+(A-1)=z$，`1` 总数为 $(o-B+1)+(B-1)=o$，相加为 $z+o=n$；又 $A\le z$、$B\le o$ 保证每段长度 $\ge1$，段长之和为 $n$。由引理 2 的取法 $|z-o|\le 1$，平衡成立。∎

**定理 1（可行性刻画）**：合法串存在当且仅当 $k\le n-2$。

**证明**：必要性由引理 3 给出。充分性：$k\le n-2$ 时 $b=n-k\ge2$，引理 4 说明输出串长度 $n$、平衡、段数为 $b$，再由引理 1 得相同对为 $n-b=k$，故是合法解。∎

**推论**：无解时输出 `-1` 正确；且构造复杂度为 $O(n)$，只做一次拼接。

## 6. 复杂度分析

- **时间**：每组只算常数个整数、再拼接 $n$ 个字符，$O(n)$；总计 $O(\sum n)\le 2\cdot10^5$ 次基本操作，1 s 时限下实测最大数据（$\sum n=2\cdot10^5$，含 $t=1000$ 的多次 I/O）约 5 ms，余量两个数量级以上。
- **空间**：输出串 $O(n)$，另有 $O(1)$ 个整数变量；C++ 中 $2\cdot10^5$ 字节，Python 中每组的 `list` 片段总字符数同样 $O(n)$，均远低于 256 MB。
- **对照限制**：$t\le1000$ 时单组均摊仅 200 字符，常数项（读入/输出）比构造更重；C++ 的 `append` 均摊 $O(n)$，Python 必须用 `"".join(parts)` 而不是循环 `+=`。

## 7. 参考代码

### C++17

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int T;
    if (!(cin >> T)) return 0;
    while (T--) {
        int n, k;
        cin >> n >> k;
        int b = n - k;                 // 段数：相邻相同对 = n - 段数
        if (b < 2) {                   // 只有一段 => 全串同字符，数量差为 n > 1
            cout << -1 << '\n';
            continue;
        }
        int A = (b + 1) / 2;           // '0' 的段数（以 '0' 开头）
        int B = b / 2;                 // '1' 的段数
        int z = n - n / 2;             // '0' 的个数 = ceil(n/2)
        int o = n / 2;                 // '1' 的个数 = floor(n/2)
        string s;
        s.reserve(n);
        for (int i = 0; i < b; ++i) {
            if (i % 2 == 0) {          // 第 i 段是 '0' 段
                int len = (i == 0) ? z - (A - 1) : 1;   // 余量全给第一段
                s.append(len, '0');
            } else {                    // 第 i 段是 '1' 段
                int len = (i == 1) ? o - (B - 1) : 1;
                s.append(len, '1');
            }
        }
        cout << s << '\n';
    }
    return 0;
}
```

### Python3

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    t = int(data[0])
    pos = 1
    out = []
    for _ in range(t):
        n = int(data[pos]); k = int(data[pos + 1]); pos += 2
        b = n - k                      # 段数 = n - 相邻相同对数
        if b < 2:                      # 一段 => 全串同字符，不平衡
            out.append("-1")
            continue
        a = (b + 1) // 2               # '0' 的段数
        c = b // 2                     # '1' 的段数
        z = n - n // 2                 # '0' 的个数
        o = n // 2                     # '1' 的个数
        parts = []
        for i in range(b):
            if i % 2 == 0:
                length = z - (a - 1) if i == 0 else 1
                parts.append("0" * length)
            else:
                length = o - (c - 1) if i == 1 else 1
                parts.append("1" * length)
        out.append("".join(parts))
    sys.stdout.write("\n".join(out) + "\n")

main()
```

## 8. 边界情况与易错点

1. **$b=1$ 必须先拦截**：$k=n-1$ 时（含 $n=2,k=1$、$n=3,k=2$）无解。若先算 $B=\lfloor b/2\rfloor=0$ 再套段长公式，会得到长度为 $o+1$ 的 `1` 段，输出串长度超过 $n$，直接 WA 而不是 RE，很难查。
2. **$k=n-2$ 是唯一的"两大段"答案**：此时 $b=2$，$A=B=1$，`0` 段长 $\lceil n/2\rceil$、`1` 段长 $\lfloor n/2\rfloor$，即"一半 `0` + 一半 `1`"。不要在这个点上误加额外分支。
3. **$n$ 为奇数时首段长度**：$n=7,k=4$ 时 $z=4$、$A=2$，首段长 $4-2+1=3$；若误写 `n/2 - (A-1) = 3-1 = 2`，则 `0` 只有 $3$ 个，总长 $6\ne 7$，长度就错了。
4. **奇偶下标的含义**：段的下标从 0 开始，`i % 2 == 0` 才是 `0` 段。若把 `A`、`B` 互换而段长表不换，`0` 的个数会变成 $\lfloor n/2\rfloor$——这本身仍合法（平衡只要求差 $\le1$），但两处必须一致，否则长度对不上。
5. **多测不要累积，输出别用 `endl`**：每组新建 `string`，用 `reserve(n)` 提常数但别 `resize`（尾部会残留 `'\0'`）；$\sum n$ 次 flush 在 1 s 下明显偏慢，统一 `'\n'`。
6. **格式与健壮性**：每组恰一行、`-1` 单独成行、答案串不含空格；建议保留 `if (!(cin >> T)) return 0;` 以免本地空输入读到未初始化值。

**延伸思考**：

1. 若把"相邻相同"改成"相邻不同"，则要求段数 $b=k+1$，可行条件变成 $k+1\le n$ 且 $b\ge2$（两种字符都要出现），即 $1\le k\le n-1$——注意 $k=0$ 时反而是全同串，无解。
2. 若把平衡条件放宽为 $|c_0-c_1|\le d$：$b=1$ 从无解变为在 $d\ge n$ 时可行；而 $b\ge2$ 时仍可构造，只需取 $c_0=\min(\lfloor(n+d)/2\rfloor,\ n-B)$、$c_1=n-c_0$，再检查 $c_0\ge A$ 即可。
3. 若要求字典序最小：仍以 `0` 开头取 $z=\lceil n/2\rceil$ 个 `0`，再把 `0` 的余量全部塞进**第一段**、把 `1` 的余量全部塞到**最后一个 `1` 段**，即得字典序最小解；首段越长、后面的 `0` 出现得越早，而段数不变时 $k$ 不受影响。
4. 若再要求串中不含 `00` 子串：每个 `0` 段都只能是长度 1，于是 `0` 的个数被逼成 $c_0=A$，可行性多出一条 $\lceil n/2\rceil=\lceil b/2\rceil$，解得 $b\in\{n,n-1\}$ 且 $b=n-1$ 仅在 $n$ 为偶数时成立——也就是说只剩 $k=0$（交替串），或 $n$ 偶数且 $k=1$ 这两种输入有解。
