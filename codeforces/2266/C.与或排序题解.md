# Codeforces 与或排序 题解

## 1. 题目概述

- **标题 / 题号**：与或排序（Codeforces 2266C，英文名 AND, OR, Sort!）
- **链接**：https://codeforces.com/problemset/problem/2266/C
- **来源**：Codeforces Round 1122 (Div. 3) · Problem C
- **难度**：$\ast 1000$
- **限制**：时间 2 s / 内存 256 MB
- **标签**：贪心，字符串，枚举

**题意**：给定长度 $n$ 的 01 串 $s$。可执行任意多次操作：选下标 $i$，把 $s_i$ 改写为**当前** $s_1,\dots,s_i$ 的按位与，或者改写为它们的按位或（每次操作二选一；单个元素的与/或就是它自己，所以 $i=1$ 的操作没有效果）。要求把 $s$ 变成**非降序**，即形如 $00\cdots011\cdots1$，求最少操作次数。多测：第一行 $t$，每组先读 $n$ 再读串 $s$，逐组输出一个整数。

**约束**：

- $1 \le t \le 10^4$，且 $\sum n \le 2\times 10^5$——总规模不大，但每组必须接近 $O(n)$；
- $2 \le n \le 2\times 10^5$，$s$ 仅由 `0`、`1` 组成；
- 任何 $O(n^2)$ 的「枚举区间 + 模拟操作」在 $n = 2\times10^5$ 时必然超时。

## 2. 示例

```text

```

题面 Notes 只解释了两组：`0011` 本就非降序，答案 $0$；`1000` 可用按位或把后三位都改成 $1$，共 $3$ 次。其余四组见 §3.4。


`10` 一次 OR 变 `11`；`01` 已非降序；`1110` 首字符是 $1$，只能把末尾的 $0$ 补成 $1$；`0000` 本身有序。

## 3. 解题思路

### 3.1 暴力思路

把 01 串当状态做 BFS：每个状态枚举 $2n$ 种操作（$n$ 个位置 × AND / OR），第一次走到非降序状态即为答案。状态数最多 $2^n$，$n = 10$ 时已是 $1024$ 个状态、$2\times10^4$ 条边，$n = 2\times10^5$ 时完全不可能。所以本题必须**放弃搜索操作序列**，改问：最终串长什么样、每个位置要改几次？暴力只留给小数据对拍（§8 第 8 条）。

### 3.2 核心观察：两处「钉死」的结构

![s₁ 不变与前导 0 区冻结，终局只能是 0^a 1^(n−a)](images/cf2266_c_anchor_concept.svg)

**观察 1：$s_1$ 永远不变。** $i=1$ 时前缀只有 $s_1$ 本身，AND 与 OR 都返回 $s_1$；$i>1$ 的操作不碰位置 $1$。

**观察 2：$s_1 = 0$ 时，前导 0 区永远变不成 1。** 设前导 $0$ 有 $j$ 个（$j$ 即第一个 $1$ 的位置减一）。位置 $1$ 恒为 $0$；位置 $2$ 的前缀只有 $0$，AND / OR 都是 $0$；……；位置 $j$ 的前缀全是 $0$，AND / OR 仍是 $0$。按时间归纳可知**位置 $1..j$ 在任何时刻都是 $0$**。更进一步：一个位置想变成 $1$ 只能靠 OR，而 OR 需要前缀里**已经有** $1$——所以「能变成 1」的位置都在某个初始 $1$ 的右边。

**观察 3：$s_1 = 0$ 时 AND 是万能清零器。** 任何前缀都含 $s_1=0$，故前缀 AND 恒为 $0$：任意位置一次 AND 就能变 $0$；而 OR 只在「前缀里还有 $1$」时才把 $0$ 变 $1$。

于是终局只有 $0^a1^{n-a}$ 一种形状，且前导 $0$ 区被冻结 ⇒ **切点必须满足 $a \ge j$**。特别地 $s_1=1$ 时位置 $1$ 永远是 $1$，只能取 $a=0$（全串变 $1$）。

### 3.3 算法流程：固定切点后代价就是「错位数」

![固定切点 a 后的两侧代价与 O(n) 扫描](images/cf2266_c_split_cost.svg)

固定可行切点 $a \ge j$（$s_1=0$ 时）：前缀 $1..a$ 里的每个 $1$ 各用一次 AND 变 $0$；后缀 $a+1..n$ 里的每个 $0$ 各用一次 OR 变 $1$。

顺序很关键：**先把后缀的 $0$ 全部 OR 成 $1$，再回头 AND 前缀的 $1$**。做 OR 时位置 $j+1$ 的 $1$ 还没被动过，而待补的 $0$ 位于 $q > a \ge j$，又因 $s_q=0$ 而位置 $j+1$ 是 $1$ 故 $q \ne j+1$，即 $q > j+1$：每次 OR 的前缀里都有这个 $1$，全部合法。代价因此恰为

$$f(a) = \#\{i \le a : s_i = 1\} + \#\{i > a : s_i = 0\}$$

这也是下界：一次操作最多改一个位置，而上面这些位置的初值都和终值不同。

记 $Z$ 为全串 $0$ 的个数，$\mathrm{bal}(a)=\#\{i\le a:s_i=1\}-\#\{i\le a:s_i=0\}$（`1` 记 $+1$、`0` 记 $-1$ 的累加），则

$$f(a) = \#\{i\le a:s_i=1\} + \bigl(Z - \#\{i\le a:s_i=0\}\bigr) = Z + \mathrm{bal}(a)$$

$Z$ 是常数，问题退化为「在 $a \ge j$ 的前缀里取最小的 $\mathrm{bal}(a)$」，一次扫描完成：

1. 统计 $Z$。若 $s_1=1$，输出 $Z$ 并结束（只能全 $1$，每个 $0$ 一次 OR）。
2. 求 $j$（前导 $0$ 个数）；若不存在 $1$（全 $0$），输出 $0$。
3. 从 $a=1$ 扫到 $n$ 维护 $\mathrm{bal}$，只对 $a \ge j$ 更新 $\min\mathrm{bal}$，输出 $Z+\min\mathrm{bal}$。

### 3.4 示例演算

![s = 01001101 的切点代价演算表](images/cf2266_c_walkthrough.svg)

以 `s = 01001101` 为例：$n=8$，$Z=4$，$j=1$。沿 $a=1..8$ 扫出的 $\mathrm{bal}$ 依次是 $-1,0,-1,-2,-1,0,-1,0$，对应的 $f$ 为 $3,4,3,2,3,4,3,4$，最小值 $2$ 落在 $a=4$（前缀 `0100`）。

最优是 $a=4$：先 OR 位置 $7$（前缀 `010011` 有 $1$）得 `01001111`，再 AND 位置 $2$（前缀 AND $=0$）得 `00001111`，两步收工。切点取 $2$ 或 $8$ 都要 $4$ 步——太靠左，左边的 $1$ 清不完；太靠右，右边的 $0$ 补不完。而 `1000` 走特判得 $Z=3$；若硬套扫描（$j=0$，允许 $a=4$）会算出 $1$，这是本题最大的坑。

## 4. 算法细节

1. **$j$ 的精确定义**：$j$ 是前导 $0$ 的个数，即 `find('1')` 的返回值（0-indexed），它同时是「锁死区长度」与「切点下界」。$s_1=1$ 时 $j=0$，但那时只允许 $a=0$，所以必须先特判，不能让扫描接管。
2. **$s_1=1$ 必须单独处理**：此时 $a=0$ 是唯一合法终局，答案 $=Z$。代码把它放在最前面 `continue`，避免后面误用形同虚设的 $a\ge j$。
3. **$s_1=0$ 时下界 $a\ge j$ 是冗余的**：$a<j$ 时前缀全 $0$，$\mathrm{bal}(a)=-a>-j=\mathrm{bal}(j)$，最小值必在 $a\ge j$ 处取到。写 `if (a >= j)` 只为让代码与证明一一对应；删掉不会错，但别在 $s_1=1$ 时删。
4. **数据范围**：$\mathrm{bal}\in[-n,n]$，答案 $\in[0,n]$，$n\le2\times10^5$，`int` 足够；答案不会超过 $n$（每位置最多改一次），别估成 $2n$。
5. **空间 $O(1)$**：无需预处理前缀数组，边扫边取最小；多测之间 $\mathrm{bal}$、$\mathrm{best}$ 重新初始化，不要写成全局。
6. **I/O**：`cin >> n >> s` 即可（串内无空格），关同步、用 `'\n'`；Python 侧一次 `sys.stdin.buffer.read().split()`，直接比较 `bytes`，省掉 $t$ 次 `decode`。本题纯计数，不需要构造或模拟操作序列。

## 5. 正确性证明

**引理 1（首字符不变）**：任何操作序列执行完毕后 $s_1$ 与初始值相同。

**证明**：$i=1$ 时 $s_1$ 被改写为 $s_1$ 与 $s_1$ 的 AND / OR，仍等于 $s_1$；$i\ge2$ 的操作不修改位置 $1$。∎

**引理 2（前导 0 区冻结）**：设 $s_1=0$、$j$ 为前导 $0$ 的个数，则任意时刻 $s_1=\dots=s_j=0$。

**证明**：对操作步数归纳。初始显然。设当前成立，若对位置 $q\le j$ 操作，前缀 $s_1..s_q$ 全为 $0$，AND 与 OR 都是 $0$，$s_q$ 不变；$q>j$ 的操作不影响位置 $1..j$。不变量保持。∎

**引理 3（下界）**：设终局为 $0^a1^{n-a}$，则操作次数 $\ge f(a)$。

**证明**：每次操作只改一个位置。前缀 $1..a$ 中初始为 $1$ 的位置终局必须为 $0$，后缀中初始为 $0$ 的位置终局必须为 $1$，这些位置初值与终值都不同，各自至少被改一次，故总次数不少于错位数 $f(a)$。∎

**引理 4（可行域）**：$s_1=0$ 时必有 $a\ge j$；$s_1=1$ 时必有 $a=0$。

**证明**：前者若 $a<j$，则位置 $a+1\le j$ 终局为 $1$，与引理 2 矛盾。后者若 $a\ge1$，则终局位置 $1$ 应为 $0$，与引理 1（位置 $1$ 恒为 $1$）矛盾，故只能 $a=0$。∎

**引理 5（构造 / 上界）**：$s_1=0$ 且 $a\ge j$ 时可用恰好 $f(a)$ 次操作得到 $0^a1^{n-a}$。

**证明**：两阶段执行。阶段一对每个 $q>a$ 且 $s_q=0$ 的位置执行 OR：位置 $j+1$ 仍为 $1$（阶段一只改 $q>a\ge j$ 的位置，而 $j+1\le a$），又 $s_q=0$ 而 $s_{j+1}=1$ 给出 $q\ne j+1$，结合 $q>a\ge j$ 得 $j+1<q$，前缀里有 $1$，故这些 $0$ 全部被置 $1$。阶段二对每个 $p\le a$ 且 $s_p=1$ 的位置执行 AND，前缀含 $s_1=0$ 使前缀 AND 恒为 $0$，全部置 $0$。两阶段正好修改 $f(a)$ 个位置，每处一次，终串前缀全 $0$、后缀全 $1$。∎

**定理**：答案为 $Z+\min\{\mathrm{bal}(a):a\ge j\}$（$s_1=0$）；$s_1=1$ 时为 $Z$。

**证明**：$s_1=0$ 时引理 3、4 给出任意方案次数 $\ge f(a)=Z+\mathrm{bal}(a)$（$a\ge j$），即 $\ge Z+\min_{a\ge j}\mathrm{bal}(a)$，引理 5 说明该下界可取到，故相等。$s_1=1$ 时终局唯一为全 $1$（引理 4），每个初始 $0$ 至少改一次给出下界 $Z$，而前缀 OR 恒为 $1$（含 $s_1=1$），逐个 OR 即可达到。∎

## 6. 复杂度分析

- **时间**：每组 $O(n)$——统计 $Z$、找前导 $0$、扫一遍前缀和；总计 $O(\sum n)\le2\times10^5$ 次基本操作。实测 C++ 处理 $n=2\times10^5$ 的单组（含进程启动与读入）约 $16$ ms，对 $2$ s 时限余量百倍以上；Python 版同一数据约 $41$ ms。
- **空间**：$O(1)$ 辅助空间（$Z$、$j$、$\mathrm{bal}$、$\mathrm{best}$ 几个整数）加上读入串本身 $O(n)$；Python 版额外一个 $O(t)$ 的答案列表，最多 $10^4$ 个短串。对比 BFS 暴力 $O(n2^n)$，$n=20$ 就卡死。

## 7. 参考代码

### C++17

```cpp
#include <iostream>
#include <string>
#include <algorithm>
#include <climits>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int t;
    if (!(cin >> t)) return 0;
    while (t--) {
        int n;
        string s;
        cin >> n >> s;
        n = (int)s.size();
        int zeros = 0;                        // Z：0 的总数
        for (char c : s) zeros += (c == '0');
        if (s[0] == '1') {                    // 首字符锁死为 1 ⇒ 只能全 1
            cout << zeros << '\n';
            continue;
        }
        int j = (int)s.find('1');             // 前导 0 个数 = 切点下界
        if (j == (int)string::npos) {         // 全 0，已非降序
            cout << 0 << '\n';
            continue;
        }
        int best = INT_MAX, bal = 0;
        for (int a = 1; a <= n; ++a) {
            bal += (s[a - 1] == '1') ? 1 : -1;
            if (a >= j) best = min(best, zeros + bal);
        }
        cout << best << '\n';
    }
    return 0;
}
```

### Python3

```python
import sys


def main() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    t = int(data[0])
    pos = 1
    out = []
    for _ in range(t):
        n = int(data[pos])
        s = data[pos + 1]                 # bytes，省去 decode
        pos += 2
        zeros = s.count(b'0')
        if s[0] == 49:                    # ord('1')
            out.append(str(zeros))
            continue
        j = s.find(b'1')                  # 前导 0 个数
        if j == -1:
            out.append('0')
            continue
        best, bal = n + 1, 0
        for a in range(1, n + 1):
            bal += 1 if s[a - 1] == 49 else -1
            if a >= j and zeros + bal < best:
                best = zeros + bal
        out.append(str(best))
    sys.stdout.write('\n'.join(out) + '\n')


main()
```

## 8. 边界情况与易错点

1. **首字符是 $1$（最容易错）**：只能全 $1$，答案是 $Z$（即 $0$ 的个数）。`1000` 正确答案是 $3$，`01000` 是 $1$，做成「统一公式」必 WA。
2. **切点下界 $a\ge j$**：`0011` 的 $j=2$，切点不能取 $0$ 或 $1$，因为位置 $1,2$ 的 $0$ 永远变不成 $1$。
3. **全 $0$ / 全 $1$**：都不用特判——全 $0$ 走 $s_1=0$ 分支、`find('1')` 返回 `npos` 后输出 $0$；全 $1$ 走 $s_1=1$ 分支且 $Z=0$。
4. **$n=2$ 最小数据**：`10` → $1$（OR 位置 $2$）；`01`、`11`、`00` → $0$；扫描从 $a=1$ 起，别把 $\mathrm{bal}(0)=0$ 混进来。
5. **答案上界**：答案 $\le n$，每位置最多改一次；不要以为左右两侧都要多次操作而估成 $2n$，也不要用 `n` 当 `best` 初值（可能恰好取到）。
6. **多测重置**：$\mathrm{bal}$、$\mathrm{best}$、$Z$ 每组重新初始化；`best` 若写成全局且不清零，第二组就会输出上一组的答案。
7. **Python 细节**：$t\le10^4$ 用 `input()` 也能过，但一次性 `read().split()` 更稳；`bytes` 索引是整数，必须写 `s[0] == 49` 而不是 `s[0] == '1'`（后者恒为 `False`）。
8. **验证方式**：本解已通过官方 $6$ 组样例、$n=2\dots9$ 的**全量穷举**（$1020$ 组，每组用 BFS 暴力求最少步数）、$400$ 组 $n=10\dots13$ 随机对拍，C++ 与 Python 输出完全一致；$n=2\times10^5$ 时 C++ 约 $16$ ms、Python 约 $41$ ms。

**延伸思考**：

1. **若首字符也能改**（额外允许一次「翻转 $s_1$」的操作）：可行域变成所有 $a$，答案就是 LeetCode 926 式的 $\min_a f(a)$，$j$ 约束消失。
2. **若允许后缀操作**（对 $s_i\dots s_n$ 取 AND/OR）：问题镜像，尾字符锁死，公式只差一次倒序扫描。
3. **若字符集扩到 $0..k-1$、把 AND/OR 换成前缀 $\min$/$\max$**：非降序终局变成「前缀最小值区冻结 + 后面非降」，「锁死」等价于前缀最小值的可达范围，代价仍是「前缀中大于目标值的个数 + 后缀中小于目标值的个数」，可 $O(nk)$ 或排序后 $O(n\log n)$。
4. **若要输出具体操作序列**：按 §3.3 的两阶段顺序（先所有 OR，再所有 AND）输出即可，操作数与答案完全相同。
