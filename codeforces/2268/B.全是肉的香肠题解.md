# Codeforces 全是肉的香肠 题解

## 1. 题目概述

- **标题 / 题号**：全是肉的香肠（Codeforces 2268B，英文名 What a SauSaGe! It's All Meat）
- **链接**：https://codeforces.com/problemset/problem/2268/B
- **来源**：Codeforces Round 1124 (Div. 1) · Problem B（Div. 2 侧编号 2269D）
- **难度**：1500（1000 分）
- **限制**：时间 2 s / 内存 256 MB
- **标签**：位运算，线性基（异或子空间），数学，暴力枚举，计数

**题意**：有 $n$ 种香肠，第 $i$ 种库存 $a_i$ 根，$0 \le a_i < 16$。允许的操作：选 $1 \le i < n$ 与 $1 \le k \le 5$，把 $a_i$、$a_{i+1}$ **同时**异或上 $3k$，可做任意多次。一种香肠叫 **All-Meat** 当且仅当库存能被 3 整除；问通过最优操作最多能让多少种变成 All-Meat。另有 $q$ 次**永久**单点赋值 $a_p := x$，初始状态与每次赋值后都要回答一次，而**每次回答时的操作都是假设性的、不改变数组**，故每组输出 $q+1$ 个数。

**约束**：

- $2 \le n \le 2\times10^5$，$0 \le q \le 2\times10^5$，$0 \le a_i, x < 16$
- $1 \le t \le 10^4$，$\sum n \le 2\times10^5$，$\sum q \le 2\times10^5$
- 值域只有 $16$ 个数而 $n,q$ 到 $2\times10^5$：暗示每个状态的最优答案有**闭式**，且每次更新只需 $O(1)$

## 2. 示例

官方样例（输入 / 输出原样）：

```text
输入：
3
2 1
10 3
1 0
3 3
15 1 5
3 0
1 10
2 0
4 0
1 2 3 4

输出：
2 2 
2 2 2 3 
1 
```

逐组对照（判据见 §3.2）：

| 当前数组 | popcount | 答案 |
|----------|----------|------|
| $[10,3]$ | $2,\,2$ | 2 |
| $[0,3]$ | $0,\,2$ | 2 |
| $[15,1,5]$ | $4,\,1,\,2$ | 2（第 2 位奇权） |
| $[15,1,0]$ | $4,\,1,\,0$ | 2 |
| $[10,1,0]$ | $2,\,1,\,0$ | 2 |
| $[10,0,0]$ | $2,\,0,\,0$ | 3 |
| $[1,2,3,4]$ | $1,\,1,\,2,\,1$ | 1（只有 3） |

自造 2 组（覆盖「全奇权」与「改成 0」）：

```text
输入：
2
2 2
5 10
1 15
2 7
5 1
1 2 4 7 8
3 0

输出：
2 2 1
0 1
```

- 第 1 组：$[5,10]$ 中 $5 = 0101$、$10 = 1010$，都是偶权，答案 2；$a_1 := 15$（$1111$）仍偶权，答案仍 2；$a_2 := 7$（$0111$，3 个 1）变奇权，答案掉到 1。
- 第 2 组：$1,2,4,7,8$ 全为奇权，答案 0；把 $a_3$ 改成 $0$ 后多一个偶权位置，答案 1。

## 3. 解题思路

### 3.1 暴力思路

搜状态：状态是整个数组，一步有 $5(n-1)$ 种选法，状态数不超过 $16^n$，$n \ge 6$ 就爆，还要对 $q+1$ 个状态各搜一次。稍好的暴力是枚举「每条边异或了什么」，组合数 $m^{n-1}$、判一遍 $O(n)$——它提示了关键：**真正要枚举的只是「每条边能贡献什么」**，而这个集合很快就会缩到 8 个值。但它仍是指数的，必须证明最优答案有闭式。

### 3.2 核心观察：偶权不变量 + 边贡献恰为偶权码

![一次操作在链上做了什么](images/cf2268_b_edge_contribution.svg)

**操作代数化。** 异或可交换、可结合，故顺序无关，只有**每条边累计异或了多少**有意义。设 $s_i$ 为第 $i$ 条边（位置 $i$ 与 $i+1$ 之间）所用 $3k$ 的异或和，$s_0 = s_n = 0$，则

$$a'_i = a_i \oplus s_{i-1} \oplus s_i \qquad (1 \le i \le n).$$

反过来，$s_i$ 只要落在张成空间里就一定凑得出：$3,6,12$ 即 $0011,0110,1100$，在 $\mathrm{GF}(2)^4$ 中线性无关，故 $G = \operatorname{span}\{3,6,9,12,15\} = \{0,3,5,6,9,10,12,15\}$、$|G| = 8$。其中 $9 = 3\oplus6\oplus12$、$15 = 3\oplus12$ 是多余的生成元，而 $5 = 3\oplus6$、$10 = 6\oplus12$ 虽不在题目给的 5 个值里，也能在同一对位置连做两次凑出。于是**每条边能独立地把 $G$ 中任意值异或到它两端**，各边互不干扰。

**看清 $G$ 是什么。** $G$ 恰是 $0..15$ 中 popcount（二进制 1 的个数）为**偶数**的全部 8 个数：$3,6,9,12,15$ 的 popcount 都是偶数，偶权数在异或下封闭、构成 3 维子空间，而上面三个线性无关的生成元正好张满它。于是每次操作给两个位置异或的都是偶权值，

$$\mathrm{popcount}(a_i) \bmod 2 \ \text{是操作不变量}, \qquad a'_i \text{ 只能落在陪集 } a_i \oplus G \text{ 内}.$$

![0..15 按 popcount 奇偶分成两半](images/cf2268_b_coset_split.svg)

**数两侧的 3 的倍数。** $0..15$ 中 3 的倍数为 $M = \{0,3,6,9,12,15\}$，popcount 依次 $0,2,2,2,2,4$ **全偶**，故 $M \subseteq G$；而奇权一侧 $\{1,2,4,7,8,11,13,14\}$ 里一个 3 的倍数都没有。于是

- $a_i$ 奇权 $\Rightarrow$ $a'_i$ 永远奇权 $\Rightarrow$ **该位置无论怎么操作都不是 All-Meat**（给出上界）；
- $a_i$ 偶权 $\Rightarrow$ $a'_i \in G = M \cup \{5,10\}$，好坏只差「别让它等于 $5$ 或 $10$」。

记 $\text{gap} = s_{i-1}\oplus s_i \in G$，则位置 $i$ 变坏当且仅当 $\text{gap} \in \{a_i\oplus5,\ a_i\oplus10\}$：**每个偶权位置只有 2 个坏 gap（8 选 2），剩下 6 个都能让它被 3 整除**；这 2 个坏 gap 正是偶权侧里仅有的两个非 3 倍数，是本题枢纽。

### 3.3 构造与算法流程

![贪心定 s_i：每步至少 4 个合法选择](images/cf2268_b_greedy_construct.svg)

按 $i = 1 \to n-1$ 依次定 $s_i$，把**所有偶权位置一次全救活**：

1. $i = 1 \ldots n-2$：$s_{i-1}$ 已定。位置 $i$ 偶权则禁掉 $s_i \in \{s_{i-1}\oplus a_i\oplus5,\ s_{i-1}\oplus a_i\oplus10\}$ 这 2 个值，还剩 $8-2=6$ 个可选；奇权则随意取。
2. $i = n-1$：要同时照顾位置 $n-1$（偶权则禁 2 个）与位置 $n$（偶权则因 $s_n = 0$ 而禁 $s_{n-1} \in \{a_n\oplus5,\ a_n\oplus10\}$ 这 2 个），并集至多 4 个，仍有 $8-4=4$ 个可选，绝不空。
3. 奇权位置全程无约束——它本就救不回来，也不妨碍别人。

故上界可达，答案为偶权位置个数：

$$\boxed{\ \text{ans} = \#\{\,i : \mathrm{popcount}(a_i) \text{ 为偶数}\,\}\ }$$

实现只需一个计数器：读入时统计一次，每次赋值 $a_p := x$ 时「旧值偶权减 1、新值偶权加 1」。**不必模拟任何操作**——操作都是假设性的，数组只被赋值语句改动。

> 💡 偶权集合的位掩码是 `0x9669`（第 $0,3,5,6,9,10,12,15$ 位为 1），判据也可写成 `(0x9669 >> a_i) & 1`，比 `popcount` 更快。

### 3.4 示例演算

![样例走查](images/cf2268_b_walkthrough.svg)

第 1 组 $[10,3]$：$10 = 1010$、$3 = 0011$，popcount 都是 2，答案 2。取 $s_1 = 3$：

$$[10,\,3] \ \xrightarrow{\ \text{两端同异或 } 3\ } \ [10\oplus3,\ 3\oplus3] = [9,\,0],$$

$9$ 与 $0$ 都被 3 整除，两位一起归位，恰好取到上界。第 2 组 $[15,1,5]$：popcount $4,1,2$，第 2 位奇权永远救不回来，答案 2。取 $s_1 = s_2 = 9$：

$$[15,\,1,\,5] \ \longrightarrow \ [15\oplus9,\ 1\oplus9\oplus9,\ 5\oplus9] = [6,\,1,\,12],$$

$6$、$12$ 都被 3 整除，第 2 位仍是 $1$——上界被恰好取到。第 3 组 $[1,2,3,4]$ 的 popcount 为 $1,1,2,1$，只有 $3$ 偶权，答案 1。

## 4. 算法细节

1. **判据三种等价写法**：`__builtin_popcount(v) % 2 == 0`、`__builtin_parity(v) == 0`、`(0x9669 >> v) & 1`（C++17）；Python 用 `bin(v).count("1") % 2 == 0`；值域 16，也可直接打 `bool good[16]` 表。
2. **加减顺序**：先按**旧值** `a[p]` 判断并减 1，**再**赋值 `a[p] = x`，最后按 `x` 判断并加 1。写反会在「新旧值同属偶权」时把计数弄错。
3. **多测重置**：`cnt` 每组从 0 重统计、`vector` 每组重建；$t$ 可达 $10^4$，别让上一组数据漏进来。
4. **$q = 0$ 也要输出**：每组固定 $q+1$ 个数，先初始答案、再逐次更新答案；共约 $2\times10^5$ 个数，C++ 攒进 `string` 一次写出、用 `'\n'` 而非 `endl`，Python 用 `" ".join` 拼行。
5. **输入才是瓶颈**：约 $2(\sum n+\sum q)\approx8\times10^5$ 个整数。§6 实测 `cin`（关同步）在原机要 $0.49$ s，手写 `fread` 只要 $0.010$ s。
6. **不需要数据结构**：只有单点赋值 + 全局计数，没有区间查询，线段树 / 树状数组纯属多余。

## 5. 正确性证明

**引理 1（偶权不变量）**：任意合法操作序列中，任何位置的 $\mathrm{popcount}(a_i) \bmod 2$ 都不变。

**证明**：一次操作给 $a_i$ 异或上 $3k \in \{3,6,9,12,15\}$，其 popcount 为 $2,2,2,2,4$ 全偶。又对任意 $u,v$ 有 $\mathrm{popcount}(u\oplus v) \equiv \mathrm{popcount}(u)+\mathrm{popcount}(v) \pmod 2$（逐位独立：$1\oplus1=0$ 贡献 0 个 1，$1\oplus0=1$ 贡献 1 个 1），取偶权的 $v = 3k$ 即得。∎

**引理 2（$G$ 即偶权集合，且边贡献可取遍 $G$）**：$G = \operatorname{span}\{3,6,9,12,15\} = \{0,3,5,6,9,10,12,15\}$，恰为 $0..15$ 中 popcount 为偶数的全体；对任意 $(s_1,\dots,s_{n-1}) \in G^{n-1}$，都存在操作序列使第 $i$ 条边总异或恰为 $s_i$。

**证明**：$3 = 0011$、$6 = 0110$、$12 = 1100$ 在 $\mathrm{GF}(2)^4$ 中线性无关，张成恰好 $2^3 = 8$ 个元素；又 $9 = 3\oplus6\oplus12$、$15 = 3\oplus12$、$5 = 3\oplus6$、$10 = 6\oplus12$ 都在其中，逐一列出即 $\{0,3,5,6,9,10,12,15\}$，检查 popcount 全偶；偶权数对异或封闭，是 3 维子空间、共 8 个，故两者相等。可达性：每个 $s_i$ 是 $\{3,6,12\}$ 某子集的异或和，在第 $i$ 条边上对该子集每个值各做一次操作即可（至多 3 次），不同边只改各自两端的两个位置，互不影响。∎

**引理 3（$M \subseteq G$，且奇权侧无 3 的倍数）**：$M = \{x \in [0,16) : 3 \mid x\} = \{0,3,6,9,12,15\} \subseteq G$；且 $[0,16)\setminus G = \{1,2,4,7,8,11,13,14\}$ 中不存在 3 的倍数。

**证明**：$M$ 的 popcount 依次 $0,2,2,2,2,4$ 全偶，由引理 2 得 $M \subseteq G$，于是 $G\setminus M = \{5,10\}$，补集就是剩下 8 个数，全为奇权，而 $M$ 全为偶权，两者不可能相交。∎

**引理 4（上界）**：若 $a_i$ 奇权，则任何操作后 $a'_i$ 都不是 3 的倍数。

**证明**：由引理 1，$a'_i$ 仍奇权；由引理 3，$[0,16)$ 中所有 3 的倍数都是偶权。∎

**引理 5（构造达到上界）**：若 $a_i$ 偶权，则存在取法使 $a'_i$ 被 3 整除；且所有偶权位置可**同时**被照顾好。

**证明**：按 §3.3 顺序构造，归纳假设 $s_0..s_{i-1}$ 已定且位置 $1..i-1$ 的偶权位置已变好。$i \le n-2$ 时位置 $i$ 的坏 gap 只有 $a_i\oplus5$、$a_i\oplus10$（奇权则没有），故坏 $s_i$ 只有 2 个，$|G|=8$ 保证至少剩 6 个选择。$i = n-1$ 时坏值集合是「位置 $n-1$ 的 2 个」与「位置 $n$ 的 2 个」之并（后者因 $s_n = 0$ 退化为 $s_{n-1}$ 本身的两个值），大小至多 4，仍剩至少 4 个。归纳完成。∎

**定理**：$\text{ans} = \#\{i : \mathrm{popcount}(a_i) \text{ 为偶数}\}$。**证明**：引理 4 给出上界（奇权位置贡献 0），引理 5 给出下界（偶权位置全部贡献 1），上下界相等。∎

## 6. 复杂度分析

- **时间**：每组 $O(n+q)$，总量 $O(\sum n+\sum q) \le 4\times10^5$ 次基本运算，每次更新严格 $O(1)$（两次 popcount + 两次加减）；**空间** $O(n)$ 存当前数组（更新时要拿旧值），其余常数个变量，Python 额外 $O(\sum n+\sum q)$ 存 token。
- **实测**（本机 Apple clang / libc++，单组 $n = q = 2\times10^5$）：C++ 的 `cin`（关同步）版 $0.49$ s，其中 $0.47$ s 全花在 libc++ 的整数解析上；换 `fread` 自建缓冲后整份程序 $0.010$ s；Python3 约 $0.26$ s。$t = 10^4$、$\sum n = \sum q = 2\times10^5$ 的形状几乎不改变耗时（总 token 数相同）。
- **结论**：按最保守的 $0.49$ s 算，相对 2 s 仍有约 4 倍余量；CF 上 g++/libstdc++ 的 `cin` 远快于 libc++，正常在 $0.1$ s 内。空间远低于 256 MB。

## 7. 参考代码

### C++17

```cpp
#include <bits/stdc++.h>
using namespace std;

// 答案 = popcount(a_i) 为偶数的位置个数
static inline bool good(int v) { return __builtin_popcount((unsigned)v) % 2 == 0; }

int main() {
    ios::sync_with_stdio(false); cin.tie(nullptr);
    int t;
    if (!(cin >> t)) return 0;
    while (t--) {
        int n, q; cin >> n >> q;
        vector<int> a(n);
        int cnt = 0;                        // 偶权元素个数 = 当前答案
        for (int &v : a) { cin >> v; if (good(v)) ++cnt; }
        cout << cnt;
        while (q--) {
            int p, x;
            cin >> p >> x;
            --p;
            if (good(a[p])) --cnt;          // 旧值离开偶权一侧
            a[p] = x;
            if (good(x)) ++cnt;             // 新值进入偶权一侧
            cout << ' ' << cnt;
        }
        cout << '\n';
    }
    return 0;
}
```

### Python3

```python
import sys


def good(v: int) -> bool:
    return bin(v).count("1") % 2 == 0      # 偶权


def main() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    t, pos, out = int(data[0]), 1, []
    for _ in range(t):
        n, q = int(data[pos]), int(data[pos + 1])
        pos += 2
        a, pos = [int(v) for v in data[pos:pos + n]], pos + n
        cnt = sum(1 for v in a if good(v))         # 答案 = 偶权元素个数
        cur = [str(cnt)]
        for _ in range(q):
            p, x = int(data[pos]) - 1, int(data[pos + 1])
            pos += 2
            cnt += good(x) - good(a[p])        # 旧值离开 / 新值进入偶权一侧
            a[p] = x
            cur.append(str(cnt))
        out.append(" ".join(cur))
    sys.stdout.write("\n".join(out) + "\n")


main()
```

## 8. 边界情况与易错点

1. **$q = 0$**：仍要输出 1 个数，别写成「有更新才输出」；$t$ 组各占一行。
2. **$n = 2$**：构造只剩 $i = n-1 = 1$ 一步，位置 1、2 的禁忌都要算，至多 4 个禁忌仍有 4 个可选，判据不变——别因 $n$ 小而加特判。
3. **$a_i = 0$**：$0$ 是偶权（popcount 0）且能被 3 整除，**算 All-Meat**，`__builtin_popcount(0) = 0` 自然给出「算」。
4. **赋值成同值**：$x = a_p$ 时「先减后加」正好抵消；漏掉旧值判断就会让计数漂移。
5. **全奇权 / 全偶权**：答案分别是 $0$ 与 $n$，同一份代码自然得出，无需特判。
6. **输出格式 / 别模拟操作**：每组一行、$q+1$ 个空格分隔整数（官方样例行末带空格也能过，按 token 比较）；操作是假设性的，模拟会让复杂度爆炸，最优值只依赖偶权计数。
