# Codeforces 子序列取反 题解

## 1. 题目概述

- **标题 / 题号**：子序列取反（Codeforces 2247C，英文名 Inversion of a Subsequence）
- **链接**：https://codeforces.com/problemset/problem/2247/C
- **来源**：Codeforces Round 1111 (Div. 2) · Problem C
- **难度**：rating 1100（1250 分）
- **限制**：时间 2 s / 内存 256 MB
- **标签**：贪心，数学，奇偶性分析

**题意**：给定两个长为 $n$ 的 01 数组 $a$ 与 $b$。一次操作分两步：

1. 选出一个**非空**下标序列 $1 \le i_1 < i_2 < \dots < i_k \le n$，要求被选中的元素**在操作当下**的值之和为**奇数**；
2. 把这 $k$ 个元素各自取反（$0 \to 1$，$1 \to 0$）。

求把 $a$ 变成 $b$ 所需的**最少操作次数**，无解输出 $-1$。多测：$t$ 组数据，$\sum n \le 2 \times 10^5$。

**约束**：

- $1 \le t \le 10^4$
- $1 \le n \le 2 \times 10^5$，且所有测试的 $n$ 之和 $\le 2 \times 10^5$
- $a_i, b_i \in \{0, 1\}$

关键难点：合法性条件依赖**操作当下**的数组值，而不是一个固定常量，所以不能只对初始状态做一次静态判断。整道题的核心就是把这个"动态约束"约化成一个计数条件。

- **用例 1**：$a=b$，答案 $0$。
- **用例 2**：$a=[1,0] \to [0,1]$。选 $S=\{1,2\}$，此时和为 $1+0=1$（奇），整体取反即得 $b$，答案 $1$。
- **用例 3**：$a=[1,1,1] \to [0,0,0]$。$S=\{1,2,3\}$ 的和为 $3$（奇），一刀全翻，答案 $1$。
- **用例 4**：$a=[1,0,1,0] \to [0,1,0,1]$。先翻 $\{1,2\}$（和 $1$）得 $[0,1,1,0]$，再翻 $\{3,4\}$（此时 $a_3=1$，和 $1$）得 $[0,1,0,1]$，答案 $2$。
- **用例 5**：差异只在第 $2,4$ 位，都是 $0 \to 1$；而所有相等的位置都是 $1$（借不到"相等的 0"），答案 $-1$。

## 3. 解题思路

### 3.1 暴力思路

把数组看成 $2^n$ 个状态，状态 $x$ 可以连到 $x \oplus S$（$S$ 非空且 $\sum_{i \in S} x_i$ 为奇数），求 $a$ 到 $b$ 的最短路。状态数是 $2^n$，每个状态的出边可达 $2^{n-1}$ 条，总边数 $\Theta(4^n)$ 量级；$n = 2 \times 10^5$ 时彻底不可行。即使写 BFS 打表，也只能看出"答案很小"，结构还得自己推。

小规模打表的结论是：**答案只可能是 $0, 1, 2, -1$ 四种**。于是问题变成"给出 $0/1/2/-1$ 的判定"。

### 3.2 核心观察：只有"1→0 型差异"的个数决定一刀能不能收工

记差异集合与几个计数：

$$D = \{i : a_i \ne b_i\}, \quad p = |\{i \in D : a_i = 1\}|, \quad q = |D| - p, \quad f_0 = |\{i : a_i = b_i = 0\}|, \quad f_1 = |\{i : a_i = b_i = 1\}|$$

把下标按"$a$ 与 $b$ 是否相等、当前是 $0$ 还是 $1$"分成四类：$1\to0$ 型（$p$ 个）、$0\to1$ 型（$q$ 个）、相等的 $1$（$f_1$ 个）、相等的 $0$（$f_0$ 个）。

![四种位置类型与 p 的奇偶性](images/cf2247_c_mismatch_types.svg)

两条最基本的观察：

- **观察 1**：一次操作就是"取反一个集合 $S$"，取反是对合运算，所以做 $m$ 次操作后，位置 $i$ 被取反的次数奇偶性决定它是否改变；要让终态等于 $b$，必须且只需**被取反奇数次的位置集合恰好是 $D$**。
- **观察 2**：如果只用一次操作，那个集合只能是 $D$ 本身，此时 $S$ 中"当前为 1"的个数恰好是 $p$，所以**一次操作可行 $\iff p$ 为奇数**（$D \ne \varnothing$ 时）。

$p$ 为偶数怎么办？关键是想清楚"多出来的操作能当什么用"：

- 若 $p \ge 2$（偶）：$1 \to 0$ 型差异至少有 $2$ 个，可以**把 $D$ 拆成两块**：先单独翻某个 $a=1$ 的差异位（和为 $1$，奇），再翻剩下的 $p-1$ 个差异位（$p-1$ 为奇数）。两块互不相交，第二块的值不受第一块影响，于是 $2$ 次搞定。
- 若 $p = 0$：差异全是 $0 \to 1$ 型，每个差异位当前都是 $0$，任何时刻都"贡献不出 1"，只能**从相等位借两个跳板**：借一个相等的 $1$（把 1 搬运出去）和一个相等的 $0$（接收 1）。两次操作后跳板各自被翻 $2$ 次、原值恢复，差异位各被翻 $1$ 次。

借不到跳板时（$f_0 = 0$ 或 $f_1 = 0$）就是无解，具体见 5 节的引理 5。

### 3.3 算法流程

![判定流程图](images/cf2247_c_decision_flow.svg)

一次线性扫描统计 $p, f_0, f_1$ 与"是否完全相同"，然后按顺序判定：

1. $D = \varnothing$（即 $a = b$）$\Rightarrow 0$；
2. $p$ 为奇数 $\Rightarrow 1$（取 $S = D$）；
3. $p$ 为偶数且 $p > 0$ $\Rightarrow 2$（拆成 $\{u\}$ 与 $D \setminus \{u\}$，$u$ 是任一 $1 \to 0$ 型差异位）；
4. $p = 0$：若同时存在相等的 $1$ 与相等的 $0$ $\Rightarrow 2$（取 $S_1=\{u,v\}$，$S_2 = D \cup \{u,v\}$），否则 $\Rightarrow -1$。

**为什么 $p = 0$ 分支要卡两个条件？** $p = 0$ 时差异位全是 $0$，于是 $f_1 = 0 \iff a$ 全为 $0$，$f_0 = 0 \iff b$ 全为 $1$：前者让数组彻底失去"可操作性"，后者让目标成为"只能出、不能进"的全 $1$ 状态，都是硬性无解（见引理 5）。

### 3.4 示例演算

以自造示例 $a=[1,0,0,1,0]$、$b=[1,1,1,1,0]$ 走一遍：$D=\{2,3\}$（都是 $0\to1$），$p=0$；相等的 $1$ 在位置 $1,4$，相等的 $0$ 在位置 $5$。取跳板 $u=1$、$v=5$。

![p=0 时的跳板构造走查](images/cf2247_c_helper_walkthrough.svg)

第 $1$ 步把"1"从跳板 $1$ 搬到跳板 $5$，第 $2$ 步用这个 1 做"引信"把 $D$ 连同两个跳板一起翻回正确值；位置 $4$ 全程没被碰过，它本来就对。对照 $p$ 为偶数的拆块法（用例 4）：$D=\{1,2,3,4\}$、$p=2$，取 $D_1=\{1\}$、$D_2=\{2,3,4\}$，两次操作的和分别是 $1$ 与 $1$，均为奇数。

## 4. 算法细节

1. **一次扫描**：读入 $a,b$ 后单循环同时维护 `p`（$a_i=1,b_i=0$）、`eq0`、`eq1` 与 `same` 标志，不要为了统计而重复遍历。
2. **判定顺序不可交换**：必须"先 `same`，再 `p 奇偶`，再 `p > 0`，最后才是 $p=0$ 的跳板判断"。把 `same` 放后面，$a=b$ 时会因为 $p=0$ 而误输出 $2$ 或 $-1$。
3. **$p>0$ 且为偶数时一定有解**，哪怕 $q=0$（例如 $[1,1] \to [0,0]$），不要额外加条件。
4. **$p=0$ 分支的两个条件缺一不可**：`eq0 > 0` 与 `eq1 > 0` 必须同时成立；样例 5 正是 `eq0 = 0`。
5. **答案范围**：只会是 $-1,0,1,2$，`int` 足够，无需 `long long`；也没有任何乘法，不存在溢出。
6. **下标**：统一 $0$-indexed 循环到 $n-1$，避免 $1$-indexed 与数组下标的 off-by-one。
7. **多测清空**：`p / eq0 / eq1 / same` 全部声明在每组内部（或每组开头重置），题目 $\sum n \le 2 \times 10^5$，按组分配 `vector` 也不会超时。
8. **I/O**：$t$ 可达 $10^4$，C++ 必须 `std::ios::sync_with_stdio(false)` + `cin.tie(nullptr)`（或直接用 `scanf`）；Python 用 `sys.stdin.buffer.read().split()` 一次性读完，避免逐行 `input()`。

## 5. 正确性证明

**引理 1（操作序列的奇偶刻画）**：设第 $j$ 次操作的集合为 $S_j$（$1 \le j \le m$）。$m$ 次操作后终态等于 $b$，当且仅当 $S_1 \oplus S_2 \oplus \cdots \oplus S_m = D$，其中 $\oplus$ 表示集合对称差。**证明**：取反是对合运算，位置 $i$ 是否改变只取决于"包含 $i$ 的操作个数的奇偶性"，而"包含 $i$ 的操作个数为奇数"正是 $i$ 属于奇数次对称差的含义。因此改变的位置集合恰为对称差，它等于 $D$ 即为终态等于 $b$。∎

**引理 2（一次操作的充要条件）**：若 $D \ne \varnothing$，则 $1$ 次操作可行当且仅当 $p$ 为奇数。**证明**：由引理 1，$m=1$ 时只能取 $S_1 = D$。合法性要求 $S_1$ 中当前 $1$ 的个数为奇数，而 $D$ 中当前为 $1$ 的位置恰是 $1 \to 0$ 型，共 $p$ 个，故需 $p$ 为奇数；反过来 $p$ 为奇数时取 $S_1 = D$ 即合法且能修好全部差异。∎

**引理 3（$p$ 偶且 $p \ge 2$ 时两次足够）**：设 $p$ 为偶数且 $p \ge 2$，则 $2$ 次操作可行。**证明**：任取 $u \in D$ 且 $a_u = 1$（存在性由 $p \ge 2$ 保证），令 $D_1 = \{u\}$，$D_2 = D \setminus D_1$。第一步取 $S_1 = D_1$，其中当前 $1$ 的个数为 $1$，合法。$S_1$ 与 $D_2$ 不相交，故第二步开始时 $D_2$ 上的值未被改动，$S_2 = D_2$ 中当前 $1$ 的个数为 $p - 1$，为奇数，合法。又 $S_1 \oplus S_2 = D$，由引理 1 终态为 $b$。∎

**引理 4（$p = 0$ 且两个跳板齐备时两次足够）**：设 $p = 0$，且 $f_0 \ge 1$、$f_1 \ge 1$，则 $2$ 次操作可行。**证明**：取 $u$ 满足 $a_u = b_u = 1$，$v$ 满足 $a_v = b_v = 0$。令 $S_1 = \{u, v\}$，其和为 $a_u + a_v = 1$，为奇数，合法；操作后 $a_u = 0$、$a_v = 1$，而 $D$ 中所有位置仍为 $0$（$p = 0$ 意味着它们原本就是 $0$，且不与 $S_1$ 相交）。再令 $S_2 = D \cup \{u, v\}$，其中当前为 $1$ 的位置只有 $v$（$u$ 已翻成 $0$，$D$ 中全为 $0$），故和为 $1$，为奇数，合法。由 $S_1 \oplus S_2 = D$ 与引理 1，终态为 $b$。∎

**引理 5（无解的两个来源）**：设 $D \ne \varnothing$，则（a）若 $a$ 全为 $0$ 则无解；（b）若 $b$ 全为 $1$ 则无解。**证明**：（a）任何非空集合 $S$ 都有 $\sum_{i \in S} a_i = 0$，为偶数，因此不存在任何合法操作，$a$ 永恒不变，而 $a \ne b$。∎（b）反设存在能把 $a$ 变成 $b$ 的操作序列，考察它的**最后一次**操作：设操作前数组为 $c$、集合为 $S$。这次操作必须把 $c$ 补成 $b$，即 $c$ 在 $S$ 内部与 $b$ 处处相反（$S$ 外必须已经等于 $b$）。由于 $b$ 处处为 $1$，$c$ 在 $S$ 上处处为 $0$，于是该次操作的和为 $0$，是偶数，与合法性矛盾。∎

**定理（算法正确性）**：上述判定给出的数恰为最少操作次数。**证明**：分情形验证。

- $D = \varnothing$：无需操作，$0$ 显然最小。
- $p$ 奇：引理 2 给出 $1$ 次方案，且 $D \ne \varnothing$ 说明 $0$ 次不行，故最小为 $1$。
- $p$ 偶且 $p \ge 2$：引理 3 给出 $2$ 次方案，引理 2 排除 $1$ 次，故最小为 $2$。
- $p = 0$ 且 $f_0, f_1 \ge 1$：引理 4 给出 $2$ 次方案，引理 2 排除 $1$ 次，故最小为 $2$。
- $p = 0$ 且（$f_0 = 0$ 或 $f_1 = 0$）：由 $p = 0$ 有 $f_0 = 0 \iff b$ 全为 $1$、$f_1 = 0 \iff a$ 全为 $0$，再由引理 5 知无解，输出 $-1$ 正确。

五种情形互斥且穷尽（$p = 0$ 时 $f_0 + f_1 = n > 0$），因此算法对每个输入都返回真实最小值。∎

## 6. 复杂度分析

- **时间**：每组一次线性扫描，$O(n)$；总时间 $O(\sum n) \le 2 \times 10^5$ 次基本运算。实测取最大规模（$t=10^4$ 且 $\sum n = 2 \times 10^5$，以及单组 $n = 2\times 10^5$）时，C++ 用 `scanf` 版本约 $0.02$ s、`cin`（已关闭同步）版本约 $0.28$ s，Python3 约 $0.12$ s，相对 $2$ s 时限余量在 $7$ 倍以上。
- **空间**：存两个长度 $n$ 的数组，$O(n)$；若边读边比（先读 $a$、再读 $b$ 时即时比较）可降到 $O(1)$ 额外空间，实测无需。

## 7. 参考代码

### C++17

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int T;
    cin >> T;
    while (T--) {
        int n;
        cin >> n;
        vector<int> a(n), b(n);
        for (int i = 0; i < n; ++i) cin >> a[i];
        for (int i = 0; i < n; ++i) cin >> b[i];
        int p = 0, eq0 = 0, eq1 = 0;   // 1->0 型差异数 / 相等的 0 / 相等的 1
        bool same = true;
        for (int i = 0; i < n; ++i) {
            if (a[i] != b[i]) {
                same = false;
                if (a[i] == 1) ++p;
            } else if (a[i] == 1) {
                ++eq1;
            } else {
                ++eq0;
            }
        }
        if (same)       cout << 0 << '\n';   // 已经相等
        else if (p & 1) cout << 1 << '\n';   // 一次翻掉 D
        else if (p > 0) cout << 2 << '\n';   // 拆成两块
        else            cout << (eq0 > 0 && eq1 > 0 ? 2 : -1) << '\n';
    }
    return 0;
}
```

### Python3

```python
import sys


def main():
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    out = []
    for _ in range(int(next(it))):
        n = int(next(it))
        a = [int(next(it)) for _ in range(n)]
        b = [int(next(it)) for _ in range(n)]
        p = eq0 = eq1 = 0
        same = True
        for x, y in zip(a, b):
            if x != y:
                same = False
                if x == 1:
                    p += 1
            elif x == 1:
                eq1 += 1
            else:
                eq0 += 1
        if same:
            ans = 0
        elif p & 1:
            ans = 1
        elif p > 0:
            ans = 2
        else:
            ans = 2 if (eq0 > 0 and eq1 > 0) else -1
        out.append(str(ans))
    sys.stdout.write("\n".join(out) + "\n")


main()
```

## 8. 边界情况与易错点

1. **$n = 1$**：$a=b$ 输出 $0$；$a=1,b=0$ 时 $p=1$ 输出 $1$；$a=0,b=1$ 时 $p=0$ 且 $f_1=0$，输出 $-1$（易误写成 $1$ 或 $2$）。
2. **$a$ 全 $0$ 而 $b$ 有 $1$**：输出 $-1$，不是 $2$——全 $0$ 数组没有任何合法操作。
3. **$b$ 全 $1$ 而 $a$ 不全为 $1$**：输出 $-1$，例如 $n=2$ 的 $[1,0] \to [1,1]$ 与样例 5 的 $[1,0,1,0,1] \to [1,1,1,1,1]$（都是 $p=0$、$f_0=0$）。这条最反直觉：全 $1$ 状态没有任何入边。
4. **$p$ 为偶数但 $p>0$**：一定是 $2$，不要因为 $q$ 的取值或 $f_0 = f_1 = 0$ 而误判无解。
5. **$a = b$ 的优先级**：此时 $p=0$、$f_0+f_1=n$，若把 `same` 判定放最后，可能输出 $2$（当 $f_0,f_1>0$）或 $-1$（当全部为 $0$ 或全部为 $1$），样例 1 会挂。
6. **多测残留**：`p/eq0/eq1/same` 必须每组重置；跨组残留是这类签到题最常见的 WA 原因。
7. **输出格式**：每组一行，$-1$ 用普通减号即可；不要多输出空格或多余换行。

**延伸思考**：

1. 若把合法性从"和为奇数"改成"和为偶数"：一次操作就需要 $S$ 中 $1$ 的个数为偶数，$S = D$ 要求 $p$ 为偶数；同时全 $0$ 数组反而"处处可操作"，无解的两个来源整体改变。可以按本文同样的"构造 + 不可能性"框架重新推一遍，答案仍是常数级。
2. 若要求每次选出的子序列长度恰为 $3$：$p=1$ 时"单点 + 拆块"的构造失效（单元素集合不再合法），需要重新分析可达性，答案上界也会从 $2$ 变大。
3. 若元素取值扩到 $\{0,1,2\}$、合法性改为"和模 $3$ 不为 $0$"：差异类型从 $4$ 种变 $6$ 种，运算从 $\mathbb{F}_2$ 上的异或变成 $\mathbb{Z}_3$ 上的取补，"借跳板"需要借两个互补的值，可以用"小规模枚举 + 大块批量处理"的方式推广。
