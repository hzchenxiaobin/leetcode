# Codeforces 骚扰幽灵 题解

## 1. 题目概述

- **标题 / 题号**：骚扰幽灵（Codeforces 2237B，英文名 Annoying the Ghost）
- **链接**：https://codeforces.com/problemset/problem/2237/B
- **来源**：Order Capital Round 2 (Codeforces Round 1104, Div. 1 + Div. 2) · Problem B
- **难度**：rating 1000（1000 分）
- **限制**：时间 1.5 s / 内存 256 MB
- **标签**：贪心、暴力枚举、匹配、逆序对（相邻交换）

**题意**：幽灵 Ja 面前有 $n$ 堆橡皮鸭排成一行，第 $i$ 堆有 $a_i$ 只。鸭子 Quack 给出一个**严格递增**的序列 $b_1 < b_2 < \cdots < b_n$，要求 Ja 分两个阶段把 $a$ 变成 $b$：

1. **加法阶段**：每堆 $i$ 选一个非负整数 $x_i$，把 $a_i$ 变成 $a_i + x_i$；
2. **交换阶段**：任意次交换**相邻**两堆。

两阶段结束后序列必须**恰好**是 $b$。求交换阶段的最少操作次数；若不存在合法过程，输出 $-1$。

**约束**：

- $1 \le t \le 2000$ 组测试，且 $\sum n \le 2000$；
- $1 \le a_i \le 10^9$，$1 \le b_1 < b_2 < \cdots < b_n \le 10^9$；
- 答案不超过 $\dfrac{n(n-1)}{2} \le 2\times 10^6$。

## 3. 解题思路

### 3.1 暴力思路

交换阶段只能**重排**数值、不改变多重集；加法阶段只能**增大**。于是最终多重集必须恰为 $\{b_1,\dots,b_n\}$，且位置 $i$ 上的最终值必须是某个 $b_j \ge a_i$。

最朴素的做法是枚举「位置 $\to$ 目标值」的全部 $n!$ 种排列，逐个检查 $b_{p_i} \ge a_i$，再数逆序对取最小。$n = 7$ 时 $7! = 5040$ 尚可，$n = 2000$ 时完全不可行；即使只判定可行性也躲不开指数级搜索。

### 3.2 核心观察：后缀允许集合 + 逆序对

![加法即认领目标值，答案即认领序列的逆序对](images/cf2237_b_matching_concept.svg)

把「位置 $i$ 最终变成 $b_j$」看成**位置 $i$ 认领槽位 $j$**。因为 $b$ 严格递增，位置 $i$ 能认领的槽位集合是一个**后缀**：

$$L_i = \min\{\, j : b_j \ge a_i \,\},\qquad \text{位置 } i \text{ 可认领 } j \in [L_i, n]$$

（若 $a_i > b_n$ 则 $L_i$ 不存在，直接无解。）加法阶段恰好是一组**完美匹配**：每个位置认领一个合法槽位，每个槽位恰好被认领一次——这只要求 $x_i = b_{p_i} - a_i \ge 0$，没有别的限制。

交换阶段的代价同样是干净的：$b$ 严格递增，最终顺序就是槽位下标的升序，所以把认领序列 $p = (p_1,\dots,p_n)$ 变成升序所需的最少相邻交换次数**恰好是 $p$ 的逆序对数**。

于是原问题化为：**在「位置 $i$ 只能选 $[L_i,n]$ 中的槽位、每槽恰用一次」的约束下，最小化认领序列的逆序对数。**

### 3.3 算法流程：从左到右取最小可用槽位

![贪心流程](images/cf2237_b_greedy_flow.svg)

**贪心**：$i$ 从 $1$ 到 $n$，在**尚未被占用**的槽位里，取**下标最小**的 $j$ 满足 $b_j \ge a_i$，把它认领给位置 $i$；若一个都找不到，输出 $-1$。实现上无需预计算 $L_i$：从 $j=1$ 开始扫，第一个满足「未占用且 $b_j \ge a_i$」的就是最小合法槽位。最后统计 $p$ 的逆序对数。

为什么「取最小」是对的？直觉是：小槽位现在不用，之后也只会被别的（约束更松的）位置占走，而拿着大槽位会让序列更早出现大下标，逆序对只会更多。严格论证见第 5 节的交换论证。

### 3.4 示例演算

![样例 10 的逐步认领](images/cf2237_b_walkthrough.svg)

以第 10 组为例：$a = (10,3,8,6,9)$，$b = (3,6,8,9,10)$。

| 步骤 $i$ | $a_i$ | 最小合法槽 $L_i$ | 此前已占用 | 认领 $p_i$ |
|----------|-------|------------------|------------|------------|
| 1 | 10 | 5（$b_5=10$） | 空集 | 5 |
| 2 | 3 | 1（$b_1=3$） | $\{5\}$ | 1 |
| 3 | 8 | 3（$b_3=8$） | $\{5,1\}$ | 3 |
| 4 | 6 | 2（$b_2=6$） | $\{5,1,3\}$ | 2 |
| 5 | 9 | 4（$b_4=9$） | $\{5,1,3,2\}$ | 4 |

得到 $p = (5,1,3,2,4)$，逆序对为 $(5,1),(5,3),(5,2),(5,4),(3,2)$，共 $5$ 个，与官方输出一致。

## 4. 算法细节

1. **不必预计算 $L_i$**：$b$ 递增，从 $j=1$ 往右扫，遇到的第一个「未占用且 $b_j \ge a_i$」的 $j$ 就是本次的最小合法槽位；单次 $O(n)$，总计 $O(n^2)$。
2. **可行性顺带判定**：某一步找不到槽位即无解；不必额外检查「排序后的 $a$ 逐项不超过 $b$」，贪心失败本身就等价于无解（引理 4）。
3. **逆序对计数**：$n \le 2000$，双层循环 $2\times10^6$ 次即可，也可以树状数组 $O(n\log n)$；C++ 版用双层循环（常数最小），Python 版用树状数组，实测都远低于时限。
4. **答案上界**：$\text{inv}(p) \le \frac{n(n-1)}{2} \approx 2\times 10^6$，`int` 也装得下，但代码里用 64 位更保险（防止以后改数据范围）。
5. **多测无状态**：$\sum n \le 2000$，每组重建 `used`/`p` 即可，不需要清空任何全局结构。
6. **读入规模**：$a_i, b_i \le 10^9$ 用 `int` 够；比较 `b[j] >= a[i]` 时两边同为 `int`，不会溢出。Python 直接用 `int`。

## 5. 正确性证明

**引理 1（认领 ↔ 加法阶段）**：存在合法过程 $\iff$ 存在排列 $p$ 使 $b_{p_i} \ge a_i$ 对一切 $i$ 成立。

**证明**：设加法后数组为 $c_i = a_i + x_i$。交换只重排元素，故 $\{c_i\}$ 与 $\{b_i\}$ 作为多重集相等；$b$ 严格递增故元素互不相同，于是存在唯一双射 $i \mapsto p_i$ 使 $c_i = b_{p_i}$，且 $x_i \ge 0 \iff b_{p_i} \ge a_i$。反过来，给定满足条件的 $p$，取 $x_i = b_{p_i} - a_i \ge 0$，再冒泡排序即可得到 $b$，过程合法。∎

**引理 2（交换次数 = 逆序对）**：给定合法排列 $p$，第二阶段的最少相邻交换次数为 $\operatorname{inv}(p)$。

**证明**：一次相邻交换只会让逆序对数改变 $\pm 1$，而升序排列的逆序对为 $0$，故任何方案至少需要 $\operatorname{inv}(p)$ 次；另一方面冒泡排序每一步恰好消去一个逆序对，共 $\operatorname{inv}(p)$ 步即可把序列排成槽位升序，也就是 $b$。下界可达。∎

**引理 3（最小可用槽位是安全选择）**：设某步剩余位置为 $i,\dots,n$、剩余槽位集合为 $S$，令 $m = \min\{j \in S : b_j \ge a_i\}$。若剩余问题有合法完美匹配，则存在一个逆序对最少的匹配把位置 $i$ 配给 $m$。

**证明**：取任一最优匹配 $p$。若 $p_i = m$ 已成立。否则 $p_i = q \in S$ 且 $q > m$（$m$ 合法且最小）。因 $p$ 是完美匹配，$m$ 必被某个位置 $j \in \{i+1,\dots,n\}$ 占用。交换配额：令 $p'_i = m$、$p'_j = q$，其余不变。

- 合法性：$p_j = m$ 说明 $b_m \ge a_j$，而 $q > m$ 给出 $b_q > b_m \ge a_j$，位置 $j$ 仍合法；位置 $i$ 由 $b_m \ge a_i$ 合法。所以这一交换对任何合法匹配都可用，与最优性无关。
- 逆序对：只有涉及 $i$、$j$ 的对会变。(i) 对子 $(i,j)$ 原本是逆序（$q > m$），现在不是，减 $1$；(ii) 对中间位置 $x$（$i < x < j$），记 $v = p_x$，原贡献为 $[q > v] + [v > m]$，新贡献为 $[m > v] + [v > q]$，按 $v < m$、$m < v < q$、$v > q$ 三种情形分别为 $1 \to 1$、$2 \to 0$、$1 \to 1$，都不增加。

于是 $\operatorname{inv}(p') \le \operatorname{inv}(p) - 1 < \operatorname{inv}(p)$，与 $p$ 最优矛盾；所以任何最优匹配都满足 $p_i = m$。∎

**引理 4（贪心失败即无解）**：若贪心在第 $i$ 步找不到合法槽位，则不存在任何合法过程。

**证明**：由引理 3 的交换构造（它只依赖合法性）对前 $i-1$ 步逐个归纳可知：只要存在合法匹配，就存在一个与贪心在位置 $1..i-1$ 上完全一致的合法匹配，于是这 $i-1$ 个位置恰好占用了 $S$ 的补集。位置 $i$ 只能从 $S$ 中选槽位，而 $S$ 中每个 $j$ 都满足 $b_j < a_i$（否则贪心第 $i$ 步不会失败），矛盾。∎

**定理**：算法输出的值等于所有合法过程的最小交换次数；无合法过程时输出 $-1$。

**证明**：由引理 3 归纳，贪心每一步的取值都能被某个最优匹配跟上，故最终得到的 $p$ 满足 $\operatorname{inv}(p) = \min\{\operatorname{inv}(p') : p' \text{ 合法}\}$；再由引理 1、引理 2，该值正是最小交换次数。若贪心中途失败，由引理 4 无解，输出 $-1$ 正确。∎

## 6. 复杂度分析

- **时间**：每组 $O(n^2)$——匹配阶段每个位置最多扫 $n$ 个槽位；逆序对用双层循环也是 $O(n^2)$（树状数组则 $O(n\log n)$）。由 $\sum n \le 2000$，最坏情况（单组 $n = 2000$）约 $4\times10^6 + 2\times10^6$ 次基本操作。
- **空间**：$O(n)$，只需 `a`、`b`、`used`、`p` 四个长度 $n$ 的数组（树状数组再 $O(n)$）。
- **与时限的对照**：实测 $n=2000$ 且答案为 $1999000$ 的最坏数据，C++ 约 $4$ ms（含进程启动开销，计时器读数 $3.5\sim4.6$ ms），相对 $1.5$ s 时限留有三个数量级余量；Python3 约 $120$ ms 也能直接通过，但若把逆序对换成 $O(n^2)$ 的双层循环 Python 写法，请注意常数，建议 PyPy 或改用树状数组。

## 7. 参考代码

### C++17

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int t;
    if (scanf("%d", &t) != 1) return 0;
    while (t--) {
        int n;
        scanf("%d", &n);
        vector<long long> a(n), b(n);
        for (int i = 0; i < n; i++) scanf("%lld", &a[i]);
        for (int i = 0; i < n; i++) scanf("%lld", &b[i]);

        // 贪心认领：从左到右，每个位置取「下标最小且未占用、值不小于 a[i]」的槽位
        vector<int> p(n, -1);
        vector<char> used(n, 0);
        bool ok = true;
        for (int i = 0; i < n && ok; i++) {
            int pick = -1;
            for (int j = 0; j < n; j++) {
                if (!used[j] && b[j] >= a[i]) { pick = j; break; }
            }
            if (pick < 0) { ok = false; break; }
            used[pick] = 1;
            p[i] = pick;
        }
        if (!ok) { puts("-1"); continue; }

        // 交换阶段的最少次数 = 认领序列的逆序对数
        long long inv = 0;
        for (int i = 0; i < n; i++)
            for (int j = i + 1; j < n; j++)
                if (p[i] > p[j]) inv++;
        printf("%lld\n", inv);
    }
    return 0;
}
```

### Python3

```python
import sys


def main() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    t = int(data[0])
    pos = 1
    out = []
    for _ in range(t):
        n = int(data[pos]); pos += 1
        a = list(map(int, data[pos:pos + n])); pos += n
        b = list(map(int, data[pos:pos + n])); pos += n

        # 贪心认领
        used = [False] * n
        perm = [-1] * n
        ok = True
        for i in range(n):
            pick = -1
            for j in range(n):
                if not used[j] and b[j] >= a[i]:
                    pick = j
                    break
            if pick < 0:
                ok = False
                break
            used[pick] = True
            perm[i] = pick
        if not ok:
            out.append("-1")
            continue

        # 树状数组统计逆序对：从右往左插入，查询比当前值小的已插入元素个数
        tree = [0] * (n + 1)
        inv = 0
        for i in range(n - 1, -1, -1):
            k = perm[i]
            while k > 0:
                inv += tree[k]
                k -= k & -k
            k = perm[i] + 1
            while k <= n:
                tree[k] += 1
                k += k & -k
        out.append(str(inv))

    sys.stdout.write("\n".join(out) + "\n")


if __name__ == "__main__":
    main()
```

## 8. 边界情况与易错点

1. **$a_i > b_n$**：最小的合法槽位都不存在，答案为 $-1$；样例 3 就是这种情形，不能输出 $0$ 或空答案。
2. **整体不匹配**：例如 $a = (3,3)$、$b = (1,5)$，两个位置都需要槽位 $2$，贪心在第二位置失败 ⇒ $-1$。「每个 $a_i \le b_n$」**只是必要条件**，不能代替可行性判定。
3. **$n = 1$**：只有一个槽位，$a_1 \le b_1$ 时答案为 $0$，否则 $-1$；循环与逆序对计数都要能正确处理 $n=1$（逆序对为 $0$）。
4. **$a$ 与 $b$ 完全相同**：加法阶段全取 $x_i = 0$，答案 $0$；不要误以为必须先「补齐」再排序。
5. **$a$ 严格递减**：逆序对达到 $\frac{n(n-1)}{2}$，这是答案上界；$n=2000$ 时为 $1999000$，用 `int` 也不会溢出，但建议 `long long`。
6. **重复值**：$a$ 里可以有很多相同的值，而 $b$ 严格递增——必须按**下标**（槽位）而不是按数值相等去配对，否则会漏掉合法的槽位分配。
7. **拿大槽位不一定更好**：例如在 $a=(2,3)$、$b=(2,3)$ 中给位置 1 挑槽位 2 虽然合法，但会多出 $1$ 个逆序对；贪心必须取**最小**的合法槽位。

- [Codeforces 2237A. Destroying Towers](https://codeforces.com/problemset/problem/2237/A)：同场 A 题，博弈 + 贪心，适合作为热身。

**延伸思考**：

1. **$b$ 只非降（允许相等）**：此时槽位 $j$ 与 $j'$ 的 $b$ 值可能相同，相同值之间可以自由互换，最优做法是「相同值按原下标顺序贪心配对」，等价于把每个 $b$ 值替换成它第一次出现的下标后套用本题。
2. **把相邻交换换成任意交换**：答案会变成 $n - (\text{置换 } p \text{ 的环数})$，因为一次任意交换可以修正一个环；此时贪心的目标也随之改变，不再与逆序对挂钩。
3. **同时允许减少鸭子**：每个位置的可选值变成区间 $[L_i, R_i]$，最小逆序对匹配不再有简单贪心，一般要用 DP 或费用流（把「越界」当作惩罚）。
4. **可迁移的贪心证明模板**：这类「按顺序决策 + 交换两个决策不使目标变差」的证明，通常只需按被交换的两点之间第三点的取值分三段讨论，本题的三段就是 $v < m$、$m < v < q$、$v > q$。
