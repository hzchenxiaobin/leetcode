# LeetCode 链表最大孪生和 题解

## 1. 题目概述

- **标题 / 题号**：链表最大孪生和（#2130，medium）
- **链接**：https://leetcode.cn/problems/maximum-twin-sum-of-a-linked-list/
- **来源**：LeetCode 第 69 场双周赛 Q2
- **难度**：中等
- **标签**：栈、链表、双指针

**题意**：给一个长度为 $n$（$n$ 为偶数）的链表，节点下标从 $0$ 开始。对 $0 \le i \le n/2 - 1$，第 $i$ 个节点的**孪生节点**是第 $(n-1-i)$ 个节点。**孪生和** = 节点值与其孪生节点值之和。返回所有孪生和的最大值。

**约束**：

- 节点数目是 $[2, 10^5]$ 中的**偶数**；
- $1 \le \text{Node.val} \le 10^5$。

## 2. 示例

**示例 1**

```text
输入：head = [5,4,2,1]
输出：6
解释：节点 0 与节点 3 孪生（5+1=6），节点 1 与节点 2 孪生（4+2=6），最大孪生和为 6。
```

**示例 2**

```text
输入：head = [4,2,2,3]
输出：7
解释：节点 0 与节点 3 孪生（4+3=7），节点 1 与节点 2 孪生（2+2=4），最大孪生和为 7。
```

**示例 3**

```text
输入：head = [1,100000]
输出：100001
解释：链表只有一对孪生节点，和为 1 + 100000 = 100001。
```

## 3. 解题思路

### 3.1 暴力思路

链表不支持随机访问，最朴素的做法是把值全部倒进数组 `vals`，再 `max(vals[i] + vals[n-1-i] for i in range(n//2))`。时间 $O(n)$、空间 $O(n)$，完全能过。变体是用栈：顺序入栈后逐个出栈，恰好按倒序与链表前半配对——这就是官方标签里"栈"的来由。两种做法都要 $O(n)$ 辅助空间。本题真正的考点是：**能否只用 $O(1)$ 额外空间**做到？

### 3.2 核心观察：孪生 = "对折"，前半与后半一一配对

![孪生节点：把链表"对折"，下标 i 配 n−1−i](images/bw69_q2_twin_model.svg)

孪生对的定义本质上是把链表**沿中线对折**：下标 $i$ 与 $n-1-i$ 粘在一起。由于 $n$ 是偶数，每个孪生对**恰好一个节点落在前半段、一个落在后半段**，共 $n/2$ 对，不存在跨前半段内部的配对。于是答案只取决于"前半段每个节点 × 它在后半段的镜像位置"。如果我们能**同时从前半段的头、后半段的尾开始向中间同步推进**，就能逐对计算。链表只能单向走，后半段是"倒着"需要的——这提示我们**反转后半段**：反转后，从后半段的头（原尾）出发恰好按倒序访问。

### 3.3 算法流程：快慢指针 + 反转 + 双指针

![快慢指针找中点，反转后半段，再双指针同行](images/bw69_q2_fast_slow_reverse.svg)

```text
1. 快慢指针：slow 一次一步、fast 一次两步，
   循环条件 fast->next && fast->next->next
   → slow 停在"前半段最后一个节点"（n 为偶数时）
2. 反转 slow->next 开始的后半段，得新链表头 b
3. a = head，b = 反转后的头；同步前进：
   ans = max(ans, a->val + b->val)
   直到 b 走到头（恰好 n/2 步）
4. 返回 ans
```

为什么 `slow` 恰好停在前半段末尾？$n$ 为偶数时，设 $n = 2k$。`fast` 从 `head` 出发每次两步，循环在 `fast->next == null`（fast 到达第 $2k-1$ 个节点，即尾节点）时停止；此时 `slow` 走了 $k-1$ 步，位于下标 $k-1$ —— 正是前半段（下标 $0 \ldots k-1$）的最后一个节点。反转 `slow->next`（即下标 $k$ 起）后，`b` 依次访问原下标 $2k-1, 2k-2, \ldots, k$，与 `a` 访问的 $0, 1, \ldots, k-1$ 恰好构成 $k$ 个孪生对。

### 3.4 示例演算

![演算：两个长度为 4 的链表的对折求和过程](images/bw69_q2_example_walkthrough.svg)

以 `[4,2,2,3]` 为例：`slow` 停在第二个节点（值 2），反转后半 `2→3` 得 `3→2`；双指针同行：$4+3=7$，$2+2=4$，答案 $7$。最小规模 $n=2$ 时快慢指针循环一次都不进，`slow` 停在节点 0，反转后直接配对一次即得答案，无需特判。

## 4. 算法细节

1. **快慢指针的停止条件**：用 `fast->next && fast->next->next` 而非 `fast && fast->next`。前者在 $n$ 为偶数时让 `slow` 停在**前半末节点**（下标 $n/2 - 1$）；后者会让 `slow` 停在**后半首节点**（下标 $n/2$），反转区间就错了。这是本题最容易写错的一行。
2. **反转的边界**：从 `slow->next` 开始反转，`slow` 本身保持指向前半末节点；反转后 `slow->next` 仍指向原后半首节点（现在成为反转链的尾），但我们不再用它——双指针走 `n/2` 步自然停。
3. **循环终止用 `b != null`**：反转链长度恰为 $n/2$，`b` 走到空时 `a` 也恰好走完前半，两边同步，不会多算或漏算。
4. **无需恢复链表**：题目只要求返回数值，反转造成的结构破坏无影响。若在真实工程中需要保持入参不变，可再反转一次复原。
5. **数值范围**：$2 \times 10^5 < 2^{31} - 1$，`int` 足够；但把"链表值求和"默认写成 `long long` 是更安全的肌肉记忆。
6. **数组化写法的对照**：如果允许 $O(n)$ 空间，`vals[i] + vals[n-1-i]` 的写法 3 行搞定，可作为对拍基准（本文验证即用它）。

## 5. 正确性证明

**引理 1（中点位置）**：$n$ 为偶数时，上述快慢指针循环结束时 `slow` 位于下标 $n/2 - 1$ 的节点。

**证明**：设 $n = 2k$。循环第 $t$ 轮开始时（$t$ 从 1 计），`fast` 在下标 $2(t-1)$，`slow` 在下标 $t-1$。循环继续当且仅当 $2(t-1)+1 \le 2k-1$ 且 $2(t-1)+2 \le 2k-1$，即 $t \le k-1$。故循环恰好执行 $k-1$ 轮后停止，此时 `slow` 在下标 $k-1 = n/2 - 1$，`fast` 在下标 $2k-2$（其 `next` 为尾节点 $2k-1$，`next->next` 为空，条件失败）。∎

**引理 2（反转后的配对序列）**：设原链节点值序列为 $v_0, v_1, \ldots, v_{n-1}$。反转下标 $n/2 \ldots n-1$ 的后缀后，从反转链头出发依次读到的值为 $v_{n-1}, v_{n-2}, \ldots, v_{n/2}$。

**证明**：反转操作把后缀的指针方向逐个调转，链遍历顺序由 $v_{n/2} \rightarrow \cdots \rightarrow v_{n-1}$ 变为 $v_{n-1} \rightarrow \cdots \rightarrow v_{n/2}$，值序列恰为原后缀的倒序。∎

**定理（算法正确）**：算法返回 $\max_{0 \le i \le n/2 - 1} \left( v_i + v_{n-1-i} \right)$，即所求最大孪生和。

**证明**：由引理 1，`a` 从 $v_0$ 出发；由引理 2，`b` 从 $v_{n-1}$ 出发。双指针第 $t$ 步（$t = 0, 1, \ldots$）时 `a` 指向 $v_t$、`b` 指向 $v_{n-1-t}$，累加的正是第 $t$ 对孪生和。反转链长为 $n/2$，故循环恰执行 $n/2$ 次，遍历全部 $n/2$ 个孪生对后 `b` 为空退出。`max` 覆盖所有对，故返回值为全体孪生和的最大值。∎

## 6. 复杂度分析

- **时间**：$O(n)$。快慢指针走 $n/2$ 轮，反转后半段访问 $n/2$ 个节点，双指针同行 $n/2$ 步，总计不超过 $1.5n$ 次指针操作。
- **空间**：$O(1)$。只用了 `slow/fast/prev/cur/a/b` 等常数个指针变量，不修改值、不建数组。数组化写法为 $O(n)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int pairSum(ListNode* head) {
        ListNode *slow = head, *fast = head;
        while (fast->next && fast->next->next) {   // n 为偶数：slow 停在前半段最后一个节点
            slow = slow->next;
            fast = fast->next->next;
        }
        ListNode* b = reverse(slow->next);         // 反转后半段
        ListNode* a = head;
        int ans = 0;
        while (b) {                                // 双指针同步走，枚举全部 n/2 个孪生对
            ans = max(ans, a->val + b->val);
            a = a->next;
            b = b->next;
        }
        return ans;
    }
private:
    ListNode* reverse(ListNode* head) {
        ListNode* prev = nullptr;
        while (head) {
            ListNode* nxt = head->next;
            head->next = prev;
            prev = head;
            head = nxt;
        }
        return prev;
    }
};
```

### Python

```python
class Solution:
    def pairSum(self, head: Optional[ListNode]) -> int:
        slow = fast = head
        while fast.next and fast.next.next:     # n 为偶数：slow 停在前半段最后一个节点
            slow, fast = slow.next, fast.next.next
        prev, cur = None, slow.next             # 反转后半段
        while cur:
            cur.next, prev, cur = prev, cur, cur.next
        ans = 0
        a, b = head, prev
        while b:                                # 双指针同步走，枚举全部 n/2 个孪生对
            ans = max(ans, a.val + b.val)
            a, b = a.next, b.next
        return ans
```

> 💡 两份代码均通过官方示例（`6`、`7`、`100001`）以及 3000 组随机偶数长链表与数组化暴力（`max(vals[i] + vals[n-1-i])`）的对拍，`mismatch = 0`。

## 8. 边界情况与易错点

1. **$n = 2$ 最小规模**：快慢指针循环零次执行，`slow` 就是节点 0，反转其后（唯一的节点 1）得单节点链，双指针恰走一步。无需任何特判——但要确认 `fast->next->next` 在 $n=2$ 时不会解引用空指针（`fast->next` 为尾节点非空，但短路求值下 `fast->next->next` 只有在 `fast->next` 非空时才求值，安全）。
2. **停止条件的两种写法**：`fast->next && fast->next->next`（slow 到前半末）vs `fast && fast->next`（slow 到后半首）。本题用前者；若误用后者，反转区间应改为"从 slow 开始"，且 $n$ 为奇数时两者行为不同——但本题 $n$ 恒为偶数，坑只剩"反转哪一段"。
3. **不要破坏前半段**：反转必须从 `slow->next` 开始，若从 `slow` 开始会把前半末节点也卷进反转，双指针走位错乱。
4. **`a` 指针不要越过中线**：循环条件用 `b`（短的那条反转链）判停；若用 `a` 判停在偶数长度下恰好同长不会错，但语义上以 `b` 为准更稳。
5. **值上界**：$10^5 + 10^5 = 2 \times 10^5$，`int` 无溢出风险（C++ `int` 上界约 $2.1 \times 10^9$）。
6. **空链表不会出现**：约束 $n \ge 2$，`head` 必非空，可放心解引用。
