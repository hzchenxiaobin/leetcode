# LeetCode 连接两字母单词得到的最长回文串 题解

## 1. 题目概述

- **标题 / 题号**：连接两字母单词得到的最长回文串（#2131，medium）
- **链接**：https://leetcode.cn/problems/longest-palindrome-by-concatenating-two-letter-words/
- **来源**：LeetCode 第 69 场双周赛 Q3
- **难度**：中等
- **标签**：贪心、数组、哈希表、字符串、计数

**题意**：给一个字符串数组 `words`，每个元素是**恰好两个小写字母**的单词。从中选择一些元素按任意顺序连接（每个元素至多用一次），拼出一个**尽可能长的回文串**，返回能得到的最大长度；拼不出任何回文串时返回 $0$。

**约束**：

- $1 \le \text{words.length} \le 10^5$；
- $\text{words[i].length} = 2$，仅含小写英文字母。

## 2. 示例

**示例 1**

```text
输入：words = ["lc","cl","gg"]
输出：6
解释："lc" + "gg" + "cl" = "lcggcl"，长度 6；"clgglc" 同样合法。
```

**示例 2**

```text
输入：words = ["ab","ty","yt","lc","cl","ab"]
输出：8
解释："ty" + "lc" + "cl" + "yt" = "tylcclyt"，长度 8；多出的 "ab" 没有镜像搭档，弃用。
```

**示例 3**

```text
输入：words = ["cc","ll","xx"]
输出：2
解释：只能选一个单词（如 "cc"）当回文；任意两个连接（如 "ccll"）都不是回文。
```

## 3. 解题思路

### 3.1 暴力思路

枚举 `words` 的所有子集（$2^n$ 种），对每个子集枚举全排列验证回文——$O(2^n \cdot n!)$ 天文数字，$n \le 10^5$ 下无从谈起。即便只是"判断哪些子集能拼成回文"，也必须先看结构。本题的关键是注意到**单词长度恒为 2**：回文中位置 $p$ 与镜像位置 $\text{len}-1-p$ 上的两个单词 $w, w'$ 必须满足 $w' = \text{reverse}(w)$（首尾镜像）。于是问题从"排列组合"坍缩成"**计数配对**"：统计每种单词出现次数，研究 $cnt[w]$ 与 $cnt[\text{rev}(w)]$ 如何配对。这一步转化才是本题考点；对拍时小规模子集枚举暴力（$n \le 6$）仍可作验证基准。

### 3.2 核心观察：镜像配对 + 自身回文词的中心特权

![回文镜像约束：左放 "ab" ⇒ 右必须放 "ba"](images/bw69_q3_pairing_model.svg)

把拼出的回文串按单词边界切开，回文的性质意味着：**第 $p$ 个单词（从头数）与倒数第 $p$ 个单词互为字符翻转**。单词只有两个字母，翻转即"首尾互换"，于是所有单词被分成两类：

1. **互异词对**（$a \ne b$，如 `"lc"` 与 `"cl"`）：`"lc"` 想出现在左半，右半对称位置必须有一个 `"cl"`。两者组成一对，贡献长度 $4$。能配的对数是 $\min(cnt[\text{"ab"}], cnt[\text{"ba"}])$——多出来的那部分没有搭档，只能弃用。
2. **自身回文词**（$a = b$，如 `"gg"`）：翻转后仍是自身。两个 `"gg"` 可以一左一右对称放置，贡献 $4$；**单个** `"gg"` 还能占据正中间（中心两侧无镜像要求，只要它自己回文），贡献 $2$。

用 $26 \times 26$ 的计数矩阵 $cnt[i][j]$（$i, j$ 为两个字母的下标）代替哈希表，地址连续、常数更小。

### 3.3 算法流程：计数 + 三块累加 + 中心贪心

![中心贪心：奇数个 "aa" 类单词，恰留一个在正中](images/bw69_q3_center_greedy.svg)

```text
1. 统计 cnt[26][26]：cnt[i][j] = 单词 (i,j) 的出现次数
2. ans = 0
   对所有 i < j：                       # 互异对，(i,j) 与 (j,i) 只统计一次
       ans += min(cnt[i][j], cnt[j][i]) * 4
3. center = false
   对所有 i：                            # 自身回文词 (i,i)
       ans += cnt[i][i] / 2 * 4          # 两两对称放置
       若 cnt[i][i] % 2 == 1：center = true
4. 若 center：ans += 2                   # 正中间还能塞一个
5. 返回 ans
```

**中心贪心的正确直觉**：任何 cnt[i][i] 的奇数余量单词都可以放中心，但**中心至多一个**——两个自身回文词都往中间放，它们的拼接处（……"aa"|"bb"……）不再是回文，除非它们本来就配成一对（那样已计入第 3 步的 $\lfloor cnt/2 \rfloor$）。所以只要**任一** $cnt[i][i]$ 为奇，就白拿 2 的中心增益，与选哪个无关。

### 3.4 示例演算

![三个官方示例的计数与贪心过程](images/bw69_q3_example_walkthrough.svg)

| 示例 | 互异对贡献 | 自配对贡献 | 中心 | 合计 |
|------|-----------|-----------|------|------|
| 1 `["lc","cl","gg"]` | $\min(1,1) \times 4 = 4$ | $cnt[\text{gg}]=1$：$0 \times 4 = 0$ | 有（奇余量 gg）$+2$ | $6$ |
| 2 `["ab","ty","yt","lc","cl","ab"]` | ty/yt $4$ + lc/cl $4$ = $8$ | 无 aa 类 | 无 | $8$ |
| 3 `["cc","ll","xx"]` | $0$ | 每种 $1$ 个：$0 \times 4$ | 有（三种都是奇）$+2$ | $2$ |

示例 3 最能体现"中心只需一个"：三个自身回文词各余 1 个，但只有正中间一个位置，`ll`、`xx` 只能弃用。

## 4. 算法细节

1. **计数结构选 $26\times26$ 数组而非哈希表**：单词两字母，共 $676$ 种，数组下标 $c_0 \times 26 + c_1$ 直接寻址，比 `unordered_map` 快数倍，还免去哈希开销。C++ 用 `int cnt[26][26] = {}` 即可。
2. **互异对只统计一次**：循环 `for i in 0..25, for j in i+1..25`，避免 `"ab"` 与 `"ba"` 各算一遍导致翻倍。若写成对角线两侧都统计，需要除以 2，容易出错。
3. **自身回文词的整除与余数**：$cnt[i][i] / 2$ 对（取整）对称放置贡献 $4 \times \lfloor cnt/2 \rfloor$；余数 $cnt \% 2$ 只影响 center 布尔值。注意 $cnt=1$ 时贡献为 0 但置 center = true——单个 aa 类单词自己就是长度 2 的回文。
4. **center 判定与顺序无关**：不关心哪个字母的余量触发，任一奇数即 $+2$；这意味着第 3 步循环里只需一个布尔累积。
5. **贪心的完整性**：第 2 步取 $\min$ 是显式的"能配多少配多少"；第 3 步把 aa 类两两配完后，剩余至多每种 1 个，其中恰一个可进中心。三块加总即最优（证明见 §5）。
6. **答案初值**：`words` 非空（$n \ge 1$），但若唯一单词是互异词（如 `"ab"`），三块贡献全为 0，返回 0，符合题意"拼不出回文返回 0"。

## 5. 正确性证明

**引理 1（镜像结构）**：设合法拼接 $W = w_1 w_2 \cdots w_m$（每个 $w_t$ 长度 2）是回文，则对每个 $t$ 有 $w_{m+1-t} = \text{reverse}(w_t)$；特别地，若 $m$ 为奇数，正中间的 $w_{(m+1)/2}$ 自身是回文（两字符相同）。

**证明**：$W$ 回文即对任意位置 $p$，$W[p] = W[|W|-1-p]$。单词 $w_t$ 占位置 $2(t-1), 2t-1$，其镜像位置 $2m-2t, 2m-2t-1$ 恰被 $w_{m+1-t}$ 占据。于是 $w_{m+1-t}[0] = W[2m-2t] = W[2t-1] = w_t[1]$，$w_{m+1-t}[1] = w_t[0]$，即 $w_{m+1-t} = \text{reverse}(w_t)$。$m$ 奇时中间单词满足 $w = \text{reverse}(w)$，即两字符相同。∎

**引理 2（计数的充分性）**：若按第 3.3 节公式算出的总长为 $L$，则存在长度为 $L$ 的合法回文拼接；反之任何合法回文拼接的长度不超过 $L$。

**证明**：

（充分性 / 可构造）取每个互异对 $(i,j), (j,i)$ 中 $\min(cnt[i][j], cnt[j][i])$ 对，左右各放一个；对每个 $i$ 取 $\lfloor cnt[i][i]/2 \rfloor$ 对 aa 词左右各放一个；若 center 为真再取任一奇余量的 aa 词放正中间。把左半任意排序为 $u_1 \cdots u_k$，右半按 $u_k^{-1} \cdots u_1^{-1}$（reverse）排列，由引理 1 的构造是回文，长度恰 $4 \cdot (\text{对数}) + (\text{中心} \times 2) = L$。

（必要性 / 上界）设任一合法回文拼接用了互异词对若干。对每个互异对 $(i,j)/(j,i)$：由引理 1，$w$ 与 $\text{reverse}(w)$ 成对出现于镜像位，故所用 $(i,j)$ 词数与 $(j,i)$ 词数在"非中心部分"相等，而中心词必为 aa 类，所以互异词 $(i,j)$ 总用量 $\le cnt[i][j]$ 且与 $(j,i)$ 用量相等，故该互异对的用量对数 $\le \min(cnt[i][j], cnt[j][i])$。对 aa 类词 $(i,i)$：非中心部分成对使用，用量为偶数 $\le 2\lfloor cnt[i][i]/2 \rfloor$；中心至多一个词且必为 aa 类，故全部 aa 类的中心用量 $\le 1$。把每类用量上界相加得总长 $\le 4\sum_{i<j}\min(cnt[i][j],cnt[j][i]) + 4\sum_i \lfloor cnt[i][i]/2 \rfloor + 2 \cdot [\exists i: cnt[i][i] \text{ 奇}] = L$。∎

**定理（算法正确）**：算法返回的 $L$ 即最长回文串长度。

**证明**：由引理 2，$L$ 同时是"可达长度"与"所有可达长度的上界"，故为最大值。算法按公式精确计算 $L$：第 2 步累加互异对、第 3 步累加 aa 类对数并记录奇偶余量、第 4 步加中心，与公式逐项一致。∎

## 6. 复杂度分析

- **时间**：$O(n + 26^2)$。统计计数一遍 $O(n)$；互异对与自配对各扫 $26 \times 26 / 2 + 26$ 个格子，常数 $O(676)$。
- **空间**：$O(26^2) = O(676)$，即计数矩阵本身；不随 $n$ 增长。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int longestPalindrome(vector<string>& words) {
        int cnt[26][26] = {};
        for (const string& w : words) ++cnt[w[0] - 'a'][w[1] - 'a'];
        int ans = 0;
        for (int i = 0; i < 26; ++i)
            for (int j = i + 1; j < 26; ++j)        // "ab" 与 "ba" 互配，每对贡献 4
                ans += min(cnt[i][j], cnt[j][i]) * 4;
        bool center = false;
        for (int i = 0; i < 26; ++i) {              // "aa" 类：两两对称放置
            ans += cnt[i][i] / 2 * 4;
            if (cnt[i][i] % 2 == 1) center = true;  // 有奇数余量 → 可留 1 个当中心
        }
        return ans + (center ? 2 : 0);
    }
};
```

### Python

```python
class Solution:
    def longestPalindrome(self, words: List[str]) -> int:
        cnt = Counter(words)
        ans = 0
        center = False
        for w, c in cnt.items():
            r = w[::-1]
            if w < r:                            # 每对 (ab, ba) 只统计一次，贡献 4
                ans += min(c, cnt.get(r, 0)) * 4
            elif w == r:                         # aa 类：两两对称放置
                ans += c // 2 * 4
                if c % 2:
                    center = True                # 奇数余量可留 1 个当中心
        return ans + (2 if center else 0)
```

> 💡 两份代码均通过官方示例（`6`、`8`、`2`）以及 4000 组随机小规模输入（$n \le 6$，字母表限制到 `abc`）与"子集 × 全排列"暴力拼回文的对拍，`mismatch = 0`。

## 8. 边界情况与易错点

1. **互异对重复计数**：若外层对 $i, j$ 双向循环（$i \ne j$ 都算），会把同一对算两遍，答案翻倍。必须 $i < j$ 或字典序 $w < \text{rev}(w)$ 只取一半。
2. **中心至多一个**：多种 aa 词都余奇数个时（示例 3），中心增益仍是 $2$ 而不是 $2 \times$ 种类数。常见 WA 是把 `center` 写成 `cnt[i][i] % 2` 的累加。
3. **$cnt = 1$ 的 aa 词**：贡献 $0 \times 4 = 0$ 但要置 center——单个 `"gg"` 自己就是长度 2 的回文，别忘了这 2 的来源。
4. **全是互异词**：如 `["ab"]`，答案 0（拼不出任何回文）。代码三块全为 0 自然返回 0，无需特判，但要意识到这是题面允许的返回值。
5. **哈希 vs 数组的下标**：`w[0] - 'a'` 得 $0 \sim 25$；Python 里 `Counter` 直接以字符串为键更自然，但遍历 `cnt.items()` 时必须用 $w < r$ 排除重复统计（$w > r$ 的部分跳过、$w = r$ 走自配分支）。
6. **单字符中心不存在**：单词长度固定为 2，回文中心要么是一个完整 aa 词，要么落在某个词的两个字符之间（偶回文），没有"半个词当中心"的情况。
7. **`min` 的语义**：互异对配对数受两边计数较小者限制，多的一侧剩词作废——不要试图"把多出的 ab 拿去当中心"（它不是回文词）。
