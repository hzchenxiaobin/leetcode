# LeetCode 将标题首字母大写 题解

## 1. 题目概述

- **标题 / 题号**：将标题首字母大写（#2129，easy）
- **链接**：https://leetcode.cn/problems/capitalize-the-title/
- **来源**：LeetCode 第 69 场双周赛 Q1
- **难度**：简单
- **标签**：字符串

**题意**：给一个字符串 `title`，它由**单个空格**连接一个或多个单词组成，每个单词只含英文字母。请按以下规则把每个单词"首字母大写"：

- 若单词长度为 $1$ 或 $2$：所有字母都变成**小写**；
- 否则（长度 $\ge 3$）：**首字母大写**，剩余字母全部变成小写。

返回处理后的 `title`。

**约束**：

- $1 \le \text{title.length} \le 100$
- `title` 由单个空格隔开的单词组成，且不含前导或后缀空格；
- 每个单词由大小写英文字母组成，且都非空。

> ⚠️ 题面中"首字母大写"这个说法有迷惑性：长度 $\le 2$ 的单词连首字母也要**小写**，这是本题唯一的坑。

## 2. 示例

**示例 1**

```text
输入：title = "capiTalIze tHe titLe"
输出："Capitalize The Title"
解释：所有单词长度都 ≥ 3，每个单词首字母大写、其余小写。
```

**示例 2**

```text
输入：title = "First leTTeR of EACH Word"
输出："First Letter of Each Word"
解释："of" 长度为 2，整体保持小写；其余单词首字母大写、剩余小写。
```

**示例 3**

```text
输入：title = "i lOve leetcode"
输出："i Love Leetcode"
解释："i" 长度为 1，保持小写；"lOve" → "Love"，"leetcode" → "Leetcode"。
```

## 3. 解题思路

### 3.1 暴力思路

直接调用语言自带 API 逐词处理：把 `title` 按空格 `split` 成单词数组，对每个单词按长度套用 `lower()` 或 `capitalize()`，最后 `' '.join` 拼回。时间 $O(n)$、空间 $O(n)$（切分数组），对 $n \le 100$ 完全够用，是赛场上的首选。真正的"暴力"其实不存在——本题没有可优化的复杂度瓶颈，考点是**仔细读规则**和**边界处理**（长度 1/2 的单词、全大写、全小写）。不过若要求 $O(1)$ 额外空间，可以放弃切分数组，在原串上双指针扫描单词边界，见 3.3。

### 3.2 核心观察：规则只依赖单词长度

![两条规范化规则：只看单词长度](images/bw69_q1_word_rules_model.svg)

把两条规则合起来看：**对单词的每个位置，输出什么只由两个量决定——单词长度与该位置是否为首字母**：

- 长度 $\le 2$：所有位置输出小写；
- 长度 $\ge 3$：位置 0 输出大写，其余位置输出小写。

于是不需要任何记忆化或状态机，一次线性扫描即可。另外，题目约束"单个空格分隔、无前后缀空格、单词非空"保证了**切分不会产生空串**，规范化后的空格位置原样保留——即"空格不动，只改字母"。这让我们可以放心地原地修改：扫描时用指针 $j$ 从单词起点 $i$ 向右找到空格或串尾，$[i, j)$ 就是一个完整的单词。

### 3.3 算法流程：一次遍历原地改写

![一次遍历：原地找单词边界并规范化](images/bw69_q1_algorithm_flow.svg)

```text
1. i = 0
2. 当 i < n：
       j = i，向右扫到 title[j] == ' ' 或 j == n，得到单词区间 [i, j)
       若 j − i ≤ 2：把 [i, j) 内每个字符 tolower
       否则：title[i] toupper，[i+1, j) 内每个字符 tolower
       i = j + 1        # 跳过那个空格
3. 返回 title
```

C++ 版本按此写法原地完成，$O(1)$ 额外空间；Python 版本用 `split` + `join` 更直观，两份代码都对。

### 3.4 示例演算

![演算：title = "First leTTeR of EACH Word"](images/bw69_q1_example_walkthrough.svg)

## 4. 算法细节

1. **单词边界判定**：内层指针 $j$ 停在空格或串尾，单词区间是左闭右开 $[i, j)$；之后 $i = j + 1$ 跳过**恰好一个**空格。由于约束保证单词间只有一个空格，这个跳法不会越界（最后停在 $n$ 上结束循环）。
2. **大小写转换**：C++ 用 `tolower` / `toupper`（返回 `int`，需转 `char`）；它们对已经是目标大小写的字母同样安全（幂等），所以无需先判断当前大小写。Python 的 `str.lower()` / `str.capitalize()` 幂等性同理。
3. **`capitalize()` 的语义**：Python 的 `w.capitalize()` 恰好是"首字母大写 + 其余小写"，与规则二完全一致，可直接用；规则一用 `w.lower()`。
4. **为什么不逐字符判断**：规则本身已把"该位置输出大写还是小写"写成显式分段函数，逐字符分支（`if pos == 0 and len >= 3`）反而容易漏掉"长度 2 的首字母要小写"这一坑。先按长度分流，再按位置转换，逻辑最清晰。
5. **返回值**：题目保证至少一个单词，无需处理空串输入。

## 5. 正确性证明

**引理 1（切分唯一性）**：按"单个空格"切分 `title` 得到的单词序列唯一，且每个单词非空、不含空格。

**证明**：约束说明 `title` 形如 $w_1\ \Box\ w_2\ \Box\ \cdots\ \Box\ w_k$（$\Box$ 为单个空格，$w_i$ 非空且不含空格）。归纳于扫描过程：初始 $i = 0$ 指向 $w_1$ 首字符；内层 $j$ 首次遇到空格的位置必是 $w_1$ 之后的那个分隔符，故 $[i, j) = w_1$；随后 $i = j + 1$ 恰指向 $w_2$ 首字符。归纳可知每个 $w_t$ 被准确取出，且循环在处理完 $w_k$ 后 $i = n + 1 > n$ 终止。切分显然唯一（空格位置固定）。∎

**定理（算法正确）**：上述一次遍历算法返回的字符串等于按题意规则处理后的 `title`。

**证明**：由引理 1，算法恰把每个单词 $w_t$ 的区间 $[i_t, j_t)$ 取出且不触碰空格。对每个区间：若 $j_t - i_t \le 2$，算法把区间内所有字符转为小写，与规则一的输出逐字符一致；若 $j_t - i_t \ge 3$，算法把位置 $i_t$ 的字符转为大写、其余转为小写，与规则二的输出逐字符一致。空格与单词序列不变。故输出串与期望串在所有位置上字符相同。∎

## 6. 复杂度分析

- **时间**：$O(n)$，$n = \text{title.length} \le 100$。外层指针 $i$ 与内层指针 $j$ 都单调右移，每个字符至多被访问常数次（读一次、写一次）。
- **空间**：C++ 原地写法 $O(1)$ 额外空间；Python `split`/`join` 写法 $O(n)$ 存放单词列表与新串。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    string capitalizeTitle(string title) {
        int n = (int)title.size();
        for (int i = 0; i < n; ) {
            int j = i;
            while (j < n && title[j] != ' ') ++j;      // [i, j) 为一个单词
            if (j - i <= 2) {                          // 长度 1/2：全部小写
                for (int t = i; t < j; ++t) title[t] = (char)tolower(title[t]);
            } else {                                   // 长度 >= 3：首字母大写，其余小写
                title[i] = (char)toupper(title[i]);
                for (int t = i + 1; t < j; ++t) title[t] = (char)tolower(title[t]);
            }
            i = j + 1;                                 // 跳过单个空格
        }
        return title;
    }
};
```

### Python

```python
class Solution:
    def capitalizeTitle(self, title: str) -> str:
        words = title.split(' ')
        for i, w in enumerate(words):
            if len(w) <= 2:                       # 长度 1/2：全部小写
                words[i] = w.lower()
            else:                                 # 长度 >= 3：首字母大写，其余小写
                words[i] = w[0].upper() + w[1:].lower()
        return ' '.join(words)
```

> 💡 两份代码均通过官方示例（`"Capitalize The Title"`、`"First Letter of Each Word"`、`"i Love Leetcode"`）以及 4000 组随机串与独立暴力（`split` + `lower`/`capitalize` + `join`）的对拍，`mismatch = 0`。

## 8. 边界情况与易错点

1. **长度 1/2 的首字母必须小写**："of" → "of"（不是 "Of"），"i" → "i"。赛场上最快的 WA 就是把规则一写成"保持原样"或"仅首字母大写失败时保留"。
2. **长度 ≥ 3 的中间字母要压小写**："EACH" → "Each"，不是 "EACH" 或 "EAcH"。输入可能全大写。
3. **大小写转换的幂等性**：`tolower`/`toupper` 对已经是目标形态的字符安全，无需预先判断；但注意 C++ 里它们接收并返回 `int`，赋回 `string` 要显式 `(char)`。
4. **切分方式**：约束保证单个空格、无前后缀空格，`split(' ')` 与 `split()` 等价；但养成用 `split(' ')` 的习惯能避免日后遇到连续空格时两者行为分叉的坑（本题不会发生）。
5. **单个单词**：`title = "a"`、`"ab"`、`"abc"` 都是合法输入，分别输出 `"a"`、`"ab"`、`"Abc"`。
6. **原地写法的指针推进**：`i = j + 1` 只在 `j < n`（停在空格）时跳空格，`j == n`（串尾）时得 $i = n + 1$ 同样退出循环，两种情况都不越界、不死循环。
