# LeetCode 使字符串有序的最少操作次数 题解

## 1. 题目概述

- **标题 / 题号**：使字符串有序的最少操作次数（#1830，hard）
- **链接**：https://leetcode.cn/problems/minimum-number-of-operations-to-make-string-sorted/
- **来源**：LeetCode 第 50 场双周赛 Q4
- **难度**：困难
- **标签**：哈希表、数学、字符串、组合数学、计数

**题意**：对字符串 $s$ 重复执行以下"操作"，直到 $s$ 变为有序（非降）：

1. 找**最大**下标 $i$（$1 \le i < n$）使 $s[i] < s[i-1]$；
2. 找**最大**下标 $j$（$i \le j < n$）使**所有** $k \in [i, j]$ 都满足 $s[k] < s[i-1]$；
3. 交换 $s[i-1]$ 与 $s[j]$；
4. 反转从下标 $i$ 开始的后缀。

返回操作次数对 $10^9 + 7$ 取模的结果。

**约束**：

- $1 \le |s| \le 3000$
- $s$ 只含小写英文字母

## 2. 示例

**示例 1**

```text
输入：s = "cba"
输出：5
解释：cba → cab → bca → bac → acb → abc，共 5 次操作。
```

**示例 2**

```text
输入：s = "aabaa"
输出：2
解释：aabaa → aaaba → aaaab，共 2 次操作。
```

**示例 3**

```text
输入：s = "cdbea"
输出：63
```

**示例 4**

```text
输入：s = "leetcodeleetcodeleetcode"
输出：982157772
```

## 3. 解题思路

### 3.1 暴力思路

直接模拟：每轮执行四步操作直到字符串非降。问题在于**操作次数本身可能是天文数字**——"aabaa" 有 $\frac{5!}{4!1!} = 5$ 个不同排列还好，但 $n = 3000$、26 种字母较均匀时排列数可达 $10^{3000}$ 量级，模拟永远跑不完。出路是先**看懂一次操作到底做了什么**，把"逐步走"翻译成"数数"。

### 3.2 核心观察一：一次操作 = 求上一个（字典序更小的）排列

![一次操作的四步展开：它就是多重集的 previous permutation](images/bw50_q4_prev_permutation.svg)

设四步操作前的串为 $s$，记 $v = s[i-1]$。由 $i$ 的**最大性**，后缀 $s[i..]$ 是**非降**的（若有 $k>i$ 使 $s[k]<s[k-1]$，$i$ 就不是最大）；由 $j$ 的定义，$s[i..j]$ 是后缀开头一段连续的"全部 $< v$" 的片段，结合非降性，$s[j]$ 恰是后缀中**小于 $v$ 的最大字符**（且取最右出现）。于是操作后：

- $s[i-1]$ 从 $v$ 换成"可用字符中严格小于 $v$ 的最大者"——在保住前缀 $s[0..i-2]$ 不变的前提下，这个位置**能取到的最大合法值**；
- 交换后的后缀仍非降，反转后**非升**——即后缀多重集能排出的**最大排列**；
- $i-1$ 恰是"能放下更小字符的最右位置"（$i$ 及以后的后缀非降，任何位置 $k \ge i$ 都找不到比 $s[k]$ 更小的可用字符）。

这三条合起来正是经典的 **`prev_permutation`**：把 $s$ 移动到它所在字母多重集的全部不同排列中**字典序紧邻的前一个**。所以"变成有序的操作次数"就是：**字典序严格小于 $s$ 的不同排列个数**（有序串是最小排列，走到它恰好要跨过所有比 $s$ 小的排列）。

### 3.3 核心观察二：排名计数——逐位固定前缀，枚举更小字符

![逐位计数：位置 i 放更小字符 d，其余任意排列](images/bw50_q4_rank_counting.svg)

多重集排列的排名是标准计数。对每个位置 $i$（后缀字符计数为 $\textit{cnt}[\cdot]$）：

$$\text{位置 } i \text{ 更小的排列数} = \sum_{d < s[i]} \underbrace{\frac{(n-1-i)!}{\prod_{c} \textit{cnt}[c]! \big/ \textit{cnt}[d]}}_{\text{固定前缀 } s[0..i) \text{，位置 } i \text{ 放 } d}$$

把分母记为 $F = \prod_c \textit{cnt}[c]!$：把一个 $d$ 从多重集中取走后，分母变为 $F / \textit{cnt}[d]$，于是每一项 $= (n-1-i)! \cdot \textit{cnt}[d] \cdot F^{-1}$，对 $d$ 求和时 $F^{-1}$ 是公因子，提出得

$$\text{term}_i = (n-1-i)! \cdot \Big(\sum_{d < s[i]} \textit{cnt}[d]\Big) \cdot F^{-1} \pmod{10^9+7}.$$

$F^{-1}$ 用**费马小定理**求逆元，且沿扫描维护：处理完位置 $i$（消费掉字符 $s[i]$）后 $F' = F/\textit{cnt}[s[i]]$，故 $F'^{-1} = F^{-1} \cdot \textit{cnt}[s[i]]$——**一次乘法**完成更新，全程只有开头做一次幂。

### 3.4 算法流程与示例演算

```text
1. 预处理 fact[0..n]，逆元 inv_fact（费马小定理）
2. cnt[26] ← s 的后缀（=全部）字符计数；invF = Π inv_fact[cnt[c]]
3. ans = 0
4. 对 i = 0 .. n-1：
       smaller = Σ_{d < s[i]} cnt[d]                # 后缀中比 s[i] 小的字符总数
       ans += fact[n-1-i] · smaller · invF
       invF *= cnt[s[i]]；cnt[s[i]] −−              # 消费 s[i]
5. 返回 ans mod 1e9+7
```

**演算 "aabaa"**（$n=5$，$\textit{cnt} = \{a{:}4, b{:}1\}$，$F = 4!\,1! = 24$）：

| $i$ | $s[i]$ | $\textit{smaller}$ | $t=n{-}1{-}i$ | $\text{term} = t! \cdot \textit{smaller} \cdot F^{-1}$ | $F$ 变化 |
|-----|--------|--------------------|----------------|--------------------------------------------------------|----------|
| 0 | a | 0 | 4 | 0 | $24/4 = 6$ |
| 1 | a | 0 | 3 | 0 | $6/3 = 2$ |
| 2 | b | $\textit{cnt}[a] = 2$ | 2 | $2! \cdot 2 \cdot \frac{1}{2} = 2$ | $2/1 = 2$（消费 b） |
| 3 | a | 0 | 1 | 0 | $2/2 = 1$ |
| 4 | a | 0 | 0 | 0 | — |

合计 $2$ ✓。交叉验证：`aabaa` 的字母多重集共 $\frac{5!}{4!\,1!} = 5$ 个排列。

![aabaa 的全部 5 个排列与 s 的排名](images/bw50_q4_example_perms.svg)

$$aaaab < aaaba < \underbrace{aabaa}_{s,\ \text{第 } 3 \text{ 名}} < abaaa < baaaa$$

比 $s$ 小的恰有 $2$ 个 ✓。**演算 "cba"**（三个互异字母，共 $3! = 6$ 个排列）：$\text{cba}$ 排第 6，比它小的 5 个 ✓。

## 4. 算法细节

1. **预计算**：$fact[0..n]$ 线性递推；$inv\_fact[n] = fact[n]^{p-2} \bmod p$ 后**倒序线性递推** $inv\_fact[i-1] = inv\_fact[i] \cdot i$，整个程序只做一次 $O(\log p)$ 幂。
2. **初始 $F^{-1}$**：$\prod_c inv\_fact[\textit{cnt}[c]]$ 逐字母连乘，$O(26)$。
3. **每步 $\textit{smaller}$**：直接累加 $\textit{cnt}[0..s[i]-1]$，$O(26)$；也可维护 26 个字母的前缀计数数组优化，但 $n \le 3000$ 无必要。
4. **更新次序**：必须**先** `invF *= cnt[c]` **再** `cnt[c] -= 1`——消费字符时分母除的是"当前个数"。
5. **全程取模**：每步乘法后 `% MOD`；C++ 中乘积上界约 $(10^9)^2 < 2^{63}$，`long long` 安全。
6. **不要排序或重排 $s$**：计数沿原串从左到右进行，$s$ 本身就是"前缀"的定义。

## 5. 正确性证明

**引理 1（操作 = 上一个排列）**：四步操作把 $s$（非降除外）变换为其字母多重集所有不同排列中字典序紧邻更小的那个 $s^-$；当且仅当 $s$ 非降时不存在合法 $i$（操作停止）。

**证明**：存在性：$i$ 有定义说明有下降对，后缀 $s[i..]$ 非降（$i$ 的最大性），且 $s[i] < v$。$s^-$ 的构造：字典序小于 $s$ 的排列必然存在一个最右位置 $p$ 放置了更小的字符、且前缀 $s[0..p)$ 不变；对任何 $k \ge i$，后缀 $s[k..]$ 非降意味着可用字符中没有比 $s[k]$ 小者，故 $p$ 最大只能取 $i-1$，$p = i-1$ 也确实可行（$s[i] < v$）。在 $p = i-1$ 处放"可用字符中严格小于 $v$ 的最大值"——由后缀非降，即 $s[j]$（$j$ 为 $< v$ 片段的末端，最右出现）——然后其余位置放后缀剩余字符的**最大排列**才能最接近 $s$；交换后后缀仍非降（$s[j] < v \le s[j+1]$ 且 $s[j-1] \le s[j]$），反转即得非升 = 最大排列。这正是四步操作，且每一步唯一确定。当 $s$ 非降时不存在下降对，引理中 $i$ 无定义，操作停止；非降串显然是最小排列。∎

**引理 2（步数 = 更小排列数）**：从 $s$ 出发反复执行引理 1 的操作直到非降，步数 $=$ 字典序严格小于 $s$ 的不同排列数 $R(s)$。

**证明**：每次操作严格减小字典序，且（由引理 1）每步恰好跳到"紧邻的前一个"排列——不同排列的字典序是全序，紧邻前驱唯一，故访问的序列是 $s > s^- > s^{--} > \dots$ 严格递减且不重不漏，终止于最小排列（非降串）。该链的长度恰为 $s$ 到最小排列之间（不含 $s$）的排列个数，即 $R(s)$。∎

**引理 3（排名公式）**：$R(s) = \sum_{i=0}^{n-1} (n-1-i)! \cdot \big(\sum_{d < s[i]} \textit{cnt}_i[d]\big) \cdot F_i^{-1}$，其中 $\textit{cnt}_i$ 是后缀 $s[i..]$ 的字符计数、$F_i = \prod_c \textit{cnt}_i[c]!$。

**证明**：按"与 $s$ 的第一个不同位置"给所有更小排列分组，组即"前缀 = $s[0..i)$、位置 $i$ 放 $d < s[i]$"。组内个数 = 剩余 $n-1-i$ 个位置上剩余多重集（$\textit{cnt}_i$ 去掉一个 $d$）的排列数 $= (n-1-i)! \cdot \prod_c (\textit{cnt}_i[c] - [c{=}d])!^{\,{-1}} = (n-1-i)! \cdot \textit{cnt}_i[d] \cdot F_i^{-1}$（因 $F_i / \textit{cnt}_i[d] = \prod_c (\textit{cnt}_i[c]-[c{=}d])!$）。对 $d < s[i]$ 求和，公因子 $F_i^{-1}$ 提出，得 $\text{term}_i$。各位置组互斥且穷尽所有更小排列。$F_i$ 的滚动更新：$F_{i+1} = F_i / \textit{cnt}_i[s[i]]$（消费一个 $s[i]$），对应逆元乘 $\textit{cnt}_i[s[i]]$。∎

**定理**：算法返回操作次数模 $10^9+7$。

**证明**：由引理 2，操作次数 $= R(s)$；由引理 3，逐位求和恰计算 $R(s)$。所有除法在模素数 $10^9+7$ 意义下通过逆元实现（$\textit{cnt}[c] \le 3000 < p$，各阶乘不含因子 $p$，可逆），同余系的加乘运算保持结果同余。∎

## 6. 复杂度分析

- **时间**：$O(n \cdot 26 + \log p)$。预计算阶乘 $O(n)$、一次费马幂 $O(\log p)$；主循环每步 $O(26)$ 求 $\textit{smaller}$ 与常数次乘法取模，$n = 3000$ 时约 $10^5$ 量级基本操作。
- **空间**：$O(n + 26)$。阶乘、逆阶乘数组与字符计数。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int makeStringSorted(string s) {
        const long long MOD = 1000000007LL;
        int n = (int)s.size();
        vector<long long> fact(n + 1), invFact(n + 1);
        fact[0] = 1;
        for (int i = 1; i <= n; ++i) fact[i] = fact[i - 1] * i % MOD;
        invFact[n] = modpow(fact[n], MOD - 2, MOD);          // 费马小定理求逆元
        for (int i = n; i >= 1; --i) invFact[i - 1] = invFact[i] * i % MOD;

        int cnt[26] = {0};
        for (char ch : s) ++cnt[ch - 'a'];
        long long invF = 1;                                  // inv(∏ cnt[c]!)
        for (int c = 0; c < 26; ++c) invF = invF * invFact[cnt[c]] % MOD;

        long long ans = 0;
        for (int i = 0; i < n; ++i) {
            int c = s[i] - 'a';
            int smaller = 0;
            for (int d = 0; d < c; ++d) smaller += cnt[d];   // 后缀中比 s[i] 小的字符总数
            if (smaller > 0)
                ans = (ans + fact[n - 1 - i] * smaller % MOD * invF) % MOD;
            invF = invF * cnt[c] % MOD;                      // 消费 s[i]：分母除以 cnt[c]
            --cnt[c];
        }
        return (int)ans;
    }
private:
    static long long modpow(long long b, long long e, long long m) {
        long long r = 1;
        while (e) {
            if (e & 1) r = r * b % m;
            b = b * b % m;
            e >>= 1;
        }
        return r;
    }
};
```

### Python

```python
class Solution:
    def makeStringSorted(self, s: str) -> int:
        MOD = 10 ** 9 + 7
        n = len(s)
        fact = [1] * (n + 1)
        for i in range(1, n + 1):
            fact[i] = fact[i - 1] * i % MOD
        inv_fact = [1] * (n + 1)
        inv_fact[n] = pow(fact[n], MOD - 2, MOD)     # 费马小定理求逆元
        for i in range(n, 0, -1):
            inv_fact[i - 1] = inv_fact[i] * i % MOD

        cnt = [0] * 26
        for ch in s:
            cnt[ord(ch) - 97] += 1
        inv_f = 1
        for c in range(26):                          # inv(∏ cnt[c]!)
            inv_f = inv_f * inv_fact[cnt[c]] % MOD

        ans = 0
        for i in range(n):
            c = ord(s[i]) - 97
            smaller = sum(cnt[:c])                   # 后缀中比 s[i] 小的字符总数
            if smaller:
                ans = (ans + fact[n - 1 - i] * smaller % MOD * inv_f) % MOD
            inv_f = inv_f * cnt[c] % MOD             # 消费 s[i]：分母除以 cnt[c]
            cnt[c] -= 1
        return ans
```

> 💡 两份代码通过官方 4 个示例（`5`、`2`、`63`、`982157772`），并与"直接模拟四步操作逐步计数"的暴力在 2000 组随机小串（$n \le 7$、字母表 $\le 4$）上对拍（`mismatch = 0`），$n = 3000$ 随机串瞬时完成且两语言结果一致。

## 8. 边界情况与易错点

1. **已经有序**：$s$ 非降（如 `"abc"`、`"aaa"`）时每个位置都不存在更小字符，全部 $\text{term}$ 为 0，返回 0 ✓。
2. **答案存的是"次数"不是排列数本身**：由引理 2 两者相等，但理解错语义容易多减一；注意"排名"是 1 起始而"更小排列数"是排名减一，公式直接累加的就是后者，无 $-1$ 修正。
3. **逆元更新次序**：`invF *= cnt[c]` 必须发生在 `cnt[c] -= 1` 之前，颠倒会把分母除错成 0 或错位。
4. **`smaller` 是"后缀计数"里的个数**：处理位置 $i$ 之前消费掉的都是 $s[0..i)$ 的字符，后缀计数天然正确；千万不要用全串计数。
5. **溢出**：C++ 中 `fact · smaller` 约 $10^{12}$、再乘 `invF` 前先 `% MOD` 压回 $10^9$ 内，全程 `long long`；Python 无溢出但每步仍要 `% MOD`（否则大数乘法变慢）。
6. **除法不可用整除**：$F^{-1}$ 必须走费马小定理/逆元，$F \bmod p$ 与真实 $F$ 不同，直接整除会错得离谱。
7. **别被"反转"吓到**：引理 1 说明反转只是"后缀取最大排列"的快捷方式；同理若题目改成"下一个排列"（LC 31 的 next），答案就是总排列数 $-$ 排名 $-$ 1。
8. **$n = 1$**：单字符有序，返回 0。
