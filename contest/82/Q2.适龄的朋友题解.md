# LeetCode 适龄的朋友 题解

## 1. 题目概述

- **标题 / 题号**：适龄的朋友（#825，medium）
- **链接**：https://leetcode.cn/problems/friends-of-appropriate-ages/
- **来源**：LeetCode 第 82 场周赛 Q2
- **难度**：中等
- **标签**：数组、双指针、二分查找、排序

**题意**：有 $n$ 个用户，`ages[i]` 是第 $i$ 个用户的年龄。用户 $x$ 向用户 $y$（$x \ne y$）发送好友请求的**前提**是下面三条「拒绝条件」全部不成立：

1. $\text{ages}[y] \le \dfrac{1}{2}\text{ages}[x] + 7$（对方太年轻）
2. $\text{ages}[y] > \text{ages}[x]$（对方比自己年长）
3. $\text{ages}[y] > 100$ 且 $\text{ages}[x] < 100$（跨过 100 岁）

请求是**有向**的：$x$ 发给 $y$ 不代表 $y$ 会发给 $x$；任何人都不会发给自己。求全部请求条数。

**约束**：

- $1 \le n \le 2 \times 10^4$
- $1 \le \text{ages}[i] \le 120$
- 答案不超过 $n(n-1) \approx 4\times10^8$，在 32 位有符号整数范围内

## 2. 示例

**示例 1**

```text
输入：ages = [16, 16]
输出：2
解释：两人年龄相同且都 ≥ 15，互相发送请求，共 2 条。
```

**示例 2**

```text
输入：ages = [16, 17, 18]
输出：2
解释：17 -> 16、18 -> 17 各一条；
      18 -> 16 被条件①拒绝（16 ≤ 18/2+7 = 16），16 更不可能发给别人。
```

**示例 3**

```text
输入：ages = [20, 30, 100, 110, 120]
输出：3
解释：110 -> 100、120 -> 110、120 -> 100；
      20、30、100 三人没有更年轻的合格对象，贡献为 0。
```

## 3. 解题思路

### 3.1 暴力思路

枚举每个有序对 $(x, y)$，逐条判断三个拒绝条件，计数即可，单对 $O(1)$。

总复杂度 $O(n^2)$：$n = 2\times10^4$ 时是 $4\times10^8$ 对，C++ 勉强卡在时限边缘，Python 必定超时。瓶颈很明显：**人数很多（$2\times10^4$），但年龄只有 120 种取值**，同年龄的人对每个 $y$ 的判断完全一样，却被重复算了成百上千遍。

### 3.2 核心观察：合法对象是一段年龄区间

![合法好友是连续年龄区间](images/wc82_q2_valid_window.svg)

固定 $x$，记 $a = \text{ages}[x]$、$b = \text{ages}[y]$。把三条拒绝条件取反：

- $b > \dfrac{a}{2} + 7$，即 $b > 0.5a + 7$；
- $b \le a$；
- 第三条**永不触发**：若 $a < 100$，则由 $b \le a$ 得 $b < 100$，不满足 $b > 100$；若 $a \ge 100$，条件要求 $a < 100$ 本身就假。

于是合法集合是整数区间

$$b \in \Bigl[\bigl\lfloor a/2 \bigr\rfloor + 8,\ a\Bigr]$$

下界之所以是 $\lfloor a/2 \rfloor + 8$ 而不是 $a/2+7$：$b$ 必须是整数，$b > a/2+7 \iff b \ge \lfloor a/2+7 \rfloor + 1 = \lfloor a/2 \rfloor + 8$。例如 $a = 17$ 时 $b > 15.5$，即 $b \ge 16 = \lfloor 17/2 \rfloor + 8$。

**这一步把「枚举人」换成了「枚举年龄 + 区间查询」**：用桶计数 $freq[1..120]$ 与前缀和 $pref[i] = \#\{j : \text{ages}[j] \le i\}$，区间人数为 $pref[a] - pref[lo-1]$；年龄同为 $a$ 的人贡献完全一致，乘上 $freq[a]$ 即可，每人再减掉「自己」这一个接收者。

### 3.3 算法流程

![计数 + 前缀和流程](images/wc82_q2_algorithm_flow.svg)

1. **桶计数**：遍历 `ages`，`freq[ages[i]] += 1`，$O(n)$。
2. **前缀和**：$pref[i] = pref[i-1] + freq[i]$（$1 \le i \le 120$），$O(120)$。
3. **按年龄枚举**：对每个 $a$ 且 $freq[a] > 0$，算 $lo = \lfloor a/2 \rfloor + 8$；若 $lo > a$ 说明区间为空（$a \le 14$），直接跳过。
4. **区间人数**：$cnt = pref[a] - pref[lo-1] - 1$（减掉的 1 是 $x$ 自己）。
5. **累加**：$ans \mathrel{+}= freq[a] \times cnt$，最后返回 $ans$。

整体只需一趟扫描 + 120 次常数操作，与人数规模基本无关。

### 3.4 示例演算

![示例走查表](images/wc82_q2_walkthrough.svg)

对 `ages = [20, 30, 100, 110, 120]`：

| $a$ | $lo = \lfloor a/2\rfloor+8$ | 区间 $[lo, a]$ 内人数 | 减自己 | 贡献 |
|-----|------|------|------|------|
| 20 | 18 | 1 | 0 | 0 |
| 30 | 23 | 1 | 0 | 0 |
| 100 | 58 | 1 | 0 | 0 |
| 110 | 63 | 2 | 1 | 1 |
| 120 | 68 | 3 | 2 | 2 |

合计 $3$，正是 $110 \to 100$、$120 \to 110$、$120 \to 100$。

- `[16,16]`：$a = 16$，$lo = 16$，区间内 2 人，减自己后 1 人，$2 \times 1 = 2$。
- `[16,17,18]`：$a=17$ 的 $lo=16$，区间 $\{16,17\}$ 得 1；$a=18$ 的 $lo=17$，区间 $\{17,18\}$ 得 1；合计 $2$。

## 4. 算法细节

1. **整数下界**：$lo$ 用整数除法算 $a/2 + 8$，不要写 $0.5 \times a + 7$ 再和整数比较，避免浮点与取整的歧义；$a$ 为奇数时（如 $17 / 2 = 8.5$）只有整数写法才与题意严格一致。
2. **区间为空必须跳过**：$a \le 14$ 时 $lo > a$，若硬算会得到负人数；加一句 `if (lo > a) continue` 既防错又省事。
3. **只能减 1**：$pref[a] - pref[lo-1]$ 含 $x$ 本人（自己的年龄 $a$ 必在 $[lo, a]$ 内），所以减去 1，而**不是**减去 $freq[a]$——同年龄的其他人是可以互相发送的。
4. **下标安全**：$lo \ge 8$（$a \ge 1$ 时），故 $lo-1 \ge 7 \ge 0$，不会越界；一旦通过 `lo <= a` 检查，$lo-1 \le a-1 \le 119$ 也在数组内。
5. **数据类型**：答案上限 $4\times10^8 < 2^{31}-1$，`int` 够用；习惯性用 `long long` 也无副作用，Python 更无整数溢出问题。
6. **前缀和下标基准**：`freq` 用 1..120 下标，$pref[0] = 0$，这样 $pref[a] - pref[lo-1]$ 对 $lo = 1$ 也不会越界。
7. **等价写法（排序 + 双指针）**：按年龄排序后，对每个 $i$，右端点是「年龄 $\le a$ 的最右位置」（即同龄组末尾），左端点是「年龄 $\ge lo$ 的第一个位置」，两者随 $i$ 单调右移，窗口人数 $-1$ 即为该用户的贡献；复杂度 $O(n \log n)$，不需要 120 这个上限。

## 5. 正确性证明

**引理 1（区间刻画）**：对年龄为 $a$ 的用户 $x$ 与年龄为 $b$ 的用户 $y$（$y \ne x$），$x$ 向 $y$ 发送请求当且仅当 $\bigl\lfloor a/2 \bigr\rfloor + 8 \le b \le a$。

**证明**：三条拒绝条件都不成立时才会发送。

- 条件 1 取反：$b > a/2+7$。因 $b$ 是整数，$b > a/2+7 \iff b \ge \lfloor a/2+7 \rfloor + 1$；又 $7$ 为整数，$\lfloor a/2+7 \rfloor = \lfloor a/2 \rfloor + 7$，故等价于 $b \ge \lfloor a/2 \rfloor + 8$。
- 条件 2 取反：$b \le a$。
- 条件 3 取反：$\lnot(b > 100 \land a < 100)$。若 $a < 100$，结合 $b \le a$ 得 $b < 100$，该式为真；若 $a \ge 100$，则 $a < 100$ 为假，该式亦为真。故条件 3 对合法集合不产生任何额外限制。

三条限制的交集即 $\lfloor a/2 \rfloor + 8 \le b \le a$。∎

**引理 2（分组计数准确）**：固定 $a$ 且 $lo \le a$，$freq[a] \cdot (pref[a] - pref[lo-1] - 1)$ 恰为全部年龄为 $a$ 的用户发出的请求数。

**证明**：由引理 1，每个年龄为 $a$ 的用户 $x$ 的接收者集合为 $\{y : lo \le \text{ages}[y] \le a,\ y \ne x\}$，其大小为 $pref[a] - pref[lo-1] - 1$（区间内共 $pref[a]-pref[lo-1]$ 人且必包含 $x$ 自己，减去 1 恰好把 $x$ 排除，其余同龄人全部保留）。所有年龄为 $a$ 的用户接收者集合大小相同，乘以 $freq[a]$ 即得该组发出的请求数。∎

**引理 3（分组不重不漏）**：不同年龄组统计的请求互不重复，且覆盖全部请求。

**证明**：每条请求由唯一的有向对 $(x, y)$ 确定，$x$ 的年龄唯一，故该请求只在 $a = \text{ages}[x]$ 这一组被计数一次；反之每组内只枚举了满足引理 1 的对，不会多算。∎

**定理**：算法返回值等于好友请求总数。

**证明**：由引理 1 与引理 2，每个非空年龄组的贡献等于该组用户发出的请求数；由引理 3，各组贡献之和恰为全部请求数，算法输出的正是这个和。∎

## 6. 复杂度分析

- **时间**：$O(n + 120)$。桶计数遍历 $n$ 个年龄；前缀和与按年龄枚举各 $O(120)$ 次常数操作。$120$ 是与 $n$ 无关的常数，故等于 $O(n)$。
- **空间**：$O(120) = O(1)$。两个长度为 121 的数组，与人数无关。
- 对比：暴力 $O(n^2)$ 时间、$O(1)$ 空间；排序双指针版 $O(n \log n)$ 时间、$O(1)$ 额外空间（原地排序）。

## 7. 参考代码

### C++

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    int numFriendRequests(vector<int>& ages) {
        const int MAXA = 120;
        vector<int> freq(MAXA + 1, 0);
        for (int a : ages) freq[a]++;            // ① 桶计数

        vector<int> pref(MAXA + 1, 0);           // ② 前缀和：pref[i] = 年龄 <= i 的人数
        for (int i = 1; i <= MAXA; i++) pref[i] = pref[i - 1] + freq[i];

        int ans = 0;
        for (int a = 1; a <= MAXA; a++) {        // ③ 按年龄枚举
            if (freq[a] == 0) continue;
            int lo = a / 2 + 8;                  // 合法接收者的年龄下界
            if (lo > a) continue;                // 区间为空（a <= 14）
            int cnt = pref[a] - pref[lo - 1] - 1; // ④ 区间人数，减掉自己
            ans += freq[a] * cnt;                // ⑤ 同龄人贡献相同，直接乘
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def numFriendRequests(self, ages: list[int]) -> int:
        MAXA = 120
        freq = [0] * (MAXA + 1)
        for a in ages:
            freq[a] += 1

        pref = [0] * (MAXA + 1)
        for i in range(1, MAXA + 1):
            pref[i] = pref[i - 1] + freq[i]

        ans = 0
        for a in range(1, MAXA + 1):
            c = freq[a]
            if c == 0:
                continue
            lo = a // 2 + 8
            if lo > a:
                continue
            # 区间 [lo, a] 内的人数，去掉用户自己
            ans += c * (pref[a] - pref[lo - 1] - 1)
        return ans
```

## 8. 边界情况与易错点

1. **$a \le 14$ 无人可发**：$lo = \lfloor a/2 \rfloor + 8 > a$，区间为空。漏写 `continue` 会让 $pref[a] - pref[lo-1]$ 变成负数，答案直接崩掉。
2. **同年龄可以互发**：$a \ge 15$ 时 $a > a/2 + 7$ 成立，同龄人互为合法对象，所以 `[16,16]` 的答案是 2 而不是 0。别把「不能发给自己」误解成「不能发给同龄人」。
3. **只减 1，不减 $freq[a]$**：区间计数里只有 $x$ 本人需要排除；若减去整组人数，同龄互发会被全部抹掉。
4. **条件 3 不是「忽略」而是要论证**：直接删掉它对本题答案无影响，但必须像引理 1 那样说明「$b \le a$ 与 $a$ 的大小关系」使它自动失效；若哪天规则改为 $b > 100$ 且 $a \ge 100$ 也拒绝，结论就不同了。
5. **下界用整除**：写成 $b > a/2+7$ 的整数版本时，$a$ 为奇数要小心取整方向；直接用 $lo = \lfloor a/2 \rfloor + 8$ 最稳。
6. **$n = 1$**：没有任何有序对，答案为 0，算法自然成立（每组 `cnt` 会被减成 0）。
7. **返回类型**：答案峰值约 $4\times10^8$，用 `int` 安全；但若把 $freq[a] \times cnt$ 误写成先乘再除以某个数之类，容易在中间过程溢出，保持「直接乘」即可。

**延伸思考**：

- 若年龄上限不是 $120$ 而是 $10^9$，桶计数不再可行，应改用「排序 + 双指针」或「排序 + 对每个 $x$ 二分左右端点」，复杂度 $O(n \log n)$。
- 若题目改问「**互发**请求的对数」，由引理 1 需同时满足 $b \le a$ 与 $a \le b$，即 $a = b$，且要求 $a > a/2+7 \iff a \ge 15$；答案是 $\sum_{a \ge 15} \binom{freq[a]}{2}$。
- 若把年龄换成任意实数（去掉整数取整），下界要写成 $b > a/2+7$，区间端点不再对齐整数，浮点误差会成为新的坑。
