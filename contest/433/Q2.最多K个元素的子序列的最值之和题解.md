# LeetCode 最多K个元素的子序列的最值之和 题解

## 1. 题目概述

- **标题 / 题号**：最多K个元素的子序列的最值之和（#3428，medium）
- **链接**：https://leetcode.cn/problems/maximum-and-minimum-sums-of-at-most-size-k-subsequences/
- **来源**：LeetCode 第 433 场周赛 Q2
- **难度**：中等
- **标签**：数组、排序、组合数学、贡献法、动态规划

**题意**：给定整数数组 `nums` 与正整数 `k`，对所有**长度至多为 `k`** 的**非空子序列**求其**最大值与最小值之和**，返回总和模 $10^9 + 7$ 的结果。子序列按下标集合计数——即使元素值相同，选不同的下标也算不同的子序列。

**约束**：

- $1 \le n = \text{nums.length} \le 10^5$
- $0 \le \text{nums}[i] \le 10^9$
- $1 \le k \le \min(100, n)$

> 💡 **读题关键**：①「至多 $k$」而非「恰好 $k$」，长度 $1 \sim k$ 都要统计，且长度 1 的子序列 $\max = \min$，贡献是**两倍**元素值；② 子序列按**下标集合**计数，$n = 10^5$、$k = 100$ 时子序列总数约 $10^{342}$ 量级，逐个枚举绝无可能；③ $\max/\min$ 只取决于所选元素的**多重集**、与顺序无关——提示**可以排序**；④ $k \le 100 \ll n$，「前缀组合数之和」存在 $O(n)$ 递推；⑤ 模数 $10^9+7$ 是质数，除法走模逆元。

## 2. 示例

**示例 1**

```text
输入：nums = [1,2,3], k = 2
输出：24
解释：长度至多为 2 的子序列共 6 个：[1]、[2]、[3]、[1,2]、[1,3]、[2,3]，
各自的 min+max 依次为 2、4、6、3、4、5，总和 = 24。
```

**示例 2**

```text
输入：nums = [5,0,6], k = 1
输出：22
解释：长度恰为 1 时 min = max = 元素自身，总和 = (5+5) + (0+0) + (6+6) = 22。
```

**示例 3**

```text
输入：nums = [1,1,1], k = 2
输出：12
解释：[1] 出现 3 次、[1,1] 出现 3 次，每个子序列 min+max 均为 2，总和 12。
三个 1 是不同下标——重复元素由「代言人」约定正确分摊（见 3.2）。
```

**示例 4（自造，覆盖 k = n 的边界）**

```text
输入：nums = [3,1,2], k = 3
输出：28
解释：全部 7 个非空子序列的 min+max 依次为
[3]→6、[1]→2、[2]→4、[3,1]→4、[3,2]→5、[1,2]→3、[3,1,2]→4，总和 28。
k = n 时长度限制失效，T(i) 退化为 2^i（见 3.3）。
```

## 3. 解题思路

### 3.1 暴力思路：枚举下标集合

枚举所有大小 $1 \sim k$ 的下标集合，逐个累加 $\max + \min$。子序列总数为 $\sum_{j=1}^{k}\binom{n}{j}$，$n = 10^5$、$k = 100$ 时仅 $\binom{10^5}{100}$ 一项就达 $10^{342}$ 量级——**枚举视角彻底破产**。正确姿势是交换求和次序，统计**每个元素作为最值出现多少次**（贡献法）。小规模暴力程序（$n \le 10$）仍有价值：充当对拍器验证公式（本文公式已与暴力在 500 组含大量重复元素的随机数据下对拍通过）。

### 3.2 核心观察：排序 + 贡献法 + 代言人

![排序后拆贡献：最大值看左池、最小值看右池](images/kseq_sorted_contribution.svg)

交换求和次序，把「对每个子序列求 $\max+\min$ 再求和」改为「对每个元素数它当最值的次数」：

$$\text{ans} \;=\; \sum_{S}\big(\max S + \min S\big) \;=\; \sum_{i=0}^{n-1} \text{nums}[i]\cdot\big(c_i^{\max} + c_i^{\min}\big)$$

其中 $c_i^{\max}$（$c_i^{\min}$）是「$\text{nums}[i]$ 恰为所在子序列最大值（最小值）**代言人**」的子序列个数。三个观察把这两个计数做对：

**第一步：排序**。子序列由下标集合唯一决定，排序只是下标置换，$\max/\min$ 只看所选元素的多重集，置换前后子序列一一对应（引理 1）。

**第二步：代言人 = 最右 / 最左**。排序后数组非降，于是任何子序列 $S$ 的**最右元素值必是 $\max S$、最左元素值必是 $\min S$**——即便有并列也无歧义。约定：$\max$ 的贡献归 $S$ 的最右元素，$\min$ 归最左元素。每个子序列恰有一对代言人，计数不重不漏（引理 2）。这也是处理**重复元素**的关键：示例 3 里三个 1 各自分摊，不多数也不漏数。

**第三步：数出来**。看排序后的下标 $i$：

- $\text{nums}[i]$ 当**最大值** $\iff$ $i \in S$ 且其余元素全部来自**左侧**下标 $< i$——任何右侧元素都 $\ge \text{nums}[i]$，要么更大直接抢走最大值，要么相等但更靠右、抢走代言人身份；
- 当**最小值** $\iff$ $i \in S$ 且其余元素全部来自**右侧**下标 $> i$（完全镜像）。

子序列长度至多 $k$、已含 $i$ 本身，故其余至多再选 $k-1$ 个。记 $m = k - 1$、$T(i) = \sum_{j=0}^{\min(i,\,m)}\binom{i}{j}$，则

$$c_i^{\max} = T(i), \qquad c_i^{\min} = T(n-1-i)$$

三步合并：

$$\boxed{\;\text{ans} \;=\; \sum_{i=0}^{n-1} \text{nums}[i]\cdot\big(T(i) + T(n-1-i)\big) \;\;\bmod\; (10^9+7)\;}$$

> ⚠️ **两个要点**：① 长度 1 的子序列自动被覆盖——两侧「其余元素」都取空集时，它同时计入 $c_i^{\max}$ 与 $c_i^{\min}$，贡献恰为 $2\cdot\text{nums}[i]$，无需特判也别漏算；② $T(i)$ 只依赖 $(i, k)$、**与数组数值无关**——最小值一侧不必另写一套逻辑，直接复用同一张 $T$ 表查镜像下标 $n-1-i$。

### 3.3 算法流程：T(i) 的 O(n) 递推

![T(i) 的池子分类与执行流程](images/kseq_T_recurrence.svg)

$T(i)$ 即「$i$ 个元素的池子里任选至多 $m$ 个」的方案数。按第 $i$ 个元素是否入池分类：不选有 $T(i-1)$ 种；选它则其余至多 $m-1$ 个，为 $T(i-1) - \binom{i-1}{m}$ 种（当 $i > m$；$i \le m$ 时修正项为零）。得递推

$$T(i) \;=\; 2\,T(i-1) - \binom{i-1}{m}\cdot[\,i > m\,], \qquad T(0) = 1$$

$i \le m$ 时 $T(i) = 2^i$，正是长度限制未生效的情形。剩下的硬骨头是 $\binom{i-1}{m}$：**增量维护** $C(i,m) = C(i-1,m)\cdot\dfrac{i}{i-m}$，除法用模逆元；$p = 10^9+7$ 为质数，线性逆元筛 $inv[i] = -\lfloor p/i\rfloor\cdot inv[p \bmod i] \bmod p$，$O(n)$ 建整表。

**完整流程**：

1. 排序 `nums`，令 $m = k-1$；
2. 线性逆元筛建 $inv[1..n]$；
3. 一趟递推 $T$：`T[0] = 1`、`comb = 1`（即 $C(m,m)$）；对 $i = 1 \ldots n-1$ 先 `T[i] = 2·T[i−1]`，若 $i > m$ 再减 `comb` 并更新 `comb ← comb·i·inv[i−m]`；
4. 汇总 $\text{ans} = \sum_i \text{nums}[i]\cdot(T[i] + T[n-1-i]) \bmod p$。

> 💡 **备选实现**：① 建阶乘表 + 逆元阶乘表后 $\binom{i-1}{m}$ 可 $O(1)$ 查表，整体同样 $O(n)$，且可复用于其他组合统计；② 对每个 $i$ 直接累加 $\sum_{j\le k-1}\binom{i}{j}$ 是 $O(nk) \le 10^7$ 次乘法取模——C++ 能过，Python 有超时风险，递推版更稳。

### 3.4 示例演算

![示例演算：nums = [1,2,3], k = 2](images/kseq_example_walkthrough.svg)

以示例 1（`nums = [1,2,3], k = 2`，$m = 1$）走查。递推：$T(0) = 1$；$T(1) = 2T(0) = 2$（$1 \le m$ 不修正）；$T(2) = 2 \cdot 2 - \binom{1}{1} = 3$（直接验证：$\binom{2}{0} + \binom{2}{1} = 3$ ✓）。

| $i$ | $\text{nums}[i]$ | 最大值次数 $T(i)$ | 最小值次数 $T(n-1-i)$ | 贡献 |
|---|---|---|---|---|
| 0 | 1 | $T(0)=1$ | $T(2)=3$ | $1\times(1+3)=4$ |
| 1 | 2 | $T(1)=2$ | $T(1)=2$ | $2\times(2+2)=8$ |
| 2 | 3 | $T(2)=3$ | $T(0)=1$ | $3\times(3+1)=12$ |

总和 $4 + 8 + 12 = 24$ ✓。回验：示例 2（$k=1 \Rightarrow m=0$，$T \equiv 1$）$\text{ans} = 2(5+0+6) = 22$ ✓；示例 3（$[1,1,1]$，$T = [1,2,3]$）三个 1 各贡献 $1\times(1+3) = 4$，合计 $12$ ✓——重复元素被代言人约定正确分摊。

## 4. 算法细节

1. **排序的合法性**：子序列 = 下标集合，排序是下标置换，把原数组的每个下标集合**双射**地映到排序数组的下标集合，而 $\max/\min$ 只依赖多重集，故排序前后的子序列一一对应、最值逐个相等。
2. **代言人把并列歧义消为零**：「$i$ 是 $S$ 的最右元素」⟺「$i \in S$ 且 $S \setminus \{i\} \subseteq \{0,\dots,i-1\}$」，这是一个纯下标条件，与数值是否并列无关——这正是重复元素下计数仍不重不漏的原因。
3. **T 表只算一遍**：$c_i^{\max} = T(i)$ 与 $c_i^{\min} = T(n-1-i)$ 共用同一张表，汇总循环里一次乘法加法同时处理两侧。
4. **comb 的初值与更新时机**：`comb` 初值取 $C(m,m) = 1$，恰在 $i = m+1$ 首次启用（此前 $i \le m$ 不需要修正），边界零特判；每次用完（减掉 $C(i-1,m)$）后立刻经 `comb·i·inv[i−m]` 推到 $C(i, m)$，供下一轮 $i+1$ 使用。
5. **线性逆元筛**：由 $p = i\cdot\lfloor p/i \rfloor + (p \bmod i)$ 移项得 $inv[i] = -\lfloor p/i\rfloor\cdot inv[p\bmod i] \bmod p$，其中 $p \bmod i < i$ 保证递推无环；仅需 `inv[1..n]`，与 `comb` 更新用到的 `inv[i−m]`（$1 \le i-m \le n-1$）范围一致。
6. **溢出控制**：$\text{nums}[i] \le 10^9 < p$，乘法前先 `% MOD`；C++ 用 `long long`，单个乘积 $\le 10^9 \times 2\times10^9 < 9.2\times10^{18}$ 不溢出。

## 5. 正确性证明

**引理 1（排序不变性）**：将 `nums` 排序不改变答案。

**证明**：子序列由下标集合唯一决定。设 $\sigma$ 为排序对应的下标置换，则原数组的每个下标集合 $S$ 被双射地映为排序数组的下标集合 $\sigma(S)$，且两者所选元素构成相同的多重集，故 $\max S' = \max S$、$\min S' = \min S$（$S'$ 为对应集合）。长度在置换下不变。因此两个数组上的「全部长度 $\le k$ 子序列的 $\max+\min$ 总和」逐项相等。∎

**引理 2（代言人唯一性）**：对排序数组任意非空下标集合 $S$，恰存在一个 $i_{\max} \in S$ 满足「$i \in S$ 且 $S \setminus \{i\} \subseteq \{0,\dots,i-1\}$」，且 $\text{nums}[i_{\max}] = \max S$；对最小值对称成立（条件改为 $S \setminus \{i\} \subseteq \{i+1,\dots,n-1\}$）。

**证明**：条件「$i \in S$ 且其余元素均在 $i$ 左侧」等价于「$i$ 是 $S$ 的最大下标」，这样的 $i$ 唯一，即 $i_{\max} = \max S$（下标取最大）。数组非降，故 $i_{\max}$ 右侧无 $S$ 的元素、$S$ 中所有元素值 $\le \text{nums}[i_{\max}]$，即 $\text{nums}[i_{\max}] = \max S$，且 $S$ 中与它并列的元素（若有）下标更小，不满足条件。最小值情形镜像。∎

**引理 3（计数公式）**：$c_i^{\max} = T(i) = \sum_{j=0}^{\min(i,\,m)}\binom{i}{j}$，$c_i^{\min} = T(n-1-i)$，其中 $m = k-1$。

**证明**：由引理 2，$\text{nums}[i]$ 是某子序列 $S$ 的最大值代言人 ⟺ $S = \{i\} \cup A$，$A \subseteq \{0,\dots,i-1\}$。长度约束 $1 \le |S| \le k$ 即 $0 \le |A| \le m$。左端恰有 $i$ 个候选元素，故 $c_i^{\max} = \sum_{j=0}^{\min(i,m)}\binom{i}{j} = T(i)$。最小值情形中 $A \subseteq \{i+1,\dots,n-1\}$ 含 $n-1-i$ 个候选，镜像得 $c_i^{\min} = T(n-1-i)$。∎

**引理 4（T 的递推）**：$T(0) = 1$；$i \le m$ 时 $T(i) = 2^i$；$i > m$ 时 $T(i) = 2T(i-1) - \binom{i-1}{m}$。

**证明**：$T(i)$ 是 $i$ 元池 $\{0,\dots,i-1\}$ 中大小 $\le m$ 的子集个数。按元素 $i-1$ 是否入选分类：不选时是 $i-1$ 元池的大小 $\le m$ 子集，共 $T(i-1)$ 个；选时其余来自 $i-1$ 元池且大小 $\le m-1$，共 $\sum_{j=0}^{\min(i-1,\,m-1)}\binom{i-1}{j}$ 个。若 $i \le m$，则 $i-1 \le m-1$，「大小 $\le m-1$」对 $i-1$ 元池无约束，该数为 $2^{i-1} = T(i-1)$，故 $T(i) = 2^i$；若 $i > m$，则 $i-1 \ge m$，该数 $= T(i-1) - \binom{i-1}{m}$（从「$\le m$」中扣去「恰为 $m$」），故 $T(i) = 2T(i-1) - \binom{i-1}{m}$。∎

**定理**：算法返回值等于所有长度至多为 $k$ 的子序列的 $\max + \min$ 总和模 $p$。

**证明**：所求为 $S_{\text{total}} = \sum_{1 \le |S| \le k}(\max S + \min S)$。由引理 2，每个 $S$ 的 $\max$ 项恰好由其最大下标 $i_{\max}$ 承担、$\min$ 项恰好由最小下标承担，故按承担者重新归组：$S_{\text{total}} = \sum_i \text{nums}[i]\cdot(c_i^{\max} + c_i^{\min})$。由引理 3，$c_i^{\max} = T(i)$、$c_i^{\min} = T(n-1-i)$，算法汇总的正是该表达式；由引理 4，递推算出的 $T$ 与定义一致。每一步运算均取模，且只涉及加、减、乘与模逆元（除数为 $[1, n]$ 内与质数 $p$ 互素的整数），结果与先精确计算再取模一致。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \log n)$，排序主导；逆元筛、$T$ 递推、汇总三趟均为 $O(n)$。相比之下逐项累加 $\sum_j \binom{i}{j}$ 的写法是 $O(nk) \le 10^7$，也可通过但多一个量级。
- **空间复杂度**：$O(n)$，逆元表 `inv` 与 `T` 表两张线性数组；排序若用原地实现不再计入。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int minMaxSums(vector<int>& nums, int k) {
        constexpr long long MOD = 1'000'000'007LL;
        const int n = nums.size();
        sort(nums.begin(), nums.end());
        const int m = k - 1;

        // ① 线性逆元表 inv[1..n]：由 p = i*(p/i) + p%i 移项即得
        vector<long long> inv(n + 1);
        inv[1] = 1;
        for (int i = 2; i <= n; ++i)
            inv[i] = (MOD - MOD / i) * inv[MOD % i] % MOD;

        // ② 一趟递推 T(i) = Σ_{j=0}^{min(i,m)} C(i,j)
        vector<long long> T(n);
        T[0] = 1;
        long long comb = 1;  // 增量维护 C(i-1, m)，初值 C(m,m)=1
        for (int i = 1; i < n; ++i) {
            T[i] = 2 * T[i - 1] % MOD;
            if (i > m) {  // i ≤ m 时 T(i)=2^i，无需修正
                T[i] = (T[i] - comb + MOD) % MOD;
                comb = comb * i % MOD * inv[i - m] % MOD;  // C(i-1,m) → C(i,m)
            }
        }

        // ③ 汇总：nums[i] 以 T(i) 次当最大值、T(n-1-i) 次当最小值
        long long ans = 0;
        for (int i = 0; i < n; ++i)
            ans = (ans + (long long)nums[i] % MOD * ((T[i] + T[n - 1 - i]) % MOD)) % MOD;
        return (int)ans;
    }
};
```

### Python

```python
class Solution:
    def minMaxSums(self, nums: List[int], k: int) -> int:
        MOD = 10**9 + 7
        nums.sort()
        n, m = len(nums), k - 1

        inv = [0] * (n + 1)  # ① 线性逆元表 inv[1..n]
        inv[1] = 1
        for i in range(2, n + 1):
            inv[i] = (MOD - MOD // i) * inv[MOD % i] % MOD

        T = [0] * n  # ② T(i) = Σ_{j=0}^{min(i,m)} C(i,j)
        T[0] = 1
        comb = 1  # 增量维护 C(i-1, m)，初值 C(m,m)=1
        for i in range(1, n):
            T[i] = 2 * T[i - 1] % MOD
            if i > m:  # i ≤ m 时 T(i)=2^i，无需修正
                T[i] = (T[i] - comb) % MOD
                comb = comb * i % MOD * inv[i - m] % MOD

        # ③ 汇总：nums[i] 以 T(i) 次当最大值、T(n-1-i) 次当最小值
        return sum(v * (T[i] + T[n - 1 - i]) for i, v in enumerate(nums)) % MOD
```

## 8. 边界情况与易错点

1. **「至多 k」不是「恰好 k」**：长度 $1 \sim k$ 全都要算；长度 1 的子序列贡献 $2\cdot\text{nums}[i]$，由两侧取空集自动覆盖，手写特判反而容易多算。
2. **重复元素是最大坑点**：不能按「值严格大于 / 小于」数左右侧个数（相等值会被漏掉或重计）。必须用代言人等价条件「其余元素全部来自左侧 / 右侧」——纯下标条件，天然无歧义。
3. **C++ 负数取模**：`T[i] - comb` 可能为负，先 `+ MOD` 再取模；Python 的 `%` 恒非负无此顾虑。
4. **乘法溢出**：$\text{nums}[i]$ 可达 $10^9$，乘法前先 `% MOD`，且全程 `long long`（$10^9 \times 2\times10^9$ 已达 `int` 的 $10^{18}$ 倍量级）。
5. **k = n 的退化**：$m = k-1 \ge n-1$，修正分支永不进入，$T(i) = 2^i$，公式退化为 $\sum_i \text{nums}[i]\,(2^i + 2^{n-1-i})$——与无长度限制版本一致，代码无需任何特判。
6. **n = 1**：递推循环体不执行，`T = [1]`，答案 $2\cdot\text{nums}[0]$，无需特判；注意逆元表长度按 $n+1$ 分配，`n = 1` 时 `inv[1]` 仍可写。
7. **inv 表下标范围**：更新用 `inv[i-m]`，$1 \le i - m \le n-1$，建 `inv[0..n]` 足够；$m = k-1$ 最小为 0（$k=1$），此时修正从 $i=1$ 起每步启用且 $C(i-1,0)=1$，递推给出 $T \equiv 1$——正对应「子序列长度只能为 1」，与示例 2 的 $T \equiv 1$ 一致。
8. **排序别忘了**：所有推导都建立在「非降」前提上；忘排序时若数组恰好多为递增，小样例可能蒙对，大样例必错。

- [LeetCode 891. 子序列宽度之和](https://leetcode.cn/problems/sum-of-subsequence-widths/)：同一套「排序 + 贡献法」骨架的无长度限制版（求 $\sum(\max - \min)$，答案为 $\sum \text{nums}[i]\,(2^i - 2^{n-1-i})$），本题 $k = n$ 特例的直接亲属。
- [LeetCode 907. 子数组的最小值之和](https://leetcode.cn/problems/sum-of-subarray-minimums/)：贡献法数最小值出现次数的**子数组**版，用单调栈求两侧控制范围，可与本题对比「子序列靠排序、子数组靠单调栈」的差异。
- [LeetCode 2104. 子数组范围和](https://leetcode.cn/problems/sum-of-subarray-ranges/)：$\sum(\max - \min)$ 的子数组版，练「按最值归位拆贡献」的手感。
- [LeetCode 3430. 最多K个元素的子数组的最值之和](https://leetcode.cn/problems/maximum-and-minimum-sums-of-at-most-size-k-subarrays/)：本场 Q4 的主站版本——把「子序列」换成「子数组」，贡献法仍在但计数改为**滑动窗口 + 单调栈/前缀和**，两题对照正是「同一种拆贡献思想在两种结构上的分岔」。

**延伸思考**：

- 若改为「长度**恰好** $k$」：$c_i^{\max} = \binom{i}{k-1}$，直接查组合数即可，反而更简单；「至多」与「恰好」之间隔着一个前缀和（$T$ 表正是组合数的前缀和）。
- 若改问「$\max$ 与 $\min$ 相等的子序列个数」（即所选元素全相等）：设值 $v$ 出现 $c$ 次，答案为 $\sum_v \sum_{j=1}^{\min(k,c)}\binom{c}{j}$——按值分桶后每桶独立套用 $T$ 式前缀和即可，是本题计数工具的又一种落点。
- 模逆元的另一条路：把 $C(i,m) = C(i-1,m)\cdot\frac{i}{i-m}$ 改写为「分子连乘区间、分母连乘区间」后统一批量求逆元，可将逆元表换成单点 `pow(x, p-2, p)`，在 $n$ 更大但只需少量组合数时更省空间。
