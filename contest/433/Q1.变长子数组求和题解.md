# LeetCode 变长子数组求和 题解

## 1. 题目概述

- **标题 / 题号**：变长子数组求和（#3427，easy）
- **链接**：https://leetcode.cn/problems/sum-of-variable-length-subarrays/
- **来源**：LeetCode 第 433 场周赛 Q1
- **难度**：简单
- **标签**：数组、前缀和

**题意**：给定长度为 `n` 的整数数组 `nums`。对**每个**下标 `i`（`0 <= i < n`），从 `i` 向左延伸**至多** `nums[i]` 个元素，定义子数组 `nums[start ... i]`，其中 `start = max(0, i - nums[i])`（向左越界就停在 `0`）。返回所有下标对应子数组中元素的总和。

**约束**：

- `1 <= n == nums.length <= 100`
- `1 <= nums[i] <= 1000`

## 2. 示例

**示例 1**

```text
输入：nums = [2,3,1]
输出：11
解释：
i=0: start = max(0, 0−2) = 0，子数组 [2]，和 2
i=1: start = max(0, 1−3) = 0，子数组 [2,3]，和 5
i=2: start = max(0, 2−1) = 1，子数组 [3,1]，和 4
总和 = 2 + 5 + 4 = 11
```

**示例 2**

```text
输入：nums = [3,1,1,2]
输出：13
解释：
i=0: start = 0，子数组 [3]，和 3
i=1: start = 0，子数组 [3,1]，和 4
i=2: start = 1，子数组 [1,1]，和 2
i=3: start = 1，子数组 [1,1,2]，和 4
总和 = 3 + 4 + 2 + 4 = 13
```

**示例 3（自造，覆盖每个下标都触发钳位的情况）**

```text
输入：nums = [5,5,5]
输出：30
解释：每个 i 都有 i − nums[i] < 0，start 恒被钳位为 0，
子数组依次为 [5]、[5,5]、[5,5,5]，和为 5 + 10 + 15 = 30。
```

## 3. 解题思路

### 3.1 暴力思路

对每个 `i` 先算 `start = max(0, i - nums[i])`，再开一个内层循环从 `start` 逐个累加到 `i`。最坏每个子数组长度为 $O(n)$，总时间 $O(n^2)$。本题 $n \le 100$，$O(n^2)$ 只有 $10^4$ 量级，完全能过；但「对每个下标求一段**连续区间**的和」是**前缀和**的标准触发场景——签到题也值得把模板走对，一旦 $n$ 加强到 $10^5$，暴力就不够看了。

### 3.2 核心观察：每个下标要的是一段连续区间和 → 前缀和 O(1) 查询

![每个下标 i 的窗口：从 max(0, i−nums[i]) 到 i](images/varlen_window_concept.svg)

预处理前缀和 $pre$，令 $pre[0] = 0$、$pre[i+1] = pre[i] + nums[i]$，则任意区间 $[l, r]$ 的和为

$$\sum_{k=l}^{r} nums[k] = pre[r+1] - pre[l]$$

于是每个下标 $i$ 对答案的贡献就是 $pre[i+1] - pre[\max(0,\, i - nums[i])]$，一趟遍历累加即可，内层循环整个消失。

### 3.3 算法流程

![算法流程：一趟建前缀和 + 一趟累加](images/varlen_prefix_flow.svg)

1. 构建长度为 $n+1$ 的前缀和数组 `pre`（`pre[0] = 0`）。
2. 遍历 `i = 0 … n−1`：计算 `start = max(0, i - nums[i])`。
3. 累加 `ans += pre[i+1] - pre[start]`。
4. 返回 `ans`。

### 3.4 示例演算

![示例演算：nums = [3,1,1,2]](images/varlen_example_walkthrough.svg)

以 `nums = [3,1,1,2]` 为例，前缀和为 `pre = [0, 3, 4, 5, 7]`：

| i | nums[i] | i−nums[i] | start | 子数组 | pre[i+1]−pre[start] |
|---|---------|-----------|-------|--------|---------------------|
| 0 | 3 | −3 | 0 | [3] | 3 − 0 = 3 |
| 1 | 1 | 0 | 0 | [3,1] | 4 − 0 = 4 |
| 2 | 1 | 1 | 1 | [1,1] | 5 − 3 = 2 |
| 3 | 2 | 1 | 1 | [1,1,2] | 7 − 3 = 4 |

总和 $3 + 4 + 2 + 4 = 13$。注意前两行：`i − nums[i]` 为负或为零时 `start` 均被钳位为 `0`，对应上表中 `pre[start] = pre[0] = 0`，区间和公式依然成立。

## 4. 算法细节

1. **前缀和带偏移存储**：定义 `pre[0] = 0`、`pre[i+1] = pre[i] + nums[i]`，区间 `[l, r]` 的和统一写成 `pre[r+1] − pre[l]`，`l = 0` 时无需特判。
2. **start 钳位**：`i − nums[i]` 可能为负（`nums[i] ≥ 1`，且 `i` 较小时必然为负），必须 `max(0, …)`，否则 `pre` 数组下标越界。
3. **数据类型**：答案上界约为 $100 \times 100 \times 1000 = 10^7$，C++ `int` 足够；Python 无需关心。
4. **两趟写法最稳**：先一趟建 `pre`、再一趟累加，比单趟内联更不易写错下标；若追求 $O(1)$ 额外空间，可直接在 `nums` 原地原地覆盖为前缀和，但可读性略差。

## 5. 正确性证明

**引理 1**（前缀和区间公式）：对任意 $0 \le l \le r \le n-1$，有 $pre[r+1] - pre[l] = \sum_{k=l}^{r} nums[k]$。

**证明**：由定义 $pre[t] = \sum_{k=0}^{t-1} nums[k]$，故 $pre[r+1] - pre[l] = \sum_{k=0}^{r} nums[k] - \sum_{k=0}^{l-1} nums[k]$。由于 $l \le r$，后一项的求和范围 $[0, l-1]$ 是前一项范围 $[0, r]$ 的前缀，逐项相消后剩下 $\sum_{k=l}^{r} nums[k]$。∎

**引理 2**（窗口合法）：对每个 $0 \le i < n$，$start_i = \max(0,\, i - nums[i])$ 满足 $0 \le start_i \le i$，即子数组 $nums[start_i \ldots i]$ 非空。

**证明**：$start_i \ge 0$ 由 $\max$ 显然成立。另一方面，$\max$ 的两个参数中 $0 \le i$ 恒成立；又因 $nums[i] \ge 1$，有 $i - nums[i] \le i - 1 < i$。两个参数都不超过 $i$，故 $\max$ 结果 $start_i \le i$。∎

**定理**：算法返回值等于所有下标 `i` 对应子数组元素之和的总和。

**证明**：所求答案为 $S = \sum_{i=0}^{n-1} \sum_{k=start_i}^{i} nums[k]$。由引理 2，每个区间 $[start_i, i]$ 满足 $0 \le start_i \le i \le n-1$，落在引理 1 的适用范围内，故 $\sum_{k=start_i}^{i} nums[k] = pre[i+1] - pre[start_i]$。算法逐下标累加的正是该表达式，与 $S$ 逐项相等。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。一趟构建前缀和 $O(n)$，一趟累加 $O(n)$；每个下标的区间和查询是 $O(1)$。相比之下暴力做法为 $O(n^2)$。
- **空间复杂度**：$O(n)$。前缀和数组占 $n+1$ 个元素；换取的是线性时间（暴力做法 $O(1)$ 空间，但时间平方）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int subarraySum(vector<int>& nums) {
        int n = nums.size();
        vector<int> pre(n + 1, 0);
        for (int i = 0; i < n; i++) pre[i + 1] = pre[i] + nums[i];
        int ans = 0;
        for (int i = 0; i < n; i++) {
            int start = max(0, i - nums[i]);
            ans += pre[i + 1] - pre[start];
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def subarraySum(self, nums: List[int]) -> int:
        pre = [0]
        for x in nums:
            pre.append(pre[-1] + x)
        return sum(pre[i + 1] - pre[max(0, i - x)]
                   for i, x in enumerate(nums))
```

## 8. 边界情况与易错点

1. **start 钳位是最大坑点**：`i − nums[i]` 经常为负（`i = 0` 时恒为负），漏写 `max(0, …)` 会数组越界或答案错误。
2. **前缀和下标偏移**：区间和是 `pre[i+1] − pre[start]`，误写成 `pre[i] − pre[start]` 会少加 `nums[i]` 本身。
3. **溢出估算**：上界 $10^7$ 远小于 `int` 上限（约 $2.1 \times 10^9$），无需 `long long`，但估算习惯要保持。
4. **n = 1**：唯一下标 `i = 0`，`start = 0`，答案即 `nums[0]`，无需特判。
5. **子数组永远非空**：`nums[i] ≥ 1` 保证 `start_i ≤ i`（引理 2），窗口至少包含 `nums[i]` 自身，不存在空区间求和的问题。
