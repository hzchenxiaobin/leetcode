# LeetCode 最多能完成排序的块 II 题解

## 1. 题目概述

- **标题 / 题号**：最多能完成排序的块 II（#768，hard）
- **链接**：https://leetcode.cn/problems/max-chunks-to-make-sorted-ii/
- **来源**：LeetCode 第 68 场周赛 Q4
- **难度**：困难
- **标签**：栈、贪心、数组、排序、单调栈

**题意**：给定整数数组 $arr$（**元素可重复**），把数组划分成若干连续块，对每块**单独升序排序**后再按原顺序拼接，要求拼接结果恰好等于整个数组升序排序的结果。求能划分出的**最多块数**。

**约束**：

- $1 \le arr.length \le 2000$
- $0 \le arr[i] \le 10^{8}$（值域远大于 $n$，不能开桶 / 离散化当索引）

$n \le 2000$ 时 $O(n^2)$ 也能通过，但本题的标准做法是 $O(n)$ 的**单调栈**——它的思想值得单独记住。

## 2. 示例

**示例 1**

```text
输入：arr = [5,4,3,2,1]
输出：1
解释：分成 2 块或更多块都无法得到所需结果。
      例如 [5,4] + [3,2,1] → [4,5,1,2,3]，不是有序数组。
```

**示例 2**

```text
输入：arr = [2,1,3,4,4]
输出：4
解释：可以分成 [2,1], [3,4,4] 两块；
      但分成 [2,1], [3], [4], [4] 能得到最多块数 4。
```

**补充示例（用于演示合并过程，非官方）**

```text
输入：arr = [4,4,2,3,1,5]
输出：2
解释：唯一合法的切分是 [4,4,2,3,1] + [5]，
      排序得 [1,2,3,4,4] + [5]，恰好整体有序。
```

## 3. 解题思路

### 3.1 暴力思路

答案是一个切分方案，切点有 $n-1$ 个候选，枚举全部 $2^{n-1}$ 种子集，再对每种方案逐块排序验证，是 $O(2^{n} \cdot n\log n)$，$n = 2000$ 时毫无可能。

稍好一点的暴力：逐个判断「切点 $i$ 是否合法」，对每个 $i$ 求出「左侧最大值」和「右侧最小值」需要扫一遍，共 $O(n^2)$（每次重新排序则是 $O(n^2 \log n)$）。$O(n^2)$ 在本题能过，但我们要的是把两次扫描也省掉。

### 3.2 核心观察：切点判定条件

![切点判定：前缀最大值 ≤ 后缀最小值](images/wc68_q4_cut_condition.svg)

**引理 1 的结论**：在 $i$ 与 $i+1$ 之间切开，当且仅当

$$\max\bigl(a[0..i]\bigr) \le \min\bigl(a[i+1..n-1]\bigr)$$

**为什么**：若存在 $p \le i < q$ 使 $a[p] > a[q]$，则排序后 $a[p]$ 必须排在 $a[q]$ 之后；但 $a[p]$ 在左边的块、$a[q]$ 在右边的块，拼接时左块整块排在前面，于是 $a[p]$ 反而出现在 $a[q]$ 前面，不可能有序。反之若左侧所有元素都 $\le$ 右侧所有元素，则左块元素作为**多重集**恰好是全体最小的 $i+1$ 个，左块内部排序就得到排序后的前 $i+1$ 个位置，右侧同理，切开一定合法。

由此得到一个非常干净的推论：**答案 = 1 + 合法切点个数**。因为「合法」只取决于切点两侧的元素集合，任意多个合法切点可以同时切开而不互相干扰（引理 2 会证）。

如果只是想 $O(n)$ 求出可切点个数，可以预处理后缀最小值数组 $\text{suf}[i] = \min(a[i..])$，再从左往右维护前缀最大值，逐个比较 $\text{pmax}[i] \le \text{suf}[i+1]$。这需要 $O(n)$ 的额外空间，而且「未来的最小值」这种全局信息必须提前算好。

### 3.3 算法流程：单调栈在线维护

![单调栈：栈中存每块的最大值](images/wc68_q4_monotonic_stack.svg)

把「右侧最小值」换成**悬而未决的块**：从左到右扫描，用一个栈保存「当前已划定分块中每一块的最大值」。可以证明（引理 3）栈自底向上**非递减**，且栈的长度就是当前前缀的最优块数。

- **$x \ge$ 栈顶**：$x$ 不小于此前所有块的最大值，它右边还没有更小的元素能把它「拉」回左边的块，因此 $x$ 可以安全地自成一块 → `push(x)`。
- **$x <$ 栈顶**：栈顶那块的最大值出现在 $x$ 之前却大于 $x$，排序后它必须排到 $x$ 之后，跨过了 $x$ 的位置 → 这块必须和 $x$ 合并。所有满足条件的块一定在栈顶连续一段（栈非递减），把它们全部弹出，记下其中的最大值 $mx$（因为非递减，**第一个弹出的就是最大值**），再把 $mx$ 压回，表示合并后的块最大值为 $mx$。

```text
st = []
for x in arr:
    if st 为空 or x >= st.top:
        st.push(x)                  # x 自成一块
    else:
        mx = st.top                 # 第一个弹出的就是被合并块中的最大值
        while st 非空 and st.top > x:
            st.pop()                # 这些块的最大值也大于 x，一起并入
        st.push(mx)                 # 合并后的块最大值为 mx（mx > x）
return len(st)
```

### 3.4 示例演算

![示例 [4,4,2,3,1,5] 的切点走查](images/wc68_q4_walkthrough.svg)

对 $a = [4,4,2,3,1,5]$ 逐个切点验证：

| $i$ | $a[i]$ | 前缀 $\max a[0..i]$ | 右侧 $\min a[i+1..]$ | 可切 |
|-----|--------|---------------------|----------------------|------|
| 0 | 4 | 4 | 1 | ✗ |
| 1 | 4 | 4 | 1 | ✗ |
| 2 | 2 | 4 | 1 | ✗ |
| 3 | 3 | 4 | 1 | ✗ |
| 4 | 1 | 4 | 5 | ✓ |

只有 $i = 4$ 可切，故答案为 $1 + 1 = 2$；两块分别是 $[4,4,2,3,1]$ 与 $[5]$。

用单调栈走一遍同一数组：读入 4 → 栈 $[4]$；读入 4，$4 \ge 4$ → 栈 $[4,4]$；读入 2，$2 < 4$，弹出 4、4 并压回 $mx = 4$ → 栈 $[4]$；读入 3 → 栈 $[4]$；读入 1 → 栈 $[4]$；读入 5，$5 \ge 4$ → 栈 $[4,5]$。栈长 2，答案 2。

再对照官方示例 2 的 $[2,1,3,4,4]$：读入 2 → $[2]$；读入 1 弹出 2、压回 2 → $[2]$；读入 3 → $[2,3]$；读入 4 → $[2,3,4]$；读入 4，$4 \ge 4$ → $[2,3,4,4]$，栈长 4，正是答案。两个相等的 4 能各自成块，靠的正是 `>=` 而不是 `>`。

## 4. 算法细节

1. **栈单调不变量**：栈中值自底向上非递减。新元素只有在 $\ge$ 栈顶时才入栈，合并又是把「一段栈顶」替换成其中最大的那个值，被压回的值 $\ge$ 剩下的栈顶（因为剩下的栈顶 $\le x < mx$），不变量始终成立。
2. **等号必须归入「新块」**：$x = $ 栈顶时**不合并**。相等的元素排序后位置可以互换，不会造成跨块逆序；若写成 `x > st.top` 才新开一块，$[2,1,3,4,4]$ 会被合并成 3 块而错答。同理 $[0,0,0]$ 的答案是 3。
3. **压回的是 $mx$ 而不是 $x$**：合并后这块的最大值仍是原来那些被弹块的最大值。若图省事压入 $x$，栈就不再记录块的真实最大值，后续判断会失效——$[3,1,2]$ 会被错答成 2（正确答案 1），$[3,1,4,2,5]$ 会被错答成 3（正确答案 2）。
4. **只需和栈顶比较**：由于栈非递减，所有 $> x$ 的块必然构成栈顶的连续一段，一旦 `st.top <= x` 就可以停止。
5. **栈的实现**：用 `vector` 手动当栈（`push_back` / `back` / `pop_back`）比 `std::stack` 快，且 C++ 里先 `reserve(n)` 避免扩容。Python 直接用 `list`。
6. **均摊 $O(1)$**：每个元素最多入栈一次、出栈一次，所以整个循环是 $O(n)$，不存在嵌套循环导致的 $O(n^2)$。
7. **等价的离线写法（可用来对拍）**：预处理后缀最小值 $\text{suf}[i] = \min(a[i..])$，一遍扫描维护前缀最大值 $\text{pmax}$，统计满足 $\text{pmax} \le \text{suf}[i+1]$ 的位置数再加 1，同样是 $O(n)$，但要 $O(n)$ 数组；单调栈把这份「后缀信息」压缩成了栈。

## 5. 正确性证明

**引理 1（切点判定）**：在 $i$ 与 $i+1$ 之间切开是合法的，当且仅当 $\max(a[0..i]) \le \min(a[i+1..n-1])$。

**证明**：

- **必要性**：设该切点属于某个合法划分。取 $p \le i$ 使 $a[p]$ 为左侧最大，取 $q > i$ 使 $a[q]$ 为右侧最小。$p$、$q$ 分属不同块且 $p$ 的块在 $q$ 的块之前。拼接结果整体有序，故前一块的每个元素 $\le$ 后一块的每个元素，即 $a[p] \le a[q]$，从而 $\max(a[0..i]) \le \min(a[i+1..])$。
- **充分性**：若条件成立，则左侧元素多重集恰为全体最小的 $i+1$ 个。左侧各块分别排序后，按块顺序拼接得到的就是这 $i+1$ 个元素的升序序列；右侧同理。二者拼接即为全局升序。∎

**引理 2（合法切点可同时取）**：任意合法切点集合可以同时切开，且任何合法划分的每个切点都是合法切点；故最大块数 $= 1 + \#\{\text{合法切点}\}$。

**证明**：设 $i < j$ 都是合法切点。由引理 1，$\max(a[0..i]) \le \min(a[i+1..j])$ 且 $\max(a[0..j]) \le \min(a[j+1..])$；中间块 $[i+1..j]$ 的元素多重集等于「全体最小 $j+1$ 个」减去「全体最小 $i+1$ 个」，故单独排序后正好落在排序数组的第 $i+1 \sim j$ 位，三段拼接有序。对任意多个切点重复该论证即得同时切开的合法性。另一方面，由引理 1 必要性，任何合法划分的切点都必是合法切点，所以块数上限就是 $1 + $ 合法切点数，而全部切开恰好达到该上限。∎

**引理 3（栈不变量）**：处理完前缀 $a[0..k]$ 后，栈中元素恰好是「把 $a[0..k]$ 视为独立问题时的最大块划分」中各块的最大值，且自底向上非递减。

**证明**：对 $k$ 归纳。

- $k = 0$：只有一个元素，一块，栈为 $[a[0]]$。
- 归纳步：设 $k-1$ 时成立，加入 $x = a[k]$。旧切点 $i \le k-2$ 在新前缀中仍合法 $\iff \max(a[0..i]) \le \min(a[i+1..k]) = \min\bigl(\min(a[i+1..k-1]),\, x\bigr)$。旧条件 $\max(a[0..i]) \le \min(a[i+1..k-1])$ 已成立，故该切点保留 $\iff$ 其**左侧块的最大值** $\le x$。由归纳假设栈值即各块最大值且非递减，满足「$\le x$」的块是栈底连续一段，其余（值 $> x$）是栈顶连续一段，它们与 $x$ 合并为一块，新块最大值为 $\max(mx, x) = mx$（$mx > x$），与算法「弹出全部 $> x$ 的块、压回 $mx$」一致；若无块被弹出，则 $x$ 自成新块，也一致。∎

**定理**：算法返回的 `len(st)` 等于最大块数。

**证明**：由引理 3，扫描结束后栈长等于整个数组最大块划分的块数；由引理 2，该划分的块数就是题目所求的最大块数。∎

## 6. 复杂度分析

- **时间**：$O(n)$。每个元素至多入栈一次、出栈一次，比较与压栈都是 $O(1)$，总操作数 $\le 2n$。
- **空间**：$O(n)$。栈最坏存 $n$ 个元素（数组严格递增时），C++ 用 `vector` 并 `reserve(n)`；此外没有额外数组。
- **对比**：排序 / 前缀多重集比较解法 $O(n \log n)$；枚举切分 $O(2^n)$；本题 $n \le 2000$，$O(n)$ 与 $O(n\log n)$ 都能过，但栈解法在 $n = 10^6$ 时依然最优。

## 7. 参考代码

### C++

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    int maxChunksToSorted(vector<int>& arr) {
        vector<int> st;
        st.reserve(arr.size());
        for (int x : arr) {
            if (st.empty() || x >= st.back()) {
                st.push_back(x);          // x 自成一块
            } else {
                int mx = st.back();       // 栈非递减：第一个弹出的就是最大值
                st.pop_back();
                while (!st.empty() && st.back() > x) {
                    st.pop_back();        // 这些块的最大值也大于 x，一并合并
                }
                st.push_back(mx);         // 合并后的块最大值为 mx
            }
        }
        return (int)st.size();
    }
};
```

### Python

```python
class Solution:
    def maxChunksToSorted(self, arr: list[int]) -> int:
        st = []                          # 每一块当前的最大值，自底向上非递减
        for x in arr:
            if not st or x >= st[-1]:
                st.append(x)             # x 单独成块（相等也新开一块）
            else:
                mx = st.pop()            # 第一个弹出的就是被合并块的最大值
                while st and st[-1] > x:
                    st.pop()             # 这些块的最大值也大于 x，一起合并
                st.append(mx)            # 合并后的块最大值为 mx
        return len(st)
```

## 8. 边界情况与易错点

1. **单元素**：`arr = [1]` → 栈长 1，不需特判。
2. **全部相等**：`[0,0,0]` → 3。判定必须写 `x >= st.top`；写成 `x > st.top` 会得到 1。
3. **严格递减**：`[5,4,3,2,1]` → 1，每一步都在合并，栈始终只剩一个元素。
4. **严格递增**：`[1,2,3]` → 3，每步都新开一块，栈深达到 $n$（正好是最坏空间）。
5. **合并后压错值**：压 $x$ 而非 $mx$，`[3,1,2]` 错答 2（应为 1）、`[3,1,4,2,5]` 错答 3（应为 2）。
6. **值域 $10^8$**：不要用元素值作数组下标做桶计数；单调栈只做比较，天然规避。
7. **返回值类型**：栈长满足 $\text{len}(st) \le n \le 2000$，`int` 足够；C++ 返回 `int` 时注意 `st.size()` 是无符号的 `size_t`，显式转换避免编译告警。
8. **不要真的模拟排序**：本题的合法性判定是纯比较，任何「分块后排序再比较」的实现都会多付 $O(n\log n)$，且容易在重复元素上写出错误的验证逻辑。
