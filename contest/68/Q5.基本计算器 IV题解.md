# LeetCode 基本计算器 IV 题解

## 1. 题目概述

- **标题 / 题号**：基本计算器 IV（#770，hard）
- **链接**：https://leetcode.cn/problems/basic-calculator-iv/
- **来源**：LeetCode 第 68 场周赛 Q5
- **难度**：困难
- **标签**：栈、递归、哈希表、数学、字符串

**题意**：给定只含小写变量、非负整数、`+`、`-`、`*` 与括号的中缀表达式。先用 `evalvars` / `evalints` 把一部分变量替换成常数，再把剩下的表达式**完全展开、合并同类项**，最后按固定规则输出：每个非零项写成 `系数*变量1*变量2*...`（系数 1 也要写，常数项只写系数，系数 0 的项整项丢弃）；整体先按次数（变量个数）降序，同次数按变量名字典序升序。

**约束**：

- $1 \le expression.length \le 250$，字符只含小写字母、数字、`+ - * ( )` 与空格，首尾无空格
- **所有符号之间都恰好有一个空格**（切词可直接按空格切）
- $0 \le evalvars.length \le 100$，$1 \le evalvars[i].length \le 20$，$-100 \le evalints[i] \le 100$
- 所有中间结果都在 32 位整数范围内

> 💡 关键信号：题目要的不是「值」，而是「多项式本身」——一切都围绕「给多项式找一个可合并的规范表示」展开。

## 2. 示例

**示例 1**

```text
输入：expression = "e + 8 - a + 5", evalvars = ["e"], evalints = [1]
输出：["-1*a","14"]
解释：e 代入 1 后是 14 - a；一次项在前，常数项在后。
```

**示例 2**

```text
输入：expression = "e - 8 + temperature - pressure",
     evalvars = ["e", "temperature"], evalints = [1, 12]
输出：["-1*pressure","5"]
解释：1 - 8 + 12 - pressure = 5 - pressure。
```

**示例 3**

```text
输入：expression = "(e + 8) * (e - 8)", evalvars = [], evalints = []
输出：["1*e*e","-64"]
解释：展开得 e*e - 8*e + 8*e - 64，一次项抵消，只剩二次项与常数项。
```

**补充示例（输出格式，非官方）**

```text
输入：expression = "a * a * b + 3 * b * b - 2 * a * a * a + 5 * c - 6 + 4 * a"
输出：["-2*a*a*a","1*a*a*b","3*b*b","4*a","5*c","-6"]
解释：次数 3 的两项按 (a,a,a) < (a,a,b) 排序，次数 1 的两项按 (a) < (c) 排序。
```

## 3. 解题思路

### 3.1 暴力思路

若所有变量都在 `evalvars` 里，这题就是「表达式求值」：栈或递归下降，$O(|expression|)$ 结束。

但题面允许**未知变量**留下来，答案是一个多项式。最直接的做法是「按分配律把表达式展开成项的列表」：加法拼接列表，乘法做笛卡尔积，最后再排序、合并。两个致命问题：

- 乘法不合并时项数按乘积增长，$(a+b+c+d)^{k}$ 这种形状指数爆炸，250 字符足以造出组合数级的中间项；
- 即使不爆，末尾「判断同类项 + 排序」也要在巨大列表上做，纯属浪费。

需要的不是更快的展开，而是一个**规范表示**：让同类项在结构上完全相同，合并退化成一次查表。

### 3.2 核心观察：把表达式看成多项式

![用系数 map 表示多项式](images/wc68_q5_poly_model.svg)

多项式对加法、减法、乘法封闭，所以每个子表达式都能返回**同一种结构**，上层直接拼接即可。取稀疏表示 $\{\text{键} \to \text{系数}\}$，键是**规范化的项**：把这一项里的变量名按字典序排好、重复次数保留，得到元组 $(v_1,\dots,v_d)$，$d$ 就是次数。于是 $a^2b$ 的键是 `(a,a,b)`，$c$ 的键是 `(c,)`，常数项是空元组 `()`；$b\cdot a\cdot a$ 与 $a\cdot a\cdot b$ 都归一成 `(a,a,b)`，天然同类。

三种运算都变成对有序键的操作：

- **加 / 减**：按键合并，系数相加 / 相减；
- **乘**：两层循环枚举键对，两个**已排序**元组归并成新键，系数相乘；
- **代入**：变量换常数。代入是环同态（先代入再乘 = 先乘再代入），可以在解析到变量时就地替换，顺便把「值为 0」的项提前消掉。

### 3.3 算法流程：递归下降 + 多项式代数

![递归下降的三层结构](images/wc68_q5_parse_flow.svg)

语法只有三层，用递归下降最省事，三个函数各自返回一个 `Poly`：

```text
expr   := term (('+' | '-') term)*
term   := factor ('*' factor)*
factor := '(' expr ')' | number | variable

parseExpr():   p = parseTerm(); while tok ∈ {+,-}: p = addSub(p, parseTerm(), ±1)
parseTerm():   p = parseFactor(); while tok 是 '*': p = multiply(p, parseFactor())
parseFactor(): '(' → 递归 parseExpr 并跳过 ')'
               数字 → {(): v}；已知变量 → {(): 值}；未知变量 → {(变量,): 1}
addSub(a,b,sign): 复制 a，对 b 的每个键做 coef += sign*b.coef，结果为 0 就删键
multiply(a,b):    每对键归并出 key，coef 相乘，结果为 0 就删键
```

切词只需按空格 `split`（题面保证符号间有空格）；为稳妥仍可先给括号两侧补空格（`replace('(', ' ( ')` 之类），成本可忽略。

### 3.4 示例演算

![示例 3 的括号乘法走查](images/wc68_q5_walkthrough.svg)

以示例 3 `(e + 8) * (e - 8)` 为例，从左到右扫描：

| 步骤 | 读入 | 动作 / 返回的多项式 |
|------|------|---------------------|
| 1 | `(` | 进入括号，递归 `parseExpr` |
| 2 | `e` | 未知，`{(e,): 1}` |
| 3 | `+` | 记下运算符，继续 `parseTerm` |
| 4 | `8` | 常数，`{(): 8}` |
| 5 | `)` | 左因子合并：`{(e,): 1, (): 8}` |
| 6 | `*` | 右因子 `(e - 8)`：`{(e,): 1, (): -8}` |
| 7 | 乘 | $2\times2=4$ 对键两两归并 |
| 8 | 合并 | `{(e,e): 1, (): -64}` |

四对乘积分别是：`(e,)`×`(e,)` → $+1\cdot e^2$；`(e,)`×`()` → $-8e$；`()`×`(e,)` → $+8e$（与上一行抵消，键被删除）；`()`×`()` → $-64$。排序后二次项在前、常数项垫底，输出 `["1*e*e","-64"]`。若再加 `evalvars = ["e"], evalints = [1]`，读入 `e` 时直接得到 `{(): 1}`，式子退化成 $1-64=-63$。

示例 1 同理：$e=1$ 时得 `{(a,): -1, (): 14}`，一次项在前，输出 `["-1*a","14"]`——注意系数 1 也要打印，`{(a,): 1}` 输出 `1*a` 而不是 `a`。

## 4. 算法细节

1. **键必须规范化**：C++ 用 `map<vector<string>, long long>`，乘法时用 `std::merge` 把两个有序键归并；Python 用 `tuple(sorted(k1 + k2))`。两者都保证同类项落进同一个键。
2. **变量名是整体**：`temperature` 是一个变量，不能按字符拆成 $t\cdot e\cdot m\cdots$；切词后每个 token 就是一个整体。
3. **提前代入**：读到变量时若在 `evalvars` 中就直接生成常数项，等价于先做求值同态再乘（引理 1）。已知变量永不进多项式，项数不会因代入膨胀。
4. **零系数剪枝**：`addSub`、`multiply`、原子构造三处都判 0，维持「`Poly` 中无 0 系数键」的不变量，输出阶段无需再过滤。
5. **排序实现**：C++ 的 `map` 已按键升序，`stable_sort` 只比次数降序，稳定性让同次数保持键升序，一步到位；Python 直接 `items.sort(key=lambda kv: (-len(kv[0]), kv[0]))`。
6. **输出格式**：先取系数，再逐个拼 `"*" + 变量名`；键为空（常数项）不拼星号；系数 1 / -1 与负号原样保留。
7. **递归深度**：长度 ≤ 250，括号嵌套不超过 62 层，远低于 Python 默认递归上限。
8. **数据类型**：C++ 用 `long long`。题面只保证「中间结果」在 32 位内，而系数之积这类瞬时量仍可能越界。

## 5. 正确性证明

设 $\sigma$ 为把 `evalvars` 映射到 `evalints`、其余变量保持不变的求值同态。

**引理 1（解析忠实性）**：对任意子表达式 $E$，`parse(E)` 返回的多项式恰好是 $\sigma(E)$ 的完全展开式。

**证明**：对 $E$ 的结构归纳。**原子**：数字 $v$ 返回 `{(): v}`；已知变量 $x$ 返回 `{(): σ(x)}`；未知变量 $y$ 返回 `{(y,): 1}`，三者正是 $\sigma$ 作用后的单项式。**加减**：由归纳假设两侧是展开式，`addSub` 按键合并系数就是多项式加减的定义。**乘**：两侧是展开式时，`multiply` 枚举全部键对、键归并、系数相乘，恰好生成分配律展开的每一项并按同类项合并，键的书写顺序不影响归并结果。**括号**：`parseFactor` 直接返回内层结果，语义不变。又因 $\sigma$ 是环同态，$\sigma(L\cdot R)=\sigma(L)\cdot\sigma(R)$（加减同理），故「提前代入」与「展开后代入」一致。∎

**引理 2（表示不变量）**：算法运行中任一 `Poly` 的键都是升序变量元组，且所有系数非 0。

**证明**：原子构造时，数字 0 与值为 0 的已知变量不建键，其余原子系数为 $v\neq0$ 或 1，键是单元素元组（升序）。归纳步：`addSub` 与 `multiply` 都在写入前判断结果是否为 0，为 0 则删除该键；`multiply` 的键由两个升序元组归并而来，仍升序。故不变量保持。∎

**引理 3（输出规则一致）**：把 `Poly` 的项按「次数降序、同次数按键字典序升序」排列并按 `系数*变量1*...` 格式化，得到的列表恰好满足题面输出要求。

**证明**：逐条对照题面：① 系数 0 的项不输出——由引理 2 不存在这样的键；② 项的变量按字典序、重复保留——键的定义即是；③ 次数降序、同次数用字典序打破平局——排序键 `(-次数, 变量元组)` 正是这一顺序；④ 系数与变量用 `*` 分隔、常数项只写系数、系数 1 也打印——格式化循环逐项处理，键为空时不拼 `*`，系数原样输出。四项对应，输出必合法。∎

**定理**：算法输出等于题目要求的简化表达式标记列表。

**证明**：由引理 1，`parseExpr()` 返回整个表达式（已代入）的展开多项式；由引理 3，对其排序格式化即得合法输出。题面保证简化结果唯一（同类项必合并、同类项只出现一次），故算法输出就是答案。∎

## 6. 复杂度分析

记最终多项式项数为 $N$、单项最大次数为 $D$（$D$ 不超过表达式里变量出现的总次数）。

- **时间**：切词与解析共 $O(L)$ 次基本操作（$L$ 为 token 数，$L \le 250$）。`addSub` 为 $O(N)$；`multiply` 为 $O(N^2 \cdot D)$（两层键对循环 × 每次 $O(D)$ 的键归并）。乘号个数为 $O(L)$，故最坏 $O(L \cdot N^2 \cdot D)$，实际数据下 $N$、$D$ 都被长度 250 限制得很小，远达不到上界。排序为 $O(N\log N)$ 次键比较，每次 $O(D)$。
- **空间**：每个多项式 $O(N\cdot D)$ 存键、$O(N)$ 存系数；递归深度 $O(\text{括号层数}) \le 62$，无其他辅助数组。

## 7. 参考代码

### C++

```cpp
using namespace std;   // LeetCode 的 C++ 环境已预置常用头文件

class Solution {
    using Poly = map<vector<string>, long long>;   // 键 = 升序变量元组，值 = 系数
    vector<string> tk;
    size_t pos = 0;
    unordered_map<string, int> subst;

    Poly addSub(const Poly& a, const Poly& b, int sign) {
        Poly r = a;
        for (auto& kv : b) {                       // 按键合并，0 系数直接删键
            long long v = r[kv.first] + sign * kv.second;
            if (v) r[kv.first] = v; else r.erase(kv.first);
        }
        return r;
    }
    Poly mul(const Poly& a, const Poly& b) {
        Poly r;
        for (auto& x : a) for (auto& y : b) {
            vector<string> key;
            merge(x.first.begin(), x.first.end(), y.first.begin(), y.first.end(),
                  back_inserter(key));
            long long v = r[key] + x.second * y.second;
            if (v) r[key] = v; else r.erase(key);
        }
        return r;
    }
    Poly parseExpr() {                             // expr := term (('+'|'-') term)*
        Poly p = parseTerm();
        while (pos < tk.size() && (tk[pos] == "+" || tk[pos] == "-")) {
            int s = tk[pos++] == "+" ? 1 : -1;
            p = addSub(p, parseTerm(), s);
        }
        return p;
    }
    Poly parseTerm() {                             // term := factor ('*' factor)*
        Poly p = parseFactor();
        while (pos < tk.size() && tk[pos] == "*") { ++pos; p = mul(p, parseFactor()); }
        return p;
    }
    Poly parseFactor() {                           // '(' expr ')' | number | variable
        string t = tk[pos];
        if (t == "(") { ++pos; Poly p = parseExpr(); ++pos; return p; }
        ++pos;
        long long v;
        if (isdigit((unsigned char)t[0])) v = stoll(t);
        else if (subst.count(t)) v = subst[t];     // 已知变量：提前代入
        else { Poly p; p[vector<string>{t}] = 1; return p; }
        Poly p;
        if (v) p[vector<string>()] = v;            // 0 不建键，保持无零系数键
        return p;
    }

public:
    vector<string> basicCalculatorIV(string expression, vector<string>& evalvars,
                                     vector<int>& evalints) {
        for (size_t i = 0; i < evalvars.size(); ++i) subst[evalvars[i]] = evalints[i];
        string s;                                  // 括号两侧补空格，再按空格切词
        for (char c : expression) {
            if (c == '(' || c == ')') { s += ' '; s += c; s += ' '; } else s += c;
        }
        stringstream ss(s);
        for (string t; ss >> t;) tk.push_back(t);

        Poly poly = parseExpr();
        vector<pair<vector<string>, long long>> items(poly.begin(), poly.end());
        stable_sort(items.begin(), items.end(), [](const auto& a, const auto& b) {
            return a.first.size() > b.first.size();   // 键已升序，稳定排序保住同次数顺序
        });
        vector<string> res;
        for (auto& p : items) {
            string item = to_string(p.second);
            for (auto& v : p.first) item += "*" + v;
            res.push_back(item);
        }
        return res;
    }
};
```

### Python

```python
from typing import List


class Solution:
    def basicCalculatorIV(self, expression: str, evalvars: List[str],
                          evalints: List[int]) -> List[str]:
        subst = dict(zip(evalvars, evalints))          # 已知变量 → 常数
        tokens = expression.replace('(', ' ( ').replace(')', ' ) ').split()
        pos = 0

        def add(p, q, sign):                           # 按键合并，0 系数删键
            r = dict(p)
            for k, v in q.items():
                nv = r.get(k, 0) + sign * v
                if nv: r[k] = nv
                elif k in r: del r[k]
            return r

        def mul(p, q):                                 # 键有序归并，系数相乘
            r = {}
            for k1, v1 in p.items():
                for k2, v2 in q.items():
                    key = tuple(sorted(k1 + k2))
                    nv = r.get(key, 0) + v1 * v2
                    if nv: r[key] = nv
                    elif key in r: del r[key]
            return r

        def parse_expr():                              # expr := term (('+'|'-') term)*
            nonlocal pos
            p = parse_term()
            while pos < len(tokens) and tokens[pos] in '+-':
                op = tokens[pos]; pos += 1
                p = add(p, parse_term(), 1 if op == '+' else -1)
            return p

        def parse_term():                              # term := factor ('*' factor)*
            nonlocal pos
            p = parse_factor()
            while pos < len(tokens) and tokens[pos] == '*':
                pos += 1
                p = mul(p, parse_factor())
            return p

        def parse_factor():                            # '(' expr ')' | number | variable
            nonlocal pos
            tok = tokens[pos]
            if tok == '(':
                pos += 1
                p = parse_expr()
                pos += 1                               # 跳过 ')'
                return p
            pos += 1
            if tok[0].isdigit():                       # 常数
                val = int(tok)
            elif tok in subst:                         # 已知变量：提前代入
                val = subst[tok]
            else:
                return {(tok,): 1}                     # 未知变量：单变量项
            return {(): val} if val else {}            # 0 不建键

        items = [(k, v) for k, v in parse_expr().items() if v]
        items.sort(key=lambda kv: (-len(kv[0]), kv[0]))
        return [str(c) + ('*' + '*'.join(k) if k else '') for k, c in items]
```

## 8. 边界情况与易错点

1. **结果恒为 0**：`"0"`、`"a - a"`、`"a*a + a*a - 2*a*a"` 都输出 `[]`，不能残留 `"0"`；原子构造时判 0 最省事。
2. **已知变量值为 0**：`"a * b"` 且 `evalints = [0]` 时 `b` 那项系数变 0、整项消失，答案是 `[]` 而非 `["0*b"]`。
3. **系数 1 / -1 必须写出来**：输出 `"1*e*e"`、`"-1*a"`，不是 `"e*e"`、`"-a"`。
4. **常数项没有星号**：输出 `"14"`、`"-64"`，写成 `"14*"` 会错。
5. **不要用整串字符串排序**：`"1*a"` 的字典序小于 `"1*b*b"`，但次数降序要求 `b*b` 在前；必须先按次数、再按变量元组。
6. **同类项要靠键合并**：输入里 `a * b` 与 `b * a` 是同一个键 `(a,b)`，按原样字符串存就会漏合并。
7. **重复变量不能去重**：`a*a` 的键是 `(a,a)`，误写成 `(a)` 会把二次项当成一次项。
8. **多字母变量整体比较**：`temperature * pressure` 输出 `1*pressure*temperature`（`pressure` 字典序在前）。
9. **乘法产生的零项**：`(a - b) * (a - b)` 会产生 `-1*a*b` 与 `-1*b*a` 两个同键项，必须在乘法内部合并、判零，否则输出会出现 `0*a*b`。
