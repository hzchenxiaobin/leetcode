# LeetCode 最少侧跳次数 题解

## 1. 题目概述

- **标题 / 题号**：最少侧跳次数（#1824，medium）
- **链接**：https://leetcode.cn/problems/minimum-side-jumps/
- **来源**：LeetCode 第 236 场周赛 Q3
- **难度**：中等
- **标签**：动态规划、贪心、数组

**题意**：

一条 **3 车道**道路由 $n+1$ 个点组成（编号 $0 \sim n$），青蛙从**点 0 的车道 2** 出发，要到达**点 $n$ 的任意车道**。给定长度为 $n+1$ 的数组 `obstacles`：`obstacles[i]` 为 $0$ 表示点 $i$ 无障碍，否则表示点 $i$ 的该车道上有障碍（每点至多一条车道有障碍）。青蛙的移动方式有两种：

1. **前进**：从点 $i$ 沿**同一车道**跳到点 $i+1$，要求点 $i+1$ 的该车道无障碍，代价 $0$；
2. **侧跳**：在**同一点**换到**另一条车道**（**不要求相邻**），要求目标车道在该点无障碍，代价 $1$；且**侧跳时可以越过障碍**——中间车道在该点即使被堵也能跨过。

求到达终点的**最少侧跳次数**。保证点 0 与点 $n$ 无障碍。

**约束**：

- `obstacles.length == n + 1`，$1 \le n \le 5 \times 10^5$ → 数据规模线性扫描，必须 $O(n)$
- $0 \le \text{obstacles}[i] \le 3$，`obstacles[0] == obstacles[n] == 0` → 起点终点无需特判封锁

## 2. 示例

**示例 1**

```text
输入：obstacles = [0,1,2,3,0]
输出：2
解释：最优方案共 2 次侧跳：点 1 处从车道 2 侧跳到车道 3；
点 2 处从车道 3 侧跳到车道 1（越过车道 2 的障碍），随后直行到终点。
```

**示例 2**

```text
输入：obstacles = [0,1,1,3,3,0]
输出：0
解释：车道 2 全程无障碍，不需要任何侧跳。
```

**示例 3**

```text
输入：obstacles = [0,2,1,0,3,0]
输出：2
解释：最优方案共 2 次侧跳。
```

## 3. 解题思路

### 3.1 暴力思路：把 (点, 车道) 当状态搜索

最直接的建模是把 **(当前点, 当前车道)** 当作状态：每个状态有 1 条「前进」边（代价 0）和 2 条「侧跳」边（代价 1）。朴素 DFS 枚举所有移动序列是指数级的；把代价当边权做 **0-1 BFS / Dijkstra** 可以做到 $O(n)$ 时间——但需要队列与距离数组，空间 $O(n)$，代码也重。

真正的问题在于：状态里的「车道」只有 **3** 个取值，且侧跳的可达结构极其规整——这个结构值得单独看清楚。

### 3.2 核心观察：三值滚动 DP + 侧跳的完全图结构

![3 车道与两种移动：直行 0 代价，侧跳 1 次、可跨道越障](images/wc236_q3_track_concept.svg)

由于只有 3 条车道，每个点只需维护 3 个值 $dp[0], dp[1], dp[2]$，分别表示「到达当前点、位于车道 $1/2/3$ 的最少侧跳数」。两个关键观察把转移化到极简：

> 💡 **观察 1（障碍 = 禁足）**：若点 $i$ 的 $o$ 号车道有障碍，青蛙既不能停留在也不能直行进入该车道，直接令 $dp[o-1] = \infty$。

> 💡 **观察 2（侧跳构成完全图）**：侧跳**不要求相邻**（$1 \leftrightarrow 3$ 也只算 1 次），且**能越过中间车道的障碍**。于是在同一点处，**任意两条空闲车道之间都是一条代价 1 的边**——空闲车道构成完全图 $K_3$。

完全图意味着：从当前**最便宜的空闲车道**出发，**一次侧跳**就能落在任何其他空闲车道上。于是每个点的转移只有两步：

1. **封锁**：`if (o) dp[o-1] = INF`；
2. **松弛**：令 $mn = \min(dp)$（封锁后取，保证来自空闲道），对每条道
   $$dp[j] = \min(dp[j],\; mn + 1)$$
   再把障碍道**重新封回** $\infty$（松弛会把 $mn+1$ 写进去）。

> ⚠️ 为什么是 $mn+1$ 而不是 $mn + |k-j|$？因为侧跳不要求相邻，任意两车道之间都只算 1 次。若误按「相邻才 1 次、跨两道算 2 次」建模，示例 1 点 2 处从 3 道跨过被封的 2 道到 1 道就需 2 次甚至不可达——这恰恰是本题最大的坑，也是「侧跳可越障」这条题面设定存在的意义。

初始：点 0 无障碍，青蛙在车道 2 代价为 $0$，侧跳到车道 1/3 各花 1 次，故 $dp = [1, 0, 1]$。

### 3.3 算法流程

![单个点的转移流程：封锁 → 取最小 → 松弛 → 重封](images/wc236_q3_dp_transition.svg)

```text
输入：obstacles[0..n]
1. dp ← [1, 0, 1]                    # 点 0：车道 2 代价 0，车道 1/3 各 1 次侧跳
2. 对 i ＝ 1, 2, …, n：
     o ← obstacles[i]
     若 o > 0：dp[o−1] ← ∞           # ① 障碍道禁足
     mn ← min(dp[0..2])              # ② 最便宜的空闲道
     对 j ＝ 0,1,2：dp[j] ← min(dp[j], mn+1)   # ③ 一次侧跳可达任意空闲道
     若 o > 0：dp[o−1] ← ∞           # ④ 重新封住，防松弛污染
3. 返回 min(dp)                      # 终点任一车道都算到达
```

### 3.4 示例演算

以示例 1 `obstacles = [0,1,2,3,0]` 为例，逐点观察 $dp$ 的演化（$\infty$ 表示被封死；「松弛后」列为该点处理完毕的最终 $dp$）：

![示例 1 逐点演算：dp 从 [1,0,1] 演化到 [2,3,3]](images/wc236_q3_example_walkthrough.svg)

| 点 $i$ | 障碍 | 封锁后 | $mn$ | 松弛后（最终 $dp$） |
|---|---|---|---|---|
| 0 | — | 初始 $[1,0,1]$（已含点 0 侧跳） | — | $[1, 0, 1]$ |
| 1 | 车道 1 | $[\infty, 0, 1]$ | 0 | $[\infty, 0, 1]$ |
| 2 | 车道 2 | $[\infty, \infty, 1]$ | 1 | $[2, \infty, 1]$ |
| 3 | 车道 3 | $[2, \infty, \infty]$ | 2 | $[2, 3, \infty]$ |
| 4 | — | $[2, 3, \infty]$ | 2 | $[2, 3, 3]$ |

关键一步在**点 2**：车道 2 被封，车道 3 的代价 $1$ 是最便宜的空闲道；车道 1 虽不相邻，但凭「侧跳可越障」以 $mn+1 = 2$ 一次跳到。随后点 3 的车道 3 被封，沿车道 1 直行即可。最终 $\min(2,3,3) = 2$ ✓。再用示例 2 验证：车道 2 全程无障碍，$dp[1]$ 恒为 $0$，答案 $0$ ✓；示例 3 同法演算得 $2$ ✓。

## 4. 算法细节

1. **状态定义与滚动**：$dp[j]$ = 到达当前处理点、位于车道 $j+1$ 的最少侧跳数。转移只依赖上一点的结果，长度 3 的数组滚动使用，空间 $O(1)$。
2. **两段式封锁**：封锁必须出现**两次**——先封再取 $mn$，保证 $mn$ 只来自空闲道（青蛙根本到不了点 $i$ 的障碍道，自然不能从它出发侧跳）；松弛后再封，防止 $mn+1$ 被写进障碍道、让下一点误判能沿该道直行。
3. **$mn+1$ 的来历**：完全图 $K_3$ 上「从全局最小值出发一步可达任意空闲道」，所以三条道的侧跳项共用同一个 $mn+1$，无需逐对枚举 $(k, j)$。
4. **初始化 $[1,0,1]$**：点 0 无障碍、起点固定在车道 2，故车道 2 为 $0$、车道 1/3 各为 $1$。也可初始化 $[\infty, 0, \infty]$ 并把循环从 $i=0$ 起跑，让第一次松弛自己补出 $[1,0,1]$，两者等价。
5. **INF 的选取**：答案上界约为 $n$ 量级（每点至多被迫一次侧跳），取 $\mathrm{INF} = 10^9$ 时 $mn + 1 \le 10^9 + 1 < 2^{31} - 1$，`int` 无溢出风险。

## 5. 正确性证明

**约定**：合法方案 = 满足题面规则的移动序列；代价 = 其中侧跳的总次数。$f_i(j)$ = 到达点 $i$ 且停在车道 $j$ 的最小代价（不可达为 $\infty$）。称车道 $j$ 在点 $i$ **空闲** iff $\text{obstacles}[i] \ne j$。

**引理 1（规范化）**：存在最优方案，使得每个点处至多执行一次侧跳，且该侧跳发生在「前进离开该点之前」。

**证明**：青蛙位于点 $p$ 时，其操作序列必为「若干次侧跳 + 一次前进」（前进即离开点 $p$）。若在点 $p$ 连续侧跳 $a_1 \to a_2 \to \cdots \to a_t$（$t \ge 2$），因各落点均须空闲，$a_t$ 在点 $p$ 空闲；由「侧跳可到任意车道」，可将这 $t$ 次替换为一次 $a_1 \to a_t$（$a_1 = a_t$ 时替换为零次），方案仍合法且代价不增。逐点处理即得规范形式。∎

**引理 2（逐点递推）**：$f_0 = [1, 0, 1]$；对 $i \ge 1$，若车道 $j$ 在点 $i$ 被封则 $f_i(j) = \infty$，否则

$$f_i(j) = \min\Big(\, f_{i-1}(j),\; mn_i + 1 \,\Big), \qquad mn_i = \min_{c\ \text{空闲}} f_{i-1}(c).$$

**证明**：对 $i$ 归纳。$i = 0$：初始位于车道 2 代价 $0$；点 0 无障碍，侧跳到车道 1/3 各一次，故 $f_0 = [1,0,1]$。

$i \ge 1$ 时，由引理 1 只需考察规范化最优方案的最后事件（到达点 $i$ 车道 $j$，$j$ 必须空闲）：

- **最后事件为直行**（点 $i-1$ 车道 $j \to$ 点 $i$ 车道 $j$）：前缀是到达点 $i-1$ 车道 $j$ 的合法方案，代价 $\ge f_{i-1}(j)$；
- **最后事件为点 $i$ 处的侧跳** $c \to j$：由引理 1 该点侧跳仅此一次，故其前缀是「直行进入点 $i$ 车道 $c$」的方案，$c$ 须空闲，代价 $\ge f_{i-1}(c)$，总代价 $\ge f_{i-1}(c) + 1$。

反过来，$f_{i-1}(j)$（$j$ 空闲时）与 $f_{i-1}(c) + 1$（$c$ 空闲）均能被合法方案实现。两方向合并即得递推式。∎

**定理**：算法返回 $\min_j f_n(j)$，即最少侧跳次数。

**证明**：对 $i$ 归纳可证循环处理完点 $i$ 后 $dp = f_i$：封锁使障碍道为 $\infty$；$mn$ 在封锁后取得，恰为 $mn_i$；松弛实现 $\min(f_{i-1}(j), mn_i + 1)$；重封恢复障碍道的 $\infty$。终点点 $n$ 无障碍且任一车道均算到达，故答案为 $\min_j f_n(j)$。∎

**推论（贪心视角）**：递推式表明每点的决策相互独立——「先看哪些道空闲，再从最便宜的空闲道一步跳到目标道」逐步取最优即全局最优，这正是完全图结构把 DP 与贪心统一起来的原因。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。逐点遍历一次，每点对 3 个车道做常数次比较与赋值。
- **空间复杂度**：$O(1)$。仅维护长度为 3 的 `dp` 数组与常数变量，与 $n$ 无关（输入数组不计入）。
- **与搜索对比**：0-1 BFS / Dijkstra 同为 $O(n)$ 时间，但需 $O(n)$ 的队列与距离数组；三值滚动 DP 把空间压到 $O(1)$，代码也短得多——「状态维度的值域极小」是放弃搜索、改用 DP 的信号。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minSideJumps(vector<int>& obstacles) {
        const int INF = 1e9;
        int dp[3] = {1, 0, 1};              // 点 0：车道 2 代价 0，车道 1/3 各 1 次侧跳
        for (int i = 1; i < (int)obstacles.size(); ++i) {
            int o = obstacles[i];
            if (o) dp[o - 1] = INF;          // ① 障碍道禁足
            int mn = min({dp[0], dp[1], dp[2]});
            for (int j = 0; j < 3; ++j)      // ② 从最便宜的空闲道一次侧跳可达任意空闲道
                dp[j] = min(dp[j], mn + 1);
            if (o) dp[o - 1] = INF;          // ③ 重新封住，防松弛污染
        }
        return *min_element(dp, dp + 3);
    }
};
```

### Python

```python
class Solution:
    def minSideJumps(self, obstacles: List[int]) -> int:
        INF = 10 ** 9
        dp = [1, 0, 1]                       # 点 0：车道 2 代价 0，车道 1/3 各 1 次侧跳
        for o in obstacles[1:]:
            if o:
                dp[o - 1] = INF              # ① 障碍道禁足
            mn = min(dp)
            for j in range(3):               # ② 从最便宜的空闲道一次侧跳可达任意空闲道
                dp[j] = min(dp[j], mn + 1)
            if o:
                dp[o - 1] = INF              # ③ 重新封住，防松弛污染
        return min(dp)
```

> 💡 对拍验证：可用 0-1 BFS（`collections.deque`，前进边权 0 头插、侧跳边权 1 尾插）互查。⚠️ 0-1 BFS 必须写成**松弛式**（弹出时若发现更短距离可更新重插）；「插入即去重」是错的——1 权侧跳边会抢先占用状态，随后 0 权前进边的更短距离进不去，对拍时会拿到虚高的答案。另可断言循环不变量：三条道的 $dp$ 值两两之差至多为 1（完全图上一次侧跳即从最小值补齐任意道）。

## 8. 边界情况与易错点

1. **侧跳按「次」不按「距离」计费**（最高频错误）：$1 \leftrightarrow 3$ 跨两条道也算 1 次，且能越过中间被封的车道。若按 $|k-j|$ 计费，示例 1 点 2 处 $3 \to 1$ 需 2 次甚至无解，答案直接错。
2. **忘记重封障碍道**：松弛 `dp[j] = min(dp[j], mn+1)` 会把 $mn+1$ 写进障碍道；若不重新置 $\infty$，下一点会误判能从该道直行进入。
3. **$mn$ 必须在封锁之后取**：青蛙到不了点 $i$ 的障碍道，侧跳的起点也必须是空闲道。先取 $mn$ 再封锁会用到「到达不了的车道」的旧值，把代价错误地压低。
4. **初始值不是 $[0,0,0]$ 也不是 $[\infty,0,\infty]$**：除非让第一次循环自己松弛，否则车道 1/3 的初始代价 1 不能省。
5. **$n = 1$**：`obstacles = [0, 0]`，循环执行一次、无封锁无变化，答案 $0$，无需特判。
6. **终点是「任一车道」**：答案取 $\min(dp)$，不要习惯性返回 $dp[1]$（车道 2）——示例 1 的最优路径就停在车道 1。
7. **无解不存在**：每点至多一条车道有障碍，恒有至少两条空闲道，递推不会全 $\infty$；若题面放宽为多条障碍（可能三道全堵），需特判返回 $-1$。
