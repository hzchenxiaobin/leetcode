# LeetCode 求出 MK 平均值 题解

## 1. 题目概述

- **标题 / 题号**：求出 MK 平均值（#1825，hard）
- **链接**：https://leetcode.cn/problems/finding-mk-average/
- **来源**：LeetCode 第 236 场周赛 Q4
- **难度**：困难
- **标签**：设计、队列、数据流、有序集合、堆（优先队列）

**题意**：给定整数 $m$ 和 $k$（$1 \le 2k < m$），以及数据流形式的若干整数。实现 `MKAverage` 类：

- `addElement(num)`：往数据流插入新元素；
- `calculateMKAverage()`：若数据流中不足 $m$ 个元素返回 $-1$；否则取**最后 $m$ 个元素**，删去其中最小的 $k$ 个与最大的 $k$ 个，对剩余 $m - 2k$ 个元素求平均值并**向下取整**。

本质是「**定长滑动窗口 + 去掉两端极值后求均值**」的数据结构设计题：窗口大小固定为 $m$（FIFO 淘汰最旧元素），每次查询要快速给出中段之和。

**约束**：

- $3 \le m \le 10^5$，$1 \le 2k < m$ → 窗口满时中段恰有 $m - 2k \ge 1$ 个元素，除法分母永不为零
- $1 \le \text{num} \le 10^5$ → 元素全为正整数（向下取整等价于整除），且值域不大（为 §3.5 的值域做法留了后门）
- `addElement` 与 `calculateMKAverage` **总调用次数**不超过 $10^5$ → 单次操作需 $O(\log m)$ 级别，总开销 $O(n \log m) \approx 10^5 \times 17$

> 💡 **一句话概括难点**：数据流**既有插入又有 FIFO 删除**，还要**同时跳过两个分界点**（最小 $k$ 个、最大 $k$ 个），且单次操作必须 $O(\log m)$——堆不支持删除任意元素，排序每次查询 $O(m \log m)$ 必然超时，正确工具是**有序多重集合**。

## 2. 示例

**示例 1**（官方示例，$m = 3, k = 1$）

```text
输入：
["MKAverage","addElement","addElement","calculateMKAverage",
 "addElement","calculateMKAverage","addElement","addElement",
 "addElement","calculateMKAverage"]
[[3,1],[3],[1],[],[10],[],[5],[5],[5],[]]
输出：[null,null,null,-1,null,3,null,null,null,5]

解释：
add(3), add(1) → 数据流 [3,1]，calc：不足 3 个 → −1
add(10) → 最后 3 个 [3,1,10]，删 {1}、{10}，剩 [3]，avg = 3
add(5)×3     → 最后 3 个 [5,5,5]，删两端各 1 个，剩 [5]，avg = 5
```

**示例 2**（预热期对照，$m = 5, k = 2$，同时也是 §8 陷阱的反例输入）

```text
输入：
["MKAverage","addElement","addElement","addElement","addElement",
 "addElement","calculateMKAverage"]
[[5,2],[5],[100],[7],[200],[1],[]]
输出：[null,null,null,null,null,null,7]

解释：第 5 个元素到达后窗口为 [5,100,7,200,1]
     升序 [1,5,7,100,200]，删最小 2 个 {1,5} 与最大 2 个 {100,200}
     剩 [7]，⌊7 / (5−4)⌋ = 7
```

## 3. 解题思路

### 3.1 暴力思路：每次查询排序

`addElement` 直接把 `num` 追加到列表，超出 $m$ 时弹出队首；`calculateMKAverage` 复制最后 $m$ 个元素、排序、删去前后各 $k$ 个、对中间段求和取整：

```text
addElement(num):
    q.push(num)
    if |q| > m: q.pop_front()
calculateMKAverage():
    if |q| < m: return -1
    w ← sorted(q)
    return sum(w[k : m-k]) // (m - 2*k)
```

每次查询 $O(m \log m)$。最坏 $n = 10^5$ 次查询、$m = 10^5$，总计 $\approx 10^5 \times 10^5 \times 17 \approx 1.7 \times 10^{11}$，**严重超时**。瓶颈在于：每次查询都把「有序性」推倒重来，没有把排序成本摊到每次插入里。

### 3.2 核心观察：三桶分区（lo / mid / hi）

![三桶分区概念](images/wc236_q4_three_buckets_concept.svg)

[295 数据流的中位数](https://leetcode.cn/problems/find-median-from-data-stream/) 用双堆维护**一个**分界点（中位数）；本题要**同时跳过最小 $k$ 个和最大 $k$ 个**，有**两个**分界点，所以要把窗口按值切成**三段**，每段一个有序多重集合：

| 桶 | 大小（窗口满时） | 内容 | 作用 |
|----|------|------|------|
| `lo` | $k$ | 最小的 $k$ 个 | 待删的极小段，只关心端点 $\max(\text{lo})$ |
| `mid` | $m - 2k$ | 中间段 | **求和目标**，维护 `mid_sum` |
| `hi` | $k$ | 最大的 $k$ 个 | 待删的极大段，只关心端点 $\min(\text{hi})$ |

配合一个普通队列 `q` 记录到达顺序（FIFO 窗口）。需要维持两条**不变量**：

- **(V) 桶间有序**：$\max(\text{lo}) \le \min(\text{mid}) \le \max(\text{mid}) \le \min(\text{hi})$（空桶视为恒真）；
- **(S) 前缀大小**：$|\text{lo}| = \min(k, N)$、$|\text{hi}| = \min(k, N - |\text{lo}|)$、$|\text{mid}| = N - |\text{lo}| - |\text{hi}|$，其中 $N$ 为当前窗口元素数。

> 💡 有了 (V) + (S)，`mid` **恰好**就是「窗口升序后删去两端 $k$ 个」的中间段——查询时无需任何排序，$\lfloor \text{mid\_sum} / (m - 2k) \rfloor$ 直接就是答案，$O(1)$。所有 $O(\log m)$ 的工作都被推到了插入/淘汰时的「桶间搬运」上。

> ⚠️ **为什么是三个有序集合而不是堆？** 堆不支持 $O(\log n)$ 删除任意元素，而本题的 FIFO 淘汰要求删「任意一个旧元素」；`multiset` / `SortedList` 支持 $O(\log n)$ 的插入、删除、取端点，是本题的正确工具。

### 3.3 算法流程：落桶 → 平衡 → 淘汰

![addElement 三步流程](images/wc236_q4_insert_evict_flow.svg)

**`addElement(num)` 三步走**：

**① 落桶**（按值定位 `num`，保持 (V)）：

```text
if |lo| < k 或 num ≤ max(lo):        lo ← num          # 属于小段
elif |hi| < k 或 num ≥ min(hi):      hi ← num          # 属于大段
else:                                mid ← num; mid_sum += num
```

条件里的「或 $|\text{桶}| < k$」服务于**预热期**（窗口元素还不足）：此时新元素无条件填满 `lo`、再填满 `hi`，两桶不满时 mid/hi 必为空，不会破坏 (V)。

**② 平衡**（溢出搬运，保持 (S)）：

```text
if |lo| > k:                                # lo 溢出
    x = max(lo) 出桶
    if mid 为空 且 |hi| < k:   hi ← x       # ← 预热期直送 hi，最易漏掉的分支！
    else:                     mid ← x; mid_sum += x
if |hi| > k:                                # hi 溢出（仅满窗后可能发生）
    x = min(hi) 出桶 → mid ← x; mid_sum += x
```

> ⚠️ **核心陷阱**：`lo` 溢出的元素去 `mid` 还是去 `hi`，取决于当前是否还在「前 $2k$ 个元素」的预热期。预热期内 mid 恒空、hi 未满，`max(lo)` 溢出后应当**直送 hi**；若无脑写「溢出去 mid」，窗口首次凑满 $m$ 个时三桶大小不是 $(k, m-2k, k)$，查询直接出错（反例见 §8 第 1 条）。

**③ 淘汰队首**（$|q| > m$ 时，`old` 出队，按值定位所在桶并删除）：

```text
old = q.pop_front()
if old ≤ max(lo):            lo 删 old；从 mid 借最小补 lo（mid_sum −= 借出值）
elif old ≥ min(hi):          hi 删 old；从 mid 借最大补 hi（mid_sum −= 借出值）
else:                        mid 删 old; mid_sum −= old      # mid 插入时临时多 1 个，正好归位
```

> 💡 **等值边界「删哪份都行」**：当 `old` 恰与桶间边界值相等时（如 `old == max(lo)`，同值元素同时存在于 lo 与 mid），从哪个桶删在物理上无关紧要——若误从 lo 删，借补会立刻把 `min(mid) == old` 的同值元素搬回 lo，净效果与直接从 mid 删除完全一致。**值相同 → 物理身份无关**，这是有序多重集合处理重复元素的通用技巧。

### 3.4 示例演算

![示例演算：m=3, k=1 三桶状态变迁](images/wc236_q4_example_walkthrough.svg)

以官方示例 $m = 3, k = 1$ 逐步追踪三桶状态：

| 操作 | 窗口 q | lo (k=1) | mid (1) | hi (k=1) | 说明 |
|------|--------|----------|---------|----------|------|
| `add(3)` | `[3]` | `{3}` | `∅` | `∅` | lo 未满，直接入 lo |
| `add(1)` | `[3,1]` | `{1}` | `∅` | `{3}` | 1 入 lo 溢出；**mid 空且 hi 未满 → 3 直送 hi** |
| `calc` | `|q|=2<3` | — | — | — | 返回 **−1** |
| `add(10)` | `[3,1,10]` | `{1}` | `{3}` | `{10}` | 10 入 hi 溢出 → 3 移入 mid |
| `calc` | `|q|=3` | — | sum=3 | — | ⌊3/1⌋ = **3** |
| `add(5)` | `[1,10,5]` | `{1}` | `{5}` | `{10}` | 5 入 mid；淘汰 3（在 mid，直接删） |
| `add(5)` | `[10,5,5]` | `{5}` | `{5}` | `{10}` | 淘汰 1（在 lo），mid 借最小 5 补 lo |
| `add(5)` | `[5,5,5]` | `{5}` | `{5}` | `{5}` | 5 入 lo 溢出→mid；淘汰 10（在 hi），mid 借最大 5 补 hi |
| `calc` | `|q|=3` | — | sum=5 | — | ⌊5/1⌋ = **5** |

三次查询依次返回 $-1, 3, 5$，与官方输出一致。注意 `add(1)` 这一步：**预热期 lo 溢出的 3 绕过 mid 直送 hi**——这正是修正后的行为（§8 会展示不修正的后果）。

### 3.5 另解：值域树状数组（免有序集合）

本题 $1 \le \text{num} \le 10^5$ 值域很小，可以完全绕开有序集合：在值域 $[1, V]$（$V = 10^5$）上开两个树状数组——`cnt` 记录每个值的出现次数、`sum` 记录每个值的和贡献，另用队列 + `total` 增量维护窗口总和。

- **插入 / 淘汰**：两个 BIT 单点更新（$\pm 1$ 与 $\pm \text{num}$），$O(\log V)$；
- **查询**（$|q| = m$）：在 `cnt` 上**倍增下降**找第 $k$ 小的值 $v_1$（最小 $v$ 使前缀计数 $\ge k$）。设严格小于 $v_1$ 的个数 $c_1 = \mathrm{cnt}(v_1 - 1)$，则最小 $k$ 个之和

$$
S_{\text{lo}} = \mathrm{sum}(v_1 - 1) + (k - c_1) \cdot v_1
$$

（比 $v_1$ 小的全取走，不足 $k$ 个的部分用 $v_1$ **补足被劈开的同值元素**）。同理取第 $m - k$ 小的值 $v_2$，大于 $v_2$ 的有 $a = m - \mathrm{cnt}(v_2)$ 个，最大 $k$ 个之和

$$
S_{\text{hi}} = (\mathrm{total} - \mathrm{sum}(v_2)) + (k - a) \cdot v_2
$$

答案 $= (\mathrm{total} - S_{\text{lo}} - S_{\text{hi}}) \;/\; (m - 2k)$。

该做法所有操作 $O(\log V)$，没有三桶的预热陷阱（查询只读全局值域统计），在 C++ 手写 `multiset` 繁琐或想练「树上二分」时是很好的替代。三桶做法更通用（不依赖值域），两者复杂度同阶。

## 4. 算法细节

1. **数据结构选型**：C++ 用 `multiset<int>`（允许重复、有序、$O(\log n)$ 插入/删除/查找端点），Python 用 `SortedList`（LeetCode 内置 `sortedcontainers`）。取端点：`*lo.rbegin()` 最大、`*hi.begin()` 最小；Python 中 `lo[-1]` / `hi[0]`。
2. **不变量是正确性的全部**：(V) 桶间有序 + (S) 前缀大小。写代码时每一处搬运都要自问「值域关系还在吗、大小变回目标了吗」——§5 的证明就是逐分支核对了这两条。
3. **落桶条件中「或 $|\text{桶}| < k$」的短路作用**：既保证预热期无条件填充 lo/hi，也天然避免了对空桶取端点（`lo.size() < k` 为真时不会解引用空的 `rbegin()`；Python 空列表取 `[-1]` 会抛异常，同样被短路保护）。
4. **溢出目的地的判定**：`mid.empty() && hi.size() < k` 恰好等价于「窗口元素数 $N < 2k$（预热期）」——由 (S)，hi 未满 ⟺ $N < 2k$，且此时 mid 必空。满窗后 lo/hi 恒满，溢出恒去 mid。这一行条件是本题与 naive 版本的**唯一差别**，也是全题最容易写错的地方（见 §8）。
5. **mid_sum 增量维护**：每次 mid 增删时同步加减，查询 $O(1)$。类型必须 `long long`：最坏 $m = 10^5$ 个 $10^5$，段和达 $10^{10}$，超出 32 位 `int`（约 $2.1 \times 10^9$）。
6. **multiset 删除必须「find + 迭代器」**：`erase(it)` 只删一个元素；`erase(value)` 会删掉**所有**等于该值的元素，破坏桶大小。这是 `multiset` 最易踩的坑。
7. **借补方向**：lo 缺员 → 从 mid 借**最小**（保住 lo 是较小的 $k$ 个）；hi 缺员 → 从 mid 借**最大**；old 在 mid 时无需借补——本条 `addElement` 的插入让 mid 临时多存 1 个，淘汰归位后正好回到 $m - 2k$。

## 5. 正确性证明

记 $N = |q|$ 为当前窗口元素数，三桶为 $L, M, H$（多重集），不变量 (V)(S) 如 §3.2 所述。

**引理 1（中段刻画）**：若 (V)(S) 成立且 $N \ge m$，则 $M$ 恰为「窗口升序后删去最小 $k$ 个与最大 $k$ 个」剩余的 $m - 2k$ 个元素（多重集意义下），且 `mid_sum` 等于其元素和。

**证明**：将窗口升序排列 $w_1 \le \cdots \le w_N$。由 (V)，任取 $x \in L, y \in M, z \in H$ 有 $x \le y \le z$，故 $L$ 恰由 $w_1, \dots, w_{|L|}$ 组成、$M$ 恰由其后的 $|M|$ 个组成、$H$ 恰由最后 $|H|$ 个组成。$N \ge m \ge 2k + 1$ 时，(S) 给出 $|L| = k$、$|H| = \min(k, N - k) = k$（因 $N - k \ge m - k > k$）、$|M| = N - 2k = m - 2k$，故 $M$ 正是删去两端后的中段。`mid_sum` 在代码中随 mid 的每次增删同步加减，对操作次数归纳即得。∎

**引理 2（插入保持不变量）**：若操作前 (V)(S) 成立，执行 `insert(num)` 后窗口含 $N + 1$ 个元素且 (V)(S) 仍成立。

**证明**：按落桶分支分情形。记操作前状态满足 (S)，即 $|L| = \min(k, N)$ 等。

① $|L| < k$：由 (S) 知 $N < k$，$M = H = \emptyset$。num 入 $L$ 后 $|L| = N + 1 = \min(k, N+1)$，(V) 平凡成立。

② num 入 $L$ 且溢出（此时必有 $|L| = k$、$N \ge k$ 且 num ≤ max(L)）：溢出元素 $x = \max(L \cup \{\text{num}\}) = \max(L)$。

- 若 $N + 1 > 2k$（即 $N \ge 2k$）：目标大小 (S) 要求 $|M| = N + 1 - 2k \ge 1$，$x$ 应入 $M$。记 $M' = M \cup \{x\}$、$L' = L \cup \{\text{num}\} \setminus \{x\}$。由 (V) 有 $x = \max(L) \le \min(M)$，故 $\min(M') = x$；又 $L'$ 中元素均 $\le x$（$x$ 原是 $L \cup \{\text{num}\}$ 的最大值，删去后其余元素均不超过它），故 $\max(L') \le x = \min(M')$，桶间有序保持。
- 若 $N + 1 \le 2k$（即 $k \le N < 2k$，预热期）：由 (S)，$M = \emptyset$ 且 $|H| = N - k < k$，$x$ 应入 $H$。记 $H' = H \cup \{x\}$。由 (V)（mid 空）$x = \max(L) \le \min(H)$；$L'$ 中元素均 $\le x$，故 $\max(L') \le \min(H')$，桶间有序保持。

两情形均逐项核对 (S) 的新目标大小成立。

③ $|H| < k$ 且 num 入 $H$（分支一为假 ⟹ $|L| = k$ 且 num > max(L)；由 (S) $N < 2k$ ⟹ $M = \emptyset$）：num > max(L) 保持 $L \le H$ 的左半关系，$M$ 为空使中半关系恒真，(S) 中 $|H| = N - k + 1 = \min(k, N+1-k)$ ✓。

④ $|H| = k$ 且 num ≥ min(H)（由 (S) $N \ge 2k$）：num 入 $H$ 溢出，$f = \min(H \cup \{\text{num}\}) = \min(H)$。由 (V) $f \ge \max(M)$，$f$ 入 $M$ 保持有序；目标 $|M| = N + 1 - 2k \ge 1$ 有空间 ✓。

⑤ max(L) < num < min(H)（$|L| = |H| = k$）：num 入 $M$，(V) 直接保持，(S) 中 $|M|$ 增 1 ✓。∎

**引理 3（删除保持不变量）**：若操作前 (V)(S) 成立且 $N = m + 1$，执行 `remove(old)` 后 (V)(S) 对 $N = m$ 成立。

**证明**：操作前由 (S)，三桶恰为 $(k,\ m+1-2k,\ k)$，且 $m + 1 - 2k \ge 2$，$M$ 非空。

- **old ≤ max(L)**：则 $L$ 中存在值等于 old 的元素。删除后 $|L| = k - 1$，从 $M$ 借 $b = \min(M)$：由 (V)，$b \ge \max(L \setminus \{\text{old}\})$，且 $b$ 原为 $M$ 的最小值，故新 $L$ 的最大值 $b \le \min(M')$ ✓；大小恢复 $(k, m - 2k, k)$ ✓。若 old 物理上属于 $M$（等值跨界），删除的是 $L$ 中的同值元素、借回的 $b$ 恰等于 old——净效果等价于直接从 $M$ 删除，多重集内容不变。
- **old ≥ min(H)**：对称，借 $\max(M)$ 补回 $H$。
- **max(L) < old < min(H)**：old 必属于 $M$，直接删除，$|M| = m - 2k$ ✓，(V) 不受影响。∎

**定理（查询正确性）**：$|q| \ge m$ 时，`calculateMKAverage()` 返回 $\lfloor \text{mid\_sum} / (m - 2k) \rfloor$，恰为所求 MK 平均值。

**证明**：初始空窗口 (V)(S) 平凡成立；由引理 2、3 归纳，每次 `addElement` 结束后 (V)(S) 成立（淘汰使 $|q| \le m$ 恒成立）。$|q| = m$ 时 $m - 2k \ge 1$，除法合法；由引理 1，mid 即删两端后的中段且 `mid_sum` 为其和；窗口元素均为正整数，C++/Python 整除即向下取整，故返回值等于题目要求的平均值。∎

## 6. 复杂度分析

- **时间**：`addElement` 每次 $O(\log m)$——落桶 1 次有序集合插入，至多 2 次溢出搬运、2 次借补，每步都是常数次 $O(\log m)$ 操作；`calculateMKAverage` 每次 $O(1)$，直接返回 $\text{mid\_sum} / (m - 2k)$。总计 $O(n \log m)$，$n = 10^5$、$\log m \approx 17$，约 $1.7 \times 10^6$ 次集合操作。
- **空间**：$O(m)$——三桶合计存 $m$ 个元素，队列另存 $m$ 个元素。
- **与暴力对比**：暴力 $O(n \cdot m \log m) \approx 10^{11}$；优化后 $O(n \log m) \approx 10^6$，快约五个数量级。核心是把「每次查询的排序」均摊成「每次插入/淘汰的桶间搬运」。

### C++

```cpp
class MKAverage {
private:
    int m, k;
    long long mid_sum = 0;
    multiset<int> lo, mid, hi;   // lo: 最小 k 个 | mid: 中段 m-2k 个 | hi: 最大 k 个
    queue<int> q;                 // FIFO 窗口

    void insert(int num) {
        if ((int)lo.size() < k || num <= *lo.rbegin()) {
            lo.insert(num);
        } else if ((int)hi.size() < k || num >= *hi.begin()) {
            hi.insert(num);
        } else {
            mid.insert(num);
            mid_sum += num;
        }
        if ((int)lo.size() > k) {                  // lo 溢出
            auto it = prev(lo.end());
            int x = *it;
            lo.erase(it);
            if (mid.empty() && (int)hi.size() < k)
                hi.insert(x);                      // 预热期：直送 hi（关键！）
            else {
                mid.insert(x);
                mid_sum += x;
            }
        }
        if ((int)hi.size() > k) {                  // hi 溢出（仅满窗后发生）
            auto it = hi.begin();
            int x = *it;
            hi.erase(it);
            mid.insert(x);
            mid_sum += x;
        }
    }

    void remove(int old) {
        if (!lo.empty() && old <= *lo.rbegin()) {          // old 在 lo（或与端点等值）
            lo.erase(lo.find(old));
            if (!mid.empty()) {
                auto it = mid.begin();
                int x = *it;
                mid.erase(it);
                mid_sum -= x;
                lo.insert(x);                              // mid 借最小补 lo
            }
        } else if (!hi.empty() && old >= *hi.begin()) {    // old 在 hi（或与端点等值）
            hi.erase(hi.find(old));
            if (!mid.empty()) {
                auto it = prev(mid.end());
                int x = *it;
                mid.erase(it);
                mid_sum -= x;
                hi.insert(x);                              // mid 借最大补 hi
            }
        } else {                                            // old 在 mid
            mid.erase(mid.find(old));
            mid_sum -= old;
        }
    }

public:
    MKAverage(int m, int k) : m(m), k(k) {}

    void addElement(int num) {
        q.push(num);
        insert(num);
        if ((int)q.size() > m) {
            int old = q.front();
            q.pop();
            remove(old);
        }
    }

    int calculateMKAverage() {
        if ((int)q.size() < m) return -1;
        return (int)(mid_sum / (m - 2 * k));
    }
};
```

### Python

```python
from sortedcontainers import SortedList
from collections import deque


class MKAverage:
    def __init__(self, m: int, k: int):
        self.m, self.k = m, k
        self.lo, self.mid, self.hi = SortedList(), SortedList(), SortedList()
        self.mid_sum = 0
        self.q = deque()

    def _insert(self, num: int) -> None:
        if len(self.lo) < self.k or num <= self.lo[-1]:
            self.lo.add(num)
        elif len(self.hi) < self.k or num >= self.hi[0]:
            self.hi.add(num)
        else:
            self.mid.add(num)
            self.mid_sum += num
        if len(self.lo) > self.k:                      # lo 溢出
            x = self.lo.pop()
            if not self.mid and len(self.hi) < self.k:
                self.hi.add(x)                         # 预热期：直送 hi（关键！）
            else:
                self.mid.add(x)
                self.mid_sum += x
        if len(self.hi) > self.k:                      # hi 溢出（仅满窗后发生）
            x = self.hi.pop(0)
            self.mid.add(x)
            self.mid_sum += x

    def _remove(self, old: int) -> None:
        if self.lo and old <= self.lo[-1]:             # old 在 lo（或与端点等值）
            self.lo.remove(old)
            if self.mid:
                x = self.mid.pop(0)
                self.mid_sum -= x
                self.lo.add(x)                         # mid 借最小补 lo
        elif self.hi and old >= self.hi[0]:            # old 在 hi（或与端点等值）
            self.hi.remove(old)
            if self.mid:
                x = self.mid.pop()
                self.mid_sum -= x
                self.hi.add(x)                         # mid 借最大补 hi
        else:                                          # old 在 mid
            self.mid.remove(old)
            self.mid_sum -= old

    def addElement(self, num: int) -> None:
        self.q.append(num)
        self._insert(num)
        if len(self.q) > self.m:
            self._remove(self.q.popleft())

    def calculateMKAverage(self) -> int:
        if len(self.q) < self.m:
            return -1
        return self.mid_sum // (self.m - 2 * self.k)
```

> 💡 实现要点：① 删除用 `find`/`pop` 精确删**一个**元素（C++ `erase(value)` 会删光同值元素）；② `mid_sum` 用 `long long`，段和最坏 $10^{10}$；③ Python 的 `SortedList.pop()` 弹最大、`pop(0)` 弹最小，语义正好对应两个端点搬运。

## 8. 边界情况与易错点

1. **预热期溢出直送 hi（本题第一大坑）**：若把「lo 溢出恒去 mid」直接照搬，窗口首次凑满时 hi 会缺员、mid 会超员。以示例 2（$m = 5, k = 2$，依次 `5, 100, 7, 200, 1`）走查：
   - **错误版**：`add(7)` 时 lo = {5,100} 溢出，100 被塞进 mid；`add(200)` 后 hi = {200}；`add(1)` 溢出 7 → mid = {7,100}。满窗时三桶为 lo={1,5}, mid={7,100}, hi={200}，返回 $\lfloor 107/1 \rfloor = 107$；
   - **正确版**：`add(7)` 时 100 **直送 hi** → hi={100}；`add(200)` → hi={100,200}；`add(1)` 溢出 7 → mid={7}。三桶恰为 $(k, m-2k, k) = (\{1,5\}, \{7\}, \{100,200\})$，返回 $7$ ✓。
   错误版不仅答案错，桶间有序性被破坏后，后续按值定位删除甚至会删到不存在的元素。**写完务必用 $k > 1$ 且「先大后小」的预热序列自测**（官方样例 $k = 1$ 恰好暴露不出这个 bug）。
2. **`multiset::erase(value)` 删光同值**：必须 `erase(find(old))` 只删一个，否则重复元素场景桶大小直接崩坏。
3. **`mid_sum` 溢出**：$m = 10^5$ 个 $10^5$ → 段和 $10^{10}$，C++ 必须 `long long`（`int` 上限约 $2.1 \times 10^9$）。累加器类型先按「元素数 × 值上界」估算。
4. **不足 m 个返回 −1**：`calc` 可在任意时刻（包括一开始）调用，别假设它总在满窗后；`|q| < m` 是唯一返回 $-1$ 的条件。
5. **等值跨桶**：`old` 与桶间边界同值时删哪份物理副本都等价（借补会换回同值元素），但前提是**桶间有序未被破坏**——这也是第 1 条错误的深层危害：有序性一旦崩了，「按值定位」本身失效。
6. **空桶取端点**：`lo.size() < k` 条件必须写在 `num <= *lo.rbegin()` 之前（短路），否则空 multiset 解引用 `rbegin()` 是未定义行为；Python 空列表 `[-1]` 直接抛异常。
7. **除法语义**：$m > 2k$ 保证分母 $\ge 1$ 无除零；元素全正，整除即向下取整，无需额外取整处理（若有负数，C++ 整除向零取整需改为 `floor` 语义）。
8. **`|q| > m` 才淘汰**：边界是「先插入再淘汰」，队列短暂存 $m + 1$ 个元素是设计使然，不要写成 `>=`。
