# LeetCode 找出游戏的获胜者 题解

## 1. 题目概述

- **标题 / 题号**：找出游戏的获胜者（#1823，medium）
- **链接**：https://leetcode.cn/problems/find-the-winner-of-the-circular-game/
- **来源**：LeetCode 第 236 场周赛 Q2
- **难度**：中等
- **标签**：约瑟夫环、递推、队列、数学、模拟

**题意**：$n$ 名小伙伴按顺时针围成一圈，编号 $1 \sim n$。从 $1$ 号所在位置开始，沿顺时针数 $k$ 名小伙伴（**计数包含起始那位**），数到的最后一名出局；若圈内还剩多人，则从出局者的顺时针下一位重新起数，如此往复，直到只剩一人。返回这名获胜者的编号。

这是经典的**约瑟夫问题**（Josephus problem）：一圈人按固定步长报数出列，求最后幸存者。

**约束**：

- $1 \le k \le n \le 500$ → 每轮数 $k$ 步、共 $n-1$ 轮，模拟总步数 $O(nk) \le 2.5 \times 10^5$，纯模拟即可通过
- 进阶要求「线性时间 + 常数空间」→ 需要从模拟升级为**递推公式**，这也是本题作为 Q2 的核心考点

## 2. 示例

**示例 1**

```text
输入：n = 5, k = 2
输出：3
解释：出局顺序为 2 → 4 → 1 → 5，最后剩下的 3 号获胜。
```

**示例 2**

```text
输入：n = 6, k = 5
输出：1
解释：小伙伴离开圈子的顺序：5、4、6、2、3，最后 1 号获胜。
```

## 3. 解题思路

### 3.1 朴素思路：队列模拟

最直接的翻译题面：用队列 `q` 存放还在圈内的小伙伴编号，每轮——

1. 把队首 $k-1$ 个编号依次「出队 → 入队尾」，相当于沿圈顺时针数 $k-1$ 步；
2. 此时队首就是本轮数到的第 $k$ 名，将其出队并丢弃（出局）；
3. 重复直到队列只剩 $1$ 个编号，它就是获胜者。

$O(nk)$ 时间、$O(n)$ 空间，在 $n \le 500$ 下毫无压力。缺点也明显：每轮都老老实实转圈数数，做了大量与最终答案无关的搬运；一旦 $n$ 放大到 $10^5$（见文末剑指 Offer 62），$O(nk)$ 直接超时。要满足进阶要求，必须换视角。

### 3.2 核心观察：删掉第一个人后，剩下的是「同一个问题的小号版本」

![核心观察：删除首个出局者后，剩余 m−1 人是编号错位 k 的同款约瑟夫问题](images/wc236_q2_relabel_recurrence.svg)

正向模拟是「从 $n$ 人往 $1$ 人删」；**反过来想**：把「删到只剩 $1$ 人」的终局当作已知，往回一圈圈加人。

用 **0-indexed** 定义 $f(m)$：圈里有 $m$ 人（编号 $0 \sim m-1$）、从 $0$ 号开始数 $k$ 个时，最后幸存者的下标。圈里第 $1$ 个出局的是 $(k-1) \bmod m$ 号；出局后从 $k \bmod m$ 号重新起数——**这恰好是一个规模 $m-1$、规则完全相同的约瑟夫问题**，只不过幸存者的新编号 $j$ 对应旧编号 $(j+k) \bmod m$。

于是只需求出 $m-1$ 规模的答案，再「错位」回来：

$$f(1) = 0, \qquad f(m) = \big(f(m-1) + k\big) \bmod m$$

最终按题目 1-indexed 输出 $f(n) + 1$。递推只依赖上一项，写成循环只需一个变量——线性时间、常数空间，正是进阶要求的答案。

> 💡 一句话：与其正向模拟「谁出局」，不如反向追问「幸存者在多大的圈里是几号」——每扩一圈，位置整体错位 $k$，再对当前圈规模 $m$ 取模回绕。

### 3.3 算法流程：一圈圈倒推

![递推演算：从 f(1)=0 推到 f(5)=2](images/wc236_q2_recurrence_walkthrough.svg)

```text
输入：n, k
1. f ← 0                          # f(1) = 0：只剩 1 人时幸存者下标为 0
2. 对 m ＝ 2, 3, …, n：
     f ← (f + k) mod m            # 圈每扩大一圈，幸存者位置错位 k
3. 返回 f + 1                     # 0-indexed → 小伙伴编号
```

### 3.4 示例演算

先正向走查游戏过程（对应示例 1 的出局顺序 $2 \to 4 \to 1 \to 5$）：

![游戏走查：n=5, k=2 的逐轮出局与胜者](images/wc236_q2_circle_simulate_concept.svg)

再沿递推公式，让 $f$ 从 $1$ 人圈「长」回 $5$ 人圈：

| 圈规模 $m$ | 递推计算 | $f(m)$ | 是否回绕 |
|---|---|---|---|
| 1 | 基础：圈里只有 0 号 | 0 | — |
| 2 | $(0+2) \bmod 2$ | 0 | $0+2 \ge 2$，回绕 |
| 3 | $(0+2) \bmod 3$ | 2 | $0+2 < 3$，不回绕 |
| 4 | $(2+2) \bmod 4$ | 0 | $2+2 \ge 4$，回绕 |
| 5 | $(0+2) \bmod 5$ | 2 | $0+2 < 5$，不回绕 |

$f(5) = 2$ → 获胜者 $= 2 + 1 = 3$ 号，与示例 1 一致。再用示例 2（$n=6,\ k=5$）验证：$f$ 依次为 $0, 1, 0, 1, 1, 0$，$f(6) + 1 = 1$ ✓。

## 4. 算法细节

1. **0-indexed 内部、1-indexed 输出**：递推在 0-indexed 下进行（$f(1)=0$ 天然简洁），最后 $+1$ 映射回题目编号。来回换算最容易在 $\pm 1$ 上翻车，建议全流程统一 0-indexed，只在 return 处转换一次。
2. **取模对象是「当前圈规模」$m$**：递推式里的 $\bmod m$ 每轮变化（圈越来越大），不是 $\bmod n$、更不是 $\bmod k$——写成固定值是最常见的笔误。
3. **递归与迭代等价**：$f(m)$ 只依赖 $f(m-1)$。递归版深度 $O(n)$ 在 $n \le 500$ 安全，但迭代版省去调用栈，才是真正的 $O(1)$ 空间；$n$ 更大时递归会爆栈（见 §8），务必迭代。
4. **队列模拟的步数细节**：一轮 = $k-1$ 次「出队入队」+ 1 次「出队丢弃」，因为计数**包含起点**；若写成 $k$ 次轮转会多数一人。数组版模拟则用下标跳跃 $idx \leftarrow (idx + k - 1) \bmod \mathrm{len}$ 再删除该位置，注意删除后下标恰好落在「下一位」上，无需再前移。
5. **递推与模拟的分工**：递推只给终点，不给过程——若要输出完整出局顺序（如示例解释），只能正向模拟；只要最终幸存者时，递推是「跳过所有中间过程」的捷径。

## 5. 正确性证明

**约定**：全部使用 0-indexed；「$m$ 人圈」指当前存活者按顺时针构成的环，编号 $0 \sim m-1$。

**引理 1（首个出局者与重启点）**：$m \ge 2$ 人圈从下标 $0$ 开始计数（可能绕圈多轮），则首个出局者下标为 $(k-1) \bmod m$，出局后新的一轮从下标 $k \bmod m$ 起数。

**证明**：顺时针报数不回头，被数到的第 $i$ 个人下标为 $(i-1) \bmod m$（绕圈只是取模的重复），故第 $k$ 个即 $(k-1) \bmod m$。该人的顺时针下一位下标为 $\big((k-1) \bmod m + 1\big) \bmod m = k \bmod m$。∎

**引理 2（重编号同构）**：首个出局者离开后剩 $m-1$ 人。以旧下标 $k \bmod m$ 为新 $0$ 号、沿顺时针重新编号 $0 \sim m-2$，则新编号 $j$ 对应旧编号 $(j + k) \bmod m$，且新圈上以相同规则报数的过程与原圈的后续过程**逐轮一致**（每轮出局同一个人）。

**证明**：$j \mapsto (j+k) \bmod m$ 在 $j \in \{0,\dots,m-2\}$ 上的取值为 $k, k+1, \dots, k+m-2 \pmod m$，恰为除 $(k-1) \bmod m$（刚出局者）外的全部 $m-1$ 个下标，故是到剩余者的双射，且 $j$ 与 $j+1$ 在圈上顺时针相邻，编号保持圈的顺序。两个过程中，每一轮报数都从各自圈里「上一出局者的下一位」起数、顺时针跳过相同的存活序列，于是数到的第 $k$ 名是同一个人；对轮数归纳即得逐轮一致。∎

**定理（约瑟夫递推）**：设 $f(m)$ 为 $m$ 人圈从下标 $0$ 起数的幸存者下标，则 $f(1) = 0$，且 $m \ge 2$ 时 $f(m) = (f(m-1) + k) \bmod m$；题目的获胜者编号为 $f(n) + 1$。

**证明**：对 $m$ 归纳。$m=1$ 时唯一存活者下标为 $0$。$m \ge 2$ 时，由引理 1 首个出局者为 $(k-1) \bmod m$ 号，重启点为 $k \bmod m$ 号；由引理 2，后续过程恰是同款 $m-1$ 人约瑟夫问题，其幸存者的新编号为 $f(m-1)$，对应旧编号 $(f(m-1) + k) \bmod m$，此即 $f(m)$。归纳完成。原始 $n$ 人圈的下标 $0 \sim n-1$ 对应小伙伴编号 $1 \sim n$，故获胜者编号为 $f(n) + 1$。∎

**推论（算法正确性）**：§3.3 的循环从 $f(1)$ 起逐步计算至 $f(n)$，返回值即获胜者编号。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。共 $n-1$ 次迭代，每次一次加法、一次取模，均为 $O(1)$。
- **空间复杂度**：$O(1)$。迭代版只维护一个整型 `f`（递归版为 $O(n)$ 调用栈）。
- **与模拟对比**：队列模拟 $O(nk)$ 时间 + $O(n)$ 空间。$n = k = 500$ 时约 $2.5 \times 10^5$ 次搬运尚可；但把 $n$ 放大到 $10^5$（剑指 Offer 62 的数据规模）时，$k$ 倍的差距立刻显现——递推对每多一人只多做一次取模。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int findTheWinner(int n, int k) {
        int f = 0;                    // f(1) = 0：0-indexed 幸存者下标
        for (int m = 2; m <= n; ++m) {
            f = (f + k) % m;          // f(m) = (f(m-1) + k) mod m
        }
        return f + 1;                 // 映射回 1-indexed 编号
    }
};
```

### Python

```python
class Solution:
    def findTheWinner(self, n: int, k: int) -> int:
        f = 0
        for m in range(2, n + 1):
            f = (f + k) % m
        return f + 1
```

> 💡 对拍验证：`collections.deque` 模拟版（每轮把队首 $k-1$ 个转到队尾、再 `popleft()` 出局，$O(nk)$）可与递推版互查；关键细节是「数 $k$ 名 = 转移 $k-1$ 次」。递推版 $f + k \le 1000$，`int` 毫无溢出风险。

## 8. 边界情况与易错点

1. **0/1-indexed 混淆**（最高频错误）：忘写最后的 `+1`，或把 $f(1)$ 初值误设为 1。快速定位手段：拿 $n=5,\ k=2$ 手算 $f(5)=2$、答案 3。
2. **取模写成固定值**：`% m` 误写成 `% n` 或 `% k`。圈规模每轮都在变，取模对象必须跟着变。
3. **计数包含起点**：题面加粗强调的坑——「数 $k$ 名」等价于「移动 $k-1$ 步」，模拟时数成 $k$ 步会整体错一位。
4. **$k$ 大于当前圈规模**：约束只保证**第一轮** $k \le n$，后续圈缩小后 $k$ 可能超过圈长（多圈绕行）。递推的 $\bmod m$ 与模拟的取模跳跃天然处理；唯独「直接假设不绕圈」的下标计算会错。
5. **$n = 1$ / $k = n$**：$n=1$ 时循环不执行，$f=0$ → 返回 1，无需特判；$k=n$ 首轮数满一整圈回到起点前一位，递推照常成立。
6. **递归爆栈**：$n \le 500$ 无感，但同款公式在剑指 Offer 62 中 $n$ 达 $10^5$，Python 默认递归上限 1000 直接崩——同款套路务必写迭代。
