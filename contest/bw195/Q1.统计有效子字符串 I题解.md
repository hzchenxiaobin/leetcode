# LeetCode 统计有效子字符串 I 题解

## 1. 题目概述

- **标题 / 题号**：统计有效子字符串 I（#4102，medium）
- **链接**：https://leetcode.cn/problems/count-valid-substrings-i/
- **来源**：LeetCode 第 195 场双周赛 Q1
- **难度**：中等
- **标签**：字符串、枚举、双指针

**题意**：给定只含 `'a'`、`'b'`、`'c'` 的字符串 $s$。若一个字符串**不把 `"abc"` 作为子串**（连续出现），则称它**有效**。求 $s$ 中有效**子串**的个数；起点或终点不同的子串分别计数。

**约束**：

- $1 \le |s| \le 10^5$
- $s$ 仅由 `a`、`b`、`c` 组成
- 答案最大约 $\frac{n(n+1)}{2} \approx 5 \times 10^9$，必须用 64 位整数

## 2. 示例

**示例 1**

```text
输入：s = "abac"
输出：10
解释：全部 10 个子串都不含 "abc"，因为 "abc" 要求三个字符连续。
```

**示例 2**

```text
输入：s = "abc"
输出：5
解释：6 个子串里只有 "abc" 本身无效，其余 5 个有效。
```

**示例 3**

```text
输入：s = "ac"
输出：3
解释："a"、"c"、"ac" 都有效。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有子串 $s[l..r]$ 并检查其中是否出现 `"abc"`：子串共 $\frac{n(n+1)}{2}$ 个，每次检查 $O(n)$，总复杂度 $O(n^3)$（用字符串查找也是 $O(n^2 \cdot n)$ 级别的常数）。$n = 10^5$ 时子串数量本身就是 $5\times 10^9$，枚举框架直接出局。

优化方向：**不要逐个枚举起点**，而是对每个右端点一次性算出「有多少个合法起点」。

### 3.2 核心观察：以 $r$ 结尾的合法起点是一段后缀

![枚举右端点 r，用 p 记录最后一条 "abc" 的起点](images/bw195_q1_scan.svg)

固定右端点 $r$，考虑所有以 $r$ 结尾的子串 $s[l..r]$（$0 \le l \le r$）。定义

$$p_r = \max\{\, q \mid s[q..q+2] = \texttt{"abc"},\ q + 2 \le r \,\}$$

即「**结束位置不超过 $r$ 的所有 `"abc"` 出现中，最大的起始下标**」（不存在时 $p_r = -1$）。

**断言**：$s[l..r]$ 含 `"abc"` 当且仅当 $l \le p_r$。

- 若 $l \le p_r$，则 $s[p_r..p_r+2]$ 整段落在子串内，故含 `"abc"`；
- 反之若子串含某条 `"abc"`，设其起点为 $q$，则 $l \le q$ 且 $q \le p_r$（$p_r$ 是最大起点），故 $l \le p_r$。

于是以 $r$ 结尾的**合法**子串恰有 $(r - p_r)$ 个（起点取 $p_r+1, p_r+2, \dots, r$），答案为

$$\sum_{r=0}^{n-1} (r - p_r)$$

而 $p_r$ 可以在扫描中 $O(1)$ 维护：只有当 $s[r-2..r]$ 恰好等于 `"abc"` 时，$p_r$ 才被更新为 $r-2$；否则 $p_r = p_{r-1}$。因为 $p_r$ 单调不减，「最大起始下标」不需要回头找。

### 3.3 算法流程

![算法流程：一遍扫描维护 p](images/bw195_q1_flow.svg)

```text
1. ans = 0;  p = -1
2. for r = 0 .. n-1:
3.     if r >= 2 and s[r-2..r] == "abc":  p = r - 2
4.     ans += r - p
5. return ans
```

### 3.4 示例演算

以 $s = \texttt{"abac"}$ 为例：

| $r$ | $s[r]$ | $s[r-2..r]$ | 更新后 $p$ | 新增合法子串数 $r-p$ | 累计 |
|-----|--------|-------------|-----------|---------------------|------|
| 0 | a | — | −1 | 1 | 1 |
| 1 | b | — | −1 | 2 | 3 |
| 2 | a | `aba` | −1 | 3 | 6 |
| 3 | c | `bac` | −1 | 4 | 10 |

答案 $10$，与示例一致。注意 $r = 3$ 时 $s[1..3] = \texttt{"bac"}$ 并不是 `"abc"`，所以 $p$ 保持 $-1$，四个以 3 结尾的子串全部合法。

再看 $s = \texttt{"abc"}$：$r = 2$ 时 $s[0..2] = \texttt{"abc"}$，$p$ 更新为 $0$，该轮新增 $2 - 0 = 2$ 个；累计 $1 + 2 + 2 = 5$，与示例一致。

## 4. 算法细节

1. **$p$ 的初值为 $-1$**：表示「还没有出现过 `"abc"`」，此时 $r - p = r + 1$，恰好是以 $r$ 结尾的全部子串数。
2. **只在 $r \ge 2$ 时检查**：`s[r-2..r]` 需要三个字符，前两轮不可能命中，加 `r >= 2` 避免负下标。
3. **$p$ 不需要取 `max`**：新出现的 `"abc"` 起点 $r-2$ 天然大于等于历史 $p$（因为 $r$ 递增），直接赋值即可；写成 `p = max(p, r-2)` 也对，只是多余。
4. **累加用 64 位**：$n = 10^5$ 时答案可达 $5 \times 10^9$，`int` 溢出，C++ 用 `long long`，Python 天然大整数。
5. **不要真的去截取子串**：判断三个字符用下标比较，避免 $O(n)$ 的字符串切片。
6. **题意是「子串」不是「子序列」**：`"abc"` 必须连续出现。若误按子序列处理，$s = \texttt{"abac"}$ 的答案会变成 $9$（少一个），这正是同场 Q3 的题意。

## 5. 正确性证明

**引理 1（判定准则）**：对任意 $0 \le l \le r < n$，子串 $s[l..r]$ 含 `"abc"` 当且仅当 $l \le p_r$。

**证明**：

（$\Leftarrow$）若 $l \le p_r$，由 $p_r$ 的定义存在 $q = p_r$ 使 $s[q..q+2] = \texttt{"abc"}$ 且 $q + 2 \le r$；又 $l \le q$，故该出现完全落在 $s[l..r]$ 内。

（$\Rightarrow$）若 $s[l..r]$ 含 `"abc"`，设其起点为 $q$，则 $l \le q$ 且 $q + 2 \le r$，故 $q$ 属于 $p_r$ 的定义集合，于是 $q \le p_r$，结合 $l \le q$ 得 $l \le p_r$。∎

**引理 2（$p_r$ 的维护正确）**：按算法第 3 行更新后，$p$ 等于 $p_r$。

**证明**：对 $r$ 归纳。$r = 0,1$ 时不可能出现 `"abc"`，$p = -1 = p_r$。设 $r-1$ 时 $p = p_{r-1}$。$p_r$ 的定义集合等于 $p_{r-1}$ 的定义集合并上「起点为 $r-2$ 的候选（当且仅当 $s[r-2..r] = \texttt{"abc"}$）」。因此若命中，$p_r = \max(p_{r-1}, r-2) = r-2$（因 $p_{r-1} \le r-3$）；否则 $p_r = p_{r-1}$。这正是算法第 3 行的两种分支。∎

**定理**：算法返回值等于 $s$ 中不含 `"abc"` 的子串个数。

**证明**：所有子串按右端点 $r$ 分成互不相交的 $n$ 组。由引理 1，以 $r$ 结尾的子串中合法的恰是起点 $l \in (p_r, r]$，共 $r - p_r$ 个；由引理 2，算法累加的正是 $r - p_r$。故总和恰为全部有效子串数。∎

## 6. 复杂度分析

- **时间**：$O(n)$。单层循环 $n$ 次，每次三次字符比较与一次加法。
- **空间**：$O(1)$。只用两个标量 $p$ 与 `ans`（不计输入本身）。

## 7. 参考代码

### C++

```cpp
#include <string>
#include <vector>

using namespace std;

class Solution {
public:
    long long countValidSubstrings(string s) {
        int n = (int)s.size();
        long long ans = 0;
        int p = -1;  // 已出现的 "abc" 中最大的起始下标
        for (int r = 0; r < n; r++) {
            if (r >= 2 && s[r - 2] == 'a' && s[r - 1] == 'b' && s[r] == 'c') {
                p = r - 2;
            }
            ans += (long long)(r - p);
        }
        return ans;
    }
};
```

### Python

```python
from typing import List

class Solution:
    def countValidSubstrings(self, s: str) -> int:
        ans = 0
        p = -1  # 已出现的 "abc" 中最大的起始下标
        for r in range(len(s)):
            if r >= 2 and s[r - 2] == 'a' and s[r - 1] == 'b' and s[r] == 'c':
                p = r - 2
            ans += r - p
        return ans
```

## 8. 边界情况与易错点

1. **$n = 1$ 或 $2$**：不可能出现 `"abc"`，答案就是子串总数 $1$ 或 $3$；`r >= 2` 的保护保证不越界。
2. **$p$ 初值必须为 $-1$**：若误设为 $0$，$r = 0$ 时新增 $0$ 个，答案会系统性偏小。
3. **只更新「最大起点」**：多条 `"abc"` 重叠出现时（如 `"abcabc"`），只需最新的那条起点，旧的自然被包含。
4. **累加用 `long long`**：$n = 10^5$ 时答案 $5 \times 10^9$ 超出 `int`；这是本题最容易吃的一次 WA。
5. **「子串」与「子序列」混淆**：本题是连续子串；子序列版本（同场 Q3）允许跳过字符，答案更小。
6. **负数下标**：若把 `r >= 2` 写成 `r > 2`，会漏掉 $r = 2$ 这一条（即首个可能的 `"abc"`）。
7. **不要用 `s.find("abc")` 循环扫描**：那样每次查找是 $O(n)$，且重叠出现（如 `"abcabc"`）的边界处理容易出错，复杂度也会退化。
