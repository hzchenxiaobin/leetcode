# LeetCode 重复字符串匹配 II 题解

## 1. 题目概述

- **标题 / 题号**：重复字符串匹配 II（#4105，hard）
- **链接**：https://leetcode.cn/problems/repeated-string-match-ii/
- **来源**：LeetCode 第 195 场双周赛 Q4
- **难度**：困难
- **标签**：数学、字符串、数论、字符串匹配

**题意**：给定两个小写字符串 $a$、$b$ 与两个正整数 $x$、$y$。记 $a*x$ 表示把 $a$ 重复 $x$ 次拼接，$b*y$ 同理。判断 $b*y$ 是否是 $a*x$ 的**子串**（连续、非空）。是则返回 `true`，否则 `false`。

**约束**：

- $1 \le |a|, |b| \le 100$
- $1 \le x, y \le 10^9$（因此两个拼接结果的长度可达 $10^{11}$，**不能真的构造字符串**）

## 2. 示例

**示例 1**

```text
输入：a = "ab", b = "abab", x = 2, y = 1
输出：true
解释：a*x = "abab"，b*y = "abab"，完全相同。
```

**示例 2**

```text
输入：a = "abc", b = "bc", x = 2, y = 3
输出：false
解释：a*x = "abcabc"，b*y = "bcbcbc"，后者不是前者的子串。
```

**示例 3**

```text
输入：a = "abcd", b = "cdab", x = 2, y = 1
输出：true
解释：a*x = "abcdabcd"，b*y = "cdab" 出现在下标 [2..5]。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的做法是把两个字符串构造出来再用 `find`：长度 $N = |a|x$、$L = |b|y$ 都可达 $10^{11}$，内存与时间都不可行。若限定 $x, y$ 很小，暴力当然正确，因此它适合作为**小数据对拍**的基准。

要利用的关键事实是：字符串虽然极长，但它们是**周期的**——$a*x$ 以 $|a|$ 为周期，$b*y$ 以 $|b|$ 为周期。

### 3.2 核心观察：两个「只需」

![起点只需枚举 0..A−1，比较只需前 min(L, lcm) 个字符](images/bw195_q4_offsets.svg)

记 $A = |a|$、$B = |b|$、$N = A \cdot x$、$L = B \cdot y$。首先是最基础的剪枝：

![长度剪枝：L 必须不超过 N](images/bw195_q4_len.svg)

若 $L > N$，答案直接为 `false`（长串不可能放进短串）。之后假设 $L \le N$，则起点 $o$ 必须满足 $0 \le o \le N - L$。

**观察一：起点只需枚举 $0 \sim A-1$。** 起点 $o$ 与 $o + A$ 看到的 $a*x$ 字符序列**完全相同**（因为 $a*x$ 以 $A$ 为周期），而 $o$ 更早、剩余长度更长。所以只要 $o + A$ 处放得下（$o + A + L \le N$），$o + A$ 能匹配就意味着 $o$ 也能匹配。因此枚举范围可缩为

$$o \in [0,\ \min(A-1,\ N-L)]$$

**观察二：每个起点只需比较前 $\min(L,\ \text{lcm}(A,B))$ 个字符。** 在固定起点 $o$ 下，第 $t$ 个待比较的字符对是

$$\Big(a[(o+t) \bmod A],\ b[t \bmod B]\Big)$$

由于「模 $A$ 的位置」以 $A$ 为周期、「模 $B$ 的位置」以 $B$ 为周期，这对下标的组合以 $\text{lcm}(A,B)$ 为周期。因此若前 $\text{lcm}(A,B)$ 个字符全部匹配，后面的（若 $L$ 更长）必然重复同样的模式，也全部匹配。

于是每个起点最多比较 $\min(L, \text{lcm}(A,B)) \le \text{lcm}(A,B) \le A \cdot B = 10^4$ 个字符，总比较量不超过

$$A \times A \cdot B = 100 \times 10^4 = 10^6$$

完全够快，且不需要构造任何长字符串。

### 3.3 算法流程

```text
1. A = |a|, B = |b|, N = A*x, L = B*y        // 64 位
2. if L > N: return false
3. period = lcm(A, B)
4. limit  = min(L, period)
5. for off = 0 .. min(A-1, N-L):
6.     ok = true
7.     for t = 0 .. limit-1:
8.         if a[(off+t) mod A] != b[t mod B]: ok = false; break
9.     if ok: return true
10. return false
```

### 3.4 示例演算

![示例 3：偏移 2 处匹配成功](images/bw195_q4_example.svg)

**示例 1**：$A=2, B=4, x=2, y=1 \Rightarrow N=4, L=4$。$\text{lcm}(2,4)=4$，因此每个起点只比较 $4$ 个字符；起点范围 $[0, \min(1,0)] = \{0\}$。逐位比较 `a*x = "abab"` 与 `b*y = "abab"` 全部相等 → `true`。

**示例 2**：$A=3, B=2, x=2, y=3 \Rightarrow N=6, L=6$。$\text{lcm}(3,2)=6$；起点范围 $\{0\}$。第 0 位：$a[0]=\texttt{a}$ 与 $b[0]=\texttt{b}$ 不等 → `false`。

**示例 3**：$A=4, B=4, x=2, y=1 \Rightarrow N=8, L=4$。$\text{lcm}(4,4)=4$，因此每个起点只比较 $4$ 个字符；起点范围 $[0, \min(3,4)] = [0,3]$。

| 起点 | 比较的 4 个字符 | 结果 |
|------|----------------|------|
| 0 | `abcd` vs `cdab` | 第 0 位不等 ✗ |
| 1 | `bcda` vs `cdab` | 第 0 位不等 ✗ |
| 2 | `cdab` vs `cdab` | 全部相等 ✓ |
| 3 | `dabc` vs `cdab` | 第 0 位不等 ✗ |

返回 `true`，与示例一致。

## 4. 算法细节

1. **64 位长度**：$N, L$ 可达 $10^{11}$，C++ 必须用 `long long`；`A * x` 中若 $A$ 是 `int`、$x$ 是 `int`，乘积会先按 `int` 计算再溢出，所以要先把 $A$ 转成 `long long`。
2. **`lcm` 的写法**：$\text{lcm}(A,B) = A / \gcd(A,B) \cdot B$。先除后乘可避免（虽然本题 $A,B \le 100$ 不会溢出的）中间溢出；C++17 可直接用 `<numeric>` 的 `std::lcm`。
3. **取模的基**：$a$ 用 `(off + t) % A`（注意 `off` 也要参与取模，因为起点不一定是 $A$ 的整数倍），$b$ 用 `t % B`（起点对 $b$ 而言恒为 0，因为 $b*y$ 从它的第一个字符开始比较）。
4. **循环上界**：`limit = min(L, period)`，其中 `L` 是 `long long`、`period` 是 `int`，比较前统一类型。
5. **提前退出**：一旦某个字符不匹配立刻 `break`，绝大多数起点在第一位就会失败，实际运行远快于上界。
6. **不要构造字符串**：任何 `a * x` 的写法在 $x = 10^9$ 时都会内存爆炸。

## 5. 正确性证明

记 $S = a*x$（长度 $N$），$T = b*y$（长度 $L$），$S[i]$ 表示 $S$ 的第 $i$ 个字符。由重复串的定义，

$$S[i] = a[i \bmod A], \qquad T[t] = b[t \bmod B]$$

**引理 1（长度必要条件）**：若 $L > N$，则 $T$ 不是 $S$ 的子串。

**证明**：子串长度不超过原串长度，故 $L \le N$ 是必要条件。∎

**引理 2（起点同余可约简）**：设 $L \le N$，若存在 $o$ 使 $T$ 能在 $S$ 的起点 $o$ 处匹配，则 $o \bmod A$ 处也能匹配。

**证明**：令 $r = o \bmod A$，则 $r \le o$，故 $r + L \le o + L \le N$，起点 $r$ 是合法的。又 $S[r + t] = a[(r+t) \bmod A] = a[(o+t) \bmod A] = S[o+t]$（因 $r \equiv o \pmod A$），故起点 $r$ 处逐位与起点 $o$ 处相同，也匹配。∎

**引理 3（周期性质）**：对固定起点 $o$，若对所有 $0 \le t < \min(L, \text{lcm}(A,B))$ 有 $S[o+t] = T[t]$，则对所有 $0 \le t < L$ 都有 $S[o+t] = T[t]$。

**证明**：设 $P = \text{lcm}(A,B)$。对任意 $t \ge P$，令 $t' = t \bmod P$，则 $t' < P$ 且 $t = t' + kP$。有

$$(o + t) \bmod A = (o + t' + kP) \bmod A = (o + t') \bmod A$$

因为 $A \mid P$；同理 $t \bmod B = t' \bmod B$ 因为 $B \mid P$。于是 $S[o+t] = S[o+t']$、$T[t] = T[t']$，而 $t' < P$ 且 $t' < t < L$，故 $t' < \min(L,P)$，由假设 $S[o+t'] = T[t']$，从而 $S[o+t] = T[t]$。∎

**定理**：算法返回 `true` 当且仅当 $T$ 是 $S$ 的子串。

**证明**：

（$\Leftarrow$）设 $T$ 是 $S$ 的子串，起点为 $o_0$。由引理 2，$r = o_0 \bmod A$ 处也能匹配，且 $r \le \min(A-1, N-L)$ 落在算法枚举范围内。对该 $r$，算法比较前 $\min(L,P)$ 位全部相等，由引理 3 全串匹配，故算法返回 `true`。

（$\Rightarrow$）若算法返回 `true`，说明存在枚举到的起点 $o$ 使前 $\min(L,P)$ 位相等，由引理 3 该起点处整段匹配，即 $T$ 是 $S$ 的子串。

综上结论成立；引理 1 保证长度剪枝不遗漏任何可行情形。∎

## 6. 复杂度分析

- **时间**：$O\big(\min(A, N-L+1) \cdot \min(L, \text{lcm}(A,B))\big)$。最坏 $A \le 100$、$\text{lcm} \le AB \le 10^4$，上界约 $10^6$ 次字符比较；实际因提前 `break` 通常远小于此。求 `gcd` 为 $O(\log \min(A,B))$。
- **空间**：$O(1)$。只用了若干整数变量，没有构造任何拼接字符串。

## 7. 参考代码

### C++

```cpp
#include <numeric>
#include <string>

using namespace std;

class Solution {
public:
    bool repeatedStringMatch(string a, string b, int x, int y) {
        long long A = (long long)a.size(), B = (long long)b.size();
        long long N = A * x, L = B * y;
        if (L > N) return false;
        long long period = lcm(A, B);          // 位置对 (offset+t)%A, t%B 的公共周期
        long long limit = min(L, period);      // 只需比较前 limit 个字符
        long long maxOff = min(A - 1, N - L);  // 起点只需枚举 0..A-1, 且必须放得下
        for (long long off = 0; off <= maxOff; off++) {
            bool ok = true;
            for (long long t = 0; t < limit; t++) {
                if (a[(off + t) % A] != b[t % B]) {
                    ok = false;
                    break;
                }
            }
            if (ok) return true;
        }
        return false;
    }
};
```

### Python

```python
from math import lcm

class Solution:
    def repeatedStringMatch(self, a: str, b: str, x: int, y: int) -> bool:
        A, B = len(a), len(b)
        N = A * x           # len(a * x)
        L = B * y           # len(b * y)
        if L > N:
            return False
        period = lcm(A, B)
        limit = min(L, period)
        max_off = min(A - 1, N - L)
        for off in range(max_off + 1):
            ok = True
            for t in range(limit):
                if a[(off + t) % A] != b[t % B]:
                    ok = False
                    break
            if ok:
                return True
        return False
```

## 8. 边界情况与易错点

1. **$L > N$**：必须直接返回 `false`，否则起点范围为负会出错（`min(A-1, N-L)` 变成负数）。
2. **$L = N$**：只可能整体相等，起点范围退化为 $\{0\}$，算法自然处理。
3. **$A = 1$**：$a$ 是单个字符，`off` 范围只有 $\{0\}$，`(off+t) % 1 = 0` 恒成立，正确。
4. **$B > A$**：$b*y$ 比一个 $a$ 周期还长也没关系，关键是 $L \le N$；此时比较会跨越多个 $a$ 周期，取模自然处理。
5. **乘法溢出**：C++ 中 `A * x` 若两个操作数都是 `int`，$100 \times 10^9$ 会在 `int` 里溢出。必须先把 `A` 提升为 `long long`。
6. **`limit` 用 `min(L, period)` 而不是 `period`**：$L$ 可能小于一个周期，此时只需比较 $L$ 个字符；写成 `period` 会越界读取「$b*y$ 之外」的位置（虽然取模后不越界，但会错误地要求额外字符匹配）。
7. **`maxOff` 必须同时受 `N-L` 限制**：只枚举 $0..A-1$ 可能包含「放不下」的起点，导致把越界位置误判为匹配。
8. **`lcm(A,B)` 的实现**：先除后乘；Python 3.9+ 有 `math.lcm`，更早版本需自己写 `A // gcd(A,B) * B`。
