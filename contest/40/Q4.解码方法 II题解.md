# LeetCode 解码方法 II 题解

## 1. 题目概述

- **标题 / 题号**：解码方法 II（#639，hard）
- **链接**：https://leetcode.cn/problems/decode-ways-ii/
- **来源**：LeetCode 第 40 场周赛 Q4
- **难度**：困难
- **标签**：字符串、动态规划

**题意**：字母 `A`–`Z` 依次编码为 `"1"`–`"26"`。给定只含数字与 `'*'` 的串 `s`，`'*'` 可代表 `1`–`9` 中任意一个数字（**不含 0**）。要求先确定每个 `'*'` 取什么数字，再把整串**完整分组**成长度为 1 或 2 的若干片段，每段的值必须落在 $[1, 26]$ 内且**不得有前导 0**。求「填法 × 分组」得到的解码方案总数，对 $10^9+7$ 取模。

**约束**：

- $1 \le \lvert s \rvert \le 10^5$
- `s[i]` 是 `'0'`–`'9'` 中的一位数字，或字符 `'*'`

## 2. 示例

**示例 1**

```text
输入：s = "*"
输出：9
解释：'*' 可表示 "1" 到 "9" 中的任意一条，分别解码为 "A" 到 "I"，共 9 种。
```

**示例 2**

```text
输入：s = "1*"
输出：18
解释："1*" 可表示 11–19 共 9 条消息，每条都有 2 种解码（拆成 1+1 或整体取 11），
      故 9 × 2 = 18。
```

**示例 3**

```text
输入：s = "2*"
输出：15
解释：21–26 各 2 种解码（6 × 2 = 12）；27–29 只能整体取 1 位字母（3 × 1 = 3）；
      合计 12 + 3 = 15。
```

## 3. 解题思路

### 3.1 暴力思路

最直白的做法：把每个 `'*'` 依次替换成 `1`–`9`，对每条得到的纯数字串跑一遍普通「解码方法」（#91）的 DP，最后把结果相加。若 `s` 中有 $k$ 个 `'*'`，枚举量是 $9^k$——$k$ 最大可达 $10^5$，只跑 $k = 20$ 就已经是 $1.2 \times 10^{19}$ 条串，指数级爆炸，完全不可行。

即使只对 $k \le 6$ 做这种"展开后统计"，也能发现一件事：**所有被展开出来的串，分组结构完全一样**，变的只是"某一步有几种可选数字"。既然如此，就没必要真的枚举，把展开的代价折叠成两个**系数**即可。

### 3.2 核心观察：星号不进枚举，只修正系数

![星号展开成数字集合后按一位、两位分别计数](images/wc40_q4_star_expansion.svg)

解码的每一步只有两种"吞法"：吃 **1 位**，或吃 **2 位**。`'*'` 的特殊之处仅仅在于让**同一步的可选数字变多**，并不会改变分组方式。于是可以把每步的取值数抽成系数：

- **一位系数** $one_i$：`'*'` → 9（可取 1–9）；`'0'` → 0（0 不能单独成码）；其他数字 → 1。
- **两位系数** $two_i$：把 $s[i-2..i-1]$ 展开后合法两位数的个数，取值只能是 $0,1,2,6,9,15$。

转移方程与 #91 完全一致，只是乘上系数：

$$dp[i] = one_i \cdot dp[i-1] + two_i \cdot dp[i-2] \pmod{10^9+7}$$

关键点在于：$one_i$、$two_i$ **都能用有限个分支 $O(1)$ 算出**，根本不需要真的展开 `'*'`。

### 3.3 状态转移与两位系数表

![状态转移流程：一位、两位两条来源相加后滚动](images/wc40_q4_dp_flow.svg)

**状态定义**：$dp[i]$ 表示前缀 $s[0..i)$ 的解码方案数，$dp[0] = 1$（空串视为 1 种方案，作为累加起点）。

**两位系数表**（记 $a = s[i-2]$、$b = s[i-1]$，仅 $i \ge 2$ 时存在）：

![两位组合的合法个数查表](images/wc40_q4_pair_table.svg)

| 情况 | $two$ | 说明 |
| --- | --- | --- |
| $a = 0$ | 0 | 前导 0 非法，`"00"`–`"09"` 全部作废 |
| $a = 1$，$b$ 为数字 | 1 | 只有 $10$–$19$ |
| $a = 2$，$b \le 6$ | 1 | $20$–$26$ |
| $a = 2$，$b \ge 7$ | 0 | $27$–$29$ 越界 |
| $a \ge 3$ | 0 | 两位必然 $> 26$ |
| $a = \texttt{'*'}$，$b$ 为数字且 $b \le 6$ | 2 | $1b$ 与 $2b$ 都合法 |
| $a = \texttt{'*'}$，$b$ 为数字且 $b \ge 7$ | 1 | 只剩 $1b$ 合法 |
| $b = \texttt{'*'}$，$a = 1$ / $a = 2$ / 其他 | 9 / 6 / 0 | $11$–$19$、$21$–$26$、无 |
| $a = b = \texttt{'*'}$ | 15 | $11$–$19$ 共 9 个，再加 $21$–$26$ 共 6 个 |

`"*0"` 落在「$a = \texttt{'*'}$、$b$ 为数字」这一行：$b = 0 \le 6$ 故 $two = 2$（只有 $10$、$20$），而 $one = 0$，于是 $dp = 2$。

### 3.4 示例演算

![s = "***" 的逐步滚动演算](images/wc40_q4_walkthrough.svg)

对 $s = \texttt{"***"}$：

| $i$ | $s[i-1]$ | $one$ | $one \cdot dp[i-1]$ | $two$ | $two \cdot dp[i-2]$ | $dp[i]$ |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | `*` | 9 | $9 \times 1 = 9$ | — | 无前一位 | 9 |
| 2 | `*` | 9 | $9 \times 9 = 81$ | 15 | $15 \times 1 = 15$ | 96 |
| 3 | `*` | 9 | $9 \times 96 = 864$ | 15 | $15 \times 9 = 135$ | 999 |

对 $s = \texttt{"1*2*"}$ 则得到 $dp = [1, 1, 18, 20, 288]$：第 2 位的 $two = 9$（$11$–$19$），第 4 位的 $two = 6$（$21$–$26$）。

## 4. 算法细节

1. **$dp[0] = 1$ 的含义是"空串只有一种解码方式"**（什么都不做）。若设成 0，所有"第一个字母吃两位"的分支都会被丢掉。
2. **滚动数组**：$dp[i]$ 只依赖 $dp[i-1]$、$dp[i-2]$，用两个变量 `dp0`（存 $dp[i-2]$）、`dp1`（存 $dp[i-1]$）即可，初值都取 1：`dp1` 对应 $dp[0]$，`dp0` 在 $i = 2$ 时恰好也是 $dp[0]$。
3. **先算 $one$、再算 $two$，两者独立判断**。`'0'` 在一位分支上贡献 0，但在两位分支上可能合法（`10`、`20`、`*0`），绝不能一见到 0 就整体返回 0。
4. **不要先切子串再转数字**：在循环里 `substr` / 切片再 `stoi` / `int()` 会带来多余分配，$n = 10^5$ 时开销明显；直接对两个字符做字符算术即可。
5. **取模时机**：每次 `cur` 组装完立刻取模。C++ 中 `two * dp0` 的最大量级是 $15 \times 10^9$，已超出 `int`，中间量必须用 `long long`。
6. **`i >= 2` 才查两位表**：$i = 1$ 时不得访问 `s[i-2]`。Python 的负索引会静默取到字符串末尾字符，是本题最隐蔽的 WA 来源。

## 5. 正确性证明

**引理 1（末段长度二分）**：任一合法解码方案中，最后一个字母对应的片段长度只能是 1 或 2。

**证明**：编码把每个字母映射为长度 1 或 2 的数字串，因此任一合法分组的每个片段长度都恰为 1 或 2，末段亦然。∎

**引理 2（系数准确）**：$one_i$ 恰等于"把 $s[i-1]$ 单独解释成一个字母"的取值方案数；$two_i$ 恰等于"把 $s[i-2..i-1]$ 合并解释成一个字母"的取值方案数。

**证明**：

- 一位情形：若 $s[i-1] = d$ 为数字，则 $d \ge 1$ 时唯一取值为 $d$、$d = 0$ 时无合法取值（前导 0 不允许），故系数为 1 或 0；若 $s[i-1] = \texttt{'*'}$，可取 $1..9$ 共 9 个数字，每个数字对应唯一字母，故系数为 9。
- 两位情形：按 $a$、$b$ 是否取 `'*'` 分四种情形，枚举所有替换后，合法两位数集合的大小正是上表所载数值（例如 $a = b = \texttt{'*'}$ 时合法集合是 $\{11,\dots,19\}\cup\{21,\dots,26\}$，共 $9 + 6 = 15$ 个），集合大小即取值方案数。∎

**引理 3（不重不漏）**：$dp[i]$ 的两项分别覆盖了"末段长 1"与"末段长 2"的全部方案，且两类互不重叠。

**证明**：末段长度由引理 1 只可能是 1 或 2，两种情形互斥，故不重；任一合法方案必属其一，故不漏。∎

**定理**：算法返回的值等于 $s$ 的解码方案总数模 $10^9+7$。

**证明**：对 $i$ 归纳。$i = 0$ 时空串只有一种解码，$dp[0] = 1$ 成立。设 $dp[i-1]$、$dp[i-2]$ 均正确。由引理 3，$s[0..i)$ 的任一方案可唯一分解为「前缀方案 + 末段」：末段长 1 的方案数为 $one_i \cdot dp[i-1]$，末段长 2 的方案数为 $two_i \cdot dp[i-2]$——系数由引理 2 给出，前缀部分由归纳假设计数正确，且前后选择相互独立，故相乘。两者相加即 $dp[i]$；逐步取模只改变同余类，不影响最终答案。归纳完成。∎

## 6. 复杂度分析

- **时间**：$O(n)$。每个位置仅做常数次字符比较与两次乘加，$n \le 10^5$ 时总计约 $10^5$ 次运算。
- **空间**：$O(1)$ 额外空间（两个滚动变量）；若保留完整 $dp$ 数组则为 $O(n)$，本题没有必要。

## 7. 参考代码

### C++

```cpp
#include <string>
using namespace std;

class Solution {
public:
    int numDecodings(string s) {
        const int MOD = 1000000007;
        int n = s.size();
        long long dp0 = 1, dp1 = 1;   // dp0 = dp[i-2]，dp1 = dp[i-1]，初值 dp[0] = 1
        for (int i = 1; i <= n; ++i) {
            int one = (s[i - 1] == '*') ? 9 : (s[i - 1] == '0' ? 0 : 1);
            long long cur = 1LL * one * dp1 % MOD;      // 末段长 1
            if (i >= 2) {                               // 末段长 2
                char a = s[i - 2], b = s[i - 1];
                int two;
                if (a == '*' && b == '*')      two = 15;                       // 11-19 + 21-26
                else if (a == '*')             two = (b <= '6') ? 2 : 1;       // 1b / 2b
                else if (b == '*')             two = (a == '1') ? 9 : (a == '2' ? 6 : 0);
                else {
                    int v = (a - '0') * 10 + (b - '0');
                    two = (v >= 10 && v <= 26) ? 1 : 0;
                }
                cur = (cur + 1LL * two * dp0) % MOD;
            }
            dp0 = dp1;
            dp1 = cur;
        }
        return (int)(dp1 % MOD);
    }
};
```

### Python

```python
class Solution:
    def numDecodings(self, s: str) -> int:
        MOD = 10 ** 9 + 7
        n = len(s)
        dp0 = dp1 = 1                     # dp0 = dp[i-2]，dp1 = dp[i-1]，初值 dp[0] = 1
        for i in range(1, n + 1):
            c = s[i - 1]
            one = 9 if c == '*' else (0 if c == '0' else 1)
            cur = one * dp1               # 末段长 1
            if i >= 2:                    # 末段长 2
                a, b = s[i - 2], s[i - 1]
                if a == '*' and b == '*':
                    two = 15                                   # 11-19 与 21-26
                elif a == '*':
                    two = 2 if b <= '6' else 1                 # 1b 与（可能的）2b
                elif b == '*':
                    two = 9 if a == '1' else (6 if a == '2' else 0)
                else:
                    v = int(a) * 10 + int(b)
                    two = 1 if 10 <= v <= 26 else 0
                cur += two * dp0
            cur %= MOD
            dp0, dp1 = dp1, cur
        return dp1
```

## 8. 边界情况与易错点

1. **`s = "0"`**：`one = 0` 且没有两位项，答案为 0。类似地 `"00"`、`"06"` 都是 0——前导 0 不能成码。
2. **`"*0"` → 2**：一位项为 0，只剩 $10$、$20$ 两种两位合并；不要误算成 $9 \times 9$ 之类。反过来 `"0*"` 必须是 0（$a = 0$ 时两位非法，$b = \texttt{'*'}$ 也救不回来）。
3. **`"**"` → 96**，不是 81：$9 \times 9$ 之外还要加上 $15 \times dp[0] = 15$ 的两位分支。
4. **$n = 1$**：`i >= 2` 的分支不执行，只有一位项；`"1"` → 1、`"*"` → 9、`"0"` → 0。
5. **取模**：全 `'*'` 串的答案约以每步 $\times 9$ 的速度增长，必须每步取模；C++ 中间乘积用 `long long`，避免 `two * dp0` 超出 `int`。
6. **Python 负索引**：$i = 1$ 时 `s[i-2]` 会静默取到 `s[-1]`，不报错却语义错误，必须用 `i >= 2` 守住。
7. **`a = '2'` 的分界**：$b \le 6$ 才合法，`"27"`、`"28"`、`"29"` 都只能各自单独成码。

**延伸思考**：本题骨架是「末段只能是 1 位或 2 位」+「每段系数可 $O(1)$ 求得」。若字母表扩到 $1..99$（末段最多 $k$ 位），状态要保留 $k-1$ 个前缀值，复杂度退化为 $O(nk)$；若 `'*'` 也允许表示 `0`，系数表需重算且要额外小心前导零。另一个方向是**去重**：若问"不同解码字符串的个数"而非"方案数"，不同分组可能拼出同一串，问题会立刻难上一个量级——这也是把"计数"与"枚举"区分开的经典分水岭。
