# LeetCode 价值和小于等于 K 的最大数字 题解

## 1. 题目概述

- **标题 / 题号**：价值和小于等于 K 的最大数字（#3007，medium）
- **链接**：https://leetcode.cn/problems/maximum-number-that-sum-of-the-prices-is-less-than-or-equal-to-k/
- **来源**：LeetCode 第 380 场周赛 Q3
- **难度**：中等
- **标签**：位运算、数学、二分查找

**题意**：定义整数 `num` 的**价格**为其二进制表示中位于第 $x, 2x, 3x, \dots$ 位（从**最低有效位**起算，位号从 1 开始）上的**设置位**个数；定义 `num` 的**累加价格**为 $\sum_{m=1}^{\text{num}} \text{price}(m)$。给定 $k$ 与 $x$，返回累加价格 $\le k$ 的**最大** `num`（最大「廉价数字」）。

**约束**：

- $1 \le k \le 10^{15}$
- $1 \le x \le 8$

> ⚠️ 读题陷阱：价格数的是计费位上 **1 的个数**，不是把这些位的权值 $2^{i-1}$ 加起来。`x = 2, num = 13`（`1101`）只在第 4 位命中一次，价格是 **1** 而不是 8。

> 💡 本题另有[每日题解 3007](../../solution/3001-3100/3007_价值和小于等于K的最大数字.md)：含固定上界 $10^{16}$ 的闭区间二分与免二分的按位贪心构造、面试问答展开，与本文互为印证；本文侧重赛场推导路径、倍增写法与严谨证明。

## 2. 示例

**示例 1**

```text
输入：k = 9, x = 1
输出：6
解释：x = 1 时所有位都计价。num = 1..7 的价格依次为 1,1,2,1,2,2,3，
     累加价格为 1,2,4,5,7,9,12。acc(6) = 9 ≤ 9，acc(7) = 12 > 9，故答案是 6。
```

**示例 2**

```text
输入：k = 7, x = 2
输出：9
解释：x = 2 时只计第 2, 4, 6, … 位。num = 1..10 的价格依次为
     0,1,1,0,0,1,1,1,1,2，累加价格为 0,1,2,2,2,3,4,5,6,8。
     acc(9) = 6 ≤ 7，acc(10) = 8 > 7，故答案是 9。
```

**示例 3**（边界补充：价格可为 0）

```text
输入：k = 1, x = 2
输出：2
解释：num = 1, 2, 3 的价格依次为 0, 1, 1，累加价格 0, 1, 2。
     acc(2) = 1 ≤ 1，acc(3) = 2 > 1，故答案是 2。
     注意 1 的价格就是 0——累加价格并非严格递增。
```

## 3. 解题思路

### 3.1 暴力思路

从 `num = 1` 起逐个计算价格并累加，首次超过 $k$ 时返回上一个 `num`，复杂度 $O(\text{answer} \cdot \log / x)$。

问题出在答案的量级：$x = 8$ 时计费位最稀疏，`num < 128` 的数价格全为 0，平均每个数只贡献约 $\frac{\log_2 \text{num}}{16}$ 个计费位；累加价格要涨到 $10^{15}$，实测答案达 $3.4 \times 10^{14}$——**answer 远大于 $k$ 本身**，逐个累加必然超时。出路是把「$1 \sim \text{num}$ 这一段数的计费位设置位总数」变成**闭式批量计算**。

### 3.2 核心观察：单调性 ⇒ 二分；按位周期 ⇒ 闭式计数

![核心概念：价格 = 计费位上设置位的个数](images/wc380_q3_price_positions.svg)

**观察 1（单调性）**：每个数的价格非负，故累加价格 $\text{acc}(\text{num})$ 关于 `num` **单调不减**（允许持平，见示例 3）。「$\text{acc} \le k$」于是呈**前缀真、后缀假**的二段性，分界点即最大廉价数字——标准的**二分答案**结构。

**观察 2（按位闭式计数）**：累加价格按位拆开，只需数「计费位上的 1」各自出现了多少次：

$$\text{acc}(\text{num}) = \sum_{i = x,\, 2x,\, 3x,\, \dots} C(\text{num},\, i)$$

其中 $C(\text{num}, i)$ 是 $0 \sim \text{num}$ 共 $n = \text{num}+1$ 个数中**第 $i$ 位为 1 的个数**（0 的价格恒为 0，白送进统计区间不改变总和）。而第 $i$ 位的取值随整数递增以 $2^i$ 为**周期**循环：先 $2^{i-1}$ 个 0、再 $2^{i-1}$ 个 1：

![按位周期计数：完整周期 + 零头](images/wc380_q3_bit_period_count.svg)

$$C(\text{num}, i) = \left\lfloor \frac{n}{2^i} \right\rfloor \cdot 2^{i-1} + \max\left(0,\ n \bmod 2^i - 2^{i-1}\right)$$

- **完整周期**：$\lfloor n / 2^i \rfloor$ 个整块，每块贡献 $2^{i-1}$ 个 1；
- **零头**：剩 $r = n \bmod 2^i$ 个数先补齐 0 段，多出的 $\max(0, r - 2^{i-1})$ 个才是 1。

这就是 [233. 数字 1 的个数](https://leetcode.cn/problems/number-of-digit-one/)「按位分周期计数」的二进制版——每次查询 $O(1)$，二分判定函数从 $O(n)$ 扫描压到 $O(\log/x)$，$k \le 10^{15}$ 才因此可解。

### 3.3 算法流程：倍增定上界 + 二分

![算法流程：倍增定上界 + 二分答案](images/wc380_q3_binary_search_flow.svg)

1. **倍增定上界**：`hi` 从 1 起步，只要 $\text{acc(hi)} \le k$ 就翻倍，出口保证 $\text{acc(hi)} > k$——免去「猜上界 $10^{16}$」的量级估算；
2. **二分**：维护不变式 $\text{acc}(l) \le k < \text{acc}(r)$，初始 $l = 0$（$\text{acc}(0) = 0$ 必廉价）、$r = \text{hi}$（必超支）；
3. 每轮取 $\text{mid} = \lfloor (l+r)/2 \rfloor$：廉价则 $l \leftarrow \text{mid}$，超支则 $r \leftarrow \text{mid}$；
4. $l + 1 = r$ 时终止，返回 $l$——最大廉价数字，且 $\text{acc}(l+1) > k$。

> 💡 赛场写法取舍：固定上界 $[1, 10^{16}]$ 的闭区间二分同样正确（上界与溢出论证见每日题解），但倍增版**不需要任何量级估算**、直接落地；两者复杂度同阶，任选其一。

### 3.4 示例演算

![示例演算：k=7, x=2 的价格表与公式验算](images/wc380_q3_example_walkthrough.svg)

对示例 2（$k = 7, x = 2$），计费位为第 2、4 位，用闭式验算：

- $\text{acc}(9)$：$n = 10$。$C(9,2) = \lfloor 10/4 \rfloor \times 2 + \max(0,\ 10 \bmod 4 - 2) = 4$（即 2, 3, 6, 7 四个数）；$C(9,4) = \max(0,\ 10 - 8) = 2$（即 8, 9）；合计 $6 \le 7$ ✓
- $\text{acc}(10)$：$C(10,2) = 5$（10 自身第 2 位也为 1），$C(10,4) = 3$（10 自身第 4 位也为 1），合计 $8 > 7$ ✗

分界点在 9 与 10 之间，二分收敛到 **9**，与逐项表格完全一致。

## 4. 算法细节

1. **$n = \text{num} + 1$**：公式统计的是 $0 \sim \text{num}$ 共 $n$ 个数。0 的任何位都是 0、不贡献价格，但把 0 放进区间能让「周期从第 0 个数开始对齐」——本题最常见的 off-by-one。
2. **只枚举计费位**：$i$ 取 $x, 2x, 3x, \dots$，其余位算 $C$ 也不计入。终止条件 $2^{i-1} \le \text{num}$（**不是** $2^i \le \text{num}$）：最高设置位所在的那一轮也要算，否则漏掉整段高位贡献，`acc` 系统性偏小、答案偏大。
3. **倍增上界为何安全**：$\text{acc}(2^t) = \lfloor t/x \rfloor \cdot 2^{t-1} + [\,x \mid t+1\,]$（$t$ 位以内每个计费位贡献 $2^{t-1}$ 个 1）。对 $k \le 10^{15}$、$x = 1 \dots 8$ 逐一验证：首次超过 $k$ 的 $t$ 至多是 49（$x = 7, 8$ 时），故倍增停在 $\text{hi} \le 2^{49}$；`acc(hi)` 内计费位 $i \le 50$，`1LL << i` 远离 `long long` 上界。
4. **求和溢出**：`acc` 求和最多约 50 项、每项 $\le \text{num}+1 \le 2^{49}$，总和 $\le 3 \times 10^{16}$，`long long` 装得下；再加「超 $k$ 提前退出」双保险——二分只关心与 $k$ 的大小关系，不关心精确值。
5. **C++ 移位用 `long long`**：`1LL << (i - 1)` 中 `i` 声明为 `long long`；若误写 `1 << i` 且 $i \ge 31$，是未定义行为。Python 大整数天然无忧。

## 5. 正确性证明

**引理 1**（按位周期计数）：对 $i \ge 1$、$n = \text{num}+1$，$0 \sim \text{num}$ 中第 $i$ 位为 1 的个数恰为 $C(\text{num}, i) = \lfloor n / 2^i \rfloor \cdot 2^{i-1} + \max(0,\ r - 2^{i-1})$，其中 $r = n \bmod 2^i$。

**证明**：非负整数 $m$ 的第 $i$ 位为 1 当且仅当 $m \bmod 2^i \in [2^{i-1},\ 2^i)$，故该位取值按 $m$ 从 0 递增以 $2^i$ 为周期，每周期内前 $2^{i-1}$ 个为 0、后 $2^{i-1}$ 个为 1。前 $\lfloor n / 2^i \rfloor$ 个完整周期各贡献 $2^{i-1}$ 个 1；余下 $r = n \bmod 2^i < 2^i$ 个数是新一周期开头，其中第 $i$ 位为 1 的有 $\min(\max(0,\ r - 2^{i-1}),\ 2^{i-1}) = \max(0,\ r - 2^{i-1})$ 个。∎

**引理 2**（累加价格的按位分解）：$\text{acc}(\text{num}) = \sum_{t \ge 1,\ 2^{tx-1} \le \text{num}} C(\text{num},\ tx)$。

**证明**：交换求和次序：

$$\text{acc}(\text{num}) = \sum_{m=1}^{\text{num}} \sum_{t \ge 1} [\,m \text{ 的第 } tx \text{ 位为 1}\,] = \sum_{t \ge 1} \sum_{m=0}^{\text{num}} [\,m \text{ 的第 } tx \text{ 位为 1}\,] = \sum_{t \ge 1} C(\text{num},\ tx)$$

（$m = 0$ 各位均为 0，加入不改变和。）当 $2^{tx-1} > \text{num}$ 时 $C(\text{num}, tx) = 0$，故截断到 $2^{tx-1} \le \text{num}$ 安全。∎

**引理 3**（单调性）：$\text{acc}$ 单调不减。

**证明**：$\text{acc}(\text{num}+1) - \text{acc}(\text{num}) = \text{price}(\text{num}+1) \ge 0$——累加价格每前进一个数恰新增该数的价格，而价格是设置位计数、非负。∎

**定理**：算法返回的 $l$ 满足 $\text{acc}(l) \le k$ 且 $\text{acc}(l+1) > k$，即最大廉价数字。

**证明**：倍增出口保证初始 $r_0 = \text{hi}$ 满足 $\text{acc}(r_0) > k$；初始 $l = 0$ 满足 $\text{acc}(0) = 0 \le k$。对二分轮数归纳维护不变式 $\text{acc}(l) \le k < \text{acc}(r)$：每轮 $\text{mid} \in (l, r)$，若 $\text{acc(mid)} \le k$ 则 $l \leftarrow \text{mid}$、左半保持；否则 $r \leftarrow \text{mid}$、右半保持。区间长度每轮至少减半，必终止于 $l + 1 = r$。此时 $l$ 廉价、$l + 1 = r$ 超支；由引理 3，一切 $> l$ 的数累加价格 $\ge \text{acc}(l+1) > k$ 均超支，故 $l$ 是最大廉价数字。∎

## 6. 复杂度分析

- **时间复杂度**：$O\!\left(\dfrac{(\log k)^2}{x}\right)$。倍增与二分各约 $\log \text{hi} \le 50$ 轮；每轮 `acc` 枚举 $\le \lceil 50/x \rceil$ 个计费位（$x = 1$ 时 50 个、$x = 8$ 时 7 个），每位 $O(1)$ 公式求 $C$。最坏（$x = 1$）约 $2 \times 50 \times 50 = 5000$ 次整数运算，瞬间完成。
- **空间复杂度**：$O(1)$，仅常数个变量。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    long long findMaximumNumber(long long k, int x) {
        // acc(num)：1..num 的累加价格；超过 k 提前退出（防溢出兼提速）
        auto acc = [&](long long num) -> long long {
            long long s = 0, n = num + 1;               // 统计 0..num 共 n 个数
            for (long long i = x; (1LL << (i - 1)) <= num; i += x) {
                long long period = 1LL << i, half = period >> 1;
                s += n / period * half + max(0LL, n % period - half);
                if (s > k) break;
            }
            return s;
        };

        long long hi = 1;
        while (acc(hi) <= k) hi <<= 1;                  // 倍增：出口保证 acc(hi) > k

        long long l = 0, r = hi;                        // 不变式：acc(l) ≤ k < acc(r)
        while (l + 1 < r) {
            long long mid = l + (r - l) / 2;
            if (acc(mid) <= k) l = mid;                 // mid 廉价，向右收缩
            else r = mid;                               // mid 超支，向左收缩
        }
        return l;                                       // 最大廉价数字
    }
};
```

### Python

```python
class Solution:
    def findMaximumNumber(self, k: int, x: int) -> int:
        def acc(num: int) -> int:                 # 1..num 的累加价格，超 k 提前退出
            s, n, i = 0, num + 1, x               # 统计 0..num 共 n 个数
            while (1 << (i - 1)) <= num:          # 只枚举计费位 x, 2x, 3x, ...
                period, half = 1 << i, 1 << (i - 1)
                s += n // period * half + max(0, n % period - half)
                if s > k:
                    break
                i += x
            return s

        hi = 1
        while acc(hi) <= k:                       # 倍增：出口保证 acc(hi) > k
            hi <<= 1

        l, r = 0, hi                              # 不变式：acc(l) ≤ k < acc(r)
        while l + 1 < r:
            mid = (l + r) // 2
            if acc(mid) <= k:
                l = mid                           # mid 廉价，向右收缩
            else:
                r = mid                           # mid 超支，向左收缩
        return l                                  # 最大廉价数字
```

> 💡 免二分的替代：从高位到低位**贪心试填**同样成立——每次试置 1 后用同一个 `acc` 判定，可行即保留；正确性与复杂度见[每日题解 3007 第 5 节](../../solution/3001-3100/3007_价值和小于等于K的最大数字.md)。

## 8. 边界情况与易错点

1. **`num + 1` 别忘加**：公式数的是 $0 \sim \text{num}$；0 不贡献价格但让周期对齐（见 §4.1）。
2. **循环终止条件**用 $2^{i-1} \le \text{num}$：写成 $2^i \le \text{num}$ 会漏掉最高设置位那一整轮，`acc` 系统性偏小、二分答案系统性偏大。
3. **答案远大于 $k$**：$x = 8$、$k = 10^{15}$ 时答案约 $3.4 \times 10^{14}$，达 $k$ 的三分之一；按 $k$ 估计答案量级或「上界取 $k$」都会错，倍增或 $10^{16}$ 上界才稳。
4. **累加价格非严格递增**：$x = 8$ 时 $1 \sim 127$ 价格全 0、`acc` 出现长平台；二分求「$\le k$ 的最大值」只需单调不减，平台不破坏二段性。
5. **溢出**：C++ 中移位必须 `1LL <<`（`1 << i` 在 $i \ge 31$ 时是 UB）；`acc` 求和上限约 $3 \times 10^{16}$，`long long` 装得下，另有「超 $k$ 提前退出」双保险。Python 大整数天然无忧。
6. **读题**：价格是计费位上 **1 的个数**，不是位权之和；位号从最低有效位起、从 1 开始计（第 $x$ 位对应权值 $2^{x-1}$）。
7. **返回值下界**：$k \ge 1$ 且 $\text{acc}(1) \le 1$，答案必 $\ge 1$；初始 $l = 0$ 只是哨兵，最终不会被返回。
