# LeetCode 找出唯一性数组的中位数 题解

## 1. 题目概述

- **标题 / 题号**：找出唯一性数组的中位数（#3134，hard）
- **链接**：https://leetcode.cn/problems/find-the-median-of-the-uniqueness-array/
- **来源**：LeetCode 第 395 场周赛 Q4
- **难度**：困难
- **标签**：数组、哈希表、二分查找、滑动窗口

**题意**：给你一个整数数组 `nums`。定义 `nums` 的**唯一性数组**：把**所有** $0 \le i \le j \lt n$ 的子数组 $\text{nums}[i..j]$ 的**不同元素个数** $\mathrm{distinct}(\text{nums}[i..j])$ 全部收集起来，按从小到大排序得到的数组。返回这个唯一性数组的**中位数**（若长度为偶数，取两个中间元素中**较小**的那个）。

**约束**：

- $1 \le n = \text{nums.length} \le 10^5$
- $1 \le \text{nums}[i] \le 10^5$

> 💡 **读题关键**：唯一性数组有 $m = \frac{n(n+1)}{2}$ 个元素，$n = 10^5$ 时约 $5 \times 10^9$ 个——**存不下、排不动**，任何「显式构造再取中位数」的思路当场出局。但中位数本质是「**第 $k$ 小**」问题：第 $k$ 小只需**计数**、不需排序；而 distinct 的取值只有 $[1, n]$，配合「计数关于阈值单调」，正是**二分答案**的标准信号。

## 2. 示例

输入：nums = [1,2,3]
输出：1
解释：唯一性数组为 [distinct([1]), distinct([2]), distinct([3]),
                    distinct([1,2]), distinct([2,3]), distinct([1,2,3])]

## 3. 解题思路

### 3.1 暴力思路：枚举所有子数组

以每个 $i$ 为左端点向右扩张 $j$，用集合增量维护 $\mathrm{distinct}(\text{nums}[i..j])$，把所有值收进数组排序，取中间：

```python
def brute(nums):
    vals = []
    for i in range(len(nums)):
        seen = set()
        for j in range(i, len(nums)):
            seen.add(nums[j])       # 右端扩张，distinct 只增不减
            vals.append(len(seen))
    vals.sort()
    return vals[(len(vals) + 1) // 2 - 1]
```

- 时间 $O(n^2 \log m)$、空间 $O(n^2)$：$n = 10^5$ 时要生成约 $5 \times 10^9$ 个值，**生成、存储、排序三重爆炸**，数据范围直接否决；
- 但暴力并非一无所获——它确认了 distinct 的两个关键性质：**固定左端、右端扩张时只增不减**（滑窗可行性），以及**值域只有 $[1, n]$**（二分可行性），还可作为小规模对拍基准。

> ⚠️ 优化方向不是「更快地排序」——瓶颈在生成 $O(n^2)$ 个值本身。凡是「把所有答案列出来再挑」的做法都无药可救，必须**只数个数、不造数组**。

### 3.2 核心观察：中位数 → 第 k 小 → 二分答案

![核心观察：中位数即第 k 小，对阈值 t 二分](images/wc395_q4_median_kth_concept.svg)

**第一步：中位数 = 第 $k = \lceil m/2 \rceil$ 小（1-indexed）**。设 $m = \frac{n(n+1)}{2}$ 为子数组总数。$m$ 为奇数时中位数是第 $\frac{m+1}{2}$ 个；为偶数时题目规定取**较小**的中间元素，即第 $\frac{m}{2}$ 个。两者统一为

$$k = \left\lceil \frac{m}{2} \right\rceil = \frac{m + 1}{2} \text{（整数除法）}$$

于是问题转化为：**求唯一性数组中第 $k$ 小的值**。

**第二步：计数谓词单调 → 二分**。定义计数函数

$$\mathrm{count}(t) = \#\{\,\text{子数组} : \mathrm{distinct} \le t\,\}$$

$t$ 越大约束越松、合法集合只扩不缩，故 $\mathrm{count}(t)$ 关于 $t$ **单调不减**。而「第 $k$ 小 $\le t$」$\iff$「至少 $k$ 个子数组的 distinct $\le t$」$\iff \mathrm{count}(t) \ge k$。于是二分找**最小**的 $t$ 使谓词为真：

$$\text{ans} = \min\{\, t \in [1, n] : \mathrm{count}(t) \ge k \,\}$$

二分值域是 $[1, n]$（distinct 最小为 1、最大为 $n$），只需约 $\lceil \log_2 n \rceil \approx 17$ 次判定，每次判定是下面的线性滑窗。

### 3.3 算法流程：「至多 t 种不同」滑窗 O(n) 计算 count(t)

![滑动窗口计算 count(t)](images/wc395_q4_sliding_window.svg)

$\mathrm{count}(t)$ 是经典的「**至多 $t$ 种不同**」滑窗计数：右端 $r$ 每前进一格，先加入 $\text{nums}[r]$；若窗口内不同元素个数超过 $t$，就收缩左端 $l$ 直到重新合法。此刻**以 $r$ 结尾**的合法子数组恰有 $r - l + 1$ 个（左端取 $l, l+1, \dots, r$ 中的任意一个都保持 distinct $\le t$），累加即可：

$$\mathrm{count}(t) = \sum_{r=0}^{n-1} \left( r - l_r + 1 \right)$$

其中 $l_r$ 是使 $\mathrm{distinct}(\text{nums}[l..r]) \le t$ 的最小左端。两个关键点：

- **不重不漏**：每个子数组只按它的**右端点**被统计一次；
- **均摊 $O(n)$**：$l$ 与 $r$ 各自单调前进、全程各走至多 $n$ 步；distinct 的增减由频率表 $O(1)$ 维护（`freq[x]` 从 0 变 1 时加一、从 1 变 0 时减一）。

外层二分值域、内层滑窗计数，整体流程：

```text
m ← n(n+1)/2,  k ← (m+1)/2              # 中位数 = 第 k 小
lo ← 1, hi ← n                          # 答案值域 [1, n]
while lo < hi:
    mid ← (lo + hi) / 2
    if count(mid) ≥ k:  hi ← mid        # 第 k 小 ≤ mid，收缩右界
    else:                lo ← mid + 1   # 第 k 小 > mid，抬升左界
return lo
```

### 3.4 示例演算

![示例演算：nums = [4,3,5,4] 的二分与滑窗走查](images/wc395_q4_example_walkthrough.svg)

以示例 3 的 $\text{nums} = [4,3,5,4]$ 为例：$n = 4$，$m = 10$，$k = \lceil 10/2 \rceil = 5$，二分值域 $[1, 4]$。

**二分过程**：

| 轮次 | lo | hi | mid | count(mid) | 判定 | 动作 |
|------|----|----|-----|-----------|------|------|
| 1 | 1 | 4 | 2 | 7 | $7 \ge 5$ ✓ | hi ← 2 |
| 2 | 1 | 2 | 1 | 4 | $4 \lt 5$ ✗ | lo ← 2 |
| — | 2 | 2 | — | — | lo = hi | 返回 **2** |

**count(2) 的滑窗走查**（$t = 2$）：

| $r$ | 收缩后窗口 | distinct | 收缩动作 | 累加 $r-l+1$ | ans |
|-----|-----------|----------|---------|-------------|-----|
| 0 | [4] | 1 | — | +1 | 1 |
| 1 | [4,3] | 2 | — | +2 | 3 |
| 2 | [3,5] | 2 | 移出 4 | +2 | 5 |
| 3 | [5,4] | 2 | 移出 3 | +2 | 7 |

得 $\mathrm{count}(2) = 7 \ge 5$；同法可得 $\mathrm{count}(1) = 4 \lt 5$，夹得第 5 小 $= 2$——与唯一性数组 $[1,1,1,1,2,2,2,3,3,3]$ 的第 5 个元素吻合 ✓。

## 4. 算法细节

1. **中位数下标统一**：$m$ 为偶数时取较小中间元素，等价于 1-indexed 的第 $\frac{m}{2}$ 个；奇数时第 $\frac{m+1}{2}$ 个。用整数除法 $k = \frac{m+1}{2}$ 一行统一两种情形（勿写成 $\frac{m}{2} + 1$，偶数时会错位）。
2. **计数公式**：滑窗中每个右端 $r$ 贡献 $r - l + 1$，即以 $r$ 结尾、左端 $\ge l$ 的子数组个数；频率表维护 `distinct`，进入（0→1）加一、离开（1→0）减一。
3. **二分写法**：闭区间上「找最小可行 $t$」用 `lo < hi` + `hi = mid` / `lo = mid + 1` 收缩；值域 $[1, n]$ 保证 $t = n$ 时 $\mathrm{count}(n) = m \ge k$ 恒真，谓词必有 true，二分不会落空。更讲究可把上界收紧到 $\mathrm{distinct}(\text{nums})$（数组中不同值的总数），省几轮无效判定。
4. **频率表选数组不选哈希表**：值域 $1 \le \text{nums}[i] \le 10^5$，`vector<int> freq(100001)` 比 `unordered_map` 快数倍；每轮二分重建的 $O(10^5)$ 开销（约 17 轮）远小于滑窗本身，也可用「记录脏槽位、只清脏槽」消除。
5. **64 位计数**：$m$ 最大 $\frac{10^5 \times (10^5 + 1)}{2} \approx 5 \times 10^9$，`count` 的返回值同量级，均超 `int` 上限（约 $2.1 \times 10^9$），C++/Java 全程 `long long` / `long`；Python 天然大数无此虑。

## 5. 正确性证明

**引理 1**（窗口单调性）：固定左端 $i$，$\mathrm{distinct}(\text{nums}[i..j])$ 关于 $j$ 单调不减；固定右端 $j$，$\mathrm{distinct}(\text{nums}[i..j])$ 关于 $i$ 单调不减。

**证明**：右端扩张只往集合加入元素，元素集合不缩小，不同元素个数不减；左端收缩反之同理。∎

**推论**（双指针合法性）：对每个右端 $r$，记 $l_r$ 为满足 $\mathrm{distinct}(\text{nums}[l..r]) \le t$ 的最小左端 $l$（若存在）。由引理 1，若 $l$ 对 $r$ 合法，则对一切 $r' \lt r$ 也合法，故 $l_r$ 关于 $r$ 单调不减——左指针全程只前进，双指针均摊 $O(n)$。∎

**引理 2**（计数单调性）：$\mathrm{count}(t) \le \mathrm{count}(t+1)$ 对一切 $t \ge 0$ 成立。

**证明**：$\{\text{子数组} : \mathrm{distinct} \le t\} \subseteq \{\text{子数组} : \mathrm{distinct} \le t+1\}$，后者集合不小于前者。∎

**引理 3**（滑窗计数正确性）：滑窗返回的 $\sum_{r} (r - l_r + 1)$ 恰等于 distinct $\le t$ 的子数组总数。

**证明**：按右端点分类。以 $r$ 结尾的子数组 $\text{nums}[l..r]$ 合法 $\iff \mathrm{distinct}(\text{nums}[l..r]) \le t$，由引理 1 该谓词关于 $l$ 单调（$l$ 越大窗口越短、distinct 越小），故合法左端恰是 $l_r, l_r + 1, \dots, r$ 共 $r - l_r + 1$ 个。每个子数组有唯一右端点，被且仅被其右端点计数一次，不重不漏。∎

**引理 4**（第 $k$ 小刻画）：设唯一性数组升序为 $a_1 \le a_2 \le \dots \le a_m$，则 $a_k \le t \iff \mathrm{count}(t) \ge k$。

**证明**：$\mathrm{count}(t) = \#\{i : a_i \le t\}$。若 $a_k \le t$，则 $a_1, \dots, a_k \le a_k \le t$，至少 $k$ 个元素 $\le t$；反之若至少 $k$ 个元素 $\le t$，由升序知其中最小的 $k$ 个全 $\le t$，故 $a_k \le t$。∎

**定理**：$\text{ans} = \min\{t \in [1, n] : \mathrm{count}(t) \ge k\}$ 等于唯一性数组的中位数（第 $k = \lceil m/2 \rceil$ 小）。

**证明**：

- **存在性**：$t = n$ 时任何子数组的 distinct $\le n$，$\mathrm{count}(n) = m \ge k$，可行集非空，最小值存在。
- **下界方向**：$\mathrm{count}(\text{ans}) \ge k$，由引理 4 得 $a_k \le \text{ans}$。
- **上界方向**：$\mathrm{count}(\text{ans} - 1) \lt k$（当 $\text{ans} = 1$ 时 $\mathrm{count}(0) = 0 \lt k$，因每个子数组 distinct $\ge 1$），由引理 4 得 $a_k \gt \text{ans} - 1$，即 $a_k \ge \text{ans}$。
- 两边夹逼得 $a_k = \text{ans}$，即返回值恰为中位数。∎

## 6. 复杂度分析

**时间复杂度**：$O(n \log n)$。

- 二分值域 $[1, n]$，共 $O(\log n)$ 轮（$n = 10^5$ 时约 17 轮）；
- 每轮内滑窗均摊 $O(n)$：左右指针各至多前进 $n$ 步，每步频率表操作 $O(1)$；
- 若每轮重建值域大小的频率表，额外 $O(C \log n)$，$C = 10^5$，与 $O(n \log n)$ 同阶，不影响总量级。

**空间复杂度**：$O(C)$，其中 $C = 10^5$ 为元素值域上界，用于频率表；哈希表实现则为 $O(\min(n, C))$。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int medianOfUniquenessArray(vector<int>& nums) {
        int n = nums.size();
        long long m = 1LL * n * (n + 1) / 2;     // 子数组总数 ≈ 5e9，必须 long long
        long long k = (m + 1) / 2;               // 中位数 = 第 k 小（偶数取较小者）

        int lo = 1, hi = n;                      // 答案值域 [1, n]
        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            if (countAtMost(nums, mid) >= k)     // 第 k 小 ≤ mid
                hi = mid;
            else
                lo = mid + 1;
        }
        return lo;
    }

  private:
    // 不同元素个数 ≤ t 的子数组数目：「至多 t 种」滑窗，均摊 O(n)
    long long countAtMost(vector<int>& nums, int t) {
        vector<int> freq(100001, 0);             // 值域 1..1e5，数组比哈希表快
        long long ans = 0;
        int left = 0, distinct = 0;
        for (int right = 0; right < (int)nums.size(); right++) {
            if (freq[nums[right]]++ == 0) distinct++;
            while (distinct > t) {               // 种类超限：收缩左端
                if (--freq[nums[left]] == 0) distinct--;
                left++;
            }
            ans += right - left + 1;             // 以 right 结尾的合法子数组个数
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def medianOfUniquenessArray(self, nums: List[int]) -> int:
        n = len(nums)
        m = n * (n + 1) // 2                # 子数组总数（约 5e9）
        k = (m + 1) // 2                    # 中位数 = 第 k 小（偶数取较小者）

        def count_at_most(t: int) -> int:
            """不同元素个数 ≤ t 的子数组数目：至多 t 种滑窗"""
            freq = defaultdict(int)
            ans, left, distinct = 0, 0, 0
            for right, x in enumerate(nums):
                if freq[x] == 0:
                    distinct += 1
                freq[x] += 1
                while distinct > t:         # 种类超限：收缩左端
                    y = nums[left]
                    freq[y] -= 1
                    if freq[y] == 0:
                        distinct -= 1
                    left += 1
                ans += right - left + 1     # 以 right 结尾的合法子数组
            return ans

        lo, hi = 1, n                       # 答案值域 [1, n]
        while lo < hi:
            mid = (lo + hi) // 2
            if count_at_most(mid) >= k:
                hi = mid
            else:
                lo = mid + 1
        return lo
```

## 8. 边界情况与易错点

1. **溢出（最常见的 WA/TLE 来源）**：$m$ 与 $\mathrm{count}$ 最大约 $5 \times 10^9$，超出 32 位 `int`；C++ 中 `1LL * n * (n+1)` 的乘法前置转型、比较 `count(...) >= k` 两边都走 64 位。Python 无此虑，但 `k` 若误用浮点除法 `math.ceil(m/2)` 会引入精度风险，用整数 `(m + 1) // 2`。
2. **偶数长度取「较小」中间元素**：题目规定与常规「取平均」不同，$k = \lceil m/2 \rceil$ 而非 $\lfloor m/2 \rfloor$ 或 $m/2+1$；$m = 10$ 时 $k = 5$，$m = 6$ 时 $k = 3$。
3. **二分不要落空**：上界取 $n$ 时 $\mathrm{count}(n) = m \ge k$ 恒真；若把上界误设为「不同元素个数 − 1」或从 0 开始 `hi`，可能返回错误值。
4. **收缩条件是 `distinct > t`**：是「超过 $t$ 才收缩」而非「$\ge t$」，后者会把恰好 $t$ 种的合法窗口也砍掉，系统性少算。
5. **单元素数组**：$n = 1$，$m = k = 1$，$\mathrm{count}(1) = 1 \ge 1$，返回 1，无需特判。
6. **全相同 / 全互异**：全相同时唯一性数组全为 1，二分第一轮即命中 $t = 1$；全互异时唯一性数组为 $[1, 2, \dots, n]$ 各若干，答案明显偏大，可作对拍极端用例。
