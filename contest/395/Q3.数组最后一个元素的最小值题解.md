# LeetCode 数组最后一个元素的最小值 题解

## 1. 题目概述

- **标题 / 题号**：数组最后一个元素的最小值（#3133，medium）
- **链接**：https://leetcode.cn/problems/minimum-array-end/
- **来源**：LeetCode 第 395 场周赛 Q3
- **难度**：中等
- **标签**：位运算

**题意**：给定两个整数 `n` 和 `x`，构造一个长度为 `n` 的**严格递增**正整数数组 `nums`，使得数组中所有元素的按位 **AND** 结果恰好为 `x`。返回 `nums[n-1]`（末元素）可能的**最小值**。

**约束**：

- `1 <= n, x <= 10^8`
- 两者都可达 $10^8$：答案会远超 32 位整型范围（见 §8），且 $O(n)$ 的枚举做法面临 $10^8$ 次运算，两头都卡常规思路

## 2. 示例

**示例 1**

```text
输入：n = 3, x = 4
输出：6
解释：数组可以是 [4, 5, 6]，末元素为 6；4 & 5 & 6 = 100₂ = 4 = x。
```

**示例 2**

```text
输入：n = 2, x = 7
输出：15
解释：数组可以是 [7, 15]；7 & 15 = 0111₂ = 7 = x。
```

**示例 3（构造，用于 §3.4 演算）**

```text
输入：n = 5, x = 2
输出：10
解释：数组可以是 [2, 3, 6, 7, 10]；五个数的 AND = 0010₂ = 2 = x。
```

## 3. 解题思路

### 3.1 暴力思路

「严格递增 + AND 定值」两个条件里，先抓住 AND 的单调性做暴力：

1. **增量枚举超集**：最小的合法元素一定是 `x` 本身（自由位全 0），之后的每个元素都是 `x` 的超集。从 `v = x` 出发，重复 `n-1` 次 `v = (v + 1) | x`，每次跳到下一个超集。时间 $O(n)$——$n \le 10^8$ 时约 $10^8$ 次运算，Python 必然超时，C++ 也贴着时限跳舞，赛场上不敢写。
2. **二分答案 + 计数**：二分末元素 `v`，需要数「$\le v$ 的超集个数」。计数本身是「把 `v` 的自由位压缩成一个数」的数位操作，还要处理 `v` 不是超集时的退化——能做，但细节远比赛场上能承受的多。

两条路的共同盲区：只想着**按顺序数**超集，没有想着**直接把第 n 个超集构造出来**。超集的序结构其实简单到离谱——它是「把位填进固定插槽」的字典序。

### 3.2 核心观察：合法元素 ⟺ x 的超集

![核心观察：AND = x ⇒ 每个元素都是 x 的超集](images/min_array_end_superset.svg)

**AND 的语义拆成两个方向**：

1. **必要**：AND 结果的每个 1 位上，**所有**元素都必须是 1。所以 `x` 的每个 1 位在 `nums` 的每个元素里都是 1——**每个元素都是 `x` 的超集**（$a \& x = x$）。
2. **充分**：把 `x` 的超集按从小到大排成序列 $s_0 < s_1 < \cdots$，其中 $s_0 = x$（自由位全 0 就是最小超集）。取**前 n 个**：天然严格递增；又因 $s_0 = x$ 的自由位全是 0，AND 在所有自由位上被 $s_0$ 压成 0，于是整体 AND 恰好是 $x$ 的 1 位——等于 $x$。

于是问题完全等价于：

$$\text{答案} = x \text{ 的超集从小到大的第 } n \text{ 个}$$

> 💡 换个视角：`x` 的 1 位是**锁死**的（所有元素必为 1），`x` 的 0 位是**自由插槽**（每个元素可 0 可 1）。递增的超集序列，就是在固定插槽里「进位」填数。

### 3.3 算法流程：把 n−1 写进 x 的 0 位

![算法流程：把 n−1 的二进制位从低到高填进 x 的 0 位插槽](images/min_array_end_bit_fill.svg)

设 `x` 从低到高的 0 位位置依次是 $p_0 < p_1 < p_2 < \cdots$（插槽序列）。断言：

$$\text{第 } i \text{ 小的超集} = x \mid \text{spread}(i), \quad \text{spread}(i) = \sum_j \big(\text{bit}_j(i)\big) \cdot 2^{p_j}$$

即**把 $i$ 的第 $j$ 个二进制位填进插槽 $p_j$**。原因：`x` 的 1 位全部固定，能区分超集大小的只剩自由位；而 $p_j$ 关于 $j$ 递增，这正是「自由位按二进制计数」——插槽上的序列 $0, 1, 2, \cdots$ 恰好按 $i$ 的顺序进位。

第 $n$ 小的超集对应 $i = n-1$（$i$ 从 0 数起），所以：

$$\boxed{\text{ans} = x \mid \text{spread}(n-1)}$$

**实现**用一次双向扫描：`ans` 从 `x` 出发，`k = n-1`；`j` 从低位到高位扫 `ans`——

- `ans` 的第 `j` 位是 1（锁定位）：跳过，不消耗 `k`；
- `ans` 的第 `j` 位是 0（插槽）：把 `k` 的最低位填入该位，然后 `k >>= 1`；
- `k` 变 0 时结束。

### 3.4 示例演算

![示例演算：n=5, x=2 的位填充表与 AND 验证](images/min_array_end_walkthrough.svg)

取构造样例 `n = 5, x = 2`（$x = 10_2$，位 1 锁定，位 0/2/3/… 是插槽）：

| $i$ | $i$ 的二进制 | 填入后元素 | 值 |
|:---:|:---:|:---:|:---:|
| 0 | `000` | `0010` | 2 |
| 1 | `001` | `0011` | 3 |
| 2 | `010` | `0110` | 6 |
| 3 | `011` | `0111` | 7 |
| 4 | `100` | `1010` | **10** |

五个数严格递增；位 1（锁定列）全为 1，插槽列因 $i=0$ 行全 0 被 AND 压成 0，AND $= 0010_2 = 2 = x$ ✓。末元素 $= x \mid \text{spread}(4) = 1010_2 = 10$。

再核对两个官方样例：`n=3, x=4` 时 $k = 2 = 10_2$，位 1 的 1 填进插槽 1 → $110_2 = 6$ ✓；`n=2, x=7` 时低 3 位全锁、第一个插槽在位置 3，$k=1$ 填入 → $1111_2 = 15$ ✓。

## 4. 算法细节

1. **为什么填 `n-1` 而不是 `n`**：超集序列从 $i=0$（即 $x$ 本身）数起，第 $n$ 个对应 $i = n-1$。这是本题最容易手滑的 off-by-one。
2. **两个「从低到高」必须对齐**：`j` 扫描 `ans` 的位序从低到高，`k` 供给位也按从低到高的顺序消耗（每次移除最低位）。插槽 $p_j$ 收到的正是 $k$ 的第 $j$ 位。
3. **只在 0 位消耗 `k`**：扫到 `ans` 的 1 位时跳过、`k` 不动；扫到 0 位才填入并右移 `k`。若在 1 位也右移 `k`，插槽与位的对应关系整体错位。
4. **答案规模**：$n, x \le 10^8 < 2^{27}$。最坏情形（如 $x$ 低 27 位全 1）插槽从第 26 位往上排，$k < 2^{27}$ 最多占 27 个插槽，最高填到第 $26+26=52$ 位附近，答案 $< 2^{53}$。**必须用 64 位整型**（实测 $n = 10^8, x = 99999999$ 时答案为 $52428799999999 \approx 5.2 \times 10^{13}$）。
5. **循环次数**：`j` 每轮要么消耗 `ans` 的一个 1 位（数量 $< 27$），要么消耗 `k` 的一个位（$< 27$），总轮数 $< 54$，即 $O(\log n + \log x)$。
6. **等价的一行解**（BMI2 指令）：`ans = x | _pdep_u64(n - 1, ~x)`——`_pdep` 恰好实现「把 `k` 的位分布到 `~x` 的 1 位（即 `x` 的插槽）」；Python 里可用 `int` 直接模拟或 `bitarray` 思路。依赖硬件扩展，了解即可，赛场上以可移植的扫描版为主。

## 5. 正确性证明

**引理 1（超集必要性）**：合法数组中每个元素 $a$ 都满足 $a \,\&\, x = x$。

**证明**：数组所有元素的 AND 等于 $x$，则对 $x$ 的每个 1 位 $d$，AND 的第 $d$ 位为 1，这要求**每个**元素的第 $d$ 位都是 1。∎

**引理 2（插槽编码保序双射）**：设 $p_0 < p_1 < \cdots$ 为 $x$ 的 0 位位置（64 位意义下）。映射 $e(a) = \sum_j \mathrm{bit}_{p_j}(a) \cdot 2^j$ 在「$x$ 的超集」与「非负整数」之间是双射（逆映射即 $\text{spread}(e) \mid x$），且对任意超集 $a, b$：$a < b \iff e(a) < e(b)$。

**证明**：双射显然：超集在 $x$ 的 1 位上全 1、信息只存于 0 位，$e$ 恰好把这些位压成一个整数，逆映射逐位还原。保序：设 $a < b$，取 $a, b$ 不同的**最高**位 $d$，则 $b$ 的第 $d$ 位为 1、$a$ 为 0，且高于 $d$ 的位两者相同。$d$ 不可能是 $x$ 的 1 位（否则由引理 1 两侧都为 1），故 $d = p_j$。于是 $e(a), e(b)$ 高于第 $j$ 位的部分相同，而第 $j$ 位上 $e(b) = 1 > 0 = e(a)$，故 $e(a) < e(b)$；反向把 $a, b$ 互换同理。∎

**定理（答案刻画与最优性）**：最小末元素 $= x \mid \text{spread}(n-1)$，即把 $n-1$ 的二进制位从低到高填入 $x$ 的 0 位。

**证明**：
**下界**：任取合法数组 $a_0 < a_1 < \cdots < a_{n-1}$。由引理 1 各元素均为超集；由引理 2 的保序性，$e(a_0) < e(a_1) < \cdots < e(a_{n-1})$ 是 $n$ 个互不相同的非负整数，故 $e(a_{n-1}) \ge n - 1$，从而
$$a_{n-1} = x \mid \text{spread}(e(a_{n-1})) \;\ge\; x \mid \text{spread}(n-1).$$
**构造达到下界**：取 $a_i = x \mid \text{spread}(i)$，$i = 0, \ldots, n-1$。由引理 2 保序性，$e(a_i) = i$ 严格递增 ⟹ 数组严格递增。AND：每个 $a_i$ 都是 $x$ 的超集，故 AND 在 $x$ 的 1 位上为 1；$a_0 = x$ 的所有插槽位为 0，故 AND 在 $x$ 的 0 位上为 0。两者合并得 AND $= x$。末元素恰为 $x \mid \text{spread}(n-1)$，达到下界。∎

## 6. 复杂度分析

- **时间复杂度**：$O(\log n + \log x)$。扫描循环的轮数不超过「`x` 的 1 位个数 + `n-1` 的位数」，在 64 位整型下不超过约 54 轮，每轮 $O(1)$ 位操作。对 $n = x = 10^8$ 的最坏用例也是常数级。
- **空间复杂度**：$O(1)$。只用 `ans`、`k`、`j` 三个整型变量，无任何数组与递归栈。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long minEnd(int n, int x) {
        long long ans = x;
        long long k = n - 1;
        for (int j = 0; k > 0; j++) {
            if (((ans >> j) & 1) == 0) {  // 插槽：填入 k 的最低位
                ans |= (k & 1) << j;
                k >>= 1;
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def minEnd(self, n: int, x: int) -> int:
        ans, k, j = x, n - 1, 0
        while k:
            if not (ans >> j) & 1:  # 插槽：填入 k 的最低位
                ans |= (k & 1) << j
                k >>= 1
            j += 1
        return ans
```

> 💡 **写法盘点**：
> - **增量法 $O(n)$**：`ans = x; 重复 n−1 次 ans = (ans + 1) | x`。正确但 $n \le 10^8$ 超时——`(v+1)|x` 是「下一个超集」的经典技巧，值得记住，但本题用不上。
> - **BMI2 一行解**：`return x | _pdep_u64(n - 1, ~x);`（需 `#include <immintrin.h>`，x86-64 目标）。`_pdep` 语义就是 spread。
> - **反方向**：`_pext_u64(v & 超集判定, ~x)` 可把任一超集「读回」压缩值——求「$\le v$ 的超集个数」时直接可用，正是二分计数版需要的核心函数。

## 8. 边界情况与易错点

1. **32 位溢出（最致命）**：$n = x = 10^8$ 时答案约 $5.2 \times 10^{13}$，`int` 必爆。C++ 返回类型与中间变量都要 `long long`；`(k & 1) << j` 中 `j` 可达 52+，`k` 若用 `int` 移位尚可但赋值回 `ans` 时务必是 64 位运算。
2. **off-by-one**：填 `n` 还是 `n-1`？序列从 $i=0$（$x$ 本身）开始，第 $n$ 个是 $i = n-1$。填 `n` 会让答案跳到「下一个超集」，样例 1 直接输出 7 而非 6。
3. **扫描时 `k` 的移位时机**：只在 `ans` 的 0 位（插槽）上右移 `k`，1 位（锁定位）只跳过。在锁定位也消耗 `k` 是最常见的实现 bug，插槽与位错位后小样例可能都过不了。
4. **`n = 1`**：`k = 0`，循环体一次不进，直接返回 `x`——「只有一个元素时它自己就是 AND 结果」。
5. **`x` 低位全 1**（如 $x = 7$）：插槽全部在高位，`j` 要一路扫过锁定位才能找到第一个插槽，循环轮数是「1 位个数 + `k` 的位数」之和而非后者。
6. **`x = 10^8` 的奇偶位交错**：锁定位与插槽交替，扫描逻辑无需特判，靠「见 1 跳过、见 0 填入」自然处理。
7. **不要枚举数组**：任何「逐个生成元素」的写法都是 $O(n \log)$ 级别起步，$10^8$ 规模下只有「直接定位第 $n$ 个超集」一条活路。
8. **验证思维**：写完可用「小规模暴力枚举超集序列的第 $n$ 个」对拍（$x < 64$、$n$ 小时直接列），本解法在 $x \in [0,64)$、全量 $n$ 下与暴力零偏差。
