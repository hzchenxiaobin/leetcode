# LeetCode 找出与数组相加的整数 I 题解

## 1. 题目概述

- **标题 / 题号**：找出与数组相加的整数 I（#3131，easy）
- **链接**：https://leetcode.cn/problems/find-the-integer-added-to-array-i/
- **来源**：LeetCode 第 395 场周赛 Q1
- **难度**：简单
- **标签**：数组、数学

**题意**：给定两个长度相等的数组 `nums1` 和 `nums2`。已知存在一个整数 `x`，把 `nums1` 的**每个元素**都加上 `x` 后，`nums1` 与 `nums2` 相等（即两数组作为多重集完全相同，元素及出现频次一致）。返回这个 `x`。`x` 可能为负数（表现为元素值减少）。

**约束**：

- `1 <= nums1.length == nums2.length <= 100`
- `0 <= nums1[i], nums2[i] <= 1000`
- 测试用例保证存在这样的整数 `x`（无需验证，直接求出即可）

## 2. 示例

**示例 1**

```text
输入：nums1 = [2,6,4], nums2 = [9,7,5]
输出：3
解释：[2,6,4] 每个元素加 3 得 [5,9,7]，与 nums2 = [9,7,5] 仅顺序不同，多重集相等。
```

**示例 2**

```text
输入：nums1 = [10], nums2 = [5]
输出：-5
解释：10 + (-5) = 5。x 可以为负数。
```

**示例 3**

```text
输入：nums1 = [1,1,1,1], nums2 = [1,1,1,1]
输出：0
解释：两数组本来就已相等，x = 0。
```

## 3. 解题思路

### 3.1 暴力思路

签到题。两条朴素路线：

1. **枚举 + 计数验证**：由数据范围知 `x ∈ [-1000, 1000]`，枚举每个候选 `x`，用哈希计数检查 `nums1` 整体加 `x` 后是否与 `nums2` 相等。时间 `O(C·n)`（`C = 2001`），太绕，完全没必要。
2. **排序 + 逐位做差**：多重集相等 ⇒ 排序后逐位相等 ⇒ 排序后任意一位的差就是 `x`。时间 `O(n log n)`，赛场上很稳，但排序其实也是多余的。

![易错点：不排序就逐位相减是错的](images/added_int_i_position_pitfall.svg)

> ⚠️ **注意**：千万不能在**原顺序**上直接逐位相减。示例 1 中 `9−2=7, 7−6=1, 5−4=1`，差值根本不是定值——数组顺序信息是无意义的噪声，`min`/`max`/`sum` 这些与顺序无关的统计量才能免疫打乱。

### 3.2 核心观察：均匀平移 ⇒ min 对应 min

![统一加 x 相当于数轴整体平移，min 对应 min](images/added_int_i_shift_concept.svg)

给**所有**元素加上同一个 `x`，等价于把整个数组在数轴上**平移** `x` 个单位：元素之间的相对次序、间距全部保持不变。因此：

- 最小值映射到最小值：$\min(\text{nums1}) + x = \min(\text{nums2})$
- 最大值映射到最大值：$\max(\text{nums1}) + x = \max(\text{nums2})$

于是答案直接由两个最小值唯一确定：

$$x = \min(\text{nums2}) - \min(\text{nums1})$$

连排序都不需要——题目又保证了 `x` 的存在性，所以这一条信息就足够了。

### 3.3 算法流程

1. 一趟扫描（或直接调用库函数）求出 `min1 = min(nums1)`、`min2 = min(nums2)`。
2. 返回 `min2 - min1`。

### 3.4 示例演算

![示例演算：排序对齐与三种等价公式](images/added_int_i_example_walkthrough.svg)

以示例 1 为例，`nums1 = [2,6,4]`，`nums2 = [9,7,5]`：

| 方法 | 计算 | 结果 |
|------|------|------|
| min | $5 - 2$ | $3$ |
| max | $9 - 6$ | $3$ |
| sum | $(21 - 12) / 3$ | $3$ |
| 排序逐位 | $[2,4,6] \to [5,7,9]$，每位差 $3$ | $3$ |

四种口径殊途同归，比赛时选最短的那个：`min(nums2) - min(nums1)`。

## 4. 算法细节

1. **求最小值**：C++ 用 `*min_element(begin, end)`，Python 用内置 `min()`；也可一次循环同时维护两个数组的 `min`，把两次扫描合并成一次。
2. **做差方向**：务必是 $\min(\text{nums2}) - \min(\text{nums1})$（加完之后等于谁，就谁在前），写反会得到 `−x`。
3. **等价写法**：`max` 版、`sum` 版（$\left(\sum \text{nums2} - \sum \text{nums1}\right) / n$）同样正确；`sum` 版注意结果是整数（题目保证存在 `x`，所以必然整除）。
4. **无需频次验证**：`x` 的存在性由题面保证，公式给出唯一解，因此不需要排序比对、也不需要哈希计数。

## 5. 正确性证明

**引理 1（平移保最小值）**：对任意非空整数多重集 $A$ 与整数 $x$，有 $\min(A + x) = \min(A) + x$，其中 $A + x = \{a + x \mid a \in A\}$。

**证明**：设 $a^* = \min(A)$。对任意 $a \in A$ 有 $a \ge a^*$，从而 $a + x \ge a^* + x$；又 $a^* + x \in A + x$ 且取到该下界，故 $\min(A + x) = a^* + x$。∎

**定理**：若存在整数 $x$ 使 `nums1` 每个元素加 `x` 后所得多重集与 `nums2` 相等，则 $x = \min(\text{nums2}) - \min(\text{nums1})$，且该值唯一。

**证明**：由题设，多重集 $\text{nums1} + x = \text{nums2}$。由引理 1，

$$\min(\text{nums2}) = \min(\text{nums1} + x) = \min(\text{nums1}) + x,$$

移项即得 $x = \min(\text{nums2}) - \min(\text{nums1})$。由于两数组的最小值唯一确定，`x` 被唯一确定，算法返回值即为所求。∎

**推论**：$\max$ 版本同理成立（平移同样保持最大值），$\text{sum}$ 版本由 $\sum (\text{nums1}_i + x) = \sum \text{nums1}_i + n \cdot x$ 两边对照 `nums2` 的和即得。

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。求两个数组的最小值各一趟线性扫描（`n ≤ 100`，常数极小）；若合并为一趟循环，扫描次数还能减半。
- **空间复杂度**：$O(1)$。只用了两个标量 `min1`、`min2`，不排序、不开哈希表。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int addedInteger(vector<int>& nums1, vector<int>& nums2) {
        return *min_element(nums2.begin(), nums2.end())
             - *min_element(nums1.begin(), nums1.end());
    }
};
```

一趟扫描合并版（避免扫两遍）：

```cpp
class Solution {
public:
    int addedInteger(vector<int>& nums1, vector<int>& nums2) {
        int min1 = nums1[0], min2 = nums2[0];
        for (int i = 1; i < (int)nums1.size(); i++) {
            min1 = min(min1, nums1[i]);
            min2 = min(min2, nums2[i]);
        }
        return min2 - min1;
    }
};
```

### Python

```python
class Solution:
    def addedInteger(self, nums1: List[int], nums2: List[int]) -> int:
        return min(nums2) - min(nums1)
```

## 8. 边界情况与易错点

1. **单元素数组**：`n = 1` 时公式退化为 `nums2[0] - nums1[0]`，示例 2 得 `-5`，无需特判。
2. **x 为负数**：`min(nums2) < min(nums1)` 时差为负，C++/Python 整数都自然支持，不需要任何特判。
3. **x = 0（数组本来就相等）**：示例 3 的 `[1,1,1,1]`，min 相减得 0。
4. **重复元素**：多重集频次不影响 `min`，重复元素照常工作；**不要**转成 `set` 去重再比较——集合会丢失频次信息，一般情形会出错。
5. **未排序陷阱**：数组顺序被打乱（示例 1 即是），按原下标逐位相减得到 `7,1,1` 不是定值；必须排序，或干脆用与顺序无关的 `min`/`max`/`sum`。
6. **做差方向写反**：正确方向是 `min(nums2) - min(nums1)`；写反后正负号恰好翻转，示例 1 会错误输出 `-3`。
7. **数值范围**：元素 `≤ 1000`，`x ∈ [-1000, 1000]`，`int` 完全无溢出风险。
