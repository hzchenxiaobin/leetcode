# LeetCode 最早完成陆地和水上游乐设施的时间 II 题解

## 1. 题目概述

- **标题 / 题号**：最早完成陆地和水上游乐设施的时间 II（#3635，medium）
- **链接**：https://leetcode.cn/problems/earliest-finish-time-for-land-and-water-rides-ii/
- **来源**：LeetCode 第 162 场双周赛 Q3
- **难度**：中等
- **标签**：数组、枚举、贪心

**题意**：与同场 Q1 完全相同，只是数据规模从 $n, m \le 100$ 放大到 $n, m \le 5 \times 10^4$。游客必须从陆地和水上各玩恰好一项（顺序任意），每项可在开放时刻或之后开始，玩完可立刻开始下一项或等待。返回完成两项的最早时刻。

**约束**：

- $1 \le n, m \le 5 \times 10^4$
- $1 \le \text{landStartTime}[i], \text{landDuration}[i], \text{waterStartTime}[j], \text{waterDuration}[j] \le 10^5$

$O(nm)$ 的枚举会到 $2.5 \times 10^9$，必须优化到 $O(n + m)$。

## 2. 示例

**示例 1**

```text
输入：landStartTime = [2,8], landDuration = [4,1], waterStartTime = [6], waterDuration = [3]
输出：9
解释：陆地 0（2→6）+ 水上游乐 0（6→9）；其余方案分别得 10、12、13。
```

**示例 2**

```text
输入：landStartTime = [5], landDuration = [3], waterStartTime = [1], waterDuration = [10]
输出：14
解释：水上游乐 0（1→11）+ 陆地 0（11→14）；反序为 18。
```

**示例 3（自造，检查「先玩类」的极值被正确利用）**

```text
输入：landStartTime = [100,1], landDuration = [1,100], waterStartTime = [50], waterDuration = [1]
输出：101
解释：先玩水上游乐（50→51），再玩陆地 0：它 100 才开放，故 100 开始、101 结束，
      即 max(51,100)+1 = 101。
      对照其他方案：陆地0→水 = max(101,50)+1 = 102；陆地1→水 = max(101,50)+1 = 102；
      水→陆地1 = max(51,1)+100 = 151。最小值为 101。
```

## 3. 解题思路

### 3.1 暴力思路

枚举 $n \times m$ 个配对、每个配对两种顺序，$O(nm)$。$n = m = 5\times10^4$ 时 $2.5\times10^9$ 次运算，C++ 也要数秒以上，Python 完全不可能。

### 3.2 核心观察：先玩的那一类只需知道「最早结束时刻」

![关键观察：先玩的那一类，只关心「最早能玩完的时刻」](images/bw162_q3_min_finish.svg)

设陆地 $i$ 的结束时刻 $f_i = \text{landStartTime}[i] + \text{landDuration}[i]$，水上游乐 $j$ 的结束时刻 $g_j = \text{waterStartTime}[j] + \text{waterDuration}[j]$。

固定第二项 $j$，若先玩陆地，最终时刻是

$$T(i, j) = \max(f_i,\ s^w_j) + d^w_j$$

其中 $s^w_j, d^w_j$ 是水上游乐 $j$ 的开放时刻与时长。函数 $\max(\cdot, s^w_j) + d^w_j$ 关于 $f_i$ **单调不减**，所以让 $f_i$ 尽可能小就是最优：

$$T_{\text{land}\to\text{water}} = \min_j \Big[\max\big(\min_i f_i,\ s^w_j\big) + d^w_j\Big]$$

也就是说，所有陆地设施可以**压缩成一个数** $F = \min_i f_i$！同理反向：

$$T_{\text{water}\to\text{land}} = \min_i \Big[\max\big(\min_j g_j,\ s^l_i\big) + d^l_i\Big]$$

答案是两者取小。这样每个方向只需扫一遍另一类，总体 $O(n + m)$。

![两个方向各扫一遍，答案取最小（示例 1 演算）](images/bw162_q3_two_directions.svg)

### 3.3 算法流程

```text
1. F = min over i of (landStartTime[i] + landDuration[i])
2. G = min over j of (waterStartTime[j] + waterDuration[j])
3. best = +∞
4. for j in 0..m-1:                    # 先陆地，后水上游乐 j
       best = min(best, max(F, waterStartTime[j]) + waterDuration[j])
5. for i in 0..n-1:                    # 先水上游乐，后陆地 i
       best = min(best, max(G, landStartTime[i]) + landDuration[i])
6. 返回 best
```

### 3.4 示例演算

示例 1：陆地 $f = [6, 9]$，故 $F = 6$；水上游乐 $g = [9]$，故 $G = 9$。

- 先陆地：$j = 0$，$\max(6, 6) + 3 = 9$。
- 先水上游乐：$i = 0$，$\max(9, 2) + 4 = 13$；$i = 1$，$\max(9, 8) + 1 = 10$。

答案 $\min(9, 13, 10) = 9$。✓

示例 2：$F = 8$，$G = 11$。

- 先陆地：$\max(8, 1) + 10 = 18$。
- 先水上游乐：$\max(11, 5) + 3 = 14$。

答案 $14$。✓ 这正是「先水后陆地」更优的例子。

## 4. 算法细节

1. **只用两个极值**：$F$ 与 $G$ 各扫一遍即可得到，不需要保存排序或其他结构。
2. **`max` 的位置**：第二项的开始时刻是 $\max(\text{第一项的结束}, \text{第二项的开放})$；把 `max` 漏掉会低估（示例 2 会算成 $1 + 10 + 3 = 14$ 恰好也对，但示例 1 会错成 $2+4+3 = 9$ 碰巧也对——数值巧合，逻辑上是错的，构造反例即可暴露）。
3. **两种顺序都要算**：删掉任一方向都会 WA（示例 2 的答案就在「先水后陆地」）。
4. **类型**：最大时刻 $\le 10^5 + 10^5 + 10^5 = 3\times10^5$，`int` 足够，但中间量用 `long long` 更稳。
5. **同一项不会被用两次**：两个方向各取「一类的一项 + 另一类的一项」，天然跨类，不存在重复。
6. **初值**：`LLONG_MAX` / `inf`。

## 5. 正确性证明

**引理 1（单调性）**：对固定的水上游乐 $j$，函数 $\varphi_j(t) = \max(t, s^w_j) + d^w_j$ 关于 $t$ 单调不减。

**证明**：$\max(t, s)$ 关于 $t$ 单调不减，加常数 $d$ 后仍单调不减。∎

**引理 2（压缩为极值）**：$\min_i \varphi_j(f_i) = \varphi_j\big(\min_i f_i\big)$。

**证明**：由引理 1，$\varphi_j$ 单调不减，故其在 $\{f_i\}$ 上的最小值在最小元素处取到。∎

**引理 3（方案全覆盖）**：任一合法方案必属于「先陆地后水上游乐」或「先水上游乐后陆地」之一，且其结束时刻形如引理 2 中的 $\varphi_j(f_i)$ 或对称形式。

**证明**：游客各玩一项，共有两种相对顺序；顺序确定后，第一项的最早结束时刻由引理 1（Q1 题解的引理 1）给出为 $f_i$ 或 $g_j$，第二项同理。∎

**定理**：算法返回值为所有合法方案的最早完成时刻。

**证明**：由引理 3，全体方案的结束时刻集合为 $\{\varphi_j(f_i)\} \cup \{\psi_i(g_j)\}$（$\psi$ 为对称形式）。由引理 2，第一族的最小值等于 $\min_j \varphi_j(F)$，正是第 4 步循环的结果；第二族的最小值等于 $\min_i \psi_i(G)$，正是第 5 步。两族最小值的较小者即全局最小，也就是算法返回的 `best`。∎

## 6. 复杂度分析

- **时间**：求 $F$、$G$ 各 $O(n)$、$O(m)$；两次扫描 $O(m)$、$O(n)$。合计 $O(n + m)$，$n, m \le 5\times10^4$ 时约 $10^5$ 次运算。
- **空间**：$O(1)$，只用两个极值与一个答案变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int earliestFinishTime(std::vector<int>& landStartTime, std::vector<int>& landDuration,
                           std::vector<int>& waterStartTime, std::vector<int>& waterDuration) {
        long long minLandFinish = std::numeric_limits<long long>::max();
        for (size_t i = 0; i < landStartTime.size(); i++) {
            minLandFinish = std::min(minLandFinish, (long long)landStartTime[i] + landDuration[i]);
        }
        long long minWaterFinish = std::numeric_limits<long long>::max();
        for (size_t j = 0; j < waterStartTime.size(); j++) {
            minWaterFinish = std::min(minWaterFinish, (long long)waterStartTime[j] + waterDuration[j]);
        }
        long long best = std::numeric_limits<long long>::max();
        for (size_t j = 0; j < waterStartTime.size(); j++) {
            best = std::min(best, std::max(minLandFinish, (long long)waterStartTime[j]) + waterDuration[j]);
        }
        for (size_t i = 0; i < landStartTime.size(); i++) {
            best = std::min(best, std::max(minWaterFinish, (long long)landStartTime[i]) + landDuration[i]);
        }
        return (int)best;
    }
};
```

### Python

```python
class Solution:
    def earliestFinishTime(self, landStartTime: list[int], landDuration: list[int],
                           waterStartTime: list[int], waterDuration: list[int]) -> int:
        min_land_finish = min(s + d for s, d in zip(landStartTime, landDuration))
        min_water_finish = min(s + d for s, d in zip(waterStartTime, waterDuration))
        best = min(max(min_land_finish, ws) + wd for ws, wd in zip(waterStartTime, waterDuration))
        best = min(best, min(max(min_water_finish, ls) + ld for ls, ld in zip(landStartTime, landDuration)))
        return best
```

## 8. 边界情况与易错点

1. **只算一个方向**：示例 2 的答案来自「先水后陆地」，漏掉即 WA。
2. **漏掉 `max`**：第二项的开始时刻必须取 $\max(\text{前项结束}, \text{本项开放})$。
3. **误以为要排序**：本题不需要排序，只需要两个最小值；排序反而是多余的 $O(n\log n)$。
4. **误以为「最小结束」与「最小开放」是同一项**：$F$ 与开放时刻无关，只与 `start + duration` 有关。
5. **溢出**：三段时间相加最大 $3\times10^5$，`int` 安全，但用 `long long` 统一处理更省心。
6. **$n = m = 1$**：退化为两种顺序取小，代码自然处理。
7. **重复游玩同一项**：两个方向都是「跨类取一项」，不会重复。

**延伸思考**：如果要求「每类至少玩一项、总共玩 $q$ 项」，就要对两类分别排序后做「贪心 + 堆」的调度模拟，复杂度 $O((n+m)\log(n+m))$。如果加上「园内移动时间」（玩完一项到下一项需要固定通勤时间 $c$），只需把 $\max(f, s)$ 改成 $\max(f + c, s)$，单调性与极值压缩的结论完全不变。

**变体**：若两个类别的项目可重复游玩（同一项能玩多次），则「最小结束时刻」依然是 $F$，答案形式不变，只是需要额外考虑「同一项玩两次」不被允许的约束。
