# LeetCode 使数组平衡的最少移除数目 题解

## 1. 题目概述

- **标题 / 题号**：使数组平衡的最少移除数目（#3634，medium）
- **链接**：https://leetcode.cn/problems/minimum-removals-to-balance-array/
- **来源**：LeetCode 第 162 场双周赛 Q2
- **难度**：中等
- **标签**：数组、排序、滑动窗口、二分查找

**题意**：数组**平衡**指最大值**至多**是最小值的 $k$ 倍。可以移除任意多个元素（但不能全部移完，剩余数组非空），求使剩余数组平衡所需移除的**最少**元素数。长度为 $1$ 的数组视为平衡。

**约束**：

- $1 \le \text{nums.length} \le 10^5$
- $1 \le \text{nums}[i] \le 10^9$
- $1 \le k \le 10^5$

注意乘积 $\text{nums}[l] \cdot k$ 可达 $10^{14}$，C++ 中必须用 `long long` 比较。

## 2. 示例

**示例 1**

```text
输入：nums = [2,1,5], k = 2
输出：1
解释：移除 5，剩 [2,1]：max 2 ≤ min 1 × 2 = 2，平衡。移除数 1。
```

**示例 2**

```text
输入：nums = [1,6,2,9], k = 3
输出：2
解释：移除 1 和 9，剩 [6,2]：6 ≤ 2 × 3 = 6，平衡。
```

**示例 3**

```text
输入：nums = [4,6], k = 2
输出：0
解释：6 ≤ 4 × 2，已平衡。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有非空子集（$2^n$ 个），对每个子集判断 $\max \le \min \cdot k$，取最大合法子集大小，答案为 $n - \text{maxSize}$。$n = 10^5$ 时完全不可行。

### 3.2 核心观察：最优解保留的是一段排序后的连续区间

![排序后：平衡子数组就是最大值不超过最小值 k 倍的连续区间](images/bw162_q2_sorted_window.svg)

**关键引理**：把 `nums` 升序排序后，最优方案保留的元素一定是**连续的一段**区间 $[l, r]$。

理由：假设最优方案保留了 $x$ 与 $z$（$x \le z$），而某个满足 $x \le y \le z$ 的 $y$ 被删掉了。那么把 $y$ 加回来：最小值不会变大（还是 $x$）、最大值不会变大（还是 $z$），所以 $\max \le \min \cdot k$ 依然成立，剩余元素更多，与「最优」矛盾。因此平衡性只取决于被保留集合的**最小值和最大值**，把中间的全留下不会破坏平衡。

于是在排序后的数组上，问题变成：找最长区间 $[l, r]$ 使得

$$a[r] \le a[l] \cdot k$$

答案 $= n - (\text{最长区间长度})$。由于 $a$ 单调不减、$a[l] \cdot k$ 随 $l$ 单调不减，可以用**双指针**：右端点 $r$ 逐个右移，左端点 $l$ 只在区间失效时右移，均摊 $O(n)$。

### 3.3 算法流程

```text
1. 升序排序 nums
2. l = 0，best = 0
3. for r in 0..n-1:
       while nums[r] > nums[l] * k:   l += 1
       best = max(best, r - l + 1)
4. 返回 n - best
```

注意 `while` 结束时必有 $l \le r$：因为 $a[r] \le a[r] \cdot k$（$k \ge 1$），所以最迟在 $l = r$ 时条件成立，不会越界。

### 3.4 示例演算

![三个示例的判定：少的是「窗口外」的元素](images/bw162_q2_example_walkthrough.svg)

**示例 2**：`nums = [1,6,2,9], k = 3`，排序得 `[1,2,6,9]`。

| $r$ | $a[r]$ | $l$ 调整 | 窗口 | 长度 |
|---|---|---|---|---|
| 0 | 1 | 无需调整 | [1] | 1 |
| 1 | 2 | $2 \le 1\cdot3$ ✓ | [1,2] | 2 |
| 2 | 6 | $6 > 1\cdot3$ → $l=1$；$6 \le 2\cdot3$ ✓ | [2,6] | 2 |
| 3 | 9 | $9 > 2\cdot3$ → $l=2$；$9 > 6\cdot3$ 不成立（$9 \le 18$）✓ | [6,9] | 2 |

最长窗口长度 $2$，答案 $4 - 2 = 2$。✓

**示例 1**：`[2,1,5]` 排序为 `[1,2,5]`，$k=2$：窗口 `[1,2]` 长度 2（$2 \le 2$）；加入 5 时 $5 > 1\cdot 2$ 且 $5 > 2 \cdot 2$，所以最长仍是 2，答案 $3-2=1$。✓

**示例 3**：`[4,6]`，$k=2$：$6 \le 4\cdot2 = 8$ ✓，整个数组平衡，答案 $0$。✓

## 4. 算法细节

1. **必须排序**：不排序就无法用「连续区间」刻画最优解，也就无法双指针。
2. **乘法溢出**：`nums[l] * k` 在 C++ 中若用 `int` 会溢出（$10^9 \times 10^5 = 10^{14}$），必须转 `long long`。
3. **`while` 而非 `if`**：$l$ 可能需要连续右移多次才能让条件成立（例如 `[1,1,1,100]`，$k=2$）。
4. **`l` 单调**：因为 $a[l] \cdot k$ 随 $l$ 不减，区间失效后 $l$ 不会回退，这就是双指针成立的依据。
5. **答案形式**：输出 `n - best`（删除的个数），不是 `best`。
6. **空数组禁止**：$k \ge 1$ 保证单元素窗口永远合法，所以 $best \ge 1$，剩余数组必然非空，不需要额外特判。
7. **$k = 1$**：条件退化为 $a[r] \le a[l]$，配合有序性只能是 $a[r] = a[l]$，即答案保留同一数值的最长频次段，这与题意一致。

## 5. 正确性证明

**引理 1（连续化）**：若存在一个平衡的保留集合 $S$，则存在一个大小不小于 $|S|$ 的平衡保留集合，其元素在排序后的数组里占据连续的一段。

**证明**：设 $S$ 的最小值为 $a[l]$、最大值为 $a[r]$（排序后下标）。把 $S$ 替换为区间 $[l, r]$ 的全部元素：最小值仍为 $a[l]$、最大值仍为 $a[r]$，故 $\max \le \min\cdot k$ 仍成立；又 $S \subseteq [l,r]$，故新集合大小不小于 $|S|$。∎

**引理 2（双指针正确）**：算法结束时 `best` 等于所有满足 $a[r] \le a[l]\cdot k$ 的区间 $[l,r]$ 的最大长度。

**证明**：对每个 $r$，算法把 $l$ 推到**最小的**使 $a[r] \le a[l]\cdot k$ 成立的下标（记为 $l^*(r)$），此时 $[l^*(r), r]$ 是以 $r$ 为右端点的最长合法区间，长度 $r - l^*(r) + 1$ 被计入 `best`。任何以 $r$ 为右端点的合法区间 $[l', r]$ 都满足 $l' \ge l^*(r)$（由 $l^*$ 的最小性），长度不超过它。故对每个 $r$ 都取到了最优，`best` 为全局最大长度。又 $l$ 单调不减（$a[l]\cdot k$ 单调），两个指针各自最多走 $n$ 步，算法正确终止。∎

**定理**：算法返回值为使剩余数组平衡所需移除的最少元素数。

**证明**：由引理 1，最优保留方案可取自某个连续区间；由引理 2，`best` 是最长平衡区间长度。移除数 $= n - |\text{保留}|$，故最少移除数 $= n - \text{best}$。∎

## 6. 复杂度分析

- **时间**：排序 $O(n\log n)$；双指针中 $r$ 走 $n$ 步、$l$ 最多走 $n$ 步，$O(n)$。合计 $O(n\log n)$。
- **空间**：$O(1)$ 额外空间（忽略排序自身开销；C++ 的 `std::sort` 为原地排序，Python 的 `sort` 为 $O(n)$ 辅助）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minRemoval(std::vector<int>& nums, int k) {
        std::sort(nums.begin(), nums.end());
        int n = (int)nums.size();
        int best = 0, l = 0;
        for (int r = 0; r < n; r++) {
            while ((long long)nums[r] > (long long)nums[l] * k) l++;
            best = std::max(best, r - l + 1);
        }
        return n - best;
    }
};
```

### Python

```python
class Solution:
    def minRemoval(self, nums: list[int], k: int) -> int:
        nums.sort()
        n = len(nums)
        best = 0
        l = 0
        for r in range(n):
            while nums[r] > nums[l] * k:
                l += 1
            best = max(best, r - l + 1)
        return n - best
```

## 8. 边界情况与易错点

1. **乘法溢出**：`nums[l] * k` 最大 $10^{14}$，C++ 用 `long long`（Python 无此问题）。
2. **忘记排序**：不排序时「连续区间」不成立，双指针结果错误。
3. **`while` 写成 `if`**：$l$ 需要连续右移，只移一次会留下非法区间。
4. **返回 `best`**：题目要的是**移除数** $n - \text{best}$。
5. **$k = 1$**：只有全等元素才能共存，答案 $n - $（最大频次）。
6. **$n = 1$**：单元素数组恒平衡，答案 $0$；此时 `best = 1`，`n - best = 0` ✓。
7. **全相同元素**：窗口始终是整个数组，答案 $0$。
8. **超大值与小 $k$**：如 `[1, 10^9]`、$k=1$，最长窗口长度 $1$，答案 $1$。
9. **$l$ 越界**：$k \ge 1$ 保证 $a[r] \le a[r]\cdot k$，`while` 必然在 $l = r$ 前停下。

**延伸思考**：把条件换成「max − min ≤ d」同样可以双指针（排序后 $a[r] - a[l] \le d$）。如果要求「移除后数组的极差不超过 $k$ 倍最小值且长度至少为 $m$」，只需在双指针里额外判断窗口长度。若 $k$ 不是常数而是每次查询给出，且查询很多，可以预处理排序后用二分把每次查询做到 $O(\log n)$ 定位（对每个 $r$ 二分最小的 $l$）。

**变体**：若要求「剩余数组必须是原数组的一个**子数组**（连续）」，就不能排序，问题变成在原序上找最长区间满足 $\max \le \min\cdot k$，需要用单调栈/线段树维护区间极值，复杂度变为 $O(n\log n)$ 且思路完全不同。
