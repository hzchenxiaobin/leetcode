# LeetCode 最早完成陆地和水上游乐设施的时间 I 题解

## 1. 题目概述

- **标题 / 题号**：最早完成陆地和水上游乐设施的时间 I（#3633，easy）
- **链接**：https://leetcode.cn/problems/earliest-finish-time-for-land-and-water-rides-i/
- **来源**：LeetCode 第 162 场双周赛 Q1
- **难度**：简单
- **标签**：数组、枚举

**题意**：有两类游乐设施——陆地 $n$ 项、水上游乐 $m$ 项，第 $i$ 项陆地设施最早开放时间 `landStartTime[i]`、时长 `landDuration[i]`；水上游乐同理。游客必须从**每一类中各玩恰好一项**，顺序任意；每项可以在开放时刻或之后任意时刻开始，开始后持续 `duration`，结束于 `开始 + duration`。玩完一项可以立刻（若已开放）开始下一项，否则等待。返回玩完这两项的**最早可能时刻**。

**约束**：

- $1 \le n, m \le 100$
- $1 \le \text{landStartTime}[i], \text{landDuration}[i], \text{waterStartTime}[j], \text{waterDuration}[j] \le 1000$

规模很小，枚举全部组合即可。

## 2. 示例

**示例 1**

```text
输入：landStartTime = [2,8], landDuration = [4,1], waterStartTime = [6], waterDuration = [3]
输出：9
解释：陆地 0 先玩：2 开始、6 结束；水上游乐已开放，6 开始、9 结束。这是最早方案。
      其余方案：水→陆地1 得 10，陆地1→水得 12，水→陆地0 得 13。
```

**示例 2**

```text
输入：landStartTime = [5], landDuration = [3], waterStartTime = [1], waterDuration = [10]
输出：14
解释：先玩水上游乐：1 开始、11 结束；陆地 5 就开放了，11 开始、14 结束。
      反过来先陆地：5 → 8，再水：8 → 18。最早 14。
```

**示例 3（自造，检查「等待」）**

```text
输入：landStartTime = [1], landDuration = [1], waterStartTime = [100], waterDuration = [1]
输出：101
解释：陆地 1 开始、2 结束；水上游乐要等到 100 才开，100 开始、101 结束。
```

## 3. 解题思路

### 3.1 暴力思路

总方案数：选一项陆地（$n$ 种）× 选一项水上游乐（$m$ 种）× 顺序（$2$ 种），共 $2nm \le 2\times10^4$。每个方案只需 $O(1)$ 计算结束时刻，因此**直接枚举**就是最优解，不需要任何优化。

### 3.2 核心观察：单项结束时刻与另一类无关

![只有两种顺序，逐对枚举即可（示例 1）](images/bw162_q1_two_orders.svg)

设陆地 $i$ 从 `landStartTime[i]` 开始，则它固定在 $f_i = \text{landStartTime}[i] + \text{landDuration}[i]$ 结束——与之后玩什么无关。同理水上游乐 $j$ 固定在 $g_j = \text{waterStartTime}[j] + \text{waterDuration}[j]$ 结束。

于是「陆地 $i$ → 水上游乐 $j$」的结束时刻只依赖三个数：

$$\text{finish} = \max(f_i,\ \text{waterStartTime}[j]) + \text{waterDuration}[j]$$

- 若 $f_i \le \text{waterStartTime}[j]$，则水上游乐刚好在开放时开始，结束于 $g_j$；
- 若 $f_i > \text{waterStartTime}[j]$，则立刻开始，结束于 $f_i + \text{waterDuration}[j]$。

注意**不能**把两项时长与两个开放时间简单相加：中间那个 `max` 正是「等待」的体现。

![暴力：n × m 对组合 × 2 种顺序，取最小结束时间](images/bw162_q1_enumerate_pairs.svg)

### 3.3 算法流程

```text
best = +∞
for i in 0..n-1:
    f = landStartTime[i] + landDuration[i]
    for j in 0..m-1:
        # 顺序一：陆地 i → 水上游乐 j
        best = min(best, max(f, waterStartTime[j]) + waterDuration[j])
        # 顺序二：水上游乐 j → 陆地 i
        g = waterStartTime[j] + waterDuration[j]
        best = min(best, max(g, landStartTime[i]) + landDuration[i])
返回 best
```

### 3.4 示例演算

示例 1 的四个方案：

| 方案 | 第一项（开始 → 结束） | 第二项（开始 → 结束） | 最终时刻 |
|---|---|---|---|
| 陆地0 → 水0 | 2 → 6 | 6 → 9（正好开放） | **9** |
| 水0 → 陆地1 | 6 → 9 | 9 → 10（已开放） | 10 |
| 陆地1 → 水0 | 8 → 9 | 9 → 12 | 12 |
| 水0 → 陆地0 | 6 → 9 | 9 → 13（陆地 2 就开放，但只能等） | 13 |

最小值为 $9$。

## 4. 算法细节

1. **先算 $f_i$、$g_j$**：在内层循环外计算 $f_i$ 可以少一次加法；$g_j$ 依赖 $j$，放在内层即可（$n, m$ 很小，优化非必需）。
2. **用 `max` 而不是「相加」**：第二项的开始时刻是 $\max(\text{前一项结束}, \text{本项开放})$，漏掉 `max` 是最常见的错误。
3. **两种顺序都要枚举**：只算「陆地→水」会漏掉「水→陆地」更优的情况（示例 2 正是如此）。
4. **类型选择**：时间最大 $1000 + 1000 + 1000 = 3000$，`int` 足够；但养成用 `long long` 存中间量的习惯没有坏处。
5. **初值**：用 `LLONG_MAX`（或 Python 的 `inf`），因为所有方案都至少产生一个有限值，不会保持初值。
6. **同一项不能重复玩**：题目要求「每一类各恰好一项」，所以 (i, j) 一定来自不同类别，天然满足，不需要额外去重。

## 5. 正确性证明

**引理 1（单项时序）**：若某设施开放时间为 $s$、时长为 $d$，且只能在时刻 $t \ge 0$ 之后才能开始玩它，则最早开始时刻为 $\max(t, s)$，最早结束时刻为 $\max(t, s) + d$。

**证明**：开始时刻必须满足「不早于开放」与「不早于到达」两个约束，即 $\ge \max(t, s)$；而 $\max(t, s)$ 同时满足两者，故最早开始时刻就是它。结束时刻 = 开始 + 时长，取最早开始即得最早结束。∎

**引理 2（固定配对下的最优结束时刻）**：对固定的一对（陆地 $i$、水上游乐 $j$），两种顺序的最早结束时刻分别为

$$T_1 = \max(f_i, s^w_j) + d^w_j, \qquad T_2 = \max(g_j, s^l_i) + d^l_i$$

其中 $f_i = s^l_i + d^l_i$，$g_j = s^w_j + d^w_j$。

**证明**：顺序一先玩陆地 $i$：它是最早能玩的设施，由引理 1 最早结束于 $f_i$（此时 $t = 0$，$\max(0, s^l_i) = s^l_i$）。之后玩水上游乐 $j$，到达时刻为 $f_i$，再由引理 1 得 $T_1$。顺序二对称。∎

**定理**：算法返回值为所有合法方案中最早的完成时刻。

**证明**：合法方案 = 「选一对 (i,j)」×「选一种顺序」，共 $2nm$ 种，循环对每种方案都计算了其最早结束时刻（引理 2），并在 `best` 中取最小。因此 `best` 就是全体合法方案最早结束时刻的最小值，即题目所求。∎

## 6. 复杂度分析

- **时间**：$O(nm)$，双重循环，每轮 $O(1)$；$n, m \le 100$ 时最多 $10^4$ 轮。
- **空间**：$O(1)$，只用了若干标量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int earliestFinishTime(std::vector<int>& landStartTime, std::vector<int>& landDuration,
                           std::vector<int>& waterStartTime, std::vector<int>& waterDuration) {
        long long best = std::numeric_limits<long long>::max();
        int n = (int)landStartTime.size(), m = (int)waterStartTime.size();
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < m; j++) {
                // 陆地 i 先，水上游乐 j 后
                long long f1 = (long long)landStartTime[i] + landDuration[i];
                long long s1 = std::max(f1, (long long)waterStartTime[j]);
                best = std::min(best, s1 + waterDuration[j]);
                // 水上游乐 j 先，陆地 i 后
                long long f2 = (long long)waterStartTime[j] + waterDuration[j];
                long long s2 = std::max(f2, (long long)landStartTime[i]);
                best = std::min(best, s2 + landDuration[i]);
            }
        }
        return (int)best;
    }
};
```

### Python

```python
class Solution:
    def earliestFinishTime(self, landStartTime: list[int], landDuration: list[int],
                           waterStartTime: list[int], waterDuration: list[int]) -> int:
        best = float('inf')
        for i in range(len(landStartTime)):
            finish_land = landStartTime[i] + landDuration[i]
            for j in range(len(waterStartTime)):
                # 陆地 i -> 水上游乐 j
                best = min(best, max(finish_land, waterStartTime[j]) + waterDuration[j])
                # 水上游乐 j -> 陆地 i
                finish_water = waterStartTime[j] + waterDuration[j]
                best = min(best, max(finish_water, landStartTime[i]) + landDuration[i])
        return best
```

## 8. 边界情况与易错点

1. **漏掉 `max`**：把结束时刻写成 `f + duration` 会忽略等待，示例 3 会错算成 3 而不是 101。
2. **只算一个方向**：示例 2 的答案来自「先水后陆地」，只算「先陆地」会得到 18。
3. **把「开放时刻」当成「结束时刻」**：`landStartTime` 只是最早可开始时间，不是结束时间。
4. **两个开放时间相加**：有读者会写 `landStart + landDur + waterStart + waterDur`，这在两项都无需等待时才成立，一般不行。
5. **重复使用同一项**：题目要求每类恰好一项，代码用两层循环各取一项，天然不会重复。
6. **初值**：用 `inf`/`LLONG_MAX`，不要用 `0`（时间都是正数，但语义上要取最小）。
7. **$n = m = 1$**：只有一种配对、两种顺序，代码自然处理。
