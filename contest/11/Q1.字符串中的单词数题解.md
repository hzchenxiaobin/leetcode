# LeetCode 字符串中的单词数 题解

## 1. 题目概述

- **标题 / 题号**：字符串中的单词数（#434，easy）
- **链接**：https://leetcode.cn/problems/number-of-segments-in-a-string/
- **来源**：LeetCode 第 11 场周赛 Q1
- **难度**：简单
- **标签**：字符串

**题意**：给定字符串 $s$，一个 **segment（单词）** 定义为一段**连续的非空格字符**。返回单词的个数。

注意两个反直觉之处：单词不需要「有意义」，`"Hello,"` 整体算一个单词（标点不切分）；分隔符只有空格，**连续空格、前导空格、尾随空格都可能存在**。

**约束**：

- $0 \le \lvert s \rvert \le 300$
- `s` 仅由大小写英文字母、数字，以及 `!@#$%^&*()_+-=',.:` 中的字符组成
- `s` 中唯一的空白字符是 `' '`（不会出现 `\t`、`\n`）

## 2. 示例

**示例 1**

```text
输入：s = "Hello, my name is John"
输出：5
解释：五个单词为 ["Hello,", "my", "name", "is", "John"]；
     "Hello," 末尾的逗号不影响它整体是一个单词。
```

**示例 2**

```text
输入：s = "Hello"
输出：1
解释：整串就是一个连续非空格段。
```

**示例 3（补充，覆盖边界）**

```text
输入：s = "   "       输出：0     解释：全空格，没有单词
输入：s = "  a  b "   输出：2     解释：前导/尾随/连续空格都只是分隔符
输入：s = ""          输出：0     解释：空串，一次循环都不执行
```

## 3. 解题思路

### 3.1 暴力思路

最直白的写法是「按空格切开、滤掉空片段、数剩下的」：Python 写 `len(s.split())`，C++ 写 `stringstream` 循环 `>>`。时间 $O(n)$，但要**额外 $O(n)$ 空间**存放每一段的拷贝，也掩盖了本题真正想考的点——「如何在不分词的情况下数出段数」。

另一个更常见的错误「暴力」是数空格：把答案当成「空格个数 $+1$」。它在 `"Hello, my name is John"` 上恰好得到 5，但只要出现多余空格就崩：

- `"  a"` 给出 3（正确是 1）；
- `"a  b"` 给出 3（正确是 2）；
- `"   "` 给出 4（正确是 0）。

这是本题最主要的失分点，也是 $O(1)$ 空间做法的动机。

### 3.2 核心观察：数「单词的左边界」

![单词左边界：每个单词恰好一个起点](images/wc11_q1_segment_boundary.svg)

一个单词就是一段**极大**的连续非空格字符，所以它有唯一的**左端点** $l$，且 $l$ 满足

$$s[l] \ne \texttt{' '} \quad\land\quad \bigl(l = 0 \ \lor\ s[l-1] = \texttt{' '}\bigr)$$

反过来，每个满足该条件的位置都恰好是一个单词的左端点。于是

$$\text{单词数} = \#\{\, i \;\big|\; s[i] \ne \texttt{' '} \ \land\ (i = 0 \lor s[i-1] = \texttt{' '}) \,\}$$

判据只依赖 $s[i]$ 与 $s[i-1]$ **两个相邻位置**，因此一次遍历、$O(1)$ 额外空间就够；而且连续空格、前导/尾随空格**自动正确**——夹在连续两个空格之间的空片段长度是 0，里面没有任何非空格字符，自然不会产生计数。

### 3.3 算法流程：两状态扫描

![两状态扫描：只在进入单词时计数](images/wc11_q1_state_machine.svg)

用布尔量 `inWord` 表示「上一个字符是否属于某个单词」（初值 `false`，对应「还在串首」）：

1. 读到**非空格**：若 `inWord == false`，说明当前字符是新单词的第一个字符，`cnt++`；随后置 `inWord = true`。
2. 读到**空格**：置 `inWord = false`，`cnt` 不变（分隔符不贡献计数）。
3. 扫描结束，返回 `cnt`。

`inWord` 正是「$s[i-1]$ 非空格」的压缩表示，初值 `false` 又等价于 $i = 0$，所以状态机与 3.2 的下标判据**逐位等价**。

### 3.4 示例演算

![示例演算表](images/wc11_q1_walkthrough.svg)

对 `s = "Hello, my name is John"`，只列发生计数或状态切换的关键位置：

| i | s[i] | 左邻 s[i−1] | 左边界？ | cnt |
|---|------|-------------|----------|-----|
| 0 | `'H'` | —（串首） | 是 | 1 |
| 6 | 空格 | `','` | 否 | 1 |
| 7 | `'m'` | 空格 | 是 | 2 |
| 9 | 空格 | `'y'` | 否 | 2 |
| 10 | `'n'` | 空格 | 是 | 3 |
| 15 | `'i'` | 空格 | 是 | 4 |
| 18 | `'J'` | 空格 | 是 | 5 |
| 21 | `'n'` | `'h'` | 否 | 5 |

最终 `cnt = 5`。注意下标 5 的逗号与它前面的 `o` 属于同一个单词：切分只发生在空格处，标点不切。

## 4. 算法细节

1. **下标 0 必须短路**：写成 `s[i] != ' ' && (i == 0 || s[i-1] == ' ')` 时 `||` 的短路保证不会访问 `s[-1]`；若把两个条件顺序颠倒（先取 `s[i-1]`）就会越界。
2. **Python 的负下标陷阱**：Python 里 `s[i-1]` 在 `i == 0` 时取到的是**最后一个字符**而不是报错，所以判据必须写成 `i == 0 or s[i-1] == ' '`，短路同样不可省。
3. **只判断 `' '`，不要用 `isspace`**：按定义分隔符就是空格这一个字符；用 `isspace(ch)` 会把制表符也当分隔符，虽然本题数据里不会出现，但用库函数替代题意是思路层面的错。
4. **状态机与下标判据二选一**：状态机一次扫描、无需回看；下标判据不需要额外变量。二者等价，但别混写在同一行（例如 `s[i] != ' ' && !inWord || ch == ' '` 这种优先级错误）。
5. **空串与全空格无需特判**：空串循环体不执行、全空格只走「空格分支」，`cnt` 都保持 0。
6. **C++ 备选写法**：`stringstream ss(s); string w; while (ss >> w) ++cnt;` 同样能过，但它依赖流的分词语义（`\t`、`\n` 也算分隔符），且会拷贝每个单词，适合当作对照答案。
7. **Python 一行版**：`sum(ch != ' ' and (i == 0 or s[i-1] == ' ') for i, ch in enumerate(s))`，`bool` 在 `sum` 中自动当 0/1；正确但可读性不如显式状态机。
8. **返回类型**：$n \le 300$，答案不超过 300，`int` / Python `int` 都足够，不需要 64 位。

## 5. 正确性证明

**引理 1（每个单词的左端点满足判据，且互不相同）**：设 $s \ne \varepsilon$，取 $s$ 中任一单词 $w = s[l..r]$（即一段极大非空格字符），则 $P(l)$ 成立，且不同单词的左端点不同。

**证明**：$w$ 是极大非空格段，故段内字符全非空格，特别地 $s[l] \ne \texttt{' '}$。若 $l > 0$，则 $s[l-1]$ 必为空格：否则 $s[l-1]$ 非空格且与 $w$ 相邻相接，$w$ 就不是极大的，矛盾。故 $l = 0 \lor s[l-1] = \texttt{' '}$，即 $P(l)$ 成立。又两个不同的单词是两个不同的极大段，若左端点相同则它们的起点相同，而极大段由起点唯一确定（向右一直延伸到第一个空格），于是两段相同，与"不同"矛盾。∎

**引理 2（满足判据的位置必是某个单词的左端点）**：若 $P(i)$ 成立，则 $i$ 是某个单词的左端点。

**证明**：由 $s[i] \ne \texttt{' '}$，$i$ 落在某个极大非空格段 $s[l..r]$ 内，故 $l \le i$。反设 $l < i$，则由极大段的定义（段内每对相邻字符都非空格）有 $s[i-1] \ne \texttt{' '}$；又 $l \le i-1$ 且 $l \ge 0$ 说明 $i-1 \ge 0$，即可以取到 $s[i-1]$。这与 $P(i)$ 中的条件「$i = 0$ 或 $s[i-1] = \texttt{' '}$」矛盾（$i > l \ge 0$ 故 $i \ne 0$）。所以 $l = i$，$i$ 是该段左端点。∎

**定理**：算法返回的值恰为 $s$ 的单词数。

**证明**：由引理 1 与引理 2，判据 $P$ 的成立位置与 $s$ 的单词之间构成**双射**，故单词数 $= \lvert\{i : P(i)\}\rvert$。

算法中 `inWord` 始终等于「$s[i-1]$ 非空格」这一命题的真值（初值 `false` 对应 $i = 0$ 时该命题无意义、按判据视为"是左边界"）：读到非空格且 `inWord` 为假时，恰好等价于 $s[i] \ne \texttt{' '} \land (i = 0 \lor s[i-1] = \texttt{' '})$，即 $P(i)$ 成立，此时 `cnt` 增一；其余情形（空格字符，或非空格但 `inWord` 为真）都不满足 $P(i)$，`cnt` 不变。因此 `cnt` 每次增一与每个 $P(i)$ 一一对应，扫描结束后 `cnt = \lvert\{i : P(i)\}\rvert$，即单词数。$s = \varepsilon$ 时不存在任何 $i$，`cnt = 0`，与"空串没有单词"一致。∎

## 6. 复杂度分析

- **时间**：$O(n)$，其中 $n = \lvert s \rvert$。每个字符仅被读一次，每次的判断是常数次比较与赋值；没有嵌套循环，也没有子串比较或切片。
- **空间**：$O(1)$。状态机写法只用 `cnt` 与 `inWord` 两个变量，不依赖输入规模（不计入只读的输入串本身）。
- **对比**：`split()` / `stringstream` 解法时间同为 $O(n)$，但空间 $O(n)$（保存每段拷贝），且每段的分配与拷贝带来较大常数；若输入规模升到 $10^7$，$O(1)$ 空间版本的优势会非常明显。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int countSegments(string s) {
        int cnt = 0;
        bool inWord = false;              // 上一个字符是否属于某个单词
        for (char ch : s) {
            if (ch != ' ') {
                if (!inWord) {            // 由「空格 / 串首」进入单词：这就是左边界
                    ++cnt;
                    inWord = true;
                }
            } else {
                inWord = false;           // 空格只是分隔符，不计数
            }
        }
        return cnt;
    }
};
```

### Python

```python
class Solution:
    def countSegments(self, s: str) -> int:
        cnt = 0
        in_word = False                   # 上一个字符是否属于某个单词
        for ch in s:
            if ch != ' ':
                if not in_word:           # 单词的第一个字符：计数 +1
                    cnt += 1
                    in_word = True
            else:
                in_word = False           # 分隔符：只切换状态
        return cnt
```

## 8. 边界情况与易错点

1. **空串**：`""` → 0。循环体不执行，`cnt` 初值 0；不要写成"先算 1 再减"之类需要特判的形式。
2. **全空格**：`"   "` → 0，而「空格数 $+1$」会给出 4。这类用例是判题的必测点。
3. **前导空格**：`"  a"` → 1。下标 0、1 是空格（`cnt` 不变），下标 2 才是左边界。
4. **尾随空格**：`"a  "` → 1。不要"扫完再 +1"，也不要在循环外补一次计数——单词数等于左边界数，串尾不额外算一个。
5. **连续空格**：`"a  b"` → 2。中间的空片段长度为 0，不构成单词。
6. **标点自身成词**：`", @"` → 2。逗号、`@` 都是非空格字符，按定义就是单词的一部分；不要用 `isalpha` 过滤。
7. **`split(' ')` 与 `split()` 不同**：`"   ".split()` 得 `[]`（正确），`"   ".split(' ')` 得 4 个空串（错）。若用 `split(' ')` 必须再滤空串。
8. **Python 负下标**：省略 `i == 0` 的短路后，`s[-1]` 会取到尾字符；在 `"a"` 上会得到 0，而正确答案是 1。
9. **别用 `isspace`**：它把 `\t`、`\n` 也算分隔符，与本题「只有空格是分隔符」的定义不符。

**延伸思考**：

- 若分隔符集合扩大（空格、`\t`、`\n` 都算），把判据里的 `ch != ' '` 换成 `!isSep(ch)`，结构与证明一字不改。
