# LeetCode 凸多边形 题解

## 1. 题目概述

- **标题 / 题号**：凸多边形（#469，medium）
- **链接**：https://leetcode.cn/problems/convex-polygon/
- **来源**：LeetCode 第 11 场周赛 Q2
- **难度**：中等
- **标签**：几何，数组，数学，多边形

**题意**：给定按顺序首尾相连的 $n$ 个顶点 `points`（其中 `points[i] = [xi, yi]`），它们围成一个**简单多边形**（边只在公共顶点处相接，其余位置互不相交）。判断这个多边形是否为**凸多边形**：等价于沿边界走一整圈时，每个顶点的**拐弯方向始终一致**（全左转或全右转），即所有内角都不超过 $180^\circ$。

**约束**：

- $3 \le n \le 10^4$
- `points[i].length == 2`，$-10^4 \le x_i, y_i \le 10^4$
- 顶点按**顺时针或逆时针**顺序给出，不保证具体绕向
- 输入保证是简单多边形，无需自己判自交

> 💡 顶点顺序可能顺时针也可能逆时针，所以算法**不能预设**叉积的基准符号。

## 2. 示例

**示例 1**

```text
输入：points = [[0,0],[0,5],[5,5],[5,0]]
输出：true
解释：四个顶点构成正方形，四个角都是 90° 的右转，拐弯方向完全一致 → 凸。
```

**示例 2**

```text
输入：points = [[0,0],[0,10],[10,10],[10,0],[5,5]]
输出：false
解释：(5,5) 是正方形内部的一点，多边形在 (5,5) 处向内凹进，
      该顶点的拐弯方向与其余顶点相反 → 凹。
```

**示例 3（补充：边上带共线点）**

```text
输入：points = [[0,0],[0,5],[5,5],[5,0],[2,0]]
输出：true
解释：(2,0) 落在线段 (5,0)–(0,0) 上，是 180° 的“平角”，
      它不改变拐弯方向；其余顶点的右转方向一致 → 仍是凸多边形。
```

## 3. 解题思路

### 3.1 暴力思路

几条看起来可行、其实行不通的路线：

1. **内角和**：凸多边形内角和为 $(n-2)\pi$，但凹多边形内角和同样是 $(n-2)\pi$，这个公式**根本无法区分**凸凹。
2. **逐顶点算内角**：用点积与模长反算 $\cos\theta$ 再 `acos`。浮点误差会让「接近 $180^\circ$」和「恰好共线」的用例随机翻车，而且每次都要开方，慢且不稳。
3. **按定义检查**：枚举每一对顶点，判断连线段是否完整落在多边形内部，复杂度 $O(n^3)$ 以上；或对每条边检查其余所有顶点是否在同一侧，$O(n^2)$，$n=10^4$ 时一亿次比较，属于「能过但不该这么写」。

本质上，凸性只关心**拐弯的符号**，不关心角度大小，所以正确做法是把几何问题降维成**整数符号比较**。

### 3.2 核心观察：相邻边叉积同号

![凸多边形与凹多边形的叉积符号对比](images/wc11_q2_cross_sign_concept.svg)

对每个顶点取相邻的两条有向边，设

$$
\vec u_i = p_{i+1} - p_i,\qquad \vec v_i = p_{i+2} - p_{i+1}
$$

（下标对 $n$ 取模），定义

$$
c_i = \vec u_i \times \vec v_i = u_x v_y - u_y v_x
= \lvert \vec u_i \rvert \lvert \vec v_i \rvert \sin\theta_i
$$

其中 $\theta_i$ 是**从 $\vec u_i$ 转到 $\vec v_i$ 的有向转角**。于是 $c_i$ 的符号就是顶点 $p_{i+1}$ 处的**转向**：

| $c_i$ 符号 | 几何含义 | 内角 |
|---|---|---|
| $> 0$ | 左转（逆时针拐） | 绕向为逆时针时 $<180^\circ$ |
| $< 0$ | 右转（顺时针拐） | 绕向为顺时针时 $<180^\circ$ |
| $= 0$ | 三点共线，不拐弯 | 恰好 $180^\circ$ |

**关键结论**：简单多边形为凸 $\iff$ 所有非零的 $c_i$ **同号**。凹点必然是一个「反向拐弯」，于是正负号同时出现；反过来，如果全程同号，说明没有任何一个内角超过 $180^\circ$，多边形就是凸的。

> ⚠️ $c_i = 0$ 的三点共线**必须跳过**：它是合法的 $180^\circ$ 平角，既不算左转也不算右转。

### 3.3 算法流程

![算法流程：一次扫描维护已见符号](images/wc11_q2_algorithm_flow.svg)

1. `sign = 0`，表示「还没有见过非零叉积」。
2. 对 $i = 0,1,\dots,n-1$，取 $j=(i+1)\bmod n$、$k=(i+2)\bmod n$，计算 $c = (p_j-p_i)\times(p_k-p_j)$。
3. 若 $c = 0$，跳过本组（共线不改方向）。
4. 否则令 $s = \operatorname{sign}(c)$；若 `sign != 0` 且 `sign != s`，说明出现了反向拐弯，立即返回 `false`。
5. 否则令 `sign = s`，继续下一组。
6. 扫描完 $n$ 组都没有冲突 → 返回 `true`。

注意第 2 步要取到 $i = n-1$，此时三元组是 $(p_{n-1}, p_0, p_1)$，闭合处的拐弯不能漏。

### 3.4 示例演算

![示例 2 的逐组叉积演算](images/wc11_q2_walkthrough.svg)

以示例 2 为例，顶点依次为 $A(0,0), B(0,10), C(10,10), D(10,0), E(5,5)$：

| $i$ | 三元组 | 两条边向量 | $c_i$ | 处理 |
|---|---|---|---|---|
| 0 | $A\to B\to C$ | $(0,10),(10,0)$ | $-100$ | 记录 `sign = −1` |
| 1 | $B\to C\to D$ | $(10,0),(0,-10)$ | $-100$ | 同号，通过 |
| 2 | $C\to D\to E$ | $(0,-10),(-5,5)$ | $-50$ | 同号，通过 |
| 3 | $D\to E\to A$ | $(-5,5),(-5,-5)$ | $+50$ | **异号 ⇒ 返回 false** |
| 4 | $E\to A\to B$ | $(-5,-5),(0,10)$ | $-50$ | 已提前返回，不再执行 |

第 3 组正是凹点 $E(5,5)$：前面 $B,C,D$ 三个转角一路右转（负），唯独这里左转（正），符号由负变正，冲突立即暴露。对照示例 1，正方形四组叉积为 $-25,-25,-25,-25$，全程同号，返回 `true`；示例 3 多出的共线点只会产生一个 $0$，被跳过，结论不变。

## 4. 算法细节

1. **下标取模闭环**：用 `(i+1)%n`、`(i+2)%n` 统一处理，不要在循环里特判 $i=n-2$、$i=n-1$，否则很容易漏掉闭合处的两组三元组。
2. **边向量写法**：`u = p[j] - p[i]`、`v = p[k] - p[j]`，即**首尾相接**的两条边。等价写法 `(p[j]-p[i]) × (p[k]-p[i])` 符号完全相同，因为 $p_k-p_i=(p_j-p_i)+(p_k-p_j)$，由叉积的双线性性展开得 $(p_j-p_i)\times(p_k-p_i)=u\times(u+v)=u\times u+u\times v=u\times v$；但首尾相接的写法几何含义更直观。
3. **基准符号不能预设**：`sign` 初值为 $0$，用第一个非零叉积确定符号。如果把初值写成 $+1$，所有顺时针输入都会被误判为凹。
4. **零的处理方式很关键**：要显式写 `if (c == 0) continue;`。若为了省事把符号归一化成 `s = c > 0 ? 1 : -1`，那么 $c=0$ 会被归成 $-1$，一个共线点就能把凸多边形判成凹。
5. **整数类型**：坐标差绝对值 $\le 2\times10^4$，乘积 $\le 4\times10^8$，两项相减 $\le 8\times10^8$，恰好卡在 32 位 int 内；但一旦题目放宽坐标范围就会溢出，C++ 里统一用 `long long` 没有额外成本。
6. **提前返回**：冲突一旦出现就没有继续扫描的必要；最坏情况（凸多边形）仍要跑满 $n$ 组，复杂度不变。

## 5. 正确性证明

**引理 1（叉积符号刻画转向）**：设 $\vec u,\vec v$ 为相邻两条边向量，$\theta\in(-\pi,\pi)$ 为 $\vec u$ 到 $\vec v$ 的有向转角，则 $\operatorname{sign}(\vec u\times\vec v)=\operatorname{sign}(\sin\theta)=\operatorname{sign}(\theta)$。

**证明**：二维叉积满足 $\vec u\times\vec v=\lvert\vec u\rvert\lvert\vec v\rvert\sin\theta$，模长非负，故符号由 $\sin\theta$ 决定；而 $\theta\in(-\pi,\pi)$ 时 $\sin\theta$ 与 $\theta$ 同号（$\theta=0$ 时同时为 $0$）。∎

**引理 2（凸 ⇒ 无非零异号）**：若多边形为凸，则所有非零 $c_i$ 同号。

**证明**：凸多边形的每个内角 $\alpha_i \le \pi$。固定绕向（不妨设逆时针），有 $\theta_i = \pi - \alpha_i \ge 0$，即每个顶点要么直行（$\theta_i=0$，$c_i=0$）要么左转（$\theta_i>0$，$c_i>0$），故非零叉积全为正；顺时针绕向同理全为负。∎

**引理 3（异号 ⇒ 非凸）**：若同时存在 $c_i>0$ 与 $c_j<0$，则多边形不是凸的。

**证明**：由引理 1，$\theta_i>0$、$\theta_j<0$，即在某处左转、另一处右转。绕行一周的总转角 $\sum_k \theta_k = \pm 2\pi$（简单多边形的旋转数定理），其符号就是整体绕向。若多边形为凸，则所有内角 $\le\pi$，所有 $\theta_k$ 与整体绕向同号或为 $0$，不可能出现反号；矛盾，故非凸。∎

**定理**：算法返回 `true` 当且仅当给定多边形是凸多边形。

**证明**：

- （$\Leftarrow$）凸多边形由引理 2 所有非零 $c_i$ 同号，扫描过程中不可能触发第 4 步的冲突，最终返回 `true`。
- （$\Rightarrow$）若返回 `true`，说明所有非零 $c_i$ 同号；又简单多边形面积非零，至少存在一个非零叉积，故符号 $s\in\{+1,-1\}$ 确定。若 $s=+1$：所有非零 $\theta_i>0$，故 $\sum_k\theta_k>0$，而简单多边形的总转角只能取 $\pm 2\pi$，于是 $\sum_k\theta_k=2\pi$、整体绕向为逆时针，且每个 $\theta_i\ge 0$，得 $\alpha_i=\pi-\theta_i\le\pi$。若 $s=-1$：对称地有 $\sum_k\theta_k=-2\pi$、整体绕向为顺时针、$\theta_i\le 0$，得 $\alpha_i=\pi+\theta_i\le\pi$。两种情形下所有内角都不超过 $180^\circ$，多边形为凸。∎

## 6. 复杂度分析

- **时间**：$O(n)$。单趟扫描 $n$ 组相邻三元组，每组只做两次减法、两次乘法、一次减法与常数次比较；出现冲突时提前返回只会更快。
- **空间**：$O(1)$。只维护一个符号变量 `sign` 与若干临时整数，没有数组、没有排序、没有递归；输入按引用传入，不产生拷贝。

## 7. 参考代码

### C++

```cpp
#include <vector>
using namespace std;

class Solution {
  public:
    bool isConvex(vector<vector<int>>& points) {
        int n = points.size();
        int sign = 0;                       // 0 表示还没遇到非零叉积
        for (int i = 0; i < n; i++) {
            int j = (i + 1) % n, k = (i + 2) % n;
            long long x1 = points[j][0] - points[i][0];
            long long y1 = points[j][1] - points[i][1];
            long long x2 = points[k][0] - points[j][0];
            long long y2 = points[k][1] - points[j][1];
            long long cross = x1 * y2 - y1 * x2;
            if (cross == 0) continue;       // 共线：内角 180°，不改变转向
            int s = cross > 0 ? 1 : -1;
            if (sign != 0 && sign != s) return false;   // 出现反向拐弯
            sign = s;
        }
        return true;
    }
};
```

### Python

```python
from typing import List


class Solution:
    def isConvex(self, points: List[List[int]]) -> bool:
        n = len(points)
        sign = 0                       # 0 表示还没遇到非零叉积
        for i in range(n):
            j, k = (i + 1) % n, (i + 2) % n
            x1 = points[j][0] - points[i][0]
            y1 = points[j][1] - points[i][1]
            x2 = points[k][0] - points[j][0]
            y2 = points[k][1] - points[j][1]
            cross = x1 * y2 - y1 * x2
            if cross == 0:             # 共线：内角 180°，不改变转向
                continue
            s = 1 if cross > 0 else -1
            if sign != 0 and sign != s:
                return False           # 出现反向拐弯
            sign = s
        return True
```

## 8. 边界情况与易错点

1. **共线点被误当成转向**：把符号归一化成 `s = cross > 0 ? 1 : -1` 是本题最常见的 WA 来源——$cross=0$ 会被归成 $-1$，于是「矩形底边插一个中点」这种合法凸多边形在逆时针输入下会立刻被判成凹。必须先判 $0$ 再归一化。
2. **漏掉闭合处的三元组**：只扫到 $i = n-3$ 会漏掉 $(p_{n-2},p_{n-1},p_0)$ 与 $(p_{n-1},p_0,p_1)$，若凹点恰好落在首尾衔接处就会误判。统一对 $n$ 取模最省心。
3. **预设了符号方向**：题目不保证顺时针还是逆时针，`sign` 必须由第一个非零叉积决定，不能初值为 $+1$ 或 $-1$。
4. **整数溢出**：本题坐标差 $\le 2\times10^4$，叉积 $\le 8\times10^8$，`int` 勉强够；但用 `int` 存中间乘积再相减的习惯一旦遇到更大坐标就会溢出，直接用 `long long`。
5. **$n = 3$ 的三角形**：只要三点不共线就必然凸，三组叉积同号，扫描顺利通过；若三点共线则违反「简单多边形」保证，不在输入范围内。
6. **全共线退化输入**：若所有叉积都是 $0$（点全部共线），算法返回 `true`。这种输入无法构成面积为正的多边形，题面已排除；若要更防御，可在末尾加 `return sign != 0;`。
7. **严格凸 vs 弱凸**：本题按「内角 $\le 180^\circ$」的宽松定义处理共线点（与站内主流通过解一致）。若题目要求严格凸（不允许 $180^\circ$），则应把 `cross == 0` 直接视为失败。
