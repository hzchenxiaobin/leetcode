# LeetCode 环绕字符串中唯一的子字符串 题解

## 1. 题目概述

- **标题 / 题号**：环绕字符串中唯一的子字符串（#467，medium）
- **链接**：https://leetcode.cn/problems/unique-substrings-in-wraparound-string/
- **来源**：LeetCode 第 11 场周赛 Q3
- **难度**：中等
- **标签**：字符串、动态规划

**题意**：`base` 是 `"abcdefghijklmnopqrstuvwxyz"` 首尾相接、向两端无限延伸得到的串，形如 `"...zabcdefghijklmnopqrstuvwxyzabc..."`。给定字符串 `s`，统计 `s` 有多少个**互不相同**的非空子串同时也是 `base` 的子串。等价说法：统计 `s` 中所有"内部每一对相邻字符都满足循环后继"的不同子串。

**约束**：

- $1 \le \lvert s \rvert \le 10^5$
- `s` 仅由小写英文字母组成

## 2. 示例

**示例 1**

```text
输入：s = "a"
输出：1
解释：只有 "a" 一个子串，它当然出现在 base 中。
```

**示例 2**

```text
输入：s = "cac"
输出：2
解释：c→a 的差值是 24、a→c 的差值是 2，都不是后继关系；
      "ca"、"ac"、"cac" 全部非法，只剩单字符 "c" 与 "a"。
```

**示例 3**

```text
输入：s = "zab"
输出：6
解释：六个子串 z、a、b、za、ab、zab 都出现在 base 中（z 的后继是 a，可以绕回）。
```

## 3. 解题思路

### 3.1 暴力思路

枚举全部 $O(n^2)$ 个区间，对每个区间逐对检查相邻字符是否满足循环后继（$O(n)$），再把合法的子串塞进哈希集合去重，总复杂度 $O(n^3)$，并且集合里最多存 $O(n^2)$ 个字符串（总长 $O(n^3)$）。当 $n = 10^5$ 时，光是枚举区间就已经 $5 \times 10^9$ 个，完全不可行。

瓶颈有两处：**判定**太贵、**去重**太贵。下面两个观察分别干掉它们。

### 3.2 核心观察：合法子串由"末字符 + 长度"唯一确定

![base 环绕串与合法相邻判定](images/wc11_q3_wrap_base_concept.svg)

**观察一（判定只需看相邻对）**：`base` 中每个字符的后继唯一（`a→b→…→y→z→a`），所以

$$t \text{ 是 base 的子串} \iff \forall j \ge 1,\;(t[j]-t[j-1]+26) \bmod 26 = 1$$

一次 $O(1)$ 的相邻比较就能否决整段，判定从 $O(\lvert t \rvert)$ 的"逐个位置试"变成一次扫描。

**观察二（合法串没有选择余地）**：既然前驱也唯一，那么给定**末字符 $c$** 和**长度 $L$**，合法的串只能是 $c$ 往左回推 $L-1$ 步得到的那一个。也就是说，`base` 的所有子串可以按 $(c, L)$ 一一索引：同一个 $(c, L)$ 只对应一个字符串，不存在"末字符相同、长度相同但内容不同"的情况。

> 💡 **这就是去重的全部**：不同合法串 $\iff$ 末字符不同或长度不同。于是"数不同子串"退化成：对每个字符 $c$，看以 $c$ 结尾的合法后缀**最长能有多长**——一个字符只需要记一个长度。

### 3.3 状态定义与算法流程

![按末字符分组：dp[c] 就是该组的子串个数](images/wc11_q3_ending_char_dp.svg)

定义

$$\mathrm{dp}[c] = \max\{\,L : s \text{ 中存在以字符 } c \text{ 结尾、长度为 } L \text{ 的合法子串}\,\}$$

由观察二，以 $c$ 结尾的不同合法子串只能是长度 $1,2,\dots$ 的各一个；又因为合法串的后缀必然合法（引理 1），长度不超过 $\mathrm{dp}[c]$ 的那些全都真实存在，所以这一组恰好有 $\mathrm{dp}[c]$ 个，答案为

$$\text{ans} = \sum_{c=\text{'a'}}^{\text{'z'}} \mathrm{dp}[c]$$

**如何求 $\mathrm{dp}$**：设 $\mathrm{run}(i)$ 为"以 $i$ 结尾的最长合法后缀"的长度，则它满足

$$\mathrm{run}(i) = \begin{cases} \mathrm{run}(i-1)+1, & i>0 \text{ 且 } s[i] \text{ 是 } s[i-1] \text{ 的循环后继} \\ 1, & \text{否则} \end{cases}$$

扫描时令 $\mathrm{dp}[s[i]] = \max(\mathrm{dp}[s[i]], \mathrm{run}(i))$：同一个字符可能出现多次，只有最长的那个后缀能带来新的长度，所以取 max。

![一次扫描的算法流程](images/wc11_q3_algorithm_flow.svg)

**为什么"取最大值"就够**：以 $s[i]$ 结尾的合法后缀长度是 $1,2,\dots,\mathrm{run}(i)$ 这一段连续区间，它们全都真实存在，所以一次 $\mathrm{run}(i)=k$ 的更新等价于把 $\mathrm{dp}[c]$ 抬到 $\ge k$；多次出现只需保留历史最大。

### 3.4 示例演算

![zab 与 cac 的逐位演算](images/wc11_q3_walkthrough.svg)

| $i$ | `s[i]` | 相邻差值（mod 26） | run | dp 更新 |
|-----|--------|--------------------|-----|---------|
| 0 | `z` | —（起点） | 1 | $\mathrm{dp}[z]=1$ |
| 1 | `a` | $(-25) \bmod 26 = 1$ ✓ | 2 | $\mathrm{dp}[a]=2$ |
| 2 | `b` | $1$ ✓ | 3 | $\mathrm{dp}[b]=3$ |

$s = \texttt{"zab"}$ 全程未断链，答案 $1+2+3=6$，对应 `z, a, b, za, ab, zab`。

再看 $s = \texttt{"cac"}$：$i=1$ 处 $c\to a$ 差 24 断链，$i=2$ 处 $a\to c$ 差 2 再次断链，所以 $\mathrm{run}$ 一直是 1，$\mathrm{dp}[a]=\mathrm{dp}[c]=1$，答案 $2$。

## 4. 算法细节

1. **`run` 的重置值是 1 而不是 0**：单字符永远合法，断链后当前位置自身仍算长度 1。
2. **循环后继判断要补模**：C++ 里写 `(s[i] - s[i-1] + 26) % 26 == 1`，`s[i] < s[i-1]` 时负数取模会得到负值；Python 的 `%` 天然返回非负，直接用 `(ord(ch) - ord(prev)) % 26 == 1` 即可。
3. **`dp` 用长度 26 的数组**：下标 `s[i] - 'a'`，不要用 `unordered_map`；26 个桶让空间严格 $O(1)$。
4. **只更新末字符对应的桶**：$s[i]$ 只可能改变 $\mathrm{dp}[s[i]]$，其他 25 个桶与本位无关。
5. **取 max 而不是累加**：$\mathrm{dp}$ 是"最长长度"，不是"出现次数"；同字符后面出现更短的 `run` 不能覆盖前面的更大值。
6. **答案上限**：$\sum \mathrm{dp}[c] \le 26 \times 10^5 = 2.6 \times 10^6$，`int` 足够，不必开 `long long`。
7. **全程不构造子串**：既不切片也不建集合，避免 $O(n^2)$ 的空间与 $O(n^2)$ 的哈希开销。
8. **等价写法（别混用）**：也可以从右往左维护"以 $i$ 开头的最长合法前缀"，令 $\mathrm{dp}[s[i]] = \max(\mathrm{dp}[s[i]], \mathrm{len})$——这统计的是"以 $c$ 开头"的那组，两个方向的总和相等（把 `s` 反转后两组互换），但**同一个实现里不要混着加**。

## 5. 正确性证明

**引理 1（局部判定）**：字符串 $t$ 是 `base` 的子串 $\iff \forall j \ge 1,\;(t[j]-t[j-1]+26) \bmod 26 = 1$。

**证明**：$(\Rightarrow)$ `base` 中任意相邻两字符都是循环后继关系，子串继承该性质。$(\Leftarrow)$ 设 $t[0]=c$，在 `base` 中取 $c$ 的任一出现位置 $p$（`base` 无限重复，必存在）；由 $t$ 满足逐位后继，从 $p$ 开始向右每位都等于 $t$ 的对应位，故从 $p$ 开始、长度为 $\lvert t\rvert$ 的片段逐位等于 $t$。∎

**引理 2（唯一性）**：末字符与长度都相同的两个合法串必然相等。

**证明**：合法串中每个字符的前驱唯一（`a` 的前驱是 `z`，其余为前一字母），故从末字符开始向左回推，每一位都被唯一确定，长度为 $L$ 时整个串唯一。∎

**引理 3（`run` 正确）**：扫描到 $i$ 时，$\mathrm{run}(i)$ 等于以 $i$ 结尾的最长合法后缀的长度。

**证明**：对 $i$ 归纳。若 $i=0$ 或 $s[i-1]\to s[i]$ 不是循环后继，则任何长度 $\ge 2$ 的以 $i$ 结尾的后缀都含相邻对 $(s[i-1],s[i])$，由引理 1 不合法，故最长长度为 $1$，与递推式一致。否则，任取以 $i-1$ 结尾、长度 $k \le \mathrm{run}(i-1)$ 的合法后缀，右接 $s[i]$ 后仍是合法后缀（新增的唯一相邻对就是 $(s[i-1],s[i])$，已验证合法），长度为 $k+1$；反过来任一以 $i$ 结尾、长度 $\ge 2$ 的合法后缀去掉末位就是以 $i-1$ 结尾的合法后缀，长度不超过 $\mathrm{run}(i-1)+1$。故 $\mathrm{run}(i)=\mathrm{run}(i-1)+1$。∎

**定理**：算法返回 $\sum_c \mathrm{dp}[c]$，它等于 `s` 的不同非空合法子串个数。

**证明**：所有合法子串按末字符分组，由引理 2 每组内"末字符相同、长度相同"的串唯一，故按 $(\text{末字符},\text{长度})$ 计数既不重也不漏。

固定字符 $c$：长度 $L$ 的合法子串以 $c$ 结尾且存在于 `s` 中 $\iff$ 存在下标 $i$ 使 $s[i]=c$ 且 $\mathrm{run}(i) \ge L$（充分性：把该合法后缀截断成它的长度 $L$ 后缀，由引理 1 仍然合法且末字符为 $c$；必要性：这个长度为 $L$ 的串本身就是以 $i$ 结尾的合法后缀）$\iff \mathrm{dp}[c] \ge L$。而算法对每个 $i$ 做了 $\mathrm{dp}[s[i]] = \max(\mathrm{dp}[s[i]], \mathrm{run}(i))$，由引理 3 扫描结束后 $\mathrm{dp}[c] = \max\{\mathrm{run}(i) : s[i]=c\}$，正是上述阈值。

于是第 $c$ 组的串数恰为 $\mathrm{dp}[c]$（长度取 $1..\mathrm{dp}[c]$ 各一个），求和即得全部不同合法子串数。∎

## 6. 复杂度分析

- **时间**：$O(n)$。单次从左到右扫描，每个位置做一次取模比较、一次 `max` 更新，都是 $O(1)$；结尾对 26 个桶求和为 $O(26) = O(1)$。
- **空间**：$O(26) = O(1)$。只有长度 26 的 `dp` 数组与常数个整数，与 $n$ 无关；没有切片、没有哈希集合。

## 7. 参考代码

### C++

```cpp
#include <string>
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int findSubstringInWraproundString(string s) {
        vector<int> dp(26, 0);          // dp[c]：以字符 c 结尾的合法子串最长长度
        int run = 0;                    // 以 s[i] 结尾的合法后缀长度
        for (int i = 0; i < (int)s.size(); ++i) {
            if (i > 0 && (s[i] - s[i - 1] + 26) % 26 == 1) ++run;
            else run = 1;               // 断链：单字符重新起步
            int c = s[i] - 'a';
            dp[c] = max(dp[c], run);
        }
        int ans = 0;
        for (int v : dp) ans += v;
        return ans;
    }
};
```

### Python

```python
class Solution:
    def findSubstringInWraproundString(self, s: str) -> int:
        dp = [0] * 26          # dp[c]：以字符 c 结尾的合法子串最长长度
        run = 0                # 以 s[i] 结尾的合法后缀长度
        for i, ch in enumerate(s):
            if i > 0 and (ord(ch) - ord(s[i - 1])) % 26 == 1:
                run += 1
            else:
                run = 1        # 断链：单字符重新起步
            k = ord(ch) - ord('a')
            if run > dp[k]:
                dp[k] = run
        return sum(dp)
```

## 8. 边界情况与易错点

1. **`z → a` 的绕回**：只用 `s[i] > s[i-1]` 判断会漏掉 `z→a`，必须用 `(s[i]-s[i-1]+26) % 26 == 1`。
2. **全同字符**：`"aaaa"` 的答案是 $1$ 而不是 $4$——$\mathrm{dp}[a]=1$，去重后只有一个串 `"a"`。
3. **长度没有 26 的上限**：`"z" + "a…z"` 重复两遍（长度 53）整段相邻差恒为 1，合法后缀长度 53，远超 26；长度上限是 $n$ 而不是 26，不能预先截断。
4. **不合法相邻的两种方向**：`"az"` 中 `a→z` 差 25，非法；`"cac"` 中 `c→a` 差 24 与 `a→c` 差 2 都非法。只要任一处断链，跨越它的所有更长子串全部作废，这正是 `run` 重置的含义。
5. **重置为 1**：写成 `run = 0` 会漏掉每个断链处的单字符子串，`"cac"` 会错答成 0。
6. **`dp` 取 max 而非赋值**：若写成 `dp[c] = run`，后面出现的更短 `run` 会覆盖掉历史最大值。单段递增的 `"zab"` 暴露不了这个问题，但 `"zaba"`（末位 `b→a` 断链把 `run` 打回 1）会：正确值 $1+2+3=6$，赋值写法得到 $5$。
7. **计算方向别混用**：按"末字符"和按"首字符"两种分组各自都能算对，但不能一边按末字符更新、一边按首字符求和。

**延伸思考**：若 `base` 换成任意字符串 $P$ 的无限重复（不再是 26 个字母的环），合法子串就不再由 $(\text{末字符},\text{长度})$ 唯一确定，$26$ 个桶也不够用了，此时要么用 $P$ 的 KMP 自动机配合"状态 + 长度"统计，要么用后缀自动机对 `s` 的所有不同子串做语言判定，复杂度会升到 $O(n\lvert P\rvert)$ 或 $O(n\log n)$ 量级。另一个变体是求每个合法子串在 `s` 中出现的**总次数**（不去重）：那就需要对每个末字符维护"长度频次的后缀和"，仍然是 $O(26n)$。这类"把去重压进 $(末字符,长度)$ 索引"的技巧，在环形、周期串问题上非常常用。
