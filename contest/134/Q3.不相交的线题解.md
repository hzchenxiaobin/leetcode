# LeetCode 不相交的线 题解

## 1. 题目概述

- **标题 / 题号**：不相交的线（#1035，medium）
- **链接**：https://leetcode.cn/problems/uncrossed-lines/
- **来源**：LeetCode 第 134 场周赛 Q3
- **难度**：中等
- **标签**：数组、动态规划、最长公共子序列

**题意**：把 `nums1`、`nums2` 分别按原顺序写在两条平行的水平线上。可以用直线连接 $nums1[i]$ 与 $nums2[j]$，每条线需满足：

1. $nums1[i] = nums2[j]$；
2. 任意两条连线**不相交**（连线端点也不能重合，即每个数字最多用一次）。

求最多能画多少条这样的线。

**约束**：

- $1 \le \text{nums1.length}, \text{nums2.length} \le 500$
- $1 \le \text{nums1}[i], \text{nums2}[j] \le 2000$

**关键概念**：一组合法连线对应一对**严格递增**的下标序列 $i_1 < i_2 < \cdots < i_k$ 与 $j_1 < j_2 < \cdots < j_k$，且 $nums1[i_t] = nums2[j_t]$——这正是**公共子序列**的定义。

## 2. 示例

**示例 1**

```text
输入：nums1 = [1,4,2], nums2 = [1,2,4]
输出：2
解释：连 1–1 与 2–2，两条线平行不相交；
      若再连 4–4，它会跨过 2–2，形成交叉，因此最多 2 条。
```

**示例 2**

```text
输入：nums1 = [2,5,1,2,5], nums2 = [10,5,2,1,5,2]
输出：3
解释：可取公共子序列 [5,2,5]（或 [2,1,5] 等），长度为 3。
```

**示例 3**

```text
输入：nums1 = [1,3,7,1,7,5], nums2 = [1,9,2,5,1]
输出：2
解释：可取公共子序列 [1,1] 或 [1,5]，最长长度为 2。
```

## 3. 解题思路

### 3.1 暴力思路

枚举 `nums1` 的每个下标，尝试与 `nums2` 中任意同值下标配对，并检查是否与已选连线交叉——这本质上是在枚举所有**不相交匹配**，方案数是组合级别（最坏可到指数级）。$n, m \le 500$ 时完全不可行。即便用「枚举子序列再判包含」的写法，也是 $O(2^{\min(n,m)})$。

### 3.2 核心观察：不相交的线就是公共子序列

![不相交的线等价于公共子序列](images/wc134_q3_lcs_model.svg)

两个方向互相蕴含：

- **合法连线 $\Rightarrow$ 公共子序列**：设想两条连线 $(i_1,j_1)$ 与 $(i_2,j_2)$ 且 $i_1 < i_2$。若 $j_1 > j_2$，则两条线段在两条平行线之间必然交叉（端点也构成交叉），矛盾。故 $j_1 < j_2$。于是合法连线给出的下标序列在两侧都严格递增，且对应值相等——它就是长度为 $k$ 的公共子序列。
- **公共子序列 $\Rightarrow$ 合法连线**：给定公共子序列对应的下标对，按下标顺序连线，两侧下标都递增，线段必然互不相交。

所以**答案就是 `nums1` 与 `nums2` 的最长公共子序列（LCS）长度**，可以直接套用经典 DP：

$$dp[i][j] = \begin{cases} dp[i-1][j-1] + 1, & nums1[i-1] = nums2[j-1] \\ \max\bigl(dp[i-1][j],\ dp[i][j-1]\bigr), & \text{otherwise} \end{cases}$$

其中 $dp[i][j]$ 表示 `nums1` 前 $i$ 个元素与 `nums2` 前 $j$ 个元素的 LCS 长度，边界 $dp[0][\cdot] = dp[\cdot][0] = 0$。

### 3.3 算法流程

```text
1. n = len(nums1), m = len(nums2)，开 (n+1) × (m+1) 的 dp 表，全部置 0
2. for i = 1 .. n:
       for j = 1 .. m:
           若 nums1[i-1] == nums2[j-1]: dp[i][j] = dp[i-1][j-1] + 1
           否则:                        dp[i][j] = max(dp[i-1][j], dp[i][j-1])
3. 返回 dp[n][m]
```

### 3.4 示例演算

![示例 1 的 DP 表](images/wc134_q3_example_walkthrough.svg)

对 `nums1 = [1,4,2]`、`nums2 = [1,2,4]` 填表：

| $dp$ | $j{=}0$ | $j{=}1$ (1) | $j{=}2$ (2) | $j{=}3$ (4) |
|------|---------|-------------|-------------|-------------|
| $i{=}0$ | 0 | 0 | 0 | 0 |
| $i{=}1$ (1) | 0 | **1** | 1 | 1 |
| $i{=}2$ (4) | 0 | 1 | 1 | **2** |
| $i{=}3$ (2) | 0 | 1 | **2** | 2 |

右下角 $dp[3][3] = 2$，与示例输出一致。两处「相等转移」分别发生在 $(1,1)$（值 1）与 $(2,3)$（值 4）。

## 4. 算法细节

1. **哨兵边界**：把 $dp$ 开成 $(n+1) \times (m+1)$，第 0 行 / 第 0 列固定为 0，转移时无需特判 $i-1$、$j-1$ 越界。
2. **相等时不要取 max**：$nums1[i-1] = nums2[j-1]$ 时直接 $dp[i-1][j-1] + 1$ 即可（经典结论：此时取 $dp[i-1][j-1]+1$ 不劣于 $\max(dp[i-1][j], dp[i][j-1])$），代码更简洁；写成三者取 max 也不会错，只是多一次比较。
3. **下标偏移**：`dp` 的第 $i$ 行对应 `nums1[i-1]`，这是最常见的 off-by-one 来源。
4. **一维滚动**：$dp[i][\cdot]$ 只依赖上一行与左侧，可压成一维；此时必须**从右往左**更新 `dp[j]`，并用临时变量保存旧的 $dp[j-1]$（即左上角的值），否则会读到本行已更新的值。
5. **空间估算**：$501 \times 501$ 个 `int` 约 1 MB，二维写法完全够用，不必为了省内存牺牲可读性。

## 5. 正确性证明

**引理 1（不相交 $\Rightarrow$ 下标双递增）**：设两组合法连线为 $(i_1, j_1)$、$(i_2, j_2)$，且 $i_1 < i_2$，则必有 $j_1 < j_2$。

**证明**：连线端点互不相同，故 $j_1 \ne j_2$。若 $j_1 > j_2$，把两条线段的端点分别记为 $A=(i_1,0), B=(i_2,0)$（上线）与 $C=(j_2,1), D=(j_1,1)$（下线，用纵坐标 0/1 区分两条平行线）。线段 $AD$ 与 $BC$ 的端点满足 $i_1 < i_2$ 而 $j_1 > j_2$，即两条线段在上下两条线上「交错」排列，由平面几何（或线性插值：两条线段在 $y=1/2$ 处的横坐标分别为 $(i_1+j_1)/2$ 与 $(i_2+j_2)/2$，且 $i_1+j_1$ 与 $i_2+j_2$ 的大小关系不定但两条线段的凸组合区间必然相交）可知它们相交，与「不相交」矛盾。∎

**引理 2（双向等价）**：`nums1` 与 `nums2` 存在长度为 $k$ 的公共子序列 $\iff$ 存在 $k$ 条互不相交的合法连线。

**证明**：

- ($\Leftarrow$) 由引理 1，合法连线按 $i$ 递增排列后，$j$ 也严格递增，且每条线满足 $nums1[i_t] = nums2[j_t]$，故 $nums1[i_1], \ldots, nums1[i_k]$ 是公共子序列。
- ($\Rightarrow$) 设公共子序列对应下标 $i_1 < \cdots < i_k$、$j_1 < \cdots < j_k$。连接 $(i_t, j_t)$，则对任意 $s < t$ 有 $i_s < i_t$ 且 $j_s < j_t$，两条线段端点不交错，由引理 1 的逆否命题知它们不相交；端点也互不相同。∎

**引理 3（LCS 转移正确）**：$nums1[i-1] = nums2[j-1]$ 时 $dp[i][j] = dp[i-1][j-1]+1$；否则 $dp[i][j] = \max(dp[i-1][j], dp[i][j-1])$（经典 LCS 结论）。

**证明**：设 $A = nums1[0..i-1]$，$B = nums2[0..j-1]$。

- 若末元素相等，则存在最优公共子序列以这对末元素结尾：任取 $A,B$ 的一个最长公共子序列 $S$，若 $S$ 已用到 $nums1[i-1]$ 与 $nums2[j-1]$，去掉末尾即得 $A' = A[0..i-2]$、$B' = B[0..j-2]$ 的公共子序列；若未用到，可把它替换为追加这对相等末元素（长度不减）。故 $dp[i][j] = dp[i-1][j-1]+1$。
- 若末元素不等，任何公共子序列都不可能同时以 $nums1[i-1]$ 与 $nums2[j-1]$ 结尾，故它要么不用 $nums1[i-1]$（长度 $\le dp[i-1][j]$），要么不用 $nums2[j-1]$（长度 $\le dp[i][j-1]$）；两个方向都能取到（各自的最优解可直接搬过来），故取 max。∎

**定理**：算法返回值为最多可画的互不相交连线数。

**证明**：由引理 2，最大连线数等于最长公共子序列长度；由引理 3 与归纳，DP 表填出的 $dp[n][m]$ 正是 LCS 长度。∎

## 6. 复杂度分析

- **时间**：$O(nm)$。两层循环各遍历一次 `dp` 的每个格子，转移为常数次比较/加法；$n, m \le 500$ 时约 $2.5 \times 10^5$ 次操作。
- **空间**：$O(nm)$（二维表）；若使用一维滚动数组则为 $O(\min(n,m))$。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int maxUncrossedLines(vector<int>& nums1, vector<int>& nums2) {
        int n = nums1.size(), m = nums2.size();
        vector<vector<int>> dp(n + 1, vector<int>(m + 1, 0));
        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= m; j++) {
                if (nums1[i - 1] == nums2[j - 1]) dp[i][j] = dp[i - 1][j - 1] + 1;
                else dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]);
            }
        }
        return dp[n][m];
    }
};
```

### Python

```python
class Solution:
    def maxUncrossedLines(self, nums1: list[int], nums2: list[int]) -> int:
        n, m = len(nums1), len(nums2)
        dp = [[0] * (m + 1) for _ in range(n + 1)]
        for i in range(1, n + 1):
            a = nums1[i - 1]
            for j in range(1, m + 1):
                if a == nums2[j - 1]:
                    dp[i][j] = dp[i - 1][j - 1] + 1
                else:
                    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
        return dp[n][m]
```

## 8. 边界情况与易错点

1. **重复元素不是「一一对应」**：`nums1` 中同一个值可以出现在不同连线里（用不同下标），但同一**下标**只能连一次。示例 3 的 `[1,...,7,1,...]` 与 `[1,...,1]` 正是这种情况。
2. **连线在端点也不能相交**：题目明确端点也不能重合，这正是「下标序列严格递增」的来源；若允许端点重合，问题会退化成多重集匹配。
3. **`dp` 下标偏移**：`dp` 用 1-based、数组用 0-based，混用是最常见的 WA。
4. **不要误以为是「最长公共子串」**：本题不要求连续，`[5,2,5]` 中间的 2 可以不取。若误写成子串 DP（不相等就清零），示例 2 会得到 2 而不是 3。
5. **一维滚动方向**：压成一维后必须从右往左更新，并暂存旧的 $dp[j-1]$。
6. **值域与空间无关**：$nums[i] \le 2000$ 只是数值范围，不影响复杂度；不要试图用它开 2000×2000 的表。
