# LeetCode 替换所有的问号 题解

## 1. 题目概述

- **标题 / 题号**：替换所有的问号（#1576，easy）
- **链接**：https://leetcode.cn/problems/replace-all-s-to-avoid-consecutive-repeating-characters/
- **来源**：LeetCode 第 205 场周赛 Q1
- **难度**：简单
- **标签**：字符串、贪心

**题意**：给定仅含小写字母和 `'?'` 的字符串 `s`，把每个 `'?'` 替换成某个小写字母，使最终串**任意相邻两字符都不相同**。不能改动非 `'?'` 字符；题目保证除 `'?'` 外原串无连续重复字符；只要返回任意一组合法答案（保证存在）。

**约束**：

- $1 \le s.length \le 100$
- `s` 仅含小写英文字母和 `'?'`

> 💡 关键保证是「除 `'?'` 外无连续重复」：替换某个字符只需照顾**左右两个邻居**，不会与更远位置冲突。这把全局问题降维成了纯局部问题。

## 2. 示例

**示例 1**

```text
输入：s = "?zs"
输出："azs"
解释：共 25 种方案（"azs" 到 "yzs"），只有填 'z' 非法（"zzs" 连续两个 'z'）。
```

**示例 2**

```text
输入：s = "ubv?w"
输出："ubvaw"
解释：共 24 种方案，填 'v' 或 'w' 非法（与左/右邻居重复）。
```

**示例 3（补充：连续问号）**

```text
输入：s = "a??"
输出："aba"
解释：第 1 个 '?' 避开左邻 'a' 填 'b'；第 2 个 '?' 避开刚填的 'b' 填 'a'。
```

## 3. 解题思路

### 3.1 暴力思路

每个 `'?'` 有 26 种选择，最坏 $26^k$ 种组合（$k$ 为问号个数），枚举后逐一检查全局合法性是指数级。即使写成回溯，实际也会很快碰壁折返——但**根本不需要**：本题约束是纯局部的（只看相邻两位），可选值域又足够大，逐位贪心即可。

### 3.2 核心观察：值域远大于约束数，贪心不回溯

![核心观察：每个问号至多 2 条邻居禁令](images/wc205_q1_neighbor_bans.svg)

**观察一：每个 `'?'` 至多 2 条禁令。**

位置 $i$ 的候选字母只被左右邻居限制：左邻居（若为字母）禁 1 个字母，右邻居（若为字母）禁 1 个字母。$26 - 2 \ge 24$，**局部永远有解**——这正是题目「答案总是存在」的原因。

**观察二：从左到右填，不会把后面逼死。**

填 $s[i]$ 时左邻居已确定；右邻居若是字母则避开，若是 `'?'` 则**不构成约束**（`'?'` 不等于任何字母）。填入后至多给右边的 `'?'` 增加 1 条禁令，它仍有 $\ge 24$ 个选择，因此**贪心无需回溯**。

**观察三（加速）：只需试 `'a'`、`'b'`、`'c'` 三个字母。**

禁令至多 2 条，由鸽笼原理，$\{a, b, c\}$ 三个候选中**必有一个**未被禁用，内层循环 3 次即可。

### 3.3 算法流程

![算法流程图](images/wc205_q1_greedy_flow.svg)

从左到右扫描，遇 `'?'` 依次试 `'a'`、`'b'`、`'c'`，取第一个与左右邻居都不同的字母填入。

### 3.4 示例演算

![示例演算：三个关键场景](images/wc205_q1_walkthrough.svg)

覆盖三种关键情形：问号两侧都是字母、连续问号（右邻未填不禁）、以及「必须查右邻居」的反例场景。

## 4. 算法细节

1. **原地修改**：C++ 的 `string` 可变，直接写回；Python 字符串不可变，先转 `list` 最后 `join`。
2. **合法性判定**（核心一行）：

   ```text
   (i == 0 || s[i-1] != c) && (i == n-1 || s[i+1] != c)
   ```

   利用 `||` **短路求值**在 $i=0$ / $i=n-1$ 处避免越界访问。
3. **候选集**：内层只需 `'a'`、`'b'`、`'c'` 三个字母（正确性见 §5 引理 1）。
4. **右邻是 `'?'`**：此时 $s[i+1] \ne c$ 自动成立；填完后它变成字母，在下一轮成为新的左邻约束。

## 5. 正确性证明

**引理 1（候选存在）**：对任意位置 $i$，记被禁字母集合为 $B_i$，则 $|B_i| \le 2$，故 $\{a,b,c\}$ 中至少有一个字母不属于 $B_i$。

**证明**：$B_i$ 仅可能包含左邻居字母（至多 1 个）与右邻居字母（至多 1 个），故 $|B_i| \le 2 < 3 = |\{a,b,c\}|$，由鸽笼原理存在 $c \in \{a,b,c\} \setminus B_i$。∎

**引理 2（贪心不破坏后续可解性）**：从左到右处理，填完 $s[i]$ 后，位置 $i+1$（若为 `'?'`）的被禁集合大小仍 $\le 2$。

**证明**：填 $s[i] = c$ 后，$i+1$ 的左邻居为字母 $c$（1 条禁令），其右邻居若为字母至多再加 1 条，合计 $\le 2$。由引理 1，$i+1$ 仍有合法候选。对问号个数归纳，每个 `'?'` 都能成功填入。∎

**定理**：算法输出的串不含任何相邻重复字符，且答案总存在。

**证明**：合法性：填 $s[i]=c$ 时已保证 $c$ 异于左邻居（若存在），故 $(i-1, i)$ 合法；若右邻居是原字母，$c$ 亦异于它，$(i, i+1)$ 合法；若右邻居是 `'?'`，其填入时会避开 $c$（引理 2 的流程）。原串非 `'?'` 部分本身无相邻重复（题目保证）。存在性：由引理 1、2 归纳即得。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。一重扫描，每个 `'?'` 内层至多 3 次常数比较（$n \le 100$，总量微不足道）。
- **空间复杂度**：$O(1)$（C++ 原地修改）；Python 需 $O(n)$ 转 `list`。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    string modifyString(string s) {
        int n = s.size();
        for (int i = 0; i < n; ++i) {
            if (s[i] != '?') continue;
            for (char c = 'a'; c <= 'c'; ++c) {
                if ((i == 0 || s[i - 1] != c) &&
                    (i == n - 1 || s[i + 1] != c)) {
                    s[i] = c;
                    break;
                }
            }
        }
        return s;
    }
};
```

### Python

```python
class Solution:
    def modifyString(self, s: str) -> str:
        t = list(s)
        n = len(t)
        for i in range(n):
            if t[i] != '?':
                continue
            for c in 'abc':
                if (i == 0 or t[i - 1] != c) and (i == n - 1 or t[i + 1] != c):
                    t[i] = c
                    break
        return ''.join(t)
```

## 8. 边界情况与易错点

1. **越界**：`i=0` 无左邻、`i=n-1` 无右邻。C++ 中 `s[-1]` 是未定义行为；Python 中 `t[-1]` 会**静默取到末尾元素**造成隐蔽 bug。必须先写 `i == 0` / `i == n-1` 短路。
2. **只查左邻居的坑**：`"?a"` 会填成 `"aa"`——右邻是原字母时必须避开（见示例演算场景③）。
3. **连续问号**：右邻是 `'?'` 时不构成禁令；且左邻可能是**刚填入**的字母而非原字符，判定时统一用当前 `s[i-1]` 即可自然覆盖。
4. **单字符 `"?"`**：输出 `"a"`。
5. **别用 26 个字母硬扫**：不算错但多余；「禁令数 + 1」个候选就够。
