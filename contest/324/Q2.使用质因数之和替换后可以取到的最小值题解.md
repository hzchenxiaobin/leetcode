# LeetCode 使用质因数之和替换后可以取到的最小值 题解

## 1. 题目概述

- **标题 / 题号**：使用质因数之和替换后可以取到的最小值（#2507，medium）
- **链接**：https://leetcode.cn/problems/smallest-value-after-replacing-with-sum-of-prime-factors/
- **来源**：LeetCode 第 324 场周赛 Q2
- **难度**：中等
- **标签**：数学、数论、质因数分解、模拟

**题意**：给定正整数 $n$。每一步把 $n$ 替换为它的**质因数之和**（按重数计——若质数 $p$ 在 $n$ 的分解中出现 $k$ 次，求和时 $p$ 加 $k$ 次），重复这一过程。返回 $n$ 能取到的**最小值**。

**约束**：

- $2 \le n \le 10^5$

> 💡 本题另有[每日题解 2507](../../solution/2501-2600/2507_使用质因数之和替换后可以取到的最小值.md)，与本文互为印证；本文按周赛复盘视角展开，重点是「停机判据」的发现过程、引理-定理式证明，以及 `n = 4` 陷阱的现场排查。

## 2. 示例

**示例 1**

```text
输入：n = 15
输出：5
解释：15 = 3 × 5 → 替换为 3 + 5 = 8
      8 = 2·2·2 → 替换为 2 + 2 + 2 = 6
      6 = 2 × 3 → 替换为 2 + 3 = 5
      5 是质数，取到的最小值为 5
```

**示例 2**

```text
输入：n = 3
输出：3
解释：3 是质数，无法再变化，最小值为 3。
```

**补充示例 3**

```text
输入：n = 4
输出：4
解释：4 = 2 × 2 → 替换为 2 + 2 = 4，值不再变化。
      4 是唯一的「合数不动点」，返回 4。
```

## 3. 解题思路

### 3.1 暴力思路：反复替换，问题出在「何时停」

本题的操作没有任何选择余地（每步唯一确定），所以「暴力」与「正解」只差一个**停机条件**。最直觉的写法是「是合数就替换」：

```cpp
while (!isPrime(n)) n = sumOfPrimeFactors(n);  // 危险！
return n;
```

这份代码会在 `n = 4` 上**死循环**：$4 = 2 \times 2$，$f(4) = 2 + 2 = 4$，替换后原地不动，而 `isPrime(4)` 永远为 `false`。这说明「是合数 ⇒ 还能变小」的直觉不成立——必须先弄清**替换操作到底把 $n$ 怎么变**，才能写对停机判据。这也是本题作为 Q2 的主要区分点：分解质因数是基本功，识别不动点才是考点。

### 3.2 核心观察：单调不增过程，落点即答案

![核心观察：质因数之和不超过自身，序列单调不增](images/wc324_q2_fixpoint_chain_concept.svg)

记 $f(n)$ 为 $n$ 的质因数之和（含重数）。三个层层递进的观察：

1. **$f(n) \le n$ 恒成立**：对 $a, b \ge 2$ 有 $a + b \le a \cdot b$（等号仅 $a = b = 2$）。把 $n$ 的质因子两两地「用乘合并」，和变积只增不减，于是质因数之和 $\le$ 乘积 $= n$。
2. **不动点恰是「质数」与 $4$**：质数 $p$ 的唯一质因子是自身，$f(p) = p$；$4 = 2 + 2 = 2 \times 2$ 是上述不等式唯一的取等情形，是**唯一的合数不动点**；其余合数处不等式严格，$f(n) < n$。
3. **必停且落点即最小值**：序列 $n, f(n), f(f(n)), \ldots$ 单调不增，非不动点处每步至少减 $1$，而正整数不能无限递减，故有限步内必落在某个不动点上；又因为序列不增，**落点 $\le$ 途中一切值**——「求最小值」被归约为「跑到不动点」。

由观察 3，停机判据只需一句：**算出 $s = f(n)$，若 $s = n$ 则停**。它同时覆盖质数与 $4$，既不需要 `isPrime` 辅助函数，也天然免疫 $4$ 的死循环。

### 3.3 算法流程

![算法流程：反复替换直到 s == n](images/wc324_q2_replace_flow.svg)

主循环只有三步：算 $s$、判 $s = n$、赋值 $n \gets s$。其中 $f(x)$ 用**试除法**求：$d$ 从 $2$ 枚举到 $\sqrt{x}$，一旦整除就除干净（每除一次累加一个 $d$，重数自然计入），循环结束后剩余值若 $> 1$，它本身就是最后一个（最大）质因子，直接累加。

### 3.4 示例演算

![示例演算：n=15 一路替换到 5](images/wc324_q2_walkthrough.svg)

以 $n = 15$ 为例逐步走查：

| 步 | $n$ | 质因数分解 | $f(n)$ | 判停 |
|----|-----|-----------|--------|------|
| 0 | 15 | 3 × 5 | 8 | 8 ≠ 15，继续 |
| 1 | 8 | 2·2·2 | 6 | 6 ≠ 8，继续 |
| 2 | 6 | 2 × 3 | 5 | 5 ≠ 6，继续 |
| 3 | 5 | （质数） | 5 | 5 = 5 → 返回 **5** ⭐ |

对照陷阱输入 $n = 4$：第 0 步 $f(4) = 2 + 2 = 4 = n$，命中不动点直接返回 $4$——这正是 `s == n` 判据比 `!isPrime(n)` 稳的地方。

## 4. 算法细节

1. **试除求 $f(x)$**：`d` 从 $2$ 起，循环条件 `d * d <= x`；一旦 `x % d == 0` 就反复除（每次 `s += d`），把重数吃干净再前进。**除的过程中 $x$ 在缩小，上界 `d * d <= x` 跟着收紧**，这是试除法自带的剪枝。
2. **残余兜底**：循环结束后若 `x > 1`，剩下的 $x$ 必是质数（比它小的因子已被前面的试除除尽），且是原数的最大质因子，直接 `s += x`。漏掉这行，质数输入第一轮 $s = 0$，$n$ 被替换成 $0$ 后返回错误答案。
3. **为什么枚举到 $\sqrt{x}$ 就够**：若 $x$ 有两个 $> \sqrt{x}$ 的质因子，其乘积已超过 $x$，矛盾；故大质因子至多一个，交给残余兜底捕获。
4. **停机判据选 `s == n`**：一步覆盖全部不动点（质数与 $4$），不引入 `isPrime`，也不漏 $4$ 这个合数不动点。
5. **轮数不必担心**：由第 5 节引理 3，合数 $n$ 满足 $f(n) \le n/2 + 2$，每轮近似减半，$10^5$ 开局十几轮内到头。

## 5. 正确性证明

**引理 1（乘加不等式）**：对整数 $a, b \ge 2$，有 $a + b \le a \cdot b$，当且仅当 $a = b = 2$ 时取等。

**证明**：$ab - a - b = (a-1)(b-1) - 1 \ge 1 - 1 = 0$（因 $a - 1, b - 1 \ge 1$），故 $ab \ge a + b$。取等当且仅当 $(a-1)(b-1) = 1$，即 $a = b = 2$。∎

**引理 2（不超过自身与取等刻画）**：对 $n \ge 2$，设 $n = p_1 p_2 \cdots p_k$ 为质因子分解（含重数），则 $f(n) = \sum_{i=1}^{k} p_i \le n$；等号成立当且仅当 $k = 1$（$n$ 为质数）或 $n = 4$。

**证明**：对 $k$ 归纳。$k = 1$ 时 $f(n) = p_1 = n$，为质数取等情形。$k \ge 2$ 时记 $A = p_1 \cdots p_{k-1} \ge 2$、$B = p_k \ge 2$，由归纳假设 $p_1 + \cdots + p_{k-1} \le A$，再用引理 1：

$$f(n) = (p_1 + \cdots + p_{k-1}) + p_k \le A + B \le A \cdot B = n$$

取等需两处同时取等：归纳处取等要求 $A$ 为质数（$k - 1 = 1$）或 $A = 4$，而引理 1 处取等要求 $A = B = 2$；二者兼容的唯一情形是 $A = B = 2$，即 $n = 2 \times 2 = 4$。∎

**引理 3（缩减率）**：若 $n$ 是合数，则 $f(n) \le \dfrac{n}{2} + 2$。

**证明**：设 $p$ 为 $n$ 的最小质因子，写 $n = p \cdot m$（$m \ge p \ge 2$）。$n$ 的质因子多重集是 $\{p\}$ 与 $m$ 的质因子多重集之并，故 $f(n) = p + f(m) \le p + m$（对 $m$ 用引理 2）。而

$$p + m \le \frac{pm}{2} + 2 \iff (p-2)(m-2) \ge 0$$

由 $p, m \ge 2$ 恒成立，代入 $pm = n$ 即得。∎

> 💡 引理 3 给出轮数上界：对合数 $n > 4$，$f(n) \le n/2 + 2 < n$，且迭代式 $n_{t+1} \le n_t / 2 + 2$ 解得 $n_t \le \dfrac{n_0 - 4}{2^t} + 4$——约 $\log_2 n$ 轮后序列进入个位数区间，随后常数步内停机。

**定理（终止性与正确性）**：从任意 $n \ge 2$ 出发反复执行 $n \gets f(n)$，过程必在有限步内停止于某个不动点 $m$（$f(m) = m$），且 $m$ 就是 $n$ 可取到的最小值。

**证明**：由引理 2，序列单调不增；每步要么值不变（即到达不动点，算法判 `s == n` 停止），要么严格减小。正整数不能无限次严格减小，故有限步内必出现值不变的一步，停在某个不动点 $m$。单调不增保证 $m \le n_t$ 对序列中一切 $n_t$ 成立，而「$n$ 可取到的值」恰为序列各项，故最小值 $= m$，算法返回的正是它。∎

## 6. 复杂度分析

- **时间复杂度**：$O(\sqrt{n} \log n)$。每轮替换做一次试除分解，代价 $O(\sqrt{n})$（$n \le 10^5$ 时 $\sqrt n \le 317$）；由引理 3，轮数为 $O(\log n)$（每轮近似减半）。总运算量 $10^4$ 量级，远低于时限。
- **空间复杂度**：$O(1)$。仅若干整型变量，原地迭代。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int smallestValue(int n) {
        while (true) {
            int s = 0;
            for (int d = 2, x = n; d * d <= x; ++d) {
                while (x % d == 0) {
                    s += d;          // 重数：每除一次累加一个 d
                    x /= d;
                }
            }
            if (x > 1) s += x;       // 残余的大质因子
            if (s == n) return n;    // 不动点：质数 或 4
            n = s;
        }
    }
};
```

### Python

```python
class Solution:
    def smallestValue(self, n: int) -> int:
        while True:
            s, x, d = 0, n, 2
            while d * d <= x:
                while x % d == 0:
                    s += d           # 重数：每除一次累加一个 d
                    x //= d
                d += 1
            if x > 1:                # 残余的大质因子
                s += x
            if s == n:               # 不动点：质数 或 4
                return n
            n = s
```

## 8. 边界情况与易错点

1. **`n = 4` 死循环**（本题头号坑）：`4` 是合数却满足 $f(4) = 4$，`while (!isPrime(n)) n = f(n);` 在此处无限循环。必须以 `s == n`（或循环内 `if (s >= n) break;` 兜底）停机。赛场上若 TLE 且输入很小，第一反应应查停机条件。
2. **`n` 本身是质数**（含最小输入 $n = 2$）：第一轮即 $s = n$，直接返回，无需特判。
3. **残余兜底漏写**：丢掉 `if (x > 1) s += x;`，则质数输入第一轮 $s = 0$，$n$ 变成 $0$ 后返回错误值 $0$。
4. **重数处理**：$8 = 2 \cdot 2 \cdot 2$ 的和是 $6$ 不是 $2$——内层必须「除干净」才前进；只除一次就推进会把 $f$ 恒算小。
5. **`d * d` 溢出习惯**：本题 $d \le 317$，`int` 无恙；但同一模板搬到 $10^{18}$ 值域时 `d * d` 在 $d > 46340$ 处溢出 32 位 `int`，习惯写 `(long long)d * d` 或 `d <= x / d`。
6. **不必预筛质数表**：单次调用、$n \le 10^5$，试除绰绰有余；筛表 / SPF 预表是大规模多查询的武器（见相关题目 2521）。
