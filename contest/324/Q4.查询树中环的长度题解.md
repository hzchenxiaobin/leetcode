# LeetCode 查询树中环的长度 题解

## 1. 题目概述

- **标题 / 题号**：查询树中环的长度（#2509，hard）
- **链接**：https://leetcode.cn/problems/cycle-length-queries-in-a-tree/
- **来源**：LeetCode 第 324 场周赛 Q4
- **难度**：困难
- **标签**：树、完全二叉树、最近公共祖先、位运算、二进制表示

**题意**：给定一棵 $2^n - 1$ 个节点的**完全二叉树**：根编号为 $1$，编号为 $\text{val}$ 的节点左孩子为 $2\,\text{val}$、右孩子为 $2\,\text{val}+1$。再给 $m$ 个查询 $queries[i]=[a_i,b_i]$，每个查询**相互独立**：在 $a_i,b_i$ 之间加一条边，求此时图中环的长度（环中边数），然后撤掉这条边。返回所有查询的答案数组。

**约束**：

- $2 \le n \le 30$：节点数至多 $2^{30}-1 \approx 1.07\times 10^9$ —— **树大到根本建不出来**
- $1 \le m \le 10^5$
- $1 \le a_i, b_i \le 2^n-1$，$a_i \ne b_i$

> 💡 本题另有[每日题解 2509](../../solution/2501-2600/2509_查询树中环的长度.md)，与本文互为印证；本文按周赛复盘视角展开，重点是「加边成环 ⟹ LCA 拆路径 ⟹ 谁大谁跳」这条推理链的提炼、「编号即路径」的二进制视角，以及引理-定理式的完整证明。

## 2. 示例

**示例 1**

```text
输入：n = 3, queries = [[5,3],[4,7],[2,3]]
输出：[4,5,3]
解释：2³−1 = 7 个节点：1 为根，2/3 为其左右子，4–7 为叶子。
  [5,3]：树上路径 5→2→1→3 长 4，加新边成环，环长 4
  [4,7]：树上路径 4→2→1→3→7 长 4，环长 5
  [2,3]：树上路径 2→1→3 长 2，环长 3
```

**示例 2（新边与树边平行）**

```text
输入：n = 2, queries = [[1,2]]
输出：[2]
解释：2 是 1 的左孩子，(1,2) 本就是树边；再加一条平行边后，
      环 = 两条平行边，长度 2 = 路径长 1 + 新边 1。
```

**示例 3（补充：一方是另一方的祖先）**

```text
输入：n = 3, queries = [[1,7]]
输出：[3]
解释：7 是 1 的「右孩子的右孩子」：树上路径 7→3→1 长 2，环长 3。
      爬树时只有 b 一侧在动，公式自动覆盖，无需特判。
```

## 3. 解题思路

### 3.1 暴力思路：建树 + 逐查询搜路径

最直接的做法是把树显式建出来，再对每个查询 BFS/DFS 找 $a\to b$ 的路径。但 $2^{30}-1\approx 10^9$ 个节点，邻接表直接 MLE；就算利用编号规律只在隐式树上搜索，单次查询也是 $O(2^n)$，$m$ 次共 $O(m\cdot 2^n)\approx 10^{14}$。暴力的浪费在于**真的去「走」路径**——这棵树的编号规律早已把任意两点间的路径写在了编号的二进制里。

### 3.2 核心观察：环 = 新边 + 树上唯一路径，路径必过 LCA

![核心观察：加边成环与 LCA 路径拆解](images/wc324_q4_cycle_lca_concept.svg)

三个层层递进的观察：

1. **树上加一条边，恰好产生一个环**。树中 $a\to b$ 的路径**唯一**，这条唯一路径与新边 $(a,b)$ 首尾相接闭合成环，环上不会再有别的边（证明见 §5 引理 1）。于是
   $$\text{环长} = \mathrm{dist}(a,b) + 1$$
   「找环」坍缩为「算树上两点距离」。
2. **堆式编号免建树**。$\mathrm{parent}(v)=\lfloor v/2\rfloor = v\gg 1$；深度 $\mathrm{dep}(v)=\lfloor\log_2 v\rfloor = \text{bit\_length}(v)-1$（第 $d$ 层恰是编号区间 $[2^d,\,2^{d+1}-1]$）。整棵树的结构信息被压缩进每个整数自身。
3. **路径必过 LCA，长度是深度差之和**。设 $l=\mathrm{LCA}(a,b)$，则
   $$\mathrm{dist}(a,b)=\mathrm{dep}(a)+\mathrm{dep}(b)-2\,\mathrm{dep}(l)$$

> 💡 一个漂亮的副产品：把 $v$ 的二进制去掉最高位的 $1$，剩下的每一位就是根到 $v$ 的走法（$0$ 走左、$1$ 走右）。$4=100_2$ 即「左左」，$7=111_2$ 即「右右」；两个编号对齐长度后的**公共前缀**正是通往 LCA 的路。这是 §4 中 $O(1)$ 位技巧的种子。

### 3.3 算法流程：谁大谁上跳，双指针爬树

![算法流程：双指针爬树与四步相遇示例](images/wc324_q4_climb_algorithm.svg)

甚至不必先求出 LCA 的编号——只要数「一共跳了多少步」：

1. 取出查询 $(a,b)$，计数 $steps=0$；
2. 循环：只要 $a\ne b$，就让**编号大**的一方跳到父节点（$\gg 1$），$steps{+}{+}$；
3. $a=b$ 时两者相遇在 LCA，输出 $steps+1$。

「谁大谁跳」为什么安全？若 $a>b$，则 $a$ **不可能**是 $b$ 的祖先——$b$ 的任何真祖先编号都 $\le\lfloor b/2\rfloor<b<a$（真祖先深度更小，编号必然更小）。于是 LCA 必是 $a$ 的真祖先，把 $a$ 上移一步绝不会跳过头。每步使 $\mathrm{dep}(a)+\mathrm{dep}(b)$ 严格减 $1$，至多 $2(n-1)\le 58$ 步必然相遇。

### 3.4 示例演算

![示例演算：三个查询的爬树过程与环长](images/wc324_q4_walkthrough.svg)

记 $c_a, c_b$ 分别为 $a, b$ 两侧各自的上跳步数，则环长 $=c_a+c_b+1$：

| 查询 | 爬树过程（按时间序） | 相遇点 | $c_a+c_b$ | 环长 | 环 |
|------|---------------------|--------|-----------|------|----|
| $[5,3]$ | $5{\to}2$（a）、$3{\to}1$（b）、$2{\to}1$（a） | $1$ | $2+1$ | $4$ | $5\to2\to1\to3\to5$ |
| $[4,7]$ | $7{\to}3$（b）、$4{\to}2$（a）、$3{\to}1$（b）、$2{\to}1$（a） | $1$ | $2+2$ | $5$ | $4\to2\to1\to3\to7\to4$ |
| $[2,3]$ | $3{\to}1$（b）、$2{\to}1$（a） | $1$ | $1+1$ | $3$ | $2\to1\to3\to2$ |

## 4. 算法细节

1. **深度无需显式计算**：主解法只比较编号大小、做右移，$\mathrm{dep}$ 只活在推导里；「$a>b\Rightarrow\mathrm{dep}(a)\ge\mathrm{dep}(b)$」由 $\lfloor\log_2\cdot\rfloor$ 的单调性保证。
2. **每查询至多 58 次迭代**：$a,b\le 2^{30}-1$，深度各至多 29；$m\le 10^5$ 时总迭代 $\le 5.8\times 10^6$ 次，每次只是「比较 + 移位 + 自增」。
3. **$O(1)$ 位技巧（进阶）**：先用 `bit_length` 之差把深的一方对齐（记移位 $s$ 步）；若对齐后 $a=b$（一方是另一方的祖先），答案即 $s+1$；否则令 $h$ 为 $a\oplus b$ 最高位的位置（从 0 起），双方各还需跳 $h+1$ 步，答案 $s+2(h+1)+1$。验证 $[4,7]$：$s=0$，$4\oplus 7=3$ 的最高位 $h=1$，答案 $0+4+1=5$ ✓。
4. **为什么不套通用 LCA 模板**：标签里的 binary lifting（倍增）是一般树上的功夫——需要 $O(V)$ 的预处理表，$V=2^{30}$ 直接不可行。而在堆式编号树上「跳 $2^i$ 级祖先」就是 $v\gg 2^i$，连预处理都省了；双指针爬树已是常数最小的写法，位技巧进一步把它压到 $O(1)$。
5. **若还想要环的节点序列**（题目只要长度）：爬树时把 $a$ 侧、$b$ 侧依次经过的编号分别记入两个数组，结尾拼上 LCA 即可，额外开销 $O(\text{环长})$。

## 5. 正确性证明

**引理 1（基本圈）**：树 $T$ 上添加一条边 $e=(a,b)$ 后，图中**恰好存在一个环**，且该环由 $e$ 与 $T$ 中 $a\to b$ 的唯一路径拼接而成。

**证明**：存在性：树中 $a\to b$ 路径唯一，记为 $P$；$P$ 与 $e$ 首尾相接成环。唯一性：任取一个环 $C$，因 $T$ 本身无环，$C$ 必须用到 $e$；从 $C$ 中删去 $e$，剩下的是 $T$ 中一条 $a\to b$、边不重复的路径，由唯一性它就是 $P$，故 $C=P+e$。∎

> 注：即使 $e$ 与某条树边平行（$b=2a$ 或 $b=2a+1$，一方是另一方的孩子），上述论证在多重图意义下同样成立——$C\setminus\{e\}$ 取到的正是那条树边，环长 $=1+1=2$，与公式一致（即示例 2）。

**引理 2（深度公式）**：对 $1\le v\le 2^n-1$，节点 $v$ 的深度 $\mathrm{dep}(v)=\lfloor\log_2 v\rfloor$；等价地，第 $d$ 层（$0\le d\le n-1$）的节点恰为区间 $[2^d,\,2^{d+1}-1]$ 的全部整数。

**证明**：对 $d$ 归纳。$d=0$：只有根 $1$。设第 $d$ 层为 $[2^d,\,2^{d+1}-1]$（$d\le n-2$）。完全二叉树中该层节点全有两个孩子 $2v,2v+1$；$v$ 遍历该区间时，$2v$ 取遍 $[2^{d+1},\,2^{d+2}-2]$ 中的偶数，$2v+1$ 取遍 $[2^{d+1}+1,\,2^{d+2}-1]$ 中的奇数，两者合并恰为 $[2^{d+1},\,2^{d+2}-1]$。又树的总节点集为 $[1,\,2^n-1]$，包含每个这样的区间，故区间内编号全部存在。∎

**引理 3（路径长度）**：设 $l=\mathrm{LCA}(a,b)$，则 $a\to b$ 的树上路径长度为 $\mathrm{dep}(a)+\mathrm{dep}(b)-2\,\mathrm{dep}(l)$。

**证明**：把「$a$ 沿父指针上行到 $l$」的链与「$l$ 下行到 $b$」的链首尾拼接，得到一条 $a\to b$ 的途径。两链若有除 $l$ 外的公共点 $u$，则 $u$ 是深度**大于** $\mathrm{dep}(l)$ 的公共祖先，与 $l$ 为最深公共祖先矛盾；故拼接结果是**简单路径**。上行链每条边深度恰减 1，长为 $\mathrm{dep}(a)-\mathrm{dep}(l)$；下行链同理长 $\mathrm{dep}(b)-\mathrm{dep}(l)$。由树中路径的唯一性，它就是 $a\to b$ 的路径。∎

**引理 4（爬树过程的正确性与计数）**：过程「$\text{while } a\ne b\text{ do }(\text{较大者})\gg 1$，$steps{+}{+}$」终止时 $a=b=\mathrm{LCA}(a_0,b_0)$，且 $steps=\mathrm{dep}(a_0)+\mathrm{dep}(b_0)-2\,\mathrm{dep}(\mathrm{LCA}(a_0,b_0))$。

**证明**：记 $A(v)$ 为 $v$ 的祖先集合（含自身），$\mathrm{LCA}(x,y)$ 即 $A(x)\cap A(y)$ 中最深者。

**不变式**：每步操作不改变 $\mathrm{LCA}(a,b)$。设该步 $a>b$。由引理 2，$b$ 的真祖先深度更小、编号 $\le\lfloor b/2\rfloor<b<a$，故 $a\notin A(b)$；而 $A(a)=A(\lfloor a/2\rfloor)\cup\{a\}$，于是
$$A(a)\cap A(b)=A(\lfloor a/2\rfloor)\cap A(b),$$
即把 $a$ 换成父节点后公共祖先集合不变，LCA 不变；$a<b$ 的情形对称。

**终止性与终值**：每步 $\mathrm{dep}(a)+\mathrm{dep}(b)$ 严格减 1，至多 $2(n-1)$ 步后两者同为根 $1$，循环必然结束；结束时 $a=b$，而 $\mathrm{LCA}(a,a)=a$，结合不变式得 $a=b=\mathrm{LCA}(a_0,b_0)$。

**计数**：$a$ 只经 $\gg 1$ 变化，每变一次深度恰减 1，终值为 LCA，故 $a$ 恰被移动 $\mathrm{dep}(a_0)-\mathrm{dep}(\mathrm{LCA})$ 次；$b$ 同理。两者相加即 $steps$。∎

**定理（答案公式）**：对每个查询 $[a,b]$，环长 $=steps+1$，其中 $steps$ 为上述爬树过程的总步数。

**证明**：由引理 4，$steps=\mathrm{dist}(a,b)$（引理 3）；由引理 1，环长 $=\mathrm{dist}(a,b)+1=steps+1$。∎

> 💡 证明链骨架：**加边 ⟹ 唯一环（引理 1）** → **环长 = 路径长（引理 3）** → **路径长 = 爬树步数（引理 4）**。引理 4 里「谁大谁跳」的安全性，本质是堆式编号下「真祖先编号严格更小」这条全序性质——一次编号大小比较，同时充当了深度比较与祖先判定。

## 6. 复杂度分析

- **时间复杂度**：$O(m\cdot n)$。每个查询至多 $\mathrm{dep}(a)+\mathrm{dep}(b)\le 2(n-1)=58$ 次循环，每次一个比较、一个移位、一个自增；$m\le 10^5$ 时总计 $\le 5.8\times 10^6$ 次整数操作。采用 §4.3 的位技巧则降至 $O(m)$。
- **空间复杂度**：$O(1)$（不计返回数组）。不建树、无预处理、无递归栈——$2^{30}$ 规模的树只以两个整数的形式参与运算。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> cycleLengthQueries(int n, vector<vector<int>>& queries) {
        vector<int> ans;
        ans.reserve(queries.size());
        for (const auto& q : queries) {
            int a = q[0], b = q[1], steps = 0;
            while (a != b) {
                if (a > b) a >>= 1;   // 编号大者上跳一步
                else       b >>= 1;
                ++steps;
            }
            ans.push_back(steps + 1); // 环长 = 路径长 + 新边
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def cycleLengthQueries(self, n: int, queries: List[List[int]]) -> List[int]:
        ans = []
        for a, b in queries:
            steps = 0
            while a != b:
                if a > b:
                    a >>= 1          # 编号大者上跳一步
                else:
                    b >>= 1
                steps += 1
            ans.append(steps + 1)    # 环长 = 路径长 + 新边
        return ans
```

### Python（$O(1)$ 位技巧版）

```python
class Solution:
    def cycleLengthQueries(self, n: int, queries: List[List[int]]) -> List[int]:
        ans = []
        for a, b in queries:
            s = abs(a.bit_length() - b.bit_length())   # 深度差：先把深的一方对齐
            if a.bit_length() > b.bit_length():
                a >>= s
            else:
                b >>= s
            if a == b:                                  # 一方是另一方的祖先
                ans.append(s + 1)
            else:
                h = (a ^ b).bit_length() - 1            # 最高不同位（从 0 起）
                ans.append(s + 2 * (h + 1) + 1)         # 双方各再跳 h+1 步
        return ans
```

## 8. 边界情况与易错点

1. **忘记 $+1$**：环长 = 路径长 + 1，新边自身占 1 条边——头号坑。写成 `steps` 会让示例 1 的三个答案全部少 1。
2. **父子加边（重边）**：$b=2a$ 时新边与树边平行，环长恰为 2（示例 2）。公式自动覆盖，**不要**专门特判——特判分支反而容易漏掉 $+1$ 或把路径长算错。
3. **一方是另一方的祖先**：如 $[1,\,2^n-1]$，路径就是根到最右叶的链，环长为 $n$。主解法只有一侧在跳，自动正确；位技巧版**必须**先判「对齐后是否相等」再取 $a\oplus b$ 的最高位——否则 $a\oplus b=0$ 时 `bit_length()-1` 得 $-1$，而 C++ 里 `__builtin_clz(0)` 更是未定义行为。
4. **任何 $O(V)$ 预处理都是陷阱**：$V=2^{30}-1\approx 10^9$，建邻接表、DFS 打深度表、通用倍增表统统 MLE——本题考察的正是识破「不需要树就能算出树上的量」。
5. **比较编号即比较深度**：$a>b\Rightarrow\mathrm{dep}(a)\ge\mathrm{dep}(b)$，主解法直接比 $a,b$，不必先算 `bit_length`；两种写法都对，但别在同一份代码里混用两种判断而写错分支。
6. **「加边—求环—删边」是无状态的**：每次查询结束后图恢复成树，查询之间互不影响，无需按序模拟、也无需记忆任何状态——三步合起来就是一个纯公式计算。
