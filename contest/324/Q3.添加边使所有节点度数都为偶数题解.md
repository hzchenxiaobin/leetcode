# LeetCode 添加边使所有节点度数都为偶数 题解

## 1. 题目概述

- **标题 / 题号**：添加边使所有节点度数都为偶数（#2508，hard）
- **链接**：https://leetcode.cn/problems/add-edges-to-make-degrees-of-all-nodes-even/
- **来源**：LeetCode 第 324 场周赛 Q3
- **难度**：困难
- **标签**：图、哈希表、奇偶分析、分类讨论

**题意**：给定 $n$ 个节点（编号 $1\sim n$）的无向图与边集 `edges`（无重边、无自环，**不一定连通**）。允许**至多添加 2 条**新边（同样不得产生重边或自环），问能否使**所有节点的度数都变为偶数**，能则返回 `true`。

**约束**：

- $3 \le n \le 10^5$
- $2 \le \text{edges.length} \le 10^5$
- $1 \le a_i, b_i \le n$，$a_i \ne b_i$，无重边

> 💡 本题另有[每日题解 2508](../../solution/2501-2600/2508_添加边使所有节点度数都为偶数.md)，与本文互为印证；本文按周赛复盘视角展开，重点是「奇点计数」这条不变量的提炼过程、引理-定理式证明，以及 $k=2$ 直连被占用时的「借道」构造。

## 2. 示例

**示例 1**

```text
输入：n = 5, edges = [[1,2],[2,3],[3,4],[4,2],[1,4],[2,5]]
输出：true
解释：各点度数 = [2,4,2,3,1]，奇点为 4、5；
      边 (4,5) 不存在，直连这一条边即可全偶。
```

**示例 2**

```text
输入：n = 4, edges = [[1,2],[3,4]]
输出：true
解释：四点度数全为 1（奇），k = 4；
      取配对 (1,3)+(2,4)，两条边均不存在，加上后度数全为 2。
```

**示例 3**

```text
输入：n = 4, edges = [[1,2],[1,3],[1,4]]
输出：false
解释：星形图，度数 = [3,1,1,1]，k = 4；
      3 种配对都含节点 1 的一条已有边，无合法配对。
```

**补充示例 4（直连被占用，借道中间点）**

```text
输入：n = 5, edges = [[1,2],[2,3],[1,3],[1,4]]
输出：true
解释：度数 = [3,2,2,1,0]，奇点为 1、4；但边 (1,4) 已存在，不能直连。
      节点 5 是孤立点，与 1、4 均不相邻，借道它加 (1,5)、(5,4)：
      度数变为 [4,2,2,2,2]，全偶。
```

## 3. 解题思路

### 3.1 暴力思路：枚举「加哪 ≤2 条边」

所有潜在新边是当前不存在的点对，共 $\binom n2 - m = O(n^2)$ 条；「加 1 条 / 加 2 条」的组合数 $O(n^4)$，每次判定还要 $O(n)$ 扫一遍度数，总计 $O(n^5)$，对 $n \le 10^5$ 完全不可行。

> ⚠️ 暴力的浪费在于**把边一条条试**，而不看每条边对全局奇偶性的净贡献。把视角从「具体加哪条边」抬升到「加完后哪些点的奇偶性被翻转」，$n^4$ 的搜索立刻坍缩成 $O(1)$ 量级的分类。

### 3.2 核心观察：奇点个数 k 的分类讨论

![核心观察：奇点个数 k 决定一切](images/wc324_q3_odd_cases_concept.svg)

记 $k$ 为**度数为奇数的节点（奇点）个数**。两条贯穿全题的性质：

1. **握手定理**：度数之和 $\sum_v \deg v = 2m$ 恒为偶，故 $k$ **必为偶数**——$k \in \{0,2,4,\dots\}$，无需讨论奇数情形。
2. **一条边恰好翻转两个端点的奇偶性**：加边 $(u,v)$ 使 $\deg u, \deg v$ 各 $+1$。对 $k$ 的净影响只有三种：两端都奇 $\Rightarrow k-2$；一奇一偶 $\Rightarrow k$ 不变（奇点搬家）；两端都偶 $\Rightarrow k+2$。**一条边至多让 $k$ 减 2**。

「至多加 2 条边」而要 $k$ 归零，立即得到硬性门槛 $k \le 4$。逐档讨论：

| $k$ | 结论 | 构造 |
|------|------|------|
| $0$ | `true` | 什么都不加 |
| $2$（奇点 $u,v$） | 看 $(u,v)$ 是否已有 | 非边 → 直连 1 条；已是边 → 借道中间点 $x$ 加 $(u,x),(x,v)$ 两条 |
| $4$（奇点 $a,b,c,d$） | 看 3 种配对 | 任一配对的两条边均为非边 → 加这 2 条 |
| $\ge 6$ | `false` | 两条边至多消 4 个奇点 |

其中 $k=2$ 的「借道」是本题最隐蔽的分支：$(u,v)$ 已是边时不能重加，但可以用一个与 $u,v$ **都不相邻**的中间点 $x$ 兜一圈——$x$ 的度数 $+2$ 奇偶不变，$u,v$ 各翻一次变偶。$k=4$ 则没有类似退路：两条边若有公共端点，该端点被翻两次仍奇，必有奇点修不完，所以**两条新边必须不重不漏地覆盖 4 个奇点**（完美匹配），只有 3 种配对可查。

### 3.3 算法流程

![算法流程：按奇点个数 k 分类处理](images/wc324_q3_decision_flow.svg)

1. 一次遍历 `edges` 统计 `deg[]`，同时把边（无序对）存入哈希集合。
2. 收集奇点 `odd`，得 $k$。
3. $k > 4 \Rightarrow$ `false`；$k = 0 \Rightarrow$ `true`。
4. $k = 2$：一次哈希查询判断 $(u,v)$；若已存在，扫 $x = 1..n$ 找与 $u,v$ 均不相邻的点。
5. $k = 4$：逐一检查 3 种配对，每条边查一次哈希集合。

### 3.4 示例演算

![示例演算：k=4 的成与败](images/wc324_q3_walkthrough.svg)

| 输入 | 度数 | 奇点 | 判定路径 | 答案 |
|------|------|------|----------|------|
| 示例 1 | $[2,4,2,3,1]$ | $4,5$ | $k=2$，$(4,5)$ 非边 → 直连 | true |
| 示例 2 | $[1,1,1,1]$ | $1,2,3,4$ | $k=4$，配对 $(1,3)+(2,4)$ 均非边 | true |
| 示例 3 | $[3,1,1,1]$ | $1,2,3,4$ | $k=4$，3 种配对全被星心 1 占用 | false |
| 补充 4 | $[3,2,2,1,0]$ | $1,4$ | $k=2$，$(1,4)$ 已有 → 借道孤立点 5 | true |

## 4. 算法细节

1. **边的哈希存储**：无向边按无序对存——Python 把 `(a,b)`、`(b,a)` 两个方向都塞进 `set`；C++ 按 $\min(a,b)\cdot(n+1)+\max(a,b)$ 编码成 `long long` 存 `unordered_set`，查询 $O(1)$。
2. **$k=2$ 的直连判定**：`odd` 里恰是 $u,v$，一次哈希查询即知 $(u,v)$ 是否已有。
3. **$k=2$ 的中间点扫描**：$x$ 需满足 $x \ne u, v$ 且 $(u,x),(x,v)$ 均非边，**$x$ 自身度数的奇偶无所谓**（它被翻两次）。$x$ 从 $1$ 到 $n$ 顺序扫，每个 $x$ 两次哈希查询，共 $O(n)$。
4. **鸽笼剪枝（可选）**：此分支中 $(u,v)$ 已是边，故 $u,v \in N(u) \cup N(v)$；若 $\deg u + \deg v < n$，则必有 $x$ 落在两邻集并集之外，直接 `true`，省去扫描。竞赛现场直接扫更稳，不容易写错。
5. **$k=4$ 的三种配对**：设奇点 $a,b,c,d$，配对为 $\{(a,b),(c,d)\}$、$\{(a,c),(b,d)\}$、$\{(a,d),(b,c)\}$，逐一检查两条边是否都查无此边，**三种必须全查**。
6. **连通性无关**：判定与构造只看各点度数的奇偶，图是否连通不影响任何一步——题面的「不一定连通」是心理烟雾，别往并查集方向跑。

## 5. 正确性证明

**引理 1（握手定理）**：任意无向图中，度数为奇数的节点个数 $k$ 为偶数。

**证明**：度数总和 $\sum_v \deg v = 2m$ 为偶数。奇点的度数均为奇数，而若干奇数之和为偶数当且仅当项数为偶，故 $k$ 为偶。∎

**引理 2（单边奇偶效应）**：添加一条边 $(x,y)$ 后，恰好 $x,y$ 的度数奇偶性翻转，其余节点不变；因此一条边使 $k$ 的变化量 $\in \{-2, 0, +2\}$，且取 $-2$ 当且仅当两端均为奇点。

**证明**：$\deg x, \deg y$ 各增加 $1$，奇偶翻转；其余度数不动。按 $x,y$ 的奇偶组合分三种情形直接读出 $k$ 的变化量。∎

**引理 3（可行方案的刻画）**：设添加的边集为 $E'$（$|E'| \le 2$），则「添加后所有点度数为偶」当且仅当「以 $E'$ 中的边作为端点出现**奇数次**的节点集合，恰为原图的奇点集合 $S$」。

**证明**：逐点叠加引理 2：每点的最终奇偶 $=$ 原奇偶 $\oplus$（该点在 $E'$ 中作为端点的次数 $\bmod 2$）。全为偶 $\iff$ 每点的端点次数奇偶性与其原度数奇偶性相反，即奇数次端点的集合 $= S$。∎

**定理（判定条件）**：设原图奇点集 $S$，$k = |S|$，则答案为 `true` 当且仅当下列之一成立：

1. $k = 0$；
2. $k = 2$，$S = \{u,v\}$，且 $(u,v)$ 非已有边，**或**存在 $x \notin \{u,v\}$ 使 $(u,x),(x,v)$ 均非已有边；
3. $k = 4$，$S = \{a,b,c,d\}$，且三种配对 $\{(a,b),(c,d)\}$、$\{(a,c),(b,d)\}$、$\{(a,d),(b,c)\}$ 中至少一种的两条边均非已有边。

**证明**：

（充分性）按各情形直接构造：情形 1 不加边；情形 2 加 $(u,v)$ 一条，或加 $(u,x),(x,v)$ 两条；情形 3 加某合法配对的两条边。由引理 3，这些构造中被翻转奇数次的点集恰为 $S$，故添加后全偶。合法性逐项核对：端点互异（无自环）、所加边均为非已有边（无重边）、边数 $\le 2$。

（必要性）设某可行方案加了边集 $E'$，$|E'| \le 2$。由引理 3，$S$ 中每点恰为 $E'$ 的奇数次端点，$S$ 外每点为偶数次端点。把「一条边贡献 2 个端点名额」记入账：$E'$ 至多 2 条边，共至多 **4 个名额**；无自环保证每点在每条边中至多占 1 个名额，即每点至多占 2 个名额。

- **$k \ge 6$ 不可能**：$S$ 中每点至少占 1 个名额，需 $k \le 4$。名额不够，无解。
- **$k = 4$**：$S$ 中每点占奇数个名额，而每点至多 2 个，故各恰占 1 个，4 个名额用满——两条边端点互不相同，且恰为 $S$ 的一个完美匹配，即三种配对之一；又所加边不能与已有边重合，故该配对两条边均非已有边。这正是情形 3 的形式。
- **$k = 2$**：$u,v$ 各恰占 1 个名额（各至多 2、须为奇数）。若 $|E'| = 1$，仅 2 个名额恰被 $u,v$ 占用，该边即 $(u,v)$ 且为非已有边。若 $|E'| = 2$，剩 2 个名额：若分属两个不同点 $y \ne z$（$y,z \notin \{u,v\}$，因 $u,v$ 已各恰占 1 个），则 $y,z$ 各占 1 个名额、成为奇数次端点，但 $y,z \notin S$，与引理 3 矛盾；若某个名额属于 $u$（或 $v$），则 $u$ 占 2 个名额为偶数次端点，同样矛盾。故两个名额必同属一点 $x \notin \{u,v\}$，两条边为 $(u,x)$ 与 $(x,v)$，且均为非已有边。∎

> 💡 必要性论证的关键是**名额计数**：$|E'| \le 2$ 意味着至多 4 个端点名额，而 $S$ 中每点必须占奇数个（至少 1 个）。$k=4$ 时名额刚好用尽、被迫成为完美匹配；$k=2$ 时余下的 2 个名额只能成对塞给同一个中间点——这正是「借道」构造唯一性的来源，也说明算法没有漏掉任何方案。

## 6. 复杂度分析

- **时间复杂度**：$O(n + m)$。统计度数与建哈希集合 $O(m)$；收集奇点 $O(n)$；$k=2$ 的中间点扫描 $O(n)$ 次哈希查询；$k=4$ 恒定 6 次查询。
- **空间复杂度**：$O(m)$。度数数组 $O(n)$、边哈希集合 $O(m)$，后者占主导。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool isPossible(int n, vector<vector<int>>& edges) {
        vector<int> deg(n + 1, 0);
        unordered_set<long long> es;
        for (auto& e : edges) {
            deg[e[0]]++, deg[e[1]]++;
            es.insert((long long)min(e[0], e[1]) * (n + 1) + max(e[0], e[1]));
        }
        vector<int> odd;
        for (int i = 1; i <= n; i++)
            if (deg[i] & 1) odd.push_back(i);

        auto has = [&](int u, int v) {
            return es.count((long long)min(u, v) * (n + 1) + max(u, v));
        };

        int k = odd.size();
        if (k > 4) return false;
        if (k == 0) return true;
        if (k == 2) {
            int u = odd[0], v = odd[1];
            if (!has(u, v)) return true;
            for (int x = 1; x <= n; x++)
                if (x != u && x != v && !has(u, x) && !has(x, v))
                    return true;
            return false;
        }
        int a = odd[0], b = odd[1], c = odd[2], d = odd[3];
        return (!has(a, b) && !has(c, d))
            || (!has(a, c) && !has(b, d))
            || (!has(a, d) && !has(b, c));
    }
};
```

### Python

```python
class Solution:
    def isPossible(self, n: int, edges: List[List[int]]) -> bool:
        deg = [0] * (n + 1)
        es = set()
        for a, b in edges:
            deg[a] += 1
            deg[b] += 1
            es.add((a, b))
            es.add((b, a))

        odd = [i for i in range(1, n + 1) if deg[i] & 1]
        k = len(odd)
        if k > 4:
            return False
        if k == 0:
            return True
        if k == 2:
            u, v = odd
            if (u, v) not in es:
                return True
            return any(x != u and x != v
                       and (u, x) not in es and (x, v) not in es
                       for x in range(1, n + 1))

        a, b, c, d = odd
        return ((a, b) not in es and (c, d) not in es) \
            or ((a, c) not in es and (b, d) not in es) \
            or ((a, d) not in es and (b, c) not in es)
```

## 8. 边界情况与易错点

1. **$k=2$ 且 $(u,v)$ 已是边**：本题头号坑。漏掉「借道」分支会对这类输入误判 `false`；反过来，借道的两条边 $(u,x),(x,v)$ 也必须查非已有边，否则重边。完全图 $K_4$ 是极端反例：所有点对都是已有边，$k=4$ 但一条边都加不了 → `false`。
2. **$k=4$ 只查了一种配对**：三种配对必须全查——某一种被占用不代表其余也被占用（示例 2 中 $(1,2)+(3,4)$ 被占用但 $(1,3)+(2,4)$ 可用）。只按「排序后相邻配对」查一种会被构造数据卡掉。
3. **中间点 $x$ 的合法性**：$x \ne u, x \ne v$（防自环），且与 $u,v$ 均不相邻（防重边）。**孤立点**（度 0）是最好的中间点，别把它排除在外。
4. **无向边哈希的姿势**：Python 存两个方向，或查询前 `min/max` 归一化；C++ 用 `min*(n+1)+max` 编码成 `long long`——只存单向会误判「非边」，用 `int` 编码会溢出（$10^5 \times 10^5$ 超 32 位）。
5. **$k$ 为奇数不必处理**：握手定理保证 $k$ 恒偶，`if k % 2: return False` 属死代码；写了无害，但别指望它救逻辑。
6. **「至多 2 条」含 0 条**：$k = 0$ 直接 `true`，不要漏判。
7. **别被「不连通」带偏**：无需并查集或 BFS，度数奇偶与连通性无关；而且中间点 $x$ 完全可以在别的连通分量里（如补充示例 4 的孤立点）。
