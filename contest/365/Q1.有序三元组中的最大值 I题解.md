# LeetCode 有序三元组中的最大值 I 题解

## 1. 题目概述

- **标题 / 题号**：有序三元组中的最大值 I（#2873，easy）
- **链接**：https://leetcode.cn/problems/maximum-value-of-an-ordered-triplet-i/
- **来源**：LeetCode 第 365 场周赛 Q1
- **难度**：简单
- **标签**：数组、枚举、前后缀分解

**题意**：给定下标从 0 开始的整数数组 `nums`，在所有满足 $i < j < k$ 的三元组 $(i, j, k)$ 中找出最大值并返回。三元组的值定义为 $(nums[i] - nums[j]) \times nums[k]$；若所有满足条件的三元组的值都是负数，返回 $0$。

**约束**：

- $3 \le nums.length \le 100$
- $1 \le nums[i] \le 10^6$

> 💡 $n \le 100$，$O(n^3)$ 暴力只有约 $1.6 \times 10^5$ 个三元组，赛时可以直接三重循环。但同场 Q2（#2874）把 $n$ 放大到 $10^5$，一次写对 $O(n)$ 才是"一份代码过两题"的最短路径。

## 2. 示例

**示例 1**

```text
输入：nums = [12,6,1,2,7]
输出：77
解释：三元组 (0, 2, 4) 的值 = (nums[0] - nums[2]) * nums[4] = (12 - 1) * 7 = 77，
可以证明不存在值大于 77 的有序三元组。
```

**示例 2**

```text
输入：nums = [1,10,3,4,19]
输出：133
解释：三元组 (1, 2, 4) 的值 = (nums[1] - nums[2]) * nums[4] = (10 - 3) * 19 = 133。
```

**示例 3（全负）**

```text
输入：nums = [1,2,3]
输出：0
解释：唯一的三元组 (0, 1, 2) 的值为 (1 - 2) * 3 = -3 < 0，故返回 0。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有 $i < j < k$，计算 $(nums[i] - nums[j]) \times nums[k]$ 取最大值，再与 $0$ 取 $\max$。$n \le 100$ 时三元组共 $\binom{100}{3} \approx 1.6 \times 10^5$ 个，瞬间跑完，Q1 数据范围下完全够用。

缺点：无法推广到 Q2（$n \le 10^5$，$O(n^3)$ 约 $1.7 \times 10^{14}$ 必然超时），且三重循环里的乘法必须用 64 位整数（见 §8）。

### 3.2 核心观察：固定中间的 j，两边各取最大

三元组的三个位置中，$j$ 是"被减数"的位置，把它枚举掉，剩下 $i$ 和 $k$ 的最优选择就都是**确定的**：

- **$i$（加号槽位）**：$nums[i]$ 前面是 $+$，对固定的 $j$，$nums[i]$ 越大值越大 → 取**前缀最大** $preMax(j) = \max\{nums[0..j-1]\}$；
- **$k$（乘号槽位）**：$nums[k]$ 是乘数，且约束保证 $nums[k] \ge 1 > 0$ → 当差值为正时，$nums[k]$ 越大值越大 → 取**后缀最大** $sufMax(j) = \max\{nums[j+1..n-1]\}$；
- **差值非正直接跳过**：若 $preMax(j) - nums[j] \le 0$，则对一切 $i < j$ 都有 $nums[i] - nums[j] \le 0$，该 $j$ 贡献的所有三元组值 $\le 0$，不可能超过兜底的 $0$。

![固定中间 j 的前后缀分解](images/wc365_q1_fix_middle_concept.svg)

> 💡 一句话：**答案 = $\max\big(0,\ \max_{j} (preMax(j) - nums[j]) \times sufMax(j)\big)$**。所有元素非正的麻烦情况被"返回 0"的兜底一口吃掉。

### 3.3 算法流程

**两遍扫描版**（本文主推，结构最清晰）：

1. 从右往左预处理后缀最大数组：$sufMax[k] = \max(sufMax[k+1],\ nums[k])$；
2. 从左往右枚举 $j = 1, \dots, n-2$，动态维护 $preMax = \max(nums[0..j-1])$；
3. 用候选值 $(preMax - nums[j]) \times sufMax[j+1]$ 更新答案，$ans$ 初始为 $0$；
4. 返回 $ans$（全负时自然返回 $0$，无需特判）。

**一遍扫描版**（$O(1)$ 空间，直接可过 Q2）：把当前遍历位置 $x$ 当作 $k$，同时维护历史最大差值 $maxDiff = \max_{i<j<x}(preMax - nums[j])$，候选值即 $maxDiff \times x$；每轮**先用后更新** $maxDiff$ 与 $preMax$。

### 3.4 示例演算

以示例 1 `nums = [12,6,1,2,7]` 走一遍两遍扫描版：

| $j$ | $preMax$ | $nums[j]$ | 差值 | $sufMax$ | 候选值 |
|-----|----------|-----------|------|----------|--------|
| 1 | 12 | 6 | 6 | 7 | 42 |
| 2 | 12 | 1 | **11** | 7 | **77** |
| 3 | 12 | 2 | 10 | 7 | 70 |

$ans = \max(0, 42, 77, 70) = 77$，对应三元组 $(i, j, k) = (0, 2, 4)$：$(12 - 1) \times 7 = 77$ ✓

## 4. 算法细节

1. **preMax 的更新时机**：先用当前 $j$ 计算候选值，再把 $nums[j]$ 并入 $preMax$——顺序颠倒会让 $j$ 自己充当 $i$，差值恒为 $0$。
2. **sufMax 查询的是区间 $[j+1, n-1]$**：即预计算数组的 $sufMax[j+1]$，注意别把 $nums[j]$ 混进乘数侧的区间。
3. **$ans$ 初值为 $0$**：天然实现"全负返回 0"，省去专门特判。
4. **64 位乘法**：最大候选 $(10^6 - 1) \times 10^6 \approx 10^{12}$，超出 `int` 上限（约 $2.1 \times 10^9$），C++ 中差值要先转 `long long` 再相乘（官方签名返回值就是 `long long`）。
5. **$j$ 的枚举范围是 $[1, n-2]$**：左边至少留一个 $i$、右边至少留一个 $k$；$n = 3$ 时仅有 $j = 1$ 一个位置。

## 5. 正确性证明

约定 $preMax(j) = \max\{nums[i] : 0 \le i < j\}$（$j \ge 1$），$sufMax(j) = \max\{nums[k] : j < k \le n-1\}$（$j \le n-2$）。

**引理 1（差值为正时的上界）**：对任意满足 $i < j < k$ 且 $nums[i] > nums[j]$ 的三元组，有 $(nums[i] - nums[j]) \times nums[k] \le (preMax(j) - nums[j]) \times sufMax(j)$。

**证明**：由定义 $preMax(j) \ge nums[i]$，$sufMax(j) \ge nums[k]$；且两个因子均非负：$nums[i] - nums[j] > 0$，$nums[k] \ge 1 > 0$。两个非负因子分别放大后乘积不减。∎

**引理 2（差值非正时无贡献）**：若 $i < j < k$ 且 $nums[i] \le nums[j]$，则 $(nums[i] - nums[j]) \times nums[k] \le 0$。

**证明**：差值 $\le 0$ 而 $nums[k] \ge 1 > 0$，故乘积 $\le 0 \le ans$（$ans$ 初值为 $0$），这类三元组不可能超过算法返回值。∎

**引理 3（候选值可达）**：每个候选值 $(preMax(j) - nums[j]) \times sufMax(j)$ 都等于某个合法三元组的值。

**证明**：取 $i^* \in [0, j)$ 使 $nums[i^*] = preMax(j)$，取 $k^* \in (j, n)$ 使 $nums[k^*] = sufMax(j)$，则 $i^* < j < k^*$ 是合法三元组，且其值恰为该候选值。∎

**定理**：算法返回 $\max\big(0,\ \max_{i<j<k}(nums[i] - nums[j]) \times nums[k]\big)$，即题目所求。

**证明**：由引理 3，候选值集合包含于三元组值集合，故 $ans = \max(0, \text{候选值最大值}) \le \max(0, \text{三元组值最大值})$。反之，设三元组值的最大值为 $v$：若 $v > 0$，则取得 $v$ 的三元组差值为正，由引理 1，其对应 $j$ 的候选值 $\ge v$，故 $ans \ge v$；若 $v \le 0$，则 $ans \ge 0 \ge v$。两个方向合并得 $ans = \max(0, v)$。∎

## 6. 复杂度分析

- **时间复杂度**：暴力 $O(n^3)$（$n \le 100$ 时约 $1.6 \times 10^5$ 次运算，瞬间完成）；优化版两遍扫描 $O(n)$，一遍扫描版同样 $O(n)$。
- **空间复杂度**：暴力 $O(1)$；两遍扫描版需 $O(n)$ 的后缀最大数组；一遍扫描版仅 $O(1)$ 额外空间。

## 7. 参考代码

### C++

```cpp
// O(n^3) 暴力：Q1 数据范围下的赛时最短路径
class Solution {
public:
    long long maximumTripletValue(vector<int>& nums) {
        int n = nums.size();
        long long ans = 0;
        for (int i = 0; i < n; i++)
            for (int j = i + 1; j < n; j++)
                for (int k = j + 1; k < n; k++)
                    ans = max(ans, (long long)(nums[i] - nums[j]) * nums[k]);
        return ans;
    }
};
```

```cpp
// O(n) 前后缀分解：枚举中间 j，可直接过 Q2（#2874）
class Solution {
public:
    long long maximumTripletValue(vector<int>& nums) {
        int n = nums.size();
        vector<long long> sufMax(n);
        sufMax[n - 1] = nums[n - 1];
        for (int k = n - 2; k >= 0; k--)
            sufMax[k] = max(sufMax[k + 1], (long long)nums[k]);
        long long ans = 0, preMax = nums[0];
        for (int j = 1; j < n - 1; j++) {
            ans = max(ans, (preMax - nums[j]) * sufMax[j + 1]);
            preMax = max(preMax, (long long)nums[j]);
        }
        return ans;
    }
};
```

```python
class Solution:
    def maximumTripletValue(self, nums: List[int]) -> int:
        n = len(nums)
        suf_max = [0] * n
        suf_max[-1] = nums[-1]
        for k in range(n - 2, -1, -1):
            suf_max[k] = max(suf_max[k + 1], nums[k])
        ans, pre_max = 0, nums[0]
        for j in range(1, n - 1):
            ans = max(ans, (pre_max - nums[j]) * suf_max[j + 1])
            pre_max = max(pre_max, nums[j])
        return ans
```

## 8. 边界情况与易错点

1. **int 溢出（本题最大的坑）**：$(10^6 - 1) \times 10^6 \approx 10^{12}$，C++ 用 `int` 相乘直接得到错误结果；差值必须在乘法**之前**转 `long long`。Python 无此问题。
2. **全负返回 0**：`ans` 初值取 0 即可兜底；不要只取候选最大值而忘了与 0 比较。
3. **$n = 3$**：只有唯一三元组 $(0, 1, 2)$，$j$ 只取 1；若其值为负，答案为 0（示例 3）。
4. **preMax 更新顺序**：先算候选再并入 $nums[j]$，否则 $i$ 与 $j$ 重合，差值恒为 0。
5. **元素全为正**：约束 $nums[i] \ge 1$ 保证乘数恒正，"差值为正取后缀最大"的贪心方向才成立；若元素可负，正差值配后缀最大、负差值配后缀最小，需额外维护后缀最小数组。
6. **差值恰为 0**：候选值为 0，与兜底值相同，不影响答案，无需特判。
