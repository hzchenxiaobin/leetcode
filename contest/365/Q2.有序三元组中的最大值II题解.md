# LeetCode 有序三元组中的最大值 II 题解

## 1. 题目概述

- **标题 / 题号**：有序三元组中的最大值 II（#2874，medium）
- **链接**：https://leetcode.cn/problems/maximum-value-of-an-ordered-triplet-ii/
- **来源**：LeetCode 第 365 场周赛 Q2
- **难度**：中等
- **标签**：数组、前后缀分解、一次遍历

**题意**：给定下标从 0 开始的整数数组 `nums`，在所有满足 $i < j < k$ 的下标三元组 $(i, j, k)$ 中，求 $(nums[i] - nums[j]) \times nums[k]$ 的最大值；若所有三元组的值都是负数，返回 $0$。

**约束**：

- $3 \le nums.length \le 10^5$
- $1 \le nums[i] \le 10^6$

> 💡 本题与同场 [Q1（#2873 有序三元组中的最大值 I）](https://leetcode.cn/problems/maximum-value-of-an-ordered-triplet-i/) **题面一字不差**，唯一区别是 $n$ 从 $100$ 放大到 $10^5$。这种「I/II 姊妹题」是 LeetCode 周赛的常见编排：Q1 给暴力留活路，Q2 逼你把做法升级到能扛住大数据。**赛时最优策略是先读两题、直接写通用版，一份代码过两题**。本题另有[每日题解 2874](../../solution/2801-2900/2874_有序三元组中的最大值II.md)：与本文互为印证；本文侧重赛场视角——完整的**优化阶梯**、一遍扫描的**角色切换**模型与基于**循环不变式**的严谨证明。

## 2. 示例

**示例 1**

```text
输入：nums = [12,6,1,2,7]
输出：77
解释：三元组 (0, 2, 4) 的值 = (nums[0] - nums[2]) * nums[4] = (12 - 1) * 7 = 77，
可以证明不存在值更大的有序三元组。
```

**示例 2**

```text
输入：nums = [1,10,3,4,19]
输出：133
解释：三元组 (1, 2, 4) 的值 = (nums[1] - nums[2]) * nums[4] = (10 - 3) * 19 = 133。
```

**示例 3（全负）**

```text
输入：nums = [1,2,3]
输出：0
解释：唯一的三元组 (0, 1, 2) 的值为 (1 - 2) * 3 = -3 < 0，故返回 0。
```

## 3. 解题思路

### 3.1 暴力思路：三重循环

枚举全部 $\binom{n}{3}$ 个三元组逐一计算取最大。$n \le 100$（Q1）时约 $1.6 \times 10^5$ 个，瞬间通过；本题 $n \le 10^5$ 时约 $1.7 \times 10^{14}$ 次运算，**必然超时**——这正是 Q2 存在的意义。

### 3.2 中间台阶：枚举 (i, j) 对 + 预处理后缀最大，$O(n^2)$

先退掉一个自由度：固定前两个下标 $(i, j)$（$i < j$），第三个下标 $k$ 的最优选择是一眼可见的——因为 $nums[k] \ge 1$ 恒正，当差值为正时 $k$ 取 $j$ 之后的**后缀最大**即可：

$$\text{ans} = \max_{i < j}\ (nums[i] - nums[j]) \times sufMax(j)$$

其中 $sufMax(j) = \max(nums[j{+}1..n{-}1])$，可从右往左 $O(n)$ 预处理。剩下双重循环枚举 $(i, j)$ 对。

可惜 $n = 10^5$ 时约 $10^{10}$ 次运算（C++ 每秒约 $10^8 \sim 10^9$ 次），**仍然超时**。这个台阶在 Q1 的 $n \le 100$ 下绰绰有余、在本题下不够看，它的真正价值是揭示了优化方向：**两个因子各自独立取最值**。

### 3.3 核心观察：固定中间的 j，两侧解耦成前后缀分解，$O(n)$

把枚举对象从「对 $(i, j)$」换成**中间下标 $j$**：$i$ 只出现在第一个因子里、$k$ 只出现在第二个因子里，约束 $i < j < k$ 恰好被劈成互不重叠的两半——

- **$i$ 侧**：$nums[i]$ 带 $+$ 号 → 取**前缀最大** $preMax(j) = \max(nums[0..j-1])$；
- **$k$ 侧**：$nums[k] \ge 1$ 恒正 → 差值为正时取**后缀最大** $sufMax(j)$；
- **差值非正直接跳过**：此时该 $j$ 的所有候选 $\le 0$，压不过兜底的 $0$。

$$\text{ans} = \max\Big(0,\ \max_{1 \le j \le n-2}\ \big(preMax(j) - nums[j]\big) \times sufMax(j)\Big)$$

后缀最值数组一遍预计算、前缀最值滚动维护，总时间 $O(n)$、空间 $O(n)$。完整推导、配图与逐格演算见[本场 Q1 题解](Q1.有序三元组中的最大值%20I题解.md)，此处只回收结论。

![优化阶梯](images/wc365_q2_optimization_ladder.svg)

### 3.4 再进一步：一遍扫描、$O(1)$ 空间——每个元素依次扮演 k → j → i

前后缀分解里，前缀最大本就在滚动维护，真正占空间的是后缀最大数组。换个视角把它也消掉：**按 $k$ 从左到右扫描，把 $i$、$j$ 的信息全部聚合进两个滚动变量**——

- $preMax$：$\max(nums[0..k-1])$，候选的 $i$（**一层聚合**）；
- $maxDiff$：$\max_{i < j < k}(nums[i] - nums[j])$，历史最优差（**两层聚合**）；
- $ans$：三元组最优值（**三层聚合**）。

每来一个新元素 $x = nums[k]$，按固定顺序执行三步：

1. **结算**（$x$ 当 $k$）：$ans \leftarrow \max(ans,\ maxDiff \times x)$；
2. **配对**（$x$ 当 $j$）：$maxDiff \leftarrow \max(maxDiff,\ preMax - x)$；
3. **入池**（$x$ 当 $i$）：$preMax \leftarrow \max(preMax,\ x)$。

聚合值层层复用：$ans$ 用「已算好的 $maxDiff$」，$maxDiff$ 用「已算好的 $preMax$」，像一条流水线。这本质是 [121. 买卖股票的最佳时机](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock/) 的两层嵌套：121 一次遍历求 $\max(nums[j] - nums[i])$（正是 $maxDiff$），本题再把历史最大差乘上后面的一个数。

![一遍扫描的角色切换](images/wc365_q2_role_switch_flow.svg)

> ⚠️ 顺序绝对不能乱：必须**先结算、再入池**。三步消费的都是**上一轮**的状态值：若把第 ② 步提前，$x$ 会用「包含自己的 $preMax$」减自己（相当于 $i = j$）；若把第 ③ 步提前，$x$ 会自己和自己配对（$j = k$）。任何调换都等于悄悄放宽了 $i < j < k$ 的约束。

### 3.5 示例演算

以示例 1 `nums = [12, 6, 1, 2, 7]` 走一遍（初始 $preMax = 12$、$maxDiff = -\infty$、$ans = 0$）：

| 轮次 $k$ | $x$ | ① 候选 $maxDiff \times x$ | $ans$ | ② 后 $maxDiff$ | ③ 后 $preMax$ |
|---|---|---|---|---|---|
| 初始 | — | — | $0$ | $-\infty$ | $12$ |
| 1 | 6 | （无效） | $0$ | $6$ | $12$ |
| 2 | 1 | $6 \times 1 = 6$ | $6$ | $\textbf{11}$（$=12-1$） | $12$ |
| 3 | 2 | $11 \times 2 = 22$ | $22$ | $11$ | $12$ |
| 4 | 7 | $11 \times 7 = \textbf{77}$ | $\textbf{77}$ | $11$ | $12$ |

$maxDiff$ 在 $k=2$ 处定格为 $12 - 1 = 11$（对应 $i=0,\ j=2$），此后在 $k=4$ 处乘上 $7$ 得到 $77$。中途 $k=3$ 时 $11 \times 2 = 22$ 只是临时答案——**先攒出差值，再等最大的乘数**，两段最优不必相邻。

![示例 1 的完整演算](images/wc365_q2_example_walkthrough.svg)

示例 2 `[1,10,3,4,19]` 同理：$maxDiff$ 在 $k=2$ 处变为 $10 - 3 = 7$，最终 $7 \times 19 = 133$。示例 3 `[1,2,3]` 递增：$maxDiff = 1 - 2 = -1$ 恒负，任何候选都压不过初值 $0$，返回 $0$。

## 4. 算法细节

1. **`maxDiff` 初值必须「足够小」**：C++ 用 `INT_MIN`——它以 `long long` 承载，乘上 $x \le 10^6$ 后约 $-2.1 \times 10^{15}$，仍在 64 位范围内且必然被 `max` 淘汰；**千万不要用 `LLONG_MIN`**（约 $-9.2 \times 10^{18}$，乘任何 $x \ge 1$ 直接溢出 64 位，属于未定义行为）。Python 用 `float('-inf')`，参与整数乘法得 $-\infty$，`max` 时自然出局。
2. **三步顺序**：先结算（①）再入池（②③）；② 用的是**未更新**的 `preMax`，③ 才把 $x$ 并入。见 3.4 的警告。
3. **`ans` 初值为 $0$**：天然实现「全负返回 0」，省去专门特判——语义上等价于把「不选任何三元组」视为值为 $0$ 的合法选项。
4. **64 位乘法**：最大候选 $(10^6 - 1) \times 10^6 \approx 10^{12}$，超出 `int` 上限（约 $2.1 \times 10^9$）；官方签名返回 `long long`，C++ 中差值要先转 `long long` 再相乘。Python 无此问题。
5. **扫描从 $k = 1$ 开始**：`preMax` 初值取 `nums[0]` 保证 $i$ 侧非空；第 1 轮的 ① 结算因 $maxDiff = -\infty$ 而无效，恰好对应「$k$ 左边凑不出合法对」的边界，无需特判。
6. **与前后缀分解版的关系**：一遍扫描版只是把「$j$ 两侧各取最值」重排成「按 $k$ 结算」，两版共享同一套正确性论证（见 §5），赛时可任选顺手的写法。

## 5. 正确性证明

针对一遍扫描版。约定 $P_k = \max(nums[0..k-1])$（$k \ge 1$），$D_k = \max_{0 \le i < j \le k-1}(nums[i] - nums[j])$（$k \ge 2$；$D_1 = -\infty$ 表示空集）。

**引理 1（配对分解）**：对 $k \ge 2$，$D_k = \max_{1 \le j \le k-1}\big(P_j - nums[j]\big)$。

**证明**：一方面，对每个 $1 \le j \le k-1$，取 $i^* < j$ 使 $nums[i^*] = P_j$，则 $P_j - nums[j] = nums[i^*] - nums[j]$ 是某个合法对的差，故右边 $\le D_k$。另一方面，对任意 $0 \le i < j \le k-1$，有 $nums[i] \le P_j$，故 $nums[i] - nums[j] \le P_j - nums[j] \le$ 右边。两个方向合并即得等式。∎

**引理 2（循环不变式）**：第 $k$ 轮（处理 $x = nums[k]$，$1 \le k \le n-1$）**开始时**，`preMax` $= P_k$ 且 `maxDiff` $= D_k$（`INT_MIN` 扮演 $-\infty$）。

**证明**：对 $k$ 归纳。$k = 1$：初始化 `preMax = nums[0]` $= P_1$，`maxDiff = INT_MIN` $= D_1$，成立。设第 $k$ 轮开始时结论成立。第 ② 步用**未更新的** `preMax` 计算：新 `maxDiff` $= \max(D_k,\ P_k - nums[k])$。由引理 1，$D_k = \max_{1 \le j \le k-1}(P_j - nums[j])$，而 $P_k - nums[k]$ 恰是该式 $j = k$ 的一项，故新 `maxDiff` $= \max_{1 \le j \le k}(P_j - nums[j]) = D_{k+1}$。第 ③ 步：新 `preMax` $= \max(P_k,\ nums[k]) = P_{k+1}$。即第 $k{+}1$ 轮开始时结论成立。∎

**定理**：算法返回 $\max\big(0,\ \max_{i<j<k}(nums[i] - nums[j]) \times nums[k]\big)$，即题目所求。

**证明**：分两个方向。

（≤，不高于目标）由引理 2，每轮候选为 $D_k \times nums[k]$。若 $D_k > 0$，由 $D_k$ 的定义可取实现它的对 $(i^*, j^*)$（$i^* < j^* < k$），故该候选恰是合法三元组 $(i^*, j^*, k)$ 的值；若 $D_k \le 0$，候选 $\le 0$，赢不过初值为 $0$ 且只增不减的 `ans`。故返回值 $\le \max(0, \text{三元组值的最大值})$。

（≥，不低于目标）设三元组值的最大值为 $v$。若 $v \le 0$，则返回值 $\ge 0 \ge v$。若 $v > 0$：取得 $v$ 的三元组 $(i, j, k)$ 的差值 $d = nums[i] - nums[j] > 0$（因 $nums[k] \ge 1 > 0$，非正差值乘不出正值），而 $(i, j)$ 在第 $k$ 轮开始时已是一个合法对，由引理 2 有 $D_k \ge d > 0$，于是第 $k$ 轮候选 $D_k \times nums[k] \ge d \times nums[k] = v$，即返回值 $\ge v$。

两个方向合并即得等式。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。单次线性扫描，每个元素仅 1 次乘法、2 次 `max` 比较；$n = 10^5$ 时实测毫秒级（含 $10^{12}$ 量级大乘法仍可忽略）。前后缀分解版同为 $O(n)$，多一遍预处理。
- **空间复杂度**：$O(1)$。只维护 `preMax`、`maxDiff`、`ans` 三个滚动变量；前后缀分解版需 $O(n)$ 的后缀最值数组。
- **与各级台阶对比**：暴力 $O(n^3) \approx 1.7 \times 10^{14}$、中间版 $O(n^2) \approx 10^{10}$ 均超时；两版 $O(n)$ 都能过，一遍扫描版还把空间省到 $O(1)$，且循环体最短、赛时最难写错。

## 7. 参考代码

### C++

```cpp
// 一遍扫描 O(n) / O(1)：每个元素依次扮演 k → j → i
class Solution {
public:
    long long maximumTripletValue(vector<int>& nums) {
        long long ans = 0;
        long long maxDiff = INT_MIN;   // max(nums[i] - nums[j])，i < j < k，可能为负
        int preMax = nums[0];          // max(nums[0..k-1])
        for (int k = 1; k < (int)nums.size(); k++) {
            int x = nums[k];
            ans = max(ans, maxDiff * x);                      // ① x 作 k：先结算
            maxDiff = max(maxDiff, (long long)preMax - x);    // ② x 作 j：配对入池
            preMax = max(preMax, x);                          // ③ x 作 i：最后入池
        }
        return ans;
    }
};
```

```cpp
// 前后缀分解 O(n) / O(n)：固定中间 j，与 Q1（#2873）的优化版一字不差
class Solution {
public:
    long long maximumTripletValue(vector<int>& nums) {
        int n = nums.size();
        vector<int> sufMax(n);
        sufMax[n - 1] = nums[n - 1];
        for (int k = n - 2; k >= 0; k--)
            sufMax[k] = max(sufMax[k + 1], nums[k]);
        long long ans = 0, preMax = nums[0];
        for (int j = 1; j < n - 1; j++) {
            ans = max(ans, (preMax - nums[j]) * (long long)sufMax[j + 1]);
            preMax = max(preMax, (long long)nums[j]);
        }
        return ans;
    }
};
```

```python
class Solution:
    def maximumTripletValue(self, nums: List[int]) -> int:
        ans = 0
        max_diff = float('-inf')      # max(nums[i] - nums[j])，i < j < k，可能为负
        pre_max = nums[0]             # max(nums[0..k-1])
        for x in nums[1:]:
            ans = max(ans, max_diff * x)          # ① x 作 k：先结算
            max_diff = max(max_diff, pre_max - x)  # ② x 作 j：配对入池
            pre_max = max(pre_max, x)              # ③ x 作 i：最后入池
        return ans
```

```python
class Solution:
    def maximumTripletValue(self, nums: List[int]) -> int:
        n = len(nums)
        suf_max = [0] * n
        suf_max[-1] = nums[-1]
        for k in range(n - 2, -1, -1):
            suf_max[k] = max(suf_max[k + 1], nums[k])
        ans, pre_max = 0, nums[0]
        for j in range(1, n - 1):               # j 左右两侧都要有元素
            ans = max(ans, (pre_max - nums[j]) * suf_max[j + 1])
            pre_max = max(pre_max, nums[j])
        return ans
```

## 8. 边界情况与易错点

1. **`LLONG_MIN` 隐形炸弹**：`maxDiff` 初值用 `INT_MIN` 而非 `LLONG_MIN`——后者乘任何 $x \ge 1$ 都会溢出 64 位（未定义行为），前者乘 $10^6$ 后约 $-2.1 \times 10^{15}$，安全且必然被 `max` 淘汰。Python 的 `float('-inf')` 无此烦恼。
2. **`int` 溢出（本题最大的坑）**：$(10^6 - 1) \times 10^6 \approx 10^{12}$，C++ 用 `int` 相乘直接得到错误结果；差值必须在乘法**之前**转 `long long`。Python 无此问题。
3. **三步顺序**：先结算再入池。② 提前会让 $x$ 用包含自己的 `preMax` 减自己（$i = j$），③ 提前会让 $x$ 自己配自己（$j = k$），都等于放宽了 $i < j < k$。
4. **全负返回 0**：`ans` 初值取 0 即可兜底；`maxDiff` 为负时的候选天然出局，无需特判。
5. **$n = 3$**：唯一三元组 $(0, 1, 2)$；一遍扫描中第 1 轮结算无效（$maxDiff = -\infty$）、第 2 轮用 $nums[0] - nums[1]$ 结算，恰好覆盖（示例 3）。
6. **姊妹题赛时策略**：开赛后先把 Q1/Q2 题面都读一遍，确认只差数据范围就直接写 $O(n)$ 版——Q1 的 $O(n^3)$ 暴力可作小数据对拍基准，一份验证、两题通吃。
7. **$nums[i] \ge 1$ 的隐含前提**：「两侧独立取最值 / 差值为正配后缀最大」依赖乘数恒正；若元素可负，负差值要配后缀**最小**值，需同时维护后缀最大与最小数组分类讨论。
8. **`maxDiff` 也可初始化为 0**：等价于把它钳位到 $\max(0, D_k)$——负差值的贡献本就被 `ans` 的 0 兜底压住，正确性不受影响；但显式 $-\infty$ 的语义更贴近「历史最大差」，便于讲解与排查。

**延伸思考**：把「一层聚合」的视角推广开——任何形如 $\max_{i_1 < i_2 < \cdots < i_m} F(\text{左侧聚合}_1, \dots)$ 的目标，都能按槽位逐层堆滚动变量：本题 $preMax$（一层）作差得 $maxDiff$（两层），再相乘得 $ans$（三层）；若把三元组推广为 $(nums[i] - nums[j]) \times nums[k] - nums[l]$ 等四槽位形式，只需再堆一层「三层聚合」变量即可，$O(n)$ 时间、$O(1)$ 空间的流水线结构不变。这也是状态机 DP 滚动数组压维的最简范例：$f_1 \to f_2 \to f_3$ 三条转移链，每条只依赖上一条。
