# LeetCode 删除子字符串后不同的终点 题解

## 1. 题目概述

- **标题 / 题号**：删除子字符串后不同的终点（#3694，medium）
- **链接**：https://leetcode.cn/problems/distinct-points-reachable-after-substring-removal/
- **来源**：LeetCode 第 166 场双周赛 Q3
- **难度**：中等
- **标签**：哈希表、字符串、前缀和

**题意**：给定由 `'U'`、`'D'`、`'L'`、`'R'` 组成的字符串 $s$ 与正整数 $k$，表示在二维网格上的移动：

- `'U'`：$(x,y) \to (x, y+1)$；`'D'`：$(x,y) \to (x, y-1)$；
- `'L'`：$(x,y) \to (x-1, y)$；`'R'`：$(x,y) \to (x+1, y)$。

必须**恰好删除一个长度为 $k$ 的连续子串**（删除后剩余部分按原顺序拼接），然后从 $(0,0)$ 出发依次执行剩余的所有移动。求最终能到达的**不同坐标**的个数。

**约束**：

- $1 \le s.length \le 10^5$
- $s$ 只包含 `'U'`、`'D'`、`'L'`、`'R'`
- $1 \le k \le s.length$

## 2. 示例

**示例 1**

```text
输入：s = "LUL", k = 1
输出：2
解释：删除长度为 1 的子串，得到 "UL"、"LL"、"LU" 三种；终点分别是 (-1,1)、(-2,0)、(-1,1)。
     去重后是 {(-1,1), (-2,0)}，共 2 个。
```

**示例 2**

```text
输入：s = "UDLR", k = 4
输出：1
解释：只能删掉整个串，剩余为空串，终点 (0,0)。
```

**示例 3**

```text
输入：s = "UU", k = 1
输出：1
解释：删除任一个 'U'，剩余都是 "U"，终点 (0,1)，只有 1 个不同终点。
```

## 3. 解题思路

### 3.1 暴力思路

枚举删除的起点 $l = 0, 1, \dots, n-k$，对每个 $l$ 重新执行一遍剩余 $n-k$ 步移动，得到终点并放入集合。每个候选 $O(n)$，共 $n-k+1$ 个候选，总复杂度 $O(n^2)$；$n = 10^5$ 时约 $10^{10}$ 次移动，必然超时。

### 3.2 核心观察：删除一段 = 从全程位移里减掉那一段的位移

![前缀和思想：全程位移减去被删段位移](images/bw166_q3_prefix_sums.svg)

位移是**可加的向量**：走完整个串的位移是各步位移之和，而「删除子串 $s[l..l+k-1]$」后的路径位移等于

$$\vec{T} - \bigl(\vec{P}[l+k] - \vec{P}[l]\bigr),$$

其中 $\vec{T} = \vec{P}[n]$ 是全程位移，$\vec{P}[i]$ 是从起点走完前 $i$ 步的位移（前缀和向量）。理由很直观：原本「前 $l$ 步 + 被删段 + 后面部分」的位移是 $\vec{P}[l] + (\vec{P}[l+k] - \vec{P}[l]) + (\vec{T} - \vec{P}[l+k]) = \vec{T}$；删掉中间那一段，就得到上式。

于是每个候选终点只需要一次二维前缀和相减，$O(1)$ 计算，全部候选丢进集合去重即可。

### 3.3 算法流程

![算法流程：前缀和 + 枚举 + 集合去重](images/bw166_q3_algorithm_flow.svg)

```text
1. px[i], py[i] 表示走完前 i 步的 x、y 坐标（px[0] = py[0] = 0）
2. T = (px[n], py[n])
3. seen = 空集合
4. for l = 0 .. n-k:
       终点 = (T.x - (px[l+k] - px[l]),  T.y - (py[l+k] - py[l]))
       把终点放入 seen
5. 返回 |seen|
```

### 3.4 示例演算

![示例 1 的三个候选终点](images/bw166_q3_example_walkthrough.svg)

示例 1：$s = \text{"LUL"}$，$k=1$，$n=3$。逐步位移与坐标：

| $i$（已走步数） | 0 | 1 | 2 | 3 |
|-----------------|---|---|---|---|
| 新增步 | — | L | U | L |
| $\vec{P}[i]$ | (0,0) | (-1,0) | (-1,1) | (-2,1) |

全程位移 $\vec{T} = (-2, 1)$。三个候选：

| $l$ | 被删段 | 被删段位移 $\vec P[l+1]-\vec P[l]$ | 终点 $=\vec T - $ 被删位移 |
|-----|--------|-----------------------------------|---------------------------|
| 0 | "L" | (-1, 0) | (-1, 1) |
| 1 | "U" | (0, 1) | (-2, 0) |
| 2 | "L" | (-1, 0) | (-1, 1) |

去重后 $\{(-1,1), (-2,0)\}$，共 2 个，与题面一致。

## 4. 算法细节

1. **两维分别做前缀和**：$x$ 方向只受 `'L'`/`'R'` 影响，$y$ 方向只受 `'U'`/`'D'` 影响，可以各用一个 `vector<int>`；也可以直接存 `pair` 前缀向量。
2. **枚举的是删除起点**：$l$ 从 $0$ 到 $n-k$，共 $n-k+1$ 个候选；$k=n$ 时只有 $l=0$，得到原点。
3. **去重用哈希集合**：坐标范围 $[-10^5, 10^5]$，可以编码成 `x * 200001 + y` 之类的整数键，也可以直接用 `set<pair<int,int>>`（$n \le 10^5$ 时 $O(n \log n)$ 完全够）。
4. **不需要真的构造剩余字符串**：这是从 $O(n^2)$ 降到 $O(n)$ 的关键——只做向量减法。
5. **坐标不会溢出**：$|x|, |y| \le 10^5$，`int` 足够；若用编码键要注意乘法不越界（$10^5 \times 2 \times 10^5 = 2 \times 10^{10}$ 超出 `int`，需 `long long`）。

## 5. 正确性证明

**引理 1（前缀和表示）**：对 $0 \le i \le n$，$\vec P[i]$ 等于前 $i$ 步位移之和，从而对 $0 \le l \le l+k \le n$，被删子串的位移为 $\vec P[l+k] - \vec P[l]$。

**证明**：$P[0] = \vec 0$，$P[i+1] = P[i] + \delta_{i+1}$（第 $i+1$ 步的位移向量）。对 $i$ 归纳即得 $P[i] = \sum_{t=1}^{i}\delta_t$。相减得 $\sum_{t=l+1}^{l+k}\delta_t$，正是 $s[l..l+k-1]$ 的位移。∎

**引理 2（终点公式）**：删除 $s[l..l+k-1]$ 后执行剩余移动，终点为 $\vec T - (\vec P[l+k] - \vec P[l])$。

**证明**：剩余路径的位移 = 前 $l$ 步位移 + 第 $l+k$ 步之后的位移 = $\vec P[l] + (\vec T - \vec P[l+k]) = \vec T - (\vec P[l+k] - \vec P[l])$。位移可交换相加，与原顺序无关。∎

**引理 3（候选完备）**：所有合法删除方式产生的终点都在算法的候选集合中，且候选集合中每个点都可由某种删除达到。

**证明**：合法删除就是选一个起点 $l \in [0, n-k]$，算法枚举了全部这样的 $l$，由引理 2 得到对应终点，故不遗漏；反之每个候选都由对应的 $l$ 产生，故不多余。∎

**定理**：算法返回的集合大小等于可到达的不同终点数。

**证明**：由引理 3，候选集合（含重复）与全部删除方式产生的终点（含重复）是同一个多重集合；去重后元素个数相同。∎

## 6. 复杂度分析

- **时间**：$O(n)$ 建前缀和，$O(n-k+1)$ 枚举候选，每个候选 $O(1)$ 计算 + 一次集合插入（均摊 $O(1)$ 的哈希表）。总时间 $O(n)$（若用平衡树则 $O(n \log n)$）。
- **空间**：$O(n)$。两个长度 $n+1$ 的前缀和数组；集合最多 $n-k+1$ 个不同点。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int distinctPoints(string s, int k) {
        int n = (int)s.size();
        vector<int> px(n + 1, 0), py(n + 1, 0);
        for (int i = 0; i < n; i++) {
            px[i + 1] = px[i];
            py[i + 1] = py[i];
            if (s[i] == 'L') px[i + 1]--;
            else if (s[i] == 'R') px[i + 1]++;
            else if (s[i] == 'U') py[i + 1]++;
            else py[i + 1]--;
        }
        long long tx = px[n], ty = py[n];
        set<pair<int, int>> seen;
        for (int l = 0; l + k <= n; l++) {
            int ex = (int)(tx - (px[l + k] - px[l]));
            int ey = (int)(ty - (py[l + k] - py[l]));
            seen.insert({ex, ey});
        }
        return (int)seen.size();
    }
};
```

### Python

```python
class Solution:
    def distinctPoints(self, s: str, k: int) -> int:
        n = len(s)
        px = [0] * (n + 1)
        py = [0] * (n + 1)
        for i, ch in enumerate(s):
            px[i + 1] = px[i] + (ch == 'R') - (ch == 'L')
            py[i + 1] = py[i] + (ch == 'U') - (ch == 'D')
        tx, ty = px[n], py[n]
        seen = set()
        for l in range(n - k + 1):
            seen.add((tx - (px[l + k] - px[l]), ty - (py[l + k] - py[l])))
        return len(seen)
```

## 8. 边界情况与易错点

1. **$k = n$**：只剩 $l=0$，终点是 $(0,0)$，答案 1；此时 $\vec P[n]-\vec P[0] = \vec T$，公式自动给出原点。
2. **不要真的拼字符串**：$n = 10^5$ 时 $O(n^2)$ 的字符串构造必然超时，必须用前缀和。
3. **`l + k <= n`**：循环上界是 $n-k$（含），共 $n-k+1$ 个候选；写成 `l < n - k` 会漏掉最后一个候选。
4. **BiFunction 式的布尔算术**：Python 里 `(ch == 'R') - (ch == 'L')` 依赖 `True == 1`、`False == 0`，简洁但要注意可读性；C++ 里必须写 `if/else`。
5. **集合元素的类型**：用 `pair<int,int>` 或元组，不要用字符串拼坐标（慢且易错）。
6. **方向映射别写错**：`'U'` 是 $y+1$、`'D'` 是 $y-1$、`'R'` 是 $x+1$、`'L'` 是 $x-1$，一旦写反，示例 1 会得到别的答案。
