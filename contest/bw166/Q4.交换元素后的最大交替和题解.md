# LeetCode 交换元素后的最大交替和 题解

## 1. 题目概述

- **标题 / 题号**：交换元素后的最大交替和（#3695，hard）
- **链接**：https://leetcode.cn/problems/maximize-alternating-sum-using-swaps/
- **来源**：LeetCode 第 166 场双周赛 Q4
- **难度**：困难
- **标签**：贪心、并查集、数组、排序

**题意**：给定整数数组 $nums$，其**交替和**定义为

$$nums[0] - nums[1] + nums[2] - nums[3] + \cdots = \sum_{i \text{ 为偶}} nums[i] - \sum_{i \text{ 为奇}} nums[i] .$$

再给定若干条可交换关系 $swaps[i] = [p_i, q_i]$，表示**可以任意次、任意顺序**地交换下标 $p_i$ 与 $q_i$ 上的元素。求能达到的最大交替和。

**约束**：

- $2 \le nums.length \le 10^5$
- $1 \le nums[i] \le 10^9$
- $0 \le swaps.length \le 10^5$，$0 \le p_i < q_i \le n-1$，无重复的交换对

## 2. 示例

**示例 1**

```text
输入：nums = [1,2,3], swaps = [[0,2],[1,2]]
输出：4
解释：三个下标互相连通，可任意重排为 [3,1,2]：3 - 1 + 2 = 4。
```

**示例 2**

```text
输入：nums = [1,2,3], swaps = [[1,2]]
输出：2
解释：下标 1、2 可互换，下标 0 固定。原数组交替和 1-2+3 = 2；
     换成 [1,3,2] 得 1-3+2 = 0，更小。故答案 2。
```

**示例 3**

```text
输入：nums = [1,1000000000,1,1000000000,1,1000000000], swaps = []
输出：-2999999997
解释：无任何交换，交替和 = 1 - 10⁹ + 1 - 10⁹ + 1 - 10⁹ = 3 - 3×10⁹ = -2999999997。
     注意这个值超出 int 范围，需要用 64 位整数。
```

## 3. 解题思路

### 3.1 暴力思路

每次交换只是交换两个位置的值，状态空间是所有可达排列，最坏有 $n!$ 种，无法枚举。即使只考虑「枚举所有排列」也有 $10^5!$ 量级。

直观上要回答两个问题：(1) 哪些位置之间可以互换元素？(2) 在这些可互换的位置上，怎样摆放元素能让交替和最大？

### 3.2 核心观察一：可交换关系是「连通分量内的任意置换」

![并查集把下标划成若干分量，分量内可任意重排](images/bw166_q4_dsu_components.svg)

把每个下标看作点，每条 $[p_i, q_i]$ 看作一条无向边，则：

- **同一连通分量内**：任意两个位置的元素都能互换。因为沿连通路径做相邻交换就能把值「搬运」到任意位置，而相邻换位生成整个对称群，所以分量内所有排列都可达。
- **不同连通分量之间**：元素不能跨越分量，每个分量内的元素集合（多重集）是**不变**的。

于是问题分解为：对每个分量，把它的元素任意重新摆放，使「该分量内偶数下标位置上元素之和」尽量大。

### 3.3 核心观察二：交替和 = 2 × 偶位和 − 总和

![每个分量的贡献：把最大的 E 个值放到偶数下标上](images/bw166_q4_topk_on_even.svg)

由于 $\sum_{\text{偶}} v - \sum_{\text{奇}} v = 2\sum_{\text{偶}} v - \sum_{\text{全部}} v$，而分量内元素总和固定，所以**最大化交替和等价于最大化「偶数下标位置上元素之和」**。

设某分量有 $E$ 个偶数下标、$O$ 个奇数下标，元素共 $E+O$ 个。要让偶位和最大，显然应把**最大的 $E$ 个元素放到偶数下标上**（其余放奇位）。该分量的贡献为

$$2 \cdot \text{topE} - \text{sumAll},$$

其中 $\text{topE}$ 是分量内元素降序排列的前 $E$ 个之和，$\text{sumAll}$ 是分量元素总和。把所有分量的贡献相加即为答案。

![算法流程：并查集分组 → 分量内排序取前 E 大](images/bw166_q4_algorithm_flow.svg)

### 3.4 算法流程

```text
1. 并查集合并所有 swaps 中出现的下标对
2. 按根节点把下标分组，同时记录每个分量的：
     所有元素值（列表）、偶数下标的个数 E、元素总和 sumAll
3. 对每个分量：
      把元素降序排序，取前 E 个求和 = topE
      贡献 = 2 * topE - sumAll，累加到答案
4. 返回答案（long long）
```

### 3.5 示例演算

![示例 1 与示例 2 的分量划分](images/bw166_q4_example_walkthrough.svg)

示例 1：`nums = [1,2,3]`，$swaps = [[0,2],[1,2]]$。三个下标连通成一个分量，偶数下标是 $\{0, 2\}$，故 $E=2$；元素降序 $\{3,2,1\}$，$\text{topE} = 3 + 2 = 5$，$\text{sumAll} = 6$，贡献 $2 \times 5 - 6 = 4$ ✓。

示例 2：`nums = [1,2,3]`，$swaps = [[1,2]]$。分量 $\{0\}$：$E=1$（下标 0），$\text{topE}=1$，$\text{sumAll}=1$，贡献 $2-1=1$。分量 $\{1,2\}$：下标 2 是偶位，$E=1$，元素 $\{2,3\}$，$\text{topE}=3$，$\text{sumAll}=5$，贡献 $6-5=1$。合计 2 ✓。

示例 3：无交换，每个下标自成一个分量。偶位分量贡献 $2v - v = v$，奇位分量贡献 $2 \times 0 - v = -v$，合计 $1 - 10^9 + 1 - 10^9 + 1 - 10^9$ ✓。

## 4. 算法细节

1. **并查集实现**：路径压缩 + 按秩合并，$O(n \alpha(n))$。也可以直接用 `swaps` 建图后 DFS/BFS 求连通分量，复杂度 $O(n + m)$，代码更短。
2. **按根分组**：先 `find(i)` 得到根，再用哈希表「根 → 下标列表」；C++ 里可以用 `map<int, vector<int>>` 或先对根做一次压缩再开数组。
3. **偶数下标计数 $E$**：分组时顺便统计 `i % 2 == 0` 的个数，不要事后重复遍历。
4. **排序取前 $E$ 大**：$O(s \log s)$（$s$ 为分量大小）；也可以 `nth_element` 做到期望 $O(s)$，但总量 $O(n \log n)$ 在本约束下完全够。
5. **64 位整数**：$n \le 10^5$、$nums[i] \le 10^9$，交替和绝对值可达 $10^{14}$，必须用 `long long`（Python 自动大整数）。
6. **$E = 0$ 的分量**：例如只有奇数下标的分量（可能吗？分量内只有一个下标且为奇数，或全部为奇数下标），此时 `topE = 0`，贡献就是 $-\text{sumAll}$。
7. **自环/重复边**：题面保证无重复交换对，且 $p_i < q_i$，并查集天然幂等。

## 5. 正确性证明

**引理 1（分量内任意置换可达）**：设某连通分量包含下标集合 $C$，$|C| = s$。则对 $C$ 上元素的任意排列，都存在一串允许的交换把它实现。

**证明**：取该分量的任意一棵生成树（连通性保证存在）。树上一条边对应一次允许的交换，即相邻换位。已知：连通图上的边换位集合生成整个对称群（对树作归纳：任一叶子 $u$ 与其邻点 $v$ 可换位，递归处理去掉叶子后的树，即可把任意元素搬到位）。更直接地：要把值从 $u$ 搬到 $v$，沿树上路径依次交换相邻两点的值即可，每步都是允许的交换。故任意置换可达。∎

**引理 2（分量的元素多重集不变）**：任何允许的交换都不改变任何一个分量的元素多重集。

**证明**：交换只在同一分量的两个下标之间进行（每条边两端同属一个分量），故元素不会跨分量移动；分量内的多重集因此保持不变。∎

**引理 3（分量最优贡献）**：设分量为 $C$，偶数下标个数为 $E$，元素总和为 $S$，元素降序为 $v_1 \ge v_2 \ge \cdots \ge v_s$。则分量能达到的最大交替和贡献为 $2\sum_{t=1}^{E} v_t - S$。

**证明**：分量的交替和贡献为 $2\sum_{\text{偶位}} v - S$（偶位指该分量内的偶数下标）。由引理 1，偶位上可以摆放 $C$ 中任意 $E$ 个元素，故要最大化 $\sum_{\text{偶位}} v$，等价于从 $s$ 个元素中选 $E$ 个使和最大，显然取最大的 $E$ 个，和为 $\sum_{t=1}^E v_t$。∎

**定理**：算法返回的值为所有可达重排中交替和的最大值。

**证明**：由引理 2，各分量的元素集合互不影响，全局交替和等于各分量贡献之和，故可对每个分量独立取最优（不同分量的选择互不制约）。由引理 3，算法对每个分量取到了最大贡献，求和后即为全局最大；且该上界由引理 1 可达（把每个分量按「前 $E$ 大放偶位」摆好，各分量独立实现）。故答案为最大值。∎

## 6. 复杂度分析

- **时间**：$O((n + m)\,\alpha(n) + n \log n)$。并查集合并 $O(m\,\alpha(n))$；分组 $O(n)$；每个分量排序，总计 $O(\sum s_i \log s_i) \le O(n \log n)$。$n, m \le 10^5$ 时约 $10^6 \sim 10^7$ 次操作。
- **空间**：$O(n + m)$。并查集数组 $O(n)$、分组容器 $O(n)$、图的邻接表（若用 DFS）$O(n + m)$。

## 7. 参考代码

### C++

```cpp
class Solution {
    vector<int> parent;

    int findRoot(int x) {
        while (parent[x] != x) {
            parent[x] = parent[parent[x]];   // 路径压缩
            x = parent[x];
        }
        return x;
    }

public:
    long long maxAlternatingSum(vector<int>& nums, vector<vector<int>>& swaps) {
        int n = (int)nums.size();
        parent.resize(n);
        vector<int> rk(n, 0);
        for (int i = 0; i < n; i++) parent[i] = i;
        for (const auto& e : swaps) {
            int a = findRoot(e[0]), b = findRoot(e[1]);
            if (a == b) continue;
            if (rk[a] < rk[b]) swap(a, b);
            parent[b] = a;
            if (rk[a] == rk[b]) rk[a]++;
        }
        unordered_map<int, vector<int>> groups;
        for (int i = 0; i < n; i++) groups[findRoot(i)].push_back(i);
        long long ans = 0;
        for (auto& kv : groups) {
            long long sumAll = 0;
            int evenCount = 0;
            vector<long long> vals;
            for (int i : kv.second) {
                vals.push_back(nums[i]);
                sumAll += nums[i];
                if (i % 2 == 0) evenCount++;
            }
            sort(vals.rbegin(), vals.rend());
            long long topE = 0;
            for (int t = 0; t < evenCount; t++) topE += vals[t];
            ans += 2 * topE - sumAll;
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maxAlternatingSum(self, nums: list[int], swaps: list[list[int]]) -> int:
        n = len(nums)
        parent = list(range(n))
        def find(x: int) -> int:
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x
        for a, b in swaps:
            ra, rb = find(a), find(b)
            if ra != rb:
                parent[rb] = ra
        groups = {}
        for i in range(n):
            groups.setdefault(find(i), []).append(i)
        ans = 0
        for idxs in groups.values():
            vals = [nums[i] for i in idxs]
            even_count = sum(1 for i in idxs if i % 2 == 0)
            vals.sort(reverse=True)
            ans += 2 * sum(vals[:even_count]) - sum(vals)
        return ans
```

## 8. 边界情况与易错点

1. **必须用 `long long`**：示例 3 的答案 $-2999999997$ 已经超出 `int`，用 `int` 会溢出成错误值。
2. **分量划分按「下标」而不是「值」**：并查集合并的是下标 $p_i, q_i$，不是值相等的位置。
3. **$E$ 的统计口径**：$E$ 是分量内**偶数下标**的个数，而不是偶数元素的个数。两者完全不同。
4. **降序取前 $E$ 个**：升序取前 $E$ 个会得到最小和，正好反了。
5. **`swaps` 为空**：每个下标自成一个分量，答案就是原数组的交替和（示例 3）。
6. **同一边重复出现**：题面保证不重复，但并查集对重复边天然安全；用 DFS 建图时也不受影响。
7. **排序稳定性无关**：只取和，不关心具体摆放，故无需稳定排序。
8. **Python 的 `setdefault` + `find`**：每次插入都调用 `find`，路径压缩后的均摊代价极低；若先压缩一遍再分组会更快。
