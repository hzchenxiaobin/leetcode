# LeetCode 众数频率字符 题解

## 1. 题目概述

- **标题 / 题号**：众数频率字符（#3692，easy）
- **链接**：https://leetcode.cn/problems/majority-frequency-characters/
- **来源**：LeetCode 第 166 场双周赛 Q1
- **难度**：简单
- **标签**：哈希表、字符串、计数

**题意**：给定只含小写字母的字符串 $s$。对每个整数 $k$，把「在 $s$ 中**恰好出现 $k$ 次**的字符」放在一组，称为频率为 $k$ 的**频率组**。

- **众数频率组**：包含**不同字符数最多**的那个频率组；
- 若多个频率组大小并列最大，取**频率 $k$ 更大**的那组；
- 返回该组包含的所有字符，顺序任意。

注意分组只看「出现次数」，不看出现位置；出现 0 次的字符（即没出现的字母）不参与任何分组。

**约束**：

- $1 \le s.length \le 100$
- $s$ 只包含小写英文字母

## 2. 示例

**示例 1**

```text
输入：s = "aaabbbccdddde"
输出："ab"（顺序不限）
解释：频率 a=3、b=3、c=2、d=4、e=1。
     k=1:{e} 大小 1；k=2:{c} 大小 1；k=3:{a,b} 大小 2；k=4:{d} 大小 1。
     最大组是 k=3 的 {a,b}，答案是 "ab"。
```

**示例 2**

```text
输入：s = "abcd"
输出："abcd"（顺序不限）
解释：四个字符频率都是 1，唯一频率组 k=1 包含 4 个字符，组大小 4 最大。
```

**示例 3**

```text
输入：s = "pfpfgi"
输出："fp"（顺序不限）
解释：p、f 各出现 2 次，g、i 各 1 次。k=2 的组 {p,f} 与 k=1 的组 {g,i} 都是 2 个字符，
     并列时取频率更大的 k=2，故答案是 {p,f}。
```

## 3. 解题思路

### 3.1 暴力思路

对每个字母 $c$（26 个）统计它出现几次，得到「字母 → 频率」的表；再对每个可能的频率 $k$（$1 \le k \le |s|$）扫一遍这 26 个字母，收集频率恰为 $k$ 的字母，比较大小。复杂度 $O(26 \cdot |s|)$，对 $|s| \le 100$ 完全够用。这已经是正解，问题只是如何写得干净、如何正确处理并列。

### 3.2 核心观察：一次分桶，再取最大桶

![按频率分桶：一桶一个频率组，取字符最多的桶](images/bw166_q1_frequency_groups.svg)

两个要点：

1. **频率相同的字符合并统计**：用一个长度 $|s|+1$ 的桶数组 `bucket[k]`，把所有「频率恰为 $k$」的字母都塞进第 $k$ 个桶；桶里字符的个数就是该频率组的大小。这样「找最大组」就是「找最长的桶」。
2. **并列规则天然由遍历顺序实现**：从左到右（$k$ 递增）扫桶，用「大小 $\ge$ 当前最优」来更新，$k$ 相同时**后出现的（更大的 $k$）会覆盖**先前的，正好满足「并列取较大 $k$」。

![算法流程：统计频次 → 分桶 → 取最大桶](images/bw166_q1_algorithm_flow.svg)

### 3.3 算法流程

```text
1. cnt[26] 统计每个字母出现次数
2. bucket[k] 收集「频率恰为 k」的字母（k 从 1 到 |s|）
3. best = 空桶
4. for k = 1 .. |s|:
       若 bucket[k] 非空 且 |bucket[k]| >= |best|:  best = bucket[k]
5. 把 best 里的字符合并成字符串返回
```

### 3.4 示例演算

![示例 1 与示例 3 的分桶结果对比](images/bw166_q1_example_walkthrough.svg)

示例 1 的 `s = "aaabbbccdddde"`：

| $k$ | 组内字符 | 组大小 | 是否众数 |
|-----|----------|--------|----------|
| 1 | {e} | 1 | 否 |
| 2 | {c} | 1 | 否 |
| 3 | {a, b} | 2 | **是**（唯一最大） |
| 4 | {d} | 1 | 否 |

示例 3 的 `s = "pfpfgi"`：

| $k$ | 组内字符 | 组大小 | 是否众数 |
|-----|----------|--------|----------|
| 1 | {g, i} | 2 | 否（并列但 $k$ 较小） |
| 2 | {p, f} | 2 | **是**（并列时取大 $k$） |

两组大小都是 2，按规则选 $k=2$，输出 `pf` 或 `fp` 都可以。

## 4. 算法细节

1. **桶的上界**：某字母最多出现 $|s|$ 次，桶数组开到 $|s|+1$ 即可；用 `vector<string>` 或 26 位掩码都行。
2. **只统计出现过的字母**：`cnt[i] == 0` 的字母不进任何桶，否则会出现空的 $k=0$ 组干扰比较。
3. **并列的处理方向**：题目要求「$k$ 更大的优先」，因此遍历必须**从小到大**并用 `>=` 更新；若用 `>` 就会保留较小 $k$ 的组。
4. **输出顺序不限**：按字母表顺序拼接即可，不必额外排序（`bucket` 中天然按字母顺序追加）。
5. **哈希表 vs 定长数组**：只有 26 个字母，定长数组最快；若字符集变大再换 `unordered_map<char,int>` + `map<int, vector<char>>`。

## 5. 正确性证明

**引理 1（分桶正确）**：对每个 $k \ge 1$，`bucket[k]` 恰好是频率为 $k$ 的字母集合，且其中每个字母互不相同、恰出现一次。

**证明**：外层遍历 26 个字母各一次，字母 $i$ 只在 `cnt[i] == 0` 时被跳过，否则被放入 `bucket[cnt[i]]`。故 `bucket[k]` 收集到的正是所有 `cnt[i] == k` 的字母，且每个字母只被放一次。∎

**引理 2（最大值选取正确）**：遍历结束后 `best` 是「大小最大、并列时 $k$ 最大」的桶。

**证明**：设最终最优桶为 $k^\*$。按 $k$ 递增顺序，只有当 $|bucket[k]| \ge |best|$ 时才替换。若 $k^\*$ 是大小最大的桶中 $k$ 最小者，则它被选中后不会再被更小的 $k$ 覆盖；若存在多个大小同为最大值的桶，由于更新条件是 $\ge$，最后一个（$k$ 最大）会胜出。因此 `best` 满足「大小最大」且「并列取最大 $k$」。∎

**定理**：返回的字符串恰好是众数频率组中的全部字符。

**证明**：由引理 1，`best` 是一个频率组；由引理 2，它是所有频率组中按题面规则最优的那个。最后把 `best` 中的字符拼成字符串，得到该组的全部字符，顺序任意均合法。∎

## 6. 复杂度分析

- **时间**：$O(|s| + 26 + |s|) = O(|s|)$。统计频次 $O(|s|)$；分桶 $O(26)$；扫桶 $O(|s|)$；拼接 $O(26)$。
- **空间**：$O(|s|)$。桶数组共存放至多 26 个字母，桶的个数为 $|s|+1$，可用稀疏结构降到 $O(26)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    string majorityFrequencyGroup(string s) {
        int cnt[26] = {0};
        for (char ch : s) cnt[ch - 'a']++;
        int n = (int)s.size();
        vector<string> bucket(n + 1);
        for (int i = 0; i < 26; i++) {
            if (cnt[i] > 0) bucket[cnt[i]] += char('a' + i);
        }
        int best = -1;
        for (int k = 1; k <= n; k++) {
            if (bucket[k].empty()) continue;
            if (best == -1 || bucket[k].size() >= bucket[best].size()) best = k;
        }
        return best == -1 ? "" : bucket[best];
    }
};
```

### Python

```python
class Solution:
    def majorityFrequencyGroup(self, s: str) -> str:
        cnt = [0] * 26
        for ch in s:
            cnt[ord(ch) - 97] += 1
        bucket = [[] for _ in range(len(s) + 1)]
        for i in range(26):
            if cnt[i] > 0:
                bucket[cnt[i]].append(chr(97 + i))
        best = []
        for k in range(1, len(s) + 1):
            if bucket[k] and len(bucket[k]) >= len(best):
                best = bucket[k]
        return "".join(best)
```

## 8. 边界情况与易错点

1. **并列取大 $k$**：这是本题唯一的「坑」，示例 3 专门考它。写成 `>` 而非 `>=` 会返回 `gi`。
2. **不要统计出现 0 次的字母**：`cnt[i] == 0` 的字母不属于任何频率组；若误放进 `bucket[0]`，会因为 26 个字母全在 $k=0$ 而得到错误答案。
3. **单字符字符串**：`s = "a"` 时唯一频率组是 $k=1$ 的 `{a}`，返回 `"a"`。
4. **全同字符**：`s = "aaaa"` 时返回 `"a"`（只有一个组）。
5. **输出顺序不限**：评测对同一组字符的不同排列都接受，按字母序输出最省事。
6. **桶数组大小**：用 $|s|+1$ 而不是常数 26——虽然单字母最多出现 $|s|$ 次，用 26 也能过（因为 $|s| \le 100$ 而 26 不够），所以**必须**按 $|s|$ 开，否则下标越界。
