# LeetCode 爬楼梯 II 题解

## 1. 题目概述

- **标题 / 题号**：爬楼梯 II（#3693，medium）
- **链接**：https://leetcode.cn/problems/climbing-stairs-ii/
- **来源**：LeetCode 第 166 场双周赛 Q2
- **难度**：中等
- **标签**：动态规划、数组

**题意**：楼梯有 $n+1$ 级台阶，编号 $0 \sim n$。给定长度为 $n$ 的数组 $costs$，其中 $costs[i]$ 是台阶 $i+1$ 的成本（即**编号为 $j$ 的台阶（$1 \le j \le n$）对应 $costs[j-1]$**，这一点由官方示例反推得到，见 §8）。从台阶 $i$ 出发只能跳到 $i+1$、$i+2$ 或 $i+3$，跳跃代价为

$$\text{cost}(i \to j) = costs[j-1] + (j-i)^2 .$$

从台阶 $0$ 出发、初始代价为 $0$，求到达台阶 $n$ 的**最小总代价**。

**约束**：

- $1 \le n = costs.length \le 10^5$
- $1 \le costs[i] \le 10^4$

## 2. 示例

**示例 1**

```text
输入：n = 4, costs = [1,2,3,4]
输出：13
解释：路径 0 → 1 → 2 → 4：
     0→1：c1 = costs[0] + 1² = 1 + 1 = 2
     1→2：c2 = costs[1] + 1² = 2 + 1 = 3
     2→4：c4 = costs[3] + 2² = 4 + 4 = 8    ← 编号 4 的台阶对应 costs[3]
     合计 2 + 3 + 8 = 13。
```

**示例 2**

```text
输入：n = 4, costs = [5,1,6,2]
输出：11
解释：路径 0 → 2 → 4：
     0→2：c2 = costs[1] + 2² = 1 + 4 = 5
     2→4：c4 = costs[3] + 2² = 2 + 4 = 6
     合计 11；对比路径 0→1→2→4：6 + 2 + 6 = 14，故 11 更优。
```

**示例 3**

```text
输入：n = 3, costs = [9,8,3]
输出：12
解释：一步 0 → 3：costs[2] + 3² = 3 + 9 = 12。
```

## 3. 解题思路

### 3.1 暴力思路

每条路径每步有 3 种选择，总共约 $3^{n}$ 条路径；枚举所有路径并累加代价，取最小值。$n = 10^5$ 时这是天文数字，显然不可行。

暴力里有一个可贵的性质：路径的代价是**逐步累加**的，且第 $j$ 级台阶的代价只取决于「从哪一级跳过来」，与更早的历史无关。这正是动态规划的适用条件。

### 3.2 核心观察：只可能从 $(j-1, j-2, j-3)$ 跳到 $j$

![DP 转移：到达 j 的最后一步只可能来自 j-1、j-2、j-3](images/bw166_q2_dp_transitions.svg)

由于单步最多跨 3 级，**到达台阶 $j$ 的最后一跳**只可能是 $j-1 \to j$、$j-2 \to j$ 或 $j-3 \to j$ 三者之一。于是设 $dp[j]$ 为到台阶 $j$ 的最小总代价，有

$$dp[0] = 0, \qquad dp[j] = c_j + \min_{d \in \{1,2,3\},\; j-d \ge 0} \bigl( dp[j-d] + d^2 \bigr),$$

其中 $c_j = costs[j-1]$ 是落上台阶 $j$ 的成本。答案即 $dp[n]$。

这里用到了一个容易忽略的点：$d^2$ **不是** $(j-i)^2$ 的近似，而是题目明确给出的「距离平方」惩罚——它让「一次跨三格」比「三次跨一格」更便宜（$9 < 3 \times 1$），所以贪心地「能跨三格就跨三格」并不一定最优，必须三种跳法都试。

### 3.3 算法流程

![算法流程：自底向上填 dp](images/bw166_q2_algorithm_flow.svg)

```text
1. dp[0] = 0；dp[1..n] = +∞
2. for j = 1 .. n:
       c = costs[j-1]
       best = +∞
       for d = 1, 2, 3:
           若 j - d >= 0:  best = min(best, dp[j-d] + d*d)
       dp[j] = c + best
3. 返回 dp[n]
```

### 3.4 示例演算

![示例 1 与示例 3 的 dp 表](images/bw166_q2_example_walkthrough.svg)

示例 1：$n=4$，$costs = [1,2,3,4]$，于是 $c_1=1, c_2=2, c_3=3, c_4=4$。

| $j$ | $c_j$ | 三种候选（$d=1,2,3$） | $dp[j]$ |
|-----|-------|------------------------|---------|
| 1 | 1 | $dp[0]+1 = 1$ | **2** |
| 2 | 2 | $dp[1]+1 = 3$，$dp[0]+4 = 4$ | **5** |
| 3 | 3 | $dp[2]+1 = 6$，$dp[1]+4 = 6$，$dp[0]+9 = 9$ | **9** |
| 4 | 4 | $dp[3]+1 = 10$，$dp[2]+4 = 9$，$dp[1]+9 = 11$ | **13** |

`dp[4] = 13` 与题面一致；且 $dp[4]$ 来自 $dp[2] + 4$，回溯得路径 $0 \to 2 \to 4$？注意示例 1 给的路径是 $0 \to 1 \to 2 \to 4$，两者 $dp$ 值相同（$5 + 4 = 9$ 对应 $0\to2\to4$ 的 $dp[2]=5$；而 $0\to1\to2$ 也是 5），因为 $dp[2] = 5$ 有两条并列最优路径，这正是「最优解不唯一但最优值唯一」。

示例 3：$n=3$，$costs=[9,8,3]$，$dp[1] = 9+1 = 10$，$dp[2] = 8 + \min(11, 4) = 12$，$dp[3] = 3 + \min(13, 14, 9) = 12$。

## 4. 算法细节

1. **下标换算**：$c_j = costs[j-1]$。做题时先拿示例反推确认——示例 1 里「编号 4 的台阶」成本是 4，对应 $costs[3]$，所以是 $j-1$ 而不是 $j$。
2. **三种跳法都要试**：$(j-i)^2$ 是凸的，跨得越远单步越贵但步数越少，不是单调关系，不能只贪心跨 3 格。
3. **边界 $j \le 3$**：$j=1$ 只有 $d=1$；$j=2$ 有 $d=1,2$；$j=3$ 才有三种。代码用 `j-d >= 0` 统一判断。
4. **空间可以压到 $O(1)$**：转移只依赖前 3 个状态，滚动数组即可；但保留 $O(n)$ 的 $dp$ 更易读、也便于回溯路径，$n \le 10^5$ 完全够用。
5. **`INF` 选取**：上界约为 $n \cdot (\max costs + 9) \approx 10^9$，用 `long long` 并把 `INF` 设为 `1e18` 最稳。
6. **代价类型**：单点最大 $10^4$，$10^5$ 级台阶总代价不超过 $10^9 + 9 \times 10^5$，`long long` 不会溢出，`int` 也勉强够，统一用 `long long` 更安全。

## 5. 正确性证明

**引理 1（最优子结构）**：设 $P$ 是一条从 $0$ 到 $j$ 的最优路径，其最后一步从 $i$ 跳到 $j$（$i \in \{j-1,j-2,j-3\}$），则 $P$ 中从 $0$ 到 $i$ 的那一段必然也是一条从 $0$ 到 $i$ 的最优路径。

**证明**：反设存在更短的从 $0$ 到 $i$ 的路径 $P'$，代价 $W(P') < W(P_{0\to i})$。把 $P'$ 接上最后一步 $i \to j$ 得到一条从 $0$ 到 $j$ 的路径，其代价为 $W(P') + \text{cost}(i\to j) < W(P_{0\to i}) + \text{cost}(i\to j) = W(P)$，与 $P$ 最优矛盾。∎

**引理 2（转移完备）**：任何从 $0$ 到 $j$ 的路径的最后一跳起点必属于 $\{j-1, j-2, j-3\}$（在非负范围内）。

**证明**：每步最多前进 3 级，故最后一跳的起点 $i$ 满足 $j - 3 \le i \le j-1$，且 $i \ge 0$。∎

**定理**：按上述转移自底向上计算得到的 $dp[n]$ 等于从台阶 $0$ 到台阶 $n$ 的最小总代价。

**证明**：对 $j$ 归纳证明 $dp[j]$ 是到 $j$ 的最小代价。$j=0$ 时 $dp[0]=0$ 显然。设对 $0..j-1$ 成立。任取一条到 $j$ 的最优路径，由引理 2 其最后一跳起点 $i \in \{j-1,j-2,j-3\}$，由引理 1 其前缀是最优的，代价为 $dp[i]$，故该路径代价为 $dp[i] + c_j + (j-i)^2$，其中某一项必被算法枚举到，所以 $dp[j] \le$ 最优值。另一方面算法枚举的每个候选都对应一条真实路径，故 $dp[j] \ge$ 最优值。两者相等。∎

## 6. 复杂度分析

- **时间**：$O(n)$。每个台阶只做 3 次常数比较与加法；$n = 10^5$ 时约 $3 \times 10^5$ 次运算。
- **空间**：$O(n)$ 存 $dp$ 数组；若用滚动数组（只存最近 3 个状态）可降为 $O(1)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int climbStairs(int n, vector<int>& costs) {
        const long long INF = (long long)4e18;
        vector<long long> dp(n + 1, INF);
        dp[0] = 0;
        for (int j = 1; j <= n; j++) {
            long long best = INF;
            for (int d = 1; d <= 3; d++) {
                if (j - d < 0) continue;
                best = min(best, dp[j - d] + (long long)d * d);
            }
            dp[j] = best + costs[j - 1];
        }
        return (int)dp[n];
    }
};
```

### Python

```python
class Solution:
    def climbStairs(self, n: int, costs: list[int]) -> int:
        INF = float("inf")
        dp = [INF] * (n + 1)
        dp[0] = 0
        for j in range(1, n + 1):
            best = INF
            for d in (1, 2, 3):
                if j - d >= 0:
                    best = min(best, dp[j - d] + d * d)
            dp[j] = best + costs[j - 1]
        return dp[n]
```

## 8. 边界情况与易错点

1. **下标 $j-1$ 而不是 $j$**：$costs$ 长度是 $n$，而台阶编号到 $n$，所以必然错开一位。用官方示例验证：示例 1 中「编号 4 的台阶」成本 4 = $costs[3]$，示例 3 中「编号 3 的台阶」成本 3 = $costs[2]$，都印证 $c_j = costs[j-1]$。若写成 $costs[j]$ 会数组越界（$j=n$ 时）。
2. **$n = 1$**：只有 $0 \to 1$，答案 $costs[0] + 1$。
3. **不能把「一次跨三格」当贪心**：$(j-i)^2$ 让远跳更贵，答案可能是混合跳法。示例 1 的最优解就用了 $1,1,2$ 三种步长。
4. **$dp$ 初值**：除 $dp[0]$ 外都应初始化为 `INF`，否则未计算的状态会以 0 参与比较，导致答案偏小。
5. **`INF` 要够大**：$4 \times 10^{18}$ 在 `long long` 内且加法不溢出；用 `INT_MAX` 则 `dp[j-d] + d*d` 可能溢出（若用 `int`）。
6. **返回类型**：题面返回整数，`long long` 结果转回 `int` 时不会截断（上界 $< 2^{31}$）。

**延伸思考**：若单步可以跳 $1 \sim k$ 级，转移变为 $O(k)$，总量 $O(nk)$；若 $k$ 与 $n$ 同阶，就需要用凸包/李超树优化——因为代价 $costs[j-1] + (j-i)^2$ 可以展开成 $j^2 - 2ij + i^2 + c_j$，对固定的 $j$ 是关于 $i$ 的一次式，斜率优化的标准形式（$dp[i] + i^2$ 作为截距、$-2i$ 作为斜率），可用单调队列或 Li Chao 树在 $O(n \log n)$ 内解决。本题 $k=3$ 属于该套路的退化情形。
