# LeetCode 检查相邻数字差 题解

## 1. 题目概述

- **标题 / 题号**：检查相邻数字差（#3931，easy）
- **链接**：https://leetcode.cn/problems/check-adjacent-digit-differences/
- **来源**：LeetCode 第 502 场周赛 Q1
- **难度**：简单
- **标签**：字符串

**题意**：给定一个**仅由数字组成**的字符串 `s`，判断**每一对相邻数字**之间的**绝对差**是否都**至多为 2**。全部满足返回 `true`，只要有一对超过 2 就返回 `false`。

**约束**：

- `2 <= s.length <= 100`
- `s` 仅由数字 `'0'`~`'9'` 组成

## 2. 示例

**示例 1**

```text
输入：s = "132"
输出：true
解释：|1−3| = 2 ≤ 2，|3−2| = 1 ≤ 2，全部满足。
```

**示例 2**

```text
输入：s = "129"
输出：false
解释：|1−2| = 1 ≤ 2，但 |2−9| = 7 > 2，存在违规对。
```

**示例 3**

```text
输入：s = "204"
输出：false
解释：|2−0| = 2 ≤ 2，但 |0−4| = 4 > 2，返回 false。
```

**示例 4**

```text
输入：s = "42"
输出：true
解释：长度恰为 2 时只有一对，|4−2| = 2 ≤ 2（注意是降序对，绝对差仍合法）。
```

## 3. 解题思路

### 3.1 暴力思路

枚举全部 `n−1` 个相邻对 `(s[i−1], s[i])`，逐对转成 `int` 计算绝对差并与 2 比较。时间 `O(n)`——这已经是最优复杂度，**暴力与最优在复杂度上没有区别**，签到题的优化空间只在「代码最短路径」：逐字符转 `int` 是多余的。

### 3.2 核心观察：字符相减 = 数字相减

![相邻数字差概念图](images/wc502_q1_digit_pairs.svg)

`'0'`~`'9'` 的 ASCII 码（48~57）**连续**，设数字 `d` 对应字符 `'0' + d`，则任意两个数字字符之差：

$$s[i] - s[i-1] = ('0' + d_i) - ('0' + d_{i-1}) = d_i - d_{i-1}$$

> 💡 **关键观察**：**无需 `int(s[i])` 转换**，C++ 中直接 `s[i] - s[i-1]` 就是数字之差，取绝对值后与 2 比较即可。（Python 的 `str` 不支持相减，需 `ord()`，见 §8。）

### 3.3 算法流程：单趟扫描 + 提前短路

![单趟扫描流程图](images/wc502_q1_scan_flow.svg)

1. 下标 `i` 从 `1` 扫到 `n−1`（0-indexed），共检查 `n−1` 对。
2. 一旦发现 $|s[i] - s[i-1]| > 2$，**立即** `return false`。
3. 扫描完仍未发现违规，说明全部对合法，`return true`。

### 3.4 示例演算

![示例演算走查](images/wc502_q1_walkthrough.svg)

以 `s = "3142"` 为例：

| i | 相邻对 | 计算 | 绝对差 | 判定 |
|---|--------|------|--------|------|
| 1 | (3, 1) | 3 − 1 = 2 | 2 | ✓ 继续 |
| 2 | (1, 4) | 1 − 4 = −3 | 3 | ✗ 短路，return false |
| 3 | (4, 2) | （未执行） | — | 已返回 |

第 2 对即违规，算法提前返回，第 3 对根本不检查。

## 4. 算法细节

1. **字符差技巧**：C++ 中 `char` 可直接做算术，`s[i] - s[i-1]` 即数字差（引理见 §5）；Python 中需 `ord(s[i]) - ord(s[i-1])`。
2. **绝对值必不可少**：相邻对可能升序（差为正）也可能降序（差为负），判定的是 $|d_i - d_{i-1}|$。
3. **提前短路**：发现一处违规即返回。不改变最坏复杂度（仍 `O(n)`），但平均更快，且是「存在性判定」类问题的标准写法。
4. **Python 一行式**：`all(abs(ord(a) - ord(b)) <= 2 for a, b in zip(s, s[1:]))`，`all()` 自带惰性短路。
5. **循环边界**：`i` 从 `1` 开始到 `n−1`（含），恰好覆盖所有 `n−1` 对，不多不少。

## 5. 正确性证明

**引理 1（字符差 = 数字差）**：对任意数字字符 $c_1, c_2 \in \{'0','1',\dots,'9'\}$，设其表示的数字为 $d_1, d_2$，则 $c_1 - c_2 = d_1 - d_2$。

**证明**：ASCII 码表中 `'0'`~`'9'` 编码连续，且 $c = \text{ord}('0') + d$。故 $c_1 - c_2 = (\text{ord}('0') + d_1) - (\text{ord}('0') + d_2) = d_1 - d_2$。∎

**引理 2（绝对差一致）**：$|c_1 - c_2| = |d_1 - d_2|$。

**证明**：对引理 1 等式两边取绝对值即得。∎

**定理**：算法返回 `true` 当且仅当 `s` 中每一对相邻数字的绝对差都至多为 2。

**证明**：

- （⇐）若所有相邻对绝对差 ≤ 2，由引理 2，循环中判定 $|s[i] - s[i-1]| > 2$ 恒为假，算法不会提前返回，扫描结束后返回 `true`。
- （⇒）证逆否命题：若存在某对 $i$ 使 $|d_i - d_{i-1}| > 2$，由引理 2，$|s[i] - s[i-1]| > 2$，循环执行到该 $i$ 时判定为真，算法返回 `false`。∎

**短路的等价性**：提前返回不改变结果——「存在违规对」一旦成立，结论即为 `false`，后续对是否合法已不影响判定（存在量词对后续无关）。

## 6. 复杂度分析

- **时间复杂度**：`O(n)`。单趟扫描 `n−1` 对，每对 `O(1)` 判定；最好情况第一对即违规，`O(1)` 返回。
- **空间复杂度**：`O(1)`。仅常数个下标变量。Python 的 `zip(s, s[1:])` 写法会产生 `O(n)` 切片，可用索引写法或 `itertools.pairwise` 保持 `O(1)` 额外空间。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool isAdjacentDiffAtMostTwo(string s) {
        for (int i = 1; i < (int)s.size(); i++) {
            // 字符相减 = 数字相减，无需转 int
            if (abs(s[i] - s[i - 1]) > 2) {
                return false;
            }
        }
        return true;
    }
};
```

### Python

```python
class Solution:
    def isAdjacentDiffAtMostTwo(self, s: str) -> bool:
        return all(abs(ord(a) - ord(b)) <= 2 for a, b in zip(s, s[1:]))
```

> 💡 **索引写法（避免 `O(n)` 切片，逻辑与 C++ 一致）**：
>
> ```python
> class Solution:
>     def isAdjacentDiffAtMostTwo(self, s: str) -> bool:
>         for i in range(1, len(s)):
>             if abs(ord(s[i]) - ord(s[i - 1])) > 2:
>                 return False
>         return True
> ```

## 8. 边界情况与易错点

1. **漏取绝对值（最大陷阱）**：降序对的字符差为负。如 `"14"`：`1 − 4 = −3 ≤ 2`，不取 `abs` 会误判为合法，而正确答案是 `false`（`|1−4| = 3 > 2`）。
2. **「至多 2」含等号**：差恰好等于 2（如 `"13"`、`"42"`）是**合法**的，违规条件是 `> 2`，不要误写成 `>= 2`。
3. **长度恰为 2**：只有一对，循环只执行一次；约束保证 `n >= 2`，**无需**特判空串或单字符。
4. **Python 字符不能直接相减**：`'3' - '1'` 抛 `TypeError`，必须 `ord()`（或 `int()`）；C++ 的 `char` 可以直接相减，两语言写法不同。
5. **溢出**：字符差范围 `[-9, 9]`，`abs` 后为 `[0, 9]`，任何整型都安全，无需考虑。
6. **前导零**：`'0'` 是合法字符，如 `"09"`：`|0−9| = 9 > 2` → `false`，无需特殊处理。
7. **短路 vs 全扫**：忘记提前 `return` 而用标志位全扫也能过（`O(n)` 相同），但短路是判定类问题的更地道写法。
