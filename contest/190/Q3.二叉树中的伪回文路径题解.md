# LeetCode 二叉树中的伪回文路径 题解

## 1. 题目概述

- **标题 / 题号**：二叉树中的伪回文路径（#1457，medium）
- **链接**：https://leetcode.cn/problems/pseudo-palindromic-paths-in-a-binary-tree/
- **来源**：LeetCode 第 190 场周赛 Q3
- **难度**：中等
- **标签**：位运算、树、深度优先搜索、广度优先搜索、二叉树

**题意**：节点值都是 $1 \sim 9$ 的二叉树，一条路径叫「伪回文」，是指路径上所有节点值的**某个排列**能构成回文串。统计从**根到叶子**的路径中伪回文路径的条数。

**约束**：

- 节点数在 $[1,\,10^5]$ 内
- $1 \le \text{Node.val} \le 9$

## 2. 示例

**示例 1**

```text
输入：root = [2,3,1,3,1,null,1]
输出：2
解释：三条根→叶路径为 [2,3,3]、[2,3,1]、[2,1,1]。
      [2,3,3] 可排成 [3,2,3]，[2,1,1] 可排成 [1,2,1]；
      [2,3,1] 三个数字各出现一次，怎么排都不是回文。
```

**示例 2**

```text
输入：root = [2,1,1,1,3,null,null,null,null,null,1]
输出：1
解释：三条路径 [2,1,1]、[2,1,3,1]、[2,1] 中，只有 [2,1,1] 是伪回文。
```

**示例 3**

```text
输入：root = [9]
输出：1
解释：唯一的路径只含一个 9，本身即回文。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的做法：DFS 枚举每条根→叶路径，到了叶子就把路径上的值抄出来统计频次，再判断能否重排成回文。若路径长度为 $L$，仅「统计 + 判定」就要 $O(L)$（排序则 $O(L\log L)$），整体代价是

$$\sum_{\text{叶子 } \ell} D(\ell),$$

其中 $D(\ell)$ 是叶子的深度。这个量**最坏是 $\Theta(n^2)$**：把 $n/2$ 个节点排成一条链，链上每个节点再挂一个叶子孩子（合法二叉树），第 $i$ 个叶子的深度是 $i+1$，于是 $\sum_i (i+1) = \Theta(n^2)$；$n = 10^5$ 时约 $10^{9}$ 量级，远超时限。

即使把频次数组改成增量维护（进节点 $+1$、回溯 $-1$），每到一个叶子仍要扫 9 个计数器才能判断「奇数频次是否超过 1 个」。真正的浪费有两处：**父路径的信息孩子可以完全复用**，不必重新统计；**判定只关心次数的奇偶**，不需要精确计数。

### 3.2 核心观察：把 9 个计数器压成 9 个二进制位

![奇偶掩码模型](images/wc190_q3_parity_mask_model.svg)

**第一步：回文的充要条件。** 一个多重集能重排成回文，当且仅当其中出现**奇数次**的元素至多 1 个。理由很直观：回文串里除正中间那个字符外，其余字符都必须成对出现。

**第二步：只保留奇偶。** 设路径上数字 $d$（$1 \le d \le 9$）出现 $c_d$ 次，定义

$$m = \sum_{d=1}^{9} \bigl(c_d \bmod 2\bigr)\, 2^{\,d-1},$$

即第 $d-1$ 位记录「$c_d$ 的奇偶」。于是路径可重排成回文 $\iff$ $m$ 的二进制里至多一个 $1$。

**第三步：增量维护。** 从父节点走到子节点，只有一个 $c_d$ 加 1，因此只有一个二进制位翻转——直接用异或：

$$m \leftarrow m \oplus 2^{\,v-1}, \qquad v = \text{子节点的值}.$$

**第四步：$O(1)$ 判定。** 「至多一个 $1$」不必真的去数位数，位运算恒等式

$$m \ \&\ (m-1) = 0 \iff \mathrm{popcount}(m) \le 1$$

一步搞定（$m=0$ 时 $0 \,\&\, (-1) = 0$ 也成立）。整条路径的判定因此压到一次位与。

> 💡 掩码只有 $2^9 = 512$ 种取值，是极小的状态空间；但它随路径不同而不同，不能把不同路径的掩码合并计数。

### 3.3 算法流程

![DFS 算法流程](images/wc190_q3_dfs_flow.svg)

递归形式最直观：

```text
dfs(u, mask):                       # mask = 根到 u 的父节点的奇偶掩码
    mask ^= 1 << (u.val - 1)        # 把 u 自己计入路径
    if u 是叶子:
        return (mask & (mask - 1)) == 0 ? 1 : 0
    return dfs(u.left, mask) + dfs(u.right, mask)
```

但单链深度可达 $10^5$，递归写法在 Python 里会直接 `RecursionError`，C++ 也有栈溢出风险。因此改用**显式栈**，把「掩码」当作栈帧的一部分**按值传递**：

1. 栈初始为 $\{(root, 0)\}$，$0$ 表示空路径的奇偶（什么都不出现）。
2. 弹出栈顶 $(u, m)$，执行 $m \leftarrow m \oplus 2^{u.val-1}$。
3. 若 $u$ 左右孩子都空：$m \ \&\ (m-1) = 0$ 则 `ans += 1`，本轮结束。
4. 否则把每个非空孩子连同 $m$ 压栈；两个孩子的先后顺序任意。
5. 栈空时返回 `ans`。

> 因为 $m$ 是拷贝进栈帧的，回溯时天然回到父路径的状态，**不需要**额外写一次「异或撤销」。

### 3.4 示例演算

![示例演算走查](images/wc190_q3_walkthrough.svg)

以 `root = [2,3,1,3,1,null,1]` 为例，三条路径与掩码演化（低位对应数字 $1$）：

| 路径 | 掩码演化（9 位） | 奇数频次的数字 | 个数 | 判定 |
|------|------------------|----------------|------|------|
| A：$2 \to 3 \to 3$ | $000000010 \to 000000110 \to 000000010$ | 2 | 1 | ✓ |
| B：$2 \to 3 \to 1$ | $000000010 \to 000000110 \to 000000111$ | 1, 2, 3 | 3 | ✗ |
| C：$2 \to 1 \to 1$ | $000000010 \to 000000011 \to 000000010$ | 2 | 1 | ✓ |

- 路径 A：$3$ 出现两次，第二次异或把它的位又翻回 $0$，最后只剩数字 $2$ 的位为 $1$。
- 路径 B：$1,2,3$ 各出现一次，掩码是 `111`，`111 & 110 = 110 ≠ 0`，不是伪回文。
- 路径 C：两个 $1$ 抵消，同理通过。

累计 $2$ 条，返回 $2$。注意路径 B 的最后一个节点（值 $1$）必须在**翻转之后**才参与判定：先判叶子再翻转，判的就是父路径而不是整条路径。

## 4. 算法细节

1. **初始掩码取 $0$**：把它理解为「根到父节点（空路径）的奇偶」，这样根节点入栈时不需要特判。
2. **叶子判定放在翻转之后**：叶子也是路径的一部分，必须先 `mask ^= ...` 再判定。若顺序反过来，判的是「父路径」：`[1,2]` 的父路径只有数字 $1$，掩码 `1` 会被误判成伪回文。
3. **异或即「计数加一取模 2」**：$c_d \bmod 2$ 在 $+1$ 后变成 $(c_d+1)\bmod 2$，正是翻转那一位；不需要读原值再写回。
4. **位下标用 $v-1$**：值 $1$ 对应最低位 $2^0$；$1 \ll (v-1)$ 在 $v \le 9$ 时最大 $256$，`int` 足够。
5. **括号不能省**：C++ 中 `==` 的优先级高于 `&`，`mask & (mask - 1) == 0` 会被解析成 `mask & ((mask - 1) == 0)`，结果只有 $0$ 或 $1$，逻辑就错了；必须写 `(mask & (mask - 1)) == 0`。Python 里 `&` 优先级高于 `==`，但仍然建议加括号自证意图。
6. **只压非空孩子**：省掉「空指针」栈帧；`root` 为空时直接返回 $0$（题目保证至少 1 个节点，但接口应当稳健）。
7. **显式栈代替递归**：树退化成链时递归深度 $10^5$；若坚持递归，Python 需 `sys.setrecursionlimit(300000)`，C++ 只能依赖运气。
8. **不要转字符串数 $1$**：`bin(mask).count('1')` 或 `__builtin_popcount(mask) <= 1` 都能过，但位与版本没有函数调用、不构造字符串，常数最小。
9. **BFS 同样可行**：队列元素换成 $(node, mask)$ 逐层扩展，掩码照样按值传递；只是队列最坏要存 $O(n)$ 个节点（满二叉树最后一层），空间比 DFS 的 $O(h)$ 差。

## 5. 正确性证明

**引理 1（掩码不变式）**：算法执行 `mask ^= 1 << (u.val - 1)` 之后、处理 $u$ 的分支之前，$mask$ 恰为根到 $u$ 路径上各值出现次数的奇偶位向量。

**证明**：对 $u$ 的深度归纳。初始压栈的是 $(root, 0)$，空路径上没有任何值，向量全 $0$，成立。设父节点 $p$ 处理完毕后掩码为根到 $p$ 的奇偶向量。孩子 $u$ 入栈时复制的是 $p$ 的掩码（含 $p$），出栈后仅对 $2^{u.val-1}$ 这一位取反：按归纳假设这位记录的是 $c_{u.val}$ 的奇偶，取反后变为 $(c_{u.val}+1) \bmod 2$，其余位不变，正是根到 $u$ 路径的奇偶向量。∎

**引理 2（回文判定）**：设 $S$ 是有限多重集，则存在 $S$ 的排列为回文 $\iff$ $S$ 中出现奇数次的元素至多 1 个。

**证明**：

- ($\Leftarrow$) 若无奇数频次元素：把每个元素的一半放左半、另一半倒序放右半，得偶长回文；若恰有一个元素 $x$ 出现奇数次：把 $x$ 放正中间，其余元素按上述成对放置，得奇长回文。
- ($\Rightarrow$) 设回文串 $P$ 长度为 $n$，则对任意 $1 \le i \le n$ 有 $P[i] = P[n+1-i]$，即除 $n$ 为奇数时的中心位置外，每个字符都成对出现，故至多中心一个字符出现奇数次。∎

由引理 1、2 及恒等式 $\mathrm{popcount}(m) \le 1 \iff m \,\&\, (m-1) = 0$，叶子处的判定条件恰为「该根→叶路径可重排成回文」。

**引理 3（路径与叶子一一对应）**：二叉树的每个叶子确定唯一的根→叶路径，每条根→叶路径的终点是叶子；算法中每个叶子恰被弹出并判定一次。

**证明**：每个节点到根的父链唯一，故叶子与根→叶路径一一对应。栈遍历中节点只在弹出时处理，每个节点恰好入栈一次（根由初始化入栈，其余由父节点压入），故每个叶子恰好被判定一次；判定时其栈帧携带的掩码由引理 1 就是该路径的奇偶向量。∎

**定理**：算法返回的值等于伪回文路径的条数。

**证明**：由引理 3，算法对每条根→叶路径恰好判定一次、且只对它们判定（非叶子直接压孩子，不计数）；由引理 1、2 及其后的等价性，判定为真的充要条件就是该路径伪回文。因此 `ans` 的累加次数恰为伪回文路径条数。∎

## 6. 复杂度分析

- **时间**：$O(n)$。每个节点入栈、出栈各一次；每次出栈做一次移位、一次异或；每个叶子做一次位与。总计 $O(n)$，$n = 10^5$ 时约 $2\times10^5$ 次栈操作。
- **空间**：$O(h)$，$h$ 为树高。DFS 的显式栈里存的是「当前路径上尚未展开的兄弟分支」，每下降一层至多多出一个待展开分支，故栈不超过 $h+1$ 个栈帧；单链时 $h = n$，满二叉树时 $h = \log n$。此外只有 `ans`、`mask` 等常数量，**不复制路径、不开计数数组**，比暴力省掉 $O(n)$ 级别的路径存储。
- **状态规模**：掩码仅 $2^9 = 512$ 种取值，可视作常数。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int pseudoPalindromicPaths(TreeNode* root) {
        if (root == nullptr) return 0;
        int ans = 0;
        // 栈帧：{当前节点, 根到父节点的奇偶掩码}
        vector<pair<TreeNode*, int>> st{{root, 0}};
        while (!st.empty()) {
            auto [node, mask] = st.back();
            st.pop_back();
            mask ^= 1 << (node->val - 1);            // 当前节点值计入路径
            if (!node->left && !node->right) {       // 叶子：判定整条路径
                if ((mask & (mask - 1)) == 0) ++ans; // 至多一个 1 即伪回文
                continue;
            }
            if (node->left)  st.push_back({node->left,  mask});
            if (node->right) st.push_back({node->right, mask});
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def pseudoPalindromicPaths(self, root: TreeNode) -> int:
        if root is None:
            return 0
        ans = 0
        stack = [(root, 0)]              # (节点, 根到父节点的奇偶掩码)
        while stack:
            node, mask = stack.pop()
            mask ^= 1 << (node.val - 1)  # 当前节点值计入路径
            if node.left is None and node.right is None:
                if (mask & (mask - 1)) == 0:
                    ans += 1             # 至多一个 1
                continue
            if node.left is not None:
                stack.append((node.left, mask))
            if node.right is not None:
                stack.append((node.right, mask))
        return ans
```

## 8. 边界情况与易错点

1. **单节点树**：先翻转再判定，`[9]` 的掩码是 `1`，`1 & 0 = 0`，返回 $1$。若先判叶子再翻转，判的就是空路径（掩码 $0$），`[1,2]` 这类两条边、两个不同数字的路径会被误判成伪回文。
2. **空树**：题目保证节点数 $\ge 1$，但 `root == nullptr` 时返回 $0$ 才算接口完整，不要让它去解引用。
3. **深链**：$10^5$ 个节点排成一条链，递归版 Python 必 `RecursionError`（默认上限 1000），C++ 也可能爆栈；显式栈是稳妥写法。
4. **掩码为 $0$ 的路径**：如 `[1,1]`，两次异或抵消，`0 & (-1) = 0`，应判为伪回文；不要额外写「掩码为 0 就跳过」。
5. **C++ 优先级坑**：`mask & (mask - 1) == 0` 与 `(mask & (mask - 1)) == 0` 语义完全不同。前者被解析成 `mask & ((mask-1) == 0)`，结果只可能是 $0$ 或 $1$，等价于只判断了 `mask == 1`，是本题最常见的静默 WA。
6. **位下标混用**：`1 << val` 与 `1 << (val - 1)` 都能自洽（前者浪费最高位），但**不能一处用 $val$、一处用 $val-1$**，否则翻转和判定看的不是同一位。
7. **叶子定义**：只有左右孩子**都**为空才是叶子；只有一个孩子时是内部节点，必须继续往下走，不能提前判定。
8. **路径定义**：题目要求根→叶，而不是任意两节点之间的路径；把「路径」理解成任意向下路径会多算。
9. **只想计数、不想去重**：不同路径即使掩码相同也各算一条，**不能**用「掩码出现过就跳过」的集合去重。

$$p(u) \oplus p(v) \oplus 2^{\,\text{val}(\mathrm{lca}(u,v))-1},$$
