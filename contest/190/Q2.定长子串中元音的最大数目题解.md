# LeetCode 定长子串中元音的最大数目 题解

## 1. 题目概述

- **标题 / 题号**：定长子串中元音的最大数目（#1456，medium）
- **链接**：https://leetcode.cn/problems/maximum-number-of-vowels-in-a-substring-of-given-length/
- **来源**：LeetCode 第 190 场周赛 Q2
- **难度**：中等
- **标签**：字符串、滑动窗口

**题意**：给定字符串 $s$ 和整数 $k$，在 $s$ 的所有**长度为 $k$ 的连续子串**中，统计每个子串里元音字母（$a, e, i, o, u$）的个数，返回其中的**最大值**。注意窗口长度固定为 $k$，不能变长也不能变短。

**约束**：

- $1 \le \lvert s \rvert \le 10^5$
- $s$ 仅由小写英文字母组成
- $1 \le k \le \lvert s \rvert$

## 2. 示例

**示例 1**

```text
输入：s = "abciiidef", k = 3
输出：3
解释：长度为 3 的子串中，"iii"（下标 3..5）含 3 个元音，是最优窗口。
```

**示例 2**

```text
输入：s = "leetcode", k = 3
输出：2
解释："lee"、"eet"、"ode" 都含 2 个元音；没有含 3 个元音的窗口。
```

**示例 3**

```text
输入：s = "rhythms", k = 4
输出：0
解释：整串不含任何元音字母，答案只能是 0。
```

**示例 4**

```text
输入：s = "aeiou", k = 2
输出：2
解释：任意长度为 2 的子串都含 2 个元音，达到上界 k。
```

## 3. 解题思路

### 3.1 暴力思路

把所有 $n-k+1$ 个长度为 $k$ 的子串都列出来，逐个字符数元音：

$$ans = \max_{0 \le i \le n-k} \sum_{j=i}^{i+k-1} v[j], \qquad v[j] = [\,s[j] \in \{a,e,i,o,u\}\,]$$

枚举本身是 $O(n)$，但每个窗口内层再扫 $k$ 个字符，总复杂度 $O\bigl((n-k+1) \cdot k\bigr)$；它在 $k \approx n/2$ 处取到最大，$n = 10^5$ 时约 $2.5 \times 10^{9}$ 次字符判断——远超 1 秒能承受的 $10^{8}$ 量级。而且在 Python 里 `s[i:i+k]` 还会真的复制一段新字符串，常数更差。

暴力慢在哪？相邻两个窗口 **重叠了 $k-1$ 个位置**，重复统计了 $k-1$ 个字符；只要把这份重叠利用起来，就能把每步的代价压到 $O(1)$。

### 3.2 核心观察：相邻窗口只差「一进一出」

![定长窗口与 0/1 数组](images/wc190_q2_window_model.svg)

**第一步：把字符问题变成求和问题。** 定义指示数组

$$
v[i] =
\begin{cases}
1, & s[i] \in \{a, e, i, o, u\}\\
0, & \text{否则}
\end{cases}
$$

于是「第 $i$ 个窗口的元音数」正好是长度为 $k$ 的区间和

$$w(i) = \sum_{j=i}^{i+k-1} v[j]$$

**第二步：区间和可以递推。** 窗口 $i$ 覆盖 $[i,\,i+k)$，窗口 $i+1$ 覆盖 $[i+1,\,i+k+1)$。两者只差两个位置：位置 $i$ 被**移出**，位置 $i+k$ 被**移入**，因此

$$w(i+1) = w(i) - v[i] + v[i+k]$$

一次加法、一次减法即可，$O(1)$。于是整道题退化为一趟扫描：

$$ans = \max\bigl\{w(0),\, w(1),\, \dots,\, w(n-k)\bigr\}$$

**第三步：顺手剪枝。** 窗口里最多只有 $k$ 个字符，所以恒有 $w(i) \le k$。一旦某个 $w(i)$ 达到 $k$，它已经是理论上界，可以直接返回 $k$，不必扫完剩余窗口。

### 3.3 算法流程

![滑动窗口算法流程](images/wc190_q2_scan_flow.svg)

1. 预处理首个窗口 $s[0..k-1]$：数出其中的元音数，记为 $cur$；令 $best = cur$。
2. 若 $best = k$，直接返回 $k$（上界已达成）。
3. 令右端点 $i$ 从 $k$ 走到 $n-1$：窗口左端点随之是 $i-k$，执行「进一个、出一个」
   $$cur \leftarrow cur + v[i] - v[i-k]$$
4. 用 $cur$ 更新 $best$；若 $best = k$ 提前结束。
5. 扫完返回 $best$。

对应的核心循环只有三行（C++ 版）：

```text
cur += isVowel(s[i]);
cur -= isVowel(s[i - k]);
best = max(best, cur);
```

### 3.4 示例演算

![示例演算走查](images/wc190_q2_walkthrough.svg)

以 $s = \texttt{"abciiidef"}$、$k = 3$ 为例，指示数组为

$$\begin{array}{c|ccccccccc}
i & 0 & 1 & 2 & 3 & 4 & 5 & 6 & 7 & 8\\
\hline
s[i] & a & b & c & i & i & i & d & e & f\\
v[i] & 1 & 0 & 0 & 1 & 1 & 1 & 0 & 1 & 0
\end{array}$$

窗口依次右移（共 $n-k+1 = 7$ 个窗口）：

| 起点 $i$ | 窗口 | 子串 | 更新式 | $cur$ | $best$ |
|---------|------|------|--------|-------|--------|
| 0 | $[0,3)$ | "abc" | 首窗口 $1+0+0$ | 1 | 1 |
| 1 | $[1,4)$ | "bci" | $1 - v[0] + v[3] = 1-1+1$ | 1 | 1 |
| 2 | $[2,5)$ | "cii" | $1 - v[1] + v[4] = 1-0+1$ | 2 | 2 |
| 3 | $[3,6)$ | "iii" | $2 - v[2] + v[5] = 2-0+1$ | 3 | 3 |
| 4 | $[4,7)$ | "iid" | $3 - v[3] + v[6] = 3-1+0$ | 2 | 3 |
| 5 | $[5,8)$ | "ide" | $2 - v[4] + v[7] = 2-1+1$ | 2 | 3 |
| 6 | $[6,9)$ | "def" | $2 - v[5] + v[8] = 2-1+0$ | 1 | 3 |

走到 $i = 3$ 时 $cur = k = 3$，已达上界，实现中可以立刻返回 $3$；即使继续扫，$best$ 也不会再变大。

## 4. 算法细节

1. **元音判定要 $O(1)$**：C++ 用 5 个字符的相等比较（或 `bool[26]` 查表），Python 用 `set("aeiou")` 的 `in` 判断。不要用 `string::find` 之类的子串搜索去判断单个字符，也不要为每个字符新建容器。
2. **先算首窗口，再滑动**：首窗口用一次 $O(k)$ 循环求出，之后每次只做增量；这样避免「每个窗口都重新求和」把复杂度打回 $O(nk)$。
3. **下标不会越界**：循环变量是**窗口右端** $i$，取值区间 $[k,\,n)$；此时要访问的 $s[i]$ 满足 $i < n$，要移出的 $s[i-k]$ 满足 $i-k \ge 0$，两个下标天然合法。若把循环写成 $[k+1, n]$ 或误用 $s[i+k]$，就会数组越界。
4. **更新顺序无所谓**：先加 $v[i]$ 再减 $v[i-k]$（或反序）都正确，因为 $k \ge 1$ 时两个下标必不相同；但**必须两个都做**，只加不减会让窗口越滑越长。
5. **剪枝条件写成 `best == k`**：由于 $w(i) \le k$，等号成立即最优；用 `>=` 也可以，但 `==` 语义更清楚。剪枝只影响常数，不影响正确性。
6. **不要在循环里切片**：Python 的 `s[i:i+k]` 是 $O(k)$ 拷贝，`len(s)` 虽然 $O(1)$，但也应提到循环外；把窗口内容交给「字符判断」而不是「子串对象」。
7. **前缀和的替代写法**：构造 $pre[i+1] = pre[i] + v[i]$，答案即 $\max_i \bigl(pre[i+k] - pre[i]\bigr)$。时间同为 $O(n)$，但要多开 $O(n)$ 空间且常数更大，仅作为校验手段（对拍时很好用）。
8. **$k = n$ 的退化**：此时只有一个窗口，滑动循环一次都不进，答案就是整串的元音数——这条路径必须靠「首窗口 + 空循环」自然覆盖，而不是特判。

## 5. 正确性证明

**引理 1（递推式成立）**：对任意整数 $0 \le i \le n-k-1$，有 $w(i+1) = w(i) - v[i] + v[i+k]$。

**证明**：由定义 $w(i) = \sum_{j=i}^{i+k-1} v[j]$，$w(i+1) = \sum_{j=i+1}^{i+k} v[j]$。两个下标集合分别为 $[i,\,i+k)$ 与 $[i+1,\,i+k+1)$，其差集为 $\{i\}$（只在第一个集合中）与 $\{i+k\}$（只在第二个集合中），交集 $[i+1,\,i+k)$ 的项完全相同，相互抵消。故

$$w(i+1) - w(i) = v[i+k] - v[i]$$

移项即得结论。∎

**引理 2（循环不变量）**：记 $w(i)$ 为左端为 $i$ 的窗口元音数。在右端变量 $i$（取值 $k \le i \le n$）的那一轮迭代**开始**时，恒有

$$cur = w(i-k), \qquad best = \max_{0 \le j \le i-k} w(j)$$

**证明**：对 $i$ 归纳。

- **初始** $i = k$：$cur$ 由首窗口循环累加得到，等于 $w(0)$；$best$ 被初始化为 $cur = w(0)$，即 $\max_{0 \le j \le 0} w(j)$。成立。
- **归纳步**：设第 $i$ 轮开始时结论成立，本轮执行 $cur \leftarrow cur + v[i] - v[i-k]$，由归纳假设与引理 1 得 $cur_{new} = w(i-k) - v(i-k) + v[i] = w(i-k+1)$；随后 $best \leftarrow \max(best,\, cur_{new}) = \max_{0 \le j \le i-k+1} w(j)$，恰为下一轮（右端 $i+1$，左端 $i+1-k$）所需的不变量。∎

**引理 3（窗口枚举完备）**：长度恰为 $k$ 的子串与起点 $i \in [0,\,n-k]$ 一一对应，故 $s$ 中所有长度为 $k$ 的子串恰为 $w(0), \dots, w(n-k)$。

**证明**：长度 $k$ 的子串由起点唯一确定，且合法起点必须满足 $i \ge 0$ 与 $i+k-1 \le n-1$，即 $i \le n-k$。区间的全部整数取值恰好给出全部子串，不重不漏。∎

**定理**：算法返回的值等于 $\max_{0 \le i \le n-k} w(i)$，即所有长度为 $k$ 的子串中元音数目的最大值。

**证明**：循环终止时右端变量 $i = n$，由引理 2 得 $best = \max_{0 \le j \le n-k} w(j)$，再由引理 3 这正是题目要求的最大值。若中途因 $best = k$ 提前返回，则由 $w(j) \le k$（窗口内至多 $k$ 个字符）知 $k$ 已是全局上界，提前返回的值与继续扫完的结果相同。∎

## 6. 复杂度分析

- **时间**：$O(n)$。首窗口统计 $O(k)$；滑动阶段每轮只做常数次字符判断与加法，共 $n-k$ 轮，$O(n-k)$。总计 $O(n)$，且每个字符至多被「进窗口」「出窗口」各访问一次，常数很小。剪枝只会让实际运行更快。
- **空间**：$O(1)$。只维护 $cur$、$best$ 等几个整数，不额外开指示数组或前缀和数组；Python 的元音集合是长度 5 的常量。
- **对比**：暴力是 $O(nk)$，前缀和是 $O(n)$ 时间 + $O(n)$ 空间；本解法是 $O(n)$ 时间 + $O(1)$ 空间，是该题的最优形态。

## 7. 参考代码

### C++

```cpp
#include <string>
using namespace std;

class Solution {
public:
    int maxVowels(string s, int k) {
        auto isVowel = [](char c) {
            return c == 'a' || c == 'e' || c == 'i' || c == 'o' || c == 'u';
        };
        int n = (int)s.size();
        int cur = 0;
        for (int i = 0; i < k; ++i) cur += isVowel(s[i]);   // 首个窗口 s[0..k-1]

        int best = cur;
        for (int i = k; i < n; ++i) {                       // 右端 i，左端 i-k
            cur += isVowel(s[i]);                           // 新进入的字符
            cur -= isVowel(s[i - k]);                       // 被移出的字符
            if (cur > best) {
                best = cur;
                if (best == k) return k;                    // 已达上界，剪枝
            }
        }
        return best;
    }
};
```

### Python

```python
class Solution:
    def maxVowels(self, s: str, k: int) -> int:
        vowels = set("aeiou")
        cur = 0
        for i in range(k):                  # 首个窗口 s[0..k-1]
            if s[i] in vowels:
                cur += 1

        best = cur
        for i in range(k, len(s)):          # 窗口右端 i，左端 i-k
            if s[i] in vowels:
                cur += 1
            if s[i - k] in vowels:
                cur -= 1
            if cur > best:
                best = cur
                if best == k:               # 已是理论上界，剪枝返回
                    return k
        return best
```

## 8. 边界情况与易错点

1. **$k = n$**：只有整串一个窗口，滑动循环体一次都不执行，必须保证 $best$ 已被初始化为首窗口的和；若把 $best$ 初始化成 0，遇到 `"aeiou"`、$k = 5$ 就会错答 0。
2. **整串无元音**：如 `"rhythms"`、$k = 4$，答案 0。此时 `best` 始终为 0，不要写成「找不到就返回 -1」或把答案初始化为负无穷。
3. **$k = 1$**：单字符窗口，答案只能是 0 或 1；首窗口循环只跑一次，`range(k, len(s))` 从 1 开始，逻辑仍然自洽。
4. **全元音串 + 大 $k$**：如 100000 个 `a`、$k = 100000$，答案 $k = 100000$；注意剪枝返回的也必须是 $k$ 本身，而不是 $k-1$ 或 `best`。
5. **只加不减 / 只减不加**：滑动时 `+v[i]` 与 `-v[i-k]` 必须成对出现，漏一个会让窗口长度漂移，`cur` 与真实窗口和脱钩。
6. **下标越界**：滑动的右端要到 $n-1$ 为止（`i < n`），不要写成 `i <= n`；被移出元素的下标是 $i-k$ 而不是 $i-k-1$。
7. **在循环里切片或重复求和**：`sum(ch in vowels for ch in s[i:i+k])` 这种写法是 $O(nk)$，恰好退化成暴力，$10^5$ 数据必超时。
8. **误把「最多」理解成「连续段」**：窗口必须严格长 $k$；`"leetcode"`、$k=3$ 的答案是 2，而不是整串中最长的连续元音段长度。
