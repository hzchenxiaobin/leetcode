# LeetCode 统计移除递增子数组的数目 II 题解

## 1. 题目概述

- **标题 / 题号**：统计移除递增子数组的数目 II（#2972，hard）
- **链接**：https://leetcode.cn/problems/count-the-number-of-incremovable-subarrays-ii/
- **来源**：LeetCode 第 120 场双周赛 Q3
- **难度**：困难
- **标签**：数组、双指针、二分查找

**题意**：与同场 Q1（#2970）完全相同：给定正整数数组 `nums`，若删除某个**非空连续子数组**后剩余元素（可为空）**严格递增**，则称该子数组为**移除递增子数组**。求其总数目。区别仅在于数据范围：

- $1 \le \textit{nums.length} \le 10^5$
- $1 \le \textit{nums}[i] \le 10^9$
- 返回类型为 `long`（总数可达 $\approx 5 \times 10^9$，超出 `int`）

## 2. 示例

**示例 1**

```text
输入：nums = [1,2,3,4]
输出：10
解释：整个数组严格递增，任何子数组都可删除，共 n(n+1)/2 = 10 个。
```

**示例 2**

```text
输入：nums = [6,5,7,8]
输出：7
解释：合法被删区间：[5]、[6]、[5,7]、[6,5]、[5,7,8]、[6,5,7]、[6,5,7,8]。
```

**示例 3**

```text
输入：nums = [8,7,6,6]
输出：3
解释：只有 [8,7,6]、[7,6,6]、[8,7,6,6]；删 [8,7] 剩 [6,6] 不严格递增。
```

## 3. 解题思路

### 3.1 暴力思路

Q1 的「枚举 $(l, r)$ + $O(n)$ 判定」是 $O(n^3)$，$n = 10^5$ 时完全不可行；即使把判定压到 $O(1)$，$O(n^2)$ 个区间的枚举本身（$10^{10}$）也过不去。计数必须**按批**进行：找出合法区间的结构性规律，一次推导出一整段的数目。

### 3.2 核心观察：剩余元素 = 前缀递增段拼后缀递增段

![三段结构：合法 ⇔ 前缀递增 + 后缀递增 + 拼接处严格上台阶](images/bw120_q3_prefix_suffix.svg)

删除子数组 $[l, r-1]$ 后，剩余元素必然是**前缀 $[0, l-1]$ 与后缀 $[r, n-1]$ 的拼接**（任一侧可为空）。于是「剩余严格递增」拆成三个独立条件：

1. **前缀严格递增**：$\textit{nums}[0..l-1]$ 递增 $\iff l \le \textit{pre}$，其中 $\textit{pre}$ 是最长严格递增前缀的长度；
2. **后缀严格递增**：$\textit{nums}[r..n-1]$ 递增 $\iff r \ge s$（$r = n$ 时空后缀天然满足），其中 $s$ 是最长严格递增后缀的起点；
3. **拼接处台阶**：两侧都非空时需 $\textit{nums}[l-1] < \textit{nums}[r]$。

若整个数组本就严格递增（$\textit{pre} = n$），任何子数组都合法，直接返回 $n(n+1)/2$。否则可证 $s \ge \textit{pre} \ge 1$（§5 引理 2），三个条件把 $l$ 限制在 $[0, \textit{pre}]$、$r$ 限制在 $[s, n]$ 内。

### 3.3 计数：对每个 $l$，合法 $r$ 是一段后缀区间 → 双指针

![双指针计数：l 增大时 r_min 单调右移](images/bw120_q3_two_pointers.svg)

固定 $l$（$0 \le l \le \textit{pre}$），合法的 $r$ 除「非空约束 $r \ge l+1$」外，还要满足台阶条件 $\textit{nums}[r] > \textit{nums}[l-1]$（$l = 0$ 时无此条件；$r = n$ 时空后缀无需台阶）。由后缀严格递增，$\textit{nums}[r]$ 随 $r$ 增大而增大，**合法的 $r$ 恰是某个右端点 $[r_{\min}(l), n]$ 的整段区间**，贡献 $n - r_{\min}(l) + 1$。

而 $l$ 从小到大时 $\textit{nums}[l-1]$ 严格递增（$l \le \textit{pre}$），故 $r_{\min}(l)$ **单调不减**——不需要每个 $l$ 重新定位，用一个从 $s$ 出发只前进的指针 $r$ 即可，总移动量 $O(n)$：

```text
若 pre == n: 返回 n(n+1)/2            # 整个数组严格递增
r = s
for l in 0..pre:
    r = max(r, l+1)                   # 被删区间非空
    while r < n 且 l > 0 且 nums[r] <= nums[l-1]:
        r += 1                         # 台阶条件不满足就右移
    ans += n - r + 1                   # [r, n] 每个位置都是合法右端
返回 ans
```

> 💡 直觉：**左保留段越长（末值越大），右保留段就必须越靠右**（开头元素更大才能接得上）；这个「越长 → 越靠右」的单调关系就是双指针的引擎。

### 3.4 示例演算

![示例演算：两例的 pre、s 与逐个 l 的计数](images/bw120_q3_walkthrough.svg)

**示例 2**（$[6,5,7,8]$）：$\textit{pre} = 1$（$5 < 6$ 断在 1），$s = 1$（后缀 $[5,7,8]$ 递增）。

| $l$ | 前缀 | 台阶条件 | $r$ 范围 | 贡献 |
|-----|------|----------|-----------|------|
| 0 | 空 | 无 | $[\max(1, 1), 4] = [1, 4]$ | 4 |
| 1 | [6] | $\textit{nums}[r] > 6$ → $r = 2, 3$（7、8）或 $r = 4$（空后缀） | $[2, 4]$ | 3 |

合计 7 ✓。

**示例 3**（$[8,7,6,6]$）：$\textit{pre} = 1$，$s = 3$（后缀只有 $[6]$，因 $6 \not< 6$）。

| $l$ | 前缀 | 台阶条件 | $r$ 范围 | 贡献 |
|-----|------|----------|-----------|------|
| 0 | 空 | 无 | $[\max(1, 3), 4] = [3, 4]$ | 2 |
| 1 | [8] | $\textit{nums}[r] > 8$ 无解 → 只剩 $r = 4$（空后缀，删 $[1, 3]$） | $[4, 4]$ | 1 |

合计 3 ✓（对应删 $[0,2]$、$[0,3]$、$[1,3]$）。

## 4. 算法细节

1. **求 `pre` 与 `s`**：`pre` 从 1 起最长延伸；`s` 从 $n-1$ 起最长向左延伸。注意**严格**比较（`>` / `<`，相等即断）。
2. **特判 `pre == n`**：整个数组递增，答案 $n(n+1)/2$。这个特判也是防御性的：通用循环在 $\textit{pre} = n$ 时 $l$ 会枚举到 $n$，语义混乱，早返回最干净。
3. **`r = max(r, l + 1)`**：保证被删区间 $[l, r-1]$ 非空。正常情况下 $r \ge s \ge \textit{pre} \ge l$，仅当 $l = \textit{pre} = s$ 时需要把 $r$ 从 $s$ 顶到 $s + 1$。
4. **台阶条件的两个豁免**：$l = 0$（空前缀）与 $r = n$（空后缀）都无需比较；循环条件 `r < n and l > 0` 天然实现（短路顺序保证不会越界访问 `nums[r]`）。
5. **溢出**：$n(n+1)/2 \approx 5 \times 10^9$，答案必须 `long long` / Python 任意精度；C++ 里 `1LL * n * (n + 1) / 2` 防止中间溢出。
6. **同向双指针的摊还**：`r` 只增不减，内层 `while` 的总步数为 $O(n)$。

## 5. 正确性证明

**引理 1（判定的三条件分解）**：删除非空子数组 $[l, r-1]$（$0 \le l < r \le n$）后剩余严格递增 $\iff$

- 前缀 $\textit{nums}[0..l-1]$ 严格递增，且
- 后缀 $\textit{nums}[r..n-1]$ 严格递增（$r = n$ 视为空、恒真），且
- $l > 0$ 且 $r < n$ 时 $\textit{nums}[l-1] < \textit{nums}[r]$。

**证明**：剩余序列是前缀与后缀的顺序拼接。拼接序列严格递增 $\iff$ 各自严格递增且拼接处满足 $\textit{nums}[l-1] < \textit{nums}[r]$（拼接处是唯一「跨段」的相邻对）；任一侧为空时跨段对不存在。∎

**引理 2（结构量关系）**：若整个数组不是严格递增，则 $1 \le \textit{pre} \le n - 1$ 且 $s \ge \textit{pre}$。

**证明**：`pre` 与 `s` 按定义存在且 $\textit{pre} \ge 1$、$s \le n - 1$。反设 $s < \textit{pre}$：则 $\textit{pre} - 1 \ge s$，下标 $\textit{pre}-1$、$\textit{pre}$ 均落在严格递增后缀 $[s, n-1]$ 内，得 $\textit{nums}[\textit{pre}] > \textit{nums}[\textit{pre}-1]$，与 `pre` 是最长递增前缀长度（$\textit{nums}[\textit{pre}] \le \textit{nums}[\textit{pre}-1]$，否则还能延伸）矛盾。∎

**引理 3（合法 r 的区间性与单调性）**：固定 $l \in [0, \textit{pre}]$，合法 $r$ 的集合恰为 $[r_{\min}(l), n]$，其中

$$r_{\min}(l) = \max\Big(l+1,\ s,\ \min\{r : s \le r \le n-1,\ \textit{nums}[r] > \textit{nums}[l-1]\}\Big)$$

（$l = 0$ 时去掉第三项），且 $r_{\min}(l)$ 关于 $l$ 单调不减。

**证明**：区间性：$r \ge s$ 保证后缀递增（$[s, n-1]$ 递增则其任何后缀递增）；后缀递增使 $\textit{nums}[r] > \textit{nums}[l-1]$ 一旦在某个 $r$ 成立，对更大的 $r$ 依旧成立，故台阶条件在 $[s, n-1]$ 上是「一段右闭后缀」，加上恒真的 $r = n$（空后缀）与下界 $l + 1$（非空被删区间），合法集为 $[\max(l+1, s, \text{首台阶下标}), n]$。单调性：$l_1 < l_2 \le \textit{pre}$ 时 $\textit{nums}[l_1 - 1] < \textit{nums}[l_2 - 1]$，使台阶条件变严，首个满足的 $r$ 只会右移；$\max$ 中其余两项也不减。∎

**定理**：算法返回移除递增子数组的总数。

**证明**：若整个数组严格递增，任何非空子数组删除后剩余是其子序列，必严格递增，总数即子数组数 $n(n+1)/2$，早返回正确。否则由引理 1、2，合法区间 $[l, r-1]$ 与满足三条件的对 $(l, r)$（$0 \le l < r \le n$，被删非空）一一对应，且 $l$ 的取值范围恰为 $[0, \textit{pre}]$（$l > \textit{pre}$ 时前缀不递增，无解）。由引理 3，每个 $l$ 的贡献为 $n - r_{\min}(l) + 1$，且 $r_{\min}$ 单调不减——算法中指针 $r$ 在处理完 $l$ 后恰停在 $r_{\min}(l)$（`max(r, l+1)` 补齐下界、`while` 推进到首个满足台阶的 $r$，由单调性跨 $l$ 复用不遗漏），累加即总数。∎

## 6. 复杂度分析

- **时间**：$O(n)$。求 `pre`、`s` 各一趟；主循环中 `l` 走 $\textit{pre} + 1$ 步、`r` 全程至多前进 $n$ 步，均摊线性。
- **空间**：$O(1)$。只维护若干下标与计数器。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long incremovableSubarrayCount(vector<int>& nums) {
        int n = (int)nums.size();
        int pre = 1;                                   // 前缀严格递增的最大长度
        while (pre < n && nums[pre] > nums[pre - 1]) ++pre;
        if (pre == n) return 1LL * n * (n + 1) / 2;     // 整个数组严格递增：删谁都可以
        int s = n - 1;                                 // 后缀严格递增的起点
        while (s > 0 && nums[s - 1] < nums[s]) --s;

        long long ans = 0;
        int r = s;
        for (int l = 0; l <= pre; ++l) {               // 左保留段 nums[0..l-1]
            if (r < l + 1) r = l + 1;                  // 被删区间 [l, r-1] 非空
            while (r < n && l > 0 && nums[r] <= nums[l - 1]) ++r;
            ans += n - r + 1;                          // r..n 每个位置都能作为右段起点
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def incremovableSubarrayCount(self, nums: list[int]) -> int:
        n = len(nums)
        pre = 1                                # 前缀严格递增的最大长度
        while pre < n and nums[pre] > nums[pre - 1]:
            pre += 1
        if pre == n:                          # 整个数组严格递增：删谁都可以
            return n * (n + 1) // 2
        s = n - 1                             # 后缀严格递增的起点
        while s > 0 and nums[s - 1] < nums[s]:
            s -= 1

        ans = 0
        r = s
        for l in range(pre + 1):              # 左保留段 nums[0..l-1]
            if r < l + 1:
                r = l + 1                      # 被删区间 [l, r-1] 非空
            while r < n and l > 0 and nums[r] <= nums[l - 1]:
                r += 1
            ans += n - r + 1                   # r..n 每个位置都能作为右段起点
        return ans
```

> 💡 两份代码均通过官方示例（`10`、`7`、`3`），并与「枚举全部 $(l, r)$ + 独立 $O(n)$ 判定」的 $O(n^3)$ 暴力对拍 3000 组随机数组（含整体递增、整体递减、小值域高重复），`mismatch = 0`；同场 Q1 的暴力亦与本题解法交叉对拍一致。

## 8. 边界情况与易错点

1. **整个数组严格递增**：必须特判返回 $n(n+1)/2$；否则 `s = 0`、主循环的 `l` 范围会越界到 $n$，语义直接错。
2. **溢出**：答案上限 $\approx 5 \times 10^9$，C++ 返回 `long long`，且 $n(n+1)$ 先乘后除要写 `1LL *`。
3. **严格递增**：`pre`/`s` 的延伸条件用 `>` / `<`；相等元素（示例 3 的双 6）立刻截断递增段。
4. **两个空侧的豁免**：`l = 0` 无台阶条件、`r = n` 空后缀恒真——`while` 条件里 `r < n && l > 0` 的短路顺序同时避免了越界访问 `nums[n]`。
5. **被删区间非空**：`r = max(r, l + 1)`；漏掉会在 $l = \textit{pre} = s$ 的边界上把「删空区间」也计入。
6. **`r` 的初值是 `s` 不是 0**：右保留段必须整体落在最长递增后缀内，从 0 起会让「后缀不递增」的区间混进计数。
7. **双指针方向**：`l` 与 `r` **同向递增**；若对每个 `l` 重置 `r`，最坏退化为 $O(n^2)$（如整体递减数组）。
