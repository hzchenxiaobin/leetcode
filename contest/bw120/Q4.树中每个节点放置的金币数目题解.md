# LeetCode 树中每个节点放置的金币数目 题解

## 1. 题目概述

- **标题 / 题号**：树中每个节点放置的金币数目（#2973，hard）
- **链接**：https://leetcode.cn/problems/find-number-of-coins-to-place-in-tree-nodes/
- **来源**：LeetCode 第 120 场双周赛 Q4
- **难度**：困难
- **标签**：树、深度优先搜索、动态规划、排序、树形 DP、堆（优先队列）

**题意**：给定 $n$ 个节点的无向树（根为节点 0）与开销数组 `cost`（`cost[i]` 可正可负，$1 \le |cost[i]|$）。在节点 $i$ 放置的金币数目 `coins[i]` 按如下规则计算：

- 若节点 $i$ 的**子树**中节点数目小于 3，放置 **1** 个金币；
- 否则，取子树内 **3 个不同节点**的开销**乘积的最大值**作为金币数；若该最大乘积为**负数**，则放置 **0** 个金币。

返回长度为 $n$ 的数组 `coins`。

**约束**：

- $2 \le n \le 2 \times 10^4$
- `edges` 一定是一棵合法的树
- $1 \le |cost[i]| \le 10^4$

## 2. 示例

**示例 1**

```text
输出：[120,1,1,1,1,1]
解释：节点 0 的子树是整棵树，最大乘积 6×5×4 = 120；
      其余节点都是叶子，子树仅 1 个节点，各放 1 个金币。
```

**示例 2**

```text
输出：[280,140,32,1,1,1,1,1,1]
解释：节点 0：8×7×5 = 280；节点 1（子树 {1,3,4,5}）：7×5×4 = 140；

```


## 3. 解题思路

### 3.1 暴力思路

对每个节点 $i$ 收集其子树的全部开销再求三元最大乘积：收集本身若从 $i$ 向下遍历是 $O(\text{子树大小})$，全部节点合计最坏 $O(n^2)$（链形树达到上界 $2 \times 10^4{}^2 = 4 \times 10^8$），再加上三元组合枚举更是不可行。**瓶颈在「每个父节点都重新收集整棵子树」**——需要把子树信息**自底向上合并**，并且只保留必要的信息。

### 3.2 核心观察一：三元最大乘积只取决于「最大 3 个 + 最小 2 个」

![最大三元乘积的三种符号情形：3 大之积 vs 两小乘一大](images/bw120_q4_product_cases.svg)

子树内 3 个不同节点开销的最大乘积，是排序数组的经典结论：设子树全部开销升序为 $a_1 \le \cdots \le a_m$，则

$$\max_{\text{三元}} = \max\big(a_m \cdot a_{m-1} \cdot a_{m-2},\ \ a_1 \cdot a_2 \cdot a_m\big)$$

- **全非负**：三个最大值之积最优；
- **恰两个大负数**：两个最小（负）与最大值之积最优（负负得正）；
- **乘积只能为负**（全部为负）：三个「最大」（绝对值最小）之积最优，结果为负 → 金币记 0。

因此**每棵子树只需向上传递 5 个候选值：最大的 3 个与最小的 2 个**，信息可完全压缩。

### 3.3 核心观察二：top-3/bottom-2 在合并下封闭 → 后序一次 DFS

![后序合并：每个子树只传 5 个候选值给父节点](images/bw120_q4_merge_concept.svg)

合并的封闭性：若每个孩子已经保留其子树的「top-3 + bottom-2」，那么**父子树**（全部孩子 ∪ 自身）的 top-3 与 bottom-2 必落在「各孩子候选值 ∪ 自身开销」之中——某个值若在自家子树里排不进 top-3，它在更大的并集里更排不进（同子树内已有 3 个更大的值）；bottom-2 同理。于是自底向上，每个节点把「孩子们各至多 5 个候选 + 自身 1 个」合并、排序、截取成新的 5 个候选，同时顺手算出本节点的金币数。整棵树恰好一次后序遍历，每个节点合并的列表长度是 $O(\text{孩子数})$ 常数级别。

> 💡 复杂度的直觉：候选列表长度被**钉死在 5**，合并的工作量正比于「孩子个数」，所有节点的孩子个数之和就是 $n - 1$ —— 总时间线性。

### 3.4 算法流程

```text
1. 建邻接表；从根 0 遍历求 parent[] 与前序 order
2. 按 order 逆序处理（孩子先于父亲）：
     cur = [cost[u]] ⊕ 各孩子已保留的候选值（至多 5×deg 个）
     sz[u] = 1 + Σ sz[孩子]
     若 sz[u] ≥ 3:
         cur 排序，best = max(末三大之积, 首两小 × 最大)
         ans[u] = best > 0 ? best : 0
     否则 ans[u] = 1
     把 cur 缩减回「最大 3 + 最小 2」（≤ 5 个），传给父节点
```

### 3.5 示例演算

![示例 2 演算：自底向上的合并与各节点金币](images/bw120_q4_example_tree.svg)

以示例 2 为例（树形见插图）：叶子节点 $3..8$ 各自上传 $[\text{cost}]$。节点 1 收到 $[3],[5],[7]$ 加自身 4，合并排序得 $[3,4,5,7]$，共 4 个节点 $\ge 3$，最大乘积 $\max(7 \times 5 \times 4,\ 3 \times 4 \times 7) = 140$；节点 2 收到 $[8],[-4],[2]$ 加自身 2，得 $[-4,2,2,8]$，$\max(8 \times 2 \times 2,\ (-4) \times 2 \times 8) = 32$。最后节点 0 汇总两个孩子的候选 $[3,4,5,7]$、$[-4,2,2,8]$ 与自身 1，排序后取 $\max(8 \times 7 \times 5,\ (-4) \times 2 \times 8) = 280$。

## 4. 算法细节

1. **遍历方式**：$n$ 可达 $2 \times 10^4$，链形树递归深度 $2 \times 10^4$ 有爆栈风险（尤其 Python 默认递归上限 1000）。两份参考代码都用**迭代**：先从根做一次显式栈遍历得 `parent` 与前序 `order`，再按 `order` 逆序处理——前序的逆序保证任意节点出现在其全部祖先之前，即「孩子先于父亲」。
2. **孩子识别**：对节点 $u$ 的邻居 $v$，`parent[v] == u` 即孩子（根 0 的 parent 为 $-1$）。
3. **合并与缩减**：合并后列表长度 $= 1 + \sum \min(sz_v, 5) \le 1 + 5\deg$；排序取 `[:2] + [-3:]` 缩回 5 个（长度 $\le 5$ 时全保留）。长度 $> 5$ 时首两与末三不重叠，下标安全。
4. **金币计算时机**：在缩减**之前**、用完整的合并列表算——此时 top-3 / bottom-2 齐备，公式直接适用；`sz[u] ≥ 3` 保证列表长度 $\ge 3$（见 §5 引理 3）。
5. **负零处理**：$|cost[i]| \ge 1$，乘积不可能为 0，`best > 0 ? best : 0` 的两分支覆盖全部情况；负乘积归零。
6. **溢出**：$|cost| \le 10^4$，乘积上界 $10^{12}$，C++ 用 `long long`（返回类型 `long[]`）；Python 任意精度无虞。
7. **内存**：孩子候选合并进父节点后立即清空（`cand[v].clear()`），峰值是 $O(n)$ 个长度 $\le 5$ 的列表。

## 5. 正确性证明

**引理 1（三元乘积公式）**：对多重集合 $S$，$|S| = m \ge 3$，设升序 $a_1 \le \cdots \le a_m$，则 3 个不同元素乘积的最大值为 $\max(a_m a_{m-1} a_{m-2},\ a_1 a_2 a_m)$。记该值为 $C$。

**证明**：先证 $C$ 可达：两候选各对应 $S$ 中三个真实存在的元素，故最大乘积 $\ge C$。再证任意三元积 $\le C$：设任意三元升序 $x \le y \le z$。

**情形一：$xyz \ge 0$。** (a) $x \ge 0$（全非负）：由 $a_m \ge z$、$a_{m-1} \ge y$、$a_{m-2} \ge x$（三个非负因子分别被三个更大的值替换，积不降），$xyz \le a_m a_{m-1} a_{m-2} \le C$。(b) $x \le y < 0 \le z$（恰两负）：此时 $S$ 至少含两个负数，故 $a_1 \le a_2 < 0$。由 $a_1$ 最小得 $|x| \le |a_1|$。对 $y$：若 $y \ge a_2$ 则 $|y| \le |a_2|$，得 $|xy| \le |a_1||a_2| = a_1 a_2$；若 $y < a_2$，则 $x, y$ 是 $S$ 中两个小于 $a_2$ 的元素，而 $S$ 中小于 $a_2$ 的元素至多一个（$a_1$ 的出现），故 $x = y = a_1$，$|xy| = |a_1|^2 \le |a_1||a_2|$。两种情况均有 $xy \le a_1 a_2$；再由 $z \le a_m$ 且 $a_1 a_2 > 0$ 得 $xyz = xy \cdot z \le a_1 a_2 \cdot a_m \le C$。

**情形二：最大乘积 $< 0$。** 若 $S$ 含非负元素：或者 $S$ 有两个负数，取它们与该非负元素得积 $\ge 0$；或者 $S$ 的负数至多一个，则至少有三个非负数，积 $\ge 0$——都与「最大乘积 $< 0$」矛盾。故 $S$ 全负，此时三元积恒负，最大者即绝对值最小者，取绝对值最小的三个（即最靠近 0 的三个）$a_m, a_{m-1}, a_{m-2}$，得 $xyz \le a_m a_{m-1} a_{m-2} = C$（且 $a_1 a_2 a_m$ 绝对值更大，不优于它）。

综上任意三元积 $\le C$，且 $C$ 可达，公式成立。∎

**引理 2（候选集封闭性）**：设 $T_u$ 为节点 $u$ 的子树开销多重集，`cand[u]` 为算法保留的集合（$|T_u| \le 5$ 时为 $T_u$ 全体，否则为 $T_u$ 的 top-3 ∪ bottom-2）。则对任意 $u$：$T_u$ 的 top-3 与 bottom-2 都包含于 $\{cost[u]\} \cup \bigcup_{v\ \text{孩子}} \text{cand}[v]$。

**证明**：对子树大小归纳。叶子：`cand` = 自身开销，显然。内部节点：$T_u$ 中任一值 $x$ 若不属于任何孩子子树则 $x = cost[u]$，在合并集中；否则 $x \in T_v$（某孩子 $v$）。若 $x$ 是 $T_u$ 的 top-3 之一：$x$ 在 $T_v$ 中排位 $t$，则 $T_v$ 中有 $t - 1$ 个 $\ge x$ 的值，它们也都在 $T_u$ 中，故 $t \le 3$，即 $x \in$ `cand[v]` 的 top-3。bottom-2 同理（排位前 2）。∎

**引理 3（长度下界）**：若 $|T_u| \ge 3$，则合并列表的长度 $\ge 3$。

**证明**：归纳可证 $|\text{cand}[v]| = \min(|T_v|, 5)$。$|T_u| \ge 3$ 时：若某孩子 $|T_v| \ge 3$，则 `cand[v]` 至少 3 个，加自身得 $\ge 4$；否则全部孩子大小 $\le 2$，各 `cand[v]` $= |T_v|$，合并长度 $= |T_u| \ge 3$。∎

**定理**：算法对每个节点正确算出金币数，总时间 $O(n)$。

**证明**：处理节点 $u$ 时，所有孩子已处理完（前序逆序保证），合并列表由引理 2 覆盖 $T_u$ 的 top-3 与 bottom-2，由引理 1 该 5 个值足以算出三元最大乘积，`best` 正确；`sz[u]` 为子树大小，`< 3` 时按题意输出 1，`≥ 3` 时输出 $\max(0, \text{best})$，与定义逐条对应。复杂度：每个节点合并的列表长度 $\le 1 + 5 \cdot \text{孩子数}$，排序常数开销，全树孩子总数为 $n - 1$，故总时间 $O(n)$、空间 $O(n)$。∎

## 6. 复杂度分析

- **时间**：$O(n)$。每个节点的合并列表长度 $\le 1 + 5\deg(u)$，排序量 $O(5\deg \log)$ 视为常数；$\sum_u \deg(u) = 2(n-1)$。实测 $n = 2 \times 10^4$（链 + 随机树）C++ 约 3–5 ms。
- **空间**：$O(n)$。邻接表 $O(n)$、候选列表总计 $\le 5n$、`order`/`parent`/`sz` 各 $O(n)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<long long> placedCoins(vector<vector<int>>& edges, vector<int>& cost) {
        int n = (int)cost.size();
        vector<vector<int>> g(n);
        for (const auto& e : edges) {
            g[e[0]].push_back(e[1]);
            g[e[1]].push_back(e[0]);
        }
        // 任意序遍历求父节点：order 是合法前序，逆序处理保证子节点先于父节点
        vector<int> parent(n, -1), order, stk = {0};
        vector<bool> vis(n, false);
        vis[0] = true;
        while (!stk.empty()) {
            int u = stk.back(); stk.pop_back();
            order.push_back(u);
            for (int v : g[u]) if (!vis[v]) {
                vis[v] = true; parent[v] = u; stk.push_back(v);
            }
        }

        vector<long long> ans(n, 1);
        vector<vector<int>> cand(n);          // 每棵子树只需保留：最大 3 个 + 最小 2 个开销
        vector<int> sz(n, 0);
        for (int i = n - 1; i >= 0; --i) {
            int u = order[i];
            vector<int>& cur = cand[u];
            cur.push_back(cost[u]);
            sz[u] = 1;
            for (int v : g[u]) if (parent[v] == u) {
                sz[u] += sz[v];
                for (int x : cand[v]) cur.push_back(x);
                cand[v].clear();
            }
            if (sz[u] >= 3) {
                sort(cur.begin(), cur.end());
                int m = (int)cur.size();
                long long best = max(1LL * cur[m - 1] * cur[m - 2] * cur[m - 3],
                                     1LL * cur[0] * cur[1] * cur[m - 1]);
                ans[u] = best > 0 ? best : 0;  // 最大乘积为负 → 0 个金币
            }
            if ((int)cur.size() > 5) {         // 缩减回「最大 3 + 最小 2」
                sort(cur.begin(), cur.end());
                vector<int> keep(cur.begin(), cur.begin() + 2);
                keep.insert(keep.end(), cur.end() - 3, cur.end());
                cur.swap(keep);
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def placedCoins(self, edges: list[list[int]], cost: list[int]) -> list[int]:
        n = len(cost)
        g = [[] for _ in range(n)]
        for a, b in edges:
            g[a].append(b)
            g[b].append(a)
        # 迭代遍历求父节点：order 是合法前序，逆序处理保证子节点先于父节点
        parent = [-1] * n
        order = []
        vis = [False] * n
        vis[0] = True
        stack = [0]
        while stack:
            u = stack.pop()
            order.append(u)
            for v in g[u]:
                if not vis[v]:
                    vis[v] = True
                    parent[v] = u
                    stack.append(v)

        ans = [1] * n
        cand = [[] for _ in range(n)]   # 每棵子树只需保留：最大 3 个 + 最小 2 个开销
        sz = [0] * n
        for u in reversed(order):
            cur = [cost[u]]
            sz[u] = 1
            for v in g[u]:
                if parent[v] == u:
                    sz[u] += sz[v]
                    cur.extend(cand[v])
                    cand[v] = []
            if sz[u] >= 3:
                cur.sort()
                best = max(cur[-1] * cur[-2] * cur[-3],
                           cur[0] * cur[1] * cur[-1])
                ans[u] = best if best > 0 else 0     # 最大乘积为负 → 0 个金币
            if len(cur) > 5:                          # 缩减回「最大 3 + 最小 2」
                cur.sort()
                cand[u] = cur[:2] + cur[-3:]
            else:
                cand[u] = cur
        return ans
```

> 💡 两份代码均通过官方示例（`[120,1,1,1,1,1]`、`[280,140,32,1,1,1,1,1,1]`、`[0,1,1]`），并与独立暴力（欧拉序求子树 + 枚举全部 $C(|T|, 3)$ 三元组）对拍 2500 组随机树（$n \le 9$、开销取 $[-5,5] \setminus \{0\}$），另以 $n = 2 \times 10^4$ 的链形树做深度与正确性抽查，`mismatch = 0`。

## 8. 边界情况与易错点

1. **深树爆栈**：$n = 2 \times 10^4$ 的链会击穿递归（Python 默认上限 1000，C++ 也有栈深风险）；务必迭代化或显式扩栈。
2. **负开销**：`[-4, 2, 2, 8]` 的最优解是 $8 \times 2 \times 2$ 而不是丢掉负数——两个负数相乘变正，**bottom-2 必须保留**；只传 top-3 是最常见错解。
3. **全负子树**：三元积必为负 → 金币为 0，而不是 1；`< 3` 个节点才是 1。
4. **乘积溢出**：$10^4 \times 10^4 \times 10^4 = 10^{12}$，C++ 中间量必须 `long long`（`1LL *` 起手），返回类型题目已给 `long[]`。
5. **缩减下标**：`cur[:2] + cur[-3:]` 仅在长度 $\ge 5$（实际 $> 5$ 即 $\ge 6$）时执行，首两与末三不重叠；长度恰为 5 时全保留即可，不要重复加入。
6. **「3 个不同节点」**：指节点不同，值可以重复（如 $[8,2,2]$ 合法）——候选列表是**多重集**语义，合并时不要去重。
7. **根不是 0 的编号陷阱**：题目固定根为 0，`parent[0] = -1` 即可；若输入边顺序把 0 放在后半，显式栈遍历仍正确。
