# LeetCode 统计移除递增子数组的数目 I 题解

## 1. 题目概述

- **标题 / 题号**：统计移除递增子数组的数目 I（#2970，easy）
- **链接**：https://leetcode.cn/problems/count-the-number-of-incremovable-subarrays-i/
- **来源**：LeetCode 第 120 场双周赛 Q1
- **难度**：简单
- **标签**：数组、双指针、二分查找、枚举

**题意**：给定正整数数组 `nums`。若删除 `nums` 的某个**非空连续子数组**后，剩余元素（可能为空）构成**严格递增**序列，则该子数组称为**移除递增子数组**。求移除递增子数组的总数目。

**约束**：

- $1 \le \textit{nums.length} \le 50$
- $1 \le \textit{nums}[i] \le 50$

## 2. 示例

**示例 1**

```text
输入：nums = [1,2,3,4]
输出：10
解释：整个数组严格递增，删掉任意子数组后剩余仍递增，
      子数组总数 n(n+1)/2 = 4×5/2 = 10。
```

**示例 2**

```text
输入：nums = [6,5,7,8]
输出：7
解释：合法的被删区间为 [5]、[6]、[5,7]、[6,5]、[5,7,8]、[6,5,7]、[6,5,7,8]。
```

**示例 3**

```text
输入：nums = [8,7,6,6]
输出：3
解释：只能删 [8,7,6]、[7,6,6]、[8,7,6,6]；删 [8,7] 剩 [6,6] 不是严格递增。
```

## 3. 解题思路

### 3.1 暴力思路（本题正解）

$n \le 50$，被删子数组由左右端点 $(l, r)$（$l \le r$）决定，共 $\dfrac{n(n+1)}{2} \le 1275$ 个；每个用 $O(n)$ 判定「剩余元素是否严格递增」，总量 $O(n^3) \approx 1.6 \times 10^5$，瞬间完成。数据范围已经明示了暴力：**先枚举，再判定，别想复杂了**。

### 3.2 核心观察：判定就是「跳过区间后逐对比较」

![枚举被删区间 [l, r]，跳过后检查剩余严格递增](images/bw120_q1_bruteforce.svg)

子数组 $[l, r]$ 与有序对 $(l, r)$（$0 \le l \le r \le n-1$）一一对应，**枚举不重不漏**。判定函数把下标 $l \sim r$ 跳过后，从头到尾检查相邻剩余元素满足 $prev < cur$；剩余为空（删的就是整个数组）视为递增——题面明确「剩余元素为空的数组也视为是递增的」。

> 💡 实现上用一个 `started` 标志区分「第一个剩余元素」，比拿 $0$ 当哨兵更稳：虽然本题元素为正整数、哨兵 $0$ 恰好可用，但哨兵写法在值域含非正数时会静默出错。

### 3.3 算法流程

```text
ans = 0
for l in 0..n-1:
    for r in l..n-1:
        若 remove(nums, l, r) 后剩余严格递增: ans += 1
返回 ans
```

其中判定：

```text
prev 未初始化, started = false
for i in 0..n-1:
    若 l ≤ i ≤ r: continue          # 跳过被删区间
    若 started 且 nums[i] ≤ prev: return false
    prev = nums[i], started = true
return true                          # 剩空 / 单元素 / 严格递增都合法
```

## 4. 算法细节

1. **枚举顺序**：双重循环 `l ≤ r`，保证每个子数组恰好一次。
2. **判定写法**：跳过 $[l, r]$ 后只需维护「上一个保留下来的元素」，与第一个保留元素之前的比较不需要哨兵值。
3. **复杂度核算**：$O(n^3)$ 在 $n = 50$ 时约 $1.6 \times 10^5$ 次基本操作，远低于任何限制。
4. **与 Q3（#2972）的关系**：Q3 是同一道题、$n$ 放大到 $10^5$、返回类型改 `long`。本题的暴力判定是 Q3 对拍的黄金参照；$O(n)$ 解法见同场 Q3 题解。

## 5. 正确性证明

**引理（子数组与端点对双射）**：$\{[l, r] : 0 \le l \le r \le n-1\}$ 与 `nums` 的全部非空连续子数组一一对应。

**证明**：非空连续子数组按定义为某段 $a_l, a_{l+1}, \dots, a_r$，端点即其表示；同一对 $(l, r)$ 只对应一段。∎

**定理**：算法返回移除递增子数组的总数目。

**证明**：算法枚举的集合与全部非空子数组一一对应（引理），判定函数逐字实现定义：「删除 $[l, r]$ 后剩余元素严格递增」，其中空剩余按题面视为递增——判定为真的子数组恰为移除递增子数组，每个被计数一次。∎

## 6. 复杂度分析

- **时间**：$O(n^3)$——$O(n^2)$ 个区间每个 $O(n)$ 判定；$n = 50$ 时约 $1.6 \times 10^5$ 次。
- **空间**：$O(1)$，判定原地扫描，不复制数组。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int incremovableSubarrayCount(vector<int>& nums) {
        int n = (int)nums.size(), ans = 0;
        for (int l = 0; l < n; ++l) {
            for (int r = l; r < n; ++r) {
                if (isIncreasingAfterRemove(nums, l, r)) ++ans;
            }
        }
        return ans;
    }
private:
    bool isIncreasingAfterRemove(vector<int>& nums, int l, int r) {
        bool started = false;
        int prev = 0;
        for (int i = 0; i < (int)nums.size(); ++i) {
            if (i >= l && i <= r) continue;      // 跳过被删区间
            if (started && nums[i] <= prev) return false;
            prev = nums[i];
            started = true;
        }
        return true;                             // 剩余为空也算严格递增
    }
};
```

### Python

```python
class Solution:
    def incremovableSubarrayCount(self, nums: list[int]) -> int:
        n = len(nums)
        ans = 0
        for l in range(n):
            for r in range(l, n):
                if self._ok(nums, l, r):
                    ans += 1
        return ans

    def _ok(self, nums: list[int], l: int, r: int) -> bool:
        prev = None
        for i, x in enumerate(nums):
            if l <= i <= r:        # 跳过被删区间
                continue
            if prev is not None and x <= prev:
                return False
            prev = x
        return True                # 剩余为空也算严格递增
```

> 💡 两份代码均通过官方示例（`10`、`7`、`3`），并与同场 Q3 的 $O(n)$ 双指针解法交叉对拍 3000 组随机数组（含整体递增 / 整体递减 / 小值域高重复），`mismatch = 0`。

## 8. 边界情况与易错点

1. **被删子数组必须非空**：题面明确「空数组不是移除递增子数组」，枚举 $l \le r$ 天然满足；不要把「剩余为空」与「被删为空」混淆——前者合法（删整个数组），后者不存在。
2. **严格递增不含相等**：示例 3 中 $[6,6]$ 不递增；判定必须用 `<=` 拒绝相等。
3. **整个数组递增**：答案 $n(n+1)/2$，可作快速自检（示例 1）。
4. **$n = 1$**：唯一子数组 $[0,0]$，删除后剩余为空，答案 1。
5. **返回类型**：本题 `int` 足够（$\le 1275$）；同场 Q3 中 $n = 10^5$，必须 `long long`，照搬代码会溢出。
6. **哨兵陷阱**：用 `prev = 0` 又不区分首个元素时，若值域含 0 或负数会误判；本题正整数侥幸可行，但 `started` 标志（或 `prev = None`）才是可迁移的写法。
