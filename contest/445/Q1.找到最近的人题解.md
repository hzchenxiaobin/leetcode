# LeetCode 找到最近的人 题解

## 1. 题目概述

- **标题 / 题号**：找到最近的人（#3516，easy）
- **链接**：https://leetcode.cn/problems/find-closest-person/
- **来源**：LeetCode 第 445 场周赛 Q1
- **难度**：简单
- **标签**：数学

**题意**：数轴上有三个人：第 1 人在位置 $x$，第 2 人在位置 $y$，第 3 人在位置 $z$ 且**不会移动**。前两人**同时、以相同的速度**向第 3 个人移动，判断谁会**先**到达 $z$：第 1 人先到返回 `1`，第 2 人先到返回 `2`，两人同时到达返回 `0`。

**约束**：

- $1 \le x, y, z \le 100$

> 💡 **读题关键**：① "**相同的速度**"把一个看似动态的追逐问题坍缩成**静态的距离比较**——速度是共同的分母，时间序即距离序；② $x$、$y$ 相对 $z$ 的**方位没有任何约束**（示例 1 的 $y$ 就在 $z$ 右侧），路程 = 数轴间距 $\lvert x - z \rvert$，**绝对值是全题唯一的考点**；③ 题面也不保证 $x \ne z$、$x \ne y$——开局已就位、两人同点甚至三人同点都要兜住（见 §8）。

## 2. 示例

**示例 1**

```text
输入：x = 2, y = 7, z = 4
输出：1
解释：第 1 人需走 |2−4| = 2 步，第 2 人需走 |7−4| = 3 步，第 1 人先到。
      注意第 2 人在 z 的右侧，是向左走的。
```

**示例 2**

```text
输入：x = 2, y = 5, z = 6
输出：2
解释：第 1 人需走 4 步，第 2 人需走 1 步，第 2 人先到（两人都在 z 左侧）。
```

**示例 3**

```text
输入：x = 1, y = 5, z = 3
输出：0
解释：两人都需走 2 步，同轮到达。
```

## 3. 解题思路

### 3.1 暴力思路：逐轮模拟

按时间步模拟，每轮两人各向 $z$ 挪一格，挪完检查谁踩到了 $z$：

```text
while true:
    if x == z and y == z: return 0   # 同轮到达（含开局三人同点）
    if x == z: return 1              # 第 1 人先踩到
    if y == z: return 2              # 第 2 人先踩到
    x += sign(z - x)                 # 各自朝 z 挪 1 格
    y += sign(z - y)
```

复杂度 $O(\max(d_1, d_2)) \le 99$，本题范围下提交也能过。但盯着循环体看：**两个距离每轮各自严格减 1**，没有任何分支与决策——第 1 人必在第 $d_1$ 轮到达，第 2 人必在第 $d_2$ 轮到达。既然"到达轮数"闭式可算，循环本身就是纯粹的浪费，直接比较两个轮数即可。

### 3.2 核心观察：同速竞速 → 只比绝对距离

![核心观察：数轴上的距离比较](images/c445_q1_number_line_distance.svg)

**结论**：设 $d_1 = \lvert x - z \rvert$，$d_2 = \lvert y - z \rvert$，则

- $d_1 < d_2$：返回 $1$；
- $d_2 < d_1$：返回 $2$；
- $d_1 = d_2$：返回 $0$。

理由只有一行：**速度相同** ⇒ 到达时间 $= \frac{\text{距离}}{\text{速度}}$，分母相同，时间的大小关系完全由分子决定——同速、同时出发的两人，**先到 ⇔ 更近**。

**绝对值是全题唯一的坑**：$x$、$y$ 与 $z$ 的相对方位没有任何约束——两人都在 $z$ 左侧（示例 2）、都在右侧、或一左一右（示例 1 的 $y = 7 > z = 4$，向左走）都可能。而"向 $z$ 移动的路程"就是数轴上两点的**间距**，与从哪一侧出发无关。

> ⚠️ **常见错误**：直接写 `z - x`、`y - z` 不加绝对值。任何只取单一方向差值的写法，都必然在另一侧的用例上得到**负距离**——如示例 1 的 `z - y = -3` 会把"3 步到"误判成"−3 步到"，比较方向全错。

### 3.3 算法流程

![算法流程：两次绝对值 + 一次三分支比较](images/c445_q1_decision_flow.svg)

| 步骤 | 动作 | 说明 |
|------|------|------|
| ① 算距离 | $d_1 = \lvert x - z \rvert$，$d_2 = \lvert y - z \rvert$ | 绝对值兼容 $z$ 两侧方位 |
| ② 第一分支 | $d_1 < d_2$ → 返回 `1` | 第 1 人更近 |
| ③ 第二分支 | $d_2 < d_1$ → 返回 `2` | 第 2 人更近 |
| ④ 兜底 | 否则返回 `0` | $d_1 = d_2$，同轮到达 |

两次减法、两次绝对值、至多两次比较——没有循环、没有数组，**与坐标范围彻底解耦**。

### 3.4 示例演算

![示例演算：三个示例的数轴快照](images/c445_q1_example_walkthrough.svg)

| $x$ | $y$ | $z$ | $d_1 = \lvert x-z \rvert$ | $d_2 = \lvert y-z \rvert$ | 比较 | 返回 |
|-----|-----|-----|------|------|------|------|
| 2 | 7 | 4 | 2 | 3 | $d_1 < d_2$ | 1 |
| 2 | 5 | 6 | 4 | 1 | $d_2 < d_1$ | 2 |
| 1 | 5 | 3 | 2 | 2 | $d_1 = d_2$ | 0 |

> 💡 第 1 行里 $y = 7 > z = 4$：第 2 人在目标**右侧**、向左走——若不取绝对值，`z - y = -3` 直接为负，胜负判断彻底翻转。绝对值不是装饰，是正确性的一部分。

## 4. 算法细节

1. **距离公式**：$d = \lvert x - z \rvert$。数轴上两点的间距天然用绝对值表示，兼容从任一侧出发；不要对"谁在左边"做任何假设或特判。
2. **三分支写法**：两个 `if` 一路短路，平局 $d_1 = d_2$ 落到兜底 `return 0`——无需单独写第三种判断，天然覆盖 $x = y = z$ 三人同点的开局。
3. **速度归一**：把"每轮走 1 格"当作速度 1，"到达轮数"就等于距离本身——这是从模拟过渡到公式的那一步。
4. **与范围解耦**：没有循环与数组，$x, y, z$ 放大到 $10^{18}$ 也依旧是常数次运算（C++ 换 `long long` 即可），而逐轮模拟在 $10^9$ 时就跑不动了。

## 5. 正确性证明

**引理 1（路程 = 绝对间距）**：从位置 $p$ 出发、每步向 $z$ 靠近 1，到达 $z$ 恰需 $\lvert p - z \rvert$ 步。

**证明**：对步数 $k$ 归纳。初始（$k = 0$）距离为 $\lvert p - z \rvert$；只要未到达，每步沿朝向 $z$ 的方向移动 1，距离严格减 1。故第 $k$ 步后距离为 $\lvert p - z \rvert - k$（$k \le \lvert p - z \rvert$），距离归零当且仅当 $k = \lvert p - z \rvert$，且此前距离恒正、尚未到达。∎

**引理 2（先到 ⇔ 更近）**：两人同时出发、速度同为 $v > 0$，则 $t_1 < t_2 \iff d_1 < d_2$。

**证明**：$t_i = d_i / v$。$v > 0$ 时，$d_1 / v < d_2 / v$ 两边同乘 $v$ 得 $d_1 < d_2$，反之亦然——除以同一正数保持序关系。∎

**定理**：算法三个返回值均正确。

**证明**：把速度归一为每轮 1 格，由引理 1，第 1 人到达轮数为 $d_1 = \lvert x - z \rvert$，第 2 人为 $d_2 = \lvert y - z \rvert$。由引理 2（即直接比较轮数）：$d_1 < d_2$ 时第 1 人先到，返回 `1` 正确；$d_2 < d_1$ 时对称，返回 `2` 正确；$d_1 = d_2$ 时两人同轮踩到 $z$，返回 `0` 正确。三种情形互斥且完备。∎

## 6. 复杂度分析

- **时间复杂度**：$O(1)$。两次减法、两次绝对值、至多两次比较；对照模拟版的 $O(\max(d_1, d_2)) \le 99$。
- **空间复杂度**：$O(1)$。仅两个距离变量。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int findClosest(int x, int y, int z) {
        int d1 = abs(x - z), d2 = abs(y - z);   // 绝对值兼容 z 两侧方位
        if (d1 < d2) return 1;
        if (d2 < d1) return 2;
        return 0;                               // 平局兜底，天然覆盖 x==y==z
    }
};
```

### Python

```python
class Solution:
    def findClosest(self, x: int, y: int, z: int) -> int:
        d1, d2 = abs(x - z), abs(y - z)
        if d1 < d2:
            return 1
        if d2 < d1:
            return 2
        return 0
```

> 💡 Python 一行版：`return (d1 < d2) + 2 * (d1 > d2)`——布尔值即 0/1，两个互斥条件加权求和恰好落在 $\{0, 1, 2\}$ 上。

## 8. 边界情况与易错点

1. **绝对值不能省**：示例 1 的 `z - y = -3` 会把"3 步"误判成"−3 步"，任何单方向差值的写法都必然在某一侧的用例上翻车。
2. **开局已就位**：$x = z$ 时 $d_1 = 0$，第 1 人立即获胜；但 $x = y = z$ 三人同点时 $d_1 = d_2 = 0$，应返回 `0` 而非 `1`——平局兜底分支恰好接住。
3. **同侧 / 异侧都要兼容**：示例 2 两人同在 $z$ 左侧，示例 1 一左一右，绝对值统一处理，不要写方位特判。
4. **返回值有三态**：`0 / 1 / 2`，只写两个 `if` 漏掉 `0` 分支是典型 WA。
5. **无溢出风险**：$1 \le x, y, z \le 100$，差值绝对值 $\le 99$，`int` 绰绰有余。
