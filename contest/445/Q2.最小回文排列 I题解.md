# LeetCode 最小回文排列 I 题解

## 1. 题目概述

- **标题 / 题号**：最小回文排列 I（#3517，medium）
- **链接**：https://leetcode.cn/problems/smallest-palindromic-rearrangement-i/
- **来源**：LeetCode 第 445 场周赛 Q2
- **难度**：中等
- **标签**：字符串、计数排序、排序

**题意**：给定一个保证为**回文**的字符串 $s$，把其中字符**全部重排**，返回所有排列中**字典序最小**且**仍是回文**的那个字符串。

**约束**：

- $1 \le |s| \le 10^5$
- $s$ 仅由小写英文字母组成
- 保证 $s$ 本身是回文串

> 💡 **读题关键**：①「$s$ 本身已是回文」不是废话——它锁定了计数的奇偶结构（奇计数字符**至多一个**），保证回文排列**必然存在**，省掉一整轮可行性判断；②「排列」是全部字符的自由重排，但回文性把**后半完全锁死**，真正有自由度的只有前半；③ 本场 Q3（3518 最小回文排列 II）把「最小」升级成「第 $k$ 小」，本题的「半串决定一切」结构正是 Q3 的地基。

## 2. 示例

**示例 1**

```text
输入：s = "z"
输出："z"
解释：仅由一个字符组成的字符串已经是字典序最小的回文。
```

**示例 2**

```text
输入：s = "babab"
输出："abbba"
解释：重排 "babab" → "abbba"，即字典序最小的回文排列。
      计数 a:2, b:3：中心只能是 b（唯一奇计数），半串 {a, b} 升序为 "ab"。
```

**示例 3**

```text
输入：s = "daccad"
输出："acddca"
解释：重排 "daccad" → "acddca"。长度为偶数、无中心，半串 {a, c, d} 升序为 "acd"。
      原串把 d 排在最前，但那不是字典序最小的选择。
```

## 3. 解题思路

### 3.1 暴力思路：枚举全部排列

枚举 $s$ 的每个排列、检查是否回文、取最小——可重排列数最坏达 $O(n!)$ 量级，$n = 10^5$ 时是天文数字，完全不可行。

收缩一步：回文由前半唯一决定，似乎只需枚举前半的排列，但 $\lfloor n/2 \rfloor = 5 \times 10^4$ 个字符的排列数同样是组合爆炸。再注意到本题 $s$ 本身是回文，**可行性天然满足**（奇计数至多一个），问题只剩**构造最优**——而下面的观察表明，最优构造根本不需要任何搜索。

### 3.2 核心观察：半串决定一切

![核心观察：半串＋中心＋镜像结构](images/c445_q2_half_mirror_structure.svg)

把任意回文排列从正中间切开：

$$\text{ans} \;=\; \underbrace{h}_{\text{半串}} \;+\; \underbrace{m}_{\text{中心（可空）}} \;+\; \mathrm{rev}(h)$$

三个部分的自由度天差地别：

- **半串 $h$（长 $\lfloor n/2 \rfloor$）**：唯一有自由度的部分——但它只是**固定多重集**的一个排列，每种字符恰 $\lfloor \mathrm{cnt}[c]/2 \rfloor$ 个（证明见 §5 引理 2）；
- **中心 $m$**：仅奇数长度存在，且由**唯一奇计数字符强制**——零自由度，别想着「把更小的字符放中间」；
- **镜像 $\mathrm{rev}(h)$**：被对称性锁死，$h$ 定则整串定。

于是整个问题坍缩为一句话：**固定多重集的最小排列是升序排列**——交换论证：若某位置放了较大字符而更小字符还在后头，交换两者立即得到更小的串（§5 引理 3）。按 $a \to z$ 顺序遍历计数桶、依次输出 $\mathrm{cnt}[c]/2$ 个 $c$，得到的半串**天然升序**——这正是计数排序（Counting Sort 标签的由来），连 `sort` 都不用跑。

### 3.3 算法流程

![算法流程：计数→定中心→桶序拼半串→镜像拼接](images/c445_q2_algorithm_flow.svg)

| 步骤 | 动作 | 说明 |
|------|------|------|
| ① 统计计数 | 一趟扫描得 $\mathrm{cnt}[26]$ | $O(n)$ |
| ② 定中心 | $\mathrm{cnt}[c]$ 为奇 $\Rightarrow m = c$ | 回文保证至多一个 |
| ③ 拼半串 | 按 $a..z$ 输出 $\mathrm{cnt}[c]/2$ 个 $c$ | 桶序天然升序，免排序 |
| ④ 镜像拼接 | $\text{ans} = h + m + \mathrm{rev}(h)$ | 反转 $O(n)$ |

四步全程线性，没有任何比较排序、搜索或回溯。

### 3.4 示例演算

![示例演算：三个官方示例全命中](images/c445_q2_example_walkthrough.svg)

| 输入 | 计数 | 中心 $m$ | 半串 $h$ | 拼接结果 |
|---|---|---|---|---|
| `z` | $z{:}1$ | `z` | ""（空） | `z` |
| `babab` | $a{:}2,\ b{:}3$ | `b` | `ab` | `ab`+`b`+`ba` = `abbba` |
| `daccad` | $a{:}2,\ c{:}2,\ d{:}2$ | 无（偶长） | `acd` | `acd`+`dca` = `acddca` |

> ⚠️ `daccad` 的原串把 `d` 排在最前，最优解却把 `a`、`c` 挪到前半——**原串本身通常不是最优，必须重建半串**，不能在原串上原地小修小补。

## 4. 算法细节

1. **计数**：`cnt[26]` 一趟统计，`int` 足够（$n \le 10^5$）。
2. **中心**：`cnt[i] & 1` 即奇计数。$n$ 为奇时**必有且恰有一个**（$s$ 是回文）；$n$ 为偶时**不存在**。C++ 用 `char mid = 0`，`if (mid)` 天然兼容两种长度。
3. **半串**：按 $i = 0..25$ 顺序 `append(cnt[i] / 2, 'a' + i)`——桶下标即字符序，输出天然升序，$O(n + \sigma)$ 优于比较排序的 $O(n \log n)$；整除 `/ 2` 自动扣除中心占用的那 1 个。
4. **拼接**：`h + m + rev(h)`。C++ 用 `string(h.rbegin(), h.rend())`，Python 用切片 `h[::-1]`；Python 循环 `+=` 拼串有 $O(n^2)$ 风险，用 `join` 一次成型。
5. **另一条更短的路**：$s$ 是回文 ⇒ $s$ 的**前半**多重集恰等于 $H$（$s[i] = s[n-1-i]$ 两两配对，引理 2 的直接推论），且奇长时 $s[n/2]$ 就是中心。所以 `h = sort(s[:n//2])` 也能直接得到答案——但计数桶版本免比较、还顺带拿到中心，仍是首选。

## 5. 正确性证明

**引理 1（结构引理）**：$s$ 是回文 ⇒ 至多一个字符计数为奇；且 $s$ 的任何回文排列中，$n$ 为奇时中心位置必为该唯一奇计数字符。

**证明**：回文中位置 $i$ 与 $n-1-i$（$i < \lfloor n/2 \rfloor$）成对出现且字符相同，每对贡献某字符计数 2；奇数长度时中心位恰贡献 1。故除中心外所有贡献均为偶数，奇计数字符至多一个。对任何回文排列：设中心字符为 $c$，则 $\mathrm{cnt}[c] = 2k + 1$ 为奇（$2k$ 来自配对、$1$ 来自中心），而奇计数字符唯一，故 $c$ 被唯一确定；$n$ 为偶时无中心位，所有计数必为偶数。∎

**引理 2（自由度引理）**：$s$ 的所有回文排列恰为 $\{\,h + m + \mathrm{rev}(h)\ :\ h\ \text{取多重集}\ H\ \text{的一个排列}\,\}$，其中 $H$ 中字符 $c$ 恰有 $\lfloor \mathrm{cnt}[c]/2 \rfloor$ 个；且两个不同的回文排列的第一个差异必落在前 $\lfloor n/2 \rfloor$ 位。

**证明**：回文排列中前半任一位置与后半镜像位置同字符，故每字符在前半出现次数 $k_c$ 满足 $\mathrm{cnt}[c] = 2k_c + [\,c = m\,]$，即前半多重集恰为 $H$，后半被锁死为 $\mathrm{rev}(h)$；中心由引理 1 强制为 $m$。反之，任取 $H$ 的排列 $h$，串 $h + m + \mathrm{rev}(h)$ 关于中心对称，是合法回文排列。若两个回文排列前半相同，则中心相同（唯一 $m$）、后半相同（前半的镜像），整串相同——故相异排列的首个差异位置 $< \lfloor n/2 \rfloor$，即**比较整串 ⇔ 比较半串**。∎

**引理 3（升序引理）**：固定多重集的所有排列中，升序排列字典序最小。

**证明**：设 $h^*$ 为升序排列，$p$ 为同一多重集的任一排列。若 $p \ne h^*$，取首位不同处 $i$：前 $i$ 位两者逐位相同，故剩余多重集相同，记为 $R$。$h^*[i]$ 是 $R$ 的最小元素（$h^*$ 升序，每位都取剩余最小者），而 $p[i] \in R$ 且 $p[i] \ne h^*[i]$，故 $p[i] > h^*[i]$，即 $h^* < p$。∎

**定理**：算法输出 $h^* + m + \mathrm{rev}(h^*)$ 是 $s$ 的字典序最小回文排列。

**证明**：由引理 2，任何回文排列形如 $h + m + \mathrm{rev}(h)$，且整串比较等价于半串比较；由引理 3，升序半串 $h^*$ 在所有合法半串中最小。故对任意回文排列 $P$ 均有 $\text{ans} \le P$；又 $\text{ans}$ 本身由对称构造而成、是合法回文排列，故为最小。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n + \sigma)$，$\sigma = 26$。一趟计数 $O(n)$、桶遍历 $O(\sigma)$、拼接与反转 $O(n)$；桶序天然有序，无需比较排序的 $O(n \log n)$。
- **空间复杂度**：$O(n)$。结果串本身；额外仅 `cnt[26]` 的 $O(\sigma)$。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    string smallestPalindrome(string s) {
        int cnt[26] = {0};
        for (char c : s) cnt[c - 'a']++;

        string half;
        char mid = 0;
        for (int i = 0; i < 26; ++i) {
            if (cnt[i] & 1) mid = 'a' + i;      // 唯一奇计数 ⇒ 中心
            half.append(cnt[i] / 2, 'a' + i);   // 桶序输出 ⇒ 半串天然升序
        }

        string ans = half;
        if (mid) ans.push_back(mid);
        ans += string(half.rbegin(), half.rend());   // 半串 + 中心 + 镜像
        return ans;
    }
};
```

### Python

```python
class Solution:
    def smallestPalindrome(self, s: str) -> str:
        cnt = [0] * 26
        for c in s:
            cnt[ord(c) - 97] += 1

        half, mid = [], ''
        for i in range(26):
            if cnt[i] & 1:
                mid = chr(97 + i)                 # 唯一奇计数 ⇒ 中心
            half.append(chr(97 + i) * (cnt[i] // 2))

        h = ''.join(half)
        return h + mid + h[::-1]                  # 半串 + 中心 + 镜像
```

> 💡 Python 一行版（利用「$s$ 回文 ⇒ 前半多重集恰为 $H$、$s[n/2]$ 即中心」）：`n = len(s); h = ''.join(sorted(s[:n // 2])); return h + s[n // 2 : n // 2 + n % 2] + h[::-1]`——偶长时中间切片为空串，两种长度统一处理。

## 8. 边界情况与易错点

1. **$n = 1$**：半串为空、中心即整串，输出 `s` 本身——构造式天然覆盖，无需特判。
2. **偶数长度没有中心**：`if (mid)` 兜底；若误取 `s[n/2]` 当中心（偶长）会多拼一个字符。Python 切片写法 `s[n//2 : n//2 + n%2]` 两种长度统一。
3. **中心零自由度**：唯一奇计数字符强制居中，「想把更小字符放中间」没有意义；`cnt[c] / 2` 整除已自动扣除中心占用的 1 个，不要手动再减一次。
4. **半串必须升序**：按桶序 $a..z$ 输出即天然升序；若照抄原串前半不排序，`daccad` 上直接 WA（原串前半 `dac` 非最优）。
5. **拼接性能**：Python 逐字符 `+=` 有 $O(n^2)$ 风险，用 `join`；C++ 用 `append(count, ch)` 批量拼接、必要时 `reserve` 免扩容。
6. **别画蛇添足判可行性**：题目保证 $s$ 是回文，奇计数至多一个天然成立；若去掉该保证（如 $s =$ `abc`），需先数奇计数个数、超过 1 个即无解（见延伸思考）。
