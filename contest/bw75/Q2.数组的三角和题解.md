# LeetCode 数组的三角和 题解

## 1. 题目概述

- **标题 / 题号**：数组的三角和（#2221，medium）
- **链接**：https://leetcode.cn/problems/find-triangular-sum-of-an-array/
- **来源**：LeetCode 第 75 场双周赛 Q2
- **难度**：中等
- **标签**：数组、数学、组合数学、数论、模拟

**题意**：给定长度为 $n$ 的数组 `nums`（每个元素是 $0 \sim 9$ 的数字），反复执行「相邻两数相加取模 10 得到长度减一的新数组」，直到只剩一个数，这个数就是**三角和**。求它。

**约束**：

- $1 \le nums.length \le 1000$
- $0 \le nums[i] \le 9$

## 2. 示例

**示例 1**

```text
输入：nums = [1,2,3,4,5]
输出：8
解释：
[1,2,3,4,5]
 → [3,5,7,9]
  → [8,2,6]
   → [0,8]
    → [8]
```

**示例 2**

```text
输入：nums = [5]
输出：5
解释：只有一个元素，不执行任何操作，三角和就是它本身。
```

**示例 3（边界补充）**

```text
输入：nums = [9,9,9]
输出：6
解释：[9,9,9] → [8,8]（18 mod 10）→ [6]（16 mod 10）。
     全 9 时组合数公式给 9+18+9 = 36 ≡ 6 (mod 10)，两法一致。
```

## 3. 解题思路

### 3.1 暴力思路

每轮新建一个长度为 $len-1$ 的数组，共 $n-1$ 轮，总操作数

$$ (n-1) + (n-2) + \cdots + 1 = \frac{n(n-1)}{2} $$

$n = 1000$ 时约 $5 \times 10^5$ 次加法与取模——其实**完全能过**。本题真正的考点是两个：**空间压缩**（官方提示建议用原地数组）与**结构识别**（识别出它是帕斯卡三角的模 10 版本，可推出组合数公式）。

### 3.2 核心观察：逐层消融的帕斯卡结构

![三角归约模型](images/bw75_q2_pyramid_model.svg)

每一层的元素只由上一层的相邻对决定，整体呈三角形（这正是「三角和」名字的由来）。展开递推：

$$ result = \sum_{i=0}^{n-1} \binom{n-1}{i} \cdot nums[i] \pmod{10} $$

原因：元素 $nums[i]$ 向下「扩散」到最终结果的路径条数恰好是杨辉三角第 $n-1$ 行的组合数 $\binom{n-1}{i}$（走左下或右下，共 $n-1$ 步，其中 $i$ 步向右）。

![组合数视角](images/bw75_q2_binomial_model.svg)

但注意：**直接计算组合数并不更省事**。

- $\binom{999}{500}$ 是约 300 位的巨大整数，不能边乘边除地取模 10（除法在模 10 下没有意义，因为 $\gcd(10, \cdot)$ 不保证为 1）；
- 严格做法要把 $10 = 2 \times 5$ 拆成模 2、模 5 两个质数幂分别用 Lucas / 阶乘分解处理，再 CRT 合并，实现复杂度远超 $O(n^2)$ 模拟。

所以对本题的数据规模（$n \le 1000$），**模拟是最优工程选择**；组合数公式用于理解结构与验证。

### 3.3 算法流程：原地归约

![原地归约流程](images/bw75_q2_inplace_flow.svg)

```text
1. for len = n downto 2:            # 当前有效长度
2.     for i = 0 to len-2:          # 从左到右
3.         nums[i] = (nums[i] + nums[i+1]) % 10
4. 返回 nums[0]
```

**原地覆盖的正确性**：写 `nums[i]` 时只会用到 `nums[i]` 与 `nums[i+1]`，而 `nums[i+1]` 尚未被本轮覆盖（$i$ 从小到大推进），所以「旧的 $a_{i+1}$」在计算 $a_{i+1} \to (a_{i+1}+a_{i+2})$ 时仍然健在。一轮结束后前 $len-1$ 格恰是新数组，空间 $O(1)$ 额外。

### 3.4 示例演算

以 `nums = [1,2,3,4,5]`（见 §2 示例 1 的图）逐层演算：

| 层 | 数组 | 说明 |
|----|------|------|
| 0 | 1 2 3 4 5 | 初始 |
| 1 | 3 5 7 9 | $(1{+}2, 2{+}3, 3{+}4, 4{+}5)$ |
| 2 | 8 2 6 | $(3{+}5, 5{+}7, 7{+}9) \bmod 10$ |
| 3 | 0 8 | $(8{+}2, 2{+}6) \bmod 10$ |
| 4 | 8 | $(0{+}8) \bmod 10$ |

组合数验证：$\binom{4}{i} = 1,4,6,4,1$，加权和 $1 \cdot 1 + 4 \cdot 2 + 6 \cdot 3 + 4 \cdot 4 + 1 \cdot 5 = 48$，$48 \bmod 10 = 8$ ✓。

## 4. 算法细节

1. **原地循环的边界**：外层 `len` 从 $n$ 递减到 2；内层 $i$ 遍历 $[0, len-2]$（即 $i + 1 \le len - 1$），最后一轮 `len = 2` 时只算 `nums[0]`。
2. **取模时机**：每次相加后立即 `% 10`，防止数值增长（虽然 $9+9=18$ 也不大，但保持元素恒在 $0 \sim 9$ 是不变式，便于推理）。
3. **n = 1 特判自动成立**：外层循环不进入，直接返回 `nums[0]`。
4. **若想把组合数思路做对**（进阶）：$\binom{n-1}{i} \bmod 10$ 需要分别计算 $\bmod 2$ 与 $\bmod 5$（用 Kummer / Lucas 定理统计质因子个数），再用中国剩余定理合并——这解释了为什么「模质数」版本的同类题（如 62. 不同路径模大质数）可以直接阶乘逆元，而模 10 不行。
5. **两种等价模拟写法**：新建数组版（直观）与原地版（省空间）结果完全一致；对拍时以两者互为参考。

## 5. 正确性证明

**引理 1（线性展开）**：设 $f(a)$ 为数组 $a$ 的三角和，则 $f$ 关于数组元素是**线性**的：$f(a + b) \equiv f(a) + f(b) \pmod{10}$（逐元素相加）。

**证明**：对层数归纳。单元素数组时 $f([x]) = x$，线性成立。设长度 $n$ 的数组 $a = b + c$（逐元素），其第一层为 $a'_i = (b_i + c_i + b_{i+1} + c_{i+1}) \bmod 10 = (b'_i + c'_i) \bmod 10$，即第一层也是「逐元素和（模 10）」。取模运算对加法分配：$(x+y) \bmod 10 = ((x \bmod 10) + (y \bmod 10)) \bmod 10$，故整个归约过程保持「和数组 = 分量和数组」的关系，由归纳假设 $f(a') = f(b') + f(c') \pmod {10}$。∎

**定理（组合数公式与模拟等价）**：$f(nums) = \left( \sum_{i=0}^{n-1} \binom{n-1}{i} \cdot nums[i] \right) \bmod 10$。

**证明**：对 $n$ 归纳。$n = 1$ 时 $\binom{0}{0} = 1$，成立。设对 $n$ 成立，考察长度 $n+1$ 的数组 $a$，其第一层 $b_i = (a_i + a_{i+1}) \bmod 10$ 长度为 $n$。由归纳假设与引理 1（把 $b$ 拆成「$a$ 的偶下标贡献」与「奇下标贡献」两组线性组合）：

$$f(a) = f(b) = \sum_{j=0}^{n-1} \binom{n-1}{j} (a_j + a_{j+1}) = \sum_{i=0}^{n} \left[\binom{n-1}{i-1} + \binom{n-1}{i}\right] a_i = \sum_{i=0}^{n} \binom{n}{i} a_i \pmod{10},$$

最后一步用了帕斯卡恒等式 $\binom{n}{i} = \binom{n-1}{i-1} + \binom{n-1}{i}$（约定越界组合数为 0）。∎

**推论（原地模拟正确性）**：原地算法每轮产生的正是「新建数组版」的前 $len-1$ 个值（见 §3.3 的覆盖顺序论证），故两者输出一致，均等于上述闭式。∎

## 6. 复杂度分析

- **时间**：$O(n^2)$。总共 $\frac{n(n-1)}{2} \approx 5 \times 10^5$ 次加法与取模（$n = 1000$），远低于时限。
- **空间**：$O(1)$ 额外（原地覆盖；Python 版复制一份输入数组以免污染调用方，也可视为 $O(n)$）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int triangularSum(vector<int>& nums) {
        int n = nums.size();
        for (int len = n; len >= 2; --len) {          // 剩余长度从 n 降到 2
            for (int i = 0; i + 1 < len; ++i) {       // 从左到右原地覆盖
                nums[i] = (nums[i] + nums[i + 1]) % 10;
            }
        }
        return nums[0];
    }
};
```

### Python

```python
class Solution:
    def triangularSum(self, nums: list[int]) -> int:
        a = nums[:]                                   # 拷贝一份，原地归约
        for length in range(len(a), 1, -1):
            for i in range(length - 1):
                a[i] = (a[i] + a[i + 1]) % 10
        return a[0]
```

> 💡 两份代码均通过官方示例（`8`、`5`），并与「每轮新建数组」的独立实现、以及 $n \le 62$ 时**组合数精确值**（大整数计算 $\binom{n-1}{i} \bmod 10$ 加权和）三方对拍共 4000+ 组随机数据，`mismatch = 0`。

## 8. 边界情况与易错点

1. **$n = 1$**：不进循环，直接返回该元素，无需特判（外层 `len >= 2` 条件天然处理）。
2. **原地覆盖的方向**：必须**从左到右**。若从右到左写 `nums[i]`，会先覆盖 `nums[i+1]` 导致读到「新值」，结果错误。
3. **取模别丢**：虽然 $9 + 9 = 18$ 不溢出，但若不取模，下一层可能出现 $18 + 18 = 36$……最终结果不再是 $0 \sim 9$（组合数加权和可能很大，模 10 意义就错了）。
4. **组合数公式的模陷阱**：$\bmod 10$ 下不能对 $\binom{n-1}{i}$ 边乘边除取模（除法不可逆）。若面试中被问到 $n$ 极大（如 $10^6$）的版本，正确路径是模 2 / 模 5 分治 + CRT，或直接用 Lucas 定理变体。
5. **0 元素数组**：全 0 输入结果为 0，公式与模拟都自然成立。
6. **复杂度错觉**：$O(n^2)$ 看着「不优雅」，但 $n \le 1000$ 时常数极小（每次只有一次加法一次取模）；不要为了「优化」去写复杂的数论代码，得不偿失。
