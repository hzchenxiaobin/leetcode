# LeetCode 公因子的数目 题解

## 1. 题目概述

- **标题 / 题号**：公因子的数目（#2427，easy）
- **链接**：https://leetcode.cn/problems/number-of-common-factors/
- **来源**：LeetCode 第 313 场周赛 Q1
- **难度**：简单
- **标签**：数学、枚举、最大公约数、数论、欧几里得算法

**题意**：给定两个正整数 `a` 和 `b`，返回它们的**公因子**的数目。若 `x` 可以同时整除 `a` 和 `b`，则 `x` 是 `a`、`b` 的一个公因子。

**约束**：

- `1 <= a, b <= 1000`

## 2. 示例

**示例 1**

```text
输入：a = 12, b = 6
输出：4
解释：12 和 6 的公因子是 1、2、3、6。
```

**示例 2**

```text
输入：a = 25, b = 30
输出：2
解释：25 和 30 的公因子是 1、5。
```

**补充示例**

```text
输入：a = 1, b = 1
输出：1
解释：1 和 1 的公因子只有 1。
```

## 3. 解题思路

### 3.1 暴力思路

公因子 `x` 必然满足 `x <= a` 且 `x <= b`，故只需枚举 `1` 到 $\min(a, b)$，逐个检查 `a % x == 0 && b % x == 0` 即可。时间 $O(\min(a, b))$，在本题 `a, b <= 1000` 的范围下最多千次取模，完全可以通过。

### 3.2 核心观察：公因子集合 = gcd(a, b) 的因子集合

![公因子集合恰为 gcd 的因子集合（韦恩图）](images/common_factors_gcd_concept.svg)

**关键观察**：`x` 是 `a`、`b` 的公因子，当且仅当 `x` 整除 $g = \gcd(a, b)$。于是问题化归为经典的**「数一个数的因子个数」**：

- 先用**欧几里得算法**求 $g = \gcd(a, b)$；
- 再数 $g$ 的因子个数。

### 3.3 算法流程：枚举到 √g 成对计数

![算法流程：求 gcd 后枚举到根号 g 成对计数](images/common_factors_flow.svg)

$g$ 的因子**成对出现**：若 $i \mid g$，则 $g / i$ 也是因子，且两者一个 $\le \sqrt{g}$、一个 $\ge \sqrt{g}$。因此只需枚举 $i = 1 \dots \lfloor\sqrt{g}\rfloor$：

- 若 $i \mid g$：计入因子对 $(i,\ g/i)$，通常贡献 `2` 个；
- 特判 $i^2 = g$（$g$ 是完全平方数）：此时 $i$ 与 $g/i$ 相同，只贡献 `1` 个。

### 3.4 示例演算

![两个示例的逐步演算表](images/common_factors_walkthrough.svg)

**示例 1**（$a=12, b=6$）：$g = 6$。$i=1$：$6 \bmod 1 = 0$，计入 `1` 和 `6`；$i=2$：$6 \bmod 2 = 0$，计入 `2` 和 `3`；$i=3$ 时 $3^2 > 6$ 停止。答案 $2 + 2 = 4$。

**示例 2**（$a=25, b=30$）：$g = 5$。$i=1$：计入 `1` 和 `5`；$i=2$：$5 \bmod 2 \ne 0$ 跳过；$i=3$ 时 $3^2 > 5$ 停止。答案 $2$。

## 4. 算法细节

1. **求 gcd**：C++ `<numeric>` 的 `std::gcd`，Python `math.gcd`，均为欧几里得算法，$O(\log \min(a,b))$。
2. **枚举上界**：循环条件写成 `i <= g / i`（或 C++ 中 `(long long)i * i <= g`），避免 `i * i` 在大数时溢出；本题 $g \le 1000$ 用哪种都安全。
3. **成对计数**：`i * i == g` 时 `ans += 1`，否则 `ans += 2`，杜绝完全平方因子的重复计数。
4. **为什么不用枚举到 min(a,b)**：因子对枚举把 $O(g)$ 降为 $O(\sqrt{g})$；虽然本题范围下两者都能过，但 $\sqrt{}$ 枚举是数因子问题的标准模板，值得养成习惯。

## 5. 正确性证明

**引理 1**（公因子判据）：设 $g = \gcd(a, b)$，则 $x$ 是 $a$、$b$ 的公因子 $\iff x \mid g$。

**证明**：

（$\Rightarrow$）设 $x \mid a$ 且 $x \mid b$。由 **Bézout 定理**，存在整数 $u, v$ 使 $g = ua + vb$。由 $x \mid a$、$x \mid b$ 得 $x \mid ua + vb = g$。

（$\Leftarrow$）设 $x \mid g$。由 $g \mid a$ 与 $g \mid b$ 及整除的传递性，得 $x \mid a$ 且 $x \mid b$，即 $x$ 是公因子。∎

**引理 2**（因子配对）：设 $g \ge 1$，$i \mid g$ 且 $i \le \sqrt{g}$，则 $g / i \ge \sqrt{g}$ 亦为 $g$ 的因子；且 $g$ 的每个因子恰在一次「$i \le \sqrt{g}$ 的枚举」中被计入（作为较小的 $i$ 或较大的 $g/i$），$i^2 = g$ 时两者重合。

**证明**：$i \mid g$ 且 $i \le \sqrt{g}$，则 $g / i$ 是整数且 $g / i \ge g / \sqrt{g} = \sqrt{g}$，显然整除 $g$。反之对 $g$ 的任一因子 $d$：若 $d \le \sqrt{g}$，它在枚举 $i = d$ 时作为对 $(d,\ g/d)$ 计入；若 $d > \sqrt{g}$，则 $g/d < \sqrt{g}$ 是整数因子，$d$ 在枚举 $i = g/d$ 时计入。两种途径互斥（$d \le \sqrt{g}$ 与 $d > \sqrt{g}$ 不同时成立），故不重不漏；仅当 $i = g/i = \sqrt{g}$ 时同一因子被对内两次命中，需只计一次。∎

**定理**：上述算法返回的 `ans` 等于 $a$、$b$ 的公因子数目。

**证明**：由引理 1，公因子集合与 $D(g)$（$g$ 的因子集合）完全相同，故只需数 $|D(g)|$。由引理 2，枚举 $1 \le i \le \lfloor\sqrt{g}\rfloor$ 并按 `i² == g ? 1 : 2` 累加，恰好对 $D(g)$ 中每个元素计一次。故 `ans = |D(g)|` 即公因子数目。∎

## 6. 复杂度分析

**时间复杂度**：$O(\log \min(a, b) + \sqrt{g})$，其中 $g = \gcd(a, b)$。前者是欧几里得算法，后者是因子对枚举；本题下界为常数级。暴力做法则为 $O(\min(a, b))$。

**空间复杂度**：$O(1)$，仅使用常数个变量。

## 7. 参考代码

### C++（gcd + 因子对枚举）

```cpp
class Solution {
public:
    int commonFactors(int a, int b) {
        int g = gcd(a, b);
        int ans = 0;
        for (int i = 1; (long long)i * i <= g; ++i) {
            if (g % i == 0) {
                ans += (i * i == g) ? 1 : 2;
            }
        }
        return ans;
    }
};
```

### C++（暴力枚举）

```cpp
class Solution {
public:
    int commonFactors(int a, int b) {
        int ans = 0;
        for (int x = 1; x <= min(a, b); ++x) {
            if (a % x == 0 && b % x == 0) {
                ++ans;
            }
        }
        return ans;
    }
};
```

### Python（gcd + 因子对枚举）

```python
from math import gcd, isqrt

class Solution:
    def commonFactors(self, a: int, b: int) -> int:
        g = gcd(a, b)
        ans = 0
        for i in range(1, isqrt(g) + 1):
            if g % i == 0:
                ans += 1 if i * i == g else 2
        return ans
```

## 8. 边界情况与易错点

1. **a 或 b 为 1**：$g = 1$，因子仅有 `1`，答案为 `1`，两种做法均天然正确，无需特判。
2. **a == b**：$g = a$，答案即 $a$ 的因子个数，如 `a = b = 36` 时为 `9`。
3. **完全平方数去重**：若 $g$ 是完全平方数（如 $g = 36$，$i = 6$），因子对 $(6, 6)$ 只能计一次，漏判会把答案多算 `1`——这是本解法最典型的错误。
4. **枚举边界**：条件必须含等号（`i * i <= g`），否则 $\sqrt{g}$ 恰为整数时漏掉整个因子对；C++ 中 `i * i` 在 `int` 下可能溢出，写 `(long long)i * i <= g` 或 `i <= g / i` 更稳。
5. **输入恒为正**：题目保证 $a, b \ge 1$，无需处理 $0$（$g = 0$ 时因子有无穷多个，问题退化）。
