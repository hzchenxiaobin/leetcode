# LeetCode 沙漏的最大总和 题解

## 1. 题目概述

- **标题 / 题号**：沙漏的最大总和（#2428，medium）
- **链接**：https://leetcode.cn/problems/maximum-sum-of-an-hourglass/
- **来源**：LeetCode 第 313 场周赛 Q2
- **难度**：中等
- **标签**：数组、矩阵、枚举、前缀和

**题意**：给定一个 $m \times n$ 的非负整数矩阵 `grid`。矩阵中的一个**沙漏**定义为如下 $3 \times 3$ 的固定形状（中间行的左右两格被挖去）：

```text
✓ ✓ ✓
  ✓
✓ ✓ ✓
```

返回所有**完整包含在矩阵中**的沙漏的元素最大总和。沙漏不能旋转。

**约束**：

- `m == grid.length`，`n == grid[i].length`
- $3 \le m, n \le 150$
- $0 \le \text{grid}[i][j] \le 10^6$

## 2. 示例

**示例 1**

```text
输入：grid = [[6,2,1,3],[4,2,1,5],[9,2,8,7],[4,1,2,9]]
输出：30
解释：总和最大的沙漏在左上角 (0,0)：
      6 + 2 + 1 + 2 + 9 + 2 + 8 = 30
```

**示例 2**

```text
输入：grid = [[1,2,3],[4,5,6],[7,8,9]]
输出：35
解释：唯一的沙漏：(1+2+3) + 5 + (7+8+9) = 35
```

**补充示例**

```text
输入：grid = [[0,0,0],[0,0,0],[0,0,0]]
输出：0
解释：全零矩阵，任何沙漏的和都是 0。
```

## 3. 解题思路

### 3.1 暴力思路：枚举左上角，逐格累加

沙漏是**跨 3 行、跨 3 列的固定形状**。任何完整落在矩阵内的沙漏都唯一对应其左上角 $(i, j)$，合法范围是 $i \in [0, m-3]$、$j \in [0, n-3]$，共 $(m-2)(n-2)$ 个位置。

对每个位置把 7 个格子直接相加：

$$H(i,j) = \text{grid}[i][j] + \text{grid}[i][j{+}1] + \text{grid}[i][j{+}2] + \text{grid}[i{+}1][j{+}1] + \text{grid}[i{+}2][j] + \text{grid}[i{+}2][j{+}1] + \text{grid}[i{+}2][j{+}2]$$

时间 $O(7mn) = O(mn)$。本题 $mn \le 22500$，总加法次数不到 $1.6 \times 10^5$，**暴力直接 AC**——这也是比赛中 Q2 的最快提交方式：读清形状、写对 7 个下标、一次通过。

### 3.2 核心观察：沙漏 = 顶行 3 连和 + 中格 + 底行 3 连和

![沙漏形状与枚举位置：左上角 (i,j) 的可行范围共 (m-2)(n-2) 个](images/hourglass_shape_enum.svg)

暴力虽然能过，但**左右相邻的沙漏共享顶行、底行各 2 格，却各自重算 3 格**。把 7 格按行分组：

$$H(i,j) = \underbrace{\sum_{k=0}^{2}\text{grid}[i][j{+}k]}_{\text{顶行 3 连和}} + \underbrace{\text{grid}[i{+}1][j{+}1]}_{\text{中格}} + \underbrace{\sum_{k=0}^{2}\text{grid}[i{+}2][j{+}k]}_{\text{底行 3 连和}}$$

两段「3 连和」都是**某一行内长度恰为 3 的区间和**——这是前缀和的招牌场景。预处理行前缀和后，每段 3 连和降为一次差分。

![沙漏按行分解为顶行 3 连和 + 中格 + 底行 3 连和，行前缀和把每段压成一次差分](images/hourglass_prefix_sum.svg)

> 💡 **为什么不用二维前缀和？** 沙漏挖掉了中间行的左右两格，求和区域带洞、不是矩形，二维前缀和的四角容斥无法直接表达。但按行拆开后每行都是规整的连续区间，**一维行前缀和恰好匹配**——前缀和的维度要与求和区域的规则性对齐。

### 3.3 算法流程

1. **预处理**：对每行 $r$ 构建长度 $n+1$ 的前缀和 $\text{pref}[r][0]=0$、$\text{pref}[r][c] = \text{pref}[r][c-1] + \text{grid}[r][c-1]$。
2. **初始化**：`ans = 0`（元素非负，最小和为 0）。
3. **枚举**：$i \in [0, m-3]$、$j \in [0, n-3]$，用差分公式 $O(1)$ 求 $H(i,j)$：

$$H(i,j) = \bigl(\text{pref}[i][j{+}3] - \text{pref}[i][j]\bigr) + \text{grid}[i{+}1][j{+}1] + \bigl(\text{pref}[i{+}2][j{+}3] - \text{pref}[i{+}2][j]\bigr)$$

4. **维护**：`ans = max(ans, H(i,j))`，枚举结束返回 `ans`。

### 3.4 示例演算

![示例演算：4×4 矩阵共 4 个沙漏，逐个求和取最大 30](images/hourglass_example_walkthrough.svg)

对示例 1 的 $4 \times 4$ 矩阵，$(m-2)(n-2) = 4$ 个沙漏：

| $(i,j)$ | 顶行 3 连和 | 中格 | 底行 3 连和 | $H(i,j)$ |
|---------|-------------|------|-------------|----------|
| $(0,0)$ | $6+2+1=9$  | $2$ | $9+2+8=19$ | $\mathbf{30}$ ★ |
| $(0,1)$ | $2+1+3=6$  | $1$ | $2+8+7=17$ | $24$ |
| $(1,0)$ | $4+2+1=7$  | $2$ | $4+1+2=7$  | $16$ |
| $(1,1)$ | $2+1+5=8$  | $8$ | $1+2+9=12$ | $28$ |

$\text{ans} = \max\{30, 24, 16, 28\} = \mathbf{30}$ ✓

示例 2 中 $m = n = 3$，只有唯一沙漏，其和即答案 $35$ ✓

## 4. 算法细节

1. **形状下标**：左上角 $(i,j)$ 的沙漏占三行——顶行 $\text{grid}[i][j..j{+}2]$、中格 $\text{grid}[i{+}1][j{+}1]$、底行 $\text{grid}[i{+}2][j..j{+}2]$。注意中格列号是 $j{+}1$（居中），最易写错。
2. **行前缀和**：$\text{pref}[r][c] = \sum_{k=0}^{c-1} \text{grid}[r][k]$，长度 $n+1$，$\text{pref}[r][0] = 0$ 为哨兵，使区间 $[j, j+2]$ 的和统一为 $\text{pref}[r][j{+}3] - \text{pref}[r][j]$，无需对 $j = 0$ 特判。
3. **枚举边界**：循环条件写 `i + 2 < m`、`j + 2 < n`（等价于 `i <= m-3`、`j <= n-3`），保证 $i{+}2 \le m{-}1$、$j{+}2 \le n{-}1$，且 $\text{pref}[\cdot][j{+}3]$ 下标合法（$\le n$）。
4. **初值**：约束 $0 \le \text{grid}[i][j]$ 保证任意沙漏和 $\ge 0$，`ans` 初始化为 0 安全。本题约束 $m, n \ge 3$，至少存在一个合法沙漏，无需特判「无解」。

## 5. 正确性证明

**引理 1（枚举完备性）**：矩阵中每个完整包含的沙漏唯一对应左上角 $(i,j)$，且 $0 \le i \le m-3$、$0 \le j \le n-3$。

**证明**：沙漏形状由左上角唯一确定（形状固定不可旋转）。沙漏占用的行列范围是 $[i, i+2] \times [j, j+2]$，它完整包含于矩阵当且仅当 $i+2 \le m-1$ 且 $j+2 \le n-1$，即 $i \le m-3$、$j \le n-3$。反之，该范围内任一 $(i,j)$ 都对应一个合法沙漏。因此枚举范围与合法沙漏集合**一一对应、不重不漏**。∎

**引理 2（差分公式正确性）**：对任意行 $r$ 与 $0 \le j \le n-3$，有 $\text{pref}[r][j+3] - \text{pref}[r][j] = \text{grid}[r][j] + \text{grid}[r][j+1] + \text{grid}[r][j+2]$。

**证明**：由定义 $\text{pref}[r][j+3] = \sum_{k=0}^{j+2}\text{grid}[r][k]$，$\text{pref}[r][j] = \sum_{k=0}^{j-1}\text{grid}[r][k]$，两者相减，$k < j$ 的项全部抵消，剩下 $k \in \{j, j+1, j+2\}$ 三项。∎

**定理**：算法返回所有合法沙漏元素和的最大值。

**证明**：由引理 1，算法枚举了全部 $(m-2)(n-2)$ 个合法沙漏且无遗漏。由引理 2 与中格直接取值，每个 $H(i,j)$ 精确等于该沙漏 7 格之和。`ans` 在枚举中对每个 $H(i,j)$ 取 `max`，故最终 `ans` 是所有沙漏和的最大值。又元素非负保证 `ans` 初值 0 不超过任何沙漏和（若所有沙漏和为 0，初值恰好也是正确答案）。∎

## 6. 复杂度分析

- **时间复杂度**：$O(m \cdot n)$。预处理行前缀和 $O(mn)$；枚举 $(m-2)(n-2)$ 个位置，每个 $O(1)$。暴力版同为 $O(mn)$，只是每位置常数 7；前缀和把每段 3 连和压成一次减法，常数降至约 5 并复用重叠段。
- **空间复杂度**：前缀和版 $O(m \cdot n)$（可滚动优化至 $O(n)$）；暴力版 $O(1)$ 额外空间。

> 💡 本题 $mn \le 2.25 \times 10^4$，两个版本都远在时限内。前缀和的价值在于把「定长形状求和」的套路沉淀下来：当矩阵放大到 $10^3 \times 10^3$ 以上、或形状覆盖格子更多时，常数差异会变得实质化。

## 7. 参考代码

### C++（暴力枚举，比赛中首选）

```cpp
class Solution {
public:
    int maxSum(vector<vector<int>>& grid) {
        int m = grid.size(), n = grid[0].size();
        int ans = 0;  // grid[i][j] >= 0，最小和为 0
        for (int i = 0; i + 2 < m; ++i)
            for (int j = 0; j + 2 < n; ++j) {
                int s = grid[i][j] + grid[i][j+1] + grid[i][j+2]
                      + grid[i+1][j+1]
                      + grid[i+2][j] + grid[i+2][j+1] + grid[i+2][j+2];
                ans = max(ans, s);
            }
        return ans;
    }
};
```

### Python（行前缀和优化版）

```python
class Solution:
    def maxSum(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        # 行前缀和：pref[r][c] = grid[r][0..c-1] 之和，pref[r][0]=0
        pref = [[0] * (n + 1) for _ in range(m)]
        for r in range(m):
            pr, row = pref[r], grid[r]
            for c in range(n):
                pr[c + 1] = pr[c] + row[c]

        ans = 0  # grid[i][j] >= 0
        for i in range(m - 2):
            for j in range(n - 2):
                top = pref[i][j + 3] - pref[i][j]
                mid = grid[i + 1][j + 1]
                bot = pref[i + 2][j + 3] - pref[i + 2][j]
                ans = max(ans, top + mid + bot)
        return ans
```

## 8. 边界情况与易错点

1. **中格下标写错**：中间格是 $(i{+}1,\, j{+}1)$，列号 $j{+}1$ 居中。写成 $(i{+}1,\, j)$ 是最常见的 WA 原因。
2. **枚举越界**：循环上界必须是 `i + 2 < m`、`j + 2 < n`。写成 `i < m` 会导致 $i{+}2$ 越界；用前缀和时 `pref[·][j+3]` 也要求 $j + 3 \le n$。
3. **`ans` 初值依赖非负约束**：本题 $0 \le \text{grid}[i][j]$，初值 0 安全。若题目改为允许负数，必须初始化为 $-\infty$（C++ `INT_MIN / 4` 防溢出，Python `float('-inf')`）——这是「利用约束简化初值」的典型点，迁移时务必复核。
4. **溢出**：7 格之和至多 $7 \times 10^6$，`int`（上限约 $2.1 \times 10^9$）绰绰有余，无需 `long long`。
5. **最小规模**：$m = n = 3$ 时只有 1 个沙漏；全零矩阵答案为 0（初值处理已覆盖）。
6. **形状不能旋转**：题面明确沙漏不可旋转，无需考虑「竖沙漏 / 横沙漏」两种朝向，只需枚举一个朝向。

**延伸思考**：

- 若沙漏改为**任意固定形状**（十字、菱形、L 形）？只要形状可分解为「若干行内连续区间 + 散点」，行前缀和差分仍然适用；碎片化越严重（散点占比高），前缀和收益越低，暴力累加反而更简单。
- 若把本题看作在矩阵上滑动一个固定 **kernel** 求响应最大值，它就是一次（稀疏）**二维卷积**——$m, n$ 极大时可用 FFT 加速到 $O(mn \log mn)$，这是图像处理中模板匹配的标准思路。
- 若允许**至多旋转一次**？只需再枚举旋转后的形状（对称沙漏），枚举两遍取最大即可。
