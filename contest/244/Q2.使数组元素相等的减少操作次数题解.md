# LeetCode 使数组元素相等的减少操作次数 题解

## 1. 题目概述

- **标题 / 题号**：使数组元素相等的减少操作次数（#1887，medium）
- **链接**：https://leetcode.cn/problems/reduction-operations-to-make-the-array-elements-equal/
- **来源**：LeetCode 第 244 场周赛 Q2
- **难度**：中等
- **标签**：数组、排序、计数

**题意**：给定整数数组 `nums`，目标是让所有元素相等。一次「减少操作」= 找出**当前最大值**（并列时取最靠前的下标），把它降到**严格小于它的次大值** `nextLargest` 上。返回使全部元素相等所需的总操作次数。

**约束**：

- $1 \le n \le 5 \times 10^4$
- $1 \le \text{nums}[i] \le 5 \times 10^4$

> 💡 本题在本仓库另有[每日题解 1887](../../solution/1801-1900/1887_使数组元素相等的减少操作次数.md)，两篇为姊妹篇：每日篇主讲「正序扫、数层序号」与面试问答、$O(n+V)$ 计数排序扩展；本篇按周赛复盘视角，主打**降序一遍合并**的赛场最短路径、以「前缀不变量 + 双计数」展开的完整正确性证明，以及答案上界 $1.25\times10^9$ 贴着 `int` 上限的溢出复盘。

## 3. 解题思路

### 3.1 暴力思路：先给操作总量算一笔账

按定义逐操作模拟：每轮找最大、找次大、改一个数、计数 $+1$，直到全等。动手前先估操作总量上界——全互异输入 $[1,2,\ldots,n]$ 时每个元素都要逐层掉到底，总操作数为

$$0+1+\cdots+(n-1)=\frac{n(n-1)}{2}$$

$n = 5\times10^4$ 时约 $1.25\times10^9$ 次。就算用堆把每轮找最值压到 $O(\log n)$，操作总量仍是十亿级，必然超时；Python 更是连零头都跑不动。**瓶颈不在数据结构，而在「逐操作」视角本身**——必须直接算出总次数，而不是把十亿次操作一个个走完。

### 3.2 核心观察：降序排列后「跨边界计数」

![核心观察：降序排列后跨值边界计数](images/wc244_q2_boundary_merge_concept.svg)

把数组互异值从小到大记为 $v_0 < v_1 < \cdots < v_{k-1}$（$k$ 个「值层」）。两个关键事实：

**事实一（操作 = 降一层）**：被操作的永远是当前最大值，而 `nextLargest` 恰是紧挨其下的那层值——一次操作恰好把一个元素从第 $m$ 层搬到第 $m-1$ 层，**不会跳层**（证明见 §5 引理 1）。

**事实二（终态 = 最小值）**：$v_0$ 永远不会被操作（只要还有更大的值在，它就不是最大值），因此过程终止时全数组等于 $v_0$。

两件事合起来：**值只能沿相邻层逐级往下走，终点是第 0 层**，所以每个元素的操作次数 = 它初始位置下面有几层 = **严格小于它的互异值个数**（记作 $\text{level}(x)$）。换一个数法：把每条「层间边界」的跨越次数加起来——第 $j$ 条边界（$v_j$ 与 $v_{j-1}$ 之间）被跨越的次数 = 值 $\ge v_j$ 的元素个数。降序排序后，当扫描位置 $i$ 首次出现 $\text{nums}[i] \ne \text{nums}[i-1]$ 时，左侧的 $0..i-1$ 恰是值 $\ge \text{nums}[i-1]$ 的全部 $i$ 个元素，**累加 $i$ 即可**：

$$\text{ans} = \sum_{i=1}^{n-1} i \cdot \bigl[\text{nums}[i] \ne \text{nums}[i-1]\bigr] \qquad (\text{降序排序后})$$

### 3.3 算法流程：降序排序 + 一遍扫描

![算法流程：降序排序与一遍扫描](images/wc244_q2_scan_flow.svg)

1. 将 `nums` **降序排序**（相同值自然聚成连续段）。
2. `ans = 0`，从 $i = 1$ 扫到 $n-1$。
3. 若 $\text{nums}[i] \ne \text{nums}[i-1]$（跨过一条值边界）：`ans += i`——边界左侧的 $i$ 个元素各记一次操作。
4. 扫描结束，`ans` 即答案。

> 💡 **对偶写法**：升序正序扫描、维护「当前层序号 cnt」也完全等价——换值时 `cnt++`，每步 `ans += cnt`。两式互为交换求和序（边界视角 vs 元素视角），每日篇主讲后者；本篇主讲前者，因为赛场心智负担最小：扫描中只需回答「换值了吗」，换值就把下标加上，不用维护任何状态。

### 3.4 示例演算

![示例演算：nums = [1,1,2,2,3] 的边界计数与操作对照](images/wc244_q2_walkthrough.svg)

以 `nums = [1,1,2,2,3]` 为例，降序后为 $[3,2,2,1,1]$：

| $i$ | $\text{nums}[i]$ | 与前值比较 | 跨过的边界 | `ans` |
|-----|------------------|------------|------------|-------|
| 1 | 2 | $2 \ne 3$ 换值 | $3\mid2$，左侧 1 个元素 | $0+1=1$ |
| 2 | 2 | $2 = 2$ | — | 1 |
| 3 | 1 | $1 \ne 2$ 换值 | $2\mid1$，左侧 3 个元素 | $1+3=4$ |
| 4 | 1 | $1 = 1$ | — | 4 |

对照真实操作序列：$3\to2$ 一次（跨过 $3\mid2$ 边界），$2\to1$ 三次（三个值 $\ge 2$ 的元素各跨一次 $2\mid1$ 边界），共 $4$ 次，与扫描结果一致 ✓。

## 4. 算法细节

1. **为什么排序是充分的**：操作总数只依赖每个元素的初始值，与操作顺序、并列时选哪个下标完全无关（§5 引理 1 之后的注记）。排序把「值 $\ge v_j$ 的元素个数」变成降序数组的一段前缀长度，边界两侧一眼可数。
2. **两种等价的一遍扫描**：
   - **边界视角（本篇主推，降序）**：换值时 `ans += i`，$i$ 即当前边界左侧元素数；
   - **元素视角（每日篇主推，升序）**：换值时 `cnt++`，每步 `ans += cnt`，`cnt` 即当前元素的层序号。
   两者由 $\sum_i \text{level}(x_i) = \sum_{j \ge 1} \bigl|\{x_i \ge v_j\}\bigr|$ 交换求和序联系起来。
3. **溢出账要算清**：答案上界 $\dfrac{n(n-1)}{2} \approx 1.25\times10^9 < 2^{31}-1 \approx 2.15\times10^9$，`int` 理论上安全但余量不足一倍。C++ 赛场求稳可直接用 `long long` 累加（返回时截断无妨），用 `int` 就要能随口说出上界论证；Python 无此忧虑。
4. **$O(n + V)$ 计数排序变体**：值域 $V \le 5\times10^4$ 与 $n$ 同阶，可用频次数组从大到小扫值域替代比较排序，细节见每日篇 §5.2，此处不展开。

## 5. 正确性证明

**约定**：初始互异值升序为 $v_0 < v_1 < \cdots < v_{k-1}$；称值为 $v_j$ 的元素「位于第 $j$ 层」。

**引理 1（值集前缀不变量）**：任意时刻，数组中出现的互异值集合恰为 $\{v_0, v_1, \ldots, v_m\}$（某个 $0 \le m \le k-1$）。

**证明**：对操作步数归纳。初始时 $m = k-1$，成立。设当前值集为前缀 $\{v_0,\ldots,v_m\}$：若 $m = 0$，全数组相等，不存在严格更小的 `nextLargest`，过程结束，不变量平凡保持；若 $m \ge 1$，操作把一个第 $m$ 层元素降为「严格小于 $v_m$ 的最大现存值」，由归纳假设该值恰为 $v_{m-1}$。若第 $m$ 层还有其他元素，值集不变；否则值集缩为 $\{v_0,\ldots,v_{m-1}\}$，仍是前缀。∎

> **注（并列规则的无关性）**：引理 1 只刻画值的集合，不涉及下标——「并列取最小编号」仅决定改哪一个格子；同层元素在值层面不可区分，故值多重集与各元素所在层的演化轨道完全确定，答案只依赖初始多重集 $\{x_i\}$。

**引理 2（逐层下降与终止）**：每次操作恰把一个元素从第 $m$ 层降到第 $m-1$ 层（$m$ 为当前顶层），不跳层；过程必在有限步后终止，且终止时所有元素等于 $v_0$。

**证明**：前一断言是引理 1 证明的直接复述（降到的是 $v_{m-1}$ 而非更低的层）。每次操作使 $\sum_i \text{nums}[i]$ 严格减少 $v_m - v_{m-1} \ge 1$，而总和有下界 $n \cdot v_0$，故操作数有限、过程终止；终止意味着无法再执行操作，即不存在严格次大值，由引理 1 此时值集为 $\{v_0\}$，全数组等于 $v_0$。∎

**定理（计数公式）**：总操作数为

$$\text{ans} = \sum_{j=1}^{k-1} \bigl|\{\,i : x_i \ge v_j\}\bigr| = \sum_{i=0}^{n-1} \text{level}(x_i), \qquad \text{level}(x) = \bigl|\{\,v \in \{v_0,\ldots,v_{k-1}\} : v < x\}\bigr|$$

**证明**：由引理 2，每次操作是某个元素跨过一条相邻层边界（第 $j$ 层 $\to$ 第 $j-1$ 层），且每层只降一次一阶，故总操作数 $= \sum_{j=1}^{k-1} c_j$，其中 $c_j$ 为边界 $j$ 的总跨越次数。对固定 $j$：层号单调不增、每操作恰降 $1$，故初值层号 $\ge j$ 的元素必从第 $j$ 层降到第 $j-1$ 层（其终态为第 $0$ 层），恰跨边界 $j$ 一次；初值层号 $< j$ 的元素层号永远到不了 $j$，不跨。因此 $c_j = |\{i : \text{level}(x_i) \ge j\}| = |\{i : x_i \ge v_j\}|$。再对元素求和换序：$\sum_j |\{\text{level} \ge j\}| = \sum_i \text{level}(x_i)$，得第二个等号。∎

**推论（算法正确性）**：降序排序后若 $\text{nums}[i] \ne \text{nums}[i-1]$，则 $\text{nums}[i-1]$ 与 $\text{nums}[i]$ 是相邻的两个互异值 $v_t, v_{t-1}$，且位置 $0..i-1$ 恰为值 $\ge v_t$ 的全部 $i$ 个元素，故 `ans += i` 逐步累出的正是定理中的 $\sum_j |\{x_i \ge v_j\}|$（每条边界在排序数组中恰出现一次）。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \log n)$，排序主导；一遍扫描 $O(n)$。值域与 $n$ 同阶时可换计数排序做到 $O(n + V)$（§4 第 4 点）。
- **空间复杂度**：$O(\log n)$，仅为排序递归栈；累加器与扫描下标 $O(1)$。直接对入参排序，无额外数组。

## 7. 参考代码

### C++（降序边界版）

```cpp
class Solution {
public:
    int reductionOperations(vector<int>& nums) {
        sort(nums.rbegin(), nums.rend());
        int ans = 0;
        for (int i = 1; i < (int)nums.size(); i++) {
            if (nums[i] != nums[i - 1]) {
                ans += i;  // 跨过一条值边界：左侧 i 个元素各记一次操作
            }
        }
        return ans;
    }
};
```

### Python（降序边界版）

```python
class Solution:
    def reductionOperations(self, nums: List[int]) -> int:
        nums.sort(reverse=True)
        ans = 0
        for i in range(1, len(nums)):
            if nums[i] != nums[i - 1]:
                ans += i
        return ans
```

### Python（正序层序号版，对偶写法）

```python
class Solution:
    def reductionOperations(self, nums: List[int]) -> int:
        nums.sort()
        ans = cnt = 0
        for i in range(1, len(nums)):
            if nums[i] != nums[i - 1]:
                cnt += 1
            ans += cnt
        return ans
```

> 💡 **写法对照**：三个版本均以官方样例 1/2/3 及 `[42]`、`[4,3,2,1]`、`[5,5,5,1]` 自造边界验证过。降序版扫描中只需回答「换值了吗」，无需维护状态，是赛场手速首选；正序版要维护 `cnt`，但直接对应「层序号」的语义。`int` 溢出论证见 §4 第 3 点。

## 8. 边界情况与易错点

1. **先估操作总量再选做法**：全互异时 $\frac{n(n-1)}{2} \approx 1.25\times10^9$ 次操作是逐操作模拟的死穴。赛场第一反应应是算出这个上界，直接排除模拟，转向计数。
2. **答案贴着 `int` 上限**：上界 $\approx 1.25\times10^9 < 2^{31}-1$，`int` 恰好安全但余量不足一倍；C++ 不放心就 `long long`。别因为「看着是计数题」就默认结果很小。
3. **`ans += i` 的 $i$ 别写错**：$i$ 是「换值位置左侧的元素个数」（0 基下标下恰为 $i$ 个）。写成 $i-1$ 是差一错误；升序从右往左扫的对应形式是 $n - i$，两套坐标系不要混用。
4. **同值层每个元素都要单独一次操作**：「一次把所有最大值一起降」是另一道题（那样答案只是 $k-1$）。并列取最小编号的规则不影响计数（§5 注记），但提醒我们一次只动一个元素。
5. **全相等 / $n = 1$ 天然为 0**：循环中从不换值（或根本不进循环），无需特判。
6. **原地排序通常没问题**：直接 `sort` 入参即可省 $O(n)$ 拷贝；若环境要求保持入参不变，先复制一份。
7. **值域含负数结论不变**：证明只用值序不用非负性；但计数排序变体的下标映射需要平移。
