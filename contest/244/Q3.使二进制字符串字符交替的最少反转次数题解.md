# LeetCode 使二进制字符串字符交替的最少反转次数 题解

## 1. 题目概述

- **标题 / 题号**：使二进制字符串字符交替的最少反转次数（#1888，medium）
- **链接**：https://leetcode.cn/problems/minimum-number-of-flips-to-make-the-binary-string-alternating/
- **来源**：LeetCode 第 244 场周赛 Q3
- **难度**：中等
- **标签**：字符串、滑动窗口、递推

**题意**：给定 01 串 `s`，两种操作可按任意顺序执行任意次：**类型 1（旋转）**删除首字符并添加到结尾；**类型 2（翻转）**任选一位反转（`'0'` ↔ `'1'`）。求使 `s` 变成**交替**串（任意相邻字符不同，即形如 `"0101…"` 或 `"1010…"`）所需的**类型 2 最少次数**（类型 1 不计数）。

**约束**：

- $1 \le n \le 10^5$
- `s[i]` 为 `'0'` 或 `'1'`

> 💡 本题在本仓库另有[每日题解 1888](../../solution/1801-1900/1888_使二进制字符串字符交替的最少反转次数.md)，两篇为姊妹篇：每日篇主讲「倍增 $t = s+s$ + 绝对模式 $P_0$ 滑窗 + 互补 trick」，配面试问答与 $n$ 奇偶扩展；本篇按周赛复盘视角，主打**免倍增的 $O(1)$ 空间相对模式递推**（一步旋转 = 中间位匹配状态全体反转 + 首尾两个修正），给出以「旋转与翻转可交换」为核心的完整正确性证明，并由此推出 $n$ 偶时旋转无效、$n$ 奇时 $a' = b \pm 1$ 的奇偶二分。

## 3. 解题思路

### 3.1 暴力思路：枚举 $n$ 个起点 × 逐位统计

旋转不改字符内容，只改起点。长度 $n$ 的串恰有 $n$ 种旋转结果 $\rho^k(s) = s[k{:}]+s[{:}k]$（$k = 0..n-1$）。对每种旋转，与两个目标 $A = 0101\cdots$、$B = 1010\cdots$ 逐位比对取较小失配数，再全局取最小。时间 $O(n^2)$、空间 $O(n)$，$n = 10^5$ 时约 $10^{10}$ 次比较，必然超时。

> ⚠️ **两个症结**：其一，相邻旋转的差异高度重叠，逐位重算纯属浪费；其二，更隐蔽——「先转完再翻」是否漏掉了「**边转边翻**」的交错策略？这是本题正确性的第一块基石，§5 引理 1 给出否定回答：旋转与翻转可交换，任何交错策略都不比「先定起点、再翻转」更省。

### 3.2 核心观察：可分离性 + 相对模式一步递推

![核心观察：旋转与翻转可分离，一步递推免倍增](images/wc244_q3_split_recur_concept.svg)

关键洞察分三层：

**第一层——旋转与翻转可分离（引理 1）**：翻转改的是「字符的值」，旋转挪的是「字符的位置」，作用对象不同，故**可交换**。任意操作序列都等价于「先旋转 $k$ 步选定起点，再翻转若干字符」，于是

$$\text{ans} = \min_{0 \le k < n} f(k), \qquad f(k) = \min\bigl(d(\rho^k(s), A),\ d(\rho^k(s), B)\bigr)$$

**第二层——互补 trick**：$A$、$B$ 逐位互补，每个位置恰与一个目标失配，故 $a_k + b_k = n$（$a_k = d(\rho^k(s), A)$，$b_k = d(\rho^k(s), B)$）。只需跟踪一个整数 $a$，$f(k) = \min(a_k,\ n - a_k)$。

**第三层——相对模式一步递推（本篇主推，免倍增）**：从 $\rho^k(s)$ 旋转到 $\rho^{k+1}(s)$，是把首字符 $c = s[k]$ 移到尾。中间 $n-1$ 位各**左移一格**，它们面对的期望值奇偶翻转（位置 $j$ 的期望从 $(j+1) \bmod 2$ 变成 $j \bmod 2$），于是**每一位的匹配状态恰好反转**——原来贡献 $a_k - m_1$ 个失配（$m_1$ 为移出位的失配），反转后贡献 $(n-1) - (a_k - m_1)$ 个；移入位 $c$ 落在位置 $n-1$，期望 $(n-1) \bmod 2$，失配 $m_2$。合计：

$$a_{k+1} = (n-1) - (a_k - m_1) + m_2, \qquad m_1 = [\,c \ne 0\,], \quad m_2 = \bigl[\,c \ne (n-1) \bmod 2\,\bigr]$$

每步 $O(1)$，全程只维护一个整数——不需要倍增串 $t = s+s$，也不需要滑动窗口。

### 3.3 算法流程：一趟统计 + $n-1$ 步递推

![算法流程：一趟统计初始 a，再 n−1 步 O(1) 递推](images/wc244_q3_recur_flow.svg)

1. 一趟扫描统计初始 $a_0$（`s[j] != j%2` 的位数），$\text{ans} \leftarrow \min(a_0,\ n - a_0)$。
2. $k$ 从 $1$ 到 $n-1$：取 $c = s[k-1]$（本步移出者），算 $m_1, m_2$，更新 $a \leftarrow (n-1) - (a - m_1) + m_2$，$\text{ans} \leftarrow \min(\text{ans},\ a,\ n - a)$。
3. 返回 $\text{ans}$。

> 💡 **奇偶二分**（推论 1/2）：$n$ 偶时 $m_1 + m_2 = 1$，每步 $a' = n - a$——$a$ 与 $b$ 纯互换，$\text{ans}$ 不变，**可直接返回 $\min(a_0, n - a_0)$**（退化为无旋转的 1758）；$n$ 奇时 $m_1 = m_2 = c$，$a' = (n-1) - a + 2c$，递推最简。统一递推无需分支，两种写法都对。

### 3.4 示例演算

![示例演算：n 偶 a/b 每步互换旋转无效；n 奇旋转真正生效](images/wc244_q3_rotation_walkthrough.svg)

**官方示例 1** `s = "111000"`（$n = 6$，偶）：

| $k$ | $\rho^k(s)$ | $a$ | $b$ | $\min$ |
|-----|------------|-----|-----|--------|
| 0 | 111000 | 4 | 2 | 2 |
| 1 | 110001 | 2 | 4 | 2 |
| 2 | 100011 | 4 | 2 | 2 |
| 3 | 000111 | 2 | 4 | 2 |
| 4 | 001110 | 4 | 2 | 2 |
| 5 | 011100 | 2 | 4 | 2 |

$a$ 与 $b$ 每步互换，$\min$ 恒为 $2$——旋转完全无效（推论 1），答案即初始 $\min(4, 2) = 2$ ✓。

**自造样例** `s = "11110"`（$n = 5$，奇）：

| $k$ | $\rho^k(s)$ | $a$ | $b$ | $\min$ |
|-----|------------|-----|-----|--------|
| 0 | 11110 | 2 | 3 | 2 |
| 1 | 11101 | 4 | **1** | **1** |
| 2 | 11011 | 2 | 3 | 2 |
| 3 | 10111 | 4 | **1** | **1** |
| 4 | 01111 | 2 | 3 | 2 |

每步移出的 $c = s[k-1]$ 依次为 $1,1,1,1$，递推 $a' = 4 - a + 2c$ 让 $a$ 在 $2 \leftrightarrow 4$ 间摆动。$k=1$ 行：旋转一次得 `11101`，与 $B = 10101$ 只差第 2 位，翻一下即交替——答案 $1$，好于初始的 $2$ ✓。这正是 $n$ 奇时旋转的价值。

## 4. 算法细节

1. **可分离性的赛场口诀**：「翻转跟着字符走，旋转只挪位置」。要能在 30 秒内说清引理 1 的交换论证，这是「枚举起点 + 数失配」框架合法性的全部前提；说不清就可能在「边转边翻」上犹豫浪费场次时间。
2. **状态只有一个整数**：$a$ 是与**窗口内相对模式** $0101\cdots$ 的失配数；$b = n - a$ 随时可恢复，无需单独存储。递推三部件——全体反转 $(n-1) - (a - m_1)$、移出修正 $-m_1$ 已并入、移入修正 $+m_2$——各对应引理 3 证明的一段。
3. **$m_2$ 的期望值与 $n$ 奇偶绑定**：位置 $n-1$ 的期望是 $(n-1) \bmod 2$，$n$ 偶为 $1$、$n$ 奇为 $0$。奇偶二分由此而来：$n$ 偶 $m_1 + m_2 \equiv 1$（$a' = b$）；$n$ 奇 $m_1 = m_2 = c$（$a' = b - 1 + 2c$）。
4. **与倍增滑窗版的对照**（每日篇主推）：那边把 $s$ 拼成 $t = s+s$，维护与**绝对模式** $P_0[j] = j \bmod 2$ 的失配 $\text{diff}_0$，窗口滑动时移出/移入各改一项；本篇维护**相对模式**的 $a$，移出字符的「匹配状态反转」一次性摊到整体上。两者每步都是 $O(1)$，但本篇免掉 $2n$ 长的串与下标取模，空间 $O(1)$。
5. **不需要 DP 数组**：答案只依赖当前 $a$ 与历史最小值，天然滚动；这是「枚举量是一维标量」带来的红利，也是本题标签虽含 DP 却可零数组实现的原因。

## 5. 正确性证明

**约定**：$\rho(x)$ 表示一次类型 1 操作的结果（首字符移到尾），$\rho^k(s) = s[k{:}]+s[{:}k]$；$A = 0101\cdots$（位置 $j$ 期望 $j \bmod 2$），$B = 1010\cdots$；$d(x, y)$ 为等长串的汉明距离；$s \oplus S$ 表示把集合 $S$ 中下标的字符翻转。

**引理 1（可分离性）**：任意操作序列的终态形如 $\rho^k(s \oplus S)$，其中 $S$ 是被翻转**奇数次**的初始字符集合；且序列中类型 2 的次数 $t \ge |S|$。反之，任意 $(k, S)$ 都可用 $k$ 次类型 1 与 $|S|$ 次类型 2 实现。

**证明**：给每个初始字符标记身份 $i$（初始位于位置 $i$）。类型 1 是位置上的循环置换——身份随位置移动而值不变；类型 2 翻转「当时位于所选位置的那个身份」的值。对固定身份 $i$，「翻转身份 $i$」与任意旋转可交换（前者改值、后者挪位置，作用在不同对象上），故可将序列中全部翻转重排到全部旋转之后而不改变终态。设身份 $i$ 共被翻 $t_i$ 次，仅奇偶性影响终值，记 $S = \{i : t_i \text{ 为奇}\}$，则终态为 $\rho^k(s \oplus S)$ 且 $t = \sum_i t_i \ge |S|$。反向构造：先做 $k$ 次类型 1，再对 $S$ 中每个身份当前所在位置各做一次类型 2——翻转允许任选位置，总能命中。∎

**引理 2（固定串的最优翻转数）**：长度为 $n$ 的交替串恰为 $A, B$ 两个（首字符决定整串）。使串 $x$ 变交替的最少翻转数为 $\min\bigl(d(x, A),\ d(x, B)\bigr)$。

**证明**：对固定目标 $T$，一次翻转恰改变一个位置的匹配状态，$d(\cdot, T)$ 每步变化 $\pm 1$，故从 $x$ 到达 $T$ 至少需 $d(x, T)$ 次；逐一翻转失配位置恰用 $d(x, T)$ 次到达 $T$。对两个目标取最小。∎

**定理（答案公式）**：$\text{ans} = \min_{0 \le k < n} f(k)$，其中 $f(k) = \min\bigl(d(\rho^k(s), A),\ d(\rho^k(s), B)\bigr)$。

**证明**：**（$\ge$）** 任一合法序列由引理 1 得终态 $\rho^k(s \oplus S)$ 交替、类型 2 代价 $t \ge |S|$。由「逐位 XOR 与位置置换可交换」得 $\rho^k(s \oplus S) = \rho^k(s) \oplus \rho^k(S)$。终态是交替串，由引理 2 等于某个 $T \in \{A, B\}$，于是 $\rho^k(S)$ 恰为 $\rho^k(s)$ 与 $T$ 的失配位集合，$|S| = d(\rho^k(s), T) \ge f(k) \ge \min_k f(k)$。**（$\le$）** 取 $k^*$ 达到最小值及对应目标 $T$：先做 $k^*$ 次类型 1，再逐一翻转与 $T$ 失配的位置，共 $f(k^*)$ 次类型 2，终态为 $T$。∎

**引理 3（一步递推）**：设 $a_k = d(\rho^k(s), A)$，$c = s[k]$（第 $k+1$ 步旋转移出的字符），则

$$a_{k+1} = (n-1) - (a_k - m_1) + m_2, \qquad m_1 = [\,c \ne 0\,], \quad m_2 = \bigl[\,c \ne (n-1) \bmod 2\,\bigr]$$

**证明**：$\rho^{k+1}(s) = \rho(\rho^k(s))$。记 $x = \rho^k(s)$，其首字符 $x[0] = s[k] = c$，旋转结果 $y$ 满足 $y[j] = x[j+1]$（$0 \le j \le n-2$）、$y[n-1] = c$。对 $j \in [0, n-2]$：$y[j]$ 与 $A[j] = j \bmod 2$ 失配 $\iff x[j+1] \ne j \bmod 2 \iff x[j+1] = (j+1) \bmod 2 \iff x[j+1]$ 在原位置与 $A$ 匹配。故这 $n-1$ 位的失配数为 $(n-1) - (a_k - m_1)$，其中 $a_k - m_1$ 是去掉移出位后 $x$ 的失配数（$A[0] = 0$，故移出位失配即 $m_1 = [c \ne 0]$）。移入位 $y[n-1] = c$ 与 $A[n-1] = (n-1) \bmod 2$ 的失配为 $m_2$。相加即得。∎

**推论 1（$n$ 偶时旋转无效）**：$n$ 偶时 $(n-1) \bmod 2 = 1$，对任意 $c \in \{0, 1\}$ 有 $m_1 + m_2 = [c \ne 0] + [c \ne 1] = 1$，故 $a_{k+1} = (n-1) - a_k + 1 = n - a_k = b_k$：$a$ 与 $b$ 每步互换，$\min(a, b)$ 不变。因此 $\text{ans} = \min(a_0, n - a_0)$，问题退化为无旋转的 1758。∎

**推论 2（$n$ 奇时的简化递推）**：$n$ 奇时 $(n-1) \bmod 2 = 0$，$m_1 = m_2 = c$（字符值本身），故 $a_{k+1} = (n-1) - a_k + 2c = b_k - 1 + 2c \in \{b_k - 1,\ b_k + 1\}$：新 $a$ 在旧 $b$ 的基础上浮动一步，旋转才可能真正改善。∎

**算法正确性**：对 $k$ 归纳，由引理 3 知循环第 $k$ 轮后 $a = a_k$；每轮累取的 $\min(a, n - a) = \min(a_k, b_k) = f(k)$，由定理覆盖全部 $k \in [0, n-1]$，故返回值即答案。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。初始一趟统计 $O(n)$，随后 $n - 1$ 步递推每步 $O(1)$（取字符、两次比较、一次加减）。$n = 10^5$ 轻松通过。
- **空间复杂度**：$O(1)$ 额外空间。全程只维护 $a$、$\text{ans}$ 与循环下标，不建倍增串、不开窗口数组（对比：暴力 $O(n^2)$/$O(n)$；倍增滑窗版 $O(n)$/$O(n)$）。

## 7. 参考代码

### C++（统一递推版）

```cpp
class Solution {
public:
    int minFlips(string s) {
        int n = s.size();
        int a = 0;                            // 与 "0101..." 的失配数
        for (int j = 0; j < n; ++j)
            if ((s[j] - '0') != (j & 1)) ++a;
        int ans = min(a, n - a);
        int tail = (n - 1) & 1;               // 移入位（位置 n-1）的期望值
        for (int k = 1; k < n; ++k) {
            int c = s[k - 1] - '0';           // 本步从头移到尾的字符
            int m1 = (c != 0);                // 它原在位置 0 的失配
            int m2 = (c != tail);             // 它落到位置 n-1 的失配
            a = (n - 1) - (a - m1) + m2;      // 中间 n-1 位匹配状态全体反转
            ans = min(ans, min(a, n - a));
        }
        return ans;
    }
};
```

### Python（统一递推版）

```python
class Solution:
    def minFlips(self, s: str) -> int:
        n = len(s)
        a = sum(int(ch) != j % 2 for j, ch in enumerate(s))
        ans = min(a, n - a)
        tail = (n - 1) % 2
        for k in range(1, n):
            c = int(s[k - 1])
            a = (n - 1) - (a - (c != 0)) + (c != tail)
            ans = min(ans, a, n - a)
        return ans
```

### Python（奇偶二分版）

```python
class Solution:
    def minFlips(self, s: str) -> int:
        n = len(s)
        a = sum(int(ch) != j % 2 for j, ch in enumerate(s))
        if n % 2 == 0:                        # 推论 1：旋转无效，退化 1758
            return min(a, n - a)
        ans = min(a, n - a)
        for k in range(n - 1):                # n 奇时 m1 = m2 = c
            a = (n - 1) - a + 2 * int(s[k])
            ans = min(ans, a, n - a)
        return ans
```

> 💡 **写法对照**：三个版本均经对拍验证——与「枚举全部旋转 × 双目标」的暴力在所有长度 $\le 10$ 的 $2046$ 个 01 串上一致，且长度 $\le 6$ 时与模拟「交错执行旋转/翻转」的 0-1 BFS（旋转代价 0、翻转代价 1）结果一致，直接验证了引理 1 的可分离性。统一递推版无分支最省心；奇偶二分版把推论 1/2 写死，赛场 $n$ 偶时可直接一行送出。

## 8. 边界情况与易错点

1. **别怕「边转边翻」**：交错操作不会更省（引理 1），但**能证明它**才是正确性的核心；赛场上至少要能说出「翻转跟着字符走、旋转挪位置、二者可交换」这句口诀。
2. **旋转方向别搞反**：类型 1 是「头 → 尾」，即 $\rho^k(s) = s[k{:}]+s[{:}k]$。官方示例 1 的 `111000` → 两次操作 → `100011` 可作自查样例；方向反了全盘皆错。
3. **递推移出字符是 $s[k-1]$**（第 $k$ 步移出的是原串第 $k-1$ 位），差一错误高发；建议用 $\rho^1(s) = s[1{:}]+s[:1]$ 小样例核对再写循环。
4. **$m_2$ 的期望值是 $(n-1) \bmod 2$**：与 $n$ 奇偶绑定，$n$ 偶为 $1$、$n$ 奇为 $0$，不要写死成 $0$ 或 $1$。
5. **$n$ 偶时每个旋转的 $\min$ 都相同不是 bug**：那是推论 1 的性质（$a \leftrightarrow b$ 互换），可直接返回 $\min(a_0, n - a_0)$；反过来 $n$ 奇时答案**不一定**在 $k = 0$ 取到，循环必须跑满。
6. **$n = 1$ 天然交替**：初始 $\min(a_0, n - a_0) = \min(0, 1) = 0$，循环不执行，无需特判。
7. **无溢出风险**：$\text{ans} \le \lfloor n/2 \rfloor \le 5 \times 10^4$，`int` 足够。
8. **若改用倍增滑窗版**（每日篇写法）：移入下标是 $i + n - 1$ 不是 $i + n$；用 $s[j \bmod n]$ 免倍增时注意恒等式 $t[i+n-1] = s[i-1]$（移入的值与移出相同，奇偶性差异才是 $a$ 变化的根源）。

**延伸思考**：

- **环形相邻对视角**：$\rho^k(x)$ 交替 $\iff$ $x$ 的 $n$ 个环形相邻对中除第 $(k-1) \bmod n$ 对外全部相异。$n$ 偶时「缺一对」自动迫使最后一对也相异（奇偶绕圈一致），故交替性旋转不变、旋转无效——这是推论 1 的组合解释；$n$ 奇时环形上不存在全部相异的串（绕圈奇数步回到自身必矛盾），恰有一个相等对的串才唯一确定可用起点。据此可把答案重述为「最少翻转使环形相邻对的相等对数降为 $0$（$n$ 偶）或 $1$（$n$ 奇）」，每次翻转影响两个相邻对，可导出下界并与本解法互相印证。
- **类型 1 改为「一步旋转到任意 $k$」**：答案不变——题目只统计类型 2 次数；但若**两种操作都计数**求总操作数最小，就变成「旋转步数与失配数」的双目标权衡，需要对每个 $k$ 求 $k + f(k)$ 的最小值，递推框架原样可用。
- **目标改为回文**：旋转 + 翻转的框架仍成立（枚举起点，最少翻转 = $n -$ 该旋转下最大匹配数），但「一步递推」不再有「匹配状态全体反转」的对称性可用，值得想想为什么。
