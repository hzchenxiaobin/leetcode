# LeetCode 螺旋矩阵 IV 题解

## 1. 题目概述

- **标题 / 题号**：螺旋矩阵 IV（#2326，medium）
- **链接**：https://leetcode.cn/problems/spiral-matrix-iv/
- **来源**：LeetCode 第 300 场周赛 Q2
- **难度**：中等
- **标签**：数组、链表、矩阵、模拟

**题意**：给定矩阵维数 $m \times n$ 和一个整数链表的头节点 `head`。生成一个 $m \times n$ 的矩阵：从**左上角**开始，按**顺时针螺旋顺序**依次填入链表中的整数；若链表提前耗尽，剩余空格用 $-1$ 填充。返回该矩阵。

**约束**：

- $1 \le m, n \le 10^5$，且 $1 \le m \cdot n \le 10^5$
- 链表节点数目在范围 $[1, m \cdot n]$ 内
- $0 \le \text{Node.val} \le 1000$

> 💡 本题 = 「59. 螺旋矩阵 II」的数据源从 $1\dots n^2$ 换成一条链表，再加「提前耗尽填 $-1$」的尾巴。赛场上真正要做的只有一件事：**又稳又快地写出螺旋遍历模板**，链表只是顺路推进指针。

## 2. 示例

**示例 1**

```text
输入：m = 3, n = 5, head = [3,0,2,6,8,1,7,9,4,2,5,5,0]
输出：[[3,0,2,6,8],[5,0,-1,-1,1],[5,2,4,9,7]]
解释：13 个节点按螺旋顺序填入 3×5 矩阵的前 13 个位置，末尾 2 个空格保持 -1。
```

**示例 2**

```text
输入：m = 1, n = 4, head = [0,1,2]
输出：[[0,1,2,-1]]
解释：单行矩阵，链表从左到右填满前 3 格，第 4 格为 -1。
```

**示例 3**（自造，覆盖「链表恰好填满矩阵、终点落在中心」的边界）

```text
输入：m = 3, n = 3, head = [1,2,3,4,5,6,7,8,9]
输出：[[1,2,3],[8,9,4],[7,6,5]]
解释：9 个节点恰好填满 3×3 矩阵，螺旋路径的终点是矩阵中心 (1,1)，没有 -1。
```

## 3. 解题思路

### 3.1 暴力思路

朴素想法分两步：先把链表遍历成数组 `vals`（长度 $k$），再生成螺旋坐标序列，把 `vals[i]` 放到第 $i$ 个螺旋坐标上，$i \ge k$ 的格子填 $-1$。

问题出在「生成螺旋坐标」这一步怎么写。最笨的写法是维护一个访问标记矩阵，**每走一格都全矩阵扫描**寻找下一个未访问的合法格子——单步 $O(mn)$，整体 $O((mn)^2)$，在本题 $mn \le 10^5$ 的规模下约 $10^{10}$ 次操作，必然超时。另一种常见实现是「逐层收缩」（54 题官方解法）：维护 `top/bottom/left/right` 四个边界，走完一圈收缩一圈。它的复杂度是对的（$O(mn)$），但**圈数公式、单行/单列的退化特判、边界收缩顺序**全是易错点，赛场上调这种代码的时间成本不低。

### 3.2 核心观察：方向循环 + 「撞墙或已填即右转」

![核心观察：四个方向循环右转，撞墙或已填即换向](images/wc300_q2_direction_cycle.svg)

顺时针螺旋只有 4 个方向，按**右 → 下 → 左 → 上**无限循环；每次只需回答一个问题：**下一格能不能走**？

$$\text{下一格 } (x+d_x,\; y+d_y) \text{ 不可走} \iff \text{出界} \;\vee\; \text{已填过}$$

- 「出界」用下标越界判断；
- 「已填过」用矩阵值判断——**初始化全 $-1$，值 $\ne -1$ 即已填**。由于约束保证 $\text{Node.val} \ge 0$，$-1$ 与真实值永不冲突，一个数组同时充当**结果矩阵**和**visited 标记**，无需额外结构。

不可走就**右转**（$d \gets (d+1) \bmod 4$），可走就直行。于是每个格子只花 $O(1)$ 决定去向，总复杂度 $O(mn)$，且**没有任何特判**——单行、单列、中心终点全部被同一条规则覆盖。

### 3.3 算法流程

![算法流程：初始化全 -1，边推进链表边螺旋填格子](images/wc300_q2_algorithm_flow.svg)

1. **初始化**：`ans` 为 $m \times n$ 全 $-1$ 矩阵；起点 $(0,0)$，方向 $d=0$（向右）；
2. **主循环**：`cur` 从 `head` 出发，只要链表未耗尽：
   - 填 `ans[x][y] = cur->val`，`cur` 前进一步；
   - **探测**：算出直行方向的下一格 $(x+d_x,\; y+d_y)$，若出界或该格 `!= -1`，则右转 $d \gets (d+1) \bmod 4$；
   - **移动**：$x \mathrel{+}= d_x$，$y \mathrel{+}= d_y$；
3. **终止**：链表耗尽即停止，未访问格子保持初始 $-1$，直接返回 `ans`。

链表推进与填格子**同步**进行，不需要预先统计链表长度；螺旋序与链表无关，是矩阵自身的性质，所以「前 $k$ 个螺旋格填链表值、其余 $-1$」自动成立。

### 3.4 示例演算

![示例演算：3×5 矩阵的螺旋填充过程与四次转向](images/wc300_q2_example_walkthrough.svg)

以示例 1（$m=3,\; n=5$，13 个节点）为例，螺旋路径共 15 格，依次为：

| 段 | 方向 | 格子（行,列） | 填入值 |
|----|------|--------------|--------|
| ① | 右 | (0,0)→(0,4) | 3, 0, 2, 6, 8 |
| ② | 下 | (1,4)→(2,4) | 1, 7 |
| ③ | 左 | (2,3)→(2,0) | 9, 4, 2, 5 |
| ④ | 上 | (1,0) | 5 |
| ⑤ | 右 | (1,1) | 0（第 13 个节点，链表耗尽） |

此后 (1,2)、(1,3) 两格无人问津，保持 $-1$。最终矩阵：

$$\begin{bmatrix} 3 & 0 & 2 & 6 & 8 \\ 5 & 0 & -1 & -1 & 1 \\ 5 & 2 & 4 & 9 & 7 \end{bmatrix}$$

注意四次转向全部由「出界」触发；而第 ④ 段结束后的第 5 次转向由「已填」触发——(1,0) 填完后探测上方 (0,0) 值为 $3 \ne -1$，右转进入内层。两种触发条件在代码里是**同一个判断**。

## 4. 算法细节

1. **方向数组**：$d_x = (0, 1, 0, -1)$、$d_y = (1, 0, -1, 0)$ 分别对应右、下、左、上。右转即 $d \gets (d+1) \bmod 4$，无需 if-else 分支。
2. **$-1$ 的双重角色**：既是「空格占位值」又是「未访问标记」。这依赖值域 $0 \le \text{val} \le 1000$ 不含 $-1$；若值域含 $-1$，必须改为独立的 `visited` 数组或已填计数。
3. **探测 → 转向 → 移动的顺序**：先用**当前方向**探测下一格，决定是否转向，**再**移动。若把「移动」提到「探测」之前，判断的就不是真正要走的方向了。
4. **最后一步的坐标是"脏"的**：填完最后一个节点后，代码仍会探测并移动一次，坐标可能落到出界位置——但循环随即因 `cur == nullptr` 退出，该坐标不再被读取。若不放心，可改成计数驱动的 `for (int i = 0; i < m * n; ++i)` 循环（配合取链表值的判空），语义完全等价。
5. **与逐层收缩写法对比**：逐层版需要圈数 $\lceil \min(m,n)/2 \rceil$ 的循环上限、`top > bottom` 的中途退出、单行/单列只走一段的特判；方向数组版把这些全部折叠进一条「右转规则」，是**代码量最小、特判为零**的螺旋模板，也是赛场首选。

## 5. 正确性证明

**引理 1**（外环行为）：设当前未访问格子恰构成矩形 $R = [r_1, r_2] \times [c_1, c_2]$（且 $R$ 之外的格子均已访问），模拟位于 $(r_1, c_1)$、方向向右。则右转规则下，接下来按顺时针访问 $R$ 的**外环**——上边 $(r_1,\, c_1..c_2)$、右边 $(r_1{+}1..r_2,\, c_2)$、下边 $(r_2,\, c_2{-}1..c_1)$、左边 $(r_2{-}1..r_1{+}1,\, c_1)$——每格恰好一次，随后在 $(r_1{+}1,\, c_1)$ 处探测到 $(r_1, c_1)$ 已访问而右转，移动到 $(r_1{+}1,\, c_1{+}1)$、方向向右。

**证明**：逐段验证。走上边时，对任意 $c < c_2$，直行下一格 $(r_1, c+1) \in R$ 且未访问，不触发转向，故一直向右走到 $(r_1, c_2)$；此时下一格 $(r_1, c_2+1)$ 要么列越界（当 $c_2 = n-1$），要么 $\notin R$——由「$R$ 外均已访问」知其值 $\ne -1$——两种情况都触发右转向下。同理，右段向下走到 $(r_2, c_2)$ 后，下一格 $(r_2+1, c_2)$ 行越界或已访问，转向左；下段走到 $(r_2, c_1)$ 后，下一格 $(r_2, c_1-1)$ 越界或已访问，转向上；左段向上走到 $(r_1+1, c_1)$ 后，下一格 $(r_1, c_1)$ 已访问，转向右并移动到 $(r_1+1, c_1+1)$。各段格子互不相同、恰好覆盖外环。∎

**引理 2**（层间递归）：引理 1 结束后，未访问区域恰为内部矩形 $R' = [r_1+1, r_2-1] \times [c_1+1, c_2-1]$，且 $R'$ 之外均已访问；模拟位于 $(r_1+1, c_1+1)$、方向向右。这正是引理 1 前提在 $R'$ 上的重演（平移同构）。若 $R$ 至多一行或一列，则外环即 $R$ 的全部格子，此后矩阵已填满。

**证明**：外环恰为 $R$ 去掉 $R'$ 的差集，故未访问区域变为 $R'$；$R'$ 若非空，其外的一切（外环与 $R$ 之外）均已访问。单行（$r_1 = r_2$）时右边、下边、左边均为空，上边即全部；单列（$c_1 = c_2$）同理。∎

**定理**：从 $(0,0)$、方向向右出发，右转规则依次访问的格子序列是**逐层顺时针螺旋序**，$m \times n$ 个格子各恰好一次；又链表长度 $k \le m \cdot n$，故输出矩阵中恰为螺旋序前 $k$ 格填链表值、其余 $mn - k$ 格为 $-1$，即题目所求。

**证明**：对层数归纳。初始未访问区域为全矩阵 $[0, m-1] \times [0, n-1]$，满足引理 1 前提。由引理 1，第 1 层外环按顺时针序访问且每格一次；由引理 2，剩余状态是内层子问题的同构重演，归纳假设给出其余层的结论，归纳至内层为空（层数有限，每层至少剥掉 2 行或 2 列）。链表方面：第 $i$ 次循环迭代填入第 $i$ 个螺旋格的值为链表第 $i$ 个节点值（$i \le k$）；$i = k$ 后 `cur` 为空、循环退出，其余格子保持初始化的 $-1$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(m \cdot n)$。链表共 $k \le mn$ 个节点，每次迭代做一次填值、一次 $O(1)$ 的探测与转向判断；遍历的格子数与节点数同阶。
- **空间复杂度**：$O(1)$ 辅助空间（不计返回矩阵）。方向数组常数大小，`ans` 既是结果又是 visited 标记，无任何额外结构；返回的 $m \times n$ 矩阵是题目要求的输出，不计入。

## 7. 参考代码

### C++

```cpp
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
class Solution {
public:
    vector<vector<int>> spiralMatrix(int m, int n, ListNode* head) {
        vector<vector<int>> ans(m, vector<int>(n, -1));
        int dx[4] = {0, 1, 0, -1};   // 右、下、左、上
        int dy[4] = {1, 0, -1, 0};
        int x = 0, y = 0, d = 0;
        for (ListNode* cur = head; cur; cur = cur->next) {
            ans[x][y] = cur->val;
            int nx = x + dx[d], ny = y + dy[d];
            if (nx < 0 || nx >= m || ny < 0 || ny >= n || ans[nx][ny] != -1)
                d = (d + 1) % 4;     // 撞墙或已填：右转
            x += dx[d];
            y += dy[d];
        }
        return ans;
    }
};
```

### Python

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def spiralMatrix(self, m: int, n: int, head: Optional[ListNode]) -> List[List[int]]:
        ans = [[-1] * n for _ in range(m)]
        dx = [0, 1, 0, -1]   # 右、下、左、上
        dy = [1, 0, -1, 0]
        x = y = d = 0
        cur = head
        while cur:
            ans[x][y] = cur.val
            cur = cur.next
            nx, ny = x + dx[d], y + dy[d]
            if nx < 0 or nx >= m or ny < 0 or ny >= n or ans[nx][ny] != -1:
                d = (d + 1) % 4   # 撞墙或已填：右转
            x += dx[d]
            y += dy[d]
        return ans
```

## 8. 边界情况与易错点

1. **探测顺序不能反**：必须先判 `nx < 0 || nx >= m || ny < 0 || ny >= n` 再读 `ans[nx][ny]`——若把已填判断放前面，出界坐标直接读数组，C++ 越界 RE、Python 抛 IndexError。
2. **忘预填 $-1$**：`vector<vector<int>> ans(m, vector<int>(n))` 默认值是 $0$ 不是 $-1$，且 $0$ 还在值域内，既错占位又破坏 visited 判断。必须显式初始化为 $-1$。
3. **$-1$ 标记的适用前提**：值域 $\ge 0$ 才能用 `!= -1` 判已填。若题目变体允许 `val = -1`，需换独立 `visited` 数组（或已填计数器），否则同值混淆。
4. **单行 / 单列 / 1×1**：方向数组版无需特判（探测自然触发两次连续转向后耗尽节点）；逐层收缩版必须特判「一行/一列只走一段」，否则同一格被重复填或越界。
5. **链表恰为 $mn$ 长时**：填最后一格后仍会执行一次探测与移动，坐标进入无效状态，但循环立即终止、不再读取。若改写成 `while True` 之类的结构，务必保证 `cur` 判空是唯一的出口。
6. **转向只转一次**：右转规则单次转向即可——螺旋路径中不存在 180° 折返（只要还有未填格子，右转后的下一格必然可走）。若写成 `while 不可走: 右转` 的循环形式也等价，但多一次冗余判断。
7. **先推进链表再填值 vs 先填值再推进**：本模板是「填值 → 推进 → 探测 → 移动」的一体节奏；若把 `cur = cur->next` 误放进探测之后，会在转向分支里跳过节点，导致整条链表错位一格。
