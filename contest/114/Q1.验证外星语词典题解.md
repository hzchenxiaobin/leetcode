# LeetCode 验证外星语词典 题解

## 1. 题目概述

- **标题 / 题号**：验证外星语词典（#953，easy）
- **链接**：https://leetcode.cn/problems/verifying-an-alien-dictionary/
- **来源**：LeetCode 第 114 场周赛 Q1
- **难度**：简单
- **标签**：数组、哈希表、字符串

**题意**：某种外星语同样使用 26 个小写字母，但字母的**大小顺序**由排列 `order` 给出：`order[0]` 是最小的字母，`order[25]` 是最大的字母。给定一串用这种语言书写的单词 `words`，判断它们是否按该语言下的**字典序**（非降）排列。

**约束**：

- $1 \le words.length \le 100$
- $1 \le words[i].length \le 20$
- $order.length = 26$，`order` 是 26 个小写字母的排列
- `words[i]` 与 `order` 中的字符都是小写英文字母

## 2. 示例

**示例 1**

```text
输入：words = ["hello","leetcode"], order = "hlabcdefgijkmnopqrstuvwxyz"
输出：true
解释：在该语言的字母表中 'h' 位于 'l' 之前（order 里 h 在第 0 位、l 在第 2 位），
     故 "hello" < "leetcode"，序列有序。
```

**示例 2**

```text
输入：words = ["word","world","row"], order = "worldabcefghijkmnpqstuvxyz"
输出：false
解释："word" 与 "world" 前三个字符相同，第 4 个字符 'd' 在 order 中排第 4 位，
     而 'l' 排第 3 位，故 "word" > "world"，顺序被破坏。
```

**示例 3**

```text
输入：words = ["apple","app"], order = "abcdefghijklmnopqrstuvwxyz"
输出：false
解释："app" 是 "apple" 的前缀，前缀更短者更小，故 "apple" > "app"。
```

## 3. 解题思路

### 3.1 暴力思路

最笨的做法：把每个单词"翻译"成按 `order` 排名组成的序列，再按标准字典序对整个数组排序，最后逐位比对排序前后的数组是否完全一样。

- 时间 $O(n\log n \cdot L)$：排序需要 $O(n\log n)$ 次两两比较，每次比较还要逐字符查排名；
- 空间 $O(nL)$：需要复制一份数组（以及排名序列）。

更关键的是，这种做法**多做了一整个排序**。验证「序列有序」根本不需要排序——只要检查每一对**相邻**元素即可。

### 3.2 核心观察：排名表 + 只看相邻两词

![把 order 翻译成 rank 排名表，之后一切比较都在 O(1) 内完成](images/wc114_q1_rank_map.svg)

- **建表**：用 `rank[c]` 记录字母 `c` 在 `order` 中的位置，即它在这门语言里的"大小名次"。$26$ 次赋值即可，之后任何两个字母的比大小都是 $O(1)$。
- **只比相邻**：字典序是**全序关系**（满足传递性），所以"整串单词非降"等价于"每一对相邻单词非降"。

$$words[0] \le words[1] \le \cdots \le words[n-1] \iff \forall i,\ words[i] \le words[i+1]$$

- **两词比大小的三条规则**（设 `a = words[i]`、`b = words[i+1]`，从左往右找到第一个不同的位置 $i_0$）：
  1. 若两词在 $i_0$ 处**都还有字符**：由 `rank[a[i_0]]` 与 `rank[b[i_0]]` 决定，前者小则有序；
  2. 若 $a$ 先走完（`a` 是 `b` 的**真前缀**）：短者更小，有序；
  3. 若 $b$ 先走完：长者更大，**违法**；
  4. 若两词完全相同：相等，有序（非降允许相等）。

### 3.3 算法流程

![算法流程：建排名表，逐对比较相邻单词](images/wc114_q1_compare_flow.svg)

```text
1. for i = 0 .. 25:  rank[order[i]] = i
2. for k = 0 .. n-2:
       a = words[k], b = words[k+1]
       i = 0
       while i < len(a) and i < len(b) and a[i] == b[i]:  i += 1
       若 i 已到达 a 或 b 的末尾:
           若 len(a) > len(b):  return false      // b 是真前缀
       否则:
           若 rank[a[i]] > rank[b[i]]:  return false
3. return true
```

### 3.4 示例演算

对示例 2 的 `words = ["word","world","row"]`、`order = "worldabcefghijkmnpqstuvxyz"`，先建表可得 `rank: w=0, o=1, r=2, l=3, d=4, a=5, b=6, c=7, ...`：

| 相邻对 | 首个不同位置 | 字符比较 | 结论 |
|--------|--------------|----------|------|
| ("word", "world") | 3 | `d`(4) vs `l`(3)，`d` 更大 | 逆序，返回 false |
| ("world", "row") | 0 | `w`(0) vs `r`(2)，`w` 更小 | 有序（此对无需再判） |

第一对就出现逆序，算法立即返回 `false`，与该题示例输出一致。示例 1 中 `("hello","leetcode")` 的首个不同位置是 0，`h`(0) < `l`(2)，整串只有一对相邻元素，故返回 `true`。

## 4. 算法细节

1. **用数组而不是哈希表**：字母表固定 26 个，`int rank[26]` 的查表是一次内存访问，比 `unordered_map` 快一个量级，也不会有哈希冲突。
2. **`rank` 的填充方向**：`rank[order[i] - 'a'] = i`——**字母 → 名次**；不要写反成"名次 → 字母"。
3. **循环终止条件**：`while (i < a.size() && i < b.size() && a[i] == b[i])` 三个条件缺一不可，任一越界都必须停下进入前缀判定。
4. **前缀判定只需比较长度**：走到末尾说明短串已结束。若 `len(a) > len(b)` 则 `b` 是 `a` 的真前缀，逆序；反之（含相等）都合法。
5. **提前返回**：一发现逆序就 `return false`，不必把剩余单词对看完。
6. **不修改输入**：全程只做只读比较，不需要排序、不需要拷贝 `words`。
7. **`n = 1` 时无相邻对**：循环一次都不执行，直接返回 `true`（单个单词必然有序）。

## 5. 正确性证明

先把「外星字典序」形式化：对两个单词 $a, b$，令 $i_0$ 为最小的满足 $i_0 < \min(|a|,|b|)$ 且 $a[i_0] \ne b[i_0]$ 的下标（若不存在则记 $i_0 = \min(|a|,|b|)$）。定义

$$
a \prec b \iff
\begin{cases}
\mathrm{rank}(a[i_0]) < \mathrm{rank}(b[i_0]), & i_0 < \min(|a|,|b|),\\
|a| < |b|, & i_0 = \min(|a|,|b|) \text{ 且 } |a| \ne |b|,\\
\text{两词相同}, & \text{否则}.
\end{cases}
$$

**引理 1（首异字符定序）**：对任意两词 $a, b$，`less(a, b)` 子过程（算法第 2 步）返回"有序"当且仅当 $a \preceq b$。

**证明**：算法用 while 循环停在最小的 $i_0$（两词字符不再相等，或有一方耗尽），与上面的 $i_0$ 定义一致。分三种情况：

- $i_0 < \min(|a|,|b|)$：算法比较 `rank[a[i_0]]` 与 `rank[b[i_0]]`，正是定义中的第一种情形，判据相同；
- $i_0 = \min(|a|,|b|)$ 且 $|a| \ne |b|$：算法只在 `len(a) > len(b)` 时判违法，等价于要求 $|a| < |b|$，与定义第二种情形相同；
- 两词长度相同且字符全同：算法不返回 false，判为相等，合法。

故两者判定完全一致。∎

**引理 2（全序的传递性）**：$\preceq$ 是集合 $\Sigma^{*}$ 上的非严格全序（自反、反对称、传递）。

**证明**：$\preceq$ 可以看作把每个单词映射为无穷序列 $(\mathrm{rank}(a_0), \mathrm{rank}(a_1), \dots)$ 并在末尾补以"比任何字母都小的终止符 $\bot$"，再按普通字典序比较（$\bot$ 只出现在末尾，且 $\bot$ 小于所有字母，恰好表达"短者在前"）。普通字典序在无穷序列上是全序，故 $\preceq$ 满足自反、反对称与传递。∎

**引理 3（相邻有序蕴含整体有序）**：若对一切 $0 \le i < n-1$ 有 $words[i] \preceq words[i+1]$，则对一切 $i < j$ 有 $words[i] \preceq words[j]$。

**证明**：对 $j - i$ 归纳。$j - i = 1$ 即题设。设对 $j - i - 1$ 成立，则 $words[i] \preceq words[j-1]$ 且 $words[j-1] \preceq words[j]$，由引理 2 的传递性得 $words[i] \preceq words[j]$。∎

**定理**：算法返回 `true` 当且仅当 `words` 按外星语字典序非降排列。

**证明**：

- 若返回 `true`：说明对每个 $k$ 都有 `less(words[k], words[k+1])` 成立。由引理 1 得 $words[k] \preceq words[k+1]$ 对所有 $k$ 成立，再由引理 3 得整个序列非降。
- 若返回 `false`：说明某个 $k$ 上 `less` 判定失败，由引理 1 得 $words[k] \succ words[k+1]$，即相邻逆序。若整串非降，则应有 $words[k] \preceq words[k+1]$，由引理 2 的反对称性导出矛盾。故序列确实不是非降的。

两个方向都成立，定理得证。∎

## 6. 复杂度分析

- **时间**：$O(26 + L)$，其中 $L = \sum_i |words[i]|$。建表固定 $26$ 次赋值；第 $k$ 对相邻单词最多比较 $\min(|words[k]|, |words[k+1]|)$ 个字符，而 $\min(|a|,|b|) \le |a|$ 且 $\le |b|$，对 $k$ 求和不超过 $2L$（每个单词最多作为左右两侧各贡献一次），故总比较次数为 $O(L)$。
- **空间**：$O(1)$，只有长度 26 的排名数组；不复制输入。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <string>

using namespace std;

class Solution {
public:
    bool isAlienSorted(vector<string>& words, string order) {
        int rank[26];
        for (int i = 0; i < 26; i++) rank[order[i] - 'a'] = i;   // 字母 -> 名次

        for (size_t k = 0; k + 1 < words.size(); k++) {
            const string& a = words[k];
            const string& b = words[k + 1];
            size_t i = 0;
            while (i < a.size() && i < b.size() && a[i] == b[i]) i++;
            if (i == a.size() || i == b.size()) {
                if (a.size() > b.size()) return false;   // b 是 a 的真前缀
            } else if (rank[a[i] - 'a'] > rank[b[i] - 'a']) {
                return false;                            // 首异字符逆序
            }
        }
        return true;
    }
};
```

### Python

```python
class Solution:
    def isAlienSorted(self, words: list[str], order: str) -> bool:
        rank = {c: i for i, c in enumerate(order)}      # 字母 -> 名次

        def less(a: str, b: str) -> bool:
            for ca, cb in zip(a, b):
                if ca != cb:
                    return rank[ca] < rank[cb]           # 首异字符定序
            return len(a) <= len(b)                      # 前缀更短者更小

        return all(less(words[i], words[i + 1]) for i in range(len(words) - 1))
```

## 8. 边界情况与易错点

1. **前缀方向写反**：`["apple","app"]` 必须返回 `false`（长串在前），而 `["app","apple"]` 返回 `true`。判断条件是 `len(a) > len(b)`，不是 `!=`。
2. **完全相同单词**：如 `["abc","abc"]` 合法（非降允许相等），不要误判为逆序。
3. **单单词数组**：`words.length = 1` 时没有相邻对，应该返回 `true`。
4. **`rank` 填反**：必须是"字母 → 名次"，写成"名次 → 字母"会让所有比较结果反过来。
5. **只判首字符**：首个不同位置之前的所有字符都相等（这正是 while 循环的作用），不能只看第 0 位。
6. **越界访问**：while 循环必须同时检查两串长度，否则访问 `a[i]`/`b[i]` 会越界。
7. **不要真排序**：排序会改变输入顺序且多做 $O(n\log n)$ 次比较，"验证有序"只需 $O(n)$ 次相邻比较。
8. **非降不等于严格递增**：`words` 中允许出现相等单词，用"非降"（`<=`）语义而非"严格递增"。
