# LeetCode 最高的广告牌 题解

## 1. 题目概述

- **标题 / 题号**：最高的广告牌（#956，hard）
- **链接**：https://leetcode.cn/problems/tallest-billboard/
- **来源**：LeetCode 第 114 场周赛 Q4
- **难度**：困难
- **标签**：数组、动态规划、0-1 背包、中途相遇

**题意**：有 $n$ 根长度为正整数的钢筋 `rods`。要把其中一部分钢筋**两两不重叠**地分成两组（分别焊成广告牌的左、右支架，同一根钢筋不能既贴左边又贴右边，也可以有钢筋压根不用），要求两侧高度**相等**，求这个相等高度（即广告牌高度）的最大值；若无法做到，返回 $0$。

形式化地：把下标集合划分为 $L \cup R \cup U$（三者互不相交），要求

$$\sum_{i \in L} rods[i] = \sum_{i \in R} rods[i] = h,$$

最大化 $h$。

**约束**：

- $0 \le rods.length \le 20$
- $1 \le rods[i] \le 1000$
- $\sum rods[i] \le 5000$

## 2. 示例

**示例 1**

```text
输入：[1,2,3,6]
输出：6
解释：{1,2,3} 与 {6} 两个不相交子集的和都是 6，故广告牌高 6。
```

**示例 2**

```text
输入：[1,2,3,4,5,6]
输出：10
解释：{2,3,5} 与 {4,6} 的和都是 10；总和 21，剩余一根 1 未被使用。
```

**示例 3**

```text
输入：[1,2]
输出：0
解释：只有两根钢筋且长度不等，怎么分都无法让两侧等高，返回 0。
```

## 3. 解题思路

### 3.1 暴力思路

每根钢筋有 3 种去向：**贴左支架**、**贴右支架**、**不用**。直接枚举所有方案是 $3^n$ 种，$n = 20$ 时约 $3.5\times10^9$，无论 C++ 还是 Python 都不可接受。

改造思路：

- 枚举子集对：先枚举一侧的钢筋集合，再在剩余集合里找和为同值的子集，仍然是 $3^n$ 级别；
- **中途相遇**（meet in the middle）：把钢筋分成两半，各自枚举 $3^{10} \approx 5.9\times10^4$ 种分配，再按"左右高度差"合并。复杂度 $O(3^{n/2}\log)$，可行但要额外写合并逻辑与排序，常数不小。

有没有更简单的结构？注意到"两根支架各自焊了多高"其实只需要关心**两个量**，这提示我们可以用"差值"做背包 DP。

### 3.2 核心观察：用 (高度差, 较矮一侧) 压缩状态

![状态设计：只需记录高度差 d 与较矮一侧的高度 s](images/wc114_q4_state.svg)

处理到某一根钢筋时，当前局面的完整信息是两侧高度 $(a, b)$。但它们可以等价地换成

$$d = a - b,\qquad s = \min(a, b).$$

- 由 $(d, s)$ 可唯一还原两侧高度：$a = s + \max(d, 0)$，$b = s + \max(-d, 0)$；
- 最终目标 $a = b$ 等价于 $d = 0$，此时广告牌高度就是 $s$。

**关键洞察（支配性）**：如果两个局面**差值相同**，那么"较矮一侧更高"的那个局面**必然更好**。因为后续每根钢筋无论贴左、贴右还是不用，都会让两侧高度同时加上"相同的变化"，差值保持不变；从更高的局面出发，最终等高时的高度恰好会多出这个差距。

于是状态数量被压到"差值的个数"，即 $O(\sum rods)$ 级别。定义

$$dp[d] = \text{差值为 } d \text{ 的所有局面中，} \min(a,b) \text{ 的最大值}.$$

初始 $dp[0] = 0$（两侧都是 0），其余为 $-1$（不可达）。

### 3.3 状态转移

![三选择转移：不用 / 贴左 / 贴右](images/wc114_q4_transition.svg)

对每根长度 $x$ 的钢筋，从状态 $(d, s)$ 出发，先还原 $a = s + \max(d,0)$、$b = s + \max(-d,0)$，再枚举三种去向：

$$
\begin{aligned}
\text{不用：}&\quad (a,\ b) \ \to\ (d,\ s)\\
\text{贴左：}&\quad (a + x,\ b) \ \to\ (d + x,\ \min(a + x, b))\\
\text{贴右：}&\quad (a,\ b + x) \ \to\ (d - x,\ \min(a, b + x))
\end{aligned}
$$

新状态的目标值都是"新差值与新的 $\min$"，用 `max` 合并进下一层 DP 数组。因为每根钢筋只能选一种去向，必须**先拷贝一份旧数组**再做转移（0-1 背包的标准写法）。

最终答案是 $dp[0]$（$d = 0$ 时的 $s$）；若 $dp[0] = 0$ 说明凑不出非空的两侧，返回 0 正好正确。

### 3.4 示例演算

![示例 1 [1,2,3,6] 的状态演化](images/wc114_q4_walkthrough.svg)

对 `rods = [1,2,3,6]` 逐根转移，只列出关键状态：

| 处理完 | 状态 d=0 | d=1 | d=2 | d=3 | d=6 | 说明 |
|--------|----------|-----|-----|-----|-----|------|
| 初始 | s=0 | — | — | — | — | 两侧均空 |
| 1 | 0 | 0 | — | — | — | 1 贴左：d=1，s=0 |
| 2 | 0 | 0 | 0 | 0 | — | d=−1 时 s=1（1 vs 2） |
| 3 | **3** | 0 | 2 | 0 | — | 3 贴右到 (3,0) 得 (3,3)，s=3 |
| 6 | 3 | … | … | … | 0 | 6 贴右到 (6,0) 得 (6,6)，s=**6** |

最后一行：状态 $(d=6, s=0)$ 表示"一侧 6、另一侧 0"，把这根 6 贴到空的那一侧后得到 $(6,6)$，$s = 6$，故 $dp[0] = 6$，与示例输出一致。

## 4. 算法细节

1. **差值下标偏移**：$d \in [-\text{sum}, \text{sum}]$，用 `idx = d + sum` 映射到数组下标；数组大小 $2 \cdot sum + 1$。总和不超过 5000，数组至多 10001 个 `int`。
2. **不可达标记**：用 $-1$ 表示不可达（$s \ge 0$，不会与合法值冲突）。
3. **0-1 背包**：每根钢筋只能用一次，所以循环体内先 `ndp = dp`（表示"不用"），再只从旧 `dp` 读取转移，最后 `dp.swap(ndp)`。
4. **差值越界**：加的钢筋总长不超过 `sum`，理论上 $d + x$ 不会越界；但加上 `if (nd >= -sum && nd <= sum)` 的保护更安全。
5. **还原 $a, b$**：$a = s + \max(d,0)$，$b = s + \max(-d,0)$；用整数运算，不会溢出（最大 5000）。
6. **Python 用字典**：只需枚举"当前可达的差值"，避免遍历 10001 个格子；`ndp = dict(dp)` 表示"不用"分支。
7. **答案取 `dp[0]`**：初始 `dp[0] = 0`，若从未达到更高的等高状态，答案自然是 0。
8. **不要漏掉"贴右"分支**：只考虑"贴左"会让所有状态差值非负，永远凑不出对称的方案。

## 5. 正确性证明

设经过前 $k$ 根钢筋后，某个分配方案的两侧高度为 $(a, b)$。记 $d = a - b$，$s = \min(a,b)$。

**引理 1（状态可逆）**：由 $(d, s)$ 可以唯一还原 $(a, b)$，即 $a = s + \max(d,0)$，$b = s + \max(-d,0)$。

**证明**：若 $d \ge 0$，则 $a \ge b$，故 $s = b$，$a = b + d = s + d$，即 $a = s + \max(d,0)$、$b = s + 0 = s + \max(-d,0)$。若 $d < 0$，对称可得。两种情况合并即得结论。∎

**引理 2（支配性）**：设两个局面 $P_1 = (a_1, b_1)$、$P_2 = (a_2, b_2)$ 满足 $a_1 - b_1 = a_2 - b_2 = d$ 且 $s_1 = \min(a_1,b_1) \ge s_2 = \min(a_2,b_2)$。则对任意剩余的钢筋分配方式，$P_1$ 的最终结果都不差于 $P_2$：若 $P_2$ 最终得到两侧高度 $h$，则 $P_1$ 用同一分配得到 $h + (s_1 - s_2)$。

**证明**：由 $d$ 相同与引理 1，$a_1 = a_2 + \Delta$、$b_1 = b_2 + \Delta$，其中 $\Delta = s_1 - s_2 \ge 0$。对剩余钢筋的任一分配，两侧高度都是在原基础上加上"分配到该侧的钢筋长度之和"，这部分对 $P_1$、$P_2$ 完全相同，故最终 $a_1' = a_2' + \Delta$、$b_1' = b_2' + \Delta$。若 $a_2' = b_2' = h$，则 $a_1' = b_1' = h + \Delta$，且 $h + \Delta \ge h$。∎

**引理 3（转移完备）**：对每个局面，下一根钢筋长度 $x$ 的三种去向恰好对应 3.3 中的三个转移式，且转移后的 $(d', s')$ 计算正确。

**证明**："不用"不改变 $(a,b)$，故 $(d,s)$ 不变。"贴左"后新高度为 $(a+x, b)$，于是 $d' = (a+x) - b = d + x$，$s' = \min(a+x, b)$。"贴右"对称：$d' = d - x$，$s' = \min(a, b+x)$。三种去向穷尽了所有可能。∎

**定理**：算法返回的 $dp[0]$ 等于满足"两侧等高"的最大高度。

**证明**：对钢筋根数 $k$ 归纳证明：处理完前 $k$ 根后，对每个可达差值 $d$，`dp[d]` 等于"前 $k$ 根钢筋的所有分配方案中，差值为 $d$ 的方案里 $\min(a,b)$ 的最大值"。

- $k = 0$：只有 $(0,0)$，$dp[0] = 0$，其余不可达，成立。
- 归纳步：任一 $k+1$ 根的方案，去掉第 $k+1$ 根钢筋即为某个 $k$ 根方案 $(a,b)$，其第 $k+1$ 根去向属于三种之一，由引理 3 得到的状态与转移式一致；反之每个转移都由真实方案实现。因此新数组覆盖了全部方案。再由引理 2，同一差值下只需保留最大的 $s$，故取 `max` 不丢失最优解。

于是 $dp[0]$ 是"差值为 0"的所有方案中 $s$ 的最大值，而差值为 0 时 $s = a = b$ 就是广告牌高度，故 $dp[0]$ 即所求最大高度。∎

## 6. 复杂度分析

- **时间**：$O(n \cdot S)$，其中 $S = \sum rods \le 5000$。每个差值状态 $O(1)$ 转移，共 $n \le 20$ 轮，总计约 $2\times10^5$ 次操作（Python 字典版本实际只遍历可达差值，通常更少）。
- **空间**：$O(S)$，两个长度为 $2S+1$ 的数组（滚动），字典版本为 $O(\text{可达差值数}) \le O(S)$。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <algorithm>

using namespace std;

class Solution {
public:
    int tallestBillboard(vector<int>& rods) {
        int total = 0;
        for (int x : rods) total += x;
        int off = total, W = 2 * total + 1;

        vector<int> dp(W, -1);      // dp[d + off] = 差值为 d 时较小一侧的最大高度
        dp[off] = 0;

        for (int x : rods) {
            vector<int> ndp = dp;   // 不使用这根钢筋
            for (int d = -total; d <= total; d++) {
                int s = dp[d + off];
                if (s < 0) continue;
                int a = s + max(d, 0), b = s + max(-d, 0);

                int na = a + x, nb = b;              // 贴到较高的一侧（记为左）
                int nd = na - nb;
                if (nd >= -total && nd <= total)
                    ndp[nd + off] = max(ndp[nd + off], min(na, nb));

                na = a; nb = b + x;                  // 贴到另一侧（记为右）
                nd = na - nb;
                if (nd >= -total && nd <= total)
                    ndp[nd + off] = max(ndp[nd + off], min(na, nb));
            }
            dp.swap(ndp);
        }
        return max(0, dp[off]);
    }
};
```

### Python

```python
class Solution:
    def tallestBillboard(self, rods: list[int]) -> int:
        dp = {0: 0}                 # 差值 -> 较小一侧的最大高度（未出现的差值不可达）

        for x in rods:
            ndp = dict(dp)          # 不使用这根钢筋
            for d, s in dp.items():
                a, b = s + max(d, 0), s + max(-d, 0)
                for na, nb in ((a + x, b), (a, b + x)):
                    nd = na - nb
                    ns = min(na, nb)
                    if ns > ndp.get(nd, -1):
                        ndp[nd] = ns
            dp = ndp

        return dp.get(0, 0)
```

## 8. 边界情况与易错点

1. **空数组或单根钢筋**：`rods = []` 或 `[5]` 都无法做出两根等高支架，返回 0（初始 `dp[0] = 0` 恰好给出 0，不需要特判）。
2. **同一根钢筋不能同时贴两侧**：这正对应"每根钢筋三选一"且要**先复制再转移**；若直接在原数组上原地更新，会变成每根钢筋可用多次的完全背包，答案偏大。
3. **只考虑"贴左"**：所有差值会保持非负，永远意会不到"右侧更高"的局面，最终多半算出 0。
4. **漏掉"不用"分支**：`ndp = dp` 的拷贝就是"不用"，漏掉的话，无法跳过某些钢筋（示例 2 中的 1 就必须跳过）。
5. **答案为 0 的合法性**：题目明确"无法安装时返回 0"，而 $dp[0]=0$ 同时表示"两侧都空"，语义一致。
6. **差值下标越界**：数组大小必须是 $2\cdot total + 1$，偏移量是 `total`；若只开 `total + 1` 会因为负差值而越界。
7. **$\min(a,b)$ 的计算**：必须先还原 $a, b$ 再取 $\min$，直接对 $d$ 与 $s$ 做加减容易搞错方向（尤其是 $d < 0$ 时）。
8. **答案不是"总和的一半"**：两侧可以都不用某些钢筋（示例 2 总和 21，答案 10 小于 $\lfloor 21/2\rfloor = 10$ 恰好相等；但示例 1 总和 12、答案 6 也相等；反例：`[1,1,1]` 答案是 1 而不是 1.5）。所有计算保持整数。
