# LeetCode 删列造序 II 题解

## 1. 题目概述

- **标题 / 题号**：删列造序 II（#955，medium）
- **链接**：https://leetcode.cn/problems/delete-columns-to-make-sorted-ii/
- **来源**：LeetCode 第 114 场周赛 Q3
- **难度**：中等
- **标签**：贪心、数组、字符串

**题意**：给定 $n$ 个**长度相同**（设为 $m$）的字符串组成数组 `strs`。选择一个列下标集合 $D$，把每个字符串中这些位置的字符删掉。要求删除后得到的字符串数组按**字典序非降**排列，求 $\lvert D\rvert$ 的**最小**值。

注意：题目**只要求行与行之间**（`strs[i] <= strs[i+1]`）有序，行内部的字符没有要求（这一点与同场的「删列造序 III」恰好相反）。

**约束**：

- $n = strs.length$，$1 \le n \le 100$
- $1 \le m = strs[i].length \le 100$，所有字符串等长
- `strs[i]` 只含小写英文字母

## 2. 示例

**示例 1**

```text
输入：strs = ["ca","bb","ac"]
输出：1
解释：删除第 0 列后得到 ["a","b","c"]，已按字典序排列（"a" <= "b" <= "c"）。
     若不删列，"ca" > "bb"（首字符 c > b），不合法，故至少删 1 列。
```

**示例 2**

```text
输入：strs = ["xc","yb","za"]
输出：0
解释：第 0 列 x < y < z 已经把相邻两行全部区分开，第 1 列无论是什么都不影响比较结果，
     所以不需要删任何列。注意 strs 的行本身不必有序（"za" 可以出现在末尾）。
```

**示例 3**

```text
输入：strs = ["zyx","wvu","tsr"]
输出：3
解释：每一列都是逆序（z>w、y>v、x>u），三列必须全部删除。
```

## 3. 解题思路

### 3.1 暴力思路

`strs` 的列数 $m \le 100$，最直接的做法是枚举所有 $2^m$ 个删除子集，对每个子集检查删除后相邻行是否非降，取合法子集的最小大小。

- 时间 $O(2^m \cdot n \cdot m)$：$m = 100$ 时 $2^{100}$ 完全不可行；
- 即使 $m \le 20$，也没有利用"列的判定是局部的、可以逐列增量判断"这一结构。

**关键难点**：某一列是否必须删除，并不能脱离"之前保留了哪些列"单独判断——如果某一对相邻行在更靠前的列上已经被严格区分开，后面这些列上的逆序就完全无害。

### 3.2 核心观察：逐列决策 + "已区分"标记

![逐列扫描：维护每对相邻行是否已被严格区分](images/wc114_q3_state.svg)

对每个相邻行对 $i \in [0, n-2]$（比较 `strs[i]` 与 `strs[i+1]`），用布尔量 `sorted[i]` 表示：

> `sorted[i] = true` ⟺ 在**已经保留的列**中，存在某一列 $c$ 使 `strs[i][c] < strs[i+1][c]`，且 $c$ 是所有**已保留列**里两行字符第一次不同的位置。

一旦 `sorted[i]` 为真，第 $i$ 对行的大小关系就**永久确定**了，之后再保留什么列都不会改变它（字典序由首个不同字符决定）。

于是从左到右扫描每一列 $c$：

- 检查所有**尚未**区分的行对（`sorted[i] == false`）在第 $c$ 列上是否出现 `strs[i][c] > strs[i+1][c]`；
- **若有逆序**：这一列一旦保留，这对行就会在该列上首次分出大小且方向错误，因此**必须删除**该列（`ans++`），并且不能更新任何 `sorted[i]`；
- **若没有逆序**：保留该列。它不会破坏任何行对，还能把该列上 `strs[i][c] < strs[i+1][c]` 的那些行对标记为已区分，从而**放宽**后续列的约束。保留永远不会让局面变差，所以贪心地保留。

![贪心决策：有逆序则删，无逆序则保留并更新标记](images/wc114_q3_flow.svg)

> 💡 **一句话总结**：把"选哪些列删"变成"从左到右逐列决定"，并让每一列只对**尚未确定顺序**的相邻行负责。

### 3.3 算法流程

```text
1. n = len(strs), m = len(strs[0])
2. sorted[0..n-2] = false, ans = 0
3. for c = 0 .. m-1:
       bad = false
       for i = 0 .. n-2:
           若 not sorted[i] 且 strs[i][c] > strs[i+1][c]:  bad = true; break
       若 bad:  ans += 1; continue                 // 该列必须删除
       for i = 0 .. n-2:
           若 not sorted[i] 且 strs[i][c] < strs[i+1][c]:  sorted[i] = true
4. return ans
```

### 3.4 示例演算

![示例 1 的逐列决策过程](images/wc114_q3_walkthrough.svg)

对示例 1 的 `strs = ["ca","bb","ac"]`，初始 `sorted = [false, false]`：

| 列 c | 第 0 对（ca / bb） | 第 1 对（bb / ac） | 判定 | 动作 |
|------|--------------------|--------------------|------|------|
| 0 | c(2) > b(1)，未区分 → 逆序 | b(1) > a(0)，未区分 → 逆序 | bad | 删除，ans = 1 |
| 1 | a(0) < b(1)，未区分 → 有序 | b(1) < c(2)，未区分 → 有序 | 保留 | sorted = [true, true] |

扫描结束，`ans = 1`，与示例输出一致。再看示例 3：三列上分别有 `z>w`、`y>v`、`x>u`，且每列处理时对应行对都还没被区分，于是三列全删，得 3。

## 4. 算法细节

1. **`sorted` 的语义要精确**：它表示"这一对相邻行在已保留的列中已经分出大小且方向正确"，而不是"当前列上这两行字符不同"。
2. **先判 bad 再更新**：一列一旦判定需要删除，就**不能**更新 `sorted`（这些字符最终不会出现在结果里）。
3. **提前 break**：发现逆序立即跳出内层循环；此时 `bad = true`，该列不会有任何 `sorted` 更新。
4. **`n == 1` 时不越界**：`vector<bool> sorted(0)`，两层循环内层都不执行，返回 0（单个字符串天然有序）。
5. **空间只需 $O(n)$**：不需要真的构造删除后的字符串；所有判断都在原串上完成。
6. **保留列不会"变坏"**：如果某列对所有未区分行对都没有逆序，保留它在数学上只会增加约束信息（可能多确定几对），绝不会破坏已确定的顺序。
7. **不要按"列本身是否非降"来删**：列内部可以随意"乱"，真正约束的是**相邻两行**在每个列上的比较关系（示例 2 第 1 列 `c,b,a` 是降序但无需删除）。
8. **行内字符不要求有序**：与「删列造序 III」区分清楚，别把约束写成了每行内部非降。

## 5. 正确性证明

**记号**：设列全集 $C = \{0,1,\dots,m-1\}$。给定保留列集合 $K \subseteq C$，把 `strs[i]` 限制在 $K$ 上得到的字符串记为 $s_i^K$（保持列的原相对顺序）。称 $K$ **合法**，若对一切 $i$ 有 $s_i^K \le s_{i+1}^K$。对第 $i$ 对相邻行，若它们在 $K$ 中某列不同，则定义其**首个分歧列** $f_K(i)$ 为 $K$ 中最小的满足 `strs[i][c] != strs[i+1][c]` 的 $c$；称 $i$ 被 $K$ **区分**，若 $f_K(i)$ 存在，且此时 $s_i^K < s_{i+1}^K$ 当且仅当 `strs[i][f] < strs[i+1][f]`。记 $\mathrm{res}(K) = \{i : f_K(i) \text{ 存在且方向为严格小于}\}$。

**引理 1（首个分歧列定序）**：$s_i^K \le s_{i+1}^K$ 当且仅当"$f_K(i)$ 不存在"或"$f_K(i)$ 存在且 `strs[i][f_K(i)] < strs[i+1][f_K(i)]`"。

**证明**：这是字典序的定义：两串在首个不同位置比较字符；若所有列字符都相同则两串相等。∎

**引理 2（已区分行对免疫）**：若 $i \in \mathrm{res}(K)$，则对任意 $K' \supseteq K$ 仍有 $i \in \mathrm{res}(K')$，即 $s_i^{K'} < s_{i+1}^{K'}$。

**证明**：$f_K(i)$ 是 $K$ 中的最小分歧列，它也在 $K'$ 中且仍是 $K'$ 中的最小分歧列（$K' \setminus K$ 中的列都大于 $f_K(i)$ 不可能更小；$K'$ 中比 $f_K(i)$ 小的列若属于 $K$ 则与 $f_K$ 的最小性矛盾，而它们若不可能属于 $K$ 就无所谓）。严格来说：$f_{K'}(i) = \min\{c \in K' : \text{字符不同}\}$，由于 $K \subseteq K'$ 且 $f_K(i)$ 是 $K$ 中最小者，$f_{K'}(i) = f_K(i)$ 或更小，但比它小的列只能在 $K$ 中取（已排除），故相等。方向同为 `<`，所以 $i \in \mathrm{res}(K')$。∎

**引理 3（贪心过程的不变量）**：设 $G_c$ 为贪心处理完前 $c$ 列（下标 $0..c-1$）后保留的列集合，$G_0 = \varnothing$。则对任何合法集合 $S \subseteq C$，令 $S_c = S \cap \{0,\dots,c-1\}$，有

$$\lvert G_c \rvert \ge \lvert S_c \rvert \quad\text{且}\quad \mathrm{res}(S_c) \subseteq \mathrm{res}(G_c).$$

**证明**：对 $c$ 归纳。

- **基础**：$c = 0$ 时两边都是空集，成立。
- **归纳步**：设 $c$ 时成立，考虑第 $c$ 列。
  - **情形 A：贪心保留列 $c$。** 则 $G_{c+1} = G_c \cup \{c\}$，$\lvert G_{c+1}\rvert = \lvert G_c\rvert + 1 \ge \lvert S_c\rvert + 1 \ge \lvert S_{c+1}\rvert$。若 $i \in \mathrm{res}(S_{c+1})$：其首个分歧列 $f_{S_{c+1}}(i)$ 若 $< c$，则 $i \in \mathrm{res}(S_c) \subseteq \mathrm{res}(G_c) \subseteq \mathrm{res}(G_{c+1})$；若 $= c$，则 `strs[i][c] < strs[i+1][c]`，而贪心保留列 $c$ 时会把所有在列 $c$ 上严格小于的未区分行对标记为已区分，故 $i \in \mathrm{res}(G_{c+1})$。综上 $\mathrm{res}(S_{c+1}) \subseteq \mathrm{res}(G_{c+1})$。
  - **情形 B：贪心删除列 $c$（存在未区分行对 $j$ 使 `strs[j][c] > strs[j+1][c]`）。** 先说明任何合法 $S$ 都**不能**包含列 $c$：反设 $c \in S$。由于 $j \notin \mathrm{res}(G_c)$，由归纳假设 $\mathrm{res}(S_c) \subseteq \mathrm{res}(G_c)$ 知 $j \notin \mathrm{res}(S_c)$，即 $j$ 在 $S_c$ 上尚未被区分。于是 $j$ 在 $S_{c+1} = S_c \cup \{c\}$ 上的首个分歧列恰为 $c$（$S_c$ 中所有列上两行都相等），而该列方向为 `>`，由引理 1 得 $s_j^{S_{c+1}} > s_{j+1}^{S_{c+1}}$，与 $S$ 合法矛盾。故 $c \notin S$，于是 $S_{c+1} = S_c$，$G_{c+1} = G_c$，两个不等式由归纳假设直接成立。

归纳完成。∎

**定理**：贪心算法输出的删除列数等于最小可能删除列数。

**证明**：令 $c = m$。由引理 3，对任意合法 $S$ 有 $\lvert G_m\rvert \ge \lvert S_m\rvert = \lvert S\rvert$，即贪心保留的列数不少于任何合法方案的保留列数，等价地，贪心删除的列数 $m - \lvert G_m\rvert$ 不超过任何合法方案的删除列数。

还需说明 $G_m$ 本身合法。对任意 $i$：若 $i \in \mathrm{res}(G_m)$，则 $s_i^{G_m} < s_{i+1}^{G_m}$；若 $i \notin \mathrm{res}(G_m)$，则 $i$ 在 $G_m$ 的所有列上两行字符都相等（否则其首个分歧列方向必为 `<`，因为贪心从不保留会导致未区分行对逆序的列，若方向为 `>` 则该行对在那一列就是未区分的逆序，矛盾），两串相等，仍有 $s_i^{G_m} \le s_{i+1}^{G_m}$。故 $G_m$ 合法，贪心的删除方案可行且列数最小。∎

## 6. 复杂度分析

- **时间**：$O(nm)$。外层 $m$ 列，每列最多两次遍历 $n-1$ 个相邻行对，共 $O(nm)$ 次字符比较；$n, m \le 100$ 时约 $2\times10^4$ 次操作。
- **空间**：$O(n)$，仅需长度为 $n-1$ 的布尔数组；不构造删除后的字符串。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <string>

using namespace std;

class Solution {
public:
    int minDeletionSize(vector<string>& strs) {
        int n = strs.size(), m = strs[0].size();
        vector<bool> sorted(n > 0 ? n - 1 : 0, false);   // 第 i 对相邻行是否已被严格区分
        int ans = 0;

        for (int c = 0; c < m; c++) {
            bool bad = false;
            for (int i = 0; i + 1 < n && !bad; i++) {
                if (!sorted[i] && strs[i][c] > strs[i + 1][c]) bad = true;   // 未区分行对出现逆序
            }
            if (bad) {          // 该列必须删除，且不更新任何标记
                ans++;
                continue;
            }
            for (int i = 0; i + 1 < n; i++) {
                if (!sorted[i] && strs[i][c] < strs[i + 1][c]) sorted[i] = true;
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def minDeletionSize(self, strs: list[str]) -> int:
        n, m = len(strs), len(strs[0])
        sorted_pair = [False] * max(n - 1, 0)     # 第 i 对相邻行是否已被严格区分
        ans = 0

        for c in range(m):
            bad = any(
                not sorted_pair[i] and strs[i][c] > strs[i + 1][c]
                for i in range(n - 1)
            )
            if bad:                 # 该列必须删除，且不更新任何标记
                ans += 1
                continue
            for i in range(n - 1):
                if not sorted_pair[i] and strs[i][c] < strs[i + 1][c]:
                    sorted_pair[i] = True

        return ans
```

## 8. 边界情况与易错点

1. **删列后不能再更新标记**：这一列最终不存在于结果中，若误更新会让后续列少判逆序，答案偏小。
2. **已区分行对的逆序无害**：示例 2 第 1 列 `c,b,a` 全逆序也无需删除，因为第 0 列已经把两对行都区分开了。忘记检查 `sorted[i]` 会多删列。
3. **`n == 1`**：没有相邻行对，答案恒为 0；注意 `vector<bool>` 与 `[False] * 0` 的长度处理，别让 `n - 1` 变成负数。
4. **相邻行相同**：某列两行字符相等时既不算逆序也不标记区分，`sorted[i]` 保持 false，交给后面的列决定。
5. **全部行完全相同**：任何列都不产生逆序，答案为 0（删除后仍相等，非降合法）。
6. **不要把约束写成"每行内部有序"**：那是「删列造序 III」（#960）的要求，本题只约束行与行之间。
7. **不要按字母表顺序"重排"列**：删除是**保持原列序**的，首个分歧列仍是原序下最靠左的那个，这是所有比较的前提。
8. **提前 break 的边界**：`for (int i = 0; i + 1 < n && !bad; i++)` 中 `i + 1 < n` 与 `!bad` 缺一不可，否则 `n == 1` 时越界或漏判。
