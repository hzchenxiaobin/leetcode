# LeetCode 最长相邻绝对差递减子序列 题解

## 1. 题目概述

- **标题 / 题号**：最长相邻绝对差递减子序列（#3409，medium）
- **链接**：https://leetcode.cn/problems/longest-subsequence-with-decreasing-adjacent-difference/
- **来源**：LeetCode 第 147 场双周赛 Q3
- **难度**：中等
- **标签**：数组、动态规划

**题意**：给定整数数组 `nums`，求一个**最长子序列** `seq`，使得相邻元素的绝对差构成**非递增**序列：

$$|\text{seq}_1 - \text{seq}_0| \ge |\text{seq}_2 - \text{seq}_1| \ge \cdots \ge |\text{seq}_m - \text{seq}_{m-1}|$$

返回该子序列的长度（子序列保持原数组相对顺序，不要求连续）。

**约束**：

- $2 \le \text{nums.length} \le 10^4$
- $1 \le \text{nums}[i] \le 300$

值域只有 $300$ 是本题的题眼：它把"差值"这个维度的状态数压到了常数级。

## 2. 示例

**示例 1**

```text
输入：nums = [16,6,3]
输出：3
解释：最长子序列 [16,6,3]，相邻绝对差 [10,3]，10 ≥ 3 非递增 ✓
```

**示例 2**

```text
输入：nums = [6,5,3,4,2,1]
输出：4
解释：最长子序列 [6,4,2,1]，相邻绝对差 [2,2,1]（注意 3 被跳过）
```

**示例 3**

```text
输入：nums = [10,20,10,19,10,20]
输出：5
解释：最长子序列 [10,20,10,19,10]，相邻绝对差 [10,10,9,9]
```

## 3. 解题思路

### 3.1 暴力思路

最直接的 DP：令 $g[i][d]$ 表示"以下标 $i$ 结尾、末段差值恰为 $d$"的最长长度，转移枚举前驱下标：

$$g[i][d] = 1 + \max_{j < i,\ |a_i - a_j| = d} \ \max_{d' \ge d} g[j][d']$$

状态数 $O(n \cdot 300)$，每个状态要扫 $j$，总复杂度 $O(n^2 \cdot 300) = O(n^2)$ 量级（$n = 10^4$ 时 $10^8$），常数还不小；更要命的是"每个 $j$ 只贡献一个差值"，为每个 $(i, d)$ 扫一遍 $j$ 完全是浪费。

### 3.2 核心观察：按"值"建状态

![状态怎么设计：值域只有 300，就按"值"而不是"下标"做 DP](images/bw147_q3_state_design.svg)

一条合法子序列能否接上新元素 $x$，**只取决于它末端的值 $u$ 和末段差值 $d'$**，与它内部的走向无关。于是可以把状态里的"下标"换成"值"：

$$f[v][d] = \text{以值 } v \text{ 结尾、末段差值恰为 } d \text{ 的最长子序列长度}$$

状态总数只有 $300 \times 301$。为了把转移里的 $\max_{d' \ge d}$ 也消掉，再对每个 $v$ 维护**后缀最大值**：

$$\text{suf}[v][d] = \max\Bigl(1,\ \max_{d' \ge d} f[v][d']\Bigr)$$

其中的 $1$ 是**基线**：长度为 1 的子序列不存在"上一次差值"，可以接任意 $d$，所以"最优长度至少是 1"。

于是转移变成 $O(1)$：

$$f[x][d] \mathrel{\text{←}} \max\bigl(f[x][d],\ 1 + \text{suf}[u][d]\bigr),\qquad d = |x - u|$$

### 3.3 算法流程

![转移：把新元素 x 接在「以 u 结尾、上次差值 ≥ |x−u|」之后](images/bw147_q3_transition.svg)

```text
1. f[1..300][0..300] = 0，suf[v][d] = 1（基线），ans = 1
2. 按原数组顺序枚举 x = nums[i]：
   a. 阶段一：对每个 u = 1..300，d = |x-u|，cand[d] = max(cand[d], suf[u][d] + 1)
   b. 阶段二：f[x][d] = max(f[x][d], cand[d])；ans = max(ans, f[x][d])
   c. 重算 suf[x][·]：从 d = 300 递减到 0，suf[x][d] = max(1, f[x][d], suf[x][d+1])
3. 返回 ans
```

**为什么必须"两阶段"**：如果边算边写 `f[x]`，那么同一个元素 $x$（当下标 $i$）可能被自己续用 —— 例如 $u = x$ 时 $d = 0$，会读到本轮刚写入的 `suf[x][0]`，等价于把同一个元素用两次。先攒候选、再统一写回，就切断了自环。

### 3.4 示例演算

![示例演算：nums 为 10、20、10、19、10、20 时的逐元素走查](images/bw147_q3_example_walkthrough.svg)

| $i$ / $x$ | 候选 $u$（$d = \lvert x-u\rvert$） | 用到的 $\text{suf}$ | 写回 | ans |
|-----------|-----------------------------------|---------------------|------|-----|
| 0 / 10 | 无前驱 | — | — | 1 |
| 1 / 20 | 10（$d=10$） | $\text{suf}[10][10]=1$ | $f[20][10]=2$ | 2 |
| 2 / 10 | 20（$d=10$） | $\text{suf}[20][10]=2$ | $f[10][10]=3$ | 3 |
| 3 / 19 | 10（$d=9$）、20（$d=1$） | $\text{suf}[10][9]=3$ | $f[19][9]=4$ | 4 |
| 4 / 10 | 19（$d=9$） | $\text{suf}[19][9]=4$ | $f[10][9]=5$ | 5 |
| 5 / 20 | 19（$d=1$）、10（$d=10$） | $\text{suf}[19][1]=4$ | $f[20][1]=5$（无提升） | 5 |

$i=3$ 是关键一步：$19$ 与 $10$ 的差值 $9 \le 10$，于是可以接在"差值 10"的链后面，差值序列开始下降；$i=4$ 的 $10$ 又以 $9 \le 9$ 接上，链长达到 5。取出子序列 $[10, 20, 10, 19, 10]$，差值 $[10,10,9,9]$ 非递增。

## 4. 算法细节

1. **值域下标从 1 开始**：`nums[i] >= 1`，所以 $f$ 的第二维可以直接用 $d \in [0, 300]$，$d=0$ 表示"相邻两元素相等"。
2. **后缀最大值的重算范围**：只有 $x$ 这一行变了，因此只需重算 `suf[x][·]`（$O(300)$），不必碰其他行。
3. **$\text{suf}$ 的第三维**：为方便写 `suf[x][d+1]`，把数组开到 $301+1$，并把 `suf[v][301] = 0`。
4. **两阶段的候选数组**：因为固定 $x$ 后每个 $u$ 对应**唯一**的 $d$（$d = |x-u|$），候选数组长度只有 $301$；但注意不同的 $u$ 可能给出**相同**的 $d$（$u = x-d$ 与 $u = x+d$），所以要用 `max` 而不是直接赋值。
5. **答案的维护时机**：在写回 `f[x][d]` 之后立刻更新 `ans`，比最后扫全表更省事。
6. **为什么不需要滚动数组**：状态只有 $300 \times 301$ 个整数，直接开静态数组；C++ 用 `static` 避免每轮重新分配。

## 5. 正确性证明

**引理 1（状态完备）**：处理完前 $i$ 个元素后，对任意 $v, d$，$f[v][d]$ 等于"只使用 $a_0..a_i$ 且以值 $v$ 结尾、末段差值恰为 $d$"的最长子序列长度；若不存在这样的子序列，则 $f[v][d] = 0$。

**证明**：对 $i$ 归纳。$i = -1$ 时全为 0，成立。设已处理完前 $i-1$ 个元素。新的 $v$ 只可能来自 $a_i = x$：

- 任何以 $a_i = x$ 结尾、末段差值为 $d$ 的子序列，去掉 $x$ 后是以某个值 $u$（$|x - u| = d$）结尾、末段差值 $d' \ge d$ 的子序列（长度为 1 的"子序列"视为 $d' = +\infty$，总满足 $d' \ge d$）。由归纳假设，其长度 $\le 1 + \text{suf}[u][d]$，故不超过阶段一产生的候选。
- 反过来，阶段一的候选 $1 + \text{suf}[u][d]$ 都能对应地构造出合法子序列（在值 $u$ 的最优链后接上 $x$），因此写回后的 $f[x][d]$ 恰好是最大值。

其他值 $v \ne x$ 的 $f$ 行本轮不变，因为所有满足条件的子序列必须以下标 $i$ 结尾。∎

**引理 2（后缀最大值正确）**：重算后 $\text{suf}[v][d] = \max(1, \max_{d' \ge d} f[v][d'])$。

**证明**：重算从 $d = 300$ 递减到 $0$，递推式为 $\text{suf}[v][d] = \max(1, f[v][d], \text{suf}[v][d+1])$，而 $\text{suf}[v][301] = 0$。由归纳（对 $d$ 从大到小）即得结论。∎

**引理 3（无自续用）**：同一元素 $a_i$ 不会被同一条子序列使用两次。

**证明**：阶段一只读旧的 $\text{suf}$（本轮对 $f[x]$ 的修改发生在阶段二），且阶段二中写入的 $f[x][\cdot]$ 只在阶段三被读入 $\text{suf}[x][\cdot]$，两者都晚于候选计算。因此阶段一的所有候选都来自"仅使用 $a_0..a_{i-1}$"的子序列，接上 $a_i$ 后每个元素至多用一次。∎

**定理**：算法返回最长合法子序列的长度。

**证明**：由引理 1、2、3，算法结束时 $f[v][d]$ 覆盖了所有合法子序列按其末端状态分类的最大值，且每条被计入的长度都对应构造得出的合法子序列。于是 $\max_{v,d} f[v][d]$（算法中维护的 `ans`）即所求；又 $n \ge 2$ 时任意两个元素构成长度 2 的合法子序列，故 `ans` 的初值 1 不会漏掉空集情形。∎

## 6. 复杂度分析

- **时间**：设值域 $V = 300$。每个元素做三项工作：枚举 $u \in [1, V]$ 产生候选（$O(V)$）、写回 $O(V)$ 个格子（$O(V)$）、重算一行后缀最大值（$O(V)$）。总时间 $O(nV) = O(300n)$，$n = 10^4$ 时约 $9 \times 10^6$ 次基本运算。
- **空间**：$f$ 与 $\text{suf}$ 各 $O(V^2) = 9 \times 10^4$ 个整数，加上长度为 $V+1$ 的候选数组；与 $n$ 无关，总计 $O(V^2)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int longestSubsequence(vector<int>& nums) {
        const int V = 300;
        // f[v][d]：以值 v 结尾、最后一段相邻绝对差恰为 d 的最长子序列长度
        // suf[v][d]：max(1, max_{d' >= d} f[v][d'])，即"上一步差值至少为 d"时的最优长度
        static int f[V + 1][V + 1];
        static int suf[V + 1][V + 2];
        for (int v = 0; v <= V; v++) {
            for (int d = 0; d <= V; d++) f[v][d] = 0;
            for (int d = 0; d <= V + 1; d++) suf[v][d] = 0;
        }
        int best[V + 1];
        int ans = 1;
        for (int x : nums) {
            for (int d = 0; d <= V; d++) best[d] = 0;
            for (int u = 1; u <= V; u++) {
                int d = x > u ? x - u : u - x;      // |x - u|
                int cand = suf[u][d] + 1;           // 接到"以 u 结尾、上次差值 >= d"之后
                if (cand > best[d]) best[d] = cand;
            }
            // 两阶段：先算完本元素的所有候选，再写回 row x，避免同一元素被自己续用
            for (int d = 0; d <= V; d++)
                if (best[d] > f[x][d]) f[x][d] = best[d];
            suf[x][V + 1] = 0;
            for (int d = V; d >= 0; d--) {
                int s = f[x][d];
                if (suf[x][d + 1] > s) s = suf[x][d + 1];
                suf[x][d] = s > 1 ? s : 1;          // 基线 1：长度 1 的子序列没有差值约束
                if (f[x][d] > ans) ans = f[x][d];
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def longestSubsequence(self, nums: list) -> int:
        V = 300
        # f[v][d]：以值 v 结尾、最后一段相邻绝对差恰为 d 的最长子序列长度
        f = [[0] * (V + 1) for _ in range(V + 1)]
        # suf[v][d]：max(1, max_{d' >= d} f[v][d'])
        suf = [[1] * (V + 2) for _ in range(V + 1)]
        ans = 1
        seen = set()
        for x in nums:
            nxt = {}                        # 本元素产生的候选，先攒后写
            for u in seen:
                d = x - u if x > u else u - x
                cand = suf[u][d] + 1
                if cand > nxt.get(d, 0):
                    nxt[d] = cand
            for u in seen:
                d = x - u if x > u else u - x
                if nxt[d] > f[x][d]:
                    f[x][d] = nxt[d]
            seen.add(x)
            row, srow = f[x], suf[x]
            srow[V + 1] = 0
            for d in range(V, -1, -1):
                s = srow[d + 1]
                if row[d] > s:
                    s = row[d]
                srow[d] = s if s > 1 else 1
            m = max(row)
            if m > ans:
                ans = m
        return ans
```

> ⚠️ Python 版本把 $u$ 的枚举换成"目前出现过的值" `seen`（已出现的值才可能作为前驱），最坏情况仍是 300 个值，复杂度不变，常数更小。

## 8. 边界情况与易错点

1. **同一元素被自己续用**：把"算候选"和"写回"混在一起写，会在 $u = x$（$d = 0$）时读到本轮刚写入的值，答案偏大。必须两阶段。
2. **基线漏了 1**：$\text{suf}$ 只取 $\max_{d' \ge d} f$，则长度为 2 的子序列都构造不出来。基线 1 不可省。
3. **并列的 $d$**：$u = x - d$ 和 $u = x + d$ 给出同一个 $d$，候选要用 `max` 合并。
4. **$d = 0$ 的合法性**：相邻元素相等时差值为 0，属合法且最"宽松"（后续任意非负差值都满足 $\le 0$ 的只有 0 本身，注意方向：$d' \ge d$ 要求 $d' \ge 0$，恒成立）。
5. **答案下界**：$n \ge 2$，答案至少 2；初值取 1 也能被正确覆盖，但若数组长度为 1（数据范围不含）时返回 1 才正确。
6. **`suf` 的越界**：重算时要用到 `suf[x][d+1]`，需要把第二维开成 $302$ 并把 `suf[v][301] = 0`。
7. **静态数组清零**：C++ 用 `static` 时若多次调用同一函数（多测），必须显式清零，否则残留上一组数据。
