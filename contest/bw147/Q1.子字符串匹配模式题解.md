# LeetCode 子字符串匹配模式 题解

## 1. 题目概述

- **标题 / 题号**：子字符串匹配模式（#3407，easy）
- **链接**：https://leetcode.cn/problems/substring-matching-pattern/
- **来源**：LeetCode 第 147 场双周赛 Q1
- **难度**：简单
- **标签**：字符串、字符串匹配

**题意**：给定字符串 $s$ 与模式串 $p$，其中 $p$ **恰好包含一个** `'*'`。`'*'` 可以替换成任意长度（含 0）的字符串。问是否存在 $s$ 的某个**子字符串**能由 $p$ 这样替换得到。

**约束**：

- $1 \le |s| \le 50$
- $1 \le |p| \le 50$
- $s$ 只含小写英文字母
- $p$ 只含小写英文字母与**一个** `'*'`

## 2. 示例

**示例 1**

```text
输入：s = "leetcode", p = "ee*e"
输出：true
解释：'*' 换成 "tcod"，子字符串 "eetcode" = s[1..7] 匹配模式串。
```

**示例 2**

```text
输入：s = "car", p = "c*v"
输出：false
解释：以 'c' 开头的子串只有 "c"、"ca"、"car"，末尾都凑不出 'v'，
      找不到任何匹配的子字符串。
```

**示例 3**

```text
输入：s = "luck", p = "u*"
输出：true
解释：'*' 取空串时子串为 "u"；取 "c" 得 "uc"；取 "ck" 得 "uck"。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的做法：枚举 $s$ 的所有子串（$O(|s|^2)$ 个），对每个子串枚举 `'*'` 替换出的长度（$O(|s|)$ 种），再逐字符比对模式 —— 总复杂度 $O(|s|^3 \cdot |p|)$。$|s| \le 50$ 时能过，但完全没有利用"模式串只有一个星号"这个强条件。

### 3.2 核心观察：星号把模式串切成两段

![子字符串匹配：在 '*' 处把模式串切成两段](images/bw147_q1_split_and_search.svg)

设 `'*'` 在 $p$ 中的位置为 $k$，令

$$\text{left} = p[0..k), \qquad \text{right} = p(k..|p|)$$

那么"$p$ 能变成 $s$ 的某子串"等价于：存在下标 $i \le j$，使得

$$s[i..i+|\text{left}|) = \text{left},\qquad s[j..j+|\text{right}|) = \text{right},\qquad i + |\text{left}| \le j$$

中间那块 $s[i+|\text{left}| .. j)$ 就是星号替换出来的任意串（可以为空）。注意这个条件**只要求两段各自出现、且左段结束不晚于右段开始**。

### 3.3 算法流程

![算法流程：切分 → 两次查找 → 比较先后顺序](images/bw147_q1_algorithm_flow.svg)

```text
1. k = p.find('*')；left = p[0..k)，right = p(k..]
2. i = s.find(left)                    # left 的最左出现
   若不存在 → false
3. j = s.find(right, i + |left|)       # 从 left 之后开始找 right
   若不存在 → false
4. 否则 → true
```

**为什么取"最左的 left + 其后最早的 right"是最优的**：left 出现得越靠左，留给 right 的空间就越大；在固定的 $i$ 下，right 出现得越早越容易成功。因此只要存在任意一组 $(i, j)$，就必然存在"left 最左出现 + 其后最早的 right"这一组。

### 3.4 示例演算

对示例 1 的 `s = "leetcode"`、`p = "ee*e"`：

| 步骤 | 结果 |
|------|------|
| 切分 | `left = "ee"`，`right = "e"` |
| 找 left | `s.find("ee") = 1`，占 $s[1..2]$ |
| 找 right | 从 $1+2=3$ 起找 `"e"`，命中下标 $7$，且 $3 \le 7$ |
| 结论 | 存在，返回 `true` |

示例 2 的 `s = "car"`、`p = "c*v"`：`left = "c"` 在 $0$ 处出现，但从下标 $1$ 起再也找不到 `"v"`，返回 `false`。示例 3 的 `p = "u*"`：`right` 为空串，`find` 从 $i+1$ 起找空串必然立即命中，返回 `true`。

## 4. 算法细节

1. **切分方式**：C++ 用 `p.find('*')` 得下标后 `substr`；Python 直接 `p.split('*')` 解包成两段，天然处理空段。
2. **第二段必须带起始位置**：`s.find(right, i + left.size())`。若写成 `s.find(right)`，会漏掉"right 出现在 left 之前"的非法情形 —— 这是本题唯一的易错点。
3. **空串语义**：`find("")` 返回起始位置（不会返回 `npos`），正好符合"星号匹配空串"的语义，无需特判。
4. **不需要 KMP**：$|s|, |p| \le 50$，标准库的线性查找足够；即便 $|s|$ 放大到 $10^5$，最优解仍是同样的两次匹配，只是可换成 KMP/Z 函数。

## 5. 正确性证明

**引理 1**：若存在下标 $i \le j$ 使 $i + |\text{left}| \le j$ 且两段分别匹配，则 $p$ 可变成 $s$ 的子串 $s[i..j+|\text{right}|)$。

**证明**：把 $p$ 中 `'*'` 替换为 $s[i+|\text{left}| .. j)$（长度 $j - i - |\text{left}| \ge 0$），得到的字符串正是 $s[i..j+|\text{right}|)$，它是 $s$ 的子串。∎

**引理 2**：若 $p$ 可变成 $s$ 的某个子串，则令 $i_0$ 为 left 的最左出现位置、$j_0$ 为从 $i_0 + |\text{left}|$ 起 right 的最早出现位置，必有 $j_0$ 存在且 $i_0 + |\text{left}| \le j_0$。

**证明**：由引理 1 的逆可知存在一组 $(i, j)$ 满足条件，故 left 至少在 $i$ 处出现，$i_0 \le i$。因为 right 在 $j \ge i + |\text{left}| \ge i_0 + |\text{left}|$ 处出现，而 $j_0$ 是从 $i_0 + |\text{left}|$ 起 right 的最早出现，故 $j_0$ 存在且 $j_0 \le j$，特别地 $j_0 \ge i_0 + |\text{left}|$。∎

**定理**：算法返回 `true` 当且仅当 $p$ 可变成 $s$ 的某子串。

**证明**：算法返回 `true` 时，取 $(i_0, j_0)$ 由引理 1 即得可行性；算法返回 `false` 时，由引理 2 的逆否命题，不存在任何满足条件的 $(i, j)$，由引理 1 的逆知不可行。∎

## 6. 复杂度分析

- **时间**：$O(|s| \cdot |p|)$ 的最坏界来自两次朴素 `find`（各 $O(|s| \cdot |\text{left}|)$、$O(|s| \cdot |\text{right}|)$）；在 $|s| \le 50$ 的约束下即 $O(|s|^2)$，可视为 $O(1)$ 级别。用 KMP 可降到 $O(|s| + |p|)$。
- **空间**：$O(|p|)$，只存两段子串（Python 的切片最多 $O(|p|)$）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool hasMatch(string s, string p) {
        size_t star = p.find('*');
        string left = p.substr(0, star);          // '*' 左边
        string right = p.substr(star + 1);        // '*' 右边
        size_t i = s.find(left);                  // 最左出现的 left
        if (i == string::npos) return false;
        size_t from = i + left.size();            // right 只能在 left 之后
        return s.find(right, from) != string::npos;
    }
};
```

### Python

```python
class Solution:
    def hasMatch(self, s: str, p: str) -> bool:
        left, right = p.split('*')
        i = s.find(left)
        if i < 0:
            return False
        return s.find(right, i + len(left)) >= 0
```

## 8. 边界情况与易错点

1. **第二段忘了带起点**：`s.find(right)` 会让 `"ba*ab"` 这类"两段顺序反了"的输入误判为 `true`。
2. **星号在首/尾**：`p = "*abc"` 时 `left` 为空串，`i = 0`，退化为"right 是否为子串"；`p = "abc*"` 时 `right` 为空串，恒成功（只要 `left` 出现）。
3. **空串 `find` 的返回值**：C++ `string::find("")` 返回起始位置参数（可能等于 `size()`），Python `str.find("")` 返回起点，二者都不会返回"未找到"，不要画蛇添足写特判。
4. **模式串长度为 1**（只有星号）：两段皆空，答案必为 `true`。
5. **大小写与字符集**：题面限定小写字母，直接按字节比较即可，无需考虑编码。
