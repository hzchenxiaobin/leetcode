# LeetCode 删除所有值为某个元素后的最大子数组和 题解

## 1. 题目概述

- **标题 / 题号**：删除所有值为某个元素后的最大子数组和（#3410，hard）
- **链接**：https://leetcode.cn/problems/maximize-subarray-sum-after-removing-all-occurrences-of-one-element/
- **来源**：LeetCode 第 147 场双周赛 Q4
- **难度**：困难
- **标签**：线段树、数组、哈希表、分治、动态规划、前缀和

**题意**：给定整数数组 `nums`，你可以执行**至多一次**操作：选定数组中出现过的整数 $X$，把所有等于 $X$ 的元素删掉（要求剩下的数组**非空**）。求所有可能得到的数组中，**最大子数组和**的最大值。

**约束**：

- $1 \le \text{nums.length} \le 10^5$
- $-10^6 \le \text{nums}[i] \le 10^6$（答案需要用 64 位整数）

题目的两个陷阱：一是"至多一次"意味着**可以不删**；二是"删掉**所有** $X$"意味着 $X$ 在子数组之外的出现也会被删，但它们不影响被选中的那段子数组 —— 这正好给出下面的"段"视角。

## 2. 示例

**示例 1**

```text
输入：nums = [-3,2,-2,-1,3,-2,3]
输出：7
解释：删除所有 X = -2，得到 [-3,2,-1,3,3]，最大子数组为 2 + (-1) + 3 + 3 = 7。
      对照：X = -3 → [-3? 无] → 最优 3；X = -1 → 3；X = 3 → 2；不删除 → 4。
```

**示例 2**

```text
输入：nums = [1,2,3,4]
输出：10
解释：最优操作是什么都不删，整个数组和为 10。
```

## 3. 解题思路

### 3.1 暴力思路

枚举每个出现过的值 $X$，把数组里所有 $X$ 删掉后跑一遍 Kadane（$O(n)$）。最坏情况（所有元素互不相同、每次删一个）复杂度 $O(n \cdot D)$，其中 $D$ 是不同取值个数，即 $O(n^2) = 10^{10}$，必然超时。

瓶颈在于：对每个 $X$ 都**重新扫一遍整个数组**。而不同的 $X$ 之间，"数组"的差别只在于删掉了自己那些位置。

### 3.2 核心观察：删除 $X$ 就是把数组切成若干段

![删掉某个值后，数组被切成若干"段"](images/bw147_q4_delete_value_segments.svg)

设 $X$ 的出现位置为 $p_1 < p_2 < \cdots < p_m$，则删除 $X$ 后，数组由下面这些**段**拼接而成：

$$S_0 = [0, p_1), \quad S_1 = (p_1, p_2), \quad \dots, \quad S_m = (p_m, n)$$

（相邻两个 $X$ 挨着时段为空，直接跳过。）

删除后的任意子数组，在**原始数组**里就是一段区间 $[l, r]$ 去掉其中所有 $X$（其中至少含一个非 $X$ 元素否则删完为空）。这条区间相对于段有两种形态：

1. **完全落在一个段内部**：它不含任何 $X$，本来就是原数组的子数组 —— 交给"不删除"的普通 Kadane 处理；
2. **跨过至少一个被删的位置**：此时它必然形如

$$\underbrace{\text{$S_i$ 的一个非空后缀}}_{\text{suff}(S_i)} + \underbrace{S_{i+1} + \cdots + S_{j-1}}_{\text{中间整段全取}} + \underbrace{\text{$S_j$ 的一个非空前缀}}_{\text{pref}(S_j)}, \qquad i < j$$

> 💡 为什么首尾只能"部分取"？中间隔着被删掉的 $X$，为了让区间连续，夹在中间的段必须**整段**取，而首尾两段可以只取一部分（正是这部分让"整段背包"做法出错，见上图的反例 $[-3,7,-100,7,-3]$：整段拼接得 8，正确答案 14）。

于是问题变成：对每个 $X$，沿它的段序列做一次**"最大子数组和"的合并**。段内需要三个量：

$$\text{sum}(S) = P[R+1] - P[L], \qquad \text{pref}(S) = \max_{L < t \le R+1} P[t] - P[L], \qquad \text{suff}(S) = P[R+1] - \min_{L \le t \le R} P[t]$$

其中 $P$ 是前缀和。注意 $\text{pref}$ 与 $\text{suff}$ 都是**非空**的（否则会引入"空区间"，全负数数组会错）。

### 3.3 算法流程

![段合并 DP：两个状态扫一遍，段内前缀/后缀靠线段树 O(log n) 取](images/bw147_q4_segment_merge_dp.svg)

```text
1. 预处理前缀和 P[0..n]；建立线段树，支持查询 P 任意区间的 最小/最大值
2. ans = 普通 Kadane(nums)            # "不删除"分支
3. 按取值把下标分组：pos[v] = {出现位置}
4. 对每个 (v, ps)：
      curSuff = -∞, curBest = -∞, prev = -1
      for k = 0 .. len(ps):           # 第 k 段是 (ps[k-1], ps[k])
          L = prev + 1, R = (k < len(ps) ? ps[k] : n) - 1
          if L > R: continue          # 空段
          sum  = P[R+1] - P[L]
          pref = maxP(L+1, R+1) - P[L]
          suff = P[R+1] - minP(L, R)
          if curSuff 存在: curBest = max(curBest, curSuff + pref)
                           curSuff = max(suff, curSuff + sum)
          else:            curSuff = suff
          ans = max(ans, curBest)
5. 返回 ans
```

段内的 $\text{pref}$、$\text{suff}$ 用线段树在 $O(\log n)$ 内取到；总段数是 $\sum_v (\text{cnt}(v)+1) = n + D = O(n)$，所以整体 $O(n \log n)$。

### 3.4 示例演算

![示例演算：删除 X = −2 得到 7](images/bw147_q4_example_walkthrough.svg)

对 `nums = [-3,2,-2,-1,3,-2,3]`，$P = [0,-3,-1,-3,-4,-1,-3,0]$。$X = -2$ 出现在下标 2、5，切成三段：

| 段 | 区间 | sum | pref | suff |
|----|------|-----|------|------|
| $S_0$ | $[0,1] = [-3,2]$ | $-1$ | $-1$ | $2$ |
| $S_1$ | $[3,4] = [-1,3]$ | $2$ | $2$ | $3$ |
| $S_2$ | $[6,6] = [3]$ | $3$ | $3$ | $3$ |

| 处理到 | curBest 更新 | curSuff 更新 |
|--------|--------------|--------------|
| $S_0$ | —（第一段无旧后缀） | $2$ |
| $S_1$ | $\max(-\infty,\, 2+2)=4$ | $\max(3,\, 2+2)=4$ |
| $S_2$ | $\max(4,\, 4+3)=\mathbf{7}$ | $\max(3,\, 4+3)=7$ |

取出的区间是 $S_0$ 的后缀 $[2]$ + $S_1$ 整段 $[-1,3]$ + $S_2$ 整段 $[3]$，和 $7$。其余取值分别得到 $3, 3, -2, 2$，而不删除时 Kadane 得 $4$，故答案为 $\max(4,7)=7$。

## 4. 算法细节

1. **线段树只存两个量**：前缀和数组 $P$ 的区间最小、最大值。段内的 $\text{pref}$、$\text{suff}$ 都能由它们 $O(1)$ 拼出，无需维护经典的 `(sum, pref, suff, best)` 四元组。
2. **两个查询区间不同**：$\text{suff}$ 用 $[L, R]$ 的最小值（不含 $R+1$），$\text{pref}$ 用 $[L+1, R+1]$ 的最大值（不含 $L$）。写成同一个区间会漏掉/多算端点，导致"空区间"混入。
3. **非空语义**：$\text{pref}$ 与 $\text{suff}$ 都不与 $0$ 取 $\max$。一旦允许空串，`curSuff + pref` 就可能表示空区间，全负数数组会返回 0。
4. **空段必须跳过**：相邻两个 $X$ 之间没有元素，$\text{sum} = 0$、$\text{pref}$ 与 $\text{suff}$ 无定义；跳过即可，因为它们对合并没有任何贡献。
5. **用 `map` 分组**：`map<int, vector<int>>` 保证按值遍历；C++ 的 `unordered_map` 也可以（无需有序）。总元素数 $n$。
6. **64 位**：$n \le 10^5$、$|a_i| \le 10^6$，前缀和绝对值可达 $10^{11}$，所有累加量必须是 `long long`。
7. **"不删除"分支不能省**：全正数数组的最优解就是不删（示例 2），且答案还必须至少等于普通最大子数组和。

## 5. 正确性证明

**引理 1（区间 ↔ 段的对应）**：固定 $X$，设其出现位置把数组切成段 $S_0, \dots, S_m$。删除 $X$ 后数组的任一非空子数组，唯一对应原数组中一段区间 $[l, r]$，该区间不含任何"删除后为空"的部分，即 $[l, r]$ 里至少有一个非 $X$ 元素；其和在删除后数组中等于 $[l,r]$ 中所有非 $X$ 元素之和。

**证明**：删除 $X$ 相当于把 $X$ 位置的元素从数组中抹去，剩余元素保持原相对顺序。删除后数组的连续一段，对应原数组中"从某个非 $X$ 元素到某个非 $X$ 元素"的区间（抹去其中的 $X$），这正是 $[l, r]$ 去掉 $X$ 的结果。反之任一含非 $X$ 元素的区间 $[l,r]$ 抹去 $X$ 后仍是删除后数组的连续一段。映射双向唯一。∎

**引理 2（跨段形态）**：设 $[l, r]$ 含至少一个 $X$ 且至少一个非 $X$ 元素。若 $S_i$ 是包含 $l$ 的段、$S_j$ 是包含 $r$ 的段，则 $i \le j$，且

- 当 $i = j$ 时 $[l,r]$ 完全落在一段内，不含 $X$（与"含 $X$"矛盾），故必有 $i < j$；
- 此时 $[l, r]$ 覆盖 $S_i$ 的一个非空后缀、$S_{i+1}, \dots, S_{j-1}$ 的全部、$S_j$ 的一个非空前缀。

**证明**：$S_i, S_j$ 之间被 $X$ 的出现位置隔开，$[l,r]$ 连续覆盖这段区间，因此中间每个段都被完整覆盖；而 $l$ 在 $S_i$ 内、$r$ 在 $S_j$ 内，故首尾只取部分。$i<j$ 由"含 $X$ 而单段不含 $X$"得到。∎

**引理 3（合并 DP 正确）**：按顺序处理段 $S_0, \dots, S_m$ 时，处理完 $S_k$ 后

- $\text{curSuff}$ 等于"以 $S_k$ 末尾为右端点、起点在某个 $S_i$（$i \le k$）内"的区间的最大和；
- $\text{curBest}$ 等于"右端点落在 $S_0..S_k$ 之内且跨过至少一次段边界"的区间的最大和。

**证明**：对 $k$ 归纳。$k = 0$ 时 $\text{curSuff} = \text{suff}(S_0)$ 即定义；$\text{curBest}$ 无定义（无段边界）。设对 $k-1$ 成立。以 $S_k$ 末尾结尾的区间要么起点在 $S_k$ 内（和为 $\text{suff}(S_k)$），要么起点在某 $S_i$（$i < k$）内，此时该区间 = 某个以 $S_{k-1}$ 末尾结尾的区间 + 整个 $S_k$，最大和为 $\text{curSuff}_{k-1} + \text{sum}(S_k)$。两者取 $\max$ 即更新式。$\text{curBest}$ 的新增候选是"右端点落在 $S_k$ 且跨段"的区间，其最大值为 $\text{curSuff}_{k-1} + \text{pref}(S_k)$（跨段区间必覆盖 $S_k$ 的一个非空前缀）；与旧值取 $\max$ 即得。∎

**定理**：算法返回所有可能操作下最大子数组和的最大值。

**证明**：任一可行解属于两类：不含被删元素（由普通 Kadane 覆盖，因为不执行操作是允许的），或含被删元素。后者由引理 2 必为"某个 $X$ 的跨段形态"，由引理 3 被相应 $X$ 的 $\text{curBest}$ 覆盖。反之，$\text{curBest}$ 的每个取值都对应引理 2、3 构造出的真实区间，且这些区间在删除对应 $X$ 后非空（首尾段非空），故都是合法可达的。于是答案为所有可行解的最大值，算法取到它。∎

## 6. 复杂度分析

- **时间**：预处理前缀和 $O(n)$；建线段树 $O(n)$；普通 Kadane $O(n)$。按值分组的段合并：段总数 $= \sum_v (\text{cnt}(v) + 1) = n + D \le 2n$，每段两次线段树查询 $O(\log n)$，共 $O(n \log n)$。总计 $O(n \log n)$，$n = 10^5$ 时约 $3.4 \times 10^6$ 次操作。
- **空间**：线段树 $O(n)$（两个长度 $2^{\lceil \log(n+1)\rceil + 1}$ 的数组）、前缀和 $O(n)$、位置分组 $O(n)$，总计 $O(n)$。

## 7. 参考代码

### C++

```cpp
class Solution {
    int sz;
    vector<long long> mn, mx;

    void build(const vector<long long>& P, int n) {
        sz = 1;
        while (sz < n + 1) sz <<= 1;
        mn.assign(2 * sz, LLONG_MAX);
        mx.assign(2 * sz, LLONG_MIN);
        for (int i = 0; i <= n; i++) mn[sz + i] = mx[sz + i] = P[i];
        for (int i = sz - 1; i >= 1; i--) {
            mn[i] = min(mn[2 * i], mn[2 * i + 1]);
            mx[i] = max(mx[2 * i], mx[2 * i + 1]);
        }
    }

    // 前缀和数组 P 在闭区间 [l, r] 上的最小值
    long long queryMin(int l, int r) {
        long long res = LLONG_MAX;
        l += sz; r += sz;
        while (l <= r) {
            if (l & 1) { res = min(res, mn[l]); l++; }
            if (!(r & 1)) { res = min(res, mn[r]); r--; }
            l >>= 1; r >>= 1;
        }
        return res;
    }

    // 前缀和数组 P 在闭区间 [l, r] 上的最大值
    long long queryMax(int l, int r) {
        long long res = LLONG_MIN;
        l += sz; r += sz;
        while (l <= r) {
            if (l & 1) { res = max(res, mx[l]); l++; }
            if (!(r & 1)) { res = max(res, mx[r]); r--; }
            l >>= 1; r >>= 1;
        }
        return res;
    }

public:
    long long maxSubarraySum(vector<int>& nums) {
        int n = (int)nums.size();
        vector<long long> P(n + 1, 0);
        for (int i = 0; i < n; i++) P[i + 1] = P[i] + nums[i];

        // 1) 不删除任何元素的情况：普通最大子数组和
        long long ans = nums[0], cur = 0;
        for (int v : nums) { cur = max((long long)v, cur + v); ans = max(ans, cur); }

        // 2) 每种取值 x 单独考虑：把 x 从数组中挖掉后求最大子数组和
        build(P, n);
        map<int, vector<int>> pos;
        for (int i = 0; i < n; i++) pos[nums[i]].push_back(i);

        for (auto& [x, ps] : pos) {
            long long curSuff = LLONG_MIN / 4;   // 已处理的最右端"贴住段尾"的最优后缀
            long long curBest = LLONG_MIN / 4;
            int prev = -1;                        // 上一个 x 的下标
            for (int k = 0; k <= (int)ps.size(); k++) {
                int L = prev + 1;
                int R = (k < (int)ps.size() ? ps[k] : n) - 1;
                prev = (k < (int)ps.size() ? ps[k] : prev);
                if (L > R) continue;              // 空段（相邻两个 x）
                long long sum = P[R + 1] - P[L];
                long long loP = queryMin(L, R);         // 段内 P 最小值
                long long hiP = queryMax(L + 1, R + 1); // 段后一位起的 P 最大值
                long long suff = P[R + 1] - loP;        // 非空后缀最大和
                long long pref = hiP - P[L];            // 非空前缀最大和
                if (curSuff > LLONG_MIN / 8) {
                    curBest = max(curBest, curSuff + pref);
                    curSuff = max(suff, curSuff + sum);
                } else {
                    curSuff = suff;
                }
            }
            if (curBest > ans) ans = curBest;
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maxSubarraySum(self, nums: list) -> int:
        n = len(nums)
        # 前缀和
        P = [0] * (n + 1)
        s = 0
        for i, v in enumerate(nums):
            s += v
            P[i + 1] = s

        # 1) 不删除任何元素：普通最大子数组和
        ans = nums[0]
        cur = 0
        for v in nums:
            cur = v if cur < 0 else cur + v
            if cur > ans:
                ans = cur

        # 2) 线段树维护 P 的区间最小 / 最大值
        sz = 1
        while sz < n + 1:
            sz <<= 1
        INF = float('inf')
        mn = [INF] * (2 * sz)
        mx = [-INF] * (2 * sz)
        for i in range(n + 1):
            mn[sz + i] = mx[sz + i] = P[i]
        for i in range(sz - 1, 0, -1):
            a, b = mn[2 * i], mn[2 * i + 1]
            mn[i] = a if a < b else b
            a, b = mx[2 * i], mx[2 * i + 1]
            mx[i] = a if a > b else b

        def qmin(l, r):                      # P[l..r] 的最小值
            res = INF
            l += sz
            r += sz
            while l <= r:
                if l & 1:
                    if mn[l] < res: res = mn[l]
                    l += 1
                if not (r & 1):
                    if mn[r] < res: res = mn[r]
                    r -= 1
                l >>= 1
                r >>= 1
            return res

        def qmax(l, r):                      # P[l..r] 的最大值
            res = -INF
            l += sz
            r += sz
            while l <= r:
                if l & 1:
                    if mx[l] > res: res = mx[l]
                    l += 1
                if not (r & 1):
                    if mx[r] > res: res = mx[r]
                    r -= 1
                l >>= 1
                r >>= 1
            return res

        # 3) 按取值分组，逐段拼接（段 = 两个同值元素之间的部分）
        pos = {}
        for i, v in enumerate(nums):
            pos.setdefault(v, []).append(i)

        NEG = -10 ** 18
        for x, ps in pos.items():
            cur_suff = NEG
            cur_best = NEG
            prev = -1
            for k in range(len(ps) + 1):
                L = prev + 1
                R = (ps[k] if k < len(ps) else n) - 1
                if k < len(ps):
                    prev = ps[k]
                if L > R:
                    continue
                seg_sum = P[R + 1] - P[L]
                suff = P[R + 1] - qmin(L, R)      # 段内非空后缀最大和
                pref = qmax(L + 1, R + 1) - P[L]  # 段内非空前缀最大和
                if cur_suff != NEG:
                    if cur_suff + pref > cur_best:
                        cur_best = cur_suff + pref
                    t = cur_suff + seg_sum
                    cur_suff = suff if suff > t else t
                else:
                    cur_suff = suff
            if cur_best > ans:
                ans = cur_best
        return ans
```

## 8. 边界情况与易错点

1. **允许空的前缀/后缀**：这是本题最隐蔽的错法。$\text{pref}$ 与 $\text{suff}$ 一旦与 $0$ 取 $\max$，`curSuff + pref` 就可能是"空区间"，全负数数组会错误返回 0。
2. **查询区间端点**：$\text{suff}$ 需要 $\min P[L..R]$，$\text{pref}$ 需要 $\max P[L+1..R+1]$。用同一个端点会多算 $P[L]$ 或少算 $P[R+1]$，在"单元素段"上表现为返回值等于整个段的相反数。
3. **空段**：两个相邻的 $X$ 之间没有任何元素，此时 $L > R$，必须 `continue`。
4. **全部元素相同**：删掉该值后数组为空，不合法。此时所有段都是空的，该值分支无候选，答案由"不删除"的 Kadane 给出。
5. **$n = 1$**：只有"不删除"一种合法选择，返回唯一元素。
6. **"至多一次"**：不要强制删除；示例 2 的 `[1,2,3,4]` 最优就是全取。
7. **`long long` 与哨兵**：最小值/最大值的哨兵要用 `LLONG_MAX / 4` 这类安全值，避免 `curSuff + sum` 溢出；Python 无此问题，用 `-10**18` 即可。
8. **答案至少是普通最大子数组和**：任何时刻都要用"不删除"分支兜底，否则"删除反而变差"的情形会漏。

- [LeetCode 1191. K 次串联后最大子数组和](https://leetcode.cn/problems/k-concatenation-maximum-sum/)：另一类"拼接/跨越"型最大子数组问题。
- [LeetCode 1749. 任意子数组和的绝对值的最大值](https://leetcode.cn/problems/maximum-absolute-sum-of-any-subarray/)：前缀和极值的典型用法。

**延伸思考**：若允许删除**最多两种**取值，段结构会变成二维的"格"（被两种值共同切割），直接枚举 $O(D^2)$ 组合不可行，需要按第一种值分段后在段内再跑一遍"删第二种值"的 DP，复杂度 $O(n \log n \cdot D)$ 或引入分治。若把"最大子数组和"换成"最大子段积"，则需同时维护最大/最小两个量，且 0 不能删（删 0 与保 0 的语义不同），问题会更微妙。
