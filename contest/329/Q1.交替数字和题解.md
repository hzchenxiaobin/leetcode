# LeetCode 交替数字和 题解

## 1. 题目概述

- **标题 / 题号**：交替数字和（#2544，easy）
- **链接**：https://leetcode.cn/problems/alternating-digit-sum/
- **来源**：LeetCode 第 329 场周赛 Q1
- **难度**：简单
- **标签**：数学

**题意**：给定正整数 `n`，其十进制表示中**最高位**分配正号，其余每一位的符号都与相邻位**相反**，形成 `+ − + − …` 的交替模式。返回所有数字带上各自符号后的和。

**约束**：

- `1 <= n <= 10^9`（最多 10 位数字）

## 2. 示例

**示例 1**

```text
输入：n = 521
输出：4
解释：(+5) + (−2) + (+1) = 4
```

**示例 2**

```text
输入：n = 111
输出：1
解释：(+1) + (−1) + (+1) = 1
```

**示例 3**

```text
输入：n = 886996
输出：0
解释：(+8) + (−8) + (+6) + (−9) + (+9) + (−6) = 0
```

## 3. 解题思路

### 3.1 朴素模拟

题目本身就是对每一位数字做带符号求和，没有更"暴力"的枚举空间。唯一要解决的问题是：**如何确定每一位的符号**。逐位从 `n` 中剥离数字（`n % 10`、`n /= 10`）再配符号也可行，但从低位往高位处理时符号方向容易搞反（见 §8 易错点 4）。

### 3.2 核心观察：符号只取决于下标奇偶

![交替符号：下标奇偶决定正负](images/wc329_q1_alternating_signs.svg)

**关键观察**：从最高位起用 `i = 0, 1, 2, …` 编号，则第 `i` 位数字的符号恰为 $(−1)^i$：

- `i` 为**偶数**（最高位、第 3 位、第 5 位 …）→ **正号**
- `i` 为**奇数** → **负号**

符号与数字本身的大小、奇偶**完全无关**。因此把 `n` 转成字符串 `s` 后，一遍扫描按下标奇偶加减即可，等价于：

$$\text{ans} = \sum_{i=0}^{d-1} (-1)^i \cdot s[i] = (\text{偶位数字和}) - (\text{奇位数字和})$$

### 3.3 算法流程

![算法流程：转字符串一遍扫描](images/wc329_q1_algorithm_flow.svg)

1. `s = to_string(n)`，令 `ans = 0`。
2. 从 `i = 0` 遍历到 `len(s) − 1`：若 `i` 为偶数则 `ans += s[i]` 对应数字，否则 `ans -= s[i]` 对应数字。
3. 返回 `ans`。

### 3.4 示例演算

![示例演算：886996 逐位走查](images/wc329_q1_example_walkthrough.svg)

以 `n = 886996` 为例，逐步累加：`8 → 0 → 6 → −3 → 6 → 0`，最终答案 `0`，与示例一致 ✓。

## 4. 算法细节

1. **字符串化是关键一步**：`to_string(n)` / `str(n)` 直接得到从最高位到最低位的数字序列，下标 `0` 天然对应最高位，避免了自己反转数字的麻烦。
2. **符号交替的实现**：`sign = (i % 2 == 0) ? +1 : −1`，或维护一个 `sign` 变量每步取反。
3. **纯数学写法（可选）**：不断 `n % 10`、`n /= 10` 从低位开始，符号以 `+ − + − …` 起步；此时最高位拿到的符号是 $(−1)^{d-1}$（`d` 为位数）。**当 `d` 为偶数时整体符号与定义相反，需要把结果取反**。实现上可在循环结束后用 `sign` 的终值判断：见 §7 C++ 的第二种写法。
4. **数据范围很小**：`d ≤ 10`，`|ans| ≤ 9 × 10 = 90`，任何整型都不会溢出。

## 5. 正确性证明

**引理 1**：设 `n` 的十进制表示自最高位起为 $d_0, d_1, \dots, d_{k-1}$，则 $d_i$ 被分配的符号为 $(-1)^i$。

**证明**：对 $i$ 归纳。$i = 0$ 为最高有效位，题设分配正号 $(-1)^0 = +1$。设 $d_i$ 的符号为 $(-1)^i$，由"剩余每位上数字的符号都与其相邻数字相反"，$d_{i+1}$ 的符号为 $-(-1)^i = (-1)^{i+1}$。归纳成立。∎

**定理**：上述算法返回题目定义的交替数字和。

**证明**：字符串 `s` 的第 `i` 个字符恰为自最高位起的第 `i` 位数字，由引理 1 其符号应为 $(-1)^i$。算法对每位累加 $(-1)^i \cdot \text{digit}(s[i])$，与定义逐位一致，故总和即为所求。∎

## 6. 复杂度分析

- **时间复杂度**：$O(d)$，其中 $d$ 为 `n` 的位数，$d = O(\log_{10} n) \le 10$。转字符串与扫描各一遍。
- **空间复杂度**：$O(d)$，存储字符串。若用 §4 的纯数学取模写法可做到 $O(1)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int alternateDigitSum(int n) {
        string s = to_string(n);
        int ans = 0;
        for (int i = 0; i < (int)s.size(); i++) {
            ans += (i % 2 == 0 ? 1 : -1) * (s[i] - '0');
        }
        return ans;
    }
};
```

纯数学写法（$O(1)$ 空间，注意位数偶数时整体取反）：

```cpp
class Solution {
public:
    int alternateDigitSum(int n) {
        int ans = 0, sign = 1;
        while (n > 0) {
            ans += sign * (n % 10);
            sign = -sign;
            n /= 10;
        }
        // 循环结束时 sign = (-1)^d：
        // d 为奇数则最高位已配正号，直接返回；d 为偶数需整体取反
        return sign == 1 ? -ans : ans;
    }
};
```

### Python

```python
class Solution:
    def alternateDigitSum(self, n: int) -> int:
        return sum((-1) ** i * int(c) for i, c in enumerate(str(n)))
```

## 8. 边界情况与易错点

1. **个位数**（`1 <= n <= 9`）：唯一数字即最高位，答案就是 `n` 本身。
2. **结果可为负**：如 `n = 12` → `(+1) + (−2) = −1`。直接返回 `ans`，**不要**取绝对值或特判非负。
3. **符号与数字值的奇偶无关**：`886996` 中两个 `9` 符号相反，因为位置一奇一偶。只看下标。
4. **纯数学写法的方向陷阱**：从最低位起算时，最低位符号取决于**位数的奇偶**。位数为偶数（如 `n = 12`）时低位起步给 `+` 会让最高位拿到 `−`，必须整体取反，这是该写法最常见的 WA 点。
5. **`n = 10^9`**：字符串为 `"1000000000"`（10 位），答案 `1`，验证循环上界写法 `i < s.size()` 而非 `<=`。
