# LeetCode 执行逐位运算使字符串相等 题解

## 1. 题目概述

- **标题 / 题号**：执行逐位运算使字符串相等（#2546，medium）
- **链接**：https://leetcode.cn/problems/apply-bitwise-operations-to-make-strings-equal/
- **来源**：LeetCode 第 329 场周赛 Q3
- **难度**：中等
- **标签**：位运算、字符串、不变量

**题意**：给定两个长度均为 $n$ 的二元字符串 $s$ 和 $\text{target}$。一次操作可任选两个**不同**下标 $i, j$，**同时**把 $s_i$ 替换为 $s_i \mid s_j$、$s_j$ 替换为 $s_i \oplus s_j$（两式都读替换前的旧值）。问能否经过**任意多次**（含 0 次）操作把 $s$ 变成 $\text{target}$。

**约束**：

- $2 \le n \le 10^5$
- $s$ 和 $\text{target}$ 仅由 `0` / `1` 组成

> 💡 一句话建模：这是**操作可达性**问题——不要求给出操作序列，只问 $\text{target}$ 是否落在 $s$ 的可达集合里。此类题的正解几乎永远是「**找不变量划界 + 构造证明连通**」，而不是搜索。

## 2. 示例

**示例 1**

```text
输入：s = "1010", target = "0110"
输出：true
解释（官方给的操作序列）：
- op(2, 0)：(1,1)→(1,0)，s 变为 "0010"
- op(2, 1)：(1,0)→(1,1)，s 变为 "0110"
```

**示例 2**

```text
输入：s = "11", target = "00"
输出：false
解释：1 的个数可以减少，但永远减不到 0。
```

**补充示例（边界）**

```text
输入：s = "00", target = "00"   输出：true（本来就相等，0 次操作也算）
输入：s = "00", target = "01"   输出：false（全 0 串冻结，造不出 1）
输入：s = "10", target = "01"   输出：true（经 "11" 中转即可换位）
```

## 3. 解题思路

### 3.1 暴力思路：BFS 所有可达状态

最朴素的做法是把可达性当搜索问题：从 $s$ 出发，每步枚举全部 $O(n^2)$ 个操作 $(i, j)$，BFS 展开整个可达集合，最后查询 $\text{target}$ 是否在集合中。

问题在于状态数上界 $2^n$：$n = 30$ 时已超过 $10^9$，$n \le 10^5$ 时是天文数字，连一个状态都存不进超立方图。搜索彻底死路——题面把 $n$ 开到 $10^5$ 本身就是提示：**正解必须与状态数无关，只依赖某种「守恒 / 不变」性质**。

### 3.2 核心观察：操作只动两位，效果只有四种

![核心观察：一次操作在 (s_i, s_j) 两位上的四种效果](images/wc329_q3_operation_cases.svg)

操作同时改写两位、且两式都读**旧值**，因此整个效果**封闭在 $(s_i, s_j)$ 这两位之内**，不会产生连锁改写。枚举 $a = s_i$、$b = s_j$ 的全部取值：

| 操作前 $(a, b)$ | 操作后 $(a \mid b,\ a \oplus b)$ | 串中 1 的个数 |
|:---:|:---:|:---:|
| $(0, 0)$ | $(0, 0)$ | 不变（白干） |
| $(0, 1)$ | $(1, 1)$ | $+1$ |
| $(1, 0)$ | $(1, 1)$ | $+1$ |
| $(1, 1)$ | $(1, 0)$ | $-1$ |

由这张 case 表直接读出三个推论：

1. **全 0 串冻结**：对里没有 1，任何操作都是 $(0,0) \to (0,0)$——全 0 串永远变不出 1；
2. **1 永不消失**：只要串里有 1——操作的对含 1 时，$a \mid b = 1$ 必落在 $i$ 位；操作的对全 0 时，其它位置的 1 原地不动——操作后串里仍有 1；
3. **1 可复制、可删除**：恰含一个 1 的对整体变成 $(1,1)$（复制）；两个 1 的对使 XOR 位归 0（删除，且**删哪一位由 $j$ 指定**）。

> ⚠️ 最容易漏的是 $(1,1) \to (1,0)$ 这一行：误以为操作只会增加 1 的个数，就会错误地用「个数够不够」来判可达。实际上个数既能加也能减，**唯一不可逾越的只有「有没有 1」这条鸿沟**。

### 3.3 算法流程：全 1 串是枢纽，判据是「是否含 1」

![可达性地图与判定流程](images/wc329_q3_reachability_hub.svg)

把推论 1–3 拼起来，可以画出完整的**可达性地图**，状态空间被切成两个世界：

- **孤岛**：全 0 串自己（冻结态，哪也去不了；也只有它能等于全 0 的 $\text{target}$）；
- **大陆**：所有含 1 的串，内部**两两可达**——任意含 1 的 $s$ 先「扩散」成全 1 串，再从全 1 串「收缩」成任意含 1 的 $\text{target}$，**全 1 串是中转枢纽**。

于是算法只有一步：**判断 $s$ 与 $\text{target}$ 是否同时含 1（或同时不含 1）**：

```python
return ('1' in s) == ('1' in target)
```

### 3.4 示例演算

![示例 1 演算：1010 经全 1 枢纽中转到 0110](images/wc329_q3_example_walkthrough.svg)

以示例 1 为例（下标从 0 开始，`op(i, j)` 表示对 $(i, j)$ 执行一次操作），走「扩散 → 收缩」的枢纽路线：

| 阶段 | 操作 | 局部效果 | 串的变化 |
|:---:|:---:|:---:|:---:|
| 扩散 1 | `op(0, 1)` | $(1,0) \to (1,1)$ | `1010 → 1110` |
| 扩散 2 | `op(0, 3)` | $(1,0) \to (1,1)$ | `1110 → 1111` |
| 收缩 1 | `op(1, 0)` | $(1,1) \to (1,0)$ | `1111 → 0111` |
| 收缩 2 | `op(1, 3)` | $(1,1) \to (1,0)$ | `0111 → 0110` ✓ |

收缩阶段始终拿 $\text{target}$ 中为 1 的位置（这里是位 1）充当 OR 位 $i$：它每步都保住 1，同时把一个多余的 1 删成 0。对照示例 2：`11 → 00` 需要把 1 清空，与推论 2 矛盾，返回 `false`。

## 4. 算法细节

1. **「同时替换」的语义**：两式都读旧值，效果封闭在两位之内——这是 case 表完备性的前提。若第二式读新值，$(0,1)$ 型会得到 $(1,0)$，1 根本无法复制，整套分析都要重做。
2. **扩散构造（$s \to$ 全 1）**：只要串含 1 且还有 0，任取 1 位 $p$ 与 0 位 $q$ 执行 `op(p, q)`（或 `op(q, p)`，两种顺序都得到 $(1,1)$），$q$ 位变 1、$p$ 位保 1。归纳可得每个 0 都能被感染，至多 $n - 1$ 步铺满。
3. **收缩构造（全 1 $\to t$）**：取 $p$ 为任一 $t_p = 1$ 的位置（存在性由 $t$ 含 1 保证）。对每个 $t_j = 0$ 的位置 $j$ 依次执行 `op(p, j)`：从全 1 出发、每个位置只被当一次 XOR 槽，故执行时 $s_j$ 仍为 1，$(1,1) \to (1,0)$ 恰好删掉它；$s_p$ 恒为 1，其余位置从未被触碰、保持 1。至多 $n - 1$ 步得到 $t$。$n \ge 2$ 保证 $p \ne j$ 时操作合法。
4. **为什么个数与位置都无关**：1 既能复制又能删除，「把 1 从 $a$ 位搬到 $b$ 位」= 在 $b$ 位复制一个、再把 $a$ 位删掉。所以可达性里唯一的信息就是**存在性**——比较 `count` 或比较下标集合都是白费。
5. **实现**：一次扫描判存在性。C++ 用 `s.find('1') != string::npos`；Python 直接 `'1' in s`。

## 5. 正确性证明

**引理 1（零串冻结）**：若 $s$ 为全 0 串，则任意有限次操作后 $s$ 仍为全 0 串。

**证明**：对操作步数归纳。全 0 串上任取两位 $a = b = 0$，新值为 $(a \mid b,\ a \oplus b) = (0, 0)$，两位均不变，其余位未被触碰，故一步操作后仍为全 0 串。∎

**引理 2（非零不变量）**：若 $s$ 至少含一个 1，则任意有限次操作后 $s$ 仍至少含一个 1。

**证明**：考察一步操作 $(i, j)$。若 $(s_i, s_j)$ 中含 1，则新 $s_i = s_i \mid s_j = 1$；若 $(s_i, s_j) = (0, 0)$，则这两位不变，串中原有的某个 1（在其它位置）原样保持。两种情形操作后均至少含一个 1。∎

**引理 3（扩散）**：若 $s$ 至少含一个 1，则 $s$ 可经有限次操作变为全 1 串。

**证明**：对 0 的个数 $z$ 归纳。$z = 0$ 时即为全 1。$z \ge 1$ 时取 1 位 $p$、0 位 $q$，执行 `op(p, q)`：新 $s_p = 1 \mid 0 = 1$，新 $s_q = 1 \oplus 0 = 1$，0 的个数减少 1 且串中仍有 1。归纳完成，至多 $n - 1$ 步。∎

**引理 4（收缩）**：若 $s$ 为全 1 串，$t$ 为任意至少含一个 1 的同长串，则 $s$ 可变为 $t$。

**证明**：取 $p$ 使 $t_p = 1$。对每个满足 $t_j = 0$ 的 $j$（显然 $j \ne p$）依次执行 `op(p, j)`：由 $s$ 出发时全为 1，且每个位置至多被选为 XOR 槽一次、OR 槽只用在 $p$，故执行 `op(p, j)` 时恒有 $s_p = s_j = 1$，该步后 $s_p = 1 \mid 1 = 1$、$s_j = 1 \oplus 1 = 0$。全部执行完后，$t_j = 0$ 处为 0，$p$ 与其余 $t_k = 1$ 处（从未被触碰，保持 1）为 1，即 $s = t$。∎

**定理（判据）**：$s$ 可变为 $\text{target}$ $\iff$ 「$s$ 含 1」与「$\text{target}$ 含 1」同真或同假。

**证明**：
（充分性）若两者均不含 1，则 $s$ 与 $\text{target}$ 都是长度为 $n$ 的全 0 串，$s = \text{target}$，0 次操作即可。若两者均含 1：由引理 3，$s$ 先变为全 1 串；再由引理 4，全 1 串变为 $\text{target}$；两段操作序列拼接即得。
（必要性）若 $s$ 全 0 而 $\text{target}$ 含 1：由引理 1，$s$ 永远全 0，不可能等于含 1 的串。若 $s$ 含 1 而 $\text{target}$ 全 0：由引理 2，$s$ 永远含 1，不可能等于全 0 串。∎

> 💡 证明骨架是「**不变量划界 + 枢纽连通**」：引理 1/2 说明「是否含 1」是把状态空间切成两半的墙（必要性）；引理 3/4 说明墙的每一侧内部连通（充分性）。这是所有操作可达性题目的通用证明模板。

## 6. 复杂度分析

- **时间复杂度**：$O(n)$——各扫描一遍 $s$ 与 $\text{target}$ 判断字符 `1` 是否出现即可（`find` / `in` 底层都是线性扫描）。对比暴力 BFS 的 $O(2^n \cdot n^2)$，这正是「找不变量」路线的收益。
- **空间复杂度**：$O(1)$——只产生两个布尔值，不随 $n$ 增长；暴力 BFS 则需要 $O(2^n)$ 的状态空间。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool makeStringsEqual(string s, string target) {
        return (s.find('1') != string::npos) ==
               (target.find('1') != string::npos);
    }
};
```

> 💡 `string::find` 找不到时返回 `string::npos`，两个「是否存在」的布尔值直接 `==` 比较。

### Python

```python
class Solution:
    def makeStringsEqual(self, s: str, target: str) -> bool:
        return ('1' in s) == ('1' in target)
```

> 💡 `in` 对字符串做子串存在性判断，走的是 C 层优化扫描，比手写 Python 循环快得多。

## 8. 边界情况与易错点

1. **全 0 → 全 0**：`true`。「任意次」包含 0 次，本来就相等无需操作。
2. **全 0 → 含 1**：`false`。冻结态造不出 1；易错点是下意识地想「先造一个 1 出来」。
3. **含 1 → 全 0**：`false`（示例 2）。个数可减但**清不到 0**；易错点是用「个数够不够删」来判可达。
4. **$n = 2$ 的换位**：`"10" → "01"` 是 `true`（经 `"11"` 中转）；别误以为 1 的位置也被保持。
5. **比较个数而非存在性**：$s$ 与 $\text{target}$ 的 1 个数不同照样可达（先铺满再删）；判据只看**有没有**，不看**几个、在哪**。
6. **漏看 $(1,1) \to (1,0)$**：case 表四行缺一不可，这一行是「收缩」阶段的全部依据。
7. **「同时替换」读旧值**：理解 case 表必须用「两式同时读旧值」的语义；若先改 $s_i$ 再算 $s_j$，$(0,1)$ 型会变成 $(1,0)$，1 无法复制。
8. **BFS 冲动**：$2^n$ 状态空间连 $n = 40$ 都扛不住；看到 $n \le 10^5$ 应条件反射地找不变量。
