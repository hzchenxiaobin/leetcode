# LeetCode 统计相交区间对 I 题解

## 1. 题目概述

- **标题 / 题号**：统计相交区间对 I（#4056，easy）
- **链接**：https://leetcode.cn/problems/number-of-intersecting-interval-pairs-i/
- **来源**：LeetCode 第 520 场周赛 Q1
- **难度**：简单
- **标签**：区间、枚举、暴力

**题意**：给定 $n$ 个闭区间 `intervals[i] = [start_i, end_i]`，统计有多少下标对 $(i, j)$（$0 \le i < j < n$）满足两区间**相交**——即至少有一个公共点。**仅共享一个端点也算相交**。

**约束**：

- `2 <= intervals.length <= 100`
- `intervals[i] == [start_i, end_i]`
- `0 <= start_i <= end_i <= 100`

## 2. 示例

**示例 1**

```text
输入：intervals = [[1,2],[2,3],[3,4]]
输出：2
解释：[1,2] 与 [2,3] 在点 2 处相交；[2,3] 与 [3,4] 在点 3 处相交。
      [1,2] 与 [3,4] 没有公共点，不相交。
```

**示例 2**

```text
输入：intervals = [[1,5],[2,4],[3,6]]
输出：3
解释：三对区间两两相交，交集分别是 [2,4]、[3,5]、[3,4]。
```

**示例 3**

```text
输入：intervals = [[1,2],[3,4],[5,6]]
输出：0
解释：所有区间两两分离，不存在相交对。
```

## 3. 解题思路

### 3.1 朴素思路：暴力枚举所有下标对

$n \le 100$，下标对至多 $\binom{100}{2} = 4950$ 个，每对 $O(1)$ 判定相交，总运算量不足 $5 \times 10^3$——**直接两两枚举就是本题正解**，不需要任何排序或预处理。签到题的关键是把「从题面到代码」的路径压到最短，同时守住"闭区间端点也算相交"这一个坑。

### 3.2 核心观察：闭区间相交的 $O(1)$ 判定

两个闭区间 $[a, b]$ 与 $[c, d]$ 的交集为：

$$[a,b] \cap [c,d] = [\max(a,c),\ \min(b,d)]$$

当且仅当 $\max(a,c) \le \min(b,d)$ 时交集非空。因此：

$$[a,b] \text{ 与 } [c,d] \text{ 相交} \iff \max(a,c) \le \min(b,d)$$

> ⚠️ **关键**：因为是**闭区间**，端点属于区间。当 $\max(a,c) = \min(b,d)$ 时两区间恰好共享一个端点，**也算相交**。判定必须带等号，这是本题唯一的陷阱。

![闭区间相交判定的三种情况](images/wc520_q1_intersect_condition.svg)

三种情况对照：

- **重叠相交**：交集是一段非空区间（示例 2）
- **端点相接**：交集退化为一个点，等号成立（示例 1 的两对）
- **完全分离**：$\max(a,c) > \min(b,d)$，交集为空（示例 3）

### 3.3 算法流程

![O(n²) 暴力枚举流程](images/wc520_q1_brute_flow.svg)

1. 双重循环枚举下标对 $(i, j)$：外层 $i$ 从 $0$ 到 $n-1$，内层 $j$ 从 $i+1$ 到 $n-1$，保证每对恰好枚举一次
2. 对每对计算 $L = \max(\text{start}_i, \text{start}_j)$ 与 $R = \min(\text{end}_i, \text{end}_j)$
3. 若 $L \le R$ 则两区间相交，计数器加一
4. 循环结束后返回计数器

### 3.4 示例演算

以示例 1 `[[1,2],[2,3],[3,4]]` 为例逐对判定：

![示例 1 逐对判定演算](images/wc520_q1_example_walkthrough.svg)

三对中两对"端点相接"相交、一对分离，答案为 $2$。可以看到**相交不具有传递性**：$(0,1)$ 相交、$(1,2)$ 相交，但 $(0,2)$ 不相交——这也是不能只判相邻对的原因。

## 4. 算法细节

1. **判定公式**：`max(start_i, start_j) <= min(end_i, end_j)`，等价于交集非空，$O(1)$ 完成
2. **下标对去重**：内层循环从 `i + 1` 开始，保证 $i < j$，每对只统计一次。若写成两个独立循环 $0..n-1$，每个有序对会被数两次，答案恰好翻倍
3. **无需排序**：$n \le 100$，排序优化没有意义，保持输入顺序直接枚举最简单
4. **不去重相同区间**：值完全相同的两个区间（如 `[2,4]` 与 `[2,4]`）是两个不同元素，仍然相交，正常计数
5. **计数上限**：最多 $\binom{100}{2} = 4950$，`int` 完全够用

## 5. 正确性证明

**引理**：闭区间 $[a,b]$ 与 $[c,d]$ 的交集恰为 $[\max(a,c), \min(b,d)]$（当 $\max(a,c) \le \min(b,d)$），否则为空集。

**证明**：点 $x$ 同时属于两个区间 $\iff$ $a \le x \le b$ 且 $c \le x \le d$ $\iff$ $\max(a,c) \le x \le \min(b,d)$。故交集即所有满足 $\max(a,c) \le x \le \min(b,d)$ 的点集 $[\max(a,c), \min(b,d)]$；当 $\max(a,c) > \min(b,d)$ 时这样的 $x$ 不存在，交集为空。闭区间的端点包含在区间内，故端点相接（$\max = \min$）时交集恰为一个点，非空。∎

**定理**：算法返回的计数等于相交下标对的总数。

**证明**：双重循环中内层 $j$ 从 $i+1$ 开始，枚举出的 $(i,j)$ 与满足 $0 \le i < j < n$ 的下标对一一对应，每对恰好判定一次。由引理，判定条件 $\max(a,c) \le \min(b,d)$ 成立当且仅当两区间有公共点即相交。计数器对每个相交对恰好加一，故返回值等于相交对总数。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n^2)$。枚举 $\binom{n}{2} \le 4950$ 个下标对，每对常数时间判定；$n \le 100$ 下毫无压力。
- **空间复杂度**：$O(1)$。仅使用常数个临时变量，不随输入规模增长。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int countIntersectingIntervals(vector<vector<int>>& intervals) {
        int n = intervals.size();
        int count = 0;
        // 枚举所有下标对 (i, j)，i < j，每对恰好一次
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                // 交集 [max(左端点), min(右端点)] 非空 <=> 相交
                int L = max(intervals[i][0], intervals[j][0]);
                int R = min(intervals[i][1], intervals[j][1]);
                if (L <= R) {
                    count++;
                }
            }
        }
        return count;
    }
};
```

### Python

```python
class Solution:
    def countIntersectingIntervals(self, intervals: list[list[int]]) -> int:
        n = len(intervals)
        ans = 0
        # 枚举所有下标对 (i, j)，i < j，每对恰好一次
        for i in range(n):
            a, b = intervals[i]
            for j in range(i + 1, n):
                c, d = intervals[j]
                # 交集非空 <=> max(左端点) <= min(右端点)
                if max(a, c) <= min(b, d):
                    ans += 1
        return ans
```

## 8. 边界情况与易错点

1. **端点相接也算相交**：判定必须用 `<=`。若写成 `<`，示例 1 会误判为 $0$（两对端点相接的对全部漏掉）。这是本题唯一的陷阱。
2. **内层从 `i + 1` 开始**：避免每个有序对被统计两次导致答案翻倍。
3. **嵌套与相同区间**：`[1,5]` 与 `[2,4]`、`[2,4]` 与 `[2,4]` 都相交。不要"去重"输入——相同值的区间是不同元素。
4. **点区间**：`start == end`（如 `[2,2]`）是一个点，与任何包含 $2$ 的闭区间相交。
5. **不要排序后只判相邻**：相交**不具有传递性**——`[1,2]`∩`[2,3]`、`[2,3]`∩`[3,4]` 都相交，但 `[1,2]` 与 `[3,4]` 不相交。排序后只检查相邻对会漏掉大量相交对。
6. **溢出**：本题计数上限 $4950$，`int` 足够；但同场 Q2（II 版）中 $n$ 大幅增大，计数需用 `long long`。

**延伸思考**：

- 如何把计数优化到 $O(n \log n)$？**正难则反**：相交对数 $= \binom{n}{2} - $ 不相交对数。按左端点排序后，若 $i$ 排在 $j$ 前，则两区间不相交 $\iff \text{end}_i < \text{start}_j$。用树状数组（值域离散化）维护已处理的右端点，对每个 $j$ 查询严格小于 $\text{start}_j$ 的个数即可——这正是本场 Q2 的解法。
- 若区间改为**半开区间** $[a, b)$ 呢？端点相接不再相交（$[1,2)$ 与 $[2,3)$ 无公共点），判定条件变为严格不等号：$\max(a,c) < \min(b,d)$。
