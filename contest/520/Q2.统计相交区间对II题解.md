# LeetCode 统计相交区间对 II 题解

## 1. 题目概述

- **标题 / 题号**：统计相交区间对 II（#4057，Medium）
- **链接**：https://leetcode.cn/problems/number-of-intersecting-interval-pairs-ii/
- **来源**：LeetCode 第 520 场周赛 Q2
- **难度**：中等
- **标签**：数组、排序、二分查找

**题意**：给定 $n$ 个闭区间 $intervals[i] = [start_i, end_i]$，统计满足 $0 \le i < j < n$ 且 $intervals[i]$ 与 $intervals[j]$ **相交**的下标对 $(i, j)$ 的数量。两个区间**至少有一个公共点**即相交，仅共享一个端点也算相交。

**约束**：

- $2 \le n \le 10^5$
- $0 \le start_i \le end_i \le 10^9$

与第 I 版（#4056，$n \le 100$、坐标 $\le 100$，Easy）题意完全相同，只是数据范围扩大：$n$ 从 $10^2$ 升到 $10^5$、坐标从 $10^2$ 升到 $10^9$，暴力 $O(n^2)$ 不再可行。

## 2. 示例

**示例 1**

```text
输入：intervals = [[1,2],[2,3],[3,4]]
输出：2
解释：共有 2 对相交区间：
  [1,2] 与 [2,3] 在点 2 处相交（仅共享端点也算）
  [2,3] 与 [3,4] 在点 3 处相交
  [1,2] 与 [3,4] 不相交（2 < 3，中间有缝隙）
```

```text
  [1,5] ∩ [2,4] = [2,4]
  [1,5] ∩ [3,6] = [3,5]
  [2,4] ∩ [3,6] = [3,4]
```

**示例 3**

```text
输入：intervals = [[1,2],[3,4],[5,6]]
输出：0
解释：三个区间两两不相交，答案为 0。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有 $\binom{n}{2}$ 个下标对，逐对判断 $max(start_i, start_j) \le min(end_i, end_j)$ 是否成立。单次判断 $O(1)$，总复杂度 $O(n^2)$。当 $n \le 10^5$ 时约 $5 \times 10^9$ 次判断，必然超时。

> 💡 观察暴力的浪费之处：判断「相交」需要同时看两个端点，而判断「不相交」只需一个条件——一方完全在另一方左侧。**正难则反**：相交对数 = 总对数 − 不相交对数，不相交的结构简单得多。

### 3.2 核心观察：正难则反，容斥计数

闭区间 $[a, b]$ 与 $[c, d]$ 相交 $\iff max(a, c) \le min(b, d)$。反过来，**不相交**当且仅当一方完全在另一方左侧：

$$\text{不相交} \iff b < c \ \text{或} \ d < a$$

关键在于：一对不相交的区间中，**恰好有一个是「左侧区间」**。左侧区间用自己的**右端点** $end_j$、右侧区间用自己的**左端点** $start_i$ 参与判定，即 $end_j < start_i$。于是：

$$\text{不相交对数} = \sum_{i=1}^{n} \#\{\, j : end_j < start_i \,\}$$

每个不相交对 $\{j, i\}$（$j$ 在左）在这个和式中恰好被统计一次——以右侧区间的 $start_i$ 为「查询」，数出所有右端点严格小于它的区间。相交的区间对永远不会满足 $end_j < start_i$，贡献为 0。

因此，把所有 $end_j$ 排序成数组 $E$，对每个 $start_i$ 在 $E$ 中**二分查找**严格小于 $start_i$ 的元素个数即可：

$$\text{答案} = \binom{n}{2} - \sum_{i=1}^{n} \#\{\, e \in E : e < start_i \,\}$$

![相交判定与容斥：答案 = 总对数 − 不相交对](images/c520_interval_pairs_complement_concept.svg)

### 3.3 算法流程

1. 提取所有区间的右端点，得到数组 $ends$，将其**排序**为 $E$（$O(n \log n)$）。
2. 初始化 $disjoint = 0$。遍历每个区间 $i$，在 $E$ 中二分查找第一个 $\ge start_i$ 的位置（`lower_bound`），其左侧元素个数就是 $\#\{e \in E : e < start_i\}$，累加到 $disjoint$（$O(n \log n)$）。
3. 返回 $\dfrac{n(n-1)}{2} - disjoint$。

![算法流程：排序右端点 + 逐个二分 + 容斥相减](images/c520_interval_pairs_flow.svg)

### 3.4 示例演算

以示例 1 `intervals = [[1,2],[2,3],[3,4]]` 为例。所有右端点排序后 $E = [2, 3, 4]$，$n = 3$，总对数 $\binom{3}{2} = 3$：

| $i$ | 区间 | $start_i$ | $E$ 中 $< start_i$ 的元素 | 个数 |
|-----|--------|-----------|----------------|------|
| 0 | $[1,2]$ | $1$ | （无） | $0$ |
| 1 | $[2,3]$ | $2$ | （无，$2$ 不算严格小于） | $0$ |
| 2 | $[3,4]$ | $3$ | $\{2\}$ | $1$ |

$disjoint = 1$（即 $[1,2]$ 整体在 $[3,4]$ 左侧这一对），答案 $= 3 - 1 = 2$，与示例输出一致。

再看示例 3 `intervals = [[1,2],[3,4],[5,6]]$`，$E = [2, 4, 6]$：$start = 1, 3, 5$ 时严格小于的个数分别为 $0, 1, 2$，$disjoint = 3$，答案 $= 3 - 3 = 0$。✓

## 4. 算法细节

1. **排序对象是「右端点数组」**，与区间在原数组中的顺序无关——因为 $\sum_i \#\{j : end_j < start_i\}$ 对**所有** $j$ 计数（不要求 $j < i$），排序后整体二分即可，无需树状数组。
2. **严格小于的边界**：`lower_bound(E, start_i)` 返回第一个 $\ge start_i$ 的位置，其前缀长度恰为严格小于 $start_i$ 的个数。共享端点（$end_j = start_i$）是**相交**，必须排除在 $disjoint$ 之外，所以不能用 `upper_bound`。
3. **不会自计自身**：$j = i$ 时需要 $end_i < start_i$，与约束 $start_i \le end_i$ 矛盾，因此无需在计数中显式排除自身。
4. **溢出**：$\binom{n}{2} \le \binom{10^5}{2} \approx 5 \times 10^9$，超过 32 位 `int` 上限（约 $2.1 \times 10^9$），C++ 中必须用 `long long`（题目接口返回值已是 `long long`）；Python 整数无溢出。
5. **备选实现**：排序 $E$ 与所有 $start$ 后可用双指针把逐个二分优化为 $O(n)$，总复杂度仍为 $O(n \log n)$（排序主导）；也可按 $start$ 排序区间后用树状数组在线统计已插入的 $end$ 中小于当前 $start$ 的个数，思路等价但代码更长。

## 5. 正确性证明

**引理 1**（相交判定）：闭区间 $[a, b]$ 与 $[c, d]$（$a \le b$，$c \le d$）相交 $\iff max(a, c) \le min(b, d)$。

**证明**：两区间相交即存在公共点 $x$，即存在 $x$ 同时满足 $a \le x \le b$ 与 $c \le x \le d$。这样的 $x$ 存在当且仅当所有下界的最大值不超过所有上界的最小值，即 $max(a, c) \le min(b, d)$；此时取 $x = max(a, c)$ 即为公共点。∎

**引理 2**（不相交的唯一侧）：若 $[a, b]$ 与 $[c, d]$ 不相交，则恰有以下之一成立：$b < c$（前者在左）或 $d < a$（后者在左），且二者不同时成立。

**证明**：由引理 1 的逆否命题，不相交 $\iff max(a, c) > min(b, d)$。
若 $a \ge c$，则 $max(a,c) = a$；若 $min(b,d) = b$，则 $a > b$ 与 $a \le b$ 矛盾，故 $min(b, d) = d$ 且 $a > d$，即 $d < a$。
若 $a < c$，则 $max(a,c) = c$；同理若 $min(b,d) = d$，则 $c > d$ 与 $c \le d$ 矛盾，故 $min(b, d) = b$ 且 $c > b$，即 $b < c$。
若二者同时成立，则 $b < c \le d < a \le b$，导出 $b < b$，矛盾。∎

**定理**：相交对数 $= \dbinom{n}{2} - \sum_{i=1}^{n} \#\{\, j : end_j < start_i \,\}$。

**证明**：全部 $\binom{n}{2}$ 个区间对划分为不相交对与相交对两类，故相交对数 $= \binom{n}{2} - $（不相交对数）。只需证和式恰等于不相交对数。

一方面，对任意不相交对 $\{j, i\}$，由引理 2 恰有一个区间在左，设为 $j$，则 $end_j < start_i$，于是该对在和式中以 $i$ 为查询被计入，且由「恰有一个左侧」知不计入其他任何求和项；又 $j = i$ 不可能（$end_i < start_i$ 与 $start_i \le end_i$ 矛盾），不影响计数。另一方面，若 $end_j < start_i$，则由引理 2 的判定条件（$j$ 整体在 $i$ 左侧）知 $\{j, i\}$ 确实不相交，即和式的每次计数都对应一个真实的不相交对。故和式与不相交对数一一对应，二者相等。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \log n)$。提取右端点 $O(n)$；排序 $O(n \log n)$；$n$ 次二分查找，每次 $O(\log n)$，共 $O(n \log n)$。$n \le 10^5$ 时约 $10^6$ 量级运算，轻松通过。
- **空间复杂度**：$O(n)$。需要额外的右端点数组 $E$（排序不可原地于输入），其余为常数个变量。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    long long countIntersectingIntervals(vector<vector<int>>& intervals) {
        long long n = intervals.size();
        vector<int> ends;
        ends.reserve(n);
        for (auto& in : intervals) ends.push_back(in[1]);
        sort(ends.begin(), ends.end());
        long long disjoint = 0;
        for (auto& in : intervals)
            disjoint += lower_bound(ends.begin(), ends.end(), in[0]) - ends.begin();
        return n * (n - 1) / 2 - disjoint;
    }
};
```

### Python

```python
from bisect import bisect_left

class Solution:
    def countIntersectingIntervals(self, intervals: list[list[int]]) -> int:
        ends = sorted(e for _, e in intervals)
        n = len(intervals)
        disjoint = sum(bisect_left(ends, s) for s, _ in intervals)
        return n * (n - 1) // 2 - disjoint
```

## 8. 边界情况与易错点

1. **整数溢出**：$\binom{10^5}{2} \approx 5 \times 10^9$ 超过 `int`，C++ 必须用 `long long` 存答案与 $disjoint$ 的累加（题目已把接口返回类型设为 `long long`，注意中间量 `disjoint` 最大同样是 $\binom{n}{2}$ 量级）。
2. **闭区间共享端点算相交**：判定不相交必须用**严格小于**（`lower_bound`），写成 `upper_bound` 会把 $end_j = start_i$ 的共享端点对错误地计入不相交，示例 1 的 $[1,2]$ 与 $[2,3]$ 就会算错。
3. **不要按 $j < i$ 的下标顺序限制计数**：$\sum_i \#\{j : end_j < start_i\}$ 是对**全部**区间 $j$ 计数的，不能只数下标更小的，否则会漏掉「下标大但位置在左」的不相交对。
4. **点区间**：$start_i = end_i$ 的退化区间是合法输入，$[2,2]$ 与 $[1,3]$、$[2,5]$ 均相交，引理 1 的判定与二分流程自动正确处理，无需特判。
5. **排序的是右端点数组**：排序整个 `intervals` 再双指针的做法需要小心 $end$ 不随 $start$ 单调，最稳妥的就是独立排序 $E$ 再整体二分。
