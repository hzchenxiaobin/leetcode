# LeetCode 查询后矩阵的和 题解

## 1. 题目概述

- **标题 / 题号**：查询后矩阵的和（#2718，medium）
- **链接**：https://leetcode.cn/problems/sum-of-matrix-after-queries/
- **来源**：LeetCode 第 348 场周赛 Q3
- **难度**：中等
- **标签**：数组、哈希表

**题意**：给定整数 $n$ 和二维数组 `queries`，初始有一个 $n \times n$、元素全为 $0$ 的矩阵。每条查询 `queries[i] = [type_i, index_i, val_i]` 执行下述操作之一：`type_i = 0` 时把第 `index_i` 行**全部**改成 `val_i`；`type_i = 1` 时把第 `index_i` 列**全部**改成 `val_i`（均为覆盖式写入）。执行完所有查询后，返回矩阵所有元素之和。

**约束**：

- $1 \le n \le 10^4$（矩阵格子数可达 $10^8$，开不下、也扫不完）
- $1 \le \text{queries.length} \le 5 \times 10^4$
- $0 \le \text{type}_i \le 1$，$0 \le \text{index}_i < n$
- $0 \le \text{val}_i \le 10^5$（答案最大约 $5 \times 10^{13}$，超出 32 位整数）

> 💡 一句话破题：「覆盖」语义 = **后写的赢**。倒着扫一遍查询，每条只在「首次见到该行 / 列」时收割自己真正管得住的格子，其余全部作废——单条 $O(1)$，全程 $O(q)$。

## 2. 示例

**示例 1**

```text
输入：n = 3, queries = [[0,0,1],[1,2,2],[0,2,3],[1,0,4]]
输出：23
解释：终态矩阵为 [[4,1,2],[4,0,2],[4,3,3]]，逐格求和为 23。
```

**示例 2**

```text
输入：n = 3, queries = [[0,0,4],[0,1,2],[1,0,1],[0,2,3],[1,2,1]]
输出：17
解释：终态矩阵为 [[1,4,1],[1,2,1],[3,3,1]]；行 0 被写了两次、行 1 被写了两次，只有最后一次有效。
```

**示例 3**（自拟：同一行被重复书写）

```text
输入：n = 2, queries = [[0,0,3],[0,0,5],[1,1,7]]
输出：19
解释：行 0 先后被写 3、5，终态取 5；终态矩阵 [[5,7],[0,7]]，和 = 19。
```

## 3. 解题思路

### 3.1 暴力思路

老老实实维护 $n \times n$ 矩阵，逐条执行、最后求和：

- **空间**：$n^2 = 10^8$ 个格子，即使 `int` 也要约 400 MB，直接爆内存；
- **时间**：每条查询写 $n$ 格，共 $O(n^2 + qn) \approx 5 \times 10^8$ 次单点写，TLE。

退一步，正向记录每行 / 每列**最后一次**写入的 `(时刻, 值)`——这已经抓住了覆盖语义，但求和仍需对每个格子比较 $t_{\text{row}}[r]$ 与 $t_{\text{col}}[c]$，$O(n^2)$ 依旧过不去；要聚合就得按时刻排序或上树状数组，绕一大圈。

正确姿势是把时间轴反过来：**倒序扫描 + 首见收割**。

### 3.2 核心观察：后写覆盖先写，倒序「首见收割」

![核心观察：后写的覆盖先写的，倒序首见收割，行/列对偶计数](images/sum_matrix_reverse_concept.svg)

**观察 1（重复书写作废）**：同一行被写多次时，只有**最后一次**影响终态——更早的写入被整行抹掉，连一格都不剩。列同理。

**观察 2（格子归属）**：终态中格子 $(r, c)$ 的值，由「行 $r$ 的最后一次书写」与「列 $c$ 的最后一次书写」中**更晚**的那次决定；两者都没有则为 $0$。

**观察 3（首见 ⇔ 最后一次；对偶计数）**：倒序遍历时，**首次**碰到某行，当且仅当这正是该行的最后一次书写。此刻「已见列集」恰是那些**更晚**才被写的列——它们身上的格子早已名花有主。于是这条行操作真正管得住的格子恰有 $n - |\text{colSeen}|$ 个，收割贡献

$$\text{val} \times (n - |\text{colSeen}|)$$

列操作对偶：$\text{val} \times (n - |\text{rowSeen}|)$。每条查询 $O(1)$，总贡献即答案。

### 3.3 算法流程

![算法流程：倒序遍历，首见收割、已见跳过](images/sum_matrix_flow.svg)

```text
1. rowSeen、colSeen 置空，ans = 0
2. 倒序遍历 queries：
   a. 行操作（type=0）：若 index 已在 rowSeen → 跳过（更晚的行书写已整行覆盖）
      否则 ans += val × (n − |colSeen|)，并把 index 加入 rowSeen
   b. 列操作（type=1）：若 index 已在 colSeen → 跳过
      否则 ans += val × (n − |rowSeen|)，并把 index 加入 colSeen
3. 返回 ans
```

### 3.4 示例演算

![示例1倒序演算：四次首见收割，合计23](images/sum_matrix_walkthrough.svg)

示例 1（$n=3$）的倒序演算如上图：$12 + 6 + 4 + 1 = 23$，与终态矩阵逐格求和一致。示例 2 同法：

| 倒序步 | 查询 | 判定 | 收割 | 累计 |
|--------|---------|----------|-------------------|------|
| ① | [1,2,1] | 列 2 首见 | $1 \times (3-0) = 3$ | 3 |
| ② | [0,2,3] | 行 2 首见 | $3 \times (3-1) = 6$ | 9 |
| ③ | [1,0,1] | 列 0 首见 | $1 \times (3-1) = 2$ | 11 |
| ④ | [0,1,2] | 行 1 首见 | $2 \times (3-2) = 2$ | 13 |
| ⑤ | [0,0,4] | 行 0 首见 | $4 \times (3-2) = 4$ | 17 ✓ |

自拟示例 3 则检验「重复书写跳过」：倒序先见 [1,1,7]（列 1，收割 $7 \times 2 = 14$），再见 [0,0,5]（行 0，收割 $5 \times 1 = 5$），最后 [0,0,3] 因行 0 **已见**被跳过，合计 $19$ ✓。

## 4. 算法细节

1. **倒序首见 ⇔ 只看最后一次**：首见判定天然过滤掉同一行 / 列更早的书写——它们对终态的贡献为零，跳过即正确（见引理 1）。
2. **收割公式的对偶结构**：行操作收割时要数「还没被更晚列书写占领」的格子 $n - |\text{colSeen}|$；行列身份互换即得列操作公式，代码完全对称。
3. **seen 的实现**：$n \le 10^4$，用两个 `char`/`bool` 数组按下标标记最快，并同步维护 `|rowSeen|`、`|colSeen|` 计数器；若行列编号大到开不下数组，换哈希集合，均摊复杂度不变。
4. **溢出防护**：单笔贡献上限 $\text{val} \times n = 10^9$，累计上限约 $5 \times 10^{13}$——C++ 必须用 `long long`，且乘法**先转型再乘**：`(long long)val * (n - seenCols)`。
5. **别正向硬做**：正向执行时「当前和」会被后续覆盖回退（更晚的行书写会抹掉该行此前的列写入），增量维护极绕；倒序一次定终身。

## 5. 正确性证明

**引理 1（重复书写作废）**：设行 $r$ 在时刻 $t_1$ 被整行写为 $v_1$，在更晚时刻 $t_2$ 又被整行写为 $v_2$，则 $t_1$ 的书写对终态无任何影响。列同理。

**证明**：$t_1$ 的书写只改动行 $r$ 的格子。到 $t_2$ 时，行 $r$ 全部 $n$ 个格子被改写为 $v_2$，$v_1$ 的痕迹已全部清除；此后行 $r$ 各格的取值仅取决于 $t_2$ 及更晚的操作。故终态与 $t_1$ 的书写无关。∎

**引理 2（格子归属）**：记 $t_{\mathrm{row}}[r], v_{\mathrm{row}}[r]$ 为行 $r$ 最后一次书写的时刻与值（从未书写记 $t = -\infty$），列同理。则终态中

$$\mathrm{cell}(r,c) = \begin{cases} v_{\mathrm{row}}[r], & t_{\mathrm{row}}[r] > t_{\mathrm{col}}[c] \\ v_{\mathrm{col}}[c], & t_{\mathrm{row}}[r] < t_{\mathrm{col}}[c] \end{cases}$$

（两个时刻均为 $-\infty$ 时 $\mathrm{cell}(r,c) = 0$；同一行 / 列的书写时刻互不相同，故无相等情形。）

**证明**：对时刻 $s$ 归纳断言 $P(s)$：「截止 $s$，格子 $(r,c)$ 的当前值由行 $r$ 与列 $c$ 的书写中不晚于 $s$ 的最后一次决定（若没有则为 $0$）」。$s=0$ 时无书写，值为 $0$，成立。设 $P(s-1)$ 成立，考察第 $s$ 条操作：它恰属于某一行或某一列。若它不是行 $r$ 或列 $c$ 的书写，$(r,c)$ 不变，断言仍真；若是（设为行 $r$ 写 $v$），则 $(r,c)$ 变为 $v$，且该书写恰是截止 $s$ 行 $r$ 的最后一次，断言真。取 $s$ 为全部操作数即得终态结论；再由引理 1，「书写序列」各自只需保留最后一次。∎

**定理（倒序首见收割正确）**：算法返回的值等于终态矩阵所有元素之和。

**证明**：算法按时刻从大到小处理每条书写。设处理到行 $r$ 的书写 $t$ 且 $r$ **首见**，则 $t = t_{\mathrm{row}}[r]$（此后不再处理行 $r$ 的书写）。此刻已见列集恰为 $\{c : t_{\mathrm{col}}[c] > t\}$：列 $c$ 已见 ⇔ 其最后一次书写已被处理 ⇔ $t_{\mathrm{col}}[c] > t$；从未被写的列永不入集。由引理 2，行 $r$ 中归属书写 $t$ 的格子恰为不在已见列集内的那 $n - |\text{colSeen}|$ 个，每格贡献 $v$，合计 $v \times (n - |\text{colSeen}|)$，即算法所加。行 $r$ 更早的书写由引理 1 对终态贡献为零，跳过合法；列操作对称。于是**每个格子的终值恰被某一次首见收割计入一次**，总和正确。∎

## 6. 复杂度分析

- **时间复杂度**：$O(q)$——倒序一趟，每条查询仅一次 seen 判定、一次乘加，均为 $O(1)$（数组标记；哈希集则为均摊 $O(1)$）。$q \le 5 \times 10^4$ 轻松通过。
- **空间复杂度**：$O(n)$——两个标记数组各 $n$ 个元素；若改用哈希集合，则为 $O(\min(n, q))$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long matrixSumQueries(int n, vector<vector<int>>& queries) {
        vector<char> rowSeen(n, 0), colSeen(n, 0);
        long long seenRows = 0, seenCols = 0, ans = 0;
        for (int i = (int)queries.size() - 1; i >= 0; i--) {
            int type = queries[i][0], index = queries[i][1], val = queries[i][2];
            if (type == 0) {
                if (rowSeen[index]) continue;
                rowSeen[index] = 1;
                ans += (long long)val * (n - seenCols);
                seenRows++;
            } else {
                if (colSeen[index]) continue;
                colSeen[index] = 1;
                ans += (long long)val * (n - seenRows);
                seenCols++;
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def matrixSumQueries(self, n: int, queries: List[List[int]]) -> int:
        ans = 0
        row_seen, col_seen = set(), set()
        for t, index, val in reversed(queries):
            if t == 0:
                if index not in row_seen:
                    ans += val * (n - len(col_seen))
                    row_seen.add(index)
            else:
                if index not in col_seen:
                    ans += val * (n - len(row_seen))
                    col_seen.add(index)
        return ans
```

## 8. 边界情况与易错点

1. **C++ 溢出**：答案最大约 $5 \times 10^{13}$，`int` 必挂。不仅 `ans` 要 `long long`，乘法 `(long long)val * (n - seenCols)` 必须**先转型再乘**——写成 `val * (n - seenCols)` 时两个 `int` 相乘，乘完已溢出。
2. **`val = 0` 也占地**：0 值书写照样覆盖并占领格子，不能因值为 0 就跳过 seen 标记，否则更早的旧值会被错误收割。
3. **同行 / 列多次书写**：靠首见判定只认最后一次；漏掉 seen 判定会重复收割（示例 3 中 [0,0,3] 必须被跳过）。
4. **n = 1**：行 0 与列 0 指向同一个格子，倒序逻辑天然「后写赢」，无需特判。
5. **type 别记反**：`0` 是行、`1` 是列，记反后所有示例全错。
6. **别把「最后一次」记成「值最大」**：决定归属的是**时刻**先后，与 val 大小无关。
