# LeetCode 最小化字符串长度 题解

## 1. 题目概述

- **标题 / 题号**：最小化字符串长度（#2716，easy）
- **链接**：https://leetcode.cn/problems/minimize-string-length/
- **来源**：LeetCode 第 348 场周赛 Q1
- **难度**：简单
- **标签**：哈希表、字符串

**题意**：给定下标从 $0$ 开始的字符串 `s`，可以执行下述操作**任意次**：选出下标 $i$，记 $c = s[i]$，在 $i$ **左侧**（若有）与**右侧**（若有）各**删除一个距离 $i$ 最近的字符 $c$**。求最终能达到的 `s` 的**最小长度**。

**约束**：

- $1 \le \mathrm{s.length} \le 100$
- `s` 仅由小写英文字母组成

> 💡 签到题的全部难度在读题：操作删除的是「与中心**同字**的最近邻居」，而不是任意字符。由「只删同类」与「中心不删」两条性质可以推出：每种字符最终恰好各剩一个——答案就是**不同字符的种数**，`len(set(s))` 一行收工。

## 2. 示例

**示例 1**

```text
输入：s = "aaabc"
输出：3
解释：选下标 1 的 'a' 为中心，删除下标 0、2 的 'a'，得 "abc"；无法再缩短。
```

**示例 2**

```text
输入：s = "cbbd"
输出：3
解释：选下标 1 的 'b' 为中心，左侧无 'b'，删除右侧下标 2 的 'b'，得 "cbd"；无法再缩短。
```

**示例 3**

```text
输入：s = "dddaaa"
输出：2
解释：先选下标 1 的 'd'，删下标 0、2 得 "daaa"；再选中间的 'a'，删两侧 'a' 得 "da"。
```

**示例 4**（自拟，覆盖全同字符）

```text
输入：s = "aaaa"
输出：1
解释：选中间某个 'a' 为中心，"aaaa" → "aa" → "a"；最后 1 个 'a' 左右无同类，无法再删。
```

## 3. 解题思路

### 3.1 暴力思路：逐次模拟

按题面硬模拟：每轮找一个出现次数 $\ge 2$ 的字符，定位中心与两侧最近同类，删除、移位，直到无法缩短。

- 每次操作定位 + 移位 $O(n)$，至多执行 $O(n)$ 轮，总计 $O(n^2)$，$n \le 100$ 完全能过；
- 但下标移位后「最近同类」需要重新定位，实现极易写错；更重要的是**题目只要最小长度、不要最终串**——模拟把精力浪费在「怎么删」的过程上，完全没必要。

签到题的正确姿势是问：**最终形态由什么决定？**

### 3.2 核心观察：只删同类 + 中心不删 ⇒ 每种字符恰剩 1 个

![核心观察：一次操作只删同类邻居，中心存活](images/minstrlen_operation_concept.svg)

细读操作的语义：删除对象是「距离 $i$ 最近的**字符 $c$**」，而 $c$ 恰是 $s[i]$ 本身。于是有两条决定性性质：

1. **只删同类**：一次操作只会删除字符 $c$，其他字符即便紧贴着 $i$ 也纹丝不动 ⇒ **各字符的缩减过程完全独立**；
2. **中心不删**：被选中的 $s[i]$ 自身保留，删的只是它的同类邻居 ⇒ **任何操作都删不光某种字符**，每种字符出现次数恒 $\ge 1$。

于是问题拆成独立子问题：**字符 $c$ 出现 $k$ 次，最少能缩到几个？**答案是 $1$——$k = 2$ 时选其一为中心、删另一个；$k \ge 3$ 时选非端点为中心，一次删 $2$ 个，$k \to k - 2$，归纳到前两种情形。每种字符都恰剩 $1$ 个，合起来：

$$\text{最小长度} = \text{s 中不同字符的种数}$$

### 3.3 算法流程：单字符缩减的决策

![单字符缩减流程：k 等于 1 终止，k 等于 2 删一，k 至少 3 删二递减](images/minstrlen_reduce_flow.svg)

对每种字符独立执行上述决策，全部缩到恰好 $1$ 个。落到实现上就是**一次遍历、字符入集合、返回集合大小**：

```text
1. seen ← 空集合
2. for ch in s: seen.add(ch)
3. return |seen|
```

由于 `s` 仅含 26 个小写字母，还可用一个 `int` 的低 26 位做**位掩码**：`mask |= 1 << (ch - 'a')`，答案即 `popcount(mask)`——集合的极简等价物。

### 3.4 示例演算

![示例演算：dddaaa 先缩 d 得 daaa 再缩 a 得 da，答案 2](images/minstrlen_walkthrough.svg)

以 `s = "dddaaa"` 为例：

| 阶段 | 对象 | 操作 | 结果 |
|------|------|------|------|
| ① | `d` 出现 3 次 | 选中间的 `d` 为中心，删左右各一个 `d` | `"daaa"` |
| ② | `a` 出现 3 次 | 选中间的 `a` 为中心，删左右各一个 `a` | `"da"` |

最终 `"da"`，长度 $2 = |\{d, a\}|$ ✓。先缩 `a` 再缩 `d` 结果相同——「互不干扰」保证了**顺序无关**。对照示例 1/2：`"aaabc"` 的不同字符 $\{a, b, c\}$ 共 3 种、`"cbbd"` 的 $\{c, b, d\}$ 共 3 种，均与输出一致。

## 4. 算法细节

1. **删除规则的语义是唯一支点**：删的是「最近的**同字**邻居」，与任意字符无关——这是把问题从「字符串模拟」降维成「字符计数」的关键。
2. **中心不删 ⇒ 下界**：以 $c$ 为中心的操作至多删掉两个 $c$，但保留中心本身，故每种字符的计数永不为 $0$（见第 5 节引理 1）。
3. **$k \ge 3$ 时必须选非端点**：只有非端点的出现位置才保证左右两侧各有一个同类，一次删 $2$ 个；$k = 2$ 时只能删 $1$ 个。
4. **集合可换成位掩码**：26 个小写字母恰对应 `int` 的 26 位，`popcount` 直接给出种数，省去哈希开销。
5. **答案与顺序、频次无关**：不同字符互不干扰，同一字符的缩减顺序也不影响结果——只需统计「是否出现过」，无需频次，更无需位置。

## 5. 正确性证明

**引理 1（下界不变量）**：任意时刻，每种在 `s` 中出现过的字符，出现次数恒 $\ge 1$。

**证明**：对操作次数归纳。删除字符 $c$ 的唯一途径是执行中心为 $c$ 的操作；该操作至多删除 $i$ 左右各一个 $c$，而中心 $s[i] = c$ 本身不被删除，操作后 $c$ 的计数仍 $\ge 1$。中心非 $c$ 的操作根本不会删除 $c$。归纳成立。∎

**引理 2（可达性）**：若 $c$ 出现 $k \ge 2$ 次，可经若干操作使其出现次数恰为 $1$，且全程不影响其他字符。

**证明**：对 $k$ 归纳。$k = 2$：任选其一为中心，删除另一侧唯一的同类，得 $1$。$k \ge 3$：取某个非端点的出现位置为中心，左右两侧各删一个，计数 $k \to k - 2 \ge 1$，由归纳假设可达 $1$。操作只删 $c$，其他字符不受影响。∎

**定理**：最小长度等于 `s` 中不同字符的种数 $d$。

**证明**：下界：由引理 1，任何操作序列结束后每种出现过的字符仍至少保留一个，故长度 $\ge d$。上界：由引理 2，对每种字符依次独立缩减到恰好一个（对 $c$ 的操作只删 $c$，互不冲突），可达到长度恰为 $d$ 的串。下界与上界重合，故最小长度 $= d$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$——一次遍历入集合/置位；$n \le 100$ 远低于任何限制，位掩码版均摊每字符 $O(1)$。
- **空间复杂度**：$O(1)$——字符集 $\Sigma = 26$ 为常数，集合至多 26 项；位掩码版恰用 1 个 `int`。

## 7. 参考代码

### C++（哈希集合）

```cpp
class Solution {
public:
    int minimizedStringLength(string s) {
        unordered_set<char> seen;
        for (char c : s) {
            seen.insert(c);
        }
        return seen.size();
    }
};
```

### C++（位掩码，极致常数）

```cpp
class Solution {
public:
    int minimizedStringLength(string s) {
        int mask = 0;
        for (char c : s) {
            mask |= 1 << (c - 'a');
        }
        return __builtin_popcount(mask);
    }
};
```

### Python

```python
class Solution:
    def minimizedStringLength(self, s: str) -> int:
        return len(set(s))
```

## 8. 边界情况与易错点

1. **$n = 1$**：如 `"a"`，答案 $1$ 而非 $0$——单个字符没有同类邻居，一步也删不了。
2. **全同字符**：`"aaaa"` 答案 $1$：$4 \to 2 \to 1$，但由引理 1 永远删不到 $0$。
3. **全互异字符**：`"abcdef"` 答案 $6$：任何中心都找不到同类邻居，长度无法改变。
4. **别误读题**：删的是「最近的**字符 $c$**」即**同字**邻居，不是「最近的任意字符」；若删任意字符，答案会变成 $1$（见延伸思考①）。
5. **不要真去模拟**：题目只问最小长度，不问最终串与操作序列；计数视角一行解决，模拟既慢又易错。
6. **返回值是长度**：不是字符串本身，别把构造最终串的负担揽进来。
7. **位掩码宽度**：26 位 $< 32$，`int` 足够，无溢出风险。
