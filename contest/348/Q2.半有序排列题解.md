# LeetCode 半有序排列 题解

## 1. 题目概述

- **标题 / 题号**：半有序排列（#2785，easy）
- **链接**：https://leetcode.cn/problems/semi-ordered-permutation/
- **来源**：LeetCode 第 348 场周赛 Q2
- **难度**：简单
- **标签**：数组、模拟

**题意**：给定下标从 $0$ 开始、长度为 $n$ 的排列 `nums`。若 `nums[0] = 1` 且 `nums[n-1] = n`，则称其为**半有序排列**。一次操作可以交换 `nums` 中**相邻**的两个元素，可以执行任意多次。求把 `nums` 变成半有序排列的最少操作次数。

**约束**：

- $2 \le n \le 50$
- `nums` 是 $1 \sim n$ 的一个排列（每个数恰好出现一次）

> 💡 本题的关键在做减法：**中间 $n-2$ 个元素的去向完全无所谓**，真正重要的只有两个下标——$1$ 的位置 $i$ 和 $n$ 的位置 $j$。一次扫描 + 一条带"交叉修正"的公式即可收工；唯一的坑是 $i > j$（$1$ 在 $n$ 右侧）时要**再减 1**。

## 2. 示例

**示例 1**

```text
输入：nums = [2,1,4,3]
输出：2
解释：交换下标 0、1 得 [1,2,4,3]，再交换下标 2、3 得 [1,2,3,4]。
```

**示例 2**

```text
输入：nums = [2,4,1,3]
输出：3
解释：见 3.4 节演算——第一步恰是 n=4 与 1 的直接互换，"一箭双雕"。
```

**示例 3**

```text
输入：nums = [1,3,4,2,5]
输出：0
解释：首位已是 1、末位已是 5 = n，无需任何操作；中间 3、4、2 乱序也不影响。
```

**示例 4**（自拟，$n = 2$ 的极端情形）

```text
输入：nums = [2,1]
输出：1
解释：仅有的两个元素恰好是 n 和 1，直接互换一次即得 [1,2]。
```

## 3. 解题思路

### 3.1 暴力思路

两条朴素路线，都不理想：

- **BFS 最短路**：把每种排列视作一个状态、每次相邻交换连一条边，从 `nums` 做 BFS 直到半有序。状态数 $n!$，$n = 50$ 时是天文数字，直接爆炸；
- **逐步模拟**：老老实实把 $1$ 一步步冒泡到首位、再把 $n$ 冒泡到末位。能做对（3.4 节的演算就是它），但要写两层循环、维护下标，且**说不清为什么这样交换次数最少**——证明比实现还长。

更危险的坑是"直觉公式"：把 $1$ 挪到首位要 $i$ 次、把 $n$ 挪到末位要 $n-1-j$ 次（$i, j$ 分别为 $1, n$ 的下标），于是直接写 $i + (n-1-j)$——**在 $1$ 位于 $n$ 右侧时会多数 1**（示例 2 按此式得 4，正确答案 3）。

### 3.2 核心观察：只有两个下标重要，交叉时一步抵两步

![核心观察：i 与 j 的两种位置关系，交叉时一次交换同时推进两个目标](images/semi_ordered_two_cases.svg)

**观察 1（其余元素是背景板）**：半有序只考核 `nums[0]` 与 `nums[n-1]`，中间 $n-2$ 个元素随便放。因此除 $1$ 与 $n$ 外，其他元素的初始位置对答案没有贡献——**全部信息就是 $i = \mathrm{pos}(1)$ 与 $j = \mathrm{pos}(n)$ 两个下标**。

**观察 2（各自的旅程）**：一次相邻交换至多让 $1$ 向左挪一步（向右是倒退，最优解不会做），故把 $1$ 从下标 $i$ 送到下标 $0$ 需要 $i$ 次、且 $i$ 次恰好够用；同理把 $n$ 从下标 $j$ 送到下标 $n-1$ 需要 $n-1-j$ 次。

**观察 3（交叉时的一箭双雕）**：若 $i > j$（$1$ 在 $n$ 右侧），$1$ 向左的旅程**必然路过** $n$ 所在的下标 $j$，两者会**恰好直接互换一次**——这一次交换同时让 $1$ 左移一步、$n$ 右移一步，同时推进两个目标，于是总步数**省 1**。若 $i < j$，两条旅程一左一右、背向而行，永不相遇，无步可省。

合并成一条**艾弗森括号**公式（$[\,\cdot\,]$ 在条件为真时取 $1$，否则取 $0$）：

$$\text{ans} = i + (n - 1 - j) - [\,i > j\,]$$

### 3.3 算法流程

![算法流程：扫描定位 i、j，按是否交叉套公式](images/semi_ordered_formula_flow.svg)

```text
1. 一次扫描：i ← pos(1)，j ← pos(n)
2. 若 i > j：ans ← i + (n-1-j) - 1    # 1 在 n 右侧，交叉省一步
   否则：    ans ← i + (n-1-j)
3. 返回 ans
```

### 3.4 示例演算

![示例演算：[2,4,1,3] 的三步交换，首步即 n 与 1 的直接互换](images/semi_ordered_walkthrough.svg)

以 `nums = [2,4,1,3]`（$n=4$，$i=2$，$j=1$，交叉情形）为例：

| 步 | 操作 | 交换双方 | 结果 | 说明 |
|----|------|----------|------|------|
| 起 | — | — | `[2,4,1,3]` | $i=2,\ j=1$，ans $= 2+2-1 = 3$ |
| ① | 交换 idx 1、2 | **4 与 1** | `[2,1,4,3]` | $1$ 左移、$4$ 右移，一步抵两步 |
| ② | 交换 idx 0、1 | 2 与 1 | `[1,2,4,3]` | $1$ 到达首位 |
| ③ | 交换 idx 2、3 | 4 与 3 | `[1,2,3,4]` | $4 = n$ 到达末位 ✓ |

共 $3$ 次 $= i + (n-1-j) - 1 = 2 + 2 - 1$ ✓。对照示例 1：`[2,1,4,3]` 中 $i=1 < j=2$，不交叉，ans $= 1 + 1 = 2$ ✓；示例 3 中 $i=0,\ j=n-1$，公式自然给 $0$ ✓。

## 4. 算法细节

1. **信息压缩**：$O(n)$ 的输入只提炼出两个下标 $i, j$——题目只考核首末两位，其余全是噪声。
2. **为什么恰好省 1、不能省 2**：一次相邻交换对"$1$ 的左移"与"$n$ 的右移"两个目标各自至多推进 $1$ 步；想一次推进两个，当且仅当交换的恰是相邻的 $(n, 1)$ 且 $n$ 在左。而 $1$ 与 $n$ 的相对顺序从"1 右 n 左"变为最终的"1 左 n 右"必须互换**奇数**次，最优取 $1$ 次；反之（"1 左 n 右"→"1 左 n 右"）互换偶数次，最优取 $0$ 次。故修正项非 $0$ 即 $1$。
3. **艾弗森括号**：$[\,i>j\,] \in \{0,1\}$ 把两个分支压成一条式子，代码零 `if`。
4. **别顺手排序中间**：把中间元素也排成升序是"完全排序"，所需交换次数（逆序对数）只会更大，且与半有序的判定无关。
5. **下标从 0 开始**：公式中的 $n-1-j$ 用的是 0 基下标；若改用 1 基"第几位" $p, q$，等价式为 $(p-1) + (n-q) - [p>q]$。

## 5. 正确性证明

**引理 1（一次交换只翻一对）**：相邻交换只改变**被交换那一对**元素的相对顺序，其余任意元素对的相对顺序不变。

**证明**：设交换下标 $k, k+1$ 上的 $x, y$。不含 $x, y$ 的对中两元素位置均不动，顺序不变；含 $x$（或 $y$）与第三者 $z$ 的对中，$x$ 仅在下标 $k$ 与 $k+1$ 之间平移一位，仍在 $z$ 的同侧，顺序亦不变。∎

**引理 2（相邻交换最短路定理）**：设 $d(P, B)$ 为排列 $P$ 与目标排列 $B$ 中相对顺序不同的元素对个数，则 $P \to B$ 的最少相邻交换次数恰为 $d(P, B)$。

**证明**：**下界**：由引理 1，每次交换至多"修正"一对顺序不合的元素对，即 $d$ 每次至多减 $1$，故至少需 $d(P,B)$ 次。**上界**（对 $d$ 归纳）：$d=0$ 时 $P$ 与 $B$ 的全对顺序一致，即 $P = B$，零次即可。$d > 0$ 时断言 $P$ 中存在**相邻**的顺序不合对：否则 $P$ 的所有相邻对都与 $B$ 的顺序一致，任取 $P$ 中 $a$ 在 $b$ 前的一对，沿 $a$ 到 $b$ 的相邻链逐对传递"$B$ 中在前"关系（传递性），得 $a$ 在 $B$ 中也在 $b$ 前，于是所有对都一致，$d = 0$，矛盾。取出该相邻不合对并交换：由引理 1，其余对的合/不合状态不变，而这一对恰好由"不合"变为"合"，$d$ 恰减 $1$，归纳得 $d$ 次可达。∎

**引理 3（目标排列的分类计数）**：对任意满足 $B[0]=1$、$B[n-1]=n$ 的排列 $B$，有

$$d(P, B) = i + (n-1-j) - [\,i>j\,] + m(B)$$

其中 $m(B) \ge 0$ 为**中间元素两两之间**顺序不合的对数，且存在 $B$ 使 $m(B)=0$（中间元素按 $P$ 中原相对顺序排）。

**证明**：按元素对是否含 $1, n$ 分四类计数（$1, n$ 各自与谁比较只取决于"$1$ 在首、$n$ 在尾"，与 $m$ 无关）：

- $\{1, x\}$（$x \ne 1, n$）：$B$ 中 $1$ 在 $x$ 前；$P$ 中 $x$ 在 $1$ 前的恰为 $P[0..i-1]$ 中除 $n$ 外的元素，共 $i - [i>j]$ 对；
- $\{n, x\}$（$x \ne 1, n$）：$B$ 中 $x$ 在 $n$ 前；$P$ 中 $n$ 在 $x$ 前的恰为 $P[j+1..n-1]$ 中除 $1$ 外的元素，共 $(n-1-j) - [i>j]$ 对；
- $\{1, n\}$：$B$ 中 $1$ 在 $n$ 前；不合当且仅当 $P$ 中 $n$ 在 $1$ 前，即 $i > j$，共 $[i>j]$ 对；
- 中间元素两两之间：即 $m(B)$。

合计 $i + (n-1-j) - [i>j] + m(B)$。取中间元素相对顺序与 $P$ 相同的 $B$，中间对全部相合，$m = 0$。∎

**定理**：最少操作次数为 $i + (n-1-j) - [i > j]$。

**证明**：答案为所有满足 $B[0]=1,\ B[n-1]=n$ 的目标中最少交换次数的最小值。由引理 3，$\min_B d(P,B) = i + (n-1-j) - [i>j] + \min_B m(B) = i + (n-1-j) - [i>j]$；再由引理 2，对每个 $B$ 该 $d$ 值恰为可达的最少交换次数。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$——一次线性扫描定位 $i, j$，再常数次加减。Python 的两次 `list.index` 也只是两趟线性扫描，仍为 $O(n)$；$n \le 50$ 毫无压力。
- **空间复杂度**：$O(1)$——只存 $i, j$ 与答案三个整数，不需要任何额外数据结构。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int semiOrderedPermutation(vector<int>& nums) {
        int n = nums.size();
        int i = 0, j = 0;
        for (int k = 0; k < n; k++) {
            if (nums[k] == 1) i = k;
            else if (nums[k] == n) j = k;
        }
        return i + (n - 1 - j) - (i > j);
    }
};
```

### Python

```python
class Solution:
    def semiOrderedPermutation(self, nums: List[int]) -> int:
        n = len(nums)
        i, j = nums.index(1), nums.index(n)
        return i + (n - 1 - j) - (i > j)
```

## 8. 边界情况与易错点

1. **已半有序**：$i = 0$ 且 $j = n-1$ 时公式自然给 $0$（示例 3），无需特判。
2. **忘减修正项**：$i > j$ 时不减 1 是最常见 WA——示例 2 会把 3 错算成 4；反过来 $i < j$ 时多减 1 同样错。
3. **$n = 2$**：排列只能是 `[1,2]`（答案 0）或 `[2,1]`（答案 $1 + 1 - 1 = 1$）——1 与 $n$ 相邻直接互换的极端交叉情形。
4. **$i = j$ 不可能**：$n \ge 2$ 时 $1 \ne n$，两者位置必不同，只需区分 $i < j$ 与 $i > j$ 两种情形。
5. **别把目标当成完全升序**：中间元素乱序不影响半有序（示例 3 中 3、4、2 乱序，答案仍为 0）；若误按"排序"做，答案会偏大。
6. **0 基与 1 基别混用**：$n-1-j$ 中的 $j$ 是 0 基下标，混用 1 基"第几位"会错位 1。
7. **数据范围极小**（$n \le 50$）：任何多项式模拟都能过，但 BFS 不可行（$50!$ 个状态）；公式 $O(n)$ 一行收工。
