# LeetCode 统计所有可行路径 题解

## 1. 题目概述

- **标题 / 题号**：统计所有可行路径（#1575，hard）
- **链接**：https://leetcode.cn/problems/count-all-possible-routes/
- **来源**：LeetCode 第 34 场双周赛 Q4
- **难度**：困难
- **标签**：记忆化、数组、动态规划

**题意**：给定**互不相同**的位置数组 `locations`（`locations[i]` 是第 $i$ 座城市在数轴上的坐标），起点城市 `start`、终点城市 `finish` 与初始油量 `fuel`。每一步可以从城市 $i$ 移动到任意城市 $j \ne i$，耗油 $|locations[i] - locations[j]|$；**任意时刻油量不能为负**；城市可以重复经过（包括 `start` 和 `finish`）。求从 `start` 出发、最终**停在** `finish` 的所有路径数目，对 $10^9 + 7$ 取余。

**约束**：

- $2 \le locations.length \le 100$，所有位置互不相同，$1 \le locations[i] \le 10^9$；
- $0 \le start, finish < locations.length$（**可能相等**）；
- $1 \le fuel \le 200$。

## 2. 示例

**示例 1**

```text
输入：locations = [2,3,6,8,4], start = 1, finish = 3, fuel = 5
输出：4
解释：四条路径（均恰好用光或用少于 5 单位油）：1→3；1→2→3；1→4→3；1→4→2→3。
```

**示例 2**

```text
输入：locations = [4,3,1], start = 1, finish = 0, fuel = 6
输出：5
解释：1→0（耗 1）；1→2→0（耗 5）；1→2→1→0（耗 5）；1→0→1→0（耗 3）；1→0→1→0→1→0（耗 5）。
     注意允许反复途经 finish（城市 0）甚至从 finish 出发再折返——每条路径以「停在 finish」计数。
```

**示例 3**

```text
输入：locations = [5,2,1], start = 0, finish = 2, fuel = 3
输出：0
解释：0→2 最短耗油 4 > 3，一条路径都没有。
```

## 3. 解题思路

### 3.1 暴力思路：直接穷举所有路径

从 `start` 出发 DFS，每一步尝试所有 $n - 1$ 个目标城市，油尽即止，遇到「当前在 finish」就计 1 条。路径长度上限是 $fuel$（每步耗油 $\ge 1$），但分支因子高达 $n - 1 = 99$：最坏约 $99^{200}$ 个分支，天文数字。示例 2 里「途经 finish 再折返」的路径说明**同一个城市可以在不同剩油状态下多次出现**——朴素的「访问过」剪枝不可用，必须换状态组织方式。

### 3.2 核心观察：油量严格递减 ⟹ 状态无环 ⟹ 可记忆化

![路径搜索树：每一步耗油至少 1，fuel 严格递减无环](images/bw34_q4_state_tree.svg)

因为位置互不相同，任意两城间耗油 $\ge 1$，**每走一步剩油严格减少**。于是「当前城市 $i$ + 剩油 $f$」就是一个不会绕回自身的状态：从 $(i, f)$ 出发的路径集合结构，只取决于 $(i, f)$ 本身，而与「怎么走到 $(i, f)$」无关——这正是**记忆化搜索**（也即最短路图上的计数 DP）成立的结构性条件。定义

$$
dp[i][f] = \text{位于城市 } i \text{、剩油 } f \text{ 时，最终停在 } finish \text{ 的路径数}.
$$

**计数细节**（本题最容易错的一处）：到达 finish 并不意味着路径必须结束——可以继续走、甚至绕一圈再回来。所以 $dp[i][f]$ 的递推里，$i = finish$ 的「就地停下」贡献一个 1，但**不提前 return**，继续枚举「从 finish 再出发」的分支：

$$
dp[i][f] = [\,i = finish\,] \; + \; \sum_{j \ne i,\ |loc_i - loc_j| \le f} dp[j]\bigl[f - |loc_i - loc_j|\bigr].
$$

这就是「恰好耗油 $\le fuel$、终点为 finish」的全部路径：每条路径被其完整步序列唯一刻画，上式按第一步展开，不重不漏。

### 3.3 状态转移与实现

![dp 状态模型与转移边](images/bw34_q4_dp_model.svg)

实现上用记忆化递归最省事：`memo[i][f]` 初始化为 $-1$ 表示未算过；递归深度最多 $fuel + 1 = 201$（每层 $f$ 至少减 1），不会爆栈。也可以写成自底向上：按 $f = 0, 1, \dots, fuel$ 从小到大填表，转移同上。总状态 $n \times (fuel + 1) = 100 \times 201$，每状态转移 $O(n)$。

### 3.4 示例演算

![示例 2 的五条路径演算](images/bw34_q4_walkthrough.svg)

以示例 2（`locations = [4,3,1]`，`start = 1`，`finish = 0`，`fuel = 6`）演算关键状态：$dp[0][f]$ 含基项 1（已在 finish），$dp[1][6] = dp[0][5] + dp[2][4]$（$|4-3|=1$、$|3-1|=2$，注意到 0 剩 $6-1=5$、到 2 剩 $6-2=4$）；$dp[0][5] = 1 + dp[1][4] + dp[2][4]$（从 0 出发到 1 耗 1、到 2 耗 3）；逐层展开最终 $dp[1][6] = 5$ ✓。其中「$1 \to 0$ 后不立即停，继续 $0 \to 1 \to 0$」的路径正是靠 $dp[0][5]$ 的「基项 + 继续走」两部分共同数出来的。

## 4. 算法细节

1. **`i == finish` 的基项**：`res = (i == finish ? 1 : 0)` 后**不能 return**，必须继续枚举移动；漏掉基项会少数「直达即停」，漏掉继续枚举会少数「途经后折返」。
2. **记忆化的初值**：用 $-1$ 与「真实计数 0」区分；用 0 当初值会导致大量重复递归（把「算过且为 0」误判成「没算过」），时间退化但仍正确——初值选 $-1$ 才是正解。
3. **取模时机**：每层递归把子项逐个 `% MOD` 后累加即可，中间和不超过 $(n+1) \cdot MOD < 2^{63}$，`long long` 安全；Python 天然大数，最后取模也行（但仍建议逐层取模省内存带宽）。
4. **递归深度**：每步耗油 $\ge 1$，深度 $\le fuel + 1 \le 201$，Python 默认递归上限 1000 足够，无需调大。
5. **`start == finish`**：答案至少为 1（零步路径），示例「`[2,1,5]`, start = finish = 0, fuel = 3」输出 2（停在原地 + $0 \to 1 \to 0$ 折返一条）。递推自动涵盖。
6. **判环的关键前提**：位置互不相同保证 $|loc_i - loc_j| \ge 1$。如果题目允许相同位置，会出现 0 耗油转移，$dp[i][f] \to dp[i][f]$ 自指，必须另行处理（本题无此坑，但要意识到记忆化成立依赖这个前提）。

## 5. 正确性证明

**引理 1（路径的递归分解）**：设 $\mathcal{P}(i, f)$ 为「从城市 $i$ 出发、总耗油 $\le f$、以停在 finish 结束」的移动序列全体。则存在不重不漏的分解：

$$
\mathcal{P}(i, f) \;=\; \bigl[\, i = finish \,\bigr] \cdot \{\varepsilon\} \;\;\biguplus\;\; \biguplus_{j \ne i,\ c_{ij} \le f} \bigl\{ (i \to j) \cdot \sigma : \sigma \in \mathcal{P}(j, f - c_{ij}) \bigr\},
$$

其中 $c_{ij} = |loc_i - loc_j|$，$\varepsilon$ 是零步序列，$\cdot$ 表示步序列的拼接。

**证明**：任取 $\sigma \in \mathcal{P}(i, f)$。若 $\sigma = \varepsilon$：路径一步不走就「停在 finish」$\Leftrightarrow i = finish$，落在第一块。否则 $\sigma$ 的第一步是某个 $i \to j$（$j \ne i$），其耗油 $c_{ij} \le f$（总耗油约束），剩余部分 $\sigma'$ 是从 $j$ 出发、总耗油 $\le f - c_{ij}$、停在 finish 的序列，即 $\sigma' \in \mathcal{P}(j, f - c_{ij})$，$\sigma$ 落在第二块中 $j$ 对应的子块。不同子块由第一步的目标城市区分、块内由 $\sigma'$ 区分，故分解不重；每条路径都恰落入一块，不漏。∎

**引理 2（无环与良定义）**：所有状态 $(i, f)$ 按字典 $(f)$ 严格分层——每条转移边 $(i, f) \to (j, f - c_{ij})$ 使 $f$ 严格减小。故按 $f$ 从小到大依次求值时，等式右端引用的状态均已算得，$dp[i][f]$ 良定义且有限。

**证明**：位置互不相同 $\Rightarrow c_{ij} \ge 1$ $\Rightarrow f - c_{ij} < f$。归纳基础 $f = 0$：无任何 $c_{ij} \le 0$ 的边，$dp[i][0] = [i = finish]$。归纳步骤由引理 1 直接给出递推式。∎

**定理**：$dp[start][fuel] \bmod (10^9+7)$ 等于题目所求的路径数对 $10^9 + 7$ 取余。

**证明**：由引理 1，$|\mathcal{P}(i, f)| = [i = finish] + \sum_{j \ne i, c_{ij} \le f} |\mathcal{P}(j, f - c_{ij})|$；由引理 2 该递推可有限计算且 $dp[i][f] = |\mathcal{P}(i, f)|$（精确计数，不取模）。题目所求即 $|\mathcal{P}(start, fuel)|$。取模只会作用于求和与比较过程——加法与取模交换（模对加法的分配律），递推逐层取模后得到的是 $|\mathcal{P}| \bmod p$。∎

## 6. 复杂度分析

- **时间**：$O(n^2 \cdot fuel)$。状态数 $n (fuel + 1) \approx 100 \times 201 = 2 \times 10^4$，每状态转移枚举 $n - 1$ 个城市，总计约 $2 \times 10^6$ 次基本操作；记忆化保证每个状态只算一次。
- **空间**：$O(n \cdot fuel) \approx 2 \times 10^4$ 个计数器；递归栈深 $O(fuel) \le 201$。

## 7. 参考代码

### C++

```cpp
class Solution {
    static constexpr long long MOD = 1000000007LL;
    vector<vector<long long>> memo;
    vector<int> loc;
    int fin;

    long long dfs(int i, int f) {          // 位于 i、剩油 f，最终停在 finish 的路径数
        if (memo[i][f] != -1) return memo[i][f];
        long long res = (i == fin) ? 1 : 0; // 原地停在 finish 也算一条路径
        for (int j = 0; j < (int)loc.size(); ++j) {
            if (j == i) continue;
            int c = loc[i] > loc[j] ? loc[i] - loc[j] : loc[j] - loc[i];
            if (c <= f) res = (res + dfs(j, f - c)) % MOD;
        }
        return memo[i][f] = res;
    }
public:
    int countRoutes(vector<int>& locations, int start, int finish, int fuel) {
        int n = (int)locations.size();
        loc = locations;
        fin = finish;
        memo.assign(n, vector<long long>(fuel + 1, -1));
        return (int)dfs(start, fuel);
    }
};
```

### Python

```python
class Solution:
    def countRoutes(self, locations: list[int], start: int, finish: int, fuel: int) -> int:
        MOD = 10 ** 9 + 7
        n = len(locations)
        memo = [[-1] * (fuel + 1) for _ in range(n)]

        def dfs(i: int, f: int) -> int:      # 位于 i、剩油 f，最终停在 finish 的路径数
            if memo[i][f] != -1:
                return memo[i][f]
            res = 1 if i == finish else 0    # 原地停在 finish 也算一条路径
            for j in range(n):
                if j == i:
                    continue
                c = abs(locations[i] - locations[j])
                if c <= f:
                    res = (res + dfs(j, f - c)) % MOD
            memo[i][f] = res
            return res

        return dfs(start, fuel)
```

> 💡 两份代码均通过全部官方示例（`4`、`5`、`0`）与 `start == finish`、单城等补充用例，并与**无记忆化路径穷举暴力**对拍 2900 组随机数据（$n \le 4$、$fuel \le 9$，含 `start == finish` 专项），`mismatch = 0`；最大规模 $n = 100$、$fuel = 200$ 下 0.1 秒级完成。

## 8. 边界情况与易错点

1. **「到达 finish 即 return」是最经典的 WA**：直接 `if (i == finish) return 1 + ...` 之外，还要允许从 finish 继续走；正确写法是基项 + 全部移动分支求和。
2. **`start == finish`**：答案含 1 条零步路径，且可能还有折返路径；不要把零步路径漏掉或特殊判死。
3. **记忆化初值用 $-1$**：若用 0 充当「未计算」，正确性不受影响但复杂度爆炸（0 值状态被反复重算），$fuel = 200$、$n = 100$ 时会超时。
4. **油量恰好为 0 的城市**：可以「停在 finish 且 $f = 0$」，`c <= f` 的比较含等号——漏等号会少数恰好耗尽油的路径。
5. **不可达输出 0**（示例 3），无解并非异常，递推自然给出 0。
6. **取模**：加法过程随时 `% MOD`；C++ 注意所有和用 `long long` 接住再截断，避免 `(res + dfs(...))` 在 `int` 上溢出。
7. **「互不相同」是隐藏前提**：它保证每步耗油 $\ge 1$、状态图无环。位置若可重复，则存在 0 耗油的自环转移，递推不再按 $f$ 分层，需要把「同位置城市」合并或对 0 边 SCC 处理。
