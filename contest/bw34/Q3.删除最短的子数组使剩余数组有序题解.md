# LeetCode 删除最短的子数组使剩余数组有序 题解

## 1. 题目概述

- **标题 / 题号**：删除最短的子数组使剩余数组有序（#1574，medium）
- **链接**：https://leetcode.cn/problems/shortest-subarray-to-be-removed-to-make-array-sorted/
- **来源**：LeetCode 第 34 场双周赛 Q3
- **难度**：中等
- **标签**：栈、数组、双指针、二分查找、单调栈

**题意**：给定整数数组 `arr`，可以删除**一个连续子数组**（可以为空，删除后剩余元素保持原相对顺序），目标是使剩余数组**非递减**。求最少需要删除的子数组长度。

**约束**：

- $1 \le arr.length \le 10^5$；
- $0 \le arr[i] \le 10^9$；
- 数组本身可能含有重复元素，非递减允许相等相邻。

## 2. 示例

**示例 1**

```text
输入：arr = [1,2,3,10,4,2,3,5]
输出：3
解释：删除 [10,4,2]，剩 [1,2,3,3,5] 非递减；删除 [3,10,4] 同样是长度 3 的解。
```

**示例 2**

```text
输入：arr = [5,4,3,2,1]
输出：4
解释：严格递减，最多只能保住一个元素，至少删 n-1 = 4 个。
```

**示例 3**

```text
输入：arr = [1,2,3]
输出：0
解释：已经非递减，删除空子数组即可。
```

**示例 4（边界）**

```text
输入：arr = [1]
输出：0
```

## 3. 解题思路

### 3.1 暴力思路：枚举删除区间

枚举删除区间 $[l, r]$（$O(n^2)$ 个），再 $O(n)$ 检查「前缀 + 后缀」拼接后是否非递减，总 $O(n^3)$；用前缀和有序性预处理可把检查降到 $O(1)$，但 $O(n^2)$ 的枚举在 $n = 10^5$ 下仍不可行。优化的线索：**合法方案的形状极度受限**。

### 3.2 核心观察：剩余部分 = 有序前缀 + 有序后缀 + 一条接缝

![保留最长有序前缀与有序后缀，中间夹缝待删](images/bw34_q3_prefix_suffix_junction.svg)

删除一段连续区间后，剩下的必然是**一个前缀** $arr[0..l-1]$ 和**一个后缀** $arr[r..n-1]$ 的拼接。三者约束：

1. **前缀自身非降** ⟺ $l \le left + 1$，其中 $left$ 是「最长非降前缀」的终点（$arr[0..left]$ 有序、$arr[left] > arr[left+1]$ 是第一个下降点）；
2. **后缀自身非降** ⟺ $r \ge right$，其中 $right$ 是「最长非降后缀」的起点；
3. **接缝** $arr[l-1] \le arr[r]$（$l = 0$ 或 $r = n$ 表示前后缀为空，天然满足）。

要删除的长度为 $r - l$（保留 $l + (n - r)$ 个），所以**固定 $r$ 时 $l$ 越大越优**；而随着 $r$ 从 $right$ 向 $n-1$ 增大，$arr[r]$ 单调不减（后缀本身非降），故最大的可行 $l$ 关于 $r$ **单调不减**——这正是双指针能一次线性扫描的原因。

### 3.3 算法流程：双指针

![双指针流程：右端扩张、左端跟进、三种保留方案取最小](images/bw34_q3_two_pointer_flow.svg)

```text
1. right ← 从 n-1 向左，找最长非降后缀起点（arr[right..n-1] 有序）
2. 若 right == 0：整体已非降，返回 0
3. left ← 从 0 向右，找最长非降前缀终点（arr[0..left] 有序）
4. ans = min(right, n-1-left)          # 方案A只留后缀(删前段) / 方案B只留前缀(删尾段)
5. l = 0
6. 对 r = right..n-1：                 # 双指针：后缀起点右移，l 只前进不后退
       while l ≤ left 且 arr[l] ≤ arr[r]：l++
       ans = min(ans, r - l)           # 保留 arr[0..l-1] + arr[r..n-1]
7. 返回 ans
```

### 3.4 示例演算

![示例 1 的双指针演算表](images/bw34_q3_walkthrough.svg)

以 $arr = [1,2,3,10,4,2,3,5]$ 为例：$left = 3$（前缀 $[1,2,3,10]$）、$right = 5$（后缀 $[2,3,5]$）。方案 A/B 给出 $\min(5, 4) = 4$。双指针：$r = 5$（$arr[5] = 2$）时 $l$ 推进到 2（$arr[2] = 3 > 2$ 停），$ans = 5 - 2 = 3$；$r = 6$（值 3）时 $l$ 推到 3（$arr[3] = 10 > 3$ 停），$ans = 3$；$r = 7$（值 5）时 $l$ 停在 3，$7 - 3 = 4$ 不更新。最终 $3$ ✓。

## 4. 算法细节

1. **先求两个「最长有序段」**：两趟独立扫描即可；若 $right = 0$ 说明整体有序，直接返回 0——这也是「删除空子数组」情形的唯一入口。
2. **两个「退化方案」别忘了初始化**：只保留后缀（删除 $[0, right-1]$，长 $right$）与只保留前缀（删除 $[left+1, n-1]$，长 $n-1-left$）。双指针循环里 $r$ 只到 $n-1$（后缀非空），覆盖不了「后缀为空」的方案 B。
3. **`l ≤ left` 是 while 的硬边界**：保留的前缀不能超过最长有序前缀，否则前缀自身先乱。$l$ 最大能到 $left+1$（整段有序前缀全留）。
4. **单调性正确性**：$arr[r]$ 随 $r$ 增大非降，故「$arr[l] \le arr[r]$ 的最大 $l$」不减；双指针总体每个元素被左右指针各扫一遍，$O(n)$。
5. **为什么不会枚举出负长度**：存在下降点时必有 $left + 1 \le right$（若 $left \ge right$ 则前后有序段重叠、整体有序），故 $l \le left + 1 \le right \le r$，$r - l \ge 0$。
6. **二分替代**：固定 $r$ 求「前缀里 $\le arr[r]$ 的最长有序段」也可以对有序前缀二分（$O(n \log n)$）；既然前缀非降，二分与双指针等价，双指针更优。

## 5. 正确性证明

**引理 1（方案刻画）**：删除区间 $[l, r]$（$0 \le l \le r \le n-1$；另允许 $l = r$ 的「空」按题意单列）后剩余非降，当且仅当 $arr[0..l-1]$ 非降、$arr[r..n-1]$ 非降且（$l > 0$ 且 $r < n$ 时）$arr[l-1] \le arr[r]$。等价地：$l \le left + 1$，$r \ge right$，接缝条件成立。

**证明**：剩余序列是前缀与后缀的顺序拼接；拼接序列非降 ⟺ 每个内部相邻对不降。前缀内部的对、后缀内部的对分别给出两段有序；唯一的跨界相邻对是 $arr[l-1], arr[r]$（前缀与后缀都非空时）。前缀非降的充要条件是 $l - 1 \le left$（$left$ 定义为最长有序前缀的终点下标：$arr[0..left]$ 有序而 $arr[0..left+1]$ 不序；若 $l - 1 > left$ 则 $arr[0..l-1]$ 含下降点，反之必有序）。后缀同理给出 $r \ge right$。∎

**引理 2（单调性）**：对 $r \ge right$，令 $L(r) = \max\{\, l \le left + 1 : l = 0 \text{ 或 } arr[l-1] \le arr[r] \,\}$。则 $L(r)$ 关于 $r$ 在 $[right, n-1]$ 上单调不减。

**证明**：$arr[right..n-1]$ 非降，故 $r_1 < r_2 \Rightarrow arr[r_1] \le arr[r_2]$。若 $l$ 在 $L(r_1)$ 的约束集合内，则 $arr[l-1] \le arr[r_1] \le arr[r_2]$，即同一 $l$ 也满足 $r_2$ 的约束集合，最大值只增不减。∎

**定理**：算法返回最优删除长度 $\min \bigl\{ r - l : \text{合法}(l,r) \bigr\}$（空删除合法时为 0）。

**证明**：整体有序时步骤 2 直接返回 0，显然最优。否则枚举覆盖三类合法方案：方案 A（$l = 0, r = right$）即「只留后缀」，在初始化中取 $right$；方案 B（$r = n$，后缀空）即「只留前缀」，在初始化中取 $n - 1 - left$；方案 C（前后缀皆非空）中 $r$ 取遍 $[right, n-1]$、$l$ 取 $L(r)$——固定 $r$ 时删除长度 $r - l$ 随 $l$ 增大而减小，故 $l$ 取 $L(r)$ 是该 $r$ 下的最优，而引理 1 说明 $(L(r), r)$ 合法（$L(r) \le left+1$ 保证前缀有序、$arr[L(r)-1] \le arr[r]$ 保证接缝、$r \ge right$ 保证后缀有序）。双指针按引理 2 的单调性推进 $l$，不会跳过任何 $L(r)$：$l$ 在每个 $r$ 处都推进到约束集合的边界。三类取最小即全局最优。∎

## 6. 复杂度分析

- **时间**：$O(n)$。求 `right`、`left` 各一趟，双指针循环中 $r$ 从 $right$ 走到 $n-1$、$l$ 从 0 走到至多 $left+1$，两端各自单调前进，总步数线性。
- **空间**：$O(1)$ 额外（只存下标与答案，原地完成）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int findLengthOfShortestSubarray(vector<int>& arr) {
        int n = (int)arr.size();
        int right = n - 1;
        while (right > 0 && arr[right - 1] <= arr[right]) --right; // 最长有序后缀起点
        if (right == 0) return 0;                                   // 整体已非降
        int left = 0;
        while (left + 1 < n && arr[left] <= arr[left + 1]) ++left;  // 最长有序前缀终点
        int ans = min(right, n - 1 - left);   // 只留后缀 / 只留前缀
        int l = 0;
        for (int r = right; r < n; ++r) {     // 保留 arr[0..l-1] + arr[r..n-1]
            while (l <= left && arr[l] <= arr[r]) ++l;
            ans = min(ans, r - l);            // 删除 arr[l..r-1]
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def findLengthOfShortestSubarray(self, arr: list[int]) -> int:
        n = len(arr)
        right = n - 1
        while right > 0 and arr[right - 1] <= arr[right]:   # 最长有序后缀起点
            right -= 1
        if right == 0:
            return 0                                        # 整体已非降
        left = 0
        while left + 1 < n and arr[left] <= arr[left + 1]:  # 最长有序前缀终点
            left += 1
        ans = min(right, n - 1 - left)          # 只留后缀 / 只留前缀
        l = 0
        for r in range(right, n):               # 保留 arr[:l] + arr[r:]
            while l <= left and arr[l] <= arr[r]:
                l += 1
            ans = min(ans, r - l)               # 删除 arr[l:r]
        return ans
```

> 💡 两份代码均通过全部官方示例（`3`、`4`、`0`、`0`）与官方 judge 三个大型样例（对独立 $O(n^2)$ 暴力验证期望为 `8`、`15`、`14`），并与**枚举删除区间的 $O(n^3)$ 暴力**对拍 3010 组随机数组（含重复值、全等、已序、全降），`mismatch = 0`。

## 8. 边界情况与易错点

1. **已有序的数组**：`right == 0` 必须最先判，返回 0（空删除）；漏判会让后面的下标逻辑白算甚至出错。
2. **全降数组**：`left = 0`、`right = n-1`，答案 $n-1$——只能保住一个元素；不要想当然地输出 $n$。
3. **两个退化方案的初始化**：双指针循环只覆盖「前后缀都非空」的拼接，只留前缀（$r = n$）与只留后缀（$l = 0$）必须单独进 `ans`，这是最常见 WA 点。
4. **相等元素**：非降比较用 `<=`；写成 `<` 会把 `[2,2,2]` 当成「必须删除」的数组。
5. **`l ≤ left` 的边界**：`l` 可以越过 `left` 吗？不行——保留超过最长有序前缀的前缀必然内部出降。`l` 最大恰好等于 `left + 1`（全部有序前缀保留）。
6. **不要输出「保留长度」**：题目要的是删除长度 $r - l$，方向别搞反。
7. **数据规模**：$arr[i] \le 10^9$ 用 `int` 即可，全程只有比较没有求和，无溢出。
