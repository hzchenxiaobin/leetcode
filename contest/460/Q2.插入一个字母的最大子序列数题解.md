# LeetCode 插入一个字母的最大子序列数 题解

## 1. 题目概述

- **标题 / 题号**：插入一个字母的最大子序列数（#3628，medium）
- **链接**：https://leetcode.cn/problems/maximum-number-of-subsequences-after-one-inserting/
- **来源**：LeetCode 第 460 场周赛 Q2
- **难度**：中等
- **标签**：贪心、字符串、动态规划、前缀和

**题意**：给定一个仅含大写字母的字符串 `s`，允许在**任意位置**（含开头、结尾）**最多插入一个**大写字母。返回插入后字符串中 `"LCT"` **子序列**数量的最大值。

**约束**：

- `1 <= s.length <= 10^5`
- `s` 仅由大写英文字母组成

## 2. 示例

**示例 1**

```text
输入：s = "LMCT"
输出：2
解释：开头插入 'L' 得 "LLMCT"，两个 LCT 子序列分别位于下标 [0,3,4] 与 [1,3,4]
```

**示例 2**

```text
输入：s = "LCCT"
输出：4
解释：开头插入 'L' 得 "LLCCT"，含 [0,2,4]、[0,3,4]、[1,2,4]、[1,3,4] 共 4 个 LCT 子序列
```

**示例 3**（无法凑出模式）

```text
输入：s = "L"
输出：0
解释：只插入一个字母不可能凑出完整的 "LCT"
```

**补充示例**（中间插入是唯一解）

```text
输入：s = "LT"
输出：1
解释：在 L 和 T 之间插入 'C' 得 "LCT"，恰好 1 个子序列；插在两端均为 0
```

## 3. 解题思路

### 3.1 暴力思路

枚举插入位置（$n+1$ 个）× 插入字符（$26$ 种，外加"不插"），每次用 $O(n)$ 的 DP 重新统计 `"LCT"` 子序列数。总复杂度 $O(26 \cdot n^2) \approx 2.6 \times 10^{11}$（$n = 10^5$），必然超时。必须利用「只插入一个字符」的结构性。

### 3.2 核心观察：拆成「原有 + 新增」，插入字符必居 L/C/T 三角之一

![三种插入角色及增益](images/wc460_q2_three_insert_cases.svg)

**关键洞察**：插入一个字符**不会破坏**任何原有子序列——`s` 的子序列仍是新串的子序列。于是

$$\text{总数} = \underbrace{\text{原串中 LCT 子序列数}}_{c_{LCT}} + \text{新增数}$$

而**新增的子序列必须用到插入的那个字符**，所以插入的字符只能是 `L`、`C` 或 `T`（插其他字母新增为 $0$）。三种角色各有最优摆法：

| 插入字符 | 最优位置 | 新增数 |
|----------|----------|--------|
| `L` | **最前**（队头角色越靠前越好） | 原串中 `"CT"` 子序列数 $c_{CT}$ |
| `C` | **要挑**（见 3.3） | 插入点前的 `L` 数 $\times$ 插入点后的 `T` 数 |
| `T` | **最后**（队尾角色越靠后越好） | 原串中 `"LC"` 子序列数 $c_{LC}$ |

> ⚠️ **本题最大的陷阱**：模式长度为 3，`C` 插在**中间**且位置需要枚举——这与熟题「2207. 字符串中最多数目的子序列」（模式长度 2，只需考虑两端）的思维定式直接冲突。`s = "LT"` 时两端插入收益均为 $0$，只有中间插 `C` 才能得到答案 $1$。

### 3.3 算法流程：两趟线性扫描

**第一趟（从左到右，链式计数 DP）**：一趟同时数出 $c_{LC}$、$c_{LCT}$、$c_{CT}$——

- 遇 `L`：$c_L \mathrel{+}= 1$
- 遇 `C`：$c_C \mathrel{+}= 1$，$c_{LC} \mathrel{+}= c_L$
- 遇 `T`：$c_{LCT} \mathrel{+}= c_{LC}$，$c_{CT} \mathrel{+}= c_C$

**第二趟（枚举插入 `C` 的位置）**：设 $preL(p)$ 为 $s[0..p)$ 中 `L` 的个数、$sufT(p)$ 为 $s[p..n)$ 中 `T` 的个数，则

$$\text{中间增益} = \max_{0 \le p \le n}\ preL(p) \times sufT(p)$$

先数出 `T` 的总数，再从左向右扫：每处理完一个字符就更新 $preL$ / $sufT$（遇 `L` 则 $preL{+}{=}1$，遇 `T` 则 $sufT{-}{=}1$），扫描途中与结束时各取一次乘积最大值（覆盖 $p = 0 \dots n$ 全部 $n+1$ 个插入点）。

![枚举插入点最大化前缀L乘后缀T](images/wc460_q2_prefix_suffix_product.svg)

### 3.4 示例演算

![LCCT完整演算](images/wc460_q2_example_walkthrough.svg)

以 `s = "LCCT"` 为例：第一趟得 $c_{LCT} = 2$、$c_{LC} = 2$、$c_{CT} = 2$；第二趟得中间插 `C` 增益最多 $1 \times 1 = 1$。三种增益取最大值 $2$，答案 $= 2 + \max(2, 1, 2) = 4$。

再看关键边界 `s = "LT"`：$c_{LCT} = c_{LC} = c_{CT} = 0$，但 $p = 1$ 处 $preL \times sufT = 1 \times 1 = 1$，答案为 $1$——收益全部来自中间插入。

## 4. 算法细节

1. **链式计数 DP**：`"LCT"` 是按 `L → C → T` 顺序的固定模式，计数方法是经典的「序列自动机计数」：三个计数器 $c_L \to c_{LC} \to c_{LCT}$ 逐字符单向更新（当前字符只会触发一个分支，无顺序歧义）。$c_{CT}$ 用同样的方式（$c_C \to c_{CT}$）在同一趟里并行维护。
2. **$sufT$ 的递推**：不需要后缀数组——先数出 `T` 总数，向右扫描时每遇到一个 `T` 就减一，即可在 $O(1)$ 空间内同步维护 $preL$ 与 $sufT$。
3. **插入点枚举含两端**：循环内「先取乘积再移动指针」对应 $p = 0 \dots n-1$，循环结束后再补一次对应 $p = n$（插在末尾）。
4. **汇总公式**：

$$\text{答案} = c_{LCT} + \max\bigl(c_{CT},\ c_{LC},\ \max_{0 \le p \le n} preL(p) \times sufT(p)\bigr)$$

## 5. 正确性证明

**引理 1（可分解性）**：在 $s$ 的位置 $p$ 插入字符 $x$ 后，`"LCT"` 子序列总数 $= c_{LCT} + N_x(p)$，其中 $N_x(p)$ 是**含插入字符**的 `"LCT"` 子序列个数。

**证明**：$s$ 的任意子序列按原相对顺序嵌入新串，仍是新串的子序列，故原有 $c_{LCT}$ 个全部保留。反之，新串中不使用插入字符的 `"LCT"` 子序列，其三个字符均来自 $s$ 且保持原序，恰是 $s$ 的一个 `"LCT"` 子序列，已被计入 $c_{LCT}$。两部分不重不漏。∎

**引理 2（各角色的增益公式）**：设插入字符为 $x$、位置为 $p$（插在 $s[p]$ 之前，$p = n$ 表示末尾），则

- (a) $x = \texttt{L}$：$N_x(p) = $ $s[p..n)$ 中 `"CT"` 子序列数，在 $p = 0$ 时取最大值 $c_{CT}$；
- (b) $x = \texttt{T}$：$N_x(p) = $ $s[0..p)$ 中 `"LC"` 子序列数，在 $p = n$ 时取最大值 $c_{LC}$；
- (c) $x = \texttt{C}$：$N_x(p) = preL(p) \times sufT(p)$；
- (d) $x \notin \{\texttt{L},\texttt{C},\texttt{T}\}$：$N_x(p) = 0$。

**证明**：(c) 含插入 `C` 的 `"LCT"` 子序列中，`C` 角色由插入字符担任，`L` 必须取自 $s[0..p)$、`T` 必须取自 $s[p..n)$。任取一个前缀 `L`（$preL(p)$ 种）与一个后缀 `T`（$sufT(p)$ 种），与插入的 `C` 恰好组成一个合法的新子序列；反之每个新子序列唯一确定这样一个有序对。这是双射，故 $N_x(p) = preL(p) \times sufT(p)$。(a)、(b) 同理：`L` 角色由插入字符担任时，`C` 与 `T` 都须取自后缀，且最优位置在端点（$s[p..n)$ 中 `"CT"` 子序列数随 $p$ 增大不增，$p=0$ 时即全串计数 $c_{CT}$；$s[0..p)$ 中 `"LC"` 子序列数随 $p$ 增大不减，$p=n$ 时即 $c_{LC}$）。(d) 此时插入字符无法在 `"LCT"` 中扮演任何角色，含它的子序列不存在。∎

**定理**：答案 $= c_{LCT} + \max\bigl(c_{CT},\ c_{LC},\ \max_{0 \le p \le n} preL(p) \times sufT(p),\ 0\bigr)$。

**证明**：「最多插入一个」的决策空间是 $\{$不插$\} \cup \{(\text{位置}, \text{字符})\}$。由引理 1，只需最大化 $N_x(p)$ 再加上 $c_{LCT}$。对 $x$ 分类：$x \notin \{\texttt{L},\texttt{C},\texttt{T}\}$ 时增益 $0$，与不插等价，由 $\max$ 中的常数 $0$ 覆盖；$x = \texttt{L},\texttt{C},\texttt{T}$ 时由引理 2，三类各自的最大增益为 $c_{CT}$、$\max_p preL(p) \times sufT(p)$、$c_{LC}$。三者取最大即得。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。第一趟链式计数与第二趟插入点枚举均为单次线性扫描，每个字符 $O(1)$ 分支更新；$n \le 10^5$ 轻松通过。
- **空间复杂度**：$O(1)$ 额外空间（不计输入串），只维护常数个计数器；无需前缀/后缀数组。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long numOfSubsequences(string s) {
        long long cL = 0, cLC = 0, cLCT = 0;
        long long cC = 0, cCT = 0;
        for (char ch : s) {
            if (ch == 'L') {
                cL++;
            } else if (ch == 'C') {
                cC++;
                cLC += cL;
            } else if (ch == 'T') {
                cLCT += cLC;
                cCT += cC;
            }
        }
        long long best = max(cCT, cLC);
        long long preL = 0, sufT = count(s.begin(), s.end(), 'T');
        for (char ch : s) {
            best = max(best, preL * sufT);   // 插在当前字符之前
            if (ch == 'L') preL++;
            else if (ch == 'T') sufT--;
        }
        best = max(best, preL * sufT);       // 插在末尾
        return cLCT + best;
    }
};
```

### Python

```python
class Solution:
    def numOfSubsequences(self, s: str) -> int:
        cL = cLC = cLCT = 0
        cC = cCT = 0
        for ch in s:
            if ch == 'L':
                cL += 1
            elif ch == 'C':
                cC += 1
                cLC += cL
            elif ch == 'T':
                cLCT += cLC
                cCT += cC

        best = max(cCT, cLC)
        preL = 0
        sufT = s.count('T')
        for ch in s:
            best = max(best, preL * sufT)    # 插在当前字符之前
            if ch == 'L':
                preL += 1
            elif ch == 'T':
                sufT -= 1
        best = max(best, preL * sufT)        # 插在末尾
        return cLCT + best
```

## 8. 边界情况与易错点

1. **溢出**：$c_{LCT}$ 最大约 $(n/3)^3 \approx 3.7 \times 10^{13}$，$c_{CT}$、$c_{LC}$ 与乘积 $preL \times sufT$ 最大约 $(n/2)^2 = 2.5 \times 10^9$，均远超 32 位 `int`，**C++ 必须用 `long long`**（Python 任意精度整数无虞）。
2. **漏掉中间插 `C`**：本题头号陷阱。`s = "LT"` 答案为 $1$，只考虑「两端插入」会误得 $0$。长度为 3 的模式与长度为 2 的套路本质不同。
3. **「最多插入一个」**：允许不插。三种增益均非负，$\max$ 中无需显式比较 $0$ 也不影响结果（全为 $0$ 时插不插答案相同）。
4. **插非 L/C/T 字母无收益**：暴力枚举 26 个字母可以不用——增益恒为 $0$。
5. **插入点枚举的两端**：循环结束后要补上 $p = n$（插在末尾）的情况；$p = 0$（插在开头）由循环第一次取值覆盖。
6. **最小规模 $n = 1$**：三种增益全为 $0$，答案为 $0$，公式自然覆盖，无需特判。
