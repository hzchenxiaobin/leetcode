# LeetCode 中位数之和的最大值 题解

## 1. 题目概述

- **标题 / 题号**：中位数之和的最大值（#3627，medium）
- **链接**：https://leetcode.cn/problems/maximum-median-sum-of-subsequences-of-size-3/
- **来源**：LeetCode 第 460 场周赛 Q1
- **难度**：中等
- **标签**：贪心、排序、数组

**题意**：给定长度为 3 的倍数的数组 `nums`，每次操作从中任选 3 个元素，将它们的**中位数**计入得分并移除。重复直到数组清空（即把整个数组划分成 $k = n/3$ 个三元组）。返回中位数之和的**最大值**。

**约束**：

- `1 <= nums.length <= 5 * 10^5`
- `nums.length % 3 == 0`
- `1 <= nums[i] <= 10^9`

## 2. 示例

**示例 1**

```text
输入：nums = [2,1,3,2,1,3]
输出：5
解释：选 (1,3,3) → 中位数 3；再选 (1,2,2) → 中位数 2，合计 5
```

**示例 2**

```text
输入：nums = [1,1,10,10,10,10]
输出：20
解释：选 (1,10,10) → 中位数 10；再选 (1,10,10) → 中位数 10，合计 20
```

**示例 3**（最小规模）

```text
输入：nums = [1,2,3]
输出：2
解释：只有一个三元组，中位数就是排序后的中间元素 2
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有「划分成三元组」的方案，取各组中位数之和的最大值。划分数为 $\frac{n!}{(3!)^k \cdot k!}$，$n=12$ 时已有 $15400$ 种，$n$ 到 $10^5$ 量级完全不可行。必须找结构性结论。

### 3.2 核心观察：排序后从第二大开始「隔一个取一个」

![排序后隔一个取一个选中位数](images/wc460_q1_sorted_selection.svg)

**直觉**：想让中位数尽量大，但每个中位数所在的三元组里必须还有一个**不小于它的元素**（组内最大值）「护驾」。因此**最大的 $k$ 个元素不能全部当中位数**——最大的元素 $a[n-1]$ 永远只能当配角。

**结论**：将数组升序排序后，答案为

$$a[n-2] + a[n-4] + \cdots + a[n-2k]$$

即**从倒数第二个开始，往前每隔一个取一个**，共 $k = n/3$ 个（下标 $n-2, n-4, \dots, k$）。

> ⚠️ 反例说明为什么不能贪取最大 $k$ 个：`[1,2,3,4,5,6]` 若想让 $\{5,6\}$ 都当中位数不可行——$6$ 的组内还需要一个 $\ge 6$ 的元素，不存在；正确答案是 $5 + 3 = 8$。

### 3.3 构造：每组 = 最小值 + 中位数 + 最大值

![三元组构造：小+中+大](images/wc460_q1_triple_pairing.svg)

按上述方式选中位数后，构造方案把升序排序后的元素分成两段：

- 下标 $k \sim n-1$ 的 $2k$ 个元素**两两相邻配对**：第 $j$ 组取 $a[n-2j]$ 当**中位数**，配上它右侧紧邻的 $a[n-2j+1]$ 当**最大值**
- 从前 $k$ 小（下标 $0 \sim k-1$）中拿 $a[k-j]$ 当**最小值**垫脚

由 $a[k-j] \le a[n-2j] \le a[n-2j+1]$，第 $j$ 组的中位数恰为 $a[n-2j]$，恰好达到上界。

### 3.4 示例演算

![示例一步演算](images/wc460_q1_example_walkthrough.svg)

`nums = [2,1,3,2,1,3]`，$n=6$，$k=2$，排序后 $a = [1,1,2,2,3,3]$：

| 组 $j$ | 最小值 | 中位数 | 最大值 | 组中位数 |
|--------|--------|--------|--------|----------|
| $j=1$ | $a[1]=1$ | $a[4]=3$ | $a[5]=3$ | 3 |
| $j=2$ | $a[0]=1$ | $a[2]=2$ | $a[3]=2$ | 2 |

答案 $= 3 + 2 = 5$。

## 4. 算法细节

1. **排序**：升序排序，$O(n \log n)$。
2. **取数**：从 $i = n-2$ 开始每次 $i \gets i - 2$，累加 $a[i]$，直到 $i < k = n/3$。由 $n - 2k = k$ 知循环恰好取到 $a[n-2], a[n-4], \dots, a[k]$，且 $k$ 与 $n$ 同奇偶，步长 2 的边界天然对齐。
3. **求和类型**：用 `long long`（见 §8 溢出分析）。

## 5. 正确性证明

**引理 1（上界）**：任意划分方案中，把 $k$ 个中位数降序排列为 $m_1 \ge m_2 \ge \cdots \ge m_k$，则 $m_j \le a[n-2j]$。

**证明**：考虑中位数最大的 $j$ 个三元组。每组中，**中位数本身**与**组内最大值**是两个互不相同的元素，且都 $\ge$ 该组中位数 $\ge m_j$。$j$ 组共 $2j$ 个**互不相同**的元素 $\ge m_j$，故 $m_j$ 不超过全数组第 $2j$ 大的元素，即升序排序后的 $a[n-2j]$。∎

**定理**：中位数之和的最大值为 $\sum_{j=1}^{k} a[n-2j]$。

**证明**：由引理 1，任意方案之和 $\le \sum_{j=1}^{k} a[n-2j]$。再证可达：构造第 $j$ 组（$j = 1, \dots, k$）为 $\{a[k-j],\ a[n-2j],\ a[n-2j+1]\}$。这些下标恰好覆盖 $0 \sim n-1$ 各一次：$n-2j$ 与 $n-2j+1$（$j=1..k$）覆盖 $k \sim n-1$，$k-j$ 覆盖 $0 \sim k-1$。又 $k - j \le n - 2j$ 等价于 $j \le 2k$，显然成立，故 $a[k-j] \le a[n-2j] \le a[n-2j+1]$，每组中位数恰为 $a[n-2j]$，之和达到上界。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \log n)$，排序主导；取数遍历为 $O(n)$。$n \le 5 \times 10^5$ 下轻松通过。
- **空间复杂度**：$O(\log n) \sim O(n)$，取决于语言的排序实现（C++ `std::sort` 仅 $O(\log n)$ 栈空间；Python 的 Timsort 需要 $O(n)$ 辅助空间）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long maximumMedianSum(vector<int>& nums) {
        sort(nums.begin(), nums.end());
        long long ans = 0;
        int n = nums.size(), k = n / 3;
        for (int i = n - 2; i >= k; i -= 2) {
            ans += nums[i];
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maximumMedianSum(self, nums: List[int]) -> int:
        nums.sort()
        n = len(nums)
        return sum(nums[i] for i in range(n - 2, n // 3 - 1, -2))
```

## 8. 边界情况与易错点

1. **最小规模 $n = 3$**：只有一个三元组，答案就是排序后的中间元素 $a[1]$，公式循环 $i$ 从 $1$ 取到 $k=1$ 自然覆盖。
2. **溢出**：$k$ 最多约 $1.7 \times 10^5$ 个中位数，每个可达 $10^9$，总和约 $1.7 \times 10^{14}$，**必须用 `long long`**（32 位 `int` 会溢出；Python 任意精度整数无需担心）。
3. **循环边界**：条件是 `i >= k`（不是 `i > k`），最后一个取的是 $a[k]$；由于 $n-2j$ 与 $n$ 同奇偶、$k = n - 2k$ 也与 $n$ 同奇偶，步长 2 的循环恰好落在 $k$ 上，不会错过也不会越界。
4. **经典错误**：直接取最大的 $k$ 个元素当中位数。`[1,2,3,4,5,6]` 会误算 $6 + 5 = 11$，实际上 $6$ 无法成为中位数，正确答案为 $8$。
5. **排序方向**：升序排序后从右侧「倒数第二个往前隔一取一」；若降序排序，则等价地取下标 $1, 3, 5, \dots, 2k-1$。
