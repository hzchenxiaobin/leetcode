# LeetCode 不含连续1的非负整数 题解

## 1. 题目概述

- **标题 / 题号**：不含连续1的非负整数（#600，hard）
- **链接**：https://leetcode.cn/problems/non-negative-integers-without-consecutive-ones/
- **来源**：LeetCode 第 34 场周赛 Q4
- **难度**：困难
- **标签**：动态规划（Dynamic Programming）、数位 DP、斐波那契数列

**题意**：给定正整数 $n$，统计区间 $[0, n]$ 中有多少个整数，其**二进制表示**里不出现连续的 `1`（即不存在相邻两位同时为 `1`）。注意 $0$ 的二进制是 `0`，视为合法。

**约束**：

- $1 \le n \le 10^9$，因此 $n$ 的二进制长度不超过 $30$ 位
- 答案在 `int` 范围内（$n=10^9$ 时答案约 $2.2 \times 10^6$）

## 2. 示例

**示例 1**

```text
输入：n = 5
输出：5
解释：0~5 的二进制表示为
  0 : 0      ✓
  1 : 1      ✓
  2 : 10     ✓
  3 : 11     ✗ 含连续 1
  4 : 100    ✓
  5 : 101    ✓
只有 3 违规，其余 5 个满足，答案为 5。
```

**示例 2**

```text
输入：n = 1
输出：2
解释：0(0)、1(1) 都合法。
```

**示例 3**

```text
输入：n = 2
输出：3
解释：0(0)、1(1)、2(10) 都合法。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的做法是从 $0$ 枚举到 $n$，对每个数取二进制串并检查是否有 `11`：单个数检查 $O(\log n)$，总计 $O(n \log n)$。$n = 10^9$ 时约 $3 \times 10^{10}$ 次位运算，**必然超时**。

换一种暴力：枚举所有长度不超过 $30$ 的二进制串再筛掉含 `11` 的——候选有 $2^{30} \approx 1.07 \times 10^9$ 个，同样是 $10^9$ 量级。

暴力的根本问题是**把每个合法的数都单独列了出来**。而本题只问个数，于是自然想到：能不能把「一段自由低位」的合法数一次性算清？这正是数位 DP（按位计数）的出发点。

### 3.2 核心观察：自由低位的个数是斐波那契数

![按末两位分类得到斐波那契递推](images/wc34_q4_fibonacci_strings.svg)

定义 $f[i]$ 为**长度为 $i$ 的自由二进制串**（允许前导 $0$、不含连续 `1`）的个数。按末位分类：

- 末位取 `0`：前 $i-1$ 位只需自身合法，共 $f[i-1]$ 种；
- 末位取 `1`：倒数第二位被迫取 `0`，即末两位固定为 `01`，剩下 $i-2$ 位自由，共 $f[i-2]$ 种。

于是

$$f[i] = f[i-1] + f[i-2], \qquad f[0] = 1,\quad f[1] = 2$$

即 $f[i] = F(i+2)$（斐波那契数），前几项是 $1, 2, 3, 5, 8, 13, 21, \dots$，增长约为 $\varphi^i$（$\varphi \approx 1.618$）。

**第二个观察（按「最高不同位」划分）**：把 $n$ 的二进制写成 $n_{m}n_{m-1}\dots n_0$。任何 $y < n$ 都存在唯一的**最高不同位** $i$：$y$ 在 $i$ 位以上与 $n$ 完全相同、第 $i$ 位为 $0$ 而 $n_i = 1$。此时低 $i$ 位完全自由，若高位前缀本身不含 `11`，那么这 $i$ 位自由位的合法取法恰为 $f[i]$ 种——**一整块答案被 $f[i]$ 一次算出**。

两个观察拼起来，只需从高位到低位扫一遍 $n$ 的二进制位，就能把答案拆成若干个 $f[i]$ 之和。

### 3.3 算法流程

![从高位到低位的数位扫描流程](images/wc34_q4_digit_scan_flow.svg)

维护两个量：`ans`（已统计的严格小于 $n$ 的合法数）与 `prev`（$n$ 的**上一位**是否为 `1`）。从最高位 $i=30$ 扫到 $i=0$：

1. 若 $n_i = 0$：本位只能照抄 `0`，令 `prev = 0`，继续；
2. 若 $n_i = 1$：先把本位**改成 `0`**，低 $i$ 位自由，贡献 `ans += f[i]`；
   - 若 `prev = 1`：本位若继续跟 `1` 就出现 `11`，而所有合法的 $y < n$ 都已在前面统计完，直接 `return ans`；
   - 否则令 `prev = 1`，继续；
3. 扫描正常结束（说明 $n$ 自身也不含连续 `1`）：`return ans + 1`，把 $n$ 本身补上。

> 💡 顺序极重要：**先** `ans += f[i]`，**再**判断 `prev`。因为「本位放 0」这一分支与 `prev` 无关（本位为 `0` 天然隔断了与上一位的关系），永远合法。

### 3.4 示例演算

![n = 5 的逐位演算与 0~5 合法性检查](images/wc34_q4_walkthrough.svg)

以 $n = 5 = (101)_2$ 为例（$f = [1,2,3,5,\dots]$）：

| 步骤 | 位 $i$ | $n_i$ | `prev` | 动作 | `ans` |
|------|--------|-------|--------|------|-------|
| 1 | 2 | 1 | 0 | `ans += f[2] = 3`（低位自由：`000`、`001`、`010`） | 3 |
| 2 | 1 | 0 | 1 | `prev ← 0`，照抄 `0` | 3 |
| 3 | 0 | 1 | 0 | `ans += f[0] = 1`（对应 `100`） | 4 |
| 结束 | — | — | 1 | `return ans + 1 = 5`（补上 `101` 自身） | 5 |

`ans = 4` 覆盖了 $\{0,1,2,4\}$，再加 $n = 5$ 本身，共 $5$ 个，与暴力枚举一致。

再看一个**会提前返回**的例子 $n = 3 = (11)_2$：

| 步骤 | 位 $i$ | $n_i$ | `prev` | 动作 | `ans` |
|------|--------|-------|--------|------|-------|
| 1 | 1 | 1 | 0 | `ans += f[1] = 2`（低位自由：`00`、`01`） | 2 |
| 2 | 0 | 1 | 1 | `ans += f[0] = 1`（对应 `10`），因 `prev = 1` → `return ans = 3` | 3 |

$3 = 11_2$ 自身非法，故不再补加 $1$，答案 $3$（即 $0,1,2$），正确。

## 4. 算法细节

1. **预处理 $f$**：$f[0]=1,\ f[1]=2$，递推至 $i = 30$（$n < 2^{30}$，最高位下标 $29$，多算一位做冗余）。数组开到 $32$ 足够。
2. **位扫描方向**：必须**从高位到低位**。低位决定的只是「能否取 `1`」，而「$y < n$」的判定由最高不同位决定，故高位优先。
3. **`prev` 的语义**：它是 $n$ 的**上一位**（更高位），而不是 $y$ 当前前缀的上一位。因为在「继续贴住 $n$」的主干路径上，二者始终相同。
4. **先加后判，且累加不能挂条件**：`ans += f[i]` 与 `prev` 检查是两条独立语句，顺序先加后判。若写成 `if (prev == 0) ans += f[i];`，那么 `prev = 1`（随后立即返回）的那一位就整块漏掉——例如 $n = (110)_2 = 6$，正确累加 $f[2] + f[1] = 3 + 2 = 5$（对应 $0,1,2,4,5$），错误写法只得到 $3$。
5. **终止条件**：`prev = 1` 且 $n_i = 1$ 时立即返回，且**不要**再 `+1`——因为 $n$ 本身含 `11`，不合法。
6. **答案上界**：所有合法数的个数不超过 $f[30] = 2178309$，`int` 足够；即使 $n$ 放宽到 $2^{31}-1$，答案也只有 $f[31] = 3524578$，仍在 `int` 内，只有到 $2^{63}$ 量级才需要换 `long long`。
7. **Python 的切片/字符串做法不必要**：直接位运算 `(n >> i) & 1` 即可，避免 `bin(n)` 字符串操作带来的常数与下标换算错误。

## 5. 正确性证明

**引理 1（递推）**：对 $i \ge 2$，$f[i] = f[i-1] + f[i-2]$，其中 $f[0]=1$、$f[1]=2$。

**证明**：设 $A_i$ 为长度 $i$、不含连续 `1` 的二进制串集合。按末位分类：末位为 `0` 的串与 $A_{i-1}$ 一一对应（去掉末位），共 $f[i-1]$ 个；末位为 `1` 的串倒数第二位必为 `0`，去掉末两位 `01` 后与 $A_{i-2}$ 一一对应，共 $f[i-2]$ 个。两类互不相交且覆盖 $A_i$，由加法原理得证。∎

**引理 2（分块计数）**：设扫描到位置 $i$ 时，$n$ 的高于 $i$ 的位构成的前缀不含连续 `1` 且 $n_i = 1$。令
$$S_i = \{\, y \in [0, n-1] : y \text{ 的高于 } i \text{ 的位等于 } n \text{ 的对应位},\ y_i = 0 \,\}$$
则 $S_i$ 中不含连续 `1` 的数恰有 $f[i]$ 个。

**证明**：$y \in S_i$ 的高位前缀固定（由题设不含 `11`），$y_i = 0$，低 $i$ 位可取任意 $i$ 位二进制串。由于 $y_i = 0$ 隔断，$y$ 合法当且仅当低 $i$ 位内部不含 `11`，其取法数由 $f$ 的定义即 $f[i]$。不同的低 $i$ 位取值给出不同的 $y$，故恰为 $f[i]$ 个。∎

**引理 3（不重不漏）**：每个 $y \in [0, n-1]$ 恰属于一个 $S_i$。

**证明**：因 $y < n$，$y$ 与 $n$ 一定在某位不同。取最高不同位 $i$：$i$ 位以上相同，且 $y_i < n_i$。若 $n_i = 0$ 则 $y_i < 0$ 不可能，故 $n_i = 1$ 且 $y_i = 0$，即 $y \in S_i$，存在性得证。唯一性：最高不同位由 $y$ 唯一确定，故不同 $i$ 的 $S_i$ 互不相交。∎

**引理 4（提前终止正确）**：若在位置 $i$（$n_i = 1$ 且 `prev` $= 1$，即 $n_{i+1} = 1$）处返回，则所有合法的 $y < n$ 已被 `ans` 统计完。

**证明**：设 $y < n$ 合法，其最高不同位为 $j$（由引理 3，$y \in S_j$）。若 $j > i$，扫描到 $j$ 时已累加；若 $j = i$，则恰在本次 `ans += f[i]` 中计入；若 $j < i$，则 $y$ 与 $n$ 在 $i, i+1$ 两位上都相同且均为 `1`，故 $y$ 含连续 `1`，与合法性矛盾。因此无遗漏。∎

**定理**：算法返回值等于 $[0, n]$ 中二进制表示不含连续 `1` 的整数个数。

**证明**：分两种情形。

1. **未提前返回**：说明扫描途中从未出现相邻两位同时为 `1`，即 $n$ 自身合法。由引理 3，$[0, n-1]$ 被划分为互不相交的 $S_i$ 之并；由引理 2，对每个满足 $n_i = 1$ 的下标（且此时高位前缀无 `11`，因为扫描未终止）累加 $f[i] = \lvert S_i \text{ 中的合法数}\rvert$。故 `ans` 恰为 $[0, n-1]$ 的合法数个数，`ans + 1` 补上合法的 $n$，即为 $[0,n]$ 的结果。
2. **提前返回**：由引理 4，`ans` 已包含全部合法的 $y < n$；又 $n$ 在 $i, i+1$ 两位皆为 `1`，自身非法不应计入，故返回 `ans` 正确。∎

## 6. 复杂度分析

- **时间**：$O(\log n)$。预处理 $f$ 只需常数次加法（$31$ 次，与 $n$ 无关）；主循环对 $n$ 的每一位做 $O(1)$ 操作，位长为 $\lfloor \log_2 n \rfloor + 1 \le 30$。总计约 $60$ 次基本运算。
- **空间**：$O(\log n)$，仅一个长度 $32$ 的数组 `f`（可视为 $O(1)$ 常数空间）；不使用递归，无栈开销。

## 7. 参考代码

### C++

```cpp
#include <iostream>
using namespace std;

class Solution {
public:
    int findIntegers(int n) {
        // f[i]：长度 i 的自由二进制串中不含连续 1 的个数
        int f[32];
        f[0] = 1;
        f[1] = 2;
        for (int i = 2; i < 32; i++) f[i] = f[i - 1] + f[i - 2];

        int ans = 0;    // 统计严格小于 n 的合法数
        int prev = 0;   // n 的上一位是否为 1
        for (int i = 30; i >= 0; i--) {
            if ((n >> i) & 1) {
                ans += f[i];          // 本位改成 0，低 i 位自由
                if (prev == 1) return ans;   // 本位只能跟 1 就会连续 11，终止
                prev = 1;
            } else {
                prev = 0;             // 本位只能照抄 0
            }
        }
        return ans + 1;   // n 自身不含连续 1，补上
    }
};
```

### Python

```python
class Solution:
    def findIntegers(self, n: int) -> int:
        # f[i]: 长度为 i 的自由二进制串中不含连续 1 的个数
        f = [1, 2]
        for _ in range(2, 31):
            f.append(f[-1] + f[-2])

        ans = 0      # 严格小于 n 的合法数个数
        prev = 0     # n 的上一位是否为 1
        for i in range(30, -1, -1):
            if (n >> i) & 1:
                ans += f[i]            # 本位改成 0，低 i 位自由
                if prev:
                    return ans         # 本位跟 1 就会连续，无法再贴住 n
                prev = 1
            else:
                prev = 0               # 本位照抄 0
        return ans + 1                 # 补上 n 自身（它不含连续 1）
```

## 8. 边界情况与易错点

1. **`n = 1`**：`ans += f[0] = 1`，循环正常结束，返回 $2$（$0$ 与 $1$）。$f[0]=1$ 恰好对应「低位全部取 $0$」的那一个数，不能把 $f[0]$ 设为 $0$。
2. **最高位下标**：$n \le 10^9 < 2^{30}$，最高位是第 $29$ 位；循环起点写 $30$ 是安全的（第 $30$ 位必为 $0$），但数组必须开到下标 $30$ 以上，否则越界。
3. **先加后判**：`ans += f[i]` 必须写在 `prev` 检查**之前**；写反会丢掉「本位放 $0$」这一整块，是本题最常见的 WA 原因（如 $n=(110)_2$）。
4. **提前返回不要 `+1`**：能提前返回说明 $n$ 自身含 `11`，不合法，若仍 `return ans + 1` 会多算一个。
5. **`prev` 初始化**：置 $0$（等价于在最高位之上补一个 $0$），这样最高位取 `1` 不会被误判为连续。
6. **前导零不影响合法性**：$n$ 的二进制没有前导零，而低位自由的部分允许全 $0$（对应较小的数），二者的「连续 `1`」判定都不受前导零影响。
7. **溢出**：本题答案 $\le f[30] = 2178309$，`int` / Python 整数都安全；若把上界放宽到 $2^{63}$ 量级才需要关心溢出。
