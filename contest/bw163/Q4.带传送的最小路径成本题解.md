# LeetCode 带传送的最小路径成本 题解

## 1. 题目概述

- **标题 / 题号**：带传送的最小路径成本（#3651，hard）
- **链接**：https://leetcode.cn/problems/minimum-cost-path-with-teleportations/
- **来源**：LeetCode 第 163 场双周赛 Q4
- **难度**：困难
- **标签**：动态规划、最短路、数组、矩阵

**题意**：给定 $m \times n$ 的非负整数矩阵 `grid` 与整数 $k$。从 $(0,0)$ 出发（出发成本 0），要到达 $(m-1, n-1)$，可用两类移动：

- **普通移动**：向右或向下走一格，成本是**目标格**的值；
- **传送**：从任意格 $(i,j)$ 传送到任意满足 $\text{grid}[x][y] \le \text{grid}[i][j]$ 的格子 $(x,y)$，成本 $0$，**最多 $k$ 次**。

返回最小总成本。

**约束**：

- $2 \le m, n \le 80$，即 $m \cdot n \le 6400$
- $0 \le \text{grid}[i][j] \le 10^4$
- $0 \le k \le 10$

成本上界约 $6400 \times 10^4 = 6.4\times10^7$，`int` 够用；但用 `long long` 统一处理更稳。

## 2. 示例

**示例 1**

```text
输入：grid = [[1,3,3],[2,5,4],[4,3,5]], k = 2
输出：7
解释：(0,0) →下 (1,0) 成本 2 →右 (1,1) 成本 +5 = 7；
      从 (1,1)（值 5）传送到 (2,2)（值 5 ≤ 5）花 0，总成本 7。
```

**示例 2**

```text
输入：grid = [[1,2],[2,3],[3,4]], k = 1
输出：9
解释：不传送：2 + 3 + 4 = 9。传送也没用（(0,0) 值为 1，只能传到值 ≤ 1 的格子）。
```

**示例 3（自造，检查 $k = 0$）**

```text
输入：grid = [[1,9],[9,1]], k = 0
输出：10
解释：只能向右/向下：1 → 9 → 1 或 1 → 9 → 1，成本都是 9 + 1 = 10。
```

## 3. 解题思路

### 3.1 暴力思路

把「用了多少次传送」作为状态做 Dijkstra：节点数 $m n (k+1) \approx 7\times10^4$，但**传送边是稠密的**——每个格子都要向所有「值不大于它」的格子连边，总边数 $O((mn)^2) = 4\times10^7$ 量级，建图与松弛都太慢；而且 Dijkstra 的堆里会塞进大量状态。

退一步：不建图，直接在分层状态上做 Dijkstra，每次扩展一个格子时要枚举所有可传送目标，复杂度仍是 $O(k (mn)^2)$，$6400^2 \times 10 \approx 4\times10^8$，太慢。

### 3.2 核心观察：按传送次数分层，层内只剩「向右/向下」

![按「已用传送次数」分层：每层先传送落地，再向右/向下做 DP](images/bw163_q4_layers_dp.svg)

关键结构：

1. **层内**只有向右/向下的移动，因此层内格子之间构成 DAG，可以按**行优先顺序**做一遍线性 DP，无需堆。
2. **层间**只有「传送」一种转移，且传送成本为 0，于是第 $t$ 层某个格子的初始值 = 「第 $t-1$ 层中，所有值 $\ge$ 它的格子」的最小值。
3. 层内 DP 与层间转移交替进行，共 $k+1$ 层。

记 $\text{dp}_t[i][j]$ 为**至多**使用 $t$ 次传送到达 $(i,j)$ 的最小成本，则

$$\text{dp}_t[i][j] = \min\Big(\underbrace{\text{dp}_{t-1}[i][j]}_{\text{不用第 } t \text{ 次}},\ \underbrace{\min_{\text{grid}[u] \ge \text{grid}[i][j]} \text{dp}_{t-1}[u]}_{\text{第 } t \text{ 次传送到这里}}\Big)$$

再在层内从左/上松弛：

$$\text{dp}_t[i][j] \leftarrow \min\big(\text{dp}_t[i][j],\ \text{dp}_t[i-1][j] + \text{grid}[i][j],\ \text{dp}_t[i][j-1] + \text{grid}[i][j]\big)$$

注意起点 $(0,0)$ 的成本恒为 $0$（出发不付钱）。

### 3.3 传送来源的快速计算：按值降序的前缀最小值

![传送来源：所有「值 ≥ 当前格」的格子里 dp 的最小值（按值降序前缀 min）](images/bw163_q4_prefix_min.svg)

$\min_{\text{grid}[u] \ge \text{grid}[i][j]} \text{dp}_{t-1}[u]$ 看起来要对每个格子扫全图（$O((mn)^2)$）。但它是**按值的后缀极值**：把所有格子按 `grid` 值**从大到小**排序，维护「已扫描过的格子的 dp 最小值」，那么扫到某个格子时，前缀最小值正好是「值 $\ge$ 它的所有格子」的最小 dp。

一个细节：**值相等的格子可以互相传送**，所以同一值的整组要先全部把 dp 汇入前缀最小值，再统一赋值给这一组的每个格子，不能边扫边赋。

排序只需做一次（值不随层变化），之后每层扫一遍 $O(mn)$。

### 3.4 示例演算

![示例 1：网格 3×3、k = 2 时答案为 7](images/bw163_q4_example_walkthrough.svg)

`grid = [[1,3,3],[2,5,4],[4,3,5]]`，$k = 2$。

**第 0 层（不用传送）**：行优先 DP（代价为进入格子的值）：

| 格子 | dp₀ |
|---|---|
| (0,0) | 0 |
| (0,1) | 3 |
| (0,2) | 6 |
| (1,0) | 2 |
| (1,1) | 7（min(3+5, 2+5)） |
| (1,2) | 10 |
| (2,0) | 6 |
| (2,1) | 9（min(7+3, 6+3)） |
| (2,2) | 14（min(10+5, 9+5)） |

**第 1 层**：先算传送落地值。按值降序：值 5 的 (1,1)、(2,2) 先互传，前缀最小 dp₀ = 7，故 (1,1)、(2,2) 的传送落地值都是 7；值 4 的 (1,2)、(2,0)：前缀 min = min(7, 10, 6) = 6；值 3 的 (0,1)、(2,1)：仍为 6；值 2 的 (1,0)：6；值 1 的 (0,0)：0。

再做层内 DP：$(2,2)$ 的落地值 7 已经是最优（从 $(1,1)$ 传送过来），最终 $\text{dp}_1[2][2] = 7$。

第 2 层不会再变小，答案 $7$。✓

## 4. 算法细节

1. **分层定义**：$\text{dp}_t$ 表示「**至多** $t$ 次」，因此每层要取 $\min(\text{dp}_{t-1}[i][j], \text{传送落地值})$，这样 $k$ 层的答案单调不增，最终 $\text{dp}_k[m-1][n-1]$ 就是答案（用不到传送时不会变差）。
2. **起点成本**：进入 $(0,0)$ 不付 `grid[0][0]`，所以 `sweep` 里对 $(0,0)$ 只做 `dp[0] = min(dp[0], 0)`。
3. **同值组处理**：先遍历整组把 `dp` 并入前缀最小值，再回填整组，避免「同值格子的 dp 还没并进来就被赋值」。
4. **排序一次**：`order` 按 `grid` 值降序，只排一次，$k+1$ 层共用。
5. **层内扫描顺序**：行优先满足「左、上已算好」，因为只有向右/向下两种移动。
6. **`INF` 的选取**：`LLONG_MAX / 4`，避免 `INF + grid` 溢出；Python 用 `float('inf')`。
7. **$k = 0$**：循环一次都不进，答案就是第 0 层的普通网格 DP。
8. **网格值可以为 0**：`grid[i][j] = 0` 时普通移动免费，传送条件 $\le$ 也包含等值，逻辑不受影响。

## 5. 正确性证明

**引理 1（层内 DP 正确）**：固定第 $t$ 层的初始值数组 $d$，按行优先顺序执行 $d[i][j] \leftarrow \min(d[i][j], d[i-1][j] + g[i][j], d[i][j-1] + g[i][j])$ 后，$d[i][j]$ 等于「从本层任一初始格子出发、只走右/下到达 $(i,j)$」的最小成本（初始格子的成本已含在 $d$ 中）。

**证明**：对 $i+j$ 归纳。$(0,0)$ 无前驱，值就是初始值。对 $(i,j) \ne (0,0)$，任何只走右/下的路径，其最后一步必来自 $(i-1,j)$ 或 $(i,j-1)$，而这两个格子的 $i+j$ 更小、已按归纳假设算出最优值；加上进入 $(i,j)$ 的成本 $g[i][j]$ 即得。行优先顺序保证处理 $(i,j)$ 时左、上均已处理。∎

**引理 2（传送落地值正确）**：按值降序扫描并维护前缀最小值后，赋给格子 $x$ 的值等于 $\min\{\text{dp}_{t-1}[u] : \text{grid}[u] \ge \text{grid}[x]\}$。

**证明**：降序排列后，所有 `grid` 值 $\ge \text{grid}[x]$ 的格子都排在 $x$ 之前或与 $x$ 同组。算法先把同值整组并入前缀最小值，再回填，故赋给 $x$ 的前缀最小值恰好覆盖「值 $\ge \text{grid}[x]$」的全部格子（含同值），且不含值更小的格子。这正是传送允许的来源集合。∎

**引理 3（分层覆盖所有方案）**：任一从 $(0,0)$ 到 $(i,j)$、使用 $c \le t$ 次传送的方案，其成本不小于 $\text{dp}_t[i][j]$。

**证明**：对 $c$ 归纳。$c = 0$ 时由引理 1。设方案用了 $c \ge 1$ 次传送，取**最后一次**传送，它从某格 $u$ 跳到 $v$（$\text{grid}[v] \le \text{grid}[u]$），之后只走右/下到 $(i,j)$。传送之前的部分用 $c-1$ 次传送到达 $u$，由归纳假设其成本 $\ge \text{dp}_{c-1}[u]$；传送后（含 $v$ 到终点的右/下移动）的成本 $\ge$ 以 $\text{dp}_{c-1}$ 为初值、从 $v$ 出发的层内最优，而引理 2 给出 $v$ 的落地值 $\le \text{dp}_{c-1}[u]$，再经引理 1 的层内 DP，得到 $\ge \text{dp}_c[i][j] \ge \text{dp}_t[i][j]$（因 $\text{dp}$ 关于 $t$ 单调不增）。∎

**引理 4（构造性）**：$\text{dp}_t[i][j]$ 对应的成本可由某个合法方案达到。

**证明**：每一层的更新要么继承上一层的同一格子（不增加传送次数），要么由引理 2 的某个来源 $u$ 传送而来（增加一次传送，且 $\text{grid}$ 条件满足），随后按引理 1 的 DP 走右/下。把这些步骤串起来就是一个使用 $\le t$ 次传送的合法方案，成本恰为 $\text{dp}_t[i][j]$。∎

**定理**：$\text{dp}_k[m-1][n-1]$ 等于题目要求的最小总成本。

**证明**：引理 3 给出下界、引理 4 给出可达性，两者相等。∎

## 6. 复杂度分析

- **时间**：
  - 排序一次 $O(mn \log(mn))$；
  - 每层：传送落地 $O(mn)$ + 层内 DP $O(mn)$，共 $k+1$ 层；
  - 总计 $O\big(mn\log(mn) + k \cdot mn\big)$。$m n = 6400$、$k = 10$ 时约 $7\times10^4$ 次基本操作，非常宽裕。
- **空间**：$O(mn)$，两层 `dp`（当前层与上一层）+ 排序下标数组。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minCost(std::vector<std::vector<int>>& grid, int k) {
        int m = (int)grid.size(), n = (int)grid[0].size();
        const long long INF = std::numeric_limits<long long>::max() / 4;
        std::vector<long long> prev(m * n, INF), cur(m * n, INF);
        // 传送来源的“按值降序前缀最小”
        std::vector<int> order(m * n);
        for (int i = 0; i < m * n; i++) order[i] = i;
        std::sort(order.begin(), order.end(), [&](int x, int y) {
            return grid[x / n][x % n] > grid[y / n][y % n];
        });

        auto sweep = [&](std::vector<long long>& d) {
            for (int i = 0; i < m; i++) {
                for (int j = 0; j < n; j++) {
                    if (i == 0 && j == 0) { if (d[0] > 0) d[0] = 0; continue; }
                    long long best = d[i * n + j];
                    if (i > 0 && d[(i - 1) * n + j] + grid[i][j] < best) best = d[(i - 1) * n + j] + grid[i][j];
                    if (j > 0 && d[i * n + j - 1] + grid[i][j] < best) best = d[i * n + j - 1] + grid[i][j];
                    d[i * n + j] = best;
                }
            }
        };

        sweep(prev);              // 0 次传送
        for (int t = 1; t <= k; t++) {
            // 传送层：从“值 >= 当前格”的格子里免费跳过来
            std::vector<long long> via(m * n, INF);
            long long bestVal = INF;
            int p = 0;
            while (p < m * n) {
                int q = p;
                int v = grid[order[p] / n][order[p] % n];
                // 把值恰为 v 的所有格子的 prefix min 汇总（同值互传也合法）
                while (q < m * n && grid[order[q] / n][order[q] % n] == v) {
                    if (prev[order[q]] < bestVal) bestVal = prev[order[q]];
                    q++;
                }
                while (p < q) { via[order[p]] = bestVal; p++; }
            }
            // 传送落地后可以继续向右/向下走
            sweep(via);
            for (int i = 0; i < m * n; i++) cur[i] = std::min(prev[i], via[i]);
            prev = cur;
        }
        long long ans = prev[m * n - 1];
        return ans >= INF ? -1 : (int)ans;
    }
};
```

### Python

```python
class Solution:
    def minCost(self, grid: list[list[int]], k: int) -> int:
        m, n = len(grid), len(grid[0])
        N = m * n
        INF = float('inf')
        order = sorted(range(N), key=lambda c: -grid[c // n][c % n])

        def sweep(d):
            # 已给定传送落地成本 d，再沿右/下做一次 DP
            for i in range(m):
                for j in range(n):
                    c = i * n + j
                    if c == 0:
                        d[0] = min(d[0], 0)
                        continue
                    best = d[c]
                    if i > 0:
                        best = min(best, d[c - n] + grid[i][j])
                    if j > 0:
                        best = min(best, d[c - 1] + grid[i][j])
                    d[c] = best

        prev = [INF] * N
        sweep(prev)                      # 0 次传送
        for _ in range(k):
            via = [INF] * N
            best_val = INF
            p = 0
            while p < N:
                q = p
                v = grid[order[p] // n][order[p] % n]
                while q < N and grid[order[q] // n][order[q] % n] == v:
                    best_val = min(best_val, prev[order[q]])
                    q += 1
                while p < q:
                    via[order[p]] = best_val
                    p += 1
            sweep(via)
            prev = [min(a, b) for a, b in zip(prev, via)]
        return prev[N - 1]
```

## 8. 边界情况与易错点

1. **起点不收成本**：`sweep` 里必须把 $(0,0)$ 强制设为 0，否则会多算 `grid[0][0]`。
2. **同值组要先合并再赋值**：若边扫边赋，同值的格子可能拿不到彼此更优的 dp（示例 1 中 (1,1) 与 (2,2) 都是 5，互相可传）。
3. **「至多 $t$ 次」而非「恰好 $t$ 次」**：每层要保留 $\min(\text{dp}_{t-1}, \text{传送落地值})$，否则会用不到传送时结果变差。
4. **传送后还能继续走**：落地后必须再做一次层内 DP（`sweep(via)`），漏掉会低估。
5. **$k = 0$**：直接返回第 0 层结果，不要进循环。
6. **`INF` 加法溢出**：所有 `INF + grid` 都要避免，代码里用 `d[c]` 初值 + 只在与有限值比较时相加。
7. **$0$ 值格子**：普通移动免费，传送条件用 $\le$（等值合法），代码不特判。
8. **终点不可达**：本题 $(0,0)$ 总能向右/向下走到终点（网格连通），不会返回 $-1$；但代码里保留 `ans >= INF ? -1` 的保险写法。
9. **排序稳定性**：`order` 只是分组依据，同值内部顺序无关紧要，因为整组一起处理。

**延伸思考**：若传送有成本 $c$（而非 0），分层 DP 依然成立，只是 $\text{via}[x] = c + \min_{\text{grid}[u]\ge\text{grid}[x]} \text{dp}_{t-1}[u]$。若传送允许「向上/向左」以外的任意方向且**不能**保证值单调，条件 $\text{grid}[x][y] \le \text{grid}[i][j]$ 就消失了，传送变成完全图，只能对每层做一次 Dijkstra 或利用「全局最小 dp」加速。
