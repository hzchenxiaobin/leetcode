# LeetCode 边反转的最小路径总成本 题解

## 1. 题目概述

- **标题 / 题号**：边反转的最小路径总成本（#3650，medium）
- **链接**：https://leetcode.cn/problems/minimum-cost-path-with-edge-reversals/
- **来源**：LeetCode 第 163 场双周赛 Q3
- **难度**：中等
- **标签**：图、最短路、堆（优先队列）

**题意**：给定 $n$ 个节点的有向带权图，`edges[i] = [u, v, w]` 表示 $u \to v$ 的成本为 $w$。

每个节点 $u$ **最多可使用一次**开关：当你到达 $u$ 且尚未使用它的开关时，可以对其**一条入边** $v \to u$ 激活开关，把它反转为 $u \to v$ 并**立即穿过**，成本为 $2w$（反转只对这一次移动有效）。

求从 $0$ 到 $n-1$ 的最小总成本，不可达返回 $-1$。

**约束**：

- $2 \le n \le 5 \times 10^4$
- $1 \le m \le 10^5$
- $1 \le w \le 1000$

## 2. 示例

**示例 1**

```text
输入：n = 4, edges = [[0,1,3],[3,1,1],[2,3,4],[0,2,2]]
输出：5
解释：走 0→1 花 3；在节点 1 用开关把 3→1 反转为 1→3，花 2·1 = 2；总成本 5。
```

**示例 2**

```text
输入：n = 4, edges = [[0,2,1],[2,1,1],[1,3,1],[2,3,3]]
输出：3
解释：不需要反转，走 0→2→1→3，成本 1+1+1 = 3。
```

**示例 3（自造，检查不可达）**

```text
输入：n = 3, edges = [[1,2,1]]
输出：-1
解释：节点 0 没有出边，也没有办法通过反转离开 0（0 没有入边可反），无法到达 2。
```

## 3. 解题思路

### 3.1 暴力思路

把「每个节点的开关是否用过」作为状态，做状态空间 Dijkstra：状态为 `(当前节点, 已用开关的节点集合)`。开关集合最大 $2^n$，$n = 5\times10^4$ 时状态爆炸。即使只保留「到当前节点时已用过的开关」，也无法压缩成多项式状态——看起来必须另找结构。

### 3.2 核心观察：把「反转」展开成一条固定的反向弧

![把「反转」变成一条反向弧：v→u 时反走 u→v 需 2·w](images/bw163_q3_double_arc.svg)

关键事实：**反转一条边只需要「到达它的终点」并「这条边指向我」**。具体地，对原边 $v \to u$（成本 $w$）：

- 正常通过：$u$ 的反面——从 $v$ 走到 $u$，花 $w$；
- 反转通过：站在 $u$ 上，把这条**入边**反转成 $u \to v$，花 $2w$。

所以我们可以直接在原图上**加一条反向弧** $u \to v$，权重 $2w$，然后跑普通 Dijkstra。这样「开关」的语义就编码进了边的方向：从 $u$ 出发走 $2w$ 的弧，等价于「在 $u$ 用掉它的开关反走某条入边」。

剩下的疑问是：**一个节点的开关只能用一次，而图上可能有多条反向弧从同一节点出发，会不会被用两次？**

需要注意两点：

1. 最短路径不会重复访问同一个节点（所有边权 $w \ge 1$，反向弧 $2w \ge 2 > 0$，正权图的最短路一定是简单路径）；
2. 路径每经过一个节点至多一次，因此在每个节点至多使用一次开关——与「最多一次」的约束完全吻合。

于是问题化为**单源最短路**，Dijkstra 即可。

![示例 1：0→1 花 3，再用节点 1 的开关反走 3→1（成本 2）到 3](images/bw163_q3_example_walkthrough.svg)

### 3.3 算法流程

```text
1. 建图 g：
   for (u, v, w) in edges:
       g[u].push((v, w))        # 正常通过
       g[v].push((u, 2*w))      # 用 v 的开关反转后通过
2. dist[0] = 0，其余 +∞；优先队列放入 (0, 0)
3. 标准 Dijkstra：每次弹出最小 dist 的节点，松弛其所有出边
4. 返回 dist[n-1]，若仍为 +∞ 则返回 -1
```

### 3.4 示例演算

**示例 1**：`n = 4`，边为 $0\to1(3)$、$3\to1(1)$、$2\to3(4)$、$0\to2(2)$。

建图后有 8 条弧，其中反向弧为 $1\to0(6)$、$1\to3(2)$、$3\to2(8)$、$2\to0(4)$。

Dijkstra 过程：

| 步骤 | 弹出 | dist 更新 | 说明 |
|---|---|---|---|
| 1 | 0 (d=0) | dist[1]=3, dist[2]=2 | 从 0 出发 |
| 2 | 2 (d=2) | dist[3]=6 | 正常弧 2→3 花 4 |
| 3 | 1 (d=3) | dist[3]=min(6, 3+2)=5, dist[0] 不回退 | 反向弧 1→3 花 2 |
| 4 | 3 (d=5) | — | 终点，答案 5 |

答案 $5$，与题面一致。注意这里既可能用正常弧（$2\to3$，成本 6），也可能用反向弧（$1\to3$，成本 5），Dijkstra 自动取优。

**示例 2**：三条正常弧构成 $0\to2\to1\to3$，成本 $1+1+1 = 3$；反向弧都更贵（$2w \ge 2$），不会更优，答案 $3$。

## 4. 算法细节

1. **反向弧权重是 $2w$**：不是 $w$，也不是 $w + \text{某常数}$；漏乘 2 会把答案算小。
2. **弧的数量**：每条边产生 2 条弧，共 $2m \le 2\times10^5$ 条，内存与时间都可接受。
3. **自环与重边**：题目没有禁止重边，邻接表天然支持；自环（$u = v$）在 `edges[i]` 中不会出现（题目保证 $u \ne v$，若出现也不会影响最短路）。
4. **距离类型**：最坏成本 $10^5 \times 2\times10^3 = 2\times10^8$，`int` 够用，但用 `long long` 更稳（也便于统一写法）。
5. **`dist[n-1]` 为 INF 时返回 $-1$**：注意用「≥ INF/2」而不是「== INF」，避免溢出写法带来的误判。
6. **不需要建「开关状态」**：这是本题的核心简化；一旦想用状态压缩就会卡死。
7. **优先队列的懒删除**：弹出时判断 `d > dist[u]` 就跳过，不必手写 decrease-key。

## 5. 正确性证明

**引理 1（反向弧与开关使用一一对应）**：在扩展图上走一条 $u \to v$、权重 $2w$ 的反向弧，当且仅当在原图中「在 $u$ 处用开关把入边 $v \to u$（权重 $w$）反转并通过」，且成本相同。

**证明**：由构造，反向弧 $u \to v$ 仅当原图存在边 $v \to u$（权重 $w$）时存在，权重恰为 $2w$。原题规定：站在 $u$、未用过开关时，可反转一条入边 $v \to u$ 并立即穿过，成本 $2w$。两者条件与成本完全一致。∎

**引理 2（路径的可行性）**：扩展图上任一条从 $0$ 到 $n-1$ 的路径，都能翻译成原题中一个合法方案，成本相同。

**证明**：逐条边翻译：正常弧直接走；反向弧 $u\to v$ 由引理 1 翻译为「在 $u$ 用开关」。由于路径是简单路径（正权最短路必然简单），每个节点至多出现一次，故每个节点的开关**至多被使用一次**，满足「最多一次」的约束。∎

**引理 3（最优方案可被表示）**：原题任一合法方案都对应扩展图上一条成本相同的路径。

**证明**：合法方案是一串「正常通过 / 反转通过」的移动。正常通过对应原弧；反转通过（在 $u$ 反转入边 $v\to u$）由引理 1 对应反向弧 $u \to v$。按时间顺序拼接即得一条从 $0$ 到 $n-1$ 的路径，成本逐段相同。∎

**定理**：扩展图上 $0 \to n-1$ 的最短路长度等于原题的最小总成本。

**证明**：由引理 2，扩展图最短路 $\ge$ 原题最优（任一扩展路径都是合法方案）；由引理 3，原题最优 $\ge$ 扩展图最短路（任一合法方案都是扩展路径）。两者相等。Dijkstra 在非负权图上正确求出最短路，故返回值为答案；不可达时 $dist = \infty$，返回 $-1$ 也正确。∎

## 6. 复杂度分析

- **时间**：建图 $O(n + m)$；Dijkstra 使用二叉堆，共 $2m$ 条弧，$O\big((n + m)\log n\big)$，$n = 5\times10^4$、$m = 10^5$ 时约 $2\times10^5 \times 17$ 次堆操作。
- **空间**：$O(n + m)$，邻接表 $2m$ 条弧 + `dist` 数组 + 堆。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minCost(int n, std::vector<std::vector<int>>& edges) {
        std::vector<std::vector<std::pair<int, long long>>> g(n);
        for (const std::vector<int>& e : edges) {
            int u = e[0], v = e[1];
            long long w = e[2];
            g[u].push_back({v, w});        // 正常通过
            g[v].push_back({u, 2 * w});    // 反转后通过
        }
        const long long INF = std::numeric_limits<long long>::max() / 4;
        std::vector<long long> dist(n, INF);
        typedef std::pair<long long, int> State;
        std::priority_queue<State, std::vector<State>, std::greater<State>> pq;
        dist[0] = 0;
        pq.push({0, 0});
        while (!pq.empty()) {
            State cur = pq.top();
            pq.pop();
            long long d = cur.first;
            int u = cur.second;
            if (d > dist[u]) continue;
            for (const auto& pr : g[u]) {
                int v = pr.first;
                long long nd = d + pr.second;
                if (nd < dist[v]) {
                    dist[v] = nd;
                    pq.push({nd, v});
                }
            }
        }
        return dist[n - 1] >= INF ? -1 : (int)dist[n - 1];
    }
};
```

### Python

```python
class Solution:
    def minCost(self, n: int, edges: list[list[int]]) -> int:
        import heapq
        g = [[] for _ in range(n)]
        for u, v, w in edges:
            g[u].append((v, w))        # 正常通过
            g[v].append((u, 2 * w))    # 反转后通过
        INF = float('inf')
        dist = [INF] * n
        dist[0] = 0
        pq = [(0, 0)]
        while pq:
            d, u = heapq.heappop(pq)
            if d > dist[u]:
                continue
            for v, w in g[u]:
                nd = d + w
                if nd < dist[v]:
                    dist[v] = nd
                    heapq.heappush(pq, (nd, v))
        return -1 if dist[n - 1] == INF else dist[n - 1]
```

## 8. 边界情况与易错点

1. **反向弧成本写成 $w$**：示例 1 会算成 4（3+1），而正确答案是 5。
2. **担心「一个节点用两次开关」**：正权图最短路是简单路径，节点不重复，开关自然不会重复使用；不需要额外状态。
3. **不可达**：返回 $-1$，注意 `dist` 的无穷大判断方式。
4. **重边**：多条同向边各自产生反向弧，Dijkstra 自动取优，不要用邻接矩阵。
5. **$n = 2$**：只需看 $0 \to 1$ 或 $1 \to 0$ 的反向弧，代码自然处理。
6. **起点的开关**：起点 0 的开关同样可用（若 0 有入边），扩展图里对应 $0 \to x$ 的反向弧，语义正确。
7. **正权保证**：$w \ge 1$，故所有弧权重 $\ge 1$，Dijkstra 适用；若允许 $w = 0$，Dijkstra 仍然正确（非负权即可）。
8. **`int` 溢出**：单条成本 $2\times10^3$，路径长度 $10^5$，总和 $2\times10^8$，`int` 尚可但接近边界，建议 `long long`。

**延伸思考**：如果每个节点的开关**可以使用多次**，那么扩展图上的反向弧可以重复使用，最短路仍用 Dijkstra（正权下简单路径已足够，不会重复用）。如果开关有「全局只能用 $K$ 次」的约束，就不能再压缩成普通图，必须做分层图最短路（状态 = 节点 × 已用次数），复杂度 $O(K(n+m)\log n)$。
