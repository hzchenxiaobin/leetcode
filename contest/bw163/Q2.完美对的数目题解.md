# LeetCode 完美对的数目 题解

## 1. 题目概述

- **标题 / 题号**：完美对的数目（#3649，medium）
- **链接**：https://leetcode.cn/problems/number-of-perfect-pairs/
- **来源**：LeetCode 第 163 场双周赛 Q2
- **难度**：中等
- **标签**：数组、数学、排序、双指针

**题意**：给定整数数组 `nums`。下标对 $(i, j)$（$i < j$）称为**完美**的，当且仅当令 $a = \text{nums}[i]$、$b = \text{nums}[j]$ 时同时满足

$$\min(|a-b|, |a+b|) \le \min(|a|, |b|), \qquad \max(|a-b|, |a+b|) \ge \max(|a|, |b|)$$

返回**不同**完美对的数量（即下标对数，$i < j$）。

**约束**：

- $2 \le \text{nums.length} \le 10^5$
- $-10^9 \le \text{nums}[i] \le 10^9$

对数最多 $\binom{10^5}{2} \approx 5\times10^9$，**超过 `int` 范围**，必须用 64 位整数。

## 2. 示例

**示例 1**

```text
输入：nums = [0,1,2,3]
输出：2
解释：完美对为 (1,2)：min(|1−2|,|1+2|)=1 ≤ min(1,2)=1 且 max=3 ≥ 2；
      (2,3)：min(|2−3|,|2+3|)=1 ≤ 2 且 max=5 ≥ 3。
      其余对不满足（例如 (1,3)：min(2,4)=2 > min(1,3)=1）。
```

**示例 2**

```text
输入：nums = [-3,2,-1,4]
输出：4
解释：完美对为 (−3,2)、(−3,4)、(2,−1)、(2,4)。
```

**示例 3**

```text
输入：nums = [1,10,100,1000]
输出：0
解释：任意两数相差都在 10 倍以上，第二条不等式永远不成立。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有 $i < j$，按定义算四个绝对值再比较，$O(n^2)$，$n = 10^5$ 时 $5\times10^9$ 次运算，不可行。必须先化简条件。

### 3.2 核心观察：两个绝对值其实是和与差

![关键恒等式：a−b 与 a+b 的绝对值，恰是两数绝对值之和与差](images/bw163_q2_absolute_reduce.svg)

**恒等式**：对任意整数 $a, b$，

$$\big\{|a-b|,\ |a+b|\big\} = \big\{|a|+|b|,\ \big||a|-|b|\big|\big\}$$

（作为**集合**相等，即「一个等于和、一个等于差的绝对值」，但哪个对应哪个可能互换。）

验证：$a = -3, b = 2$ 时 $|a-b| = 5 = |a|+|b|$，$|a+b| = 1 = ||a|-|b||$；$a = 2, b = -1$ 时 $|a-b| = 3 = |a|+|b|$，$|a+b| = 1 = ||a|-|b||$。

有了它，原条件立刻化简。记 $A = |a|$、$B = |b|$，则

- 第一式：$\min(A+B,\ |A-B|) \le \min(A, B)$。因为 $|A-B| \le A+B$ 恒成立，所以等价于 $|A-B| \le \min(A,B)$；
- 第二式：$\max(A+B,\ |A-B|) \ge \max(A,B)$。因为 $A+B \ge \max(A,B)$ 恒成立，所以**第二式自动成立**，无需检查。

于是完美 $\iff$

$$|A - B| \le \min(A, B) \iff \max(A,B) \le 2\min(A,B)$$

（最后一步：设 $A \le B$，则条件为 $B - A \le A$，即 $B \le 2A$。）

也就是说，**只看绝对值，较大者不超过较小者的两倍**。

### 3.3 算法流程：排序 + 双指针

![取绝对值、排序，再用双指针数「比值 ≤ 2」的数对](images/bw163_q2_two_pointer.svg)

1. 把 `nums` 全部取绝对值，升序排序得到 $a_0 \le a_1 \le \dots \le a_{n-1}$；
2. 对每个 $i$，向右推进指针 $r$，使 $a_r \le 2a_i$ 且 $r$ 最大；
3. 以 $i$ 为较小端（下标意义上）的完美对数量是 $r - i$（即 $j \in (i, r]$）；
4. 累加所有 $i$ 的贡献。

指针 $r$ 单调不减（因为 $2a_i$ 随 $i$ 增大而不减），所以总体 $O(n)$ 扫描，加上排序 $O(n\log n)$。

### 3.4 示例演算

**示例 2**：`nums = [-3,2,-1,4]`，取绝对值得 `[3,2,1,4]`，排序为 `[1,2,3,4]`。

| $i$ | $a_i$ | $2a_i$ | 最远 $r$ | 贡献 $r - i$ |
|---|---|---|---|---|
| 0 | 1 | 2 | 1 | 1（对子 (1,2)） |
| 1 | 2 | 4 | 3 | 2（对子 (2,3)、(2,4)） |
| 2 | 3 | 6 | 3 | 1（对子 (3,4)） |
| 3 | 4 | 8 | 3 | 0 |

总计 $1 + 2 + 1 = 4$，与题目输出的 4 一致。

把结果翻译回原数组：`abs` 排序后的 `[1,2,3,4]` 对应原下标的 `2,1,0,3`，对应的原数组对为 $(-1,2)$、$(2,-3)$、$(2,4)$、$(-3,4)$，正是题面列出的四个（顺序无关）。

**示例 1**：`[0,1,2,3]` 绝对值排序为 `[0,1,2,3]`。$i=0$（$a=0$）：$2a = 0$，$r$ 停在 0，贡献 0；$i=1$：$2a = 2$，$r = 2$，贡献 1；$i=2$：$2a = 4$，$r=3$，贡献 1；$i=3$：贡献 0。合计 2 ✓。

**示例 3**：`[1,10,100,1000]`，$i=0$ 时 $2a = 2 < 10$，所有贡献为 0，答案 0 ✓。

## 4. 算法细节

1. **必须整体取绝对值**：条件只与 $|a|, |b|$ 有关，先取绝对值能把负数问题一次性消掉。
2. **计数用 `long long`**：答案可达 $5\times10^9$，`int` 溢出。
3. **指针不回退**：$2a_i$ 单调不减，`r` 可以延续上一轮的位置；但要注意 `r` 不能小于 `i`，代码里写 `if (r < i) r = i`。
4. **等号**：条件是「不超过」两倍，即 $a_r \le 2a_i$ 时**取等也合法**（示例 1 的 $2 \le 2\cdot1$ 正是取等）。
5. **$a_i = 0$**：$2a_i = 0$，只有当 $a_r = 0$ 时才成立，即只有 0 与 0 配对——与化简式一致（$\max(0,0) \le 2\cdot0$）。
6. **下标顺序**：排序打乱了原下标，但完美性的判定只依赖两个值，与先后无关，所以按「排序后位置」计数等价于按原下标 $i<j$ 计数。
7. **不要用浮点除法**：用 $a_j \le 2a_i$ 的整数比较，避免精度问题。

## 5. 正确性证明

**引理 1（绝对值恒等式）**：对任意整数 $a, b$，$\{|a-b|, |a+b|\} = \{|a|+|b|, ||a|-|b||\}$。

**证明**：设 $A = |a|, B = |b|$。若 $a, b$ 同号（含某个为 $0$），则 $|a+b| = A + B$，$|a-b| = |A - B|$；若异号，则 $|a-b| = A + B$，$|a+b| = |A-B|$。两种情况都恰好得到 $\{A+B, |A-B|\}$。∎

**引理 2（条件化简）**：对任意 $a, b$，原两条不等式同时成立 $\iff \max(|a|,|b|) \le 2\min(|a|,|b|)$。

**证明**：记 $A = |a|, B = |b|$。

*必要性*：设两条都成立。由引理 1，两个绝对值就是 $A+B$ 与 $|A-B|$。第二式给出 $\max(A+B, |A-B|) = A+B \ge \max(A,B)$（恒真），第一式给出 $\min(A+B, |A-B|) = |A-B| \le \min(A,B)$。设 $A \le B$，则 $B - A \le A$，即 $B \le 2A$，也就是 $\max \le 2\min$。

*充分性*：若 $\max(A,B) \le 2\min(A,B)$，设 $A \le B$，则 $B - A \le A = \min(A,B)$，故第一式成立；第二式恒真。∎

**引理 3（双指针计数正确）**：对排序后的 $a$，算法对每个 $i$ 累加 $r_i - i$，其中 $r_i$ 是满足 $a_{r} \le 2a_i$ 的最大下标，则总和等于完美对个数。

**证明**：对每个 $i$，满足 $j > i$ 且 $a_j \le 2a_i$ 的 $j$ 构成后缀区间 $(i, r_i]$（因为 $a$ 有序），个数为 $r_i - i$。由引理 2，这正好是以 $i$ 为较小端的完美对个数。每个完美对 $\{i,j\}$（设 $i<j$）恰好在 $i$ 这一轮被计入一次，不重不漏。∎

**定理**：算法返回值等于完美对总数。

**证明**：由引理 2、3，累加值等于全部完美对个数。排序不改变「哪些值对满足条件」，因为条件只依赖 $|a|, |b|$ 的取值集合；而按下标 $i<j$ 计数与按排序后位置计数等价（每个无序值对 $\{x,y\}$ 与它在原数组中的一次出现对应；重复值的情况由「每个 $i$ 只向后计数」自然处理）。∎

## 6. 复杂度分析

- **时间**：取绝对值 $O(n)$；排序 $O(n\log n)$；双指针 $O(n)$（$r$ 单调，总移动 $O(n)$）。合计 $O(n\log n)$。
- **空间**：$O(n)$（存绝对值数组；Python 为列表，C++ 为 `vector<long long>`）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long perfectPairs(std::vector<int>& nums) {
        int n = (int)nums.size();
        std::vector<long long> a(n);
        for (int i = 0; i < n; i++) a[i] = std::llabs((long long)nums[i]);
        std::sort(a.begin(), a.end());
        long long ans = 0;
        int r = 0;
        for (int i = 0; i < n; i++) {
            if (r < i) r = i;
            while (r + 1 < n && a[r + 1] <= 2 * a[i]) r++;
            ans += (r - i);
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def perfectPairs(self, nums: list[int]) -> int:
        a = sorted(abs(v) for v in nums)
        n = len(a)
        ans = 0
        r = 0
        for i in range(n):
            if r < i:
                r = i
            while r + 1 < n and a[r + 1] <= 2 * a[i]:
                r += 1
            ans += r - i
        return ans
```

## 8. 边界情况与易错点

1. **答案溢出**：$5\times10^9$ 超过 `int`，C++ 必须用 `long long` 计数。
2. **不取绝对值**：直接对原数排序会把负数排到左边，判定完全错乱。
3. **误以为第二条不等式也要额外检查**：它恒成立（$|a|+|b| \ge \max(|a|,|b|)$），化简后只需检查一条。
4. **取等**：$a_j = 2a_i$ 时合法，`<=` 不能写成 `<`。
5. **$0$ 的处理**：$0$ 只能与 $0$ 组成完美对；`2*0 = 0` 的比较自然正确。
6. **指针越界**：`while r + 1 < n` 与 `if (r < i) r = i` 两句缺一不可。
7. **重复元素**：例如 `[2,2,2]`，三对都是完美对（$2 \le 4$），双指针会正确累加 $2 + 1 + 0 = 3$。
8. **$n = 2$**：直接判一对，答案要么 0 要么 1。
