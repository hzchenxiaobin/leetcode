# LeetCode 覆盖网格的最少传感器数目 题解

## 1. 题目概述

- **标题 / 题号**：覆盖网格的最少传感器数目（#3648，medium）
- **链接**：https://leetcode.cn/problems/minimum-sensors-to-cover-grid/
- **来源**：LeetCode 第 163 场双周赛 Q1
- **难度**：中等
- **标签**：数学、贪心

**题意**：给定 $n \times m$ 的网格与整数 $k$。放在 $(r, c)$ 的传感器能覆盖所有与它**切比雪夫距离**不超过 $k$ 的格子，即

$$\max\big(|r_1 - r_2|,\ |c_1 - c_2|\big) \le k$$

求覆盖整个网格所需的**最少**传感器数量。

**约束**：

- $1 \le n, m \le 1000$
- $0 \le k \le 1000$

答案最大为 $10^6$（$k = 0$ 时每格一个），`int` 足够，但公式里用 `long long` 做中间量更稳。

## 2. 示例

**示例 1**

```text
输入：n = 5, m = 5, k = 1
输出：4
解释：在 (0,3)、(1,0)、(3,3)、(4,1) 各放一个即可覆盖全网格；3 个不够。
```

**示例 2**

```text
输入：n = 2, m = 2, k = 2
输出：1
解释：k = 2 ≥ 1，一个传感器就能覆盖 2×2 全部格子。
```

**示例 3（自造，检查 k = 0）**

```text
输入：n = 2, m = 3, k = 0
输出：6
解释：k = 0 时传感器只能覆盖自己，每格都要一个。
```

## 3. 解题思路

### 3.1 暴力思路

最朴素的想法是「枚举放几个、放哪里」：从 1 个开始试所有位置组合，直到覆盖全网格。位置组合数是 $C(nm, s)$，$nm = 10^6$ 时完全不可行。即使对小网格能跑，也无法指导大规模。

### 3.2 核心观察：一个传感器恰好覆盖一个 $(2k+1)\times(2k+1)$ 方块

![一个传感器覆盖一个 (2k+1)×(2k+1) 方块（切比雪夫半径 k）](images/bw163_q1_chebyshev_tile.svg)

切比雪夫距离的「球」是**正方形**：以 $(r, c)$ 为中心、半径 $k$ 的覆盖区域是

$$[r-k, r+k] \times [c-k, c+k]$$

即一个边长为 $2k+1$ 的正方形（被网格边界裁掉一部分）。

于是自然的想法：把 $n \times m$ 的网格切成边长为 $2k+1$ 的方块，**每块一个传感器**。这样能得到可行解

$$\Big\lceil \frac{n}{2k+1}\Big\rceil \times \Big\lceil \frac{m}{2k+1}\Big\rceil$$

剩下的问题是：**能否更少**？答案是**不能**，理由来自「采样点」：

在网格中取这些格子

$$P = \Big\{\big(i(2k+1),\ j(2k+1)\big) \ \Big|\ 0 \le i < \lceil n/(2k+1)\rceil,\ 0 \le j < \lceil m/(2k+1)\rceil\Big\}$$

共 $\lceil n/(2k+1)\rceil \cdot \lceil m/(2k+1)\rceil$ 个（都落在网格内，因为 $(N-1)(2k+1) \le n-1$）。任取其中两个**不同**的点，它们在行方向或列方向相差至少 $2k+1$，所以切比雪夫距离 $\ge 2k+1 > k$——**一个传感器不可能同时覆盖两个采样点**。因此传感器数至少等于采样点个数，下界与上界吻合！

![答案公式与两个示例](images/bw163_q1_formula.svg)

### 3.3 算法流程

```text
side = 2k + 1
ans = ⌈n / side⌉ × ⌈m / side⌉
返回 ans
```

向上取整用整数写法 `(x + side - 1) / side`。

### 3.4 示例演算

**示例 1**：$n = m = 5$，$k = 1$，$side = 3$。$\lceil 5/3\rceil = 2$，答案 $2 \times 2 = 4$。

采样点为 $(0,0), (0,3), (3,0), (3,3)$，两两切比雪夫距离至少 $3 > 1$，所以至少要 4 个；而每 $3\times3$ 方块放一个（放在方块中心或边界处）确实能覆盖 5×5，故答案是 4。

**示例 2**：$n = m = 2$，$k = 2$，$side = 5$。$\lceil 2/5\rceil = 1$，答案 $1$。

**示例 3**：$n = 2, m = 3, k = 0$，$side = 1$。答案是 $2 \times 3 = 6$。

## 4. 算法细节

1. **边长是 $2k+1$**：半径 $k$ 的正方形覆盖 $2k+1$ 行、$2k+1$ 列（含中心），不要写成 $2k$。
2. **向上取整的整数写法**：`(n + side - 1) / side`；注意 `n + side - 1` 在 $n, side \le 2001$ 时不会溢出 `int`，但用 `long long` 更保险。
3. **$k = 0$**：$side = 1$，公式退化为 $n \times m$，正确（每格一个）。
4. **$k$ 很大**：$side$ 可能超过 $n$ 与 $m$，此时两个向上取整都等于 1，答案 $1$（一个传感器覆盖全网格）。
5. **不要真的去模拟覆盖**：本题是纯公式题，模拟留到小数据对拍时使用。
6. **$n \ne m$ 的矩形**：两个方向分别取整再相乘即可，注意**不能**先算面积再除（那会少算）。

## 5. 正确性证明

**引理 1（单个传感器的覆盖区域）**：放在 $(r_0, c_0)$ 的传感器覆盖的格子集合是 $[r_0-k, r_0+k] \times [c_0-k, c_0+k] \cap \text{网格}$。

**证明**：$d_\infty((r,c),(r_0,c_0)) \le k \iff |r - r_0| \le k$ 且 $|c - c_0| \le k$，即 $r \in [r_0-k, r_0+k]$、$c \in [c_0-k, c_0+k]$。∎

**引理 2（下界）**：任何覆盖方案至少需要 $\lceil n/(2k+1)\rceil \cdot \lceil m/(2k+1)\rceil$ 个传感器。

**证明**：记 $S = 2k+1$，$N = \lceil n/S\rceil$，$M = \lceil m/S\rceil$。对 $0 \le i < N$、$0 \le j < M$，点 $p_{ij} = (iS, jS)$ 满足 $iS \le (N-1)S \le n-1 < n$，同理 $jS \le m-1$，故都在网格内，共 $NM$ 个。

对任意 $p_{ij} \ne p_{i'j'}$，若 $i \ne i'$，则行坐标之差 $= |i-i'|S \ge S > k$；若 $i = i'$ 则 $j \ne j'$，列坐标之差 $\ge S > k$。总之 $d_\infty(p_{ij}, p_{i'j'}) \ge S > k$。

由引理 1，一个传感器若同时覆盖这两个点，就要同时满足两个「距离 $\le k$」的约束，与其距离 $> k$ 矛盾。所以每个传感器最多覆盖一个采样点，传感器数 $\ge NM$。∎

**引理 3（上界）**：存在一个使用 $NM$ 个传感器的覆盖方案。

**证明**：对 $0 \le i < N$、$0 \le j < M$，在第 $i$ 个行块的第 $j$ 个列块内放置一个传感器，位置取

$$\Big(\min(iS + k,\ n-1),\ \min(jS + k,\ m-1)\Big)$$

第 $i$ 个行块是 $[iS,\ \min(iS + 2k,\ n-1)]$，块内任意行 $r$ 满足 $iS \le r \le iS + 2k$ 且 $r \le n-1$。

- 若 $iS + k \le n-1$：传感器行坐标为 $r_0 = iS + k$，则 $|r - r_0| \le k$（因 $r \in [r_0 - k, r_0 + k]$）✓；
- 若 $iS + k > n-1$（只可能是最后一个行块）：传感器行坐标为 $r_0 = n-1$，此时由 $iS > n-1-k$ 得 $n-1-r \le n-1-iS < k$，故 $|r - r_0| < k$ ✓。

列方向同理（把 $n$ 换成 $m$、$N$ 换成 $M$）。因此第 $(i,j)$ 个块内的所有格子都被该块的传感器覆盖，$NM$ 个块覆盖整个网格。∎

**定理**：最少传感器数 $= \lceil n/(2k+1)\rceil \cdot \lceil m/(2k+1)\rceil$。

**证明**：引理 2 给出下界、引理 3 给出达到下界的构造，两者相等。∎

## 6. 复杂度分析

- **时间**：$O(1)$，只有两次除法与一次乘法。
- **空间**：$O(1)$。

> 与「对拍用」的暴力（枚举位置组合验证最小覆盖）相比，公式解把指数级搜索压成了常数时间，这正是「切比雪夫球的方形结构 + 采样点下界」的威力。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minSensors(int n, int m, int k) {
        long long side = 2LL * k + 1;
        long long a = (n + side - 1) / side;
        long long b = (m + side - 1) / side;
        return (int)(a * b);
    }
};
```

### Python

```python
class Solution:
    def minSensors(self, n: int, m: int, k: int) -> int:
        side = 2 * k + 1
        return ((n + side - 1) // side) * ((m + side - 1) // side)
```

## 8. 边界情况与易错点

1. **边长写成 $2k$**：会漏掉中心那一格，$5\times5$、$k=1$ 时得到 $3\times3 = 9$ 而不是 $4$。
2. **忘记向上取整**：直接用 `n / side` 在 $n = 5$、$side = 3$ 时得到 1，答案会变成 1。
3. **$k = 0$**：$side = 1$，答案 $nm$，公式自然成立，不需要特判。
4. **$k$ 大于等于网格尺寸**：$side > \max(n,m)$，两个取整都是 1，答案 1。
5. **先求面积再除**：$\lceil nm / side^2\rceil$ 与正确公式不同（例如 $n=m=5$、$side=3$：前者 $\lceil 25/9\rceil = 3$，正确是 $4$）。
6. **`int` 乘法**：$k = 1000$ 时 $side = 2001$，两次取整各 ≤ 1000，乘积 ≤ $10^6$，不会溢出；但用 `long long` 写更稳。
7. **矩形而非正方形**：两个方向必须各自取整，不能合并。

**延伸思考**：若把切比雪夫距离换成**曼哈顿距离**（菱形覆盖），边长变成 $2k+1$ 的菱形，最优覆盖数不再是简单乘积——一维上需要 $\lceil n/(k+1)\rceil$ 个点（每个点覆盖 $2k+1$ 个位置中的 $k$ 个方向），二维最优铺法需要更细致的构造。若传感器只能放在「整数坐标且不越界」的约束更严（例如必须放在格子中心），结论不变，因为上面的构造已经满足。

**变体**：若要求「任意两个传感器不能互相覆盖」（独立集最大化），答案也是 $\lceil n/(2k+1)\rceil \cdot \lceil m/(2k+1)\rceil$，与本题对偶：采样点集合正是一个最大独立集。
