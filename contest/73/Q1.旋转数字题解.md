# LeetCode 旋转数字 题解

## 1. 题目概述

- **标题 / 题号**：旋转数字（#788，medium）
- **链接**：https://leetcode.cn/problems/rotated-digits/
- **来源**：LeetCode 第 73 场周赛 Q1
- **难度**：中等
- **标签**：数学，动态规划，数位 DP

**题意**：把一个整数 $x$ 的十进制表示**逐位**旋转 180°（位置不变、不能跳过任何一位）。若每一位旋转后仍是数字，称 $x$ **合法**；在合法前提上，若旋转结果与原数**不同**，称 $x$ 为**好数**。问 $[1, n]$ 内好数的个数。

题面给定的映射是固定的：

$$0\to 0,\quad 1\to 1,\quad 8\to 8,\quad 2\leftrightarrow 5,\quad 6\leftrightarrow 9$$

其余 $3,4,7$ 旋转后不再是数字，任何含它们的数都**不合法**。判定只作用在每一位数字上，不做整体翻转，因此「是否与原数相同」完全由数字集合决定。

**约束**：

- $1 \le n \le 10^4$
- 输入只有正整数，答案一定落在 $[0, n]$ 内

> 💡 签到题的关键：**别把「合法」和「好」混成一个布尔值**。合法只要求每位可转，好还额外要求「至少有一位真的变了」。把这两件事拆开，剩下的只是一次集合计数。

## 3. 解题思路

### 3.1 暴力思路

最直接的写法是对 $x = 1,2,\dots,n$ 逐个判定：遇到 $3,4,7$ 立刻判为不合法；遇到 $2,5,6,9$ 打上「已变化」标记；遇到 $0,1,8$ 只标记「仍合法」。最后「合法且已变化」的才是好数。单个数 $O(\log x)$ 位，总计 $O(n\log n)$，$n = 10^4$ 时约 $4\times 10^4$ 次位操作，C++ 与 Python 都是毫秒级，**本题直接用暴力就能过**。

但暴力有两处极易写错，翻车的往往不是复杂度而是判定：

1. 只看「有没有 $2,5,6,9$」而不排除 $3,4,7$，会把 $23$ 判成好数（$3$ 是死位）；
2. 只看「全体合法」而不要求「至少一位变化」，会把 $1$、$8$、$10$、$11$ 判成好数。

而且暴力有天花板：$n$ 每多一位，枚举量涨 10 倍，$n = 10^9$ 就不可行。本题判定本质是**逐位的**，天然适合计数而不是枚举。

### 3.2 核心观察：好数 = 合法数 − 不变数

![数字旋转后的三类命运与集合分解](images/wc73_q1_digit_classes.svg)

按「旋转 180° 后的命运」把所有数字分成三类：

- $A = \{0,1,8\}$：**自映射**，旋转后仍是自己；
- $B = \{2,5,6,9\}$：**互换**（$2\leftrightarrow 5$、$6\leftrightarrow 9$），旋转后变成另一个数字；
- $C = \{3,4,7\}$：**非法**，旋转后不再是数字。

于是三个概念都能逐位表述：$x$ **合法** $\iff$ 每一位 $\in A\cup B$；$x$ **不变** $\iff$ 每一位 $\in A$；$x$ **好** $\iff$ 每一位 $\in A\cup B$，且至少有一位 $\in B$。

记 $R = A\cup B = \{0,1,2,5,6,8,9\}$。由于 $A\subseteq R$，且 $R = A\sqcup B$，「合法」这个整体恰好被拆成互不相交的两块：

$$\{\text{合法}\} \;=\; \{\text{不变}\} \;\sqcup\; \{\text{好}\}\qquad\Rightarrow\qquad \#\text{好} \;=\; \#\text{合法} - \#\text{不变}$$

这一步是整个解法的支点：原题的「至少一位属于 $B$」是**存在性条件**，直接枚举得维护状态位；放进差集后，两个计数都退化成同一句话——「每一位都从某个 7 元（或 3 元）集合里取」。于是只需要会数

$$f(n, S) = \#\{\,x \in [0,n] \;:\; x \text{ 的每一位都} \in S\,\}$$

答案就是 $f(n, R) - f(n, A)$。

### 3.3 算法流程：数位统计 count(n, S)

![数位统计：逐位首次变小后自由填](images/wc73_q1_digit_count_flow.svg)

$f(n,S)$ 用标准的「数位统计」求：把 $n$ 写成 $L$ 位十进制 $d_0d_1\cdots d_{L-1}$，对每个位置 $i$ 枚举「$x$ 与 $n$ 首次不同的位恰好是 $i$」的那些 $x$——前 $i$ 位与 $n$ 完全一致，第 $i$ 位取一个**比 $d_i$ 小**且**属于 $S$** 的数字，后面 $L-1-i$ 位在 $S$ 中任意填。

```text
count(n, S):
    d ← n 的十进制位（高位在前），L ← len(d)，k ← |S|
    total ← 0
    for i in 0 .. L-1:
        c ← #{ v ∈ S : v < d[i] }
        total ← total + c × k^(L-1-i)        # 第 i 位首次变小，后面自由填
        if d[i] ∉ S: return total            # 前缀塌陷，更靠后的候选全部作废
    return total + 1                          # 全 L 位都合法：n 本身也算一个
```

最后返回 $count(n, R) - count(n, A)$。

这里允许**前导零**：$0 \in A\subseteq R$，补出来的前导零旋转后仍是 $0$，既不破坏「每位合法」也不制造 $B$ 位，所以「补零后的 $L$ 位串」与原数判定等价。代价是 $0$ 会被两次计数各算一次，相减时正好抵消——不需要额外写 `started`（是否已开始）状态。

### 3.4 示例演算

![n = 20 的逐位走查](images/wc73_q1_walkthrough.svg)

先看官方示例 $n = 10$（$d = [1,0]$，$R$ 有 $k=7$ 个数字、$A$ 有 $k=3$ 个）：

- $count(10, R)$：$i=0$ 时 $d_0=1$，比 $1$ 小的可行数字只有 $\{0\}$，贡献 $1\times 7^{1}=7$；$1\in R$ 继续。$i=1$ 时 $d_1=0$，没有更小的数字，贡献 $0$；$0\in R$，走完加 $1$。合计 $8$（即 $0,1,2,5,6,8,9,10$）。
- $count(10, A)$：同理 $1\times 3^{1}=3$，走完加 $1$，合计 $4$（即 $0,1,8,10$）。
- 答案 $8-4=4$，与示例 1 一致。

再看 $n = 20$，两位都逐位走查：

| 集合 | 位 $i$ | $d_i$ | 更小的可行数字 | 贡献 |
|------|--------|-------|----------------|------|
| $R$ | 0 | 2 | $\{0,1\}$ | $2\times 7^{1}=14$ |
| $R$ | 1 | 0 | 无 | $0$ |
| $R$ | — | 走完 | 前缀 $2,0$ 均合法 | $+1\Rightarrow 15$ |
| $A$ | 0 | 2 | $\{0,1\}$ | $2\times 3^{1}=6$ |
| $A$ | 0 | 2 | $2\notin A$，前缀塌陷 | 停止 $\Rightarrow 6$ |

$15-6=9$，对应 $2,5,6,9,12,15,16,19,20$。注意 $A$ 的最后一行：$d_0 = 2$ 不在 $A$ 里，所以补上 $2\times 3^1$ 后立刻返回，$20\sim29$ 一个都不该再算——这正是「塌陷即返回」的作用。

## 4. 算法细节

1. **幂次下标是 $(L-1-i)$**。第 $i$ 位后面还剩 $L-1-i$ 个自由位，故权重为 $k^{L-1-i}$；误写成 $k^{i}$ 等于把首位当末位，$n=10$ 会从 $4$ 变成 $0$。
2. **「更小的可行数字」直接数**。$S$ 只有 7 或 3 个元素，循环比较是 $O(k)$ 常数；若推广到 $S$ 很大，改成排序 + `lower_bound` 保留 $O(\log k)$。
3. **塌陷必须立即返回**。$d_i\notin S$ 说明以 $n$ 的前 $i+1$ 位为前缀的数已不合法，而「首次差异更靠后」意味着前缀完全相同，故更后面的分支一个都不存在。漏掉它会多算：$n=37$ 时 $R$ 的计数会从 $21$ 变成 $27$，多出来的正是 $30,31,32,35,36$ 与 $37$ 自身。
4. **走完所有位要加 1**。循环只覆盖 $x<n$，$x=n$ 自身需要单独补上，且只在所有位都属于 $S$ 时才执行。
5. **用补前导零代替 `started` 状态**。若坚持不许前导零，就得额外记录「是否已填非零位」并在首位排除 $0$，代码复杂一倍；补零 + 两次计数抵消 $0$ 等价且更短。
6. **$0$ 的抵消要对齐下标**。`count` 返回 $[0,n]$ 上的计数，两次调用都含 $0$，直接相减即可；别再手动 `-1`，否则 $n=10$ 会得到 $3$。
7. **常量表比 if 链稳**。把映射写成 `rot[10] = {0,1,2,-1,-1,5,9,-1,8,6}`，判定只看 `rot[d]` 的取值，比一长串 `if/else` 更不易漏掉 $5$ 或 $9$。
8. **类型选择**。本题 $n\le 10^4$，`int` 足够；若把 $n$ 放宽到 $10^{18}$，累计计数会超 32 位，需 `long long`，而 $7^{19}\approx 1.1\times 10^{16}$ 仍在 64 位内，不必上高精度。

## 5. 正确性证明

**引理 1（逐位判定的等价性）**：设 $x$ 的各位为 $c_0,\dots,c_{m-1}$，则 $x$ 合法 $\iff$ 所有 $c_j\in R$；$x$ 不变 $\iff$ 所有 $c_j\in A$；$x$ 好 $\iff$ 所有 $c_j\in R$ 且存在 $j$ 使 $c_j\in B$。

**证明**：由映射表，一位数字旋转后仍是数字当且仅当它属于 $R$，故合法性等价于每位属于 $R$。整体旋转结果与原数相同等价于每位像都等于自身，而映射表中恰有 $A$ 满足 $d\to d$，故「不变」等价于每位属于 $A$。好在合法前提上要求不同，即至少一位的像不等于自身；$R = A\sqcup B$ 中恰 $B$ 的像不等于自身。（逐位比较的合法性：合法数的首位不为 $0$，而 $0$ 只由 $0$ 映射得到，故旋转后位数不变，两个数相等当且仅当逐位相等。）∎

**引理 2（不交并分解）**：$\{\text{合法数}\} = \{\text{不变数}\}\ \sqcup\ \{\text{好数}\}$。

**证明**：由引理 1，$A\subseteq R$，故不变数必合法。任取合法数 $x$：若所有位属于 $A$，它是不变数；否则某位属于 $R\setminus A = B$，它是好数；两种情况覆盖全部合法数。互斥性：好数要求存在某位属于 $B$，不变数要求所有位属于 $A$，而 $A\cap B=\varnothing$，故不能同时成立。∎

**引理 3（补零不改变判定）**：把 $x$ 写成固定长度 $L$ 的前导零形式，则「每位属于 $S$（$S\in\{R,A\}$）」的判定与原表示一致，且 $x=0$ 在 $f(n,R)$ 与 $f(n,A)$ 中各被计 1 次。

**证明**：前导零的像是 $0\in A\subseteq R$，它既不违反「每位属于 $S$」，也不额外产生 $B$ 位，故补零与否判定相同。$x=0$ 补零后全为 $0$，既属于 $R$ 也属于 $A$，故两次计数各含它一次。∎

**引理 4（count 的正确性）**：对任意 $S$，`count(n, S)` 的返回值等于 $\#\{x\in[0,n]: x \text{ 的每一位}\in S\}$。

**证明**：对每个 $x<n$，令 $i$ 是 $x$ 与 $n$ 的 $L$ 位补零表示中**第一个不同**的位置。则 $x$ 被唯一归入第 $i$ 轮：该轮枚举 $v<d_i$ 且 $v\in S$，共 $c_i$ 种选法，后面 $L-1-i$ 位任取 $S$ 中 $k$ 个数字，计 $c_i\,k^{L-1-i}$ 个，恰好覆盖所有第 $i$ 位首次变小的合法 $x$。不同 $i$ 对应的集合互不相交（首次不同位置唯一），故 `total` 精确统计了 $[0,n)$ 中的合法 $x$。若所有位 $d_i\in S$，$n$ 自身合法，`+1` 后正好覆盖 $[0,n]$；否则在第一个 $d_i\notin S$ 处返回，此时不存在前缀与 $n$ 相同而更靠后首次变小的合法 $x$（其前缀已含非法位），故无遗漏。∎

**定理**：`rotatedDigits(n)` 返回 $[1,n]$ 中好数的个数。

**证明**：由引理 2、引理 4，$\#\{\text{好}\} = \#\{\text{合法}\} - \#\{\text{不变}\} = f(n,R) - f(n,A)$。由引理 3，补零不改变判定，而 $0$ 在两次计数中同时出现、相减抵消，故结果等于区间 $[1,n]$ 上的好数个数。∎

## 6. 复杂度分析

- **时间**：$O(L\cdot k)$，其中 $L = \lfloor\log_{10} n\rfloor + 1 \le 5$（$n\le 10^4$）、$k\le 7$ 为集合大小。两次 `count` 各扫 $L$ 位、每位比较至多 $k$ 个候选，总计不到 $100$ 次基本操作，即 $O(\log n)$；$n$ 每增大 10 倍只多一次循环，而暴力要多 10 倍枚举。
- **空间**：$O(L)$ 保存 `n` 的各位（$L\le 5$ 个整数），边除边算可降到 $O(1)$；Python 的 `str(n)` 另占 $O(L)$ 字符。
- **数值范围**：$n\le 10^4$ 时答案 $\le 2320$，`int` 足够；扩展到 $10^{18}$ 时答案约 $1.6\times 10^{15}$，需 `long long`。

## 7. 参考代码

### C++

```cpp
#include <string>
using namespace std;

class Solution {
public:
    int rotatedDigits(int n) {
        int rot[7]  = {0, 1, 2, 5, 6, 8, 9};   // 旋转后仍是数字
        int self[3] = {0, 1, 8};               // 旋转后仍是自己
        return count(n, rot, 7) - count(n, self, 3);
    }
private:
    // 统计 [0, limit] 中「每一位都属于 allow」的整数个数
    int count(int limit, const int* allow, int k) {
        string s = to_string(limit);
        int L = (int)s.size(), total = 0;
        for (int i = 0; i < L; ++i) {
            int d = s[i] - '0', rest = L - 1 - i, smaller = 0, powK = 1;
            for (int j = 0; j < k; ++j) if (allow[j] < d) ++smaller;
            for (int t = 0; t < rest; ++t) powK *= k;
            total += smaller * powK;
            bool ok = false;
            for (int j = 0; j < k; ++j) if (allow[j] == d) ok = true;
            if (!ok) return total;             // 前缀塌陷，后面的候选全废
        }
        return total + 1;                      // limit 自身也合法
    }
};
```

### Python

```python
class Solution:
    def rotatedDigits(self, n: int) -> int:
        ROTATABLE = (0, 1, 2, 5, 6, 8, 9)   # 旋转后仍是数字
        SELF = (0, 1, 8)                     # 旋转后仍是自己

        def count(limit: int, allowed: tuple) -> int:
            s, k, total = str(limit), len(allowed), 0
            for i, ch in enumerate(s):
                d, rest = ord(ch) - ord('0'), len(s) - 1 - i
                # 这一位取一个比 d 小、且允许的数字，后面的位随便填
                total += sum(1 for v in allowed if v < d) * (k ** rest)
                if d not in allowed:          # 这一位塌陷，后面不可能全合法
                    return total
            return total + 1                  # limit 本身也合法

        return count(n, ROTATABLE) - count(n, SELF)
```

## 8. 边界情况与易错点

1. **$n = 1$ 与 $n = 2$**：答案分别是 $0$ 和 $1$。$1$ 合法但不变，是「只看合法」写法最容易误判的数。
2. **$n = 10$**：$10$ 由 $1$ 与 $0$ 组成且都自映射，不是好数；答案 $4$ 而非 $5$。
3. **首位非法（$n = 3$、$n = 37$）**：`count` 在 $i=0$ 补完「更小分支」后立即返回。$n=3$ 时两个集合返回 $3$ 与 $2$，差为 $1$（只有 $2$）；漏掉提前返回则会把 $30,31,32,35,36$ 与 $37$ 自身也算进去（$21\to27$）。
4. **数字 $0$ 的双重计入**：$f(n,R)$ 与 $f(n,A)$ 都含 $0$，相减自动抵消；不要再减 1，也不要把 $0$ 排除后再相减，否则 $n=10$ 会得到 $3$。
5. **前导零**：$v<d_0$ 时允许 $v=0$，这正是「位数更短」的那些数。若禁用前导零又没补回短位数，$n=10$ 的答案会退化成 $0$（正确为 $4$）。
6. **幂次权重写反**：$k^{L-1-i}$ 写成 $k^{i}$ 时，$n=10$ 得到 $0$（正确为 $4$）；用样例自查一遍就能定位。
7. **判断顺序**：必须先累加本位的「更小分支」，再判断 $d_i\notin S$ 的塌陷；顺序颠倒会漏掉本应计入的那一批数。
8. **容斥方向**：$A\subseteq R$，故 $f(n,R)\ge f(n,A)$，差一定非负；写成 $f(A)-f(R)$ 得到负数，是典型的调试信号。

- **若旋转还要整体翻转数位顺序**（真实 7 段数码管的物理旋转）：判定会同时依赖两端数字，$108$ 这类「全自映射但反转后不同」的数要重新归类，答案与本题不同——审题时务必确认是否要求翻转。
