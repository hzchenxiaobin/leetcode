# LeetCode 逃脱阻碍者 题解

## 1. 题目概述

- **标题 / 题号**：逃脱阻碍者（#789，medium）
- **链接**：https://leetcode.cn/problems/escape-the-ghosts/
- **来源**：LeetCode 第 73 场周赛 Q2
- **难度**：中等
- **标签**：数组、数学

**题意**：你从 $(0,0)$ 出发，目的地是 $\text{target} = (x_t, y_t)$；地图上还有若干个阻碍者，第 $i$ 个从 $(x_i, y_i)$ 出发。每一回合，你和所有阻碍者**同时**行动：向东/西/南/北移动 1 格，或者原地不动。阻碍者的走法不受你控制，可以针对你采取任意策略。问是否存在你的走法，使得在**任意**阻碍者行为下，你都能在抵达目的地的那一回合（含）之前，全程不与任何阻碍者同格——特别地，与阻碍者**同时**站上 target 也不算逃脱成功。

**约束**：

- $1 \le \text{ghosts.length} \le 100$
- $\text{ghosts}[i].\text{length} = 2$，$-10^4 \le x_i, y_i \le 10^4$
- 同一位置可能有多个阻碍者（不保证互异）
- $\text{target.length} = 2$，$-10^4 \le x_t, y_t \le 10^4$

## 2. 示例

**示例 1**

```text
输入：ghosts = [[1,0],[0,3]], target = [0,1]
输出：true
解释：你从 (0,0) 一步就到 (0,1)，只需 1 步；
      两个阻碍者到 (0,1) 都至少要 2 步，谁也拦不住你。
```

**示例 2**

```text
输入：ghosts = [[1,0]], target = [2,0]
输出：false
解释：你要 2 步才能到 (2,0)，而阻碍者在 (1,0)，
      1 步就到终点，正好卡在你与目的地之间，稳稳守株待兔。
```

**示例 3**

```text
输入：ghosts = [[2,0]], target = [1,0]
输出：false
解释：你和阻碍者都需要 1 步到达 (1,0)，双方同时抵达；
      题目规定同时到达（包括目的地）不算逃脱成功。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的做法是把题目当成一个**博弈搜索**：状态写成「你的位置 + 全部阻碍者的位置 + 已用回合数」，每层枚举你的一次移动，再枚举所有阻碍者的联合移动（要对每种阻碍者走法都成立，是 $\forall$ 分支），搜索到你在终点仍未被抓为止。

状态数直接爆炸：单是双方的坐标就落在 $2\times10^4 \times 2\times10^4$ 的格点上，阻碍者最多 100 个，联合状态是天文数字；即便把搜索限制在终点附近的小方框内，分支因子也有 $5^{100}$。这条路不可行——它没有利用「网格无墙、距离可以闭式写出」这个结构。

### 3.2 核心观察：同时出发，只比「到终点的最少步数」

![你与阻碍者到终点的最少步数比较](images/wc73_q2_distance_race.svg)

网格里没有墙，从任意点 $p$ 到 $q$ 的最少步数就是**曼哈顿距离** $\lvert p_x-q_x\rvert + \lvert p_y-q_y\rvert$，而且这个数字是**硬下界**：每一回合最多把某一维坐标改动 1，所以谁也快不过它。

于是整局比赛被压缩成两个数字的比较：

$$T = \lvert x_t\rvert + \lvert y_t\rvert,\qquad d_i = \lvert x_i-x_t\rvert + \lvert y_i-y_t\rvert$$

你会以 $T$ 步抵达终点；阻碍者 $i$ 至少要 $d_i$ 步。得到判据：

$$\text{逃脱成功} \iff \forall i,\ d_i > T$$

两个方向都不难体会：

- 若某个 $d_i \le T$，它沿最短路直奔终点即可。$d_i < T$ 时它先到并原地守着；$d_i = T$ 时你们**同时**踩上终点，按题意同样算失败。
- 若所有 $d_i > T$，你就沿任意一条最短路径全速直冲。任意时刻 $t$，阻碍者到终点的距离至少还剩 $d_i - t$，而你的只剩 $T-t$，两者恒不相等，因此**它们不可能和你在同一格**。

> 💡 **绕路是净亏**：每多花一步，你的到达时刻就变大，只会让更多阻碍者满足 $d_i \le T$，并不会换来任何安全。所以「最短路径 + 不停留」永远是最优策略。

### 3.3 算法流程

![单遍比较的算法流程](images/wc73_q2_algorithm_flow.svg)

1. 计算你的最短步数 $T = \lvert x_t\rvert + \lvert y_t\rvert$（起点就是原点，所以直接对 $\text{target}$ 取绝对值）。
2. 遍历 `ghosts`，对每个阻碍者计算 $d_i = \lvert x_i-x_t\rvert + \lvert y_i-y_t\rvert$。
3. 一旦发现某个 $d_i \le T$，立刻返回 `false`（它比你近或与你同速，终点必被守住）。
4. 全部扫完都没触发，返回 `true`。

比较用的不等号方向是本题的**唯一**易错点：必须是「阻碍者**严格更远**」才安全。

### 3.4 示例演算

![三个官方示例的距离走查](images/wc73_q2_walkthrough.svg)

- **示例 1**：$T = \lvert0\rvert + \lvert1\rvert = 1$；两个阻碍者分别要 $2$ 和 $2$ 步，$2 > 1$ 全成立，输出 `true`。
- **示例 2**：$T = \lvert2\rvert + \lvert0\rvert = 2$；阻碍者要 $\lvert1-2\rvert + 0 = 1$ 步，$1 \le 2$ 触发失败，输出 `false`。
- **示例 3**：$T = \lvert1\rvert + \lvert0\rvert = 1$；阻碍者要 $\lvert2-1\rvert + 0 = 1$ 步，$1 \le 1$（同时到达）触发失败，输出 `false`。

三个例子恰好覆盖三种形态：**全部严格更远**、**明显更近**、**恰好同时**。

## 4. 算法细节

1. **距离闭式化**：无墙网格上不需要 BFS/Dijkstra，最短距离就是 $\lvert\Delta x\rvert + \lvert\Delta y\rvert$，一次 $O(1)$ 的算术运算就代替了一整次图搜索。
2. **只算到终点，不算到你**：判据里双方都对着 target 度量，避免「阻碍者此刻在哪、往哪走」这类动态信息，把博弈问题降成静态比较。
3. **等号归入失败**：$d_i = T$ 表示双方同时抵达终点，题面明确「同时到达一个位置（包括目的地）都不算逃脱成功」，所以代码写 `d <= mine` 而不是 `d < mine`。
4. **提前返回**：命中即 `return false`，最坏仍 $O(n)$，但在绝大多数随机数据上几乎立刻就结束。
5. **不需要去重**：多个阻碍者站在同一格只是重复计算同一个 $d_i$，结论不受影响；连「阻碍者是否互相阻挡」也不用考虑——它们可以重叠。
6. **整数安全**：坐标绝对值 $\le 10^4$，单轴距离 $\le 2\times10^4$，总距离 $\le 4\times10^4$，C++ 的 `int` 足够；若把坐标放大到 $10^9$ 量级就要换 `long long`。
7. **不要用欧氏距离**：$\sqrt{\cdot}$ 既不对（一步只能走 1 格）又会引入浮点误差，必须用曼哈顿距离。
8. **接口与顺序**：函数名 `escapeGhosts`，参数 `ghosts` 在前、`target` 在后，返回 `bool`，与题目给出的签名一致。

## 5. 正确性证明

![用「到终点的剩余距离」夹住两条轨迹](images/wc73_q2_intercept_bound.svg)

**引理 1（到达时间下界）**：从任意起点 $p$ 出发，若某走法在第 $t$ 回合到达终点，则 $t \ge \operatorname{dist}(p, \text{target})$；等价地，$t < \operatorname{dist}(p,\text{target})$ 时所在的格子一定不是终点。

**证明**：每回合移动至多改变 1 单位曼哈顿位移，$t$ 回合累计走过的曼哈顿路程不超过 $t$。由三角不等式 $\operatorname{dist}(p,\text{target}) \le$ 走过的路程，故 $t \ge \operatorname{dist}(p,\text{target})$。∎

**引理 2（剩余距离的 1-Lipschitz 性）**：设阻碍者 $i$ 在时刻 $t$ 位于 $g_i(t)$，则对任意策略都有

$$\operatorname{dist}(g_i(t), \text{target}) \ge d_i - t$$

**证明**：对 $t$ 归纳。$t=0$ 时取等号。若 $t$ 时刻成立，本回合它至多移动 1 格（或原地不动），由三角不等式 $\operatorname{dist}(g_i(t+1),\text{target}) \ge \operatorname{dist}(g_i(t),\text{target}) - \operatorname{dist}(g_i(t),g_i(t+1)) \ge \operatorname{dist}(g_i(t),\text{target}) - 1 \ge d_i - (t+1)$。∎

**推论**：若你每回合都沿最短路径走一步（每步恰好让到终点的距离减 1），则 $t \le T$ 时 $\operatorname{dist}(p(t),\text{target}) = T - t$。

**定理**：`escapeGhosts(ghosts, target)` 返回 `true`，当且仅当对所有 $i$ 都有 $d_i > T$。

**证明（充分性）**：设所有 $d_i > T$。你的策略是「沿任意一条最短路径，每回合走一步」，第 $T$ 回合站上 target。对任意 $0 \le t \le T$ 与任意阻碍者 $i$，由引理 2 与推论

$$\operatorname{dist}(g_i(t),\text{target}) \ge d_i - t > T - t = \operatorname{dist}(p(t),\text{target}) \ge 0$$

若 $g_i(t) = p(t)$，则两点到 target 的距离应相等，与上式矛盾，故你在全程都不与任何阻碍者同格。特别地 $t = T$ 时 $\operatorname{dist}(g_i(T),\text{target}) > 0$，说明终点上没有阻碍者。又因引理 2 对阻碍者的**任意**走法都成立（推理未用到其具体策略），所以「不管阻碍者怎么移动」都能逃脱，返回 `true` 正确。∎

**证明（必要性）**：设存在某个 $i$ 使 $d_i \le T$。取该阻碍者的策略「每回合沿最短路走向 target，第 $d_i$ 回合到达后原地不动」。设你在第 $t$ 回合首次站上 target，由引理 1 取 $p=(0,0)$ 得 $t \ge T \ge d_i$，而它在第 $d_i$ 回合就已经在 target 上并一直待着，于是 $t$ 时刻你与它同格——被抓，逃脱失败。也就是说存在一种阻碍者行为让你无法成功，故返回 `false` 正确。∎

## 6. 复杂度分析

- **时间**：$O(n)$，其中 $n = \text{ghosts.length} \le 100$。每个阻碍者只做 4 次减法、4 次取绝对值、3 次加法与 1 次比较，全部为常数时间；最坏扫完整个数组。
- **空间**：$O(1)$ 额外空间，只用 `mine` 与 `d` 两个整型临时变量，输入数组原地只读，不复制、不建图、不建队列。
- **对比**：若真的写博弈搜索，状态至少是「位置对 × 阻碍者位置」的笛卡尔积，指数级；本解法把这个结构彻底绕开了。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool escapeGhosts(vector<vector<int>>& ghosts, vector<int>& target) {
        int tx = target[0], ty = target[1];
        int mine = abs(tx) + abs(ty);          // 你到终点的最短步数 T
        for (const vector<int>& g : ghosts) {
            int d = abs(g[0] - tx) + abs(g[1] - ty);  // 阻碍者 i 的最短步数
            if (d <= mine) return false;       // 比你近或同时到：必定被堵
        }
        return true;
    }
};
```

### Python

```python
class Solution:
    def escapeGhosts(self, ghosts: list[list[int]], target: list[int]) -> bool:
        tx, ty = target
        mine = abs(tx) + abs(ty)               # 你到终点的最短步数 T
        for gx, gy in ghosts:
            d = abs(gx - tx) + abs(gy - ty)    # 阻碍者 i 的最短步数
            if d <= mine:
                return False                   # 比你近或同时到达：被堵死
        return True
```

## 8. 边界情况与易错点

1. **等号方向写反**：`d < mine` 会漏掉「同时到达」的情形，示例 3 立刻挂掉；必须是 `d <= mine`。
2. **目的地就是起点**：`target = [0,0]` 时 $T = 0$，只要没有阻碍者站在原点就返回 `true`（第 0 回合你已经到达，无需再走）。
3. **阻碍者站在原点**：此时 $d_i = T$（无论 $T$ 是多少），判据给出 `false`；直觉上它从第一回合就能贴身跟着你，确实跑不掉。
4. **只有一个阻碍者却很远**：判据要求「所有 $d_i > T$」，不能因为「大部分都很远」就放过那一个近的，必须全扫一遍。
5. **重复坐标**：同一格站着多个阻碍者不改变结论，无需 set 去重，也不会因为重复比较而出错。
6. **极值坐标**：$-10^4$ 与 $10^4$ 混合时 `abs` 结果仍是正数，C++ `int` 不会溢出（最大 $4\times10^4$）；Python 本身无溢出问题。
7. **误用 BFS**：本题网格无墙、无边界，BFS 只是把 $O(1)$ 的公式拖成 $O(\text{面积})$，属于杀鸡用牛刀且极易写错。
8. **误以为可以等待**：停留一回合会让 $T$ 增大，等于把「安全」主动让给对方，不会带来任何好处。

**延伸思考**：本题之所以能一行判据解决，靠的是**无墙**+**双方速度相同**两条前提。若地图出现墙体，曼哈顿距离不再是下界，「谁先到」要对每个格子比较两套 BFS 距离（多源 BFS）；此时判据变成「是否存在一条路径，使路径上每一格你的到达时刻都严格早于所有阻碍者」，这正是 2258 的解法。另一个变体是「阻碍者速度是你的 $k$ 倍」，只需把判据改成 $d_i > k\cdot T$ 即可（同时到达的边界仍要仔细处理）。再进一步，如果题目要求输出**具体走法**而不只是可行性，就得在满足判据的前提下做一次贪心回溯——因为任意最短路径都安全，随便走一条即可。
