# LeetCode 分割正方形 II 题解

## 1. 题目概述

- **标题 / 题号**：分割正方形 II（#3454，hard）
- **链接**：https://leetcode.cn/problems/separate-squares-ii/
- **来源**：LeetCode 第 150 场双周赛 Q3
- **难度**：困难
- **标签**：线段树、数组、二分查找、扫描线

**题意**：给定 $n$ 个边与坐标轴平行的正方形 `squares[i] = [xᵢ, yᵢ, lᵢ]`（左下角 + 边长）。找一条水平线 $y$，使**线上方**的正方形总面积等于**线下方**的面积，返回**最小的**这样的 $y$（误差 $10^{-5}$ 内算对）。

与同场 Q2 的唯一区别：**重叠区域只统计一次**——统计的是正方形的**并集**面积，而不是各正方形面积之和。

**约束**：

- $1 \le n \le 5\times10^4$
- $0 \le x_i, y_i \le 10^9$，$1 \le l_i \le 10^9$
- **所有正方形的总面积不超过 $10^{15}$**
- 答案误差 $10^{-5}$ 以内视为正确

## 2. 示例

**示例 1**

```text
输入：squares = [[0,0,1],[2,2,1]]
输出：1.00000
解释：两个 1×1 正方形不重叠，并集面积 2，y = 1 时上下各 1。
```

**示例 2**

```text
输入：squares = [[0,0,2],[1,1,1]]
输出：1.00000
解释：小正方形完全落在大正方形内部，重叠只算一次，并集面积 = 4（不是 5）。
      每层的截面长度都是 2，所以 y = 1 时上下各 2。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的做法：枚举所有"层"（$y_i$ 与 $y_i + l_i$ 共 $2n$ 个高度切出的区间），对每个高度重新扫一遍所有正方形求 x 方向并集长度，得到每层面积后累加找答案。每层 $O(n \log n)$，总体 $O(n^2 \log n)$，$n = 5\times10^4$ 时约 $10^{10}$，不可行。

另一个思路是"二分 $y$ + 每次用扫描线算并集面积"，复杂度 $O(n\log n\log C)$，可以过，但常数较大。而本题有一个更漂亮的一次扫描做法：**答案只可能在层与层的边界之间被确定**，于是从小到大扫过所有层，边累加边定位答案。

### 3.2 核心观察：层分解 + 每层并集长度

![并集面积 = 每一高度层被覆盖的 x 总长度对 y 的积分](images/bw150_q3_layers.svg)

记 $L(t)$ 为高度 $t$ 处、所有**覆盖该高度**的正方形的 x 区间之**并集长度**：

$$L(t) = \Bigl\lvert \bigcup_{i:\ y_i \le t < y_i + l_i} [x_i,\ x_i + l_i] \Bigr\rvert$$

由"截面法"（Cavalieri 原理），并集面积等于

$$A(y) = \int_0^y L(t)\,\mathrm{d}t$$

关键性质：

1. **$L(t)$ 只在 $2n$ 个事件处变化**：某个正方形在 $y_i$ 处"进入"（把 $[x_i, x_i+l_i]$ 加入覆盖），在 $y_i + l_i$ 处"离开"（移出覆盖）。两层事件之间 $L(t)$ 恒定。
2. 于是 $A(y)$ 是**分段线性、连续、单调不减**的函数，且每层的增量是"整数 $\times$ 整数"——可以**全程用整数精确累加**。
3. 答案是最小的 $y$ 使 $A(y) \ge \frac{1}{2}A(\infty)$。扫到第一个使累计值跨过一半的层，在该层内解一次线性方程即可。

### 3.3 算法流程

![线段树维护覆盖长度：区间加 + 根节点 covered](images/bw150_q3_segment_tree.svg)

```text
1. 把所有 x_i、x_i + l_i 排序去重 → xs[0..m-1]，叶子是相邻端点之间的“段”
2. 事件：每个正方形产生两个事件 (y_i, +1, [x_i, x_i+l_i]) 与 (y_i+l_i, −1, …)
3. 按 y 升序扫事件；每两个相邻事件之间是一层：
       layer_len = covered[1]（线段树根节点维护的当前覆盖总长度）
       记录 band = (层底, 层顶, layer_len)
   在 y 处先结算上一层，再批量执行该 y 的所有事件
4. total = Σ layer_len × 层高（= 并集总面积），half = total / 2
5. 再扫一遍 band：
       acc += layer_len × 层高
       若 layer_len > 0 且 acc 首次 ≥ half：
           返回 层底 + (half − (acc − layer_len×层高)) / layer_len
```

**线段树**的职责：支持「对一个 x 区间加/减 1」并随时回答「被覆盖的总长度」。每个节点维护：

- `cnt[node]`：本节点区间被**完整覆盖**的次数；
- `covered[node]`：本节点区间内被覆盖的长度。

重算规则：`cnt > 0` 时整段都被覆盖（`covered = xs[r] - xs[l]`）；否则叶子为 0、内部节点为左右孩子之和。根节点的 `covered` 就是 $L(t)$。

### 3.4 示例演算

![示例 1：三层事件切分，第一层就跨过一半，答案 1.0](images/bw150_q3_example_walkthrough.svg)

对示例 1（`[[0,0,1],[2,2,1]]`）：

| 层 | 截面长度 $L$ | 层面积 | 累计 |
|----|------|--------|------|
| $[0,1]$ | 1 | 1 | 1（≥ half = 1，命中） |
| $[1,2]$ | 0 | 0 | 1 |
| $[2,3]$ | 1 | 1 | 2 = 总面积 |

$y = 0 + \dfrac{1 - 0}{1} = 1$，与输出一致。

示例 2（`[[0,0,2],[1,1,1]]`）更有意思：小正方形完全在大正方形内部，并集面积是 4（不是 Q2 的 5），每层 $L(t) = 2$，于是 $y = 2/2 = 1$。同一个输入在 Q2 的答案是 $7/6 \approx 1.16667$——差异正来自"重叠算不算两次"。

## 4. 算法细节

1. **离散化到"段"**：$m$ 个端点划分出 $m-1$ 个小段，叶子代表 $[xs[j], xs[j+1])$，长度 $xs[j+1]-xs[j]$；更新时把 $[x_i, x_i+l_i]$ 映射成下标区间 $[\text{idx}(x_i), \text{idx}(x_i+l_i))$。
2. **事件先结算后执行**：扫到高度 $y$ 时，先用**上一层的覆盖长度**结算区间 $[\text{prev}, y]$，再处理该 $y$ 上的全部事件。顺序反了会漏算或错算一层。
3. **同高度事件批量处理**：多个正方形可能在同一个 $y$ 上进出，必须一次性处理完再开始下一层，否则会产生零高度的"假层"。
4. **整数精确**：层高、覆盖长度都是整数，累计面积是整数（$\le 10^{15}$，`long long` 足够）；只在最后一步做一次浮点除法，因此没有累计误差，$10^{-5}$ 的精度绰绰有余。
5. **`total` 也可直接由 band 求和得到**，不必另算并集面积。
6. **线段树用数组实现**：节点数 $4m$；递归深度 $O(\log m) \le 17$。C++ 用 `vector`，Python 用 `list`。
7. **`m == 1` 不会出现**：$l_i \ge 1$ 保证每个正方形给出两个不同的 x 端点。

## 5. 正确性证明

**引理 1（层分解）**：并集面积 $A(y) = \int_0^y L(t)\,\mathrm{d}t$，其中 $L(t)$ 如上定义。

**证明**：设 $U$ 为所有正方形的并集，$U_y = U \cap \{0 \le \text{纵坐标} \le y\}$。对 $U_y$ 作"切片"：对每个 $t$，$U_y$ 在高度 $t$ 处的截面是 $\bigcup_{i: y_i \le t < y_i+l_i}[x_i, x_i+l_i]$，长度为 $L(t)$。由测度的切片（Fubini）定理，$U_y$ 的面积 $=\int_0^y L(t)\,\mathrm{d}t$。∎

**引理 2（$L$ 分段常值，事件完备）**：$L(t)$ 在每两个相邻事件高度之间恒定；事件集合恰为 $\{y_i\}$ 与 $\{y_i + l_i\}$。

**证明**：固定 $t$，覆盖 $t$ 的正方形集合 $S(t) = \{i : y_i \le t < y_i + l_i\}$。当 $t$ 在两个相邻事件之间移动时，没有任何 $y_i$ 或 $y_i+l_i$ 被跨过，故 $S(t)$ 不变，$L(t)$ 也不变。反之，跨过 $y_i$（$i$ 进入）或 $y_i+l_i$（$i$ 离开）时 $S(t)$ 变化，故事件必须包含这 $2n$ 个高度。∎

**引理 3（线段树正确维护 $L$）**：扫描到高度 $t$ 时，线段树根节点的 `covered` 值等于 $L(t)$。

**证明**：对线段树高度归纳。叶子的 `covered` 为整段长度（被覆盖）或 0；内部节点若 `cnt > 0` 则整个区间被某次完整更新覆盖，`covered` 即区间长度；否则其覆盖完全由两个孩子决定，等于两者之和。这也正是"并集长度"的递归定义。由引理 2，每个正方形的进入/离开恰好对应一次区间 $+1/-1$，故任何时刻的 `cnt` 都是真实覆盖重数。∎

**引理 4（答案定位）**：设 `band` 按高度升序排列，累计面积 $acc_k = \sum_{j<k} L_j \cdot h_j$。若 $k$ 是第一个满足 $acc_{k+1} \ge \text{half}$ 的下标，则最小可行高度为 $y^\* = \text{lo}_k + \dfrac{\text{half} - acc_k}{L_k}$（$L_k > 0$）。

**证明**：由引理 1、2，$A$ 在 $[\text{lo}_k, \text{hi}_k]$ 上等于 $acc_k + L_k(t - \text{lo}_k)$，且此前的层累计都不足 half，即 $A(y) < \text{half}$ 对所有 $y \le \text{lo}_k$ 成立，故 $y^\* \ge \text{lo}_k$。在该层内 $A$ 严格递增（$L_k > 0$），解 $A(y) = \text{half}$ 得唯一根，即最小可行点。∎

**定理**：算法输出的 $y$ 就是所求的最小水平线高度。

**证明**：由引理 3 扫描得到的 `band` 序列与真实 $A(y)$ 完全一致；由引理 4 定位的 $y^\*$ 满足 $A(y^\*) = \text{half} = \frac{1}{2}A(\infty)$，即线上面积 $= A(\infty) - A(y^\*) = \text{half}$ 等于线下面积；且按引理 4 的论证它是最小的。整数累加保证 $A$ 的值精确，最后一次除法只引入不超过 $10^{-16}$ 相对误差，远小于 $10^{-5}$ 容差。∎

## 6. 复杂度分析

- **时间**：$O(n\log n)$。离散化排序 $O(n\log n)$；事件排序 $O(n\log n)$；每个事件一次线段树区间更新 $O(\log n)$，共 $2n$ 次；最后的 band 扫描 $O(n)$。总计 $O(n\log n)$，$n=5\times10^4$ 时约 $10^6$ 级别操作。
- **空间**：$O(n)$。$xs$ 与事件数组各 $O(n)$，线段树 $4m = O(n)$ 个节点。

## 7. 参考代码

### C++

```cpp
class Solution {
    vector<long long> xs;
    vector<int> cnt;
    vector<long long> covered;

    void update(int node, int l, int r, int ql, int qr, int delta) {
        if (qr <= l || r <= ql) return;
        if (ql <= l && r <= qr) {
            cnt[node] += delta;
        } else {
            int mid = (l + r) >> 1;
            update(node << 1, l, mid, ql, qr, delta);
            update(node << 1 | 1, mid, r, ql, qr, delta);
        }
        if (cnt[node] > 0) covered[node] = xs[r] - xs[l];
        else if (r - l == 1) covered[node] = 0;
        else covered[node] = covered[node << 1] + covered[node << 1 | 1];
    }

public:
    double separateSquares(vector<vector<int>>& squares) {
        struct Event { long long y, xl, xr; int delta; };
        vector<Event> events;
        for (auto& sq : squares) {
            long long x = sq[0], y = sq[1], l = sq[2];
            xs.push_back(x);
            xs.push_back(x + l);
            events.push_back({y, x, x + l, 1});
            events.push_back({y + l, x, x + l, -1});
        }
        sort(xs.begin(), xs.end());
        xs.erase(unique(xs.begin(), xs.end()), xs.end());
        int m = (int)xs.size();
        cnt.assign(4 * m + 8, 0);
        covered.assign(4 * m + 8, 0);
        sort(events.begin(), events.end(),
             [](const Event& a, const Event& b) { return a.y < b.y; });

        struct Band { long long lo, hi, len; };
        vector<Band> bands;
        long long prev = events[0].y;
        size_t idx = 0;
        while (idx < events.size()) {
            long long y = events[idx].y;
            if (y > prev) {
                bands.push_back({prev, y, covered[1]});
                prev = y;
            }
            while (idx < events.size() && events[idx].y == y) {
                int ql = (int)(lower_bound(xs.begin(), xs.end(), events[idx].xl) - xs.begin());
                int qr = (int)(lower_bound(xs.begin(), xs.end(), events[idx].xr) - xs.begin());
                update(1, 0, m - 1, ql, qr, events[idx].delta);
                idx++;
            }
        }

        long long total = 0;
        for (auto& b : bands) total += (b.hi - b.lo) * b.len;
        double half = (double)total / 2.0;
        long long acc = 0;
        for (auto& b : bands) {
            long long band = (b.hi - b.lo) * b.len;
            if (b.len > 0 && (double)acc + (double)band >= half)
                return (double)b.lo + (half - (double)acc) / (double)b.len;
            acc += band;
        }
        return bands.empty() ? 0.0 : (double)bands.back().hi;
    }
};
```

### Python

```python
class Solution:
    def separateSquares(self, squares: list[list[int]]) -> float:
        xs = []
        events = []  # (y, xl, xr, delta)
        for x, y, l in squares:
            xs.append(x)
            xs.append(x + l)
            events.append((y, x, x + l, 1))
            events.append((y + l, x, x + l, -1))
        xs = sorted(set(xs))
        m = len(xs)
        index = {v: i for i, v in enumerate(xs)}
        events.sort()

        cnt = [0] * (4 * m + 8)      # 该节点被完整覆盖的次数
        covered = [0] * (4 * m + 8)  # 该节点被覆盖的 x 长度

        def update(node: int, l: int, r: int, ql: int, qr: int, delta: int) -> None:
            if qr <= l or r <= ql:
                return
            if ql <= l and r <= qr:
                cnt[node] += delta
            else:
                mid = (l + r) >> 1
                update(node << 1, l, mid, ql, qr, delta)
                update(node << 1 | 1, mid, r, ql, qr, delta)
            if cnt[node] > 0:
                covered[node] = xs[r] - xs[l]
            elif r - l == 1:
                covered[node] = 0
            else:
                covered[node] = covered[node << 1] + covered[node << 1 | 1]

        # 一段段扫过 y：每层 [prev, y] 的并集面积 = 覆盖长度 × 层高
        bands = []
        prev, idx = events[0][0], 0
        while idx < len(events):
            y = events[idx][0]
            if y > prev:
                bands.append((prev, y, covered[1]))
                prev = y
            while idx < len(events) and events[idx][0] == y:
                _, xl, xr, delta = events[idx]
                update(1, 0, m - 1, index[xl], index[xr], delta)
                idx += 1

        total = sum((hi - lo) * length for lo, hi, length in bands)
        half = total / 2.0
        acc = 0
        for lo, hi, length in bands:
            band = (hi - lo) * length
            if acc + band >= half and length > 0:
                return lo + (half - acc) / length
            acc += band
        return float(bands[-1][1])
```

## 8. 边界情况与易错点

1. **重叠只算一次**：这是与 Q2 的核心差异。若直接累加 $l_i^2$，示例 2 会得到 5 而不是 4，答案变成 $7/6$。
2. **同高度事件必须批量**：多个正方形在同一个 $y$ 进出时，若逐个事件就结算一层，会产生层高为 0 的假层；虽然层高为 0 不影响面积，但 `covered` 的中间状态会污染结算。
3. **先结算再更新**：层 $[\text{prev}, y]$ 的截面长度是"该层内"的 $L$，也就是**处理 y 处事件之前**的 `covered[1]`。
4. **`L = 0` 的层不能用来求解**：`half - acc` 除以 0 会出问题；判断顺序写成 `length > 0 and acc + band >= half`。
5. **正方形完全嵌套 / 完全相同**：线段树用 `cnt` 计数而非布尔标记，重复覆盖能正确累加与撤销（示例 2 就是嵌套）。
6. **边界相切**：两个正方形只在边界上接触时，并集面积不受影响（测度为零），事件顺序无所谓；不要为了"相切"增加特判。
7. **整数溢出**：坐标最大 $2\times10^9$（$x_i + l_i$），面积最大 $10^{15}$，都在 `long long` 范围内；用 `int` 存坐标会溢出（C++ 里 `sq[0] + sq[2]` 可能超过 `INT_MAX`）。
8. **Python 的闭包递归**：`update` 内部递归深度 $O(\log m)$，但调用次数约 $2n \times 2\log m$，注意别在循环里重复创建列表；`index` 字典把坐标映射到下标，避免 `list.index` 的 $O(n)$ 查找。
