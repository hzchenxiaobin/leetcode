# LeetCode 最短匹配子字符串 题解

## 1. 题目概述

- **标题 / 题号**：最短匹配子字符串（#3455，hard）
- **链接**：https://leetcode.cn/problems/shortest-matching-substring/
- **来源**：LeetCode 第 150 场双周赛 Q4
- **难度**：困难
- **标签**：双指针、字符串、二分查找、字符串匹配

**题意**：给定字符串 `s` 与模式 `p`，其中 `p` **恰好包含两个 `'*'`**。`'*'` 可以匹配**任意长度（含 0）**的字符序列。求 `s` 的**最短子串**，使其与 `p` 完全匹配；没有则返回 `-1`。空子串也算合法子串。

**约束**：

- $1 \le |s| \le 10^5$
- $2 \le |p| \le 10^5$，`p` 只含小写字母且**恰好两个 `'*'`**

## 2. 示例

**示例 1**

```text
输入：s = "abaacbaecebce", p = "ba*c*ce"
输出：8
解释：最短匹配子串是 s[5..12] = "baecebce"
      = "ba" + "e" + "c" + "eb" + "ce"，长度 8。
```

**示例 2**

```text
输入：s = "baccbaadbc", p = "cc*baa*adb"
输出：-1
解释：后缀 "adb" 在 s 中不出现，任何子串都无法匹配。
```

**示例 3**

```text
输入：s = "a", p = "**"
输出：0
解释：两个 '*' 都匹配空串，空子串即匹配，长度 0。
```

**示例 4**

```text
输入：s = "madlogic", p = "*adlogi*"
输出：6
解释：取子串 "adlogi"，首尾的 '*' 都匹配空串。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有 $O(n^2)$ 个子串，每个用通配符匹配判定，单次 $O(|p|)$，总 $O(n^2|p|) \approx 10^{15}$，不可行。即使把匹配压缩到 $O(1)$（预处理），$O(n^2)$ 个区间仍然太多。

必须利用"**恰好两个 `'*'`**"这一强结构。

### 3.2 核心观察：`p` 被两个 `'*'` 切成三段固定文本

![p = A*B*C，匹配的子串形状固定为 A + X + B + Y + C](images/bw150_q4_split.svg)

把 $p$ 按两个 `'*'` 切开：

$$p = A \; * \; B \; * \; C$$

其中 $A, B, C$ 都是**不含 `'*'` 的字面串**（可以为空）。一个串 $t$ 与 $p$ 匹配，当且仅当

$$t = A + X + B + Y + C$$

其中 $X, Y$ 是任意串（可为空）。于是

$$|t| = |A| + |B| + |C| + |X| + |Y|$$

要最短，就让 $X$、$Y$ **尽量短**，也就是让 $A, B, C$ 在 $s$ 中的出现位置**尽量紧凑**。

形式化：在 $s$ 中选三个起点 $i \le j \le k$，满足

- $s[i \ldots i+|A|) = A$，即 $A$ 出现在 $i$；
- $j \ge i + |A|$ 且 $s[j \ldots j+|B|) = B$；
- $k \ge j + |B|$ 且 $s[k \ldots k+|C|) = C$；

此时对应子串是 $s[i \ldots k+|C|)$，长度 $= k + |C| - i$。目标是

$$\min \big(k + |C| - i\big)$$

### 3.3 算法流程

![三步流水线：出现位置 → minC → h → 扫 A](images/bw150_q4_pipeline.svg)

把"同时选 $i, j, k$"拆成从右往左的三层后缀最小值：

1. **出现位置**：用 Z 函数（`pattern + '#' + s`）在 $O(|pat| + n)$ 内求出 `occA`、`occB`、`occC` 三个布尔数组（`occ[i]` = 该模式是否从 $i$ 开始出现）。
2. **`minC[x]`**：$C$ 的最小合法起点，要求 $\ge x$：

$$\text{minC}[x] = \min\{\, k \ge x : \text{occC}[k] \,\}$$

从右往左一次递推：`minC[x] = occC[x] ? x : minC[x+1]`。
3. **`h[e]`**：从位置 $e$ 起依次放下 $B$、$C$ 后能得到的最小右端点：

$$h[e] = \min\Big(h[e+1],\ \big[\text{occB}[e]\big]\ \text{minC}[e+|B|] + |C|\Big)$$

其中 $[\cdot]$ 表示条件成立才取该项，否则为 $+\infty$。
4. **扫 $A$**：对每个 `occA[i]` 为真的 $i$，候选长度是 $h[i+|A|] - i$，取最小；若全为 $+\infty$ 返回 `-1`。

```text
1. 切分 p → A, B, C
2. occA, occB, occC = Z 函数求出现位置
3. minC[x] = occC[x] ? x : minC[x+1]        （x 从 n 递减到 0）
4. h[e] = min(h[e+1], occB[e] ? minC[e+|B|] + |C| : ∞)   （e 从 n 递减到 0）
5. ans = min over i with occA[i] of (h[i+|A|] − i)
6. ans = ∞ ? −1 : ans
```

### 3.4 示例演算

![示例 1：A 出现在 0 与 5，取 i = 5 得长度 8](images/bw150_q4_example_walkthrough.svg)

对示例 1（`s = "abaacbaecebce"`，`p = "ba*c*ce"`，故 $A = \text{"ba"}$、$B = \text{"c"}$、$C = \text{"ce"}$）：

- `occA`：$i = 0$（`s[0..1] = "ba"`）与 $i = 5$（`s[5..6] = "ba"`）；
- `occB`（字符 `'c'`）：4、8、11；
- `occC`（`"ce"`）：8、11；
- `minC`：$x \le 8 \Rightarrow 8$，$9 \le x \le 11 \Rightarrow 11$，$x \ge 12 \Rightarrow \infty$；
- `h`：$h[4] = \text{minC}[5] + 2 = 10$，$h[8] = \text{minC}[9] + 2 = 13$，$h[11] = \infty$；后缀取最小后 $h[0..4] = 10$、$h[5..8] = 13$、$h[9..11] = \infty$。

| $i$ | $h[i+2]$ | 候选长度 |
|-----|----------|----------|
| 0 | $h[2] = 10$ | 10 |
| 5 | $h[7] = 13$ | **8** |

答案 8：$s[5..12] = \text{"baecebce"}$，对应 $A$ 在 5、$B$ 在 8、$C$ 在 11，空隙 $X = \text{"e"}$、$Y = \text{"eb"}$。

其余示例：示例 2 中 $C = \text{"adb"}$ 在 $s$ 中不出现，`minC` 全为 $\infty$，故 `h` 全为 $\infty$、答案 `-1`；示例 3 的 `p = "**"` 使三段全空，`occ` 全真、`minC[x] = x`，$i = 0$ 时候选 $= 0$；示例 4 的 $A = C = \text{""}$、$B = \text{"adlogi"}$ 只在 1 处出现，$h[1] = 7$，$i = 1$ 得 $7 - 1 = 6$。

## 4. 算法细节

1. **Z 函数求出现位置**：构造 `pat + '#' + s`（`'#'` 不在字母表内，不会误匹配），`z[|pat|+1+i] >= |pat|` 即表示 `pat` 从 $i$ 开始出现。三次调用分别对 $A, B, C$。
2. **空模式的特殊处理**：空串在**每个位置** $0..n$ 都"出现"，故 `occ` 全为真；不能走 Z 函数的路径（空模式长度 0，`z` 判断会失效）。
3. **数组开到 $n+2$**：`minC[n+1]`、`h[n+1]` 作为哨兵（$+\infty$），避免 $e = n$ 时越界。
4. **`e + |B| <= n` 才有效**：$B$ 在 $e$ 处出现要求 `occB[e]` 为真，而 Z 函数只在 $e + |B| \le n$ 时置真，逻辑自洽；但读取 `minC[e + |B|]` 前仍要保证下标不超过 $n$。
5. **`INF` 用 $10^9$**：答案长度不超过 $n \le 10^5$，$10^9$ 足够区分"无解"。
6. **不要用 `s.find` 循环找全部出现**：对 `s = "aaa...a"`、`pat = "aa"` 这类输入，逐位置调用 `find` 可能退化到 $O(n^2)$；Z 函数是严格线性的。
7. **只扫 $i \le n - |A|$**：`occA` 的下标范围是 $0..n-|A|$，越界读会取到哨兵值导致答案错误。

## 5. 正确性证明

**引理 1（匹配的等价刻画）**：对任意串 $t$，$t$ 与 $p = A*B*C$ 匹配当且仅当存在分解 $t = A + X + B + Y + C$。

**证明**：$p$ 中只有两个 `'*'`，按 `'*'` 为界，匹配过程中字面串 $A$、$B$、$C$ 必须**按顺序**分别与 $t$ 的对应位置逐字符相等，两个 `'*'` 各自吞掉一段任意串 $X$、$Y$（可为空）。反过来，给定这样的分解，令第一个 `'*'` 匹配 $X$、第二个匹配 $Y$ 即得一个合法匹配。∎

**引理 2（`minC` 正确）**：递推得到的 `minC[x]` 等于 $\min\{k \ge x : \text{occC}[k]\}$（空集时为 $+\infty$）。

**证明**：对 $x$ 从 $n$ 到 $0$ 归纳。$x = n+1$ 时集合为空，值为 $+\infty$（哨兵）。设 `minC[x+1]` 正确：若 `occC[x]` 为真，则 $x$ 是可选起点中最小的（因为要求 $\ge x$，而 $x$ 本身可行），故 `minC[x] = x`；否则集合与 $\{k \ge x+1\}$ 相同，`minC[x] = minC[x+1]`。∎

**引理 3（`h` 正确）**：递推得到的 `h[e]` 等于

$$\min\Big\{\text{minC}[j+|B|] + |C| \;:\; j \ge e,\ \text{occB}[j]\Big\}$$

（无可行 $j$ 时为 $+\infty$）。

**证明**：对 $e$ 从 $n$ 到 $0$ 归纳。$e = n$ 时没有 $j \ge n$ 能让 $B$ 完整放下（除 $B$ 为空，此时 `minC[n]` 有效），按定义取值。设 $h[e+1]$ 正确。若 `occB[e]` 为真，则可行的 $j$ 集合是 $\{e\}$ 并上 $j \ge e+1$ 的集合，对应最小值为 $\min(\text{minC}[e+|B|] + |C|,\ h[e+1])$；否则只有后一部分。∎

**定理**：算法输出等于最短匹配子串的长度（无匹配时为 `-1`）。

**证明**：由引理 1，$s$ 的每个匹配子串都对应三元组 $(i, j, k)$ 且长度 $= k + |C| - i$；反之每个满足条件的三元组给出一个匹配子串。于是

$$\text{OPT} = \min_{i:\ \text{occA}[i]} \Big( -i + \min_{j \ge i+|A|,\ \text{occB}[j]} \big( \text{minC}[j+|B|] + |C| \big) \Big) = \min_{i:\ \text{occA}[i]} \big( h[i+|A|] - i \big)$$

由引理 2、3，`minC`、`h` 的计算与上式一致，故算法第 5 步得到的正是 OPT。若没有可行三元组，所有候选为 $+\infty$，返回 `-1` 正确。∎

## 6. 复杂度分析

- **时间**：$O(|s| + |p|)$。三次 Z 函数各 $O(|s| + |pat|)$；`minC`、`h` 各一次线性递推；扫描 $A$ 的出现位置 $O(n)$。总计线性。
- **空间**：$O(|s|)$。三个 `occ` 数组、`minC`、`h`，以及 Z 函数所需的 `z` 数组（长度 $|pat| + 1 + |s|$）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int shortestMatchingSubstring(string s, string p) {
        // p = A + '*' + B + '*' + C
        int first = (int)p.find('*');
        int second = (int)p.find('*', first + 1);
        string A = p.substr(0, first);
        string B = p.substr(first + 1, second - first - 1);
        string C = p.substr(second + 1);
        int n = (int)s.size();
        const int INF = 1000000000;

        auto occurrences = [&](const string& pat) {
            vector<char> occ(n + 1, 0);
            if (pat.empty()) { fill(occ.begin(), occ.end(), 1); return occ; }
            int m = (int)pat.size();
            if (m > n) return occ;
            string t = pat + "#" + s;
            int L = (int)t.size();
            vector<int> z(L, 0);
            for (int i = 1, l = 0, r = 0; i < L; i++) {
                if (i < r) z[i] = min(r - i, z[i - l]);
                while (i + z[i] < L && t[z[i]] == t[i + z[i]]) z[i]++;
                if (i + z[i] > r) { l = i; r = i + z[i]; }
            }
            for (int i = 0; i + m <= n; i++)
                if (z[m + 1 + i] >= m) occ[i] = 1;
            return occ;
        };

        vector<char> occA = occurrences(A), occB = occurrences(B), occC = occurrences(C);

        // minC[x]：后缀 C 的起点（>= x）中最小的那个
        vector<int> minC(n + 2, INF);
        for (int x = n; x >= 0; x--) minC[x] = occC[x] ? x : minC[x + 1];

        // h[e]：从 e 之后开始匹配 "B ... C" 时能得到的最小右端点
        vector<int> h(n + 2, INF);
        for (int e = n; e >= 0; e--) {
            h[e] = h[e + 1];
            if (occB[e] && e + (int)B.size() <= n) {
                int k = minC[e + (int)B.size()];
                if (k < INF) h[e] = min(h[e], k + (int)C.size());
            }
        }

        int ans = INF;
        for (int i = 0; i + (int)A.size() <= n; i++)
            if (occA[i] && h[i + (int)A.size()] < INF)
                ans = min(ans, h[i + (int)A.size()] - i);
        return ans >= INF ? -1 : ans;
    }
};
```

### Python

```python
class Solution:
    def shortestMatchingSubstring(self, s: str, p: str) -> int:
        first = p.index('*')
        second = p.index('*', first + 1)
        a, b, c = p[:first], p[first + 1:second], p[second + 1:]
        n = len(s)
        INF = 10 ** 9

        def occurrences(pat: str):
            occ = [False] * (n + 1)
            if not pat:
                return [True] * (n + 1)
            if len(pat) > n:
                return occ
            text = pat + '#' + s
            m = len(text)
            z = [0] * m
            l = r = 0
            for i in range(1, m):
                if i < r:
                    z[i] = min(r - i, z[i - l])
                while i + z[i] < m and text[z[i]] == text[i + z[i]]:
                    z[i] += 1
                if i + z[i] > r:
                    l, r = i, i + z[i]
            start = len(pat) + 1
            for i in range(n - len(pat) + 1):
                if z[start + i] >= len(pat):
                    occ[i] = True
            return occ

        occ_a, occ_b, occ_c = occurrences(a), occurrences(b), occurrences(c)

        # min_c[x]：后缀 C 的起点 >= x 时，最小的合法起点
        min_c = [INF] * (n + 2)
        for x in range(n, -1, -1):
            min_c[x] = x if occ_c[x] else min_c[x + 1]

        # h[e]：后缀部分（B + 中间空隙 + C）在 e 之后完成时的最小“右端点”
        h = [INF] * (n + 2)
        for e in range(n, -1, -1):
            h[e] = h[e + 1]
            if occ_b[e] and e + len(b) <= n:
                k = min_c[e + len(b)]
                if k < INF:
                    val = k + len(c)
                    if val < h[e]:
                        h[e] = val

        ans = INF
        for i in range(n - len(a) + 1):
            if occ_a[i] and h[i + len(a)] < INF:
                ans = min(ans, h[i + len(a)] - i)
        return -1 if ans >= INF else ans
```

## 8. 边界情况与易错点

1. **空段处理**：`A`、`B`、`C` 都可能为空（如 `p = "**"`、`p = "*adlogi*"`）。空模式的"出现位置"是**所有** $0..n$，必须特判，否则 Z 函数会给出全 false 的错误结果。
2. **两段之间的空隙不能为负**：$j \ge i + |A|$、$k \ge j + |B|$ 是硬约束，写代码时用"从 $i+|A|$ 开始找"的 `h` 天然满足；若改成"任意 $B$ 出现 + 任意 $C$ 出现"就会允许重叠，答案偏小。
3. **前缀/后缀模式长度超过 $n$**：此时该模式不可能出现，`occ` 全 false，最终返回 `-1`。
4. **哨兵数组长度 $n+2$**：`minC[e+|B|]` 的下标最大是 $n$；`h[n+1]` 作为尾部哨兵，少开一位会越界（C++）或 `IndexError`（Python）。
5. **空子串答案是 0**：`p = "**"`、`s = "a"` 时答案为 0，不要因为"没找到非空匹配"就返回 `-1`；注意 `ans` 初始化为 $+\infty$，真正的 0 会被正确记录。
6. **`'#'` 分隔符**：`s` 与 `p` 只含小写字母，因此 `'#'` 不会出现在任一侧，`pat + '#' + s` 的 Z 值不会被跨段匹配污染。
7. **别用 `find` 找全部出现位置**：`str.find`/`std::string::find` 逐位置调用在周期串上会退化，必须用 Z 函数（或 KMP）保证线性。
8. **返回类型是 `int`**：长度不超过 $n$，`INF` 只用于内部比较，最后必须把 $+\infty$ 翻成 `-1`。
