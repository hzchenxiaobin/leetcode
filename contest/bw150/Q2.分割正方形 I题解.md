# LeetCode 分割正方形 I 题解

## 1. 题目概述

- **标题 / 题号**：分割正方形 I（#3453，medium）
- **链接**：https://leetcode.cn/problems/separate-squares-i/
- **来源**：LeetCode 第 150 场双周赛 Q2
- **难度**：中等
- **标签**：数组、二分查找

**题意**：给定 $n$ 个**边与坐标轴平行**的正方形 `squares[i] = [xᵢ, yᵢ, lᵢ]`（左下角坐标 + 边长）。找一条水平线 $y$，使**线上方正方形的总面积等于线下方正方形的总面积**，要求返回**最小的**这样的 $y$。

**关键约定**：正方形**可以重叠**，重叠区域**按每个正方形分别计数**（即总面积就是 $\sum l_i^2$，与位置无关）。

**约束**：

- $1 \le n \le 5\times10^4$
- $0 \le x_i, y_i \le 10^9$，$1 \le l_i \le 10^9$
- **所有正方形的总面积不超过 $10^{12}$**（因此单个 $l_i \le 10^6$，$l_i^2$ 可用 `double` 精确表示）
- 答案误差 $10^{-5}$ 以内视为正确

## 2. 示例

**示例 1**

```text
输入：squares = [[0,0,1],[2,2,1]]
输出：1.00000
解释：两个 1×1 正方形面积各 1。y = 1 时线下的只有一个正方形（面积 1），
      线上的也只有一个（面积 1），最小可行 y 为 1。
```

**示例 2**

```text
输入：squares = [[0,0,2],[1,1,1]]
输出：1.16667
解释：总面积 4 + 1 = 5，目标 2.5。y ∈ [1,2] 时线下面积 2y + (y−1) = 3y − 1，
      令其等于 2.5 得 y = 7/6 ≈ 1.16667。
```

## 3. 解题思路

### 3.1 暴力思路

$y$ 是连续量，不可能直接枚举。若按 $10^{-6}$ 的步长逐个试，坐标上界 $10^9$ 意味着 $10^{15}$ 次计算，完全不可行。即便只枚举"关键高度"（所有 $y_i$、$y_i + l_i$，$2n$ 个断点）再逐个断点求面积，$O(n^2)$ 也偏慢——而且本题并不需要显式求出所有断点。

正确的方向是：**把"线下面积"写成 $y$ 的函数，观察它的形状**。

### 3.2 核心观察：线下面积是 $y$ 的分段线性单调函数

![单个正方形对线下面积的贡献是 l·clamp(y−y₀, 0, l)](images/bw150_q2_area_model.svg)

第 $i$ 个正方形在直线 $y$ 以下的面积是

$$\text{part}_i(y) = l_i \cdot \text{clamp}(y - y_i,\ 0,\ l_i) = \begin{cases} 0, & y \le y_i \\ l_i (y - y_i), & y_i < y < y_i + l_i \\ l_i^2, & y \ge y_i + l_i \end{cases}$$

由于重叠要**重复计数**，全部线下面积就是对每个正方形**独立求和**：

$$A(y) = \sum_{i=0}^{n-1} l_i \cdot \text{clamp}(y - y_i,\ 0,\ l_i)$$

这个函数有三个好性质：

1. **单调不减**：每一项都关于 $y$ 单调不减；
2. **连续**：每一项都是连续的分段线性函数（在 $y_i$、$y_i + l_i$ 处左右极限相等）；
3. **端点值确定**：$A(0) = 0$（若存在 $y_i = 0$ 仍需 $y > y_i$ 才增长，最小 $y$ 处为 0），$A(\max_i(y_i + l_i)) = \sum l_i^2$。

于是答案就是

$$y^* = \min\{\, y \ge 0 : A(y) \ge \tfrac{1}{2}\textstyle\sum l_i^2 \,\}$$

而由连续性，$A(y^*) = \frac{1}{2}\sum l_i^2$ **恰好成立**（不会出现"跳过"一半的情况），所以"最小可行 $y$"就是题目要的那个点。

### 3.3 算法流程

![二分最小可行 y：A(mid) ≥ half 收紧上界](images/bw150_q2_binary_search.svg)

```text
1. total = Σ lᵢ²，half = total / 2
2. lo = 0，hi = maxᵢ(yᵢ + lᵢ)
3. 重复 60 次：
       mid = (lo + hi) / 2
       A = Σᵢ lᵢ · clamp(mid − yᵢ, 0, lᵢ)
       若 A >= half:  hi = mid      // mid 可行，答案不超过它
       否则:          lo = mid      // mid 不可行，答案比它大
4. 返回 hi
```

**为什么"返回 hi"而不是"返回 lo"**：不变式是「$lo$ 不可行、$hi$ 可行」，所以收敛到的是**最小可行点**，正是题目要的"最小 $y$"。

### 3.4 示例演算

![示例 2：两段线段拼出 A(y)，与 2.5 的交点即 7/6](images/bw150_q2_example_walkthrough.svg)

对示例 2（`[[0,0,2],[1,1,1]]`）：

- 总面积 $= 2^2 + 1^2 = 5$，目标 $2.5$；
- $y \in [0,1]$：只有红色正方形贡献，$A = 2y$，到 $y=1$ 时为 2；
- $y \in [1,2]$：两个正方形都贡献，$A = 2y + (y - 1) = 3y - 1$；
- 解 $3y - 1 = 2.5$ 得 $y = 7/6 \approx 1.16667$，与题面输出一致。

示例 1（`[[0,0,1],[2,2,1]]`）则展示了"平台"情形：$y \in [1,2]$ 时 $A \equiv 1$ 恒等于目标，**最小**可行点取平台左端 $y = 1$，这正是必须用"最小可行点"而不是随便一个可行点的原因。

## 4. 算法细节

1. **二分上界取 $\max_i(y_i + l_i)$**：超过所有正方形顶部后 $A$ 恒为总面积，必有可行点；下界取 $0$ 即可（所有 $y_i \ge 0$）。
2. **迭代次数 60 次足够**：$\text{hi} - \text{lo}$ 初始不超过 $2\times10^9$，60 次折半后区间长度 $\le 2\times10^9 / 2^{60} \approx 1.7\times10^{-9}$，远小于要求的 $10^{-5}$。
3. **精度技巧：把"整块在线下"的部分单独精确累加**。完全落在直线下方的正方形贡献 $l_i^2$，总面积不超过 $10^{12} < 2^{53}$，用整数（`long long` / Python `int`）累加是**精确**的；只有被直线切开的正方形才产生浮点的 $l_i(y - y_i)$。两部分分开累加后，浮点部分的量级不超过 $\sum_{\text{切开}} l_i^2 \le \max l_i \cdot S$（$S$ 为该处的斜率），因此 $y$ 的误差约为 $\varepsilon \cdot \max l_i \sim 10^{-10}$，远优于 $10^{-5}$ 容差。若不分开累加，$10^{12}$ 量级下 `double` 的 ulp 约为 $2\times10^{-4}$，在极端数据上有风险。
4. **不排序、不建结构**：每次判定直接扫一遍数组，$O(n)$；60~100 次共 $3\times10^6 \sim 5\times10^6$ 次乘加。
5. **`clamp` 手写**：`mid >= y + l` 记满额 $l^2$（精确部分），`mid > y` 记部分 $l(mid - y)$，否则记 0。
6. **`l * l` 用 `long long`**：$l_i \le 10^6$ 时 $l_i^2 \le 10^{12}$，转 `double` 时精确；不要用 `int` 相乘（会溢出）。
7. **Python 侧用 60 次而非 100 次**：$5\times10^4 \times 100$ 次循环在 Python 下偏慢，60 次已满足精度需求。

## 5. 正确性证明

**引理 1（$A$ 单调不减且连续）**：$A(y) = \sum_i l_i\,\text{clamp}(y - y_i, 0, l_i)$ 在 $[0, +\infty)$ 上连续、单调不减，且 $A(y) \to \sum l_i^2$（$y \to +\infty$）。

**证明**：每一项 $\text{clamp}(y-y_i,0,l_i)$ 是连续分段线性函数，且斜率非负（依次为 $0, l_i, 0$），故每项连续、单调不减；有限个这样的函数之和仍连续、单调不减。当 $y \ge \max_i(y_i + l_i)$ 时每项都取到 $l_i$，总和为 $\sum l_i^2$。∎

**引理 2（二分不变式）**：算法每轮结束后保持「$A(lo) < \text{half}$ 且 $A(hi) \ge \text{half}$」。

**证明**：初值 $A(0) = 0 < \text{half}$（总额 $\ge 1 > 0$），$A(\max_i(y_i+l_i)) = \text{total} \ge \text{half}$。设不变式成立，取 `mid`：若 $A(\text{mid}) \ge \text{half}$ 则把 $hi$ 更新为 `mid`，否则把 $lo$ 更新为 `mid`，两种情况都保持不变式。∎

**定理**：算法输出 $y$ 满足 $\lvert y - y^\*\rvert \le 2\times10^9/2^{60} < 2\times10^{-9}$，其中 $y^\*$ 是最小可行点。

**证明**：设 $y^\* = \min\{y : A(y) \ge \text{half}\}$。由引理 2，任何时刻 $lo < y^\* \le hi$（$A(lo) < \text{half}$ 说明 $lo$ 不是可行点，故 $lo < y^\*$；$A(hi) \ge \text{half}$ 说明 $hi$ 可行，故 $y^\* \le hi$）。每轮区间长度减半，经过 60 轮后 $hi - lo \le 2\times10^9/2^{60}$，而 $y^\* \in (lo, hi]$，故 $hi$ 与 $y^\*$ 的偏差不超过该区间长度，远小于 $10^{-5}$。又由引理 1 的连续性，$A(y^\*) = \text{half}$，即该点确实使上下面积相等。∎

## 6. 复杂度分析

- **时间**：$O(60n)$。每轮一次线性扫描求 $A(\text{mid})$，共 60 轮。$n = 5\times10^4$ 时约 $3\times10^6$ 次浮点运算。
- **空间**：$O(1)$ 额外空间（除输入数组外）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    double separateSquares(vector<vector<int>>& squares) {
        double total = 0, hi = 0;
        for (auto& sq : squares) {
            total += (double)sq[2] * sq[2];
            hi = max(hi, (double)sq[1] + sq[2]);
        }
        double half = total / 2.0;
        double lo = 0.0;
        for (int it = 0; it < 100; it++) {
            double mid = (lo + hi) / 2.0;
            double full = 0, frac = 0;
            for (auto& sq : squares) {
                long long l = sq[2];
                if (mid >= (double)sq[1] + l) full += (double)(l * l);
                else if (mid > sq[1]) frac += (double)l * (mid - sq[1]);
            }
            if (full + frac >= half) hi = mid; else lo = mid;
        }
        return hi;
    }
};
```

### Python

```python
class Solution:
    def separateSquares(self, squares: list[list[int]]) -> float:
        half = sum(l * l for _, _, l in squares) / 2.0
        lo, hi = 0.0, float(max(y + l for _, y, l in squares))
        for _ in range(60):
            mid = (lo + hi) / 2
            full = 0          # 整个正方形都在线下：整数，可精确累加
            frac = 0.0        # 被直线切开的正方形：浮点部分
            for _, y, l in squares:
                if mid >= y + l:
                    full += l * l
                elif mid > y:
                    frac += l * (mid - y)
            if full + frac >= half:
                hi = mid
            else:
                lo = mid
        return hi
```

## 8. 边界情况与易错点

1. **"最小 $y$" 与 "某个 $y$" 不同**：函数可能在一整段区间上恒等于目标（示例 1 的 $[1,2]$），必须取**左端点**。用「$A(\text{mid}) \ge \text{half}$ 就收 $hi$」的写法天然满足。
2. **重叠要重复计数**：本题总面积是 $\sum l_i^2$，不能用并集面积；那是同场 Q3 的要求，两者结论不同。
3. **上界必须是 $\max(y_i + l_i)$**：用 `eventTime` 式的固定大常数也可以，但会损失精度；用实际最大值更稳。
4. **`h >= l` 与 `h <= 0` 的等号**：$h = l$ 时贡献满额 $l^2$，$h = 0$ 时贡献 0，取哪边都不影响连续函数的值，但 `h <= 0 continue` 与 `h >= l` 满额必须写成互补关系。
5. **整数溢出（C++）**：`sq[2] * sq[2]` 若用 `int` 乘会溢出（$l_i$ 可能达到 $10^6$，平方 $10^{12}$ 超过 `int`），务必转 `double` 或用 `long long`。
6. **迭代次数与精度**：50 次约 $1.8\times10^{-6}$ 偏差，可能不够稳；60 次或 100 次更保险，代价很小。
7. **$y_i$ 很大但面积小时**：二分区间的绝对值大，但因为是从 $0$ 到 $10^9$ 折半，60 次后仍能分辨 $10^{-9}$，不必担心"大数相减丢精度"。
8. **返回值类型是 `double`**：不要返回整数 $1$ 之类的截断值，输出格式按题目要求保留小数。
