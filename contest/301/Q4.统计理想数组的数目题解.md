# LeetCode 统计理想数组的数目 题解

## 1. 题目概述

- **标题 / 题号**：统计理想数组的数目（#2338，hard）
- **链接**：https://leetcode.cn/problems/count-the-number-of-ideal-arrays/
- **来源**：LeetCode 第 301 场周赛 Q4
- **难度**：困难
- **标签**：数学、组合数学、动态规划、数论

**题意**：给定 $n$ 与 $\text{maxValue}$，统计长度为 $n$ 的数组 $\text{arr}$ 的数目，要求每个 $\text{arr}[i] \in [1, \text{maxValue}]$，且每个 $\text{arr}[i]$ 都能被 $\text{arr}[i-1]$ 整除（相邻整除，**允许相等**）。答案对 $10^9+7$ 取模。

**约束**：

- $2 \le n \le 10^4$
- $1 \le \text{maxValue} \le 10^4$

> 💡 **关键信号**：整除关系允许相等，意味着同一个值可以**连续复读任意多次**——$n$ 高达 $10^4$，但"值真正发生跳变"的次数有对数级上界（不同值至多 $\lfloor\log_2\text{maxValue}\rfloor + 1 \le 14$ 个）。把"重复"交给隔板法、把"取值"交给一个对数层数的 DP，正是本题的胜负手。

## 3. 解题思路

### 3.1 暴力思路：按数组长度逐层递推的倍数 DP

令 $dp[i][v]$ 为长度 $i$、末元素为 $v$ 的理想数组数：

$$dp[i][v] = \sum_{u \mid v} dp[i-1][u], \qquad dp[1][v] = 1$$

转移按"倍数推送"实现：对每个 $u$，把 $dp[i-1][u]$ 加到 $dp[i][u], dp[i][2u], dp[i][3u], \dots$，单层代价为调和级数 $\sum_{u=1}^{M}\lfloor M/u \rfloor \approx M\ln M$。总时间 $O(n\cdot M\ln M)$，代入 $n = M = 10^4$ 约 $9\times10^8$ 次加乘，**超时**；不滚动时 $n\times M$ 的表还要约 800MB 内存。

> ⚠️ 症结：$n$ 这一维被逐层展开，但数组里绝大多数位置都在"复读"——真正需要决策的只有**不同值之间的跳变**，而跳变次数有对数级上界。应当把 $n$ 维折叠成一个组合数。

### 3.2 核心观察：压缩成「严格整除链」

![核心观察：相等值压缩成严格整除链](images/wc301_q4_block_compression.svg)

**观察一（值非降）**：正整数 $a \mid b$ 蕴含 $b \ge a$，故理想数组非降，相同的值连续成段。

**观察二（块压缩）**：把相邻相等的一段压成一个块，得到不同值序列 $d_1 < d_2 < \cdots < d_k$。块边界处相邻两数恰满足 $d_i \mid d_{i+1}$ 且 $d_i \ne d_{i+1}$，即**严格整除**。

**观察三（链长对数级）**：严格整除意味着商是不小于 2 的整数，$d_{i+1} \ge 2d_i$，累乘得 $d_k \ge 2^{k-1}d_1 \ge 2^{k-1}$，故

$$k \le \lfloor\log_2 M\rfloor + 1 \le 14 \qquad (M \le 10^4,\ 2^{13}=8192 \le 10^4 < 2^{14})$$

**观察四（计数自由拆分）**：一条链 $(d_1,\dots,d_k)$ 加上一组正块长 $(l_1,\dots,l_k)$（$\sum l_i = n$）唯一确定一个理想数组，反之亦然。两者**互相独立**：链只管"出现哪些值、什么顺序"，块长只管"各值复读几遍"。

> 💡 一句话：理想数组 = **严格整除链** $\otimes$ **正整数划分**。链的个数用 DP 数，划分的个数用隔板法数，按 $k$ 求和即得答案。$n \le 10^4$ 但 $k \le 14$——这就是把 $10^9$ 级运算压到 $10^6$ 的折叠点。

### 3.3 算法流程：$g$ 递推 + 隔板法合成

**第一步：数链。** 令 $g[k][v]$ 为长度 $k$、末元素为 $v$ 的严格整除链数：

$$g[1][v] = 1, \qquad g[k][m] = \sum_{u \mid m,\ u < m} g[k-1][u]$$

实现仍用倍数推送：对每个 $u$，把 $g[k-1][u]$ 加到 $g[k][2u], g[k][3u], \dots$——**从 $2u$ 开始**，跳过 $m = u$ 正是"严格"的体现，也正是层数从 $n$ 掉到 $\log_2 M$ 的原因。记 $S_k = \sum_{v=1}^{M} g[k][v]$ 为长度 $k$ 的链总数。

**第二步：数块长（隔板法）。** 给定链长 $k$，块长是 $n$ 的有序正整数分解：

![隔板法：块长是 n 的有序划分](images/wc301_q4_stars_bars.svg)

$n$ 个位置之间有 $n-1$ 个间隙，任选 $k-1$ 个放隔板，切出的 $k$ 段非空区间长度即 $(l_1,\dots,l_k)$，故方案数为 $\binom{n-1}{k-1}$。

**第三步：合成。**

$$\text{ans} = \sum_{k=1}^{\min(n,\,K)} \binom{n-1}{k-1}\cdot S_k \pmod{10^9+7}, \qquad K = \lfloor\log_2 M\rfloor + 1$$

（$k > K$ 时无链存在；$k > n$ 时 $\binom{n-1}{k-1} = 0$，块数不能超过位置数。）

### 3.4 示例演算

![示例 2 演算](images/wc301_q4_walkthrough.svg)

以示例 2（$n=5,\ M=3$）走查，$K = \lfloor\log_2 3\rfloor + 1 = 2$：

| $k$ | $g[k][\cdot]$（$v = 1,2,3$） | 链 | $S_k$ | $\binom{n-1}{k-1}$ | 贡献 |
|-----|------------------------------|-----|-------|--------------------|------|
| 1 | $1,\ 1,\ 1$ | $[1]$、$[2]$、$[3]$ | 3 | $\binom{4}{0} = 1$ | 3 |
| 2 | $0,\ 1,\ 1$ | $1\mid 2$、$1\mid 3$ | 2 | $\binom{4}{1} = 4$ | 8 |

合计 $3 + 8 = 11$，与示例一致。以链 $1\mid 2$ 为例：配上块长 $(1,4),(2,3),(3,2),(4,1)$ 恰好生成示例解释中"含一个不同值 2 的 4 个"数组。

对照示例 1（$n=2,\ M=5$）：$K = 3$，但 $k=3$ 的链 $1\mid 2\mid 4$ 因 $\binom{1}{2} = 0$ 不贡献——$n = 2$ 摆不下三个不同值，组合数自动截断，无需人工特判。

## 4. 算法细节

1. **链长上界 $K$**：`while ((1LL << K) <= M) K++` 得 $K = \lfloor\log_2 M\rfloor + 1$，$M \le 10^4 \Rightarrow K \le 14$。写成 $\lfloor\log_2 M\rfloor$ 会漏掉最长链（如 $M=4$ 的 $1\mid2\mid4$）。
2. **$k$ 的循环上界取 $\min(n, K)$**：$k > n$ 时块数超过位置数；若组合数函数不防御 $b > a$，这里漏截断会直接越界。
3. **组合数预处理只需到 $n-1$**：第二参数 $k-1 \le \min(n,K)-1 \le n-1$。阶乘 $O(n)$ 建表，逆元用费马小定理求 $\mathrm{invFact}[n-1]$ 后线性回推。
4. **$g$ 用滚动数组**，每层清零后按倍数推送，倍数**从 $2u$ 起**；`g[u] == 0` 时跳过是常数优化（深层大多数 $v$ 凑不出 $k$ 级链），不改变最坏复杂度。
5. **$g[0]$ 保持为 $0$**：初始化只给下标 $1..M$ 置 1。若对整个数组一刀切置 1，$S_k$ 每层多 1——示例 1 会算出 11 而非 10，自造用例一测即暴露。
6. **全程只加乘、无减法**，取模不产生负数；$\binom{n-1}{k-1}\cdot S_k$ 是两个小于 $10^9+7$ 的数相乘，C++ 需 `long long`。

## 5. 正确性证明

**引理 1（双射）**：理想数组与二元组（严格整除链 $d_1 \mid \cdots \mid d_k$，正块长 $(l_1,\dots,l_k)$ 且 $\sum l_i = n$）一一对应。

**证明**：正整数 $a \mid b$ 蕴含 $b \ge a$，故理想数组非降，相等值连续成段；压缩得链与块长，且块边界相邻两数为 $d_i \mid d_{i+1}$、$d_i \ne d_{i+1}$，即链是严格整除链。反之，给定链与块长按段展开：段内相邻相等（$a \mid a$），段边界满足 $d_i \mid d_{i+1}$，展开结果是理想数组。两映射互逆。∎

**引理 2（链长上界）**：$k \le \lfloor\log_2 M\rfloor + 1$。

**证明**：$d_i \mid d_{i+1}$ 且 $d_i \ne d_{i+1}$ 蕴含商 $d_{i+1}/d_i$ 为不小于 2 的整数，即 $d_{i+1} \ge 2d_i$。归纳得 $d_k \ge 2^{k-1}d_1 \ge 2^{k-1}$；又 $d_k \le M$，故 $2^{k-1} \le M$。∎

**引理 3（隔板法）**：$\sum l_i = n$ 的正整数解 $(l_1,\dots,l_k)$ 共 $\binom{n-1}{k-1}$ 组。

**证明**：$n$ 个位置间有 $n-1$ 个间隙，任取 $k-1$ 个插入隔板，把位置切成 $k$ 段非空区间，段长从左到右即 $(l_1,\dots,l_k)$；反之任一组解按 $l_i$ 放隔板。间隙的 $k-1$ 子集与解一一对应，共 $\binom{n-1}{k-1}$ 组。∎

**引理 4（$g$ 的递推）**：$g[k][m] = \sum_{u \mid m,\, u < m} g[k-1][u]$，且 $S_k = \sum_v g[k][v]$ 恰为长度 $k$ 的严格链总数。

**证明**：长度 $k$、末元素 $m$ 的链与二元组（长度 $k-1$、末元素 $u$ 的链，$u$ 为 $m$ 的真因子）一一对应——增删末元素互逆。按 $m$ 求和即得 $S_k$。∎

**定理**：$\text{ans} = \sum_{k=1}^{\min(n,K)} \binom{n-1}{k-1} S_k$。

**证明**：由引理 1，理想数组按（链长 $k$，链取值）划分为两两不交的类；每条长度 $k$ 的链恰配 $\binom{n-1}{k-1}$ 个数组（引理 3），长度 $k$ 的链共 $S_k$ 条（引理 4）。$k > K$ 时无链（引理 2），$k > n$ 时 $\binom{n-1}{k-1} = 0$（引理 3 中 $k-1 > n-1$ 无从选起）。对 $k$ 求和即得。∎

> 💡 证明链的关键是**引理 1 的解耦**：把"值怎么选"与"值怎么复读"拆成两个互相独立的子问题后，两个子问题各有现成计数工具（倍数 DP 与隔板法），正确性几乎是"自动"成立的。

## 6. 复杂度分析

- **时间复杂度**：$O\!\left(n + K\cdot M\ln M\right) = O\!\left(M\log^2 M + n\right)$。阶乘与逆阶乘预处理 $O(n)$；$g$ 递推共 $K-1 \le 13$ 个推层（$k = 2..K$），每层倍数推送代价 $\sum_{u=1}^{M}\left(\lfloor M/u\rfloor - 1\right) \approx M\ln M \approx 9\times10^4$，合计约 $1.2\times10^6$ 次加乘；每层求和 $O(M)$ 可忽略。
- **空间复杂度**：$O(M + n)$。$g$ 的两个滚动数组与阶乘、逆阶乘表。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int idealArrays(int n, int maxValue) {
        const long long MOD = 1e9 + 7;
        int M = maxValue;

        // 链长上界 K = floor(log2 M) + 1：2^(K-1) <= M
        int K = 1;
        while ((1LL << K) <= M) K++;

        // 组合数 C(n-1, k-1) 只需阶乘到 n-1
        vector<long long> fact(n), invFact(n);
        fact[0] = 1;
        for (int i = 1; i < n; i++) fact[i] = fact[i - 1] * i % MOD;
        auto powMod = [&](long long a, long long b) {
            long long r = 1; a %= MOD;
            while (b) { if (b & 1) r = r * a % MOD; a = a * a % MOD; b >>= 1; }
            return r;
        };
        invFact[n - 1] = powMod(fact[n - 1], MOD - 2);
        for (int i = n - 1; i >= 1; i--) invFact[i - 1] = invFact[i] * i % MOD;
        auto C = [&](int a, int b) -> long long {
            if (b < 0 || b > a) return 0;
            return fact[a] * invFact[b] % MOD * invFact[a - b] % MOD;
        };

        // g[v]：当前层长度 k、末元素 v 的严格链数（滚动）
        vector<long long> g(M + 1), ng(M + 1);
        for (int v = 1; v <= M; v++) g[v] = 1;      // k = 1

        long long ans = 0;
        int kmax = min(n, K);
        for (int k = 1; k <= kmax; k++) {
            if (k > 1) {
                fill(ng.begin(), ng.end(), 0);
                for (int u = 1; u <= M; u++) {
                    if (g[u] == 0) continue;
                    for (int m = 2 * u; m <= M; m += u)   // 从 2u 起：保证严格
                        ng[m] = (ng[m] + g[u]) % MOD;
                }
                swap(g, ng);
            }
            long long S = 0;
            for (int v = 1; v <= M; v++) S = (S + g[v]) % MOD;
            ans = (ans + C(n - 1, k - 1) * S) % MOD;
        }
        return (int)ans;
    }
};
```

### Python

```python
class Solution:
    def idealArrays(self, n: int, maxValue: int) -> int:
        MOD = 10**9 + 7
        M = maxValue

        # 链长上界 K = floor(log2 M) + 1：2^(K-1) <= M
        K = 1
        while (1 << K) <= M:
            K += 1

        # 组合数 C(n-1, k-1) 只需阶乘到 n-1
        fact = [1] * n
        for i in range(1, n):
            fact[i] = fact[i - 1] * i % MOD
        inv_fact = [1] * n
        inv_fact[n - 1] = pow(fact[n - 1], MOD - 2, MOD)
        for i in range(n - 1, 0, -1):
            inv_fact[i - 1] = inv_fact[i] * i % MOD

        def C(a: int, b: int) -> int:
            if b < 0 or b > a:
                return 0
            return fact[a] * inv_fact[b] % MOD * inv_fact[a - b] % MOD

        g = [0] * (M + 1)
        for v in range(1, M + 1):        # k = 1
            g[v] = 1

        ans = 0
        for k in range(1, min(n, K) + 1):
            if k > 1:
                ng = [0] * (M + 1)
                for u in range(1, M + 1):
                    if g[u]:
                        for m in range(2 * u, M + 1, u):   # 从 2u 起：保证严格
                            ng[m] = (ng[m] + g[u]) % MOD
                g = ng
            S = sum(g) % MOD
            ans = (ans + C(n - 1, k - 1) * S) % MOD
        return ans
```

## 8. 边界情况与易错点

1. **$g[0]$ 必须为 0**：初始化只给下标 $1..M$ 置 1；一刀切置 1 会让 $S_k$ 每层多 1，示例 1 算出 11 而非 10。
2. **倍数枚举从 $2u$ 开始**：包含 $m = u$ 会把"原地相等"也当成一次链跳变，链长上限退化成 $n$，层数爆炸、计数全错。
3. **$K$ 差一**：$K = \lfloor\log_2 M\rfloor + 1$。$M = 10^4$ 时 $2^{13} = 8192 \le 10^4 < 2^{14}$，$K = 14$；漏掉 $+1$ 会丢最长链（$M = 4,\ n = 3$ 时漏掉 $[1,2,4]$，得 12 而非 13）。
4. **$k$ 上界取 $\min(n, K)$**：防的是组合数越界与无效层；防御性的 `C`（$b > a$ 返回 0）可兜底，但显式截断更清晰。
5. **溢出**：`fact[a] * invFact[b] % MOD * invFact[a-b]` 与 `C(...) * S` 均小于 $10^{18}$，必须 `long long`；`ng[m] + g[u]` 随加随模。
6. **$M = 1$**：$K = 1$、$k_{\max} = 1$，答案 $\binom{n-1}{0}\cdot 1 = 1$，无需特判。
7. **别按试除找因子**：转移直接调和级数倍数推送；对每个 $v$ 试除分解是 $O(M\sqrt M)$，平白多一个根号。
8. **暴力 DP 的"伪可行"陷阱**：$9\times10^8$ 次加法在 C++ O2 下约数秒，属于"看起来能赌"的区间，赛时请直接转向压缩思路。
