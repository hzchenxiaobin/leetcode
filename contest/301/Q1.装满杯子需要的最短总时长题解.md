# LeetCode 装满杯子需要的最短总时长 题解

## 1. 题目概述

- **标题 / 题号**：装满杯子需要的最短总时长（#2335，easy）
- **链接**：https://leetcode.cn/problems/minimum-amount-of-time-to-fill-cups/
- **来源**：LeetCode 第 301 场周赛 Q1
- **难度**：简单
- **标签**：贪心、数组、排序、堆（优先队列）

**题意**：饮水机供应冷水、温水、热水三种。每一秒，你可以装满 **2 杯不同类型**的水，或者装满 **1 杯任意类型**的水。给定长度为 3 的数组 `amount`，`amount[i]` 表示第 `i` 种水需要装满的杯数，返回装满所有杯子所需的**最少秒数**。

**约束**：

- `amount.length == 3`
- `0 <= amount[i] <= 100`

## 2. 示例

**示例 1**

```text
输入：amount = [1,4,2]
输出：4
解释：第 1 秒装「冷水+温水」，第 2、3 秒各装「温水+热水」，第 4 秒单装一杯温水。
```

**示例 2**

```text
输入：amount = [5,4,4]
输出：7
解释：前 6 秒每秒装两种不同类型各一杯，第 7 秒单装最后一杯。
```

**示例 3**

```text
输入：amount = [5,0,0]
输出：5
解释：只有冷水有需求，每秒只能装一杯。
```

## 3. 解题思路

### 3.1 暴力思路

把每一秒的决策当作搜索分支，状态是三元组 $(x, y, z)$，BFS 搜到 $(0,0,0)$ 即停。状态数 $O(101^3) \approx 10^6$，可行但对签到题来说太重。另一个朴素做法是**贪心模拟**：每一秒都装「当前剩余最多的两种类型」各一杯（只剩一种非零时单装一杯），由于 $\sum amount \le 300$，模拟至多 300 步。这个做法是对的，但下面可以看到它可以直接浓缩成一个公式。

### 3.2 核心观察：两条下界夹出答案

![配对视角与两条下界](images/2335_pairing_concept.svg)

把「每秒装 2 杯不同类型」看成一次**配对**——同一秒里两杯必须类型不同，等价于：**每一秒、每一类型至多被消耗 1 杯**。由此立刻得到两条**下界**：

1. **总量下界**：每秒至多装 2 杯，$n$ 秒至多 $2n$ 杯，故 $ans \ge \left\lceil S/2 \right\rceil$，其中 $S = a+b+c$ 为总杯数；
2. **单类下界**：同一类型每秒至多装 1 杯，故 $ans \ge \max(a,b,c)$。

> 💡 **关键之处**：这两条下界可以**同时取到**。设排序后 $a \le b \le c$，则

$$ans = \max\left(c,\ \left\lceil \frac{S}{2} \right\rceil\right)$$

- 当 $a+b \le c$ 时右边的 $c$ 占主导：小两类全部「搭车」与 $c$ 配对也填不满 $c$，多出来的部分只能逐秒单装；
- 当 $a+b > c$ 时 $\left\lceil S/2 \right\rceil$ 占主导：三类互相「喂牌」，几乎每秒都能装满 2 杯。

### 3.3 算法流程

![算法流程：按 a+b 与 c 的大小分两种情况](images/2335_algorithm_flow.svg)

1. 排序得 $a \le b \le c$，记 $S = a+b+c$；
2. 若 $a+b \le c$（**最大值主导**）：让 $a$、$b$ 两类全部与 $c$ 配对，花 $a+b$ 秒；$c$ 还剩 $c-(a+b)$ 杯，逐秒单装。总时长恰为 $c$；
3. 若 $a+b > c$（**三足鼎立**）：每秒装「剩余最多的两类」各一杯，几乎每秒都消耗 2 杯，总时长 $\left\lceil S/2 \right\rceil$；
4. 两式合并，一次 `max` 返回即可。

### 3.4 示例演算

![示例 [1,4,2] 的 4 秒装杯过程](images/2335_example_walkthrough.svg)

以 `amount = [1,4,2]` 为例：排序得 $a=1, b=2, c=4$，$S=7$。因 $a+b=3 \le 4=c$，走「最大值主导」分支，答案 $= c = 4$。装杯方案：

| 秒 | 操作 | 剩余 (冷,温,热) |
|----|------|-----------------|
| 1 | 冷 + 温 | (0, 3, 2) |
| 2 | 温 + 热 | (0, 2, 1) |
| 3 | 温 + 热 | (0, 1, 0) |
| 4 | 温 单装 | (0, 0, 0) |

再验证 `amount = [5,4,4]`：排序得 $a=4, b=4, c=5$，$a+b=8>5$，走「三足鼎立」分支，$S=13$，答案 $= \lceil 13/2 \rceil = 7$ ✓。

## 4. 算法细节

1. **排序**：只有 3 个数，`sort` 即可，常数开销。
2. **上取整**：$\lceil S/2 \rceil$ 用整数运算 `(S + 1) / 2`（C++）或 `(S + 1) // 2`（Python），避免浮点误差。
3. **合并公式**：无需分支讨论，直接 `max(c, (a+b+c+1)/2)` 一次返回。
4. **贪心模拟写法**（保底方案）：若赛时不想推公式，用「每秒取剩余最多的两类各装一杯」直接模拟，$S \le 300$ 步内必然结束，同样正确（正确性由 §5 引理 2 保证）。

## 5. 正确性证明

设排序后 $a \le b \le c$，$S = a+b+c$。

**引理 1（下界）**：$ans \ge \max\left(c,\ \left\lceil S/2 \right\rceil\right)$。

**证明**：每种合法操作每秒至多装 2 杯，故 $n$ 秒至多装 $2n$ 杯，而总需求为 $S$ 杯，得 $2\cdot ans \ge S$，即 $ans \ge \lceil S/2 \rceil$。又操作 B 要求两杯类型不同、操作 A 只装一杯，故**同一秒内同一类型至多被装 1 杯**；数量最多的类型需要装 $c$ 杯，得 $ans \ge c$。两条下界同时成立。∎

**引理 2（配对引理）**：设当前三类剩余量为 $x \le y \le z$，总数 $n = x+y+z$ 为偶数且 $z \le n/2$（$n \ge 2$）。则存在装法使接下来每一秒都装 2 杯不同类型，恰好再用 $n/2$ 秒装完。

**证明**：对 $n$ 归纳。$n = 2$ 时 $z \le 1$ 说明至多一类有 1 杯以上，即至少两类非零，各装一杯，1 秒完成。设 $n \ge 4$：这一秒装「剩余最多的两类」各一杯，装后总数为 $n-2$（仍为偶数）。断言装后最大计数 $z' \le (n-2)/2$：

- 若 $z'$ 来自被装的两类之一，则 $z' \le z - 1 \le n/2 - 1 = (n-2)/2$；
- 若 $z'$ 来自未参与的第三类 $x$，反设 $x > (n-2)/2$，则 $x \ge n/2$，于是 $z \ge y \ge x \ge n/2$，三类之和 $\ge 3n/2 > n$，与总和恰为 $n$ 矛盾。

于是装后仍满足引理条件（总数 $n-2$ 偶、最大计数 $\le (n-2)/2$），由归纳假设再花 $(n-2)/2$ 秒装完，合计 $n/2$ 秒。∎

**定理**：$ans = \max\left(c,\ \left\lceil S/2 \right\rceil\right)$。

**证明**：由引理 1，只需证右端可达。分两种情形。

- **情形一 $a+b \le c$**：先花 $a+b$ 秒，每秒装「（$a$ 类或 $b$ 类中未装完的）一杯 + $c$ 类一杯」，将 $a$、$b$ 两类全部装完并同步消耗 $c$ 类 $a+b$ 杯；再花 $c-(a+b)$ 秒逐秒单装 $c$ 类剩余的杯。总时长 $(a+b) + (c-a-b) = c$。又 $S = a+b+c \le 2c \Rightarrow \lceil S/2 \rceil \le c$，故 $c = \max(c, \lceil S/2 \rceil)$，恰好达到下界。
- **情形二 $a+b > c$**：此时 $S > 2c$，即 $c < S/2$，故 $c \le \lfloor S/2 \rfloor$。若 $S$ 为偶数，初始即满足引理 2 条件（最大计数 $c \le S/2$），花 $S/2 = \lceil S/2 \rceil$ 秒装完。若 $S$ 为奇数，先花 1 秒单装任意一杯，剩 $S-1$ 杯（偶数），最大计数不超过 $c \le \lfloor S/2 \rfloor = (S-1)/2$，满足引理 2 条件，再花 $(S-1)/2$ 秒；合计 $1 + (S-1)/2 = \lceil S/2 \rceil$ 秒。又 $S > 2c \Rightarrow \lceil S/2 \rceil > c$，故 $\max(c, \lceil S/2 \rceil) = \lceil S/2 \rceil$，恰好达到下界。∎

## 6. 复杂度分析

- **时间复杂度**：$O(1)$。排序 3 个元素 + 一次 `max`，均为常数开销（若采用贪心模拟写法则为 $O(S)$，$S \le 300$）。
- **空间复杂度**：$O(1)$。仅用常数个变量。

## 7. 参考代码

### C++（公式 O(1)）

```cpp
class Solution {
public:
    int fillCups(vector<int>& amount) {
        sort(amount.begin(), amount.end());
        int a = amount[0], b = amount[1], c = amount[2];
        return max(c, (a + b + c + 1) / 2);
    }
};
```

### Python（公式 O(1)）

```python
class Solution:
    def fillCups(self, amount: List[int]) -> int:
        a, b, c = sorted(amount)
        return max(c, (a + b + c + 1) // 2)
```

### Python（贪心模拟，保底写法）

```python
class Solution:
    def fillCups(self, amount: List[int]) -> int:
        amount.sort()
        ans = 0
        while amount[2] > 0:
            if amount[1] > 0:
                amount[1] -= 1
            amount[2] -= 1
            amount.sort()
            ans += 1
        return ans
```

## 8. 边界情况与易错点

1. **全零输入** `amount = [0,0,0]`：答案 0，公式 $\max(0, \lceil 0/2 \rceil) = 0$，无需特判。
2. **只剩一类非零**（如 `[5,0,0]`）：只能逐秒单装，答案 $= c = 5$；此时 $\lceil S/2 \rceil = 3 < 5$，验证了「单类下界」不可省略。
3. **奇数总杯数别用 `S/2`**：`[1,4,2]` 中 $S=7$，整除得 3 是错的，必须写 `(S+1)/2` 上取整得 4。
4. **两杯必须不同类型**：不能把操作 B 理解成「一秒装两杯同类水」，否则 `[5,0,0]` 会错误地答 3。
5. **答案与顺序无关**：只依赖三个数构成的多重集合，先排序再套公式即可，无需关心哪杯是冷水。
6. **无溢出风险**：$amount[i] \le 100$，$S \le 300$，`int` 绰绰有余。
