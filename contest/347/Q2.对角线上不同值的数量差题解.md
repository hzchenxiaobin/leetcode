# LeetCode 对角线上不同值的数量差 题解

## 1. 题目概述

- **标题 / 题号**：对角线上不同值的数量差（#2711，medium）
- **链接**：https://leetcode.cn/problems/difference-of-number-of-distinct-values-on-diagonals/
- **来源**：LeetCode 第 347 场周赛 Q2
- **难度**：中等
- **标签**：数组、哈希表、矩阵

**题意**：给定 $m \times n$ 的矩阵 `grid`，对每个格子 $(r, c)$ 计算：

- **topLeft[r][c]**：**左上对角线**上**不同值**的个数——即 $(r-1,c-1), (r-2,c-2), \dots$ 这些格子的值去重后的个数；
- **bottomRight[r][c]**：**右下对角线**上**不同值**的个数——即 $(r+1,c+1), (r+2,c+2), \dots$ 的值去重后的个数；
- `answer[r][c] = |topLeft[r][c] - bottomRight[r][c]|`。

返回整个 `answer` 矩阵。

**约束**：

- `m == grid.length`，`n == grid[i].length`
- `1 <= m, n <= 50`
- `1 <= grid[i][j] <= 50`

> 💡 读完约束先记两件事：① 矩阵至多 $50 \times 50 = 2500$ 格，任何 $O(m \cdot n \cdot \min(m, n))$ 的做法都稳过；② **值域只有 $1 \sim 50$**，集合可以用定长计数数组实现，为优化留了后门。

## 2. 示例

**示例 1**

```text
输入：grid = [[1,2,3],[3,1,5],[3,2,1]]
输出：[[1,1,0],[1,0,1],[0,1,1]]
解释：以 (0,0) 为例：右下对角线 [(1,1)=1, (2,2)=1] → 不同值 {1} → 1 个；
左上对角线为空 → 0 个，故 answer[0][0] = |0 - 1| = 1。
```

**示例 2**

```text
输入：grid = [[1]]
输出：[[0]]
解释：唯一格子的左上、右下对角线都为空，answer = 0。
```

**示例 3（自拟，覆盖"对角线上有重复值"）**

```text
输入：grid = [[3,8,4],[6,5,2],[9,7,3]]
输出：[[2,1,0],[1,0,1],[0,1,2]]
解释：主对角线 d = r - c = 0 上的值依次为 3,5,3 —— 值 3 出现两次。
- (0,0)：左上 {} → 0，右下 {5,3} → 2，answer = |0-2| = 2。
- (1,1)：左上 {3} → 1，右下 {3} → 1（同一个 3 在两侧各计一次），answer = 0。
- (2,2)：左上 {3,5} → 2，右下 {} → 0，answer = 2。
```

## 3. 解题思路

### 3.1 暴力思路：逐格重建集合

对每个格子 $(r, c)$，分别向左上、向右下走整条对角线，各用一个哈希集合去重，答案取两集合大小之差的绝对值。$m \times n$ 个格子、每格每侧最多走 $\min(m, n) \le 50$ 步，总计约 $2500 \times 50 \times 2 = 2.5 \times 10^5$ 次操作，**本题能过**。

问题在于**重复劳动**：同一条对角线上相邻格子的左上对角线只差一个元素，逐格重建集合把同样的内容算了 $O(\min(m, n))$ 遍。

### 3.2 核心观察：对角线平铺 + 滚动集合

![对角线概念：topLeft 与 bottomRight](images/wc347_q2_diagonal_concept.svg)

**关键性质**：同一条对角线上的格子满足 $r - c$ 恒定；沿对角线从左上到右下，$r$ 严格递增。于是

- **左上对角线 = 对角线上当前格之前的前缀**
- **右下对角线 = 当前格之后的后缀**

题目本质是：把每条对角线平铺成一维数组后，对每个位置求「**前缀不同值个数**」与「**后缀不同值个数**」之差的绝对值。

而「前缀不同值个数」用**滚动集合**沿对角线扫一遍就能全部求出：

- **正向扫描**（左上 → 右下）：维护集合 `seen`。到达格子 $(r, c)$ 时，`seen` 恰好装着前面所有格子的值，因此**加入前**记录集合大小即得 topLeft；随后把 `grid[r][c]` 加入 `seen`，供下一个格子使用。
- **逆向扫描**（右下 → 左上）：对称地，**加入前**记录集合大小即得 bottomRight。

相邻两个格子之间，集合只增减一个元素，增量更新均摊 $O(1)$——这就是对暴力「逐格重建」的彻底复用。

### 3.3 算法流程

![两遍扫描流程：正向记 topLeft，逆向记 bottomRight](images/wc347_q2_two_pass_flow.svg)

```
1. 枚举对角线编号 d = r - c，范围 -(n-1) .. m-1
2. 收集该对角线的所有格子，按 r 升序排好
3. 正向扫：ans[r][c] = 集合大小（加入前）→ topLeft；再插入 grid[r][c]
4. 清空 seen
5. 逆向扫：ans[r][c] = |ans[r][c] - 集合大小|（加入前）→ 回填绝对值；再插入
6. 所有对角线处理完，返回 ans
```

上图中平铺的对角线值为 3,5,3,7,5：三行分别给出每个位置的 topLeft、bottomRight 与最终 answer，重复值（两个 3、两个 5）在每一侧都只按不同值计一次。

### 3.4 示例演算

![示例 1 演算：主对角线 d = 0 的两遍扫描](images/wc347_q2_example_walkthrough.svg)

以**示例 1** 的主对角线 $d = 0$（格子 $(0,0), (1,1), (2,2)$，值均为 1）为例：

| 步骤 | 格子 | 加入前 seen | 记录 | 加入后 seen |
|------|------|------------|------|------------|
| 正向 1 | (0,0) | { } | topLeft = 0 | {1} |
| 正向 2 | (1,1) | {1} | topLeft = 1 | {1} |
| 正向 3 | (2,2) | {1} | topLeft = 1 | {1} |
| 逆向 1 | (2,2) | { } | bottomRight = 0 | {1} |
| 逆向 2 | (1,1) | {1} | bottomRight = 1 | {1} |
| 逆向 3 | (0,0) | {1} | bottomRight = 1 | {1} |

汇总：`answer[0][0] = |0-1| = 1`，`answer[1][1] = |1-1| = 0`，`answer[2][2] = |1-0| = 1`，与示例输出对角线一致 ✓。

## 4. 算法细节

1. **对角线枚举**：$d = r - c \in [-(n-1),\ m-1]$。左端点跟 $n$ 走、右端点跟 $m$ 走，非方阵时两者不同，不要顺手写错。
2. **格子收集**：$d \ge 0$ 时对角线从 $(d, 0)$ 出发；$d < 0$ 时从 $(0, -d)$ 出发。统一写成「$r$ 从 $\max(0, d)$ 起，且 $r - d < n$」，对任意形状的矩阵都正确。
3. **记录时机**：先记录集合大小、再插入当前值——顺序反了会把当前格自己算进去。
4. **复用答案矩阵**：正向扫把 topLeft 暂存进 `ans[r][c]`，逆向扫直接回填 $|topLeft - bottomRight|$，无需额外临时矩阵。
5. **集合实现**：值域 $1 \sim 50$，可用 `bool seen[51]` + 计数器 `cnt` 替代哈希集，插入/查询严格 $O(1)$ 且常数极小（C++ 版采用）。
6. **两遍之间必须清空** `seen`（数组版连同 `cnt` 一起归零）。

## 5. 正确性证明

**引理 1（对角线的代数刻画）**：格子 $(r_1, c_1)$、$(r_2, c_2)$ 同属一条题意对角线，当且仅当 $r_1 - c_1 = r_2 - c_2$；且在同一条对角线上按 $r$ 升序排列，恰好是沿「左上 → 右下」方向的顺序。

**证明**：题意对角线从顶行或最左列出发、每步移动 $(+1, +1)$，全程 $r - c$ 不变，必要性成立。反之若 $r_1 - c_1 = r_2 - c_2$ 且 $r_1 < r_2$，则 $(r_2, c_2) = (r_1 + k,\ c_1 + k)$，$k = r_2 - r_1$，中途格子都在矩阵内（端点都在），两格可经 $k$ 步 $(+1, +1)$ 互达，故同线。又同线上每一步 $r$ 增 1 当且仅当 $c$ 增 1，故 $r$ 的升序即右下方向 ∎

**引理 2（前缀 / 后缀刻画）**：固定一条对角线，按 $r$ 升序记其格子为 $x_1, \dots, x_k$。对任意 $t$：$x_t$ 的**左上对角线**恰为 $\{x_1, \dots, x_{t-1}\}$，**右下对角线**恰为 $\{x_{t+1}, \dots, x_k\}$。

**证明**：$x_s$（$s < t$）与 $x_t$ 同线且 $r_s < r_t$，由定义属于 $x_t$ 的左上对角线；反之，左上对角线中任一格子与 $x_t$ 同线且行号更小，由引理 1 它必是某个 $x_s$（$s < t$）。同理右下 ∎

**定理（正确性）**：两遍扫描结束后，对所有格子有 `ans[r][c] = |topLeft[r][c] - bottomRight[r][c]|`。

**证明**：对每条对角线 $x_1, \dots, x_k$：正向扫描到达 $x_t$ 时，对 $t$ 归纳可知 `seen` 恰为 $\{grid[x_1], \dots, grid[x_{t-1}]\}$——$t = 1$ 时为空；每步先记录后插入保持该不变量。故记录值等于前 $t-1$ 格**不同值**的个数，由引理 2 即 topLeft。逆向扫描同理得 bottomRight，并将 `ans` 覆写为 $|topLeft - bottomRight|$。所有对角线两两不交且覆盖全矩阵，故结论对所有格子成立 ∎

## 6. 复杂度分析

- **时间复杂度**：$O(m \cdot n)$。每个格子恰好被访问 2 次（正向 + 逆向）；哈希集合均摊 $O(1)$，计数数组版严格 $O(1)$（值域 $1 \sim 50$）。相比暴力 $O(m \cdot n \cdot \min(m, n))$，省掉的正是「逐格重建集合」的重复劳动。
- **空间复杂度**：$O(m \cdot n)$。其中答案矩阵 $O(m \cdot n)$（必选），对角线格子列表 $O(\min(m, n))$，集合 $O(\min(m, n))$（计数数组为 $O(50)$）。除答案外辅助空间仅 $O(\min(m, n))$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<vector<int>> differenceOfDistinctValues(vector<vector<int>>& grid) {
        int m = grid.size(), n = grid[0].size();
        vector<vector<int>> ans(m, vector<int>(n));

        // 同一条对角线 r - c 恒定，d 取遍 -(n-1) .. m-1
        for (int d = -(n - 1); d <= m - 1; d++) {
            vector<pair<int,int>> cells;              // 对角线格子，按 r 升序
            for (int r = max(0, d); r < m && r - d < n; r++)
                cells.emplace_back(r, r - d);

            vector<bool> seen(51, false);             // 值域 1~50，计数数组代替哈希集
            int cnt = 0;

            for (auto& [r, c] : cells) {             // 正向：topLeft 暂存进 ans
                ans[r][c] = cnt;                     // 加入前记录
                if (!seen[grid[r][c]]) { seen[grid[r][c]] = true; cnt++; }
            }

            fill(seen.begin(), seen.end(), false);   // 两遍之间必须清空
            cnt = 0;
            for (int i = (int)cells.size() - 1; i >= 0; i--) {
                auto [r, c] = cells[i];
                ans[r][c] = abs(ans[r][c] - cnt);    // |topLeft - bottomRight|
                if (!seen[grid[r][c]]) { seen[grid[r][c]] = true; cnt++; }
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def differenceOfDistinctValues(self, grid: List[List[int]]) -> List[List[int]]:
        m, n = len(grid), len(grid[0])
        ans = [[0] * n for _ in range(m)]

        for d in range(-(n - 1), m):                 # d = r - c
            cells = [(r, r - d) for r in range(max(0, d), m) if r - d < n]

            seen = set()                             # 正向：前缀不同值
            for r, c in cells:
                ans[r][c] = len(seen)                # 加入前记录 => topLeft
                seen.add(grid[r][c])

            seen = set()                             # 逆向：后缀不同值
            for r, c in reversed(cells):
                ans[r][c] = abs(ans[r][c] - len(seen))
                seen.add(grid[r][c])

        return ans
```

## 8. 边界情况与易错点

1. **记录时机反了**：先插入再记录大小会把当前格自身计入，topLeft / bottomRight 双双偏大。牢记「**先记后插**」。
2. **忘了清空 seen**：两遍共用一个集合时，逆向扫描会把前缀的值混进来；数组版要连 `cnt` 一起归零。
3. **方向搞错**：本题对角线沿 $r - c$（左上 → 右下）方向；$r + c$ 是副对角线方向，写错全盘皆错。
4. **d 的枚举范围**：$-(n-1) \le d \le m-1$。左端点是**负的 $n-1$**（第一列出发的短对角线），别误写成 $-(m-1)$。
5. **边界行列的空侧**：首行/首列格子的左上为空、末行/末列的右下为空，答案天然为 0，无需特判；$1 \times 1$ 矩阵直接返回 `[[0]]`。
6. **重复值只计一次**：示例 3 中 (1,1) 两侧的值都是 3，各计 1——集合语义自动保证；若手写计数逻辑，别把「元素个数」当成「不同值个数」。
7. **非方阵**：各对角线长度不等（最短 1、最长 $\min(m, n)$），用「起点 + 越界判断」统一收集，不要按固定长度处理。
8. **周赛实操**：$m, n \le 50$ 时暴力 5 分钟写完零风险，先保 AC；时间充裕再改两遍扫描。中等题里「先暴力兜底再优化」是常见节奏。
