# LeetCode 矩阵中最大共享路径和 题解

## 1. 题目概述

- **标题 / 题号**：矩阵中最大共享路径和（#3938，medium）
- **链接**：https://leetcode.cn/problems/maximum-path-intersection-sum-in-a-grid/
- **来源**：LeetCode 第 183 场双周赛 Q3
- **难度**：中等
- **标签**：数组、动态规划、矩阵、前缀和

**题意**：给定 $m \times n$ 整数矩阵 `grid`，两位玩家各走一条单调路径：

- 玩家 1：从 $(0,0)$ 到 $(m-1,n-1)$，只能**向右或向下**；
- 玩家 2：从 $(m-1,0)$ 到 $(0,n-1)$，只能**向右或向上**。

若某格子同时属于两条路径，称其为**共享格**。求所有共享格的数值之和的**最大**可能值（两条路径都必须从起点走到终点，路径本身不能跳过格子）。

**约束**：

- $2 \le m, n \le 1000$
- $4 \le m \cdot n \le 5 \times 10^5$
- $-100 \le grid[i][j] \le 100$

## 2. 示例

**示例 1**

```text
输入：grid = [[1,2,0,-3],[1,-2,1,0],[-4,2,-1,3],[3,-3,3,-2],[-1,-5,0,1]]
输出：4
解释：玩家 1 走 (0,0)→(1,0)→(2,0)→(2,1)→(2,2)→(2,3)→(3,3)→(4,3)；
     玩家 2 走 (4,0)→(4,1)→(3,1)→(2,1)→(2,2)→(2,3)→(1,3)→(0,3)。
     共享格是第 2 行的 (2,1)、(2,2)、(2,3)，和为 2 + (-1) + 3 = 4。
```

**示例 2**

```text
输入：grid = [[4,-2,-3],[-1,-3,-1],[-4,2,-1]]
输出：3
解释：最优玩家 1 走 (0,0)→(1,0)→(1,1)→(1,2)→(2,2)，
     玩家 2 走 (2,0)→(1,0)→(0,0)→(0,1)→(0,2)，共享格 (0,0)、(1,0)，和为 4 + (-1) = 3。
```

## 3. 解题思路

### 3.1 暴力思路

枚举两条路径的所有组合：玩家 1 的路径数 $\binom{m+n-2}{m-1}$，玩家 2 同样多，两者相乘是天文数字（$m = n = 20$ 时已超过 $10^{20}$）。即便用 DP 同时维护两条路径（四维状态 $O(m^2 n^2)$），在 $m \cdot n = 5\times 10^5$ 时也必然超时。

关键是要发现：**共享格不能是任意形状**，它被两条路径的单调性死死限制住。

### 3.2 核心观察：共享格必是同一行/列上的连续段

![两条单调路径的公共格：必是同一行或同一列上的连续段](images/bw183_q3_shared_segment.svg)

- **共享格是连续的**：两条路径的公共部分必然是各自路径上的一段（路径是一条不自交的格点序列），所以共享格集合是一条连续段。
- **这段只能是水平的或竖直的**：
  - 玩家 2 的路径只能**向上或向右**，玩家 1 只能**向下或向右**。在共享段上，两人的移动方向必须一致：要么都向右（水平段），要么都向上/向下——但竖直方向两人相反，**不可能同向**。因此共享段若竖直，就只能是一个格子（长度为 1）。
  - 换句话说：长度 $\ge 2$ 的共享段一定是**某一行的连续区间**；竖直方向最多共享 1 格。
- **长度为 1 的共享格必须「内部」**：如果唯一的共享格落在第一行或最后一行（或第一列、最后一列），由于两条路径都必经过这些边界上的某些格，可以证明必然产生更多共享格或直接矛盾——题面提示给出结论：**单个共享格必须满足 $0 < i < m-1$ 且 $0 < j < n-1$**。

于是答案变成三个来源的最大值：

1. 每一行中「长度 $\ge 2$ 的最大子段和」；
2. 每一列中「长度 $\ge 2$ 的最大子段和」；
3. 内部格子 $(1 \le i \le m-2,\ 1 \le j \le n-2)$ 的最大单格值。

### 3.3 算法流程

![降维：每行/每列做一次「长度至少 2」的最大子段和](images/bw183_q3_kadane.svg)

对每一行（列同理）做一次**带长度约束的 Kadane**：

```text
any = grid[i][0]              // 以 j 结尾、长度 ≥ 1 的最大和
ge2 = -INF                    // 以 j 结尾、长度 ≥ 2 的最大和
for j = 1 .. n-1:
    x = grid[i][j]
    nge2 = max(any, ge2) + x  // 要么把长度 1 扩成长度 2，要么继续延长
    any  = max(x, any + x)    // 要么另起一段
    ge2  = nge2
    ans  = max(ans, ge2)
```

- 行的遍历与列的遍历各做一遍；
- 最后扫描内部格子取单格最大值；
- 三者取最大即为答案。

### 3.4 示例演算

示例 1 的各候选取值：

| 来源 | 子段 | 和 |
|------|------|-----|
| 第 0 行 | `[1,2]` | 3 |
| **第 2 行** | **`[2,-1,3]`** | **4** |
| 第 3 行 | `[3,-3,3]` | 3 |
| 第 0 列 | `[1,1]` | 2 |
| 第 2 列 | `[3,0]` | 3 |
| 第 3 列 | `[0,3]` | 3 |
| 内部单格 | 最大为 `grid[3][2] = 3` | 3 |

最大值 4 来自第 2 行的 `[2,-1,3]`，恰好对应题面解释中的共享格 $(2,1),(2,2),(2,3)$，和 $2 + (-1) + 3 = 4$。

示例 2 中第 0 列 `[4,-1,-4]` 的子段 `[4,-1]` 和为 3，对应题面解释的共享格 $(0,0),(1,0)$，故输出 3。

## 4. 算法细节

1. **两个 Kadane 变量**：`any` 与 `ge2` 分别表示「以当前位置结尾、长度 $\ge 1$ / $\ge 2$」的最大和，转移必须先算 `nge2` 再用旧的 `any` 更新，顺序不能反。
2. **负无穷的选取**：`ge2` 初始为 $-\infty$（C++ 用 `LLONG_MIN/4`，Python 用 `float("-inf")`），保证长度为 1 的位置不会被误当成合法段。
3. **列的遍历**：`grid[i][j]` 按行存储，遍历列时访问跨度大、缓存不友好；$m \cdot n \le 5\times10^5$ 尚可接受，若想更快可以先把矩阵转置再按行处理。
4. **单格候选**：仅当 $m \ge 3$ 且 $n \ge 3$ 时存在内部格；否则该类候选为空（不影响答案，因为长度 $\ge 2$ 的候选一定存在——$m, n \ge 2$）。
5. **答案可能为负**：所有值都是负数时，答案是最不「亏」的那一段（例如两格中较大的那个加另一格），不是 0——不要用「与 0 取 max」。
6. **累加范围**：$m \cdot n \le 5\times10^5$、$|grid| \le 100$，单段和最多 $5\times10^7$，`int` 勉强够，但用 `long long` 更稳。

## 5. 正确性证明

记两条路径的共享格集合为 $S$。

**引理 1（同段补齐）**：若 $a, c \in S$ 在同一行 $r$ 且 $col(a) < col(c)$，则 $[r,\ col(a)]$ 到 $[r,\ col(c)]$ 之间的每个格都属于 $S$。同列亦然。

**证明**：玩家 1 的行号非降、玩家 2 的行号非增；两者都经过 $a$ 与 $c$ 且行号相同，故从 $a$ 到 $c$ 期间两人都不可能离开第 $r$ 行（离开意味着行号变化，之后无法回到 $r$）。在两格之间只能向右移动，于是两人都经过这整段，段内每格都被两人经过，属于 $S$。同列情形：两人在列 $j$ 上分别向下、向上经过 $a, c$，列号非降意味着离开列 $j$ 后无法返回，故两人都完整经过 $a$ 到 $c$ 的列段。∎

**引理 2（共享集必在同一行或同一列）**：$S$ 中所有格要么同处一行，要么同处一列。

**证明**：考察 $S$ 中任意两个不同的格：
- 若同行，则因两人的列号都非降，两人访问这两格的先后顺序必然一致；
- 若异行，则玩家 1 的行号非降、玩家 2 的行号非增，两人访问顺序必然相反。

若 $S$ 中既有同行的 $a, c$（设 $col(a) < col(c)$，所在行为 $r$），又有异行的 $d$，则 $d$ 只能满足 $row(d) < r$ 或 $row(d) > r$：

- $row(d) < r$：玩家 1 先访问 $d$ 后访问 $a$，列号非降给出 $col(a) \ge col(d)$；玩家 2 先访问 $a, c$ 后访问 $d$（顺序相反），列号非降给出 $col(d) \ge col(c) > col(a)$，矛盾。
- $row(d) > r$：玩家 1 先访问 $c$ 后访问 $d$，得 $col(d) \ge col(c)$；玩家 2 先访问 $d$ 后访问 $a$，得 $col(a) \ge col(d) \ge col(c)$，与 $col(a) < col(c)$ 矛盾。

故 $S$ 不可能「既有同行对又有异行格」：要么存在同行对（于是全部同处一行），要么两两异行——此时任意两格的访问顺序都相反，两人在 $S$ 上的顺序整体互为逆序，列号一侧非降、另一侧非增，只能全列相同，即全部同处一列。∎

**引理 3（单个共享格必须在内部）**：若 $|S| = 1$，则该格满足 $0 < i < m-1$ 且 $0 < j < n-1$。

**证明**：以第一行为例。玩家 2 一旦到达第 0 行就只能一路向右直到 $(0,n-1)$，故它恰在某列 $c_2$ 处首次进入第 0 行；玩家 1 在第 0 行从 $(0,0)$ 一路向右直到某列 $c_1$ 处向下离开。两人在第 0 行上的共享格恰为区间 $[\min(c_1,c_2), \max(c_1,c_2)]$ 之交，即列区间 $[\min, \max]$（若非空则至少 1 格）。若 $c_1 \ne c_2$，行 0 上至少共享两格；若 $c_1 = c_2 = c$，则玩家 1 必经过 $(1,c)$（向右离开行 0 的唯一方式是向下）、玩家 2 必经过 $(1,c)$（向上进入行 0 的唯一方式），于是 $|S| \ge 2$，矛盾。四种边界（首行、末行、首列、末列）论证完全对称，故唯一共享格必须在内部。∎

**引理 4（候选可达）**：任一行的长度 $\ge 2$ 区间、任一列的长度 $\ge 2$ 区间、任一内部单格，都存在一对合法路径使共享格之和**不小于**该候选值。

**证明（构造）**：
- 水平段（行 $r$、列区间 $[c_1,c_2]$，$c_2 > c_1$）：玩家 1 走「$(0,0)$ 右行至 $(0,c_1)$ → 下行至 $(r,c_1)$ → 右行至 $(r,c_2)$ → 下行至 $(m-1,c_2)$ → 右行至 $(m-1,n-1)$」；玩家 2 走「$(m-1,0)$ 右行至 $(m-1,c_1)$ → 上行至 $(r,c_1)$ → 右行至 $(r,c_2)$ → 上行至 $(0,c_2)$ → 右行至 $(0,n-1)$」。逐段对照可知两人只在第 $r$ 行的 $[c_1,c_2]$ 上重合（其余部分分别位于不同行/列），故共享和恰为该段之和。
- 竖直段：把上述构造旋转 90°（玩家 1、玩家 2 分别沿行方向让路），同理。
- 内部单格 $(i,j)$（$0<i<m-1$，$0<j<n-1$）：玩家 1 走「沿第 0 列下行至 $(i,0)$ → 沿第 $i$ 行右行至 $(i,n-1)$ → 沿第 $n-1$ 列下行至 $(m-1,n-1)$」；玩家 2 走「沿第 $m-1$ 行右行至 $(m-1,j)$ → 沿第 $j$ 列上行至 $(0,j)$ → 沿第 0 行右行至 $(0,n-1)$」。两条路径的公共格只有 $(i,j)$（$i$ 是内部行、$j$ 是内部列，两者恰好在 $(i,j)$ 处十字相交）。

∎

**定理**：算法返回值等于共享格之和的最大可能值。

**证明**：设最优路径对的共享和为 $V$，其共享集为 $S$。若 $|S| \ge 2$，由引理 1、2，$S$ 是某行或某列上的连续段（长度 $\ge 2$），故 $V$ 不超过该行/列「长度 $\ge 2$ 的最大子段和」，即 $V \le$ 算法结果。若 $|S| = 1$，由引理 3 该格在内部，$V$ 不超过内部单格最大值，同样 $V \le$ 算法结果。另一方面，由引理 4，算法枚举的每个候选值都能被某对路径达到（或超过），故算法结果 $\le V$。两者结合得算法结果 $= V$。∎

## 6. 复杂度分析

- **时间**：$O(mn)$。每一行一次线性 Kadane，每一列一次线性 Kadane，内部单格一次线性扫描；总计 $3mn$ 次常数级操作。$m n \le 5\times10^5$ 时约 $1.5\times10^6$ 次，实测 C++ 约 $0.17$ s（含转置访问开销）。
- **空间**：$O(1)$ 额外空间（只用到若干累加器与答案变量），不额外申请 DP 表。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long maxScore(vector<vector<int>>& grid) {
        int m = grid.size(), n = grid[0].size();
        const long long NEG = LLONG_MIN / 4;
        long long ans = NEG;
        for (int i = 0; i < m; i++) {
            long long any = grid[i][0], ge2 = NEG;
            for (int j = 1; j < n; j++) {
                long long x = grid[i][j];
                long long nge2 = max(any, ge2) + x;
                any = max(x, any + x);
                ge2 = nge2;
                ans = max(ans, ge2);
            }
        }
        for (int j = 0; j < n; j++) {
            long long any = grid[0][j], ge2 = NEG;
            for (int i = 1; i < m; i++) {
                long long x = grid[i][j];
                long long nge2 = max(any, ge2) + x;
                any = max(x, any + x);
                ge2 = nge2;
                ans = max(ans, ge2);
            }
        }
        for (int i = 1; i + 1 < m; i++)
            for (int j = 1; j + 1 < n; j++)
                ans = max(ans, (long long)grid[i][j]);
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maxScore(self, grid: list[list[int]]) -> int:
        m, n = len(grid), len(grid[0])
        NEG = float("-inf")
        ans = NEG

        def scan(seq: list[int]) -> int:
            best = NEG
            any_len = seq[0]
            ge2 = NEG
            for x in seq[1:]:
                ge2 = max(any_len, ge2) + x
                any_len = max(x, any_len + x)
                best = max(best, ge2)
            return best

        for i in range(m):
            ans = max(ans, scan(grid[i]))
        for j in range(n):
            ans = max(ans, scan([grid[i][j] for i in range(m)]))
        for i in range(1, m - 1):
            for j in range(1, n - 1):
                ans = max(ans, grid[i][j])
        return ans
```

## 8. 边界情况与易错点

1. **$m = 2$ 或 $n = 2$**：不存在内部格子，单格候选为空；长度 $\ge 2$ 的候选仍然存在（因为 $m, n \ge 2$，行或列至少有两格），答案不会漏。
2. **全负数矩阵**：答案是一个负数，不能与 0 取 max。例如 `[[-1,-2],[-3,-4]]`：行段 `[-1,-2]` 和为 $-3$、`[-3,-4]` 和为 $-7$，列段 `[-1,-3]` 和为 $-4$、`[-2,-4]` 和为 $-6$，故答案是 $-3$。
3. **`ge2` 的初值**：必须是负无穷，不能用 0；否则在负数矩阵上会把「长度 1」误判为合法。
4. **转移顺序**：先算 `nge2`（用到旧的 `any`、`ge2`），再更新 `any`，最后赋 `ge2`。若先更新 `any`，长度 2 的段会被算成「长度 3」。
5. **单格必须在内部**：边界上的单格不可能成为唯一共享格（题面提示），若不加限制直接把全矩阵最大值纳入候选，会在「边界大正数、内部小值」的用例上 WA。
6. **竖直段也是合法候选**：两条路径可以**反向**遍历同一列（玩家 1 向下、玩家 2 向上），示例 2 的共享格 $(0,0),(1,0)$ 正是这种竖直段。所以行与列都必须扫，不能只扫行。
7. **共享段可以落在边界行/列**：长度 $\ge 2$ 时边界行/列完全合法（构造见引理 4），只有「单个共享格」才要求内部。
