# LeetCode 将 0 移到末尾的最少交换次数 题解

## 1. 题目概述

- **标题 / 题号**：将 0 移到末尾的最少交换次数（#3936，easy）
- **链接**：https://leetcode.cn/problems/minimum-swaps-to-move-zeros-to-end/
- **来源**：LeetCode 第 183 场双周赛 Q1
- **难度**：简单
- **标签**：数组、双指针

**题意**：给定整数数组 `nums`。一次操作可以交换任意两个**不同下标**的元素。求把所有 `0` 都移到数组**末尾**所需的**最少**操作次数（非 0 元素之间的相对顺序不作要求）。

**约束**：

- $1 \le nums.length \le 100$
- $0 \le nums[i] \le 100$

## 2. 示例

**示例 1**

```text
输入：nums = [0,1,0,3,12]
输出：2
解释：交换 nums[0] 与 nums[3] 得 [3,1,0,0,12]，再交换 nums[2] 与 nums[4] 得 [3,1,12,0,0]。
```

**示例 2**

```text
输入：nums = [0,1,0,2]
输出：1
解释：交换 nums[0] 与 nums[3] 一步到位，得 [2,1,0,0]。
```

**示例 3**

```text
输入：nums = [1,2,0]
输出：0
解释：0 已经在末尾，无需交换。
```

## 3. 解题思路

### 3.1 暴力思路

把「所有 0 都在末尾」当作目标状态，在状态图上做 BFS（每个状态是一次交换的结果）。状态数是 $n!$ 级别的排列，$n = 100$ 时完全不可行；即使 $n \le 8$ 也要枚举上万个状态。注意本题**不要求非 0 元素保序**，这让问题比「移动零」（LeetCode 283）更简单——不需要模拟移动，只需要数「错位」。

### 3.2 核心观察：末尾 $z$ 个格子必须全是 0

![把 0 挪到末尾：末尾 z 个格子必须全是 0](images/bw183_q1_suffix.svg)

设数组中共有 $z$ 个 0。任何「所有 0 都在末尾」的合法终态，都满足：

- 后 $z$ 个位置（下标 $n-z \sim n-1$）**全是 0**；
- 前 $n-z$ 个位置**全是非 0**。

于是问题变成：**把后 $z$ 个格子里的非 0 元素换出去**。设后 $z$ 格中非 0 的个数为 $b$，那么：

- **下界**：每次交换最多把一个非 0 元素从后缀区换出（同时换一个 0 进来），所以至少要 $b$ 次；
- **可达性**：后缀区里有 $b$ 个非 0，前缀区里恰有 $b$ 个 0（因为 0 的总数是 $z$，后缀区已有 $z-b$ 个 0），逐个配对交换即可用 $b$ 次完成。

因此答案就是 $b$——**后缀区中非 0 元素的个数**，等价于「前缀区中 0 的个数」。一遍扫描即可，$O(n)$。

### 3.3 算法流程

```text
1. z = nums 中 0 的个数
2. bad = 0
3. for i = n - z .. n - 1:  若 nums[i] != 0 则 bad++
4. 返回 bad
```

### 3.4 示例演算

![示例演算：数一数末尾 z 格里有几个非 0](images/bw183_q1_walkthrough.svg)

| `nums` | $z$ | 末尾 $z$ 格 | 其中非 0 个数 | 答案 |
|--------|-----|--------------|----------------|------|
| `[0,1,0,3,12]` | 2 | `[3,12]` | 2 | 2 |
| `[0,1,0,2]` | 2 | `[0,2]` | 1 | 1 |
| `[1,2,0]` | 1 | `[0]` | 0 | 0 |

示例 1 中后缀区的 `3` 与 `12` 各与前面的一个 `0` 交换，两次搞定；示例 3 的后缀区已经是 `0`，无需操作。

## 4. 算法细节

1. **统计 $z$**：`count(nums.begin(), nums.end(), 0)` 或一遍循环。
2. **后缀区间**：`[n - z, n - 1]`。注意 $z$ 可能为 0（无 0）或等于 $n$（全 0），此时区间为空或整个数组，循环边界都要正确。
3. **无符号下标的坑**：C++ 中 `n - z` 若用 `size_t` 计算，$z \le n$ 时安全；但若把 `z` 写成 `int` 而 `n` 是 `size_t`，`n - z` 会做无符号运算，务必保证 $z \le n$（本题恒成立）。
4. **不必真的交换**：只计数即可，避免额外 $O(n)$ 的模拟开销。
5. **「非 0」而不是「正数」**：元素可能是负数（本题 $nums[i] \ge 0$，但写法上应判 `!= 0` 而非 `> 0`）。

## 5. 正确性证明

**引理 1（终态的充要条件）**：数组「所有 0 都在末尾」$\iff$ 后 $z$ 个位置全为 0（等价地，前 $n-z$ 个位置全非 0）。

**证明**：0 的总数为 $z$。若后 $z$ 个位置全为 0，则 $z$ 个 0 已全部用尽，前 $n-z$ 个位置必非 0，故所有 0 都在末尾。反之若所有 0 都在末尾，末尾连续 0 的个数至少为 $z$，而数组一共只有 $z$ 个 0，故恰好是后 $z$ 个位置。∎

**引理 2（下界）**：设后 $z$ 个位置中有 $b$ 个非 0 元素，则任何合法终态都至少需要 $b$ 次交换。

**证明**：一次交换涉及两个位置，最多把**一个**非 0 元素从后 $z$ 个位置移出（若交换双方都在后缀区则一个也没移出，若一方在后缀区则至多移出一个）。由引理 1，终态要求后缀区非 0 元素个数为 0，即需把 $b$ 个非 0 全部移出，故至少 $b$ 次。∎

**引理 3（可达性）**：存在恰好 $b$ 次交换的构造。

**证明**：后缀区有 $b$ 个非 0，故后缀区有 $z - b$ 个 0；前缀区（长度 $n-z$）中的 0 个数为 $z - (z-b) = b$。把后缀区的 $b$ 个非 0 与前缀区的 $b$ 个 0 一一配对交换，每次交换后该非 0 进入前缀区、该 0 进入后缀区且不再被动，$b$ 次后后缀区全为 0。∎

**定理**：算法返回的 `bad` 等于最少交换次数。

**证明**：算法统计的正是后缀区非 0 元素个数 $b$。由引理 2 至少需要 $b$ 次，由引理 3 恰能用 $b$ 次完成，故最少次数为 $b$。∎

## 6. 复杂度分析

- **时间**：$O(n)$。统计 0 的个数一遍，统计后缀区非 0 元素再一遍。
- **空间**：$O(1)$，只用到两个计数器。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minimumSwaps(vector<int>& nums) {
        int n = nums.size();
        int z = 0;
        for (int v : nums)
            if (v == 0) z++;
        int bad = 0;
        for (int i = n - z; i < n; i++)
            if (nums[i] != 0) bad++;
        return bad;
    }
};
```

### Python

```python
class Solution:
    def minimumSwaps(self, nums: list[int]) -> int:
        z = nums.count(0)
        return sum(1 for v in nums[len(nums) - z:] if v != 0)
```

## 8. 边界情况与易错点

1. **没有 0**：$z = 0$，后缀区间为空，答案 0（数组已满足「所有 0 都在末尾」）。
2. **全是 0**：$z = n$，后缀区间是整数组且全为 0，答案 0。
3. **$z = 1$**：只看最后一个格子是否为 0（示例 3）。
4. **不要把问题做成「保序移动」**：本题不要求非 0 元素保序，一旦按 LeetCode 283 的双指针「移动」去数交换次数，就会把答案算大（那是另一种等价于「逆序对/位移」的度量）。
5. **交换双方必须不同下标**：一次交换不能「自己和自己换」，所以下界论证里每次最多移出一个非 0 是紧的。
6. **一次交换可能同时修好两个位置**？不会：后缀区的一个非 0 与前缀区的一个 0 交换，恰好各修好一个位置，所以 $b$ 次不多不少。

**延伸思考**：若要求非 0 元素**保序**，最少交换次数就不再是错位数，而等于「每个 0 需要跨越的非 0 个数」之和，可用双指针 $O(n)$ 统计。若允许「把 0 移到末尾或开头（二选一）」，就是两个方向的错位数取最小。若操作改成「把任意元素移到任意位置」（插入而非交换），答案会变成「最长保序子序列」相关的量。
