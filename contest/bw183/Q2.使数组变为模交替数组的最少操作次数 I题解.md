# LeetCode 使数组变为模交替数组的最少操作次数 I 题解

## 1. 题目概述

- **标题 / 题号**：使数组变为模交替数组的最少操作次数 I（#3937，medium）
- **链接**：https://leetcode.cn/problems/minimum-operations-to-make-array-modulo-alternating-i/
- **来源**：LeetCode 第 183 场双周赛 Q2
- **难度**：中等
- **标签**：数组、枚举、数学

**题意**：给定整数数组 `nums` 与整数 $k$。一次操作可以把任意元素 $+1$ 或 $-1$。若存在**两个不同**的整数 $x, y$（$0 \le x, y < k$）使得

- 每个**偶数**下标 $i$ 满足 `nums[i] % k == x`；
- 每个**奇数**下标 $i$ 满足 `nums[i] % k == y`，

则称数组是**模交替**的。求最少操作次数。

**约束**：

- $1 \le n \le 100$
- $1 \le nums[i] \le 10^9$
- $2 \le k \le 100$

## 2. 示例

**示例 1**

```text
输入：nums = [1,4,2,8], k = 3
输出：2
解释：取 x = 1（偶数下标）、y = 2（奇数下标）：
     4 加 1 变 5（5 % 3 = 2 ✓），2 减 1 变 1（1 % 3 = 1 ✓），共 2 次操作。
```

**示例 2**

```text
输入：nums = [1,1,1], k = 3
输出：1
解释：把中间的 1 加到 2，得 [1,2,1]，此时 x = 1、y = 2，只需 1 次操作。
```

## 3. 解题思路

### 3.1 暴力思路

直接枚举所有 $x, y$ 组合（$k^2 \le 10^4$ 种），对每种组合遍历数组求代价：$O(k^2 n) = 10^6$，在 $n, k \le 100$ 时完全可行——这就是本题的正解框架。真正需要想清楚的是**单个元素到达指定残差的最小操作数**，以及**为什么可以按奇偶两组独立预处理**。

### 3.2 核心观察：按奇偶拆成两组残差，代价是「环上距离」

![按奇偶下标拆成两组残差，问题变成「各选一个残差」](images/bw183_q2_residue.svg)

- **只关心残差**：把 $nums[i]$ 变成任何与目标 $x$ 同余的数，操作次数相同吗？不同，但**最小的**次数只取决于 $r = nums[i] \bmod k$ 与 $x$ 在模 $k$ 环上的距离：

$$d(r, x) = \min\big(|r - x|,\ k - |r - x|\big)$$

因为把数值 $+1$ 会让残差沿环前进一格，$-1$ 则后退一格；从 $r$ 走到 $x$ 的最短步数就是环上的最短距离（可以加也可以减，故取两种方向的最小值）。
- **按奇偶分组**：偶数下标只受 $x$ 影响、奇数下标只受 $y$ 影响，两组互不干扰。于是先统计两组各自的**残差直方图** $cnt_E[\cdot]$、$cnt_O[\cdot]$，再预处理

$$cost_E[x] = \sum_{r} cnt_E[r] \cdot d(r, x), \qquad cost_O[y] = \sum_{r} cnt_O[r] \cdot d(r, y)$$

- **答案**：

$$\min_{x \ne y} \big(cost_E[x] + cost_O[y]\big)$$

枚举 $x, y$ 是 $O(k^2)$，加上预处理 $O(k^2)$，总复杂度 $O(k^2 + n)$，与 $n$ 的上界无关。

### 3.3 算法流程

```text
1. 统计甚至下标残差直方图 even[r]、奇数下标直方图 odd[r]
2. for x in 0..k-1:
       costE[x] = Σ_r even[r] * min(|r-x|, k-|r-x|)
       costO[x] = Σ_r odd[r]  * min(|r-x|, k-|r-x|)
3. ans = min{ costE[x] + costO[y] : 0 ≤ x,y < k, x ≠ y }
4. 返回 ans
```

### 3.4 示例演算

![示例 1 演算：把每个元素挪到目标残差的最小步数](images/bw183_q2_walkthrough.svg)

`nums = [1,4,2,8]`、$k = 3$：偶数下标 $\{0,2\}$ 的残差是 $\{1, 2\}$，奇数下标 $\{1,3\}$ 的残差也是 $\{1, 2\}$。

取 $x = 1$（偶数下标）、$y = 2$（奇数下标）：

| 下标 / 值 | 当前残差 | 目标残差 | 步数 |
|-----------|----------|----------|------|
| 0 / 1 | 1 | $x = 1$ | 0 |
| 1 / 4 | 1 | $y = 2$ | 1 |
| 2 / 2 | 2 | $x = 1$ | 1 |
| 3 / 8 | 2 | $y = 2$ | 0 |

总代价 $0+1+1+0 = 2$，与题面一致。若取 $(x, y) = (2, 1)$ 代价同样为 2；其它组合更大，故答案是 2。

## 4. 算法细节

1. **残差直方图**：`even[nums[i] % k]++`（$i$ 偶）、`odd[...]++`（$i$ 奇）。$k \le 100$，数组很小。
2. **环上距离**：`d = abs(r - x); d = min(d, k - d);`。注意 $k - d$ 是「绕环另一侧」的步数，只有当 $k \ge 2$ 时才有意义（题面保证 $k \ge 2$）。
3. **$x \ne y$ 的枚举**：直接双重循环加 `if (x != y)`。$k \ge 2$ 保证至少存在一组，`ans` 不会被初始化值污染（用 `INT_MAX` 起步）。
4. **$n = 1$ 的退化**：只有一个偶数下标，奇数侧直方图全 0，`costO[y]` 恒为 0；仍要选 $y \ne x$，答案就是「把唯一元素调到某个 $x$ 的最小代价」（$x$ 任选，故最优 $x$ 就是它当前的残差，答案为 0——只要 $k \ge 2$ 就有别的 $y$ 可选）。示例 2 的 $n = 3$ 则有奇数侧。
5. **数值范围**：$nums[i] \le 10^9$，`nums[i] % k` 安全；操作次数上界约 $n \cdot k/2 \le 5000$，`int` 足够。
6. **不必真的修改数组**：所有代价都是「距离」，只需统计。

## 5. 正确性证明

**引理 1（单元素的环上距离公式）**：把 $v$ 变成某个满足 $v' \equiv x \pmod k$ 的整数，最少需要 $\min(|r - x|, k - |r - x|)$ 次 $\pm 1$ 操作，其中 $r = v \bmod k$。

**证明**：设做了 $d$ 次操作，其中 $p$ 次 $+1$、$q$ 次 $-1$，则 $v' = v + p - q$ 且 $d \ge p + q \ge |p - q|$。要求 $v' \equiv x$，即 $(p - q) \equiv x - r \pmod k$。于是 $|p - q|$ 必须是某个满足 $t \equiv x - r \pmod k$ 的非负整数 $t$ 的绝对值，其最小值就是 $\min(|r-x|, k-|r-x|)$（沿环两个方向）。取到该值的构造是「一直 $+1$」或「一直 $-1$」，共 $d = \min(|r-x|, k-|r-x|)$ 次。∎

**引理 2（两组可分离）**：对任意 $x \ne y$，使数组模交替的最少操作数等于 $cost_E[x] + cost_O[y]$。

**证明**：每个元素的操作次数只能依赖它自己与目标残差（操作之间互不影响，且没有「一起改」的捷径）。偶数下标的目标是 $x$、奇数是 $y$，由引理 1，两侧各自最少为 $cost_E[x]$、$cost_O[y]$，且可同时取到（对每个元素独立按最优方向操作），故总和等于两者之和。∎

**定理**：算法返回最少操作次数。

**证明**：合法的 $(x, y)$ 组合有限（$k(k-1)$ 种且都满足 $0 \le x, y < k$、$x \ne y$），算法枚举全部组合，对每种组合按引理 2 得到该组合下的最少操作数，取最小值即全局最优。∎

## 6. 复杂度分析

- **时间**：$O(n + k^2)$。统计直方图 $O(n)$；预处理 $cost_E, cost_O$ 各 $O(k^2)$；枚举 $(x,y)$ 为 $O(k^2)$。$n, k \le 100$ 时约 $10^4$ 次运算。
- **空间**：$O(k)$，两个残差直方图与两份代价数组。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minOperations(vector<int>& nums, int k) {
        vector<int> even(k, 0), odd(k, 0);
        for (int i = 0; i < (int)nums.size(); i++) {
            if (i % 2 == 0) even[nums[i] % k]++;
            else odd[nums[i] % k]++;
        }
        vector<int> ce(k, 0), co(k, 0);
        for (int x = 0; x < k; x++)
            for (int r = 0; r < k; r++) {
                int d = abs(r - x);
                d = min(d, k - d);
                ce[x] += even[r] * d;
                co[x] += odd[r] * d;
            }
        int ans = INT_MAX;
        for (int x = 0; x < k; x++)
            for (int y = 0; y < k; y++)
                if (x != y) ans = min(ans, ce[x] + co[y]);
        return ans;
    }
};
```

### Python

```python
class Solution:
    def minOperations(self, nums: list[int], k: int) -> int:
        even = [0] * k
        odd = [0] * k
        for i, v in enumerate(nums):
            if i % 2 == 0:
                even[v % k] += 1
            else:
                odd[v % k] += 1

        def costs(cnt: list[int]) -> list[int]:
            res = [0] * k
            for x in range(k):
                s = 0
                for r in range(k):
                    if cnt[r]:
                        d = abs(r - x)
                        s += cnt[r] * min(d, k - d)
                res[x] = s
            return res

        ce = costs(even)
        co = costs(odd)
        return min(ce[x] + co[y] for x in range(k) for y in range(k) if x != y)
```

## 8. 边界情况与易错点

1. **$x \ne y$ 是硬约束**：若允许 $x = y$，答案会更小；必须显式排除。$k = 2$ 时只有 $(0,1)$、$(1,0)$ 两种组合。
2. **$n = 1$**：奇数侧为空，代价 0；但 $y$ 仍须与 $x$ 不同，不能把「只有一组」当作无解。
3. **环上距离不要写成 $|r - x|$**：当 $k$ 较小时绕环更近，例如 $k = 10$、$r = 9$、$x = 0$，直线距离 9 但环上距离只有 1。
4. **数值可以减到 0 甚至负数**：题面只限制 `nums[i]` 的初始范围，不限制操作后的值，所以「$-1$ 方向」始终可用（这也是引理 1 里两个方向都成立的原因）。
5. **`INT_MAX` 起步**：`ans` 初始化要足够大，且 $k \ge 2$ 保证至少一组可行，不会返回未更新的值。
6. **残差直方图 vs 逐个元素枚举**：若写成「对每组 $(x,y)$ 都遍历数组」，复杂度 $O(k^2 n) = 10^6$ 也能过，但按直方图预处理更清晰，且能直接迁移到 II 版的大 $n$。
