# LeetCode 统计有根树中不相邻子集的数目 题解

## 1. 题目概述

- **标题 / 题号**：统计有根树中不相邻子集的数目（#3939，hard）
- **链接**：https://leetcode.cn/problems/count-non-adjacent-subsets-in-a-rooted-tree/
- **来源**：LeetCode 第 183 场双周赛 Q4
- **难度**：困难
- **标签**：树、深度优先搜索、数组、动态规划

**题意**：给定 $n$ 个节点的有根树，`parent` 描述父子关系（`parent[0] = -1`，节点 0 为根；对 $1 \le i < n$ 有 $parent[i] < i$）。`nums[i]` 是节点 $i$ 的值，另有整数 $k$。

求满足下面两条的**非空**节点子集个数（对 $10^9+7$ 取模）：

1. 子集中节点值之和能被 $k$ 整除；
2. 子集中没有两个节点在树中**相邻**（即不存在某节点与其父节点同时被选）。

**约束**：

- $1 \le n \le 1000$
- $parent[0] = -1$，且 $0 \le parent[i] < i$（对 $1 \le i < n$）
- $1 \le nums[i] \le 10^9$，$1 \le k \le 100$

## 2. 示例

**示例 1**

```text
输入：parent = [-1,0,1], nums = [1,2,3], k = 3
输出：1
解释：树是链 0-1-2。非空子集中满足「无相邻 + 和被 3 整除」的只有 {2}（值 3）。
     {0}=1、{1}=2、{0,2}=4 余数都不为 0；{0,1}、{1,2}、{0,1,2} 都有相邻节点。
```

**示例 2**

```text
输入：parent = [-1,0,0,0], nums = [2,1,2,1], k = 3
输出：2
解释：0 是根，1、2、3 都是它的孩子。有效子集为 {1,2}（1+2=3）与 {2,3}（2+1=3）。
     {0,1}、{0,2}、{0,3} 都相邻；单点里只有根值 2，2 % 3 ≠ 0。
```

## 3. 解题思路

### 3.1 暴力思路

枚举全部 $2^n$ 个子集，逐个检查「无父子同选」与「和 $\bmod k = 0$」。$n \le 1000$ 时 $2^{1000}$ 完全不可行；即便 $n = 20$，$O(2^n \cdot n)$ 也只是勉强。必须用树上 DP 把「相邻」这一局部约束与「模 $k$ 的余数」这一全局约束一起压进状态。

### 3.2 核心观察：树上「选/不选」DP + 余数维

![树形 DP：每个节点维护「选 / 不选」两套余数计数](images/bw183_q4_dp_states.svg)

- **相邻约束是局部的**：一个节点是否可选，只取决于它的**父节点**是否被选（以及它的孩子是否被选，在自底向上合并时体现）。这正是树形 DP 的标准形态。
- **余数维**：需要知道子树内的「和模 $k$」，而 $k \le 100$，于是状态为

$$dp_0[u][r] = \#\{\text{在 } u \text{ 的子树中选点，} u \text{ 不选，和} \bmod k = r\}$$
$$dp_1[u][r] = \#\{\text{在 } u \text{ 的子树中选点，} u \text{ 选，和} \bmod k = r\}$$

- **初值**：$dp_0[u][0] = 1$（$u$ 不选，子树的空选择，和为 0）；$dp_1[u][nums[u] \bmod k] = 1$（$u$ 选，和为 $nums[u]$）。
- **合并孩子**：把子节点 $v$ 的计数并入 $u$。若 $u$ 被选，则 $v$ 一定不能被选，只能用 $dp_0[v]$；若 $u$ 不选，则 $v$ 选不选都行，用 $dp_0[v] + dp_1[v]$。余数按 $(a + b) \bmod k$ 卷积。
- **答案**：$dp_0[0][0] + dp_1[0][0] - 1$，减去的 1 是**空集**（$dp_0[0][0]$ 里包含「一个都不选」）。

### 3.3 算法流程

![合并 = 余数卷积；parent[i] < i 保证可以倒序迭代](images/bw183_q4_merge.svg)

```text
1. 对每个 u：dp0[u][0] = 1，dp1[u][nums[u] % k] += 1
2. for v = n-1 down to 1:                  // parent[v] < v ⇒ 逆序即后序
       u = parent[v]
       childAny[r] = dp0[v][r] + dp1[v][r]
       new0[(a+b) % k] += dp0[u][a] * childAny[b]
       new1[(a+b) % k] += dp1[u][a] * dp0[v][b]
       dp0[u] = new0，dp1[u] = new1
3. 返回 (dp0[0][0] + dp1[0][0] - 1 + MOD) % MOD
```

**为什么可以逆序迭代而不写递归**：题面保证 $parent[i] < i$，所以子节点的编号一定大于父节点。从 $n-1$ 递减到 1 处理 $v$ 时，$v$ 的所有后代编号都大于 $v$、都已经被合并进 $dp[v]$，可以安全地把 $dp[v]$ 整体并入 $dp[parent[v]]$。这样既避免了 $n = 1000$ 的递归深度问题，也不需要显式建树。

### 3.4 示例演算

![示例 2 演算：根与三个孩子](images/bw183_q4_walkthrough.svg)

`parent = [-1,0,0,0]`、`nums = [2,1,2,1]`、$k = 3$：

- 叶子 1（值 1）：$dp_0 = [1,0,0]$，$dp_1 = [0,1,0]$（余数 1）；
- 叶子 2（值 2）：$dp_0 = [1,0,0]$，$dp_1 = [0,0,1]$（余数 2）；
- 叶子 3（值 1）：同叶子 1；
- 根 0（值 2）：初值 $dp_0 = [1,0,0]$，$dp_1 = [0,0,1]$。合并三个孩子后，$dp_1[0][0]$ 需要「根选中 + 孩子全不选」且余数和为 0：$2 \bmod 3 = 2 \ne 0$，故不贡献；$dp_0[0][0]$ 统计「根不选、孩子任选」中和 $\equiv 0$ 的方案，其中 $\{1,2\}$ 与 $\{2,3\}$ 两组命中（各贡献 1），加空集后 $dp_0[0][0] = 3$，$dp_1[0][0] = 0$，答案 $= 3 + 0 - 1 = 2$。

## 4. 算法细节

1. **状态数组**：`vector<vector<long long>> dp0(n, vector<long long>(k))`，共 $n \times k \le 10^5$ 个格子；两个数组共 $2\times10^5$ 个 `long long`。
2. **合并必须用临时数组**：`new0`、`new1` 先算完再覆盖，否则 $dp_0[u]$ 会被自己刚写入的值再次卷积（同一孩子被重复计入）。
3. **取模时机**：每次加法后取模，避免 `long long` 溢出（两个 $<10^9+7$ 的数相乘约 $10^{18}$，仍在 `long long` 内）。
4. **`nums[u] % k`**：$nums[u] \le 10^9$，先取模再作为下标。
5. **逆序迭代**：`for (int v = n-1; v >= 1; --v)`，因为 $parent[v] < v$ 保证拓扑序。
6. **答案减一**：$dp_0[0][0] + dp_1[0][0]$ 含空集（$dp_0[0][0]$ 的空选择贡献 1），题目要求非空，减 1 后取模防负。
7. **每个孩子的两套状态**：合并时 `childAny` 只算一次，避免在双重循环里反复相加。

## 5. 正确性证明

**引理 1（DP 语义）**：合并完 $u$ 的全部孩子后，$dp_0[u][r]$ 等于「$u$ 的子树内满足相邻约束、$u$ 不选、节点和 $\equiv r \pmod k$」的方案数；$dp_1[u][r]$ 同理但要求 $u$ 被选。

**证明**：对 $u$ 的子树高度归纳。叶子没有孩子，$dp_0[u][0] = 1$（唯一方案是空集，和为 0）、$dp_1[u][nums[u] \bmod k] = 1$（唯一方案是 $\{u\}$），语义成立。设 $u$ 的孩子 $v_1, \dots, v_m$，并设已合并前 $t$ 个孩子后语义成立；合并 $v = v_{t+1}$ 时：

- $u$ 不选：$u$ 与孩子之间没有约束，$v$ 是否被选都合法，且 $v$ 子树内部必须满足约束（归纳假设保证 $dp_0[v]$、$dp_1[v]$ 已计入），故方案数按余数卷积为 $dp_0[u][a] \cdot (dp_0[v][b] + dp_1[v][b])$ 累加到 $r = (a+b) \bmod k$；
- $u$ 被选：$v$ 不能选，只能取 $dp_0[v]$，故为 $dp_1[u][a] \cdot dp_0[v][b]$。

两种情况都恰好枚举了 $v$ 子树的所有合法方案且不重不漏，归纳成立。∎

**引理 2（逆序迭代的正确性）**：按 $v = n-1, n-2, \dots, 1$ 的顺序把 $dp[v]$ 并入 $dp[parent[v]]$ 时，处理 $v$ 之前 $dp[v]$ 已包含其整棵子树的信息。

**证明**：对 $v$ 归纳（按编号递减）。$v$ 的孩子 $c$ 满足 $parent[c] = v$，由 $parent[c] < c$ 得 $c > v$，故所有孩子在 $v$ 之前被处理并已并入 $dp[v]$；孩子的子树信息由归纳假设完整。故处理 $v$ 时 $dp[v]$ 是其整棵子树的完整 DP。∎

**定理**：算法返回的答案等于满足两条约束的非空子集个数。

**证明**：由引理 2，$dp_0[0]$、$dp_1[0]$ 是根节点整棵树的完整 DP。由引理 1，$dp_0[0][0] + dp_1[0][0]$ 统计了「满足相邻约束且和 $\equiv 0 \pmod k$」的全部方案，其中恰好包含一个空集方案（空集在 $dp_0[0][0]$ 中，和为 0，且 $0 \equiv 0$）。题目要求非空，减去 1 即得所求；模运算下减 1 后补正不影响结果。∎

## 6. 复杂度分析

- **时间**：$O(n k^2)$。每个非根节点被合并一次，每次合并是两个长度为 $k$ 的数组做卷积，$O(k^2)$。$n \le 1000$、$k \le 100$ 时约 $10^7$ 次乘加，实测 C++ 约 $12$ ms。
- **空间**：$O(nk)$。两套 DP 共 $2nk$ 个 `long long`（约 $2\times10^5$ 个），外加临时数组 $O(k)$；无递归栈。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int countValidSubsets(vector<int>& parent, vector<int>& nums, int k) {
        const long long MOD = 1000000007LL;
        int n = parent.size();
        vector<vector<long long>> dp0(n, vector<long long>(k, 0));
        vector<vector<long long>> dp1(n, vector<long long>(k, 0));
        for (int u = 0; u < n; u++) {
            dp0[u][0] = 1;
            dp1[u][nums[u] % k] = 1;
        }
        for (int v = n - 1; v >= 1; v--) {
            int u = parent[v];
            vector<long long> childAny(k, 0), n0(k, 0), n1(k, 0);
            for (int r = 0; r < k; r++) childAny[r] = (dp0[v][r] + dp1[v][r]) % MOD;
            for (int a = 0; a < k; a++) {
                if (dp0[u][a])
                    for (int b = 0; b < k; b++)
                        if (childAny[b]) {
                            int t = (a + b) % k;
                            n0[t] = (n0[t] + dp0[u][a] * childAny[b]) % MOD;
                        }
                if (dp1[u][a])
                    for (int b = 0; b < k; b++)
                        if (dp0[v][b]) {
                            int t = (a + b) % k;
                            n1[t] = (n1[t] + dp1[u][a] * dp0[v][b]) % MOD;
                        }
            }
            dp0[u].swap(n0);
            dp1[u].swap(n1);
        }
        long long ans = (dp0[0][0] + dp1[0][0] - 1) % MOD;
        if (ans < 0) ans += MOD;
        return (int)ans;
    }
};
```

### Python

```python
class Solution:
    def countValidSubsets(self, parent: list[int], nums: list[int], k: int) -> int:
        MOD = 10 ** 9 + 7
        n = len(parent)
        dp0 = [[0] * k for _ in range(n)]
        dp1 = [[0] * k for _ in range(n)]
        for u in range(n):
            dp0[u][0] = 1
            dp1[u][nums[u] % k] = 1
        for v in range(n - 1, 0, -1):
            u = parent[v]
            child_any = [(dp0[v][r] + dp1[v][r]) % MOD for r in range(k)]
            n0 = [0] * k
            n1 = [0] * k
            for a in range(k):
                if dp0[u][a]:
                    ca = dp0[u][a]
                    for b in range(k):
                        if child_any[b]:
                            n0[(a + b) % k] = (n0[(a + b) % k] + ca * child_any[b]) % MOD
                if dp1[u][a]:
                    ca = dp1[u][a]
                    for b in range(k):
                        if dp0[v][b]:
                            n1[(a + b) % k] = (n1[(a + b) % k] + ca * dp0[v][b]) % MOD
            dp0[u], dp1[u] = n0, n1
        return (dp0[0][0] + dp1[0][0] - 1) % MOD
```

## 8. 边界情况与易错点

1. **$n = 1$**：只有一个根。$dp_0[0][0] = 1$，$dp_1[0][nums[0] \bmod k]$。答案 = $dp_0[0][0] + dp_1[0][0] - 1$，即 $nums[0] \equiv 0 \pmod k$ 时为 1，否则 0。
2. **跳过空集**：$dp_0[u][0]$ 恒含「子树全不选」这一方案，最终答案必须减 1，否则会多算空集。
3. **临时数组**：不能原地卷积，否则同一孩子会被计入两次——这是树形背包最常见的 bug。
4. **`nums[u] % k` 作为下标**：$nums[u]$ 可达 $10^9$，不取模直接当下标会越界。
5. **链状树**：$n = 1000$ 的链在递归实现下会爆栈（默认递归深度约 $1000 \sim$ 几千），本解法用逆序迭代规避。
6. **取模**：乘积可能到 $10^{18}$，C++ 用 `long long` 并在每次加法后取模；Python 无溢出问题但仍需取模保持数值可控。
7. **减一取模为负**：C++ 中 `(a + b - 1) % MOD` 可能为负（当 $a + b = 0$ 时），需补一次 `+MOD`；Python 的 `%` 天然返回非负。
8. **$k = 1$**：所有和都能被 1 整除，答案退化成「树上不相邻的非空子集个数」，DP 仍正确（余数只有 0 一维）。
