# LeetCode 统计一个字符串的 k 子序列美丽值最大的数目 题解

## 1. 题目概述

- **标题 / 题号**：统计一个字符串的 k 子序列美丽值最大的数目（#2842，hard）
- **链接**：https://leetcode.cn/problems/count-k-subsequences-of-a-string-with-maximum-beauty/
- **来源**：LeetCode 第 112 场双周赛 Q4
- **难度**：困难
- **标签**：贪心、哈希表、数学、组合数学、字符串、排序

**题意**：给定字符串 $s$ 与整数 $k$。**k 子序列**指 $s$ 的长度为 $k$ 且**所有字符互不相同**的子序列（每个字符在子序列中恰出现一次）。$f(c)$ 为字符 $c$ 在 $s$ 中的出现次数。k 子序列的**美丽值**为其每个字符 $c$ 的 $f(c)$ 之和。返回美丽值**最大**的 k 子序列数目，对 $10^9 + 7$ 取模。注意：两个 k 子序列只要有一个字符在原串中的**下标**不同，即为不同子序列。

**约束**：

- $1 \le |s| \le 2 \times 10^5$
- $1 \le k \le |s|$
- $s$ 只含小写英文字母

## 2. 示例

**示例 1**

```text
输入：s = "bcca", k = 2
输出：4
解释：f(b)=1, f(c)=2, f(a)=1。美丽值最大的 2 子序列必含 'c'（f=2）
     再配 'a' 或 'b'（f=1），美丽值为 3。
     方案数 = 'c' 的 2 个下标选 1 个 × 'a'/'b' 二选一（2 种字符选择 × 各 1 个下标）
            = 2 × 2 = 4。
```

**示例 2**

```text
输入：s = "abbcd", k = 4
输出：2
解释：f(a)=1, f(b)=2, f(c)=1, f(d)=1。四个不同字符必须全选，
     美丽值 1+2+1+1 = 5；b 的出现位置有 2 种选法，其余字符各 1 种，共 2 个。
```

**示例 3（边界补充）**

```text
输入：s = "aa", k = 2
输出：0
解释：不同字符只有 1 个（'a'），凑不出 k = 2 个互不相同的字符。
```

## 3. 解题思路

### 3.1 暴力思路

枚举 $s$ 中所有 $k$ 个位置的组合 $\binom{n}{k}$（要求选出位置上的字符互异），逐一计算美丽值再统计最大值个数——$n = 2\times10^5$ 下组合数是天文数字，完全不可行。但暴力揭示了一个关键结构：**美丽值只依赖「选了哪些字符」，与「选了哪些下标」无关**；下标选择只把每个「字符集合」的方案数放大 $\prod_c f(c)$ 倍。于是问题拆成两层：先找「使 $\sum f(c)$ 最大的 $k$ 字符集合」，再数「这些集合各自的展开方案数」。

### 3.2 核心观察：最大美丽值 = 频次前 k 大之和；计数分「整取」与「跨界」两段

![核心观察：按频次从大到小装满 k 个名额，边界桶组合数 C(c,t)](images/bw112_q4_greedy_buckets.svg)

**第一层（哪个字符集合最优）**：美丽值是所选字符频次之和，要 $k$ 个不同字符、和最大——贪心：**取频次最大的 $k$ 个字符**。交换论证显然：若某最优解含频次 $u$ 而不含更大的 $v$，换成 $v$ 和严格变大，矛盾。

**第二层（有多少个达到最大值的子序列）**：注意达到**同一最大美丽值**的字符集合可能不唯一！设频次从大到小为 $v_1 \ge v_2 \ge \dots$，逐个「装入」名额：频次 $v$ 的字符共 $c$ 个（同频次的一桶）。若名额在某一桶内用不完（$k$ 落在桶中间），则**该桶任选 $t$ 个**（$t$ 为剩余名额）都不改变总和（同频次！），组合数 $\binom{c}{t}$ 种字符集合选择；而每个字符集合的子序列方案数为 $\prod f(c)$——**同一桶内字符频次相同**，故乘积统一为 $v^t$。

$$\text{答案} = \binom{c}{t} \cdot v^t \cdot \prod_{\text{更高频桶整取}} v_i^{c_i}$$

其中「更高频的桶」全部整桶取（$c_i$ 个全选，贡献 $v_i^{c_i}$），只有**恰好跨在 $k$ 名额边界上的桶**贡献组合数 $\binom{c}{t}$。若 $k$ 恰好在某桶边界处用尽（$t = c$），$\binom{c}{c} = 1$，退化为整桶取，公式依然成立。

### 3.3 算法流程

```text
1. 统计 26 个字母频次 f[c]，非零频次降序排列为 freq
2. 若不同字符数 < k：返回 0（凑不出 k 个互异字符）
3. ans = 1, 剩余名额 rem = k, i = 0
4. while rem > 0：
       v = freq[i]；向右扫描同频段 [i, j)，段长 c = j − i
       t = min(rem, c)
       ans *= v^t                     （该段贡献 t 个字符，每个 f = v）
       若 t < c：ans *= C(c, t)       （段内任选 t 个）
       rem −= t, i = j
5. 返回 ans mod 1e9+7
```

### 3.4 示例演算

![示例演算：两层相乘的计数结构（示例 1）](images/bw112_q4_walkthrough.svg)

以示例 1 `s = "bcca"`、$k = 2$ 为例：频次为 $c{:}2,\ a{:}1,\ b{:}1$（降序 2, 1, 1）。第一桶 $v = 2$、$c = 1$：$t = \min(2, 1) = 1$，整取，ans $= 2^1 = 2$，rem $= 1$。第二桶 $v = 1$、$c = 2$：$t = \min(1, 2) = 1 < c = 2$，ans $\times= 1^1 \times \binom{2}{1} = 2$ → ans $= 4$，rem $= 0$。返回 $4$ ✓——含义：必选 c（2 个下标选法）× 在 a、b 中任选一个（$\binom{2}{1}$ 种字符选择 × 各 1 个下标）。

以示例 2 `s = "abbcd"`、$k = 4$ 为例：频次降序 2, 1, 1, 1。第一桶整取贡献 $2^1$；第二桶 $v = 1$、$c = 3$、$t = 3 = c$ 整取（$\binom{3}{3} = 1$），贡献 $1^3$。ans $= 2$ ✓。

| 桶（频次） | 字符数 c | 取 t | 字符选择 | 方案贡献 |
|------------|----------|------|----------|----------|
| 2 | 1（c） | 1 | C(1,1)=1 | 2¹ |
| 1 | 2（a,b） | 1 | C(2,1)=2 | 1¹×2 |

## 4. 算法细节

1. **先判「不够 k 个不同字符」**：不同字符数 $< k$ 时无 k 子序列，返回 0（示例 3）；这一步必须在贪心之前。
2. **同频桶的边界判定**：只有「$t < c$」（名额在桶中间用尽）才乘 $\binom{c}{t}$；$t = c$ 时桶被整取，$\binom{c}{c} = 1$ 可省略。若 $k$ 恰好落在桶边界，公式自动退化，无需特判。
3. **幂与组合的取模**：$v^t$ 用快速幂（$t \le 26$ 很小，直接循环乘也行，但仍按 mod 乘法写）；$\binom{c}{t}$ 的 $c \le 26$、$t \le c$，用精确整数计算 $\prod_{i=1}^{t} \frac{c - t + i}{i}$ 即可（先乘后除保证整除），也可预处理 26 以内的杨辉三角。注意 $\binom{c}{t}$ 本身 $< 10^9$，取模前后都安全。
4. **「字符集合选择」与「下标选择」的乘法结构**：一个 k 子序列 = 「选 k 个互异字符的集合」×「每字符选一个出现下标」。前者由桶组合数 $\binom{c}{t}$ 与整桶选取决定，后者每字符恰 $f(c)$ 种、且**相互独立**，乘法原理得 $\prod f(c)$。两层相乘即总方案数，全程 mod $10^9 + 7$。
5. **频次桶的遍历**：26 个字母频次统计 $O(n + 26)$，按频次降序排序 $O(26 \log 26)$；或者直接开「频次 → 该频次字符数」的桶（频次 $\le n$），从高往低扫——两种实现等价，前者代码更短。
6. **为什么整取的高频桶不产生其他最大值方案**：更高的桶若不整取（少选一个），省出的名额只能给更低频的字符，总和严格变小（见 §5 引理 2），故不构成竞争方案。

## 5. 正确性证明

**引理 1（子序列计数的分解）**：k 子序列与「（k 元互异字符集合 $C$，为每个 $c \in C$ 指定一个出现下标）」一一对应。

**证明**：k 子序列的 $k$ 个位置两两字符互异，取其字符集合 $C$ 与每位置的下标即得右侧对象；反之给定 $C$ 与下标指定，按 $s$ 中下标升序取出即得唯一 k 子序列（子序列保序）。两个方向的构造互逆。∎

**推论**：固定字符集合 $C$ 的 k 子序列数目为 $\prod_{c \in C} f(c)$（各字符下标选择独立，乘法原理），其美丽值为 $\sum_{c \in C} f(c)$。

**引理 2（最大美丽值的贪心结构）**：设不同字符的频次降序为 $v_1 \ge v_2 \ge \dots \ge v_D$。字符集合 $C$（$|C| = k$）的美丽值最大当且仅当 $C$ 恰由「前若干个整频次桶 + 边界桶中任取若干」构成：即存在 $0 \le t \le c$（$c$ 为某桶的字符数），$C$ 包含所有频次大于该桶的全部字符、该桶中恰 $t$ 个字符，且不再含更低频字符。

**证明**：（充分方向的和值）设边界桶频次为 $v$：高于 $v$ 的全取、$v$ 桶取 $t$、低于 $v$ 的不取，共 $k$ 个字符（桶边界恰使总数为 $k$）。其和为 $\sum_{u > v} u \cdot c_u + v t$。（必要性 / 最优性）对任意 $k$ 元字符集 $C'$，记 $S(C') = \sum f$。经典交换论证：若 $C'$ 不含某个频次大于 $v$ 的字符 $w$ 却含某个频次小于 $v$ 的字符 $x$（或同桶内少取一个、桶外低频多取一个），用 $w$ 换 $x$ 得 $S$ 不减（严格大于当 $f(w) > f(x)$）。反复交换可把任意 $C'$ 变成上述「整取 + 边界桶」形态且 $S$ 不减；反之，该形态的任何 $C'$ 都可对称交换回贪心形态且 $S$ 不增。于是 $\max S = $ 贪心形态之和，且达到最大值的集合恰为全部贪心形态集合——具体地：最大值集合 $=$ 「高桶整取 + $v$ 桶任取 $t$ 个」的全部 $\binom{c}{t}$ 种选择（若 $t = c$ 或 $t = 0$ 则边界桶唯一确定，$\binom{c}{0} = \binom{c}{c} = 1$）。∎

**引理 3（同桶计数的均匀性）**：边界桶内任意 $t$ 个字符的选取，其 $\prod f$ 均等于 $v^t$。

**证明**：同桶字符频次全为 $v$，$t$ 个字符的乘积为 $v^t$，与具体选了哪些字符无关。∎

**定理**：美丽值最大的 k 子序列数目为 $\binom{c}{t} \cdot v^t \cdot \prod_{\text{高频桶 } i} v_i^{c_i} \pmod{10^9 + 7}$。

**证明**：由引理 2，达到最大美丽值的字符集合恰为「高频桶整取 + 边界桶 $\binom{c}{t}$ 种选择」。由引理 1 推论，每个字符集合 $C$ 贡献 $\prod_{c \in C} f(c)$ 个子序列。由引理 3 与乘法原理，总方案数为 $\binom{c}{t} \times \left(\prod_{\text{高频桶}} v_i^{c_i}\right) \times v^t$，各因子独立相乘后取模即得。∎

## 6. 复杂度分析

- **时间**：$O(n + |\Sigma| \log |\Sigma|)$。频次统计 $O(n)$；排序 26 个频次 $O(26 \log 26)$；桶遍历与快速幂合计 $O(|\Sigma| \log k)$（每桶一次 $\binom{c}{t}$ 精确计算 $O(t)$、快速幂 $O(\log t)$，桶数 $\le$ 不同频次数 $\le 26$）。总计以 $O(n)$ 为主导。
- **空间**：$O(|\Sigma|) = O(26)$，仅频次数组与桶列表。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int countKSubsequencesWithMaxBeauty(string s, int k) {
        long long f[26] = {0};
        for (char c : s) ++f[c - 'a'];
        vector<long long> freq;
        for (int i = 0; i < 26; ++i)
            if (f[i] > 0) freq.push_back(f[i]);
        sort(freq.begin(), freq.end(), greater<long long>());
        if ((long long)freq.size() < k) return 0;          // 不同字符不够 k 个
        long long ans = 1;
        size_t i = 0;
        while (k > 0) {
            long long v = freq[i];
            size_t j = i;
            while (j < freq.size() && freq[j] == v) ++j;
            long long c = (long long)(j - i);              // 频次恰好为 v 的字符个数
            long long take = min((long long)k, c);
            ans = ans * powmod(v, take) % MOD;
            if (take < c) ans = ans * comb(c, take) % MOD; // 边界频次上选 take 个
            k -= (int)take;
            i = j;
        }
        return (int)ans;
    }
private:
    static constexpr long long MOD = 1000000007LL;
    static long long powmod(long long b, long long e) {
        long long r = 1; b %= MOD;
        while (e > 0) {
            if (e & 1) r = r * b % MOD;
            b = b * b % MOD;
            e >>= 1;
        }
        return r;
    }
    static long long comb(long long n, long long r) {      // n,r <= 26，精确整数
        long long res = 1;
        for (long long t = 1; t <= r; ++t) res = res * (n - r + t) / t;
        return res;
    }
};
```

### Python

```python
from math import comb

class Solution:
    def countKSubsequencesWithMaxBeauty(self, s: str, k: int) -> int:
        MOD = 10 ** 9 + 7
        freq = sorted(Counter(s).values(), reverse=True)
        if len(freq) < k:
            return 0
        ans = 1
        i = 0
        while k > 0:
            v = freq[i]
            j = i
            while j < len(freq) and freq[j] == v:
                j += 1
            c = j - i                       # 频次恰好为 v 的字符个数
            take = min(k, c)
            ans = ans * pow(v, take, MOD) % MOD
            if take < c:                    # 边界频次上还需选一部分
                ans = ans * comb(c, take) % MOD
            k -= take
            i = j
        return ans
```

（`Counter` 来自 `collections`，LeetCode 环境已预导入；`math.comb` 是 Python 3.8+ 的精确组合数，$c \le 26$ 无溢出之虞。）

> 💡 两份代码均通过官方示例（`4`、`2`）与「不同字符不足 k」「单字符全同」等定向用例，并与「枚举全部 $\binom{n}{k}$ 位置组合、逐个算美丽值」的暴力做了 4 万组（C++）/ 6 千组（Python）随机对拍（$n \le 12$、小字母表密集碰撞），另验证 $n = 2\times10^5$、$k = 13$ 的性能用例，失配数为 0。

## 8. 边界情况与易错点

1. **不同字符数 $< k$**：直接返回 0（示例 3 的 `"aa", k=2`）；这步漏了会在后续「桶耗尽名额未满」处数组越界或错误相乘。
2. **边界桶的组合数**：只有 $t < c$（名额在桶中间用尽）才乘 $\binom{c}{t}$；写成「每桶都乘 $\binom{c}{t}$」会在整取桶上多乘 $\binom{c}{c} = 1$（碰巧无害），但在 $t = 0$ 的低频桶上多乘 $\binom{c}{0} = 1$ 也无害——真正危险的是把 $t$ 算成 $c$ 之外的值。
3. **「下标不同即不同子序列」**：计数的对象是下标组合而非字符串——`"bcca"` 的两个 `c` 给出 2 倍方案（示例 1 的 4 = 2 × 2）；若误按「字符串去重」计数会得 2。
4. **组合数取模的陷阱**：$\binom{c}{t}$ 中 $c \le 26$，先算精确值再取模最稳；若推广到大 $c$ 需要阶乘逆元（费马小定理）。本题规模下不必上逆元，但别对「先取模再除」的错误写法妥协——除法不保同余。
5. **快速幂的底数**：$v \le n \le 2\times10^5 < 10^9+7$，`b %= MOD` 是防御性写法；指数 $t \le 26$ 很小。
6. **空桶 / $k = 0$ 循环**：`while k > 0` 的终止由「桶总字符数 $\ge k$」（第 1 点的前置检查）保证；若漏判，最后一桶取尽后 `i` 越界。
7. **频次为 0 的字母**：不进入 `freq`（`f[i] > 0` 过滤），它们不参与任何 k 子序列；若误把 0 频次放进排序数组，「$v^0 = 1$」会让答案虚增。
