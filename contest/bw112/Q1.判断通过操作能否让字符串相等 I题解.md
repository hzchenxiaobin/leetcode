# LeetCode 判断通过操作能否让字符串相等 I 题解

## 1. 题目概述

- **标题 / 题号**：判断通过操作能否让字符串相等 I（#2839，easy）
- **链接**：https://leetcode.cn/problems/check-if-strings-can-be-made-equal-with-operations-i/
- **来源**：LeetCode 第 112 场双周赛 Q1
- **难度**：简单
- **标签**：字符串

**题意**：给定两个长度均为 $4$、只含小写字母的字符串 $s_1, s_2$。你可以对**任意一个**字符串执行**任意次**以下操作：选择下标 $i, j$ 满足 $j - i = 2$，交换这两个下标上的字符。若能让 $s_1$ 与 $s_2$ 相等，返回 `true`；否则返回 `false`。

**约束**：

- $s_1.length = s_2.length = 4$
- 两串只含小写英文字母

## 2. 示例

**示例 1**

```text
输入：s1 = "abcd", s2 = "cdab"
输出：true
解释：对 s1 操作：交换 (0,2) 得 "cbad"，再交换 (1,3) 得 "cdab" = s2。
```

**示例 2**

```text
输入：s1 = "abcd", s2 = "dacb"
输出：false
解释：无论如何交换都无法相等。
```

**示例 3（边界补充）**

```text
输入：s1 = "abcd", s2 = "badc"
输出：false
解释：交换只能在 {0,2} 内部与 {1,3} 内部进行，
     "badc" 需要把 a（下标 1）换到下标 0，跨奇偶交换做不到。
```

## 3. 解题思路

### 3.1 暴力思路

长度固定为 4，操作只有两个：`swap(0,2)` 与 `swap(1,3)`。每个操作执行偶数次等于不执行，因此对某个字符串总共只有 $2 \times 2 = 4$ 种可达状态（每个操作做 0 或 1 次），逐一与另一串比较即可——$O(1)$，是最直接的写法。但「枚举 4 种状态」依赖长度为 4 的小数据这一巧合；把结论提炼成「奇偶不变量」，解法就与长度无关，也直接迁移到 Q2（长度 $10^5$ 版本）。

### 3.2 核心观察：交换不改变「下标奇偶」，字符被锁在两个轨道里

![核心观察：交换只发生在同奇偶下标之间，两条独立轨道](images/bw112_q1_parity_tracks.svg)

操作要求 $j - i = 2$，即 $i$ 与 $j$ **奇偶性相同**：偶下标只能与偶下标换，奇下标只能与奇下标换。于是字符永远待在自己「初始下标的奇偶类」里：

- **偶轨道**：下标 $\{0, 2\}$（长度 4 时恰两个位置），轨道内字符可以任意重排（两个位置交换或不换，两种排列都能达到）；
- **奇轨道**：下标 $\{1, 3\}$，同理。

因此 $s_1$ 能变成 $s_2$（或反过来，操作对两串对称）当且仅当：**两串的偶下标字符多重集相等，且奇下标字符多重集相等**。长度 4 时就是比较 $\{s_1[0], s_1[2]\}$ 与 $\{s_2[0], s_2[2]\}$、$\{s_1[1], s_1[3]\}$ 与 $\{s_2[1], s_2[3]\}$——各自排序后逐个比较即可。

### 3.3 算法流程

```text
1. 取 a = s1[0::2] 与 b = s2[0::2]（偶下标轨道）
2. 取 c = s1[1::2] 与 d = s2[1::2]（奇下标轨道）
3. 返回 (sorted(a) == sorted(b)) 且 (sorted(c) == sorted(d))
```

### 3.4 示例演算

![示例演算：暴力 4 种可达状态与轨道判定的对照](images/bw112_q1_walkthrough.svg)

以示例 1 `s1 = "abcd"`、`s2 = "cdab"` 为例：偶轨道 $s_1$ 取 $\{a, c\}$、$s_2$ 取 $\{c, a\}$，排序后都是 `ac` ✓；奇轨道 $s_1$ 取 $\{b, d\}$、$s_2$ 取 $\{d, b\}$，排序后都是 `bd` ✓。两条轨道都匹配，返回 `true`。

以示例 2 `s1 = "abcd"`、`s2 = "dacb"` 为例：偶轨道 $s_1$ 为 $\{a,c\}$、$s_2$ 为 $\{d,c\}$，`ac ≠ dc`，返回 `false`。

| 串 | 偶轨道 {0,2} | 奇轨道 {1,3} |
|----|--------------|--------------|
| "abcd" | {a, c} | {b, d} |
| "cdab" | {c, a} → ac | {d, b} → bd |
| "dacb" | {d, c} → dc | {a, b} → ab |

第一行 vs 第二行：两轨道都相等 → `true`；第一行 vs 第三行：偶轨道 `ac ≠ dc` → `false`。

## 4. 算法细节

1. **双向性**：操作可施加于 $s_1$ 或 $s_2$ 任一串，但「轨道内多重集相等」是对称条件（$s_1$ 的轨道多重集 $= s_2$ 的轨道多重集），无需关心到底操作谁。
2. **长度 4 的简化**：偶轨道 $\{0,2\}$ 与奇轨道 $\{1,3\}$ 各只有 2 个字符，排序比较退化为「$(s_1[0] = s_2[0] \wedge s_1[2] = s_2[2]) \vee (s_1[0] = s_2[2] \wedge s_1[2] = s_2[0])$」；用 `sorted` 写法更短且天然推广到 Q2。
3. **多重集而非集合**：轨道内比较的是**带重数的字符集合**（排序后逐位比），不能用 `set` 去重——`"aab"` 类重复必须区分（长度 4 场景两位置若相同，set 会把信息抹掉）。
4. **「任意次」的语义**：虽然操作可执行任意多次，但两条轨道内两两交换生成的群就是轨道内的全体排列（长度 4 时轨道大小 2，群恰为 $\{id, swap\}$），「任意次」并不带来新可达状态。
5. **复杂度**：$O(1)$（长度固定 4）；推广到长度 $n$ 则排序为 $O(n \log n)$、计数为 $O(n)$。

## 5. 正确性证明

**引理 1（奇偶不变量）**：任何操作序列保持每个字符所处下标的奇偶性不变。

**证明**：操作只交换下标 $i$ 与 $i+2$，两者奇偶性相同，被交换的两个字符各自仍处于同奇偶的下标上。归纳于操作次数：初始命题平凡成立；每步操作保持命题。∎

**引理 2（轨道内可达全排列）**：设轨道（同奇偶下标集合）大小为 $t$。长度 4 时 $t = 2$，轨道内可以恰好达到两种排列：恒等与对换；即轨道内字符的任意重排（大小 2 的全体排列）都可达。

**证明**：$t = 2$ 时轨道 $\{p, p+2\}$ 上的操作要么不执行（恒等）、要么执行奇数次（对换，因为两次对换复合为恒等），两种排列穷尽了 $2! = 2$ 种全部排列。∎

**定理**：$s_1$ 可经有限次操作变为 $s_2$ $\iff$ 两串偶轨道字符多重集相等且奇轨道字符多重集相等。

**证明**：（⇒）由引理 1，$s_1$ 偶轨道上的字符始终待在偶轨道，若最终 $s_1 = s_2$，则 $s_2$ 偶轨道上的字符恰是 $s_1$ 偶轨道字符的一个排列，多重集相等；奇轨道同理。（⇐）两轨道多重集相等意味着存在轨道内排列 $\pi_e, \pi_o$ 把 $s_1$ 的偶、奇轨道分别变成 $s_2$ 的对应轨道（多重集相等 ⇔ 存在双射）。由引理 2，长度 4 时轨道内任何排列可达，故把 $\pi_e, \pi_o$ 对应的操作依次执行（轨道互不相交，操作可任意交错）后 $s_1 = s_2$。∎

## 6. 复杂度分析

- **时间**：$O(1)$。长度固定为 4，排序两个长度 2 的片段、两次字符串比较均为常数操作。
- **空间**：$O(1)$。常数个临时字符串片段。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool canBeEqual(string s1, string s2) {
        for (int p = 0; p < 2; ++p) {              // p=0 看偶下标 {0,2}，p=1 看奇下标 {1,3}
            char a[2] = {s1[p], s1[p + 2]};
            char b[2] = {s2[p], s2[p + 2]};
            sort(a, a + 2);
            sort(b, b + 2);
            if (a[0] != b[0] || a[1] != b[1]) return false;
        }
        return true;
    }
};
```

### Python

```python
class Solution:
    def canBeEqual(self, s1: str, s2: str) -> bool:
        return sorted(s1[0::2]) == sorted(s2[0::2]) and \
               sorted(s1[1::2]) == sorted(s2[1::2])
```

> 💡 两份代码均通过官方示例（`true`、`false`）与「两串相同 / 仅差一次 swap(0,2) / 仅差一次 swap(1,3) / 跨轨道错位」四个定向用例，并与「枚举 swap(0,2)×swap(1,3) 全部 4 种组合」的暴力做了 30 万组（C++）/ 5 万组（Python）随机对拍（字母表 26 全覆盖），失配数为 0。

## 8. 边界情况与易错点

1. **跨轨道不可换**：`j - i = 2` 限定同奇偶；`"abcd"` vs `"badc"` 需要 a 从下标 1 挪到下标 0（跨奇偶），返回 `false`——这是最容易误判为 `true` 的反例。
2. **多重集比较而非集合**：用 `set` 会丢失重复信息，长度 4 时两轨道各 2 个字符，若两字符相同 `set` 大小变 1，比较侥幸不炸；但推广到 Q2（长轨道、多重复）必错，从 Q1 就养成 `sorted`/计数的习惯。
3. **操作对象可以是任一串**：不要只对 $s_1$ 枚举操作；好在判定条件对称，比较两条轨道的多重集已涵盖双向。
4. **「任意次」不扩大可达集**：轨道大小 2 时交换两次复原，枚举 0/1 次已完备；不必担心「多次组合出奇迹」。
5. **长度恰为 4**：下标 $p, p+2$ 最大取到 3，不会越界；若题目改长度 5+，$p + 2$ 需上界判断（推广写法用切片 $s[0::2]$、$s[1::2]$ 更稳）。

**延伸思考**：本题的本质是**群作用下的不变量判定**——操作生成位置集合上的一个置换群（这里由对换 $(0\ 2)$、$(1\ 3)$ 生成的 $\mathbb{Z}_2 \times \mathbb{Z}_2$），两串等价当且仅当在群作用下同轨道；判定不变量（每条轨道的多重集）给出 $O(1)$ 检验。把操作换成「相邻交换」（生成全对称群 $S_n$）等价类就是多重集；换成「循环移位」等价类是最小表示；换成「翻转」则是回文等价类——竞赛里这类「操作不变量」题的通用套路：**先找操作保持什么不变，再证不变量相同时必可达**。
