# LeetCode 使数组按非递减顺序排列 题解

## 1. 题目概述

- **标题 / 题号**：使数组按非递减顺序排列（#2289，medium）
- **链接**：https://leetcode.cn/problems/steps-to-make-array-non-decreasing/
- **来源**：LeetCode 第 295 场周赛 Q3
- **难度**：中等
- **标签**：单调栈、栈、数组、动态规划、模拟

**题意**：给定下标从 **0** 开始的整数数组 `nums`。**一步操作**中，**同时**移除所有满足 $\text{nums}[i-1] > \text{nums}[i]$ 的 $\text{nums}[i]$（$0 < i < \text{nums.length}$），即把凡是"比左邻严格小"的元素一次性全删掉。重复执行，直到 `nums` 变为**非递减**数组，返回所需的操作**轮数**。

**约束**：

- $1 \le \text{nums.length} \le 10^5$
- $1 \le \text{nums}[i] \le 10^9$

> 💡 关键信号：每轮删除是**批量同时**进行的，所以"总轮数"不是"删除总个数"，而是由**最晚被删的那个元素**决定——这提示我们把问题从"逐轮模拟"改写为"逐元素求被删轮次"。

## 2. 示例

**示例 1**

```text
输入：nums = [5,3,4,4,7,3,6,11,8,5,11]
输出：3
解释：
- 步骤 1：[5,3,4,4,7,3,6,11,8,5,11] 删 3,3,8,5 → [5,4,4,7,6,11,11]
- 步骤 2：[5,4,4,7,6,11,11] 删 4,6 → [5,4,7,11,11]
- 步骤 3：[5,4,7,11,11] 删 4 → [5,7,11,11]
[5,7,11,11] 非递减，返回 3。
```

**示例 2**

```text
输入：nums = [4,5,7,7,13]
输出：0
解释：nums 已是非递减数组，返回 0。
```

**补充示例 3（最坏轮数）**

```text
输入：nums = [10,1,2,3,4,5]
输出：5
解释：每轮只删最右侧紧贴 10 的那一个：1→2→3→4→5，共 5 轮。
      6 个元素却要 5 轮——轮数可达 O(n)，这正是暴力模拟的卡点。
```

## 3. 解题思路

### 3.1 暴力思路：逐轮模拟删除

每轮扫一遍数组，标记所有满足 $\text{nums}[i-1] > \text{nums}[i]$ 的下标并一次性删除；若本轮一个都没删则停止。逻辑完全照搬题面，正确性显然，但**最坏 $O(n^2)$**：如补充示例 3 的 $[n,1,2,\dots,n-1]$ 阶梯数组，每轮只删一个、共 $n-1$ 轮 × 每轮 $O(n)$ 扫描 $\to 10^{10}$，必超时。

> ⚠️ 卡点不在"扫一遍贵"，而在"轮数本身可以是 $O(n)$"。只有把**每个元素第几轮被删**提前算出来，才能避开逐轮模拟。

### 3.2 核心观察：总轮数 = 每个元素被删轮次的最大值

![杀手—障碍模型与+1延迟](images/2289_monotonic_stack_concept.svg)

定义 $r[i]$ 为 $\text{nums}[i]$ **被删的轮次**，永不删则 $r[i]=0$。由于每轮删掉的恰是"$r$ 值等于该轮号"的那批元素，只要还有 $r[i] \ge k$ 的元素，第 $k$ 轮就还会删东西，故：

$$\text{答案} = \max_i\ r[i]$$

问题转化为：**如何不模拟就求出每个 $r[i]$？**

观察一个会被删的元素 $i$：删它的一定是**左侧某个值严格更大的存活元素**。设 $j^*(i)$ 为 $i$ 左侧**最近的**满足 $\text{nums}[j] > \text{nums}[i]$ 的下标（"**杀手**"），则 $j^*$ 与 $i$ 之间的元素全都 $\le \text{nums}[i]$，它们当不了杀手，是挡在 $j^*$ 面前的"**障碍**"——必须先被清空，$j^*$ 才能成为 $i$ 的左邻动手。于是：

$$r[i] = 1 + \max\Big(0,\ \max_{j^*(i) < k < i} r[k]\Big)$$

即**障碍中最晚被清的轮次 + 1**（"+1 延迟"）。若左侧没有更大的元素，$i$ 是迄今最大值，永不删，$r[i]=0$。

### 3.3 算法流程：单调栈 + 轮次 DP

![单调栈DP流程](images/2289_dp_flow.svg)

用**单调栈**（存下标，自底向顶值**严格递减**）一趟维护"杀手链"：处理 $i$ 时——

1. **弹出所有 $\text{nums}[\text{top}] \le \text{nums}[i]$ 的栈顶**：弹掉的都是值不大于 $\text{nums}[i]$ 的"障碍"，弹出时取 $\text{maxR} \leftarrow \max(\text{maxR},\ \text{dp}[\text{top}])$ 吸收其轮次信息；
2. **看栈是否非空**：非空则新栈顶就是离 $i$ 最近、值严格更大的存活者（杀手），$\text{dp}[i] = \text{maxR} + 1$；空则 $i$ 是迄今最大值，$\text{dp}[i] = 0$（此时 $\text{maxR}$ 直接丢弃）；
3. **$i$ 入栈**，成为后续元素的左边界候选；$\text{ans} \leftarrow \max(\text{ans},\ \text{dp}[i])$。

> ⚠️ 弹栈条件是 $\le$ 而非 $<$：删除条件是**严格** $\text{nums}[i-1] > \text{nums}[i]$，等值元素当不了杀手，属于障碍，同样要弹出并吸收其 $r$。写成 $<$ 会让等值障碍滞留栈中被误当杀手，答案偏小。

## 4. 算法细节

1. **栈存下标而非值**：弹出时要读 $\text{dp}[\text{top}]$，只存值就拿不到轮次信息；用 `vector<int>` 当栈，`back()`/`pop_back()`/`push_back()` 即可。
2. **maxR 的"信息折叠"**：一个元素被弹出后，它的 $r$ 信息折叠进弹出它的元素的 $r$ 里（$r \ge 1 + r_{\text{被弹}}$）。于是"$(j^*, i)$ 内所有元素的 $r$ 最大值"不需要真的枚举区间——处理 $i$ 时被弹出的那批元素的 $\text{dp}$ 取 max 就是它（正确性见 §5 引理 2）。
3. **栈空时丢弃 maxR**：栈空说明 $\text{nums}[i]$ 是迄今最大值，永不删；它将永存并屏蔽左侧一切——右侧元素的杀手只能是它或更右侧者，与左侧已删障碍的历史轮次无关，故 maxR 可安全丢弃，$\text{dp}[i]=0$。
4. **dp 数组可省**：若只求答案，$\text{dp}[i]$ 只在元素入栈后被读一次，可用 `pair<值, r>` 存进栈里省掉数组；但保留 dp 数组更贴近思路，也便于调试。
5. **数据范围**：值 $\le 10^9$、$n \le 10^5$，全程只做比较与加减，`int` 足够，无需 `long long`；轮次最大 $n-1 < 10^5$ 同样不溢出。

## 5. 正确性证明

**引理 1（左邻即最近存活者）**：任一轮开始时，存活元素保持原有相对顺序；元素 $i$ 在该轮的左邻恰为 $i$ 左侧最近的、仍存活的元素。

**证明**：每轮删除只移除元素、不重排；某轮初 $i$ 的左邻即删除后与之紧邻者，亦即左侧最近存活者。∎

**定理 1（轮次公式）**：对每个 $i$，恰下列之一成立：

- (a) 不存在 $j < i$ 使 $\text{nums}[j] > \text{nums}[i]$（$i$ 是含等值的前缀最大值），此时 $r[i] = 0$；
- (b) 存在这样的 $j$，取 $j^*$ 为其中**下标最大**者，则 $r[i] = 1 + \max\big(0,\ \max_{j^* < k < i} r[k]\big)$。

**证明**：对 $i$ 强归纳，设一切 $k < i$ 已按 (a)/(b) 定准 $r[k]$。

(a)：由引理 1，任一轮初 $i$ 的左邻是某个左侧存活元素，值 $\le \text{nums}[i]$，严格大于永不成立，故 $r[i] = 0$。

(b)：先看 $(j^*, i)$ 内的 $k$：由 $j^*$ 的最大性，$\text{nums}[k] \le \text{nums}[i] < \text{nums}[j^*]$，故 $k$ 左侧存在更大者，由归纳假设 $k$ 属 (b) 类，$r[k] \ge 1$。记 $M = \max(0, \max_{j^* < k < i} r[k])$，$t = M + 1$。

**前 $t-1$ 轮 $i$ 不被删**（区间为空时 $M=0$、$t=1$，无需论证）：取达到 $r[k_0] = M$ 的 $k_0 \in (j^*, i)$，对任意 $s' \le t-1 = M$，第 $s'$ 轮初 $k_0$ 尚存活（$r[k_0] = M \ge s'$），故 $i$ 的左邻落在 $(j^*, i)$ 内、其值 $\le \text{nums}[i]$，不删。

**第 $t$ 轮 $i$ 被删**：$(j^*, i)$ 内元素 $r \le M = t-1$，第 $t$ 轮初全部消失。设此时 $i$ 的左邻为 $j'$（$j' \le j^*$，引理 1）。断言 $\text{nums}[j'] > \text{nums}[i]$，反设 $\text{nums}[j'] \le \text{nums}[i]$：因 $\text{nums}[j^*] > \text{nums}[i]$，$j' \ne j^*$，故 $j' < j^*$ 且 $j'$ 存活至第 $t$ 轮。而 $j^*$ 不能存活至第 $t$ 轮（否则 $i$ 的最近存活左邻是更近的 $j^*$），设 $j^*$ 死于第 $s_1 \le t-1$ 轮；由引理 1，第 $s_1$ 轮初 $j^*$ 的左邻 $m_1$ 满足 $\text{nums}[m_1] > \text{nums}[j^*] > \text{nums}[i]$，且 $j' \le m_1 < j^*$（$j'$ 该轮存活）。若 $m_1 = j'$ 已得 $\text{nums}[j'] > \text{nums}[i]$，矛盾；否则 $m_1$ 亦不能存活至第 $t$ 轮（否则最近存活左邻是 $m_1$ 而非 $j'$），设死于第 $s_2$ 轮，其左邻 $m_2$ 同理满足 $\text{nums}[m_2] > \text{nums}[m_1] > \text{nums}[i]$、$j' \le m_2 < m_1$。如此得严格下降链 $j^* > m_1 > m_2 > \cdots \ge j'$，链上每个元素值都 $> \text{nums}[i]$；下标有下界，链必终止于 $j'$，得 $\text{nums}[j'] > \text{nums}[i]$，与反设矛盾。故断言成立，第 $t$ 轮初 $i$ 的左邻值严格更大，$i$ 被删。

两相结合 $r[i] = t$。∎

**引理 2（栈的刻画与信息折叠）**：处理 $i$ 之前，元素 $m$ 在栈中当且仅当 $\text{nums}[m] > \max(\text{nums}[m{+}1..i{-}1])$（$m$ 是扫描前缀的后缀最大值），且栈中 $\text{dp}[m] = r[m]$。从而若 $j^*(i)$ 存在则弹空 $\le \text{nums}[i]$ 者后栈顶恰为 $j^*(i)$，且 $\text{maxR} = \max(0, \max_{j^* < k < i} r[k])$。

**证明**：对处理顺序归纳。$m$ 在处理 $m' > m$ 时被弹出当且仅当 $\text{nums}[m] \le \text{nums}[m']$，故"$m$ 在栈中（处理 $i$ 前）" $\iff$ 一切 $m < m' < i$ 有 $\text{nums}[m'] < \text{nums}[m]$，即后缀最大值刻画；栈中下标自底向顶递增、值严格递减、$\text{dp}=r$ 由定理 2 的归纳保证。

**弹出的元素都属 $(j^*, i)$ 且计入真实轮次**：设 $k$ 被弹出，则 $\text{nums}[k] \le \text{nums}[i]$。反设 $k < j^*$：由栈刻画，一切 $k < m' < i$ 有 $\text{nums}[m'] < \text{nums}[k]$，取 $m' = j^*$ 得 $\text{nums}[j^*] < \text{nums}[k] \le \text{nums}[i]$，与 $\text{nums}[j^*] > \text{nums}[i]$ 矛盾。故 $k \in (j^*, i)$，计入的 $\text{dp}[k] = r[k]$ 均为 $(j^*, i)$ 内真实轮次。

**弹后栈顶恰为 $j^*$（若存在）**：$j^*$ 不会被中途弹出——能弹出 $j^*$ 的处理轮次 $i''$ 必有 $i'' > j^*$，而处理 $i$ 之前的 $i'' \in (j^*, i)$ 满足 $\text{nums}[i''] \le \text{nums}[i] < \text{nums}[j^*]$，弹不动 $j^*$；故 $j^*$ 一直在栈中。$(j^*, i)$ 内的栈中元素均 $\le \text{nums}[i]$、全部弹出，弹后栈顶即 $j^*$。

**maxR 覆盖全部**：对 $(j^*, i)$ 内任一 $k$：若处理 $i$ 时 $k$ 仍在栈中，则因 $\text{nums}[k] \le \text{nums}[i]$ 被弹出，$r[k]$ 计入 maxR；若 $k$ 已在处理某 $i' \in (k, i)$ 时被弹出，则 $i' \in (j^*, i)$（因 $j^* < k < i' < i$），且弹出 $k$ 时栈中至少还有 $j^*$（由上段，$\text{nums}[i'] \le \text{nums}[i] < \text{nums}[j^*]$ 弹不动 $j^*$），故栈非空、$\text{dp}[i'] = \text{maxR}' + 1 \ge r[k] + 1 > r[k]$。若 $i'$ 仍在栈中则其 $r[i']$ 计入 maxR 而覆盖 $r[k]$；否则对 $i'$ 递归——下标严格递增的折叠链终结于本次被弹出者，每个 $r[k]$ 均被覆盖，不重不漏。∎

**定理 2（算法正确性）**：算法维护的 $\text{dp}[i]$ 恒等于真实轮次 $r[i]$，返回值 $\max_i \text{dp}[i]$ 即为所求操作数。

**证明**：对 $i$ 归纳。处理 $i$ 时弹出全部 $\text{nums}[\text{top}] \le \text{nums}[i]$ 者：若此后栈非空，由引理 2，栈顶即 $j^*(i)$ 且 $\text{maxR} = \max(0, \max_{j^* < k < i} r[k])$，由定理 1 (b) 得 $\text{dp}[i] = \text{maxR} + 1 = r[i]$；若栈空，由引理 2 的栈刻画，左侧不存在任何"后缀最大值"，特别地不存在 $j < i$ 使 $\text{nums}[j] > \text{nums}[i]$（若存在则 $j^*(i)$ 是后缀最大值、应在栈中），由定理 1 (a) 得 $\text{dp}[i] = 0 = r[i]$。最后，第 $k$ 轮删掉的恰是 $r$ 值等于 $k$ 的批次，且只要存在 $r[i] \ge k$ 的元素第 $k$ 轮就非空，故操作数 $= \max_i r[i] = \max_i \text{dp}[i]$，即返回值。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。每个下标至多**入栈一次、出栈一次**，`while` 弹栈的总执行次数不超过 $n$，加上外层 $n$ 次循环，均摊每次 $O(1)$；$n \le 10^5$ 轻松通过。
- **空间复杂度**：$O(n)$。单调栈与 dp 数组各 $O(n)$；最坏情形（严格递减输入如 $[n, n-1, \dots, 1]$）栈存满 $n$ 个元素。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int totalSteps(vector<int>& nums) {
        int n = nums.size(), ans = 0;
        vector<int> dp(n, 0);      // dp[i] = nums[i] 被删的轮次，0 表示永不删
        vector<int> st;            // 单调栈：存下标，自底向顶值严格递减
        for (int i = 0; i < n; ++i) {
            int maxR = 0;
            while (!st.empty() && nums[st.back()] <= nums[i]) {
                maxR = max(maxR, dp[st.back()]);   // 吸收障碍的轮次
                st.pop_back();
            }
            dp[i] = st.empty() ? 0 : maxR + 1;     // 栈顶残留者 = 杀手
            ans = max(ans, dp[i]);
            st.push_back(i);
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def totalSteps(self, nums: List[int]) -> int:
        n = len(nums)
        dp = [0] * n              # dp[i] = nums[i] 被删的轮次
        st: list[int] = []        # 单调栈：存下标，自底向顶值严格递减
        ans = 0
        for i in range(n):
            max_r = 0
            while st and nums[st[-1]] <= nums[i]:
                max_r = max(max_r, dp[st.pop()])   # 吸收障碍的轮次
            if st:                # 栈顶残留者 = 杀手
                dp[i] = max_r + 1
            ans = max(ans, dp[i])
            st.append(i)
        return ans
```

## 8. 边界情况与易错点

1. **弹栈条件写成 `<`**：等值元素当不了杀手（删除是严格 `>`），必须用 `<=` 弹出并吸收其 dp。示例 1 的 $i=3$（第二个 4）须弹出等值的 $4(2)$ 才得 $\text{maxR}=2$、$r[3]=3$；写成 `<` 会令等值障碍滞留栈中被误当杀手，$r[3]$ 只得 $1$，最终答案偏小，WA。
2. **栈空时误写 `dp[i] = maxR + 1`**：栈空说明 $i$ 是迄今最大值、永不删，必须 `dp[i] = 0` 且丢弃 maxR；否则会把已被屏蔽的左侧历史轮次错误计入。
3. **答案不是"删除元素个数"也不是"dp 之和"**：每轮**批量**删除，答案取 $\max$ 而非求和/计数。示例 1 删了 7 个元素但只有 3 轮。
4. **单元素 / 已有序数组**：$n=1$ 或整体非递减时不进 while、dp 全 0，返回 0，无需特判。
5. **最坏轮数用例**：$[n, 1, 2, \dots, n-1]$ 每轮删一个，共 $n-1$ 轮；单调栈做法依然 $O(n)$，但暴力模拟 $O(n^2)$ 超时——可作为对拍用例。
6. **严格递减数组空间**：$[10^5, \dots, 1]$ 使栈同时存 $10^5$ 个下标，属正常 $O(n)$ 空间，不要试图"优化"成常数栈。
7. **同轮"左邻"语义**：删除判定基于**本轮开始时**的快照，同轮被删的元素互不挤占（示例 1 第 1 轮的 8 删 5，虽然 8 自己也在该轮被删）——理解这点才能接受定理 1 中"$j^*$ 可与 $i$ 同轮死"的公式。

**延伸思考**：若把删除条件改为 $\text{nums}[i-1] \ge \text{nums}[i]$（等值也删），弹栈条件相应改为 $<$，且存活刻画变为"严格前缀最大值"，公式结构不变；若要求输出每轮删除的下标集合，按 $r$ 值分桶即可，复杂度仍 $O(n)$。另一个有趣的视角：把"谁删了我"连成父边，$r[i]$ 就是这棵森林中 $i$ 的深度，$\max r$ 即最大树高——本题等价于在单调栈扫描中在线维护这棵森林的高度。
