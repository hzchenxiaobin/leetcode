# LeetCode 三除数 题解

## 1. 题目概述

- **标题 / 题号**：三除数（#1952，easy）
- **链接**：https://leetcode.cn/problems/three-divisors/
- **来源**：LeetCode 第 252 场周赛 Q1
- **难度**：简单
- **标签**：数学、数论、质数判定、枚举

**题意**：给你一个正整数 $n$，判断 $n$ 是否**恰好有三个正除数**：是返回 `true`，否则返回 `false`。若存在整数 $k$ 满足 $n = k \times m$，则 $m$ 是 $n$ 的一个除数。

**约束**：

- $1 \le n \le 10^4$

> 💡 本题在本仓库另有[每日题解 1952](../../solution/1901-2000/1952_三除数.md)，两篇为姊妹篇：那边侧重「审题三关键」、三种 Python 写法对照、大 $n$ 的 Miller–Rabin 与 $d(n)$ 计数公式扩展、以及面试问答。本篇按周赛复盘视角，聚焦**签到题从题面到一步判定的最短路径**——「除数成对 ⟹ 奇数个必为完全平方 ⟹ 恰好 3 即质数平方」的两步观察、两道关卡的引理-定理化证明，以及 $n = 1$ 这个唯一致命 WA 点的复盘。两篇互为印证。

## 2. 示例

**示例 1**

```text
输入：n = 2
输出：false
解释：2 只有两个除数：1 和 2。
```

**示例 2**

```text
输入：n = 4
输出：true
解释：4 有三个除数：1、2 和 4。
```

**示例 3**（自造，覆盖两大陷阱）

```text

输出：false
解释：1 只有 1 个除数（1 自己），且 1 按定义不是质数。

输出：false
解释：16 是完全平方数（4²），但除数有 1、2、4、8、16 共 5 个——
      根 4 = 2×2 是合数，多出了第四、第五个除数。
```

## 3. 解题思路

### 3.1 赛场直觉：计数判定（暴力）

最稳的签到写法是直接把判定当计数做：枚举 $d = 1, \dots, n$，统计满足 $d \mid n$ 的个数，最后比较是否等于 $3$。一重循环 $O(n)$，$n \le 10^4$ 时一万次取模，必然 AC——**比赛追求提交速度时，这就是零风险保底路径**。

稍加优化：除数**成对出现**（$d$ 与 $n/d$），只需枚举到 $\sqrt{n}$，每命中一个 $d$ 计数加 2、单独处理 $d = n/d$ 的自配对，复杂度降为 $O(\sqrt{n}) \approx 100$ 次。

但两者都把「判定问题」当「计数问题」做——题目只问**是否等于 3**，而「恰好 3」这一约束本身蕴含极强的数论结构，可以一步到位：

### 3.2 核心观察：奇数个必为完全平方，恰好 3 即质数平方

![除数配对与质数平方判定概念图](images/wc252_q1_prime_square_concept.svg)

关键洞察分两步，分别对应「总数为奇」与「总数恰为 3」两层约束：

**第一步：除数成对 ⟹ 总数为奇 ⟺ $n$ 是完全平方数。** 对 $n$ 的每个除数 $d$，$n/d$ 也是除数，二者配成一对 $(d,\ n/d)$。配对只在 $d = n/d$ 即 $d^2 = n$ 时「自配对」合并为一个——此时 $d = \sqrt{n}$。因此除数总数 $=$ 成对数 $\times 2$ $+$（$0$ 或 $1$ 个自配对），**总数为奇 ⟺ 存在自配对 ⟺ $n$ 是完全平方数**，记 $n = k^2$。

**第二步：恰好 3 个 ⟺ $k$ 是质数。** $n = k^2$ 时，除数集合已包含 $\{1,\ k,\ k^2\}$（一对 $(1, k^2)$ + 自配对 $k$），恰好 3 个。若 $k$ 是**合数**，设 $k = a \cdot b$（$1 < a < k$），则 $a \mid k \mid k^2$ 且 $a \notin \{1, k, k^2\}$，是第四个除数，总数 $\ge 4$；反之 $k$ 是**质数**时，$k$ 只有 $1$ 与 $k$ 两个因子，$k^2$ 的除数**恰好**就是这三个。

$$\boxed{d(n) = 3 \;\Longleftrightarrow\; n = p^2 \text{，其中 } p \text{ 为质数}}$$

> 💡 **除数计数公式视角**：若 $n = p_1^{a_1} \cdots p_r^{a_r}$，则 $d(n) = (a_1+1)\cdots(a_r+1)$。令乘积等于 $3$（质数），只能是单一因子 $(a_1+1) = 3$，即 $r = 1,\ a_1 = 2$，故 $n = p^2$。这是配对论证的代数镜像，殊途同归。

> ⚠️ **$n = 1$ 是唯一的致命陷阱**：$1 = 1^2$ 是完全平方、能过第一关，但 $1$ 按定义**不是质数**（它只有 $1$ 个除数）。若不做 `k < 2` 特判，试除循环一次都不执行，会直接落到 `return true`——这是本题最经典的 WA。

### 3.3 算法流程：两道关卡

![两道关卡判定算法流程图](images/wc252_q1_algorithm_flow.svg)

整体是「两道关卡」串联判定：

1. **整数开方**：取 $k = \lfloor\sqrt{n}\rfloor$（Python `math.isqrt`，C++ `(int)sqrt(n)`）。
2. **第一关——完全平方**：若 $k^2 \ne n$，除数总数为偶数 $\ne 3$，立即 `return false`（淘汰 $n = 2$ 这类）。
3. **特判 $k < 2$**：$k = 1$（即 $n = 1$）非质数，`return false`。
4. **第二关——$k$ 是否质数**：对 $i$ 从 $2$ 试除到 $\lfloor\sqrt{k}\rfloor$，一旦 $k \bmod i = 0$ 则 $k$ 合数，`return false`（淘汰 $n = 16$ 这类「平方但根合数」）；全部不整除则通过。
5. **通过两关**：$n = p^2$（$p$ 质数），`return true`。

> 💡 两关各司其职：第一关筛掉非完全平方（除数偶数个），第二关筛掉「平方但根合数」（除数 $\ge 5$ 个）。$n \le 10^4$ 时 $k \le 100$、$\sqrt{k} \le 10$，试除至多 $9$ 次。

### 3.4 示例演算

![示例演算：六个 n 过两道关卡的走查表](images/wc252_q1_example_walkthrough.svg)

以六组 $n$ 走查两道关卡：

| $n$ | $k = \lfloor\sqrt{n}\rfloor$ | 第一关 $k^2 = n$? | 第二关 $k$ 质数? | 全部除数 | 个数 | 结果 |
|-----|------------------------------|------------------|------------------|----------|------|------|
| 4 | 2 | ✓ | ✓ 质数 | $\{1, 2, 4\}$ | 3 | `true` |
| 9 | 3 | ✓ | ✓ 质数 | $\{1, 3, 9\}$ | 3 | `true` |
| 25 | 5 | ✓ | ✓ 质数 | $\{1, 5, 25\}$ | 3 | `true` |
| 2 | 1 | ✗（$1 \ne 2$） | — | $\{1, 2\}$ | 2 | `false` |
| 16 | 4 | ✓ | ✗ $4 = 2\cdot 2$ | $\{1, 2, 4, 8, 16\}$ | 5 | `false` |
| 1 | 1 | ✓ | ✗ $1$ 非质数 | $\{1\}$ | 1 | `false` |

- **`true` 的 $n$**：$4, 9, 25$——均为质数平方（$2^2, 3^2, 5^2$），除数恰为 $\{1, p, p^2\}$ ✓
- **$n = 2$**：非完全平方，除数成对 $(1, 2)$ 共 2 个（偶数），第一关即淘汰 ✗
- **$n = 16$**：过第一关，但 $\sqrt{16} = 4$ 合数，多出 $2, 8$ 两个除数共 5 个，第二关淘汰 ✗
- **$n = 1$**：过第一关，但根为 $1$ 非质数，仅 1 个除数，靠 `k < 2` 特判拦截 ✗

## 4. 算法细节

1. **整数开方的稳健性**：Python `math.isqrt` 精确无误差；C++ `(int)sqrt(n)` 依赖浮点，理论上有 ±1 风险。本题 $n \le 10^4$ 在 `double` 精度下绝对安全，但工程习惯是取整后回验 $k^2$ 与 $(k \pm 1)^2$ 再微调（或直接整数二分开方）。
2. **`k < 2` 特判不可省**：$n = 1$ 时 $k = 1$，试除循环 `for (i = 2; i * i <= k; ...)` 条件 `4 <= 1` 不成立、一次都不执行，若无特判直接落到 `return true`。该特判同时覆盖 $k = 0$（$n = 0$，虽不在约束内但更稳健）。
3. **试除上界只需 $\lfloor\sqrt{k}\rfloor$**：若 $k$ 有大于 $\sqrt{k}$ 的因子，必配对出一个小于 $\sqrt{k}$ 的因子，从小的一侧枚举不重不漏。$k \le 100$ ⟹ $i$ 只取 $2 \dots 10$，至多 9 次取模。
4. **为什么不用「枚举到 $\sqrt n$ 数个数」**：$O(\sqrt n) = 100$ 与两关法 $O(n^{1/4})$ 在本题规模下同为瞬时，但后者揭示结构、可扩展性完全不同——$n$ 放宽到 $10^{12}$ 时 $\sqrt n = 10^6$ 次取模已经吃紧，而 $n^{1/4} = 10^3$ 依然轻松。
5. **返回 `true` 的值域很小**：$p^2 \le 10^4 \Rightarrow p \le 97$，即 $1 \dots 10^4$ 中只有 25 个 `true`（$4, 9, 25, \dots, 9409$）。若反复查询可预存 25 个值二分/哈希判定，单次查询则无此必要。

## 5. 正确性证明

**引理 1（配对与奇偶）**：$n$ 的正除数在配对 $\{d,\ n/d\}$ 下两两分组；除数个数为奇数，当且仅当 $n$ 是完全平方数。

**证明**：映射 $\sigma(d) = n/d$ 是除数集合到自身的**对合**（$\sigma(\sigma(d)) = d$）。其对合轨道大小为 2（$d \ne n/d$）或 1（$d = n/d \iff d^2 = n$）。于是除数总数 $= 2 \times (\text{二元轨道数}) + (\text{一元轨道数})$，其中一元轨道数只能是 $0$ 或 $1$。总数为奇 $\iff$ 一元轨道存在 $\iff$ 存在 $d$ 使 $d^2 = n \iff n$ 是完全平方数。∎

**引理 2（质数平方的除数集）**：若 $p$ 是质数，则 $p^2$ 的正除数**恰好**是 $\{1, p, p^2\}$；若 $k \ge 2$ 是合数，则 $k^2$ 至少有 4 个正除数。

**证明**：$p$ 质数时，设 $d \mid p^2$。由唯一分解定理，$d$ 的质因数只能取自 $\{p\}$ 且幂次 $\le 2$，故 $d \in \{1, p, p^2\}$；三者显然都整除 $p^2$ 且互异，故除数集恰为三者。$k$ 合数时，取 $k$ 的最小非平凡因子 $a$，写 $k = a \cdot b$ 且 $1 < a \le b$，由 $a \le b$ 得 $a^2 \le ab = k$，故 $a \le \sqrt{k} < k$；又合数 $k \ge 4$ 保证 $k < k^2$。于是 $1 < a < k < k^2$ 四数两两互异，且 $a \mid k \mid k^2$，故均为 $k^2$ 的除数，至少 4 个。∎

**定理**：$d(n) = 3 \iff n = p^2$ 且 $p$ 为质数。

**证明**：（⇐）由引理 2 前半，$d(p^2) = 3$。（⇒）$d(n) = 3$ 为奇数，由引理 1 存在 $k \ge 1$ 使 $n = k^2$。若 $k = 1$ 则 $n = 1$、$d(n) = 1 \ne 3$，矛盾，故 $k \ge 2$。此时 $1 < k < k^2$（$k \ge 2$）三者互异且均为 $n$ 的除数；$d(n) = 3$ 说明除数集**恰好**为 $\{1, k, k^2\}$。若 $k$ 是合数，由引理 2 后半 $d(k^2) \ge 4$，矛盾。故 $k$ 是质数。∎

**算法正确性**：第一关判 $k^2 \ne n$ 返回 `false`——由 $k = \lfloor\sqrt n\rfloor$ 满足 $k^2 \le n < (k+1)^2$，整数平方落在 $k^2$ 或 $(k+1)^2$ 处，故 $n$ 是完全平方 $\iff k^2 = n$，第一关恰好淘汰全部非完全平方（引理 1：除数偶数个 $\ne 3$）。过第一关后 $n = k^2$，`k < 2` 拦截 $k = 1$（$d = 1$）与 $k = 0$；第二关试除 $\lfloor\sqrt k\rfloor$ 内发现因子 $\iff k$ 是合数（因子成对，小的一侧必被枚举到），淘汰后剩下 $k \ge 2$ 且质数。结合定理，算法返回 `true` $\iff n = p^2$（$p$ 质数）$\iff d(n) = 3$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n^{1/4})$。整数开方 $O(1)$（固定机器字长；亦可视为 $O(\log n)$ 数值法）；第二关试除到 $\sqrt{k} = n^{1/4}$，$n = 10^4$ 时 $k \le 100$、至多 9 次取模。对照：暴力计数 $O(n) = 10^4$，成对计数 $O(\sqrt n) = 10^2$，本题规模下三者都瞬时——差距要到 $n = 10^{12}$（$10^6$ vs $10^3$）才真正显现。
- **空间复杂度**：$O(1)$。仅常数个变量 `k`、`i`。

## 7. 参考代码

### C++（两道关卡：判完全平方 + 试除判质数）

```cpp
class Solution {
public:
    bool isThree(int n) {
        int k = sqrt(n);
        if (k * k != n) return false;
        if (k < 2) return false;
        for (int i = 2; i * i <= k; ++i) {
            if (k % i == 0) return false;
        }
        return true;
    }
};
```

### Python（`math.isqrt` + 试除判质数）

```python
import math

class Solution:
    def isThree(self, n: int) -> bool:
        k = math.isqrt(n)
        if k * k != n or k < 2:
            return False
        return all(k % i for i in range(2, math.isqrt(k) + 1))
```

### Python（暴力计数：赛场零风险保底）

```python
class Solution:
    def isThree(self, n: int) -> bool:
        return sum(n % d == 0 for d in range(1, n + 1)) == 3
```

> 💡 **写法对照**：① 两关法把「恰好 3」的数学结构写成两道关卡，$O(n^{1/4})$，是值得沉淀的写法；② 暴力计数一行流 $O(n)$，在本题数据范围下同样 AC——**赛场上「思路不熟先保底」**，这两行就是签到的最短保险路径；③ `all(k % i ...)` 中 `k % i` 非 0 即真，配合短路求值即试除判质数。

## 8. 边界情况与易错点

1. **$n = 1$（唯一致命陷阱）**：$1 = 1^2$ 能过第一关；若没有 `k < 2` 特判，试除循环一次不执行、直接落到 `return true`。1 不是质数（只有 1 个除数），必须显式拦截。
2. **「见平方就 true」**：$n = 16$ 是完全平方，但根 $4 = 2 \times 2$ 是合数，除数共 5 个（$\{1,2,4,8,16\}$）。同理 $36 = 6^2$、$100 = 10^2$ 都要靠第二关淘汰——两道关卡缺一不可。
3. **「恰好」的边界**：质数 $n = 2, 3, 5, \dots$ 恰有 **2** 个除数，$n = 6$ 有 **4** 个，都返回 `false`。「质数」与「三个除数」只差一步平方。
4. **C++ 浮点开方**：`(int)sqrt(n)` 理论上可能因浮点误差差 1（本题 $n \le 10^4$ 安全）。稳健写法是回验并微调，或整数二分；Python `math.isqrt` 无此问题。
5. **$n = 0$ 不在约束内**（$n \ge 1$），但 `k < 2` 特判恰好顺带覆盖 $k = 0$ 的情形，代码天然稳健。
6. **别把判定做成计数**：题目只要 yes / no。找到充要条件 $n = p^2$（$p$ 质数）后连除数都不用枚举——「判定问题优先找充要条件」是数论签到题的通用套路。
