# LeetCode 收集足够苹果的最小花园周长 题解

## 1. 题目概述

- **标题 / 题号**：收集足够苹果的最小花园周长（#1954，medium）
- **链接**：https://leetcode.cn/problems/minimum-garden-perimeter-to-collect-enough-apples/
- **来源**：LeetCode 第 252 场周赛 Q3
- **难度**：中等
- **标签**：数学、二分查找

**题意**：无限二维网格上每个整数坐标 $(i, j)$ 处有一棵苹果树，树上有 $|i| + |j|$ 个苹果。要买一块以 $(0,0)$ 为中心、四边与坐标轴平行的**正方形**土地，使土地**内部及边缘上**的苹果总数**至少**为 $\text{neededApples}$，返回满足条件的最小**周长**。

**约束**：

- $1 \le \text{neededApples} \le 10^{15}$——量级决定答案 $n^\ast \approx (\text{neededApples}/4)^{1/3} \le 63\,000$，任何逐格点的做法都不可行，必须拿到苹果总数的闭式公式。

> 💡 本题在本仓库另有[每日题解 1954](../../solution/1901-2000/1954_收集足够苹果的最小花园周长.md)，两篇为姊妹篇：那边侧重可分性推导的分步讲解、面试五问与 875 / 1011 二分答案家族。本篇按周赛复盘视角，聚焦**从对称性到公式的两条推导路径**（可分性与环分解），并补上每日篇未展开的**整数归约**（为什么只考虑整数半边长、周长为何恒为 8 的倍数）与**完整的引理-定理证明**。

## 2. 示例

**示例 1**

```text
输入：neededApples = 1
输出：8
解释：边长为 2 的正方形（半边长 n = 1）包含 12 个苹果，周长 = 2 × 4 = 8。
```

**示例 2**

```text
输入：neededApples = 13
输出：16
解释：n = 1 时只有 12 个，差 1 个；n = 2 时有 60 个 ≥ 13，周长 = 16。
```

**示例 3**

```text
输入：neededApples = 1000000000
输出：5040
解释：A(629) = 997,807,860 < 10⁹；A(630) = 1,002,570,660 ≥ 10⁹，周长 = 8 × 630 = 5040。
```

## 3. 解题思路

### 3.1 暴力思路：逐格点累加

以 $(0,0)$ 为中心、半边长为 $n$ 的正方形覆盖格点集恰是 $\max(|i|,|j|) \le n$，共 $(2n+1)^2$ 个。最朴素的做法是从小到大枚举 $n$，对每个 $n$ 双重循环遍历全部格点累加 $|i|+|j|$，直到总和 $\ge \text{neededApples}$。

死穴在复杂度：$\text{neededApples}$ 可达 $10^{15}$，对应 $n^\ast \approx 6.3 \times 10^4$，总工作量

$$\sum_{k=1}^{n^\ast} (2k+1)^2 \approx \frac{4}{3}\,(n^\ast)^3 \approx 3 \times 10^{14}$$

次基本操作，**必然 TLE**。

> ⚠️ 暴力给出的真正启示：苹果数只差一个 $O(1)$ 的**闭式公式**。拿到公式后，线性枚举 $n$（约 $6.3\times10^4$ 步）都能过；再由单调性上二分，就是标准的 $O(\log)$ 解法。

### 3.2 核心观察：对称性给出闭式公式

![格点苹果分布：n=1 与 n=2 的正方形](images/wc252_q3_garden_grid_concept.svg)

正方形关于 $x$ 轴、$y$ 轴双双对称，而 $|i|+|j|$ 恰好也能拆成两个**独立**的一维求和——两条路径都直通同一个公式。

**路径一（可分性）**：把 $|i|+|j|$ 拆开，对 $|i|$ 而言 $j$ 只是「陪跑」，内层求和直接变成行数 $2n+1$：

$$A(n) = \sum_{i=-n}^{n}\sum_{j=-n}^{n} (|i|+|j|) = (2n+1)\sum_{i=-n}^{n}|i| + (2n+1)\sum_{j=-n}^{n}|j| = 2\,(2n+1)\cdot n(n+1)$$

**路径二（环分解）**：把正方形看成一圈圈「洋葱」——第 $k$ 环是 $\max(|i|,|j|) = k$ 的格点，其苹果总和**恰好是 $12k^2$**（引理 3 给出计算）。于是

$$A(n) = \sum_{k=1}^{n} 12k^2 = 12\cdot\frac{n(n+1)(2n+1)}{6} = 2n(n+1)(2n+1)$$

平方和公式在这里「几何现身」。

$$\boxed{A(n) = 2n(n+1)(2n+1) = 4n^3+6n^2+2n \approx 4n^3,\qquad \text{周长} = 8n}$$

**验证**：$A(1) = 12$ ✓（示例 1）、$A(2) = 60$ ✓、$A(630) = 1{,}002{,}570{,}660$ ✓（示例 3）。

![两条推导路径：可分性与环分解](images/wc252_q3_ring_separability_derivation.svg)

还有一个容易被忽略的观察：**只需考虑整数半边长**。设正方形半边长为实数 $r$，覆盖的格点集与半边长 $\lfloor r \rfloor$ 的正方形**完全相同**（引理 1），周长却更小。所以最优解必在整数 $n$ 处取到，周长恒为 8 的倍数，答案与 $n$ 一一对应。

### 3.3 算法流程：下界二分

![二分流程与演算走查](images/wc252_q3_binary_search_walkthrough.svg)

$A(n)$ 关于 $n$ **严格递增**（每环增量 $12k^2 > 0$），「找最小 $n$ 使 $A(n) \ge \text{neededApples}$」是标准的**下界二分**：

1. **定上界**：$A(n) \ge 4n^3$，令 $4n^3 \ge 10^{15}$ 得 $n^\ast \le 63\,000$，取 `hi = 10^5`（此时 $A(10^5) \approx 4\times10^{15}$，既覆盖全部输入，又远离 `long long` 上限）。
2. **二分**：`lo = 0`，`while lo < hi` 取 `mid`：若 $A(\text{mid}) \ge T$ 则 `hi = mid`（mid 可行，收缩），否则 `lo = mid + 1`（mid 太小，抬升）。
3. **返回**：循环结束时 `lo == hi == n*`，答案 $= 8 \times \text{lo}$。

### 3.4 示例演算

| $n$ | $A(n) = 2n(n+1)(2n+1)$ | 周长 $8n$ | 判定 |
|-----|------------------------|-----------|------|
| $0$ | $0$ | $0$ | 起点 |
| $1$ | $12$ | $8$ | $12 \ge 1$ ✓ → 示例 1 |
| $2$ | $60$ | $16$ | $60 \ge 13$ ✓ → 示例 2（$n=1$ 仅差 1 个苹果！） |
| $629$ | $997{,}807{,}860$ | $5032$ | $< 10^9$ ✗ |
| $630$ | $1{,}002{,}570{,}660$ | $5040$ | $\ge 10^9$ ✓ → 示例 3 |

示例 2 的考点正是「一步之差」：$13 - 12 = 1$，逼着你确认公式而不是拍脑袋估阶。

## 4. 算法细节

1. **推导的最短路径**：拆和 $\to$ 内层提因子 $2n+1$ $\to$ 两个同构求和 $\times 2$，三行得到 $A(n) = 2(2n+1)\,n(n+1)$。考场紧张时优先走这条；环分解 $12k^2$ 更漂亮，适合当第二条验证线。
2. **上界不是拍脑袋**：由 $A(n) \ge 4n^3$ 得 $n^\ast \le (10^{15}/4)^{1/3} \approx 63\,000$，`hi = 10^5` 留足余量。二分正确性要求 $A(\text{hi}) \ge T$ 必须成立。
3. **溢出边界**：C++ 全程 `long long`（函数签名就是 `long long`，官方提示）。$A(10^5) \approx 4.0 \times 10^{15}$、$A(10^6) \approx 4 \times 10^{18}$ 都安全；但若随手把 `hi` 设成 $10^7$，中途 $A(\text{mid}) \approx 4 \times 10^{21}$ 直接溢出——**上界放大反而引爆溢出**。
4. **二分模板**：`lo = 0, hi = 10^5`，循环不变量为「$n < lo$ 均不可行，$n \ge hi$ 均可行」，`lo + (hi - lo) / 2` 防溢出写法顺手养成。
5. **替代解法对照**：① 公式 + 线性枚举：$O(n^\ast) \approx 6.3\times 10^4$ 步，能过但不如二分优雅；② 浮点立方根 $k_0 = \lceil (T/4)^{1/3} \rceil$ 再微调：$O(1)$ 但有精度风险（$T$ 到 $10^{15}$ 时 `pow` 误差可致偏差 1），赛场不划算。**二分是精度与速度的双保险**。
6. **「内部或边缘」都是闭区域**：覆盖条件就是 $\max(|i|,|j|) \le n$，不需要任何 $\pm 1$ 修补。

## 5. 正确性证明

以下设 $T = \text{neededApples} \ge 1$，$A(n)$ 为半边长 $n$（非负整数）的正方形内苹果总数。

**引理 1（整数归约）**：半边长为实数 $r \ge 0$ 的正方形，其覆盖的格点集与半边长 $\lfloor r \rfloor$ 的正方形完全相同。

**证明**：格点 $(i,j)$ 被覆盖当且仅当 $\max(|i|,|j|) \le r$。$\max(|i|,|j|)$ 是整数，而整数 $m \le r \iff m \le \lfloor r \rfloor$，故覆盖集相同。苹果数只依赖覆盖集，而周长 $8\lfloor r \rfloor \le 8r$，因此最优解总可在整数半边长处取到，且周长是 8 的倍数。∎

**引理 2（闭式公式）**：$A(n) = 2n(n+1)(2n+1)$。

**证明**：由可分性，

$$A(n) = \sum_{i=-n}^{n}\sum_{j=-n}^{n}|i| + \sum_{i=-n}^{n}\sum_{j=-n}^{n}|j| = (2n+1)\sum_{k=-n}^{n}|k| + (2n+1)\sum_{k=-n}^{n}|k| = 2(2n+1)\cdot n(n+1),$$

其中 $\sum_{k=-n}^{n}|k| = 2(1+2+\cdots+n) = n(n+1)$。∎

**引理 3（环增量）**：第 $n$ 环（$\max(|i|,|j|) = n$ 的格点）的苹果总和恰为 $12n^2$。

**证明**：环上 4 个角点 $(\pm n, \pm n)$ 各 $2n$ 个苹果，合计 $8n$。每条边（不含角）有 $2n-1$ 个格点，以右边 $(n, j)$、$|j| \le n-1$ 为例，苹果和为

$$\sum_{j=-(n-1)}^{n-1} (n + |j|) = n(2n-1) + (n-1)n = n(3n-2),$$

四条边合计 $4n(3n-2) = 12n^2 - 8n$。总计 $12n^2 - 8n + 8n = 12n^2$。∎

> 💡 推论：$A(n) = \sum_{k=1}^{n} 12k^2 = 12 \cdot \dfrac{n(n+1)(2n+1)}{6} = 2n(n+1)(2n+1)$，与引理 2 互相印证——平方和公式的几何来源就是这圈「洋葱」。$n=1$ 时环即整个 $3\times3$ 方格，$12 = 12 \cdot 1^2$ ✓。

**引理 4（严格单调）**：$A(n) - A(n-1) = 12n^2 > 0$，故 $A$ 严格递增；从而可行集 $\{n : A(n) \ge T\}$ 形如 $\{n^\ast, n^\ast+1, \dots\}$（上封闭），$n^\ast$ 存在且唯一（$A(0)=0 < T$，$A(n) \ge 4n^3 \to \infty$）。∎

**定理**：答案 $= 8n^\ast$，其中 $n^\ast = \min\{n \ge 0 : A(n) \ge T\}$。

**证明**：由引理 1，只需在整数半边长中寻找；周长 $8n$ 随 $n$ 严格递增，与 $n$ 一一对应，故最小周长在最小可行 $n^\ast$ 处取到。二分过程维持不变量「$n < lo$ 时 $A(n) < T$，$n \ge hi$ 时 $A(n) \ge T$」：初值 `lo = 0`（无更小者）与 `hi = 10^5`（$A(\text{hi}) \approx 4\times10^{15} \ge T$）满足；每次收缩保持不变量，区间长度严格递减，终止时 `lo = hi = n*`。∎

## 6. 复杂度分析

- **时间复杂度**：$O(\log H)$，$H = 10^5$ 为二分上界，约 17 次迭代，每次 $O(1)$ 计算闭式公式；由 $H = O(T^{1/3})$ 也写作 $O(\log T)$。
- **空间复杂度**：$O(1)$，仅 `lo`、`hi`、`mid` 等常数个变量。

> 💡 对照：逐格点暴力 $O((n^\ast)^3) \approx 3\times10^{14}$ 不可行；公式 + 线性枚举 $O(n^\ast) \approx 6.3\times10^4$ 可行。**推导公式一步把指数从 3 降到 0，是本题唯一的考点分水岭**。

## 7. 参考代码

### C++（下界二分）

```cpp
class Solution {
public:
    long long minimumPerimeter(long long neededApples) {
        long long lo = 0, hi = 100000;   // A(1e5) ≈ 4e15 ≥ 1e15，覆盖全部输入且不溢出
        while (lo < hi) {
            long long mid = lo + (hi - lo) / 2;
            long long apples = 2 * mid * (mid + 1) * (2 * mid + 1);  // A(n) = 2n(n+1)(2n+1)
            if (apples >= neededApples) hi = mid;   // mid 可行：收缩上界
            else                        lo = mid + 1;  // mid 太小：抬升下界
        }
        return 8 * lo;                  // 半边长 n* → 周长 8n*
    }
};
```

### Python（下界二分）

```python
class Solution:
    def minimumPerimeter(self, neededApples: int) -> int:
        lo, hi = 0, 100000
        while lo < hi:
            mid = (lo + hi) // 2
            if 2 * mid * (mid + 1) * (2 * mid + 1) >= neededApples:
                hi = mid
            else:
                lo = mid + 1
        return 8 * lo
```

### Python（环增量枚举，对照版）

```python
class Solution:
    def minimumPerimeter(self, neededApples: int) -> int:
        apples = n = 0
        while apples < neededApples:
            n += 1
            apples += 12 * n * n        # 引理 3：第 n 环恰贡献 12n²
        return 8 * n
```

> 💡 **写法对照**：① 二分版是「单调计数函数找下界」的标准姿势，精度与速度双保险；② 枚举版直接消费环分解引理，$O(n^\ast) \approx 6.3\times10^4$ 步稳过——推不出完整闭式、只想清楚环增量时的赛场保底写法。

## 8. 边界情况与易错点

1. **上界与溢出联动（C++ 头号陷阱）**：全程 `long long`；`hi` 必须保证 $A(\text{hi}) \ge T$ 且中途不溢出——`hi = 10^5` 两条都满足（$A \approx 4\times10^{15}$），随手改成 $10^7$ 会在比较前就溢出成未定义行为。
2. **返回的是周长 $8n$，不是 $n$**；也别把周长算成 $4n$——边长是 $2n$，周长 $= 4 \times 2n = 8n$，系数错一位答案翻倍/减半。
3. **「内部或边缘」是闭区域**：覆盖条件 $\max(|i|,|j|) \le n$，无需任何 $\pm 1$；本题也不存在「非整数半边长更优」的坑（引理 1 已归约）。
4. **二分下界从 0 起**：$A(0) = 0 < 1 \le T$，`lo = 0` 与不变量天然相容；若从 `lo = 1` 起也对本题无害，但从 0 起更通用。
5. **浮点立方根的精度陷阱**：$T \le 10^{15}$ 时 `pow(T / 4, 1/3)` 的误差可能让 $k_0$ 偏 1，微调循环不可省；整数二分完全规避该问题。
6. **示例 2 的「一步之差」**：$A(1) = 12$ 与 $T = 13$ 只差 1 个苹果，公式哪怕差一个符号都会在这里现形——用它当推导后的第一个 sanity check。
7. **别把 $A(n)$ 记成 $2n(n+1)$ 或 $4n(n+1)(2n+1)$**：$n=1$ 代入应为 12、$n=2$ 应为 60，两个锚点值先验一遍再写二分。
