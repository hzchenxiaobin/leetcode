# LeetCode 你可以工作的最大周数 题解

## 1. 题目概述

- **标题 / 题号**：你可以工作的最大周数（#1953，medium）
- **链接**：https://leetcode.cn/problems/maximum-number-of-weeks-for-which-you-can-work/
- **来源**：LeetCode 第 252 场周赛 Q2
- **难度**：中等
- **标签**：贪心、数组、数学

**题意**：$n$ 个项目，第 $i$ 个有 $\text{milestones}[i]$ 个阶段任务。每周必须完成**某一个项目的恰好一个**任务，且**相邻两周不能做同一个项目**。做到「全部任务完成」或「剩余任务全属于上一周刚做过的项目、再做必违规」时被迫停止。返回最多能工作多少周。

**约束**：

- $1 \le n \le 10^5$
- $1 \le \text{milestones}[i] \le 10^9$（任务总数 $S$ 可达 $10^{14}$）

> 💡 本题在本仓库另有[每日题解 1953](../../solution/1901-2000/1953_你可以工作的最大周数.md)，两篇为姊妹篇：那边侧重「分隔符 / 槽位」建模的审题三关键、面试五问、以及 767 / 1405 / 621 家族对照表。本篇按周赛复盘视角，聚焦**从题面到公式的最短识别路径**，并补上每日篇引用 767 而未展开的**可达性完整证明**——「受限」情形的偶奇位构造与「全完成」情形的发牌构造都严格证出，形成引理-定理闭环。

## 3. 解题思路

### 3.1 暴力思路：大根堆逐周模拟

最直觉的做法是**逐周贪心模拟**：用大根堆维护各项目剩余任务数，每周从「不等于上一周项目」里挑剩余最多的做一个、放回时减一。优先削峰的直觉是避免高频项目在尾部扎堆。

死穴在复杂度：每周一次堆操作 $O(\log n)$，而**模拟步数 = 工作周数**，量级是任务总数 $S \le 10^5 \times 10^9 = 10^{14}$——即使每秒 $10^8$ 次堆操作也要跑数年，**必然 TLE**。

> ⚠️ 暴力给出的真正启示：题目只要「最多几周」这个数，**不需要具体每周安排**——计数问题不必构造，应直接推导闭式公式。

### 3.2 核心观察：只有最大堆可能卡住——隔板与槽位

![核心观察：其余任务是隔板，rest 个隔板隔出 rest+1 个 A 槽](images/wc252_q2_separator_slots_concept.svg)

记 $S = \sum_i \text{milestones}[i]$（总数），$M = \max_i \text{milestones}[i]$（最大项目 $A$ 的任务数），$\text{rest} = S - M$（其余所有任务数）。规则只区分「同项目 / 不同项目」、**不关心隔板具体来自哪个项目**，于是可把其余任务合并看作「隔板」，问题只剩一个几何结构：

- $A$ 的任意两个任务之间必须**至少隔一个别的任务**；
- $\text{rest}$ 个隔板最多把时间线切成 $\text{rest} + 1$ 个「$A$ 槽」，每个槽至多放 1 个 $A$；
- 因此 $A$ 至多做 $\text{rest} + 1$ 个，加上全部隔板，总周数 $\le 2\,\text{rest} + 1$；当然也不超过 $S$。

$$\boxed{\text{答案} = \min\!\big(S,\; 2\,(S - M) + 1\big)}$$

| 情形 | 条件 | 答案 | 直觉 |
|------|------|------|------|
| 全部完成 | $M \le \text{rest} + 1$（即 $2M \le S + 1$） | $S$ | $A$ 全部塞得进 $\text{rest}+1$ 个槽 |
| 受限 | $M \ge \text{rest} + 2$（即 $2M \ge S + 2$） | $2\,\text{rest} + 1$ | 只放得下 $\text{rest}+1$ 个 $A$，多出的 $M - \text{rest} - 1$ 个全部浪费 |

> 💡 **为什么次大值不用管**：卡住意味着某项目满足 $c > (S - c) + 1$ 即 $2c > S + 1$。若有两个项目同时满足，则 $S \ge c_1 + c_2 > \dfrac{S+1}{2} + \dfrac{S+1}{2} = S + 1$，矛盾——**同一时刻至多一个项目能成为瓶颈，且它必是最大项目**。这正是公式里只出现一个 $\max$ 的原因。

### 3.3 算法流程：一趟求和取最值

![算法流程：一趟遍历求 S 与 M，一个比较出答案](images/wc252_q2_algorithm_flow.svg)

1. 一趟遍历 `milestones`，同时累加 $S$、维护 $M$。
2. 计算 $\text{rest} = S - M$。
3. 若 $M \le \text{rest} + 1$ 返回 $S$，否则返回 $2\,\text{rest} + 1$；等价地直接返回 $\min(S,\ 2\,(S - M) + 1)$。

### 3.4 示例演算：两个构造

![示例演算：受限情形的隔板填槽与临界情形的降序发牌](images/wc252_q2_deal_construction_walkthrough.svg)

**受限情形 $[5,2,1]$**（$M = 5 > \text{rest} + 1 = 4$）：把 $\text{rest} + 1 = 4$ 个 $A$ 放在**偶数下标** $0,2,4,6$，$\text{rest} = 3$ 个隔板（B、B、C）**任意**填满奇数下标 $1,3,5$：

| 下标 | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
|------|---|---|---|---|---|---|---|
| 项目 | A | B | A | B | A | C | A |

逐周即 $A\,B\,A\,B\,A\,C\,A$，共 $7 = 2 \times 3 + 1$ 周；项目 0 还剩 1 个 $A$ 无槽可放。

**临界情形 $[1,2,3]$**（$M = 3 \le \text{rest} + 1 = 4$）：**发牌构造**——按数量降序把任务排成一队 $C\,C\,C\,B\,B\,A$（同项目连续成块），前 $\lceil S/2 \rceil = 3$ 个发到偶数槽 $0,2,4$，其余发到奇数槽 $1,3,5$：

| 下标 | 0 | 1 | 2 | 3 | 4 | 5 |
|------|---|---|---|---|---|---|
| 项目 | C | B | C | B | C | A |

逐周即 $C\,B\,C\,B\,C\,A$，6 = S 周全部完成。

## 4. 算法细节

1. **一趟遍历同时求 $S$ 与 $M$**：循环体内 `total += m; mx = max(mx, m);`，不需要两次遍历，更不需要排序。
2. **判据等价变形**：$M \le \text{rest} + 1 \iff 2M \le S + 1$。写 `mx <= rest + 1` 可避免 `2 * mx` 的中间乘法；若写后者，C++ 注意用 `2LL * mx`。
3. **无分支写法**：`return min(S, 2 * (S - mx) + 1);` 一个表达式覆盖两种情形——两种情形下 $\min$ 恰好分别取到两支（见定理证明），不易写错边界。
4. **溢出是本题头号陷阱**：$S \le 10^{14}$，比 32 位 `int` 上限（约 $2.1 \times 10^9$）高四个数量级。C++ 中 `total`、`rest`、返回值全程 `long long`（题目接口返回类型本身就是 `long long`，是个提示）；Python 原生大整数无此问题。
5. **别排序**：只需 $\max$，$O(n \log n)$ 的排序能过但纯属浪费。

## 5. 正确性证明

以下设 $A$ 为里程碑数最多的项目，$M = \text{milestones}[A]$，$S$ 为总任务数，$\text{rest} = S - M$。「合法序列」指任意相邻两周项目不同的工作安排。

**引理 1（上界）**：任何合法序列的长度 $L \le \min(S,\ 2\,\text{rest} + 1)$。

**证明**：$L \le S$ 显然（每周恰完成一个任务）。设序列中 $A$ 的任务出现 $k$ 次、其余任务出现 $u$ 次，即 $L = k + u$、$u \le \text{rest}$。把 $A$ 的任务按时间顺序记为 $a_1, \dots, a_k$；对每个 $1 \le j < k$，$a_j$ 与 $a_{j+1}$ 之间至少夹一周非 $A$ 项目（否则相邻同项目违规），且这 $k - 1$ 段夹层两两不重叠、各含至少一个非 $A$ 任务，故 $u \ge k - 1$。于是

$$L = k + u \le (u + 1) + u = 2u + 1 \le 2\,\text{rest} + 1. \qquad \square$$

**引理 2（受限情形可达）**：若 $M \ge \text{rest} + 2$，则存在长度为 $2\,\text{rest} + 1$ 的合法序列。

**证明**：构造：在位置 $0, 2, 4, \dots, 2\,\text{rest}$（共 $\text{rest} + 1$ 个偶数位）放 $A$ 的任务（$M \ge \text{rest} + 2 > \text{rest} + 1$，足够取用）；在位置 $1, 3, \dots, 2\,\text{rest} - 1$（共 $\text{rest}$ 个奇数位）**任意**放入其余项目的全部 $\text{rest}$ 个任务。任意相邻两位必为一偶一奇：偶位全是 $A$、奇位全是非 $A$，故任意相邻两位项目不同，序列合法且长度恰为 $2\,\text{rest} + 1$。∎

> 💡 引理 2 的漂亮之处：奇数位**彼此不相邻**，其余项目内部无论怎么排都不可能「自己撞自己」——「次大项目会不会也卡住」的疑虑被构造直接消解。

**引理 3（临界情形可达·发牌构造）**：若 $2M \le S + 1$，则存在长度为 $S$ 的合法序列（全部完成）。

**证明**：将项目按里程碑数**降序**排列（$c_1 = M \ge c_2 \ge \cdots \ge c_n$），把全部任务排成一列 $t_0, t_1, \dots, t_{S-1}$——同项目的任务在列中**连续成块**。令 $h = \lceil S/2 \rceil$，按「发牌」放置：$k < h$ 的 $t_k$ 放到位置 $2k$；$k \ge h$ 的 $t_k$ 放到位置 $2(k - h) + 1$。只需证任意同项目的两个任务 $t_i, t_j$（$i < j$）最终位置不相邻。

先记录两个事实：

- **(a)** 由 $2M \le S + 1$ 得 $M \le h$（$S$ 偶时 $M \le S/2 = h$；$S$ 奇时 $M \le (S+1)/2 = h$），故任意块长 $c \le M \le h$；
- **(b)** $t_i, t_j$ 同块，故 $j - i \le c - 1$。

分三种情况：

1. **同落偶数段**（$j < h$）：位置 $2i$ 与 $2j$ 相差 $2(j - i) \ge 2$，不相邻；
2. **同落奇数段**（$i \ge h$）：位置 $2(i-h)+1$ 与 $2(j-h)+1$ 相差 $2(j-i) \ge 2$，不相邻；
3. **跨段**（$i < h \le j$）：位置为 $2i$ 与 $2(j-h)+1$，相邻当且仅当 $j - i \in \{h - 1,\ h\}$：
   - 若 $j - i = h$：则 $c \ge h + 1 > M$，与 (a) 矛盾；
   - 若 $j - i = h - 1$：则 $c \ge h$，结合 (a) 得 $c = h = M$，该块是长为 $M$ 的最大块。若另有一块也长为 $h$，则 $S \ge 2h \ge S$，迫使 $S$ 为偶数且**恰好只有这两个项目**——两块分别是列首 $[0, h-1]$（全落偶数段）与列尾 $[h, S-1]$（全落奇数段），均不跨段，与情形 3 矛盾；若最大块唯一，它必排在**列首** $[0, h-1]$，则 $j \le h - 1 < h$，与 $j \ge h$ 矛盾。

三种情况均不产生相邻同项目，故发牌结果是合法安排，长度为 $S$。∎

**定理**：答案 $= \min(S,\ 2\,(S - M) + 1)$。

**证明**：上界由引理 1。可达性分两种情形（整数下二者恰覆盖所有输入）：

- 若 $2M \le S + 1$：移项得 $2\,(S - M) + 1 \ge S$，故 $\min = S$，由引理 3 可达；
- 若 $2M \ge S + 2$（等价于 $M \ge \text{rest} + 2$）：移项得 $2\,(S - M) + 1 \le S - 1 < S$，故 $\min = 2\,(S - M) + 1 = 2\,\text{rest} + 1$，由引理 2 可达。

两种情形的可达值都压到上界，故为答案。∎

**算法正确性**：一趟遍历正确求出 $S$ 与 $M$，返回值由定理直接给出。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。一趟遍历同时求总和与最大值；比较与返回 $O(1)$。
- **空间复杂度**：$O(1)$。仅 `total`、`mx`、`rest` 三个变量。

> 💡 对照：大根堆模拟 $O(S \log n)$，$S$ 可达 $10^{14}$，约 $10^{15}$ 量级的基本操作，完全不可行——「识别出隔板结构、把逐周模拟压成闭式公式」正是本题的考点。

## 7. 参考代码

### C++（显式两分支，体现分界线）

```cpp
class Solution {
public:
    long long numberOfWeeks(vector<int>& milestones) {
        long long total = 0, mx = 0;
        for (int m : milestones) {
            total += m;
            mx = max(mx, (long long)m);
        }
        long long rest = total - mx;
        if (mx <= rest + 1) return total;   // A 不超过槽位数：全部完成
        return 2 * rest + 1;                // A 只能做 rest+1 个
    }
};
```

### Python（min 一行版）

```python
class Solution:
    def numberOfWeeks(self, milestones: List[int]) -> int:
        total = sum(milestones)
        return min(total, 2 * (total - max(milestones)) + 1)
```

### Python（显式两分支版）

```python
class Solution:
    def numberOfWeeks(self, milestones: List[int]) -> int:
        total, mx = sum(milestones), max(milestones)
        rest = total - mx
        return total if mx <= rest + 1 else 2 * rest + 1
```

> 💡 **写法对照**：① 分支版把分界线 $M \le \text{rest}+1$ 显式写出来，赛场调试直观；② `min` 版一个表达式收掉两种情形——$M \le \text{rest}+1$ 时 $2\,\text{rest}+1 \ge S$ 自动取 $S$，反之取 $2\,\text{rest}+1$，正确性即定理的两行移项。

## 8. 边界情况与易错点

1. **32 位溢出（头号 WA）**：$S$ 最高 $10^{14}$，`int` 累加约 22 个 $10^9$ 就溢出。C++ 全程 `long long`；题目返回类型本身就是 `long long`，是官方给的提示。
2. **单项目 $[x]$**：$\text{rest} = 0$，$x \ge 2$ 时 $M \ge \text{rest} + 2$，答案 $2 \times 0 + 1 = 1$；$x = 1$ 时两种公式都给 $1 = S$——无需特判。
3. **临界 $M = \text{rest} + 1$ 仍全完成**：如 $[2,1] \to 3$、$[4,3] \to 7$、$[4,2,1] \to 7$。若把分界错写成 $M \le \text{rest}$，会在这些用例上错误截断成 $2\,\text{rest} + 1$（少算 1 周）。
4. **误设多个瓶颈**：至多一个项目能满足「任务数 > 其余 + 1」（若有两个，两者之和超过 $S+1$，矛盾），判据里不该出现次大值。
5. **「停止」是被迫不是主动**：不是做完隔板就主动停，而是隔板耗尽后剩余任务全属 $A$、而上一周恰是 $A$——想通这一点才能理解答案恰为 $2\,\text{rest} + 1$。
6. **别排序**：$O(n \log n)$ 能过但没必要，一趟 `sum` + `max` 即可。
