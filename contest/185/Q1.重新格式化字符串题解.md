# LeetCode 重新格式化字符串 题解

## 1. 题目概述

- **标题 / 题号**：重新格式化字符串（#1417，easy）
- **链接**：https://leetcode.cn/problems/reformat-the-string/
- **来源**：LeetCode 第 185 场周赛 Q1
- **难度**：简单
- **标签**：字符串、计数、交错合并

**题意**：给定一个混合了**小写字母**和**数字**的字符串 `s`，要求**重新排列**其中的字符，使得**任意两个相邻字符的类型都不同**（字母后面跟数字、数字后面跟字母）。存在合法排法时返回任意一种，否则返回**空字符串** `""`。

**约束**：

- $1 \le s.length \le 500$
- `s` 仅由小写英文字母和/或数字组成

> 💡 一句话定位：合法性只取决于字符的**类型**而与字符本身无关，问题退化为「两类字符能否严格交替」——签到题的全部难度浓缩在一个计数判据上。

## 3. 解题思路

### 3.1 暴力思路：枚举全排列

最朴素的做法是枚举 `s` 的所有排列，逐个检查相邻类型是否不同，返回第一个合法的：$O(n! \cdot n)$，$n \le 500$ 下是天文数字。即使改成「逐位放置 + 回溯」，最坏情形同样是指数级。

> ⚠️ 暴力失败的原因：它把每个字符当作互不相同的个体去排列，而合法性**只取决于类型**（字母 / 数字）——同类型字符互相替换不改变合法性。把视角从「字符排列」降到「类型交替」，数量关系立刻浮现。

### 3.2 核心观察：合法 ⟺ 交替 ⟺ $|c_L - c_D| \le 1$

![核心观察：合法串是两类严格交替，数量差至多 1](images/wc185_q1_alternating_pattern_concept.svg)

「相邻类型不同」意味着位置 $i$ 与 $i+1$ 的类型互异，于是位置 $i$ 与 $i+2$ 的类型**相同**——类型沿下标**逐位交替**，整条串形如 `A B A B A B …`。

换个角度：长度为 $n$ 的串有**偶数位槽** $\lceil n/2 \rceil$ 个、**奇数位槽** $\lfloor n/2 \rfloor$ 个；类型逐位交替 ⇒ 同一类字符必须**整体挤进同一组槽位**。于是：

- 多的一类数量 $\le \lceil n/2 \rceil$，少的一类 $\le \lfloor n/2 \rfloor$，而两者之和恰为 $n$；
- 因此两类数量**只能**是 $\lceil n/2 \rceil$ 与 $\lfloor n/2 \rfloor$——差至多为 1。

$$\text{有解} \iff |c_L - c_D| \le 1$$

差 $\ge 2$ 时无解：如 `"aabb12"` 有 4 个字母，但偶数位槽只有 $\lceil 6/2 \rceil = 3$ 个，装不下，必有两个字母相邻。条件满足时的构造也是唯一套路：**数量多的一类占偶数位（0 号位开头），少的一类占奇数位**，逐位交错填写；$c_L = c_D$ 时谁开头都行。

### 3.3 算法流程：分桶 → 判可行 → 交错填位

![算法流程：分桶计数、判可行性、多数类占偶数位交错填写](images/wc185_q1_algorithm_flow.svg)

```text
输入：s
① letters ← s 中的字母，digits ← s 中的数字       （一趟分桶）
② 若 |len(letters) − len(digits)| > 1：返回 ""     （判可行）
③ a ← 较多的一类（占偶数位、开头），b ← 另一类     （定开头）
④ res[2i] ← a[i]，res[2i+1] ← b[i]，返回 res       （交错填写）
```

### 3.4 示例演算

![示例演算：covid2019 与 ab123 的交错构造](images/wc185_q1_example_walkthrough.svg)

以示例 4 `s = "covid2019"` 为例：

| 步骤 | 操作 | 结果 |
|------|------|------|
| ① 分桶 | letters = [c,o,v,i,d]，digits = [2,0,1,9] | $c_L = 5$，$c_D = 4$ |
| ② 判可行 | \\|5 − 4\\| = 1 ≤ 1 | ✓ 有解 |
| ② 定开头 | 字母多 → 字母占偶数位 | c 先 |
| ③ 交错填写 | c, 2, o, 0, v, 1, i, 9, d | `"c2o0v1i9d"` ✓ |

对照：示例 5 `"ab123"` 数字多 → 数字占偶数位 → `"1a2b3"`；示例 2 `"leetcode"` 差 8 > 1 → 直接返回 `""`。

## 4. 算法细节

1. **分桶**：一趟扫描，`isalpha(c)` 入 `letters`、`isdigit(c)` 入 `digits`。题面保证只有小写字母与数字，两个判定互斥且完备，无需其他分支。
2. **判据边界**：无解条件是 $|c_L - c_D| > 1$（**严格大于**）；差恰好 1 对应奇数长度串，合法。
3. **别名消分支**：令 `a` 引用较多的一类、`b` 引用较少的一类，把「谁开头」统一进同一段交错代码；C++ 用 `auto&` 引用避免数组拷贝。
4. **按奇偶位直写**：`a[i]` 写入下标 $2i$、`b[i]` 写入下标 $2i+1$。当 $c_a = c_b + 1$ 时最后一个奇数位不存在，`if (i < b.size())` 天然收尾，末尾恰好多出一个 `a` 类字符。
5. **数据范围**：$n \le 500$，计数与下标均可用 `int`。

## 5. 正确性证明

**引理 1（必要性）**：若 `s` 存在合法重排，则 $|c_L - c_D| \le 1$。

**证明**：设合法串长 $n$。相邻字符类型不同，即对 $0 \le i \le n-2$，位置 $i$ 与 $i+1$ 的类型互异；特别地，位置 $i$ 与 $i+2$ 的类型相同。由归纳，全部偶数位为同一类型，全部奇数位为另一类型。因此两类字符分别占据 $\lceil n/2 \rceil$ 个偶数位与 $\lfloor n/2 \rfloor$ 个奇数位，数量差为 $n \bmod 2 \le 1$。∎

**引理 2（充分性）**：若 $|c_L - c_D| \le 1$，则「多数类占偶数位」的交错构造产出合法串。

**证明**：设 $a$ 为较多的一类，$c_a \ge c_b$，$n = c_a + c_b$。构造把 $a[i]$ 放在位置 $2i$（$0 \le i \le c_a - 1$）、$b[i]$ 放在位置 $2i+1$（$0 \le i \le c_b - 1$）。由判据 $c_a \le c_b + 1$：

- 最大偶数位 $2(c_a - 1) \le 2c_b \le n - 1$，最大奇数位 $2c_b - 1 \le n - 1$，所有下标合法；
- 偶数位恰用 $c_a$ 个、奇数位恰用 $c_b$ 个，合计 $n$ 个位置不重不漏。

任意相邻位置对 $(2i,\ 2i+1)$、$(2i+1,\ 2i+2)$ 上的字符分属两类，类型不同，构造合法。∎

**定理**：算法当且仅当 $|c_L - c_D| \le 1$ 时返回合法重排，否则返回 `""`。

**证明**：若 $|c_L - c_D| > 1$，由引理 1 不存在任何合法重排，算法第 ② 步返回 `""`，与题意一致；否则由引理 2，第 ④ 步构造的串合法，算法将其返回。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。分桶一趟线性扫描，判可行 $O(1)$，交错填写一趟线性扫描。
- **空间复杂度**：$O(n)$。两个分桶数组合计容纳 $n$ 个字符，结果串 $O(n)$。（可先按类型 partition 再按下标交换做到 $O(1)$ 额外空间，但 $n \le 500$ 下无此必要。）

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    string reformat(string s) {
        string letters, digits;
        for (char c : s)
            (isalpha(c) ? letters : digits).push_back(c);
        if (abs((int)letters.size() - (int)digits.size()) > 1) return "";

        auto &a = (letters.size() >= digits.size()) ? letters : digits;  // 多数类占偶数位
        auto &b = (letters.size() >= digits.size()) ? digits : letters;

        string res(s.size(), ' ');
        for (int i = 0; i < (int)a.size(); i++) {
            res[2 * i] = a[i];
            if (i < (int)b.size()) res[2 * i + 1] = b[i];
        }
        return res;
    }
};
```

### Python

```python
class Solution:
    def reformat(self, s: str) -> str:
        letters = [c for c in s if c.isalpha()]
        digits = [c for c in s if c.isdigit()]
        if abs(len(letters) - len(digits)) > 1:
            return ""
        if len(letters) < len(digits):      # 多数类占偶数位（开头）
            letters, digits = digits, letters
        res = []
        for x, y in zip(letters, digits):   # 两类按序配对
            res += [x, y]
        if len(letters) > len(digits):      # 多数类恰多一个，补末尾
            res.append(letters[-1])
        return "".join(res)
```

> 💡 两份代码同一骨架：**判可行 → 多数类开头 → 交错**。C++ 直接对结果下标 $2i$、$2i+1$ 赋值；Python 用 `zip` 把两类按序配对，多数类多出的最后一个字符单独补尾。

## 8. 边界情况与易错点

1. **单字符串（$n = 1$）**：$|1 - 0| = 1 \le 1$，**合法**——没有相邻对，`"a"` → `"a"`、`"7"` → `"7"`。误判成无解返回 `""` 是本题最典型的 WA。
2. **全同类串（$n \ge 2$）**：如 `"leetcode"`、`"1229857369"`，差为 $n \ge 2$，返回 `""`。
3. **判据符号**：无解是**严格大于 1**；误写成 `>= 1` 会把所有奇数长度的合法输入（如 `"ab123"`）全部判死。
4. **差 1 时开头唯一**：多数类**必须**开头。若 `"ab123"` 让字母开头，写到 `a1b2` 后数字 `3` 无处安放——交错循环若不检查 `b` 是否越界，会漏字符或数组越界。
5. **相等时答案不唯一**：$c_L = c_D$ 时任一类开头均可（示例 1 的多个合法输出），判题为 Special Judge，返回任意合法解。
6. **返回约定**：无解返回空字符串 `""`，不是返回原串。
7. **字符判定**：题面保证仅小写字母与数字，`isalpha` / `isdigit` 互斥完备，无需处理其他字符。
