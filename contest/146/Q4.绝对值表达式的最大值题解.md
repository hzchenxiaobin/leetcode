# LeetCode 绝对值表达式的最大值 题解

## 1. 题目概述

- **标题 / 题号**：绝对值表达式的最大值（#1131，medium）
- **链接**：https://leetcode.cn/problems/maximum-of-absolute-value-expression/
- **来源**：LeetCode 第 146 场周赛 Q4
- **难度**：中等
- **标签**：数组，数学

**题意**：给定两个等长的整数数组 `arr1`、`arr2`（长度均为 $n$），在所有下标对 $(i, j)$ 上最大化

$$E(i,j) = |arr1[i] - arr1[j]| + |arr2[i] - arr2[j]| + |i - j|$$

返回这个最大值。三项绝对值本质上是三个维度：两个数组的取值差，以及**下标差**本身——第三项把「位置」也当成了一个坐标轴，这是本题最容易忽略的一点。

**约束**：

- $2 \le n \le 4 \times 10^4$
- $-10^6 \le arr1[i], arr2[i] \le 10^6$
- $0 \le i, j < n$，**允许** $i = j$（此时表达式为 0，所以答案必然非负）

> 💡 注意第三项用的是下标差的**绝对值**，因此 $(i,j)$ 与 $(j,i)$ 完全对称，枚举时不必考虑顺序。

## 2. 示例

**示例 1**

```text
输入：arr1 = [1,2,3,4]，arr2 = [-1,4,5,6]
输出：13
解释：取 i = 3、j = 0：
      |arr1[3]-arr1[0]| = |4-1| = 3
      |arr2[3]-arr2[0]| = |6-(-1)| = 7
      |3-0| = 3
      合计 3 + 7 + 3 = 13，是全部 16 个下标对中的最大值。
```

**示例 2**

```text
输入：arr1 = [1,-2,-5,0,10]，arr2 = [0,-2,-1,-7,-4]
输出：20
解释：取 i = 2、j = 4：
      |-5-10| = 15，|-1-(-4)| = 3，|2-4| = 2，合计 20。
```

**补充示例（最小规模，非官方）**

```text
输入：arr1 = [1,1]，arr2 = [1,1]
输出：1
解释：两数组取值全相同，只剩 |i-j| 起作用；n = 2 时只有 |0-1| = 1。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有下标对 $(i,j)$，每对用 $O(1)$ 算出 $E(i,j)$，取最大值。

- 下标对数量为 $n^2$，当 $n = 4\times10^4$ 时是 $1.6\times10^9$ 对；
- 每对至少 3 次减法、3 次取绝对值、2 次加法，常数不小，C++ 也要跑好几秒，Python 则是分钟级；
- 这个结构也几乎没有剪枝空间——最大值可能出现在任意一对下标上。

所以暴力必然超时，需要把「枚举下标对」这件事整体消掉。

### 3.2 核心观察：绝对值拆成符号组合，max 顺序可以交换

![绝对值拆成 8 个线性式](images/wc146_q4_sign_decomposition.svg)

**第一步：把绝对值写成 max。** 对任意实数 $u$ 有 $|u| = \max(u, -u)$。三个绝对值各自独立地取符号，于是

$$|u| + |v| + |w| = \max_{\sigma \in \{\pm 1\}^3} \bigl(\sigma_1 u + \sigma_2 v + \sigma_3 w\bigr)$$

代入 $u = arr1[i]-arr1[j]$ 等，并记

$$f_\sigma(k) = \sigma_1 \cdot arr1[k] + \sigma_2 \cdot arr2[k] + \sigma_3 \cdot k$$

就有 $E(i,j) = \max_\sigma \bigl(f_\sigma(i) - f_\sigma(j)\bigr)$。

**第二步：交换两个 max 的顺序。** 对有限集合，$\max$ 之间可以任意交换：

$$\max_{i,j} E(i,j) = \max_\sigma \max_{i,j} \bigl(f_\sigma(i) - f_\sigma(j)\bigr) = \max_\sigma \Bigl(\max_i f_\sigma(i) - \min_j f_\sigma(j)\Bigr)$$

关键在最后一步：$f_\sigma(i)$ 只依赖 $i$，$f_\sigma(j)$ 只依赖 $j$，两者**完全解耦**，于是「枚举下标对」变成了「各自求一个最大、一个最小」。

**第三步：8 组砍到 4 组。** 注意 $f_{-\sigma} = -f_\sigma$，因此

$$\max_i f_{-\sigma}(i) - \min_j f_{-\sigma}(j) = -\min_i f_\sigma(i) + \max_j f_\sigma(j)$$

与 $\sigma$ 的差值完全相同。所以每对相反符号只算一次即可：固定 $\sigma_1 = +1$，只枚举 $(\sigma_2, \sigma_3)$ 的 4 种组合，也就是 4 个线性式

$$arr1[i] + arr2[i] + i,\quad arr1[i] + arr2[i] - i,\quad arr1[i] - arr2[i] + i,\quad arr1[i] - arr2[i] - i$$

> ⚠️ 只能固定 $\sigma_1, \sigma_2, \sigma_3$ 中的**一个**符号。固定两个（比如同时固定 $\sigma_1 = \sigma_3 = +1$）就只剩 2 组，会漏解：`arr1 = [10,0,0]`、`arr2 = [10,0,0]` 的答案是 22（来自 $arr1[i]+arr2[i]-i$），只用 $+i$ 的两组只能得到 19。

### 3.3 算法流程

![算法流程：4 组符号各一趟扫描](images/wc146_q4_scan_flow.svg)

```text
ans ← 0
for (σ2, σ3) in {+1,-1} × {+1,-1}:        # 共 4 组，σ1 固定为 +1
    mx ← -∞, mn ← +∞
    for i in 0 .. n-1:
        f ← arr1[i] + σ2*arr2[i] + σ3*i
        mx ← max(mx, f)
        mn ← min(mn, f)
    ans ← max(ans, mx - mn)
return ans
```

每组符号对应一次线性扫描，维护 $f$ 的最大值与最小值，最后用「最大 − 最小」更新答案。4 组符号 × 每次 $n$ 步，总计 $4n$ 次基本运算。

也可以把 4 组符号合并成**一趟**扫描：同时维护 4 个 $mx$ 和 4 个 $mn$（共 8 个变量），每个下标一次性更新完。这样对数组只遍历一次，循环开销更小（$n = 4\times10^4$ 时 C++ 约快 20%），但两种写法复杂度相同。

### 3.4 示例演算

![示例 1 的四组线性式演算](images/wc146_q4_walkthrough.svg)

对示例 1（`arr1 = [1,2,3,4]`，`arr2 = [-1,4,5,6]`）逐行计算 $f_\sigma$：

| 线性式 | $f(0)$ | $f(1)$ | $f(2)$ | $f(3)$ | 最大 | 最小 | 差值 |
|--------|--------|--------|--------|--------|------|------|------|
| $arr1+arr2+i$ | 0 | 7 | 10 | 13 | 13 | 0 | **13** |
| $arr1+arr2-i$ | 0 | 5 | 6 | 7 | 7 | 0 | 7 |
| $arr1-arr2+i$ | 2 | -1 | 0 | 1 | 2 | -1 | 3 |
| $arr1-arr2-i$ | 2 | -3 | -4 | -5 | 2 | -5 | 7 |

第一行差值 13 最大，对应的下标是 $i = 3$（$f$ 最大）、$j = 0$（$f$ 最小），回代验证 $3 + 7 + 3 = 13$，与官方答案一致。

示例 2 的最优行是 $arr1-arr2+i$：$f = [1,\,1,\,-2,\,10,\,18]$，最大值 18（下标 4）、最小值 −2（下标 2），差值 20，正好对应 $i=2$、$j=4$，与手算一致。

## 4. 算法细节

1. **符号枚举的写法**：外层两重循环 `for s2 in {1,-1}`、`for s3 in {1,-1}` 最直观；也可以手动展开 4 个表达式 `a+b+i`、`a+b-i`、`a-b+i`、`a-b-i`，省掉循环开销，但可读性略差。
2. **`ans` 初值取 0**：因为 $i = j$ 合法且此时 $E = 0$，答案非负；取 0 与取 $-\infty$ 都能过，但取 0 更贴合语义，也避免空数组之外的意外。
3. **数值范围**：单项 $f_\sigma(k)$ 的绝对值不超过 $10^6 + 10^6 + 4\times10^4 \approx 2.04\times10^6$，差值不超过 $4.08\times10^6$，`int` 足够；若担心后续推广到更大数据，用 `long long` 也只是零成本。
4. **只需要值，不需要下标**：题目只要最大值，所以更新 $mx$、$mn$ 时不必记录 argmax/argmin。若改问「返回最优下标对」，就在更新时同步保存下标，并在取差值前检查两个下标是否相同（相同则退化为 0，需要额外比较次优值）。
5. **$i$、$j$ 无需限制顺序**：第三项是 $|i-j|$，而我们的 $\max_i f - \min_j f$ 天然覆盖两个方向，不需要再补「$i < j$」的分支。
6. **遍历写法**（Python）：`for i, (a, b) in enumerate(zip(arr1, arr2))` 最简洁、可读性最好；但 `enumerate(zip(...))` 会为每个下标构造一个元组，追求极限常数时 `for i in range(n)` 配下标访问反而略快，两者在本机 $n = 4\times10^4$ 上相差不到 5 ms，选顺眼的即可。
7. **不要把 4 组写成 2 组**：这是本题最高频的 WA 原因，见 3.2 的警告与第 8 节第 1 条。

## 5. 正确性证明

**引理 1（绝对值的符号展开）**：对任意实数 $u, v, w$，

$$|u| + |v| + |w| = \max_{\sigma \in \{\pm1\}^3} (\sigma_1 u + \sigma_2 v + \sigma_3 w)$$

**证明**：由 $|x| = \max(x, -x)$，三项的符号选择互不影响，故

$$|u|+|v|+|w| = \max_{\sigma_1 \in \{\pm 1\}} (\sigma_1 u) + \max_{\sigma_2 \in \{\pm 1\}} (\sigma_2 v) + \max_{\sigma_3 \in \{\pm 1\}} (\sigma_3 w) = \max_{\sigma_1,\sigma_2,\sigma_3 \in \{\pm 1\}} (\sigma_1 u + \sigma_2 v + \sigma_3 w)$$

（最后一个等号成立，是因为三个 $\max$ 相互独立、取值可以同时达到。）∎

**引理 2（解耦）**：对任意符号向量 $\sigma$ 与任意两个数组，

$$\max_{i,j}\bigl(f_\sigma(i) - f_\sigma(j)\bigr) = \max_i f_\sigma(i) - \min_j f_\sigma(j)$$

**证明**：设 $i^*$ 是 $f_\sigma$ 的最大值点，$j^*$ 是最小值点。对任意 $i, j$ 有 $f_\sigma(i) - f_\sigma(j) \le f_\sigma(i^*) - f_\sigma(j^*)$，而取 $i = i^*, j = j^*$ 时等号成立，故最大值恰为 $f_\sigma(i^*) - f_\sigma(j^*)$。∎

**引理 3（对称性，8 组可砍半）**：对任意 $\sigma$，

$$\max_i f_{-\sigma}(i) - \min_j f_{-\sigma}(j) = \max_i f_\sigma(i) - \min_j f_\sigma(j)$$

**证明**：$f_{-\sigma} = -f_\sigma$，于是 $\max_i(-f_\sigma(i)) = -\min_i f_\sigma(i)$，$\min_j(-f_\sigma(j)) = -\max_j f_\sigma(j)$，两者相减得 $-\min_i f_\sigma(i) + \max_j f_\sigma(j)$，与右边相同。∎

**定理**：算法返回的值等于 $\max_{i,j} E(i,j)$。

**证明**：由引理 1，$E(i,j) = \max_\sigma \bigl(f_\sigma(i) - f_\sigma(j)\bigr)$；对 $\sigma$ 与 $(i,j)$ 两个有限 $\max$ 交换顺序（有限集合上 $\max$ 可交换），再由引理 2 解耦，得

$$\max_{i,j} E(i,j) = \max_\sigma \Bigl( \max_i f_\sigma(i) - \min_j f_\sigma(j) \Bigr)$$

由引理 3，$\{\sigma\}$ 中每个符号向量的差值都与其相反向量相同，故遍历「固定 $\sigma_1 = +1$ 的 4 组」得到的最大值与遍历全部 8 组相同。算法正是对这 4 组各求一次 $\max_i f_\sigma(i) - \min_j f_\sigma(j)$ 并取最大，因此结果等于 $\max_{i,j} E(i,j)$。∎

## 6. 复杂度分析

- **时间**：$O(n)$。外层固定 4 组符号，内层对 $n$ 个下标各做一次线性运算与两次比较，总计约 $4n$ 次基本操作；$n = 4\times10^4$ 时不到 $2\times10^5$ 次，远低于 $O(n^2)$ 的 $1.6\times10^9$。
- **空间**：$O(1)$。只用了 `ans`、`mx`、`mn` 等常数个变量，不需要额外数组或哈希表。
- **常数优化**：把 4 组合并成一趟，可把对数组的遍历次数从 4 降到 1，减少循环开销（C++ 下约快 20%），但不改变渐近复杂度。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maxAbsValExpr(vector<int>& arr1, vector<int>& arr2) {
        int n = arr1.size();
        int ans = 0;
        // 固定 σ1 = +1，枚举 σ2、σ3 的 4 种组合
        for (int s2 : {1, -1}) {
            for (int s3 : {1, -1}) {
                int mx = INT_MIN, mn = INT_MAX;
                for (int i = 0; i < n; i++) {
                    int f = arr1[i] + s2 * arr2[i] + s3 * i;
                    if (f > mx) mx = f;
                    if (f < mn) mn = f;
                }
                if (mx - mn > ans) ans = mx - mn;
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maxAbsValExpr(self, arr1: list[int], arr2: list[int]) -> int:
        ans = 0
        # 固定 σ1 = +1，枚举 σ2、σ3 的 4 种组合
        for s2 in (1, -1):
            for s3 in (1, -1):
                mx, mn = -10**18, 10**18
                for i, (a, b) in enumerate(zip(arr1, arr2)):
                    f = a + s2 * b + s3 * i
                    if f > mx:
                        mx = f
                    if f < mn:
                        mn = f
                ans = max(ans, mx - mn)
        return ans
```

## 8. 边界情况与易错点

1. **只固定一个符号**：固定 $\sigma_1 = +1$ 后仍必须枚举 $\sigma_2,\sigma_3$ 的 4 种组合。若顺手把 $\sigma_3$ 也固定成 $+1$，答案会偏小（`arr1 = [10,0,0]`、`arr2 = [10,0,0]` 会输出 19 而非 22）。
2. **`ans` 的初值**：因为 $i = j$ 允许且值为 0，答案非负，初值取 0 是安全的；若错写成「必须 $i \ne j$」的逻辑，就要额外处理 $n = 2$ 的特例。
3. **$n = 2$ 的最小规模**：只有一对不同下标，答案是 $|arr1[0]-arr1[1]| + |arr2[0]-arr2[1]| + 1$，索引项恒为 1，注意别把 $|1-0|$ 漏掉。
4. **下标项不要写成 $i - j$**：题面是 $|i-j|$，实现里用 $\sigma_3 \cdot i$（$\sigma_3 \in \{+1,-1\}$）已隐含两个方向；若手写成 `i - j` 且不取绝对值，会漏掉一半情况。
5. **符号与取负的顺序**：$s_2 = -1$ 表示 $-arr2[i]$，不要误写成 $arr2[i] - arr1[i]$ 之类的错位；建议先写出目标线性式再翻译成代码。
6. **溢出与类型**：本题 `int` 足够（上界约 $4.08\times10^6$），但若题目数据换成 $10^9$ 量级，$arr1[i]+arr2[i]+i$ 就会溢出 `int`，此时应改用 `long long`。
7. **`i`、`j` 可相同**：若某个线性式在所有下标上取值相同，其差值为 0；本题 $\sigma_3 = \pm 1$ 保证 $f$ 随下标单调变化，4 组里必有正的差值，所以 `ans` 不会停在初值 0 上。
