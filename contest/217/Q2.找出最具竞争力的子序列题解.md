# LeetCode 找出最具竞争力的子序列 题解

## 1. 题目概述

- **标题 / 题号**：找出最具竞争力的子序列（#1673，medium）
- **链接**：https://leetcode.cn/problems/find-the-most-competitive-subsequence/
- **来源**：LeetCode 第 217 场周赛 Q2
- **难度**：中等
- **标签**：贪心、栈、单调栈、数组

**题意**：给定整数数组 `nums` 和正整数 $k$，返回 `nums` 中长度为 $k$ 且**最具竞争力**的子序列。相同长度的子序列 $a$、$b$ 在第一个不同的位置上，若 $a$ 的数字更小，则称 $a$ 比 $b$ 更具竞争力（即同长度子序列按**字典序**比较大小）。

**约束**：

- $1 \le \text{nums.length} \le 10^5$
- $0 \le \text{nums}[i] \le 10^9$
- $1 \le k \le \text{nums.length}$

## 2. 示例

**示例 1**

```text
输入：nums = [3,5,2,6], k = 2
输出：[2,6]
解释：所有长 2 子序列 {[3,5],[3,2],[3,6],[5,2],[5,6],[2,6]} 中，[2,6] 字典序最小。
```

**示例 2**

```text
输入：nums = [2,4,3,3,5,4,9,6], k = 4
输出：[2,3,3,4]
```

**示例 3（补充：想换也换不起的情形）**

```text
输入：nums = [3,2,1], k = 2
输出：[2,1]
解释：扫描到末尾的 1 时栈为 [2]，虽然 2 > 1，但弹掉 2 后剩余元素凑不满长度 2，
     只能保留 2 → 答案 [2,1]。
```

## 3. 解题思路

### 3.1 暴力思路

枚举全部 $\binom{n}{k}$ 个长度为 $k$ 的子序列、取字典序最小：$n$ 达 $10^5$，组合数是天文数字。退一步做 DP——令 $f(i,j)$ 表示「从下标 $i$ 起还需选 $j$ 个数」的字典序最小序列——状态有 $O(nk)$ 个、每个状态的答案又是序列本身，转移与比较的代价使其总量轻松超过 $10^{10}$。必须利用字典序**逐位确定**的贪心结构。

### 3.2 核心观察：见小就换、换得起才换（单调栈）

「字典序最小」意味着答案由第一位决定：第一位能多小就多小；并列时看第二位……于是用**栈**维护「目前已承诺的最优前缀」，对每个新元素 $x = \text{nums}[i]$：

1. **见小就换**：若栈顶 $t > x$，则任何以「$\dots, t$」为前缀的候选，都在 $t$ 的位置上输给「把 $t$ 换成 $x$」的候选——交换严格更优；
2. **换得起才换**：弹掉 $t$ 后栈长减一，必须保证「剩余栈 + 尚未入场的元素（含 $x$）」仍凑得满 $k$ 个，即 $(|S|-1)+(n-i)\ge k$；
3. **栈满即丢**：栈长达到 $k$ 后，不触发弹栈的新元素直接丢弃。

![核心观察：见小就换、换得起才换](images/1673_greedy_pop_concept.svg)

> 💡 **一句话总结**：栈里存的是「已承诺的最优前缀」；弹栈 = 用严格更小的值兑现同一位置，守门条件 = 保证承诺仍能兑现成长度 $k$。

### 3.3 算法流程

对每个 $x = \text{nums}[i]$（$i = 0, 1, \dots, n-1$）依次执行：

1. **弹栈循环**：当栈非空、栈顶 $> x$、且 $(|S|-1)+(n-i)\ge k$ 时，弹出栈顶；
2. **入栈**：若 $|S| < k$，压入 $x$；否则（$|S|=k$）丢弃 $x$。

扫描结束后栈长恰为 $k$，从栈底到栈顶即答案。

![算法流程：条件弹栈与限流入栈](images/1673_monotonic_stack_flow.svg)

### 3.4 示例演算

以示例 2（$n=8, k=4$）逐步走查：

| $i$ | $x$ | 弹栈检查（顶 $> x$ ? 弹后可补足 ?）| 动作 | 栈（底→顶）|
|---|---|---|---|---|
| 0 | 2 | 栈空，无栈顶可弹 | 入栈 | [2] |
| 1 | 4 | $4 > 2$ ? 否 | 入栈 | [2,4] |
| 2 | 3 | $4 > 3$ ✓ 且 $(2-1)+(8-2)=7 \ge 4$ | 弹 4，入 3 | [2,3] |
| 3 | 3 | $3 > 3$ ? 否（相等不弹）| 入栈 | [2,3,3] |
| 4 | 5 | $5 > 3$ ? 否 | 入栈 | [2,3,3,5] |
| 5 | 4 | $5 > 4$ ✓ 且 $(4-1)+(8-5)=6 \ge 4$ | 弹 5，入 4 | [2,3,3,4] |
| 6 | 9 | $9 > 4$ ? 否，且栈长 $= k$ | 丢弃 9 | [2,3,3,4] |
| 7 | 6 | $6 > 4$ ? 否，且栈长 $= k$ | 丢弃 6 | [2,3,3,4] |

结束：栈长 $= k = 4$，返回 **[2,3,3,4]**。

![示例演算：k = 4 时的逐步走查](images/1673_walkthrough.svg)

## 4. 算法细节

1. **数据结构**：一维数组模拟栈即可。由弹栈规则可归纳证明：**栈内元素从底到顶非降**（压入 $x$ 前，所有 $> x$ 的栈顶已被弹出，留下的都 $\le x$）——这正是「单调栈」名称的由来；也因非降，弹栈循环每弹一个都确有收益。
2. **守门条件的推导**：弹掉栈顶后栈长为 $|S|-1$，凑满 $k$ 还需 $k-|S|+1$ 个元素，而含 $x$ 在内尚未入场的元素恰有 $n-i$ 个，故充要条件为 $n-i \ge k-|S|+1$，整理即 $(|S|-1)+(n-i)\ge k$。
3. **入栈限流**：只在 $|S|<k$ 时压入，保证栈长不超过 $k$；与守门条件合起来，扫描结束时 $|S|=k$（见引理 1），无需截断。
4. **相等不弹**：弹栈用严格大于比较。栈顶 $=x$ 时弹与不弹得到的值序列相同（换入等值元素不改变任何一位），约定严格 $>$ 以省去无谓操作。
5. **满栈仍要判断弹栈**：$|S|=k$ 时守门条件 $(k-1)+(n-i)\ge k$ 等价于 $n-i\ge 1$，恒成立——满栈时「弹一压一」的换顶操作总是被放行（演算表中 $i=5$ 即满栈换顶），不要在栈满后提前退出扫描。

## 5. 正确性证明

**引理 1（可行性不变量）**：任意时刻（设即将处理下标 $i$、栈长 $s$），有 $s+(n-i)\ge k$；扫描结束时 $s=k$，即最终栈是长度为 $k$ 的合法子序列。

**证明**：对操作归纳。初始 $i=0$、$s=0$：$0+n\ge k$ 由约束 $k\le n$。弹栈的守门条件恰为 $(s-1)+(n-i)\ge k$，弹出后保持。入栈（$s<k$）后对下一位置：$(s+1)+(n-i-1)=s+(n-i)\ge k$。栈满丢弃后：$k+(n-i-1)\ge k$。故不变量始终成立。结束时 $i=n$：$s\ge k$；又入栈限流保证 $s\le k$，故 $s=k$。∎

**引理 2（弹栈的充分性——交换论证）**：设处理 $x=\text{nums}[i]$ 时栈为 $S$、栈顶 $t$ 满足 $t>x$ 且 $(|S|-1)+(n-i)\ge k$，则任何以完整栈 $S$ 为前缀的长度 $k$ 子序列，都存在（字典序）严格更小的长度 $k$ 子序列。

**证明**：栈中元素的下标均 $< i$。构造

$$A' \;=\; \big(S \setminus \{t\}\big) \;+\; [x] \;+\; Z,$$

其中 $Z$ 取 $\text{nums}[i{+}1..n{-}1]$ 中任意 $k-|S|$ 个元素。由守门条件 $n-i-1\ge k-|S|$，$Z$ 存在；三段元素下标分别 $< i$、$= i$、$> i$，故 $A'$ 是长度为 $(|S|-1)+1+(k-|S|)=k$ 的合法子序列。任取以 $S$ 为前缀的长度 $k$ 子序列 $F$：前 $|S|-1$ 位 $A'$ 与 $F$ 相同，第 $|S|$ 位 $A'$ 为 $x<t$，故 $A' <_{\mathrm{lex}} F$。∎

**引理 3（守门条件恰好刻画可补全性）**：$(|S|-1)+(n-i)\ge k$ 成立，当且仅当存在以 $(S\setminus\{t\})+[x]$ 为前缀的长度 $k$ 子序列。

**证明**：该前缀长度为 $|S|$，须在其后（下标 $> i$）补足 $k-|S|$ 个元素，可补 $\Leftrightarrow n-1-i\ge k-|S| \Leftrightarrow (|S|-1)+(n-i)\ge k$。∎

**定理**：算法结束时返回的栈是字典序最小的长度 $k$ 子序列。

**证明**：由引理 1，输出可行。最优性按三步操作逐一核对「不丢最优」：

- **弹栈**：由引理 2，以「含 $t$ 的完整栈」为前缀的候选都被严格更小的 $A'$ 压制，弹出无损；而弹栈被守门条件拦截时，由引理 3，想换成的前缀形态根本不存在可行完成，忍住同样无损。
- **不弹而入/丢**（栈顶 $t \le x$）：把 $x$ 放在第 $|S|$ 位的任何候选 $F=(S\setminus\{t\})+[x]+R$（$R$ 为其后 $k-|S|$ 个元素），被 $F'=S+R$ 压制——后者合法（$R$ 的下标均在 $i$ 之后）且在第 $|S|$ 位以 $t<x$ 严格更小；若 $t=x$，则 $F'$ 与 $F$ 的值序列相同，换入无收益。至于「先不弹、等更晚的更小元素 $w$ 到达再弹」的形态：$w$ 到达时若 $t$ 仍是栈顶，同样的交换论证照常裁决；若 $t$ 上方叠有更大元素（栈非降，故它们 $\ge t > w$），弹栈循环先弹它们——任何「让某一位比算法更小」的企图，都恰对应算法某一次被守门条件放行的弹栈。

对扫描位置归纳：算法终止时的栈与字典序最小子序列在每一位上相等——若在某位首次出现更小值，它必然源于上述某次偏离决策点的形态，而每种形态都已被交换论证排除。故输出即字典序最小。∎

> 💡 **一句话总结**：弹栈条件 = 「交换严格更优」∧「弹后仍可凑满 $k$」；入栈限流 = 「栈满不再承诺」。二者恰好把「每一位都能兑现」与「每一位都尽量小」同时锁死。

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。每个元素至多被压栈一次、弹栈一次，弹栈循环的总步数被压栈总数摊还，不超过 $n$；扫描本身一遍 $O(n)$。
- **空间复杂度**：$O(k)$。栈最多容纳 $k$ 个元素（即返回值本身），辅助变量仅 $O(1)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> mostCompetitive(vector<int>& nums, int k) {
        int n = nums.size();
        vector<int> st;
        for (int i = 0; i < n; ++i) {
            while (!st.empty() && st.back() > nums[i]
                   && (int)st.size() - 1 + n - i >= k) {
                st.pop_back();
            }
            if ((int)st.size() < k) {
                st.push_back(nums[i]);
            }
        }
        return st;
    }
};
```

### Python

```python
class Solution:
    def mostCompetitive(self, nums: List[int], k: int) -> List[int]:
        n = len(nums)
        st = []
        for i, x in enumerate(nums):
            while st and st[-1] > x and len(st) - 1 + n - i >= k:
                st.pop()
            if len(st) < k:
                st.append(x)
        return st
```

## 8. 边界情况与易错点

1. **相等不弹**：弹栈必须用严格 $>$。写成 $\ge$ 时值序列往往不变，但会做无谓的弹出（把较早的等值元素换成较晚的），白白多动栈；约定 $>$ 即可。
2. **守门条件写错**：漏写整个条件，或误写成 $|S|+(n-i)\ge k$（后者更宽松、同样过弹），都会在 `nums = [3,2,1], k = 2` 上翻车：末尾处理 $1$ 时栈为 $[2]$，正确条件 $(1-1)+(3-2)=1 < 2$ 拦住弹出；写错则弹出 $2$，最终凑不满 $k$ 个。
3. **满栈不能提前退出**：$i=5$ 的满栈换顶（弹 5 压 4）是必须的优化；若在 $|S|=k$ 时直接 `break`，示例 2 会错误返回 $[2,3,3,5]$。
4. **$k=n$**：此时 $s\le i$ 使守门条件 $(s-1)+(n-i)\ge n$ 恒假，永不弹栈，返回原数组——正确，因为一个元素都不能丢。
5. **$k=1$**：算法自然退化为「维护当前最小值」，守门条件 $(s-1)+(n-i)\ge 1$ 恒成立，返回数组最小值。
6. **数据范围**：$0 \le \text{nums}[i] \le 10^9 < 2^{31}-1$，`int` 足够；栈最多 $10^5$ 个元素，无溢出风险。
