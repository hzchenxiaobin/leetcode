# LeetCode 最富有客户的资产总量 题解

## 1. 题目概述

- **标题 / 题号**：最富有客户的资产总量（#1672，easy）
- **链接**：https://leetcode.cn/problems/richest-customer-wealth/
- **来源**：LeetCode 第 217 场周赛 Q1
- **难度**：简单
- **标签**：数组、矩阵

**题意**：给定一个 $m \times n$ 的整数网格 `accounts`，其中 `accounts[i][j]` 表示第 $i$ 位客户在第 $j$ 家银行托管的资产数量。一位客户的**资产总量**等于他在各家银行资产数量之和。求**最富有客户**（资产总量最大者）的资产总量。

**约束**：

- `m == accounts.length`
- `n == accounts[i].length`
- `1 <= m, n <= 50`
- `1 <= accounts[i][j] <= 100`

## 2. 示例

**示例 1**

```text
输入：accounts = [[1,2,3],[3,2,1]]
输出：6
解释：第 1 位客户资产总量 = 1+2+3 = 6，第 2 位 = 3+2+1 = 6，并列最富，返回 6。
```

**示例 2**

```text
输入：accounts = [[1,5],[7,3],[3,5]]
输出：10
解释：三位客户资产总量分别为 6、10、8，第 2 位最富，返回 10。
```

**示例 3**

```text
输入：accounts = [[2,8,7],[7,1,3],[1,9,5]]
输出：17
解释：第 1 位客户资产总量 = 2+8+7 = 17，为最大值。
```

## 3. 解题思路

### 3.1 暴力思路

签到题。按定义模拟：逐行求和，再用打擂台维护最大值，一次遍历即为最优。没有更"聪明"的必要——任何排序、堆等做法都只是把 $O(mn)$ 的必读开销之上再叠加多余操作。

### 3.2 核心观察：行和取最大

矩阵的**每一行就是一位客户**在所有银行的资产分布，因此第 $i$ 位客户的资产总量就是**第 $i$ 行的元素之和**（行和），答案即所有行和的最大值：

$$\text{ans} = \max_{0 \le i < m} \; \sum_{j=0}^{n-1} \text{accounts}[i][j]$$

![核心观察：按行求和再取最大](images/1672_wealth_concept.svg)

> 💡 **一句话总结**：行 = 客户，列 = 银行；沿**行**方向求和，与列无关。不要把行列方向搞反。

### 3.3 算法流程：逐行打擂台

1. 初始化 `ans = 0`；
2. 遍历每一行 `row`，计算行和 `s = sum(row)`；
3. 打擂台：`ans = max(ans, s)`；
4. 遍历结束，返回 `ans`。

全程只用两个变量（当前行和、全局最大值），无需任何额外数据结构。

### 3.4 示例演算

以 `accounts = [[1,5],[7,3],[3,5]]` 为例，逐行求和并打擂台：

| 客户 | 各银行资产 | 行和 | ans 变化 |
|------|-----------|------|----------|
| 0 | 1, 5 | 1 + 5 = 6 | 0 → 6 |
| 1 | 7, 3 | 7 + 3 = 10 | 6 → 10（新最大）|
| 2 | 3, 5 | 3 + 5 = 8 | 8 < 10，不变 |

最终 `ans = 10`。

![示例演算：逐行求和与打擂台](images/1672_wealth_walkthrough.svg)

## 4. 算法细节

1. **行和计算**：对固定行 `row`，`s = Σ row[j]`，C++ 可手写循环或 `accumulate`，Python 直接 `sum(row)`。
2. **打擂台更新**：`ans = max(ans, s)`，边算边更，无需先存下所有行和。
3. **初始化**：约束 `accounts[i][j] >= 1`，行和恒为正，`ans` 初始化为 `0` 是安全的；若元素允许为负，应初始化为极小值或首行之和。
4. **数据范围核查**：$m, n \le 50$，每个元素 $\le 100$，最大行和 $50 \times 100 = 5000$，`int` 绰绰有余，无溢出风险。

## 5. 正确性证明

**引理 1**：第 $i$ 位客户的资产总量等于 `accounts` 第 $i$ 行所有元素之和 $w_i = \sum_j \text{accounts}[i][j]$。

**证明**：`accounts[i][j]` 定义为第 $i$ 位客户在第 $j$ 家银行托管的资产数量，客户的资产总量即在**所有**银行上的资产之和。固定 $i$、对全部 $j$ 求和，恰为第 $i$ 行的行和。∎

**定理**：算法返回最富有客户的资产总量，即 $\max_i w_i$。

**证明**：算法按行遍历，由引理 1，第 $i$ 轮计算出的 `s` 恰为 $w_i$。对已处理的行数 $k$ 归纳：$k=0$ 时 `ans = 0`；因约束保证 $w_i \ge n \ge 1 > 0$，首轮比较后 `ans` 必被某个真实行和取代。设处理完前 $k$ 行后 `ans` $= \max(w_0, \dots, w_{k-1})$，则处理第 $k$ 行后 `ans` $= \max(\max(w_0,\dots,w_{k-1}), w_k)$ = $\max(w_0, \dots, w_k)$，归纳成立。全部 $m$ 行处理完毕后 `ans` $= \max_{0 \le i < m} w_i$，即最富有客户的资产总量。∎

## 6. 复杂度分析

- **时间复杂度**：$O(mn)$。每个元素恰好被读取、累加一次，已是信息论下界（每个数都会影响答案，必须全读）。
- **空间复杂度**：$O(1)$。仅使用 `ans` 与当前行和两个变量（不计输入本身）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maximumWealth(vector<vector<int>>& accounts) {
        int ans = 0;
        for (const auto& row : accounts) {
            int s = 0;
            for (int x : row) s += x;
            ans = max(ans, s);
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maximumWealth(self, accounts: List[List[int]]) -> int:
        ans = 0
        for row in accounts:
            ans = max(ans, sum(row))
        return ans
```

## 8. 边界情况与易错点

1. **最小规模**：`m = n = 1` 时答案就是 `accounts[0][0]`，打擂台逻辑天然覆盖。
2. **并列最富**：多个客户行和相同（如示例 1），返回该值即可，题目不要求区分是谁。
3. **`ans` 初始化**：本题元素恒正，初始化 0 安全；若推广到元素可零/可负的变体，需初始化为极小值或首行之和，否则会错误地返回 0。
4. **行列方向**：对"客户"求和是**沿行**方向；若误按列求和（相当于对转置矩阵计算），结果可能错误。
5. **无需防溢出**：最大行和仅 5000，`int` 足够；但若值域放大到 $10^9$ 且 $n$ 到 $10^5$，C++ 需改用 `long long`。
