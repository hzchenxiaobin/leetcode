# LeetCode 数组的最小偏移量 题解

## 1. 题目概述

- **标题 / 题号**：数组的最小偏移量（#1675，hard）
- **链接**：https://leetcode.cn/problems/minimize-deviation-in-array/
- **来源**：LeetCode 第 217 场周赛 Q4
- **难度**：困难
- **标签**：贪心、数组、堆（优先队列）、有序集合

**题意**：给定由 $n$ 个**正整数**组成的数组 `nums`，可对任意元素执行任意次两类操作：元素为**偶数**时可 $\div 2$，元素为**奇数**时可 $\times 2$。数组的**偏移量**定义为任意两元素的最大差值，即 $\max - \min$。求若干次操作后数组能达到的**最小偏移量**。

**约束**：

- $2 \le n \le 5 \times 10^4$
- $1 \le \text{nums}[i] \le 10^9$

> 💡 难点在于每个元素的可达取值**不是连续区间**，而是一条「÷2 链」；两类操作一升一降，直接搜索状态空间毫无边界。破局点是把两类操作**统一成单向变化**，再用堆贪心「只压最大值」。

## 2. 示例

**示例 1**

```text
输入：nums = [1,2,3,4]
输出：1
解释：1(奇)×2 → 2，4(偶)÷2 → 2，数组变为 [2,2,3,2]，偏移量 = 3 − 2 = 1。
```

**示例 2**

```text
输入：nums = [4,1,5,20,3]
输出：3
解释：1×2 → 2，20÷2 → 10、再 ÷2 → 5，数组变为 [4,2,5,5,3]，偏移量 = 5 − 2 = 3。
```

**示例 3**

```text
输入：nums = [2,10,8]
输出：3
解释：10÷2 → 5，8÷2 → 4，数组变为 [2,5,4]，偏移量 = 5 − 2 = 3。
```

## 3. 解题思路

### 3.1 暴力思路

先看清每个元素「能变成哪些值」：设 $c$ 为 $x$ 去掉全部因子 2 后的**奇核心**，则 $x$ 的可达取值是一条链——偶数 $x$ 可达 $\{x, x/2, \ldots, c\}$（一路折到底），奇数 $x$ 可达 $\{x, 2x\}$（翻倍后变偶，折半又回到 $x$）。

暴力做法是**枚举每个元素从各自链上取一个值的组合**，对每组组合算 $\max - \min$ 取最小。但偶数的链长可达 $O(\log 10^9) \approx 30$，$n = 5\times10^4$ 时组合数是天文数字；值域高达 $10^9$ 也排除了任何按值域 DP 的念头。**瓶颈**：我们在「组合」的维度上搜索，而组合之间大量互相支配。

换视角：不要枚举组合，而是**单调地压低最大值**——偏差只由 $\max$ 和 $\min$ 两个统计量决定，能动的其实只有「谁当 $\max$、当到多低」。

### 3.2 核心观察：奇数翻倍统一 + 大顶堆贪心折半

![核心观察：奇数翻倍统一操作与贪心折半](images/1675_chain_concept.svg)

**观察一：两类操作可以统一成「只能 $\div 2$」。** 奇数唯一能做的上升操作是 $\times 2$（变偶），做完之后就和偶数一样只能 $\div 2$。因此**预处理时把所有奇数先 $\times 2$**：

- 此后**全数组都是偶数**，唯一可做的操作就是 $\div 2$；
- 每个元素的取值只能沿链**单调减小**，不再有「先变大再变小」的反复。

> ⚠️ **奇数翻倍不丢最优**：翻倍只是把链的起点从 $x$ 抬到 $2x$，链的成员不变——若最优解中该奇数取原值 $x$，把翻倍后的 $2x$ 再 $\div 2$ 即可还原。原值仍在链上，故预处理不丢解。

**观察二：缩小偏差，唯一有建设性的动作是降低 $\max$。** 统一化后所有值只能减小，故 $\min$ 只会不变或变小——降 $\min$ 只会让偏差更大或不变。于是贪心策略浮现：

> 每次取出当前最大值 $\max$，将其 $\div 2$ 放回，沿途记录 $\max - \min$，取最小；当 $\max$ 变为**奇数**（无法再 $\div 2$）时停止。

**为何贪心正确（直觉）**：每一步折半后的数组都是一个**真实可达的配置**（每个元素都停在自身链上的某一点），所以沿途记录的每一个偏差都**可达**；而最优解里每个元素取的值也都在各自链上——贪心逐层下压 $\max$ 的过程，必然会「路过」一个不劣于最优解的配置（严格证明见 §5）。

> 💡 **识别信号**：每个变量的取值受限于一维「单调链」，目标是 $\min(\max - \min)$ → 想「堆贪心 + 折半极值」。与 1648「每次取最大值削一格」同源，只是削的方式是 $\div 2$ 而非 $-1$。

### 3.3 算法流程

![算法流程：预处理与大顶堆贪心循环](images/1675_heap_flow.svg)

流程要点：

1. **预处理**：遍历 `nums`，奇数 $\times 2$；全部入**大顶堆**，同时维护全局最小值 `mn`，`ans` 初始化为 $+\infty$。
2. **贪心循环**：当堆顶（即当前 $\max$）为**偶数**时：先记录 $\text{ans} \leftarrow \min(\text{ans},\ \text{堆顶} - \text{mn})$；再弹出堆顶 $mx$，令 $v = mx/2$ 放回堆，并更新 $\text{mn} \leftarrow \min(\text{mn}, v)$。
3. **终止**：堆顶为奇数时无法再折半，在循环外**补一次** $\text{ans} \leftarrow \min(\text{ans}, \text{堆顶} - \text{mn})$ 后返回。

> ⚠️ **最后一次记录别漏**：循环退出时堆顶已是奇数，但「奇数 $\max$ 配当前 $\min$」这个可达配置的偏差还没记录，必须在循环外补记一次。

### 3.4 示例演算

以 `nums = [4,1,5,20,3]` 为例：

![示例演算：nums = [4,1,5,20,3]，答案 = 3](images/1675_walkthrough.svg)

**预处理**：奇数 $1\to2$、$5\to10$、$3\to6$，得 $[4,2,10,20,6]$，$\min = 2$，入堆。

| 轮次 | 堆内容（降序） | $\max$ | $\min$ | dev | ans | 动作 |
|------|--------------|--------|--------|-----|-----|------|
| 初始 | 20,10,6,4,2 | 20 | 2 | 18 | 18 | $20 \div 2 \to 10$ |
| 1 | 10,10,6,4,2 | 10 | 2 | 8 | 8 | $10 \div 2 \to 5$ |
| 2 | 10,6,5,4,2 | 10 | 2 | 8 | 8 | $10 \div 2 \to 5$ |
| 3 | 6,5,5,4,2 | 6 | 2 | 4 | 4 | $6 \div 2 \to 3$ |
| 4 | 5,5,4,3,2 | 5✦ | 2 | **3** | **3** | $\max$ 为奇，停止 |

最终可达配置 $[4,2,5,5,3]$，$\max - \min = 5 - 2 = 3$ ✓（✦ 表示奇数，折半链终止。）

> 💡 注意 $20 \to 10 \to 5$ 这条链：折半到 $5$ 时变奇停止，恰好贡献了最优 $\max = 5$；而 $6 \to 3$ 把另一个较大的 $6$ 压到 $3$，没有拖低 $\min$（$\min$ 已是 $2$）。沿途 dev 依次为 $18 \to 8 \to 8 \to 4 \to 3$，最小值 $3$ 即答案。

## 4. 算法细节

1. **预处理与等价性**：`x & 1` 为真则 `x <<= 1`。此后每个元素从**链顶**出发，只能沿链向下折半。链顶取值：偶数 $x$ 的链顶是 $x$，奇数 $x$ 的链顶是 $2x$；两种链顶都 $\le 2 \times 10^9$。
2. **堆与 `mn` 的维护**：大顶堆只暴露 $\max$，$\min$ 用变量 `mn` 单独维护。由于所有值**只减不增**，`mn = min(mn, v)` 在每次折半放回时更新即可始终等于堆内真实最小值，无需重扫。
3. **记录时机覆盖全部中间状态**：循环在每次折半**前**记录 `堆顶 − mn`，循环外补记终止态。于是堆中**每一个出现过的配置**（初始态、每次折半后的新态、终止态）的偏差都被记录，`ans` 取的就是全程可达配置偏差的最小值——这是 §5 正确性论证的落点。
4. **终止条件为何是「堆顶为奇数」**：预处理后全数组为偶，$\div 2$ 可能让某值变奇。奇数无法再 $\div 2$；若对奇数 $\times 2$，则回到链上方已探索过的状态（且方向与「降 $\max$」相反），不产生新信息。故堆顶变奇即全局 $\max$ 无法再降，贪心结束。
5. **数值范围**：$10^9$ 的奇数翻倍后为 $2 \times 10^9 < 2^{31} - 1 \approx 2.147 \times 10^9$，C++ `int` **勉强**安全；若数值上界再抬一格就会溢出，稳妥起见可用 `long long`（见 §8）。
6. **有序集合变体**：C++ `multiset` / Java `TreeMap` 能同时 $O(1)$ 取 $\max$ 与 $\min$，逻辑更对称（记录后删 `rbegin()`、插入折半值），复杂度同级；Python 无平衡树，`heapq` 存负数模拟大顶堆是标准做法。

## 5. 正确性证明

**引理 1（可达集合恰为一条 ÷2 链）**：对元素 $x$，设 $c$ 为其去掉全部因子 2 后的奇核心。记 $\text{top}(x) = x$（$x$ 为偶）或 $2x$（$x$ 为奇）。则 $x$ 经任意操作序列可达的取值集合恰为
$$\{\, \text{top}(x),\ \text{top}(x)/2,\ \ldots,\ c \,\}.$$

**证明**：任一时刻的值都形如 $c \cdot 2^j$（$j \ge 0$）：$\div 2$ 使 $j$ 减 $1$；$\times 2$ 仅当 $j = 0$（值为奇）时可用，使 $j$ 从 $0$ 变 $1$。
（1）若初始 $j_0 \ge 1$（$x$ 偶）：$j$ 的上升只发生在 $j=0$ 处且只能到 $j=1$，从 $1$ 又只能降回 $0$，故 $j$ 永不超过 $j_0$、也永不为负；可达 $j \in [0, j_0]$，对应 $\{c, 2c, \ldots, x\}$。
（2）若 $j_0 = 0$（$x$ 奇）：可达 $j \in \{0, 1\}$，即 $\{x, 2x\}$。
两种情形统一为：从 $\text{top}(x)$ 出发反复 $\div 2$ 恰好遍历全部可达值。特别地，预处理「奇数 $\times 2$」只是把链顶从 $x$ 抬到 $2x$，链的成员不变，故不丢解。∎

**引理 2（规范最优解存在）**：存在一个最优配置，使得记其最大值为 $M^\*$ 时，每个元素 $i$ 取**自身链上 $\le M^\*$ 的最大值** $v_i$；且该配置的最大值仍为 $M^\*$、最小值不小于原最优配置的最小值 $m^\*$。

**证明**：取任意最优配置 $(v'_i)$，$M^\* = \max_i v'_i$，逐元素把 $v'_i$ 提升为 $v_i$：由 $v'_i \le M^\*$ 且 $v_i$ 是链上 $\le M^\*$ 的最大值，得 $v'_i \le v_i \le M^\*$。于是 $\max_i v_i \le M^\*$（取到 $M^\*$ 的那个元素不变，故恰为 $M^\*$），$\min_i v_i \ge \min_i v'_i = m^\*$，新配置偏差 $\le M^\* - m^\* = D^\*$，又 $D^\*$ 是所有可达配置偏差的下界，故该配置仍最优。∎

**定理（贪心正确性）**：算法返回值等于最小偏差 $D^\*$。

**证明**：分两个方向。
（1）**ans $\ge D^\*$**：算法记录的每个偏差都对应一个真实可达配置——初始时每个元素在链顶，每次折半把某个元素沿自身链下移一格（引理 1），故每个记录值 $\ge D^\*$。
（2）**ans $\le D^\*$**：取引理 2 的规范最优解 $(v_i)$（最大值 $M^\*$、最小值 $m^\*$），考察算法运行：
- **阶段不变量**：只要当前 $\max > M^\*$，被折半元素的当前值 $w$ 满足 $w > M^\* \ge v_i$。同一链上的值形如 $c \cdot 2^j$，$w > v_i$ 蕴含 $w \ge 2 v_i$，故 $w/2 \ge v_i$——折半不会把任何元素压到其规范值以下。因此在「$\max > M^\*$」的整个阶段内，每个元素值恒 $\ge v_i$，从而 $\min \ge m^\*$。
- **必然穿越**：当 $\max > M^\*$ 时堆顶不可能是奇数——否则堆顶元素的当前值 $g$ 是其链上的奇数，由引理 1 链上唯一的奇数是链底奇核心，而 $v_k \le M^\* < g$ 是同一链上比 $g$ 更小的值，矛盾。故循环不会提前终止；又每次折半使堆内元素总和严格减小（值恒为 $\ge 1$ 的整数），过程有限，必在有限步内**首次出现** $\max \le M^\*$ 的配置。
- 此刻 $\max \le M^\*$ 且 $\min \ge m^\*$，而该配置必被记录（§4 第 3 条），记录的偏差 $\le M^\* - m^\* = D^\*$。

结合（1）（2）得 ans $= D^\*$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \log M \log n)$，其中 $M \le 2 \times 10^9$（预处理后的链顶上界），$\log M \approx 31$。每个元素至多被折半 $O(\log M)$ 次就触底（奇核心），总折半次数 $\le 31n$；每次折半对应一次堆弹出 + 一次堆插入，各 $O(\log n)$。$n = 5\times10^4$ 时约 $31 \times 5\times10^4 \times 2 \times 16 \approx 5\times10^7$ 量级的底层操作，可 AC（实际远小于该上界——多数元素很快变奇停止）。
- **空间复杂度**：$O(n)$，大顶堆始终只存 $n$ 个当前值。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minimumDeviation(vector<int>& nums) {
        priority_queue<int> pq;          // 大顶堆
        int mn = INT_MAX;
        for (int x : nums) {
            if (x & 1) x <<= 1;          // 奇数先 ×2，统一为偶数
            pq.push(x);
            mn = min(mn, x);
        }

        int ans = INT_MAX;
        while (pq.top() % 2 == 0) {      // 堆顶为偶数才能继续 ÷2
            int mx = pq.top();
            ans = min(ans, mx - mn);     // 记录折半前的偏差
            pq.pop();
            pq.push(mx >> 1);
            mn = min(mn, mx >> 1);       // 折半可能产生新的最小值
        }
        return min(ans, pq.top() - mn);  // 堆顶为奇数时的最终偏差
    }
};
```

### Python

```python
class Solution:
    def minimumDeviation(self, nums: List[int]) -> int:
        pq = []                          # heapq 是小顶堆，存负数模拟大顶堆
        mn = float('inf')
        for x in nums:
            if x & 1:
                x <<= 1                  # 奇数先 ×2
            heapq.heappush(pq, -x)
            mn = min(mn, x)

        ans = float('inf')
        while -pq[0] % 2 == 0:           # 堆顶（取负还原）为偶数
            mx = -heapq.heappop(pq)
            ans = min(ans, mx - mn)
            v = mx >> 1
            heapq.heappush(pq, -v)
            mn = min(mn, v)
        return min(ans, -pq[0] - mn)
```

## 8. 边界情况与易错点

1. **忘记预处理奇数 $\times 2$**：奇数将永远无法变化（既不能 $\div 2$，「翻倍再折半」的往返也没被建模），统一化失效，直接漏解。
2. **`mn` 不随折半更新**：折半产生的新值可能小于当前 `mn`（如 $\max = 6 \to 3$ 而 $\min$ 原为 $4$），漏更新会把偏差算大。
3. **循环外的最终补记漏掉**：循环在「堆顶为奇」时退出，该终止配置的偏差尚未记录，务必在 `return` 前补 `min(ans, pq.top() - mn)`。
4. **`int` 贴边溢出**：奇数翻倍后最大 $2 \times 10^9$，仅比 `INT_MAX`（$2147483647$）小约 $1.5 \times 10^8$；本题侥幸安全，但换成 `long long` 更稳，也要警惕题目改约束后踩雷。
5. **Python 负数取模**：堆里存的是负数，`-pq[0] % 2` 在 Python 中结果非负、判偶安全；直接写 `pq[0] % 2 == 0` 对负偶数同样成立（$-20 \bmod 2 = 0$），但混用容易出错，建议统一先取负还原。
6. **最小规模与平凡情形**：$n = 2$、或全数组相同（如 $[1,1]$ 预处理后 $[2,2]$，首轮即记录 $0$）都要能走通整个循环逻辑，不需要特判。
7. **不要在统一化后尝试「回升」**：对奇数 $\times 2$ 只是回到链上已探索的状态，方向与降 $\max$ 相反；贪心严格沿「取 max → 折半」单方向推进即可。
