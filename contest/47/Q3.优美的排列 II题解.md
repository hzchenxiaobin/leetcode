# LeetCode 优美的排列 II 题解

## 1. 题目概述

- **标题 / 题号**：优美的排列 II（#667，medium）
- **链接**：https://leetcode.cn/problems/beautiful-arrangement-ii/
- **来源**：LeetCode 第 47 场周赛 Q3
- **难度**：中等
- **标签**：数组、数学

**题意**：用 $1$ 到 $n$ 这 $n$ 个正整数各一次排成数组 $\text{answer}$，要求相邻两项之差的绝对值集合

$$\bigl\{\,|a_1-a_2|,\ |a_2-a_3|,\ \dots,\ |a_{n-1}-a_n|\,\bigr\}$$

中**恰好有 $k$ 个不同的整数**。答案不唯一，返回任意一个合法排列即可。

**约束**：

- $1 \le k < n \le 10^4$
- 题面只有这一条约束；$k < n$ 已隐含 $n \ge 2$
- 输出必须是 $1\sim n$ 的**排列**（不能重复、不能越界）

> 说明：本题题面没有「Create the variable named …」之类的注入噪声，无需额外处理。

## 3. 解题思路

### 3.1 暴力思路

最直接的做法是枚举 $1\sim n$ 的全部排列，对每个排列统计差值的不同个数，取第一个满足要求的：复杂度 $O(n! \cdot n)$。$n = 10^4$ 时排列数为天文数字，完全不可行。

即使改成带状态压缩的搜索（状压 DP 记录「已用数字集合」和「差值集合」），状态数是 $O(2^n \cdot n \cdot 2^n)$ 级别，最多只能扛 $n \approx 15$，与 $10^4$ 相差甚远。

关键在于：题目**只要求返回任意一组解**。这几乎是在明示「答案是构造出来的，不是搜出来的」。

### 3.2 核心观察：前缀铺平 + 剩余区间首尾交替

![前缀差恒为 1，剩余 k 个数首尾交替](images/wc47_q3_prefix_weave.svg)

三个小观察把构造直接推出来：

1. **差值只有 $n-1$ 个**，所以不同值的个数最多 $n-1$，即必须有 $k \le n-1$。题面给的 $k < n$ 正好落在这个上界内，说明**任何合法的 $k$ 都有解**。
2. **连续递增段的差值全部等于 $1$**：$1,2,3,\dots,m$ 只贡献 $1$ 种差值，是「零成本」的填充料。取 $m = n-k$，这一段用掉 $n-k$ 个数。
3. **剩下的 $k$ 个数恰好是区间 $[m+1,\,n] = [n-k+1,\,n]$**，长度正好是 $k$。把这个区间的**最大值与最小值交替取出**，得到 $n,\ m+1,\ n-1,\ m+2,\ \dots$；相邻差依次是 $k,\ k-1,\ k-2,\ \dots$，一路递减到 $1$，正好是 $k$ 个不同的值。

两段接上时，接缝处的差是 $n - m = n - (n-k) = k$，**和交替段的首差是同一个值**，因此拼接不会多出新的差值。于是整体差值集合恰好是 $\{1, 2, \dots, k\}$，大小为 $k$。

> 💡 反向等价理解：$1,n,2,n-1,\dots$ 这种「首尾交替」是全排列中差值种类最多（$n-1$ 种）的经典形状，本题只是把它**截断到 $k$ 种**，多出来的数用递增段消化掉。

### 3.3 算法流程

![双指针交替的流程](images/wc47_q3_two_pointer_flow.svg)

```text
构造 constructArray(n, k):
    m ← n − k
    ans ← [1, 2, …, m]              # 前缀：差值全为 1
    lo ← m + 1, hi ← n              # 剩余区间 [m+1, n]，共 k 个数
    while lo ≤ hi:
        ans.push(hi); hi ← hi − 1   # 先吐最大值，制造差值 k
        if lo ≤ hi:
            ans.push(lo); lo ← lo + 1
    return ans
```

两个指针从区间两端向中间夹：`hi` 单调减、`lo` 单调增，每个数恰好被取出一次，循环结束时恰好吐出 $k$ 个数。

**顺序不能反**：若先取 `lo` 再取 `hi`，接缝差会退化成 $1$（与前缀重复），交替段首差变成 $k-1$，最终只剩 $k-1$ 种不同差值。

### 3.4 示例演算

![n = 9, k = 3 的逐步走查](images/wc47_q3_walkthrough_n9k3.svg)

以 $n = 9,\ k = 3$ 为例，$m = n-k = 6$：

| 步骤 | 操作 | 当前 ans |
|------|------|----------|
| 0 | 前缀 $1\sim 6$ | `[1,2,3,4,5,6]` |
| 1 | `lo=7, hi=9` → 出 $9$，$hi=8$；$7\le 8$ 再出 $7$，$lo=8$ | `[1,2,3,4,5,6,9,7]` |
| 2 | 出 $8$，$hi=7$；$lo=8 > 7$ 停止 | `[1,2,3,4,5,6,9,7,8]` |

最终差值数组 $[1,1,1,1,1,3,2,1]$：前 $5$ 个来自前缀内部，第 $6$ 个是接缝（$9-6=3$），后面 $2,1$ 来自交替段内部，不同值恰为 $\{1,2,3\}$，共 $3 = k$ 个。

## 4. 算法细节

1. **前缀长度 $m = n-k$**：因为 $k < n$，所以 $m \ge 1$，前缀永不为空，不必为「空前缀」写特判。
2. **接缝的正确性依赖 $m$ 的取值**：只有把前缀恰好取到 $m = n-k$，接缝差才等于 $k$；若取 $m' \ne n-k$，接缝差变成 $n-m'$，会与交替段的某个差值错位，导致不同值个数偏移。
3. **循环内的第二次判定**：`if lo <= hi` 不能省。$k$ 为奇数时最后一轮只剩一个数，第二次 push 会把 $hi$ 重复输出（或越界）。
4. **交替段首元素必须是最大值**：代码里先 `ans.push(hi)` 再 `ans.push(lo)`；反过来只能得到 $k-1$ 种差值。
5. **无需去重表**：前缀与剩余区间不相交，交替过程 `lo` 只增、`hi` 只减，天然不会重复，省掉 `visited` 数组。
6. **计数自检**：输出长度 $= m + k = n$；差值总数 $= (m-1) + 1 + (k-1) = n-1$，与排列长度严格吻合，可写成 `assert` 在本地调试。
7. **预分配**：C++ 用 `reserve(n)`，Python 用 `list.append`，避免扩容带来的常数开销。

## 5. 正确性证明

**引理 1（输出是排列）**：算法的输出恰好包含 $1, 2, \dots, n$ 各一次。

**证明**：前缀贡献 $1\sim m$；交替段从区间 $[m+1,\,n]$ 的两端向内逐个取数，`hi` 严格递减、`lo` 严格递增，每个数至多取一次，且循环条件保证区间被完整取空，故 $[m+1,\,n]$ 中每个数恰好出现一次。两段不交，并集为 $[1,n]$，长度为 $m+k=n$。∎

**引理 2（交替段的差值形状）**：设交替段为 $b_0, b_1, \dots, b_{k-1}$，其中 $b_{2t} = n-t$、$b_{2t+1} = m+1+t$（$m = n-k$）。则对 $0 \le j \le k-2$ 恒有

$$|b_{j+1} - b_j| = k - 1 - j .$$

**证明**：分奇偶两种情形。

- $j = 2t$（偶数位到奇数位）：$|b_{2t+1} - b_{2t}| = |(m+1+t) - (n-t)| = n - m - 1 - 2t = k-1-2t$。
- $j = 2t+1$（奇数位到偶数位）：$|b_{2t+2} - b_{2t+1}| = |(n-t-1) - (m+1+t)| = n - m - 2 - 2t = k-2-2t$。

两种情形都等于 $k-1-j$（用到 $n - m = k$）。∎

**引理 3（差值集合恰为 $\{1,\dots,k\}$）**：输出的全部 $n-1$ 个差值组成的集合 $S$ 满足 $S = \{1,2,\dots,k\}$。

**证明**：先证 $S \subseteq \{1,\dots,k\}$。前缀内部 $a_{i+1}-a_i = 1$；接缝处 $a_{m+1} - a_m = n - m = k$；交替段内部由引理 2 得 $k-1, k-2, \dots, 1$。三者都落在 $[1,k]$ 内。

再证反向包含。$k = n - m$ 由接缝给出。对 $1 \le v \le k-1$，取 $j = k-1-v \in [0,\,k-2]$，引理 2 给出差值为 $v$。$v = 1$ 也已覆盖（$k \ge 2$ 时取 $j = k-2$；$k = 1$ 时由接缝 $k = 1$ 覆盖）。故每个 $1 \le v \le k$ 都出现在 $S$ 中。∎

**定理**：算法输出满足题意，即它是 $1\sim n$ 的排列且相邻差值恰有 $k$ 个不同整数。

**证明**：由引理 1 输出是排列；由引理 3 差值集合为 $\{1,\dots,k\}$，其大小为 $k$。故输出合法。∎

**推论（解的存在性与紧性）**：对任意 $1 \le k < n$ 本构造都给出合法解；而差值只有 $n-1$ 个，故 $k \le n-1$ 是不可突破的上界，题设的取值范围是紧的。

## 6. 复杂度分析

- **时间**：$O(n)$。前缀写入 $m$ 次、双指针循环共写入 $k$ 次，合计恰好 $n$ 次赋值；每个元素只被访问常数次，无排序、无搜索。
- **空间**：$O(n)$，且全部来自返回数组本身；除 `ans`、`lo`、`hi`、`m` 外不使用任何额外数据结构，额外空间 $O(1)$。
- **常数**：$n = 10^4$ 时总操作数约 $10^4$，远低于任何时限。

## 7. 参考代码

### C++

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> constructArray(int n, int k) {
        vector<int> ans;
        ans.reserve(n);
        int m = n - k;                       // 前缀 1..m 的相邻差值恒为 1
        for (int i = 1; i <= m; ++i) ans.push_back(i);
        int lo = m + 1, hi = n;              // 剩余区间 [m+1, n]，共 k 个数
        while (lo <= hi) {                   // 首尾交替：先取最大，制造差值 k
            ans.push_back(hi--);
            if (lo <= hi) ans.push_back(lo++);
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def constructArray(self, n: int, k: int) -> list[int]:
        ans = []
        m = n - k                      # 前缀 1..m 的相邻差值恒为 1
        ans.extend(range(1, m + 1))
        lo, hi = m + 1, n              # 剩余区间 [m+1, n]，恰好 k 个数
        while lo <= hi:                # 首尾交替：先取最大，制造差值 k
            ans.append(hi)
            hi -= 1
            if lo <= hi:
                ans.append(lo)
                lo += 1
        return ans
```

## 8. 边界情况与易错点

1. **$k = 1$**：$m = n-1$，交替段只剩一个数 $n$，输出 $1,2,\dots,n$，差值全为 $1$。不要为 $k=1$ 写特判，通用代码自然正确。
2. **$k = n-1$**：$m = 1$，前缀只有一个元素，此时「差 $1$」不再由前缀提供，而由交替段末项提供（如 $n=4,k=3$ 得 `[1,4,2,3]`，差 $[3,2,1]$）。任何「前缀至少两个元素」的隐含假设都会在这里翻车。
3. **$n = 2,\ k = 1$**：最小规模，输出 `[1,2]`，差值 $\{1\}$；循环体只执行一次 `push(hi)`，第二次 push 被 `lo <= hi` 挡掉。
4. **交替顺序写反**：必须先取 `hi` 再取 `lo`。反序会让接缝差变成 $1$、首差变成 $k-1$，最终只有 $k-1$ 种差值，属于最隐蔽的 WA。
5. **漏掉循环内的二次判定**：$k$ 为奇数时最后一轮 `lo == hi`，若无条件再 push 一次，会把同一个数输出两遍（长度 $n+1$、出现重复），排列性质立刻破坏。
6. **不要用「先排 $1\dots n$ 再交换」的启发式**：一次交换同时影响左右两个差值，种类计数极易跑偏；本题的构造是「一次写对」，不要引入交换。
7. **输出长度校验**：$m + k = n$ 必须成立；若把 $m$ 写成 $n-k+1$ 之类的偏移，会多输出一个数。
