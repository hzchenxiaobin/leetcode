# LeetCode 找出第 N 个二进制字符串中的第 K 位 题解

## 1. 题目概述

- **标题 / 题号**：找出第 N 个二进制字符串中的第 K 位（#1545，medium）
- **链接**：https://leetcode.cn/problems/find-kth-bit-in-nth-binary-string/
- **来源**：LeetCode 第 201 场周赛 Q2
- **难度**：中等
- **标签**：递归、分治、字符串、位运算

**题意**：定义二进制串序列：$S_1 = \texttt{"0"}$；当 $i > 1$ 时，$S_i = S_{i-1} + \texttt{"1"} + \mathrm{reverse}(\mathrm{invert}(S_{i-1}))$，其中 `invert` 把每位 0/1 互换，`reverse` 把整个串反转。给定 $n$ 和 $k$，返回 $S_n$ 的第 $k$ 位字符（下标从 1 开始，题目保证 $k$ 在 $S_n$ 长度范围内）。

**约束**：

- $1 \le n \le 20$
- $1 \le k \le 2^n - 1$

> 💡 切入信号：**串长指数增长（$2^{20} - 1 \approx 10^6$）却只问一个位置**——几乎在明示「不要真的构造串，顺着递推结构定位」。这是「递归/分治定位」族题目的标准长相（对照 779. 第K个语法符号）。

## 2. 示例

**示例 1**

```text
输入：n = 3, k = 1
输出："0"
解释：S3 = "0111001"，第 1 位为 "0"。
```

**示例 2**

```text
输入：n = 4, k = 11
输出："1"
解释：S4 = "011100110110001"，第 11 位为 "1"。
```

**示例 3**

```text
输入：n = 1, k = 1
输出："0"
解释：S1 = "0"。
```

**示例 4（补充：正中间捷径）**

```text
输入：n = 4, k = 8
输出："1"
解释：第 8 位 = 2^3 恰好是 S4 的正中间，由递推式直接给出 '1'，无需递归。
```

## 3. 解题思路

### 3.1 暴力思路：把串真的构造出来

$n \le 20 \Rightarrow |S_n| = 2^n - 1 \le 1{,}048{,}575$。逐层拼接，总字符拷贝量 $\sum_{i=1}^{n}(2^i - 1) \approx 2^{21} \approx 2 \times 10^6$，内存峰值约 2 MB——**能过**，比赛里作为保底手段完全合法：

```python
class Solution:
    def findKthBit(self, n: int, k: int) -> str:
        s = "0"
        for _ in range(n - 1):
            inv = s.translate(str.maketrans("01", "10"))
            s = s + "1" + inv[::-1]
        return s[k - 1]
```

但这是把一道 $O(n)$ 的结构题做成了 $O(2^n)$ 的模拟题：我们只关心 1 个位置，却为其余一百万个字符付了全款。一旦数据范围把 $n$ 放大到 30、60（这类题的常见后手），这条路立刻死掉。

### 3.2 核心观察：三段式结构，只定位不构造

![核心观察：Sn 的三段式自相似结构](images/wc201_q2_structure_concept.svg)

**观察一（长度）**：$|S_i| = 2|S_{i-1}| + 1$，归纳得 $|S_n| = 2^n - 1$。于是 $S_n$ 的**正中间**是第 $2^{n-1}$ 位。

**观察二（三段式）**：递推式把 $S_n$ 天然切成三段：**左半**是上一层的原串、**中间**恒为 `'1'`、**右半**是上一层的**镜像取反**（见上图）。

**观察三（定位）**：对查询位 $k$ 三选一：

- $k = 2^{n-1}$：正中间，直接返回 `'1'`；
- $k < 2^{n-1}$：落在左半，问题变成 $S_{n-1}$ 的第 $k$ 位——**同一问题，规模减半**；
- $k > 2^{n-1}$：落在右半，镜像回左半再取反：$S_n[k] = 1 \oplus S_{n-1}[2^n - k]$。

每层 $O(1)$ 判断 + 一次递归，$n$ 每层严格减 1，深度不超过 20。

### 3.3 算法流程

![算法流程图：三分支递归](images/wc201_q2_recursion_flow.svg)

`find(n, k)`：$n = 1$ 返回 `'0'`；否则与 $mid = 2^{n-1}$ 三分支比较，右半分支先镜像（$k \leftarrow 2^n - k$）再对返回值取反。迭代版把「取反」折叠成一个 `flipped` 计数器，最终返回 `'0' ⊕ flipped`。

### 3.4 示例演算

![示例演算：n=4, k=11 的递归下降与回代](images/wc201_q2_example_walkthrough.svg)

$n = 4,\ k = 11$：$(4,11) \to 11 > 8$，$k \leftarrow 16-11 = 5$ $\to$ $(3,5) \to 5 > 4$，$k \leftarrow 8-5 = 3$ $\to$ $(2,3) \to 3 > 2$，$k \leftarrow 4-3 = 1$ $\to$ $(1,1)$ 基例 `'0'`；回代时三次取反：`'0' → '1' → '0' → '1'`。答案 `'1'`，与示例 2 一致。

## 4. 算法细节

1. **长度与中点**：$|S_n| = 2^n - 1$（归纳），$mid = 2^{n-1} = |S_{n-1}| + 1$，代码用移位 `1 << (n - 1)` 计算。
2. **镜像公式推导**：右半 = $\mathrm{reverse}(\mathrm{invert}(S_{n-1}))$。记 $M = |S_{n-1}| = 2^{n-1} - 1$，长度为 $M$ 的串反转后，第 $i$ 位是原串第 $M + 1 - i$ 位。右半在 $S_n$ 中占据第 $mid+1 \ldots 2 \cdot mid - 1$ 位，令 $i = k - mid$，解得 $S_n[k] = \mathrm{invert}(S_{n-1})[2 \cdot mid - k] = 1 \oplus S_{n-1}[2^n - k]$。**自检口径**：镜像位 $k' = 2^n - k$ 与 $k$ 关于中点对称（$k + k' = 2^n$），可借此快速检查公式有没有写错。
3. **位运算视角**：$2^n - k = (2^n - 1) - (k - 1)$，即镜像位恰是 $(k-1)$ 的 $n$ 位**按位取反**：`k' = ((1 << n) - 1) ^ (k - 1)`。「反射 = 按位取反」暗示整条下降路径只由 $k$ 的二进制位决定（见延伸思考）。
4. **迭代版**：`flipped` 记录进右半的次数；途中遇 $k = mid$ 直接返回 $1 \oplus flipped$；循环到 $n = 1$ 返回 `'0' ⊕ flipped`。省掉递归栈，空间 $O(1)$。
5. **提前出口 $k = 1$**（可选优化）：$S_1 = \texttt{"0"}$，且每层构造都把上一层完整地放在左半，所以任何 $S_n$ 的第 1 位都是 `'0'`，`k == 1` 可提前返回。
6. **数据范围**：$n \le 20$，$2^{20} < 2^{31}$，`int` 即可，无溢出风险。

## 5. 正确性证明

**引理 1（长度公式）**：对一切 $n \ge 1$，$|S_n| = 2^n - 1$。

**证明**：对 $n$ 归纳。$n = 1$ 时 $|S_1| = 1 = 2^1 - 1$。设 $|S_{n-1}| = 2^{n-1} - 1$，则 $|S_n| = 2|S_{n-1}| + 1 = 2(2^{n-1} - 1) + 1 = 2^n - 1$。∎

**引理 2（三段结构与中点）**：$S_n = S_{n-1} \cdot \texttt{'1'} \cdot \mathrm{reverse}(\mathrm{invert}(S_{n-1}))$，且 $\texttt{'1'}$ 恰位于第 $2^{n-1}$ 位；左半占据第 $1 \ldots 2^{n-1} - 1$ 位，右半占据第 $2^{n-1} + 1 \ldots 2^n - 1$ 位。

**证明**：递推式即定义。左段长 $|S_{n-1}| = 2^{n-1} - 1$，故 $\texttt{'1'}$ 位于第 $(2^{n-1} - 1) + 1 = 2^{n-1}$ 位；右段占其余 $|S_{n-1}| = 2^{n-1} - 1$ 位。∎

**引理 3（镜像取反公式）**：对 $2^{n-1} < k \le 2^n - 1$，有 $S_n[k] = 1 \oplus S_{n-1}[2^n - k]$。

**证明**：记 $M = 2^{n-1} - 1 = |S_{n-1}|$。对长度为 $M$ 的串 $x$，$\mathrm{reverse}(x)$ 的第 $i$ 位是 $x$ 的第 $M + 1 - i$ 位。于是 $S_n$ 右半的第 $i$ 位（即 $S_n$ 的第 $2^{n-1} + i$ 位）为 $\mathrm{invert}(S_{n-1})[M + 1 - i]$。取 $i = k - 2^{n-1}$（由 $k \le 2^n - 1$ 知 $i \le M$，下标合法），得

$$S_n[k] = \mathrm{invert}(S_{n-1})[M + 1 - (k - 2^{n-1})] = \mathrm{invert}(S_{n-1})[2^n - k] = 1 \oplus S_{n-1}[2^n - k].$$

∎

**定理（算法正确性）**：对一切 $1 \le k \le 2^n - 1$，`find(n, k)` 返回 $S_n$ 的第 $k$ 位。

**证明**：对 $n$ 强归纳。$n = 1$ 时 $k = 1$，$S_1 = \texttt{"0"}$，返回 `'0'` 正确。设结论对 $n - 1$ 成立，对 $(n, k)$（$n \ge 2$）分三种情形：

- $k = 2^{n-1}$：由引理 2，该位是 `'1'`，返回正确；
- $k < 2^{n-1}$：由引理 2，$S_n[k] = S_{n-1}[k]$，且 $1 \le k \le 2^{n-1} - 1 = |S_{n-1}|$，由归纳假设递归正确；
- $k > 2^{n-1}$：由引理 3，$S_n[k] = 1 \oplus S_{n-1}[2^n - k]$，且 $2^{n-1} + 1 \le k \le 2^n - 1$ 推出 $1 \le 2^n - k \le 2^{n-1} - 1$，下标合法，由归纳假设递归值正确，取反后正确。∎

**终止性**：每层 $n$ 严格减 1，至多 $n$ 层触底；迭代版循环体每轮 $n$ 减 1，同理有限步终止。

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。每层只做常数次比较与一次 $k$ 的变换，递归深度 $\le n \le 20$。对比暴力构造的 $O(2^n)$。
- **空间复杂度**：递归版 $O(n)$ 栈深（$n \le 20$，可忽略不计）；迭代版 $O(1)$。

## 7. 参考代码

### C++（递归版）

```cpp
class Solution {
public:
    char findKthBit(int n, int k) {
        if (n == 1) return '0';           // 基例必须先于 mid 判断，见 §8
        int mid = 1 << (n - 1);           // |Sn| = 2^n - 1 的正中间
        if (k == mid) return '1';
        if (k < mid) return findKthBit(n - 1, k);
        // 右半：镜像到左半，返回值取反（'0'/'1' 恰差最低位，^1 即互换）
        return findKthBit(n - 1, (1 << n) - k) ^ 1;
    }
};
```

### Python（迭代版）

```python
class Solution:
    def findKthBit(self, n: int, k: int) -> str:
        flip = 0
        while n > 1:
            mid = 1 << (n - 1)
            if k == mid:
                return str(1 ^ flip)
            if k > mid:
                k = (1 << n) - k   # 镜像位
                flip ^= 1          # 记一次取反
            n -= 1
        return str(flip)           # 基例 '0' ⊕ 累计取反
```

## 8. 边界情况与易错点

1. **基例判断必须先于 mid 判断**：$n = 1$ 时 $k = 1 = 2^0 = mid$，若先判 `k == mid` 会返回 `'1'`——但 $S_1 = \texttt{"0"}$ 根本没有分隔符。三段式结构只在 $n \ge 2$ 时存在，因为 $S_1$ 是递推的**起点**而非产物。
2. **取反不能漏**：右半分支的答案是递归值取反，漏掉后 $(n, k) = (2, 3)$ 会错返回 `'0'`（正确 `'1'`）。`k == mid`、`k < mid`、`k > mid` 三分支互斥，要写全。
3. **镜像位是 $2^n - k$，不是 $2^n - 1 - k$ 也不是 $k - mid$**：且 $n$ 是**当前层**的 $n$，每进一层都要用新 $n$ 重算 $mid$ 与镜像。自检口径：$k + k' = 2^n$（关于中点对称）。
4. **1-indexed 全程统一**：题目 $k$ 从 1 开始；若改用 0-indexed，镜像公式变为 $i' = 2^n - 2 - i$，差一错误高发。选一套口径贯穿到底。
5. **溢出无忧但别手滑**：$n \le 20$，`1 << 20` 远小于 `int` 上限；防御性地写 `1LL << n` 也可以。
6. **暴力构造版的坑**（若走 §3.1 保底路线）：C++ 里 `s = s + "1" + t` 每层产生大临时串，建议先 `s.reserve((1 << n) - 1)`；Python 的 `invert` 用 `str.maketrans("01", "10")` 建表一次，别放在循环里反复建。
7. **别把「k == 1 提前返回」和基例混为一谈**：前者是可选优化（任何 $S_n$ 首位都是 `'0'`），后者是正确性必需（$n = 1$ 无中点）。
