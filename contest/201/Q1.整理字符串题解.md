# LeetCode 整理字符串 题解

## 1. 题目概述

- **标题 / 题号**：整理字符串（#1544，easy）
- **链接**：https://leetcode.cn/problems/make-the-string-great/
- **来源**：LeetCode 第 201 场周赛 Q1
- **难度**：简单
- **标签**：栈、字符串

**题意**：给定仅含大小写英文字母的字符串 `s`。「坏对」指相邻两个字符是**同一个字母的大小写两种形态**（如 `"eE"`、`"Ee"`）。每次操作可任选一个坏对并**同时删除**这两个字符，反复操作直到串中不再有坏对。返回最终的串（题目保证答案唯一，空串也是合法答案）。

**约束**：

- $1 \le s.length \le 100$
- `s` 仅含大小写英文字母

> 💡 签到题的切入信号：「**相邻**满足某条件就**成对删除**」——栈的教科书触发词。真正要警惕的只有一点：删除会让原本被隔开的字符变成新邻居，产生**级联**删除。

## 2. 示例

**示例 1**

```text
输入：s = "leEeetcode"
输出："leetcode"
解释：下标 1-2 的 "eE" 是坏对，删除后串中不再有任何坏对。
```

**示例 2**

```text
输入：s = "abBAcC"
输出：""
解释：删除顺序不唯一，但终态都是空串：
     "abBAcC" --> "aAcC" --> "cC" --> ""
     "abBAcC" --> "abBA" --> "aA"  --> ""
```

**示例 3**

```text
输入：s = "s"
输出："s"
解释：单字符不可能构成坏对。
```

**示例 4（补充：同大小写的相同字母不删）**

```text
输入：s = "ddaA"
输出："dd"
解释："aA" 是坏对，被删掉；剩下的 "dd" 同为小写，不是坏对，保留。
```

## 3. 解题思路

### 3.1 暴力思路

反复从头扫描：找到第一个坏对就删除，然后**重新扫描**，直到某一轮找不到坏对。每轮 $O(n)$，最坏删 $n/2$ 轮，总计 $O(n^2)$。$n \le 100$ 完全能过，但每轮重扫把「已确认无坏对的前缀」信息全部丢掉，浪费明显。

> ⚠️ 更隐蔽的错误版本是「只扫一遍、删掉所有互不重叠的坏对」：它处理不了级联。`"abBAcC"` 一趟删掉 `bB` 和 `cC` 后得到 `"aA"` 就停了，停在了一个非法的「终态」。**删除产生的新邻居必须继续检查。**

### 3.2 核心观察：栈天然处理「删除后的新相邻」

![核心观察：级联删除与栈机制](images/wc201_q1_stack_concept.svg)

**观察一：级联是本质难点。** 删除一对后，左右两侧字符挤到一起，可能构成新的坏对，需要继续删（见上图 ①）。

**观察二：栈 = 「已确认无坏对的前缀」。** 从左到右逐字符处理；每个字符**入栈前**只与栈顶比较：

- 栈顶与新字符构成坏对 → 弹出栈顶，新字符**不入栈**（这对字符一起消失）；
- 否则 → 新字符正常入栈。

弹出后，**新的栈顶自动暴露**——它恰好就是「删除后被挤出来的左邻居」，下一个字符到来时自然与它比较。级联因此被一趟扫描免费处理，无需回头（见上图 ②）。

**坏对判定**：两个英文字母 $a, b$ 构成坏对 $\iff$ 同字母异大小写 $\iff |a - b| = 32$（ASCII 中大小写恰好相差 32）。等价写法：`tolower(a) == tolower(b) && a != b`，位运算版 `(a ^ 32) == b`。

### 3.3 算法流程

![算法流程图](images/wc201_q1_algorithm_flow.svg)

一趟扫描 + 一个栈，每个字符至多一次压栈、一次弹栈，总操作数不超过 $2n$。

### 3.4 示例演算

![示例演算：leEeetcode 与 abBAcC](images/wc201_q1_example_walkthrough.svg)

例 1 的关键在第 3 步：`E` 到来时与栈顶 `e` 抵消。例 2 展示级联的典型形态：第 4 步的 `A` 之所以能被删，是因为第 3 步删掉 `bB` 之后 `a` 才与它相邻——这正是暴力法要靠反复重扫、栈法靠弹栈自动解决的情形。

## 4. 算法细节

1. **判定条件**（三选一，本题输入仅字母，均安全）：
   - `abs(st.back() - c) == 32`：最快。纯字母输入下「差 32」与「同字母异大小写」严格等价——相同字母同形态差为 0，不同字母跨大小写差为 $32 \pm k$（$k \ge 1$），取不到 32。
   - `tolower(st.back()) == tolower(c) && st.back() != c`：最通用，不依赖「仅字母」这一前提。
   - `(st.back() ^ 32) == c`：位运算翻转第 6 位即大小写互换。
2. **容器选择**：C++ 直接用 `string` 当栈（`back` / `push_back` / `pop_back`），扫描结束时它本身就是答案，零转换；Python 用 `list`，最后 `"".join`。
3. **$O(1)$ 原地变体**（进阶）：双指针 `top` 在原串上模拟栈——`s[top++] = c` 是压栈，`top--` 是弹栈，最后 `resize(top)` 截断：

   ```cpp
   class Solution {
   public:
       string makeGood(string s) {
           int top = 0;
           for (char c : s) {
               if (top > 0 && abs(s[top - 1] - c) == 32) top--;
               else s[top++] = c;
           }
           s.resize(top);
           return s;
       }
   };
   ```

## 5. 正确性证明

**引理 1（栈不变式）**：任何时刻，栈内任意相邻两字符不构成坏对。

**证明**：对操作次数归纳。初始栈空，平凡成立。设某次操作前命题成立：若执行压栈，压入前已验证「栈顶与新字符」非坏对，栈内其余相邻对不变；若执行弹栈，仅移除栈顶字符，剩余部分的相邻对是原先相邻对的子集，仍无坏对。∎

**引理 2（栈过程是合法删除序列）**：栈算法执行中的每次弹栈，都对应在「原串删去已消字符后的当前串」中删除一个相邻坏对。

**证明**：某时刻栈自底向上为 $t_1 t_2 \cdots t_k$，当前串即 $t_1 t_2 \cdots t_k\, r$（$r$ 为尚未读入的后缀）。读入 $r$ 的首字符 $c$ 时，$c$ 与 $t_k$ 在当前串中相邻；若二者构成坏对，「弹出 $t_k$ 且 $c$ 不入栈」恰是删除这对相邻字符的一次合法操作。∎

**引理 3（局部合流）**：若串 $u$ 中存在两个坏对，分别删去得到 $u_1, u_2$，则 $u_1 = u_2$，或二者可继续删除到同一个串。

**证明**：设两坏对位于 $(i, i+1)$ 与 $(j, j+1)$。若不重叠（$|i - j| \ge 2$），两次删除作用在不相交的位置上，可交换，故 $u_1 = u_2$。若重叠，不妨设 $j = i + 1$：由 $s[i], s[i+1]$ 是坏对知 $s[i]$ 是 $s[i+1]$ 的同字母异形态；同理 $s[i+2]$ 也是。同一字母的异形态唯一，故 $s[i] = s[i+2]$。删 $(i, i+1)$ 后该处剩下 $s[i+2]$，删 $(i+1, i+2)$ 后该处剩下 $s[i]$，两者相同，其余部分完全一致，故 $u_1 = u_2$。∎

**定理（终态唯一 & 算法正确）**：无论按何种顺序删除坏对，终态唯一；且栈算法返回该终态。

**证明**：每次删除使长度严格减 2，过程必然终止。结合引理 3 的局部合流，由 Newman 引理（终止 + 局部合流 $\Rightarrow$ 合流）知：所有删除序列都终止于同一个不可再删的串，即终态唯一——这正是题目「保证答案唯一」的真正来历。由引理 2，栈算法走出了一条合法删除序列；由引理 1，算法结束时栈内无坏对（不可再删），故栈中内容就是这个唯一终态。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。每个字符至多一次压栈、一次弹栈，总操作数 $\le 2n$。
- **空间复杂度**：$O(n)$。栈最坏保留全部 $n$ 个字符（串中无坏对时）；改用双指针原地写法可降至 $O(1)$（输出所占空间不计）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    string makeGood(string s) {
        string st;
        for (char c : s) {
            if (!st.empty() && abs(st.back() - c) == 32) {
                st.pop_back();
            } else {
                st.push_back(c);
            }
        }
        return st;
    }
};
```

### Python

```python
class Solution:
    def makeGood(self, s: str) -> str:
        st = []
        for c in s:
            if st and abs(ord(st[-1]) - ord(c)) == 32:
                st.pop()
            else:
                st.append(c)
        return ''.join(st)
```

## 8. 边界情况与易错点

1. **先判空栈**：`st.back()` / `st[-1]` 在空栈上是 C++ 未定义行为 / Python `IndexError`。`!st.empty() &&` / `st and` 必须短路在前。
2. **`a != b` 不能省**（`tolower` 版判定）：否则 `"aa"` 会被误删。`abs(a - b) == 32` 版天然排除此情况（相同字母同形态差为 0）。
3. **`abs(a - b) == 32` 依赖「仅字母」**：一般 ASCII 字符也可能差 32（如 `` ` ``(96) 与 `@`(64)）；若输入不保证纯字母，应改用 `tolower` 版判定。
4. **不能只删一趟互不重叠的对**：级联会产生新坏对（`"abBAcC"` 一趟后剩 `"aA"`），必须用栈或反复扫描直到稳定。
5. **空串输出**：可能全部消光（`"abBAcC"` → `""`），题目明确空串合法，直接返回空串即可。
6. **单字符**：无坏对，原样返回。
7. **别用 `stack<char>` 再转 `string`**：C++ 里 `string` 本身就是现成的字符栈，省一次转换。
