# LeetCode 分汤 题解

## 1. 题目概述

- **标题 / 题号**：分汤（#808，medium）
- **链接**：https://leetcode.cn/problems/soup-servings/
- **来源**：LeetCode 第 78 场周赛 Q3
- **难度**：中等
- **标签**：数学、动态规划、概率与统计

**题意**：A、B 两锅汤初始各 $n$ 毫升。每一回合等概率（各 $1/4$）执行下列四种取汤方案之一：$(100,0)$、$(75,25)$、$(50,50)$、$(25,75)$，前者从 A 取、后者从 B 取。若某锅剩余量不足要求的量，就把该锅**剩余部分全部取走**（不允许"欠账"）。一旦有锅被取空，**该回合立即停止**。求

$$P(\text{A 先取空}) + \frac{1}{2}\cdot P(\text{两锅在同一回合取空})$$

**约束**：

- $0 \le n \le 10^9$，状态不能按毫升展开
- 四种操作概率均为 $1/4$，且与之前所有回合**无关**（无记忆）
- 取不够时取光剩余：剩余量被"截断"到 $0$
- 返回值与正确答案的误差在 $10^{-5}$ 内即判通过

## 2. 示例

**示例 1**

```text
输入：n = 50
输出：0.62500
解释：只看第一回合的四个分支
  操作 1 (A−100, B−0)  → A 取空，B 还剩 50   → A 先空
  操作 2 (A−75,  B−25) → A 取空，B 还剩 25   → A 先空
  操作 3 (A−50,  B−50) → 两锅同时取空        → 记 ½
  操作 4 (A−25,  B−75) → B 取空，A 还剩 25   → B 先空
  答案 = 0.25 × (1 + 1 + 0.5 + 0) = 0.625
```

**示例 2**

```text
输入：n = 100
输出：0.71875
解释：按第一回合的四个分支，得到四个子状态
  操作 1 → A 直接取空                        → 贡献 0.25 × 1
  操作 2 → 变成 (A=25,  B=75)，后续概率 0.875 → 贡献 0.25 × 0.875
  操作 3 → 变成 (A=50,  B=50)，后续概率 0.625 → 贡献 0.25 × 0.625
  操作 4 → 变成 (A=75,  B=25)，后续概率 0.375 → 贡献 0.25 × 0.375
  答案 = 0.25 × (1 + 0.875 + 0.625 + 0.375) = 0.71875
```

**示例 3（补充：$n < 25$ 的边界）**

```text
输入：n = 24
输出：0.62500
解释：m = ⌈24 / 25⌉ = 1，与 n = 25 完全等价
  操作 1 → A 取光（24 < 100），B 一动不动 → A 先空
  操作 2/3/4 → A、B 都在这一回合被取光      → 同时空，记 ½
  答案 = 0.25 × (1 + 0.5 + 0.5 + 0.5) = 0.625
```

## 3. 解题思路

### 3.1 暴力思路

把 $(a,b)$ 的**毫升数**直接当状态：$dp$ 表要 $10^9 \times 10^9$ 个格子，空间 $10^{18}$ 量级，显然不可行；即使 $n \le 5000$，也要 $5000^2 = 2.5\times 10^7$ 格，Python 根本跑不动。不带记忆化的递归分支因子为 $4$、深度可达 $m$ 层，复杂度 $4^m$，同样爆炸。

真正的困难有两处：一是 $n$ 的量级，二是"取不够就取光"与"立即停止"这两个语义。前者靠**量化**解决，后者靠**边界值**解决。

### 3.2 核心观察：25ml 量化 + 大 $n$ 收敛

![把毫升缩放到 25ml 单位并处理截断](images/wc78_q3_scale_and_clamp.svg)

**观察 1（量化）**：四种操作的扣除量都是 $25$ 的倍数，所以同一锅的剩余量只需区分 $\lceil x/25 \rceil$，即"还剩几个 25ml"。

**观察 2（截断 = 向上取整）**：剩余不足一次扣除时会被取光，因此 $x$ 毫升与 $\min(x, 25)$ 毫升的后续行为**完全相同**。把初始量缩放成

$$m = \left\lceil \frac{n}{25} \right\rceil = \left\lfloor \frac{n + 24}{25} \right\rfloor$$

状态数就降到 $(m+1)^2$；四种操作也随之变成单位量 $(4,0)$、$(3,1)$、$(2,2)$、$(1,3)$。下标为负时**夹到 0**，正是"取光不欠账"。

**观察 3（大 $n$ 收敛）**：$n$ 越大，B 先取空的概率越快衰减到 0，答案趋于 1。

![误差随 m 指数衰减，m 超过 192 时已远小于 1e−5](images/wc78_q3_convergence.svg)

每回合 A 的扣除是独立同分布的 $U\{1,2,3,4\}$（均值 $2.5$，即 62.5ml），B 的扣除是 $4 - $ A 的扣除（均值 $1.5$，即 37.5ml），A 平均每回合比 B 多取一个单位。实测误差 $E_m = 1 - dp[m][m]$ 近似按 $0.58^{\,m/10}$ 衰减：$E_{179} = 9.79\times10^{-6}$ 已跌破 $10^{-5}$，$E_{192} = 5.01\times10^{-6}$。因此取

$$m > 192 \ (\text{即 } n > 4800) \implies \text{直接返回 } 1.0$$

这也是题面提示"For large $n$, the answer approaches a constant value"的含义。

### 3.3 状态设计与转移

![dp[a][b] 由四个更小的状态等权累加](images/wc78_q3_dp_transition.svg)

令 $dp[a][b]$ 表示"A、B 分别还剩 $a$、$b$ 个单位时，题面所求概率"。边界与转移为

$$dp[a][b]=\begin{cases}
\dfrac{1}{2}, & a \le 0 \text{ 且 } b \le 0\\[4pt]
1, & a \le 0 < b\\[4pt]
0, & b \le 0 < a\\[4pt]
\dfrac{1}{4}\big(dp[a-4][b]+dp[a-3][b-1]+dp[a-2][b-2]+dp[a-1][b-3]\big), & a,b \ge 1
\end{cases}$$

实现上不必写四个分支：用一个取数函数 $at(a,b) = dp[\max(a,0)][\max(b,0)]$ 把负下标一律夹到 $0$，边界值预先写进第 $0$ 行与第 $0$ 列即可。

**填表顺序**：四个前驱的 $a$ 坐标分别为 $a-4,a-3,a-2,a-1$，都严格小于 $a$，所以外层按 $a$ 递增、内层 $b$ 任意方向都能保证"用到的格子已算好"。

### 3.4 示例演算

![n = 50 的 3×3 DP 表与 dp[2][2] 的四个前驱](images/wc78_q3_walkthrough.svg)

$n = 50$ 时 $m = 2$，逐格填表（$a$ 为行、$b$ 为列）：

$$dp[2][2] = \tfrac14\big(\underbrace{dp[0][2]}_{1} + \underbrace{dp[0][1]}_{1} + \underbrace{dp[0][0]}_{0.5} + \underbrace{dp[1][0]}_{0}\big) = \tfrac{2.5}{4} = 0.625$$

$n = 100$ 时 $m = 4$，整张表如下，右下角 $dp[4][4] = 0.71875$ 与示例 2 一致：

| $a \backslash b$ | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| 0 | 0.50000 | 1.00000 | 1.00000 | 1.00000 | 1.00000 |
| 1 | 0 | 0.62500 | 0.75000 | 0.87500 | 1.00000 |
| 2 | 0 | 0.50000 | 0.62500 | 0.75000 | 0.90625 |
| 3 | 0 | 0.37500 | 0.50000 | 0.65625 | 0.81250 |
| 4 | 0 | 0.25000 | 0.40625 | 0.56250 | **0.71875** |

## 4. 算法细节

1. **缩放**：`m = (n + 24) / 25`（整数除法）。$n = 0$ 时 $m = 0$，表退化成 $1\times1$，直接返回 $dp[0][0] = 0.5$，无需额外特判。
2. **三组边界值**：$dp[0][0] = 0.5$（同回合取空，只记一半）；$dp[0][b] = 1$（$b \ge 1$，A 已空而 B 还有 → A 先空）；$dp[a][0] = 0$（$a \ge 1$，B 已空 → A 没有先空）。
3. **下标截断**：取数时统一写成 $at(a,b) = dp[\max(a,0)][\max(b,0)]$。这一步把"取不够就取光"直接编码进查表，四个转移写法完全一致，不容易漏分支。
4. **填表顺序**：外层 $a$ 从 $1$ 到 $m$、内层 $b$ 从 $1$ 到 $m$。因为前驱的 $a$ 严格更小，也可按 $a+b$ 递增填，效果相同。
5. **滚动数组（可选）**：$dp[a][\cdot]$ 只依赖 $a-4 \sim a-1$ 四行，保留 5 行环形缓冲即可把空间从 $O(m^2)$ 降到 $O(m)$；本题格子数只有约 $3.7$ 万，直接开二维表更省心。
6. **阈值判断要前置**：`m > 192` 的判断必须放在建表之前。$n = 10^9$ 时 $m = 4\times10^7$，若先建表会直接内存溢出。
7. **浮点类型**：累计误差是 $O(m^2\epsilon_{\text{machine}})$，可忽略；但必须使用 64 位浮点——C++ 写 `double`，Python 的 `float` 本身就是 64 位。C++ 的 `float` 只有 7 位有效数字，$10^{-5}$ 的容差下不可靠。

## 5. 正确性证明

**引理 1（量化等价）**：设某锅剩余 $x \ge 1$ 毫升，本回合要从它取走 $k$ 个单位（$k \in \{0,1,2,3,4\}$，即 $25k$ 毫升）。则新剩余量的单位数恰为 $\max(m_x - k, 0)$，其中 $m_x = \lceil x/25 \rceil$。

**证明**：若 $x \ge 25k$，新剩余 $x - 25k$，其单位数 $\lceil (x-25k)/25\rceil = \lceil x/25\rceil - k = m_x - k$（$k$ 为整数）。若 $x < 25k$，按题意取光，剩余 $0$，单位数为 $0 = \max(m_x - k, 0)$。两种情形都与下标截断后的查表结果一致。∎

**引理 2（终止性）**：任何一条操作序列至多 $m$ 回合就会让至少一锅取空。

**证明**：每回合 A 的扣除量至少 $1$ 个单位（四种操作分别扣 $4,3,2,1$），故 $t$ 回合后 A 的累计扣除 $\ge t$。取 $t = m$ 时累计扣除 $\ge m$，A 必已取空，游戏在第 $m$ 回合或更早停止。∎

**引理 3（递推正确）**：设 $f(a,b)$ 为状态 $(a,b)$ 下题面所求概率，则 $f$ 与 $dp$ 在 $a,b \ge 0$ 上处处相等。

**证明**：$a \le 0$ 或 $b \le 0$ 的三种终局按定义读出，二者一致。当 $a,b \ge 1$ 时，第一回合的四种操作等概率且互相排斥，由全概率公式

$$f(a,b) = \frac{1}{4}\Big(f(a-4,b) + f(a-3,b-1) + f(a-2,b-2) + f(a-1,b-3)\Big)$$

其中越界参数按引理 1 截断。等号右侧每个状态的 $a$ 坐标严格小于 $a$，故对 $a$ 作归纳：假设所有 $a' < a$ 时 $f = dp$，则 $f(a,b)$ 也等于 $dp[a][b]$，唯一性得证。∎

**定理**：算法输出与正确答案的误差不超过 $10^{-5}$。

**证明**：当 $m \le 192$ 时，由引理 3，$dp[m][m] = f(m,m)$ 是精确值。当 $m > 192$ 时输出 $1$，误差为 $E_m = 1 - f(m,m)$；数值上 $E_m$ 单调不增，且 $E_{179} = 9.79\times10^{-6} < 10^{-5}$、$E_{192} = 5.01\times10^{-6}$，故 $m > 192$ 时 $E_m < 5.01\times10^{-6} < 10^{-5}$，落在容差内。∎

> **关于 $E_m$ 的解析上界**：设停止时刻为 $t$。"B 先空"意味着累计扣除满足 $cum_B(t) \ge m$ 而 $cum_A(t) \le m-1$，且跨过 $m$ 的那一步最多越界 2 个单位，故 $cum_B(t) \le m+2$；两式相加并用每回合两锅扣除之和恒为 $4$，得 $4t \le 2m+1$，即 $t \le \lceil m/2 \rceil$。"同归于尽"同理（用到 $t-1$ 回合两锅都还没空）。于是在第 $\lceil m/2 \rceil$ 回合，A 的累计扣除必然偏离其均值 $2.5\lceil m/2\rceil$ 至少约 $0.25m$，由 Hoeffding 不等式得误差 $\lesssim 2\exp(-(m-4)/36)$，即 $m \ge 450$ 时有纯解析保证。本文沿用社区通行的 $m > 192$：格子数少约 5 倍，而实测误差 $5.0\times10^{-6}$ 仍只有容差的一半。

## 6. 复杂度分析

- **时间**：$m \le 192$ 时填 $(m+1)^2 - 1$ 格，每格 $4$ 次查表 + 常数次运算，为 $O(m^2)$，约 $3.7\times10^4$ 次操作；$n > 4800$ 时只有一次整除与一次比较，$O(1)$。把缩放后的规模记作 $m' = \min(\lceil n/25\rceil, 193)$，总时间就是 $O(m'^2)$，与 $n$ 的具体大小无关。
- **空间**：二维表 $O(m^2)$，约 $193^2 \times 8$ 字节 $\approx 300$ KB；若用 5 行滚动缓冲则为 $O(m)$。

## 7. 参考代码

### C++

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    double soupServings(int n) {
        // 操作量均为 25 的倍数：以 25ml 为单位缩放到 m，不足 25ml 向上取整
        int m = (n + 24) / 25;
        if (m > 192) return 1.0;                       // n > 4800，误差 < 1e-5

        vector<vector<double>> dp(m + 1, vector<double>(m + 1, 0.0));
        dp[0][0] = 0.5;                                // 同回合取空，只记一半
        for (int b = 1; b <= m; ++b) dp[0][b] = 1.0;   // A 先取空
        // dp[a][0] = 0.0, a >= 1                       // B 先取空

        auto at = [&](int a, int b) -> double {
            // 下标为负意味着"取不够，取光"，等价于 0
            return dp[a > 0 ? a : 0][b > 0 ? b : 0];
        };

        for (int a = 1; a <= m; ++a)
            for (int b = 1; b <= m; ++b)
                dp[a][b] = 0.25 * (at(a - 4, b) + at(a - 3, b - 1)
                                 + at(a - 2, b - 2) + at(a - 1, b - 3));
        return dp[m][m];
    }
};
```

### Python

```python
class Solution:
    def soupServings(self, n: int) -> float:
        # 四种操作都是 25ml 的倍数，把 n 缩放成以 25ml 为单位的 m（向上取整）
        m = (n + 24) // 25
        if m > 192:                     # n > 4800，误差已小于 1e-5
            return 1.0

        dp = [[0.0] * (m + 1) for _ in range(m + 1)]
        dp[0][0] = 0.5                  # 两锅同回合取空，只记一半
        for b in range(1, m + 1):
            dp[0][b] = 1.0              # A 空了、B 还有：A 先取空
        # dp[a][0] = 0.0 (a >= 1)       # B 空了、A 还有：A 没有先取空

        def at(a: int, b: int) -> float:
            # 负下标等价于 0："取不够就取光"
            return dp[a if a > 0 else 0][b if b > 0 else 0]

        for a in range(1, m + 1):
            for b in range(1, m + 1):
                dp[a][b] = 0.25 * (at(a - 4, b) + at(a - 3, b - 1)
                                   + at(a - 2, b - 2) + at(a - 1, b - 3))
        return dp[m][m]
```

## 8. 边界情况与易错点

1. **$n = 0$**：$m = 0$，表退化为 $1\times1$，返回 $dp[0][0] = 0.5$。题意里"同回合取空只记一半"在这一格上自洽，不要特判成 $0$ 或 $1$。
2. **$n < 25$**：$m = 1$，答案恒为 $0.625$。A 无论如何都会被一次取光，B 只在操作 2/3/4 时被同步取光，$0.25\times(1+0.5\times3) = 0.625$。
3. **向上取整写错**：写成 `n / 25 + 1` 会在 $n$ 是 $25$ 的倍数时多算一格，答案直接变成"多 25ml"的那个问题——$n = 50$ 会输出 $0.65625$（真实答案 $0.625$）。必须用 `(n + 24) / 25`。
4. **阈值判断在缩放之后**：先算 $m$ 再判 $m > 192$。若直接判 $n > 4800$ 也可以，但两个条件必须一致（$n = 4801$ 时 $m = 193$）；漏判会为 $n = 10^9$ 建 $4\times10^7$ 阶的表而 MLE。
5. **同空权重是 $\tfrac12$ 而不是 $1$**：$dp[0][0]$ 与所有"同回合取空"的项都按 $0.5$ 计；写成 $1$ 会让 $n = 50$ 的输出变成 $0.75$。
6. **截断要两侧都夹**：只夹 $a$ 忘了夹 $b$（或反之）会越界访问；四个转移里 $b$ 的下标分别是 $b, b-1, b-2, b-3$，$b \le 3$ 时就为负。
7. **精度**：C++ 用 `double`（Python 的 `float` 本身是 64 位），不要用 C++ 的 32 位 `float`；返回值不要取整、`round` 或格式化，直接返回浮点数。
