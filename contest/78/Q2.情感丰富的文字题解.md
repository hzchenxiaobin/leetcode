# LeetCode 情感丰富的文字 题解

## 1. 题目概述

- **标题 / 题号**：情感丰富的文字（#809，medium）
- **链接**：https://leetcode.cn/problems/expressive-words/
- **来源**：LeetCode 第 78 场周赛 Q2
- **难度**：中等
- **标签**：数组、双指针、字符串

**题意**：把一个串中**相邻且相同**的字符称作一个字母组（如 `"heeellooo"` 分成 `h`、`eee`、`ll`、`ooo`）。允许对某个字母组做一次**扩张**：往组里添加同一个字符，使该组长度达到 **3 或以上**（原本就更长的组可以继续变长）。给定目标串 `s` 和一组查询词，统计有多少个查询词能通过若干次扩张变成 `s`。

**约束**：

- $1 \le \lvert s \rvert,\ \lvert \text{words} \rvert \le 100$
- $1 \le \lvert \text{words}[i] \rvert \le 100$
- `s` 与所有 `words[i]` 均只含小写英文字母

## 2. 示例

**示例 1**

```text
输入：s = "heeellooo", words = ["hello", "hi", "helo"]
输出：1
解释："hello" 的 e 组与 o 组各扩张成 3，得到 "heeellooo"，可扩张；
      "hi" 只有 2 组，与 s 的 4 组对不上；
      "helo" 的 l 组只有 1 个，要凑到 s 的 2 个，但扩张只能停在 3 以上。
```

**示例 2**

```text
输入：s = "zzzzzyyyyy", words = ["zzyy", "zy", "zyy"]
输出：3
解释：s 的组是 z×5、y×4，两个组的长度都 ≥ 3，因此任何 z、y 个数不超过 5、4 的
      单词都能扩张过去："zzyy"(2,2)、"zy"(1,1)、"zyy"(1,2) 三个词全部可扩张。
```

**示例 3（补充示例，说明「短组」卡死的情形）**

```text
输入：s = "aab", words = ["ab", "aab", "aaaaab"]
输出：1
解释："aab" 与 s 完全相同，可扩张（零次操作）；
      "ab" 的第一个 a 组要 1→2，但目标长度 2 < 3，非法；
      "aaaaab" 第一个 a 组 5 个，比 s 的 2 个还多，而扩张只能加不能减，非法。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的做法是**枚举所有可达的扩张结果**：把查询词按组切开，对每组枚举最终长度（保持不变，或扩张到任一 $\ge 3$ 且不超过 $\lvert s \rvert$ 的值），拼出整串再和 `s` 比较。

组数最坏是 $\lvert s \rvert = 100$，每组有 $O(\lvert s \rvert)$ 种长度选择，候选总量达到 $100^{100}$ 级别，完全不可行；即便按长度和剪枝，单次判定也是指数级。

另一种常见错误是**只逐字符比**：用两个指针同步走，跳过连续相同的字符。这样会丢掉"每组有多少个"这个关键信息——`"helo"` 与 `"heeellooo"` 的字符序列完全一致（`h,e,l,o`），只有长度关系才能区分它们，所以要另外记住每组的长度（个数），回到"按组比较"。

### 3.2 核心观察：字母组分解唯一，逐组对齐即可

![按字母组对齐的三条判定](images/wc78_q2_group_alignment.svg)

**关键结构**：扩张操作只在某个组**内部**添加同字符，它既不改变"组与组的先后顺序"，也不会把两个组合并（相邻两组字符必然不同），更不会拆组。因此只要 `w` 能变成 `s`，两边的**组序列必然一一对应**：

- 组数必须相同；
- 第 $k$ 组的字符必须相同；
- 第 $k$ 组的长度 $n_2$（`w`）不能超过 $n_1$（`s`），因为只能加字母、不能删字母。

剩下唯一的细节是**扩张的下界 3**。设 `s` 的第 $k$ 组长为 $n_1$、`w` 的对应组长为 $n_2$：

- $n_2 = n_1$：一次操作都不用，天然合法（哪怕 $n_1 = 1$ 或 $2$）；
- $n_2 < n_1$：必须把这一组从 $n_2$ 加到 $n_1$，而每次扩张的结果长度必须 $\ge 3$，所以要求 $n_1 \ge 3$；
- $n_2 > n_1$：只能加不能减，非法。

三段合起来就是一条充要条件：

$$\text{第 } k \text{ 组合法} \iff n_1 = n_2 \ \text{ 或 }\ n_1 \ge \max(n_2,\, 3)$$

> 💡 换句话说：**组长的"短"是 `s` 的属性**。`s` 里长度为 1 或 2 的组是"硬约束"，查询词在这些位置必须一字不差；只有长度 $\ge 3$ 的组才允许查询词少写几个。

### 3.3 算法流程

![判定流程图](images/wc78_q2_check_flow.svg)

1. 先把 `s` 做**游程编码**（run-length encoding），得到 `groups(s)`：一组 `(字符, 长度)`，只算一次。
2. 对每个 `w`，同样求 `groups(w)`。
3. 若 `groups(w)` 与 `groups(s)` 的**长度不同**，直接 `continue`（组数不同就不可能对齐）。
4. 否则逐组检查：字符不同、或 $n_2 > n_1$、或（$n_1 > n_2$ 且 $n_1 < 3$）时判为非法，立即 `break`。
5. 所有组都通过则 `ans += 1`；遍历完所有 `w` 后返回 `ans`。

判定是纯粹的**线性扫描 + 一次对齐**，没有任何分支需要回溯——因为每一组的约束彼此独立，且每一组只有"过"或"不过"，不存在"先让它过、后面再补救"的余地。

### 3.4 示例演算

![示例 1 逐组演算](images/wc78_q2_walkthrough.svg)

以 `s = "heeellooo"`（组：`h×1`、`e×3`、`l×2`、`o×3`）为例：

| 查询词 | 与 `s` 的分组对比 | 结论 |
|--------|-------------------|------|
| `"hello"` | `h×1` ｜ `e×1` ｜ `l×2` ｜ `o×1` | 4 组全过：$1=1$、$1<3$ 且 $3\ge 3$、$2=2$、$1<3$ 且 $3\ge3$ → ✓ |
| `"hi"` | `h×1` ｜ `i×1` | 组数 $2 \ne 4$ → 直接淘汰 |
| `"helo"` | `h×1` ｜ `e×1` ｜ `l×1` ｜ `o×1` | 第 ③ 组要 $1 \to 2$，但 $2 < 3$ → 非法 |

- `"hello"` 的 `l×2` 与 `s` 的 `l×2` **正好相等**，不需要扩张，所以"目标长度 2 小于 3"这一条根本不触发；
- `"helo"` 差在同一个位置，它需要把 `l` 扩到 2，而 2 不是合法的扩张落点。

因此第一个示例答案为 $1$。第二个示例中 `s` 的组是 `z×5`、`y×4`，两个组都 $\ge 3$，三个词在两个位置上都不超过 5、4，故全部通过，答案为 $3$。

## 4. 算法细节

1. **游程编码用一次遍历完成**：`i` 指向组首，`j` 一路右移到字符变化处，`(t[i], j-i)` 就是一组，再令 `i = j`。不要用 `Counter` 或排序，那样会丢掉组的顺序。
2. **先比组数**：组数不同直接淘汰，这一步同时避免了后续逐组循环时的越界与错配（`"hi"` 就靠这一步被筛掉）。
3. **比字符只比组首字符**：组内字符相同是分解的定义，无需再逐个比对。
4. **三条判定可以压成一个表达式**：非法 $\iff n_1 < n_2$ 或（$n_1 > n_2$ 且 $n_1 < 3$）；等价地，合法 $\iff n_1 = n_2$ 或 $n_1 \ge \max(n_2, 3)$。
5. **非法即 `break`**：某一组已经判死就没有继续比较的意义，提前退出可省掉无谓的扫描。
6. **缓存的粒度**：`groups(s)` 只算一次并在所有词之间复用；`groups(w)` 每个词各算一次。$\lvert \text{words} \rvert \le 100$ 时这点缓存不明显，但它让总代价的式子更干净。
7. **整数范围安全**：长度上限 100，计数与比较都在 `int` 内，无溢出风险；答案也不超过 $\lvert \text{words} \rvert \le 100$。
8. **换一种双指针写法时**：`i`、`j` 分别在 `s`、`w` 上跳**整组**，必须每一步把整组吃干净再比长度；如果只前进一格，就退化成"逐字符比较"，会丢掉长度信息并答错 `"helo"` 这类用例。

## 5. 正确性证明

**引理 1（分解唯一）**：任意非空字符串 $t$ 的字母组分解是唯一的，即把 $t$ 切成极大的同字符连续段，得到的组序列与每段长度都由 $t$ 唯一确定。

**证明**：组的边界只能落在"相邻两字符不同"的位置，这类位置由 $t$ 本身唯一确定；每个组的字符与长度随之唯一确定。∎

**引理 2（操作的组不变性）**：若 $w$ 经若干次扩张得到 $s$，则 $\text{groups}(w)$ 与 $\text{groups}(s)$ 组数相同，且逐组字符相同、长度满足 $n_2 \le n_1$。

**证明**：对操作次数归纳。零次操作时 $w = s$，由引理 1 分解完全相同。

设 $w$ 经 $k$ 次操作得到 $w'$，再对 $w'$ 的某组（字符 $c$，长 $L$）扩张得到 $w''$。扩张只在组内添加 $c$：组的左邻与右邻（若存在）字符均不为 $c$，故 $c$ 不会与邻组合并，也不会产生新的组边界；组数不变、组字符序列不变、只有该组长度由 $L$ 变为 $L' > L$，且其余组长度不变。于是每一步都保持"组数与组字符序列不变、长度只增不减"，归纳即得结论，$n_2 \le n_1$ 也随之成立。∎

**引理 3（充分性）**：若 $\text{groups}(w)$ 与 $\text{groups}(s)$ 组数相同、逐组字符相同，且每组满足 $n_1 = n_2$ 或 $n_1 \ge \max(n_2, 3)$，则 $w$ 可扩张成 $s$。

**证明**：对每个 $n_2 < n_1$ 的组，单独施加一次扩张，把该组长度从 $n_2$ 加到 $n_1$。由条件 $n_1 \ge \max(n_2, 3) \ge 3$，这次操作的结果长度满足题面"达到 3 或以上"的要求，合法。由于各组的字符互不相同且相邻组字符不同，对某一组的扩张不影响其他组的边界与长度，多次扩张之间互不干扰。所有需要扩张的组处理完后，逐组长度都等于 $n_1$、组字符与顺序都与 `s` 一致，由引理 1 唯一性得整串等于 $s$。∎

**引理 4（必要性中的长度下界）**：若 $n_2 < n_1$，则 $n_1 \ge 3$。

**证明**：由引理 2，$w$ 的第 $k$ 组最终变成 `s` 的第 $k$ 组，长度由 $n_2$ 增至 $n_1$，故至少发生过一次针对该组的扩张，而每次扩张的结果长度必须 $\ge 3$，因此最终长度 $n_1 \ge 3$。∎

**定理**：算法对每个查询词的判定恰为"可扩张"，因此返回的计数正确。

**证明**：算法对 `w` 返回真的条件正是引理 3 的前提（组数相同、组字符相同、每组 $n_1 = n_2$ 或 $n_1 \ge \max(n_2,3)$），由引理 3 得 `w` 确实可扩张，这是**可靠性**；反之若 `w` 可扩张，由引理 2 得组数与组字符一致、$n_2 \le n_1$，再由引理 4 得 $n_2 < n_1$ 时 $n_1 \ge 3$，恰好满足算法要求，这是**完备性**。两者合起来说明判定与"可扩张"等价，逐词累加得到的计数即为答案。∎

## 6. 复杂度分析

- **时间**：$O\bigl(\lvert s \rvert + \sum_i \lvert \text{words}[i] \rvert\bigr)$。`groups(s)` 一次线性扫描；每个词做一次线性扫描求分解，再一次线性扫描逐组比较，组数不超过该词长度。最坏 $100 \times 100 = 10^4$ 个字符量级，完全在时限内。
- **空间**：$O(\lvert s \rvert + \max_i \lvert \text{words}[i] \rvert)$，用于存放两边的分组数组；组数不超过对应串长。若把比较改成边扫边比（不显式存 `groups(w)`），额外空间可降到 $O(\lvert s \rvert)$，即只缓存 `s` 的分解。

## 7. 参考代码

### C++

```cpp
#include <string>
#include <vector>
#include <utility>
using namespace std;

class Solution {
public:
    int expressiveWords(string s, vector<string>& words) {
        auto groups = [](const string& t) {
            vector<pair<char, int>> g;
            for (size_t i = 0; i < t.size(); ) {
                size_t j = i;
                while (j < t.size() && t[j] == t[i]) ++j;
                g.push_back({t[i], (int)(j - i)});
                i = j;
            }
            return g;
        };

        auto gs = groups(s);
        int ans = 0;
        for (const string& w : words) {
            auto gw = groups(w);
            if (gw.size() != gs.size()) continue;      // 组数不同，无法对齐
            bool ok = true;
            for (size_t k = 0; k < gs.size(); ++k) {
                int n1 = gs[k].second;                 // s 的组长
                int n2 = gw[k].second;                 // 查询词的组长
                if (gs[k].first != gw[k].first ||      // 字符不同
                    n1 < n2 ||                         // 只能变长，不能变短
                    (n1 > n2 && n1 < 3)) {             // 扩张落点必须 >= 3
                    ok = false;
                    break;
                }
            }
            if (ok) ++ans;
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def expressiveWords(self, s: str, words: list[str]) -> int:
        def groups(t: str):
            res = []
            i, n = 0, len(t)
            while i < n:
                j = i
                while j < n and t[j] == t[i]:
                    j += 1
                res.append((t[i], j - i))
                i = j
            return res

        gs = groups(s)                      # s 的分组只算一次
        ans = 0
        for w in words:
            gw = groups(w)
            if len(gw) != len(gs):          # 组数必须相同
                continue
            ok = True
            for (c1, n1), (c2, n2) in zip(gs, gw):
                if c1 != c2 or n1 < n2 or (n1 > n2 and n1 < 3):
                    ok = False
                    break
            if ok:
                ans += 1
        return ans
```

## 8. 边界情况与易错点

1. **查询词与 `s` 完全相同**：此时每组都取到 $n_1 = n_2$，即使 `s` 里有长度为 1 或 2 的组也必须算"可扩张"。若把判定写成"$n_1$ 必须 $\ge 3$"，`s = "aab"`、`words = ["aab"]` 会被错判成 0（正确答案是 1）。
2. **组数不同必须先拦下**：`"hi"` 与 `"heeellooo"` 字符集都不重叠，若直接逐组比较而不比组数，会越界或错位比较。
3. **查询词比 `s` 长**：$n_2 > n_1$ 一定非法（不能删字母），如 `s = "a"`、`w = "aaa"`。
4. **`s` 的短组是硬约束**：`s` 中长度为 1、2 的组要求查询词一字不差，`"helo"` 就死在 `l×2` 这个位置上。
5. **组字符相同但顺序错位**：`s = "ab"`、`w = "ba"` 组数与长度都对得上，必须靠字符比较拦住。
6. **单字符输入**：`s = "a"`、`words = ["a"]` 答案 1；`words = ["aa", "b"]` 则为 0、0，注意 `"aa"` 属于第 3 条（变短不可能）。
7. **别用 `set` / `Counter` 做分解**：它们丢掉顺序，`"ab"` 与 `"ba"` 会被误判为同一类；必须保留组序列。
8. **`break` 之后不要继续累加**：某个词判死后要保证不再进入 `ans += 1` 分支，布尔变量与 `break` 的组合要写对。
