# LeetCode 寻找排列 题解

## 1. 题目概述

- **标题 / 题号**：寻找排列（#484，medium）
- **链接**：https://leetcode.cn/problems/find-permutation/
- **来源**：LeetCode 第 16 场周赛 A 卷 Q1
- **难度**：中等
- **标签**：栈，贪心，数组，字符串

**题意**：给定只含 `'I'`（increasing）和 `'D'`（decreasing）的**签名串** $s$，令 $n = \lvert s \rvert + 1$。要求返回 $1 \sim n$ 的一个排列 $p$，使得对每个 $0 \le i < \lvert s \rvert$：$s[i] = \texttt{'I'}$ 时 $p[i] < p[i+1]$，$s[i] = \texttt{'D'}$ 时 $p[i] > p[i+1]$。在所有满足签名的排列中，返回**字典序最小**的那一个。

**约束**：

- $1 \le \lvert s \rvert \le 10^4$
- $s[i] \in \{\texttt{'I'}, \texttt{'D'}\}$
- 返回值类型为整数数组，长度 $n = \lvert s \rvert + 1$，元素是 $1 \sim n$ 的一个排列

## 2. 示例

**示例 1**

```text
输入：s = "I"
输出：[1,2]
解释：n = 2，只有 [1,2] 满足 p[0] < p[1]，它自然也是字典序最小的。
```

**示例 2**

```text
输入：s = "DI"
输出：[2,1,3]
解释：n = 3。[2,1,3] 与 [3,1,2] 都满足 2 > 1 < 3，
      但 [2,1,3] 的字典序更小（首位 2 < 3），故答案为 [2,1,3]。
```

**示例 3（补充，连续 D 段）**

```text
输入：s = "DDI"
输出：[3,2,1,4]
解释：前两个 D 要求 p[0] > p[1] > p[2]，这段必须放 3,2,1；末尾 I 接上 4。
```

## 3. 解题思路

### 3.1 暴力思路

把 $1 \sim n$ 的所有排列按字典序枚举，逐个校验签名，第一个合法的就是答案。正确性显然，但排列数是 $n!$：$n = 12$ 时已是 $4.8 \times 10^8$，$n = 10^4$ 时完全不可行。回溯 + 剪枝（每步只挑能维持当前关系的数）最坏仍是 $O(n!)$，因为「按位枚举候选值」的分支并没有被有效压缩。

> 💡 换个角度：真正被签名约束住的不是「每个位置放哪个数」，而是**连续 D 构成的段**。抓住段，问题就退化成排序。

### 3.2 核心观察：基准 $1..n$ + 每一段连续 D 整体翻转

![基准 1..n 与 D 段翻转](images/wc16_q1_d_run_reverse.svg)

先看没有任何约束时字典序最小的排列：$1, 2, \dots, n$，它把所有 `'I'` 都满足了，只有 `'D'` 不满足。于是把 $s$ 里**每一段极大的连续 D** 单独拎出来：

- 若 $s[i..j-1]$ 全为 `'D'`（长度 $k = j - i$），那么它要求 $p[i] > p[i+1] > \cdots > p[j]$，共 $j - i + 1$ 个数**严格递减**。
- 两个 D 段之间一定隔着一个 `'I'`，所以各段互不干扰，可以分别处理。

**做法**：以 $1..n$ 为基准，让每个 D 段覆盖的下标区间 $[i, j]$ 上的数**整体倒序**。倒序后这一段恰好是连续整数降序，天然满足整段 D；而段与段之间的 `'I'` 处，前一段的最小值小于后一段的最小值，依然递增。对示例 `"DDIDI"`：段 $[0,2]$ 翻转成 $3,2,1$，段 $[3,4]$ 翻转成 $5,4$，其余不动 → $3,2,1,5,4,6$。

### 3.3 算法流程

![扫描并翻转 D 段](images/wc16_q1_algorithm_flow.svg)

1. 令 $n = \lvert s \rvert + 1$，初始化 `res = [1, 2, ..., n]`，指针 `i = 0`。
2. 若 `i == len(s)` 结束；若 `s[i] == 'I'`，说明这一位已被基准满足，`i += 1` 后继续。
3. 否则 `s[i] == 'D'`：从 `i` 出发找**极大 D 串的终点** `j`（`j` 停在不等于 `'D'` 的位置或串尾）。此时 D 串是 $s[i..j-1]$，需要倒序的是下标区间 $[i, j]$（$j - i + 1$ 个数）。
4. `reverse(res[i..j])`，然后令 `i = j`（跳过整段，注意不是 `j + 1`）。
5. 扫描结束返回 `res`。

等价的**栈写法**：遍历 `s + 'I'`（末尾补一个哨兵 `'I'`），把 $1, 2, \dots$ 依次压栈；每遇到 `'I'` 就把栈里所有元素弹出追加到答案。哨兵保证最后一段 D 也被清空。两种写法结果完全相同。

### 3.4 示例演算

![s = "DDIDI" 的逐步演算](images/wc16_q1_example_walkthrough.svg)

以 $s = \texttt{"DDIDI"}$（$n = 6$）为例：

| 步骤 | 动作 | `res` |
|------|------|-------|
| 初始 | `i = 0`，基准升序 | 1 2 3 4 5 6 |
| ① | D 段 $s[0..1]$，$j = 2$，翻转 $1,2,3$ | 3 2 1 4 5 6 |
| ② | $s[2] = \texttt{'I'}$，不动，`i = 3` | 3 2 1 4 5 6 |
| ③ | D 段 $s[3..3]$，$j = 4$，翻转 $4,5$ | 3 2 1 5 4 6 |
| ④ | $s[4] = \texttt{'I'}$，`i = 5` 越界，结束 | 3 2 1 5 4 6 |

校验：$3 > 2 > 1 < 5 > 4 < 6$，恰好是 `D D I D I`。由于 $s[0..1]$ 是两个 D，首位必须大于后两位，最小只能取 $3$，所以这个结果就是字典序最小的。

## 4. 算法细节

1. **基准排列是字典序最小的起点**：$1, 2, \dots, n$ 已经是「只考虑 I」时的最优解，后续任何调整只会让某些位置变大、某些位置变小；翻转 D 段恰好只把「必须变小」的位置改小，不破坏已满足的 I。
2. **翻转区间是闭区间 $[i, j]$**：D 串在签名里的下标是 $s[i..j-1]$，它约束的是**数**的下标 $p[i..j]$，一共 $j - i + 1$ 个数。写成 `[i, j-1]` 会少翻转一个，最后一个 D 关系就不成立。
3. **`i = j`：指针停在待处理的字符上**：`j` 停在第一个不是 `'D'` 的字符上（可能是 `'I'`，也可能越界）。写成 `i = j + 1` 结果其实一样（因为 `s[j]` 必然不是 `'D'`，那一轮本来也是空转），但 `i = j` 的语义更清楚：**每轮只处理「一个 D 段」或「一个 I」**，不会多跳。
4. **不要写成 `i += 1`**：那样同一段 D 会被反复翻转，结果直接错。例如 `"DD"` 会先翻成 $[3,2,1]$，再翻 $[1,2]$ 得 $[3,1,2]$，第二个 D 就不成立了。必须一次跳过整段。
5. **指针单调前进**：`i` 只增不减，`j` 从 `i` 出发也单调前进，因此外层 `while` 只在 `i` 变化时继续，天然是线性扫描；所有翻转的区间互不重叠，翻转总代价也不超过 $n$。
6. **C++ 的 `std::reverse` 是左闭右开**：`reverse(res.begin() + i, res.begin() + j + 1)` 才对应闭区间 $[i, j]$；`j + 1` 最大取到 `n`，正好是可以的尾后迭代器。
7. **Python 切片赋值**：`res[i:j+1] = reversed(res[i:j+1])` 语义清晰；也可以写 `res[i:j+1] = res[i:j+1][::-1]`，两者都会新建 $O(j-i+1)$ 的临时列表，总开销仍是 $O(n)$。
8. **栈写法的哨兵**：遍历 `s + 'I'` 而不是 `s`，否则末尾的 D 段永远不会被弹出；哨兵 `'I'` 不会污染结果，它只触发一次清栈。

## 5. 正确性证明

记 $n = \lvert s \rvert + 1$，算法输出的数组为 `res`。

**引理 1（分块结构）**：把位置 $0..n-1$ 按如下方式切块：对 $s$ 的每一段极大 D 串 $s[i..j-1]$ 取块 $[i, j]$；剩下的位置各成一块（长度 1）。则这些块恰好划分 $0..n-1$，第 $k$ 个块覆盖下标 $[a_k, b_k]$，且 $a_1 = 0$，$b_k + 1 = a_{k+1}$，$b_{\text{last}} = n-1$。

**证明**：极大 D 串互不相邻（相邻会合并），且被 `'I'` 隔开；长度 1 的块只出现在 `'I'` 处。块首尾相接，覆盖全部下标，无重叠。∎

**引理 2（构造合法）**：算法输出的 `res` 满足签名 $s$。

**证明**：由引理 1，块 $k$ 覆盖 $[a_k, b_k]$。算法对这些位置的赋值恰是连续整数 $a_k+1, \dots, b_k+1$ 的某个排列（D 段为倒序，长度 1 的块原地不动），所以全部块的取值合起来正好是 $1 \sim n$，`res` 是排列。

- **块内 D 关系**：若块来自极大 D 串 $s[i..j-1]$，翻转后 $p[i], \dots, p[j] = j+1, j, \dots, i+1$ 严格递减，段内每个 D 都成立。
- **块间的 I 关系**：相邻两块 $[a, b]$、$[b+1, c]$ 之间必是 `'I'`。由赋值方式，块末尾 $p[b]$ 是块内最小值 $a+1$，而右块首元素 $p[b+1] \ge b+2 > a+1$，故 $p[b] < p[b+1]$，`'I'` 成立。

覆盖全部位置，故 `res` 合法。∎

**引理 3（贪心下界）**：设某时刻已确定前缀，剩余未使用的最小值为 $m$，当前块覆盖位置 $[i, i+k]$（$k \ge 0$）。则任意合法完成的排列 $p$ 都满足 $p[i] \ge m + k$；取等号时必有 $p[i], \dots, p[i+k] = m+k, m+k-1, \dots, m$。

**证明**：块内要求 $p[i] > p[i+1] > \cdots > p[i+k]$，这 $k+1$ 个数是从 $\{m, m+1, \dots, n\}$ 中取出的互不相同整数，最小的 $k+1$ 个候选是 $m, \dots, m+k$，故严格递减序列的首项至少为 $m+k$。若 $p[i] = m+k$，则后面 $k$ 个数都落在 $[m, m+k-1]$ 这 $k$ 个整数上且互不相同，只能依次取 $m+k-1, \dots, m$，取值被唯一确定。∎

**定理**：算法输出的是字典序最小的合法排列。

**证明**：对块数归纳。设块的顺序为引理 1 中的 $[a_1, b_1], [a_2, b_2], \dots$。算法在第 $k$ 块开始时，前 $k-1$ 块已占用 $1, \dots, a_k$（由引理 2 的证明知块 $t$ 用掉的值正是 $a_t+1..b_t+1$，逐块拼起来就是 $1..a_k$），故剩余最小值为 $m = a_k + 1$，块的右端 $b_k = a_k + k'$（记块内跨度 $k'$）。

由引理 3，任何合法排列在这个位置 $a_k$ 的取值都 $\ge m + k' = b_k + 1$，而算法的取值恰为 $b_k + 1$：若块来自 D 段，翻转后 $p[a_k] = b_k + 1$；若块长度为 1，$p[a_k] = a_k + 1 = b_k + 1$。于是**在每个块的最左位置，算法都取到了任意合法排列所能取的最小值**，且按引理 3 的等号情形，块内其余取值被唯一确定（与算法一致）。因此不存在任何合法排列在某个最左的分歧位置上比算法更小：若 $q \ne \mathrm{res}$，设 $t$ 是最小的分歧位置，它必是某个块的首位 $a_k$（否则块内取值由首位唯一确定），而 $q[t] \ge \mathrm{res}[t]$，矛盾于 $q$ 字典序更小。∎

**推论（栈写法等价）**：栈写法在遇到 `'I'` 时把自上一个 `'I'` 以来压入的连续整数全部弹出，得到的正是该块的倒序，与翻转法逐块一致，故两者输出相同。∎

## 6. 复杂度分析

- **时间**：$O(n)$。指针 `i` 从 $0$ 单调递增到 $\lvert s \rvert$，每个字符最多被判断一次；找 D 段终点的 `j` 也是单调前进，总步数不超过 $\lvert s \rvert$；各 D 段的翻转区间互不重叠，翻转元素总数 $\le n$。
- **空间**：$O(n)$。结果数组占 $n$ 个整数；除它之外只需要 `i, j` 两个下标和常数个临时变量，额外空间 $O(1)$（若把返回值不计入，则为 $O(1)$）。栈写法需要额外 $O(n)$ 的栈，但不优于翻转法。

## 7. 参考代码

### C++

```cpp
#include <algorithm>
#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> findPermutation(string s) {
        int n = (int)s.size() + 1;
        vector<int> res(n);
        for (int i = 0; i < n; i++) res[i] = i + 1;      // 字典序最小的基准排列
        int i = 0;
        while (i < (int)s.size()) {
            if (s[i] == 'I') { i++; continue; }          // 基准已满足，跳过
            int j = i;
            while (j < (int)s.size() && s[j] == 'D') j++; // j 停在 D 段之后
            reverse(res.begin() + i, res.begin() + j + 1); // 闭区间 [i, j] 倒序
            i = j;                                        // 整段跳过
        }
        return res;
    }
};
```

### Python

```python
from typing import List


class Solution:
    def findPermutation(self, s: str) -> List[int]:
        n = len(s) + 1
        res = list(range(1, n + 1))            # 字典序最小的基准排列
        i = 0
        while i < len(s):
            if s[i] == 'I':                    # 基准已满足，跳过
                i += 1
                continue
            j = i
            while j < len(s) and s[j] == 'D':  # j 停在 D 段之后
                j += 1
            res[i:j + 1] = reversed(res[i:j + 1])   # 闭区间 [i, j] 倒序
            i = j                              # 整段跳过
        return res
```

## 8. 边界情况与易错点

1. **全为 `'D'`**：如 `"DDD"` → $[4,3,2,1]$，首位取到 $n$。代码会把 $[0,3]$ 一次翻完，`j` 直接走到串尾 $\lvert s \rvert$，`reverse` 的尾后迭代器正好是 `begin() + n`，不越界。
2. **全为 `'I'`**：结果是 $1, 2, \dots, n$，循环里每次只做 `i += 1`，一次翻转都没有。
3. **长度为 1 的输入**：`"I"` → $[1,2]$，`"D"` → $[2,1]$；单个 D 段只覆盖 2 个数，翻转即交换。
4. **空输入**（题意保证 $\lvert s \rvert \ge 1$，但代码要稳）：`n = 1`，`res = [1]`，`while` 不进入，返回 $[1]$。
5. **`i = j` 写成 `i += 1`**：同一个 D 段会被反复翻转，例如 `"DD"` 得到 $[3,1,2]$，第二个 D 不成立。这是本题最常见的实现 bug。
6. **翻转区间差一**：D 串是 $s[i..j-1]$，但整段涉及的下标是 $p[i..j]$。少翻一个或把 `j` 当开区间，都会让最后一个 D 关系失效。
7. **栈写法漏哨兵**：直接遍历 `s` 而不补 `'I'`，末尾那段 D 永远留在栈里没弹出，答案长度不足 $n$。
8. **不要退回 $O(n^2)$ 的写法**：例如对每个 `'D'` 单独做一次相邻交换（冒泡式修正），$\lvert s \rvert = 10^4$、全 D 时会退化到 $10^8$，虽然可能勉强过，但没有必要的风险。
