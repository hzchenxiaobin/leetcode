# LeetCode 构造矩形 题解

## 1. 题目概述

- **标题 / 题号**：构造矩形（#492，easy）
- **链接**：https://leetcode.cn/problems/construct-the-rectangle/
- **来源**：LeetCode 第 16 场周赛 B 卷 Q4
- **难度**：简单
- **标签**：数学

**题意**：给定页面面积 `area`，构造一个整数边长的矩形，边长写作 $[L, W]$（长、宽），满足三个条件：$L \times W = \text{area}$；$L \ge W$；$L - W$ 尽可能小。返回 `[L, W]`。

换句话说：在 `area` 的所有**约数对** $(w,\ \text{area}/w)$ 中，挑出「两数最接近」的那一对，并把大的放前面。

**约束**：

- $1 \le \text{area} \le 10^7$
- 返回值长度固定为 2，顺序是 $[L, W]$

## 2. 示例

**示例 1**

```text
输入：area = 4
输出：[2, 2]
解释：全部方案 [1,4]、[2,2]、[4,1]；
      [1,4] 不满足 L >= W；
      [2,2] 的差值为 0，优于 [4,1] 的差值 3。
```

**示例 2**

```text
输入：area = 37
输出：[37, 1]
解释：37 是质数，唯一的合法方案就是 37 x 1。
```

**示例 3**

```text
输入：area = 122122
输出：[427, 286]
解释：122122 = 2 x 7 x 11 x 13 x 61；
      不超过 sqrt(area) = 349 的最大约数是 286，对应 L = 427，差值 141。
```

## 3. 解题思路

### 3.1 暴力思路

最直白的做法是枚举宽度 $W = 1, 2, \dots, \text{area}$：若 $W \mid \text{area}$ 且 $\text{area}/W \ge W$，就用 $\text{area}/W - W$ 更新答案。

- 时间 $O(\text{area})$，$\text{area} = 10^7$ 时单次调用最多 $10^7$ 次取模，C++ 勉强能过、Python 已接近超时；
- 更糟的是，穷举把「$W$ 与 $\text{area}/W$ 是一对」这个**对称结构**完全浪费了：只要检查到 $\sqrt{\text{area}}$ 为止就够。

关键问题变成：能不能只枚举一半候选，并且保证不漏掉最优解？

### 3.2 核心观察：约数对镜像对称，答案取最大可行宽度

![约数对关于根号 area 镜像对称](images/wc16_q4_sqrt_factor_pairs.svg)

把每个合法的宽 $W$ 和它的搭档 $L = \text{area}/W$ 看成数轴上关于中心对称的一对点。因为 $W \cdot L = \text{area}$：

$$W \le L \iff W \le \frac{\text{area}}{W} \iff W^2 \le \text{area} \iff W \le \lfloor\sqrt{\text{area}}\rfloor$$

于是**合法解全部落在左半边**——候选宽度只有 $1 \sim \lfloor\sqrt{\text{area}}\rfloor$ 这一个区间，且每个合法解唯一对应一个该区间内的约数。

再看目标函数。在 $W \le \sqrt{\text{area}}$ 上

$$f(W) = \frac{\text{area}}{W} - W$$

是**严格递减**的：$W$ 变大时被减数变小、减数变大，两头都在收窄。所以「差值最小」等价于「在可行宽度里取最大的那个」。

> 💡 **一句话结论**：$W^{*}$ = 不超过 $\lfloor\sqrt{\text{area}}\rfloor$ 的**最大约数**，答案就是 $[\text{area}/W^{*},\ W^{*}]$。

### 3.3 算法流程

![自顶向下扫描约数](images/wc16_q4_scan_flow.svg)

既然要「最大的可行约数」，就**从大到小**试，第一个命中即停：

1. 令 $w \leftarrow \lfloor\sqrt{\text{area}}\rfloor$（由 3.2，它是可能的最大宽度）；
2. 若 $\text{area} \bmod w = 0$，直接返回 $[\text{area}/w,\ w]$；
3. 否则 $w \leftarrow w - 1$，回到第 2 步。

因为 $1$ 一定是约数，循环必定在 $w \ge 1$ 处停止，不会越界。整个流程是单层循环 + 一条取模，没有任何数据结构。

### 3.4 示例演算

![area = 122122 的扫描过程](images/wc16_q4_walkthrough_122122.svg)

以 `area = 122122` 为例：$349^2 = 121801 < 122122 < 350^2 = 122500$，起点 $w = 349$。

| 步骤 | $w$ | $122122 \bmod w$ | 判定 |
|------|-----|------------------|------|
| 1 | 349 | 321 | 否，$w \leftarrow 348$ |
| 2 | 348 | 322 | 否，$w \leftarrow 347$ |
| 3 | 347 | 325 | 否，$w \leftarrow 346$ |
| … | 346 → 288 | … | 连续 59 个候选都不整除 |
| 63 | 287 | 147 | 否，$w \leftarrow 286$ |
| 64 | 286 | 0 | **是**，返回 $[122122/286,\ 286] = [427,\ 286]$ |

共检查 $349 - 286 + 1 = 64$ 个候选，其中 63 次是「一次取模就否决」。差值 $427 - 286 = 141$，而 $182 \times 671$ 的差值是 489，确实更差。

## 4. 算法细节

1. **起点必须是精确的整数平方根**：取 $\lfloor\sqrt{\text{area}}\rfloor$。Python 用 `math.isqrt(area)`；C++ 用 `(int)sqrt((double)area)` 后再补一句 `while ((long long)w * w > area) --w;` 兜住浮点误差（`area = 10^7` 附近必须谨慎）。
2. **返回值顺序**：`[L, W] = [area / w, w]`，长在前、宽在后。因为 $w \le \sqrt{\text{area}}$，所以 `area / w >= w` 天然成立，无需交换。
3. **循环安全**：`area >= 1`，且 $1$ 整除任何数，所以 `w` 最坏减到 1 时必然返回，不会出现 `w == 0` 的除零。
4. **循环不变式**：每轮开始前，区间 $(w,\ \lfloor\sqrt{\text{area}}\rfloor]$ 内不存在 `area` 的约数——这正是「第一个命中就是最大约数」的依据（见 §5 引理 3）。
5. **不需要质因数分解**：试除到 $\sqrt{\text{area}}$ 已经是最简方案；先分解再凑「最接近 $\sqrt{\text{area}}$ 的约数组合」本质是子集选择问题，规模小时反而更慢更易错。
6. **整数与溢出**：`area <= 10^7`，`area / w * w == area` 全程落在 `int` 内；只有 `w * w` 的校验建议提升到 `long long`，避免对更大的 `area` 复用时溢出。
7. **不要从 $w = 1$ 往上找**：那样找到的是**最小**约数（即 $[\text{area},\ 1]$），恰好是差值最大的方案，方向必须自顶向下。

## 5. 正确性证明

**引理 1（合法宽度的范围）**：若 $(L, W)$ 是满足 $L \ge W$ 且 $L \cdot W = \text{area}$ 的整数解，则 $W \mid \text{area}$ 且 $W \le \lfloor\sqrt{\text{area}}\rfloor$。

**证明**：由 $L = \text{area}/W$ 为整数得 $W \mid \text{area}$；由 $W^2 \le W \cdot L = \text{area}$ 得 $W \le \sqrt{\text{area}}$，两边取整即得 $W \le \lfloor\sqrt{\text{area}}\rfloor$。∎

**引理 2（目标函数单调）**：$f(W) = \text{area}/W - W$ 在 $1 \le W \le \lfloor\sqrt{\text{area}}\rfloor$ 上严格递减。

**证明**：设 $1 \le W_1 < W_2$，则

$$f(W_1) - f(W_2) = \frac{\text{area}}{W_1} - \frac{\text{area}}{W_2} + (W_2 - W_1) = \frac{\text{area}(W_2 - W_1)}{W_1 W_2} + (W_2 - W_1) > 0$$

故 $f(W_1) > f(W_2)$。∎

**引理 3（循环退出时 $w$ 是最大可行约数）**：循环结束时被返回的 $w$ 等于 $\max\{d : d \mid \text{area},\ d \le \lfloor\sqrt{\text{area}}\rfloor\}$。

**证明**：初始 $w_0 = \lfloor\sqrt{\text{area}}\rfloor$。归纳：若 $w$ 不是约数，则任何 $d > w$ 且 $d \le w_0$ 都已在之前各轮中被否决，故 $w$ 以上的候选里不存在约数；此时令 $w \leftarrow w-1$，不变式保持。循环仅在 `area % w == 0` 时退出，此时 $w$ 自身是约数，结合不变式即知它是区间内最大的约数。∎

**定理**：算法返回的 $[\text{area}/W^{*},\ W^{*}]$ 是所有合法方案中 $L - W$ 最小者。

**证明**：由引理 1，任一合法方案的宽都在 $[1, \lfloor\sqrt{\text{area}}\rfloor]$ 内且是 `area` 的约数；由引理 3，$W^{*}$ 是该集合的最大元素。对任意合法宽 $W \le W^{*}$，由引理 2 的严格递减性得 $f(W) \ge f(W^{*})$，等号仅在 $W = W^{*}$ 时成立。因此 $W^{*}$ 对应的方案差值最小，且最优解唯一。∎

## 6. 复杂度分析

- **时间**：$O(\sqrt{\text{area}})$。最坏情况（`area` 为质数）从 $\lfloor\sqrt{\text{area}}\rfloor$ 一路减到 1，共 $\lfloor\sqrt{\text{area}}\rfloor$ 轮，每轮一次取模，$O(1)$；`area = 10^7` 时上界约 3162 轮，远小于时限。
- **空间**：$O(1)$。只用到 `w` 一个整型变量和长度为 2 的返回数组。

## 7. 参考代码

### C++

```cpp
#include <cmath>
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> constructRectangle(int area) {
        int w = (int)sqrt((double)area);        // floor(sqrt(area))
        while ((long long)w * w > area) --w;    // 兜住浮点误差
        while (area % w != 0) --w;              // 自顶向下找最大约数
        return {area / w, w};                   // L 在前，W 在后
    }
};
```

### Python

```python
from math import isqrt


class Solution:
    def constructRectangle(self, area: int) -> list[int]:
        w = isqrt(area)          # 精确的 floor(sqrt(area))，无浮点误差
        while area % w != 0:     # 自顶向下扫，第一个约数即答案
            w -= 1
        return [area // w, w]    # area // w >= w 自动成立
```

## 8. 边界情况与易错点

1. **`area = 1`**：`w = 1`，直接返回 `[1, 1]`，不能因为「矩形退化」而特判返回空数组。
2. **`area` 是质数**：例如 37、9999991，循环会一直减到 1，返回 $[\text{area},\ 1]$；这条路径也验证了循环下界必须取到 1。
3. **`area` 是完全平方数**：`w = isqrt(area)` 第一步就整除，返回 $[\sqrt{\text{area}},\ \sqrt{\text{area}}]$，差值 0，是最优下界。
4. **浮点 `sqrt` 截断误差**：`(int)sqrt((double)area)` 可能比真实的 $\lfloor\sqrt{\text{area}}\rfloor$ 差 1。偏小时只是多跑一轮；偏大时 `w * w > area`，必须用 `while ((long long)w * w > area) --w;` 修正。Python 一律用 `isqrt`，不要写 `int(area ** 0.5)`。
5. **返回顺序写反**：题目要求 `[L, W]` 且 $L \ge W$，若写成 `[w, area / w]` 会导致 `L < W` 而 WA。
6. **扫描方向写反**：从 1 向上扫会得到差值最大的解，务必从 $\lfloor\sqrt{\text{area}}\rfloor$ 向下扫。
7. **除零风险**：`w` 递减到 0 只可能在 `area` 为 0 时发生，而约束保证 `area >= 1`；若扩展输入范围，需要在循环前加保护。

**延伸思考**：

1. 若把「差值最小」换成「周长最小」，因为周长 $= 2(L + W) = 2(\text{area}/W + W)$ 在 $W \le \sqrt{\text{area}}$ 上同样单调递减，答案与本题完全一致——两个目标在约数对上是同一个序。
