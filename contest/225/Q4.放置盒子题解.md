# LeetCode 放置盒子 题解

## 1. 题目概述

- **标题 / 题号**：放置盒子（#1739，hard）
- **链接**：https://leetcode.cn/problems/building-boxes/
- **来源**：LeetCode 第 225 场周赛 Q4
- **难度**：困难
- **标签**：贪心，数学，二分查找

**题意**：房间是边长 $n$ 的立方体（长、宽、高都是 $n$），要把 $n$ 个 $1\times 1\times 1$ 的盒子全部放进去。盒子可以放在地面任意位置；但若盒子 $x$ 放在盒子 $y$ 的**正上方**，则 $y$ 的四个竖直侧面都**必须**紧贴另一个盒子或墙。求**触碰地面的盒子数的最小值**。

换句话说：给定 $n$ 个盒子，在支撑规则下把它们堆成一个「塔群」，问底层最少要占多少个格子。注意目标不是「能放多少」，而是「$n$ 个盒子全部放完时，底层格数尽量少」。

**约束**：

- $1 \le n \le 10^9$
- 房间的边长也是 $n$，远大于任何最优结构需要的跨度，因此**远离角落的那两面墙永远不起作用**，只有角落的两面墙能「免费」当支撑
- 盒子的长宽高都是 $1$，所有坐标可视为整数格点

## 2. 示例

**示例 1**

```text
输入：n = 3
输出：3
解释：3 个盒子只能全部放在地面上（只有一个盒子时，它的四个侧面没有盒子可依靠，无法再往上叠）。
```

**示例 2**

```text
输入：n = 4
输出：3
解释：底层沿角落摆成 3 格的「L 形」，第 4 个盒子叠在角上。
      角上那格的 -x、-y 两侧贴墙，(1,0)、(0,1) 两侧有盒子，四个侧面满足要求。
```

**示例 3**

```text
输入：n = 10
输出：6
解释：底层 6 格摆成三角形（行数 3、2、1），其上依次放 3、1 个盒子，
      共 6 + 3 + 1 = 10 个，底层只要 6 格。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的想法是搜索：枚举底层占用的格子集合 $S$，再枚举每格向上叠多高，检查支撑规则。单是「底层格子集合」就有 $2^{O(n)}$ 种，$n = 10^9$ 时完全不可做。

换个方向：如果**固定底层格子数 $b$**，能不能求出「用 $b$ 个触地盒子最多能放多少个盒子」？若记这个最大值为 $G(b)$，答案就是最小的 $b$ 使 $G(b) \ge n$。而 $b$ 的量级是 $O(n^{2/3})$（$n = 10^9$ 时约 $1.65\times 10^6$），逐个枚举同样太慢，所以关键变成：**推导 $G(b)$ 的闭式**。

### 3.2 核心观察：角落阶梯金字塔

**观察 1（永远贴角）**：墙只在盒子的侧面贴墙时才有用，所以最优摆放必然靠住房间的一个角，让底层格子同时贴住两面墙。把靠角的两条方向记为 $i$、$j$ 轴，格子用 $(i,j)$ 表示。

**观察 2（高度刻画）**：设 $(i,j)$ 这一列叠了 $d(i,j)$ 个盒子（$d=0$ 表示该格没盒子）。摆放合法，当且仅当对每个格子 $(i,j)$ 的每个**房间内**的 4 邻居 $(i',j')$：

$$d(i,j) \le d(i',j') + 1$$

即每一列都要比它的四个邻居「矮不超过 1」。这条不等式把三维的支撑规则压缩成了一个**逐格的高度约束**，是后面所有推导的基础。

**观察 3（阶梯金字塔）**：取底层的三角形区域 $\{(i,j) : i+j \le h-1\}$，共 $T_h = \frac{h(h+1)}{2}$ 格，并令 $d(i,j) = h - i - j$。它满足观察 2 的不等式（相邻格高度正好差 1），于是全部能放下，总盒数为

$$\sum_{i+j \le h-1} (h-i-j) = \sum_{k=1}^{h} T_k = F(h) = \frac{h(h+1)(h+2)}{6}$$

注意第 $z$ 层（从下往上数）的盒子数是 $T_{h-z+1}$：$T_h, T_{h-1}, \dots, T_1$，即「底层大三角形，逐层收缩」。

![角落阶梯金字塔：底层占用 T_h 格时最多能放 F(h) 个盒子](images/wc225_q4_staircase_model.svg)

### 3.3 算法流程

$h$ 层阶梯金字塔是「刚好用完」的最省结构。如果 $n$ 比 $F(h)$ 多出 $r$ 个盒子，多出来的部分**不可能叠在塔尖上**（塔尖那格高 $h$，它的两个外侧邻居都是空的，撑不住第 $h+1$ 层），只能拿去把底层往「斜坡方向」铺宽。

把底层从 $T_h$ 格扩到 $T_h + k$ 格（把前 $k$ 行各向右延长 1 格），上层会连带多出 $k-1, k-2, \dots, 1$ 格，总增益为一个三角形数：

$$G(T_h + k) = F(h) + T_k, \qquad 0 \le k \le h$$

于是算法只有三步：

1. 求最大的 $h$ 使 $F(h) \le n$；
2. 令 $base = T_h$，$rest = n - F(h)$；
3. 求最小的 $k$ 使 $T_k \ge rest$，答案 $= base + k$。

![算法流程：先求最大 h，再求最小 k](images/wc225_q4_flow.svg)

第 3 步既可以线性递增（$k \le h+1 \approx 1817$，完全够快），也可以直接解二次方程：

$$k = \left\lceil \frac{\sqrt{8 \cdot rest + 1} - 1}{2} \right\rceil$$

### 3.4 示例演算

以 $n = 13$ 为例：$F(3) = 10 \le 13 < F(4) = 20$，所以 $h = 3$，$base = T_3 = 6$，$rest = 3$；最小的 $k$ 满足 $T_k \ge 3$ 是 $k = 2$，答案 $= 6 + 2 = 8$。

实际摆放（底层行长为 $4,3,1$，共 8 格）与各列高度如下，总盒数 $3+2+2+1+2+1+1+1 = 13$，恰好是 $8 + 4 + 1$：

| $n$ | $h$ | $F(h)$ | $base = T_h$ | $rest$ | $k$ | 答案 |
| --- | --- | --- | --- | --- | --- | --- |
| 3 | 1 | 1 | 1 | 2 | 2 | 3 |
| 4 | 2 | 4 | 3 | 0 | 0 | 3 |
| 10 | 3 | 10 | 6 | 0 | 0 | 6 |
| 13 | 3 | 10 | 6 | 3 | 2 | 8 |

![演算表：n = 3、4、10、13 的 h、rest、k 与最终答案](images/wc225_q4_walkthrough.svg)

## 4. 算法细节

1. **求 $h$**：从 $h = 0$ 开始，`while (h+1)*(h+2)*(h+3)/6 <= n: ++h`。由于 $F(h) \approx h^3/6$，$h$ 最多约 $1816$，循环是 $O(\sqrt[3]{n})$；也可以用 `upper_bound` 二分，$O(\log n)$。
2. **求 $base$**：$base = T_h = h(h+1)/2$，它就是底层触地的格子数（每格至少 1 个盒子）。
3. **剩余量**：$rest = n - F(h)$，由 $h$ 的最大性必有 $0 \le rest < T_{h+1}$，因此第 3 步求出的 $k \le h+1$。
4. **求 $k$**：$rest = 0$ 时 $k = 0$（$n$ 正好是完整金字塔，例如 $n = 4, 10, 20, 35$）；否则取最小的 $k$ 使 $T_k \ge rest$，可用 `while k*(k+1)/2 < rest: ++k` 或解二次方程取整。
5. **答案**：$base + k$。当 $k = h+1$ 时答案正好等于 $T_{h+1}$，即「下一级完整金字塔的底层」，不需要特判。
6. **只算数量，不构造方案**：整个过程不落地任何坐标，因此既不用开数组也不用模拟，空间 $O(1)$。
7. **整型溢出**：$F(h+1) = (h+1)(h+2)(h+3)/6$ 在 $n = 10^9$ 附近仍约为 $10^9$，但三个因子连乘的中间值约 $6\times 10^9$，**超过 32 位**，C++ 里必须用 `long long`（或先除后乘）。

## 5. 正确性证明

**引理 1（高度刻画）**：把每列盒子数记为 $d(i,j)$，则摆放合法 $\iff$ 对每个格子的每个房间内 4 邻居都有 $d(i,j) \le d(i',j') + 1$。

**证明**：

*必要性*：设 $d(i,j) = t \ge 2$，则第 $t$ 层的盒子压在 $(i,j,t-2)$ 上，规则要求 $(i,j,t-2)$ 的四个侧面都有盒子或墙。对每个房间内的邻居 $(i',j')$，其对应位置必然有盒子，即 $d(i',j') \ge t-1$，整理即 $d(i,j) \le d(i',j')+1$。$t = 1$ 时不等式自动成立。

*充分性*：给定满足不等式的 $d$，在每格 $(i,j)$ 竖直堆 $d(i,j)$ 个盒子。取第 $z$ 层的盒子（$z \ge 2$，压在 $(i,j,z-2)$ 上），对它的每个侧面：贴墙的一侧直接满足；否则该侧对应邻居 $(i',j')$，由 $d(i,j) \ge z$ 与不等式得 $d(i',j') \ge z-1$，即 $(i',j',z-2)$ 有盒子。故支撑条件全部满足。∎

**引理 2（距离上界）**：设底层格子集合为 $S$（$|S| = b$），则 $\sum_{(i,j)\in S} d(i,j) \le \sum_{(i,j) \in S} \operatorname{dist}\big((i,j), S^{c}\big)$，其中 $\operatorname{dist}$ 是房间内的 4-邻接距离、$S^{c}$ 是房间内不属于 $S$ 的格子；且取 $d = \operatorname{dist}$ 时等号可达。

**证明**：任取 $(i,j)$ 到 $S^c$ 的一条最短路径 $(i,j) = u_0, u_1, \dots, u_L$，其中 $u_L \in S^c$ 即 $d(u_L) = 0$。由引理 1 沿路径累加 $L$ 次：$d(u_0) \le d(u_1) + 1 \le \cdots \le d(u_L) + L = L$，取所有路径的最小值即得 $d(i,j) \le \operatorname{dist}((i,j), S^c)$。另一方面，距离函数本身是 $1$-Lipschitz 的，满足引理 1 的不等式，故该上界可整体达到。∎

**引理 3（边界计数）**：设 $T$ 是一族格子，$\partial T$ 为「不属于 $T$ 但与 $T$ 中某格 4-邻接」的格子集合（靠墙方向不计）。若把 $T$ 逐行向角落压缩（行长单调不增、向左对齐）得到阶梯形，则 $|T|$ 不变而 $|\partial T|$ 不增；对行长 $r_0 \ge r_1 \ge \cdots \ge r_{t-1} \ge 1$ 的阶梯形，

$$|\partial T| = r_0 + 1, \qquad |T| \le T_{r_0}$$

**证明**：压缩每一步只把格子往角落挪，随后比较边界：右边界每行贡献 1 格（$t$ 格），阶梯落差 $r_i - r_{i+1}$ 处贡献 $r_i - r_{i+1} - 1$ 格（与下一行的右边界格重合），最下一行贡献 $r_{t-1}$ 格，又行长单调不增且不超过 $r_0$，最多只有 $r_0$ 行，故 $|T| \le T_{r_0}$。边界格数为 $|\partial T| = t + r_{t-1} + \sum_{i<t-1}(r_i - r_{i+1} - 1) = r_0 + 1$。压缩不增边界是标准结论：把某行右端的格子平移进更短的一行，只会让「右侧/下方」的邻居变少。∎

**引理 4（上一层至多多少格）**：设 $b = T_h + k$（$0 \le k \le h$），底层有 $b$ 个盒子，则上一层盒子数不超过 $T_{h-1} + \max(0, k-1)$。

**证明**：设上层集合为 $T$。每个 $(i,j) \in T$ 的 4 个邻居都在 $S$ 中，故 $S \supseteq T \cup \partial T$，于是 $b \ge |T| + |\partial T|$。

若 $k \ge 1$ 且 $|T| \ge T_{h-1} + k > T_{h-1}$，由引理 3 的压缩形式，$|T| + |\partial T| \ge |T| + h + 1 \ge T_h + k + 1 > b$，矛盾；故 $|T| \le T_{h-1} + k - 1$。若 $k = 0$，同理 $|T| > T_{h-1}$ 会推出 $|T| + |\partial T| \ge T_h + 2 > b$，故 $|T| \le T_{h-1}$。∎

![等周引理：阶梯形的外边界只由最长行决定，上一层只能落在内部格上](images/wc225_q4_boundary_lemma.svg)

**定理（$G$ 的闭式）**：$b = T_h + k$（$0 \le k \le h$，且 $T_h \le b < T_{h+1}$）时，用 $b$ 个触地盒子最多能放 $F(h) + T_k$ 个盒子。

**证明**：对 $b$ 归纳。$b = 1$ 时显然 $G(1) = 1 = F(1) + T_0$。

*上界*：底层 $b$ 格，上层 $m = |T| \le T_{h-1} + \max(0,k-1)$（引理 4）。去掉底层后，上层自身的摆放同样合法，由归纳假设总数不超过 $b + G(m)$。设 $k \ge 1$，则 $m \le T_{h-1} + (k-1)$，故

$$G(b) \le b + G(m) \le (T_h + k) + \big(F(h-1) + T_{k-1}\big) = F(h) + T_k$$

$k = 0$ 时 $m \le T_{h-1}$，同理 $G(b) \le T_h + F(h-1) = F(h) = F(h) + T_0$。

*下界*：取底层为「前 $k$ 行各延长 1 格」的阶梯形（行长为 $h+1, h, \dots, h-k+2, h-k, \dots, 1$），并令 $d$ 为到补集的距离。直接计算得第 $z$ 层（$z \ge 1$，底层为 $z = 1$）恰有 $T_{h-z+1} + \max(0, k-z+1)$ 个格子，合计 $F(h) + T_k$，故该值可达。∎

**结论**：答案是最小的 $b$ 使 $G(b) \ge n$。由 $G$ 关于 $b$ 单调不减、且 $G(T_h + k) = F(h) + T_k$，取最大的 $h$ 使 $F(h) \le n$、$k$ 为最小使 $T_k \ge n - F(h)$，则 $b = T_h + k$ 即所求。

## 6. 复杂度分析

- **时间**：求 $h$ 需要约 $O(\sqrt[3]{n})$ 次循环（$n = 10^9$ 时约 $1816$ 次）；求 $k$ 同样至多 $1817$ 次；合计 $O(\sqrt[3]{n})$，可视为常数级。若两处都改用二分，则为 $O(\log n)$。
- **空间**：只用了几个整型变量，$O(1)$，不构造任何摆放方案。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int minimumBoxes(int n) {
        long long h = 0;
        // 最大的 h 使得 h 层完整金字塔 F(h) = h(h+1)(h+2)/6 不超过 n
        while ((h + 1) * (h + 2) * (h + 3) / 6 <= n) ++h;
        long long used = h * (h + 1) * (h + 2) / 6;
        long long base = h * (h + 1) / 2;  // 底层触地格子数 T_h
        long long rest = n - used;         // 还差多少个盒子
        long long k = 0;
        while (k * (k + 1) / 2 < rest) ++k;  // 最小的 k 使 T_k >= rest
        return (int)(base + k);
    }
};
```

### Python

```python
class Solution:
    def minimumBoxes(self, n: int) -> int:
        # F(h) = h(h+1)(h+2)/6：h 层完整阶梯金字塔的盒子总数
        h = 0
        while (h + 1) * (h + 2) * (h + 3) // 6 <= n:
            h += 1
        used = h * (h + 1) * (h + 2) // 6
        base = h * (h + 1) // 2          # 底层触地格子数 T_h
        rest = n - used                  # 剩余盒子数
        k = 0
        while k * (k + 1) // 2 < rest:   # 最小的 k 使 T_k >= rest
            k += 1
        return base + k
```

## 8. 边界情况与易错点

1. **$n = 1, 2, 3$**：$h = 1$，$base = 1$，$rest = 0, 1, 2$，得到 $k = 0, 1, 2$，答案 $1, 2, 3$。$n = 3$ 说明「补盒子」有时一个底层格子都省不下来。
2. **$rest = 0$（完全金字塔）**：$n = 4, 10, 20, 35, 56, \dots$ 时 $k = 0$，答案就是 $T_h$，不要误进 while 循环加 1。
3. **$k$ 可以等于 $h+1$**：当 $rest > T_h$ 时，答案 $= T_h + (h+1) = T_{h+1}$，即下一级金字塔的底层，此时 $G$ 恰好跳变到 $F(h+1) \ge n$，无需特判。
4. **溢出**：`(h+1)*(h+2)*(h+3)` 约 $6 \times 10^9$，32 位 `int` 会溢出，必须 `long long`；Python 无此问题。
5. **房间够不够大**：最优结构底层最长行 $r_0 = h+1 \le 1817$、高度 $h \le 1816$；而当 $n$ 很小时 $h \approx \sqrt[3]{6n}$ 也随之变小（$n \le 2$ 时 $r_0 \le 2$），所以结构始终放得进边长 $n$ 的房间，不必额外判越界。
6. **不要真的去模拟摆放**：本题只问数量；一旦试图构造坐标，就会引入 $O(n)$ 的模拟与大量边界讨论。
