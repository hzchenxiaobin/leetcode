# LeetCode 满足三条件之一需改变的最少字符数 题解

## 1. 题目概述

- **标题 / 题号**：满足三条件之一需改变的最少字符数（#1737，medium）
- **链接**：https://leetcode.cn/problems/change-minimum-characters-to-satisfy-one-of-three-conditions/
- **来源**：LeetCode 第 225 场周赛 Q2
- **难度**：中等
- **标签**：哈希表、字符串、计数、前缀和

**题意**：给定两个仅由小写字母组成的字符串 `a` 和 `b`。一次操作可以把 `a` 或 `b` 中的**任意一个字符**改成**任意小写字母**。目标是让下面三个条件**之一**成立：

1. `a` 中每个字母都**严格小于** `b` 中每个字母（按字母表序）；
2. `b` 中每个字母都严格小于 `a` 中每个字母；
3. `a` 和 `b` 都**只由同一个字母**组成（两串各自全同，且用的是同一个字母）。

返回达成目标所需的最少操作次数。

**约束**：

- $1 \le \text{a.length},\ \text{b.length} \le 10^5$
- `a`、`b` 仅由小写字母组成

## 2. 示例

**示例 1**

```text
输入：a = "aba", b = "caa"
输出：2
解释：
- 条件 1：把 b 的两个 'a' 改成 'c'，得 b = "ccc"（2 次），'b' < 'c' 成立；
- 条件 2：a 改成 "bbb"（1 次）+ b 改成 "aaa"（2 次），共 3 次；
- 条件 3：a 的 'b'→'a'（1 次）+ b 的 'c'→'a'（1 次），共 2 次。
最优 2 次（条件 1 与条件 3 并列）。
```

**示例 2**

```text
输入：a = "dabadd", b = "cda"
输出：3
解释：条件 1 的最佳方案是把 b 全改成 "eee"（3 次），max(a) = 'd' < 'e' = min(b)。
```

**示例 3**（边界情形：答案为 0）

```text
输入：a = "z", b = "a"
输出：0
解释：b 的每个字母 'a' 都严格小于 a 的每个字母 'z'，条件 2 天然成立。
```

## 3. 解题思路

### 3.1 暴力思路

最朴素的想法是给每个字符独立决定目标字母，但每个字符有 26 种选择，搜索空间是 $26^{|a|+|b|}$，直接爆炸。

退一步观察：三个条件都只关心两串字母的**值域分布**（最大值、最小值、是否全同），与字符的**位置**无关。所以先压成频次表 `cntA[26]`、`cntB[26]`，信息不丢。此时对每个条件分别枚举「阈值 / 目标字母」，再逐个 $O(26)$ 扫频次数组数违规个数，总代价 $O(26^2) = 676$——能过，但没吃透结构。

> ⚠️ **症结**：条件 1/2 的代价本质是「某串中 $> c$ 的字母数 + 另一串中 $\le c$ 的字母数」，两者都是**值域上的区间计数**，而区间计数正是前缀和的招牌场景。不预处理前缀和，每个候选都要现算一遍区间和，浪费了重复计算。

### 3.2 核心观察：三个条件统一为「枚举一个字母 c」

![三个条件的统一视角：值域切分与同字母归并](images/wc225_q2_three_conditions.svg)

**洞察 1：条件 1/2 = 值域切分。**「`a` 的每个字母 < `b` 的每个字母」等价于 $\max(a) < \min(b)$。只需选一个**边界字母** $c$，把 `a` 全部压到 $\le c$、`b` 全部压到 $> c$（即 $\ge c+1$），两侧值域**不重叠**，天然严格。条件 2 只是把 `a`、`b` 对调，公式镜像。

**洞察 2：条件 3 = 同字母归并。**枚举统一字母 $c \in [$ `'a'`, `'z'` $]$，把两串中所有 $\ne c$ 的字符各改一次成 $c$ 即可。

**洞察 3：每步操作代价恒为 1，与「改成哪个字母」无关。**违规字符改到合法侧的**任意**字母代价都一样（比如统统改成 `'a'` 或 `'z'`），不存在「挑最近字母」的问题——所以固定 $c$ 后的代价**恰好等于违规字符的计数**。

三个条件的代价全是值域区间计数。对边界 $c$，条件 1 的代价为

$$\text{ops}_1(c) = \underbrace{(\text{lenA} - \text{preA}[c])}_{a\text{ 中} > c\text{ 的字符数}} + \underbrace{\text{preB}[c]}_{b\text{ 中} \le c\text{ 的字符数}}$$

其中 $\text{preA}[c]$ 是 `a` 中 $\le c$ 的字符个数（**值域前缀和**）。预处理后，每个 $c$ 的代价 $O(1)$ 查表。

> 💡 **边界 $c$ 为什么只到 `'y'`？** `b` 侧要放 $> c$ 的字母，$c = $ `'z'` 时无字母可选，而 `b` 非空。所以条件 1/2 只枚举 $c \in [$ `'a'`, `'y'` $]$ 共 25 个；条件 3 不切分值域，$c$ 可取满 26 个。

### 3.3 算法流程

![频次与值域前缀和：每个候选 c 的代价 O(1) 查表](images/wc225_q2_prefix_count.svg)

1. **统计频次**：扫描 `a`、`b` 各一次，得 `cntA[26]`、`cntB[26]`，记录 `lenA`、`lenB`；
2. **条件 3**：枚举 $c \in [0, 26)$，$\text{ops}_3(c) = (\text{lenA} - \text{cntA}[c]) + (\text{lenB} - \text{cntB}[c])$，取最小；
3. **条件 1/2**：滚动累加前缀和 $\text{preA}$、$\text{preB}$，枚举 $c \in [0, 25)$，同时算 $\text{ops}_1(c) = (\text{lenA} - \text{preA}) + \text{preB}$ 与 $\text{ops}_2(c) = (\text{lenB} - \text{preB}) + \text{preA}$，取最小；
4. 返回三组的最小值。

> 💡 条件 1 与条件 2 **共用同一组前缀和**，公式只是两项对调，放在同一个循环里一起算即可。

### 3.4 示例演算

![示例演算：三条件代价表，条件 1 在 c='d' 处取得全局最小 3](images/wc225_q2_walkthrough.svg)

以示例 2 `a = "dabadd"`、`b = "cda"` 为例（只列 `'a'..'e'`，之后前缀和不再变化）：

| $c$ | `'a'` | `'b'` | `'c'` | `'d'` | `'e'` |
|-----|-------|-------|-------|-------|-------|
| `preA[c]`（a 中 ≤ c） | 2 | 3 | 3 | 6 | 6 |
| `preB[c]`（b 中 ≤ c） | 1 | 1 | 2 | 3 | 3 |
| $\text{ops}_1$（$a<b$） | 5 | 4 | 5 | **3** | 3 |
| $\text{ops}_2$（$b<a$） | **4** | 5 | 4 | 6 | 6 |
| $\text{ops}_3$（同字母） | 6 | 8 | 8 | **5** | 9 |

- $\text{ops}_1$ 在 $c = $ `'d'` 触底为 **3**：`a` 已全部 $\le$ `'d'`（零改动），`b` 三个字母全改成 `'e'`；
- $\text{ops}_2$、$\text{ops}_3$ 的行最小分别为 4、5，均劣于 3；
- 故答案 $\min(3, 4, 5) = 3$，方案 `b = "cda"` → `"eee"`。

> 💡 $c$ 越过 `a` 的最大字母 `'d'` 后，$\text{ops}_1$ 稳定在 $\text{lenB} = 3$：`a` 侧已零改动，而 `b` 全部 $\le c$ 只能全改——**最佳边界通常落在某串的最大字母附近**。

## 4. 算法细节

1. **下标与滚动前缀**：约定 $\text{preA}[c]$ 为 `a` 中 $\le$ 第 $c$ 个字母的字符个数。实现时无需显式数组，两个滚动变量在枚举 $c$ 的循环里顺手累加即可。
2. **违规字符怎么改**：条件 1 中，`a` 中 $> c$ 的字符改成 `'a'`（必 $\le c$），`b` 中 $\le c$ 的字符改成 `'z'`（必 $> c$，$c \le$ `'y'` 保证 `'z'` 可用）。由洞察 3，改成合法侧任意字母代价相同。
3. **两处循环上界不同**：条件 3 枚举 $[0, 26)$，条件 1/2 枚举 $[0, 25)$。这是本题最高频的错点（见 §8 第 1 条的反例）。
4. **条件 3 不用前缀和**：它只问「$= c$ 的个数」，是**单点**查询；条件 1/2 问「$\le c$ / $> c$ 的个数」，才是**区间**查询。
5. **答案初始化**：用 `INT_MAX` / 大值起步，三组枚举统一 `min` 进来，天然覆盖「答案为 0」的输入（如示例 3）。

## 5. 正确性证明

**引理 1（切分边界存在性）**：若字符串对 $(a', b')$ 满足条件 1，则存在 $c \in \{$ `'a'`, …, `'y'` $\}$，使 $a'$ 的所有字母 $\le c$ 且 $b'$ 的所有字母 $\ge c+1$。

**证明**：取 $c = \max(a')$（两串非空，$c$ 存在）。显然 $a'$ 的所有字母 $\le c$。由条件 1，$\min(b') > \max(a') = c$，故 $b'$ 的所有字母 $\ge c+1$；又 $\min(b') \le$ `'z'`，得 $c + 1 \le$ `'z'`，即 $c \le$ `'y'`。∎

**引理 2（固定边界的最小代价）**：固定 $c \le$ `'y'`，使 `a` 全部 $\le c$ 且 `b` 全部 $> c$ 的最少操作数恰为 $f_1(c) = (\text{lenA} - \text{preA}[c]) + \text{preB}[c]$（`preA`、`preB` 按**原串**统计）。

**证明**：**下界**：终态 `a` 全 $\le c$，故原 `a` 中每个 $> c$ 的字符必被改过；同理原 `b` 中每个 $\le c$ 的字符必被改过。两组字符分属两串、互不重叠，操作数至少为两者计数之和 $f_1(c)$。**上界**：把 `a` 中 $> c$ 的每个字符改成 `'a'`、`b` 中 $\le c$ 的每个字符改成 `'z'`（$c \le$ `'y'` 保证 `'z' > c$ 可用），其余不动，恰好 $f_1(c)$ 次操作达成要求。∎

**引理 3（条件 3 的最小代价）**：固定 $c$，使两串都全为 $c$ 的最少操作数恰为 $f_3(c) = (\text{lenA} - \text{cntA}[c]) + (\text{lenB} - \text{cntB}[c])$。

**证明**：终态两串全为 $c$，故原两串中每个 $\ne c$ 的字符必被改过，下界为其计数之和；把它们各改成 $c$ 即达上界。∎

**定理（算法最优）**：设 $f_2(c) = (\text{lenB} - \text{preB}[c]) + \text{preA}[c]$（条件 2 的对称公式），则算法输出 $ans = \min\bigl(\min_c f_1(c),\ \min_c f_2(c),\ \min_c f_3(c)\bigr)$ 等于最优值 $OPT$。

**证明**：分两个方向。

- **可达性（$ans \ge OPT$）**：由引理 2、3 的上界构造，每个候选值都对应一个可行方案，故其最小值 $ans$ 本身是可行代价，而 $OPT$ 是最小可行代价，得 $ans \ge OPT$。
- **最优性（$ans \le OPT$）**：取任一最优方案，其终态满足三条件之一。若为条件 1：由引理 1 存在 $c \le$ `'y'` 使终态 `a` 全 $\le c$、`b` 全 $> c$；于是原 `a` 中 $> c$、原 `b` 中 $\le c$ 的字符都被该方案修改过（终值必须落到对侧），由引理 2 的下界得 $OPT \ge f_1(c) \ge ans$。若为条件 2，对称地 $OPT \ge f_2(c) \ge ans$。若为条件 3：终态两串全为某个 $c$，由引理 3 的下界 $OPT \ge f_3(c) \ge ans$。

两方向合并得 $ans = OPT$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(|a| + |b| + 26)$。统计频次线性扫两串各一遍；条件 3 枚举 26 个字母、条件 1/2 枚举 25 个边界，每个候选 $O(1)$ 查表。$|a|, |b| \le 10^5$ 时总计约 $2 \times 10^5$ 次基本操作。
- **空间复杂度**：$O(26) = O(1)$。两个频次数组加两个滚动前缀变量，与输入规模无关。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minCharacters(string a, string b) {
        int cntA[26] = {0}, cntB[26] = {0};
        for (char ch : a) ++cntA[ch - 'a'];
        for (char ch : b) ++cntB[ch - 'a'];
        int lenA = a.size(), lenB = b.size();

        int ans = INT_MAX;
        for (int c = 0; c < 26; ++c)
            ans = min(ans, lenA - cntA[c] + lenB - cntB[c]);

        int preA = 0, preB = 0;
        for (int c = 0; c < 25; ++c) {  // 边界 c 至多 'y'，上界是 25
            preA += cntA[c];
            preB += cntB[c];
            ans = min(ans, min(lenA - preA + preB,   // 条件 1
                               lenB - preB + preA)); // 条件 2
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def minCharacters(self, a: str, b: str) -> int:
        cntA, cntB = [0] * 26, [0] * 26
        for ch in a:
            cntA[ord(ch) - 97] += 1
        for ch in b:
            cntB[ord(ch) - 97] += 1
        lenA, lenB = len(a), len(b)

        ans = min(lenA - cntA[c] + lenB - cntB[c] for c in range(26))

        preA = preB = 0
        for c in range(25):  # 边界 c 至多 'y'，上界是 25
            preA += cntA[c]
            preB += cntB[c]
            ans = min(ans,
                      lenA - preA + preB,  # 条件 1
                      lenB - preB + preA)  # 条件 2
        return ans
```

## 8. 边界情况与易错点

1. **条件 1/2 的循环上界必须是 25**（$c$ 至多 `'y'`）。误写成 `range(26)` / `c < 26` 时，$c = $ `'z'` 会算出 $\text{ops}_1 = (a \text{ 中} > \text{'z'} \text{ 的} = 0) + (b \text{ 中} \le \text{'z'} \text{ 的} = \text{lenB}) = \text{lenB}$ 的**假代价**。它不是无害的偏大估计，而可能**偏小**：反例 `a = "aazzz"`, `b = "z"`——正确答案是 **2**（`a` 的两个 `'a'` 改成 `'z'`，两串全 `'z'`），误写版输出 **1**，对应「把 `b` 的 `'z'` 改成 $>$ `'z'`」这一**不存在的方案**（引理 2 的上界构造在 $c = $ `'z'` 时失效，因为 `'z'` 之上无字母可放）。
2. **严格小于靠「值域不重叠」保证**：`a` 侧 $\le c$、`b` 侧 $> c$。若两侧区间重叠（例如都写 $\le c$），字母 $c$ 可同时出现在两串，失去严格性——如 `a = "a"`, `b = "a"` 会被误判为 0 成本满足条件 1。
3. **两个循环上界不同**（条件 3 是 26、条件 1/2 是 25），复制上一段循环顺手抄错是最常见的事故来源。
4. **答案可以是 0**：如 `a = "z"`, `b = "a"` 已满足条件 2。初始化用足够大的值，不要预设「至少改一次」。
5. **频次表别抄错下标**：`cntB[ch - 'a']` 误写成 `cntA` 或以 `'b'` 为基准，是复制粘贴高危区。
6. **数值范围**：总代价 $\le |a| + |b| \le 2 \times 10^5$，`int` 足够，无溢出风险。
