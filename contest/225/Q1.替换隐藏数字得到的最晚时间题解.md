# LeetCode 替换隐藏数字得到的最晚时间 题解

## 1. 题目概述

- **标题 / 题号**：替换隐藏数字得到的最晚时间（#1736，easy）
- **链接**：https://leetcode.cn/problems/latest-time-by-replacing-hidden-digits/
- **来源**：LeetCode 第 225 场周赛 Q1
- **难度**：简单
- **标签**：贪心、字符串

**题意**：给定格式为 `hh:mm` 的字符串 `time`，其中某些数字位被隐藏（用 `?` 表示）。把每个 `?` 替换成一个数字，使其成为 `00:00` 到 `23:59` 之间的合法时间，返回能得到的最晚时间。

**约束**：

- `time` 长度固定为 5，格式为 `hh:mm`
- `?` 只出现在数字位，题目保证至少能构成一个合法时间

## 2. 示例

**示例 1**

```text
输入：time = "2?:?0"
输出："23:50"
解释：以 2 开头的最晚一小时是 23，以 0 结尾的最晚一分钟是 50。
```

**示例 2**

```text
输入：time = "0?:3?"
输出："09:39"
```

**示例 3**

```text
输入：time = "1?:22"
输出："19:22"
```

## 3. 解题思路

### 3.1 暴力思路

两种朴素做法都能过（毕竟只有 4 个 `?`）：

- **组合枚举**：每个 `?` 有 10 种填法，至多 $10^4 = 10000$ 种组合，逐一校验合法性取最大。
- **倒序枚举**：从 `23:59` 向下枚举全部 1440 个合法时刻，返回第一个与非 `?` 位全部吻合的。

但签到题的正确打开方式是找**逐位贪心**的最短路径——4 次条件判断，零枚举。

### 3.2 核心观察：时间大小 = 四元组字典序，逐位贪心

![逐位贪心概念图](images/latest_time_greedy_concept.svg)

**关键观察 1**：把时间写成四元组 $(h_1, h_2, m_1, m_2)$，时间的先后顺序恰好等于这个四元组的**字典序**（小时是高位，分钟是低位，详见 §5 引理 1）。

**关键观察 2**：合法性约束只**耦合小时相邻两位**：

- 小时部分要求 $10h_1 + h_2 \le 23$，$h_1$ 与 $h_2$ 互相牵制
- 分钟部分 $m_1 \le 5$、$m_2 \le 9$ 恒可同时取到，两位等价于**独立**

于是从高位到低位，每一位取「在已定前缀下仍能补全成合法时间的最大数字」——典型的**带可行性检查的贪心**。

### 3.3 算法流程

![判定流程图](images/latest_time_decision_flow.svg)

按 $h_1 \to h_2 \to m_1 \to m_2$ 的顺序处理四个数字位（下标 2 的 `:` 恒定不动）：

1. `time[0] == '?'`：看 `time[1]`——若它固定且 $> 3$，$h_1$ 只能填 `1`；否则填 `2`
2. `time[1] == '?'`：看已定的 $h_1$——若 $h_1 = 2$，$h_2$ 最多填 `3`；否则填 `9`
3. `time[3] == '?'`：分钟十位恒可填 `5`
4. `time[4] == '?'`：分钟个位恒可填 `9`

> ⚠️ 顺序不能反：必须**先定 $h_1$ 再定 $h_2$**，因为 $h_2$ 的上限取决于 $h_1$ 是否为 2。

### 3.4 示例演算

![示例演算图](images/latest_time_walkthrough.svg)

| 输入 | $h_1$ | $h_2$ | $m_1$ | $m_2$ | 输出 |
|------|-------|-------|-------|-------|------|
| `"??:??"` | 2 | 3 | 5 | 9 | `"23:59"` |
| `"?4:3?"` | 1（被固定的 4 限制） | 4（固定） | 3（固定） | 9 | `"14:39"` |
| `"2?:22"` | 2（固定） | 3 | 2（固定） | 2（固定） | `"23:22"` |

重点看第二行：`?4:3?` 若把 $h_1$ 填成 2 得到 `24:39`，非法；只有 `14:39` 合法。这就是「看相邻位再决策」的意义。

## 4. 算法细节

1. **小时耦合的推导**：$h_1$ 的可行条件是「存在 $h_2$ 使 $10h_1 + h_2 \le 23$」：
   - $h_2$ 自由：填 $h_2 = 3$ 后 $h_1 = 2$ 可行，而 2 是数字上界，故取 2
   - $h_2$ 固定为 $d$：$d \le 3$ 时 $20 + d \le 23$，$h_1 = 2$ 可行；$d \ge 4$ 时 $20 + d > 23$ 非法，退而取 1（$10 + d \le 19$）
2. **$h_2$ 的上限**：$h_1 = 2$ 时最大可行 $h_2 = 3$；$h_1 \in \{0, 1\}$ 时 $h_2 = 9$。这一步在 $h_1$ 已定之后做，规则才成立。
3. **分钟独立**：$m_1 = 5$ 时无论 $m_2$ 取何值都有 $50 + m_2 \le 59$，故 $m_1$ 恒可取 5；$m_2 = 9$ 时由 $m_1 \le 5$ 有 $10m_1 + 9 \le 59$，恒可行。两位与前序结果无关。
4. **实现**：直接在原串上原地替换固定下标的字符，固定字符（含 `:`）一律不动。

## 5. 正确性证明

**引理 1（字典序等价）**：合法时间之间的先后顺序，等于四元组 $(h_1, h_2, m_1, m_2)$ 按位的字典序。

**证明**：合法时间对应小时值 $H = 10h_1 + h_2 \in [0, 23]$ 与分钟值 $M = 10m_1 + m_2 \in [0, 59]$，时刻数值 $T = 60H + M$。两位十进制数的大小比较即对应数位的字典序，故 $H$ 与 $(h_1, h_2)$ 字典序一致，$M$ 与 $(m_1, m_2)$ 字典序一致。又 $M_1 - M_2 \ge -59 > -60$，当 $H_1 > H_2$ 时 $T_1 - T_2 = 60(H_1 - H_2) + (M_1 - M_2) \ge 60 - 59 = 1 > 0$，即小时的差异足以压倒任何分钟的差异。故 $T$ 的大小等价于 $(H, M)$ 的字典序，进而等价于 $(h_1, h_2, m_1, m_2)$ 的字典序。∎

**引理 2（可行性保持）**：按 $h_1 \to h_2 \to m_1 \to m_2$ 顺序，每步取「当前前缀下仍存在合法补全的最大数字」，则每步取完后仍存在合法补全，且该最大值恰为 §4 规则给出的值。

**证明**：逐位验证（固定数字不被改动是前提，题设保证固定数字自洽）：

- $h_1$：合法条件为存在 $h_2$ 使 $10h_1 + h_2 \le 23$。$h_2$ 自由时 $h_1 = 2$ 可行且为数字上界；$h_2$ 固定为 $d \le 3$ 时 $h_1 = 2$ 可行，$d \ge 4$ 时 $h_1 = 2$ 不可行而 $h_1 = 1$ 可行。取的即最大可行值，且可行补全存在。
- $h_2$：$h_1$ 已定且合法。$h_1 = 2$ 时最大可行 $h_2 = 3$（$23 \le 23$）；$h_1 \le 1$ 时最大可行 $h_2 = 9$（$\le 19$）。
- $m_1$：最大可行值为 5——$m_2$ 固定为 $d$ 时 $50 + d \le 59$，$m_2$ 自由时 $50 + 9 \le 59$，补全均存在。
- $m_2$：最大可行值为 9——$m_1$ 合法意味着 $m_1 \le 5$，故 $10m_1 + 9 \le 59$。∎

**定理（贪心最优）**：按引理 2 规则填出的时间 $G$ 是所有与输入兼容的合法时间中最晚的。

**证明**：由引理 2，$G$ 合法且与输入兼容。设 $T^*$ 为任一与输入兼容的合法时间。固定数字位两者都等于输入，必然相同；设 $p$ 为第一个不同的位，则 $T^*$ 与 $G$ 在 $p$ 之前各位完全一致，即 $T^*$ 是「$G$ 的前缀」的一个合法补全，故 $T^*_p$ 是该前缀约束下的可行数字。而 $G_p$ 取的是同前缀下的最大可行数字，得 $G_p \ge T^*_p$；又 $G_p \ne T^*_p$，故 $G_p > T^*_p$，由引理 1 得 $G > T^*$。若不存在不同位则 $G = T^*$。故对一切 $T^*$ 有 $G \ge T^*$，$G$ 最晚。∎

## 6. 复杂度分析

- **时间复杂度**：$O(1)$。串长固定为 5，仅 4 次条件判断；一般化为 $O(n)$。
- **空间复杂度**：$O(1)$。原地替换（Python 中转 `list` 后 `join`，仍为常数级）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    string maximumTime(string time) {
        if (time[0] == '?')
            time[0] = (time[1] != '?' && time[1] > '3') ? '1' : '2';
        if (time[1] == '?')
            time[1] = (time[0] == '2') ? '3' : '9';
        if (time[3] == '?') time[3] = '5';
        if (time[4] == '?') time[4] = '9';
        return time;
    }
};
```

### Python

```python
class Solution:
    def maximumTime(self, time: str) -> str:
        t = list(time)
        if t[0] == '?':
            t[0] = '1' if t[1] != '?' and t[1] > '3' else '2'
        if t[1] == '?':
            t[1] = '3' if t[0] == '2' else '9'
        if t[3] == '?':
            t[3] = '5'
        if t[4] == '?':
            t[4] = '9'
        return ''.join(t)
```

## 8. 边界情况与易错点

1. **`?4:??` 类输入（最大的坑）**：$h_2$ 固定为 4~9 时 $h_1$ 只能填 1，填 2 会得到 `24:xx` 非法——「每位独立取最大」的无脑模板在这里翻车。
2. **`2?:??` 类输入**：$h_1$ 固定为 2 时 $h_2$ 最多填 3，不能照搬 9（`29:xx` 非法）。
3. **先看相邻位再决策**：$h_1$ 的规则要看 `time[1]`，$h_2$ 的规则要看刚定下的 $h_1$，顺序固定为 $h_1 \to h_2$。
4. **下标 2 恒为 `':'`**：不处理，也**不要**当成可替换字符；重建字符串时别弄丢它。
5. **固定数字无需校验**：题目保证能构成合法时间，像 `3?:..`、`?:7x` 这类固定数字本身非法的输入不会出现。
6. **分钟两位与前序无关**：$m_1$ 恒可取 5、$m_2$ 恒可取 9，不存在耦合，与小时部分的决策互不干扰。
7. **全 `?` 输入**：`"??:??"` 应得 `"23:59"`，可作为对拍基准用例。
