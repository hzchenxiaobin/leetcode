# LeetCode 找出第 K 大的异或坐标值 题解

## 1. 题目概述

- **标题 / 题号**：找出第 K 大的异或坐标值（#1738，medium）
- **链接**：https://leetcode.cn/problems/find-kth-largest-xor-coordinate-value/
- **来源**：LeetCode 第 225 场周赛 Q3
- **难度**：中等
- **标签**：位运算、数组、矩阵、前缀异或、排序、堆、快速选择

**题意**：给定一个 $m \times n$ 的**非负整数**矩阵 `matrix` 和整数 `k`。坐标 $(a, b)$ 的**目标值**定义为：对所有满足 $0 \le i \le a < m$ 且 $0 \le j \le b < n$ 的元素 `matrix[i][j]` 执行异或（$\oplus$）的结果，即**左上角矩形区域内全体元素的异或和**。返回所有 $m \cdot n$ 个坐标中**第 $k$ 大**的目标值（$k$ 从 1 开始，重复值按重数各占一名）。

**约束**：

- $1 \le m, n \le 1000$，即 $mn \le 10^6$
- $0 \le \mathrm{matrix}[i][j] \le 10^6 < 2^{20}$
- $1 \le k \le m \cdot n$

## 2. 示例

**示例 1**

```text
输入：matrix = [[5,2],[1,6]], k = 1
输出：7
解释：坐标 (0,1) 的目标值是 5 XOR 2 = 7，为最大的目标值。
```

**示例 2**

```text
输入：matrix = [[5,2],[1,6]], k = 2
输出：5
解释：坐标 (0,0) 的目标值是 5 = 5，为第 2 大的目标值。
```

**示例 3**

```text
输入：matrix = [[5,2],[1,6]], k = 3
输出：4
解释：坐标 (1,0) 的目标值是 5 XOR 1 = 4，为第 3 大的目标值。
```

**示例 4**

```text
输入：matrix = [[5,2],[1,6]], k = 4
输出：0
解释：坐标 (1,1) 的目标值是 5 XOR 2 XOR 1 XOR 6 = 0，为第 4 大的目标值。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的做法：对每个坐标 $(a,b)$ 重新遍历矩形 $R(a,b)$，把内部元素逐个异或：

- 时间复杂度 $O(m^2 n^2)$，当 $m = n = 1000$ 时高达 $10^{12}$，完全不可行。

**中间优化**：先对每一行做**一维行前缀异或** $\mathrm{rowP}[i][b] = \mathrm{matrix}[i][0] \oplus \cdots \oplus \mathrm{matrix}[i][b]$，则坐标 $(a,b)$ 的目标值为 $\bigoplus_{i=0}^{a} \mathrm{rowP}[i][b]$，单点查询降为 $O(m)$：

- 总复杂度 $O(m^2 n) = 10^9$，C++ 勉强、Python 必超时，还是不够。

症结在于：相邻坐标的矩形只差一条边，却被整块重算。需要把**矩形异或**也做成可 $O(1)$ 递推的前缀量。

### 3.2 核心观察：二维前缀异或（容斥原理）

![二维前缀异或容斥概念图](images/wc225_q3_prefix_xor_concept.svg)

定义 $P[a][b]$ 为矩形 $R(a,b)$（$0 \le i \le a$，$0 \le j \le b$）内全体元素的异或，则它可以用三个更小的前缀**容斥**出来：

$$P[a][b] = P[a-1][b] \oplus P[a][b-1] \oplus P[a-1][b-1] \oplus \mathrm{matrix}[a][b]$$

**为什么不需要减号？** 与二维前缀和不同，异或的逆运算就是它自己：$x \oplus x = 0$。把三个矩形直接异或到一起，按每个格子被覆盖的次数分类：

| 格子位置 | $P[a-1][b]$ | $P[a][b-1]$ | $P[a-1][b-1]$ | $\mathrm{matrix}[a][b]$ | 总次数 |
|---|---|---|---|---|---|
| $i < a$ 且 $j < b$（内部 A） | ✓ | ✓ | ✓ | — | 3（奇） |
| $i = a$，$j < b$（新行 B） | — | ✓ | — | — | 1 |
| $i < a$，$j = b$（新列 C） | ✓ | — | — | — | 1 |
| $i = a$，$j = b$（角格） | — | — | — | ✓ | 1 |
| $i > a$ 或 $j > b$（外部） | — | — | — | — | 0 |

偶数次出现成对抵消，奇数次出现恰好净剩一份（见 §5 引理 1）。于是上式右侧恰好等于 $R(a,b)$ 内每个元素各出现一次的异或。

> 💡 **一句话记忆**：前缀和的容斥是「加、加、减、加」；前缀异或的容斥是「异或、异或、异或、异或」——运算符全部一样，因为异或自己就是自己的逆。

### 3.3 第 k 大的选取

递推完成后手里有 $mn \le 10^6$ 个值，接下来是经典的**第 $k$ 大**问题：

![算法流程图](images/wc225_q3_flow.svg)

- **排序**：降序排序后取第 $k$ 个，$O(mn \log mn)$，约 $2 \times 10^7$ 次比较，最简单可靠；
- **小顶堆**：维护大小为 $k$ 的堆，$O(mn \log k)$，当 $k \ll mn$ 时更省；
- **计数排序**：矩阵元素 $\le 10^6 < 2^{20}$，异或结果仍在 $[0, 2^{20})$ 内（高位不会凭空产生），开 $2^{20}$ 个桶统计频次后从高往低扫，$O(mn + 2^{20})$ 理论最优；
- **快速选择**：C++ 的 `nth_element` 平均 $O(mn)$，不用完整排序。

本题数据规模下四种写法都能通过，按语言习惯选择即可（C++ 用 `nth_element`，Python 直接 `sort`）。

### 3.4 示例演算

![示例演算图](images/wc225_q3_walkthrough.svg)

以 `matrix = [[5,2],[1,6]]` 为例（$P$ 表外圈补一行一列 0 哨兵，下标从 1 开始）：

1. $P[1][1] = 0 \oplus 0 \oplus 0 \oplus 5 = 5$ —— 即坐标 $(0,0)$ 的目标值；
2. $P[1][2] = 0 \oplus 5 \oplus 0 \oplus 2 = 7$ —— 坐标 $(0,1)$；
3. $P[2][1] = 5 \oplus 0 \oplus 0 \oplus 1 = 4$ —— 坐标 $(1,0)$；
4. $P[2][2] = 7 \oplus 4 \oplus 5 \oplus 6 = 0$ —— 坐标 $(1,1)$。

四个目标值 $\{5, 7, 4, 0\}$ 降序排列为 $7, 5, 4, 0$，于是 $k=1,2,3,4$ 分别对应 $7, 5, 4, 0$，与四个官方示例完全一致。

## 4. 算法细节

1. **哨兵设计**：$P$ 开成 $(m+1) \times (n+1)$，第 0 行与第 0 列全为 0（空矩形的异或）。递推时无需对首行、首列做任何特判，代价只是多一圈内存。
2. **递推顺序**：行优先双重循环 $i = 1 \ldots m$，$j = 1 \ldots n$。计算 $P[i][j]$ 时依赖的左格、上格、左上格均已就绪。
3. **边递推边收集**：把每个 $P[i][j]$（$i, j \ge 1$）顺手 push 进一维数组 `vals`，注意**哨兵行/列的 0 不是目标值**，循环务必从 1 开始。
4. **下标偏移**：$P[i][j]$ 对应坐标 $(i-1, j-1)$ 的目标值。
5. **第 $k$ 大选择**：C++ 用 `nth_element` 配合 `greater<int>()`，使位置 $k-1$ 恰好落降序第 $k$ 名；Python 对 $10^6$ 个整数 `sort` 约零点几秒，足够。
6. **空间优化（可选）**：$P$ 表可滚动成两行（$O(n)$ 额外空间），但 `vals` 本身就需要 $O(mn)$，通常无必要。

## 5. 正确性证明

**引理 1**（异或的自逆性）：对任意非负整数 $x$，有 $x \oplus x = 0$，$x \oplus 0 = x$；因此在一串异或中，出现偶数次的值整体贡献为 0，出现奇数次的值等价于恰好出现一次。

**证明**：异或是按位的模 2 加法。同一 bit 自身相加两次为 $0 \pmod 2$，故 $x \oplus x = 0$；而 $0$ 是异或的单位元。对出现次数按奇偶性归纳即得后半句。∎

**引理 2**（容斥递推）：设 $P[a-1][b]$、$P[a][b-1]$、$P[a-1][b-1]$ 分别是各自矩形的全体元素异或，则

$$P[a-1][b] \oplus P[a][b-1] \oplus P[a-1][b-1] \oplus \mathrm{matrix}[a][b] = P[a][b]$$

**证明**：对任意格子 $(i,j)$ 统计其在右侧四项中的出现次数（见 §3.2 分类表）：内部 A 区 3 次、新行 B 区 1 次、新列 C 区 1 次、角格 $(a,b)$ 由末项贡献 1 次、矩形外部 0 次。由引理 1，每个 $R(a,b)$ 内的格子净贡献恰一份，外部格子净贡献为零，故右侧等于 $\bigoplus_{(i,j) \in R(a,b)} \mathrm{matrix}[i][j] = P[a][b]$。∎

**定理**：算法返回的正是全体坐标目标值中的第 $k$ 大。

**证明**：对 $(a,b)$ 按行优先（字典序）作归纳。基例：$a = -1$ 或 $b = -1$（哨兵）对应空矩形，异或为 0，与初始化一致。归纳步：三个更小的前缀均已是正确矩形异或（归纳假设），由引理 2，$P[a][b]$ 是 $R(a,b)$ 的正确异或。故 `vals` 恰为 $mn$ 个坐标目标值构成的多重集；又 $1 \le k \le mn$，第 $k$ 大（按重数计）必然存在，排序 / 快速选择 / 计数都正确取出该元素。∎

## 6. 复杂度分析

- **时间复杂度**：
  - 前缀异或递推：$O(mn)$，每个格子一次三路异或；
  - 第 $k$ 大选择：排序 $O(mn \log mn)$（参考代码 Python 采用），C++ `nth_element` 平均 $O(mn)$，计数排序可做到 $O(mn + 2^{20})$；
  - 总量级不超过 $2 \times 10^7$ 次基本运算。
- **空间复杂度**：$O(mn)$ —— $P$ 表 $(m+1)(n+1)$ 与值数组 `vals` 各一份；$P$ 可滚动优化到 $O(n)$，但 `vals` 不可避免。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int kthLargestValue(vector<vector<int>>& matrix, int k) {
        int m = matrix.size(), n = matrix[0].size();
        // 多加一行一列 0 哨兵，首行/首列无需特判
        vector<vector<int>> P(m + 1, vector<int>(n + 1, 0));
        vector<int> vals;
        vals.reserve((size_t)m * n);

        for (int i = 1; i <= m; ++i) {
            for (int j = 1; j <= n; ++j) {
                P[i][j] = P[i - 1][j] ^ P[i][j - 1] ^ P[i - 1][j - 1] ^ matrix[i - 1][j - 1];
                vals.push_back(P[i][j]);
            }
        }

        // 快速选择：位置 k-1 恰为降序第 k 名，平均 O(mn)
        nth_element(vals.begin(), vals.begin() + (k - 1), vals.end(), greater<int>());
        return vals[k - 1];
    }
};
```

### Python

```python
class Solution:
    def kthLargestValue(self, matrix: List[List[int]], k: int) -> int:
        m, n = len(matrix), len(matrix[0])
        # 第 0 行 / 第 0 列为 0 哨兵
        P = [[0] * (n + 1) for _ in range(m + 1)]
        vals = []
        for i in range(1, m + 1):
            row, prev, mat = P[i], P[i - 1], matrix[i - 1]
            for j in range(1, n + 1):
                row[j] = prev[j] ^ row[j - 1] ^ prev[j - 1] ^ mat[j - 1]
                vals.append(row[j])
        vals.sort(reverse=True)
        return vals[k - 1]
```

## 8. 边界情况与易错点

1. **首行 / 首列**：坐标 $(0,b)$、$(a,0)$ 的矩形退化为一条线。用哨兵下标从 1 开始递推即可无特判；若不开哨兵，必须单独处理 `$i==0 || j==0$` 的分支。
2. **循环起点**：收集 `vals` 时只收 $i, j \ge 1$ 的格子，哨兵行的 0 不是任何坐标的目标值。
3. **重复值按重数计**：全 0 矩阵的所有目标值都是 0，任何 $k$ 答案均为 0；第 $k$ 大是「多重集」意义下的名次。
4. **值域与溢出**：$\mathrm{matrix}[i][j] \le 10^6 < 2^{20}$，任意异或结果仍落在 $[0, 2^{20})$，`int` 完全够用、无溢出风险；这也是计数排序只需 $2^{20}$ 个桶的原因。
5. **k 的含义**：第 $k$ 大 = 降序第 $k$ 个 = 升序第 $mn - k + 1$ 个（0 下标为 $mn - k$），注意差一。
6. **别退化成一维前缀**：只做行前缀的 $O(m^2 n)$ 做法在本题规模下（$10^9$）会超时，务必上二维容斥。
7. **Python 提速**：内层循环把 `P[i]`、`P[i-1]`、`matrix[i-1]` 提为局部变量，$10^6$ 次循环能快约一倍。
