# LeetCode 找出最大的可达成数字 题解

## 1. 题目概述

- **标题 / 题号**：找出最大的可达成数字（#2769，easy）
- **链接**：https://leetcode.cn/problems/find-the-maximum-achievable-number/
- **来源**：LeetCode 第 353 场周赛 Q1
- **难度**：简单
- **标签**：数学

**题意**：给定整数 `num` 和 `t`。称 `x` 为**可达成数字**，若通过**不超过** `t` 次操作能使 `x` 与 `num` 相等。每次操作：将 `x` 增加或减少 `1`，**同时可以选择**将 `num` 增加或减少 `1`（`num` 也可不变）。返回所有可达成数字中的最大值 `x`。

**约束**：

- `1 <= num, t <= 50`

## 2. 示例

**示例 1**

```text
输入：num = 4, t = 1
输出：6
解释：x = 6 时，操作一次：x 减 1 变为 5，同时 num 加 1 变为 5，二者相等。
```

**示例 2**

```text
输入：num = 3, t = 2
输出：7
解释：x = 7 时，操作两次（每次 x 减 1、num 加 1）：
      操作 1：x = 6, num = 4
      操作 2：x = 5, num = 5，二者相等。
```

## 3. 解题思路

### 3.1 暴力思路

从小到大枚举候选 `x`，对每个 `x` 贪心模拟：每次操作让 `x` 朝 `num` 靠近 1、`num` 朝 `x` 靠近 1，检查 `t` 次内能否相等。由于答案是 `num + 2t`，枚举上界清楚时可行，但仍属"没想清楚"的写法。

### 3.2 核心观察：盯住差值，每次操作差值最多缩小 2

![数轴上 x 与 num 相向移动，每次操作差距缩小 2](images/max_achievable_gap_concept.svg)

**关键观察**：设差值 $d = x - num$。每次操作：

- `x` 必须变化 `±1`，`num` 至多变化 `±1`（也可不变）

因此 `d` 每次操作**至多变化** `±2`（`x` 和 `num` 相向移动时）。要让 `x == num`，即把 $d$ 归零，必须满足

$$|d| = |x - num| \le 2t$$

反之，只要 $|x - num| \le 2t$，让 `x` 与 `num` 每次相向移动（`x` 大就减，`num` 小就加），每步差值恰好缩小 `2`，最多 $\lceil |x-num|/2 \rceil \le t$ 步即可相等。

于是**最大可达成数字**就是：

$$x_{\max} = num + 2t$$

### 3.3 算法流程

```text
1. 读入 num, t
2. 输出 num + 2 * t
```

一行公式，无需循环。

### 3.4 示例演算

![num=3, t=2 时 x=7 逐步收敛到 num](images/max_achievable_walkthrough.svg)

`num = 3, t = 2`，候选 `x = 7`：

| 操作 | x | num | 差值 x − num |
|------|---|-----|--------------|
| 初始 | 7 | 3 | 4 |
| 1（x−1, num+1） | 6 | 4 | 2 |
| 2（x−1, num+1） | 5 | 5 | 0 ✓ |

初始差值 $4 = 2 \times 2 = 2t$，恰好 $t$ 步归零，故 $7$ 可达成且是最大值。

## 4. 算法细节

1. **差值视角**：把"两个变量各自变化"转化为单变量 $d = x - num$ 的变化，每次操作 $d$ 的改变量为 $\Delta d = \Delta x - \Delta num \in \{-2, -1, 0, 1, 2\}$，归零最快每步缩 `2`。
2. **上界与下界同时成立**：$|x - num| > 2t$ 时不可行（上界）；$|x - num| \le 2t$ 时相向移动可行（可达），故可行域恰为 $[num - 2t,\ num + 2t]$，取最大右端点。
3. **奇偶性无需特判**：$x - num$ 为奇数时相向移动会在中途错过？不会——`num` 侧可以"不动"（`num` 变化是可选的），差值每步缩 `1` 或 `2` 自由组合，奇数差值同样 $\le t$ 步内可归零（差值 $2t-1$ 时用 $t-1$ 步缩 `2` 再 1 步缩 `1`）。

## 5. 正确性证明

**引理 1**：若 `x` 可达成，则 $|x - num| \le 2t$。

**证明**：设第 $i$ 次操作后 $d_i = x_i - num_i$。每次操作 $x$ 变化 $\pm 1$，$num$ 变化 $\pm 1$ 或 $0$，故 $|d_i - d_{i-1}| \le |x_i - x_{i-1}| + |num_i - num_{i-1}| \le 2$。$t$ 次操作后 $d_t = 0$，而 $|d_t| \ge |d_0| - 2t$，故 $|x - num| = |d_0| \le 2t$。∎

**引理 2**：若 $|x - num| \le 2t$，则 `x` 可达成。

**证明**：不妨 $x > num$（对称）。每步操作取 $x \gets x - 1$、$num \gets num + 1$（当 $d \ge 2$），差值每步减 `2`；当 $d = 1$ 时取 $x \gets x - 1$、`num` 不变，差值减 `1`。差值从 $|x - num| \le 2t$ 出发，每步至少减 `1` 且可减 `2`，至多 $t$ 步内归零，此时 `x == num`。∎

**定理**：最大可达成数字为 $num + 2t$。

**证明**：由引理 1，可达成 `x` 满足 $x \le num + 2t$；由引理 2，$x = num + 2t$（$|x - num| = 2t \le 2t$）可达成。故最大值为 $num + 2t$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(1)$。仅一次加法与乘法。
- **空间复杂度**：$O(1)$。无额外存储。

## 8. 边界情况与易错点

1. **误写 `num + t`**：忘了 `num` 也在动，两个变量相向移动每步差值缩 `2`，答案是 `num + 2t` 而非 `num + t`。
2. **`num` 的变化是可选的**：题面"可以选择将 num 增加或减少 1"意味着 `num` 可以原地不动，处理奇数差值时靠这一点补齐最后一步，不需要任何奇偶特判。
3. **`t` 次是上界不是必须**：操作"不超过 `t` 次"，差值提前归零即可停止。
4. **溢出**：$num, t \le 50$，答案 $\le 150$，`int` 足够；但该题推广到大数据范围时需注意 `2 * t` 的乘法溢出（用 `long long` / Python 无此虑）。
