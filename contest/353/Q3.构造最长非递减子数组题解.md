# LeetCode 构造最长非递减子数组 题解

## 1. 题目概述

- **标题 / 题号**：构造最长非递减子数组（#2771，medium）
- **链接**：https://leetcode.cn/problems/longest-non-decreasing-subarray-from-two-arrays/
- **来源**：LeetCode 第 353 场周赛 Q3
- **难度**：中等
- **标签**：数组、动态规划

**题意**：给定两个长度均为 $n$ 的数组 `nums1` 与 `nums2`。构造新数组 `nums3`：每个下标 $i$ 处从 `nums1[i]` 与 `nums2[i]` 中**二选一**赋给 `nums3[i]`。要求用最优策略赋值，使 `nums3` 中**最长非递减子数组**（连续段，允许相等）的长度最大，返回该长度。

**约束**：

- $1 \le n \le 10^5$ —— 排除 $O(n^2)$ 及以上，要求线性一遍扫
- $1 \le nums1[i], nums2[i] \le 10^9$ —— 值为正、无溢出风险

## 2. 示例

**示例 1**

```text
输入：nums1 = [2,3,1], nums2 = [1,2,1]
输出：2
解释：nums3 = [nums1[0], nums2[1], nums2[2]] = [2,2,1]，
      下标 0→1 的 [2,2] 是长度为 2 的非递减子数组（相等也算非递减），2 为最大可达长度。
```

**示例 2**

```text
输入：nums1 = [1,3,2,1], nums2 = [2,2,3,4]
输出：4
解释：nums3 = [nums1[0], nums2[1], nums2[2], nums2[3]] = [1,2,3,4]，
      整个数组非递减，长度 4 为最大可达长度。
```

**示例 3**

```text
输入：nums1 = [1,1], nums2 = [2,2]
输出：2
解释：nums3 = [nums1[0], nums1[1]] = [1,1]，整个数组非递减。
```

## 3. 解题思路

### 3.1 暴力思路

每个位置有「取 A」「取 B」两种选择，共 $2^n$ 种 `nums3` 构造方案，每种再 $O(n)$ 扫一遍求最长非递减子数组，总复杂度 $O(2^n \cdot n)$，$n = 10^5$ 时天文数字。瓶颈在于**重叠子问题**：一个构造方案「好不好」，只取决于「以每个位置结尾、末尾取了哪个值的最长段长」——前缀内部怎么选，后面根本不关心。

### 3.2 核心观察：末尾值只有两种候选 ⇒ 两个并列状态

![双状态概念：每个位置二选一，末尾值必为二者之一，四条转移边](images/twoarr_nondecr_states_concept.svg)

> 💡 **关键观察一（连续 ⇒ 单前驱）**：「非递减**子数组**」要求连续，以 $i$ 结尾的段前一位必是 $i-1$——这与子序列型 DP（如 [300. LIS](https://leetcode.cn/problems/longest-increasing-subsequence/) 要枚举所有 $j<i$）是根本分野：**连续 → 只看相邻前驱；可断 → 枚举所有前驱**。

> 💡 **关键观察二（末尾值只有两种）**：位置 $i$ 的取值只能是 $a_i$ 或 $b_i$（记 $a_i = nums1[i]$，$b_i = nums2[i]$），不存在第三个候选。于是「以 $i$ 结尾的最长长度」按末尾选择拆成**两个并列状态**：

- $dp[i][0]$：`nums3[i]` 取 $a_i$ 时，以 $i$ 结尾的最长非递减子数组长度；
- $dp[i][1]$：`nums3[i]` 取 $b_i$ 时，以 $i$ 结尾的最长非递减子数组长度。

每个状态从 $i-1$ 的两个状态转移：只要「当前值 ≥ 前位末尾值」就能续接 $+1$，否则该前驱断开、从 1 重新起算：

$$
\begin{aligned}
dp[i][0] &= 1 + \max\big(\mathbb{1}[a_i \ge a_{i-1}] \cdot dp[i\!-\!1][0],\ \ \mathbb{1}[a_i \ge b_{i-1}] \cdot dp[i\!-\!1][1]\big) \\
dp[i][1] &= 1 + \max\big(\mathbb{1}[b_i \ge a_{i-1}] \cdot dp[i\!-\!1][0],\ \ \mathbb{1}[b_i \ge b_{i-1}] \cdot dp[i\!-\!1][1]\big)
\end{aligned}
$$

其中 $\mathbb{1}[\cdot]$ 在条件成立时取 1、否则取 0（不成立的那条转移贡献 0，`max` 与外层 1 保证最差从 1 起算）。边界 $dp[0][0] = dp[0][1] = 1$；答案取 $\max_{i,k} dp[i][k]$。

> ⚠️ **单状态陷阱**：若只记 $dp[i] = $ 以 $i$ 结尾的最长长度而丢掉「末尾选了哪行」的信息，续接判断 $nums3[i+1] \ge ？$ 就无从下手——「选 a 能续、选 b 不能续」（或反之）时必错。这是本题相对 [674. 最长连续递增序列](https://leetcode.cn/problems/longest-continuous-increasing-subsequence/) 的唯一升级点，也是最常见 WA 点。

### 3.3 算法流程

![O(n) 一遍扫与 O(1) 滚动变量流程](images/twoarr_nondecr_transition_flow.svg)

1. 初始化滚动变量 $dp0 = dp1 = 1$（位置 0 两个状态的值），$ans = 1$；
2. $i$ 从 $1$ 到 $n-1$：用 $dp0/dp1$（即 $dp[i-1][\cdot]$）按上式算出 $cur0/cur1$（即 $dp[i][\cdot]$）；
3. 滚动更新 $dp0 \leftarrow cur0$、$dp1 \leftarrow cur1$，并 $ans \leftarrow \max(ans, cur0, cur1)$；
4. 循环结束返回 $ans$。

### 3.4 示例演算

![示例 2 逐步填表演算](images/twoarr_nondecr_example_walkthrough.svg)

以**示例 2**（`nums1 = [1,3,2,1]`，`nums2 = [2,2,3,4]`）为例，逐位填两行 dp：

| $i$ | $a_i$ | $b_i$ | $dp[i][0]$（选 a） | $dp[i][1]$（选 b） |
|-----|-------|-------|--------------------|--------------------|
| 0 | 1 | 2 | 1（初始） | 1（初始） |
| 1 | 3 | 2 | 2（$a \ge a_0$ ✓，$a \ge b_0$ ✓） | 2（$b \ge a_0$ ✓，$b \ge b_0$ ✓） |
| 2 | 2 | 3 | 3（**仅** $a \ge b_1$ ✓，续 B 行） | 3（✓ ✓） |
| 3 | 1 | 4 | 1（✗ ✗，重新起算） | **4**（✓ ✓） |

注意 $i=2$ 选 $a=2$ 时只能续上 **B 行**（$2 \ge 2$ ✓ 而 $2 \ge 3$ ✗）——单状态 dp 在此必错。答案 $= \max\{1,1,2,2,3,3,1,4\} = 4$，对应构造 $nums3 = [1,2,3,4]$（$a_0, b_1, b_2, b_3$）。

## 4. 算法细节

1. **状态设计**：$dp[i][0/1]$ = 以 $i$ 结尾、末尾分别取 $a_i / b_i$ 的最长非递减子数组长度。初值 $dp[0][0] = dp[0][1] = 1$。
2. **四条转移逐条对齐**：$a_i \ge a_{i-1}$、$a_i \ge b_{i-1}$、$b_i \ge a_{i-1}$、$b_i \ge b_{i-1}$——写代码时四个 `if` 与四个条件一一对应，别漏交叉项（$a$ 续 $b$、$b$ 续 $a$）。
3. **滚动变量**：$dp[i]$ 只依赖 $dp[i-1]$，两个变量 $dp0/dp1$ 即可；但必须**先把 $cur0/cur1$ 都算完再覆盖**——$cur1$ 的计算仍需旧的 $dp0/dp1$，边算边覆盖会把 $i-1$ 的状态污染成 $i$ 的。
4. **答案取全局 max**：$dp$ 语义是「以 $i$ 结尾」，最优段可在任意位置结束，故答案在循环中随时收集，**不是** $dp[n-1]$。
5. **为何不能贪心**：「逐位取两候选中的较小值」看似安全（值越小越易被后位续接），实则错——它可能让**当前位就断掉**。反例：`nums1 = [5,1], nums2 = [4,3]`，逐位取 min 得 `[4,1]`（断，长 1）；而取 `[4,3]`（两位都取 B）非递减，长 2。同理「合并成 min/max 单数组再 DP」丢失了逐位配对信息，均不可行；正解必须**并列维护两个分支**。

## 5. 正确性证明

**引理 1（前驱唯一性）**：在任何合法构造 `nums3` 中，以 $i$ 结尾、长度 $\ge 2$ 的非递减子数组，其倒数第二个元素必位于下标 $i-1$，且取值 $\in \{a_{i-1}, b_{i-1}\}$。

**证明**：子数组是连续区间，以 $i$ 结尾长度 $\ge 2$ 的区间为 $[j, i]$ 且 $j \le i-1$；若 $j < i-1$，区间内下标 $i-1$ 两侧均为区间元素，倒数第二个元素按位置就是 $i-1$。又由构造规则，`nums3[i-1]` 只能取 $a_{i-1}$ 或 $b_{i-1}$。∎

**引理 2（转移方程）**：设 $L(i,0)$ 为**所有**合法构造中「以 $i$ 结尾且 `nums3[i]` $= a_i$」的非递减子数组长度的最大值（$L(i,1)$ 对称），则 $L(0,0) = L(0,1) = 1$，且对 $i \ge 1$：

$$
L(i,0) = 1 + \max\big(\mathbb{1}[a_i \ge a_{i-1}] \cdot L(i\!-\!1,0),\ \ \mathbb{1}[a_i \ge b_{i-1}] \cdot L(i\!-\!1,1)\big)
$$

**证明**：**（≥）** 取 $\max$ 中任一非零项，设为 $k \in \{0,1\}$ 且 $a_i \ge v_{i-1,k}$（$v_{i-1,0}=a_{i-1}$，$v_{i-1,1}=b_{i-1}$）。由 $L(i-1,k)$ 的定义，存在构造使某个长为 $L(i-1,k)$ 的非递减段以 $i-1$ 结尾且末尾为 $v_{i-1,k}$；该构造**对下标 $i$ 的选择不做约束**，令 `nums3[i]` $= a_i$，由 $a_i \ge v_{i-1,k}$ 知延长后的段仍非递减，长 $L(i-1,k)+1$，故 $L(i,0) \ge$ 该项 $+1$；对所有项取 max 得 ≥ 方向。**（≤）** 任取一个构造及其以 $i$ 结尾、末尾为 $a_i$、长 $\ell$ 的非递减段。若 $\ell = 1$，则 $\ell \le 1 + 0 \le$ 右侧。若 $\ell \ge 2$，由引理 1 该段倒数第二位在 $i-1$、取值 $v \in \{a_{i-1}, b_{i-1}\}$，且 $v \le a_i$（非递减），其前 $i$ 个元素构成以 $i-1$ 结尾、末尾为 $v$ 的合法段，长 $\ell - 1 \le L(i-1,k_v)$，且 $a_i \ge v$ 使对应指示项非零，故 $\ell \le 1 + L(i-1,k_v) \le$ 右侧。∎

**定理**：算法返回值等于所有构造方案下 `nums3` 最长非递减子数组长度的最大值。

**证明**：对 $i$ 归纳可证 $dp[i][0] = L(i,0)$、$dp[i][1] = L(i,1)$：$i=0$ 为初值；$i \ge 1$ 时滚动变量按引理 2 的方程计算，归纳假设保证 $dp0/dp1$ 即 $L(i-1,\cdot)$。另一方面，任何构造的最长非递减子数组以某个 $i$ 结尾且末尾取值 $\in \{a_i, b_i\}$，故其长 $\le \max_k L(i,k) \le \max_{j,k} L(j,k)$；反之 $\max_{j,k} L(j,k)$ 由某构造实现。算法返回 $ans = \max_{i,k} dp[i][k] = \max_{i,k} L(i,k)$，恰为所求。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。每个位置做 4 次比较、2 次加法与常数次 `max`，一遍扫完；$n = 10^5$ 毫无压力。
- **空间复杂度**：$O(1)$。仅 $dp0/dp1/ans$ 三个滚动变量（「连续段 DP 只依赖相邻前驱」天然支持滚动）；若需还原构造方案保留整表与决策记录则为 $O(n)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maxNonDecreasingLength(vector<int>& nums1, vector<int>& nums2) {
        int n = nums1.size();
        int dp0 = 1, dp1 = 1;          // dp[i-1][0], dp[i-1][1]
        int ans = 1;
        for (int i = 1; i < n; i++) {
            int a = nums1[i], b = nums2[i];
            int pa = nums1[i - 1], pb = nums2[i - 1];
            int cur0 = 1, cur1 = 1;    // 先置 1：条件全不成立时本位单独成段
            if (a >= pa) cur0 = max(cur0, dp0 + 1);
            if (a >= pb) cur0 = max(cur0, dp1 + 1);
            if (b >= pa) cur1 = max(cur1, dp0 + 1);
            if (b >= pb) cur1 = max(cur1, dp1 + 1);
            dp0 = cur0;                // cur0/cur1 都算完才覆盖
            dp1 = cur1;
            ans = max(ans, max(dp0, dp1));
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maxNonDecreasingLength(self, nums1: List[int], nums2: List[int]) -> int:
        dp0 = dp1 = 1          # 以 i-1 结尾、末尾选 nums1 / nums2 的最长长度
        ans = 1
        for i in range(1, len(nums1)):
            a, b = nums1[i], nums2[i]
            pa, pb = nums1[i - 1], nums2[i - 1]
            cur0 = 1 + max((a >= pa) * dp0, (a >= pb) * dp1)
            cur1 = 1 + max((b >= pa) * dp0, (b >= pb) * dp1)
            dp0, dp1 = cur0, cur1
            ans = max(ans, dp0, dp1)
        return ans
```

> 💡 Python 版用 `(cond)` 布尔值参与算术（`True=1/False=0`）把「成立取 dp、不成立取 0」写成一行；元组赋值 `dp0, dp1 = cur0, cur1` 天然先算右侧再赋值，规避覆盖顺序坑。

## 8. 边界情况与易错点

1. **$n = 1$**：循环不进入，返回初值 1，天然正确，无需特判。
2. **非递减允许相等**：条件是 $\ge$ 不是 $>$，写成严格不等会把示例 1 的 `[2,2]` 判断为断开而错答 1。
3. **单状态陷阱**：丢掉「末尾选了哪行」的信息无法判断续接（见 §3.2 ⚠ 与 §3.4 的 $i=2$），两状态必须并列维护到最后一刻。
4. **滚动覆盖顺序**：$cur1$ 依赖旧 $dp0/dp1$，必须先算完两个 cur 再统一覆盖；C++ 里逐个赋值前先存 `cur0/cur1` 局部变量，或用 `tie/swap` 式成对更新。
5. **答案取全局 max**：最优段可在中间结束，返回 `dp[n-1]` 或只在循环外取一次都会漏解。
6. **贪心合并必错**：「逐位取 min/max」「合并成单数组再 DP」都有反例（见 §4 第 5 点），不要试图省掉第二个状态。
7. **溢出无忧**：值 $\le 10^9$、长度 $\le 10^5$，`int` 足够，无需 `long long`。

**延伸思考**：

1. **三数组 $k$ 选一**：把状态扩成 $k$ 个并列，转移 $k^2$ 条边，仍是 $O(n k^2)$ 一遍扫——「末尾候选只有 $k$ 种」的观察不变。
2. **改成最长非递减子序列（可断开）**：转移需枚举所有前驱，朴素 $O(n^2)$；可对「以各长度结尾的最小值集合」做平衡树/树状数组维护，做到 $O(n \log n)$，体会「连续」性质对复杂度的决定性影响。
3. **还原构造方案**：保留整张 dp 表并记录每个状态的转移前驱（选 A/B 及来源行），从全局最大值格回溯即可输出具体的 `nums3`——赛场上若题目追加「输出方案」，只需加一行决策记录。
