# LeetCode 达到末尾下标所需的最大跳跃次数 题解

## 1. 题目概述

- **标题 / 题号**：达到末尾下标所需的最大跳跃次数（#2770，medium）
- **链接**：https://leetcode.cn/problems/maximum-number-of-jumps-to-reach-the-last-index/
- **来源**：LeetCode 第 353 场周赛 Q2
- **难度**：中等
- **标签**：数组、动态规划

**题意**：给定长度为 $n$ 的数组 `nums` 与整数 `target`，初始位于下标 $0$。一步操作可以从下标 $i$ 跳到任意下标 $j$，要求 $i < j$ 且 $-target \le nums[j] - nums[i] \le target$（即值差不超过 `target`）。求到达下标 $n-1$ 的**最大跳跃次数**；无法到达返回 $-1$。

**约束**：

- $2 \le n \le 1000$ —— $O(n^2)$ 恰好够用，提示朴素 DP 是预期解法
- $-10^9 \le nums[i] \le 10^9$ —— 值差最大 $2 \times 10^9$，贴近 `int` 上界
- $0 \le target \le 2 \times 10^9$

## 2. 示例

**示例 1**

```text
输入：nums = [1,3,6,4,1,2], target = 2
输出：3
解释：跳跃序列 0 → 1 → 3 → 5（值 1→3→4→2），共 3 跳；
      下标 2 的值 6 与两侧值差均超 2，只能跳过。
```

**示例 2**

```text
输入：nums = [1,3,6,4,1,2], target = 3
输出：5
解释：带宽放宽到 3 后可逐格跳跃 0→1→2→3→4→5，共 5 跳（即 n−1，答案上界）。
```

**示例 3**

```text
输入：nums = [1,3,6,4,1,2], target = 0
输出：-1
解释：target = 0 要求相邻值相等，本例不存在从 0 到 5 的跳跃序列。
```

## 3. 解题思路

### 3.1 暴力思路

从下标 0 出发 DFS 枚举所有跳跃序列：每一步的目的地有 $O(n)$ 种选择，序列长度最坏 $O(n)$，方案数是指数级；$n = 1000$ 时必然超时。突破口在于把「跳跃」抽象成图上的边，寻找**最优子结构**。

### 3.2 核心观察：只能向右跳 ⇒ DAG，求「最大次数」即求最长路径

![跳跃关系构成 DAG，最大跳跃次数即最长路径](images/max_jumps_dag_concept.svg)

> 💡 **关键观察一**：跳跃必须严格向右（$i < j$），因此把下标看作点、可跳关系看作有向边，得到一张**有向无环图（DAG）**——不存在环，天然具有**无后效性**，按下标从小到大计算即拓扑序，DP 可行。

> 💡 **关键观察二**：题目求的是「**最大**跳跃次数」而非「最少步数」——这正是与 45. 跳跃游戏 II 相反的方向。最少步数对应 BFS 分层；而**最多步数对应 DAG 上的最长路径**，直接线性 DP，连 BFS 都不需要。

设 $dp[i]$ 为**从 0 到达下标 $i$ 的最大跳跃次数**，不可达记为 $-1$。一次转移到 $i$ 的跳跃必来自某个左侧的 $j$，于是：

$$
dp[i] \;=\; \max_{\substack{0 \le j < i \\ |nums[i] - nums[j]| \le target \\ dp[j] \ne -1}} \bigl(dp[j] + 1\bigr)
$$

若无满足条件的 $j$，则 $dp[i]$ 保持 $-1$（不可达）。答案是 $dp[n-1]$。

该结构与**最长递增子序列 LIS（#300）完全同构**：都是 $dp[i] = \max(dp[j]+1)$ 的"最长链"DP，只是转移条件从「值单调」换成了「值域带宽」。

### 3.3 算法流程

![O(n²) 双重循环线性 DP 流程](images/max_jumps_dp_flow.svg)

1. 初始化 $dp[0] = 0$（起点 0 跳到达），其余 $dp[i] = -1$；
2. 外层循环 $i$ 从 $1$ 到 $n-1$；
3. 内层循环 $j$ 从 $0$ 到 $i-1$：若 $dp[j] \ne -1$ 且 $|nums[i] - nums[j]| \le target$，则 $dp[i] = \max(dp[i],\ dp[j]+1)$；
4. 返回 $dp[n-1]$。

### 3.4 示例演算

![示例 1 的 dp 逐步演算](images/max_jumps_dp_walkthrough.svg)

以示例 1 `nums = [1,3,6,4,1,2], target = 2` 为例：

1. $dp[0] = 0$：起点；
2. $dp[1] = 1$：仅 $j=0$ 可跳（$|3-1|=2 \le 2$）；
3. $dp[2] = -1$：$j=0$ 差 5、$j=1$ 差 3，均超带宽，不可达；
4. $dp[3] = 2$：$j=1$ 可跳（$|4-3|=1$），$dp[1]+1=2$；注意 $j=2$ 虽满足 $|4-6|=2 \le 2$，但 $dp[2]=-1$ 须跳过；
5. $dp[4] = 2$：$j=0$（差 0）给 1，$j=1$（差 2）给 2，取最大 2；
6. $dp[5] = 3$：$j=3$（差 2）给 3，$j=4$（差 1）给 3，取 3。

最优路径 $0 \to 1 \to 3 \to 5$，答案 $dp[5] = 3$。

## 4. 算法细节

1. **状态设计**：$dp[i]$ = 从 0 到 $i$ 的最大跳跃次数；$dp[0] = 0$，其余初始化为 $-1$。
2. **$-1$ 的双重语义**：既是「不可达」标记，又被 `dp[j] != -1` 过滤——不可达的点**不能作为转移来源**。若不过滤，$dp[j]+1 = 0$ 会冒充「0 跳到达」参与取 max，把不可达误判成可达（本题最常见的 WA 点）。
3. **计算顺序**：$i$ 升序、$j < i$，保证转移来源先于目标算出；下标升序就是这张 DAG 的拓扑序，无需显式建图。
4. **判定条件**：$|nums[i] - nums[j]| \le target$ 等价于 $nums[j] \in [nums[i] - target,\ nums[i] + target]$，一次减法加绝对值即可，避免写两个不等式。
5. **为何不求最短路**：45. 跳跃游戏 II 求**最少**步数用 BFS/贪心；本题求**最多**步数，即 DAG 最长路径，直接 DP 取 max。方向想反会全场白给。
6. **为何不做 $O(n \log n)$ 优化**：LIS 能二分优化靠的是条件 $nums[j] < nums[i]$ 的**单调性**（可维护"各长度最小尾元素"）；本题条件是**值域带宽**，关于下标不单调，该贪心结构失效。$n \le 1000$ 时 $O(n^2) = 10^6$ 次判断毫无压力，朴素写法即正解。

## 5. 正确性证明

**引理 1（DAG 性质）**：把每个下标看作点、每条满足 $i < j$ 且 $|nums[j]-nums[i]| \le target$ 的关系 $i \to j$ 看作有向边，得到的有向图 $G$ 无环；且任何到达 $i\ (i \ge 1)$ 的非空路径，其最后一条边必形如 $j \to i$（$j < i$）。

**证明**：$G$ 中所有边均由小下标指向大下标。若存在环，取环中下标最大的点 $v$，它的出边指向下标更大的点，不可能回到环内，矛盾。故 $G$ 是 DAG。路径上下标沿边严格递增，最后一条进入 $i$ 的边只能来自某个 $j < i$。∎

**引理 2（最优子结构）**：设 $L(i)$ 为从 $0$ 到 $i$ 的最大跳跃次数（不可达记 $-\infty$），则 $L(0) = 0$，且对 $i \ge 1$：

$$
L(i) \;=\; \max_{\substack{0 \le j < i \\ |nums[i] - nums[j]| \le target}} \bigl(L(j) + 1\bigr)
$$

（右侧为空集时 $L(i) = -\infty$。）

**证明**：**（≥）** 对任意满足条件的 $j$：若 $L(j) = -\infty$ 则该侧贡献为 $-\infty$，不影响；否则取 $0$ 到 $j$ 的最长路径（长 $L(j)$），再追加边 $j \to i$，得到一条到达 $i$ 的合法路径，长 $L(j)+1$，故 $L(i) \ge L(j)+1$，对所有 $j$ 取 max 得 $L(i) \ge$ 右侧。**（≤）** 反之，任何到达 $i$ 的合法路径长度 $k \ge 1$，由引理 1 其最后一步为某个 $j \to i$，前缀是到达 $j$ 的路径，长 $k - 1 \le L(j)$，故 $k \le L(j) + 1 \le$ 右侧，再对路径取 sup 得 $L(i) \le$ 右侧。∎

**定理**：算法结束时，对一切 $i$：$dp[i] = L(i)$（若可达）或 $dp[i] = -1$（若 $L(i) = -\infty$）；特别地，返回值 $dp[n-1]$ 恰为所求最大跳跃次数（不可达时为 $-1$）。

**证明**：对 $i$ 归纳。$i = 0$ 时 $dp[0] = 0 = L(0)$。设结论对所有 $j < i$ 成立。转移中条件 $dp[j] \ne -1$ 恰好排除 $L(j) = -\infty$ 的不可达前驱（归纳假设下 $dp[j] = -1 \iff L(j) = -\infty$）；对其余 $j$ 有 $dp[j] = L(j)$，故 $dp[i]$ 的候选值恰为引理 2 右侧的候选值（不可达前驱贡献 $-\infty$ 被剔除）。若候选为空，$dp[i]$ 保持 $-1$，且 $L(i) = -\infty$（引理 2 右侧为空）；否则 $dp[i] = \max\{L(j)+1\} = L(i)$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n^2)$。外层 $i$、内层 $j$ 枚举全部 $(i, j)$ 对（$j < i$，共 $\binom{n}{2} \approx 5 \times 10^5$ 个），每对 $O(1)$ 完成带宽判定与转移；$n \le 1000$ 远在时限内。
- **空间复杂度**：$O(n)$。仅一个一维 $dp$ 数组，不显式建图。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maximumJumps(vector<int>& nums, int target) {
        int n = nums.size();
        vector<int> dp(n, -1);
        dp[0] = 0;
        for (int i = 1; i < n; i++) {
            for (int j = 0; j < i; j++) {
                if (dp[j] != -1 &&
                    abs((long long)nums[i] - nums[j]) <= target) {
                    dp[i] = max(dp[i], dp[j] + 1);
                }
            }
        }
        return dp[n - 1];
    }
};
```

### Python

```python
class Solution:
    def maximumJumps(self, nums: List[int], target: int) -> int:
        n = len(nums)
        dp = [-1] * n
        dp[0] = 0
        for i in range(1, n):
            for j in range(i):
                if dp[j] != -1 and abs(nums[i] - nums[j]) <= target:
                    dp[i] = max(dp[i], dp[j] + 1)
        return dp[-1]
```

## 8. 边界情况与易错点

1. **求「最大」不是「最小」**：别条件反射套跳跃游戏 II 的 BFS/贪心模板——那是求最少步数；本题求最多步数，DP 里存 max。
2. **忘记过滤 $dp[j] = -1$**：$-1 + 1 = 0$ 会把不可达点变成「0 跳可达」参与取 max，导致不可达被误判为可达、或污染出偏大/非 $-1$ 的错误答案。这是本题头号 WA 点。
3. **$n = 2$ 无需特判**：外层循环 $i = 1$、内层 $j = 0$，能跳返回 1，不能跳返回 $-1$，自然处理。
4. **溢出**：$|nums[i] - nums[j]|$ 最大 $2 \times 10^9$，恰好小于 `INT_MAX`（约 $2.147 \times 10^9$），`int` 勉强安全；但 C++ 中做 `int` 减法已贴着边界，防御性写法是先 `(long long)` 强转再取绝对值（Python 无此虑）。
5. **target = 0**：只有相邻值相等才能跳；若数组全相等，答案是 $n - 1$。
6. **答案上界自检**：每次跳跃下标至少前进 1，故答案 $\le n - 1$；输出超过 $n-1$ 必有 bug。

**延伸思考**：

1. **数据规模加大**：若 $n$ 达 $10^5$，可将转移改述为"对已处理的 $j$，在值域区间 $[nums[i]-target,\ nums[i]+target]$ 内取最大 $dp[j]$ 再加 1"——离散化 `nums` 后用权值线段树/树状数组维护区间最大值，整体 $O(n \log n)$。
2. **改成求最少跳跃次数**：仍是 DAG 上的路径问题，把转移的 $\max$ 换成 $\min$（仍 $O(n^2)$），或按 dp 值 BFS 分层。
