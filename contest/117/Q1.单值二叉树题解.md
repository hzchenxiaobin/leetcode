# LeetCode 单值二叉树 题解

## 1. 题目概述

- **标题 / 题号**：单值二叉树（#965，easy）
- **链接**：https://leetcode.cn/problems/univalued-binary-tree/
- **来源**：LeetCode 第 117 场周赛 Q1
- **难度**：简单
- **标签**：树、深度优先搜索、广度优先搜索、二叉树

**题意**：如果一棵二叉树的**每个节点都具有相同的值**，则称它是单值二叉树。给定根节点 `root`，判断它是否为单值二叉树。

**约束**：

- 节点数在 $[1, 100]$ 内
- 每个节点的值在 $[0, 99]$ 内

## 2. 示例

**示例 1**

```text
输入：root = [1,1,1,1,1,null,1]
输出：true
解释：        1
            /   \
           1     1
          / \   /
         1   1 1
      所有节点的值都是 1，是单值二叉树。
```

**示例 2**

```text
输入：root = [2,2,2,5,2]
输出：false
解释：        2
            /   \
           2     2
          / \
         5   2
      节点 5 的值为 5 ≠ 2，不是单值二叉树。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的做法：完整遍历一次树，把所有节点的值收进一个列表，再检查列表中的所有值是否相同。

- 时间 $O(n)$，已经是线性的；
- 空间 $O(n)$：额外存了一个长度 $n$ 的列表，其实完全没必要——只要拿一个"基准值"边遍历边比较即可，发现不同就能立即返回。

### 3.2 核心观察：与根节点比较

![单值 ⟺ 每个节点的值都等于根节点的值](images/wc117_q1_root_value.svg)

**观察**：若一棵树的定义是"所有节点值相同"，那么它们必然都等于**根节点的值** $v_0$。反之，若每个节点都等于 $v_0$，则所有节点值当然相同。于是

$$\text{单值二叉树} \iff \forall u \in T:\ val(u) = val(root).$$

所以只需在遍历过程中，把每个节点的值与 $v_0$ 比较：

- 全部相等 → `true`；
- 只要有一个不等 → 立即 `false`（可以提前剪枝，不必遍历完整棵树）。

![算法流程：携带根值递归/迭代检查](images/wc117_q1_flow.svg)

也可以用"与父节点比较"的写法（若每个节点都等于父节点，则由传递性全都相等），两种写法等价；直接与根值比较少传一个参数，更简洁。

### 3.3 算法流程

```text
1. v0 = root.val
2. dfs(node):
       若 node 为空:  return true
       若 node.val != v0:  return false        // 提前失败
       return dfs(node.left) and dfs(node.right)
3. return dfs(root)
```

### 3.4 示例演算

![示例 2 的检查过程：节点 5 处提前失败](images/wc117_q1_walkthrough.svg)

对示例 2 的 `root = [2,2,2,5,2]`，$v_0 = 2$：

| 访问顺序 | 节点值 | 与 $v_0 = 2$ 比较 | 结果 |
|----------|--------|-------------------|------|
| 根 | 2 | 相等 | 继续 |
| 左孩子 | 2 | 相等 | 继续 |
| 左左（值为 5） | 5 | **不等** | 立即返回 false |
| 其余节点 | — | — | 不再访问（已剪枝） |

示例 1 中的所有节点都是 1，递归全部返回 true，最终答案为 `true`。

## 4. 算法细节

1. **基准值取根节点的值**：只需读一次 `root.val`，之后每个节点与它比较；不要每次递归都重新读根（虽然也能过，但语义不清晰）。
2. **短路求值**：`dfs(left) and dfs(right)` 在 C++ 中用 `&&`，Python 中用 `and`，左子树失败时右子树不再访问。
3. **空节点返回 true**：空树（`null` 孩子）不贡献任何"值"，天然满足条件。
4. **迭代写法**：用栈做 DFS，弹出节点时比较，任何一个不等就返回 false；空间 $O(h)$。
5. **不要排序或去重**：用 `set` 收集值再判断大小为 1 也能得到答案，但多做了一次集合插入，且丢失了"提前失败"的机会。
6. **值域小不是重点**：虽然 $val \in [0,99]$，但本题不需要桶计数——只需要判断"是否只有一个不同值"。
7. **递归深度**：节点数 $\le 100$，即使退化成链深度也只有 100，不必担心爆栈。

## 5. 正确性证明

**引理 1（判据等价）**：设 $v_0 = val(root)$。树 $T$ 是单值二叉树，当且仅当对 $T$ 中每个节点 $u$ 都有 $val(u) = v_0$。

**证明**：

- **必要性**：若 $T$ 单值，则所有节点的值都相同，而根是其中一个节点，故所有节点都等于 $v_0$。
- **充分性**：若每个节点都等于 $v_0$，则任意两个节点的值都等于 $v_0$，故全部相同，$T$ 单值。∎

**引理 2（递归过程正确）**：`dfs(node)` 返回 `true` 当且仅当以 `node` 为根的子树中所有节点的值都等于 $v_0$。

**证明**：对子树高度归纳。

- 空子树：没有节点，条件空真，返回 `true` 正确。
- 非空：若 `node.val != v0`，直接返回 `false`，而该子树确实不满足条件；否则需左、右子树都满足，由归纳假设两次递归的返回值分别正确，`and` 的结果即"整棵子树满足"。∎

**定理**：算法返回 `true` 当且仅当 `root` 是单值二叉树。

**证明**：由引理 2，`dfs(root)` 为 `true` ⟺ 整棵树所有节点值都等于 $v_0$；由引理 1，这等价于 $T$ 是单值二叉树。∎

## 6. 复杂度分析

- **时间**：$O(n)$，每个节点访问一次；失败时提前返回，实际访问的更少。
- **空间**：$O(h)$，$h$ 为树高（递归栈深度），最坏 $O(n)$（退化成链），最好 $O(\log n)$（平衡时）。

## 7. 参考代码

### C++

```cpp
using namespace std;

class Solution {
public:
    bool isUnivalTree(TreeNode* root) {
        if (!root) return true;
        return dfs(root, root->val);
    }

private:
    bool dfs(TreeNode* node, int v0) {
        if (!node) return true;               // 空节点不贡献值
        if (node->val != v0) return false;    // 提前失败
        return dfs(node->left, v0) && dfs(node->right, v0);
    }
};
```

### Python

```python
class Solution:
    def isUnivalTree(self, root: "TreeNode") -> bool:
        if root is None:
            return True
        v0 = root.val

        def dfs(node) -> bool:
            if node is None:
                return True                     # 空节点不贡献值
            if node.val != v0:
                return False                    # 提前失败
            return dfs(node.left) and dfs(node.right)

        return dfs(root)
```

## 8. 边界情况与易错点

1. **只有一个节点**：`[7]` 一定单值，返回 `true`。
2. **只有某一个叶子不同**：如示例 2 的节点 5，递归必须下探到叶子才能发现，不能只看根和它的直接孩子。
3. **空树**：题面保证节点数 $\ge 1$；若允许空树，按定义应返回 `true`，代码中的 `if (!root) return true;` 已兜底。
4. **只比较父子会漏**：单看"每个节点都等于父节点"逻辑上也等价（传递性），但若只比较了部分父子对（例如只比较左孩子）就会漏判，必须覆盖所有边。
5. **基准值不要用 0 作为哨兵**：节点值可以是 0，用"0 表示未初始化"的写法会误判。
6. **短路写法**：`&&`/`and` 的短路特性是提前失败的关键，写成 `dfs(left) & dfs(right)`（位与）会失去短路，虽不影响正确性但会多遍历。
7. **递归与迭代都可**：$n \le 100$ 时递归安全；若上限放大到 $10^5$ 的链状树，应改用显式栈迭代。
8. **不要用中序遍历"检查有序"**：单值并不要求 BST，中序遍历有序是更强的条件，会误判。
