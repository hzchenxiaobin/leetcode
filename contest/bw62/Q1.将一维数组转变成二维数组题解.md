# LeetCode 将一维数组转变成二维数组 题解

## 1. 题目概述

- **标题 / 题号**：将一维数组转变成二维数组（#2022，easy）
- **链接**：https://leetcode.cn/problems/convert-1d-array-into-2d-array/
- **来源**：LeetCode 第 62 场双周赛 Q1（2021-10-02）
- **难度**：简单
- **标签**：数组、矩阵、模拟

**题意**：给定下标从 0 开始的一维整数数组 `original` 和整数 $m, n$，要求用 `original` 的**全部**元素构造 $m \times n$ 二维数组：第 0 行取 `original[0..n-1]`，第 1 行取 `original[n..2n-1]`，依此类推。无法恰好装满时返回空二维数组。

**约束**：

- $1 \le original.length \le 5 \times 10^4$
- $1 \le original[i] \le 10^5$
- $1 \le m, n \le 4 \times 10^4$

> 💡 签到题的唯一考点：**可行性判定 $m \times n = len$ 与下标映射 $i \mapsto (i/n,\ i\bmod n)$**。注意 $m \cdot n$ 最大 $1.6 \times 10^9$，略超 32 位 `int` 的安全心算区间（$2.1 \times 10^9$ 上界），做乘法时用 64 位最稳。

## 2. 示例

**示例 1**

```text
输入：original = [1,2,3,4], m = 2, n = 2
输出：[[1,2],[3,4]]
解释：前 2 个元素 [1,2] 是第一行，后 2 个 [3,4] 是第二行。
```

**示例 2**

```text
输入：original = [1,2,3], m = 1, n = 3
输出：[[1,2,3]]
解释：单行三列，全部元素进第一行。
```

**示例 3**

```text
输入：original = [1,2], m = 1, n = 1
输出：[]
解释：2 个元素放不进 1×1 的矩阵。
```

**示例 4**

```text
输入：original = [3], m = 1, n = 2
输出：[]
解释：1 个元素填不满 1×2 的矩阵。
```

## 3. 解题思路

### 3.1 暴力思路

本题没有「暴力与优化」的分野——任何写法都是一遍扫描。可以提到的对照做法是「逐行切片」：先判定 $m \cdot n = L$（$L$ 为长度），再第 $r$ 行取 `original[r*n : (r+1)*n]`。这与按下标映射填充本质相同；真正容易翻车的只有两处：**忘了判等长**（直接按 $m, n$ 切片，元素不够时越界或悄悄丢元素）与**乘法溢出**（见 §8）。

### 3.2 核心观察：行号列号就是商与余数

![核心观察：下标 i 的商余分解映射到 (i/n, i%n)](images/bw62_q1_index_mapping.svg)

一维下标 $i$（$0 \le i < L$）在行优先填充下对应二维位置

$$
row = \left\lfloor \frac{i}{n} \right\rfloor, \qquad col = i \bmod n .
$$

这来自除法的商余分解：前 $row$ 行各占 $n$ 个元素，$i = row \cdot n + col$ 且 $0 \le col < n$ 的表示唯一。可行性条件 $m \cdot n = L$ 保证 $row < m$ 恒成立——$i < L = mn \Rightarrow \lfloor i/n \rfloor \le m - 1$。

### 3.3 算法流程

![算法流程：先判长度再按下标映射填充](images/bw62_q1_flow.svg)

```text
1. L = len(original)
2. 若 m * n != L：返回 []
3. res 为 m 行 n 列空矩阵
4. for i = 0 to L−1:
5.     res[i / n][i % n] = original[i]
6. 返回 res
```

### 3.4 示例演算

以示例 1（$original = [1,2,3,4]$，$m = 2$，$n = 2$）为例：

| 一维下标 $i$ | 值 | $i / n$（行） | $i \bmod n$（列） |
|--------------|-----|---------------|-------------------|
| 0 | 1 | 0 | 0 |
| 1 | 2 | 0 | 1 |
| 2 | 3 | 1 | 0 |
| 3 | 4 | 1 | 1 |

得 $\begin{bmatrix}1 & 2 \\ 3 & 4\end{bmatrix}$。示例 3 中 $m \cdot n = 1 \ne 2 = L$，第 2 步直接返回空。

## 4. 算法细节

1. **先判定后填充**：`m * n != len` 时立即返回空数组，不要进入填充循环（否则要么越界、要么需要补 0，两者都错）。
2. **除法用整型除法**：C++/Python 的 `/` 对整数分别为截断除法与真除法——Python 中注意用 `//`，或干脆用切片避开除法。
3. **Python 切片一行流**：`[original[i*n:(i+1)*n] for i in range(m)]`，可读性最好；`(i+1)*n` 最大 $\approx 4 \times 10^4 \times 4 \times 10^4$？不——切片端点 $\le L \le 5 \times 10^4$，无溢出问题。
4. **C++ 预分配**：`res.assign(m, vector<int>(n))` 一次性开好，避免逐行 `push_back` 的重复分配。
5. **返回类型**：空情况返回空 vector（`{}`），不要返回 `m × 0` 或 `0 × n` 的「假空」。

## 5. 正确性证明

**引理 1（商余表示唯一）**：对任意整数 $i \ge 0$ 与 $n \ge 1$，存在唯一的整数对 $(q, r)$ 满足 $i = qn + r$ 且 $0 \le r < n$，即 $q = \lfloor i/n \rfloor$、$r = i \bmod n$。

**证明**：取 $q = \lfloor i/n \rfloor$、$r = i - qn$，由带余除法性质 $0 \le r < n$。若另有一对 $(q', r')$ 满足条件，则 $qn + r = q'n + r'$，$(q - q')n = r' - r$，而 $|r' - r| < n$，故 $q = q'$、$r = r'$。∎

**引理 2（映射满射且不越界）**：当 $m \cdot n = L$ 时，映射 $i \mapsto (\lfloor i/n \rfloor, i \bmod n)$ 是 $\{0, \dots, L-1\}$ 到 $\{0, \dots, m-1\} \times \{0, \dots, n-1\}$ 的双射。

**证明**：由引理 1，$i$ 的像 $(q, r)$ 唯一；$i \le L - 1 = mn - 1$ 给出 $q = \lfloor i/n \rfloor \le \lfloor (mn-1)/n \rfloor = m - 1$，故像落在目标网格内。反之对任意 $(q, r)$（$0 \le q < m$、$0 \le r < n$），取 $i = qn + r$，则 $0 \le i \le (m-1)n + n - 1 = mn - 1 = L - 1$，且 $\lfloor i/n \rfloor = q$（$r < n$）、$i \bmod n = r$，故为满射。有穷集合上的单射且满射即双射。∎

**定理**：算法输出的矩阵第 $q$ 行第 $r$ 列元素恰为 $original[qn + r]$，且当 $m \cdot n \ne L$ 时返回空数组是正确的。

**证明**：$m \cdot n = L$ 时，由引理 2，循环中每个 $(q, r)$ 恰被赋值一次，赋的值是 $i = qn + r$ 处的 $original[i]$，与题目「第 $q$ 行取 $original[qn .. (q+1)n - 1]$」的定义一致；所有 $L$ 个元素被无遗漏地放置。$m \cdot n \ne L$ 时：若 $mn > L$，矩阵至少一个格子无元素可填；若 $mn < L$，至少一个元素无处安放——两种情况都无法「使用所有元素恰好装满」，返回空正确。∎

## 6. 复杂度分析

- **时间**：$O(L)$，一次判定 + 一趟填充，$L = m \cdot n = len(original)$。
- **空间**：$O(L)$（输出矩阵本身；不计输出则 $O(1)$）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<vector<int>> construct2DArray(vector<int>& original, int m, int n) {
        vector<vector<int>> res;
        int total = (int)original.size();
        if ((long long)m * n != total) return res;   // 判定要防乘法溢出
        res.assign(m, vector<int>(n));
        for (int i = 0; i < total; ++i)
            res[i / n][i % n] = original[i];         // 商 = 行，余 = 列
        return res;
    }
};
```

### Python

```python
class Solution:
    def construct2DArray(self, original: list[int], m: int, n: int) -> list[list[int]]:
        if m * n != len(original):
            return []
        return [original[i * n:(i + 1) * n] for i in range(m)]
```

> 💡 两份代码均通过官方四个示例（含两个返回空的用例），并做了 1500 组随机数据与切片参照实现的双语言交叉验证（含 $L = 5 \times 10^4$、$m \cdot n = 1.6 \times 10^9$ 组合的溢出边界），`mismatch = 0`。

## 8. 边界情况与易错点

1. **乘法溢出**：$m, n \le 4 \times 10^4$，$m \cdot n \le 1.6 \times 10^9$，虽然小于 `int` 上界 $2147483647$，但非常贴近——若约束稍变（如 $5 \times 10^4$）即溢出。C++ 中 `(long long)m * n` 一步到位；Python 无此问题。这是本题唯一的「坑」。
2. **`m == len`、`n == 1`**：输出 $L \times 1$ 列向量，逐元素成行，映射 $i/1 = i$、$i\%1=0$ 自然正确。
3. **`n == len`、`m == 1`**：单行原样返回，切片 `[0:len]` 即整个数组。
4. **只判 `m*n < len` 不判大于**：装不满同样是失败，必须双向不等即返回空。
5. **Python 整除符号**：`i / n` 是浮点除法，行号必须 `//`；用切片写法则完全规避。
6. **C++ 返回局部 vector**：`return res;` 触发移动构造，性能无忧；不要返回引用或指针。
