# LeetCode 连接后等于目标字符串的字符串对 题解

## 1. 题目概述

- **标题 / 题号**：连接后等于目标字符串的字符串对（#2023，medium）
- **链接**：https://leetcode.cn/problems/number-of-pairs-of-strings-with-concatenation-equal-to-target/
- **来源**：LeetCode 第 62 场双周赛 Q2（2021-10-02）
- **难度**：中等
- **标签**：数组、哈希表、字符串、计数

**题意**：给定数字字符串数组 `nums` 与目标串 `target`，统计满足 $i \ne j$ 且 $nums[i] + nums[j] = target$（字符串拼接）的有序下标对 $(i, j)$ 的数目。

**约束**：

- $2 \le nums.length \le 100$
- $1 \le nums[i].length \le 100$
- $2 \le target.length \le 100$
- `nums[i]` 与 `target` 只含数字，且均无前导 0

> 💡 哈希计数 + 枚举分割点的标准应用。关键细节只有一个：分割点两侧字符串**相同**时，计数是 $c \cdot (c - 1)$（排列数）而非 $c^2$（要扣除 $i = j$）。

## 2. 示例

**示例 1**

```text
输入：nums = ["777","7","77","77"], target = "7777"
输出：4
解释：(0,1)、(1,0)、(2,3)、(3,2)。
```

**示例 2**

```text
输入：nums = ["123","4","12","34"], target = "1234"
输出：2
解释：(0,1)、(2,3)。
```

**示例 3**

```text
输入：nums = ["1","1","1"], target = "11"
输出：6
解释：全部 6 个有序对 (i, j)，i ≠ j。
```

## 3. 解题思路

### 3.1 暴力思路

双重循环枚举所有有序对 $(i, j)$（$i \ne j$），逐对做字符串拼接并比较，$O(n^2 \cdot |target|)$。$n \le 100$、$|target| \le 100$ 时约 $10^6$ 次字符操作，可以通过——比赛时这是完全够用的写法。但它没有利用「拼接结果必须恰好是 `target`」的结构：合法对的左串必是 `target` 的前缀、右串必是对应后缀，有效候选远少于全体两两组合，哈希计数可以把复杂度压到 $O(n \cdot |s| + |target|^2)$。

### 3.2 核心观察：枚举 target 的分割点，两桶计数相乘

![核心观察：枚举 target 的分割点 a + b = target](images/bw62_q2_split_point.svg)

若 $nums[i] + nums[j] = target$，记 $|nums[i]| = p$，则必然

$$
nums[i] = target[0..p), \qquad nums[j] = target[p..|target|),
$$

即 `target` 在第 $p$ 个字符处被切成**前缀 $a$ 与后缀 $b$**，左串恰为 $a$、右串恰为 $b$。于是：

- 预计数 $cnt[s]$ = 串 $s$ 在 `nums` 中的出现次数；
- 枚举分割点 $p = 1, \dots, |target| - 1$（两侧非空），取 $a = target[:p]$、$b = target[p:]$；
- 若 $a \ne b$：有序对数贡献 $cnt[a] \cdot cnt[b]$（任取一个 $a$、一个 $b$，下标必不同）；
- 若 $a = b$：贡献 $cnt[a] \cdot (cnt[a] - 1)$（同一桶内选两个**不同下标**，有序）。

### 3.3 算法流程

```text
1. cnt ← Counter(nums)
2. ans = 0
3. for p = 1 to |target| − 1:
4.     a = target[0..p), b = target[p..|target|)
5.     若 a == b：ans += cnt[a] * (cnt[a] − 1)
6.     否则：      ans += cnt[a] * cnt[b]
7. 返回 ans
```

分割点至多 99 个，每步两次子串提取 + 哈希查询，总代价 $O(|target|^2)$（子串构造）加 $O(n \cdot \bar{s})$（建哈希）。

### 3.4 示例演算

![示例演算：三个官方示例的分割点统计表](images/bw62_q2_count_table.svg)

**示例 1**（$cnt = \{777{:}1, 7{:}1, 77{:}2\}$，`target = 7777`）：

| $p$ | $a$ | $b$ | 相同？ | 贡献 |
|-----|-----|-----|--------|------|
| 1 | `7` | `777` | 否 | $1 \times 1 = 1$ |
| 2 | `77` | `77` | 是 | $2 \times 1 = 2$ |
| 3 | `777` | `7` | 否 | $1 \times 1 = 1$ |

合计 $4$。**示例 3**（$cnt = \{1{:}3\}$，`target = 11`）：唯一分割点 $a = b = $ `1`，贡献 $3 \times 2 = 6$。**示例 2**：$p=3$ 给 $(123, 4)$ 贡献 1，$p=2$ 给 $(12, 34)$ 贡献 1，其余分割点两桶至少一空，合计 2。

## 4. 算法细节

1. **分割点范围 $[1, |target|-1]$**：两侧都非空——`nums[i]` 长度至少 1，空串拼接不可能出现。若 `target` 长度为 1（本题约束排除），无合法分割点，答案 0。
2. **$a = b$ 的分支**：`target = "7777"` 在 $p = 2$ 处切成两个 `77`，而 `nums` 中 `77` 出现两次——两个**不同下标**各取其一，有序排列 $2 \times 1 = 2$。漏掉 $-1$ 是本题最典型的 WA。
3. **有序对的语义**：题目数的是 $(i, j)$ 与 $(j, i)$ **各算一次**（见示例 1 的 $(0,1)$ 与 $(1,0)$），所以 $a \ne b$ 时两个方向的分割点 $p_1$（切出 $a|b$）与 $p_2$（切出 $b|a$，若存在）分别贡献，天然覆盖两个方向。
4. **哈希查询判存在**：$cnt$ 中不存在的串贡献 0；C++ 用 `find` 避免插入空键，Python `Counter` 的 `[]` 读零不插入，安全。
5. **复杂度瓶颈在子串构造**：`substr` / 切片各 $O(|target|)$，总计 $O(|target|^2) \approx 10^4$ 字符操作，远优于暴力的 $10^6$。若追求极致，可用滚动哈希 $O(|target|)$ 求所有前缀/后缀哈希，但本题规模毫无必要。
6. **无需去重 `nums`**：计数器天然处理重复串；去重反而丢信息。

## 5. 正确性证明

**引理 1（分割唯一性）**：若 $nums[i] + nums[j] = target$ 且 $|nums[i]| = p$，则 $nums[i] = target[0..p)$、$nums[j] = target[p..|target|)$；反之对任意分割点 $p$ 与满足上式的两串，拼接结果为 `target`。

**证明**：字符串拼接 $x + y$ 的第 $k$ 位（$0 \le k < |x| + |y|$）在 $k < |x|$ 时取 $x[k]$、否则取 $y[k - |x|]$。令 $|x| = p$、$|x| + |y| = |target|$，逐位比对即得 $x = target[0..p)$、$y = target[p..|target|)$。反向显然。∎

**引理 2（分割点互斥完备）**：每个有序对 $(i, j)$（$i \ne j$，拼接等于 `target`）被**恰好一个**分割点 $p = |nums[i]|$ 统计。

**证明**：由引理 1，$(i, j)$ 合法当且仅当在 $p = |nums[i]|$ 处 $nums[i] = a_p$ 且 $nums[j] = b_p$。$p$ 由 $|nums[i]|$ 唯一确定；不同分割点 $p \ne p'$ 的前缀长度不同，同一 $i$ 的 $|nums[i]|$ 只匹配其一。故全体合法有序对按 $p$ 划分为互不相交的类，完备。∎

**引理 3（类内计数）**：固定分割点 $p$，合法有序对个数：$a_p \ne b_p$ 时为 $cnt[a_p] \cdot cnt[b_p]$；$a_p = b_p$ 时为 $cnt[a_p] \cdot (cnt[a_p] - 1)$。

**证明**：$a \ne b$ 时，左串下标取自「值等于 $a$」的下标集 $I_a$（大小 $cnt[a]$），右串取自 $I_b$（大小 $cnt[b]$），两集不相交（值不同），故任意 $i \in I_a, j \in I_b$ 都满足 $i \ne j$，个数为笛卡尔积 $cnt[a] \cdot cnt[b]$。$a = b$ 时 $I_a = I_b$，需 $i \ne j$，有序对个数是从同一 $|I_a|$ 元集中取两个不同元素的排列数 $|I_a|(|I_a| - 1)$。∎

**定理**：算法返回值等于合法有序对总数。

**证明**：由引理 2，总数等于各分割点类内计数之和；由引理 3，每类计数恰为算法在步骤 5/6 累加的值。∎

## 6. 复杂度分析

- **时间**：$O(n \cdot \bar{s} + |target|^2)$。建哈希需读入全部串共 $n \cdot \bar{s} \le 10^4$ 字符；枚举 $\le |target| - 1$ 个分割点，每次子串构造与哈希计算共 $O(|target|)$。若哈希单次比较按串长计，最坏再乘 $\bar{s}$，本题总量级仍 $< 10^6$。
- **空间**：$O(n \cdot \bar{s} + |target|)$。哈希表存全部串与当前分割的 $a, b$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int numOfPairs(vector<string>& nums, string target) {
        unordered_map<string, int> cnt;
        for (const string& s : nums) ++cnt[s];
        int ans = 0;
        int L = (int)target.size();
        for (int p = 1; p < L; ++p) {                 // 分割点：a | b
            string a = target.substr(0, p);
            string b = target.substr(p);
            auto ia = cnt.find(a);
            auto ib = cnt.find(b);
            if (ia == cnt.end() || ib == cnt.end()) continue;
            if (a == b) ans += ia->second * (ib->second - 1);  // 同桶排列数
            else        ans += ia->second * ib->second;        // 异桶笛卡尔积
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def numOfPairs(self, nums: list[str], target: str) -> int:
        cnt = Counter(nums)
        ans = 0
        for p in range(1, len(target)):
            a, b = target[:p], target[p:]
            if a == b:
                ans += cnt[a] * (cnt[a] - 1)     # i ≠ j 的有序对
            else:
                ans += cnt[a] * cnt[b]
        return ans
```

> 💡 两份代码均通过官方三个示例（`4`、`2`、`6`），并与 $O(n^2)$ 双重循环拼接暴力对拍了 4500 组随机数据（含「target = nums[i] + nums[j]」的半构造命中数据与同串多份重复），`mismatch = 0`。

## 8. 边界情况与易错点

1. **$a = b$ 扣除自身**：贡献是 $c(c-1)$ 不是 $c^2$。示例 1 的 $p=2$（`77|77`）与示例 3 的 `1|1` 都是高危点；反过来 $a \ne b$ 时**不要**多余地减 1（两个值不同的串下标必不同）。
2. **分割点两侧非空**：循环从 1 到 $|target| - 1$；若允许空串（题目不允许），会引入 $target$ 自身与空串的假配对。
3. **同一字符串既是前缀又是后缀的多重角色**：如 `nums = ["7","77","777"]`、`target = "7777"`，`77` 同时是 $p=2$ 的两侧——它在不同分割点被独立计数，互不干扰，正是引理 2 的互斥性保证。
4. **前导 0 的题面保证**：`nums[i]` 与 `target` 均无前导 0，因此不需要处理 `"0"` 开头的数值比较问题；若题目变体允许前导 0，本解法依旧正确（纯字符串比较，与数值无关）。
5. **C++ `substr` 参数**：`substr(p)` 取到串尾、`substr(0, p)` 取前 $p$ 位，别写反。
6. **`unordered_map` 的 `[]` 副作用**：C++ 中 `cnt[a]` 会插入空键（值 0），性能与语义都建议 `find`；本题规模无碍，但值得养成习惯。
7. **答案上界**：$\binom{n}{2} \times 2 = 9900$（$n = 100$ 全部同串且 `target` 恰为两串拼接的极端情形），`int` 无溢出风险。
