# LeetCode 求出所有子序列的能量和 题解

## 1. 题目概述

- **标题 / 题号**：求出所有子序列的能量和（#3082，hard）
- **链接**：https://leetcode.cn/problems/find-the-sum-of-the-power-of-all-subsequences/
- **来源**：LeetCode 第 126 场双周赛 Q4
- **难度**：困难
- **标签**：数组、动态规划、背包问题、0-1 背包

**题意**：定义整数数组的**能量**为「和恰好等于 $k$ 的子序列的数目」。给定长度为 $n$ 的正整数数组 `nums` 和正整数 `k`，求 `nums` 的**所有子序列的能量之和**（子序列指按下标递增取出的任意子集，含空序列），结果对 $10^9 + 7$ 取余。

**约束**：

- $1 \le n \le 100$
- $1 \le nums[i] \le 10^4$
- $1 \le k \le 100$

**关键前提**：题目在「子序列」之上又套了一层「子序列」，直接按定义枚举是双重指数。破局点是把「所有子序列的能量之和」改成**计数对**：数一数「(外层子序列, 内层子序列)」这样的配对有多少个——换一种数法，指数就变成了 $2^{n - j}$ 这样的闭式因子。

## 2. 示例

**示例 1**

```text
输入：nums = [1,2,3], k = 3
输出：6
解释：和为 3 的子序列有两类：{3}（贡献 2^2 = 4 次）与 {1,2}（贡献 2^1 = 2 次），合计 6。
      按定义枚举也能得到 2 + 1 + 1 + 1 + 1 = 6。
```

**示例 2**

```text
输入：nums = [2,3,3], k = 5
输出：4
解释：和为 5 的子集按下标有两个：{2, 第一个 3} 与 {2, 第二个 3}，各被 2^(3−2) = 2 个外层子序列包含，
      合计 2 + 2 = 4。注意两个 3 是不同下标的元素，不能按值去重。
```

**示例 3**

```text
输入：nums = [1,2,3], k = 7
输出：0
解释：总和才 6，不存在和为 7 的子序列，所有能量都为 0。
```

**示例 4（边界补充：重复元素）**

```text
输入：nums = [1,1], k = 1
输出：4
解释：和为 1 的子序列有两个（分别取第一个 1、第二个 1），各自被 2^(2−1) = 2 个外层子序列包含，
      合计 4。逐个枚举验证：外层取 []（能量 0）、[1a]（1）、[1b]（1）、[1a,1b]（2），和为 4。
```

## 3. 解题思路

### 3.1 暴力思路

按定义做：枚举 `nums` 的所有子序列（$2^n$ 个），对每个子序列再枚举它的子序列统计和为 $k$ 的个数（$2^{|T|}$ 个）。总复杂度 $O(3^n)$ 甚至 $O(4^n)$，$n = 100$ 时毫无希望。

退一步的「聪明暴力」是：枚举外层子序列 $T$，用一次 $O(|T| \cdot k)$ 的背包统计其和为 $k$ 的子序列数，总复杂度 $O(2^n \cdot nk)$，依然是指数级的。

暴力的浪费在于：**同一个「和为 $k$ 的子序列」会被大量外层子序列反复统计**。只要换个计数视角，就能把重复的部分一次性算清。

### 3.2 核心观察：交换求和顺序，答案 = 每个「和为 $k$ 的子序列」被包含的次数

![核心观察：交换求和顺序，把双重子序列变成「被包含次数」](images/bw126_q4_pair_counting.svg)

把答案写成计数对：

$$\text{answer} = \sum_{T \subseteq nums} \#\{S : S \text{ 是 } T \text{ 的子序列},\ \text{sum}(S) = k\} = \#\big\{(T, S) : S \subseteq T \subseteq nums,\ \text{sum}(S) = k\big\}.$$

交换求和顺序，改为枚举「内层」$S$：

$$\text{answer} = \sum_{S \subseteq nums,\ \text{sum}(S) = k} \#\{T : S \subseteq T \subseteq nums\}.$$

对固定的 $S$，$T$ 只需「包含 $S$ 的所有下标」、其余 $n - |S|$ 个元素**任选**，所以

$$\#\{T : S \subseteq T\} = 2^{\,n - |S|}.$$

于是问题化为一个干净的计数：**对所有和为 $k$ 的子集 $S$，累加 $2^{n-|S|}$**。

这一步把「三重结构」压成了「一层背包 + 一个权重」，是本题的核心。它同时解释了一个容易误判的现象：**没被选进 $S$ 的元素不是「没用」，而是贡献了一个因子 $2$**。

### 3.3 算法流程：带权重的 0-1 背包

![算法流程：dp 数组的两种转移（不选乘 2、选则累加）](images/bw126_q4_dp_transition.svg)

顺着 3.2 的式子设计 DP。处理到前缀前 $i$ 个元素时，定义

$$dp[s] = \sum_{\substack{S \subseteq \{0,\dots,i-1\} \\ \text{sum}(S) = s}} 2^{\,i - |S|}.$$

注意指数用的是**已处理元素个数** $i$ 而不是 $n$：这样可以边处理边结算因子 $2$，不必显式记录 $|S|$。加入第 $i+1$ 个元素 $x$ 时：

- **$x \notin S$**：子集不变，但已处理个数从 $i$ 变成 $i+1$，指数 $+1$，故该部分贡献**乘以 2**；
- **$x \in S$**：$S' = S \cup \{x\}$，和从 $s - x$ 变成 $s$，而指数 $i+1 - (|S|+1) = i - |S|$ **不变**，故直接累加 $dp[s-x]$。

于是转移为

$$dp'[s] = 2 \cdot dp[s] + dp[s - x] \quad(\text{当 } s \ge x),\qquad dp'[s] = 2 \cdot dp[s] \quad(\text{当 } s < x).$$

初值 $dp[0] = 1$（空集，权重 $2^{0} = 1$），其余为 $0$；按 $s$ **从大到小**更新（0-1 背包的经典写法，避免同一个 $x$ 被用两次）。处理完 $n$ 个元素后 $dp[k]$ 就是答案。

### 3.4 示例演算

![示例 1 的 DP 逐行更新](images/bw126_q4_example_walkthrough.svg)

`nums = [1,2,3]`，`k = 3`。初始 $dp = [1, 0, 0, 0]$（下标为和 $0 \sim 3$）。

| 处理 | $x$ | $dp[0]$ | $dp[1]$ | $dp[2]$ | $dp[3]$ | 说明 |
|------|-----|---------|---------|---------|---------|------|
| 初始 | — | 1 | 0 | 0 | 0 | 空集 |
| 第 1 个 | 1 | 2 | 1 | 0 | 0 | $dp_1 = 2\cdot 0 + dp_0 = 1$ |
| 第 2 个 | 2 | 4 | 2 | 2 | 1 | $dp_2 = 2\cdot 0 + dp_0 = 2$，$dp_3 = 2\cdot 0 + dp_1 = 1$ |
| 第 3 个 | 3 | 8 | 4 | 4 | **6** | $dp_3 = 2\cdot 1 + dp_0 = 2 + 4 = 6$ |

最终 $dp[3] = 6$，与示例输出一致。对照 3.2 的公式验证：和为 $3$ 的子集有 $\{3\}$（$|S| = 1$，权重 $2^{3-1} = 4$）与 $\{1,2\}$（$|S| = 2$，权重 $2^{3-2} = 2$），合计 $6$。

再看示例 2（`nums = [2,3,3]`，`k = 5`）：按 3.2 直接数——和为 $5$ 的子集是「$2$ 加上第一个 $3$」与「$2$ 加上第二个 $3$」，各自权重 $2^{3-2} = 2$，合计 $4$；注意子集是**按下标**区分的，两个 $3$ 视为不同元素，这与「子序列」的定义一致。

## 4. 算法细节

1. **转移必须逆序**：`for (s = k; s >= 0; --s)`，这样 `dp[s - x]` 读到的还是「未加入 $x$ 时」的旧值。正序更新会让同一个 $x$ 在同一轮里被用第二次，答案虚高。
2. **`s < x` 时只乘 2**：此时 $x$ 无法进入子集（放进去和就超过 $k$，而所有元素为正，之后不可能再降下来），只能让它「不被选中」，贡献因子 $2$。
3. **初值 $dp[0] = 1$**：代表空集，指数 $0$、权重 $2^0 = 1$。漏掉它整条链都会是 $0$。
4. **取模时机**：每一步都 `% MOD`，中间乘积用 `long long`。$dp[s] \le 10^9+6$，乘 2 后不超过 $2 \times 10^9$，仍在 `long long` 安全范围内（用 `int` 会溢出）。
5. **不需要显式记录 $|S|$**：这是「指数用已处理个数」这一设计带来的最大好处——省掉一维状态，空间从 $O(nk)$ 降到 $O(k)$，时间也从 $O(n^2 k)$ 降到 $O(nk)$。
6. **与「按长度计数」写法的关系**：另一种等价写法是令 $dp[i][j][\ell]$ = 前缀 $i$ 中和为 $j$、长度为 $\ell$ 的子序列个数，最后对每个 $\ell$ 把 $dp[n][k][\ell]$ 乘以 $2^{n-\ell}$ 求和。它多出「长度」一维（时间 $O(n^2k)$、空间 $O(nk)$），而本题把 $2$ 的幂**边算边乘**，直接省掉了这一维。注意 $2$ 的指数是「**长度**」而不是「下标」，两者混用是最常见的错误。
7. **元素大于 $k$**：$nums[i] \le 10^4$ 而 $k \le 100$，很多元素放不进任何合法子集，它们只贡献因子 $2$（对应「在外层子序列里可选可不选」），代码无需特判。
8. **空序列的语义**：$k \ge 1$ 且元素为正，空序列永远不算「和为 $k$」，所以 $dp[0]$ 的初值只是为了让转移起链，不会污染答案。

## 5. 正确性证明

设元素下标集为 $[n] = \{0, \dots, n-1\}$，把子序列等同于下标子集。

**引理 1（换序恒等式）**：$\displaystyle\sum_{T \subseteq [n]} \#\{S \subseteq T : \text{sum}(S) = k\} = \sum_{\substack{S \subseteq [n] \\ \text{sum}(S) = k}} 2^{\,n - |S|}$。

**证明**：左端是计数对集合 $\mathcal{P} = \{(T, S) : S \subseteq T \subseteq [n],\ \text{sum}(S) = k\}$ 的元素个数（对固定 $T$ 数 $S$）。按 $S$ 分组重数：对固定的合法 $S$，满足 $S \subseteq T \subseteq [n]$ 的 $T$ 由「$[n] \setminus S$ 中取哪些元素」唯一决定，共 $2^{n - |S|}$ 个。故左端 $= \sum_{S \text{ 合法}} 2^{n-|S|}$。∎

**引理 2（$dp$ 不变式）**：处理完前 $i$ 个元素后，对每个 $0 \le s \le k$，
$$dp[s] = \sum_{\substack{S \subseteq \{0,\dots,i-1\} \\ \text{sum}(S) = s}} 2^{\,i - |S|}.$$

**证明**：对 $i$ 归纳。$i = 0$ 时只有空集（和 $0$、$|S| = 0$），$dp[0] = 1 = 2^{0}$，其余为 $0$，成立。

设 $i$ 成立，考察第 $i$ 个元素 $x$（记 $S \subseteq \{0,\dots,i\}$）。按 $x \in S$ 与否分类：

- $x \notin S$：则 $S \subseteq \{0, \dots, i-1\}$，其贡献为 $2^{(i+1) - |S|} = 2 \cdot 2^{i - |S|}$，对所有这类 $S$ 求和得 $2 \cdot dp[s]$（用归纳假设）。
- $x \in S$：令 $S' = S \setminus \{x\}$，$S' \subseteq \{0,\dots,i-1\}$ 且和 $= s - x$，贡献 $2^{(i+1) - |S|} = 2^{i - |S'|}$，求和得 $dp[s - x]$。

两类相加即得转移公式；$s < x$ 时第二类为空，只剩下 $2 \cdot dp[s]$。故不变式对 $i+1$ 成立。∎

**引理 3（逆序更新实现正确转移）**：按 $s$ 从 $k$ 递减到 $0$ 就地更新 $dp$，得到的是「用旧值计算的新值」，与引理 2 的转移一致。

**证明**：更新 $dp[s]$ 时用到的 `dp[s - x]` 满足 $s - x < s$，由于 $s$ 递减遍历，下标更小的位置尚未被本轮更新，仍是旧值；而 `dp[s]` 自身在读取时也未被覆盖（先读出再写回）。故每个位置都恰是「旧值的新函数」，等价于用新数组计算。∎

**定理**：算法返回的 $dp[k]$ 等于 `nums` 所有子序列的能量之和（对 $10^9+7$ 取余）。

**证明**：由引理 2 取 $i = n$ 得 $dp[k] = \sum_{S \subseteq [n],\ \text{sum}(S) = k} 2^{n - |S|}$，正是引理 1 给出的答案。引理 3 保证代码的逆序就地更新确实实现了该转移，故返回值正确。又因全程取模，返回值等于真实值对 $10^9+7$ 的余数。∎

## 6. 复杂度分析

- **时间**：$O(nk)$。每个元素对 $s = 0 \sim k$ 做一次常数级转移，$n \le 100$、$k \le 100$ 时约 $10^4$ 次运算，实测不到 $1$ 毫秒。
- **空间**：$O(k)$。只需一个长度 $k+1$ 的 DP 数组；不记录长度维、不记录前缀维。若按官方提示写成 $dp[i][j]$ 则需要 $O(nk)$ 空间与 $O(n^2 k)$ 时间（还要再枚举长度），本解法在两方面都更优。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int sumOfPower(vector<int>& nums, int k) {
        const int MOD = 1e9 + 7;
        vector<long long> dp(k + 1, 0);
        dp[0] = 1;                                   // 空集，权重 2^0
        for (int x : nums) {
            for (int s = k; s >= 0; --s) {           // 逆序：0-1 背包，避免重复使用 x
                long long cur = dp[s] * 2 % MOD;     // x 不进入子集：指数 +1，权重 ×2
                if (s >= x) cur = (cur + dp[s - x]) % MOD;   // x 进入子集：指数不变
                dp[s] = cur;
            }
        }
        return (int)dp[k];
    }
};
```

### Python

```python
class Solution:
    def sumOfPower(self, nums: list[int], k: int) -> int:
        MOD = 10 ** 9 + 7
        dp = [0] * (k + 1)
        dp[0] = 1                                  # 空集，权重 2^0
        for x in nums:
            for s in range(k, x - 1, -1):          # 能和 x 一起构成和 s
                dp[s] = (dp[s] * 2 + dp[s - x]) % MOD
            for s in range(min(x - 1, k), -1, -1): # x 太大，只能不计入
                dp[s] = dp[s] * 2 % MOD
        return dp[k]
```

> 💡 两份代码通过官方示例（`6`、`4`、`0`）与 `[1,1], k = 1`（答案 `4`）、`[1,1,1], k = 3`、`[10^4, 10^4], k = 1`（答案 `0`）等边界，并与「枚举全部下标子集 $S$、对合法的求和 $2^{n-|S|}$」的暴力在 200 组随机数据（$n \le 11$，值域 $\le 8$，$k \le 12$）上对拍，`mismatch = 0`；此外还与「按定义枚举外层子序列、再枚举其子序列」的**双重枚举**（等价于 $O(3^n)$）在 120 组随机数据（$n \le 7$）上对拍，`mismatch = 0`，从而验证了换序公式本身；C++ 与 Python 在 $n = 100$、$k = 100$ 的极限数据上结果一致。

## 8. 边界情况与易错点

1. **正序更新会重复使用元素**：内层循环必须从 $k$ 递减。写成递增时，$x$ 会在同一轮里被反复塞进同一个子集，答案偏大且难以发现（小数据上甚至偶尔正确）。
2. **忘记乘 2**：`dp[s] * 2` 对应「未选中的元素贡献一个因子 2」。漏掉它就把「被包含次数」当成了 1，答案会只剩 $O(1)$ 量级。
3. **忘记 `dp[0] = 1`**：整条 DP 全为 0，答案恒为 0。
4. **对「长度」与「已处理个数」的混淆**：若模仿官方提示写 $dp[i][j]$ 再乘 $2^{n-j}$，必须保证 $j$ 是**子序列长度**而不是下标；两者混用会得到错误权重。本解法用「已处理个数」做指数，天然规避了这个问题。
5. **取模与溢出**：`dp[s] * 2` 最大约 $2 \times 10^9$，超过 `int` 上界，C++ 必须用 `long long` 暂存再取模。
6. **`s < x` 的分支**：$x$ 放不进任何和为 $s$ 的子集（元素全正，加了就超 $k$ 无法回头），此时只做乘 2。Python 版把它拆成两个循环只是写法差异，逻辑一致。
7. **两个相同的元素是不同下标**：示例 2 中两个 $3$ 各自形成不同子集，这正是「子序列」的定义（按下标区分），不要按值去重。
8. **`k` 大于总和**：DP 中 `dp[k]` 始终为 0，答案为 0（示例 3）；无需特判，也不能因为「没有解」而返回别的值。
