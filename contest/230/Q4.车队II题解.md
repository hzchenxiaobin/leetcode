# LeetCode 车队 II 题解

## 1. 题目概述

- **标题 / 题号**：车队 II（#1776，hard）
- **链接**：https://leetcode.cn/problems/car-fleet-ii/
- **来源**：LeetCode 第 230 场周赛 Q4
- **难度**：困难
- **标签**：栈、单调栈、数组、数学、堆（优先队列）

**题意**：一条**单车道**上有 $n$ 辆车同向行驶，给定 $\textit{cars}[i] = [\textit{position}_i, \textit{speed}_i]$，位置**严格递增**（左边车的 $\textit{position}$ 更小）。当一辆车追上前方车辆/车队时，二者**合并成一个车队**，此后以其中**最慢**一辆车（即最前方领队）的速度前进。返回 $\textit{answer}[i]$：第 $i$ 辆车与它**前方相邻的下一辆车**相遇的秒数——若那辆车先并入了别的车队，则以它与该车队的相遇为准；永不相遇则记 $-1$。误差需在 $10^{-5}$ 以内。

**约束**：

- $1 \le \textit{cars.length} \le 10^5$
- $1 \le \textit{position}_i, \textit{speed}_i \le 10^6$
- $\textit{position}_i < \textit{position}_{i+1}$

> 💡 本题在本仓库另有[每日题解 1776](../../solution/1701-1800/1776_车队II.md)：以「两条弹栈规则的物理含义 + 面试问答」为主线。本篇按**周赛复盘视角**展开：先把题意重构成「轨迹线求交」的几何模型（时空图），再用引理—定理结构把「弹栈安全 + 停栈正确」补严（含一条容易被略过的**不可穿越引理**），并附暴力对照、堆模拟替代路线与边界清单，两篇互为印证。

## 3. 解题思路

### 3.1 暴力思路：向右逐辆扫描，$O(n^2)$

时间连续、相遇时刻是实数，「逐时刻离散模拟」不可行；可行的朴素做法是**逐车向右扫**：对每辆车 $i$，从 $j = i+1$ 开始向右检查——

- 若 $s_i > s_j$ 且（$\textit{res}[j] = -1$ 或 $\tau(i,j) \le \textit{res}[j]$），其中 $\tau(i,j) = \dfrac{p_j - p_i}{s_i - s_j}$：$j$ 是 $i$ 的有效目标，$\textit{res}[i] = \tau(i,j)$，停止；
- 否则（追不上 $j$，或 $j$ 会在 $i$ 到来前并入前方车队）：$j$ 不再是有效目标，$j$ 右移继续。

这个做法**正确但太慢**：位置、速度都严格递增时，每辆车都要扫到最右端，总比较次数 $\Theta(n^2)$；$n = 10^5$ 时约 $10^{10}$ 次，必然超时。

> ⚠️ **症结在「链式合并」**：$i$ 追上 $j$ 前，$j$ 可能先并入更慢的领队 $w$ 而减速，$i$ 的目标随之变成 $w$；$w$ 又可能被更前方吸收……朴素做法每辆车都从头重扫这条「领队链」，而**右侧车已经扫过的结论其实可以复用**。

### 3.2 核心观察：追上车队 = 追上领队的匀速线

![核心观察：时空图——车队位置恒等于领队的匀速线，追车队就是与领队线求交](images/wc230_q4_fleet_line_concept.svg)

**观察一（轨迹线视角）**：车队无论合并多少次，其位置恒等于**领队**从 $t=0$ 出发的匀速直线 $\ell_L:\ p_L + s_L t$（§5 引理 1）。合并只是让后车「贴上」这条线，**不改变线本身**。因此 $x$ 追上「由 $L$ 领队、且 $L$ 尚未被更前方吸收」的车队，当且仅当 $x$ 的轨迹与 $\ell_L$ 相交于 $L$ 的在位期间，交点时刻 $\tau(x, L) = (p_L - p_x)/(s_x - s_L)$ **只用 $L$ 的初始数据**，与中间发生过几次合并、何时合并完全无关。

用图中三辆车 $X(0,3)$、$Y(24,2)$、$Z(44,1)$ 验证：$Y$ 在 $t=20$ 追上 $Z$ 并入车队；$X$ 若照搬「追 $Y$ 的原线」会得到 $\tau(X,Y)=24$，但 $Y$ 早已不在原线上——$X$ 真正的相遇是与车队线 $44 + t$ 求交：$3t = 44 + t \Rightarrow t = 22 = \tau(X, Z)$。**中间车 $Y$ 的合并过程完全不需要模拟**。

**观察二（右侧先定 + 候选淘汰）**：$i$ 的答案只依赖它右侧车的「领队链」，从右向左处理时右侧信息已全部确定。把「还可能被后方追上的车」（候选领队）存进栈，栈顶就是距 $i$ 最近的候选 $j$：

- $j$ 对 $i$ 无效（两条判据见 §3.3）⟹ **弹掉后永不再看**——它对更左的所有车同样无效；
- $j$ 有效 ⟹ $\textit{res}[i] = \tau(i, j)$，停栈。

「弹掉的候选永不再看」正是从 $O(n^2)$ 降到 $O(n)$ 均摊的全部来源。

### 3.3 算法流程：从右向左单调栈

![算法流程：从右向左单调栈，两条弹栈规则加停栈赋值，均摊 O(n)](images/wc230_q4_monotonic_stack_flow.svg)

从 $i = n-1$ 到 $0$ 逆序遍历，对每辆车执行「找有效目标」的循环，栈顶 $j$ 的三种判定：

| 栈顶 $j$ 的状态 | 判定 | 动作 | 物理含义 |
|---|---|---|---|
| $s_i \le s_j$ | **规则①** | 弹 $j$ | $i$ 追不上 $j$ 的原速形态；$j$ 要么并入前方慢车队（$i$ 改追其领队，即栈的下一层），要么永不吸收任何人（由引理 2 它必是栈底，弹后栈空） |
| $\textit{res}[j] \ne -1$ 且 $\tau(i,j) > \textit{res}[j]$ | **规则②** | 弹 $j$ | $i$ 到达前 $j$ 已被吸收，$i$ 改追吸收它的车队（领队恰为栈的下一层） |
| 其余：$s_i > s_j$ 且 $\tau(i,j) \le \textit{res}[j]$（或 $\textit{res}[j] = -1$） | **停栈** | $\textit{res}[i] = \tau(i,j)$ | $i$ 恰在 $j$ 仍领队期间追上 $j$（本人或其车队） |

每辆车无论弹了多少层，最后**无条件入栈**（弹空后 $i$ 自己成为新栈底候选）。两个易被问到的细节：

- 停栈条件用**严格大于**判弹：$\tau = \textit{res}[j]$ 时 $i$ 恰在 $j$ 并入的瞬间与其同位置，按「占据同一位置即相遇」计入 $\textit{res}[i] = \tau$；
- $\textit{res}[j] = -1$ 是**哨兵**：$j$ 永不被吸收，即它就是某个车队的最终领队——判据 $\textit{res}[j] \ne -1 \wedge t > \textit{res}[j]$ 天然放行。

### 3.4 示例演算

![示例 2 演算：从右向左四步，栈中为候选领队](images/wc230_q4_example_walkthrough.svg)

以**示例 2** $\textit{cars} = [[3,4],[5,4],[6,3],[9,1]]$ 走查（栈按底→顶书写）：

| 步 | $i$ | $(p, s)$ | 栈（处理前） | 判定与动作 | res 变化 |
|---|---|---|---|---|---|
| ① | 3 | $(9, 1)$ | 空 | 栈空 → 保持哨兵；push 3 | $[-,-,-,-1]$ |
| ② | 2 | $(6, 3)$ | $[3]$ | $t=\frac{9-6}{3-1}=1.5$，$\textit{res}[3]=-1$ 哨兵放行 → 停栈；push 2 | $[-,-,1.5,-1]$ |
| ③ | 1 | $(5, 4)$ | $[3, 2]$ | $t=\frac{6-5}{4-3}=1 \le \textit{res}[2]=1.5$（2 未被吸收）→ 停栈；push 1 | $[-,1,1.5,-1]$ |
| ④ | 0 | $(3, 4)$ | $[3, 2, 1]$ | 规则① 弹 1（$4 \le 4$）；规则② 弹 2（$t=3 > 1.5$）；停栈于 3：$t=\frac{9-3}{4-1}=2$；push 0 | $[2,1,1.5,-1]$ |

**第④步是全场关键**——car0 连续弹掉两个栈顶：

- **弹 1**：car0 与 car1 同速，永远追不上「原速的 car1」；但 car1 稍后会并入慢车队而减速，所以它不是有效障碍；
- **弹 2**：car0 追 car2 的**原线**要 $t = \frac{6-3}{4-3} = 3$，但 car2 在 $t=1.5$ 已并入领队 car3，$t=3$ 时 car2 早已不在原线上；
- **追 3**：car0 与领队 car3 的匀速线求交，$t = \frac{9-3}{4-1} = 2$，$\textit{res}[3] = -1$ 放行。

> 💡 **物理时间线核对**：$t=1$ car1 追上 car2（车队速 3）→ $t=1.5$ 车队追上 car3（车队速 1）→ $t=2$ car0 追上车队 $\{1,2,3\}$。car0 的答案 $2$ 既不是「追不上 car1」的 $-1$，也不是「追 car2 原线」的 $3$——两条弹栈规则各挡掉一种错误答案。

## 4. 算法细节

1. **栈存下标，不存值**：判定 $j$ 需要三样信息——$\textit{cars}[j]$ 的 $p_j, s_j$（算 $\tau$）与 $\textit{res}[j]$（判是否先被吸收）。存下标一次索引全部。
2. **两条弹栈规则各挡一种错误**（见 §3.3 表）：规则① 挡「永远追不上原速形态」，规则② 挡「能追上但对方已消失」。少了任何一条都会 WA：只用② 会在「同速但前方更慢」时漏解（car0 对 car1），只用① 会在「能追上但目标先被吸收」时算出幻影时刻（car0 对 car2 的 $t=3$）。
3. **$\textit{res}$ 初始化为 $-1.0$（double）**：$-1$ 兼作「永不被吸收」的哨兵；相遇时间是实数（$1.5$），类型上直接用浮点数组。
4. **停栈条件用严格 $>$**：$\tau = \textit{res}[j]$ 意味着 $i$ 恰在 $j$ 并入瞬间与之同点，算相遇，赋 $\tau$。
5. **C++ 先转 `double` 再除**：`(double)(pj - p) / (s - sj)`；两个 `int` 直接相除会截断。Python 的 `/` 天然返回 float，无此坑。
6. **弹空后仍要 push**：$i$ 成为新栈底——它可能追上前方任何一辆车，也是更左侧车的新候选。
7. **弹栈对更左的车同样安全**：被弹掉的 $j$ 只可能是「追不上」或「先被吸收」两种形态（§5 引理 2、引理 3 保证它不会挡住任何后来者的真实相遇），所以**永久删除**不损失信息——这正是均摊 $O(n)$ 的根基。

## 5. 正确性证明

记 $\tau(x, y) = \dfrac{p_y - p_x}{s_x - s_y}$（$s_x > s_y$ 时有定义），$\ell_L(t) = p_L + s_L t$。

**引理 1（车队 ≡ 领队匀速线）**：设车队在时刻 $t_0$ 由若干部件合并而成、领队为 $L$（最前车），则对一切 $t \ge t_0$，车队位置为 $\ell_L(t) = p_L + s_L t$。

**证明**：对吸收次数归纳。单车情形平凡。设车队 $\mathcal{A}$（领队 $a$）在 $t_0$ 追上领队为 $L$ 的车队 $\mathcal{B}$：追上即同位置，由归纳假设 $\mathcal{B}$ 位于 $\ell_L(t_0)$，$\mathcal{A}$ 也在该点；合并后新车队以最慢者 $L$ 的速度 $s_L$ 从该点匀速前进，位置恰为 $\ell_L(t) = p_L + s_L t$（同一点、同速度、同方向的两条匀速线重合）。∎

**推论**：$x$ 追上「由 $L$ 领队且 $L$ 在位」的车队 $\iff$ $s_x > s_L$ 且（$\textit{res}[L] = -1$ 或 $\tau(x, L) \le \textit{res}[L]$）。

**引理 2（栈不变量）**：任意时刻，栈内相邻两层 $w$（下，更右）与 $m$（上，更左）满足：$s_m > s_w$，$\textit{res}[m] = \tau(m, w)$，且 $\textit{res}[m] \le \textit{res}[w]$（$\textit{res}[w] = -1$ 时不设上界）。从而 $m$ 在 $\textit{res}[m]$ 时刻并入**由 $w$ 领队**的车队。此外 $\textit{res}[m] = -1$ 当且仅当 $m$ 位于栈底。

**证明**：$m$ 入栈前，其 while 循环恰好停在新栈顶 $w$ 上（停栈条件即 $s_m > s_w$ 且 $\textit{res}[w] = -1$ 或 $\tau(m,w) \le \textit{res}[w]$），且算法赋 $\textit{res}[m] = \tau(m, w)$；$m$ 之下的元素在 $m$ 存栈期间不变。若 $m$ 弹空了栈，$\textit{res}[m]$ 保持 $-1$，且 $m$ 入栈时栈空、必居栈底。∎

**引理 3（不可穿越）**：设处理 $x$ 时栈顶为 $j$，且 $x$ 未在 $j$ 消失前追上它（$s_x \le s_j$，或 $\tau(x,j) > \textit{res}[j] \ne -1$）。则对一切 $t < \textit{res}[j]$（若 $\textit{res}[j] = -1$ 则对一切 $t$）有 $\textit{pos}_x(t) < \textit{pos}_j(t)$；且对栈中 $j$ 下方任一层 $w$，只要 $\tau(x, w)$ 有定义则 $\tau(x, w) \ge \textit{res}[j]$。

**证明**：前者：位置差 $(p_x - p_j) + (s_x - s_j)t$，$s_x \le s_j$ 时恒负；$s_x > s_j$ 且 $\tau(x,j) > \textit{res}[j]$ 时该线性函数在 $t < \tau(x,j)$ 内为负。后者：反设 $\tau(x, w) < \textit{res}[j]$。由引理 2，$j$ 在 $\textit{res}[j]$ 时刻并入 $w$ 领队的车队，即 $j$ 的原线与 $\ell_w$ 相交于 $\textit{res}[j]$，且 $p_j < p_w,\ s_j > s_w$，故 $t < \textit{res}[j]$ 时 $\textit{pos}_j(t) < \ell_w(t)$。于是在 $t = \tau(x, w) < \textit{res}[j]$ 处 $\textit{pos}_x(t) = \ell_w(t) > \textit{pos}_j(t)$，与前者的 $\textit{pos}_x(t) < \textit{pos}_j(t)$ 矛盾。∎

**定理**：算法输出的 $\textit{res}[x]$ 等于 $x$ 与其物理下一辆车 $y$ 首次同位置的真实时刻；不相遇时为 $-1$。

**证明**：从右向左归纳，设右侧所有车的 $\textit{res}$ 均为真值，考察处理 $x$ 时 while 循环的落点。

- **停栈于 $j$**（$s_x > s_j$ 且 $\textit{res}[j] = -1$ 或 $\tau(x,j) \le \textit{res}[j]$）：由引理 1 推论，$\tau(x, j)$ 是 $x$ 追上「$j$ 领队、$j$ 在位」车队的真实时刻。若无弹出则 $j = y$，即 $x$ 直接追上 $y$ 本人；若有弹出，则由下面两条，每个被弹者最终都并入 $j$ 领队的车队，$x$ 追上的车队包含 $y$——两种情况均给出 $\textit{res}[x] = \tau(x,j)$ 的真实首次相遇（此前 $x$ 位于一切前方车之后，由引理 3）。
- **规则① 弹 $j$（$s_x \le s_j$）**：由引理 3，$x$ 永远在 $j$ 后方。若 $\textit{res}[j] = -1$，由引理 2 $j$ 是栈底，弹后栈空，$j$ 永不消失且始终挡在 $x$ 与前车之间，$\textit{res}[x] = -1$ 正确。否则 $j$ 在 $\textit{res}[j]$ 并入 $w$ 领队的车队（引理 2），此后 $x$ 的目标改为与 $\ell_w$ 求交，跳过 $j$、与 $w$ 比较恰好等价。
- **规则② 弹 $j$（$\tau(x,j) > \textit{res}[j] \ne -1$）**：$x$ 到达 $j$ 的原线之前 $j$ 已并入 $w$ 领队的车队，$x$ 的目标同样是与 $\ell_w$ 求交（引理 3 保证该交点不早于 $\textit{res}[j]$，即相遇发生在车队形成之后），跳过 $j$、与 $w$ 比较恰好等价。

两条规则都把 $x$ 的目标正确移交给「含 $y$ 的车队的下一任领队」，而由引理 2 该领队正是栈中下一层；循环终止时的落点必属上述三种之一。∎

> ⚠️ 引理 3 是整个证明里最容易被直觉略过的一环：没有它，「$x$ 与 $\ell_w$ 的交点可能早于 $j$ 并入」就无法排除，停栈算出的时刻可能是车队尚未形成时的**幻影时刻**。比赛中它是隐式假设，复盘时应当显式化。

## 6. 复杂度分析

- **时间复杂度**：$O(n)$ 均摊。每个下标至多入栈 1 次、出栈 1 次，while 的总步数不超过 $2n$；对照暴力 $O(n^2)$，差距全部来自「弹掉的候选永不再看」——这正是单调栈类题（如每日温度）的均摊论证。
- **空间复杂度**：$O(n)$。栈最坏存全部下标（速度严格递增时），$\textit{res}$ 是输出数组不计。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<double> getCollisionTimes(vector<vector<int>>& cars) {
        int n = cars.size();
        vector<double> res(n, -1.0);
        vector<int> stk;                        // 候选领队的下标，栈顶 = 最近的车
        for (int i = n - 1; i >= 0; --i) {
            int p = cars[i][0], s = cars[i][1];
            while (!stk.empty()) {
                int j = stk.back();
                int pj = cars[j][0], sj = cars[j][1];
                if (s <= sj) {
                    stk.pop_back();              // 规则①：x 追不上 j
                } else {
                    double t = (double)(pj - p) / (s - sj);
                    if (res[j] != -1.0 && t > res[j]) {
                        stk.pop_back();          // 规则②：j 先被前方吸收
                    } else {
                        res[i] = t;               // 停栈：t 秒后追上 j（或其车队）
                        break;
                    }
                }
            }
            stk.push_back(i);                    // i 成为新的候选领队
        }
        return res;
    }
};
```

### Python

```python
class Solution:
    def getCollisionTimes(self, cars: list[list[int]]) -> list[float]:
        n = len(cars)
        res: list[float] = [-1.0] * n
        stk: list[int] = []                       # 候选领队的下标，栈顶 = 最近的车
        for i in range(n - 1, -1, -1):
            p, s = cars[i]
            while stk:
                j = stk[-1]
                pj, sj = cars[j]
                if s <= sj:
                    stk.pop()                     # 规则①：x 追不上 j
                else:
                    t = (pj - p) / (s - sj)
                    if res[j] != -1.0 and t > res[j]:
                        stk.pop()                 # 规则②：j 先被前方吸收
                    else:
                        res[i] = t                # 停栈：t 秒后追上 j（或其车队）
                        break
            stk.append(i)                         # i 成为新的候选领队
        return res
```

> 💡 两版逻辑一致。C++ 用 `vector` 充当栈，除法显式转 `(double)` 防整数截断；Python `/` 天然返回 float。除零不可能：$s - s_j > 0$ 已被规则① 的 `s <= sj` 分支先行排除。

## 8. 边界情况与易错点

1. **$n = 1$**：栈空直接 $-1$，`while` 一次不进，无需特判。
2. **全员同速 / 速度随位置递增**：规则① 连续弹空，全 $-1$；别在弹空处提前 `break` 出外层循环。
3. **规则① 不是「追不上就输出 $-1$」**：$s_i \le s_j$ 时 $j$ 可能并入前方慢车队而减速，$i$ 仍可能追上减速后的车队。写成 `if s <= sj: res[i] = -1, break` 是本题最经典的 WA——示例 2 的 car0 正是被同速的 car1「挡过」又最终追上车队。
4. **规则② 的等号方向**：弹栈条件必须用**严格大于**。$\tau = \textit{res}[j]$ 时 $i$ 恰在 $j$ 并入瞬间与之同点，按题意算相遇，应停栈赋 $\tau$。
5. **C++ 整数除法**：`(pj - p) / (s - sj)` 两个 `int` 相除截断为 0 或错值，必须先转 `double` 再除。
6. **$\textit{res}$ 类型**：用 `double`/`float` 并初始化 $-1$；相遇时间是实数（示例 2 的 $1.5$），且 $-1$ 哨兵兼作「永不被吸收的领队」标记。
7. **弹空后忘记 `push`**：$i$ 必须入栈成为新候选（它可能被更左的车追上），否则后续车的栈内容错乱。
8. **精度与范围**：$p, s \le 10^6$ ⟹ $|p_j - p_i| < 10^6$、$s_i - s_j \le 10^6 - 1$、$\tau \le 10^6$；double 有 15+ 位有效数字，单次除法的相对误差 $\sim 10^{-16}$，绝对误差 $\ll 10^{-5}$，无需 `long double`。

**延伸思考**：① **事件堆模拟 $O(n \log n)$**（官方堆标签的由来）：把「相邻活动单元的相遇事件」放入小根堆，初始为 $n-1$ 个相邻对（$s_i > s_{i+1}$ 才有事件）；每次弹出最早事件即执行一次合并，随后为合并单元的左邻居对新领队重算一个候选事件入堆（用并查集或链表维护「右侧最近的独立车队」，过期事件弹出时重算即可）。它与单调栈殊途同归：堆版按物理时间顺序结算合并、更贴近直觉但代码更重；单调栈版把「下一任领队」提前算好，一遍扫完。② **若追问 $t$ 时刻还剩多少车队**：每次相遇即一次合并，对 $\textit{res}$ 排序后二分即可（车队数 $= n -$ 时刻 $t$ 前的合并数），本题的输出天然就是合并事件表。③ **若速度允许为负（对向而行）**：「车队速度 = 最慢者」的模型崩塌（穿行而非跟随），单调栈不再适用，只能回到事件模拟。④ **853 可看作本题的计数投影**：本题算出每辆车的相遇时刻后，「到达终点前的车队数」只是它的一次函数。
