# LeetCode 分割的最大得分 题解

## 1. 题目概述

- **标题 / 题号**：分割的最大得分（#3788，medium）
- **链接**：https://leetcode.cn/problems/maximum-score-of-a-split/
- **来源**：LeetCode 第 482 场周赛 Q1
- **难度**：中等
- **标签**：数组、前缀和

**题意**：给定长度为 $n$ 的整数数组 `nums`，选一个分割下标 $i$（$0 \le i < n-1$）。记 `prefixSum(i)` 为前缀 `nums[0..i]` 的**和**，`suffixMin(i)` 为后缀 `nums[i+1..n-1]` 的**最小值**，分割得分为 $\text{score}(i) = \text{prefixSum}(i) - \text{suffixMin}(i)$。返回所有合法分割下标中的**最大得分**。

**约束**：

- `2 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`

## 2. 示例

**示例 1**

```text
输入：nums = [10,-1,3,-4,-5]
输出：17
解释：最优分割 i = 2，score(2) = (10 + (-1) + 3) - (-5) = 17
```

**示例 2**

```text
输入：nums = [-7,-5,3]
输出：-2
解释：最优分割 i = 0，score(0) = (-7) - (-5) = -2
```

**示例 3**

```text
输入：nums = [1,1]
输出：0
解释：唯一合法分割 i = 0，score(0) = 1 - 1 = 0
```

## 3. 解题思路

### 3.1 暴力思路

对每个 $i$ 从 $0$ 到 $n-2$，现场计算 `prefixSum(i)`（扫一遍左段）与 `suffixMin(i)`（扫一遍右段），取最大。单次 $O(n)$，总复杂度 $O(n^2)$。$n = 10^5$ 时约 $10^{10}$ 次操作，超时。

### 3.2 核心观察：前缀「边扫边加」+ 后缀「预处理最小值」

![分割得分：前缀和减后缀最小值](images/max_split_score_concept.svg)

`score(i)` 由两个**方向相反**的区间统计量拼成：

- **前缀和**：从左往右扫，用变量 `pre` 滚动维护，`pre += nums[i]` 即可从 `prefixSum(i-1)` 得到 `prefixSum(i)`，$O(1)$ 转移，无需数组。
- **后缀最小值**：从右往左递推**后缀最小值数组** `sufMin[j] = min(nums[j..n-1])`，转移 `sufMin[j] = min(nums[j], sufMin[j+1])`，查询 `suffixMin(i)` 就是 `sufMin[i+1]`，$O(1)$。

两者都是"预处理一趟、每次查询 $O(1)$"的经典套路，合起来每个分割点只需 $O(1)$ 时间打分，总复杂度 $O(n)$。

![后缀最小值数组从右往左递推](images/max_split_score_suffix_min.svg)

### 3.3 算法流程

1. **建后缀最小值数组**：`sufMin[n-1] = nums[n-1]`，`j` 从 `n-2` 递减到 `1`，`sufMin[j] = min(nums[j], sufMin[j+1])`（`j = 0` 永远查不到）。
2. **从左往右枚举分割点**：`pre = 0`，`i` 从 `0` 到 `n-2`，每步 `pre += nums[i]`，用 `pre - sufMin[i+1]` 更新答案。
3. 返回答案最大值。

### 3.4 示例演算

`nums = [10, -1, 3, -4, -5]`（$n = 5$，分割点 $i \in \{0,1,2,3\}$）：

| $i$ | prefixSum($i$) | 后缀区间 | suffixMin($i$) | score($i$) |
|-----|----------------|----------|----------------|------------|
| 0   | 10             | [-1,3,-4,-5] | -5        | 15         |
| 1   | 9              | [3,-4,-5]    | -5        | 14         |
| 2   | 12             | [-4,-5]       | -5        | **17** ✓   |
| 3   | 8              | [-5]          | -5        | 13         |

![示例1枚举所有分割点的演算表](images/max_split_score_walkthrough.svg)

注意 score 序列为 15 → 14 → 17 → 13，**先降后升再降**，关于 $i$ 没有单调性，必须全部枚举。

## 4. 算法细节

1. **两趟扫描**：第一趟从右往左建 `sufMin`，第二趟从左往右滚 `pre` 并打分，两趟互不干扰。
2. **数据类型**：$\lvert$前缀和$\rvert \le 10^5 \times 10^9 = 10^{14}$，超出 32 位整数范围；score 最大约 $2 \times 10^{14}$，C++ 必须用 `long long`（题目接口返回类型就是 `long long`），Python 天然大整数无碍。
3. **下标对齐**：`suffixMin(i)` 的区间从 `i+1` 开始，查表用 `sufMin[i+1]`；建表时 `j` 只需递减到 `1`（`j = 0` 用不到，算了也不错）。
4. **O(1) 额外空间变体**：由 `prefixSum(i) = total - sum(nums[i+1..n-1])`，可从右往左一趟同时维护后缀和与后缀最小值，用 `total - sufSum - mn` 打分，省掉 `sufMin` 数组：

```python
total = sum(nums)
ans, suf_sum, mn = float('-inf'), 0, float('inf')
for j in range(len(nums) - 1, 0, -1):
    suf_sum += nums[j]
    mn = min(mn, nums[j])
    ans = max(ans, total - suf_sum - mn)
```

## 5. 正确性证明

**引理 1**：对任意 $j \in [1, n-1]$，递推得到的 `sufMin[j]` 等于 $\min(\text{nums}[j..n-1])$。

**证明**：对 $j$ 从 $n-1$ 到 $1$ 倒序归纳。边界：`sufMin[n-1] = nums[n-1]` 即单元素区间的最小值，成立。归纳步：设 `sufMin[j+1] = min(nums[j+1..n-1])`，则 `sufMin[j] = min(nums[j], sufMin[j+1]) = min(nums[j..j+1..n-1])`，即区间 $[j, n-1]$ 的最小值。∎

**引理 2**：第二趟扫描处理到 $i$ 时，`pre` 恰为 $\sum_{k=0}^{i}\text{nums}[k]$。

**证明**：对 $i$ 归纳。`pre` 初始为 0（空前缀的和），每步先执行 `pre += nums[i]` 再打分，故打分时 `pre` 覆盖区间 $[0, i]$。∎

**定理**：算法返回 $\max_{0 \le i \le n-2}\big(\text{prefixSum}(i) - \text{suffixMin}(i)\big)$，即题目所求。

**证明**：合法分割下标恰为 $i \in [0, n-2]$，循环逐一枚举、无遗漏无重复。由引理 1、2，每次计算的 `pre - sufMin[i+1]` 恰等于 $\text{score}(i)$。对这些值取 `max` 即为所求最大得分。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。一趟从右往左建 `sufMin` + 一趟从左往右打分，各 $O(n)$。
- **空间复杂度**：$O(n)$，为 `sufMin` 数组；采用 §4 的变体可降到 $O(1)$ 额外空间。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long maximumScore(vector<int>& nums) {
        int n = nums.size();
        vector<int> sufMin(n);
        sufMin[n - 1] = nums[n - 1];
        for (int j = n - 2; j >= 1; j--) {
            sufMin[j] = min(nums[j], sufMin[j + 1]);
        }
        long long ans = LLONG_MIN, pre = 0;
        for (int i = 0; i + 1 < n; i++) {
            pre += nums[i];
            ans = max(ans, pre - sufMin[i + 1]);
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maximumScore(self, nums: List[int]) -> int:
        n = len(nums)
        suf_min = [0] * n
        suf_min[-1] = nums[-1]
        for j in range(n - 2, 0, -1):
            suf_min[j] = min(nums[j], suf_min[j + 1])
        ans, pre = float('-inf'), 0
        for i in range(n - 1):
            pre += nums[i]
            ans = max(ans, pre - suf_min[i + 1])
        return ans
```

## 8. 边界情况与易错点

1. **64 位溢出**：$n \le 10^5$、$|\text{nums}[i]| \le 10^9$，前缀和与得分可达 $10^{14} \sim 2 \times 10^{14}$，C++ 用 `int` 必挂，须 `long long`。
2. **分割点范围**：$0 \le i \le n-2$，最后一个元素**永远属于后缀**；不存在 $i = n-1$（后缀为空，`suffixMin` 无定义）。循环条件写 `i + 1 < n` 防越界。
3. **off-by-one**：查询用 `sufMin[i+1]` 而非 `sufMin[i]`，后缀从 $i+1$ 开始。
4. **答案可为负**：全负数组（示例 2）最优解是 $-2$，答案不能初始化为 0，应初始化为极小值（`LLONG_MIN` / `-inf`）或首个 score(0)。
5. **$n = 2$**：唯一分割 $i = 0$，答案 = `nums[0] - nums[1]`，被通用流程自然覆盖，无需特判。
6. **别把两边搞混**：前缀用**和**、后缀用**最小值**，是一"加"一"min"的组合，不是前后缀同一种统计量。
