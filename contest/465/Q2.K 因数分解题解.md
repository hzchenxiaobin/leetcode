# LeetCode K 因数分解 题解

## 1. 题目概述

- **标题 / 题号**：K 因数分解（#3669，medium）
- **链接**：https://leetcode.cn/problems/balanced-k-factor-decomposition/
- **来源**：LeetCode 第 465 场周赛 Q2
- **难度**：中等
- **标签**：数学、回溯、数论

**题意**：给定整数 $n$ 和 $k$，把 $n$ **恰好**拆成 $k$ 个正整数，使它们的**乘积等于** $n$。在所有拆法中，返回**最大值 − 最小值**最小的一种，顺序任意。

**约束**：

- $4 \le n \le 10^5$
- $2 \le k \le 5$
- $k$ 严格小于 $n$ 的正因子总数（即因子数 $\ge 3$，$n$ 必为合数；但算法不依赖这一条——$[1,\dots,1,n]$ 型拆法总是存在）

> 💡 关键读题点：拆出的数允许为 $1$（示例 2 中 $[1,1,44]$ 是合法方案）；目标是**最小化极差**而非让乘积最大，这是与"整数拆分"类题目的本质区别。

## 2. 示例

**示例 1**

```text
输入：n = 100, k = 2
输出：[10,10]
解释：10 * 10 = 100，极差为 0，已是最小可能值。
```

**示例 2**

```text
输入：n = 44, k = 3
输出：[2,2,11]
解释：全部 4 种不下降拆法：
  [1,1,44] 极差 43；[1,2,22] 极差 21；[1,4,11] 极差 10；[2,2,11] 极差 9 ✓
```

**示例 3（完全 $k$ 次幂，极差直接为 0）**

```text
输入：n = 8, k = 3
输出：[2,2,2]
解释：8 = 2³，三个因子全取 2 即可，极差 0。同理 32768 = 8⁵、k = 5 时答案为 [8,8,8,8,8]。
```

**示例 4（因子太少，被迫用 1 填充）**

```text
输入：n = 99998, k = 3
输出：[1,2,49999]
解释：99998 = 2 × 49999，49999 是质数，只有 4 个因子，k = 3 时最优只能是 [1,2,49999]，极差 49998。
```

## 3. 解题思路

### 3.1 暴力思路

$n$ 的因子构成候选集合，$n \le 10^5$ 时因子数 $D \le 128$（最大在 $n = 83160 = 2^3 \cdot 3^3 \cdot 5 \cdot 7 \cdot 11$）。暴力枚举所有有序 $k$ 元组并检查乘积是否为 $n$，组合数 $D^k$，$k = 5$ 时约 $128^5 \approx 3.4 \times 10^{10}$——不可行。等价地，把 $n$ 的每个质因子扔进 $k$ 个盒子也是 $k^{\omega(n)}$ 级别的爆炸。必须利用题目结构剪枝。

### 3.2 核心观察：不下降枚举 + 整除链

1. **顺序无关（排序不变性）**：目标只看 $\max - \min$，与因子顺序无关。$k!$ 个排列共享同一个多重集，只需枚举**不下降**序列 $a_1 \le a_2 \le \dots \le a_k$，每个多重集恰好访问一次。
2. **整除性**：不下降序列中，已选部分的乘积必须整除 $n$。等价地，每一步选的 $d$ 必须整除**剩余乘积** $\text{rem} = n / (a_1 \cdots a_j)$。
3. **上界 $d^t \le \text{rem}$**：还剩 $t$ 个名额时，后面的因子都 $\ge$ 当前 $d$、乘积恰为 $\text{rem}$，故 $d^t \le \text{rem}$。这把每层枚举上界压到 $\text{rem}^{1/t} \le \sqrt{n} \approx 316$。
4. **末因子强制**：$t = 1$ 时最后一个因子被唯一确定为 $\text{rem}$，无需枚举。

![核心观察：多重集排序与逐步整除](images/kfactor_nondec_sequences.svg)

这四条约束合起来，搜索树就变成 $n$ 的**乘法分拆树**：$n \le 10^5$、$k \le 5$ 时全范围实测最坏仅 **2864 个节点、9497 次整除判断**（$n = 90720$，$k = 5$），朴素 DFS 毫无压力。

### 3.3 算法流程

1. 初始化保底方案 $\text{best} = [1, \dots, 1, n]$（极差 $n - 1$，恒合法）。
2. DFS($\text{rem}$, $\text{start}$)：设当前路径为 $\text{path}$，剩余名额 $t = k - |\text{path}|$。
   - 若 $t = 1$：末因子强制为 $\text{rem}$，用 $(\text{rem} - \text{path}[0])$ 尝试更新 best，回溯。
   - 否则令 $d$ 从 $\text{start}$ 起递增，循环条件 $d^t \le \text{rem}$；仅当 $d \mid \text{rem}$ 时递归 DFS$(\text{rem}/d,\ d)$。
3. 返回 best。

### 3.4 示例演算

以 $n = 44$、$k = 3$ 为例（$\lfloor 44^{1/3} \rfloor = 3$，$\lfloor \sqrt{44} \rfloor = 6$）：

| 步骤 | path | rem | 动作 | best |
|------|------|-----|------|------|
| 0 | [] | 44 | 初始化保底方案 | [1,1,44]，极差 43 |
| 1 | [] | 44 | $d_1 = 1$：$1^3 \le 44$ 且 $1 \mid 44$，进入 | 不变 |
| 2 | [1] | 44 | $d_2 = 1$ → 末因子 44 | [1,1,44]，极差 43（不更新）|
| 3 | [1] | 44 | $d_2 = 2$ → 末因子 22 | [1,2,22]，极差 21 |
| 4 | [1] | 44 | $d_2 = 4$ → 末因子 11 | [1,4,11]，极差 10 |
| 5 | [] | 44 | $d_1 = 2$：$2^3 = 8 \le 44$ 且 $2 \mid 44$，进入 | 不变 |
| 6 | [2] | 22 | $d_2 = 2$ → 末因子 11 | **[2,2,11]，极差 9 ✓** |
| 7 | [] | 44 | $d_1 = 3$ 不整除 44 跳过；$d_1 = 4$ 时 $4^3 > 44$，循环终止 | [2,2,11] |

其中 $d_2 = 3, 5, 6$（$d_2^2 \le 44$ 但不整除 44）与 $d_1 = 3$ 都被整除性过滤。整棵树只有 **7 次函数调用、12 次整除判断**：

## 4. 算法细节

1. **保底方案**：`best` 初始化为 `[1]*(k-1) + [n]`，恒合法且极差最大，此后只需"严格更小才替换"，避免空答案特判。
2. **末因子强制**：$t = 1$ 时直接取 $\text{rem}$。由 $t = 2$ 时的循环条件 $d^2 \le \text{rem}$ 可得 $\text{rem}/d \ge d$，即强制末因子不小于前一个因子，**不下降性自动维持**，无需额外比较（见引理 3）。
3. **幂比较用整数运算**：C++ 里用循环乘法算 $d^t$，避免 `pow` 浮点误差。看似会溢出，实则安全：能进入循环体的 $d$ 满足 $d^t \le \text{rem} \le 10^5$；首次失败的判定值至多 $317^2 \approx 1.01 \times 10^5$（$t = 2$）或 $11^5 \approx 1.6 \times 10^5$（$t = 5$），`int` 足够，用 `long long` 更稳妥。
4. **极差比较的写法**：保底方案与所有候选都是不下降序列，故 `best.back() - best.front()` 即 $\max - \min$，无需再求最值。
5. **可选强化剪枝（本题用不上）**：当前状态下最终极差 $\ge \max(\lceil \text{rem}^{1/t} \rceil,\ \text{path}$ 末元素$) - \text{path}[0]$（剩余 $t$ 个数的最大值不低于其几何平均），若已 $\ge$ 当前最优可剪枝。乘法分拆树实在太小，朴素写法在 Python 下最坏约 2ms。

## 5. 正确性证明

**引理 1（排序不变性）**：任一合法分割方案按不下降排序后仍合法，且 $\max - \min$ 不变。

**证明**：乘法满足交换律，重排不改变乘积；$\max$、$\min$ 是多重集的对称函数，与顺序无关。∎

**引理 2（访问完整性）**：任一合法方案的不下降代表 $a_1 \le \dots \le a_k$ 必被 DFS 访问。

**证明**：对 $j$ 归纳断言：DFS 会以 $\text{path} = (a_1, \dots, a_j)$、$\text{rem} = a_{j+1} \cdots a_k$ 到达某次调用。$j = 0$ 时即初始调用 DFS$(n, 1)$。设断言对 $j$ 成立（$j < k - 1$），此时 $t = k - j \ge 2$，剩余因子 $a_{j+1}, \dots, a_k$ 均 $\ge a_j = \text{start}$，且：

- $a_{j+1} \mid \text{rem}$（$a_{j+1}$ 整除 $a_{j+1} \cdots a_k$）；
- $a_{j+1}^t \le a_{j+1} \cdots a_k = \text{rem}$（$t$ 个均 $\ge a_{j+1}$ 的整数之积）。

故循环会枚举到 $d = a_{j+1}$ 并递归，断言对 $j + 1$ 成立。$j = k - 1$ 时 $t = 1$，代码特判直接选中 $\text{rem} = a_k$。∎

**引理 3（末因子不下降性自动保持）**：若在 $t = 2$ 时经条件 $d^2 \le \text{rem}$ 递归，则强制末因子 $\text{rem}/d \ge d$。

**证明**：$d^2 \le \text{rem} \Rightarrow \text{rem}/d \ge d$。∎

**定理**：算法返回的方案极差最小。

**证明**：设最优方案为 $S$，由引理 1 可设 $S$ 不下降，由引理 2 它对应的叶子被访问，其极差 $(a_k - a_1)$ 参与 best 比较。best 初始为合法方案，每片叶子处取"当前所有已见方案的最小极差"，故最终 best 的极差 $\le S$ 的极差，又 $S$ 最优，二者相等。∎

## 6. 复杂度分析

- **时间复杂度**：每个内部节点的枚举量不超过 $\text{rem}^{1/2} \le \sqrt{n} \approx 316$（$t \ge 2$ 时 $d^t \le \text{rem}$），节点数为乘法分拆树的大小。$n \le 10^5$、$k \le 5$ 时全范围实测最坏 2864 个节点、9497 次整除判断（$n = 90720$，$k = 5$），Python 约 2ms、C++ 微秒级。理论上界可写为 $O(\sqrt{n} \cdot P(n, k))$，其中 $P(n, k)$ 为 $n$ 的长度 $\le k$ 的不下降因子前缀数，实际极小。
- **空间复杂度**：$O(k)$——递归深度与 path 长度均不超过 $k \le 5$（输出数组不计）。

## 7. 参考代码

### C++

```cpp
class Solution {
    int k;
    vector<int> best, path;

    long long power(long long d, int t) {   // 整数幂，避免浮点误差
        long long r = 1;
        while (t--) r *= d;
        return r;
    }

    void dfs(int rem, int start) {
        int t = k - (int)path.size();
        if (t == 1) {                       // 末因子被强制为 rem
            if (rem - path[0] < best.back() - best.front()) {
                best = path;
                best.push_back(rem);
            }
            return;
        }
        for (long long d = start; power(d, t) <= rem; d++) {
            if (rem % d == 0) {             // 整除剩余乘积才递归
                path.push_back((int)d);
                dfs(rem / (int)d, (int)d);  // start 抬高到 d，保证不下降
                path.pop_back();
            }
        }
    }

public:
    vector<int> minDifference(int n, int k) {
        this->k = k;
        best.assign(k - 1, 1);
        best.push_back(n);                  // 保底方案 [1,...,1,n]
        dfs(n, 1);
        return best;
    }
};
```

### Python

```python
class Solution:
    def minDifference(self, n: int, k: int) -> List[int]:
        best = [1] * (k - 1) + [n]          # 保底方案 [1,...,1,n]
        path = []

        def dfs(rem: int, start: int) -> None:
            t = k - len(path)
            if t == 1:                      # 末因子被强制为 rem
                if rem - path[0] < best[-1] - best[0]:
                    best[:] = path + [rem]
                return
            d = start
            while d ** t <= rem:            # 上界 d^t <= rem
                if rem % d == 0:
                    path.append(d)
                    dfs(rem // d, d)        # start 抬高到 d
                    path.pop()
                d += 1

        dfs(n, 1)
        return best
```

## 8. 边界情况与易错点

1. **末因子必须强制**：若 $t = 1$ 时仍用循环条件 $d^1 \le \text{rem}$ 从 start 扫到 rem，前缀全 1 时一片叶子就要 $O(n)$ 次循环，整体退化。特判 $t = 1$ 后每片叶子 $O(1)$。
2. **start 必须传 $d$ 而不是 1**：否则同一多重集的不同排列被重复枚举，退回 $D^k$ 暴力。
3. **溢出假象**：$d^t$ 看似爆 `int`，但循环条件保证进入循环体的 $d^t \le 10^5$，首次失败的判定值也不超过 $11^5 \approx 1.6 \times 10^5$，`int` 即可；用 `long long` 是求稳。
4. **保底方案不能忘**：不初始化 best 的话，$n = 99998$、$k = 3$ 这类"只有保底方案附近可选"的用例会返回空。
5. **`best.back() - best.front()` 依赖有序性**：保底方案与所有候选均为不下降序列；若改成乱序收集，必须改用 `max() - min()`。
6. **完全 $k$ 次幂无需特判**：$n = m^k$ 时 DFS 自然走到 $[m, \dots, m]$（极差 0），如 $100 = 10^2$、$8 = 2^3$、$32768 = 8^5$。
7. **题目约束已排除质数**（因子数 $\ge 3$），但即使 $n$ 为质数，算法也正确返回 $[1, \dots, 1, n]$，无需依赖该约束。
8. **输出顺序任意**：题目允许任意顺序，我们的输出天然不下降，不必再排序。
