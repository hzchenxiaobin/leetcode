# LeetCode 在网格图中访问一个格子的最少时间 题解

## 1. 题目概述

- **标题 / 题号**：在网格图中访问一个格子的最少时间（#2577，hard）
- **链接**：https://leetcode.cn/problems/minimum-time-to-visit-a-cell-in-a-grid/
- **来源**：LeetCode 第 334 场周赛 Q4
- **难度**：困难
- **标签**：最短路、Dijkstra、堆（优先队列）、广度优先搜索、矩阵、奇偶性

**题意**：给定 $m \times n$ 的非负整数矩阵 `grid`，$\text{grid}[r][c]$ 表示访问格子 $(r,c)$ 的最早时刻——到达 $(r,c)$ 时已经过的时间必须 $\ge \text{grid}[r][c]$。$t=0$ 从左上角 $(0,0)$ 出发，**每单位时间必须移动**到上下左右相邻格子之一（不能停留在格子上），每次移动花费 $1$ 单位时间。求最早到达右下角 $(m-1, n-1)$ 的时刻，无法到达返回 $-1$。

**约束**：

- $2 \le m, n \le 1000$，$4 \le m \times n \le 10^5$
- $0 \le \text{grid}[i][j] \le 10^5$，$\text{grid}[0][0] = 0$

> 💡 **读题关键**：① 门禁约束的是**到达时刻**（不是出发时刻，注意与 422 场 Q2/Q3 区分）；② **不能停留**——「等待」只能靠在相邻两格间来回折返实现，这正是本题全部技巧的来源；③ 起点没有前驱、无法折返，因此存在 $-1$ 的可能。

## 2. 示例

**示例 1**

```text
输入：grid = [[0,1,3,2],[5,1,2,5],[4,3,8,6]]
输出：7
解释：(0,0)₀ → (0,1)₁ → (1,1)₂ → (1,2)₃ → (1,1)₄ → (1,2)₅ → (1,3)₆ → (2,3)₇。
      t=4、t=5 在 (1,1)↔(1,2) 间折返一次，等 grid[1][3]=5 的门开。
```

**示例 2**

```text
输入：grid = [[0,2,4],[3,2,1],[1,0,4]]
输出：-1
解释：第一步必须在时刻 1 进入 (0,1) 或 (1,0)，但两者门禁分别为 2 和 3，均大于 1；
      起点又不能停留等待，无解。
```

**示例 3**（自造，覆盖「中途被迫折返」）

```text
输入：grid = [[0,1,2],[1,9,4],[2,4,3]]
输出：6
解释：t=2 到 (0,2) 后，t=3 进不了 (1,2)（3 < 4 且奇偶不符），
      在 (0,2)↔(0,1) 折返一次，t=5 进 (1,2)，t=6 到 (2,2)。
```

## 3. 解题思路

### 3.1 暴力思路

第一反应是 BFS，但「到达时刻 $\ge$ 门禁」的约束会**打破层序**：同一格子早到未必能用，绕路晚到反而可能更优。朴素的正确做法是把**时刻**扩进状态，在 $(\text{格子},\ t)$ 的状态图上做 BFS：边 $(r,c,t) \to (nr,nc,t+1)$ 要求 $t+1 \ge \text{grid}[nr][nc]$。

问题是时刻上限：最优解不超过「最大门禁 + 一点折返」约 $3 \times 10^5$，状态数约 $mn \times 3 \times 10^5 = 3 \times 10^{10}$，彻底爆炸。

**破局点**：时刻维其实是冗余的——同一格子上，只有「时刻的奇偶」与「是否已达最早」两件事有意义。把时刻维压掉，就得到 Dijkstra。

### 3.2 核心观察：奇偶锁定 + 折返等待

![核心观察：时刻奇偶被格子锁死，折返一次多耗 2 单位时间](images/grid334_parity_bounce.svg)

**观察 1（奇偶不变量）**：若 $t$ 时刻位于 $(r,c)$，则 $t \equiv r+c \pmod 2$。每移动一步 $t$ 增 $1$，同时 $(r+c)$ 的奇偶翻转，同余式归纳保持。**棋盘染色锁死了每个格子的到达时刻奇偶。**

**观察 2（折返 = 以 2 为单位的等待）**：不能停留，但可以在相邻两格间**来回弹跳**：若 $t$ 时刻合法位于 $u$，走法的前驱是 $p$（$t-1$ 时刻位于 $p$），则折返段 $u \to p \to u \to p \to \cdots$ 中每次重新进入 $u$、$p$ 的时刻都严格变大，门禁自动满足。于是从 $\text{dist}[u] = d$ 出发进入邻居 $v$ 的**可达时刻集合**恰为

$$\{\, t : t \ge \max(d+1,\ \text{grid}[v]),\quad t \equiv d+1 \pmod 2 \,\}$$

即「不早于门禁、且与 $d+1$ 同奇偶」的所有时刻——**等待只能以 2 为单位**。

**观察 3（起点是唯一例外）**：$(0,0)$ 没有前驱，折返等待在起点不成立。第一步必须在时刻 $1$ 进入门禁 $\le 1$ 的邻居；若 $\text{grid}[0][1] > 1$ 且 $\text{grid}[1][0] > 1$，直接返回 $-1$（约束 $m, n \ge 2$ 保证两个邻居都存在）。只要第一步走得出去，之后处处可折返——**特判通过后答案必然存在**。

### 3.3 状态转移：Dijkstra 边松弛

![边松弛：把 grid 值奇偶上取整到与 d+1 同奇偶](images/grid334_relax_parity.svg)

定义 $h(v)$ 为**不小于 $\text{grid}[v]$ 且 $\equiv r_v+c_v \pmod 2$ 的最小整数**（门禁做奇偶上取整）。由观察 1，$d+1$ 与 $r_v+c_v$ 天然同奇偶，于是松弛公式可以写成一行：

$$t = \begin{cases} d+1, & d+1 \ge \text{grid}[v] \\[2pt] \text{grid}[v] + \bigl((\text{grid}[v] - d - 1) \bmod 2\bigr), & \text{否则} \end{cases}$$

等价地 $t = \max\bigl(d+1,\ h(v)\bigr)$（「先取 max 再调奇偶」与「分别调奇偶再取 max」相同，见 §4）。这正是把网格看成的带节点入场时间的最短路问题；由于松弛函数 $t = \max(d+1, h(v))$ 关于 $d$ **单调不减**、且恒有 $t > d$，标准的 **Dijkstra**（小根堆）适用：每个格子首次弹出时的标签就是它的最早到达时刻。

![算法流程：起点特判加 Dijkstra，弹出终点即返回](images/grid334_dijkstra_flow.svg)

算法流程：

1. 特判 $\text{grid}[0][1] > 1$ 且 $\text{grid}[1][0] > 1$，是则返回 $-1$；
2. $\text{dist}[0][0] = 0$，$(0,0,0)$ 入小根堆；
3. 弹出堆顶 $(d, r, c)$：过期（$d > \text{dist}[r][c]$）则跳过；若 $(r,c)$ 是终点，返回 $d$；
4. 对四个邻居按上述公式算 $t$，若优于当前 $\text{dist}$ 则更新并入堆，回到 3。

### 3.4 示例演算

![示例 1 演算：网格值、奇偶上取整门禁 h、dist 与最优路径时间戳](images/grid334_walkthrough.svg)

对示例 1，先给每个格子算 $h$（门禁奇偶上取整），再跑 Dijkstra（下表 $\text{dist}$ 为最终结果）：

| 格子 | (0,0) | (0,1) | (0,2) | (0,3) |
|------|-------|-------|-------|-------|
| grid | 0 | 1 | 3 | 2 |
| $h$  | 0 | 1 | 4 | 3 |
| dist | **0** | **1** | 4 | 5 |

| 格子 | (1,0) | (1,1) | (1,2) | (1,3) |
|------|-------|-------|-------|-------|
| grid | 5 | 1 | 2 | 5 |
| $h$  | 5 | 2 | 3 | 6 |
| dist | 5 | **2** | **3** | 6 |

| 格子 | (2,0) | (2,1) | (2,2) | (2,3) |
|------|-------|-------|-------|-------|
| grid | 4 | 3 | 8 | 6 |
| $h$  | 4 | 3 | 8 | 7 |
| dist | 4 | 3 | 8 | **7** |

几次关键松弛：

- 弹出 $(0,0), d=0$：$(0,1)$ 得 $t = 1 \ge 1$ 直接入；$(1,0)$ 得 $t = 5 + (5-1)\%2 = 5$；
- 弹出 $(1,1), d=2$：$(1,2)$ 得 $t = 3 \ge 2$ 直接入；$(2,1)$ 得 $t = 3$；
- 弹出 $(1,2), d=3$：$(1,3)$ 因 $t=4 < 5$ 上取整为 $t = 5 + (5-4)\%2 = 6$；$(2,2)$ 得 $t = 8 + (8-4)\%2 = 8$；
- 弹出 $(1,3), d=6$：$(2,3)$ 得 $t = 7 \ge 6$ ✓；
- 弹出 $(2,3), d=7$：是终点，返回 $7$。

对应的最优走法正是示例路径 $\cdots (1,2)_3 \to (1,1)_4 \to (1,2)_5 \to (1,3)_6 \to (2,3)_7$——折返的那两步就是「以 2 为单位的等待」的实体化。

## 4. 算法细节

1. **两种松弛写法等价**：记 $p = r_v + c_v$，$\operatorname{pa}(x)$ 为把 $x$ 上调到 $\equiv p \pmod 2$ 的最小整数。$\operatorname{pa}$ 关于 $x$ 单调不减，而单调函数与 $\max$ 可交换：$\operatorname{pa}(\max(a,b)) = \max(\operatorname{pa}(a), \operatorname{pa}(b))$。故「先 $\max$ 再调奇偶」$=$「$\max(d+1, \operatorname{pa}(\text{grid}[v]))$」$= \max(d+1, h(v))$。代码用分支式 `t = grid[v] + (grid[v] - t) % 2` 一行实现。
2. **$-1$ 特判不可省**：不做特判时，Dijkstra 会「默许在起点折返等待」，把不可达误算成可达——示例 2 会被算成 $6$（正确答案是 $-1$）。特判通过后终点必可达（引理 3），循环结束后的 `return -1` 只是防御性代码。
3. **堆元素与过期判断**：$(d, r, c)$ 直接入堆；弹出时 `d > dist[r][c]` 说明是过期条目，跳过。无需 visited 数组，也无需 decrease-key——同一格子可能多次入堆，标签递减。
4. **弹出终点才返回**：入堆/松弛时的标签未必最优（之后可能被更小的替换），必须等它作为堆顶弹出时返回。
5. **数值范围**：$mn \le 10^5$，答案上界约 $\max(\text{grid}) + mn \approx 2 \times 10^5$，`int` 完全够用，无溢出风险。
6. **为什么不能普通 BFS**：松弛值 $t$ 不等于「层深 + 1」，门禁与折返打破了层序；Dijkstra「每次弹出全局最小标签」恰好吸收这种非均匀的时间推进。

## 5. 正确性证明

**引理 1（奇偶不变量）**：任何合法走法中，若 $t$ 时刻位于 $(r,c)$，则 $t \equiv r+c \pmod 2$。

**证明**：对 $t$ 归纳。$t=0$ 时位于 $(0,0)$，$0 \equiv 0$。设 $t$ 时刻结论成立且位于 $(r,c)$，则 $t+1$ 时刻位于其某邻居 $(r',c')$，$r'+c' = r+c \pm 1$，故 $t+1 \equiv r+c+1 \equiv r'+c' \pmod 2$。∎

**引理 2（折返等待）**：设某合法走法在时刻 $d \ge 1$ 位于 $u$，$p$ 为其 $d-1$ 时刻的前驱，$v$ 为 $u$ 的任一邻居。则对任意满足 $t \ge d+1$、$t \equiv d+1 \pmod 2$、$t \ge \text{grid}[v]$ 的 $t$，存在合法走法在时刻 $t$ 位于 $v$，且前 $d$ 步与原走法一致。

**证明**：将原走法在 $u$ 处截断，接上折返段 $u \xrightarrow{d+1} p \xrightarrow{d+2} u \xrightarrow{d+3} p \to \cdots$。由 $t \equiv d+1 \pmod 2$ 且 $t \ge d+1$，$k = \frac{t-d-1}{2}$ 为非负整数，折返 $k$ 个往返后在时刻 $t-1$ 回到 $u$，最后一步于时刻 $t$ 进入 $v$。折返段中进入 $p$ 的时刻 $d+1, d+3, \dots$ 均 $> d-1 \ge \text{grid}[p]$，进入 $u$ 的时刻 $d+2, d+4, \dots$ 均 $> d \ge \text{grid}[u]$，又 $t \ge \text{grid}[v]$，全程合法。∎

**引理 3（起点特判充要）**：无解当且仅当 $\text{grid}[0][1] > 1$ 且 $\text{grid}[1][0] > 1$。

**证明**：（⇒ 无解方向）第一步必须在时刻 $1$ 进入 $(0,1)$ 或 $(1,0)$，需要对应门禁 $\le 1$；若均 $> 1$，则不存在合法的第一步。且 $(0,0)$ 无前驱，引理 2 的折返不可用（「在起点等待」等价于停留，不合法），故无解。

（⇐ 有解方向）设 $\text{grid}[0][1] \le 1$（另一侧对称）。对从 $(0,0)$（$d=0$）出发进入邻居 $v$、目标时刻 $t \ge \max(1, \text{grid}[v])$ 且 $t$ 为奇数的情形：若 $v = (0,1)$ 且 $\text{grid}[v] \le 1$，时刻 $1$ 直接进入；否则在 $(0,0)$ 与 $(0,1)$ 间折返 $k = \frac{t-1}{2}$ 个往返，于时刻 $t-1$ 回 $(0,0)$、时刻 $t$ 进 $v$（进入 $(0,1)$ 的时刻 $1, 3, \dots$ 均 $\ge \text{grid}[0][1]$，回到 $(0,0)$ 的时刻 $\ge 2 > 0 = \text{grid}[0][0]$）。故起点的「虚拟等待」总能被折返实现。此后每条走法都含至少一步，引理 2 处处可用，网格连通，用「沿任意最短路逐步走、走不动就折返等 2 拍」即可到达终点。∎

**定理 1（递推式）**：记 $\text{dist}[v]$ 为到达 $v$ 的最早时刻（$\text{dist}[(0,0)] = 0$），则对任意 $v \ne (0,0)$：

$$\text{dist}[v] = \min_{u \sim v} \max\bigl(\text{dist}[u] + 1,\ h(v)\bigr)$$

**证明**：（$\ge$）取到达 $v$ 的最优走法，设其于时刻 $t$ 首次到达 $v$，最后一步来自邻居 $u$、时刻 $t-1$。该走法的前缀是到达 $u$ 的合法走法，故 $\text{dist}[u] \le t-1$；又 $t \ge \text{grid}[v]$ 且由引理 1 $t \equiv r_v+c_v \pmod 2$，故 $t \ge h(v)$。于是 $\max(\text{dist}[u]+1, h(v)) \le t$，对所有 $u$ 取 $\min$ 仍 $\le t = \text{dist}[v]$。

（$\le$）取任一邻居 $u$ 及其最优走法（$\text{dist}[u]=d$）。令 $t = \max(d+1, h(v))$，则 $t \ge d+1$、$t \equiv d+1 \pmod 2$（$d+1$ 与 $h(v)$ 均 $\equiv r_v + c_v$）、$t \ge \text{grid}[v]$。若 $u \ne (0,0)$ 或其最优走法非空，由引理 2 可在时刻 $t$ 到达 $v$；若 $u = (0,0)$（空走法），由引理 3（特判已通过）同样可行。故 $\text{dist}[v] \le t$，对所有 $u$ 取 $\min$ 即得。∎

**定理 2（Dijkstra 正确性）**：算法中每个格子**首次弹出**时的标签等于其真实 $\text{dist}$。

**证明**：先注意两点事实。**（a）可行性**：堆中任意标签都由「已定型格子的正确 $\text{dist}$」经引理 2/3 的构造推出，是可实现的到达时刻，故标签 $\ge \text{dist}$（过期条目被 `d > dist` 跳过，松弛只用弹出的最终标签）。**（b）弹出标签单调不减**：小根堆性质。

对弹出次序归纳。首次弹出 $(0,0)$ 标签 $0 = \text{dist}[(0,0)]$ ✓。设前 $k$ 次弹出均定型正确，考察第 $k+1$ 次弹出 $(d^*, v)$：由 (a) 已有 $d^* \ge \text{dist}[v]$。反设 $d^* > \text{dist}[v]$，取到达 $v$ 的最优走法 $P = x_0, x_1, \dots, x_T$（$x_0 = (0,0)$，$x_T = v$，$T = \text{dist}[v] < d^*$，$x_i$ 于时刻 $i$ 被进入）。令 $j$ 为第一个**尚未定型**的下标（存在：$x_T = v$ 此刻才弹出）。$x_{j-1}$ 已定型且标签正确 $= \text{dist}[x_{j-1}]$，它被弹出时松弛过边 $x_{j-1} \to x_j$，给 $x_j$ 的标签 $\le \max(\text{dist}[x_{j-1}]+1, h(x_j))$；而 $P$ 于时刻 $j-1 \ge \text{dist}[x_{j-1}]$ 在 $x_{j-1}$、时刻 $j$ 进入 $x_j$，故 $j \ge \text{dist}[x_{j-1}]+1$ 且 $j \ge h(x_j)$，于是 $x_j$ 的当前标签 $\le j \le T < d^*$。$x_j$ 未定型故仍在堆中，与「$d^*$ 是当前堆顶最小」矛盾。故 $d^* = \text{dist}[v]$。∎

**推论**：由引理 3，特判通过后终点必可达；由定理 2，终点首次弹出时返回的 $d$ 即最少到达时刻。未通过特判时返回 $-1$ 正确。

## 6. 复杂度分析

- **时间复杂度**：$O(mn \log(mn))$。每个格子只在**定型弹出**时松弛其 $4$ 个邻居一次，有效松弛共 $O(mn)$ 次；每次堆操作 $O(\log(mn))$；过期条目至多与有效松弛同阶，不影响量级。特判 $O(1)$。
- **空间复杂度**：$O(mn)$。`dist` 矩阵与堆（至多 $O(mn)$ 个条目）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minimumTime(vector<vector<int>>& grid) {
        // 起点特判：第一步必须在时刻 1 进入门禁 ≤ 1 的邻居
        if (grid[0][1] > 1 && grid[1][0] > 1) return -1;

        int m = grid.size(), n = grid[0].size();
        vector<vector<int>> dist(m, vector<int>(n, INT_MAX));
        priority_queue<tuple<int, int, int>, vector<tuple<int, int, int>>, greater<>> pq;
        dist[0][0] = 0;
        pq.emplace(0, 0, 0);
        int dirs[4][2] = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};

        while (!pq.empty()) {
            auto [d, r, c] = pq.top();
            pq.pop();
            if (d > dist[r][c]) continue;          // 过期条目
            if (r == m - 1 && c == n - 1) return d; // 弹出即最优
            for (auto& [dr, dc] : dirs) {
                int nr = r + dr, nc = c + dc;
                if (nr < 0 || nr >= m || nc < 0 || nc >= n) continue;
                int t = d + 1;
                if (t < grid[nr][nc]) {            // 等到门开且与 d+1 同奇偶
                    t = grid[nr][nc] + (grid[nr][nc] - t) % 2;
                }
                if (t < dist[nr][nc]) {
                    dist[nr][nc] = t;
                    pq.emplace(t, nr, nc);
                }
            }
        }
        return -1; // 特判通过后必可达，防御性返回
    }
};
```

### Python

```python
import heapq

class Solution:
    def minimumTime(self, grid: List[List[int]]) -> int:
        if grid[0][1] > 1 and grid[1][0] > 1:
            return -1
        m, n = len(grid), len(grid[0])
        dist = [[float('inf')] * n for _ in range(m)]
        dist[0][0] = 0
        pq = [(0, 0, 0)]
        while pq:
            d, r, c = heapq.heappop(pq)
            if d > dist[r][c]:
                continue
            if r == m - 1 and c == n - 1:
                return d
            for nr, nc in ((r + 1, c), (r - 1, c), (r, c + 1), (r, c - 1)):
                if 0 <= nr < m and 0 <= nc < n:
                    t = d + 1
                    if t < grid[nr][nc]:                 # 折返等待，奇偶上取整
                        t = grid[nr][nc] + (grid[nr][nc] - t) % 2
                    if t < dist[nr][nc]:
                        dist[nr][nc] = t
                        heapq.heappush(pq, (t, nr, nc))
        return -1
```

## 8. 边界情况与易错点

1. **忘记 $-1$ 特判（最高频翻车点）**：Dijkstra 会默许「在起点折返等待」，示例 2 会被误算成 $6$ 而非 $-1$。反过来，特判通过后**不要再担心无解**，答案必然存在。
2. **奇偶调整方向搞反**：只能**向上补 1**（时刻不能早于门禁），写成 $\text{grid}[v] - 1$ 会得到非法时刻。补 1 的依据是 $t \equiv d+1 \pmod 2$，不是随便补。
3. **误用普通 BFS / 0-1 BFS**：门禁与折返打破层序，必须 Dijkstra；同理「按 $r+c$ 分层 DP」也不成立——$h$ 值沿路径不单调。
4. **在入堆时返回答案**：松弛值未必最终最优，必须等终点作为堆顶弹出再返回。
5. **`(grid[v] - t) % 2` 只在 `t < grid[v]` 分支用**：保证差为正，规避负数取模在 C++（向零取整）与 Python（向下取整）下的语义差异。
6. **同一格子多次入堆是正常的**：靠 `d > dist[r][c]` 过期判断跳过，不要用 visited 阻止后续更优的更新。
7. **$m, n \ge 2$ 由约束保证**：特判中访问 `grid[0][1]`、`grid[1][0]` 不会越界；若改编成允许 $1 \times n$ 的版本需加保护。
