# LeetCode 找出字符串的可整除数组 题解

## 1. 题目概述

- **标题 / 题号**：找出字符串的可整除数组（#2575，medium）
- **链接**：https://leetcode.cn/problems/find-the-divisibility-array-of-a-string/
- **来源**：LeetCode 第 334 场周赛 Q2
- **难度**：中等
- **标签**：数组、数学、字符串

**题意**：给定下标从 $0$ 开始、长度为 $n$ 的数字字符串 `word`（由 `0`–`9` 组成）与正整数 $m$。求长度为 $n$ 的数组 `div`：若前缀 `word[0..i]` 表示的**数值**能被 $m$ 整除则 `div[i] = 1`，否则 `div[i] = 0`。

**约束**：

- $1 \le n \le 10^5$
- `word` 只含数字 `0`–`9`
- $1 \le m \le 10^9$

## 2. 示例

**示例 1**

```text
输入：word = "998244353", m = 3
输出：[1,1,0,0,0,1,1,0,0]
解释：能被 3 整除的前缀有 4 个："9"、"99"、"998244"、"9982443"。
```

**示例 2**

```text
输入：word = "1010", m = 10
输出：[0,1,0,1]
解释：能被 10 整除的前缀有 2 个："10" 和 "1010"。
```

**示例 3**（自造，覆盖 $m=1$ 全整除）

```text
输入：word = "505", m = 1
输出：[1,1,1]
解释：任何整数都能被 1 整除。
```

## 3. 解题思路

### 3.1 暴力思路

对每个 $i$，把 `word[0..i]` 解析成整数再判 `% m == 0`：

- **大数装不下**：$n$ 可达 $10^5$ 位，数值量级 $10^{10^5}$，远超 `long long`（约 $9.2\times 10^{18}$，仅 19 位）；
- **重复计算**：即使 Python 大整数能保正确，每次从头解析子串是 $O(i)$，总计 $O(n^2)\approx 10^{10}$，必然超时。

前缀之间只差「末尾追加一位」，理应增量维护——但增量维护的不能是数值本身（太长），而是它 $\bmod m$ 的**余数**。

### 3.2 核心观察：模对乘加可分配，余数滚动传递

![核心观察：追加一位等于旧数乘10加d，取模可滚动传递，只需维护小于m的余数](images/div334_rolling_remainder.svg)

设已处理前缀数值为 $V_{old}$，其余数 $r = V_{old} \bmod m$。追加数字 $d$ 后新前缀数值为

$$
V_{new} = V_{old} \times 10 + d.
$$

由取模对乘法与加法的分配律：

$$
V_{new} \bmod m = \big((V_{old} \bmod m)\times 10 + d\big) \bmod m = (r \times 10 + d) \bmod m.
$$

于是**不需要 $V_{old}$ 本身，只凭 $r$ 和 $d$ 就能推出新余数**：维护滚动余数 $r \gets (r\times 10 + d)\bmod m$，每步检查 $r$ 是否为 $0$ 即得 `div[i]`。$r$ 恒小于 $m \le 10^9$，「$10^5$ 位大数」被压成「一个机器字」。

### 3.3 算法流程

![算法流程：r=0，遍历每位 d=word[i]-'0'，r=(r×10+d)%m，r==0 则 div[i]=1 否则 0，返回](images/div334_flow.svg)

1. **初始化**：`r = 0`（空前缀数值为 $0$，余数 $0$）；
2. **滚动扫描**：对 $i = 0, \dots, n-1$：取 $d = \text{word}[i] - {}$`'0'`，更新 $r = (r\times 10 + d)\bmod m$，令 `div[i] = (r == 0) ? 1 : 0`；
3. **返回** `div`。

### 3.4 示例演算

![示例演算：word=998244353, m=3，逐位滚动余数，归零处 div=1](images/div334_walkthrough.svg)

以示例 1 `word="998244353"`、$m=3$ 为例：

| $i$ | $d$ | $r_{old}$ | $r_{old}\times 10+d$ | $r_{new}$ | `div[i]` |
|-----|-----|-----------|----------------------|-----------|----------|
| 0 | 9 | 0 | $9$ | $\mathbf{0}$ | 1 |
| 1 | 9 | 0 | $9$ | $\mathbf{0}$ | 1 |
| 2 | 8 | 0 | $8$ | $2$ | 0 |
| 3 | 2 | 2 | $22$ | $1$ | 0 |
| 4 | 4 | 1 | $14$ | $2$ | 0 |
| 5 | 4 | 2 | $24$ | $\mathbf{0}$ | 1 |
| 6 | 3 | 0 | $3$ | $\mathbf{0}$ | 1 |
| 7 | 5 | 0 | $5$ | $2$ | 0 |
| 8 | 3 | 2 | $23$ | $2$ | 0 |

输出 `[1,1,0,0,0,1,1,0,0]`。注意 $i=5,6$ 连续归零：余数一旦为 $0$ 就「重新出发」，若新位本身也是 $m$ 的倍数（$24$、$3$ 均被 $3$ 整除）则继续整除。

示例 2 `word="1010"`、$m=10$：$r$ 依次为 $1,0,1,0$，输出 `[0,1,0,1]`——以 $0$ 结尾且前缀数值恰为 $10$ 的倍数时归零。

## 4. 算法细节

1. **递推式**：$r_i = (r_{i-1}\times 10 + d_i)\bmod m$，$r_{-1}=0$；`div[i] = 1` 当且仅当 $r_i = 0$。
2. **中间量上界**：$r < m \le 10^9$，故 $r\times 10 + d \le (10^9-1)\times 10 + 9 < 1.1\times 10^{10}$。C++ 中 `int` 上界约 $2.1\times 10^9$ **放不下**，`r` 必须声明为 `long long`（或强制转换后再乘）；Python 无此虑。
3. **取模时机**：每步乘加后立即 `% m`，把 $r$ 压回 $< m$。这既保证 C++ 不溢出，也保证 Python 中 $r$ 不随位数膨胀（否则大整数乘法退化为 $O(n^2)$）。
4. **数据结构**：结果数组定长 `vector<int> div(n)` 一次分配；无其他结构。

## 5. 正确性证明

**引理 1**（模的分配律）：对任意非负整数 $V$、数字 $d\ (0\le d\le 9)$，有

$$
(V\times 10 + d)\bmod m = \big((V\bmod m)\times 10 + d\big)\bmod m.
$$

**证明**：设 $V = qm + r$，其中 $0\le r < m$。则

$$
V\times 10 + d = (10q)\,m + (r\times 10 + d),
$$

且 $r\times 10+d\ge 0$。由带余除法商余唯一性，$(V\times 10+d)\bmod m = (r\times 10+d)\bmod m$。∎

**定理**：对每个 $i\in[0,n)$，算法维护的 $r_i$ 等于前缀数值 $V_i = \overline{\text{word}[0..i]}$ 对 $m$ 的余数，从而 `div[i] = 1` 当且仅当 $m \mid V_i$。

**证明**：对 $i$ 归纳。基例 $i=0$：$r_0 = (0\times 10 + d_0)\bmod m = d_0\bmod m = V_0\bmod m$。归纳步：设 $r_{i-1} = V_{i-1}\bmod m$，则算法计算 $r_i = (r_{i-1}\times 10 + d_i)\bmod m$，由引理 1（取 $V = V_{i-1}$，$d = d_i$，注意 $V_i = V_{i-1}\times 10 + d_i$）得 $r_i = V_i\bmod m$。故 `div[i]=1` $\iff r_i = 0 \iff m\mid V_i$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。每个字符做一次乘法、一次加法、一次取模，共 $n$ 步，均为 $O(1)$。
- **空间复杂度**：$O(1)$ 额外空间。仅用 `r`、`d` 两个标量；返回数组不计入。

读入必须遍历每个字符，$\Omega(n)$ 不可破，$O(n)$ 已最优。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> divisibilityArray(string word, int m) {
        int n = word.size();
        vector<int> div(n);
        long long r = 0;                 // 滚动余数，恒有 0 <= r < m <= 1e9
        for (int i = 0; i < n; ++i) {
            int d = word[i] - '0';
            r = (r * 10 + d) % m;        // r*10+d < 1.1e10，long long 安全
            div[i] = (r == 0) ? 1 : 0;
        }
        return div;
    }
};
```

### Python

```python
class Solution:
    def divisibilityArray(self, word: str, m: int) -> List[int]:
        div = []
        r = 0
        for ch in word:
            d = ord(ch) - ord('0')
            r = (r * 10 + d) % m
            div.append(1 if r == 0 else 0)
        return div
```

## 8. 边界情况与易错点

1. **`int` 溢出**：`r * 10 + d` 上界约 $1.1\times 10^{10}$，超 `int`。C++ 中 `r` 用 `long long`；若写成 `(word[i]-'0') * 10 + r` 且 `r` 为 `int` 同样溢出，且溢出是未定义行为而非可察觉的回绕。
2. **$m = 1$**：任何数都被 $1$ 整除，`div` 全 $1$，递推自然覆盖（每步 `r == 0`），无需特判。
3. **前导零**：`word` 以 `'0'` 开头时 $V_0 = 0$，而 $0 \bmod m = 0$ 对任何 $m\ge 1$ 成立，故 `div[0] = 1`，符合数学定义「零可被任何非零整数整除」。
4. **`r == 0` 判定位置**：必须取模之后再判零。判在取模前（即判 $r\times 10+d=0$）只对全零串有效，是典型错位。
5. **Python 别省 `% m`**：不取模在 Python 里结果仍正确，但 `r` 位数线性增长到 $10^5$ 位，每步乘法 $O(\text{位数})$，总 $O(n^2)$ 超时——取模同时是性能要求。
