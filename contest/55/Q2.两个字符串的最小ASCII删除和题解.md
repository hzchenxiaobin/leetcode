# LeetCode 两个字符串的最小ASCII删除和 题解

## 1. 题目概述

- **标题 / 题号**：两个字符串的最小ASCII删除和（#712，medium）
- **链接**：https://leetcode.cn/problems/minimum-ascii-delete-sum-for-two-strings/
- **来源**：LeetCode 第 55 场周赛 Q2
- **难度**：中等
- **标签**：字符串，动态规划，最长公共子序列

**题意**：给定两个只含小写字母的字符串 `s1`、`s2`。每次可以从任意一个串里删掉一个字符，被删字符的 ASCII 值计入代价。要求用最小的总代价把两个串变成**完全相同**的字符串（允许是空串），返回这个最小代价。

**约束**：

- $1 \le \lvert s1 \rvert, \lvert s2 \rvert \le 1000$
- `s1`、`s2` 仅由小写英文字母组成
- 答案上界：$2000 \times 122 = 244000$，`int` 足够

## 2. 示例

**示例 1**

```text
输入：s1 = "sea"，s2 = "eat"
输出：231
解释：删 s1 的 's'（ASCII 115）与 s2 的 't'（ASCII 116），两串都变成 "ea"，代价 115+116=231。
```

**示例 2**

```text
输入：s1 = "delete"，s2 = "leet"
输出：403
解释：删 "delete" 的 d、e、e（100+101+101）得到 "let"；删 "leet" 的 e（101）也得到 "let"，
      合计 403。若都变成 "lee" 需要 433，都变成 "eet" 需要 417，都更大。
```

**示例 3（补充：说明"权最大"≠"长度最长"）**

```text
输入：s1 = "zzzzaaaaa"，s2 = "aaaaazzzz"
输出：970
解释：总 ASCII 和 Σ = 1946。保留 "aaaaa"（权 485，长度 5）代价 1946−2×485 = 976；
      保留 "zzzz"（权 488，长度 4）代价 1946−2×488 = 970，更短反而更划算。
      两串中 z 与 a 的先后顺序相反，无法同时保留，只能在两者间取权更大者。
```

## 3. 解题思路

### 3.1 暴力思路

最直白的枚举：把 `s1` 的每个下标子集当作"保留"、`s2` 的每个下标子集也当作"保留"，两者保留出的字符串相等时结算代价。方案数 $2^{n+m}$，$n=m=1000$ 时是天文数字。

换个角度枚举"最终字符串"同样不可行：长度 $k$ 的目标串有 $26^k$ 种。真正可行的是**按前缀划分状态**的记忆化/递推，状态 $(i,j)$ 共 $10^6$ 个，每格 $O(1)$ 转移——难点不在复杂度，而在把"删除代价"翻译成一个可递推的量。

### 3.2 核心观察：删除总量固定，等价于最大化"保留的权和"

![删除与公共子序列的对应关系](images/wc55_q2_delete_vs_lcs.svg)

设最终两串都变成 $t$。删字符不改变剩余字符的相对顺序，所以 $t$ 既是 `s1` 的子序列、又是 `s2` 的子序列，即 **$t$ 必须是公共子序列**；反过来，任一公共子序列 $t$ 都能靠"删掉两串中没被选中的字符"得到，是合法终态。

记 $w(t)=\sum_{c\in t}\operatorname{ord}(c)$、$\Sigma=\Sigma_1+\Sigma_2$ 为两串 ASCII 总和，则终态为 $t$ 时的删除代价

$$C(t)=\bigl(\Sigma_1-w(t)\bigr)+\bigl(\Sigma_2-w(t)\bigr)=\Sigma-2w(t)$$

$\Sigma$ 是**定值**，与方案无关，于是

$$\min_t C(t)\iff\max_t w(t)$$

问题化为：**求 `s1` 与 `s2` 的权和最大的公共子序列（最大权 LCS）**。

> ⚠️ 注意：这里的"最大"按字符权而非按长度。示例 3 中长度 4 的 `"zzzz"`（权和 488）优于长度 5 的 `"aaaaa"`（权和 485），因此**不能**先求 LCS 长度再算权值。

### 3.3 状态与转移

![状态与转移](images/wc55_q2_dp_transition.svg)

定义 $dp[i][j]$ 为 `s1` 前 $i$ 个字符与 `s2` 前 $j$ 个字符的最大权公共子序列权重。任一前缀与空串只能有空的公共子序列，故边界为

$$dp[0][j]=dp[i][0]=0$$

转移分两种情形：

$$dp[i][j]=\begin{cases}dp[i-1][j-1]+\operatorname{ord}\bigl(s1[i-1]\bigr), & s1[i-1]=s2[j-1]\\ \max\bigl(dp[i-1][j],\ dp[i][j-1]\bigr), & \text{否则}\end{cases}$$

最终 $W=dp[n][m]$，答案 $\Sigma-2W$。

**字符相同时为什么能直接接在左上角之后**：设 $s1[i-1]=s2[j-1]=c$。若最优公共子序列 $Z$ 完全不用这两个末字符，把 $c$ 追加到 $Z$ 末尾仍是公共子序列且权更大，矛盾；若 $Z$ 只用了其中一个，把那一对改配成这对末字符，权不变、配对位置仍递增；若两个都用，则它们必须互相配对（否则坐标递增性冲突）。所以总存在最优解以这对末字符收尾。

**一维滚动**：$dp[i][j]$ 只依赖上一行与当前行左侧，故只需一行。按 $i$ 递增、$j$ 递增填表，用 `diag` 暂存 $dp[i-1][j-1]$（即被覆盖前的 `dp[j-1]`）。

### 3.4 示例演算

![s1="sea" 与 s2="eat" 的填表过程](images/wc55_q2_walkthrough.svg)

对 `s1 = "sea"`、`s2 = "eat"` 填出 $4\times4$ 的表（行是 `s1` 前缀，列是 `s2` 前缀）：

| $dp[i][j]$ | $\varnothing$ | e | a | t |
|---|---|---|---|---|
| $\varnothing$ | 0 | 0 | 0 | 0 |
| s | 0 | 0 | 0 | 0 |
| e | 0 | **101** | 101 | 101 |
| a | 0 | 101 | **198** | 198 |

- $dp[2][1]$：`e`=`e`，取左上 $dp[1][0]=0$ 再加 101，得 101。
- $dp[3][2]$：`a`=`a`，取左上 $dp[2][1]=101$ 再加 97，得 198。
- $dp[3][3]$：`a`≠`t`，取 $\max(dp[2][3],dp[3][2])=\max(101,198)=198$。

于是 $W=198$、$\Sigma=313+314=627$，答案 $627-2\times198=231$，与示例 1 吻合。

示例 2 的三个候选都是长度 3 的公共子序列：`"let"` 权 $108+101+116=325$、`"eet"` 权 $318$、`"lee"` 权 $310$。取最大者 $W=325$，答案 $1053-650=403$——这也解释了题面中 433、417 为什么更差：它们分别是 $1053-2\times310$ 与 $1053-2\times318$。

## 4. 算法细节

1. **下标对齐**：$dp$ 用 1-based，字符用 0-based，判断写 `s1[i-1] == s2[j-1]`；外层 `for i in 1..n`、内层 `for j in 1..m`，避免在循环体里到处 `+1`。
2. **滚动数组的更新顺序**：内层 $j$ 必须**升序**（要读本行刚算出的 $dp[j-1]$）；覆盖前先 `up = dp[j]` 保存旧值，本轮末尾再 `diag = up`。
3. **相同字符时不必再取 max**：由 §3.3 的论证，$dp[i-1][j-1]+\operatorname{ord}(c)$ 已不小于另外两个来源；写成 `max` 也不会错，只是多一次比较。
4. **答案最后才拼装**：$dp$ 只维护"最大权和"，$\Sigma$ 单独统计。若把删除代价直接塞进转移，就会把"保留"与"删除"两个量混在同一个状态里，既不直观也容易漏项。
5. **空间取短边**：滚动数组长度取 $m=\min(\lvert s1\rvert,\lvert s2\rvert)$ 即可，因为 $w$ 与串的顺序无关、答案对称，可以先 `if len(s1) < len(s2): swap`。
6. **另一种等价写法**：直接定义 $f[i][j]$ 为"两前缀的最小删除和"，则 $f[0][j]=\sum_{k<j}\operatorname{ord}(s2[k])$、$f[i][0]=\sum_{k<i}\operatorname{ord}(s1[k])$，相等时用 $f[i-1][j-1]$，否则用 $\min\bigl(f[i-1][j]+\operatorname{ord}(s1[i-1]),\ f[i][j-1]+\operatorname{ord}(s2[j-1])\bigr)$。它与本文写法满足 $f[i][j]=P_1[i]+P_2[j]-2\,dp[i][j]$（$P$ 为前缀权和），是同一 DP 的两种坐标。
7. **字符取值**：C++ 中 `char` 可能带符号，转 `unsigned char` 再转 `int` 更稳妥；小写字母虽然安全，但这是通用习惯。
8. **不要用递归记忆化**：$n=m=1000$ 时递归深度可达 $2000$，Python 默认递归上限为 1000，容易 `RecursionError`；迭代填表没有这个风险。

## 5. 正确性证明

**引理 1（终态 ↔ 公共子序列）**：删完后两串都等于 $t$，则 $t$ 是 `s1`、`s2` 的公共子序列；反之任一公共子序列 $t$ 都可由"删掉两串中未参与匹配的字符"得到，且代价恰为 $\Sigma-2w(t)$。

**证明**：删字符不改变剩余字符的相对顺序，故 $t$ 同时是两串的子序列。反向：固定 $t$ 在 `s1`、`s2` 中的各一次嵌入，把未嵌入的字符全部删掉即得 $t$；被删字符的权和为 $(\Sigma_1-w(t))+(\Sigma_2-w(t))$。∎

**引理 2（转移正确）**：对 $i,j\ge1$，记 $X=s1[:i]$、$Y=s2[:j]$。若 $s1[i-1]=s2[j-1]=c$，则 $dp[i][j]=dp[i-1][j-1]+\operatorname{ord}(c)$；否则 $dp[i][j]=\max\bigl(dp[i-1][j],dp[i][j-1]\bigr)$。

**证明**：

*相等时*：取 $X,Y$ 的任一最优公共子序列 $Z$。若 $Z$ 不使用 $s1[i-1]$ 与 $s2[j-1]$，把 $c$ 追加到 $Z$ 末尾仍是公共子序列、权和增加 $\operatorname{ord}(c)>0$，与最优性矛盾；若 $Z$ 只使用其中之一（例如 $s1[i-1]$ 配到 $s2[k],k<j-1$），把该对改配为 $(i-1,j-1)$，字符同为 $c$、权和不变，且 $(i-1,j-1)$ 仍是最后一对，公共子序列性质保持；若两个都使用，则它们必须互相配对，否则两对的坐标递增性冲突。故存在权不小于 $Z$ 的最优解以这对末字符收尾，去掉 $c$ 后是 $(i-1)\times(j-1)$ 前缀的公共子序列，权 $\le dp[i-1][j-1]$，得 $dp[i][j]\le dp[i-1][j-1]+\operatorname{ord}(c)$；反向把 $c$ 接到 $dp[i-1][j-1]$ 的最优解之后即得 $\ge$，故取等。

*不等时*：任一公共子序列若不用 $s1[i-1]$，则它是 $X$ 去掉末字符与 $Y$ 的公共子序列，权 $\le dp[i-1][j]$；若用 $s1[i-1]$，则它必不用 $s2[j-1]$（末字符不相同无法配对），是 $X$ 与 $Y$ 去掉末字符的公共子序列，权 $\le dp[i][j-1]$。故总有 $dp[i][j]\le\max(dp[i-1][j],dp[i][j-1])$；而这两个值分别由对应前缀的最优解取到（它们的公共子序列也是 $X,Y$ 的公共子序列），故取等。∎

**引理 3（滚动数组不变量）**：处理第 $i$ 行第 $j$ 列之前，`dp[j]` 恒为 $dp[i-1][j]$、`diag` 恒为 $dp[i-1][j-1]$；写入后 `dp[j]` 变为 $dp[i][j]$。

**证明**：对 $j$ 归纳。$j=1$ 之前本行尚未写过任何格子，`dp[1]` 仍是上一行的值；`diag` 初始化为 $0$，正是 $dp[i-1][0]$。设处理完 $j-1$ 后成立：`dp[j]` 未被本行覆盖，仍为 $dp[i-1][j]$；`diag` 在该轮末尾被赋成旧 `dp[j-1]`，即 $dp[i-1][j-1]$。算出 $dp[i][j]$ 写入后，`diag` 更新为保存的 `up`=$dp[i-1][j]$，恰好满足列 $j+1$ 对角元的需求。∎

**定理**：`minimumDeleteSum` 返回最小删除代价 $\min_t\bigl(\Sigma-2w(t)\bigr)$。

**证明**：由引理 2 与引理 3，填表结束时数组末项 `keep[m]` 即 $dp[n][m]=W$，为两串最大权公共子序列的权和。由引理 1，任一终态 $t$ 的代价为 $\Sigma-2w(t)\ge\Sigma-2W$；取 $t$ 为最大权公共子序列时等号成立。故返回的 $\Sigma-2W$ 即为最小代价。∎

## 6. 复杂度分析

- **时间**：$O(nm)$。双层循环恰好 $nm\le10^6$ 次状态转移，每次 $O(1)$（一次比较，加一次加法或一次 `max`）；统计 $\Sigma$ 额外 $O(n+m)$。
- **空间**：$O(\min(n,m))$ 个整数（滚动数组）加常数额外变量；若保留完整二维表则为 $O(nm)$，本文实现为前者。

## 7. 参考代码

### C++

```cpp
#include <string>
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int minimumDeleteSum(string s1, string s2) {
        int n = s1.size(), m = s2.size();
        // keep[j] = s1[:i] 与 s2[:j] 的最大 ASCII 权和公共子序列权重
        vector<int> keep(m + 1, 0);
        for (int i = 1; i <= n; ++i) {
            int diag = 0;                        // dp[i-1][j-1]
            for (int j = 1; j <= m; ++j) {
                int up = keep[j];                // dp[i-1][j]，覆盖前先存
                if (s1[i - 1] == s2[j - 1]) {
                    keep[j] = diag + (int)(unsigned char)s1[i - 1];
                } else {
                    keep[j] = max(keep[j], keep[j - 1]);   // keep[j-1] 已是本行值
                }
                diag = up;                       // 供下一列当对角元
            }
        }
        int total = 0;
        for (char c : s1) total += (int)(unsigned char)c;
        for (char c : s2) total += (int)(unsigned char)c;
        return total - 2 * keep[m];
    }
};
```

### Python

```python
class Solution:
    def minimumDeleteSum(self, s1: str, s2: str) -> int:
        # 短串放内层，空间取 O(min(n, m))；答案与两串顺序无关
        if len(s1) < len(s2):
            s1, s2 = s2, s1
        n, m = len(s1), len(s2)

        keep = [0] * (m + 1)          # keep[j] = s1[:i] 与 s2[:j] 的最大权和公共子序列
        for i in range(1, n + 1):
            diag = 0                  # dp[i-1][j-1]
            ci = ord(s1[i - 1])
            for j in range(1, m + 1):
                up = keep[j]          # dp[i-1][j]，覆盖前先存
                if s1[i - 1] == s2[j - 1]:
                    keep[j] = diag + ci
                elif keep[j - 1] > keep[j]:   # keep[j-1] 已是本行值
                    keep[j] = keep[j - 1]
                diag = up             # 供下一列当对角元

        total = sum(map(ord, s1)) + sum(map(ord, s2))
        return total - 2 * keep[m]
```

## 8. 边界情况与易错点

1. **没有公共字符**：如 `s1="abc"`、`s2="xyz"`，$W=0$，答案就是 $\Sigma$（两串全删，都变成空串），空串是合法的终态，不要额外特判。
2. **两串完全相同**：如 `"abc"`/`"abc"`，每格都走对角，$W=\Sigma_1$，返回 0；若把对角转移写成无条件 `diag + ci`（不判字符相等），也会给出 0，但示例 1 会算错。
3. **长度悬殊**：$n=1,m=1000$ 时表只有 1001 格；Python 版先交换使 $m=\min$，注意交换发生在 `n, m` 赋值**之前**，否则内层长度取反。
4. **漏掉 $-2W$ 的系数 2**：只写 $\Sigma-W$ 会把"每个保留字符在两串中各留一次"算成一次，示例 1 会得到 $627-198=429$。
5. **滚动数组内层写成倒序**：倒序时 `keep[j-1]` 仍是上一行的值，"取左邻"会错算成"取上邻"，对角元 `diag` 也会读到过期值。
6. **把"最大权"当成"最长"**：示例 3 会答成 976 而不是 970，这是本题最容易踩的概念性错误。
7. **答案范围**：$0\le W\le\min(\Sigma_1,\Sigma_2)$，故答案恒在 $[0,\Sigma]$；$\Sigma\le244000$，`int` 足够。但若把权重换成更大的值（如 Unicode 码位）就需评估溢出。
8. **空串入参**：题面保证长度 $\ge1$，代码对空串也自然正确（循环不执行，返回另一串的权和），可作为防御性检查。
