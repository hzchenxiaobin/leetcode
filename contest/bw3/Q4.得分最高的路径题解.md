# LeetCode 得分最高的路径 题解

## 1. 题目概述

- **标题 / 题号**：得分最高的路径（#1102，medium）
- **链接**：https://leetcode.cn/problems/path-with-maximum-minimum-value/
- **来源**：LeetCode 第 3 场双周赛 Q4
- **难度**：中等
- **标签**：深度优先搜索、广度优先搜索、并查集、二分查找、堆（优先队列）、Dijkstra 算法、矩阵

**题意**：给定 $R \times C$ 的**非负**整数矩阵 `grid`，从左上角 $(0,0)$ 出发走到右下角 $(R-1, C-1)$，每步只能移动到上下左右相邻、且**未曾访问过**的格子（路径是简单路径）。一条路径的**得分**定义为路径上所有格值的**最小值**（瓶颈）。求所有合法路径中的**最大得分**。

**约束**：

- $1 \le R, C \le 100$
- $0 \le grid[i][j] \le 10^9$

## 2. 示例

**示例 1**

```text
输入：grid = [[5,4,5],[1,2,6],[7,4,6]]
输出：4
解释：路径 5 → 4 → 5 → 6 → 6 的最小值为 4，是所有路径中的最大瓶颈。
```

**示例 2**

```text
输入：grid = [[2,2,1,2,2,2],[1,2,2,2,1,2]]
输出：2
解释：矩阵里只出现 1 和 2 两种值，存在一条全 2 的走廊（如
     (0,0)→(0,1)→(1,1)→(1,2)→(1,3)→(0,3)→(0,4)→(0,5)→(1,5)），得分 2。
```

**示例 3**

```text
输入：grid = [[3,4,6,3,4],[0,2,1,1,7],[8,8,3,2,7],[3,2,4,9,8],[4,1,2,0,0],[4,6,5,4,3]]
输出：3
解释：值 ≥ 4 的格子无法连通两个角（中段横着 1、2 组成的低谷带），值 ≥ 3 的格子恰好连通，故答案为 3。
```

## 3. 解题思路

### 3.1 暴力思路

DFS 枚举起点到终点的**所有简单路径**，逐条取最小值再取最大。简单路径的数量是指数级的：即便 $4 \times 4$ 的网格，角到角的简单路径已数以千计，$100 \times 100$ 完全不可行。不过它时间复杂度虽差，逻辑最朴素，可以留作**小规模对拍的基准**（本文代码正是用 $1 \times 1$ 至 $4 \times 4$ 的随机小矩阵，把正解与全路径枚举对拍了 400 组）。

### 3.2 核心观察：从「最大化最小值」到「瓶颈路」

![核心观察：路径得分等于路径最小格值，三种等价视角](images/bw3_q4_bottleneck_concept.svg)

**观察一：「不重复访问」的约束可以去掉。** 若一条走法重复经过某些格子形成环，把环删掉仍是从起点到终点的走法，且剩余格子是原路径的子集——**最小值只增不减**（详见引理 1）。这说明简单路径的最优值与一般路径的最优值相同，BFS、并查集这类**不记忆路径**的算法因此获得了合法身份。

**观察二：瓶颈视角。** 定义 $D(v)$ 为从起点到格子 $v$ 的所有路径中「路径最小值」的最大值（**最大瓶颈**）。答案就是 $D(终点)$。它满足与最短路完全同构的松弛结构：

$$\text{最短路：} \quad dist(v) = \min\big(dist(u) + w\big) \qquad \text{瓶颈路：} \quad D(v) = \max_u \ \min\big(D(u),\ grid[v]\big)$$

加法换成取 $\min$、最小化换成最大化，Dijkstra 的整套贪心框架原样照搬——这就是**最大瓶颈路**（widest path）。

**观察三：对偶的单调谓词。** 「得分 $\ge x$ 的路径存在」$\iff$「只走值 $\ge x$ 的格子时两角连通」——后者随 $x$ 增大由真变假、单调，天然可**二分答案 + BFS 判定**。

> 💡 三种视角殊途同归：按 $D$ 从大到小松弛（Dijkstra 变体）、按阈值二分（二分 + BFS）、按格值从大到小激活格子（并查集，官方 hint 路线）。本文主推其中代码最紧凑、证明最系统的 **Dijkstra 变体**（即观察二），另两条路线的要点与证明附在 §4 与 §5 末尾。

### 3.3 算法流程（Dijkstra 变体：最大瓶颈路）

![算法流程：大根堆每次弹出瓶颈最大的格子并松弛四邻](images/bw3_q4_algorithm_flow.svg)

```text
1. best[r][c] = -1（全部未知）；best[0][0] = grid[0][0]；堆 push (grid[0][0], 起点)
2. 循环：弹出瓶颈 d 最大的格子 (r, c)
3.     若 (r, c) 是终点 (R-1, C-1)：返回 d
4.     若 d < best[r][c]：是过期堆条目，跳过        # 懒删除
5.     对 (r, c) 的每个相邻格 v：
6.         nd = min(d, grid[v])                     # 走到 v 后路径的瓶颈
7.         若 nd > best[v]：best[v] = nd，push (nd, v)
8. （R, C ≥ 1 时终点必被弹出，循环必然结束）
```

### 3.4 示例演算

![示例演算：三乘三示例五次弹出拿到答案4](images/bw3_q4_example_walkthrough.svg)

以示例 1 的 $3 \times 3$ 网格为例，堆的完整演化只需 **5 次弹出**：

| 弹出 | 格子 | 瓶颈 $d$ | 松弛动作 |
|------|------|-----------|----------|
| ① | $(0,0)$ | 5 | $(0,1) \to \min(5,4)=4$；$(1,0) \to \min(5,1)=1$ |
| ② | $(0,1)$ | 4 | $(0,2) \to 4$；$(1,1) \to \min(4,2)=2$ |
| ③ | $(0,2)$ | 4 | $(1,2) \to \min(4,6)=4$ |
| ④ | $(1,2)$ | 4 | $(2,2) \to \min(4,6)=4$ |
| ⑤ | $(2,2)$ | 4 | **是终点，返回 4** ✓ |

两个耐人寻味的细节：其一，堆里的 $(1,0)$（key 为 1）、$(1,1)$（key 为 2）**从未弹出**——瓶颈视角自动绕开了那两个「坑」，而朴素的「每步贪心走相邻最大格」在别的数据上会一头栽进低谷（例 3 中从 3 一路奔向 9 的贪心路线会撞上值为 0 的格子，得分瞬间归零）；其二，$(2,0)$、$(2,1)$ 直到算法结束甚至**没有入过堆**——终点弹出即停，堆中剩余全是劣质或过期条目。

## 4. 算法细节

1. **`best` 初值 $-1$**：格值非负，任何真实瓶颈 $\ge 0 > -1$，保证第一次松弛必然生效；若推广到可负格值，应改用「是否已发现」标记或 $-\infty$。
2. **堆条目打包**：`(d, r * C + c)` 压成 `pair<int,int>`，大根堆按 `d` 排序；Python 没有大根堆，取负存入 `heapq`。
3. **过期条目（懒删除）**：`best[v]` 被抬高后旧条目留在堆里，弹出时 `d < best[r][c]` 即跳过——即便不跳过答案也不受影响（旧 key 只会松弛出更小的 `nd`，覆盖不了更大的 `best`），但跳过能省掉无效松弛，也让代码意图更清晰。
4. **终点判定放在过期判定之前**：终点首次弹出的条目必然是它**最大**的 key（终点所有条目都还在堆里，最大堆先弹最大者），返回它即 $D(终点)$（引理 4）。
5. **每格至多入堆 4 次**：`best[v]` 每次被抬高都来自一个不同邻居的弹出，而邻居只有 4 个 → 总堆操作 $O(RC)$。
6. **备选一（二分 + BFS）**：把矩阵所有格值去重排序，二分最大 $x$ 使「只走 $\ge x$ 的格子」BFS 可达终点；判定 $O(RC)$、总 $O(RC\log(RC))$。
7. **备选二（并查集，官方 hint）**：格子按值**降序**逐个激活，与已激活的相邻格合并；两角首次连通时，当前激活值即答案——把 Q3 的「按时间排序加边」换成「按格值排序加格」，一模一样的骨架。

## 5. 正确性证明

以下把相邻四连通的格子看成图 $G$ 的节点，$s = (0,0)$ 为起点、$t = (R-1,C-1)$ 为终点；对任意节点 $v$，定义 $D(v) = \max_{P:\ s \rightsquigarrow v} \ \min_{u \in P} grid[u]$（若把 $D$ 定义在允许重复访问的走法上，结论相同，见引理 1）。

**引理 1（去环不减分）**：任何从 $s$ 到 $t$ 的走法（允许重复访问）都包含一条从 $s$ 到 $t$ 的简单路径，且其最小值 $\ge$ 原走法的最小值。

**证明**：设走法为节点序列 $W = v_0, v_1, \dots, v_L$（$v_0 = s$，$v_L = t$）。若 $W$ 中有节点重复，取最小的 $j$ 使存在 $i < j$ 且 $v_i = v_j$，删除段 $v_{i+1}, \dots, v_j$，得到更短的合法走法 $W'$，且 $W'$ 的节点集是 $W$ 节点集的子集，故 $\min W' \ge \min W$。$W$ 长度有限，重复删除必然终止于一条无重复的走法，即简单路径。于是「简单路径的最大得分」不小于「任意走法的最大得分」，而简单路径本就是走法的子集，两者相等。∎

**引理 2（`best` 不高估）**：任意时刻，`best[v]` 要么是 $-1$，要么等于某条真实 $s \rightsquigarrow v$ 路径的瓶颈值；从而 `best[v]` $\le D(v)$ 恒成立。

**证明**：对 `best[v]` 的赋值历史归纳。首次赋值 `best[s] = grid[s]` 对应单点路径 $s$，瓶颈恰为 $grid[s]$ ✓。每次更新形如 `best[v] ← nd = min(best[u], grid[v])`：由归纳假设 `best[u]` 对应一条真实路径 $P_u$（瓶颈为 `best[u]`），把 $v$ 接在 $P_u$ 末端得到一条 $s \rightsquigarrow v$ 的走法，其瓶颈为 $\min(best[u], grid[v]) = nd$——即使 $v$ 已出现在 $P_u$ 中、走法带环，由引理 1 去环后瓶颈不减，仍有 $D(v) \ge nd$。∎

**引理 3（弹出即最优，交换论证）**：按 `best` 从大到小的顺序弹出节点 $u$ 时，必有 `best[u] = D(u)`。

**证明**：对弹出顺序归纳：假设此前弹出的每个节点 $x$ 都满足 `best[x] = D(x)`（归纳基础：最先弹出的一定是 $s$，`best[s] = D(s)`，因为任何 $s$ 的路径都含 $s$，瓶颈 $\le grid[s]$）。现弹出 `best` 最大的 $u$，反设 `best[u] < D(u)`。取一条取得 $D(u)$ 的路径 $P$（由引理 1 可设其为简单路径），沿 $P$ 从 $s$ 走向 $u$：$s$ 已弹出，故存在**第一个未弹出**的节点 $y \in P$，其前驱 $x \in P$ 已弹出（或 $x = y = s$ 与 $s$ 已弹出矛盾，故 $x \ne y$ 且已弹出）。由归纳假设 `best[x] = D(x)`。$x$ 弹出时曾松弛 $y$（相邻），故 `best[y]` $\ge \min(best[x], grid[y]) = \min(D(x), grid[y])$。而 $P$ 的 $s \rightsquigarrow x$ 前缀最小值 $\ge D(u)$（整条 $P$ 的最小值是 $D(u)$，前缀只多不少），于是 $D(x) \ge D(u)$；又 $grid[y] \ge D(u)$（$y$ 在 $P$ 上）。两者取 $\min$ 得 `best[y]` $\ge D(u) > best[u]$。但 $y$ 已入堆、未弹出，`best` 最大的堆顶却是 $u$，矛盾。∎

**引理 4（终点首弹即最大键）**：终点 $t$ 首次被弹出时，弹出的键值等于当时的 `best[t]`。

**证明**：`best[t]` 每次抬高都同步压入一个同键条目，且从未有任何 $t$ 的条目被弹出（首弹之前），故 $t$ 的全部条目此刻都还在堆中；最大堆弹出当前最大者，弹出的正是 $t$ 曾获得的最大的键，即当前的 `best[t]`。∎

**定理**：算法返回 $D(t)$，即所有简单路径的最大得分。

**证明**：网格有限且四连通，$t$ 必然可达（有限次松弛后入堆并弹出）。由引理 4，$t$ 首次弹出时返回当时的 `best[t]`；由引理 3，弹出时 `best[t] = D(t)`。再由引理 2（`best[t]` $\le D(t)$，结合等号成立）与引理 1（简单路径约束不改变最优值），返回值恰为所求。∎

**补充（二分视角的证明）**：记 $check(x)$ 为「只用值 $\ge x$ 的格子做 BFS，$s$ 可达 $t$」。则 $check(x) = \text{true} \iff D(t) \ge x$：$\Leftarrow$ 取得 $D(t)$ 的路径全由 $\ge D(t) \ge x$ 的格子组成，落在子图中；$\Rightarrow$ 子图中那条 $s$–$t$ 路径的所有格子 $\ge x$，是原图中一条得分 $\ge x$ 的路径。谓词随 $x$ 增大单调转假，二分「最大的可行 $x$」即 $D(t)$，正确性立得。∎

## 6. 复杂度分析

- **时间**：$O(RC \log(RC))$。每格至多入堆 4 次（引理 2 的归纳显示每次抬高来自不同邻居），堆操作 $O(RC)$ 个、每个 $O(\log(RC))$。二分 + BFS 同阶；并查集版本 $O(RC\,\alpha(RC))$ 还能更小。
- **空间**：$O(RC)$。`best` 矩阵与堆；$R, C \le 100$ 时 $RC \le 10^4$，毫无压力。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maximumMinimumPath(vector<vector<int>>& grid) {
        int R = grid.size(), C = grid[0].size();
        vector<vector<int>> best(R, vector<int>(C, -1)); // 到每格的最大瓶颈
        priority_queue<pair<int, int>> pq;               // (瓶颈, r*C+c) 大根堆
        best[0][0] = grid[0][0];
        pq.push({grid[0][0], 0});
        const int dr[4] = {0, 0, 1, -1}, dc[4] = {1, -1, 0, 0};
        while (!pq.empty()) {
            auto [d, rc] = pq.top(); pq.pop();
            int r = rc / C, c = rc % C;
            if (r == R - 1 && c == C - 1) return d;     // 终点首次弹出即最优
            if (d < best[r][c]) continue;               // 过期堆条目
            for (int i = 0; i < 4; ++i) {
                int nr = r + dr[i], nc = c + dc[i];
                if (nr < 0 || nr >= R || nc < 0 || nc >= C) continue;
                int nd = min(d, grid[nr][nc]);          // 瓶颈 = min(路径瓶颈, 新格值)
                if (nd > best[nr][nc]) {
                    best[nr][nc] = nd;
                    pq.push({nd, nr * C + nc});
                }
            }
        }
        return -1;                                      // R, C ≥ 1 时不会到达
    }
};
```

### Python

```python
import heapq


class Solution:
    def maximumMinimumPath(self, grid: list[list[int]]) -> int:
        R, C = len(grid), len(grid[0])
        best = [[-1] * C for _ in range(R)]      # 到每格的最大瓶颈
        heap = [(-grid[0][0], 0, 0)]              # 取负模拟大根堆
        dirs = [(0, 1), (0, -1), (1, 0), (-1, 0)]
        while heap:
            negd, r, c = heapq.heappop(heap)
            d = -negd
            if r == R - 1 and c == C - 1:
                return d                          # 终点首次弹出即最优
            if d < best[r][c]:
                continue                          # 过期堆条目
            for dr, dc in dirs:
                nr, nc = r + dr, c + dc
                if 0 <= nr < R and 0 <= nc < C:
                    nd = min(d, grid[nr][nc])    # 瓶颈 = min(路径瓶颈, 新格值)
                    if nd > best[nr][nc]:
                        best[nr][nc] = nd
                        heapq.heappush(heap, (-nd, nr, nc))
        return -1                                 # R, C ≥ 1 时不会到达
```

> 💡 两份代码均已通过官方全部示例（`4`、`2`、`3`）以及 400+ 组随机小网格与「全简单路径枚举」暴力的对拍验证——对拍同时实证了引理 1（简单路径约束与一般走法等价）。

## 8. 边界情况与易错点

1. **$1 \times 1$ 网格**：起点即终点，直接返回 `grid[0][0]`（代码首次弹出即命中）。
2. **`best` 初值 $-1$ 依赖格值非负**：若允许负格值，改用 `INT_MIN` 并以「是否等于初值」区分未发现，或单独维护 visited。
3. **方向全反**：这是「最大化瓶颈」不是「最小化长度」——堆要**大**根堆、松弛取 `min`、更新条件是 `nd > best`，照抄最短路模板把三个方向写反是最常见翻车点。
4. **过期条目要跳过**：`d < best[r][c]` 时 `continue`；不跳虽不致错（旧键只能松弛出更小的 `nd`），但会浪费堆操作，也容易被后续改动放大成 bug。
5. **答案的上下界**：$min(grid[0][0], grid[R-1][C-1]) \le$ 答案 $\le$ 路径能企及的最大值；答案必是矩阵中出现过的某个格值（二分版本可据此把值域收敛到去重数组）。
6. **只有 4 向移动**，没有对角线；越界判断四个方向都不能少。
7. **贪心走相邻最大格是错的**：瓶颈取决于整条路径的最小值而非局部选择（见 3.4 的例子）；正确的贪心必须是「按瓶颈松弛」。
8. **「不重复访问」是烟雾弹**：不需要在算法里维护 visited 路径集合去强制简单路径——引理 1 已证明这不会改变答案，反而强加约束会把 BFS/并查集路线全盘堵死。
