# LeetCode 叶子相似的树 题解

## 1. 题目概述

- **标题 / 题号**：叶子相似的树（#872，easy）
- **链接**：https://leetcode.cn/problems/leaf-similar-trees/
- **来源**：LeetCode 第 94 场周赛 Q1
- **难度**：简单
- **标签**：树、深度优先搜索、二叉树

**题意**：把一棵二叉树的所有**叶子结点**（没有左右孩子的结点）按**从左到右**的顺序排列，得到的序列称为「叶值序列」。给定两棵二叉树的根 `root1`、`root2`，若它们的叶值序列完全相同则返回 `true`，否则返回 `false`。

**关键点**：

- 只看叶子的**值序列**，不看树的形状——形状完全不同的两棵树也可能叶相似。
- 顺序必须是**从左到右**，这决定了遍历方式（先左后右的 DFS）。
- 叶子序列长度也要相同，长度不同自然不相似。

**约束**：

- 两棵树的结点数都在 $[1, 200]$ 内
- 结点值在 $[0, 200]$ 内

## 2. 示例

**示例 1**

```text
输入：root1 = [3,5,1,6,2,9,8,null,null,7,4]
     root2 = [3,5,1,6,7,4,2,null,null,null,null,null,null,9,8]
输出：true
解释：root1 的叶子从左到右是 6, 7, 4, 9, 8；
     root2 的叶子从左到右也是 6, 7, 4, 9, 8，故叶相似。
```

**示例 2**

```text
输入：root1 = [1,2,3], root2 = [1,3,2]
输出：false
解释：root1 的叶值序列是 [2, 3]，root2 的是 [3, 2]，顺序不同，不相似。
```

**示例 3**（补充，验证形状无关）

```text
输入：root1 = [3,5,1], root2 是一棵形状不同但叶子同为 [5,1] 的树
输出：true
解释：只要叶子值序列一致，树的形状可以任意不同。
```

## 3. 解题思路

### 3.1 暴力思路

「暴力」在这里没有什么可优化的空间：无论怎么做，都必须把两棵树的叶子都看一遍，下界是 $O(n_1 + n_2)$。常见的笨办法有两种：

- **层序遍历后按层筛选**：BFS 得到的叶子顺序是「按层」的，同层的叶子虽然从左到右，但不同层的叶子顺序会被打乱，**直接错**。例如一棵左深右浅的树，BFS 会先收集浅层的叶子。
- **中序遍历收集所有结点再筛叶子**：中序的叶子顺序确实是从左到右，但会遍历所有结点并额外判断「是否为叶子」，比「只在叶子处收集」多做无用功（虽然复杂度同阶）。

所以正解就是「先左后右的 DFS，在叶子处收集」。

### 3.2 核心观察：先左后右的 DFS 天然给出从左到右的叶序

![先序遍历：左子树先入栈，叶子自然从左到右](images/wc94_q1_dfs_leaves.svg)

对二叉树做**先序遍历**（根 → 左 → 右）时，访问到的叶子结点的先后顺序，恰好就是它们在树上从左到右的顺序。原因是：任一叶子 $u$ 在另一叶子 $v$ 的左边，当且仅当 $u$ 所在的子树在某个祖先处是「左分支」而 $v$ 在「右分支」，先序遍历先走左分支，因此 $u$ 先被访问。

于是算法极简：

1. 对 `root1` 做一次先序遍历，遇到叶子就把值追加到列表 `a`。
2. 对 `root2` 做一次先序遍历，得到列表 `b`。
3. 返回 `a == b`。

迭代写法用一个栈：弹出结点时若是叶子就收集，否则**先压右孩子、再压左孩子**（栈是后进先出，左孩子后压就会先弹出，从而实现「先左后右」）。

### 3.3 算法流程

```text
leaves(root):
    res = []，stack = [root]
    while stack 非空：
        node = stack.pop()
        if node.left == null and node.right == null:
            res.append(node.val)
        else:
            if node.right != null: stack.push(node.right)   // 先压右
            if node.left  != null: stack.push(node.left)    // 后压左 → 先访问
    return res

主函数：返回 leaves(root1) == leaves(root2)
```

### 3.4 示例演算

对示例 2 的 `root1 = [1,2,3]`、`root2 = [1,3,2]`（层序建树）：

| 步骤 | 树 1 栈内容（栈顶在右） | 树 1 收集 | 树 2 栈内容 | 树 2 收集 |
|------|----------------------|----------|------------|----------|
| 初始 | `[1]` | — | `[1]` | — |
| 弹出 1 | `[3, 2]` | — | `[2, 3]` | — |
| 弹出 2 | `[3]` | `[2]`（2 是叶子） | `[2]` 弹出 3 | `[3]`（3 是叶子） |
| 弹出 3 | `[]` | `[2, 3]` | `[2]` 弹出 2 | `[3, 2]` |

两者分别为 `[2, 3]` 与 `[3, 2]`，不相等，返回 `false`。这个例子也说明了**顺序敏感**：只要左右顺序不同，结果就不同。

## 4. 算法细节

1. **叶子判定必须是 `!left && !right`**：只有一个孩子的结点**不是**叶子，不能被收集。这是本题最高频的错误。
2. **迭代时先压右再压左**：栈的 LIFO 特性决定了「后压先出」，写反会让叶序整体左右颠倒。
3. **空树情况**：题目保证结点数 $\ge 1$，所以根不会是 `nullptr`。若要做防御性编程，可在入口加 `if (!root) return {};`。
4. **提前剪枝（可选）**：如果一边的叶子数已经超过另一边，可以直接返回 `false`；但对 $n \le 200$ 的规模没有必要，反而增加代码复杂度。
5. **递归深度**：最坏是一条链（深度 $200$），递归不会爆栈；但迭代写法更稳妥，也更容易迁移到「两棵树同时遍历、边遍历边比较」的省空间版本。
6. **值域小**：值在 $[0,200]$，若追求极致可以不开列表比较，而用「双指针同步遍历」两个栈来流式比较，空间 $O(h_1 + h_2)$。

## 5. 正确性证明

**引理 1（先序遍历的叶序 = 从左到右）**：设 $u, v$ 是两个不同的叶子，且 $u$ 在树上位于 $v$ 的左侧（即在中序序列中 $u$ 先于 $v$），则先序遍历先访问 $u$ 再访问 $v$。

**证明**：设 $w$ 是 $u, v$ 的最近公共祖先（存在且唯一）。$u \ne v$ 且 $w$ 不是叶子（它有两个不同子树分别含 $u$、$v$），故 $u$ 在 $w$ 的左子树、$v$ 在 $w$ 的右子树（否则二者在同一侧，$w$ 就不是最近公共祖先）。先序遍历访问 $w$ 后，先完整遍历左子树（含 $u$），再遍历右子树（含 $v$），故 $u$ 先被访问。∎

**引理 2（算法收集的序列正确）**：`leaves(root)` 返回的恰是该树从左到右的叶值序列。

**证明**：算法访问的结点集合与先序遍历一致（栈的压入弹出规则即先序遍历的模拟），只是仅在叶子处记录。由引理 1，叶子的访问顺序即从左到右，因此记录下的值序列正是叶值序列。∎

**定理**：函数返回 `true` $\iff$ 两棵树的叶值序列相同。

**证明**：由引理 2，`a`、`b` 分别是两棵树的叶值序列。列表相等要求长度相同且逐位相同，这正是「叶值序列相同」的定义，故返回值与题意等价。∎

## 6. 复杂度分析

- **时间**：$O(n_1 + n_2)$。每棵树的每个结点恰好入栈、出栈各一次，比较两个列表 $O(\min(|a|,|b|) + 1)$，其中叶子数不超过结点数。
- **空间**：$O(h_1 + h_2 + |a| + |b|)$。栈的深度为树高（最坏 $O(n)$），叶子列表长度不超过结点数；若用「双栈同步遍历」可把列表部分省到 $O(h_1+h_2)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool leafSimilar(TreeNode* root1, TreeNode* root2) {
        vector<int> a, b;
        getLeaves(root1, a);
        getLeaves(root2, b);
        return a == b;
    }
private:
    void getLeaves(TreeNode* node, vector<int>& out) {
        if (!node) return;
        if (!node->left && !node->right) { out.push_back(node->val); return; }
        getLeaves(node->left, out);
        getLeaves(node->right, out);
    }
};
```

### Python

```python
class Solution:
    def leafSimilar(self, root1, root2) -> bool:
        def leaves(root) -> list:
            res, st = [], [root]
            while st:
                node = st.pop()
                if not node.left and not node.right:
                    res.append(node.val)
                else:
                    if node.right:
                        st.append(node.right)     # 先压右
                    if node.left:
                        st.append(node.left)      # 后压左 → 先弹出
            return res

        return leaves(root1) == leaves(root2)
```

## 8. 边界情况与易错点

1. **单孩子结点不是叶子**：`[1,2]` 的叶子是 `[2]`（2 没有孩子）；结点 1 有一个孩子，不算叶子。判定写成 `!node.left || !node.right` 是本題最经典的错。
2. **栈的压入顺序**：必须先 `right` 后 `left`。写反后示例 1 仍可能通过（若两棵树对称地颠倒），但示例 2 会错，很多人的提交就死在这一条。
3. **用 BFS 收集叶子**：层序会把「浅层的叶子」提前，顺序错误。例如示例 2 的两棵树会得到相同的 BFS 叶序，从而误判为 `true`。
4. **两棵树的叶子数量不同**：列表长度不同，`==` 直接返回 `false`，不需要额外判断。
5. **单结点树**：`[1]` 的叶值序列是 `[1]`，两棵都是单结点且值相同则 `true`。
6. **值相同但顺序不同**：如示例 2，值集合一样、顺序不同，必须返回 `false`——所以不能比较排序后的序列。
