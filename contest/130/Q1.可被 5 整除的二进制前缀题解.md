# LeetCode 可被 5 整除的二进制前缀 题解

## 1. 题目概述

- **标题 / 题号**：可被 5 整除的二进制前缀（#1018，easy）
- **链接**：https://leetcode.cn/problems/binary-prefix-divisible-by-5/
- **来源**：LeetCode 第 130 场周赛 Q1
- **难度**：简单
- **标签**：数组、位运算、数学

**题意**：给定只含 `0`/`1` 的数组 `nums`，把前缀 `nums[0..i]` 当成一个二进制数（`nums[0]` 是最高位）得到 $x_i$：

$$x_i = \sum_{j=0}^{i} nums[j] \cdot 2^{\,i-j}$$

返回布尔数组 `answer`，其中 `answer[i]` 为 `true` 当且仅当 $x_i$ 能被 $5$ 整除。

**约束**：

- $1 \le nums.length \le 10^5$
- $nums[i]$ 仅为 $0$ 或 $1$

> 💡 本题的本质是「**超长整数的模 5 判定**」。$x_i$ 最多有 $10^5$ 个二进制位（约 $3 \times 10^4$ 位十进制），任何定长整数类型都装不下，唯一出路是只保留**余数**。

## 2. 示例

**示例 1**

```text
输入：nums = [0,1,1]
输出：[true,false,false]
解释：前缀对应的数字依次为 0, 01, 011，即十进制 0, 1, 3。
      只有 0 能被 5 整除，故 answer[0] = true，其余为 false。
```

**示例 2**

```text
输入：nums = [1,1,1]
输出：[false,false,false]
解释：前缀为 1, 3, 7，都不能被 5 整除。
```

**示例 3（自造，覆盖前导零）**

```text
输入：nums = [0,0,1,1]
输出：[true,true,false,false]
解释：前缀为 0, 00, 001, 0011，即 0, 0, 1, 3。
      前两个前缀的数值都是 0，0 能被 5 整除。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的做法：对每个 $i$ 重新把 `nums[0..i]` 拼成二进制串、转成十进制，再判 `% 5 == 0`。

- 用 C++ 的 `long long`：$10^5$ 位二进制数远超 $2^{63}$，**直接溢出**，结果不可信。
- 用 Python 的大整数：能算，但第 $i$ 个前缀要花 $O(i)$ 位运算，总计 $O(n^2)$ 位复杂度，$n = 10^5$ 时不可接受。

所以暴力要么错、要么慢，必须换思路。

### 3.2 核心观察：只需传递「余数」，不传递「数值」

![模 5 不变量：只保留余数，容量恒定为 5 个状态](images/wc130_q1_mod_invariant.svg)

注意相邻前缀之间的关系是**递推**而不是重新计算：

$$x_i = 2 \cdot x_{i-1} + nums[i], \qquad x_0 = nums[0]$$

而取模对加法和乘法都保持同态（$m = 5$）：

$$(a \cdot b + c) \bmod m = \bigl((a \bmod m)\cdot(b \bmod m) + (c \bmod m)\bigr) \bmod m$$

于是设 $r_i = x_i \bmod 5 \in \{0,1,2,3,4\}$，就有

$$r_i = (2 \cdot r_{i-1} + nums[i]) \bmod 5$$

**关键结论**：$x_i$ 是否能被 5 整除，只取决于 $r_i$ 是否为 0；而 $r_i$ 只依赖 $r_{i-1}$ 与当前位 $nums[i]$。状态空间只有 5 个数，永远不会溢出。

> 💡 这是一个典型的「**把大对象折叠成等价小状态**」的技巧：只要目标函数（这里是 `% 5`）对递推运算同态，就不必保留原对象。

### 3.3 算法流程

![算法流程：一次线性扫描，边读边取模](images/wc130_q1_flow.svg)

```text
1. cur = 0, answer = []
2. for i = 0 .. n-1:
       cur = (cur * 2 + nums[i]) % 5
       answer 追加 (cur == 0)
3. 返回 answer
```

第 3.2 节写出的是理论递推，代码里把「$x_0 = nums[0]$」也统一进循环：`cur` 初值为 0，首位进入后 `cur = nums[0]`，与定义一致。

### 3.4 示例演算

![示例演算：三个前缀的余数轨迹](images/wc130_q1_walkthrough.svg)

对 `nums = [0,1,1]`：

| $i$ | $nums[i]$ | 计算式 | $r_i$ | $x_i$ | 能被 5 整除 |
|---|---|---|---|---|---|
| 0 | 0 | $(0 \times 2 + 0) \bmod 5$ | 0 | 0 | ✓ |
| 1 | 1 | $(0 \times 2 + 1) \bmod 5$ | 1 | 1 | ✗ |
| 2 | 1 | $(1 \times 2 + 1) \bmod 5$ | 3 | 3 | ✗ |

对 `nums = [1,1,1]`：余数依次为 $1 \to 3 \to 7 \bmod 5 = 2$，对应数值 $1, 3, 7$，三个都不是 5 的倍数，输出 `[false,false,false]` ✓。

## 4. 算法细节

1. **取模基数固定为 5**：判定条件是「被 5 整除」，所以余数状态取 $\{0,1,2,3,4\}$ 即可；若题目改成「被 $k$ 整除」，把 5 换成 $k$ 同样成立。
2. **`cur * 2 + nums[i]` 不会溢出**：`cur ∈ [0,4]`、`nums[i] ∈ {0,1}`，中间结果最大 $9$，用 `int` 足够。改写前若用 `int` 存完整数值，$i \ge 31$ 就已经溢出了。
3. **边扫边判**：判断 `cur == 0` 必须在**更新之后**做，否则会把上一个前缀的结论推到当前位。
4. **返回类型是 `vector<bool>`**：C++ 的 `vector<bool>` 是位压缩特化，`push_back(bool)` 语义正常；不要为了「省位」换成 `vector<char>`（没必要，且接口类型不符）。
5. **不要用「末位是 0 或 5」判十进制整除**：这是十进制规则，二进制前缀没有这个性质，必须走取模。

## 5. 正确性证明

记 $r_i = x_i \bmod 5$，`cur_i` 为算法第 $i$ 轮循环结束后的变量值。

**引理 1（递推同态）**：对任意 $i \ge 1$，$x_i = 2 x_{i-1} + nums[i]$。

**证明**：由定义

$$x_i = \sum_{j=0}^{i} nums[j] 2^{i-j} = 2 \sum_{j=0}^{i-1} nums[j] 2^{i-1-j} + nums[i] = 2 x_{i-1} + nums[i]$$

其中第二个等号把 $j \le i-1$ 的每一项的指数 $i-j$ 拆成 $(i-1-j)+1$。直观上，这就是「把 `nums[0..i-1]` 的二进制串左移一位（乘 2），末位补上 $nums[i]$」。∎

**引理 2（取模保持递推）**：$r_i = (2 r_{i-1} + nums[i]) \bmod 5$。

**证明**：由引理 1，$r_i = (2x_{i-1} + nums[i]) \bmod 5$。因 $2 x_{i-1} \equiv 2 r_{i-1} \pmod 5$（同余对乘法封闭），故 $2x_{i-1} + nums[i] \equiv 2r_{i-1} + nums[i] \pmod 5$，两边取最小非负剩余即得。∎

**引理 3（循环不变式）**：每轮循环结束时 `cur` $= r_i$。

**证明**：对 $i$ 归纳。$i = 0$ 时循环体执行 `cur = (0 * 2 + nums[0]) % 5 = nums[0] % 5 = r_0`。设第 $i-1$ 轮结束 `cur` $= r_{i-1}$，则第 $i$ 轮执行 `cur = (r_{i-1} * 2 + nums[i]) % 5`，由引理 2 等于 $r_i$。∎

**定理**：算法输出的 `answer[i]` 为 `true` 当且仅当 $x_i$ 能被 5 整除。

**证明**：由引理 3，第 $i$ 轮追加的布尔值为 `cur == 0`，即 $r_i = 0$，即 $x_i \bmod 5 = 0$，即 $5 \mid x_i$。∎

## 6. 复杂度分析

- **时间**：$O(n)$。每个元素做一次乘加、一次取模、一次比较，均为 $O(1)$ 常数运算，与数值大小无关。
- **空间**：$O(1)$ 额外空间（不计输出数组）；只维护 `cur` 一个整数。
- **对比**：暴力（重算前缀）为 $O(n^2)$ 位运算，且 C++ 定长整数会溢出。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<bool> prefixesDivBy5(vector<int>& nums) {
        vector<bool> ans;
        int cur = 0;                       // cur = x_i mod 5，恒在 [0,4]
        for (int x : nums) {
            cur = (cur * 2 + x) % 5;       // 递推：x_i = 2*x_{i-1} + nums[i]
            ans.push_back(cur == 0);
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def prefixesDivBy5(self, nums: list[int]) -> list[bool]:
        ans = []
        cur = 0                             # cur = x_i mod 5，恒在 [0,4]
        for x in nums:
            cur = (cur * 2 + x) % 5
            ans.append(cur == 0)
        return ans
```

## 8. 边界情况与易错点

1. **溢出**：这是本题第一大坑。$n = 10^5$ 时完整数值有 $10^5$ 个二进制位，`int`（31 位）、`long long`（63 位）都会溢出，必须只保留余数。
2. **前导零**：`nums` 以 0 开头时，数值仍是 0，`0 % 5 == 0`，所以输出 `true`（示例 3）。不要因为「二进制串看着不像数」就特判掉。
3. **全 0 数组**：每个前缀都是 0，答案全 `true`。
4. **判定时机**：先更新 `cur` 再比较，否则答案整体错位一位。
5. **返回类型**：题面要求 `list<boolean>`，C++ 写 `vector<bool>`（不是 `vector<char>`、也不是 `string`）。
6. **空数组**：约束保证 $n \ge 1$，但即使为空，循环不执行、返回空数组也是正确的。
