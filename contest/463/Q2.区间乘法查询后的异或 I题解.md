# LeetCode 区间乘法查询后的异或 I 题解

## 1. 题目概述

- **标题 / 题号**：区间乘法查询后的异或 I（#3653，medium）
- **链接**：https://leetcode.cn/problems/xor-after-range-multiplication-queries-i/
- **来源**：LeetCode 第 463 场周赛 Q2
- **难度**：中等
- **标签**：数组、模拟

**题意**：给定长度为 $n$ 的整数数组 `nums` 与 $q$ 个查询。每个查询 $[l, r, k, v]$ 的执行流程：令 $\text{idx} = l$；只要 $\text{idx} \le r$，就执行 $\text{nums}[\text{idx}] \leftarrow \text{nums}[\text{idx}] \times v \bmod (10^9 + 7)$，然后 $\text{idx} \gets \text{idx} + k$。所有查询**依次**执行完毕后，返回数组全体元素的**按位异或**。

**约束**：

- $1 \le n = \text{nums.length} \le 10^3$
- $1 \le \text{nums}[i] \le 10^9$
- $1 \le q = \text{queries.length} \le 10^3$
- $0 \le l_i \le r_i < n$，$1 \le k_i \le n$，$1 \le v_i \le 10^5$

> 💡 **赛时快速切入**：数据范围是本题最大的"提示"——先估**操作总量**：单次查询至多摸 $\lceil n/k \rceil \le n$ 个下标，最坏总计 $q \cdot n \le 10^6$，**直接模拟就是正解**。真正的坑只有两个：**读对题**（是步长跳跃，不是连续区间整段乘）和**别溢出**（C++ 中间乘积约 $10^{14}$，要 64 位）。

## 2. 示例

**示例 1**

```text
输入：nums = [1,1,1], queries = [[0,2,1,4]]
输出：4
解释：k = 1，退化为连续区间：[1,1,1] → [4,4,4]，
      4 ^ 4 ^ 4 = 4。
```

**示例 2**

```text
输入：nums = [2,3,1,5,4], queries = [[1,4,2,3],[0,2,1,2]]
输出：31
解释：查询① [1,4,2,3]：k = 2，只摸下标 1、3 → [2,9,1,15,4]
      查询② [0,2,1,2]：k = 1，摸下标 0、1、2  → [4,18,2,15,4]
      4 ^ 18 ^ 2 ^ 15 ^ 4 = 31。
```

## 3. 解题思路

### 3.1 暴力思路：按题意逐步模拟

把每个查询原样执行：$\text{idx}$ 从 $l$ 出发，每轮「乘 $v$、取模、$+k$」，越过 $r$ 即止；所有查询跑完后把数组异或。关键是**估算操作总量**——查询 $[l, r, k, v]$ 摸到的下标为 $l, l+k, l+2k, \dots$，共

$$\left\lfloor \frac{r - l}{k} \right\rfloor + 1 \ \le\ \left\lceil \frac{n}{k} \right\rceil \ \le\ n \quad (k \ge 1)$$

个，于是最坏总操作数

$$T \le \sum_{i=1}^{q} \left( \left\lfloor \frac{r_i - l_i}{k_i} \right\rfloor + 1 \right) \le q \cdot n = 10^3 \times 10^3 = 10^6,$$

每步只是一次 64 位乘法加一次取模。$10^6$ 量级的运算远低于时限——**暴力模拟即为正解**，不需要任何数据结构。

### 3.2 核心观察：等差跳跃 + 模乘可交换

![核心观察：查询以步长 k 跳跃，只摸等差数列上的下标](images/xor_mul_stride_jump.svg)

**观察一（跳跃式修改）**：查询 $[l, r, k, v]$ **不是**把 $[l, r]$ 内所有元素都乘 $v$，只修改等差数列链 $l, l+k, l+2k, \dots$ 上不超过 $r$ 的位置。$k = 1$ 才退化为连续区间（示例 1）；$k \ge 2$ 时区间内其余元素**原封不动**——示例 2 的查询①覆盖 $[1,4]$，却没碰 $\text{nums}[2]$。把题读成"整段区间乘"是本题头号 WA 来源。

**观察二（模乘交换律 ⇒ 顺序无关）**：每条查询对每个被摸下标只做「乘 $v_i$ 再取模」。由模乘法的**交换律与结合律**，下标 $j$ 的最终值只取决于**覆盖它的查询的 $v$ 之积**：

$$\text{nums}_{\text{final}}[j] \equiv \text{nums}_0[j] \times \prod_{i:\, j \in S_i} v_i \pmod{10^9 + 7},$$

与查询执行顺序无关（证明见 §5）。这既说明"按给定顺序模拟"的结果唯一正确，也为 II 版的**离线批量处理**埋下伏笔。

**观察三（数据范围即算法信号）**：$n, q \le 10^3$ 是出题人放出的"可模拟"信号；同场 Q4（Hard）把两者放大到 $10^5$，逐步模拟立刻爆炸。**先算操作总量、再定算法**，是周赛读完题后的第一反射。

### 3.3 算法流程

![算法流程：逐查询跳跃模拟，最后整体异或](images/xor_mul_simulation_flow.svg)

| 步骤 | 操作 | 说明 |
|------|------|------|
| ① 取查询 | 读 $[l, r, k, v]$，置 $\text{idx} = l$ | 按输入顺序依次处理 |
| ② 判断 | $\text{idx} \le r$？ | 否则本查询结束，取下一条 |
| ③ 乘模 | $\text{nums}[\text{idx}] \leftarrow \text{nums}[\text{idx}] \times v \bmod (10^9+7)$ | C++ 中间乘积用 64 位 |
| ④ 跳跃 | $\text{idx} \gets \text{idx} + k$ | $k \ge 1$，循环必终止 |
| ⑤ 异或 | $\text{ans} \leftarrow \bigoplus_i \text{nums}[i]$ | 全部查询做完后统一执行一次 |

### 3.4 示例演算

![示例2演算：两步查询后的数组与最终异或](images/xor_mul_example_walkthrough.svg)

**示例 2**（答案 31）：

| 阶段 | 摸到的下标 | 数组变化 |
|------|-----------|----------|
| 初始 | — | $[2, 3, 1, 5, 4]$ |
| 查询① $[1,4,2,3]$ | $1, 3$（步长 2，下一个 $5 > 4$ 停） | $[2, \mathbf{9}, 1, \mathbf{15}, 4]$ |
| 查询② $[0,2,1,2]$ | $0, 1, 2$（步长 1，连续段） | $[\mathbf{4}, \mathbf{18}, \mathbf{2}, 15, 4]$ |

最终 $\text{ans} = 4 \oplus 18 \oplus 2 \oplus 15 \oplus 4 = 31$（二进制 $11111$）。注意 $\text{nums}[2]$ 只被查询②乘过一次——查询①虽然"覆盖"它，却跳过了它。

## 4. 算法细节

1. **循环写法**：内层 `for (int idx = l; idx <= r; idx += k)` 一行表达「起点、步长、含端点上界」。条件是 `<=` 而非 `<`：$r$ 本身在链上时必须被乘。
2. **取模时机**：每次乘完立即 `% MOD`，保证任意时刻 $\text{nums}[\text{idx}] < 10^9 + 7$。初始 $\text{nums}[i] \le 10^9 < \text{MOD}$，天然落在模域内，无需预处理。
3. **64 位中间积**：$\text{nums}[\text{idx}] < 10^9 + 7$、$v \le 10^5$，乘积上界 $\approx 10^{14} < 2^{47}$——超 `int`、在 `long long` 内。C++ 必须写 `(long long)nums[idx] * v % MOD`。
4. **异或收尾**：`ans` 从 $0$ 起逐个 `^= nums[i]`，对**取模后的最终值**做；结果 $< 2^{31}$，`int` 足够。
5. **顺序随意、按序最省事**：由 §3.2 观察二，任意执行顺序结果相同，按输入顺序模拟即可，无需排序或离线。

## 5. 正确性证明

**引理 1（单查询的影响集合）**：查询 $[l, r, k, v]$ 恰好把集合 $S = \{\, l + jk \mid j \ge 0,\ l + jk \le r \,\}$ 中每个下标的值替换为「原值乘 $v$ 再对 $p = 10^9 + 7$ 取模」，每个下标恰被乘一次；$S$ 之外的下标不变。

**证明**：模拟循环从 $\text{idx} = l$ 出发，每轮先乘法取模、再 $\text{idx} \gets \text{idx} + k$，故被访问的下标依次为 $l, l+k, l+2k, \dots$；循环条件 $\text{idx} \le r$ 等价于 $l + jk \le r$，即恰好访问 $S$ 中全部元素、各一次。$k \ge 1$ 保证 $j$ 有上界 $\lfloor (r-l)/k \rfloor$，循环必然终止。∎

**引理 2（顺序无关性）**：设 $I_j = \{\, i \mid j \in S_i \,\}$ 为覆盖下标 $j$ 的查询集合，则无论查询按何种顺序执行，恒有

$$\text{nums}_{\text{final}}[j] \equiv \text{nums}_0[j] \times \prod_{i \in I_j} v_i \pmod p.$$

**证明**：对固定 $j$，各查询依次作用映射 $x \mapsto x \cdot v_i \bmod p$（$i \in I_j$）。模 $p$ 的剩余类上乘法满足结合律与交换律，故这些映射的复合等于 $x \mapsto x \cdot \prod_{i \in I_j} v_i \bmod p$，与作用次序无关；$I_j$ 之外的查询不触碰 $j$（引理 1）。∎

**定理**：按题目给定顺序对每个查询执行 §3.3 的模拟，最后对数组全体取异或，所得即为所求答案。

**证明**：由引理 1，模拟忠实实现每条查询的语义；由引理 2，给定顺序执行后每个下标取得唯一确定的最终值 $\text{nums}_{\text{final}}[j]$。程序输出 $\bigoplus_{j=0}^{n-1} \text{nums}_{\text{final}}[j]$，与题目定义的返回值一致。∎

## 6. 复杂度分析

- **时间复杂度**：$O(q \cdot n + n)$。所有查询的跳跃步数之和 $\sum_i \left( \lfloor (r_i - l_i) / k_i \rfloor + 1 \right) \le q \cdot n \le 10^6$，每步一次乘法一次取模；收尾异或一趟 $O(n)$。
- **空间复杂度**：$O(1)$ 额外空间——原地修改 `nums`，答案只需一个变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int xorAfterQueries(vector<int>& nums, vector<vector<int>>& queries) {
        const long long MOD = 1'000'000'007LL;
        for (const auto& q : queries) {
            int l = q[0], r = q[1], k = q[2];
            long long v = q[3];
            for (int idx = l; idx <= r; idx += k) {                 // 等差跳跃：l, l+k, l+2k, …, ≤ r
                nums[idx] = (int)((long long)nums[idx] * v % MOD);  // 中间乘积约 10^14，必须 64 位
            }
        }
        int ans = 0;
        for (int x : nums) ans ^= x;                                // 异或的是取模后的最终值
        return ans;
    }
};
```

### Python

```python
class Solution:
    def xorAfterQueries(self, nums: List[int], queries: List[List[int]]) -> int:
        MOD = 10 ** 9 + 7
        for l, r, k, v in queries:
            for idx in range(l, r + 1, k):      # range 天然支持步长跳跃
                nums[idx] = nums[idx] * v % MOD
        ans = 0
        for x in nums:
            ans ^= x
        return ans
```

## 8. 边界情况与易错点

1. **读题：是跳跃不是整段**：查询 $[l, r, k, v]$ 只摸 $l, l+k, \dots$。把"覆盖 $[l, r]$ 的所有元素都乘 $v$"是头号错误，用示例 2 自检——查询①执行后 $\text{nums}[2]$ 必须仍是 $1$。
2. **C++ 溢出**：`int` × `int` 中间积约 $10^{14}$ 直接溢出，必须显式转 `long long`；Python 无此问题。
3. **异或对象**：对**每次乘法都取模后的最终数组**做异或，不是原数组、也不是"不取模的乘积"。
4. **循环含端点**：`idx <= r`，$r$ 在链上时也要乘；写成 `<` 会漏掉恰好落在 $r$ 的位置。
5. **$k > r - l$ 或 $l = r$**：只乘 $\text{nums}[l]$ 一个位置，循环天然只跑一轮，无需特判。
6. **$v = 1$**：相当于空操作，照常执行不影响正确性。
7. **终止性**：$k \ge 1$ 由题目保证，不存在死循环；若题面允许 $k = 0$ 才需特判（本题不需要）。
8. **模数**：$10^9 + 7$，别手滑写成 $998244353$ 或 $10^9 + 9$。
