# LeetCode 单调数组对的数目 I 题解

## 1. 题目概述

- **标题 / 题号**：单调数组对的数目 I（#3250，hard）
- **链接**：https://leetcode.cn/problems/find-the-count-of-monotonic-pairs-i/
- **来源**：LeetCode 第 410 场周赛 Q3
- **难度**：困难
- **标签**：数组、动态规划、前缀和、组合数学

**题意**：给定长度为 $n$ 的**正**整数数组 $nums$，数出有多少对长度同为 $n$ 的**非负**整数数组 $(arr1, arr2)$ 满足：

- $arr1$ 单调**非递减**：$arr1[0] \le arr1[1] \le \dots \le arr1[n-1]$；
- $arr2$ 单调**非递增**：$arr2[0] \ge arr2[1] \ge \dots \ge arr2[n-1]$；
- 逐位和锁定：$arr1[i] + arr2[i] = nums[i]$ 对所有 $0 \le i \le n-1$ 成立。

答案对 $10^9 + 7$ 取模后返回。

**约束**：

- $1 \le n = nums.length \le 2000$
- $1 \le nums[i] \le 50$

> 💡 **读题三连**：① 逐位和把 $arr2$ 钉死为 $nums[i] - arr1[i]$——**arr2 没有自由度**，问题坍缩成单序列计数；② 两条单调性方向相反，但都只约束**相邻两位**，是逐位局部条件，天然适合 DP；③ $nums[i] \le 50$ 的极小值域 + 计数取模，是标准的**值域 DP 计数**信号。本场 Q3 直接标困难、Q4 是值域放大到 1000 的姊妹题，这道题正是分场胜负的手筋。

## 2. 示例

**示例 1**

```text
输入：nums = [2,3,2]
输出：4
解释：全部单调数组对为
      ([0, 1, 1], [2, 2, 1])
      ([0, 1, 2], [2, 2, 0])
      ([0, 2, 2], [2, 1, 0])
      ([1, 2, 2], [1, 1, 0])
```

**示例 2**

```text
输入：nums = [5,5,5,5]
输出：126
```

**示例 3（边界：$n = 1$）**

```text
输入：nums = [1]
输出：2
解释：单元素数组的两条单调性均空真成立，逐位和 1 拆成 (0,1)、(1,0) 两对。
```

## 3. 解题思路

### 3.1 暴力思路：逐位枚举 arr1

由读题观察 ①，只需枚举 $arr1$：每位在 $[0, nums[i]]$ 中取值，$arr2$ 随之确定，DFS 边填边校验两条单调性，填满 $n$ 位计数 $+1$。最坏组合数 $\prod_i (nums[i] + 1) \le 51^{2000}$，指数爆炸，剪枝救不了状态空间本身。

退一步的**朴素 DP** 是把「前 $i$ 位、末位填 $s$」当状态、转移时枚举前一位 $t$：$O(n \cdot V^2)$，$V = 50$ 时约 $5 \times 10^6$，本题勉强能过；但同场 Q4 把值域放大到 $1000$，同样的做法变成 $2 \times 10^9$ 直接超时。周赛里看到 I/II 姊妹结构，应当**一步到位**写出 $O(n \cdot V)$。

### 3.2 核心观察：arr1 定则 arr2 定，双单调坍缩成一条上界

![核心观察：分界线视角与约束合并](images/wc410_q3_band_concept.svg)

把每个 $nums[i]$ 画成一根柱子，蓝色（$arr1$）从底部垫起、橙色（$arr2$）盖在顶上，**蓝橙分界线的高度就是 $arr1[i]$**。记 $s = arr1[i]$，$t = arr1[i-1]$，$\Delta = nums[i] - nums[i-1]$（$nums$ 的抬升量），两条单调性逐条翻译：

- $arr1$ 非减 $\iff t \le s$；
- $arr2$ 非增 $\iff nums[i] - s \le nums[i-1] - t \iff t \le s - \Delta$；
- 合并：$t \le \min(s,\ s - \Delta)$。

两条约束**方向相同**——都是对前一位取值的**单侧上界**，没有下界！几何直觉（见上图）：分界线只能不降；且 $nums$ 抬升 $\Delta > 0$ 时分界线必须至少跟着抬 $\Delta$——$nums$ 涨得越快，可行带被挤压得越窄。示例 1 中 $i = 1$ 处 $s = 0$ 的死路正是这个挤压：$nums$ 从 2 涨到 3，$arr1$ 停在 0 意味着 $arr2$ 要从 2 涨到 3，违反非增。

「只有上界、没有下界」意味着**前一位的值越小越安全**，转移窗口恒为前缀 $[0, t_{\max}]$——这正是前缀和最舒服的形态；更有趣的是 $s$ 每加 1，$t_{\max}$ 恰好加 1，滑窗匀速右移。

### 3.3 算法流程：值域 DP + 前缀和 + 滚动数组

![算法流程：逐位滚动，前缀和 O(1) 转移](images/wc410_q3_dp_flow.svg)

定义 $dp[i][s]$ = 填好前 $i+1$ 位、且 $arr1[i] = s$ 的合法 $arr1$ 个数：

- **初始**：$dp[0][s] = 1$（$0 \le s \le nums[0]$）——首位无前驱，任取；
- **转移**：$dp[i][s] = \sum_{t=0}^{t_{\max}} dp[i-1][t]$，其中 $t_{\max} = \min(s, s - \Delta)$，$t_{\max} < 0$ 时该状态死亡、值为 0；
- **答案**：$\sum_{s=0}^{nums[n-1]} dp[n-1][s]$。

实现上对**上一层**预处理前缀和 $pre[k] = \sum_{t < k} dp[i-1][t]$，每个状态一次 $O(1)$ 查询 $pre[t_{\max}+1]$；转移只读上一层、写本层，两组数组交替滚动。

### 3.4 示例演算

![示例 1 的三层 dp 走查](images/wc410_q3_example_walkthrough.svg)

以 $nums = [2,3,2]$ 走一遍（见上图表）：

| $i$ | $\Delta$ | $t_{\max}$ 规则 | $dp$ 行（$s = 0, 1, 2, 3$） |
|-----|----------|-----------------|------------------------------|
| 0 | — | — | $1, 1, 1, -$（$s \le 2$） |
| 1 | $+1$ | $s - 1$（③ 更紧） | $0, 1, 2, 3$ |
| 2 | $-1$ | $s$（② 主导） | $0, 1, 3, -$（$s \le 2$） |

$i = 1$ 这轮最能看清挤压：$\Delta = +1$ 把窗口整体压低一位，$s = 0$ 时 $t_{\max} = -1$，状态直接死亡；而 $s = 3$ 恰好收下整层前缀和 $1 + 1 + 1 = 3$。末层求和 $0 + 1 + 3 = 4$，与示例给出的四个数组对一一对应（末位 $s = 1$ 一种、$s = 2$ 三种，见上图右表）。顺带一提，$[5,5,5,5]$ 算出 126，恰好是隔板数 $\binom{9}{4}$——这个彩蛋见「相关题目与扩展」。

## 4. 算法细节

1. **状态开在值上**：$nums[i] \le 50$，第二维只需 $V + 1$（$V = \max(nums)$），与 $n$ 无关。$V$ 动态取自输入，同一份代码**原样能过 Q4（#3251，值域 1000）**。
2. **前缀和的下标偏移**：$pre$ 开到 $V + 2$ 长，查询统一写 $pre[t_{\max} + 1]$ 表示「$t < t_{\max} + 1$ 即 $t \le t_{\max}$」；先判 $t_{\max} \ge 0$ 再查，避免负下标。
3. **$s$ 的枚举上界**：每层只枚举 $s \le nums[i]$。上界来自 $arr2[i] = nums[i] - s \ge 0$——不是优化，是**合法性本身**；$arr1[i] \ge 0$ 由枚举起点 0 保证。
4. **滚动**：`swap(dp, ndp)` 后 `ndp` 整层作废（下一轮先清零再写），两层交替，空间 $O(V)$。
5. **全程取模**：每个中间值加减后立即 `% MOD`，C++ 用 `long long` 承接加法防溢出；模加法对计数归纳封闭（见 §5 定理末注）。
6. **首末层的特殊性**：首位无前驱（没有相邻约束）、末位无后继（不约束别人），所以初始化是「一段全 1」、收尾是「整层求和」，只有中间位受双约束夹击。

## 5. 正确性证明

**引理 1**（影子引理）：合法单调数组对 $(arr1, arr2)$ 与满足条件组 (C) 的序列 $arr1$ 一一对应，其中：

- (C1) 对所有 $i$：$0 \le arr1[i] \le nums[i]$；
- (C2) 对所有 $1 \le i \le n-1$：$arr1[i-1] \le arr1[i]$ 且 $nums[i] - arr1[i] \le nums[i-1] - arr1[i-1]$。

**证明**：正向，设 $(arr1, arr2)$ 合法。两数组非负且逐位和为 $nums[i]$，故 $arr1[i] \ge 0$、$arr2[i] = nums[i] - arr1[i] \ge 0$，即 (C1)；$arr1$ 非减即 (C2) 前半，$arr2$ 非增逐位展开即 (C2) 后半。反向，设 $arr1$ 满足 (C)，令 $arr2[i] = nums[i] - arr1[i]$。由 (C1)，$arr2[i] \ge 0$，两数组均非负；长度与逐位和显然；(C2) 前半即 $arr1$ 非减，后半即 $arr2$ 非增，故 $(arr1, arr2)$ 合法。又因逐位和把 $arr2$ 唯一确定，映射 $arr1 \mapsto (arr1, arr2)$ 是单射；每个合法对都由其 $arr1$ 经该映射产生，故为双射。∎

**引理 2**（约束合并）：记 $s = arr1[i]$，$t = arr1[i-1]$，$\Delta = nums[i] - nums[i-1]$，则 (C2) $\iff t \le \min(s, s - \Delta)$。

**证明**：(C2) 前半即 $t \le s$；后半移项：$nums[i] - s \le nums[i-1] - t \iff t \le nums[i-1] - nums[i] + s = s - \Delta$。两个上界同时成立当且仅当 $t$ 不超过二者较小值。∎

**定理**：算法返回值等于单调数组对的个数（模 $10^9 + 7$ 意义下）。

**证明**：对 $i$ 归纳断言：$dp[i][s]$ 等于「满足 (C) 的前缀 $arr1[0..i]$ 且 $arr1[i] = s$」的个数（模意义下）。$i = 0$：(C) 退化为 $0 \le s \le nums[0]$，每个 $s$ 恰一个序列，$dp[0][s] = 1$ 成立。设第 $i - 1$ 层断言成立。考虑末位为 $s$ 的合法前缀，去掉第 $i$ 位后是末位为 $t$ 的合法前缀（(C) 中不涉及第 $i$ 位的条件全部保留），且由引理 2，相邻两位须满足 $t \le \min(s, s - \Delta)$；反之，任取满足该上界的合法前缀（末位 $t$）拼接 $s$（要求 $0 \le s \le nums[i]$，恰为枚举范围），由引理 2 拼接结果仍满足 (C)。这给出了两边集合的双射（按第 $i - 1$ 位的取值分类，各类互斥且穷尽），故 $dp[i][s] = \sum_{t \le t_{\max}} dp[i-1][t]$，与代码的前缀和查询一致。由引理 1，末层求和即数组对总数。取模只影响数值表示：同余对加法封闭，归纳可知每层 $dp$ 值 $\equiv$ 真实计数 $\pmod{10^9 + 7}$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \cdot V)$，$V = \max(nums) \le 50$。每轮先 $O(V)$ 算上一层前缀和，再 $O(V)$ 完成本层转移，共 $n - 1$ 轮，总量 $\approx 2000 \times 51 \approx 10^5$，毫秒级。
- **空间复杂度**：$O(V)$。滚动数组只保留上一层与前缀和，与 $n$ 无关。
- **对照**：朴素 DP $O(n \cdot V^2) = 5 \times 10^6$ 本题可过但 Q4（$V = 1000$）为 $2 \times 10^9$ 超时；DFS 枚举 $O(51^n)$ 完全不可行。前缀和优化从「锦上添花」变「生死线」正是 I/II 姊妹题的出题意图。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int countOfPairs(vector<int>& nums) {
        const int MOD = 1'000'000'007;
        const int V = *max_element(nums.begin(), nums.end());
        vector<long long> dp(V + 1), ndp(V + 1), pre(V + 2);
        for (int s = 0; s <= nums[0]; ++s) dp[s] = 1;          // 首位任取
        for (int i = 1; i < (int)nums.size(); ++i) {
            for (int s = 0; s <= V; ++s)                       // 上一层前缀和
                pre[s + 1] = (pre[s] + dp[s]) % MOD;
            const int delta = nums[i] - nums[i - 1];
            fill(ndp.begin(), ndp.end(), 0);
            for (int s = 0; s <= nums[i]; ++s) {               // s ≤ nums[i]：arr2 非负
                const int tmax = min(s, s - delta);            // 双约束合并的上界
                if (tmax >= 0) ndp[s] = pre[tmax + 1];         // 窗口恒为 [0, tmax]
            }
            dp.swap(ndp);                                      // 滚动
        }
        long long ans = 0;
        for (int s = 0; s <= nums.back(); ++s) ans = (ans + dp[s]) % MOD;
        return (int)ans;
    }
};
```

### Python

```python
class Solution:
    def countOfPairs(self, nums: List[int]) -> int:
        MOD = 10 ** 9 + 7
        V = max(nums)
        dp = [1] * (nums[0] + 1) + [0] * (V - nums[0])          # 首位任取
        for i in range(1, len(nums)):
            pre = [0] * (V + 2)                                 # 上一层前缀和
            for s in range(V + 1):
                pre[s + 1] = (pre[s] + dp[s]) % MOD
            delta = nums[i] - nums[i - 1]
            ndp = [0] * (V + 1)
            for s in range(nums[i] + 1):                        # s ≤ nums[i]：arr2 非负
                tmax = min(s, s - delta)                        # 双约束合并的上界
                if tmax >= 0:
                    ndp[s] = pre[tmax + 1]                      # 窗口恒为 [0, tmax]
            dp = ndp                                            # 滚动
        return sum(dp[: nums[-1] + 1]) % MOD
```

## 8. 边界情况与易错点

1. **$n = 1$**：主循环不执行，直接返回 $nums[0] + 1$（单元素数组两条单调性均空真，逐位和 $k$ 有 $k + 1$ 种拆法）。代码无需特判，但要在心里过一遍。
2. **忘掉 $s \le nums[i]$ 的上界**：它来自 $arr2[i] \ge 0$，漏掉会把非法方案（$arr2$ 出现负数）计入，例如示例 1 的 $s = 3$ 在 $i = 2$ 处。
3. **$t_{\max} < 0$ 的死状态**：$\Delta > 0$ 且 $s < \Delta$ 时前缀为空，务必判 `tmax >= 0` 再查前缀和，否则轻则越界、重则负下标读错值。
4. **前缀和偏移**：`pre[tmax + 1]` 与「$pre$ 开 $V + 2$ 长、$pre[0] \equiv 0$」配套；改成 `pre[tmax]` 之类的半开半闭写法极易差一。
5. **滚动后清零**：`ndp` 每轮先清零再写，只写 $s \le nums[i]$ 的格子；若沿用上一轮残值会把死状态误当活状态。
6. **溢出**：C++ 中间累加用 `long long`（两个 `int` 级的模值相加也会先在 `int` 里溢出的话——本题加数均 $< 10^9 + 7$，`long long` 承接安全）；Python 无此虑。
7. **别被两条单调性吓到去开二维状态**：$(arr1[i], arr2[i])$ 二维状态是伪需求——逐位和之下只剩一个自由度。
