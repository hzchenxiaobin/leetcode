# LeetCode 统计好节点的数目 题解

## 1. 题目概述

- **标题 / 题号**：统计好节点的数目（#3249，medium）
- **链接**：https://leetcode.cn/problems/count-the-number-of-good-nodes/
- **来源**：LeetCode 第 410 场周赛 Q2
- **难度**：中等
- **标签**：树、深度优先搜索

**题意**：给定一棵以节点 $0$ 为根、共 $n$ 个节点的**无向树**（$n - 1$ 条边）。若某节点的**所有「以子节点为根的子树」所含节点数完全相同**，则该节点是**好节点**。返回树中好节点的数目。

**约束**：

- $2 \le n \le 10^5$
- $edges.length = n - 1$，$0 \le a_i, b_i < n$
- 输入保证 $edges$ 总表示一棵有效的树

> 💡 **快速切入**：题目问的是「孩子的子树大小是否全等」，而**子树大小**恰是树形 DP 最基础的自底向上量——后序 DFS 一趟就能全部求出。判定所需的信息与遍历返回值天然重合，这是一道标准的「换皮 size 统计」题。

## 2. 示例

**示例 1**

```text
输入：edges = [[0,1],[0,2],[1,3],[1,4],[2,5],[2,6]]
输出：7
解释：完全二叉形态，每个节点的孩子 size 都全等，所有 7 个节点都是好节点。
```

**示例 2**

```text
输入：edges = [[0,1],[1,2],[2,3],[3,4],[0,5],[1,6],[2,7],[3,8]]
输出：6
解释：节点 0/1/2 各有两个 size 不等的孩子（坏），其余 6 个节点为好。
```

**示例 3**

```text
输入：edges = [[0,1],[1,2],[1,3],[1,4],[0,5],[5,6],[6,7],[7,8],[0,9],[9,10],[9,12],[10,11]]
输出：12
解释：除节点 9 外其他所有节点都是好节点（9 的孩子 size 为 {2, 1} 不等）。
```

## 3. 解题思路

### 3.1 暴力思路：逐节点独立数子树

对每个节点 $u$：枚举其每个孩子 $v$，单独做一次 BFS/DFS 数出 $v$ 子树的大小，再检查这些大小是否全等。单个节点 $O(n)$，全树 $O(n^2)$，$n = 10^5$ 时约 $10^{10}$ 次操作，必然超时。

低效的根源在于：**同一次遍历得到的信息被反复丢弃**——$u$ 在数孩子 $v$ 的子树大小时，其实已经走遍了 $v$ 的整个子树，但算完即扔，$v$ 自己的判定又得从头再走一遍。

### 3.2 核心观察：子树大小一遍后序 DFS「顺手」全算出来

![核心观察：好节点判定只需比较孩子的子树大小](images/good_nodes_subtree_size_concept.svg)

定义 $\text{size}[u]$ 为以 $u$ 为根的子树的节点数，则：

$$\text{size}[u] = 1 + \sum_{v \in \text{children}(u)} \text{size}[v]$$

这是一个**自底向上**的递推：只要按**后序**（先孩子、后自己）遍历一次，每个节点的 size 都能在所有孩子返回后立刻拼出来。而「$u$ 是否好」的判定恰好只需要**孩子们的 size**——这些值正是递归调用的返回值。于是「算 size」与「判好」可以在**同一次 DFS** 里完成：

- 收齐孩子返回的各 $sz$，全相等（或没有孩子）则 $ans{+}{+}$；
- 向父节点返回 $1 + \sum sz$。

> 💡 **空真（vacuous truth）**：叶子没有孩子，「所有孩子的子树大小相同」这一全称命题**空真成立**，所以**叶子必是好节点**。同理，只有一个孩子的节点也必是好——只有一个值，无从不等。示例 3 中 12 个好节点里有 5 个是靠「空真 / 单孩子」入选的，别把它们漏了。

### 3.3 算法流程

![算法流程：后序 DFS 一趟同时算 size 与判好](images/good_nodes_dfs_flow.svg)

| 步骤 | 操作 | 说明 |
|------|------|------|
| ① 建图 | 无向边 $(a, b)$ 两端都加入邻接表 | 树以无向形式给出 |
| ② 后序 DFS | `dfs(u, fa)`，遇到 `v == fa` 跳过 | 防回头；根的 fa 取 $-1$ |
| ③ 判好 | 收集各孩子返回的 sz，全等则 `ans++` | $O(1)$：只记第一个 sz + 好坏标记 |
| ④ 回传 | 返回 $1 + \sum sz$ | 即 $\text{size}[u]$ |
| ⑤ 收尾 | 根处理完输出 ans | — |

> ⚠️ **Python 爆栈**：$n \le 10^5$ 且树可能退化成链（深 $10^5$），Python 默认递归上限 1000，即便 `sys.setrecursionlimit` 调大仍有 C 栈溢出风险。稳妥做法是**迭代两趟**：先用栈扫出「父先于子」的 `order`，再**逆序**遍历 `order` 累计 size——逆序恰好等价于后序（孩子总在父亲之前处理）。

### 3.4 示例演算

![示例 2 走查：逐节点核对孩子 size 是否全等](images/good_nodes_walkthrough.svg)

以示例 2 逐节点核对（见上图右表）：节点 0 的孩子 size 为 $\{7, 1\}$、节点 1 为 $\{5, 1\}$、节点 2 为 $\{3, 1\}$，均不全等 → 坏；节点 3 的孩子 size $\{1, 1\}$ 相等 → 好；$4/5/6/7/8$ 均为叶子 → 空真好。合计 6 个好节点，与示例输出一致。

## 4. 算法细节

1. **无向树转有根树**：邻接表双向存边，DFS 带父参数 `fa`，遇到 `v == fa` 跳过——这是无向图上树遍历的标配写法。
2. **迭代后序的构造**：栈扫描得到的 `order` 天然满足「父在子前」（孩子入栈时父已出栈，归纳可证所有后代都在父之后）；`reversed(order)` 则「子在父前」，等价于后序。
3. **$O(1)$ 判等**：不必把所有孩子 size 存进集合——只须记 `first[u]`（u 的**第一个**孩子上报的 size）与 `good[u]` 标记：后续孩子的 size 与 `first[u]` 不等即置 `good[u] = False`。子树 size 至少为 1，可用 0 作「尚无孩子上报」的哨兵。
4. **上推时机**：逆序遍历到 $u$ 时，$u$ 的所有孩子都已处理完、`size[u]` 已收齐，把 `size[u]` 加到 `size[parent[u]]` 上即完成父节点的收集；根节点（`u == 0`）不上推。
5. **答案统计**：`good` 数组中 `True` 的个数；叶子从未被置 `False`，天然计入。

## 5. 正确性证明

**引理 1**（size 的递归正确性）：按后序计算时，`dfs(u)` 的返回值等于以 $u$ 为根的子树的节点数。

**证明**：对子树高度归纳。$u$ 为叶子时返回 $1$，正确。设 $u$ 的孩子为 $v_1, \dots, v_k$（$k \ge 1$），后序保证它们先于 $u$ 完成；归纳假设各 `dfs(v_i)` 返回 $\text{size}[v_i]$。以 $u$ 为根的子树节点集合 $= \{u\} \cup \bigcup_i \text{subtree}(v_i)$，且各 $\text{subtree}(v_i)$ 两两不相交，故 $\text{size}[u] = 1 + \sum_i \text{size}[v_i]$，即返回值正确。∎

**引理 2**（好节点判定准则）：$u$ 是好节点 $\iff$ $u$ 的各孩子 $v_1, \dots, v_k$ 的 $\text{size}$ 两两相等；$k = 0$（叶子）时空真成立。

**证明**：好节点的定义即「所有以子节点为根的子树包含的节点数相同」，逐字翻译即 $\text{size}[v_1] = \cdots = \text{size}[v_k]$。$k = 0$ 时该全称命题没有约束对象，空真；$k = 1$ 时只有一个值，平凡相等。∎

**定理**：算法返回给定树中好节点的数目。

**证明**：树连通无环，DFS 从根出发经 `fa` 参数避免回头，每个节点恰被访问一次（每条无向边仅被「父 → 子」方向通过），故每个节点恰被判定一次、不重不漏。由引理 1，判定时拿到的各孩子返回值即真实 size；由引理 2，「全等（或无孩子）则计数」恰好等价于 $u$ 是好节点。计数一一对应，返回值正确。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。建邻接表 $O(n)$；DFS 每个节点进出一次，每条无向边被两端各查看一次共 $2(n-1)$ 次；每个节点的判好为 $O(1)$。
- **空间复杂度**：$O(n)$。邻接表 $O(n)$；`size` / `parent` / `first` / `good` 数组各 $O(n)$；迭代栈最深处 $O(n)$（链状树），递归版另有同等量级的调用栈。

## 7. 参考代码

### C++（后序 DFS 递归版）

```cpp
class Solution {
    vector<vector<int>> g;
    int ans = 0;

    // 返回以 u 为根的子树大小；顺手判定 u 是否好节点
    int dfs(int u, int fa) {
        int sz = 1;        // u 自身
        int first = -1;    // 第一个孩子的子树大小
        bool good = true;
        for (int v : g[u]) {
            if (v == fa) continue;   // 无向边：跳过来路
            int s = dfs(v, u);       // 后序：先算孩子
            if (first < 0) first = s;
            else if (s != first) good = false;
            sz += s;
        }
        if (good) ++ans;   // 叶子 / 孩子全等 → 好节点
        return sz;
    }

public:
    int countGoodNodes(vector<vector<int>>& edges) {
        int n = edges.size() + 1;
        g.assign(n, {});
        for (auto& e : edges) {
            g[e[0]].push_back(e[1]);
            g[e[1]].push_back(e[0]);
        }
        dfs(0, -1);
        return ans;
    }
};
```

### Python（迭代两趟版，防链状树爆栈）

```python
class Solution:
    def countGoodNodes(self, edges: List[List[int]]) -> int:
        n = len(edges) + 1
        g = [[] for _ in range(n)]
        for a, b in edges:
            g[a].append(b)
            g[b].append(a)

        # 第一趟：栈扫描，得到「父先于子」的 order
        parent = [-1] * n
        order = []
        stack = [0]
        while stack:
            u = stack.pop()
            order.append(u)
            for v in g[u]:
                if v != parent[u]:
                    parent[v] = u
                    stack.append(v)

        # 第二趟：逆序 order = 后序，自底向上累计
        size = [1] * n
        first = [0] * n        # 0 表示尚无孩子上报（size >= 1，哨兵安全）
        good = [True] * n      # 叶子保持 True（空真）
        for u in reversed(order):
            if u:              # 非根：向父节点上报
                p = parent[u]
                size[p] += size[u]
                if not first[p]:
                    first[p] = size[u]
                elif size[u] != first[p]:
                    good[p] = False
        return sum(good)
```

## 8. 边界情况与易错点

1. **忘记防回头**：无向边两端都进了邻接表，DFS 不带 `fa`（或不记 visited）会在 $0 \leftrightarrow 1$ 之间来回横跳，轻则答案错、重则死循环。
2. **Python 递归深度**：链状树深达 $10^5$，默认上限 1000 直接 `RecursionError`；`sys.setrecursionlimit(300000)` 在部分环境仍可能崩底层 C 栈，比赛里推荐直接写迭代两趟版。
3. **叶子别漏计**：「没有孩子」是空真好节点，最典型的错误是把它当坏节点；只有单个孩子的节点同样是好节点。
4. **C++ 递归深度**：$10^5$ 层、每帧不大，通常可过；不放心可换成与 Python 相同的两趟迭代。
5. **哨兵取值**：用 `first[u] == 0` 表示「尚无孩子上报」之所以安全，是因为任何子树 $\text{size} \ge 1$；若改用其他哨兵注意初始化一致。
6. **n 的来源**：题目不直接给 $n$，须由 `len(edges) + 1` 推出，别误写成 `len(edges)`。
