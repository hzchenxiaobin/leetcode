# LeetCode 单调数组对的数目 II 题解

## 1. 题目概述

- **标题 / 题号**：单调数组对的数目 II（#3251，hard）
- **链接**：https://leetcode.cn/problems/find-the-count-of-monotonic-pairs-ii/
- **来源**：LeetCode 第 410 场周赛 Q4
- **难度**：困难
- **标签**：数组、动态规划、前缀和、组合数学

**题意**：给定长度为 $n$ 的**正**整数数组 $nums$，数出有多少对长度同为 $n$ 的**非负**整数数组 $(arr1, arr2)$ 满足：

- $arr1$ 单调**非递减**：$arr1[0] \le arr1[1] \le \dots \le arr1[n-1]$；
- $arr2$ 单调**非递增**：$arr2[0] \ge arr2[1] \ge \dots \ge arr2[n-1]$；
- 逐位和锁定：$arr1[i] + arr2[i] = nums[i]$ 对所有 $0 \le i \le n-1$ 成立。

答案对 $10^9 + 7$ 取模后返回。

**约束**：

- $1 \le n = nums.length \le 2000$
- $1 \le nums[i] \le 1000$

> 💡 **读题三连**：① 题面与同场 Q3（#3250）**一字不差**——先确认这不是新算法，而是值域 $50 \to 1000$ 的**复杂度压力测试**；② 重算预算：$O(n \cdot V^2)$ 从 $5 \times 10^6$（能过）膨胀到 $2 \times 10^9$（必死），前缀和优化从「锦上添花」升格为「生死线」；③ 值域放大后浮出一个 Q3 里看不见的新现象——**答案可以为 0**（大幅锯齿摆动把可行带挤死），写完必须专门拿无解用例验一验。

解释：全部单调数组对为

      ([0, 1, 2], [2, 2, 0])
      ([0, 2, 2], [2, 1, 0])
      ([1, 2, 2], [1, 1, 0])
```

输出：126
解释：恰为隔板数 C(9,4)——全相等时问题退化为非减序列计数。
```

**示例 3（自拟：棘轮死局）**

```text
输入：nums = [1,1000,1]
输出：0
解释：i = 1 处 nums 上涨 999，arr1 必须至少涨到 999；
      i = 2 处 nums 回落到 1，但 arr1 非减、再也下不来，
      而 arr1[2] ≤ nums[2] = 1 —— 无解，答案为 0。
```

## 3. 解题思路

### 3.1 暴力思路：Q3 的朴素做法在这里死掉

由逐位和，$arr2$ 完全由 $arr1$ 决定，只需枚举 $arr1$。DFS 逐位试 $[0, nums[i]]$ 中的每个值、边填边校验，组合数最坏 $\prod_i (nums[i] + 1) \le 1001^{2000}$，指数爆炸。

「数组的朴素 DP」把「前 $i$ 位、末位填 $s$」当状态、转移枚举前一位 $t$，共 $O(n \cdot V^2)$。Q3 里 $V = 50$，约 $5 \times 10^6$ 勉强能过；**本题 $V = 1000$，直接变成 $2 \times 10^9$——超时板上钉钉**。算法结构一个字都不用改，生死的只是转移的代价：把「枚举 $t$ 求和」换成「前缀和一次查询」，$O(V^2)$ 层就塌缩成 $O(V)$。

> ⚠️ **姊妹题打法**：周赛出现 I/II 同名题时，小数据版就该一步到位写出优化复杂度的版本——在 Q3 写了 $O(nV^2)$ 的人，Q4 要在剩余时间里现场重做转移优化；在 Q3 直接写 $O(nV)$ 的人，Q4 换个题号重交一次即可。本题正是这个策略的教科书案例。

### 3.2 核心观察：棘轮效应——上涨全额吃下，回落一分不还

先复用同场 Q3 的两个观察（推导细节见 Q3 题解）：逐位和把 $arr2$ 钉死为 $nums[i] - arr1[i]$，**arr2 没有任何自由度**；两条单调性逐位合并成对前值的**单侧上界**。设 $s = arr1[i]$、$t = arr1[i-1]$、$\Delta = nums[i] - nums[i-1]$：

- $arr1$ 非减 $\iff t \le s$；
- $arr2$ 非增 $\iff nums[i] - s \le nums[i-1] - t \iff t \le s - \Delta$。

利用恒等式 $\min(s,\ s - \Delta) = s - \max(0, \Delta)$，两条约束合并成一条最顺口的形式。记 $d = \max(0, \Delta)$（**本轮 nums 的净涨幅**），则

$$t \le s - d$$

**读法（跷跷板）**：nums 上涨时 $arr2$ 只许降不许升，涨幅必须**由 arr1 全额吃下**——$arr1[i]$ 至少是 $arr1[i-1] + d$；nums 持平或下跌时 $d = 0$，约束只剩非减本身。约束仍是「前值越小越安全」的**前缀窗口** $[0, s-d]$，前缀和一次查询 $O(1)$。

![核心观察：棘轮效应与可行带](images/wc410_q4_ratchet_concept.svg)

把「$arr1[i] \ge arr1[i-1] + d_i$」沿位置累加，得到值域放大后浮出的新结构——**棘轮**：

$$\ell_i = \sum_{k \le i} \max(0, \Delta_k)$$

是 $arr1[i]$ 的硬下界，**只升不降**。nums 的每次上涨都被棘轮永久锁存；回落时 $arr1$ 一分不还、全部跌幅由 $arr2$ 吞下。于是可行带 $[\ell_i,\ nums[i]]$ 随锯齿左右剪切，一旦 $\ell_i > nums[i]$，该层支撑为空、其后全零——**答案为 0**（见上图右面板与示例 3）。

### 3.3 算法流程：值域 DP + 前缀和 + 棘轮区间裁剪

![算法流程：前缀和 O(1) 转移与复杂度预算](images/wc410_q4_dp_flow.svg)

定义 $dp[i][s]$ = 填好前 $i+1$ 位、且 $arr1[i] = s$ 的合法 $arr1$ 个数：

- **初始**：$dp[0][s] = 1$（$0 \le s \le nums[0]$）——首位无前驱，任取；
- **转移**：$dp[i][s] = \sum_{t \le s - d} dp[i-1][t] = pre[s - d + 1]$，其中 $pre[k] = \sum_{t < k} dp[i-1][t]$ 是上一层前缀和，$d = \max(0, \Delta)$；
- **答案**：$\sum_{s=0}^{nums[n-1]} dp[n-1][s]$。

实现上维护棘轮变量 $lo = \ell_i$，每层 $lo \mathrel{+}= d$，然后**只扫支撑区间 $s \in [lo,\ nums[i]]$**——区间外的状态恒为 0，跳过不改变结果（证明见 §5 引理 3）。这个裁剪一举三得：跳过死格子、自动免疫 $t_{\max} < 0$ 的负下标（$s \ge lo \ge d \Rightarrow s - d \ge 0$）、天然处理无解（区间空 $\Rightarrow$ 整层 0 $\Rightarrow$ 答案 0）。转移只读上一层、写本层，两组数组滚动。

### 3.4 示例演算

![示例演算：常规例与棘轮死局走查](images/wc410_q4_example_walkthrough.svg)

左表是 $nums = [2,3,2]$ 的三层 dp（与 Q3 题解的演算表同一张，此处从简）：$i=1$ 层 $\Delta = +1$、$d = 1$，分布整体右移一格、$s = 0$ 清零；$i = 2$ 层 $d = 0$，退化为普通前缀和堆积；末层求和 $0 + 1 + 3 = 4$ ✓。

右侧是 Q4 味道最浓的**棘轮死局** $nums = [1,1000,1]$：

| $i$ | $\Delta$ | $d$ | $\ell$ | 本层 dp |
|-----|----------|-----|--------|---------|
| 0 | — | — | 0 | $s \in [0,1]$：$1, 1$ |
| 1 | $+999$ | 999 | 999 | 1001 格只有 2 格活：$dp[999]=1$，$dp[1000]=2$ |
| 2 | $-999$ | 0 | 999 | 支撑区间 $[999, 1]$ 为空：**全 0** |

$arr1$ 在 $i=1$ 被顶到 $\ge 999$ 后再也下不来，$nums$ 回落到 1 也救不回——末层求和得 0 ✓。顺带一提，$[5,5,5,5]$ 同法算出 126，恰是隔板数 $\binom{9}{4}$，闭式见「相关题目与扩展」。

## 4. 算法细节

1. **值域维动态取** $V = \max(nums)$，第二维长度 $V + 1$ 与 $n$ 无关——同一份代码**原样可过 Q3**（#3250，值域 50），这正是姊妹题的意图。
2. **前缀和的下标偏移**：$pre$ 开 $V + 2$ 长、$pre[0] \equiv 0$，定义 $pre[k] = \sum_{t < k} dp[i-1][t]$，查询统一写 $pre[s - d + 1]$ 表示「$t \le s - d$」，全程无边界特判。
3. **棘轮变量 $lo$ 的三重身份**：理论下界 $\ell_i$（证明见 §5）、循环起点（只扫活格子）、负下标与无解的天然防线。锯齿大摆动的数据全靠它跳过死格子（实测 2000 长交替 $1/1000$ 用例 0.2s vs 全 1000 用例 0.4s）。
4. **滚动清零**：`ndp` 每轮整层清零再写，只写 $[\ell_i, nums[i]]$ 内的格子；区间外的 0 与「上一层越界 0」经前缀和自动传播。
5. **取模纪律**：每个中间值加减后立即 `% MOD`；C++ 用 `long long` 承接模加法防溢出，Python 在 `accumulate` 的 lambda 里即时取模，防止大整数膨胀拖慢循环。
6. **首末层的特殊性**：首位无前驱（初始化是「一段全 1」）、末位无后继（收尾是「整层求和」），只有中间位受双约束夹击——与 Q3 完全一致。

## 5. 正确性证明

**引理 1**（影子双射）：合法单调数组对 $(arr1, arr2)$ 与满足条件组 (C) 的序列 $arr1$ 一一对应，其中：

- (C1) 对所有 $i$：$0 \le arr1[i] \le nums[i]$；
- (C2) 对所有 $1 \le i \le n-1$：$arr1[i-1] \le arr1[i]$ 且 $nums[i] - arr1[i] \le nums[i-1] - arr1[i-1]$。

**证明**：正向，设 $(arr1, arr2)$ 合法。非负性给出 (C1)；$arr1$ 非减即 (C2) 前半，$arr2$ 非增逐位展开即 (C2) 后半。反向，设 $arr1$ 满足 (C)，令 $arr2[i] = nums[i] - arr1[i]$，由 (C1) 知 $arr2 \ge 0$，长度与逐位和显然，(C2) 前后半分别就是两条单调性。逐位和把 $arr2$ 唯一确定，映射为单射；又每个合法对都由其 $arr1$ 产生，故为双射。∎

**引理 2**（约束合并）：记 $s = arr1[i]$，$t = arr1[i-1]$，$d = \max(0, \Delta)$，$\Delta = nums[i] - nums[i-1]$，则 (C2) $\iff t \le s - d$。

**证明**：(C2) 即 $t \le s$ 且 $t \le s - \Delta$，$\iff t \le \min(s, s - \Delta)$。而 $\Delta \ge 0$ 时 $\min(s, s-\Delta) = s - \Delta = s - d$，$\Delta < 0$ 时 $\min(s, s-\Delta) = s = s - d$，两种情形统一为 $s - d$。∎

**引理 3**（棘轮引理）：设 $\ell_0 = 0$、$\ell_i = \ell_{i-1} + \max(0, \Delta_i)$。若第 $i-1$ 层 dp 的非零支撑恰为区间 $[\ell_{i-1},\ nums[i-1]]$（允许为空），则第 $i$ 层 dp 的非零支撑恰为 $[\ell_i,\ nums[i]]$（允许为空）。

**证明**：转移为 $dp[i][s] = \sum_{t \le s - d} dp[i-1][t]$（引理 2 + 前缀和），其中求和范围还隐含 $t$ 落在上一层枚举范围 $[0, nums[i-1]]$ 内。若上层支撑为空（全 0），则和式恒 0，本层也空，命题成立。否则 $\ell_{i-1} \le nums[i-1]$，和式非零 $\iff$ 满足 $t \le s - d$ 的活格子存在 $\iff \ell_{i-1} \le s - d$（活格子组成区间，取其左端点即可；反之任何可行 $t \ge \ell_{i-1}$）。于是本层非零 $\iff s \ge \ell_{i-1} + d = \ell_i$ 且 $s \le nums[i]$，即支撑恰为 $[\ell_i, nums[i]]$；且当区间非空时取 $t = \ell_{i-1}$（归纳保证 $dp[i-1][\ell_{i-1}] \ge 1$）得 $dp[i][\ell_i] \ge 1$，区间确实「非空支撑」。∎

**推论**：答案非零 $\iff$ 对所有 $i$ 有 $\ell_i \le nums[i]$——一遍扫描 $O(n)$ 即可判空；一层变空则其后每层全零。

**定理**：上述算法（含只扫 $[\ell_i,\ nums[i]]$ 的区间裁剪）返回单调数组对的个数（模 $10^9 + 7$ 意义下）。

**证明**：对 $i$ 归纳断言：$dp[i][s] \equiv$ 「满足 (C) 的前缀 $arr1[0..i]$ 且 $arr1[i] = s$」的个数（模意义下）。$i = 0$：(C) 退化为 $0 \le s \le nums[0]$，每个 $s$ 恰一个序列，$dp[0][s] = 1$ 成立。设第 $i-1$ 层成立。末位为 $s$ 的合法前缀按 $arr1[i-1] = t$ 分类（互斥穷尽），由引理 2，拼接合法 $\iff t \le s - d$ 且 $0 \le s \le nums[i]$（恰为本层枚举范围），故 $dp[i][s] = \sum_{t \le s-d} dp[i-1][t]$，与前缀和查询一致。由引理 3，$s \notin [\ell_i, nums[i]]$ 的状态 dp 值恒为 0，跳过它们不改变任何取值，裁剪合法。由引理 1，末层求和即数组对总数。同余对加法封闭，归纳可知每层 dp 值 $\equiv$ 真实计数 $\pmod{10^9 + 7}$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \cdot V)$，$V = \max(nums) \le 1000$。每层一趟前缀和 $O(V)$ + 支撑区间扫描 $\le O(V)$，共 $n - 1$ 层，上界 $\approx 2000 \times 1001 \approx 2 \times 10^6$；区间裁剪只减不增。实测（本机）：$n = 2000$、$nums$ 全 1000 的极端用例，C++ 约 9ms、Python 约 0.39s；交替 $1/1000$ 的锯齿无解用例 Python 约 0.2s。
- **空间复杂度**：$O(V)$。滚动 `dp`、`ndp` 与前缀和 `pre` 三个一维数组，与 $n$ 无关。完整二维表要 $2 \times 10^6$ 个格子，C++ 尚可承受但毫无必要，Python 嵌套列表要上百 MB——滚动是硬需求。
- **对照**：朴素 DP $O(n \cdot V^2) = 2 \times 10^9$ 在 Q4 必超时（Q3 的 $5 \times 10^6$ 能过，正是被「惯坏」的地方）；DFS 枚举 $O(1001^n)$ 完全不可行。本文代码另与 DFS 暴力随机对拍 600 组、与全相等闭式 $\binom{n+V}{n}$ 抽查多组，全部一致。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int countOfPairs(vector<int>& nums) {
        const int MOD = 1'000'000'007;
        const int V = *max_element(nums.begin(), nums.end());
        vector<long long> dp(V + 1), ndp(V + 1), pre(V + 2);
        for (int s = 0; s <= nums[0]; ++s) dp[s] = 1;      // 首位任取
        int lo = 0;                                         // 棘轮下界 ℓ：arr1[i] ≥ lo
        for (int i = 1; i < (int)nums.size(); ++i) {
            const int d = max(0, nums[i] - nums[i - 1]);   // 上涨必须由 arr1 吃下
            lo += d;                                        // 棘轮只升不降
            for (int s = 0; s <= V; ++s)                    // 上一层前缀和
                pre[s + 1] = (pre[s] + dp[s]) % MOD;
            fill(ndp.begin(), ndp.end(), 0);
            for (int s = lo; s <= nums[i]; ++s)             // 只扫支撑区间 [ℓ, nums[i]]
                ndp[s] = pre[s - d + 1];                    // 前缀窗口 [0, s−d]
            dp.swap(ndp);                                   // 滚动
        }
        long long ans = 0;
        for (int s = 0; s <= nums.back(); ++s) ans = (ans + dp[s]) % MOD;
        return (int)ans;
    }
};
```

### Python

```python
from itertools import accumulate

class Solution:
    def countOfPairs(self, nums: List[int]) -> int:
        MOD = 10 ** 9 + 7
        V = max(nums)
        dp = [1] * (nums[0] + 1) + [0] * (V - nums[0])      # 首位任取
        lo = 0                                               # 棘轮下界 ℓ
        for i in range(1, len(nums)):
            d = max(0, nums[i] - nums[i - 1])                # 上涨必须由 arr1 吃下
            lo += d                                          # 棘轮只升不降
            pre = list(accumulate(dp, lambda a, b: (a + b) % MOD, initial=0))
            ndp = [0] * (V + 1)
            for s in range(lo, nums[i] + 1):                 # 只扫支撑区间 [ℓ, nums[i]]
                ndp[s] = pre[s - d + 1]                      # 前缀窗口 [0, s−d]
            dp = ndp                                         # 滚动
        return sum(dp[: nums[-1] + 1]) % MOD
```

## 8. 边界情况与易错点

1. **$n = 1$**：主循环不执行，直接返回 $nums[0] + 1$（两条单调性均空真，逐位和 $k$ 有 $k+1$ 种拆法）。代码无需特判，但心里要过一遍。
2. **答案可以为 0**：$[1,1000,1]$、大幅锯齿摆动都归零。不要下意识地 `max(ans, 1)`，对拍也要专门带上无解用例——判空判据 $\forall i: \ell_i \le nums[i]$ 只需 $O(n)$。
3. **忘掉 $s \le nums[i]$ 的上界**：它来自 $arr2[i] \ge 0$，漏掉会把 $arr2$ 为负的非法方案计入。
4. **$t_{\max} < 0$ 的死状态**：不裁剪的写法必须先判再查前缀和，否则负下标越界；本文的裁剪写法因 $s \ge lo \ge d$ 自动免疫。
5. **前缀和差一**：`pre[s - d + 1]` 与「`pre` 开 $V + 2$ 长、$pre[0] \equiv 0$」配套，改成 `pre[s - d]` 之类的写法极易差一。
6. **滚动后清零**：`ndp` 每轮先清零再写；若沿用上一轮残值，死状态会被误当活状态。
7. **溢出与运行时**：C++ 中间累加用 `long long`；Python 的 `accumulate` 参数 `initial=0` 需要 Python ≥ 3.8（LeetCode 环境满足），低版本换手写循环。
8. **别在 Q3 偷懒**：本题最大的「易错点」其实发生在 Q3——值域小就写 $O(nV^2)$，到了 Q4 没时间重推。姊妹题一律按大数据版的预算来设计小数据版的解法。

**延伸思考**：若 $nums$ 恒为 $V$，$d \equiv 0$，问题退化为「$0 \le a_0 \le \dots \le a_{n-1} \le V$」的序列计数，隔板法立得闭式 $\binom{n + V}{n}$（阶乘 + 逆元可 $O(n + V)$ 直出，是检验 DP 实现的对拍利器，$[5,5,5,5] \to \binom{9}{4} = 126$）。若值域进一步放大到 $10^9$，值域数组开不动，但「每层分布 = 上层前缀和右移 $d$ 格、再截断到支撑区间」的保形结构仍在——可对区间端点做离散化、跟踪分段函数（前缀和逐层抬高多项式次数），有兴趣可深挖。工程习惯上，先用 $\ell_i \le nums[i]$ 花 $O(n)$ 判空再进 DP，能白省无解大样例的计算。
