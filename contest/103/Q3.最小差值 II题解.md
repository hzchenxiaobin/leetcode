# LeetCode 最小差值 II 题解

## 1. 题目概述

- **标题 / 题号**：最小差值 II（#910，medium）
- **链接**：https://leetcode.cn/problems/smallest-range-ii/
- **来源**：LeetCode 第 103 场周赛 Q3
- **难度**：中等
- **标签**：数组、数学、贪心、排序

**题意**：给定整数数组 `nums` 和整数 `k`。对**每个**下标 $i$，必须把 `nums[i]` 变成 `nums[i] + k` **或** `nums[i] - k`（二选一，不能不选）。操作后数组的**分数**是最大值与最小值之差，求能达到的**最小分数**。

**约束**：

- $1 \le nums.length \le 10^4$
- $0 \le nums[i] \le 10^4$
- $0 \le k \le 10^4$

与同场 Q1 的关键区别：Q1 允许在 $[-k, k]$ 内**任意**调整，答案有闭式解；本题**必须恰好 $\pm k$**，两端无法同时向中间靠拢（一个数只能选一边），因此需要额外做决策。

## 2. 示例

**示例 1**

```text
输入：nums = [1], k = 0
输出：0
解释：单元素，最大值 = 最小值。
```

**示例 2**

```text
输入：nums = [0,10], k = 2
输出：6
解释：0 加 2 变 2、10 减 2 变 8，分数 8 − 2 = 6。
```

**示例 3**

```text
输入：nums = [1,3,6], k = 3
输出：3
解释：变成 [4,6,3]（1+3、3+3、6−3），最大值 6、最小值 3，分数 3。
      若全加 k 得 [4,6,9] 分数 5，全减 k 得 [−2,0,3] 分数 5，都不如 3 好。
```

**示例 4（自造，两端互换）**

```text
输入：nums = [2,7,2], k = 1
输出：3
解释：2 加 1 得 3、7 减 1 得 6，另一个 2 加 1 得 3 → [3,3,6]，分数 3。
```

## 3. 解题思路

### 3.1 暴力思路

每个元素有 2 种选择（$+k$ 或 $-k$），共 $2^n$ 种组合。$n = 10^4$ 时是天文数字，直接枚举不可行。

能不能 DP？分数是「全局最大值 − 全局最小值」，它依赖于所有元素的取值，状态里必须同时记录当前最大值与最小值，值域 $10^4$ 下状态数是 $O(V^2)$，再加上 $n$ 个元素，规模 $10^4 \times 10^8$，不可接受。

必须找到组合的结构。

### 3.2 核心观察：排序后最优解是「一刀切」

![排序后总存在分界点：左边 +k，右边 −k](images/wc103_q3_split_concept.svg)

先把 `nums` 排序，记为 $a_0 \le a_1 \le \dots \le a_{n-1}$。设每个元素的符号 $s_i \in \{+1, -1\}$，最终值 $b_i = a_i + s_i k$。

**关键引理（交换论证）**：若存在 $i < j$ 使得 $s_i = -1$、$s_j = +1$（即「小的减、大的加」，把区间拉宽了），那么把它们互换为 $s_i = +1$、$s_j = -1$ 后，最终极差**不会变大**。

直观上：$a_i - k \le a_j - k \le a_j + k$ 且 $a_i - k \le a_i + k \le a_j + k$，交换后两个元素都落在原来的 $[a_i - k,\ a_j + k]$ 之内，所以整体最大值不会升高、最小值不会降低。

于是可以反复消除这类「逆序对」，直到所有 $+1$ 都排在所有 $-1$ 前面。也就是说，最优解一定长这样：

$$b = \underbrace{a_0 + k,\ \dots,\ a_{t-1} + k}_{\text{前 } t \text{ 个加}},\ \underbrace{a_t - k,\ \dots,\ a_{n-1} - k}_{\text{后 } n-t \text{ 个减}}$$

只需枚举分界点 $t \in [0, n]$（$t = 0$ 是全部减、$t = n$ 是全部加）。对固定的 $t$：

- 最大值来自「前半段的最大」$a_{t-1} + k$ 与「后半段的最大」$a_{n-1} - k$，取二者较大；
- 最小值来自「前半段的最小」$a_0 + k$ 与「后半段的最小」$a_t - k$，取二者较小。

即

$$\text{score}(t) = \max\bigl(a_{t-1} + k,\ a_{n-1} - k\bigr) - \min\bigl(a_0 + k,\ a_t - k\bigr).$$

答案就是所有 $t$ 中的最小值。$t = 0$ 或 $t = n$ 时两段只剩一段，分数退化为原数组极差 $a_{n-1} - a_0$。

### 3.3 算法流程

![枚举分界点的流程](images/wc103_q3_algorithm_flow.svg)

```text
1. 排序 nums
2. ans = nums[n-1] - nums[0]              # 对应 t = 0 与 t = n
3. for i = 0 .. n-2:                      # 分界在 i 与 i+1 之间，即 t = i+1
4.     hi = max(nums[i] + k, nums[n-1] - k)
5.     lo = min(nums[0] + k, nums[i+1] - k)
6.     ans = min(ans, hi - lo)
7. 返回 ans
```

$n = 1$ 时循环不进入，直接返回 0。

### 3.4 示例演算

![示例演算：nums = [1,3,6]，k = 3](images/wc103_q3_walkthrough.svg)

对 `nums = [1,3,6]`、$k = 3$（已排序）：

| 分界 | 结果数组 | 最大值 | 最小值 | 分数 |
|------|----------|--------|--------|------|
| 全部减 / 全部加 | [−2,0,3] / [4,6,9] | 3 / 9 | −2 / 4 | 5 |
| $t=1$（1 加，3、6 减） | [4,0,3] | $\max(4, 3) = 4$ | $\min(4, 0) = 0$ | 4 |
| $t=2$（1、3 加，6 减） | [4,6,3] | $\max(6, 3) = 6$ | $\min(4, 3) = 3$ | **3** |

最优分数为 3，对应 $t = 2$。

## 4. 算法细节

1. **必须排序**：交换论证依赖于 $a_i \le a_j$ 的下标顺序；不排序时「前缀加、后缀减」的结构不成立。
2. **分界点的两种枚举方式**：循环 $i$ 从 $0$ 到 $n-2$，代表「$0..i$ 加、$i+1..n-1$ 减」，即 $t = i+1$；$t=0$ 与 $t=n$ 由初始值 `nums[n-1] - nums[0]` 覆盖。别漏掉全部同号的两种情形。
3. **公式中的下标**：$a_{t-1}$ 是前半段最后一个（最大），$a_t$ 是后半段第一个（最小），$a_0$ 是前半段第一个（最小），$a_{n-1}$ 是后半段最后一个（最大）。四个下标对应四个极值，写错一个就全错。
4. **`hi` 与 `lo` 可能交错**：当 $a_{t-1} + k > a_t - k$ 时，两段在数值上重叠，此时 `hi - lo` 仍由上述公式给出，不需要额外处理。
5. **不要先排序再按原顺序假设**：题目对下标没有约束，排序不改变答案（每个元素独立选择 $\pm k$，与位置无关）。
6. **数据类型**：$nums[i], k \le 10^4$，加减后仍在 `int` 范围内，无需 `long long`。

## 5. 正确性证明

**引理 1（交换不增）**：设 $a_i \le a_j$（$i < j$），若当前方案中 $s_i = -1$、$s_j = +1$，则把两者互换为 $s_i = +1$、$s_j = -1$ 后，最终数组的极差不增大。

**证明**：记原值 $b_i = a_i - k$、$b_j = a_j + k$，新值 $b_i' = a_i + k$、$b_j' = a_j - k$。由 $a_i \le a_j$ 得

$$b_i = a_i - k \le a_j - k = b_j', \qquad b_i' = a_i + k \le a_j + k = b_j,$$

即新值 $b_i'$、$b_j'$ 都落在区间 $[b_i, b_j]$ 内。

设原方案的最大值为 $M$、最小值为 $m$。由于 $M \ge b_j$、$m \le b_i$，新方案中所有元素（其余元素不变，$b_i', b_j' \in [b_i, b_j] \subseteq [m, M]$）仍落在 $[m, M]$ 内，故新最大值 $M' \le M$、新最小值 $m' \ge m$，从而 $M' - m' \le M - m$。∎

**引理 2（分界形态）**：存在最优方案，使得存在 $t \in [0, n]$，满足 $i < t$ 时 $s_i = +1$、$i \ge t$ 时 $s_i = -1$。

**证明**：任取一个最优方案。若存在 $i < j$ 且 $s_i = -1$、$s_j = +1$，由引理 1 交换后极差不增，仍是（或更优的）最优方案，且逆序对「$i<j$ 而 $s_i=-1, s_j=+1$」的数量严格减少 1。该数量非负，故反复交换必在有限步后终止，此时不存在这样的逆序对，即所有 $+1$ 都在所有 $-1$ 之前，方案具有所述分界形态。∎

**引理 3（固定分界的分数）**：对具有分界 $t$（$1 \le t \le n-1$）的方案，分数为

$$\max\bigl(a_{t-1} + k,\ a_{n-1} - k\bigr) - \min\bigl(a_0 + k,\ a_t - k\bigr).$$

**证明**：前段 $a_0 + k, \dots, a_{t-1} + k$ 随下标单调不减，其最大值是 $a_{t-1} + k$、最小值是 $a_0 + k$；后段 $a_t - k, \dots, a_{n-1} - k$ 同样单调不减，最大值为 $a_{n-1} - k$、最小值为 $a_t - k$。整体最大值是两段最大值中的较大者，整体最小值是两段最小值中的较小者，相减即得。∎

**定理**：算法返回值等于所有合法方案中分数的最小值。

**证明**：由引理 2，只需在「分界形态」的方案中找最优，而它们由 $t = 0, 1, \dots, n$ 完全刻画。$t = 0$ 与 $t = n$ 的分数都是 $a_{n-1} - a_0$（全部同号，极差不变），已由初始值覆盖；$t \in [1, n-1]$ 由循环逐一计算，且引理 3 给出了每个 $t$ 的精确分数。算法取这些值的最小值，恰为全局最优。∎

## 6. 复杂度分析

- **时间**：$O(n \log n)$。排序是主要开销；枚举 $n-1$ 个分界点、每个 $O(1)$，是 $O(n)$。$n = 10^4$ 时排序约 $1.3\times 10^5$ 次比较。
- **空间**：$O(\log n)$ 到 $O(n)$，取决于排序实现（C++ `std::sort` 为 $O(\log n)$ 栈空间，Python `sort` 为 $O(n)$ 的临时空间）；除此之外只用了常数个变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int smallestRangeII(vector<int>& nums, int k) {
        sort(nums.begin(), nums.end());
        int n = (int)nums.size();
        int ans = nums[n - 1] - nums[0];   // t = 0 或 t = n：全部同号
        for (int i = 0; i + 1 < n; i++) {
            // 0..i 取 +k，i+1..n-1 取 -k
            int hi = max(nums[i] + k, nums[n - 1] - k);
            int lo = min(nums[0] + k, nums[i + 1] - k);
            ans = min(ans, hi - lo);
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def smallestRangeII(self, nums: list[int], k: int) -> int:
        nums.sort()
        n = len(nums)
        ans = nums[-1] - nums[0]
        for i in range(n - 1):
            hi = max(nums[i] + k, nums[-1] - k)
            lo = min(nums[0] + k, nums[i + 1] - k)
            ans = min(ans, hi - lo)
        return ans
```

## 8. 边界情况与易错点

1. **忘了全部同号的情形**：`ans` 必须先用 `nums[n-1] - nums[0]` 初始化，否则当最优解是「全加」或「全减」时会漏解。
2. **`n = 1`**：循环不执行，返回 0；若把初始化写成别的东西（比如 `INT_MAX`），会返回错误值。
3. **分界点下标错位**：$i$ 表示「前 $i+1$ 个元素加 $k$」，因此最大值候选是 `nums[i] + k`（不是 `nums[i+1] + k`），最小值候选是 `nums[i+1] - k`（不是 `nums[i] - k`）。
4. **以为答案在 $t = n/2$ 处**：最优分界点不一定是中点，例如 `[0,10]`、$k=2$ 时 $t=1$ 最优（分数 6），而 `[1,100,101]`、$k=10$ 时最优也在 $t=1$，必须全枚举。
5. **`k = 0`**：所有方案分数都等于原极差，公式自动给出该值。
6. **重复元素**：排序后相等元素相邻，公式不受影响（交换论证对相等元素同样成立）。
7. **与 Q1 混淆**：Q1 允许每个元素在 $[-k,k]$ 内任意调，答案是 $\max(0, (M-m)-2k)$；本题必须恰好 $\pm k$，两者的答案可能不同（示例 3：Q1 答案是 0，本题是 3）。
