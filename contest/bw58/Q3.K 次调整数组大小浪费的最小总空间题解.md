# LeetCode K 次调整数组大小浪费的最小总空间 题解

## 1. 题目概述

- **标题 / 题号**：K 次调整数组大小浪费的最小总空间（#1959，medium）
- **链接**：https://leetcode.cn/problems/minimum-total-space-wasted-with-k-resizing-operations/
- **来源**：LeetCode 第 58 场双周赛 Q3
- **难度**：中等
- **标签**：数组、动态规划、前缀和

**题意**：设计一个动态数组。时刻 $t$ 的元素数目为 $nums[t]$，该时刻数组大小 $size_t$ 必须满足 $size_t \ge nums[t]$；时刻 $t$ 的浪费为 $size_t - nums[t]$，总浪费为各时刻浪费之和。调整大小（改成任意值）**至多** $k$ 次；初始大小任意且**不计入**调整次数。求最小总浪费。

**约束**：

- $1 \le nums.length \le 200$
- $1 \le nums[i] \le 10^6$
- $0 \le k \le nums.length - 1$

## 2. 示例

**示例 1**

```text
输入：nums = [10,20], k = 0
输出：10
解释：初始大小 20：size = [20,20]，浪费 (20-10)+(20-20) = 10。
```

**示例 2**

```text
输入：nums = [10,20,30], k = 1
输出：10
解释：初始 20，时刻 2 调整为 30：size = [20,20,30]，浪费 10+0+0 = 10。
```

**示例 3**

```text
输入：nums = [10,20,15,30,20], k = 2
输出：15
解释：size = [10,20,20,30,30]，浪费 0+0+5+0+10 = 15。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有「调整时刻」的组合（在 $n-1$ 个间隙位置中选 $\le k$ 个切点），每段的最优大小取段内最大值，求各段浪费之和。切点组合数 $\sum_{j\le k}\binom{n-1}{j}$，$n=200$、$k=199$ 时是天文数字。但对小 $n$ 它是完美的对拍暴力（见 §7 后说明）。另一个朴素 DP 是 $O(n^3 k)$（三重循环外再套 $k$ 层），$n=200$ 时 $1.6\times10^9$，偏慢；需要把「段内最值」预处理成表格，让转移 $O(n)$ 内完成。

### 3.2 核心观察：分段模型 + 区间 DP

![分段模型：每段大小取段内最大值，浪费 = max×len − sum](images/bw58_q3_segment_model.svg)

调整恰好发生在相邻两段的边界：**一次分段方案对应一组 size 序列**。关键事实：固定一段 $[l, r]$（不调整），该段的最优大小是 $\max(nums[l..r])$——更小装不下、更大更浪费。于是：

$$cost(l, r) = \max(nums[l..r]) \cdot (r - l + 1) - \sum_{t=l}^{r} nums[t]$$

问题变成：**把数组切成至多 $k+1$ 段，最小化各段 cost 之和**——经典的区间划分 DP（「划分型 DP」）。

用前缀和 $pre$ 与区间最值表 $mx$（$mx[l][r] = \max(nums[l..r])$，可 $O(n^2)$ 递推）把 $cost$ 做成 $O(1)$ 查询。

### 3.3 状态转移

设 $dp[j][i]$ = 前 $i$ 个数（$nums[0..i-1]$）**恰好**用 $j$ 次调整（即 $j+1$ 段）的最小总浪费：

$$dp[j][i] = \min_{t < i}\Big\{ dp[j-1][t] + cost(t, i-1) \Big\}, \qquad dp[0][i] = cost(0, i-1)$$

边界 $dp[j][0] = 0$（空前缀无浪费）。答案为 $\min_{j \le k} dp[j][n]$（「至多 $k$ 次」= 恰好 $j$ 次取最小；多调整不会更差，但取 min 稳妥且免费）。

### 3.4 示例演算

![示例 3 演算：dp 表与最优分段方案](images/bw58_q3_walkthrough.svg)

以示例 3（$nums = [10,20,15,30,20]$，$k=2$）为例。$cost$ 表（部分）：

| 段 | max | len | sum | cost |
|----|-----|-----|-----|------|
| $[10]$ | 10 | 1 | 10 | 0 |
| $[20,15]$ | 20 | 2 | 35 | 5 |
| $[30,20]$ | 30 | 2 | 50 | 10 |

$dp[2][5] = dp[1][3] + cost(3,4)$；而 $dp[1][3] = dp[0][1] + cost(1,2) = 0 + 5 = 5$（前缀 $[10]$ 一段 + $[20,15]$ 一段）。故 $dp[2][5] = 5 + 10 = 15$，与官方一致；对应分段 $[10]\,|\,[20,15]\,|\,[30,20]$，即 size 序列 $[10, 20, 20, 30, 30]$。

## 4. 算法细节

1. **段的最优大小是段内 max**：对固定段 $[l,r]$，$size$ 必须取同一值 $v \ge \max$；浪费 $= v \cdot len - sum$ 关于 $v$ 严格递增（$len>0$），故 $v = \max$ 最优。这也是「调整成任意大小」不需要枚举 $v$ 的原因。
2. **「恰好 j 次」与「至多 k 次」**：转移按恰好 $j$ 定义，最终对 $j = 0..k$ 取 min。事实上 $dp[j][n]$ 关于 $j$ 单调不增（多一次调整可复制少一次的最优解：把某段再切一刀浪费只会减不会增——严格地说可以不切，浪费不变），但直接取 min 免去论证。
3. **cost 的 O(1) 查询**：$mx[l][r] = \max(mx[l][r-1], nums[r])$ 递推 $O(n^2)$；$pre$ 前缀和 $O(n)$。转移时 $cost(t, i-1) = mx[t][i-1] \cdot (i-t) - (pre[i] - pre[t])$。
4. **数据范围与溢出**：$n \le 200$、$nums[i] \le 10^6$，中间浪费量级远超 32 位整型。实测构造（$n = 200$、前 100 个 $10^6$、后 100 个 $1$、$k = 0$）的答案为 $5049994950 \approx 5.05\times 10^9$，已超 `int`（上界 $2^{31}-1 \approx 2.15\times 10^9$）。理论上界更大：单段浪费 $\le 200 \times 10^6 = 2\times 10^8$，全体之和上界 $\sim 4\times 10^{10}$。本题 LeetCode 返回类型为 `int`（官方数据保证答案在 int 内），但**本地对拍与中间累加必须用 `long long`**，否则溢出会污染比较结果。
5. **循环边界**：$t$ 从 $j$ 到 $i-1$（前 $t$ 个数至少要容纳 $j$ 段，故 $t \ge j$；也可从 0 开始，$dp[j-1][t]$ 为 INF 时自动跳过，但显式下界更快）。
6. **k ≥ n−1 的退化**：每段长 1、浪费恒 0，DP 自然算出 0，无需特判。

## 5. 正确性证明

**引理 1（段内最优大小）**：固定段 $[l, r]$（期间不调整），最小浪费为 $\max(nums[l..r]) \cdot (r-l+1) - \sum_{t=l}^{r} nums[t]$。

**证明**：段内 $size$ 恒为某值 $v$，合法性要求 $v \ge nums[t]$ 对所有 $t \in [l,r]$，即 $v \ge M := \max(nums[l..r])$。浪费 $= \sum (v - nums[t]) = len \cdot v - sum$，是 $v$ 的严格增函数（$len \ge 1$），故 $v = M$ 时最小。∎

**引理 2（DP 覆盖所有方案）**：任何合法的 size 序列都对应唯一的「分段 + 每段取段内 max」方案，且其浪费不大于原方案。

**证明**：size 序列在时刻 $t \to t+1$ 处改变当且仅当发生一次调整（初始时刻的 size 是「初始大小」，不属于调整）。设调整时刻为 $t_1 < \dots < t_j$（$j \le k$），它们把 $[0, n)$ 切成 $j+1$ 段，每段内 size 恒定为某 $v_m \ge$ 段内 max；把每段 $v_m$ 换成段内 max 不破坏合法性（仍 $\ge nums[t]$）且浪费不增（引理 1），调整次数不变。故最优解可在「分段 + 段内 max」的形式中取到。∎

**定理**：$\min_{j \le k} dp[j][n]$ 等于最小总浪费。

**证明**：对 $j$ 与 $i$ 归纳：$dp[j][i]$ 恰是「前 $i$ 个数切成 $j+1$ 段、每段按引理 1 取最优」的最小总浪费。归纳基础 $dp[0][i] = cost(0, i-1)$ 即引理 1。归纳步：最后一段为 $[t, i-1]$ 时，前 $t$ 个数须切成 $j$ 段，最优为 $dp[j-1][t]$（归纳假设），枚举 $t$ 取 min 即转移式。由引理 2，最优解具有分段形式且每段取 max，故 $\min_{j \le k} dp[j][n]$ 覆盖所有合法方案的最小值。∎

## 6. 复杂度分析

- **时间**：$O(n^2 + k \cdot n^2)$。$mx$ 表与 $pre$ 各 $O(n^2)$ / $O(n)$；DP 三重循环（$j \le k$、$i \le n$、$t \le n$）为 $O(kn^2)$。$n = 200$、$k = 199$ 时约 $8\times 10^6$，毫秒级。实测 C++ 与 Python 均在 0.1s 内完成。
- **空间**：$O(n^2)$。$mx$ 表与 DP 表（可滚动掉 $j$ 维至 $O(n)$，但 $k \le n$ 时保留二维更清晰）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minSpaceWastedKResizing(vector<int>& nums, int k) {
        int n = nums.size();
        vector<long long> pre(n + 1, 0);
        for (int i = 0; i < n; ++i) pre[i + 1] = pre[i] + nums[i];
        vector<vector<int>> mx(n, vector<int>(n));       // mx[l][r] = max(nums[l..r])
        for (int i = 0; i < n; ++i) {
            mx[i][i] = nums[i];
            for (int j = i + 1; j < n; ++j) mx[i][j] = max(mx[i][j - 1], nums[j]);
        }
        const long long INF = LLONG_MAX / 4;
        vector<vector<long long>> dp(k + 1, vector<long long>(n + 1, INF));
        dp[0][0] = 0;
        for (int i = 1; i <= n; ++i)
            dp[0][i] = (long long)mx[0][i - 1] * i - pre[i];
        for (int j = 1; j <= k; ++j)
            for (int i = 1; i <= n; ++i)
                for (int t = j; t < i; ++t)              // 前 t 个至少要 j 段
                    dp[j][i] = min(dp[j][i], dp[j - 1][t] +
                                   (long long)mx[t][i - 1] * (i - t) - (pre[i] - pre[t]));
        long long ans = INF;
        for (int j = 0; j <= k; ++j) ans = min(ans, dp[j][n]);
        return (int)ans;
    }
};
```

### Python

```python
class Solution:
    def minSpaceWastedKResizing(self, nums: list[int], k: int) -> int:
        n = len(nums)
        pre = [0] * (n + 1)
        for i, x in enumerate(nums):
            pre[i + 1] = pre[i] + x
        mx = [[0] * n for _ in range(n)]                 # mx[l][r] = max(nums[l..r])
        for i in range(n):
            mx[i][i] = nums[i]
            for j in range(i + 1, n):
                mx[i][j] = max(mx[i][j - 1], nums[j])
        INF = float('inf')
        dp = [[INF] * (n + 1) for _ in range(k + 1)]
        dp[0][0] = 0
        for i in range(1, n + 1):
            dp[0][i] = mx[0][i - 1] * i - pre[i]
        for j in range(1, k + 1):
            for i in range(1, n + 1):
                best = INF
                for t in range(j, i):                    # 前 t 个至少要 j 段
                    cand = dp[j - 1][t] + mx[t][i - 1] * (i - t) - (pre[i] - pre[t])
                    if cand < best:
                        best = cand
                dp[j][i] = best
        return min(dp[j][n] for j in range(k + 1))
```

> 💡 两份代码均通过全部官方示例（`10`、`10`、`15`），并与「递归枚举所有分段」暴力对拍 2000 组随机数据（$n \le 12$），`mismatch = 0`；另在 $n = 200$、$k = 199$ 与 $k = 0$ 的大规模数据上做了 C++/Python 交叉验证（结果一致）。

## 8. 边界情况与易错点

1. **中间量必须 long long**：最坏总浪费理论可达 $\sim 4\times 10^{10}$（构造大 $n$、大 $nums$、$k=0$），`int` 累加会溢出比较失真。C++ 的 `dp`、`pre` 乘法项都要 `long long`。
2. **「恰好 j 次」的最终取 min**：转移按恰好 $j$ 定义，若只返回 `dp[k][n]` 可能偏大（最优解未必用满 $k$ 次——虽然本题单调不增，取 min 更稳）。
3. **初始大小不计调整**：即第一段不消耗调整名额，转移里 $dp[0][\cdot]$ 已体现（第一段从 $dp[0][0]=0$ 出发）。
4. **t 的下界**：$t \ge j$（前 $t$ 个数切成 $j$ 段需 $t \ge j$）；从 0 开始也能对（INF 挡住），但会浪费循环。
5. **k = 0 退化**：整段一个 max，$dp[0][n]$ 直接给答案；别把 `dp[0][0] = 0` 漏初始化导致 INF 传染。
6. **段长为 1 的段**：cost 恒 0（max×1 − 本身），$k \ge n-1$ 时答案 0，DP 自动覆盖。
7. **mx 表行列别写反**：$mx[t][i-1]$ 是「下标 $t..i-1$ 的 max」；递推时内层 $j$ 从 $i+1$ 起、引用 $mx[i][j-1]$，方向反了会得到错误最值。
