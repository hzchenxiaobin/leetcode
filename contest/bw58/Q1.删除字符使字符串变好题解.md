# LeetCode 删除字符使字符串变好 题解

## 1. 题目概述

- **标题 / 题号**：删除字符使字符串变好（#1957，easy）
- **链接**：https://leetcode.cn/problems/delete-characters-to-make-fancy-string/
- **来源**：LeetCode 第 58 场双周赛 Q1
- **难度**：简单
- **标签**：字符串

**题意**：没有**三个连续相同**字符的字符串称为好字符串。给定 $s$，删除最少的字符使 $s$ 变成好字符串，返回删除后的字符串。数据保证答案唯一。

**约束**：

- $1 \le s.length \le 10^5$
- $s$ 只包含小写英文字母

## 2. 示例

**示例 1**

```text
输入：s = "leeetcode"
输出："leetcode"
解释：第一组 'e' 有三个连续，删掉一个即可。
```

**示例 2**

```text
输入：s = "aaabaaaa"
输出："aabaa"
解释：第一组 'a' 删一个，第二组 'a'（四个连续）删两个。
```

**示例 3**

```text
输入：s = "aab"
输出："aab"
解释：没有三个连续相同字符，一个也不用删。
```

## 3. 解题思路

### 3.1 暴力思路

反复扫描：只要存在 `s[i] == s[i+1] == s[i+2]` 就删掉 `s[i+2]`，直到没有三连。每次删除 $O(n)$，最坏删 $n-2$ 个字符，总计 $O(n^2)$，$n = 10^5$ 时约 $10^{10}$，超时。另一种「正确但绕」的做法是按字符分段（把 $s$ 切成极大同字符游程 run），每段保留前两个、丢弃其余——这已经是 $O(n)$，但分段实现要维护边界，不如一遍扫描直接。

### 3.2 核心观察：贪心保留——每段同字符至多留两个

![游程压缩：每个同字符段至多保留前两个](images/bw58_q1_run_compress.svg)

把 $s$ 切成极大同字符游程 $r_1, r_2, \dots$。**好字符串 ⇔ 每个游程长度 $\le 2$**。要让删除数最少，就要保留数最多；显然每个长度 $\ge 3$ 的游程只能保留其中 $\le 2$ 个字符（任意三个同字符都违规），而保留**恰好两个**总是安全的（不与相邻游程冲突，因为相邻游程字符不同）。因此最优解 = 每个游程保留前两个字符。

实现上无需显式分段：顺序扫描，维护答案串 `ans`，当前字符 `c` 仅当 `ans` 末尾**不是**两个 `c` 时才追加。这就是一遍扫描的贪心。

### 3.3 算法流程

![一遍扫描流程：判定只看答案串末尾两个字符](images/bw58_q1_scan_flow.svg)

```text
1. ans ← 空
2. 对 s 中每个字符 c：
       若 len(ans) >= 2 且 ans[-1] == c 且 ans[-2] == c：
           跳过（删除 c）                    # 已有两个连续 c
       否则：
           ans 追加 c
3. 返回 ans
```

### 3.4 示例演算

以 `s = "aaabaaaa"` 为例：

| 读入 | ans 末尾 | 动作 | ans |
|------|----------|------|-----|
| a | （空） | 追加 | "a" |
| a | "a" | 追加（不足两个） | "aa" |
| a | "aa" | **跳过**（已有两个 a） | "aa" |
| b | "aa" | 追加（字符不同） | "aab" |
| a | "ab" | 追加 | "aaba" |
| a | "ba" | 追加 | "aabaa" |
| a | "aa" | **跳过** | "aabaa" |
| a | "aa" | **跳过** | "aabaa" |

结果 `"aabaa"`，删除 3 个字符，与官方一致。

## 4. 算法细节

1. **判断「末尾两个」而非「前面两个」**：新字符只可能与 ans 的**末尾**形成三连（更前面的字符早已被隔断），所以只查 `ans[-1]`、`ans[-2]`。
2. **顺序无关的正确性**：贪心按原串顺序保留，天然保持相对顺序；「保留每游程前两个」与「保留任两个」删除数相同，取前两个实现最简单。
3. **C++ 用 `push_back` 构造**：先 `reserve` 可避免扩容；不要在原串上 `erase`（$O(n^2)$）。
4. **Python 用列表 + join**：`ans.append` 后 `"".join`，比字符串 `+=` 快（虽然 CPython 会优化，列表法是稳妥习惯）。
5. **无需特判长度 < 3**：`len(ans) >= 2` 的守卫条件天然覆盖短串。

## 5. 正确性证明

**引理 1**：字符串是好字符串，当且仅当它的每个极大同字符游程长度 $\le 2$。

**证明**：若某游程长度 $\ge 3$，取其中连续三个同字符即违反定义。反之，若所有游程 $\le 2$，任何连续三个位置必然跨越游程边界，其中至少一次相邻字符不同，故不存在三个连续相同字符。∎

**引理 2（保留数上界）**：任何好子序列（保持相对顺序的删除结果）中，每个游程 $r_i$ 至多保留 2 个字符。

**证明**：子序列保持相对顺序，同一游程内保留的字符在结果中仍连续相邻（游程之间字符不同，无法插入同字符打断——精确地说：结果中若保留某游程的 $k$ 个字符，它们之间不可能夹进其他字符，因为原串里它们本来就是连续的且其他保留字符都在游程外）。若 $k \ge 3$，结果中出现三个连续同字符，违反好字符串定义。∎

**定理（贪心最优）**：算法返回的串是好字符串，且删除字符数最少。

**证明**：算法对每个游程恰好保留前两个字符（第三个同字符到达时 `ans` 末尾已是两个 `c`，必被跳过；后续同字符同理），由引理 1 结果是好字符串。删除数 $= \sum_i \max(0, |r_i| - 2)$；由引理 2，任何可行解每游程至多保留 2 个，即至少删除 $\max(0, |r_i| - 2)$ 个，与算法的删除数相等，故最优。∎

## 6. 复杂度分析

- **时间**：$O(n)$。每个字符一次比较、至多一次追加。
- **空间**：$O(n)$。答案串最坏与原串等长（无需删除时）；不计输出则 $O(1)$ 额外。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    string makeFancyString(string s) {
        string ans;
        for (char c : s) {
            int n = ans.size();
            if (n >= 2 && ans[n - 1] == c && ans[n - 2] == c) continue;   // 已有两个连续 c
            ans.push_back(c);
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def makeFancyString(self, s: str) -> str:
        ans: list[str] = []
        for c in s:
            if len(ans) >= 2 and ans[-1] == c and ans[-2] == c:
                continue                     # 已有两个连续 c，跳过
            ans.append(c)
        return "".join(ans)
```

> 💡 两份代码均通过官方示例（`"leeetcode"` → `"leetcode"`、`"aaabaaaa"` → `"aabaa"`、`"aab"` → `"aab"`），并另测了全同字符（`"aaaa"` → `"aa"`）与长度 1 的边界。

## 8. 边界情况与易错点

1. **全同字符**：`"aaaa…a"`（$10^5$ 个）应输出 `"aa"`，只保留两个；判据只看 ans 末尾，天然正确。
2. **长度 1 或 2**：无需删除，`len(ans) >= 2` 守卫保证不误删。
3. **比较对象搞错**：是和「答案串末尾两个」比较，不是和「原串前两个」比较——原串里 `aabaa` 中间的 a 与后面的 a 不构成三连，但若按原串位置判断就会错删。
4. **C++ 原地 erase 陷阱**：对 `s` 逐个 `erase` 是 $O(n^2)$，$n = 10^5$ 会超时；构造新串是正解。
5. **答案唯一性**：本题数据保证答案唯一（每游程保留前两个），无需纠结「保留哪两个」。
