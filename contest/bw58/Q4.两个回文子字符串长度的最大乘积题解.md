# LeetCode 两个回文子字符串长度的最大乘积 题解

## 1. 题目概述

- **标题 / 题号**：两个回文子字符串长度的最大乘积（#1960，hard）
- **链接**：https://leetcode.cn/problems/maximum-product-of-the-length-of-two-palindromic-substrings/
- **来源**：LeetCode 第 58 场双周赛 Q4
- **难度**：困难
- **标签**：字符串、Manacher 算法、双指针、滚动哈希

**题意**：给定下标从 $0$ 开始的字符串 $s$，选出四个整数 $i \le j < k \le l$，使子串 $s[i..j]$ 与 $s[k..l]$ 都是**奇数长度**的回文串且二者不重叠（$j < k$），最大化两段长度之积。返回最大乘积。保证 $|s| \ge 2$。

**约束**：

- $2 \le s.length \le 10^5$
- $s$ 只包含小写英文字母

## 2. 示例

**示例 1**

```text
输入：s = "ababbb"
输出：9
解释："aba"（长 3）与 "bbb"（长 3）不重叠，乘积 9。
```

**示例 2**

```text
输入：s = "zaaaxbbby"
输出：9
解释："aaa" 与 "bbb" 各长 3，乘积 9。
```

## 3. 解题思路

### 3.1 暴力思路

$O(n^2)$ 打回文表 `isPal[i][j]`，再枚举所有奇数长度回文对——总计 $O(n^2)$ 状态 + $O(n^2)$ 枚举对，$n = 10^5$ 时空间就先爆（$10^{10}$ 布尔）。即便用中心扩展把「每个位置的最长回文」压到 $O(n^2)$ 时间、$O(n)$ 空间，枚举分割点与两侧最优的组合仍需仔细的预处理。本题的正解是 **Manacher 线性求出所有中心的最长奇回文**，再从回文区间端点出发做两次「覆盖式最值传播」，最后枚举分割点。

### 3.2 核心观察：Manacher 半径 → 每个起点/终点的最长奇回文

![Manacher 半径转化为 startLen / endLen 的桶传播](images/bw58_q4_manacher_model.svg)

**第一步：Manacher 奇半径**。$d1[c]$ = 以 $c$ 为中心的**奇**回文半径（回文区间 $[c - d1[c] + 1,\ c + d1[c] - 1]$，长度 $2d1[c] - 1$）。标准 Manacher $O(n)$ 求出。

**第二步：每个起点/终点的最长奇回文**。定义：

- $startLen[i]$：以 $i$ 为**左端点**的最长奇回文长度；
- $endLen[i]$：以 $i$ 为**右端点**的最长奇回文长度。

直接枚举中心再滑动是 $O(n^2)$ 的；标准技巧是**桶 + 前后缀传播**。对 $startLen$：中心 $c$ 的回文左端点为 $lo(c) = c - d1[c] + 1$。在位置 $lo$ 处记录「以该处开头的回文的最远中心」，即 $bucket[lo] = \max(bucket[lo], c)$；随后从左到右扫，$best[i] = \max(best[i-1], bucket[i])$，则 $startLen[i] = 2(best[i] - i) + 1$——因为 $best[i]$ 是所有 $lo \le i$ 的中心中最大者，其回文覆盖 $i$ 开头向右延伸至 $2 \cdot best[i] - i$，长度恰为 $2(best[i] - i) + 1$（注意 $best[i] \ge i$ 恒成立：中心 $i$ 自身半径 $\ge 1$ 保证了 $bucket[i] \ge i$ 的传播）。$endLen$ 对称：$bucket2[hi(c)] = \min(\dots, c)$，从右到左传播，$endLen[i] = 2(i - best2[i]) + 1$。

> ⚠️ 注意传播的正确性依赖「短回文被长回文覆盖」的传递：若中心 $c$ 的回文从 $lo(c) \le i$ 开头，且另有一中心 $c' > c$ 的回文同样覆盖 $i$ 开头，传播后的 $best[i]$ 取最大中心，其回文必然也以 $\le i$ 开头且更长吗？——不一定「以 $\le i$ 开头」，但**以 $best[i]$ 为中心、$i$ 为左端的奇回文确实存在**：因为 $best$ 来自某个 $lo(c') \le i$ 的中心 $c'$，它的回文区间 $[lo(c'), 2c' - lo(c')] \supseteq$ 以 $i$ 开头的子区间吗？非也——这里正是本题最精妙处，见 §5 引理 2 的证明：**若 $lo(c') \le i \le c'$，则以 $i$ 开头、中心 $c'$、长度 $2(c'-i)+1$ 的串是 $c'$ 回文的「后缀镜像」，仍是回文**。传播取最大中心保证 $best[i] \ge i$（桶里中心 $i$ 自身贡献 $bucket[i] \ge i$），于是 $i \le best$ 成立、引理适用。

**第三步：枚举分割点**。左段必须在 $[0, m]$ 内、右段在 $[m+1, n-1]$ 内（$m$ 为分割下标）。记：

$$pre[m] = \max_{i \le m} endLen[i], \qquad suf[m] = \max_{i \ge m} startLen[i]$$

答案 $= \max_{0 \le m < n-1} pre[m] \times suf[m+1]$。$pre$、$suf$ 各一次线性扫描。

### 3.3 算法流程

```text
1. Manacher 求 d1[0..n-1]（奇半径）
2. bucket[lo] = max(中心)：lo = c − d1[c] + 1
   从左到右：best[i] = max(best[i-1], bucket[i])
   startLen[i] = 2(best[i] − i) + 1
3. bucket2[hi] = min(中心)：hi = c + d1[c] − 1
   从右到左：best2[i] = min(best2[i+1], bucket2[i])
   endLen[i] = 2(i − best2[i]) + 1
4. pre[m] = max(pre[m-1], endLen[m])        （前缀最值）
   suf[m] = max(suf[m+1], startLen[m])      （后缀最值）
5. 答案 = max(pre[m] × suf[m+1])  对 m = 0..n-2
```

### 3.4 示例演算

![示例 ababbb 演算：d1、startLen、endLen 与分割点枚举](images/bw58_q4_walkthrough.svg)

以 $s = $ `ababbb`（$n=6$）为例。Manacher 求得 $d1 = [1,2,2,1,2,1]$，各中心的回文区间：

| 中心 $c$ | 0 | 1 | 2 | 3 | 4 | 5 |
|---------|---|---|---|---|---|---|
| 回文区间 | $[0,0]$ | $[0,2]$ | $[1,3]$ | $[3,3]$ | $[3,5]$ | $[5,5]$ |
| 回文串 | a | aba | bab | b | bbb | b |

桶传播后：

- $startLen = [3, 3, 1, 3, 1, 1]$：位置 0 开头最长 `aba`（中心 1）、位置 1 开头最长 `bab`（中心 2）、位置 3 开头最长 `bbb`（中心 4）；
- $endLen = [1, 1, 3, 3, 1, 3]$：位置 2 结尾最长 `aba`（中心 1）、位置 3 结尾最长 `bab`（中心 2）、位置 5 结尾最长 `bbb`（中心 4）。

枚举分割点 $m$：

| $m$ | $pre[m]$（左半最长结尾回文） | $suf[m+1]$（右半最长开头回文） | 乘积 |
|-----|------|------|------|
| 0 | 1 | 3 | 3 |
| 1 | 1 | 3 | 3 |
| 2 | 3 | 3 | **9** |
| 3 | 3 | 1 | 3 |
| 4 | 3 | 1 | 3 |

最大乘积 $9$：$m=2$ 时左半取结尾于 2 的 `aba`（区间 $[0,2]$，长 3），右半取开头于 3 的 `bbb`（区间 $[3,5]$，长 3），恰好不重叠，与官方答案一致。

## 4. 算法细节

1. **Manacher 只需奇半径 $d1$**：题目限定奇数长度，$d2$（偶半径）用不上；标准模板里两段循环只保留 $d1$ 段。
2. **$d1[c]$ 的语义**：半径含中心，回文长度 $2d1[c] - 1$，左端 $c - d1[c] + 1$、右端 $c + d1[c] - 1$。三个换算贯穿全题，写错一个全盘皆错。
3. **桶传播的两个方向**：$startLen$ 用「按左端点入桶、取最大中心、从左往右传播 max」；$endLen$ 用「按右端点入桶、取最小中心、从右往左传播 min」。方向搞反会得到 $best < i$ 之类的非法状态。
4. **为什么取 max/min 中心就够**：以 $startLen$ 为例，$best[i]$ 是覆盖 $i$ 为起点的「最靠右中心」；引理 2 说明以 $i$ 开头、$best[i]$ 为中心的回文长度 $2(best[i]-i)+1$ 合法且是最大（任何以 $i$ 开头的奇回文的中心 $c$ 满足 $c \ge i$ 且 $lo(c) \le i$，被桶传播纳入，故 $best[i] \ge c$ 隐含长度不小于 $2(c-i)+1$？——精确论证见 §5）。
5. **long long**：$n = 10^5$ 时单段长可达 $n$，乘积上界 $(n/2)^2 = 2.5 \times 10^9$，**超 int**（实测全 `a` 串答案 $2499999999$）。C++ 用 `long long`；Python 无虞。
6. **乘积在 $n \ge 2$ 时非零**：任何单字符都是奇回文，$pre[m] \ge 1$、$suf[m+1] \ge 1$，无需特判空段。
7. **d1 求法（两循环 Manacher）**：维护当前最右回文 $[l, r]$，新中心 $i$ 在 $r$ 内时初始化 $k = \min(d1[l+r-i], r - i + 1)$，再暴力扩展。这是标准写法，保证线性。

## 5. 正确性证明

**引理 1（Manacher 正确性）**：算法求得的 $d1[c]$ 等于以 $c$ 为中心的最长奇回文半径。

**证明**：标准结论。关键在于镜像初始化 $k = \min(d1[l+r-i], r-i+1)$ 不越界也不漏：若 $d1[l+r-i] < r - i + 1$，由 $[l, r]$ 的回文对称性，以 $i$ 为中心的回文半径与镜像点相同且无法立即扩展（否则镜像点也可扩展，与 $d1$ 最大性矛盾）；否则从 $r - i + 1$ 起继续暴力扩展。每步扩展使 $r$ 严格右移，总扩展次数 $\le n$，线性。∎

**引理 2（起点回文刻画）**：对任意 $i \le c$，若以 $c$ 为中心的回文左端 $lo(c) \le i$，则以 $i$ 为左端、$c$ 为中心的子串 $s[i..2c-i]$ 是回文，长 $2(c-i)+1$；且以 $i$ 为左端的最长奇回文长度 $startLen[i] = 2(best[i] - i) + 1$，其中 $best[i] = \max\{c : lo(c) \le i\}$（按桶传播定义）。

**证明**：先证前半。设 $c$ 的回文区间 $[lo, hi]$（$lo \le i \le c \le hi$）。子串 $s[i..2c-i]$ 关于中心 $c$ 对称：其左半 $s[i..c]$ 与右半 $s[c+1..2c-i]$ 互为镜像。由 $[lo, hi]$ 整体回文，位置 $lo + hi - x$ 与 $x$ 处字符相同；对 $x \in [i, 2c-i]$，$lo + hi - x \in [2c - (2c-i), \dots] \subseteq [lo, hi]$ 也落在该回文内，且 $x \mapsto 2c - x$ 是中心对称——而 $s[i..2c-i]$ 自身中心对称即回文（回文的子串若与中心对齐则仍是回文：因为对任意 $x \in [i, 2c-i]$，$s[x] = s[2c - x]$ 直接由 $c$ 回文性给出，且 $2c - x \in [i, 2c-i]$）。故 $s[i..2c-i]$ 回文。再证 $startLen$ 公式。一方面 $best[i]$ 对应某中心 $c^* = best[i]$，$lo(c^*) \le i$，由前半以 $i$ 开头存在长 $2(c^* - i) + 1$ 的回文，故 $startLen[i] \ge 2(best[i]-i)+1$。注意 $bucket[i] \ge i$（中心 $i$ 自身 $lo = i$ 入桶）保证 $best[i] \ge i$，长度为正奇数。另一方面，设以 $i$ 开头的最长奇回文长 $L$、中心 $c_L = i + (L-1)/2 \ge i$，则 $lo(c_L) = 2c_L - (i + L - 1) \le i$？由 $lo(c_L) = c_L - d1[c_L] + 1 \le i$（该回文以 $i$ 开头，$d1[c_L] \ge (L+1)/2$，故 $lo \le i$），于是 $c_L$ 入桶于 $lo \le i$ 处，传播后 $best[i] \ge c_L$，得 $startLen[i] = 2(best[i]-i)+1 \ge 2(c_L - i)+1 = L$。两个不等式合并即等式。∎

**引理 3（对称结论）**：$endLen[i] = 2(i - best2[i]) + 1$，$best2[i] = \min\{c : hi(c) \ge i\}$，论证与引理 2 镜像对称。∎

**定理（分割点枚举完备）**：最优解 $(s[i_1..j_1], s[k_1..l_1])$（$j_1 < k_1$）的乘积等于 $\max_m pre[m] \times suf[m+1]$。

**证明**：取 $m = j_1$：左段以 $j_1$ 结尾、长 $L_1$，故 $pre[j_1] \ge endLen[j_1] \ge L_1$；右段以 $k_1 \ge j_1 + 1$ 开头、长 $L_2$，故 $suf[j_1+1] \ge startLen[k_1] \ge L_2$（后缀最值覆盖所有起点 $\ge m+1$）。于是 $pre[j_1] \times suf[j_1+1] \ge L_1 L_2$，即枚举最大值不小于最优。反之，任意 $m$ 处 $pre[m] \times suf[m+1]$ 对应的实际回文对（取达到最值的下标）满足「左段结尾 $\le m$ < 右段开头 $\ge m+1$」，即不重叠的合法对，故枚举值均可达到，枚举最大值不大于最优。二者相等。∎

**推论**：算法输出即最大乘积。∎

## 6. 复杂度分析

- **时间**：$O(n)$。Manacher 线性（均摊：$r$ 只右移）；两次桶传播、两次前后缀最值、一次分割点枚举各 $O(n)$。$n = 10^5$ 实测 C++ 0.01s、Python 0.15s。
- **空间**：$O(n)$。$d1$、两个桶、$startLen$ / $endLen$、$pre$ / $suf$ 各一个长度 $n$ 数组。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long maxProduct(string s) {
        int n = s.size();
        // Manacher：d1[c] = 以 c 为中心的奇回文半径，回文区间 [c-d1[c]+1, c+d1[c]-1]
        vector<int> d1(n);
        for (int i = 0, l = 0, r = -1; i < n; ++i) {
            int k = (i > r) ? 1 : min(d1[l + r - i], r - i + 1);
            while (0 <= i - k && i + k < n && s[i - k] == s[i + k]) ++k;
            d1[i] = k--;
            if (i + k > r) { l = i - k; r = i + k; }
        }
        // startLen[i]：以 i 开头的最长奇回文长度
        vector<int> bucket(n, -1);
        for (int c = 0; c < n; ++c) {
            int lo = c - d1[c] + 1;
            bucket[lo] = max(bucket[lo], c);
        }
        vector<long long> startLen(n), endLen(n);
        int best = -1;
        for (int i = 0; i < n; ++i) {
            best = max(best, bucket[i]);            // 恒有 best >= i（中心 i 自身）
            startLen[i] = 2LL * (best - i) + 1;
        }
        // endLen[i]：以 i 结尾的最长奇回文长度
        vector<int> bucket2(n, n);
        for (int c = 0; c < n; ++c) {
            int hi = c + d1[c] - 1;
            bucket2[hi] = min(bucket2[hi], c);
        }
        int best2 = n;
        for (int i = n - 1; i >= 0; --i) {
            best2 = min(best2, bucket2[i]);         // 恒有 best2 <= i
            endLen[i] = 2LL * (i - best2) + 1;
        }
        // 前缀/后缀最值 + 枚举分割点
        long long ans = 0;
        vector<long long> pre(n), suf(n);
        pre[0] = endLen[0];
        for (int i = 1; i < n; ++i) pre[i] = max(pre[i - 1], endLen[i]);
        suf[n - 1] = startLen[n - 1];
        for (int i = n - 2; i >= 0; --i) suf[i] = max(suf[i + 1], startLen[i]);
        for (int i = 0; i + 1 < n; ++i)
            ans = max(ans, pre[i] * suf[i + 1]);
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maxProduct(self, s: str) -> int:
        n = len(s)
        # Manacher：d1[c] = 以 c 为中心的奇回文半径
        d1 = [0] * n
        l, r = 0, -1
        for i in range(n):
            k = 1 if i > r else min(d1[l + r - i], r - i + 1)
            while 0 <= i - k and i + k < n and s[i - k] == s[i + k]:
                k += 1
            d1[i] = k
            if i + k - 1 > r:
                l, r = i - k + 1, i + k - 1
        # startLen[i]：以 i 开头的最长奇回文长度
        bucket = [-1] * n
        for c in range(n):
            lo = c - d1[c] + 1
            bucket[lo] = max(bucket[lo], c)
        start_len = [0] * n
        best = -1
        for i in range(n):
            best = max(best, bucket[i])            # 恒有 best >= i
            start_len[i] = 2 * (best - i) + 1
        # endLen[i]：以 i 结尾的最长奇回文长度
        bucket2 = [n] * n
        for c in range(n):
            hi = c + d1[c] - 1
            bucket2[hi] = min(bucket2[hi], c)
        end_len = [0] * n
        best2 = n
        for i in range(n - 1, -1, -1):
            best2 = min(best2, bucket2[i])         # 恒有 best2 <= i
            end_len[i] = 2 * (i - best2) + 1
        # 前缀/后缀最值 + 枚举分割点
        pre = [0] * n
        pre[0] = end_len[0]
        for i in range(1, n):
            pre[i] = max(pre[i - 1], end_len[i])
        suf = [0] * n
        suf[n - 1] = start_len[n - 1]
        for i in range(n - 2, -1, -1):
            suf[i] = max(suf[i + 1], start_len[i])
        return max(pre[i] * suf[i + 1] for i in range(n - 1))
```

> 💡 两份代码均通过官方示例（`ababbb` → 9、`zaaaxbbby` → 9），并与两个独立暴力对拍：①「$O(n^2)$ 回文打表 + 前后缀最值」对拍 2500 组随机串（字母表 2/3/5，$n \le 30$）；②「全对枚举所有奇回文对」的 $O(n^4)$ 暴力对拍 400 组（$n \le 14$），均 `mismatch = 0`。另在 $n = 10^5$ 的全 `a` 串（答案 $2499999999$，实证 `long long` 必要）与随机串上做了 C++/Python 交叉验证。

## 8. 边界情况与易错点

1. **乘积溢出 int**：全 `a`、$n = 10^5$ 时答案 $\lfloor n/2 \rfloor \times \lceil n/2 \rceil = 49999 \times 50001 = 2499999999 > 2^{31} - 1$。C++ 的中间 `pre[i] * suf[i+1]` 必须在 `long long` 域相乘（数组直接声明 `long long` 最稳）；返回类型本题就是 `long long`。
2. **Manacher 边界更新**：扩展后 `l, r` 要更新为 `i-k+1, i+k-1`（`k` 已自减或相应换算），写错会让镜像初始化失效、退化为 $O(n^2)$ 甚至答案错误。
3. **桶传播方向**：$startLen$ 从左到右取 **max** 中心；$endLen$ 从右到左取 **min** 中心。方向或 max/min 搞反，`best - i` 可能为负或非最优。
4. **`best[i] >= i` 的保证**：中心 $i$ 自身（半径 1）在 $bucket[i]$ 入桶 $i$，传播链保证不减；若漏掉这一自贡献，孤立位置会得到 `best < i` 的非法长度。
5. **分割点枚举范围**：$m$ 从 $0$ 到 $n-2$（右半至少一个字符）；`suf[m+1]` 下标别越界。
6. **只枚举奇数长度**：偶回文一律非法；Manacher 的 $d2$ 段不要顺手写上再用错。
7. **别把 `startLen` / `endLen` 混用**：$pre$ 用 $endLen$（左段看结尾），$suf$ 用 $startLen$（右段看开头），交叉使用会静默出错（对拍才能发现）。

- [LeetCode 647. 回文子串个数](https://leetcode.cn/problems/palindromic-substrings/)：统计所有中心回文数，$d1 + d2$ 求和。
- [LeetCode 214. 最短回文串](https://leetcode.cn/problems/shortest-palindrome/)：Manacher 求前缀回文，与本题 `endLen` 同源。
- [LeetCode 1960. 两个回文子字符串长度的最大乘积](https://leetcode.cn/problems/maximum-product-of-the-length-of-two-palindromic-substrings/)：本题本体。

**延伸思考**：本题的「桶 + 传播」是把「每个起点的最长回文」从 $O(n^2)$ 压到 $O(n)$ 的关键，本质是利用了回文的**中心对称性**（引理 2）：长回文内部任何对齐中心的子串仍是回文。同样的思想可以把「每个位置作为端点的最长回文」推广到偶数长度（用 $d2$ 做两个对称的桶传播）。若把「两个不重叠回文」改成「$k$ 个不重叠回文长度之和最大」，可以DP：$f[i][j]$ = 前 $i$ 个字符切出 $j$ 个不重叠回文的最长总长，转移用 $endLen$ 前缀最值，复杂度 $O(nk)$——这是「划分型 DP」与「回文结构」的组合拳。另一个方向是回文树（Eertree），它能线性枚举所有**本质不同**回文，适合去重统计类问题。
