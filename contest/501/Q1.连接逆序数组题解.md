# LeetCode 连接逆序数组 题解

## 1. 题目概述

- **标题 / 题号**：连接逆序数组（#3925，easy）
- **链接**：https://leetcode.cn/problems/concatenate-array-with-reverse/
- **来源**：LeetCode 第 501 场周赛 Q1
- **难度**：简单
- **标签**：数组、模拟

**题意**：给定长度为 $n$ 的整数数组 $nums$，构造长度为 $2n$ 的新数组 $ans$：**前 $n$ 个元素照抄** $nums$（$ans[i] = nums[i]$），**后 $n$ 个元素为 $nums$ 的逆序**（$ans[i+n] = nums[n-1-i]$），两个映射对一切 $0 \le i \le n-1$ 成立。返回 $ans$。

**约束**：

- $1 \le nums.length \le 100$
- $1 \le nums[i] \le 100$

> 💡 **审题关键**：这是一道纯下标映射的签到题。唯二要弄清的是：后半第 $i$ 个位置对应**全局下标** $i+n$，取值来自 $nums[n-1-i]$（**倒数第** $i+1$ **个元素**）；并且是「逆序**抄写**到新数组」，**不是**把前半原地反转。

## 2. 示例

**示例 1**

```text
输入：nums = [1,2,3]
输出：[1,2,3,3,2,1]
解释：前 3 个元素与 nums 相同；后 3 个元素按 nums 的逆序填入：
     ans[3] = nums[2] = 3，ans[4] = nums[1] = 2，ans[5] = nums[0] = 1。
```

**示例 2**

```text
输入：nums = [1]
输出：[1,1]
解释：长度为 1 的数组逆序后保持不变，前后两半都是 [1]。
```

**示例 3**

```text
输入：nums = [2,4,6,8]
输出：[2,4,6,8,8,6,4,2]
解释：n = 4 时后半从下标 4 开始：ans[4]=nums[3]=8，ans[5]=nums[2]=6，
     ans[6]=nums[1]=4，ans[7]=nums[0]=2。答案整体回文。
```

## 3. 解题思路

### 3.1 暴力思路

最朴素的做法分两趟：先把 $nums$ 整个复制进 $ans$ 的前半，再**倒序**遍历 $nums$ 逐个追加到尾部。时间 $O(n)$、额外空间 $O(1)$——复杂度上这已经是最优，$n \le 100$ 怎么写都能过。签到题的优化空间不在复杂度，而在「从题面到代码的**最短路径**」：观察两个下标映射 $ans[i] = nums[i]$ 与 $ans[i+n] = nums[n-1-i]$，它们**都只由同一个循环变量 $i$ 决定**——第二趟的倒序遍历完全可以并进第一趟。

### 3.2 核心观察：两个映射共享同一个循环变量

![一趟循环两个映射概念图](images/wc501_q1_mirror_mapping.svg)

**观察一（一轮填两格）**。对每个 $0 \le i \le n-1$，用同一个 $i$ 同时执行两个赋值：左半第 $i$ 格照抄 $nums[i]$，右半第 $i$ 格（全局位置 $i+n$）取 $nums[n-1-i]$。一趟循环、每轮两个赋值，前后两半**同时**填满。

**观察二（镜像位）**。位置 $j$ 与 $2n-1-j$ 关于**中缝**对称——两者下标之和恒为 $2n-1$。主写法一轮填位置 $i$ 与 $i+n$，写入的值 $nums[i]$ 与 $nums[n-1-i]$ 各自还会出现在自己的镜像位上（$nums[i]$ 同时落在位置 $i$ 与 $2n-1-i$）。由此得到**双指针**等价写法：$l=0$、$r=2n-1$，每轮直接填一对镜像位 $ans[l] = ans[r] = nums[i]$，随后 $l{+}{+}$、$r{-}{-}$、$i{+}{+}$——与主写法覆盖同样的位置、写入同样的值，只是「配对方式」不同（见 §5 引理 3）。

**观察三（答案必为回文）**。由构造直接可得 $ans[i] = ans[2n-1-i]$——整个 $ans$ 是**回文数组**（示例 1 的 `1,2,3,3,2,1` 正读反读一致）。这个性质与实现无关，可以当**自检断言**：写完后验证对称位置相等，即可确认后半没有填错方向。

> 💡 **一句话总结**：一趟循环，每个 $i$ 同时写 $ans[i]$（照抄）与 $ans[i+n]$（镜像取 $nums[n-1-i]$）；答案天然回文，可用对称性自检。

### 3.3 算法流程

![算法流程图](images/wc501_q1_algorithm_flow.svg)

1. 新建长度 $2n$ 的数组 $ans$（预先开好，不逐个 `push_back`）。
2. 循环变量 $i$ 从 $0$ 到 $n-1$，每轮执行两个赋值：$ans[i] = nums[i]$、$ans[i+n] = nums[n-1-i]$。
3. $n$ 轮结束后 $2n$ 个格子全部填满，返回 $ans$。

### 3.4 示例演算

![示例演算走查](images/wc501_q1_walkthrough.svg)

以 $nums = [1,2,3]$（$n = 3$）为例：

| 轮次 $i$ | $ans[i] = nums[i]$ | $ans[i+n] = nums[n-1-i]$ | $ans$ 当前状态 |
|---------|--------------------|--------------------------|----------------|
| $i=0$ | $ans[0] = 1$ | $ans[3] = nums[2] = 3$ | `[1, _, _, 3, _, _]` |
| $i=1$ | $ans[1] = 2$ | $ans[4] = nums[1] = 2$ | `[1, 2, _, 3, 2, _]` |
| $i=2$ | $ans[2] = 3$ | $ans[5] = nums[0] = 1$ | `[1, 2, 3, 3, 2, 1]` ✓ |

边界 $n=1$：唯一一轮 $i=0$ 填 $ans[0] = ans[1] = nums[0]$，得 `[1,1]`——单元素数组逆序不变，前后两半相同，统一映射天然覆盖，**零特判**。

## 4. 算法细节

1. **预先开好 $2n$ 再按下标写入**：C++ 用 `vector<int> ans(2 * n)`，Python 用 `[0] * (2 * n)`。比逐个 `push_back` / `append` 更直白，也免去讨论容量增长。
2. **镜像下标的现场推导**：后半第 $i$ 个位置是全局下标 $i+n$；「逆序」意味着它取 $nums$ 的**倒数第** $i+1$ 个元素，其下标为 $n - (i+1) = n-1-i$。**自查法**：代入 $i=0$，应取到 $nums[n-1]$（最后一个元素），与示例 1 的 $ans[n] = nums[n-1]$ 一致。
3. **双指针等价写法**：$l=0$、$r=2n-1$、$i=0$，每轮 $ans[l] = ans[r] = nums[i]$，然后 $l{+}{+}$、$r{-}{-}$、$i{+}{+}$。与主写法覆盖相同的位置集合、写入相同的值，只是配对方式不同（见 §5 引理 3），可用于交叉验证。
4. **回文断言自检**：调试期加一行 `assert(ans[i] == ans[2*n-1-i])`，能立刻暴露「后半填错方向」类笔误（比如误写成 $nums[n-i]$）。
5. **Python 惯用一行式**：`return nums + nums[::-1]`——切片产生逆序副本，`+` 拼接两段，语义与题意逐字对应；与显式循环同为 $O(n)$，只是多一份 $n$ 大小的临时副本。

## 5. 正确性证明

**引理 1（覆盖性）**：当 $i$ 取遍 $0, 1, \dots, n-1$ 时，算法写入的位置集合为 $\{0,\dots,n-1\} \cup \{n,\dots,2n-1\} = \{0,\dots,2n-1\}$，每个位置**恰好被写一次**。

**证明**：左半写入位置 $i$ 遍历 $[0, n-1]$ 内全部整数，右半写入位置 $i+n$ 遍历 $[n, 2n-1]$ 内全部整数；两区间不相交且并集为 $[0, 2n-1]$，故 $2n$ 个位置无重复、无遗漏地各被赋值一次。∎

**引理 2（取值正确）**：算法执行后，对一切 $0 \le i \le n-1$ 有 $ans[i] = nums[i]$ 且 $ans[i+n] = nums[n-1-i]$。

**证明**：循环体只有两个赋值语句，即这两个等式本身；由引理 1，每个位置只被写一次，不存在后续覆盖，故终态保持等式成立。∎

**引理 3（双指针写法等价）**：双指针循环每轮开始时恒有 $l = i$ 且 $r = 2n-1-i$；循环结束后对一切 $0 \le i \le n-1$ 有 $ans[i] = nums[i]$ 且 $ans[2n-1-i] = nums[i]$，输出与主算法一致。

**证明**：对轮数归纳证明不变量：初始 $l=0=i$、$r=2n-1=2n-1-0$ 成立；若某轮开始时成立，轮末 $l' = i+1$、$r' = 2n-1-(i+1)$、$i' = i+1$，命题传递。由该不变量，每轮写入位置 $i$ 与 $2n-1-i$、值均为 $nums[i]$；$i$ 取遍 $[0, n-1]$ 时这两个位置集合仍是 $[0, n-1]$ 与 $[n, 2n-1]$（后者因 $2n-1-i$ 随 $i$ 取遍 $[n, 2n-1]$），无重无漏。特别地，对 $j \ge n$ 有 $ans[j] = nums[2n-1-j]$，与题目定义的后半取值一致。∎

**定理**：算法返回的 $ans$ 恰为题目所定义的唯一数组。

**证明**：题目对 $ans$ 的每个下标处的取值都有明确定义（前半 $ans[i]=nums[i]$；后半以下标 $j \ge n$ 记，令 $i = j-n \in [0, n-1]$，则 $ans[j] = nums[n-1-i] = nums[2n-1-j]$），故所求数组唯一。由引理 1，算法对全部 $2n$ 个位置各赋值一次；由引理 2，每次赋的值与题目定义逐下标一致。因此返回值与所求数组逐下标相等。∎

**推论（回文性）**：返回的 $ans$ 满足 $ans[i] = ans[2n-1-i]$ 对一切 $0 \le i \le 2n-1$ 成立。

**证明**：不妨设 $i \le n-1$（否则对称交换 $i \leftrightarrow 2n-1-i$）。则 $2n-1-i \ge n$，由定理的取值规则：$ans[i] = nums[i]$，$ans[2n-1-i] = nums[2n-1-(2n-1-i)] = nums[i]$，两者相等。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。单趟循环 $n$ 轮，每轮两个 $O(1)$ 赋值，共 $2n$ 次写入；读题面、读输入的代价不计。
- **空间复杂度**：$O(1)$ **额外空间**（输出数组按惯例不计入）。输出本身占 $O(n)$——题目要求返回 $2n$ 数组，不可避免。Python 一行式 `nums + nums[::-1]` 中 `nums[::-1]` 会额外产生一份 $n$ 大小的逆序副本，仍在同一量级。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> concatWithReverse(vector<int>& nums) {
        int n = nums.size();
        vector<int> ans(2 * n);
        for (int i = 0; i < n; i++) {
            ans[i] = nums[i];              // 左半：原序照抄
            ans[i + n] = nums[n - 1 - i];  // 右半：镜像逆序
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def concatWithReverse(self, nums: list[int]) -> list[int]:
        n = len(nums)
        ans = [0] * (2 * n)
        for i in range(n):
            ans[i] = nums[i]
            ans[i + n] = nums[n - 1 - i]
        return ans
```

> 💡 **双指针变体（结果与主写法完全一致，见 §5 引理 3）**：
>
> ```python
> class Solution:
>     def concatWithReverse(self, nums: list[int]) -> list[int]:
>         n = len(nums)
>         ans = [0] * (2 * n)
>         l, r = 0, 2 * n - 1
>         for x in nums:
>             ans[l] = ans[r] = x
>             l += 1
>             r -= 1
>         return ans
> ```
>
> 以及语义与题意逐字对应的切片一行式：`return nums + nums[::-1]`。

## 8. 边界情况与易错点

1. **`n - 1 - i` 误写成 `n - i`（最高频笔误）**：代入 $i=0$ 自查——应取 $nums[n-1]$（最后一个元素），写成 `n - i` 会取到 $nums[n]$（越界）或思路直接错位。同理右半起点是全局下标 $n$，别与「前半最后一格 $n-1$」混淆。
2. **`ans` 长度忘开 $2n$**：预开 `vector<int> ans(2 * n)` / `[0] * (2 * n)`，开成 $n$ 会越界；若用 `push_back` 追加则无此问题，但要保证追加的是**倒序**元素。
3. **误解题意为「原地反转前半再拼接」**：题目是构造**新数组**、前半原样照抄，没有任何原地操作；把前半反转了就全错了。
4. **$n = 1$ 边界**：唯一一轮 $i=0$ 填 $ans[0] = ans[1] = nums[0]$，统一映射天然覆盖，**无需特判**。
5. **双指针变体三步缺一不可**：`l += 1`、`r -= 1` 与循环推进（`i` 或 `for x`）都要动，漏掉推进会把同一个值填满整行。
6. **溢出**：$n \le 100$、元素值 $\le 100$，下标与值都远在任何整型范围内，无需考虑。
7. **回文自检**：正确实现必满足 $ans[i] = ans[2n-1-i]$；调试期加断言可快速定位「后半方向填反」类错误。

**延伸思考**：

- **多段拼接推广**：若要求 $ans$ = $nums$ 拼其逆序再拼 $nums$（长度 $3n$），映射仍是「一个循环变量驱动多个位置」，只是写入位置变成 $i$、$i+n$、$2n+i$。
- **原地扩展版**：若允许在 $nums$ 自身容量上扩展（容量 $\ge 2n$），倒序遍历追加即可：`for i in range(n - 1, -1, -1): nums.append(nums[i])`——注意必须**倒序**追加，正序追加得到的是原序副本。
- **流式版**：若 $n$ 极大且结果只需流式消费，可用生成器先产出 $nums$ 再产出其逆序，额外空间除输入外 $O(1)$。
- **自检方法论**：「构造题找不变量」——本题的不变量是回文性 $ans[i] = ans[2n-1-i]$，任何正确实现都满足；把不变量写成断言是最便宜的测试。
