# LeetCode 根据二叉树创建字符串 题解

## 1. 题目概述

- **标题 / 题号**：根据二叉树创建字符串（#606，medium）
- **链接**：https://leetcode.cn/problems/construct-string-from-binary-tree/
- **来源**：LeetCode 第 35 场周赛 Q2
- **难度**：中等
- **标签**：树，深度优先搜索，字符串，二叉树

**题意**：把一棵二叉树序列化成字符串，规则基于**前序遍历**：每个节点先写自己的值；若它有孩子，就把孩子「套在括号里」——左孩子一组括号在前，右孩子一组括号在后。所有**可省略的空括号对** `()` 都要省略，唯一例外是「**左孩子为空、右孩子存在**」时必须保留一对 `()` 顶住左孩子的位置，否则无法恢复原树结构。返回这棵树的字符串表示。

**约束**：

- 节点数量范围 $[1, 10^4]$
- $-1000 \le \text{Node.val} \le 1000$，即每个值最多 5 个字符（含负号）
- 树不保证平衡，最坏是一条 $10^4$ 个节点的单链（深度 $10^4$）

## 2. 示例

**示例 1**

```text
输入：root = [1,2,3,4]
输出："1(2(4))(3)"
解释：完整形式是 1(2(4)())(3()())，其中 2 的右槽、3 的两个孩子槽都是空的，
      可以全部省略，得到 1(2(4))(3)。
```

**示例 2**

```text
输入：root = [1,2,3,null,4]
输出："1(2()(4))(3)"
解释：2 没有左孩子但有右孩子 4。若把 2 后面的 () 也省略，
      2(4) 会被读成「2 只有左孩子 4」，结构就错了，所以这一对必须保留。
```

**补充示例（边界）**

```text
输入：root = [1]
输出："1"
解释：叶子节点没有任何孩子，不写括号；写成 "1()" 就是多余的空括号对。
```

## 3. 解题思路

### 3.1 暴力思路

最省事的做法是先按完整形式递归输出：

$$\text{full}(v) = \text{val}(v) + \texttt{(}\ \text{full}(\text{left}) \ \texttt{)(}\ \text{full}(\text{right}) \ \texttt{)}$$

空孩子输出空串。示例 1 会得到 `1(2(4)())(3()())`，然后把所有可省的 `()` 删掉。麻烦在于「哪些 `()` 可省」需要看**父节点是否还有右孩子**：单纯对字符串做 `replace("()", "")` 会连必需的 `()` 一起删掉，而写成「先展开成括号树再判断」等价于把原问题重做一遍。若改成枚举「保留/删除哪几对括号」再验证能否反解析，是指数级。

另一条暴力路是**直接拼字符串**：每次递归返回 `string` 并做 `+` 拼接，深度为 $h$ 时会产生 $O(nh)$ 的字符复制，最坏 $O(n^2)$。这两点都不划算，需要换个角度。

### 3.2 核心观察：括号的取舍是「局部」的

![四种情形，四种写法](images/wc35_q2_rule_concept.svg)

**关键观察**：在完整形式里，一个 `()` 只可能是某个节点的**左槽**或**右槽**，而它能不能省，只取决于**当前节点自己**的左右孩子是否为空：

- 它是**右槽** → 一定可省。前序写到右孩子时，右槽位于整个节点的末尾，删掉它不会让后面的内容错位。
- 它是**左槽** → 只有当右槽也空时才可省。否则删掉后，右槽的内容会顶上来被读成左槽，结构改变。

于是「省略空括号」这条全局规则塌缩成了**递归时的一步局部决策**，不需要回看祖先：

| 情形 | 输出 | 说明 |
|------|------|------|
| 叶子（左右皆空） | `v` | 不写括号 |
| 只有左孩子 | `v(L)` | 右槽省略 |
| 只有右孩子 | `v()(R)` | 左槽补 `()`，右槽照写 |
| 左右都有 | `v(L)(R)` | 两组都不省 |

> 💡 一句话记忆：**有左就写左，有右就写右，左空右非空时补一对 `()` 占位。**

### 3.3 算法流程

![前序 DFS 流程](images/wc35_q2_dfs_flow.svg)

对节点 `node` 递归执行：

1. 追加 `to_string(node->val)`。
2. 若左右孩子都为空 → 直接返回（叶子不加括号）。
3. 追加 `"("`；若左孩子存在则递归左孩子；追加 `")"`。
   —— 左孩子为空时这两步什么都不写进去，正好留下 `()`。
4. 若右孩子存在：追加 `"("`，递归右孩子，追加 `")"`。
   —— 右孩子为空则整组跳过，正好实现「省略空括号」。

第 3 步「先写括号再判断左孩子」的写法是关键：括号的**开闭**由当前节点决定，**内容**由子树的递归决定，两者解耦，代码里就只剩两个 `if`。

### 3.4 示例演算

![示例 2 逐步拼接](images/wc35_q2_walkthrough.svg)

以 `root = [1,2,3,null,4]` 为例，递归顺序为 1 → 2 → 4 → 3：

| 步骤 | 访问节点 | 决策依据 | 当前输出 |
|------|----------|----------|----------|
| 1 | 1 | 左右都有 → 写 `(`、递归左、写 `)`、写 `(`、递归右 | `1(` |
| 2 | 2 | 左空右非空 → 左槽留空，得 `()`，再写 `(` 递归右 | `1(2()(` |
| 3 | 4 | 叶子 → 只写值 | `1(2()(4)` |
| 4 | 回到 1，写 `)` 与 `(` 后访问 3 | 3 是叶子 → 只写值 | `1(2()(4))(3` |
| 5 | 回到 1，收尾 `)` | 所有括号闭合 | `1(2()(4))(3)` |

作为对照，示例 1 的 `[1,2,3,4]` 中 2 只有左孩子，于是 2 的右槽被省略，输出 `1(2(4))(3)`。

## 4. 算法细节

1. **用可变缓冲区拼接**。C++ 传 `string& out`，Python 用 `list.append` + `"".join`。若每次递归返回 `string` 再相加，深度 $10^4$ 时会退化为 $O(n^2)$。
2. **递归函数写成 `void dfs(TreeNode*, string&)`**，不要返回字符串；返回值会诱发大量临时对象复制。
3. **括号与数值分开追加**：先用 `to_string(val)`（Python `str(val)`）处理负号，再单独 `out += '('`，避免在格式化里拼字符串。
4. **闭合顺序与前序一一对应**：写 `(` → 递归左 → 写 `)` → 若右存在再写 `( 递归 右 )`。先闭合左槽再开右槽，序列才合法，反解析时才能按「第一个括号组是左、第二个是右」切分。
5. **右槽整组省略**：判断的是 `node->right` 是否为空，而不是「右子树输出是否为空」——后者在右孩子存在时永远非空，容易写成多余的 `if`。
6. **深度保护**：最坏深度 $10^4$。C++ 递归栈足够；Python 默认上限 1000，必须 `sys.setrecursionlimit(100000)`，或改用显式栈的迭代写法。
7. **输出长度上界**：$n$ 个值（每个至多 5 字符，含负号）+ 至多 $2n$ 个括号字符，总量 $O(n)$，最坏约 $7 \times 10^4$ 字符，不会有内存问题。

## 5. 正确性证明

**引理 1（子树的递归输出正确）**：对任意节点 $v$，`dfs(v)` 写出的字符串恰为以 $v$ 为根的子树按题面四条规则得到的表示。

**证明**：对子树高度 $h$ 做结构归纳。

- $h=0$（$v$ 是叶子）：代码只写 `val(v)` 后返回，与「叶子不写括号」一致。
- 设 $h \ge 1$ 且对高度 $< h$ 的子树成立。此时 $v$ 至少有一个孩子，分两种情形：
  - 右孩子为空（必为「只有左孩子」）：代码写 `val(v)`、`(`、`dfs(left)`、`)`，得到 `v(L)`，右槽按规则省略，且右槽组整块跳过。
  - 右孩子非空：代码写 `val(v)`、`(`、`dfs(left)`（左空则空串）、`)`、`(`、`dfs(right)`、`)`，得到 `v(L)(R)` 或 `v()(R)`，正是规则要求的两组括号（左空右非空时保留空括号对）。
  由归纳假设 `dfs(left)`、`dfs(right)` 正确，拼接后即为整棵子树的表示。∎

**引理 2（空括号对的取舍是局部的）**：在完整形式中，某个 `()` 可以省略，当且仅当它位于**右槽**，或者它位于**左槽**且同一节点的右槽也为空。

**证明**：完整形式中每个节点的孩子都占一个槽位，从左到右依次为左槽、右槽。右槽处于该节点的末尾：删掉它之后，后续内容是祖先的下一个槽位，与「右槽不存在」的语义完全一致，故可省。左槽不是末尾：若其后紧跟非空右槽，删掉左槽会让右槽的内容被解析成左槽，树结构改变，故不可省；若右槽也为空，则左槽后没有任何内容，删掉后该节点退化为「无孩子」，与前序语义一致，故可省。∎

**引理 3（字符串可唯一反解）**：任意一棵二叉树的表示形如 `v`、`v(L)`、`v()(R)` 或 `v(L)(R)`，四种形态的前缀互不混淆，因此可以自顶向下唯一解析。

**证明**：四种形态都以数字开头，紧随其后的字符只有两种可能：字符串结束（叶子）或 `(`。若为 `(`，由括号配对可切出第一个括号组；再看其后的字符：若已到串尾，则只有左孩子 `v(L)`；若紧接着又是 `(`，说明有两个组，第一个为空串则左孩子为空（`v()(R)`），否则左右都在（`v(L)(R)`）。切分方式唯一，递归下去即得唯一原树。∎

**定理**：`tree2str(root)` 返回的字符串就是题面定义的表示，且与原树一一对应。

**证明**：由引理 1，输出逐层满足题面的括号规则，且所有空括号对的取舍都符合规则；由引理 2，算法保留的 `()` 恰好是「左空右非空」这一必需情形，省略的恰好是可省情形，故没有多写也没有少写；由引理 3，该字符串能唯一反解回原树，满足「表示与原树一一对应」的要求。∎

## 6. 复杂度分析

- **时间**：$O(n)$。每个节点恰好被访问一次，追加自身的值（位数 $\le 5$，常数）与至多 4 个括号字符；`to_string` 的位数有上界，故总字符写入量 $O(n)$。字符串采用均摊 $O(1)$ 的追加，不产生二次复制。
- **空间**：$O(n + h)$。输出缓冲区 $O(n)$；递归栈深度等于树高 $h$，最坏 $h = n = 10^4$，平均为 $O(\log n)$。若不计算返回值的空间，则额外空间为 $O(h)$。

## 7. 参考代码

### C++

```cpp
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    string tree2str(TreeNode* root) {
        string out;
        dfs(root, out);
        return out;
    }

private:
    void dfs(TreeNode* node, string& out) {
        if (!node) return;
        out += to_string(node->val);
        if (!node->left && !node->right) return;   // 叶子：不写任何括号
        out += '(';
        dfs(node->left, out);                      // 左孩子为空时这里什么都不写，留下 "()"
        out += ')';
        if (node->right) {                         // 右孩子为空 → 整组括号省略
            out += '(';
            dfs(node->right, out);
            out += ')';
        }
    }
};
```

### Python

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
import sys
from typing import List, Optional

class Solution:
    def tree2str(self, root: Optional[TreeNode]) -> str:
        sys.setrecursionlimit(100000)          # 最坏是一条 10^4 节点的单链
        out: List[str] = []

        def dfs(node: Optional[TreeNode]) -> None:
            if node is None:
                return
            out.append(str(node.val))
            if node.left is None and node.right is None:
                return                          # 叶子：不写括号
            out.append("(")
            dfs(node.left)                      # 左空时这里不写内容，自然留下 "()"
            out.append(")")
            if node.right is not None:          # 右空则整组省略
                out.append("(")
                dfs(node.right)
                out.append(")")

        dfs(root)
        return "".join(out)
```

## 8. 边界情况与易错点

1. **单节点**：`[1]` 必须输出 `"1"`。若漏判叶子，会得到 `"1()"`，多出一对空括号。
2. **左空右非空**：`[1,null,2]` 必须是 `"1()(2)"`。漏掉 `()` 会输出 `"1(2)"`，反解析时 2 会被当作左孩子，结构直接错掉——这是本题唯一的「必须保留」例外。
3. **左非空右空**：`[1,2]` 输出 `"1(2)"`，不能补成 `"1(2)()"`；判断右槽时看的是 `node->right` 是否为空，而不是「是否写过括号」。
4. **负值**：`val` 可取 $-1000$，如 `[-1000,-1000]` 输出 `"-1000(-1000)"`。用 `to_string` / `str()`，不要手写 `char(val + '0')` 之类的转换。
5. **深链导致栈溢出**：`10^4` 个节点全在右侧的链，Python 默认递归上限 1000 会抛 `RecursionError`，必须提高上限或改写成显式栈迭代。
6. **缓冲区不能复用成成员变量**：多次调用同一个 `Solution` 对象时，若把 `out` 写成成员/静态变量，字符串会跨调用累加，结果必定错误。
7. **空树**：约束保证 $n \ge 1$，但代码里 `if (!node) return;` 保证空指针安全，也便于本地对拍。
8. **拼接方式**：C++ 里 `return to_string(val) + "(" + dfs(l) + ")"` 这种写法虽然正确但会产生 $O(nh)$ 复制，深链上会 TLE；必须用引用传参或 `list` 缓冲。
