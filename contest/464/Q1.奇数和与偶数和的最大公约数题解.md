# LeetCode 奇数和与偶数和的最大公约数 题解

## 1. 题目概述

- **标题 / 题号**：奇数和与偶数和的最大公约数（#3658，easy）
- **链接**：https://leetcode.cn/problems/gcd-of-odd-and-even-sums/
- **来源**：LeetCode 第 464 场周赛 Q1
- **难度**：简单
- **标签**：数学、数论

**题意**：给定整数 $n$，记 `sumOdd` 为最小的 $n$ 个正奇数（$1, 3, 5, \dots$）之和，`sumEven` 为最小的 $n$ 个正偶数（$2, 4, 6, \dots$）之和，返回 $\gcd(\text{sumOdd}, \text{sumEven})$。

**约束**：

- `1 <= n <= 1000`

## 2. 示例

**示例 1**

```text
输入：n = 4
输出：4
解释：sumOdd  = 1 + 3 + 5 + 7  = 16
      sumEven = 2 + 4 + 6 + 8  = 20
      gcd(16, 20) = 4
```

**示例 2**

```text
输入：n = 5
输出：5
解释：sumOdd  = 1 + 3 + 5 + 7 + 9  = 25
      sumEven = 2 + 4 + 6 + 8 + 10 = 30
      gcd(25, 30) = 5
```

## 3. 解题思路

### 3.1 暴力思路

直接模拟：循环累加前 $n$ 个奇数与前 $n$ 个偶数，再跑欧几里得算法求 $\gcd$。时间 $O(n + \log n)$，对本题 $n \le 1000$ 完全够用。但作为签到题，值得多想一步：两个和都有**闭式**，能否直接推出答案？

### 3.2 核心观察：两个和的闭式

![前n个奇数和与偶数和的闭式](images/gcd_odd_even_sums.svg)

- 前 $n$ 个正奇数之和是**完全平方数**：$\text{sumOdd} = 1 + 3 + \cdots + (2n-1) = n^2$
- 前 $n$ 个正偶数之和：$\text{sumEven} = 2 + 4 + \cdots + 2n = n(n+1)$

于是问题化为求 $\gcd\big(n^2,\ n(n+1)\big)$。

### 3.3 公式推导：答案就是 $n$

利用 $\gcd$ 的**齐次性**（公因子可提出）：$\gcd(na, nb) = n \cdot \gcd(a, b)$，

$$\gcd\big(n^2,\ n(n+1)\big) = n \cdot \gcd(n,\ n+1)$$

而**相邻整数互质**：$\gcd(n, n+1) = 1$（任何公因子必整除它们的差 $1$）。

$$\boxed{\gcd(\text{sumOdd}, \text{sumEven}) = n}$$

> 💡 另一条等价路线：$\gcd(a, b) = \gcd(a, b - a)$，故 $\gcd(n^2,\ n^2 + n) = \gcd(n^2,\ n) = n$（因 $n \mid n^2$）。两条路殊途同归。

### 3.4 示例演算

![n=4 的完整演算与欧几里得验证](images/gcd_odd_even_derivation.svg)

以 $n = 4$ 走一遍完整流程：

| 步骤 | 计算 | 结果 |
|------|------|------|
| 奇数和 | $1 + 3 + 5 + 7$ | $16 = 4^2$ |
| 偶数和 | $2 + 4 + 6 + 8$ | $20 = 4 \times 5$ |
| 提出公因子 | $\gcd(16, 20) = 4 \cdot \gcd(4, 5)$ | $4 \cdot 1$ |
| 答案 | | $4 = n$ ✓ |

## 4. 算法细节

1. **闭式求和**：无需循环，$\text{sumOdd} = n^2$，$\text{sumEven} = n(n+1)$。
2. **公因子提出**：$\gcd(n^2, n(n+1)) = n \cdot \gcd(n, n+1) = n \cdot 1$。
3. **直接返回 $n$**：代码一行 `return n;`。若比赛时不敢直接相信推导，也可以老实算出两个和再跑 `std::gcd` / `math.gcd`，同样 $O(1)$，双保险。

## 5. 正确性证明

**引理 1**：前 $n$ 个正奇数之和为 $n^2$。

**证明**：第 $i$ 个正奇数为 $2i - 1$，故
$$\sum_{i=1}^{n} (2i-1) = 2 \cdot \frac{n(n+1)}{2} - n = n^2. \quad \blacksquare$$

**引理 2**：相邻整数互质，即 $\gcd(n, n+1) = 1$。

**证明**：设 $d = \gcd(n, n+1)$，则 $d \mid n$ 且 $d \mid n+1$，故 $d \mid (n+1) - n = 1$，即 $d = 1$。∎

**引理 3**（$\gcd$ 的齐次性）：对任意正整数 $n, a, b$，$\gcd(na, nb) = n \cdot \gcd(a, b)$。

**证明**：$na$ 与 $nb$ 的公因子集合恰为 $n \cdot (a, b\text{ 的公因子集合})$。设 $g = \gcd(a, b)$，写 $a = g a'$，$b = g b'$ 且 $\gcd(a', b') = 1$，则 $na = ng \cdot a'$，$nb = ng \cdot b'$，且 $a', b'$ 无大于 1 的公因子，故 $\gcd(na, nb) = ng$。∎

**定理**：$\gcd(\text{sumOdd}, \text{sumEven}) = n$。

**证明**：由引理 1 及等差数列求和，$\text{sumOdd} = n^2$，$\text{sumEven} = n(n+1)$。由引理 3，
$$\gcd\big(n^2,\ n(n+1)\big) = n \cdot \gcd(n,\ n+1) \overset{\text{引理 2}}{=} n \cdot 1 = n. \quad \blacksquare$$

## 6. 复杂度分析

- **时间复杂度**：$O(1)$。直接返回 $n$，无循环。若采用求和 + 欧几里得的稳妥写法，也是 $O(1)$（$n \le 1000$）。
- **空间复杂度**：$O(1)$。仅常数变量。

## 8. 边界情况与易错点

1. **$n = 1$**：$\text{sumOdd} = 1$，$\text{sumEven} = 2$，$\gcd = 1 = n$，公式成立。
2. **"最小的正偶数"从 2 开始**：$0$ 是偶数但**不是正偶数**，若误把 $0$ 计入会得到错误的 `sumEven`（好在 $0$ 不影响和，但会数错个数）。
3. **溢出**：$n \le 1000$ 时 $n(n+1) \le 1001000$，`int` 足够；若数据范围放大到 $10^9$，闭式写法依然 $O(1)$，但求和写法需要 `long long` 且循环会超时——这正是闭式的价值。
4. **别把 $\gcd(n^2, n(n+1))$ 误算为 $n^2$**：$n+1$ 与 $n$ 互质不代表 $n+1$ 与 $n^2$ 互质之外的因子不能进入 $\gcd$；必须严格走"提出 $n$"这一步（例如 $n=4$ 时 $\gcd(16,20)=4$ 而非 $16$）。
