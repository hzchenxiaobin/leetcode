# LeetCode 分割数组中数字的数位 题解

## 1. 题目概述

- **标题 / 题号**：分割数组中数字的数位（#2553，easy）
- **链接**：https://leetcode.cn/problems/separate-the-digits-in-an-array/
- **来源**：LeetCode 第 97 场双周赛 Q1
- **难度**：简单
- **标签**：数组、模拟

**题意**：给定一个正整数数组 `nums`，返回一个数组 `answer`：把 `nums` 中每个整数做**数位分割**，并按 `nums` 中出现的**相同顺序**依次拼接进 `answer`。对一个整数做数位分割，指把它的每一位十进制数字**按原本出现顺序**（高位在前）排成数组，例如 $10921$ 分割为 $[1, 0, 9, 2, 1]$。

**约束**：

- $1 \le nums.length \le 1000$
- $1 \le nums[i] \le 10^5$

## 2. 示例

**示例 1**

```text
输入：nums = [13,25,83,77]
输出：[1,3,2,5,8,3,7,7]
解释：
- 分割 13 得到 [1,3]；
- 分割 25 得到 [2,5]；
- 分割 83 得到 [8,3]；
- 分割 77 得到 [7,7]。
依次拼接：answer = [1,3,2,5,8,3,7,7]。
```

**示例 2**

```text
输入：nums = [7,1,3,9]
输出：[7,1,3,9]
解释：每个数都只有一位，分割结果就是它本身。
```

**示例 3（边界补充）**

```text
输入：nums = [100000]
输出：[1,0,0,0,0,0]
解释：达到上界 10^5，共 6 位，注意中间的 0 一个都不能丢。
```

## 3. 解题思路

### 3.1 暴力思路

签到题没有「暴力」与「优化」的分层——任何正确做法都是一遍扫描。最直接的实现：对每个 `x` 反复 `x % 10`、`x /= 10` 收集低位到高位，再**反转**得到高位在前的顺序，逐个追加到 `answer`。这是纯模拟，时间 $O(\sum \text{位数})$，对本题数据规模绰绰有余。唯一容易写错的点是**取余法天然是低位在前**，忘记反转就会把 $13$ 写成 $[3,1]$。

### 3.2 核心观察：数位分割 = 十进制字符串展开

![核心观察：整数到十进制数位序列的两种展开方式](images/bw97_q1_digit_expansion.svg)

把整数看作十进制字符串，「数位分割」就是**按原顺序（高位在前）枚举字符串的每个字符**并转成数字。于是实现可以二选一：

- **字符串路线**：`to_string(x)` 后逐字符 `c - '0'`，天然高位在前，无需反转；
- **算术路线**：`x % 10` 收集后整体反转，或先数出位数再从高位除法剥落。

两条路线本质相同：都是把数按十进制逐位展开。字符串路线更短、更不易错，是签到题的「最短路径」。

### 3.3 算法流程

![算法流程：逐个数、逐个数位追加到 answer](images/bw97_q1_algorithm_flow.svg)

```text
1. answer ← 空数组
2. 对 nums 中每个 x（按原顺序）：
       s ← x 的十进制字符串
       对 s 中每个字符 c（从左到右，即高位到低位）：
            answer.push_back(c - '0')
3. 返回 answer
```

答案长度先于计算就能确定：$L = \sum_i \lfloor \log_{10} nums[i] \rfloor + 1$，可以直接 `reserve` 预留。

### 3.4 示例演算

以 `nums = [13, 25, 83, 77]` 为例：

| 处理的数 | 字符串 | 追加的数位 | answer 当前状态 |
|----------|--------|-----------|-----------------|
| 13 | "13" | 1, 3 | [1, 3] |
| 25 | "25" | 2, 5 | [1, 3, 2, 5] |
| 83 | "83" | 8, 3 | [1, 3, 2, 5, 8, 3] |
| 77 | "77" | 7, 7 | [1, 3, 2, 5, 8, 3, 7, 7] |

注意 $10 \le nums[i] \le 99$ 时每个数贡献 2 位，但**位数随数值变化**（$7$ 贡献 1 位、$100000$ 贡献 6 位），答案长度不能按「每个数固定几位」预估上限去截断。

## 4. 算法细节

1. **顺序双重保证**：外层按 `nums` 下标顺序遍历，内层按字符串从左到右遍历，两者都不能乱——前者对应「按照 nums 中出现的相同顺序」，后者对应「按原本出现的顺序排列」。
2. **`reserve` 的量级**：最坏 $1000 \times 6 = 6000$ 个元素，`reserve(nums.size() * 6)` 一次扩容即可，避免 `vector` 反复翻倍；当然本题规模下不 `reserve` 也毫无压力。
3. **字符转数字**：`c - '0'` 依赖 ASCII/Unicode 中数字字符连续编码，C++ 与 Python 均成立；Python 里更直接用 `int(c)`。
4. **Python 一行化**：双层推导 `[int(c) for x in nums for c in str(x)]`，外层循环在前、内层在后，语义与两重 for 完全一致。
5. **算术路线的写法**（如果不想碰字符串）：`vector<int> t; while (x) { t.push_back(x % 10); x /= 10; }` 再 `reverse(t)`；或先求最高位权重再从高位剥：`p = 1; while (p * 10 <= x) p *= 10; while (p) { ans.push_back(x / p % 10); p /= 10; }`。
6. **复杂度与规模匹配**：$L \le 6000$，$O(L)$ 的一遍扫描连 1ms 都用不到；任何额外排序/去重都是对题意的误读。

## 5. 正确性证明

**引理 1（十进制表示唯一）**：任意正整数 $x$ 存在唯一的十进制表示 $x = \sum_{t=0}^{m-1} d_t \cdot 10^t$，其中 $d_{m-1} \ge 1$，$0 \le d_t \le 9$。

**证明**：存在性由带余除法链得到：$x = 10 q_1 + r_0$，$q_1 = 10 q_2 + r_1$，……，$q$ 严格递减且非负，链有限终止；把各步余数按相反顺序排出即得 $d_{m-1} \dots d_1 d_0$。唯一性：若 $x$ 有两种表示，设 $t$ 为最高 differing 位，两式相减得 $10^t (d_t - d_t') = 10^{t+1} \cdot N$，则 $10^t \mid d_t - d_t'$，而 $|d_t - d_t'| \le 9 < 10^t$（$t \ge 0$ 时 $10^t \ge 1$，当 $t = 0$ 需 $|d_0 - d_0'| \le 9 < 10$ 成立），故 $d_t = d_t'$，矛盾。∎

**引理 2（字符串即数位序列）**：`to_string(x)` 的输出恰好是 $x$ 的十进制表示 $d_{m-1} d_{m-2} \dots d_0$ 从左到右排列，且每个字符 `c` 满足 `c - '0' = d_t`。

**证明**：标准库规定 `to_string` 的输出为 $x$ 的十进制数字序列（无前导零、无正负号，$x$ 为正）；数字字符 `'0'`~`'9'` 连续编码，故 `c - '0'` 精确还原该位数值。∎

**定理**：上述算法返回的数组等于题目要求的 `answer`。

**证明**：归纳于处理完成的数的个数 $i$。$i = 0$ 时 `answer` 为空，与「空前缀」一致。设处理完前 $i$ 个数后 `answer` 恰为 $nums[0..i-1]$ 依次分割的拼接。处理 $nums[i]$ 时，由引理 2，内层循环按从左到右枚举出 $nums[i]$ 的全部数位 $d_{m-1}, \dots, d_0$（由引理 1 这正是且仅是数位分割的定义），逐个追加到尾部，不删除、不重排已有元素；故处理完后 `answer` 为前 $i+1$ 个数的依次拼接。循环终止时覆盖全部 $n$ 个数，即所求。∎

## 6. 复杂度分析

- **时间**：$O(L)$，其中 $L = \sum_i (\lfloor \log_{10} nums[i] \rfloor + 1) \le 1000 \times 6 = 6000$ 是答案总长度。每个数位只被生成一次、追加一次。
- **空间**：$O(L)$ 存储答案（这是必须的输出空间）；字符串临时对象每个数 $O(\log_{10} nums[i])$，逐个数处理时可复用，额外空间 $O(6) = O(1)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> separateDigits(vector<int>& nums) {
        vector<int> ans;
        ans.reserve(nums.size() * 6);           // 10^5 至多 6 位
        for (int x : nums) {
            string s = to_string(x);            // 高位在前
            for (char c : s) ans.push_back(c - '0');
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def separateDigits(self, nums: List[int]) -> List[int]:
        return [int(c) for x in nums for c in str(x)]
```

> 💡 两份代码均通过官方示例（`[1,3,2,5,8,3,7,7]`、`[7,1,3,9]`）与上界样例 `[100000] → [1,0,0,0,0,0]`。

## 8. 边界情况与易错点

1. **中间的 0 不能丢**：$100000$ 分割为 6 位 $[1,0,0,0,0,0]$；用 `while (x) { x /= 10; }` 式的取余收集时要靠**反转**保序，且不要用「`while (x)` 遇 0 提前结束」产生空数组的错误联想（本题 $nums[i] \ge 1$，单个 0 不会出现，但反转别忘）。
2. **顺序两层都要保**：外层数的顺序、内层位（高位在前）的顺序。取余法产出低位在前，直接追加会把 $13$ 变 $[3,1]$。
3. **不要去重、不要排序**：题面只要求展开拼接，`[7,7]` 的两件 7 都要保留；`answer` 长度是变量，别按固定 `2 * n` 开数组。
4. **数字字符转换**：`c - '0'` / `int(c)`；若误用 `int(str(x))` 之外的花活（如 `ord` 差值写错基点）会整体偏移。
5. **数据规模极小**：$O(L)$ 模拟即可，无需任何预处理；签到题的坑只在「顺序」与「保位」。
