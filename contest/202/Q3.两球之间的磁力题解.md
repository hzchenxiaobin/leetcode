# LeetCode 两球之间的磁力 题解

## 1. 题目概述

- **标题 / 题号**：两球之间的磁力（#1552，medium）
- **链接**：https://leetcode.cn/problems/magnetic-force-between-two-balls/
- **来源**：LeetCode 第 202 场周赛 Q3
- **难度**：中等
- **标签**：数组、排序、二分查找、贪心

**题意**：给定 $n$ 个互不相同的位置 $\mathrm{position}[i]$（篮子，每个篮子至多放一个球），要把 $m$ 个球放入其中 $m$ 个篮子。两球分别位于 $x, y$ 时磁力为 $|x - y|$。目标是**最大化任意两球间的最小磁力**，返回这个最大化的最小磁力。

**约束**：

- $2 \le n \le 10^5$
- $1 \le \mathrm{position}[i] \le 10^9$，且互不相同
- $2 \le m \le n$

> 💡 本题在本仓库另有[每日题解 1552](../../solution/1501-1600/1552_两球之间的磁力.md)：侧重「二分答案」的识别信号、与 1011 的镜像对照及面试表达。本篇按周赛复盘视角展开，主推「**最大化最小值 → 排序塌缩两两间距 → 二分答案 + 贪心 check**」三步骨架，并补全可行集前缀单调性与贪心交换论证两条严格证明，附上下界收紧与 $m = 2$ / $m = n$ 边界清单，两篇互为印证。

## 2. 示例

**示例 1**

```text
输入：position = [1,2,3,4,7], m = 3
输出：3
解释：球放在 1、4、7，磁力为 [3, 3, 6]，最小磁力 3。
     若要求最小磁力 ≥ 4，最多只能放 2 个球（如 1 和 7），不够 3 个。
```

**示例 2**

```text
输入：position = [5,4,3,2,1,1000000000], m = 2
输出：999999999
解释：排序后放首尾两篮，最小磁力即两球间距 10⁹ − 1。
```

**示例 3（边界自拟）**

```text
输入：position = [5,4,3,2,1], m = 5
输出：1
解释：m = n，所有篮子都得放球，答案退化为最小相邻间距 1。
```

## 3. 解题思路

### 3.1 暴力思路

两种朴素做法：

- **组合枚举**：枚举 $\binom{n}{m}$ 种选法，取最小间距最大者。$n = 10^5$、$m$ 取 $n/2$ 时组合数是天文数字，不可行。
- **答案域线性扫**：答案 $d \in [1, \mathrm{span}]$（$\mathrm{span} = \max - \min$）。从大到小逐一尝试 $d$，每个 $d$ 用一趟 $O(n)$ 贪心验证能否放下 $m$ 球，首个可行即答案。总复杂度 $O(n \cdot \mathrm{span})$，$\mathrm{span}$ 可达 $10^9$，约 $10^{14}$ 次操作——超时。

> 💡 症结在于**答案域天然有序、可行性关于 $d$ 单调，却被线性扫描白白浪费**。「有序 + 单调判定」正是二分的用武之地——把「逐一尝试」换成「折半排除」。

### 3.2 核心观察：count(d) 单调不增——「最大化最小值」的二段性

![核心观察：间距 d 越大能放的球越少，可行集是前缀，二分答案](images/wc202_q3_monotonicity_concept.svg)

定义 $\mathrm{count}(d)$ 为**以间距 $\ge d$ 为约束最多能放的球数**（一趟从左到右贪心即可求得，见引理 3）。它关于 $d$ 单调不增：$d$ 越大约束越紧，能放的球只会更少。于是可行集

$$F = \{\, d \ge 1 : \mathrm{count}(d) \ge m \,\} = \{1, 2, \ldots, d^*\}$$

是一个**前缀**——左侧全可行、右侧全不可行（二段性），所求答案即 $d^* = \max F$。以 $[1,2,3,4,7]$、$m = 3$ 为例：$\mathrm{count}(1..6) = 5, 3, 3, 2, 2, 2$，分界点 $d^* = 3$。

这正是「**最大化最小值 → 二分答案**」套路（对偶版本「最小化最大值」见 [1011](https://leetcode.cn/problems/capacity-to-ship-packages-within-d-days/)）：

> **识别信号**：题目求「最大的最小 / 最小的最大」，且给定候选值能 $O(n)$ 验证合法性 → 二分答案。本题二分间距 $d$：可行时向右找更大（`lo = mid + 1`），不可行时向左缩（`hi = mid − 1`）。

### 3.3 算法流程：排序 + 二分间距 + 贪心 check

![算法流程：排序、定界、二分中点、贪心 check、区间收缩与返回](images/wc202_q3_binary_greedy_flow.svg)

1. **排序**：把「任意两球间距 $\ge d$」塌缩为「**相邻**两球间距 $\ge d$」——排序后任两球间距是中间相邻间距之和（引理 1），check 从 $O(m^2)$ 两两判定降为 $O(n)$ 相邻扫描。
2. **定界**：$lo = 1$（位置互异且为正整数，最小可行间距 $\ge 1$）；$hi = \lfloor \mathrm{span} / (m-1) \rfloor$——$m$ 个球有 $m - 1$ 段间距，若每段 $\ge d$，各段都落在 $[p_{\min}, p_{\max}]$ 内，相加得 $\mathrm{span} \ge d(m-1)$，这是物理上界。
3. **循环**：取 $mid$，贪心 check——首球固定放最左 $p[0]$，从左到右扫，$p[i] - \mathrm{last} \ge mid$ 就放球并更新 $\mathrm{last}$，计数达 $m$ 即提前终止。
4. **收缩**：可行（$\mathrm{count} \ge m$）记 $ans = mid$、$lo = mid + 1$；不可行 $hi = mid - 1$。$lo > hi$ 时返回 $ans$。

### 3.4 示例演算

![示例演算：position = [1,2,3,4,7]，m = 3，两轮二分命中 d* = 3](images/wc202_q3_walkthrough.svg)

以示例 1 为例，排序后 $[1,2,3,4,7]$，$\mathrm{span} = 6$，$hi = \lfloor 6/2 \rfloor = 3$，$lo = 1$：

| 轮次 | 区间 $[lo, hi]$ | $mid$ | 贪心放球 | $\mathrm{count}$ | 判定与收缩 |
|------|----------------|-------|----------|------------------|------------|
| 1 | $[1, 3]$ | 2 | 1 → 3 → 7（间距 2、4） | 3 | 可行 ✓，$ans = 2$，$lo = 3$ |
| 2 | $[3, 3]$ | 3 | 1 → 4 → 7（间距 3、3） | 3 | 可行 ✓，$ans = 3$，$lo = 4$ |

$lo = 4 > hi = 3$，循环结束，返回 $ans = 3$。$\log_2 3 \approx 1.6$，两轮即命中——二分只做「必要」的尝试，这就是它对线性扫描的碾压来源。

## 4. 算法细节

1. **排序的真正作用**：不止是让贪心从左到右成立，更是把约束「任意两球」化为「相邻两球」（引理 1），check 单次 $O(n)$ 而非 $O(m^2)$——$m$ 接近 $10^5$ 时后者必超时。
2. **上界的两种取法**：$hi = \lfloor \mathrm{span}/(m-1) \rfloor$ 是紧上界；直接取 $hi = \mathrm{span}$ 也正确，只多几次无效 check。分母 $m - 1 \ge 1$（$m \ge 2$），无除零风险。
3. **贪心 check 的三个要点**：$\mathrm{count}$ 初值 **1**（首球固定放 $p[0]$，引理 3 的归纳起点）；$\mathrm{last}$ 初始化为 $p[0]$；$\mathrm{count}$ 达 $m$ 立即 break——提前终止让 check 常数更小。
4. **二分方向口诀**：**最大化 → 可行向右搜**（$ans = mid$，$lo = mid + 1$）；最小化 → 可行向左搜（$hi = mid - 1$）。方向写反会一路收敛到最小可行值 $1$。
5. **溢出评估**：$\mathrm{position}[i] \le 10^9 \Rightarrow \mathrm{span} \le 10^9 - 1 < 2^{31} - 1$，`int` 安全；若位置上限抬到 $10^{18}$，需换 64 位整数。

## 5. 正确性证明

**引理 1（相邻即全体）**：排序后的位置中任取 $m$ 个 $p_{i_1} < p_{i_2} < \cdots < p_{i_m}$，则「任意两球间距 $\ge d$」当且仅当「所有相邻间距 $\ge d$」。

**证明**：（⇐）对 $j > k$，$p_{i_j} - p_{i_k} = \sum_{t=k}^{j-1} (p_{i_{t+1}} - p_{i_t}) \ge (j-k)\,d \ge d$。（⇒）相邻两球也是「任意两球」中的一对，直接 $\ge d$。∎

**引理 2（单调性与二段性）**：$d \le d' \Rightarrow \mathrm{count}(d) \ge \mathrm{count}(d')$；从而可行集 $F$ 是前缀 $\{1, \ldots, d^*\}$。

**证明**：任何满足间距 $\ge d'$ 的放法同时满足间距 $\ge d$，故后者能放的球数不少于前者。又 $d = 1$ 时所有 $n$ 个互异位置都可放，$\mathrm{count}(1) = n \ge m$，$F$ 非空且关于 $d$ 向下封闭，必为前缀。∎

**引理 3（贪心 check 最优，交换论证）**：从最左位置开始「能放就放」的贪心放置，得到的球数恰为 $\mathrm{count}(d)$。

**证明**：设任一满足间距 $\ge d$ 的方案 $Q$ 依次放在 $q_1 < q_2 < \cdots$，贪心依次放在 $g_1 < g_2 < \cdots$。对 $k$ 归纳证明 $g_k \le q_k$（只要两者都放了第 $k$ 球）：$g_1 = p_{\min} \le q_1$。若 $g_k \le q_k$，则 $q_{k+1} \ge q_k + d \ge g_k + d$，而 $q_{k+1}$ 是真实存在的位置，贪心取 $g_{k+1}$ 为**第一个** $\ge g_k + d$ 的位置，故 $g_{k+1} \le q_{k+1}$。于是 $Q$ 放满 $k+1$ 球时贪心也已放满 $k+1$ 球（贪心扫描不会跳过任何 $\ge g_k + d$ 的位置）。对 $k$ 归纳得贪心球数 $\ge$ 任何方案的球数，而贪心自身合法，故等于 $\mathrm{count}(d)$。∎

**定理（算法正确性）**：设 $d^* = \max F$，算法返回 $d^*$。

**证明**：初始 $ans = 1 \in F$。先证 $hi$ 初值 $\ge d^*$：若 $d \in F$，取一个可行放法，由引理 1 其 $m-1$ 段相邻间距均 $\ge d$ 且全部落在 $[p_{\min}, p_{\max}]$ 内，相加得 $\mathrm{span} \ge d(m-1)$，即 $d \le \mathrm{span}/(m-1)$。循环不变式：**任意时刻 $d^* \in [lo, hi] \cup \{ans\}$**。若 $mid \in F$：$mid \le d^*$，执行 $ans = mid$、$lo = mid + 1$ 后，或 $d^* \in [lo, hi]$（当 $d^* > mid$），或 $d^* = mid = ans$。若 $mid \notin F$：由引理 2 的前缀结构 $mid > d^*$，执行 $hi = mid - 1$ 后仍有 $d^* \in [lo, hi]$。区间每轮至少减半，循环必终止于 $lo > hi$，此时 $d^* = ans$，即返回值。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \log n + n \log S)$，其中 $S = \lfloor \mathrm{span}/(m-1) \rfloor \le 10^9$。排序 $O(n \log n)$；二分 $O(\log S) \le 30$ 轮，每轮贪心 check $O(n)$（$\mathrm{count}$ 达 $m$ 提前终止）。$n = 10^5$ 时总量约 $5 \times 10^6$，远低于时限。
- **空间复杂度**：$O(1)$ 额外空间（排序原地；C++ 递归栈 $O(\log n)$）。

## 7. 参考代码

### 方法一：排序 + 二分答案 + 贪心 check（推荐）

#### C++

```cpp
class Solution {
public:
    int maxDistance(vector<int>& position, int m) {
        sort(position.begin(), position.end());
        int lo = 1;
        int hi = (position.back() - position.front()) / (m - 1);
        int ans = 1;
        while (lo <= hi) {
            int mid = lo + (hi - lo) / 2;
            if (canPlace(position, mid, m)) {
                ans = mid;        // 可行：向右找更大间距
                lo = mid + 1;
            } else {
                hi = mid - 1;     // 不可行：向左缩小间距
            }
        }
        return ans;
    }

private:
    bool canPlace(const vector<int>& position, int d, int m) {
        int count = 1;                       // 首球固定放最左
        int last = position.front();
        for (int i = 1; i < (int)position.size() && count < m; ++i) {
            if (position[i] - last >= d) {
                ++count;
                last = position[i];
            }
        }
        return count >= m;
    }
};
```

#### Python

```python
class Solution:
    def maxDistance(self, position: List[int], m: int) -> int:
        position.sort()
        lo, hi = 1, (position[-1] - position[0]) // (m - 1)
        ans = 1
        while lo <= hi:
            mid = (lo + hi) // 2
            if self._can_place(position, mid, m):
                ans = mid       # 可行：向右找更大间距
                lo = mid + 1
            else:
                hi = mid - 1    # 不可行：向左缩小间距
        return ans

    def _can_place(self, position: List[int], d: int, m: int) -> bool:
        count, last = 1, position[0]
        for p in position[1:]:
            if count >= m:
                break
            if p - last >= d:
                count += 1
                last = p
        return count >= m
```

### 方法二：答案域线性扫（对拍验证用）

```python
class Solution:
    def maxDistance(self, position: List[int], m: int) -> int:
        position.sort()
        for d in range(position[-1] - position[0], 0, -1):
            count, last = 1, position[0]
            for p in position[1:]:
                if p - last >= d:
                    count += 1
                    last = p
            if count >= m:
                return d
```

> 💡 赛时建议：方法二在 $\mathrm{span}$ 大时必然超时（$O(n \cdot \mathrm{span})$），仅用于小数据对拍——生成 $n \le 8$、坐标 $\le 20$ 的随机用例，与方法一核对一致后放心提交。

## 8. 边界情况与易错点

1. **$m = 2$**：答案就是 $\mathrm{span}$（首尾各一球），此时 $hi = \mathrm{span}/(2-1) = \mathrm{span}$，二分自然收敛，无需特判。
2. **$m = n$**：所有篮子都得放球，唯一选法，答案退化为**最小相邻间距**（排序后 $\min_i (p_{i+1} - p_i)$）；二分照常收敛，无需特判。
3. **$\mathrm{count}$ 初值是 1 不是 0**：首球固定放最左（引理 3 的归纳起点），漏掉会把每次 check 的球数少算一个。
4. **忘排序**：输入乱序（示例 2 即是 $[5,4,3,2,1,\ldots]$），不排序则贪心、$\mathrm{span}$、上下界全错。
5. **二分方向写反**：可行时须 $lo = mid + 1$ 向右找更大；误写 $hi = mid - 1$ 会一路向左、返回最小可行值 1。
6. **「任意两球」不必两两枚举**：排序后相邻约束即全体约束（引理 1）；$O(m^2)$ 两两判定在 $m$ 接近 $10^5$ 时超时。
7. **提前终止**：$\mathrm{count}$ 达 $m$ 即 break，check 常数更小，赛时好习惯。
8. **一篮一球是隐含约定**：若允许同篮多球，最小磁力恒为 0——「位置互不相同 + 每篮至多一球」才使本题有意义；实现上无需显式处理（贪心天然每位置至多一球）。
9. **溢出**：$\mathrm{span} \le 10^9 - 1 < 2^{31} - 1$，`int` 安全；约束放大需换 `long long`。
