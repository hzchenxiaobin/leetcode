# LeetCode 使数组中所有元素相等的最小操作数 题解

## 1. 题目概述

- **标题 / 题号**：使数组中所有元素相等的最小操作数（#1551，medium）
- **链接**：https://leetcode.cn/problems/minimum-operations-to-make-array-equal/
- **来源**：LeetCode 第 202 场周赛 Q2
- **难度**：中等
- **标签**：数学、贪心、不变量、等差数列

**题意**：给定长度为 $n$ 的数组 $\mathrm{arr}$，其中 $\mathrm{arr}[i] = 2i + 1$，即 $\mathrm{arr} = [1, 3, 5, \ldots, 2n-1]$。一次操作任选两个下标 $x, y$，令 $\mathrm{arr}[x]$ 减 $1$、$\mathrm{arr}[y]$ 加 $1$——本质是**把 1 个单位从 $x$ 搬到 $y$**。求使所有元素相等的最小操作数。

**约束**：

- $1 \le n \le 10^4$

> 💡 本题在本仓库另有[每日题解 1551](../../solution/1501-1600/1551_使数组中所有元素相等的最小操作数.md)：侧重首尾配对与闭式公式 $\lfloor n^2/4 \rfloor$ 的推导及面试表达。本篇按周赛复盘视角展开，主推「**不变量锁定目标 → 缺口计数定答案 → 对称结构出闭式**」三步框架，并用势函数补全「下界 + 构造上界」的完整证明与边界清单，两篇互为印证。

## 3. 解题思路

### 3.1 暴力思路：逐次模拟搬运

最朴素的写法是按题面模拟：每一步找一个高于目标的下标 $x$ 和一个低于目标的下标 $y$，执行一次搬运，直到全体相等。单步扫描 $O(n)$，而总步数约为 $\lfloor n^2/4 \rfloor$（见下），$n = 10^4$ 时约 $2.5 \times 10^7$ 步、合计 $\sim 10^{11}$ 次基本操作——不可行。

> 💡 症结在于**把「计数」当成「过程」来做**：操作是匀速的流水账，每步固定搬 1 单位，步数完全由「要搬的总量」决定，根本不需要逐步模拟。

退一步的 $O(n)$ 做法已经能过：直接用 $2i+1$ 求值扫一遍，把所有低于目标的差额累加。但输入只有**一个整数** $n$，答案理应是 $n$ 的闭式函数——$O(1)$ 可解。

### 3.2 核心观察：不变量锁定目标，缺口计数定答案

![核心观察：操作搬运 1 单位、总和不变，目标锁定为 n，答案 = 总缺口](images/wc202_q2_invariant_concept.svg)

三步推理，每步都只依赖题面结构：

1. **不变量**：一次操作一减一加，**总和不变**。初始 $\sum_{i=0}^{n-1} (2i+1) = n^2$（前 $n$ 个奇数之和），终态 $n$ 个元素全等于 $c$ 则 $nc = n^2$，故 $c = n$。**目标值不需要搜索，被不变量直接锁定**——这是「搬运型」操作（保总和，目标取平均值）区别于「修改型」操作（如 [462](https://leetcode.cn/problems/minimum-moves-to-equal-array-elements-ii/)，不保总和、目标取中位数）的分水岭。
2. **计数**：每步恰好搬运 1 单位。把 $\mathrm{arr}[i] < n$ 的差额（**缺口**）加总记为 $D$，则任何方案至少 $D$ 步（每步至多填 1 单位缺口）；把每一步都对准「盈余 → 缺口」，恰可 $D$ 步完成。**答案 = 总缺口 $D$**。
3. **结构**：$\mathrm{arr}$ 是对称等差数列，$\mathrm{arr}[i] + \mathrm{arr}[n-1-i] = 2n$ 恒成立，缺口与盈余关于中心镜像——$D$ 可以**首尾配对**闭式求和，$O(1)$ 出结果。

### 3.3 算法流程：首尾配对求闭式

![算法流程：首尾配对，奇偶分讨求和，统一为 n²/4 向下取整](images/wc202_q2_pairing_flow.svg)

把下标 $i$ 与 $n-1-i$ 配成一对。每对和恒为 $2n$、平均值恰为 $n$，**对内自平衡**——大的一半向小的一半搬运，不跨对流动：

$$\mathrm{ops}_i = \frac{\mathrm{arr}[n-1-i] - \mathrm{arr}[i]}{2} = \frac{(2n - 2i - 1) - (2i + 1)}{2} = n - 1 - 2i$$

对 $i = 0, 1, \ldots, \lfloor n/2 \rfloor - 1$ 求和（$n$ 奇数时中间元素 $\mathrm{arr}[(n-1)/2] = n$ 已达标、贡献 0）：

- **$n = 2m$（偶数）**：操作数为 $n-1, n-3, \ldots, 1$，即前 $m$ 个正奇数之和：

$$\mathrm{ans} = 1 + 3 + \cdots + (2m-1) = m^2 = \frac{n^2}{4}$$

- **$n = 2m+1$（奇数）**：操作数为 $n-1, n-3, \ldots, 2$，即前 $m$ 个正偶数之和：

$$\mathrm{ans} = 2 + 4 + \cdots + 2m = m(m+1) = \frac{n^2 - 1}{4}$$

两种情况合并为一个统一公式：

$$\boxed{\mathrm{ans} = \left\lfloor \frac{n^2}{4} \right\rfloor}$$

验证：$n = 3 \Rightarrow \lfloor 9/4 \rfloor = 2$ ✓；$n = 6 \Rightarrow \lfloor 36/4 \rfloor = 9$ ✓；$n = 1 \Rightarrow 0$ ✓；$n = 2 \Rightarrow 1$（`[1,3]` 搬一步成 `[2,2]`）✓。

### 3.4 示例演算

![示例演算：n=6 按对搬运，5+3+1=9 步](images/wc202_q2_walkthrough.svg)

以 $n = 6$ 为例，$\mathrm{arr} = [1, 3, 5, 7, 9, 11]$，目标 $= 6$：

| 阶段 | 数组 | 处理的对 | 本轮步数 |
|------|------|----------|----------|
| 初始 | [1, 3, 5, 7, 9, 11] | — | — |
| ① | [6, 3, 5, 7, 9, 6] | 对 (1, 11)：$(11-1)/2$ | 5 |
| ② | [6, 6, 5, 7, 6, 6] | 对 (3, 9)：$(9-3)/2$ | 3 |
| ③ | [6, 6, 6, 6, 6, 6] | 对 (5, 7)：$(7-5)/2$ | 1 |

总步数 $5 + 3 + 1 = 9 = \lfloor 6^2/4 \rfloor$，与示例 2 输出一致。也可按缺口核对：$(6-1) + (6-3) + (6-5) = 5 + 3 + 1 = 9$ ✓。

## 4. 算法细节

1. **目标值的来历**：总和不变量给出终态公共值 $c = n^2/n = n$；题目保证可达，无需再验证。
2. **答案 = 总缺口**：$D = \sum_{2i+1 < n} \big(n - (2i+1)\big)$，恰有 $\lfloor n/2 \rfloor$ 项（$n$ 奇数时中间元素等于 $n$ 不计入），配对化简即 $\lfloor n^2/4 \rfloor$。
3. **配对搬运量取半**：$\mathrm{arr}[n-1-i] - \mathrm{arr}[i] = 2(n - 1 - 2i)$ 是偶数（两元素同为奇数），除以 2 后恰为整数步数；漏掉 $\div 2$ 会把答案算成 $2D$。
4. **整数除法实现**：`n * n / 4`（C++）与 `n * n // 4`（Python）对非负数即向下取整，自动覆盖奇偶两种情况，无需 if 分支。
5. **溢出评估**：$n \le 10^4 \Rightarrow n^2 \le 10^8 < 2^{31} - 1 \approx 2.1 \times 10^9$，`int` 安全；若约束放宽到 $10^5$ 以上需换 `long long`。

## 5. 正确性证明

**引理 1（目标值被不变量锁定）**：任何使数组变为全等的操作序列，其终态公共值必为 $n$。

**证明**：每次操作使一个元素 $-1$、另一个 $+1$，总和不变。初始总和 $\sum_{i=0}^{n-1}(2i+1) = n^2$。设终态公共值为 $c$，则 $nc = n^2$，解得 $c = n$。∎

**引理 2（缺口与盈余相等，且等于 $\lfloor n^2/4 \rfloor$）**：记缺口 $G = \sum_{a_i < n}(n - a_i)$、盈余 $S = \sum_{a_i > n}(a_i - n)$，则 $G = S = \lfloor n^2/4 \rfloor$。

**证明**：$G - S = \sum_i (n - a_i) = n^2 - n^2 = 0$，故 $G = S$。由 $\mathrm{arr}[i] + \mathrm{arr}[n-1-i] = 2n$，低于 $n$ 的元素恰是前 $\lfloor n/2 \rfloor$ 个，逐项计算：

- $n = 2m$：$G = \sum_{i=0}^{m-1}\big(2m - (2i+1)\big) = (2m-1) + (2m-3) + \cdots + 1 = m^2 = n^2/4$；
- $n = 2m+1$：中间元素 $a_m = n$ 不计入，$G = \sum_{i=0}^{m-1}(2m - 2i) = 2m + (2m-2) + \cdots + 2 = m(m+1) = (n^2-1)/4$。

两种情况均为 $\lfloor n^2/4 \rfloor$。∎

**引理 3（下界）**：任何可行操作序列的长度至少为 $G$。

**证明**：定义势函数 $\Phi = \sum_i |a_i - n|$。一次操作只改动两个元素、各变动 $1$，每个 $|a_i - n|$ 至多减少 $1$（还可能增加），故每步 $\Phi$ 至多减少 $2$。由引理 1，终态所有元素等于 $n$，$\Phi$ 终值为 $0$；由引理 2，$\Phi$ 初值为 $G + S = 2G$。于是步数 $\ge \Phi_{\text{初}} / 2 = G$。∎

**引理 4（上界，构造）**：存在恰用 $G$ 步的操作序列。

**证明**：对每个 $i \in [0, \lfloor n/2 \rfloor - 1]$，对 $(i,\ n-1-i)$ 连续执行 $\mathrm{ops}_i = (a_{n-1-i} - a_i)/2 = n - 1 - 2i$ 次操作（每次取 $x = n-1-i,\ y = i$）。因 $a_{n-1-i} - a_i$ 为偶数，$\mathrm{ops}_i$ 是非负整数；这些操作把该对两元素都变为 $n$（对内和保持 $2n$）。$n$ 为奇数时中间元素本就等于 $n$。总步数 $\sum_i (n-1-2i) = G = \lfloor n^2/4 \rfloor$。∎

**定理**：使数组所有元素相等的最小操作数为 $\lfloor n^2/4 \rfloor$。

**证明**：由引理 3（任何方案 $\ge \lfloor n^2/4 \rfloor$）与引理 4（存在方案 $= \lfloor n^2/4 \rfloor$）夹逼即得。∎

## 6. 复杂度分析

- **时间复杂度**：$O(1)$。一次乘法加一次整除；若用 $O(n)$ 缺口累加版做对拍，也只是 $n \le 10^4$ 的一次线性扫描。
- **空间复杂度**：$O(1)$。公式版连数组都不必构造——$O(n)$ 的中间数组也可省去。

## 7. 参考代码

### 方法一：$O(1)$ 闭式公式（推荐）

#### C++

```cpp
class Solution {
public:
    int minOperations(int n) {
        return n * n / 4;   // 整数除法即向下取整，奇偶通吃
    }
};
```

#### Python

```python
class Solution:
    def minOperations(self, n: int) -> int:
        return n * n // 4
```

### 方法二：$O(n)$ 缺口累加（对拍验证用）

#### C++

```cpp
class Solution {
public:
    int minOperations(int n) {
        int ans = 0;
        for (int i = 0; i < n / 2; ++i) {
            ans += n - (2 * i + 1);   // 低于目标 n 的缺口逐项累加
        }
        return ans;
    }
};
```

#### Python

```python
class Solution:
    def minOperations(self, n: int) -> int:
        return sum(n - (2 * i + 1) for i in range(n // 2))
```

> 💡 赛时建议：先交方法二保底（思路直白、不易写错），再推公式换方法一；用 $n = 1 \ldots 100$ 对拍两法一致后放心提交。两法的化简关系：$\sum_{i=0}^{\lfloor n/2 \rfloor - 1} (n - 1 - 2i) = \lfloor n^2/4 \rfloor$。

## 8. 边界情况与易错点

1. **$n = 1$**：`arr = [1]` 天然相等，$\lfloor 1/4 \rfloor = 0$，公式自动给出，无需特判。
2. **$n = 2$**：`[1, 3]` 搬一步成 `[2, 2]`，$\lfloor 4/4 \rfloor = 1$ ✓；只有一对的退化情形，配对逻辑同样成立。
3. **目标值未必是数组元素**：$n$ 为偶数时数组全是奇数，$n$（偶数）不在其中——「使元素相等」不要求终值取自原数组。误以为「目标必须选数组里的数」会不敢下公式。
4. **混淆两类操作的目标统计量**：本题「搬运 1 单位」**保持总和**，目标是**平均值**；[462](https://leetcode.cn/problems/minimum-moves-to-equal-array-elements-ii/)「单个元素 $\pm 1$」不保持总和，目标是**中位数**。$n$ 恰好也是等差数列中位点上的数值，纯属对称巧合，不要由此误记「目标取中位数位置的值」。
5. **漏掉除以 2**：每对的搬运量是**差值的一半**（差为偶数）；直接把 $\mathrm{arr}[n-1-i] - \mathrm{arr}[i]$ 求和会得到 $2D$，答案翻倍。
6. **奇偶分讨写错**：`n * n / 4` 的整数除法已自动向下取整；若手写奇偶分支，注意奇数 $n$ 时中间元素贡献 $0$，项数是 $\lfloor n/2 \rfloor$ 而非 $\lceil n/2 \rceil$。
7. **溢出**：$n \le 10^4$ 时 $n^2 \le 10^8$，`int` 安全；若约束放大（$n \ge 5 \times 10^4$ 时 $n^2$ 超 `int`），须显式 `(long long)n * n`。
8. **$x = y$ 的空操作**：题面允许两下标相同（一减一加抵消，数组不变），但任何最优方案都不会用它——势函数视角下这一步 $\Phi$ 不降，纯浪费一步。
