# LeetCode 统计镜子反射路径数目 题解

## 1. 题目概述

- **标题 / 题号**：统计镜子反射路径数目（#3665，medium）
- **链接**：https://leetcode.cn/problems/twisted-mirror-path-count/
- **来源**：LeetCode 第 164 场双周赛 Q3
- **难度**：中等
- **标签**：动态规划、数组、矩阵、记忆化搜索

**题意**：给定 $m \times n$ 的二进制网格，`0` 是空格、`1` 是镜子。机器人从 $(0,0)$ 出发，只能向右或向下移动，目标是 $(m-1,n-1)$。当它**试图进入**一个镜子格时会被反射（**不进入**该格）：

- 向右进入镜子 → 转向下，移动到镜子**正下方**的格子；
- 向下进入镜子 → 转向右，移动到镜子**正右方**的格子；
- 若反射后落到网格外，该路径**无效**；
- 若反射后落到另一个镜子上，会**立即再次反射**（规则同上，方向由进入方向决定）。

返回不同的有效路径数，对 $10^9+7$ 取模。

**约束**：

- $2 \le m, n \le 500$
- `grid[i][j]` 为 0 或 1
- `grid[0][0] = grid[m-1][n-1] = 0`（起点终点必为空地）

## 2. 示例

**示例 1**

```text
输入：grid = [[0,1,0],[0,0,1],[1,0,0]]
输出：5
```

**示例 2**

```text
输入：grid = [[0,0],[0,0]]
输出：2
解释：只有「右→下」与「下→右」两条。
```

**示例 3**

```text
输入：grid = [[0,1,1],[1,1,0]]
输出：1
解释：(0,0) 向右撞 (0,1) 的镜子 → 落到 (1,1)，那里也是镜子 → 立即再反射 → 落到 (1,2)，到达终点；
      (0,0) 向下撞 (1,0) 的镜子 → 落到 (1,1) → 再反射 → (2,1) 越界，无效。答案 1。
```

## 3. 解题思路

### 3.1 暴力思路

模拟「一步一判」：状态为「当前位置 + 当前移动方向」，每次按规则走一格或反射一次。路径数可以指数级，但状态数只有 $O(mn)$ 级别——**问题在于要数路径条数，而不是判定可达性**，所以需要 DP。

难点在于：一次「向右」的尝试可能连续反射很多次，落点不是简单的 $(i, j+1)$。朴素做法是对每条路径逐步模拟，最坏 $O(mn \cdot (m+n))$ 甚至更差。

### 3.2 核心观察：把「一次移动」压缩成「一次落点查询」

![反射规则：向右撞镜子 ⇒ 转向下；向下撞镜子 ⇒ 转向右](images/bw164_q3_reflect_chain.svg)

定义函数 $h(r, c, d)$ = 「机器人以方向 $d$ **正要进入**格子 $(r,c)$ 时，最终停在哪里」，其中 $d = 0$ 表示向右进入、$d = 1$ 表示向下进入：

- $(r,c)$ 越界 → 返回「无效」；
- `grid[r][c] == 0` → 停在 $(r,c)$；
- `grid[r][c] == 1`（镜子）→ 反射：$d \gets 1 - d$，并沿新方向落到镜子旁的格子：
  - 原方向向右（$d=0$）→ 新方向向下，落点 $(r+1, c)$；
  - 原方向向下（$d=1$）→ 新方向向右，落点 $(r, c+1)$；
  - 继续对落点调用 $h$（若落点还是镜子，自然就「立即再次反射」）。

于是从当前格 $(i,j)$ 出发只有两种尝试：

$$\text{向右} \Rightarrow h(i,\ j+1,\ 0), \qquad \text{向下} \Rightarrow h(i+1,\ j,\ 1)$$

拿到落点后，把路径数累加过去即可。

**关键性质**：每次反射后落点的「行 + 列」严格增大（向右反射落到 $(r+1,c)$：行 +1；向下反射落到 $(r,c+1)$：列 +1），所以 $h$ 的递归链必然在有限步内终止，并且**落点的行列不小于当前格**。

### 3.3 算法流程

![落点行列都严格更大 ⇒ 按行优先顺序做 DP](images/bw164_q3_dp_order.svg)

```text
1. 记忆化：memoR[r][c]、memoD[r][c] 分别缓存 h(r,c,0)、h(r,c,1)
2. dp[0][0] = 1
3. 按行优先遍历每个格子 (i, j)：
       若 dp[i][j] == 0 则跳过
       A = h(i, j+1, 0)        # 尝试向右
       若 A 有效: dp[A] += dp[i][j]
       B = h(i+1, j, 1)        # 尝试向下
       若 B 有效: dp[B] += dp[i][j]
4. 返回 dp[m-1][n-1] mod 1e9+7
```

**为什么行优先就够**：落点 $(r', c')$ 满足 $r' \ge i$ 且 $c' \ge j$，且至少一个严格变大，所以落点在行优先序中一定排在 $(i,j)$ 之后，处理 $(i,j)$ 时它的 dp 尚未被使用——不会漏算也不会重复。

$h$ 有 $2mn$ 个状态，用记忆化后每条反射链只算一次，总代价 $O(mn)$。

### 3.4 示例演算

![示例 1：5 条有效路径（M 标记表示撞镜子后被反射）](images/bw164_q3_example_paths.svg)

以示例 3（`grid = [[0,1,1],[1,1,0]]`）说明「连续反射」：

- 向右：$h(0,1,0)$：$(0,1)$ 是镜子 → 转向下 → 落点 $(1,1)$ → $h(1,1,1)$：$(1,1)$ 是镜子 → 转向右 → 落点 $(1,2)$ → $h(1,2,0)$：$(1,2)$ 是空格 → 停在 $(1,2)$，正是终点，(0,0) 这一支贡献 1 条路径。
- 向下：$h(1,0,1)$：$(1,0)$ 是镜子 → 转向右 → 落点 $(1,1)$ → $h(1,1,0)$：镜子 → 转向下 → 落点 $(2,1)$ → 越界 → 无效。

故答案为 1，与题面一致。

示例 2 没有镜子：向右落到 $(0,1)$，再向右/向下到 $(1,1)$；向下落到 $(1,0)$，再向右到 $(1,1)$，共 2 条。

## 4. 算法细节

1. **状态表示**：$h$ 的三个参数中 $(r,c,d)$ 组合最多 $2mn$ 个，用两个二维数组（C++）或字典（Python）缓存。C++ 用 `-2` 表示「未计算」、`-1` 表示「无效」、其余为落点下标 $r \cdot n + c$。
2. **「进入」的语义**：$h(r,c,d)$ 的第一个参数是**目标格**，不是当前格。从 $(i,j)$ 尝试向右时调用的是 $h(i, j+1, 0)$，而不是 $h(i,j,0)$——这是最容易写错的地方。
3. **连续反射**：$h$ 内部用循环/递归自然处理「落点还是镜子」的情况，不需要在 DP 里额外展开。
4. **越界判定**：反射后落点越界 → 整条路径无效，**不累加**（不是「停住」）。
5. **取模**：每次累加都取模，避免溢出；C++ 用 `(cell + ways) % MOD`，`ways` 与 `cell` 都小于模数，`int` 相加不会溢出（< $2^{31}$）。
6. **记忆化的方向**：$h(r,c,0)$ 与 $h(r,c,1)$ 要分开缓存，因为同一格的两种进入方向落点不同。
7. **Python 的递归深度**：最坏反射链长度可达 $m + n \approx 1000$，用递归会逼近默认递归上限，因此用「走链 + 记忆化」的迭代写法。
8. **起点终点必为空地**：由约束保证，因此 $dp[0][0] = 1$ 不会被镜子覆盖。

## 5. 正确性证明

**引理 1（反射链终止且落点单调）**：对任意 $(r,c,d)$，$h$ 的计算在有限步内结束；且若落点 $(r',c')$ 有效，则 $r' \ge r$、$c' \ge c$，且 $r' + c' > r + c$。

**证明**：每次反射把 $(r,c)$ 更新为 $(r+1,c)$ 或 $(r,c+1)$，即 $r+c$ 严格 +1，因此步数不超过 $m + n$（否则越界返回无效）。单调性由每次更新只增不减即得。∎

**引理 2（$h$ 的语义正确）**：$h(r,c,d)$ 返回的落点，正是机器人以方向 $d$ 试图进入 $(r,c)$ 后、按题目规则连续反射所实际停留的格子；返回「无效」当且仅当题目规则会导致越界。

**证明**：对反射链长度归纳。链长 0：$(r,c)$ 越界或为空地，算法分别返回无效或 $(r,c)$，与规则一致。链长 $k+1$：$(r,c)$ 是镜子，规则说「转向后移到镜子正下方/正右方」，算法正是在翻转方向后把目标改成该相邻格并继续求解（链长减少 1），由归纳假设正确。∎

**引理 3（DP 不重不漏）**：按行优先遍历时，`dp[i][j]` 在用于转移之前已经累计了所有从 $(0,0)$ 到 $(i,j)$ 的有效路径数。

**证明**：对行优先序归纳。$(0,0)$ 只有初始值 1，且没有前驱（落点单调性保证没有路径能回到起点）。对 $(i,j) \ne (0,0)$，任何到达 $(i,j)$ 的路径，其最后一步必是「从某格 $(p,q)$ 尝试向右/向下」，由引理 1 落点单调性，$(p,q)$ 的行优先序严格小于 $(i,j)$，已在之前处理并把路径数累加进来。不同前驱的路径互不重复（最后一步的起点与方向唯一确定），且覆盖所有路径。∎

**定理**：`dp[m-1][n-1]` 等于有效路径数对 $10^9+7$ 取模的结果。

**证明**：由引理 2、3，DP 精确统计了所有以 $(0,0)$ 为起点、每一步都合法的路径；由题目，路径在到达 $(m-1,n-1)$ 时结束（该格无出边，落点若存在必然越界，因而不会继续贡献），所以终点 dp 值就是有效路径数。取模不改变计数的正确性。∎

## 6. 复杂度分析

- **时间**：$h$ 的状态共 $2mn$ 个，每个状态沿链前进的分摊代价为 $O(1)$（链上状态会被缓存），故记忆化部分 $O(mn)$；DP 遍历 $O(mn)$。合计 $O(mn)$，$m, n \le 500$ 时约 $2.5\times10^5$。
- **空间**：$O(mn)$，两个缓存数组 + dp 表。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int m, n;
    std::vector<std::vector<int>> g, memoR, memoD;

    // h(r, c, d)：机器人以方向 d 试图进入 (r, c)，返回最终停留格的下标（-1 表示飞出边界）
    // d = 0 向右，d = 1 向下
    int h(int r, int c, int d) {
        if (r < 0 || r >= m || c < 0 || c >= n) return -1;
        if (g[r][c] == 0) return r * n + c;
        std::vector<std::vector<int>>& memo = (d == 0 ? memoR : memoD);
        if (memo[r][c] != -2) return memo[r][c];
        int res = (d == 0) ? h(r + 1, c, 1) : h(r, c + 1, 0);
        memo[r][c] = res;
        return res;
    }

    int uniquePaths(std::vector<std::vector<int>>& grid) {
        g = grid;
        m = (int)g.size();
        n = (int)g[0].size();
        memoR.assign(m, std::vector<int>(n, -2));
        memoD.assign(m, std::vector<int>(n, -2));
        const int MOD = 1000000007;
        std::vector<std::vector<int>> dp(m, std::vector<int>(n, 0));
        dp[0][0] = 1;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                int ways = dp[i][j];
                if (ways == 0) continue;
                int a = h(i, j + 1, 0);   // 尝试向右
                if (a >= 0) {
                    int& cell = dp[a / n][a % n];
                    cell = (int)((cell + (long long)ways) % MOD);
                }
                int b = h(i + 1, j, 1);   // 尝试向下
                if (b >= 0) {
                    int& cell = dp[b / n][b % n];
                    cell = (int)((cell + (long long)ways) % MOD);
                }
            }
        }
        return dp[m - 1][n - 1];
    }
};
```

### Python

```python
class Solution:
    def uniquePaths(self, grid: list[list[int]]) -> int:
        MOD = 10 ** 9 + 7
        m, n = len(grid), len(grid[0])

        # h(r, c, d)：机器人以方向 d 正要进入格子 (r, c)，返回最终停留格；None 表示飞出边界。
        # d = 0 向右，d = 1 向下。用「走链 + 记忆化」实现，避免深递归。
        memo = {}

        def h(r, c, d):
            path = []
            while True:
                if r < 0 or r >= m or c < 0 or c >= n:
                    res = None
                    break
                if grid[r][c] == 0:
                    res = (r, c)
                    break
                key = (r, c, d)
                if key in memo:
                    res = memo[key]
                    break
                path.append(key)
                d ^= 1                                  # 撞到镜子：方向翻转
                if d == 1:
                    r += 1                              # 转向下：落到镜子正下方
                else:
                    c += 1                              # 转向右：落到镜子正右方
            for key in path:
                memo[key] = res
            return res

        dp = [[0] * n for _ in range(m)]
        dp[0][0] = 1
        for i in range(m):
            for j in range(n):
                ways = dp[i][j]
                if ways == 0:
                    continue
                for land in (h(i, j + 1, 0), h(i + 1, j, 1)):
                    if land is not None:
                        r, c = land
                        dp[r][c] = (dp[r][c] + ways) % MOD
        return dp[m - 1][n - 1]
```

## 8. 边界情况与易错点

1. **把「进入镜子」当成「落在镜子上」**：机器人被反射时**不进入**镜子格，落点是镜子的正下方/正右方。若误以为落在镜子上再继续，路径会算多。
2. **连续反射**：落点还是镜子时必须立即再反射（示例 3 的核心）。只在反射一次后停下会得到错误答案。
3. **`h` 的第一个参数是目标格**：从 $(i,j)$ 向右要调用 $h(i, j+1, 0)$，写成 $h(i, j, 0)$ 会原地打转。
4. **越界 = 路径无效**：不能「停在边界」或「忽略这一步」，必须丢弃整条路径。
5. **取模**：每步取模；C++ 里 `cell + ways` 用 `long long` 中转更稳。
6. **递归深度**：最坏反射链 $m + n \approx 1000$，Python 建议用迭代 + 记忆化（本题代码即如此）。
7. **镜像缓存要按方向分开**：同一格的 $h(r,c,0)$ 与 $h(r,c,1)$ 结果不同。
8. **起点与终点**：约束保证它们为空地，所以 $dp[0][0] = 1$ 与终点判定都安全；若输入不保证，需要额外特判。
9. **行列上限**：$500 \times 500$，$O(mn)$ 的 DP 与缓存都是 $2.5\times10^5$ 级别，注意不要写成 $O((mn)^2)$。

**延伸思考**：如果允许「向上/向左」移动，落点的单调性被破坏，DP 不再成立，需要按图论做「路径计数 + 拓扑」或状态压缩。如果镜子可以旋转（例如 `/` 与 `\` 两种反射方向），$h$ 的规则会变成「右↔上」等四种映射，但「落点行列单调」的性质不变，仍然可以行优先 DP。

**变体**：若要求「最多反射 $K$ 次」，就在状态里加上反射次数，复杂度变为 $O(Kmn)$；若要求「路径长度的期望」，则要在 DP 中同时维护概率。
