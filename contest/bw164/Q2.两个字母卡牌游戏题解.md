# LeetCode 两个字母卡牌游戏 题解

## 1. 题目概述

- **标题 / 题号**：两个字母卡牌游戏（#3664，medium）
- **链接**：https://leetcode.cn/problems/two-letter-card-game/
- **来源**：LeetCode 第 164 场双周赛 Q2
- **难度**：中等
- **标签**：数组、字符串、计数、贪心

**题意**：给定牌堆 `cards`（每张牌是长度为 2 的小写字母串）与字母 `x`。每轮必须从牌堆中取出两张**兼容**的牌并移除，得 1 分；两张牌兼容当且仅当它们的字符串**恰好有一个位置不同**，且两张牌都必须包含字母 `x`。无法继续时游戏结束。求最优策略下的**最大得分**。

**约束**：

- $2 \le \text{cards.length} \le 10^5$
- 每张牌长度 2，字母范围 `'a'`–`'j'`，`x` 也在该范围内

注意「恰好一个位置不同」：`"aa"` 与 `"aa"` 有两个位置相同（0 个不同），**不兼容**；`"ab"` 与 `"ba"` 两个位置都不同，也**不兼容**。

## 2. 示例

**示例 1**

```text
输入：cards = ["aa","ab","ba","ac"], x = "a"
输出：2
解释：第一轮取 "ab" 与 "ac"（只差第 2 位）；第二轮取 "aa" 与 "ba"（只差第 1 位）。
```

**示例 2**

```text
输入：cards = ["aa","ab","ba"], x = "a"
输出：1
解释：只能取 "aa" 与 "ba"，之后 "ab" 与前两者都不兼容（"ab" vs "ba" 两位都不同）。
```

**示例 3**

```text
输入：cards = ["aa","ab","ba","ac"], x = "b"
输出：0
解释：含 b 的牌只有 "ab" 与 "ba"，它们两位都不同，不兼容。
```

## 3. 解题思路

### 3.1 暴力思路

把问题看成「在兼容图上求最大匹配」，直接做一般图最大匹配（带重边）复杂度太高（$O(V^3)$ 且 $V = 10^5$）。若用贪心「能配就配」，会掉进陷阱：例如牌为 `"xx"`、`"xa"`、`"ay"`（$x$ 固定）时先配前两张就不优。必须先把**图的结构**分析清楚。

### 3.2 核心观察：含 $x$ 的牌只有三种型

![含 x 的牌只有三种型，兼容关系固定（x = a 为例）](images/bw164_q2_type_graph.svg)

任何含 $x$ 的牌，其两个位置中至少有一个是 $x$，因此只可能是：

- **A 型**：`"xx"`（两个位置都是 $x$），设共 $a$ 张；
- **B 型**：`"xc"`（第一位 $x$、第二位 $c \ne x$），按 $c$ 分组，第 $c$ 组有 $p_c$ 张；
- **C 型**：`"cx"`（第一位 $c \ne x$、第二位 $x$），按 $c$ 分组，第 $c$ 组有 $q_c$ 张。

逐对分析兼容性（「恰好一个位置不同」）：

| 配对 | 位置 1 | 位置 2 | 不同位置数 | 兼容？ |
|---|---|---|---|---|
| `xx` 与 `xc` | $x$ vs $x$ 同 | $x$ vs $c$ 异 | 1 | ✓ |
| `xx` 与 `cx` | $x$ vs $c$ 异 | $x$ vs $x$ 同 | 1 | ✓ |
| `xc` 与 `xd`（$c \ne d$） | 同 | 异 | 1 | ✓ |
| `xc` 与 `xc` | 同 | 同 | 0 | ✗ |
| `cx` 与 `dx`（$c \ne d$） | 异 | 同 | 1 | ✓ |
| `cx` 与 `cx` | 同 | 同 | 0 | ✗ |
| `xc` 与 `cy` | $x$ vs $c$ 异 | $c$ vs $y$ 异（$y = x$ 时才有同的情况，但 C 型要求首位 $\ne x$） | 2 | ✗ |
| `xx` 与 `xx` | 同 | 同 | 0 | ✗ |

于是兼容图的结构非常干净：

- $\{A\}$ 是**一个点**，与所有 B、C 都相连；
- **B 内部**是「按字母分的完全多部图」：同字母不相连，不同字母全相连；
- **C 内部**同理；
- B 与 C 之间**完全没有边**。

于是最大匹配可以按「B 内部」「C 内部」「A 去补」三块分别考虑。

### 3.3 类内最大匹配：完全多部图的配对公式

对一组「按字母分组的牌」（B 或 C），设总量 $T$、最大一组有 $M$ 张，则类内最多能配出

$$g = \min\Big(\Big\lfloor \frac{T}{2} \Big\rfloor,\ T - M\Big)$$

对：每对至少占 2 张牌，所以不超过 $\lfloor T/2 \rfloor$；每对里至多一张来自最大组（同组不相连），所以对数不超过「非最大组的牌数」$T - M$。这两个上界可以同时达到（把最大组的牌尽量与非最大组的牌交叉配对，剩下的非最大组内部再配）。

![最大匹配 = 类内能凑几对 + 用 xx 去补「落单」的牌](images/bw164_q2_matching_model.svg)

### 3.4 用 A 型去补：为什么「拿走最大的那组」最优

取 $u$ 张 `"xx"` 与 B 类配对（每张 `"xx"` 与一张 B 牌配，得 $u$ 对），剩下的 B 牌再按上面的公式配。此时 B 类贡献

$$f_B(u) = u + \min\Big(\Big\lfloor \frac{T_B - u}{2} \Big\rfloor,\ (T_B - u) - M_B(u)\Big)$$

其中 $M_B(u)$ 是「拿走 $u$ 张后，最大的字母组还剩多少张」。因为 $g$ 只通过 $M$ 依赖具体分布，且 $g$ 关于 $M$ 单调不增，所以**要让 $M$ 尽量小**——最优策略永远是**从当前最大的那组里拿牌**（水往低处流）。

$f_B(u)$ 可以用一个最大堆逐张模拟：每拿一张就把堆顶减一（减到 0 就弹出），同时记录当前的 $T$ 与 $M$，边模拟边把 $f_B(u)$ 存进数组。$T_B \le 10^5$，总代价 $O(T_B \log 26)$。

### 3.5 两类共享同一批 `"xx"`

设分给 B 类 $u$ 张 `"xx"`、分给 C 类 $v$ 张，则 $u + v \le a$。由于 $f_B, f_C$ 都关于各自参数**单调不减**（每多给一张 `"xx"`，最多还原地不动，不会变差），对固定的 $u$ 一定取 $v = \min(a - u,\ T_C)$。于是只需枚举 $u \in [0, \min(a, T_B)]$：

$$\text{ans} = \max_{u} \Big[ f_B(u) + f_C\big(\min(a - u,\ T_C)\big) \Big]$$

枚举量不超过 $\min(a, T_B) + 1 \le 10^5$。

### 3.6 示例演算

![示例 1 / 示例 2 的匹配演算：先分类计数，再用堆模拟拿牌，最后枚举分配](images/bw164_q2_example_walkthrough.svg)

**示例 1**：`cards = ["aa","ab","ba","ac"]`，$x = $ `'a'`。

- A：`"aa"` → $a = 1$；
- B：`"ab"`（$c = b$）、`"ac"`（$c = c$）→ $T_B = 2$，分组 $\{b:1, c:1\}$，$M_B = 1$；
- C：`"ba"`（$c = b$）→ $T_C = 1$，$M_C = 1$。

计算 $f_B$：$u = 0$：$g = \min(1,\ 2-1) = 1$ → $f_B(0) = 1$；$u = 1$：拿走一张（最大组任一张），剩 $\{1\}$，$T_B - u = 1$，$M = 1$ → $g = \min(0, 0) = 0$ → $f_B(1) = 1$。
$f_C$：$v = 0$：$g = \min(0, 1-1) = 0$ → $f_C(0) = 0$；$v = 1$：$g = 0$ → $f_C(1) = 1$。

枚举 $u$：$u = 0$ → $f_B(0) + f_C(\min(1,1)) = 1 + 1 = 2$；$u = 1$ → $f_B(1) + f_C(0) = 1 + 0 = 1$。答案 $2$。✓

**示例 2**：`["aa","ab","ba"]`，$x = $ `'a'`：$a = 1$，$T_B = 1$（`"ab"`），$T_C = 1$（`"ba"`）。$f_B = [0, 1]$，$f_C = [0, 1]$。
$u = 0$：$0 + f_C(1) = 1$；$u = 1$：$1 + f_C(0) = 1$。答案 $1$。✓

**示例 3**：$x = $ `'b'`：含 $b$ 的牌 `"ab"` 是 C 型（$c = a$）、`"ba"` 是 B 型（$c = a$），A 型 0 张。$T_B = 1, M_B = 1$，$f_B(0) = 0$；$T_C = 1$，$f_C(0) = 0$。答案 $0$。✓（B 与 C 之间没有边，正是「两位都不同」）

## 4. 算法细节

1. **分型计数**：遍历每张牌，若两位都是 $x$ 计入 $a$，否则若首位是 $x$ 计入 $p_{c}$，否则若末位是 $x$ 计入 $q_{c}$；不含 $x$ 的牌直接丢弃。
2. **用堆模拟拿牌**：`build(cnt)` 返回数组 $f$，$f[u]$ 对应「拿走 $u$ 张后该类的最大贡献」。注意每轮先更新 $T$、再把堆顶减一，然后读取新的 $M$。
3. **$f$ 的下标**：$f[0]$ 对应「一张 `"xx"` 都不用」；模拟循环跑 $T$ 次，得到 $f[0..T]$。
4. **枚举上界**：`u <= min(a, T_B)`；`v = min(a - u, T_C)` 保证不越界。
5. **`"xx"` 只有一种型**：不要按字母拆分 `"xx"`（它没有第二个字母维度），它不是「B 型的一种」。
6. **空格子**：某类完全为空时 $f = [0]$，长度为 1，$T = 0$，所有计算自动退化。
7. **字母表大小**：题目只有 `'a'`–`'j'` 共 10 个字母，因此堆中不同字母组至多 9 个（不含 $x$），$O(\log 26)$ 的堆操作可视为常数。

## 5. 正确性证明

**引理 1（兼容性分类）**：含 $x$ 的牌必属 $A$（`xx`）、$B_c$（`xc`，$c \ne x$）、$C_c$（`cx`，$c \ne x$）之一，且兼容关系恰为：

- $A$ 与任意 $B_c$、$C_c$ 兼容；
- $B_c$ 与 $B_d$ 兼容 $\iff c \ne d$；$C_c$ 与 $C_d$ 兼容 $\iff c \ne d$；
- $B_c$ 与 $C_d$ **永不**兼容；
- 同型牌两两不兼容（含 $A$ 与 $A$）。

**证明**：含 $x$ 的两种位置组合只有 $(x,x)$、$(x,c)$、$(c,x)$ 三类。对 $(x,c)$ 与 $(c',x)$：第 1 位 $x \ne c'$（因 $C$ 型要求 $c' \ne x$）必不同，第 2 位 $c \ne x$ 必不同，故至少 2 个位置不同，不兼容。其余情况直接比较两个位置即得表中结论；同型两张牌逐位相同，不同位置数为 0。∎

**引理 2（完全多部图的最大匹配）**：设某类牌的字母分组大小为 $p_1, \dots, p_r$，$T = \sum p_i$，$M = \max p_i$，则类内最大配对数 $= \min(\lfloor T/2\rfloor,\ T - M)$。

**证明**：*上界*：每对消耗 2 张牌 → 对数 $\le \lfloor T/2 \rfloor$；每对中不能两张都来自最大组（同组不相连），故每对至少消耗一张非最大组的牌 → 对数 $\le T - M$。

*可达*：设最大组有 $M$ 张。若 $M \le T - M$，把最大组的每张牌与非最大组的牌一一配对，再将剩余的非最大组牌两两配对（可能剩 1 张），共配出 $\lfloor T/2\rfloor$ 对，达到第一个上界。若 $M > T - M$，把最大组的牌与非最大组的牌逐一配对，直到非最大组用完，共 $T - M$ 对，达到第二个上界。∎

**引理 3（拿牌策略最优）**：对固定的 $u$，从当前最大的字母组里取牌可以使 $M_B(u)$ 最小，从而使 $f_B(u)$ 最大。

**证明**：$g = \min(\lfloor (T-u)/2 \rfloor, (T-u) - M)$ 中 $T - u$ 固定，$g$ 关于 $M$ 单调不增，故最大化 $g$ 等价于最小化剩余最大组大小。设当前分组大小为 $p_1 \ge \dots \ge p_r$，若从非最大组取走一张，则最大组不变；若从最大组取走，则最大值不增。因此每步取最大组是（弱）最优的，归纳即得。∎

**引理 4（枚举的完整性）**：最优方案中，B 类与 `"xx"` 的配对数 $u$ 与 C 类的配对数 $v$ 满足 $u + v \le a$，且此时总对数不超过 $f_B(u) + f_C(v)$；反之对每个 $u + v \le a$ 都存在方案达到 $f_B(u) + f_C(v)$。

**证明**：任一匹配可分解为「与 `"xx"` 配的对」和「类内配的对」。设与 `"xx"` 配的对中，B 类有 $u$ 对、C 类有 $v$ 对，则 $u + v \le a$；其余 B 牌（$T_B - u$ 张，可能已被取走 $u$ 张）内部配对不超过 $g$，故总对数 $\le f_B(u) + f_C(v)$。反过来，给定 $u, v$，按引理 3 的策略取走 $u$ 张 B 牌与 $v$ 张 C 牌，与 `"xx"` 配成 $u + v$ 对，再按引理 2 在剩余牌内配到 $g$，总对数恰为 $f_B(u) + f_C(v)$（各类之间无冲突）。∎

**引理 5（单调性）**：$f_B$ 与 $f_C$ 关于其参数单调不减。

**证明**：多给一张 `"xx"`，即从该类拿走一张牌：与 `"xx"` 配的对数 +1；剩余牌减少 1 张，由引理 2，$g$ 至多减少 1（$\lfloor (T-1)/2\rfloor \ge \lfloor T/2 \rfloor - 1$，且 $T - 1 - M' \ge T - M - 1$，其中 $M' \le M$）。二者相加不减。∎

**定理**：算法返回值为最优策略下的最大得分。

**证明**：由引理 4，最优值 $= \max_{u+v \le a} [f_B(u) + f_C(v)]$。由引理 5，对固定 $u$ 取 $v = \min(a-u, T_C)$ 最优，于是算法的枚举覆盖了最优解，且每一项都是可达的匹配大小，故返回值为最大匹配大小，即最大得分。∎

## 6. 复杂度分析

- **时间**：分型计数 $O(n)$；两次 `build` 各 $O(T \log 26)$（$T \le n$，堆中元素不超过 26 个）；枚举 $O(\min(a, T_B)) \le O(n)$。合计 $O(n \log 26) = O(n)$。
- **空间**：$O(26)$ 计数数组 + $O(T_B + T_C)$ 的两个 $f$ 数组。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int score(std::vector<std::string>& cards, char x) {
        int xi = x - 'a';
        long long A = 0;
        long long bCnt[26] = {0}, cCnt[26] = {0};
        for (const std::string& s : cards) {
            int p = s[0] - 'a', q = s[1] - 'a';
            if (p == xi && q == xi) A++;            // "xx"
            else if (p == xi) bCnt[q]++;            // "x?" 
            else if (q == xi) cCnt[p]++;            // "?x"
        }
        // f[u] = 用掉 u 张 "xx" 与这一类牌配对后，这一类能贡献的最大对数
        auto build = [](long long cnt[26]) {
            std::priority_queue<int> pq;
            long long T = 0;
            for (int i = 0; i < 26; i++) {
                if (cnt[i] > 0) { pq.push((int)cnt[i]); T += cnt[i]; }
            }
            std::vector<long long> f;
            long long L = pq.empty() ? 0 : pq.top();
            f.push_back(std::min(T / 2, T - L));    // u = 0
            while (!pq.empty()) {
                int c = pq.top(); pq.pop();
                T -= 1;
                if (--c > 0) pq.push(c);
                L = pq.empty() ? 0 : pq.top();
                f.push_back((long long)f.size() + std::min(T / 2, T - L));
            }
            return f;
        };
        std::vector<long long> fb = build(bCnt), fc = build(cCnt);
        long long B = (long long)fb.size() - 1, C = (long long)fc.size() - 1;
        long long best = 0;
        for (long long u = 0; u <= std::min(A, B); u++) {
            long long v = std::min(A - u, C);
            best = std::max(best, fb[u] + fc[v]);
        }
        return (int)best;
    }
};
```

### Python

```python
class Solution:
    def score(self, cards: list[str], x: str) -> int:
        import heapq
        xi = ord(x) - 97
        a = 0
        b_cnt = [0] * 26          # "x?"
        c_cnt = [0] * 26          # "?x"
        for s in cards:
            p, q = ord(s[0]) - 97, ord(s[1]) - 97
            if p == xi and q == xi:
                a += 1
            elif p == xi:
                b_cnt[q] += 1
            elif q == xi:
                c_cnt[p] += 1

        def build(cnt):
            # f[u] = 拿 u 张 "xx" 与这一类配对后，这一类的最大总对数
            heap = [-c for c in cnt if c > 0]
            heapq.heapify(heap)
            total = -sum(heap)
            big = -heap[0] if heap else 0
            f = [min(total // 2, total - big)]
            while heap:
                c = -heapq.heappop(heap)
                total -= 1
                if c - 1 > 0:
                    heapq.heappush(heap, -(c - 1))
                big = -heap[0] if heap else 0
                f.append(len(f) + min(total // 2, total - big))
            return f

        fb, fc = build(b_cnt), build(c_cnt)
        B, C = len(fb) - 1, len(fc) - 1
        return max(fb[u] + fc[min(a - u, C)] for u in range(min(a, B) + 1))
```

## 8. 边界情况与易错点

1. **把「同型牌」当成可配**：两张 `"bc"` 完全一样，不兼容。若误以为「同字母可配」，用 $\lfloor T/2 \rfloor$ 直接算就会偏大（示例 1 里 `"ab"` 与 `"ac"` 才可配，`"ab"` 与另一张 `"ab"` 不行）。
2. **把 B 与 C 混着配**：`"xc"` 与 `"cx"` 两位都不同，永不兼容，这是示例 3 的考点。
3. **只用 $\lfloor T/2\rfloor$ 而忽略最大组**：必须取 $\min(\lfloor T/2\rfloor, T - M)$。
4. **忘记 `"xx"` 可以补「落单」的牌**：只算类内配对会低估。
5. **`"xx"` 与 `"xx"` 配对**：两者相同，不兼容，$A$ 与 $A$ 之间无边。
6. **枚举上界写错**：`u` 最大到 $\min(a, T_B)$，`v = min(a - u, T_C)`；越界会数组越界或逻辑错。
7. **堆模拟的时机**：先 `T -= 1`、再更新堆顶、再读新的 $M$，顺序反了会用到旧的 $M$。
8. **不含 `x` 的牌**：直接丢弃，它们永远不能参与（每轮都要求两张都含 $x$）。
