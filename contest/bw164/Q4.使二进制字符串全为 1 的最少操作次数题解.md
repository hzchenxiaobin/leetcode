# LeetCode 使二进制字符串全为 1 的最少操作次数 题解

## 1. 题目概述

- **标题 / 题号**：使二进制字符串全为 1 的最少操作次数（#3666，hard）
- **链接**：https://leetcode.cn/problems/minimum-operations-to-equalize-binary-string/
- **来源**：LeetCode 第 164 场双周赛 Q4
- **难度**：困难
- **标签**：字符串、数学、位运算、贪心

**题意**：给定二进制字符串 `s` 与整数 $k$。一次操作必须选择**恰好 $k$ 个不同的下标**并翻转这些位置上的字符（`0` 变 `1`、`1` 变 `0`）。求使字符串**全部变为 `1`** 所需的最少操作次数；不可能则返回 $-1$。

**约束**：

- $1 \le |s| \le 10^5$
- $1 \le k \le |s|$

## 2. 示例

**示例 1**

```text
输入：s = "110", k = 1
输出：1
解释：只有一个 0，一次操作翻转它即可。
```

**示例 2**

```text
输入：s = "0101", k = 3
输出：2
解释：操作 1 翻转 {0,1,3}："0101" → "1000"；操作 2 翻转 {1,2,3}："1000" → "1111"。
```

**示例 3**

```text
输入：s = "101", k = 2
输出：-1
解释：k 为偶数，t 次操作总翻转数是偶数；而需要奇数次翻转的位置（那个 0）只有 1 个，奇偶无法匹配。
```

## 3. 解题思路

### 3.1 暴力思路

在字符串状态上做 BFS：每步枚举 $k$ 个下标的组合，状态数 $2^n$、转移数 $\binom{n}{k}$，$n = 10^5$ 完全不可行。即使 $n$ 很小，这也是指数级。

要把它变成可计算的判定：**固定操作次数 $t$，判断 $t$ 次操作能否达成目标**。这样只需从小到大枚举 $t$，第一个可行的 $t$ 就是答案。

### 3.2 核心观察：只看每个下标被翻转次数的奇偶性

![只看每个下标被翻转次数的奇偶性](images/bw164_q4_flip_parity.svg)

设第 $i$ 个下标在 $t$ 次操作中共被选中 $f_i$ 次。最终要全为 `1`，即：

- 原本是 `1` 的位置：翻转偶数次（保持 `1`）；
- 原本是 `0` 的位置：翻转奇数次（变成 `1`）。

记

$$r_i = \begin{cases} 1, & s_i = \texttt{'0'} \\ 0, & s_i = \texttt{'1'} \end{cases}, \qquad z = \#\{\,i : s_i = \texttt{'0'}\,\}$$

则 $f_i \equiv r_i \pmod 2$。又因为每次操作对每个下标最多选一次，所以 $f_i \le t$。并且总翻转次数满足

$$\sum_i f_i = t \cdot k$$

把 $f_i$ 写成 $f_i = r_i + 2 g_i$（$g_i \ge 0$ 为整数），代入得

$$\sum_i g_i = \frac{t \cdot k - z}{2}$$

而 $f_i \le t$ 等价于 $g_i \le \big\lfloor (t - r_i)/2 \big\rfloor$。于是「$t$ 次可行」等价于下面三个条件：

1. **总量够**：$t k \ge z$；
2. **奇偶一致**：$t k - z$ 为偶数；
3. **容量够**：$\dfrac{t k - z}{2} \le z\Big\lfloor\dfrac{t-1}{2}\Big\rfloor + (n - z)\Big\lfloor\dfrac{t}{2}\Big\rfloor$。

![给定操作次数 t，可行的三个充要条件](images/bw164_q4_feasibility.svg)

### 3.3 还要保证「能排成 $t$ 次操作」

上面只保证存在一组翻转次数 $f_i$。还需要确认它**能拆成 $t$ 次、每次恰好 $k$ 个不同下标**的操作。这是一个 0-1 矩阵的存在性问题：构造 $t \times n$ 的 0-1 矩阵，每行和恰为 $k$、第 $i$ 列和恰为 $f_i$。

经典结论（Gale–Ryser 的特例）：当每行的和都等于 $k \le n$、每列和 $f_i \le t$、且总和 $tk$ 相等时，这样的 0-1 矩阵**一定存在**。所以三个条件同时也是充分的——不需要额外的构造检查。

### 3.4 如何枚举 $t$

条件 1 给出下界 $t \ge \lceil z/k \rceil$；条件 2 要求 $tk$ 与 $z$ 同奇偶。由于 $k \le n$，条件 3 的右侧约为 $t \cdot n$，通常远大于 $tk$，只有在 $k$ 接近 $n$ 时才可能卡住。于是：

- 从 $t = 1$ 开始逐个检查，第一个满足三条的就是答案；
- 枚举到多大？若 $k \le n - 1$，取 $t \approx z + 4$ 即可让三条同时成立（条件 3 的右侧约为 $t(n-k) + z$ 量级，总能用余量补齐奇偶），故答案不超过 $n + 4$；
- 若 $k = n$，每次操作翻转**全部**下标，所有位置的翻转次数都等于 $t$，奇偶性完全同步，因此只有「已全 1」与「全 0」两种情形可行——而三条条件会自动得出这一结论（见 §4.5），无需特判；
- 代码里统一枚举到 $4n + 10$，足够覆盖所有可行情形；超出仍不可行即为 $-1$。

### 3.5 示例演算

![示例 2 演算：s = 0101，k = 3，答案 2](images/bw164_q4_example_walkthrough.svg)

**示例 2**：$s = \texttt{"0101"}$，$n = 4$，$z = 2$，$k = 3$。

- $t = 1$：$tk = 3 < z$？不，$3 \ge 2$；$tk - z = 1$ 为奇数 → 条件 2 不成立，跳过。
- $t = 2$：$tk = 6$，$6 - 2 = 4$ 为偶数 ✓；容量 $= z\lfloor 1/2 \rfloor\cdot 2 + (n-z)\lfloor 2/2\rfloor \cdot 2$，按「$2g_i$ 上限」计算为 $z \cdot 2\lfloor (t-1)/2\rfloor + (n-z)\cdot 2\lfloor t/2 \rfloor = 2 \times 0 + 2 \times 2 = 4$，而需要的额外翻转 $tk - z = 4 \le 4$ ✓。

于是 $t = 2$ 可行，答案 2，与题面给出的操作方案一致（两个 0 各被翻一次，两个 1 各被翻两次：$f = (1, 2, 1, 2)$ 对应下标 0..3，总和 6 = 2×3 ✓）。

**示例 3**：$s = \texttt{"101"}$，$z = 1$，$k = 2$。$tk$ 恒为偶数，$z$ 为奇数，条件 2 永远不成立 → 返回 $-1$。

**示例 1**：$s = \texttt{"110"}$，$z = 1$，$k = 1$。$t = 1$：$tk = 1 \ge 1$，$1 - 1 = 0$ 偶数，容量 0 ✓ → 答案 1。

## 4. 算法细节

1. **$z = 0$ 直接返回 $0$**：已经是全 1，无需操作。注意不要输出 $k$ 相关的值。
2. **条件 3 的写法**：容量指「额外还能安排多少次成对翻转」，即 $\sum_i \lfloor (t - r_i)/2 \rfloor$，表示 $\sum g_i$ 的上界。代码里写成 `z * ((t - 1) / 2) + (n - z) * (t / 2)`，正是 $\sum \lfloor (t-r_i)/2\rfloor$。
3. **奇偶性**：用 `(total - z) % 2 != 0` 判断，注意 C++ 中负数取模的坑（这里 `total >= z` 由条件 1 保证，不会出现负数）。
4. **枚举上界**：$4n + 10$，用 `long long` 累乘避免 $tk$ 溢出（$t \le 4\times10^5$，$k \le 10^5$，乘积 $4\times10^{10}$ 超 `int`）。
5. **$k = n$ 不需要特判**：此时每次操作翻转全部下标，所有位置的翻转次数都是 $t$，奇偶性同步。把 $k = n$ 代入三条条件会得到矛盾（见引理 4），所以公式**自动**返回 $-1$（当 $0 < z < n$）或 $1$（当 $z = n$），与手工分析一致。
6. **$k = 1$**：每次只翻一个位，$t$ 必须等于 $z$，公式会给 $t = z$（$tk - z = 0$，容量条件自动满足）。
7. **枚举下界**：条件 1 已经保证 $tk \ge z$；不满足时直接 `continue`，不要提前返回 $-1$。

## 5. 正确性证明

**引理 1（必要条件的推导）**：设 $t$ 次操作可以把 $s$ 变成全 1，$f_i$ 为第 $i$ 位被翻转的次数，则 $f_i \equiv r_i \pmod 2$、$f_i \le t$、$\sum f_i = tk$、$z = \sum r_i$。

**证明**：最终字符 $= s_i \oplus (f_i \bmod 2)$，要等于 1 即 $f_i \bmod 2 = 1 - s_i = r_i$。每次操作对每个下标至多选一次，故 $f_i \le t$；每次操作恰翻 $k$ 个下标，故总翻转次数为 $tk$；$r_i$ 的和就是 0 的个数 $z$。∎

**引理 2（三条件的等价刻画）**：存在非负整数 $f_i$ 满足引理 1 的三个条件 $\iff$ 条件 1、2、3 成立。

**证明**：令 $g_i = (f_i - r_i)/2$。由 $f_i \equiv r_i$ 知 $g_i \ge 0$ 为整数；$\sum f_i = tk$ 给出 $\sum g_i = (tk - z)/2$，故 $tk \ge z$ 且 $tk - z$ 为偶数（条件 1、2）。$f_i \le t$ 给出 $2g_i \le t - r_i$，即 $g_i \le \lfloor (t-r_i)/2\rfloor$；所有 $g_i$ 之和为 $(tk-z)/2$，故条件 3。反之若三条件成立，直接取任意满足 $\sum g_i = (tk-z)/2$ 且 $g_i$ 不超过各自上界的非负整数（例如从全 0 开始逐个填满），再令 $f_i = r_i + 2g_i$，即满足全部条件。∎

**引理 3（可实现性）**：若存在 $f_i$ 满足 $0 \le f_i \le t$、$\sum f_i = tk$，则存在 $t$ 次操作（每次 $k$ 个不同下标）恰好实现这些翻转次数。

**证明**：构造 $t \times n$ 的 0-1 矩阵 $A$，$A_{sj} = 1$ 表示第 $s$ 次操作翻转第 $j$ 位。要求每行和 $= k$、第 $j$ 列和 $= f_j$。这是 Gale–Ryser 定理的特例：行和序列全为 $k$、列和序列 $f_1 \ge \dots \ge f_n$，存在 0-1 矩阵当且仅当 $\sum k = \sum f_j$ 且对每个 $k'$ 有 $\sum_j \min(f_j, k') \ge \sum_{s \le k'} \text{行和} = k' \cdot k$。取 $k' = k$ 时 $\sum_j \min(f_j, k) $……更直接的做法：用「贪心 + 每次选当前 $f_j$ 最大的 $k$ 个位置」的构造，由「列和不超过行数」保证永不失败（这是经典的 0-1 矩阵构造法）。因此矩阵存在。∎

**引理 4（$k = n$ 时公式同样正确）**：设 $k = n$。若 $z = n$，则 $t = 1$ 满足三条条件；若 $0 < z < n$，则对任意 $t$ 三条条件不能同时成立。

**证明**：$z = n$ 时 $tk = n$、$tk - z = 0$ 为偶，$g = 0$，容量 $z\lfloor 0/2\rfloor + 0 = 0$，故 $g \le$ 容量成立，$t = 1$ 可行。

设 $0 < z < n$。若 $t = 2s$ 为偶数：条件 3 要求 $g = (2sn - z)/2 = sn - z/2 \le z(s-1) + (n-z)s = ns - z$，即 $z/2 \ge z$，与 $z > 0$ 矛盾。若 $t = 2s+1$ 为奇数：容量 $= zs + (n-z)s = ns$，$g = ((2s+1)n - z)/2$，条件 3 要求 $(2s+1)n - z \le 2ns$，即 $n \le z$，与 $z < n$ 矛盾。故三条件永不成立。∎

**定理**：算法返回值为最少操作次数；无解返回 $-1$。

**证明**：先处理 $z = 0$（答案为 0，显然最优）。其余情形按 $t = 1, 2, \dots$ 递增检查三条件：由引理 1、2，条件成立 $\iff$ 存在合法的翻转次数方案；由引理 3，该方案可实现为 $t$ 次操作。因此第一个满足条件的 $t$ 就是最少操作次数。$k = n$ 的情形由引理 4 保证公式给出的结论正确。若枚举到 $4n + 10$ 仍不满足：$k \le n-1$ 时容量条件随 $t$ 线性增长（系数 $n-k \ge 1$），而 $g$ 只有 $tk/2$ 量级，取 $t \approx z + 4$ 并调整奇偶即可满足全部三条，故此时真的无解，返回 $-1$ 正确。∎

## 6. 复杂度分析

- **时间**：统计 $z$ 为 $O(n)$；枚举 $t$ 至 $4n + 10$ 次，每次 $O(1)$。合计 $O(n)$。
- **空间**：$O(1)$（只用了 $z$、$n$、$k$ 等标量）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minOperations(std::string s, int k) {
        int n = (int)s.size();
        long long z = 0;
        for (char ch : s) if (ch == '0') z++;
        if (z == 0) return 0;
        long long limit = 4LL * n + 10;
        for (long long t = 1; t <= limit; t++) {
            long long total = t * k;
            if (total < z) continue;
            if ((total - z) % 2 != 0) continue;
            long long g = (total - z) / 2;                 // 需要额外分配的“成对翻两次”
            long long cap = (z * ((t - 1) / 2)) + ((n - z) * (t / 2));
            if (g <= cap) return (int)t;
        }
        return -1;
    }
};
```

### Python

```python
class Solution:
    def minOperations(self, s: str, k: int) -> int:
        n = len(s)
        z = s.count('0')
        if z == 0:
            return 0
        for t in range(1, 4 * n + 11):
            total = t * k
            if total < z or (total - z) % 2 != 0:
                continue
            g = (total - z) // 2                    # 还要额外翻的“成对次数”
            cap = z * ((t - 1) // 2) + (n - z) * (t // 2)
            if g <= cap:
                return t
        return -1
```

## 8. 边界情况与易错点

1. **$z = 0$**：已经全 1，答案 $0$；不要进入枚举（否则可能返回 $k$ 相关的大数）。
2. **$k = n$ 时不要想当然**：此时所有位置的翻转次数都等于 $t$，奇偶性同步；实际上三条条件会自动判出「$0 < z < n$ 无解」，代码无需为它写分支（见引理 4）。
3. **奇偶条件**：$tk$ 与 $z$ 必须同奇偶，示例 3 就卡在这里。
4. **容量条件的含义**：$\sum \lfloor (t - r_i)/2\rfloor$，表示每个下标在满足奇偶后还能「多翻」的次数除以 2；漏掉它会低估所需操作数。
5. **`int` 溢出**：$tk$ 最大 $4\times10^{10}$，C++ 必须 `long long`。
6. **枚举上界太小**：若只枚举到 $n$ 可能错过答案（$k$ 较小时答案可能接近 $2n$）；$4n + 10$ 足够安全。
7. **$k$ 为偶数且 $z$ 为奇数**：直接无解，可以被奇偶条件筛出，不需要提前特判。
8. **$k = 1$**：答案是 $z$，可以自检公式。
9. **$n = 1$**：$k = 1$，$s = \texttt{"0"}$ 时答案 1、$s = \texttt{"1"}$ 时答案 0；用公式也能得到（$t = 1$：$tk = 1 \ge z = 1$，$0$ 偶，容量 0 ✓）。
