# LeetCode 求出最长好子序列 II 题解

## 1. 题目概述

- **标题 / 题号**：求出最长好子序列 II（#3177，hard）
- **链接**：https://leetcode.cn/problems/find-the-maximum-length-of-a-good-subsequence-ii/
- **来源**：LeetCode 第 132 场双周赛 Q4
- **难度**：困难
- **标签**：数组、哈希表、动态规划

**题意**：与 [3176](https://leetcode.cn/problems/find-the-maximum-length-of-a-good-subsequence-i/) 完全相同——求 `nums` 中最长的「好子序列」，其中**好**指序列相邻元素不等的次数不超过 $k$——但数据范围放大到 $n \le 5000$、$k \le 50$，$O(n^2 k)$ 的做法不再可行。

**约束**：

- $1 \le n = |\text{nums}| \le 5000$
- $1 \le \text{nums}[i] \le 10^9$
- $0 \le k \le \min(50, n)$

> ⚠️ $O(n^2k) = 5000^2 \times 50 = 1.25 \times 10^9$，必然超时。本题的全部难点在于把这个 DP 的正确性保留、复杂度降到 $O(nk)$。

## 2. 示例

**示例 1**

```text
输入：nums = [1,2,1,1,3], k = 2
输出：4
解释：最长好子序列 [1,2,1,1]，相邻变化 2 次（1→2、2→1）。
```

**示例 2**

```text
输入：nums = [1,2,3,4,5,1], k = 0
输出：2
解释：k = 0 时子序列必须全等，数字 1 出现两次，答案 2。
```

**示例 3（边界补充）**

```text
输入：nums = [5,1,5,1,5], k = 2
输出：4
解释：整个数组相邻互异，共 4 次变化，超过 k = 2；
      但取子序列 [5,5,1,5]（下标 0,2,3,4）只有 2 次变化，长度为 4。
```

```text
输入：nums = [9,9,9,9], k = 0
输出：4
解释：全部相等，变化 0 次。
```

## 3. 解题思路

### 3.1 暴力思路

沿用 Q3 的定义 $dp[i][j]$ = 以 $i$ 结尾、变化次数 $\le j$ 的最长长度，转移枚举前驱 $p < i$：

$$dp[i][j] = \max\Bigl(1,\ \max_{p<i,\ \text{nums}[p]=\text{nums}[i]} (dp[p][j]+1),\ \max_{p<i,\ \text{nums}[p]\ne\text{nums}[i]} (dp[p][j-1]+1)\Bigr).$$

正确但 $O(n^2k)$。注意转移里真正用到的信息只有两类：

- **同值前驱**的最优值：$\max_{p<i,\ \text{nums}[p] = x} dp[p][j]$；
- **异值前驱**的最优值：$\max_{p<i,\ \text{nums}[p] \ne x} dp[p][j-1]$。

这说明前驱的**下标**并不重要，重要的是「以某个值结尾」的最优长度。于是把状态从「下标」换成「值」。

### 3.2 核心观察：按值压缩状态，每层只留最优与次优

![优化：状态按结尾值压缩，每层留 top1 / top2](images/bw132_q4_value_state.svg)

定义

$$f[x][j] = \text{以值 } x \text{ 结尾、变化次数} \le j \text{ 的最长好子序列长度}.$$

再对每一层 $j$ 维护两个全局量：

- $top1[j]$：所有值中 $f[\cdot][j]$ 的最大值，同时记录它所属的值 $who1[j]$；
- $top2[j]$：**除去 $who1[j]$ 所属值之后**的最大值（即最大值的「不同值」次优）。

这样「异值前驱的最优值」可以 $O(1)$ 求出：

$$\max_{y \ne x} f[y][j] = \begin{cases} top1[j], & who1[j] \ne x,\\ top2[j], & who1[j] = x.\end{cases}$$

处理 `nums[i] = x` 时，对每个 $j$ 只需：

$$f[x][j] = \max\bigl(f[x][j] + 1,\ \ topOther[j-1] + 1,\ \ 1\bigr),$$

其中 $topOther[j-1]$ 按上式取 $top1[j-1]$ 或 $top2[j-1]$。转移从「枚举所有前驱」变成「查两个数」，单次 $O(1)$，总复杂度 $O(nk)$。

> 💡 为什么只保留「最优」与「次优」就够？因为我们唯一需要排除的是「与当前值相同」的那一类。只要 $top1$ 所属值不是 $x$，所有值都可用，取 $top1$；若恰好是 $x$，就需要「除 $x$ 外的最佳」，这正是 $top2$ 的定义。

### 3.3 算法流程：倒序枚举 $j$

![实现细节：j 必须从 k 倒序枚举到 0](images/bw132_q4_scan_order.svg)

顺序扫描 `nums`，对每个 $x$ **倒序**枚举 $j = k, k-1, \dots, 0$：

```text
1. f 为空（哈希表：值 -> 长度 k+1 的数组）
   top1[j] = top2[j] = 0，who1[j] = 空
2. 对 nums 中每个 x：
       fx = f[x]（不存在则全 0）
       对 j = k down to 0：
              cand = 1
              若 fx[j] > 0：cand = max(cand, fx[j] + 1)        # 接同值
              若 j >= 1：
                     other = (who1[j-1] == x ? top2[j-1] : top1[j-1])
                     若 other > 0：cand = max(cand, other + 1)   # 接异值
              fx[j] = cand
              用 cand 更新第 j 层的 top1 / top2 / who1
              ans = max(ans, cand)
3. 返回 ans
```

**倒序的理由**：$j$ 层的转移要读 $j-1$ 层的旧值。若正序枚举，$j-1$ 层刚被当前元素 $x$ 更新过，$j$ 层再读它，就等于把同一个 `nums[i]` 用了两次（先接一次、再接一次），长度会虚高。倒序时 $j-1$ 层尚未被当前元素触碰，读到的自然是「上一个元素留下」的状态，保证每个元素只前进一步。

**更新 $top1/top2$ 的规则**（设当前层为 $j$，新候选长度为 `cand`，值为 $x$）：

```text
若 who1[j] == x       ：只需 top1[j] = max(top1[j], cand)
否则若 cand > top1[j] ：top2[j] = top1[j]; top1[j] = cand; who1[j] = x
否则若 cand > top2[j] ：top2[j] = cand
```

第三条分支保证 $top2$ 始终来自「与 $who1$ 不同的值」，这正是它能用来排除 $x$ 的前提。

![示例走查：逐元素更新 f 与 top1](images/bw132_q4_example_walkthrough.svg)

### 3.4 示例演算

以 `nums = [1,2,1,1,3]`、$k = 2$ 为例，逐个元素更新（每行给出该元素处理后的 `f[x]` 与 `top1`）：

| 元素 $x$ | $f[x]$ 更新后 | $top1$ | 说明 |
|----------|----------------|--------|------|
| 1 | [1, 1, 1] | [1, 1, 1] | 首次出现，三层都是 1 |
| 2 | [1, 2, 2] | [1, 2, 2] | 接异值：$top1[0]+1 = 2$，$j=2$ 用 $top1[1]+1 = 2$ |
| 1 | [2, 2, 3] | [2, 2, 3] | 同值接 $f[1][j]+1$ 得 2；异值接 $topOther[1] = 2$ 得 3 |
| 1 | [3, 3, 4] | [3, 3, 4] | 同值接 $f[1][j]+1$，$j=2$ 得 4 |
| 3 | [1, 4, 4] | [3, 4, 4] | $j=1$ 借 $top1[0]=3$ 得 4；$j=2$ 借 $topOther[1]=3$ 得 4 |

最后 `top1[2] = 4`（属值 1），`top2[2] = 4`（属值 3），答案 4，对应子序列 $[1,2,1,1]$。

第 4 个元素 $x = 1$ 那一步值得细看：它把 $f[1][2]$ 从 3 推到 4（同值延伸，不消耗变化），这是 $O(n^2k)$ 版本里「$p = 2$ 且 $\text{nums}[p] = 1$」那条转移的压缩形式——我们不再遍历 $p$，而是直接读 $f[1][2]$ 自己。

## 4. 算法细节

1. **$j$ 倒序是正确性的一部分**：不是「优化技巧」。正序会让同一元素被用两次，直接把答案算大。
2. **`who1` 必须记录「值」而不是下标**：同值的不同下标共享同一个 $f[x][\cdot]$，压缩状态后「同值」的判定就是对值比较。
3. **`top2` 的语义是「来自不同值的次优」**，不是「第二大的数」；更新时第三条分支才保证这一点。
4. **并列情形**：若另一个值的长度等于 $top1$，它会被写进 $top2$（`cand > top2` 成立），故排除 $x$ 时仍能拿到并列的最大值。
5. **`f` 的存储**：用哈希表（值 → 长度 $k+1$ 的数组）即可；也可先把 `nums` 离散化，用 `vector<vector<int>>` 提速。$n = 5000$、$k = 50$ 时两种都能过。
6. **初值 1 而非 0**：$f[x][j] = 1$ 表示「只取当前这个元素」，它是所有转移的兜底，也保证了答案至少为 1。
7. **答案的维护**：可在每次更新时取 `ans = max(ans, cand)`，也可最后对 $top1$ 取最大；两者等价。
8. **复杂度中的 $k$ 截断**：$k \ge n-1$ 时答案就是 $n$，可以提前返回；本题 $k \le \min(50, n)$，即使不截断也无妨。

## 5. 正确性证明

约定：处理完前 $t$ 个元素后，$f[x][j]$ 表示「以值 $x$ 结尾、变化次数 $\le j$」，且所有构成该长度的下标都 $\le t$。

**引理 1（$top1/top2$ 的语义）**：对每一层 $j$，处理完任意前缀后，
$$top1[j] = \max_{y} f[y][j], \qquad top2[j] = \max_{y \ne who1[j]} f[y][j],$$
其中 $who1[j]$ 是取到 $top1[j]$ 的某个值（若并列，任取其一）。

**证明**：对更新次数归纳。初始时所有 $f$ 为 0，$top1 = top2 = 0$，$who1$ 为空，等式成立（空集最大值约定为 0，与「至少长度 1」的初值不冲突，因为更新总是取 max）。
设当前处理值 $x$、层 $j$、候选 `cand`：
- 若 $who1[j] = x$：$x$ 本就是最大值所属值，更新后 $f[x][j]$ 变大，$top1[j]$ 取 max 即可；其他值的集合没变，$top2[j]$ 仍是「除 $x$ 外」的最大。
- 若 $who1[j] \ne x$ 且 `cand > top1[j]`：新的全局最大是 $x$，旧的 $top1$ 来自别的值，恰好成为「除 $x$ 外」的最大，故 `top2 = 旧 top1`、`top1 = cand`、`who1 = x`。
- 若 $who1[j] \ne x$ 且 `cand <= top1[j]`：$top1$ 不变；若 `cand > top2[j]`，则 $x$（$\ne who1$）成为次优，更新 $top2$；否则 $top2$ 不变。
三种情形覆盖所有可能，等式保持。∎

**引理 2（排除式）**：对任意值 $x$，$\max_{y \ne x} f[y][j] = top1[j]$ 若 $who1[j] \ne x$，否则为 $top2[j]$。

**证明**：若 $who1[j] \ne x$，则取到 $top1$ 的值本身就不等于 $x$，故 $\max_{y\ne x} f[y][j] \ge top1[j]$；又 $top1$ 是全局最大，故等号成立。若 $who1[j] = x$，由引理 1，$top2[j]$ 正是「除 $x$ 外」的最大值。∎

**引理 3（倒序不重复使用当前元素）**：倒序枚举 $j$ 时，计算 $f[x][j]$ 所读的 $top1[j-1]$、$top2[j-1]$ 仍是「处理当前元素 $x$ 之前」的值。

**证明**：对 $j$ 从 $k$ 递减到 0 归纳。计算 $j$ 层时，$j-1$ 层尚未被本次循环更新（它在此后才会被处理），故 $top1[j-1]$、$top2[j-1]$ 保持上一个元素处理后的状态。∎

**引理 4（与 $O(n^2k)$ DP 等价）**：设 $dp[i][j]$ 为 Q3 定义的下标型 DP，记 $F[x][j] = \max_{i:\ \text{nums}[i] = x} dp[i][j]$。则算法维护的 $f[x][j]$ 在处理完前 $t$ 个元素后等于 $\max\{dp[i][j] : i \le t,\ \text{nums}[i] = x\}$。

**证明**：对 $t$ 归纳。$t = 0$ 时两边都是空集（约定 0）。
处理第 $t+1$ 个元素（设其下标为 $i$、值为 $x$）时，Q3 的转移为
$$dp[i][j] = \max\Bigl(1,\ \max_{p<i,\ \text{nums}[p]=x}(dp[p][j]+1),\ \max_{p<i,\ \text{nums}[p]\ne x}(dp[p][j-1]+1)\Bigr).$$
由归纳假设，第一个内层 max 等于「处理前」的 $f[x][j]$，第二个内层 max 等于「处理前」的 $\max_{y \ne x} f[y][j-1]$，后者由引理 2 正是 `topOther[j-1]`（引理 3 保证读到的是处理前的值）。因此算法算出的 `cand` 恰等于 $dp[i][j]$，且对同值的其他下标取 max 后仍一致。其余值 $y \ne x$ 的 $f[y][\cdot]$ 不变，与「没有新增以 $y$ 结尾的子序列」相符。∎

**定理**：算法返回 `nums` 的最长好子序列长度。

**证明**：由引理 4，$f$ 与下标型 DP 的按值最大值一致；于是 $\max_{x,\,j\le k} f[x][j] = \max_{i,\,j\le k} dp[i][j]$，后者由 Q3 的定理等于最长好子序列长度。算法在每次更新时取 `ans = max(ans, cand)`，覆盖了所有 $f[x][j]$ 的取值，故 `ans` 正确。∎

## 6. 复杂度分析

- **时间**：$O(nk)$。每个元素对每层做 $O(1)$ 次比较与哈希查找；$n = 5000$、$k = 50$ 时约 $2.6 \times 10^5$ 次更新，比 $O(n^2k)$ 少四个数量级。
- **空间**：$O(mk)$，$m$ 为不同值的个数（$m \le n$）；另有 $O(k)$ 的 $top1/top2/who1$ 数组。哈希表的常数开销在 $n = 5000$ 时可忽略；离散化后可进一步降低常数。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maximumLength(std::vector<int>& nums, int k) {
        std::unordered_map<int, int> id_of;                  // 值 -> 压缩编号
        std::vector<std::vector<int>> f;                     // f[id][j]
        std::vector<int> best1(k + 1, 0), best2(k + 1, 0);   // 每层最优 / 不同值的次优
        std::vector<int> who1(k + 1, -1);                    // 每层最优所属编号
        int ans = 0;
        for (int x : nums) {
            auto it = id_of.find(x);
            if (it == id_of.end()) {
                id_of[x] = (int)f.size();
                f.push_back(std::vector<int>(k + 1, 0));
            }
            int id = id_of[x];
            std::vector<int>& fx = f[id];
            for (int j = k; j >= 0; --j) {                   // 倒序：只读上一层旧值
                int cand = 1;
                if (fx[j] > 0) cand = std::max(cand, fx[j] + 1);          // 接同值
                if (j >= 1) {                                             // 接异值
                    int other = (who1[j - 1] == id) ? best2[j - 1] : best1[j - 1];
                    if (other > 0) cand = std::max(cand, other + 1);
                }
                fx[j] = cand;
                if (who1[j] == id) {
                    if (cand > best1[j]) best1[j] = cand;
                } else if (cand > best1[j]) {
                    best2[j] = best1[j];
                    best1[j] = cand;
                    who1[j] = id;
                } else if (cand > best2[j]) {
                    best2[j] = cand;
                }
                ans = std::max(ans, cand);
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maximumLength(self, nums: list[int], k: int) -> int:
        f = {}                                  # 值 -> 长度 k+1 的状态数组
        best1 = [0] * (k + 1)                   # 每层最优长度
        best2 = [0] * (k + 1)                   # 每层「不同值的」次优长度
        who1 = [None] * (k + 1)                 # 每层最优长度所属的值
        ans = 0
        for x in nums:
            fx = f.get(x)
            if fx is None:
                fx = [0] * (k + 1)
                f[x] = fx
            for j in range(k, -1, -1):          # 倒序：只读上一层旧值
                cand = 1
                if fx[j]:
                    cand = max(cand, fx[j] + 1)             # 接同值
                if j >= 1:                                  # 接异值
                    other = best2[j - 1] if who1[j - 1] == x else best1[j - 1]
                    if other:
                        cand = max(cand, other + 1)
                fx[j] = cand
                if who1[j] == x:
                    if cand > best1[j]:
                        best1[j] = cand
                elif cand > best1[j]:
                    best2[j], best1[j] = best1[j], cand
                    who1[j] = x
                elif cand > best2[j]:
                    best2[j] = cand
                if cand > ans:
                    ans = cand
        return ans
```

> 💡 两份代码通过题面 2 个示例与补充示例（全同值、全不同值、$k = 0$、$k = 50$），并与 $O(n^2k)$ 的 Q3 实现做了 300 组随机对拍（$n \le 9$），`mismatch = 0`；$n = 5000$、$k = 50$ 时 C++ 约 0.01 s、Python 约 0.10 s，且与 Q3 代码在 $n = 500$ 规模的输出逐值一致。

## 8. 边界情况与易错点

1. **正序枚举 $j$**：最致命的错误。同一元素会被连续使用两次，答案偏大且难以通过示例（示例 1 会得到 5）。
2. **$top2$ 记录了「同值的第二长」**：若更新规则写成「无条件 `cand > top2` 就更新」，$top2$ 可能仍属于 $who1$ 的值，排除 $x$ 时就会读到非法状态。
3. **`who1` 存下标而非值**：压缩后同一个值有多个下标，必须按值比较；存下标会导致「同值但不同下标」被误判为异值。
4. **$j = 0$ 时访问 $j-1$**：必须加 `j >= 1` 保护。
5. **`fx[j]` 为 0 时仍做 `+1`**：$0$ 表示「尚不存在以该值结尾的序列」，直接加 1 会得到 1，虽不致命但会与「初值 1」的语义混淆；显式判空更清晰。
6. **并列最大值的处理**：另一值的长度等于 $top1$ 时应写入 $top2$，否则排除 $x$ 时会丢掉这个并列最优。
7. **忘记更新 `ans`**：若只在最后读 $top1$ 的最大值也能得到正确答案，但需要遍历所有层；两者别混着写一半。
8. **$n = 1$**：循环返回 1；$k = 0$ 时也返回 1，符合预期。
9. **`k` 大于 $n-1$**：答案就是 $n$，算法同样正确（多余层不会产生更长序列）。

**延伸思考**：本题的优化能成立，依赖两个结构性质：（1）转移只区分「同值 / 异值」两类，因此每层只需保留最优与「不同值的次优」；（2）代价是 0/1 的常数，因此「变化次数」可以作为一层维度。若把限制改成「相邻元素之差的总和不超过 $k$」，两类前驱就变成「所有可能的差值」，「最优 + 次优」不足以刻画，需要按值域维护线段树或平衡树；若再要求输出具体子序列，则还要记录前驱指针，空间从 $O(nk)$ 涨到 $O(nk)$ 并带常数。另一条扩展是把「不超过 $k$ 次变化」换成「恰好 $k$ 段连续相等块」，此时答案与「段数」直接对应，可用贪心 + 计数在 $O(n)$ 内求出每段的长度分布。
