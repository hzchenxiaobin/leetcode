# LeetCode 清除数字 题解

## 1. 题目概述

- **标题 / 题号**：清除数字（#3174，easy）
- **链接**：https://leetcode.cn/problems/clear-digits/
- **来源**：LeetCode 第 132 场双周赛 Q1
- **难度**：简单
- **标签**：栈、字符串、模拟

**题意**：给定只含小写字母和数字的字符串 `s`，反复执行如下操作直到没有数字：**删除第一个数字字符**，以及它左边**最近的**一个非数字字符。返回删除完所有数字后的字符串。题目保证所有数字都能按此规则被删除。

**约束**：

- $1 \le |s| \le 100$
- `s` 只包含小写英文字母和数字字符
- 输入保证所有数字都可以按上述操作被删除

## 2. 示例

**示例 1**

```text
输入：s = "abc"
输出："abc"
解释：字符串中没有数字，无需删除。
```

**示例 2**

```text
输入：s = "cb34"
输出：""
解释：先对 3 执行操作，删掉 3 和它左侧的 b，s 变成 "c4"；
      再对 4 执行操作，删掉 4 和它左侧的 c，s 变成 ""。
```

**示例 3（边界补充）**

```text
输入：s = "a1b2c3"
输出：""
解释：每次数字都恰好和一个字母配对，三个字母全部被删掉。
```

```text
输入：s = "abcd9"
输出："abc"
解释：只剩一个数字，它带走左侧最近的 d。
```

## 3. 解题思路

### 3.1 暴力思路

严格按题面模拟：每一轮找到**第一个**数字，再向左找到最近的字母，把这两个字符一起删掉，重复到没有数字。用字符串（或列表）实现时，每次删除要移动后面的字符，单轮 $O(n)$，最多 $n/2$ 轮，总时间 $O(n^2)$。$|s| \le 100$ 时当然能过，但这段代码写起来啰嗦（下标偏移、边界判断多），而且不是本题想考的结构。

### 3.2 核心观察：字母入栈，遇到数字就弹栈

![核心：字母入栈，数字弹栈](images/bw132_q1_stack_model.svg)

注意一个关键事实：**数字字符本身不会留下任何东西，它唯一的作用是「抵消掉」左侧最近的一个尚未被删除的字母。** 而「左侧最近的未删除字母」正是「从左到右处理时，仍然活着的最后一个字母」。

于是用一个栈只存字母：

- 读到**字母**：`push` 入栈（它暂时活着）；
- 读到**数字**：`pop` 掉栈顶（栈顶就是它左侧最近、尚未被抵消的字母），数字自身丢弃。

处理完整个字符串，栈中剩下的就是答案，且顺序天然正确（栈底到栈顶即原序）。

> 💡 这个观察与「删除第一个数字 + 左侧最近字母」的**执行顺序**是等价的：从左到右扫到某个数字时，它左边的数字都已被处理，此时左边最近的存活字母恰是栈顶。

### 3.3 算法流程

```text
1. st = 空栈
2. 对 s 中每个字符 c：
       若 c 是数字：若栈非空则 pop（丢弃数字本身）
       否则：push(c)
3. 返回栈中自底向上的字符
```

![示例演算：cb34 的两轮删除对应两次弹栈](images/bw132_q1_example_walkthrough.svg)

以 `"cb34"` 为例：

| 读入 | 类型 | 动作 | 栈（底 → 顶） | 当前串 |
|------|------|------|----------------|--------|
| c | 字母 | push | [c] | cb34 |
| b | 字母 | push | [c, b] | cb34 |
| 3 | 数字 | pop b | [c] | c4 |
| 4 | 数字 | pop c | [] | （空） |

最终栈为空，返回 `""`，与示例 2 一致。

### 3.4 示例演算：与题面删除顺序对照

题面的删除顺序是「先删第一个数字」。在 `"cb34"` 中第一个数字是 `3`，它左边最近的字母是 `b`，删掉后得到 `"c4"`；下一个数字 `4` 带走 `c`，得到空串。栈模拟给出的弹栈顺序**恰好就是** `b`、`c`——因为从左到右扫描时，第一个遇到的数字必然就是当前串的第一个数字，它要抵消的字母必然就是栈顶。

再看 `"abcd9"`：`a,b,c,d` 依次入栈，遇到 `9` 弹掉 `d`，栈剩下 `[a,b,c]`，输出 `"abc"`。注意这里并没有「删除 9 后还要继续处理右边的字符」的复杂情况——9 后面什么都没有。

但如果数字后面还有字母，例如 `"a1bc2"`：`a` 入栈、`1` 弹掉 `a`、`b`、`c` 入栈、`2` 弹掉 `c`，输出 `"b"`。用题面规则验证：第一个数字 `1` 带走 `a`，串变成 `"bc2"`；第一个数字 `2` 带走 `c`，得到 `"b"`，一致。

## 4. 算法细节

1. **数字不入栈**：数字自身的「位置」不需要保留，它只是触发一次弹栈。
2. **弹栈前判空**：题面保证所有数字都能被删除，因此 `pop` 时栈一定非空；但写上 `if (!st.empty())` 可以防御不合法的输入，代价可忽略。
3. **字符判定**：C++ 用 `isdigit((unsigned char)c)`（务必转 `unsigned char`，避免负值字符触发未定义行为）；Python 用 `c.isdigit()`（本题只有 ASCII 数字，安全）。
4. **返回顺序**：`std::string` 作为栈时，从底到顶就是答案，直接返回即可；用 `vector<char>` 则需要重新拼字符串。
5. **空间**：栈最多存 $|s|$ 个字符，但实际只需存未被抵消的字母，最坏 $O(n)$。
6. **不修改原串**：一次遍历即可，不需要真的做删除操作，避免了字符串搬移。

## 5. 正确性证明

**引理 1（栈内容 = 未删除的字母）**：在处理完 `s` 的前 $i$ 个字符后，栈中自底向上的序列，恰好等于「仅对前 $i$ 个字符执行题面删除操作后」剩下的字母序列（不含已被抵消的字母与所有数字）。

**证明**：对 $i$ 归纳。
$i = 0$ 时栈为空，前缀也为空，成立。
设处理完前 $i$ 个字符后成立，考察第 $i+1$ 个字符 $c$：
- 若 $c$ 是字母：题面操作不会删除它（只删数字与数字左侧的字母），它成为剩余序列的末尾；算法把它压栈，也追加到末尾，成立。
- 若 $c$ 是数字：题面规定删除 $c$ 本身以及它左侧最近的未删除字母。由归纳假设，前 $i$ 个字符中未删除的字母正是栈内容，故「左侧最近的未删除字母」就是栈顶。删除它等价于弹栈，$c$ 本身不入栈，成立。∎

**引理 2（删除顺序的合法性）**：算法按从左到右的顺序处理数字，与题面「总是先删当前串的第一个数字」的顺序一致。

**证明**：设当前待处理的最左数字在原串中的位置为 $j$。所有位置小于 $j$ 的字符都不是数字，且按归纳假设它们中未被删除的字母与栈内容对应。扫描指针停在第 $j$ 个字符时，前面的数字都已处理完毕，因此第 $j$ 个数字正是当前串的第一个数字。∎

**定理**：算法返回的字符串等于题目所求的最终字符串。

**证明**：由引理 2，算法处理数字的顺序与题面一致；由引理 1，每步之后栈内容与题面状态下剩余的字母一致。处理完全部字符后已无数字（题目保证数字全部可删），此时栈内容即最终字符串。∎

> 注：题面保证「所有数字都可以被删除」，这等价于扫描过程中任意前缀里数字的个数不超过字母的个数，因此不会出现对空栈 `pop` 的情况。

## 6. 复杂度分析

- **时间**：$O(n)$。每个字符至多入栈一次、出栈一次，判定为常数时间。
- **空间**：$O(n)$。栈最坏存下所有字母；返回的字符串本身也占 $O(n)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    std::string clearDigits(std::string s) {
        std::string st;                            // 只存字母的栈
        for (char c : s) {
            if (isdigit((unsigned char)c)) {
                if (!st.empty()) st.pop_back();    // 抵消左侧最近字母
            } else {
                st.push_back(c);
            }
        }
        return st;                                 // 栈底到栈顶即答案
    }
};
```

### Python

```python
class Solution:
    def clearDigits(self, s: str) -> str:
        st = []                                    # 只存字母的栈
        for c in s:
            if c.isdigit():
                if st:                             # 抵消左侧最近字母
                    st.pop()
            else:
                st.append(c)
        return ''.join(st)
```

> 💡 两份代码通过题面 2 个示例、`"a1b2c3"`、`"abcd9"`、`"a1bc2"`、纯字母、相邻数字 `"ab12"`（保证可删的形态）等边界，并与「反复删除第一个数字及其左侧字母」的字面模拟做了 300 组随机对拍（`mismatch = 0`）。

## 8. 边界情况与易错点

1. **没有数字**：栈原样保留，返回原串，示例 1 覆盖。
2. **数字把字母删光**：返回空串，示例 2 覆盖；注意空串是合法答案，不要特判成 `"0"` 之类。
3. **`pop` 空栈**：题面保证不会发生；若担心脏数据，加 `if (!st.empty())` 即可，不影响正确性。
4. **`isdigit` 的参数类型**：C++ 中 `char` 可能是有符号的，传入负值属于未定义行为，必须转 `unsigned char`。
5. **误把数字也入栈**：数字只需触发弹栈，一旦入栈会破坏「栈顶 = 最近存活字母」的不变式。
6. **误按「括号匹配」的对称顺序处理**：本题数字只与**左侧**字母配对，方向是单向的；不能像括号那样用「右括号弹左括号」的直觉随意套用（虽然这里恰好也是弹栈，但语义要清楚）。
7. **返回值顺序**：用 `vector<char>` 存栈再拼接时，别把栈顶当开头输出。
