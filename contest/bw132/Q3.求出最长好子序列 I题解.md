# LeetCode 求出最长好子序列 I 题解

## 1. 题目概述

- **标题 / 题号**：求出最长好子序列 I（#3176，medium）
- **链接**：https://leetcode.cn/problems/find-the-maximum-length-of-a-good-subsequence-i/
- **来源**：LeetCode 第 132 场双周赛 Q3
- **难度**：中等
- **标签**：数组、哈希表、动态规划

**题意**：称序列 `seq` 是**好序列**，若在下标范围 $[0, |\text{seq}| - 2]$ 中，满足 $\text{seq}[i] \ne \text{seq}[i+1]$ 的下标 $i$ **不超过 $k$** 个——也就是相邻元素「变化」的次数不超过 $k$。给定数组 `nums`，求它所有**好子序列**中最长的长度。

**约束**：

- $1 \le n = |\text{nums}| \le 500$
- $1 \le \text{nums}[i] \le 10^9$
- $0 \le k \le \min(n, 25)$

> 💡 $n$ 只有 500、$k$ 只有 25，这明示了 $O(n^2 k)$ 的做法：$500^2 \times 25 \approx 6.25 \times 10^6$，非常宽裕。加强版见 [3177](https://leetcode.cn/problems/find-the-maximum-length-of-a-good-subsequence-ii/)，那里 $n$ 换成 $5 \times 10^3$，需要把 $O(n^2 k)$ 优化到 $O(nk)$。

## 2. 示例

**示例 1**

```text
输入：nums = [1,2,1,1,3], k = 2
输出：4
解释：最长好子序列是 [1,2,1,1]（下标 0,1,2,3）：
      相邻变化发生在 1→2 与 2→1，共 2 次，不超过 k = 2。
```

**示例 2**

```text
输入：nums = [1,2,3,4,5,1], k = 0
输出：2
解释：k = 0 时子序列必须全部相等。数字 1 出现两次（下标 0 和 5），
      故最长长度为 2。
```

**示例 3（边界补充）**

```text
输入：nums = [7,7,7], k = 0
输出：3
解释：整段都是同一个值，取全部即可，变化次数为 0。
```

```text
输入：nums = [1,2,3], k = 5
输出：3
解释：k 不小于 n−1 时，整个数组本身就是好序列。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有子序列（$2^n$ 个），逐个检查相邻变化次数是否 $\le k$，取最长。$n = 500$ 时 $2^{500}$ 完全没有可行性。即便只想「按最后一个元素划分」，也必须借助动态规划把「前缀的最优解」记下来。

### 3.2 核心观察：状态只需要「结尾下标」与「已用变化次数」

![状态设计：dp 状态与两种转移](images/bw132_q3_dp_model.svg)

任何子序列都由「**最后一个元素的下标**」唯一刻画其延伸方式：想在它后面接上 `nums[i]`，只需要知道「前一个元素的值」与「已经用掉多少次变化」，而不关心更早的元素。

于是定义

$$dp[i][j] = \text{以 } i \text{ 结尾、相邻不等次数} \le j \text{ 的最长好子序列长度}.$$

转移时枚举前驱 $p < i$：

- 若 $\text{nums}[p] = \text{nums}[i]$：接上去**不增加**变化次数，用 $dp[p][j] + 1$；
- 若 $\text{nums}[p] \ne \text{nums}[i]$：接上去**消耗**一次变化，用 $dp[p][j-1] + 1$（要求 $j \ge 1$）。

即

$$dp[i][j] = \max\left(1,\ \max_{\substack{p < i \\ \text{nums}[p] = \text{nums}[i]}} \bigl(dp[p][j] + 1\bigr),\ \max_{\substack{p < i \\ \text{nums}[p] \ne \text{nums}[i]}} \bigl(dp[p][j-1] + 1\bigr)\right).$$

初值 $dp[i][j] = 1$ 对应「只取 `nums[i]` 自己」这一合法子序列。答案取所有 $dp[i][j]$（$j \le k$）的最大值。

> 💡 这里 $j$ 取「**至多** $j$ 次」的语义，比「恰好 $j$ 次」更方便：初值天然是 1，答案直接取最大值，无需区分「用了不到 $j$ 次」的情形。由于限制是「不超过 $k$」，至多语义与题意完全吻合。

### 3.3 算法流程

```text
1. dp[i][j] = 1   对所有 i ∈ [0, n), j ∈ [0, k]
2. ans = 1
3. 对 i = 0 .. n-1：
       对 p = 0 .. i-1：
              若 nums[p] == nums[i]：
                     对 j = 0 .. k：dp[i][j] = max(dp[i][j], dp[p][j] + 1)
              否则：
                     对 j = 1 .. k：dp[i][j] = max(dp[i][j], dp[p][j-1] + 1)
       对 j = 0 .. k：ans = max(ans, dp[i][j])
4. 返回 ans
```

计算顺序上，$dp[i][\cdot]$ 只依赖 $p < i$ 的行，所以按 $i$ 递增填表即可，与内层 $j$ 的方向无关（不涉及原地滚动）。

![示例填表：数组 1 2 1 1 3、k 为 2 的 dp 表](images/bw132_q3_example_walkthrough.svg)

### 3.4 示例演算

对 `nums = [1,2,1,1,3]`、$k = 2$，逐行填表（行是 $i$，列是 $j$）：

| $i$ | `nums[i]` | $j=0$ | $j=1$ | $j=2$ | 关键转移 |
|-----|-----------|-------|-------|-------|----------|
| 0 | 1 | 1 | 1 | 1 | 初值 |
| 1 | 2 | 1 | 2 | 2 | 由 $i=0$ 异值转移：$dp[0][0]+1 = 2$ |
| 2 | 1 | 2 | 2 | 3 | 同值接 $i=0$ 得 2；异值接 $i=1$ 的 $j-1$ 得 $dp[1][1]+1 = 3$ |
| 3 | 1 | 3 | 3 | 4 | 同值接 $i=2$：$dp[2][j]+1$，$j=2$ 时为 4 |
| 4 | 3 | 1 | 4 | 4 | 异值接 $i=3$：$dp[3][1]+1 = 4$ |

最大值为 $4$，对应子序列 $[1,2,1,1]$（变化 $1\to2$ 与 $2\to1$，共 2 次）。注意 $i=4$ 那一行的 $j=2$ 也是 4，对应 $[1,2,1,3]$ 之类，但长度无法再增大。

## 4. 算法细节

1. **$j$ 的语义是「至多」**：因此 `dp[i][j]` 关于 $j$ 单调不减。写转移时不必额外做 `dp[i][j] = max(dp[i][j], dp[i][j-1])` 的平滑，因为「至多 $j$ 次」的最优解在「至多 $j-1$ 次」的范围内也被允许，而转移枚举了全部前驱，天然覆盖。
2. **异值分支要求 $j \ge 1$**：$j = 0$ 时不允许任何变化，只能接同值前驱；循环从 $j = 1$ 开始可避免越界。
3. **初值 1 而非 0**：空子序列不是合法答案（题目求非空子序列），每个位置至少能单独成序列。
4. **三重循环顺序**：$i$ 外层、$p$ 中层、$j$ 内层，$p < i$ 保证子序列下标递增；把 $j$ 放最内层可让内存访问连续，常数更小。
5. **`k` 的有效上界**：$k > n-1$ 时整个数组都是好序列，答案就是 $n$；即便不特判，DP 也会给出 $n$，所以无需额外处理。
6. **值域 $10^9$**：只做相等比较，不需要离散化；若想像 Q4 那样用「值 → 状态」的哈希表加速，则需要先压缩值域。
7. **空间**：$O(nk)$ 的二维表；本题不需要滚动数组，保留全表更易调试。

## 5. 正确性证明

**引理 1（子序列的「去掉末尾」性质）**：设 $S$ 是以 `nums[i]` 结尾的好子序列，长度为 $L \ge 2$，去掉末尾后得到 $S'$，它以某个 `nums[p]`（$p < i$）结尾，且
- 若 $\text{nums}[p] = \text{nums}[i]$，则 $S'$ 的变化次数与 $S$ 相同；
- 若 $\text{nums}[p] \ne \text{nums}[i]$，则 $S'$ 的变化次数比 $S$ 少 1。

**证明**：$S$ 的相邻对由 $S'$ 的相邻对加上最后一对 $(\text{nums}[p], \text{nums}[i])$ 组成。变化次数是「相邻不等的对数」，故末对相等时不增加、不等时增加 1。∎

**引理 2（DP 值的可达性）**：对任意 $i, j$，存在一个以 $i$ 结尾、变化次数不超过 $j$ 的好子序列，其长度恰为 $dp[i][j]$。

**证明**：对 $i$ 归纳（同一 $i$ 内对转移来源归纳）。基例 $dp[i][j] = 1$ 由单元素子序列 $[\text{nums}[i]]$ 达成（变化 0 次）。归纳步：若 $dp[i][j]$ 由 $dp[p][j] + 1$（同值）更新而来，由归纳假设存在以 $p$ 结尾、变化 $\le j$ 的序列 $S'$，在其后追加 `nums[i]`；由引理 1 变化次数不变，仍 $\le j$，长度 $dp[p][j] + 1$。异值情形同理，追加后变化次数至多 $j-1+1 = j$。∎

**引理 3（DP 值的上界）**：对任意以 $i$ 结尾、变化次数 $\le j$ 的好子序列 $S$，有 $|S| \le dp[i][j]$。

**证明**：对 $|S|$ 归纳。$|S| = 1$ 时 $|S| = 1 \le dp[i][j]$。设 $|S| \ge 2$，$S' = S \setminus \{\text{末尾}\}$ 以某 $p < i$ 结尾。若 $\text{nums}[p] = \text{nums}[i]$，由引理 1 知 $S'$ 的变化次数 $\le j$，故 $|S'| \le dp[p][j]$（归纳假设），于是 $|S| \le dp[p][j] + 1 \le dp[i][j]$（后者由转移取 max 保证）。若 $\text{nums}[p] \ne \text{nums}[i]$，则 $S'$ 的变化次数 $\le j-1$，同理 $|S| \le dp[p][j-1] + 1 \le dp[i][j]$。∎

**定理**：算法返回的 `ans` 等于 `nums` 的最长好子序列长度。

**证明**：
（$\ge$）对任意 $i$ 与 $j \le k$，引理 2 给出一个长度 $dp[i][j]$ 的合法好子序列，故最优解长度不小于 $\max_{i,\,j \le k} dp[i][j] = $ `ans`。
（$\le$）设 $S^*$ 是最长好子序列，以其末尾下标 $i$ 结尾、变化次数 $\le k$。由引理 3，$|S^*| \le dp[i][k] \le$ `ans`。
两方向合并得 `ans` $= |S^*|$。∎

## 6. 复杂度分析

- **时间**：$O(n^2 k)$。外层 $i$ 共 $n$ 次，中层 $p$ 平均 $n/2$ 次，内层 $j$ 共 $k+1$ 次；$n = 500$、$k = 25$ 时约 $3 \times 10^6$ 次转移。
- **空间**：$O(nk)$ 的 DP 表；若只保留必要行可降到 $O(n)$，但本题无必要。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maximumLength(std::vector<int>& nums, int k) {
        int n = (int)nums.size();
        // dp[i][j]：以 i 结尾、相邻不等次数不超过 j 的最长好子序列长度
        std::vector<std::vector<int>> dp(n, std::vector<int>(k + 1, 1));
        int ans = 1;
        for (int i = 0; i < n; ++i) {
            for (int p = 0; p < i; ++p) {
                if (nums[p] == nums[i]) {                 // 接同值：不花次数
                    for (int j = 0; j <= k; ++j)
                        dp[i][j] = std::max(dp[i][j], dp[p][j] + 1);
                } else {                                  // 接异值：花 1 次
                    for (int j = 1; j <= k; ++j)
                        dp[i][j] = std::max(dp[i][j], dp[p][j - 1] + 1);
                }
            }
            for (int j = 0; j <= k; ++j) ans = std::max(ans, dp[i][j]);
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maximumLength(self, nums: list[int], k: int) -> int:
        n = len(nums)
        # dp[i][j]：以 i 结尾、相邻不等次数不超过 j 的最长好子序列长度
        dp = [[1] * (k + 1) for _ in range(n)]
        ans = 1
        for i in range(n):
            di = dp[i]
            for p in range(i):
                dpp = dp[p]
                if nums[p] == nums[i]:                 # 接同值：不花次数
                    for j in range(k + 1):
                        if dpp[j] + 1 > di[j]:
                            di[j] = dpp[j] + 1
                else:                                  # 接异值：花 1 次
                    for j in range(1, k + 1):
                        if dpp[j - 1] + 1 > di[j]:
                            di[j] = dpp[j - 1] + 1
            m = max(di)
            if m > ans:
                ans = m
        return ans
```

> 💡 两份代码通过题面 2 个示例与补充示例（$k = 0$ 全同值、$k \ge n-1$、单元素、全不同值），并与「枚举所有子序列检查相邻变化次数」的暴力实现做了 300 组随机对拍（$n \le 9$），`mismatch = 0`；$n = 500$、$k = 25$ 时 C++ 约 0.005 s、Python 约 0.21 s。

## 8. 边界情况与易错点

1. **$k = 0$**：只能取全部相等的子序列，答案等于众数的出现次数；异值分支完全不会执行，注意循环从 $j = 1$ 开始时不要越界。
2. **$k \ge n-1$**：整个数组都是好序列，答案 $n$；DP 自然给出，不必特判。
3. **初值写成 0**：会导致「只选一个元素」的情况被漏掉，$n = 1$ 时直接返回 0。
4. **异值转移误用 $dp[p][j]$**：接异值必须消耗一次变化，只能用 $dp[p][j-1]$；写成 $dp[p][j]$ 相当于把变化次数当成免费。
5. **同值转移误用 $dp[p][j-1]$**：接同值不消耗变化，用 $j-1$ 会低估长度（但不会超过真值，属于「答案偏小」的隐蔽错误）。
6. **下标顺序**：$p$ 必须严格小于 $i$，否则会构造出下标非递增的「子序列」（其实是重排）。
7. **答案取值**：要取所有 $i$、所有 $j \le k$ 的最大值，只取 `dp[n-1][k]` 是错的（最优子序列未必以下标 $n-1$ 结尾）。
8. **复杂度估算**：$O(n^2k)$ 在 $n = 500$ 时可过，但同样的代码在 $n = 5000$ 的 Q4 会超时，不要直接套用。

**延伸思考**：本题的状态之所以能是二维的，是因为「变化次数」是**可加的一阶量**：每接一个元素，代价要么 0 要么 1，与更早的元素无关。若把限制改成「相邻元素之差的绝对值之和不超过 $k$」，代价就依赖于具体的两个值，状态需扩展为「结尾值 + 已用代价」，复杂度随之上升。另一条扩展是把「不超过 $k$ 次变化」改为「恰好 $k$ 次」，此时「至多」语义不再适用，需要把初值与转移都改成「恰好」，并在初始化时禁止「变化次数不足」的状态参与转移。
