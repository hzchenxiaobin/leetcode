# LeetCode 得分最高的最小轮调 题解

## 1. 题目概述

- **标题 / 题号**：得分最高的最小轮调（#798，hard）
- **链接**：https://leetcode.cn/problems/smallest-rotation-with-highest-score/
- **来源**：LeetCode 第 75 场周赛 Q4
- **难度**：困难
- **标签**：数组、前缀和、差分数组

**题意**：给定长度为 $n$ 的数组 `nums`，把它**左旋** $k$ 位（$0 \le k < n$）得到

$$\text{arr}[i] = \text{nums}[(i+k) \bmod n]$$

若 $\text{arr}[i] \le i$，位置 $i$ 贡献 1 分。求**总分最高**的轮调量 $k$；若并列，返回**最小**的 $k$。

**约束**：

- $1 \le n \le 10^5$
- $0 \le \text{nums}[i] < n$（值域与下标范围一致，这一点是后面「得分区间」成立的关键）

## 2. 示例

**示例 1**

```text
输入：nums = [2,3,1,4,0]
输出：3
解释：逐个 k 的得分如下
      k = 0, [2,3,1,4,0], score 2
      k = 1, [3,1,4,0,2], score 3
      k = 2, [1,4,0,2,3], score 3
      k = 3, [4,0,2,3,1], score 4   ← 最高，答案 3
      k = 4, [0,2,3,1,4], score 3
```

**示例 2**

```text
输入：nums = [1,3,0,2,4]
输出：0
解释：无论怎么轮调得分恒为 3，故取最小的 k = 0。
```

**补充示例**

```text
输入：nums = [1,0]
输出：1
解释：k = 0 时为 [1,0]，只有位置 1 得分（0 ≤ 1），score = 1；
      k = 1 时为 [0,1]，两位都满足（0 ≤ 0、1 ≤ 1），score = 2。
```

## 3. 解题思路

### 3.1 暴力思路

对每个 $k \in [0, n-1]$ 真实地旋转一次数组、再扫一遍统计得分：单次 $O(n)$，总计 $O(n^2)$。$n = 10^5$ 时约 $10^{10}$ 次比较，必然超时。

更糟的是，很多人第一反应是「维护一个能增量更新的分数」，但左旋一位会让几乎所有被访问到的元素下标同时变化，分数没有局部性，增量更新不成立。所以正确的方向不是「改数组」，而是**换枚举对象**：不再枚举 $k$，而是枚举元素。

### 3.2 核心观察：固定元素，看它在哪些 k 上得分

![轮调只是下标平移](images/wc75_q4_rotation_mapping.svg)

轮调不改变元素值，只改变它的**位置**。原下标 $j$ 的元素，在轮调 $k$ 后落在

$$p_j(k) = (j-k) \bmod n$$

于是「$j$ 是否得分」这件事被刻画成 $k$ 轴上的一个集合：

- 当 $k \le j$ 时 $p = j-k$，得分条件 $j-k \ge v$ 即 $k \le j-v$，得到区间 $[0,\ j-v]$；
- 当 $k > j$ 时 $p = j-k+n$，得分条件 $j-k+n \ge v$ 即 $k \le j+n-v$，得到区间 $[j+1,\ j+n-v]$。

其中 $v = \text{nums}[j]$。两段的端点都可能越界（$j-v$ 可能为负，$j+n-v$ 可能超过 $n-1$），裁剪掉即可；它们**都不会绕过 $n-1$ 回绕**，所以普通差分就够用（这正是本题比一般环形区间题好写的地方）。

于是每个元素对答案的贡献变成「在 $k$ 轴上一段区间 +1」，$n$ 个元素就是 $n$ 次区间加。

### 3.3 算法流程：区间加 → 差分 → 前缀和

![得分区间转差分数组](images/wc75_q4_interval_diff.svg)

1. 开长度为 $n+1$ 的差分数组 `diff`（多出的第 $n$ 位只作收尾，避免 $r+1=n$ 越界）。
2. 对每个元素 $j$：
   - 做一次 $[0,\ j-v]$ 的区间加；
   - 做一次 $[j+1,\ j+n-v]$ 的区间加。
   区间加的实现统一裁剪：$l = \max(l,0)$，$r = \min(r,n-1)$，若 $l > r$ 直接跳过。
3. 从 $k=0$ 到 $n-1$ 扫一遍，$cur \mathrel{+}= \text{diff}[k]$，此时 $cur$ 就是 $\text{score}(k)$。
4. 只在 $cur$ **严格大于**历史最大值时更新答案，从而天然满足「并列取最小 $k$」。

这样每个元素只做常数次整数运算，整体线性。

### 3.4 示例演算

![示例演算](images/wc75_q4_walkthrough.svg)

以 `nums = [2,3,1,4,0]`（$n=5$）为例，逐元素列出得分区间：

| $j$ | $v$ | 第一段 $[0,\ j-v]$ | 第二段 $[j+1,\ j+n-v]$ | 得分的 $k$ |
|-----|-----|--------------------|------------------------|-----------|
| 0 | 2 | 空（$-2<0$） | $[1,\ 3]$ | 1, 2, 3 |
| 1 | 3 | 空（$-2<0$） | $[2,\ 3]$ | 2, 3 |
| 2 | 1 | $[0,\ 1]$ | $[3,\ 4]$ | 0, 1, 3, 4 |
| 3 | 4 | 空（$-1<0$） | $[4,\ 4]$ | 4 |
| 4 | 0 | $[0,\ 4]$ | 空（$5>4$） | 0, 1, 2, 3, 4 |

按列求和得到 $\text{score} = [2, 3, 3, 4, 3]$，最大值 4 只在 $k=3$ 出现，故返回 3，与示例一致。

## 4. 算法细节

1. **落点公式取模的括号**：$p = (j-k) \bmod n$，$j-k$ 可能为负，C++ 里必须补一次 $+n$ 再取模，写成 `((j - k) % n + n) % n`；本文的推导只在 $k \le j$ 与 $k > j$ 两个分支里用加减法，完全回避了取模。
2. **$k = j$ 归第一段**：此时 $p = 0$，仍满足 $p < n$，是合法位置；把 $k=j$ 分到第一段才能保证两段恰好无交无漏：第一段 $\subseteq [0, j]$，第二段 $\subseteq [j+1, n-1]$。
3. **裁剪顺序**：先按公式算出端点、再统一 `max(l,0)`/`min(r,n-1)`。$j+n-v \le (n-1)+n \le 2\times10^5$，`int` 足够，不会溢出。
4. **差分数组开 $n+1$**：右端点 $r$ 最大取到 $n-1$，需要写 `diff[n] -= 1` 收尾；数组只开 $n$ 会越界（UB，可能静默改坏别的变量）。
5. **严格大于才更新**：因为 $k$ 从小到大枚举，`if (cur > bestScore)` 让「第一个达到最大值的 $k$」胜出；写成 `>=` 会返回最大的 $k$，正好错在并列情形。
6. **无需真旋转、无需哈希**：全程只有区间端点的加减与一次前缀和，空间也只需一个长度 $n+1$ 的数组。
7. **可选的等价写法**：把两段合并成「环形区间」再写环形差分也能过，但需要处理跨越 $n-1$ 的回绕，边界更容易错；本题两段天然不跨界，直接普通差分最稳。

## 5. 正确性证明

**引理 1（落点公式）**：轮调 $k$ 后，原下标 $j$ 的元素位于 $p_j(k) = (j-k) \bmod n$。

**证明**：轮调后 $\text{arr}[i] = \text{nums}[(i+k) \bmod n]$，元素 $j$ 出现的位置 $i$ 满足 $(i+k) \equiv j \pmod n$，即 $i \equiv j-k \pmod n$。区间 $[0,n-1]$ 内这样的 $i$ 唯一，故 $p_j(k) = (j-k) \bmod n$。∎

**引理 2（得分区间刻画）**：设 $v = \text{nums}[j]$，则元素 $j$ 在轮调 $k \in [0,n-1]$ 下得分当且仅当

$$k \in \bigl[0,\ j-v\bigr] \ \cup\ \bigl[j+1,\ j+n-v\bigr]$$

（区间在超出 $[0,n-1]$ 的部分视为空；两段互不相交。）

**证明**：分两种情形。

- $k \le j$：由引理 1，$j-k \in [0, j] \subseteq [0,n-1]$，故 $p = j-k$，无需取模。得分 $p \ge v \iff k \le j-v$。与 $k \le j$ 取交，因 $v \ge 0$ 有 $j-v \le j$，得 $k \in [0, j-v]$。
- $k > j$：此时 $j-k \le -1$，加 $n$ 后 $p = j-k+n$，且 $p \ge j-(n-1)+n = j+1 \ge 1$、$p \le j-1+n \le n-1$，仍在 $[0,n-1]$ 内，无需再次取模。得分 $p \ge v \iff k \le j+n-v$。与 $j+1 \le k \le n-1$ 取交，得 $k \in [j+1, \min(n-1, j+n-v)]$。

又第一段含于 $[0,j]$、第二段含于 $[j+1,n-1]$，二者不交；两情形穷尽 $k \in [0,n-1]$，故并集即全部得分的 $k$。∎

**引理 3（差分与前缀和还原得分）**：在处理完全部元素后，前缀和 $S[k] = \sum_{i=0}^{k} \text{diff}[i]$ 满足 $S[k] = \text{score}(k)$。

**证明**：先看单个元素。它对 $[l,r]$ 做区间加：`diff[l] += 1`、`diff[r+1] -= 1`，则对任意 $k$，

$$S_{\text{单}}(k) = \mathbf{1}[\,l \le k \le r\,]$$

（$r+1 \le n$ 保证收尾写在数组内；差分数组下标覆盖 $[0,n]$）。这正是「$k$ 落在 $[l,r]$ 内」的示性函数，也就是「该元素在 $k$ 上得分」。各元素贡献可加，故 $S[k]$ 等于在 $k$ 上得分的元素个数，即 $\text{score}(k)$。∎

**定理**：算法返回的 $k$ 是使 $\text{score}(k)$ 最大、且下标最小的轮调量。

**证明**：由引理 2，每个元素被加到恰好正确的 $k$ 区间上；由引理 3，扫描时变量 $cur$ 恰好等于 $\text{score}(k)$。算法按 $k$ 递增枚举，且仅在 $cur > \text{bestScore}$ 时更新，故 `bestK` 是首个（因而最小）取得最大值的下标。∎

## 6. 复杂度分析

- **时间**：$O(n)$。每个元素两次区间加，均为 $O(1)$；最后一次前缀和扫描 $O(n)$。没有排序、没有取模乘除。
- **空间**：$O(n)$。仅一个长度为 $n+1$ 的差分数组；输入数组只读，不需要复制旋转结果。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int bestRotation(vector<int>& nums) {
        int n = nums.size();
        vector<int> diff(n + 1, 0);

        // 在 k 轴闭区间 [l, r] 上加 1（自动裁剪到 [0, n-1]）
        auto add = [&](int l, int r) {
            l = max(l, 0);
            r = min(r, n - 1);
            if (l > r) return;
            diff[l] += 1;
            diff[r + 1] -= 1;
        };

        for (int j = 0; j < n; j++) {
            int v = nums[j];
            add(0, j - v);          // k <= j：位置为 j - k
            add(j + 1, j + n - v);  // k >  j：位置为 j - k + n
        }

        int bestK = 0, bestScore = -1, cur = 0;
        for (int k = 0; k < n; k++) {
            cur += diff[k];
            if (cur > bestScore) {  // 严格大于 => 并列时保留更小的 k
                bestScore = cur;
                bestK = k;
            }
        }
        return bestK;
    }
};
```

### Python

```python
from typing import List


class Solution:
    def bestRotation(self, nums: List[int]) -> int:
        n = len(nums)
        diff = [0] * (n + 1)

        def add(l: int, r: int) -> None:
            """在 k 轴闭区间 [l, r] 上加 1，越界部分自动裁剪"""
            l = max(l, 0)
            r = min(r, n - 1)
            if l > r:
                return
            diff[l] += 1
            diff[r + 1] -= 1

        for j, v in enumerate(nums):
            add(0, j - v)            # k <= j：位置为 j - k
            add(j + 1, j + n - v)    # k >  j：位置为 j - k + n

        best_k, best_score, cur = 0, -1, 0
        for k in range(n):
            cur += diff[k]
            if cur > best_score:     # 严格大于 => 并列时保留更小的 k
                best_score, best_k = cur, k
        return best_k
```

## 8. 边界情况与易错点

1. **$n = 1$**：`nums = [0]`，唯一元素 $j=0,v=0$，第一段 $[0,0]$ 命中，答案 0。若把区间写成半开或漏掉 $v=0$ 的情形就会错。
2. **全 0 数组**：任意 $k$ 都拿满 $n$ 分，必须返回 0。这题几乎专门用来检查「并列取最小」，`>` 与 `>=` 一字之差就是 WA。
3. **$v = n-1$**：第一段 $[0, j-v]$ 对 $j < n-1$ 为空；第二段 $[j+1, j+n-v]$ 只剩 $k=j+1$；特别地 $j=n-1$ 时第二段起点为 $n$ 越界，只有 $k=0$ 得分。
4. **$v = 0$**：第一段是 $[0, j]$，第二段 $[j+1, j+n]$ 上界越界被裁掉，合起来正好覆盖全部 $k$——不要因为第二段越界就误以为整段无效。
5. **两端同时越界**：$v$ 较大且 $j$ 也较大时，可能同时出现 $j-v < 0$（第一段左端溢出）与 $j+n-v > n-1$（第二段右端溢出），必须**分别**对两段裁剪，不能因为其中一段为空就跳过另一个元素或整个元素。
6. **下标基准**：题面位置与 $i$ 的比较都是 0-based，若推导时误用 1-based，条件会变成 $p+1 \ge v$，全盘错位。
7. **差分数组长度**：写 `diff[r + 1] -= 1` 时 $r$ 可达 $n-1$，必须开 $n+1$；扫描只到 $n-1$，末位自然不会读到。
