# LeetCode 均匀树划分 题解

## 1. 题目概述

- **标题 / 题号**：均匀树划分（#663，medium）
- **链接**：https://leetcode.cn/problems/equal-tree-partition/
- **来源**：LeetCode 第 46 场周赛 Q3
- **难度**：中等
- **标签**：树、深度优先搜索、二叉树

**题意**：给定一棵带权二叉树，要求**恰好删除一条边**，把它分成两棵树，并判断是否存在某种删法使得两棵树的节点权值之和相等。

**约束**：

- 节点值 $val \in [-10^{5}, 10^{5}]$，可以为负数或 $0$
- 节点数 $1 \le n \le 10^{4}$
- 必须恰好删一条边，因此 $n = 1$ 时无解

## 2. 示例

**示例 1**

```text
输入：root = [5,10,10,null,null,2,3]
输出：true
解释：删除根节点 5 与其右侧子节点 10 之间的边，
      得到 {5,10} 与 {10,2,3}，两部分的和都是 15。
```

**示例 2**

```text
输入：root = [1,2,10,null,null,2,20]
输出：false
解释：整棵树总和为 35，删除任意一条边后两部分之和都不可能相等。
```

## 3. 解题思路

### 3.1 暴力思路

树有 $n-1$ 条边。最直白的做法是枚举每条边，删掉后从两侧各做一次遍历求节点和，比较是否相等：单次判断 $O(n)$，总计 $O(n^{2})$。$n = 10^{4}$ 时约 $10^{8}$ 次操作，常数偏大；而且每换一条边都得重新组织一次遍历，实现也繁琐。

瓶颈在于「每条边都要重新统计一遍和」。但删边后的两部分有很强的结构，一次遍历就能拿到全部候选值。

### 3.2 核心观察：删边 = 切出一棵非根子树

![删一条边等价于切出一棵非根子树](images/wc46_q3_cut_edge_subtree.svg)

树是无环连通图，删掉任意一条边 $e = (\mathrm{parent}(v), v)$ 后必然恰好裂成两个连通块，其中一侧的节点集合正好是 $v$ 的整棵子树 $\mathrm{subtree}(v)$，另一侧则是剩下的部分。记

$$\operatorname{sum}(v) = \sum_{u \in \mathrm{subtree}(v)} u.val, \qquad S = \operatorname{sum}(\mathrm{root})$$

那么两部分之和分别是 $\operatorname{sum}(v)$ 与 $S - \operatorname{sum}(v)$，要求它们相等，即要求

$$\operatorname{sum}(v) = S - \operatorname{sum}(v) \iff \operatorname{sum}(v) = \frac{S}{2}$$

于是原问题被压缩成两个判定：

1. $S$ 必须是**偶数**。节点值都是整数，子树和也是整数，两半之和相等时各自恰为 $S/2$，不可能是非整数；
2. 存在某个**非根**节点 $v$ 使 $\operatorname{sum}(v) = S/2$。

「非根」这一条最容易被忽略：根的子树就是整棵树，它不对应任何一条边，把根算进去会凭空造出一个不存在的切法。

### 3.3 算法流程

![一次后序遍历的流程](images/wc46_q3_algorithm_flow.svg)

只需要一次后序遍历，伪代码如下：

```text
dfs(v, isRoot):
    if v == null: return 0
    s = v.val + dfs(v.left, false) + dfs(v.right, false)
    if not isRoot: seen.insert(s)      # 根不入集合
    return s

S = dfs(root, true)
if S % 2 != 0: return false
return (S // 2) in seen
```

后序保证「先拿到两个孩子的子树和，再合成自己的」，每个节点只被访问一次；根作为唯一例外不入集合，用它的返回值充当 $S$。

### 3.4 示例演算

![两个示例的后序演算](images/wc46_q3_walkthrough.svg)

**示例 1**：`[5,10,10,null,null,2,3]`，根为 5，右孩子 10 带两个叶子 2、3。

| 访问顺序（后序） | 子树和 | 是否入集合 |
|------------------|--------|------------|
| 2 | 2 | 是 |
| 3 | 3 | 是 |
| 10（左孩子） | 10 | 是 |
| 10（右孩子） | $10+2+3=15$ | 是 |
| 5（根） | $5+10+15=30$ | 否（$S=30$） |

$S = 30$ 为偶数，$S/2 = 15$，而 $\{2,3,10,15\}$ 中恰好有 15 → 返回 `true`。

**示例 2**：`[1,2,10,null,null,2,20]`，右子树和为 $10+2+20=32$，$S = 1+2+32 = 35$ 为奇数，直接返回 `false`，连集合都不用查。

## 4. 算法细节

1. **必须后序**：子树和要等两个孩子的结果都算完才能确定，前序拿不到孩子信息；后序的返回值天然就是子树和。
2. **根的子树和单独用**：$S = \operatorname{sum}(\mathrm{root})$ 就是 `dfs(root)` 的返回值。由于根本身不入集合，代码里无需再 `erase`，也就天然避开了「$S = 0$ 时根把自己匹配上」的假阳性。
3. **集合只存值**：判定只关心「$S/2$ 是否作为某个非根子树和出现过」，用 `set` / `unordered_set` / Python 的 `set` 即可，重复值不影响结论。
4. **奇偶判断的负数语义**：C++ 中 `-7 % 2 == -1`，所以写 `total % 2 != 0` 能正确识别负奇数；写成 `total % 2 == 1` 对负奇数会失效。Python 的 `%` 返回非负值，`-7 % 2 == 1`，两种写法都对。
5. **累加用 64 位**：$n \le 10^{4}$、$|val| \le 10^{5}$，故 $|S| \le 10^{9}$。这个值仍在 `int` 范围内（$2.1\times10^{9}$），但余量只剩一倍左右，用 `long long` 累加可以完全不必推理溢出；Python 整数天然无溢出。
6. **空节点返回 0**：写 `if (!v) return 0;` 之后，叶子节点、只有一个孩子的节点都不需要额外特判。
7. **递归深度**：链状树深度可达 $10^{4}$。C++ 每帧很小通常够用，Python 默认递归上限 1000 会 `RecursionError`，需要 `sys.setrecursionlimit` 或改成显式栈的迭代后序。

## 5. 正确性证明

**引理 1**：对任意非根节点 $v$，删掉边 $(\mathrm{parent}(v), v)$ 后，两个连通块的点集分别为 $\mathrm{subtree}(v)$ 与 $V \setminus \mathrm{subtree}(v)$。

**证明**：树删去一条边后恰剩两个连通块。$v$ 与其任意后代的路径都不经过该边，故 $\mathrm{subtree}(v)$ 整体留在 $v$ 所在块内；反过来，$v$ 所在块中任一节点 $u$ 若要走到 $v$ 以外，路径必须经过边 $(\mathrm{parent}(v), v)$，删边后不可能，故 $u \in \mathrm{subtree}(v)$。所以 $v$ 侧恰为 $\mathrm{subtree}(v)$，另一侧是它的补集。∎

**引理 2**：存在合法删边使两半和相等 $\iff$ $S$ 为偶数且存在非根节点 $v$ 满足 $\operatorname{sum}(v) = S/2$。

**证明**：

- ($\Rightarrow$) 设删掉 $(\mathrm{parent}(v), v)$ 后两半和相等。由引理 1，两半之和分别为 $\operatorname{sum}(v)$ 与 $S - \operatorname{sum}(v)$，相等即得 $\operatorname{sum}(v) = S/2$；既然两边都是整数，$S = 2\operatorname{sum}(v)$ 必为偶数。
- ($\Leftarrow$) 若 $S$ 为偶数且某非根节点 $v$ 满足 $\operatorname{sum}(v) = S/2$，由于 $v$ 非根，边 $(\mathrm{parent}(v), v)$ 确实存在，删掉它，由引理 1 两半之和分别为 $S/2$ 与 $S - S/2 = S/2$，相等。∎

**定理**：`checkEqualTree` 返回 `true` 当且仅当原树可以按要求划分。

**证明**：对树高归纳可知后序遍历中 `dfs` 对每个节点都正确返回其子树和（空树返回 0；节点值加上两个孩子已正确算出的子树和即为该节点子树和），且恰好把所有非根节点的子树和放入 `seen`，因此 `seen` 就是全部非根子树和的集合；$S$ 由同一次遍历得到。当 $S$ 为偶数时，「`seen` 包含 $S/2$」与「存在非根 $v$ 使 $\operatorname{sum}(v) = S/2$」等价（集合是精确比较，不存在哈希碰撞问题），再由引理 2 得结论；当 $S$ 为奇数时，由引理 2 必不可划分，算法也返回 `false`。∎

## 6. 复杂度分析

- **时间**：$O(n)$。一次后序遍历访问每个节点一次，每节点做常数次加法与一次集合插入；根处理完后是一次奇偶判断与一次集合查询，哈希集合均摊 $O(1)$。
- **空间**：$O(n)$。集合最坏存 $n-1$ 个子树和；递归栈深度等于树高 $h$，最坏 $O(n)$（链状树），最好 $O(\log n)$（平衡树）。

## 7. 参考代码

### C++

```cpp
#include <functional>
#include <unordered_set>
using namespace std;

class Solution {
public:
    bool checkEqualTree(TreeNode* root) {
        if (!root) return false;
        unordered_set<long long> seen;
        seen.reserve(20000);
        // 后序遍历：返回子树和；非根节点把子树和放进集合
        function<long long(TreeNode*, bool)> dfs = [&](TreeNode* node, bool isRoot) -> long long {
            if (!node) return 0;
            long long s = node->val;
            s += dfs(node->left, false);
            s += dfs(node->right, false);
            if (!isRoot) seen.insert(s);   // 根不入表：不存在「删掉根」这条边
            return s;
        };
        long long total = dfs(root, true);
        if (total % 2 != 0) return false;  // 负奇数取模为 -1，非 0 依然是奇数
        return seen.count(total / 2) > 0;
    }
};
```

### Python

```python
import sys
from typing import Optional

class Solution:
    def checkEqualTree(self, root: Optional[TreeNode]) -> bool:
        sys.setrecursionlimit(30000)
        seen = set()

        def dfs(node: Optional[TreeNode], is_root: bool) -> int:
            if node is None:
                return 0
            s = node.val + dfs(node.left, False) + dfs(node.right, False)
            if not is_root:
                seen.add(s)          # 根不入表，避免 S = 0 时自己匹配自己
            return s

        total = dfs(root, True)
        if total % 2 != 0:
            return False
        return (total // 2) in seen
```

## 8. 边界情况与易错点

1. **单节点树**：`[0]` 应返回 `false`。$S = 0$ 是偶数、$S/2 = 0$ 看起来「存在」，但树里根本没有边可删。若把根也插进集合再查询，这种情况会被误判为 `true`，这是本题最经典的坑。
2. **零和情形**：$S = 0$ 且存在非根零和子树时必须返回 `true`，例如 `[0,0,0]` 应返回 `true`（删任一条边得到 $\{0\}$ 与 $\{0,0\}$，两边和都是 0）。所以既不能「根也入表后直接查」，也不能简单地「全部入表再 `erase(S)`」。
3. **`erase` 删同值的陷阱**：`unordered_set::erase(key)` 会删掉**所有**等于该值的元素。若采用「先全部插入、再 `erase(total)`」的写法，遇到 $S = 0$ 且存在多个 0 和子树时会把正确答案一起删掉，必须改用 `multiset` 只删一个，或者像本文直接让根不入表。
4. **负权值**：$S$ 可能为负，$S/2$ 也可能为负；判定奇数务必写 `total % 2 != 0`，不要写 `total % 2 == 1`（C++ 对负数会失效）。
5. **比较的是权值和，不是节点数**：题目只要求和相等，不要额外加「两侧节点数相同」的条件。
6. **单孩子节点**：空孩子返回 0 直接参与加法，无需判断「有没有左孩子」。
7. **Python 递归深度**：链状树深 $10^{4}$，不调 `setrecursionlimit` 会直接抛异常；也可以用显式栈的迭代后序规避。
