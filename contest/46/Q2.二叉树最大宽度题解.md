# LeetCode 二叉树最大宽度 题解

## 1. 题目概述

- **标题 / 题号**：二叉树最大宽度（#662，medium）
- **链接**：https://leetcode.cn/problems/maximum-width-of-binary-tree/
- **来源**：LeetCode 第 46 场周赛 Q2
- **难度**：中等
- **标签**：树、深度优先搜索、广度优先搜索、二叉树

**题意**：把二叉树嵌进一棵「无限深的满二叉树」坐标系里：根占位置 $1$，位置 $i$ 的左孩子占 $2i$，右孩子占 $2i+1$。每一层的**宽度**是该层**最左非空节点**与**最右非空节点**的位置差加一，中间那些在满二叉树里存在、但实际为空的占位也计入长度。求所有层宽度的最大值。

**约束**：

- 节点数 $1 \le n \le 3000$
- $-100 \le \text{Node.val} \le 100$（节点值不参与计算，只为建树）
- 答案保证落在 32 位有符号整数范围内

## 2. 示例

**示例 1**

```text
输入：root = [1,3,2,5,3,null,9]
输出：4
解释：最大宽度出现在第 3 层，宽度为 4（位置 5,3,null,9）。
```

**示例 2**

```text
输入：root = [1,3,2,5,null,null,9,6,null,7]
输出：7
解释：最大宽度出现在第 4 层，两端是 6 和 7，
      中间隔着 5 个空位，故宽度 = 7。
```

**示例 3**

```text
输入：root = [1,3,2,5]
输出：2
解释：第 2 层是 (3,2)，第 3 层只有 5 一个节点，宽度 1；取最大得 2。
```

## 3. 解题思路

### 3.1 暴力思路

最直白的做法是「补全成一棵满二叉树再数」：把每个真实节点放到数组里，左孩子放 $2i$、右孩子放 $2i+1$，空位填 `null`，然后逐层扫描这一层的数组，找最左和最右的非空元素。

问题在于**数组长度由深度决定，而不是由节点数决定**：一条 3000 节点的链深度就是 3000，需要 $2^{3000}$ 个格子，任何语言都放不下。即使只看「答案 ≤ 32 位」这一条，宽度本身也能到 $2^{31}$ 量级，一旦真的展开空位，时间与空间都会爆炸。

所以暴力不可行的根源是：**我们只需要两端的占位号，不需要中间的占位**。

### 3.2 核心观察：占位号可以沿边递推，宽度只看两端

![满二叉树编号与每层宽度](images/wc46_q2_heap_index.svg)

关键有两点：

1. **占位号是局部可算的**。根记 $1$（从 $0$ 起也一样），则任意节点 $i$ 的左孩子是 $2i$、右孩子是 $2i+1$。孩子的位置只依赖父节点的位置，**完全不需要中间的空节点存在**。于是无论空位有多少，我们都能用一个整数精确表示「这个节点在满二叉树中的第几列」。
2. **宽度只依赖同层最左与最右两个位置**。设第 $d$ 层最左占位号为 $L$、最右为 $R$，则该层宽度恰为

$$w_d = R - L + 1$$

因为满二叉树第 $d$ 层的位置是连续编号的，$L$ 与 $R$ 之间的每一个整数位置都对应一个（可能为空的）占位。

还有一个必须重视的工程细节：朴素的 $2i$ 递推在两三百层后就会让 `long long` 溢出（$2^{3000}$ 天文数字）。但注意 $w_d$ 只用到**差值**，所以可以把整层占位号统一减去本层最左值 $L$：

$$R - L + 1 = (R - L) + 1 = \text{rel}_{\max} + 1,\qquad \text{rel}(v) = p(v) - L$$

整层平移不改变任何差值，却把编号死死压在小范围里（相对编号不超过 $2n$ 量级），**既防溢出又保持答案不变**。

### 3.3 算法流程

![BFS 逐层处理流程](images/wc46_q2_bfs_flow.svg)

1. 队列放入 `(root, 1)`，`ans = 0`。
2. 每轮先取 `size = q.size()` 与队首的绝对占位号 `first`，把 `last = first`。
3. 循环 `size` 次：弹出 `(node, idx)`，令 `rel = idx - first`、`last = rel`；若左孩子存在，入队 `(left, rel * 2)`；右孩子存在则入队 `(right, rel * 2 + 1)`。
4. 本层出完，`ans = max(ans, last + 1)`（因为最左节点的 `rel` 一定是 $0$）。
5. 队列空时返回 `ans`。

注意第 3 步孩子用的是 `rel * 2`，等价于「下一层整体减去了 $2 \times \text{first}$」，仍然是对下一层的统一平移，由引理 3 宽度不受影响。

**DFS 变体**（标签里也有 DFS）：用一个 `map<depth, leftmost>` 记录每层第一次遇到的最左下标的**相对值**，进入节点时若该层未记录则记录，然后 `ans = max(ans, idx - leftmost[depth] + 1)`，随后递归时同样传 `(i - leftmost) * 2` 之类的相对编号。DFS 少一个队列，但语义不如 BFS「按层」直观。

### 3.4 示例演算

对示例 2（`root = [1,3,2,5,null,null,9,6,null,7]`）逐层走一遍：

![示例 2 的逐层演算表](images/wc46_q2_example_walkthrough.svg)

| 层 | 该层原始占位号 | `first` | `rel = idx - first` | 宽度 |
|----|----------------|---------|---------------------|------|
| 1 | 1 | 1 | 0 | 1 |
| 2 | 2, 3 | 2 | 0, 1 | 2 |
| 3 | 4, 7 | 4 | 0, 3 | 4 |
| 4 | 8, 14 | 8 | 0, 6 | **7** |

第 4 层只有 2 个真实节点，宽度却是 7——这就是「空位计入长度」的含义。第 3 层占位号从 4 跳到 7，是因为节点 `2`（位置 3）的右孩子 `9` 落在 $2\times3+1=7$，中间位置 5、6 是两个空儿子。

## 4. 算法细节

1. **编号起点统一**：根用 $0$ 或 $1$ 都可以（宽度是差值，起点只影响整体偏移），但全树必须一致；本文代码与插图统一用 $1$，于是根在第 1 列。
2. **每层必须先锁 `first`**：入队/出队期间 `first` 是本层最左的**原始**占位号，不能等到出完再取，否则队列里已经混入下一层。
3. **`rel` 的计算是防溢出的核心**：`rel = idx - first`，同一层统一减同一个数，宽度公式保持不变；孩子用 `rel * 2` / `rel * 2 + 1` 入队，等价于下一层再整体平移。
4. **队列顺序即左右顺序**：父节点从左到右出队，孩子先左后右入队，因此同层节点在队列里天然从左到右排列，最后一个弹出的 `rel` 就是本层最大相对编号，不需要再比较。
5. **宽度写成 `last + 1`**：因为本层最左节点的 `rel` 必为 $0$，公式退化成「右端点相对坐标 + 1」，少一次减法也更不容易写错。
6. **`long long` 兜底**：虽然归一化后相对编号只有 $O(n)$ 量级，但 `rel * 2 + 1` 在极端宽层仍可能摸到 $2^{32}$，C++ 一律用 `long long` 存占位号，最后再转 `int` 返回。
7. **DFS 写法的记录时机**：DFS 先序遍历会先访问某层最左节点，故「该层首次出现」即最左；但递归传入的编号也必须相对化（例如 `2 * (i - leftmost)`），否则同样会溢出。

## 5. 正确性证明

**引理 1（占位号即满二叉树列号）**：设节点 $v$ 深度为 $d$，按「根为 $1$，左孩子 $2i$，右孩子 $2i+1$」递推得到的编号 $p(v)$，恰等于 $v$ 在深度 $d$ 的满二叉树中从左起的列号。

**证明**：对深度归纳。$d=0$ 时只有根，编号 $1$ 即第 $1$ 列。设深度 $d$ 的节点 $u$ 编号为 $k$，由归纳假设它在第 $k$ 列；其左孩子编号 $2k$，而满二叉树第 $k$ 列节点的左孩子正在第 $2k$ 列；右孩子编号 $2k+1$，同理落在第 $2k+1$ 列。故深度 $d+1$ 的编号也正确。∎

**引理 2（宽度公式）**：第 $d$ 层最左非空节点占位号为 $L$、最右为 $R$，则该层宽度为 $R-L+1$。

**证明**：由引理 1，满二叉树第 $d$ 层的位置恰是从 $2^d$ 到 $2^{d+1}-1$ 的连续整数，每个整数对应一个占位（可能为空）。区间 $[L,R]$ 内的整数个数为 $R-L+1$，正好是两端点之间（含端点）的长度；而这些位置正对应题目定义的「两端点之间延伸出的节点（含 null）」。∎

**引理 3（整层平移不变）**：把同一层的所有占位号减去同一个常数 $c$，该层宽度不变。

**证明**：宽度 $=(R-c)-(L-c)+1=R-L+1$，与 $c$ 无关。∎

**引理 4（队内同层有序）**：按上述入队规则，队列中属于同一层的节点，按从左到右排列。

**证明**：初始只有根。归纳：某层出队顺序为 $v_1,v_2,\dots,v_k$（从左到右），每个 $v_j$ 先压入左孩子再压入右孩子，产生的下一层序列为 $L_1,R_1,L_2,R_2,\dots$，左右孩子之间的相对顺序与父节点一致，故下一层仍从左到右。∎

**定理**：算法返回所有层宽度的最大值。

**证明**：每层处理时，队首是本层最左节点（引理 4），其原始编号被取为 `first`；最后一弹出的是本层最右节点（引理 4），其相对编号 `last` 由引理 3 满足 `last + 1 = R - L + 1`，即该层真实宽度（引理 2）。算法对每一层都更新 `ans = max(ans, last + 1)`，而所有存在节点的层都会被 BFS 访问且仅访问一次，故返回值为全体层宽度的最大值。∎

## 6. 复杂度分析

- **时间**：$O(n)$。每个节点恰好入队、出队各一次，出队时做常数次算术与最多两次入队；逐层更新 `ans` 也是每层 $O(1)$，层数不超过 $n$。
- **空间**：$O(n)$。队列中最多同时存放相邻两层节点，总数不超过 $n$；相对编号是 $O(1)$ 个整数，无额外数组（DFS 变体额外用 $O(h)\le O(n)$ 的深度映射与递归栈）。

## 7. 参考代码

### C++

```cpp
#include <algorithm>
#include <queue>
#include <utility>
using namespace std;

struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
};

class Solution {
public:
    int widthOfBinaryTree(TreeNode* root) {
        if (!root) return 0;
        int ans = 0;
        queue<pair<TreeNode*, long long>> q;   // 占位号用 long long 兜底
        q.push({root, 1});
        while (!q.empty()) {
            int size = (int)q.size();
            long long first = q.front().second;  // 本层最左的原始占位号
            long long last = first;
            for (int i = 0; i < size; ++i) {
                auto [node, idx] = q.front();
                q.pop();
                long long rel = idx - first;     // 整层平移：宽度不变，防溢出
                last = rel;
                if (node->left)  q.push({node->left,  rel * 2});
                if (node->right) q.push({node->right, rel * 2 + 1});
            }
            ans = max(ans, (int)last + 1);       // 最左 rel 恒为 0
        }
        return ans;
    }
};
```

### Python

```python
from collections import deque


class Solution:
    def widthOfBinaryTree(self, root: TreeNode | None) -> int:
        if root is None:
            return 0
        ans = 0
        q = deque([(root, 1)])
        while q:
            size = len(q)
            first = q[0][1]          # 本层最左节点的原始占位号
            last = first
            for _ in range(size):
                node, idx = q.popleft()
                rel = idx - first    # 归一化：整层同减，宽度不变
                last = rel
                if node.left:
                    q.append((node.left, rel * 2))
                if node.right:
                    q.append((node.right, rel * 2 + 1))
            ans = max(ans, last + 1)
        return ans
```

## 8. 边界情况与易错点

1. **单节点**：`[1]` → 宽度 1。此时 `first = 1`，归一化后 `rel = last = 0`，宽度 `last + 1 = 1`，不要漏算端点本身。
2. **3000 层深链**：`[1,1,1,...]` 全挂在左边或全挂右边时宽度恒为 1。若不做归一化，编号会随深度按 $2^d$ 指数增长，3000 层时达到 $2^{3000}$ 量级，`long long` 直接溢出成负数——这是本题最经典的 WA 原因。代码实测 3000 节点左链返回 1。
3. **宽度可以远大于该层节点数**：示例 2 第 4 层只有 2 个真实节点，宽度却是 7。绝不能用「该层节点个数」当宽度。
4. **忘记按层分批**：必须在弹出前固定 `size`，否则会边出队边混入下一层，`first`/`last` 都失去意义。注意本层宽度在循环**结束后**才更新，不要放在循环里。
5. **`first` 取了归一化后的值却又用原始 `last`**：两者必须来自同一套坐标系。本代码 `first` 取原始占位号，`last` 取相对值，宽度写成 `last + 1`；若写成 `last - first + 1` 就会少算。
6. **答案类型**：题面保证结果在 32 位有符号整数范围内，但中间量 `rel * 2 + 1` 可能超出 `int`，所以占位号用 `long long`、只在返回时转 `int`。
7. **空树**：LeetCode 保证 $n \ge 1$，但工程代码仍应判空返回 0，避免解引用空指针。
