# LeetCode 奇怪的打印机 题解

## 1. 题目概述

- **标题 / 题号**：奇怪的打印机（#664，hard）
- **链接**：https://leetcode.cn/problems/strange-printer/
- **来源**：LeetCode 第 46 场周赛 Q4
- **难度**：困难
- **标签**：字符串、动态规划

**题意**：从一张空白纸开始，打印机每轮只能把**一段连续区间**整体刷成**同一个字符**，后刷的字符会覆盖先刷的字符。给定目标串 `s`，求从空白刷出 `s` 所需的最少轮数。

换个说法：要用最少的「同字符区间覆盖」叠出目标串。关键在于**先铺后盖**——先把一大段刷成某个字符，再用别的小段去覆盖它，这样同一个字符只需一次刷印就能出现在多个不相邻的位置上。

**约束**：

- $1 \le \lvert s \rvert \le 100$
- `s` 仅由小写英文字母组成

## 2. 示例

**示例 1**

```text
输入：s = "aaabbb"
输出：2
解释：第 1 轮刷 "aaa"，第 2 轮刷 "bbb"，两轮各自覆盖一段连续区间。
```

**示例 2**

```text
输入：s = "aba"
输出：2
解释：第 1 轮把整段刷成 "aaa"，第 2 轮把中间位置刷成 "b" 盖住原来的 'a'。
      若每个字符各刷一次需要 3 轮，"先铺后盖"省掉了 1 轮。
```

**示例 3（补充，非官方）**

```text
输入：s = "abca"
输出：3
解释：第 1 轮把整段刷成 "aaaa"，第 2 轮在 1 号位刷 "b"，第 3 轮在 2 号位刷 "c"，
      首尾两个 'a' 由同一轮涂色完成，因此不是 4 轮。
```

## 3. 解题思路

### 3.1 暴力思路

暴力就是搜索每一轮的「字符 + 区间」：字符有至多 26 种、区间有 $\frac{n(n+1)}{2}$ 种，而答案最坏是 $n$（逐字符各刷一次），搜索树大小约为 $\left(26\cdot\frac{n^2}{2}\right)^{n}$，$n = 100$ 时完全不可行。

贪心也走不通。「从左往右扫，遇到相同字符就把上一次的涂色延长过来」这种写法会漏掉**先铺后盖**：`"aba"` 只有先刷 `"aaa"` 再盖 `"b"` 才是 2 轮，而一眼看上去每个字符都不同，贪心会给出 3。要判断「某个位置该由哪一轮涂色负责」，必须同时知道区间两端的字符，这正是**区间**结构。

观察题目的两条规则：一轮涂色只作用在**一个连续区间**上；某个位置最终的字符，只取决于**最后一次**覆盖它的那一轮。于是问题天然按区间递归：想解决 $[i,j]$，只需要知道「$i$ 处的字符最后由哪一轮铺上去、那一轮还顺带盖住了右边哪些位置」。

### 3.2 核心观察：同字符的两端可以共用一次涂色

![一次涂色顺便盖住同字符的远处位置](images/wc46_q4_shared_turn.svg)

记 $f(i,j)$ 为刷出子串 $s[i..j]$ 的最少轮数。盯住区间最左的位置 $i$：它的最终字符是 $s[i]$，那么**最后一次覆盖 $i$ 的那一轮**涂的必然是 $s[i]$，并且覆盖一个以 $i$ 为左端点的区间 $[i,k]$（把右端点收缩到最后一个「最终字符仍为 $s[i]$」的位置，收缩不会破坏正确性）。

- **$k = i$**：这一轮只对 $i$ 有用，可以先解决 $[i+1,j]$，再补刷一次 $i$，得到 $f(i,j) \le f(i+1,j)+1$。
- **$k > i$**：此时必有 $s[k] = s[i]$，也就是 $i$ 与 $k$ 由**同一轮**涂色完成。中间那段 $[i+1,k-1]$ 上的字符和 $s[i]$ 不同，必须在这轮之后（或之前的其它轮里）另外补齐；右半段 $[k,j]$ 也照常处理。两段子问题各自只在自己的区间里落笔，互不干扰，于是 $f(i,j) \le f(i+1,k-1) + f(k,j)$。

右端点 $k$ 可以取**任何**满足 $s[k] = s[i]$ 的位置，所以要对所有候选取最小：

$$f(i,j) = \min\Big( f(i+1,j)+1,\ \min_{\substack{i < k \le j \\ s[k]=s[i]}} \big( f(i+1,k-1) + f(k,j) \big) \Big)$$

这一步是本题的灵魂：**同一个字符在区间内出现多次时，只有一次涂色是「免费搭车」的，其余同字符位置仍要靠右侧子问题自己解决**——所以不能简单地把「同字符出现次数」相加。

### 3.3 算法流程 / 状态转移

![区间 DP 的转移与填写顺序](images/wc46_q4_interval_dp_flow.svg)

- **状态**：$dp[i][j]$ 表示刷出 $s[i..j]$ 的最少轮数，$0 \le i \le j < n$。
- **边界**：$dp[i][i] = 1$（一个字符总要刷一次）；约定空区间 $dp[i+1][i] = 0$。
- **转移**：按上式，先取基准 $dp[i+1][j]+1$，再枚举 $k \in (i,j]$ 且 $s[k] = s[i]$ 的位置，用 $dp[i+1][k-1] + dp[k][j]$ 尝试更新。
- **顺序**：$i$ 从 $n-1$ 递减到 $0$，$j$ 从 $i+1$ 递增到 $n-1$。$dp[i][j]$ 依赖的三项分别是 $dp[i+1][j]$（长度少 1）、$dp[i+1][k-1]$（长度至少少 2）、$dp[k][j]$（左端点右移，区间更短），长度全部严格小于 $j-i+1$，所以任何「按区间长度递增」的顺序都合法。
- **答案**：$dp[0][n-1]$。

### 3.4 示例演算

![s = "abca" 的 DP 表与还原过程](images/wc46_q4_walkthrough.svg)

以 `s = "abca"` 为例，表按长度递增填写，只填上三角：

| $i \backslash j$ | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| **0** | 1 | 2 | 3 | **3** |
| **1** | — | 1 | **2** | 3 |
| **2** | — | — | 1 | 2 |
| **3** | — | — | — | **1** |

求 $dp[0][3]$：基准值是 $dp[1][3] + 1 = 3 + 1 = 4$；区间内与 $s[0] = \texttt{a}$ 相同的位置只有 $k = 3$，候选值为

$$dp[1][2] + dp[3][3] = 2 + 1 = 3$$

取最小值得到 $3$。还原成涂色序列：第 1 轮刷 $[0,3]$ 得 `"aaaa"`，第 2 轮刷 $[1,1]$ 得 `"abaa"`，第 3 轮刷 $[2,2]$ 得 `"abca"`，与 $dp[0][3]$ 一致。

再看两个例子：`"aba"` 的 $dp[0][2] = dp[1][1] + dp[2][2] = 2$（$s[0] = s[2]$ 共享第 1 轮）；`"aaabbb"` 先压缩成 `"ab"`，$dp[0][1] = dp[1][1] + 1 = 2$。

## 4. 算法细节

1. **区间长度递增是安全顺序**。$L = j-i+1$ 时，$dp[i+1][j]$ 长度 $L-1$、$dp[i+1][k-1]$ 长度 $k-i-1 \le L-2$、$dp[k][j]$ 长度 $j-k+1 \le L-1$，都严格小于 $L$，因此按 $L$ 递增填写（或等价地 $i$ 递减、$j$ 递增）不会读到未计算的值。
2. **空区间的处理**。$k = i+1$ 时 $dp[i+1][k-1] = dp[i+1][i]$ 是空区间，必须取 $0$。代码里用 `k - 1 >= i + 1 ? dp[i+1][k-1] : 0` 判断，或者把表开到 $(n+1)\times(n+1)$ 并初始化 $dp[i+1][i] = 0$。
3. **必须枚举所有同字符位置 $k$**，不能只取最近或最远的那个。只保留最远位置时 `"aaa"` 会算出 2（实际 1）；只保留最近位置时 `"abcacba"` 会算出 5（实际 4）。原因是「共享一次涂色」的候选位置之间会互相顶替，多一个候选就多一种省轮数的可能。
4. **状态不能压成一维**。转移里同时出现 $dp[i+1][k-1]$ 与 $dp[k][j]$，左侧区间的右端点和右侧区间的左端点没有共同的单一下标，$O(n^2)$ 个状态都是必需的。
5. **先合并相邻相同字符**。连续相同的字符块只需一轮涂色覆盖，把它们压缩成一个字符不改变答案（一轮涂色本就能覆盖整段相同字符，压缩既不会变差也不会变好），因此 `"aaabbb"` 可以先变成 `"ab"`。$n \le 100$ 时这只是常数级加速，但能缩小内层循环。
6. **答案只依赖 $n$**：最坏情况是每个字符各刷一次，所以答案 $\le n \le 100$，用 `int` 足够；$O(n^3) = 10^6$ 次操作，无需任何优化技巧。

## 5. 正确性证明

**引理 1（上界构造）**：对任意 $i < k \le j$ 且 $s[k] = s[i]$，有 $f(i,j) \le f(i+1,k-1) + f(k,j)$；并且 $f(i,j) \le f(i+1,j) + 1$。

**证明**：

- 后者：先用最优方案刷出 $[i+1,j]$，再单独刷一次 $[i,i]$，后刷不会影响已经正确的 $[i+1,j]$。∎
- 前者：先按 $[k,j]$ 的最优方案刷，并把其中「最终在 $k$ 处留下 $s[k]$ 的那一轮」向左延伸，使其覆盖 $[i,k]$——这一轮的颜色是 $s[k] = s[i]$，延伸后仍是同一字符的连续区间，合法，且只多覆盖了 $i$ 与 $[i+1,k-1]$ 中的位置；随后再执行 $[i+1,k-1]$ 的最优方案（只在该区间内落笔）。最终 $i$ 保留 $s[i]$、$[i+1,k-1]$ 由第二个子方案修正、$[k,j]$ 保持正确，总轮数为 $f(i+1,k-1)+f(k,j)$。∎

**引理 2（限制引理）**：若存在 $[i,j]$ 的合法方案 $S$，则对任意子区间 $[a,b] \subseteq [i,j]$，把 $S$ 中每一轮的涂色区间与 $[a,b]$ 求交、丢弃空交集，得到的是 $[a,b]$ 的合法方案，轮数不超过 $\lvert S \rvert$。

**证明**：每一轮的交集仍是同一字符的连续区间（可能为空），仍是合法的涂色动作。$[a,b]$ 中任一位置的最终字符由「最后一次覆盖它的那一轮」决定，求交后这一轮仍是最后一次覆盖它的轮次，故最终结果不变。∎

**引理 3（分解引理）**：设 $S$ 是 $[i,j]$ 的最优方案，$m = \lvert S \rvert$，$T$ 为 $S$ 中**最后一次覆盖 $i$** 的一轮。$T$ 的颜色必为 $s[i]$；把 $T$ 的右端点收缩到最后一个「最终字符仍为 $s[i]$」的位置 $k$（$i$ 右侧没有这样的位置时 $k = i$），则

- $k = i$ 时，$m \ge f(i+1,j) + 1$；
- $k > i$ 时（此时 $s[k] = s[i]$），$m \ge f(i+1,k-1) + f(k,j)$。

**证明**：

- **$k = i$**：$T$ 只落在 $i$ 上，删掉它后其余 $m-1$ 轮在 $[i+1,j]$ 上仍合法，由引理 2 得 $f(i+1,j) \le m-1$。
- **$k > i$**：先做**规范化**。称一轮 $U \ne T$ 是「跨界」的，若它同时覆盖 $[i+1,k-1]$ 与 $[k,j]$ 中的位置。在全体最优方案中取跨界轮次最少的一个，说明它一定没有跨界轮：
  1. $U$ 早于 $T$：$U$ 落在 $[i,k]$ 内的涂色会被 $T$ 整段覆盖（$T$ 更晚且覆盖整个 $[i,k]$），裁掉这部分后 $U$ 只剩 $(k,q] \subseteq [k,j]$，最终结果不变、轮数不变，跨界轮次减一；
  2. $U$ 晚于 $T$ 且颜色为 $s[i]$：裁掉 $U$ 落在 $[i+1,k-1]$ 的部分后，那里的最终字符仍是 $s[i]$（$T$ 已铺好同色，若原本由更晚的涂色决定则更晚的涂色依旧覆盖它），跨界轮次减一；
  3. $U$ 晚于 $T$ 且颜色 $d \ne s[i]$：$U$ 在 $k$ 上留下的 $d$ 必被更晚的某轮改回 $s[i]$（$k$ 的最终字符是 $s[i]$），说明 $k$ 处的收尾同样是一轮「$s[i]$ 涂色」；于是可以把 $T$ 与这轮收尾合并看作 $i$、$k$ 共享的那一轮，$U$ 的跨界部分由它承担，从而 $U$ 可收缩到一侧，跨界轮次减一。

  每次调整都严格减少跨界轮次且不增加轮数，故有限步后得到一个「无跨界轮」的最优方案。

  此时 $S$ 的其余 $m-1$ 轮被分成两组：$A$ 完全落在 $[i+1,k-1]$，$B$ 完全落在 $[k,j]$。$A$ 本身是 $[i+1,k-1]$ 的合法方案，故 $f(i+1,k-1) \le \lvert A \rvert$；$B$ 再加上 $T$（$T$ 覆盖 $k$ 且整体落在 $[k,j]$ 内）是 $[k,j]$ 的合法方案，故 $f(k,j) \le \lvert B \rvert + 1$。又 $m = \lvert A \rvert + \lvert B \rvert + 1$，两式相加即得 $f(i+1,k-1) + f(k,j) \le m$。∎

**定理**：算法输出的 $dp[0][n-1]$ 等于最少涂色轮数 $f(0,n-1)$。

**证明**：对区间长度归纳。长度为 1 时 $dp[i][i] = 1 = f(i,i)$。设长度 $< L$ 时 $dp = f$ 成立，考察长度 $L$ 的区间 $[i,j]$：由引理 1，两种构造给出 $f(i,j) \le dp[i][j]$（$dp[i][j]$ 正是这些构造值的最小值，且构造出的候选都取自更短的区间，归纳假设保证其值等于对应的 $f$）；由引理 3，任一最优方案 $S$ 给出 $f(i,j) = \lvert S \rvert \ge f(a,b)$，其中 $f(a,b)$ 是某个更短区间的答案（$f(i+1,j)$ 或 $f(i+1,k-1)+f(k,j)$），按归纳假设它等于对应的 $dp$ 值，而该 $dp$ 值又参与 $dp[i][j]$ 的取最小，故 $f(i,j) \ge dp[i][j]$。故 $dp[i][j] = f(i,j)$，归纳成立，取 $i=0,\,j=n-1$ 即得结论。∎

## 6. 复杂度分析

- **时间**：$O(n^3)$。状态数 $O(n^2)$，每个状态枚举 $k$ 是 $O(n)$；$n \le 100$ 时约 $10^6$ 次基本操作，实测在毫秒级。
- **空间**：$O(n^2)$，即 $100 \times 100$ 的 `int` 表，约 40 KB；不需要额外辅助数组（若先做相邻去重，则用 $O(n)$ 的临时字符串）。
- **去重后的规模**：令 $m$ 为相邻去重后的长度（$m \le n$），时间降为 $O(m^3)$，空间 $O(m^2)$。

## 7. 参考代码

### C++

```cpp
#include <string>
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int strangePrinter(string s) {
        int n = (int)s.size();
        if (n == 0) return 0;
        vector<vector<int>> dp(n, vector<int>(n, 0));
        for (int i = n - 1; i >= 0; --i) {
            dp[i][i] = 1;                       // 单字符总要有一次涂色
            for (int j = i + 1; j < n; ++j) {
                dp[i][j] = dp[i + 1][j] + 1;    // 分支 ①：s[i] 独占一次涂色
                for (int k = i + 1; k <= j; ++k) {
                    if (s[k] != s[i]) continue; // 分支 ②：只考虑与 s[i] 同字符的 k
                    int left = (k - 1 >= i + 1) ? dp[i + 1][k - 1] : 0; // 空区间取 0
                    dp[i][j] = min(dp[i][j], left + dp[k][j]);
                }
            }
        }
        return dp[0][n - 1];
    }
};
```

### Python

```python
class Solution:
    def strangePrinter(self, s: str) -> int:
        n = len(s)
        if n == 0:
            return 0
        dp = [[0] * n for _ in range(n)]
        for i in range(n - 1, -1, -1):
            dp[i][i] = 1                       # 单字符总要有一次涂色
            for j in range(i + 1, n):
                dp[i][j] = dp[i + 1][j] + 1    # 分支 ①：s[i] 独占一次涂色
                for k in range(i + 1, j + 1):
                    if s[k] != s[i]:
                        continue               # 分支 ②：只考虑与 s[i] 同字符的 k
                    left = dp[i + 1][k - 1] if k - 1 >= i + 1 else 0
                    if left + dp[k][j] < dp[i][j]:
                        dp[i][j] = left + dp[k][j]
        return dp[0][n - 1]
```

## 8. 边界情况与易错点

1. **$n = 1$**：`"a"` 应返回 1。注意边界是 $dp[i][i] = 1$ 而不是 0，写成 0 会让所有答案偏小 1。
2. **$k = i+1$ 时的空区间**：`"ab"` 中 $k = i+1$ 不是同字符位置，但 `"aa"`（去重前）会命中 $k = i+1$，此时 $dp[i+1][k-1]$ 是空区间，必须取 0，否则会越界或读到脏值。
3. **只保留最近/最远的同字符位置**：`"aaa"` 只保留最远位置会算出 2、`"abcacba"` 只保留最近位置会算出 5（正确值分别是 1 和 4）。$k$ 的候选必须全部枚举。
4. **漏掉分支 ①**：若只写「同字符共享」的分支而不写 $dp[i+1][j]+1$，遇到 `"abc"` 这种区间内没有重复字符的情况就没有候选值可用，必须保留基准项。
5. **遍历顺序写反**：如果外层 $i$ 递增、内层 $j$ 递减，$dp[i+1][j]$ 与 $dp[k][j]$ 都可能尚未计算，会得到错误答案。牢记按区间长度递增（或 $i$ 递减、$j$ 递增）。
6. **不要拿「不同字符块数」当答案**：块数既不是下界也不是上界——`"aabbaa"` 有 3 个块但答案是 2（一个 `a` 段 + 一个 `b` 段即可），而 `"abcabc"` 有 6 个块、答案 5。答案只能靠区间 DP 求。
7. **两种对称写法不要混用**：本解法以左端点 $i$ 为主，只访问 $dp[i+1][j]$、$dp[i+1][k-1]$、$dp[k][j]$；若改写成以右端点 $j$ 为主，则要相应改成 $dp[i][j-1]$、$dp[k+1][j-1]$、$dp[i][k]$。混用会读到未初始化的格子。另外 Python 与 C++ 都不会溢出（答案 $\le 100$）。

- [LeetCode 1312. 让字符串成为回文串的最少插入次数](https://leetcode.cn/problems/minimum-insertion-steps-to-make-a-string-palindrome/)：字符串上的区间 DP 热身题，可以先练「按长度递增填表」的手感。

**延伸思考**：若把规则改成「每轮只能刷**一个位置**」，答案退化为 $n$；若改成「每轮可以同时刷若干个**互不相邻**的同字符位置」，问题就不再是区间 DP，而要考虑字符出现位置的独立性。另一个自然的变体是要求输出具体的涂色方案（而不是最少次数）：只要在转移时记录取到最小值的 $k$，再自顶向下递归打印 $[k,j]$、延伸涂色到 $[i,k]$、最后补 $[i+1,k-1]$，就能在线性于答案的额外时间内还原出一个最优序列。
