# LeetCode 使差值相等的最少数组改动次数 题解

## 1. 题目概述

- **标题 / 题号**：使差值相等的最少数组改动次数（#3224，medium）
- **链接**：https://leetcode.cn/problems/minimum-array-changes-to-make-differences-equal/
- **来源**：LeetCode 第 135 场双周赛 Q3
- **难度**：中等
- **标签**：数组、哈希表、前缀和

**题意**：给定长度为偶数 $n$ 的数组 $nums$（$0 \le nums[i] \le k$）。每次操作可以把**任意一个**元素改成 $[0, k]$ 内的**任意**整数。要求操作后存在整数 $X$，使得对所有 $0 \le i < n$ 都有

$$\lvert a[i] - a[n-1-i] \rvert = X$$

求最少操作次数。

注意 $X$ 只要对所有"对称位置对"成立即可，且 $X$ 不必等于数组中已存在的某个差值——它是我们**自由选择**的目标值（$0 \le X \le k$）。

**约束**：

- $2 \le n = nums.length \le 10^5$，且 $n$ 为偶数
- $0 \le nums[i] \le k \le 10^5$

$n$ 与 $k$ 都到 $10^5$，所以"枚举 $X$（$O(k)$ 个）× 每对单独算代价（$O(n)$）"的 $O(nk) = 10^{10}$ 必须优化；目标是把每个 $X$ 的代价从 $O(n)$ 降到 $O(1)$ 摊还。

## 2. 示例

**示例 1**

```text
输入：nums = [1,0,1,2,4,3], k = 4
输出：2
解释：三对分别是 (1,3)、(0,4)、(1,2)，差值 2、4、1。
      取 X = 2：把 nums[1] 改成 2、nums[3] 改成 3，得到 [1,2,1,3,4,3]，
      三对变成 (1,3)、(2,4)、(1,3)，差值都是 2，共 2 次改动。
```

**示例 2**

```text
输入：nums = [0,1,2,3,3,6,5,4], k = 6
输出：2
解释：四对分别是 (0,4)、(1,5)、(2,6)、(3,3)，差值 4、4、4、0。
      取 X = 4：把 nums[3] 改成 0、nums[4] 改成 4，得到 [0,1,2,0,4,6,5,4]，
      四对变成 (0,4)、(1,5)、(2,6)、(0,4)，差值都是 4，共 2 次改动。
```

**示例 3（边界补充）**

```text
输入：nums = [1,3], k = 5
输出：0
解释：只有一对，取 X = 2 即已满足，无需改动。

输入：nums = [0,0], k = 0
输出：0
解释：k = 0 时所有元素只能是 0，X 只能为 0，天然满足。
```

> 💡 示例 1 的 2 次改动有两个最优目标值：取 $X = 1$ 时把 `nums[5]` 改成 2、`nums[1]` 改成 3，得 `[1,3,1,2,4,2]`，三对差值都是 1。这说明**最优方案不唯一，$X$ 也不唯一**，枚举 $X$ 时必须把所有取值都扫一遍。

## 3. 解题思路

### 3.1 暴力思路

最朴素的框架是把 $X$ 从 $0$ 枚举到 $k$，对每个 $X$ 计算总代价：

```text
ans = INF
for X in 0..k:
    cost = 0
    for i in 0..n/2-1:
        a, b = nums[i], nums[n-1-i]
        # 求把 (a,b) 改成差值 X 的最少改动次数（0/1/2）
        cost += (逐个枚举 a', b' ∈ [0,k] 判断)
    ans = min(ans, cost)
```

内层如果也暴力枚举 $a', b'$，单对就是 $O(k^2)$，整体 $O(nk^3)$，完全不可行；即便单对用 $O(1)$ 判定，整体仍是 $O(nk) = 10^{10}$。

关键突破口是：**单对的代价只有 $0, 1, 2$ 三种取值，且"是否 $\le 1$"对 $X$ 构成一个前缀**。于是每个 $X$ 的代价可以用两个桶 + 一次后缀扫描 $O(1)$ 得到。

### 3.2 核心观察：单对代价是"一个点 + 一段前缀"

![单对 (a, b) 的代价随 X 变化：0 次 / 1 次 / 2 次](images/bw135_q3_pair_cost.svg)

固定一对 $(a, b)$，不妨设 $a \le b$，记

$$d = b - a, \qquad T = \max(k - a,\ b)$$

**一次改动是否够用？** 只改一个元素意味着另一个保持不变：

- 保留 $a$、只改 $b$：需要 $b' = a + X \le k$ 或 $b' = a - X \ge 0$，即 $X \le k - a$ 或 $X \le a$；
- 保留 $b$、只改 $a$：需要 $a' = b + X \le k$ 或 $a' = b - X \ge 0$，即 $X \le k - b$ 或 $X \le b$。

四个条件取并集，由于 $a \le b$ 蕴含 $k - a \ge k - b$ 与 $b \ge a$，并集恰好是 $X \le T$。于是

$$\text{cost}(X) = \begin{cases} 0, & X = d \\ 1, & X \ne d \text{ 且 } X \le T \\ 2, & X > T \end{cases}$$

注意 $d = b - a \le b \le T$，所以"$0$ 次点"永远落在"$\le 1$ 次"的前缀里，不会出现矛盾。

当 $X > T$ 时两次是否一定够？够——取 $(a', b') = (0, X)$，因为 $X \le k$ 保证 $X$ 合法，代价至多 2。

### 3.3 算法流程

![算法流程：两个桶 + 一次后缀扫描](images/bw135_q3_suffix_scan.svg)

设 $m = n/2$ 为对数，定义

- $zero[X]$：满足 $d = X$ 的对数（这些对在该 $X$ 下代价为 0）；
- $one[X]$：满足 $T \ge X$ 的对数（这些对在该 $X$ 下代价 $\le 1$）。

那么 $X$ 的总代价为

$$\text{cost}(X) = 2 \cdot \big(m - one[X]\big) + 1 \cdot \big(one[X] - zero[X]\big) = 2m - one[X] - zero[X]$$

最终的答案就是 $\min_{0 \le X \le k} \text{cost}(X)$。

实现上：

```text
1. 对每对 (a,b)（先令 a <= b）：
       zero[b - a] += 1
       cntT[max(k - a, b)] += 1
2. 对 X 从 k 递减到 0：
       run += cntT[X]; one[X] = run        # one 是 cntT 的后缀和
3. ans = min over X of (2m - one[X] - zero[X])
```

$one$ 是 $cntT$ 的后缀累加，因此 $one[X]$ 随 $X$ 单调不增，符合"$X$ 越大越难一次改好"的直觉。

### 3.4 示例演算

![示例演算：nums = [1,0,1,2,4,3]，k = 4](images/bw135_q3_example_walkthrough.svg)

$nums = [1,0,1,2,4,3]$，$k = 4$，$m = 3$，$2m = 6$。三对为 $(1,3)$、$(0,4)$、$(1,2)$：

| 配对 | $d$ | $T = \max(k-a, b)$ | 0 次点 |
|---|---|---|---|
| $(1,3)$ | 2 | $\max(3,3) = 3$ | $X = 2$ |
| $(0,4)$ | 4 | $\max(4,4) = 4$ | $X = 4$ |
| $(1,2)$ | 1 | $\max(3,2) = 3$ | $X = 1$ |

于是 $zero = \{1{:}1,\ 2{:}1,\ 4{:}1\}$，$cntT = \{3{:}2,\ 4{:}1\}$，后缀和得 $one[0..4] = 3,3,3,3,1$：

| $X$ | $one[X]$ | $zero[X]$ | $\text{cost} = 6 - one - zero$ |
|---|---|---|---|
| 0 | 3 | 0 | 3 |
| 1 | 3 | 1 | **2** |
| 2 | 3 | 1 | **2** |
| 3 | 3 | 0 | 3 |
| 4 | 1 | 1 | 4 |

最小值为 2，与示例输出一致。取 $X = 1$ 时逐对核对：$(1,3)$ 的 $T = 3 \ge 1$ 而 $d = 2 \ne 1$，代价 1（把 3 改成 2）；$(0,4)$ 的 $T = 4 \ge 1$ 而 $d = 4 \ne 1$，代价 1（把 0 改成 3）；$(1,2)$ 的 $d = 1 = X$，代价 0。合计 $1 + 1 + 0 = 2$。

## 4. 算法细节

1. **配对方式**：只处理 $i < n/2$，第 $i$ 对是 $(nums[i],\ nums[n-1-i])$，不重不漏。
2. **先排序两元素**：$a = \min$、$b = \max$，这样 $d = b - a \ge 0$ 且 $T = \max(k-a, b)$ 的推导成立。忘记排序会用到错误的 $T$。
3. **$T$ 的取值范围**：$b \le k$ 且 $k - a \le k$，故 $0 \le T \le k$，桶大小 $k+1$ 足够。
4. **$X$ 的范围**：由 $\lvert a' - b' \rvert \le k$（两数都在 $[0,k]$）知只需枚举 $X \in [0, k]$。
5. **后缀和的方向**：`for (X = k; X >= 0; --X) run += cntT[X]; one[X] = run;`，顺序不能反，否则得到的是前缀和（含义变成 $T \le X$，与需求相反）。
6. **答案初值**：取 $2m = n$（每对都改 2 次的代价），保证一定能被刷新；用 $k+1$ 个 $X$ 逐个更新。
7. **不需要离散化 $X$**：$k \le 10^5$，直接开 $k+1$ 的数组即可，$O(k)$ 空间可接受。
8. **代价 0 的对不会重复计数**：$zero$ 与 $one$ 统计的是"对数"而非"元素数"，公式里已经扣掉重叠部分。

## 5. 正确性证明

**引理 1（单对代价的闭式刻画）**：对一对 $(a, b)$（$a \le b$），记 $d = b-a$、$T = \max(k-a, b)$，则对任意 $X \in [0, k]$，把这对改成差值恰为 $X$ 的最少改动次数为

$$\text{cost}(X) = \begin{cases} 0, & X = d \\ 1, & X \ne d,\ X \le T \\ 2, & X > T \end{cases}$$

**证明**：

（1）$X = d$ 时无需改动，代价 0，且不可能更少。

（2）设 $X \ne d$ 且 $X \le T$。由 $T = \max(k-a,\ a,\ k-b,\ b)$（因为 $a \le b$ 时 $\max(k-a,a,k-b,b) = \max(k-a,b)$），至少有一个条件成立：

- $X \le k - a$：令 $b' = a + X \in [0, k]$，$a$ 不动，$\lvert a - b'\rvert = X$，改 1 个；
- $X \le a$：令 $b' = a - X \in [0, k]$，改 1 个；
- $X \le k - b$：令 $a' = b + X \in [0, k]$，改 1 个；
- $X \le b$：令 $a' = b - X \in [0, k]$，改 1 个。

故代价 $\le 1$；又 $X \ne d$ 说明原对不满足要求，必须至少改 1 个，故代价恰为 1。

（3）设 $X > T$。此时上述四个不等式全部不成立，即 $a + X > k$、$a - X < 0$、$b + X > k$、$b - X < 0$：只改一个元素无论怎么改都凑不出差值 $X$，故代价 $\ge 2$。另一方面 $X \le k$，取 $(a', b') = (0, X)$ 是合法赋值且差值恰为 $X$，代价 $\le 2$。故代价恰为 2。∎

**引理 2（总代价的桶公式）**：对任意 $X$，全部 $m$ 对的总代价为 $2m - one[X] - zero[X]$。

**证明**：把 $m$ 对按引理 1 分三类：代价 2 的有 $m - one[X]$ 对（即 $T < X$ 的对），代价 1 的有 $one[X] - zero[X]$ 对（$T \ge X$ 但 $d \ne X$），代价 0 的有 $zero[X]$ 对。三类不重不漏，故总代价

$$2(m - one[X]) + 1 \cdot (one[X] - zero[X]) + 0 \cdot zero[X] = 2m - one[X] - zero[X] \qquad \blacksquare$$

**定理**：算法返回的 $\min_{0 \le X \le k}\big(2m - one[X] - zero[X]\big)$ 就是最少改动次数。

**证明**：一方面，任何合法方案都必须选定某个 $X$（题面要求存在 $X$ 使所有对差值相同），且各对之间互不相交，总改动次数等于各对改动次数之和，故总次数不少于该 $X$ 下的最小总代价（引理 2）；对 $X$ 取最小即为全局下界。另一方面，对取得最小值的那个 $X$，按引理 1 的构造逐对取到最优（每个元素只属于一对，构造互不冲突），即可用该次数达成目标，故下界可达。所以最小值即为答案。∎

## 6. 复杂度分析

- **时间**：$O(n + k)$。配对并填两个桶 $O(n)$；后缀扫描 $O(k)$；枚举 $X$ 求最小 $O(k)$。总计 $O(n + k) \le 2 \times 10^5$ 级别。
- **空间**：$O(k)$。三个长度 $k+1$ 的整型数组（$zero$、$cntT$、$one$），约 $3 \times 10^5$ 个 `int`。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minChanges(vector<int>& nums, int k) {
        int n = nums.size(), m = n / 2;
        vector<int> zero(k + 1, 0);          // zero[X]：差值恰为 X 的对数（0 次改动）
        vector<int> cntT(k + 1, 0);          // cntT[T]：阈值为 T 的对数
        for (int i = 0; i < m; ++i) {
            int a = nums[i], b = nums[n - 1 - i];
            if (a > b) swap(a, b);           // 令 a <= b
            ++zero[b - a];
            ++cntT[max(k - a, b)];           // 该对“最多改 1 次”可实现的 X 上界
        }
        vector<int> one(k + 1, 0);           // one[X]：X <= T 的对数（最多改 1 次即可）
        int run = 0;
        for (int X = k; X >= 0; --X) { run += cntT[X]; one[X] = run; }
        int ans = n;                          // 每对都改 2 次的上界
        for (int X = 0; X <= k; ++X)
            ans = min(ans, 2 * m - one[X] - zero[X]);
        return ans;
    }
};
```

### Python

```python
class Solution:
    def minChanges(self, nums: list[int], k: int) -> int:
        n, m = len(nums), len(nums) // 2
        zero = [0] * (k + 1)      # zero[X]：差值恰为 X 的对数
        cntT = [0] * (k + 1)      # cntT[T]：阈值为 T 的对数
        for i in range(m):
            a, b = nums[i], nums[n - 1 - i]
            if a > b:
                a, b = b, a
            zero[b - a] += 1
            cntT[max(k - a, b)] += 1          # “最多改 1 次”可实现的 X 上界
        one = [0] * (k + 1)                   # one[X]：X <= T 的对数
        run = 0
        for X in range(k, -1, -1):
            run += cntT[X]
            one[X] = run
        ans = n                                # 每对都改 2 次的上界
        for X in range(k + 1):
            ans = min(ans, 2 * m - one[X] - zero[X])
        return ans
```

> 💡 两份代码均通过官方示例（`2`、`2`）与 $n = 2$、$k = 0$ 等边界，并与"枚举 $X$、每对再枚举所有 $a', b' \in [0,k]$ 取最小"的暴力解在 400 组随机输入（$k \le 6$，$n \le 8$）上对拍一致（`mismatch = 0`）；$n = 10^5, k = 10^5$ 的极限输入耗时约 $0.11$ 秒。

## 8. 边界情况与易错点

1. **$k = 0$**：所有元素只能是 0，$X$ 只能为 0，答案 0。代码中桶大小 1，$T = \max(0-a, b) = 0$，逻辑自洽。
2. **$n = 2$**：只有一对，取 $X = d$ 即可，答案 0。公式验证：$X = d$ 时 $one[d] \ge 1$（因 $T \ge d$）、$zero[d] = 1$，$\text{cost} = 2 - 1 - 1 = 0$。
3. **全相同数组**：所有对 $d = 0$，取 $X = 0$ 时 $one[0] = m$、$zero[0] = m$，$\text{cost} = 2m - m - m = 0$。
4. **忘记排序 $a, b$**：若直接用原顺序，$T = \max(k-a, b)$ 可能偏小（当 $a > b$ 时把大值当成了 $a$），导致把某些"1 次可完成"的对误判为 2 次。
5. **$T$ 可能等于 $k$**：桶必须开到 $k+1$，否则越界。例如 $a = 0, b = k$ 时 $T = k$。
6. **后缀和写反**：若写成前缀累加，$one[X]$ 会变成"$T \le X$ 的对数"，含义完全相反，答案偏大。
7. **代价 0 的对被算两次**：公式 $2m - one - zero$ 中 $zero$ 是"从代价 1 里扣出来"的，别写成 $2m - one + zero$。
8. **$X$ 的枚举上界**：不要枚举到 $2k$ 或 $n$，$X \le k$ 是由元素取值范围决定的硬上界。
9. **数据范围与溢出**：答案不超过 $n \le 10^5$，`int` 足够；但中间量 $2m$ 也别用 `char`、`short` 之类的窄类型。
