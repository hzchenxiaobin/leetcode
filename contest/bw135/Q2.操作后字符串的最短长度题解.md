# LeetCode 操作后字符串的最短长度 题解

## 1. 题目概述

- **标题 / 题号**：操作后字符串的最短长度（#3223，medium）
- **链接**：https://leetcode.cn/problems/minimum-length-of-string-after-operations/
- **来源**：LeetCode 第 135 场双周赛 Q2
- **难度**：中等
- **标签**：哈希表、字符串、计数

**题意**：给定字符串 $s$，可以反复执行如下操作：选一个下标 $i$，要求 $s[i]$ 的**左边和右边都至少有一个字符与它相同**；然后删除 $i$ 左侧最近的同字符、以及 $i$ 右侧最近的同字符（$i$ 本身保留）。操作可以进行任意次，求操作后字符串的**最短长度**。

一句话概括：每次操作相当于"从某个字母的出现序列里，挖掉夹在中间的一个字母的左右邻居"，因此**每个字母各减 2**，别的字母毫发无损。答案只与各字母出现次数有关，与顺序无关。

**约束**：

- $1 \le s.length \le 2 \times 10^5$
- $s$ 仅由小写英文字母组成

$|s|$ 达到 $2 \times 10^5$，所以不能对字符串本身做模拟（每次删除都是 $O(n)$），必须把它化成 26 个计数的数学问题。

## 2. 示例

**示例 1**

```text
输入：s = "abaacbcbb"
输出：5
解释：先选下标 2（字符 a），删掉它左右最近的 a（下标 0 与 3），得 "bacbcbb"；
     再选下标 3（字符 b），删掉左右最近的 b，得 "acbcb"，长度 5。
```

**示例 2**

```text
输入：s = "aa"
输出：2
解释：每个字母只有 2 个，凑不出"左右都有同字符"的下标，无法操作。
```

**示例 3（补充）**

```text
输入：s = "aaaa"
输出：2
解释：选下标 1，删掉下标 0 与 2，剩下 "aa"，再无法操作。

输入：s = "abc"
输出：3
解释：三个字母各 1 个，无法操作。
```

## 3. 解题思路

### 3.1 暴力思路

直接按定义模拟需要"枚举所有可操作的下标 + 真的做删除"，每一步都是 $O(n)$ 的字符串拼接，最坏操作次数 $O(n)$，总复杂度 $O(n^2) = 4 \times 10^{10}$，必然超时。即便用链表做到 $O(n)$ 次删除，仍然要为"选哪个下标"做决策搜索（不同选择会导致后续可操作集合不同），状态空间不可控。

### 3.2 核心观察：只有频次重要

![一次操作删掉左右最近的同字母各一个](images/bw135_q2_delete_op.svg)

盯住某一个字母 $c$，设它在当前串中出现 $k$ 次，出现位置为 $p_1 < p_2 < \dots < p_k$。

- 一次合法操作若选了某个 $i$（$s[i] = c$），删掉的是 $i$ 左右最近的 $c$。若 $i = p_t$（$2 \le t \le k-1$），删掉的正是 $p_{t-1}$ 与 $p_{t+1}$，于是 $c$ 的计数**恰好减 2**，其余字母计数不变。
- 反过来，只要 $k \ge 3$，取 $i = p_2$ 就一定有"左侧最近的 $c$（$p_1$）"和"右侧最近的 $c$（$p_3$）"，操作合法。

所以：**$k \ge 3$ 时总能继续减 2；$k \le 2$ 时这个字母再也动不了。** 而且每次只减 2，说明 $k$ 的**奇偶性是不变量**。

于是每个字母的终态被完全锁定：

| 初始计数 $k$ | 能减到 | 说明 |
|---|---|---|
| $k = 0$ | 0 | 不出现，不贡献 |
| $k = 1$ | 1 | 无法操作 |
| $k = 2$ | 2 | 无法操作 |
| $k \ge 3$ 且 $k$ 为奇 | 1 | 减到 1 停住（$k=3$ 时减一次） |
| $k \ge 3$ 且 $k$ 为偶 | 2 | 减到 2 停住（$k=4$ 时减一次） |

### 3.3 算法流程

![频次模型：每个字母独立减少到余数 1 或 2](images/bw135_q2_reduce_model.svg)

```text
1. 统计 26 个字母的出现次数 cnt[c]
2. ans = 0
3. 对每个 cnt[c] > 0：
       cnt[c] < 3  → ans += cnt[c]
       cnt[c] >= 3 → ans += (cnt[c] 为偶 ? 2 : 1)
4. 返回 ans
```

更进一步，三个分支可以压成一个式子：记 $f(k) = \min(k,\ 2 - (k \bmod 2))$，则答案是 $\sum_c f(k_c)$。逐项验证：$f(0)=0$、$f(1)=1$、$f(2)=2$、$f(3)=1$、$f(4)=2$、$f(5)=1$，与上表完全吻合。

### 3.4 示例演算

![示例演算：s = "abaacbcbb"，答案 5](images/bw135_q2_example_walkthrough.svg)

$s = \text{"abaacbcbb"}$ 的计数为 $a{:}3,\ b{:}4,\ c{:}2$：

| 字母 | 计数 | 处理 | 留下 |
|---|---|---|---|
| a | 3 | $3 \to 1$（删 1 次，每次 2 个） | 1 |
| b | 4 | $4 \to 2$（删 1 次） | 2 |
| c | 2 | 不足 3 个，无法操作 | 2 |

总长 $1 + 2 + 2 = 5$，与示例输出一致。

## 4. 算法细节

1. **只需 26 个计数器**：用 `int cnt[26]`（C++）或 `collections.Counter`（Python），一次遍历 $O(n)$。
2. **答案范围**：每个字母最多留 2 个，答案不超过 $\min(|s|, 52)$；但注意 $|s| \le 2$ 时直接就是 $|s|$，所以用 `int` 足矣。
3. **不要真的构造字符串**：题目只问长度，各字母彼此独立，构造会平白引入 $O(n)$ 内存和大量拼接开销。
4. **`k >= 3` 的写法**：`k % 2 == 0 ? 2 : 1` 可以合并成 `1 + (k % 2 == 0)`；也可以写成 `2 - k % 2`，含义是"偶留 2、奇留 1"。
5. **紧凑公式的适用范围**：$f(k) = \min(k, 2 - (k \bmod 2))$ 对 $k = 0,1,2$ 也成立，因此不必特判 $k < 3$；但用 `min` 容易让人误读成"简单截断"，复盘时保留显式三分支写法可读性更好。
6. **顺序无关性**：因为"$k \ge 3$ 就一定能操作"，任何排列下都能把每个字母独立压到终态，所以不需要考虑字母之间的相对位置。

## 5. 正确性证明

先明确一个记号：对字母 $c$，记当前串中 $c$ 的出现位置为 $p_1 < \dots < p_k$。

**引理 1（操作只改变一个字母，且恰好减 2）**：任取一次合法操作，设被选下标处的字符为 $c$、操作前 $c$ 出现 $k$ 次，则操作后 $c$ 出现 $k - 2$ 次，其它字母的出现次数不变。

**证明**：被选下标 $i$ 满足左右各至少有一个 $c$，设其左侧最近的 $c$ 在位置 $L$、右侧最近的 $c$ 在位置 $R$。删除的正是位置 $L$ 与 $R$ 上的两个字符，它们都是 $c$；$i$ 与其它字符不动。故 $c$ 减少 2 个，其余字母不变。∎

**引理 2（可操作性判据）**：当前串中字母 $c$ 存在合法下标（即某个 $c$ 的左右都有 $c$）当且仅当 $c$ 的出现次数 $k \ge 3$。

**证明**：若 $k \ge 3$，取 $i = p_2$，其左侧有 $p_1$、右侧有 $p_3$，合法。若 $k \le 2$ 且 $k \ge 1$：$k = 1$ 时该字符左右都没有 $c$；$k = 2$ 时两个 $c$ 互为左右邻居，任选其一，另一侧没有 $c$。两者都不合法。∎

**引理 3（终态刻画）**：任何无法继续操作的串，每个字母出现次数都 $\le 2$。

**证明**：若某字母出现 $\ge 3$ 次，由引理 2 存在合法操作，与"无法继续"矛盾。∎

**定理**：记各字母的初始计数为 $k_c$，则最短长度为

$$\sum_{c} \begin{cases} k_c, & k_c < 3 \\ 1, & k_c \ge 3 \text{ 且 } k_c \text{ 为奇} \\ 2, & k_c \ge 3 \text{ 且 } k_c \text{ 为偶} \end{cases}$$

**证明**：分两部分。

*可达性（上界）*：由引理 2，只要 $k_c \ge 3$ 就能再操作一次，由引理 1 每次把 $k_c$ 减 2。反复操作直到 $k_c \le 2$（奇数的减到 1，偶数的减到 2），对每个字母依次处理即可达到公式给出的长度；各字母的操作互不干扰（引理 1 保证只动被选字母），因此可以逐个压到底。

*最优性（下界）*：由引理 1，每个字母的计数只减 2，故其**奇偶性是不变量**；由引理 3，终态每个字母至多 2 个。于是对单个字母 $c$：$k_c$ 为奇数时终态只能是 $1$（不能是 0，更不能是 $\ge 3$）；$k_c$ 为偶数时终态只能是 $0$ 或 $2$。而 $k_c = 2$ 时无法再减（引理 2），$k_c = 0$ 自然保持 0，故偶数且非零时终态为 2。$k_c < 3$ 时本就不能操作，保持原值。下界与公式相等。∎

## 6. 复杂度分析

- **时间**：$O(n + 26)$，其中 $n = |s|$。一次遍历统计频次，再一次遍历 26 个字母累加。
- **空间**：$O(1)$（严格说是 $O(|\Sigma|) = O(26)$）。只需固定大小的计数数组，与 $n$ 无关。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minimumLength(string s) {
        int cnt[26] = {0};
        for (char c : s) ++cnt[c - 'a'];
        int ans = 0;
        for (int i = 0; i < 26; ++i) {
            if (cnt[i] == 0) continue;
            if (cnt[i] < 3) ans += cnt[i];              // 不足 3 个，无法操作
            else ans += (cnt[i] % 2 == 0 ? 2 : 1);      // 减到余数 1 或 2
        }
        return ans;
    }
};
```

### Python

```python
from collections import Counter

class Solution:
    def minimumLength(self, s: str) -> int:
        ans = 0
        for c in Counter(s).values():
            if c < 3:
                ans += c                       # 不足 3 个，无法操作
            else:
                ans += 2 if c % 2 == 0 else 1  # 减到余数 1 或 2
        return ans
```

> 💡 两份代码均通过官方示例（`5`、`2`）与 $|s| = 1$、全同字符等边界，并与"按定义 BFS 枚举所有可达字符串、取最小长度"的暴力解在 400 组随机串（长度 $\le 8$，字母表 2~3 个）上对拍一致（`mismatch = 0`）；$|s| = 2 \times 10^5$ 的极限输入耗时约 $0.02$ 秒。

## 8. 边界情况与易错点

1. **$|s| = 1$**：无法操作，答案 1。代码里 `cnt[c] = 1 < 3` 走第一分支，正确。
2. **两个同字母 `"aa"`**：答案 2，不是 0。$k = 2$ 时"没有夹在中间的同字母"，无法删除（这条最容易错写成 $k \bmod 2$）。
3. **三个同字母 `"aaa"`**：答案 1（删掉首尾两个）。若误以为"必须至少 4 个"会算成 3。
4. **全同字符 `"a" * 200000`**：偶数，答案 2，不是 0。
5. **不要尝试按字符位置模拟删除**：删除会改变下标，容易写出越界或死循环；本题的性质保证完全不需要这样做。
6. **`ans` 的初值与类型**：C++ 用 `int` 足够（$\le 2\times10^5$）；Python 无需担心。
7. **字符统计的下标**：`c - 'a'` 前要确认只含小写字母（题面已保证），否则会越界。
