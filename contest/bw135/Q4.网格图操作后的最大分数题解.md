# LeetCode 网格图操作后的最大分数 题解

## 1. 题目概述

- **标题 / 题号**：网格图操作后的最大分数（#3225，hard）
- **链接**：https://leetcode.cn/problems/maximum-score-from-grid-operations/
- **来源**：LeetCode 第 135 场双周赛 Q4
- **难度**：困难
- **标签**：数组、动态规划、矩阵、前缀和

**题意**：给定 $n \times n$ 的矩阵 $grid$，初始全白。一次操作：选格子 $(i, j)$，把**第 $j$ 列从第 $0$ 行到第 $i$ 行**全部染黑。操作可执行任意次（含 0 次）。最终得分为所有满足下面条件的**白格**的 $grid[i][j]$ 之和：

> 格子 $(i,j)$ 是白的，且它**左边或右边的相邻格子至少有一个是黑的**。

求最大总得分。注意"左边/右边"只指同一行相邻的两列 $(i,j-1)$ 与 $(i,j+1)$，不含斜向。

**约束**：

- $1 \le n = grid.length \le 100$
- $grid[i].length = n$
- $0 \le grid[i][j] \le 10^9$

$n \le 100$ 说明可以承受 $O(n^3)$（$10^6$）甚至 $O(n^4)$（$10^8$，但 Python 会吃力）；单格最大 $10^9$，答案最大 $100 \times 100 \times 10^9 = 10^{13}$，**必须用 64 位整数**。

## 2. 示例

**示例 1**

```text
输入：grid = [[0,0,0,0,0],[0,0,3,0,0],[0,1,0,0,0],[5,0,0,3,0],[0,0,0,0,2]]
输出：11
解释：把第 1 列染到第 3 行（h₁ = 4）、第 4 列染到第 4 行（h₄ = 5），
      得分的白格是 grid[3][0] + grid[1][2] + grid[3][3] = 5 + 3 + 3 = 11。
```

**示例 2**

```text
输入：grid = [[10,9,0,0,15],[7,1,0,8,0],[5,20,0,11,0],[0,0,0,1,2],[8,12,1,10,3]]
输出：94
解释：把第 1、2、3 列分别染到第 1、4、0 行，即高度向量 h = [0, 2, 5, 1, 0]，
      得分白格为 (0,0)、(1,0)、(2,1)、(4,1)、(1,3)、(2,3)、(3,3)、(4,3)、(0,4)，
      总和 10 + 7 + 20 + 12 + 8 + 11 + 1 + 10 + 15 = 94。
```

**示例 3（边界补充）**

```text
输入：grid = [[5]]
输出：0
解释：只有一列，没有左右相邻的列，任何白格都不会被打分。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的想法是搜索"操作序列"。但每次操作有 $n^2$ 种选择、可执行任意次，状态空间爆炸。退一步注意到**同一列多次操作等价于一次**（取最大的那个 $i$），于是每列最终只有 $n+1$ 种形态，总状态数 $(n+1)^n$——$n = 100$ 时是天文数字。所以必须靠 DP。

### 3.2 核心观察：用"列高度"刻画状态，得分按列分解

![每列的黑色格子必是顶部前缀，用一个高度 h 描述](images/bw135_q4_column_height.svg)

**第一步：把操作序列压缩成高度向量。** 一次操作染黑的是第 $j$ 列的一个"顶部前缀"。同列多次操作取并集后仍是前缀（取最大的 $i$），不同列互不影响。所以任何操作结果的等价描述是：每列有一个高度 $h_j \in [0, n]$，第 $j$ 列的第 $0 \sim h_j - 1$ 行是黑的，其余行是白的。反之任意高度向量都可达（对 $h_j > 0$ 的列执行一次"染到第 $h_j - 1$ 行"）。

**第二步：把得分改写为按列的求和。** 第 $j$ 列的白格是行 $i \ge h_j$ 的格子；它被打分当且仅当 $i < h_{j-1}$ 或 $i < h_{j+1}$，即

$$i < \max(h_{j-1},\ h_{j+1})$$

（网格外的邻居视为高度 $0$，即 $h_{-1} = h_n = 0$）。于是第 $j$ 列的贡献是

$$f_j = \sum_{i = h_j}^{\max(h_{j-1}, h_{j+1}) - 1} grid[i][j]$$

区间为空时（$\max \le h_j$）贡献为 0。记第 $j$ 列的前缀和 $P_j(t) = \sum_{i < t} grid[i][j]$，则

$$f_j = \max\Bigl(0,\ P_j\bigl(\max(h_{j-1}, h_{j+1})\bigr) - P_j(h_j)\Bigr)$$

![单列贡献：只被更高的那个邻居限制](images/bw135_q4_score_formula.svg)

记 $g_j(x) = \max\bigl(0,\ P_j(x) - P_j(h_j)\bigr)$，则 $f_j = g_j\bigl(\max(h_{j-1}, h_{j+1})\bigr)$——**列 $j$ 的贡献只取决于三个相邻高度**。这是能做 DP 的根本原因。

### 3.3 算法流程：从 $O(n^4)$ 到 $O(n^3)$

![DP 转移：把 max 拆成两种情形，用前缀/后缀最大值加速](images/bw135_q4_dp_transition.svg)

从左到右逐列决策高度。选完 $h_j$ 时，列 $j-1$ 的贡献 $f_{j-1} = g_{j-1}(\max(h_{j-2}, h_j))$ 就可以定稿了（它需要的三个高度都已知）。因此状态取

$$dp\bigl[h_{j-1}\bigr]\bigl[h_j\bigr] = \text{已定稿列 } 0..j-1 \text{ 的贡献之和的最大值}$$

朴素转移枚举 $h_{j+1}$：

$$dp'\bigl[h_j\bigr]\bigl[h_{j+1}\bigr] = \max_{h_{j-1}} \Bigl( dp\bigl[h_{j-1}\bigr]\bigl[h_j\bigr] + g_j\bigl(\max(h_{j-1}, h_{j+1})\bigr) \Bigr)$$

状态数 $O(n^2)$、转移 $O(n)$、共 $n$ 列 ⇒ $O(n^4) = 10^8$。用"拆分 $\max$"把它降到 $O(n^3)$：

- **情形 A：$h_{j+1} \le h_{j-1}$**，此时 $\max = h_{j-1}$，增量 $g_j(h_{j-1})$ **与 $h_{j+1}$ 无关**。对每个固定的 $h_j$，对 $h_{j-1}$ 做后缀最大：

$$suf[x] = \max_{h_{j-1} \ge x}\Bigl( dp\bigl[h_{j-1}\bigr]\bigl[h_j\bigr] + g_j(h_{j-1}) \Bigr)$$

- **情形 B：$h_{j+1} > h_{j-1}$**，此时 $\max = h_{j+1}$，增量 $g_j(h_{j+1})$ **与 $h_{j-1}$ 无关**。对每个固定的 $h_j$，对 $h_{j-1}$ 做前缀最大：

$$pre[x] = \max_{h_{j-1} \le x} dp\bigl[h_{j-1}\bigr]\bigl[h_j\bigr]$$

两者合并：

$$dp'\bigl[h_j\bigr]\bigl[h_{j+1}\bigr] = \max\Bigl( suf\bigl[h_{j+1}\bigr],\ pre\bigl[h_{j+1}-1\bigr] + g_j(h_{j+1}) \Bigr)$$

每个 $h_j$ 只需 $O(n)$ 扫描两次，故每列 $O(n^2)$、总计 $O(n^3)$。

**边界处理**：

- 初始化 $h_{-1} = 0$：`dp[0][h_0] = 0`（对任意 $h_0$ 都合法，因为左边界外没有黑格）。
- 收尾 $h_n = 0$：枚举末状态 $(h_{n-2}, h_{n-1})$ 后，补上最后一列的

$$f_{n-1} = g_{n-1}(h_{n-2}) = \max\Bigl(0,\ P_{n-1}(h_{n-2}) - P_{n-1}(h_{n-1})\Bigr)$$

取全局最大即为答案。

### 3.4 示例演算

**示例 1**：取 $h = [0, 4, 0, 0, 5]$，逐列算贡献（网格外邻居高度为 0）：

| 列 $j$ | $h_j$ | $\max(h_{j-1}, h_{j+1})$ | 计分行区间 | 贡献 |
|---|---|---|---|---|
| 0 | 0 | $\max(0, 4) = 4$ | $[0, 3]$ | $0+0+0+5 = 5$ |
| 1 | 4 | $\max(0, 0) = 0$ | 空 | 0 |
| 2 | 0 | $\max(4, 0) = 4$ | $[0, 3]$ | $0+3+0+0 = 3$ |
| 3 | 0 | $\max(0, 5) = 5$ | $[0, 4]$ | $0+0+0+3+0 = 3$ |
| 4 | 5 | $\max(0, 0) = 0$ | 空（全列已黑） | 0 |

合计 $5 + 3 + 3 = 11$，与示例输出一致（得分的正是 $grid[3][0], grid[1][2], grid[3][3]$）。

**示例 2**：取 $h = [0, 2, 5, 1, 0]$：

| 列 $j$ | $h_j$ | $\max(h_{j-1}, h_{j+1})$ | 计分行 | 贡献 |
|---|---|---|---|---|
| 0 | 0 | $\max(0, 2) = 2$ | $[0, 1]$ | $10 + 7 = 17$ |
| 1 | 2 | $\max(0, 5) = 5$ | $[2, 4]$ | $20 + 0 + 12 = 32$ |
| 2 | 5 | $\max(2, 1) = 2$ | 空（$2 \le 5$） | 0 |
| 3 | 1 | $\max(5, 0) = 5$ | $[1, 4]$ | $8 + 11 + 1 + 10 = 30$ |
| 4 | 0 | $\max(1, 0) = 1$ | $[0, 0]$ | $15$ |

合计 $17 + 32 + 0 + 30 + 15 = 94$。

> 💡 注意：这里的"局部最优"不能靠逐列贪心得到——把第 4 列从高度 0 抬到 1 会多染黑 $grid[0][4] = 15$ 这一格（它本可计分），白白损失 15 分。DP 通过"相邻三列一起看"避免了这类错误。

## 4. 算法细节

1. **前缀和方向**：$P_j(t) = \sum_{i < t} grid[i][j]$，维度是 $n+1$，$t \in [0, n]$；$P_j(0) = 0$。
2. **高度范围**：$h_j \in [0, n]$，状态表大小 $(n+1) \times (n+1)$。
3. **"负贡献"必须截断**：当 $\max(h_{j-1}, h_{j+1}) \le h_j$ 时 $P_j(\max) - P_j(h_j) \le 0$，含义是"没有任何白格可计分"，要取 0 而不是负值。代码里用 `max(0LL, ...)`。
4. **不可达状态**：用 `NEG = -(1LL << 60)` 标记，转移时跳过（或允许加法后仍是极小值，效果相同）。
5. **情形 A 的后缀数组长度是 $n+2$**：因为要访问 `suf[h_{j+1}]`，当 $h_{j+1} = n$ 时下标为 $n$，故多开一格。
6. **情形 B 的边界**：$h_{j+1} = 0$ 时 $pre[-1]$ 不存在（下标越界），此时只能走情形 A（因为 $0 \le h_{j-1}$ 恒成立），代码用 `hn > 0` 判断。
7. **最后一行/列的处理**：收尾时用 $h_n = 0$，只补一列，不要重复计算前面的列。
8. **`long long`**：前缀和单列最大 $10^{11}$，总和 $10^{13}$，`int` 会溢出。
9. **$n = 1$**：循环 `i < n - 1` 不执行，收尾时 $P_0(0) - P_0(h_0) \le 0$ 被截为 0，答案 0，正确。

## 5. 正确性证明

**引理 1（高度向量刻画）**：任一操作序列的结果都可唯一表示为高度向量 $(h_0, \dots, h_{n-1}) \in [0,n]^n$（第 $j$ 列黑格为第 $0 \sim h_j-1$ 行）；反之任一高度向量都可由操作实现。

**证明**：单次操作把第 $j$ 列的行区间 $[0, i]$ 染黑，是"顶部前缀"；同一列上多次操作的结果是这些前缀的并集，仍为 $[0, \max i]$ 形式，长度记作 $h_j$。不同列的操作作用在不同列上，互不干扰，故结果由 $(h_j)$ 完全决定。若某列从未被操作，则 $h_j = 0$，仍在 $[0,n]$ 中。反向：给定 $(h_j)$，对每个 $h_j > 0$ 的列 $j$ 执行一次以 $i = h_j - 1$ 为目标的操作，即得到该向量；$h_j = 0$ 的列不操作。∎

**引理 2（单列贡献公式）**：在上述记号下，最终列 $j$ 的得分贡献为

$$f_j = \max\Bigl(0,\ P_j\bigl(\max(h_{j-1}, h_{j+1})\bigr) - P_j(h_j)\Bigr)$$

其中 $h_{-1} = h_n = 0$。

**证明**：列 $j$ 的白格恰是行 $i \in [h_j, n-1]$。它被打分当且仅当同行的左邻 $(i, j-1)$ 或右邻 $(i, j+1)$ 为黑，即 $i < h_{j-1}$ 或 $i < h_{j+1}$，等价于 $i < m$，其中 $m = \max(h_{j-1}, h_{j+1})$。故计分集合为 $[h_j, n-1] \cap [0, m-1] = [h_j, m-1]$（$m \le n$）。若 $m \le h_j$ 则为空集，贡献 0；否则贡献 $\sum_{i=h_j}^{m-1} grid[i][j] = P_j(m) - P_j(h_j) > 0$。合并两情况即得公式（$\max(0,\cdot)$ 正好处理空集）。∎

**引理 3（DP 语义正确）**：设 $D_j(A, B)$ 表示"已确定 $h_0, \dots, h_j$，其中 $h_{j-1} = A$、$h_j = B$ 时 $\sum_{c=0}^{j-1} f_c$ 的最大值"，则初始化 $D_0(0, B) = 0$ 与转移式

$$D_{j+1}(B, C) = \max_{A} \Bigl( D_j(A, B) + g_j\bigl(\max(A, C)\bigr) \Bigr)$$

恰好枚举了所有高度向量的前缀，且不重不漏。

**证明**：对 $j$ 归纳。$j = 0$ 时前缀只有 $h_0$，$h_{-1}$ 固定为 0，尚无任何列被定稿，故 $D_0(0, B) = 0$ 对每个 $B$ 成立。归纳步：由引理 2，$f_j$ 只依赖 $(h_{j-1}, h_j, h_{j+1}) = (A, B, C)$，与更早的列无关；因此给定 $(A,B)$ 下所有历史的最优值 $D_j(A,B)$ 加上 $f_j$ 就是新状态的最优值，对 $A$ 取最大即覆盖全部历史。每个高度向量 $(h_0,\dots,h_{j+1})$ 唯一对应一条转移路径，故不重不漏。∎

**引理 4（加速等价）**：转移式的内层最大值可按 $C$ 与 $A$ 的大小关系拆开计算：

$$\max_{A}\Bigl(D_j(A,B) + g_j(\max(A,C))\Bigr) = \max\Bigl(\underbrace{\max_{A \ge C}\bigl(D_j(A,B) + g_j(A)\bigr)}_{suf[C]},\ \underbrace{\max_{A < C} D_j(A,B) + g_j(C)}_{pre[C-1] + g_j(C)}\Bigr)$$

**证明**：对任意 $A$，若 $A \ge C$ 则 $\max(A,C) = A$，增量只与 $A$ 有关；若 $A < C$ 则 $\max(A,C) = C$，增量只与 $C$ 有关。两种情形互斥且穷尽所有 $A$，故原最大值等于两个子最大值中的较大者。$suf$ 是后缀最大、$pre$ 是前缀最大，均可 $O(n)$ 预处理。∎

**定理**：算法返回值为最大总得分。

**证明**：由引理 1，任何操作方案都等价于某个高度向量；由引理 2，其总得分为 $\sum_j f_j$；由引理 3、4，DP 在所有高度向量上精确地求出了 $\sum_j f_j$ 的最大值（初始状态与收尾分别正确处理了 $h_{-1} = h_n = 0$）；故返回值等于 $\max_{(h_j)} \sum_j f_j$，即最大总得分。又由引理 1 的可达性，该上界可由实际操作实现。∎

## 6. 复杂度分析

- **时间**：$O(n^3)$。外层 $n-1$ 列，每列对每个 $h_j$（$n+1$ 种）做两次 $O(n)$ 扫描并填 $O(n)$ 个新状态，共约 $(n-1)(n+1) \cdot 3(n+1) \approx 3 \times 10^6$ 次基本运算（$n = 100$）。收尾枚举 $O(n^2)$。
- **空间**：$O(n^2)$。前缀和 $P$ 为 $n \times (n+1)$；两个 DP 表各 $(n+1)^2$；每列临时数组 $O(n)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long maximumScore(vector<vector<int>>& grid) {
        int n = grid.size();
        vector<vector<long long>> P(n, vector<long long>(n + 1, 0));
        for (int c = 0; c < n; ++c)
            for (int t = 1; t <= n; ++t)
                P[c][t] = P[c][t - 1] + grid[t - 1][c];
        const long long NEG = -(1LL << 60);
        int H = n;                       // 高度取值 0..n
        vector<vector<long long>> dp(H + 1, vector<long long>(H + 1, NEG));
        for (int h = 0; h <= H; ++h) dp[0][h] = 0;   // 状态 (h_{-1}=0, h_0)
        for (int i = 0; i < n - 1; ++i) {
            vector<vector<long long>> ndp(H + 1, vector<long long>(H + 1, NEG));
            for (int hi = 0; hi <= H; ++hi) {
                vector<long long> suf(H + 2, NEG), pre(H + 1, NEG);
                for (int hl = H; hl >= 0; --hl) {
                    long long g = max(0LL, P[i][hl] - P[i][hi]);
                    long long v = (dp[hl][hi] <= NEG / 2) ? NEG : dp[hl][hi] + g;
                    suf[hl] = max(suf[hl + 1], v);
                }
                long long run = NEG;
                for (int hl = 0; hl <= H; ++hl) {
                    run = max(run, dp[hl][hi]);
                    pre[hl] = run;
                }
                for (int hn = 0; hn <= H; ++hn) {
                    long long best = suf[hn];                   // 情形 hn <= hl
                    if (hn > 0 && pre[hn - 1] > NEG / 2) {
                        long long g = max(0LL, P[i][hn] - P[i][hi]);
                        best = max(best, pre[hn - 1] + g);      // 情形 hn > hl
                    }
                    ndp[hi][hn] = best;
                }
            }
            dp.swap(ndp);
        }
        long long ans = 0;
        for (int a = 0; a <= H; ++a)          // a = h_{n-2}
            for (int b = 0; b <= H; ++b) {    // b = h_{n-1}
                if (dp[a][b] <= NEG / 2) continue;
                long long g = max(0LL, P[n - 1][a] - P[n - 1][b]);
                ans = max(ans, dp[a][b] + g);
            }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maximumScore(self, grid: list[list[int]]) -> int:
        n = len(grid)
        P = [[0] * (n + 1) for _ in range(n)]
        for c in range(n):
            for t in range(1, n + 1):
                P[c][t] = P[c][t - 1] + grid[t - 1][c]
        NEG = -(1 << 60)
        H = n
        dp = [[NEG] * (H + 1) for _ in range(H + 1)]
        for h in range(H + 1):
            dp[0][h] = 0                       # 状态 (h_{-1}=0, h_0)
        for i in range(n - 1):
            ndp = [[NEG] * (H + 1) for _ in range(H + 1)]
            Pi = P[i]
            for hi in range(H + 1):
                base = Pi[hi]
                g = [Pi[x] - base for x in range(H + 1)]
                for x in range(H + 1):
                    if g[x] < 0:
                        g[x] = 0
                col = [dp[hl][hi] for hl in range(H + 1)]
                suf = [NEG] * (H + 2)
                for hl in range(H, -1, -1):
                    v = NEG if col[hl] <= NEG // 2 else col[hl] + g[hl]
                    suf[hl] = v if v > suf[hl + 1] else suf[hl + 1]
                pre = [NEG] * (H + 1)
                run = NEG
                for hl in range(H + 1):
                    if col[hl] > run:
                        run = col[hl]
                    pre[hl] = run
                row = ndp[hi]
                for hn in range(H + 1):
                    best = suf[hn]                            # 情形 hn <= hl
                    if hn > 0 and pre[hn - 1] > NEG // 2:
                        cand = pre[hn - 1] + g[hn]            # 情形 hn > hl
                        if cand > best:
                            best = cand
                    row[hn] = best
            dp = ndp
        ans = 0
        Pn = P[n - 1]
        for a in range(H + 1):
            for b in range(H + 1):
                if dp[a][b] <= NEG // 2:
                    continue
                g = Pn[a] - Pn[b]
                if g < 0:
                    g = 0
                if dp[a][b] + g > ans:
                    ans = dp[a][b] + g
        return ans
```

> 💡 两份代码均通过官方示例（`11`、`94`）与 $n = 1$ 边界，并与"枚举 $(n+1)^n$ 个高度向量、直接按题面规则逐格统计"的暴力解在 300 组随机小网格（$n \le 4$，含大量 0）上对拍一致（`mismatch = 0`）；$n = 100$ 的随机极限输入 C++ 约 $0.02$ 秒、Python 约 $0.47$ 秒。

## 8. 边界情况与易错点

1. **$n = 1$**：没有左右邻居，任何白格都不得分，答案 0。代码自然满足（见 §4 第 9 点）。
2. **全 0 网格**：答案 0；注意不要把 `NEG` 误当成答案（初始 `ans = 0`）。
3. **`max` 截断**：忘记 `max(0, ...)` 会把"空区间"算成负贡献，DP 可能选出更差的结果，答案偏小。
4. **`int` 溢出**：$P_j(n)$ 可达 $10^{11}$，总和 $10^{13}$，必须 `long long` / Python 原生大整数。
5. **相邻只算左右**：对角格子不算邻居，若误把"上下左右"都算上会得到完全错误的答案。
6. **黑格自身不计分**：得分只统计**白**格，被染黑的格子不贡献（无论值多大）。
7. **越界邻居视为高度 0**：第 0 列没有左邻、第 $n-1$ 列没有右邻，等价于 $h_{-1} = h_n = 0$；若把越界当成 $n$ 会让整列都"被邻居照亮"，答案严重偏大。
8. **收尾只补最后一列**：末状态已经包含了前 $n-1$ 列的贡献，收尾再加一次前面的列会重复计数。
9. **后缀数组长度**：`suf` 需要 $n+2$ 个位置，否则 $h_{j+1} = n$ 时越界。
10. **一列可以完全不染**（$h_j = 0$），这往往是最优解的一部分（示例 2 的第 0、4 列），不要默认每列都染。

**延伸思考**：如果操作改成"染黑以 $(i,j)$ 为角的一个矩形"，列高度模型立刻失效，需要换成"阶梯形"状态，复杂度会上升。如果邻接关系改成"上下左右四个方向任意一个黑"，则列的贡献不再能只依赖相邻三列，而要按行重新建模。另一个方向是：本题的"$O(n^4) \to O(n^3)$"用的是"把依赖同一个变量的 $\max$ 提前预处理成前缀/后缀最值"，这个套路在"分段 DP + 分段长度代价"的题里反复出现（如石子合并的 Knuth 优化、$k$ 段划分的凸优化）。
