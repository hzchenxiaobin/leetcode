# LeetCode 森林中的兔子 题解

## 1. 题目概述

- **标题 / 题号**：森林中的兔子（#781，medium）
- **链接**：https://leetcode.cn/problems/rabbits-in-forest/
- **来源**：LeetCode 第 71 场周赛 Q2
- **难度**：中等
- **标签**：贪心、数组、哈希表、数学

**题意**：森林里兔子总数未知，我们只问到了其中 $n$ 只：对第 $i$ 只问「**还有多少只其它兔子与你颜色相同**」，它回答 $answers[i]$。回答诚实地反映了它所在颜色类的规模，但森林里还有大量兔子没被问到。求森林中兔子数量的**最小值**。

关键点在于：一只兔子的回答 $x$ 并不代表只有 $x+1$ 只兔子，而是代表**它所在的那个颜色类恰有 $x+1$ 只兔子**——剩下的同伴可能一句都没说。我们要用最少的总数去「凑」出这一堆自洽的颜色类。

**约束**：

- $1 \le n \le 1000$
- $0 \le answers[i] \le 999$
- 未被询问的兔子不产生任何回答，但必须计入总数

## 2. 示例

**示例 1**

```text
输入：answers = [1,1,2]
输出：5
解释：两只回答 1 的兔子可以同色（红色），该颜色共 2 只；
      回答 2 的兔子不能是红色，否则组大小矛盾，设为蓝色，则该组共 3 只；
      蓝色组里另外 2 只没被问到。
      最少总数 = 3 只受访 + 2 只未受访 = 5。
```

**示例 2**

```text
输入：answers = [10,10,10]
输出：11
解释：三只回答 10 的兔子同属一个颜色类（该类恰有 11 只），
      另 8 只同色兔子没被问到；总数 11，而不是 3 或 33。
```

**补充示例（自测，非官方）**

```text
输入：answers = [0,0,0,1,1,1,1]
输出：7
解释：回答 0 的三只兔子互不同色，各自单独成组 → 3 只；
      回答 1 的四只兔子两两成组 → 2 组 × 2 只 = 4 只；
      合计 3 + 4 = 7。
```

> 💡 三个例子分别覆盖了「同一回答值被多组容纳且末组不满」「组容量远大于出现次数」「$x=0$ 时容量为 1」三种形态。

## 3. 解题思路

### 3.1 暴力思路

把题目直译成搜索：每只兔子必须落进一个大小恰为 $answers[i]+1$ 的颜色类，于是可以**枚举 $n$ 只兔子的集合划分**，对每种划分检查「同一块内回答值全部相同且块大小 $\le x+1$」，再按每块补满 $x+1$ 计总数取最小。

这个枚举是精确的（我在验证阶段就用它做随机对拍，$n \le 8$ 时完全够用），但集合划分的数量是 Bell 数：$\mathrm{Bell}(8) = 4140$ 尚可，$\mathrm{Bell}(n)$ 随 $n$ 指数爆炸，$n = 1000$ 时是天方夜谭。另一条朴素路线「枚举森林总数 $M$ 再检验可行性」同样要反复做分组搜索，$M$ 的上界可达 $5\times 10^{5}$，也不可行。

必须找到**结构性的分解**，让每个回答值独立结算。

### 3.2 核心观察：同色组的大小被回答值钉死

![同色组容量模型](images/wc71_q2_group_capacity.svg)

三句话就能把结构说完：

1. **组的规模是确定的**。若兔子 $r$ 回答 $x$，则 $r$ 所在颜色类恰有 $x+1$ 只（$r$ 自己 + $x$ 只同色同伴），与是否被问到无关。
2. **组内回答值一致**。同一颜色类大小唯一，故该类中凡被问到的兔子，回答都是 $x$；反过来，回答 $x$ 的兔子与回答 $y \ne x$ 的兔子**绝不可能同色**。
3. **组内回答 $x$ 的兔子至多 $x+1$ 只**。整组才 $x+1$ 只，被问到的当然不超过它。

于是问题被彻底拆开：回答 $x$ 的 $c$ 只兔子，每 $x+1$ 只塞进一个颜色类，塞不下就再开新类。第 $k$ 个类里即便只坐了 1 只，也**照样要按 $x+1$ 只**计入总数（空位由没被问到的同色兔子补齐）。

设

$$k_x = \left\lceil \frac{c_x}{x+1} \right\rceil$$

则答案为

$$\text{ans} = \sum_{x} k_x \cdot (x+1)$$

不同 $x$ 的颜色类互不相同，所以各桶之间没有任何耦合——这正是贪心可行的原因。

### 3.3 算法流程

![计数与上取整流程](images/wc71_q2_counting_flow.svg)

1. **计数**：扫一遍 $answers$，得到 $c_x$（回答 $x$ 的兔子数）。值域只有 $[0, 999]$，用长度 1000 的数组即可，$O(n + 1000)$。
2. **逐桶结算**：对每个 $c_x > 0$ 的 $x$，令容量 $g = x+1$，组数 $k_x = \lceil c_x / g \rceil$。
3. **整数上取整**：$k_x = \lfloor (c_x + g - 1) / g \rfloor$，全程整数，不引入浮点误差。
4. **累加**：$\text{ans} \mathrel{+}= k_x \cdot g$，最后返回 $\text{ans}$。

伪代码（$d$ 为不同回答值个数）：

```text
cnt ← 统计 answers 的频次
ans ← 0
for x, c in cnt:
    g ← x + 1
    ans ← ans + ((c + g - 1) // g) * g
return ans
```

### 3.4 示例演算

![示例演算表](images/wc71_q2_walkthrough.svg)

**示例 1**：`answers = [1,1,2]`。

| 回答 $x$ | 次数 $c$ | 容量 $g = x+1$ | 组数 $k = \lceil c/g \rceil$ | 贡献 $k \cdot g$ |
|----------|----------|----------------|------------------------------|------------------|
| 1 | 2 | 2 | $2/2 \to 1$ | 2 |
| 2 | 1 | 3 | $1/3 \to 1$ | 3 |
| 合计 | | | | **5** |

**示例 2**：`answers = [10,10,10]`。只有一个桶：$c = 3$，$g = 11$，$k = \lceil 3/11 \rceil = 1$，贡献 $1 \times 11 = 11$。**注意 $k$ 是 1 而不是 3**：三只回答 10 的兔子属于同一个 11 只的组。

**补充示例**：`answers = [0,0,0,1,1,1,1]`。$x = 0$ 时 $g = 1$，$c = 3$，$k = 3$，贡献 3；$x = 1$ 时 $g = 2$，$c = 4$，$k = 2$，贡献 4；合计 7。

## 4. 算法细节

1. **计数结构的选择**：值域固定为 $0 \sim 999$，C++ 用 `int cnt[1000]` 比 `unordered_map` 更快也更省；若题目值域变大或不确定，用哈希表更稳。Python 直接 `Counter(answers)`。
2. **上取整必须用整数式**：$k = (c + g - 1) / g$（整除）。写成 `c / g` 会下取整（$c=3, g=11$ 时得 0，直接错），写成 `math.ceil(c / g)` 则在 $c$ 很大时有浮点精度隐患。
3. **$x = 0$ 无需特判**：$g = 1$，$k = c$，每只回答 0 的兔子各自独占一个颜色类，公式自然正确；若特意写 `if x == 0: ans += c` 反而多一处易错分支。
4. **绝不跨回答值合并**：$x \ne y$ 的兔子不同色（组大小矛盾）。若错误地「把所有回答合并成 $x+1$ 个一桶」，`[1,1,2]` 会算成 3 而不是 5。
5. **绝不按 $c$ 而不是 $k \cdot g$ 累加**：末组不满也要补满。`[10,10,10]` 按 $c$ 累加得 3，正确答案是 11。
6. **答案上界**：$n \le 1000$ 且 $answers[i] \le 999$，最坏构造是 `answers = [0,1,2,...,999]`，答案为 $\sum_{x=0}^{999}(x+1) = 500500$，`int` 足够；但仍然建议留意「答案可以远大于 $n$」这个反直觉点。
7. **只遍历出现过的值**：数组全扫 1000 次、或只遍历 $d$ 个不同值都可以，两者都远低于 $10^{6}$ 次操作。

## 5. 正确性证明

**引理 1（组大小由回答决定）**：若兔子 $r$ 回答 $x$，则 $r$ 所在颜色类的兔子数恰为 $x+1$。

**证明**：题面定义了 $x$ 是「与 $r$ 颜色**相同**的**其它**兔子数」。设该颜色类共有 $S$ 只，则与 $r$ 同色的其它兔子恰有 $S-1$ 只，故 $S - 1 = x$，即 $S = x+1$。∎

**引理 2（同类必同答）**：同一颜色类中任意两只被问到的兔子回答值相同。

**证明**：设 $r_1, r_2$ 同色，分别回答 $x_1, x_2$。由引理 1，该颜色类大小同时等于 $x_1+1$ 与 $x_2+1$，故 $x_1 = x_2$。∎

**引理 3（单桶下界）**：对任意 $x$，$c_x$ 只回答 $x$ 的兔子至少占据 $\left\lceil c_x/(x+1) \right\rceil$ 个颜色类。

**证明**：由引理 2，这 $c_x$ 只兔子所在的颜色类中，凡被问到的都回答 $x$；而每个这样的类由引理 1 恰含 $x+1$ 只兔子，因此其中至多 $x+1$ 只回答 $x$ 的兔子。把 $c_x$ 只兔子放进若干个容量为 $x+1$ 的类，类数至少为 $\left\lceil c_x/(x+1)\right\rceil$。∎

**引理 4（全局下界）**：任何自洽的森林，兔子总数不少于 $\sum_{x} \left\lceil c_x/(x+1)\right\rceil (x+1)$。

**证明**：由引理 2，一个颜色类只可能盛放单一回答值的受访兔子，因此按回答值把「含有受访兔子的颜色类」分成互不相交的族。对固定的 $x$，族中每个类恰含 $x+1$ 只兔子，且由引理 3 这样的类至少有 $\left\lceil c_x/(x+1)\right\rceil$ 个，故该族贡献至少 $\left\lceil c_x/(x+1)\right\rceil (x+1)$ 只。不含受访兔子的颜色类只会让总数更大。对所有 $x$ 求和即得下界。∎

**引理 5（下界可达）**：存在兔子数恰为 $\sum_x \left\lceil c_x/(x+1)\right\rceil (x+1)$ 的自洽森林。

**证明**：构造如下。对每个 $x$，把 $c_x$ 只回答 $x$ 的兔子任意分成 $k_x = \left\lceil c_x/(x+1)\right\rceil$ 组，使得每组不超过 $x+1$ 只（依次装 $x+1$ 只直到不足）。为每组补上 $x+1 - \lvert \text{组}\rvert$ 只未受访兔子，并把该组染成**独一无二**的颜色（不同组颜色互不相同）。此时每个颜色类恰有 $x+1$ 只，类内每只受访兔子回答的都是 $x$，与其记录一致；各类颜色不同，互不干扰，故整个森林自洽。总兔子数恰为 $\sum_x k_x (x+1)$。∎

**定理**：算法输出的是森林中兔子数量的最小值。

**证明**：算法输出 $\sum_x k_x (x+1)$，其中 $k_x = \left\lceil c_x/(x+1)\right\rceil$。由引理 4 它是所有自洽森林的下界，由引理 5 该下界可达到，故它等于最小值。∎

## 6. 复杂度分析

- **时间**：$O(n + V)$，其中 $V = 1001$ 为回答值域。一次扫描计数 $O(n)$，一次遍历值域 $O(V)$；若改用哈希表，则为 $O(n + d)$，$d \le 1001$ 为不同回答值个数。无论哪种都在 $10^{6}$ 次基本操作以内。
- **空间**：$O(V)$ 的计数数组（哈希表版本为 $O(d)$），不随 $n$ 增长；除此之外只用了常数个累加变量。

## 7. 参考代码

### C++

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    int numRabbits(vector<int>& answers) {
        int cnt[1000] = {0};                 // answers[i] <= 999
        for (int x : answers) cnt[x]++;

        int ans = 0;
        for (int x = 0; x < 1000; x++) {
            int c = cnt[x];
            if (c == 0) continue;
            int g = x + 1;                   // 该颜色类的固定大小
            int k = (c + g - 1) / g;         // 需要的组数（整数上取整）
            ans += k * g;                    // 末组不满也按 g 只计
        }
        return ans;
    }
};
```

### Python

```python
from collections import Counter


class Solution:
    def numRabbits(self, answers: list[int]) -> int:
        ans = 0
        for x, c in Counter(answers).items():
            g = x + 1                     # 该颜色类的固定大小
            k = (c + g - 1) // g          # 需要的组数（整数上取整）
            ans += k * g                  # 末组不满也按 g 只计
        return ans
```

## 8. 边界情况与易错点

1. **$x = 0$**：容量为 1，每只回答 0 的兔子各自独占一类。`answers = [0,0]` 的答案是 2，不是 1。公式 $k = \lceil c/1 \rceil = c$ 已经覆盖，无需特判。
2. **下取整陷阱**：$c = 3, g = 11$ 时 `c / g == 0`，必须写 `(c + g - 1) / g`；这是本题最常见的 WA 来源。
3. **末组不满也要补满**：`[10,10,10]` 的答案是 11，按「只数受访兔子」算会得到 3，按「每组都要 $x+1$ 只受访兔子」算会得到 33。
4. **跨回答值合并**：回答 1 与回答 2 的兔子不可能同色（组大小 2 与 3 矛盾）。把不同回答值塞进同一桶会低估答案。
5. **答案可以远大于 $n$**：`[999]` 的答案是 1000。不要用「答案 $\le n$」的直觉去做剪枝或开数组。
6. **值域边界**：$answers[i] = 999$ 时容量 1000，计数数组下标最大为 999，开 1000 个足够；若误开 999 个会越界。
7. **计数与遍历范围一致**：数组版只遍历 $[0, 999]$，忘记处理 $x = 999$ 的桶会漏算；哈希表版不要边遍历边改表。
