# LeetCode 二叉搜索树节点最小距离 题解

## 1. 题目概述

- **标题 / 题号**：二叉搜索树节点最小距离（#783，easy）
- **链接**：https://leetcode.cn/problems/minimum-distance-between-bst-nodes/
- **来源**：LeetCode 第 71 场周赛 Q1
- **难度**：简单
- **标签**：树、深度优先搜索、广度优先搜索、二叉搜索树、二叉树

**题意**：给定一棵二叉搜索树（BST）的根节点 `root`，返回树中**任意两个不同节点值之差的绝对值**的最小值。由于 BST 中不存在重复值，答案至少为 $1$。

**约束**：

- 节点数目 $n \in [2, 100]$
- $0 \le \text{Node.val} \le 10^5$
- 输入保证是一棵合法的二叉搜索树

> 💡 本题与 [530. 二叉搜索树的最小绝对差](https://leetcode.cn/problems/minimum-absolute-difference-in-bst/) 完全等价：把「任意两节点」理解成「中序序列中的任意两项」，两题就只差一个函数名。

## 2. 示例

**示例 1**

```text
输入：root = [4,2,6,1,3]
输出：1
解释：中序遍历得到 [1,2,3,4,6]，相邻差为 1、1、1、2，最小差为 1。
      所有点对中最接近的是 1 与 2（或 2 与 3、3 与 4）。
```

**示例 2**

```text
输入：root = [1,0,48,null,null,12,49]
输出：1
解释：中序遍历得到 [0,1,12,48,49]，相邻差为 1、11、36、1，最小差为 1。
      注意 12 与 48 之间差了 36，但 0 与 1、48 与 49 都只差 1。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的做法是把所有点对都枚举一遍：

$$\text{ans} = \min_{u \neq v} \lvert v_u - v_v \rvert,\qquad v_u \text{ 表示节点 } u \text{ 的值}$$

$n \le 100$ 时点对数约为 $5\times10^3$，暴力**能过**，但完全没有用到「这是一棵 BST」这一关键条件。若树退化成普通二叉树，更通用的做法是先收集所有值再排序，时间 $O(n\log n)$。

问题在于：这两种做法都没有回答「BST 的顺序性能不能直接省掉排序、甚至省掉所有跨项比较」。答案是能。

### 3.2 核心观察：BST 中序 = 升序，最小差只可能在相邻项

![BST 中序遍历得到升序序列，最小差在相邻项](images/wc71_q1_bst_inorder.svg)

**观察一（顺序性）**：BST 的中序遍历（左 → 根 → 右）恰好把节点值按**严格升序**输出。因为根的值大于左子树全部节点、小于右子树全部节点，递归地拼接三段自然有序。

于是问题被翻译成一个纯序列问题：给定升序序列 $a_1 < a_2 < \dots < a_n$，求 $\min_{i<j}(a_j - a_i)$。

**观察二（相邻性）**：在升序序列中，最小差**只可能**由相邻两项取到。理由很朴素——对 $j \ge i+2$，

$$a_j - a_i = (a_j - a_{i+1}) + (a_{i+1} - a_i) \ge a_{i+1} - a_i \ge \min_k (a_{k+1}-a_k)$$

也就是说，任何跨项差都被它夹在中间的某个相邻差「压住」了，永远不可能更小。

> 💡 一句话：**「任意两节点」的最优解必然出现在「中序相邻」上**，这把 $O(n^2)$ 的点对枚举直接压到 $O(n)$ 的相邻比较。

### 3.3 算法流程

![中序遍历时维护 prev 与 ans](images/wc71_q1_algorithm_flow.svg)

维护两个变量：

- `prev`：**上一个被访问**的节点值（即中序前驱），初值不存在；
- `ans`：迄今最小的相邻差，初值 $+\infty$。

对当前节点 `node`，中序的访问顺序是 `dfs(left) → 处理 node → dfs(right)`，因此「处理 node」这一步拿到的正好是升序序列中的下一个元素：

1. 若 `prev` 存在，则 `ans = min(ans, node.val - prev)`；
2. 令 `prev = node.val`（供下一次比较用）；
3. 继续递归右子树。

遍历结束后 `ans` 就是答案。整个过程每个节点只被访问一次，没有额外存储序列的数组。

### 3.4 示例演算

![示例 2 的逐步走查](images/wc71_q1_walkthrough.svg)

以示例 2 的 `root = [1,0,48,null,null,12,49]` 为例，中序访问顺序为 $0 \to 1 \to 12 \to 48 \to 49$：

| 步 | cur | prev | cur − prev | ans |
|----|-----|------|-----------|-----|
| 1 | 0 | 无 | — | ∞ |
| 2 | 1 | 0 | 1 | 1 |
| 3 | 12 | 1 | 11 | 1 |
| 4 | 48 | 12 | 36 | 1 |
| 5 | 49 | 48 | 1 | 1 |

第 1 步 `prev` 为空，只做「登记」不做比较；之后每次比较都与 `ans` 取 min。最终答案 $1$，与官方输出一致。

## 4. 算法细节

1. **`prev` 的初值用「是否存在」标记**，不要用魔数。C++ 里加一个 `bool hasPrev`（或因为本题 $val \ge 0$ 而用 `prev = -1` 兜底），Python 里用 `prev = None`；一旦题目放宽到负值，魔数写法会静默出错。
2. **`ans` 初值取 `INT_MAX` / `float('inf')`**。不要初始化成 $0$（会让 `min` 永远返回 $0$），也不要初始化成 $1$（答案完全可能大于 $1$，例如值集 $\{0, 519, 1277, 2236, 2776\}$ 的最小差是 $519$）。
3. **差值不需要 `abs`**。中序序列严格升序，`node.val - prev` 天然非负；只有「任意点对暴力」才需要绝对值。省掉一次分支与一次取绝对值。
4. **递归与迭代都行，注意栈深**。本题 $n \le 100$，递归深度最多 $100$，安全；若 $n$ 放大到 $10^5$ 且树退化成链，递归会爆栈，此时应改成显式栈的中序迭代：
   ```text
   stack ← [];  cur ← root
   while cur ≠ null or stack 非空:
       一路向左压栈直到 null
       弹出并处理（比较 prev、更新 ans、prev ← cur.val）
       cur ← cur.right
   ```
5. **可以提前剪枝**。因为 BST 无重复值，任意两节点差 $\ge 1$，所以一旦 `ans == 1` 就可以立刻返回——它已经达到理论下界，后面不可能更优。在「最小值恰好为 1」的常见数据上能省掉大半遍历。
6. **Python 闭包里改外层变量要用 `nonlocal`**。`ans`、`prev` 定义在 `minDiffInBST` 体内、在嵌套函数 `inorder` 里赋值，漏写 `nonlocal` 会静默创建局部变量，导致返回 `inf`。
7. **接口名与参数顺序严格照 `metaData`**：`int minDiffInBST(TreeNode* root)`，只接收一个 `root`，返回值是 `int`；注意别写成 530 题的 `getMinimumDifference`。

## 5. 正确性证明

**引理 1（中序升序）**：对任意一棵合法 BST，其中序遍历序列严格递增。

**证明**：对树高归纳。空树与单节点显然成立。设根为 $r$，左子树 $L$、右子树 $R$。中序序列为「中序($L$)，$r$，中序($R$)」。由 BST 性质，$L$ 中所有值 $< r$，$R$ 中所有值 $> r$；由归纳假设，中序($L$)、中序($R$) 各自严格递增。三段拼接后：左段内部递增且末项 $< r$，右段内部递增且首项 $> r$，故整体严格递增。∎

**引理 2（最小值落在相邻项）**：设 $a_1 < a_2 < \dots < a_n$（$n \ge 2$），则

$$\min_{1 \le i < j \le n} (a_j - a_i) = \min_{1 \le k < n} (a_{k+1} - a_k)$$

**证明**：记 $D = \min_k (a_{k+1}-a_k)$。

- ($\le$) 每个相邻差 $a_{k+1}-a_k$ 本身就是某个点对的差，故左边 $\le D$。
- ($\ge$) 任取 $i<j$。若 $j=i+1$，差就是某个相邻差，$\ge D$；若 $j \ge i+2$，由 $a_j \ge a_{i+1}$ 得 $a_j - a_i \ge a_{i+1}-a_i \ge D$（这里用了升序，$a_{i+1} \le a_j$）。故所有点对差都 $\ge D$，左边 $\ge D$。

两侧夹逼，等号成立。∎

**定理**：算法返回的值等于树中任意两不同节点值之差的绝对值的最小值。

**证明**：由引理 1，算法按严格升序 $a_1 < \dots < a_n$ 访问节点，且恰好在访问每个 $a_k$（$k \ge 2$）时把 $a_k - a_{k-1}$ 与 `ans` 取 min，因此结束时

$$\text{ans} = \min_{2 \le k \le n}(a_k - a_{k-1})$$

由引理 2，它等于全部点对差的最小值；又因严格升序，$a_j - a_i > 0$ 就是两值之差的绝对值。∎

## 6. 复杂度分析

- **时间**：$O(n)$。中序遍历每个节点恰好进入、处理、离开各一次，每次处理只做一次减法与一次比较（$O(1)$）；若触发 `ans == 1` 剪枝则可能更早结束。相比「收集 + 排序」的 $O(n\log n)$，这里省掉了排序。
- **空间**：$O(h)$，$h$ 为树高，只用于递归栈或显式栈，没有额外数组。平衡树 $h = O(\log n)$；链状最坏 $h = O(n)$。若需要严格 $O(1)$ 额外空间，可用 Morris 中序遍历。

## 7. 参考代码

### C++

```cpp
#include <algorithm>
#include <climits>
#include <functional>

/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    int minDiffInBST(TreeNode* root) {
        int ans = INT_MAX;
        int prev = -1;
        bool hasPrev = false;

        std::function<void(TreeNode*)> inorder = [&](TreeNode* node) {
            if (node == nullptr || ans == 1) return;   // 空节点，或已达下界 1 → 剪枝
            inorder(node->left);                       // 左
            if (hasPrev) ans = std::min(ans, node->val - prev);  // 根：与中序前驱比较
            prev = node->val;
            hasPrev = true;
            inorder(node->right);                      // 右
        };

        inorder(root);
        return ans;
    }
};
```

### Python

```python
from typing import Optional


class Solution:
    def minDiffInBST(self, root: Optional[TreeNode]) -> int:
        ans = float('inf')
        prev = None

        def inorder(node: Optional[TreeNode]) -> None:
            nonlocal ans, prev
            if node is None or ans == 1:               # 空节点，或已达下界 1 → 剪枝
                return
            inorder(node.left)                         # 左
            if prev is not None:                       # 根：与中序前驱比较
                ans = min(ans, node.val - prev)
            prev = node.val
            inorder(node.right)                        # 右

        inorder(root)
        return ans
```

## 8. 边界情况与易错点

1. **只有两个节点**：`root = [2,1]`（左孩子）或 `root = [1,null,2]`（右孩子），两者的中序序列都是 `[1,2]`，答案都是 $1$。此时 `prev` 为空的分支恰好被跳过一次，逻辑必须正确。
2. **链状 BST**：若按升序依次插入 $1,2,\dots,100$，树会退化成一条只有右孩子的链，深度恰好等于节点数 $100$。递归不会爆栈，但要清楚「栈深上限是 $n$ 而不是 $\log n$」；若数据放大到 $10^5$，就必须换成显式栈迭代或 Morris 遍历。
3. **`prev` 用 `-1` 做哨兵的前提是 $val \ge 0$**。本题恰好满足，但一旦值域含负数，`hasPrev` 标记才是正确写法——这是把代码迁移到 530 变体时最容易踩的坑。
4. **`ans` 不能用 $1$ 初始化**。最小差完全可能远大于 $1$，如 `[0,null,2236,1277,2776,519]` 的答案是 $519$；用 $1$ 初始化会直接返回错误结果。
5. **最小差不一定出现在「父子」之间**。反例 `root = [10,5,15,null,8]`：父子差为 $10-5=5$、$15-10=5$、$8-5=3$，最小值是 $3$；但 $8$ 与 $10$ 差 $2$，真实答案是 $2$。所以「只比较每个节点与其左右孩子」的写法是错的，必须比较**中序相邻**（即跨子树的边界对）。
6. **`abs` 只在无序集合上才需要**。若把 BST 性质换成普通二叉树，就必须先排序或先收集值，否则 `node.val - prev` 可能为负，`min` 会把负数当成答案。
7. **剪枝 `ans == 1` 只对「值互不相同」成立**。BST 保证无重复，故下界为 $1$；若允许重复值，下界变成 $0$，剪枝条件要相应改写。

**延伸思考**：

1. 若这棵树**不是** BST，只能退化为「收集全部值 + 排序」，$O(n\log n)$；可见 BST 性质本身就是一次免费的排序。
