# LeetCode 到达终点 题解

## 1. 题目概述

- **标题 / 题号**：到达终点（#780，hard）
- **链接**：https://leetcode.cn/problems/reaching-points/
- **来源**：LeetCode 第 71 场周赛 Q3
- **难度**：困难
- **标签**：数学，最大公约数，欧几里得算法

**题意**：从点 $(sx, sy)$ 出发，每一步可以把其中一个坐标加上另一个坐标，即 $(x,y)\to(x,\,x+y)$ 或 $(x,y)\to(x+y,\,y)$。问能否恰好到达终点 $(tx, ty)$。

**约束**：

- $1 \le sx, sy, tx, ty \le 10^9$
- 四个数都是**正整数**——这个条件决定了「倒推的前驱唯一」，是整道题的支点。

## 2. 示例

**示例 1**

```text
输入：sx = 1, sy = 1, tx = 3, ty = 5
输出：true
解释：(1,1) -> (1,2) -> (3,2) -> (3,5)
```

**示例 2**

```text
输入：sx = 1, sy = 1, tx = 2, ty = 2
输出：false
解释：除起点外，可达点的两个坐标一定不相等，故 (2,2) 不可达。
```

**示例 3**

```text
输入：sx = 1, sy = 1, tx = 1, ty = 1
输出：true
解释：零步转换，起点即终点。
```

## 3. 解题思路

### 3.1 暴力思路

从起点做 BFS/DFS，每个点有 2 条出边。即使按「坐标不超过 $tx, ty$」剪枝，可访问的状态也只是 $[sx,tx]\times[sy,ty]$，最坏约 $10^{18}$；而路径条数随步数指数增长。$10^9$ 的数据范围下，正向枚举完全不可行。

换一个角度：题目只问**可达性**，不需要枚举路径。如果一条路径存在，它是否唯一？

### 3.2 核心观察：从终点倒推，前驱唯一

![正向分叉 vs 反向唯一前驱](images/wc71_q3_reverse_unique.svg)

设当前点 $(x,y)$ 且 $x>y$。它是怎么来的？

- 若最后一步是 $(X,Y)\to(X,\,X+Y)$，那么 $y = X+Y > X = x$，与 $x>y$ 矛盾；
- 所以最后一步只能是 $(X,Y)\to(X+Y,\,Y)$，于是 $Y=y$、$X=x-y$。

**结论**：只要 $x>y$，$(x,y)$ 的前驱**有且只有** $(x-y,\,y)$。同理 $y>x$ 时前驱唯一是 $(x,\,y-x)$。于是从终点倒推不存在分支——顺着唯一的一条链往回走，看能否落在起点即可。

进一步地，「连续减同一个数」可以整批完成：

![一次取模代替多次减法](images/wc71_q3_batch_subtract.svg)

当 $x>y$ 时，倒推链会连续执行 $x\gets x-y$ 共 $\lfloor x/y \rfloor$ 次，直到第一坐标小于 $y$。这与**一次取模**等价：$x \bmod y = x - \lfloor x/y\rfloor\cdot y$。于是每轮把较大坐标对较小坐标取模，全过程就是欧几里得算法，最多约 $45$ 轮。

### 3.3 算法流程

![倒推欧几里得：循环与三种终止情形](images/wc71_q3_euclid_flow.svg)

```text
while sx < tx and sy < ty:          # 两个坐标都还有余量
    if tx < ty: ty %= tx            # y 较大 → 只可能是 y 被加了 x
    else:       tx %= ty            # x 较大 → 只可能是 x 被加了 y
# 退出时：tx >= sx 或 ty >= sy
if sx == tx and sy <= ty and (ty - sy) % sx == 0: return true   # 之后只能给 y 加 x
if sy == ty and sx <= tx and (tx - sx) % sy == 0: return true   # 之后只能给 x 加 y
return false
```

循环条件用 **且**（`and`）而不是或：只要有一个坐标已经退到起点，另一方向的批量减法就可能「跨过」起点，必须停下来单独判定。

**为什么退出后只剩两种可行情形**：坐标只增不减，所以 $tx<sx$ 或 $ty<sy$ 直接无解。否则退出时必有 $tx=sx$ 或 $ty=sy$：

- $tx=sx$：x 方向永远不能再加（一旦加大就回不到 $sx$），此后所有步都是 $(x,x+y)$，故 $ty = sy + k\cdot sx\ (k\ge 0)$，即 $sy\le ty$ 且 $(ty-sy)\bmod sx = 0$；
- $ty=sy$：对称地，$sx\le tx$ 且 $(tx-sx)\bmod sy = 0$。

### 3.4 示例演算

![示例 (1,1) → (3,5) 的倒推走查](images/wc71_q3_walkthrough.svg)

以示例 1 为例，倒推两步后得到 $(1,2)$，此时 $tx=sx$，终止判定 $(ty-sy)\bmod sx=(2-1)\bmod 1=0$ 成立，返回 `true`；沿正向 (1,1) → (1,2) → (3,2) → (3,5) 也验证了每一步都合法。

再看示例 2：$(2,2)$ 两坐标相等，循环体执行 $tx \bmod ty = 2\bmod 2 = 0$，落到 $(0,2)$；循环因 $sx<tx$ 不成立而退出，两个判定都不满足，返回 `false`——正符合「除起点外可达点的两个坐标必不相等」。

## 4. 算法细节

1. **循环不变式**：循环体中「整批减」只在两个坐标都严格大于起点对应值时进行，此时较大坐标的前驱唯一，取模不会跨过起点，可达性保持不变。
2. **批量减 vs 逐步减**：逐步 `tx -= ty` 的轮数可达 $10^9$，必然 TLE；一次取模把 $\lfloor tx/ty\rfloor$ 步压成 $O(1)$。
3. **两种终止情形要判整除**：$tx=sx$ 时只能给 $y$ 加 $x$，所以差值必须是 $sx$ 的整数倍；少写 `% sx == 0` 会把 (2,4)→(2,7) 之类的点误判为可达。
4. **`sy <= ty` / `sx <= tx` 不能省**：它挡掉「另一坐标已经小于起点」的不可达情况。例如 $sx=5,sy=1,tx=3,ty=1$，若省略 `sx <= tx`，就会因 $(3-5)\bmod 1=0$ 误返回 `true`。
5. **除零安全**：循环体内 $tx \ge sx+1 \ge 2$、$ty \ge sy+1 \ge 2$，取模的除数至少为 2；终止判定里的 `% sx`、`% sy` 由约束 $sx,sy\ge 1$ 保证非零。
6. **终止性**：每轮取模后，较大坐标变成原较小值，较小坐标变成模余数，与欧几里得算法同构；$10^9$ 内不超过约 $45$ 轮。
7. **整数类型**：所有运算都在 $10^9$ 量级，C++ 用 `int` 足够，不涉及乘法；Python 无溢出问题，但不要用浮点除法近似取模。

## 5. 正确性证明

记 $R(x,y)$ 表示「$(x,y)$ 可由起点 $(sx,sy)$ 到达」，并约定坐标小于起点对应值的点不可达（前向操作只会让坐标增大）。

**引理 1（前驱唯一）**：若 $(x,y)$ 由起点经至少一步得到且 $x>y$，则 $(x,y)$ 只能由 $(x-y,\,y)$ 一步得到。

**证明**：最后一步有两种可能。若是 $(X,Y)\to(X,\,X+Y)$，则 $y=X+Y>X=x$，与 $x>y$ 矛盾；故最后一步必为 $(X,Y)\to(X+Y,\,Y)$，此时 $Y=y$、$X=x-y$，前驱唯一。∎

**引理 2（非起点的可达点两坐标不等）**：若 $(x,y)\ne(sx,sy)$ 可达，则 $x\ne y$。

**证明**：取路径的最后一步，两种操作分别产生 $x<y$ 与 $x>y$ 的点，均不相等。∎

**引理 3（一步等价）**：设 $x>y\ge 1$ 且 $x>sx$，则 $R(x,y)\iff R(x-y,\,y)$。

**证明**：($\Leftarrow$) 若 $(x-y,y)$ 可达，对它做一次 $(X,Y)\to(X+Y,Y)$ 即得 $(x,y)$。($\Rightarrow$) 若 $(x,y)$ 可达，由 $x>sx$ 知它不是起点，故至少走了一步，由引理 1 其前驱 $(x-y,\,y)$ 必可达。∎

**引理 4（取模批处理 / 循环不变式）**：设 $x>y\ge1$、$x>sx$、$y>sy$，记 $r=x\bmod y$，则 $R(x,y)\iff R(r,\ y)$。

**证明**：设 $x=r+ky\ (k\ge1)$，分两种情形。

(1) $r\ge sx$：对 $i=0,1,\dots,k-1$，点 $(x-iy,\ y)$ 的第一坐标等于 $r+(k-i)y>y$ 且 $\ge r\ge sx$，满足引理 3 的使用条件。链式应用引理 3 即得 $R(x,y)\iff R(r,y)$。

(2) $r<sx$：此时 $R(r,y)$ 为假（第一坐标小于起点）。反设 $R(x,y)$ 为真，沿唯一链回退到停止点 $r'=x-jy$——即 $r'$ 已不再同时大于 $y$ 与 $sx$，且 $R(r',y)$ 仍为真，$r'\equiv r\pmod y$。于是：

- 若 $r'<y$，则 $r'=r<sx$，与 $R(r',y)$ 为真矛盾；
- 若 $r'=y$，则 $(y,y)$ 可达，与引理 2 矛盾（$y>sy$ 说明它不是起点）；
- 若 $r'>y$，链在此停止只可能是因为 $r'\le sx$：若 $r'<sx$ 同上矛盾；若 $r'=sx$，则 $R(sx,y)$ 为真，说明从 $(sx,sy)$ 起第一坐标恒为 $sx$，所有步都是给 $y$ 加 $sx$，得 $y=sy+k\,sx\ (k\ge1)$，故 $y>sx$；又 $x=sx+jy$，于是 $r=x\bmod y=sx\bmod y=sx$，与 $r<sx$ 矛盾。

故 $R(x,y)$ 为假。

两种情形都得到 $R(x,y)\iff R(r,y)$。∎

**引理 5（终止判定）**：循环退出时 $R(tx,ty)$ 等于两个整除判定中任一为真的结果。

**证明**：先看坐标已小于起点的情形。若 $tx<sx$ 或 $ty<sy$，由坐标只增不减知 $R$ 为假；而两个判定分别暗含 $sx=tx$（或 $sx\le tx$）与 $sy\le ty$（或 $sy=ty$），此时都不成立，故返回假，正确。否则 $tx\ge sx$、$ty\ge sy$，退出条件强迫 $tx=sx$ 或 $ty=sy$：

- $tx=sx$：任何给 $x$ 加法的步骤都会使第一坐标永久大于 $sx$，故之后只能给 $y$ 加 $x$，即 $ty=sy+k\,sx\,(k\ge0)$，等价于 $sy\le ty$ 且 $(ty-sy)\bmod sx=0$；
- $ty=sy$：对称，等价于 $sx\le tx$ 且 $(tx-sx)\bmod sy=0$。

（当 $tx=sx$ 且 $ty=sy$ 时两者同时成立，返回真。）∎

**定理**：算法返回 `true` $\iff$ $(tx,ty)$ 可由 $(sx,sy)$ 到达。

**证明**：初始时不变式 $R(tx,ty)$ 当然成立。每轮循环体执行前有 $sx<tx$、$sy<ty$，较大坐标 $>$ 较小坐标且 $>$ 起点对应值，由引理 4 取模前后 $R(tx,ty)$ 不变。循环每次让较大坐标严格变小（取模结果小于除数），故必然终止。终止时由引理 5，两个判定恰好刻画 $R(tx,ty)$，故返回值正确。∎

## 6. 复杂度分析

- **时间**：$O(\log \max(tx,ty))$。每轮循环把较大坐标对较小坐标取模，构成欧几里得算法，除法次数与 $\log_\varphi \max(tx,ty)$ 同阶；$10^9$ 内不超过约 $45$ 轮，每轮 $O(1)$。
- **空间**：$O(1)$。只用了四个整型参数与常数个临时变量，无递归、无额外容器。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool reachingPoints(int sx, int sy, int tx, int ty) {
        // 倒推：只要两个坐标都还大于起点，就整批减掉较小者
        while (sx < tx && sy < ty) {
            if (tx < ty) ty %= tx;   // y 较大：y 只可能被加了 x
            else        tx %= ty;    // x 较大：x 只可能被加了 y
        }
        // 退出后 tx == sx 或 ty == sy，剩下的一段必须能整除走完
        if (sx == tx && sy <= ty && (ty - sy) % sx == 0) return true;
        if (sy == ty && sx <= tx && (tx - sx) % sy == 0) return true;
        return false;
    }
};
```

### Python

```python
class Solution:
    def reachingPoints(self, sx: int, sy: int, tx: int, ty: int) -> bool:
        # 倒推：只要两个坐标都还大于起点，就整批减掉较小者
        while sx < tx and sy < ty:
            if tx < ty:
                ty %= tx          # y 较大：y 只可能被加了 x
            else:
                tx %= ty          # x 较大：x 只可能被加了 y
        # 退出后 tx == sx 或 ty == sy，剩下的一段必须能整除走完
        if sx == tx and sy <= ty and (ty - sy) % sx == 0:
            return True
        if sy == ty and sx <= tx and (tx - sx) % sy == 0:
            return True
        return False
```

## 8. 边界情况与易错点

1. **起点即终点**（示例 3）：循环不进入，第一个判定给出 `(1-1) % 1 == 0`，返回 `true`；不要因为「一步都没走」而特判成 `false`。
2. **`tx == ty` 且非起点**：如 $(1,1)\to(2,2)$，取模后落到 $0$，循环退出、判定失败，返回 `false`。除起点外不存在两坐标相等的可达点（引理 2）。
3. **循环条件写成 `or`**：只剩一个坐标有余量时若继续取模，会把它压到起点以下，从而漏掉正确答案。例如 $sx=1,sy=1,tx=3,ty=1$，正确的是跳过循环、由 $sy=ty$ 判定整除得到 `true`；写成 `or` 会算出 $3\bmod 1=0$ 后返回 `false`。必须用 `and`。
4. **漏掉 `sy <= ty` / `sx <= tx`**：若只写 $tx=sx$ 与整除条件，$sx=3,sy=9,tx=3,ty=3$ 会因 $(3-9)\bmod 3=0$ 误返回 `true`；而 $y$ 只能增大，$9\to3$ 根本不可能。负差值取模在 C++ 与 Python 中都可能得 $0$，必须先判 $sy\le ty$ 挡住。
5. **漏掉整除判定**：$tx=sx$ 只说明 x 不再增长，还需 $ty-sy$ 是 $sx$ 的整数倍；例如 $sx=2,sy=4,tx=2,ty=7$ 不可达。
6. **逐步减法 TLE**：把取模写成 `while (tx > sx) tx -= ty;` 时，$ty=1$、$tx=10^9$ 会退化成 $10^9$ 次循环。
7. **取模得 0 的误判**：循环内出现 $0$ 只是「链已断」的信号，随后循环必然退出并返回 `false`，不要额外判断把它当成 `true`。
