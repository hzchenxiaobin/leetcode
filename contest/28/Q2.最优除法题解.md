# LeetCode 最优除法 题解

## 1. 题目概述

- **标题 / 题号**：最优除法（#553，medium）
- **链接**：https://leetcode.cn/problems/optimal-division/
- **来源**：LeetCode 第 28 场周赛 Q2
- **难度**：中等
- **标签**：数组、数学、动态规划

**题意**：给定正整数数组 `nums`，把相邻元素依次用除号连成 $a_1 / a_2 / \cdots / a_n$，可以**任意加括号**改变运算顺序（数字顺序不变，只改变结合方式）。返回使表达式值**最大**的那个表达式字符串，且表达式中**不允许冗余括号**（不写任何不影响运算优先级的括号）。

**约束**：

- $1 \le \text{nums.length} \le 10$
- $2 \le \text{nums}[i] \le 1000$
- 对给定输入，最优除法（去冗余括号后）**唯一**
- $n = 10$ 时全部加括号方案仅 $C_9 = 4862$ 种，枚举量本身不大

> 💡 三个赛场信号：① 展开后每个元素的指数只能是 $\pm 1$；② $a_2$ 是第一个除数，符号被钉死为负；③ 要让值最大 = 让尽可能多的 $a_i$ 变**分子因子**，因此只要把 $a_2..a_n$ 一起括起来。

## 2. 示例

**示例 1**

```text
输入：nums = [1000,100,10,2]
输出："1000/(100/10/2)"
解释：1000/(100/10/2) = 1000/((100/10)/2) = 200
     对比：1000/(100/10)/2 = 50，1000/(100/(10/2)) = 50
           1000/100/10/2 = 0.5，1000/100/(10/2) = 2
     加粗的 "1000/((100/10)/2)" 与答案等价，但内层括号不影响优先级，属冗余。
```

**示例 2**

```text
输入：nums = [2,3,4]
输出："2/(3/4)"
解释：2/(3/4) = 8/3 ≈ 2.667；穷举全部方案后没有更大的值。
```

**补充示例 3（长度 1、2 的边界，题面未列出但必须处理）**

```text
输入：nums = [7]        输出："7"        （只有一个数，没有除号）
输入：nums = [7,3]      输出："7/3"      （唯一方案，加括号即冗余）
```

## 3. 解题思路

### 3.1 暴力思路

**枚举所有加括号方式**：$n$ 个数的完全加括号方案数是 Catalan 数

$$C_{n-1} = \frac{1}{n}\binom{2n-2}{n-1}, \qquad n = 10 \Rightarrow C_9 = 4862$$

每个方案还要用分数精确求值再比大小，最后再按「去冗余括号」的规则输出字符串。$O(C_{n-1}\cdot n)$ 写得通，但只是拿枚举兜底，分数类、字符串去括号都是额外的出错点。

**区间 DP**（通用模板）：设 $f(l,r)$、$g(l,r)$ 为子表达式 $a_l..a_r$ 的最大/最小值，则

$$f(l,r) = \max_{l \le k < r} \frac{f(l,k)}{g(k+1,r)}, \qquad g(l,r) = \min_{l \le k < r} \frac{f(l,k)}{g(k+1,r)}$$

（分子取最大、分母取最小；值恒正所以商的最大值可这样拼）。$O(n^3)$ 对 $n \le 10$ 当然够，但它只回答「最大是多少」，还得额外记录表达式串——而本题答案有闭式结构，DP 是杀鸡用牛刀。

### 3.2 核心观察：让 a₂ 当分母，其余全进分子

![符号向量：a₁ 恒在分子，a₂ 恒在分母](images/wc28_q2_sign_vector_concept.svg)

**第一步：把「加括号」翻译成「选符号」。** 任何加括号方案都是一棵满二叉树：叶子自左向右恰为 $a_1,\dots,a_n$，内部节点全是除法。把表达式展开约分，结果必然形如

$$\text{val} = \prod_{i=1}^{n} a_i^{\,e_i}, \qquad e_i \in \{+1,-1\}$$

因为除法节点只做指数相减，绝不会出现 $|e_i| \ge 2$。于是「找最大表达式」等价于「找最大的符号向量」。

**第二步：两个端点的符号是钉死的。**

- $e_1 = +1$：$a_1$ 是最左叶子，沿路每个祖先都把它当左孩子，除号永远除不到它。
- $e_2 = -1$：$a_2$ 是第一个除数——它是「只含 $a_1,a_2$ 的最小子树」右孩子的最左叶子，随后一路作为左孩子上行，恒在分母。

**第三步：把 $a_3..a_n$ 全部翻到分子。** $a_i \ge 2 > 1$，一个元素从分母搬到分子，值至少乘以 $2^2 = 4$，所以**正号越多值越大**；而正号个数无法超过 $n-1$（$a_2$ 必须占掉一个负号）。取

$$a_1 / (\,a_2 / a_3 / \cdots / a_n\,) = \frac{a_1 \cdot a_3 \cdot a_4 \cdots a_n}{a_2}$$

符号向量为 $(+,-,+,\dots,+)$，正号恰好 $n-1$ 个，顶到上界——这就是答案，而且**整串只需这一对括号**。

> 💡 直觉版：分母越小商越大。把 $a_2$ 这个「第一个除数」继续当除数链的头，它带着 $a_3..a_n$ 一起做分母，而 $a_3..a_n$ 在链内又各自成为分子——一次括号同时完成全部翻转。

### 3.3 算法流程

![三分支拼串流程](images/wc28_q2_flow.svg)

按长度分三种情况，互斥且覆盖全部输入：

| 情况 | 返回值 | 说明 |
|------|--------|------|
| $n = 1$ | `a₁` | 没有除号，数字本身 |
| $n = 2$ | `a₁/a₂` | 唯一方案，任何括号都冗余 |
| $n \ge 3$ | `a₁/(a₂/a₃/…/aₙ)` | 唯一一对括号，包住 $a_2..a_n$ |

$n \ge 3$ 时括号内部**不再加任何括号**：除法左结合，子串 $a_2/a_3/\cdots/a_n$ 天然解析为 $((\cdots(a_2/a_3)/\cdots)/a_n)$，正是符号向量 $(+,-,+,\dots,+)$ 对应的那棵树。

### 3.4 示例演算

![示例演算：5 种方案的符号向量与值](images/wc28_q2_walkthrough.svg)

以 `nums = [1000,100,10,2]` 为例，共 $C_3 = 5$ 种方案，逐个展开：

| 方案 | 展开后的分子/分母 | 符号向量 | 值 |
|------|-------------------|----------|-----|
| `1000/100/10/2` | $1000/(100\cdot10\cdot2)$ | $+---$ | $0.5$ |
| `1000/(100/10)/2` | $1000\cdot10/(100\cdot2)$ | $+-+-$ | $50$ |
| `(1000/100)/(10/2)` | $1000\cdot2/(100\cdot10)$ | $+--+$ | $2$ |
| `1000/(100/(10/2))` | $1000\cdot10/(100\cdot2)$ | $+-+-$ | $50$ |
| `1000/(100/10/2)` | $1000\cdot10\cdot2/100$ | $+-++$ | $\mathbf{200}$ |

两个细节值得注意：

- 第 2、4 行符号向量相同（都是 $+-+-$），值就都是 $50$——**值只由符号向量决定**，不同括号写法可以同值。
- 只有最后一行正号数 $3 = n-1$ 顶到上界；其余方案至少把某个 $a_i\,(i \ge 3)$ 留在分母，值被压小 $a_i^2$ 倍以上。

## 4. 算法细节

1. **三个分支一个都不能少**：$n=1$ 返回裸数字、$n=2$ 返回 `a₁/a₂`；若把两种情况硬塞进 $n\ge3$ 的模板，会得到 `2/()`、`2/(3)` 这类非法或冗余的串。
2. **括号只加一对，位置固定**：先写 `a₁`，紧跟 `/`，再写 `(`，然后 `a₂`，此后每个 $a_i$ 前补一个 `/`，末尾补 `)`。$a_2$ 必须紧贴左括号，否则它又跑回分子。
3. **分隔符交给循环或标准库**：C++ 用 `if (i > 1) res += "/";` 避免首尾多斜杠；Python 直接 `"/".join(map(str, nums[1:]))`。
4. **不做浮点求值**：本题只输出字符串，不必算值；真实值小到 $a_1/(a_2\cdots a_n) < 10^{-27}$、大到 $a_1a_3\cdots a_n \le 1000^9$，`double` 两侧都不安全。
5. **数字直接转字符串**：$a_i \le 1000$ 最多 4 位，`to_string` / `str` 不会输出科学计数法，输出中也不能出现空格。
6. **唯一性无需校验**：题面保证最优除法唯一，而构造对任意输入都给出那个唯一最优符号向量，所以不必枚举候选比较。
7. **先想「能否构造」再想「是否 DP」**：看到「最大表达式」容易条件反射写区间 DP；本题的符号向量分析一步到位给出 $O(n)$ 闭式答案。若想用 DP 交叉验证，就按 3.1 的 $f/g$ 双表各存最大/最小值，别只存最大值（商的最大值依赖分母的最小值）。

## 5. 正确性证明

记合法表达式 $E$ 的值为 $\mathrm{val}(E)$，符号向量 $e(E) = (e_1,\dots,e_n)$。

**引理 1（展开形式）**：任意合法表达式满足 $\mathrm{val}(E) = \prod_i a_i^{e_i}$，其中每个 $e_i \in \{+1,-1\}$。

**证明**：对表达式树归纳。单叶 $a_i$：$e_i = +1$。内部节点 $E = X/Y$：由归纳假设 $\mathrm{val}(X) = \prod a_i^{e_i(X)}$、$\mathrm{val}(Y) = \prod a_i^{e_i(Y)}$，故 $\mathrm{val}(E) = \prod a_i^{\,e_i(X)-e_i(Y)}$；$X$、$Y$ 的叶子集合不相交，指数是 $\pm1$ 之差，仍属 $\{\pm1\}$。∎

**引理 2（端点符号固定）**：任意合法表达式恒有 $e_1 = +1$、$e_2 = -1$。

**证明**：先证「子树最左叶子的相对指数为 $+1$」：对子树大小归纳，内部节点 $X/Y$ 的最左叶子就是 $X$ 的最左叶子，它在 $X$ 内为 $+1$，而 $X$ 在该节点处符号为正，故仍为 $+1$。于是全树最左叶子 $a_1$ 的指数为 $+1$。
再取包含 $a_1,a_2$ 的最小子树 $T$。子树叶子是连续区间，$T$ 极小迫使 $T$ 的左孩子只含 $a_1$、右孩子以 $a_2$ 为最左叶子（否则左孩子已含 $a_1,a_2$，与极小性矛盾）。$a_2$ 在右孩子内为 $+1$，在 $T$ 内翻为 $-1$；又 $T$ 含 $a_1$，而 $a_1$ 是全局最左叶子，故 $T$ 在通往根的路径上恒为左孩子、不再翻号。因此 $e_2 = -1$。∎

**引理 3（正号数上界）**：$n \ge 2$ 时，任意合法表达式的正号个数 $\mathrm{pos}(E) \le n-1$。

**证明**：证明更强的结论：对任意子树 $S$，$\mathrm{pos}(S) \le |S|$，且 $|S| \ge 2$ 时 $\mathrm{pos}(S) \le |S|-1$。单叶时 $\mathrm{pos} = 1 = |S|$。内部 $S = X/Y$：$X$ 的正号指数在 $S$ 中仍为正，$Y$ 的正号指数（在 $Y$ 内为正）在 $S$ 中翻成负，故 $\mathrm{pos}(S) = \mathrm{pos}(X) + \big(|Y| - \mathrm{pos}(Y)\big)$；由归纳 $\mathrm{pos}(X) \le |X|$，且 $Y$ 的最左叶子为正故 $\mathrm{pos}(Y) \ge 1$，于是 $\mathrm{pos}(S) \le |X| + |Y| - 1 = |S| - 1$。取 $S$ 为整棵树即得。∎

**引理 4（正号最多者严格最大）**：设 $e \ne e'$ 均满足 $e_1 = e'_1 = +1$、$e_2 = e'_2 = -1$，且 $\mathrm{pos}(e) = n-1$，则 $\mathrm{val}(e') < \mathrm{val}(e)$。

**证明**：由 $e_2 = -1$ 与 $\mathrm{pos}(e) = n-1$，$e$ 的正号集合只能是 $\{1,3,4,\dots,n\}$，即 $i \ne 2$ 时 $e_i = +1$。因 $e' \ne e$ 且 $e'_2 = -1$，必存在 $j \ge 3$ 使 $e'_j = -1$；同时不可能有 $e'_i = +1 > e_i$（$i \ne 2$ 处 $e_i$ 已是 $+1$）。于是差异只出现在 $e_i = +1,\, e'_i = -1$ 的位置 $i \in P \ni j$，且

$$\frac{\mathrm{val}(e)}{\mathrm{val}(e')} = \prod_{i \in P} a_i^{\,e_i - e'_i} = \prod_{i \in P} a_i^{2} \ge a_j^{2} \ge 2^2 = 4 > 1. \qquad \blacksquare$$

**定理**：返回串 $S^\star = a_1/(a_2/a_3/\cdots/a_n)$ 的值为 $\dfrac{a_1a_3\cdots a_n}{a_2}$，它是所有合法表达式中唯一的最大者。

**证明**：由引理 1 的展开，$S^\star$ 的符号向量为 $(+,-,+,\dots,+)$，正号数 $n-1$ 达到引理 3 的上界；由引理 4，它严格大于任何其他符号向量对应的表达式。而任一合法表达式都由引理 1 对应某个符号向量、由引理 2 固定端点符号，故不存在更大的方案。再论唯一性与括号最少性：$S^\star$ 中的那对括号不可省——去掉后 $a_2$ 变为乘数，值为 $a_1/(a_2a_3\cdots a_n) < \mathrm{val}(S^\star)$；括号内部不再有括号，因为左结合恰好生成 $(+,-,+,\dots,+)$ 对应的那棵树，再加括号只会冗余。因此 $S^\star$ 是去冗余括号后唯一的最优表达式。∎

> 💡 $n=1$ 无运算符，值即 $a_1$；$n=2$ 只有 $a_1/a_2$ 一种方案。代码的三个分支与定理边界一致。

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。三个分支至多各扫一遍数组拼接字符串，每个数最多 4 个字符，总字符数 $O(n)$，无排序、无回溯。
- **空间复杂度**：$O(n)$。返回串长度 $\Theta(n)$（含分隔符与括号）；除输出外只需常数个临时变量，C++ 的 `string` 扩容也仍是 $O(n)$ 量级。
- **对比**：Catalan 枚举 $O(C_{n-1}\cdot n)$（$n=10$ 约 $5\times10^4$ 次分数运算），区间 DP $O(n^3)$ 且需维护表达式串；闭式构造在常数与代码量上都占优，且不可能写错分支条件之外的逻辑。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    string optimalDivision(vector<int>& nums) {
        int n = (int)nums.size();
        if (n == 1) return to_string(nums[0]);                             // 无除号
        if (n == 2) return to_string(nums[0]) + "/" + to_string(nums[1]);  // 唯一方案
        string res = to_string(nums[0]) + "/(";
        for (int i = 1; i < n; ++i) {
            if (i > 1) res += "/";   // a2 紧贴左括号，其后每项前补一个 '/'
            res += to_string(nums[i]);
        }
        res += ")";
        return res;
    }
};
```

### Python

```python
class Solution:
    def optimalDivision(self, nums: List[int]) -> str:
        n = len(nums)
        if n == 1:
            return str(nums[0])
        if n == 2:
            return f"{nums[0]}/{nums[1]}"
        return f"{nums[0]}/({'/'.join(map(str, nums[1:]))})"
```

## 8. 边界情况与易错点

1. **$n = 1$**：只返回 `"7"`，既不能带 `/` 也不能带括号；返回 `"7/"`、`"7/()"` 都是 WA。
2. **$n = 2$**：唯一方案 `"7/3"`；写成 `"7/(3)"` 括号冗余，字符串严格比较同样 WA。
3. **括号范围错**：`"1000/(100)/10"`、`"1000/(100/10)/2"` 都不是最优（值 50 而非 200）；括号必须同时包住 $a_2$ 与 $a_n$。
4. **给 $a_1$ 加括号**：`"(1000)/(100/10/2)"`、外层再套 `(...)` 都不影响优先级，属冗余括号。
5. **用浮点自测**：$a_1/(a_2\cdots a_n)$ 可达 $10^{-27}$ 量级、$a_1a_3\cdots a_n$ 可达 $1000^9$，`double` 两侧都可能失真；自测应改用分数（`Fraction` / 有理数）精确比较。
6. **分隔符手写漏改**：循环里少一个 `/` 或多一个尾随 `/`，生成的串无法解析或含义改变——建议用 `join` 或统一的 `if (i > 1)` 保护。
7. **误判「必须 DP」**：$n \le 10$ 时区间 DP 也能过，但若把 DP 的最大/最小值配对写反（分子取最小），会在 $a_i$ 相等时偶发正确、随机数据上暴露；本题直接用闭式构造更稳。

**延伸思考**：

- **改成求最小值**：正号越少越好，答案是 $a_1/(a_2a_3\cdots a_n)$，即裸连除 `a₁/a₂/a₃/…/aₙ`（左结合），一个括号都不用。最大值与最小值正好落在同一约束（$e_1=+1,\ e_2=-1$）下符号向量的两个极端：$n-1$ 个正号对上 $1$ 个正号。
- **允许 $a_i = 0$ 或负数**：0 会让分母为零的表达式无定义；负数打破「正号越多值越大」的单调性（需按 $|a_i|$ 与符号分别讨论），引理 4 整条失效。
- **允许重排数组**：由 $\mathrm{val} = \prod_i a_i \big/ a_2^{2}$ 可知只需把**最小元素**放到 $a_2$ 位置，一次线性扫描即可，最优结构仍是「一个分母 + 其余全乘」。
- **$n$ 很大（如 $10^5$）**：答案串本身长 $O(n)$，构造仍是 $O(n)$；但若要求输出**数值**，就必须用大整数或取对数比较，浮点依旧不可用。
