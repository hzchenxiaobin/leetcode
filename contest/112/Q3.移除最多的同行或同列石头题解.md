# LeetCode 移除最多的同行或同列石头 题解

## 1. 题目概述

- **标题 / 题号**：移除最多的同行或同列石头（#947，medium）
- **链接**：https://leetcode.cn/problems/most-stones-removed-with-same-row-or-column/
- **来源**：LeetCode 第 112 场周赛 Q3
- **难度**：中等
- **标签**：深度优先搜索、并查集、图、哈希表

**题意**：平面上有 $n$ 块石头，坐标为 `stones[i] = [x_i, y_i]`，同一坐标至多一块。每次**移除**一块石头的前提是：**同一行或同一列上还存在其它（未被移除的）石头**。求最多能移除多少块。

**约束**：

- $1 \le stones.length \le 1000$
- $0 \le x_i, y_i \le 10^4$
- 没有两块石头在同一坐标

## 2. 示例

**示例 1**

```text
输入：stones = [[0,0],[0,1],[1,0],[1,2],[2,1],[2,2]]
输出：5
解释：6 块石头连成一片，可以依次移除 5 块，最后剩 [0,0]。
```

**示例 2**

```text
输入：stones = [[0,0],[0,2],[1,1],[2,0],[2,2]]
输出：3
解释：{[0,0],[0,2],[2,0],[2,2]} 这 4 块连成一片，可移除 3 块；
     [1,1] 孤立（同行同列都没有别的石头），一块也移不掉。
```

**示例 3**

```text
输入：stones = [[0,0]]
输出：0
解释：只有一块石头，没有同行/同列的伙伴，无法移除。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的想法是**搜索移除顺序**：每一步枚举"当前可移除的石头"，递归下去，取最大步数。状态数是"剩余石头集合"，$n = 1000$ 时是 $2^{1000}$ 级别，完全不可行。

退一步的贪心（"每次都移走度数最小的石头"）也没有明显正确性依据，容易构造反例。需要找**结构性的刻画**。

### 3.2 核心观察：行/列二分图，石头是边

![把「行」与「列」当节点，石头就是一条边](images/wc112_q3_bipartite.svg)

关键建模：把每个**行号**和每个**列号**都看成图中的一个**节点**（行节点、列节点分属两侧，构成二分图），每块石头 $(x, y)$ 看成连接"行 $x$"与"列 $y$"的**一条边**。

在这个模型下：

- "石头 $s$ 同行或同列还有别的石头" $\iff$ 边 $s$ 的某个端点上还连着**另一条边**；
- "移除石头" $\iff$ **删除这条边**（行、列节点保留）。

于是问题变成：**在一个无向图（二分图）中，最多能删掉多少条边，使得每次删除时被删的边至少与另一条边共用一个端点？**

对于**一个连通分量**（设它含 $k$ 条边、即 $k$ 块石头）：

- **上界**：不可能把 $k$ 条边全删光。最后剩下的那条边，其两个端点上已没有任何其它边，按规则不能删。所以最多删 $k-1$ 条。
- **可达**：$k - 1$ 条总能删到。在连通分量里取一棵**生成树**，从叶子开始按"后序"删边：删某条边时，它在树中的父节点方向上还有边（除非它是最后一条），因此该边至少有一个端点仍连着别的边，合法。

所以每个连通分量贡献 $k-1$，总答案

$$\boxed{\;\text{ans} = n - \#\{\text{连通分量}\}\;}$$

这与示例 2 完全吻合：5 块石头、2 个连通分量 ⇒ $5 - 2 = 3$。

### 3.3 算法流程：并查集

![removeStones：并查集合并行与列](images/wc112_q3_flow.svg)

```text
1. 并查集，节点编号：
      行 x  → 编号 x            (0 ≤ x ≤ 10^4)
      列 y  → 编号 ~y（负数）    （避免与行号冲突）
2. for (x, y) in stones:
       union(x, ~y)              // 这块石头把它的行与列连起来
3. 统计所有石头所在行的根，去重得到连通分量数 C
4. return n - C
```

列用 `~y`（即 $-y-1$）而不是 `y + 10001` 也可以，二者都行；`~y` 的好处是不依赖值域常数。

### 3.4 示例演算

![示例 2：两个分量，各留一块](images/wc112_q3_example.svg)

对 `stones = [[0,0],[0,2],[1,1],[2,0],[2,2]]`：

| 石头 | union 操作 | 说明 |
|------|-----------|------|
| (0,0) | 行0 ↔ 列0 | 新建两个节点 |
| (0,2) | 行0 ↔ 列2 | 列2 并入分量 A |
| (1,1) | 行1 ↔ 列1 | 新建分量 B |
| (2,0) | 行2 ↔ 列0 | 行2 并入分量 A |
| (2,2) | 行2 ↔ 列2 | 已在同一分量，无变化 |

最终分量 A = {行0, 行2, 列0, 列2}（4 块石头），分量 B = {行1, 列1}（1 块石头）。$C = 2$，答案 $= 5 - 2 = 3$，与示例一致。

## 4. 算法细节

1. **节点编号**：行直接用 $x$；列用 `~y`（负数）或 `y + 10^5`。用 `~y` 时所有列号 $\in [-10001, -1]$，与行号 $[0,10^4]$ 不冲突。
2. **只对出现的行列建点**：不需要开 $2\times10^4$ 的数组，用哈希表按需创建即可（坐标范围小，开数组也行）。
3. **路径压缩**：并查集用"路径减半"或递归压缩，均摊复杂度 $O(\alpha(n))$。
4. **统计分量**：只需对**每块石头的行节点**求根并去重——因为任何列节点都与某块石头的行节点在同一分量，所以不会漏掉分量。
5. **答案公式**：`n - 分量数`，而不是 `n - 1`（多分量时每分量各留一块）。
6. **DFS 等价写法**：也可以从每块石头出发 DFS 遍历同行/同列的石头上标记，复杂度 $O(n^2)$（$n\le1000$ 时 $10^6$ 也能过），并查集更通用。
7. **不要真的维护"剩余石头"**：本题只需计数，删除顺序的构造不必输出。

## 5. 正确性证明

**建模**：构造二分图 $G = (R \cup C, E)$，$R$ 为出现过的行号集合，$C$ 为出现过的列号集合，$E = \{(x, y) : (x,y) \in stones\}$（行 $x$ 与列 $y$ 之间的边）。

**引理 1（可删性等价）**：石头 $s = (x,y)$ 在当前局面下可移除 $\iff$ 边 $(x,y)$ 在当前的 $G$ 中与另一条边共享端点。

**证明**：石头 $s$ 可移除 $\iff$ 存在另一块石头 $s'$ 满足 $s'$ 与 $s$ 同行或同列 $\iff$ 存在边 $(x,y')$ 或 $(x',y)$，即与 $(x,y)$ 共享端点。∎

**引理 2（分量上界）**：含 $k \ge 1$ 条边的连通分量最多删除 $k-1$ 条边。

**证明**：若删光 $k$ 条边，考虑**最后**被删的那条边 $e$。删除它时图中只剩 $e$ 这一条边（该分量的其它边都已删除），$e$ 的两个端点均无其它边相连，由引理 1 不可删，矛盾。故最多删 $k-1$ 条。∎

**引理 3（分量可达）**：含 $k \ge 1$ 条边的连通分量可以删除 $k-1$ 条边。

**证明**：只需构造一个"始终保持单连通、每次只删 1 条边、直到只剩 1 条边"的过程。设当前分量连通且剩余边数 $m \ge 2$，分两种情形：

1. **含有环**：取环上任一条边 $e$。$e$ 的两个端点在环上都有另一条边，故 $e$ 与别的边共享端点（可删）；且删掉环边后图**仍连通**，$m$ 减一。
2. **是一棵树**（无环）：取任一叶子节点 $v$，其唯一关联边 $e = (v,u)$。因 $m\ge2$ 而树有 $m$ 条边即 $m+1$ 个节点，$m+1 \ge 3$，故 $u$ 在树中的度数 $\ge 2$（否则树只有 $\{u,v\}$ 两个点、$m=1$），即 $e$ 与另一条边共享端点 $u$，可删；删去叶子边后剩下的图（树去掉一条叶子边）仍连通，$m$ 减一。

两种情形都能让"剩余图连通且边数减一"，从这个新的连通分量继续，直到 $m=1$ 为止，共删除 $k-1$ 条边。∎

**定理**：最多可移除的石头数为 $n - C$，其中 $C$ 是 $G$ 的连通分量数。

**证明**：

- **上界**：每个分量独立，由引理 2 分量 $i$ 最多删 $k_i-1$ 条，故总数 $\le \sum (k_i-1) = n - C$。
- **可达**：由引理 3，每个分量都能删到 $k_i - 1$ 条，各分量互不影响（不同分量的石头既不同行也不同列，删除顺序可任意交错），故总可达 $n-C$。
- 两边合并即得结论；并查集算出的正是 $C$（连通分量数），故 `n - C` 正确。∎

## 6. 复杂度分析

- **时间**：$O(n\,\alpha(A))$，$A$ 为不同行/列节点数（$\le 2n$）。每块石头两次 `find` 一次 `union`，路径压缩下均摊近似 $O(1)$。
- **空间**：$O(A) = O(n)$ 的并查集哈希表（若开数组则 $O(\text{值域})$）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    unordered_map<int, int> par;

    int findRoot(int x) {
        if (!par.count(x)) { par[x] = x; return x; }
        if (par[x] != x) par[x] = findRoot(par[x]);   // 路径压缩
        return par[x];
    }

    int removeStones(vector<vector<int>>& stones) {
        for (auto& s : stones) {
            int a = findRoot(s[0]);        // 行 s[0]
            int b = findRoot(~s[1]);       // 列 s[1]，用 ~y 与行号区分
            if (a != b) par[a] = b;
        }
        unordered_set<int> roots;
        for (auto& s : stones) roots.insert(findRoot(s[0]));
        return (int)stones.size() - (int)roots.size();
    }
};
```

### Python

```python
class Solution:
    def removeStones(self, stones: list[list[int]]) -> int:
        parent = {}

        def find(x: int) -> int:
            if x not in parent:
                parent[x] = x
                return x
            while parent[x] != x:          # 路径压缩（迭代）
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x

        for x, y in stones:
            a, b = find(x), find(~y)       # 行 x 与列 y 合并（列用 ~y 区分）
            if a != b:
                parent[a] = b

        roots = {find(x) for x, _ in stones}
        return len(stones) - len(roots)
```

## 8. 边界情况与易错点

1. **单块石头**：$n=1$，$C=1$，答案 $0$——不能移除唯一一块。
2. **答案不是 $n-1$**：多分量时要按分量数减（示例 2 的答案是 3 而不是 4）。
3. **行列编号冲突**：若把列也编号成 $y$，当 $y = x$ 时会与行节点误合并（例如 `[[1,1]]` 会被当成自环）。必须用 `~y` 或 `y + 10^5` 区分。
4. **同一坐标无重复**：题面保证，所以无需处理重边；若允许重边，公式仍成立但要先合并重复坐标。
5. **列坐标为 0**：`~0 = -1`，是合法编号；不要写成 `-y`（`-0 = 0` 会与行 0 冲突！）。
6. **统计分量用行节点**：若用列节点统计，同样正确（只要统一），但千万不要混用行、列分别去重再相加。
7. **DFS 写法的复杂度**：按行/列分组后两两连边会构造 $O(n^2)$ 条边，$n=1000$ 时 $10^6$ 尚可，但并查集更简洁。
8. **哈希表查找的常数**：C++ 的 `unordered_map` 在小数据下常数偏大，可换成 `vector<int> par(20001, -1)` 的数组版（行 $0..10^4$、列 $10^5..$），速度更快。
