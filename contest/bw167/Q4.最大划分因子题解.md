# LeetCode 最大划分因子 题解

## 1. 题目概述

- **标题 / 题号**：最大划分因子（#3710，hard）
- **链接**：https://leetcode.cn/problems/maximum-partition-factor/
- **来源**：LeetCode 第 167 场双周赛 Q4
- **难度**：困难
- **标签**：二分查找、图、深度优先搜索、广度优先搜索、并查集、数组

**题意**：给定平面上的 $n$ 个点 $points[i] = [x_i, y_i]$，曼哈顿距离为 $|x_i - x_j| + |y_i - y_j|$。要把这 $n$ 个点分成**恰好两个非空组**，一个划分的**划分因子**定义为「位于同一组内的所有无序点对之间的**最小**曼哈顿距离」。求所有合法划分中划分因子的**最大值**。

补充规定：单元素组没有组内点对；当 $n = 2$（两组各 1 个点）时没有组内点对，划分因子记为 0。

**约束**：

- $2 \le points.length \le 500$
- $-10^8 \le x_i, y_i \le 10^8$

## 2. 示例

**示例 1**

```text
输入：points = [[0,0],[0,2],[2,0],[2,2]]
输出：4
解释：分成 {[0,0],[2,2]} 与 {[0,2],[2,0]}：
     第一组唯一对距离 |0-2|+|0-2| = 4；第二组 |0-2|+|2-0| = 4；
     划分因子 min(4,4) = 4，这是最大值。
```

**示例 2**

```text
输入：points = [[0,0],[0,1],[10,0]]
输出：11
解释：分成 {[0,1],[10,0]} 与 {[0,0]}：
     第一组唯一对距离 |0-10|+|1-0| = 11；第二组是单点组，无组内点对。
     划分因子 11。
```

**示例 3（补充例子）**

```text
输入：points = [[0,0],[0,0]]
输出：0
解释：n = 2，唯一划分是两组各一个点，无组内点对，划分因子为 0。
```

## 3. 解题思路

### 3.1 暴力思路

划分方案共 $2^{n-1}-1$ 种（$n=500$ 时是天文数字），每种方案还要 $O(n^2)$ 求组内最小距离，完全不可行。即便只想「所有点对距离」也要 $O(n^2)$，这部分是必须做的（$n=500$ 时约 12.5 万对）。

暴力的价值在于提示我们：**答案一定是某两个点之间的距离**（或 0），因为划分因子是若干对距离的最小值。

### 3.2 核心观察：把「最大化」转成「判定 + 二分」

![判定问题：距离小于 D 的点对必须分居两组，即图 G_D 必须可二分](images/bw167_q4_bipartite_check.svg)

换个角度问：**给定 $D$，是否存在划分使得所有同组点对的距离都 $\ge D$？** 记这个判定为 $P(D)$。

构造一张图 $G_D$：顶点是点，**若两点距离 $< D$ 就连一条边**。则

$$P(D) \text{ 成立} \iff \text{存在把 } G_D \text{ 正常二染色的方案（相邻点异色）}.$$

理由：划分因子 $\ge D$ 等价于「距离 $< D$ 的每一对都必须分属不同组」，这正是二染色对「边」的要求。于是判定退化为**二分图判定**，用 BFS/DFS 染色即可，$O(n^2)$（无需真的建边，直接枚举点对）。

而 $P(D)$ 关于 $D$ **单调**：$D$ 变大时边集只会增加（距离 $< D$ 的对变多），二染色只会更难，所以 $P$ 呈现「前真后假」的形状，可以二分答案。

由于答案必是某对点的距离（或 0），把所有 $O(n^2)$ 个距离去重排序，在其上二分即可。

![二分答案：候选值取所有点对距离，P(D) 前真后假](images/bw167_q4_binary_search.svg)

### 3.3 算法流程

```text
1. 若 n == 2：直接返回 0（唯一划分没有组内点对）
2. 枚举所有点对，收集曼哈顿距离，去重排序得到候选数组 cand
3. 在 cand 上二分：
       lo = 0, hi = len(cand) - 1, ans = 0
       while lo <= hi:
             mid = (lo + hi) // 2
             若 bipartite(cand[mid])：ans = cand[mid]；lo = mid + 1
             否则：hi = mid - 1
4. 返回 ans

bipartite(D)：
   对每个未染色的点做 DFS/BFS 染色；在枚举「u 的邻居」时
   现场计算 dist(u, v) < D 判定，不预建邻接表
   若发现某条边两端同色 → 返回 false
   全部染色完成 → 返回 true
```

### 3.4 示例演算

![示例 1 的四个候选值与染色结果](images/bw167_q4_example_walkthrough.svg)

示例 1：四个点 $A(0,0), B(0,2), C(2,0), D(2,2)$，两两距离：

| 点对 | 距离 |
|------|------|
| A–B | 2 |
| A–C | 2 |
| A–D | 4 |
| B–C | 4 |
| B–D | 2 |
| C–D | 2 |

候选值 $\{0, 2, 4\}$（0 用于兜底）。

- $D = 2$：边集为空（没有距离 $< 2$ 的对）→ 可二分 → 成立；
- $D = 4$：边集为 4 条长度为 2 的边（A–B、A–C、B–D、C–D），构成一个 4-环 $A\text{–}B\text{–}D\text{–}C\text{–}A$，仍可二染色 → 成立；
- 于是答案取到候选最大值 4 ✓。

示例 2：三点 $A(0,0), B(0,1), C(10,0)$，距离 $AB = 1$、$AC = 10$、$BC = 11$，候选 $\{0,1,10,11\}$。

- $D = 10$：只有边 $A$–$B$ → 二分图 ✓；
- $D = 11$：边 $A$–$B$、$A$–$C$，是一条链 → 二分图 ✓；
- 答案 11 ✓（$D$ 再大也没有候选值了）。

## 4. 算法细节

1. **$n = 2$ 必须特判为 0**：若按判定流程，$P(d_0)$（$d_0$ 是两点距离）对应边集为空、可二分，会错误地返回 $d_0$。原因是「两组各 1 个点」没有组内点对，划分因子按定义为 0，而 $P$ 的语义（存在划分使同组距离 $\ge D$）在 $n=2$ 时对任何 $D$ 都平凡成立，**不能**把「因子 $\ge D$」与「$P(D)$」划等号。$n \ge 3$ 时必有一组含 $\ge 2$ 个点，两者才等价。
2. **不预建邻接表**：边数可达 $O(n^2)$，每次判定都重建邻接表开销大；直接双重循环现场算距离，$O(n^2)$ 判定、常数极小。
3. **距离用 64 位**：坐标差最大 $2 \times 10^8$，曼哈顿距离最大 $4 \times 10^8$，`int` 其实够，但求和时 `abs(x1-x2) + abs(y1-y2)` 若无溢出风险也不必用 `long long`——为通用性统一 `long long` 更稳。
4. **候选数组含 0**：答案可能是 0（所有点重合）。把 0 加入候选并把 `ans` 初始化为 0 最省心。
5. **单调性方向**：$D$ 增大 → 约束变多 → 可行性变差，所以二分是「找最后一个可行」。
6. **染色实现**：用 `vector<int> color(n, -1)`，栈式 DFS；`color[v] == color[u]` 即冲突。多连通分量要全部染完才能返回 true。
7. **两点重合**：若存在两个点坐标完全相同，它们距离为 0，必须分居两组（否则同组最小距离为 0）；判定图里 0 距离的对在任何 $D > 0$ 时都是边，正好强制异组。若 $D = 0$ 则没有约束。
8. **两个组的非空性**：$n \ge 3$ 且所求 $D$ 使得图有边时，染色两类都非空；若图无边（所有对距离 $\ge D$），任意划一个点到另一组即可让两组非空，不影响因子下界。因此只要 $P(D)$ 成立就一定能取到两个非空组。

## 5. 正确性证明

**引理 1（判定等价，$n \ge 3$）**：设 $D \ge 0$。存在划分使两个组都非空且划分因子 $\ge D$，当且仅当图 $G_D$（边集为所有距离 $< D$ 的点对）是二分图。

**证明**：（$\Rightarrow$）设划分为 $(S, \bar S)$ 且因子 $\ge D$。任取 $G_D$ 的一条边 $\{u,v\}$，其距离 $< D$，若 $u,v$ 同组则同组距离 $< D$，与因子 $\ge D$ 矛盾，故 $u,v$ 异组。于是「按组染色」就是 $G_D$ 的一个正常二染色，$G_D$ 是二分图。
（$\Leftarrow$）设 $G_D$ 有正常二染色 $c: V \to \{0,1\}$。取 $S = \{v : c(v) = 0\}$、$\bar S = \{v : c(v) = 1\}$。任取同组的 $u,v$，若距离 $< D$，则 $G_D$ 有边 $\{u,v\}$，染色要求异色，与同组矛盾；故同组所有点对距离 $\ge D$。又 $n \ge 3$ 时两组中至少一组含 $\ge 2$ 个点（若两组都只有 1 个点则点数 $\le 2$），故因子定义为「组内点对最小值」而非空值，且 $\ge D$。若 $G_D$ 无边，把任意一个点单独划出即成两组非空，同组点对距离均 $\ge D$。∎

**引理 2（单调性）**：若 $D_1 \le D_2$ 且 $P(D_2)$ 成立，则 $P(D_1)$ 成立。

**证明**：$D_1 \le D_2$ 蕴含「距离 $< D_1$」的对集合是「距离 $< D_2$」的子集，故 $G_{D_1}$ 是 $G_{D_2}$ 的子图。二分图的所有子图仍是二分图，故 $G_{D_1}$ 二分，由引理 1 得 $P(D_1)$。∎

**引理 3（答案在候选集中）**：设最优划分为因子 $f$，则 $f = 0$ 或 $f$ 等于某对点的距离。

**证明**：若某一组含 $\ge 2$ 个点，$f$ 是该组内所有点对距离的最小值，故等于某个点对距离；若两组都是单点（仅 $n=2$），$f = 0$。∎

**定理**：算法返回最大可能的划分因子。

**证明**：设最优因子为 $f$。由引理 3，$f$ 属于候选集（$f=0$ 时 0 在候选集中）。由引理 1，$P(f)$ 成立（最优划分本身就是见证）。对候选集中任何 $D > f$，若 $P(D)$ 成立则由引理 1 存在因子 $\ge D > f$ 的划分，与最优性矛盾，故 $P(D)$ 不成立。因此 $f$ 恰是候选集中满足 $P$ 的最大值。由引理 2，满足 $P$ 的候选值构成前缀，二分查找（找最后一个成立的）必命中 $f$。故输出为最大划分因子。∎

## 6. 复杂度分析

- **时间**：$O(n^2 \log n)$。枚举点对求距离 $O(n^2)$；排序去重 $O(n^2 \log n)$；二分 $O(\log n^2) = O(\log n)$ 轮，每轮二分图判定 $O(n^2)$，合计 $O(n^2 \log n)$。$n = 500$ 时约 $2.5 \times 10^5 \times 18 \approx 4.5 \times 10^6$ 次操作。
- **空间**：$O(n^2)$ 存候选距离（至多 $\binom{n}{2} \approx 1.25 \times 10^5$ 个），加染色数组 $O(n)$。若改为对整数域直接二分（值域 $4 \times 10^8$，约 29 轮），空间可降到 $O(n)$，但每轮判定更多。

## 7. 参考代码

### C++

```cpp
class Solution {
    vector<vector<int>> pts;

    long long dist(int i, int j) {
        return (long long)llabs((long long)pts[i][0] - pts[j][0]) +
               (long long)llabs((long long)pts[i][1] - pts[j][1]);
    }

    // 判断图 G_D（边：距离 < D）是否二分图
    bool bipartite(long long D) {
        int n = (int)pts.size();
        vector<int> color(n, -1);
        vector<int> stk;
        for (int s = 0; s < n; s++) {
            if (color[s] != -1) continue;
            color[s] = 0;
            stk.push_back(s);
            while (!stk.empty()) {
                int u = stk.back();
                stk.pop_back();
                for (int v = 0; v < n; v++) {
                    if (v == u || dist(u, v) >= D) continue;
                    if (color[v] == -1) {
                        color[v] = color[u] ^ 1;
                        stk.push_back(v);
                    } else if (color[v] == color[u]) {
                        return false;
                    }
                }
            }
        }
        return true;
    }

public:
    int maxPartitionFactor(vector<vector<int>>& points) {
        int n = (int)points.size();
        if (n == 2) return 0;
        pts = points;
        vector<long long> cand;
        cand.push_back(0);
        for (int i = 0; i < n; i++)
            for (int j = i + 1; j < n; j++) cand.push_back(dist(i, j));
        sort(cand.begin(), cand.end());
        cand.erase(unique(cand.begin(), cand.end()), cand.end());
        int lo = 0, hi = (int)cand.size() - 1;
        long long ans = 0;
        while (lo <= hi) {
            int mid = (lo + hi) / 2;
            if (bipartite(cand[mid])) {
                ans = cand[mid];
                lo = mid + 1;
            } else {
                hi = mid - 1;
            }
        }
        return (int)ans;
    }
};
```

### Python

```python
class Solution:
    def maxPartitionFactor(self, points: list[list[int]]) -> int:
        n = len(points)
        if n == 2:
            return 0

        def dist(i: int, j: int) -> int:
            return abs(points[i][0] - points[j][0]) + abs(points[i][1] - points[j][1])

        def bipartite(D: int) -> bool:
            color = [-1] * n
            for s in range(n):
                if color[s] != -1:
                    continue
                color[s] = 0
                stack = [s]
                while stack:
                    u = stack.pop()
                    for v in range(n):
                        if v == u or dist(u, v) >= D:
                            continue
                        if color[v] == -1:
                            color[v] = color[u] ^ 1
                            stack.append(v)
                        elif color[v] == color[u]:
                            return False
            return True

        cand = sorted({0} | {dist(i, j) for i in range(n) for j in range(i + 1, n)})
        lo, hi, ans = 0, len(cand) - 1, 0
        while lo <= hi:
            mid = (lo + hi) // 2
            if bipartite(cand[mid]):
                ans = cand[mid]
                lo = mid + 1
            else:
                hi = mid - 1
        return ans
```

## 8. 边界情况与易错点

1. **$n = 2$ 返回 0**：这是本题最容易漏的特判。不要指望二分自然给出 0。
2. **$n = 3$**：三点划分只能是「2 + 1」，因子就是那对点之间的距离，故答案是三点间**最大**的成对距离？不对——要取**最优**划分，即选哪两点同组，使该距离最大，所以答案 = 三对距离中的**最大值**。可用示例 2 校验（1、10、11 中的最大值 11 ✓）。
3. **候选值必须包含 0**：全部点重合时答案为 0；若候选集只放正距离，会返回错误的大值。
4. **坐标差可能为负**：`abs` 要用 `llabs` 或先转 `long long` 再取绝对值（C++ 里 `abs(int)` 在差为 $-2 \times 10^8$ 时没问题，但 `long long` 版本更安全）。
5. **判定用 `< D` 而不是 `<= D`**：因子是「最小值」，只有**严格小于** $D$ 的对才必须异组；用 `<=` 会把等于 $D$ 的对也强制拆开，导致答案偏大。
6. **染色要覆盖所有连通分量**：漏染一个分量就会漏判冲突。
7. **二分的边界**：`lo = mid + 1` 只有在判定成立时才可推进；`ans` 初值 0 保证无解时返回 0（实际 $D=0$ 恒成立）。
8. **复杂度常数**：每轮判定做 $O(n^2)$ 次距离计算，若预存距离矩阵（$500 \times 500$ 的 `int`，约 1MB）可以把每轮常数降一半，是常见的加速手段。
