# LeetCode 最长斐波那契子数组 题解

## 1. 题目概述

- **标题 / 题号**：最长斐波那契子数组（#3708，medium）
- **链接**：https://leetcode.cn/problems/longest-fibonacci-subarray/
- **来源**：LeetCode 第 167 场双周赛 Q2
- **难度**：中等
- **标签**：数组、动态规划（线性扫描）

**题意**：给定正整数数组 $nums$。若一个连续序列从第三项起，每一项都等于前两项之和，则称它为**斐波那契**的。求 $nums$ 中最长斐波那契**子数组**的长度。

注意：长度为 1 或 2 的子数组**恒为**斐波那契，所以答案至少是 2。

**约束**：

- $3 \le nums.length \le 10^5$
- $1 \le nums[i] \le 10^9$

## 2. 示例

**示例 1**

```text
输入：nums = [1,1,1,1,2,3,5,1]
输出：5
解释：最长的是 nums[2..6] = [1,1,2,3,5]：1+1=2、1+2=3、2+3=5。
     （nums[0..6] = [1,1,1,1,2,3,5] 不满足，因为 1+1 ≠ 1。）
```

**示例 2**

```text
输入：nums = [5,2,7,9,16]
输出：5
解释：整个数组都是斐波那契：5+2=7、2+7=9、7+9=16。
```

**示例 3**

```text
输入：nums = [1000000000,1000000000,1000000000]
输出：2
解释：1e9 + 1e9 = 2e9 ≠ 1e9，第三项不满足；最长只能取长度为 2 的任意相邻两项。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有子数组（$O(n^2)$ 个），对每个子数组扫一遍检查是否斐波那契（$O(n)$），总复杂度 $O(n^3)$；用「前缀和 + 递推」也只能降到 $O(n^2)$。$n = 10^5$ 时 $O(n^2)$ 就已经不可接受，必须做到 $O(n)$。

### 3.2 核心观察：斐波那契性是「逐项递推」的，可以增量维护

![斐波那契子数组的链式递推](images/bw167_q2_fib_chain.svg)

定义条件

$$\text{ok}(i) :\quad nums[i] = nums[i-1] + nums[i-2] \qquad (i \ge 2).$$

一个子数组 $nums[l..r]$（$r - l + 1 \ge 3$）是斐波那契的，当且仅当**所有** $i \in [l+2, r]$ 都满足 $\text{ok}(i)$——这是定义的直接转写，因为每个 $i \ge l+2$ 都要求「$i$ 等于前两项之和」。

于是可以定义 $len[i]$ = 「以 $i$ 结尾的最长斐波那契子数组长度」，得到极简的转移：

$$len[0] = 1,\quad len[1] = 2,\quad len[i] = \begin{cases} len[i-1] + 1, & \text{ok}(i) \\ 2, & \text{否则} \end{cases}$$

理由：若 $\text{ok}(i)$ 成立，把「以 $i-1$ 结尾的最长斐波那契子数组」向右延长一项即可（它内部所有条件本来就成立）；若 $\text{ok}(i)$ 不成立，任何长度 $\ge 3$ 且以 $i$ 结尾的子数组都必然包含 $i-2, i-1, i$ 这三项，从而违反定义，故只能取长度 2。

答案就是 $\max_i len[i]$。

### 3.3 算法流程

![算法流程：一遍扫描维护以 i 结尾的最长长度](images/bw167_q2_algorithm_flow.svg)

```text
1. 若 n <= 2：返回 n
2. best = 2；cur = 2
3. for i = 2 .. n-1:
       若 nums[i] == nums[i-1] + nums[i-2]: cur = cur + 1
       否则:                                cur = 2
       best = max(best, cur)
4. 返回 best
```

全程只用一个 `cur` 变量滚动，空间 $O(1)$。

### 3.4 示例演算

![示例 1 的逐项判定与 cur 变化](images/bw167_q2_example_walkthrough.svg)

示例 1：`nums = [1,1,1,1,2,3,5,1]`

| $i$ | $nums[i]$ | $nums[i-1]+nums[i-2]$ | $\text{ok}(i)$ | $cur$ | $best$ |
|-----|-----------|------------------------|----------------|-------|--------|
| 0 | 1 | — | — | 1 | 2 |
| 1 | 1 | — | — | 2 | 2 |
| 2 | 1 | 1+1 = 2 | ✗ | 2 | 2 |
| 3 | 1 | 1+1 = 2 | ✗ | 2 | 2 |
| 4 | 2 | 1+1 = 2 | ✓ | 3 | 3 |
| 5 | 3 | 1+2 = 3 | ✓ | 4 | 4 |
| 6 | 5 | 2+3 = 5 | ✓ | 5 | **5** |
| 7 | 1 | 3+5 = 8 | ✗ | 2 | 5 |

答案 5，对应子数组 $nums[2..6] = [1,1,2,3,5]$，与题面一致。示例 2 则是 5 次判定全部成立，长度涨到 5。

## 4. 算法细节

1. **加法溢出**：$nums[i] \le 10^9$，两项之和最大 $2 \times 10^9$，超过 `int` 上界 $2^{31}-1 \approx 2.147 \times 10^9$ 吗？$2 \times 10^9 < 2.147 \times 10^9$，勉强不溢出，但**不要赌**——用 `long long` 更安全（Python 本身无此问题）。
2. **长度 1、2 恒合法**：不需要任何判定，直接以 2 作为 `cur` 的初值；$n \ge 3$ 保证至少有一对相邻元素。
3. **`ok(i)` 只看三项**：不要写成「检查整个窗口」，那是 $O(n^2)$。斐波那契性是可增量的。
4. **重置为 2 而不是 1**：失败时以 $i$ 结尾的最长合法长度仍是 2（$nums[i-1..i]$），因为任意两项都合法。这是本题最容易写错的一处。
5. **`best` 初值为 2**：即使全部判定失败，答案也是 2。
6. **严格递增性不需要**：题面只要求正整数，不要求递增；例如 `[2,1,3,4,7]` 也是斐波那契（$2+1=3$）。

## 5. 正确性证明

**引理 1（定义的条件化）**：对 $r - l + 1 \ge 3$，子数组 $nums[l..r]$ 是斐波那契的 $\iff$ 对所有 $i \in [l+2, r]$ 有 $\text{ok}(i)$。

**证明**：按定义，子数组的第 $j$ 项（$j \ge 3$，对应原下标 $i = l + j - 1$）等于前两项之和，即 $nums[i] = nums[i-1] + nums[i-2]$，也就是 $\text{ok}(i)$。遍历 $j = 3, \dots, r-l+1$ 即得 $i = l+2, \dots, r$。反之亦然。∎

**引理 2（转移正确）**：对 $i \ge 2$，以 $i$ 结尾的最长斐波那契子数组长度满足 $len[i] = len[i-1] + 1$（当 $\text{ok}(i)$ 成立）或 $len[i] = 2$（否则）。

**证明**：若 $\text{ok}(i)$ 成立，设以 $i-1$ 结尾的最长斐波那契子数组为 $nums[l..i-1]$（长度 $len[i-1]$）。则 $nums[l..i]$ 内部所有条件和原来相同，再加上 $\text{ok}(i)$，由引理 1 它是斐波那契的，故 $len[i] \ge len[i-1] + 1$。另一方面，任何以 $i$ 结尾、长度 $\ge 3$ 的斐波那契子数组去掉末项后是以 $i-1$ 结尾的斐波那契子数组（长度减 1），故 $len[i] - 1 \le len[i-1]$，即 $len[i] \le len[i-1] + 1$。两者相等。

若 $\text{ok}(i)$ 不成立，任何长度 $\ge 3$ 且以 $i$ 结尾的子数组都含 $i-2,i-1,i$，由引理 1 与 $\text{ok}(i)$ 失败可知它不是斐波那契的；而长度 2 恒合法，故 $len[i] = 2$。∎

**定理**：算法输出的 `best` 等于 $nums$ 中最长斐波那契子数组的长度。

**证明**：由引理 2，算法维护的 `cur` 逐项等于 $len[i]$，`best` 是 $\max_{0 \le i \le n-1} len[i]$。而任一最长斐波那契子数组必以某个下标结尾，故其长度不超过 `best`；反之 $len[i]$ 对应的子数组真实存在，故 `best` 可达。∎

## 6. 复杂度分析

- **时间**：$O(n)$。一次线性扫描，每个下标准一次加法与比较。
- **空间**：$O(1)$。只用 `cur`、`best` 两个变量（不存 $len$ 数组）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int longestSubarray(vector<int>& nums) {
        int n = (int)nums.size();
        if (n <= 2) return n;
        int best = 2, cur = 2;
        for (int i = 2; i < n; i++) {
            long long sum = (long long)nums[i - 1] + nums[i - 2];
            if (nums[i] == sum) cur++;
            else cur = 2;
            best = max(best, cur);
        }
        return best;
    }
};
```

### Python

```python
class Solution:
    def longestSubarray(self, nums: list[int]) -> int:
        n = len(nums)
        if n <= 2:
            return n
        best = cur = 2
        for i in range(2, n):
            if nums[i] == nums[i - 1] + nums[i - 2]:
                cur += 1
            else:
                cur = 2
            best = max(best, cur)
        return best
```

## 8. 边界情况与易错点

1. **失败时重置为 2**：写成 1 会让示例 1 的答案变成 4（在 $i=2$、$i=3$ 连续失败后从 1 重新起算），这是最典型的 WA。
2. **加法溢出**：用 `long long` 或 Python 大整数；`int` 在 $10^9+10^9$ 时虽然不溢出，但一旦数据范围放宽就会踩坑。
3. **$n = 3$**：至少有一组三元组要判定；全部失败时答案是 2。
4. **全相同元素**：`[5,5,5,5]` 中 $5+5 = 10 \ne 5$，答案 2。
5. **首项为 0 的变体**：本题 $nums[i] \ge 1$，若允许 0，则 `[0,0,0]` 仍是斐波那契（$0+0=0$），代码不用改。
6. **不需要判断递增**：斐波那契性只由递推关系决定，`[2,1,3]` 合法。
