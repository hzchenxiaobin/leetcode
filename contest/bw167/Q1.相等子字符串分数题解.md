# LeetCode 相等子字符串分数 题解

## 1. 题目概述

- **标题 / 题号**：相等子字符串分数（#3707，easy）
- **链接**：https://leetcode.cn/problems/equal-score-substrings/
- **来源**：LeetCode 第 167 场双周赛 Q1
- **难度**：简单
- **标签**：字符串、前缀和

**题意**：给定小写字母字符串 $s$。字符串的**得分**定义为所有字符在字母表中位置之和（`'a'`=1，`'b'`=2，…，`'z'`=26）。问是否存在下标 $i$（$0 \le i < n-1$），使得把 $s$ 拆成两个**非空**子串 $s[0..i]$ 与 $s[i+1..n-1]$ 后，两段得分**相等**。存在返回 `true`，否则返回 `false`。

**约束**：

- $2 \le s.length \le 100$
- $s$ 只包含小写英文字母

## 2. 示例

**示例 1**

```text
输入：s = "adcb"
输出：true
解释：在下标 i = 1 处拆分：左 "ad" 得分 1+4 = 5，右 "cb" 得分 3+2 = 5，相等。
```

**示例 2**

```text
输入：s = "bace"
输出：false
解释：i=0：2 与 1+3+5=9；i=1：2+1=3 与 3+5=8；i=2：2+1+3=6 与 5。
     三种拆分都不等，返回 false。
```

**示例 3（补充例子）**

```text
输入：s = "aaaa"
输出：true
解释：i = 1 时左右各 "aa"，得分都是 2，相等。
```

## 3. 解题思路

### 3.1 暴力思路

枚举拆分点 $i = 0, 1, \dots, n-2$，对每个 $i$ 分别求左段与右段的字符和。求和可以每次扫一遍，单次 $O(n)$，总共 $O(n^2)$；$n \le 100$ 时完全够用。但既然总和固定，右段的和可以直接由「总和 − 左段和」得到，于是每个拆分点只需 $O(1)$。

### 3.2 核心观察：左右两段互补

![总和固定：左段 + 右段 = 总分，判等即判「左段 = 总分/2」](images/bw167_q1_score_balance.svg)

设总得分为 $S$（常量）。对拆分点 $i$，设左段得分为 $L_i$，则右段得分必为 $S - L_i$。于是

$$L_i = S - L_i \iff 2 L_i = S .$$

两种等价的实现：

1. **前缀和**：预计算前缀和数组 $P$，$L_i = P[i+1]$，判 $2P[i+1] = P[n]$；
2. **在线**：先求总和 $S$，再从左往右累加 $L$，每加一个字符就判一次 $2L = S$。

两者都是 $O(n)$。注意一个前提：$S$ 必须为偶数，否则绝不可能相等（可以在开头直接返回 `false`，但逐个判断也会自然失败）。

![算法流程：先求总分，再从左累加并判 2L = S](images/bw167_q1_algorithm_flow.svg)

### 3.3 算法流程

```text
1. S = sum(s[i] - 'a' + 1) 的字符和
2. L = 0
3. for i = 0 .. n-2:                // 左段至少 1 个、右段至少 1 个
       L += val(s[i])
       若 2 * L == S: 返回 true
4. 返回 false
```

循环只到 $n-2$：因为 $i = n-1$ 时右段为空，不满足「两个非空子串」。

### 3.4 示例演算

![示例 1 与示例 2 的逐个拆分点判定](images/bw167_q1_example_walkthrough.svg)

示例 1：`s = "adcb"`，逐字符值 $1, 4, 3, 2$，$S = 10$。

| 拆分点 $i$ | 左段 | $L_i$ | $2L_i$ | 与 $S=10$ 比较 |
|------------|------|-------|--------|----------------|
| 0 | "a" | 1 | 2 | 不等 |
| 1 | "ad" | 5 | 10 | **相等 → true** |
| 2 | "adc" | 8 | 16 | 不等（右段只剩 "b" 的 2） |

示例 2：`s = "bace"`，值 $2,1,3,5$，$S = 11$（奇数，注定无解），三个拆分点 $2L = 4, 6, 12$ 都不等于 11，返回 `false`。

## 4. 算法细节

1. **字符值换算**：`ch - 'a' + 1`，不要写成 `ch - 'a'`（那会让 `'a'` 变成 0，示例 1 就会误判：$4+0=3+1$ 之类）。
2. **循环上界 $n-2$**：$i$ 是左段最后一个字符的下标，左段非空要求 $i \ge 0$，右段非空要求 $i+1 \le n-1$，即 $i \le n-2$。
3. **判等用乘法**：`2 * L == S` 比「左右两段分别求和再比」少算一次，也避免了两段都算错却相等这种假阳性。
4. **$S$ 为奇数可直接返回**：$2L = S$ 无整数解；这只是一个常数优化，逻辑上不必要。
5. **不需要预处理前缀和**：从左往右边加边判即可，空间 $O(1)$。
6. **`n = 2`**：只有一个拆分点 $i=0$，左右各一个字符，只有两字符相同时返回 `true`。

## 5. 正确性证明

**引理 1（互补性）**：对任意拆分点 $i \in [0, n-2]$，左段得分 $L_i$ 与右段得分 $R_i$ 满足 $L_i + R_i = S$。

**证明**：$L_i$ 是 $s[0..i]$ 的字符值之和，$R_i$ 是 $s[i+1..n-1]$ 的字符值之和，二者恰好覆盖 $s$ 的每个字符各一次，故和为全体字符值之和 $S$。∎

**引理 2（判等等价）**：$L_i = R_i \iff 2L_i = S$。

**证明**：由引理 1，$R_i = S - L_i$。故 $L_i = R_i \iff L_i = S - L_i \iff 2L_i = S$。∎

**引理 3（枚举完备）**：所有合法拆分点恰为 $i = 0, 1, \dots, n-2$。

**证明**：拆分要求左右两段都非空，故 $0 \le i$ 且 $i + 1 \le n - 1$，即 $0 \le i \le n-2$；反之每个这样的 $i$ 都给出合法拆分。∎

**定理**：算法返回 `true` 当且仅当存在得分相等的合法拆分。

**证明**：（$\Leftarrow$）若存在合法拆分 $i$ 使两段得分相等，则由引理 3 该 $i$ 被枚举到，由引理 2 有 $2L_i = S$，算法在该步返回 `true`。（$\Rightarrow$）若算法返回 `true`，则某个被枚举的 $i$ 满足 $2L_i = S$，由引理 2 知两段得分相等，且由引理 3 该拆分合法。∎

## 6. 复杂度分析

- **时间**：$O(n)$。求总和一遍 $O(n)$；从左累加并判定一遍 $O(n)$；字符值换算 $O(1)$。
- **空间**：$O(1)$。只用了总和与当前左段和两个变量（若改写成前缀和数组则为 $O(n)$，但没必要）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool scoreBalance(string s) {
        int n = (int)s.size();
        int total = 0;
        for (char ch : s) total += ch - 'a' + 1;
        int left = 0;
        for (int i = 0; i + 1 < n; i++) {
            left += s[i] - 'a' + 1;
            if (2 * left == total) return true;
        }
        return false;
    }
};
```

### Python

```python
class Solution:
    def scoreBalance(self, s: str) -> bool:
        total = sum(ord(ch) - 96 for ch in s)
        left = 0
        for i in range(len(s) - 1):
            left += ord(s[i]) - 96
            if 2 * left == total:
                return True
        return False
```

## 8. 边界情况与易错点

1. **左右都必须非空**：循环不能到 $i = n-1$（右段为空），也不能从 $i=-1$ 开始（左段为空）。
2. **字符值从 1 开始**：`ord(ch) - 96` 或 `ch - 'a' + 1`，写成 `-97` 会让 `'a'` 计 0，示例 1 的左右段会变成 $4$ 与 $2+1=3$，误判。
3. **$S$ 为奇数**：不可能相等，直接返回 `false` 也正确；但注意不要因此漏掉枚举（万一题目以后改成「得分差的绝对值」）。
4. **单字符重复串**：`"aa"` 返回 `true`（各 1），`"ab"` 返回 `false`（1 vs 2）。
5. **长度 100 全 `'z'`**：$S = 2600$，$2L = 2600$ 在 $i = 49$ 时成立，返回 `true`。
6. **别用浮点**：`total / 2` 在奇数时会截断成整数，导致误判（如 $S=11$ 时 $11/2=5$，而 $L=5$ 会被误认为相等）。
