# LeetCode 边权重均等查询 题解

## 1. 题目概述

- **标题 / 题号**：边权重均等查询（#2846，hard）
- **链接**：https://leetcode.cn/problems/minimum-edge-weight-equilibrium-queries-in-a-tree/
- **来源**：LeetCode 第 361 场周赛 Q4
- **难度**：困难
- **标签**：树、最近公共祖先、倍增、前缀计数、枚举

**题意**：给定一棵 $n$ 个节点的无向带权树（`edges[i] = [ui, vi, wi]`）与 $m$ 条查询 `queries[i] = [ai, bi]`。一次操作可将**任意一条边**的权值改为**任意值**。对每条查询，求使 $a_i \to b_i$ 路径上所有边权相等的最少操作次数。查询之间相互独立（每条查询开始时树都回到初始状态）。

**约束**：

- $1 \le n \le 10^4$
- $edges.length = n - 1$，$1 \le w_i \le 26$ ← **本题题眼**
- $1 \le m \le 2 \times 10^4$
- $0 \le a_i, b_i < n$（允许 $a_i = b_i$）

> ⚠️ 读约束：$w_i \le 26$ 意味着权值域极小，可以对「每个节点 × 每种权值」做前缀计数——这是整道题的突破口；若盯着 $n$、$m$ 去想线段树、树剖，方向就偏了。

## 2. 示例

**示例 1**

```text
输入：n = 7, edges = [[0,1,1],[1,2,1],[2,3,1],[3,4,2],[4,5,2],[5,6,2]],
     queries = [[0,3],[3,6],[2,6],[0,6]]
输出：[0,0,1,3]

解释：
查询 (0,3)：路径边权 [1,1,1]，已均等，答案 0。
查询 (3,6)：路径边权 [2,2,2]，已均等，答案 0。
查询 (2,6)：路径边权 [1,2,2,2]，把边 [2,3] 改成 2，答案 1。
查询 (0,6)：路径边权 [1,1,1,2,2,2]，保留 3 条权 2（或权 1），改其余 3 条，答案 3。
```

## 3. 解题思路

### 3.1 暴力思路

对每条查询 $(a, b)$：从 $a$ 做 BFS/DFS 记录父指针，再从 $b$ 沿父指针回溯到 $a$ 得到路径，桶计数 26 种权值后取 $L - \max_c cnt(c)$。单次查询 $O(n)$，总计 $O(nm) = 10^4 \times 2 \times 10^4 = 2 \times 10^8$——且树退化成链时每次 BFS 都要扫全树，C++ 勉强、Python 必超时。

思路的「计数取最大」部分完全正确，瓶颈只在**单次查询获取路径统计太贵**。优化的目标：把每条查询的路径统计降到 $O(\log n + 26)$ 以内。

### 3.2 核心观察一：答案 = 路径长 − 众数出现次数

![核心观察：保留众数权值，其余边全改](images/edge_equilibrium_majority_concept.svg)

设路径长为 $L$，权值 $t$ 在路径上出现 $cnt(t)$ 次。若最终统一为 $t$，则**初权不等于 $t$ 的边各需恰好 1 次操作**，代价为

$$ops(t) = L - cnt(t)$$

$t$ 取遍所有候选（含路径上未出现的权值，此时 $ops(t) = L$）取最小：

$$ans = L - \max_{t}\ cnt(t)$$

即**保留出现次数最多的权值不动，其余边全改成它**。于是单条查询只需求出路径上 26 个计数 $cnt(1), \dots, cnt(26)$ 的最大值——问题从「改边」转化为「路径计数」。

### 3.3 核心观察二 + 算法流程：前缀计数 + LCA 容斥

![算法骨架：根到点前缀计数 + LCA 容斥](images/edge_equilibrium_prefix_lca_model.svg)

权值只有 26 种，于是「根到点」的计数向量是可存储、可 $O(1)$ 转移的：以任意节点（取 0）为根 BFS，为每个节点 $v$ 维护

- $cnt[v][c]$：根 $\to v$ 路径上权为 $c$ 的边数（26 维）；
- $depth[v]$ 与倍增表 $up[k][v]$（跳 $2^k$ 步到达的祖先）。

查询 $(a, b)$ 时设 $l = \mathrm{lca}(a, b)$，利用「根 $\to a$ 与根 $\to b$ 的公共部分恰是根 $\to l$」做容斥：

$$cnt_P(c) = cnt[a][c] + cnt[b][c] - 2 \cdot cnt[l][c], \qquad L = depth[a] + depth[b] - 2 \cdot depth[l]$$

$$ans = L - \max_{1 \le c \le 26} cnt_P(c)$$

```text
预处理（一次）：
① 以 0 为根 BFS：求 depth[v]、up[0][v]、cnt[v][*]（整拷父节点向量，再 cnt[w]++）
② 倍增：up[k][v] = up[k-1][ up[k-1][v] ]
每条查询 (a, b)：
③ 倍增求 l = lca(a, b)
④ L = depth[a] + depth[b] − 2·depth[l]
⑤ best = max over c∈[1,26] 的 cnt[a][c] + cnt[b][c] − 2·cnt[l][c]
⑥ ans = L − best
```

> 💡 这正是「树上点对距离」$dist = depth[a] + depth[b] - 2 \cdot depth[l]$ 的按权值分解版：把权 $c$ 的边看作长度 1、其余边长度 0，套 26 遍。任何**可减**的路径统计量（计数、和、异或）都能这样「前缀 + 容斥」$O(1)$ 拿到。

### 3.4 示例演算

![示例演算：查询 (2,6) 逐步计算](images/edge_equilibrium_walkthrough.svg)

以示例 1 演算查询 $(2, 6)$：$l = \mathrm{lca}(2,6) = 2$（$a$ 本身是 $b$ 的祖先），$L = 6 + 2 - 2 \times 2 = 4$；

| $c$ | $cnt[6][c]$ | $cnt[2][c]$ | $-2 \cdot cnt[2][c]$ | 路径计数 |
|---|---|---|---|---|
| 1 | 3 | 2 | −4 | 1 |
| 2 | 3 | 0 | 0 | **3** |
| 其他 | 0 | 0 | 0 | 0 |

$best = 3$（保留三条权 2 的边），$ans = 4 - 3 = 1$，与期望一致。四条查询依此得 $[0, 0, 1, 3]$。

## 4. 算法细节

1. **建图与 BFS 定向**：无向边两端各存一次邻接；用 `visited` 数组防止沿边弹回父节点。**必须 BFS 而非递归 DFS**——$n = 10^4$ 的链状树递归深度达 $10^4$，Python 直接 `RecursionError`，C++ 也有爆栈风险。
2. **计数向量的转移**：首访子节点时从父节点**整拷** 27 长度数组再对边权自增，总代价 $O(27n) \approx 2.7 \times 10^5$。C++ 用 `vector<array<int,27>>`（约 1 MB），Python 用列表切片拷贝。
3. **倍增表**：$up[0][v]$ 为父节点，根的父指向**根自身**作哨兵——上跳越过头也停在根，全程无需判空。$LOG$ 取满足 $2^{LOG} \ge n$ 的最小值（深度差最大 $n-1$）。
4. **LCA 两步走**：先把较深的点按深度差的二进制拆位上跳对齐；若两点未重合，再从高位到低位「$up[k][x] \ne up[k][y]$ 则同跳」，最后 $up[0][x]$ 即 LCA。
5. **公式无需特判**：$a = b$ 时 $L = 0$、$best = 0$、$ans = 0$；$a$ 是 $b$ 的祖先时公式退化为 $cnt[b][c] - cnt[a][c]$，均自动正确。
6. **枚举范围 $c \in [1, 26]$**：`best` 初始化为 0（空路径/无命中权值时兜底），查询循环只扫 26 次。

## 5. 正确性证明

**引理 1（单条查询的代价公式）**：设 $P$ 为 $a \to b$ 路径，$|P| = L$，权值 $t$ 在 $P$ 上出现 $cnt_P(t)$ 次（$L = 0$ 时规定所有 $cnt_P(t) = 0$）。使 $P$ 上边权全相等的最少操作数为

$$L - \max_{1 \le t \le 26} cnt_P(t)$$

**证明**：任意可行方案最终使路径边权统一为某个值 $t^*$。初权 $\ne t^*$ 的边至少需改一次（每次操作只改一条边），故代价 $\ge L - cnt_P(t^*) \ge L - \max_t cnt_P(t)$。反之，取出现次数最多的权值 $t^\star$（$L \ge 1$ 时 $cnt_P(t^\star) \ge 1$；$L = 0$ 时代价为 0），仅把权 $\ne t^\star$ 的边各改一次，代价恰为 $L - \max_t cnt_P(t)$。两方向夹逼得证。∎

**引理 2（前缀计数正确性）**：BFS 首访节点 $v$ 时令 $cnt[v] \leftarrow cnt[\mathrm{parent}(v)]$ 并将 $cnt[v][w(\mathrm{parent}(v), v)]$ 自增 1。则 $cnt[v][c]$ 等于根 $\to v$ 路径上权为 $c$ 的边数。

**证明**：对 BFS 序归纳。根节点路径为空，计数全 0，基础成立。节点 $v$ 的父 $p$ 先于 $v$ 被访问，由归纳假设 $cnt[p][\cdot]$ 正确；根 $\to v$ 的边多重集等于根 $\to p$ 的边多重集添加单条边 $(p, v)$，「整拷 + 对该边权自增」恰是此多重集运算在计数向量上的像。∎

**引理 3（容斥公式）**：设 $l = \mathrm{lca}(a, b)$，$S_a, S_b, S_l$ 分别为根 $\to a$、根 $\to b$、根 $\to l$ 路径的边集。则

$$cnt_P(c) = cnt[a][c] + cnt[b][c] - 2 \cdot cnt[l][c]$$

**证明**：树中根到任一点路径唯一，两条根出发路径的公共边集恰是根 $\to$ 它们最近公共祖先的路径，即 $S_a \cap S_b = S_l$（若不然，公共边可延伸到更深的公共祖先，与 $l$ 的最近性矛盾）。而 $a \to b$ 路径 $P = (S_a \setminus S_l) \uplus (S_b \setminus S_l)$（树上去掉公共前缀后两侧不相交）。对权 $c$ 计数：$cnt_P(c) = (cnt[a][c] - cnt[l][c]) + (cnt[b][c] - cnt[l][c])$。同理 $L = |P| = depth[a] + depth[b] - 2 \cdot depth[l]$。∎

**定理**：算法对每条查询输出正确的最少操作数。

**证明**：倍增法求 LCA 的正确性为经典结论（按二进制拆解任意祖先距离，哨兵保证不越界）。由引理 2，各节点计数向量正确；由引理 3，公式算出的 $cnt_P(c)$ 与 $L$ 即该查询路径的真实值；代入引理 1 的公式即得最少操作数。∎

## 6. 复杂度分析

- **时间复杂度**：$O\bigl(27n + n\log n + m(\log n + 26)\bigr)$
  - BFS 建序 + 计数向量转移 $O(27n)$；
  - 倍增表 $O(n \log n)$（$n = 10^4$ 时 $\approx 1.4 \times 10^5$）；
  - 每条查询 LCA $O(\log n)$ + 枚举 26 个权值 $O(26)$，共 $m$ 条。
- **空间复杂度**：$O(27n + n\log n)$。计数向量约 1 MB，倍增表 $10^4 \times 14$ 个整数，均无压力。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> minOperationsQueries(int n, vector<vector<int>>& edges, vector<vector<int>>& queries) {
        vector<vector<pair<int,int>>> g(n);
        for (auto& e : edges) {
            g[e[0]].push_back({e[1], e[2]});
            g[e[1]].push_back({e[0], e[2]});
        }
        int LOG = 1;                                  // 2^LOG >= n，深度差最大 n-1
        while ((1 << LOG) < n) ++LOG;

        vector<int> depth(n, 0);
        vector<vector<int>> up(LOG, vector<int>(n, 0));  // up[0][根]=根：哨兵免判空
        vector<array<int, 27>> cnt(n);                   // 根→v 各权值边数
        cnt[0].fill(0);

        vector<int> order;                               // 数组即 BFS 队列，防链状树爆栈
        order.reserve(n);
        vector<char> vis(n, 0);
        order.push_back(0);
        vis[0] = 1;
        for (int i = 0; i < (int)order.size(); ++i) {
            int v = order[i];
            for (auto [to, w] : g[v]) {
                if (vis[to]) continue;                   // 无向边，跳过来向
                vis[to] = 1;
                depth[to] = depth[v] + 1;
                up[0][to] = v;
                cnt[to] = cnt[v];                        // 整拷父节点 + 自增本边权
                cnt[to][w]++;
                order.push_back(to);
            }
        }
        for (int k = 1; k < LOG; ++k)
            for (int v = 0; v < n; ++v)
                up[k][v] = up[k - 1][up[k - 1][v]];

        vector<int> ans;
        ans.reserve(queries.size());
        for (auto& q : queries) {
            int a = q[0], b = q[1];
            int x = a, y = b;
            if (depth[x] < depth[y]) swap(x, y);         // x 为较深者
            int diff = depth[x] - depth[y];
            for (int k = 0; k < LOG; ++k)                // ① 二进制拆位对齐深度
                if (diff >> k & 1) x = up[k][x];
            if (x != y) {                                // ② 高位到低位同跳找分叉
                for (int k = LOG - 1; k >= 0; --k)
                    if (up[k][x] != up[k][y]) { x = up[k][x]; y = up[k][y]; }
                x = up[0][x];
            }
            int l = x;                                   // l = lca(a, b)
            int len = depth[a] + depth[b] - 2 * depth[l];
            const auto &ca = cnt[a], &cb = cnt[b], &cl = cnt[l];
            int best = 0;                                // ③ 众数计数（0 兜底空路径）
            for (int c = 1; c <= 26; ++c)
                best = max(best, ca[c] + cb[c] - 2 * cl[c]);
            ans.push_back(len - best);                   // ④ L − best
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def minOperationsQueries(self, n: int, edges: List[List[int]], queries: List[List[int]]) -> List[int]:
        g = [[] for _ in range(n)]
        for u, v, w in edges:
            g[u].append((v, w))
            g[v].append((u, w))

        LOG = max(1, n.bit_length())              # 2^LOG >= n
        depth = [0] * n
        up = [[0] * n for _ in range(LOG)]        # up[0][根]=根：哨兵免判空
        cnt = [None] * n                          # 根→v 各权值边数
        cnt[0] = [0] * 27

        visited = [False] * n                     # BFS 防爆栈、防走回头路
        visited[0] = True
        queue = [0]
        for v in queue:                           # 列表边遍历边追加，即为队列
            for to, w in g[v]:
                if visited[to]:
                    continue
                visited[to] = True
                depth[to] = depth[v] + 1
                up[0][to] = v
                c = cnt[v][:]                     # 整拷父节点 + 自增本边权
                c[w] += 1
                cnt[to] = c
                queue.append(to)

        for k in range(1, LOG):                   # 倍增表
            prev, cur = up[k - 1], up[k]
            for v in range(n):
                cur[v] = prev[prev[v]]

        ans = []
        for a, b in queries:
            x, y = a, b
            if depth[x] < depth[y]:               # x 为较深者
                x, y = y, x
            diff = depth[x] - depth[y]
            k = 0
            while diff:                           # ① 二进制拆位对齐深度
                if diff & 1:
                    x = up[k][x]
                diff >>= 1
                k += 1
            if x != y:                            # ② 高位到低位同跳找分叉
                for k in range(LOG - 1, -1, -1):
                    if up[k][x] != up[k][y]:
                        x = up[k][x]
                        y = up[k][y]
                x = up[0][x]
            l = x                                 # l = lca(a, b)
            length = depth[a] + depth[b] - 2 * depth[l]
            ca, cb, cl = cnt[a], cnt[b], cnt[l]
            best = max(ca[c] + cb[c] - 2 * cl[c] for c in range(1, 27))  # ③ 众数
            ans.append(length - best)             # ④ L − best
        return ans
```

## 8. 边界情况与易错点

1. **读约束看到 $w_i \le 26$**：本题最关键的一步。权值域可枚举才有「前缀计数」；见到树上路径统计，先扫一眼值域再选数据结构。
2. **$a = b$ 是合法查询**：答案 0。公式自然覆盖，但代码里 `best` 必须初始化 0，否则对空路径取 `max` 会出错。
3. **递归爆栈**：链状树深度 $10^4$，Python 递归 DFS 必炸，C++ 也悬；统一写迭代 BFS。
4. **无向边 BFS 忘记标记访问**：会沿边弹回父节点、重复入队导致死循环或计数错误。
5. **倍增哨兵 `up[0][根] = 根`**：若初始化为 $-1$，上跳越界后下标 $-1$ 直接越内存；哨兵写法全程免判空。
6. **`LOG` 上界**：深度差最大 $n - 1$，必须保证 $2^{LOG} \ge n$（或 $> n-1$），否则拆位对齐时会漏跳高位。
7. **LCA 第二步的前提**：「同跳找分叉」必须先做深度对齐，且 $k$ 要**从高位往低位**枚举——从低位开始会停在分叉下方。
8. **查询相互独立**：不存在把某次改边延续到下次的坑，逐条独立计算即可；反之也别想着「共享修改」去贪心。
9. **数值范围**：答案 $\le n - 1 < 10^4$，`int` 足够；C++ 计数数组 $10^4 \times 27 \times 4\text{B} \approx 1$ MB，注意别开成 $26 \times 2^{26}$ 之类的笔误。
