# LeetCode 统计对称整数的数目 题解

## 1. 题目概述

- **标题 / 题号**：统计对称整数的数目（#2843，easy）
- **链接**：https://leetcode.cn/problems/count-symmetric-integers/
- **来源**：LeetCode 第 361 场周赛 Q1
- **难度**：简单
- **标签**：数学、枚举、字符串

**题意**：给定闭区间 `[low, high]`，统计其中「对称整数」的个数。一个数由 $2n$ 位数字组成，若前 $n$ 位数字之和等于后 $n$ 位数字之和，则称其为对称整数。

**约束**：

- `1 <= low <= high <= 10^4`

## 2. 示例

**示例 1**

```text
输入：low = 1, high = 100
输出：9
解释：1 到 100 内共有 9 个对称整数：11、22、33、44、55、66、77、88、99。
```

**示例 2**

```text
输入：low = 1200, high = 1230
输出：4
解释：1200 到 1230 内共有 4 个对称整数：1203、1212、1221、1230。
```

## 3. 解题思路

### 3.1 暴力思路

签到题。区间最长 $10^4$ 个数，直接**枚举每个数逐个判定**即可，无需任何预处理。

### 3.2 核心观察：拆半求和、逐位比较

![对称整数的定义：拆成前后两半比较数字和](images/csi_split_halves.svg)

关键观察有两点：

1. **位数必须为偶数**：定义要求 $2n$ 位。一位数（1~9）、三位数（100~999）、五位数（10000）都不可能是对称整数，直接跳过。
2. **判定只需拆半求和**：把 $x$ 转成字符串 $s$（长度 $n$ 为偶数），比较前半 `s[:n/2]` 与后半 `s[n/2:]` 的数字和是否相等。

例如 `1221`：前半 `1+2=3`，后半 `2+1=3`，相等 → 对称；`1200`：前半 `1+2=3`，后半 `0+0=0`，不等 → 不对称。

### 3.3 算法流程

![枚举判定流程：奇数位跳过，偶数位拆半比较](images/csi_enum_flow.svg)

```text
for x in [low, high]:
    s = str(x)
    n = len(s)
    if n 为奇数: continue          # 定义排除奇数位数
    left  = s[0 .. n/2) 的数字和
    right = s[n/2 .. n) 的数字和
    if left == right: ans += 1
```

### 3.4 示例演算

以示例 2 `[1200, 1230]` 为例，扫描高亮 4 个命中：

| x | 位数 | 拆半 | left / right | 对称 |
|------|------|-------|--------------|------|
| 1200 | 4（偶） | `12 \| 00` | 3 / 0 | ✗ |
| 1203 | 4（偶） | `12 \| 03` | 3 / 3 | ✓ |
| 1212 | 4（偶） | `12 \| 12` | 3 / 3 | ✓ |
| 1221 | 4（偶） | `12 \| 21` | 3 / 3 | ✓ |
| 1230 | 4（偶） | `12 \| 30` | 3 / 3 | ✓ |
| 其余 | 4（偶） | — | — | ✗ |

答案 = 4 ✓

## 4. 算法细节

1. **数位提取**：`to_string(x)` 转字符串最直接；也可以用 `% 10` 逐位除法提取，两种方式在 $10^4$ 规模下无差别。
2. **奇偶判定前置**：位数奇数时提前 `continue`，省去求和计算——既是剪枝也是正确性的一部分（奇数位数按定义就不是对称整数）。
3. **求和方式**：前半从左往右累加、后半从右往左累加（对称位置成对比较），或直接对两个子串分别求和，写法随意，语义等价。
4. **数据规模**：区间内至多 $10^4$ 个数、每个至多 5 位，总操作数 $5 \times 10^4$，远低于任何时限压力。

## 5. 正确性证明

**引理 1**：位数不是偶数的整数不是对称整数。

**证明**：定义要求整数由 $2n$ 位数字组成。设 $x$ 的位数为 $d$，若存在 $n$ 使 $d = 2n$，则 $d$ 为偶数；反之 $d$ 为奇数时不存在这样的 $n$，$x$ 不满足定义。∎

**定理**：算法返回的恰是 `[low, high]` 内对称整数的个数。

**证明**：算法遍历区间内每个整数 $x$，各判定恰一次，无遗漏无重复。对每个 $x$：
- 若位数 $d$ 为奇数，由引理 1 判非对称，与定义一致；
- 若 $d$ 为偶数，取 $n = d/2$，判定条件「`s[:n]` 数字和 = `s[n:]` 数字和」正是定义中「前 $n$ 位数字之和等于后 $n$ 位数字之和」的字面翻译。

故计数与定义完全一致。∎

## 6. 复杂度分析

- **时间复杂度**：$O((high - low + 1) \cdot D)$，其中 $D \le 5$ 为数字位数上限（$high \le 10^4$）。至多约 $5 \times 10^4$ 次基本操作。
- **空间复杂度**：$O(D)$，仅需字符串与常数变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int countSymmetricIntegers(int low, int high) {
        int ans = 0;
        for (int x = low; x <= high; ++x) {
            string s = to_string(x);
            int n = s.size();
            if (n % 2) continue;
            int left = 0, right = 0;
            for (int i = 0; i < n / 2; ++i) {
                left  += s[i] - '0';
                right += s[n - 1 - i] - '0';
            }
            if (left == right) ++ans;
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def countSymmetricIntegers(self, low: int, high: int) -> int:
        ans = 0
        for x in range(low, high + 1):
            s = str(x)
            m = len(s)
            if m % 2 == 0:
                half = m // 2
                if sum(map(int, s[:half])) == sum(map(int, s[half:])):
                    ans += 1
        return ans
```

## 8. 边界情况与易错点

1. **一位数不是对称整数**：`1 <= low` 意味着区间可能覆盖 1~9，这些数虽「前后各 0.5 位」直觉上特殊，但定义要求 $2n$ 位，单 digit 直接排除——示例 1 中 1~99 内只有 11~99 共 9 个。
2. **奇数位数必须跳过**：三位数（100~999）整个区间可整体跳过；`high = 10^4` 时 10000 是五位数，也不能漏判。
3. **`low == high`**：单点区间也要正常判定一次。
4. **前导零不存在**：整数本身无前导零，但后半部分可以有 0（如 `1230` 的后半 `30`），求和时照常计入。
5. **别混淆「回文」与「对称」**：本题比较的是**数字和**而非逐位镜像，`1203` 不是回文但是对称整数。
