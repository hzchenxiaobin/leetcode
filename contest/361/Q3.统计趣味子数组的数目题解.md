# LeetCode 统计趣味子数组的数目 题解

## 1. 题目概述

- **标题 / 题号**：统计趣味子数组的数目（#2845，medium）
- **链接**：https://leetcode.cn/problems/count-of-interesting-subarrays/
- **来源**：LeetCode 第 361 场周赛 Q3
- **难度**：中等
- **标签**：数组、哈希表、前缀和、同余

**题意**：给定整数数组 `nums` 与整数 `modulo`、`k`。对子数组 `nums[l..r]`，设 `cnt` 为区间内满足 `nums[i] % modulo == k` 的下标数量；若 `cnt % modulo == k`，则称其为**趣味子数组**。统计并返回趣味子数组的数目。

**约束**：

- $1 \le nums.length \le 10^5$
- $1 \le nums[i] \le 10^9$
- $1 \le modulo \le 10^9$
- $0 \le k < modulo$

## 2. 示例

**示例 1**

```text
输入：nums = [3,2,4], modulo = 2, k = 1
输出：3
解释：趣味子数组为 [3]、[3,2]、[3,2,4]。
三者中满足 nums[i]%2==1 的下标都只有 i=0，即 cnt=1，1%2==1。
```

**示例 2**

```text
输入：nums = [3,1,9,6], modulo = 3, k = 0
输出：2
解释：趣味子数组为 [1]（cnt=0，0%3==0）与 [3,1,9,6]（cnt=3，3%3==0）。
```

## 3. 解题思路

### 3.1 暴力思路

枚举每个左端点 $l$，向右扩展右端点 $r$ 时增量维护 `cnt`（每遇到一个好元素 `cnt++`），逐个检查 `cnt % modulo == k`。时间 $O(n^2)$、空间 $O(1)$。

$n = 10^5$ 时约 $10^{10}$ 次基本操作，必然超时。另一条常见歧路是**滑动窗口**：固定 $l$ 增大 $r$ 时 `cnt` 确实单调不减，但趣味条件看的是 `cnt mod modulo`——`cnt` 每跨过 $m$ 的一个倍数，余数就从 $m-1$ 绕回 $0$，**趣味与否不具单调性**，双指针无法收缩，此路不通。

### 3.2 核心观察：0/1 化 + 前缀和同余配对

![核心观察：0/1 化与前缀和同余配对](images/interesting_subarrays_01_prefix_concept.svg)

**第一步：0/1 化。** 元素的具体数值无关紧要，只关心它是不是「好元素」（$nums[i] \bmod m = k$）。把每个元素替换为 $1$（好）或 $0$（坏），问题变为统计「区间和满足模条件」的子数组。

**第二步：前缀和。** 设 $s_j$ 为前 $j$ 个元素中好元素的个数（$s_0 = 0$），则子数组 `nums[l..r]` 的好元素数

$$cnt = s_{r+1} - s_l \quad (0 \le l \le r \le n-1)$$

**第三步：同余变形。** 趣味条件 $cnt \bmod m = k$ 等价于把 $cnt$ 写成 $qm + k$ 的形式，移项即

$$cnt \bmod m = k \iff s_{r+1} - k \equiv s_l \pmod m$$

于是固定右端点 $j = r+1$ 后，**满足条件的左端点 $i$ 恰是所有 $s_i \equiv (s_j - k) \pmod m$ 的 $i < j$**——用哈希表按「余数 → 出现次数」分组，一步查出来。

> 💡 这正是「和可被 K 整除的子数组」（LC 974）的同款套路：**凡「子数组和/计数满足某模条件」，先写前缀和，再把条件改写成两侧同余**，一侧枚举、一侧哈希查。

### 3.3 算法流程：一次遍历 + 哈希表

![算法流程：单次遍历，先查后插](images/interesting_subarrays_hash_flow.svg)

```text
s = 0，map = {0: 1}          # 空前缀 s[0] = 0，余数 0 计 1 次
ans = 0
for j = 1..n:                 # j 为前缀右边界，对应子数组右端点 r = j-1
    s += (nums[j-1] % m == k)         # ① 前缀好元素数 O(1) 递推
    target = ((s - k) % m + m) % m    # ② 修正负余数（C++）
    ans += map[target]                # ③ 先查：配对左端点的个数
    map[s % m] += 1                   # ④ 后插：s[j] 的余数入表
return ans
```

**先查后插**的顺序不可颠倒：$k = 0$ 时 `target = s[j] % m`，若先插入再查询，$s_j$ 会与**自己**配对，凭空多算一个空子数组。

### 3.4 示例演算

![示例 2 的逐轮演算表](images/interesting_subarrays_walkthrough.svg)

对示例 2（`nums = [3,1,9,6]`，`m = 3`，`k = 0`）：好元素为 3、9、6，0/1 序列 `[1,0,1,1]`，前缀和 `s = [0,1,1,2,3]`。

| j | s[j] | target = (s[j]−k)%3 | 查询前哈希表 | 累加 | 命中子数组 | ans |
|---|------|---------------------|--------------|------|------------|-----|
| 1 | 1 | 1 | {0:1} | +0 | — | 0 |
| 2 | 1 | 1 | {0:1, 1:1} | +1（i=1） | nums[1..1]=[1]，cnt=0 | 1 |
| 3 | 2 | 2 | {0:1, 1:2} | +0 | — | 1 |
| 4 | 3 | 0 | {0:1, 1:2, 2:1} | +1（i=0） | nums[0..3]，cnt=3 | 2 |

例如 $j=4$ 时 $s_4 = 3$，`target = 3 % 3 = 0`，表中余数 0 的计数为 1（来自 $i=0$ 的 $s_0=0$），对应子数组 `[3,1,9,6]`，`cnt = 3`，`3 % 3 == 0` ✓。最终答案 2，与示例一致。

## 4. 算法细节

1. **0/1 化不落地**：无需真的构造 0/1 数组，遍历时用 `s += (nums[j] % m == k)` 一行完成前缀和递推（布尔值隐式转 0/1）。
2. **负余数修正（C++）**：当 $s < k$（仅 $k>0$ 时可能）时 `s - k` 为负，C++ 的 `%` 保留符号，必须写 `((s - k) % m + m) % m`。中间量绝对值不超过 $2m \le 2 \times 10^9 < 2^{31}-1$，`int` 不溢出；Python 的 `%` 天然非负，直接 `(s - k) % modulo`。
3. **初始化 `map[0] = 1`**：对应空前缀 $s_0 = 0$（余数 0）。漏掉它就漏数所有 $l = 0$ 的子数组——示例 1 的三个趣味子数组全部以 0 为左端点，漏初始化会直接返回 0。
4. **先查后插**：查询时表中必须只有 $i < j$ 的前缀，保证每个 $(i, j)$ 对恰统计一次（$k=0$ 时防自配）。
5. **哈希表而非计数数组**：$modulo$ 高达 $10^9$，开桶不可行；但表中键至多 $n+1$ 个（每轮至多新增一个余数），空间与 $modulo$ 无关。
6. **答案类型**：所有元素都是好元素且 $m > n$ 时，每个子数组都趣味，答案达 $\frac{n(n+1)}{2} \approx 5 \times 10^9$，超出 `int` 上限，必须 `long long` / Python 无此虑。

## 5. 正确性证明

**引理 1（趣味条件的同余转化）**：设 $s_j$ 为前 $j$ 个元素中好元素的个数（$s_0 = 0$）。子数组 `nums[l..r]` 是趣味子数组，当且仅当

$$s_{r+1} - k \equiv s_l \pmod m$$

**证明**：由前缀和定义，$cnt = s_{r+1} - s_l$。由带余除法，存在唯一 $q \ge 0$、$r' \in [0, m)$ 使 $cnt = qm + r'$，且 $cnt \bmod m = r'$。故

$$cnt \bmod m = k \iff r' = k \iff \exists q \in \mathbb{Z},\ cnt = qm + k \iff m \mid (cnt - k) \iff m \mid (s_{r+1} - s_l - k)$$

其中第二处等价用到 $0 \le k < m$（题面保证）时「$r' = k$ 与 $cnt \equiv k \pmod m$」互推。最后一条即 $s_{r+1} - k \equiv s_l \pmod m$。∎

**引理 2（右端点配对计数）**：固定 $j \in [1, n]$，以 $r = j-1$ 为右端点的趣味子数组个数为

$$\bigl|\{\, i \in [0, j-1] : s_i \equiv (s_j - k) \pmod m \,\}\bigr|$$

**证明**：以 $j-1$ 为右端点的子数组与 $[0, j-1]$ 中的左端点 $l$ 一一对应。对 $i = l$，由引理 1，子数组 `nums[i..j-1]` 趣味 $\iff s_i \equiv (s_j - k) \pmod m$。对满足条件的 $i$ 计数即得结论。∎

**定理**：算法返回的 `ans` 恰等于趣味子数组总数。

**证明**：*循环不变量*：处理第 $j$ 轮的查询之前，哈希表恰为 $\{r \mapsto \#\{i \in [0, j-1] : s_i \bmod m = r\}\}$。$j = 1$ 时表为 $\{0 \mapsto 1\}$（仅含 $s_0$），成立。每轮**先查后插**且仅插入 $s_j \bmod m$，故归纳保持。

*计数恰一次*：第 $j$ 轮累加的 `map[target]`（其中 $target \equiv s_j - k \pmod m$，$0 \le target < m$）恰为引理 2 中的计数，即以 $j-1$ 为右端点的趣味子数组个数。全部子数组按右端点划分为 $n$ 组（$r = 0, \dots, n-1$ 对应 $j = 1, \dots, n$），各组贡献相加，每个趣味子数组在且仅在其右端点所在的组被统计一次。故 `ans` 等于趣味子数组总数。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$ 期望。每个元素一次 $O(1)$ 递推、一次哈希查询、一次哈希插入，共 $n$ 轮（哈希单次均摊 $O(1)$）。
- **空间复杂度**：$O(n)$。哈希表至多存 $n+1$ 个不同的余数键（与 $modulo \le 10^9$ 的大小无关）；其余仅常数个变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long countInterestingSubarrays(vector<int>& nums, int modulo, int k) {
        long long ans = 0;
        int s = 0;
        unordered_map<int, int> cnt;
        cnt[0] = 1;                                          // 空前缀 s[0] = 0
        for (int x : nums) {
            s += (x % modulo == k);                          // ① 前缀好元素数
            int target = ((s - k) % modulo + modulo) % modulo; // ② 修正负余数
            ans += cnt[target];                              // ③ 先查：配对的左端点数
            cnt[s % modulo]++;                               // ④ 后插：s[j] 的余数入表
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def countInterestingSubarrays(self, nums: List[int], modulo: int, k: int) -> int:
        ans = 0
        s = 0
        cnt = {0: 1}                          # 空前缀 s[0] = 0
        for x in nums:
            s += 1 if x % modulo == k else 0  # ① 前缀好元素数
            target = (s - k) % modulo         # ② Python 取模天然非负
            ans += cnt.get(target, 0)         # ③ 先查
            cnt[s % modulo] = cnt.get(s % modulo, 0) + 1  # ④ 后插
        return ans
```

## 8. 边界情况与易错点

1. **答案溢出（最常见 WA）**：$n = 10^5$ 时答案可达 $\frac{n(n+1)}{2} \approx 5 \times 10^9 > 2^{31}-1$，C++ 必须用 `long long` 存 `ans`；`s`、`k`、`target` 均在 `int` 范围内，无须扩大。
2. **C++ 负余数**：$k > 0$ 且 $s < k$ 时 `s - k` 为负，`(s - k) % modulo` 为负或零，漏修会查错桶，写成 `((s - k) % modulo + modulo) % modulo`。
3. **漏初始化 `cnt[0] = 1`**：所有 $l = 0$ 的趣味子数组将被漏数。示例 1（`[3,2,4]`, `m=2`, `k=1`）的三个趣味子数组全部从下标 0 出发，漏掉后答案变 0。
4. **先插后查（顺序颠倒）**：`k = 0` 时若先插入再查询，$s_j$ 与自己配对，多算空子数组。反例：`nums=[1], m=2, k=0`，正确答案 1（`[1]`：cnt=0），错误顺序得 2。
5. **不要开 `modulo` 大小的桶数组**：$modulo \le 10^9$，会 MLE；哈希表键数上界是 $n+1$。
6. **对拍样例 `m = 1, k = 0`**：任何数模 1 余 0，所有元素都是好元素且 `cnt % 1 == 0` 恒真，答案应为 $\frac{n(n+1)}{2}$，可作 sanity check。
7. **两个条件别混淆**：「好元素」判 `nums[i] % m == k`，「趣味」判 `cnt % m == k`，两者共用 $k$ 但作用对象不同（元素 vs 计数）。
