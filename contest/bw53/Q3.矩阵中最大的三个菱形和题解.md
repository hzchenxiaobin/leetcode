# LeetCode 矩阵中最大的三个菱形和 题解

## 1. 题目概述

- **标题 / 题号**：矩阵中最大的三个菱形和（#1878，medium）
- **链接**：https://leetcode.cn/problems/get-biggest-three-rhombus-sums-in-a-grid/
- **来源**：LeetCode 第 53 场双周赛 Q3
- **难度**：中等
- **标签**：数组、数学、矩阵、前缀和、排序、堆（优先队列）

**题意**：给定 $m \times n$ 整数矩阵 `grid`。**菱形和**指一个正方形旋转 $45^\circ$ 后的**边界**上元素之和（四个角必须落在格子中心对齐的格点上，即边落在网格的对角线方向上；面积可为 0，即单个格子）。求所有菱形和中**互不相同**的前三大，降序返回；不足三个则全部返回。

**约束**：

- $m = grid.length$，$n = grid[i].length$
- $1 \le m, n \le 100$（题面截断处为 $1 \le m$，官方原始约束为 $1 \le m, n \le 100$）
- $0 \le grid[i][j] \le 10^5$

> ⚠️ 题面渲染中「1 ≤ m ≤ …」的截断不影响解题；按 LeetCode 官方约束 $m, n \le 100$、$grid[i][j] \le 10^5$。

## 2. 示例

**示例 1**

```text
输入：grid = [[3,4,5,1,3],[3,3,4,2,3],[20,30,200,40,10],[1,5,5,4,1],[4,3,2,2,5]]
输出：[228,216,211]
解释：最大的三个菱形和：
- 228 = 20 + 3 + 200 + 5（中心 (2,3)、半径 1）
- 216 = 200 + 2 + 10 + 4（中心 (2,2)、半径 1）
- 211 = 5 + 200 + 4 + 2（中心 (2,2) 到 (2,3) 一带的半径 1 菱形）
```

**示例 2**

```text
输入：grid = [[1,2,3],[4,5,6],[7,8,9]]
输出：[20,9,8]
解释：20 = 4+2+6+8（中心 (1,1)、半径 1）；9 与 8 是面积为 0 的单格菱形。
```

**示例 3**

```text
输入：grid = [[7,7,7]]
输出：[7]
解释：三个单格菱形的和都是 7，互不相同的和只有 {7}，返回 [7]。
```

## 3. 解题思路

### 3.1 暴力思路

枚举中心 $(c_i, c_j)$ 与半径 $r$，沿菱形四条边逐格累加求和（每条边 $r+1$ 或 $r$ 格），单次求和 $O(r)$，总计 $O(mn \cdot \bar r^2)$（$\bar r \le 50$），最坏约 $10^4 \times 50^2 = 2.5 \times 10^7$，可过但不优雅。本题的数据范围故意放宽到 $100 \times 100$，让「直接展开」也能通过，但正解应当用**对角线前缀和**把每个菱形求和降到 $O(1)$。

### 3.2 核心观察：菱形由「中心 + 半径」唯一确定

![菱形几何：中心与四个角](images/bw53_q3_rhombus_geometry.svg)

菱形的四条边分别沿网格的**两条对角线方向**（↘ 与 ↙）。以中心 $(c_i, c_j)$、半径 $r$ 定义的菱形，四个角为：

$$T = (c_i - r, c_j),\quad R = (c_i, c_j + r),\quad B = (c_i + r, c_j),\quad L = (c_i, c_j - r)$$

合法条件是四角都在网格内，等价于 $r \le \min(c_i, c_j, m - 1 - c_i, n - 1 - c_j)$。**枚举 $(c_i, c_j, r)$ 三元组即不重不漏地枚举所有菱形**（$r = 0$ 是单格菱形）。

### 3.3 算法流程：对角线前缀和 + O(1) 查询

![对角线前缀和：四条边各一次区间查询](images/bw53_q3_diagonal_prefix.svg)

预处理两个前缀和数组：

$$s_1[i][j] = grid[i][j] + s_1[i-1][j-1] \quad (\text{↘ 对角线})$$
$$s_2[i][j] = grid[i][j] + s_2[i-1][j+1] \quad (\text{↙ 对角线})$$

沿 ↘ 方向从 $(r_1, c_1)$ 到 $(r_2, c_2)$（$r_2 - r_1 = c_2 - c_1 \ge 0$）的**段和**为 $s_1[r_2][c_2] - s_1[r_1 - 1][c_1 - 1]$（越界取 0）；↙ 段和同理用 $s_2$。菱形四条边：

```text
T→R（↘）、R→B（↙）、L→B（↘）、T→L（↙）
```

四段相加后，**四个角各被相邻两条边计入两次**，再减去四角各一次即得菱形和。每个菱形求和 $O(1)$。

最后把所有和放入**有序集合（去重）**，降序取前三个。

### 3.4 示例演算

![示例演算：三个最大菱形和](images/bw53_q3_example_walkthrough.svg)

以示例 1 的 $5 \times 5$ 矩阵为例（见上图）：三个半径 1 的菱形分别以不同中心取得 228、216、211；注意 $200$、$5$、$4$、$2$ 等格子被多个菱形共享——它们是不同位置的不同菱形，**按和的数值去重**后才得到恰好三个互不相同的最大值。

## 4. 算法细节

1. **前缀和递推的越界处理**：$s_1[i][j]$ 依赖左上角 $(i-1, j-1)$，$i = 0$ 或 $j = 0$ 时取 0；$s_2[i][j]$ 依赖 $(i-1, j+1)$，$j + 1 = n$ 时取 0。用条件表达式即可，不需要哨兵行列。
2. **段和查询的越界处理**：查询起点 $(r_1, c_1)$ 的「前一格」$(r_1 - 1, c_1 - 1)$ 或 $(r_1 - 1, c_1 + 1)$ 可能越界，同样取 0。这是最容易写错的地方：**↘ 段的前驱是左上格，↙ 段的前驱是右上格**。
3. **四角重复扣除**：T、R、B、L 四个角点各自出现在两条边的段和中（如 T 同时在 T→R 与 T→L 中），所以总和要减去 $\sum_{\text{四角}} grid$ 一次。
4. **$r = 0$ 特判**：单格菱形的「四条边」退化成同一个点，公式会把 $grid$ 重复加 4 次再扣 3 次（结果正确但绕），直接 `sums.insert(grid[ci][cj])` 更清晰。
5. **去重与取前三**：用 `set`（C++）或 `set`（Python）自动去重，再降序取前 3；或维护三个变量的滚动最大（更省空间但易错）。`set` 大小至多 $m^2 \cdot r_{\max}$ 级别（实际 $\le 10^4 \times 50$），完全可承受。
6. **中间结果溢出**：$r = 50$ 时菱形边界有 $4r = 200$ 格，每格 $\le 10^5$，和 $\le 2 \times 10^7$，`int` 足够；但若用 `int` 累加四段前缀和的差值，单段最大 $\le 100 \times 10^5 = 10^7$，四段相加 $\le 4 \times 10^7$，仍在 `int` 内。用 `long long` 只是保险起见。

## 5. 正确性证明

**引理 1（菱形枚举的不重不漏）**：网格中每个合法菱形（含面积 0 的）都可唯一表示为「中心 $(c_i, c_j)$ + 半径 $r \ge 0$」，且合法当且仅当 $r \le \min(c_i, c_j, m-1-c_i, n-1-c_j)$。

**证明**：菱形是正方形旋转 $45^\circ$，其对称中心是两对角线交点；由格点约束，中心为某格 $(c_i, c_j)$（四个角是格点，对称轴沿对角线方向，中心必落在格点）。半径 $r$ 定义为角到中心的切比雪夫距离（沿对角线方向的步数），四个角由 $(c_i, c_j, r)$ 唯一确定。反之，任取满足边界约束的 $(c_i, c_j, r)$，四角都在网格内，且每条边沿对角线方向逐格连接，构成合法菱形。不同 $(c_i, c_j, r)$ 生成的菱形角点集合不同（中心或半径不同），故不重。∎

**引理 2（对角线段和公式）**：设 $s_1$ 如上定义。对满足 $r_2 - r_1 = c_2 - c_1 \ge 0$ 的格点对，↘ 段 $(r_1, c_1) \to (r_2, c_2)$ 上的元素和等于 $s_1[r_2][c_2] - s_1[r_1 - 1][c_1 - 1]$（越界项取 0）。↙ 段同理。

**证明**：$s_1[i][j]$ 是从 $(i, j)$ 沿 ↖ 反向走到边界为止的对角线前缀和，即所有满足 $k \ge 0$、$(i - k, j - k)$ 在界内的格子之和。段 $(r_1, c_1) \to (r_2, c_2)$ 上的格子恰为 $\{(r_2 - k, c_2 - k) : 0 \le k \le r_2 - r_1\}$。由 $s_1[r_2][c_2] = \sum_{k \ge 0, \text{界内}} grid[r_2 - k][c_2 - k]$ 与 $s_1[r_1 - 1][c_1 - 1] = \sum_{k \ge 0, \text{界内}} grid[r_1 - 1 - k][c_1 - 1 - k]$，后者恰好是前者中 $k \ge r_2 - r_1 + 1$ 的部分（下标平移 $k' = k - (r_2 - r_1 + 1)$ 后逐项对应且都在界内，因 $(r_1 - 1, c_1 - 1)$ 与 $(r_2, c_2)$ 同对角线且在前者之前），相减即得段和。∎

**定理（菱形和公式的正确性）**：以 $(c_i, c_j, r)$（$r \ge 1$）定义的菱形，其边界元素和等于

$$D_1(T, R) + D_2(R, B) + D_1(L, B) + D_2(T, L) - grid[T] - grid[R] - grid[B] - grid[L]$$

其中 $D_1, D_2$ 分别为 ↘、↙ 段和，$T, R, B, L$ 为四角。

**证明**：菱形边界可分解为四条对角线段 $T \to R$（↘）、$R \to B$（↙）、$B \to L$（↖，即 ↘ 的反向，与 $L \to B$ 同集合）、$L \to T$（↗，与 $T \to L$ 同集合）。按 $T \to R$、$R \to B$、$L \to B$、$T \to L$ 四段累加时，每条边上的非角点格子各被计入一次；四个角点 $T, R, B, L$ 各出现在两条相邻段的端点上，被计入两次。因此四段之和 = 边界和 + 四角和，再减去四角和一次即得边界和。由引理 2，每段和可由 $s_1, s_2$ 的 $O(1)$ 差值给出。∎

**推论**：算法枚举所有 $(c_i, c_j, r)$（引理 1 保证不重不漏），对每个菱形用定理的 $O(1)$ 公式求和，存入去重集合后降序取前三，返回的恰为互不相同的最大三个菱形和（或全部，若不足三个）。∎

## 6. 复杂度分析

- **时间**：$O(mn \cdot r_{\max} + S \log S)$，其中 $r_{\max} \le \min(m, n) / 2$。枚举每个中心的所有半径是 $O(mn \cdot \min(m,n))$（$100 \times 100 \times 50 = 5 \times 10^5$），每次求和 $O(1)$；集合插入与最终排序为 $O(S \log S)$（$S \le m n \min(m,n)$）。若维护「滚动前三」可去掉 $\log$ 因子，但量级不变。
- **空间**：$O(mn)$ 两个前缀和数组（`long long` 时约 $2 \times 10^4 \times 8$ 字节）+ $O(S)$ 去重集合。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> getBiggestThree(vector<vector<int>>& grid) {
        int m = (int)grid.size(), n = (int)grid[0].size();
        // s1[i][j]：以 (i,j) 结尾的 ↘ 对角线前缀和；s2：↙
        vector<vector<long long>> s1(m, vector<long long>(n)), s2(m, vector<long long>(n));
        for (int i = 0; i < m; ++i)
            for (int j = 0; j < n; ++j) {
                long long a = (i > 0 && j > 0) ? s1[i - 1][j - 1] : 0;
                long long b = (i > 0 && j + 1 < n) ? s2[i - 1][j + 1] : 0;
                s1[i][j] = grid[i][j] + a;
                s2[i][j] = grid[i][j] + b;
            }
        auto diag1 = [&](int r1, int c1, int r2, int c2) -> long long {   // ↘ 段和
            long long pre = (r1 > 0 && c1 > 0) ? s1[r1 - 1][c1 - 1] : 0;
            return s1[r2][c2] - pre;
        };
        auto diag2 = [&](int r1, int c1, int r2, int c2) -> long long {   // ↙ 段和
            long long pre = (r1 > 0 && c1 + 1 < n) ? s2[r1 - 1][c1 + 1] : 0;
            return s2[r2][c2] - pre;
        };

        set<long long> sums;                            // 自动去重
        for (int ci = 0; ci < m; ++ci)
            for (int cj = 0; cj < n; ++cj) {
                int rmax = min(min(ci, m - 1 - ci), min(cj, n - 1 - cj));
                for (int r = 0; r <= rmax; ++r) {
                    if (r == 0) { sums.insert(grid[ci][cj]); continue; }
                    int ti = ci - r, tj = cj, ri = ci, rj = cj + r;
                    int bi = ci + r, bj = cj, li = ci, lj = cj - r;
                    long long s = diag1(ti, tj, ri, rj)     // T→R
                                + diag2(ri, rj, bi, bj)     // R→B
                                + diag1(li, lj, bi, bj)     // L→B
                                + diag2(ti, tj, li, lj)     // T→L
                                - grid[ti][tj] - grid[ri][rj]
                                - grid[bi][bj] - grid[li][lj];
                    sums.insert(s);
                }
            }
        vector<int> ans;
        for (auto it = sums.rbegin(); it != sums.rend() && (int)ans.size() < 3; ++it)
            ans.push_back((int)*it);
        return ans;
    }
};
```

### Python

```python
class Solution:
    def getBiggestThree(self, grid: list[list[int]]) -> list[int]:
        m, n = len(grid), len(grid[0])
        s1 = [[0] * n for _ in range(m)]                # ↘ 对角线前缀和
        s2 = [[0] * n for _ in range(m)]                # ↙
        for i in range(m):
            for j in range(n):
                a = s1[i - 1][j - 1] if i > 0 and j > 0 else 0
                b = s2[i - 1][j + 1] if i > 0 and j + 1 < n else 0
                s1[i][j] = grid[i][j] + a
                s2[i][j] = grid[i][j] + b

        def diag1(r1, c1, r2, c2):                      # ↘ 段和
            pre = s1[r1 - 1][c1 - 1] if r1 > 0 and c1 > 0 else 0
            return s1[r2][c2] - pre

        def diag2(r1, c1, r2, c2):                      # ↙ 段和
            pre = s2[r1 - 1][c1 + 1] if r1 > 0 and c1 + 1 < n else 0
            return s2[r2][c2] - pre

        sums = set()
        for ci in range(m):
            for cj in range(n):
                rmax = min(ci, m - 1 - ci, cj, n - 1 - cj)
                for r in range(rmax + 1):
                    if r == 0:
                        sums.add(grid[ci][cj])
                        continue
                    ti, tj = ci - r, cj                 # 上角
                    ri, rj = ci, cj + r                 # 右角
                    bi, bj = ci + r, cj                 # 下角
                    li, lj = ci, cj - r                 # 左角
                    total = (diag1(ti, tj, ri, rj)      # T→R
                             + diag2(ri, rj, bi, bj)    # R→B
                             + diag1(li, lj, bi, bj)    # L→B
                             + diag2(ti, tj, li, lj)    # T→L
                             - grid[ti][tj] - grid[ri][rj]
                             - grid[bi][bj] - grid[li][lj])  # 四角各扣一次
                    sums.add(total)
        return sorted(sums, reverse=True)[:3]
```

> 💡 两份代码均通过官方三个示例（`[228,216,211]`、`[20,9,8]`、`[7]`），并与「沿周长逐格累加」的暴力实现大规模对拍：C++ 侧 5 万组随机网格（至多 $8\times 8$）+ $50 \times 50$ 满规模性能冒烟，Python 侧 3300 组（含至多 $15 \times 15$），全部 `mismatch = 0`。

## 8. 边界情况与易错点

1. **单行/单列矩阵**（如 `[[7,7,7]]`）：`rmax = 0`，只有单格菱形，三个和全部相同，去重后返回 `[7]`。
2. **去重语义**：返回的是「互不相同的和」的前三，不是「前三个菱形」——相同数值只保留一个；不足三个全返回。
3. **前驱格子方向**：↘ 段查询减去的是起点的**左上**格 $(r_1-1, c_1-1)$，↙ 段减去的是起点的**右上**格 $(r_1-1, c_1+1)$。写反会得到错误段和（对拍时立刻暴露）。
4. **四角重复计算**：忘记扣除四角会把每个角多算一次（半径 1 时结果恰好翻倍错误）；用「四段和 − 四角」公式要一次到位。
5. **$r=0$ 不要走公式**：退化情形四段全指向中心，公式结果虽然凑巧正确（$4g - 3g = g$，对 $r=0$ 实际是 $T=R=B=L$，四段和为 $4g$、扣四角 $4g$ 得 0——**不对**，$r=0$ 时公式给出 0 而非 $g$），必须特判直接加 $grid[ci][cj]$。（对拍能抓出这类退化错误。）
6. **返回类型**：和可能达到 $2 \times 10^7$，`int` 够用，但 C++ 里用 `long long` 累加更稳；返回时转 `int`。
7. **降序排列**：`set` 是升序，要用 `rbegin` 反向遍历；Python `sorted(..., reverse=True)`。
