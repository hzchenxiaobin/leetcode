# LeetCode 仅含置位位的最小整数 题解

## 1. 题目概述

- **标题 / 题号**：仅含置位位的最小整数（#3370，easy）
- **链接**：https://leetcode.cn/problems/smallest-number-with-all-set-bits/
- **来源**：LeetCode 第 426 场周赛 Q1
- **难度**：简单
- **标签**：位运算、数学

**题意**：给定正整数 `n`，返回大于等于 `n` 且二进制表示中每一位都是 **置位位**（值为 `1`）的最小整数 `x`。换句话说，找最小的 `x >= n`，使 `x` 的二进制形如 `111...1`（全 `1`）。

**约束**：

- `1 <= n <= 1000`

## 2. 示例

**示例 1**

```text
输入：n = 5
输出：7
解释：7 的二进制表示是 "111"。
```

**示例 2**

```text
输入：n = 10
输出：15
解释：15 的二进制表示是 "1111"。
```

**示例 3**

```text
输入：n = 3
输出：3
解释：3 的二进制表示是 "11"，本身已全为 1。
```

## 3. 解题思路

### 3.1 暴力思路

从 `n` 开始逐个向上枚举 `x = n, n+1, n+2, ...`，检查 `x` 是否全 `1`。由于 `n <= 1000`，答案不超过 `1023`，最多枚举一千多次，比赛时完全能过。

但逐位检查写起来繁琐，且没有沉淀价值——签到题的目标是找到**从题面到代码的最短路径**。

### 3.2 核心观察：全 1 数就是梅森数 $2^b - 1$

![全1候选序列](images/all_set_bits_sequence.svg)

二进制全 `1` 的数只有一种形状：`b` 个 `1` 连排，其值为

$$
\underbrace{11\cdots1}_{b \text{ 位}} = 2^b - 1
$$

即**梅森数**序列 `1, 3, 7, 15, 31, 63, ...`。候选答案极少且严格递增，所以答案是**第一个满足 $2^b - 1 \ge n$ 的梅森数**。

### 3.3 算法流程：一步取位数

![核心观察：位数与答案](images/all_set_bits_concept.svg)

设 `b = n` 的二进制位数（`bit_length`），则 $2^{b-1} \le n < 2^b$。**答案就是 $2^b - 1$**，无需任何比较：

- 若 `n` 本身全 `1`：则 `n` 恰好等于 $2^b - 1$，答案就是 `n` 自己；
- 否则：$n < 2^b - 1$，而位数更少的全 `1` 数最大只有 $2^{b-1} - 1 < 2^{b-1} \le n$，都不够，所以 $2^b - 1$ 就是最小的满足者。

两种情况被同一个表达式 $2^b - 1$ 统一覆盖，一行代码即可：

```python
return (1 << n.bit_length()) - 1
```

### 3.4 示例演算

![示例演算表](images/all_set_bits_walkthrough.svg)

| n | 二进制 | b = 位数 | $2^b - 1$ | 答案 | 说明 |
|---|--------|---------|-----------|------|------|
| 3 | `11` | 2 | 3 | 3 | 本身全 1，取自身 |
| 5 | `101` | 3 | 7 | 7 | `11`=3 < 5，取 `111` |
| 8 | `1000` | 4 | 15 | 15 | `111`=7 < 8，取 `1111` |
| 10 | `1010` | 4 | 15 | 15 | 同上 |
| 1000 | `1111101000` | 10 | 1023 | 1023 | 上界情形 |

## 4. 算法细节

1. **位数获取**：Python 用 `n.bit_length()`；C++ 用内置 `__lg(n)`（即 $\lfloor \log_2 n \rfloor$，等于 `bit_length - 1`）或 C++20 的 `std::bit_width(n)`。
2. **构造答案**：`b` 位全 `1` 的数 = `(1 << b) - 1`，也可从 `1` 出发反复 `x = (x << 1) | 1` 向左"生长"出全 `1` 串。
3. **统一表达式**：`(1 << (n.bit_length())) - 1` 同时覆盖"`n` 本身全 1"与"需要进位"两种情况，不需要 if 分支。
4. **备用写法（枚举版）**：`x = 1; while (x < n) x = (x << 1) | 1;`，循环次数不超过 11 次（$n \le 1000 < 2^{10}$），同样 `O(1)`。

## 5. 正确性证明

**引理 1**：二进制表示全为 `1` 的正整数 `x` 必形如 $2^b - 1$（`b >= 1`），且序列 $2^1-1 < 2^2-1 < \cdots$ 严格递增。

**证明**：`b` 个 `1` 的二进制数按位权求和为 $\sum_{i=0}^{b-1} 2^i = 2^b - 1$。`b` 增大时值严格增大。∎

**引理 2**：设 `b = bit_length(n)`，则 $2^{b-1} \le n \le 2^b - 1$。

**证明**：`b` 为 `n` 的最高位索引加一，故 $2^{b-1} \le n < 2^b$，又 $2^b - 1 = 2^b - 1$ 是该区间上界。∎

**定理**：对任意正整数 `n`，满足 `x >= n` 且二进制全 `1` 的最小整数 `x` 为 $2^b - 1$，其中 `b = bit_length(n)`。

**证明**：由引理 2，$2^b - 1 \ge n$，故 $2^b - 1$ 是合法候选。再证最小：位数少于 `b` 的全 `1` 数最大为 $2^{b-1} - 1 < 2^{b-1} \le n$（引理 2），均不满足 `x >= n`；而位数相同的全 `1` 数唯一（就是 $2^b - 1$）。故 $2^b - 1$ 是最小合法解。∎

## 6. 复杂度分析

- **时间复杂度**：`O(1)`。`bit_length` 与移位均为常数次机器指令；`n <= 1000`，答案不超过 10 位。
- **空间复杂度**：`O(1)`。仅用常数个变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int smallestNumber(int n) {
        // __lg(n) = floor(log2(n)) = bit_length(n) - 1
        return (1 << (__lg(n) + 1)) - 1;
    }
};
```

枚举版（不依赖内置函数，更直白）：

```cpp
class Solution {
public:
    int smallestNumber(int n) {
        int x = 1;
        while (x < n) {
            x = (x << 1) | 1;   // 1 -> 11 -> 111 -> 1111 ...
        }
        return x;
    }
};
```

### Python

```python
class Solution:
    def smallestNumber(self, n: int) -> int:
        return (1 << n.bit_length()) - 1
```

## 8. 边界情况与易错点

1. **n 本身全 1**：如 `n = 1, 3, 7`，答案就是 `n` 自己。若实现时先"进一位再补 1"（即返回 $2^{b+1} - 1$）会得到错误的大一档答案——用统一公式 `(1 << bit_length) - 1` 天然规避。
2. **n = 1（下界）**：`bit_length(1) = 1`，答案 `1`，勿特判漏掉。
3. **n = 1000（上界）**：`1000 = 0b1111101000`，10 位，答案 `1023`，`int` 范围绰绰有余，无溢出风险。
4. **误判"置位位"**：题面是"仅包含置位位"，即每一位都必须是 `1`（不是"至少一个 1"或"含某个指定位置 1"），审题别偏。
5. **C++ 内置函数选择**：`__lg(1) = 0` 正确；若用 `std::bit_width` 则直接 `(1 << std::bit_width(n)) - 1`，注意两者相差 1，别混用。
