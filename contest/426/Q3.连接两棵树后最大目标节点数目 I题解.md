# LeetCode 连接两棵树后最大目标节点数目 I 题解

## 1. 题目概述

- **标题 / 题号**：连接两棵树后最大目标节点数目 I（#3372，medium）
- **链接**：https://leetcode.cn/problems/maximize-the-number-of-target-nodes-after-connecting-trees-i/
- **来源**：LeetCode 第 426 场周赛 Q3
- **难度**：中等
- **标签**：树、广度优先搜索、深度优先搜索

**题意**：给两棵无向树（节点数分别为 $n$、$m$）与整数 $k$。若节点 $u$ 到 $v$ 的路径边数 **$\le k$**，则称 $u$ 是 $v$ 的**目标节点**（自己一定是自己的目标节点）。对每个 $i \in [0, n)$：允许在树 1 中任选一个节点 $a$、树 2 中任选一个节点 $b$，连上一条边 $(a,b)$，使树 1 中节点 $i$ 在**合并后的整棵树**里的目标节点数目最多；各查询相互独立（连完要拆掉）。返回长度为 $n$ 的数组 $answer$。

**约束**：

- $2 \le n, m \le 1000$
- $\text{edges1.length} = n - 1$，$\text{edges2.length} = m - 1$
- $0 \le k \le 1000$
- 输入保证 edges1、edges2 都构成合法的树

> 💡 **读题关键**：① 连边的两个端点**都可以任选**，并非必须连节点 $i$（示例 1 的解释里，各查询在树 1 侧连的节点未必是 $i$）；② 目标节点可以来自**两棵树**——答案 = 树 1 贡献 + 树 2 贡献；③ 本题与同场 Q4（#3373）同框架不同问法：Q3 是"距离 $\le k$"且 $n, m \le 1000$，逐点 BFS 即可；Q4 换成"**偶数距离**"且 $n, m \le 10^5$，必须线性做法。

## 3. 解题思路

### 3.1 暴力思路

对每个查询 $i$，枚举连法 $(a, b)$（共 $n \times m$ 种），连边后对整图做一次 BFS，数出与 $i$ 距离 $\le k$ 的节点个数，取最大：

- 单次 BFS 代价 $O(n+m)$，单查询 $O(nm \cdot (n+m))$，总计 $O(n^2 m (n+m))$——$n = m = 1000$ 时约 $2 \times 10^{12}$，严重超时；
- 即使已经想到"贡献拆成两棵树"，若没看穿"**树 2 的最优贡献是一个与 $i$ 无关的常量**"，仍会对每个 $i$ 重复求一遍树 2 侧的最优，白跑 $n$ 遍。

> 💡 暴力的浪费在于：$n \times m$ 种连法看似自由度巨大，实际只有两个标量在起作用——树 1 侧的"内部计数"与树 2 侧的"剩余预算"。把这两个量拆干净，连法根本不用枚举。

### 3.2 核心观察：桥边拆解 + 贪心取 $a = i$

![加桥边后的路径分解](images/wc426_q3_bridge_budget.svg)

**观察 1（树 1 内部距离不变）**：两棵树加一条边 $(a,b)$ 后仍是**一棵更大的树**（$n+m$ 个节点、$n+m-1$ 条边、连通无环）。树 1 内部两点间的路径永远不会跨过桥——跨过去就必须再跨回来，而树中路径唯一、不许重复走边。于是查询 $i$ 在树 1 内的目标节点数**与连法无关**，记

$$
count_1[i] = \#\{\, x \in T_1 : d_1(i, x) \le k \,\}
$$

其中 $d_1$ 是树 1 内的距离函数。这部分只需求 $n$ 次受限 BFS。

**观察 2（跨树路径分解）**：$i$（树 1）到 $w$（树 2）的唯一路径必经桥**恰好一次**，形态完全固定：

$$
\text{dist}(i, w) = d_1(i, a) + 1 + d_2(b, w) \le k
\iff d_2(b, w) \le k - d_1(i, a) - 1
$$

**观察 3（贪心：取 $a = i$）**：树 2 侧的"距离预算"为 $k - d_1(i,a) - 1$，随 $d_1(i,a)$ 增大而缩小；而树 1 侧贡献又与连法无关（观察 1）。于是最优连法就是"**$i$ 直连树 2 中最优的 $b$**"，树 2 贡献收缩为一个**全局常量**：

$$
best2 = \max_{b \in T_2} \#\{\, y \in T_2 : d_2(b, y) \le k-1 \,\}
$$

> 💡 **一句话结论**：
> $$answer[i] = count_1[i] + best2$$
> 树 1 侧逐点算，树 2 侧**只算一次**；$k = 0$ 时预算 $k-1 < 0$，$best2 = 0$。

### 3.3 算法流程

![算法流程](images/wc426_q3_bfs_count.svg)

1. 建两棵树的邻接表；
2. 对树 1 的每个节点 $i$ 做一次**限制深度 $\le k$ 的 BFS**，数出 $count_1[i]$；
3. 若 $k \ge 1$：对树 2 的每个节点 $b$ 做一次**限制深度 $\le k-1$ 的 BFS**，取最大得 $best2$；$k = 0$ 则 $best2 = 0$；
4. $answer[i] = count_1[i] + best2$。

限制深度的 BFS 写法：只有 $dist < r$ 的节点才向外扩展，搜索天然被圈在半径内——$k$ 小的时候连整棵树都不必遍历完，实际远好于 $O(n^2)$ 上界。

### 3.4 示例演算

![示例 1 演算](images/wc426_q3_example_walkthrough.svg)

以示例 1 走查（$k = 2$，树 1 五个点、树 2 八个点）：

| 步骤 | 计算 | 结果 |
|---|---|---|
| 树 1 逐点 BFS（半径 2） | $count_1 = [5, 3, 5, 4, 4]$ | 节点 1 到 3、4 的距离为 3，只数到 $\{1,0,2\}$ |
| 树 2 逐点 BFS（半径 1） | $cnt_2 = [4,3,3,2,4,2,2,2]$ | $best2 = 4$（$b = 0$ 或 $4$，即树 2 的"局部中心"） |
| 拼答案 | $count_1[i] + 4$ | $[9, 7, 9, 8, 8]$ ✓ |

## 4. 算法细节

1. **限制深度的 BFS**：队列里只放 $dist \le r$ 的节点，弹出时若 $dist = r$ 就不再扩展。半径小则提前终止，实测远快于平方上界。
2. **$k = 0$ 特判**：预算 $k - 1 = -1$，树 2 永远贡献 0，$best2 = 0$；此时 $count_1[i] = 1$（只有自己），$answer[i] = 1$。代码里 `r < 0` 的短路正是防这个。
3. **必须迭代 / BFS**：链状树递归深度达 $n = 1000$，恰好卡在 Python 默认递归上限上，递归 DFS 有 `RecursionError` 风险；BFS 天然规避。
4. **距离数组的开销**：每次 BFS 分配新 $dist$ 数组（$O(n)$）总代价 $O(n^2)$，$n \le 1000$ 完全可接受；追求常数可用"时间戳"版本标记避免反复清空。
5. **建图**：邻接表即可，$n, m \le 1000$ 无内存压力。
6. **不显式加边**：整套做法从头到尾没有真的连过边——这是"拆解法"的工程红利，天然满足"查询相互独立"。

## 5. 正确性证明

**引理 1（整图为树；树 1 内部路径不跨桥）**：连边 $(a,b)$ 后的图 $G$ 是树；且对同属树 1 的 $x, y$，$G$ 中 $x \to y$ 的路径就是树 1 中 $x \to y$ 的路径，长度 $d_1(x, y)$。

**证明**：$G$ 有 $n+m$ 个节点、$(n-1)+(m-1)+1 = n+m-1$ 条边且连通，故是树，任意两点路径唯一。树 1 自身含有 $x \to y$ 的一条路径，由唯一性，它就是 $G$ 中 $x \to y$ 的路径。∎

**引理 2（跨桥路径形态）**：$i$ 属树 1、$w$ 属树 2 时，$G$ 中 $\text{dist}(i, w) = d_1(i, a) + 1 + d_2(b, w)$。

**证明**：桥是两棵树之间唯一的连接边，$i \to w$ 的路径必经桥**恰好一次**（经两次必重复走边，树中不可能）；桥之前的部分构成树 1 中 $i \to a$ 的路径，桥之后的部分构成树 2 中 $b \to w$ 的路径，由树中路径唯一性，两段长度分别恰为 $d_1(i,a)$ 与 $d_2(b,w)$。∎

**定理**：对每个 $i$，$answer[i] = count_1[i] + best2$，其中 $best2 = 0$（若 $k = 0$），否则 $best2 = \max_{b \in T_2} \#\{y \in T_2 : d_2(b,y) \le k-1\}$。

**证明**：目标节点集 = 树 1 部分 $\cup$ 树 2 部分，二者不相交。

- **树 1 部分**：由引理 1，无论连法如何，恒为 $\{x \in T_1 : d_1(i,x) \le k\}$，大小 $count_1[i]$。
- **树 2 部分上界**：由引理 2，$w \in T_2$ 是目标 $\iff d_2(b, w) \le k - d_1(i,a) - 1$；而 $d_1(i,a) \ge 0$，故对**任何**连法 $(a,b)$，合法的 $w$ 都落在 $\{y : d_2(b, y) \le k-1\}$ 内，个数不超过 $best2$。$k = 0$ 时 $k - d_1(i,a) - 1 \le -1 < 0$，任何连法下树 2 部分为空，上界 0。
- **可达**：$k \ge 1$ 时取 $a = i$、$b$ 取到 $best2$ 的节点，则条件化为 $d_2(b, w) \le k-1$，树 2 部分恰有 $best2$ 个；树 1 部分不受影响（引理 1）。$k = 0$ 时 $best2 = 0$，任何连法都同时取到两部分的上界。

上界与构造吻合，定理得证。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n^2 + m^2)$。树 1 做 $n$ 次 BFS、树 2 做 $m$ 次，每次 $O(\text{所在树的大小})$，限制深度时更少；$n, m \le 1000$ 时总计不超过 $2 \times 10^6$ 级别，稳过。
- **空间复杂度**：$O(n + m)$。邻接表与单次 BFS 的距离数组均线性；输出数组不计入额外空间。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    vector<int> maxTargetNodes(vector<vector<int>>& edges1, vector<vector<int>>& edges2, int k) {
        int n = edges1.size() + 1, m = edges2.size() + 1;
        auto g1 = build(n, edges1);
        auto g2 = build(m, edges2);

        int best2 = 0;                       // k = 0 时预算为负，树 2 无从贡献
        if (k > 0) {
            for (int b = 0; b < m; b++)
                best2 = max(best2, countWithin(g2, b, k - 1));
        }

        vector<int> ans(n);
        for (int i = 0; i < n; i++)
            ans[i] = countWithin(g1, i, k) + best2;
        return ans;
    }

  private:
    vector<vector<int>> build(int n, vector<vector<int>>& edges) {
        vector<vector<int>> g(n);
        for (auto& e : edges) {
            g[e[0]].push_back(e[1]);
            g[e[1]].push_back(e[0]);
        }
        return g;
    }

    // 与 s 距离 <= r 的节点个数（r < 0 时为 0），BFS 限制在半径内
    int countWithin(vector<vector<int>>& g, int s, int r) {
        if (r < 0) return 0;
        int cnt = 0;
        vector<int> dist(g.size(), -1);
        queue<int> q;
        dist[s] = 0;
        q.push(s);
        while (!q.empty()) {
            int u = q.front();
            q.pop();
            cnt++;                          // 入过队的都在半径内
            if (dist[u] == r) continue;     // 抵达边界，不再扩展
            for (int v : g[u]) {
                if (dist[v] < 0) {
                    dist[v] = dist[u] + 1;
                    q.push(v);
                }
            }
        }
        return cnt;
    }
};
```

### Python

```python
class Solution:
    def maxTargetNodes(self, edges1: List[List[int]], edges2: List[List[int]], k: int) -> List[int]:
        def build(n: int, edges: List[List[int]]) -> List[List[int]]:
            g = [[] for _ in range(n)]
            for a, b in edges:
                g[a].append(b)
                g[b].append(a)
            return g

        def count_within(g: List[List[int]], s: int, r: int) -> int:
            if r < 0:
                return 0
            dist = {s: 0}
            q = deque([s])
            cnt = 0
            while q:
                u = q.popleft()
                cnt += 1
                if dist[u] == r:
                    continue
                for v in g[u]:
                    if v not in dist:
                        dist[v] = dist[u] + 1
                        q.append(v)
            return cnt

        n, m = len(edges1) + 1, len(edges2) + 1
        g1, g2 = build(n, edges1), build(m, edges2)

        best2 = 0 if k == 0 else max(count_within(g2, b, k - 1) for b in range(m))

        return [count_within(g1, i, k) + best2 for i in range(n)]
```

## 8. 边界情况与易错点

1. **忘扣桥的 1 条边**：树 2 的半径必须是 $k-1$ 而不是 $k$。示例 1 若误用 $k$，则 $best2$ 变成 6（$b=0$ 时距离 $\le 2$ 的有 6 个点），$i = 1$ 会错算成 9，与 $i = 0$ 无法区分。
2. **$k = 0$ 忘特判**：预算 $k - 1 = -1$，`countWithin(g2, b, -1)` 必须返回 0；否则会把"到不了"的地方数进去。
3. **误以为必须连节点 $i$**：题面端点任选。取 $a = i$ 恰好是观察 3 论证出的最优（预算最大），硬编码 $a = i$ 的代码是对的——但要想清楚**为什么**对，否则换个问法（比如 Q4）同样的直觉未必成立。
4. **递归 DFS 爆栈**：$n, m \le 1000$ 的链递归深度恰为 1000，压着 Python 默认上限，DFS 递归写法有 `RecursionError` 风险，BFS 稳。
5. **漏数源点自己**：$d(i,i) = 0 \le k$ 恒成立，自己永远是自己的目标节点，计数别漏。
6. **查询相互独立**：别把上一查询的边留在图里。本做法根本不显式加边，天然无此风险。
7. **答案上界自查**：$answer[i] \le n + m \le 2000$，`int` 无溢出风险。
8. **别上更重的算法**：$n, m \le 1000$ 的数据范围就是"逐点 BFS"的暗示（$O(n^2)$ 可过）；Q4 规模升到 $10^5$ 才需要奇偶染色的线性做法，别提前优化。
