# LeetCode 识别数组中的最大异常值 题解

## 1. 题目概述

- **标题 / 题号**：识别数组中的最大异常值（#3371，medium）
- **链接**：https://leetcode.cn/problems/identify-the-largest-outlier-in-an-array/
- **来源**：LeetCode 第 426 场周赛 Q2
- **难度**：中等
- **标签**：数组、哈希表、计数、枚举

**题意**：给定整数数组 `nums`，共 $n$ 个元素，其中恰好有 $n-2$ 个是**特殊数字**；剩下的两个中，一个是所有特殊数字的**和**（它本身也是数组元素），另一个是**异常值**（既非特殊数字、也非那个"和"）。三种角色的**下标**必须互不相同，但**值可以重复**。返回所有合法拆分中**最大**的异常值。

**约束**：

- $3 \le nums.length \le 10^5$
- $-1000 \le nums[i] \le 1000$
- 输入保证至少存在一个可能的异常值

> 💡 **读题关键**：① "和"不是抽象数字，而是**真实存在于数组中的一个元素**，其值等于其余 $n-2$ 个特殊数字之和；② 问的是"**可能的**最大异常值"——同一数组或有多种合法拆分，取最大者；③ "下标互异、值可相同"（示例 3 是命题人挖好的坑）。

## 2. 示例

**示例 1**

```text
输入：nums = [2,3,5,10]
输出：10
解释：特殊数字为 2、3，和为 5（也是数组元素），异常值为 10。
```

**示例 2**

```text
输入：nums = [-2,-1,-3,-6,4]
输出：4
解释：特殊数字为 -2、-1、-3，和为 -6，异常值为 4。
```

**示例 3**

```text
输入：nums = [1,1,1,1,1,5,5]
输出：5
解释：特殊数字为五个 1，和为 5；另一个 5 为异常值——值相同、下标不同。
```

## 3. 解题思路

### 3.1 暴力思路

枚举哪两个下标 $i$、$j$ 分别充当"和元素"与"异常值"，验证其余 $n-2$ 个元素之和是否恰好等于 $nums[i]$：

- 朴素写法：$O(n^2)$ 对组合 × $O(n)$ 求和验证 = $O(n^3)$；
- 预计算总和把验证降到 $O(1)$，仍有 $O(n^2)$ 对组合——$n = 10^5$ 时约 $10^{10}$ 次运算，必超时。

> 💡 暴力的浪费在于：**"和元素"一旦确定，异常值就被数组总和唯一锁死**——根本不需要枚举第二个下标。这正是下面的突破口。

### 3.2 核心观察：总和恒等式 total = 2T + x

![总和恒等式](images/outlier_sum_identity.svg)

设特殊数字之和为 $T$、异常值为 $x$、数组总和为 $\text{total}$。把整个数组加起来时，$T$ 被**数了两次**——特殊数字贡献一次，"和元素"的值又是 $T$、再贡献一次：

$$
\text{total} = \underbrace{T}_{\text{特殊数字之和}} + \underbrace{T}_{\text{和元素的值}} + x = 2T + x
$$

移项即得 $x = \text{total} - 2T$。而 $T$ **必然是数组中的某个元素**（和元素就在数组里），于是只需枚举每个元素 $s$ 充当 $T$，$O(1)$ 反解出候选异常值 $cand = \text{total} - 2s$，再查哈希表确认 $cand$ 在数组中"另有出现"即可。

更妙的是**存在即合法**：设 $cand$ 出现在下标 $j \ne i$，则其余 $n-2$ 个元素之和

$$
\text{total} - s - cand = \text{total} - s - (\text{total} - 2s) = s
$$

恰好等于"和元素"的值——拆分自动成立，**无需任何额外验证**。

### 3.3 算法流程

![算法流程图](images/outlier_enumerate_flow.svg)

两趟线性扫描：

1. **第一趟**：累加 $\text{total}$，同时建哈希计数表 $cnt$（值 → 出现次数）；
2. **第二趟**：枚举每个 $s \in nums$ 充当"和元素"，计算 $cand = \text{total} - 2s$；
3. **存在性检查（带同值修正）**：若 $cand = s$，则该值需出现 $\ge 2$ 次（一个下标当和、另一个当异常值）；否则出现 $\ge 1$ 次即可；
4. 通过检查则更新 $ans = \max(ans, cand)$，枚举结束返回 $ans$。

### 3.4 示例演算

![示例演算表](images/outlier_example_walkthrough.svg)

以示例 2 `nums = [-2,-1,-3,-6,4]`（$\text{total} = -8$）走查第二趟：

| $s$（充当和） | $cand = \text{total} - 2s$ | 在数组中？ | 更新 ans |
|---|---|---|---|
| $-2$ | $-8+4 = -4$ | ✗ | — |
| $-1$ | $-8+2 = -6$ | ✓ | $-6$ |
| $-3$ | $-8+6 = -2$ | ✓ | $-2$ |
| $-6$ | $-8+12 = 4$ | ✓ | **4** |
| $4$ | $-8-8 = -16$ | ✗ | — |

答案为 $4$，对应拆分：特殊数字 $-2,-1,-3$、和元素 $-6$、异常值 $4$。

再对照示例 3 的同值坑：`[1,1,1,1,1,5,5]`，$\text{total} = 15$。枚举 $s=1$ 时 $cand = 13$ ✗；枚举 $s=5$ 时 $cand = 5$，此时 $cand = s$，必须确认 $cnt[5] \ge 2$——恰好有两个 5，一个当和元素、一个当异常值 ✓，答案 $5$。

## 4. 算法细节

1. **枚举方向选"和"而不是"异常值"**：若枚举异常值 $x$ 反解 $T = (\text{total} - x)/2$，需先判 $\text{total} - x$ 的**奇偶性**；枚举和元素则 $cand = \text{total} - 2s$ 永远是整数，无除法无奇偶，干净利落。
2. **计数结构**：`unordered_map` / `Counter` 通用；注意到 $|nums[i]| \le 1000$，值域只有 2001 个整数，可用长度 2001 的计数数组（下标 = 值 + 1000）替代，常数更小。
3. **同值修正统一写法**：$cnt[cand] \ge (cand = s\ ?\ 2 : 1)$。$cand = s$ 时要两个不同下标，故需出现两次；$cand \ne s$ 时值不同下标自然不同，一次即可。
4. **答案初始化为 $-\infty$**：异常值可为负（如 `[-10,5,5]` 的唯一合法异常值是 $-10$），初始化成 `0` 会被 $\max$ 吞掉负数解。
5. **值域桶判界**：$cand = \text{total} - 2s$ 可达 $\pm 10^8$，远超 $[-1000, 1000]$ 值域，落桶前必须判界；哈希表查不到自动 miss，无此问题。
6. **溢出**：$|\text{total}| \le 10^5 \times 1000 = 10^8$，`int` 尚装得下，但相减时建议用 64 位兜底。

## 5. 正确性证明

**引理 1（恒等式）**：任何合法拆分都满足 $\text{total} = 2T + x$，其中 $T$ 为特殊数字之和，$x$ 为异常值。

**证明**：合法拆分按互异下标把数组分成三部分：$n-2$ 个特殊数字（和为 $T$）、一个值为 $T$ 的和元素、一个值为 $x$ 的异常值。三部分覆盖全体元素，故 $\text{total} = T + T + x = 2T + x$。∎

**引理 2（存在即合法）**：设 $s = nums[i]$，$cand = \text{total} - 2s$。若存在下标 $j \ne i$ 使 $nums[j] = cand$（$cand = s$ 时即该值出现 $\ge 2$ 次），则"$i$ 当和元素、$j$ 当异常值、其余当特殊数字"是合法拆分。

**证明**：其余 $n-2$ 个元素之和为

$$
\text{total} - nums[i] - nums[j] = \text{total} - s - (\text{total} - 2s) = s = nums[i],
$$

恰好等于和元素的值，合法性定义满足。∎

**定理**：算法返回值恰为所有合法拆分中异常值的最大值。

**证明**：分两个方向。

- **不漏**（每个合法异常值都被枚举到）：设某合法拆分的和元素在下标 $i$、异常值为 $x$。由引理 1，$x = \text{total} - 2\,nums[i]$；算法枚举 $s = nums[i]$ 时算出的 $cand$ 恰为 $x$，且 $x$ 在下标 $j \ne i$ 处出现，必通过存在性检查，参与取 $\max$。
- **不重**（通过检查的 cand 都合法）：由引理 2，每个通过检查的 $cand$ 都对应一个合法拆分，不会把非法值误报为异常值。

两方向合并，算法输出恰为合法异常值集合的最大值。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。第一趟求和 + 建表，第二趟枚举每个元素、每次 $O(1)$ 查表。
- **空间复杂度**：$O(n)$（哈希表存值 → 出现次数）；换成值域桶后为 $O(V)$，$V = 2001$，与 $n$ 无关。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int getLargestOutlier(vector<int>& nums) {
        long long total = accumulate(nums.begin(), nums.end(), 0LL);
        unordered_map<int, int> cnt;
        for (int v : nums) cnt[v]++;

        int ans = INT_MIN;                        // 异常值可能为负，初始化 −∞
        for (int s : nums) {                      // 枚举 s 充当「和」元素
            int cand = int(total - 2LL * s);      // 反解候选异常值
            int need = (cand == s) ? 2 : 1;       // 同值时须出现两次
            auto it = cnt.find(cand);
            if (it != cnt.end() && it->second >= need) ans = max(ans, cand);
        }
        return ans;
    }
};
```

值域桶版（值域仅 2001，常数更小）：

```cpp
class Solution {
  public:
    int getLargestOutlier(vector<int>& nums) {
        long long total = accumulate(nums.begin(), nums.end(), 0LL);
        array<int, 2001> cnt{};
        for (int v : nums) cnt[v + 1000]++;

        int ans = INT_MIN;
        for (int s : nums) {
            long long cand = total - 2LL * s;
            if (cand < -1000 || cand > 1000) continue;   // 判界！cand 可达 ±1e8
            int need = (cand == s) ? 2 : 1;
            if (cnt[cand + 1000] >= need) ans = max(ans, int(cand));
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def getLargestOutlier(self, nums: List[int]) -> int:
        total = sum(nums)
        cnt = Counter(nums)

        ans = float('-inf')
        for s in cnt:                      # 只枚举出现过的值（至多 2001 个）
            cand = total - 2 * s
            need = 2 if cand == s else 1   # 同值时须出现两次
            if cnt.get(cand, 0) >= need:
                ans = max(ans, cand)
        return ans
```

## 8. 边界情况与易错点

1. **同值陷阱（示例 3）**：`[1,1,1,1,1,5,5]` 中 $s=5$ 时 $cand=5$，必须确认 $cnt[5] \ge 2$——一个 5 当和元素、另一个当异常值。漏掉同值修正，此用例必挂。
2. **ans 初始化成 0**：异常值可为负，如 `[-10,5,5]` 的答案是 $-10$，若 `ans = 0` 则 $\max(0, -10) = 0$，返回错误答案。
3. **枚举方向搞反**：枚举"异常值"反解 $T = (\text{total} - x)/2$ 需额外判奇偶，除法与同值修正叠加容易写乱；推荐枚举"和元素"。
4. **值域桶不判界**：$cand$ 范围可达 $\pm 10^8$，直接 `cnt[cand + 1000]` 会数组越界（C++ 中为未定义行为），落桶前先判 $-1000 \le cand \le 1000$。
5. **n = 3 下界**：特殊数字只有 1 个，如 `[1,1,1]`（特殊数字 1、和 1、异常值 1，答案 1）。枚举逻辑天然覆盖，无需特判。
6. **重复枚举同一值**：第二趟对每个下标都检查一遍，同一值被重复计算但结果幂等，不影响正确性；追求常数可只枚举 `cnt` 的键（至多 2001 个）。
