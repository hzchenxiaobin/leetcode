# LeetCode 连接两棵树后最大目标节点数目 II 题解

## 1. 题目概述

- **标题 / 题号**：连接两棵树后最大目标节点数目 II（#3373，hard）
- **链接**：https://leetcode.cn/problems/maximize-the-number-of-target-nodes-after-connecting-trees-ii/
- **来源**：LeetCode 第 426 场周赛 Q4
- **难度**：困难
- **标签**：树、广度优先搜索、深度优先搜索、二分图染色

**题意**：给两棵无向树（节点数分别为 $n$、$m$）。若节点 $u$ 到 $v$ 的路径边数是**偶数**，则称 $u$ 是 $v$ 的**目标节点**（自己一定是自己的目标节点）。对每个 $i \in [0, n)$：允许在树 1 中任选一个节点 $a$、树 2 中任选一个节点 $b$，连上一条边 $(a,b)$，使树 1 中节点 $i$ 在**整个连通图**里的目标节点数目最多；各查询相互独立（连完要拆掉）。返回长度为 $n$ 的数组 $answer$。

**约束**：

- $2 \le n, m \le 10^5$
- 输入保证 edges1、edges2 都构成合法的树

> 💡 **读题关键**：① 连边的两个端点**都可以任选**，并非必须连节点 $i$（示例 1 的解释里，各查询在树 1 侧连的节点未必是 $i$）；② 目标节点可以来自**两棵树**——答案 = 树 1 贡献 + 树 2 贡献；③ 本题与同场 Q3（#3372）只是"目标"的定义不同：Q3 是"距离 $\le k$"且 $n, m \le 1000$，本题是"**偶数距离**"且 $n, m \le 10^5$，必须线性做法。

## 3. 解题思路

### 3.1 暴力思路

对每个查询 $i$，枚举连法 $(a, b)$（共 $n \times m$ 种），连边后对整图做一次 BFS，数出与 $i$ 偶距的节点个数，取最大：

- 单次 BFS 代价 $O(n+m)$，单查询 $O(nm \cdot (n+m))$，总计 $O(n^2 m (n+m))$——$n = m = 10^5$ 时约 $10^{20}$，天文数字；
- 即使已经想到"按奇偶染色"预处理距离奇偶，若没看穿"**答案与连法无关**"，仍要对每个 $i$ 枚举 $(a,b)$ 的 $O(nm) = 10^{10}$ 种组合，照样超时。

> 💡 暴力的浪费在于：连法 $(a,b)$ 看似自由度巨大，实际只有"**奇偶配平**"在起作用——把这一点想透，$(a,b)$ 根本不用枚举。

### 3.2 核心观察：树的深度奇偶二染色

![树的深度奇偶二染色](images/wc426_q4_parity_coloring.svg)

树中任意两点 $u, v$，任取根 $r$，有经典恒等式

$$
\text{dist}(u, v) = \text{depth}(u) + \text{depth}(v) - 2 \cdot \text{depth}(\mathrm{lca}(u, v))
$$

模 $2$ 后 $2 \cdot \text{depth}(\mathrm{lca})$ 一项消失，得到

$$
\text{dist}(u, v) \equiv \text{depth}(u) + \text{depth}(v) \pmod 2
$$

于是**按深度的奇偶给节点染成两色**，就有：**同色 $\Leftrightarrow$ 偶距，异色 $\Leftrightarrow$ 奇距**。这正是"树是二分图"的体现——每条边两端深度必然一奇一偶。

对树 1 染色后，节点 $i$ 在**树 1 内部**的目标节点就是与它同色的那一类，共 $C_1[\text{color}(i)]$ 个。关键在于：**这一部分与连边无关**——树 1 内部两点间的路径永远不会跨过桥边（桥是两棵树之间唯一的连接，跨过去就必须再跨回来，而树中路径唯一、不许重复走边）。

### 3.3 加桥边的路径分解：奇偶配平

![加桥边后的路径分解](images/wc426_q4_bridge_analysis.svg)

连上 $(a, b)$ 后，整个图恰好还是**一棵更大的树**：$n + m$ 个节点、$(n-1)+(m-1)+1 = n+m-1$ 条边、连通无环。于是 $i$（树 1）到 $w$（树 2）的唯一路径必然**恰好经过桥一次**，形态完全固定：

$$
\text{dist}(i, w) = \underbrace{\text{dist}_1(i, a)}_{p_1} + \underbrace{1}_{\text{桥}} + \underbrace{\text{dist}_2(b, w)}_{p_2}
$$

$w$ 是 $i$ 的目标节点 $\iff p_1 + p_2 \equiv 1 \pmod 2$，分两种情况讨论：

- **情况 A**（$a$ 与 $i$ 同色，$p_1$ 为偶）：需要 $p_2$ 为奇，即 $w$ 与 $b$ **异色**。把 $b$ 放进树 2 的**小类**，$w$ 就能取遍**大类**，贡献 $\max C_2$；
- **情况 B**（$a$ 与 $i$ 异色，$p_1$ 为奇）：需要 $p_2$ 为偶，即 $w$ 与 $b$ **同色**。把 $b$ 放进树 2 的**大类**，$w$ 同样取遍大类，贡献 $\max C_2$。

两种情况殊途同归：**树 2 的贡献恒为 $\max(C_2[0], C_2[1])$**。它也不可能更大——合法的 $w$ 永远被限制在树 2 的**某一个**颜色类里（$w$ 的颜色由 $b$ 的颜色和 $p_1$ 的奇偶唯一确定），单类大小的上界就是 $\max C_2$。

> 💡 **一句话结论**：
> $$answer[i] = C_1[\text{color}(i)] + \max(C_2[0], C_2[1])$$
> 与连哪条边、连哪两个节点**完全无关**。困难的部分全在推理，代码只是两次 BFS。

### 3.4 示例演算

![示例 1 演算](images/wc426_q4_example_walkthrough.svg)

以示例 1 走查（树 1 五个点、树 2 八个点）：

| 步骤 | 树 1 | 树 2 |
|---|---|---|
| 染色（从 0 出发 BFS） | 偶层 $\{0,3,4\}$、奇层 $\{1,2\}$ | 偶层 $\{0,4,7\}$、奇层 $\{1,2,3,5,6\}$ |
| 两类大小 | $C_1 = (3, 2)$ | $C_2 = (3, 5)$，故 $\max C_2 = 5$ |

套公式 $answer[i] = C_1[\text{color}(i)] + 5$：节点 0、3、4 属偶层（$3 + 5 = 8$），节点 1、2 属奇层（$2 + 5 = 7$），得 $[8,7,7,8,8]$，与预期一致。

## 4. 算法细节

1. **染色实现**：从任意节点（如 0）出发 BFS，`col[v] = col[u] ^ 1`。$n, m \ge 2$ 的树至少有一条边，两类都非空；换根至多让两类整体互换，不影响"两类各自大小"的计数。
2. **必须迭代 / BFS**：$n, m \le 10^5$，链状树递归深度达 $10^5$——Python 默认递归上限 1000 必抛 `RecursionError`，C++ 也有栈溢出风险，BFS 天然规避。
3. **建图**：邻接表 `vector<vector<int>>` 即可（内存足够）；追求常数可用链式前向星。
4. **统计与输出**：数出 $C_1[0], C_1[1], C_2[0], C_2[1]$，取 $best = \max(C_2[0], C_2[1])$，则 $answer[i] = C_1[\text{col}_1[i]] + best$，一次遍历收尾。
5. **不需要枚举 $(a,b)$**：由 §5 定理，任意连法能达到的最优值都相同；构造上取 $a = i$、$b$ 为树 2 小类中任一节点即可达到上界。

## 5. 正确性证明

**引理 1（奇偶引理）**：树 $T$ 任取根 $r$，对任意两点 $u, v$ 有 $\text{dist}(u,v) \equiv \text{depth}(u) + \text{depth}(v) \pmod 2$。

**证明**：设 $l = \mathrm{lca}(u, v)$，则 $u \to v$ 的路径由 $u \rightarrow l$ 与 $l \rightarrow v$ 两段拼成，边数 $= (\text{depth}(u) - \text{depth}(l)) + (\text{depth}(v) - \text{depth}(l)) = \text{depth}(u) + \text{depth}(v) - 2\,\text{depth}(l)$，模 $2$ 即得。∎

**推论 1**：同色 $\Leftrightarrow$ 偶距，异色 $\Leftrightarrow$ 奇距。且**换根不改变划分**：设新根 $r'$，则对任意 $v$ 有 $\text{depth}'(v) \equiv \text{depth}(v) + \text{dist}(r, r') \pmod 2$，全体节点的深度奇偶统一平移同一常数，两类要么不动、要么整体互换。

**引理 2（整图仍为树；树 1 内部路径不跨桥）**：连边 $(a,b)$ 后的图 $G$ 是树；且对同属树 1 的 $x, y$，$G$ 中 $x \to y$ 的路径就是树 1 中 $x \to y$ 的路径，不经过桥。

**证明**：$G$ 有 $n+m$ 个节点、$(n-1)+(m-1)+1 = n+m-1$ 条边且连通，故是树，任意两点路径唯一。树 1 自身含有 $x \to y$ 的一条路径，由唯一性，它就是 $G$ 中 $x \to y$ 的路径。∎

**引理 3（跨桥路径形态）**：$i$ 属树 1、$w$ 属树 2 时，$G$ 中 $i \to w$ 的路径长度 $= \text{dist}_1(i, a) + 1 + \text{dist}_2(b, w)$。

**证明**：桥是两棵树之间唯一的连接边，$i \to w$ 的路径必经桥**恰好一次**；桥之前的部分构成树 1 中 $i \to a$ 的路径，桥之后的部分构成树 2 中 $b \to w$ 的路径，由树中路径唯一性，两段长度分别恰为 $\text{dist}_1(i,a)$ 与 $\text{dist}_2(b,w)$。∎

**定理**：对每个 $i$，$answer[i] = C_1[\text{color}(i)] + \max(C_2[0], C_2[1])$。

**证明**：目标节点集 = 树 1 部分 $\cup$ 树 2 部分，二者不相交。

- **上界**：树 1 部分由引理 1、2，恰为"$i$ 的同色类"，大小 $C_1[\text{color}(i)]$，与连法无关。树 2 部分：$w$ 是目标 $\iff \text{dist}_2(b,w) \equiv \text{dist}_1(i,a) + 1 \pmod 2$（引理 3），即 $w$ 落在由 $\text{color}(b)$ 与 $\text{dist}_1(i,a)$ 奇偶**唯一确定的一个颜色类**中，大小不超过 $\max C_2$。
- **可达**：取 $a = i$（$p_1 = 0$，为偶），则 $w$ 需与 $b$ 异色；因 $m \ge 2$ 两类非空，取 $b$ 为树 2 **较小类**中任一节点，则 $w$ 取遍**较大类**，恰得 $\max C_2$ 个目标节点；同时树 1 部分不受影响（引理 2）。

上界与构造吻合，定理得证。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n + m)$。两棵树各一次 BFS 染色，加两次线性计数与一次 $O(n)$ 的输出拼接。
- **空间复杂度**：$O(n + m)$。邻接表、颜色数组、BFS 队列均线性；输出数组不计入额外空间。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    vector<int> maxTargetNodes(vector<vector<int>>& edges1, vector<vector<int>>& edges2) {
        int n = edges1.size() + 1, m = edges2.size() + 1;
        vector<int> col1 = parityColor(n, edges1);
        vector<int> col2 = parityColor(m, edges2);

        int c1[2] = {0, 0}, c2[2] = {0, 0};
        for (int c : col1) c1[c]++;
        for (int c : col2) c2[c]++;
        int best = max(c2[0], c2[1]);           // 树 2 贡献上限：较大颜色类

        vector<int> ans(n);
        for (int i = 0; i < n; i++) ans[i] = c1[col1[i]] + best;
        return ans;
    }

  private:
    // BFS 按深度奇偶染色：0 = 偶层，1 = 奇层
    vector<int> parityColor(int n, vector<vector<int>>& edges) {
        vector<vector<int>> g(n);
        for (auto& e : edges) {
            g[e[0]].push_back(e[1]);
            g[e[1]].push_back(e[0]);
        }
        vector<int> col(n, -1);
        queue<int> q;
        col[0] = 0;
        q.push(0);
        while (!q.empty()) {
            int u = q.front();
            q.pop();
            for (int v : g[u]) {
                if (col[v] < 0) {
                    col[v] = col[u] ^ 1;
                    q.push(v);
                }
            }
        }
        return col;
    }
};
```

### Python

```python
class Solution:
    def maxTargetNodes(self, edges1: List[List[int]], edges2: List[List[int]]) -> List[int]:
        def parity_color(n: int, edges: List[List[int]]) -> List[int]:
            g = [[] for _ in range(n)]
            for a, b in edges:
                g[a].append(b)
                g[b].append(a)
            col = [-1] * n
            col[0] = 0
            q = deque([0])
            while q:
                u = q.popleft()
                for v in g[u]:
                    if col[v] < 0:
                        col[v] = col[u] ^ 1
                        q.append(v)
            return col

        col1 = parity_color(len(edges1) + 1, edges1)
        col2 = parity_color(len(edges2) + 1, edges2)
        c1, c2 = Counter(col1), Counter(col2)
        best = max(c2[0], c2[1])
        return [c1[c] + best for c in col1]
```

## 8. 边界情况与易错点

1. **误以为必须连节点 $i$**：题面是"第一棵树中的**一个节点**"，端点任选。好在由定理，连谁都一样——但读错题容易在推导时自我设限（比如误以为必须讨论 $a = i$）。
2. **树 2 贡献取错**：必须取 $\max(C_2[0], C_2[1])$。若固定取 $b$ 所在的某一类，当树 2 两类大小悬殊时会漏掉更优解——正确策略是让 $b$ 落在**小类**、目标 $w$ 收**大类**（或反之）。
3. **递归 DFS 爆栈**：$n, m \le 10^5$ 的链状树递归深达 $10^5$，Python 报 `RecursionError`、C++ 可能栈溢出，务必 BFS 或显式栈迭代。
4. **与 Q3 混淆**：Q3（#3372）的目标定义是"距离 $\le k$"且 $n, m \le 1000$，标准做法是每个点 BFS 一遍的 $O(n^2)$；照搬到本题既超时又答不对——本题没有 $k$，问的是**偶数距离**。
5. **保留访问标记**：`col` 初始化为 $-1$ 兼作访问标记，防止重复入队；树本无环，但保留标记写法更稳。
6. **两类非空的隐性保证**：$n, m \ge 2$ $\Rightarrow$ 树至少有一条边 $\Rightarrow$ 奇偶两类各至少一个节点，"取 $b$ 为小类节点"永远可行，无需特判空类。
7. **答案上界自查**：$answer[i] \le n + m \le 2 \times 10^5$，`int` 足够，无溢出风险。
