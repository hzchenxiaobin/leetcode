# LeetCode 下标对中的最大距离 题解

## 1. 题目概述

- **标题 / 题号**：下标对中的最大距离（#1855，medium）
- **链接**：https://leetcode.cn/problems/maximum-distance-between-a-pair-of-values/
- **来源**：LeetCode 第 240 场周赛 Q2
- **难度**：中等
- **标签**：数组、双指针、二分查找

**题意**：

给定两个**非递增**数组 `nums1`（长 $n$）与 `nums2`（长 $m$）。下标对 $(i, j)$ 需同时满足两个条件才算**有效**：**下标条件** $i \le j$ 与**值条件** $\text{nums1}[i] \le \text{nums2}[j]$。有效对 $(i, j)$ 的**距离**为 $j - i$。返回所有有效对距离的**最大值**；不存在有效对时返回 $0$。

**约束**：

- $1 \le n,\ m \le 10^5$
- $1 \le \text{nums1}[i],\ \text{nums2}[j] \le 10^5$
- `nums1`、`nums2` 均**非递增**

> 💡 **一句话审题**：要 $j - i$ 大，直觉想让 $i$ 小、$j$ 大；但 $i$ 越小 $\text{nums1}[i]$ 越大（非递增），值条件反而越难过——两个约束在**下标**与**值**两个维度上反向拉扯。而两个数组各自的单调性恰好把每行的可行域塑造成「前缀 ∩ 后缀」的规整区间，正是**单调性 + 双指针**（或二分）的标准信号。


## 3. 解题思路

### 3.1 暴力思路：枚举所有下标对

双重循环枚举 $i$ 与 $j \ge i$，逐对检查值条件 $\text{nums1}[i] \le \text{nums2}[j]$，取最大的 $j - i$。

- 时间 $O(nm) = 10^{10}$、空间 $O(1)$：$n = m = 10^5$ 时必然超时；
- 但暴力暴露了冗余所在：`nums2` **非递增**意味着对固定的 $i$，值条件的判定结果在 $j$ 上「前真后假」——一个位置失守，其后全部失守，大量重复比较可以整段跳过。

### 3.2 核心观察：合法 j 是「值前缀」截去「j < i」，且截点 R_i 随 i 只增不减

![核心观察：固定 i 时合法 j 是一段前缀再截断，R_i 随 i 单调不减](images/wc240_q2_valid_prefix_concept.svg)

把「对每个 $i$ 找最优 $j$」形式化，只需三层观察：

1. **值条件刻画前缀**：`nums2` 非递增，若某处 $\text{nums2}[j] < \text{nums1}[i]$，其后所有 $j$ 更不满足。故满足值条件的 $j$ 构成 `nums2` 的一段**前缀** $[0,\ R_i]$，其中 $R_i$ 是最右的满足者（不存在记 $R_i = -1$）。
2. **叠加下标条件**：合法 $j$ 还需 $j \ge i$，与前缀相交得 $[i,\ R_i]$（$R_i \ge i$ 时非空）。距离 $j - i$ 关于 $j$ 严格递增，故行 $i$ 的最优就是 $j = R_i$，贡献 $R_i - i$。全局答案即

   $$\text{ans} \;=\; \max_{0 \le i < n,\; R_i \ge i} \big( R_i - i \big)$$

3. **$R_i$ 单调不减**：`nums1` 非递增，$i$ 右移时 $\text{nums1}[i]$ 变小、门槛降低，能撑住的前缀只会长不会缩：$R_0 \le R_1 \le \cdots \le R_{n-1}$。

第 3 层正是双指针的入场券：用一个**只前进不后退**的指针 $j$ 维护 $R_i$，外层扫 $i$，总代价 $O(n + m)$。

> 💡 **比赛实战路径**：即便没看到第 3 层，前两层已足以给出**二分保底**——对每个 $i$ 在 `nums2` 上二分找最右的满足 $\text{nums2}[j] \ge \text{nums1}[i]$ 的位置，$O(n \log m) \approx 1.7 \times 10^6$ 次比较，稳过；看出第 3 层后再换成线性双指针。周赛里「二分保底 → 双指针优化」是这类单调性题的常见节奏（见 §7 备选代码）。

### 3.3 算法流程：归并式双指针

![算法流程：外层扫 i，指针 j 拉齐后推进到首个失守点，R_i = j − 1](images/wc240_q2_two_pointer_flow.svg)

1. 初始化 `i = 0`、`j = 0`、`ans = 0`。
2. **拉齐**：`j = max(j, i)`，保证 $i \le j$（指针不回退前提下的单向修正）。
3. **推进**：只要 `j < m` 且 `nums2[j] ≥ nums1[i]`，就 `j++`。结束时 `j` 停在本行**首个值条件失守点**（或越界 $m$），故 $R_i = j - 1$。
4. **更新**：若 `j - 1 ≥ i`（本行有合法对），`ans = max(ans, j - 1 - i)`。
5. `i++` 回到第 2 步；$i$ 扫完输出 `ans`。

指针 $j$ 的全部移动只有两种——**拉齐**（跳到 $i$）与**推进**（越过一段前缀），方向都向右，总步数不超过 $n + m$，均摊每行 $O(1)$。

### 3.4 示例演算

![示例 1 演算：逐行拉齐、推进、记录 R_i − i，i=2 行距离跃升为 2](images/wc240_q2_walkthrough.svg)

以示例 1 为例（完整表格见插图）：

| $i$ | $\text{nums1}[i]$ | $j$ 拉齐后 | while 推进 | $R_i = j-1$ | 行最优 $R_i - i$ | ans |
|---|---|---|---|---|---|---|
| 0 | 55 | 0 | $0 \to 1$（$100 \ge 55$，$20 < 55$ 停） | 0 | 0 | 0 |
| 1 | 30 | 1 | 原地（$20 < 30$） | 0 | —（$R_1 < i$） | 0 |
| 2 | 5 | 2（拉齐） | $2 \to 3 \to 4 \to 5 = m$ | 4 | $\mathbf{2}$ | **2** |
| 3 | 4 | 5（$= m$） | 不动 | 4 | 1 | 2 |
| 4 | 2 | 5（$= m$） | 不动 | 4 | 0 | 2 |

> 💡 **观察要点**：$i = 2$ 那轮门槛从 30 骤降到 5，$j$ 从拉齐点一路推到越界，$R_2 = 4$，距离跃升为 2；最终最优对 $(2, 4)$ 满足 $5 \le 5$——**值条件含等号**。$i = 1$ 那轮 $R_1 = 0 < 1$ 无合法对，$j$ 停在原地，靠下一轮的拉齐追上 $i$。

## 4. 算法细节

1. **指针 j 的语义**：「上一行失守后的第一个位置」。每行先拉齐（抬到不低于 $i$）再推进（送到本行失守点），两种移动都单向向右，这是 $O(n+m)$ 的来源。
2. **拉齐必须保序**：写 `j = max(j, i)`，绝不能写 `j = i`——覆盖式赋值会把已推进的 $j$ 拉回去重扫，`nums1 = [1,...,1]`、`nums2 = [2,...,2]` 时退化为 $O(nm)$。指针只能前进，是双指针的命根子。
3. **拉齐的安全性**：被拉齐跳过的位置 $j < i$，对当前行非法（下标条件），对后续行 $i' > i$ 更非法，跳过永不亏。
4. **短路顺序**：`while` 先判 `j < m` 再取 `nums2[j]`，避免越界；结束时 `j` 可为 $m$，此时 $R_i = j - 1 = m - 1$ 是 `nums2` 末元素下标，天然合法。
5. **值条件含等号**：推进条件是 `nums2[j] >= nums1[i]`，相等也推进。丢了等号会把示例 1 的 $(2,4)$（$5 \le 5$）判非法，答案错成 1。
6. **ans 初值 0 的双重语义**：既是「无有效对」的约定返回值，也自动滤掉一切非正候选（本写法中 `j-1 >= i` 门槛已保证候选非负，见 §8 第 7 条的另一种写法）。
7. **无溢出风险**：$n, m \le 10^5$，距离与下标均在 `int` 范围内——对照本场 Q3（子数组最小乘积）必须全程 `long long`，本题可以放心用 `int`。

## 5. 正确性证明

记 $V_i = \{\, j : 0 \le j < m,\ \text{nums2}[j] \ge \text{nums1}[i] \,\}$，$R_i$ 为其最大元素（$V_i = \varnothing$ 时 $R_i = -1$）。算法中行 $i$ 的拉齐起点记 $s_i = \max(J_{i-1},\ i)$（$J_{-1} = 0$，$J_i$ 为行 $i$ 结束时的指针位置）；由 `while` 的行为，$J_i$ 是「从 $s_i$ 起向右第一个满足 $\text{nums2}[\cdot] < \text{nums1}[i]$ 的位置，找不到则为 $m$」。

**引理 1（前缀结构与行最优）**：$V_i$ 是 `nums2` 的一段前缀 $[0,\ R_i]$；行 $i$ 的合法 $j$ 全体为 $[i,\ R_i]$（$R_i \ge i$ 时，否则为空），行最优距离为 $R_i - i$。

**证明**：若 $j_0 \notin V_i$，则对一切 $j > j_0$，由 `nums2` 非递增有 $\text{nums2}[j] \le \text{nums2}[j_0] < \text{nums1}[i]$，即 $j \notin V_i$——真假分界至多出现一次，故 $V_i$ 为前缀。再叠加 $j \ge i$：两区间之交为 $[i, R_i]$；$j - i$ 随 $j$ 严格递增，最大者在 $j = R_i$。∎

**引理 2（单调性）**：$i < i'$ ⟹ $R_i \le R_{i'}$。

**证明**：`nums1` 非递增给出 $\text{nums1}[i'] \le \text{nums1}[i]$，故 $V_i \subseteq V_{i'}$（值门槛只降不升），前缀右端点随之只右不移。∎

**引理 3（指针不变式：候选皆真）**：行 $i$ 结束时若 $J_i - 1 \ge i$，则 $(i,\ J_i - 1)$ 是有效对。

**证明**（对 $i$ 归纳）：行 $i$ 中 `while` 若至少推进一步，则 $J_i - 1$ 恰是最后一步验证过的满足者，$\text{nums2}[J_i - 1] \ge \text{nums1}[i]$ 成立，配合 $J_i - 1 \ge i$ 即有效。若一步未走，则 $J_i = s_i = \max(J_{i-1}, i)$：取到 $i$（拉齐）时 $J_i - 1 = i - 1 < i$，前提不成立，空真；取到 $J_{i-1} > i$ 时 $J_i - 1 = J_{i-1} - 1 \ge i$，由上一行的不变式（$J_{i-1} - 1 \ge i > i - 1$）知 $(i-1,\ J_{i-1} - 1)$ 有效，于是 $\text{nums2}[J_{i-1} - 1] \ge \text{nums1}[i-1] \ge \text{nums1}[i]$（`nums1` 非递增，门槛下降后值条件保持），下标条件 $J_{i-1} - 1 \ge i$ 亦成立，故 $(i,\ J_i - 1)$ 有效。∎

**引理 4（指针上界）**：对一切行 $k$，$J_k \le \max(R_k + 1,\ k)$。

**证明**（对 $k$ 归纳）：若 $s_k \le R_k + 1$，则 $R_k + 1$ 本身是 $s_k$ 右侧可见的失守点（或恰为 $m$），首个失守点 $J_k \le R_k + 1$。若 $s_k > R_k + 1$，则 `while` 一步未走、$J_k = s_k = \max(J_{k-1}, k)$：最大值取到 $k$ 时 $J_k = k$，得证；取到 $J_{k-1}$（此时 $J_{k-1} \ge k$）时，归纳假设与引理 2 给出 $J_{k-1} \le \max(R_{k-1} + 1,\ k - 1) \le \max(R_k + 1,\ k - 1) < s_k$，矛盾——该情形不发生。∎

**定理（算法正确）**：算法返回 $\max\{\, j - i : (i, j)\ \text{有效} \,\}$；无有效对时返回 $0$。

**证明**：**每个候选都是真距离**：算法仅在 $J_i - 1 \ge i$ 时记录候选 $J_i - 1 - i$，由引理 3 该值必为某个有效对的距离；`ans` 初值 $0$ 又与「无有效对」的约定一致，故输出不超过真最大值。**每个真距离都被覆盖**：任取有效对 $(i, j)$，由引理 1 知 $i \le j \le R_i$。由引理 4 与引理 2，$J_{i-1} \le \max(R_{i-1} + 1,\ i - 1) \le \max(R_i + 1,\ i - 1) = R_i + 1$（因 $i - 1 < i \le R_i$），且 $i \le R_i$，故拉齐起点 $s_i = \max(J_{i-1}, i) \le R_i + 1$。于是 $[s_i,\ R_i]$ 内的位置全部值合法（引理 1 的前缀），`while` 逐个推过它们，最终停在首个失守点 $R_i + 1$，即 $J_i = R_i + 1$；此时门槛 $J_i - 1 \ge i$ 成立，算法记录候选 $R_i - i \ge j - i$。两向夹逼即得相等。∎

> 💡 **证明骨架可迁移**：「候选皆真」靠指针不变式（引理 3），「真值皆被覆盖」靠单调性 + 指针上界（引理 2 + 引理 4）——这对引理是所有同向双指针题的标准证明配方，与滑动窗口正确性的证法同构。

## 6. 复杂度分析

- **时间复杂度**：$O(n + m)$。外层 $i$ 共 $n$ 行；指针 $j$ 的移动只有拉齐（每行至多一次、累计 $\le n$ 步）与推进（全程 $\le m$ 步），合计 $\le n + m$ 步，每行其余操作 $O(1)$。$n = m = 10^5$ 时总操作量约 $3 \times 10^5$ 次。
- **空间复杂度**：$O(1)$。仅 `i`、`j`、`ans` 三个变量，原地扫描。
- **与暴力对比**：从 $O(nm) = 10^{10}$ 压到 $O(n + m)$，四个数量级的削减全部来自「每个位置至多被指针越过一次」；二分版 $O(n \log m)$ 则是没利用 $R_i$ 单调性时的保守收获。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maxDistance(vector<int>& nums1, vector<int>& nums2) {
        int n = nums1.size(), m = nums2.size();
        int ans = 0, j = 0;
        for (int i = 0; i < n; ++i) {
            j = max(j, i);                              // 拉齐：保证 i ≤ j，单向修正
            while (j < m && nums2[j] >= nums1[i]) ++j;  // 推进到首个失守点或 m
            if (j - 1 >= i) ans = max(ans, j - 1 - i);  // R_i = j - 1
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maxDistance(self, nums1: List[int], nums2: List[int]) -> int:
        n, m = len(nums1), len(nums2)
        ans = 0
        j = 0
        for i in range(n):
            if j < i:
                j = i                      # 拉齐：保证 i ≤ j
            while j < m and nums2[j] >= nums1[i]:
                j += 1                     # 推进到首个失守点或 m
            if j - 1 >= i:
                ans = max(ans, j - 1 - i)  # R_i = j - 1
        return ans
```

### 二分查找写法（备选）

```cpp
class Solution {
public:
    int maxDistance(vector<int>& nums1, vector<int>& nums2) {
        int n = nums1.size(), m = nums2.size(), ans = 0;
        for (int i = 0; i < n; ++i) {
            int lo = i, hi = m - 1, r = i - 1;        // 只在 [i, m-1] 内找
            while (lo <= hi) {
                int mid = lo + (hi - lo) / 2;
                if (nums2[mid] >= nums1[i]) r = mid, lo = mid + 1;
                else hi = mid - 1;
            }
            if (r >= i) ans = max(ans, r - i);        // r = R_i
        }
        return ans;
    }
};
```

> 💡 两份双指针实现与二分实现均已验证：官方示例 1 / 2 / 3、无有效对（`[10,9]` 与 `[5,5]` → 0）、距离全 0（`[5,1]` 与 `[9,2]` → 0）、$n > m$、全相等元素等特判全部通过；另与 $O(nm)$ 暴力在 20000 组随机非递增数组对（$n, m \le 12$）上逐一对拍一致。

## 8. 边界情况与易错点

1. **值条件含等号（头号坑）**：$\text{nums1}[i] \le \text{nums2}[j]$ 是「小于等于」，示例 1 的 $(2,4)$ 正是 $5 \le 5$。双指针的推进条件与二分的判定条件都要保住等号，丢掉后答案错成 1。
2. **拉齐写成覆盖 `j = i`（次号坑）**：指针被拉回重扫已扫过的段，全 1 对全 2 的用例直接退化 $O(nm)$ 超时。必须 `j = max(j, i)`。
3. **`while` 条件的短路顺序**：必须先判 `j < m` 再取 `nums2[j]`；结束时 `j` 可为 $m$，`R_i = j - 1 = m - 1` 仍是合法下标，不要对 `j == m` 另写分支。
4. **$n > m$**：$i$ 可能推进到 $\ge m$，拉齐后 `while` 被 `j < m` 短路、门槛 `j - 1 >= i` 自动为假，无需特判。
5. **「无有效对」与「距离全 0」都返回 0**：如 `[10,9]` 对 `[5,5]`（无对）、`[5,1]` 对 `[9,2]`（有对但全是 $i = j$）。`ans` 初值 0 一并兜底，输出语义与题面约定一致。
6. **二分版的区间与初值**：在 $[i,\ m-1]$ 上找最右满足者，`r` 初值 $i - 1$ 表示「未找到」时 $r < i$ 自然跳过；注意 `nums2` 是**降序**，不能直接套升序数组的 `bisect_right` 模板，命中后要向右收缩（`lo = mid + 1`）。
7. **换极简写法时的负候选**：官方题解风格 `while (i < n && j < m) nums1[i] > nums2[j] ? ++i : ans = max(ans, j++ - i);` 中 $j - i$ 可能为负，靠 `ans` 初值 0 滤掉；本写法用 `j - 1 >= i` 门槛显式排除。换写法前想清楚防护在哪一层。
8. **溢出核查（免检）**：距离 $\le 10^5 < 2^{31}$，全程 `int` 安全，无需 64 位。

**延伸思考**：

1. **数组改为非递减**：$i$ 右移时门槛升高，$R_i$ 单调不增，指针 $j$ 应改为从右往左推进；或把两个数组翻转，化归为非递增情形再套原算法。
2. **改统计有效对的个数**：答案变为 $\sum_{R_i \ge i} (R_i - i + 1)$——同一套前缀结构从「取 max」换成「求和」，双指针骨架完全不变。
3. **改问「是否存在距离恰为 $k$ 的有效对」**：即判定是否存在 $i$ 使 $R_i \ge i + k$，在行最优序列上再做一次判定即可；也可对每个 $i$ 直接检查位置 $i + k$ 是否落在前缀内，$O(n)$ 单趟完成。
