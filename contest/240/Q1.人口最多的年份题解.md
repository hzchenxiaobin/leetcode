# LeetCode 人口最多的年份 题解

## 1. 题目概述

- **标题 / 题号**：人口最多的年份（#1854，easy）
- **链接**：https://leetcode.cn/problems/maximum-population-year/
- **来源**：LeetCode 第 240 场周赛 Q1
- **难度**：简单
- **标签**：数组、计数、差分数组、前缀和

**题意**：给定二维整数数组 `logs`，其中 `logs[i] = [birth_i, death_i]` 表示第 $i$ 个人的出生与死亡年份。年份 $x$ 的**人口**定义为这一年活着的人数；第 $i$ 个人计入年份 $x$ 当且仅当 $x$ 在闭区间 $[birth_i, death_i - 1]$ 内——**死亡当年不计入**。返回人口最多且**最早**的年份。

**约束**：

- $1 \le logs.length \le 100$
- $1950 \le birth_i < death_i \le 2050$

> 💡 **审题关键**：两个细节定成败——① 存活年份本质是**左闭右开**区间 $[birth, death)$：出生当年算、死亡当年不算；② 人口并列时取**最早**年份。年份值域仅 $1950 \dots 2050$ 共 101 年，这一窄值域正是桶计数 / 差分数组可用的前提。

## 2. 示例

**示例 1**

```text
输入：logs = [[1993,1999],[2000,2010]]
输出：1993
解释：人口最多为 1，而 1993 是人口为 1 的最早年份。
```

**示例 2**

```text
输入：logs = [[1950,1961],[1960,1971],[1970,1981]]
输出：1960
解释：人口最多为 2，分别出现在 1960 和 1970；其中最早年份是 1960。
```

**示例 3**（自拟，覆盖「死亡当年不计入」）

```text
输入：logs = [[1993,1994]]
输出：1993
解释：此人只在 1993 年活着；1994 是其死亡年，不计入。
人口最多为 1，最早年份 1993。
```

## 3. 解题思路

### 3.1 暴力思路：逐年数人头

最直接的做法：对每个年份 $y$ 从 $1950$ 到 $2049$，遍历 `logs` 统计满足 $birth_i \le y < death_i$ 的人数，取人口最大且最早的年份。年份约 100 个 × 人数至多 100，约 $10^4$ 次判定，必然 AC。

签到题不必到此为止——把视角从「每个年份去数有多少人」切换到「每个人向哪些年份投放 $+1$」，就能得到**一次打标记、一趟前缀和**的差分解法。它是区间计数类问题的通用模板（拼车、航班预订、区间加法全是同款），值得在 Q1 就沉淀下来。

### 3.2 核心观察：一条命 = 年份轴上的一段 $[birth, death)$

![核心观察：存活区间与 +1/−1 端点标记](images/wc240_q1_pop_interval_concept.svg)

第 $i$ 个人在年份轴上占据**左闭右开**区间 $[birth_i, death_i)$：他让区间内每个年份的人口 $+1$。差分数组的技巧是只动**两个端点**：

- 在 `birth` 处 `diff[birth] += 1`：从这年起人口多一人；
- 在 `death` 处 `diff[death] -= 1`：到这年人口少一人——**−1 恰好打在 `death`，而不是 `death + 1`**。

原因是区间右端**开着**：`death − 1` 是他活着的最后一年（$+1$ 仍生效），`death` 这年他已退出。前缀和累加到 `death` 时，$+1$ 与 $−1$ 相抵，人口自动归位。对比闭区间 $[s, e]$ 计数（如 370. 区间加法）要把 $-1$ 打在 `e + 1`，这里是本题最容易顺手写错的一步。

$$\mathrm{pop}[y] = \sum_{k=1950}^{y} \mathrm{diff}[k]$$

### 3.3 算法流程：打桩 → 一趟扫描

![算法流程：打桩、前缀和与取最早最大](images/wc240_q1_pop_diff_flow.svg)

1. 建长度 101 的 `diff`（下标 $y - 1950$），对每个 `logs[i]`：`diff[birth-1950] += 1`，`diff[death-1950] -= 1`；
2. 从 $y = 1950$ 起一趟扫描，`cur += diff[y-1950]`，`cur` 即该年人口；
3. `cur > best`（**严格大于**）时更新 `best` 与答案 `ans`——扫描自小到大，严格大于保证并列时保留**最早**年份；
4. 扫描上界取 $2049$ 即可：$death_i \le 2050$ 意味着最晚活到 $2049$，$2050$ 年人口恒为 0，而 $n \ge 1$ 保证最大人口 $\ge 1$，答案不会落在空年。

### 3.4 示例演算

![示例演算：三段生命线与人口阶梯](images/wc240_q1_pop_walkthrough.svg)

以示例 2 为例：三个人的存活区间分别是 $[1950,1961)$、$[1960,1971)$、$[1970,1981)$，按年份顺序整理打桩事件：

| 年份事件 | diff 变化 | 该年人口 cur |
|----------|-----------|--------------|
| 1950（P1 出生） | $+1$ | 1 |
| 1960（P2 出生） | $+1$ | 2 |
| 1961（P1 死亡） | $-1$ | 1 |
| 1970（P3 出生） | $+1$ | 2 |
| 1971（P2 死亡） | $-1$ | 1 |
| 1981（P3 死亡） | $-1$ | 0 |

人口最大值为 2，出现在 1960 与 1970；严格大于 + 从小到大扫描 ⇒ 返回最早的 1960。

## 4. 算法细节

1. **下标映射**：年份减 1950 落在 $[0, 100]$，`diff` 至少开 **101** 格；`death = 2050` 时写入下标 100 仍在界内。惯性开 100 格会在 `death = 2050` 时越界写——C++ 中是未定义行为，Python 直接 `IndexError`。
2. **−1 的落点**：打在 `death` 本身，不是 `death + 1`。左闭右开区间的差分端点就是 `birth` 与 `death`，无需任何 ±1 修正。
3. **扫描上界**：$1950 \dots 2049$。所有非零人口的年份都在其中；多扫到 2050 也不影响正确性，只是多余。
4. **严格大于**：用 `>` 而非 `>=`。配合年份从小到大扫描，并列时天然保留最早年份（示例 2 的 1960/1970 并列是官方特意设计的考点）。
5. **初值**：`best = 0` 即可。$n \ge 1$ 时出生年人口至少为 1，答案必然被更新，不会误返回初始占位值。

## 5. 正确性证明

**引理 1（贡献的指示函数分解）**：对任意人 $(b, d)$（$b < d$）与年份 $y$，其对年份 $y$ 人口的贡献为 $\mathbb{1}[\,b \le y \le d-1\,]$，且

$$\mathbb{1}[\,b \le y \le d-1\,] = \mathbb{1}[\,y \ge b\,] - \mathbb{1}[\,y \ge d\,].$$

**证明**：按 $y$ 与 $b, d$ 的大小关系分三类：

- $y < b$：两边均为 $0 - 0 = 0$；
- $b \le y \le d - 1$：两边均为 $1 - 0 = 1$（此处用到 $b < d$ 保证该段非空）；
- $y \ge d$：两边均为 $1 - 1 = 0$。

三类穷尽所有情形，等式恒成立。∎

**引理 2（差分标记还原人口）**：按算法对每个人 $(b, d)$ 执行 `diff[b] += 1`、`diff[d] -= 1` 后，前缀和

$$S(y) = \sum_{k=1950}^{y} \mathrm{diff}[k] = \mathrm{pop}(y).$$

**证明**：单独看人 $(b, d)$ 写入的标记：$b$ 处的 $+1$ 当且仅当 $y \ge b$ 时被累入 $S(y)$，$d$ 处的 $-1$ 当且仅当 $y \ge d$ 时被累入。故 $(b, d)$ 对 $S(y)$ 的净贡献为 $\mathbb{1}[\,y \ge b\,] - \mathbb{1}[\,y \ge d\,]$，由引理 1 恰等于他对 $\mathrm{pop}(y)$ 的贡献。$S(y)$ 为全体人的贡献之和，即 $\mathrm{pop}(y)$。∎

**定理**：算法返回**人口最多且最早**的年份。

**证明**：由引理 2，扫描中的 `cur` 逐等于各年人口。由约束 $1950 \le birth < death \le 2050$，所有可能非零人口的年份都在 $[1950, 2049]$ 内（2050 年人口恒为 0，而 $n \ge 1$ 使最大人口 $\ge 1$，空年不可能当选），扫描区间覆盖全部候选年份。循环不变量：`ans` 始终是已扫年份中人口最大值的**首次出现年份**——因为年份递增扫描且仅在 `cur > best`（严格大于）时更新。扫描结束时 `best` 即全局最大人口，`ans` 即其最早出现年份。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n + C)$。打桩一趟 $O(n)$（$n \le 100$），扫描一趟 $O(C)$（$C = 101$ 为年份跨度），总计常数级。
- **空间复杂度**：$O(C)$，即长度 101 的差分数组，另有 `cur`、`best`、`ans` 常数个变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maximumPopulation(vector<vector<int>>& logs) {
        vector<int> diff(101);                 // diff[y - 1950]
        for (auto& log : logs) {
            diff[log[0] - 1950] += 1;          // 出生：人口 +1 起点
            diff[log[1] - 1950] -= 1;          // 死亡当年退出：−1 打在 death
        }
        int best = 0, ans = 1950, cur = 0;
        for (int y = 1950; y <= 2049; ++y) {    // 2050 人口恒为 0，扫到 2049 即可
            cur += diff[y - 1950];
            if (cur > best) {                   // 严格大于：并列取最早
                best = cur;
                ans = y;
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maximumPopulation(self, logs: List[List[int]]) -> int:
        diff = [0] * 101
        for birth, death in logs:
            diff[birth - 1950] += 1
            diff[death - 1950] -= 1
        best, ans, cur = 0, 1950, 0
        for y in range(1950, 2050):            # 覆盖 1950..2049
            cur += diff[y - 1950]
            if cur > best:                      # 严格大于：并列取最早
                best, ans = cur, y
        return ans
```

## 8. 边界情况与易错点

1. **−1 的落点（最大坑）**：必须打在 `death`，不是 `death + 1`。存活区间是 $[birth, death)$ 左闭右开；把闭区间模板的 `e + 1` 惯例带进来，会把「死亡当年不计入」变成「计入」，直接 WA。
2. **差分数组开 101 格**：下标 `y - 1950` 最大到 100（`death = 2050`），只开 100 格会越界。
3. **并列取最早**：更新条件用 `>` 而非 `>=`。示例 2 中 1960 与 1970 并列，官方特意考察此点。
4. **答案不会是 2050**：所有 $death_i \le 2050$ ⇒ 最晚活到 2049；2050 年人口恒为 0，而最大人口 $\ge 1$，扫描上界到 2049 即可。
5. **单人单年**：`[[1993,1994]]` 中 1994 年人口为 0，答案是 1993——「死亡当年不计入」的最小用例，可当对拍样例。
6. **无溢出风险**：人口计数 $\le n \le 100$，`int` 足够。
7. **`birth < death` 由约束保证**：存活区间非空，无需特判。
