# LeetCode 二叉树中的最长交错路径 题解

## 1. 题目概述

- **标题 / 题号**：二叉树中的最长交错路径（#1372，medium）
- **链接**：https://leetcode.cn/problems/longest-zigzag-path-in-a-binary-tree/
- **来源**：LeetCode 第 21 场双周赛 Q3
- **难度**：中等
- **标签**：树、深度优先搜索、动态规划、二叉树、树形 DP

**题意**：交错路径定义如下：任选二叉树中一个节点和一个方向（左或右），沿该方向移动到子节点；然后**交换方向**（左变右、右变左），继续移动；反复「走一步、换方向」直到无法移动（子节点为空）。路径长度为**经过的节点数减 1**（单节点路径长度 0）。返回整棵树中最长交错路径的长度。

**约束**：

- 树最多有 $50000$ 个节点
- 节点值在 $[1, 100]$ 之间

## 2. 示例

**示例 1**

```text
输入：root = [1,null,1,1,1,null,null,1,1,null,1,null,null,null,1,null,1]
输出：3
解释：蓝色节点构成最长交错路径（右 → 左 → 右），经过 4 个节点，长度 3。
```

**示例 2**

```text
输出：4
解释：最长交错路径为 左 → 右 → 左 → 右，经过 5 个节点，长度 4。
```

**示例 3**

```text
输入：root = [1]
输出：0
解释：单节点树，路径长度为 0。
```

## 3. 解题思路

### 3.1 暴力思路

枚举每个节点作为起点、枚举初始方向（左/右），沿交错规则向下走到底，统计步数。每个起点的行走至多 $O(h)$，总计 $O(n \cdot h)$，退化成链时 $O(n^2) = 2.5 \times 10^9$，$n = 5 \times 10^4$ 下超时。瓶颈是「同一节点的同一方向被反复计算」——起点 $u$ 向左走的交错路径，其后续部分恰好是「$u$ 的左孩子向右走的交错路径」。这提示把「从某节点出发、先走某方向」定义成子问题。

### 3.2 核心观察：以 (节点, 方向) 为状态的树形 DFS

![后序 DFS：每个节点返回 (先左, 先右) 两个交错长度](images/bw21_q3_dfs_model.svg)

定义 $L(u)$ = 从节点 $u$ 出发**先向左走一步**的交错路径最大长度，$R(u)$ = 先向右走的最大长度。转移一目了然：

$$L(u) = R(u.\text{left}) + 1 \qquad R(u) = L(u.\text{right}) + 1$$

向左走一步到达左孩子后必须换向右，于是接上左孩子处的 $R$；边界为空树返回 $-1$，使叶子节点处 $L = R = 0$（叶子的「先走某方向」无路可走，长度 0，即单节点路径）。答案取所有节点 $\max(L, R)$ 的全局最大——因为**路径起点可以是任意节点**，而任何交错路径必以其某端点为「起点 + 初始方向」，被 $\max(L(u), R(u))$ 覆盖。

每个节点的信息由两个孩子 $O(1)$ 合成，整棵树一遍后序 DFS 即 $O(n)$。

### 3.3 算法流程

```text
dfs(u):
    若 u 为空：返回 (−1, −1)
    (ll, lr) ← dfs(u.left)          # 左孩子处 (先左, 先右)
    (rl, rr) ← dfs(u.right)         # 右孩子处 (先左, 先右)
    L = lr + 1                      # 先向左，下一步在左孩子处向右
    R = rl + 1                      # 先向右，下一步在右孩子处向左
    ans = max(ans, L, R)
    返回 (L, R)

主流程：ans = 0；dfs(root)；返回 ans
```

返回值是**二元组**而不是单值，这是与普通「树高」DFS 的关键区别：父亲向左走需要左孩子的「先右」值，向右走需要右孩子的「先左」值，两个方向都要向上传。

### 3.4 示例演算

![交错路径：每走一步必须换方向（示例 2，答案 4）](images/bw21_q3_zigzag_tree.svg)

以示例 2 为例，最长路径自根出发：**左 → 右 → 左 → 右**，依次经过根、左孩子、左孩子的右孩子、该节点的左孩子、再向右到叶子，共 5 个节点，长度 $5 - 1 = 4$。

用递推核一遍：设该路径终段叶子为 $v$，则 $L(v) = R(v) = 0$；其父（走右到达 $v$ 前一步先左）处 $L = R(v) + 1 = 1$；再上一层 $R = L(\cdot) + 1 = 2$；再上层 $L = 2 + 1 = 3$……逐层 +1 直到根，根处对应方向值为 4，即答案。每一步「+1」恰对应路径上的一条边，与「节点数 − 1」的定义吻合。

## 4. 算法细节

1. **返回 (L, R) 二元组**：单值不够——父节点向左要孩子的 $R$、向右要孩子的 $L$，两个方向的信息都得向上传。
2. **空树哨兵 $-1$**：$L(u) = R(\text{null}) + 1 = 0$，自然处理「叶子无路可走」；若空树返回 0，叶子的 $L$ 会错成 1（凭空多一条不存在的边）。
3. **ans 在每个节点处更新**：路径起点任意，不能只看根的返回值（那是「从根出发」的路径）；在递归函数内 `ans = max(ans, L, R)` 一网打尽。
4. **成员变量 or 引用传参**：C++ 用成员 `ans`、Python 用 `nonlocal`，避免把「最大值」和「返回值」混在一个返回类型里。
5. **树的深度**：$n = 5 \times 10^4$ 退化成链时递归深度达 $5 \times 10^4$，Python 默认递归上限 1000 不够，需 `sys.setrecursionlimit` 调大或改为显式栈迭代。
6. **值域无用**：节点值 $[1,100]$ 与路径判定无关，纯属干扰信息，不用读。

## 5. 正确性证明

**引理 1（路径的端点刻画）**：任何非空交错路径 $p$ 存在唯一的「起点节点 $u$ 与初始方向 $d$」，使得 $p$ 恰为从 $u$ 沿 $d$ 按交错规则走到底（或走到路径末端）的序列；且路径长度等于其边数。

**证明**：交错路径由题面构造：选节点和方向，走一步换向，重复直到无法移动。路径即所经节点序列 $v_0, v_1, \dots, v_k$，相邻两点是父子关系且相邻两步方向交替，长度 $= k = $ 边数 $=$ 节点数 − 1。给定路径序列，$v_0$ 与 $v_0 \to v_1$ 的方向即其起点与初始方向，唯一。反之，任何 $(u, d)$ 按规则走出的序列都是交错路径。∎

**引理 2（转移方程）**：对任意节点 $u$，$L(u) = R(\text{left}(u)) + 1$，$R(u) = L(\text{right}(u)) + 1$，其中空节点的 $L = R = -1$。

**证明**：以 $L(u)$ 为例。从 $u$ 先向左的交错路径第一步必到 $\text{left}(u)$（若为空则无路可走）。第一步之后规则要求换向右，故后续部分是「从 $\text{left}(u) 出发先向右」的交错路径；反之任何以 $\text{left}(u)$ 为起点先向右的路径拼上边 $u \to \text{left}(u)$ 都得到 $u$ 处先向左的合法路径。两方向一一对应且长度恰差 1（多一条边），故 $L(u) = R(\text{left}(u)) + 1$。$\text{left}(u)$ 为空时 $R(\text{null}) = -1$ 给出 $L(u) = 0$，对应「无路可走、长度 0」。$R(u)$ 对称。∎

**定理**：算法返回的 `ans` 等于树中最长交错路径的长度。

**证明**：由引理 1，最长交错路径有起点 $(u, d)$；由引理 2 的归纳（自底向上，每个节点的 $L, R$ 在其孩子之后算出且只依赖孩子），算法算出的 $L(u), R(u)$ 恰为从 $u$ 出发两个方向的最长交错长度。于是最优值 $= \max_{u} \max(L(u), R(u))$，而算法在访问每个 $u$ 时执行 `ans = max(ans, L, R)`，取遍所有节点，得 `ans` = 最优值。∎

## 6. 复杂度分析

- **时间**：$O(n)$。每个节点恰好被访问一次，访问处 $O(1)$ 合成两个方向值并更新答案；$n = 5 \times 10^4$ 时毫秒级。
- **空间**：$O(h)$ 递归栈，$h$ 为树高，最坏（链）$O(n)$；平衡时 $O(\log n)$。除栈外只用常数个工作变量。

## 7. 参考代码

### C++

```cpp
class Solution {
    int ans = 0;
    // 返回 {先向左走的最长交错长度, 先向右走的最长交错长度}
    pair<int, int> dfs(TreeNode* node) {
        if (!node) return {-1, -1};                       // 空树：长度 -1，使叶子为 0
        auto [l, r] = dfs(node->left);
        auto [l2, r2] = dfs(node->right);
        int L = r + 1;   // 向左一步后，在左孩子处必须接着向右
        int R = l2 + 1;  // 向右一步后，在右孩子处必须接着向左
        ans = max(ans, max(L, R));
        return {L, R};
    }
public:
    int longestZigZag(TreeNode* root) {
        ans = 0;
        dfs(root);
        return ans;
    }
};
```

### Python

```python
class Solution:
    def longestZigZag(self, root) -> int:
        ans = 0
        def dfs(node):
            nonlocal ans
            if node is None:
                return (-1, -1)
            _, lr = dfs(node.left)           # 左孩子处"先向右"的长度
            rl, _ = dfs(node.right)          # 右孩子处"先向左"的长度
            L, R = lr + 1, rl + 1
            ans = max(ans, L, R)
            return (L, R)
        dfs(root)
        return ans
```

> 💡 两份代码均通过官方 3 组示例（3、4、0），并与「枚举所有起点 × 初始方向、按规则行走」的暴力对拍 3000 组随机树（深度 ≤ 7，随机剪枝造出各种形态）全部一致。

## 8. 边界情况与易错点

1. **空树返回 $-1$ 而不是 $0$**：这是本题最经典的坑。返回 0 会让叶子的 $L = R = 1$，答案凭空 +1。−1 的语义是「这条不存在的边贡献 −1，抵消 +1 后叶子长度为 0」。
2. **答案不能只取根的值**：最长路径的起点可能在任意子树，必须在每个节点处更新全局最大值。
3. **方向别接错**：$L(u)$ 接的是左孩子的 **R**（换向），$R(u)$ 接右孩子的 **L**。写成「左接左」会得到「只往一个方向走」的路径长度（变成树高问题）。
4. **Python 递归深度**：$n = 5 \times 10^4$ 的链状树会爆默认递归上限；提交环境下 LeetCode 的栈通常够用，本地验证时应 `sys.setrecursionlimit(10**5)` 或改写为迭代后序。
5. **长度的定义是节点数 − 1**：单节点路径长度 0；空树（题目保证 root 非空，但递归里会频繁遇到）按 −1 哨兵处理，不影响对外答案。
6. **成员变量重置**（C++）：若 Solution 对象被复用调用多次，`ans` 需在入口重置为 0（本文写法已处理）。
