# LeetCode 二叉搜索子树的最大键值和 题解

## 1. 题目概述

- **标题 / 题号**：二叉搜索子树的最大键值和（#1373，hard）
- **链接**：https://leetcode.cn/problems/maximum-sum-bst-in-binary-tree/
- **来源**：LeetCode 第 21 场双周赛 Q4
- **难度**：困难
- **标签**：树、深度优先搜索、二叉搜索树、动态规划、二叉树、树形 DP

**题意**：给定一棵二叉树（节点键值可负、可重复），返回**任意**「二叉搜索子树」的键值和的最大值。二叉搜索树（BST）定义：任意节点的左子树中所有键值都**小于**该节点键值，右子树中所有键值都**大于**该节点键值，且左右子树各自也是 BST。若所有子树的键值和都为负，返回 0（空子树）。

**约束**：

- 树有 1 到 40000 个节点
- 每个节点键值在 $[-4 \times 10^4, 4 \times 10^4]$ 之间

## 2. 示例

**示例 1**

```text
输入：root = [1,4,3,2,4,2,5,null,null,null,null,null,null,4,6]
输出：20
解释：键值为 3 的子树（节点 3、2、5、4、6）是和最大的 BST，键值和 3+2+5+4+6 = 20。
```

**示例 2**

```text
输入：root = [4,3,null,1,2]
输出：2
解释：根 4 的左子树含 3 > 右路径…具体地：节点 4 的左孩子 3，而 3 < 4 合法，
      但 3 的子树 {1,2} 中 2 > 3 且挂在 3 的左边不合法；单节点 {2} 是和最大的 BST，和为 2。
```

**示例 3**

```text
输入：root = [-4,-2,-5]
输出：0
解释：所有节点键值为负，任何非空 BST 子树的和都为负，取空子树，返回 0。
```

**示例 4**

```text
输入：root = [2,1,3]
输出：6
解释：整棵树就是 BST，总和 2+1+3 = 6。
```

## 3. 解题思路

### 3.1 暴力思路

枚举每个节点作为子树根，$O(n)$ 个候选；对每个候选先 $O(\text{子树大小})$ 验证 BST（需要同时拿到子树最小/最大值与左右子树合法性），再 $O(\text{子树大小})$ 求和。最坏（链状全合法 BST）$O(n^2) \approx 1.6 \times 10^9$，$n = 4 \times 10^4$ 下超时。观察浪费所在：「验证」与「求和」都从零开始，而子树的信息完全由左右孩子的信息**合成**——这正是树形 DP 的信号。

### 3.2 核心观察：BST 身份四元组的后序合成

![BST 子树的「身份四元组」：后序自底向上合成](images/bw21_q4_bst_quadruple.svg)

一棵子树是不是 BST、键值和是多少，由如下**四元组**完整描述：

$$(\text{isBST},\ \text{sum},\ \text{min},\ \text{max})$$

即「是否合法 BST / 子树键值和 / 子树最小键 / 子树最大键」。空树定义为 $(\text{true}, 0, +\infty, -\infty)$。对节点 $u$，其四元组可由左右孩子的四元组 $O(1)$ 合成：

$$\text{isBST}(u) = \text{isBST}(l) \wedge \text{isBST}(r) \wedge \big(\text{max}(l) < u.\text{val} < \text{min}(r)\big)$$

$$\text{sum}(u) = \text{sum}(l) + \text{sum}(r) + u.\text{val},\quad \text{min}(u) = \min(\text{min}(l), u.\text{val}),\quad \text{max}(u) = \max(\text{max}(r), u.\text{val})$$

三个要点：**为什么 min/max 必须传**——父节点要和「整棵左子树的最大值 / 整棵右子树的最小值」比较，而不只是直接孩子（孩子值合法不代表孙子越界不发生）；**为什么空树取 $\pm\infty$**——让任何有限键值都能通过严格不等式；**为什么 sum 只在合法时累计**——非法子树的和向上传毫无意义，置 0 作废即可（isBST=false 已隔离）。

### 3.3 算法流程：后序 DFS

![后序合成流程：孩子信息就绪后 O(1) 判定父节点](images/bw21_q4_postorder_flow.svg)

```text
dfs(u):
    若 u 为空：返回 (true, 0, +∞, −∞)
    (lb, ls, lmn, lmx) ← dfs(u.left)
    (rb, rs, rmn, rmx) ← dfs(u.right)
    若 lb 且 rb 且 lmx < u.val < rmn：
        sum ← ls + rs + u.val
        ans ← max(ans, sum)
        返回 (true, sum, min(lmn, u.val), max(rmx, u.val))
    否则：
        返回 (false, 0, 0, 0)      # 非法：其余字段作废
主流程：ans = 0；dfs(root)；返回 ans
```

后序保证「先孩子后父亲」，每个节点被访问一次、合成 $O(1)$。

## 4. 算法细节

1. **元组的类型选择**：和最大 $4 \times 10^4 \times 4 \times 10^4 = 1.6 \times 10^9$，超过 `int` 上界（约 $2.1 \times 10^9$ 的一半），C++ 用 `long long` 累加最稳（$1.6 \times 10^9$ 实际恰在 `int` 边界内，但贴近上界，别赌）。Python 无此虑。
2. **min/max 的来源要交叉**：$\text{min}(u) = \min(\text{min}(l), u.\text{val})$——万一 $u$ 无左孩子，min 来自自身；$\text{max}(u) = \max(\text{max}(r), u.\text{val})$ 对称。空树的 $\pm\infty$ 让这些 min/max 在无孩子时自动退化为 $u.\text{val}$。写成「min = 左孩子的 min」会在左子树为空时错拿 $+\infty$。
3. **非法时其余字段传什么**：isBST=false 后父节点判定必然失败，sum/min/max 随便填（本文传 0）；但**不能**把 isBST 传成 true。
4. **ans 初始化为 0**：题目规定全负时返回 0（空子树），所以 ans 的下界就是 0，天然处理示例 3。
5. **严格不等式**：BST 定义是「左子树**小于**、右子树**大于**」，等于即非法。判定写 `lmx < val && val < rmn`，别写 $\le$。这也是键值可重复时最容易错的一格。
6. **递归深度**：$n = 4 \times 10^4$ 的链需要同等深度递归；C++ 栈一般可承受（每帧很小），Python 建议 `sys.setrecursionlimit(10**5)`。
7. **一次遍历同时拿四个量**：不要为了 min/max 再跑一遍 DFS（那是 $O(n^2)$ 回潮）。

## 5. 正确性证明

**引理 1（BST 的局部判定）**：以 $u$ 为根的子树是 BST，当且仅当 $u$ 的左子树是 BST、右子树是 BST、且左子树的最大键 $< u.\text{val} <$ 右子树的最小键（空子树视为 BST，其 max/min分别取 $-\infty / +\infty$）。

**证明**：（⇒）设 $u$ 的子树是 BST。由定义左右子树各自是 BST。左子树中任一键 $x$ 满足 $x < u.\text{val}$，特别地其最大键 $\text{max}(l) < u.\text{val}$（最大键存在时；空子树取 $-\infty$ 亦满足）。右子树对称。（⇐）设三条件成立。左子树是 BST 意味着其中所有键 $\le \text{max}(l) < u.\text{val}$（BST 中根到叶键值受子树最值约束：左子树所有键 $\le$ 左子树根，归纳可得全部 $\le \text{max}(l)$），同理右子树所有键 $\ge \text{min}(r) > u.\text{val}$。结合左右子树自身满足 BST 性质，$u$ 的子树满足定义的三个条款，是 BST。∎

**引理 2（合成值正确）**：算法对每个节点 $u$ 算出的 $(\text{isBST}, \text{sum}, \text{min}, \text{max})$ 与「以 $u$ 为根的子树」的真实值一致（当 isBST 为 false 时后三个字段无意义）。

**证明**：对子树高度归纳。空树按定义返回 $(\text{true}, 0, +\infty, -\infty)$，与约定一致。设 $u$ 的左右子树的四元组已正确（后序保证先算孩子）。isBST 由引理 1 的等价条件直接合成，正确。合法时：子树键值和 = 左子和 + 右子和 + $u.\text{val}$，即加法合成；子树最小键 $= \min(\text{min}(l), u.\text{val})$（若左子树非空，最小值在左子树中或就是 $u.\text{val}$ 当左子树为空——min 公式覆盖两情形，因空树 min 为 $+\infty$ 不影响取小）；最大键对称。归纳成立。∎

**定理**：算法返回的 ans 等于「所有 BST 子树键值和的最大值（全负时为 0）」。

**证明**：可行性——算法每次更新 ans 都发生在判定合法的节点，由引理 2 该节点确为某 BST 子树的根、sum 为其真实键值和，故 ans ≤ 最优值（且 ans ≥ 0，因初始为 0）。最优性——设最优 BST 子树以 $w$ 为根（若最优值为 0，即所有子树和为负或空树，ans 初值 0 已达）。DFS 必访问 $w$，由引理 2 其判定为合法且 sum 为真实和，故 ans ≥ sum$(w)$ = 最优值。两方向相等。∎

## 6. 复杂度分析

- **时间**：$O(n)$。每个节点一次访问、$O(1)$ 合成四元组并更新答案；$n = 4 \times 10^4$ 时 C++ 毫秒级。
- **空间**：$O(h)$ 递归栈，$h$ 为树高，最坏（链）$O(n)$；每帧常数大小（一个四元组）。总额外空间 $O(n)$ 上界。

## 7. 参考代码

### C++

```cpp
class Solution {
    int ans = 0;
    // 返回 {isBST, sum, min, max}；空树 = {true, 0, +inf, -inf}
    tuple<bool, long long, long long, long long> dfs(TreeNode* node) {
        if (!node) return {true, 0, LLONG_MAX, LLONG_MIN};
        auto [lb, ls, lmn, lmx] = dfs(node->left);
        auto [rb, rs, rmn, rmx] = dfs(node->right);
        if (lb && rb && lmx < node->val && node->val < rmn) {
            long long sum = ls + rs + node->val;
            ans = max(ans, (int)sum);
            return {true, sum, min(lmn, (long long)node->val), max(rmx, (long long)node->val)};
        }
        return {false, 0, 0, 0};                          // 非法：其余字段作废
    }
public:
    int maxSumBST(TreeNode* root) {
        ans = 0;
        dfs(root);
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maxSumBST(self, root) -> int:
        ans = 0
        def dfs(node):
            nonlocal ans
            if node is None:
                return (True, 0, float('inf'), float('-inf'))
            lb, ls, lmn, lmx = dfs(node.left)
            rb, rs, rmn, rmx = dfs(node.right)
            if lb and rb and lmx < node.val < rmn:
                s = ls + rs + node.val
                ans = max(ans, s)
                return (True, s, min(lmn, node.val), max(rmx, node.val))
            return (False, 0, 0, 0)
        dfs(root)
        return ans
```

> 💡 两份代码均通过官方 5 组示例（20、2、0、6、7），并与「枚举全部子树 + 区间上下界递归验证 BST + 独立求和」的暴力对拍 3000 组随机树（值域 $[-15,15]$ 压缩以制造重复键与越界键）全部一致。

## 8. 边界情况与易错点

1. **全负树返回 0**：ans 初值 0 即可，不要把「最大 BST 和」初始化成 $-\infty$ 再输出——题目允许空子树。
2. **重复键值非法**：`lmx < val < rmn` 是**严格**不等式；$[2, 2, 2]$ 中根与左孩子同为 2，不是 BST。
3. **min/max 别只看孩子**：父节点必须和「整棵左子树的最大键」比较。反例：根 5，左孩子 3、左孩子的右孩子 6——3 < 5 合法，但 6 > 5 已越界；只有传子树真正的 max 才能拦住。
4. **溢出**：$4 \times 10^4$ 个节点、每个 $\pm 4 \times 10^4$，极端和 $\pm 1.6 \times 10^9$。C++ `int` 侥幸够用但贴边，用 `long long` 累加；返回前再转 `int`。
5. **空树哨兵**：$+\infty / -\infty$ 使不等式自动通过、min/max 自动退化为节点自身值；哨兵方向别写反（左 max 用 $-\infty$、右 min 用 $+\infty$）。
6. **非法子树的信息不上传**：一旦 isBST=false，父节点判定必然失败；但若顺手把「非法子树里仍合法的孙子的 sum」拿来更新答案会引入**错误**——孙子的合法性已在它自己被访问时用过了，重复计或不计都不影响正确性，但「跨过非法节点重组子树」绝不允许。
7. **递归深度**（Python）：$4 \times 10^4$ 链状树需要调大递归上限。
