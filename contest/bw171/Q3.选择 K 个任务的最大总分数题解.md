# LeetCode 选择 K 个任务的最大总分数 题解

## 1. 题目概述

- **标题 / 题号**：选择 K 个任务的最大总分数（#3767，medium）
- **链接**：https://leetcode.cn/problems/maximize-points-after-choosing-k-tasks/
- **来源**：LeetCode 第 171 场双周赛 Q3
- **难度**：中等
- **标签**：贪心、数组、排序、堆（优先队列）

**题意**：有 $n$ 个任务，第 $i$ 个任务若用**技巧 1** 完成得 `technique1[i]` 分，用**技巧 2** 完成得 `technique2[i]` 分。要求**至少 $k$ 个**任务使用技巧 1（其余任务任选技巧），求能获得的**最大总分数**。

**约束**：

- $1 \le n = technique1.length = technique2.length \le 10^5$
- $1 \le technique1[i], technique2[i] \le 10^5$
- $0 \le k \le n$

> 💡 「**至少** $k$ 个」而不是「恰好 $k$ 个」：多出来的任务也可以用技巧 1，只要那样更划算。

## 2. 示例

**示例 1**

```text
输入：technique1 = [5,2,10], technique2 = [10,3,8], k = 2
输出：22
解释：任务 1、2 用技巧 1（2 + 10），任务 0 用技巧 2（10），合计 22。
```

**示例 2**

```text
输入：technique1 = [10,20,30], technique2 = [5,15,25], k = 2
输出：60
解释：技巧 1 处处更优，全部用技巧 1：10 + 20 + 30 = 60。
```

**示例 3**

```text
输入：technique1 = [1,2,3], technique2 = [4,5,6], k = 0
输出：15
解释：k = 0 时不受限，全用技巧 2：4 + 5 + 6 = 15。
```

## 3. 解题思路

### 3.1 暴力思路

枚举「哪些任务用技巧 1」的所有子集（大小 $\ge k$），取最大得分：$O(2^n)$，$n = 10^5$ 完全不可行。$O(nk)$ 的 DP（前 $i$ 个任务中 $j$ 个用技巧 1）也要 $10^{10}$。

### 3.2 核心观察：从「全用技巧 1」出发，只关心差值

![基线全用技巧 1，改用技巧 2 相当于加上差值 Δ](images/bw171_q3_delta_model.svg)

设所有任务都用技巧 1，总分为

$$base = \sum_{i=0}^{n-1} technique1[i]$$

若把任务 $i$ 改用技巧 2，总分增加

$$\Delta_i = technique2[i] - technique1[i]$$

于是「技巧 1 集合为 $S$（$|S| \ge k$）」的方案总分为

$$base + \sum_{i \notin S} \Delta_i$$

约束 $|S| \ge k$ 等价于 $|\\{i : i \notin S\\}| \le n - k$，即**最多只能把 $n-k$ 个任务改用技巧 2**。

于是问题化为：从 $\Delta_0, \ldots, \Delta_{n-1}$ 中**至多挑 $n-k$ 个**，使它们的和最大。显然：

1. 只挑 $\Delta_i > 0$ 的（挑负的只会亏）；
2. 在正的里面挑**最大的** $n-k$ 个。

### 3.3 算法流程

![算法流程：求 base、算 Δ、排序后取前 n−k 个正数](images/bw171_q3_greedy_flow.svg)

```text
1. base = sum(technique1)；delta[i] = technique2[i] - technique1[i]
2. 把 delta 降序排序
3. limit = n - k
4. for i = 0 .. limit-1:
       若 delta[i] > 0:  base += delta[i]
       否则:            break        # 降序，后面的都非正
5. 返回 base
```

因为 $\Delta$ 已降序，遇到第一个非正数就可以提前 `break`。

### 3.4 示例演算

对示例 1：`technique1 = [5,2,10]`、`technique2 = [10,3,8]`、$k = 2$。

| i | technique1 | technique2 | Δ |
|---|------------|------------|---|
| 0 | 5 | 10 | +5 |
| 1 | 2 | 3 | +1 |
| 2 | 10 | 8 | −2 |

$base = 5 + 2 + 10 = 17$，$\Delta$ 降序为 $[5, 1, -2]$，$n - k = 1$。取前 1 个 $\Delta = 5 > 0$，加到 $base$ 得 $17 + 5 = 22$，与示例一致。

对示例 2：$\Delta = [-5, -5, -5]$，$n-k = 1$，第一个就非正，`break`，答案 $base = 60$。
对示例 3：$k = 0$，$n-k = 3$，$\Delta = [3,3,3]$，全取，$base = 6 + 9 = 15$。

## 4. 算法细节

1. **只排序 $\Delta$**：不必构造「(t1, t2) 对」的数组，单独存差值即可，省内存也省比较开销。
2. **降序排序**：C++ 用 `sort(delta.rbegin(), delta.rend())`，Python 用 `sort(reverse=True)`；也可以用「升序 + 从尾部取」。
3. **`break` 优化**：降序后一旦 `delta[i] <= 0`，后面的都不优于 0，直接跳出。注意条件是 `> 0` 而非 `>= 0`（取 0 无收益但也无害，跳出更简洁）。
4. **`n - k` 可能为 0**：$k = n$ 时一个都不许改，循环不执行，答案就是 $base$。
5. **64 位求和**：$n \le 10^5$、$technique^*[i] \le 10^5$，总和可达 $10^{10}$，C++ 必须用 `long long`（返回类型 metaData 已给出 `long`）。
6. **不需要堆**：标签里有「堆（优先队列）」，但既然要「取最大的 $n-k$ 个」，全排序 $O(n \log n)$ 比堆 $O(n \log(n-k))$ 更简单；只有当 $n-k$ 远小于 $n$ 且不想全排序时，堆才有优势。
7. **负数 $\Delta$ 不参与**：这一点对应题意中的「至少 $k$ 个用技巧 1」——负的 $\Delta$ 意味着技巧 1 更优，而使用技巧 1 的数量没有上限，所以直接保留技巧 1。

## 5. 正确性证明

**引理 1（得分刻画）**：对任意方案（技巧 1 集合 $S$，$|S| \ge k$），总分为 $base + \sum_{i \notin S}\Delta_i$。

**证明**：总分 $= \sum_{i \in S} t1_i + \sum_{i \notin S} t2_i$。把 $t2_i$ 写成 $t1_i + \Delta_i$，得 $\sum_{i \in S} t1_i + \sum_{i \notin S}(t1_i + \Delta_i) = \sum_i t1_i + \sum_{i \notin S}\Delta_i = base + \sum_{i\notin S}\Delta_i$。∎

**引理 2（规模约束等价）**：$|S| \ge k \iff |\{i : i \notin S\}| \le n - k$。

**证明**：$|\{i \notin S\}| = n - |S|$，故 $|S| \ge k \iff n - |S| \le n - k$。∎

**引理 3（贪心取最大正差值最优）**：设 $\Delta$ 降序为 $\Delta_{(1)} \ge \Delta_{(2)} \ge \cdots$。对任意 $0 \le m \le n$，$\max_{|T| \le m} \sum_{i \in T}\Delta_i = \sum_{i=1}^{m} \max(\Delta_{(i)}, 0)$。

**证明**：设 $r$ 为 $\Delta$ 中正数的个数。（上界）任意 $T$，$|T| \le m$，其和 $\le$ 取 $T$ 为前 $\min(m,r)$ 个正数之和，因为：负项剔除只增不减；在正项中，$k$ 个数的最大和就是取最大的 $k$ 个。（下界）取 $T^\ast = \{$前 $\min(m,r)$ 个最大正数$\}$，其和恰为 $\sum_{i=1}^{m}\max(\Delta_{(i)},0)$，且 $|T^\ast| \le m$ 满足约束。故等号成立。∎

**定理**：算法输出为最大总分数。

**证明**：由引理 1、2，问题等价于在「至多挑 $m = n-k$ 个 $\Delta$」中最大化 $base + \sum \Delta$，即最大化 $\sum \Delta$。由引理 3，最优值为 $\sum_{i=1}^{m}\max(\Delta_{(i)},0)$。算法的第 4 步正是遍历降序 $\Delta$ 的前 $m$ 项，把其中 $>0$ 的累加到 $base$；`break` 之后跳过的是 $\le 0$ 的项，而 $\max(\Delta,0) = 0$ 对它们成立，故累加结果恰为 $base + \sum_{i=1}^{m}\max(\Delta_{(i)},0)$。因此算法输出等于最优值。∎

## 6. 复杂度分析

- **时间**：$O(n \log n)$，瓶颈在排序。求 `base` 与 `delta` 一趟 $O(n)$；排序 $O(n \log n)$；遍历至多 $n-k+1$ 项 $O(n)$。$n = 10^5$ 时排序约 $1.7 \times 10^6$ 次比较。
- **空间**：$O(n)$ 存 `delta` 数组；若允许原地改写 `technique1`，可复用为 `delta`，空间降为 $O(1)$（不计输入）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long maxPoints(vector<int>& technique1, vector<int>& technique2, int k) {
        int n = (int)technique1.size();
        long long base = 0;
        vector<int> delta(n);
        for (int i = 0; i < n; i++) {
            base += technique1[i];
            delta[i] = technique2[i] - technique1[i];
        }
        sort(delta.rbegin(), delta.rend());
        int limit = n - k;
        for (int i = 0; i < limit; i++) {
            if (delta[i] <= 0) break;
            base += delta[i];
        }
        return base;
    }
};
```

### Python

```python
class Solution:
    def maxPoints(self, technique1: list[int], technique2: list[int], k: int) -> int:
        base = sum(technique1)
        delta = sorted((b - a for a, b in zip(technique1, technique2)), reverse=True)
        limit = len(technique1) - k
        for i in range(limit):
            if delta[i] <= 0:
                break
            base += delta[i]
        return base
```

## 8. 边界情况与易错点

1. **把「至少 $k$」当成「恰好 $k$」**：那就要取「恰好 $n-k$ 个差值最大的」，即使 $\Delta$ 为负也必须改——示例 2 会因此得到 55（把某个 $\Delta=-5$ 加上）而非 60。
2. **`limit` 算成 `k`**：允许改用的任务数是 $n-k$（技巧 2 的配额），不是 $k$。
3. **`int` 溢出**：$n \times \max(technique) \le 10^{10}$，`base` 必须 `long long`；`delta` 本身在 $[-99999, 99999]$，`int` 够。
4. **`k = 0`**：`limit = n`，全部 $\Delta$ 参与，等价于「每个任务独立取较大的技巧」，示例 3 即此情形。
5. **`k = n`**：`limit = 0`，循环不执行，答案 $base$。
6. **`break` 条件写成 `>= 0`**：效果相同（加 0 无影响），但若把 `break` 写在 `if (delta[i] > 0)` 的 `else` 里而忘记跳出，性能会退化（不影响正确性）。
7. **原地改动输入**：若直接对 `technique1` 排序再算，会破坏「第 $i$ 个任务」的对应关系，必须先算好 `delta` 再排序。
8. **负数 $-0$ 的错觉**：$\Delta = 0$ 时两种技巧得分相同，取不取都行；代码中 `break` 会跳过它们，结果不变。
