# LeetCode 固定长度子数组中的最小逆序对数目 题解

## 1. 题目概述

- **标题 / 题号**：固定长度子数组中的最小逆序对数目（#3768，hard）
- **链接**：https://leetcode.cn/problems/minimum-inversion-count-in-subarrays-of-fixed-length/
- **来源**：LeetCode 第 171 场双周赛 Q4
- **难度**：困难
- **标签**：线段树、数组、滑动窗口

**题意**：给定长度为 $n$ 的整数数组 `nums` 和整数 $k$。逆序对指 $i < j$ 且 $nums[i] > nums[j]$ 的下标对。求 `nums` 中**所有长度为 $k$ 的子数组**里，逆序对数量的**最小值**。

**约束**：

- $1 \le n = nums.length \le 10^5$
- $1 \le nums[i] \le 10^9$
- $1 \le k \le n$

## 2. 示例

**示例 1**

```text
输入：nums = [3,1,2,5,4], k = 3
输出：0
解释：[3,1,2] 有 2 个逆序对；[1,2,5] 有 0 个；[2,5,4] 有 1 个。最小为 0。
```

**示例 2**

```text
输入：nums = [5,3,2,1], k = 4
输出：6
解释：只有一个子数组 [5,3,2,1]，逆序对为 C(4,2) = 6。
```

**示例 3**

```text
输入：nums = [2,1], k = 1
输出：0
解释：长度为 1 的子数组不可能有逆序对，答案 0。
```

## 3. 解题思路

### 3.1 暴力思路

对每个起点 $l$ 单独求 $nums[l..l+k-1]$ 的逆序对：$O(k \log k)$（归并或树状数组），共 $n-k+1$ 个窗口，总 $O(nk\log k)$。$k$ 与 $n$ 同阶时是 $O(n^2 \log n) \approx 10^{11}$，不可行。

但注意：相邻两个窗口**只差两个元素**（出去一个、进来一个）。如果能用 $O(\log n)$ 的时间把「旧窗口的逆序对数」修正成「新窗口的逆序对数」，总复杂度就降到 $O(n \log n)$。

### 3.2 核心观察：增量修正只涉及「跨窗口」的两组配对

![滑动一格：删掉左端元素、加入右端元素，逆序对数的变化量可以精确算出](images/bw171_q4_slide_update.svg)

设当前窗口 $W = [l,\ l+k-1]$，下一个窗口 $W' = [l+1,\ l+k]$，两者共享中间部分 $M = [l+1,\ l+k-1]$（$k-1$ 个元素）。

把 $W$ 内的逆序对按「是否涉及左端 $nums[l]$」分成两类：

- **不涉及 $nums[l]$ 的**：这些对完全落在 $M$ 内，也**完全属于** $W'$；
- **涉及 $nums[l]$ 的**：因为 $nums[l]$ 是窗口最左元素，它只能作为逆序对中「较大且在左」的一方，数量为

  $$A = \#\{\,j \in M : nums[j] < nums[l]\,\}$$

同理，$W'$ 的逆序对 = $M$ 内部的逆序对 + 涉及新元素 $nums[l+k]$ 的逆序对。而 $nums[l+k]$ 是窗口最右元素，只能作为「较小且在右」的一方，数量为

$$B = \#\{\,j \in M : nums[j] > nums[l+k]\,\}$$

又因为 $W$ 的逆序对 = $M$ 内部逆序对 + $A$，故

$$\boxed{\ \text{inv}(W') = \text{inv}(W) - A + B\ }$$

即滑动一格只需三步：

1. 从数据结构中删掉 $nums[l]$，并让 `inv -= A`（$A$ = 当前结构中**严格小于** $nums[l]$ 的个数）；
2. 让 `inv += B`（$B$ = 当前结构中**严格大于** $nums[l+k]$ 的个数）；
3. 把 $nums[l+k]$ 插入结构。

### 3.3 算法流程：树状数组维护窗口内的值计数

![树状数组：离散化后按排名计数，前缀和即「比我小的个数」](images/bw171_q4_bit_query.svg)

值域 $10^9$，先**离散化**（排序去重），把每个数映射到 $1 \sim m$ 的排名。设 $cnt(\le r)$ 为当前窗口中排名 $\le r$ 的元素个数（树状数组前缀和）：

- 严格小于 $v$（排名 $r_v$）的个数 $= cnt(\le r_v - 1)$；
- 严格大于 $v$ 的个数 $= |W| - cnt(\le r_v)$。

```text
1. 离散化：vals = 去重排序(nums)，rank(v) = 其在 vals 中的位置 + 1
2. 建初始窗口 [0, k-1]：
      inv = 0
      for i = 0 .. k-1:
          r = rank(nums[i])
          inv += (已插入个数) - cnt(<= r)     # 之前插入的元素中比它大的
          BIT.add(r, 1)
3. ans = inv
4. for i = k .. n-1:
      rOut = rank(nums[i-k])
      BIT.add(rOut, -1)                     # 先把出去的删掉
      inv -= cnt(<= rOut - 1)               # 减去 A：窗口内比它小的
      rIn = rank(nums[i])
      inv += (k - 1) - cnt(<= rIn)          # 加上 B：窗口内比它大的
      BIT.add(rIn, 1)
      ans = min(ans, inv)
5. 返回 ans
```

注意第 4 步中删除发生在计算 $A$ **之前**：因为 $A$ 数的是「$M$ 内比 $nums[l]$ 小的元素」，而 $M$ 正是删掉 $nums[l]$ 后的窗口，所以先删再查，语义自然对齐。

### 3.4 示例演算

![示例演算：在数组 3,1,2,5,4 上以 k=3 逐步滑动](images/bw171_q4_example_walkthrough.svg)

对 `nums = [3,1,2,5,4]`、$k = 3$，排名（vals $=[1,2,3,4,5]$）：$3 \to 3$、$1 \to 1$、$2 \to 2$、$5 \to 5$、$4 \to 4$。

**初始窗口 [3,1,2]**：

| i | nums[i] | 已插入 | $cnt(\le r)$ | 新增逆序对 | inv |
|---|---------|--------|--------------|------------|-----|
| 0 | 3 (r=3) | 0 | 0 | 0 | 0 |
| 1 | 1 (r=1) | 1 | 0 | 1 | 1 |
| 2 | 2 (r=2) | 2 | 1 | 1 | 2 |

`inv = 2`，与手算一致（(3,1)、(3,2)）。

**滑动到 [1,2,5]**（$i = 3$）：删 $nums[0] = 3$（r=3），$cnt(\le 2) = 2$，$inv = 2 - 2 = 0$；加 $nums[3] = 5$（r=5），$cnt(\le 5) = 2$，$B = (3-1) - 2 = 0$，$inv = 0$。窗口 $[1,2,5]$ 逆序对 0 ✓。

**滑动到 [2,5,4]**（$i = 4$）：删 $nums[1] = 1$（r=1），$cnt(\le 0) = 0$，$inv$ 不变；加 $nums[4] = 4$（r=4），$cnt(\le 4) = 1$（元素 2），$B = 2 - 1 = 1$，$inv = 1$。窗口 $[2,5,4]$ 逆序对 1 ✓。

最小值 $\min(2, 0, 1) = 0$，与示例一致。

## 4. 算法细节

1. **离散化**：`sort` + `unique` + `lower_bound`（C++）或 `sorted(set())` + 字典（Python）。**重复值必须映射到同一排名**——逆序对要求严格大于，重复值之间不算逆序对。
2. **树状数组下标 1-based**：`rank` 从 1 开始。`add(idx)` 与 `query(idx)`（前缀和，含 `idx`）都要注意边界。
3. **删除的顺序**：先 `add(rOut, -1)` 再查 `cnt(<= rOut-1)`。若先查再删，$A$ 会把 $nums[l]$ 自身所在排名的计数带上（但它不小于自己，实际不受影响）；**真正会出错**的是 $B$ 的分母 `k-1`：删完之后窗口大小恰为 $k-1$，用这个值算「比 $b$ 大的个数」才正确。
4. **`B` 的计算**：$B = (k-1) - cnt(\le r_{in})$。用「当前窗口大小减去 $\le b$ 的个数」，天然得到严格大于的个数，无需再减 1。
5. **答案用 `long long`**：$k = 10^5$ 时单个窗口最多 $\frac{k(k-1)}{2} \approx 5 \times 10^9$ 个逆序对，超过 `int`。
6. **$k = 1$**：窗口只有一个元素，$A$、$B$ 恒为 0，答案 0。代码直接走完也不会错，但提前返回更清晰。
7. **线段树 vs 树状数组**：标签写「线段树」，但本题只需要「单点加 + 前缀和」，树状数组足够且常数更小。若还要查询「第 k 小」或区间最值，才需要线段树。
8. **空窗口保护**：$k = n$ 时循环 `i = k .. n-1` 不执行，直接返回初始 `inv`。

## 5. 正确性证明

**引理 1（滑动修正公式）**：设 $W = [l, l+k-1]$，$W' = [l+1, l+k]$，$M = [l+1, l+k-1]$。则
$$\text{inv}(W') = \text{inv}(W) - A + B,\quad A = \#\{j \in M : nums[j] < nums[l]\},\ B = \#\{j \in M : nums[j] > nums[l+k]\}.$$

**证明**：先把 $W$ 的逆序对分割为「左端点为 $l$ 的」与「不含 $l$ 的」。前者数量为 $A$——因为 $l$ 是窗口最小下标，任何含 $l$ 的逆序对必以 $l$ 为左端点，且要求 $nums[l] > nums[j]$，$j \in M$。后者完全位于 $M$ 内，恰等于 $\text{inv}(M)$。故 $\text{inv}(W) = \text{inv}(M) + A$。

同理对 $W' = M \cup \{l+k\}$，$l+k$ 是最大下标，任何含它的逆序对必以它为右端点，要求 $nums[j] > nums[l+k]$，$j \in M$，数量为 $B$。故 $\text{inv}(W') = \text{inv}(M) + B$。

两式相减得 $\text{inv}(W') - \text{inv}(W) = B - A$，即所求。∎

**引理 2（树状数组查询语义）**：设树状数组维护当前窗口内各排名值的计数，$cnt(\le r)$ 为其前缀和。则对排名 $r_v$ 的元素 $v$：
- 窗口中严格小于 $v$ 的个数 $= cnt(\le r_v - 1)$；
- 窗口中严格大于 $v$ 的个数 $= |W| - cnt(\le r_v)$。

**证明**：$cnt(\le r)$ 统计的是排名 $\le r$ 的元素个数，而「排名更小」与「值更小」在离散化下等价（$rank$ 保序，等值同排名）。故 $\le r_v - 1$ 恰好是「值严格小于 $v$」。总数 $|W|$ 分为「$\le v$」与「$> v$」两部分，后者即 $|W| - cnt(\le r_v)$。∎

**引理 3（初始窗口正确）**：建初始窗口结束时 `inv` 等于 $\text{inv}([0,k-1])$。

**证明**：按 $i$ 递增插入，插入 $nums[i]$ 时累加「已插入元素中排名严格大于 $r_i$ 的个数」，恰好等于以 $i$ 为右端点、右端点之前元素为左端点的逆序对数量。每个逆序对 $(a,b)$（$a<b$）在插入 $b$ 时被唯一计入一次。求和即得全部逆序对。∎

**定理**：算法返回值为所有长度为 $k$ 的子数组中逆序对数的最小值。

**证明**：
（1）**不变量**：由引理 3，初始时 `inv` $=\text{inv}(W_0)$，树状数组存的是 $W_0$ 的值计数。归纳假设第 $i-k$ 轮后 `inv` $=\text{inv}(W_{i-k})$ 且结构存 $W_{i-k}$。第 $i$ 轮：先删 $nums[i-k]$，结构变为 $M = W_{i-k} \cap W_{i-k+1}$；由引理 2 减去 $A$ 与加上 $B$ 的语义正确；由引理 1，`inv` 变为 $\text{inv}(W_{i-k+1})$；再插入 $nums[i]$，结构恢复为 $W_{i-k+1}$。不变量得证。
（2）**取最小**：算法对 $i = k, \ldots, n-1$ 逐轮执行，配合初始窗口，恰好覆盖全部 $n-k+1$ 个长度为 $k$ 的窗口；每轮后都用 `ans = min(ans, inv)` 更新。由（1），`inv` 每轮都是对应窗口的真实逆序对数，故 `ans` 是这些值的最小值。∎

## 6. 复杂度分析

- **时间**：$O(n \log n)$。离散化排序 $O(n \log n)$；建初始窗口 $k$ 次 `add`/`query`，$O(k \log n)$；滑动 $n-k$ 轮，每轮 2 次 `add` + 2 次 `query`，$O((n-k)\log n)$。合计 $O(n \log n)$，$n = 10^5$ 时约 $4 \times 10^5 \times 17 \approx 7 \times 10^6$ 次树状数组操作。
- **空间**：$O(n)$。离散化数组、排名、树状数组各 $O(n)$；无递归。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long minInversionCount(vector<int>& nums, int k) {
        int n = (int)nums.size();
        if (k <= 1) return 0;

        vector<int> vals = nums;
        sort(vals.begin(), vals.end());
        vals.erase(unique(vals.begin(), vals.end()), vals.end());
        int m = (int)vals.size();
        vector<int> rankOf(n);
        for (int i = 0; i < n; i++) {
            rankOf[i] = (int)(lower_bound(vals.begin(), vals.end(), nums[i]) - vals.begin()) + 1;
        }

        vector<int> bit(m + 1, 0);
        auto add = [&](int idx, int d) {
            for (; idx <= m; idx += idx & -idx) bit[idx] += d;
        };
        auto query = [&](int idx) {
            int s = 0;
            for (; idx > 0; idx -= idx & -idx) s += bit[idx];
            return s;
        };

        long long inv = 0;
        for (int i = 0; i < k; i++) {
            int r = rankOf[i];
            inv += i - query(r);   // 已插入 i 个元素中比 nums[i] 大的
            add(r, 1);
        }

        long long ans = inv;
        for (int i = k; i < n; i++) {
            int rOut = rankOf[i - k];
            add(rOut, -1);
            inv -= query(rOut - 1);          // 减去 A
            int rIn = rankOf[i];
            inv += (k - 1) - query(rIn);     // 加上 B
            add(rIn, 1);
            ans = min(ans, inv);
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def minInversionCount(self, nums: list[int], k: int) -> int:
        n = len(nums)
        if k <= 1:
            return 0

        vals = sorted(set(nums))
        rank = {v: i + 1 for i, v in enumerate(vals)}
        m = len(vals)
        bit = [0] * (m + 1)

        def add(idx: int, d: int) -> None:
            while idx <= m:
                bit[idx] += d
                idx += idx & -idx

        def query(idx: int) -> int:
            s = 0
            while idx > 0:
                s += bit[idx]
                idx -= idx & -idx
            return s

        rk = [rank[v] for v in nums]

        inv = 0
        for i in range(k):
            r = rk[i]
            inv += i - query(r)
            add(r, 1)

        ans = inv
        for i in range(k, n):
            r_out = rk[i - k]
            add(r_out, -1)
            inv -= query(r_out - 1)
            r_in = rk[i]
            inv += (k - 1) - query(r_in)
            add(r_in, 1)
            if inv < ans:
                ans = inv
        return ans
```

## 8. 边界情况与易错点

1. **重复值**：`strictly greater` 才能构成逆序对。`query(r)` 统计的是 $\le r$（含相等），所以「大于」要用 `总数 - query(r)`；若误写成 `总数 - query(r-1)` 会把相等元素也算进去。
2. **删除与查询的顺序**：必须**先删后查**，才能用 `k-1` 作为窗口大小。若顺序颠倒，窗口大小是 $k$，$B$ 会多算 1。
3. **`inv` 与 `ans` 用 64 位**：$k$ 可达 $10^5$，单窗口逆序对可达 $5 \times 10^9$，`int` 溢出。
4. **$k = 1$**：合法的逆序对数为 0；虽然主循环也能得到 0（`query(0) = 0`、`(k-1) - query(...) = 0`），但 `(k-1)` 为 0 时逻辑刚好退化，显式返回更安全。
5. **$k = n$**：没有滑动轮次，返回初始窗口的逆序对数（示例 2 的 6）。
6. **离散化排名从 1 开始**：`bit` 大小为 $m+1$，`add(0, ...)` 会死循环（`idx += idx & -idx` 当 `idx=0` 时不动）。务必保证 `rankOf >= 1`。
7. **`query(rOut - 1)` 当 `rOut = 1`**：`query(0)` 返回 0，不会越界，但 `bit[0]` 不能被访问——`query` 的 `while (idx > 0)` 保证安全。
8. **值域 $10^9$**：不能开桶数组，必须离散化；这是与「值域小」版本的关键区别。
9. **`ans` 初值**：必须以初始窗口的 `inv` 打底，否则 $k = n$ 时循环不执行，`ans` 会停留在 `LLONG_MAX`。
