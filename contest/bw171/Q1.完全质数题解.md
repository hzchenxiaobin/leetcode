# LeetCode 完全质数 题解

## 1. 题目概述

- **标题 / 题号**：完全质数（#3765，medium）
- **链接**：https://leetcode.cn/problems/complete-prime-number/
- **来源**：LeetCode 第 171 场双周赛 Q1
- **难度**：中等
- **标签**：数学、枚举、数论

**题意**：给出整数 $num$。若它的**每一个前缀**与**每一个后缀**（都取其十进制表示的前 $k$ 位 / 后 $k$ 位，$1 \le k \le$ 位数）都是**质数**，则称 $num$ 为**完全质数**，返回 `true`，否则 `false`。

注意两点：前后缀都**包含它自身**（$k = $ 位数）；个位数只有本身是质数时才算完全质数。

**约束**：

- $1 \le num \le 10^9$（至多 10 位）

## 2. 示例

**示例 1**

```text
输入：num = 23
输出：true
解释：前缀 {2, 23}、后缀 {3, 23} 全为质数。
```

**示例 2**

```text
输入：num = 39
输出：false
解释：前缀 {3, 39} 中 39 = 3×13 不是质数；后缀 {9, 39} 也都不是质数。
```

**示例 3**

```text
输入：num = 7
输出：true
解释：唯一的前缀与后缀都是 7，7 是质数。
```

## 3. 解题思路

### 3.1 暴力思路

先提取 $2L$ 个前后缀数（$L \le 10$ 为位数），再对每个数做 $O(\sqrt{x})$ 的试除。总复杂度 $O(L\sqrt{num}) \approx 10 \times 31623 \approx 3 \times 10^5$，**这已经足够快**，是本题的正解骨架。

优化空间有两处：一是把「判断质数」抽成函数复用；二是「提前退出」——任何一个前后缀不是质数就立即返回 false（示例 2 在 $k=1$ 的后缀 9 就该退出）。

### 3.2 核心观察：前后缀是「同一个字符串的两个切片」

![前缀与后缀：同一串的两个方向的切片，k 从 1 到 L](images/bw171_q1_prefix_suffix.svg)

把 $num$ 写成字符串 $s$（长度 $L$）。第 $k$ 个前缀就是 $s[0..k-1]$，第 $k$ 个后缀就是 $s[L-k..L-1]$：

- 前缀序列：$s_0,\ s_0s_1,\ \ldots,\ s_0 \cdots s_{L-1}$（逐步变长，末尾追加）
- 后缀序列：$s_{L-1},\ s_{L-2}s_{L-1},\ \ldots,\ s_0 \cdots s_{L-1}$（逐步变长，头部追加）

两者都包含完整的 $num$ 本身，所以 **$num$ 自身必须是质数**——这是最快的剪枝。

### 3.3 算法流程

![算法流程：枚举 k，分别取前后缀并判质数](images/bw171_q1_algorithm_flow.svg)

```text
1. s = to_string(num)，L = len(s)
2. for k = 1 .. L:
       pre  = int(s[0..k-1])
       suf  = int(s[L-k..L-1])
       若 !isPrime(pre) 或 !isPrime(suf):  返回 false
3. 返回 true

isPrime(x):
   若 x < 2: 返回 false
   for d = 2 .. floor(sqrt(x)):
       若 x % d == 0: 返回 false
   返回 true
```

### 3.4 示例演算

对 $num = 23$：

| k | 前缀 | 是否质数 | 后缀 | 是否质数 |
|---|------|----------|------|----------|
| 1 | 2 | ✓ | 3 | ✓ |
| 2 | 23 | ✓ | 23 | ✓ |

全部通过，返回 `true`。

对 $num = 39$：

| k | 前缀 | 是否质数 | 后缀 | 是否质数 |
|---|------|----------|------|----------|
| 1 | 3 | ✓ | 9 = 3² | ✗ |

在 $k = 1$ 就失败，立即返回 `false`。

## 4. 算法细节

1. **`sqrt` 边界**：循环条件写 `d * d <= x`（用 `long long` 防溢出），不要写 `d <= sqrt(x)`（浮点误差可能漏判完全平方数）。
2. **`x < 2`**：0 和 1 都不是质数，必须显式排除。前缀里可能出现 0 吗？$num$ 无前导零，所以前缀首位非 0、前缀本身 $\ge 1$；后缀可能以 0 结尾（如 $num = 120$ 的后缀 20、10 都不是质数），此时 `isPrime(20)` 正确返回 false。
3. **字符串切片**：C++ `stoi(s.substr(pos, len))`；注意 $L \le 10$，$num \le 10^9$ 时 `stoi` 不会溢出（最大 999999999 < INT_MAX）。若上界放大到 $10^{18}$ 就要换 `stoll`。
4. **提前退出**：每个 $k$ 先判前缀再判后缀，任一失败即返回，最坏情况仍要跑满 $2L$ 次判质数。
5. **重复判断可略**：$k = L$ 时前后缀都等于 $num$，判一次即可；也可先单独判定 $num$ 是否为质数，是则循环从 $k = 1$ 到 $L-1$，能少一半工作量。
6. **`bool` 返回**：LeetCode 上返回 `true` / `false`，Python 用 `True` / `False`。

## 5. 正确性证明

**引理 1（前后缀的切片表示）**：$num$ 的十进制串为 $s$（长 $L$），则第 $k$ 个前缀的数值等于 $\text{int}(s[0..k-1])$，第 $k$ 个后缀等于 $\text{int}(s[L-k..L-1])$，且 $k = L$ 时两者都等于 $num$。

**证明**：前缀是「前 $k$ 位数字」按原顺序组成的数，即 $s[0..k-1]$；后缀是「后 $k$ 位数字」按原顺序组成的数，即 $s[L-k..L-1]$。$k = L$ 时两个区间都是整个串。∎

**引理 2（试除正确性）**：对 $x \ge 2$，`isPrime(x)` 返回 `true` 当且仅当 $x$ 是质数。

**证明**：若 $x$ 是合数，则 $x = a \cdot b$ 且 $2 \le a \le b \le x-1$，于是 $a \le \sqrt{x}$，循环在 $d = a$ 时发现 $a \mid x$，返回 false。反之若循环发现某个 $d \in [2, \lfloor\sqrt x\rfloor]$ 整除 $x$，则 $x$ 有非平凡因子，是合数。$x < 2$ 由显式判断排除。∎

**定理**：算法返回 `true` 当且仅当 $num$ 是完全质数。

**证明**：
（⇒）假设算法返回 `true`，说明对每个 $k \in [1, L]$，前缀与后缀都通过了 `isPrime`。由引理 2，它们全是质数；由引理 1，这覆盖了 $num$ 的**全部**前缀与后缀。故 $num$ 满足完全质数定义。
（⇐）假设 $num$ 是完全质数。则它的每个前缀、每个后缀都是质数。算法恰好枚举了这些数（引理 1），由引理 2 每个判定都返回 true，故循环不提前退出，最终返回 `true`。
两个方向都成立，故算法与定义等价。∎

## 6. 复杂度分析

- **时间**：$O(L \sqrt{num})$。$L \le 10$，每个前后缀试除到 $\sqrt{num} \le 31623$，最坏约 $2 \times 10 \times 31623 \approx 6 \times 10^5$ 次取模（提前退出还会更少）。$L$ 位数生成切片另有 $O(L^2)$ 的字符串开销，可忽略。
- **空间**：$O(L)$，仅用于存放十进制串与临时子串。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool completePrime(int num) {
        string s = to_string(num);
        int L = (int)s.size();
        for (int k = 1; k <= L; k++) {
            int pre = stoi(s.substr(0, k));
            int suf = stoi(s.substr(L - k, k));
            if (!isPrime(pre) || !isPrime(suf)) return false;
        }
        return true;
    }

private:
    bool isPrime(int x) {
        if (x < 2) return false;
        for (long long d = 2; d * d <= x; d++) {
            if (x % d == 0) return false;
        }
        return true;
    }
};
```

### Python

```python
class Solution:
    def completePrime(self, num: int) -> bool:
        def is_prime(x: int) -> bool:
            if x < 2:
                return False
            d = 2
            while d * d <= x:
                if x % d == 0:
                    return False
                d += 1
            return True

        s = str(num)
        L = len(s)
        for k in range(1, L + 1):
            if not is_prime(int(s[:k])):
                return False
            if not is_prime(int(s[L - k:])):
                return False
        return True
```

## 8. 边界情况与易错点

1. **$num = 1$**：前缀后缀都是 1，`isPrime(1)` 必须返回 false（1 不是质数），答案是 false。
2. **$num$ 以 0 结尾**：如 $120$，后缀 $0$、$20$、$120$ 中含 0，`isPrime` 对 $\ge 2$ 的偶数会正确判为合数，但 0 本身要由 `x < 2` 排除。
3. **完全平方数**：如 $num = 49$，试除上界必须含 $\lfloor\sqrt{49}\rfloor = 7$，用 `d * d <= x` 能正确覆盖；若写成 `d * d < x` 会把 49 误判为质数。
4. **`int` 溢出**：$d \cdot d$ 在 $d$ 接近 $31623$ 时约 $10^9$，`int` 勉强够但危险，循环变量用 `long long` 更稳。
5. **忘记 $k = L$**：前后缀都包含自身，若循环只写到 $L-1$，像 $num = 4$（自身非质数但 1 位数没有别的检查）这类会误判。$L = 1$ 时循环必须执行一次。
6. **重复判 `num`**：$k = L$ 时前后缀相同，判两次是常数浪费；可以先判 `isPrime(num)` 再循环 $1..L-1$，逻辑更清晰。
7. **`substr` 参数顺序**：`s.substr(pos, len)`（C++）是「起点 + 长度」，别写成「起点 + 终点」。
