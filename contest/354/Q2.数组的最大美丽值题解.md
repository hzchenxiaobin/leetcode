# LeetCode 数组的最大美丽值 题解

## 1. 题目概述

- **标题 / 题号**：数组的最大美丽值（#2779，medium）
- **链接**：https://leetcode.cn/problems/maximum-beauty-of-an-array-after-applying-operation/
- **来源**：LeetCode 第 354 场周赛 Q2
- **难度**：中等
- **标签**：数组、排序、滑动窗口、二分查找

**题意**：给定数组 `nums` 与非负整数 $k$。每个下标**至多操作一次**：把 $\text{nums}[i]$ 替换为 $[\text{nums}[i]-k,\ \text{nums}[i]+k]$ 内的**任意整数**。数组的美丽值定义为其中**由相等元素组成的最长子序列**的长度。对数组执行任意次操作后，返回可能取得的最大美丽值。

**约束**：

- $1 \le n \le 10^5$
- $0 \le \text{nums}[i],\ k \le 10^5$

## 2. 示例

**示例 1**

```text
输入：nums = [4,6,1,2], k = 2
输出：3
解释：6 的可达区间 [4,8]、2 的可达区间 [0,4] 都包含 4。
     把 6 和 2 都改成 4，得 [4,4,1,4]，下标 0、1、3 构成相等子序列，长度 3。
```

**示例 2**

```text
输入：nums = [1,1,1,1], k = 10
输出：4
解释：无需任何操作，整个数组已全相等，美丽值 = 4。
```

**补充示例**

```text
输入：nums = [8,3,6], k = 1
输出：2
解释：3 的可达区间 [2,4]、6 的 [5,7]、8 的 [7,9] 无三元公共点；
     取 v = 7：6 与 8 均可变成 7，美丽值 2。
```

## 3. 解题思路

### 3.1 朴素思路：枚举目标值

「子序列」允许删除任意元素，因此**下标顺序与位置无关**，本质问题是：**选一个目标值 $v$，统计最多有多少个元素能变成 $v$**。朴素做法是枚举目标值 $v$（候选值域约 $3\times10^5$ 个整数）再线性扫描计数，整体 $O(n \cdot V) \approx 3\times10^{10}$，必然超时；若进而枚举「选哪些下标」则是指数级。必须利用「计数与顺序无关」的结构做优化。

### 3.2 核心观察：区间化 + 一维 Helly

![每个元素对应一个定长区间，全组取公共交点](images/wc354_q2_interval_common_point_concept.svg)

把每个元素翻译成数轴上的**定长区间**：$\text{nums}[i]$ 能变成 $v \iff v \in [\text{nums}[i]-k,\ \text{nums}[i]+k]$。于是：

> **一组下标能全部变成同一个值 $v$ $\iff$ 它们的区间有公共交点 $\iff$ 组内 $\max - \min \le 2k$。**

最后一步是一维 Helly 定理：区间族有公共点当且仅当「最大左端点 ≤ 最小右端点」，代入即 $\max(\text{nums}) - k \le \min(\text{nums}) + k$。

> ⚠️ 是 **$2k$ 不是 $k$**：组内两个元素可以一个 $+k$、一个 $-k$，各让一半，判据因此放宽一倍——这是本题最高频的 WA 点。

于是问题变成：**选出最多的元素，使组内最大值 − 最小值 ≤ 2k**。将数组排序后，最优组一定是**连续段**——夹在组内最小、最大元素之间的所有元素并入后组的最值不变，可行性保持而长度只增（引理 3 严格化）。问题最终归约为：

> 排序后求最长窗口 $[l, r]$，满足 $\text{nums}[r] - \text{nums}[l] \le 2k$。

### 3.3 算法流程：排序 + 同向双指针

![排序加同向双指针算法流程](images/wc354_q2_sliding_window_flow.svg)

经典滑动窗口：右端 $r$ 从左到右推进，一旦窗口违反 $\text{nums}[r] - \text{nums}[l] > 2k$ 就右移 $l$ 收缩。由排序的单调性，$r$ 增大时满足条件的最小 $l$ 只增不减，双指针各走 $O(n)$ 步。

**二分写法**同样可行：对每个 $i$，二分找最大的 $j$ 使 $\text{nums}[j] \le \text{nums}[i] + 2k$（`upper_bound`），候选答案为 $j - i$。

### 3.4 示例演算

![示例逐步演算表](images/wc354_q2_example_walkthrough.svg)

以 `nums = [4,6,1,2], k = 2` 为例：排序得 $[1,2,4,6]$，阈值 $2k = 4$。$r$ 逐步右移：$r=2$ 时窗口 $[1,2,4]$（$4-1=3\le4$）取到长度 3；$r=3$ 时 $6-1=5>4$ 触发 $l$ 右移，窗口变为 $[2,4,6]$（$6-2=4\le4$），长度仍为 3。最终答案 3。✅

## 4. 算法细节

1. **排序是前提**：窗口条件依赖「窗口两端即组内最值」这一排序性质，未排序直接双指针必错。
2. **窗口判据推导**：排序后 $\text{nums}[r] = \max$、$\text{nums}[l] = \min$，代入 3.2 的组可达判据直接得 $\text{nums}[r]-\text{nums}[l]\le 2k$。
3. **收缩必须用 `while`**：一次右移 $l$ 可能仍不满足（如左端是极小值 $1$、右端远大时），必须循环收缩到条件恢复。
4. **目标值的构造**：窗口可行时，公共交点可取 $v = \text{nums}[r] - k$（组内最大值 $-k$），它是整数且落在每个区间内，见引理 2。
5. **单调性（双指针正确的前提）**：$r$ 增大时 $\text{nums}[r]$ 不减，故满足条件的最小 $l$ 单调不减，$l$ 无需回退。
6. **二分版边界**：`upper_bound` 返回**第一个大于** $\text{nums}[i]+2k$ 的位置 $j$，窗口长度为 $j-i$；勿用 `lower_bound`（会漏掉恰好等于阈值的元素）。
7. **无溢出风险**：$\text{nums}[i] + 2k \le 3\times10^5$，`int` 与 Python 均安全。

## 5. 正确性证明

**引理 1（单元素可达）**：$\text{nums}[i]$ 能通过一次操作变成整数 $v$ $\iff$ $v \in [\text{nums}[i]-k,\ \text{nums}[i]+k]$。

**证明**：操作定义即「把 $\text{nums}[i]$ 替换为该区间内任一整数」，逐字翻译即得。∎

**引理 2（一维 Helly / 区间交判据）**：区间族 $\{[a_i, b_i]\}$ 存在公共点 $\iff$ $\max a_i \le \min b_i$；且当公共点存在时，$x = \max a_i$ 就是一个公共点（端点全为整数时 $x$ 为整数）。

**证明**：（⇐）取 $x = \max a_i$。对任意 $i$：$a_i \le x$；又 $x = \max a_i \le \min b_i \le b_i$，故 $x \in [a_i, b_i]$。（⇒）若 $x$ 为公共点，则对任意 $i$ 有 $a_i \le x \le b_i$，两侧分别取 $\max$ / $\min$ 得 $\max a_i \le x \le \min b_i$。∎

**定理 1（组可达判据）**：下标集合 $S$ 中所有元素可变成同一整数 $\iff$ $\max_{i \in S} \text{nums}[i] - \min_{i \in S} \text{nums}[i] \le 2k$。

**证明**：由引理 1，「全部变成 $v$」即 $v$ 属于每个区间 $[\text{nums}[i]-k,\ \text{nums}[i]+k]$（$i \in S$），即区间族有公共点；由引理 2 等价于 $\max_i(\text{nums}[i]-k) \le \min_i(\text{nums}[i]+k)$，即 $\max \text{nums} - k \le \min \text{nums} + k$，移项即 $\max - \min \le 2k$。∎

**引理 3（连续段最优）**：数组排序后，存在一个**连续窗口**达到最优解。

**证明**：设 $S$ 为任一可行集，$l^{\ast}, r^{\ast}$ 分别为 $S$ 中元素在排序数组中的最小、最大位置，则 $\text{nums}[l^{\ast}] = \min_S$、$\text{nums}[r^{\ast}] = \max_S$。排序数组中位于 $[l^{\ast}, r^{\ast}]$ 内的每个元素值都介于二者之间，故窗口 $[l^{\ast}, r^{\ast}]$ 的最大值 − 最小值 $= \max_S - \min_S \le 2k$，同样可行，且长度 $\ge |S|$。对最优集应用即得。∎

**定理 2（双指针正确性）**：算法返回排序数组中最长可行窗口的长度，即最大美丽值。

**证明**：**（以 $r$ 为右端的最优性）**对固定 $r$，内层 `while` 终止时 $l$ 是满足 $\text{nums}[r]-\text{nums}[l] \le 2k$ 的最小下标（若收缩到 $l = r$，差为 $0 \le 2k$ 必然满足，窗口恒非空），故 $[l, r]$ 是以 $r$ 为右端的最长可行窗口。**（不遗漏）**由引理 3，全局最优是某个以 $r_0$ 为右端的窗口，会在迭代 $r_0$ 时被统计。**（不重复 / 复杂度）**$r$ 递增时最小可行 $l$ 单调不减，$l$ 指针只前进不回退，两指针各移动 $O(n)$ 步。综上 `ans` 恰为最长可行窗口长度；由定理 1 与「子序列可任删元素」，该长度即最大美丽值。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \log n)$——排序为主导；双指针扫描 $O(n)$（二分写法为 $O(n \log n)$，同阶）。
- **空间复杂度**：$O(1)$——仅 `l`、`ans` 等常数变量（不计排序自身的递归栈 / 辅助空间）。

## 7. 参考代码

### C++

```cpp
// 排序 + 滑动窗口（双指针）
class Solution {
public:
    int maximumBeauty(vector<int>& nums, int k) {
        sort(nums.begin(), nums.end());
        int n = nums.size(), ans = 0, l = 0;
        for (int r = 0; r < n; ++r) {
            while (nums[r] - nums[l] > 2 * k) {
                ++l;                       // 收缩左端，l = r 时必然停止
            }
            ans = max(ans, r - l + 1);
        }
        return ans;
    }
};
```

```cpp
// 排序 + 二分（upper_bound 版）
class Solution {
public:
    int maximumBeauty(vector<int>& nums, int k) {
        sort(nums.begin(), nums.end());
        int n = nums.size(), ans = 0;
        for (int i = 0; i < n; ++i) {
            int j = upper_bound(nums.begin() + i, nums.end(),
                                nums[i] + 2 * k) - nums.begin();
            ans = max(ans, j - i);          // [i, j) 内元素都可变成同一值
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maximumBeauty(self, nums: List[int], k: int) -> int:
        nums.sort()
        l = 0
        ans = 0
        for r, x in enumerate(nums):
            while x - nums[l] > 2 * k:
                l += 1
            ans = max(ans, r - l + 1)
        return ans
```

```python
from bisect import bisect_right

class Solution:
    def maximumBeauty(self, nums: List[int], k: int) -> int:
        nums.sort()
        return max(bisect_right(nums, x + 2 * k) - i for i, x in enumerate(nums))
```

## 8. 边界情况与易错点

1. **「子序列」是烟雾弹**：子序列允许删除任意元素，任意下标集合都构成合法子序列，与顺序无关——不要往 LIS 型 DP 的方向钻。
2. **判据是 $2k$ 不是 $k$**：两端元素一个 $+k$、一个 $-k$ 可相互靠拢 $2k$，写成 $\le k$ 是本题最高频 WA。
3. **必须先排序**：窗口条件依赖端点即组内最值的排序性质。
4. **收缩用 `while` 而非 `if`**：一次右移 $l$ 可能仍不满足条件，需要循环收缩。
5. **$k = 0$**：判据退化为 $\text{nums}[r] = \text{nums}[l]$，即相同元素的最大出现次数，代码自动覆盖，无需特判。
6. **$n = 1$ / 全相等**：答案分别为 $1$ / $n$，窗口机制自动覆盖。
7. **二分用 `upper_bound` / `bisect_right`**：阈值取 $\text{nums}[i] + 2k$，取等号合法；`lower_bound` 会漏解。
8. **溢出**：$\text{nums}[i] + 2k \le 3\times10^5$，`int` 安全。
