# LeetCode 特殊元素平方和 题解

## 1. 题目概述

- **标题 / 题号**：特殊元素平方和（#2778，easy）
- **链接**：https://leetcode.cn/problems/sum-of-squares-of-special-elements/
- **来源**：LeetCode 第 354 场周赛 Q1
- **难度**：简单
- **标签**：数组、枚举、数论

**题意**：给定下标从 **1** 开始、长度为 $n$ 的整数数组 `nums`。若 $n \bmod i = 0$（即下标 $i$ 整除 $n$），则 `nums[i]` 是**特殊元素**。返回所有特殊元素的**平方和**。

**约束**：

- $1 \le n = \text{nums.length} \le 50$
- $1 \le \text{nums}[i] \le 50$

## 2. 示例

**示例 1**

```text
输入：nums = [1,2,3,4]
输出：21
解释：n = 4。下标 1、2、4 满足 4 % i == 0，均为特殊元素。
     平方和 = 1² + 2² + 4² = 1 + 4 + 16 = 21。
```

**示例 2**

```text
输入：nums = [2,7,1,19,18,3]
输出：63
解释：n = 6。特殊下标为 1、2、3、6（恰为 6 的全部因子）。
     平方和 = 2² + 7² + 1² + 3² = 4 + 49 + 1 + 9 = 63。
```

**补充示例**

```text
输入：nums = [1,2,3,4,5]
输出：26
解释：n = 5 是质数，仅下标 1、5 特殊。平方和 = 1² + 5² = 26。
```

```text
输入：nums = [7]
输出：49
解释：n = 1，唯一下标 1 即 1 的因子，答案 = 7² = 49。
```

## 3. 解题思路

### 3.1 签到题最短路径：三步翻译直接写

Q1 的目标是**从题面到代码的最短路径**，本题只需三步翻译：

1. 「$n$ 能被 $i$ 整除」→ 判据 $n \bmod i = 0$；
2. 「下标从 1 开始」→ 循环 $i = 1, 2, \dots, n$，取元素 `nums[i-1]`；
3. 「平方和」→ 命中判据时累加 $\text{nums}[i-1]^2$。

单重循环 $O(n)$，$n \le 50$ 直接写完交题，无需任何预处理。

### 3.2 核心观察：特殊下标 = $n$ 的因子

![特殊下标即 n 的因子](images/special_squares_divisor_concept.svg)

把判据翻译成熟悉的语言：$n \bmod i = 0 \iff i \mid n$，即**特殊下标集合就是 $n$ 的因子集合**。由此立刻得到两个免费结论：

- $i = 1$ 与 $i = n$ **恒特殊**（任何数都被 1 和自身整除）；
- $n$ 为质数时仅有首尾两个特殊元素（如补充示例 $n = 5$）。

这一步不是本题的必需优化，而是**签到题的套路沉淀**：看到 $a \bmod b = 0$ 就该条件反射「因子关系」。

### 3.3 进阶：成对枚举因子，$O(n) \to O(\sqrt{n})$

![成对枚举因子到 sqrt(n)](images/special_squares_sqrt_pairing.svg)

利用因子成对性：若 $d \mid n$，则 $n/d \mid n$，且 $d$ 与 $n/d$ 中必有一个 $\le \sqrt{n}$。于是只需枚举 $d \le \lfloor\sqrt{n}\rfloor$，每命中一个因子就**成对**收获 $d$ 与 $n/d$ 两个下标；当 $d = n/d$（$n$ 为完全平方数）时二者重合，**只加一次**。

本题 $n \le 50$，$O(n)$ 与 $O(\sqrt{n})$ 毫无差别；但当 $n$ 达到 $10^9$ 量级（如 [1492. n 的第 k 个因子](https://leetcode.cn/problems/the-kth-factor-of-n/)）时，$\sqrt{n}$ 枚举是必须的手段，这是可迁移的通用范式。

### 3.4 示例演算

![示例演算表](images/special_squares_walkthrough.svg)

以 `nums = [2,7,1,19,18,3]`、$n = 6$ 为例逐下标演算：下标 1、2、3、6 命中（$6 \bmod i = 0$），下标 4、5 落选；平方和 $= 4 + 49 + 1 + 9 = 63$。✅

## 4. 算法细节

1. **循环范围**：$i$ 从 $1$ 到 $n$（闭区间），对每个 $i$ 判断 $n \bmod i$ 是否为 $0$。
2. **下标转换**：题目 1-indexed、代码 0-indexed，命中时累加 `nums[i-1] * nums[i-1]`。
3. **值域估算**：最坏 $n = 50$ 个元素全部特殊，每个 $\le 50^2 = 2500$，总和 $\le 125000$，`int` 完全足够，无需 `long long`。
4. **$\sqrt{n}$ 版本**：循环条件写 `d * d <= n` 避免浮点误差；命中因子 $d$ 时累加 `nums[d-1]²`，若 `n/d != d` 再累加 `nums[n/d-1]²`。

## 5. 正确性证明

**引理 1**：满足 $n \bmod i = 0$ 的 $i \in [1, n]$ 恰为 $n$ 在 $[1, n]$ 内的全部因子。

**证明**：$i \mid n$ 的定义即存在整数 $k$ 使 $n = ik$，等价于 $n \bmod i = 0$；又 $n$ 的因子不超过 $n$ 自身，故 $[1, n]$ 恰好覆盖全部因子。∎

**定理 1**：$O(n)$ 算法返回所有特殊元素的平方和。

**证明**：循环对每个 $i \in [1, n]$ 恰好检查一次——**无遗漏**；条件 $n \bmod i = 0$ 由引理 1 恰好筛出全部特殊下标——**无误加**；每次命中累加项为 $\text{nums}[i-1]^2$，与「特殊元素的平方」定义一致——**无重复、无错项**。故累加结果即所求。∎

**引理 2**（因子成对覆盖）：对 $n$ 的任意因子 $i$，$\min(i,\, n/i) \le \sqrt{n}$。

**证明**：反设 $i > \sqrt{n}$ 且 $n/i > \sqrt{n}$，则 $n = i \cdot (n/i) > n$，矛盾。∎

**定理 2**：$\sqrt{n}$ 版本同样正确。

**证明**：由引理 2，每个因子 $i$ 必以 $d = \min(i, n/i) \le \sqrt{n}$ 的形式被枚举命中，从而 $i$ 以 $d$ 或 $n/d$ 的身份被累加；当 $d \ne n/d$ 时两下标不同、各加一次，当 $d = n/d$（仅完全平方数）时判重后恰好加一次。覆盖完备且不重复。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$（逐下标枚举）或 $O(\sqrt{n})$（成对取因子）。$n \le 50$ 时两者均可忽略不计。
- **空间复杂度**：$O(1)$。仅需常数变量 `ans` 与循环变量。

## 7. 参考代码

### C++

```cpp
// O(n) 逐下标枚举
class Solution {
public:
    int sumOfSquares(vector<int>& nums) {
        int n = nums.size(), ans = 0;
        for (int i = 1; i <= n; ++i) {
            if (n % i == 0) {
                ans += nums[i - 1] * nums[i - 1];
            }
        }
        return ans;
    }
};
```

```cpp
// O(sqrt(n)) 成对取因子
class Solution {
public:
    int sumOfSquares(vector<int>& nums) {
        int n = nums.size(), ans = 0;
        for (int d = 1; d * d <= n; ++d) {
            if (n % d == 0) {
                ans += nums[d - 1] * nums[d - 1];
                if (n / d != d) {           // 完全平方数避免重复计入
                    ans += nums[n / d - 1] * nums[n / d - 1];
                }
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def sumOfSquares(self, nums: List[int]) -> int:
        n = len(nums)
        return sum(x * x for i, x in enumerate(nums, 1) if n % i == 0)
```

## 8. 边界情况与易错点

1. **1-indexed 坑**：命中时取 `nums[i-1]` 而非 `nums[i]`，否则 $i = n$ 时数组越界——本题最高频的 WA 原因。
2. **循环从 1 开始**：若从 $i = 0$ 起循环，$n \bmod 0$ 是除零错误（RE）；且 0 也不是合法下标。
3. **$n = 1$**：唯一下标 1 必特殊，答案即 $\text{nums}[0]^2$，算法自动覆盖，无需特判。
4. **质数长度**：仅下标 1、$n$ 特殊，其余全部跳过，勿因「特殊元素太少」怀疑写错。
5. **完全平方数判重**（仅 $\sqrt{n}$ 版本）：$d = n/d$ 时两个下标重合（如 $n = 4, d = 2$），必须 `if (n / d != d)`，否则同一元素的平方被加两次。
6. **平方的是元素值**：累加 $\text{nums}[i-1]^2$，不是下标 $i^2$，读题别串行。
7. **溢出**：本题上限 $125000$，`int` 足够；若值域放大到 $10^5$ 级别则需换 `long long`。
