# LeetCode 合法分割的最小下标 题解

## 1. 题目概述

- **标题 / 题号**：合法分割的最小下标（#2780，medium）
- **链接**：https://leetcode.cn/problems/minimum-index-of-a-valid-split/
- **来源**：LeetCode 第 354 场周赛 Q3
- **难度**：中等
- **标签**：数组、哈希表、Boyer-Moore 投票、前缀统计

**题意**：若长度为 $m$ 的数组中值 $x$ 出现**超过一半**次（$2\times\text{cnt} > m$），称 $x$ 为该数组的**支配元素**。给定长度为 $n$ 且**有且只有一个支配元素**的数组 `nums`，在 $0 \le i < n-1$ 处切成左半 `nums[0..i]` 与右半 `nums[i+1..n-1]`，分割**合法**当且仅当两半的支配元素**相同**（隐含两半各自存在支配元素）。求最小合法分割下标，不存在返回 $-1$。

**约束**：

- $1 \le n \le 10^5$
- $1 \le \text{nums}[i] \le 10^9$
- `nums` 有且只有一个支配元素

> 💡 值域高达 $10^9$，不能开桶数组统计频次，只能用**哈希表**或 **Boyer-Moore 投票**找支配元素。

## 2. 示例

**示例 1**

```text
输入：nums = [1,2,2,2]
输出：2
解释：i=2 切成 [1,2,2] 与 [2]。
     左半 2 出现 2 次，2×2=4 > 3，支配元素为 2；
     右半 2 出现 1 次，2×1=2 > 1，支配元素为 2。
     两半支配元素相同，i=2 为最小合法下标。
```

**示例 2**

```text
输入：nums = [2,1,3,1,1,1,7,1,2,1]
输出：4
解释：i=4 切成 [2,1,3,1,1] 与 [1,7,1,2,1]。
     左半 1 出现 3 次，2×3=6 > 5；右半 1 出现 3 次，2×3=6 > 5。
     两半支配元素均为 1，合法。
```

**示例 3**

```text
输入：nums = [3,3,3,3,7,2,2]
输出：-1
解释：全局支配元素 x=3（出现 4 次，2×4=8 > 7），f=4，n=7。
     i=0：左半 cnt=1，2 > 1 ✓；右半 f−cnt=3，右半长 6，2×3=6 > 6 ✗。
     i=1..5：右半 x 频次不断减少，均不过半；i≥1 起左半虽过半但右半更不满足。
     无合法分割，返回 -1。
```

## 3. 解题思路

### 3.1 暴力思路

枚举每个分割点 $i$（共 $n-1$ 个），对左右两半**分别**用哈希表重新统计频次、找出支配元素并比较是否相同。每个分割点重建统计需 $O(n)$，总计 $O(n^2)$，在 $n = 10^5$ 下约 $10^{10}$ 次操作，必然超时。

> ⚠️ 「增量维护」也不好做：$i$ 右移时左半增加一个元素、右半减少一个元素。**删除元素**后右半的支配元素是谁、旧的支配元素失效后如何找出新者，都无法 $O(1)$ 回答，强行用有序结构也会退化到 $O(n \log n)$ 以上且实现复杂。必须寻找结构性观察。

### 3.2 核心观察：合法分割两半的支配元素，必然是全局支配元素 x

![核心观察：两半支配元素必为全局支配元素](images/wc354_q3_global_dominant_concept.svg)

设全局支配元素为 $x$（题目保证唯一）。**关键引理**：若分割 $i$ 合法，则两半的支配元素一定都等于 $x$。

> 💡 **加法论证**：设两半支配元素同为 $y$，则 $y$ 在左半出现 $c_1$ 次满足 $2c_1 > i+1$，在右半出现 $c_2$ 次满足 $2c_2 > n-1-i$。两式相加得 $2(c_1+c_2) > n$，即 $y$ 在**整个数组**中出现超过 $n/2$ 次，$y$ 是全局支配元素。由唯一性，$y = x$。

于是问题归一为**只盯住 $x$ 一个值**：

1. **找全局支配元素 $x$**：用 **Boyer-Moore 投票**一次遍历锁定，$O(n)$ 时间 $O(1)$ 空间——题目保证存在出现 $> n/2$ 的元素，投票结束时留下的候选必为 $x$。
2. **前缀扫描**：从左到右遍历 $i = 0, \dots, n-2$，维护 $cnt$ = $x$ 在 `nums[0..i]` 中的出现次数，右半频次为 $f - cnt$（$f$ 为 $x$ 的总频次，无需后缀数组）。分割 $i$ 合法当且仅当：

$$2 \cdot cnt > i + 1 \quad \text{且} \quad 2 \cdot (f - cnt) > n - 1 - i$$

第一个满足的 $i$ 即答案。

### 3.3 算法流程

![投票找 x 加前缀扫描的算法流程](images/wc354_q3_scan_flow.svg)

投票找 $x$ → 统计总频次 $f$ → 从左扫描维护前缀计数 $cnt$ → 判定「$x$ 在左右两半是否都严格过半」→ 命中即返回 $i$，扫完无解返回 $-1$。三趟线性扫描，全程 $O(1)$ 额外空间。

### 3.4 示例演算

![示例二逐步演算表](images/wc354_q3_example_walkthrough.svg)

以 `nums = [2,1,3,1,1,1,7,1,2,1]` 为例：投票得 $x=1$，总频次 $f=6$，$n=10$。$i=0..3$ 时右半的 1 频次总是充足，**瓶颈在左半**——$2 \cdot cnt > i+1$ 均不成立（$i=1$、$i=3$ 处恰好取等，差一个元素）；直到 $i=4$，左半 $[2,1,3,1,1]$ 中 1 出现 3 次（$6>5$ ✓），右半 $[1,7,1,2,1]$ 中 1 出现 3 次（$6>5$ ✓），两半同时过半，返回 4。✅

## 4. 算法细节

1. **Boyer-Moore 投票**：维护 `candidate` 与 `vote`，读入元素时若 `vote == 0` 则换候选，随后 `vote += (x == candidate) ? 1 : -1`。由于题目保证存在出现 $> n/2$ 的元素，结束时 `candidate` 必为 $x$，**无需验证**候选的正确性。
2. **`vote` 不是频次**：投票结束的 `vote` 只是个中间量，绝不等于 $x$ 的真实出现次数；$f$ 必须另扫一遍单独统计。
3. **右半频次由差得到**：右半 $x$ 的频次 $= f - cnt$，一前一后两个计数即可覆盖两半判定，避免建后缀统计。
4. **判定用整数乘 2**：支配定义是「**严格超过**一半」，写成 $2 \cdot cnt > len$ 的整数比较，避免浮点除法与取整歧义。
5. **扫描范围 $[0, n-2]$**：右半必须非空；$n=1$ 时循环不执行，自然返回 $-1$。
6. **哈希表替代方案**：不熟投票可用 `unordered_map` / `Counter` 统计全局频次取最大者，时间同为 $O(n)$、空间 $O(n)$，逻辑完全一致（见参考代码第二版）。

## 5. 正确性证明

**引理 1（支配元素唯一）**：任何数组中支配元素至多一个。

**证明**：设 $x \ne y$ 都是长度为 $m$ 的数组的支配元素，则 $2\,\text{cnt}(x) > m$ 且 $2\,\text{cnt}(y) > m$，相加得 $\text{cnt}(x) + \text{cnt}(y) > m$。但 $x, y$ 互异，两组出现位置不相交，$\text{cnt}(x) + \text{cnt}(y) \le m$，矛盾。∎

**引理 2（合法分割的支配元素 = 全局支配元素）**：若分割 $i$ 合法，则两半的共同支配元素 $y$ 满足 $y = x$。

**证明**：合法性给出 $2c_1 > i+1$（$c_1$ 为 $y$ 在左半出现次数）与 $2c_2 > n-1-i$（$c_2$ 为 $y$ 在右半出现次数）。相加得 $2(c_1+c_2) > n$，即 $y$ 在全数组出现 $> n/2$ 次，$y$ 是全局支配元素；由题设唯一性，$y = x$。∎

**引理 3（Boyer-Moore 投票正确性）**：若数组中存在出现次数 $> n/2$ 的元素 $x$，投票结束时的候选必为 $x$。

**证明**：把过程看作维护「待定多重集」$S$：候选与 `vote` 恰好描述 $S$ 由 `vote` 个候选副本组成（对步数归纳：候选更换时 `vote` 归零对应 $S$ 清空；同值入票对应 $S$ 增加一个副本；异值对抗对应从 $S$ 删去一个候选副本、同时新元素不入集）。每次对抗**至多消去一个 $x$ 的副本**。若最终候选 $\ne x$，则 $S$ 末态不含 $x$，$x$ 的全部 $\text{cnt}(x) > n/2$ 个副本均须经对抗消去，需要 $> n/2$ 次对抗、共消去 $> n$ 个元素，超过数组长度 $n$，矛盾。故最终候选 $= x$。∎

**引理 4（判定等价性）**：记 $cnt_i$ = $x$ 在 `nums[0..i]` 中的出现次数，则

$$\text{分割 } i \text{ 合法} \iff 2\,cnt_i > i+1 \ \wedge\ 2\,(f - cnt_i) > n - 1 - i.$$

**证明**：（⇒）分割合法，由引理 2 两半支配元素均为 $x$。支配元素定义即 $x$ 在左半出现 $> (i+1)/2$ 次、在右半出现 $> (n-1-i)/2$ 次，即两个不等式。（⇐）两不等式成立则 $x$ 在两半各自严格过半，由引理 1 两半的支配元素存在且唯一，均必为 $x$；两半支配元素相同，分割合法。∎

**定理（算法正确性）**：算法返回最小合法分割下标；不存在时返回 $-1$。

**证明**：由引理 3，投票候选即全局支配元素 $x$，$f$ 为其真实频次；扫描中 $cnt$ 归纳可得始终等于 $cnt_i$。由引理 4，循环条件恰为「分割 $i$ 合法」的充要判定，故不会漏判、误判。$i$ 从 $0$ 递增，首个命中的 $i$ 即最小合法下标并立即返回；循环走完未命中则不存在合法分割，返回 $-1$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$——三次线性扫描：Boyer-Moore 投票一趟、统计 $f$ 一趟、前缀判定一趟，共至多 $3n$ 次比较，无需排序。
- **空间复杂度**：$O(1)$——仅 `candidate`、`vote`、`f`、`cnt` 等常数变量；哈希表版本为 $O(n)$。

## 7. 参考代码

### C++

```cpp
// Boyer-Moore 投票 + 前缀计数，O(n) / O(1)
class Solution {
public:
    int minimumIndex(vector<int>& nums) {
        int n = nums.size();
        int candidate = 0, vote = 0;
        for (int x : nums) {                 // ① 投票找全局支配元素
            if (vote == 0) candidate = x;
            vote += (x == candidate) ? 1 : -1;
        }
        int f = 0;
        for (int x : nums) f += (x == candidate);   // ② 总频次 f
        int cnt = 0;
        for (int i = 0; i + 1 < n; ++i) {    // ③ 前缀扫描，i ∈ [0, n-2]
            cnt += (nums[i] == candidate);
            if (cnt * 2 > i + 1 && (f - cnt) * 2 > n - 1 - i) return i;
        }
        return -1;
    }
};
```

```cpp
// 哈希表版本：不依赖投票技巧，逻辑同构
class Solution {
public:
    int minimumIndex(vector<int>& nums) {
        int n = nums.size();
        unordered_map<int, int> freq;
        int candidate = 0, f = 0;
        for (int x : nums) {
            if (++freq[x] > f) { f = freq[x]; candidate = x; }
        }
        int cnt = 0;
        for (int i = 0; i + 1 < n; ++i) {
            cnt += (nums[i] == candidate);
            if (cnt * 2 > i + 1 && (f - cnt) * 2 > n - 1 - i) return i;
        }
        return -1;
    }
};
```

### Python

```python
class Solution:
    def minimumIndex(self, nums: List[int]) -> int:
        candidate, vote = 0, 0
        for x in nums:                       # ① Boyer-Moore 投票
            if vote == 0:
                candidate = x
            vote += 1 if x == candidate else -1
        f = sum(1 for x in nums if x == candidate)   # ② 总频次
        n, cnt = len(nums), 0
        for i in range(n - 1):                # ③ 前缀扫描
            cnt += nums[i] == candidate
            if cnt * 2 > i + 1 and (f - cnt) * 2 > n - 1 - i:
                return i
        return -1
```

```python
from collections import Counter

class Solution:
    def minimumIndex(self, nums: List[int]) -> int:
        x, f = Counter(nums).most_common(1)[0]
        n, cnt = len(nums), 0
        for i in range(n - 1):
            cnt += nums[i] == x
            if cnt * 2 > i + 1 and (f - cnt) * 2 > n - 1 - i:
                return i
        return -1
```

## 8. 边界情况与易错点

1. **严格大于，不能取等**：支配要求「超过一半」，判定必须是 $2 \cdot cnt > len$。示例 2 中 $i=1$（$2\times1=2$ 对左半长 2）与 $i=3$（$2\times2=4$ 对左半长 4）都恰好取等而不合法——把 `>` 写成 `>=` 是本题最高频 WA。
2. **不要对两半分别求支配元素再比较**：右半随着 $i$ 右移不断**失去**元素，支配元素的失效与接替难以增量维护；应由引理 2 归结为「只检查全局 $x$」。
3. **右半长度是 $n-1-i$ 不是 $n-i$**：右半为 `nums[i+1..n-1]`，长度 $n-1-i$；左半长度是 $i+1$。两个长度都别代错。
4. **`vote` ≠ 频次**：投票结束的 `vote` 只是算法中间量，$f$ 必须重新统计；误用 `vote` 当 $f$ 必错。
5. **投票无需二次验证**：题目保证支配元素存在，Boyer-Moore 的候选必然就是 $x$，不必再扫一遍确认候选出现次数确实过半。
6. **单元素半边**：长度 1 的半边其唯一元素必是支配元素（$2\times1 > 1$），如示例 1 的右半 `[2]`，判定公式自动覆盖。
7. **$n = 1$**：不存在合法分割（$0 \le i < n-1 = 0$ 无解），循环不执行返回 $-1$，无需特判。
8. **无解情形的形态**：如 `[3,3,3,3,7,2,2]`，前段分割右半不够多、后段分割左半已稀释，全程无命中；不要假设答案总是存在。
9. **溢出**：$n \le 10^5$，$cnt \cdot 2 \le 2\times10^5$，`int` 与 Python 均安全。
10. **值域 $10^9$**：频次统计不能开桶数组，须用投票或哈希表。
