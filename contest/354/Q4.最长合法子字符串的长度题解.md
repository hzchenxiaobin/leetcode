# LeetCode 最长合法子字符串的长度 题解

## 1. 题目概述

- **标题 / 题号**：最长合法子字符串的长度（#2781，hard）
- **链接**：https://leetcode.cn/problems/length-of-the-longest-valid-substring/
- **来源**：LeetCode 第 354 场周赛 Q4
- **难度**：困难
- **标签**：字符串、哈希表、滑动窗口（双指针）

**题意**：给定字符串 `word` 与字符串数组 `forbidden`。若一个字符串**不包含** `forbidden` 中的任何一个串作为子串，称其为**合法**。求 `word` 的**最长合法子字符串**的长度（子串可以为空，故答案 $\ge 0$）。

**约束**：

- $1 \le |\text{word}| \le 10^5$，只含小写字母
- $1 \le |\text{forbidden}| \le 10^5$
- $1 \le |\text{forbidden}[i]| \le 10$，只含小写字母

> 💡 本题的题眼全在最后一条约束：**每个禁串长度 $\le 10$**。它决定了"一个原本合法的窗口在右端扩一位后会变非法"这件事只能发生在一个极小的局部——**以新右端点结尾的至多 10 个后缀**里。抓住这一点，滑动窗口每次只需 $O(10)$ 次哈希查询即可维护合法性。

## 2. 示例

**示例 1**

```text
输入：word = "cbaaaabc", forbidden = ["aaa","cb"]
输出：4
解释：最长合法子串为 "aabc"（长度 4）。
     任何长度 ≥ 5 的子串要么跨越中间的 "aaa" 段，要么首尾拼出 "cb"。
```

**示例 2**

```text
输入：word = "leetcode", forbidden = ["de","le","e"]
输出：4
解释：最长合法子串为 "tcod"（长度 4）。
     "e" 被整体禁止，串被切成零散段，最长段为 "tcod"。
```

**示例 3（自拟，覆盖"答案为 0"）**

```text
输入：word = "aaa", forbidden = ["a"]
输出：0
解释：所有非空子串都包含 "a"，均非法；空串合法，答案为 0。
```

## 3. 解题思路

### 3.1 暴力思路

枚举全部 $O(n^2)$ 个子串 `word[s..e]`，逐个判定合法性：若对每个禁串做朴素包含检查，单次判定 $O(|sub| \cdot |\text{forbidden}|)$，总量 $O(n^3)$ 级别；即使把 `forbidden` 存入哈希集合、对长度为 $\ell$ 的子串枚举其全部子子串去查（$\le 10\ell$ 个），单次判定仍要 $O(10\ell)$，总量 $\ge 10^5 \times 10^5 \times 10$ 字符级操作，必然超时。

> ⚠️ 瓶颈在于：判定"窗口是否合法"时重复检查了大量**早已检查过**的区域。窗口每次只右移一格，新扩进来的只有一个字符——"新的非法"只可能发生在以新右端点结尾的位置。必须利用这个局部性 + "禁串长度 $\le 10$"。

### 3.2 核心观察：禁串长度 ≤ 10 ⇒ 每步只查以 r 结尾的至多 10 个后缀

![核心观察：禁串长度 ≤ 10，只需检查以 r 结尾的至多 10 个后缀](images/wc354_q4_suffix_check_concept.svg)

两条关键性质：

1. **合法性对子串封闭（遗传性）**：合法串的任意子串仍合法；反之，含禁串的串，其所有超串也非法。于是若 `word[left..r]` 合法，则 `word[left..r']`（$r' < r$）也合法——**对每个右端点 $r$，使其合法的最小起点 $L(r)$ 单调不减**，双指针（滑动窗口）成立。
2. **局部性**：设窗口 $[left, r-1]$ 合法。$r$ 右移一位后，窗口内**新增的非法可能**只来自**恰好以 $r$ 结尾**的禁串（若某个禁串完全落在 $[left, r-1]$ 内，与旧窗口合法性矛盾；起点在 $left$ 之前的禁串则与本窗口无关）。而禁串长度 $\le 10$，故只需检查后缀 `word[i..r]`，$i = r, r-1, \dots, \max(left, r-9)$——至多 $\min(10, r-left+1)$ 个。一旦 `word[i..r] ∈ forbidden`，任何包含它的窗口全部非法，必须 **left = i+1**（起点跳过整个禁串）。

> 💡 一句话：**窗口每次只右移一格，"新的非法"只能以新的 $r$ 结尾；禁串又短（≤ 10），所以每个 $r$ 只需 ≤ 10 次哈希查询，窗口合法性即可增量维护。**

### 3.3 算法流程

![滑动窗口算法流程图](images/wc354_q4_sliding_window_flow.svg)

`forbidden` 去重入哈希集合 → 双指针扫描：$r$ 每右移一位，按 $L = 1, 2, \dots, \min(10,\ r-left+1)$ **升序**检查后缀 `word[r-L+1..r]`，命中则 `left = r-L+2` 并 break（更长的后缀起点更靠左、约束更弱）→ 内层结束后更新 `ans = max(ans, r-left+1)` → 扫完返回 `ans`。

### 3.4 示例演算

![示例一逐步演算表](images/wc354_q4_example_walkthrough.svg)

以示例 1 `word = "cbaaaabc"`、`forbidden = {"aaa","cb"}` 走查：$r=1$ 处 `"cb"` 命中，left 被顶到 1；$r=4$、$r=5$ 处 `"aaa"` 两次命中，left 顶到 3 再到 4；此后窗口一路扩张，$r=7$ 时窗口为 `"aabc"`（长度 4），即答案。✅

## 4. 算法细节

1. **建集合**：`forbidden` 整体塞入哈希集合（自动去重），建表 $O(\sum|f_i|) \le 10^6$。
2. **只查窗口内的后缀**：以 $r$ 结尾、长度 $L$ 的后缀起点为 $r-L+1$。起点 $< left$ 的禁串给出的约束 $left \ge 起点+1 \le left$ 自动满足，不必查——把 `r-L+1 >= left` 写进循环条件即可自然截断，窗口很短时还能顺带少查几次。
3. **L 升序 + 命中即 break**：先查短后缀。一旦命中起点 $i$ 的禁串，更长的后缀起点只会更小（约束更弱），无需再看；首个命中的约束最强，left 单次更新即为本步最终值。
4. **left 更新为 r−L+2**：即"禁串起点的下一位"，不是 $r-L+1$；且只能右移不能左移——按上述写法 left 天然单调不减。
5. **ans 在内层循环之后更新**：先让 left 就位，再统计窗口长度 $r-left+1$；`ans` 初值为 0（答案可能为 0，见示例 3）。
6. **单次查询代价**：截取长度 $\le 10$ 的后缀再哈希，$O(10)$；每步至多 $\min(10, r-left+1)$ 次。
7. **Trie 优化（可选）**：把 `forbidden` **倒序**插入 Trie，查询时从 $r$ 向左逐字符走 Trie 边、遇终点标记即命中——省去字符串构造与哈希，每步严格 $\le 10$ 次字符比较（见参考代码 Python 第二版）。

## 5. 正确性证明

**引理 1（合法性对子串封闭）**：合法字符串的任意子串合法。

**证明**：设 $S$ 是合法串 $T$ 的子串。若 $S$ 含某禁串 $f$，则 $f$ 同样是 $T$ 的子串，与 $T$ 合法矛盾。∎

**引理 2（left 单调性）**：对 $0 \le r < n$，定义 $L(r) = \min\{\, i : \text{word}[i..r] \text{ 合法} \,\}$（约定 $i = r+1$ 对应空串，合法，故 $L(r)$ 恒存在且 $\le r+1$）。则 $L(r+1) \ge L(r)$。

**证明**：记 $i = L(r+1)$。若 $i = r+2$，则由 $L(r) \le r+1$ 结论平凡成立。若 $i \le r+1$：`word[i..r+1]` 合法，其子串 `word[i..r]`（可能为空）合法（引理 1），故 $L(r) \le i = L(r+1)$。∎

**引理 3（答案的逐点分解）**：对任意 $s \le e$，`word[s..e]` 合法 $\iff s \ge L(e)$；从而最长合法子串长度 $= \max_{0 \le e < n} \big(e - L(e) + 1\big)$。

**证明**：（⇒）`word[L(e)..e]` 合法而 $s < L(e)$ 时，若 `word[s..e]` 也合法则与 $L(e)$ 的最小性矛盾，故 $s \ge L(e)$... 准确地说：若 $s \ge L(e)$，则 `word[s..e]` 是合法串 `word[L(e)..e]` 的子串，合法（引理 1）；若 $s < L(e)$，由 $L(e)$ 的最小性，`word[s..e]` 非法。故以 $e$ 结尾的最长合法子串恰为 `word[L(e)..e]`，长度 $e - L(e) + 1$；任意合法子串以某个 $e$ 结尾，对其长度 $\le e - L(e) + 1$，取 $\max$ 即全局最长。∎

**引理 4（约束只需来自"以 r 结尾的窗口内禁串"）**：设处理 $r$ 之前 `left = L(r-1)`，则

$$L(r) = \max\Big(L(r-1),\ 1 + \max\{\, a \ge L(r-1) : \text{word}[a..r] \in \text{forbidden} \,\}\Big),$$

其中内层 $\max$ 取空集时为 $-\infty$。

**证明**：对 $i \ge L(r-1)$：`word[i..r]` 非法 $\iff$ 它包含某个禁串 $f$，即存在禁串出现区间 $[a, b] \subseteq [i, r]$。若 $b \le r-1$，则该出现落在 `word[i..r-1]` 内使其非法，与 $i \ge L(r-1)$ 矛盾（由 $L(r-1)$ 定义 `word[L(r-1)..r-1]` 合法，引理 1 保证其一切子串合法）。故非法 $\iff$ 存在**以 $r$ 结尾**的禁串 `word[a..r]` 与 $i \le a$。于是 `word[i..r]` 合法 $\iff i \ge 1 + \max\{a\}$（在 $a \ge L(r-1)$ 的禁串中取），对 $i$ 取最小即得 $L(r)$。又 $a < L(r-1)$ 的禁串给出 $a + 1 \le L(r-1)$，不改变最大值。∎

**定理（算法正确性）**：扫描到每个 $r$ 处理完毕时，算法维护的 `left` 恰为 $L(r)$，且返回值 $= \max_r (r - L(r) + 1)$。

**证明**：对 $r$ 归纳。$r = 0$：内层仅查 `word[0]`（$L \le \min(10, 1) = 1$），禁则 `left = 1 = L(0)`，否则 `left = 0 = L(0)`。

归纳步：设处理 $r-1$ 后 `left = L(r-1)`。算法按 $L = 1, 2, \dots$ 升序检查后缀 `word[r-L+1..r]`，循环条件 $r-L+1 \ge left$ 恰好过滤出 $a \ge L(r-1)$ 的后缀，$L \le 10$ 恰好覆盖所有可能的禁串（禁串长度 $\le 10$）。$L$ 升序即起点 $a$ 降序，**首个命中的起点最大**、约束最强（$a+1$ 最大）；break 跳过的更长后缀起点更小、约束更弱，不影响结果。故算法把 left 更新为

$$\max\Big(L(r-1),\ 1 + \max\{\, a \ge L(r-1) : \text{word}[a..r] \in \text{forbidden} \,\}\Big) = L(r) \quad (\text{引理 4}),$$

且窗口 `[left, r]` 合法。随后 `ans` 累入 $r - L(r) + 1$；结合引理 3，扫描结束时 `ans` 即最长合法子串长度。∎

## 6. 复杂度分析

- **时间复杂度**：$O\big(\sum|f_i| + 100\,n\big)$。建哈希集合 $O(\sum|f_i|) \le 10 \times 10^5 = 10^6$；扫描主体每个 $r$ 至多 $\min(10, r-left+1) \le 10$ 次查询，每次构造 $\le 10$ 字符的后缀并哈希 $O(10)$，合计 $\le 100n = 10^7$ 字符级操作，C++ / Python 均轻松通过。Trie 版每步严格 $\le 10$ 次字符比较，总量 $O(\sum|f_i| + 10n)$。
- **空间复杂度**：$O(\sum|f_i|)$——哈希集合 / Trie 存所有禁串共 $\le 10^6$ 字符；指针与计数 $O(1)$。

## 7. 参考代码

### C++

```cpp
// 滑动窗口 + 哈希集合：O(总禁串长 + 100n) / O(总禁串长)
class Solution {
public:
    int longestValidSubstring(string word, vector<string>& forbidden) {
        unordered_set<string> bad(forbidden.begin(), forbidden.end());
        int n = word.size(), left = 0, ans = 0;
        for (int r = 0; r < n; ++r) {
            // 升序查以 r 结尾、起点 >= left 的后缀；禁串长度 <= 10
            for (int L = 1; L <= 10 && r - L + 1 >= left; ++L) {
                if (bad.count(word.substr(r - L + 1, L))) {
                    left = r - L + 2;   // 起点跳过整个禁串
                    break;              // 更长后缀的约束只会更弱
                }
            }
            ans = max(ans, r - left + 1);
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def longestValidSubstring(self, word: str, forbidden: List[str]) -> int:
        bad = set(forbidden)
        n = len(word)
        left = ans = 0
        for r in range(n):
            for L in range(1, 11):              # 禁串长度 <= 10
                i = r - L + 1
                if i < left:                    # 窗口外的后缀：约束已满足
                    break
                if word[i:r + 1] in bad:
                    left = i + 1                # 起点跳过整个禁串
                    break                       # 更长后缀的约束只会更弱
            ans = max(ans, r - left + 1)
        return ans
```

```python
# Trie 优化版：禁串倒序插入，从 r 向左走边查终点标记
class Solution:
    def longestValidSubstring(self, word: str, forbidden: List[str]) -> int:
        root = {}
        for f in forbidden:                     # 倒序插入：根端对齐后缀末字符
            node = root
            for ch in reversed(f):
                node = node.setdefault(ch, {})
            node['#'] = True                    # 单词终点标记
        n = len(word)
        left = ans = 0
        for r in range(n):
            node = root
            for i in range(r, left - 1, -1):    # 从 r 向左，至多走到 left
                node = node.get(word[i])
                if node is None:                # 无任何禁串是该后缀的延伸
                    break
                if '#' in node:                 # word[i..r] ∈ forbidden
                    left = i + 1
                    break                       # 更左的匹配约束更弱
            ans = max(ans, r - left + 1)
        return ans
```

## 8. 边界情况与易错点

1. **答案可以为 0**：如 `word = "aaa", forbidden = ["a"]`，所有非空子串非法（空串合法）。`ans` 初值须为 0，不能初始化为 1、也不能假设"至少一个字符合法"。
2. **常数 10 完全依赖题面**：`L ≤ 10` 来自 $|\text{forbidden}[i]| \le 10$。若上限变化或写通用模板，应取禁串实际最大长度；漏改此处会**静默漏判**长禁串（窗口看似合法实则含禁），极难排查。
3. **left 更新为 r−L+2（禁串起点的下一位）**，不是 $r-L+1$；方向只能向右——好在本算法结构下 left 天然单调不减，无需显式取 max。
4. **命中即 break 是安全的**：$L$ 升序 ⇒ 起点降序，首个命中起点最大、约束最强；若不 break 继续查，必须写 `left = max(left, i+1)` 而非直接赋值，否则会被更弱（更左）的命中拉回 left，窗口反而含禁串。
5. **窗口外的后缀不必查**：起点 $< left$ 的禁串约束自动满足；用循环条件 `r-L+1 >= left` 截断即可，兼作短窗口剪枝。
6. **单字符禁串会把串切碎**：如示例 2 的 `"e"`，left 可能被顶到 $r+1$（窗口为空），此时 $r-left+1 = 0$，逻辑自动兼容，无需特判。
7. **不要看到双重循环就认为 $O(n^2)$**：内层次数被 $\min(10, 窗口长)$ 硬性封顶，总复杂度与外层线性同阶。
8. **Python 切片右端是 r+1**：`word[i:r+1]` 表示 `word[i..r]`；写成 `word[i:r]` 会漏掉末字符。建议先写暴力对拍（`any(f in sub for f in forbidden)`）再提交。
9. **forbidden 有重复 / 自包含**（如同时含 `"ab"` 与 `"aab"`）：哈希集合自动去重；自包含关系无需处理——算法每次取的是"以 r 结尾的命中中起点最大者"，天然覆盖所有情形。
