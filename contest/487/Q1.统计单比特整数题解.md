# LeetCode 统计单比特整数 题解

## 1. 题目概述

- **标题 / 题号**：统计单比特整数（#3827，easy）
- **链接**：https://leetcode.cn/problems/count-monobit-integers/
- **来源**：LeetCode 第 487 场周赛 Q1
- **难度**：简单
- **标签**：位运算、数学、枚举

**题意**：如果一个整数的二进制表示中所有位都相同，则称其为**单比特数**（Monobit）。给定整数 `n`，返回 `[0, n]`（闭区间）内单比特数的个数。

**约束**：

- `0 <= n <= 1000`

## 2. 示例

**示例 1**

```text
输入：n = 1
输出：2
解释：[0, 1] 内整数的二进制表示为 "0" 和 "1"，各只有一位，均为单比特数。
```

**示例 2**

```text
输入：n = 4
输出：3
解释：[0, 4] 内只有 0("0")、1("1")、3("11") 是单比特数；
      2("10") 和 4("100") 的位不全相同。
```

**补充示例**

```text
输入：n = 1000
输出：10
解释：0, 1, 3, 7, 15, 31, 63, 127, 255, 511 共 10 个（1023 > 1000）。
```

## 3. 解题思路

### 3.1 暴力思路：逐个检查

枚举 `[0, n]` 内每个 `x`，转二进制字符串后检查是否所有字符相同：

```python
ans = sum(1 for x in range(n + 1) if len(set(bin(x)[2:])) == 1)
```

时间复杂度 $O(n \log n)$，对 $n \le 1000$ 完全够用，但没有利用问题结构。签到时可以直接写，写完再想优化。

### 3.2 核心观察：正的单比特数必为全 1 数

![核心观察：单比特数就是全 1 数](images/monobit_concept.svg)

正整数的二进制表示**无前导零**，最高位必为 `1`。若要求所有位都相同，则**每一位都是 1**。因此：

- 正的单比特数恰好是**全 1 数**：$1_2, 11_2, 111_2, \dots$，即 $2^k - 1\ (k \ge 1)$；
- 再补上 $0$（二进制 `"0"`，仅一位，天然单比特）。

**结论**：$[0, n]$ 内的单比特数集合为 $\{0\} \cup \{2^k - 1 : k \ge 1,\ 2^k - 1 \le n\}$，只需数一数有多少个 $2^k - 1$ 不超过 $n$。

### 3.3 算法流程：迭代生成全 1 数

![算法流程：从 1 开始不断 x ← 2x+1](images/monobit_flow.svg)

从 $x = 1$（二进制 `"1"`）出发，每步 $x \leftarrow 2x + 1$，等价于在二进制末尾追加一个 `1`：

$$1 \to 11_2(3) \to 111_2(7) \to 1111_2(15) \to \cdots$$

`ans` 初始化为 `1`（计入 $0$），每遇到一个 $x \le n$ 就加一，直到 $x > n$ 停止。

### 3.4 示例演算

![示例演算：n=4 与 n=1000](images/monobit_example_walkthrough.svg)

`n = 4`：逐个检查 `[0, 4]`：

| x | 二进制 | 单比特？ |
|---|--------|----------|
| 0 | 0      | ✓ |
| 1 | 1      | ✓ |
| 2 | 10     | ✗ |
| 3 | 11     | ✓ |
| 4 | 100    | ✗ |

答案 = 3 ✓（注意 $7 = 111_2$ 也是单比特数，但 $7 > 4$ 不在范围内）。

`n = 1000`：$1, 3, 7, 15, 31, 63, 127, 255, 511 \le 1000$，而 $1023 > 1000$，加上 $0$，答案 = 10。

## 4. 算法细节

1. **0 的处理**：$0$ 的二进制是 `"0"`，只有一位，属于单比特数，故 `ans` 从 1 起步。
2. **全 1 数的生成**：`x = 2 * x + 1` 等价于二进制左移一位再低位补 1，避免字符串拼接，一步 $O(1)$。
3. **位技巧判别**：$x$ 是全 1 数（或 $0$）$\iff$ `x & (x + 1) == 0`。例如 $7\ \&\ 8 = 0$，而 $6\ \&\ 7 = 6 \ne 0$。可用于暴力解法的加速判别。
4. **闭式解**：$2^k - 1 \le n \iff k \le \log_2(n+1)$，故答案 $= 1 + \lfloor \log_2(n+1) \rfloor$（对 $n \ge 0$ 恒成立）。实现上循环写法更稳：浮点 `log` 在 $n+1$ 恰为 2 的幂附近可能有精度问题。

## 5. 正确性证明

**引理 1**：正整数 $x$ 是单比特数 $\iff$ $x = 2^k - 1$（某个 $k \ge 1$）。

**证明**：
（⟸）$2^k - 1 = \underbrace{11\cdots1}_{k\text{ 个}}{}_2$，所有位相同，是单比特数。
（⟹）正整数的二进制表示唯一且不含前导零，最高位为 1。若所有位相同，则每一位都等于最高位的 1，故 $x = \sum_{i=0}^{k-1} 2^i = 2^k - 1$。∎

**引理 2**：$0$ 是单比特数。

**证明**：$0$ 的二进制表示为 `"0"`，仅含一个位，平凡地满足"所有位都相同"。∎

**定理**：算法返回 $[0, n]$ 内单比特数的个数，即 $1 + \left|\{\,k \ge 1 : 2^k - 1 \le n\,\}\right|$。

**证明**：由引理 1、2，$[0, n]$ 内单比特数集合为 $\{0\} \cup \{2^k - 1 : k \ge 1,\ 2^k - 1 \le n\}$。对循环不变式归纳：第 $i$ 次进入循环判断时 $x = 2^i - 1$（$i = 1$ 时 $x = 1 = 2^1 - 1$；若某次 $x = 2^i - 1$，则更新后 $x' = 2x + 1 = 2^{i+1} - 1$）。于是循环体对每个满足 $2^i - 1 \le n$ 的 $i \ge 1$ 恰好执行一次 `ans++`；一旦 $2^i - 1 > n$，后续值单调递增均 $> n$，循环终止。加上初值 1 计入 $0$，返回值恰为所求个数。∎

## 6. 复杂度分析

- **时间复杂度**：$O(\log n)$。循环次数为满足 $2^k - 1 \le n$ 的 $k$ 的个数，约 $\log_2(n+1)$ 次；$n \le 1000$ 时至多 10 次。
- **空间复杂度**：$O(1)$。只使用常数个变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int countMonobit(int n) {
        int ans = 1;      // 0 的二进制是 "0"，天然单比特
        long long x = 1;  // 全 1 数：1, 3, 7, 15, ...
        while (x <= n) {
            ans++;
            x = 2 * x + 1;  // 二进制末尾追加一个 1
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def countMonobit(self, n: int) -> int:
        ans = 1  # 0 是单比特数
        x = 1    # 全 1 数：1, 3, 7, 15, ...
        while x <= n:
            ans += 1
            x = 2 * x + 1
        return ans
```

## 8. 边界情况与易错点

1. **n = 0**：区间只有 $\{0\}$，答案为 1，别返回 0。
2. **漏掉 0**：`ans` 忘记从 1 初始化是最常见的错。
3. **审题**：「所有位都相同」不等于「只由 0 和 1 组成」。$2 = 10_2$、$4 = 100_2$ 都不是单比特数。
4. **前导零**：判断时不要给二进制串补前导零（如把 $4$ 写成 `"0100"`），标准二进制表示无前导零；`bin(x)` 天然正确。
5. **浮点闭式**：`1 + int(math.log2(n + 1))` 理论上等价，但在 $n + 1$ 恰为 2 的幂附近可能因浮点误差少算一个，循环写法最稳。
6. **溢出**：$n \le 1000$ 时 `x` 最大到 2047，`int` 足够；若数据范围推广到 $10^{18}$，C++ 需用 `long long` 并防 `2x+1` 溢出（可用 `x > (n - 1) / 2` 提前判停）。
