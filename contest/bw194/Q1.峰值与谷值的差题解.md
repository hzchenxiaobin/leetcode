# LeetCode 峰值与谷值的差 题解

## 1. 题目概述

- **标题 / 题号**：峰值与谷值的差（#4088，easy）
- **链接**：https://leetcode.cn/problems/difference-between-peaks-and-valleys/
- **来源**：LeetCode 第 194 场双周赛 Q1
- **难度**：简单
- **标签**：数组、枚举、一次扫描

**题意**：给定长度为 $n$ 的整数数组 `nums`，记 $a_i = \text{nums}[i]$。对**内部下标** $1 \le i \le n-2$：若 $a_i$ **严格大于**左右两侧（$a_i > a_{i-1}$ 且 $a_i > a_{i+1}$）称为**峰值**；若**严格小于**左右两侧称为**谷值**。返回「所有峰值之和 − 所有谷值之和」。

**约束**：

- $3 \le n = \text{nums.length} \le 100$
- $-100 \le \text{nums[i]} \le 100$

## 2. 示例

**示例 1**

```text
输入：nums = [1,5,2,4,1,3,0]
输出：9
解释：峰值是 nums[1]=5、nums[3]=4、nums[5]=3；谷值是 nums[2]=2、nums[4]=1。
差值 = (5+4+3) − (2+1) = 9。
```

**示例 2**

```text
输入：nums = [-5,-6,-1,-2,5,3,2]
输出：12
解释：峰值是 nums[2]=-1、nums[4]=5；谷值是 nums[1]=-6、nums[3]=-2。
差值 = (−1+5) − (−6−2) = 4 + 8 = 12。
```

**示例 3**

```text
输入：nums = [6,5,2,5,5,3,6]
输出：-5
解释：数组中没有峰值（nums[3]=5 的右侧 5 不满足严格大于，nums[4]=5 两侧相等）；
谷值是 nums[2]=2、nums[5]=3。差值 = 0 − (2+3) = −5。
```

## 3. 解题思路

### 3.1 直接做法：按定义逐个内部下标判定

签到题的最短路径：题面已把峰、谷的判定式写死，只需枚举全部内部下标 $1 \le i \le n-2$，套定义比较后累加即可，一次扫描 $O(n)$ **本身就是最优解**（任何算法至少要读完整个数组，$\Omega(n)$）。本题比拼的不是算法，而是**读题仔细度**：严格不等号、首尾下标排除、等值平台三类坑（见 §8）。

### 3.2 核心观察：判定超局部 + 峰谷互斥但不完备

![峰谷判定概念图：只看三元组（左,中,右）的严格比较](images/bw194_q1_peak_valley_def.svg)

1. **判定超局部**：下标 $i$ 是否为峰/谷，只取决于三元组 $(a_{i-1},\, a_i,\, a_{i+1})$，与数组其余部分无关。因此无需任何预处理或数据结构，扫到哪判到哪。
2. **峰谷互斥但不完备**：峰要求两个严格大于、谷要求两个严格小于，显然不可能同时成立；但**第三类「都不是」真实存在**——单调坡上的中间点、等值平台（如 $5,5$）两侧比较全失败。所以判谷必须独立写两个严格小于，**不能**用「不是峰」来兜底。
3. **符号累加**：不必先收集峰列表、谷列表再分别求和——峰时 `ans += a[i]`、谷时 `ans -= a[i]`，一趟循环结束 `ans` 就是差值。

### 3.3 算法流程

1. 初始化 $\text{ans} = 0$。
2. 从 $i = 1$ 扫到 $i = n-2$：
   - 若 $a_i > a_{i-1}$ 且 $a_i > a_{i+1}$：$\text{ans} \mathrel{+}= a_i$（峰）；
   - 否则若 $a_i < a_{i-1}$ 且 $a_i < a_{i+1}$：$\text{ans} \mathrel{-}= a_i$（谷）；
   - 否则什么都不做。
3. 返回 $\text{ans}$。

### 3.4 示例演算

![示例 1 演算表：ans 峰加谷减，一趟得到 9](images/bw194_q1_scan_walkthrough.svg)

示例 1 中 5 个内部下标依次判定为 峰、谷、峰、谷、峰，$\text{ans}$ 依次为 $5 \to 3 \to 7 \to 6 \to 9$，扫完即答案。

![示例 3：等值平台 5,5 两类判定全失败，无峰，答案为负](images/bw194_q1_flat_negative.svg)

示例 3 是本题唯一的「坑」样本：$a_3 = 5$ 因右侧相等不是峰、$a_4 = 5$ 因左侧相等谷峰都不是，最终峰值和为 $0$，答案 $-5$ 为负数。

## 4. 算法细节

- 循环写成 `for (int i = 1; i < n - 1; ++i)`，恰好枚举全部内部下标；$n \ge 3$ 保证 $n - 2 \ge 1$，循环体至少可执行。
- 判定用 `if` 峰 / `else if` 谷的顺序：峰谷互斥保证每个下标至多触发一次累加，第三类天然落入隐式 else。
- **谷的判定必须独立写** $a_i < a_{i-1} \land a_i < a_{i+1}$：峰的否定推不出谷（$a_i = a_{i-1}$ 时两个方向同时失败），这是本题唯一的逻辑陷阱。
- 值域核算：内部下标至多 $98$ 个，峰值和与谷值和的绝对值均 $\le 98 \times 100 = 9800$，故 $|\text{ans}| \le 19600$，`int` 无溢出风险。

## 5. 正确性证明

**引理 1（互斥性）**：任意内部下标 $i$ 不可能同时是峰与谷。

**证明**：若 $i$ 同时为峰与谷，则 $a_i > a_{i-1}$ 与 $a_i < a_{i-1}$ 同时成立，矛盾。∎

**引理 2（局部性）**：$i$ 的类别（峰 / 谷 / 都不是）由 $(a_{i-1}, a_i, a_{i+1})$ 三元组唯一确定。

**证明**：峰与谷的定义中仅出现 $a_{i-1}, a_i, a_{i+1}$ 三个量，且均为确定性的布尔条件，与数组其余元素无关。∎

**定理**：上述算法返回 $\displaystyle\sum_{i \text{ 为峰}} a_i \;-\; \sum_{i \text{ 为谷}} a_i$。

**证明**：循环恰好枚举每个内部下标一次，由引理 2 每个下标被唯一归类，由引理 1 峰、谷两个分支至多命中一个，与隐式 else 一起构成不重不漏的三分类。对已扫描下标个数归纳：初始时已扫描集合为空，$\text{ans} = 0$ 成立；每步扫描 $i$ 后，$\text{ans}$ 等于「已扫描部分的峰值和 − 谷值和」这一不变量被保持（峰加、谷减、否则不变）。循环结束时覆盖全部内部下标，即全部峰与谷，$\text{ans}$ 即所求差值。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。单次扫描，每个内部下标至多 4 次比较与 1 次加法。
- **空间复杂度**：$O(1)$。仅常数个变量，不存峰谷列表。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int peakValleyDifference(vector<int>& nums) {
        int n = nums.size(), ans = 0;
        for (int i = 1; i < n - 1; ++i) {
            if (nums[i] > nums[i - 1] && nums[i] > nums[i + 1]) ans += nums[i];
            else if (nums[i] < nums[i - 1] && nums[i] < nums[i + 1]) ans -= nums[i];
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def peakValleyDifference(self, nums: list[int]) -> int:
        ans = 0
        for i in range(1, len(nums) - 1):
            if nums[i] > nums[i - 1] and nums[i] > nums[i + 1]:
                ans += nums[i]
            elif nums[i] < nums[i - 1] and nums[i] < nums[i + 1]:
                ans -= nums[i]
        return ans
```

## 8. 边界情况与易错点

1. **循环范围**：只判 $1 \le i \le n-2$；把 $0$ 或 $n-1$ 纳入会数组越界或误判（首尾没有两侧邻居）。
2. **严格比较**：等值平台（示例 3 的 $5,5$）既非峰也非谷；把 `>` 写成 `>=`、`<` 写成 `<=` 会在平台处误判。
3. **不能用「不是峰」推「是谷」**：判谷必须独立两次严格小于，`else` 兜底会把第三类（单调段、平台）全部算成谷。
4. **答案可为负**（示例 3 返回 $-5$）：`ans` 从 $0$ 起步、直接返回即可，无需取绝对值或担心符号。
5. **溢出**：$|\text{ans}| \le 19600$，`int` 安全，无需 `long long`。

**延伸思考**：若要多次查询任意区间 $[l, r]$ 内的峰谷差，可预处理前缀和 $P[i] = \sum_{j \le i,\, j 为峰} a_j$ 与同理的 $V[i]$，区间合法下标为 $[l+1, r-1]$，答案 $= (P[r-1] - P[l]) - (V[r-1] - V[l])$，每次查询 $O(1)$。若是流式输入，只需保留最近三个值即可 $O(1)$ 空间在线判定峰谷。
