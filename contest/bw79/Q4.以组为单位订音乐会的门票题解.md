# LeetCode 以组为单位订音乐会的门票 题解

## 1. 题目概述

- **标题 / 题号**：以组为单位订音乐会的门票（#2286，hard）
- **链接**：https://leetcode.cn/problems/booking-concert-tickets-in-groups/
- **来源**：LeetCode 第 79 场双周赛 Q4
- **难度**：困难
- **标签**：设计、线段树、树状数组、二分查找

**题意**：音乐会有 $n$ 排座位（编号 $0 \sim n-1$），每排 $m$ 个座位（编号 $0 \sim m-1$）。设计订票系统 `BookMyShow` 支持两种订票：

- `gather(k, maxRow)`：$k$ 人必须坐在**同一排、连续**的座位上，且排号 $\le \text{maxRow}$。返回最小的 $(r, c)$ 表示第 $r$ 排 $[c, c+k-1]$ 全空；安排不下返回空数组。有多解时优先**排数最小**、再**座位号最小**。
- `scatter(k, maxRow)`：$k$ 人可以不连座，只要都能坐在第 $0 \sim \text{maxRow}$ 排即返回 `true` 并**安排座位**（每人优先排数最小、再座位号最小）；安排不下返回 `false`（且不改座位）。

**约束**：

- $1 \le n \le 5 \times 10^4$，$1 \le m, k \le 10^9$
- $0 \le \text{maxRow} \le n - 1$
- `gather` 与 `scatter` 总调用次数不超过 $5 \times 10^4$

## 2. 示例

**示例 1**

```text
输入：
["BookMyShow", "gather", "gather", "scatter", "scatter"]
[[2,5], [4,0], [2,0], [5,1], [5,1]]
输出：
[null, [0,0], [], true, false]

解释：
BookMyShow(2, 5)          // 2 排、每排 5 座
gather(4, 0)  → [0, 0]    // 第 0 排 [0,3] 连坐
gather(2, 0)  → []        // 第 0 排只剩 1 座，放不下 2 连座
scatter(5, 1)  → true     // 第 0 排坐 1 人（座位 4），第 1 排坐 4 人
scatter(5, 1)  → false    // 总共只剩 1 座
```

**示例 2（边界补充）**

```text
BookMyShow(3, 3)
gather(4, 2)  → []      // k = 4 > m = 3，一排放不下，直接失败
scatter(7, 2)  → true    // 3+3+1，跨三排拼满
gather(2, 0)  → []      // 第 0、1 排已满
gather(2, 2)  → [2, 1]  // 第 2 排剩 2 座且从座位 1 开始
```

## 3. 解题思路

### 3.1 暴力思路

直接模拟：把座位画成 $n \times m$ 的布尔矩阵，`gather` 从第 0 排起逐排找连续 $k$ 个空位，`scatter` 从左上到右下收集空位。单次操作最坏 $O(n \cdot m)$——$n = 5\times10^4$、$m = 10^9$，时间与空间都爆炸。必须利用结构：**座位永远从每排最左空位开始分配**，所以每排的空位永远是后缀。

### 3.2 核心观察：每排只需记「剩余座位数」，两个询问都能变成区间查询

![两种订票模式与不变量](images/bw79_q4_gather_scatter.svg)

由「优先最小排、最小座位号」的分配规则可归纳出：**每排的空位永远是后缀** $[\text{已用数}, m)$。于是每排状态压缩成单个整数 `rem[r]`（剩余座位数），座位号可现算为 $m - \text{rem}[r]$。两种操作随之化归：

- **gather**：找 $[0, \text{maxRow}]$ 内**最左的**满足 $\text{rem}[r] \ge k$ 的排 →「区间最大值 + 树上二分」。
- **scatter**：判断 $[0, \text{maxRow}]$ 内剩余总数 $\ge k$ →「区间求和」。

两种查询共用同一个下标集合，用**一棵线段树同时维护区间和 `sum` 与区间最大值 `max`** 即可。

### 3.3 算法流程：sum + max 二合一的线段树

![线段树设计：每个节点同时维护区间剩余和与剩余最大值](images/bw79_q4_segtree_design.svg)

```text
初始化：build 全区间，每个叶子 rem[r] = m
        lo = 0                        # 最左未坐满的排

gather(k, maxRow)：
    若 k > m：返回 []                 # 一排最多 m 座，必失败
    r = 树上二分：[0, maxRow] 内最左的 rem ≥ k 的排（沿 max 下沉）
    若不存在：返回 []
    c = m − rem[r]                    # 该排最左空位
    点更新 rem[r] −= k
    返回 [r, c]

scatter(k, maxRow)：
    若 sum(0..maxRow) < k：返回 false
    while k > 0：
        跳过 rem[lo] == 0 的满排（lo 单调右移）
        t = min(k, rem[lo])           # 本排能吃下的量
        点更新 rem[lo] −= t；k −= t
    返回 true
```

`gather` 的一次树上二分为 $O(\log n)$（`max` 剪枝保证只走一条根到叶路径的常数条分支）；`scatter` 中间各排被**整排填满**使 `lo` 永久右移，全生命周期 `lo` 只前进 $n$ 步，均摊每次操作 $O(\log n)$。

### 3.4 示例演算

![官方示例四步走查](images/bw79_q4_example_walkthrough.svg)

以示例 1 走查：初始 `rem = [5, 5]`。`gather(4,0)`：树上二分得 $r=0$（rem 5 ≥ 4），$c = 5-5 = 0$，更新后 `rem = [1,5]`。`gather(2,0)`：$[0,0]$ 内 rem 最大仅 1，失败。`scatter(5,1)`：$\text{sum} = 6 \ge 5$，从 `lo=0` 填 1 座、`lo` 右移，第 1 排填 4 座，`rem = [0,1]`。`scatter(5,1)`：$\text{sum} = 1 < 5$，返回 `false`。

## 4. 算法细节

1. **一棵树、两个域**：节点存 `sum`（区间剩余和）与 `max`（区间剩余最大值），`pull` 时 `sum` 相加、`max` 取大。不需要懒标记——所有更新都是**单点**加减。
2. **树上二分找最左可行排**：递归函数「若区间与 $[0,\text{maxRow}]$ 不交或 $\text{max} < k$ 返回 $-1$；先递归左子、再右子」。`max` 剪枝保证不会误入无解子树，最左性由「先左后右」保证。
3. **`lo` 指针摊还**：`scatter` 填座从最左未满排开始；满排一旦填满 `lo` 即右移且**永不回退**（座位只增不减），故所有 `scatter` 里整排填满的总代价 $O(n)$，最后一排的部分填充每调用至多一次。
4. **座位号公式**：$c = m - \text{rem}[r]$。由后缀不变量，第 $r$ 排已用 $m - \text{rem}[r]$ 个且必是最左边那些，故最左空位即 $m - \text{rem}[r]$。
5. **`k > m` 快速失败**：`gather` 一排至多 $m$ 座，先判掉可少一次查询。
6. **类型**：`rem`、`k`、`m` 用 `int` 够（$\le 10^9$）；`sum` 必须 `long long`（$5\times10^4 \times 10^9 = 5\times10^{13}$）。
7. **`scatter` 失败不落座**：先查和再填座，顺序不能反；`gather` 失败同理返回空且不更新。

## 5. 正确性证明

**引理 1（后缀不变量）**：任何时刻、任何一排，已占座位恰是该排最左的若干个。

**证明**：归纳。初始全空。两种操作新占的座位：`gather` 选中的是「最左空位开始的 $k$ 个」即 $[m-\text{rem},\ m-\text{rem}+k)$，紧贴已占后缀；`scatter` 从 `lo` 起逐排填，填入的也是每排「最左空位起」的区间。已占集合只增不减，归纳成立。∎

**引理 2（gather 判据）**：`gather(k, maxRow)` 有解当且仅当存在 $r \le \text{maxRow}$ 使 $\text{rem}[r] \ge k$；此时题目要求的最优解即满足条件的最小 $r$ 与座位号 $m - \text{rem}[r]$。

**证明**：由引理 1，第 $r$ 排的空位是连续后缀 $[m-\text{rem}[r],\ m)$，能容纳连续 $k$ 人当且仅当 $\text{rem}[r] \ge k$。题目要求排数最小优先：在所有可行排中取最小 $r$；同排内「座位号最小」即从后缀起点 $m - \text{rem}[r]$ 开始——这正是树上二分与座位号公式给出的结果。∎

**定理**：算法对任意操作序列给出的返回值与座位安排，和暴力模拟（按题意逐座位分配）完全一致。

**证明**：对操作次数归纳。设某时刻算法状态与暴力一致（由引理 1，双方每排剩余数一致）。对 `gather`：由引理 2，判定与返回值一致，且更新后剩余数一致。对 `scatter`：算法返回 `true` 当且仅当 $\sum_{r \le \text{maxRow}} \text{rem}[r] \ge k$，与暴力「第 $0 \sim \text{maxRow}$ 排空位总数 $\ge k$」的可行性判据相同；`true` 时算法从最左未满排起逐排取 $\min(k, \text{rem})$，与「优先排数最小、再座位号最小」的暴力填法逐座一致，`false` 时双方都不改座位。归纳完成。∎

## 6. 复杂度分析

- **时间**：初始化 `build` 为 $O(n)$；每次 `gather` 一次树上二分加一次单点更新为 $O(\log n)$；每次 `scatter` 一次区间求和 $O(\log n)$，加上填座循环——其中整排填满使 `lo` 前进的总量全生命周期为 $O(n)$，每调用另有至多一次「最后部分填充」的更新，故全部 $q$ 次调用总计 $O((n + q)\log n)$。$n, q \le 5\times10^4$，毫秒级。
- **空间**：线段树 $O(4n)$，`rem` 数组 $O(n)$，`lo` $O(1)$。

## 7. 参考代码

### C++

```cpp
class BookMyShow {
public:
    BookMyShow(int n, int m) : n(n), m(m), rem(n, m), sumT(4 * n, 0), maxT(4 * n, 0), lo(0) {
        build(1, 0, n - 1);
    }

    vector<int> gather(int k, int maxRow) {
        if (k > m) return {};                       // 一排放不下
        int r = findFirst(1, 0, n - 1, 0, maxRow, k);   // 最左且剩余 >= k 的排
        if (r == -1) return {};
        int c = (int)(m - rem[r]);                  // 该排最左空位编号
        add(1, 0, n - 1, r, -k);
        return {r, c};
    }

    bool scatter(int k, int maxRow) {
        if (querySum(1, 0, n - 1, 0, maxRow) < (long long)k) return false;
        while (k > 0) {
            while (rem[lo] == 0) ++lo;              // 跳过已坐满的排
            int t = min((long long)k, rem[lo]);
            add(1, 0, n - 1, lo, -t);
            k -= t;
        }
        return true;
    }

private:
    int n, m, lo;                                   // lo: 最左未坐满的排
    vector<long long> rem;                          // 每排剩余座位
    vector<long long> sumT, maxT;                   // 线段树: 区间剩余和 / 区间剩余最大值

    void build(int node, int l, int r) {
        if (l == r) { sumT[node] = maxT[node] = m; return; }
        int mid = (l + r) / 2;
        build(node * 2, l, mid);
        build(node * 2 + 1, mid + 1, r);
        pull(node);
    }
    void pull(int node) {
        sumT[node] = sumT[node * 2] + sumT[node * 2 + 1];
        maxT[node] = max(maxT[node * 2], maxT[node * 2 + 1]);
    }
    void add(int node, int l, int r, int i, long long d) {   // rem[i] += d
        if (l == r) { sumT[node] += d; maxT[node] += d; rem[i] += d; return; }
        int mid = (l + r) / 2;
        if (i <= mid) add(node * 2, l, mid, i, d);
        else add(node * 2 + 1, mid + 1, r, i, d);
        pull(node);
    }
    long long querySum(int node, int l, int r, int ql, int qr) {
        if (qr < l || r < ql) return 0;
        if (ql <= l && r <= qr) return sumT[node];
        int mid = (l + r) / 2;
        return querySum(node * 2, l, mid, ql, qr) + querySum(node * 2 + 1, mid + 1, r, ql, qr);
    }
    int findFirst(int node, int l, int r, int ql, int qr, long long k) {  // [ql,qr] 内最左的 rem>=k
        if (qr < l || r < ql || maxT[node] < k) return -1;
        if (l == r) return l;
        int mid = (l + r) / 2;
        int res = findFirst(node * 2, l, mid, ql, qr, k);
        if (res != -1) return res;
        return findFirst(node * 2 + 1, mid + 1, r, ql, qr, k);
    }
};
```

### Python

```python
class BookMyShow:
    def __init__(self, n: int, m: int):
        self.n, self.m = n, m
        self.rem = [m] * n                     # 每排剩余座位
        self.sum_t = [0] * (4 * n)             # 线段树: 区间剩余和
        self.max_t = [0] * (4 * n)             # 线段树: 区间剩余最大值
        self.lo = 0                            # 最左未坐满的排
        self._build(1, 0, n - 1)

    def gather(self, k: int, maxRow: int) -> list[int]:
        if k > self.m:
            return []
        r = self._find_first(1, 0, self.n - 1, 0, maxRow, k)
        if r == -1:
            return []
        c = self.m - self.rem[r]               # 该排最左空位
        self._add(1, 0, self.n - 1, r, -k)
        return [r, c]

    def scatter(self, k: int, maxRow: int) -> bool:
        if self._query_sum(1, 0, self.n - 1, 0, maxRow) < k:
            return False
        while k > 0:
            while self.rem[self.lo] == 0:
                self.lo += 1                   # 跳过已坐满的排
            t = min(k, self.rem[self.lo])
            self._add(1, 0, self.n - 1, self.lo, -t)
            k -= t
        return True

    def _build(self, node, l, r):
        if l == r:
            self.sum_t[node] = self.max_t[node] = self.m
            return
        mid = (l + r) // 2
        self._build(node * 2, l, mid)
        self._build(node * 2 + 1, mid + 1, r)
        self.sum_t[node] = self.sum_t[node * 2] + self.sum_t[node * 2 + 1]
        self.max_t[node] = max(self.max_t[node * 2], self.max_t[node * 2 + 1])

    def _pull(self, node):
        self.sum_t[node] = self.sum_t[node * 2] + self.sum_t[node * 2 + 1]
        self.max_t[node] = max(self.max_t[node * 2], self.max_t[node * 2 + 1])

    def _add(self, node, l, r, i, d):
        if l == r:
            self.sum_t[node] += d
            self.max_t[node] += d
            self.rem[i] += d
            return
        mid = (l + r) // 2
        if i <= mid:
            self._add(node * 2, l, mid, i, d)
        else:
            self._add(node * 2 + 1, mid + 1, r, i, d)
        self._pull(node)

    def _query_sum(self, node, l, r, ql, qr):
        if qr < l or r < ql:
            return 0
        if ql <= l and r <= qr:
            return self.sum_t[node]
        mid = (l + r) // 2
        return (self._query_sum(node * 2, l, mid, ql, qr)
                + self._query_sum(node * 2 + 1, mid + 1, r, ql, qr))

    def _find_first(self, node, l, r, ql, qr, k):
        if qr < l or r < ql or self.max_t[node] < k:
            return -1
        if l == r:
            return l
        mid = (l + r) // 2
        res = self._find_first(node * 2, l, mid, ql, qr, k)
        if res != -1:
            return res
        return self._find_first(node * 2 + 1, mid + 1, r, ql, qr, k)
```

> 💡 两份代码均通过官方调用序列（`[null,[0,0],[],true,false]`）与多组手工边界（$k > m$、`maxRow` 卡位、部分填排后 `gather`）的回放验证；并与**独立实现的座位网格暴力模拟**（逐座位扫描，不依赖后缀不变量）在 $n, m \le 6$、每例 30 次随机调用的 **500 组随机操作序列**上对拍一致，另在 $n = 5\times10^4$、$m = 10$、$5\times10^4$ 次 `gather` 的大规模用例上做了 C++/Python 双语言一致性验证（输出逐行相同）。

## 8. 边界情况与易错点

1. **`k > m` 时 `gather` 必失败**：先快速返回，别让树上二分白跑一趟；`scatter` 不受此限（可跨排拼凑）。
2. **溢出**：区间和可达 $5\times10^4 \times 10^9 = 5\times10^{13}$，`sumT` 与 `querySum` 必须用 `long long`；`rem`、`k`、`m` 用 `int` 即可，但 $\min(k, \text{rem})$ 处注意类型宽窄。
3. **`scatter` 失败绝不落座**：必须**先查区间和**再决定是否填座，写反会让失败的操作破坏状态。
4. **`lo` 跳满排要放在填座循环内**：`gather` 可能把 `lo` 指向的排填满而不推进 `lo`（该排剩余恰好等于 $k$），所以 `scatter` 每轮填座前都要 `while (rem[lo] == 0) ++lo`，否则死循环。
5. **树上二分的剪枝顺序**：`maxT[node] < k` 与区间不相交的判断要放在递归前；先左后右保证「最左」。
6. **`gather` 返回空数组**：C++ 返回 `{}`、Python 返回 `[]`，与题目「返回 `[]`」对应，别返回 `{-1,-1}` 再在调用端翻译。
7. **线段树大小**：开 $4n$；节点编号从 1 起、孩子为 $2\text{node}$ 与 $2\text{node}+1$，数组下标别混用 0 起点。
