# LeetCode 判断一个数的数字计数是否等于数位的值 题解

## 1. 题目概述

- **标题 / 题号**：判断一个数的数字计数是否等于数位的值（#2283，easy）
- **链接**：https://leetcode.cn/problems/check-if-number-has-equal-digit-count-and-digit-value/
- **来源**：LeetCode 第 79 场双周赛 Q1
- **难度**：简单
- **标签**：哈希表、字符串、计数

**题意**：给定下标从 $0$ 开始、长度为 $n$ 且只包含数字的字符串 `num`。如果对**每个**下标 $0 \le i < n$，**数位 $i$ 在 `num` 中恰好出现了 `num[i]` 次**，返回 `true`；否则返回 `false`。

**约束**：

- $n = \text{num.length}$，$1 \le n \le 10$
- `num` 只包含数字字符

## 2. 示例

**示例 1**

```text
输入：num = "1210"
输出：true
解释：
num[0] = '1'，数字 0 出现了 1 次 ✓
num[1] = '2'，数字 1 出现了 2 次 ✓
num[2] = '1'，数字 2 出现了 1 次 ✓
num[3] = '0'，数字 3 出现了 0 次 ✓
```

**示例 2**

```text
输入：num = "030"
输出：false
解释：
num[0] = '0'，要求数字 0 出现 0 次，实际出现 2 次 ✗
num[1] = '3'，要求数字 1 出现 3 次，实际出现 0 次 ✗
num[2] = '0'，要求数字 2 出现 0 次，实际出现 0 次 ✓
```

**示例 3（边界补充）**

```text
输入：num = "2020"
输出：true
解释：数字 0 出现 2 次（num[0]=2 ✓），数字 2 出现 2 次（num[2]=2 ✓），
     数字 1、3 均出现 0 次（num[1]=num[3]=0 ✓）。
```

## 3. 解题思路

### 3.1 暴力思路

最直白的做法是**按定义逐条检查**：对每个下标 $i$，再扫一遍整个字符串统计数位 $i$ 的出现次数，与 `num[i]` 比较。时间 $O(n^2)$。本题 $n \le 10$，这样做完全能过；但它把「统计」重复做了 $n$ 遍——统计量其实与 $i$ 无关，一遍就能全部算出来。

### 3.2 核心观察：先计数，后核对

![核对流程：先建计数数组再逐位比对](images/bw79_q1_digit_count_check.svg)

把「数位 $i$ 出现了几次」统一预处理成计数数组 $\text{cnt}[0..9]$：扫一遍 `num`，每个字符 `c` 使 $\text{cnt}[c - \text{'0'}]$ 加一。之后每个下标 $i$ 的判定退化为一次数组比较：

$$\text{cnt}[i] \stackrel{?}{=} \text{num}[i] - \text{'0'}$$

**注意区分两个角色**：下标 $i$ 是「哪个数字」，`num[i]` 的数值是「要求出现几次」，$\text{cnt}[i]$ 是「实际出现几次」。三者只在计数数组这一层交汇。

### 3.3 算法流程

```text
1. cnt[0..9] ← 0
2. 对 num 中每个字符 c：cnt[c − '0'] += 1
3. 对每个下标 i ∈ [0, n)：
       若 cnt[i] ≠ num[i] − '0' → 返回 false
4. 返回 true
```

### 3.4 示例演算

![反例走查："030" 逐位判定](images/bw79_q1_example_walkthrough.svg)

以 `"030"` 为例：一遍扫描得 $\text{cnt}[0] = 2$、$\text{cnt}[3] = 1$，其余为 0。核对时下标 0 与下标 1 立即失配（$2 \ne 0$、$0 \ne 3$），返回 `false`。而 `"1210"` 扫描得 $\text{cnt} = [1,2,1,0]$，与 `num` 逐位相等（$1,2,1,0$），返回 `true`。

## 4. 算法细节

1. **计数数组只开 10 个桶**：字符集是数字 $0 \sim 9$，`cnt[10]` 足够；用 `c - '0'` 把字符映射到下标。
2. **比较方向别写反**：是「数位 $i$ 的实际出现次数 $\text{cnt}[i]$」对比「要求次数 `num[i]` 的数值」，不是对比字符本身。
3. **`num[i]` 的数值不会超过 9**：单字符数字，天然落在 $\text{cnt}$ 的下标范围内；即使 `num[i]` 大于 $n$（比如 $n=3$、`num[i]=9`），$\text{cnt}[i] \le n < 9$ 也会自然判负，无需特判。
4. **核对只到下标 $n-1$**：数位 $i \ge n$ 不在核对范围内（没有对应的 `num[i]`），但它们出现的次数已在第一步被统计——统计全串、核对前 $n$ 位，两者并不矛盾。
5. **提前返回**：遇到第一个失配即可返回 `false`，无需扫完。

## 5. 正确性证明

**引理 1（计数的正确性）**：一遍扫描后，$\text{cnt}[d]$ 等于数字 $d$ 在 `num` 中的出现次数。

**证明**：初始均为 0；每个字符恰好被访问一次，且只使与其数值对应的桶加 1。归纳可得扫描结束时每个桶的值恰为对应数字的出现次数。∎

**定理**：算法返回 `true` 当且仅当对每个 $0 \le i < n$ 都有「数位 $i$ 在 `num` 中出现 `num[i]` 次」。

**证明**：由引理 1，步骤 3 中 $\text{cnt}[i]$ 即数位 $i$ 的实际出现次数，`num[i] − '0'` 即题意要求的出现次数，二者相等与否正是题意的逐条判定。算法当且仅当所有 $n$ 条判定全部通过时返回 `true`，与题设条件逐字等价。∎

## 6. 复杂度分析

- **时间**：$O(n + |\Sigma|)$，其中字符集大小 $|\Sigma| = 10$。扫描计数 $O(n)$，核对至多 $n$ 次、每次 $O(1)$。
- **空间**：$O(|\Sigma|) = O(10)$，即计数数组本身。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool digitCount(string num) {
        int cnt[10] = {0};
        for (char c : num) ++cnt[c - '0'];
        for (int i = 0; i < (int)num.size(); ++i)
            if (cnt[i] != num[i] - '0') return false;
        return true;
    }
};
```

### Python

```python
class Solution:
    def digitCount(self, num: str) -> bool:
        cnt = [0] * 10
        for c in num:
            cnt[ord(c) - 48] += 1
        for i, ch in enumerate(num):
            if cnt[i] != ord(ch) - 48:
                return False
        return True
```

> 💡 两份代码均通过官方示例（`true` / `false`）与边界用例（`"1"`、`"2020"`、`"0"`、`"12101"`）的本地验证，结果全部符合预期。

## 8. 边界情况与易错点

1. **`num = "0"` 返回 `false`**：数字 0 要求出现 0 次，但 '0' 自身出现了 1 次。
2. **$n = 1$ 时恒为 `false`**：唯一的字符要么是 '0'（则数字 0 出现 1 次，但 `num[0]=0` 要求 0 次），要么非 '0'（则数字 0 出现 0 次，但 `num[0] ≥ 1`），两种情况都失配。
3. **不要用「字符相等」代替「次数相等」**：判定的对象是 `cnt[i]`（次数）与 `num[i]` 的**数值**，把 `num[i]` 当字符与某个数字字符比较是常见笔误。
4. **计数数组勿越界**：`c - '0'` 依赖输入确实只含数字；题目已保证，无需额外防御。
5. **`"2020"` 这类双数字自描述串**：0 与 2 各出现 2 次，1 与 3 各 0 次，是另一组合法答案，可作为自测用例。
