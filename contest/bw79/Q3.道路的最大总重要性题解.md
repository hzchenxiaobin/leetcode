# LeetCode 道路的最大总重要性 题解

## 1. 题目概述

- **标题 / 题号**：道路的最大总重要性（#2285，medium）
- **链接**：https://leetcode.cn/problems/maximum-total-importance-of-roads/
- **来源**：LeetCode 第 79 场双周赛 Q3
- **难度**：中等
- **标签**：贪心、图、排序、堆（优先队列）

**题意**：国家里有 $n$ 座城市（编号 $0 \sim n-1$）与若干双向道路 `roads[i] = [ai, bi]`（无重复道路、无自环）。需要给每座城市安排一个 $1 \sim n$ 之间**互不相同**的整数值；一条道路的重要性为其两端城市值之和。求所有道路重要性之和的**最大值**。

**约束**：

- $2 \le n \le 5 \times 10^4$
- $1 \le \text{roads.length} \le 5 \times 10^4$
- $0 \le a_i, b_i \le n - 1$，$a_i \ne b_i$，无重复道路

## 2. 示例

**示例 1**

```text
输入：n = 5, roads = [[0,1],[1,2],[2,3],[0,2],[1,3],[2,4]]
输出：43
解释：赋值 [2,4,5,3,1]（城市 2 度数最大，配最大值 5）。
     六条边重要性 6+9+8+7+7+6 = 43，可证明不可能更大。
```

**示例 2**

```text
输入：n = 5, roads = [[0,3],[2,4],[1,3]]
输出：20
解释：赋值 [4,3,2,5,1]，三边重要性 9+3+8 = 20。
```

**示例 3（边界补充）**

```text
输入：n = 2, roads = [[0,1]]
输出：3
解释：度数都是 1，赋 (2,1)，重要性 2+1 = 3。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有 $n!$ 种赋值方案、逐一求和取最大——$n = 5 \times 10^4$ 直接天文数字。稍加观察可以发现：求和时城市的「身份」并不重要，只有它的**度数**决定其值被计入的次数。抓住这一点，问题就从「排列」塌缩成「配对」。

### 3.2 核心观察：总和 $= \sum_v \deg(v) \times \text{value}(v)$

![核心观察：每座城市的值恰好被计入它的度数次](images/bw79_q3_degree_contribution.svg)

把每条边的重要性 $\text{value}(a) + \text{value}(b)$ **按端点拆开**：城市 $v$ 的值每条与它相连的边都会加一次，共 $\deg(v)$ 次。于是

$$\text{总分} = \sum_{(a,b) \in \text{roads}} (\text{value}(a) + \text{value}(b)) = \sum_{v=0}^{n-1} \deg(v) \times \text{value}(v)$$

赋值方案与图的**结构彻底解耦**——剩下的只是一个纯代数问题：把 $1 \sim n$ 这 $n$ 个权值分配给度数序列 $\deg(0), \dots, \deg(n-1)$，使乘积和最大。

### 3.3 算法流程：度数降序配大权值

![贪心：度数降序配权值 n, n−1, …, 1](images/bw79_q3_sort_assign.svg)

由**重排不等式**（或下节的交换论证），乘积和最大当且仅当两个序列**同序**排列：度数越大的城市配越大的值。

```text
1. 统计每座城市的度数 deg[v]（每条边两端各 +1）
2. 将 deg 降序排序得 d[0] ≥ d[1] ≥ … ≥ d[n−1]
3. ans = Σ d[i] × (n − i)      # 第 i 大的度数配上第 i 大的权值 n−i
4. 返回 ans
```

### 3.4 示例演算

以示例 1 走查：度数依次为城市 2 是 $4$、城市 1 是 $3$、城市 0 与 3 各 $2$、城市 4 是 $1$。降序 $[4,3,2,2,1]$，配上权值 $[5,4,3,2,1]$：

$$4{\times}5 + 3{\times}4 + 2{\times}3 + 2{\times}2 + 1{\times}1 = 20 + 12 + 6 + 4 + 1 = 43 \checkmark$$

示例 2：度数 $[2,1,1,1,1]$（城市 3 度 2），配 $[5,4,3,2,1]$ 得 $10+4+3+2+1 = 20$。

## 4. 算法细节

1. **度数统计**：`deg[r[0]]++、deg[r[1]]++`，一条边两端各加一；无需建邻接表。
2. **排序后权值即位次**：降序第 $i$ 位（0 起）配的权值恰是 $n - i$，不必真正生成权值数组。
3. **用 `long long` 累加**：单条边重要性 $\le (n-1) + n < 10^5$，边数 $\le 5\times10^4$，总和上界约 $5\times10^9$，**超出 32 位 `int`**（约 $2.1\times10^9$）；题目返回类型也是 `long`。
4. **排序方向别搞反**：`greater<int>()` 降序；若误升序，得到的是**最小**总分（重排不等式的另一侧）。
5. **堆解法等价**：把度数放入大根堆，依次弹出配 $n, n-1, \dots$，与排序同效；排序写起来更短。

## 5. 正确性证明

**引理 1（按端点拆分）**：任意赋值方案的总分为 $\sum_v \deg(v) \times \text{value}(v)$。

**证明**：每条边 $(a, b)$ 在总分中贡献 $\text{value}(a) + \text{value}(b)$。把贡献记到端点头上：城市 $v$ 每作为某条边的一端被记 $\text{value}(v)$ 一次，共被记 $\deg(v)$ 次。求和交换次序即得。∎

**引理 2（交换论证）**：设 $\deg(u) > \deg(v)$ 而当前方案中 $\text{value}(u) < \text{value}(v)$。交换两者的值后总分变化量为 $(\deg(u) - \deg(v))(\text{value}(v) - \text{value}(u)) > 0$。

**证明**：交换前 $u$ 的贡献为 $\deg(u)\,\text{value}(u)$、$v$ 为 $\deg(v)\,\text{value}(v)$；交换后两贡献为 $\deg(u)\,\text{value}(v)$ 与 $\deg(v)\,\text{value}(u)$。差为

$$[\deg(u)\text{value}(v) + \deg(v)\text{value}(u)] - [\deg(u)\text{value}(u) + \deg(v)\text{value}(v)] = (\deg(u) - \deg(v))(\text{value}(v) - \text{value}(u)),$$

由假设两因子均为正，故严格增。∎

**定理（贪心正确性）**：把度数降序排列并与 $n, n-1, \dots, 1$ 依次配对，所得总分最大。

**证明**：设某最优方案中存在「逆序对」$u, v$：$\deg(u) > \deg(v)$ 但 $\text{value}(u) < \text{value}(v)$。由引理 2 交换两者的值可使总分严格增大，与最优性矛盾；故最优方案中没有逆序对，即度数与值**同序**。同序配对在不重复的权值 $1 \sim n$ 下是唯一的（度数相同的城市之间互换不影响乘积和），正是贪心方案。再由引理 1，贪心方案的总分就是全局最大值。∎

> 💡 这正是**重排不等式**：两序列同序相乘求和最大、逆序相乘求和最小。引理 2 的交换论证是它的两行证明。

## 6. 复杂度分析

- **时间**：$O(n + m \log n)$？非也——排序对象是长度为 $n$ 的度数数组，故为 $O(n + m + n\log n)$：统计度数 $O(m)$，排序 $O(n \log n)$，求和 $O(n)$。$n, m \le 5\times10^4$，毫秒级。
- **空间**：$O(n)$，度数数组（排序若原地则无额外开销；Python 的 `sort` 亦为原地）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long maximumImportance(int n, vector<vector<int>>& roads) {
        vector<int> deg(n, 0);
        for (const auto& r : roads) {
            ++deg[r[0]];
            ++deg[r[1]];
        }
        sort(deg.begin(), deg.end(), greater<int>());
        long long ans = 0;
        for (int i = 0; i < n; ++i)
            ans += (long long)deg[i] * (n - i);   // 度数大者配大权值 n, n-1, ...
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maximumImportance(self, n: int, roads: list[list[int]]) -> int:
        deg = [0] * n
        for a, b in roads:
            deg[a] += 1
            deg[b] += 1
        deg.sort(reverse=True)
        return sum(d * (n - i) for i, d in enumerate(deg))
```

> 💡 两份代码均通过官方示例（43、20）与边界用例（$n=2$ 单边、无边图），并与「全排列枚举最优赋值」的暴力实现在 $n \le 7$ 的 **500 组随机图**上对拍一致（`mismatch = 0`）；另在 $n = 3000$、$m = 20000$ 的大图上做了 C++/Python 双语言一致性验证。

## 8. 边界情况与易错点

1. **溢出（最大陷阱）**：总和上界约 $5\times10^9 > 2^{31} - 1$，C++ 必须 `long long` 累加；注意 `deg[i] * (n - i)` 两个 `int` 相乘会先按 `int` 溢出，写 `(long long)deg[i] * (n - i)` 强转在前。
2. **`n` 座城市不一定都有道路**：孤立城市度数为 0，配权值时贡献为 0，无需特判；但它们**仍占用一个权值名额**（$1 \sim n$ 各用一次），排序配对天然正确处理。
3. **排序方向**：升序会得到最小值。示例 1 若升序配对得 $4{\times}1+3{\times}2+2{\times}3+2{\times}4+1{\times}5 = 27 \ne 43$，可作反向自测。
4. **度数与权值都从「大」开始对应**：`i` 从 0 起时权值是 $n - i$ 而非 $i + 1$，二者相差一个镜像，写反即得最小值。
5. **返回类型**：LeetCode 接口为 `long` / Python `int`；C++ 返回 `long long` 与平台 `long`（LP64 下同宽）兼容。
