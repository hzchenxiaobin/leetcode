# LeetCode 英雄的力量 题解

## 1. 题目概述

- **标题 / 题号**：英雄的力量（#2681，hard）
- **链接**：https://leetcode.cn/problems/power-of-heroes/
- **来源**：LeetCode 第 104 场双周赛 Q4
- **难度**：困难
- **标签**：数组、数学、动态规划、前缀和、排序

**题意**：定义一组英雄（数组 `nums` 的非空子序列）的力量为 $\max^2 \times \min$（组内最大值的平方乘最小值）。求**所有**非空英雄组的力量之和，对 $10^9+7$ 取余。

**约束**：

- $1 \le nums.length \le 10^5$
- $1 \le nums[i] \le 10^9$

## 2. 示例

**示例 1**

```text
输入：nums = [2,1,4]
输出：141
解释：7 个组的力量：[2]→8、[1]→1、[4]→64、[2,1]→4、[2,4]→32、
      [1,4]→16、[2,1,4]→16，总和 8+1+64+4+32+16+16 = 141。
```

**示例 2**

```text
输入：nums = [1,1,1]
输出：7
解释：7 个非空子集，每组 max=min=1，力量都是 1。
```

**示例 3（边界补充）**

```text
输入：nums = [1000000000]
输出：998373120
解释：唯一一组的力量 = (10^9)^2 × 10^9 = 10^27，取模后为 998373120。
      单元素组也按 max²×min 计算（即立方）。
```

## 3. 解题思路

### 3.1 暴力思路

枚举 $2^n - 1$ 个非空子集、对每个子集求 $\max$ 与 $\min$——$n = 10^5$ 直接爆炸；即便退到"排序后枚举 $(i, j)$ 作为最小/最大下标对"的 $O(n^2)$ 聚合（每对 $(i,j)$ 贡献 $2^{j-i-1}$ 个子集），$10^{10}$ 也不可行。必须让"同一最大值的全部组"在**一趟扫描**里合并计算，把 $2$ 的幂指数差转成滚动递推。

### 3.2 核心观察：排序后按 (最小, 最大) 对拆分，中间元素自由

![核心观察：排序后固定最小 a_i 与最大 a_j，中间 j−i−1 个元素任选，2^(j−i−1) 个组共享同一力量 a_i·a_j²](images/bw104_q4_minmax_pairs.svg)

将数组升序排序为 $a_0 \le a_1 \le \cdots \le a_{n-1}$。任意非空子集由它的**最小下标 $i$ 与最大下标 $j$**（$i \le j$）唯一刻画：子集必须包含 $a_i, a_j$，而中间下标 $i+1, \dots, j-1$ 的元素**任选**——共 $2^{j-i-1}$ 个子集（$i = j$ 时恰为单元素组 $\{a_i\}$）。下标序即值序，故这些组的力量**全部相同**：

$$\text{力量} = a_j^2 \cdot a_i, \qquad \text{组数} = 2^{j-i-1} \ (i < j), \quad 1 \ (i = j)$$

$$\text{ans} = \sum_{j=0}^{n-1} a_j^2 \Big( a_j + \sum_{i<j} a_i \cdot 2^{\,j-1-i} \Big)$$

括号里正是"以 $a_j$ 为最大值"的所有组的 $\min$ 加权和：单元素组贡献 $a_j$ 本身，其余每组按其最小值计一次。

### 3.3 算法流程：滚动量 $W$ 一步翻倍

![算法流程：滚动维护 W_j = Σ_{i<j} a_i·2^(j-1-i)，每步 W ← 2W + a_j，答案累加 a_j²(a_j+W)](images/bw104_q4_dp_recurrence.svg)

括号内的和式 $W_j = \sum_{i<j} a_i \cdot 2^{j-1-i}$ 无法对每个 $j$ 重算，但它有完美的递推：**每往右挪一个元素，之前所有项的指数都恰好加一**，

$$W_0 = 0, \qquad W_{j} = 2\,W_{j-1} + a_{j-1} \quad (j \ge 1)$$

于是单趟扫描，边滚边加：

```text
1. 将 nums 升序排序
2. ans = 0, W = 0
3. for a in nums:              # a = a_j
4.     ans += a² * (a + W)
5.     W = 2*W + a             # 为下一个 j 准备 W_{j+1}
6. 返回 ans mod 1e9+7（全程取模）
```

### 3.4 示例演算

![示例演算：数组 2,1,4 排序后三步贡献 1、12、128，合计 141](images/bw104_q4_example_walkthrough.svg)

以示例 1（排序后 $[1, 2, 4]$）演算：

| $j$ | $a_j$ | $W_j$ | 贡献 $a_j^2(a_j + W_j)$ | 对应的组 |
|-----|-------|-------|--------------------------|----------|
| 0 | 1 | 0 | $1 \times (1+0) = 1$ | $\{1\}$ |
| 1 | 2 | 1 | $4 \times (2+1) = 12$ | $\{2\}$ 力 4、$\{1,2\}$ 力 4、…共 $4+4+4=12$ |
| 2 | 4 | $2 \times 1 + 2 = 4$ | $16 \times (4+4) = 128$ | $\{4\}$64、$\{1,4\}$16、$\{2,4\}$32、$\{1,2,4\}$16 |

合计 $1 + 12 + 128 = 141$ ✓。验算 $j=2$ 的 $W_2 = 4$：$\sum_{i<2} a_i 2^{1-i} = a_0 \cdot 2 + a_1 \cdot 1 = 2 + 2 = 4$ ✓。示例 2（$[1,1,1]$）：贡献 $1, 2, 4$，和为 $7$ ✓。

## 4. 算法细节

1. **排序是前提**：升序后"最小下标 = 值最小、最大下标 = 值最大"，$\min$/$\max$ 由下标边界直接读出；乱序处理则 $(i,j)$ 不再对应值界，整个拆分失效。
2. **重复值自动正确**：拆分按**下标**计（最小下标、最大下标），$[1,1,1]$ 的 7 个子集被 $i \le j$ 的 6 个下标对不重不漏地覆盖（$(0,1)$ 覆盖 $\{0,1\}$，$(0,2)$ 覆盖 $\{0,2\}$、$\{0,1,2\}$，等等）——不需要任何去重特判。
3. **$i = j$ 的单元素组**：$2^{j-i-1} = 2^{-1}$ 无意义，故公式里把单元素组单独拆成 $a_j$ 一项（即 $a_j^2 \cdot a_j = a_j^3$），不要硬套指数。
4. **取模纪律（C++）**：$a \le 10^9 < \text{MOD}$，故 $a \cdot a \le 10^{18}$ 在 `long long` 内安全；但**必须先 `a*a % MOD` 再乘第二个因子**——若写成 `a * a * ((a+w)%MOD)`，中间积可达 $10^{18} \times 10^9 = 10^{27}$ 直接溢出。每个乘号两侧都保持在 $10^{18}$ 以下。
5. **$W$ 的量级**：$W$ 是 $2$ 的幂加权和，模意义下滚动即可；先模后乘的顺序为 `(a*a%MOD) * ((a+W)%MOD) % MOD`。
6. **Python 无溢出**：大整数天然安全，但仍要对 $10^9+7$ 取模防超时（$10^5$ 个 $10^{27}$ 量级的数累加尚可，取模是规范做法）。

## 5. 正确性证明

**引理 1（按最小/最大下标的不重不漏拆分）**：任一非空下标子集 $S$ 唯一确定 $(i, j) = (\min S, \max S)$；反之，给定 $i \le j$，包含 $S$ 的选择恰为 $\{i, j\} \cup T$，$T$ 取遍 $\{i+1, \dots, j-1\}$ 的全部子集（$i = j$ 时 $T = \varnothing$ 且 $\{i,j\} = \{i\}$）。故以 $(i,j)$ 分类，子集族两两不交、并为全体非空子集，且第 $(i,j)$ 类恰含 $2^{j-i-1}$（$i<j$）或 $1$（$i=j$）个子集。

**证明**：$\min$ 与 $\max$ 是集合的确定函数，两类 $(i,j) \ne (i',j')$ 的子集其 $(\min, \max)$ 必不同，故不交；任何非空子集取自身 $(\min, \max)$ 归入对应类，故不漏。给定 $(i,j)$：$i \in S$ 与 $j \in S$ 是最小/最大下标的强制条件，严格介于两者之间的下标无任何约束，独立任选，共 $2^{j-i-1}$ 种；$i = j$ 时 $S = \{i\}$ 唯一 ∎

**引理 2（类内力量恒定）**：升序排序后，第 $(i,j)$ 类中每个子集的力量都等于 $a_j^2 \cdot a_i$（$i = j$ 时为 $a_i^3$）。

**证明**：类内任意子集 $S$ 含 $a_i$ 与 $a_j$ 且其余元素下标介于其间，排序保证 $a_i \le a_x \le a_j$ 对一切 $x \in S$ 成立，故 $\max S = a_j$、$\min S = a_i$（相等时亦然），力量 $= a_j^2 \cdot a_i$ 与 $T$ 的取法无关 ∎

**引理 3（递推的正确性）**：$W_0 = 0$，$W_j = \sum_{i<j} a_i \cdot 2^{j-1-i}$ 满足 $W_j = 2 W_{j-1} + a_{j-1}$。

**证明**：$W_j = \sum_{i<j-1} a_i 2^{j-1-i} + a_{j-1} 2^{0} = 2 \sum_{i<j-1} a_i 2^{j-2-i} + a_{j-1} = 2 W_{j-1} + a_{j-1}$；$W_0$ 显然为 $0$ ∎

**定理**：$\text{ans} = \sum_{j} a_j^2 \big(a_j + W_j\big) \bmod p$ 是所有非空英雄组的力量和。

**证明**：把引理 1 的分类按 $j$ 分桶：第 $j$ 桶的力量和 $= a_j^2 \cdot \big(\sum_{i<j} a_i \cdot 2^{j-i-1}\big) + a_j^2 \cdot a_j$（$i<j$ 各类加上 $i=j$ 的单元素类）。由引理 2 各类力量恒定，由引理 1 类数即 $2^{j-i-1}$ 与 $1$，故第 $j$ 桶和 $= a_j^2\,(W_j + a_j)$，其中 $W_j$ 由引理 3 逐项递推。桶间不重不漏（引理 1），求和即总力量；对 $p$ 取模保持同余 ∎

## 6. 复杂度分析

- **时间**：$O(n \log n)$，排序主导；扫描部分每个元素常数次乘加与取模，$O(n)$。$n = 10^5$ 时毫秒级。
- **空间**：$O(1)$ 额外（原地排序 + 两个滚动变量）；Python `sort` 为 $O(n)$ 辅助。

## 7. 参考代码

### C++

```cpp
class Solution {
    static constexpr long long MOD = 1e9 + 7;

   public:
    int sumOfPower(vector<int>& nums) {
        sort(nums.begin(), nums.end());
        long long ans = 0, w = 0;   // w = Σ_{i<j} a_i · 2^(j-1-i) (mod MOD)
        for (long long a : nums) {
            // 以 a 为最大值的组：a² · (Σ min)，min 部分聚合为 (a + w)
            ans = (ans + a % MOD * (a % MOD) % MOD * ((a + w) % MOD)) % MOD;
            w = (2 * w + a) % MOD;
        }
        return (int)ans;
    }
};
```

### Python

```python
class Solution:
    def sumOfPower(self, nums: List[int]) -> int:
        MOD = 10 ** 9 + 7
        nums.sort()
        ans = w = 0                      # w = Σ_{i<j} a_i · 2^(j-1-i) (mod MOD)
        for a in nums:
            # 以 a 为最大值的组：a² · (Σ min)，min 部分聚合为 (a + w)
            ans = (ans + a * a % MOD * ((a + w) % MOD)) % MOD
            w = (2 * w + a) % MOD
        return ans
```

> 💡 两份代码均通过官方示例（`141`、`7`）与"单元素 $10^9$"的大数取模边界，并与"枚举全部非空子集求 $\max^2 \cdot \min$"的暴力对拍 2511 组随机数据（$n \le 11$，含重复值、已排序、逆序、$10^9$ 值域），另有 $n = 10^5$ 满规模 C++/Python 一致性冒烟，`mismatch = 0`。

## 8. 边界情况与易错点

1. **取模顺序（C++ 唯一大坑）**：`a*a` 可达 $10^{18}$，安全；但若把表达式写成 `a*a*((a+w)%MOD)`，先算 `a*a` 与后因子相乘的中间积达 $10^{27}$ 溢出 `long long`。**必须每步乘完立刻 `% MOD`**，保证任一中间乘积两因子均 $< 10^9+7$（乘积 $< 10^{18.1}$）。
2. **单元素组是立方**：$i = j$ 时力量 $= a^3$，公式里体现在 $a_j^2 \cdot a_j$ 项；漏掉这一项所有答案都偏小。
3. **重复值不需要特判**：按下标拆分天然处理 $[1,1,1] \to 7$；若画蛇添足去重（当不同值算）会算错。
4. **排序方向**：必须**升序**——递推 $W_j = 2W_{j-1} + a_{j-1}$ 中"新的 $a_{j-1}$ 以指数 $0$ 入池、旧项全体翻倍"依赖从左到右值递增的语义。
5. **答案类型**：接口返回 `int`，C++ 累加器必须 `long long`（过程值最高 $10^{18}$ 量级），返回前一次性转换。
6. **负数不存在但别想当然**：约束保证 $1 \le nums[i]$，若值域含负数，$\max^2 \cdot \min$ 的符号处理与"排序后 $\min$ 位置"都要重新论证。
