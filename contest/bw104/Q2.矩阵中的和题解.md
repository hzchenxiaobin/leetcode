# LeetCode 矩阵中的和 题解

## 1. 题目概述

- **标题 / 题号**：矩阵中的和（#2679，medium）
- **链接**：https://leetcode.cn/problems/sum-in-a-matrix/
- **来源**：LeetCode 第 104 场双周赛 Q2
- **难度**：中等
- **标签**：数组、矩阵、排序、模拟、堆（优先队列）

**题意**：给定二维数组 `nums`，初始分数 $0$。重复以下操作直到矩阵为空：每一行删除其最大值（若有多个最大值任删一个）；在本次删除的所有数中取最大值加入分数。返回最终分数。

**约束**：

- $1 \le nums.length \le 300$
- $1 \le nums[i].length \le 500$
- $0 \le nums[i][j] \le 10^3$

## 2. 示例

**示例 1**

```text
输入：nums = [[7,2,1],[6,4,2],[6,5,3],[3,2,1]]
输出：15
解释：第一轮删 7,6,6,3，分数 +7；第二轮删 2,4,5,2，分数 +5；
      第三轮删 1,2,3,1，分数 +3。总分 7 + 5 + 3 = 15。
```

**示例 2**

```text
输入：nums = [[1]]
输出：1
解释：唯一一轮删掉 1，分数 +1。
```

**示例 3（边界补充）**

```text
输入：nums = [[5,5,5]]
输出：15
解释：同一行三个并列最大值被逐轮删除，每轮贡献 5，
      总分 5 + 5 + 5 = 15。
```

## 3. 解题思路

### 3.1 暴力思路

忠实模拟：每轮对每行取最大、删除，再对删除集合取最大累加——用堆（每行一个大根堆）实现是 $O(D \cdot m\log n)$，$D$ 为轮数（最长行的长度），总量约 $500 \times 300 \times \log 500 \approx 1.35 \times 10^6$，能过；朴素实现（每轮线性扫每行求最大再删）是 $O(D \cdot mn) \approx 4.5 \times 10^7$，C++ 也能过但难看。瓶颈在于"删谁、每轮谁最大"看起来必须逐轮计算——排序观察把这层模拟完全抹掉。

### 3.2 核心观察：第 j 轮删的就是每行第 j 大，行内顺序无关

![核心观察：每行排序后，第 j 轮删的恰是各行第 j 大的数，得分按“列”聚合](images/bw104_q2_sort_columns.svg)

每一行每轮删掉的都是"当前剩下的最大值"，且删除是逐轮进行的——所以**第 $j$ 轮里第 $i$ 行被删的数，恰是该行第 $j$ 大的数**，与删除过程中选了哪个并列最大值无关。而每行被删的数字集合（及其被删的轮次）只由这一行自己的多重集决定，与别的行毫无关系。

于是把每行降序排列成"第 $0$ 列最大、第 $j$ 列第 $j+1$ 大"的矩阵，则第 $j$ 轮的得分就是**第 $j$ 列的列最大值**：

$$\text{ans} = \sum_{j=0}^{\text{cols}-1} \max_i \text{nums}[i][j]$$

排序一次性把 $D$ 轮模拟压成一次"按列取最大求和"。

### 3.3 算法流程

![算法流程：行内升序排序 → 从末尾倒数第 j 个即第 j 大 → 逐列取最大累加](images/bw104_q2_algorithm_flow.svg)

```text
1. 对每一行升序排序（第 j 大 = row[len-1-j]）
2. cols = 最长行的长度
3. score = 0
4. for j = 0 .. cols-1:
5.     mx = 0
6.     for 每行 row：
7.         若 len(row) > j：mx = max(mx, row[len-1-j])
8.     score += mx
9. 返回 score
```

### 3.4 示例演算

![示例演算：四行排序后按列取最大 7、5、3，总分 15](images/bw104_q2_example_walkthrough.svg)

示例 1 各行升序排序后：

| 行（升序） | 第 1 大 | 第 2 大 | 第 3 大 |
|------------|---------|---------|---------|
| $[1,2,7]$ | **7** | 2 | 1 |
| $[2,4,6]$ | **6** | 4 | 2 |
| $[3,5,6]$ | **6** | **5** | 3 |
| $[1,2,3]$ | **3** | 2 | 1 |
| 列最大 | $7$ | $5$ | $3$ |

总分 $7 + 5 + 3 = 15$，与逐轮模拟完全一致。

## 4. 算法细节

1. **升序后第 $j$ 大的下标**：`row[row.size()-1-j]`（从末尾倒数第 $j+1$ 个）。降序排序则直接 `row[j]`，两者等价，写哪种都行但要统一。
2. **行内并列最大值不影响结论**：`[5,5,5]` 无论先删哪个 $5$，各轮删除值都是 $\{5,5,5\}$，排序版天然正确——因为"第 $j$ 大"对多重集而言是良定义的。
3. **行长不齐的处理**：约束不保证各行等长。短行提前耗尽后不再参与后续轮次，循环里加 `len(row) > j` 的判断即可；等长数据下该判断恒真，无额外开销。
4. **分数量级**：至多 $500$ 轮、每轮 $\le 10^3$，总分 $\le 5 \times 10^5$，`int` 足够（接口也是 `int`）；养成用 `long long` 累加的习惯更稳。
5. **堆实现作对照**：每行建大根堆，每轮弹出各堆顶取最大——正确性与排序版同源（都依赖"每行第 $j$ 轮删第 $j$ 大"），复杂度 $O(mn\log n)$ 略差、代码更长，比赛推荐排序版。
6. **复杂度瓶颈**：排序 $O(mn\log n)$ 主导；列扫描 $O(mn)$。也可按计数排序做到 $O(mn + V)$，值域 $10^3$ 时可选，但无必要。

## 5. 正确性证明

**引理 1（单行删除序列）**：第 $i$ 行在第 $j$ 轮被删除的数等于该行所有数中第 $j+1$ 大的数（多重集意义下，并列时任取其一）。

**证明**：对 $j$ 归纳。第 $0$ 轮删的是当前最大值，即第 $1$ 大 ✓。设前 $j$ 轮删除的依次是第 $1..j$ 大各一个，则剩余多重集恰为原多重集去掉前 $j$ 大，其最大值即第 $j+1$ 大，故第 $j$ 轮删第 $j+1$ 大，归纳成立。删除最大值时"任选一个并列者"只影响多重集内部哪个副本被移走，多重集本身不变 ∎

**引理 2（行间独立）**：任意一行的删除时刻表只由该行自身的多重集决定；各轮"删除集合中的最大值"等于"各行第 $j+1$ 大"这组数的最大值。

**证明**：操作规则对每行独立执行（每行各删一个），删除互不干涉，由引理 1 第 $j$ 轮的删除集合恰为 $\{\text{第 } i \text{ 行的第 } j{+}1 \text{ 大} : i \text{ 行仍非空}\}$；其最大值即该轮得分。短行耗尽后不再贡献，等价于"该行第 $j+1$ 大不存在"，不影响 max 的正确性 ∎

**定理**：$\text{ans} = \sum_{j \ge 0} \max_i (\text{第 } i \text{ 行的第 } j{+}1 \text{ 大})$，排序后按列取最大求和即得。

**证明**：轮数 $D$ 等于最长行的长度，$j \ge D$ 时所有行都已为空、矩阵已空，过程终止；对 $0 \le j < D$，由引理 2 第 $j$ 轮得分恰为各行第 $j+1$ 大的最大值。行升序排序后第 $j+1$ 大位于 `row[len-1-j]`（行长 $\le j+1$ 的行不参与），故算法逐列取最大求和逐轮匹配模拟结果，矩阵清空即求和完毕 ∎

## 6. 复杂度分析

- **时间**：$O(mn \log n)$。每行排序总计对 $mn$ 个数各做 $O(\log n)$ 次比较；列扫描再 $O(mn)$。$m \le 300,\ n \le 500$ 时约 $1.35 \times 10^6$ 次比较，毫秒级。
- **空间**：$O(1)$ 额外——行内原地排序；若不允许改输入则需复制 $O(mn)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int matrixSum(vector<vector<int>>& nums) {
        for (auto& row : nums) sort(row.begin(), row.end());
        int cols = 0;
        for (const auto& row : nums) cols = max(cols, (int)row.size());
        long long score = 0;
        for (int j = 0; j < cols; ++j) {           // 第 j 轮：各行第 j 大的数
            int mx = 0;
            for (const auto& row : nums)
                if ((int)row.size() > j) mx = max(mx, row[row.size() - 1 - j]);
            score += mx;
        }
        return (int)score;
    }
};
```

### Python

```python
class Solution:
    def matrixSum(self, nums: List[List[int]]) -> int:
        for row in nums:
            row.sort()
        cols = max(len(row) for row in nums)
        score = 0
        for j in range(cols):                     # 第 j 轮：各行第 j 大的数
            mx = 0
            for row in nums:
                if len(row) > j:
                    mx = max(mx, row[len(row) - 1 - j])
            score += mx
        return score
```

> 💡 两份代码均通过官方示例（`15`、`1`）与"单行全并列最大值"边界，并与"每轮真实删除再取最大"的逐轮模拟暴力对拍 3009 组随机数据（含不等行长、全 0、单行单列），另有 $300 \times 500$ 满规模 C++/Python 一致性冒烟，`mismatch = 0`。

## 8. 边界情况与易错点

1. **`[[1]]` 单格矩阵**：一轮结束，`cols = 1`，返回该值本身。
2. **行内并列最大值**：`[5,5,5]` 的删除值是三个 $5$ 而不是"一个 5 删完就没了"——排序版自动正确，但写堆版时若误用"set 去重"就会错。
3. **行长不齐**：短行耗尽即退出后续轮次，`len(row) > j` 的判断不能省（虽然本题官方数据可能等长，约束未保证）。
4. **下标方向**：升序排序后第 $j$ 大在**末尾倒数**，`row[len-1-j]`；写成 `row[j]` 会把"第 $j$ 大"算成"第 $j$ 小"，样例 1 立刻露馅（得 1+2+3=6 ≠ 15）。
5. **别真去逐轮删除**：$O(mn)$ 朴素模拟虽也能过，但把"每轮删第 $j$ 大"的洞察漏掉，本题就白考了。
6. **`mx` 初值 0**：值域非负（$0 \le nums[i][j]$），以 $0$ 为哨兵安全；若值域含负数应初始化为极小值（本题不会发生）。
