# LeetCode 老人的数目 题解

## 1. 题目概述

- **标题 / 题号**：老人的数目（#2678，easy）
- **链接**：https://leetcode.cn/problems/number-of-senior-citizens/
- **来源**：LeetCode 第 104 场双周赛 Q1
- **难度**：简单
- **标签**：数组、字符串

**题意**：给定字符串数组 `details`，每个元素是长度 $15$ 的定长编码，自左向右依次为：手机号码（$10$ 位）、性别（$1$ 位，`M`/`F`/`O`）、年龄（$2$ 位）、座位号（$2$ 位）。统计年龄**严格大于 $60$** 的乘客数。

**约束**：

- $1 \le details.length \le 100$
- $details[i].length = 15$
- 编码中仅含数字字符；$details[i][10] \in \{M, F, O\}$
- 手机号码与座位号互不相同（对本题无用）

## 2. 示例

**示例 1**

```text
输入：details = ["7868190130M7522","5303914400F9211","9273338290F4010"]
输出：2
解释：三位乘客的年龄分别为 75、92、40，前两人超过 60 岁。
```

**示例 2**

```text
输入：details = ["1313579440F2036","2921522980M5644"]
输出：0
解释：年龄 20 与 56，均不超过 60。
```

**示例 3（边界补充）**

```text
输入：details = ["1234567890M6001"]
输出：0
解释：年龄恰好 60，必须“严格大于”才算，输出 0。
```

## 3. 解题思路

### 3.1 暴力思路

本题没有复杂度可言——每条记录独立判定，难点只在**把年龄两位数从定长编码的固定位置抠出来**。最朴素的做法是逐字符拼：取出 `s[11]`、`s[12]` 两个字符，按十进制位权重组 $\text{age} = 10 \cdot (s[11] - '0') + (s[12] - '0')$；或者直接用语言自带的切片 `int(s[11:13])`。两者完全等价，剩下的就是一遍计数。

### 3.2 核心观察：定长编码 + 严格大于

![核心观察：15 位定长编码的解剖，年龄占下标 11、12 两位](images/bw104_q1_string_layout.svg)

记录是**定长**的，所有字段位置全局固定：下标 $0..9$ 是手机号，$10$ 是性别，$11..12$ 是年龄，$13..14$ 是座位号。于是年龄不需要任何解析逻辑，直接按位取：

$$\text{age} = (s[11] - '0') \times 10 + (s[12] - '0')$$

判定条件是 $\text{age} > 60$，**严格大于**——`"60"` 不算。一个有用的细节：两位十进制数的大小比较与字符串字典序一致，所以 `s[11:13] > "60"` 是等价写法，连数值转换都可以省掉。

### 3.3 算法流程

![算法流程：遍历每条记录 → 切出下标 11、12 两位 → 数值化与 60 比较 → 计数](images/bw104_q1_age_judge.svg)

```text
1. cnt = 0
2. for s in details:
3.     age = (s[11]-'0')*10 + (s[12]-'0')
4.     若 age > 60：cnt += 1
5. 返回 cnt
```

### 3.4 示例演算

以 `"7868190130M7522"` 为例：

| 下标段 | 内容 | 含义 |
|--------|------|------|
| $0..9$ | `7868190130` | 手机号 |
| $10$ | `M` | 性别 |
| $11..12$ | `75` | 年龄 $= 7 \times 10 + 5 = 75 > 60$ ✓ |
| $13..14$ | `22` | 座位号 |

三条记录依次判 $75$ ✓、$92$ ✓、$40$ ✗，共 $2$ 人。

## 4. 算法细节

1. **下标从 0 数**：年龄在 $11..12$，不是 $10..11$——下标 $10$ 是性别位，这是本题唯一能踩的坑。
2. **字符转数字**：C++ 用 `(s[11]-'0')*10 + (s[12]-'0')`；Python 直接 `int(s[11:13])` 更顺手，切片是左闭右开，`[11:13]` 恰取两位。
3. **严格大于**：$60$ 本身不计数；若把条件写成 `>= 61` 与 `> 60` 等价，但 `>= 60` 是错的。
4. **年龄上界**：两位数最大 $99$，`int` 完全无压力。
5. **无效信息直接忽略**：手机号、座位号的唯一性约束对本题毫无作用，比赛时别被"互不相同"之类的字眼带偏。

## 5. 正确性证明

**引理 1（切片等价性）**：对任意由两个数字字符组成的串 $s_{11}s_{12}$，$10(s_{11}-'0') + (s_{12}-'0')$ 等于其数值；且两位十进制串的字典序与数值序一致，即 $s_{11}s_{12} > $ `"60"` 当且仅当数值 $> 60$。

**证明**：十进制的位权展开即得数值。字典序：两位数字串按最高位（十位）先比、个位后比，与数值比较的顺序一致 ∎

**定理**：算法返回年龄严格大于 $60$ 的乘客数。

**证明**：每条记录定长 $15$，由编码规则年龄恰在 $11..12$（题面给定）。由引理 1，步骤 3 求得的 `age` 即该乘客年龄，步骤 4 的判定与"年龄 $> 60$"等价；各记录相互独立，计数互不影响，遍历全部记录后 `cnt` 即满足条件的总数 ∎

## 6. 复杂度分析

- **时间**：$O(L \cdot n)$，其中 $L = 15$ 为记录长度、$n$ 为记录数——每条记录只看两个字符。
- **空间**：$O(1)$，只用一个计数器。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int countSeniors(vector<string>& details) {
        int cnt = 0;
        for (const string& s : details)
            if ((s[11] - '0') * 10 + (s[12] - '0') > 60) ++cnt;
        return cnt;
    }
};
```

### Python

```python
class Solution:
    def countSeniors(self, details: List[str]) -> int:
        return sum(1 for s in details if int(s[11:13]) > 60)
```

> 💡 两份代码均通过官方示例（`2`、`0`）与"年龄恰为 60"的边界，并与"字典序比较两位年龄串"的独立判定法对拍 2007 组随机数据（含 $59/60/61/99$ 构造年龄），`mismatch = 0`。

## 8. 边界情况与易错点

1. **严格大于 $60$**：`"60"` 不算老人；边界测试必须含一个恰好 $60$ 的记录。
2. **下标 11 而不是 10**：性别占下标 $10$；把年龄取成 $s[10..11]$ 会把性别字符卷进来，C++ 里 `'M'-'0'` 直接得到垃圾数值。
3. **别用 `stoi` 切整串**：`stoi(s)` 会对手机号码转数值，与年龄无关；转年龄必须先切再转。
4. **`details[i].length == 15` 是硬保证**：可以放心用定长下标，不必做长度防御。
5. **年龄两位含前导零**：如 `"07"`——`int("07") = 7`、`(s[11]-'0')*10+... = 7`，两种写法都正确处理。
