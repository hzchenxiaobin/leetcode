# LeetCode 形成目标字符串需要的最少字符串数 I 题解

## 1. 题目概述

- **标题 / 题号**：形成目标字符串需要的最少字符串数 I（#3291，medium）
- **链接**：https://leetcode.cn/problems/minimum-number-of-valid-strings-to-form-target-i/
- **来源**：LeetCode 第 415 场周赛 Q3
- **难度**：中等
- **标签**：字典树（Trie）、动态规划、字符串、跳跃游戏模型

**题意**：给定字符串数组 `words` 与字符串 `target`。若 $x$ 是 `words` 中**任意**一个字符串的**前缀**（长度 $\ge 1$），则 $x$ 是「有效字符串」。有效字符串可**重复取用**，要求用尽可能少的有效字符串首尾相接拼成 `target`，返回最少段数；拼不出返回 $-1$。

**约束**：

- $1 \le \text{words.length} \le 100$，$1 \le \text{words[i].length} \le 5 \times 10^3$，$\sum \text{words[i].length} \le 10^5$
- $1 \le \text{target.length} \le 5 \times 10^3$，`words[i]` 与 `target` 只含小写字母

> 💡 读题抓三个信号：① 「前缀」而非「整词」——有效集合是所有 word 的所有前缀，总规模 $\le 10^5$，正好能被一棵 Trie 装下；② 「拼接 + 最少段数」是**线性 DP**（单词拆分 LC 139 家族），且「前缀取任意长度」让转移变成一段**区间**——即跳跃游戏 II 模型；③ 无解要返回 $-1$，DP 哨兵必须能区分「可达」与「不可达」。

## 2. 示例

**示例 1**

```text
输入：words = ["abc","aaaaa","bcdef"], target = "aabcdabc"
输出：3
解释："aa"（aaaaa 的前缀）+ "bcd"（bcdef 的前缀）+ "abc"（abc 的前缀）。
```

**示例 2**

```text
输入：words = ["abababab","ab"], target = "ababaababa"
输出：2
解释："ababa" + "ababa"，同一段可重复取用。
```

**示例 3**

```text
输入：words = ["abcdef"], target = "xyz"
输出：-1
解释：所有 word 前缀都以 'a' 开头，target 首字符即无解。
```

## 3. 解题思路

### 3.1 暴力思路

朴素线性 DP：设 $dp[i]$ = 覆盖 $target[0..i)$ 的最少段数，$dp[0] = 0$，

$$dp[j] = \min\{\, dp[i] + 1 \;:\; i < j,\ \ target[i..j)\ \text{是有效字符串} \,\}$$

瓶颈在**有效性判定**：`target[i..j)` 有效 ⟺ 它与某个 word 的前 $\ell = j - i$ 个字符逐位相等。逐对检查每次 $O(n)$（遍历 words、逐字符比较），转移对数 $O(n^2)$，总量 $\approx 1.25 \times 10^{11}$，不可行。

### 3.2 核心观察一：Trie 一次遍历，批量判定一个起点的所有前缀

![Trie：路径存在即有效前缀，失配即停](images/min_valid_strings_trie_concept.svg)

把所有 `words` 插入一棵 Trie，有两个关键性质：

- **性质 A（不需要 isEnd）**：Trie 中深度为 $d$ 的节点**存在**，当且仅当它是某个 word 的长度为 $d$ 的前缀——插入操作只为「真实前缀」创建节点。因此「`target[i..j)` 有效」⟺「从根沿这条子串走下去路径存在」，**全程无需词尾标记**（与 LC 208 的习惯正好相反）。
- **性质 B（前缀封闭性）**：若 `target[i..i+ℓ)` 有效，则长度 $1 \sim \ell-1$ 的截断全部有效（前缀的前缀仍是前缀）。所以**从固定起点 $i$ 出发沿 Trie 走一遍**，途经的每个节点都贡献一个有效长度，直到失配或走到串尾。

于是单个起点的匹配代价从 $O(n \cdot \ell)$ 降为 $O(\mathrm{mn}[i])$（$\mathrm{mn}[i]$ = 从 $i$ 出发的最长匹配长度），全部起点合计 $O(n \cdot L)$，其中 $L = \min(\text{最长 word 长度},\ n) \le 5000$，至多 $2.5 \times 10^7$ 步。

### 3.3 核心观察二：问题 = 带区间转移的「跳跃游戏 II」

![mn 数组与跳跃游戏 II 模型](images/min_valid_strings_jump_game.svg)

由性质 B，从 $i$ 开始的一段可以把**下一段的起点**推到 $[i+1,\ i+\mathrm{mn}[i]]$ 中的任意位置。求最少段数走到 $n$——这正是 [45. 跳跃游戏 II](https://leetcode.cn/problems/jump-game-ii/) 的模型：站在位置 $i$ 可跳到区间内任一点，求到达 $n$ 的最少步数。

> ⚠️ **「每步贪心取最长匹配」是错的**。反例：`words = ["abc","cdef"]`, `target = "abcdef"`：贪心第 0 段取最长 "abc" 落在位置 3，而 "def…" 无任何匹配（死点），返回 $-1$；最优解是 "ab" + "cdef" 共 **2** 段。跳跃游戏 II 的正确姿势是 **BFS 分层**（维护当前层边界与下一层最远边界）或等价的区间 DP——本题 $n$ 只有 5000，直接写 DP 最省事，模型与 LC 45 完全同构。

### 3.4 示例演算

![示例 1 走查：逐起点沿 Trie 更新 dp](images/min_valid_strings_walkthrough.svg)

以示例 1（`words = ["abc","aaaaa","bcdef"]`, `target = "aabcdabc"`）走查（「死点」= $\mathrm{mn} = 0$ 的位置）：

| 起点 $i$ | target[i] | $\mathrm{mn}[i]$ | 匹配到的前缀 | 更新动作 |
|---|---|---|---|---|
| 0 | a | 2 | a, aa | $dp[1] = dp[2] = 1$ |
| 1 | a | 3 | a, ab, abc | $dp[3] = dp[4] = 2$ |
| 2 | b | 3 | b, bc, bcd | $dp[5] = 2$（$dp[3], dp[4]$ 不变） |
| 3 | c | 0 | — | 死点：$dp[3] = 2$ 可达却无法延伸 |
| 4 | d | 0 | — | 死点 |
| 5 | a | 3 | a, ab, abc | $dp[6] = dp[7] = dp[8] = 3$ |
| 6 | b | 2 | b, bc | $dp[7], dp[8]$ 已是 3，不更新 |
| 7 | c | 0 | — | 死点 |

最终 $dp = [0,1,1,2,2,2,3,3,3]$，答案 $dp[8] = \mathbf{3}$，对应划分 `aa | bcd | abc`。注意**位置 3、4 的 dp 值有限却是死点**——最优路径绕开了它们，这正是朴素贪心会翻车、区间 DP 必不可少的原因。

## 4. 算法细节

1. **Trie 的数组实现**：`ch[v][c]` 存孩子编号，节点 $0$ 为根、编号 $0$ 兼作「无边」哨兵（新节点编号从 1 起自增，天然不冲突）。总节点数 $\le \sum|word| + 1 \le 10^5 + 1$。
2. **不要 isEnd**：有效字符串是**前缀**，Trie 路径存在即有效；误加「词尾才算」的判断会把 `aa`、`bcd` 这类非整词前缀判为无效（见 §8 第 1 条）。
3. **DP 主循环（升序拓扑序）**：按 $i = 0 \to n-1$ 处理，转移只指向更大的下标，处理 $i$ 时 $dp[i]$ 已定型。内层从根沿 `target[i..]` 走 Trie，每走一步更新 $dp[j+1] \gets \min(dp[j+1],\ dp[i]+1)$，失配即 `break`。
4. **剪枝**：$dp[i] = \infty$（该前缀不可达）时直接跳过——从不可达起点出发的匹配纯属浪费（示例 3 里位置 1 起全被跳过）。
5. **哨兵值**：C++ 取 $10^9$（远离真值上界 $n \le 5000$），Python 用 `float("inf")`。
6. **内联 vs 显式 mn 数组**：代码把「匹配」与「转移」内联在一次双循环里；也可先算出整个 $\mathrm{mn}[]$ 数组、再跑一遍跳跃游戏 II 的分层贪心（$O(n)$），二者完全等价。Q4（II 版）必须走后者的优化路线。

## 5. 正确性证明

**引理 1（Trie 判定的正确性）**：对任意字符串 $s$：$s$ 是 `words` 中某字符串的前缀 ⟺ Trie 中从根沿 $s$ 的路径存在。

**证明**：Trie 的节点仅在插入 word 时被创建。深度为 $d$ 的节点 $v$ 存在 ⟺ 插入某个 $w$ 时创建了 $v$ ⟺ $w$ 的前 $d$ 个字符恰为根到 $v$ 的路径上的字符。故「路径存在」⟺「存在 $w$ 使 $s$ 等于 $w$ 的前 $d$ 个字符」⟺ $s$ 是某 word 的前缀。∎

**引理 2（转移方程）**：设 $OPT(i)$ 为覆盖 `target` 前 $i$ 个字符所需的最少段数（不可达记 $+\infty$），则 $OPT(0) = 0$，且对 $j \ge 1$：

$$OPT(j) = \min\Bigl(\;\min_{\substack{i<j \\ target[i..j)\ \text{有效}}}\bigl(OPT(i)+1\bigr)\;\Bigr)$$

**证明**：任一覆盖前 $j$ 个字符的方案按段切分，最后一段恰为 $target[i..j)$（某 $i < j$ 且该段有效）；去掉它得到一个覆盖前 $i$ 个字符的方案，故 $OPT(j) \ge OPT(i)+1$ 对该 $i$ 成立，从而 $OPT(j)$ 不小于右边。反之，把覆盖前 $i$ 个字符的方案（段数 $OPT(i)$）拼上有效段 $target[i..j)$ 得到覆盖前 $j$ 个字符的方案，故对每个可行 $i$ 有 $OPT(j) \le OPT(i)+1$，取 $\min$ 得 $OPT(j)$ 不大于右边。∎

**定理**：算法结束时 $dp[n] = OPT(n)$；特别地，$dp[n] = \infty$ ⟺ 无解。

**证明**：对 $t = 0, 1, \dots, n$ 归纳证明「处理完位置 $0..t-1$ 后 $dp[t]$ 已定型且等于 $OPT(t)$」。

- **可达下界（$dp[t] \ge OPT(t)$）**：对更新次数归纳。$dp[0] = 0$ 对应空方案。每次更新形如 $dp[j+1] \gets dp[i]+1$：若 $dp[i]$ 对应真实方案（归纳假设），由引理 1，Trie 途经的深度 $j+1-i$ 的节点对应的段是有效字符串，拼上去仍是真实方案，故 $dp[j+1]$ 的每个有限值都不小于某个真实方案的段数 $\ge OPT(j+1)$。
- **最优上界（$dp[t] \le OPT(t)$）**：取 $OPT(t)$ 的一个最优方案，设其最后一段为 $target[i^*..t)$（$i^* < t$，有效），则 $OPT(t) = OPT(i^*) + 1$。由归纳假设，处理位置 $i^*$ 时 $dp[i^*] = OPT(i^*)$ 已定型。又由引理 1，从根沿 $target[i^*..]$ 的路径存在，深度 $t - i^*$ 的节点必在失配**之前**的路径上（性质 B：路径无空洞），故算法执行了 $dp[t] \gets \min(dp[t],\ dp[i^*]+1)$，得 $dp[t] \le OPT(i^*) + 1 = OPT(t)$。

两个方向合并得 $dp[t] = OPT(t)$，取 $t = n$ 即得结论；$dp[n] = \infty$ 时由可达下界知不存在任何方案，返回 $-1$ 正确。∎

> 💡 证明中「深度 $t-i^*$ 的节点必被走到」正是性质 B 的价值：有效长度没有空洞，内层循环不会中途 break 掉更长的有效段。

## 6. 复杂度分析

- **时间复杂度**：$O\bigl(S + n \cdot \min(n, L_{\max})\bigr)$，$S = \sum|\text{word}| \le 10^5$。建 Trie 逐字符 $O(S)$；DP 双循环中每个起点 $i$ 至多走 $\min(n - i,\ \text{Trie 深度})$ 步，最坏 $n^2 = 2.5 \times 10^7$ 次数组访问，轻松通过。
- **空间复杂度**：数组版 Trie $O(26S) \approx 2.6 \times 10^6$ 个 `int`（约 10 MB）；`dp` 数组 $O(n)$。若用孩子哈希表实现可压到 $O(S)$，代价是常数稍大。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int minValidStrings(vector<string>& words, string target) {
        int n = target.size();
        vector<array<int, 26>> ch = {array<int, 26>{}};   // 节点 0 为根，0 表示无边
        for (const string& w : words) {
            int v = 0;
            for (char c : w) {
                int k = c - 'a';
                if (ch[v][k] == 0) {
                    ch[v][k] = ch.size();
                    ch.push_back({});
                }
                v = ch[v][k];
            }
        }
        const int INF = 1e9;
        vector<int> dp(n + 1, INF);
        dp[0] = 0;
        for (int i = 0; i < n; i++) {
            if (dp[i] == INF) continue;   // 不可达起点：匹配是浪费
            int v = 0;
            for (int j = i; j < n; j++) {
                v = ch[v][target[j] - 'a'];
                if (v == 0) break;        // 失配即停
                dp[j + 1] = min(dp[j + 1], dp[i] + 1);
            }
        }
        return dp[n] == INF ? -1 : dp[n];
    }
};
```

### Python

```python
class Solution:
    def minValidStrings(self, words: List[str], target: str) -> int:
        n = len(target)
        ch = [[0] * 26]                    # 节点 0 为根，0 表示无边
        for w in words:
            v = 0
            for c in w:
                k = ord(c) - 97
                if ch[v][k] == 0:
                    ch[v][k] = len(ch)
                    ch.append([0] * 26)
                v = ch[v][k]
        INF = float("inf")
        dp = [INF] * (n + 1)
        dp[0] = 0
        for i in range(n):
            if dp[i] == INF:
                continue
            base = dp[i] + 1
            v = 0
            for j in range(i, n):
                v = ch[v][ord(target[j]) - 97]
                if v == 0:
                    break
                if base < dp[j + 1]:
                    dp[j + 1] = base
        return -1 if dp[n] == INF else dp[n]
```

## 8. 边界情况与易错点

1. **「前缀」≠「整词」**：有效判定不需要 isEnd。带着 LC 139 单词拆分的肌肉记忆去标记词尾，会把示例 1 的 "aa"、"bcd" 判成无效——答案从 3 直接变 $-1$。
2. **贪心取最长匹配必错**：见 §3.3 反例（`["abc","cdef"]` / `"abcdef"`，贪心得 $-1$，最优为 2）。若要贪心，必须用跳跃游戏 II 的**分层 BFS**（维护层边界），不是「每步跳最远」。
3. **死点**：$dp[i]$ 有限不代表位置 $i$ 能继续延伸（示例 1 的位置 3、4），最终只看 $dp[n]$。
4. **处理顺序**：必须按起点升序转移（DAG 拓扑序）；倒序枚举 $i$ 会读到未定型的 $dp$ 值。
5. **不可达剪枝**：$dp[i] = \infty$ 时跳过整段匹配，最坏情形能省下大量无效 Trie 行走。
6. **word 互为前缀 / 重复**：Trie 自动共享路径，插入幂等，无需去重。
7. **匹配长度上界**：单个 word 可长达约 $10^5$，但内层被 $n$ 截断，匹配总量只有 $O(n^2)$，不会退化成 $O(nS)$。
8. **哨兵取值**：C++ 用 $10^9$ 而非 `INT_MAX`，防御 `dp[i] + 1` 溢出（本题有剪枝守卫，一般碰不到，但换个写法就可能踩雷）。
