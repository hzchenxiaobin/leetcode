# LeetCode 数字小镇中的捣蛋鬼 题解

## 1. 题目概述

- **标题 / 题号**：数字小镇中的捣蛋鬼（#3289，easy）
- **链接**：https://leetcode.cn/problems/the-two-sneaky-numbers-of-digitville/
- **来源**：LeetCode 第 415 场周赛 Q1
- **难度**：简单
- **标签**：数组、哈希表、数学

**题意**：数字小镇 Digitville 的列表 `nums` 本应包含 $0 \sim n-1$ 的每个整数**恰好一次**，但有两个「捣蛋鬼」数字各自**多出现了一次**（各出现两次），使列表长度变为 $n+2$。请找出这两个数字，返回一个长度为 2 的数组，**顺序任意**。

**约束**：

- `2 <= n <= 100`
- `nums.length == n + 2`
- `0 <= nums[i] < n`
- 输入保证 `nums` 中**恰好**包含两个重复的元素

> 💡 读题抓三个信号：① 参数里没有 $n$，由 `nums.length == n + 2` 反解 $n = \mathrm{len}(\text{nums}) - 2$；② 值域 $0 \sim n-1$ 连续且有界；③ 除两个捣蛋鬼各出现两次外，其余数字恰好出现一次、一个不缺——这是所有解法成立的结构前提。

## 2. 示例

**示例 1**

```text
输入：nums = [0,1,1,0]
输出：[0,1]
解释：数字 0 和 1 分别在数组中出现了两次。
```

**示例 2**

```text
输入：nums = [0,3,2,1,3,2]
输出：[2,3]
解释：数字 2 和 3 分别在数组中出现了两次。
```

**示例 3**

```text
输入：nums = [7,1,5,4,3,4,6,0,9,5,8,2]
输出：[4,5]
解释：数字 4 和 5 分别在数组中出现了两次。
```

## 3. 解题思路

### 3.1 暴力思路

排序后相同值必然相邻，扫一遍收集相邻相等对，$O(n \log n)$；或对每个位置向后找相同值，$O(n^2)$。在 $n \le 100$ 下都能过，签到不卡常。但「找重复」本质只关心**每个值出现了几次**，为此付出一次排序方向绕远了——更短的通路是直接沿「出现次数」建统计。

### 3.2 核心观察：值域即下标，边数边收

![快速切入：题面特征 → 计数数组](images/sneaky_read_to_algo.svg)

- **观察 1（值域连续有界）**：所有值都落在 $0 \sim n-1$，而 $n$ 又能从数组长度反解。开一个长度为 $n$ 的计数数组 `cnt`，**下标本身就是值**——不需要哈希函数、不存在冲突、无需扩容。值域已知且不大时，桶计数完胜泛型哈希表。
- **观察 2（恰两次 → 到 2 即收）**：普通数字的计数到 1 封顶；计数一旦涨到 2，撞上的必然是捣蛋鬼的**第二次露面**。于是 `++cnt[v] == 2` 成立的瞬间就地收集，连第二遍扫描都省了。
- **观察 3（下标安全）**：$0 \le \text{nums[i]} < n < n + 2 = \mathrm{len}(\text{nums})$，任何值作为 `cnt` 的下标都不会越界，无需额外检查。

### 3.3 算法流程

![算法流程：一遍扫描，边数边收](images/sneaky_count_flow.svg)

单循环主链：取出元素 $v$ → `cnt[v]` 自增 → 是否恰为 2 → 是则收集、继续扫描；元素取尽时 `ans` 里恰好装着两个捣蛋鬼，返回即可。

### 3.4 示例演算

![示例演算：cnt 数组的逐步变化](images/sneaky_example_walkthrough.svg)

以示例 2（`nums = [0,3,2,1,3,2]`，$n = 4$）走表：

| $i$ | $v$ | `cnt`（下标 0..3） | 触发 | `ans` |
|-----|-----|--------------------|------|-------|
| 0 | 0 | `[1,0,0,0]` | — | `[]` |
| 1 | 3 | `[1,0,0,1]` | — | `[]` |
| 2 | 2 | `[1,0,1,1]` | — | `[]` |
| 3 | 1 | `[1,1,1,1]` | — | `[]` |
| 4 | 3 | `[1,1,1,2]` | `cnt[3]` 到 2 ✓ | `[3]` |
| 5 | 2 | `[1,1,2,2]` | `cnt[2]` 到 2 ✓ | `[3,2]` |

前 4 步 `cnt` 被均匀填成全 1（每个数字都露过面了）；后 2 步是「第二次露面」的专享时刻——两个捣蛋鬼就此落网。

## 4. 算法细节

1. **反解 $n$**：$n = \mathrm{len}(\text{nums}) - 2$。别把桶开成 `len(nums)` 大小——本题因值域更小侥幸不越界，但浪费空间且语义错位。
2. **计数数组 vs 哈希表**：值域 $0 \sim n-1$ 已知且不大时优先桶——`vector<int>` / Python 列表比 `unordered_map` / `Counter` 常数小、缓存友好，是竞赛签到的稳定选择。
3. **边数边收**：`++cnt[v] == 2` 的判定与收集在同一趟完成；也可写成两遍扫描（先全量计数，再筛 `cnt[v] == 2`），对本题二者等价。
4. **备选：数学法 $O(1)$ 空间**。设捣蛋鬼为 $x, y$（$x \ne y$），与期望序列 $0 \sim n-1$ 的和、平方和作差，多出的部分全部来自 $x, y$：

$$a = x + y = \sum_{v \in \text{nums}} v - \frac{n(n-1)}{2}, \qquad b = x^2 + y^2 = \sum_{v \in \text{nums}} v^2 - \frac{n(n-1)(2n-1)}{6}$$

由 $(x-y)^2 = 2(x^2+y^2) - (x+y)^2 = 2b - a^2$ 得 $|x-y| = \sqrt{2b - a^2}$，与 $x + y = a$ 联立即解出：

$$x = \frac{a + \sqrt{2b - a^2}}{2}, \qquad y = \frac{a - \sqrt{2b - a^2}}{2}$$

竞赛视角：计数法代码量最小、最不易错，Q1 首选；数学法留给「不许额外空间」的追问。

## 5. 正确性证明

**引理 1（出现次数结构）**：`nums` 中恰有两个值各出现两次，其余 $n-2$ 个值各出现一次，且两个捣蛋鬼互异。

**证明**：`nums` 本应包含 $0 \sim n-1$ 各一次（长度 $n$），实际长度 $n+2$，多出的 2 个位置由「各多出现一次」的两个数字填补。若某数字多出现不止一次，或捣蛋鬼不止两个，则与题面「恰好包含两个重复的元素」矛盾；若两个捣蛋鬼相同，该数将出现三次，与「两个数字**各自**多出现一次」矛盾。∎

**引理 2（判定等价）**：一遍扫描中 `++cnt[v] == 2` 成立，当且仅当 $v$ 是捣蛋鬼且当前是它的第二次出现。

**证明**：由引理 1，捣蛋鬼 $v$ 恰出现两次：第一次访问使 `cnt[v]` 从 0 到 1，第二次从 1 到 2，此后不再出现；非捣蛋鬼仅出现一次，自增结果恒为 1，永不等于 2。∎

**定理**：算法返回的 `ans` 恰为两个捣蛋鬼组成的长度为 2 的数组。

**证明**：由引理 2，收集仅在「捣蛋鬼第二次出现」事件上触发；由引理 1，这样的事件恰有两次（$x$、$y$ 各一次），故扫描结束时 `ans` 长度为 2 且元素恰为 $x, y$（顺序为第二次露面的先后）。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。$n+2$ 个元素各一次 $O(1)$ 的计数与判定；读入即 $\Omega(n)$ 下界，一遍扫描已达最优。
- **空间复杂度**：$O(n)$。计数数组长为 $n$（不计输出数组）；若改用数学法可降至 $O(1)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> getSneakyNumbers(vector<int>& nums) {
        int n = (int)nums.size() - 2;
        vector<int> cnt(n, 0), ans;
        for (int v : nums) {
            if (++cnt[v] == 2) {
                ans.push_back(v);
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def getSneakyNumbers(self, nums: List[int]) -> List[int]:
        n = len(nums) - 2
        cnt = [0] * n
        ans = []
        for v in nums:
            cnt[v] += 1
            if cnt[v] == 2:
                ans.append(v)
        return ans
```

## 8. 边界情况与易错点

1. **$n$ 不在参数里**：必须 `n = len(nums) - 2` 反解；把桶开成 `len(nums)` 是常见笔误（本题侥幸不越界，但语义已偏）。
2. **捣蛋鬼可以是 0**：计数法完全无影响；但若迁移到 442 式「取负原地标记」，$-0 = 0$ 会让标记静默失效，须改用 $+n$ 偏移。
3. **最小规模 $n = 2$**：`nums` 长度 4，0 与 1 各出现两次，答案必为 `[0,1]`，算法自然覆盖。
4. **捣蛋鬼早早露面**：如示例 1 `[0,1,1,0]`，前 4 步内就收满——边数边收不依赖「扫完再筛」，天然处理任何出现顺序。
5. **答案顺序任意**：按第二次露面顺序返回即可，无需排序（判题不接受特定顺序时才需 `sort`）。
6. **数学法的平方和溢出**：$n \le 100$ 时 $\sum v^2 \lesssim 10^6$，`int` 足够；迁移到大值域变体（如 645 类）必须换 64 位，这是数学法最常见翻车点。
