# LeetCode 重复叠加字符串匹配 题解

## 1. 题目概述

- **标题 / 题号**：重复叠加字符串匹配（#686，medium）
- **链接**：https://leetcode.cn/problems/repeated-string-match/
- **来源**：LeetCode 第 52 场周赛 Q1
- **难度**：中等
- **标签**：字符串, 字符串匹配, KMP 算法, Boyer–Moore 算法, 扩展 KMP

**题意**：给定小写字母串 $a$ 与 $b$，求最小的整数 $k \ge 0$，使 $b$ 是 $a$ 重复叠加 $k$ 次所得串 $a^k$ 的**子串**；若无论叠加多少次都无法做到，返回 $-1$。注意 $a^0$ 是空串。

**约束**：

- $1 \le \lvert a \rvert, \lvert b \rvert \le 10^4$
- $a$、$b$ 仅由小写英文字母组成

## 2. 示例

**示例 1**

```text
输入：a = "abcd", b = "cdabcdab"
输出：3
解释：a 重复三遍得 "abcdabcdabcd"（下标 2..9 正好是 b），
      而 a 重复两遍 "abcdabcd" 中 b 无法出现。
```

**示例 2**

```text
输入：a = "a", b = "aa"
输出：2
解释：a 重复 1 次是 "a"，不含 "aa"；重复 2 次是 "aa"，命中。
```

**示例 3**

```text
输入：a = "abc", b = "wxyz"
输出：-1
解释：a^k 只含 a、b、c，永远不可能出现 w/x/y/z。
```

## 3. 解题思路

### 3.1 暴力思路

最直白的做法：从 $k = 1$ 开始，每次把 $a^k$ 拼出来，判断 $b$ 是否为它的子串，一旦命中就返回 $k$。它有三个致命问题：

1. **上界未知**：如果 $b$ 永远不出现，循环无法终止，必须先自己证明一个上界。
2. **重复计算的浪费**：第 $k$ 轮文本长为 $k m$（$m = \lvert a \rvert$），逐轮重新拼接并搜索，试到 $K$ 轮的总代价约为 $\sum_{k \le K} O(km) = O(K^2 m)$；即使 $K$ 只取 $L/m + 1$，也已有 $O(L^2/m)$ 量级。
3. **朴素匹配太慢**：每轮用逐字符比较找子串，最坏 $O(km \cdot L)$，整体可达 $O(L^3/m)$，$10^4$ 时必然超时。

所以真正要解决的是两件事：**把候选 $k$ 收敛到常数个**，以及**用线性算法做一次匹配**。

### 3.2 核心观察：答案只可能是 q 或 q+1

![答案上界：匹配窗口最多跨 q+1 个 a 块](images/wc52_q1_block_bound.svg)

令 $m = \lvert a \rvert$、$L = \lvert b \rvert$，记 $q = \lceil L/m \rceil = \lfloor (L+m-1)/m \rfloor$。**下界**：$a^k$ 的长度是 $km$，要容纳长度为 $L$ 的 $b$ 必须 $km \ge L$，即 $k \ge q$，所以 $k = 1, \dots, q-1$ 可以直接排除。

**上界**：把 $a^\infty$ 看成一个周期为 $m$ 的无限串，它的第 $i$ 个字符恒为 $a[i \bmod m]$。若 $b$ 在某个 $a^k$ 中从下标 $p$ 处出现，则匹配只依赖偏移 $r = p \bmod m$：

$$b[j] = a[(p+j) \bmod m] = a[(r+j) \bmod m], \quad 0 \le j < L .$$

也就是说，**换一个 $k$ 并不会改变匹配的内容，只影响窗口放不放得下**。让窗口从 $r$ 开始，需要覆盖到下标 $r + L - 1$，块数为

$$\left\lceil \frac{r+L}{m} \right\rceil \le \left\lceil \frac{(m-1)+L}{m} \right\rceil \le q+1 .$$

因此只要 $b$ 能在任意多次叠加中出现，它就一定能在 $a^q$ 或 $a^{q+1}$ 中出现。结合下界，答案被压缩到两个候选：

$$k^{*} = \min\{\,k \in \{q,\, q+1\} : b \subseteq a^k\,\}, \quad \text{两个都不行则为 } -1 .$$

> 💡 直观理解：$a^q$ 已经「够长」，唯一的问题是 $b$ 的起点可能落在某个块中间，导致尾部溢出一个块——最多再多借一块就够了。

### 3.3 算法流程：两次线性匹配

![算法流程：最多两次 KMP 匹配](images/wc52_q1_flow.svg)

1. **字符集预判**（剪枝）：若 $b$ 中含有 $a$ 里不存在的字母，直接返回 $-1$，省掉拼接与匹配。
2. 计算 $q = \lceil L/m \rceil$，构造 $s = a^q$，用 KMP 在 $s$ 中找 $b$：命中则返回 $q$。
3. 否则把 $s$ 再追加一个 $a$（变成 $a^{q+1}$），再做一次 KMP：命中则返回 $q+1$。
4. 仍未命中，返回 $-1$。

**前缀函数与匹配指针**：先对模式串 $b$ 求前缀函数

$$\pi[i] = \max\{\, t \le i : b[0..t) = b[i-t+1..i+1) \,\},$$

即 $b[0..i]$ 的最长「真前缀 = 真后缀」长度；匹配时文本指针只前进，失配就令 $k \leftarrow \pi[k-1]$，把模式串跳到下一个可能对齐的位置。

![KMP 前缀函数：末尾 cdab 与开头 cdab 相同](images/wc52_q1_kmp_pi.svg)

为什么不用 `std::string::find` 或 `b in s` 了事？CPython 的 `str.find` 用 Two-Way 算法、最坏线性，但 C++ 标准库的 `std::string::find` 并未规定复杂度，主流实现在最坏情况下是 $O(\lvert s \rvert \cdot L)$ 的朴素匹配；写成 KMP 才能给出**确定性**的 $O(\lvert a \rvert + \lvert b \rvert)$ 上界，这也是本题标签里 KMP / Z 算法 / Boyer–Moore 的考点。

### 3.4 示例演算

对 $a = \texttt{"abcd"}$、$b = \texttt{"cdabcdab"}$：$m = 4$、$L = 8$，得 $q = \lceil 8/4 \rceil = 2$。

![示例演算：a² 未命中，a³ 在下标 2 命中](images/wc52_q1_walkthrough.svg)

| 尝试 | 文本 | 结果 |
|------|------|------|
| $k = q = 2$ | `abcdabcd` | 未命中：窗口长 8 只能从下标 0 起，首字符 a ≠ c |
| $k = q+1 = 3$ | `abcdabcdabcd` | 命中，起始下标 2，占据下标 2..9 |

于是答案为 $3$。再验证两个小例子：$a = \texttt{"a"}$、$b = \texttt{"aa"}$ 时 $q = 2$，$a^2 = \texttt{"aa"}$ 命中，返回 $2$；$a = \texttt{"abc"}$、$b = \texttt{"wxyz"}$ 在字符集预判处就返回 $-1$。

## 4. 算法细节

1. **$q$ 的取整写法**：整数运算用 `(L + m - 1) / m`，不引入浮点运算与取整误差；由 $m \ge 1$ 保证不除零。
2. **不要一次性构造 $a^{q+1}$**：先构造 $a^q$ 并匹配，失败后再 `s += a`。这样既省一次长串拷贝，也天然保证「先小后大」的最小性顺序。
3. **前缀函数只求一次、搜索抽成函数**：$\pi$ 只与 $b$ 有关，两次匹配共用，这是总时间压到线性的关键；把「在 $t$ 中找 $b$」写成同一个闭包，换 $t$ 即可，避免复制粘贴改错边界。
4. **流式匹配（进阶）**：可以不显式拼接，把 $a$ 循环 $q+1$ 遍、逐字符喂给 KMP 的匹配循环，额外空间从 $O(L+m)$ 降到 $O(L)$（只留 $\pi$）。
5. **命中即返回**：匹配指针 $k$ 一旦等于 $L$ 立刻 `return True`，因此访问 `b[k]` 时恒有 $k < L$，不会越界；若把返回判断挪到循环外，就必须补 `k < L` 的保护。
6. **字符集预判只是剪枝**：它能把「字母都不对」的负例提前挡掉，但**不能**替代匹配——字符集相同的串仍可能因周期错位无法匹配（见 §8 第 5 条）。

## 5. 正确性证明

**引理 1（长度下界）**：若 $b$ 是 $a^k$ 的子串，则 $k \ge q$。

**证明**：$a^k$ 的长度为 $km$，包含长度 $L$ 的子串要求 $km \ge L$，两边除以 $m$ 并取上整得 $k \ge \lceil L/m \rceil = q$。∎

**引理 2（$q+1$ 块充分）**：若 $b$ 是某个 $a^k$（$k \ge 1$）的子串，则 $b$ 也是 $a^{q+1}$ 的子串。

**证明**：设 $b$ 在 $a^k$ 中从下标 $p$ 开始出现，令 $r = p \bmod m$。对每个 $j \in [0, L)$ 有 $b[j] = a[(p+j) \bmod m] = a[(r+j) \bmod m]$，第二个等号是因为 $p \equiv r \pmod m$。取 $k' = \lceil (r+L)/m \rceil$，则 $r + L \le k'm$，区间 $[r, r+L)$ 完全落在 $a^{k'}$ 内，且下标 $r+j$ 处的字符仍为 $a[(r+j) \bmod m] = b[j]$，故 $b$ 在 $a^{k'}$ 中从 $r$ 开始出现。

再由 $r \le m-1$ 与 $q = \lceil L/m \rceil$ 估计块数：写 $L = (q-1)m + t$，其中 $1 \le t \le m$，则

$$\frac{m-1+L}{m} = q + \frac{t-1}{m} < q+1 \implies k' \le q+1 .$$

因为 $a^{q+1}$ 是在 $a^{k'}$ 末尾继续追加 $a$ 得到的，原有的出现位置不受影响，所以 $b$ 也是 $a^{q+1}$ 的子串。∎

**引理 3（KMP 判定正确）**：`contains(t)` 返回真当且仅当 $b$ 是 $t$ 的子串。

**证明**：匹配过程中维护不变式：处理完 $t$ 的前 $i$ 个字符后，$k$ 等于「$b$ 的某个前缀同时是 $t[0..i)$ 的后缀」的最大长度。初始 $i=0, k=0$ 成立；读入字符 $c$ 时，若 $c = b[k]$ 则 $k$ 加一，否则由 $\pi$ 的定义，所有长度大于 $\pi[k-1]$ 的候选前缀都不可能成为新后缀，令 $k \leftarrow \pi[k-1]$ 继续比较不丢失任何可行匹配；所有候选试尽后 $k=0$ 也成立。当 $k$ 首次达到 $L$ 时，$t$ 中以当前位置结尾的长度 $L$ 的窗口恰好等于 $b$，判定返回真；反之若 $b$ 出现在 $t$ 中，走到该窗口末尾时不变式会令 $k = L$，同样返回真。∎

**引理 4（字符集预判正确）**：若 $b$ 含 $a$ 中不存在的字符，则任何 $a^k$ 都不含 $b$。**证明**：$a^k$ 的每个字符都来自 $a$，其字符集是 $a$ 字符集的子集；$b$ 含集合外的字符，故不可能等于 $a^k$ 的任何子串。∎

**定理**：算法返回值是最小的可行叠加次数；若不可行则返回 $-1$。

**证明**：分三种情况。

- 返回 $q$：引理 3 保证 $a^q$ 确实含 $b$；引理 1 保证 $k < q$ 全部失败，故 $q$ 最小。
- 返回 $q+1$：算法已确认 $a^q$ 不含 $b$，引理 1 排除 $k < q$，而引理 3 确认 $a^{q+1}$ 含 $b$，故 $q+1$ 最小。
- 返回 $-1$：若因字符集预判返回，由引理 4 不可行；否则两次 KMP 都失败，而引理 2 说明「只要存在可行 $k$，$a^q$ 或 $a^{q+1}$ 中必有一个含 $b$」，与引理 3 的判定矛盾，故不存在可行 $k$。∎

## 6. 复杂度分析

- **时间**：前缀函数 $O(L)$；第一段文本长 $qm \le L + m - 1$，KMP 扫描 $O(qm + L)$；第二段文本长 $(q+1)m \le L + 2m$，同样 $O((q+1)m + L)$；字符集预判 $O(L + m)$。合计 $O(\lvert a \rvert + \lvert b \rvert)$，与答案 $q$ 的大小无关，$10^4$ 规模下远快于时限。
- **空间**：前缀函数 $\pi$ 为 $O(L)$；显式拼接串最长 $(q+1)m \le L + 2m$，即 $O(L + m)$；若改用流式匹配，则额外空间可降为 $O(L)$。

## 7. 参考代码

### C++

```cpp
#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    int repeatedStringMatch(string a, string b) {
        int m = (int)a.size(), L = (int)b.size();

        // 字符集预判：b 里出现了 a 中不存在的字母，直接无解
        bool inA[26] = {false};
        for (char c : a) inA[c - 'a'] = true;
        for (char c : b) if (!inA[c - 'a']) return -1;

        int q = (L + m - 1) / m;              // 最少需要的块数

        // 前缀函数只对模式串 b 求一次，两次匹配共用
        vector<int> pi(L, 0);
        for (int i = 1, k = 0; i < L; ++i) {
            while (k && b[i] != b[k]) k = pi[k - 1];
            if (b[i] == b[k]) ++k;
            pi[i] = k;
        }

        auto contains = [&](const string& t) -> bool {
            int k = 0;
            for (char ch : t) {
                while (k && ch != b[k]) k = pi[k - 1];
                if (ch == b[k]) {
                    if (++k == L) return true; // 命中即返回，k 始终 < L
                }
            }
            return false;
        };

        string s;
        s.reserve((q + 1) * (size_t)m);
        for (int i = 0; i < q; ++i) s += a;
        if (contains(s)) return q;            // 先试较小的 q，保证最小性
        s += a;                               // 再追加一块，变成 a^{q+1}
        if (contains(s)) return q + 1;
        return -1;
    }
};
```

### Python

```python
class Solution:
    def repeatedStringMatch(self, a: str, b: str) -> int:
        # 字符集预判：b 用了 a 里没有的字母，任何叠加都不可能命中
        if set(b) - set(a):
            return -1

        m, L = len(a), len(b)
        q = (L + m - 1) // m          # 最少需要的块数

        # 前缀函数：pi[i] 为 b[0..i] 的最长「真前缀 = 真后缀」长度
        pi = [0] * L
        k = 0
        for i in range(1, L):
            while k and b[i] != b[k]:
                k = pi[k - 1]
            if b[i] == b[k]:
                k += 1
            pi[i] = k

        def contains(text: str) -> bool:
            k = 0
            for ch in text:
                while k and ch != b[k]:
                    k = pi[k - 1]
                if ch == b[k]:
                    k += 1
                    if k == L:        # 命中，立即返回
                        return True
            return False

        s = a * q
        if contains(s):
            return q
        s += a
        if contains(s):
            return q + 1
        return -1
```

## 8. 边界情况与易错点

1. **$a = b$ 的答案不是 0**：如 $a = b = \texttt{"a"}$，$q = 1$，$a^1$ 已含 $b$，返回 $1$。虽然题面提到 0 次是空串，但 $b$ 非空，故答案至少为 1。
2. **$m = 1$**：$q = L$，答案是 $L$ 或 $-1$；此时跨块数的上界退化为 $q$ 而非 $q+1$，但仍在 $\{q, q+1\}$ 内，所以统一写法依然正确。
3. **$m > L$**：$q = 1$，大部分情况试一次 $a$ 就够，例如 $a = \texttt{"abcd"}, b = \texttt{"bc"}$ 返回 $1$；换成 $a = \texttt{"abc"}, b = \texttt{"ca"}$ 却要返回 $2$（$a^2 = \texttt{"abcabc"}$ 中下标 2 命中），不能因为 $L < m$ 就直接返回 $1$。
4. **不能跳过 $a^q$ 直接返回 $q+1$**：$a = \texttt{"abcd"}, b = \texttt{"cd"}$ 的最小答案是 $1$，若先构造 $a^2$ 并返回 $2$ 就错了。必须先试 $q$。
5. **字符集相同也可能无解**：$a = \texttt{"aba"}, b = \texttt{"bab"}$ 时 $b$ 的字母全在 $a$ 中，但 $a^k$ 的所有长度 3 窗口只有 `aba`、`baa`、`aab` 三种，永远凑不出 `bab`，答案 $-1$——这正是不能用「字符集判断」替代匹配的原因。
6. **KMP 的越界**：`ch == b[k]` 中必须保证 $k < L$；本写法在 $k = L$ 时立刻返回，故安全。若在循环内先比较再判断命中，或把返回挪出循环，就会访问 `b[L]` 越界。
7. **整数范围**：$(q+1)m \le L + 2m \le 3 \times 10^4$，`int` 足够；但 `s.reserve((q + 1) * m)` 在 $q$ 极大时也要注意乘法类型（本代码用 `size_t` 强转避免无符号比较告警）。
