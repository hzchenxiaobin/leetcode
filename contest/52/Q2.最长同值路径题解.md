# LeetCode 最长同值路径 题解

## 1. 题目概述

- **标题 / 题号**：最长同值路径（#687，中等）
- **链接**：https://leetcode.cn/problems/longest-univalue-path/
- **来源**：LeetCode 第 52 场周赛 Q2
- **难度**：中等
- **标签**：树，深度优先搜索，二叉树，树形 DP

**题意**：给定一棵二叉树 `root`，在**所有节点值完全相同的简单路径**中求最长者。路径长度按**边数**计（不是点数），且不要求经过根节点。

**约束**：

- 节点数在 $[0, 10^4]$ 内，$0$ 表示空树
- $-1000 \le \text{Node.val} \le 1000$，允许负数与 $0$
- 树的深度不超过 $1000$

> 💡 题面里「这条路径可以经过也可以不经过根节点」是本题的关键提示：最优解可能整条藏在某棵深子树里，因此必须把**每个节点都当作路径的最高点**评估一次，而只做一遍自顶向下的贪心是不够的。

## 2. 示例

**示例 1**

```text
输入：root = [5,4,5,1,1,null,5]
输出：2
解释：最长同值路径是 5 → 5 → 5（根、根的右子、右子的右子），共 2 条边。
```

**示例 2**

```text
输入：root = [1,4,5,4,4,null,5]
输出：2
解释：最长同值路径是 4 → 4 → 4（左侧的 4 与它的两个儿子），共 2 条边。
```

**补充示例（非官方，覆盖边界）**

```text
输入：root = []
输出：0        空树没有任何路径

输入：root = [1,2,3]
输出：0        没有任何一对父子同值，最长路径退化为单个点，边数 0

输入：root = [1,1,null,1,null,1]
输出：3        四个 1 连成一条竖直链，3 条边
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有点对 $(u, v)$，取出树上唯一的 $u \to v$ 路径，逐点检查是否同值，规模 $O(n^3)$（$n = 10^4$ 时约 $10^{12}$，完全不可行）；即使先预处理 LCA 也只能做到 $O(n^2)$，仍然过不了。

更本质的问题在于：我们只想要**最大值**，却枚举了全部 $O(n^2)$ 条路径，浪费了大量信息。

### 3.2 核心观察：同值边森林，答案 = 最大连通块的直径

![同值边把树切成若干同值连通块](images/wc52_q2_same_value_forest.svg)

**观察 1（同值路径 ⇔ 全程走同值边）**：一条路径上所有节点同值，当且仅当路径的**每条边**都连接同值的父子。把这种边称为**同值边**。

**观察 2（同值边构成森林）**：只保留同值边，原树被切成若干个连通块，块内任意两点的树路径完全落在块内、且全程同值。于是

$$\text{本题答案} = \max_{\text{同值连通块 } C} \operatorname{diam}(C)$$

其中直径以边数计。问题从「求全树最优路径」变成「在若干块上分别求树的直径，取最大」，而这两件事可以**一次后序 DFS** 同时完成。

### 3.3 算法流程 / 状态转移

![每个节点只向上交还一条臂](images/wc52_q2_dp_arms.svg)

定义 $down(u)$ 为：**从 $u$ 出发、只向下走同值边**所能走的最多边数，即「单臂长度」。设 $l, r$ 分别是 $u$ 向左、向右伸出的、可延伸的同值臂长：

$$l = \begin{cases} down(u.left) + 1, & u.left \ne \varnothing \text{ 且 } u.left.val = u.val \\ 0, & \text{否则} \end{cases}$$

$$r = \begin{cases} down(u.right) + 1, & u.right \ne \varnothing \text{ 且 } u.right.val = u.val \\ 0, & \text{否则} \end{cases}$$

每个节点只做两件事：

- **结算（拐弯）**：$ans \leftarrow \max(ans,\ l + r)$ —— 以 $u$ 为最高点、在 $u$ 处拐弯的路径；
- **上交（单臂）**：$down(u) = \max(l, r)$ —— 父节点最多只能接一条臂。

```text
dfs(u):
    if u == null: return 0
    lh = dfs(u.left)                      // 后序遍历：先算两个儿子
    rh = dfs(u.right)
    l = (u.left  != null && u.left.val  == u.val) ? lh + 1 : 0
    r = (u.right != null && u.right.val == u.val) ? rh + 1 : 0
    ans = max(ans, l + r)                 // 在此拐弯
    return max(l, r)                      // 只交一条臂
```

答案就是遍历结束后的 `ans`，初始值为 $0$（单节点路径没有边）。

### 3.4 示例演算

![示例 1 自底向上的演算表](images/wc52_q2_example_walkthrough.svg)

对 `root = [5,4,5,1,1,null,5]`，后序顺序为「左叶子 1 → 右叶子 1 → 节点 4 → 右子 5 → 根 5」：

| 顺序 | 节点（值） | 左臂 $l$ | 右臂 $r$ | 返回 $down$ | 全局 $ans$ |
|------|------------|----------|----------|-------------|------------|
| 1 | 左叶子（1） | 0 | 0 | 0 | 0 |
| 2 | 右叶子（1） | 0 | 0 | 0 | 0 |
| 3 | 节点（4） | 0 | 0 | 0 | 0 |
| 4 | 右子（5） | 0 | 1 | 1 | 1 |
| 5 | 根（5） | 0 | 2 | 2 | 2 |

- 节点 4 的两个儿子值都是 1，但都**不等于 4**，所以两臂都是 0，这个块退化为单点；
- 「右子 5」只有右儿子且同值，$r = 0 + 1 = 1$，$ans$ 首次变为 1；
- 根 5 的右儿子同值，$r = down(\text{右子 }5) + 1 = 2$，左儿子 4 异值故 $l = 0$，$ans = 2$。

最终答案为 2，对应路径 $5 \to 5 \to 5$（两条边）。这也说明「按点数 3」是错的，必须返回边数。

## 4. 算法细节

1. **比较对象是「子节点 vs 当前节点」**：`u.left.val == u.val`，不是 `u.left.val == u.right.val`。同值性必须逐边验证，父子对才是判据。
2. **必须后序遍历**：先递归得到 $down(u.left)$、$down(u.right)$，再算 $l, r$ 与 $down(u)$；写成先序会在子节点信息就绪前使用它。
3. **空节点返回 0 最省事**：把 `null` 的 $down$ 定义为 $0$，同时用 `node != null` 保护取值，就自然处理了单边缺儿子、叶子节点、空整树三种情况，不必特判。
4. **边数口径**：叶子节点 $down = 0$（一条边也没走）。若你把 $down$ 定义成点数，题面答案就要在最后 $-1$，容易在空树上出错。
5. **用外部变量收集答案**：$ans$ 通过成员变量 / 闭包 / 引用参数跨递归共享，`dfs` 的返回值只承载「单臂」，职责单一，不易写错。
6. **不要为「值」开数组**：值域虽只有 $[-1000, 1000]$，但同一值可能出现在多个不相邻的块里，按值聚合会混淆不同块，必须按树结构做 DP。
7. **Python 的递归深度**：链状树深度可达 $1000$，默认 `sys.setrecursionlimit(1000)` 会抛 `RecursionError`，解法里显式放宽到 $10^4$（等价地也可以写成显式栈的后序遍历）。
8. **答案上界**：最长同值路径不超过 $n - 1 \le 9999$ 条边，`int` 足够；但不要用 `0` 当「不存在」哨兵，因为节点值可以是 $0$。

## 5. 正确性证明

**引理 1（同值路径的同值边刻画）**：路径 $P$ 上所有节点同值 $\iff$ $P$ 的每条边都是同值边。

**证明**：若 $P$ 上所有节点值都等于 $v$，则 $P$ 的任一条边连接的两个端点值都是 $v$，故为同值边。反之，若 $P$ 的每条边都是同值边，沿路径逐边传递可得 $P$ 上所有节点值相同。∎

**引理 2（$down$ 不变式）**：`dfs(u)` 的返回值等于 $down(u)$，即从 $u$ 出发、只沿同值边向下走的最大边数。

**证明**：对 $u$ 的子树高度归纳。若 $u$ 为空，返回 0，等于定义。否则设两个儿子的返回值已分别为 $down(u.left)$、$down(u.right)$（归纳假设）。从 $u$ 向下的同值链第一步只能落在某个同值子节点 $c$ 上；若 $c$ 与 $u$ 异值则该方向无链（长度 0），若同值则链长 $= 1 + (\text{从 } c \text{ 向下的同值链长}) \le 1 + down(c)$，且取到 $down(c)$ 的那条链可达等号。两方向互相独立，故最大值恰为 $\max(l, r)$，与算法返回值一致。∎

**引理 3（拐弯结算正确）**：对任意节点 $u$，$l + r$ 等于「最高点恰为 $u$ 的同值路径」的最大长度。

**证明**：设 $P$ 的最高点为 $u$。$P$ 从 $u$ 出发只有两种走向：落到左子树或右子树，且每一侧最多只能取一条向下的链（否则在子树内出现分叉，与「简单路径」矛盾）。于是 $|P| = a + b$，其中 $a$ 是左侧链的边数、$b$ 是右侧链的边数（某一侧为空时取 0）。由引理 1，链上每条边都必须是同值边，故 $a \le l$、$b \le r$（$a = 0$ 或 $b = 0$ 时显然成立），于是 $|P| \le l + r$。反过来，取到 $l$ 的那条左链与取到 $r$ 的那条右链在 $u$ 处拼接，是一条真实存在的同值路径，长度为 $l + r$。∎

**定理**：算法返回的值等于最长同值路径的长度。

**证明**：任取一条同值路径 $P$，它的最高点 $u$ 唯一，由引理 3 有 $|P| \le l_u + r_u$，而 $l_u + r_u$ 在遍历到 $u$ 时已被计入 $ans$，故 $|P| \le ans$，即 $ans$ 是上界。另一方面，$ans$ 在每次更新时都对应一条真实路径（引理 3 的可达性部分），故 $ans$ 可达下界。两者相等，答案为最长同值路径长度。空树时 `dfs` 立即返回 0，而 $ans$ 保持 0，恰好等于空树的答案。∎

## 6. 复杂度分析

- **时间**：$O(n)$。每个节点恰好被访问一次，节点内只做常数次比较、加法和取最大值；不存在按值域的额外开销（值域 $[-1000, 1000]$ 与复杂度无关）。
- **空间**：$O(h)$，$h$ 为树高，用于递归调用栈；题目保证 $h \le 1000$。除栈外只用了常数个变量（`ans`、`l`、`r`），未额外建图或建表。
- **补充**：若改成显式栈的迭代后序遍历，空间仍是 $O(h)$，但可以彻底摆脱语言递归深度限制。

## 7. 参考代码

### C++

```cpp
#include <algorithm>
#include <functional>

class Solution {
public:
    int longestUnivaluePath(TreeNode* root) {
        int ans = 0;
        // 返回：从 node 出发、只向下延伸的同值链的最大边数
        std::function<int(TreeNode*)> dfs = [&](TreeNode* node) -> int {
            if (node == nullptr) return 0;
            int lh = dfs(node->left);
            int rh = dfs(node->right);
            int armL = (node->left  && node->left->val  == node->val) ? lh + 1 : 0;
            int armR = (node->right && node->right->val == node->val) ? rh + 1 : 0;
            ans = std::max(ans, armL + armR);   // 以 node 为最高点「拐弯」
            return std::max(armL, armR);        // 只把一条臂交还给父节点
        };
        dfs(root);
        return ans;
    }
};
```

### Python

```python
import sys

sys.setrecursionlimit(10000)        # 链状树深度可达 1000，默认上限会 RecursionError


class Solution:
    def longestUnivaluePath(self, root: "TreeNode | None") -> int:
        self.ans = 0

        # 返回：从 node 出发、只向下延伸的同值链的最大边数
        def dfs(node):
            if node is None:
                return 0
            left = dfs(node.left)
            right = dfs(node.right)
            arm_l = left + 1 if node.left and node.left.val == node.val else 0
            arm_r = right + 1 if node.right and node.right.val == node.val else 0
            self.ans = max(self.ans, arm_l + arm_r)   # 以 node 为最高点「拐弯」
            return max(arm_l, arm_r)                  # 只把一条臂交还给父节点

        dfs(root)
        return self.ans
```

## 8. 边界情况与易错点

1. **空树**：`root = null` 直接返回 0。递归写法里 `dfs(null) = 0`、`ans` 初值 0，天然正确；若在函数开头就访问 `root->val` 会空指针。
2. **单节点**：答案为 0（没有边）。很多人返回 0 后觉得「不对，应该至少是 1」，是把点数当成了长度。
3. **向上返回 `max(l, r)` 而不是 `l + r`**：这是本题最容易错的地方。把两臂同时交还给父节点，等价于让路径在 $u$ 处分叉后又向上延伸，不再是简单路径；分叉只允许在「拐弯结算」时发生。
4. **同值判断的对象**：是「当前节点与子节点」，不是「两个子节点之间」。`[1,4,5,4,4,null,5]` 里两个 4 是兄弟关系却不相邻，不能直接连成路径。
5. **节点值可以为 0 或负数**：不要用 `0` 当作「没有同值子节点」的哨兵，$l = 0$ 只表示「这条臂长 0」，与节点值无关。
6. **深链递归**：深度 $1000$ 的链在 Python 下会触发 `RecursionError`，必须 `sys.setrecursionlimit`；C++ 默认栈通常够用，但递归 lambda 要注意捕获方式（`[&]`）。
7. **树是链时答案等于 $n-1$**：例如 1000 个 7 组成的左斜链，答案 $999$，别因为 `ans` 初始化为 0 而漏掉这种「单臂」形态（它在根处按 $l + r$ 结算，$r = 0$）。
8. **不要用全局哈希表按值聚合**：同一个值可能分布在多棵互不相连的块里，按值统计会把不同块错接在一起。
