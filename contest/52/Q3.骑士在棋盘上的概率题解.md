# LeetCode 骑士在棋盘上的概率 题解

## 1. 题目概述

- **标题 / 题号**：骑士在棋盘上的概率（#688，medium）
- **链接**：https://leetcode.cn/problems/knight-probability-in-chessboard/
- **来源**：LeetCode 第 52 场周赛 Q3
- **难度**：中等
- **标签**：动态规划、概率 DP、网格

**题意**：在 $n \times n$ 的棋盘上，骑士从 $(row, column)$ 出发（行、列均从 $0$ 开始编号）。每一步它从 8 种马步中**等概率**随机选一个，**即使这一步会跳出棋盘也照走不误**；而一旦跳出棋盘，骑士立刻停下。求骑士走完 $k$ 步后**仍留在棋盘上**的概率，也就是这 $k$ 步**每一步都没有出界**的概率。

**约束**：

- $1 \le n \le 25$：格子总数最多 $625$，状态空间很小
- $0 \le k \le 100$：走法总数 $8^{100} \approx 2 \times 10^{90}$，**绝不可能枚举路径**
- $0 \le row, column \le n-1$：起点一定在盘内
- $n \le 2$ 时任何马步都会出界，$k \ge 1$ 的答案恒为 $0$（最容易漏掉的边界）

## 2. 示例

**示例 1**

```text
输入：n = 3, k = 2, row = 0, column = 0
输出：0.06250
解释：从 (0,0) 只有 2 种走法不越界：(1,2) 与 (2,1)；
      从这两个格子继续走，各自也只有 2 种走法留在盘内。
      合法 2 步路径 2 × 2 = 4 条，全部路径 8² = 64 条，
      概率 = 4 / 64 = 0.0625。
```

**示例 2**

```text
输入：n = 1, k = 0, row = 0, column = 0
输出：1.00000
解释：一步都不用走，骑士必然还在棋盘上。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的想法是枚举全部 $8^k$ 条走法序列，逐条判断是否全程不出界，把合法序列数除以 $8^k$。$k = 100$ 时是 $2\times10^{90}$ 量级，完全不可行；即使「一旦出界就剪枝」，剪掉的只是少量分支，量级仍是 $O(8^k)$——$k = 20$ 就已经超过 $10^{17}$。

暴力的浪费在于：它把「怎么走到这里」当成了信息。而实际上，两条不同的路径只要**此刻停在同一个格子、剩下的步数相同**，它们后续出界的概率就完全一样。

### 3.2 核心观察：把「路径枚举」压缩成「格子上的概率」

![骑士的 8 种走法与固定的分母 8](images/wc52_q3_knight_moves_model.svg)

设 $f_t(r,c)$ 表示**从格子 $(r,c)$ 出发、再走 $t$ 步仍然每一步都留在棋盘上**的概率。只要这 $t$ 步还没出界，下一步的 8 个候选方向就与「此前是怎么走过来的」无关（**无后效性**），因此

$$f_t(r,c) \;=\; \frac{1}{8}\sum_{\text{界内的 }(r',c')} f_{t-1}(r',c'), \qquad (r',c') = (r+dr_i,\; c+dc_i)$$

其中 $(dr_i, dc_i)$ 取遍 8 个马步位移。**求和只累加落在盘内的邻居**，出界的那些方向贡献 $0$——它们不是「选项变少」，而是「这条分支的概率质量直接消失」。

> 💡 一句话：$8^k$ 条路径按「第 $t$ 步结束时停在哪一格」分成 $n^2$ 类，同类路径的后续行为完全一致，于是状态数从 $8^k$ 塌缩到 $k \cdot n^2 \le 6.25\times10^4$。

注意**分母恒为 $8$**：哪怕某个格子在盘内只有 2 个合法方向，也是除以 8 而不是除以 2（后者算出的是「条件于没出界」的概率，会把答案系统性地放大）。

### 3.3 算法流程与状态转移

![算法流程：逐层传播与滚动数组](images/wc52_q3_dp_flow.svg)

1. **初始化**：$f_0(r,c) = 1$，还没开始走，无论在哪一格都必然「还在盘上」。
2. **逐层推进**：对 $t = 1,2,\dots,k$，用上一层的表算出本层的表。
3. **单格转移**：枚举 8 个方向，越界的丢弃，界内的累加，最后除以 8。
4. **滚动数组**：第 $t$ 层只依赖第 $t-1$ 层，两个 $n\times n$ 数组交替（`swap`）即可，空间 $O(n^2)$。
5. **答案**：$f_k(row, column)$。

等价的「正向」写法是把概率分布往前推：$p_0(row,column)=1$，$p_t(r',c') = \frac{1}{8}\sum p_{t-1}(r,c)$（$(r,c)$ 是能与 $(r',c')$ 互达的界内格），最后答案是 $\sum_{r,c} p_k(r,c)$。两者算的是同一件事：都等于「合法 $k$ 步路径数 $/\,8^k$」（见 §5 引理 2、引理 3），只是一个从起点向前播、一个从终点向后收。

### 3.4 示例演算

以示例 1 的 $n = 3,\ k = 2,\ (row,column) = (0,0)$ 为例。

![示例演算：初始层与第一层的概率表](images/wc52_q3_walkthrough.svg)

$3\times3$ 棋盘上每个格子的界内马步数 $m$：

| 位置 | 格子 | $m$ | $f_1 = m/8$ |
|------|------|-----|-------------|
| 四角 | $(0,0),(0,2),(2,0),(2,2)$ | 2 | 0.25 |
| 四边中点 | $(0,1),(1,0),(1,2),(2,1)$ | 2 | 0.25 |
| 中心 | $(1,1)$ | 0 | 0 |

于是

$$f_2(0,0) = \frac{f_1(1,2) + f_1(2,1)}{8} = \frac{0.25 + 0.25}{8} = \frac{0.5}{8} = 0.0625$$

从 $(0,0)$ 一步只能到 $(1,2)$ 或 $(2,1)$，其余 6 个方向立刻出界，所以只查了 2 个邻居——这正是「越界项记 0」在起作用。

计数视角的交叉验证：合法 2 步路径 $2 \times 2 = 4$ 条，总路径 $8^2 = 64$ 条，$4/64 = 0.0625$，一致。

## 4. 算法细节

1. **方向数组**：按 $(\pm2,\pm1)$ 与 $(\pm1,\pm2)$ 两组成对写出全部 8 个位移 $(2,1),(2,-1),(-2,1),(-2,-1),(1,2),(1,-2),(-1,2),(-1,-2)$；只写「大的坐标在前」的 4 个是最常见的漏写。
2. **判界**：`0 <= nr < n && 0 <= nc < n` 同时判断行列，写成一个条件即可；不需要额外处理边界环、也不需要对棋盘做 padding。
3. **除以 8 而不是除以合法邻居数**：这是本题唯一的概念性陷阱。合法邻居数只是分子的一部分，分母永远是「等概率的 8 个候选」。
4. **两层数组滚动**：在同一张表上原地更新会读到本层刚写入的值，等于把递推变成了错误的「多步混合」，必须用两张表（或先整层拷贝）。
5. **$k = 0$ 直接返回 $1.0$**：虽然不是必须（循环 $0$ 次时 $f_0$ 就是 $1$），但显式处理能让 $n=1$ 的用例一眼看明白。
6. **浮点类型**：用 `double`。$k=100$ 时每层做 $n^2$ 次加法与一次除法，误差量级约 $10^{-15}$，远低于 $10^{-5}$ 的判定阈值。`float` 只有约 7 位有效数字，本题实测误差已达 $10^{-8}$ 量级，虽仍能通过但没有收益，不建议降精度。
7. **可以提前终止**：若某一层整张表都为 $0$（例如 $n \le 2$），后面不可能再变正，直接返回 $0$；这既是微优化也是很好的正确性自检。
8. **需要绝对精确时**：改用整数计数——$N_t$ 是合法路径条数，Python 大整数可直接算到 $8^{100}$，最后再除 $8^k$ 转 `float`，完全没有浮点误差。

## 5. 正确性证明

**引理 1（单步转移正确）**：对盘内格子 $(r,c)$，一步之后仍留在盘上的概率恰为 $m(r,c)/8$，其中 $m(r,c)$ 是界内马步的个数；且落在某个具体界内格 $(r',c')$ 的概率恰好是 $1/8$。

**证明**：8 个马步位移向量两两不同，因此「选中第 $i$ 个方向」这 8 个事件互斥且各自概率为 $1/8$。落点 $(r+dr_i, c+dc_i)$ 由方向唯一确定，所以每个界内落点的概率就是 $1/8$；「留在盘上」是这 $m(r,c)$ 个互斥事件的并，概率为 $m(r,c)/8$。∎

**引理 2（概率 = 合法路径数 / $8^k$）**：记 $N_k(r,c)$ 为从 $(r,c)$ 出发的 $k$ 步走法序列中全程不出界的条数，则所求概率 $P = N_k(r,c)/8^k$。

**证明**：一次「走 $k$ 步」的随机实验等价于从 $8^k$ 个等可能的走法序列（每条形如 $d_1d_2\cdots d_k$，概率 $8^{-k}$）中均匀抽一个。「$k$ 步全程不出界」这个事件恰好由其中的 $N_k(r,c)$ 个序列组成，故其概率为 $N_k(r,c) \cdot 8^{-k}$。∎

**引理 3（递推等于计数递推）**：对一切 $t \ge 0$ 与盘内格子 $(r,c)$，有 $f_t(r,c) = N_t(r,c)/8^t$。

**证明**：对 $t$ 归纳。$t=0$ 时 $N_0 = 1$（空序列）、$f_0 = 1$，成立。设对 $t-1$ 成立。按**第一步的方向**对合法序列分类：第一步走到界内格 $(r',c')$ 后，剩余 $t-1$ 步必须是「从 $(r',c')$ 出发全程不出界」的序列，共 $N_{t-1}(r',c')$ 条；不同第一步方向给出的序列互不相同（首项不同），故

$$N_t(r,c) = \sum_{\text{界内的 }(r',c')} N_{t-1}(r',c')$$

代入归纳假设与递推式：

$$f_t(r,c) = \frac{1}{8}\sum_{\text{界内的 }(r',c')} \frac{N_{t-1}(r',c')}{8^{t-1}} = \frac{N_t(r,c)}{8^{t}}$$

归纳完成。∎

**定理**：算法返回的 $f_k(row, column)$ 恰为骑士走完 $k$ 步后仍在棋盘上的概率。

**证明**：由引理 3，返回值为 $N_k(row,column)/8^k$；由引理 2，该比值正是所求概率。$k=0$ 时返回 $f_0 = 1$，与「一步没走必然在盘上」相符。∎

## 6. 复杂度分析

- **时间**：$O(k \cdot n^2 \cdot 8) = O(k n^2)$。每层枚举 $n^2$ 个格子、每格查 8 个方向，$k$ 层合计。最坏 $100 \times 625 \times 8 = 5\times10^5$ 次加法，对时限而言微不足道。
- **空间**：$O(n^2)$。滚动数组只保留两层，$2 \times 625$ 个 `double` 约 $10$ KB；若为了调试保留全部 $k+1$ 层则是 $O(k n^2)$，也在 $6$ 万格以内。
- **对比暴力**：暴力是 $O(8^k)$，$k=20$ 就已是 $10^{17}$ 量级；状态压缩把指数级降成了「步数 × 格子数」。

## 7. 参考代码

### C++

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    double knightProbability(int n, int k, int row, int column) {
        if (k == 0) return 1.0;
        static const int dr[8] = {2, 2, -2, -2, 1, 1, -1, -1};
        static const int dc[8] = {1, -1, 1, -1, 2, -2, 2, -2};

        // f[r][c]：从 (r,c) 出发再走 t 步仍留在棋盘上的概率
        vector<vector<double>> f(n, vector<double>(n, 1.0));
        for (int step = 0; step < k; ++step) {
            vector<vector<double>> g(n, vector<double>(n, 0.0));
            for (int r = 0; r < n; ++r) {
                for (int c = 0; c < n; ++c) {
                    double sum = 0.0;
                    for (int d = 0; d < 8; ++d) {
                        int nr = r + dr[d], nc = c + dc[d];
                        if (nr >= 0 && nr < n && nc >= 0 && nc < n)
                            sum += f[nr][nc];          // 越界方向不加，等价贡献 0
                    }
                    g[r][c] = sum / 8.0;               // 分母恒为 8
                }
            }
            f.swap(g);                                 // 滚动到下一层
        }
        return f[row][column];
    }
};
```

### Python

```python
class Solution:
    def knightProbability(self, n: int, k: int, row: int, column: int) -> float:
        moves = ((2, 1), (2, -1), (-2, 1), (-2, -1),
                 (1, 2), (1, -2), (-1, 2), (-1, -2))
        # f[r][c]：从 (r,c) 出发再走 t 步仍留在棋盘上的概率
        f = [[1.0] * n for _ in range(n)]
        for _ in range(k):
            g = [[0.0] * n for _ in range(n)]
            for r in range(n):
                for c in range(n):
                    s = 0.0
                    for dr, dc in moves:
                        nr, nc = r + dr, c + dc
                        if 0 <= nr < n and 0 <= nc < n:
                            s += f[nr][nc]      # 越界方向跳过，贡献 0
                    g[r][c] = s / 8.0           # 分母恒为 8
            f = g
        return f[row][column]
```

## 8. 边界情况与易错点

1. **$k = 0$**：不走就必定在盘上，答案是 $1$。$n=1$ 的示例正是这种情况，别因为「$n=1$ 走不了马步」而提前返回 $0$。
2. **$n \le 2$ 且 $k \ge 1$**：马步要求在某个方向上跨 $2$ 格，而 $n=2$ 时坐标差最大只有 $1$，因此任何一步都必然出界，答案恒为 $0$。测试时容易漏，建议显式加一条用例。
3. **分母写成「合法方向数」**：例如 $n=3$、起点 $(0,0)$ 时除以 $2$，会得到 $0.5$ 而不是 $0.0625$——高了 8 倍。正确做法是恒除以 $8$。
4. **原地更新**：只用一个二维数组边读边写，会用到本层已经被覆盖的值，结果偏大且难以察觉；必须两层交替。
5. **浮点类型**：用 `double`。`float` 在本题实测误差约 $10^{-8}$，虽然仍能通过，但精度余量很小、又没有任何性能收益；一旦把 $k$ 或棋盘调大，误差还会继续累积，是「本地过、评测 WA」的经典隐患。
6. **方向数组写错**：漏写或重写某个方向会让答案整体偏大（多算了不存在的分支）或偏小；建议按 $(\pm2,\pm1)$、$(\pm1,\pm2)$ 两组机械地写全 8 个。
7. **误以为「概率和恒为 1」**：第 $t$ 层所有格子的概率之和等于「$t$ 步全程不出界」的概率，随 $t$ 单调不增，一般严格小于 $1$（只有 $t=0$ 时恒为 $1$，$n \le 2$ 且在 $t \ge 1$ 时为 $0$）。别拿「和为 1」当断言。
8. **返回错格子**：答案是 $f[row][column]$，参数顺序是 `(n, k, row, column)`，别把 `row` 当列用（方阵上虽然对称，但换了棋盘形状就会错）。

**延伸思考**：

1. **$k$ 很大**（例如 $10^9$）：把一层的 $n^2$ 个状态看成向量，转移是固定的线性变换 $v_t = M v_{t-1}$（$M$ 每行只有 8 个非零元，元素为 $1/8$）。用**矩阵快速幂**可做到 $O((n^2)^3 \log k)$，但 $n=25$ 时 $625^3$ 太大；更实用的做法是利用 $M$ 的稀疏性反复平方并稀疏化，或者直接求 $M$ 的主特征值做近似——这条路径在竞赛中通常只在小 $n$ 时可行。
2. **「恰好第 $k$ 步出界」的概率**：不能写成 $1 - f_k$（那是「前 $k$ 步内某一步出界」）。正确做法是用第 $k-1$ 层的分布乘以该格的出界方向占比：$\sum_{r,c} p_{k-1}(r,c)\cdot\bigl(8-m(r,c)\bigr)/8$。
3. **换成别的棋子或三维棋盘**：只需替换方向数组与坐标维度，递推结构（「累加界内邻居、固定除以候选数」）完全不变，这是本题最可迁移的模板。
4. **完全精确的答案**：用大整数统计合法路径条数再转浮点，可把「概率 DP 的浮点误差」变成「只在大整数转浮点时损失一次精度」，也是校验实现是否写错的好办法。
