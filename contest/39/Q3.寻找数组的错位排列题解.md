# LeetCode 寻找数组的错位排列 题解

## 1. 题目概述

- **标题 / 题号**：寻找数组的错位排列（#634，medium）
- **链接**：https://leetcode.cn/problems/find-the-derangement-of-an-array/
- **来源**：LeetCode 第 39 场周赛 Q3
- **难度**：中等
- **标签**：数学、动态规划、组合数学

**题意**：初始数组是升序的 $[1, 2, \dots, n]$。把它重新排列后，若**每个元素都不在自己原来的位置上**，这样的排列称为错位排列（derangement）。求长度为 $n$ 的错位排列总数，由于答案可能很大，结果对 $10^9 + 7$ 取模后返回。

**约束**：

- $1 \le n \le 10^6$
- 返回值对 $10^9 + 7$ 取模
- 本题为会员题（Prime），官方只提供英文题面，中文题面缺失

> 💡 结论先行：设 $D(n)$ 为答案，则 $D(0) = 1$、$D(1) = 0$，且 $D(n) = (n-1)\bigl(D(n-1) + D(n-2)\bigr) \bmod (10^9+7)$；一趟 $O(n)$ 迭代即可，空间只需两个变量。

## 2. 示例

**示例 1**

```text
输入：n = 3
输出：2
解释：原数组为 [1,2,3]。两个错位排列是 [2,3,1] 和 [3,1,2]。
      另外 4 个排列都有不动点：[1,2,3] 三个全在原位，[1,3,2] 中 1 在原位，
      [2,1,3] 中 3 在原位，[3,2,1] 中 2 在原位。
```

**示例 2**

```text
输入：n = 2
输出：1
解释：原数组为 [1,2]，唯一合法的排列是 [2,1]。
```

**示例 3（补充）**

```text
输入：n = 1
输出：0
解释：原数组为 [1]，唯一的排列就是 [1] 本身，元素 1 必然在原位。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的做法是枚举 $1 \sim n$ 的所有 $n!$ 个排列，逐个检查是否有不动点。复杂度 $O(n \cdot n!)$：$n = 10$ 时已有 $3.6\times10^6$ 个排列，$n = 12$ 就到 $4.8\times10^8$，而本题 $n$ 高达 $10^6$——**指数级枚举在本题没有任何生存空间**。

另一条路是容斥原理：

$$D(n) = \sum_{k=0}^{n} (-1)^k \binom{n}{k} (n-k)! = n! \sum_{k=0}^{n} \frac{(-1)^k}{k!}$$

这把复杂度压到 $O(n)$，但需要预处理阶乘与阶乘逆元（还要额外 $O(n)$ 数组、每次求逆 $O(\log M)$），常数明显偏大。能不能只用加法与乘法，边算边滚？可以，关键是一个**组合分解**。

### 3.2 核心观察：按元素 1 的落点分类

![按元素 1 的落点分成两类情形](images/wc39_q3_derangement_branch.svg)

在任意一个错位排列里，元素 $1$ 一定不在位置 $1$，所以它可以去 $n-1$ 个位置中的任意一个，设为 $j$（$j \neq 1$）。**固定 $j$ 之后，再看元素 $j$ 去了哪里**，只有两种互斥的情形：

- **情形 A**：元素 $j$ 去了位置 $1$。此时 $1$ 与 $j$ 互换，两个位置被彻底占死；剩下 $n-2$ 个元素要在剩下的 $n-2$ 个位置上各自错排，方案数 $D(n-2)$。
- **情形 B**：元素 $j$ 没有去位置 $1$。此时把位置 $1$ 与位置 $j$ **看成一个槽位**（把位置 $1$ 重命名为 $j$）：剩余 $n-1$ 个元素中，$j$ 不许落在这个槽位上，其余元素 $k$ 不许落在位置 $k$ 上——这恰好是 $n-1$ 个元素的全错排，方案数 $D(n-1)$。

两类相加，再乘上 $j$ 的 $n-1$ 种选择：

$$D(n) = (n-1)\bigl(D(n-1) + D(n-2)\bigr)$$

基数：$D(0) = 1$（空排列视为 1 种有效方案，它是递推的地平面），$D(1) = 0$（唯一元素无处可去）。

> ⚠️ 常见误区：情形 B **不是**「元素 $j$ 也没动」，而是「$j$ 没去位置 $1$」；把位置 $1$ 当成 $j$ 的原位来合并，才能得到完整的 $n-1$ 规模错排。

### 3.3 算法流程 / 状态转移

![滚动两个变量的一趟递推](images/wc39_q3_rolling_vars.svg)

递推只依赖前两项，因此**不需要数组**，用两个标量滚动即可，完全避开 $10^6$ 规模的额外内存：

1. 初始化 `prev2 = D(0) = 1`、`prev1 = D(1) = 0`。
2. 令 $i$ 从 $2$ 枚举到 $n$：`cur = (i-1) * (prev1 + prev2) % MOD`。
3. 滚动：`prev2 = prev1`，`prev1 = cur`。
4. 循环结束返回 `prev1`（即 $D(n)$）。

对 $n = 1$，循环体一次都不执行，直接返回 `prev1 = 0`，正好是正确答案。

**两条可用来对拍的等价式**（写题解时互相验证，非常有用）：

$$D(n) = n\,D(n-1) + (-1)^n, \qquad D(n) = \left\lfloor \frac{n!}{e} + \frac{1}{2} \right\rfloor$$

前者只需一个变量、多一个符号项；后者说明错排数与 $n!/e$ 只差不到 $1/2$，也就解释了「$n$ 较大时错排占全排列的比例趋于 $1/e \approx 0.3679$」。

### 3.4 示例演算

![n = 0…6 的递推走查表](images/wc39_q3_walkthrough.svg)

| $n$ | $D(n-1)$ | $D(n-2)$ | $D(n) = (n-1)(D(n-1)+D(n-2))$ |
|-----|----------|----------|-------------------------------|
| 2 | 0 | 1 | $1 \times (0+1) = 1$ |
| 3 | 1 | 0 | $2 \times (1+0) = 2$ |
| 4 | 2 | 1 | $3 \times (2+1) = 9$ |
| 5 | 9 | 2 | $4 \times (9+2) = 44$ |
| 6 | 44 | 9 | $5 \times (44+9) = 265$ |

其中 $n=3$ 一行与官方示例吻合（答案为 $2$）。序列 $1, 0, 1, 2, 9, 44, 265, \dots$ 即 OEIS A000166。

## 4. 算法细节

1. **基数必须成对设置**：$D(0) = 1$ 与 $D(1) = 0$ 缺一不可。若把 $D(0)$ 误设为 $0$，则 $D(2) = 1 \times (0+0) = 0$，整条序列全错。
2. **循环从 $i = 2$ 开始**：这样 $n = 1$ 时循环不执行、直接返回 $0$，天然处理了唯一的小规模特判，不必额外写 `if`。
3. **取模时机**：先做加法再做乘法。和不超过 $2\times10^9$，乘以 $i-1$（$\le 10^6-1$）后不超过 $2\times10^{15}$，安全落在 64 位整数（约 $9.2\times10^{18}$）内，一轮只需一次取模。
4. **C++ 的类型**：`(i-1)` 是 `int`，与 `long long` 的累加器运算时会自动提升，所以直接写 `(i-1) * (prev1 + prev2)` 也不会溢出；但把累加器声明成 `int` 就必炸——$2\times10^{15}$ 远超 32 位。显式写 `(long long)(i - 1)` 是把这条约束钉在代码里，避免日后改成 `int` 变量时静默溢出。
5. **空间只留两个标量**：$n = 10^6$ 时开 `vector<int>` 也只要 4 MB，但完全没必要；滚动变量把空间降到 $O(1)$，也顺带避免了「数组下标差一」这类错误。
6. **不要递归实现**：$n = 10^6$ 的递归深度会直接爆栈，即使加记忆化也白白消耗 $O(n)$ 空间。
7. **对拍建议**：实现后顺手用 $D(n) = n\,D(n-1) + (-1)^n$ 再跑一遍，两条递推在 $n \le 10^6$ 全部一致才说明没写错取模。

## 5. 正确性证明

**引理 1（分类完备且互斥）**：设 $n \ge 2$。每个 $n$ 元错位排列都对应唯一的二元组 $(j, c)$，其中 $j \in \{2,\dots,n\}$ 是元素 $1$ 所在的位置，$c \in \{A, B\}$ 表示元素 $j$ 是否位于位置 $1$。

**证明**：元素 $1$ 在错位排列中不可能位于位置 $1$，故其落点 $j$ 唯一存在且 $j \neq 1$；随后元素 $j$ 的落点要么是位置 $1$，要么不是，二者互斥且穷尽，故 $c$ 唯一。∎

**引理 2（情形 A 的方案数）**：固定 $j$，在「元素 $1$ 在位置 $j$ 且元素 $j$ 在位置 $1$」的条件下，剩余部分的方案数为 $D(n-2)$。

**证明**：位置 $1, j$ 已被占满，剩余 $n-2$ 个元素 $[n]\setminus\{1,j\}$ 只能落在剩余的 $n-2$ 个位置 $[n]\setminus\{1,j\}$ 上，且每个元素 $k$ 仍不许落在位置 $k$——这正是 $n-2$ 元错排的定义，二者一一对应。∎

**引理 3（情形 B 的方案数）**：固定 $j$，在「元素 $1$ 在位置 $j$ 且元素 $j$ 不在位置 $1$」的条件下，剩余部分的方案数为 $D(n-1)$。

**证明**：此时剩余元素集为 $[n]\setminus\{1\}$，剩余位置集为 $[n]\setminus\{j\}$，两者大小都是 $n-1$。把剩余位置集中的位置 $1$ 重命名为 $j$，于是位置集可写作 $\{2,\dots,n\}$。约束随之变为：

- 对 $k \neq j$：元素 $k$ 不许落在位置 $k$（原封不动）；
- 对 $k = j$：原位置 $j$ 已不可用，「元素 $j$ 不去位置 $1$」正是重命名后「元素 $j$ 不许落在位置 $j$」。

因此重命名后的问题就是 $n-1$ 个元素的全错排，方案数 $D(n-1)$。反之，任一 $\{2,\dots,n\}$ 上的错排中元素 $j$ 不在位置 $j$，还原标签后 $j$ 也不在位置 $1$，顺利回到情形 B。两个方向互为逆映射，故为双射。∎

**定理（递推正确）**：对 $n \ge 2$，$D(n) = (n-1)\bigl(D(n-1) + D(n-2)\bigr)$；且算法输出 $D(n) \bmod (10^9+7)$。

**证明**：由引理 1，全部错位排列按 $(j, c)$ 划分成 $2(n-1)$ 个互不相交的块；由引理 2、3，固定 $j$ 后两类块的大小分别是 $D(n-2)$ 与 $D(n-1)$，且与 $j$ 的具体取值无关；由加法与乘法原理即得递推式。算法方面：$n \le 1$ 时返回值与基数一致；$n \ge 2$ 时对 $n$ 归纳——第 $i$ 轮循环结束后 `prev1` 恰为 $D(i)$（归纳假设前一轮 `prev2 = D(i-2)`、`prev1 = D(i-1)`，代入递推式即得），而模运算与加法、乘法可交换，故最终返回值等于 $D(n) \bmod (10^9+7)$。∎

## 6. 复杂度分析

- **时间**：$O(n)$。循环执行 $n-1$ 轮，每轮 1 次加法、1 次乘法、1 次取模，均为常数时间；$n = 10^6$ 时约 $10^6$ 次基本运算，可在毫秒级完成。
- **空间**：$O(1)$。只保留 `prev2`、`prev1`、`cur` 三个标量，与 $n$ 无关；不需要数组、不需要阶乘表、不需要逆元。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int findDerangement(int n) {
        const long long MOD = 1000000007LL;
        long long prev2 = 1;   // D(0) = 1
        long long prev1 = 0;   // D(1) = 0
        for (int i = 2; i <= n; ++i) {
            // D(i) = (i - 1) * (D(i - 1) + D(i - 2)) mod MOD
            long long cur = (long long)(i - 1) * ((prev1 + prev2) % MOD) % MOD;
            prev2 = prev1;
            prev1 = cur;
        }
        return (int)prev1;
    }
};
```

### Python

```python
class Solution:
    def findDerangement(self, n: int) -> int:
        MOD = 10 ** 9 + 7
        prev2, prev1 = 1, 0        # D(0) = 1, D(1) = 0
        for i in range(2, n + 1):
            # D(i) = (i - 1) * (D(i - 1) + D(i - 2)) mod MOD
            prev2, prev1 = prev1, (i - 1) * (prev1 + prev2) % MOD
        return prev1
```

## 8. 边界情况与易错点

1. **$n = 1$ 返回 $0$**：唯一排列就是原排列，不存在错排。若把 `prev1` 初始化成 $1$，会在这里返回错误答案。
2. **$n = 2$ 返回 $1$**：$[2,1]$ 是唯一解；这也是递推 $(2-1)(D(1)+D(0)) = 1 \times (0+1) = 1$ 的首个非平凡验证点。
3. **基数 $D(0) = 1$ 别写成 $0$**：空排列按定义算 1 种方案，它是递推的种子；写错会让 $D(2), D(3), \dots$ 全体退化。
4. **32 位溢出**：`(i-1) * (prev1 + prev2)` 最大约 $2\times10^{15}$，必须用 `long long`；用 `int` 直接乘会静默溢出并返回错误的负数或小值。
5. **循环上界是 $i \le n$**：写成 $i < n$ 会少算一轮，$n \ge 2$ 时答案变成 $D(n-1)$，示例 1 会输出 $1$ 而非 $2$。
6. **改用 $D(n) = n D(n-1) + (-1)^n$ 时的负数取模**：C++ 中 `n * d - 1` 可能为负，需要 `(x % MOD + MOD) % MOD`；Python 的 `%` 天然返回非负，可直接写。
7. **不要用递归或记忆化数组**：$n = 10^6$ 的递归深度会爆栈；而滚动变量已经是最优空间，再加数组只是浪费。
