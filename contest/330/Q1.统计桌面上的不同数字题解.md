# LeetCode 统计桌面上的不同数字 题解

## 1. 题目概述

- **标题 / 题号**：统计桌面上的不同数字（#2549，easy）
- **链接**：https://leetcode.cn/problems/count-distinct-numbers-on-board/
- **来源**：LeetCode 第 330 场周赛 Q1
- **难度**：简单
- **标签**：数学、脑筋急转弯、模拟、哈希表

**题意**：给定正整数 `n`，初始时桌面（board）上只有 `n`。在 $10^9$ 天里，每天对桌面上**每个**数字 $x$，找出所有满足 $1 \le i \le n$ 且 $x \bmod i = 1$ 的 `i`，并把它们放上桌面（上桌后一直保留）。求 $10^9$ 天后桌面上**不同**整数的数目。

**约束**：

- `1 <= n <= 100`
- 天数固定为 $10^9$，远大于 `n` 的规模

> 💡 读题信号：迭代次数大到明显跑不完（$10^9$ 天），而状态空间很小（数字只能来自 $[1,n]$）——典型的「过程冗余、终态可解析」型签到题，先想终态由什么决定，而不是直接模拟。

## 2. 示例

**示例 1**

```text
输入：n = 5
输出：4
解释：初始桌面 {5}。
  第 1 天：5%2=1、5%4=1 → 桌面 {2,4,5}。
  第 2 天：4%3=1 → 桌面 {2,3,4,5}。
  此后不再有新增，十亿天结束时桌面为 {2,3,4,5}。
```

**示例 2**

```text
输入：n = 3
输出：2
解释：3%2=1 → 桌面 {2,3}，此后稳定，共 2 个不同数字。
```

**补充示例**

```text
输入：n = 1
输出：1
解释：桌面只有初始的 1，而 1%1=0，永远无新增，答案为 1（注意不是 n−1=0）。

输入：n = 2
输出：1
解释：2%1=0、2%2=0，无新增，桌面保持 {2}，答案 1 = n−1。
```

## 3. 解题思路

### 3.1 暴力思路：逐日模拟到收敛

按题意维护桌面集合 $S$（初始 $\{n\}$）：每天对每个 $x \in S$ 枚举 $i \in [1,n]$，凡 $x \bmod i = 1$ 就加入 $S$，直到某天无新增即收敛。因 $n \le 100$，每天 $O(n^2)$、至多 $n$ 天收敛，总计 $O(n^3) \le 10^6$，**在本题约束下可以直接 AC**。

但这个写法被 $10^9$ 天的题面吓唬住了：真正的终态由一个代数恒等式唯一决定，根本不必逐日跑。签到题的目标是找到**从题面到代码的最短路径**——比赛时更推荐先用它**打表**：模拟出 $n = 1..8$ 的答案，一眼看出规律再写一行代码。

### 3.2 核心观察：$x \bmod (x-1) = 1$ 触发链式下降

![核心观察：x%(x−1)=1 触发链式下降，桌面收敛为 {2,…,n}](images/wc330_q1_chain_concept.svg)

先打表（模拟 $n = 1..8$）：

| $n$ | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|-----|---|---|---|---|---|---|---|---|
| 答案 | 1 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |

规律立刻浮现：答案 $= \max(n-1,\ 1)$。为什么？

- **恒等式**：对任意 $x \ge 3$，有 $x = 1 \cdot (x-1) + 1$，故 $x \bmod (x-1) = 1$。于是**每个桌面上的 $x \ge 3$ 次日必把 $x-1$ 拉上桌**，形成链 $n \to n-1 \to n-2 \to \cdots \to 2$；
- **链在 2 处终止**：$2 \bmod 1 = 0 \ne 1$（且 $2 \bmod i$ 对 $i \ge 2$ 恒不为 1），2 无法拉出新数；
- **两道夹逼锁定终态**：① 候选 $i \in [1,n]$，桌面数字不会超过 $n$；② $x \bmod 1 \equiv 0$，数字 1 **永远不会被拉上桌**（$n \ge 2$ 时）。

三件事合起来：$n \ge 2$ 时终态**恰好**是 $\{2, 3, \dots, n\}$，共 $n-1$ 个。

### 3.3 算法流程：一次比较直接出答案

![算法流程：判断 n 是否为 1，等价 max(n−1,1)](images/wc330_q1_algorithm_flow.svg)

流程是无循环的三分支判定：

1. 若 $n = 1$ → 返回 $1$（终态 $\{1\}$，$n-1 = 0$ 失效）；
2. 若 $n \ge 2$ → 返回 $n - 1$（终态 $\{2, \dots, n\}$）；
3. 两种情况统一写成 `max(n - 1, 1)`。

收敛性无忧：桌面只增不减且 $\subseteq [1,n]$，链式下降至多 $n-2$ 天集齐 $\{2,\dots,n\}$，$n - 2 \le 98 \ll 10^9$，「十亿天」只是「跑到不动」的保证。

### 3.4 示例演算

![示例演算：n=5 逐日桌面变化，收敛到 {2,3,4,5}](images/wc330_q1_example_walkthrough.svg)

- **$n = 5$**：$\{5\} \xrightarrow{+2,+4} \{2,4,5\} \xrightarrow{+3} \{2,3,4,5\}$，此后稳定，答案 $4 = n-1$。注意第 1 天同时拉出 2 和 4（5 的「因数捷径」），但**即使没有捷径**，链 $5 \to 4 \to 3 \to 2$ 也保证三天内集齐；
- **$n = 3$**：$\{3\} \to \{2,3\}$，答案 $2 = n-1$；
- **$n = 1$**：$\{1\}$ 永不变（$1 \bmod 1 = 0$），答案 $1$，是唯一的特判点。

## 4. 算法细节

1. **余数条件的等价刻画**：当 $x \ge 2$ 时，$x \bmod i = 1 \iff i \mid (x-1)$ 且 $2 \le i \le x-1$。即每个上桌的 $x$ 带来的正是 $x-1$ 的真因数（落在 $[2, x-1]$ 内）：
   - $x = 5$ 带来 $4$ 的因数 $\{2, 4\}$；$x = 4$ 带来 $3$ 的因数 $\{3\}$；$x = 3$ 带来 $2$ 的因数 $\{2\}$；$x = 2$ 带来 $1$ 的因数——空集（链终止的另一种解释）。
2. **链式下降是「保底」**：因数捷径只会**提前**拉入某些数（如 5 直接带出 2），不影响终态集合；链 $x \to x-1$ 保证最坏 $n-2$ 天内 $\{2,\dots,n\}$ 全部上桌。
3. **统一表达式**：`max(n - 1, 1)` 同时覆盖 $n = 1$ 与 $n \ge 2$，无需 if 分支；写成三元 `n == 1 ? 1 : n - 1` 亦可。
4. **模拟枚举的小优化**：逐日模拟版中 $i$ 可从 2 枚举到 $n$——因为 $x \bmod 1 \equiv 0$ 恒不等于 1，$i = 1$ 永远无贡献。
5. **比赛策略**：先写 10 行模拟打表确认规律（防猜错），再交 $O(1)$ 版本；两者在本题约束下都能过，但后者从题面到代码只要一行。

## 5. 正确性证明

**引理 1（值域有界）**：任何时刻桌面上的数都属于 $[1, n]$。

**证明**：初始桌面仅有 $n \in [1,n]$；每天新增的数 $i$ 按规则满足 $1 \le i \le n$。对天数归纳即得。∎

**引理 2（1 永不上桌）**：对任意正整数 $x$，$x \bmod 1 = 0 \ne 1$。故当 $n \ge 2$ 时（1 不是初始数字），1 永远不会出现在桌面上。

**证明**：$x = x \cdot 1 + 0$，商为 $x$、余数为 0。∎

**引理 3（链式下降）**：若某天 $x$（$3 \le x \le n$）在桌面上，则最晚次日开始 $x - 1$ 一直在桌面上。

**证明**：$x = 1 \cdot (x-1) + 1$ 且 $2 \le x-1 \le n$，故 $x \bmod (x-1) = 1$，按规则 $x-1$ 于次日上桌；桌面只增不减，故此后一直在。∎

**引理 4（有限收敛）**：桌面集合 $S$ 单调不减且 $S \subseteq [1,n]$，故至多 $n-1$ 天后不再有新增；由 $n \le 100 \le 10^9$，「$10^9$ 天后」的桌面即为收敛终态 $S_\infty$。

**证明**：若某天有新增则 $|S|$ 至少增加 1，而 $|S| \le n$，从 $|S_0| = 1$ 出发至多新增 $n-1$ 次；之后集合不变。∎

**定理**：$n = 1$ 时答案为 $1$；$n \ge 2$ 时答案为 $n - 1$。

**证明**：

- $n = 1$：候选 $i$ 只有 1，而 $1 \bmod 1 = 0 \ne 1$，永远无新增，$S_\infty = \{1\}$，答案 1。
- $n \ge 2$：
  - **下界**（$\{2,\dots,n\} \subseteq S_\infty$）：$n$ 在第 0 天就在桌面上；对 $k = n, n-1, \dots, 3$ 反复应用引理 3，知 $k - 1$ 最晚于次日上桌。归纳得 $n-1, n-2, \dots, 2$ 全部出现在 $S_\infty$ 中。
  - **上界**（$S_\infty \subseteq \{2,\dots,n\}$）：由引理 1，$S_\infty \subseteq [1, n]$；由引理 2，$1 \notin S_\infty$（$n \ge 2$ 时 1 非初始数字且永不被拉上桌）。
  - 两边夹逼得 $S_\infty = \{2, 3, \dots, n\}$，$|S_\infty| = n - 1$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(1)$。一次减法与一次比较（或 `max`），与 $n$ 无关。
- **空间复杂度**：$O(1)$。仅常数个变量。
- **对照：逐日模拟版**：时间 $O(n^3)$（每天 $O(n^2)$ 枚举、至多 $n$ 天收敛）、空间 $O(n)$，在 $n \le 100$ 下亦可 AC，但没有利用终态规律。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int distinctNumbers(int n) {
        // n >= 2 时终态为 {2,...,n}，共 n-1 个；n = 1 时桌面只有 {1}
        return max(n - 1, 1);
    }
};
```

模拟版（打表 / 对拍用，同样可通过）：

```cpp
class Solution {
public:
    int distinctNumbers(int n) {
        unordered_set<int> board{n};
        while (true) {
            unordered_set<int> nxt = board;
            for (int x : board)
                for (int i = 2; i <= n; ++i)  // i=1 时 x%1==0，可跳过
                    if (x % i == 1) nxt.insert(i);
            if (nxt.size() == board.size()) break;  // 无新增，收敛
            board = move(nxt);
        }
        return board.size();
    }
};
```

### Python

```python

```

模拟版：

```python
class Solution:
    def distinctNumbers(self, n: int) -> int:
        board = {n}
        while True:
            nxt = board | {i for x in board for i in range(2, n + 1) if x % i == 1}
            if len(nxt) == len(board):
                return len(board)
            board = nxt
```

## 8. 边界情况与易错点

1. **$n = 1$ 必须特判**：$n - 1 = 0$ 是错误答案，正确为 1（桌面只有初始的 1，且 $1 \bmod 1 = 0$ 永无新增）。用 `max(n - 1, 1)` 统一覆盖。
2. **误以为 1 会上桌**：$x \bmod 1 \equiv 0$，任何 $x$ 都无法把 1 拉上桌。若忽略这点会把 $[1,n]$ 全算进去，误答 $n$。
3. **别真模拟 $10^9$ 天**：即使写模拟版，也要在「无新增」时提前退出（状态单调有界，$\le n$ 天必收敛）；按天数硬循环 $10^9$ 次必然超时。
4. **$n = 2$ 无需单独分支**：链根本不启动（$2 \bmod 1 = 0$、$2 \bmod 2 = 0$），答案 $1 = n - 1$，已被统一表达式覆盖。
5. **无溢出风险**：$n \le 100$，一次减法用 `int` 绰绰有余。
6. **读题细节**：「$10^9$ 天内**每天**执行」意味着新增从第 1 天开始生效；「一旦上桌则一直保留」保证集合单调不减——这是收敛性成立的前提，别按可删除的集合理解。
