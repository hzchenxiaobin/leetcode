# LeetCode 将珠子放入背包中 题解

## 1. 题目概述

- **标题 / 题号**：将珠子放入背包中（#2551，hard）
- **链接**：https://leetcode.cn/problems/put-marbles-in-bags/
- **来源**：LeetCode 第 330 场周赛 Q3
- **难度**：困难
- **标签**：贪心、数组、排序、堆（优先队列）

**题意**：给定排成一排的 $n$ 个珠子，第 $i$ 个珠子重量为 $\text{weights}[i]$。要把全部珠子放进 $k$ 个背包，要求每个背包非空，且珠子按原顺序切成 $k$ 个**连续段**（若第 $i$、$j$ 个珠子同袋，则下标 $i$ 到 $j$ 之间的珠子都必须在该袋中）。一个装有下标 $i$ 到 $j$ 珠子的背包，其**价格**为 $\text{weights}[i] + \text{weights}[j]$（只算首尾两颗）。方案的**分数**是 $k$ 个背包的价格之和。求所有合法方案中「最大分数 − 最小分数」。

**约束**：

- $1 \le k \le n \le 10^5$
- $1 \le \text{weights}[i] \le 10^9$

> 💡 读题信号：连续段划分 $\Rightarrow$ 方案由「切点位置」唯一决定；价格只依赖每段**端点** $\Rightarrow$ 分数能改写成「相邻元素配对和」的组合；要求最大与最小之差 $\Rightarrow$ 两者可**独立**优化。三个信号都指向排序贪心，而非 DP。

## 2. 示例

**示例 1**

```text
输入：weights = [1,3,5,1], k = 2
输出：4
解释：最小分数方案 [1],[3,5,1]：(1+1) + (3+1) = 6；
      最大分数方案 [1,3],[5,1]：(1+3) + (5+1) = 10；差 = 10 - 6 = 4。
```

**示例 2**

```text
输入：weights = [1,3], k = 2
输出：0
解释：唯一方案 [1],[3]，最大最小分数相等。
```

**补充示例**

```text
输入：weights = [1,3,5,1], k = 3
输出：4
解释：相邻和 pairs = [4,8,6]，选 2 个切点。
      最小 = (1+1) + 4 + 6 = 12（切缝隙 0、2：[1],[3,5],[1]）；
      最大 = (1+1) + 8 + 6 = 16（切缝隙 1、2：[1,3],[5],[1]）；差 = 4。

输入：weights = [1,3,5,1], k = 4
输出：0
解释：k = n，三个缝隙必须全切，方案唯一，最大 = 最小。
```

## 3. 解题思路

### 3.1 暴力思路：枚举切法 / 区间 DP

最直观的做法是枚举所有切法：在 $n-1$ 个缝隙中选 $k-1$ 个下刀，共 $\binom{n-1}{k-1}$ 种，每种 $O(k)$ 求分数——$n = 10^5$ 时候选数是天文数字。

退一步想 DP：设 $f[i][j]$ 为前 $i$ 个珠子分成 $j$ 袋的最小（大）分数，转移枚举最后一段起点，$O(n^2 k)$，在 $n = 10^5$ 下同样不可行。

两条朴素路都堵死，说明必须挖掘**分数本身的结构**：价格只含首尾端点，中间珠子的重量根本不进分数——这个「浪费」正是突破口。比赛现场的正确节奏是：手算示例 1 的两个分数，盯着 $(1+1)+(3+1)$ 与 $(1+3)+(5+1)$ 展开、重新凑对，恒等式自然浮现。

### 3.2 核心观察：分数 = 固定底座 + 切点相邻和

![核心观察：分数=固定底座+切点相邻和，袋价求和会换搭档](images/wc330_q3_split_concept.svg)

**划分 ⇔ 选切点**：一个合法方案就是在 $n-1$ 个缝隙（缝隙 $i$ 指珠子 $i$ 与 $i+1$ 之间）中选出恰好 $k-1$ 个切点。

**分数分解**：把 $k$ 个袋的价格加起来：

- 第一个袋的**左端**永远是珠子 $0$，最后一个袋的**右端**永远是珠子 $n-1$——这两项对任何方案都固定，称为**底座** $w_0 + w_{n-1}$；
- 其余每个端点都紧贴着一个切点：若在缝隙 $i$ 处下刀，珠子 $i$ 是左袋的右端、珠子 $i+1$ 是右袋的左端，该切点贡献 $w_i + w_{i+1}$。

于是：

$$\text{score}(S) \;=\; \underbrace{w_0 + w_{n-1}}_{\text{固定底座}} \;+\; \sum_{i \in S}\left(w_i + w_{i+1}\right)$$

直觉上这是一次「换搭档」：袋价求和 $(w_0+w_1)+(w_2+w_3)+\cdots$ 展开后重新配对，首尾两颗抱团成底座，中间端点两两挂在切点上。**分数与切点之外的一切无关，只依赖选中的相邻和**。

**推论**：底座对所有方案相同，因此最大分数取「$n-1$ 个相邻和中前 $k-1$ 大之和」，最小分数取「前 $k-1$ 小之和」，且做差时底座直接抵消：

$$\text{答案} = \left(\text{前 } k-1 \text{ 大相邻和之和}\right) - \left(\text{前 } k-1 \text{ 小相邻和之和}\right)$$

### 3.3 算法流程：相邻和排序贪心

![算法流程：相邻和排序，前k-1大减前k-1小](images/wc330_q3_algorithm_flow.svg)

1. 计算 $n-1$ 个相邻和 $\text{pairs}[i] = w_i + w_{i+1}$，$i = 0, \dots, n-2$；
2. 将 $\text{pairs}$ 升序排序；
3. 最小分数 $=$ 底座 $+$ 前 $k-1$ 小之和；最大分数 $=$ 底座 $+$ 前 $k-1$ 大之和；
4. 答案 $=$ 最大 $-$ 最小（底座抵消，实现时甚至无需计算底座）。

排序可换成大小为 $k-1$ 的**双堆**（$O(n \log k)$）或**快速选择**（平均 $O(n)$），见 §4 与 §8。

### 3.4 示例演算

![示例演算：weights=[1,3,5,1], k=2的最小/最大分数与答案](images/wc330_q3_example_walkthrough.svg)

以 $\text{weights} = [1,3,5,1]$，$k = 2$ 为例：

- 相邻和 $\text{pairs} = [1{+}3,\ 3{+}5,\ 5{+}1] = [4, 8, 6]$，底座 $= w_0 + w_3 = 2$；
- **最小分数**：选最小相邻和 $4$（切缝隙 0，方案 $[1] \mid [3,5,1]$），分数 $= 2 + 4 = 6$，与袋价 $(1+1)+(3+1) = 6$ 吻合；
- **最大分数**：选最大相邻和 $8$（切缝隙 1，方案 $[1,3] \mid [5,1]$），分数 $= 2 + 8 = 10$，与袋价 $(1+3)+(5+1) = 10$ 吻合；
- **答案** $= 10 - 6 = 4$，即 $8 - 4$——底座 $2$ 两边都出现，做差时抵消。

再验证两个极端：$k = 3$ 时前 2 小 $= 4+6$、前 2 大 $= 8+6$，差仍为 $4$；$k = 4 = n$ 时缝隙全切、方案唯一，差 $= 0$。

## 4. 算法细节

1. **切点模型**：方案 $\Leftrightarrow$ 切点集 $S \subseteq \{0, 1, \dots, n-2\}$，$|S| = k-1$。给定 $S = \{i_1 < i_2 < \cdots < i_{k-1}\}$，令 $i_0 = -1$、$i_k = n-1$，则第 $t$ 袋为区间 $[i_{t-1}+1,\ i_t]$。这是后续一切推导的载体。
2. **分数分解的推导**：第 $t$ 袋价格为 $w_{l_t} + w_{r_t}$，求和 $\sum_t (w_{l_t} + w_{r_t})$。全部左端点集合 $= \{0\} \cup \{i+1 : i \in S\}$，全部右端点集合 $= \{n-1\} \cup \{i : i \in S\}$，代入即得分解式。**关键在于每个切点 $i$ 恰好贡献两项 $w_i + w_{i+1}$，与袋的边界严丝合缝，无重无漏。**
3. **最大 / 最小独立**：分解式中底座是常数，$f(S) = \sum_{i \in S} \text{pairs}[i]$ 的最大 / 最小是两个互不干扰的选数问题——这正是「求差」而不是「求某个值」的善意：两者可以各贪各的。
4. **排序 / 双堆 / 快速选择的权衡**：排序 $O(n \log n)$ 最简单；$k \ll n$ 时用两个大小为 $k-1$ 的堆各维护前 $k-1$ 大 / 小，$O(n \log k)$；`nth_element` 快速选择 + 部分求和可做到平均 $O(n)$。本题 $n \le 10^5$，排序绰绰有余，**现场首选排序**。
5. **一行做差**：排序后答案可写成 $\sum_{i=0}^{k-2}\left(\text{pairs}[m-1-i] - \text{pairs}[i]\right)$（$m = n-1$），第 $i$ 小与第 $i$ 大配对相减，代码极短且天然处理 $k = 1$（空和为 0）。
6. **溢出**：单个相邻和 $\le 2 \times 10^9$，勉强不超 `int` 上限（$2^{31}-1 \approx 2.147 \times 10^9$），但 $10^5$ 个相邻和求和可达 $2 \times 10^{14}$，必须用 `long long` 承接——题目返回类型本身就是 `long long`，这是提示。

## 5. 正确性证明

**引理 1（切点表示）**：合法分配方案与「从 $n-1$ 个缝隙 $\{0,\dots,n-2\}$ 中选出恰好 $k-1$ 个切点」的集合一一对应。

**证明**：（构造互逆）给定合法分配，相邻两袋之间存在唯一分界缝隙 $i$（左袋形如 $[\,\dots, i]$，右袋形如 $[i+1, \dots\,]$），$k$ 个袋共有 $k-1$ 个分界，收集即得 $S$。反之给定 $S = \{i_1 < \cdots < i_{k-1}\}$，按第 1 点构造 $k$ 个区间：由 $0 \le i_1 < \cdots < i_{k-1} \le n-2$ 知各区间长度 $\ge 1$（非空）且首尾相接覆盖 $[0, n-1]$，是合法分配。两个构造显然互逆。∎

**引理 2（分数分解）**：设切点集 $S$ 对应方案的分数为 $\text{score}(S)$，则

$$\text{score}(S) = w_0 + w_{n-1} + \sum_{i \in S}\left(w_i + w_{i+1}\right).$$

**证明**：第 $t$ 袋 $[l_t, r_t]$ 的价格为 $w_{l_t} + w_{r_t}$，故 $\text{score}(S) = \sum_{t=1}^{k}\left(w_{l_t} + w_{r_t}\right)$。全部左端点恰为多重集 $\{0\} \cup \{i+1 : i \in S\}$：第一袋左端是 $0$；其余每袋左端紧贴其左侧切点。同理全部右端点恰为 $\{n-1\} \cup \{i : i \in S\}$。代入求和即得分解式。∎

**引理 3（选数贪心）**：从 $m$ 个数中选 $r$ 个（$0 \le r \le m$）求和，最大值为最大的 $r$ 个数之和，最小值为最小的 $r$ 个数之和。

**证明**：（交换论证，证最大情形）设某选法 $T$ 不含当前未选的最大可用元素 $x$，而含某个 $y < x$，则把 $y$ 换成 $x$ 后和严格不减。反复交换至不存在这样的对，$T$ 恰为前 $r$ 大，且和单调不减到最大。最小情形对称。∎

**定理**：最大分数 − 最小分数 $=$ $\text{pairs}$ 数组（$\text{pairs}[i] = w_i + w_{i+1}$，共 $n-1$ 个）前 $k-1$ 大之和减前 $k-1$ 小之和。

**证明**：由引理 1，优化变量即切点集 $S$（$|S| = k-1$）；由引理 2，$\text{score}(S) = C + f(S)$，其中常数 $C = w_0 + w_{n-1}$，$f(S) = \sum_{i \in S} \text{pairs}[i]$。由引理 3，$\max_S f = $ 前 $k-1$ 大之和，$\min_S f = $ 前 $k-1$ 小之和。故

$$\max \text{score} - \min \text{score} = \left(C + \max f\right) - \left(C + \min f\right) = \max f - \min f,$$

常数 $C$ 抵消，定理得证。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \log n)$。构造相邻和 $O(n)$；排序 $O(n \log n)$；求前后 $k-1$ 项部分和 $O(k) \subseteq O(n)$。可优化为双堆 $O(n \log k)$ 或快速选择平均 $O(n)$，但本题规模下无必要。
- **空间复杂度**：$O(n)$，存储 $n-1$ 个相邻和。排序为原地，不计递归栈时可视为 $O(1)$ 额外空间（快速选择同理）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long putMarbles(vector<int>& weights, int k) {
        int n = weights.size();
        int m = n - 1;                       // 缝隙数
        vector<long long> pairs(m);
        for (int i = 0; i < m; i++)
            pairs[i] = (long long)weights[i] + weights[i + 1];
        sort(pairs.begin(), pairs.end());
        long long diff = 0;
        for (int i = 0; i < k - 1; i++)      // 第 i 小配第 i 大；k=1 时空循环
            diff += pairs[m - 1 - i] - pairs[i];
        return diff;                          // 底座抵消，无需计算
    }
};
```

### Python

```python
class Solution:
    def putMarbles(self, weights: List[int], k: int) -> int:
        pairs = sorted(a + b for a, b in zip(weights, weights[1:]))
        m = len(pairs)
        return sum(pairs[m - 1 - i] - pairs[i] for i in range(k - 1))
```

> 💡 两个版本都靠「循环上界为 $k-1$」天然处理 $k=1$（空和为 0）；$k=n$ 时前后 $k-1$ 项都取遍全数组，差为 0。若追求 $O(n \log k)$，可用两个大小为 $k-1$ 的堆分别维护前 $k-1$ 大 / 小，注意 $k=1$ 时堆为空要跳过。

## 8. 边界情况与易错点

1. **溢出是头号陷阱**：单个相邻和 $\le 2\times 10^9$，`int` 勉强装得下但只差 $7\%$ 余量；而和式可达 $2\times 10^{14}$，`int` 必炸。C++ 中相邻和在累加前就要转 `long long`，别等求和时才转。
2. **$k = 1$**：不切任何缝隙，min = max，答案 0。循环上界 $k-1 = 0$ 自然处理；若用堆，注意堆大小为 0 时的空操作。
3. **$k = n$**：$n-1$ 个缝隙全选，方案唯一，答案 0。走主流程「前 $n-1$ 大 $=$ 前 $n-1$ 小 $=$ 全部」同样得 0，无需特判。
4. **$n = 1$**：此时必有 $k = 1$，`pairs` 为空。Python 的 `zip(w, w[1:])` 为空、`range(0)` 为空，安全；C++ 循环不执行，安全。
5. **误读价格定义**：袋价格**只含首尾两颗珠子**，中间珠子重量不进分数；单颗珠子成袋时价格 $= 2 w_i$（首尾是同一颗）。此外「$i$ 到 $j$ 都在同袋」就是连续段划分，别想成任意子集。
6. **别上区间 DP**：$O(n^2 k)$ 在 $10^5$ 规模必超时；看到 $n \le 10^5$ 就应锁定线性 / 线性对数做法。
7. **做差时忘了底座抵消也无妨**：若在最大、最小两边都老实加上底座 $w_0 + w_{n-1}$，做差结果不变——但如果题目改问「最大分数」本身，底座就**不能**丢。
8. **排序下标方向**：升序排序后第 $i$ 小是 `pairs[i]`，第 $i$ 大是 `pairs[m-1-i]`（$m = n-1$），一不留神写成 `pairs[n-1-i]` 会差一位。
9. **快速选择的坑**：`nth_element` 只保证第 $k$ 位就位，两侧**无序**，对其做「前缀和」前必须再对两侧各自排序或重新遍历求和——不如直接全排序稳。
