# LeetCode 统计上升四元组 题解

## 1. 题目概述

- **标题 / 题号**：统计上升四元组（#2552，hard）
- **链接**：https://leetcode.cn/problems/count-increasing-quadruplets/
- **来源**：LeetCode 第 330 场周赛 Q4
- **难度**：困难
- **标签**：树状数组、数组、动态规划、枚举、前缀和

**题意**：给定长度为 $n$ 的整数数组 $\text{nums}$，它是 $1$ 到 $n$ 的一个排列。统计满足 $0 \le i < j < k < l < n$ 且

$$\text{nums}[i] < \text{nums}[k] < \text{nums}[j] < \text{nums}[l]$$

的四元组 $(i,j,k,l)$ 的个数。注意值的大小链按位置排布是「小-大-中-最大」：前两个位置 $i,j$ 与后两个位置 $k,l$ 的值**交错**，中间的 $(j,k)$ 恰好构成一个逆序对——本质是统计排列中 **「1-3-2-4」模式**的出现次数。

**约束**：

- $4 \le n \le 4000$
- $1 \le \text{nums}[i] \le n$，$\text{nums}$ 中所有数字互不相同（是排列）

> 💡 读题信号：$n \le 4000$ 的计数题 $\Rightarrow$ 允许 $O(n^2) \approx 1.6 \times 10^7$，排除 $O(n^3)$（$6.4 \times 10^{10}$）；答案是「个数」且可高达 $10^{13}$ 量级 $\Rightarrow$ 返回值必须 64 位整数；值域恰为 $[1,n]$ 的排列 $\Rightarrow$ 值可直接当数组下标，无需离散化；链在中段交叉 $\Rightarrow$ 「枚举中间对 + 乘法原理」是标准切入点（与逆序对计数同族）。

## 2. 示例

**示例 1**

```text
输入：nums = [1,3,2,4,5]
输出：2
解释：(i,j,k,l) = (0,1,2,3)：1 < 2 < 3 < 4 ✓
      (i,j,k,l) = (0,1,2,4)：1 < 2 < 3 < 5 ✓
```

**示例 2**

```text
输入：nums = [1,2,3,4]
输出：0
解释：唯一的位置组合 (0,1,2,3) 满足 2 < 3，即 nums[k] < nums[j] 不成立，
      整个排列没有任何逆序对，答案为 0。
```

**补充示例**

```text
输入：nums = [2,4,1,3,5]
输出：1
解释：(i,j,k,l) = (0,1,3,4)：2 < 3 < 4 < 5 ✓。
      唯一做出贡献的中间对是 (j,k) = (1,3)（nums[j]=4 > nums[k]=3）。
```

## 3. 解题思路

### 3.1 暴力思路：四重循环枚举

最直观的做法是四重循环枚举 $(i,j,k,l)$ 并检查整条链，$O(n^4) \approx 2.6 \times 10^{14}$，完全不可行。

优化一档：枚举 $(i,j,k)$ 后对 $l$ 的计数需要「位置 $>k$ 且值 $> \text{nums}[j]$」的二维信息，若对每对 $(j,k)$ 现数一遍左侧 $i$ 与右侧 $l$，是 $O(n^2)$ 对 $\times O(n) = O(n^3) \approx 6.4 \times 10^{10}$，依然超时。数据范围明确把人推向：**每对 $(j,k)$ 必须 $O(1)$ 地拿到左右两侧的计数**。

### 3.2 核心观察：枚举中间对 (j,k)，乘法原理

![核心观察：枚举中间对(j,k)，左右两侧独立选择（乘法原理）](images/wc330_q4_pair_concept.svg)

把链 $\text{nums}[i] < \text{nums}[k] < \text{nums}[j] < \text{nums}[l]$ 以中间对 $(j,k)$ 为**铰链**拆成左右两段：

- **铰链条件**：$\text{nums}[j] > \text{nums}[k]$——$(j,k)$ 必须是逆序对，否则链的中段 $\text{nums}[k] < \text{nums}[j]$ 断裂；
- **左侧（选 $i$）**：$i < j$ 且 $\text{nums}[i] < \text{nums}[k]$，记方案数为
  $$A(j,k) = \#\{\, i < j : \text{nums}[i] < \text{nums}[k] \,\}\quad(\text{阈值是 } k \text{ 的值})$$
- **右侧（选 $l$）**：$l > k$ 且 $\text{nums}[l] > \text{nums}[j]$，记方案数为
  $$B(j,k) = \#\{\, l > k : \text{nums}[l] > \text{nums}[j] \,\}\quad(\text{阈值是 } j \text{的值})$$

固定 $(j,k)$ 之后，$i$ 只看 $j$ 左边、$l$ 只看 $k$ 右边，**两类选择互不影响**——乘法原理给出该对的贡献 $A(j,k) \times B(j,k)$。于是

$$\text{答案} = \sum_{\substack{j < k \\ \text{nums}[j] > \text{nums}[k]}} A(j,k) \times B(j,k)$$

中间对共 $O(n^2)$ 个，每个若能 $O(1)$ 取得 $A$、$B$，总复杂度即为 $O(n^2)$。

### 3.3 算法流程：双计数增量维护，O(n²) 时间 / O(n) 空间

![算法流程：外层k从右向左扫，入池+标量cnt增量维护](images/wc330_q4_algorithm_flow.svg)

**难点**在于 $A$ 依赖「前缀 $[0,j)$ × 阈值 $\text{nums}[k]$」、$B$ 依赖「后缀 $(k,n)$ × 阈值 $\text{nums}[j]$」，都是区间×值域的二维信息，直接建表要 $O(n^2)$ 空间（$n=4000$ 时约 64MB）。以 $k$ 为**主元**从右往左扫可以把二维压成一维：

1. **维护值域数组** $\text{rightGreater}[v] = \#\{l > k : \text{nums}[l] > v\}$：$k$ 每左移一格，位置 $k+1$ 上的元素 $x = \text{nums}[k+1]$ 进入右侧池——所有 $v < x$ 的 $\text{rightGreater}[v]$ 加一（值域上的**前缀批量加**，每轮 $O(n)$）；
2. **内层 $j$ 从左往右扫**，维护**标量** $\text{cnt} = \#\{i < j : \text{nums}[i] < \text{nums}[k]\}$：整个内层循环中阈值 $\text{nums}[k]$ 固定不变，所以只需一个标量——$j$ 每右移一格，刚离开锚点的 $\text{nums}[j]$ 成为新的候选 $i$，若 $\text{nums}[j] < \text{nums}[k]$ 则 $\text{cnt}$ 加一（$O(1)$）；
3. **命中即累加**：当 $\text{nums}[j] > \text{nums}[k]$（铰链成立）时，
   $$\text{ans} \mathrel{+}= \text{cnt} \times \text{rightGreater}[\text{nums}[j]]$$

### 3.4 示例演算

![示例演算：nums=[1,3,2,4,5]的唯一逆序对贡献1×2=2](images/wc330_q4_example_walkthrough.svg)

以 $\text{nums} = [1,3,2,4,5]$ 为例：全部 $(j,k)$ 对中只有 $(1,2)$ 满足 $\text{nums}[j] = 3 > 2 = \text{nums}[k]$：

- **左侧**：$i < 1$ 且 $\text{nums}[i] < \text{nums}[k] = 2$，候选 $\{0\}$（$1 < 2$ ✓）$\Rightarrow A = 1$；
- **右侧**：$l > 2$ 且 $\text{nums}[l] > \text{nums}[j] = 3$，候选 $\{3, 4\}$（$4, 5$ 均 $> 3$ ✓）$\Rightarrow B = 2$；
- **贡献** $= 1 \times 2 = 2$，对应四元组 $(0,1,2,3)$ 与 $(0,1,2,4)$，与示例 1 的解释吻合。

其余 $(j,k)$ 对（如 $(0,1),(0,2),(1,3)$ 等）都是正序对，链在中段断裂贡献 0；示例 2 的 $[1,2,3,4]$ 没有任何逆序对，答案 0。

## 4. 算法细节

1. **循环边界**：外层 $k$ 从 $n-2$ 递减到 $2$——$k \le n-2$ 保证右边还有位置放 $l$，$k \ge 2$ 保证左边能取到完整的 $i < j \le k-1$（$j \ge 1$ 使 $i = 0$ 可选）；内层 $j$ 从 $1$ 到 $k-1$。四元组中的 $(j,k)$ 必然落在这个范围内，不会漏。
2. **入池时机**：处理 $k$ **之前**先把 $\text{nums}[k+1]$ 加入 $\text{rightGreater}$（首轮 $k = n-2$ 恰好只入池 $\text{nums}[n-1]$）。若误把入池放在循环末尾（加 $\text{nums}[k]$），锚点自己会被算进右侧池，$B$ 虚高。
3. **cnt 初始化**：内层 $j$ 从 $1$ 起扫，$i = 0$ 的贡献 $[\text{nums}[0] < \text{nums}[k]]$ 要预先折入初始值；漏掉会系统性少算 $A$。
4. **前缀批量加的代价**：入池循环共执行 $\sum_{k} (\text{nums}[k+1] - 1) \le \frac{n(n+1)}{2} \approx \frac{n^2}{2}$ 次（排列保证值均匀），与内层循环总量 $\sum_k (k-1) \approx \frac{n^2}{2}$ 同量级，两者合计约 $n^2$。
5. **为什么不用树状数组**：$\text{rightGreater}$ 的操作模式是「值域前缀区间加 + 单点查」。换成差分 + 树状数组（单点加、前缀和查询）可把空间保持 $O(n)$ 并支持在线修改，但内层每对 $(j,k)$ 一次查询变 $O(\log n)$，总量 $O(n^2 \log n) \approx 2 \times 10^8$ 反而更慢——本题静态、值域小，朴素数组 + 批量循环是最优搭配。
6. **替代实现（二维预处理）**：官方题解一类的做法是定义 $\text{less}[j][v] = \#\{i<j : \text{nums}[i]<v\}$，按 $j$ 递推 $\text{less}[j][v] = \text{less}[j-1][v] + [\text{nums}[j-1] < v]$，再枚举 $(j,k)$ 查表配对对称的 $\text{greater}$ 表——$O(n^2)$ 时间 / $O(n^2)$ 空间（16M 个 `int` 约 64MB，需开 `short` 或确认内存限制）。本文解法时间相同、空间降到 $O(n)$。
7. **严格不等号**：链上三处比较、$A/B$ 计数、铰链判断全部严格。排列中无重复值，相等情形不出现；但 `if / else if` 的结构天然兼容一般数组（相等时既不进 $A$ 也不进 $B$、铰链不成立），对拍验证也确认了重复值下依然正确。

## 5. 正确性证明

**引理 1（铰链分解）**：设 $Q$ 为全体上升四元组，$P$ 为全体满足 $1 \le j < k \le n-2$、$\text{nums}[j] > \text{nums}[k]$、$0 \le i < j$ 且 $\text{nums}[i] < \text{nums}[k]$、$k < l < n$ 且 $\text{nums}[l] > \text{nums}[j]$ 的四元下标组 $(j,k,i,l)$，则 $Q$ 与 $P$ 存在双射。

**证明**：正向：$(i,j,k,l) \in Q$ 时，由 $i < j$ 知 $j \ge 1$，由 $l > k$ 知 $k \le n-2$；链的中段给出 $\text{nums}[j] > \text{nums}[k]$，两端给出 $\text{nums}[i] < \text{nums}[k]$ 与 $\text{nums}[l] > \text{nums}[j]$，故 $(j,k,i,l) \in P$。反向：$P$ 的条件直接拼出 $\text{nums}[i] < \text{nums}[k]$、$\text{nums}[k] < \text{nums}[j]$、$\text{nums}[j] < \text{nums}[l]$ 与 $i < j < k < l$，故 $(i,j,k,l) \in Q$。两个方向的映射都保持全部四个下标不变，互为逆映射。∎

**推论（乘法原理）**：$\text{答案} = \sum_{\text{nums}[j] > \text{nums}[k]} A(j,k) \times B(j,k)$。固定 $(j,k)$ 后，合法的 $i$ 全在 $j$ 左侧、合法的 $l$ 全在 $k$ 右侧，两类选取无任何耦合，独立组合共 $A \times B$ 种；不同 $(j,k)$ 由四元组唯一确定（引理 1 的分类），求和不重不漏。∎

**引理 2（增量不变量）**：(a) 外层处理 $k$ 时（入池之后、内层之前），对一切 $v \in [1,n]$ 有 $\text{rightGreater}[v] = \#\{l : k < l < n,\ \text{nums}[l] > v\}$；(b) 内层扫描到 $j$ 时（比较之前），$\text{cnt} = \#\{i : 0 \le i < j,\ \text{nums}[i] < \text{nums}[k]\}$。

**证明**：(a) 对 $k$ 从 $n-2$ 到 $2$ 归纳。$k = n-2$ 时入池 $\text{nums}[n-1]$，$\text{rightGreater}[v] = [\text{nums}[n-1] > v]$，池恰为 $\{n-1\}$，成立。设处理 $k+1$ 时成立（池为 $\{k+2, \dots, n-1\}$），处理 $k$ 时先入池 $x = \text{nums}[k+1]$：$v < x$ 的分量加 $1$ 恰是位置 $k+1$ 对阈值 $v$ 的贡献 $[x > v]$，其余分量不变，故不变量对池 $\{k+1, \dots, n-1\}$ 成立。(b) 对 $j$ 从 $1$ 到 $k-1$ 归纳。$j = 1$ 时初值 $\text{cnt} = [\text{nums}[0] < \text{nums}[k]] = \#\{i < 1 : \text{nums}[i] < \text{nums}[k]\}$，成立。设 $j$ 时成立；处理完 $j$ 后，位置 $j$ 成为下一轮（$j+1$）的候选 $i$，增量 $[\text{nums}[j] < \text{nums}[k]]$ 由 `else if` 分支精确执行，故 $j+1$ 时仍成立。∎

**定理**：算法返回上升四元组的个数。

**证明**：内层在 $(j,k)$ 处仅当 $\text{nums}[j] > \text{nums}[k]$ 时累加 $\text{cnt} \times \text{rightGreater}[\text{nums}[j]]$。由引理 2，该项等于 $\#\{i < j : \text{nums}[i] < \text{nums}[k]\} \times \#\{l > k : \text{nums}[l] > \text{nums}[j]\} = A(j,k) \times B(j,k)$。累加范围为 $2 \le k \le n-2$、$1 \le j \le k-1$ 且铰链成立的对，恰覆盖 $P$ 中所有 $(j,k)$（$j \ge 1, k \le n-2$ 由引理 1 给出，不在此范围的对不可能出现在任何四元组中）。由引理 1 推论，该和等于 $|Q|$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n^2)$。外层 $k$ 共 $O(n)$ 轮，每轮两件事：入池的前缀批量加 $\sum_k (\text{nums}[k+1]-1) \le \frac{n(n+1)}{2} \approx \frac{n^2}{2}$ 次加法，内层 $j$ 扫描共 $\sum_k (k-1) \approx \frac{n^2}{2}$ 次比较与累加；合计约 $n^2 \approx 1.6 \times 10^7$ 次基本操作（$n = 4000$ 时 C++ 数十毫秒，Python 实测约 1 秒出头）。
- **空间复杂度**：$O(n)$。仅一个值域数组 $\text{rightGreater}$ 与常数个标量，显著优于二维预处理版本的 $O(n^2)$（约 64MB）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long countQuadruplets(vector<int>& nums) {
        int n = nums.size();
        vector<int> rightGreater(n + 2);          // rightGreater[v] = #{l>k : nums[l]>v}
        long long ans = 0;
        for (int k = n - 2; k >= 2; k--) {
            int x = nums[k + 1];                  // 位置 k+1 进入右侧池
            for (int v = 1; v < x; v++) rightGreater[v]++;
            int nk = nums[k];
            int cnt = nums[0] < nk;               // j=1 时 #{i<1 : nums[i]<nk}
            for (int j = 1; j < k; j++) {
                if (nums[j] > nk)
                    ans += (long long)cnt * rightGreater[nums[j]];
                else if (nums[j] < nk)
                    cnt++;                        // nums[j] 成为后续 j 的候选 i
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def countQuadruplets(self, nums: List[int]) -> int:
        n = len(nums)
        right_greater = [0] * (n + 2)             # right_greater[v] = #{l>k : nums[l]>v}
        ans = 0
        for k in range(n - 2, 1, -1):
            x = nums[k + 1]                       # 位置 k+1 进入右侧池
            for v in range(1, x):
                right_greater[v] += 1
            nk = nums[k]
            cnt = 1 if nums[0] < nk else 0        # j=1 时 #{i<1 : nums[i]<nk}
            for j in range(1, k):
                nj = nums[j]
                if nj > nk:
                    ans += cnt * right_greater[nj]
                elif nj < nk:
                    cnt += 1                       # nums[j] 成为后续 j 的候选 i
        return ans
```

> 💡 两个版本已对拍验证：官方两例、补充例 $[2,4,1,3,5] \to 1$、$n \le 8$ 的**全部排列**、3000 组随机排列以及含重复值的随机数组，均与 $O(n^4)$ 暴力一致。

## 8. 边界情况与易错点

1. **溢出是头号陷阱**：四元组总数上界 $\binom{4000}{4} \approx 1.07 \times 10^{13}$，实测 $n = 4000$ 的随机排列答案约 $4.3 \times 10^{11}$，远超 `int`（$2^{31}-1 \approx 2.1 \times 10^9$）。单个累加项 $\text{cnt} \times \text{rightGreater}[\cdot] \le n^2 = 1.6 \times 10^7$ 不炸，但**累加和**必炸——C++ 累加前要转 `long long`。Python 无此虞。
2. **k 的循环边界与方向**：从 $n-2$ **递减**到 $2$。$k = n-1$ 右边没有 $l$，$k \le 1$ 左边放不下 $i < j$。Python 是 `range(n - 2, 1, -1)`，终点 $1$（不含）即 $k$ 最小取 $2$。
3. **入池时机**：先入池 $\text{nums}[k+1]$ 再跑内层；首轮入池的是 $\text{nums}[n-1]$。顺序颠倒会把锚点或漏或多算进 $B$。
4. **cnt 初始化**：内层从 $j=1$ 起扫，$i=0$ 的贡献要预先折入初值，漏掉后每个 $(j,k)$ 的 $A$ 都少 $[\text{nums}[0] < \text{nums}[k]]$。
5. **阈值交叉别搞反**：$A$ 的阈值是 $\text{nums}[k]$（$j$ 左侧小于 **k 的值**），$B$ 的阈值是 $\text{nums}[j]$（$k$ 右侧大于 **j 的值**）——两侧阈值恰好都取自**对面**锚点，这是本题最独特的记忆点，也是对拍时最值得盯的量。
6. **严格不等号**：链上比较、$A/B$ 计数、铰链判断共五处全部严格。排列无重复值，等号不出现；`if / else if` 结构对一般数组的相等情形也天然安全（相等不进任何计数、铰链不成立）。
7. **二维预处理版本的内存**：$\text{less}[j][v]$ 表 16M 个 `int` 约 64MB，LeetCode 可过但接近上限，稳妥起见开 `short`（值 $\le 4000 < 32767$）；本文 $O(n)$ 版本无此虑。
8. **最小规模 $n = 4$**：$k$ 只取 $2$、$j$ 只取 $1$、$i = 0$、$l = 3$，恰好检验整条链，循环边界自然覆盖，无需特判。

**延伸思考**：若改成**非严格**版本（四处 $\le$），只需同步放宽五处比较符，但重复值时相等元素的归属要逐一核对（链条件与 $A/B$ 计数必须一致放宽）。若 $\text{nums}$ 不是排列、值域达 $10^9$，先离散化，「前缀批量加」依然成立。若要求支持在线插入删除，就把 $\text{rightGreater}$ 换成差分 + 树状数组（区间加、单点查各 $O(\log n)$），总复杂度 $O(n^2 \log n)$ 换来动态性。更长的交错模式（如「1-3-2-4-5」五元模式）一般没有这样干净的乘法分解，需按模式长度做 DP 并配合值域树状数组逐长度扩展，复杂度整体上一档。
