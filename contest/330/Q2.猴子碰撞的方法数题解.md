# LeetCode 猴子碰撞的方法数 题解

## 1. 题目概述

- **标题 / 题号**：猴子碰撞的方法数（#2550，medium）
- **链接**：https://leetcode.cn/problems/count-collisions-of-monkeys-on-a-polygon/
- **来源**：LeetCode 第 330 场周赛 Q2
- **难度**：中等
- **标签**：数学、组合计数、容斥原理（补集计数）、快速幂

**题意**：一个正凸多边形有 $n$ 个顶点，按顺时针编号 $0$ 到 $n-1$，每个顶点上**恰好一只猴子**。所有猴子**同时**移动一步到相邻顶点，方向自选：

- 顺时针：$(i+1) \bmod n$，或
- 逆时针：$(i-1+n) \bmod n$。

若移动后**至少有两只猴子停在同一个顶点**，或**有两只猴子在一条边上相交**，则发生碰撞。求至少发生一次碰撞的移动方法数，对 $10^9+7$ 取模。

**约束**：

- $3 \le n \le 10^9$

> 💡 读题信号：计数对象是「至少一次碰撞」，正面分类（同顶相撞 / 边上相交 / 多对同时撞）极易重漏；而 $n \le 10^9$ 说明答案必然有封闭形式且需要 $O(\log n)$ 的幂运算——**正难则反 + 快速幂**的组合信号非常明确。

## 2. 示例

**示例 1**

```text
输入：n = 3
输出：6
解释：共 2³ = 8 种移动方式，其中 6 种发生碰撞。
  例如「猴 1 顺、猴 2 逆、猴 3 顺」：猴 1 与猴 2 在边 (1,2) 上相向相遇。
```

**示例 2**

```text
输入：n = 4
输出：14
解释：共 2⁴ = 16 种移动方式，其中 14 种发生碰撞。
```

**补充示例**

```text
输入：n = 5
输出：30
解释：2⁵ − 2 = 30，与「不碰撞仅全顺 / 全逆 2 种」一致。
```

## 3. 解题思路

### 3.1 暴力思路：枚举 $2^n$ 种方向组合逐一判定

每只猴子 2 个选择，总方案 $2^n$。最直白的做法是枚举每个方向串，模拟移动后判定是否碰撞。

两条路都堵死：

1. **规模上不可行**：$n \le 10^9$，$2^n$ 是约 $3\times 10^8$ 位的天文数字，连枚举的边都摸不到；
2. **判定本身繁琐**：碰撞分「同顶」「边交」「多对同时」等情形，同一方案里多个碰撞事件还容易重复计数——即使 $n = 20$ 让你写对拍，判定代码也容易写漏。

比赛现场的正确节奏是：**手玩 $n=3$（8 种）、$n=4$（16 种）全枚举**，观察哪些串不碰撞——一眼看出只有「全顺」「全逆」两个幸存者，规律立现。

### 3.2 核心观察：正难则反——不碰撞 $\iff$ 全员同向

![核心观察：不碰撞⟺全员同向，混向环形必有一条相向边](images/wc330_q2_complement_concept.svg)

**正难则反**：与其数「至少一次碰撞」，不如数「一次也不碰撞」，再用总数减去。

**关键定理**：一个方案不碰撞 $\iff$ 全部猴子朝同一方向移动。

分两个方向看：

- **$\Longleftarrow$（全员同向则安全）**：全顺时猴 $i$ 去 $(i+1) \bmod n$，这是顶点编号的一次**循环移位**——每个顶点恰好接收一只猴子，无同顶；每条边至多被一只猴子**单向**穿越，无相向而行。全逆是对称的反向循环移位。两种方案都安全。
- **$\Longrightarrow$（混向则必撞）**：把方向排成**环形 0/1 串**（顺为 1、逆为 0）。若不全同，串中既有 1 又有 0。绕环一圈必然出现 **1→0 转变**（否则 1 一旦出现就沿环传到底，得全 1，矛盾）。在任一 1→0 转变处：猴 $i$ 顺时针沿边 $(i, i+1)$ 走向 $i+1$，猴 $i+1$ 逆时针沿**同一条边**走向 $i$——两只猴子**相向而行，必在边内相遇**，碰撞。

> ⚠️ 注意「0→1 转变」不撞：那种边上两猴**背向离开**（猴 $i$ 逆去 $i-1$、猴 $i+1$ 顺去 $i+2$）。所以论证必须锁定 1→0 转变，不能任取一个方向改变处。环形串里 1→0 与 0→1 转变数相等且 $\ge 1$，前者一定存在。

于是不碰撞的方案**恰好 2 种**（全顺、全逆），答案为：

$$\text{碰撞方法数} = 2^n - 2 \pmod{10^9+7}$$

### 3.3 算法流程：补集计数 + 快速幂

![算法流程：正难则反数不碰撞，快速幂算2^n mod p](images/wc330_q2_algorithm_flow.svg)

流程是一条线性链，无分支循环：

1. 总方案 $2^n$（每猴独立 2 选 1）；
2. 正难则反，数「不碰撞」= 全员同向 = 2 种；
3. 答案 $= 2^n - 2$；
4. $n \le 10^9$：用**快速幂**（二进制拆分逐位平方）在 $O(\log n)$ 内求 $2^n \bmod p$；
5. 输出 $(2^n \bmod p - 2 + p) \bmod p$（加 $p$ 修负）。

### 3.4 示例演算

![示例演算：n=3全枚举验证+快速幂求2^n mod p](images/wc330_q2_example_walkthrough.svg)

- **$n=3$**：全枚举 8 个方向串，仅 $\to\to\to$（全顺）与 $\leftarrow\leftarrow\leftarrow$（全逆）安全，其余 6 种全撞（每个混向串必有相向边）。碰撞数 $6 = 2^3 - 2$，与示例 1 吻合；
- **$n=4$**：$2^4 - 2 = 14$，与示例 2 吻合；
- **快速幂演算 $n=5=101_2$**：$base$ 依次为 $2 \to 4 \to 16$，bit0=1 时 $ans = 1 \times 2 = 2$，bit1=0 跳过，bit2=1 时 $ans = 2 \times 16 = 32$，即 $2^5 \bmod p = 32$，答案 $32 - 2 = 30$。

## 4. 算法细节

1. **计数模型**：一个移动方案 $=$ 环形方向串 $(d_0, d_1, \dots, d_{n-1}) \in \{0,1\}^n$，猴子相互独立，总数恰为 $2^n$。题目所求是「至少一对碰撞」的方案数，按**方案**计数而非按碰撞对计数——这决定了补集相减的对象是「零碰撞方案」。
2. **不碰撞的完整刻画**：安全方案 $=$ $\{$全顺$\} \cup \{$全逆$\}$。$n \ge 3$ 时这是**两个不同**的方案：若全顺与全逆相同，则对每个 $i$ 有 $(i+1) \equiv (i-1) \pmod n$，即 $n \mid 2$，与 $n \ge 3$ 矛盾。
3. **快速幂二进制拆分**：写 $n = \sum_k b_k 2^k$，则 $2^n = \prod_k \left(2^{2^k}\right)^{b_k}$。实现上维护 $base = 2^{2^k} \bmod p$，每轮自乘平方；当 $b_k = 1$ 时把它累乘进 $ans$。全程取模，中间乘积不超过 $(10^9)^2 \approx 10^{18} < 2^{63}$。
4. **为什么不能先算 $2^n$ 再取模**：$2^{10^9}$ 约有 $3\times 10^8$ 个十进制位，构造与存储都是天文代价；模意义下逐步约减到 $O(\log n)$ 次小乘法即可。
5. **修负**：数学上 $2^n - 2 \ge 0$（$n \ge 3$），但 $(2^n \bmod p)$ 可能落在 $[0, 2)$，C++ 直接相减会得到负数，须 `(ans - 2 + MOD) % MOD`；Python 的 `%` 天然非负，可直接减。
6. **比赛策略**：先手玩 $n=3$ 确认「只有 2 个安全串」，再套快速幂模板，全程 5 分钟内可 AC；若对「混向必撞」没把握，可写 $n \le 20$ 的暴力对拍验证 $2^n - 2$。

## 5. 正确性证明

**引理 1（同向安全）**：全员顺时针（或全员逆时针）的方案不发生碰撞。

**证明**：全顺时，猴 $i$ 的目标为 $(i+1) \bmod n$。映射 $\sigma(i) = (i+1) \bmod n$ 是顶点集 $\{0,\dots,n-1\}$ 到自身的**双射**（循环移位），故每个顶点恰好被一只猴子占据，无同顶碰撞。边上相交方面： monkeys 同时出发、同速行进，边 $(i, i+1)$ 上只有猴 $i$ 顺向穿越，任两条移动路径不会在边的内部相遇。全逆时 $\sigma(i) = (i-1+n) \bmod n$ 同理。∎

**引理 2（转变存在性）**：环形 0/1 串 $(d_0,\dots,d_{n-1})$（下标模 $n$）若不全相同，则存在下标 $i$ 使 $d_i = 1$ 且 $d_{i+1} = 0$（1→0 转变）。

**证明**：反设不存在 1→0 转变，即对一切 $i$，$d_i = 1 \Rightarrow d_{i+1} = 1$。串中至少有一个 1（不全同且不全 0 时；若全 0 则已与「不全同」矛盾，故确有 1）。从某个 $d_j = 1$ 出发反复应用该蕴含，沿环得 $d_{j+1} = d_{j+2} = \cdots = 1$，绕完一圈回到 $d_j$，得**全部**为 1，与「不全同」矛盾。∎

**引理 3（混向必撞）**：若方向串不全同，则方案必发生碰撞。

**证明**：由引理 2 取 1→0 转变处 $i$：$d_i = 1$（猴 $i$ 顺时针，沿边 $(i, i+1)$ 从 $i$ 走向 $i+1$），$d_{i+1} = 0$（猴 $i+1$ 逆时针，沿同一条边 $(i, i+1)$ 从 $i+1$ 走向 $i$）。两只猴子同时出发、速度相同、路径为同一条线段且方向相反，必在时刻 $t = 1/2$ 于边的中点相遇——发生「相交在一条边上」的碰撞。∎

**定理**：碰撞方案数为 $2^n - 2$（模 $10^9+7$ 意义下）。

**证明**：方案总数为 $2^n$（每猴独立 2 选 1）。由引理 1，全顺与全逆这 2 个方案不碰撞；由引理 3 的逆否命题（不碰撞 $\Rightarrow$ 全员同向），不碰撞方案**只能是**这 2 个。又 $n \ge 3$ 时全顺 $\ne$ 全逆（见 §4 第 2 点），故不碰撞方案恰 2 种。按补集相减，碰撞方案数 $= 2^n - 2$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(\log n)$。快速幂循环次数为 $n$ 的二进制位数 $\lfloor \log_2 n \rfloor + 1$；$n \le 10^9$ 时约 30 次乘法取模。注意 $O(n)$ 的线性累乘在 $n = 10^9$ 下约 $10^9$ 次乘法，同样会超时——**对数级不是优化，是门槛**。
- **空间复杂度**：$O(1)$。仅 `ans`、`base` 等常数个变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int monkeyMove(int n) {
        const long long MOD = 1e9 + 7;
        long long ans = 1, base = 2;
        while (n) {
            if (n & 1) ans = ans * base % MOD;  // 该二进制位为 1，累乘
            base = base * base % MOD;           // 平方，供下一位使用
            n >>= 1;
        }
        return (ans - 2 + MOD) % MOD;           // 2^n - 2，加 MOD 防负数
    }
};
```

### Python

```python
class Solution:
    def monkeyMove(self, n: int) -> int:
        MOD = 10**9 + 7
        return (pow(2, n, MOD) - 2) % MOD
```

> 💡 Python 的三参数内置 `pow(2, n, MOD)` 底层即快速幂，一行搞定；C++ 版注意中间乘积用 `long long` 承接，`int * int` 会溢出。

## 8. 边界情况与易错点

1. **别直接算 $2^n$ 再减**：$2^{10^9}$ 有约 $3\times 10^8$ 位，C++ 里连 `long long` 都远远装不下（$2^{62}$ 就到顶），必须在模意义下用快速幂逐步约减。
2. **修负不能省（C++）**：$(2^n \bmod p)$ 可能小于 2（例如 $2^n \equiv 0 \text{ 或 } 1 \pmod p$ 的情形），`ans - 2` 会得到负数，必须 `+ MOD` 再取模；Python `%` 天然非负可省。
3. **中间乘法溢出**：`base * base` 可达 $(10^9)^2 \approx 10^{18}$，必须 `long long`；两个 `int` 相乘在赋值给 `long long` 前就已按 `int` 溢出，写 `long long ans, base` 声明。
4. **误把「0→1 转变」当碰撞**：只有 1→0 转变（猴 $i$ 顺、猴 $i+1$ 逆）才相向；0→1 转变处两猴背向离开，不在这条边上相遇。证明「混向必撞」时若随手取一个方向改变处推「相向」，是常见伪证。
5. **误以为猴子能「错开」**：题设所有猴子同时出发且各走一条完整边，速度相同，相向必在边中点相遇——不存在「先后的躲闪」。
6. **$n \ge 3$ 的隐含作用**：保证每个顶点的两个邻点不同（每猴确有 2 个**不同**选择），且全顺、全逆是两个**不同**方案；$n=2$ 时公式会失效（退化为同一种换位），这也是题目约束从 3 起的原因。
7. **最小样例自检**：$n=3$ 应输出 $6 = 2^3-2$；若写成 $2^n - 2$ 却忘了取模或修负，小样例可能恰好对、大样例炸——务必用 $n=3,4$ 双样例验证。
8. **别按碰撞对计数**：题目数的是「方案数」（至少一次碰撞的方案），不是碰撞发生的总次数；混向方案里可能同时有多对相向边（如 $n=6$ 的串 $111000$ 有 1 处、$101010$ 有 3 处），都只算「1 个碰撞方案」。
