# LeetCode 关闭分部的可行集合数目 题解

## 1. 题目概述

- **标题 / 题号**：关闭分部的可行集合数目（#2959，hard）
- **链接**：https://leetcode.cn/problems/number-of-possible-sets-of-closing-branches/
- **来源**：LeetCode 第 119 场双周赛 Q4
- **难度**：困难
- **标签**：位运算、图、枚举、最短路、堆（优先队列）

**题意**：公司有 $n$ 个分部，一些分部之间有带权无向道路（可能有重边），初始时所有分部两两可达。公司要**关闭**其中任意个分部（也可以一个不关），要求剩下的分部之间仍然两两可达，且任意两个剩余分部之间的**距离**（最短路长度）不超过 `maxDistance`。关闭一个分部后，与它相连的道路全部不可通行。求满足条件的**关闭方案数**（不同的关闭集合算不同方案；全部关闭也是方案）。

**约束**：

- $1 \le n \le 10$
- $1 \le \textit{maxDistance} \le 10^5$
- $0 \le \textit{roads.length} \le 1000$
- $0 \le u_i, v_i \le n - 1$，$u_i \ne v_i$，$1 \le w_i \le 1000$
- 一开始所有分部两两可达

## 2. 示例

**示例 1**

```text
输入：n = 3, maxDistance = 5, roads = [[0,1,2],[1,2,10],[0,2,10]]
输出：5
解释：可行的关闭集合：{2}（剩 0,1，距离 2）、{0,1}（剩 2）、
      {1,2}（剩 0）、{0,2}（剩 1）、{0,1,2}（全关）。
      注意全开不合法：0 到 2 的最短路为 10 > 5。
```

**示例 2**

```text
输入：n = 3, maxDistance = 5, roads = [[0,1,20],[0,1,10],[1,2,2],[0,2,2]]
输出：7
解释：全开时 0↔1 走 0-2-1，距离 2+2 = 4 ≤ 5，合法；重边取较短的那条。
```

**示例 3**

```text
输入：n = 1, maxDistance = 10, roads = []
输出：2
解释：不关（剩 {0}）与全关（剩空集）都合法——没有点对需要检查。
```

## 3. 解题思路

### 3.1 暴力思路

方案总数就是所有关闭集合的个数，至多 $2^{10} = 1024$ 个，**枚举本身就是完备的**。真正的子问题只有一个：给定「保留哪些分部」，如何判定「两两可达且最远距离 $\le \textit{maxDistance}$」。对每个候选集合：

- 只保留**两端都在集合内**的道路（重边取最小），得到诱导子图；
- 判定连通性；
- 计算所有保留点对的最短路并检查最大值。

把这三件事写对、写快，题目就解完了。

### 3.2 核心观察：$n \le 10$ → 子集枚举 + Floyd 是绝配

![核心思路：枚举保留集合，Floyd 只在保留点内中转](images/bw119_q4_enum_floyd.svg)

- **枚举侧**：$n \le 10$ 意味着「保留哪些点」可以用一个 10 位掩码表示，$2^n$ 个掩码每个独立判定，$1024$ 次判定毫无压力；
- **判定侧**：点数 $\le 10$，直接跑 $O(n^3)$ 的 **Floyd-Warshall** 求全源最短路最省事——比每个源点跑一次 Dijkstra 代码短、常数小，还**天然顺带判连通**（距离为 $\infty$ 即不连通）；
- **关闭与保留互补**：枚举「保留集合」或「关闭集合」完全等价（二者互补且双射），按保留集合枚举可以直接把关闭的点从图中「抠掉」。

> 💡 一步到位的写法：邻接矩阵初始化为 $\infty$（对角线为 0），只用保留点作 Floyd 的**中转点 $k$**；最后检查所有保留点对 $d[i][j] \le \textit{maxDistance}$——$\infty$（不连通）自动被判为不合法，无需单独写连通性检查。

### 3.3 算法流程

```text
ans = 0
for open in 0 .. 2^n - 1:            # open 的第 i 位 = 1 表示分部 i 保留
    初始化 d[i][j] = INF，d[i][i] = 0（仅保留点）
    for (u, v, w) in roads:
        若 u、v 都保留 且 w < d[u][v]:   # 重边取最小
            d[u][v] = d[v][u] = w
    Floyd：只用保留点 k 作中转
    若所有保留点对 (i < j) 均满足 d[i][j] <= maxDistance:
        ans += 1                      # 剩 0/1 个点时无点对，天然合法
返回 ans
```

### 3.4 示例演算

![示例 1 的图与几个掩码的判定](images/bw119_q4_example_graph.svg)

以示例 1（$n = 3$，`maxDistance = 5`）为例，边为 $0\text{-}1:2$、$1\text{-}2:10$、$0\text{-}2:10$：

| 保留集合 | 距离矩阵（保留点间） | 最远距离 | 判定 |
|----------|----------------------|----------|------|
| $\{0,1,2\}$ | $d_{01}=2,\ d_{02}=10,\ d_{12}=10$ | 10 | ✗（> 5） |
| $\{0,1\}$ | $d_{01}=2$ | 2 | ✓ |
| $\{0,2\}$ | $d_{02}=10$ | 10 | ✗ |
| $\{1,2\}$ | $d_{12}=10$ | 10 | ✗ |
| $\{0\},\{1\},\{2\},\varnothing$ | 无点对 | — | ✓（三个单点 + 空集全部合法） |

数一下：合法的保留集合为 $\{0,1\},\{0\},\{1\},\{2\},\varnothing$，共 5 个，与输出一致（取补集即得示例解释中的 5 个关闭集合）。

![示例 2：重边取最短 + Floyd 中转带来的捷径](images/bw119_q4_floyd_matrix.svg)

示例 2（`maxDistance = 5`）中全开掩码的演算：$0\text{-}1$ 有重边 $20, 10$，取 $10$；Floyd 以 $2$ 为中转后 $d_{01} = \min(10,\ 2 + 2) = 4 \le 5$——**全开也合法**，这正是「两两可达必须经中转」的典型，也是 Floyd 相比「直接看边」的价值所在。该输入最终 7 个掩码全部合法。

## 4. 算法细节

1. **掩码语义**：`open >> i & 1 == 1` 表示分部 $i$ 保留。枚举范围 $[0, 2^n)$，空集（全关）与全集（全开）都自然包含。
2. **建矩阵时先看两端**：道路 $(u, v, w)$ 仅当 $u$、$v$ 都保留才进入矩阵；重边通过 `w < d[u][v]` 判断取最小。**顺序**：先初始化 $\infty$ 与对角 0，再松弛边。
3. **Floyd 的中转点裁剪**：三层循环里对 $k$（以及 $i, j$）加 `open >> x & 1` 判断，等价于只在诱导子图上跑；配合 `d[i][k] == INF` / `d[k][j] == INF` 的跳过，避免 $\infty$ 参与加法。
4. **INF 取值**：真实路径长 $\le (n-1) \cdot w_{\max} = 9 \times 1000 = 9000$，取 $\text{INF} = 10^9$ 既远大于任何真实值，相加也不会溢出 `int`（代码中已对 $\infty$ 短路，双保险）。
5. **合法性检查**：只查 $i < j$ 的保留点对，$\infty > \textit{maxDistance}$ 自动覆盖「不连通」情形；剩 0 个或 1 个点时点对集合为空，直接合法——**全关方案与只关剩一个的方案绝不能漏**（示例 3 中答案为 2 就是考这个）。
6. **复杂度账**：每个掩码：建矩阵 $O(m)$ + Floyd $O(n^3)$，总计 $2^n \cdot (m + n^3) \approx 1024 \times (1000 + 1000) \approx 2 \times 10^6$，瞬间跑完。

## 5. 正确性证明

**引理 1（判定的充要条件）**：保留集合 $S$ 可行 $\iff$ 诱导子图 $G[S]$（只含两端都在 $S$ 内的道路，重边取最小权）中任意两点可达，且所有点对最短路 $\le \textit{maxDistance}$；$|S| \le 1$ 时恒可行。

**证明**：关闭分部后其关联道路不可通行，故剩余分部之间的可行路径**恰好**是 $G[S]$ 中的路径；距离即 $G[S]$ 中的最短路长。$|S| \le 1$ 时没有点对需要满足约束，条件空真。∎

**引理 2（Floyd 在裁剪中转点后仍正确）**：只枚举 $S$ 内的点作中转，最终 $d[i][j]$ 等于 $G[S]$ 中 $i$ 到 $j$ 的最短路长（不可达为 $\text{INF}$）。

**证明**：Floyd 的标准不变式为：处理完中转点集合 $\{k_0, k_1, \dots\}$ 的前缀后，$d[i][j]$ 是**仅允许已处理中转点**的最短路。$G[S]$ 中最短路的中转点必然全部属于 $S$（路径本身在 $G[S]$ 内），故遍历完 $S$ 内全部中转点后，$d[i][j]$ 收敛到 $G[S]$ 的真实最短路。用 $S$ 之外的点中转反而会引入「被关闭的道路」，被裁剪掉恰是所需。∎

**定理**：算法返回可行的关闭方案数。

**证明**：保留集合与关闭集合通过按位取反双射，故「可行关闭方案数 = 可行保留集合数」。算法枚举所有 $2^n$ 个保留集合，每个恰好被引理 1、2 的判定处理一次：判定为真则计数。枚举完备、判定与题意等价、互不重复，故计数正确。∎

## 6. 复杂度分析

- **时间**：$O(2^n \cdot (m + n^3))$。代入上界 $n = 10$、$m = 1000$：$2^{10} \times (1000 + 10^3) \approx 2 \times 10^6$；其中建矩阵扫一遍 `roads` 与 Floyd 三层循环各占一半。
- **空间**：$O(n^2)$，即每个掩码重用的距离矩阵；不计读入，$O(n^2 + m)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int numberOfSets(int n, int maxDistance, vector<vector<int>>& roads) {
        int ans = 0;
        for (int open = 0; open < (1 << n); ++open)   // 枚举「保留哪些分部」
            if (check(n, maxDistance, roads, open)) ++ans;
        return ans;
    }
private:
    bool check(int n, int maxDistance, vector<vector<int>>& roads, int open) {
        const int INF = 1e9;
        vector<vector<int>> d(n, vector<int>(n, INF));
        for (int i = 0; i < n; ++i)
            if (open >> i & 1) d[i][i] = 0;
        for (const auto& r : roads) {                 // 两端都保留的道路才可用，重边取最小
            int u = r[0], v = r[1], w = r[2];
            if ((open >> u & 1) && (open >> v & 1) && w < d[u][v]) {
                d[u][v] = w; d[v][u] = w;
            }
        }
        for (int k = 0; k < n; ++k) {                 // Floyd 只在保留点中转
            if (!(open >> k & 1)) continue;
            for (int i = 0; i < n; ++i) {
                if (!(open >> i & 1) || d[i][k] == INF) continue;
                for (int j = 0; j < n; ++j) {
                    if (!(open >> j & 1) || d[k][j] == INF) continue;
                    if (d[i][k] + d[k][j] < d[i][j]) d[i][j] = d[i][k] + d[k][j];
                }
            }
        }
        for (int i = 0; i < n; ++i) {
            if (!(open >> i & 1)) continue;
            for (int j = i + 1; j < n; ++j) {
                if (!(open >> j & 1)) continue;
                if (d[i][j] > maxDistance) return false;   // INF 也会被判为不合法
            }
        }
        return true;                                  // 剩 0 或 1 个分部：无点对，直接合法
    }
};
```

### Python

```python
class Solution:
    def numberOfSets(self, n: int, maxDistance: int, roads: list[list[int]]) -> int:
        ans = 0
        for open_mask in range(1 << n):        # 枚举「保留哪些分部」
            if self._check(n, maxDistance, roads, open_mask):
                ans += 1
        return ans

    def _check(self, n: int, maxDistance: int, roads: list[list[int]], open_mask: int) -> bool:
        INF = float("inf")
        d = [[INF] * n for _ in range(n)]
        for i in range(n):
            if open_mask >> i & 1:
                d[i][i] = 0
        for u, v, w in roads:                   # 两端都保留的道路才可用，重边取最小
            if (open_mask >> u & 1) and (open_mask >> v & 1) and w < d[u][v]:
                d[u][v] = d[v][u] = w
        for k in range(n):                     # Floyd 只在保留点中转
            if not (open_mask >> k & 1):
                continue
            for i in range(n):
                if not (open_mask >> i & 1) or d[i][k] == INF:
                    continue
                dik = d[i][k]
                for j in range(n):
                    if not (open_mask >> j & 1) or d[k][j] == INF:
                        continue
                    nd = dik + d[k][j]
                    if nd < d[i][j]:
                        d[i][j] = nd
        for i in range(n):
            if not (open_mask >> i & 1):
                continue
            for j in range(i + 1, n):
                if not (open_mask >> j & 1):
                    continue
                if d[i][j] > maxDistance:       # INF（不连通）同样不合法
                    return False
        return True                              # 剩 0 或 1 个分部：无点对，直接合法
```

> 💡 两份代码均通过官方示例（`5`、`7`、`2`），并与独立实现的「枚举 + BFS 连通性 + Dijkstra 最短路」暴力对拍 2700 组随机图（含 $n = 10$ 满边、重边、紧阈值的极端构造），`mismatch = 0`。

## 8. 边界情况与易错点

1. **全关与只剩一个点**：无点对需要检查，**恒合法**。示例 3 的答案 2 就是明证；检查循环写成「枚举 $i < j$ 的保留点对」时这两类自然通过，但若先验地写「必须连通才计数」就会漏掉空集。
2. **重边取最小**：`roads` 明确允许多条道路，建矩阵时若直接赋值 `d[u][v] = w` 会被后面的长边覆盖（示例 2 中 $0\text{-}1$ 的 $20$ 与 $10$）。
3. **关闭点不能当中转点**：Floyd 的 $k$ 层必须跳过关闭点，否则算出的距离用到了「已经封路」的路径。
4. **$\infty$ 的处理**：判据 `d[i][j] > maxDistance` 同时覆盖了「不连通」；若先把 $\infty$ 参与加法再比较，`int` 会溢出成负数——代码里对 `INF` 提前 `continue` 双保险。Python 用 `float("inf")` 无溢出之忧。
5. **枚举范围**：是 $2^n$ 个**保留**掩码（或对称地枚举关闭掩码），别只枚举 $2^n - 1$ 个非空集合——空集（全关）是合法方案。
6. **初始连通只对「全开」保证**：判定代码不依赖这个假设，任何掩码都按诱导子图实际计算即可。
