# LeetCode 统计元素和差值为偶数的分区方案 题解

## 1. 题目概述

- **标题 / 题号**：统计元素和差值为偶数的分区方案（#3704，easy）
- **链接**：https://leetcode.cn/problems/count-partitions-with-even-sum-difference/
- **来源**：LeetCode 第 434 场周赛 Q1
- **难度**：简单
- **标签**：数组、数学、前缀和、奇偶性

**题意**：给定长度为 $n$ 的正整数数组 `nums`。**分区**是指按下标 $i$（$0 \le i < n-1$）把数组切成两个**非空**子数组：左部 `nums[0..i]`、右部 `nums[i+1..n-1]`。统计"左部元素和 **减** 右部元素和"为**偶数**的分区方案数。

**约束**：

- `2 <= n == nums.length <= 100`
- `1 <= nums[i] <= 100`

## 2. 示例

**示例 1**

```text
输入：nums = [10,10,3,7,6]
输出：4
解释：S = 36 为偶数，全部 n−1 = 4 个切分都满足：
      i=0: [10] | [10,3,7,6]，差 = 10 − 26 = −16（偶）
      i=1: [10,10] | [3,7,6]，差 = 20 − 16 = 4（偶）
      i=2: [10,10,3] | [7,6]，差 = 23 − 13 = 10（偶）
      i=3: [10,10,3,7] | [6]，差 = 30 − 6 = 24（偶）
```

**示例 2**

```text
输入：nums = [1,2,2]
输出：0
解释：S = 5 为奇数，i=0 差 = 1−4 = −3、i=1 差 = 3−2 = 1，全为奇数，
      不存在满足条件的分区。
```

**示例 3**

```text
输入：nums = [2,4,6,8]
输出：3
解释：S = 20 为偶数，全部 n−1 = 3 个切分都满足。
```

## 3. 解题思路

### 3.1 暴力思路：枚举切分点逐个判定

最直接的做法：枚举 $i$ 从 $0$ 到 $n-2$，维护左边和 $L$（从 $0$ 出发每轮累加 `nums[i]`），右边和 $R = S - L$，判定 $(L - R)$ 是否为偶数。若不预处理总和而是每次现算左右和则是 $O(n^2)$；配合总和 $S$ 一次遍历即为 $O(n)$ 时间、$O(1)$ 空间。本题 $n \le 100$，怎么写都能过——**但暴力完全没有用到题面的结构性观察**，签到题的价值恰恰在于把 $n$ 次判定压缩成 $1$ 次判定。

### 3.2 核心观察：差的奇偶性与切分点无关

设切分点为 $i$，左边和为 $L = L(i)$，总和为 $S$，则右边和 $R = S - L$，于是差

$$D(i) = L - R = L - (S - L) = 2L - S$$

**关键在于 $2L$ 恒为偶数**，因此

$$D(i) \equiv -S \equiv S \pmod 2$$

——差的奇偶性**只由总和 $S$ 决定**，与切分点 $i$ 完全无关！于是：

- $S$ 为偶数：$n-1$ 个切分**全部**满足，答案就是 $n - 1$；
- $S$ 为奇数：$n-1$ 个切分**全不**满足，答案为 $0$。

![奇偶性只由总和决定](images/even_sum_partition_concept.svg)

> 💡 不喜欢代数的直观版：$L - R$ 与 $L + R$ 的奇偶性总相同（因为 $(L+R) - (L-R) = 2R$ 是偶数），而 $L + R$ 恒等于总和 $S$。**差的奇偶 = 总和的奇偶**，一次看穿。

### 3.3 算法流程

![一次求和加一次分支的流程](images/even_sum_partition_flow.svg)

1. 遍历一次数组求总和 $S$（实际只需要它的奇偶性）。
2. 若 $S$ 为偶数，返回 $n - 1$；否则返回 $0$。

### 3.4 示例演算

以示例 1 `nums = [10,10,3,7,6]`（$S = 36$，偶）走查全部 4 个切分点：

| 切分点 $i$ | 左部（和 $L$） | 右部（和 $R$） | 差 $D = L - R$ | 偶？ |
|-----------|---------------|---------------|---------------|------|
| 0 | `[10]`（10） | `[10,3,7,6]`（26） | $-16$ | ✓ |
| 1 | `[10,10]`（20） | `[3,7,6]`（16） | $4$ | ✓ |
| 2 | `[10,10,3]`（23） | `[7,6]`（13） | $10$ | ✓ |
| 3 | `[10,10,3,7]`（30） | `[6]`（6） | $24$ | ✓ |

四个差恰好全为偶数，答案 $4 = n - 1$；示例 2 中 $S = 5$ 为奇数，两个差 $-3, 1$ 全为奇数，答案 $0$。

## 4. 算法细节

1. **只需奇偶性**：求和过程中可以边加边对 2 取模（`s = (s + x) % 2`），虽然 $S \le 100 \times 100 = 10^4$ 直接累加也毫无压力。
2. **切分点总数是 $n-1$**：$i$ 取 $0, 1, \ldots, n-2$，共 $n-1$ 个，且 $n \ge 2$ 保证至少存在一个切分。**不是 $n$ 个**——$i = n-1$ 时右部为空，不合法。
3. **无需前缀和数组**：若退而写暴力版，滚动维护 $L$、用 $R = S - L$ 即可，$O(1)$ 附加空间；最优版连 $L$ 都不需要。
4. **返回值直接由分支给出**：`(S % 2 == 0) ? n - 1 : 0`，一行核心逻辑。

## 5. 正确性证明

**引理 1（差的表示）**：对任意切分点 $i \in [0, n-2]$，设 $L(i) = \sum_{k=0}^{i} \text{nums}[k]$，则差 $D(i) = 2L(i) - S$。

**证明**：左右两部不交且并为整个数组，故 $R(i) = S - L(i)$，从而 $D(i) = L(i) - R(i) = L(i) - (S - L(i)) = 2L(i) - S$。∎

**定理**：满足条件的分区数为 $n - 1$（当 $S$ 为偶数）或 $0$（当 $S$ 为奇数）。

**证明**：由引理 1，$D(i) = 2L(i) - S \equiv S \pmod 2$，与 $i$ 无关，即所有切分点的差具有**相同的奇偶性**。合法切分点恰为 $i \in \{0, 1, \ldots, n-2\}$ 共 $n-1$ 个（两侧均非空）。若 $S$ 偶，则每个 $D(i)$ 均为偶数，$n-1$ 个全部计入；若 $S$ 奇，则每个 $D(i)$ 均为奇数，计数为 $0$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$——一次遍历求总和，随后 $O(1)$ 分支。$n \le 100$，可视为常数级。
- **空间复杂度**：$O(1)$——只用了总和与长度两个标量，无前缀和数组。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int countPartitions(vector<int>& nums) {
        int s = accumulate(nums.begin(), nums.end(), 0);
        // 差 D = 2L − S ≡ S (mod 2)，与切分点无关
        return s % 2 == 0 ? (int)nums.size() - 1 : 0;
    }
};
```

### Python

```python
class Solution:
    def countPartitions(self, nums: List[int]) -> int:
        # 差 D = 2L − S ≡ S (mod 2)，与切分点无关
        return len(nums) - 1 if sum(nums) % 2 == 0 else 0
```

## 8. 边界情况与易错点

1. **切分点个数是 $n-1$ 不是 $n$**：$i \in [0, n-2]$，两侧必须非空；$i = n-1$ 时右部为空不合法。示例 1 的 $n=5$ 对应 $4$ 个方案。
2. **差可以是负数**（示例 1 的 $i=0$ 差为 $-16$）：偶数与符号无关；若写暴力判定，C++ 中 `(-16) % 2 == 0` 成立，判断 `== 0` 即可，不要写 `(L - R) % 2` 之外的多余条件。
3. **读题别读偏**：是"左右**元素和**之差"为偶数，不是元素两两之差，也不是差为 $0$；偶数包含 $0$ 和负偶数。
4. **溢出无忧**：$S \le 10^4$，`int` 绰绰有余；`accumulate` 的初始值给 `0`（int）即可，别给 `0LL` 也没必要。
5. **`nums[i] >= 1` 全为正**：本题无 $0$、负数干扰；即便有，奇偶性论证依然成立，结论不变。
6. **最小规模 $n = 2$**：仅一个切分点 $i = 0$，答案只能是 $1$（$S$ 偶）或 $0$（$S$ 奇），用来快速自测。

**延伸思考**：

- 若改问"差为**奇数**的分区数"：与本题互补，答案为 $n-1$ 减去偶数方案数，即 $S$ 奇时 $n-1$、$S$ 偶时 $0$。
- 若改问"差恰好等于 $k$"（$|k| \le 2 \times 10^4$）：奇偶捷径失效，需前缀和 + 哈希统计满足 $2L = S + k$ 的 $L$ 出现次数，注意 $S + k$ 的奇偶整除性。

- 若分成 $k$ 段问"任意两段和之差均为偶数"：等价于各段和全部同奇偶，可在 $\bmod 2$ 意义下用前缀和分析。
