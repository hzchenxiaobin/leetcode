# LeetCode 找到最接近目标值的函数值 题解

## 1. 题目概述

- **标题 / 题号**：找到最接近目标值的函数值（#1521，hard）
- **链接**：https://leetcode.cn/problems/find-a-value-of-a-mysterious-function-closest-to-target/
- **来源**：LeetCode 第 198 场周赛 Q4
- **难度**：困难
- **标签**：位运算、数组、动态规划、稀疏表、二分查找

**题意**：题面先用递归定义给出一个「神秘函数」：区间长度为 1 时 $\mathrm{func}(\text{arr}, l, r)$ 返回 $\mathrm{arr}[l]$；长度大于 1 时取中点 $m = \lfloor (l+r)/2 \rfloor$，返回 $\mathrm{func}(\text{arr}, l, m) \,\&\, \mathrm{func}(\text{arr}, m+1, r)$。给定数组 `arr` 与整数 `target`，在所有下标对 $(l, r)$ 上最小化 $\left| \mathrm{func}(\text{arr}, l, r) - \mathrm{target} \right|$，返回这个最小差值。

**约束**：

- $1 \le \mathrm{arr.length} \le 10^5$
- $1 \le \mathrm{arr}[i] \le 10^6$
- $0 \le \mathrm{target} \le 10^7$

> 💡 **审题关键**：三处定生死——① **先揭穿函数**：把递归展开，func 就是 $\mathrm{arr}[l..r]$ 的**按位与**（§3.1 一行归纳可证），题目瞬间从「神秘函数」变成位运算套路题；② $\mathrm{arr}[i] \le 10^6 < 2^{20}$，一切候选函数值都落在 20 个比特位之内；③ $\mathrm{target} \le 10^7$ **可以大于一切可达函数值**（示例 2），此时最优解必在「最大可达值」一侧，算法无需特判。

> ⚠️ 题面写 $0 \le l, r < n$，但 $l > r$ 时函数走 else 分支直接返回 $\mathrm{arr}[l]$，与单元素子数组 $[l, l]$ 的值重复，不影响答案——有效枚举范围就是 $l \le r$ 的非空连续子数组（示例 1 也恰好只列了 $\binom{5}{2} + 5 = 15$ 对）。

## 2. 示例

**示例 1**

```text
输入：arr = [9,12,3,7,15], target = 5
输出：2
解释：所有 [l,r] 数对及对应函数值：
  [0,0]=9  [1,1]=12 [2,2]=3  [3,3]=7  [4,4]=15
  [0,1]=8  [1,2]=0  [2,3]=3  [3,4]=7
  [0,2]=0  [1,3]=0  [2,4]=3
  [0,3]=0  [1,4]=0
  [0,4]=0
函数值集合 {9,12,3,7,15,8,0}，最接近 5 的是 7 和 3，差值 |7-5| = |3-5| = 2。
```

**示例 2**

```text
输入：arr = [1000000,1000000,1000000], target = 1
输出：999999
解释：任意子数组的按位与都是 1000000，最小差值 |1000000-1| = 999999。
```

**示例 3**

```text
输入：arr = [1,2,4,8,16], target = 0
输出：0
解释：子数组 [0,4] 的按位与 = 1 & 2 & 4 & 8 & 16 = 0，命中 target。
```

## 3. 解题思路

### 3.1 第一步：揭穿神秘函数

函数定义只有两行：长度为 1 时返回单元素；否则把 $[l, r]$ 从中点切成两半，把两半的函数值**按位与**起来。以 `arr = [9,12,3,7,15]`、查询 $\mathrm{func}(\text{arr}, 1, 3)$ 为例展开递归树：

![揭穿神秘函数：递归树展开后 func 就是区间按位与](images/wc198_q4_func_unwrap.svg)

整棵树剥到底全是单元素叶子，自底向上一路 $\&$ 上去——由按位与的结合律，**分治的切分顺序根本不影响结果**。所以：

$$\mathrm{func}(\text{arr}, l, r) = \mathrm{arr}[l] \,\&\, \mathrm{arr}[l+1] \,\&\, \cdots \,\&\, \mathrm{arr}[r]$$

题目于是还原为：**求所有连续子数组按位与中，最接近 target 的值与 target 的最小绝对差**。

### 3.2 暴力思路：$O(n^2)$ 枚举被卡死

朴素做法是双重循环：固定左端点 $l$，向右扩张 $r$，用变量增量维护 $\mathrm{AND}(l..r)$，每次更新答案。内层 $O(1)$，但总循环次数 $\frac{n(n+1)}{2} \approx 5 \times 10^9$，在 $n = 10^5$ 下必然超时。

两条经典优化路线也全部失效：

- **前缀路线**：前缀 AND 无法相减——AND 没有「逆运算」，知道 $\mathrm{AND}(0..r)$ 和 $\mathrm{AND}(0..l-1)$ 推不出 $\mathrm{AND}(l..r)$，「区间 = 前缀差」只属于加法与异或。
- **滑动窗口路线**：右端点右移时窗口 AND 只减不增没问题，但左端点右移时**无法撤销**已经被 AND 清掉的比特位，双指针的单调可控性断了。

> 💡 一句话：**「不可逆」是本题一切困难的根源**。破解它的钥匙不是硬造可逆性，而是发现候选函数值根本没有那么多。

### 3.3 核心观察：固定右端点，AND 值是一条长度 $\le 21$ 的「降序位集链」

固定右端点 $r$，让左端点 $l$ 从 $r$ 向 $0$ 移动。每左移一格，子数组多吞一个数，AND 结果**只会清位、不会置位**：

$$\mathrm{AND}(l-1..r) = \mathrm{AND}(l..r) \,\&\, \mathrm{arr}[l-1] \subseteq \mathrm{AND}(l..r)$$

于是这 $r+1$ 个左端点对应的 AND 值构成一条**按位集合单调收缩的链**。关键结论：

- 值沿链（$l$ 递减方向）**单调不增**，且**每严格下降一次，至少清掉 1 个为 1 的比特位**；
- 本题所有值 $\le 10^6 < 2^{20}$，只有 20 个比特位；
- 所以严格下降至多发生 **20 次**，**互异 AND 值至多 $20 + 1 = 21$ 个**。

也就是说，尽管以 $r$ 结尾的子数组有 $r+1$ 个，它们的函数值**只有不超过 21 种**。$n$ 个右端点，总共只有 $O(21n) \approx 2 \times 10^6$ 个有意义的候选值——全部枚举一遍也毫无压力。

![核心观察：固定右端点，子数组 AND 值构成降序位集链](images/wc198_q4_and_chain_concept.svg)

### 3.4 算法流程：逐右端点滚动维护降序链

用一个列表 `dp` 维护**以当前元素结尾的所有子数组的互异 AND 值**（按降序排列）。处理新元素 $x = \mathrm{arr}[r]$ 时：

1. **链头放 $x$**：$x$ 对应单元素子数组 $[r, r]$；
2. **整体 AND**：旧链每个值 $v$ 更新为 $v \,\&\, x$（对应左端点不动、右端点扩张到 $r$）；
3. **相邻去重**：旧链是嵌套位集链，与同一个 $x$ 相与后嵌套关系保持，且一切 $v \,\&\, x$ 的位集都含于 $x$，故新链仍降序——降序序列中相等值必相邻，一遍扫描去掉重复，链长回到 $\le 21$；
4. **降序扫描更新答案**：链从大到小扫，$v \ge \mathrm{target}$ 时用 $v - \mathrm{target}$ 更新；**碰到首个 $v < \mathrm{target}$** 时用 $\mathrm{target} - v$ 更新一次后即可 break——后面的值只会更小、离 target 更远。

![算法流程：链头放 x、整体 AND、相邻去重、降序扫描单侧早停](images/wc198_q4_dp_transition_flow.svg)

```text
1. dp = []（空链），ans = +∞
2. 对每个 x = arr[r]：
   a. ndp = [x]                     # 链头：单元素子数组
   b. 对 dp 中每个 v（降序）：
        w = v & x
        若 w != ndp 末尾元素：追加 w  # 降序 ⇒ 重复必相邻
   c. dp = ndp                       # 新链，长度 ≤ 21
   d. 扫描 dp（降序）：
        v ≥ target  → ans = min(ans, v − target)
        v < target  → ans = min(ans, target − v)；break  # 后面更小更远
   e. 若 ans == 0：返回 0            # 理论下界，提前收工
3. 返回 ans
```

### 3.5 示例演算

以 `arr = [9,12,3,7,15], target = 5` 走查全程：

![示例演算：每个右端点 r 的降序链与答案更新](images/wc198_q4_walkthrough.svg)

第 3 步（$r=2$）是关键一跳：旧链 $\{12, 8\}$ 整体 $\&\ 3$ 后变成 $\{0, 0\}$，**两条链值殊途同归撞成同一个 0**——这正是去重让链长始终钉死在 $\le 21$ 的原因（每碰撞一次，链反而变短）。同时 $3 < \mathrm{target}$ 触发单侧早停：检查完 $|3-5|=2$ 即 break，后面的 $0$ 不必再扫。最终答案 **2**。

## 4. 算法细节

1. **链的表示**：普通数组按降序存互异值即可，无需哈希集合。降序是「相邻去重」与「单侧早停」共同的前提，由位集链结构天然保证。若改用 `set` / `unordered_set`（如本站 [每日题解 1521](../../solution/1501-1600/1521_找到最接近目标值的函数值.md) 的写法），去重照样成立，但**集合无序，单侧早停就用不上了**，只能全量扫——有序数组版既是常数更小，又是优化抓手。
2. **链头位置是正确性关键**：$x$ 必须放在链头（最大端）。因为一切 $v \,\&\, x$ 的位集都含于 $\mathrm{bits}(x)$，$x$ 一定是新链最大值；反之若把 $x$ 接到链尾，降序被破坏，相邻去重失效，链长失控退化到 $O(n)$。
3. **只存值、不存端点**：本题只关心 $|v - \mathrm{target}|$，无需记录每个值对应哪些左端点。若题目改为计数（如 3209「子数组按位与值为 K 的数目」），每个链节点需附带「覆盖的左端点个数」，套路不变。
4. **官方标签的替代路线**（稀疏表 / 线段树 / 二分）：固定**左端点** $l$，$\mathrm{AND}(l..r)$ 随 $r$ 增大单调不增，用 ST 表 $O(1)$ 查询区间 AND，二分找出值发生跳变的至多 21 个 $r$ 断点逐一检查，复杂度 $O(n \log V \log n)$。与滚动链互为镜像，正确但代码量和常数都更大。
5. **两处剪枝**：`ans == 0` 达到理论下界立即返回；单侧早停把每轮答案检查从链长 $\le 21$ 压到「target 上方全查 + 下方只查一个」。

## 5. 正确性证明

**引理 1（揭穿神秘函数）**：对任意 $0 \le l \le r < n$，$\mathrm{func}(\text{arr}, l, r) = \mathrm{arr}[l] \,\&\, \mathrm{arr}[l+1] \,\&\, \cdots \,\&\, \mathrm{arr}[r]$。

**证明**：对区间长度 $d = r - l$ 强归纳。$d = 0$ 时函数走 else 分支返回 $\mathrm{arr}[l]$，成立。设 $d < k$ 时结论成立，考察 $d = k \ge 1$：记 $m = \lfloor (l+r)/2 \rfloor$，由 $l \le m < r$，两个子调用 $\mathrm{func}(l, m)$ 与 $\mathrm{func}(m+1, r)$ 的区间长度均 $< k$，由归纳假设分别等于 $\mathrm{AND}(l..m)$ 与 $\mathrm{AND}(m{+}1..r)$；按位与满足结合律，两者相与即 $\mathrm{AND}(l..r)$。∎

**引理 2（位集链）**：固定 $r$，记 $f_r(l) = \mathrm{AND}(l..r)$。则对 $1 \le l \le r$ 有 $\mathrm{bits}\big(f_r(l-1)\big) \subseteq \mathrm{bits}\big(f_r(l)\big)$，从而 $f_r(l-1) \le f_r(l)$——左端点左移时位集收缩、数值单调不增。

**证明**：$f_r(l-1) = f_r(l) \,\&\, \mathrm{arr}[l-1]$，按位与只会把 $\mathrm{arr}[l-1]$ 为 0 的位清掉、不会置任何新位，故位集合单调收缩；位集合包含关系蕴含整数意义的大小关系（$v \,\&\, w = v \Rightarrow v \le w$）。∎

**引理 3（链长界）**：集合 $\{f_r(l) : 0 \le l \le r\}$ 的互异值个数至多 $\min(r, 20) + 1$。

**证明**：把互异值按 $l$ 从大到小排成严格递减序列 $w_0 > w_1 > \cdots > w_{m-1}$（$w_0 = \mathrm{arr}[r]$）。由引理 2，相邻两项位集合真包含，即每次严格下降至少清掉一个为 1 的位。又 $\mathrm{arr}[i] \le 10^6 < 2^{20}$，故一切 $f_r(l) < 2^{20}$，位集合大小至多 20，于是 $m - 1 \le 20$。∎

**引理 4（循环不变量）**：处理完 $\mathrm{arr}[0..i]$ 后，列表 `dp` 恰为 $\{\mathrm{AND}(l..i) : 0 \le l \le i\}$ 的互异值集合，且按降序排列。

**证明**：对 $i$ 归纳。$i = 0$ 时 `dp = [arr[0]]` 成立。设第 $i$ 轮结论成立，第 $i+1$ 轮处理 $x = \mathrm{arr}[i+1]$：以 $i+1$ 结尾的子数组按左端点分两类——单元素子数组 $[i{+}1..i{+}1]$，值为 $x$；一般子数组 $[l..i{+}1]$（$l \le i$），值为 $\mathrm{AND}(l..i) \,\&\, x$。由引理 2，旧链降序且位集逐项收缩，与同一 $x$ 相与后收缩关系保持；又 $\mathrm{bits}(v \,\&\, x) \subseteq \mathrm{bits}(x)$，故 $[x, v_1 \,\&\, x, \cdots]$ 整体仍降序；降序序列中相等值必相邻，算法的相邻去重恰好清除全部重复。∎

**定理**：算法返回值 $= \min_{0 \le l \le r \le n-1} \left| f_r(l) - \mathrm{target} \right|$。

**证明**：算法输出是若干个 $\left| v - \mathrm{target} \right|$ 的最小值，每个 $v$ 都来自某轮 `dp`，由引理 4 等于某个真实子数组的 AND，故输出 $\ge$ 所求最小值。反之，对任意子数组 $[l..r]$，其值 $v$ 在第 $r$ 轮结束时的 `dp` 中（引理 4）。再证单侧早停不会漏掉它：链降序，故所有 $\ge \mathrm{target}$ 的值排在扫描路径前段、必然全部被检查；设扫描中首个小于 $\mathrm{target}$ 的链值为 $v^*$，则任何 $v < \mathrm{target}$ 都排在 $v^*$ 之后（或就是 $v^*$），有 $v \le v^*$，$\mathrm{target} - v \ge \mathrm{target} - v^*$，即**用 $v^*$ 更新已不劣于用任何后面被跳过的值更新**。两种情形下 `ans` 都不高于 $\left| v - \mathrm{target} \right|$；取遍所有子数组即得输出 $\le$ 所求最小值。∎

## 6. 复杂度分析

- **时间复杂度**：$O\big(n \cdot (B+1)\big)$，其中 $B = 20$。每轮转移与答案检查均为链长线性，链长由引理 3 界定为 $\le 21$；$n = 10^5$ 时约 $2.1 \times 10^6$ 次基本操作，远低于时限。单侧早停还能进一步压缩答案检查的常数。
- **空间复杂度**：$O(B+1) = O(21)$。只维护当前一条链（转移后 `move` 释放旧链），无需任何历史。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int closestToTarget(vector<int>& arr, int target) {
        int ans = INT_MAX;
        vector<int> dp;                        // 以当前元素结尾的互异 AND 值（降序）
        for (int x : arr) {
            vector<int> ndp;
            ndp.push_back(x);                  // ① 链头：单元素子数组，新链最大值
            for (int v : dp) {                 // ② 旧链整体 & x
                int w = v & x;
                if (w != ndp.back())           // ③ 降序 ⇒ 重复必相邻
                    ndp.push_back(w);
            }
            dp = move(ndp);
            for (int v : dp) {                  // ④ 降序扫描，单侧早停
                if (v >= target) {
                    ans = min(ans, v - target);
                } else {
                    ans = min(ans, target - v);
                    break;                      // 后面只会更小更远
                }
            }
            if (ans == 0) return 0;             // 可选剪枝：已达理论下界
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def closestToTarget(self, arr: List[int], target: int) -> int:
        ans = inf
        dp = []                                # 以当前元素结尾的互异 AND 值（降序）
        for x in arr:
            ndp = [x]                          # ① 链头：单元素子数组，新链最大值
            for v in dp:                       # ② 旧链整体 & x
                w = v & x
                if w != ndp[-1]:               # ③ 降序 ⇒ 重复必相邻
                    ndp.append(w)
            dp = ndp
            for v in dp:                       # ④ 降序扫描，单侧早停
                if v >= target:
                    ans = min(ans, v - target)
                else:
                    ans = min(ans, target - v)
                    break                      # 后面只会更小更远
            if ans == 0:
                return 0                       # 可选剪枝：已达理论下界
        return ans
```

## 8. 边界情况与易错点

1. **第一步永远是揭穿函数**：别被递归定义吓住，先归纳证明 func = 区间按位与再动手。顺带注意 $l > r$ 时函数走 else 分支返回 $\mathrm{arr}[l]$，与单元素子数组 $[l,l]$ 重复，不影响答案——赛时可以直接按 $l \le r$ 处理。
2. **target 可以比一切可达值都大**：$\mathrm{target} \le 10^7$ 而 AND 值 $\le 10^6$。此时最优必是「最大可达值」一侧；最大可达 AND = $\max(\mathrm{arr})$（单元素子数组即可取到，任何更长区间只会清位）——闭式为 $\mathrm{target} - \max(\mathrm{arr})$，算法天然处理，无需特判。示例 2（全 $10^6$、target 为 1）则是反向极端：所有值都在 target 上方。
3. **去重是命门**：忘记去重则链每轮至少长一格，$n$ 轮膨胀到 $O(n)$，总复杂度退化 $O(n^2)$ 必 TLE。示例 1 中 $12 \,\&\, 3 = 8 \,\&\, 3 = 0$ 的碰撞正说明：旧链多个值经 $\&\ x$ 后可能**合流成同一个值**。
4. **链头位置错 → 隐性 $O(n^2)$**：$x$ 必须放链头（最大端）。若接在链尾，降序被破坏，相邻去重失效，链长失控。这是与 OR 镜像题（$x$ 放最小端）最容易写反的地方。
5. **早停方向别搞反**：链是**降序**，早停只发生在**首个 $v < \mathrm{target}$ 检查完之后**；$v \ge \mathrm{target}$ 一侧每往下一个值差值可能更小，绝不能提前停。
6. **溢出检查**：$\left| v - \mathrm{target} \right| \le \max(10^6, 10^7) < 2^{31} - 1$，C++ `int` 安全；若值域升到 $10^{18}$ 需换 `long long`，同时链长界变为 61，其余不变。
7. **`ans` 初始化**：必须为 $+\infty$（`INT_MAX` / `inf`），不要初始化为 0；首轮单元素子数组必被检查，循环至少执行一次，答案必定被正确更新。

**延伸思考**：

- **变体：计数**——「AND 值恰好等于 target 的子数组个数」怎么做？链节点改为 `(值, 该值覆盖的左端点个数)`，转移时合并相邻等值节点的计数，总复杂度仍是 $O(21n)$。
- **变体：target 超上界的闭式**——若 $\mathrm{target} > 10^6 \ge \max(\mathrm{arr})$，答案恒为 $\mathrm{target} - \max(\mathrm{arr})$，可 $O(n)$ 直接返回；比赛中可作为对拍用的特判。
- **值域进阶**：若 $\mathrm{arr}[i] \le 10^{18}$，则 $B = 60$、链长界 61，复杂度 $O(61n)$，做法完全不变。
- **家族推广**：GCD 同样满足「区间扩张单调不增 + 每次严格下降至少减半」，互异值也至多 $O(\log V)$ 个——[2941. 子数组的最大 GCD-Sum](https://leetcode.cn/problems/maximum-gcd-sum-of-a-subarray/) 一族与本题共用「滚动候选链」模板，只是收缩依据从「清位」换成「减半」。
