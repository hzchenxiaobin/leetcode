# LeetCode 换水问题 题解

## 1. 题目概述

- **标题 / 题号**：换水问题（#1518，easy）
- **链接**：https://leetcode.cn/problems/water-bottles/
- **来源**：LeetCode 第 198 场周赛 Q1
- **难度**：简单
- **标签**：数学、模拟

**题意**：购入 `numBottles` 瓶满水，喝掉一瓶水就会得到一个空瓶；`numExchange` 个空瓶可以在超市兑换 1 瓶满水。问最多能喝到多少瓶水。

**约束**：

- $1 \le \text{numBottles} \le 100$
- $2 \le \text{numExchange} \le 100$

> 💡 签到题两个读题点：① 兑换来的满水**喝掉后又会变回空瓶**，可以继续参与下一轮兑换（连锁兑换）；② 必须攒够 $e$ 个空瓶才能换，不找零、不拆分。数据范围小到怎么写都能过，但这题值得沉淀的是「消耗-兑换」类问题的**数轮数套路**：看清每一轮的净变化，一笔写出 $O(1)$ 公式。

## 2. 示例

**示例 1**

```text
输入：numBottles = 9, numExchange = 3
输出：13
解释：喝 9 瓶得 9 个空瓶 → 换 3 瓶喝掉（累计 12）得 3 个空瓶
      → 换 1 瓶喝掉（累计 13）得 1 个空瓶，1 < 3 无法再换。
      共喝 9 + 3 + 1 = 13 瓶。
```

**示例 2**

```text
输入：numBottles = 15, numExchange = 4
输出：19
解释：喝 15 得 15 空 → 换 3 瓶剩 3 空 → 喝 3 得 3+3=6 空 → 换 1 瓶剩 2 空
      → 喝 1 得 2+1=3 空 < 4，停止。共喝 15 + 3 + 1 = 19 瓶。
```

**示例 3**（自拟，覆盖「最后一轮兑换后恰好只剩保底空瓶」）

```text
输入：numBottles = 5, numExchange = 5
输出：6
解释：喝 5 得 5 空 → 恰好换 1 瓶 → 喝掉（累计 6）剩 1 个空瓶，5 个才够换，停止。
      注意最后手里永远捏着 1 个换不出去的「保底」空瓶。
```

## 3. 解题思路

### 3.1 暴力思路：逐轮模拟

最直白的做法是**按轮模拟**：每轮先喝光手里所有满水（累加答案、满水变空瓶），再用空瓶尽量兑换新满水。伪代码只有六行：

```text
ans = 0, full = b, empty = 0
while full > 0:
    ans += full          # 喝光所有满水
    empty += full        # 满水变空瓶
    full = empty // e    # 兑换出新满水
    empty = empty % e    # 剩下换不掉的空瓶
return ans
```

每轮结束后空瓶数约为原来的 $\frac{1}{e}$（整除取商，余数至多 $e-1$），轮数是 $O(\log_e b)$ 量级，$b \le 100$ 时几轮就结束。赛时这个写法 30 秒敲完、几乎不可能错，是签到题的首选。

### 3.2 核心观察：一次「兑换 + 喝掉」净消耗 $e - 1$ 个空瓶

![核心观察：一次兑换加喝掉净耗 e−1 个空瓶](images/wc198_q1_exchange_cycle.svg)

把一次「兑换 + 喝掉」看作一个**完整循环**：

1. 拿 $e$ 个空瓶换 1 瓶满水（空瓶 $-e$）；
2. 喝掉这瓶满水（多喝 $+1$ 瓶，空瓶 $+1$）。

一轮结束后，空瓶**净减少** $e - 1$ 个，同时**累计多喝 1 瓶**：

> 💡 **每多喝 1 瓶，就「净消耗」$e - 1$ 个空瓶**——而不是 $e$ 个，因为喝完的瓶子自己会吐回来。

初始喝完 $b$ 瓶后手里恰有 $b$ 个空瓶。此后每次额外兑换净消耗 $e-1$ 个，但**终止时手里必剩至少 1 个空瓶**（每次喝完都吐回 1 个，而它已不足以凑够 $e$ 个去兑换）——这是永远换不出去的「保底空瓶」。因此能被净消耗的空瓶至多 $b - 1$ 个，额外多喝的瓶数为

$$k = \left\lfloor \frac{b - 1}{e - 1} \right\rfloor,$$

最终答案为

$$\text{ans} = b + \left\lfloor \frac{b - 1}{e - 1} \right\rfloor.$$

> ⚠️ **为什么分子是 $b-1$ 而不是 $b$**：反例 $b=2,\ e=3$——$\lfloor 2/2 \rfloor = 1$ 会认为还能多喝 1 瓶，但 2 个空瓶 $< 3$ 根本换不了，正确答案是 2。那「保底的 1 个空瓶」不能计入可消耗的预算，所以分子必须减 1。

**代入验证**：$b=9,e=3$：$k=\lfloor 8/2 \rfloor=4$，ans $=13$ ✓；$b=15,e=4$：$k=\lfloor 14/3 \rfloor=4$，ans $=19$ ✓。

### 3.3 算法流程

![算法流程：模拟版循环与公式版一步到位](images/wc198_q1_simulation_flow.svg)

两条路：**模拟版**用 `while` 循环重复「喝光 → 兑换」，直到某轮换不出新满水（`full == 0`）为止；**公式版**直接数轮数，一次整除出答案。两者对任意输入等价（第 5 节证明），赛时按手速任选。

### 3.4 示例演算

![示例演算：b=9, e=3 逐轮喝光与兑换走查](images/wc198_q1_example_walkthrough.svg)

以 $b = 9,\ e = 3$ 为例逐轮走查（完整过程见上图）：

| 轮次 | 喝掉满水 | 累计喝 | 喝后空瓶 | 兑换（÷3） | 剩余空瓶（%3） | 新满水 |
|------|---------|--------|---------|-----------|---------------|--------|
| 1 | 9 | 9 | 9 | 3 | 0 | 3 |
| 2 | 3 | 12 | 3 | 1 | 0 | 1 |
| 3 | 1 | 13 | 1 | 0 | 1 | 0（停止） |

第 3 轮换不出新满水，循环终止，共喝 **13** 瓶。对照公式：额外喝的 $3 + 1 = 4$ 瓶恰为 $k = \lfloor (9-1)/(3-1) \rfloor = 4$，结果一致。

## 4. 算法细节

1. **模拟版状态设计**：只需 `ans` / `full` / `empty` 三个变量，每轮按「喝光（`ans += full; empty += full`）→ 兑换（`full = empty / e; empty %= e`）」推进，`full == 0` 即终止。
2. **整除与取模必须同时取**：`full` 和 `empty` 都来自**同一个**兑换前的空瓶数，Python 用 `divmod(empty, e)` 一步取商和余；C++ 若先 `empty %= e` 再 `empty / e`，商会被余数覆盖，是这类题最常见的手滑。
3. **公式推导三步走**：初始喝完 $b$ 瓶得 $b$ 个空瓶 → 每轮「兑换 + 喝掉」净耗 $e-1$、多喝 1 瓶 → 终止时必剩 1 个保底空瓶，可得消耗预算恰为 $b-1$。
4. **C++ 整数除法**对非负数天然下取整，与 $\lfloor \cdot \rfloor$ 一致，无需额外处理；$e \ge 2$ 保证分母 $e-1 \ge 1$ 不会除零。
5. **两种写法互为对拍**：赛时若用公式版，可用模拟版在 $b, e \le 20$ 的范围内暴力对拍自查。

## 5. 正确性证明

**引理 1（状态不变量）**：若初始喝完 $b$ 瓶后，前 $k$ 次「兑换 + 喝掉」均已发生，则此时累计喝掉 $b + k$ 瓶，手里空瓶数为 $b - k(e-1)$。

**证明**：对 $k$ 归纳。$k = 0$ 时喝完初始 $b$ 瓶，空瓶恰为 $b$，成立。设结论对 $k$ 成立且第 $k+1$ 次兑换发生：兑换消耗 $e$ 个空瓶换来 1 瓶满水，喝掉它累计 $+1$ 且吐回 1 个空瓶，故空瓶数变为 $b - k(e-1) - e + 1 = b - (k+1)(e-1)$，累计喝掉 $b + k + 1$ 瓶。∎

**引理 2（可行性与单调性）**：第 $k$ 次「兑换 + 喝掉」能发生，当且仅当 $b - (k-1)(e-1) \ge e$；且可行性是前缀可行的——一旦某次不可行，之后永远不可行。

**证明**：第 $k$ 次兑换前手里空瓶数为 $b - (k-1)(e-1)$（引理 1），能兑换当且仅当其 $\ge e$。若某次兑换前空瓶 $< e$，说明满水已全部喝光、兑换是空瓶的唯一去向，此后空瓶数不再变化，后续每次判定依然 $< e$，永不可行。∎

**定理**：最多能喝 $\text{ans} = b + \left\lfloor \dfrac{b-1}{e-1} \right\rfloor$ 瓶。

**证明**：由引理 2，实际发生的兑换次数是满足 $b - (k-1)(e-1) \ge e$ 的最大 $k$。该不等式等价于 $b - k(e-1) \ge 1$，即 $k \le \frac{b-1}{e-1}$；由 $e \ge 2$ 知分母非零，故最大兑换次数 $k^{\ast} = \left\lfloor \frac{b-1}{e-1} \right\rfloor$。再由引理 1，最终累计喝掉 $b + k^{\ast}$ 瓶。∎

## 6. 复杂度分析

- **时间复杂度**：模拟版 $O(\log b)$——每轮结束后空瓶数约为原来的 $\frac{1}{e}$ 加上至多 $e-1$ 的余数，轮数对数级（$b \le 100$ 时至多几轮）；公式版 $O(1)$，只有一次整除。本题范围下两者都远低于限制。
- **空间复杂度**：两种写法均为 $O(1)$，只用到常数个变量。

## 7. 参考代码

### C++（逐轮模拟，签到首选）

```cpp
class Solution {
  public:
    int numWaterBottles(int numBottles, int numExchange) {
        int ans = 0, full = numBottles, empty = 0;
        while (full > 0) {
            ans += full;                  // 喝光所有满水
            empty += full;                // 满水变空瓶
            full = empty / numExchange;   // 兑换出新满水
            empty %= numExchange;         // 剩下换不掉的空瓶
        }
        return ans;
    }
};
```

### Python（$O(1)$ 公式）

```python
class Solution:
    def numWaterBottles(self, numBottles: int, numExchange: int) -> int:
        return numBottles + (numBottles - 1) // (numExchange - 1)
```

两种写法等价（第 5 节定理）；Python 模拟版把兑换一行写成 `full, empty = divmod(empty, numExchange)` 即可，此处从略。

## 8. 边界情况与易错点

1. **$b = 1$（最小输入）**：喝 1 瓶后仅 1 个空瓶，$e \ge 2$ 必然换不了，答案就是 1。公式中分子 $b - 1 = 0$ 自动给出 $k = 0$，无需特判。
2. **$e = 2$（兑换最频繁的极端）**：每轮净耗 1 个空瓶，答案为 $2b - 1$；这是对公式/模拟对拍最敏感的一组输入。
3. **公式分子是 $b-1$ 不是 $b$**：保底空瓶不能计入消耗预算，$b=2,\ e=3$ 是最短反例（见 3.2 节 ⚠️）。
4. **模拟版先取商再取余**（或 `divmod` 同步）：两者都源于兑换前的空瓶数，顺序写反会用余数覆盖商。
5. **别漏「连锁兑换」**：换来的满水喝掉后又是空瓶，能继续参与下一轮兑换——示例 1 的 $9 \to 3 \to 1$ 两连跳正是它；把「换到的水」直接计入答案却忘了它会吐回空瓶，就会少算。
6. **溢出**：最大答案 $100 + \lfloor 99/1 \rfloor = 199$，`int` 绰绰有余；数据放大到 $10^9$ 时需 `long long`，公式版依然 $O(1)$。
