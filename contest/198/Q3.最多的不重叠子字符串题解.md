# LeetCode 最多的不重叠子字符串 题解

## 1. 题目概述

- **标题 / 题号**：最多的不重叠子字符串（#1520，hard）
- **链接**：https://leetcode.cn/problems/maximum-number-of-non-overlapping-substrings/
- **来源**：LeetCode 第 198 场周赛 Q3
- **难度**：困难
- **标签**：贪心、哈希表、字符串、排序

**题意**：给定只含小写字母的字符串 `s`，选出**最多数目**的非空子字符串，满足两个条件：

1. **互不重叠**：任意两个子串 `s[i..j]` 与 `s[x..y]` 满足 $j < x$ 或 $i > y$，即不共享任何下标；
2. **全量收集**：子串只要包含字符 `char`，`s` 中**所有** `char` 的出现都必须落在这个子串内。

在数目相同的前提下，返回总长度最小的解（题目保证唯一），返回顺序任意。

**约束**：

- $1 \le |\mathrm{s}| \le 10^5$
- `s` 只包含小写英文字母（字符集大小 $\sigma = 26$）

> 💡 **审题关键**：三处定生死——① 条件 2 是「全量收集」：子串含某字符哪怕一次，就必须包揽该字符在整串中的**全部**出现，这把合法子串的形状锁死为「若干字符跨度的并」；② 合法子串本身可以有 $\Theta(n^2)$ 个（如全互异字符的串，**任何**子串都合法），但有「代表性」的极小合法子串**至多 26 个**——每个出现过的字符各派生一个「闭包」，问题瞬间坍缩成经典区间调度；③ 不重叠是**严格不共享下标**（$j < x$），相邻子串如 $[0,2]$ 与 $[3,5]$ 合法——「数目优先、长度其次」的双目标词典序正是贪心区间调度的加权变体。

## 2. 示例

**示例 1**

```text
输入：s = "adefaddaccc"
输出：["e","f","ccc"]
解释：满足条件 2 的合法子串共 6 个：
  "adefaddaccc"（含 a,d,e,f → 须覆盖全部 a,d,e,f）
  "adefadda"    （含 a,d,e,f）
  "ef"          （含 e,f）
  "e"           （只含 e）
  "f"           （只含 f）
  "ccc"         （只含 c）
选整串只能 1 个；选 "adefadda"+"ccc" 得 2 个；"ef" 可拆成 "e"+"f" 两个，
数目更多，不是最优。最优解 ["e","f","ccc"]，共 3 个，总长 5。
```

**示例 2**

```text
输入：s = "abbaccd"
输出：["d","bb","cc"]
解释：["d","abba","cc"] 也是 3 个，但总长 1+4+2 = 7 > 1+2+2 = 5，
不是最优——数目相同时贪长度。
```

**边界示例**

```text
输入：s = "aaaa"
输出：["aaaa"]
解释：任何真子串都含 'a' 却没包揽全部 'a'，违反条件 2；
唯一合法子串是整串本身。

输入：s = "ab"
输出：["a","b"]
解释：相邻单字符互不重叠（0 < 1），两个都可选。
```

## 3. 解题思路

### 3.1 暴力思路：$O(n^2)$ 候选 + 组合优化，双倍超时

朴素做法分两层：先枚举全部 $\Theta(n^2)$ 个子串、逐一验证条件 2（对所含每个字符查其 `first`/`last` 是否都落在区间内，单次 $O(\sigma)$）；再在合法子串集合上做「最多不重叠 + 最小总长」的组合优化——子集枚举指数爆炸，区间 DP 也要 $O(n^2)$ 级别。$n = 10^5$ 下两层都不可行。

瓶颈在于：合法子串太多了（全互异字符的串里连 $\Theta(n^2)$ 个都是合法的）。要往下走，必须找到「代表」——用极少数候选子串顶替全体合法子串参与优化。

### 3.2 核心观察：每个字符派生一个「闭包」候选

定义字符 $c$ 的**跨度** $I_c = [\,\mathrm{first}[c],\ \mathrm{last}[c]\,]$。任何含 $c$ 的合法子串必须覆盖 $I_c$；但只覆盖 $I_c$ 还不够——区间内部出现的其他字符 $d$ 同样被「全量收集」约束拖下水：区间必须继续吞下 $I_d$；吞并后区间内可能出现新字符，继续吞，直到区间内出现的所有字符的跨度都已包含在内。这个不动点记为**闭包** $\mathrm{cl}(c)$，它就是「包含字符 $c$ 的最小合法子串」。

![核心观察：闭包扩张——包含某字符的最小合法子串](images/wc198_q3_closure_expansion.svg)

闭包有三条关键性质（§5 严格证明）：

1. **合法性**：$\mathrm{cl}(c)$ 自身满足条件 2——不动点条件「区间内出现的每个字符的跨度都在区间内」恰好就是条件 2 的定义；
2. **极小性**：任何含 $c$ 的合法子串 $[i,j]$ 必有 $\mathrm{cl}(c) \subseteq [i,j]$——闭包是这类子串的最小者；
3. **代表性（换元不降级）**：任何合法子串都能被它内部的任一字符的闭包「替代」——闭包是它的子串，数目不减、长度不增。于是「在 $\Theta(n^2)$ 个合法子串上做双目标优化」等价于「在 $\le 26$ 个闭包上做同样的优化」。

> ⚠️ **别和「划分字母区间」（763）的跨度连通块搞混**：763 要求划分**覆盖全串**，把**跨度相交**的字符合并成连通块（例 1 中 $I_e = [2,2]$ 与 $I_a = [0,7]$ 相交，会并成一块 $[0,7]$）；本题的扩张由「**区间内出现**」触发，而非「跨度相交」——子串 $[2,2]$ 里根本没有 `a`，所以 `e` 的闭包就是 $[2,2]$ 自己。若误用 763 的连通块做法，例 1 只能得 2 段，而正确答案是 3 段。这个触发条件的差别正是本题的题眼。

### 3.3 候选结构：层状嵌套 + 右端点互异 → 最早结束贪心

把 $\le 26$ 个闭包去重放到数轴上，会出现两种非常规整的结构（§5 引理 3、引理 4 证明）：

- **层状性**：两个不同闭包要么不相交，要么一个真包含另一个（相交必嵌套）；
- **右端点互异**：不同闭包的右端点两两不同。

于是「最早结束」贪心格外干净：按右端点升序排序（互异 ⇒ 顺序唯一，不需要任何 tie-break），依次扫描，维护 `lastEnd`（初始 $-1$），一旦候选满足 $\mathrm{st} > \mathrm{lastEnd}$ 就选中。

![候选闭包的层状结构与最早结束贪心](images/wc198_q3_laminar_candidates.svg)

例 1 走查：候选按右端点排为 $[2,2] \to [3,3] \to [0,7] \to [8,10]$，依次选中 e、f，跳过 $[0,7]$（$\mathrm{st}=0 \le 3$，与 e/f 重叠），再选 ccc——数目 3、总长 5，双双最优。注意合法子串 `"ef"` 虽短，却同时含两个闭包 $[2,2]$、$[3,3]$，拆开数目更多——**闭包的极小性保证它不被任何子串支配**。

### 3.4 算法流程

![算法流程：跨度统计、闭包扩张、去重排序、贪心选择](images/wc198_q3_greedy_flow.svg)

```text
1. 一趟扫描：统计每个字符的 first[c] / last[c]
2. 对每个出现过的字符 c 求闭包：
   st, en ← first[c], last[c]；k ← st
   循环直到 k > en：
     d = s[k]
     en ← max(en, last[d])          # 右扩：吞并 d 的跨度右端
     若 first[d] < st：              # 左扩：d 的跨度越出左端
       st ← first[d]；k ← st         # 回退到新左端重扫
     否则 k ← k + 1
   记录候选 (st, en)
3. 候选去重（不同字符闭包可能相同），按右端点 en 升序排序
4. lastEnd ← −1；依次考察 (st, en)：
   若 st > lastEnd：选中，lastEnd ← en
5. 输出所有选中的 s[st..en]
```

### 3.5 示例演算

![示例演算：两个官方样例的闭包求取与贪心选择全流程](images/wc198_q3_example_walkthrough.svg)

例 1 的关键一跳在字符 `d`：初始跨度 $[1,6]$，扫描到 $k=4$ 遇到 `a`，吞并 $I_a = [0,7]$ 后整个候选变成 $[0,7]$——与字符 `a` 的闭包完全相同，去重后只留一份。例 2 的关键对比在 `"abba"` 与 `"bb"`：同为含 `a`/`b` 的合法子串，右端点 3 的 `"abba"` 输给右端点 2 的 `"bb"`，数目不变、总长从 7 省到 5。

## 4. 算法细节

1. **扩张循环的顺序不能反**：先执行 `en ← max(en, last[d])`，再判断左回退。若先回退，当前字符 `d` 的右端信息会随 `k` 重置而丢失（重扫虽会再遇到它，但依赖重扫路径完整，容易写出隐性 bug）。代码里两行的先后顺序即此意。
2. **回退重扫的正确性**：`st` 左移后，$[\mathrm{st}_{\text{新}},\ \mathrm{st}_{\text{旧}})$ 这段从未扫过，必须把 `k` 重置到新 `st` 从头扫；已扫部分的 `min`/`max` 是幂等操作，重复无害。
3. **每字符至多 $\sigma+1$ 趟扫描**：`st` 每次回退都严格变小，且只能落到某个字符的 `first` 值上（至多 26 种取值）；每趟扫描的长度不超过该字符闭包的长度，且 $\sum_c |\mathrm{cl}(c)| \le \sigma n$。这是复杂度上界 $O(\sigma^2 n)$ 的来源。
4. **去重**：不同字符的闭包可能完全相同（例 1 中 `a` 与 `d` 都是 $[0,7]$——跨度互相嵌住的字符会同生共死）。`sort + unique`（或集合）去重。不去重其实也不会选错（重复区间第二次会被 `st > lastEnd` 挡下），但显式去重让候选集与 §5 的证明对象一一对应。
5. **排序键**：按右端点即可——引理 4 保证不同闭包右端点互不相同，排序无歧义。「右端相同选更短」之类的防御性 tie-break 在本题结构下是多余的（那是没证明引理 4 时的保险丝）。
6. **「放弃」变体**（官方题解的写法）：扩张途中一旦遇到 $\mathrm{first}[d] < \mathrm{first}[c]$ 就直接放弃字符 `c`——被放弃的闭包必然真包含某个保留下来的更小闭包（支配关系），贪心结果不变。本篇保留完整闭包，与 §5 的极小性证明严丝合缝。

## 5. 正确性证明

约定：区间 $[i,j]$ **合法**指其中出现的每个字符 $d$ 都有 $I_d \subseteq [i,j]$；$\mathrm{cl}(c)$ 由 §3.2 的不动点过程产生；记 $L_A, R_A$ 为区间 $A$ 的左右端点。

**引理 1（闭包的良定义与极小性）**：对每个出现过的字符 $c$：(a) 闭包过程有限步终止；(b) $\mathrm{cl}(c)$ 合法；(c) 任何包含 $I_c$ 的合法区间 $[i,j]$ 都满足 $\mathrm{cl}(c) \subseteq [i,j]$。

**证明**：(a) 每轮要么区间严格变长要么终止，区间长度以 $n$ 为上界。(b) 不动点条件「区间内出现的每个字符的跨度都在区间内」逐字就是合法性。(c) 对轮数归纳：第 0 轮 $I_c \subseteq [i,j]$；设第 $t$ 轮区间 $J_t \subseteq [i,j]$，则 $J_t$ 内出现的每个字符 $d$ 也在 $[i,j]$ 内出现，由 $[i,j]$ 合法得 $I_d \subseteq [i,j]$，故 $J_{t+1} = J_t \cup \{\,I_d : d \text{ 在 } J_t \text{ 内出现}\,\} \subseteq [i,j]$。∎

**引理 2（代表性）**：合法子串 $[i,j]$ 与其内部出现的任一字符 $c$，都有 $\mathrm{cl}(c) \subseteq [i,j]$。

**证明**：$[i,j]$ 合法且含 $c$，则 $I_c \subseteq [i,j]$，由引理 1(c) 即得。∎

**推论 1**：设 $\mathcal{C}$ 为全体闭包（去重后）。则不重叠合法子串的最大数目 $k$ = $\mathcal{C}$ 中不重叠闭包的最大个数；且「数目为 $k$、总长最小」的解 = 「$k$ 个不重叠闭包的最小总长」。

**证明**：任一数目 $m$ 的解 $\{T_1, \dots, T_m\}$，取各 $T_i$ 内出现的字符 $c_i$，由引理 2 得互异且互不重叠的闭包 $\mathrm{cl}(c_i) \subseteq T_i$，故 $|\mathcal{C}|$ 的不重叠最大数 $\ge m$；反之 $m$ 个不重叠闭包本身就是数目 $m$ 的解，两个方向合起来数目相等。长度方向：数目 $k$ 的任何解 $\sum |T_i| \ge \sum |\mathrm{cl}(c_i)|$，后者是某个 $k$ 个不重叠闭包族的总长，故 $\ge$ 最小值；而达到该最小值的闭包族自身就是数目 $k$、恰为此总长的解。∎

**引理 3（层状性）**：两个不同的闭包要么不相交，要么一个真包含另一个。

**证明**：设 $A, B$ 相交且 $L_A \le L_B$，相交即 $L_B \le R_A$。断言 $B \subseteq A$。反设 $R_B > R_A$。把 $B$ 的扩张分解成单步链 $J_0 \subset J_1 \subset \cdots \subset J_t = B$，每步并入「在当前区间出现的某个字符」的跨度。取第一个右端越过 $R_A$ 的步骤 $s$：其前一步 $J_{s-1}$ 右端 $\le R_A$、左端 $\ge L_B \ge L_A$，故 $J_{s-1} \subseteq A$；该步由某个在 $J_{s-1}$ 内出现的字符 $u$ 触发，$u$ 在 $A$ 内出现且 $A$ 合法 $\Rightarrow I_u \subseteq A \Rightarrow r_u \le R_A$，但该步之后右端 $= r_u > R_A$，矛盾。∎

**引理 4（右端点互异）**：不同闭包的右端点两两不同。

**证明**：反设 $\mathrm{cl}(x) = [L_1, R] \supsetneq \mathrm{cl}(y) = [L_2, R]$，$L_1 < L_2$。若 $x$ 在 $[L_2, R]$ 内出现，则 $I_x \subseteq \mathrm{cl}(y)$，由引理 1(c) 得 $\mathrm{cl}(x) \subseteq \mathrm{cl}(y)$，矛盾；故 $I_x \subseteq [L_1, L_2)$。考察 $\mathrm{cl}(x)$ 的单步扩张链：右端须从 $r_x < L_2$ 长到 $R \ge L_2$，取第一次越过 $L_2$ 的步骤，其前一步区间 $\subseteq [L_1, L_2)$，触发字符 $u$ 在其中出现（$\Rightarrow l_u < L_2$），且该步右端 $r_u \in [L_2, R]$。于是 $u$ 在 $\mathrm{cl}(y)$ 内出现 $\Rightarrow I_u \subseteq [L_2, R] \Rightarrow l_u \ge L_2$，与 $l_u < L_2$ 矛盾。∎

**定理**：把 $\mathcal{C}$ 按右端点升序排序，依次考察 $(\mathrm{st}, \mathrm{en})$，维护 `lastEnd`（初值 $-1$），$\mathrm{st} > \mathrm{lastEnd}$ 则选中并更新 $\mathrm{lastEnd} = \mathrm{en}$。则选出的族 (1) 数目为 $k$；(2) 总长为一切 $k$ 个不重叠闭包族的最小。结合推论 1，该族即所求。

**证明**：(1) 记贪心依次选出 $g_1, \dots, g_k$，任一不重叠族按右端点排序为 $h_1, \dots, h_m$。归纳证明 $R_{g_i} \le R_{h_i}$（$i \le \min(k,m)$）：$g_1$ 是全体候选中右端点最小者；设 $R_{g_{i-1}} \le R_{h_{i-1}}$，则 $h_i$ 满足 $L_{h_i} > R_{h_{i-1}} \ge R_{g_{i-1}}$，在贪心第 $i$ 步时可用，而 $g_i$ 是当时可用的右端最小者。若 $m > k$：$h_{k+1}$ 满足 $L_{h_{k+1}} > R_{h_k} \ge R_{g_k} = \mathrm{lastEnd}$，贪心终止时仍会选中它，矛盾。故 $m \le k$，贪心数目即最大值。

(2) 对 $|\mathcal{C}|$ 归纳。设 $c_1$ 为右端点最小的候选（引理 4 $\Rightarrow$ 唯一）。**每个最优 $k$-族都含 $c_1$**：若最优族 $H$ 不含 $c_1$——由引理 3 与引理 4，其余候选要么与 $c_1$ 不相交、要么真包含 $c_1$（真被 $c_1$ 包含者右端更小或与 $c_1$ 相同，均与 $c_1$ 右端最小矛盾；不相交且在左侧者右端 $< L_{c_1} \le R_{c_1}$，同样矛盾）——若 $H$ 的成员都与 $c_1$ 不相交，则 $H \cup \{c_1\}$ 是数目 $k+1$ 的不重叠族，与 $k$ 最大矛盾；故 $H$ 含真包住 $c_1$ 的成员 $f$，用 $c_1$ 替换 $f$ 得 $H'$：仍不重叠、数目 $k$，且 $|H'| = |H| - |f| + |c_1| < |H|$（$c_1 \subsetneq f$，长度严格变短），与 $H$ 总长最优矛盾。令 $D$ 为与 $c_1$ 不相交的候选集（全部位于 $c_1$ 右侧）。贪心在 $c_1$ 之后的选法恰是对 $D$ 做同一贪心：真包含 $c_1$ 者左端 $\le R_{c_1}$，永远被跳过；$D$ 的成员右端点顺序不变。$D$ 的最大不重叠数为 $k-1$（$\ge$：最优族去掉 $c_1$；$\le$：否则拼上 $c_1$ 超过 $k$）。任一最优 $k$-族去掉 $c_1$ 后是 $D$ 中的 $(k-1)$-族且为 $D$ 的长度最优（若 $D$ 有更省的同数族，拼回 $c_1$ 将比 $H$ 更省，矛盾）。由归纳假设，贪心在 $D$ 上取到该最小总长，故贪心总长 $= |c_1| + \min_D \le |H|$。∎

**推论 2（唯一性）**：最优闭包族唯一——定理 (2) 已证每个最优族都含 $c_1$，剥掉 $c_1$ 后的余下部分是 $D$ 的唯一最优族（对 $|\mathcal{C}|$ 归纳），逐层剥洋葱即得唯一。这正是题目「可以证明最小总长度解是唯一的」的来源。

## 6. 复杂度分析

- **时间复杂度**：$O(n + \sigma^2 n + \sigma \log \sigma)$，其中 $\sigma = 26$。一趟统计 $O(n)$；闭包扩张最坏 $O(\sigma^2 n)$——每个字符至多 $\sigma + 1$ 趟扫描、每趟不超过其闭包长度，而 $\sum_c |\mathrm{cl}(c)| \le \sigma n$，上界约 $6.8 \times 10^7$ 次字符访问（实际远小于：闭包长度之和通常远小于 $\sigma n$，绝大多数串一两趟就收敛）；排序去重 $O(\sigma \log \sigma)$；贪心 $O(\sigma)$。
- **空间复杂度**：$O(\sigma)$ 额外空间（`first`/`last` 数组与候选表，C++ 直接在原串上扫描）；输出子串共 $O(n)$。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    vector<string> maxNumOfSubstrings(string s) {
        int n = s.size();
        vector<int> first(26, -1), last(26, -1);
        for (int i = 0; i < n; i++) {
            int c = s[i] - 'a';
            if (first[c] == -1) first[c] = i;
            last[c] = i;
        }
        vector<pair<int, int>> cands;                 // (st, en)：各字符的闭包
        for (int c = 0; c < 26; c++) {
            if (first[c] == -1) continue;
            int st = first[c], en = last[c];
            int k = st;
            while (k <= en) {
                int d = s[k] - 'a';
                en = max(en, last[d]);                // 先记右端信息
                if (first[d] < st) {                  // 左侧有字符跨度越界
                    st = first[d];
                    k = st;                           // 回退到新左端重扫
                } else {
                    k++;
                }
            }
            cands.emplace_back(st, en);
        }
        // 引理 4：不同闭包右端点互不相同 ⇒ 按右端点排序无歧义
        sort(cands.begin(), cands.end(),
             [](const pair<int, int>& a, const pair<int, int>& b) { return a.second < b.second; });
        cands.erase(unique(cands.begin(), cands.end()), cands.end());
        vector<string> res;
        int lastEnd = -1;
        for (auto& [st, en] : cands) {
            if (st > lastEnd) {                       // 严格大于：不重叠 = j < x
                res.push_back(s.substr(st, en - st + 1));
                lastEnd = en;
            }
        }
        return res;
    }
};
```

### Python

```python
class Solution:
    def maxNumOfSubstrings(self, s: str) -> List[str]:
        first, last = {}, {}
        for i, ch in enumerate(s):
            first.setdefault(ch, i)
            last[ch] = i
        cands = set()
        for ch in first:
            st, en = first[ch], last[ch]
            k = st
            while k <= en:
                d = s[k]
                en = max(en, last[d])                 # 先记右端信息
                if first[d] < st:                     # 左侧有字符跨度越界
                    st = first[d]
                    k = st                            # 回退到新左端重扫
                else:
                    k += 1
            cands.add((st, en))
        res = []
        last_end = -1
        for st, en in sorted(cands, key=lambda x: x[1]):
            if st > last_end:                         # 严格大于：不重叠 = j < x
                res.append(s[st:en + 1])
                last_end = en
        return res
```

## 8. 边界情况与易错点

1. **全同字符**：`s = "aaaa"` 中任何真子串都含 `a` 却没包揽全部 `a`，唯一合法子串是整串——答案 `["aaaa"]`。贪心天然正确（唯一闭包就是 $[0, n-1]$）。
2. **扩张别忘了向左**：只写 `en ← max(en, last[d])` 不处理 `st` 左移是最常见的 WA——`"abab"` 中 `b` 的闭包是 $[0,3]$ 而非 $[1,3]$，左端被 $I_a$ 拉出去。回退时 `k` 必须重置到新 `st`，且 `en` 的更新要放在回退判断**之前**（见 §4 第 1 条）。
3. **严格不等号**：不重叠条件是 $j < x$，判断必须写 `st > lastEnd` 而非 `>=`；相邻区间 $[0,2]$ 与 $[3,5]$ 合法，共享下标才算重叠。
4. **763 套路迁移错误**：按「跨度相交就合并连通块」做，例 1 只能得 2 段——扩张的触发条件是「区间内出现」，不是「跨度相交」（§3.2 的 ⚠️ 块）。
5. **排序别用左端点**：按左端点排序会先选中 $[0,7]$，把 e、f、ccc 全部压住，例 1 直接错成 2 段。必须按右端点（最早结束）。
6. **数目优先于长度**：先最大化个数、再谈总长——例 2 中 `["d","abba","cc"]`（3 个、总长 7）输给 `["d","bb","cc"]`（3 个、总长 5），但两者数目并列；若把长度放在第一位贪心，会在数目上翻车。
7. **去重意识**：`a` 与 `d` 闭包相同很常见；不去重侥幸不错（重复区间第二次会被 `st > lastEnd` 挡下），但显式去重与证明对齐、代码意图清晰。
8. **无空解**：$n \ge 1$ 时整串永远合法，答案至少 1 段；贪心必选第一个（右端最小的）候选，不存在空输出。

**延伸思考**：

- **为什么候选只有 26 个**：可解性的根源是「包含即全量」把合法子串的下界锁到字符跨度上，而字符只有 $\sigma$ 种。若把条件 2 弱化成「出现次数至多一半」之类，闭包结构立刻失效，问题往往回到 $O(n^2)$ 起步。
- **双目标词典序贪心的交换论证**（§5 定理 (2)）：先证「每个最优解必含当前最早结束的候选」（严格长度差排除替换反例），再归纳收尾——这套论证可直接搬到其他「数目优先、代价其次」的区间调度变体。
- **字符集推广**：若字符集换成任意集合 $\Sigma$（如 unicode），候选数仍线性于出现过的字符数，整套做法与证明不变，复杂度中 $\sigma$ 换成 $|\Sigma|$。
