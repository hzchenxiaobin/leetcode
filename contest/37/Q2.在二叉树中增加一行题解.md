# LeetCode 在二叉树中增加一行 题解

## 1. 题目概述

- **标题 / 题号**：在二叉树中增加一行（#623，medium）
- **链接**：https://leetcode.cn/problems/add-one-row-to-tree/
- **来源**：LeetCode 第 37 场周赛 Q2
- **难度**：中等
- **标签**：树，深度优先搜索，广度优先搜索，二叉树

**题意**：给定二叉树根 `root`、整数 `val` 与深度 `depth`（根位于深度 $1$），要在深度 `depth` 处「造出一整行」值为 `val` 的节点。做法是：对深度 $depth-1$ 的**每个非空节点** `cur`，新建两个值为 `val` 的节点，分别作为 `cur` 的左、右子树根；`cur` 原来的左子树接到**新左节点的左指针**上，原来的右子树接到**新右节点的右指针**上。特例 `depth == 1` 时没有 $depth-1$ 层，于是新建一个 `val` 节点作为整棵树的新根，原树整体成为它的**左子树**。返回新树的根。

**约束**：

- 节点数在 $[1, 10^4]$ 范围内
- 树的深度在 $[1, 10^4]$ 范围内（不保证平衡，可能是 $10^4$ 个节点的单链）
- 节点值 $-100 \le \text{Node.val} \le 100$；$-10^5 \le val \le 10^5$
- $1 \le depth \le \text{树的深度} + 1$，因此 $depth-1$ 层一定存在且非空

## 2. 示例

**示例 1**

```text
输入：root = [4,2,6,3,1,5], val = 1, depth = 2
输出：[4,1,1,2,null,null,6,3,1,5]
解释：depth−1 = 1，这一层只有根 4。4 的左右各插入一个 1：新左节点接住原子树 2（含 3、1），
      新右节点接住原子树 6（含 5），层序写出即 4 | 1 1 | 2 null null 6 | 3 1 5。
```

**示例 2**

```text
输入：root = [4,2,null,3,1], val = 1, depth = 3
输出：[4,2,null,1,1,3,null,null,1]
解释：depth−1 = 2，这一层只有节点 2。2 的左右各插入一个 1：新左节点的左孩子是原左子树 3，
      新右节点的右孩子是原右子树 1，原来的 3、1 被整体下推一层，变成深度 4 的节点。
```

**补充示例（两个关键边界）**

```text
输入：root = [4,2,6,3,1,5], val = 1, depth = 1
输出：[1,4,null,2,6,3,1,5]
解释：depth = 1 走特例：新根为 1，原树挂在它的左指针上，右指针为空。

输入：root = [1,2,3], val = 5, depth = 3     （depth = 树高 + 1）
输出：[1,2,3,5,5,5,5]
解释：depth−1 = 2 层是叶子层 2、3，它们原本没有孩子，仍要各新建两个 5。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的做法是「先序列化再插行」：把树按层序导出成数组，在数组里插出一整行，再反序列化回来。问题在于插入一行后，**下层所有节点的下标整体平移**，空节点占位必须一个不差地补出来；而且即使 `depth == 2`（只动根的两个指针）也要把整棵树复制一遍，时间 $O(n)$、额外空间 $O(n)$，代码还很脆。另一种朴素思路是「先收集再统一改」：BFS 把全部节点连同层号存进 `vector<vector<TreeNode*>>`，再从第 $depth-1$ 层取出节点逐个挂接。这能写对，但存了整棵树，空间 $O(n)$；而且必须过滤掉「$depth-1$ 层节点为空的那些孩子」——题面只对**非空节点** `cur` 操作，误把空指针当成 `cur` 会直接段错误。

所以两种暴力的时间虽已是 $O(n)$ 下界，却都多花了没必要的时间和空间——真正需要改写的只有 $depth-1$ 这一层。

### 3.2 核心观察：插入是一次「局部挂接」

![局部挂接：新节点占住 depth 层，原子树整体下移](images/wc37_q2_insert_rewire_concept.svg)

把规则逐条翻译成指针操作，会得到三个关键结论：

1. **只有 $depth-1$ 层的节点被改写**。对别的节点，连一个指针都不碰；原树中深度 $\ge depth$ 的节点只是「整体下移一层」，相对结构、父子关系、中序相对次序全部不变。
2. **挂接是非对称的**。新左节点只认原来的**左**子树（`newLeft.left = cur.left`，它的右孩子为空）；新右节点只认原来的**右**子树（`newRight.right = cur.right`，它的左孩子为空）。绝不能写成 `newLeft.right = cur.right`——那样中序顺序就变了。
3. **`depth == 1` 是唯一「没有父层」的情形**，无法用上面的局部挂接表达，只能造一个新根：`newRoot.left = root`，`newRoot.right = null`。

于是问题塌缩成一句话：**走到第 $depth-1$ 层，对层内每个节点做一次固定的三指针改写。** 剩下的全部工作量只是「怎么稳稳地走到那一层」。

### 3.3 算法流程

![BFS 下潜到 depth−1 层再整层挂接](images/wc37_q2_bfs_flow.svg)

1. **特判**：若 `depth == 1`，返回 `new TreeNode(val, root, nullptr)`，结束。
2. **初始化**：队列 `q = {root}`，当前层号 `curDepth = 1`（根在深度 1）。
3. **下潜**：当 `curDepth < depth - 1` 时循环——先记下本层节点数 `sz`，弹出 `sz` 个节点，把它们的**非空**孩子按左、右顺序入队，然后 `curDepth++`。循环执行 $depth-2$ 次后停下。
4. **此时 `q` 中恰好是第 $depth-1$ 层的全部非空节点**（这是下面正确性证明里的引理 1）。
5. **整层挂接**：依次弹出每个 `cur`，执行 `newLeft = TreeNode(val, cur.left, null)`、
   `newRight = TreeNode(val, null, cur.right)`，再令 `cur.left = newLeft`、`cur.right = newRight`。**新节点不入队**。
6. 返回 `root`（`depth >= 2` 时根没有变）。

为什么用 BFS 而不是递归 DFS？因为树深可以达到 $10^4$（退化成一条链），Python 默认递归上限 1000 会直接 `RecursionError`；BFS 是迭代的，天然没有栈风险，而且「按层推进」和题意「在第 $depth-1$ 层操作」完全同构，`curDepth` 一个变量就把层号管住了。DFS 写法当然也行（递归参数带层号，`d == depth-1` 时就地挂接并**不再往下递归**），只是要额外处理递归深度。

### 3.4 示例演算

![示例 2 的前后对照](images/wc37_q2_example_walkthrough.svg)

**示例 1**（`root = [4,2,6,3,1,5]`，`val = 1`，`depth = 2`）：

| 步骤 | 内容 |
|------|------|
| 下潜 | `curDepth` 已等于 `depth-1 = 1`，一次都不下潜，队列即 `{4}` |
| 挂接 | `4`：新左 `1` 接原左 `2`（带 3、1），新右 `1` 接原右 `6`（带 5） |
| 层序 | `4` ｜ `1 1` ｜ `2 null null 6` ｜ `3 1 5` |

**示例 2**（`root = [4,2,null,3,1]`，`val = 1`，`depth = 3`）：

| 步骤 | 内容 |
|------|------|
| 下潜 | 条件 `curDepth < 2`，执行 1 轮：弹出 `{4}`、入队 `{2}`（4 的右孩子为空不入队），队列即第 2 层 |
| 挂接 | `2`：新左 `1` 接原左 `3`，新右 `1` 接原右 `1` |
| 层序 | `4` ｜ `2 null` ｜ `1 1` ｜ `3 null null 1`，即 `[4,2,null,1,1,3,null,null,1]` |

注意示例 2 输出里最后的那个 `1`：它是**新右节点的右孩子**，位于第 4 层最右侧；如果误挂成左孩子，层序会变成 `[4,2,null,1,1,3,null,1]`，一眼就能看出错。

## 4. 算法细节

1. **`depth == 1` 必须是第一步特判**，返回的是**新节点**而不是 `root`：`new TreeNode(val, root, nullptr)`。新根的右孩子一定为空（题面只说「原树作为左子树」），写成左右都挂原树是错的。
2. **先建新节点、后改写父指针**。`new TreeNode(val, cur->left, nullptr)` 这一步已经读走了旧左指针，之后 `cur->left = newLeft` 才安全；如果先 `cur->left = new TreeNode(val)`，旧子树指针就永久丢失了（既错又泄漏）。
3. **整层出队要「先固化长度」**。写成 `while (!q.empty())` 边弹边压，会把下一层甚至更深的节点也当成 $depth-1$ 层处理；正确写法是先取 `sz = q.size()` 再循环 `sz` 次。同理，第二阶段弹出的新节点绝不能再入队，否则会重复插入甚至死循环。
4. **入队只入非空孩子**。空孩子不是 `cur`，不能插入；这条同时保证了队列里永远是真实节点，第二阶段 `while (!q.empty())` 不需要额外判空。
5. **下潜次数是 $depth-2$，不是 $depth-1$**。`curDepth` 从 1（根所在层）起算，循环条件写 `curDepth < depth - 1`；`depth = 2` 时条件立即为假，队列就是 `{root}`，正好。
6. **左右挂法不对称**（本题最易错的一点）：新左节点只继承**左**子树，新右节点只继承**右**子树，另一侧一律为空。这是「增加一行」而不是「交换子树」。
7. **深链防护**。`depth` 可达 $10^4$：BFS 时队列里最多只有一个元素，非常省；若改写递归 DFS，务必 `sys.setrecursionlimit(100000)` 或用显式栈，否则链状树直接崩。

## 5. 正确性证明

**引理 1（BFS 恰好停在 $depth-1$ 层）**：对任意 $depth \ge 2$，第 3 步的下潜循环结束时，队列中的节点恰好是原树第 $depth-1$ 层的全部非空节点，且按从左到右的顺序排列。

**证明**：对 `curDepth` 归纳。初始 `curDepth = 1`，队列为 `{root}`，正是第 1 层的全部（非空）节点，结论成立。设某轮开始时 `curDepth = k` 且队列恰为第 $k$ 层节点；本轮弹出这 `sz` 个节点、按左后右的顺序压入它们的非空孩子，由层序定义，压入的正是第 $k+1$ 层的全部非空节点，且相对次序不变，随后 `curDepth` 变为 $k+1$，结论保持。循环共执行 $depth-2$ 轮，结束时 `curDepth = depth-1`，故队列即第 $depth-1$ 层全部非空节点。∎

**引理 2（单点挂接正确）**：对第 $depth-1$ 层的任一节点 `cur`，执行 `newLeft = TreeNode(val, cur.left, null)`、`newRight = TreeNode(val, null, cur.right)`、`cur.left = newLeft`、`cur.right = newRight` 之后：`cur` 的左右孩子都变为值为 `val` 的新节点，新左节点的左子树恰为 `cur` 的原左子树，新右节点的右子树恰为 `cur` 的原右子树，且 `cur` 及其子树的其余部分不变。

**证明**：`newLeft` 在构造时把 `cur.left` 读入自己的左指针、右指针置空；`newRight` 把 `cur.right` 读入自己的右指针、左指针置空；随后两条赋值只改写 `cur` 的两个孩子指针，且写入的正是刚构造的两个节点。因此旧左子树只被「转移」到 `newLeft.left`，旧右子树只被「转移」到 `newRight.right`，没有任何节点被复制或丢弃，其余指针未被触碰。∎

**引理 3（$depth = 1$ 的特判正确）**：算法在 `depth == 1` 时返回的新树满足题面第四条规则。

**证明**：新根值为 `val`，其左孩子为原根 `root`、右孩子为空。于是原树整体成为新根的左子树，且原树每个节点的深度都增加 1，正好对应「在深度 1 处增加一行、原有节点整体下移一层」。∎

**定理**：算法返回的树恰为题目要求的那棵树（该树由规则唯一确定）。

**证明**：分两种情形。

- `depth == 1`：由引理 3，返回树满足规则；且规则在此情形下唯一地指定了「新根 + 原树作左子树」，故与要求一致。
- $depth \ge 2$：由引理 1，算法改写的节点集合恰为第 $depth-1$ 层的全部非空节点；由引理 2，其中每个 `cur` 都被替换为「两个 `val` 孩子 + 原左子树挂新左、原右子树挂新右」的形态，其余节点指针未被改动。这正好逐条满足题面四条规则，故结果与规则唯一确定的树相同。

两种情形的返回树都与要求一致，定理得证。∎

## 6. 复杂度分析

- **时间**：$O(n)$。下潜阶段访问第 $1$ 到第 $depth-1$ 层的每个节点各一次，每个节点做常数次出入队与判空；挂接阶段访问第 $depth-1$ 层节点各一次，每次新建两个节点、写四个指针，$O(1)$。设第 $depth-1$ 层有 $k$ 个节点，则总时间为 $O(\text{前 }depth-1\text{ 层节点数} + k) \le O(n)$。特别地 `depth = 2` 时只访问根，$O(1)$；`depth = 树高 + 1` 时访问全部节点，仍为 $O(n)$。
- **空间**：$O(w)$，$w$ 为第 $1$ 到第 $depth-1$ 层中最宽一层的节点数，最坏 $w = O(n)$（完全二叉树最底层约 $n/2$ 个节点）。队列之外只有常数个临时指针；新建的 $2k$ 个节点属于答案本身，不计入额外空间。若改用递归 DFS，则额外还有 $O(h)$ 的调用栈，$h$ 为树高，最坏 $10^4$。

## 7. 参考代码

### C++

```cpp
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    TreeNode* addOneRow(TreeNode* root, int val, int depth) {
        if (depth == 1) {
            return new TreeNode(val, root, nullptr);   // 原树整体成为新根的左子树
        }

        queue<TreeNode*> q;
        q.push(root);
        int curDepth = 1;
        // 下潜 depth-2 次，循环结束后 q 中就是第 depth-1 层
        while (!q.empty() && curDepth < depth - 1) {
            int sz = q.size();                         // 先固化本层节点数
            for (int i = 0; i < sz; ++i) {
                TreeNode* cur = q.front();
                q.pop();
                if (cur->left)  q.push(cur->left);     // 只入队非空孩子
                if (cur->right) q.push(cur->right);
            }
            ++curDepth;
        }

        // 对 depth-1 层的每个节点做一次局部挂接
        while (!q.empty()) {
            TreeNode* cur = q.front();
            q.pop();
            TreeNode* newLeft  = new TreeNode(val, cur->left,  nullptr);  // 新左继承原左子树
            TreeNode* newRight = new TreeNode(val, nullptr, cur->right);  // 新右继承原右子树
            cur->left  = newLeft;
            cur->right = newRight;
        }
        return root;
    }
};
```

### Python

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
from collections import deque
from typing import Optional


class Solution:
    def addOneRow(self, root: Optional[TreeNode], val: int, depth: int) -> Optional[TreeNode]:
        if depth == 1:
            return TreeNode(val, root, None)          # 原树整体成为新根的左子树

        q = deque([root])
        cur_depth = 1
        # 下潜 depth-2 次，循环结束后 q 中就是第 depth-1 层
        while q and cur_depth < depth - 1:
            for _ in range(len(q)):                   # 先固化本层节点数，整层出队
                cur = q.popleft()
                if cur.left:
                    q.append(cur.left)                # 只入队非空孩子
                if cur.right:
                    q.append(cur.right)
            cur_depth += 1

        # 对 depth-1 层的每个节点做一次局部挂接（新节点不再入队）
        while q:
            cur = q.popleft()
            new_left = TreeNode(val, cur.left, None)   # 新左继承原左子树
            new_right = TreeNode(val, None, cur.right)  # 新右继承原右子树
            cur.left = new_left
            cur.right = new_right
        return root
```

## 8. 边界情况与易错点

1. **`depth == 1`**：`root = [4,2,6,3,1,5], val = 1` 应得 `[1,4,null,2,6,3,1,5]`。若忘记返回新根（仍返回 `root`），或把原树同时挂到左右两侧，答案直接错。
2. **补到最底层（`depth = 树高 + 1`）**：`[1,2,3], val = 5, depth = 3` 应得 `[1,2,3,5,5,5,5]`；此时 $depth-1$ 层是叶子，原孩子全为空，仍必须为**每个**叶子新建两个 `5`，只给「已有孩子的位置」插入会漏一半。单节点树同理：`[1], val = 5, depth = 2` 应得 `[1,5,5]`。
3. **单侧孩子必须挂对侧**：示例 2 中新右节点的原右子树 `1` 要挂在**右**指针上，输出末位才是 `...null,null,1]`；挂到左指针会变成 `[4,2,null,1,1,3,null,1]` 之类结构，层序长度都不一样。
4. **旧指针丢失**：先 `cur->left = new TreeNode(val)` 再想取原子树就没有引用了。务必把 `cur->left` 作为构造参数传给新节点。
5. **整层处理写成了全树处理**：漏掉 `sz = q.size()` 会导致 `depth-1` 层之外的节点也被挂接，节点数暴涨（甚至无限循环）。
6. **深树与递归上限**：树深可达 $10^4$。BFS 版本无风险；若用递归 DFS，Python 必须 `sys.setrecursionlimit(100000)`，否则链状数据 `RecursionError`。

**延伸思考**：

1. **统计插入后第 $depth$ 层的节点数**：不需要真的建树。因为每个 $depth-1$ 层节点都会得到**两个**新孩子（原孩子是否为空都新建），所以插入后该层节点数恒为 $2k$，$k$ 为 $depth-1$ 层节点数——与原 $depth$ 层有多少节点完全无关。
2. **只插一侧的变体**：若要求「只在新左节点插入、原右子树保持不动」，只需把 `cur.right` 的改写去掉，同时注意此时「增加一行」的语义已被破坏，需要重新确认题意。
3. **交换语义的变体**：若要求「原左子树成为新左节点的**右**子树」，就是把 `newLeft` 的两个孩子换个位置。本题所有变体都只是改一处构造参数，骨架（走到第 $depth-1$ 层 + 局部挂接）不变。
