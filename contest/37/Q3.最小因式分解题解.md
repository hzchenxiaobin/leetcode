# LeetCode 最小因式分解 题解

## 1. 题目概述

- **标题 / 题号**：最小因式分解（#625，medium）
- **链接**：https://leetcode.cn/problems/minimum-factorization/
- **来源**：LeetCode 第 37 场周赛 Q3
- **难度**：中等
- **标签**：贪心、数学、质因数分解

**题意**：给定正整数 $a$，求**最小**的正整数 $b$，使 $b$ 的**每一位数字之积**等于 $a$。若不存在这样的 $b$，或者最小的 $b$ 超出 **32 位有符号整数**范围，返回 $0$。

换个说法：把 $a$ 写成若干个取自 $\{2,3,4,5,6,7,8,9\}$ 的因子之积，每个因子对应 $b$ 的一位，要求拼出来的十进制数最小。

**约束**：

- $1 \le a \le 2^{31}-1$，即 $a \le 2147483647$
- 返回值必须是 32 位有符号整数：无解、溢出都返回 `0`
- 入参只有一个整数，不存在空输入/长度限制之类的坑

> 💡 **先定两个调子**：$b$ 的数位中出现 $0$ 会让乘积变成 $0$、出现 $1$ 只增加位数不改变乘积，所以最优解的数位全部落在 $\{2,\dots,9\}$；又因为**位数越少，数值越小**，问题就化成「用最少的数位撑起乘积 $a$」。

## 2. 示例

**示例 1**

```text
输入：a = 48
输出：68
解释：6 × 8 = 48，且 68 是满足条件的最小正整数。
      其它分解：2 × 4 × 6 → 246（三位，更大）；
      48 = 3 × 16 不合法，因为 16 不是单个十进制数位。
```

**示例 2**

```text
输入：a = 15
输出：35
解释：3 × 5 = 15；1 × 3 × 5 → 135 位数更多只能更大。
```

**示例 3（补充：无解的情形）**

```text
输入：a = 11
输出：0
解释：11 是大于 7 的质数，而任何数位 2..9 都不含因子 11，故无解。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的做法是从小到大枚举 $b = 1, 2, 3, \dots$，计算各位数字之积，第一个等于 $a$ 的就是答案。问题在于上界完全不可预判：$a = 2^{19}$ 时答案已经是 $2888882$，$a$ 再大一点就突破 $10^9$，枚举量无法估计。另一个朴素想法是枚举 $a$ 的全部因子分解再取最小拼接，因子组合数随 $a$ 的因子个数指数增长，最坏同样是指数级。两种做法在 $a \le 2^{31}-1$ 上都不可接受。

### 3.2 核心观察：把质因子「打包」进数位

![质因子打包](images/wc37_q3_greedy_digit_packing.svg)

三条观察层层递进：

1. **数位只能是 $2..9$**：$0$ 让乘积归零，$1$ 只增位数，都不出现在最优解里。
2. **位数越少越好**：$b$ 没有前导零，任何 $k$ 位数都小于任何 $k+1$ 位数，所以先最小化位数，再在同位数内最小化数值。
3. **一个数位就是质因子 $2,3,5,7$ 的一个小包裹**：$9 = 3^2$、$8 = 2^3$、$6 = 2\cdot 3$、$4 = 2^2$、$5$、$7$ 各自独占。要让位数最少，就得让每个数位「吃满」——先 $9$（两个 3），再 $8$（三个 2），再 $6$（一个 2 加一个 3），最后才轮到 $4$、$3$、$2$ 收尾。

于是得到贪心：**$d$ 从 $9$ 递减到 $2$，只要 $a$ 还能被 $d$ 整除，就一直除以 $d$ 并记录 $d$；循环结束后 $a \ne 1$ 说明含 $\ge 11$ 的质因子，无解**。

为什么 $9$ 必须排在 $8$ 前面？因为 $3$ 只有 $9$（一次两个）和 $6$、$3$（一次一个）能吃，$9$ 是唯一一次吃掉两个 3 的数位，留到后面就会被拆成两个数位。比如 $36 = 4 \times 9 = 49$（两位），若先拿 $6$ 就只剩 $6 \times 6 = 66$，更大。

### 3.3 算法流程

![算法流程](images/wc37_q3_algorithm_flow.svg)

1. $a < 10$：$a$ 本身是一位数，直接返回 $a$（含 $a = 1$，其各位之积为 $1$）。
2. `digits = []`，$d$ 从 $9$ 到 $2$：`while a % d == 0: a //= d; digits.append(d)`。
3. 若 $a \ne 1$：无解，返回 `0`。
4. `digits` 是**降序**记录的，反转后逐位拼成 $b$（升序即同位数下的最小排列）。
5. 拼接过程中一旦 $b > 2^{31}-1$ 立即返回 `0`。

### 3.4 示例演算

![演算示例](images/wc37_q3_walkthrough.svg)

$a = 756 = 2^2 \cdot 3^3 \cdot 7$ 的逐步走查见上图：$756 \to 84 \to 12 \to 2 \to 1$，记录 $[9,7,6,2]$，反转得 $b = 2679$，校验 $2\times6\times7\times9 = 756$。

再走一遍示例 1：$a = 48 = 2^4 \cdot 3$。$d=9$ 不整除；$d=8$ 整除一次，$48/8 = 6$，$6 \not\equiv 0 \pmod 8$ 故只记一个 $8$；$d=6$ 整除，$6/6 = 1$。记录 $[8,6]$，反转得 $b = 68$。✓

## 4. 算法细节

1. **特判一位数**：$a < 10$ 直接返回 $a$。这不是可选优化——若跳过，$a = 1$ 时循环结束时 `digits` 为空，拼出来的 $b = 0$ 是错的。
2. **用 `while` 而不是 `if`**：$a = 243 = 3^5$ 需要连续除两次 $9$（$243 \to 27 \to 3$），记录 $[9,9,3]$，答案 $399$；写成 `if` 会漏掉数位。
3. **循环顺序必须 $9 \to 2$ 递减**：只有递减才能保证每个数位都是「当前能用的最大包裹」，也才能保证记录序列天然降序、反转即升序。
4. **拼接用 64 位 / 大整数**：位数最多可达 $\lfloor \log_2 a \rfloor \le 30$，远超 `int`，C++ 中间结果必须 `long long`。
5. **溢出可提前判定**：若数位个数 $\ge 10$，则 $b \ge 2222222222 > 2^{31}-1$ 必然溢出；而 9 位最大也只到 $999999999 < 2^{31}-1$，一定安全。所以 `digits.size() >= 10` 时可直接返回 `0`，代码里保留数值判断做双保险。
6. **余数校验放在循环之后**：若 $a$ 含 $\ge 11$ 的质因子，循环结束时 $a > 1$。不要在处理过程中提前返回，否则 $a = 48$ 这类输入会被误杀（$d = 9$ 时不整除，但后面还有机会）。
7. **不需要回溯/DP**：DFS 枚举分解也能做，但贪心已是 $O(\log a)$ 且可证明正确（见 §5），没必要引入指数级复杂度。

## 5. 正确性证明

记 $a = 2^p 3^q 5^r 7^s$（若含 $\ge 11$ 的质因子见引理 1），$P = \lfloor p/3 \rfloor$，$Q = \lfloor q/2 \rfloor$。

**引理 1（可行性）**：$a$ 能写成若干数位之积 $\iff$ $a$ 的质因子全部属于 $\{2,3,5,7\}$；此时贪心循环结束时 $a = 1$。

**证明**：数位都在 $2..9$ 中，其质因子只有 $2,3,5,7$，故乘积 $a$ 的质因子也只能是这四个，必要性得证。充分性：若 $a$ 只含这四个质因子，贪心按 $9,8,7,6,5,4,3,2$ 的顺序去除时，$5$ 与 $7$ 在各自那一轮被彻底除尽；$2$ 的指数被 $8,6,4,2$ 逐轮消耗完；$3$ 的指数被 $9,6,3$ 逐轮消耗完，故结束时 $a = 1$。反之若 $a$ 含质因子 $p \ge 11$，任何数位之积都不含 $p$，无解，且贪心结束时必有 $a \ge p > 1$。∎

**引理 2（位数下界，贪心恰好取到）**：任意合法解的数位个数 $k \ge r + s + \lceil p/3 + q/2 \rceil$，而贪心解恰好有这么多位。

**证明**：$5$ 与 $7$ 都不能与别的数位相乘（$5 \cdot 2 = 10 > 9$，$7\cdot2 > 9$），所以每个 $5$、每个 $7$ 必须独占一位，这部分固定 $r + s$ 位。对只含 $2,3$ 的数位赋权 $w(d) = t_2(d)/3 + t_3(d)/2$（$t_i$ 为该数位中质因子 $i$ 的指数）：$w(2) = 1/3$、$w(3) = 1/2$、$w(4) = 2/3$、$w(6) = 5/6$、$w(8) = w(9) = 1$，每个数位的权都不超过 $1$，而全部数位权之和恰为 $p/3 + q/2$，故承载 $2,3$ 的那部分数位个数 $k' \ge \lceil p/3 + q/2\rceil$。下界可达：贪心先除尽 $9$（占 $Q$ 位）、再除尽 $8$（占 $P$ 位），之后 $p \bmod 3 \in \{0,1,2\}$、$q \bmod 2 \in \{0,1\}$，六种余数组合的收尾数位与位数如下表，位数与 $\lceil p/3 + q/2\rceil = P + Q + \lceil (p\bmod3)/3 + (q\bmod2)/2\rceil$ 逐行相等。∎

| $(p \bmod 3,\ q \bmod 2)$ | 收尾数位 | 位数 | 下界 |
|---|---|---|---|
| $(0,0)$ | 无 | $P+Q$ | $P+Q$ |
| $(0,1)$ | $3$ | $P+Q+1$ | $P+Q+1$ |
| $(1,0)$ | $2$ | $P+Q+1$ | $P+Q+1$ |
| $(1,1)$ | $6$ | $P+Q+1$ | $P+Q+1$ |
| $(2,0)$ | $4$ | $P+Q+1$ | $P+Q+1$ |
| $(2,1)$ | $6,\,2$ | $P+Q+2$ | $P+Q+2$ |

**引理 3（同位数下数值最小）**：设贪心解数位升序为 $g_1 \le \dots \le g_m$，任意 $m$ 位合法解的数位升序为 $d_1 \le \dots \le d_m$，则 $g$ 拼成的数不大于 $d$ 拼成的数。

**证明**：位数固定时升序排列显然最小。若解中存在两个数位 $x \le y$ 可「再平衡」为 $x' < x$、$y' > y$ 且 $x'y' = xy$、$y' \le 9$，则替换后位数不变：新的升序序列中 $x'$ 使某个前缀多出一个更小的值，而变大只发生在更靠后的位置，故数值严格变小（例如 $\{3,4\} \to \{2,6\}$ 得 $26 < 34$，$\{4,4\} \to \{2,8\}$ 得 $28 < 44$，$\{6,6\} \to \{4,9\}$ 得 $49 < 66$）。贪心解正好是这样一次次再平衡的终点：它每一步取的都是「当前能整除剩余值的最大数位」，因此它的最小数位已无法再变小、最大数位也无法再变大，不存在任何可替换的数对；而可替换状态之间的替换严格减小数值、不会循环，同一 $a$ 的终止状态唯一，于是从任意 $m$ 位解出发反复替换必停在贪心解，贪心解不大于任何 $m$ 位解。∎

**定理**：算法返回的 $b$ 是满足条件的最小正整数；返回 `0` 时，要么无解，要么所有解都超出 32 位有符号整数范围。

**证明**：由引理 1，贪心能除到 $1$ 当且仅当 $a$ 的质因子都 $\le 7$，否则返回 `0`，与「无解返回 0」一致。设 $a$ 可解，贪心解有 $m$ 位：引理 2 说明它位数最少，引理 3 说明它在 $m$ 位解中数值最小，故是最小解。若 $m \ge 10$，引理 2 说明任何解的位数都 $\ge 10$，而数位都 $\ge 2$，故 $b \ge 2222222222 > 2^{31}-1$，所有解都溢出，返回 `0` 正确；反之 $m \le 9$ 时 $b \le 999999999 < 2^{31}-1$，代码里的数值判断不会误伤。∎

## 6. 复杂度分析

- **时间**：$O(\log a)$。外层固定 8 轮（$d = 9..2$）；内层 `while` 的总执行次数等于最终数位个数，而数位至少是 $2$，故不超过 $\lfloor \log_2 a \rfloor \le 30$；合计 $O(\log a)$，实际是常数级（不超过 38 次判断）。
- **空间**：$O(\log a)$，即 `digits` 数组，最多 30 个元素；其余变量 $O(1)$。
- 注意**不需要试除到 $\sqrt{a}$** 的质因数分解：只关心 $2..9$ 这 8 个数位，与 $a$ 的大小无关。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <climits>
using namespace std;

class Solution {
public:
    int smallestFactorization(int num) {
        if (num < 10) return num;               // 一位数直接返回（含 num = 1）
        vector<int> digits;
        for (int d = 9; d >= 2; --d) {
            while (num % d == 0) {              // 能除就除到底
                num /= d;
                digits.push_back(d);
            }
        }
        if (num != 1) return 0;                 // 含 >= 11 的质因子，无解
        long long res = 0;
        for (int i = (int)digits.size() - 1; i >= 0; --i) {
            res = res * 10 + digits[i];         // 逆序拼接 => 数位升序
            if (res > INT_MAX) return 0;        // 超出 32 位有符号整数
        }
        return (int)res;
    }
};
```

### Python

```python
class Solution:
    def smallestFactorization(self, num: int) -> int:
        if num < 10:
            return num                      # 一位数（含 1）直接返回
        digits = []
        for d in range(9, 1, -1):
            while num % d == 0:             # 能除就除到底
                num //= d
                digits.append(d)
        if num != 1:
            return 0                        # 含 >= 11 的质因子，无解
        res = 0
        for d in reversed(digits):
            res = res * 10 + d              # 逆序拼接 => 数位升序
            if res > 2**31 - 1:
                return 0                    # 超出 32 位有符号整数
        return res
```

## 8. 边界情况与易错点

1. **$a = 1$**：返回 $1$（$1$ 的各位之积为 $1$）。忘记特判 $a < 10$ 会返回 $0$。
2. **$a$ 是无解的大质数**：如 $a = 11$、$a = 2^{31}-1 = 2147483647$（梅森素数）都返回 `0`；注意不要写成返回 $-1$。
3. **溢出**：$a = 2^{30} = 1073741824 \Rightarrow 8888888888$、$a = 3^{19} = 1162261467 \Rightarrow 3999999999$，都超过 $2^{31}-1$，要返回 `0`，而不是截断后的负数。
4. **循环顺序写错**：$a = 36$ 若先试 $6$ 会得到 $66$，正确答案是 $49$（$36 = 4\times 9$）；顺序必须 $9 \to 2$ 递减。
5. **`if` 代替 `while`**：$a = 243 = 3^5$ 需要 $[9,9,3]$，每个 $d$ 只判断一次会漏数位。
6. **拼接用 `int`**：中间结果 $8888888888$ 已溢出 `int`，C++ 必须用 `long long`；Python 虽不受限，仍要显式判 $> 2^{31}-1$。
7. **不要引入数位 $1$**：$1$ 不改变乘积只增加位数（$15 \to 135$ 比 $35$ 大），最优解里永远没有 $1$。
