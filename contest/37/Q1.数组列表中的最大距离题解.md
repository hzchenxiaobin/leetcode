# LeetCode 数组列表中的最大距离 题解

## 1. 题目概述

- **标题 / 题号**：数组列表中的最大距离（#624，medium）
- **链接**：https://leetcode.cn/problems/maximum-distance-in-arrays/
- **来源**：LeetCode 第 37 场周赛 Q1
- **难度**：中等
- **标签**：贪心、数组

**题意**：给定 $m$ 个**已按升序排好**的数组。从**两个不同的数组**中各取一个整数 $a$、$b$，距离定义为 $|a-b|$，求能取到的**最大距离**。注意取数只能跨数组，同一数组内部取两个数是不允许的。

**约束**：

- $m = \text{arrays.length}$，$2 \le m \le 10^5$
- $1 \le \text{arrays}[i].\text{length} \le 500$
- $-10^4 \le \text{arrays}[i][j] \le 10^4$，且 `arrays[i]` **升序**
- 所有数组中的整数总数不超过 $10^5$

> 💡 输入规模的点睛之处：数组个数 $m$ 可达 $10^5$，但**总元素数只有 $10^5$**。这说明"每个数组都读完"是可接受的（$O(\text{total})$），而"枚举数组对"（$O(m^2)$）不可接受——优化的方向是**把每个数组压成一个数**，而不是去找更快的枚举。

## 2. 示例

**示例 1**

```text
输入：arrays = [[1,2,3],[4,5],[1,2,3]]
输出：4
解释：从第一个数组（或第三个）选 1，从第二个数组选 5，|1 − 5| = 4。
      跨数组组合里 4 就是上限：arr0 的 1 与 arr1 的 5、arr2 的 1 与 arr1 的 5 都达到它。
```

**示例 2**

```text
输入：arrays = [[1],[1]]
输出：0
解释：两个数组都只有一个数 1，唯一合法的跨数组取法给出 |1 − 1| = 0。
```

**示例 3**（补充：全局最值同属一个数组的陷阱）

```text
输入：arrays = [[0,9],[3,4]]
输出：6
解释：全局最小 0 与全局最大 9 都在 arr0，二者不能相减（同一数组）。
      合法取法只有跨数组：|0 − 4| = 4、|9 − 3| = 6，故答案为 6。
```

## 3. 解题思路

### 3.1 暴力思路

最直白的做法是枚举所有**跨数组的元素对** $(a,b)$，取 $|a-b|$ 的最大值。总元素数 $N$ 满足 $N \le 10^5$，元素对数量是 $O(N^2) = 10^{10}$ 级别，必然超时。

退一步，先把每个数组"读完"，然后枚举**数组对** $(i,j)$ 并在每个数组里挑最优元素——数组对本身有 $m^2$ 个，$m = 10^5$ 时同样是 $10^{10}$，仍然不行。

> 两个暴力都卡在"枚举两种东西的笛卡尔积"上。要想做到 $O(N)$，必须让**每个数组只贡献一个常数大小的代表**，并且让"代表之间的配对"能在一趟扫描里完成。

### 3.2 核心观察：每个数组只留首尾，答案是一族"有序对"的最大值

![核心观察：升序数组只留首尾，答案是有序对极值之差的最大值](images/wc37_q1_head_tail_concept.svg)

**观察 1（中间元素是废票）**：数组升序，故 $\min = $ 首元素、$\max = $ 末元素。对任意 $a \in A_i$ 与任意外部值 $v$，函数 $f(x) = |x - v|$ 在区间 $[mn_i, mx_i]$ 上是凸函数，最大值必在端点取得：

$$|a - v| \le \max\bigl(|mn_i - v|,\ |mx_i - v|\bigr)$$

也就是说，任何一个中间元素能拿到的距离，它的某个端点同样能拿到。**每个数组压缩成一个区间 $[mn_i, mx_i]$，中间元素全部丢掉**。

**观察 2（距离拆成"谁出最小、谁出最大"）**：$|a-b| = \max(a,b) - \min(a,b)$。设取数分别来自 $A_i$、$A_j$（$i \ne j$），则

$$|a-b| \le \max\bigl(mx_j - mn_i,\ mx_i - mn_j\bigr)$$

右端两个量都是**可实际取到**的距离（分别取 $mn_i$ 与 $mx_j$、$mx_i$ 与 $mn_j$）。于是把方向也枚举进去，问题等价于

$$\text{答案} = \max_{i \ne j}\ \bigl(mx_j - mn_i\bigr)$$

即：**枚举"哪个数组出最小值、哪个数组出最大值"这一有序对**。有序对值可能为负，但最大值一定 $\ge 0$（见 §5 引理 2 的补充），所以下面一律以 $0$ 兜底。

> 💡 一句话：**"选两个数比大小"被降维成"选两个数组定方向"，候选从 $N^2$ 个元素对缩到 $2m$ 个有序对。**
### 3.3 算法流程：前缀最值单趟扫描

![算法流程：先算候选、再更新前缀最值](images/wc37_q1_scan_flow.svg)

设 `prefMin` / `prefMax` 为**已经处理过的数组**里 $mn$ 的最小值与 $mx$ 的最大值。扫描到第 $t$ 个数组时，只拿它和前缀配对：

1. 初始化 `best = 0`，`prefMin = +∞`，`prefMax = −∞`；
2. 对每个数组 $t$：取 $mn = A_t[0]$、$mx = A_t[\text{len}-1]$；
3. 若前缀非空，算两个候选：`candA = mx − prefMin`（$t$ 出最大、前面出最小）、`candB = prefMax − mn`（$t$ 出最小、前面出最大），`best = max(best, candA, candB)`；
4. **然后**更新 `prefMin = min(prefMin, mn)`、`prefMax = max(prefMax, mx)`；
5. 扫描结束返回 `best`。

> ⚠️ 第 3、4 步的顺序是本题唯一的技术点：**先算候选、后更新前缀**。若把更新提到前面，$mn$ 与 $mx$ 就可能来自同一个数组，$mx - mn$ 变成"自己减自己"，直接违反"两个不同数组"的约束。

注意 $\max_{i<t}(mx_t - mn_i) = mx_t - \min_{i<t} mn_i$，而 $\min_{i<t} mn_i$ 与 $\max_{i<t} mx_i$ 正是两个前缀标量——每步只需两次取最值，不必维护"次大 / 次小"。

### 3.4 示例演算

![示例演算：三个数组的两步前缀扫描走查](images/wc37_q1_example_walkthrough.svg)

**示例 1**（`[[1,2,3],[4,5],[1,2,3]]`）：

| $t$ | $mn$ | $mx$ | `prefMin` | `prefMax` | `candA = mx − prefMin` | `candB = prefMax − mn` | `best` |
|-----|------|------|-----------|-----------|------------------------|------------------------|--------|
| 0 | 1 | 3 | $\infty$ | $-\infty$ | 前缀空，跳过 | 前缀空，跳过 | 0 |
| 1 | 4 | 5 | 1 | 3 | $5-1=4$ | $3-4=-1$ | 4 |
| 2 | 1 | 3 | 1 | 5 | $3-1=2$ | $5-1=4$ | 4 |

$t=1$ 时 `candA` 命中答案（arr1 的 5 与 arr0 的 1），$t=2$ 的 `candB` 只是复现同一组数组对，故最终返回 $4$ ✓。

**示例 3**（`[[0,9],[3,4]]`，同数组陷阱）：

| $t$ | $mn$ | $mx$ | `prefMin` | `prefMax` | `candA` | `candB` | `best` |
|-----|------|------|-----------|-----------|---------|---------|--------|
| 0 | 0 | 9 | $\infty$ | $-\infty$ | 跳过 | 跳过 | 0 |
| 1 | 3 | 4 | 0 | 9 | $4-0=4$ | $9-3=6$ | 6 |

`candB` 用到了 arr0 的最大值 9 与 arr1 的最小值 3，跨数组合法，得 $6$ ✓；而"全局 max − 全局 min = 9"因为两端同在 arr0 而非法。

**示例 2**（`[[1],[1]]`）：$t=1$ 时 `candA = candB = 0`，`best` 保持 $0$ ✓。

## 4. 算法细节

1. **升序是免费信息**：直接 `a.front()` / `a.back()`（Python `a[0]` / `a[-1]`）取首尾，$O(1)$；不要写 `min(a)`、`max(a)`，那会把复杂度从 $O(m)$ 变成 $O(N)$（虽然本题仍可过，但白白多扫一遍）。
2. **顺序即正确性**：候选计算必须排在 `prefMin / prefMax` 更新之前。等价写法是先算出 `mn, mx` 局部变量，再参与候选，再更新前缀。
3. **前缀为空的判定**：C++ 用 `prefMin == INT_MAX` 判首轮，或用 `i > 0`；Python 用 `None` 哨兵，避免把 $+\infty$ 参与整数运算后得到 `inf`。
4. **`best` 初值取 0**：答案非负（$m \ge 2$，总能取到某个合法距离，且距离是绝对值），而 `candA`、`candB` 都可能为负，用 0 兜底省掉一次特判。
5. **不维护次大 / 次小**：常见的另一种写法是同时记录全局 min/max 的**所属下标**，若下标相同就退而使用次大 / 次小。这个写法要处理"次值不存在""多个并列极值"等分支，容易写错；前缀法用**时间顺序**天然隔离同数组，代码短且无分支。
6. **值域与类型**：$|a-b| \le 2 \times 10^4$，`int` 足够；即便放大到 $10^9$ 级别的值，只要用 `long long` 存差即可。切勿用无符号类型做减法，负数会回绕。
7. **流式即可**：不需要把 `mn/mx` 全部存下来再枚举数组对，扫描时用一个标量 `best` 累积，额外空间常数。

## 5. 正确性证明

**引理 1（端点支配）**：设 $A$ 升序，$mn = A[0]$、$mx = A[\text{len}-1]$。对任意 $a \in A$ 与任意整数 $v$，有 $|a - v| \le \max(|mn - v|,\ |mx - v|)$。

**证明**：令 $g(x) = |x - v|$。$a \in [mn, mx]$ 可写成凸组合 $a = (1-\lambda)mn + \lambda\, mx$（$\lambda \in [0,1]$），由绝对值函数的凸性

$$g(a) = g\bigl((1-\lambda)mn + \lambda\, mx\bigr) \le (1-\lambda)g(mn) + \lambda\, g(mx) \le \max\bigl(g(mn), g(mx)\bigr)$$

即证。∎

**引理 2（有序对公式）**：记 $mn_i = A_i[0]$、$mx_i = A_i[\text{len}-1]$，则

$$\max_{\substack{i \ne j\\ a \in A_i,\ b \in A_j}} |a - b| = \max_{i \ne j}\bigl(mx_j - mn_i\bigr)$$

**证明**：

- ($\le$) 任取 $i \ne j$、$a \in A_i$、$b \in A_j$。若 $a \le b$，则 $|a-b| = b - a \le mx_j - mn_i$；若 $a > b$，交换两个数所对的角色即得 $|a-b| = a - b \le mx_i - mn_j$。两种情形都被某个有序对的差值所界住，故左端 $\le$ 右端。
- ($\ge$) 设右端在有序对 $(i^*, j^*)$ 处取得。若 $mx_{j^*} - mn_{i^*} \ge 0$，取 $a = mn_{i^*}$、$b = mx_{j^*}$ 即得同样的距离，故左端 $\ge$ 右端。若 $mx_{j^*} - mn_{i^*} < 0$，则 $mx_{j^*} < mn_{i^*}$，考虑反方向有序对 $(j^*, i^*)$：由 $mn_{i^*} \le mx_{i^*}$、$mn_{j^*} \le mx_{j^*}$ 得 $mx_{i^*} - mn_{j^*} \ge mn_{i^*} - mx_{j^*} > 0$，与 $(i^*,j^*)$ 取到最大值矛盾。故最大值处必非负，两个方向一致。

补充：$m \ge 2$ 时右端必 $\ge 0$——若某对 $(i,j)$ 有 $mx_j < mn_i$，则反方向 $mx_i - mn_j \ge mn_i - mx_j > 0$，二者取大即非负；所以用 $0$ 兜底不会改变结果。∎

**引理 3（前缀扫描枚举全部有序对）**：扫描到第 $t$ 个数组时（$t$ 从 0 计），`prefMin` $=\min_{i<t} mn_i$、`prefMax` $=\max_{i<t} mx_i$；且

$$\texttt{candA} = \max_{i<t}\bigl(mx_t - mn_i\bigr),\qquad \texttt{candB} = \max_{i<t}\bigl(mx_i - mn_t\bigr)$$

**证明**：`prefMin` 是所有已处理 $mn_i$ 的最小值，故 $mx_t - \texttt{prefMin} = mx_t - \min_{i<t} mn_i = \max_{i<t}(mx_t - mn_i)$，`candB` 同理。∎

**定理**：算法返回 $\max_{i \ne j}(mx_j - mn_i)$，即题目所求最大距离。

**证明**：记 $M = \max_{i \ne j}(mx_j - mn_i)$，并设它在有序对 $(i^*, j^*)$ 处取得，令 $t = \max(i^*, j^*)$。

1. **不漏（`best` ≥ $M$）**：若 $i^* < j^* = t$，则引理 3 给出 `candA` $= \max_{i<t}(mx_t - mn_i) \ge mx_{j^*} - mn_{i^*} = M$；若 $j^* < i^* = t$，同理 `candB` $= \max_{j<t}(mx_j - mn_t) \ge mx_{j^*} - mn_{i^*} = M$。故扫描结束时 `best` $\ge M$。
2. **不超（`best` ≤ $M$）**：每个候选都由**一个更早的数组**与当前数组组成，是某个 $i \ne j$ 的 $mx_j - mn_i$；由 $M$ 的定义它 $\le M$。初值 $0 \le M$（引理 2 的补充），所以 `best` 全程 $\le M$。

两者合并得 `best` $= M$，再由引理 1（端点支配，保证取数只需端点）与引理 2（有序对公式，保证 $M$ 恰为最大跨数组距离）即得结论。∎

## 6. 复杂度分析

- **时间**：$O(m)$。每个数组只读首元素与末元素（$O(1)$ 次比较与减法），总共常数次操作 / 数组。$\Omega(m)$ 也是下界——任何一个未读的数组都可能藏着新的极值，使答案变大。
- **空间**：$O(1)$。只维护 `best`、`prefMin`、`prefMax`、`mn`、`mx` 五个标量，与 $m$ 和总元素数无关（不计输入本身）。
- 对比：按总元素数读入也是 $O(N)$，但那是输入体量，不是算法开销；本实现严格只碰 $2m$ 个元素。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maxDistance(vector<vector<int>>& arrays) {
        int best = 0;                                   // 答案非负，0 兜底
        int prefMin = INT_MAX, prefMax = INT_MIN;       // 已处理数组的极值
        for (auto& a : arrays) {
            int mn = a.front(), mx = a.back();          // 升序：首即最小、末即最大
            if (prefMin != INT_MAX) {                   // 先算候选（只与更早的数组配对）
                best = max(best, mx - prefMin);         // 当前出最大，前面出最小
                best = max(best, prefMax - mn);         // 当前出最小，前面出最大
            }
            prefMin = min(prefMin, mn);                 // 后更新前缀，保证 i != j
            prefMax = max(prefMax, mx);
        }
        return best;
    }
};
```

### Python

```python
class Solution:
    def maxDistance(self, arrays: List[List[int]]) -> int:
        best = 0
        pref_min = pref_max = None                      # None 表示前缀为空
        for a in arrays:
            mn, mx = a[0], a[-1]                        # 升序：首即最小、末即最大
            if pref_min is not None:                    # 只与更早的数组配对
                best = max(best, mx - pref_min, pref_max - mn)
            pref_min = mn if pref_min is None else min(pref_min, mn)
            pref_max = mx if pref_max is None else max(pref_max, mx)
        return best
```

## 8. 边界情况与易错点

1. **全局最值同属一个数组**（示例 3 `[[0,9],[3,4]]`）：直接写 `max(max(a) for a in arrays) - min(min(a) for a in arrays)` 会答 9，正确是 6。这是本题最高频的 WA。
2. **先更新前缀再算候选**：同样会把"当前数组出最小 + 当前数组出最大"算进候选，等价于上一条的错误，且更隐蔽（只在某些数据上翻车）。
3. **全部数组只含相同元素**（`[[1],[1]]`）：所有候选为 0，`best` 初值必须为 0 而不是 $-\infty$ 或某个"未初始化"值。
4. **单元素数组**：$mn = mx$，前缀更新与候选计算都正常，无需特判；`candA`、`candB` 可能相等，重复计算无害。
5. **负数**：值域含负数，距离是绝对值，差值本身可能为负；用 0 兜底、用有符号类型，别假设"最大值一定大于最小值"。
6. **数组未排序就套模板**：`a[0]` / `a[-1]` 只在升序前提下是极值。若题目去掉"升序"条件，必须改成对每个数组扫一遍求 `min/max`，总复杂度 $O(N)$ 仍成立。
7. **`m = 2` 的退化**：扫描到第二个数组时给出全部候选，答案只取决于两个数组的四个端点组合，代码无需特殊分支。
8. **值域与溢出**：本题 $|a-b| \le 2 \times 10^4$，`int` 安全；若把值放大到 $10^9$，`mx - prefMin` 仍在 `int` 内但已接近边界，稳妥起见用 `long long`。

**延伸思考**：

1. 若要求"取 $k$ 个**不同数组**的数，使最大值减最小值最大"：答案仍是某个 $mx_j - mn_i$（$i \ne j$），中间的 $k-2$ 个数可以在两个数组之外的任意数组里任取，只要 $m \ge k$；$k > m$ 时无解。整体仍是 $O(m)$。
2. 若改成"求**最小**的跨数组距离"：不能只看端点，需要把 $m$ 个区间按 $mn$ 排序后扫描相邻区间（类似区间交集检测），$O(m \log m)$；本题的端点支配引理在此**失效**。
3. 若数组个数 $m$ 很大而每个数组极长：复杂度仍是 $O(\min(N, m))$ 量级的读入，瓶颈不在算法而在 I/O——此时"只读首尾"的优势会非常明显。
