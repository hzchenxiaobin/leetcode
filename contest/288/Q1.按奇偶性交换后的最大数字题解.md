# LeetCode 按奇偶性交换后的最大数字 题解

## 1. 题目概述

- **标题 / 题号**：按奇偶性交换后的最大数字（#2231，easy）
- **链接**：https://leetcode.cn/problems/largest-number-after-digit-swaps-by-parity/
- **来源**：LeetCode 第 288 场周赛 Q1
- **难度**：简单
- **标签**：贪心、排序、数学

**题意**：给定正整数 $num$，可以交换 $num$ 中**奇偶性相同**的任意两位数字（都是奇数或都是偶数），交换次数不限。返回能得到的**最大**数值。

**约束**：

- $1 \le \text{num} \le 10^9$

> 💡 签到题，题眼在于读出两层结构：**不变量**——跨奇偶的数字永不可换，所以「哪些位放奇数、哪些位放偶数」的格局锁死；**自由度**——同奇偶数字之间可任意交换，等价于**组内可自由排列**。两者合起来，最优策略就是「奇组降序填奇位、偶组降序填偶位」，一趟贪心回填解决。

> 💡 本题在本仓库另有[每日题解 2231](../../solution/2201-2300/2231_按奇偶性交换后的最大数字.md)：主线同为分组排序贪心，附面试问答、桶计数三解与「对换生成全排列」的群论展开。本篇按**周赛复盘视角**展开，补齐引理-定理化的可达性与最优性证明及赛场易错清单，两篇互为印证。

## 2. 示例

**示例 1**

```text
输入：num = 1234
输出：3412
解释：
  交换数字 3 和数字 1，结果得到 3214。
  交换数字 2 和数字 4，结果得到 3412。
  注意，不能交换数字 4 和数字 1，因为它们奇偶性不同。
```

**示例 2**

```text
输入：num = 65875
输出：87655
解释：
  交换数字 8 和数字 6，结果得到 85675。
  交换数字 5 和数字 7，结果得到 87655。
```

**补充示例 3（0 是偶数）**

```text
输入：num = 105
输出：501
解释：奇数池 [1, 5] 降序为 [5, 1]，偶数池 [0] 不变。
  位 0(奇)→5，位 1(偶)→0，位 2(奇)→1，得 501。
  0 是偶数，永远不能与 1、5 互换。
```

## 3. 解题思路

### 3.1 暴力思路

最直观的做法是「改进交换」：每轮枚举所有同奇偶的数字对 $O(d^2)$，若交换后数值变大就执行，直到找不到能变大的交换为止（每次交换严格增大数值、可达状态有限，必然终止）。也可以 BFS 枚举全部可达状态（组内排列数至多 $9! = 362880$，$d \le 10$ 时同样瞬间完成）取最大。

由于 $d \le 10$，两者赛时都能过，但都有同一个问题：**没看透结构**——反复交换本质上只是在两个奇偶组内各自做全排列，既然等价于自由排列，一次排序就是天然终点，无需任何搜索。

> ⚠️ 本题作为 Q1 的真正考点是把操作语义翻译成排列语义：「同奇偶可任意交换」$\Rightarrow$「组内可自由排列」。完成这一步翻译，后面的排序贪心是显然的。

### 3.2 核心观察：组内自由排列 + 位奇偶格局锁死

![核心观察：同奇偶数字自由排列，位的奇偶格局锁死](images/wc288_q1_parity_pool_concept.svg)

**观察一（自由度）**：题目允许交换**任意**两位同奇偶数字，不限相邻、不限次数。对换能生成全排列（引理 2 给出构造证明），所以奇数字在奇数位集合上可以任意重排，偶数字同理。

**观察二（不变量）**：奇数字永远不能与偶数字互换，于是**每个位置的奇偶类别由 $num$ 唯一锁定**——能调整的只有「奇位上各个奇数字的顺序」和「偶位上各个偶数字的顺序」。

**观察三（贪心最优）**：两个组的资源与约束完全独立（奇位只消耗奇数字、偶位只消耗偶数字），要让整个数最大就是让高位尽量大——把两组数字各自**降序排序**，再按原位的奇偶性从高到低回填，即得全局最大（交换论证见第 5 节）。

### 3.3 算法流程

![算法流程：分组 → 各自降序 → 按原位奇偶回填](images/wc288_q1_algorithm_flow.svg)

1. **数位化**：`num` 转为十进制字符串 $s$（$d$ 位）。
2. **分组**：遍历 $s$，按数位值 $\bmod 2$ 的余数把奇数字收集进 `odd[]`、偶数字收集进 `even[]`。
3. **排序**：`odd[]`、`even[]` 各自降序排序。
4. **回填**：再遍历 $s$ 一遍，原位是奇数就取 `odd[oi++]`，是偶数就取 `even[ei++]`，同时 `ans = ans × 10 + d` 累积。
5. **返回** `ans`。

### 3.4 示例演算

![示例演算：分组降序 → 逐位回填](images/wc288_q1_example_walkthrough.svg)

| 输入 | 奇数池 → 降序 | 偶数池 → 降序 | 逐位回填 | 答案 |
|------|--------------|--------------|----------|------|
| `1234` | $[1,3] \to [3,1]$ | $[2,4] \to [4,2]$ | 位0奇→3，位1偶→4，位2奇→1，位3偶→2 | `3412` |
| `65875` | $[5,7,5] \to [7,5,5]$ | $[6,8] \to [8,6]$ | 位0偶→8，位1奇→7，位2偶→6，位3奇→5，位4奇→5 | `87655` |
| `105` | $[1,5] \to [5,1]$ | $[0] \to [0]$ | 位0奇→5，位1偶→0，位2奇→1 | `501` |

> 💡 **关键不变量**：回填时每位取自的池与该位原数字的奇偶一致，位奇偶格局全程不变，结果一定合法（可达，见引理 2）。

## 4. 算法细节

1. **数位化**：C++ 用 `to_string(num)`，Python 用 `str(num)`，全程按字符处理，避免逐位除法取模再反转的绕路。
2. **分组判据**：`(c - '0') % 2`（C++）/ `int(c) % 2`（Python）。C++ 直接写 `c % 2` 恰好也对（`'0'` 的 ASCII 码 48 是偶数），但那是字符编码的巧合，别依赖。
3. **降序排序**：`sort(v.rbegin(), v.rend())` / `sorted(..., reverse=True)`。
4. **双指针回填**：`oi`、`ei` 分别是 `odd[]`、`even[]` 的「下一个当前最大」下标，两组指针**独立推进**；按**原位的奇偶**决定从哪个池取数，`ans = ans * 10 + d` 累积即可，无需先拼字符串。
5. **$O(1)$ 空间桶计数版**：数字只有 0–9，用 `cnt[10]` 统计频次代替分组排序；回填时奇位从 $9$ 到 $1$、偶位从 $8$ 到 $0$ 步长 $-2$ 找首个 `cnt > 0` 的数字，取用后计数减一。每位至多探测 5 个桶，总体 $O(d)$ / $O(1)$。

## 5. 正确性证明

**约定**：把 $num$ 的十进制表示看作长度为 $d$ 的数字串，位置从左（高位）到右编号 $0 \dots d-1$；每个位置 $i$ 的**奇偶类别**即 $num_i$ 的奇偶。称 $x$ **可达**，若 $x$ 可由 $num$ 经有限次合法交换得到。

**引理 1（不变量）**：任何可达的数 $x$ 满足：(a) $x$ 与 $num$ 的数字多重集相同；(b) 对每个位置 $i$，$x_i \equiv num_i \pmod 2$。

**证明**：对交换次数归纳。零次交换即 $num$，(a)(b) 平凡成立。设 $x$ 满足 (a)(b)，一次合法交换交换位置 $i, j$ 上的数字，且 $x_i \equiv x_j \pmod 2$。(a)：交换不改变多重集。(b)：位置 $i$ 的新数字 $x_j$ 与 $x_i$ 同奇偶，由归纳假设 $x_i \equiv num_i$，故 $x_j \equiv num_i \pmod 2$；位置 $j$ 同理；其余位置不动。∎

**引理 2（可达性）**：反之，任何同时满足 (a)、(b) 的数 $x$ 都可达。

**证明**：由 (b)，$x$ 与 $num$ 的每个位置的奇偶类别逐一相同，于是 $x$ 在全部奇类别位置上的数字恰好是 $num$ 的奇数字的一种重排。对这些位置从左到右逐个归位：设位置 $i$ 的目标数字当前位于同类位置 $k \ne i$，交换 $i$ 与 $k$——两位置同类、两数字同奇偶，是合法操作；它把目标数字归位，且不影响已归位的更左位置。每个位置至多一次交换，至多 $m - 1$ 次（$m$ 为该类位置数）后所有奇类别位置与 $x$ 一致；偶类别位置同理。有限次合法交换后得到 $x$。∎

**推论**：可达集 $= \{ x : \text{(a)} \wedge \text{(b)} \}$。原问题等价于：在「每位奇偶类别与 $num$ 相同」的约束下，重排 $num$ 的数字使所得整数最大。

**定理（贪心最优）**：奇组降序填奇位、偶组降序填偶位所得的 $ans$ 是可达集中的最大值。

**证明**：设 $OPT$ 为可达集中的最大值，由引理 1 它满足 (a)(b)。先证 $OPT$ 组内必降序：反设存在同奇偶类别的位置 $i < j$ 使 $OPT_i < OPT_j$。由 (b)，$OPT_i$ 与 $OPT_j$ 同为奇数字或同为偶数字，故交换 $OPT$ 的位置 $i, j$ 是一次合法操作，交换后 (a)(b) 仍成立（论证同引理 1），所得 $OPT'$ 仍可达。$OPT'$ 与 $OPT$ 是同一多重集的排列、位数相同，前缀位置 $0 \dots i-1$ 相同而 $OPT'_i = OPT_j > OPT_i$，故 $OPT' > OPT$，与 $OPT$ 最大矛盾。因此 $OPT$ 在每个奇偶类别内部降序。

再证 $OPT$ 唯一确定：$OPT$ 的位奇偶类别分布与 $num$ 相同（(b)），每个类别上安放的多重集与 $num$ 对应类别的多重集相同（(a)），而一个多重集的降序排列唯一。所以 $OPT$ 恰为「分组降序回填」的结果，即算法输出 $ans$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(d \log d)$，其中 $d \le 10$ 为位数。分组遍历 $O(d)$，两组排序共 $O(d \log d)$，回填遍历 $O(d)$。桶计数版免排序，降为 $O(d)$（每位至多探测同奇偶的 5 个桶）。
- **空间复杂度**：$O(d)$，即 `odd[]` 与 `even[]` 两组暂存（最坏各 $d$ 个）。桶计数版为 $O(1)$（固定 10 个桶）。

> 💡 $d \le 10$ 时任何写法都瞬间通过，本题的价值在于「把交换语义翻译成排列语义」的结构洞察，而非性能。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int largestInteger(int num) {
        string s = to_string(num);
        string odd, even;
        for (char c : s) ((c - '0') % 2 ? odd : even).push_back(c);
        sort(odd.rbegin(), odd.rend());
        sort(even.rbegin(), even.rend());
        int oi = 0, ei = 0, ans = 0;
        for (char c : s) {
            int d = ((c - '0') % 2 ? odd[oi++] : even[ei++]) - '0';
            ans = ans * 10 + d;
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def largestInteger(self, num: int) -> int:
        s = str(num)
        odd = sorted((c for c in s if int(c) % 2), reverse=True)
        even = sorted((c for c in s if not int(c) % 2), reverse=True)
        oi = ei = 0
        out = []
        for c in s:
            if int(c) % 2:
                out.append(odd[oi]); oi += 1
            else:
                out.append(even[ei]); ei += 1
        return int("".join(out))
```

## 8. 边界情况与易错点

1. **0 是偶数**：分组判据必须落在数字值上（`(c-'0') % 2` / `int(c) % 2`），0 归偶组、永远留在偶位——补充示例 `105 → 501` 正是考察这一点。
2. **一位数**：无交换对象，原样返回；双指针回填天然覆盖（两组各至多一个元素）。
3. **全部数字同奇偶**（如 `13579`、`24680`）：退化为整体降序排序，算法无需特判。
4. **答案可能等于输入**（如 `4321`，两组本已降序）：不要因为「没变化」怀疑写错——重排的执行与否不影响结果。
5. **溢出审计**：$num \le 10^9$。回排不改变位数与位奇偶格局：9 位输入结果至多 $999999999$；10 位输入只可能是 $10^9 = 1000000000$，其奇组 $\{1\}$、偶组为 9 个 0，回填唯一。故 $ans \le 10^9 < 2^{31} - 1$，`int` 安全；且 $ans$ 首位取自 $num$ 首位所在组的最大值 $\ge num$ 首位 $\ge 1$，不可能出现前导零。
6. **交换次数不限**：别误套 [670. 最大交换](https://leetcode.cn/problems/maximum-swap/) 的「只交换一次」模板——那里排序不可行，本题恰恰相反，排序就是正解。
7. **两组指针独立**：`oi`、`ei` 各自推进、判据是**原位的奇偶**；共用一个指针或按「当前数字奇偶之外的判据」取数都会破坏位格局（等价于把偶数字塞进奇位，结果不可达）。

**延伸思考**：

- **推广到 $k$ 个交换类**：若规则改为「模 $k$ 余数相同的两位可交换」，可达集仍是「每位余数类别锁死、各类内自由排列」，分组降序回填的模板原封不动。
- **求最小值**：各类内改升序回填即可；若 $num$ 首位是偶数且偶组含 0（如 $num = 20$，两位全偶），首位可能被填成 0（可达排列 `02`），作为整数输出时位数会缩短——这是合法的数值结果，直接拼整数返回即可。
