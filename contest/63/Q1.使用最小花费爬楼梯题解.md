# LeetCode 使用最小花费爬楼梯 题解

## 1. 题目概述

- **标题 / 题号**：使用最小花费爬楼梯（#746，easy）
- **链接**：https://leetcode.cn/problems/min-cost-climbing-stairs/
- **来源**：LeetCode 第 63 场周赛 Q1
- **难度**：简单
- **标签**：数组、动态规划

**题意**：`cost[i]` 是「从第 $i$ 级台阶向上爬」要支付的费用；付过之后可以跨 **1 级或 2 级**。你可以从下标 $0$ 或 $1$ 的台阶开始，求到达**楼梯顶部**（位置 $n$，即最后一级台阶之后的位置，$n = \text{cost.length}$）的最低总花费。

关键在于**费用挂在「离开台阶」这个动作上**：站在第 $i$ 级台阶上、还没迈步时并不付费；一旦付了 `cost[i]`，就获得「从 $i$ 向上走 1 或 2 级」的权利。因此最后一步的落点是 $n$，最后一笔付费必然是 `cost[n-1]` 或 `cost[n-2]`。

**约束**：

- $2 \le \text{cost.length} \le 1000$
- $0 \le \text{cost}[i] \le 999$

规模很小，$O(n)$ 的线性 DP 绰绰有余；真正的难点不在复杂度，而在**状态语义的定义**——把「离开时付费」写对，答案就自然落到 $f[n]$ 上。

## 2. 示例

**示例 1**

```text
输入：cost = [10,15,20]
输出：15
解释：从下标 1 出发。
      - 支付 15，向上跨 2 级，直接到达顶部（位置 3）。
      总花费 15。
      对比：从 0 出发要付 10 + 20 = 30，更贵。
```

**示例 2**

```text
输入：cost = [1,100,1,1,1,100,1,1,100,1]
输出：6
解释：从下标 0 出发。
      - 支付 1，跨 2 级到下标 2；支付 1，跨 2 级到下标 4；
      - 支付 1，跨 2 级到下标 6；支付 1，跨 1 级到下标 7；
      - 支付 1，跨 2 级到下标 9；支付 1，跨 1 级到顶部。
      总花费 1+1+1+1+1+1 = 6。三个 100 全程被绕开。
```

## 3. 解题思路

### 3.1 暴力思路

一条走法就是一串「1 或 2」的步长序列，从 $0$ 或 $1$ 出发、累加恰好到 $n$。枚举所有序列：设长度为 $n$ 的走法数为 $W(n)$，则 $W(n) = W(n-1) + W(n-2)$，是斐波那契级别的量，$n = 1000$ 时约为 $10^{208}$，完全不可枚举。

暴力的浪费点很明确：不同的步长序列会**反复经过同样的位置**，从同一个位置 $i$ 之后的「最优后续花费」被重复计算了几十上百次。这正是 DP 要消掉的重叠子问题。

### 3.2 核心观察：把状态定义在「离开之前」

![状态定义：花费在离开台阶时支付](images/wc63_q1_state_concept.svg)

定义 $f[i]$ = **站在位置 $i$、尚未支付 `cost[i]`** 时的最小累计花费。位置 $n$ 表示楼梯顶部（已经在最后一级台阶之外，无需再付任何钱）。于是：

- $f[0] = f[1] = 0$：可以直接站在下标 0 或 1 上，站上去不要钱；
- 想停到位置 $i$，最后一步只能从 $i-1$ 跨 1 级、或从 $i-2$ 跨 2 级；
- 迈出这一步时，付的是**离开的那一级**的价钱，即 `cost[i-1]` 或 `cost[i-2]`。

> 💡 **一句话记住语义**：$f$ 的下标是「人现在站的位置」，转移时加的钱是「离开的那级台阶」的价钱——所以转移式里出现的永远是 `cost[i-1]`、`cost[i-2]`，不会出现与 $f[i]$ 同下标的项。

这样定义的好处是**答案只有一个**：$f[n]$，不需要在最后再做一次 `min` 或者判断从哪级起跳。

### 3.3 状态转移

![状态转移：两条入边取较小者](images/wc63_q1_transition_flow.svg)

对 $i \ge 2$：

$$f[i] = \min\bigl(f[i-1] + \text{cost}[i-1],\ f[i-2] + \text{cost}[i-2]\bigr)$$

初始 $f[0] = f[1] = 0$，答案 $f[n]$。

**等价的逆向写法**（与官方提示一致）：令 $g[i]$ 为「从第 $i$ 级出发爬到顶部」的最小花费，则 $g[n] = 0$，$g[i] = \text{cost}[i] + \min(g[i+1], g[i+2])$，答案为 $\min(g[0], g[1])$。它与正向写法是同一张 DAG 上倒推与正推的关系：**正向把「两个起点」吸收进初值，答案收敛成一个下标；逆向把「终点」吸收进初值，答案摊成两个下标**。两种都能 AC，但写题时只选一种、不要混着用。

### 3.4 示例演算

![演算：cost = [1,100,1,1,1,100,1,1,100,1] 的 f 表](images/wc63_q1_walkthrough.svg)

先看示例 1（$n = 3$）：

| $i$ | 0 | 1 | 2 | 3（顶部） |
|-----|---|---|---|---|
| `cost[i]` | 10 | 15 | 20 | — |
| $f[i]$ | 0 | 0 | $\min(0+15,\ 0+10) = 10$ | $\min(10+20,\ 0+15) = 15$ |

$f[3] = 15$：最后一步是从下标 1 跨 2 级上来，付 `cost[1] = 15`，正与官方答案一致。

再看示例 2 的关键几步：$f[6] = \min(f[5]+\text{cost}[5],\ f[4]+\text{cost}[4]) = \min(3+100,\ 2+1) = 3$ 绕开了 `cost[5] = 100`；$f[9] = \min(f[8]+\text{cost}[8],\ f[7]+\text{cost}[7]) = \min(4+100,\ 4+1) = 5$ 绕开了 `cost[8] = 100`；最后 $f[10] = \min(f[9]+\text{cost}[9],\ f[8]+\text{cost}[8]) = \min(5+1,\ 4+100) = 6$，又绕开了 `cost[9] = 100`。三个 100 一个都没踩。

## 4. 算法细节

1. **费用归属不要写反**：转移里加的是 `cost[i-1]` 与 `cost[i-2]`（离开台阶的价钱）。写成 `cost[i]` 就把语义改成了「踏上时付费」，边界会全错。
2. **起点初始化**：`f[0] = f[1] = 0`，不是 `f[0] = cost[0]`。题目说「可以选择从下标 0 或 1 开始」，站上去那一下不付费。
3. **循环上界是 $n$**：`for i in range(2, n+1)`，当 $i = n$ 时正好取到 `cost[n-1]`，这一步就是「离开最后一级台阶」。循环只写到 $n-1$ 会漏掉最后一步。
4. **滚动数组**：$f[i]$ 只依赖前两项，用 `f0, f1` 两个变量交替即可，空间 $O(1)$。更新顺序必须是「先算新的 $f_2$，再把 `f0, f1 = f1, f2`」，否则会覆盖掉 $f[i-2]$。
5. **整数范围**：最大花费约 $999 \times 1000 \approx 10^6$，`int` 足够；C++ 里用 `long long` 累加再转回 `int` 是零成本的保险，防止未来把值域放宽。
6. **可选：还原路径**：若需要输出走了哪几级，在 DP 时保存每个 $i$ 的决策（取的是 $i-1$ 还是 $i-2$），再从 $n$ 反向回溯；相等时取哪个都不影响最优值。
7. **别写无记忆化的递归**：朴素递归 `dfs(i) = cost[i] + min(dfs(i+1), dfs(i+2))` 会把同一条后缀重复展开指数次，等价于 3.1 的暴力；要写递归就必须加记忆化（本题 `n ≤ 1000`，记忆化递归的栈深也安全）。

## 5. 正确性证明

**引理 1（状态语义）**：对任意 $0 \le i \le n$，$f[i]$ 等于「从下标 0 或 1 出发、恰好停在位置 $i$、且尚未支付 `cost[i]`」的所有走法中的最小花费。

**证明**：对 $i$ 归纳。

- $i = 0, 1$：起点本身免费，唯一走法是「什么都不做」，花费 0，与 $f[0] = f[1] = 0$ 相符。
- $i \ge 2$：任取一条停在 $i$ 的走法。由于每次只能跨 1 或 2 级，它的**最后一步**必然从 $i-1$ 或 $i-2$ 迈出；迈出时支付该台阶的 `cost`，故整条走法的花费等于「停在 $i-1$ 的花费 $+\ \text{cost}[i-1]$」或「停在 $i-2$ 的花费 $+\ \text{cost}[i-2]$」。由归纳假设，这两类走法各自的最小值就是 $f[i-1] + \text{cost}[i-1]$ 与 $f[i-2] + \text{cost}[i-2]$；对所有走法取最小即为二者较小者，与递推式一致。∎

**引理 2（最优子结构）**：若某条最优走法经过位置 $i$ 后继续前进，则它在 $i$ 之前的那一段，也是「停在 $i$」的最优走法。

**证明**：若不然，存在另一条停在 $i$ 且更便宜的走法，用它替换前缀，整条走法会更便宜，与「最优」矛盾。∎

**定理**：算法返回的 $f[n]$ 等于到达楼梯顶部的最小总花费。

**证明**：楼梯顶部就是位置 $n$（最后一级台阶之后），到达顶部即「停在 $n$」且此后无需再付任何费用。由引理 1，$f[n]$ 正是停在 $n$ 的最小花费；算法按 $i = 2, 3, \dots, n$ 的顺序依递推式计算，每项都只用到已算好的前两项，故返回的 $f[n]$ 与定义值相等。∎

## 6. 复杂度分析

- **时间**：$O(n)$。一次线性扫描，每轮两次加法、一次比较；$n \le 1000$，常数极小。
- **空间**：$O(1)$。只保留 $f[i-2]$ 与 $f[i-1]$ 两个滚动变量；若保留整个 $f$ 数组则为 $O(n)$（还原路径时需要）。
- **递归写法**：若用记忆化递归，栈深度 $O(n)$，本题 $n \le 1000$ 安全，但没必要。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int minCostClimbingStairs(vector<int>& cost) {
        int n = (int)cost.size();
        // f[i]：站在位置 i（尚未支付 cost[i]）的最小累计花费；位置 n 即楼梯顶部
        long long f0 = 0, f1 = 0;   // f[0] = f[1] = 0，可从 0 或 1 免费起步
        for (int i = 2; i <= n; i++) {
            long long f2 = min(f1 + cost[i - 1], f0 + cost[i - 2]);
            f0 = f1;
            f1 = f2;
        }
        return (int)f1;
    }
};
```

### Python

```python
from typing import List


class Solution:
    def minCostClimbingStairs(self, cost: List[int]) -> int:
        n = len(cost)
        # f[i]：站在位置 i（尚未支付 cost[i]）的最小累计花费；位置 n 即楼梯顶部
        f0, f1 = 0, 0          # f[0] = f[1] = 0，可以从 0 或 1 免费起步
        for i in range(2, n + 1):
            f2 = min(f1 + cost[i - 1], f0 + cost[i - 2])
            f0, f1 = f1, f2
        return f1
```

## 8. 边界情况与易错点

1. **终点是 $n$ 而不是 $n-1$**：答案写 `f[n-1]` 就漏付了 `cost[n-1]`。示例 1 会得到 10 而不是 15，是最典型的 WA。
2. **「到达时付费」的误写**：`f[i] = cost[i] + min(f[i-1], f[i-2])` 看起来对称漂亮，但它把付费挂在了踏上台阶的瞬间，最后一步直接漏算，起点还会被多收一次 `cost[0]`；示例 1 会得到 30 而不是 15。要小心的是**示例 2 在这种错法下碰巧也等于 6**，不能拿它当回归用例。
3. **两个起点不要混用两种框架**：正向写法答案是 $f[n]$；逆向写法答案是 $\min(g[0], g[1])$。把逆向的答案套到正向数组上（或反之）会少算一步。
4. **`cost[i]` 可以为 0**：会出现大量平局与「免费台阶」，取哪条转移都不改变最优值；不要拿 0 当「未计算」的哨兵。
5. **$n = 2$ 的退化情形**：循环只跑 $i = 2$ 一轮，$f[2] = \min(\text{cost}[1], \text{cost}[0])$，即一步跨到顶。`[0, 999]` 返回 0，`[999, 0]` 返回 0。
6. **跨 2 级的能力必须真的用上**：示例 1 的答案 15 就是「从下标 1 跨两级直接到顶」，若实现只允许跨 1 级会得到 35；对拍时要专门覆盖「最优解全程靠跨 2 级」的数据。
7. **`cost` 为空或长度 1**：题目约束 $n \ge 2$，无需特判；若强行扩展到 $n = 1$，初始化 $f[1]$ 会越界，需额外处理。
