# LeetCode 隔离病毒 题解

## 1. 题目概述

- **标题 / 题号**：隔离病毒（#749，hard）
- **链接**：https://leetcode.cn/problems/contain-virus/
- **来源**：LeetCode 第 63 场周赛 Q4
- **难度**：困难
- **标签**：深度优先搜索、广度优先搜索、数组、矩阵、模拟

**题意**：给定 $m \times n$ 的 $0/1$ 棋盘 `isInfected`（$1$ 为已感染）。每天按固定规则推进一次：

1. 把值为 $1$ 的格子按**四方向连通**分成若干**感染区域**；
2. 选出**对未感染格威胁最大**的区域（威胁 = 下一夜会新被感染的格子数，题目保证最大者唯一），沿它全部边界装防火墙，把这批墙数累加进答案，该区域从此**永久失效**；
3. 其余区域向相邻的 $0$ 格**各扩散一格**（同一格只被感染一次）。

循环直到「没有感染格」或「没有任何区域还能威胁到 $0$ 格」。若最终仍有 $0$ 格幸免，返回总墙数；若世界被全部感染（已无 $0$ 格），同样返回已用墙数。两种结局可以统一成一条终止条件：**最大威胁格数 = 0 时停止**。

**约束**：

- $m = \text{isInfected.length}$，$n = \text{isInfected}[i].\text{length}$，$1 \le m, n \le 50$
- `isInfected[i][j]` 只能是 $0$ 或 $1$
- 过程中「威胁最大的区域」严格唯一，不存在并列

规模只有 $2500$ 个格子，瓶颈不在单轮开销而在**轮数**：每轮 $O(mn)$、轮数 $O(mn)$ 也只有约 $6 \times 10^6$ 次操作。

## 3. 解题思路

### 3.1 暴力思路

最朴素的想法是把棋盘上所有 $1$ 当成**一个整体**：统计整块病毒与 $0$ 的边界边数并一次性封死。这对示例 1 会给出 $9$ 之类的错答案，因为题目要求**每天只能封一个区域**，先封谁、后封谁直接决定总墙数。

第二种朴素想法是「每天对每个区域都重扫一遍棋盘求边界」：单轮要对 $R$ 个区域各扫 $O(mn)$，总 $O((mn)^3)$，在 $50 \times 50$ 上约 $1.5 \times 10^{10}$，太慢。而**枚举隔离顺序**更是没必要——题目已经把顺序规定死（威胁最大者优先且无并列），枚举 $2^{R}$ 种顺序毫无意义。

所以关键在于：**一次 DFS 同时算出三样东西**——连通块本身、它的威胁格集合、它的边界边数。这样单轮 $O(mn)$，剩下的就是按规则老实模拟。

### 3.2 核心观察：威胁格数 ≠ 墙数

![区域的威胁格数与墙数](images/wc63_q4_region_threat_model.svg)

一个区域要同时维护两个量，它们**不能混用**：

- **威胁格数** $= \lvert \text{frontier} \rvert$，frontier 是该区域四方向相邻的 $0$ 格**去重**后的集合。它回答「下一夜会有几个新格子被感染」，用来**挑区域**。
- **墙数** $=$ 该区域与 $0$ 格之间的**相邻边条数**。它回答「把这区域彻底封死要几面墙」，用来**累加答案**。

两者为什么不同？因为一个空格可能同时贴着同一区域的多个感染格。示例 2 的洞只有 $1$ 个威胁格，却有 $4$ 条边、需要 $4$ 面墙；示例 1 第 2 天的空格 $(3,6)$ 同时挨着 $(2,6)$ 与 $(3,7)$，多出来的那条边就是墙数从 $4$ 变成 $5$ 的原因。

> 💡 还有一个更隐蔽的点：**不同区域可能共享同一个威胁格**。示例 3 的 $(1,3)$ 左挨 $(1,2)$、右挨 $(1,4)$，同时属于左右两个区域的 frontier。所以右侧长条的威胁数是 $11$ 而不是 $10$——去重只能在**区域内部**做，不能跨区域去重。

### 3.3 算法流程

![模拟算法流程](images/wc63_q4_algorithm_flow.svg)

循环执行，直到最大威胁格数为 $0$：

1. **标连通块**：扫描全盘，遇到值为 $1$ 且未访问的格子就做一次 DFS/BFS，得到一个区域。
2. **边遍历边统计**：对区域内每个格子看四邻居——邻居是 $1$ 就继续入栈；邻居是 $0$ 就 `walls += 1`（每条边一面墙），并把它登记进 frontier 集合（`set` 或「认领标记」去重）。
3. **选块**：取 frontier 最大的区域；若它的 frontier 为空，说明所有区域都无威胁，跳出循环。
4. **封死**：`ans += walls`，把该区域所有格子标记为 $2$（已隔离：既不扩散、也不当安全格）。
5. **其余扩散**：对其它区域，把它们 frontier 里的 $0$ 格置为 $1$。必须**先统计完全部区域、再统一写入**，否则本轮新感染的格子会被后面的区域误当成本轮 frontier。
6. 回到第 1 步。

用 $2$ 而不是 $0$ 表示「已隔离」是整套实现的地基：隔离区的格子仍然是病毒（不能被别人感染，也不产生墙壁计数），但它永远不会再扩散，也不会再出现在连通块里。

### 3.4 示例演算

![示例 1 逐天走查](images/wc63_q4_walkthrough.svg)

对示例 1 跑一遍：

| 轮次 | 各区域（威胁格数，墙数） | 选中 | 累计 ans |
|------|--------------------------|------|----------|
| 第 1 天 | 左区 $(5, 5)$、右区 $(4, 4)$ | 左区 | 5 |
| 第 2 天 | 右块 $(4, 5)$（已扩散成 7 格） | 右块 | 10 |
| 第 3 天 | 没有值为 1 的格子 → 最大威胁 $0$ | 结束 | 10 |

注意第 2 天右块的变化：第 1 天它只有 $3$ 格、墙数 $4$；扩散后变成 $7$ 格，威胁格仍是 $4$ 个，墙数却涨到 $5$，因为空格 $(3,6)$ 同时贴着 $(2,6)$ 与 $(3,7)$。这说明**墙数必须按边实时重算，不能缓存上一轮的结果**。

## 4. 算法细节

1. **每轮都重算，不要复用上一轮的区域划分**：区域会因扩散而合并（示例 1 第 2 天的 7 格块就是原 3 格加上 4 个新格子），任何跨轮缓存都会失效。
2. **frontier 去重要落到实现上**：C++ 开一个 `owner` 数组，`owner[nx][ny] != id` 时才 `threat[id]++` 并写回 `id`；Python 直接 `set.add`。因为区域是**逐个完整处理**的，单张 `owner` 表不会把 A 区已认领的格子重复算给 B 区——B 区确实也该认领它。
3. **墙按边累加**：遍历每个感染格的四邻居时，对每个 $0$ 邻居各加一次，天然就是边的条数。
4. **隔离用值 $2$**：既不是 $1$（不扩散、不成块），也不是 $0$（不被感染、不产生墙）。若置成 $0$，示例 3 中隔离的 $(1,4)$ 会被左区重新感染。
5. **扩散时再查一次 `g == 0`**：两个区域的 frontier 可能重叠，先处理者置 $1$ 后，后处理者不能覆盖它，也不该重复计数。
6. **终止条件只要一条**：`最大威胁 == 0` 同时覆盖「全盘感染、没有 $0$ 格」和「剩余 $0$ 格都被隔离区挡开」两种结局。
7. **不必上并查集**：能增量维护，但扩散不断合并区域、删除操作难写；$mn \le 2500$ 时每轮重扫完全够用。

## 5. 正确性证明

**引理 1（墙数 = 边界边数）**：隔离一个区域所需的最少防火墙数，等于该区域格子与值为 $0$ 的格子之间的相邻边条数。

**证明**：防火墙只能装在两个相邻格的共享边界上。若某条「感染格—空格」的边没有墙，病毒当晚就从这条边溢出，区域并未被隔离，故每条这样的边都必须有墙，下界为边数。另一方面，把这 $k$ 条边全部封上后，该区域与任何 $0$ 格都不再有相邻通道，病毒无法外溢，$k$ 面墙即可达成隔离，上界也是边数。∎

**引理 2（选块规则一致）**：算法每天选中的区域，恰是题目定义的「下一夜会感染最多未感染格」的那个区域。

**证明**：下一夜被新感染的格子，恰好是与该区域相距 $1$ 步的 $0$ 格；同一个 $0$ 格被多个感染格同时覆盖也只算一格。故威胁数 $= \lvert \text{frontier} \rvert$（区域内去重）。算法以 `argmax` 取之，且题设保证最大值严格唯一，故选中者与题目规定完全一致。∎

**引理 3（终止性）**：每轮或立即终止，或至少把一个非空区域永久标记为 $2$；因此轮数不超过 $mn$，算法必然终止。

**证明**：若最大威胁 $> 0$，被隔离的区域非空，其格子由 $1$ 变 $2$ 后不再参与任何连通块与统计；格子总数 $mn$ 有限，故最多 $mn$ 轮。若最大威胁 $= 0$，则不存在「感染格与 $0$ 格相邻」的情形：要么全盘已感染（无 $0$ 格），要么剩余 $0$ 格已被隔离区完全挡开（已尽力保存），再操作只会增加墙数而不再改变结局。∎

**定理**：算法返回的值等于题目所定义过程中安装的防火墙总数。

**证明**：对轮次归纳。由引理 2，每轮选中的区域与题目规则一致；由引理 1，每轮累加的墙数就是该轮应装的墙数；扩散步骤按 frontier 置 $1$，与「每个感染格向四邻扩散一格」等价（重复感染同一格不改变结果）。由引理 3，循环在题目规定的两种结局处停止，此时 `ans` 已累计全部墙数，正是题目要求的返回值。∎

## 6. 复杂度分析

- **时间**：$O((mn)^2)$。每轮标连通块、统计 frontier 与墙数、扩散各扫一遍网格，均为 $O(mn)$；由引理 3 轮数 $\le mn$。$m = n = 50$ 时约 $6.25 \times 10^6$ 次操作，实际轮数远小于 $mn$。
- **空间**：$O(mn)$。网格副本、`seen` 标记、DFS 栈、`owner` 数组与 frontier 集合都是 $O(mn)$ 级别。

## 7. 参考代码

### C++

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    int containVirus(vector<vector<int>>& isInfected) {
        int m = isInfected.size(), n = isInfected[0].size(), ans = 0;
        vector<vector<int>> g = isInfected;
        const int dx[4] = {1, -1, 0, 0}, dy[4] = {0, 0, 1, -1};
        while (true) {
            vector<vector<char>> seen(m, vector<char>(n, 0));
            vector<vector<pair<int,int>>> cells;   // 每个区域的格子
            vector<int> threat, walls;             // 威胁格数（去重）、墙数（边数）
            vector<vector<int>> owner(m, vector<int>(n, -1));  // 威胁格归属，用于去重
            for (int i = 0; i < m; i++) for (int j = 0; j < n; j++) {
                if (g[i][j] != 1 || seen[i][j]) continue;
                int id = cells.size();
                cells.push_back({}); threat.push_back(0); walls.push_back(0);
                vector<pair<int,int>> st{{i, j}};
                seen[i][j] = 1;
                while (!st.empty()) {
                    auto [x, y] = st.back(); st.pop_back();
                    cells[id].push_back({x, y});
                    for (int d = 0; d < 4; d++) {
                        int nx = x + dx[d], ny = y + dy[d];
                        if (nx < 0 || nx >= m || ny < 0 || ny >= n) continue;
                        if (g[nx][ny] == 1) {
                            if (!seen[nx][ny]) { seen[nx][ny] = 1; st.push_back({nx, ny}); }
                        } else if (g[nx][ny] == 0) {
                            walls[id]++;                        // 每条边一面墙
                            if (owner[nx][ny] != id) { owner[nx][ny] = id; threat[id]++; }
                        }
                    }
                }
            }
            int k = cells.size(), best = 0;
            if (k == 0) break;
            for (int i = 1; i < k; i++) if (threat[i] > threat[best]) best = i;
            if (threat[best] == 0) break;               // 无威胁：全感染或已全部挡住
            ans += walls[best];
            for (auto& c : cells[best]) g[c.first][c.second] = 2;    // 永久隔离
            for (int id = 0; id < k; id++) if (id != best)
                for (auto& c : cells[id]) for (int d = 0; d < 4; d++) {
                    int nx = c.first + dx[d], ny = c.second + dy[d];
                    if (nx >= 0 && nx < m && ny >= 0 && ny < n && g[nx][ny] == 0) g[nx][ny] = 1;
                }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def containVirus(self, isInfected: list[list[int]]) -> int:
        g = [row[:] for row in isInfected]
        m, n = len(g), len(g[0])
        dirs = ((1, 0), (-1, 0), (0, 1), (0, -1))
        ans = 0
        while True:
            seen = [[False] * n for _ in range(m)]
            comps = []                          # (cells, frontier, walls)
            for i in range(m):
                for j in range(n):
                    if g[i][j] != 1 or seen[i][j]: continue
                    seen[i][j] = True
                    st, cells, frontier, walls = [(i, j)], [], set(), 0
                    while st:
                        x, y = st.pop()
                        cells.append((x, y))
                        for dx, dy in dirs:
                            nx, ny = x + dx, y + dy
                            if 0 <= nx < m and 0 <= ny < n:
                                if g[nx][ny] == 1:
                                    if not seen[nx][ny]:
                                        seen[nx][ny] = True
                                        st.append((nx, ny))
                                elif g[nx][ny] == 0:
                                    walls += 1              # 每条边一面墙
                                    frontier.add((nx, ny))  # 威胁格去重
                    comps.append((cells, frontier, walls))
            if not comps: break
            best = max(comps, key=lambda c: len(c[1]))
            if not best[1]: break                   # 最大威胁为 0，收工
            ans += best[2]
            for x, y in best[0]:
                g[x][y] = 2                         # 永久隔离，不再扩散
            for cells, frontier, _ in comps:
                if cells is best[0]: continue
                for x, y in frontier:
                    if g[x][y] == 0: g[x][y] = 1    # 其余区域扩散一格
        return ans
```

## 8. 边界情况与易错点

1. **全盘都是 $1$**：没有 $0$ 格，第一轮威胁为 $0$，直接返回 $0$——世界已全部感染，题目要求返回已用墙数（$0$）。
2. **隔离格不能置 $0$**：必须换成与「安全」区分的值（如 $2$）。示例 3 中隔离的 $(1,4)$ 仍与左区相邻，置 $0$ 会被重新感染，答案偏小。
3. **frontier 只在区域内部去重**：漏去重会让「贴着两个感染格的空格」被算成两个威胁格，选块选错；反过来跨区域去重又会把示例 3 的 $(1,3)$ 只算给一个区域，同样选错。
4. **墙数按边、不按格**：一个空格可能贡献多条边，示例 2 的洞就是 $1$ 格 $4$ 墙；按格累加会输出 $1$ 而不是 $4$。
5. **扩散要「同时」发生**：先统计完所有区域的 frontier，再统一写入；边统计边写会把刚感染的格子当成下一轮 frontier。
6. **区域每轮都要重算**：扩散会让区域合并、墙数变化。
7. **四方向越界检查**：`nx` 与 `ny` 两个都要判，漏判 `ny` 在 $m \ne n$ 时越界。
