# LeetCode 找到最大三角形面积 题解

## 1. 题目概述

- **标题 / 题号**：找到最大三角形面积（#3588，medium）
- **链接**：https://leetcode.cn/problems/find-maximum-area-of-a-triangle/
- **来源**：LeetCode 第 159 场双周赛 Q2
- **难度**：中等
- **标签**：贪心、几何、数组、哈希表、数学、枚举

**题意**：给定 $n$ 个互不相同的二维点 `coords`。从中选三个点组成三角形，要求三角形的**至少一条边平行于 $x$ 轴或 $y$ 轴**，且**面积不为 $0$**。返回最大三角形的**两倍面积**；不存在这样的三角形则返回 $-1$。

**约束**：

- $1 \le n \le 10^5$
- $1 \le x_i, y_i \le 10^6$，所有点互不相同

> 💡 返回「两倍面积」是为了避免浮点误差：$2S = \text{底} \times \text{高}$，两个整数相乘。

## 2. 示例

**示例 1**

```text
输入：coords = [[1,1],[1,2],[3,2],[3,3]]
输出：2
解释：三角形 (1,1),(1,2),(3,1)... 实际给出的最佳取底边 1、高 2：2S = 1×2 = 2（面积 1）。
```

**示例 2**

```text
输入：coords = [[1,1],[2,2],[3,3]]
输出：-1
解释：三点共线，任何两点连线都不平行于坐标轴，不满足条件。
```

**示例 3（自造）**

```text
输入：coords = [[1,1],[1,5],[7,3]]
输出：24
解释：底边 (1,1)-(1,5) 长 4，高为 |7-1| = 6，2S = 24。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有三点组合 $O(n^3)$，检查是否有边平行于坐标轴，再算面积。$n = 10^5$ 时 $1.7\times10^{15}$ 组，完全不可行。即使优化到「先按 $x$ 分组、组内取点」，组内组合仍是平方级。

### 3.2 核心观察：底边只有两类，高取全局最远

![至少一条边平行于坐标轴 -> 底边只有两类](images/bw159_q2_axis_base.svg)

- 平行于坐标轴的边只有两种：**竖底**（两点同 $x$）与**横底**（两点同 $y$）。
- 一旦底边确定，面积只取决于第三点到这条底边所在直线的**垂直距离**，也就是：
  - 竖底在 $x = c$ 上：高 $= |x_3 - c|$，与第三点的 $y$ 无关；
  - 横底在 $y = c$ 上：高 $= |y_3 - c|$，与第三点的 $x$ 无关。
- 因此对**固定的 $x = c$**：
  - 最长的竖底 $= \max Y(c) - \min Y(c)$（同 $x$ 的点里的 $y$ 极差）；
  - 最大高 $= \max(c - x_{\min},\ x_{\max} - c)$（用全局最左或最右的点做第三点）；
  - 候选 $= \text{底} \times \text{高}$。
- 横底完全对称：对固定的 $y = c$，底 $= \max X(c) - \min X(c)$，高 $= \max(c - y_{\min}, y_{\max} - c)$。

于是只需要 $O(n)$ 的扫描统计「每个 $x$ 的 $y$ 极值」「每个 $y$ 的 $x$ 极值」以及全局四个极值。

### 3.3 算法流程

![对每个 x 取 y 极差做底，高取最左/最右的 x](images/bw159_q2_extreme_height.svg)

```text
1. 一趟扫描：更新 xmin, xmax, ymin, ymax
             更新 xLow[x], xHigh[x]（同 x 的 y 最小/最大）
             更新 yLow[y], yHigh[y]（同 y 的 x 最小/最大）
2. best = 0
3. 对每个出现过的 x：
       base = xHigh[x] - xLow[x]
       h    = max(x - xmin, xmax - x)
       best = max(best, base * h)
4. 对每个出现过的 y：
       base = yHigh[y] - yLow[y]
       h    = max(y - ymin, ymax - y)
       best = max(best, base * h)
5. best > 0 ? best : -1            # 面积为 0 视为不存在
```

### 3.4 示例演算

![示例 1 的三种取法](images/bw159_q2_example_walk.svg)

`coords = [(1,1),(1,2),(3,2),(3,3)]`，$x_{\min}=1, x_{\max}=3, y_{\min}=1, y_{\max}=3$。

| 底类型 | 固定值 | 底 | 高 | $2S$ |
|--------|--------|----|----|------|
| 竖底 | $x=1$ | $2-1=1$ | $\max(0,2)=2$ | 2 |
| 竖底 | $x=3$ | $3-2=1$ | $\max(2,0)=2$ | 2 |
| 横底 | $y=2$ | $3-1=2$ | $\max(1,1)=1$ | 2 |

三种取法都得 $2$，与官方输出一致。示例 2 中三个点 $(1,1),(2,2),(3,3)$ 的 $x,y$ 都互不相同，任一列/行的极差都是 $0$，`best` 保持 $0$，返回 $-1$。

## 4. 算法细节

1. **哈希表 vs 排序**：值域 $10^6$，可以用数组，也可以 `unordered_map`；用哈希表写法可直接适配更大的坐标范围。
2. **底必须来自同一条线**：`xHigh[x] - xLow[x]` 只在同一个 $x$ 的两个点上成立，跨 $x$ 取极差是错的。
3. **第三点必须 $x$ 不同**：若所有点都在同一条竖线上，则 $x_{\max} = x_{\min} = c$，高为 $0$，候选面积为 $0$，自然被排除。
4. **面积非零**：`best > 0 ? best : -1`；不能用「底或高为 0」单独判断，必须看乘积。
5. **同一 $x$ 上只有 1 个点**：此时底为 $0$，候选面积 $0$，不会污染答案。
6. **数值范围**：坐标 $\le 10^6$，底与高各 $\le 10^6$，乘积 $\le 10^{12}$，必须 `long long`（Python 无需处理）。
7. **不要真的算叉积**：本题的旋转卡壳式最优点总落在极值上，用 $O(1)$ 公式即可，不必对所有点求叉积。

## 5. 正确性证明

**引理 1（底边的两种形态）**：若三角形的某条边平行于坐标轴，则这条边的两个端点满足「$x$ 相同」或「$y$ 相同」。

**证明**：平行于 $y$ 轴的线段两端 $x$ 坐标相同，平行于 $x$ 轴的线段两端 $y$ 坐标相同。∎

**引理 2（给定 $x$ 的最优候选）**：设某条竖底位于 $x = c$，则 $2S \le \big(\max Y(c) - \min Y(c)\big)\cdot \max(c - x_{\min},\ x_{\max} - c)$，且该上界可达。

**证明**：底的两端都在 $x=c$ 上，长度 $\le \max Y(c) - \min Y(c)$。第三点 $P$ 的 $x_P \ne c$（否则三点共线、面积为 0，不合法），所以高 $= |x_P - c| \le \max(c - x_{\min},\ x_{\max} - c)$（因为 $x_{\min} \le x_P \le x_{\max}$）。两者相乘得上界。取底为 $(c, \min Y(c))$、$(c, \max Y(c))$，第三点取 $x$ 达到 $x_{\min}$ 或 $x_{\max}$ 的任意一点（其 $x \ne c$，否则 $x_{\min} = x_{\max} = c$，此时高为 0 上界也是 0），即达到上界。∎

**引理 3（横底对称）**：对横底的结论与引理 2 对称，上界为 $\big(\max X(c) - \min X(c)\big)\cdot\max(c-y_{\min}, y_{\max}-c)$，且可达。

**证明**：与引理 2 逐字对称（交换 $x \leftrightarrow y$）。∎

**定理**：算法返回值等于所有合法三角形的最大两倍面积（不存在时为 $-1$）。

**证明**：由引理 1，任一合法三角形的轴平行边必是竖底或横底之一。若是竖底且位于 $x=c$，由引理 2 其 $2S$ 不超过算法在 $c$ 处的候选值；横底同理由引理 3。故算法遍历所有可能位置后的最大值是所有合法三角形 $2S$ 的上界，而引理 2、3 又说明这些上界都能被真实的合法三角形取到，因此最大值相等。当所有候选都为 0 时说明不存在面积非零的合法三角形，返回 $-1$ 正确。∎

## 6. 复杂度分析

- **时间**：$O(n)$。一趟扫描更新全局极值与每行/每列的极值；随后遍历不同的 $x$（至多 $n$ 个）与不同的 $y$（至多 $n$ 个），每次 $O(1)$。
- **空间**：$O(n)$。两个哈希表最多各存 $n$ 个键、每个键两个整数。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long maxArea(vector<vector<int>>& coords) {
        int xmin = INT_MAX, xmax = INT_MIN, ymin = INT_MAX, ymax = INT_MIN;
        unordered_map<int, int> xLow, xHigh, yLow, yHigh;  // 同 x / 同 y 下的另一坐标最小、最大值
        for (auto& p : coords) {
            int x = p[0], y = p[1];
            xmin = min(xmin, x);
            xmax = max(xmax, x);
            ymin = min(ymin, y);
            ymax = max(ymax, y);
            auto itx = xLow.find(x);
            if (itx == xLow.end()) {
                xLow[x] = y;
                xHigh[x] = y;
            } else {
                itx->second = min(itx->second, y);
                xHigh[x] = max(xHigh[x], y);
            }
            auto ity = yLow.find(y);
            if (ity == yLow.end()) {
                yLow[y] = x;
                yHigh[y] = x;
            } else {
                ity->second = min(ity->second, x);
                yHigh[y] = max(yHigh[y], x);
            }
        }

        long long best = 0;
        // 底边平行于 y 轴：竖底在同一条 x 上，高由另一侧最远的 x 提供
        for (auto& kv : xLow) {
            int x = kv.first;
            long long base = (long long)xHigh[x] - kv.second;
            long long h = max((long long)x - xmin, (long long)xmax - x);
            best = max(best, base * h);
        }
        // 底边平行于 x 轴：横底在同一条 y 上，高由另一侧最远的 y 提供
        for (auto& kv : yLow) {
            int y = kv.first;
            long long base = (long long)yHigh[y] - kv.second;
            long long h = max((long long)y - ymin, (long long)ymax - y);
            best = max(best, base * h);
        }
        return best > 0 ? best : -1;   // 面积不能为 0
    }
};
```

### Python

```python
class Solution:
    def maxArea(self, coords: list[list[int]]) -> int:
        xmin = min(p[0] for p in coords)
        xmax = max(p[0] for p in coords)
        ymin = min(p[1] for p in coords)
        ymax = max(p[1] for p in coords)

        x_low, x_high = {}, {}      # 同 x 下的 y 最小值 / 最大值
        y_low, y_high = {}, {}      # 同 y 下的 x 最小值 / 最大值
        for x, y in coords:
            if x in x_low:
                x_low[x] = min(x_low[x], y)
                x_high[x] = max(x_high[x], y)
            else:
                x_low[x] = x_high[x] = y
            if y in y_low:
                y_low[y] = min(y_low[y], x)
                y_high[y] = max(y_high[y], x)
            else:
                y_low[y] = y_high[y] = x

        best = 0
        # 竖底（平行 y 轴）：底在同一条 x 上，高取左右最远的 x
        for x in x_low:
            base = x_high[x] - x_low[x]
            h = max(x - xmin, xmax - x)
            best = max(best, base * h)
        # 横底（平行 x 轴）：底在同一条 y 上，高取上下最远的 y
        for y in y_low:
            base = y_high[y] - y_low[y]
            h = max(y - ymin, ymax - y)
            best = max(best, base * h)
        return best if best > 0 else -1     # 面积不能为 0
```

## 8. 边界情况与易错点

1. **所有点共线或同 x**：候选面积全为 $0$，必须返回 $-1$，不能返回 $0$。
2. **底与高要相乘后判零**：只有底为 $0$ 或高为 $0$ 才是退化三角形，单看某一个量不严谨。
3. **第三点的 $x$（或 $y$）必须与底不同**：若 $x_{\min} = x_{\max}$（所有点同 $x$），高为 $0$，公式自动给出 $0$，无需特判。
4. **底只能取同一条线上的两点**：`xHigh - xLow` 是正确的极差，跨行取极差会得到不存在的底。
5. **`long long`**：$10^6 \times 10^6 = 10^{12}$，`int` 溢出。
6. **$n < 3$**：无法组成三角形，答案 $-1$（哈希表里每个键都只有一个点，底为 0）。
7. **坐标可能重复？** 题目保证点互不相同；若允许重复，需要额外的「同一位置多点」处理，本题不需要。
8. **哈希表遍历顺序**：答案与遍历顺序无关（取全局最大值），不要依赖顺序。
