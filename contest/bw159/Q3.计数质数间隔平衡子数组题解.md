# LeetCode 计数质数间隔平衡子数组 题解

## 1. 题目概述

- **标题 / 题号**：计数质数间隔平衡子数组（#3589，medium）
- **链接**：https://leetcode.cn/problems/count-prime-gap-balanced-subarrays/
- **来源**：LeetCode 第 159 场双周赛 Q3
- **难度**：中等
- **标签**：队列、数组、数学、数论、滑动窗口、单调队列

**题意**：给定整数数组 `nums` 与整数 $k$。若一个子数组满足：

1. 其中**至少包含两个质数**；
2. 子数组中**最大质数与最小质数之差** $\le k$，

则称它是**质数间隔平衡**的。返回这样的子数组个数。

**约束**：

- $1 \le n \le 5\times 10^4$
- $1 \le \text{nums}[i] \le 5\times 10^4$
- $0 \le k \le 5\times 10^4$

> 💡 非质数元素只影响「端点可以伸多远」，真正参与判定的是质数的**数值极差**。先把质数抽出来单独看，问题就清晰了。

## 2. 示例

**示例 1**

```text
输入：nums = [1,2,3], k = 1
输出：2
解释：合法子数组为 [2,3] 与 [1,2,3]：都含质数 2、3，极差 3-2 = 1 <= 1。
```

**示例 2**

```text
输入：nums = [2,3,5,7], k = 3
输出：4
解释：合法的是 [2,3]、[2,3,5]、[3,5]、[5,7]。注意 [3,5,7] 极差 7-3=4 > 3，不合法。
```

**示例 3（自造）**

```text
输入：nums = [2,2], k = 0
输出：1
解释：两个质数都是 2，极差 0 <= 0，合法。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有子数组 $O(n^2)$ 个，每个子数组扫一遍求质数的最值，$O(n)$，总 $O(n^3)$；用增量维护极值可降到 $O(n^2)$。$n = 5\times10^4$ 时 $2.5\times 10^9$，仍然太慢。而且「子数组是否合法」关于左端点**并不单调**（加元素可能让极差超限），不能直接套普通滑动窗口。

### 3.2 核心观察：只看质数序列，且固定右端时左端是「后缀区间」

![把质数抽出来看：非质数只影响端点可选个数](images/bw159_q3_prime_positions.svg)

设数组中的质数按下标升序为 $p_0 < p_1 < \cdots < p_{m-1}$，数值为 $v_0, v_1, \dots, v_{m-1}$。

一个子数组 $[l, r]$ 内的质数，恰好是「下标落在 $[l,r]$ 内」的那段连续质数 $p_s, p_{s+1}, \dots, p_e$。所以子数组的合法性只取决于**质数窗口 $[s, e]$**：

- 至少两个质数：$e - s + 1 \ge 2$；
- 极差 $\le k$：$\max(v_s..v_e) - \min(v_s..v_e) \le k$。

**关键单调性**：固定右端 $e$，当左端 $s$ 变小时质数窗口变大，极差只会变大或不变。所以「使 $\max-\min \le k$」的 $s$ 构成一个**后缀区间** $[s_{\min}(e),\ e]$；并且 $s_{\min}(e)$ 关于 $e$ **单调不减**（$[s, e+1]$ 合法 $\Rightarrow$ $[s,e]$ 合法）。于是可以用**单调队列 + 双指针**在 $O(m)$ 内求出所有 $s_{\min}(e)$。

### 3.3 算法流程

![固定最右质数 e，最小合法左端 s，左右端点各自自由](images/bw159_q3_window_count.svg)

对每个 $e$，统计「质数窗口恰为 $[s, e]$（$s \in [s_{\min}(e),\ e-1]$）」的子数组个数：

- **右端点** $r$ 必须落在 $[p_e,\ p_{e+1} - 1]$，共 $\text{pos}[e+1] - \text{pos}[e]$ 个（$p_m$ 视为 $n$）；
- **左端点** $l$ 要「包含 $p_s$ 但不包含 $p_{s-1}$」，即 $l \in (p_{s-1},\ p_s]$，共 $p_s - p_{s-1}$ 个（$p_{-1}$ 视为 $-1$）。

对 $s$ 从 $s_{\min}(e)$ 到 $e-1$ 求和可用望远镜化简：

$$\sum_{s=s_{\min}(e)}^{e-1} \big(p_s - p_{s-1}\big) = p_{e-1} - p_{s_{\min}(e)-1}$$

于是

$$\text{贡献}(e) = \big(\text{pos}[e+1] - \text{pos}[e]\big)\cdot\big(\text{pos}[e-1] - \text{pos}[s_{\min}(e)-1]\big)$$

```text
1. 埃氏筛出 [1, max(nums)] 内的质数
2. 抽出 pos[]（质数下标）与 val[]（质数数值）
3. 单调队列维护 val 的最大/最小值，双指针 s 表示最小合法左端：
   for e = 0 .. m-1:
       把 e 压入两个单调队列
       while s <= e 且 max - min > k: 若队头是 s 则弹出；s++
       若 e >= 1 且 s <= e-1:
           rCnt = (e+1 < m ? pos[e+1] : n) - pos[e]
           lCnt = pos[e-1] - (s >= 1 ? pos[s-1] : -1)
           ans += rCnt * lCnt
```

### 3.4 示例演算

`nums = [2,3,5,7]`，$k = 3$，质数全满：`pos = [0,1,2,3]`、`val = [2,3,5,7]`。

| $e$ | $s_{\min}(e)$ | 右端可选 | 左端可选 | 贡献 |
|-----|--------------|---------|---------|------|
| 1（$v=3$） | 0 | $\text{pos}[2]-\text{pos}[1] = 1$ | $\text{pos}[0]-(-1) = 1$ | 1 |

## 4. 算法细节

1. **筛法范围**：只需筛到 `max(nums)`（$\le 5\times10^4$），`isPrime[0] = isPrime[1] = false`，$1$ 不是质数。
2. **单调队列存下标**：比较时用 `val[queue.back()]`，弹出时用 `queue.front() == s` 判断是否需同步收缩。
3. **两根指针的配合**：`s` 只在「当前窗口极差 $> k$」时右移，且右移时同步弹出队头等于 $s$ 的元素。
4. **$s_{\min}(e) > e-1$ 时跳过**：此时窗口内不足两个质数，没有合法子数组。
5. **端点计数公式**：右端点是「取到下一个质数之前」的所有位置，左端点是「越过上一个质数之后」的所有位置——两段互不干扰，可以相乘。
6. **望远镜求和**：$\sum_{s=s_{\min}}^{e-1}(p_s - p_{s-1}) = p_{e-1} - p_{s_{\min}-1}$，把内层求和压成 $O(1)$，这是 $O(m)$ 而非 $O(m^2)$ 的关键。
7. **数值范围**：子数组总数 $\le \frac{n(n+1)}{2}\approx 1.25\times10^9$，`int` 勉强够但接近上限，内部用 `long long`。

## 5. 正确性证明

**引理 1（质数窗口刻画）**：子数组 $[l,r]$ 内包含的质数集合恰为 $\{p_s, \dots, p_e\}$，其中 $s$ 是满足 $p_s \ge l$ 的最小下标、$e$ 是满足 $p_e \le r$ 的最大下标。

**证明**：质数序列按下标升序排列，$[l,r]$ 内的质数自然是序列中连续的一段；两端下标由「第一个 $\ge l$」与「最后一个 $\le r$」唯一确定。∎

**引理 2（固定 $e$ 的单调性）**：对固定 $e$，令 $f(s) = \max(v_s..v_e) - \min(v_s..v_e)$。则 $f$ 关于 $s$ 单调不增（$s$ 变大窗口变小）；因此使 $f(s) \le k$ 的 $s$ 构成后缀 $[s_{\min}(e), e]$，且 $s_{\min}(e)$ 关于 $e$ 单调不减。

**证明**：$s$ 增大时窗口 $[s,e]$ 是原窗口的子集，其最大值不增、最小值不减，故极差不增。于是「$f(s)\le k$」的解集是后缀。又 $[s,e+1]$ 合法 $\Rightarrow$ 其子窗口 $[s,e]$ 合法，故 $s_{\min}(e) \le s_{\min}(e+1)$。∎

**引理 3（计数分解无重漏）**：每个合法子数组 $[l,r]$ 唯一对应一组 $(e, s, l, r)$，其中 $e$ 是 $[l,r]$ 内最右质数、$s$ 是最左质数；且对固定的 $e$，合法子数组的 $l$ 恰为满足 $s_{\min}(e) \le s \le e-1$ 对应区间的并集，个数为 $\text{pos}[e-1] - \text{pos}[s_{\min}(e)-1]$。

**证明**：给定 $[l,r]$，最左/最右质数唯一，故 $(e,s)$ 唯一。反之给定 $(e,s)$ 与满足 $l \in (p_{s-1}, p_s]$、$r \in [p_e, p_{e+1})$ 的 $(l,r)$，该子数组的质数窗口恰为 $[s,e]$，不重不漏。各区间的端点互不重叠（左端点区间按 $s$ 划分、相邻区间只在边界处相接），故可直接求和；求和用望远镜化简即得公式。∎

**定理**：算法输出等于质数间隔平衡子数组的个数。

**证明**：由引理 1，子数组合法 $\iff$ 其质数窗口 $[s,e]$ 满足 $e-s+1\ge2$ 且极差 $\le k$，后者由引理 2 等价于 $s \ge s_{\min}(e)$。算法对每个 $e$ 恰好枚举了所有满足 $s_{\min}(e)\le s\le e-1$ 的窗口并乘以对应的端点选择数（引理 3），累加即得全部合法子数组，且每个恰计一次。∎

## 6. 复杂度分析

- **时间**：$O(V\log\log V + n + m)$，其中 $V = \max(\text{nums}) \le 5\times10^4$、$m \le n$ 为质数个数。筛法 $O(V\log\log V)$，抽取质数 $O(n)$，双指针 + 单调队列中每个质数最多进队出队各一次，$O(m)$。
- **空间**：$O(V + n)$。筛法布尔数组 $O(V)$，`pos`/`val` 与两个单调队列各 $O(m)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int primeSubarray(vector<int>& nums, int k) {
        int n = (int)nums.size();
        int mx = 0;
        for (int v : nums) mx = max(mx, v);
        // 埃氏筛
        vector<bool> isPrime(mx + 1, true);
        if (mx >= 0) isPrime[0] = false;
        if (mx >= 1) isPrime[1] = false;
        for (int i = 2; (long long)i * i <= mx; i++) {
            if (!isPrime[i]) continue;
            for (int j = i * i; j <= mx; j += i) isPrime[j] = false;
        }

        // 把质数按下标抽出来：pos[t] 为第 t 个质数的下标，val[t] 为其数值
        vector<int> pos, val;
        for (int i = 0; i < n; i++) {
            if (isPrime[nums[i]]) {
                pos.push_back(i);
                val.push_back(nums[i]);
            }
        }
        int m = (int)pos.size();
        long long ans = 0;
        deque<int> maxQ, minQ;      // 质数数值序列上的单调队列
        int s = 0;                  // 满足 max-min <= k 的最小左端（在质数序列上）
        for (int e = 0; e < m; e++) {
            while (!maxQ.empty() && val[maxQ.back()] <= val[e]) maxQ.pop_back();
            maxQ.push_back(e);
            while (!minQ.empty() && val[minQ.back()] >= val[e]) minQ.pop_back();
            minQ.push_back(e);
            while (s <= e && val[maxQ.front()] - val[minQ.front()] > k) {
                if (maxQ.front() == s) maxQ.pop_front();
                if (minQ.front() == s) minQ.pop_front();
                s++;
            }
            if (e >= 1 && s <= e - 1) {
                // 右端点可选个数：pos[e] .. pos[e+1]-1
                long long rCnt = (long long)((e + 1 < m ? pos[e + 1] : n) - pos[e]);
                // 左端点可选个数：对 s' in [s, e-1] 求和 (pos[s'] - pos[s'-1]) = pos[e-1] - pos[s-1]
                long long lCnt = (long long)pos[e - 1] - (s >= 1 ? pos[s - 1] : -1);
                ans += rCnt * lCnt;
            }
        }
        return (int)ans;
    }
};
```

### Python

```python
class Solution:
    def primeSubarray(self, nums: list[int], k: int) -> int:
        n = len(nums)
        mx = max(nums)
        # 埃氏筛
        is_prime = bytearray([1]) * (mx + 1)
        if mx >= 0:
            is_prime[0] = 0
        if mx >= 1:
            is_prime[1] = 0
        i = 2
        while i * i <= mx:
            if is_prime[i]:
                is_prime[i * i::i] = bytearray(len(is_prime[i * i::i]))
            i += 1

        # 抽出质数：pos[t] 为第 t 个质数的下标，val[t] 为其数值
        pos = [i for i, v in enumerate(nums) if is_prime[v]]
        val = [v for v in nums if is_prime[v]]
        m = len(pos)

        ans = 0
        max_q, min_q = [], []        # 存下标，维护 val 的单调队列
        s = 0                        # 满足 max-min <= k 的最小左端（质数序列上）
        for e in range(m):
            while max_q and val[max_q[-1]] <= val[e]:
                max_q.pop()
            max_q.append(e)
            while min_q and val[min_q[-1]] >= val[e]:
                min_q.pop()
            min_q.append(e)
            while s <= e and val[max_q[0]] - val[min_q[0]] > k:
                if max_q[0] == s:
                    max_q.pop(0)
                if min_q[0] == s:
                    min_q.pop(0)
                s += 1
            if e >= 1 and s <= e - 1:
                r_cnt = (pos[e + 1] if e + 1 < m else n) - pos[e]
                l_cnt = pos[e - 1] - (pos[s - 1] if s >= 1 else -1)
                ans += r_cnt * l_cnt
        return ans
```

## 8. 边界情况与易错点

1. **质数个数 $< 2$**：答案 0，循环中 `e >= 1` 与 `s <= e-1` 双条件保证不误计。
2. **$k = 0$**：只允许「所有质数相同」，例如 `[2,2]`；双指针条件写成严格大于 `> k`（即 `> 0`）才对。
3. **极差方向**：判定是 `max - min > k` 才收缩；写成 `< k` 或漏绝对值会错。
4. **单调队列同步弹出**：收缩 `s` 时必须检查队头是否等于 `s`，否则队头会指向窗口外的元素，`max/min` 失真。
5. **$1$ 不是质数**：筛法必须显式置 `is_prime[0] = is_prime[1] = 0`；$1$ 在题面里也明确被排除。
6. **望远镜公式的下标**：$s = 0$ 时 `pos[s-1]` 要用 $-1$（表示「第一个质数左边」），写成 $0$ 会少算 $l = 0$ 的那个位置。
7. **左右端点计数相乘**：不要漏掉「$r$ 可以一直取到下一个质数之前」这一段非质数尾巴。
8. **`int` 上限**：$1.25\times10^9$ 仍在 `int` 内，但已经接近；内部用 `long long` 更稳妥。
