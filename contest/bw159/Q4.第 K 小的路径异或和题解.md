# LeetCode 第 K 小的路径异或和 题解

## 1. 题目概述

- **标题 / 题号**：第 K 小的路径异或和（#3590，hard）
- **链接**：https://leetcode.cn/problems/kth-smallest-path-xor-sum/
- **来源**：LeetCode 第 159 场双周赛 Q4
- **难度**：困难
- **标签**：树、深度优先搜索、数组、有序集合

**题意**：给定一棵以节点 $0$ 为根、含 $n$ 个节点的树（父数组 `par`），每个节点有权值 `vals[i]`。定义**路径异或和** $\text{px}[u]$ 为从根到 $u$ 的路径上所有节点权值的按位异或（含 $u$）。

对每个查询 $[u, k]$，求「以 $u$ 为根的子树中，所有节点的 $\text{px}$ 值里**第 $k$ 小的不同值**」；若不同值不足 $k$ 个，返回 $-1$。

**约束**：

- $1 \le n \le 5\times 10^4$
- $0 \le \text{vals}[i] \le 10^5$
- $1 \le \text{queries.length} \le 5\times 10^4$
- `par[0] == -1`，$0 \le \text{par}[i] < n$，`par` 表示一棵合法的树

> 💡 注意两个关键词：「**子树内**」与「**不同**值」。前者提示 DFS 序 / 树上合并，后者提示去重集合。

## 2. 示例

**示例 1**

```text
输入：par = [-1,0,0], vals = [1,1,1], queries = [[0,1],[0,2],[0,3]]
输出：[0,1,-1]
解释：px = [1, 1^1=0, 1^1=0]；子树 0 的不同值为 {0,1}。
     第 1 小是 0，第 2 小是 1，第 3 小不存在 -> -1。
```

**示例 2**

```text
输入：par = [-1,0,1], vals = [5,2,7], queries = [[0,1],[1,2],[1,3],[2,1]]
输出：[0,7,-1,0]
解释：px = [5, 7, 0]；子树 0 的值 {0,5,7}，子树 1 的 {0,7}，子树 2 的 {0}。
```

**示例 3（自造）**

```text
输入：par = [-1,0], vals = [0,5], queries = [[1,1],[0,2]]
输出：[5,5]
解释：px = [0, 5]；子树 1 只有 {5}；子树 0 的不同值 {0,5}，第 2 小是 5。
```

## 3. 解题思路

### 3.1 暴力思路

对每个查询 $[u,k]$：DFS 收集子树 $u$ 的所有节点，取 $\text{px}$ 值、去重、排序，再取第 $k$ 个。单次 $O(n\log n)$，$q = 5\times10^4$ 时 $O(qn\log n)$ 约 $10^{10}$，超时。需要把「同一棵子树的重复计算」合并起来。

### 3.2 核心观察：子树 = 先序序上的一段连续区间

![路径异或和：子树内的取值就是一个多重集合](images/bw159_q4_subtree_xor.svg)

- 先算出每个节点的路径异或值：$\text{px}[i] = \text{px}[\text{par}[i]] \oplus \text{vals}[i]$，由于 $\text{par}[i] < i$，按编号顺序一遍递推即可。
- 对树做**先序 DFS**，得到 `tin[u]`（进入位置）、`tout[u]`（子树最后位置）与 `euler[]` 数组。子树 $u$ 的节点恰为 `euler[tin[u] .. tout[u]]`。
- 于是每个查询变成：**在区间 $[tin[u], tout[u]]$ 上，求 $\text{px}$ 值的第 $k$ 小不同值**。

### 3.3 算法流程

![DSU on tree + 树状数组](images/bw159_q4_dsu_fenwick.svg)

两种实现，思路一致，任选其一：

**（A）DSU on tree（C++ 版，树上启发式合并 + 树状数组）**

```text
1. 求 px[]、tin/tout/euler[]、子树大小 sz[]、重儿子 heavy[]
2. 把每个查询挂到它的 u 上
3. 把 px 值离散化，用树状数组 bit 维护「当前集合中不同取值个数」
4. dfs(u, keep)：
     对每个轻儿子 v： dfs(v, false)
     对重儿子：      dfs(heavy[u], true)
     把每个轻儿子子树暴力加入（addPos 逐个 +1）
     加入 u 自己
     回答挂在 u 上的查询：第 k 小 = bit 倍增定位
     若 keep == false：把整棵子树逐个 -1 撤回
5. 答案数组输出
```

- 每个节点被「加入」的次数 = 它到根的路径上轻边数 $+1 = O(\log n)$，总加点 $O(n\log n)$；每次加点 $O(\log n)$，故 $O(n\log^2 n)$。
- 第 $k$ 小用树状数组的**倍增定位**：从高位到低位试跳，累计前缀和，$O(\log n)$。

**（B）小集合并入大集合（Python 版，`SortedSet`）**

```text
按「孩子先于父亲」的顺序（BFS 序的逆序）处理每个节点 u：
    cur = SortedSet({px[u]})
    对每个孩子 v：
        若 |set[v]| > |cur|：把 cur 并入 set[v]，cur = set[v]
        否则：把 set[v] 并入 cur
    回答挂在 u 上的查询：cur[k-1]（k > |cur| 时为 -1）
    set[u] = cur
```

这是**小集合并入大集合**（small-to-large）：每个元素每次被搬动时，所在集合大小至少翻倍，故每个元素最多被搬动 $O(\log n)$ 次，总复杂度 $O(n\log^2 n)$。

### 3.4 示例演算

![示例 2 的子树与第 k 小](images/bw159_q4_example_walk.svg)

`par = [-1,0,1]`、`vals = [5,2,7]`：$\text{px} = [5,\ 5\oplus2=7,\ 5\oplus2\oplus7=0]$。

| 子树 | 包含节点 | 路径异或值 | 不同值（升序） | 查询答案 |
|------|---------|-----------|---------------|---------|
| 0 | $\{0,1,2\}$ | $\{5,7,0\}$ | $[0,5,7]$ | $k=1 \to 0$ |
| 1 | $\{1,2\}$ | $\{7,0\}$ | $[0,7]$ | $k=2 \to 7$，$k=3 \to -1$ |
| 2 | $\{2\}$ | $\{0\}$ | $[0]$ | $k=1 \to 0$ |

输出 $[0,7,-1,0]$，与官方示例一致。示例 1 中 $\text{px} = [1,0,0]$，去重后为 $\{0,1\}$，所以 $k=3$ 时返回 $-1$。

## 4. 算法细节

1. **$\text{px}$ 的递推顺序**：题目保证 $\text{par}[i] < i$，所以从小到大一遍即可，无需 DFS。
2. **先序区间**：`tin[u]` 是 $u$ 首次被访问的位置，`tout[u]` 是「离开 $u$ 时已访问的位置数 $-1$」；子树节点在 `euler` 上连续，这是 DSU on tree 能用「区间整体加减」的基础。
3. **重儿子**：子树规模最大的孩子。留用它的数据可以避免重复加点，是复杂度的关键。
4. **去重**：树状数组维护的是「每个取值出现次数」，但只在 `occ` 从 0 变 1（或 1 变 0）时才更新 BIT，从而 BIT 里存的是**不同值个数**。
5. **第 $k$ 小的倍增定位**：树状数组的 `bit[i]` 是「区间和」，用 `step` 从 $2^{\lfloor\log m\rfloor}$ 递减，`bit[pos+step] < k` 就跳并减去，最后 `pos+1` 即答案下标。
6. **`keep` 标记**：轻儿子处理完要撤回（否则影响兄弟），重儿子保留给父亲复用。这是 DSU on tree 的标准写法。
7. **Python 用 `SortedSet` 而非 `SortedList`**：后者允许重复，会把重复的 $\text{px}$ 值当成不同的排名项；`SortedSet` 是集合语义，正合题意。
8. **$-1$ 判定**：$k$ 可能大于当前集合大小，务必判断后再取第 $k$ 个。

## 5. 正确性证明

**引理 1（路径异或递推）**：令 $\text{px}[0] = \text{vals}[0]$，$\text{px}[i] = \text{px}[\text{par}[i]] \oplus \text{vals}[i]$，则 $\text{px}[i]$ 等于根到 $i$ 路径上所有节点权值的异或和。

**证明**：对节点编号归纳。根到 $i$ 的路径 = 根到 $\text{par}[i]$ 的路径 + 节点 $i$，异或满足结合律，故 $\text{px}[i] = \text{px}[\text{par}[i]] \oplus \text{vals}[i]$。由于 $\text{par}[i] < i$，按编号递增计算时 $\text{px}[\text{par}[i]]$ 已就绪。∎

**引理 2（子树 = 先序区间）**：先序 DFS 中，子树 $u$ 的节点在 `euler` 上恰好占据连续区间 $[\text{tin}[u], \text{tout}[u]]$。

**证明**：先序遍历先访问 $u$ 再递归访问整棵子树，因此 $u$ 的子树节点在遍历序列中紧接 $u$ 之后、连续排列，直到最后一个叶子；`tout[u]` 是离开子树前的最后位置，故区间恰好覆盖子树。∎

**引理 3（集合内容正确性）**：在 DSU on tree 处理完节点 $u$ 的「合并」步骤后，树状数组中的取值集合恰为 $\{\text{px}[v] : v \in \text{subtree}(u)\}$，且每个取值只计一次。

**证明**：对树高归纳。轻儿子各自被处理并撤回，重儿子的数据结构保留；随后把每个轻儿子子树与 $u$ 自身逐个加入。由于撤回保证进入 $u$ 时 BIT 只含重儿子的子树，加入全部轻儿子子树与 $u$ 后恰为整棵子树。`occ` 的计数保证同一取值只贡献 1 个 BIT 单位。∎

**定理**：对每个查询 $[u,k]$，算法输出为子树 $u$ 中第 $k$ 小的不同路径异或值（不足 $k$ 个时为 $-1$）。

**证明**：由引理 1 得到正确的 $\text{px}$，由引理 3 在回答查询时 BIT 恰含子树 $u$ 的不同取值集合，且 BIT 的前缀和 = 不超过某值的不同值个数，倍增定位求出的正是第 $k$ 小的那个值。$k$ 大于集合大小时输出 $-1$，符合定义。∎

## 6. 复杂度分析

- **时间**：
  - C++（DSU on tree + BIT）：$O(n\log^2 n + q\log n)$。每个节点被加入 $O(\log n)$ 次、每次 BIT 更新 $O(\log n)$；每个查询倍增定位 $O(\log n)$。
  - Python（small-to-large + `SortedSet`）：$O(n\log^2 n + q\log n)$，每个元素最多被搬动 $O(\log n)$ 次，每次插入 $O(\log n)$。
- **空间**：$O(n + q)$。$\text{px}$、`tin/tout/euler`、`sz/heavy`、`occ/bit` 各 $O(n)$，查询按节点分组 $O(q)$；Python 版每层的集合在合并后释放，峰值 $O(n)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> kthSmallest(vector<int>& par, vector<int>& vals, vector<vector<int>>& queries) {
        int n = (int)par.size();
        vector<vector<int>> ch(n);
        for (int i = 1; i < n; i++) ch[par[i]].push_back(i);

        // ---- 1. 根到每个节点的路径异或和（par[i] < i，按编号顺序即可）----
        vector<int> px(n);
        px[0] = vals[0];
        for (int i = 1; i < n; i++) px[i] = px[par[i]] ^ vals[i];

        // ---- 2. 先序欧拉序 + 子树区间 [tin, tout] ----
        vector<int> tin(n), tout(n), euler(n);
        {
            int timer = 0;
            vector<pair<int, int>> st{{0, 0}};
            while (!st.empty()) {
                auto [u, state] = st.back();
                st.pop_back();
                if (state == 0) {
                    tin[u] = timer;
                    euler[timer++] = u;
                    st.push_back({u, 1});
                    for (int i = (int)ch[u].size() - 1; i >= 0; i--) st.push_back({ch[u][i], 0});
                } else {
                    tout[u] = timer - 1;
                }
            }
        }
        vector<int> sz(n);
        for (int u = 0; u < n; u++) sz[u] = tout[u] - tin[u] + 1;

        // ---- 3. 查询按节点分组 ----
        int q = (int)queries.size();
        vector<int> ans(q, -1);
        vector<vector<pair<int, int>>> qs(n);
        for (int i = 0; i < q; i++) qs[queries[i][0]].push_back({queries[i][1], i});

        // ---- 4. 路径异或值离散化 + 树状数组（统计「当前集合中有多少个不同的值」）----
        vector<int> uniq = px;
        sort(uniq.begin(), uniq.end());
        uniq.erase(unique(uniq.begin(), uniq.end()), uniq.end());
        int m = (int)uniq.size();
        vector<int> id(n);
        for (int i = 0; i < n; i++)
            id[i] = (int)(lower_bound(uniq.begin(), uniq.end(), px[i]) - uniq.begin()) + 1;

        vector<int> occ(m + 1, 0), bit(m + 1, 0);
        int distinctCnt = 0;
        auto bitAdd = [&](int i, int v) {
            for (; i <= m; i += i & -i) bit[i] += v;
        };
        auto addPos = [&](int p, int delta) {
            int v = id[euler[p]];
            if (delta > 0) {
                if (occ[v]++ == 0) { bitAdd(v, 1); distinctCnt++; }
            } else {
                if (--occ[v] == 0) { bitAdd(v, -1); distinctCnt--; }
            }
        };
        auto kthValue = [&](int k) {          // 第 k 小（1 <= k <= distinctCnt）
            int pos = 0, rem = k;
            int step = 1;
            while (step * 2 <= m) step *= 2;
            for (; step > 0; step >>= 1) {
                int nxt = pos + step;
                if (nxt <= m && bit[nxt] < rem) {
                    pos = nxt;
                    rem -= bit[nxt];
                }
            }
            return uniq[pos];                 // 对应的真实取值
        };

        // ---- 5. 树上启发式合并（DSU on tree）----
        vector<int> heavy(n, -1);
        for (int u = 0; u < n; u++) {
            int best = 0;
            for (int v : ch[u]) {
                if (sz[v] > best) { best = sz[v]; heavy[u] = v; }
            }
        }
        vector<tuple<int, int, int>> stk;     // (节点, 是否保留, 阶段)
        stk.push_back({0, 1, 0});
        while (!stk.empty()) {
            auto [u, keep, stage] = stk.back();
            stk.pop_back();
            if (stage == 0) {
                stk.push_back({u, keep, 1});
                for (int v : ch[u]) {
                    if (v != heavy[u]) stk.push_back({v, 0, 0});
                }
            } else if (stage == 1) {
                stk.push_back({u, keep, 2});
                if (heavy[u] >= 0) stk.push_back({heavy[u], 1, 0});
            } else {
                for (int v : ch[u]) {
                    if (v == heavy[u]) continue;
                    for (int p = tin[v]; p <= tout[v]; p++) addPos(p, +1);
                }
                addPos(tin[u], +1);
                for (auto& [k, qi] : qs[u]) {
                    ans[qi] = (k <= distinctCnt) ? kthValue(k) : -1;
                }
                if (!keep) {
                    for (int p = tin[u]; p <= tout[u]; p++) addPos(p, -1);
                }
            }
        }
        return ans;
    }
};
```

### Python

```python
from sortedcontainers import SortedSet


class Solution:
    def kthSmallest(self, par: list[int], vals: list[int], queries: list[list[int]]) -> list[int]:
        n = len(par)
        ch = [[] for _ in range(n)]
        for i in range(1, n):
            ch[par[i]].append(i)

        # 根到每个节点的路径异或和（par[i] < i，按编号顺序即可）
        px = [0] * n
        px[0] = vals[0]
        for i in range(1, n):
            px[i] = px[par[i]] ^ vals[i]

        # 查询按节点分组，同时求一个「孩子先于父亲」的处理顺序（BFS 序的逆序）
        qs = [[] for _ in range(n)]
        for qi, (u, k) in enumerate(queries):
            qs[u].append((k, qi))
        order = [0]
        for u in order:
            for v in ch[u]:
                order.append(v)

        ans = [-1] * len(queries)
        sets = [None] * n
        for u in reversed(order):
            cur = SortedSet([px[u]])
            for v in ch[u]:
                sv = sets[v]
                if len(sv) > len(cur):        # 小的并入大的
                    sv.update(cur)
                    cur = sv
                else:
                    cur.update(sv)
                sets[v] = None
            sets[u] = cur
            for k, qi in qs[u]:
                ans[qi] = cur[k - 1] if k <= len(cur) else -1
        return ans
```

## 8. 边界情况与易错点

1. **「不同」二字**：必须去重。`SortedList` 允许重复，会把重复值算成不同的名次；用 `SortedSet` 或 `occ` 计数。
2. **$k$ 超界**：返回 $-1$，不能抛异常或返回集合最后一个元素。
3. **单节点子树**：$n = 1$ 时只有一个值，$k=1$ 返回该值，$k \ge 2$ 返回 $-1$。
4. **$\text{par}[i] < i$**：这是题目给的额外便利，可以直接按编号循环算 $\text{px}$；若父下标任意，需要用 BFS/DFS 顺序。
5. **DSU on tree 的 `keep` 语义**：轻儿子必须 `keep = false`（用完即撤），重儿子 `keep = true`；写反会导致数据污染，答案错乱。
6. **树状数组定位的边界**：`step` 从不超过 $m$ 的最大 $2$ 的幂开始；`nxt <= m` 的判断不可少。
7. **递归深度**：$n = 5\times10^4$ 的链会让递归 DFS 溢出，C++ 版用显式栈、Python 版用 BFS 序逆序，都规避了递归。
8. **结果类型**：$\text{px}$ 值最大不超过 $2^{17}$ 量级（$\text{vals} \le 10^5$ 的异或仍在 $< 2^{17}$ 内），`int` 足够。
