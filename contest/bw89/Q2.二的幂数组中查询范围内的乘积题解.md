# LeetCode 二的幂数组中查询范围内的乘积 题解

## 1. 题目概述

- **标题 / 题号**：二的幂数组中查询范围内的乘积（#2438，medium）
- **链接**：https://leetcode.cn/problems/range-product-queries-of-powers/
- **来源**：LeetCode 第 89 场双周赛 Q2
- **难度**：中等
- **标签**：位运算、数组、前缀和

**题意**：给定正整数 $n$，按构造规则得到唯一的**非递减**数组 `powers`：它由**最少个数**的 2 的幂组成且和恰为 $n$。再给一组查询 `queries[i] = [left, right]`，要求 $\prod_{j=\text{left}}^{\text{right}} \text{powers}[j]$ 对 $10^9 + 7$ 取模的结果，按查询顺序返回答案数组。

**约束**：

- $1 \le n \le 10^9$
- $1 \le \text{queries.length} \le 10^5$
- $0 \le \text{left}_i \le \text{right}_i < \text{powers.length}$

## 2. 示例

**示例 1**

```text
输入：n = 15, queries = [[0,1],[2,2],[0,3]]
输出：[2,4,64]
解释：15 = 1 + 2 + 4 + 8，powers = [1,2,4,8]。
      [0,1] → 1×2 = 2；[2,2] → 4；[0,3] → 1×2×4×8 = 64。
```

**示例 2**

```text
输入：n = 2, queries = [[0,0]]
输出：[2]
解释：2 = 2，powers = [2]，单点查询答案就是 2。
```

**补充：$n = 10^9$ 的规模感**

```text
10^9 = 2^9 + 2^8 + 2^27 + 2^26 + ... （二进制共 13 个 1）
powers.length = popcount(10^9) = 13，指数和最大不超过 29×13 ≈ 400，
答案真实值约为 2^400，必须边乘边取模。
```

## 3. 解题思路

### 3.1 暴力思路

对每个查询直接把 `powers[left..right]` 连乘并取模：单次查询至多乘 30 项（$n \le 10^9 < 2^{30}$，二进制中 1 的个数不超过 30），总量 $O(30 \times 10^5) = 3 \times 10^6$ 次模乘，其实已经能过。但如果看不出「乘同底数幂 = 指数相加」这一层，直接对原始 $n$ 做因子分解之类的做法则会走弯路。本题的考点正是：**把区间乘积转成指数的区间和**，再用前缀和 $O(1)$ 回答。

### 3.2 核心观察：同底数幂相乘 = 指数相加

![核心观察：二进制分解与同底数幂指数相加](images/bw89_q2_binary_decompose.svg)

`powers` 的构造规则本质上就是 $n$ 的**二进制表示**：$n = \sum_{e \in E} 2^e$，其中 $E$ 是 $n$ 的二进制中所有为 1 的位。例如 $n = 15 = 1111_2$，$E = \{0,1,2,3\}$，`powers = [1,2,4,8]`。因此数组元素都是 $2^{e_i}$，区间乘积变成

$$\prod_{j=l}^{r} 2^{e_j} = 2^{e_l + e_{l+1} + \cdots + e_r}$$

指数部分是**求和**而非求积——这正是前缀和最擅长的：预处理指数前缀和 `pre[i] = e_0 + ... + e_{i-1}`，区间指数和就是 `pre[r+1] - pre[l]`，每个查询 $O(1)$ 得到指数 $t$，最后用**快速幂**计算 $2^t \bmod (10^9+7)$。

### 3.3 算法流程

![算法流程：二进制分解 → 指数前缀和 → 快速幂](images/bw89_q2_prefix_exponent.svg)

```text
1. 分解：for e in 0..29: 若 n 的第 e 位为 1，记指数 e（天然递增）
2. 前缀和：pre[0] = 0, pre[i+1] = pre[i] + e_i
3. 对每个查询 [l, r]：
       t = pre[r+1] - pre[l]          # 区间乘积 = 2^t
       answers[i] = 2^t mod (1e9+7)  # 快速幂，O(log t)
```

### 3.4 示例演算

![示例演算：n=15 的三个查询](images/bw89_q2_example_walkthrough.svg)

以 $n = 15$ 为例：$E = \{0,1,2,3\}$，前缀和 `pre = [0, 0, 1, 3, 6]`。

| 查询 | 指数区间和 | 乘积 | 模 $10^9+7$ |
|------|-----------|------|------------|
| `[0,1]` | $pre[2] - pre[0] = 1$ | $2^1$ | 2 |
| `[2,2]` | $pre[3] - pre[2] = 2$ | $2^2$ | 4 |
| `[0,3]` | $pre[4] - pre[0] = 6$ | $2^6$ | 64 |

## 4. 算法细节

1. **`powers` 的唯一性**：$n$ 的二进制表示唯一，故按指数升序排列的 2 的幂列表唯一且非递减；「最少个数」由二进制分解的极小性保证（见 §5 引理 1）。
2. **只存指数，不存幂**：区间乘积只关心指数和，直接存 $e_i$ 更省——指数最大 29，个数最多 30，指数和不超过 $29 \times 30 < 900$，用 `int` / 普通整数即可，甚至不需要 `long long`。
3. **前缀和差分**：`pre[r+1] - pre[l]` 给出区间指数和，避免每个查询重新累加；数组开 `m+1` 长度，`pre[0] = 0` 哨兵。
4. **快速幂**：$2^t \bmod p$ 用反复平方法，$O(\log t) \le 30$ 步；也可以预处理全部 $2^{0..900} \bmod p$（一次线性递推），查询 $O(1)$——两者总量都是 $O(30 \times 10^5)$ 级别，任选其一。参考代码采用快速幂，逻辑独立、不需额外数组。
5. **取模时机**：本题幂 $2^t$ 本身巨大（$t$ 可达数百），绝不能先算真实值再取模，必须在模乘过程中逐步 `% MOD`。
6. **分解循环边界**：$n \le 10^9 < 2^{30}$，枚举 $e \in [0, 29]$ 足够；写成 `while (n)` 每次取最低位再右移亦可。

## 5. 正确性证明

**引理 1（构造唯一且最少）**：`powers` 恰为 $n$ 的二进制表示中各为 1 的位对应的 $2^e$ 按指数升序排列；且任何「和为 $n$ 的 2 的幂多重集」的元素个数都不少于 popcount$(n)$。

**证明**：存在性显然：二进制展开本身就是一组和为 $n$ 的 2 的幂。唯一性：设多重集 $M$ 和为 $n$，按指数分组，把每组内 $2^k$ 的个数写成二进制，等价于将 $M$ 规范化为「每个指数至多出现一次」的集合而不改变总和与元素个数的下界（两个 $2^k$ 换成一个 $2^{k+1}$ 元素个数还减少）；规范化后即二进制表示，由二进制唯一性得指数集合 $E$ 唯一。最少性：规范化只减不增元素个数，故任何 $M$ 的个数 $\ge$ popcount$(n)$。∎

**引理 2（区间乘积的指数形式）**：对任意区间 $[l, r]$，$\prod_{j=l}^{r} \text{powers}[j] = 2^{\,pre[r+1]-pre[l]}$。

**证明**：`powers[j] = 2^{e_j}`，而同底数幂相乘指数相加：$\prod_{j=l}^{r} 2^{e_j} = 2^{\sum_{j=l}^{r} e_j}$；后者由前缀和定义 $= 2^{pre[r+1]-pre[l]}$。∎

**定理（算法正确性）**：按 §3.3 流程输出的每个 `answers[i]` 等于真实乘积对 $10^9+7$ 的余数。

**证明**：由引理 1，分解得到的指数序列与题面构造的 `powers` 一一对应；由引理 2，每个查询的真实乘积为 $2^{t_i}$，$t_i = pre[r_i+1]-pre[l_i]$；快速幂在模意义下计算 $2^{t_i} \bmod p$（反复平方保持 $\tilde{a}\tilde{b} \equiv ab \pmod p$，归纳可证每一步均只依赖同余类），且 $t_i \ge 0$ 保证指数非负，输出即为所求余数。∎

## 6. 复杂度分析

- **时间**：分解 $O(\log n) \le 30$；前缀和 $O(\log n)$；每个查询一次 $O(1)$ 差分加一次 $O(\log \sum e) \le 10$ 步的快速幂（指数和 $< 900$，$\log_2 900 \approx 10$）。总计 $O(\log n + q \log \log n)$，本题规模下即 $O(q \cdot 10)$，约 $10^6$ 次模乘。
- **空间**：$O(\log n)$。指数数组与前缀和数组各至多 31 个元素；答案数组不计入额外空间。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> productQueries(int n, vector<vector<int>>& queries) {
        const long long MOD = 1'000'000'007;
        vector<int> exps;                          // n 的二进制分解：2 的指数，递增
        for (int e = 0; e < 30; ++e)
            if (n >> e & 1) exps.push_back(e);
        int m = (int)exps.size();
        vector<long long> pre(m + 1, 0);           // 指数前缀和 pre[i] = e_0+...+e_{i-1}
        for (int i = 0; i < m; ++i) pre[i + 1] = pre[i] + exps[i];
        vector<int> ans;
        ans.reserve(queries.size());
        for (auto& q : queries) {                  // powers[l..r] 的乘积 = 2^(pre[r+1]-pre[l])
            long long e = pre[q[1] + 1] - pre[q[0]];
            ans.push_back((int)qpow(2, e, MOD));
        }
        return ans;
    }
private:
    long long qpow(long long x, long long e, long long mod) {  // 快速幂
        long long r = 1;
        x %= mod;
        while (e) {
            if (e & 1) r = r * x % mod;
            x = x * x % mod;
            e >>= 1;
        }
        return r;
    }
};
```

### Python

```python
class Solution:
    def productQueries(self, n: int, queries: list) -> list:
        MOD = 10 ** 9 + 7
        exps = [e for e in range(30) if n >> e & 1]   # 二进制分解出的指数，递增
        pre = [0]                                      # 指数前缀和
        for e in exps:
            pre.append(pre[-1] + e)
        # powers[l..r] 的乘积 = 2^(pre[r+1]-pre[l])
        return [pow(2, pre[r + 1] - pre[l], MOD) for l, r in queries]
```

> 💡 两份代码均通过官方示例（`[2,4,64]`、`[2]`），并与「直接连乘取模」的暴力在 4000 组随机 $n \in [1, 10^9]$、随机查询下对拍一致；$n = 10^9$、$10^5$ 个查询的极端规模下 C++ 用时约 0.2s。

## 8. 边界情况与易错点

1. **$n$ 是 2 的幂**：如 $n = 2$，`powers` 只有一个元素，查询必须形如 `[0,0]`；前缀和长度 `m+1 = 2`，下标 `pre[r+1] = pre[1]` 不越界。
2. **区间端点含右端 $m-1$**：差分访问 `pre[r+1]`，数组必须开 `m+1`；若只开 `m` 会差一个元素越界。
3. **指数和会很大但仍有限**：最大 $29 \times 13 \approx 400$ 量级（popcount($10^9$) = 13），`int` 足够；但**乘积本身** $2^{400}$ 千万不能真实计算，必须走模乘或快速幂。
4. **快速幂初值**：`r = 1` 且 `x %= mod` 先做一次；本题 $x = 2 < p$ 可省，但写成通用快速幂更稳。
5. **分解顺序**：按 $e$ 从小到大枚举得到非递减的 `powers`，与题面一致；若从大到小枚举则顺序颠倒，查询下标含义会错位。
6. **不要把 `n` 与 `powers.length` 混淆**：查询约束里的上界是 `powers.length` = popcount($n$)，不是 30。

**延伸思考**：把「区间乘积」化成「区间指数和」是**对数思想**的标准应用——当所有元素同底时可对指数做前缀和。若元素底数不同（如区间内是任意整数），则前缀和失效，可考虑前缀乘积模素数（遇 0 失效需记 0 的个数）或线段树维护区间乘积；若查询离线且模数不是素数，还可对每个素因子分别维护指数前缀和，用 CRT 合并——这是「阶乘末尾的 0」类问题的推广。
