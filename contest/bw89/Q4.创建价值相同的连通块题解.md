# LeetCode 创建价值相同的连通块 题解

## 1. 题目概述

- **标题 / 题号**：创建价值相同的连通块（#2440，hard）
- **链接**：https://leetcode.cn/problems/create-components-with-same-value/
- **来源**：LeetCode 第 89 场双周赛 Q4
- **难度**：困难
- **标签**：树、深度优先搜索、数组、数学、枚举

**题意**：给定一棵 $n$ 个节点的无向树（$0 \sim n-1$ 编号），节点 $i$ 的价值为 $\text{nums}[i]$。可以删除若干条边，把树分割成若干连通块，一个连通块的**价值**是其内所有节点价值之和。要求删除后**所有连通块价值相等**，求最多能删除多少条边。

**约束**：

- $1 \le n \le 2 \times 10^4$
- $1 \le \text{nums}[i] \le 50$
- `edges` 构成一棵合法树，边数恰为 $n - 1$

## 2. 示例

**示例 1**

```text
输入：nums = [6,2,2,2,6], edges = [[0,1],[1,2],[1,3],[3,4]]
输出：2
解释：删 [0,1] 和 [3,4]，得到连通块 [0]、[1,2,3]、[4]，
      价值分别为 6、6、6。不存在删除更多边的方案。
```

**示例 2**

```text
输入：nums = [2], edges = []
输出：0
解释：没有边可删。
```

**补充：全等值链**

```text
输入：nums = [3,3,3], edges = [[0,1],[1,2]]
输出：2
解释：三条边全删，得到 3 个价值为 3 的单点连通块——块数最多恰等于 n。
```

## 3. 解题思路

### 3.1 暴力思路

枚举边集的所有 $2^{n-1}$ 个子集，对每个子集用并查集求出连通块并检查各块价值是否相等，取删除边数最多的可行方案——$O(2^{n-1} \cdot n)$，$n$ 稍大即爆炸，只能当对拍工具（本文就用它做小规模验证）。方向性观察：若最终分成 $c$ 个连通块，每块价值相等且总和为 $S = \sum \text{nums}$，则每块价值 $= S/c$，**$c$ 必须整除 $S$**——可行 $c$ 只有 $S$ 的因子，这把搜索空间压缩到 $O(d(S))$ 个候选。

### 3.2 核心观察：候选删边 = 子树和是 target 整倍数的边

![核心观察：以 0 为根，删边对应「子树和 ≡ 0 (mod target)」](images/bw89_q4_tree_cut_model.svg)

把树以节点 $0$ 为根定向。若目标分成 $c$ 块、每块价值 $t = S/c$，删除一条边 $(u, \text{parent}(u))$ 后，$u$ 一侧成为一个独立连通块的最高节点。关键性质是：**每条被删的边 $(u, p)$ 都满足 subtree$(u) \equiv 0 \pmod t$**（§5 引理 1 的核心）。反过来，把**所有**满足该条件的边全删掉，得到的每个连通块价值都是 $t$ 的整倍数——这些「候选边」天然自带上限，数目不可能超过 $c - 1$（§5 引理 2）。于是判定「能否分成 $c$ 块」只需要数一数：

$$K_c = \#\{\,u \ne \text{root} : \text{subtree}(u) \bmod t = 0\,\} \stackrel{?}{=} c - 1$$

子树和只需求**一次** DFS，之后每个因子做一遍 $O(n)$ 的计数即可。

### 3.3 算法流程

![算法流程：求子树和 → 枚举因子 → 计数判定](images/bw89_q4_divisor_flow.svg)

```text
1. 建邻接表，以 0 为根迭代 DFS，得到 order（父先于子）与 parent
2. 按 order 逆序累加，得到每个点的子树和 sum[u]，S = sum[0]
3. mx = max(nums)（剪枝下界）
4. for c = n downto 1:              # 块数从大到小，先找到的删边最多
       若 S % c != 0：跳过
       t = S / c
       若 t < mx：跳过              # 含最大点的块价值不可能小于 mx
       K = #{ u ≠ root : sum[u] % t == 0 }
       若 K == c - 1：返回 c - 1
5. 返回 0（c = 1 恒可行，兜底）
```

### 3.4 示例演算

![示例 1：子树和与因子判定演算](images/bw89_q4_example_walkthrough.svg)

示例 1 的树以 0 为根（0−1，1−2，1−3，3−4），子树和为 `sum[4]=6, sum[3]=8, sum[2]=2, sum[1]=12, sum[0]=18`，$S = 18$。因子 $c$ 从 5 到 1 试探（要求 $c \mid 18$）：

| $c$ | $t = S/c$ | 候选子树（$\text{sum} \bmod t = 0$，非根） | $K$ | $K = c-1$？ |
|-----|----------|------------------------------------------|-----|------------|
| 5, 4 | — | 18 不整除 | — | 跳过 |
| 3 | 6 | 节点 1（12）、节点 4（6） | 2 | ✔，返回 2 |
| 2 | 9 | 节点 1（12 ≢ 0）…… 实际无 | 0 | ✘ |

$c = 3$ 时 $K = 2 = c - 1$，删边方案即「删全部候选边」：(1,0) 与 (4,3)，得到 `[0]`、`[1,2,3]`、`[4]` 三块价值全 6。答案 2。若 $c$ 更小（$K = 0 < c-1$）或更大（候选不足）都不可行，$c$ 从大到小首个命中即最大删边数。

## 4. 算法细节

1. **以 0 为根、迭代 DFS**：链状树深度可达 $2 \times 10^4$，C++/Python 递归都可能栈溢出（Python 默认递归上限 1000），用显式栈先序遍历得 `order`（父先于子），再按 `order` **逆序**累加子树和——等价于后序回累，全程无递归。
2. **只求一次子树和**：所有因子的判定共用同一份 `sum`，复杂度 $O(n \cdot d(S))$；$S \le 2 \times 10^4 \times 50 = 10^6$，因子数 $d(S) \le 240$，总量 $\le 5 \times 10^6$ 次取模。
3. **剪枝 $t \ge \text{max(nums)}$**：价值 $t$ 的连通块必须装得下最大的单点价值；$t < \text{max}$ 直接判不可行，省掉计数循环。
4. **$c$ 从大到小、首中即返**：可行性关于 $c$ **不单调**（块多块少各有各的难处），不能二分；但答案 $= c - 1$ 随 $c$ 递增，从 $n$ 往下试到的第一个可行 $c$ 就是最大删边数。
5. **`parent[0] = 0` 哨兵**：防止根被当成未访问而重复入栈；计数循环 `for i in 1..n-1` 用 `order[i]` 跳过根（根没有父边）。
6. **等价的「贪心切」写法**：官方题解常用 DFS 返回「减去已切子树后的子树和」，整除即切一刀并计数。它与本实现等价：贪心版本切掉的恰是所有候选边（被切走的子块价值都是 $t$ 的倍数，剩余部分模 $t$ 不变，§5 引理 1 同样适用）。数「原始子树和整除」的写法省去了带模 DFS，更不易写错。

## 5. 正确性证明

**引理 1（删边的必要条件）**：把树分割成若干价值均为 $t$ 的连通块的任一方案中，每条被删的边 $(u, p(u))$ 都满足 subtree$(u) \equiv 0 \pmod t$（subtree 指以 $u$ 为根的原始子树和）。

**证明**：删边 $(u, p(u))$ 后，含 $u$ 的连通块 $C(u)$ 以 $u$ 为最高节点，其价值为 $t$。$C(u)$ 等于子树 $u$ 挖去其中被「悬挂切断」的若干完整连通块，而这些连通块都是该分割方案中的块，价值均为 $t$。于是 subtree$(u) = t + k \cdot t = (k+1) t \equiv 0 \pmod t$（$k \ge 0$ 为嵌套块数）。∎

**引理 2（删全部候选边的结构与上界）**：令 $K = \#\{u \ne \text{root} : \text{subtree}(u) \equiv 0 \pmod t\}$。把全部 $K$ 条候选边删掉后，得到 $K + 1$ 个连通块，每块价值都是 $t$ 的正整倍数；从而 $K + 1 \le c$（$c = S/t$ 为目标块数）。

**证明**：对每个连通块（设其最高节点为 $u$；根块的最高节点为 root），块价值 = subtree$(u) - \sum_{\text{嵌套候选 } w} \text{subtree}(w)$：每个被挖去的候选子树 $w$ 的 subtree$(w) \equiv 0 \pmod t$，且这些子树两两不交、并集恰为块内被切走的部分。被减数与每个减数都是 $t$ 的倍数，故块价值 $\equiv 0 \pmod t$；又节点价值 $\ge 1$，块价值 $> 0$，故每块价值 $\ge t$。$K+1$ 个块总和为 $S = c \cdot t$，于是 $(K+1) \cdot t \le c \cdot t$，即 $K \le c - 1$。（根块同理由 $S - \sum$ 全为 $t$ 的倍数得出。）∎

**定理（判定与答案）**：存在把树分成 $c$ 块（每块价值 $t = S/c$）的删边方案，当且仅当 $K = c - 1$；答案为 $\max\{c - 1 : c \mid S,\ K_c = c - 1\}$。

**证明**：（⇐）若 $K = c - 1$，由引理 2，删全部候选边得 $K + 1 = c$ 个块，每块价值 $\ge t$、总和恰 $c \cdot t$，故每块价值恰为 $t$，方案成立。（⇒）若存在方案，由引理 1 其 $c - 1$ 条删边全是候选边，故候选边总数 $K \ge c - 1$；又由引理 2 恒有 $K \le c - 1$，故 $K = c - 1$。两部分合并即判定条件。答案取所有可行 $c$ 中最大者对应 $c - 1$，因为可行 $c$ 的上界受 $K \le c - 1$ 约束、且 $c = 1$ 恒可行（$K = 0$，不删边），集合非空。∎

> ⚠️ 注意引理 2 的上界方向：候选边**不会**多到超过 $c-1$，这是「价值全为正 + 全是 $t$ 的倍数 + 总和固定」三者合力的结果——负价值或 0 价值都会破坏该论证。

## 6. 复杂度分析

- **时间**：$O(n \cdot d(S))$。建图 + 迭代 DFS + 子树和 $O(n)$；每个 $S$ 的因子一遍 $O(n)$ 计数，$S \le 10^6$ 使 $d(S) \le 240$，总计 $\le 5 \times 10^6$ 次整除判断；剪枝会进一步砍掉 $t < \text{max}$ 的因子。$n = 2 \times 10^4$ 链状极端数据 C++/Python 均 $< 0.1$ s。
- **空间**：$O(n)$。邻接表、`order`、`parent`、`sum` 各一个长度 $n$ 的数组。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int componentValue(vector<int>& nums, vector<vector<int>>& edges) {
        int n = (int)nums.size();
        vector<vector<int>> g(n);
        for (auto& e : edges) {
            g[e[0]].push_back(e[1]);
            g[e[1]].push_back(e[0]);
        }
        vector<int> parent(n, -1), order, stk = {0};
        order.reserve(n);
        parent[0] = 0;
        while (!stk.empty()) {                     // 迭代 DFS：得到父先于子的顺序
            int u = stk.back(); stk.pop_back();
            order.push_back(u);
            for (int v : g[u]) if (parent[v] == -1) {
                parent[v] = u;
                stk.push_back(v);
            }
        }
        vector<long long> sum(nums.begin(), nums.end());
        for (int i = n - 1; i >= 1; --i)           // 逆序累加：子树和先就位
            sum[parent[order[i]]] += sum[order[i]];
        long long S = 0;
        for (int x : nums) S += x;
        int mx = *max_element(nums.begin(), nums.end());
        for (int d = n; d >= 1; --d) {             // d = 连通块个数，从大到小
            if (S % d) continue;
            long long target = S / d;              // 每块的价值
            if (target < mx) continue;              // 某块含最大点，值不可能更大
            int cnt = 0;                           // 子树和恰为 target 整倍数的非根子树数
            for (int i = 1; i < n; ++i)
                if (sum[order[i]] % target == 0) ++cnt;
            if (cnt == d - 1) return d - 1;        // 删 d-1 条边，块数恰为 d
        }
        return 0;
    }
};
```

### Python

```python
class Solution:
    def componentValue(self, nums: list, edges: list) -> int:
        n = len(nums)
        g = [[] for _ in range(n)]
        for a, b in edges:
            g[a].append(b)
            g[b].append(a)
        parent = [-1] * n
        parent[0] = 0
        order, stk = [], [0]
        while stk:                                  # 迭代 DFS：父先于子
            u = stk.pop()
            order.append(u)
            for v in g[u]:
                if parent[v] == -1:
                    parent[v] = u
                    stk.append(v)
        total = list(nums)
        for i in range(n - 1, 0, -1):               # 逆序累加子树和
            total[parent[order[i]]] += total[order[i]]
        S, mx = total[0], max(nums)
        for d in range(n, 0, -1):                   # d = 连通块个数，从大到小
            if S % d or S // d < mx:
                continue
            target = S // d                         # 每块的价值
            cnt = sum(1 for i in range(1, n) if total[order[i]] % target == 0)
            if cnt == d - 1:
                return d - 1
        return 0
```

> 💡 两份代码均通过官方示例（`2`、`0`），并与「枚举全部 $2^{n-1}$ 个边子集 + 并查集检查」的暴力在 3600 组随机树（$n \le 11$，含链、星两类构造）上逐组一致；$n = 2 \times 10^4$ 的链与全 1 极端数据下 C++ 均约 0.06 s。

## 8. 边界情况与易错点

1. **$n = 1$**：无边可删，$c = 1$ 的循环里计数为空、$K = 0 = c - 1$ 成立，返回 0；不要特判时漏掉「读入零条边」。
2. **链深栈溢出**：递归 DFS 在 $2 \times 10^4$ 深的链上会爆栈（Python 尤甚），务必迭代化或提前 `setrecursionlimit` 并改造为显式栈。
3. **可行性不单调**：不能对 $c$ 二分。例如 `nums = [1,1,1,2]`，$c=4$ 不可行而 $c=2$ 可行；反例方向同样存在，逐因子判定才稳。
4. **$K$ 与 $c-1$ 的相等关系**：写成 `K >= d-1` 虽因引理 2 的上界而等价，但会把「候选边恰多一条、恰好不可行」的边界情形掩盖；理解引理 1 的必要条件后再写 `==`，语义最清晰。
5. **根不能算候选**：根没有父边，`subtree(root) = S` 恒整除 $t$，计数循环必须跳过 `order[0]`（`for i in 1..n-1`）。
6. **求和溢出**：$S \le 10^6$、子树和同阶，`int` 够用；C++ 参考代码用 `long long` 保险。若把 $\text{nums}[i]$ 范围看成 $10^9$ 量级会误判溢出方向。
7. **整除判断的对象**：先判 $S \bmod c$ 再算 $t = S/c$，两者顺序颠倒会在 $c \nmid S$ 时产生非整数目标，白白多算一遍。
