# LeetCode 有效时间的数目 题解

## 1. 题目概述

- **标题 / 题号**：有效时间的数目（#2437，easy）
- **链接**：https://leetcode.cn/problems/number-of-valid-clock-times/
- **来源**：LeetCode 第 89 场双周赛 Q1
- **难度**：简单
- **标签**：字符串、枚举

**题意**：给定长度为 5 的字符串 `time`，格式 `"hh:mm"`，表示电子时钟时间。其中某些数位被 `?` 替换，每个 `?` 可以换成 $0 \sim 9$ 中任意一个数字。合法时间要求 $00 \le hh \le 23$、$00 \le mm \le 59$。求把所有 `?` 替换完后能得到的**合法时间的数目**。

**约束**：

- `time` 长度为 5，格式保证为 `"hh:mm"`（含冒号）
- 替换前的固定数位构成合法时间片段（题面保证 `00 <= hh <= 23`、`00 <= mm <= 59`）
- 只有数位位置可能是 `?`，冒号位置固定

## 2. 示例

**示例 1**

```text
输入：time = "?5:00"
输出：2
解释：? 可以替换成 0 或 1，得到 "05:00" 或 "15:00"；
      替换成 2 得到 "25:00" 不是合法时间。共 2 种。
```

**示例 2**

```text
输入：time = "0?:0?"
输出：100
解释：两个 ? 各有 10 种选择，共 10 × 10 = 100 种。
```

**示例 3**

```text
输入：time = "??:??"
输出：1440
解释：小时 24 种选择，分钟 60 种选择，共 24 × 60 = 1440 种
      （恰好等于一天的总分钟数）。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的做法：枚举全部 $24 \times 60 = 1440$ 个合法时间，逐一检查它是否与 `time` 的模式匹配（`?` 可匹配任意数字，其余字符必须相等），统计匹配数。单次询问 $O(1440)$，正确性显然。更进一步，小时与分钟本来就是独立的两段，可以拆成 $O(24) + O(60)$。本题数据只有一个字符串，暴力完全够用；但既然小时、分钟互不干扰，还能一步到位写成 $O(1)$ 的**分位计数**。

### 3.2 核心观察：小时与分钟独立，乘法原理合并

![核心观察：小时与分钟独立，乘法原理合并](images/bw89_q1_split_positions.svg)

合法时间的要求可以拆成两条互不影响的规则：小时段 `hh` 落在 $[0, 23]$、分钟段 `mm` 落在 $[0, 59]$。`?` 的替换也只在各自段内进行，因此：

$$\text{答案} = (\text{小时段的合法填法数}) \times (\text{分钟段的合法填法数})$$

这就是**乘法原理**。每一段只有两位数字，`?` 的分布只有「两位都是 / 只有十位是 / 只有个位是 / 都不是」四种组合，分别数一下合法值个数即可，全程 $O(1)$。

### 3.3 分位计数的四种情形

![小时位四种情形的计数表](images/bw89_q1_case_table.svg)

以小时段 `a?b`（`a` 为十位、`b` 为个位）为例：

| 十位 `a` | 个位 `b` | 合法小时数 | 说明 |
|----------|----------|-----------|------|
| `?` | `?` | 24 | $00 \sim 23$ 全部可选 |
| `?` | 数字 $d$ | $d \le 3$ 时 3，否则 2 | 个位 $\le 3$ 时十位可取 0/1/2，否则只能 0/1 |
| 数字 | `?` | `0`/`1` 时 10，`2` 时 4 | `00..19` 全合法，`20..23` 只有 4 个 |
| 数字 | 数字 | 1（题面保证合法） | 本身即是 |

分钟段更宽松：个位 $0 \sim 9$ 全部合法，约束只在十位 $\le 5$，同理可列一张小表（见 §4）。

### 3.4 示例演算

![三个示例的分位计数演算](images/bw89_q1_example_walkthrough.svg)

| 输入 | 小时段计数 | 分钟段计数 | 答案 |
|------|-----------|-----------|------|
| `?5:00` | `?5` → 个位 5 > 3，十位取 0/1 → 2 | `00` → 1 | $2 \times 1 = 2$ |
| `0?:0?` | `0?` → 十位 0，个位任意 → 10 | `0?` → 十位 0 ≤ 5，个位任意 → 10 | $10 \times 10 = 100$ |
| `??:??` | `??` → 24 | `??` → 60 | $24 \times 60 = 1440$ |

## 4. 算法细节

1. **分段**：`time[0]`、`time[1]` 是小时的两位，`time[3]`、`time[4]` 是分钟的两位，`time[2]` 恒为 `:`，无需处理。
2. **小时计数** `countHour(a, b)`：
   - 双 `?`：直接返回 24。
   - 仅十位 `?`：个位 $b \le 3$ 时十位可取 0/1/2（如 `?3` → 03,13,23），否则只能取 0/1（如 `?5` → 05,15）。
   - 仅个位 `?`：十位 `0`/`1` 时个位 10 种；十位 `2` 时只有 20~23 共 4 种；十位 $\ge 3$ 无解（题面保证不会出现）。
   - 双数字：本身合法返回 1。
3. **分钟计数** `countMinute(a, b)`：
   - 双 `?`：60。仅十位 `?`：个位任意合法，十位可取 0~5，共 6。仅个位 `?`：十位 $\le 5$ 时 10 种，否则 0。双数字：十位 $\le 5$ 返回 1。
4. **防御式返回 0**：虽然题面保证输入是合法模式，`countHour` 对「十位 $\ge 3$ 且个位是 `?`」这类非法组合仍返回 0，使函数在任意输入上都有定义，便于对拍验证。
5. **乘法合并**：两段计数相乘即答案，用 `int` 即可（最大 1440）。

## 5. 正确性证明

**引理 1（独立性）**：一个替换方案合法，当且仅当小时段替换后的数值 $\le 23$ 且分钟段替换后的数值 $\le 59$；两个条件分别只依赖各自段的替换。

**证明**：合法时间的定义即「$00 \le hh \le 23$ 且 $00 \le mm \le 59$」，`hh` 的取值只由 `time[0]`、`time[1]` 上的替换决定，`mm` 只由 `time[3]`、`time[4]` 决定，两组替换变量不相交，故条件相互独立。∎

**引理 2（计数公式的正确性）**：`countHour(a, b)` 返回集合 $\{h \in [0, 23] : h$ 的两位十进制表示与模式 `a?b` 匹配$\}$ 的大小；`countMinute` 同理对 $[0, 59]$。

**证明**：逐一核对四种情形。小时段：① 双 `?` 匹配所有 24 个值；② 十位 `?`、个位 $d$：匹配的 $h$ 形如 $\overline{xd}$，$x \in \{0,1,2\}$ 且 $10x + d \le 23$，当 $d \le 3$ 时 $x$ 三个都合法（$23 + d \le 26$ 中最大 $23 \le 23$ 当 $d \le 3$，即 $2d \le 3$ 时 $x=2$ 合法），当 $d \ge 4$ 时 $x = 2$ 给出 $24 + d - d > 23$ 不合法，只剩 $x \in \{0,1\}$；③ 十位数字 $c$、个位 `?`：$c = 0,1$ 时 $c0 \sim c9$ 全部 $\le 19 \le 23$ 共 10 个，$c = 2$ 时仅 $20 \sim 23$ 共 4 个，$c \ge 3$ 时最小值 $c0 \ge 30 > 23$ 无解；④ 双数字：至多匹配一个值，存在当且仅当其 $\le 23$。分钟段：个位无约束，仅需 $10a + b \le 59$ 即 $a \le 5$，四种情形同理可验。∎

**定理**：`countHour(time[0], time[1]) × countMinute(time[3], time[4])` 等于合法替换方案的数目。

**证明**：合法替换方案 = （小时段的合法填法）×（分钟段的合法填法），由引理 1，二者独立的笛卡尔积一一对应于完整方案；每个因子的大小由引理 2 给出。∎

## 6. 复杂度分析

- **时间**：$O(1)$。只对 4 个字符做常数次比较与分支，没有任何循环。
- **空间**：$O(1)$。不随输入规模增长（输入本身固定长度 5）。

> 💡 若采用 §3.1 的枚举写法（枚举 $0 \sim 23$ 与 $0 \sim 59$ 再匹配模式），时间为 $O(24 + 60)$，同样是常数级，且更不易写错分支——两种写法都可通过全部数据。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int countTime(string time) {
        return countHour(time[0], time[1]) * countMinute(time[3], time[4]);
    }
private:
    // 统计模式 a?b 下 0..23 中合法的小时数
    int countHour(char a, char b) {
        if (a == '?' && b == '?') return 24;
        if (a == '?') return b <= '3' ? 3 : 2;            // 十位可取 0/1/2 或 0/1
        if (b == '?') {                                    // 十位已确定
            if (a <= '1') return 10;                       // 00..19 全部合法
            if (a == '2') return 4;                         // 20..23
            return 0;
        }
        return (a - '0') * 10 + (b - '0') <= 23 ? 1 : 0;   // 无 '?'，本身是否合法
    }
    // 统计模式 a?b 下 0..59 中合法的分钟数
    int countMinute(char a, char b) {
        if (a == '?' && b == '?') return 60;
        if (a == '?') return 6;                             // 个位 0..9 均合法
        if (b == '?') return a <= '5' ? 10 : 0;
        return a <= '5' ? 1 : 0;
    }
};
```

### Python

```python
class Solution:
    def countTime(self, time: str) -> int:
        def count_hour(a: str, b: str) -> int:
            if a == '?' and b == '?':
                return 24
            if a == '?':
                return 3 if b <= '3' else 2      # 十位可取 0/1/2 或 0/1
            if b == '?':
                if a <= '1':
                    return 10                   # 00..19 全部合法
                return 4 if a == '2' else 0     # 20..23
            return 1 if int(a) * 10 + int(b) <= 23 else 0

        def count_minute(a: str, b: str) -> int:
            if a == '?' and b == '?':
                return 60
            if a == '?':
                return 6                        # 个位 0..9 均合法
            if b == '?':
                return 10 if a <= '5' else 0
            return 1 if a <= '5' else 0

        return count_hour(time[0], time[1]) * count_minute(time[3], time[4])
```

> 💡 两份代码均通过官方示例（`2`、`100`、`1440`），并对全部 $11^4 = 14641$ 种四位置模式（每位取 `?` 或数字）与「枚举 $24 \times 60$ 个时间逐位匹配」的暴力对拍一致。

## 8. 边界情况与易错点

1. **小时上界是不规则的 23**：`?5` 只有 2 种而不是 3 种（25 非法），`2?` 只有 4 种而不是 10 种。这是本题唯一容易数错的分支，建议单独列成表格核对。
2. **分钟上界 59 规则**：约束完全落在十位（$\le 5$），个位任意，不要把分钟也套用小时那套「个位 $\le 3$」的特殊分支。
3. **`??` 不要想当然**：小时 `??` 是 24 不是 100，分钟 `??` 是 60 不是 100；整串 `??:??` 恰为 1440。
4. **拆段下标**：分钟段是 `time[3]`、`time[4]`，冒号在 `time[2]`；把分钟写成 `time[2]` 起手的下标偏移是低级失误。
5. **乘法而非加法**：两段独立要相乘；写成相加会在 `??:??` 上得到 $24 + 60 = 84$，一测便知。
6. **防御非法输入**：分位计数函数对「十位 $\ge 6$ 的分钟」等非法模式返回 0，保证函数全域有定义，方便与暴力对拍。
