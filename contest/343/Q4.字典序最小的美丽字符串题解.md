# LeetCode 字典序最小的美丽字符串 题解

## 1. 题目概述

- **标题 / 题号**：字典序最小的美丽字符串（#2663，hard）
- **链接**：https://leetcode.cn/problems/lexicographically-smallest-beautiful-string/
- **来源**：LeetCode 第 343 场周赛 Q4
- **难度**：困难
- **标签**：贪心、字符串、构造

**题意**：如果一个字符串满足以下两个条件，则称其为**美丽字符串**：

1. 由英语小写字母表的**前 `k` 个**字母组成；
2. 不包含任何**长度为 2 或更长**的回文子字符串。

给定一个长度为 `n` 的美丽字符串 `s` 和正整数 `k`，返回一个长度为 `n` 的美丽字符串，满足：在**字典序大于 `s`** 的所有美丽字符串中**字典序最小**。若不存在这样的字符串，返回空字符串。

**约束**：

- $1 \le n = \text{s.length} \le 10^5$
- $4 \le k \le 26$
- `s` 保证是一个美丽字符串

> 📚 本题在本仓库另有[每日题解 2663](../../solution/2601-2700/2663_字典序最小的美丽字符串.md)：侧重局部观察的直觉推导与面试问答；本篇作为周赛复盘，补全「定位最右 + 贪心重填」的**引理-定理完整证明**（§5）、与「下一个排列」的赛时联想链和易错清单。

> 💡 两条关键信号：① 「无长度 ≥2 回文」是**全局条件**，但长回文的中心必藏短回文——它可被**两条局部规则**（$s[i] \ne s[i-1]$、$s[i] \ne s[i-2]$）等价替代，这是贪心逐位构造的前提；② 求字典序最小的更大串，本质是「下一个排列」骨架——**公共前缀尽可能长**，即从右往左找第一个能增大的位置。$k \ge 4$ 则保证贪心**永不卡死**。

## 2. 示例

**示例 1**

```text
输入：s = "abcz", k = 26
输出："abda"
解释："abda" 既是美丽字符串（无任何 ≥2 长度回文），又字典序大于 "abcz"。
      可以证明不存在同时满足「字典序大于 "abcz"」「美丽」「字典序小于 "abda"」的字符串。
```

**示例 2**

```text
输入：s = "dc", k = 4
输出：""
解释：k = 4 时字母表只有 a、b、c、d。
      位置 1 的 c 只能增大到 d，却与 s[0]='d' 构成长度 2 回文；
      位置 0 的 d 已是最大字母。不存在满足条件的字符串。
```

**示例 3**（自造，展示「增大字符不是 $s[i]+1$」的跳选情形）

```text
输入：s = "acbd", k = 4
输出："acda"
解释：从右往左：位置 3 的 d 已是最大，不能增大；
      位置 2 的 b 首先试 c，但 c 与前一位 s[1]='c' 构成长度 2 回文，跳过；
      试 d，d≠c 且 d≠a 合法 → 定位，s[2] 改为 d；
      位置 3 重填：a 满足 a≠d 且 a≠c → 填 a。
      输出 "acda" > "acbd"，且是满足条件的最小者。
```

## 3. 解题思路

### 3.1 暴力思路

**逐个生成候选**：按字典序递增地枚举长度为 $n$、字符集为前 $k$ 个字母的串，检查每个候选是否美丽、是否大于 $s$。候选总量 $k^n$（$n=10^5$ 时天文数字）；即使只从 $s$ 出发「按位进位」地生成下一个串并检查，单次检查就要 $O(n)$，且中间可能隔着的无效候选是指数级的。

**判定的浪费**也很大：检查「是否含长度 $\ge 2$ 回文」若按定义扫所有子串是 $O(n^2)$。两个暴力都死在**没有利用题目的结构**：

1. 「无回文」其实只需看**相邻与相隔一位**的字符（局部性）；
2. 「字典序最小的更大串」其实只需改**最右一个位置**，其余重置为最小（贪心性）。

### 3.2 核心观察：回文条件局部化 + 公共前缀最长

**观察一：无长度 ≥2 回文 ⟺ 相邻不同且相隔一位不同。**

![美丽条件的局部化：长回文中心必藏短回文](images/beautiful_string_palindrome_center.svg)

任何长度 $L \ge 4$ 的回文，其**中心**必含一个长度 2（$L$ 为偶）或长度 3（$L$ 为奇）的回文。于是「禁止一切长度 ≥2 的回文」等价于只禁止长度 2、3 的回文，即两条**逐位局部规则**：

$$s[i] \ne s[i-1] \quad (\text{禁 len2}), \qquad s[i] \ne s[i-2] \quad (\text{禁 len3})$$

每个位置的合法性只取决于**前两个字符**——这是逐位贪心构造的基石（引理 1 给出严格证明）。

**观察二：字典序最小的更大串 ⟺ 公共前缀最长。**

设 $t > s$，则 $t$ 与 $s$ 存在**首个不同位置** $i$：前缀相同且 $t[i] > s[i]$。两个候选相比，分叉位置越**靠右**，串的字典序越**小**（在 $t_1$ 的分叉位置上，分叉更靠右的 $t_2$ 仍等于 $s$，被 $t_1$ 的「增大」压过）。因此最优解的分叉位置应取**最右**的「可增大」位置 $j$——存在合法字符 $c > s[j]$（$c \ne s[j-1]$、$c \ne s[j-2]$）的位置。

**$k \ge 4$ 的角色**：定位时位置 $j$ 的候选区间 $(s[j],\, \text{`a'+}k)$ 内要排除前两个字符（至多 2 个禁忌值），重填时每格禁忌恰为前两个**互异**字符（前缀美丽 ⟹ 相邻不同），恒有 $k - 2 \ge 2$ 个可选——**贪心永不卡死**，这正是题目把 $k$ 下界设为 4 的原因。

### 3.3 算法流程

![算法流程：右扫定位 + 最小合法增大 + 后缀贪心重填](images/beautiful_string_greedy_flow.svg)

三步，与「下一个排列」骨架一一对应：

1. **右扫定位**：$i$ 从 $n-1$ 向 $0$ 扫，找**最右**的位置 $i$，使得存在字符 $c \in (s[i],\ \text{`a'+}k)$ 且 $c \ne s[i-1]$（若有）、$c \ne s[i-2]$（若有）。取**最小**的合法 $c$（从 $s[i]+1$ 起逐个试，首次命中即最小）；
2. **最小合法增大**：置 $s[i] \leftarrow c$。此时 $s[0..i]$ 仍是美丽前缀，且已大于原前缀；
3. **后缀贪心重填**：对 $j = i+1, \dots, n-1$，每格从 `a` 起逐个试，取首个满足 $d \ne s[j-1]$ 且 $d \ne s[j-2]$ 的字符。

若扫完所有位置都找不到，返回 `""`。

### 3.4 示例演算

![示例演算：abcz → abda 与 dc → 空串](images/beautiful_string_example_walkthrough.svg)

以 `s = "abcz", k = 26` 走查：

| 步 | 考察位置 | 尝试 | 合法性检查 | 结果 |
|----|----------|------|------------|------|
| 1 | $i=3$（`z`） | 更大字符 | `z` 已是前 26 个字母中最大 | ✗ 左移 |
| 2 | $i=2$（`c`） | `d` | $d \ne b$（前1）✓，$d \ne a$（前2）✓ | ✓ 定位，`c` 改 `d` |
| 3 | $j=3$ 重填 | `a` | $a \ne d$（前1）✓，$a \ne b$（前2）✓ | ✓ 填 `a` |

保留前缀 `"ab"` + 最小合法增大 `d` + 贪心重填 `a` = `"abda"`。

> 💡 留意步 2：`c` 的候选从 `d` 开始试且**首次命中即停**——不能「一步到位」改成 `z`，也不能在 `c+1` 撞禁忌时直接放弃该位置；示例 3（`acbd`）中 `b` 的首个候选 `c` 撞了前一位，跳到 `d` 才命中。右侧重填同理：每格从 `a` 试起，整体才最小。

## 4. 算法细节

1. **候选即试即得**：定位的内层循环从 $s[i]+1$ 递增、重填的内层循环从 `a` 递增，**第一次命中就是最小合法字符**，无需收集候选再取最小。
2. **增大位只查前两位**：前缀 $s[0..i-1]$ 原本美丽且未改动，增大 $s[i]$ 只可能新增长度 2（撞 $s[i-1]$）或长度 3（撞 $s[i-2]$）回文，故只查这两位；右侧 $s[i+1..]$ 随后被**整体重填**，填值时主动避开 $s[i]$，与右侧的冲突无需预查。
3. **`top = 'a' + k` 是开区间上界**：合法字符为 `'a'` 至 `'a'+k-1`，所有候选循环写 `c < top`。
4. **下标边界**：位置 0 没有前一位 / 前两位，位置 1 只有长度 2 约束，对应两个 `if (i >= 1)`、`if (i >= 2)` 守卫；$n = 1$ 时天然只剩「位置 0 直接增大」。
5. **原地修改**：C++ 直接改入参 `string`；Python 先 `list(s)` 再 `join`（字符串不可变）。
6. **无解即返回**：只要定位成功，后缀**必然**能填满（每格禁忌恰 2 个互异字符、可选 $k-2 \ge 2$ 个），不存在「定位成功却填不下去」的情形，无需任何回溯。

## 5. 正确性证明

**引理 1（回文条件局部化）**：字符串 $t$ 不含长度 $\ge 2$ 的回文子串，当且仅当对一切 $i \ge 1$ 有 $t[i] \ne t[i-1]$，且对一切 $i \ge 2$ 有 $t[i] \ne t[i-2]$。

**证明**：（⇐ 方向的逆否命题）设 $t$ 含有长度 $\ge 2$ 的回文子串，取**最短**者，长为 $L$，记为 $p_0 p_1 \cdots p_{L-1}$（$p_j = p_{L-1-j}$）。若 $L = 2$，则 $p_0 = p_1$ 违反第一条规则；若 $L = 3$，则 $p_0 = p_2$ 违反第二条规则；若 $L \ge 4$：
- $L$ 为偶数：中心两位 $p_{L/2-1} = p_{L/2}$，构成 $t$ 中长度为 2 的回文子串；
- $L$ 为奇数：中心三位 $p_{(L-3)/2} = p_{(L+1)/2}$，构成 $t$ 中长度为 3 的回文子串。

两种情形都与 $L$ 的最小性矛盾。故无长度 $\ge 2$ 回文的串必满足两条局部规则；反之两条规则直接排除了长度 2、3 的回文，再由上述「最短回文只能是 2 或 3」排除一切 $\ge 2$ 回文。∎

**引理 2（前缀越长，串越小）**：设 $t_1, t_2$ 均为长度 $n$ 的串且均 $> s$；$t_1$ 与 $s$ 的首个不同位置为 $i_1$（$t_1[i_1] > s[i_1]$），$t_2$ 与 $s$ 的首个不同位置为 $i_2$，且 $i_2 > i_1$。则 $t_2 < t_1$。

**证明**：因 $i_1 < i_2$，$t_2$ 在位置 $i_1$ 仍等于 $s[i_1]$，而 $t_1[i_1] > s[i_1]$，故 $t_2[i_1] < t_1[i_1]$；又 $t_1[0..i_1-1] = t_2[0..i_1-1] = s[0..i_1-1]$，即 $i_1$ 是 $t_1, t_2$ 的首个不同位置且此处 $t_2$ 更小，故 $t_2 < t_1$。∎

**引理 3（贪心重填可行且最小）**：设 $p[0..j]$ 是满足局部规则的美丽前缀。对 $i = j+1, \dots, n-1$，令 $g[i]$ 为满足 $d \ne p[i-1]$、$d \ne p[i-2]$ 的**最小**字符。则：

(a) 每个 $g[i]$ 存在（重填永不卡死）；
(b) $p[0..j]\,g[j+1..n-1]$ 是美丽串；
(c) 在所有以 $p[0..j]$ 为前缀的长度 $n$ 美丽串中，该串字典序最小。

**证明**：(a) 位置 $i$ 的禁忌为 $p[i-1], p[i-2]$ 两个**互异**字符（前缀满足 $p[i-1] \ne p[i-2]$），可选字符 $k - 2 \ge 2 > 0$ 个，最小者存在。
(b) 逐位验证引理 1 的两条规则：位置 $\le j$ 不变仍满足；位置 $i > j$ 的约束 $g[i] \ne p[i-1]$、$g[i] \ne p[i-2]$ 正是构造条件（此时 $p[0..i-1]$ 已是包含 $g$ 的合法前缀，归纳成立）。
(c) 设 $h$ 是任一以 $p[0..j]$ 为前缀的美丽串，$m$ 是 $g$ 与 $h$ 的首个不同位置（不存在则相等）。则 $m > j$ 且 $g[0..m-1] = h[0..m-1]$，故两者的禁忌集相同，$h[m]$ 是 $g[m]$ 位置的一个合法候选；而 $g[m]$ 取的是**最小**合法字符且 $g[m] \ne h[m]$，故 $g[m] < h[m]$，即 $g < h$。∎

**定理**：设 $j$ 为**最右**的可增大位置（存在合法字符 $c > s[j]$ 且 $c \ne s[j-1], c \ne s[j-2]$；不存在则算法返回空串）。算法输出 $ans = s[0..j-1] + c^* + g[j+1..n-1]$（$c^*$ 为最小合法增大字符，$g$ 为贪心重填）是字典序大于 $s$ 的**最小**美丽串；算法返回空串当且仅当不存在这样的串。

**证明**：**合法性**：$s[0..j-1]$ 美丽且未改动；$c^*$ 避开 $s[j-1], s[j-2]$，由引理 1 该前缀满足局部规则；再由引理 3(b)，$ans$ 整体美丽。**大于 $s$**：前缀相同且 $c^* > s[j]$。
**最小性**：任取美丽串 $t > s$，设 $t$ 与 $s$ 首个不同位置为 $i$（$t[i] > s[i]$）。由 $t$ 美丽（引理 1），$t[i] \ne s[i-1], t[i] \ne s[i-2]$，故 $i$ 是可增大位置，$i \le j$。
- 若 $i < j$：$ans[0..i-1] = t[0..i-1] = s[0..i-1]$ 且 $ans[i] = s[i] < t[i]$，故 $ans < t$。
- 若 $i = j$：$t[j]$ 是合法增大字符，而 $c^*$ 是最小合法增大字符，$c^* \le t[j]$。若 $c^* < t[j]$，则 $ans < t$；若 $c^* = t[j]$，则 $t$ 与 $ans$ 共享前缀 $s[0..j-1] + c^*$，由引理 3(c)，$ans$ 的后缀 $\le t$ 的后缀，故 $ans \le t$。

即对一切 $t > s$ 的美丽串有 $ans \le t$，$ans$ 最小。
**无解判定**：若算法返回空串而存在 $t > s$ 的美丽串，则 $t$ 的首个不同位置可增大，算法应已定位成功，矛盾；故返回空串当且仅当无解。∎

## 6. 复杂度分析

- **时间复杂度**：$O(nk)$，$k \le 26$ 时即 $O(26\,n)$。定位扫描每个位置至多试 $k$ 个候选字符；后缀重填每格禁忌只有 2 个互异字符，`a`、`b`、`c` 三个候选中必有其一合法，故每格**至多试 3 次**，重填整体 $\le 3n$。对 $n = 10^5$ 约几百万次字符比较，瞬时通过。
- **空间复杂度**：$O(n)$。C++ 原地修改入参 `string`；Python 显式 `list(s)` 转换。除返回串外无额外结构。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    string smallestBeautifulString(string s, int k) {
        int n = s.size();
        char top = 'a' + k;                     // 合法字符上界（开区间）：'a' .. 'a'+k-1
        for (int i = n - 1; i >= 0; --i) {      // ① 右扫定位：最右的可增大位置
            for (char c = s[i] + 1; c < top; ++c) {
                if (i >= 1 && c == s[i - 1]) continue;   // 禁 len2 回文
                if (i >= 2 && c == s[i - 2]) continue;   // 禁 len3 回文
                s[i] = c;                               // ② 最小合法增大字符
                for (int j = i + 1; j < n; ++j) {       // ③ 后缀贪心重填
                    for (char d = 'a'; d < top; ++d) {
                        if (j >= 1 && d == s[j - 1]) continue;
                        if (j >= 2 && d == s[j - 2]) continue;
                        s[j] = d;
                        break;
                    }
                }
                return s;
            }
        }
        return "";   // 每个位置都无法增大：s 已是字典序最大的美丽串
    }
};
```

### Python

```python
class Solution:
    def smallestBeautifulString(self, s: str, k: int) -> str:
        n = len(s)
        top = ord('a') + k                  # 合法字符上界（开区间）
        s = list(s)
        for i in range(n - 1, -1, -1):      # ① 右扫定位：最右的可增大位置
            for c in range(ord(s[i]) + 1, top):
                if i >= 1 and c == ord(s[i - 1]):
                    continue                # 禁 len2 回文
                if i >= 2 and c == ord(s[i - 2]):
                    continue                # 禁 len3 回文
                s[i] = chr(c)               # ② 最小合法增大字符
                for j in range(i + 1, n):   # ③ 后缀贪心重填
                    for d in range(ord('a'), top):
                        if j >= 1 and d == ord(s[j - 1]):
                            continue
                        if j >= 2 and d == ord(s[j - 2]):
                            continue
                        s[j] = chr(d)
                        break
                return ''.join(s)
        return ""
```

## 8. 边界情况与易错点

1. **误以为定位成功后还要回溯**：只要 $k \ge 4$，后缀重填**永不卡死**（禁忌恰 2 个互异字符），不需要任何「填不动就换位置」的回溯逻辑。
2. **增大字符 $\ne s[i]+1$**：候选从 $s[i]+1$ 起逐个试、跳过撞前两位的（示例 3：`b` 的候选 `c` 撞前一位，跳到 `d`）。两个常见 bug：撞禁忌后直接判定该位置不可增大、或直接跳到 $k-1$ 的最大字符。
3. **后缀必须从 `a` 整体重置**：增大位右侧不能「保留原字符试着加点什么」——分叉之后右侧任何字符都合法候选，字典序最小要求逐格从 `a` 贪心取。
4. **只查前两位，不要全局检查回文**：每步改动后重扫整串找回文会把复杂度拉到 $O(n^2)$ 超时；由引理 1，两条 $O(1)$ 局部规则完全等价。
5. **`i >= 1` / `i >= 2` 边界守卫**：位置 0 无任何约束（$n=1$ 时退化为「直接增大首字符」，如 `k>1` 时 `a`→`b`）、位置 1 只有长度 2 约束。漏写守卫会越界，写反则漏判。
6. **`top = 'a' + k` 是开区间**：合法字符是 `'a'` 到 `'a'+k-1`，循环条件 `c < top`；误写成 `c <= top` 会引入第 $k+1$ 个非法字母。
7. **无解的典型形态**：输入串已是该 $k$ 下「字典序最大的美丽串」（如 `dc`、`k=4`）。无解时返回**空字符串**，不要返回 `s` 或 `"-1"`。
8. **题目保证 $k \ge 4$**：赛时不要花时间特判 $k < 4$；但要理解若 $k = 3$，重填每格仅剩 1 个可选（仍能填但「最小」受限），若 $k < 3$ 贪心可能真正死锁。
9. **Python 字符串不可变**：先 `list(s)`，逐位用 `ord`/`chr` 比较，最后 `join`；直接下标赋值会报错。
10. **别把「子串」当「子序列」**：禁止的是回文**子串**（连续）；若误读成子序列，「无长度 2 回文子序列」等价于「所有字符互异」，问题会完全变味。

**延伸思考**：

- **只禁止奇数长回文会怎样？** 奇回文的中心必含长度 3 回文，条件退化为单条局部规则 $s[i] \ne s[i-2]$（相邻可以相等），贪心框架原样适用，每格禁忌只剩 1 个字符。
- **改成求字典序**最大的美丽串（要求小于 $s$）：对称地把「增大」换「减小」、重填从 `'a'+k-1` 倒序贪心即可。
- **$k = 3$ 的边界行为**：重填每格禁忌 2 个互异字符后仅剩 1 个可选，贪心仍可执行但无自由度；定位时要求 $(s[i],\ \text{`a'+}k)$ 内避开 2 个禁忌，更容易走到无解——算法本身无需修改。
