# LeetCode 找出叠涂元素 题解

## 1. 题目概述

- **标题 / 题号**：找出叠涂元素（#2661，medium）
- **链接**：https://leetcode.cn/problems/first-completely-painted-row-or-column/
- **来源**：LeetCode 第 343 场周赛 Q2
- **难度**：中等
- **标签**：数组、哈希表、矩阵

**题意**：给定下标从 0 开始的整数数组 `arr` 与 $m \times n$ 整数矩阵 `mat`，二者都**恰好**包含 $[1, m \times n]$ 内的全部整数各一次（互为排列）。从 $i = 0$ 起依次把 `mat` 中等于 `arr[i]` 的格子涂色，找出**第一个**使 `mat` 的某一行或某一列**全部涂色**的元素，返回其下标 $i$。

**约束**：

- $m = \text{mat.length}$，$n = \text{mat}[i].\text{length}$，$\text{arr.length} = m \times n$
- $1 \le m, n \le 10^5$，$1 \le m \times n \le 10^5$
- $1 \le \text{arr}[i], \text{mat}[r][c] \le m \times n$
- `arr` 中整数互不相同；`mat` 中整数互不相同

> 📚 本题在本仓库另有[每日题解 2661](../../solution/2601-2700/2661_找出叠涂元素.md)：主解为「位置预处理 + 行列计数」的增量视角，含两种解法完整对比与面试问答；本篇作为周赛复盘走另一条等价路径——「反向索引 + 完成时刻」的整体视角，并给出两种写法的赛时取舍。

> 💡 两条关键信号：**值域稠密**——`arr` 与 `mat` 都恰是 $[1, m \times n]$ 的排列，故「值 → 时刻」「值 → 坐标」都能用数组 $O(1)$ 寻址，题目把哈希表的活儿送成了数组下标；**「首个满足」型目标**——既可增量模拟「边涂边判」，也可整体倒推「先算出每条线的完成时刻，再取最小」。两条路都是 $O(mn)$，赛时选写得最顺的那条。

输出：2

      i=2 涂 4 于 (0,1)，此时第一行 {1,4} 与第二列 {3,4} 同时涂满，返回 2。
```

输出：3

      i=3 涂 4 于 (1,1)，第二列 {2,7,4} 全部涂色，返回 3。
```

## 3. 解题思路

### 3.1 暴力思路：逐步涂色、逐步判满

朴素做法：先遍历 `mat` 建 `pos[v] = (r, c)`（否则每步还要在矩阵里搜值），再模拟涂色；每涂一格后扫描所在行 $r$（$O(n)$）与所在列 $c$（$O(m)$）是否全涂，整体 $O(mn \cdot (m+n))$。$m = 10^5, n = 1$ 时 $m + n \approx 10^5$，总量约 $10^{10}$，**超时**。

> ⚠️ 两处浪费：一是「判满」重扫整行整列——其实只需计数；二是逐格模拟——「每条线**何时**涂满」其实可以由 `arr` **整体倒推**，不必一格一格走。本篇走「整体倒推」这条路，「计数」路线见 §4 的对照写法。

### 3.2 核心观察：行列的「完成时刻」——瓶颈最大值

换个方向想：不模拟涂色过程，而是对每条线（行或列）**直接算出它被涂满的确切时刻**。

- **值 $v$ 的涂色时刻**就是 $v$ 在 `arr` 中的下标，记 $\mathrm{idx}[v]$——一遍扫 `arr` 即得；
- **行 $r$ 的完成时刻** $T_r = \max_c \mathrm{idx}[\mathrm{mat}[r][c]]$：一行涂满 $\iff$ 它的**最后一格**被涂上 $\iff$ 行内最大时刻到达，列同理；
- **答案** $= \min(\text{所有 } m+n \text{ 条线的完成时刻})$：首个涂满的线，就是完成时刻最小的那条。

![核心观察：一条线的完成时刻 = 线内各格涂色时刻的最大值](images/first_paint_completion_concept.svg)

> 💡 $\max$ 刻画「线内瓶颈」（等最晚的那一格），$\min$ 选「最早完成的线」，min 套 max 的嵌套是「瓶颈—择优」的经典结构。答案天然存在：涂完最后一格时全矩阵涂满，至少有一条线完成，故 $\min$ 必落在 $[0, mn-1]$ 内，**无需哨兵返回值**。

### 3.3 算法流程：反向索引三步走

![算法流程：反向索引三步走，min 套 max](images/first_paint_algo_flow.svg)

1. 扫 `arr` 一遍，建表 $\mathrm{idx}[\text{arr}[i]] = i$（值 → 涂色时刻）；
2. 逐行扫 `mat`：行内累积 $\max$ 得该行完成时刻 `cur`，`ans = min(ans, cur)`；
3. 逐列扫 `mat`：与步骤 2 同构，只换循环方向；
4. 返回 `ans`。

### 3.4 示例演算

以**示例 2** 走查：`arr = [2,8,7,4,1,3,5,6,9]`，`mat = [[3,2,5],[1,4,6],[8,7,9]]`（$m = n = 3$）。预处理得 $\mathrm{idx}$：$2 \to 0$、$8 \to 1$、$7 \to 2$、$4 \to 3$、$1 \to 4$、$3 \to 5$、$5 \to 6$、$6 \to 7$、$9 \to 8$。

![示例演算：第二列在 i=3 率先涂满](images/first_paint_example_walkthrough.svg)

| 线 | 组成（值 → 时刻） | 完成时刻 = max |
|----|------------------|:---:|
| 行 0 | 3→5，2→0，5→6 | 6 |
| 行 1 | 1→4，4→3，6→7 | 7 |
| 行 2 | 8→1，7→2，9→8 | 8 |
| 列 0 | 3→5，1→4，8→1 | 5 |
| 列 1 | 2→0，4→3，7→2 | **3** ★ |
| 列 2 | 5→6，6→7，9→8 | 8 |

答案 $= \min\{6, 7, 8, 5, 3, 8\} = 3$ ✓。时刻 3 涂上 4，第二列 $\{2, 7, 4\}$ 恰好涂满——瓶颈正是时刻最大的那格 $(1,1)$。

顺带验证**示例 1**：行 0 的 $T = \max(0, 2) = 2$，列 1 的 $T = \max(2, 1) = 2$，$\min\{2, 3, 3, 2\} = 2$ ✓——两条线**并列**最早完成也不影响取 $\min$。

## 4. 算法细节

1. **数组代替哈希表**：值域恰为 $[1, mn]$ 且互不重复，`idx` 用长度 $mn + 1$ 的数组以值直接做下标，$O(1)$ 寻址、无散列常数、缓存友好。值域稀疏的变体才需要退回 `unordered_map`。

2. **累积 max、一路 min**：行扫描无需 `rowMax` 数组，行内一个 `last` 变量累积 $\max$，随即 `ans = min(ans, last)` 丢掉即可；`last` 初始化为 $0$ 安全（$\mathrm{idx} \ge 0$ 且每行非空），`ans` 初始化为 `INT_MAX`（或 $mn - 1$，因答案必 $\le mn - 1$）。

3. **两段同构扫描**：步骤 ② ③ 结构完全相同，只对调循环变量 $r / c$。复制粘贴后**忘改变量**会把列循环写回行循环——结果错但不越界、不报错，是本解法唯一的隐蔽笔误（见 §8）。

4. **对照写法：行列计数法（增量视角）**：建 `pos[v] = (r, c)`，涂一格让 `rowCnt[r]`、`colCnt[c]` 各 $+1$，`rowCnt[r] == n`（行满看列数）或 `colCnt[c] == m`（列满看行数）即返回 $i$：

   ```cpp
   class Solution {
   public:
       int firstCompleteIndex(vector<int>& arr, vector<vector<int>>& mat) {
           int m = mat.size(), n = mat[0].size(), total = m * n;
           vector<pair<int,int>> pos(total + 1);            // 值 → 坐标
           for (int r = 0; r < m; ++r)
               for (int c = 0; c < n; ++c)
                   pos[mat[r][c]] = {r, c};

           vector<int> rowCnt(m, 0), colCnt(n, 0);
           for (int i = 0; i < total; ++i) {
               auto [r, c] = pos[arr[i]];
               if (++rowCnt[r] == n || ++colCnt[c] == m)    // 行满==n / 列满==m
                   return i;
           }
           return -1;                                        // 理论不可达
       }
   };
   ```

5. **赛时取舍**：两种写法代码量与复杂度同级，差别在结构：

   | 维度 | 完成时刻法（本篇主解） | 行列计数法（对照） |
   |------|----------------------|-------------------|
   | 视角 | 整体倒推：一次算出所有线的完成时刻 | 增量正推：边涂边判 |
   | 循环结构 | 三段平铺，无嵌套判定 | 单主循环 + 触发式返回 |
   | 提前终止 | 无，$m+n$ 条线必须扫完 | 有，命中即 `return` |
   | 哨兵返回值 | 不需要（$\min$ 必在 $[0, mn-1]$） | 需 `return -1` 占位 |
   | 典型笔误 | 行/列两段循环变量写串 | `rowCnt==n` / `colCnt==m` 方向写反 |

   顺手哪个写哪个，写完用 §8 的自测三件套验一遍即可（计数法的完整剖析见[每日题解 2661](../../solution/2601-2700/2661_找出叠涂元素.md)）。

## 5. 正确性证明

约定「时刻 $t$」指已涂完 $\text{arr}[0..t]$ 的状态，$t \in [0, mn-1]$。

**引理 1（线的完成时刻）**：对任意行 $r$，令 $T_r = \max_c \mathrm{idx}[\mathrm{mat}[r][c]]$。则时刻 $t$ 后第 $r$ 行全部涂色，当且仅当 $t \ge T_r$。对任意列 $c$，令 $T_c = \max_r \mathrm{idx}[\mathrm{mat}[r][c]]$，结论同理。

**证明**：第 $r$ 行全部涂色 $\iff$ 对每个 $c$，格 $(r, c)$ 已涂 $\iff$ 对每个 $c$，$\mathrm{idx}[\mathrm{mat}[r][c]] \le t$ $\iff$ $\max_c \mathrm{idx}[\mathrm{mat}[r][c]] \le t$ $\iff$ $T_r \le t$。列的情形将 $c$ 换成 $r$ 逐字重复。∎

**定理**：所求下标恰为 $\min\bigl(\min_r T_r,\ \min_c T_c\bigr)$。

**证明**：记 $M$ 为该最小值。「时刻 $t$ 存在某条线涂满」$\iff$ 存在线 $\ell$（某行或某列）使 $t \ge T_\ell$（由引理 1 及其列版本）$\iff$ $t \ge M$。又 `arr` 是 $[1, mn]$ 的排列，每格必被涂且时刻互异取遍 $0 \sim mn-1$，故每个 $T$ 良定义且 $M \in [0, mn-1]$。所求下标是满足条件的最小 $t$，即 $t = M$。∎

**推论**：算法三步依次计算 $\mathrm{idx}$、各线的 $\max$ 与整体的 $\min$，返回值即 $M$，与所求一致。

## 6. 复杂度分析

- **时间复杂度**：$O(mn)$。建 `idx` 一趟 $O(mn)$；行扫描与列扫描各访问 $mn$ 个格子，每格一次 $O(1)$ 比较；总计约 $3mn$ 次基本操作。
- **空间复杂度**：$O(mn)$。`idx` 数组占 $mn + 1$；其余仅 `last`、`ans` 等常数个变量（不用 `rowMax`/`colMax` 数组的话额外空间 $O(1)$）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int firstCompleteIndex(vector<int>& arr, vector<vector<int>>& mat) {
        int m = mat.size(), n = mat[0].size();
        vector<int> idx(m * n + 1);
        for (int i = 0; i < m * n; ++i) idx[arr[i]] = i;   // 值 → 涂色时刻

        int ans = INT_MAX;
        for (int r = 0; r < m; ++r) {              // 每行完成时刻 = 行内 max
            int last = 0;
            for (int c = 0; c < n; ++c) last = max(last, idx[mat[r][c]]);
            ans = min(ans, last);
        }
        for (int c = 0; c < n; ++c) {              // 每列完成时刻 = 列内 max
            int last = 0;
            for (int r = 0; r < m; ++r) last = max(last, idx[mat[r][c]]);
            ans = min(ans, last);
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def firstCompleteIndex(self, arr: List[int], mat: List[List[int]]) -> int:
        m, n = len(mat), len(mat[0])
        idx = [0] * (m * n + 1)
        for i, v in enumerate(arr):                 # 值 → 涂色时刻
            idx[v] = i

        ans = m * n - 1                             # 答案必 <= mn-1
        for row in mat:                             # 每行完成时刻 = 行内 max
            ans = min(ans, max(idx[v] for v in row))
        for col in zip(*mat):                       # 每列完成时刻 = 列内 max
            ans = min(ans, max(idx[v] for v in col))
        return ans
```

## 8. 边界情况与易错点

1. **极端形状答案为 0**：$m \times 1$ 或 $1 \times n$ 时每条线（或每列）只有一格，涂 `arr[0]` 即涂满某条线，答案恒为 $0$。完成时刻法自动得出：单格线的 $T = \mathrm{idx}[\text{该格}]$，最小值即 $0$。
2. **$1 \times 1$**：`arr = [1]`、`mat = [[1]]`，涂第 0 格即行 0 与列 0 同时涂满，返回 $0$。
3. **返回下标而非值**：返回的是 $i$，不是 `arr[i]`。
4. **两段扫描写串**：完成时刻法 ② ③ 复制粘贴后忘对调 $r / c$，把列循环写成行循环——结果错但通常不越界、不报错，最难排查，提交前专门瞄一眼。
5. **计数法判满方向**（若用对照写法）：行满 `rowCnt[r] == n`（列数）、列满 `colCnt[c] == m`（行数），口诀「行满看列数、列满看行数」，写反是最常见笔误。
6. **数组长度 $mn + 1$**：值从 $1$ 到 $mn$，`idx`/`pos` 长度 $mn + 1$（下标 0 弃用）——这是值域恰为 $[1, mn]$ 的赠品，变体题里值域稀疏时要退回哈希表。
7. **并列完成不影响**：多条线同时最早完成（如示例 1 的行 0 与列 1 同为时刻 2），取 $\min$ 天然兼容。
8. **赛时自测三件套**：$1 \times 1$、$1 \times n$（答案应为 0）、示例 2（列胜出 + 瓶颈格验证）——三个用例把形状边界与 min-max 结构全部踩一遍。
