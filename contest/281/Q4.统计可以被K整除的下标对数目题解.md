# LeetCode 统计可以被K整除的下标对数目 题解

## 1. 题目概述

- **标题 / 题号**：统计可以被K整除的下标对数目（#2183，hard）
- **链接**：https://leetcode.cn/problems/count-array-pairs-divisible-by-k/
- **来源**：LeetCode 第 281 场周赛 Q4
- **难度**：困难
- **标签**：数组、数学、数论、gcd（最大公约数）、计数、枚举

**题意**：给定下标从 0 开始、长度为 `n` 的正整数数组 `nums` 与正整数 `k`，统计同时满足 $0 \le i < j \le n-1$ 且 $k \mid \text{nums}[i] \times \text{nums}[j]$ 的下标对 $(i, j)$ 的数目。

**约束**：

- $1 \le \text{nums.length} \le 10^5$
- $1 \le \text{nums}[i],\ k \le 10^5$

> 💡 **读题定位**：三个信号词——「**乘积整除**」「**配对计数**」「$n$ 高达 $10^5$」——直接宣告 $O(n^2)$ 暴力两两判定不可行，必须把「数与数之间的配对」压缩成「类别与类别之间的配对」。整除问题的标准降维手段是**质因子视角**：$k \mid x \cdot y$ 只关心 $x, y$ 各自「贡献给 $k$ 的质因子」，与 $k$ 无关的部分全是废话——而恰好有一个函数把这部分废话剥得干干净净：$\gcd(x, k)$。于是每个数塌缩成 $k$ 的一个因子，值域从 $10^5$ 塌到至多 **128** 个，配对在因子层面完成。这是「gcd 因子配对」的经典套路，值得整体沉淀。

## 2. 示例

**示例 1**（官方）

```text
输入：nums = [1,2,3,4,5], k = 2
输出：7
解释：共 7 对下标积能被 2 整除：(0,1)、(0,3)、(1,2)、(1,3)、(1,4)、(2,3)、(3,4)，
      积分别为 2、4、6、8、10、12、20。
      其余如 (0,2) 积为 3、(2,4) 积为 15，均不被 2 整除。
```

**示例 2**（官方）

```text
输入：nums = [1,2,3,4], k = 5
输出：0
解释：不存在积能被 5 整除的下标对。
```

**示例 3**（自造：都有公共因子，仍不合法）

```text
输入：nums = [9, 6], k = 12
输出：0
解释：9·6 = 54 = 2·3³，而 12 = 2²·3 —— 只凑出一个 2，缺一个 2，54 % 12 = 6 ≠ 0。
      「两个数都与 k 有公共因子」远远不够，要逐质因子凑够幂次。
```

**示例 4**（自造：质因子互补，合法）

```text
输入：nums = [4, 9], k = 12
输出：1
解释：4·9 = 36 = 2²·3²，凑够了 2²·3。
      gcd(4,12) = 4 贡献 2²，gcd(9,12) = 3 贡献 3 —— 正好是一对互补的因子。
```

## 3. 解题思路

### 3.1 暴力思路

枚举全部 $\binom{n}{2} \approx 5 \times 10^9$ 个下标对，逐一判定 $k \mid \text{nums}[i] \cdot \text{nums}[j]$，时间 $O(n^2)$，在 $n = 10^5$ 下必然超时。

朴素改进都绕不开一个事实：判定「这一对是否合法」只取决于 $x, y$ **各自**与 $k$ 的关系，而与 $x, y$ 的其他部分无关。既然配对的合法性由「每个数与 $k$ 的关系」唯一决定，就该把每个数**替换成它与 $k$ 的关系的摘要**——摘要相同的一切数两两等价，配对变成等价类之间的计数。问题只剩下：这个「关系摘要」取什么函数，才能既**不损失配对信息**，又**值域足够小**。

### 3.2 核心观察：gcd(x, k) 是「配对能力」的完备摘要

![核心观察：gcd 逐质因子截断，配对判定完全等价](images/wc281_q4_gcd_factor_concept.svg)

答案是 $g = \gcd(x, k)$。先把 $k$ 分解为 $k = \prod p^{a_p}$，则「$k \mid x \cdot y$」逐质因子等价于

$$v_p(x) + v_p(y) \ \ge\ a_p \qquad (\forall\, p \mid k)$$

其中 $v_p(\cdot)$ 是质因数分解中 $p$ 的幂次。注意两件事：

- $x$ 中 $p$ 的幂次一旦**超过** $a_p$，超出部分对「凑够 $a_p$」毫无帮助——单侧最多只需要 $a_p$ 个 $p$；
- 而 $\gcd(x, k)$ 恰好逐维做了这次截断：$v_p(\gcd(x,k)) = \min(v_p(x),\, a_p)$。

于是截断不损失任何配对信息，得到本题主定理（严格证明见 §5）：

$$k \mid x \cdot y \iff k \mid \gcd(x,k) \cdot \gcd(y,k)$$

**这一步的收益是降维打击**：把每个 $\text{nums}[i]$ 替换成 $g_i = \gcd(\text{nums}[i], k)$ 不改变任何一对的合法性，而所有 $g_i$ 都是 $k$ 的**因子**。$k \le 10^5$ 时因子个数 $d(k)$ 至多 **128** 个（$k = 83160 = 2^3 \cdot 3^3 \cdot 5 \cdot 7 \cdot 11$ 时取到），于是「$n = 10^5$ 个数的两两配对」塌缩成「$128$ 个因子值的两两配对」——只需枚举因子对 $(d_1, d_2)$，判定 $k \mid d_1 \cdot d_2$，再按频次累加。

### 3.3 算法流程

![算法流程：因子表 → GCD 频次表 → 因子对枚举](images/wc281_q4_algorithm_flow.svg)

三步流水线：

1. **求因子表**：$d$ 从 1 到 $\lfloor\sqrt{k}\rfloor$ 扫描，$k \bmod d = 0$ 时成对收集 $d$ 与 $k/d$（$d^2 = k$ 时只收一次），$O(\sqrt{k})$；
2. **统计 GCD 频次**：遍历 `nums`，对每个 $x$ 计算 $g = \gcd(x, k)$，`freq[g]++`，$O(n \log k)$；
3. **枚举因子对**：对所有 $d_1 \le d_2$，若 $d_1 \cdot d_2 \bmod k = 0$：$d_1 \ne d_2$ 时累加 $\text{freq}[d_1] \cdot \text{freq}[d_2]$（两类各取一个）；$d_1 = d_2$ 时累加 $\binom{\text{freq}[d_1]}{2}$（同类内部组合），$O(d(k)^2)$。

### 3.4 示例演算

![示例演算：nums=[1,2,3,4,5,6], k=6 的三步走查](images/wc281_q4_example_walkthrough.svg)

以 `nums = [1,2,3,4,5,6]`，`k = 6` 为例（比官方示例更能暴露易错点）：

| 步 | 内容 | 结果 |
|----|------|------|
| ① 因子表 | $6 = 2 \cdot 3$ | $\{1,\, 2,\, 3,\, 6\}$ |
| ② GCD 频次 | $[1,2,3,2,1,6]$ 逐个与 6 取 gcd | $\text{freq} = \{1{:}2,\ 2{:}2,\ 3{:}1,\ 6{:}1\}$ |
| ③ 枚举 10 对 | $(1,6){:}\checkmark{+}2$、$(2,3){:}\checkmark{+}2$、$(2,6){:}\checkmark{+}2$、$(3,6){:}\checkmark{+}1$、$(6,6){:}\checkmark{+}0$；其余 5 对 ✗ | 合计 $7$ |

其中两个细节值得盯住：$(6,6)$ 合法但 $\binom{1}{2} = 0$（同因子必须用组合数）；$(3,3)$ 同因子但 $9 \bmod 6 \ne 0$（先判整除再计数）。暴力对拍恰好也是 7 对：$(1,6),(2,3),(2,6),(3,4),(3,6),(4,6),(5,6)$。

## 4. 算法细节

1. **因子表成对收集**：`d * d <= k` 循环内同时收 `d` 与 `k/d`，注意 `d == k/d` 时去重；因子表本身无序没关系，枚举因子对时统一按值排序后取 $d_1 \le d_2$ 的组合即可（或直接 `sort` 一次，$d(k) \le 128$ 排序开销可忽略）。
2. **频次表的数据结构**：键只会是 $k$ 的因子，`unordered_map` 足够快；追求常数可以离散化成数组（值 → 因子表下标），但本题瓶颈在 $n$ 次 gcd，不必优化。
3. **因子对判定的另一视角**：因为 $d_1 \mid k$，有 $d_1 d_2 \bmod k = 0 \iff (k / d_1) \mid d_2$——即 $d_2$ 是「需求因子」$k/d_1$ 的**倍数**。由它可写出**一次遍历**变体（见 §7 末）：对每个 $x$ 算 $g = \gcd(x,k)$、$\text{need} = k/g$，把频次表中所有 $\text{need} \mid d$ 的 $\text{freq}[d]$ 加进答案，再 `freq[g]++`。正确性：$k \mid g \cdot d \iff (k/g) \mid d$（因 $g \mid k$，两边同除 $g$ 即证）。
4. **乘积判定的安全性**：$d_1 d_2 \le k^2 \le 10^{10}$，超出 `int` 但远小于 $2^{63}$，`(long long)d1 * d2 % k` 安全；同理频次乘积 $\text{freq}[d_1] \cdot \text{freq}[d_2] \le 10^{10}$、$\binom{c}{2} \approx 5 \times 10^9$ 都必须用 64 位累加。
5. **gcd 的调用方式**：`nums[i]` 可以远大于 $k$（如 $99991$ 对 $k=7$），gcd 无需任何预处理直接算；不要试图先 `nums[i] % k` 再取 gcd——虽然在本题恰好也等价（$(x \bmod k)$ 与 $x$ 对 $k$ 的 gcd 相同），但多绕一步毫无收益。
6. **不要用「余数」做配对键**：$(x \bmod k)(y \bmod k) \equiv xy \pmod k$ 判定虽对，但余数值域 $[0, k)$ 高达 $10^5$ 种且无配对结构，仍然 $O(n^2)$；gcd 视角值域只有 $d(k) \le 128$ 且保持整除关系——**「正确但不可降维」与「正确且可降维」隔着这道题的全部距离**。

## 5. 正确性证明

设 $k = \prod_{p \mid k} p^{a_p}$（$a_p \ge 1$），$v_p(x)$ 表示 $x$ 中质数 $p$ 的幂次（$x \ge 1$，故良定义）。核心事实：$k \mid z \iff \forall p \mid k:\ v_p(z) \ge a_p$。

**引理 1（gcd 的逐维截断）**：对任意 $x \ge 1$ 与 $p \mid k$，$v_p(\gcd(x, k)) = \min(v_p(x),\, a_p)$。

**证明**：$\gcd(x, k) = \prod_q q^{\min(v_q(x),\, v_q(k))}$，而 $p \mid k$ 时 $v_p(k) = a_p$，代入即得。∎

**引理 2（截断不损配对）**：对非负整数 $x, y$ 及 $a \ge 1$，$\min(x, a) + \min(y, a) \ge a \iff x + y \ge a$。

**证明**：（⇒）$\min(x,a) \le x$ 且 $\min(y,a) \le y$，相加即得。（⇐）若 $x, y$ 均 $< a$，则左边 $= x + y \ge a$；否则不妨 $x \ge a$，则 $\min(x, a) = a$，左边 $\ge a + 0 = a$。∎

**定理（配对等价）**：对任意 $x, y \ge 1$，$k \mid x \cdot y \iff k \mid \gcd(x, k) \cdot \gcd(y, k)$。

**证明**：逐质因子比较。对每个 $p \mid k$：

$$v_p(x) + v_p(y) \ge a_p \overset{\text{引理 2}}{\iff} \min(v_p(x), a_p) + \min(v_p(y), a_p) \ge a_p \overset{\text{引理 1}}{\iff} v_p(\gcd(x,k)) + v_p(\gcd(y,k)) \ge a_p$$

左端串起来恰是 $k \mid xy$ 的逐维刻画，右端是 $k \mid \gcd(x,k)\gcd(y,k)$ 的逐维刻画；不整除 $k$ 的质数对两侧均无贡献。故两侧整体等价。∎

**推论（因子层计数正确）**：原答案等于

$$\sum_{\substack{d_1 < d_2,\ k \mid d_1 d_2}} \text{freq}[d_1] \cdot \text{freq}[d_2] \; + \sum_{\substack{d,\ k \mid d^2}} \binom{\text{freq}[d]}{2}$$

其中 $d_1, d_2, d$ 取遍 $k$ 的因子。

**证明**：把每个下标 $i$ 映射为 $g_i = \gcd(\text{nums}[i], k)$，由定理，对 $(i, j)$ 合法 $\iff$ 无序因子对 $\{g_i, g_j\}$ 满足 $k \mid g_i g_j$。将所有下标对按 $(\min(g_i,g_j),\, \max(g_i,g_j))$ 分桶：桶两两不交且覆盖全部 $\binom{n}{2}$ 对。$d_1 < d_2$ 的桶中每对恰由 $d_1$ 类与 $d_2$ 类各取一个元素组成，共 $\text{freq}[d_1] \cdot \text{freq}[d_2]$ 对（选出两个元素后 $i < j$ 的排序唯一）；$d_1 = d_2$ 的桶是同类内部的无序对，共 $\binom{c}{2}$ 对。对合法桶求和即得答案。∎

> 💡 **证明结构复盘**：引理 1 是 gcd 的代数性质（截断），引理 2 是整道题的命门——**「单侧超过需求的冗余不参与配对」**，两个方向各一行。定理把「乘积整除」逐质因子地翻译到截断后的量上，推论再把「逐对判定」重组为「按桶计数」。这四步是所有「gcd 因子配对」类题目的通用证明骨架，2183 之后见到的同型题可以直接套。

## 6. 复杂度分析

- **时间复杂度**：$O(\sqrt{k} + n \log k + d(k)^2)$。求因子表 $O(\sqrt{k}) \approx 316$；遍历 `nums` 每次欧几里得 gcd $O(\log k) \le 17$，共约 $1.7 \times 10^6$ 次，是**全程主瓶颈**；因子对枚举 $d(k)^2 \le 128^2 = 16384$ 次，可忽略。整体视作 $O(n \log k)$。
- **空间复杂度**：$O(d(k))$——因子表与频次表都只存 $k$ 的因子，至多 128 个键。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    long long countPairs(vector<int>& nums, int k) {
        // ① 求 k 的全部因子
        vector<int> divisors;
        for (int d = 1; (long long)d * d <= k; ++d)
            if (k % d == 0) {
                divisors.push_back(d);
                if (d != k / d) divisors.push_back(k / d);
            }

        // ② 统计 gcd(nums[i], k) 的频次
        unordered_map<int, int> freq;
        for (int x : nums) freq[__gcd(x, k)]++;

        // ③ 枚举因子对 (d1 <= d2)
        long long ans = 0;
        int m = divisors.size();
        for (int i = 0; i < m; ++i)
            for (int j = i; j < m; ++j) {
                int d1 = divisors[i], d2 = divisors[j];
                if ((long long)d1 * d2 % k == 0) {
                    if (d1 == d2) {
                        long long c = freq[d1];
                        ans += c * (c - 1) / 2;      // 同因子内部组合
                    } else {
                        ans += (long long)freq[d1] * freq[d2];  // 两类各取一个
                    }
                }
            }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def countPairs(self, nums: List[int], k: int) -> int:
        from math import gcd

        # ① 求 k 的全部因子
        divisors = []
        d = 1
        while d * d <= k:
            if k % d == 0:
                divisors.append(d)
                if d != k // d:
                    divisors.append(k // d)
            d += 1

        # ② 统计 gcd(nums[i], k) 的频次
        freq = {}
        for x in nums:
            g = gcd(x, k)
            freq[g] = freq.get(g, 0) + 1

        # ③ 枚举因子对 (d1 <= d2)
        ans = 0
        m = len(divisors)
        for i in range(m):
            for j in range(i, m):
                d1, d2 = divisors[i], divisors[j]
                if d1 * d2 % k == 0:
                    if d1 == d2:
                        c = freq.get(d1, 0)
                        ans += c * (c - 1) // 2    # 同因子内部组合
                    else:
                        ans += freq.get(d1, 0) * freq.get(d2, 0)  # 两类各取一个
        return ans
```

### 变体：一次遍历（C++）

利用 §4 的 $(k/d_1) \mid d_2$ 视角，边扫 `nums` 边计数，省去因子对二重循环：

```cpp
class Solution {
  public:
    long long countPairs(vector<int>& nums, int k) {
        vector<int> divisors;
        for (int d = 1; (long long)d * d <= k; ++d)
            if (k % d == 0) {
                divisors.push_back(d);
                if (d != k / d) divisors.push_back(k / d);
            }
        unordered_map<int, int> freq;
        long long ans = 0;
        for (int x : nums) {
            int g = __gcd(x, k), need = k / g;   // 搭档的因子值必须是 need 的倍数
            for (int d : divisors)
                if (d % need == 0) ans += freq[d];
            freq[g]++;
        }
        return ans;
    }
};
```

> ⚠️ 两份主代码与变体均对官方示例、2000 组随机数据（$n \le 30$，$k \le 100$）及特殊形态用例（$k = 1$、$k = 83160$、全相同元素、`nums[i] > k` 等）与暴力对拍一致。

## 8. 边界情况与易错点

1. **溢出是本题最大的坑**：答案最大 $\binom{10^5}{2} \approx 5 \times 10^9$，频次乘积最大 $10^{10}$，均超 `int32`——累加器、`freq[d1] * freq[d2]`、$c(c-1)/2$ 三处都要 64 位。C++ 忘写 `(long long)` 强转会**恰好过小数据、WA 大数据**，最隐蔽。
2. **$d_1 = d_2$ 用组合数**：$\binom{c}{2} = c(c-1)/2$，写成 $c^2$ 会把有序对和自己配自己都算进去。
3. **先判整除再计数**：同因子对未必合法（$k = 6$ 时 $3 \cdot 3 = 9$ 不被 6 整除）；合法因子对也未必有贡献（$c = 1$ 时 $\binom{1}{2} = 0$）。「合法性」与「贡献量」是两个独立检查。
4. **因子收集去重**：$d^2 = k$（如 $k = 36, d = 6$）时只收一次，否则因子表含重复值，计数翻倍。
5. **$k = 1$**：一切乘积都被 1 整除，答案 $\binom{n}{2}$；算法自然正确——唯一因子 $1$ 满足 $1 \cdot 1 \bmod 1 = 0$，无需特判。
6. **$n = 1$**：没有配对，答案 0，算法自然输出 0。
7. **`nums[i]` 与 $k$ 无关时**：$g = 1$，它对配对的贡献由搭档单侧凑满全部 $k$ 决定（搭档 $g_y = k$ 即可），算法自动处理；不要在统计前「过滤掉与 $k$ 互质的数」——它们和 $g = k$ 的元素配对依然合法。
8. **变体中判定方向**：是 `d % need == 0`（$d$ 是需求因子的**倍数**），写反成 `need % d == 0` 会在 $k$ 非平方数时大面积出错。
9. **`unordered_map` 的 `operator[]`**：查询不存在的键会插入 0，本题键集合有界（$\le 128$）无碍，但若换到键域大的场景应改用 `find`/`count`。

**延伸思考**：

- **三元组推广**：统计 $k \mid x \cdot y \cdot z$ 的三元组？引理 2 可推广到三项（$\sum_i \min(x_i, a) \ge a \iff \sum_i x_i \ge a$，证法相同：全 $< a$ 时等价，否则某侧 $\min = a$ 封顶即达标），因此把每个数截断成 $\gcd(x, k)$ 依然无损；计数变为对 $d(k)^3$ 个因子三元组求和，或枚举两个因子后查第三个的前缀计数。
- **`nums[i] = 0` 的彩蛋**：若题目放开 $0 \le \text{nums}[i]$，$0$ 与任何数之积为 $0$、被一切 $k$ 整除；而 $\gcd(0, k) = k$，因子配对自动把含 $0$ 的对判为合法——算法**零修改兼容**，这正是 gcd 定义 $\gcd(0, k) = k$ 的精妙之处。
- **$k$ 更大时还成立吗**：$k \le 10^9$ 时 $d(k) \le 1344$，方法依然成立且因子枚举依旧便宜，瓶颈始终是 $n$ 次 gcd；真正失效的是「按值开桶」类的常数优化，哈希表写法不受影响。
- **有序对与子数组版本**：若问有序对 $(i \ne j)$，答案是本答案的 2 倍；若问「整体乘积被 $k$ 整除的最长/最短子数组」，可用「子数组 gcd 随长度延长单调不增」的经典技巧，值得作为下一题练手。
