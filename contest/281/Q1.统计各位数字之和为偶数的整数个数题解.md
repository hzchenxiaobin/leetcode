# LeetCode 统计各位数字之和为偶数的整数个数 题解

## 1. 题目概述

- **标题 / 题号**：统计各位数字之和为偶数的整数个数（#2180，easy）
- **链接**：https://leetcode.cn/problems/count-integers-with-even-digit-sum/
- **来源**：LeetCode 第 281 场周赛 Q1
- **难度**：简单
- **标签**：数学、模拟

**题意**：给定正整数 `num`，统计 **小于或等于** `num` 且 **各位数字之和为偶数** 的正整数个数。例如 $19$ 的数字和为 $1+9=10$（偶），$10$ 的数字和为 $1$（奇）。

**约束**：

- $1 \le \text{num} \le 1000$

> 💡 **读题定位**：签到题。数据范围只有 $10^3$，「枚举每个数 → 拆位求和 → 判奇偶」的 $O(\text{num} \cdot d)$ 模拟是赛场上最短的下手路径，没有陷阱、开盒即用。本题真正的价值在复盘：数字和的奇偶性沿数轴**几乎是隔一出一个**——配对观察能把答案压成一行 $O(1)$ 公式，这个「偶数打头、加一不进位」的论证手法在数字 DP 与奇偶构造题里反复出现，值得沉淀。

## 3. 解题思路

### 3.1 暴力思路：逐个数、逐位拆

直接照题意模拟：枚举 $i = 1, 2, \ldots, \text{num}$，对每个 $i$ 用「除 10 取余」拆出各位求和 $\mathrm{ds}(i)$，和为偶数则计数加一。

- 每个 $i$ 至多 $d = 4$ 位（$\text{num} \le 1000$），总运算量 $\le 4000$ 次整数操作；
- 本题 $10^3$ 的范围下**没有任何性能问题**，这就是赛时 AC 的最短路径。

「暴力」在本题并不暴力——它是与数据范围匹配的正解。真正需要动脑的是下面这步观察：这份枚举里藏着一行 $O(1)$ 公式。

### 3.2 核心观察：偶数打头的配对——加一必不进位，奇偶必然翻转

![核心观察：配对 {2k, 2k+1} 每对恰一个数字和为偶数](images/wc281_q1_pair_parity_concept.svg)

把非负整数轴按 **$\{2k,\ 2k+1\}$**（偶数打头）两两分组：$\{0,1\},\{2,3\},\{4,5\},\ldots$。关键观察是：

- $2k$ 的**个位必是偶数**（$0,2,4,6,8$ 之一），因此 $2k+1$ 只把个位加一、**永远不产生进位**；
- 不进位意味着其他各位不变，于是 $\mathrm{ds}(2k+1) = \mathrm{ds}(2k) + 1$，**奇偶性恰好翻转**；
- 所以每一对 $\{2k, 2k+1\}$ 中**恰好有一个**数字和为偶数——数轴上「数字和为偶」的分布是严格的隔一出一个（以偶数起点对齐）。

**为什么配对必须偶数打头？** 若改成 $\{2k-1,\ 2k\}$（奇数打头），奇数个位是 $9$ 时加一会进位：$9 \to 10$ 数字和 $9 \to 1$，一奇一奇；$19 \to 20$ 数字和 $10 \to 2$，一偶一偶——奇偶**不翻转**，配对失效（示例 4 正是这个现象）。进位会吞噬「$+1$ 翻转奇偶」的规律，而偶数个位 $+1$ 最大到 $9$，天然规避进位。

### 3.3 算法流程

![算法流程：签到走模拟，进阶走配对 O(1)](images/wc281_q1_algorithm_flow.svg)

两条等价路线：

**路线 A（模拟，赛时主力）**：

1. `ans = 0`；
2. 枚举 $i = 1 \ldots \text{num}$：内层 `while` 拆位求 $\mathrm{ds}(i)$；
3. $\mathrm{ds}(i)$ 为偶则 `ans++`；返回 `ans`。

**路线 B（配对观察 → $O(1)$ 公式）**：

1. 求出 $s = \mathrm{ds}(\text{num})$（只需处理 `num` 一个数）；
2. 由配对结论：$[0, \text{num}]$ 中「数字和为偶」的个数 $\approx$ 一半，再按 `num` 奇偶修正：

$$
\text{ans} = \left\lfloor \frac{\text{num}}{2} \right\rfloor - \bigl[\, \text{num 为偶} \wedge \mathrm{ds}(\text{num}) \text{ 为奇} \,\bigr]
$$

- **num 为奇数** $2k+1$：$[0, 2k+1]$ 恰被 $k+1$ 对完美划分，每对贡献 $1$ 个偶，共 $k+1$ 个；其中 $0$（数字和 $0$，偶）不在 $[1,\text{num}]$ 内，扣掉后剩 $k = \lfloor \text{num}/2 \rfloor$，修正项为 $0$；
- **num 为偶数** $2k$：$[1, 2k-1]$ 按奇数情形有 $k-1$ 个；再看 $2k$ 自己——数字和为偶才额外加一。合并即上式。

### 3.4 示例演算

![示例演算：num=30 的逐格清点与 O(1) 公式验证](images/wc281_q1_example_walkthrough.svg)

以 $\text{num} = 30$ 为例。

**逐格清点**（模拟视角）：

- $1 \sim 10$：$2,4,6,8$ 共 **4** 个；
- $11 \sim 20$：$11,13,15,17,19,20$ 共 **6** 个（注意 $19$ 与 $20$ 相邻都入榜）；
- $21 \sim 30$：$22,24,26,28$ 共 **4** 个；
- 合计 $4 + 6 + 4 = 14$ ✓。

**配对清点**（观察视角）：$\{2,3\},\{4,5\},\ldots,\{28,29\}$ 共 $14$ 对，每对恰出一个；首对 $\{0,1\}$ 的偶是 $0$ 本身，不在统计范围；再看 $30$ 自身：$\mathrm{ds}(30)=3$ 为奇，不加分。合计 $14$ ✓。

**公式验证**：$30$ 为偶数，$\mathrm{ds}(30) = 3$ 为奇 → $\text{ans} = 30/2 - 1 = 14$ ✓。三种方式殊途同归。

## 4. 算法细节

1. **拆位求和的标准写法**：C++ 用 `for (int j = i; j; j /= 10) s += j % 10;`，纯整数运算、无字符串开销；Python 里 `sum(map(int, str(i)))` 更短，两种写法在本题规模下等价。注意循环条件写 `j` 而非 `j > 0` 即可（$i \ge 1$ 保证至少进一次循环）。

2. **$O(1)$ 公式的统一表达**：修正项 `[num 为偶 且 ds(num) 为奇]` 用一个布尔表达式实现——C++ 中 `(num % 2 == 0 && s % 2 == 1)` 可直接被减（`bool` 提升为 `int`）；Python 中 `num % 2 == 0 and s % 2 == 1` 同理。**num 为奇时无需看 $\mathrm{ds}(\text{num})$**：奇数 $2k+1$ 自身在数对 $\{2k, 2k+1\}$ 中，其奇偶已被配对「吸收」，不会破坏计数。

3. **配对方向是本题观察的全部精髓**：奇偶翻转依赖「个位 $+1$ 不进位」。偶数个位 $\in \{0,2,4,6,8\}$，$+1$ 后 $\le 9$，永不进位；奇数个位为 $9$ 时必进位，进位把个位 $9$ 折成 $0$ 并向十位加一，数字和净变化 $-9c + 1$（$c$ 为连续末尾 $9$ 的个数），奇偶不再可控。**「锚定一个不触发进位的起点」**是构造奇偶交替论证的通用抓手。

4. **为什么「大约一半」直觉是对的**：配对结论说明 $[0, 2k+1]$ 中偶数字和恰好占一半（$k+1$ 个 / $2k+2$ 个）。答案对 $\text{num}/2$ 的偏离永远不超过 $1$——提交前可用「答案必为 $\lfloor \text{num}/2 \rfloor$ 或 $\lfloor \text{num}/2 \rfloor - 1$」做快速 sanity check。

## 5. 正确性证明

记 $\mathrm{ds}(n)$ 为 $n$ 的各位数字之和，$f(n) = \mathrm{ds}(n) \bmod 2$ 为其奇偶性。

**引理 1（不进位则和加一）**：若 $n$ 的个位数字为偶数，则 $\mathrm{ds}(n+1) = \mathrm{ds}(n) + 1$，故 $f(n+1) \ne f(n)$。

**证明**：设 $n$ 的个位为 $e \in \{0,2,4,6,8\}$，则 $n + 1$ 除个位变为 $e+1 \in \{1,3,5,7,9\}$ 外与 $n$ 完全相同（$e + 1 \le 9$，无进位）。于是 $\mathrm{ds}(n+1) = \mathrm{ds}(n) - e + (e+1) = \mathrm{ds}(n) + 1$，数字和恰增加 $1$，奇偶性翻转。∎

**引理 2（配对恰一偶）**：对任意 $k \ge 0$，数对 $\{2k,\ 2k+1\}$ 中恰有一个数的数字和为偶数。

**证明**：$2k \bmod 10 \in \{0,2,4,6,8\}$ 为偶数个位，由引理 1，$\mathrm{ds}(2k+1) = \mathrm{ds}(2k) + 1$，二者奇偶性相反，故恰一偶一奇。∎

**定理（$O(1)$ 公式）**：$[1, \text{num}]$ 中数字和为偶数的个数为

$$
\mathrm{ans} = \left\lfloor \frac{\text{num}}{2} \right\rfloor - \bigl[\, \text{num} \equiv 0 \pmod 2 \bigr] \cdot \bigl[\, \mathrm{ds}(\text{num}) \bmod 2 = 1 \,\bigr].
$$

**证明**：分两种情形。

- **$\text{num} = 2k+1$（奇）**：区间 $[0, 2k+1]$ 被数对 $\{0,1\},\{2,3\},\ldots,\{2k,2k+1\}$ 完美划分（共 $k+1$ 对），由引理 2 每对恰贡献 $1$ 个偶，故 $[0, 2k+1]$ 中有 $k+1$ 个。其中 $0$ 的数字和为 $0$（偶）属于统计外的数，故 $[1, 2k+1]$ 中恰 $k$ 个。此时 $\lfloor \text{num}/2 \rfloor = k$，修正项为 $0$，公式成立。
- **$\text{num} = 2k$（偶）**：拆分 $[1, 2k] = [1, 2k-1] \cup \{2k\}$。前者由奇数情形（$\text{num}' = 2k-1 = 2(k-1)+1$）恰有 $k-1$ 个；后者按 $\mathrm{ds}(2k)$ 的奇偶决定是否加一。故个数为 $k - 1 + [\mathrm{ds}(\text{num}) \text{ 为偶}] = k - [\mathrm{ds}(\text{num}) \text{ 为奇}]$，与公式一致（此时 $\lfloor \text{num}/2 \rfloor = k$）。∎

**模拟解的正确性**是显然的：它逐一无重复、无遗漏地检查 $[1, \text{num}]$ 中每个数是否满足谓词 $\mathrm{ds}(n) \bmod 2 = 0$，与题目定义逐一对应。∎

> 💡 **证明结构复盘**：引理 1 是「局部运算规则」（进位分析），引理 2 是「局部规则在数轴上的周期化」（配对结构），定理是「结构到区间的计数合成」。这套「先分析边界运算、再找周期结构、最后合成区间计数」的三段式，正是数位 DP 类题目的雏形——本题相当于数位 DP 退化成一行公式的特例。

## 6. 复杂度分析

- **时间复杂度**：模拟为 $O(\text{num} \cdot d)$，其中 $d \le 4$ 是数字位数，最坏约 $4 \times 10^3$ 次整数运算；配对公式为 $O(d)$——只需求 $\text{num}$ 自身的数字和（若视位数为常数则为 $O(1)$）。
- **空间复杂度**：两种解法均为 $O(1)$，只使用常数个计数与拆位变量。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int countEven(int num) {
        // 方案 A：直接模拟，O(num · d)
        int ans = 0;
        for (int i = 1; i <= num; ++i) {
            int s = 0;
            for (int j = i; j; j /= 10) s += j % 10;
            ans += (s % 2 == 0);
        }
        return ans;
    }
};
```

进阶一行版（配对 $O(1)$ 公式）：

```cpp
class Solution {
  public:
    int countEven(int num) {
        int s = 0;
        for (int j = num; j; j /= 10) s += j % 10;
        return num / 2 - (num % 2 == 0 && s % 2 == 1);
    }
};
```

### Python

```python
class Solution:
    def countEven(self, num: int) -> int:
        # 方案 A：直接模拟，O(num · d)
        ans = 0
        for i in range(1, num + 1):
            s = sum(map(int, str(i)))
            if s % 2 == 0:
                ans += 1
        return ans
```

进阶一行版：

```python
class Solution:
    def countEven(self, num: int) -> int:
        s = sum(map(int, str(num)))
        return num // 2 - (num % 2 == 0 and s % 2 == 1)
```

> ⚠️ Python 的 `and` 返回操作数本身（`False`/`1`），直接被减合法；但可读性见仁见智，赛时以「模拟保底、公式加分」为策略，两种都值得写一遍。

## 8. 边界情况与易错点

1. **`num = 1` 答案为 0**：$[1,1]$ 内只有 $1$ 自己，数字和 $1$ 为奇。模拟自然得 $0$；公式 $\lfloor 1/2 \rfloor = 0$，修正项不生效 ✓。这是最小输入，提交前先心算。

2. **「小于或等于」包含 `num` 自身**：模拟天然覆盖；$O(1)$ 公式中偶数情形的修正项 $[\mathrm{ds}(\text{num}) \text{ 为奇}]$ 干的就是「把多算的 `num` 自己扣掉」这件事——若忘了修正，$\text{num}=30$ 会输出 $15$ 而非 $14$。

3. **数字和奇偶 ≠ 数值奇偶**：$10$ 是偶数但数字和 $1$ 为奇；$19$ 是奇数但数字和 $10$ 为偶。**不要**把条件写成 `i % 2 == 0`，也不要在 $O(1)$ 公式里拿 `num % 2` 去判数字和的奇偶。

4. **进位配对陷阱**：想走 $O(1)$ 路线时，配对必须 **偶数打头**。若错用 $\{2k-1, 2k\}$（奇数打头）并在脑中默认「相邻两数奇偶必翻转」，会在 $9 \to 10$、$19 \to 20$ 这类进位点翻车（两数奇偶相同）。验证方法：拿 $\text{num} = 10$ 手推——正确公式给 $4$（$2,4,6,8$），错误配对会给 $5$。

5. **修正项的适用条件**：`num` 为奇数时**不看** $\mathrm{ds}(\text{num})$。例如 $\text{num}=19$：$\mathrm{ds}=10$ 为偶，但答案由配对直接给 $9$，与 $19$ 自身数字和的奇偶无关（它已在数对 $\{18,19\}$ 中被计入）。把修正条件写成只看数字和奇偶、漏掉 `num % 2 == 0`，会在奇数输入上出错。

6. **求和循环的终止条件**：`for (int j = i; j; j /= 10)` 依赖 $i \ge 1$；本题下标从 $1$ 起枚举天然安全，但若把同样的循环搬到「可能传入 $0$」的场景（求 $\mathrm{ds}(0)$ 应为 $0$），需特判或改写为 `do-while`。

7. **无溢出风险**：$\text{num} \le 1000$，数字和最大 $\mathrm{ds}(999)=27$，计数最大 $499$，全程 32 位绰绰有余——本题没有 C++/Python 的差异坑，属于「纯逻辑签到」。

**延伸思考**：

- **若 $\text{num}$ 高达 $10^{18}$？** 模拟必然超时，但配对公式**依然一行成立**——引理 1/2 的论证完全不依赖数量级，$\mathrm{ans} = \lfloor \text{num}/2 \rfloor - [\text{num 偶} \wedge \mathrm{ds}(\text{num}) \text{ 奇}]$ 对任意大的 `num` 都正确。这类「结构观察秒杀数位 DP」的场面，是先写暴力再找规律的最大红利。
- **增量递推数字和**：相邻两数的数字和满足 $\mathrm{ds}(n+1) = \mathrm{ds}(n) + 1 - 9 \cdot t(n)$，其中 $t(n)$ 是 $n$ 的末尾连续 $9$ 的个数（如 $19 \to 20$：$10 + 1 - 9 = 2$）。用它可以 $O(1)$ 递推整条数轴的数字和，配对结论正是它在偶数个位处（$t=0$）的特例。
- **反向询问——第 $k$ 个数字和为偶的数是几？** 由配对结构，第 $k$ 个必落在数对 $\{2k,\ 2k+1\}$（$k \ge 1$）中：$\mathrm{ds}(2k)$ 为偶则答案是 $2k$，否则是 $2k+1$。如第 $5$ 个是 $11$（$\mathrm{ds}(10)$ 为奇）、第 $10$ 个是 $20$（$\mathrm{ds}(20)$ 为偶），可作公式的逆运算自检。
