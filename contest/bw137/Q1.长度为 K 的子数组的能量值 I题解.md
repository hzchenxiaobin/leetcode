# LeetCode 长度为 K 的子数组的能量值 I 题解

## 1. 题目概述

- **标题 / 题号**：长度为 K 的子数组的能量值 I（#3254，medium）
- **链接**：https://leetcode.cn/problems/find-the-power-of-k-size-subarrays-i/
- **来源**：LeetCode 第 137 场双周赛 Q1
- **难度**：中等
- **标签**：数组、滑动窗口

**题意**：给定长度为 $n$ 的整数数组 `nums` 和正整数 $k$。一个数组的**能量值**定义为：

1. 如果**所有**元素都是**依次连续且上升**的（即对每个相邻位置都有 $nums[j] + 1 = nums[j+1]$），能量值为其中**最大**的元素；
2. 否则能量值为 $-1$。

要求返回长度为 $n - k + 1$ 的数组 `results`，其中 $results[i]$ 是子数组 $nums[i..i+k-1]$ 的能量值。

**约束**：

- $1 \le n = nums.length \le 500$
- $1 \le nums[i] \le 10^5$
- $1 \le k \le n$

## 2. 示例

**示例 1**

```text
输入：nums = [1,2,3,4,3,2,5], k = 3
输出：[3,4,-1,-1,-1]
解释：5 个长度为 3 的子数组依次为
     [1,2,3] → 3
     [2,3,4] → 4
     [3,4,3] → -1（不是连续的）
     [4,3,2] → -1（不是上升的）
     [3,2,5] → -1（不是连续的）
```

**示例 2**

```text
输入：nums = [2,2,2,2,2], k = 4
输出：[-1,-1]
解释：相邻差恒为 0，两个窗口都不合法。
```

**示例 3**

```text
输入：nums = [3,2,3,2,3,2], k = 2
输出：[-1,3,-1,3,-1]
解释：只有 [2,3] 这类恰好 +1 的窗口合法，其能量值为 3。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的做法：枚举 $i = 0, 1, \dots, n-k$，对每个窗口从 $i+1$ 扫到 $i+k-1$，检查是否满足 $nums[j] = nums[j-1] + 1$；一旦全部满足，答案就是窗口末元素，否则为 $-1$。

单窗口判定 $O(k)$，共 $n-k+1$ 个窗口，时间 $O\big((n-k+1) \cdot k\big) \le O(n^2)$。$n \le 500$ 时约为 $2.5 \times 10^5$ 次比较，**完全够用**——这正是 I 版作为签到题的意义：先把判据写清楚，再考虑优化。

### 3.2 核心观察：合法性只看相邻差，合法时最大值必是末元素

![能量值判据：窗口内相邻差全为 +1 才有值](images/bw137_q1_concept.svg)

关键观察有两条：

- **合法性判据**：窗口合法 $\iff$ 对窗口内每个相邻位置都有 $nums[j] = nums[j-1] + 1$。既不需要排序，也不需要额外集合。
- **合法即严格递增**：若相邻差恒为 $+1$，则窗口从左到右严格递增，因此**末元素就是最大元素**，无需再求 $\max$。

由此得到一个容易踩坑的等价变形：不能只看"值域"，必须看"顺序"。例如 $[3,2,1]$ 的值域连续（$3-1+1 = 3$），但它是**下降**的，能量值应为 $-1$。

### 3.3 算法流程

![暴力流程：逐个窗口检查相邻差](images/bw137_q1_flow.svg)

```text
1. results = 空数组
2. for i = 0 .. n - k:
       ok = true
       for j = i + 1 .. i + k - 1:
           若 nums[j] != nums[j-1] + 1:  ok = false; break
       若 ok:  results 追加 nums[i + k - 1]
       否则:   results 追加 -1
3. 返回 results
```

### 3.4 示例演算

![示例演算：五个窗口的相邻差与结论](images/bw137_q1_walkthrough.svg)

对示例 1 的 `nums = [1,2,3,4,3,2,5]`、`k = 3`：

| i | 子数组 | 相邻差 | 结论 | results[i] |
|---|--------|--------|------|-----------|
| 0 | [1, 2, 3] | +1, +1 | 连续上升 | 3 |
| 1 | [2, 3, 4] | +1, +1 | 连续上升 | 4 |
| 2 | [3, 4, 3] | +1, −1 | 出现断点 | −1 |
| 3 | [4, 3, 2] | −1, −1 | 出现断点 | −1 |
| 4 | [3, 2, 5] | −1, +3 | 出现断点 | −1 |

答案为 `[3, 4, -1, -1, -1]`。注意最后一个窗口里 $5$ 是全局最大值，但它所在的窗口不合法，所以结果仍是 $-1$：**合法性优先于数值大小**。

## 4. 算法细节

1. **判定顺序**：先把整个窗口的相邻差查完再决定输出，`break` 之后不能继续累加。
2. **末元素取值**：合法时直接取 `nums[i + k - 1]`；如果为了可读性写成对窗口取 $\max$，结果相同但多做 $k$ 次比较。
3. **窗口个数**：`i` 的上界是 $n - k$（闭区间），产出恰好 $n - k + 1$ 个答案，不要写成 $n - k - 1$。
4. **$k = 1$ 的特例**：长度为 1 的子数组没有相邻对，"空真"地满足条件，能量值就是该元素本身；循环里 `j` 从 `i + 1` 开始、到 `i` 结束自然不执行，无需特判。
5. **越界安全**：`i + k <= n` 保证 `nums[i + k - 1]` 不越界。

## 5. 正确性证明

**引理 1（合法性刻画）**：窗口 $nums[i..i+k-1]$ 合法，当且仅当对任意 $j \in (i, i+k-1]$ 都有 $nums[j] = nums[j-1] + 1$。

**证明**：题面定义"所有元素依次连续且上升"即"对每个相邻位置 $nums[u] + 1 = nums[u+1]$"，逐字转写即为该条件，故充要。∎

**引理 2（末元素即最大值）**：若窗口合法且 $k \ge 1$，则 $nums[i+k-1] = \max\{nums[i], \dots, nums[i+k-1]\}$。

**证明**：对 $k$ 归纳。$k = 1$ 时显然。若长度为 $k$ 的窗口合法，则其前 $k-1$ 个元素也满足相邻差为 $+1$，由归纳假设前缀最大值为 $nums[i+k-2]$；又由引理 1，$nums[i+k-1] = nums[i+k-2] + 1 > nums[i+k-2]$，故末元素严格大于前缀最大值，即为整个窗口最大值。∎

**定理**：算法输出的 `results[i]` 等于子数组 $nums[i..i+k-1]$ 的能量值。

**证明**：分两种情况。

- 若窗口合法：由引理 1，内层循环一次都不会把 `ok` 置为 `false`，算法输出 `nums[i+k-1]`；由引理 2，这正是窗口最大值，符合能量值定义。
- 若窗口不合法：由引理 1，存在某个相邻位置不满足 $+1$，内层循环必然把 `ok` 置为 `false`，算法输出 $-1$，也符合定义。

算法对 $i = 0, \dots, n-k$ 逐一处理，恰好覆盖全部 $n-k+1$ 个子数组，故结果数组完全正确。∎

## 6. 复杂度分析

- **时间**：$O\big((n-k+1) \cdot k\big)$。每个窗口最多检查 $k-1$ 个相邻对，最坏（所有元素都连续）时没有提前退出，总计不超过 $(n-k+1)(k-1) \le O(n^2)$。$n \le 500$ 时约 $2.5 \times 10^5$ 次整数比较。
- **空间**：$O(1)$ 额外空间（不计长度为 $n-k+1$ 的输出数组）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> resultsArray(vector<int>& nums, int k) {
        int n = (int)nums.size();
        vector<int> res;
        for (int i = 0; i + k <= n; i++) {
            bool ok = true;
            for (int j = i + 1; j < i + k; j++) {
                if (nums[j] != nums[j - 1] + 1) { ok = false; break; }
            }
            res.push_back(ok ? nums[i + k - 1] : -1);
        }
        return res;
    }
};
```

### Python

```python
class Solution:
    def resultsArray(self, nums: list[int], k: int) -> list[int]:
        n = len(nums)
        res = []
        for i in range(n - k + 1):
            ok = all(nums[j] == nums[j - 1] + 1 for j in range(i + 1, i + k))
            res.append(nums[i + k - 1] if ok else -1)
        return res
```

## 8. 边界情况与易错点

1. **`k == 1`**：每个单元素窗口都合法，应输出 `nums` 本身；不要把"没有相邻对"误判成不合法。
2. **`k == n`**：只有首尾一个窗口，注意循环上界与下标 `n - 1` 的对应关系。
3. **全相同元素**：相邻差为 $0$，全部窗口不合法（示例 2），返回值全是 $-1$。
4. **递减但值域连续**：如 `[3,2,1]`，最大值减最小值加一等于长度，但方向相反，必须返回 $-1$——判据要检查"顺序"，不能只检查"值域"。
5. **不要先排序**：排序会破坏"依次"这一位置信息，无法再判断是否逐个 $+1$。
6. **提前 break**：一旦发现断点就跳出内层循环，否则可能在后续元素上"凑巧"满足 $+1$ 而被误判为合法。
7. **数据范围陷阱**：$nums[i]$ 可达 $10^5$，但本题只需比较，不存在溢出；若后续统计和值需注意用 `long long`。
