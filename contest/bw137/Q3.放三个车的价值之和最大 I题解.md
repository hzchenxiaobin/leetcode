# LeetCode 放三个车的价值之和最大 I 题解

## 1. 题目概述

- **标题 / 题号**：放三个车的价值之和最大 I（#3256，hard）
- **链接**：https://leetcode.cn/problems/maximum-value-sum-by-placing-three-rooks-i/
- **来源**：LeetCode 第 137 场双周赛 Q3
- **难度**：困难
- **标签**：数组、动态规划、枚举、矩阵

**题意**：给定 $m \times n$ 的整数矩阵 `board`，`board[i][j]` 是格子 $(i,j)$ 的价值。在棋盘上放**三个车**，要求两两之间都**无法互相攻击**（即任意两个车不在同一行、也不在同一列），求三个格子价值之和的最大值。

换句话说：选出三个格子 $(i_1,j_1), (i_2,j_2), (i_3,j_3)$，使得 $i_1, i_2, i_3$ 两两不同、$j_1, j_2, j_3$ 两两不同，最大化价值之和。

**约束**：

- $3 \le m = board.length \le 100$
- $3 \le n = board[i].length \le 100$
- $-10^9 \le board[i][j] \le 10^9$

注意价值**可以为负**：不存在"不选"的选项，必须恰好放三个车，所以答案是三个数之和，可能为负。

## 2. 示例

**示例 1**

```text
输入：board = [[-3,1,1,1],[-3,1,-3,1],[-3,2,1,1]]
输出：4
解释：选择 (0,2), (1,3), (2,1)，价值 1 + 1 + 2 = 4。
     三行三列互不相同，两两不攻击。
```

**示例 2**

```text
输入：board = [[1,2,3],[4,5,6],[7,8,9]]
输出：15
解释：选择 (0,0), (1,1), (2,2)，价值 1 + 5 + 9 = 15（主对角线）。
```

**示例 3**

```text
输入：board = [[1,1,1],[1,1,1],[1,1,1]]
输出：3
解释：任意三个不同行不同列的格子，价值之和都是 3。
```

## 3. 解题思路

### 3.1 暴力思路

最朴素的枚举是选出三个格子：$O\big((mn)^3\big)$，$m=n=100$ 时约 $10^{12}$，不可行。

稍好一点的思路是枚举三行再枚举三列：$O\big(\binom{m}{3}\binom{n}{3}\big) \approx 1.6 \times 10^5 \times 1.6 \times 10^5 = 2.6 \times 10^{10}$，仍然不可行。

瓶颈在于：一旦确定了三行，三列的选法数量是 $n^3$ 级别，而实际上每行只需要这几个列中"最值钱的那几个"。

### 3.2 核心观察：每行只需保留前 3 大

![每行只保留前 3 大的格子](images/bw137_q3_top3_reduction.svg)

**观察**：在最优方案中，每个车都落在其所在行的**前 3 大**格子里。

理由：一行里最多只放一个车（否则同行互相攻击）。固定最优方案的其余两个车，它们最多占用 2 个列；于是在本行的前 3 大格子里，**至少有一个的列没被占用**。把本行的车换成这个格子，行不变、与另两个车的行仍不同，列也与它们不同，合法性保持，而价值只增不减。

由此把候选从 $m \times n$ 压缩到不超过 $3m$（$m \le 100$ 时最多 300 个），代价是一次 $O(m n \log n)$ 的行内排序。

### 3.3 算法流程

![枚举行三元组，每组 27 种取法](images/bw137_q3_rowtriple_enum.svg)

```text
1. 对每一行，取出价值前 3 大的 (价值, 列号)，记作 top[i]（按价值降序）
2. ans = -∞
3. for 行三元组 (a, b, c)，a < b < c:
       for (va, ca) in top[a]:
           for (vb, cb) in top[b]:
               若 ca == cb: continue
               for (vc, cc) in top[c]:
                   若 cc == ca 或 cc == cb: continue
                   ans = max(ans, va + vb + vc)
4. 返回 ans
```

每组行三元组最多检查 $3 \times 3 \times 3 = 27$ 种取法，其中列号两两不同的只有 $3! = 6$ 种，其余被筛掉。

### 3.4 示例演算

![示例 2 演算：三条"广义对角"同分](images/bw137_q3_walkthrough.svg)

对示例 2 的 `board = [[1,2,3],[4,5,6],[7,8,9]]`：

| 行 | 前 3 大（价值, 列） |
|----|--------------------|
| 0 | (3, 2), (2, 1), (1, 0) |
| 1 | (6, 2), (5, 1), (4, 0) |
| 2 | (9, 2), (8, 1), (7, 0) |

行三元组只有 $\{0,1,2\}$ 一组。列号两两不同的取法共 6 种，其中：

| 取法 | 价值之和 |
|------|---------|
| (0,0)、(1,1)、(2,2) | 1 + 5 + 9 = 15 |
| (0,2)、(1,1)、(2,0) | 3 + 5 + 7 = 15 |
| (0,1)、(1,2)、(2,0) | 2 + 6 + 7 = 15 |

同为 15，取最大即 15，与示例一致。

## 4. 算法细节

1. **只存 3 个而不是 4 个**：每行最多被另外两个车占用 2 个列，前 3 大即可保证至少一个可用，因此每行保留 3 个是最省的。
2. **排序方式**：把每行的 $(board[i][j], j)$ 按价值降序排序，取前 3。C++ 用 `sort` + `greater`，Python 用 `sorted(..., reverse=True)[:3]`。
3. **列号判重是核心**：必须检查 `ca != cb`、`cc != ca`、`cc != cb` 三个不等式；漏掉任何一个都会得出"同列两个车"的非法方案。
4. **用 64 位整数**：单个格子可达 $10^9$，三数之和可达 $3 \times 10^9$，超过 `int` 上界，必须用 `long long`（Python 无此问题）。
5. **答案初值**：用极小值（C++ `LLONG_MIN`，Python `None`）而不是 0，因为答案可能为负。
6. **行数恰好为 3**：此时只有一个行三元组，算法退化为对 $3 \times 3$ 的 27 种取法扫描。

## 5. 正确性证明

**引理 1（行内候选剪枝）**：存在一个最优方案，其中每个车所在的格子，都是它所在行的前 3 大格子之一。

**证明**：取任一最优方案，设其中一个车在 $(r, c)$。方案中另外两个车分别在某两列 $c_1 \ne c_2$（都不等于 $c$，否则同列攻击）。把第 $r$ 行的全部格子按价值降序排列，前 3 大记为 $g_1, g_2, g_3$。由于 $c_1, c_2$ 最多排除 2 个列，$g_1, g_2, g_3$ 中至少有一个的列不是 $c_1$ 也不是 $c_2$，记为 $g_t = (r, c')$。用 $(r, c')$ 替换 $(r, c)$：

- 行仍为 $r$，与另外两个车的行不同；
- 列 $c' \notin \{c_1, c_2\}$，与另外两个车的列不同；
- 价值 $val(g_t) \ge val(g_1) \ge \dots \ge val(g_3) \ge val(r,c)$（因为 $(r,c)$ 只是本行某一格，而 $g_1$ 是本行最大），所以总和不变小。

替换后方案仍合法且不劣，重复对另外两个车做同样替换即可。∎

**引理 2（枚举完备性）**：枚举所有行三元组 $(a,b,c)$，再枚举 $top[a] \times top[b] \times top[c]$ 中列号两两不同的取法，覆盖了全部满足条件的候选方案。

**证明**：任取一个合法方案，三行互不相同，不妨排序为 $a < b < c$，它必然出现在某个行三元组中；由引理 1 可把它改造成三个格子都在对应行的前 3 大里，于是它是 $top[a] \times top[b] \times top[c]$ 的一个元素；合法方案的三列互不相同，恰好通过三个不等式的过滤。而每个通过过滤的三元组都对应一个真实的合法放置（三行来自不同行三元组元素，三列经检查互异）。∎

**定理**：算法返回的值等于所有合法放置方案中价值之和的最大值。

**证明**：由引理 2，算法考察的候选集合包含一个不劣于最优解的方案，故 `ans` $\ge$ 最优值；又算法中每个被计入 `ans` 的三元组都满足"三行互异、三列互异"，是合法的放置方案，故 `ans` $\le$ 最优值。两者夹逼得 `ans` 等于最优值。∎

## 6. 复杂度分析

- **时间**：预处理每行取前 3 大，共 $O(m n \log n)$；枚举 $\binom{m}{3}$ 个行三元组，每组最多 $27$ 次赋值与比较，共 $O(m^3)$。$m = n = 100$ 时约 $1.6 \times 10^5 \times 27 \approx 4.4 \times 10^6$ 次比较，远快于时限。
- **空间**：$O(m)$ 存放每行的前 3 大（严格说是 $O(3m)$），不计输入矩阵。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long maximumValueSum(vector<vector<int>>& board) {
        int m = (int)board.size(), n = (int)board[0].size();
        vector<vector<pair<long long,int>>> top(m);
        for (int i = 0; i < m; i++) {
            vector<pair<long long,int>> v;
            v.reserve(n);
            for (int j = 0; j < n; j++) v.push_back({(long long)board[i][j], j});
            sort(v.begin(), v.end(), greater<pair<long long,int>>());
            if ((int)v.size() > 3) v.resize(3);
            top[i] = v;
        }
        long long ans = LLONG_MIN;
        for (int a = 0; a < m; a++)
            for (int b = a + 1; b < m; b++)
                for (int c = b + 1; c < m; c++)
                    for (auto& x : top[a])
                        for (auto& y : top[b]) {
                            if (x.second == y.second) continue;
                            for (auto& z : top[c]) {
                                if (z.second == x.second || z.second == y.second) continue;
                                ans = max(ans, x.first + y.first + z.first);
                            }
                        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maximumValueSum(self, board: list[list[int]]) -> int:
        m, n = len(board), len(board[0])
        top = [sorted(((board[i][j], j) for j in range(n)), reverse=True)[:3] for i in range(m)]
        ans = None
        for a in range(m):
            for b in range(a + 1, m):
                for c in range(b + 1, m):
                    for va, ca in top[a]:
                        for vb, cb in top[b]:
                            if ca == cb:
                                continue
                            for vc, cc in top[c]:
                                if cc == ca or cc == cb:
                                    continue
                                s = va + vb + vc
                                if ans is None or s > ans:
                                    ans = s
        return ans
```

## 8. 边界情况与易错点

1. **答案可能为负**：全负矩阵时三个车都得放上去，取"最不亏"的三个数，初值必须用负无穷而不是 0。
2. **`int` 溢出**：三个 $10^9$ 相加是 $3 \times 10^9 > 2^{31}-1$，必须 `long long`；用 `int` 会得到错误答案且难以察觉。
3. **列号判重漏写**：只检查 `ca != cb` 而忘了 `cc` 与它们的比较，会接受同列方案，答案偏大。
4. **每行只留 3 个**：留 2 个不够（另外两个车可能正好占掉这 2 列），留 3 个刚好；留 4 个不会错但浪费。
5. **`m == 3` 或 `n == 3`**：行三元组或列选择唯一化，注意循环边界仍然正确（`b = a+1`、`c = b+1`）。
6. **不要假设行数小于列数**：本题行列对称，但如果做转置优化需保证 $m \le n$ 前提成立。
7. **同一行出现重复价值**：如示例 3 全 1 矩阵，`sort` 会把不同列的同值格子都保留，判重只看列号，不受影响。
