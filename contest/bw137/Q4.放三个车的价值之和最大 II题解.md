# LeetCode 放三个车的价值之和最大 II 题解

## 1. 题目概述

- **标题 / 题号**：放三个车的价值之和最大 II（#3257，hard）
- **链接**：https://leetcode.cn/problems/maximum-value-sum-by-placing-three-rooks-ii/
- **来源**：LeetCode 第 137 场双周赛 Q4
- **难度**：困难
- **标签**：数组、动态规划、枚举、矩阵

**题意**：给定 $m \times n$ 的整数矩阵 `board`，在棋盘上放**三个车**，要求两两之间都不能互相攻击（不在同一行、也不在同一列），求三个格子价值之和的最大值。

即选出三个格子 $(i_1,j_1),(i_2,j_2),(i_3,j_3)$，三行互不相同、三列互不相同，最大化价值之和。价值可以为负，且必须恰好放三个车（不能"不选"）。

**约束**：

- $3 \le m = board.length \le 500$
- $3 \le n = board[i].length \le 500$
- $-10^9 \le board[i][j] \le 10^9$

与同场 Q3 的**唯一区别**是数据范围从 $100$ 放大到 $500$——但正是这一放大让 Q3 的 $O(m^3)$ 算法失效。

## 2. 示例

**示例 1**

```text
输入：board = [[-3,1,1,1],[-3,1,-3,1],[-3,2,1,1]]
输出：4
解释：选择 (0,2), (1,3), (2,1)，价值 1 + 1 + 2 = 4。
```

**示例 2**

```text
输入：board = [[1,2,3],[4,5,6],[7,8,9]]
输出：15
解释：选择 (0,0), (1,1), (2,2)，价值 1 + 5 + 9 = 15。
```

**示例 3**

```text
输入：board = [[1,1,1],[1,1,1],[1,1,1]]
输出：3
解释：任意三个不同行不同列的格子，价值之和都是 3。
```

## 3. 解题思路

### 3.1 暴力思路

同场 Q3 的做法：每行取前 3 大，再枚举行三元组，每组尝试 27 种取法。

- 复杂度 $O\big(\binom{m}{3} \times 27\big)$。
- $m = 100$ 时约 $4.4 \times 10^6$，Q3 秒过；
- $m = 500$ 时 $\binom{500}{3} \approx 2.07 \times 10^7$，乘 27 约 $5.6 \times 10^8$，**超出时限**。

所以必须放弃"枚举行三元组"，换一个视角：**固定一个锚点车，再去精确地找另外两个**。

![从 I 版到 II 版：数据范围放大后必须换算法](images/bw137_q4_scale.svg)

### 3.2 核心观察：锚点 + 按列聚合，跳过"列堆积"陷阱

![陷阱：同一列的高值候选彼此冲突](images/bw137_q4_column_trap.svg)

两条剪枝依然成立：

- **行剪枝**：每个车都在其所在行的前 3 大里（另外两个车最多占用 2 列）。
- **列剪枝**：每个车也都在其所在列的前 3 大里（另外两个车最多占用 2 行）。

于是候选集合 $C$ 只有不超过 $3m$ 个格子。

**陷阱**：如果固定锚点后简单地"按价值取前 4 个再两两配对"，会失败。例如某列堆着一串高值（$200, 190, 180, 170$），它们彼此冲突（同列），前 4 个配不出任何合法对，而真正的最优解可能是 $200 + 100 + 2$。**必须先按列聚合、每列只贡献自己的前几个，再做配对**。

正确的配对做法：固定锚点 $a=(i,j)$ 后，令 $D$ 为 $C$ 中去掉行 $i$、去掉列 $j$ 的候选集。对每个列 $c$，记它在 $D$ 中的前 3 大（来自不同行）为 $b_1(c), b_2(c), b_3(c)$，按 $b_1$ 降序给列排名。此时：

- 最优配对一定包含"排名第一的列的某个格子"；
- 配对的另一半，一定落在"排名前 5 的列"的前 3 大之内。

（严格证明见第 5 节引理 3。）因此每个锚点只需在"前 5 列 × 每列 3 个 = 至多 15 个候选"里两两枚举，共 $\binom{15}{2} = 105$ 对。

### 3.3 算法流程

![II 版算法：锚点 + 每列前 3 大 + 前 5 列配对](images/bw137_q4_algorithm_flow.svg)

```text
1. 每行取价值前 3 大，得到候选集 C（≤ 3m 个格子），同时记录每个格子的行、列、价值
2. 每列也取前 3 大（来自不同行），用于快速查询
3. ans = -∞
4. for 每个锚点 a = (i, j) ∈ C:
       对每一列 c ≠ j，取它在「排除行 i」后的前 3 大格子
       若该列没有可用格子则跳过
       按列首价值降序，只保留前 5 列
       把这 5 列的至多 15 个格子展开成候选表 cand
       for cand 中任意两个格子 x, y:
           若 x 与 y 的行相同或列相同: continue
           ans = max(ans, val(a) + val(x) + val(y))
5. 返回 ans
```

### 3.4 示例演算

以示例 2 的 `board = [[1,2,3],[4,5,6],[7,8,9]]` 为例，取锚点 $a = (0,0)$（价值 1）：

- 排除行 0 与列 0 后，剩下的列是列 1、列 2；
- 列 2 的前 3 大：$(9, \text{行}2)$、$(6, \text{行}1)$、$(3, \text{行}0\text{ 已排除})$ → 得 $(9,\text{行}2), (6,\text{行}1)$；
- 列 1 的前 3 大：$(8,\text{行}2), (5,\text{行}1)$；
- 按列首价值排序：列 2（$b_1=9$）、列 1（$b_1=8$），共 4 个候选；
- 两两配对时，$(9,\text{行}2)$ 与 $(8,\text{行}2)$ **同行冲突**，必须退一步取次大：
  - $(9,\text{行}2) + (5,\text{行}1) = 14$
  - $(6,\text{行}1) + (8,\text{行}2) = 14$

于是候选总和为 $1 + 14 = 15$，与答案一致。这个例子正好说明两个实现要点：**每列要留前 3 大（而不是只留最大）**，以及**配对必须真的两两检查行列冲突**。

## 4. 算法细节

1. **预计算每列前 4 大**：查询时要"排除锚点所在行"，所以每列预存 4 个（来自不同行）就够——去掉 1 行后仍剩 3 个，正好满足"每列前 3 大"的需求。
2. **锚点枚举范围**：锚点取自候选集 $C$（每行前 3 大），共不超过 $3m \le 1500$ 个，而不是整个 $m \times n$。
3. **每列保留前 3 大（预计算时存 4 个）**：配对时每列只会被用到一个格子，看似前 2 个就够；但引理 3 的替换论证需要"排除锚点所在行后仍能取到该列在 $D$ 中的最大值"，故 $D$ 中每列要留 3 个，而 $D$ 比 $C$ 少一行，因此预计算时每列存 4 个（来自不同行）即可。
4. **前 5 列的选择**：按"该列在 $D$ 中的首值"降序做部分选择（C++ 用 `nth_element` + 局部排序，Python 用 `sort`），只保留 5 个，随后展开成至多 15 个格子。
5. **判重两个维度**：候选来自不同列（构造时已按列分组），但同一列可能有 3 个格子，所以仍需检查列号；行号更必须检查。
6. **64 位整数**：三数之和可达 $3 \times 10^9$，C++ 必须 `long long`，答案初值用 `LLONG_MIN`；Python 无溢出问题，用 `None` 表示"尚未取到"。
7. **时间复杂度常数**：每个锚点的工作量是"扫一遍列（$n$）+ 105 次配对"，所以总工作量约 $3m \times (n + 105)$，$m=n=500$ 时不到 $10^6$ 量级。

## 5. 正确性证明

**引理 1（行内剪枝）**：存在最优方案，使每个车都是其所在行的前 3 大格子之一。

**证明**：取最优方案中的一个车 $(r,c)$，另外两个车占用的列记为 $c_1 \ne c_2$。把第 $r$ 行的格子按价值降序排，前 3 大中至少有一个的列不等于 $c_1, c_2$（最多 2 个列被排除），记作 $(r, c')$。替换后行仍为 $r$、列 $c'$ 与另两个车不同，且 $val(r,c') \ge val(r,c)$，故方案合法且不劣。∎

**引理 2（列内剪枝）**：存在最优方案，使每个车都是其所在列的前 3 大格子之一。

**证明**：与引理 1 对偶：另外两个车最多占用 2 行，故本列前 3 大中至少有一个的行没被占用，替换后合法且不劣。∎

**引理 3（配对引理）**：设 $D$ 是一个候选集合，其中每行至多 3 个格子；对每一列，只保留它在 $D$ 中价值最大的 3 个格子（来自不同行）。对每列 $c$ 记 $b_1(c)$ 为其最大值、$b_2(c)$ 为与之不同行的次大值、$b_3(c)$ 为再次者，并按 $b_1$ 降序排列各列。则 $D$ 中"行互异、列互异"的最大权二格组，可由以下方式取得：取 $b_1$ 排名前 5 的列，各取其前 3 大格子，在其中任取两个满足行列互异的格子。

**证明**：设最优二格组为 $\{u, v\}$，$u \in X$、$v \in Y$、$X \ne Y$。

*第一步：可设其中一格来自排名第一的列 $Z_1$。* 若 $Z_1 \in \{X, Y\}$，已成立。否则 $b_1(Z_1) \ge b_1(X) \ge val(u)$ 且 $b_1(Z_1) \ge b_1(Y) \ge val(v)$。设 $g_1$ 为 $Z_1$ 的最大值格子（行 $\rho$）。若 $\rho \ne row(u)$，则 $\{g_1, u\}$ 合法（列 $Z_1 \ne X$，行不同），且 $val(g_1) + val(u) \ge val(v) + val(u)$；若 $\rho = row(u)$，则因 $row(u) \ne row(v)$ 有 $\rho \ne row(v)$，$\{g_1, v\}$ 合法且 $val(g_1) + val(v) \ge val(u) + val(v)$。两种情形都得到不劣的、含 $Z_1$ 格子的二格组。

*第二步：另一半落在前 5 列内。* 固定第一步得到的格子 $g$（列 $Z_1$，行 $\rho$）。另一半必须在 $D' = D \setminus \{\text{列 } Z_1, \text{行 } \rho\}$ 中取。设 $Z^*$ 是 $D'$ 中"列内最大值"最大的列，$g^*$ 为 $Z^*$ 在 $D'$ 中的最大格子。则 $D'$ 中任何格子都不优于 $g^*$，且 $g^*$ 与 $g$ 行列皆不同（列 $Z^* \ne Z_1$，行 $\ne \rho$），故可把另一半换成 $g^*$，值不减。

下面论证 $Z^*$ 属于原 $b_1$ 排名的前 5 列。从 $D$ 到 $D'$ 只删除了 1 列与 1 行。删除行 $\rho$ 会影响那些"在行 $\rho$ 有格子"的列的列内最大值；由条件每行至多 3 个格子，故受影响的列至多 3 个。于是原排名中除 $Z_1$ 与这至多 3 个受影响列之外，其余列在 $D'$ 中的首值与原来的 $b_1$ 相同、相对次序也不变。若 $Z^*$ 不在原排名前 5，则前 5 列中除 $Z_1$ 与至多 3 个受影响列外，至少还剩 1 个未受影响的列 $Z_k$（$k \le 5$），它在 $D'$ 中的首值 $= b_1(Z_k) \ge b_1(Z^*) = Z^*$ 在 $D'$ 中的首值，与 $Z^*$ 是 $D'$ 中最优列矛盾。故 $Z^*$ 必在前 5 列内。

最后，$g^*$ 是 $Z^*$ 在 $D'$ 中的最大格子，而 $D'$ 相对 $D$ 只少了一行，故 $g^*$ 必在该列前 2 大之内，自然也在前 3 大之内。于是最优二格组可被"前 5 列 × 每列前 3 大"这一候选集合覆盖。∎

**定理**：算法返回值等于合法放置方案中价值之和的最大值。

**证明**：记最优三格组为 $T^*$，由引理 1、2 可设 $T^* \subseteq C$。枚举锚点时取 $a \in T^*$（必被枚举到），令 $D$ 为 $C$ 去掉 $a$ 的行与列，则 $T^* \setminus \{a\}$ 是 $D$ 中的合法二格组，由引理 3 算法所取的候选集合中存在一个权值不低于它的二格组 $\{x,y\}$，于是 `ans` $\ge val(a) + val(x) + val(y) \ge val(T^*)$。

另一方面，算法中每次更新都基于"三行互异、三列互异"的三个格子（锚点与 $D$ 中的二格组本就避开了锚点的行列，二格组内部又检查了行列），因此每个被计入的值都是一个合法放置方案的价值之和，故 `ans` $\le$ 最优值。两者夹逼，`ans` 等于最优值。∎

## 6. 复杂度分析

- **预处理**：每行排序取前 3 大，$O(m n \log n)$；每列从候选集中取前 3 大，$O(m \log m)$ 级别。
- **主循环**：枚举至多 $3m$ 个锚点；每个锚点扫一遍 $n$ 列构造候选（$O(n)$），选出前 5 列（C++ 用 `nth_element` 为 $O(n)$，Python 用 `sort` 为 $O(n \log n)$），再枚举至多 $\binom{15}{2} = 105$ 对（$O(1)$）。合计 $O(m n \log n)$，$m = n = 500$ 时不到 $10^6$ 量级的基本操作。
- **空间**：$O(m + n)$ 存放每列/每行的前几个候选，候选表长度不超过 15，可忽略。

## 7. 参考代码

### C++

```cpp
class Solution {
    struct ColCells {
        long long b1;
        int col;
        vector<pair<long long,int>> cells;  // (value, row)，按值降序
    };
public:
    long long maximumValueSum(vector<vector<int>>& board) {
        int m = (int)board.size(), n = (int)board[0].size();

        // 每行前 3 大：(value, col)
        vector<vector<pair<long long,int>>> rowTop(m);
        for (int i = 0; i < m; i++) {
            vector<pair<long long,int>> v;
            v.reserve(n);
            for (int j = 0; j < n; j++) v.push_back({(long long)board[i][j], j});
            sort(v.begin(), v.end(), greater<pair<long long,int>>());
            if ((int)v.size() > 3) v.resize(3);
            rowTop[i] = v;
        }

        // 每列前 4 大：(value, row)
        vector<vector<pair<long long,int>>> colTop(n);
        for (int i = 0; i < m; i++)
            for (auto& p : rowTop[i]) colTop[p.second].push_back({p.first, i});
        for (int j = 0; j < n; j++) {
            sort(colTop[j].begin(), colTop[j].end(), greater<pair<long long,int>>());
            if ((int)colTop[j].size() > 4) colTop[j].resize(4);
        }

        long long ans = LLONG_MIN;
        vector<ColCells> cols;
        cols.reserve(n);
        vector<pair<long long,int>> cand;  // (value, row)
        vector<int> candCol;

        for (int i = 0; i < m; i++) {
            for (auto& anchor : rowTop[i]) {
                long long va = anchor.first;
                int ca = anchor.second;

                cols.clear();
                for (int j = 0; j < n; j++) {
                    if (j == ca) continue;
                    ColCells cc;
                    cc.b1 = LLONG_MIN;
                    cc.col = j;
                    for (auto& p : colTop[j]) {
                        if (p.second == i) continue;
                        cc.cells.push_back(p);
                        if ((int)cc.cells.size() == 3) break;
                    }
                    if (cc.cells.empty()) continue;
                    cc.b1 = cc.cells[0].first;
                    cols.push_back(std::move(cc));
                }
                if ((int)cols.size() < 2) continue;

                // 只保留 b1 最大的 5 列（部分选择，避免整表排序）
                int take = min(5, (int)cols.size());
                nth_element(cols.begin(), cols.begin() + (take - 1), cols.end(),
                            [](const ColCells& A, const ColCells& B) { return A.b1 > B.b1; });
                sort(cols.begin(), cols.begin() + take,
                     [](const ColCells& A, const ColCells& B) { return A.b1 > B.b1; });

                cand.clear();
                candCol.clear();
                for (int t = 0; t < take; t++)
                    for (auto& p : cols[t].cells) {
                        cand.push_back(p);
                        candCol.push_back(cols[t].col);
                    }

                int L = (int)cand.size();
                for (int x = 0; x < L; x++)
                    for (int y = x + 1; y < L; y++) {
                        if (cand[x].second == cand[y].second) continue;
                        if (candCol[x] == candCol[y]) continue;
                        long long s = va + cand[x].first + cand[y].first;
                        if (s > ans) ans = s;
                    }
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maximumValueSum(self, board: list[list[int]]) -> int:
        m, n = len(board), len(board[0])
        row_top = [sorted(((board[i][j], j) for j in range(n)), reverse=True)[:3] for i in range(m)]

        col_top = [[] for _ in range(n)]
        for i in range(m):
            for v, j in row_top[i]:
                col_top[j].append((v, i))
        for j in range(n):
            col_top[j].sort(reverse=True)
            del col_top[j][4:]

        ans = None
        for i in range(m):
            for va, ca in row_top[i]:
                cols = []
                for j in range(n):
                    if j == ca:
                        continue
                    cells = [(v, r) for (v, r) in col_top[j] if r != i][:3]
                    if cells:
                        cols.append((cells[0][0], j, cells))
                if len(cols) < 2:
                    continue
                cols.sort(key=lambda t: -t[0])
                cand = []
                for _, j, cells in cols[:5]:
                    for v, r in cells:
                        cand.append((v, r, j))
                L = len(cand)
                for x in range(L):
                    vx, rx, cx = cand[x]
                    for y in range(x + 1, L):
                        vy, ry, cy = cand[y]
                        if rx == ry or cx == cy:
                            continue
                        s = va + vx + vy
                        if ans is None or s > ans:
                            ans = s
        return ans
```

## 8. 边界情况与易错点

1. **"按价值取前几个再配对"会错**：如第 3.2 节的列堆积反例，前 4 个可能全在同一列。必须按列聚合，每列只出自己的前 3 大。
2. **每列只预存 4 个**：查询要排除锚点所在行，去掉 1 个后必须还剩至少 3 个；只存 3 个会让某些列在排除后凑不满前 3 大。
3. **列数不足**：锚点所在列被排除后，若剩余有候选的列少于 2，则这个锚点不可能构成三车方案，直接跳过（`n >= 3` 时一般不会发生，但排除后仍要判断）。
4. **`int` 溢出**：三数之和可达 $3 \times 10^9$，C++ 必须 `long long`，最小值初值用 `LLONG_MIN`。
5. **同行/同列判重**：候选来自至多 5 列，同列可能贡献 3 个格子，所以列号与行号**都要**检查，漏一个就非法。
6. **锚点必须取自候选集**：若把锚点枚举成整个矩阵的 $m n$ 个格子，复杂度会退化到 $O(m n (n + 105))$，虽然仍可接受但偏离了"每行前 3 大"的剪枝本意，也更容易写错。
7. **并列价值**：示例 3 全 1 矩阵里排序结果与列号无关，判重只看行列，结果仍是 3。
8. **全负矩阵**：必须恰好放三个车，答案可能为负，不要用 0 作初值。
