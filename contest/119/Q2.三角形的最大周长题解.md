# LeetCode 三角形的最大周长 题解

## 1. 题目概述

- **标题 / 题号**：三角形的最大周长（#976，easy）
- **链接**：https://leetcode.cn/problems/largest-perimeter-triangle/
- **来源**：LeetCode 第 119 场周赛 Q2
- **难度**：简单
- **标签**：贪心、数组、数学、排序

**题意**：给定正数数组 `nums`（代表长度），从中选**三条边**组成面积不为零的三角形，返回能组成的三角形的**最大周长**；若无法组成任何非退化三角形，返回 `0`。

**约束**：

- $3 \le nums.length \le 10^4$
- $1 \le nums[i] \le 10^6$

> 💡 面积不为零 $\iff$ 三边**严格**满足三角不等式：任两边之和大于第三边。等号成立（退化三角形）不算。

## 2. 示例

**示例 1**

```text
输入：nums = [2,1,2]
输出：5
解释：排序后 1,2,2，1+2 > 2 成立，周长 1+2+2 = 5。
```

**示例 2**

```text
输入：nums = [1,2,1,10]
输出：0
解释：排序后 1,1,2,10。1+1 = 2 不满足严格大于（退化），
      其余组合要么含 10（1+1 < 10），要么就是 1,2,10 这类更不可能的组合。
      没有任何组合能构成非退化三角形，返回 0。
```

**示例 3**

```text
输入：nums = [3,6,2,3]
输出：8
解释：排序后 2,3,3,6。从最大的 6 开始：3+3 = 6 不严格大于 6，失败；
      退一格看 3,3,2：2+3 > 3 ✓，周长 8。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有三元组 $(i,j,k)$，判定三角不等式，取周长最大：$O(n^3)$，$n = 10^4$ 时 $10^{12}$ 次，完全不可行。稍加优化（固定两边后二分第三边）能到 $O(n^2 \log n)$，仍然慢，而且没抓住「周长最大」的结构。

### 3.2 核心观察：最大周长一定来自「相邻的三个大数」

![排序后从右往左，一次只检查相邻的三个数](images/wc119_q2_sorted_triple.svg)

先把 `nums` **升序**排序。设排序后数组为 $a_0 \le a_1 \le \dots \le a_{n-1}$，考察最大的三个数 $a_{n-3}, a_{n-2}, a_{n-1}$：

- 若 $a_{n-3} + a_{n-2} > a_{n-1}$，它们就构成三角形，且周长是**所有可能三元组中最大的**（因为这是三个最大的数之和），直接返回；
- 若不成立，即 $a_{n-3} + a_{n-2} \le a_{n-1}$：那么**任何**含 $a_{n-1}$ 的三元组都不可能是三角形。因为另外两边最多是 $a_{n-2}, a_{n-3}$，其和都超不过 $a_{n-1}$，更小的两边只会更差。于是 $a_{n-1}$ 可以从候选里**永久剔除**。

剔除后剩下的最大三个数变成 $a_{n-4}, a_{n-3}, a_{n-2}$，重复同样的判断。每轮只需要一次比较，总计 $O(n)$ 次判断（排序占主导）。

### 3.3 算法流程

![贪心剔除链：不满足就丢掉当前最大值，最多扫一遍](images/wc119_q2_greedy_chain.svg)

```text
1. 升序排序 nums
2. for i = n-1 down to 2:
       若 nums[i-2] + nums[i-1] > nums[i]:
           返回 nums[i-2] + nums[i-1] + nums[i]
3. 返回 0
```

### 3.4 示例演算

对示例 3 的 `nums = [3,6,2,3]` 排序得 `a = [2,3,3,6]`：

| $i$ | 三元组 $(a_{i-2}, a_{i-1}, a_i)$ | 判定 | 动作 |
|---|---|---|---|
| 3 | (3, 3, 6) | $3+3 = 6$，不严格大于 ✗ | 剔除 6，$i$ 减一 |
| 2 | (2, 3, 3) | $2+3 = 5 > 3$ ✓ | 返回 $2+3+3 = 8$ |

结果为 8，与示例一致。示例 2 的 `a = [1,1,2,10]`：$i=3$ 时 $1+2=3 \le 10$ ✗；$i=2$ 时 $1+1=2 \le 2$ ✗（等号不成立），循环结束，返回 0。

## 4. 算法细节

1. **必须严格大于**：$a + b = c$ 是退化三角形（三点共线），面积为 0，题目明确排除；写成 `>=` 会错。
2. **从右往左扫**：这样第一个成功的三元组就是周长最大的，不用比较所有候选。
3. **只需检查相邻的三个**：不需要考虑「跳过某个元素」的组合——理由见引理 2。
4. **升序 + 只判一次不等式**：因为 $a_{i-2} \le a_{i-1} \le a_i$，只需验证 $a_{i-2} + a_{i-1} > a_i$ 这一条，另外两条（$a_{i-2}+a_i > a_{i-1}$、$a_{i-1}+a_i > a_{i-2}$）自动成立。
5. **溢出**：$nums[i] \le 10^6$，三数之和 $\le 3 \times 10^6$，`int` 安全。
6. **Python 排序**：`nums.sort()` 原地排序；若不想修改输入，用 `sorted(nums)`。

## 5. 正确性证明

**引理 1（只需判一条不等式）**：对 $a \le b \le c$，三边构成非退化三角形 $\iff a + b > c$。

**证明**：「$\Rightarrow$」由三角不等式直接得到。「$\Leftarrow$」：已知 $a + b > c$，需证 $a + c > b$ 与 $b + c > a$。由 $c \ge b$ 得 $a + c \ge a + b > c \ge b$，故 $a + c > b$；由 $b \ge a$ 且 $c > 0$ 得 $b + c > a$。三条不等式全部严格成立。∎

**引理 2（剔除准则）**：设 $a_0 \le a_1 \le \dots \le a_{n-1}$。若 $a_{n-3} + a_{n-2} \le a_{n-1}$，则不存在含 $a_{n-1}$ 的非退化三角形。

**证明**：任取含 $a_{n-1}$ 的三元组 $\{a_{n-1}, a_p, a_q\}$，其中 $p, q < n-1$ 且 $p \ne q$。不妨 $a_q \le a_p$，则 $a_p \le a_{n-2}$、$a_q \le a_{n-3}$（因为除 $a_{n-1}, a_{n-2}$ 外最大的元素就是 $a_{n-3}$）。于是 $a_p + a_q \le a_{n-3} + a_{n-2} \le a_{n-1}$，由引理 1，该三边不能构成非退化三角形。∎

**引理 3（最大候选）**：若 $a_{n-3} + a_{n-2} > a_{n-1}$，则 $\{a_{n-3}, a_{n-2}, a_{n-1}\}$ 的周长是所有合法三元组中最大的。

**证明**：任何三元组的周长都不超过三个最大元素之和 $a_{n-3} + a_{n-2} + a_{n-1}$（其余元素各自不超过对应位置的值）。该三元组本身合法（引理 1），故它取到上界。∎

**定理**：算法返回最大周长；若无解返回 0。

**证明**：算法从 $i = n-1$ 递减，等价于「反复用引理 2 剔除不可能参与解的最大元素」。设第一次成功的位置为 $i^*$，则所有 $> i^*$ 的元素都已被证明不可能出现在任何合法三元组中（引理 2 逐轮应用），而未剔除部分的最大三元素正是 $\{a_{i^*-2}, a_{i^*-1}, a_{i^*}\}$，由引理 3 它是剩余部分的合法解中周长最大的，也就是全局最大。若循环走完没有成功，说明每个元素都被剔除，不存在合法三元组，返回 0 正确。∎

## 6. 复杂度分析

- **时间**：$O(n \log n)$，排序占主导；扫描最多 $n-2$ 次比较，$O(n)$。$n = 10^4$ 时约 $10^4 \times 14$ 次比较。
- **空间**：$O(\log n)$ 排序栈空间（`std::sort` 内省排序）或 $O(1)$ 额外空间（不计输入）；Python 的 `TimSort` 最坏 $O(n)$ 辅助空间。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int largestPerimeter(vector<int>& nums) {
        sort(nums.begin(), nums.end());
        for (int i = (int)nums.size() - 1; i >= 2; i--) {
            if (nums[i - 2] + nums[i - 1] > nums[i]) {
                return nums[i - 2] + nums[i - 1] + nums[i];
            }
        }
        return 0;
    }
};
```

### Python

```python
class Solution:
    def largestPerimeter(self, nums: list[int]) -> int:
        nums.sort()
        for i in range(len(nums) - 1, 1, -1):
            if nums[i - 2] + nums[i - 1] > nums[i]:
                return nums[i - 2] + nums[i - 1] + nums[i]
        return 0
```

## 8. 边界情况与易错点

1. **等号陷阱**：`1,1,2` 是退化三角形（面积 0），必须用严格大于；示例 2 专门考这个。
2. **只有 3 个元素**：循环只跑 $i = 2$ 一轮，要么返回周长要么返回 0，注意循环下界是 `i >= 2` 而不是 `i >= 0`。
3. **全部相等**：如 `[5,5,5]` → 15；`[1,1,1]` → 3。
4. **长边压制**：如 `[1,2,1,10]`，最大元素 10 一旦不满足，立刻被剔除，别写成「跳过 10 后重新排序」——数组已排序，跳过即可。
5. **不要漏掉「剔除后重判」**：剔除最大值后要看新的三元组，而不是直接返回 0。
6. **修改输入**：`sort` 会打乱 `nums`；若调用方复用，先拷贝。
7. **Python 的 `range(len(nums)-1, 1, -1)`**：右端是开区间，正好停在 2，别写成 `range(len(nums)-1, 0, -1)` 导致 `nums[-1]` 之类的越界访问（Python 负索引不报错，但语义全错）。
