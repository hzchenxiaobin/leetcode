# LeetCode 和可被 K 整除的子数组 题解

## 1. 题目概述

- **标题 / 题号**：和可被 K 整除的子数组（#974，medium）
- **链接**：https://leetcode.cn/problems/subarray-sums-divisible-by-k/
- **来源**：LeetCode 第 119 场周赛 Q3
- **难度**：中等
- **标签**：数组、哈希表、前缀和

**题意**：给定整数数组 `nums` 与整数 $k$，返回**非空**连续子数组的个数，要求子数组元素之和能被 $k$ 整除。

**约束**：

- $1 \le nums.length \le 3 \times 10^4$
- $-10^4 \le nums[i] \le 10^4$
- $2 \le k \le 10^4$

> ⚠️ `nums[i]` 可以是**负数**，前缀和的余数在 C++ 里会是负数（`-1 % 5 == -1`），必须先规范化再计数，否则会漏算。

## 2. 示例

**示例 1**

```text
输入：nums = [4,5,0,-2,-3,1], k = 5
输出：7
解释：满足条件的 7 个子数组为
[4,5,0,-2,-3,1], [5], [5,0], [5,0,-2,-3], [0], [0,-2,-3], [-2,-3]
```

**示例 2**

```text
输入：nums = [5], k = 9
输出：0
解释：唯一子数组 [5] 的和 5 不能被 9 整除。
```

**示例 3**

```text
输入：nums = [-1,2,9], k = 2
输出：2
解释：单元素 [2] 的和是 2；整个数组 [-1,2,9] 的和是 10，两者都能被 2 整除。
      前缀和序列为 0, -1, 1, 10，模 2 的余数是 0, 1, 1, 0 —— 两个 0 配一对。
```

## 3. 解题思路

### 3.1 暴力思路

枚举左右端点 $i \le j$，累加 `nums[i..j]` 判定整除性：$O(n^2)$ 或 $O(n^3)$。$n = 3 \times 10^4$ 时 $O(n^2) \approx 4.5 \times 10^8$，超时。

### 3.2 核心观察：前缀和同余 ⟺ 区间和整除

![前缀和取模：同余的前缀就是一段可被 k 整除的区间](images/wc119_q3_prefix_mod.svg)

记前缀和

$$P_0 = 0,\qquad P_j = \sum_{t=1}^{j} nums[t]$$

那么子数组 `nums[i..j]`（$1 \le i \le j$）的和为 $P_j - P_{i-1}$。于是

$$k \mid (P_j - P_{i-1}) \iff P_j \equiv P_{i-1} \pmod{k}$$

**结论：数「和能被 $k$ 整除的子数组」= 数「前缀和数组中同余的元素对」**。从左到右扫一遍，用桶 `cnt[r]` 记录「余数为 $r$ 的前缀和已经出现过几次」，当前前缀余数为 $r$ 时，`cnt[r]` 就是能与当前位置配对、构成合法子数组的数量。

初值 `cnt[0] = 1` 代表空前缀 $P_0 = 0$，这样「从下标 0 开始的子数组」也能被统计到。

### 3.3 算法流程

![算法流程：一次扫描 + 余数桶](images/wc119_q3_negative_mod.svg)

```text
1. cnt[0 .. k-1] = 0；cnt[0] = 1     # 空前缀，余数 0
2. s = 0，ans = 0
3. for x in nums:
       s = ((s + x) % k + k) % k      # 规范化为 [0, k)
       ans += cnt[s]                  # 此前同余的前缀个数
       cnt[s] += 1
4. 返回 ans
```

### 3.4 示例演算

对示例 1 的 `nums = [4,5,0,-2,-3,1]`，$k = 5$，初始 `cnt[0] = 1`：

| 步骤 | $x$ | 前缀和 $s$ | $s \bmod 5$ | `ans += cnt[r]` | `cnt` 变化 |
|---|---|---|---|---|---|
| 1 | 4 | 4 | 4 | +0 | cnt[4] = 1 |
| 2 | 5 | 9 | 4 | +1 | cnt[4] = 2 |
| 3 | 0 | 9 | 4 | +2 | cnt[4] = 3 |
| 4 | -2 | 7 | 2 | +0 | cnt[2] = 1 |
| 5 | -3 | 4 | 4 | +3 | cnt[4] = 4 |
| 6 | 1 | 5 | 0 | +1 | cnt[0] = 2 |

`ans = 0+1+2+0+3+1 = 7` ✓。注意第 4、5 步的中间前缀和出现负数（$7-5$、$4-5$ 等），若不做规范化，`-3 % 5 = -3` 会被当成独立余数，必然算错。

## 4. 算法细节

1. **余数规范化**：C++ 的 `%` 对负数返回负余数，必须 `((s % k) + k) % k`；Python 的 `%` 对正 $k$ 已返回非负余数，无需处理。
2. **`cnt` 用数组而非哈希表**：$k \le 10^4$，直接开长度 $k$ 的桶，$O(k)$ 空间换取 $O(1)$ 查找，比 `unordered_map` 更快更省。
3. **`ans` 的类型**：最坏 $n(n+1)/2 \approx 4.5 \times 10^8$，`int` 上限 $2.1 \times 10^9$ 勉强够；稳妥起见 C++ 用 `long long`，Python 无此问题。
4. **`cnt[0] = 1` 不能忘**：它代表「空前缀」，漏掉会把所有「从下标 0 开始」的合法子数组全部丢掉。
5. **一次扫描搞定**：先 `ans += cnt[s]` 再 `cnt[s]++`，顺序不能反，否则会把自己和自配对，多算 $n$ 个。
6. **`nums[i] = 0`**：零元素不改变前缀和，会让同一个余数连续出现多次，正好被桶计数自然处理（示例 1 里的 `[0]`、`[0,-2,-3]` 都来自这里）。

## 5. 正确性证明

**引理 1（整除等价于同余）**：对任意整数 $A, B$ 与正整数 $k$，$k \mid (A - B) \iff A \equiv B \pmod k$。

**证明**：$A - B = qk$ 即 $A = B + qk$，正是「$A$ 与 $B$ 模 $k$ 同余」的定义。∎

**引理 2（桶计数的正确性）**：设扫描到第 $j$ 个元素时，`cnt[r]` 等于下标集合 $\{i \in [0, j-1] : P_i \bmod k = r\}$ 的大小。则 `ans` 在扫描结束后等于 $\#\{(i, j) : 0 \le i < j \le n,\ P_i \equiv P_j \pmod k\}$。

**证明**：对 $j$ 归纳。$j = 0$ 时 `cnt[0] = 1` 对应 $P_0 = 0$，正确。设处理到 $j$ 时不变式成立，程序执行 `ans += cnt[s]`（$s = P_j \bmod k$），新增的计数恰为「所有 $i < j$ 且 $P_i \equiv P_j$ 的个数」；随后 `cnt[s]++` 把 $P_j$ 计入桶，不变式对 $j+1$ 仍成立。故扫描结束时 `ans` 恰好统计了所有同余的前缀对。∎

**定理**：算法返回的非空子数组个数恰为「元素和能被 $k$ 整除」的子数组个数。

**证明**：子数组 `nums[i+1..j]`（$0 \le i < j \le n$）与下标对 $(i, j)$ 一一对应，其和为 $P_j - P_i$。由引理 1，$k \mid (P_j - P_i) \iff P_i \equiv P_j \pmod k$。由引理 2，`ans` 恰好统计了满足该条件的全部下标对，故与合法子数组一一对应，数量相等。∎

## 6. 复杂度分析

- **时间**：$O(n + k)$。初始化桶 $O(k)$，一次扫描 $O(n)$，每次取模与桶访问 $O(1)$。
- **空间**：$O(k)$，即余数桶；不存储前缀和数组，边扫边算。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int subarraysDivByK(vector<int>& nums, int k) {
        vector<int> cnt(k, 0);
        cnt[0] = 1;                       // 空前缀，余数为 0
        int s = 0;
        long long ans = 0;
        for (int x : nums) {
            s = ((s + x) % k + k) % k;    // 规范化为 [0, k)
            ans += cnt[s];                // 此前同余的前缀个数
            cnt[s]++;
        }
        return (int)ans;
    }
};
```

### Python

```python
class Solution:
    def subarraysDivByK(self, nums: list[int], k: int) -> int:
        cnt = [0] * k
        cnt[0] = 1              # 空前缀，余数为 0
        s = 0
        ans = 0
        for x in nums:
            s = (s + x) % k     # Python 的取模结果天然非负
            ans += cnt[s]
            cnt[s] += 1
        return ans
```

## 8. 边界情况与易错点

1. **负数余数**：C++ 里 `-3 % 5 == -3`，必须规范化；这是本题最高频的 WA 原因。
2. **`cnt[0] = 1` 漏写**：所有「从头开始且和能被整除」的子数组都会丢失，答案偏小。
3. **`ans += cnt[s]` 与 `cnt[s]++` 顺序颠倒**：会把自己算进配对里，答案偏大 $n$。
4. **`ans` 溢出**：$n = 3 \times 10^4$ 时最坏 $4.5 \times 10^8$，`int` 勉强够但接近上限；用 `long long` 更稳。
5. **$k$ 大于数组长度**：完全合法，前缀和余数分布稀疏，桶仍能正确工作。
6. **全零数组**：`[0,0,0], k = 2` → 所有 6 个子数组都合法，桶计数自然给出正确答案。
7. **`nums[i]` 恰为 $k$ 的倍数**：余数不变，等价于「零元素」，正确处理。
8. **不要用 `unordered_map<int,int>` 存余数**：虽然可行，但哈希常数与冲突会让 $3 \times 10^4$ 规模的优势消失，数组桶更稳。
