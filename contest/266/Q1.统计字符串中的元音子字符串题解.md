# LeetCode 统计字符串中的元音子字符串 题解

## 1. 题目概述

- **标题 / 题号**：统计字符串中的元音子字符串（#2062，easy）
- **链接**：https://leetcode.cn/problems/count-vowel-substrings-of-a-string/
- **来源**：LeetCode 第 266 场周赛 Q1
- **难度**：简单
- **标签**：哈希表、字符串、位运算

**题意**：给定字符串 `word`，统计其中**元音子字符串**的数目。子字符串是字符串中**连续**的非空字符序列；元音子字符串要求**仅由元音 `a`、`e`、`i`、`o`、`u` 组成**，且**五种元音全部至少出现一次**。

**约束**：

- $1 \le \text{word.length} \le 100$
- `word` 仅由小写英文字母组成

## 2. 示例

**示例 1**

```text
输入：word = "aeiouu"
输出：2
解释：合法子串为 "aeiou" 与 "aeiouu"（前者是后者的前缀，两个都计数）。
```

**示例 2**

```text
输入：word = "cuaieuouac"
输出：7
解释：两端辅音 c 切出纯元音段 "uaieuoua"，段内合法子串：
      uaieuo、uaieuou、uaieuoua、aieuo、aieuou、aieuoua、ieuoua
```

**示例 3**

```text
输入：word = "bbaeixoubb"
输出：0
解释：辅音墙把元音切成 "aei" 与 "ou" 两段，都凑不齐 5 种元音。
```

## 3. 解题思路

### 3.1 暴力思路

枚举全部 $O(n^2)$ 个子串，每个再用 $O(n)$ 检查"全为元音且 5 种齐全"，总复杂度 $O(n^3)$。$n \le 100$ 时约 $10^6$ 次字符判断，同样能过——但完全没必要：固定左端点向右扩展时，可以**增量维护**已出现的元音集合，把每次判定降为 $O(1)$。

### 3.2 核心观察：辅音是"墙"，合法子串只在段内

![辅音是墙：元音子串必然落在纯元音段内](images/vowel2062_concept.svg)

1. **辅音即墙**：合法子串不含任何辅音，因此它必然完整落在某个**极大纯元音段**内（两端被辅音或字符串边界夹住）；跨墙的子串一律非法，直接排除。
2. **段内条件只剩一个**：段内字符已保证全为元音，只差"5 种元音各至少一次"。
3. **右端点单调性**：固定左端点后向右扩展，已出现的元音**种数只增不减**——一旦凑齐 5 种，之后更长的窗口全部合法，直到撞墙。

于是对每个起点只需向右扫一遍，用一个 5 位二进制掩码（或哈希集合）维护出现了哪些元音即可。

### 3.3 算法流程

![算法流程：枚举左端点与位掩码扩展右端点](images/vowel2062_flow.svg)

```text
for i in 0 .. n-1:
    if word[i] 是辅音: continue          # 起点本身非法
    mask = 0                             # 5 位掩码，第 k 位 = 第 k 种元音已出现
    for j in i .. n-1:
        if word[j] 是辅音: break         # 撞墙，起点 i 的所有子串判完
        mask |= 1 << pos(word[j])        # 增量记录该元音
        if mask == 31: ans += 1          # 0b11111：5 种齐全
```

### 3.4 示例演算

![示例演算：cuaieuouac 中 7 个合法子串](images/vowel2062_walkthrough.svg)

以 `word = "cuaieuouac"` 为例，唯一纯元音段为 `"uaieuoua"`（下标 1–8）：

| 起点 i | 首次凑齐 5 种的位置 | 合法右端点 | 个数 |
|--------|--------------------|-----------|------|
| 1（u） | j = 6（加入 o） | 6, 7, 8 | 3 |
| 2（a） | j = 6 | 6, 7, 8 | 3 |
| 3（i） | j = 8（加入 a） | 8 | 1 |
| 4（e） | 永远缺 i | — | 0 |
| 5…8 | 窗口更短 | — | 0 |

合计 $3+3+1=7$，与示例一致 ✓

## 4. 算法细节

1. **元音判定**：用集合 `V = {a, e, i, o, u}` 一次比较完成；C++ 可用 `string("aeiou").find(c)` 是否为 `string::npos`。
2. **位掩码代替哈希表**：5 个元音各占 `mask` 的 1 位，`mask == 31`（即 $0\mathrm{b}11111$）判定"5 种齐全"，天然去重（同一元音重复出现不改变掩码）。
3. **辅音即 break**：内层循环遇到辅音立即停止，不需要预处理出所有段；撞墙后的更长窗口必然非法。
4. **无需特判 $n < 5$**：长度不足 5 的窗口永远凑不齐 5 种元音，`mask == 31` 自然不会成立。

## 5. 正确性证明

**引理 1**：合法子串的每个字符都是元音，因此它完整落在某个极大纯元音段内。

**证明**：设子串 `word[l..r]` 合法。若存在 $l \le k \le r$ 使 `word[k]` 为辅音，则该子串含有非元音字符，与"仅由元音组成"矛盾。∎

**引理 2**：固定左端点 $l$，记 $S_r$ 为 `word[l..r]` 中出现过的元音集合，则 $S_r \subseteq S_{r+1}$；且若 `word[r+1]` 是辅音，则对一切 $r' \ge r+1$，子串 `word[l..r']` 均非法。

**证明**：右端点右移只往集合中加入字符、不删除，故集合单调不减。若 `word[r+1]` 为辅音，则以 $l$ 为起点、右端点 $\ge r+1$ 的子串都包含该辅音，由引理 1 均非法。∎

**定理**：上述算法对每个合法子串恰好计数一次。

**证明**：算法枚举了所有满足"`word[i..j]` 全为元音"的起点-终点对 $(i, j)$（遇辅音即 break；由引理 2，被跳过的 $(i, j')$ 全部非法，不损失解）。对每个枚举到的 $(i, j)$，增量维护使 `mask` 恰好记录 `word[i..j]` 中出现过的元音种类（引理 2 的单调性保证），故 `mask == 31` 当且仅当 5 种元音齐全，即该子串合法。每对 $(i, j)$ 至多计一次，计数不重不漏。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n^2)$。外层 $n$ 个起点，内层最多扫到段尾；$n \le 100$ 时至多约 $10^4$ 次常数操作，签到题定位下绰绰有余。
- **空间复杂度**：$O(1)$。只维护 `mask` 与两个下标，不随输入规模增长。

> 💡 本题是"枚举 + 增量维护"的模板题：凡是右端点右移只会**增加**信息的统计（字符种类数、最大值等），都可以把逐子串重算降为 $O(1)$ 增量更新。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int countVowelSubstrings(string word) {
        string vowels = "aeiou";
        int n = word.size(), ans = 0;
        for (int i = 0; i < n; i++) {
            if (vowels.find(word[i]) == string::npos) continue;
            int mask = 0;
            for (int j = i; j < n; j++) {
                size_t p = vowels.find(word[j]);
                if (p == string::npos) break;
                mask |= 1 << p;
                if (mask == 31) ans++;
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def countVowelSubstrings(self, word: str) -> int:
        vowels = set('aeiou')
        n, ans = len(word), 0
        for i in range(n):
            if word[i] not in vowels:
                continue
            seen = set()
            for j in range(i, n):
                if word[j] not in vowels:
                    break
                seen.add(word[j])
                if len(seen) == 5:
                    ans += 1
        return ans
```

## 8. 边界情况与易错点

1. **子串必须连续**：不是子序列，中间不能跳过辅音；示例 4 `bbaeixoubb` 里 `aeiou` 并不连续，答案为 0。
2. **遇辅音必须 break**：误写成 `continue` 会把跨墙子串也拿去计数，严重出错。
3. **判定条件是 `mask == 31`**：5 位全 1 才算齐全；只判"出现过元音"或"种数 > 0"都会 WA。
4. **答案可能为 0**：全辅音字符串、或所有纯元音段都凑不齐 5 种（如 `bbaeixoubb` 被切成两段）。
5. **元音可重复**：只要求 5 种各至少一次，掩码/集合天然处理重复，无需去重逻辑。
6. **无需特判 $n < 5$**：短窗口自动不满足 `mask == 31`。
