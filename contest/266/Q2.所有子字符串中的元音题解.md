# LeetCode 所有子字符串中的元音 题解

## 1. 题目概述

- **标题 / 题号**：所有子字符串中的元音（#2063，medium）
- **链接**：https://leetcode.cn/problems/vowels-of-all-substrings/
- **来源**：LeetCode 第 266 场周赛 Q2
- **难度**：中等
- **标签**：数学、字符串、动态规划、组合数学

**题意**：给定字符串 `word`，返回其**所有子字符串**中**元音的总数**，元音指 `a`、`e`、`i`、`o`、`u`。子字符串是字符串中连续的非空字符序列。注意统计的是元音**个数**——同一子串里每个元音都各计一次，而不是「含元音的子串数」。

**约束**：

- $1 \le \text{word.length} \le 10^5$
- `word` 仅由小写英文字母组成
- 答案可能超过有符号 32 位整数的范围（$n = 10^5$ 全元音时约 $1.67 \times 10^{14}$），计算时需当心

## 2. 示例

**示例 1**

```text
输入：word = "aba"
输出：6
解释：6 个子串 "a"、"ab"、"aba"、"b"、"ba"、"a" 的元音数依次为
      1、1、2、0、1、1，总和为 6。
```

**示例 2**

```text
输入：word = "abc"
输出：3
解释："a"、"ab"、"abc" 各含 1 个元音；"b"、"bc"、"c" 不含元音，总计 3。
```

**示例 3**

```text
输入：word = "ltcd"
输出：0
解释：所有子串均不含元音。
```

**示例 4**

```text
输入：word = "noosabasboosa"
输出：237
```

## 3. 解题思路

### 3.1 暴力思路

两层循环枚举全部 $O(n^2) \approx 5 \times 10^9$ 个子串，逐个扫描统计元音再求和，总复杂度 $O(n^3)$；即便预处理元音**前缀和**把单个子串的统计降到 $O(1)$，整体仍是 $O(n^2)$——$n = 10^5$ 下必然超时。子串的**个数**躲不掉平方级，所以任何「逐子串处理」的算法都没救，突破口只能是**换视角：不枚举子串，改枚举字符**。

### 3.2 核心观察：贡献法——一个元音被多少个子串覆盖

![贡献法：位置 i 的元音被 (i+1)(n-i) 个子串覆盖](images/wc266_q2_concept.svg)

把求和顺序交换一下：

$$
\underbrace{\sum_{t \in \text{子串}} \text{vowelCnt}(t)}_{\text{按子串求和}} \;=\; \underbrace{\sum_{i=0}^{n-1} \big[\text{word}[i] \text{ 是元音}\big] \times \big(\text{覆盖位置 } i \text{ 的子串数}\big)}_{\text{按字符位置求和}}
$$

固定位置 $i$：子串 $[l, r]$ 覆盖 $i$ 当且仅当 $l \le i \le r$，于是

- **左端点** $l \in \{0, 1, \dots, i\}$，共 $i + 1$ 种选择；
- **右端点** $r \in \{i, i+1, \dots, n-1\}$，共 $n - i$ 种选择。

两条约束**互相独立**（一个只卡左端、一个只卡右端），由乘法原理直接相乘：

$$
\text{contribution}(i) = (i + 1) \times (n - i)
$$

每个覆盖 $i$ 的子串都会把 `word[i]` 这个元音数一次。重复计入不是 bug 而是题意——统计元音**总数**，子串 `"aba"` 里的两个 `a` 本来就该各算一次。

> ⚠️ **与本场 Q1 的对比**：Q1（2062）要求元音「凑齐 5 种」，子串的内容互相影响，只能真去扫子串；Q2 只数元音**个数**，每个位置的属性（是否元音）与子串里其他字符**无关**，所以整段子串枚举才能压缩成对单个位置的 $O(1)$ 贡献计算。

### 3.3 算法流程

![算法流程：一趟扫描，元音位置累加贡献](images/wc266_q2_flow.svg)

单层循环：判定 `word[i]` 是否元音（$O(1)$ 查 5 元音集合），是则把 $(i+1) \times (n-i)$ 累加进 `ans`。每个位置只判一次、至多加一次。注意乘法**先转型 64 位再相乘**。

### 3.4 示例演算

![示例演算：aba 与 noosabasboosa 的贡献表](images/wc266_q2_walkthrough.svg)

以 `word = "aba"`、$n = 3$ 为例：

| $i$ | word[i] | 元音? | $(i+1) \times (n-i)$ | ans |
|-----|---------|-------|----------------------|-----|
| 0 | a | ✓ | $1 \times 3 = 3$ | 3 |
| 1 | b | ✗ | — | 3 |
| 2 | a | ✓ | $3 \times 1 = 3$ | 6 |

- **$i=0$，`a`**：左端点只能取 0（1 种），右端点可取 0/1/2（3 种），覆盖子串 `"a"`、`"ab"`、`"aba"`，贡献 $1 \times 3 = 3$。
- **$i=1$，`b`**：辅音，贡献 0。
- **$i=2$，`a`**：左端点可取 0/1/2（3 种），右端点只能取 2（1 种），覆盖子串 `"a"`(后)、`"ba"`、`"aba"`，贡献 $3 \times 1 = 3$。

最终 `ans = 6` ✓。再用示例 4 自检：`word = "noosabasboosa"`，$n = 13$，元音位于 $i \in \{1,2,4,6,9,10,12\}$，贡献依次为 $24+33+45+49+40+33+13 = 237$ ✓。

## 4. 算法细节

1. **公式推导**：子串与指标对 $(l, r)$（$0 \le l \le r \le n-1$）一一对应。覆盖位置 $i$ 的条件 $l \le i \le r$ 把两维解耦：$l$ 有 $i+1$ 个取值、$r$ 有 $n-i$ 个取值，独立相乘即 $(i+1)(n-i)$。无需任何预处理。
2. **元音判定**：5 个字符的集合一次比较 $O(1)$。C++ 可写 `string("aeiou").find(c) != string::npos` 或查表 `bool isV[26]`；Python 用 `set('aeiou')`。常数都极小，比赛时写最快手的那种即可。
3. **DP 视角**（对应官方标签 Dynamic Programming）：设 $f(i)$ 为所有**以 $i$ 结尾**的子串的元音总数，则以 $i$ 结尾的 $i+1$ 个子串每个都比「以 $i-1$ 结尾」的对应版本多出一个 `word[i]`，故
   $$f(i) = f(i-1) + (i+1) \cdot \big[\text{word}[i] \text{ 是元音}\big], \qquad \text{ans} = \sum_{i=0}^{n-1} f(i).$$
   把递推展开：$f(j) = \sum_{k \le j} (k+1) \cdot [\text{word}[k] \text{ 是元音}]$，再对 $j$ 求和，位置 $k$ 的系数恰为 $(k+1)(n-k)$——**DP 与贡献法殊途同归**，后者只是把前者的滚动求和一次性写成了闭式。
4. **溢出控制**：全元音时 $\text{ans} = \sum_{i=0}^{n-1}(i+1)(n-i) = \dfrac{n(n+1)(n+2)}{6} \approx 1.67 \times 10^{14}$，是 32 位 `int` 上限（约 $2.1 \times 10^9$）的 8 万倍。C++ 中 `ans` 必须声明 `long long`，且 `(long long)(i + 1) * (n - i)` **先转型再相乘**——两个 `int` 相乘在赋值前就已溢出。Python 原生大整数无需关心。

## 5. 正确性证明

**引理 1（交换求和顺序）**：记 $\mathcal{S}$ 为 `word` 的全部子串集合，$V = \{a,e,i,o,u\}$，$c(i)$ 为覆盖位置 $i$ 的子串个数，则

$$
\sum_{t \in \mathcal{S}} \text{vowelCnt}(t) \;=\; \sum_{i=0}^{n-1} \big[\text{word}[i] \in V\big] \cdot c(i).
$$

**证明**：对任意子串 $t$，$\text{vowelCnt}(t) = \sum_{i=0}^{n-1} [i \in t] \cdot [\text{word}[i] \in V]$（子串的元音数等于其覆盖的元音位置个数）。于是

$$
\sum_{t \in \mathcal{S}} \text{vowelCnt}(t) = \sum_{t \in \mathcal{S}} \sum_{i} [i \in t]\,[\text{word}[i] \in V] = \sum_{i} [\text{word}[i] \in V] \sum_{t} [i \in t] = \sum_{i} [\text{word}[i] \in V] \cdot c(i),
$$

其中第二步交换了**有限和**的求和顺序（双重计数恒等式）。∎

**引理 2（覆盖计数）**：覆盖位置 $i$ 的子串恰有 $(i+1)(n-i)$ 个。

**证明**：子串与指标对 $(l, r)$（$0 \le l \le r \le n-1$）一一对应（子串即 `word[l..r]`）。覆盖条件 $i \in [l, r]$ 等价于 $l \le i$ 且 $r \ge i$，故覆盖 $i$ 的子串对应二元组集合 $\{(l, r) : 0 \le l \le i,\ i \le r \le n-1\}$：$l$ 有 $i+1$ 个取值、$r$ 有 $n-i$ 个取值，两约束分别只涉及 $l$ 与 $r$，由乘法原理恰有 $(i+1)(n-i)$ 个。每个满足条件的对唯一确定一个覆盖 $i$ 的子串，不重不漏。∎

**定理**：算法的返回值等于 `word` 所有子字符串的元音总数。

**证明**：算法输出 $A = \sum_{i} [\text{word}[i] \in V] \cdot (i+1)(n-i)$。由引理 2，$c(i) = (i+1)(n-i)$，代入引理 1 的右端即得 $A = \sum_{t \in \mathcal{S}} \text{vowelCnt}(t)$，且算法对每个位置恰好累加一次、元音判定与下标计算均无误。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。单趟扫描 $n$ 个位置，每位置一次 $O(1)$ 元音判定（5 元音集合）加至多一次 $O(1)$ 乘加。相比暴力的 $O(n^3)$ / 前缀和版的 $O(n^2)$，是「按子串求和 → 按位置求和」换来的两到三个数量级提升。
- **空间复杂度**：$O(1)$。只维护累加器与元音集合（常数大小），不随输入规模增长。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long countVowels(string word) {
        long long ans = 0;
        int n = word.size();
        string vowels = "aeiou";
        for (int i = 0; i < n; ++i) {
            if (vowels.find(word[i]) != string::npos) {
                ans += (long long)(i + 1) * (n - i);
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def countVowels(self, word: str) -> int:
        n = len(word)
        vowels = set('aeiou')
        return sum((i + 1) * (n - i) for i, c in enumerate(word) if c in vowels)
```

## 8. 边界情况与易错点

1. **32 位溢出（本题最高频 WA）**：$n = 10^5$ 全元音时答案 $\frac{n(n+1)(n+2)}{6} \approx 1.67 \times 10^{14}$。C++ 中 `ans` 用 `long long`，乘法 `(long long)(i + 1) * (n - i)` 先转型再乘——直接写 `(i + 1) * (n - i)` 时两个 `int` 相乘已经溢出，转型发生在赋值前就晚了。返回类型也必须是 64 位（LeetCode 签名已给 `long long`）。
2. **「元音总数」≠「含元音的子串数」**：子串 `"aba"` 含 2 个元音要计 2 次。若误按后者去做（总数减全辅音子串数），`"aba"` 会得到 5 而非 6——读题时先分清这两件事。
3. **元音集合只有 5 个**：`a e i o u`，别按英语习惯把 `y` 算进去，也别漏掉 `u`。
4. **全辅音与单字符**：全辅音串答案 0；$n = 1$ 且该字符为元音时答案 $1 \times 1 = 1$。公式天然覆盖，无需特判。
5. **贡献公式方向别写反**：是 $(i+1)(n-i)$（左端点含 $i$ 自身、右端点含 $n-1$），不是 $i \times (n-i-1)$。自检方法：首字符必须被全部 $n$ 个子串覆盖，即 $i = 0$ 处贡献应为 $n$。
6. **重复元音不需要去重**：与 Q1 的「凑齐 5 种」不同，本题每个元音位置独立贡献，`"aaa"` 中三个 `a` 各算各的，无需任何去重逻辑。
