# LeetCode 分配给商店的最多商品的最小值 题解

## 1. 题目概述

- **标题 / 题号**：分配给商店的最多商品的最小值（#2064，medium）
- **链接**：https://leetcode.cn/problems/minimized-maximum-of-products-distributed-to-any-store/
- **来源**：LeetCode 第 266 场周赛 Q3
- **难度**：中等
- **标签**：二分查找、贪心、数组

**题意**：有 $n$ 间零售商店和 $m$ 种商品，第 $i$ 种商品有 `quantities[i]` 件。要求把**所有**商品分配到商店，规则是：**一间商店至多持有一种商品**，但持有的件数不限（也可以分到 0 件）。设 $x$ 为分配后所有商店中商品数目的最大值，求 $x$ 的最小可能值。

**约束**：

- $1 \le m \le n \le 10^5$
- $1 \le quantities[i] \le 10^5$

## 2. 示例

**示例 1**

```text
输入：n = 6, quantities = [11,6]
输出：3
解释：商品 0（11 件）分 4 间：2,3,3,3；商品 1（6 件）分 2 间：3,3。
      max(2,3,3,3,3,3) = 3，且无法做到最大值 ≤ 2。
```

**示例 2**

```text
输入：n = 7, quantities = [15,10,10]
输出：5
解释：三种商品分别分 3、2、2 间商店，每间都是 5 件，恰好用满 7 间。
```

**示例 3**

```text
输入：n = 1, quantities = [100000]
输出：100000
解释：唯一的商店必须装下全部 100000 件商品 0。
```

## 3. 解题思路

### 3.1 暴力思路：逐个枚举上界 x

答案 $x$ 的取值范围是 $[1, \max(quantities)]$。最直接的做法是从小到大枚举 $x$，对每个 $x$ 检查是否存在合法分配，第一个可行的 $x$ 即答案。单次检查只需 $O(m)$（见 3.2），但 $x$ 的范围可达 $10^5$，总复杂度 $O(m \cdot \max q) \approx 10^{10}$，必然超时。

另一类朴素想法是直接构造最优分配（例如用优先队列每次把商品塞给当前负载最小的商店），但「一间商店只能放一种商品」意味着各类商品占用的商店集合**互不相交**，商店数在各类之间的划分方式组合爆炸，贪心无从下手——没有明确的局部最优决策。

### 3.2 核心观察：二分答案（最小化最大值）

这是经典的「**最小化最大值**」模型，标准套路是**二分答案**：把「求最优」改写成「**判定**」。

**判定问题**：给定上界 $x$，能否把所有商品分完，使每间商店不超过 $x$ 件？

**判定公式**（关键）：由于一间商店只能放一种商品，$q_i$ 件第 $i$ 类商品单独考虑——每间最多装 $x$ 件，至少需要 $\lceil q_i / x \rceil$ 间商店，且这个下界可以取到（前 $\lfloor q_i / x \rfloor$ 间装满，最后一间装余数）。不同种类占用的商店互不相交，因此：

$$\text{check}(x) \iff \sum_{i=0}^{m-1} \left\lceil \frac{quantities[i]}{x} \right\rceil \le n$$

**单调性**：$x$ 越大，每个 $\lceil q_i / x \rceil$ 只会不变或变小，总和单调不增。于是可行性呈「前缀不可行、后缀可行」的模式——**不可行的是 ✗✗✗ 前缀，可行的是 ✓✓✓ 后缀**，二者之间只有一个分界点，二分找到第一个 ✓ 即答案。

![二分答案概念：可行性关于 x 单调](images/wc266_q3_concept.svg)

### 3.3 算法流程

在 $[lo, hi] = [1, \max(quantities)]$ 上二分。上界 $hi$ 一定可行：$x = \max(quantities)$ 时每类只需 1 间商店、共 $m \le n$ 间。整个过程中维护不变量「$hi$ 始终可行、$lo - 1$ 始终不可行」，循环结束时 $lo = hi$ 即最小可行值：

## 4. 算法细节

1. **ceil 的整数实现**：$\lceil q/x \rceil = \lfloor (q + x - 1) / x \rfloor$，C++ 写作 `(q + x - 1) / x`，Python 写作 `(q + x - 1) // x`。**不要**用浮点 `ceil(q / x)`——$10^5$ 规模下浮点除法可能产生精度误差，导致判定翻转。
2. **二分模板与不变量**：可行时执行 `hi = mid`（mid 可能就是答案，不能排除），不可行时执行 `lo = mid + 1`（mid 确定不可行，安全排除）。区间每轮至少缩小一半，保证终止。
3. **提前退出**：check 中累加和一旦超过 $n$ 立即返回 false，既省时间又防溢出。
4. **上界正确性**：$x = \max(quantities)$ 时 $\sum \lceil q_i / x \rceil = m \le n$ 必然可行，二分不会越界；下界取 1（$q_i \ge 1$ 保证答案至少为 1）。

## 5. 正确性证明

**引理 1**（单类商品的最少商店数）：把 $q$ 件同种商品分配到若干商店、每间不超过 $x$ 件，所需商店数的最小值为 $\lceil q / x \rceil$。

**证明**：一方面，$k$ 间商店至多容纳 $kx$ 件商品，故 $kx \ge q$，即 $k \ge q / x$；$k$ 为整数，故 $k \ge \lceil q / x \rceil$。另一方面，取 $k = \lceil q / x \rceil$ 间：前 $k - 1$ 间各装 $x$ 件，最后一间装 $q - (k-1) \cdot x$ 件；由 $k \ge q/x$ 得 $q \le kx$，故余数 $q - (k-1)x \le x$（且 $q > 0$ 时余数 $\ge 1 > 0$），每间均不超过 $x$ 件，方案合法。∎

**引理 2**（判定条件）：上界 $x$ 可行 $\iff$ $\sum_i \lceil q_i / x \rceil \le n$。

**证明**：（⇒）每间商店只能放一种商品，故各类商品占用的商店集合两两不交；由引理 1，第 $i$ 类至少占用 $\lceil q_i / x \rceil$ 间，对 $i$ 求和即得商店总数 $\ge \sum_i \lceil q_i / x \rceil \le n$ 必须成立。（⇐）令第 $i$ 类恰好占用 $k_i = \lceil q_i / x \rceil$ 间商店，由 $\sum k_i \le n$ 知商店够用（多余的商店分 0 件）；由引理 1 的构造，每类都能在 $k_i$ 间内分完且每间不超过 $x$ 件。∎

**定理 1**（单调性）：若 $x$ 可行，则 $x + 1$ 也可行。

**证明**：对任意正整数 $q$，有 $q / (x+1) \le q / x$，向上取整后 $\lceil q/(x+1) \rceil \le \lceil q/x \rceil$，故 $\text{check}(x+1)$ 的和不大于 $\text{check}(x)$ 的和；由引理 2，$x$ 可行蕴含 $x+1$ 可行。∎

**定理 2**（算法正确性）：上述二分返回的值等于最优答案 $x^*$。

**证明**：记可行集为 $S$。由引理 2，$x = \max q \in S$（此时和为 $m \le n$），故 $S$ 非空；由定理 1，$S$ 是一段后缀 $[x^*, \max q]$。二分过程始终维护不变量「$hi \in S$，且 $lo - 1 \notin S$ 或 $lo = 1$」：初始时 $hi = \max q \in S$ 成立；每轮若 $\text{check}(mid)$ 为真则置 $hi = mid$（$mid \in S$ 保持），否则置 $lo = mid + 1$（$mid \notin S$，故 $lo - 1 \notin S$ 保持）。区间每轮至少减半，终止时 $lo = hi \in S$ 且 $lo - 1 \notin S$，即 $lo = x^*$。由引理 2，$S$ 恰为「存在最大值 $\le x$ 的合法分配」的 $x$ 全体，故 $x^*$ 正是题意所求的最小最大值。∎

## 6. 复杂度分析

- **时间复杂度**：$O(m \log \max q)$。二分共 $O(\log \max q) \approx 17$ 轮，每轮 check 线性扫描 $m \le 10^5$ 个商品数，总计约 $1.7 \times 10^6$ 次整数运算。
- **空间复杂度**：$O(1)$。仅使用常数个标量变量（不计输入数组本身）。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int minimizedMaximum(int n, vector<int>& quantities) {
        auto check = [&](long long x) {
            long long need = 0;
            for (int q : quantities) {
                need += (q + x - 1) / x;
                if (need > n) return false;   // 提前退出，同时防溢出
            }
            return true;
        };
        int lo = 1, hi = *max_element(quantities.begin(), quantities.end());
        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            if (check(mid)) hi = mid;
            else lo = mid + 1;
        }
        return lo;
    }
};
```

### Python

```python
class Solution:
    def minimizedMaximum(self, n: int, quantities: List[int]) -> int:
        def check(x: int) -> bool:
            return sum((q + x - 1) // x for q in quantities) <= n

        lo, hi = 1, max(quantities)
        while lo < hi:
            mid = (lo + hi) // 2
            if check(mid):
                hi = mid
            else:
                lo = mid + 1
        return lo
```

## 8. 边界情况与易错点

1. **$n = m$**（含 $n = 1$ 的示例 3）：每类商品恰好分到 1 间商店，答案就是 $\max(quantities)$。二分自然覆盖，无需特判。
2. **累加和溢出**：$x = 1$ 时 $\sum \lceil q_i / x \rceil = \sum q_i$ 可达 $10^5 \times 10^5 = 10^{10}$，超出 32 位 int 范围。C++ 必须用 `long long` 累加（或在超过 $n$ 时提前返回）；Python 无此问题。
3. **ceil 必须用整数运算**：浮点 `ceil(q / x)` 在大数下有精度风险，统一写 `(q + x - 1) / x`。
4. **二分死循环**：不可行时写 `lo = mid` 会死循环，必须是 `lo = mid + 1`；可行时必须是 `hi = mid` 而非 `hi = mid - 1`（mid 可行时可能正是答案）。
5. **判定条件是 $\le n$ 而非 $= n$**：商店允许分到 0 件，多余的商店可以闲置，只需「需要的商店数不超过 $n$」。
6. **角色混淆**：$n$ 是商店数（容量维度），$m$ 是商品种类数；判定公式是对**商品种类**求和、与**商店数**比较，方向别搞反。

**延伸思考**：

- 若去掉「一间商店只能一种商品」的限制（各类商品可混装），则商品成为彼此独立的个体，判定退化为总量比较 $\sum q_i \le n \cdot x$，答案直接变为 $\lceil \sum q_i / n \rceil$，不再需要二分。
- 能否不二分？可以证明最优值必形如 $\lceil q_i / k \rceil$（某类 $i$、某个正整数 $k$）：若 $x^* - 1$ 不可行而 $x^*$ 可行，则存在某类在 $x^* - 1$ 与 $x^*$ 之间「跨过一档」。对每类只有 $O(\sqrt{q_i})$ 个不同的 $\lceil q_i / k \rceil$ 值（整除分块），候选总数 $O(m \sqrt{\max q})$，理论上可排序扫描求解，但实现远比二分繁琐，比赛中二分是唯一推荐写法。
