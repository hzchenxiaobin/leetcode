# LeetCode 删除元素后 K 个字符串的最长公共前缀 题解

## 1. 题目概述

- **标题 / 题号**：删除元素后 K 个字符串的最长公共前缀（#3485，hard）
- **链接**：https://leetcode.cn/problems/longest-common-prefix-of-k-strings-after-removal/
- **来源**：LeetCode 第 152 场双周赛 Q3
- **难度**：困难
- **标签**：字典树、数组、字符串

**题意**：给定字符串数组 `words` 和整数 $k$。对每个下标 $i$，把 `words[i]` 删掉，在剩下的字符串中选出 $k$ 个**下标互不相同**的字符串，使它们的**最长公共前缀（LCP）长度**最大，把这个最大长度记为 `answer[i]`。若删除后剩下的字符串不足 $k$ 个，则 `answer[i] = 0`。

**约束**：

- $1 \le k \le words.length \le 10^5$
- $1 \le |words[i]| \le 10^4$
- $words[i]$ 只含小写英文字母
- $\sum |words[i]| \le 10^5$

## 2. 示例

**示例 1**

```text
输入：words = ["jump","run","run","jump","run"], k = 2
输出：[3,4,4,3,4]
解释：
  删下标 0（jump）：剩 run,run,jump,run → run 出现 3 次，任意两个的 LCP = "run"，长度 3；
  删下标 1（run） ：剩 jump,run,jump,run → jump 出现 2 次，LCP = "jump"，长度 4；
  删下标 2（run） ：同上，长度 4；
  删下标 3（jump）：剩 jump,run,run,run → 长度 3；
  删下标 4（run） ：剩 jump,run,run,jump → 长度 4。
```

**示例 2**

```text
输入：words = ["dog","racer","car"], k = 2
输出：[0,0,0]
解释：任意两个字符串的首字母都不同，删掉一个之后剩下的两个也没有公共前缀，长度都是 0。
```

**示例 3（易错）**

```text
输入：words = ["a","aaa"], k = 1
输出：[3,1]
解释：删掉 "a" 后只剩 "aaa"，一个字符串的 LCP 就是它自身，长度 3；
      删掉 "aaa" 后只剩 "a"，长度 1。答案可能超过被删串自身的长度。
```

## 3. 解题思路

### 3.1 暴力思路

对每个 $i$：把 `words[i]` 去掉，然后在剩下的串里统计"每个长度 $L$ 的前缀出现过几次"，取满足"出现次数 $\ge k$"的最大 $L$。单次统计需要遍历所有串的所有前缀，复杂度 $O(\sum |w|)$，乘上 $n$ 次删除就是 $O(n \sum |w|)$，最坏 $10^5 \times 10^5 = 10^{10}$，必然超时。

即使把"重建统计"换成"Trie 上路径计数减一"，**每次删除仍要沿被删串走一遍**，而"求当前最大可行深度"又要在整棵 Trie 上找最深的计数 $\ge k$ 的节点，同样不能每次重扫。必须把"删一个串的影响"限制在 $O(|w_i|)$，并且能 $O(1)$ 地回答"这个深度行不行"。

### 3.2 核心观察：删一个串只影响它自己的前缀

![Trie 上每个节点记经过的单词数，删一个词就是路径减一](images/bw152_q3_trie_remove.svg)

把 `words` 建成 Trie，每个节点 $v$ 记录 `cnt[v]` = **经过该节点的单词数**，节点深度 = 对应前缀长度。于是：

- 长度 $L$ 的某个前缀出现了 $c$ 次 $\iff$ 深度为 $L$ 的对应节点 `cnt = c`；
- 答案 = 所有 `cnt ≥ k` 的节点中**最大深度**（这里用的是删除**之后**的计数）。

关键观察：**删除 `words[i]` 只会让它自己的那些前缀计数减一**，其它前缀（哪怕是同一层、同样字符开头的另一个分支）完全不变。

于是对固定的 $i$ 和询问深度 $L$：

$$
\text{删除后的前缀集合} = \underbrace{\{\text{words}[i] \text{ 的 } L \text{ 长前缀}\}}_{\text{计数减一}} \cup \underbrace{\{\text{同层其它不同前缀}\}}_{\text{计数不变}}
$$

只要能对"同层其它前缀的最大计数"做 $O(1)$ 查询，就能 $O(1)$ 判断每个深度是否可行。

### 3.3 算法流程：每层存前两大，答案拆成两段

![每个深度 d 只需回答一件事：别的 d 长前缀够不够 k 个](images/bw152_q3_two_cases.svg)

**每层统计**：遍历所有 Trie 节点，按深度 $d$ 统计该层"不同前缀"的计数的

- $H1[d]$：最大计数；$m1[d]$：达到 $H1$ 的不同前缀个数；$H2[d]$：次大计数（没有则 $-1$）。

**同层其它前缀的最大计数**：对深度 $d$ 的某个前缀 $P$（计数 $c$），

$$
\text{maxOther}(P) = \begin{cases}
H2[d], & c = H1[d] \text{ 且 } m1[d] = 1 \ (\text{即 } P \text{ 是该层唯一的最大者})\\
H1[d], & \text{否则}
\end{cases}
$$

**每个 $i$ 只需扫自己的路径**。设 $L_i = |words[i]|$：

- **$d \le L_i$**：深度 $d$ 可行 $\iff$ `cnt − 1 ≥ k`（自己这个前缀减一后仍够）**或** `maxOther ≥ k`（同层别的不同前缀够）。
- **$d > L_i$**：`words[i]` 在这一层没有前缀，删除对它毫无影响，深度 $d$ 可行 $\iff$ `H1[d] ≥ k`。用后缀最大值预处理好 $O(1)$ 查询：

$$
\text{bestFree}[d] = \max\{\, d' \ge d : H1[d'] \ge k \,\} \quad(\text{不存在则为 } -1)
$$

最终 $\text{answer}[i] = \max\big(\text{①中可行的最大 } d,\ \text{bestFree}[L_i+1]\big)$。

> 💡 **为什么必须有第二段**：示例 3 的 `["a","aaa"]`，删掉 `"a"` 之后答案是 3，比被删串自身长度 1 还大。只扫自己的路径只能得到 1，必须靠 `bestFree` 补上。

```text
1. 若 n - 1 < k: 全部返回 0
2. 建 Trie，记 cnt、dep
3. 按深度统计 H1、m1、H2
4. bestFree[maxDep+1] = -1；for d = maxDep..1:
       bestFree[d] = max(bestFree[d+1], H1[d] ≥ k ? d : -1)
5. for i = 0..n-1:
       best = 0；沿 words[i] 的路径逐层 d = 1..|w_i|:
           若 cnt-1 ≥ k 或 maxOther(d, cnt) ≥ k: best = d
       若 |w_i|+1 ≤ maxDep: best = max(best, bestFree[|w_i|+1])
       answer[i] = best
```

### 3.4 示例演算

![示例 1：每层统计 (H1, m1, H2)，再逐词扫自己的路径](images/bw152_q3_example_walkthrough.svg)

`words = ["jump","run","run","jump","run"]`，$k = 2$。Trie 中：

| 深度 | 该层前缀（计数） | $H1$ | $m1$ | $H2$ | bestFree |
|------|------------------|------|------|------|----------|
| 1 | j:2, r:3 | 3 | 1 | 2 | 4 |
| 2 | ju:2, ru:3 | 3 | 1 | 2 | 4 |
| 3 | jum:2, run:3 | 3 | 1 | 2 | 4 |
| 4 | jump:2 | 2 | 1 | -1 | 4 |

- 删下标 0 的 `"jump"`：$d = 1..3$ 时 `r` 分支计数 3 减不了（不是自己的前缀），`maxOther = H1 = 3 ≥ 2`，可行；$d = 4$ 时自己减一得 $1 < 2$，而 $m1[4] = 1$ 且自己就是唯一最大者，`maxOther = H2 = -1`，不可行。$L_i = 4$，$L_i + 1$ 越界无第二段。$\Rightarrow 3$。
- 删下标 1 的 `"run"`：$d = 1..3$ 都是自己的前缀，$3 - 1 = 2 \ge 2$，可行；$d = 4 > L_i = 3$，查 `bestFree[4] = 4`（`jump` 还剩两个）。$\Rightarrow 4$。
- 删下标 3 的 `"jump"`：与下标 0 对称，$\Rightarrow 3$。
- 其余下标同理 $\Rightarrow 4$。

最终 `answer = [3,4,4,3,4]`，与官方输出一致。

## 4. 算法细节

1. **Trie 的存储**：节点数不超过 $\sum|w| + 1 \le 10^5 + 1$。C++ 用 `vector<array<int,26>>` 显式 26 叉（约 $10^5 \times 26 \times 4\text{B} \approx 10\text{MB}$），插入时注意 `push_back` 会让引用失效，务必用下标而非引用访问父节点。
2. **每层统计只需一遍遍历**：所有节点按 `dep` 归入对应层的统计量，`H1/m1/H2` 的更新写成三段：比最大者更大（原最大降为次大、`m1 = 1`）、等于最大者（`m1++`）、否则更新次大值。
3. **`maxOther` 的两种情形**：只有在"自己是该层唯一最大者"时才需要退到 $H2$，否则同层必存在另一个计数为 $H1$ 的前缀，直接取 $H1$。
4. **第二段用后缀最大值**：`bestFree[d]` 定义为"深度 $\ge d$ 的可行深度最大值"，从 $maxDep$ 往 $1$ 递推，查询 $O(1)$。
5. **提前返回**：`n - 1 < k` 时删掉任何一个都凑不齐 $k$ 个串，答案全 0，可以在建 Trie 之前就返回，省掉全部开销。
6. **深度从 1 开始**：长度 0 的公共前缀恒可行但没有意义，答案取的是"最大可行长度"，因此统计与扫描都从 $d = 1$ 起步。
7. **重复字符串**：完全相同的串在 Trie 里共用同一条路径，计数自然累加；这正是 $m1$ 会出现大于 1 的情形。

## 5. 正确性证明

设 `cnt'` 表示删除 `words[i]` 之后各前缀的出现次数，`cnt` 为删除前。

**引理 1（删除只减自己的前缀）**：对任意长度 $L$ 的前缀串 $P$，

$$cnt'(P) = cnt(P) - [\,P \text{ 是 } words[i] \text{ 的 } L \text{ 长前缀}\,]$$

**证明**：删掉的只有 `words[i]` 这一个串。若 $P$ 是它的 $L$ 长前缀，则 $P$ 的贡献恰好少 1；否则 `words[i]` 本来就不贡献 $P$，其余字符串的贡献一律不变。∎

**引理 2（问题等价于找最长可行前缀）**：长度 $L$ 存在 $k$ 个剩余字符串（下标互异）以某串 $P$ 为公共前缀 $\iff$ 存在长度 $L$ 的前缀 $P$ 使 $cnt'(P) \ge k$。因此 `answer[i]` 等于满足该条件的最大 $L$。

**证明**：$k$ 个串的最长公共前缀长度 $\ge L$ $\iff$ 它们共享同一个长度为 $L$ 的前缀 $P$，而这 $k$ 个串都在计数 $cnt'(P)$ 里，故 $cnt'(P) \ge k$。反之若某 $P$ 有 $cnt'(P) \ge k$，取贡献它的 $k$ 个串（互不相同），它们的 LCP 至少是 $P$ 的长度 $L$。∎

**引理 3（同层其它前缀的最大计数）**：设深度 $d$ 上各不同前缀的计数最大值为 $H1$、达到它的前缀个数为 $m1$、次大值为 $H2$。对该层任一前缀 $P$（计数 $c$）：

$$\max_{Q \ne P,\ |Q| = d} cnt(Q) = \begin{cases} H2, & c = H1 \text{ 且 } m1 = 1\\ H1, & \text{否则}\end{cases}$$

**证明**：若 $c = H1$ 且 $m1 = 1$，则 $P$ 是唯一取到最大值的不同前缀，其余前缀的计数都 $\le H2$ 且有人取到 $H2$，故最大值就是 $H2$（若该层只有 $P$ 一个前缀，则 $H2 = -1$，最大值记为"不存在"）。否则存在 $Q \ne P$ 且 $cnt(Q) = H1$，于是最大值 $\ge H1$；又所有计数 $\le H1$，故恰为 $H1$。∎

**引理 4（逐深度可行性判定）**：对 $d \le |words[i]|$，深度 $d$ 可行 $\iff$ $cnt(P_i) - 1 \ge k$ 或 $\text{maxOther}(P_i) \ge k$（$P_i$ 为 `words[i]` 的 $d$ 长前缀）；对 $d > |words[i]|$，深度 $d$ 可行 $\iff$ $H1[d] \ge k$。

**证明**：$d \le |words[i]|$ 时，该层的不同前缀分成 $P_i$ 与"其它"两类，由引理 1，$P_i$ 的计数变为 $cnt(P_i) - 1$、其它的不变；于是 $\max_P cnt'(P) \ge k$ $\iff$ 两类中至少一个的最大值 $\ge k$，即引理 3 给出的两个条件之一。$d > |words[i]|$ 时 $P_i$ 不存在，所有前缀计数都不变，可行性就是 $H1[d] \ge k$。∎

**定理**：算法输出的 `answer[i]` 等于题目要求的值。

**证明**：由引理 4，算法在 $d \le |w_i|$ 段内取到了这一段所有可行深度的最大值，而 $d > |w_i|$ 段内可行深度的最大值恰为 `bestFree[|w_i|+1]`（后缀最大值定义），两段合并取最大即覆盖了全部深度 $d \le maxDep$。再由引理 2，这个最大可行深度就是 `answer[i]`。当 $n - 1 < k$ 时不存在 $k$ 个剩余字符串，任何深度都不可行，输出 0 亦正确。∎

## 6. 复杂度分析

- **建 Trie**：$O(\sum |w|)$ 时间，节点数不超过 $\sum|w| + 1$，空间 $O(26 \sum |w|)$（用 26 叉数组）或 $O(\sum|w|)$（用哈希/邻接表）。
- **每层统计**：遍历所有节点一次，$O(\sum |w|)$ 时间。
- **`bestFree` 递推**：$O(maxDep) \le O(\max|w|)$。
- **逐词回答**：第 $i$ 个串沿自己的路径走 $|w_i|$ 步，合计 $\sum |w_i| = O(\sum|w|)$。
- **总时间**：$O(\sum |w|)$，本题 $\sum|w| \le 10^5$，非常宽松。
- **空间**：$O(\sum |w|)$。

对比：暴力每个删除都重扫整棵 Trie 是 $O(n \sum|w|) = 10^{10}$ 量级，本题的优化点就是把"删除的影响"限制在被删串的路径上。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> longestCommonPrefix(vector<string>& words, int k) {
        int n = (int)words.size();
        vector<int> ans(n, 0);
        if (n - 1 < k) return ans;             // 删掉一个后不足 k 个串

        // ---------- 建 Trie：cnt[v] = 经过节点 v 的单词数 ----------
        vector<array<int, 26>> ch(1);
        ch[0].fill(-1);
        vector<int> cnt(1, 0), dep(1, 0);
        for (const string& w : words) {
            int cur = 0;
            cnt[0]++;
            for (char c : w) {
                int nxt = ch[cur][c - 'a'];
                if (nxt == -1) {
                    nxt = (int)ch.size();
                    array<int, 26> fresh;
                    fresh.fill(-1);
                    ch.push_back(fresh);
                    cnt.push_back(0);
                    dep.push_back(dep[cur] + 1);
                    ch[cur][c - 'a'] = nxt;
                }
                cur = nxt;
                cnt[cur]++;
            }
        }
        int nodes = (int)ch.size(), maxDep = 0;
        for (int v = 1; v < nodes; v++) maxDep = max(maxDep, dep[v]);

        // ---------- 每层统计：最大值 H1、达到最大值的节点数 m1、次大值 H2 ----------
        vector<int> H1(maxDep + 2, -1), H2(maxDep + 2, -1);
        vector<int> m1(maxDep + 2, 0), bestFree(maxDep + 3, -1);
        for (int v = 1; v < nodes; v++) {
            int d = dep[v], c = cnt[v];
            if (c > H1[d]) {
                H2[d] = H1[d];
                H1[d] = c;
                m1[d] = 1;
            } else if (c == H1[d]) {
                m1[d]++;
            } else if (c > H2[d]) {
                H2[d] = c;
            }
        }
        for (int d = maxDep; d >= 1; d--) {
            bestFree[d] = max(bestFree[d + 1], H1[d] >= k ? d : -1);
        }

        // ---------- 逐个单词：沿自己的路径扫一遍 ----------
        for (int i = 0; i < n; i++) {
            const string& w = words[i];
            int len = (int)w.size(), cur = 0, best = 0;
            for (int d = 1; d <= len; d++) {
                cur = ch[cur][w[d - 1] - 'a'];
                int c = cnt[cur];
                bool ok = (c - 1 >= k);                        // 该前缀自身减一后仍够
                if (!ok) {
                    int other = (c == H1[d] && m1[d] == 1) ? H2[d] : H1[d];
                    ok = (other >= k);                         // 或同层别的不同前缀够
                }
                if (ok) best = d;
            }
            if (len + 1 <= maxDep) best = max(best, bestFree[len + 1]);
            ans[i] = best;
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def longestCommonPrefix(self, words: list[str], k: int) -> list[int]:
        n = len(words)
        ans = [0] * n
        if n - 1 < k:                     # 删掉一个后不足 k 个串
            return ans

        # ---------- 建 Trie：cnt[v] = 经过节点 v 的单词数 ----------
        ch = [{}]                         # 每个节点：字符 -> 子节点
        cnt = [0]
        dep = [0]
        for w in words:
            cur = 0
            cnt[0] += 1
            for c in w:
                nxt = ch[cur].get(c)
                if nxt is None:
                    nxt = len(ch)
                    ch.append({})
                    cnt.append(0)
                    dep.append(dep[cur] + 1)
                    ch[cur][c] = nxt
                cur = nxt
                cnt[cur] += 1
        max_dep = max(dep) if dep else 0

        # ---------- 每层统计：最大值 H1、达到最大值的节点数 m1、次大值 H2 ----------
        H1 = [-1] * (max_dep + 2)
        H2 = [-1] * (max_dep + 2)
        m1 = [0] * (max_dep + 2)
        for v in range(1, len(ch)):
            d, c = dep[v], cnt[v]
            if c > H1[d]:
                H2[d], H1[d], m1[d] = H1[d], c, 1
            elif c == H1[d]:
                m1[d] += 1
            elif c > H2[d]:
                H2[d] = c
        best_free = [-1] * (max_dep + 3)
        for d in range(max_dep, 0, -1):
            best_free[d] = best_free[d + 1]
            if H1[d] >= k:
                best_free[d] = max(best_free[d], d)

        # ---------- 逐个单词：沿自己的路径扫一遍 ----------
        for i, w in enumerate(words):
            length = len(w)
            cur = 0
            best = 0
            for d in range(1, length + 1):
                cur = ch[cur][w[d - 1]]
                c = cnt[cur]
                ok = c - 1 >= k
                if not ok:
                    other = H2[d] if (c == H1[d] and m1[d] == 1) else H1[d]
                    ok = other >= k
                if ok:
                    best = d
            if length + 1 <= max_dep:
                best = max(best, best_free[length + 1])
            ans[i] = best
        return ans
```

## 8. 边界情况与易错点

1. **$n - 1 < k$**：删掉任何一个后剩下的串都不足 $k$ 个，答案全 0。必须先判，否则后续逻辑会在"计数不够"上绕弯路。
2. **漏掉 $d > |w_i|$ 的第二段**：这是本题最大的陷阱，示例 3（`["a","aaa"]`，`k = 1`）会直接暴露——只扫自己的路径会给出 1，正确答案是 3。
3. **`maxOther` 的"唯一最大者"判断**：只有 `c == H1 && m1 == 1` 才退到 $H2$；若 `m1 ≥ 2` 却仍用 $H2$，会**低估**同层其它前缀的计数，导致答案偏小。
4. **$H2$ 的初值**：用 $-1$ 表示"不存在"，判定时 $-1 \ge k$ 恒假，正好符合"没有其它前缀"的语义；不要用 0 当哨兵（若 $k$ 可能为 0 才会出问题，但本题 $k \ge 1$）。
5. **Trie 插入的引用失效**：C++ 里 `vector` 扩容后旧引用全部失效，插入时必须用下标重新访问父节点。
6. **深度 0**：空前缀在每层都存在且计数为 $n$，但它对应的答案是长度 0；从 $d = 1$ 开始扫描，天然避开。
7. **重复字符串**：完全相同的串共享路径，计数累加，$m1$ 可能大于 1，注意 `H2` 的更新顺序（"更大 / 相等 / 更小"三种分支）。
8. **`bestFree` 越界**：$|w_i|+1$ 可能大于 $maxDep$，此时没有第二段，直接跳过；数组开 $maxDep+3$ 个元素可避免越界。
