# LeetCode 设计电子表格 题解

## 1. 题目概述

- **标题 / 题号**：设计电子表格（#3484，medium）
- **链接**：https://leetcode.cn/problems/design-spreadsheet/
- **来源**：LeetCode 第 152 场双周赛 Q2
- **难度**：中等
- **标签**：设计、数组、哈希表、字符串、矩阵

**题意**：实现一个电子表格类，它有 **26 列**（`'A'` 到 `'Z'`）和 `rows` 行，每个单元格存一个 $0 \sim 10^5$ 的整数：

- `Spreadsheet(int rows)`：初始化，所有单元格初值为 $0$；
- `void setCell(String cell, int value)`：把单元格 `cell` 设为 `value`，`cell` 形如 `"A1"`、`"B10"`（字母是列，数字是 $1$ 起始的行号）；
- `void resetCell(String cell)`：把单元格重置为 $0$；
- `int getValue(String formula)`：计算形如 `"=X+Y"` 的公式，`X`、`Y` 各自要么是**单元格引用**，要么是**非负整数**，返回两操作数之和。

**约束**：

- $1 \le rows \le 10^3$
- $0 \le value \le 10^5$
- 公式保证为 `"=X+Y"` 格式，操作数是合法单元格引用或不大于 $10^5$ 的非负整数
- 单元格引用的行号在 $1 \sim rows$ 之间
- `setCell`、`resetCell`、`getValue` 的调用总次数不超过 $10^4$

## 2. 示例

**示例 1**

```text
输入：
["Spreadsheet", "getValue", "setCell", "getValue", "setCell", "getValue", "resetCell", "getValue"]
[[3], ["=5+7"], ["A1", 10], ["=A1+6"], ["B2", 15], ["=A1+B2"], ["A1"], ["=A1+B2"]]

输出：[null, 12, null, 16, null, 25, null, 15]

解释：
Spreadsheet(3)            // 3 行 26 列，全为 0
getValue("=5+7")          // 12
setCell("A1", 10)         // A1 = 10
getValue("=A1+6")         // 10 + 6 = 16
setCell("B2", 15)         // B2 = 15
getValue("=A1+B2")        // 10 + 15 = 25
resetCell("A1")           // A1 归零
getValue("=A1+B2")        // 0 + 15 = 15
```

## 3. 解题思路

### 3.1 暴力思路

最直接的做法是开一个 `rows × 26` 的二维数组：`setCell` 直接下标赋值，`resetCell` 赋 $0$，`getValue` 把两个操作数解析成"格子坐标或字面量"再查表。$rows \le 1000$、列数 26，数组最多 $2.6\times 10^4$ 个格子，完全放得下，复杂度也够。

这个方案唯一的问题是**浪费**：$10^4$ 次调用最多碰几千个格子，却要为 $2.6\times 10^4$ 个格子买单；更重要的是 `rows` 这个参数在我们的代码里其实毫无用处（它只约束输入合法性）。用哈希表存"被写过的格子"，代码更短、语义更贴近"稀疏表格"。

### 3.2 核心观察：两个操作数彼此独立，直接查表相加即可

![一个哈希表就是整张表：(列字母 + 行号) → 整数值](images/bw152_q2_cell_map.svg)

本题的公式被严格限制为 `"=X+Y"`，两个操作数**都只可能**是：

- 一个**单元格引用**（首字符是字母），查表得值，**从未被 `setCell` 设置过就按 $0$ 算**；
- 一个**非负整数字面量**（首字符是数字），直接取它的数值。

没有嵌套公式、没有区域求和、没有依赖链，所以**不需要拓扑排序或依赖图**（这一点与「设计 Excel 求和公式」那类题形成鲜明对比）。`getValue` 就是"解析 → 两次查表 → 相加"。

数据结构：

- `unordered_map<string,int> cells`：键是规范化后的单元格名（如 `"A1"`），值是整数；
- `setCell(cell, v)`：`cells[cell] = v`；
- `resetCell(cell)`：`cells.erase(cell)`——删除键与"置 0"在"查不到返回 0"的语义下完全等价，而且能避免表里堆积大量 0。

### 3.3 算法流程

![getValue 的三步：切分 → 逐项求值 → 相加](images/bw152_q2_formula_parse.svg)

```text
setCell(cell, value):   cells[cell] = value
resetCell(cell):        cells.erase(cell)

getValue(formula):                      # formula 形如 "=X+Y"
    plus = formula.find('+', 1)         # 从下标 1 开始找第一个 '+'
    X = formula[1 .. plus-1]
    Y = formula[plus+1 ..]
    return operand(X) + operand(Y)

operand(s):
    if s 的首字符是数字: return int(s)
    if cells 里存在 s:   return cells[s]
    return 0
```

### 3.4 示例演算

| 操作 | 解析 | 查表结果 | 返回 |
|------|------|----------|------|
| `getValue("=5+7")` | X = `"5"`、Y = `"7"` | 两个都是字面量 | 12 |
| `setCell("A1", 10)` | — | `A1 → 10` | null |
| `getValue("=A1+6")` | X = `"A1"`、Y = `"6"` | `A1 = 10` | 16 |
| `setCell("B2", 15)` | — | `B2 → 15` | null |
| `getValue("=A1+B2")` | X = `"A1"`、Y = `"B2"` | `10 + 15` | 25 |
| `resetCell("A1")` | — | 删除 `A1` | null |
| `getValue("=A1+B2")` | X = `"A1"`、Y = `"B2"` | `A1` 查不到按 0 | 15 |

输出序列 `[null, 12, null, 16, null, 25, null, 15]`，与示例一致。

## 4. 算法细节

1. **切分位置**：从下标 $1$ 开始找第一个 `'+'`。公式保证格式为 `"=X+Y"`，且 $X$ 是单元格引用（大写字母 + 数字）或纯数字，两者都不含 `'+'`，所以第一个 `'+'` 就是分隔符，不需要正则。
2. **字面量与引用的判定**：看首字符是不是数字（`isdigit` / `s[0].isdigit()`）。单元格引用一定以 `'A'`~`'Z'` 开头，因此判定是**无歧义**的。
3. **缺省值**：未设置的格子按 $0$ 算。用 `erase` 实现 `resetCell`，查表时"找不到就返回 0"，两件事由同一个语义保证，不必真的往表里写 $0$。
4. **行号可能是多位数**：`"B10"`、`"Z1000"` 都要能处理，所以不能假设单元格名长度为 2；本方案把整串当键，天然不受影响。
5. **`rows` 不必保存**：它只用于限定合法行号范围，题目保证输入合法，因此构造函数可以什么都不做（C++ 里用 `(void)rows;` 消除未使用参数告警）。
6. **数值范围**：`value ≤ 10^5`，两个字面量相加 ≤ $2\times 10^5$，`int` 足够，无溢出风险。

## 5. 正确性证明

**引理 1（切分正确）**：对任意合法公式 `"=X+Y"`，从下标 $1$ 起第一个 `'+'` 的位置 $p$ 满足：`formula[1..p-1] = X`、`formula[p+1..] = Y`。

**证明**：合法公式中 $X$ 与 $Y$ 分别是单元格引用或非负整数，两者都只含大写字母与十进制数字，不含 `'+'`；因此串中唯一的 `'+'` 就是分隔符。又 `formula[0] = '='`，故从下标 $1$ 开始第一次出现的 `'+'` 正是该分隔符。∎

**引理 2（求值正确）**：对任意操作数串 $s$，`operand(s)` 返回它在电子表格语义下的数值。

**证明**：分两种情况。若 $s$ 首字符是数字，由题设 $s$ 是非负整数字面量，`int(s)` 即其值。否则 $s$ 首字符是大写字母，由题设 $s$ 是合法的单元格引用；若该格曾被 `setCell` 设置，表内存的正是最新值（`setCell` 直接覆盖），返回它；若曾 `resetCell` 过或从未设置，表内无此键，返回 $0$，与"重置为 0 / 初始为 0"的语义一致。∎

**引理 3（状态维护）**：任意时刻，表内键集合恰为"当前值语义上非 0 的、被显式设置过的格子"的超集（允许存 0），且对每个格子，`operand` 的结果等于其当前应有值。

**证明**：`setCell` 把键设为新值，覆盖旧值；`resetCell` 删除键，之后查询返回 0；未出现的键查询返回 0。三种情况与题目语义逐一对应，归纳即得。∎

**定理**：`getValue(formula)` 返回公式的真实计算结果，即 $X$ 与 $Y$ 的当前值之和。

**证明**：由引理 1 正确切分出 $X, Y$；由引理 2、3 两者求值正确；返回它们的和即公式值。∎

## 6. 复杂度分析

- **`setCell` / `resetCell`**：哈希表一次写入/删除，均摊 $O(1)$（键为长度至多 4 的短字符串，字符串哈希也是 $O(1)$）。
- **`getValue`**：切分与两次查表，$O(|formula|)$，本题 $|formula|$ 是常数级（$\le 12$ 左右）。
- **总时间**：$O(\text{调用次数})$，$10^4$ 次调用轻松通过。
- **空间**：$O(U)$，$U$ 为被 `setCell` 过且未 `resetCell` 的不同格子数，不超过调用次数 $10^4$；若用二维数组则是固定的 $26 \times rows$ 空间。

## 7. 参考代码

### C++

```cpp
class Spreadsheet {
public:
    Spreadsheet(int rows) {
        (void)rows;
    }

    void setCell(string cell, int value) {
        cells[cell] = value;
    }

    void resetCell(string cell) {
        cells.erase(cell);
    }

    int getValue(string formula) {
        size_t plus = formula.find('+', 1);
        string a = formula.substr(1, plus - 1);
        string b = formula.substr(plus + 1);
        return operand(a) + operand(b);
    }

private:
    unordered_map<string, int> cells;

    int operand(const string& s) {
        if (!s.empty() && isdigit((unsigned char)s[0])) return stoi(s);
        auto it = cells.find(s);
        return it == cells.end() ? 0 : it->second;
    }
};
```

### Python

```python
class Spreadsheet:
    def __init__(self, rows: int):
        self.cells: dict[str, int] = {}

    def setCell(self, cell: str, value: int) -> None:
        self.cells[cell] = value

    def resetCell(self, cell: str) -> None:
        self.cells.pop(cell, None)

    def getValue(self, formula: str) -> int:
        a, b = formula[1:].split("+")
        return self._operand(a) + self._operand(b)

    def _operand(self, s: str) -> int:
        if s[0].isdigit():
            return int(s)
        return self.cells.get(s, 0)
```

## 8. 边界情况与易错点

1. **公式两端都是数字**：`"=5+7"` 不涉及任何格子，别把它当成"引用解析失败"。
2. **操作数含 `0`**：`"=0+0"`、`"=A1+0"` 都是合法的，`isdigit('0')` 为真，走字面量分支。
3. **`resetCell` 一个从未设置过的格子**：不能报错；用 `erase` / `pop` 天然安全。
4. **`resetCell` 之后再 `getValue`**：必须返回 $0$，不能返回上一次的旧值——如果用"置 0"实现，注意别写成"忽略这次调用"。
5. **多位数行号**：`"B10"`、`"Z1000"`，若按 `cell[0]` 和 `cell[1]` 手工拼坐标会错；直接整串作键最稳。
6. **把 `'+'` 找错**：必须从下标 $1$ 之后开始找（跳过开头的 `'='`），否则若实现成从头找，`'='` 不会干扰但语义不清晰；更严重的是不能按 `'='` 或其它字符切。
7. **误加依赖处理**：本题公式不会嵌套、不会互相引用，不要引入拓扑排序或递归求值，纯属自找麻烦。
8. **`rows` 未使用告警**：C++ 中未使用的构造参数会触发 `-Wunused-parameter`，用 `(void)rows;` 静默掉即可，不要为了"用上它"而多开一个数组。
