# LeetCode 最长特殊路径 II 题解

## 1. 题目概述

- **标题 / 题号**：最长特殊路径 II（#3486，hard）
- **链接**：https://leetcode.cn/problems/longest-special-path-ii/
- **来源**：LeetCode 第 152 场双周赛 Q4
- **难度**：困难
- **标签**：树、深度优先搜索、数组、哈希表、前缀和

**题意**：给定一棵以 $0$ 为根的无向树，$n$ 个节点，`edges[i] = [uᵢ, vᵢ, lengthᵢ]` 表示一条长度为 $length_i$ 的边；`nums[i]` 是节点 $i$ 的值。

一条**特殊路径**是**从祖先到子孙的向下路径**，且路径上所有节点值**互不相同，最多允许一个值出现两次**。

返回长度为 2 的数组 `result`：`result[0]` 是**最长**特殊路径的**长度**（边权和），`result[1]` 是所有最长特殊路径中**最少的节点数**。

**约束**：

- $2 \le n \le 5\times 10^4$
- $edges.length = n - 1$，$1 \le length_i \le 10^3$
- $0 \le nums[i] \le 5\times 10^4$
- 输入保证 `edges` 是一棵有效的树

## 2. 示例

**示例 1**

```text
输入：edges = [[0,1,1],[1,2,3],[1,3,1],[2,4,6],[4,7,2],[3,5,2],[3,6,5],[6,8,3]]
      nums = [1,1,0,3,1,2,1,1,0]
输出：[9,3]
解释：最长特殊路径有两条：
      1 → 2 → 4，值 [1,0,1]（值 1 出现两次），长度 3+6 = 9，3 个节点；
      1 → 3 → 6 → 8，值 [1,3,1,0]，长度 1+5+3 = 9，4 个节点。
      所有最长路径中节点数最少为 3。
```

**示例 2**

```text
输入：edges = [[1,0,3],[0,2,4],[0,3,5]], nums = [1,1,0,2]
输出：[5,2]
解释：最长路径是 0 → 3，值 [1,2]，长度 5，2 个节点。
      0 → 1 的值是 [1,1]，只有一个值重复，长度 3；0 → 2 长度 4。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有"祖先—后代"对 $(u,v)$，把 $u \to v$ 路径上的值收集起来数频次，判断"至多一个值出现两次"，合法就用前缀距离算长度。枚举 $O(n^2)$ 对、每对 $O(n)$ 判断，总 $O(n^3)$；$n = 5\times 10^4$ 时是 $10^{14}$ 量级，完全不可行。

优化方向很自然：**DFS 一遍，边往下走边维护当前根路径上的信息**，把"判断合法性 + 求最优起点"做到均摊很小。

### 3.2 核心观察：把「选起点」变成「选一个深度下界」

![把「选祖先」变成「选起点深度 U」：起点越浅，路径越长](images/bw152_q4_ancestor_window.svg)

固定路径的**最深节点** $v$（深度 $dep[v]$）。任何以 $v$ 为最深点的特殊路径都由"起点 $u$"决定，而 $u$ 必是 $v$ 的祖先（或 $v$ 自己）。设起点深度为 $U = dep[u]$，则：

- **路径长度** $= dist[v] - dist[u]$（根到节点距离的前缀和之差）；
- **节点数** $= dep[v] - U + 1$。

因为所有边权都是正整数，$dist$ 沿路径**严格递增**，所以让起点**越浅**（$U$ 越小）路径就越长、节点数也越多。于是问题变成：

> 对每个 $v$，求出**允许的最浅起点深度 $U_{\min}$**，取 $u = $ 深度为 $U_{\min}$ 的那个祖先，就是一个候选答案。

再看"合法"这个条件怎么变成对 $U$ 的约束。

### 3.3 算法流程：两个约束合成的下界

![U 的三个来源：两个约束都只要求「起点更深」](images/bw152_q4_constraints.svg)

设当前根到 $v$ 的路径上，某个值 $x$ 的出现深度依次为 $o_1 < o_2 < \dots < o_k$（记 $k$ 为该值在**整条根路径**上的出现次数）。路径 $u \to v$ 中 $x$ 的出现次数，就是 $o_j \ge U$ 的个数。

**约束一：任何值不能出现三次。**
出现 $\ge 3$ 次 $\iff o_{k-2} \ge U$。所以必须对每个出现 $\ge 3$ 次的值都有 $U > o_{k-2}$，即

$$U \ge b1 + 1,\qquad b1 = \max_{\text{出现} \ge 3 \text{ 次的值}} o_{k-2}\quad(\text{不存在则 } b1 = -1)$$

**约束二：最多一个值出现两次。**
$x$ 出现 $\ge 2$ 次 $\iff o_{k-1} \ge U$，记 $s_x = o_{k-1}$（该值"倒数第二次出现"的深度）。要求满足 $s_x \ge U$ 的值至多一个，设所有 $s_x$ 中**第二大**的为 $s_{(2)}$，则

$$U \ge s_{(2)} + 1\quad(\text{不足两个值时 } s_{(2)} = -1)$$

两者合并：

$$\boxed{U_{\min} = \max\big(b1 + 1,\ s_{(2)} + 1,\ 0\big)}$$

而 $U_{\min} \le dep[v]$ 恒成立（$o_{k-2} \le dep[v] - 2$、$s_{(2)} \le dep[v] - 1$），所以总能取到合法的 $u$。

**如何维护 $b1$ 与 $s_{(2)}$？** 用 DFS 维护每个值的深度栈 `occ[x]`，外加两个"可删除的多重集合"：

- `b1set` 存放所有出现 $\ge 3$ 次的值的 $o_{k-2}$，取 $\max$ 即 $b1$；
- `sset` 存放所有出现 $\ge 2$ 次的值的 $s_x$，取**前两大**即得 $s_{(1)}$ 与 $s_{(2)}$。

进入节点：先删掉该值旧的出现次数带来的贡献，压入新深度，再加入新贡献；退出节点时反向操作。这样两个集合的内容**始终**等于"当前根路径"对应的贡献集合。

![DFS 一趟到底：路径上只维护三个结构](images/bw152_q4_dfs_state.svg)

```text
1. 迭代 DFS（栈里放 (节点, 父节点, 根距离, 深度, 是否退出)）
2. 进入 v：
       delContrib(nums[v])；occ[nums[v]].push(dep)；addContrib(nums[v])
       pathDist[dep] = dist
       b1 = b1set 的最大值（空则 -1）；s2 = sset 的第二大（不足两个则 -1）
       U  = max(b1+1, s2+1, 0)
       candLen = dist − pathDist[U]，candNodes = dep − U + 1
       用 (candLen, −candNodes) 更新全局最优
3. 退出 v：delContrib；occ[x].pop()；addContrib
```

### 3.4 示例演算

以示例 2 为例：树为 $0$ 连 $1,2,3$（边权 $3,4,5$），`nums = [1,1,0,2]`。

| 访问节点 | `occ` 状态 | $b1$ | $s_{(2)}$ | $U_{\min}$ | 候选（长度, 节点数） |
|----------|------------|------|-----------|------------|----------------------|
| 0 | 1:[0] | -1 | -1 | 0 | (0, 1) |
| 1 | 1:[0,1] | -1 | -1（只有一个 $s=0$） | 0 | (3, 2) |
| 2 | 1:[0], 0:[1] | -1 | -1 | 0 | (4, 2) |
| 3 | 1:[0], 2:[1] | -1 | -1 | 0 | **(5, 2)** |

取最大长度 5、节点数 2，与输出 $[5,2]$ 一致。示例 1 中，走到节点 4 时根路径值序列为 $1,1,0,1$（`nums[0..]`），值 1 出现三次，于是 $b1$ 把起点压到深度 1，得到路径 $1\to2\to4$（长度 9、3 个节点）；走到节点 8 时同理得到 $1\to3\to6\to8$（长度 9、4 个节点），最终 $[9,3]$。

## 4. 算法细节

1. **迭代 DFS**：$n$ 可达 $5\times10^4$，链状树会让递归深度到 $5\times10^4$，C++ 可能爆栈、Python 一定会。用显式栈 + "(节点, 父节点, 距离, 深度, 是否退出)" 事件即可。
2. **`pathDist` 按深度索引**：DFS 过程中同一深度只属于当前路径，回溯后被新分支覆盖，不需要额外回滚；读取 `pathDist[U]` 得到的正是当前路径上深度 $U$ 那个祖先到根的距离。
3. **贡献的增删要成对**：进入节点与退出节点分别调用 `delContrib` + `addContrib`，保证集合内容与 `occ` 严格同步。C++ 用 `multiset` 显式 `erase(find(x))`（只删一个实例）；Python 用"大顶堆 + 惰性删除计数器"（`Counter` 记待删次数，取堆顶前先弹出已删项）。
4. **取前两大**：`sset` 需要第二大值。C++ 用 `rbegin()` 再 `++`；Python 先弹出堆顶、清理后再看新堆顶，随后把原堆顶放回。
5. **更新答案的 tie-break**：长度更大就替换；长度相同则取节点数更小的（等价于取 $U$ 更小的候选，但对不同 $v$ 的候选必须显式比较）。
6. **值域映射**：`nums[i] \le 5\times10^4$，可以直接开 `maxVal+1` 个 `vector`，省掉哈希开销。
7. **`dist` 用 64 位**：最长 $5\times10^4 \times 10^3 = 5\times10^7$，`int` 其实够，但涉及差值运算，用 `long long` 更稳妥。

## 5. 正确性证明

固定 $v$，记 $P$ 为根到 $v$ 的节点序列，`occ[x]` 为值 $x$ 在 $P$ 上的出现深度序列 $o_1 < \dots < o_k$。

**引理 1（合法性 = 两个深度下界）**：设 $u$ 是 $v$ 的祖先（或 $v$ 自己），$U = dep[u]$。则路径 $u \to v$ 合法，当且仅当 $U > b1$ 且 $U > s_{(2)}$，其中 $b1$、$s_{(2)}$ 如 §3.3 定义。

**证明**：值 $x$ 在 $u \to v$ 上的出现次数为 $t_x = |\{j : o_j \ge U\}|$。

- 若 $t_x \ge 3$，则 $o_{k-2} \ge U$（因为至少有 $o_{k-2}, o_{k-1}, o_k$ 三个满足 $\ge U$）；反之若 $o_{k-2} \ge U$，则 $t_x \ge 3$。故"不存在出现 3 次的值" $\iff$ 对所有 $x$ 有 $o_{k-2} < U$ $\iff$ $U > b1$。
- 若 $t_x \ge 2$，则 $o_{k-1} \ge U$；反之若 $o_{k-1} \ge U$，则 $t_x \ge 2$。故"至多一个值出现两次" $\iff$ 满足 $s_x \ge U$ 的值至多一个 $\iff$ $U > s_{(2)}$（第二大者都不满足，则至多只有最大者满足）。

两者同时成立即合法。∎

**引理 2（最浅合法起点最优）**：对固定 $v$，记 $U_{\min} = \max(b1+1, s_{(2)}+1, 0)$，则 $U_{\min} \le dep[v]$，且以 $u = $ 深度 $U_{\min}$ 的祖先为起点时，路径长度与节点数分别达到"以 $v$ 为终点的所有路径"中的最大值与最小值。

**证明**：由引理 1，合法起点集合是深度落在 $[U_{\min}, dep[v]]$ 的祖先集合，是一个非空后缀（$U_{\min} \le dep[v]$ 见 §3.3 的不等式，且 $U_{\min} \ge 0$ 保证取得到）。长度 $= dist[v] - dist[u]$，节点数 $= dep[v] - U + 1$；由于每条边权 $\ge 1$，$dist$ 随深度严格递增，故 $U$ 最小（起点最浅）时 $dist[u]$ 最小，长度最大、节点数最小。∎

**引理 3（结构维护正确）**：在 DFS 的任意时刻，`occ[x]` 恰为值 $x$ 在当前根路径上的出现深度（升序），`b1set` 恰含每个出现 $\ge 3$ 次值的 $o_{k-2}$（每值一个），`sset` 恰含每个出现 $\ge 2$ 次值的 $s_x$（每值一个）。

**证明**：对 DFS 事件序列归纳。初始时三者皆空，与"根路径为空"一致。进入节点 $v$ 时，先把值 $x = nums[v]$ 的旧贡献（存在时）从两个集合删掉，再把 $dep[v]$ 压入 `occ[x]`，最后按新长度 $k$ 加入 $o_{k-2}$（若 $k \ge 3$）与 $s_x = o_{k-1}$（若 $k \ge 2$）；退出时对称。由于 $x$ 的旧贡献被精确删除、新贡献被精确加入，且其它值的贡献未变，不变式在每一步后成立。∎

**定理**：算法返回的 `[最长长度, 最少节点数]` 与题目要求一致。

**证明**：任何一条特殊路径都有唯一的最深节点 $v$，且以 $v$ 为终点、某个祖先 $u$ 为起点。由引理 2，对每个 $v$，最优候选（同长度下节点最少）就是 $U_{\min}$ 对应的那条路径，算法对每个 $v$ 恰好计算了它。故全局最优必在候选集中，取最大值（长度优先、节点数次优）即得答案。由引理 3，算法使用的 $b1$ 与 $s_{(2)}$ 正是当前路径的真实值，故候选计算正确。∎

## 6. 复杂度分析

- **DFS 遍历**：每个节点进出各一次，共 $O(n)$ 步。
- **集合操作**：每步常数次 `multiset` 插入/删除，$O(\log n)$；Python 的堆操作同理。
- **取前两大**：C++ `rbegin()` 两次迭代 $O(1)$；Python 一次弹出 + 一次压入 $O(\log n)$。
- **总时间**：$O(n \log n)$，$n = 5\times10^4$ 时约 $10^6$ 次基本操作。
- **空间**：$O(n + \max nums)$。`occ` 按值域开数组、总元素数恰为路径长度 $\le n$；`pathDist` 与 DFS 栈均 $O(n)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> longestSpecialPath(vector<vector<int>>& edges, vector<int>& nums) {
        int n = (int)nums.size();
        vector<vector<pair<int, int>>> g(n);
        for (auto& e : edges) {
            g[e[0]].push_back({e[1], e[2]});
            g[e[1]].push_back({e[0], e[2]});
        }
        int maxVal = 0;
        for (int x : nums) maxVal = max(maxVal, x);

        vector<vector<int>> occ(maxVal + 1);   // 值 -> 当前路径上该值的深度栈
        multiset<int> b1set, sset;             // 三连约束 / 重复约束的候选深度
        vector<long long> pathDist(n + 1, 0);  // 按深度记录根到当前节点的距离

        // 让 x 的贡献与它当前的出现次数保持一致（进入/退出各调用一次）
        auto addContrib = [&](int x) {
            auto& v = occ[x];
            int k = (int)v.size();
            if (k >= 3) b1set.insert(v[k - 3]);
            if (k >= 2) sset.insert(v[k - 2]);
        };
        auto delContrib = [&](int x) {
            auto& v = occ[x];
            int k = (int)v.size();
            if (k >= 3) b1set.erase(b1set.find(v[k - 3]));
            if (k >= 2) sset.erase(sset.find(v[k - 2]));
        };

        long long bestLen = -1;
        int bestNodes = 1000000000;   // 节点数的哨兵上界
        struct Ev { int u, p, dep; long long dist; bool exit; };
        vector<Ev> st;
        st.push_back({0, -1, 0, 0, false});
        while (!st.empty()) {
            Ev e = st.back();
            st.pop_back();
            int x = nums[e.u];
            if (e.exit) {
                delContrib(x);
                occ[x].pop_back();
                addContrib(x);
                continue;
            }
            delContrib(x);
            occ[x].push_back(e.dep);
            addContrib(x);
            pathDist[e.dep] = e.dist;

            int b1 = b1set.empty() ? -1 : *b1set.rbegin();     // 最大的「倒数第三个」深度
            int s2 = -1;                                       // 第二大的「倒数第二个」深度
            if (sset.size() >= 2) {
                auto it = sset.rbegin();
                ++it;
                s2 = *it;
            }
            int U = max(max(b1 + 1, s2 + 1), 0);                // 最浅的合法祖先深度
            long long len = e.dist - pathDist[U];
            int nodes = e.dep - U + 1;
            if (len > bestLen || (len == bestLen && nodes < bestNodes)) {
                bestLen = len;
                bestNodes = nodes;
            }

            st.push_back({e.u, e.p, e.dep, e.dist, true});
            for (auto& [nv, w] : g[e.u]) {
                if (nv != e.p) st.push_back({nv, e.u, e.dep + 1, e.dist + w, false});
            }
        }
        return {(int)bestLen, bestNodes};
    }
};
```

### Python

```python
import heapq
from collections import Counter


class Solution:
    def longestSpecialPath(self, edges: list[list[int]], nums: list[int]) -> list[int]:
        n = len(nums)
        g: list[list[tuple[int, int]]] = [[] for _ in range(n)]
        for u, v, w in edges:
            g[u].append((v, w))
            g[v].append((u, w))

        occ: list[list[int]] = [[] for _ in range(max(nums) + 1)]  # 值 -> 深度栈
        # 两个「可删除的大顶堆」：heap 存 -深度，dead 记录被删除但仍在堆里的次数
        b1heap: list[int] = []
        s1heap: list[int] = []
        b1dead: Counter = Counter()
        s1dead: Counter = Counter()
        path_dist = [0] * (n + 1)          # 按深度记录根到当前节点的距离

        def clean(h: list[int], dead: Counter) -> None:
            while h and dead[-h[0]] > 0:
                dead[-h[0]] -= 1
                heapq.heappop(h)

        def top(h: list[int], dead: Counter) -> int:
            clean(h, dead)
            return -h[0] if h else -1

        def add_contrib(x: int) -> None:
            v = occ[x]
            k = len(v)
            if k >= 3:
                heapq.heappush(b1heap, -v[k - 3])
            if k >= 2:
                heapq.heappush(s1heap, -v[k - 2])

        def del_contrib(x: int) -> None:
            v = occ[x]
            k = len(v)
            if k >= 3:
                b1dead[v[k - 3]] += 1
            if k >= 2:
                s1dead[v[k - 2]] += 1

        best_len, best_nodes = -1, 10 ** 9
        stack = [(0, -1, 0, 0, False)]     # (节点, 父节点, 距离, 深度, 是否退出)
        while stack:
            u, p, dist, dep, exiting = stack.pop()
            x = nums[u]
            if exiting:
                del_contrib(x)
                occ[x].pop()
                add_contrib(x)
                continue
            del_contrib(x)
            occ[x].append(dep)
            add_contrib(x)
            path_dist[dep] = dist

            b1 = top(b1heap, b1dead)       # 最大的「倒数第三个」深度
            s2 = -1                        # 第二大的「倒数第二个」深度
            if s1heap:
                clean(s1heap, s1dead)
                if s1heap:
                    first = heapq.heappop(s1heap)
                    clean(s1heap, s1dead)
                    if s1heap:
                        s2 = -s1heap[0]
                    heapq.heappush(s1heap, first)
            U = max(b1 + 1, s2 + 1, 0)     # 最浅的合法祖先深度

            length = dist - path_dist[U]
            nodes = dep - U + 1
            if length > best_len or (length == best_len and nodes < best_nodes):
                best_len, best_nodes = length, nodes

            stack.append((u, p, dist, dep, True))
            for nv, w in g[u]:
                if nv != p:
                    stack.append((nv, u, dist + w, dep + 1, False))
        return [best_len, best_nodes]
```

## 8. 边界情况与易错点

1. **递归爆栈**：$5\times10^4$ 的链在 Python 里递归必崩、C++ 也可能栈溢出。必须用显式栈迭代。
2. **忘记"最多一个值出现两次"的第二个约束**：只处理"三次"会漏掉两个不同值各出现两次的情形（例如 `1,2,1,2`），结果偏大。
3. **`s_{(2)}` 的空与单元素**：只有一个值出现两次时，$s_{(2)} = -1$，不构成任何限制；用 $0$ 当哨兵在 $k \ge 1$ 时不会错，但不严谨。
4. **贡献删除写错下标**：进入时新贡献是 $o_{k-2}/o_{k-1}$（$k$ 为**加入后**的次数），退出时要先按**删除前**的次数删旧贡献、再 `pop`、再按**删除后**的次数加回。这正是本题最容易写崩的地方，建议封装成 `addContrib` / `delContrib` 两个函数。
5. **`U` 越界**：理论上 $U \le dep[v]$，但若约束处理有误会取到 $dep[v]+1$，此时 `pathDist` 读到的是别的分支的脏值。可以加一行断言或在取 $U$ 后 `U = min(U, dep)` 兜底。
6. **tie-break 方向**：题目要"最长路径中**最少**节点数"，别写成最多；长度相同时要比较节点数。
7. **单节点路径**：长度 0、节点 1，本题数据保证 $n \ge 2$ 且边权为正，最优解一定落在某条至少一条边的路径上，初始化 `bestLen = -1` 即可自动被覆盖。
8. **多值同深**：两个不同值的 $s_x$ 可能相同，`sset` 必须按**多重集合**处理（重复元素保留），否则"前两大"会算错。
