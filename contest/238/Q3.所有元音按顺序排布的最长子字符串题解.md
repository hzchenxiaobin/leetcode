# LeetCode 所有元音按顺序排布的最长子字符串 题解

## 1. 题目概述

- **标题 / 题号**：所有元音按顺序排布的最长子字符串（#1839，medium）
- **链接**：https://leetcode.cn/problems/longest-substring-of-all-vowels-in-order/
- **来源**：LeetCode 第 238 场周赛 Q3
- **难度**：中等
- **标签**：字符串、滑动窗口、双指针

**题意**：称一个字符串是**美丽的**，当且仅当：① 5 个元音 `a`、`e`、`i`、`o`、`u` **都至少出现一次**；② 所有 `a` 都在所有 `e` 前面、所有 `e` 都在所有 `i` 前面……即元音按 `a < e < i < o < u` 的字典序**升序排布**。给定一个只含元音的字符串 `word`，返回其中**最长美丽子字符串**的长度；不存在则返回 `0`。子字符串是连续字符序列。

**约束**：

- `1 <= word.length <= 5 * 10^5`
- `word` 只包含字符 `'a'`、`'e'`、`'i'`、`'o'`、`'u'`

> 💡 读题抓两个信号：① 条件 ② 的「升序排布」是一条**单调性**——美丽子串内部相邻字符只能**相等或上升**，任何一处下降都是不可跨越的硬边界，这把任意子串压缩成线性个「非降段」；② `word` 只含 5 种字符且元音的字典序恰好与 ASCII 序一致（`'a' < 'e' < 'i' < 'o' < 'u'`），判定无需任何映射表，直接字符比较。两者叠加暗示：一次线性扫描足矣。

## 3. 解题思路

### 3.1 暴力思路：枚举所有子串再逐一验证

枚举全部 $O(n^2)$ 个子串 $[i, j]$，每个子串从头扫一遍验证「相邻非降」与「5 种元音齐全」，单次 $O(n)$，总计 $O(n^3) \approx 10^{17}$（$n = 5 \times 10^5$）；即便固定左端点增量维护把单次验证降到 $O(1)$，$O(n^2) \approx 2.5 \times 10^{11}$ 个子串仍然远超周赛预算。

> ⚠️ 浪费在于无视结构：美丽子串**不可能跨越任何下降点**，而下降点至多 $n - 1$ 个，它们天然把 `word` 切成**线性个极大非降段**——所有跨段的枚举全是无用功。

### 3.2 核心观察：美丽 = a⁺e⁺i⁺o⁺u⁺，下降点是墙

![核心观察：美丽子串形如 a+e+i+o+u+ 的五块拼接，下降点切出极大非降段](images/1839_vowel_segment_concept.svg)

两个环环相扣的观察：

1. **美丽的块结构**：条件 ② 要求所有 `a` 在所有 `e` 前、所有 `e` 在所有 `i` 前……于是美丽子串必然形如
   $$a^{p}\,e^{q}\,i^{r}\,o^{s}\,u^{t}, \qquad p, q, r, s, t \ge 1$$
   ——五个**非空等值块**依序拼接。换言之，子串内部相邻字符**只能相等或严格上升**，一旦出现下降（如 `…io` 后跟 `a`）立刻出局。
2. **下降点切分**：凡 $word[i] < word[i-1]$ 处即**墙**，任何美丽子串必完整落在某个极大非降段内（§5 引理 2）。而段内字符非降，于是每个**上升**处引入的字母必然是段内**从未出现过的更大字母**——一个计数器 `distinct` 就能跟踪段内元音种数，连哈希集合都省了（§5 引理 3）。

> 💡 **推论（整段美丽）**：若某个极大非降段凑齐 5 种元音，则**整段**就是美丽的——整段非降 ✓ 且 5 种齐 ✓，该段的候选长度就是**段长**。`distinct` 在段内单调不减、首次到 5 后保持到段末，最优候选天然出现在段尾。

### 3.3 算法流程：一次扫描 + 段级重置

![算法流程：遇下降整段重置，distinct 到 5 更新答案](images/1839_vowel_scan_flow.svg)

`left` 是当前段段首、`distinct` 是段内已见元音种数，`right` 从 $1$ 扫到 $n-1$：

```text
left = 0，distinct = 1（首字符自带 1 种）
对每个 right：
    若 word[right] < word[right-1]：        # 下降点 —— 开新段
        left = right，distinct = 1
    否则若 word[right] > word[right-1]：    # 上升 —— 引入新元音
        distinct += 1
    （相等：什么都不做）
    若 distinct == 5：                      # 5 种齐，段前缀美丽
        ans = max(ans, right - left + 1)
```

> 💡 与经典滑窗（如第 3 题「无重复字符的最长子串」）的分水岭：那里条件被破坏时要**渐进收缩左端**；这里段一旦确定，段内种数**单调不减**、最优就是整段——`left` 只在下降点**整段重置**，永不回头。`left` 与 `right` 各至多前进 $n$ 步。

### 3.4 示例演算

![示例演算：word = aeiaaioaaaaeiiiiouuuooaauuaeiu 切成 6 个非降段，段③整段美丽](images/1839_vowel_walkthrough.svg)

以示例 1 `word = "aeiaaioaaaaeiiiiouuuooaauuaeiu"`（$n = 30$）走查。5 个下降点把串切成 6 个极大非降段：

| 段 | 区间 | 内容 | 上升数 → distinct | 美丽？ | 候选长度 |
|----|------|------|------------------|--------|----------|
| ① | [0,2] | `aei` | 2 → 3 | ✗ 缺 o、u | — |
| ② | [3,6] | `aaio` | 2 → 3 | ✗ 缺 e、u | — |
| ③ | [7,19] | `aaaaeiiiiouuu` | 4 → 5 | ✓ | **13** |
| ④ | [20,21] | `oo` | 0 → 1 | ✗ | — |
| ⑤ | [22,25] | `aauu` | 1 → 2 | ✗ 缺 e、i、o | — |
| ⑥ | [26,29] | `aeiu` | 3 → 4 | ✗ 缺 o | — |

段③内部：`distinct` 在位置 17（首个 `u`）**首次达 5**，`ans = 17 - 7 + 1 = 11`；随后两个 `u` 相等续接，`distinct` 保持 5，`ans` 续涨为 12、13——段尾恰为整段长。最终 `ans = 13` ✓（对应子串 `aaaaeiiiiouuu`）。

## 4. 算法细节

1. **字母序即 ASCII 序**：`'a'(97) < 'e'(101) < 'i'(105) < 'o'(111) < 'u'(117)`，元音的字典序恰好与字符编码一致——直接 `word[right] < word[right - 1]` 比较即可，不需要任何「元音序号」映射表（这是题面「只含元音」送的大礼）。
2. **`distinct` 的双重身份**：它是段内**种数**；而在被判定美丽的段里，它同时就是**块号**——5 种齐的非降段必形如 $a^p e^q i^r o^s u^t$，第 $k$ 次上升恰进入第 $k+1$ 块。`distinct == 5` 因此与「五块齐备」严格等价：字母表只有 5 个字母、上升至多 4 次，种数到 5 当且仅当五种全到场（§5 引理 3(iii)）。
3. **为何每步都判 `distinct == 5`，而不等段尾收账**：段内种数单调不减，到 5 后只会保持到段末——在每个 `distinct == 5` 的位置更新，段尾自动取到整段长；且循环内更新天然覆盖**最后一个段**。若改成「段结束时收账」，最后一个段没有下降点收尾、循环结束后又容易忘记补刀，是经典 WA 点。
4. **重置语义**：新段以 `word[right]` 起始、已含 1 种元音，故重置 `distinct = 1` 而非 `0`；`left = right` 跳到新段首。`<` / `=` / `>` 三分支一个都不能写错：相等分支既不重置也不计数。
5. **无需哈希**：非降性保证「上升必引入新字母」（§5 引理 3(i)），一个整型计数器顶替了哈希集合，空间 $O(1)$ 且常数极小。若段内允许下降（如无序版元音题），这一省力就不成立，得换位掩码/哈希。
6. **正则一行流（Python 玩法）**：美丽的正则刻画就是 `a+e+i+o+u+`，故 `max(map(len, re.findall(r'a+e+i+o+u+', word)), default=0)` 直接得到答案——各块字母互不相同、贪心匹配恰好逐段吃满且无回溯爆炸，与双指针版殊途同归。

## 5. 正确性证明

**引理 1（美丽的刻画）**：只含元音的子串 $s$ 是美丽的 $\iff$ $s$ **非降**（相邻 $s_k \le s_{k+1}$）**且** $s$ 含全部 5 种元音。

**证明**：（⇐）设 $s$ 非降且 5 种齐。对任意字母 $x < y$，若存在位置 $p < q$ 使 $s_p = y$、$s_q = x$，则 $s_p > s_q$ 与非降矛盾；故 $x$ 的每次出现都在 $y$ 的每次出现之前——条件 ② 成立；条件 ① 即「5 种齐」。（⇒）条件 ① 直接给出 5 种齐。条件 ② 对相邻元音对（`a,e`）、（`e,i`）、（`i,o`）、（`o,u`）给出「前者全在后者前」，经传递可得对**任意** $x < y$，「$x$ 全在 $y$ 前」。反设 $s$ 存在相邻下降 $s_p > s_{p+1}$，取 $x = s_{p+1} < y = s_p$，则存在 $y$（位置 $p$）在 $x$（位置 $p+1$）之前，违反上述断言，矛盾；故 $s$ 非降。∎

**引理 2（切分）**：美丽子串必完整落在某个极大非降段内。

**证明**：由引理 1，美丽子串非降，其内部不含任何相邻下降对。若它跨越某个下降点 $(i-1, i)$（即 $word[i-1] > word[i]$），则该相邻下降对落入子串内部，矛盾。极大非降段恰由全部下降点切分而成、段内无下降点，故非降子串不能跨过任何下降点，只能完整含于两相邻下降点之间，即落在某个极大非降段内。∎

**引理 3（段内计数）**：设 $R = word[l..r]$ 是一个非降段，$D(k)$ 表示 $word[l..k]$ 中不同字母数：
(i) 每个上升处 $word[k] > word[k-1]$ 引入的字母在 $word[l..k-1]$ 中从未出现，且 $D(k) = D(k-1) + 1$；相等处 $D(k) = D(k-1)$；
(ii) $D$ 在段内单调不减；
(iii) 段内上升总数至多 4，且 $D(r) = 5 \iff R$ 含全部 5 种元音。

**证明**：(i) 非降使 $word[k-1]$ 是前缀 $word[l..k-1]$ 的最大字母，上升处 $word[k] > word[k-1] \ge$ 前缀中所有字母，故 $word[k]$ 是新字母，$D$ 增 1；相等处 $word[k] = word[k-1]$ 已在旧前缀中出现，$D$ 不变。(ii) 由 (i) 立得。(iii) 上升处的字母沿「严格变大」排成严格递增序列，字母表仅 5 个字母，故上升至多 4 次；又 $D(r) = 1 + \text{段内上升总数}$，$D(r) = 5$ 当且仅当段内出现过 5 个互不相同的字母，即全部 5 种元音。∎

**引理 4（循环不变量）**：处理完位置 $right$ 后，$left$ 是包含 $right$ 的极大非降段的段首，且 $distinct = D(right)$（该段从段首到 $right$ 的种数）。

**证明**：对 $right$ 归纳。基准（$right = 0$）：$left = 0$、$distinct = 1$，恰是首个极大段前缀的段首与种数。归纳步：若 $word[right] < word[right-1]$，则 $right$ 开启新段，其段首为 $right$、前缀种数为 1，赋值恰是如此；否则 $right$ 与 $right-1$ 同段，段首不变，由引理 3(i) 种数按「上升 +1、相等不变」更新，与 $D(right)$ 一致。∎

**定理**：上述一遍扫描返回 `word` 中最长美丽子字符串的长度。

**证明**：（ans ≤ OPT）每次更新 `ans` 时 `distinct == 5`，由引理 4，窗口 $[left, right]$ 是某极大非降段的一个含 5 种元音的前缀——它非降且 5 种齐，由引理 1 是美丽子串，长度 $right - left + 1$ 可行，故 `ans` 不超过最优值 OPT。（ans ≥ OPT）取最长美丽子串 $S$，由引理 2 它落在某极大段 $R$ 内；$S$ 含 5 种元音且 $R \supseteq S$，故 $R$ 也含 5 种且非降，由引理 3(iii) $R$ 末位置 $r^*$ 处种数为 5。扫描处理 $r^*$ 时，由引理 4 有 $left = R$ 的段首且 $distinct = 5$，该轮执行 `ans = max(ans, r* - left + 1) = |R| ≥ |S| = OPT`。两向合并，`ans = OPT`。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。`right` 单趟扫描，每步一次字符比较加至多一次计数与更新；`left` 仅在下降点跳跃且只增不减，总移动量不超过 $n$。$n = 5 \times 10^5$ 时毫秒级通过。
- **空间复杂度**：$O(1)$。仅 `ans`、`left`、`distinct` 三个整型变量，无哈希表、无数组——非降性把「种类维护」从集合压缩成了计数器。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int longestBeautifulSubstring(string word) {
        int n = word.size(), ans = 0;
        int left = 0, distinct = 1;          // 段首 / 段内已见元音种数
        for (int right = 1; right < n; right++) {
            if (word[right] < word[right - 1]) {
                left = right;                // 下降点：整段重置
                distinct = 1;
            } else if (word[right] > word[right - 1]) {
                distinct++;                  // 上升：引入新元音
            }
            if (distinct == 5) {             // 五块齐备，段前缀美丽
                ans = max(ans, right - left + 1);
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def longestBeautifulSubstring(self, word: str) -> int:
        ans = left = 0
        distinct = 1
        for right in range(1, len(word)):
            if word[right] < word[right - 1]:
                left, distinct = right, 1    # 下降点：整段重置
            elif word[right] > word[right - 1]:
                distinct += 1                # 上升：引入新元音
            if distinct == 5:                # 五块齐备，段前缀美丽
                ans = max(ans, right - left + 1)
        return ans
```

## 8. 边界情况与易错点

1. **`distinct` 重置为 1 而非 0（头号坑）**：新段以 `word[right]` 起始、自带 1 种元音；置 0 会让全段种数系统性少 1，`distinct` 永远到不了 5，返回恒 0。
2. **相等分支写错**：重置条件是**严格** `word[right] < word[right - 1]`；写成 `<=` 会把 `a→a` 误判成下降，每个等值块都被腰斩。相等时既不重置也不 `++`。
3. **漏判尾段**：把更新 `ans` 放在「段结束」时（下降点处收账），最后一个段没有下降点收尾，循环外又容易忘记补刀——在**每个** `distinct == 5` 的位置更新（如参考代码）则天然覆盖尾段。
4. **`n < 5` / 单字符**：循环不执行或 `distinct` 到不了 5，`ans` 自然为 0，无需特判；想省也可开头 `if (n < 5) return 0;`。
5. **全同字符（如 `"aaaaa"`）**：`distinct` 恒为 1，返回 0，判据天然覆盖。
6. **比较方向写反**：下降是「当前比前一个**小**」。把 `>` 当重置条件则逻辑完全颠倒（好在 `aaaa…` 之类的输入上会立刻显形）。
7. **只要长度不要子串**：题目只问长度，切勿顺手拼接子串本体——$n = 5 \times 10^5$ 的字符串构造会白白吃掉内存与时间。
