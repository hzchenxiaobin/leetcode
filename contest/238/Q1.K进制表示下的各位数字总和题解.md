# LeetCode K 进制表示下的各位数字总和 题解

## 1. 题目概述

- **标题 / 题号**：K 进制表示下的各位数字总和（#1837，easy）
- **链接**：https://leetcode.cn/problems/sum-of-digits-in-base-k/
- **来源**：LeetCode 第 238 场周赛 Q1
- **难度**：简单
- **标签**：数学

**题意**：给定十进制整数 $n$ 和基数 $k$，把 $n$ 转换成 $k$ 进制表示，返回转换后各位数字的**总和**。各位数字与其和均按十进制理解。

**约束**：

- `1 <= n <= 100`
- `2 <= k <= 10`

## 2. 示例

**示例 1**

```text
输入：n = 34, k = 6
输出：9
解释：34 的 6 进制表示为 54，5 + 4 = 9
```

**示例 2**

```text
输入：n = 10, k = 10
输出：1
解释：k = 10 时无需转换，1 + 0 = 1
```

**补充示例**

```text
输入：n = 100, k = 2
输出：3
解释：100 的二进制表示为 1100100，各位和 1+1+0+0+1+0+0 = 3
```

## 3. 解题思路

### 3.1 朴素思路：先拼出表示，再逐位求和

最直接的做法是把 $k$ 进制表示**完整构造出来**：反复"除 $k$ 取余"把余数存进数组，倒序拼接得到表示，再逐字符求和。正确且 $O(\log_k n)$，但对本题来说是**绕路**——题目只要求数字和，而加法满足交换律，"存数组、倒序、拼串"三步全是无用功。

### 3.2 核心观察：除 k 取余，边除边加

![除 k 取余法：余数即最低位](images/1837_basek_concept.svg)

**关键观察**：

- $n \bmod k$ 恰是 $n$ 的 $k$ 进制表示的**最低位**；
- $n / k$（整除）把最低位**剥掉**，商是剩下的高位部分；
- 重复到 $n = 0$，每一步的余数**直接累加**进答案即可。

> 💡 **最短路径**：求和对位序不敏感，所以既不用数组、也不用倒序——`while` 循环里两行代码搞定。

### 3.3 算法流程

![算法流程：while 循环逐位累加](images/1837_basek_flow.svg)

```text
sum ← 0
while n > 0:
    sum ← sum + n mod k    # 剥出最低位并累加
    n ← n div k            # 去掉最低位
return sum
```

### 3.4 示例演算

![示例演算：n=34, k=6](images/1837_basek_walkthrough.svg)

以 $n = 34,\ k = 6$ 为例：

| 轮次 | 除法 | 余数 | 商（新 n） | sum |
|------|------|------|------|------|
| 初始 | — | — | 34 | 0 |
| ① | 34 ÷ 6 | 4 | 5 | 0 + 4 = 4 |
| ② | 5 ÷ 6 | 5 | 0 | 4 + 5 = 9 |
| 停止 | n = 0 | — | — | **9** ✓ |

验证：$34 = 5 \times 6 + 4$，即 $54_6$，$5 + 4 = 9$ ✓

## 4. 算法细节

1. **位提取**：每轮 `n % k` 取出当前最低位。$2 \le k \le 10$ 保证余数 $r \in [0, k)$ 是单个十进制数字，直接相加即可。
2. **位消除**：`n /= k`（整除）去掉该位。$k \ge 2$ 保证商严格小于 $n$，循环必然终止。
3. **顺序无关**：数字和满足交换律，余数按产生顺序（低位在前）直接累加，无需倒序——这是与"写出 $k$ 进制表示"类题目（如 504 题）的本质区别。
4. **语言差异**：C++ 的 `int` 整除 `/` 与取余 `%` 直接可用；Python 用 `//=` 与 `%`。

## 5. 正确性证明

**引理 1（余数即最低位）**：设 $n \ge 1$，$n = q \cdot k + r$，$0 \le r < k$，则 $r$ 是 $n$ 的 $k$ 进制表示的最低位，且 $q$ 的 $k$ 进制表示恰为 $n$ 去掉最低位后的高位部分。

**证明**：设 $q$ 的 $k$ 进制表示为 $\sum_{i=0}^{m-1} a_i k^i$（$0 \le a_i < k$），则

$$n = k \sum_{i=0}^{m-1} a_i k^i + r = \sum_{i=0}^{m-1} a_i k^{i+1} + r$$

每位数字均落在 $[0, k)$，构成合法的 $k$ 进制展开，且个位恰为 $r$。∎

**引理 2（数字和可加）**：记 $S(n)$ 为 $n$ 的 $k$ 进制各位数字和，则 $S(n) = S(q) + r$。

**证明**：由引理 1，$n$ 的数字多重集等于 $q$ 的数字多重集添上元素 $r$，逐位求和即得。∎

**定理**：上述循环结束时 `sum` $= S(n_0)$（$n_0$ 为初始 $n$）。

**证明**：对 $n_0$ 归纳。若 $n_0 = 0$，循环不执行，`sum` $= 0$，与空表示的数字和约定一致。若 $n_0 \ge 1$，第一轮执行 `sum += r`、`n = q`，且 $q = \lfloor n_0 / k \rfloor < n_0$；由归纳假设，余下轮次恰好累加 $S(q)$，合计 $S(q) + r = S(n_0)$。又商每轮严格递减且非负，循环必在有限步内终止。∎

## 6. 复杂度分析

- **时间复杂度**：$O(\log_k n)$。每轮 $n$ 至少缩小为原来的一半（$k \ge 2$），循环次数为 $\lfloor \log_k n \rfloor + 1$；本题 $n \le 100$，最多 7 轮。
- **空间复杂度**：$O(1)$。只用 `sum` 与循环变量，不需要数组或字符串。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int sumBase(int n, int k) {
        int sum = 0;
        while (n > 0) {
            sum += n % k;
            n /= k;
        }
        return sum;
    }
};
```

### Python

```python
class Solution:
    def sumBase(self, n: int, k: int) -> int:
        s = 0
        while n:
            s += n % k
            n //= k
        return s
```

## 8. 边界情况与易错点

1. **n < k**：$k$ 进制表示只有一位，答案就是 $n$ 本身，循环恰好执行一轮（如 $n = 5, k = 8$ → 5），无需特判。
2. **中间位为 0**：如 $n = 60, k = 6$，表示为 $140_6$，中间余数为 0——照常累加（加 0）并继续处理商，不能提前退出。
3. **k = 10**：退化为十进制数位和，同一份代码天然覆盖，不要写特判分支。
4. **答案按十进制返回**：`sum` 本身就是十进制数，不要画蛇添足再做一次进制转换。
5. **无溢出风险**：$n \le 100$，数字和远小于 `int` 上界。
