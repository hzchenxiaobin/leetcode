# LeetCode 最高建筑高度 题解

## 1. 题目概述

- **标题 / 题号**：最高建筑高度（#1840，hard）
- **链接**：https://leetcode.cn/problems/maximum-building-height/
- **来源**：LeetCode 第 238 场周赛 Q4
- **难度**：困难
- **标签**：数组、排序、数学、约束传播

**题意**：从 $1$ 到 $n$ 编号排成一列建 $n$ 栋建筑。高度需满足：① 每栋高度是非负整数；② 第一栋高度必须为 $0$；③ 任意相邻两栋高度差不超过 $1$。此外数组 `restrictions` 给出额外限制，`restrictions[i] = [id_i, maxHeight_i]` 表示第 `id_i` 栋高度不能超过 `maxHeight_i`。在所有限制下，返回最高建筑能达到的最高高度。

**约束**：

- `2 <= n <= 10^9`
- `0 <= restrictions.length <= min(n - 1, 10^5)`
- `2 <= id_i <= n`
- `id_i` 是唯一的
- `0 <= maxHeight_i <= 10^9`

> 💡 读题抓两个信号：① $n$ 高达 $10^9$ 而限制只有 $10^5$ 个——逐位置枚举或 DP 必然超时，答案必然**完全由限制点决定**；② 「相邻差 $\le 1$」意味着一个限制的影响以**斜率 1** 向两侧扩散：限制 $(\mathrm{id}, c)$ 对任意位置 $x$ 施加的上界恰是 $c + |x - \mathrm{id}|$，一个 **V 形**。整道题就是把 $m+1$ 个 V 形的**下包络**的最高点找出来。

## 3. 解题思路

### 3.1 暴力思路

最直接的暴力是对每个位置 $x \in [1, n]$ 计算「所有 V 形上界的最小值」再取最大，即 $O(nm)$——在 $n \le 10^9$ 下完全不可行；按位置 DP 同样死于 $n$ 的规模。

但这个「算不动的式子」本身恰恰是突破口：$H(x) = \min_r \big(c_r + |x - \mathrm{id}_r|\big)$ 是关于 $x$ 的**分段线性函数**，每段斜率只可能是 $+1$、$-1$ 或 $0$。它的最大值不可能出现在段内非极值处，而所有「拐点」都源自某个限制点——于是候选位置从 $10^9$ 个压缩到 $O(m)$ 个段，每段只需 $O(1)$ 求出峰值。

### 3.2 核心观察：V 形包络与下包络

把「建筑 1 高度为 0」也看作一个限制 $(1, 0)$。于是共有 $m+1$ 个限制点，每个限制点 $(\mathrm{id}, c)$ 生成一个 V 形上界函数：

$$f_r(x) = c_r + |x - \mathrm{id}_r|$$

三个关键事实（证明见 §5）：

1. **上界**：任何合法高度序列 $h$ 都逐点满足 $h(x) \le f_r(x)$——从 $\mathrm{id}_r$ 走到 $x$ 需要 $|x - \mathrm{id}_r|$ 步，每步高度至多变 $1$。
2. **下包络**：$H(x) = \min_r f_r(x)$ 压住所有合法序列，即 $h(x) \le H(x)$。
3. **下包络自身合法**：每个 $f_r$ 相邻两点差恰为 $\pm 1$，有限个 1-Lipschitz 函数的逐点最小值仍 1-Lipschitz，且 $H(1) = 0$、$H \ge 0$、$H$ 满足所有限制。

因此 **$H$ 就是「逐点最优天际线」**：任何合法方案逐点不超过 $H$，而 $H$ 自己就是合法方案。答案 $= \max_{1 \le x \le n} H(x)$。剩下的工作只是高效求出这个最大值——它只会出现在**限制点**、**相邻两限制点之间的「帐篷峰」**，或**最后一个限制点之后的尾段**。

![核心观察：每个限制生成 V 形上界，真实上界是所有 V 的下包络，峰值出现在两腿交叉处](images/1840_maxbuilding_envelope_concept.svg)

### 3.3 算法流程：两趟传播 + 逐段取峰

$H$ 在限制点 $\mathrm{id}_i$ 处的取值不必显式对 $m+1$ 个 V 求最小——按位置排序后，**两趟线性传播**即可求出：

1. 把 $(1, 0)$ 加入限制数组，按 $\mathrm{id}$ 升序排序；
2. **正向传播**：$h_i \leftarrow \min\big(h_i,\ h_{i-1} + (\mathrm{id}_i - \mathrm{id}_{i-1})\big)$，让左侧限制（含 $(1,0)$）的**右腿**逐个压过来；
3. **反向传播**：$h_i \leftarrow \min\big(h_i,\ h_{i+1} + (\mathrm{id}_{i+1} - \mathrm{id}_i)\big)$，补上右侧限制的**左腿**；
4. 此时 $h_i = H(\mathrm{id}_i)$。对相邻两个限制点 $(p, h_p)$、$(q, h_q)$，段 $[p, q]$ 内 $H(x) = \min\big(h_p + (x-p),\ h_q + (q-x)\big)$，最大值（帐篷峰）为：

$$\text{peak} = \left\lfloor \frac{h_p + h_q + (q - p)}{2} \right\rfloor$$

5. **尾段**：最后一个限制点 $(\mathrm{id}_{\text{last}}, h_{\text{last}})$ 之后 $H(x) = h_{\text{last}} + (x - \mathrm{id}_{\text{last}})$，在 $x = n$ 处取到 $h_{\text{last}} + (n - \mathrm{id}_{\text{last}})$；
6. 答案 $=$ 所有段峰与尾段的最大值（段峰不小于两端点高度，限制点自身无需单独考虑）。

![算法流程：加 (1,0) → 排序 → 正向传播 → 反向传播 → 逐段取峰 + 尾段 → 取最大值](images/1840_maxbuilding_two_pass_flow.svg)

### 3.4 示例演算

以示例 3 演算：$n = 10$，`restrictions = [[5,3],[2,5],[7,4],[10,3]]`。

**第一步**：加入 $(1, 0)$ 并排序得 $(1,0), (2,5), (5,3), (7,4), (10,3)$。

**第二步**：正向传播（左腿 $\to$ 右腿）：

| 限制点 | 公式 | 正向后 |
|--------|------|-------|
| $(2,5)$ | $\min(5,\ 0+1)$ | $(2,1)$ |
| $(5,3)$ | $\min(3,\ 1+3)$ | $(5,3)$ |
| $(7,4)$ | $\min(4,\ 3+2)$ | $(7,4)$ |
| $(10,3)$ | $\min(3,\ 4+3)$ | $(10,3)$ |

**第三步**：反向传播（右腿 $\to$ 左腿）：$(7,4) \to \min(4, 3+3)=4$，$(5,3) \to \min(3, 4+2)=3$，$(2,1) \to \min(1, 3+3)=1$，$(1,0) \to \min(0, 1+1)=0$——本例正向已经充分，反向没有再收紧任何值。

**第四步**：逐段取峰 + 尾段：

| 段 | 计算 | 峰值 |
|----|------|------|
| $(1,0) \sim (2,1)$ | $\lfloor (0+1+1)/2 \rfloor$ | $1$ |
| $(2,1) \sim (5,3)$ | $\lfloor (1+3+3)/2 \rfloor$ | $3$ |
| $(5,3) \sim (7,4)$ | $\lfloor (3+4+2)/2 \rfloor$ | $4$ |
| $(7,4) \sim (10,3)$ | $\lfloor (4+3+3)/2 \rfloor$ | $\mathbf{5}$ ★ |
| 尾段 $(10,3) \to 10$ | $3 + (10-10)$ | $3$ |

答案为 $\max\{1,3,4,5,3\} = 5$，与期望一致。取到峰值的交叉点在 $x = 8$，最优天际线正是 $[0,1,2,3,3,4,4,5,4,3]$。

## 4. 算法细节

### 4.1 为什么必须加入 $(1, 0)$

它一举三得：① 把「首建筑高度为 0」这一硬约束统一进限制体系；② 作为排序后的第一个点，是正向传播的起点，保证传播后每个 $h_i \le \mathrm{id}_i - 1$；③ 无任何额外限制时（$m = 0$），算法退化为纯尾段计算，答案 $n - 1$ 自然成立。

### 4.2 正向传播的确切含义

对排序后的限制执行 $h_i \leftarrow \min\big(h_i,\ h_{i-1} + (\mathrm{id}_i - \mathrm{id}_{i-1})\big)$。对 $i$ 归纳可得传播后：

$$h_i = \min_{j \le i} \big(c_j + \mathrm{id}_i - \mathrm{id}_j\big)$$

即**所有左侧限制的右腿**在 $\mathrm{id}_i$ 处的最小值——这就是 $\min$ 套 $\min$ 可以「接力」的原因：$c_j + \mathrm{id}_i - \mathrm{id}_j = (c_j + \mathrm{id}_{i-1} - \mathrm{id}_j) + (\mathrm{id}_i - \mathrm{id}_{i-1})$，左腿最紧的前一项加上固定步长就是它在下一点的值。

### 4.3 反向传播补上另一半

对称地，反向传播后 $h_i$ 恰为 $\min$ 中再并入**所有右侧限制的左腿**，最终 $h_i = H(\mathrm{id}_i)$（完整证明见 §5 引理 3）。注意**两趟缺一不可**：正向只看到左侧约束，右侧限制对左侧点的影响（左腿）完全缺失，见 §8 第 2 条的反例。

### 4.4 帐篷峰公式

设相邻限制点 $P = (p, h_p)$、$Q = (q, h_q)$（$p < q$），且已满足 $h_p = H(p)$、$h_q = H(q)$。段内 $H(x) = \min\big(h_p + (x-p),\ h_q + (q-x)\big)$：从 $P$ 出发以斜率 $1$ 上升的左腿、从 $Q$ 出发以斜率 $1$ 下降的右腿，交叉点在

$$x^* = \frac{h_q - h_p + p + q}{2}$$

峰高 $= \frac{h_p + h_q + (q - p)}{2}$。由于建筑位置取整数，交叉点可能落在半整数位置，故**下取整**：$\text{peak} = \left\lfloor \frac{h_p + h_q + q - p}{2} \right\rfloor$。两趟传播保证 $|h_q - h_p| \le q - p$，交叉点不会落在段外，且峰 $\ge \max(h_p, h_q)$——所以逐段峰已经覆盖了限制点自身的高度，代码里不必再单独比较 $h_i$。

### 4.5 尾段

最后一个限制点右侧没有别的 V 形中心，$H$ 以斜率 $1$ 一路爬升，直到 $x = n$：贡献 $h_{\text{last}} + (n - \mathrm{id}_{\text{last}})$。

## 5. 正确性证明

**引理 1（V 形上界）**：设 $h$ 为任意合法高度序列，$r = (\mathrm{id}, c)$ 为任一限制点（含 $(1,0)$）。则对一切位置 $x$：$h(x) \le c + |x - \mathrm{id}|$。

**证明**：相邻高度差 $\le 1$，故对任意 $x, y$ 有 $|h(x) - h(y)| \le |x - y|$（对距离归纳）。取 $y = \mathrm{id}$：$h(x) \le h(\mathrm{id}) + |x - \mathrm{id}| \le c + |x - \mathrm{id}|$。∎

**引理 2（下包络是逐点最优的合法天际线）**：令 $H(x) = \min_{r} \big(c_r + |x - \mathrm{id}_r|\big)$。则 (a) $H$ 是合法方案；(b) 任何合法方案 $h$ 逐点满足 $h \le H$。

**证明**：(b) 是引理 1 的直接推论（$H$ 是所有限制对应上界的逐点最小值）。(a) 中各项非负故 $H \ge 0$；每个 $f_r(x) = c_r + |x - \mathrm{id}_r|$ 是 1-Lipschitz 的，设 $H(x) = f_p(x)$、$H(y) = f_q(y)$，则 $H(x) - H(y) \le f_q(x) - f_q(y) \le |x - y|$，同理 $H(y) - H(x) \le |x - y|$，故 $|H(x+1) - H(x)| \le 1$；$H(1) \le 0 + 0 = 0$ 结合 $H \ge 0$ 得 $H(1) = 0$；且 $H(\mathrm{id}_r) \le c_r$ 满足所有额外限制；各项均为整数故 $H$ 取整数值。∎

**定理 1**：最高建筑能达到的最高高度 $= \max_{1 \le x \le n} H(x)$。

**证明**：$H$ 合法（引理 2a），故答案 $\ge \max_x H(x)$；任何合法方案逐点 $\le H$（引理 2b），故任何合法方案的最高建筑 $\le \max_x H(x)$，答案 $\le \max_x H(x)$。两边夹即得。∎

**引理 3（两趟传播求出限制点处的包络值）**：限制点按 $\mathrm{id}$ 排序（含 $(1,0)$），记原始上限为 $c_i$。正向传播后 $a_i = \min_{j \le i} \big(c_j + \mathrm{id}_i - \mathrm{id}_j\big)$；再反向传播后 $b_i = H(\mathrm{id}_i)$。

**证明**：正向对 $i$ 归纳：$a_i = \min\big(c_i,\ a_{i-1} + (\mathrm{id}_i - \mathrm{id}_{i-1})\big)$，展开 $a_{i-1}$ 即得声明的形式。反向同理归纳得 $b_i = \min_{j \ge i} \big(a_j + \mathrm{id}_j - \mathrm{id}_i\big)$。

一方面（$\ge$）：固定 $j \ge i$，展开 $a_j = \min_{k \le j} (c_k + \mathrm{id}_j - \mathrm{id}_k)$。对每个 $k \le j$：若 $k \le i$，则 $c_k + \mathrm{id}_j - \mathrm{id}_k + \mathrm{id}_j - \mathrm{id}_i \ge c_k + \mathrm{id}_i - \mathrm{id}_k \ge H(\mathrm{id}_i)$；若 $k > i$（则 $i < k \le j$），则 $c_k + (\mathrm{id}_j - \mathrm{id}_k) + (\mathrm{id}_j - \mathrm{id}_i) \ge c_k + \mathrm{id}_k - \mathrm{id}_i \ge H(\mathrm{id}_i)$。对所有 $j, k$ 取最小得 $b_i \ge H(\mathrm{id}_i)$。

另一方面（$\le$）：取 $j = i$ 得 $b_i \le a_i = \min_{k \le i} \big(c_k + \mathrm{id}_i - \mathrm{id}_k\big)$，覆盖了左半候选；对每个 $k > i$，取 $j = k$ 得 $b_i \le a_k + \mathrm{id}_k - \mathrm{id}_i \le c_k + \mathrm{id}_k - \mathrm{id}_i$，覆盖了右半候选。故 $b_i \le H(\mathrm{id}_i)$。∎

**引理 4（段峰公式与尾段公式）**：设相邻限制点 $P = (p, h_p)$、$Q = (q, h_q)$（$p < q$）满足 $h_p = H(p)$、$h_q = H(q)$。则：

1. 对 $x \in [p, q]$：$H(x) = \min\big(h_p + (x - p),\ h_q + (q - x)\big)$，整数最大值为 $\left\lfloor \frac{h_p + h_q + q - p}{2} \right\rfloor$；
2. 对 $x \ge \mathrm{id}_{\text{last}}$：$H(x) = h_{\text{last}} + (x - \mathrm{id}_{\text{last}})$。

**证明**：

1. **（$\ge$ 方向）** 所有限制点要么在 $p$ 左侧（含 $p$）要么在 $q$ 右侧（含 $q$）（排序后相邻，中间无别的限制点）。对 $\mathrm{id}_k \le p$：$x \ge p \ge \mathrm{id}_k$，故 $f_k(x) = f_k(p) + (x - p) \ge H(p) + (x - p)$；对 $\mathrm{id}_k \ge q$：$f_k(x) = f_k(q) + (q - x) \ge H(q) + (q - x)$。于是 $H(x)$（全体 $f_k$ 的最小值）$\ge$ 两条腿的较小者。**（$\le$ 方向）** 设 $H(p) = f_{k^*}(p)$，则 $H(x) \le f_{k^*}(x) \le f_{k^*}(p) + |x - p| = H(p) + (x - p)$；同理 $H(x) \le H(q) + (q - x)$。两方向合并即得段内表达式。峰值：两条斜率 $\pm 1$ 的直线在 $t^* = \frac{h_q - h_p + q - p}{2}$ 处相交（$t = x - p$），由两趟传播后 $|h_q - h_p| \le q - p$ 知 $t^* \in [0, q - p]$，峰值 $\frac{h_p + h_q + q - p}{2}$；$x$ 为整数故下取整。
2. 设 $H(\mathrm{id}_{\text{last}}) = f_{k^*}(\mathrm{id}_{\text{last}})$。对 $x \ge \mathrm{id}_{\text{last}}$：$H(x) \le f_{k^*}(x) \le f_{k^*}(\mathrm{id}_{\text{last}}) + (x - \mathrm{id}_{\text{last}}) = h_{\text{last}} + (x - \mathrm{id}_{\text{last}})$；又每个限制点都在 $\mathrm{id}_{\text{last}}$ 左侧（含其自身），$f_k(x) = f_k(\mathrm{id}_{\text{last}}) + (x - \mathrm{id}_{\text{last}}) \ge h_{\text{last}} + (x - \mathrm{id}_{\text{last}})$，取最小仍 $\ge$。∎

**定理 2（算法正确性）**：算法返回的值等于 $\max_{1 \le x \le n} H(x)$，结合定理 1 即为答案。

**证明**：$[1, n]$ 被限制点划分为：首限制点 $(1, 0)$ 自身（$H(1) = 0$）、相邻限制点之间的段、以及尾段。段内最大值由引理 4.1 的峰公式给出且峰 $\ge \max(h_p, h_q) \ge H(\mathrm{id}_p), H(\mathrm{id}_q)$，故「段峰」同时覆盖了限制点处的取值；尾段最大值由引理 4.2 给出。算法对这些候选取最大，恰好等于 $\max_x H(x)$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(m \log m)$，瓶颈在排序（$m \le 10^5$）；正向传播、反向传播、逐段取峰均为单次线性扫描 $O(m)$。与 $n$ 无关——这正是 $n \le 10^9$ 也能瞬间求解的原因。
- **空间复杂度**：$O(m)$，存储加入 $(1,0)$ 后的限制数组（含排序）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maxBuilding(int n, vector<vector<int>>& restrictions) {
        vector<vector<int>> r = restrictions;
        r.push_back({1, 0});                 // 统一加入首建筑约束 (1, 0)
        sort(r.begin(), r.end());
        int m = r.size();
        for (int i = 1; i < m; i++)          // 正向：左侧限制的右腿压过来
            r[i][1] = min(r[i][1], r[i - 1][1] + r[i][0] - r[i - 1][0]);
        for (int i = m - 2; i >= 0; i--)     // 反向：右侧限制的左腿压过来
            r[i][1] = min(r[i][1], r[i + 1][1] + r[i + 1][0] - r[i][0]);
        int ans = r[m - 1][1] + n - r[m - 1][0];   // 尾段：斜率 1 爬到 n
        for (int i = 0; i + 1 < m; i++) {          // 相邻限制点之间的帐篷峰
            int peak = (r[i][1] + r[i + 1][1] + r[i + 1][0] - r[i][0]) / 2;
            ans = max(ans, peak);
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maxBuilding(self, n: int, restrictions: List[List[int]]) -> int:
        r = [[1, 0]] + [list(x) for x in restrictions]   # 拷贝，避免改动原数组
        r.sort()
        for i in range(1, len(r)):                        # 正向传播
            r[i][1] = min(r[i][1], r[i - 1][1] + r[i][0] - r[i - 1][0])
        for i in range(len(r) - 2, -1, -1):               # 反向传播
            r[i][1] = min(r[i][1], r[i + 1][1] + r[i + 1][0] - r[i][0])
        ans = r[-1][1] + n - r[-1][0]                     # 尾段
        for a, b in zip(r, r[1:]):                         # 帐篷峰
            ans = max(ans, (a[1] + b[1] + b[0] - a[0]) // 2)
        return ans
```

## 8. 边界情况与易错点

1. **必须加入 $(1, 0)$**：它既是硬约束又是传播起点。漏掉后，如 `n = 10, restrictions = [[3,5]]` 会错误地由尾段算出 $5 + 7 = 12$，而真实答案只有 $9$（首建筑为 $0$ 的右腿把一切压在 $x - 1$ 之下）。

2. **两趟传播缺一不可**：只做正向会 WA。反例 `n = 10, restrictions = [[4,3],[6,0]]`：正向后 $(4,3)$ 未被任何左侧约束收紧，段 $(1,0) \sim (4,3)$ 的峰被误算为 $\lfloor (0+3+3)/2 \rfloor = 3$；而 $(6,0)$ 的**左腿**其实把位置 4 压到 $2$，反向传播得 $(4,2)$，正确的峰为 $\lfloor (0+2+3)/2 \rfloor = 2$。

3. **峰值公式要下取整**：两条腿的交叉点可能落在半整数位置。如 $(1,0)$ 与 $(3,1)$：峰 $= \lfloor (0+1+2)/2 \rfloor = 1$，位置 2 的真实上界 $\min(1, 2) = 1$；上取整会得到不可达的 $2$。

4. **别忘了尾段**：最后一个限制点之后没有右腿封顶，贡献 $h_{\text{last}} + (n - \mathrm{id}_{\text{last}})$。样例 2（无限制）就是纯尾段，答案 $n - 1$。

5. **溢出分析**：直接用**未传播的原始值**计算峰公式可能三个 $10^9$ 相加而爆 `int`。两趟传播后每个有效值 $h_i \le \mathrm{id}_i - 1 < n$，峰公式中间量 $\le 2n - 2 < 2^{31} - 1$，`int` 恰好安全；若不想推导这个上界，全程 `long long` 最稳妥。C++ 里注意 `r.push_back({1, 0})` 之后才排序，且 $\mathrm{id}_i \ge 2$ 保证 $(1,0)$ 必为排序后首元素。

6. **排序键是 `id`**：限制给出顺序乱（样例 3 就是乱的），必须按位置排序后传播；`id` 互异保证无重复位置。

7. **无需单独比较限制点自身高度**：由 $|h_{i+1} - h_i| \le \mathrm{id}_{i+1} - \mathrm{id}_i$，段峰 $\ge$ 两端点高度，逐段取峰已自动覆盖所有限制点处的 $H$ 值。

8. **Python 引用陷阱**：`restrictions + [[1, 0]]` 得到的外层列表是新对象，但内层列表仍是引用，原地修改会污染入参；应先 `[list(x) for x in ...]` 拷贝（C++ 侧 `vector<vector<int>> r = restrictions` 天然值拷贝）。

- 本场 Q2（[1838. 最高频元素的频数](https://leetcode.cn/problems/frequency-of-the-most-frequent-element/)）：同为「每步 $+1$、总量受限」的可达性问题，一个作用于元素值域、一个作用于相邻差——周赛里两道题共享「Lipschitz/步长」主题。

**延伸思考**：

- **输出整条天际线**：两趟传播后，$h^*(x) = \min_i \big(h_i + |x - \mathrm{id}_i|\big)$ 直接给出每个位置的最优高度（下包络本身即方案），$O(n)$ 或按段输出均可。
- **相邻差推广为 $\le k$**：V 形腿斜率变为 $k$，帐篷峰公式相应变为 $\left\lfloor \frac{h_p + h_q + k(q - p)}{2} \right\rfloor$，两趟传播的步长乘 $k$，算法结构不变。
- **限制改为「高度恰好等于 $c$」**：需要同时夹住上下界（可达区间非空判定 + 双向传播上下两套包络），接近差分约束系统的雏形。
