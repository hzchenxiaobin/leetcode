# LeetCode 合并两棵树后的最小直径 题解

## 1. 题目概述

- **标题 / 题号**：合并两棵树后的最小直径（#3203，hard）
- **链接**：https://leetcode.cn/problems/find-minimum-diameter-after-merging-two-trees/
- **来源**：LeetCode 第 404 场周赛 Q4
- **难度**：困难
- **标签**：树、深度优先搜索、广度优先搜索、图

**题意**：给定两棵无向树（$n$ 与 $m$ 个节点，边数组 $\textit{edges1}$、$\textit{edges2}$）。必须在两棵树中各选一个节点，用一条新边把它们连起来，得到一棵 $n+m$ 个节点的树。求新树**直径**（任意两点间最长路径的长度）的最小值。

**约束**：

- $1 \le n, m \le 10^5$
- $\textit{edges1}$、$\textit{edges2}$ 分别是合法的树（长度 $n-1$、$m-1$）
- 注意 $n=1$（或 $m=1$）时边数组为空——**单点树是合法输入**

> 💡 读题关键：① 新树 = 两棵子树 + 恰好一条"桥边"；② 直径完全由"最长路径"决定，而树上最长路径的结构是可彻底刻画的（直径、半径、中心三件套）；③ 只问最小值、不问方案——大概率是一道"求两个直径 + 一个公式"的题。

## 2. 示例

**示例 1**

```text
输入：edges1 = [[0,1],[0,2],[0,3]], edges2 = [[0,1]]
输出：3
解释：把第一棵树的节点 0（星形中心）与第二棵树的任意节点相连，得到直径为 3 的树。
```

**示例 2**

```text
输入：edges1 = edges2 = [[0,1],[0,2],[0,3],[2,4],[2,5],[3,6],[2,7]]
输出：5
解释：两棵树同构，直径都是 4；连接两个中心（都是节点 0），跨树最长路 2 + 1 + 2 = 5。
```

**补充示例（两个单点）**

```text
输入：edges1 = [], edges2 = []
输出：1
解释：两棵树各只有一个点，连起来就是一条边，直径为 1。
```

**补充示例（单点 × 长链）**

```text
输入：edges1 = [], edges2 = [[0,1],[1,2],[2,3]]
输出：3
解释：链自身直径 d₂ = 3 摆在那里；连在链的中心上，max(0, 3, 0 + 2 + 1) = 3，直径不涨。
```

## 3. 解题思路

### 3.1 暴力思路

枚举连接方案 $(u \in T_1,\ v \in T_2)$，共 $n \cdot m$ 种，对每种方案求新树直径再取最小：

- **朴素**：每种方案用双 BFS 重算直径，单次 $O(n+m)$，总计 $O\big(nm(n+m)\big)$——$n=m=10^5$ 时光是枚举就是 $10^{10}$ 种方案，完全不可行；
- **改进**：新树直径 $=\max\big(d_1,\,d_2,\,\mathrm{ecc}_1(u)+1+\mathrm{ecc}_2(v)\big)$（§3.2 观察 1），其中 $d_1, d_2$ 只需算一次；对每棵树从每个点 BFS 一遍得到所有点的离心率 $\mathrm{ecc}$，再 $O(nm)$ 枚举——$O(n^2+m^2+nm)$，$n=10^5$ 时仍是 $10^{10}$，超时。

瓶颈在于**枚举连接点**。但观察 $\max$ 里的三项：$d_1$、$d_2$ 与 $(u,v)$ 无关，唯一能优化的是交叉项 $\mathrm{ecc}_1(u)+\mathrm{ecc}_2(v)$——而它对 $u$、$v$ 是**可分离**的。

### 3.2 核心观察：三类路径 + 各取中心

**观察 1（新直径的三类路径）**：加边 $(u,v)$ 后，新树中任何一条（简单）路径要么完全待在 $T_1$ / $T_2$ 内部，要么恰好跨过新边一次，后者形如 $x \to \cdots \to u \to v \to \cdots \to y$。于是

$$D(u,v) = \max\big(d_1,\; d_2,\; \mathrm{ecc}_1(u) + 1 + \mathrm{ecc}_2(v)\big)$$

其中 $\mathrm{ecc}(x) = \max_y \mathrm{dist}(x,y)$ 是 $x$ 的**离心率**（到树内最远点的距离）。

![核心观察：合并后直径的三类候选路径，交叉项是唯一可优化的](images/w404_merge_diameter_decompose.svg)

**观察 2（交叉项可分离）**：$\max(A, t)$ 关于 $t$ 单调不减，且 $u$、$v$ 可以独立选取，所以

$$\min_{u,v} \max\big(A,\ \mathrm{ecc}_1(u)+1+\mathrm{ecc}_2(v)\big) = \max\big(A,\ 1+\min_u \mathrm{ecc}_1(u)+\min_v \mathrm{ecc}_2(v)\big)$$

即两棵树**各自独立地**把连接点挪到"最居中"的位置——离心率最小的点，即树的**中心**。

**观察 3（树的半径 $= \lceil d/2 \rceil$）**：对直径为 $d$ 的树，任何点的离心率 $\ge \lceil d/2 \rceil$（直径两端点从两侧"夹住"了它）；而直径路径的中点恰好取到 $\lceil d/2 \rceil$。这个最小值就是树的**半径** $r = \lceil d/2 \rceil$。

![中心与半径：任意点离心率有下界，直径路径中点恰好取到](images/w404_center_radius.svg)

三步合一，答案是一个只依赖 $d_1, d_2$ 的公式：

$$\textit{ans} = \max\big(d_1,\; d_2,\; \lceil d_1/2 \rceil + 1 + \lceil d_2/2 \rceil\big)$$

> 💡 妙处在于：**甚至不需要找出中心在哪里**——只需知道"取中心能把离心率压到 $\lceil d/2 \rceil$"，代入公式即可。整道题坍缩为"求两个直径"。

### 3.3 算法流程：双 BFS 求直径 + $O(1)$ 公式

![算法流程：两棵树各做两次 BFS 求直径，代入公式](images/w404_double_bfs_flow.svg)

```text
1. 对 T1：从任意点 s 做 BFS¹，取最远点 u（u 必是某条直径的端点）
2. 从 u 做 BFS²，dist 的最大值即 T1 的直径 d1
3. 对 T2 同理得 d2
4. ans = max(d1, d2, ⌈d1/2⌉ + 1 + ⌈d2/2⌉)，其中 ⌈d/2⌉ = (d+1) 整除 2
```

### 3.4 示例演算

![示例 2 演算：直径 4，中心 0，连中心后跨树路径 2+1+2=5](images/w404_example2_walkthrough.svg)

以示例 2 走一遍（两棵树同构）：

1. **BFS¹(0)**：距离数组为 $\{0{:}0,\ 1{:}1,\ 2{:}1,\ 3{:}1,\ 4{:}2,\ 5{:}2,\ 7{:}2,\ 6{:}2\}$，最远点取 $u=4$（取 5/6/7 之一皆可，距离并列）；
2. **BFS²(4)**：最大距离为 4（到节点 6），故 $d = 4$，直径路径 $4 \to 2 \to 0 \to 3 \to 6$；
3. 中心是直径路径中点——节点 0，$\mathrm{ecc}(0) = 2 = \lceil 4/2 \rceil$；
4. 连接两个中心 $0$—$0'$，三类路径：留在 $T_1$ 内 $d_1 = 4$；留在 $T_2$ 内 $d_2 = 4$；跨新边 $\mathrm{ecc}(0) + 1 + \mathrm{ecc}(0') = 2 + 1 + 2 = 5$，由 $6 \to 3 \to 0 \to 0' \to 3' \to 6'$ 实现。

$\textit{ans} = \max(4, 4, 5) = 5$ ✓。

示例 1 同理：星形 $d_1 = 2$（半径 1），单边 $d_2 = 1$（半径 1），$\textit{ans} = \max(2, 1, 1+1+1) = 3$ ✓。

## 4. 算法细节

1. **双 BFS 求直径**：邻接表 + 队列。第一次从任意点出发取最远点 $u$；第二次从 $u$ 出发，`dist` 的最大值即直径。正确性完全依赖引理 2（任取一点的最远点必是直径端点）。
2. **为什么用 BFS 不用递归 DFS**：$n$ 可达 $10^5$，一条链就让递归深度达到 $10^5$——Python 默认递归上限 1000 直接 `RecursionError`，C++ 也有栈溢出风险。BFS 天然迭代；偏爱 DFS 就写显式栈版本。
3. **半径不用单独求**：$r = \lceil d/2 \rceil = (d+1) \,/\, 2$，由引理 4 直接从直径得出，无需定位中心节点——这是本题最省事的一步。
4. **向上取整**：$d$ 为奇数时直径中点落在边上，中点两侧相邻节点的离心率都是 $(d+1)/2$（如单边树 $d=1$，两端点 $\mathrm{ecc}=1$），公式对奇偶统一成立。
5. **另解：换根 DP**：用两次 DFS 换根可求出每个点的离心率，答案 $= \max(d_1, d_2, \min_u \mathrm{ecc}_1(u) + 1 + \min_v \mathrm{ecc}_2(v))$；由引理 4 它与公式殊途同归，但代码量与思维量都更大。本题的最短路径就是"直径 → 半径 → 公式"。

## 5. 正确性证明

记 $\mathrm{dist}_i$、$\mathrm{ecc}_i$ 为树 $T_i$ 内的距离与离心率，$d_i$ 为直径。先约定一个事实：对树中一条路径 $P$ 和任意点 $x$，$x$ 到 $P$ 存在唯一的**投影** $g(x) \in P$——$x$ 到 $P$ 上任何点的路径都先经过 $g(x)$（若 $x$ 到 $P$ 有两条不同途径，与树上两点路径唯一矛盾）。

**引理 1（三段分解）**：对任意 $u \in T_1$、$v \in T_2$，添加边 $(u,v)$ 后新树的直径 $D(u,v) = \max\big(d_1,\ d_2,\ \mathrm{ecc}_1(u) + 1 + \mathrm{ecc}_2(v)\big)$。

**证明**：删去新边后新树分裂为 $T_1$、$T_2$ 两个连通块。任取新树中一条简单路径 $P'$：若 $P'$ 不含新边，则它整体落在一个块内，长度 $\le d_1$ 或 $\le d_2$；若 $P'$ 含新边，由简单性它恰经过新边一次，必一端在 $T_1$、另一端在 $T_2$，且可分解为 $x \to \cdots \to u$、$(u,v)$、$v \to \cdots \to y$ 三段，长度 $= \mathrm{dist}_1(x,u) + 1 + \mathrm{dist}_2(v,y) \le \mathrm{ecc}_1(u) + 1 + \mathrm{ecc}_2(v)$。故 $D(u,v) \le \max$ 三项。反向：$T_1$ 内的直径路径在新树中依然存在，故 $D \ge d_1$（同理 $D \ge d_2$）；取 $x^*$ 为 $u$ 在 $T_1$ 内的最远点、$y^*$ 为 $v$ 在 $T_2$ 内的最远点，则 $x^* \to \cdots \to u \to v \to \cdots \to y^*$ 是新树中的路径，故 $D \ge \mathrm{ecc}_1(u) + 1 + \mathrm{ecc}_2(v)$。两向合一。∎

**引理 2（双 BFS）**：树 $T$ 中任取 $s$，设 $u$ 是距 $s$ 最远的点**之一**，则 $u$ 必是某条直径的端点；从而"任取一点 BFS 取最远点 $u$，再从 $u$ BFS 取最大距离"得到的就是直径。

**证明**：取任意一条直径 $(a,b)$，$d = \mathrm{dist}(a,b)$，$P$ 为其路径。设 $t = g(u)$（$u$ 向 $P$ 的投影），则 $\mathrm{dist}(u,a) = \mathrm{dist}(u,t) + \mathrm{dist}(t,a)$，$\mathrm{dist}(u,b) = \mathrm{dist}(u,t) + \mathrm{dist}(t,b)$。不妨 $\mathrm{dist}(t,a) \le \mathrm{dist}(t,b)$。

若 $\mathrm{dist}(u,t) \ge \mathrm{dist}(t,a)$，则 $\mathrm{dist}(u,b) \ge \mathrm{dist}(t,a) + \mathrm{dist}(t,b) = d$，而任意两点距离 $\le d$，故 $(u,b)$ 是一条直径，结论成立。以下反设 $\mathrm{dist}(u,t) < \mathrm{dist}(t,a) \le \mathrm{dist}(t,b)$，记 $e = g(s)$，分两种情况导出矛盾：

- **情况一（$s$ 与 $u$ 在 $P$ 的同一侧分支，$e = t$）**：由 $u$ 距 $s$ 最远，$\mathrm{dist}(s,u) \ge \mathrm{dist}(s,b) = \mathrm{dist}(s,e) + \mathrm{dist}(e,b)$；又 $s \to e \to u$ 是一条途径，三角不等式给 $\mathrm{dist}(s,u) \le \mathrm{dist}(s,e) + \mathrm{dist}(e,u)$。合并得 $\mathrm{dist}(e,u) \ge \mathrm{dist}(e,b) \ge \mathrm{dist}(e,a) > \mathrm{dist}(e,u)$，矛盾。
- **情况二（$s$ 与 $u$ 不在同一侧分支；此时 $s \to u$ 的路径先后经过 $e$ 与 $t$，$e$ 到 $t$ 的一段沿 $P$ 行进）**：$\mathrm{dist}(s,u) = \mathrm{dist}(s,e) + \mathrm{dist}(e,t) + \mathrm{dist}(t,u)$。
  - 若 $e$ 在 $a$ 侧（$\mathrm{dist}(a,e) \le \mathrm{dist}(a,t)$）：$\mathrm{dist}(s,b) = \mathrm{dist}(s,e) + \mathrm{dist}(e,t) + \mathrm{dist}(t,b)$，与上式及 $\mathrm{dist}(s,u) \ge \mathrm{dist}(s,b)$ 联立得 $\mathrm{dist}(t,u) \ge \mathrm{dist}(t,b) \ge \mathrm{dist}(t,a)$，矛盾；
  - 若 $e$ 在 $b$ 侧（$\mathrm{dist}(a,e) \ge \mathrm{dist}(a,t)$）：同理用 $\mathrm{dist}(s,a) = \mathrm{dist}(s,e) + \mathrm{dist}(e,t) + \mathrm{dist}(t,a)$ 与 $\mathrm{dist}(s,u) \ge \mathrm{dist}(s,a)$ 得 $\mathrm{dist}(t,u) \ge \mathrm{dist}(t,a)$，矛盾。

反设不成立，故 $u$ 是某条直径的端点。第二部分：设该直径为 $(u,c)$，$\mathrm{dist}(u,c) = d$；设 $v$ 为距 $u$ 最远的点，则 $\mathrm{dist}(u,v) \ge \mathrm{dist}(u,c) = d$，又 $\le d$，故 $\mathrm{dist}(u,v) = d$，即第二次 BFS 的最大距离恰为直径。∎

**引理 3（离心率下界）**：树 $T$ 中任意点 $x$ 满足 $\mathrm{ecc}(x) \ge \lceil d/2 \rceil$。

**证明**：设 $(a,b)$ 为一条直径。把路径 $x \to a$ 与 $x \to b$ 拼接，得到一条 $a$ 到 $b$ 的途径，长度 $\mathrm{dist}(x,a) + \mathrm{dist}(x,b) \ge \mathrm{dist}(a,b) = d$（途径不短于最短路）。故 $\max(\mathrm{dist}(x,a), \mathrm{dist}(x,b)) \ge d/2$；距离为整数，故 $\max \ge \lceil d/2 \rceil$。而 $\mathrm{ecc}(x) \ge \max(\mathrm{dist}(x,a), \mathrm{dist}(x,b))$。∎

**引理 4（中心与半径）**：存在点 $c$ 使 $\mathrm{ecc}(c) = \lceil d/2 \rceil$；从而 $\min_x \mathrm{ecc}(x) = \lceil d/2 \rceil$（树的半径），取到最小值的点称为树的中心。

**证明**：取直径路径 $a = p_0, p_1, \dots, p_d = b$，令 $c = p_{\lfloor d/2 \rfloor}$，则 $\mathrm{dist}(a,c) = \lfloor d/2 \rfloor$，$\mathrm{dist}(c,b) = \lceil d/2 \rceil$。对任意点 $x$，设 $t = g(x)$ 为其向该路径的投影（$x$ 到路径上任何点 $y$ 均有 $\mathrm{dist}(x,y) = \mathrm{dist}(x,t) + \mathrm{dist}(t,y)$）：

- 若 $t$ 在 $a \cdots c$ 段：$\mathrm{dist}(x,b) = \mathrm{dist}(x,t) + \mathrm{dist}(t,b) \le d$，而 $\mathrm{dist}(x,b) = \mathrm{dist}(x,c) + \mathrm{dist}(c,b)$，故 $\mathrm{dist}(x,c) \le d - \lceil d/2 \rceil = \lfloor d/2 \rfloor \le \lceil d/2 \rceil$；
- 若 $t$ 在 $c \cdots b$ 段：$\mathrm{dist}(x,a) = \mathrm{dist}(x,t) + \mathrm{dist}(t,a) \le d$，而 $\mathrm{dist}(x,a) = \mathrm{dist}(x,c) + \mathrm{dist}(a,c)$，故 $\mathrm{dist}(x,c) \le d - \lfloor d/2 \rfloor = \lceil d/2 \rceil$。

（$x$ 本身在路径上时 $t = x$，仍被覆盖。）故对一切 $x$ 有 $\mathrm{dist}(x,c) \le \lceil d/2 \rceil$，即 $\mathrm{ecc}(c) \le \lceil d/2 \rceil$；结合引理 3 得 $\mathrm{ecc}(c) = \lceil d/2 \rceil$ 且它是最小值。∎

**定理**：最小合并直径 $= \max\big(d_1,\ d_2,\ \lceil d_1/2 \rceil + 1 + \lceil d_2/2 \rceil\big)$，双 BFS + 公式在 $O(n+m)$ 时间内正确计算它。

**证明**：由引理 1，$\min_{u,v} D(u,v) = \min_{u,v} \max\big(d_1, d_2, \mathrm{ecc}_1(u) + 1 + \mathrm{ecc}_2(v)\big)$。记 $A = \max(d_1, d_2)$、$t(u,v) = \mathrm{ecc}_1(u) + 1 + \mathrm{ecc}_2(v)$。因 $\max(A, \cdot)$ 单调不减，对任意 $(u,v)$ 有 $\max(A, t(u,v)) \ge \max(A, t^*)$，其中 $t^* = \min t$；而取到 $t^*$ 的 $(u^*, v^*)$ 使等号成立，故 $\min \max(A, t) = \max(A, t^*)$。又 $u, v$ 独立选取，$t^* = 1 + \min_u \mathrm{ecc}_1(u) + \min_v \mathrm{ecc}_2(v) = 1 + \lceil d_1/2 \rceil + \lceil d_2/2 \rceil$（引理 4），代入即得公式。$d_1, d_2$ 由引理 2 的双 BFS 正确求出，复杂度见 §6。∎

> 💡 一句话复盘：**新直径的三个候选中，唯一可优化的"跨树路径"是可分离的——各自连到中心，交叉项变成 半径 + 新边 + 半径，而树的半径恰为 $\lceil d/2 \rceil$。** 于是整道题坍缩成"求两个直径 + 一个公式"。

## 6. 复杂度分析

- **时间复杂度**：$O(n + m)$。两棵树各做两次 BFS，每次遍历全部点边；最后公式 $O(1)$。
- **空间复杂度**：$O(n + m)$。邻接表与距离数组。
- **对照**：朴素枚举 $O(nm(n+m)) \approx 10^{15}$；全点离心率 $O(n^2 + m^2) \approx 10^{10}$；本题 $O(n+m)$——从"枚举连接方案"到"只看两个直径"的降维打击。

## 7. 参考代码

### C++

```cpp
class Solution {
    vector<int> bfs(vector<vector<int>>& g, int s) {
        vector<int> dist(g.size(), -1);
        queue<int> q;
        dist[s] = 0;
        q.push(s);
        while (!q.empty()) {
            int u = q.front(); q.pop();
            for (int v : g[u])
                if (dist[v] == -1) {
                    dist[v] = dist[u] + 1;
                    q.push(v);
                }
        }
        return dist;
    }

    int diameter(vector<vector<int>>& edges) {
        int n = edges.size() + 1;
        vector<vector<int>> g(n);
        for (auto& e : edges) {
            g[e[0]].push_back(e[1]);
            g[e[1]].push_back(e[0]);
        }
        vector<int> d0 = bfs(g, 0);                 // 任意点出发
        int u = max_element(d0.begin(), d0.end()) - d0.begin();
        vector<int> d1 = bfs(g, u);                 // 从最远点 u 再来一次
        return *max_element(d1.begin(), d1.end());  // 最大距离即直径
    }

public:
    int minimumDiameterAfterMerge(vector<vector<int>>& edges1, vector<vector<int>>& edges2) {
        int d1 = diameter(edges1), d2 = diameter(edges2);
        return max({d1, d2, (d1 + 1) / 2 + (d2 + 1) / 2 + 1});
    }
};
```

### Python

```python
class Solution:
    def minimumDiameterAfterMerge(self, edges1: List[List[int]], edges2: List[List[int]]) -> int:
        def diameter(edges):
            n = len(edges) + 1
            g = [[] for _ in range(n)]
            for a, b in edges:
                g[a].append(b)
                g[b].append(a)

            def bfs(s):
                dist = [-1] * n
                dist[s] = 0
                q = deque([s])
                while q:
                    u = q.popleft()
                    for v in g[u]:
                        if dist[v] == -1:
                            dist[v] = dist[u] + 1
                            q.append(v)
                return dist

            d0 = bfs(0)                             # 任意点出发
            u = max(range(n), key=d0.__getitem__)   # 最远点 u（必是直径端点）
            return max(bfs(u))                      # 最大距离即直径

        d1 = diameter(edges1)
        d2 = diameter(edges2)
        return max(d1, d2, (d1 + 1) // 2 + (d2 + 1) // 2 + 1)
```

## 8. 边界情况与易错点

1. **$n=1$ / $m=1$（边数组为空）**：单点树直径 0、离心率 0；代码里 `len(edges)+1` 个节点，BFS 正常工作，无需特判。两个单点相连答案为 1。
2. **向上取整**：$\lceil d/2 \rceil$ 必须写 `(d+1)/2`。写成 `d/2` 的反例：两条单边树（$d_1=d_2=1$）正确答案 3，取整错误时算出 1。
3. **交叉项的 $+1$**：新边本身贡献 1，漏加则"两个单点"会答 0 而非 1。
4. **别忘了 $\max(d_1, d_2)$**：一棵树自身直径很大时，怎么连都救不回来。$10^5$ 长的链挂一个单点，答案仍是 $10^5$。
5. **只 BFS 一次不够**：一次 BFS 只得到"距起点的最远距离"，仅当起点恰为直径端点时才等于直径——这正是要 BFS 两次的原因（引理 2）。
6. **递归 DFS 爆栈**：$10^5$ 长的链使递归深度 $10^5$，Python 直接 `RecursionError`，C++ 也有栈溢出风险；用 BFS 或迭代 DFS。
7. **并列最远点任取其一**：`max_element` / `max()` 遇到并列取先者即可，引理 2 对"之一"成立。
8. **无向边建双向**：邻接表要加两条边，常见笔误。
