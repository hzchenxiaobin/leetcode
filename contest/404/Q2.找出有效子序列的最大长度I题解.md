# LeetCode 找出有效子序列的最大长度 I 题解

## 1. 题目概述

- **标题 / 题号**：找出有效子序列的最大长度 I（#3201，medium）
- **链接**：https://leetcode.cn/problems/find-the-maximum-length-of-valid-subsequence-i/
- **来源**：LeetCode 第 404 场周赛 Q2
- **难度**：中等
- **标签**：数组、动态规划、枚举、贪心

**题意**：给定整数数组 `nums`，从中选出一个**子序列** `sub`（保序、可不连续），要求 `sub` 中**所有相邻元素之和的奇偶性全都相同**，即

$$(\text{sub}[0] + \text{sub}[1]) \bmod 2 = (\text{sub}[1] + \text{sub}[2]) \bmod 2 = \cdots = (\text{sub}[x-2] + \text{sub}[x-1]) \bmod 2$$

返回这样的**最长有效子序列**的长度。

**约束**：

- $2 \le \text{nums.length} \le 2 \times 10^5$
- $1 \le \text{nums}[i] \le 10^7$

> 💡 **审题关键**：判定条件里只出现加法与 $\bmod\ 2$——$(a + b) \bmod 2$ 只由 $a, b$ 的**奇偶性**决定，与具体数值无关。值域 $10^7$ 是烟雾弹，整个数组可以压成一个 0/1 串。另外这是**子序列**不是子数组：可以跳着选，但不许改变顺序。

## 2. 示例

**示例 1**

```text
输入：nums = [1,2,3,4]
输出：4
解释：整个数组 [1, 2, 3, 4] 就是一个有效子序列：
     相邻和 3, 5, 7 全是奇数。
```

**示例 2**

```text
输入：nums = [1,2,1,1,2,1,2]
输出：6
解释：最长有效子序列是 [1, 2, 1, 2, 1, 2]（跳过第 4 个元素），
     相邻和 3, 3, 3, 3, 3 全是奇数。
```

**示例 3**

```text
输入：nums = [1,3]
输出：2
解释：[1, 3] 相邻和为 4（偶数），整个数组即答案。
```

## 3. 解题思路

### 3.1 暴力思路：枚举子序列 / O(n²) DP 都会超时

最直接的想法是枚举所有子序列逐一验证——$2^n$ 种组合，指数爆炸。退一步是标准的「以 $i$ 结尾」DP：

$$f[i][j] = \text{以 } \text{nums}[i] \text{ 结尾、最后一对和} \bmod 2 = j \text{ 的最长长度}$$

转移需要枚举前一个元素的下标 $i'$，整体 $O(n^2)$。本题 $n \le 2 \times 10^5$，$4 \times 10^{10}$ 次运算必然超时——必须把「奇偶性」这层信息彻底榨干，把平方降成线性。

### 3.2 核心观察：只看奇偶，有效子序列只有三种形态

由 $(a + b) \bmod 2 = (a \bmod 2) \oplus (b \bmod 2)$，判定条件只关心每个元素的**一比特信息**：奇偶性。设某有效子序列所有相邻和的**公共奇偶性**为 $k \in \{0, 1\}$：

- **$k = 0$（相邻和全是偶数）**：奇+奇=偶、偶+偶=偶 → 相邻元素必须**同奇偶**，奇偶性沿子序列一路传导——**要么全奇，要么全偶**，两种形态；
- **$k = 1$（相邻和全是奇数）**：奇+偶=奇 → 相邻元素必须**异奇偶**——**奇偶交替**，一种形态（奇开头、偶开头都归它管）。

于是全部候选只有三个，答案**三选一**：

$$\text{ans} = \max(\underbrace{\text{奇数个数}}_{\text{全奇}},\ \underbrace{\text{偶数个数}}_{\text{全偶}},\ \underbrace{\text{最长交替}}_{k=1})$$

而**最长交替子序列**有经典刻画：把 `nums` 切成**极大同奇偶连续段**（每个段内奇偶相同、相邻段奇偶互异），**每个段各取一个元素**就得到最长交替子序列，其长度恰为**段数** $R$（双向夹逼：每段取一个确实合法且保序；同一段内取两个则它们之间的被选元素全都同奇偶，交替性必被破坏，故每段至多取一个）。

![核心观察：三种奇偶形态三选一](images/valid_subseq_parity_forms.svg)

### 3.3 算法流程：三个计数器，一趟扫描

全奇/全偶各是一个计数器；最长交替 = 段数，也只需一个「遇到奇偶翻转就 +1」的计数器。全程一次遍历：

```text
odd = even = runs = 0, last = -1     # last：上一个元素的奇偶，-1 为哨兵
for x in nums:
    p = x & 1
    if p == 1: odd += 1
    else:      even += 1
    if p != last:                    # 奇偶翻转 → 进入新的一段
        runs += 1
        last = p
return max(odd, even, runs)
```

![算法流程：三计数器一趟扫描](images/valid_subseq_count_flow.svg)

### 3.4 示例演算

以示例 2 `nums = [1,2,1,1,2,1,2]` 为例，奇偶序列为 $1,0,1,1,0,1,0$：

| 奇偶序列 | 1 | 0 | 1 | 1 | 0 | 1 | 0 |
|----------|---|---|---|---|---|---|---|
| 段划分 | ① | ② | ③ | ③ | ④ | ⑤ | ⑥ |

- **全奇**：$1,1,1,1$ 共 4 个；**全偶**：$2,2,2$ 共 3 个；
- **交替**：6 个极大同奇偶段（$1\,|\,0\,|\,1\,1\,|\,0\,|\,1\,|\,0$），每段取一个 → $[1,2,1,2,1,2]$，长度 6；
- $\text{ans} = \max(4, 3, 6) = 6$ ✓。

![示例演算：奇偶段分解与三候选](images/valid_subseq_runs_walkthrough.svg)

复核另外两个示例：

- `[1,2,3,4]`：奇偶 $1,0,1,0$，全奇 2、全偶 2、段数 4 → $\text{ans} = 4$ ✓；
- `[1,3]`：奇偶 $1,1$，全奇 2、全偶 0、段数 1 → $\text{ans} = 2$ ✓。

## 4. 算法细节

1. **奇偶压缩**：用 `x & 1` 取代 `x % 2`，位运算更稳（本题全为正数无区别，养成习惯防负数取模陷阱）。

2. **段计数的哨兵**：`last` 初始化为 $-1$（既非 0 也非 1），保证第一个元素必然触发 `runs += 1`。若误初始化为 0，全奇数组会漏掉第一段。

3. **「每段取一个」的正确性**（§3.2 双向夹逼的展开）：
   - **可达**：相邻极大段奇偶互异，段首元素构成保序交替子序列，长度为段数 $R$；
   - **上界**：交替子序列在任一段内至多取一个元素——若取了同段两个元素 $i < j$，则子序列中位于二者之间的元素（若有）都落在该段内（段连续），必然出现相邻两元素同奇偶，矛盾；若没有中间元素则二者直接相邻、同奇偶同样矛盾。
   - 因此「最长交替」不需要分奇开头/偶开头分别求——两种开头的交替子序列长度都不超过 $R$，而 $R$ 可达。

4. **备选写法：统一 DP 一个转移式通吃**。枚举公共奇偶 $k \in \{0,1\}$，设 $f[r]$ 为「相邻和 $\bmod 2 = k$ 的子序列中以奇偶 $r$ 结尾的最长长度」。处理奇偶为 $p$ 的元素时，前驱奇偶 $q$ 须满足 $q \oplus p = k$，解得 $q = k \oplus p$，于是转移仅一行：

   $$f[p] \leftarrow f[k \oplus p] + 1$$

   两轮扫描后取 $\max(f[0], f[1])$。这个转移式把三种形态**统一进一个式子**（$k=0$ 轮自动退化为奇偶计数），且**原样推广**到同场 Q3（3202，把 $\bmod\ 2$ 换成 $\bmod\ k$）——分类计数法在 Q3 会因候选形态爆炸而失效，届时必须换这套 DP，详见「相关题目与扩展」。

## 5. 正确性证明

**引理 1（形态分类）**：长度 $x \ge 2$ 的有效子序列必为「全奇」「全偶」「奇偶交替」三种形态之一。

**证明**：设所有相邻和的公共奇偶性为 $k$。

- $k = 0$：对每个相邻对有 $(\text{sub}[i] + \text{sub}[i+1]) \equiv 0 \pmod 2$，即 $\text{sub}[i] \equiv \text{sub}[i+1] \pmod 2$——相邻元素同奇偶。对 $i$ 归纳，全体元素奇偶性相同，故为全奇或全偶。
- $k = 1$：同理相邻元素奇偶互异，奇偶性沿位置逐位翻转，即奇偶交替。∎

**引理 2（交替的刻画）**：`nums` 的最长奇偶交替子序列长度等于极大同奇偶连续段的段数 $R$。

**证明**：

- **$\ge$**：段与段相邻处奇偶互异（极大性），故「第 1 段取第一个元素、第 2 段取第一个元素、……」得到一个保序子序列，相邻被选元素来自相邻段、奇偶互异，是长度为 $R$ 的交替子序列。
- **$\le$**：设交替子序列在某段内取了下标 $i < j$ 两个元素。由段的连续性，子序列中位于 $i, j$ 之间的元素（若有）均取自该段、与它们同奇偶。于是子序列中 $\text{sub}[i]$ 到 $\text{sub}[j]$ 之间（含两端）任意相邻对都同奇偶：若中间无被选元素则 $\text{sub}[i], \text{sub}[j]$ 直接相邻、同奇偶，矛盾；若有被选元素则第一对相邻被选元素同奇偶，矛盾。故每段至多贡献一个元素，长度 $\le R$。∎

**定理**：算法输出 $\max(\text{odd}, \text{even}, R)$ 即最长有效子序列的长度，且 $n \ge 2$ 时其值 $\ge 2$。

**证明**：

- **可行性（$\ge$ 每个候选都可构造）**：全部奇数构成有效子序列（任意相邻和 = 奇+奇 = 偶，全同奇偶 ✓），长度为 odd；全部偶数同理，长度为 even；引理 2 的构造给出长度 $R$ 的交替子序列（任意相邻和 = 奇+偶 = 奇 ✓）。故输出对应一个真实存在的有效子序列。
- **最优性（任一有效子序列被三个候选覆盖）**：设 $S$ 为任一有效子序列。若 $|S| \ge 2$，由引理 1 它是三种形态之一：全奇则 $|S| \le \text{odd}$（奇数总共只有 odd 个），全偶则 $|S| \le \text{even}$，交替则由引理 2 $|S| \le R$。故 $\max(\text{odd}, \text{even}, R) \ge |S|$。若 $|S| = 1$ 则平凡地被覆盖（$n \ge 2$ 时三个候选均 $\ge 1$）。
- **$\ge 2$**：$n \ge 2$ 时，若数组含两种奇偶则 $R \ge 2$；若只含一种奇偶则 $\max(\text{odd}, \text{even}) \ge 2$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。一趟扫描，每个元素只做一次位与、若干次比较与自增，均为 $O(1)$。
- **空间复杂度**：$O(1)$。仅 `odd`、`even`、`runs`、`last` 四个整型变量。

> 💡 对比 $O(n^2)$ DP：$n = 2 \times 10^5$ 时快 5 个数量级。能降复杂度的本质是把「前一个元素是**谁**」压缩成「前一个元素的**奇偶性**」——需要记录的状态从 $n$ 个下标降到 1 比特。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int maximumLength(vector<int>& nums) {
        int odd = 0, even = 0, runs = 0;
        int last = -1;                       // 哨兵：既非 0 也非 1
        for (int x : nums) {
            int p = x & 1;
            p ? ++odd : ++even;              // 全奇 / 全偶 两个候选
            if (p != last) {                 // 奇偶翻转 → 新的一段
                ++runs;                      // 最长交替候选 = 段数
                last = p;
            }
        }
        return max({odd, even, runs});
    }
};
```

### Python

```python
class Solution:
    def maximumLength(self, nums: List[int]) -> int:
        odd = even = runs = 0
        last = -1                            # 哨兵：既非 0 也非 1
        for x in nums:
            p = x & 1
            if p:
                odd += 1                     # 全奇候选
            else:
                even += 1                    # 全偶候选
            if p != last:                    # 奇偶翻转 → 新的一段
                runs += 1                    # 最长交替候选 = 段数
                last = p
        return max(odd, even, runs)
```

### 备选：统一 DP（为 Q3 铺路的写法）

```python
class Solution:
    def maximumLength(self, nums: List[int]) -> int:
        ans = 0
        for k in (0, 1):                     # k：相邻和的公共奇偶
            f = [0, 0]                       # f[r]：以奇偶 r 结尾的最长长度
            for x in nums:
                p = x & 1
                f[p] = f[k ^ p] + 1          # 前驱奇偶必为 k ^ p
            ans = max(ans, f[0], f[1])
        return ans
```

## 8. 边界情况与易错点

1. **三个候选缺一不可**：只数 `odd/even` 会漏掉交替形态（`[1,2]` 全奇全偶各 1，答案却是 2）；只数 `runs` 会漏掉全同奇偶形态（`[1,3]` 段数 1，答案是 2）。必须 $\max$ 齐上三项。
2. **子序列 ≠ 子数组**：「最长交替」数的是**段数**，不是最长交替**子数组**的长度。`[1,2,1,1,2,1,2]` 里最长交替子数组是 4，但答案（子序列）是 6，跳选的自由度正是子序列题的精髓。
3. **`last` 哨兵取 -1**：初始化为 0 会让全奇数组漏计第一段（`runs` 少 1，`[1,3]` 得 0 段）；初始化为 1 同理坑全偶数组。$-1$ 保证首元素必开新段。
4. **答案至少为 2 无需特判**：$n \ge 2$ 时任取两个元素，只有一对相邻和，条件自动成立。三个候选的最大值天然 $\ge 2$（见 §5 定理），不必写 `if n >= 2` 之类的补丁。
5. **不要被值域迷惑**：$1 \le \text{nums}[i] \le 10^7$ 不需要离散化、去重或任何值域处理——条件只读奇偶一比特，`x & 1` 一步到位。
6. **长度 1 的条件是真空的**：$x = 1$ 时没有相邻对，条件平凡成立。本题 $n \ge 2$ 使其无影响，但若写「逐元素维护状态」的解法（如 DP），别假设子序列长度至少为 2 才开始转移。

**延伸思考**：

- 为什么 Q2 能「数数」而 Q3 必须 DP？本质是**约束只涉及相邻元素的二元关系**时，状态可压缩到「关系相关的等价类」：模 2 只有 2 个等价类、候选形态常数个；模 $k$ 有 $k$ 个等价类，候选形态数随 $k$ 平方增长，而 DP 的状态数只随 $k$ 线性增长——选哪个取决于「枚举候选」和「维护状态」哪个便宜。
- 若把问题改成「统计**恰好**长度为 $x$ 的有效子序列个数」：三形态分别用组合计数（全奇/全偶 $C(\text{odd},x)$、$C(\text{even},x)$）与奇偶前缀和（交替形态按段组合）解决，从最优化退化为计数，是很好的组合数学练习。
- 若约束改成「相邻和的奇偶性按 $0,1,0,1,\dots$ **周期交替**」：给 DP 加一维「当前处于周期哪个位置」即可，转移结构不变——周期性约束是这类题的下一个变体方向。
