# LeetCode 找出最长的超赞子字符串 题解

## 1. 题目概述

- **标题 / 题号**：找出最长的超赞子字符串（#1542，hard）
- **链接**：https://leetcode.cn/problems/find-longest-awesome-substring/
- **来源**：LeetCode 第 32 场双周赛 Q4
- **难度**：困难
- **标签**：位运算、哈希表、字符串

**题意**：给定数字串 $s$。子串（非空连续）若能**经过任意次字符交换**变成回文串，则称为「超赞子字符串」。返回最长超赞子字符串的长度。

**约束**：

- $1 \le |s| \le 10^5$
- $s$ 仅由数字组成

## 2. 示例

**示例 1**

```text
输入：s = "3242415"
输出：5
解释："24241" 重排后可得回文 "24142"。
```

**示例 2**

```text
输入：s = "12345678"
输出：1
解释：任何长度 ≥ 2 的子串都有两个及以上出现奇数次的字符。
```

**示例 3**

```text
输入：s = "213123"
输出：6
解释："213123" 重排得回文 "231132"。
```

**示例 4（边界补充）**

```text
输入：s = "00"
输出：2
解释："00" 本身就是回文。
```

## 3. 解题思路

### 3.1 暴力思路

枚举全部 $O(n^2)$ 个子串，每个用 $O(10)$ 的计数数组判断「至多一个字符出现奇数次」，总 $O(10 n^2)$，$n = 10^5$ 时约 $10^{11}$ 次操作，超时。优化方向：把「子串的字符奇偶状态」表示成可 $O(1)$ 增量维护、$O(1)$ 比较的量——**前缀异或掩码**。

### 3.2 核心观察：重排回文的判定 + 前缀异或

![前缀异或掩码](images/bw32_q4_prefix_xor_mask.svg)

**判定引理**：多重集合能重排成回文，当且仅当**出现奇数次的字符至多一种**（偶数长度回文要求零个，奇数长度回文恰一个放正中）。

**状态压缩**：只关心每个数字出现次数的**奇偶**。定义 10 位掩码 $\textit{mask}$：第 $d$ 位为 1 表示数字 $d$ 已出现奇数次。预处理前缀掩码 $P_i$ = $s[0..i]$ 的奇偶掩码，则子串 $s[l..r]$ 的奇偶掩码为

$$P_r \oplus P_{l-1}$$

（异或恰好消去两次出现的抵消部分——这是「奇偶计数差」的完美代数结构）。

**最长子串转化**：固定右端点 $r$，合法的 $P_{l-1}$ 只有两种：

- $P_{l-1} = P_r$（子串掩码全 0，全部偶数次，偶回文）；
- $P_{l-1} = P_r \oplus 2^d$（子串掩码恰第 $d$ 位为 1，$d \in [0, 10)$，奇回文）。

要子串最长，就要 $l-1$ **最小**。于是维护 $\textit{first}[m]$ = 掩码 $m$ **首次出现**的下标（初始 $\textit{first}[0] = -1$ 对应空前缀），每个右端点 $O(1)$ 查询「同掩码首现」与 $O(10)$ 查询「翻转一位掩码的首现」，取最大跨度。

这与经典题「最长子数组使其和为 k / 模 m 同余」完全同构：**前缀状态 + 首现哈希**，只是「状态」从数值换成 10 位异或掩码、查询从单点变成 11 个目标。

### 3.3 算法流程

```text
1. first[0..1023] = 未出现；first[0] = -1（空前缀）
2. mask = 0, ans = 0
3. 对 i = 0 .. n-1：
       mask ^= 1 << (s[i] - '0')
       若 first[mask] 未出现：first[mask] = i
       ans = max(ans, i - first[mask])            # 掩码全偶
       对 d = 0 .. 9：
           m2 = mask ^ (1 << d)
           若 first[m2] 已出现：ans = max(ans, i - first[m2])   # 恰一位奇
4. 返回 ans
```

### 3.4 示例演算

![演算走查表](images/bw32_q4_walkthrough_table.svg)

以 $s = \text{"3242415"}$ 为例（完整掩码表见上图）：前缀掩码依次为 $8$（只有 3 奇）、$12$、$28$、$24$、$8$（4 出现第二次抵消，回到 3 奇）、$10$、$56$。最优答案 5 在下标 5 处产生：当前 $\textit{mask} = P_5 = 10$，查询翻转第 1 位的目标 $10 \oplus 2 = 8$，命中 $\textit{first}[8] = 0$（下标 0 处的前缀掩码），跨度 $5 - 0 = 5$，对应子串 $s[1..5] = \text{"24241"}$——其掩码 $P_5 \oplus P_0 = 10 \oplus 8 = 2$，恰数字 1 出现奇数次（1 次），是奇回文，重排得 "24142"。同掩码配对在下标 4 处贡献长度 4（$P_4 = 8 = P_0$），翻转查询未更长，最终答案 $5$ ✓。

## 4. 算法细节

1. **掩码更新是异或不是置位**：`mask ^= 1 << d`，同一数字第二次出现时把位翻回 0。误用 `|=` 会把「出现两次」误记为奇。
2. **`first` 记首现不记末现**：要最长子串，左端点越小越好；同一个掩码再次出现时**不更新** `first`。
3. **`first[0] = -1`**：空前缀。它使「从串首开始的子串」也能被 $i - \textit{first}[m]$ 正确计算（下标差即长度）。漏掉它，`"213123"` 这类答案从头开始的样例会算小。
4. **查询顺序**：先记录当前 `mask` 的首现（若未出现），再做查询——否则 $i - \textit{first}[\textit{mask}]$ 用刚写入的自身会得 0（无害但白算）；先查询后写入也可，两者等价，注意别把「更新首现」误写成「覆盖」。
5. **数组代替哈希表**：掩码域只有 $2^{10} = 1024$，用定长数组 + 哨兵（如 $-2$ 表示未出现）比哈希表快得多；这是状态压缩带来的常数红利。
6. **「至多一个奇字符」的 11 个目标**：同掩码 1 个 + 翻转一位 10 个。子串长度的奇偶由掩码 popcount 的奇偶自动决定，无需额外讨论。

## 5. 正确性证明

**引理 1（重排回文判定）**：字符多重集能重排成回文串，当且仅当出现次数为奇数的字符种类数 $\le 1$。

**证明**：（充分）设奇数次字符为 $c_0$（或没有）。对每个偶数次字符 $c$，将其 $\textit{cnt}(c)$ 个副本对半分到串两端；把 $c_0$ 的全部副本放正中。构造出的串 $u \cdot c_0^{\textit{cnt}(c_0)} \cdot \textit{rev}(u)$ 显然是回文。（必要性）设 $w$ 是回文，长 $L$。若 $L$ 偶，位置 $i$ 与 $L-1-i$ 配对成 $L/2$ 对，每对贡献同字符两次，所有字符次数皆为偶；若 $L$ 奇，同理除正中一个位置外全部配对，正中字符是唯一的奇数次字符。∎

**引理 2（前缀异或分解）**：子串 $s[l..r]$ 中数字 $d$ 出现次数的奇偶性，等于 $P_r$ 与 $P_{l-1}$ 第 $d$ 位异或的值；从而子串的奇偶掩码恰为 $P_r \oplus P_{l-1}$。

**证明**：$P_i$ 第 $d$ 位 $= (\textit{cnt}_i(d) \bmod 2)$，其中 $\textit{cnt}_i(d)$ 是 $s[0..i]$ 中 $d$ 的出现次数。子串计数 $\textit{cnt}(l, r, d) = \textit{cnt}_r(d) - \textit{cnt}_{l-1}(d)$，模 2 下减法即加法：$\textit{cnt}(l,r,d) \bmod 2 = (\textit{cnt}_r(d) + \textit{cnt}_{l-1}(d)) \bmod 2 = P_r[d] \oplus P_{l-1}[d]$。逐位成立即掩码异或成立。∎

**引理 3（合法配对的目标集）**：子串 $s[l..r]$ 超赞 ⟺ $P_{l-1} \in \{P_r\} \cup \{P_r \oplus 2^d : 0 \le d < 10\}$。

**证明**：由引理 1，超赞 ⟺ 子串掩码至多一位为 1。由引理 2，子串掩码 $= P_r \oplus P_{l-1}$，故 ⟺ $P_r \oplus P_{l-1} \in \{0, 2^0, \dots, 2^9\}$ ⟺ $P_{l-1} \in \{P_r\} \cup \{P_r \oplus 2^d\}$（异或 $P_r$ 自逆）。∎

**定理**：算法返回最长超赞子字符串的长度。

**证明**：对每个右端点 $r$，由引理 3，以 $r$ 结尾的最长超赞子串的左端点 $l$ 满足 $P_{l-1}$ 属于 11 个目标掩码之一；$l$ 最小 ⟺ $l - 1$ 最小 ⟺ 目标掩码的**首次出现下标**最小。算法用 $\textit{first}$ 数组对每个目标取首现下标，$r - \textit{first}$ 即以 $r$ 结尾的最长长度（注意 $\textit{first}[m] \le r$ 恒成立：当前掩码 $P_r$ 若从未出现则恰在本轮写入，跨度 0 不影响正确性）。对所有 $r$ 取最大，覆盖了全部子串的右端点，故返回值是最长超赞子串长度。∎

**与「最长奇偶回文子串」的同构**：把「数字 $d$ 的奇偶位」看作字符集大小为 $k$ 的字母表，「子串内每种字符出现偶数次（或恰一个奇）」在两个问题里完全一致；$k = 1$ 时该框架退化为「最长和为偶/奇子数组」（掩码 1 位），$k = 26$ 时即是「重排回文子串」的一般形态。状态压缩 + 前缀首现是这一整族的统一解法。

## 6. 复杂度分析

- **时间**：$O(10n + 2^{10})$。每个右端点 1 次掩码更新 + 11 次首现查询（10 次翻转一位 + 1 次同掩码）；初始化 $\textit{first}$ 数组 $O(1024)$。
- **空间**：$O(2^{10})$。首现数组 1024 个整数；无需保存全部前缀掩码（增量维护单个 `mask` 即可）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int longestAwesome(string s) {
        const int UNSEEN = -2;
        vector<int> first(1 << 10, UNSEEN);    // first[mask]：前缀异或值首次出现的下标
        first[0] = -1;                          // 空前缀（下标 -1）
        int mask = 0, ans = 0;
        for (int i = 0; i < (int)s.size(); ++i) {
            mask ^= 1 << (s[i] - '0');
            if (first[mask] == UNSEEN) first[mask] = i;
            if (i - first[mask] > ans) ans = i - first[mask];          // 全偶
            for (int d = 0; d < 10; ++d) {                              // 恰一个奇
                int m2 = mask ^ (1 << d);
                if (first[m2] != UNSEEN && i - first[m2] > ans) ans = i - first[m2];
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def longestAwesome(self, s: str) -> int:
        first = [-2] * (1 << 10)          # -2 = 未出现
        first[0] = -1                      # 空前缀
        mask = ans = 0
        for i, ch in enumerate(s):
            mask ^= 1 << (ord(ch) - 48)
            if first[mask] == -2:
                first[mask] = i
            if i - first[mask] > ans:
                ans = i - first[mask]
            for d in range(10):
                m2 = mask ^ (1 << d)
                if first[m2] != -2 and i - first[m2] > ans:
                    ans = i - first[m2]
        return ans
```

> 💡 两份代码均通过官方全部示例（`5`、`1`、`6`、`2`）及单字符边界，另与 361 组随机串（含 2/3/4/10 种数字、单字符重复、双字符交替等对抗样例）上的 $O(n^2)$ 计数暴力对拍，`mismatch = 0`。

## 8. 边界情况与易错点

1. **`first[0] = -1` 不可漏**：空前缀的掩码是 0；漏掉后所有「从头开始」的超赞子串都会算短（如 `"213123"` 会从 6 掉到某个更小值）。
2. **首现不要被覆盖**：再次遇到同一掩码时保持 `first` 不变。误写 `first[mask] = i`（每次更新）会把答案变成「最短」方向。
3. **异或 vs 按位或**：`mask ^= 1 << d` 正确处理「同一数字出现两次抵消」；`|=` 会在 `"00"` 上把掩码错记为 1，导致答案错误。
4. **未出现哨兵的选择**：用 $-2$（或任何 $< -1$ 的值）区别于合法下标 $-1$；若用 $-1$ 当哨兵，会与空前缀混淆造成误命中。
5. **循环内 11 个查询都要做**：只查同掩码（不做翻转一位）会漏掉所有奇数长度回文情形，`"24241"` 类样例立即出错；反之只查翻转也会漏全偶情形。
6. **popcount 不必显式算**：「至多一个奇字符」已通过 11 个目标掩码的枚举隐式表达，无需对每个子串统计 popcount。
