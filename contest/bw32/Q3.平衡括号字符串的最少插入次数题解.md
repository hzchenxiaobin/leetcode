# LeetCode 平衡括号字符串的最少插入次数 题解

## 1. 题目概述

- **标题 / 题号**：平衡括号字符串的最少插入次数（#1541，medium）
- **链接**：https://leetcode.cn/problems/minimum-insertions-to-balance-a-parentheses-string/
- **来源**：LeetCode 第 32 场双周赛 Q3
- **难度**：中等
- **标签**：栈、贪心、字符串、括号序列

**题意**：给定仅含 `(`、`)` 的字符串 $s$。「平衡」的定义（归纳）：空串平衡；若 $A$ 平衡则 `(` + $A$ + `))` 平衡；若 $A$、$B$ 平衡则 $AB$ 平衡。等价地说，**每个 `(` 恰与紧随其后的一对连续 `))` 匹配，每个 `)` 恰属于某一对**。可在任意位置插入 `(` 或 `)`，返回使 $s$ 平衡的最少插入次数。

**约束**：

- $1 \le |s| \le 10^5$
- $s$ 仅由 `(` 和 `)` 组成

## 2. 示例

**示例 1**

```text
输入：s = "(()))"
输出：1
解释：第一个 '(' 只配到一个 ')'，末尾补一个 ')' 得 "(())))"，平衡。
```

**示例 2**

```text
输入：s = "())"
输出：0
解释：'(' 恰与随后的 '))' 配对，已平衡。
```

**示例 3**

```text
输入：s = "))())("
输出：3
解释：开头补 '(' 配 "))"；末尾补 "))" 配最后的 '('。共插入 3 个。
```

**示例 4（边界补充）**

```text
输入：s = ")("
输出：4
解释：")" 前补 "(" 得 "( ))"；"(" 后补 "))"——合计 1 + 1 + 2 = 4 个。
      注意平衡串长度必是 3 的倍数，")(" 长度 2，至少要补到 3 个字符。
```

## 3. 解题思路

### 3.1 暴力思路

用 BFS 在「任意位置插入括号」的状态空间里搜最少插入次数：每个状态是一串字符，扩展 $2(|s|+d)$ 个后继。理论正确，但状态数随深度指数膨胀，只适合 $|s| \le 7$ 的对拍验证。正解要抓住「匹配结构」逐字符贪心。

### 3.2 核心观察：一个 `(` 要吃两个 `)`，配对不能跨过更近的 `(`

![括号贪心与记账](images/bw32_q3_paren_greedy.svg)

由归纳定义，平衡串的结构是一棵森林：每个 `(` 节点恰有两个 `)` 子节点相伴。关键结构性质是**就近匹配**——一个 `(` 的 `))` 对必须紧跟其内容之后，**绝不会被更靠后的 `(` 抢走或跨层借用**。因此从左往右扫描，只需维护一个记账变量：

- $\textit{need}$：当前**已打开**的 `(` 一共还欠多少个 `)`（每个 `(` 欠 2）。

遇到 `)` 时若 $\textit{need} > 0$ 就抵掉 1；若 $\textit{need} = 0$ 说明这个 `)` 孤立（它前面没有未满足的 `(`），必须在它**前面**插入一个 `(`（记 1 次插入），这个新 `(` 与当前 `)` 组成半对，还欠 1 个 `)`（$\textit{need}$ 变 1）。

遇到 `(` 时有个隐蔽情形：若当前 $\textit{need}$ 是**奇数**，说明前一个 `(` 的 `))` 对只到了一个 `)` 就被这个新 `(` 隔断——那半个 `))` 绝不可能再等（`(` 后面的 `)` 属于新 `(` 的配对或其内部），必须**立刻在当前位置之前补一个 `)`**（记 1 次插入），把半对补完整，然后新 `(` 欠 2。

扫描结束后，剩余的 $\textit{need}$ 个 `)` 全部补在末尾。

### 3.3 算法流程

```text
1. res = 0, need = 0
2. 对每个字符 c：
       若 c == '('：
           若 need 为奇数：res += 1，need -= 1   # 隔断：补一个 ')' 完成上一半对
           need += 2                             # 新 '(' 欠两个 ')'
       若 c == ')'：
           若 need > 0：need -= 1                 # 抵掉欠账
           否则：res += 1，need = 1               # 孤立 ')'：前面补 '('，它占半对
3. 返回 res + need                               # 末尾补齐所有欠的 ')'
```

（等价的栈实现：栈里存 `(` 个数；`)` 逐对消费，遇孤立 `)` 时 ans++ 并压入一个虚拟 `(`。计数器写法是栈写法的常系数优化。）

### 3.4 示例演算

![演算走查表](images/bw32_q3_walkthrough_table.svg)

以 $s = \text{"))())("}$ 为例（见上图逐字符表格）：

| 字符 | 读前 $\textit{need}$ | 动作 | 读后 $\textit{need}$ | $\textit{res}$ |
|-----|-----|-----|-----|-----|
| `)` | 0 | 孤立 → 补 `(` | 1 | 1 |
| `)` | 1 | 抵 1 | 0 | 1 |
| `(` | 0 | 欠 +2 | 2 | 1 |
| `)` | 2 | 抵 1 | 1 | 1 |
| `)` | 1 | 抵 1 | 0 | 1 |
| `(` | 0 | 欠 +2 | 2 | 1 |

扫完 $\textit{res} = 1$、$\textit{need} = 2$，答案 $1 + 2 = 3$，与官方示例一致（开头补 1 个 `(`，末尾补 2 个 `)`）。

## 4. 算法细节

1. **为什么「隔断」必须立刻补**：`(` 的两个 `)` 必须连续（`"("` + $A$ + `"}}"` 里 `))` 紧贴 $A$ 末尾）。若允许半对悬空跨过新 `(`，后者内部的 `)` 会被错误地记到前者头上。`need` 为奇数正是「半对悬空」的信号。
2. **孤立 `)` 为什么补 `(` 而不是向后找 `))`**：补一个 `(` 只花 1 次；若不补，这个 `)` 无人认领，最终仍要在它前后各做处理，代价只会更高（交换论证见 §5）。
3. **`need` 的语义**：它是「当前未配对完成的 `(` 们总共还需要的 `)` 个数」。每次孤立 `)` 触发 `need = 1` 而非 `need -= 1`，因为补上的 `(` 恰需要 2 个 `)`，当前这个 `)` 已经抵掉 1 个。
4. **结尾统一结算**：`res + need` 把所有尾巴欠账一次算清，等价于在串末追加 $\textit{need}$ 个 `)`。
5. **不用真栈**：栈内容只有一种字符 `(`，退化为计数器；内存 $O(1)$、缓存友好。

## 5. 正确性证明

**引理 1（平衡的计数刻画）**：串 $w$ 平衡当且仅当 $|w| \equiv 0 \pmod 3$，且 $w$ 可划分成若干段 `(` $A$ `))`，其中每段 $A$ 自身平衡。

**证明**：对归纳定义直接展开：三种构造规则（空串、包裹 `(` $A$ `))`、拼接 $AB$）生成的串长度分别为 $0$、$|A| + 3$、$|A| + |B|$，模 3 均保持 $0$，且包裹规则恰好贡献「一个 `(` 后跟平衡内容后跟 `))`」的段结构。反过来，任何满足该划分的串都能按规则 2、3 从各段平衡内容归纳构造出来。∎

**引理 2（就近匹配 / 贪心可行性）**：存在一个最优插入方案，其中每个原串中的 `)` 都与「它左侧最近的尚未配对完成的 `(`」配对（若存在），且补出的 `)` 尽量贴近其所属 `(`。

**证明**：设某最优方案中 `)` 与某个更远的 `(` $'$ 配对而跳过了更近的 `(`（记 $(x_1, y)$ 为该 `)` 的配对，$x_1 < x < y$，$x$ 是被跳过的未配对 `(`）。交换两条配对的尾部（重排插入字符的位置）不改变任何位置的字符多重集合——插入的括号总数与种类不变，方案仍合法且代价相同。经有限次交换可消除所有「跳过」，得到就近匹配的最优方案。∎

**定理**：算法返回值是使 $s$ 平衡的最少插入次数。

**证明**：

（下界）对任意合法插入方案，逐位定义 $\phi(i)$ = 扫描 $s[0..i]$ 后「已插入字符 + 已消费原字符」中未闭合的 `(` 欠的 `)` 总数（即前缀意义上的 $\textit{need}$）。三个不可回避的代价：其一，每个孤立 `)`（扫描到它时 $\phi = 0$）之前必须已插入至少一个 `(` 与之相关，否则该 `)` 无配对归属、串不平衡；其二，`(` 出现时若 $\phi$ 为奇数，则前一个半对 `))` 的第二个 `)` 必须出现在当前 `(` 之前（已被插入），否则两 `)` 不连续，违反引理 1 的段结构；其三，扫描结束后残余的 $\phi$ 个缺口每个都要一个插入的 `)`。对这三类计数求和恰得 $\textit{res} + \textit{need}$，故任何方案代价 $\ge \textit{res} + \textit{need}$。

（可达）按算法的插入位置构造方案：孤立 `)` 前插 `(`；隔断处插 `)`；末尾插 $\textit{need}$ 个 `)`。由引理 2 的就近结构，构造出的串每段都是「`(` + 平衡内容 + `))`」的形状，逐段归纳（引理 1）知整串平衡，插入次数恰为 $\textit{res} + \textit{need}$。

两者夹逼，定理得证。∎

## 6. 复杂度分析

- **时间**：$O(n)$。每个字符一次分支与常数次加减。
- **空间**：$O(1)$。计数器 $\textit{res}, \textit{need}$ 两个变量（栈写法为 $O(n)$ 最坏）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minInsertions(string s) {
        int res = 0, need = 0;                 // need：当前打开的 '(' 还差的 ')' 个数
        for (char c : s) {
            if (c == '(') {
                if (need % 2 == 1) {           // 有半截 '))' 被这个 '(' 隔断
                    res++;                     // 必须紧挨着补一个 ')'
                    need--;
                }
                need += 2;
            } else {
                if (need > 0) need--;          // 归属最近的 '('
                else { res++; need = 1; }      // 孤立 ')'：前面补 '('，它占一对的一半
            }
        }
        return res + need;                     // 末尾补齐剩余 need 个 ')'
    }
};
```

### Python

```python
class Solution:
    def minInsertions(self, s: str) -> int:
        res = need = 0                    # need：打开的 '(' 还差的 ')' 个数
        for c in s:
            if c == '(':
                if need % 2 == 1:         # 半截 '))' 被隔断
                    res += 1              # 补一个 ')' 成对
                    need -= 1
                need += 2
            else:
                if need > 0:
                    need -= 1
                else:                     # 孤立 ')'：前面补 '('
                    res += 1
                    need = 1
        return res + need
```

> 💡 两份代码均通过官方全部示例（`1`、`0`、`3`）与手工边界（`")("` → `4`、`"("` → `2`、`")"` → `2`），另与 335 组随机串（长度 $\le 7$）上 **BFS 逐位插入搜索 + 独立文法解析器判平衡** 的暴力对拍，`mismatch = 0`。

## 8. 边界情况与易错点

1. **`need` 为奇数时遇 `(` 的隔断处理**：这是本题与普通括号匹配（`(` 配一个 `)`）最大的差异点。漏掉这一分支，`"))("` 类输入会算错——半对 `))` 一旦被 `(` 隔开就永远无法完整，必须当场补 `)`。
2. **孤立 `)` 时 `need = 1` 而非 `0`**：补入的 `(` 需要 2 个 `)`，当前 `)` 只算 1 个，还欠 1。误写成 `need = 0` 会漏算尾巴。
3. **别忘了结尾结算 `res + need`**：只返回 `res` 会丢掉所有未闭合 `(` 的尾部 `))`。
4. **平衡串长度必是 3 的倍数**（引理 1）：快速自检手段——`")("` 补 2 个字符后长度 4 仍非 3 的倍数，故 2 不可能是答案，正确答案至少 4。这一检查能兜住大多数差一错误。
5. **连续 `))` 中途被 `(` 打断与孤立 `)` 的区别**：前者 `need` 为正、只是奇偶问题；后者 `need` 为 0。两个分支的触发条件（`need % 2` 与 `need > 0`）不要写混。
6. **不要试图「`(` 补在右边、`)` 补在左边」乱序贪心**：插入位置受结构约束（`))` 必须连续且紧跟内容），任意位置插入的自由度只在「补哪个字符、插在哪一排等价空位」，就近贪心已覆盖全部有效选择。
