# LeetCode 第 k 个缺失的正整数 题解

## 1. 题目概述

- **标题 / 题号**：第 k 个缺失的正整数（#1539，easy）
- **链接**：https://leetcode.cn/problems/kth-missing-positive-number/
- **来源**：LeetCode 第 32 场双周赛 Q1
- **难度**：简单
- **标签**：数组、二分查找

**题意**：给定**严格升序**的正整数数组 $\textit{arr}$ 与整数 $k$。从 1 开始的正整数序列中，去掉 $\textit{arr}$ 中出现的数后得到「缺失序列」，返回缺失序列中的第 $k$ 个数。

**约束**：

- $1 \le \textit{arr.length} \le 1000$
- $1 \le \textit{arr}[i] \le 1000$
- $1 \le k \le 1000$
- 对所有 $1 \le i < j \le \textit{arr.length}$ 有 $\textit{arr}[i] < \textit{arr}[j]$

**进阶**：能否设计 $O(\log n)$ 的算法？

## 2. 示例

**示例 1**

```text
输入：arr = [2, 3, 4, 7, 11], k = 5
输出：9
解释：缺失的正整数为 [1, 5, 6, 8, 9, 10, 12, 13, ...]，第 5 个是 9。
```

**示例 2**

```text
输入：arr = [1, 2, 3, 4], k = 2
输出：6
解释：缺失序列为 [5, 6, 7, ...]，第 2 个是 6。
```

**示例 3（边界补充）**

```text
输入：arr = [2], k = 1
输出：1
解释：1 没有出现在数组里，是第 1 个缺失的正整数。
```

## 3. 解题思路

### 3.1 暴力思路

从小到大枚举正整数 $1, 2, 3, \dots$，用集合或双指针跳过 $\textit{arr}$ 中出现的数，数到第 $k$ 个缺失即返回。时间 $O(\textit{arr}[n-1] + k)$，本题规模下（值域 $\le 1000$、$k \le 1000$）完全够用；但题目「进阶」明确要求 $O(\log n)$，且值域变大后线性枚举会失效，值得掌握下述两种更优做法。

### 3.2 核心观察：缺失个数函数 $\textit{missing}(i) = \textit{arr}[i] - (i+1)$

![二分视角](images/bw32_q1_missing_binary_search.svg)

对下标 $i$（从 0 开始），$\textit{arr}[0..i]$ 共 $i + 1$ 个数，若无缺失则 $\textit{arr}[i]$ 应等于 $i + 1$。由于数组严格升序且每个元素都是正整数，**下标 $i$ 之前（不含 $\textit{arr}[i]$ 自身）缺失的正整数个数恰为**

$$\textit{missing}(i) = \textit{arr}[i] - (i + 1) \ge 0,$$

且 $\textit{missing}$ 随 $i$ **单调不减**（相邻差 $\textit{arr}[i+1] - \textit{arr}[i] - 1 \ge 0$）。于是可以二分：找**第一个** $\textit{missing}(i) \ge k$ 的下标 $\textit{lo}$。

设答案为 $\textit{ans}$（第 $k$ 个缺失数），则比 $\textit{ans}$ 小的正整数中恰有 $\textit{lo}$ 个在数组里（它们正是 $\textit{arr}[0..\textit{lo}-1]$，因为 $\textit{missing}(\textit{lo}-1) < k$ 说明前 $\textit{lo}$ 个元素都 $< \textit{ans}$）、$k - 1$ 个缺失，合计 $\textit{lo} + k - 1$ 个，故

$$\textit{ans} = \textit{lo} + k.$$

（若所有 $\textit{missing}(i) < k$，则 $\textit{lo} = n$，公式同样成立——此时答案在数组末尾之外。）

### 3.3 算法流程（两版）

![线性扫描演算](images/bw32_q1_linear_scan_table.svg)

**二分版**：

```text
1. lo = 0, hi = n
2. while lo < hi：
       mid = (lo + hi) / 2
       若 arr[mid] - (mid + 1) >= k：hi = mid     # 缺的太多，往左找
       否则：lo = mid + 1
3. 返回 k + lo
```

**线性版**（更好写，$O(n)$）：从 $\textit{ans} = k$ 出发，逐个检查 $\textit{arr}[i]$：若 $\textit{arr}[i] \le \textit{ans}$ 则该元素挡在答案前面，$\textit{ans}{+}{+}$；遇到第一个 $\textit{arr}[i] > \textit{ans}$ 即停止。

### 3.4 示例演算

以 $\textit{arr} = [2, 3, 4, 7, 11]$、$k = 5$ 为例：

| $i$ | $\textit{arr}[i]$ | $\textit{missing}(i)$ | 与 $k=5$ 比较 |
|-----|-----|-----|-----|
| 0 | 2 | $2 - 1 = 1$ | $< 5$ |
| 1 | 3 | $3 - 2 = 1$ | $< 5$ |
| 2 | 4 | $4 - 3 = 1$ | $< 5$ |
| 3 | 7 | $7 - 4 = 3$ | $< 5$ |
| 4 | 11 | $11 - 5 = 6$ | $\ge 5$ ✓ |

第一个 $\ge k$ 的下标 $\textit{lo} = 4$，答案 $= k + \textit{lo} = 5 + 4 = 9$。线性版演算（上图）：$\textit{ans}$ 从 5 起被 $2, 3, 4, 7$ 依次顶到 $9$，$11 > 9$ 停止，同样得 $9$。

## 4. 算法细节

1. **$\textit{missing}(i)$ 为何非负**：严格升序正整数保证 $\textit{arr}[i] \ge i + 1$（前 $i+1$ 个互不相同的最小正整数至少是 $1..i+1$），故差值 $\ge 0$；这一非负性也是公式 $\textit{ans} = \textit{lo} + k$ 在 $\textit{lo} = n$ 时仍成立的基础。
2. **二分边界**：闭开区间 $[\textit{lo}, \textit{hi})$ 模板，`hi` 初始为 $n$（不是 $n-1$），允许「全体都不够」的答案落在数组之外。
3. **线性版的停止条件**：数组有序，一旦 $\textit{arr}[i] > \textit{ans}$，后面的元素更大，不会再顶动 $\textit{ans}$，可立即 `break`（不 break 也正确，只是白扫）。
4. **答案可能超出数组值域**：如 $\textit{arr} = [1, 2, 3, 4]$、$k = 2$，答案 6 大于 $\textit{arr}[n-1] = 4$；两版算法都不需要特判「越界」。
5. **不要用「值域打表」当主解**：$O(V + n)$ 的桶标记在本题 $V \le 1000$ 可行，但值域一变大（如 $10^9$）立即失效，不具备迁移性。

## 5. 正确性证明

**引理 1（缺失计数的封闭形式）**：对每个下标 $i \in [0, n)$，严格小于 $\textit{arr}[i]$ 的正整数中，不在数组里的个数恰为 $\textit{missing}(i) = \textit{arr}[i] - (i + 1)$。

**证明**：小于 $\textit{arr}[i]$ 的正整数共 $\textit{arr}[i] - 1$ 个；其中属于数组的是 $\textit{arr}[0..i-1]$ 的全部 $i$ 个（严格升序保证它们都 $< \textit{arr}[i]$，且没有别的数组元素 $< \textit{arr}[i]$）。相减得 $(\textit{arr}[i] - 1) - i = \textit{arr}[i] - (i+1)$。∎

**引理 2（单调性）**：$\textit{missing}(i+1) - \textit{missing}(i) = \textit{arr}[i+1] - \textit{arr}[i] - 1 \ge 0$，故 $\textit{missing}$ 单调不减，二分查找合法。

**证明**：直接作差：$\textit{missing}(i+1) - \textit{missing}(i) = (\textit{arr}[i+1] - i - 2) - (\textit{arr}[i] - i - 1) = \textit{arr}[i+1] - \textit{arr}[i] - 1$，由严格升序（相邻差 $\ge 1$）得非负。∎

**定理**：设 $\textit{lo}$ 为第一个满足 $\textit{missing}(\textit{lo}) \ge k$ 的下标（若不存在取 $n$），则第 $k$ 个缺失的正整数是 $k + \textit{lo}$。

**证明**：记答案为 $\textit{ans}$，$m$ 为数组中小于 $\textit{ans}$ 的元素个数（显然恰为 $\textit{arr}[0..m-1]$）。小于 $\textit{ans}$ 的正整数共有 $\textit{ans} - 1$ 个，由「$\textit{ans}$ 是第 $k$ 个缺失」知其中缺失的恰 $k - 1$ 个，故 $\textit{ans} - 1 = (k-1) + m$，即 $\textit{ans} = k + m$。只需证 $m = \textit{lo}$。

对任意 $i < m$：$\textit{arr}[i] < \textit{ans}$，由引理 1，小于 $\textit{arr}[i]$ 的缺失数 $\textit{missing}(i) \le k - 1 < k$（若 $\ge k$，则第 $k$ 个缺失数 $< \textit{arr}[i] < \textit{ans}$，矛盾），故下标 $i$ 不满足条件，$\textit{lo} \ge m$。反之对 $i = m$（若 $m < n$）：数组中小于 $\textit{arr}[m]$ 的元素恰 $m$ 个，且 $\textit{arr}[m] \ge \textit{ans}$（否则 $\textit{arr}[m]$ 也应计入 $m$）。于是区间 $[1, \textit{arr}[m])$ 内包含了全部 $m$ 个「数组中的元素」和 $\textit{missing}(m)$ 个缺失数；由于 $\textit{ans} \le \textit{arr}[m]$，前 $k$ 个缺失数全部落在该区间内，即 $\textit{missing}(m) \ge k$，下标 $m$ 满足条件，$\textit{lo} \le m$。合并得 $\textit{lo} = m$（$m = n$ 时任何下标都不满足条件，$\textit{lo} = n = m$ 亦成立）。∎

## 6. 复杂度分析

- **时间**：二分版 $O(\log n)$；线性版 $O(n)$；暴力枚举版 $O(V + k)$（$V$ 为值域上界）。
- **空间**：$O(1)$。三种做法都只需常数额外空间。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int findKthPositive(vector<int>& arr, int k) {
        // missing(i) = arr[i] - (i + 1)：下标 i 之前缺失的正整数个数，单调不减
        // 二分第一个 missing(i) >= k 的下标 lo，则答案恰为 k + lo
        int lo = 0, hi = (int)arr.size();
        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            if (arr[mid] - (mid + 1) >= k) hi = mid;
            else lo = mid + 1;
        }
        return k + lo;
    }
};
```

### Python

```python
class Solution:
    def findKthPositive(self, arr: list[int], k: int) -> int:
        lo, hi = 0, len(arr)
        while lo < hi:
            mid = (lo + hi) // 2
            if arr[mid] - (mid + 1) >= k:
                hi = mid
            else:
                lo = mid + 1
        return k + lo
```

> 💡 两份代码均通过官方示例（`9`、`6`）与边界用例（`arr = [2], k = 1` → `1`；`arr = [1], k = 1` → `2`），另与 502 组随机数据（含答案落在数组内/外、$k$ 大于全部缺失数等情形）上的「模拟缺失序列」暴力对拍，`mismatch = 0`。线性版（`for x in arr: if x <= k: k += 1 else break; return k`）同样验证通过。

## 8. 边界情况与易错点

1. **答案落在数组之外**：$\textit{missing}(n-1) < k$ 时 $\textit{lo} = n$，公式 $k + n$ 直接给出正确答案；二分上界必须初始化为 $n$ 而非 $n - 1$。
2. **数组无任何缺失**：如 $[1,2,3,4]$，$\textit{missing}(i) = 0$ 对所有 $i$ 成立，$\textit{lo} = n$，答案 $k + n$，正确。
3. **$\textit{arr}[i] - (i+1)$ 的溢出**：本题值域 $\le 1000$ 无溢出；推广到大值域时 C++ 注意用足够宽的类型。
4. **二分模板细节**：条件是 $\ge k$ 而非 $> k$；写反会把「恰好缺 $k$ 个」的位置漏掉（例如 $\textit{missing}(\textit{lo}) = k$ 时答案正好处在 $\textit{arr}[\textit{lo}]$ 之前，$\textit{lo}$ 必须被选中）。
5. **线性版别忘 break**：不 break 仍正确，但数组有序性带来的提前终止是它唯一的优化点；反过来误写成「遇到 $\textit{arr}[i] \le k$ 就 break」会把后续顶位元素漏掉。
