# LeetCode 前序遍历构造二叉搜索树 题解

## 1. 题目概述

- **标题 / 题号**：前序遍历构造二叉搜索树（#1008，medium）
- **链接**：https://leetcode.cn/problems/construct-binary-search-tree-from-preorder-traversal/
- **来源**：LeetCode 第 127 场周赛 Q4
- **难度**：中等
- **标签**：栈、树、二叉搜索树、二叉树、单调栈、数组

**题意**：给定一棵**二叉搜索树**的**前序遍历**数组 `preorder`（值互不相同），还原这棵树并返回根节点。题目保证数据合法：一定存在对应的 BST。

BST 定义：对任意节点，其左子树所有值**严格小于**它，右子树所有值**严格大于**它。前序遍历顺序为「根 → 左子树 → 右子树」。

**约束**：

- $1 \le preorder.length \le 100$
- $1 \le preorder[i] \le 10^8$
- `preorder` 中的值互不相同

## 2. 示例

**示例 1**

```text
输入：preorder = [8,5,1,7,10,12]
输出：[8,5,10,1,7,null,12]
解释：根为 8；左子树 5（左孩子 1，右孩子 7）；右子树 10（右孩子 12）。
```

**示例 2**

```text
输入：preorder = [1,3]
输出：[1,null,3]
解释：1 是根，3 > 1 只能作为右孩子。
```

**示例 3**

```text
输入：preorder = [4,2,1,3,6,5,7]
输出：[4,2,6,1,3,5,7]
解释：完全平衡的 BST，前序恰好按层「根-左-右」排布。
```

## 3. 解题思路

### 3.1 暴力思路

前序的第一个元素是根。要在剩余部分找到「左子树在哪结束」，暴力做法是从左往右扫，找到第一个大于根的值作为分界点，然后递归建左右子树：

```
build(l, r):
    root = pre[l]
    找到最小的 k，使 pre[k] > root（或 k = r+1）
    left  = build(l+1, k-1)
    right = build(k, r)
```

每层都要扫描整个区间找分界点，最坏情况（树退化成一条链，例如 `[1,2,3,...,100]`）总复杂度 $O(n^2)$。$n \le 100$ 时 $10^4$ 次比较当然能过，但如果把「一遍扫描」换成「带着上界顺序消费」，可以做到 $O(n)$ 且代码更短。

### 3.2 核心观察：上界（upper bound）就是递归所需的全部信息

![前序序列中，根的左子树连续在前、右子树连续在后](images/wc127_q4_split_concept.svg)

关键结构：前序序列里，根的**后面**先是**整棵左子树**，再是**整棵右子树**。而 BST 保证左子树所有值小于根、右子树所有值大于根。于是「分界点」等价于「第一个大于根的位置」——**一旦我们知道当前子树的取值上界，就能判断下一个元素是否还属于这棵子树**。

把这一点写成递归：

```
build(bound):                       # bound = 当前子树所有节点必须 ≤ bound
    若下标越界 或 preorder[idx] > bound:   返回 null
    root = new Node(preorder[idx++])
    root.left  = build(root.val)    # 左子树的上界收紧为根值
    root.right = build(bound)       # 右子树继承祖先传下来的上界
    返回 root
```

直觉：递归进入某个子树时，它的所有节点都被「夹」在一个区间里，`bound` 就是这个区间的右端点。`preorder[idx] > bound` 说明当前元素属于**更上层的某个右子树**，因此当前子树已经结束（返回 `null`），指针不动，交给上层继续消费。

因为 `idx` 只增不减、每个节点恰好被创建一次，整个过程是 $O(n)$，且不需要任何分界点查找。

![递归调用顺序：随指针一次性消费整个前序数组](images/wc127_q4_recursion_flow.svg)

### 3.3 算法流程

```text
1. idx = 0
2. root = build(+∞)
3. 返回 root

build(bound):
    若 idx >= n 或 preorder[idx] > bound: 返回 null
    node = new TreeNode(preorder[idx]); idx++
    node.left  = build(node.val)
    node.right = build(bound)
    返回 node
```

`bound` 用 `long long` / `float('inf')` 表示正无穷，避免用 $10^8+1$ 之类的魔法数。

**另一种等价的 $O(n)$ 写法（单调栈）**：维护一个递减栈保存「还有右孩子待填的祖先」。遍历 `preorder`：若当前值小于栈顶值，它一定是栈顶的左孩子；否则不断弹栈（弹到栈顶大于当前值），最后一个弹出的节点就是当前值的父节点（作为其右孩子）。栈内始终递减，正是从根一路向左走下来的路径。

### 3.4 示例演算

![示例演算：遍历 [8,5,1,7,10,12] 的建树过程](images/wc127_q4_walkthrough.svg)

对 `preorder = [8,5,1,7,10,12]` 追踪指针 `idx` 与 `bound`：

| 步 | 调用 | `pre[idx]` | `bound` | 判定 | 动作 |
|---|---|---|---|---|---|
| 1 | build(∞) | 8 | ∞ | 8 ≤ ∞ | 建根 8，idx→1 |
| 2 | build(8) | 5 | 8 | 5 ≤ 8 | 建左孩子 5，idx→2 |
| 3 | build(5) | 1 | 5 | 1 ≤ 5 | 建左孩子 1，idx→3 |
| 4 | build(1) | 7 | 1 | 7 > 1 | null（1 无左孩子） |
| 5 | build(1) | 7 | 1 | 7 > 1 | null（1 无右孩子） |
| 6 | build(8) | 7 | 8 | 7 ≤ 8 | 建 5 的右孩子 7，idx→4 |
| 7 | build(7) | 10 | 7 | 10 > 7 | null（7 无左孩子） |
| 8 | build(8) | 10 | 8 | 10 > 8 | null（7 无右孩子，5 的右子树结束） |
| 9 | build(∞) | 10 | ∞ | 10 ≤ ∞ | 建 8 的右孩子 10，idx→5 |
| 10 | build(10) | 12 | 10 | 12 > 10 | null（10 无左孩子） |
| 11 | build(∞) | 12 | ∞ | 12 ≤ ∞ | 建 10 的右孩子 12，idx→6 |
| 12 | build(12) | — | 12 | idx 越界 | null |

得到的树：`8(5(1,∅,7), 10(∅,12))`，层序输出 `[8,5,10,1,7,null,12]` ✓。

## 4. 算法细节

1. **`idx` 必须是引用/全局状态**：C++ 用 `int& idx` 或在 `Solution` 里放成员变量；Python 用 `self.idx` 或 `nonlocal`。若按值传递，越界判断会全部失效。
2. **上界的传递方向**：左子树的上界是**当前根值**（严格小于），右子树的上界是**从祖先继承的 `bound`**。写反会导致把右子树的节点错误地收进左子树。
3. **返回 `null` 时不能移动指针**：`pre[idx] > bound` 的那个元素属于上层，必须原样留给上层消费。
4. **越界判断在前**：先判 `idx >= n` 再取 `pre[idx]`，短路顺序不能反。
5. **等值处理**：题目保证值互不相同，`>` 与 `>=` 等价；若有重复值，BST 定义要求严格不等，应保持 `>` 并用一致的规则（例如重复值放右侧）否则会失真。
6. **递归深度**：最坏（递增序列）深度为 $n \le 100$，远低于栈限制；若 $n$ 放大到 $10^5$，需改成单调栈迭代版。
7. **内存**：每个节点 `new` 一次，共 $O(n)$；`preorder` 只读一次。

## 5. 正确性证明

设 $P = preorder$，$P[a..b]$ 为某棵子树的前序段。

**引理 1（前序段划分）**：任意子树 $T$ 的前序段由「根 + 左子树前序段 + 右子树前序段」拼接而成；且左子树所有值 $<$ 根值 $<$ 右子树所有值。

**证明**：前序遍历的定义即「根 → 左 → 右」，故拼接顺序成立。BST 的定义给出左右子树的取值与根的大小关系。∎

**引理 2（上界判定的充要性）**：在 `build(bound)` 调用处，指针指向的元素 $P[idx]$ 属于当前子树，当且仅当 $idx < n$ 且 $P[idx] \le bound$。

**证明**：
（必要性）若 $P[idx]$ 属于当前子树，则它是某个后代节点的值；当前子树的所有值都 $\le bound$（因为 `bound` 是祖先给出的上界，且 BST 中子树值域被祖先区间夹住），故 $P[idx] \le bound$。
（充分性）设 $idx < n$ 且 $P[idx] \le bound$。若 $P[idx]$ 不属于当前子树，那么它必属于某个已在栈上、尚未完成的祖先的**右子树**（前序中当前位置之后的元素只可能属于：当前子树的子孙，或祖先的右子树）。而这样的祖先的右子树所有值都 $>$ 该祖先的值；同时当前子树是沿着「左链 / 右链」一路走下来的，`bound` 在每一层都是某个祖先的值或祖先继承的上界。由引理 1 逐层比较可知，属于当前子树的元素区间恰为「小于最近的左转祖先的值、且大于最近的右转祖先的值」，写成 `bound` 就是上界。故 $P[idx] \le bound$ 时它必在当前子树内。∎

**引理 3（终止与唯一性）**：`build` 每次返回时，`idx` 恰好越过当前子树的前序段；返回 `null` 时指针不动。

**证明**：对子树节点数归纳。叶子：建根后递归两次都返回 `null`，`idx` 前移 1，恰越过叶子的前序段。一般情形：左子树递归结束于其段末（归纳），右子树同理，`idx` 恰好越过两段加根。∎

**定理**：算法返回的树以前序等于 `preorder` 且是合法 BST。

**证明**：由引理 2，节点的归属判定与真实 BST 一致，因此建出的左右子树节点集合与真实 BST 相同；由引理 1，递归的左右划分顺序与前序一致；由引理 3，每个节点恰好被消费一次且指针推进顺序就是前序顺序，故构造出的树前序序列恰为 `preorder`。BST 性质由构造方式（左子树上界 = 根值、右子树继承 `bound`）逐层保证。∎

## 6. 复杂度分析

- **时间**：$O(n)$。`idx` 单调递增，每个元素被读取、比较常数次；每个节点只创建一次，递归调用总数 $O(n)$（含空调用，空调用次数也是 $O(n)$）。
- **空间**：$O(h)$ 递归栈（$h$ 为树高），最坏 $O(n)$；输出树本身 $O(n)$（不计入辅助空间）。
- 对比：朴素「每层找分界点」是 $O(n^2)$（链状树最坏）；单调栈迭代版是 $O(n)$ 时间、$O(h)$ 额外空间。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    TreeNode* bstFromPreorder(vector<int>& preorder) {
        int idx = 0;
        return build(preorder, idx, LONG_MAX);
    }

private:
    TreeNode* build(vector<int>& pre, int& idx, long long bound) {
        if (idx >= (int)pre.size() || pre[idx] > bound) return nullptr;
        TreeNode* root = new TreeNode(pre[idx++]);
        root->left = build(pre, idx, root->val);
        root->right = build(pre, idx, bound);
        return root;
    }
};
```

### Python

```python
class Solution:
    def bstFromPreorder(self, preorder: list[int]) -> TreeNode:
        self.idx = 0

        def build(bound: float) -> TreeNode:
            if self.idx >= len(preorder) or preorder[self.idx] > bound:
                return None
            root = TreeNode(preorder[self.idx])
            self.idx += 1
            root.left = build(root.val)
            root.right = build(bound)
            return root

        return build(float('inf'))
```

## 8. 边界情况与易错点

1. **`idx` 未共享**：把 `idx` 按值传参，递归内部的推进不会反映到外层，会无限重复建同一个节点或越界。
2. **上界传错**：`root.right = build(bound)` 写成 `build(root.val)` 会让右子树只允许小于根的值，整棵树退化。
3. **`null` 时移动指针**：会导致上层漏掉本应属于它的节点，最终少建节点。
4. **退化树**：`preorder = [1,2,3,...,100]` 是纯右链，递归深度 100；若 $n$ 到 $10^5$ 会爆栈，需用单调栈版。
5. **递增序列却被建成左链**：说明左右递归顺序或上界写反了，可用该用例快速自检。
6. **`LONG_MAX` 与 `int` 混用**：C++ 里 `LONG_MAX` 是 `long`，比较 `pre[idx] > bound` 会自动提升，安全；但如果把 `bound` 声明成 `int`，初值就会溢出。
7. **`nullptr` 与空指针**：C++ 用 `nullptr`（C++11），不要写 `NULL` 混用。
8. **序列化输出**：题目返回树结构，判题比较的是层序（含 `null`）；自己验证时要写层序序列化，不能只打印前序。
