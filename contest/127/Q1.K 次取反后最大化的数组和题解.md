# LeetCode K 次取反后最大化的数组和 题解

## 1. 题目概述

- **标题 / 题号**：K 次取反后最大化的数组和（#1005，easy）
- **链接**：https://leetcode.cn/problems/maximize-sum-of-array-after-k-negations/
- **来源**：LeetCode 第 127 场周赛 Q1
- **难度**：简单
- **标签**：贪心、数组、排序

**题意**：给定整数数组 `nums` 和整数 `k`，**恰好**执行 `k` 次操作：选一个下标 `i`，把 `nums[i]` 换成 `-nums[i]`（同一个下标可以反复选）。返回操作后数组可能的最大和。

**约束**：

- $1 \le nums.length \le 10^4$
- $-100 \le nums[i] \le 100$
- $1 \le k \le 10^4$

> 💡 两个关键字：**恰好 k 次**（不能用少）与**可重复选同一元素**（所以偶数次操作可以互相抵消）。

## 2. 示例

**示例 1**

```text
输入：nums = [4,2,3], k = 1
输出：5
解释：翻转 2 得到 [4,-2,3]，和为 5。所有元素非负且必须翻一次，只能选绝对值最小的。
```

**示例 2**

```text
输入：nums = [3,-1,0,2], k = 3
输出：6
解释：翻转 -1（第 1 次）得 1；剩下 2 次可以都作用在 0 上（0 取反仍是 0），数组为 [3,1,0,2]，和 6。
```

**示例 3**

```text
输入：nums = [2,-3,-1,5,-4], k = 2
输出：13
解释：翻 -4、-3 得到 [2,3,-1,5,4]，和 13。翻绝对值最大的两个负数收益最大。
```

## 3. 解题思路

### 3.1 暴力思路

每步枚举 $n$ 个下标，共 $k$ 步，复杂度 $O(n^k)$。$k$ 最大 $10^4$，完全不可行。

也可以「DP：前 $i$ 个元素用了 $j$ 次操作」——但每次操作的收益只与元素本身有关，彼此独立，没有必要上 DP。

### 3.2 核心观察：只看「被翻奇数次的集合」

![取反的净效果由被翻奇数次的元素集合决定](images/wc127_q1_greedy_concept.svg)

对同一个下标操作偶数次等于没操作。所以任何长度为 $k$ 的操作序列，其**净效果**只由一个集合 $S$ 决定：

$$S = \{\, i : \text{下标 } i \text{ 被操作了奇数次}\,\}$$

新数组的和为

$$\text{sum}' = \text{sum} - 2\sum_{i \in S} nums[i]$$

而且 $S$ 必须满足两条约束：

- $|S| \le k$（至少要翻 $|S|$ 次）；
- $|S| \equiv k \pmod 2$（剩下的次数必须两两配对抵消）。

反过来，任给满足这两条的 $S$，都可以构造出合法的 $k$ 步序列：先把 $S$ 里每个下标翻一次，剩下的 $k - |S|$ 是偶数次，全部作用在任意一个下标上即可。

于是问题转化为：**在 $|S| \le k$、$|S| \equiv k \pmod 2$ 的约束下，最小化 $\sum_{i \in S} nums[i]$**。

因此**负数一定要优先翻**（翻负数会让和增加 $2|nums[i]|$），而且负数里**绝对值越大的越先翻**。把数组升序排列后，最优的 $S$ 就是「最靠前的一段」，唯一需要小心的是**奇偶性与「负数翻完之后」这两个边界**：

- 若负数还没翻完 $k$ 就用光了：翻掉 $k$ 个最负的元素即可；
- 若负数翻完了 $k$ 还有剩余：剩下的次数若为偶数，全部浪费在某个元素上（净效果为零）；若为奇数，就不得不多翻一次，此时选**绝对值最小**的元素，代价 $2\min|nums[i]|$ 最小。

### 3.3 算法流程

![算法流程：排序 → 翻负数 → 处理剩余次数的奇偶](images/wc127_q1_flow.svg)

```text
1. 升序排序 nums
2. for i = 0 .. n-1:
       若 k > 0 且 nums[i] < 0:  nums[i] = -nums[i];  k--
3. sum = 所有元素之和
4. 若 k 为奇数:  sum -= 2 * min(nums)
5. 返回 sum
```

注意第 2 步结束后，数组里已没有负数（或 $k$ 已用尽），第 4 步的 `min` 取的是**翻转之后**的最小值——它可能是刚被翻正的那个「原来最接近 0 的负数」，也可能是原本就最小的正数。

### 3.4 示例演算

![示例演算：翻掉两个最负的数](images/wc127_q1_walkthrough.svg)

对示例 3 的 `nums = [2,-3,-1,5,-4]`、`k = 2`：

| 步 | 排序后数组 | `k` | 动作 |
|---|---|---|---|
| 初始 | [-4,-3,-1,2,5] | 2 | |
| 1 | [4,-3,-1,2,5] | 1 | 翻最负的 -4 |
| 2 | [4,3,-1,2,5] | 0 | 翻次负的 -3 |
| 结束 | [4,3,-1,2,5] | 0 | $k$ 用尽，和为 $4+3-1+2+5 = 13$ |

再看示例 2 的 `[3,-1,0,2]`、`k = 3`：排序 `[-1,0,2,3]` → 翻 `-1`（$k=2$）→ 数组 `[1,0,2,3]`，此时已无负数，$k=2$ 为偶数 → 什么都不用做，和 $6$ ✓。若把 $k$ 改成 $5$（剩余奇数次），就要再翻一次最小值 $0$，代价 $0$，和仍是 $6$。

## 4. 算法细节

1. **排序一次即可**：翻转负数后数组不再有序（`[-4,-3,-1]` 变 `[4,3,-1]`），所以求 `min` 必须重新扫一遍，不能直接用 `nums[0]`。
2. **边翻边减 `k`**：循环里只有 `nums[i] < 0 && k > 0` 才翻，天然处理了「$k$ 小于负数个数」与「$k$ 大于负数个数」两种情形。
3. **剩余次数的处理**：只需判断 `k % 2 == 1`，然后 `sum -= 2 * minVal`。$k$ 剩余多少不影响结果（偶数次全浪费）。
4. **计数排序优化**：值域只有 $[-100,100]$，可以用长度 201 的桶做到 $O(n + V)$；但 $n \le 10^4$ 时 $O(n\log n)$ 的排序已足够，且更好写。
5. **溢出**：$n \cdot |nums[i]| \le 10^4 \times 100 = 10^6$，`int` 足够；用 `long long` 也无妨。
6. **`k` 很大时的直觉**：$k = 10^4$、$n = 1$ 时，反复翻同一个元素，最终符号由 $k$ 的奇偶决定——这正是「偶数次抵消」的直接体现。

## 5. 正确性证明

记 $A$ 为原数组，$\text{sum} = \sum A_i$，$S$ 为被操作奇数次的元素集合。

**引理 1（净效果刻画）**：任意 $k$ 步操作序列的结果都等于「把 $S$ 中元素取反」，且 $\text{sum}' = \text{sum} - 2\sum_{i\in S} A_i$，其中 $|S| \le k$、$|S| \equiv k \pmod 2$。

**证明**：每个下标的最终符号只由它被操作的次数奇偶决定，故结果就是 $S$ 中元素取反。取反一个元素使总和变化 $-2A_i$，故 $\text{sum}' = \text{sum} - 2\sum_{i\in S} A_i$。操作总次数为 $k$，其中 $|S|$ 个下标各被操作奇数次（至少 1 次），其余下标被操作偶数次，所以 $|S| \le k$ 且 $k - |S|$ 为偶数。∎

**引理 2（可行性）**：任给 $|S| \le k$ 且 $|S| \equiv k \pmod 2$ 的集合 $S$，都存在 $k$ 步操作序列使其恰为「被操作奇数次的集合」。

**证明**：先把 $S$ 中每个下标操作一次（共 $|S|$ 次），剩余 $k - |S|$ 为偶数，全部作用在任意一个下标（比如下标 $0$）上，偶数次操作互不改变奇偶性，故奇数次集合仍为 $S$。∎

**引理 3（固定大小取最小前缀）**：在 $A$ 升序排列后，对任意固定大小 $t$，使 $\sum_{i\in S} A_i$ 最小的 $S$ 就是前 $t$ 个元素。

**证明**：交换论证。若最优 $S$ 中存在 $i \notin S$、$j \in S$ 且 $A_i < A_j$，把 $j$ 换成 $i$ 后和减少 $A_j - A_i > 0$，矛盾。故 $S$ 必为最小的 $t$ 个下标组成的前缀。∎

**引理 4（贪心取得最优 $t$）**：设负数个数为 $m$，前缀和 $P(t) = \sum_{i<t} A_i$ 在 $t \le m$ 时严格递减、在 $t \ge m$ 时非递减。因此可行集合 $T = \{t : 0 \le t \le \min(k,n),\ t \equiv k \pmod 2\}$ 上 $P$ 的最小值，正是算法所取的 $t^*$。

**证明**：$t \le m$ 时 $A_{t-1} < 0$，故 $P(t) - P(t-1) = A_{t-1} < 0$；$t > m$ 时 $A_{t-1} \ge 0$，故 $P$ 非递减。于是 $P$ 在 $T$ 上的最小值取在离 $m$ 最近的可行点：

- 若 $\min(k,n) \le m$：可行点中最大的是 $t = \min(k,n)$（它与 $k$ 同奇偶），且 $P$ 在 $[0, m]$ 上递减，故最优。
- 若 $\min(k,n) > m$：候选只有 $m$（若与 $k$ 同奇偶）或 $m-1, m+1$（若不同奇偶，取两者中 $P$ 更小者）。前者对应「翻完所有负数、剩余偶数次浪费」；后者正是「翻完所有负数后再翻一次绝对值最小的元素」——若该最小绝对值来自某个负数（即 $A_{m-1} < 0$ 且 $|A_{m-1}| \le A_m$），实际效果等价于不翻它（$t = m-1$），否则等价于多翻一个正数（$t = m+1$）。

而算法的第 2 步恰好把 $k$ 优先用于 $A_0, A_1, \dots$ 中为负的那些（至多 $m$ 个），第 4 步在剩余 $k$ 为奇数时减去 $2\min|A_i|$，与上面三种情形一一对应。∎

**定理**：算法返回最大可能的数组和。

**证明**：由引理 2，任何合法 $S$ 都能实现，且由引理 1 目标函数为 $\text{sum} - 2\sum_S A_i$，只需最小化 $\sum_S A_i$；由引理 3 固定大小取前缀最优，由引理 4 算法取的 $t^*$ 使前缀和最小。故算法结果等于最大可能和。∎

## 6. 复杂度分析

- **时间**：$O(n \log n)$，排序占主导；之后的翻转扫描与求最小值都是 $O(n)$。
- **空间**：$O(\log n)$（排序栈）或 $O(1)$（不计输入）；若用计数排序则额外 $O(V) = O(201)$。
- 对比：暴力 $O(n^k)$；DP 需要 $O(nk)$ 且并不更简单。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int largestSumAfterKNegations(vector<int>& nums, int k) {
        sort(nums.begin(), nums.end());
        for (int i = 0; i < (int)nums.size() && k > 0; i++) {
            if (nums[i] < 0) {
                nums[i] = -nums[i];
                k--;
            }
        }
        int sum = 0;
        for (int v : nums) sum += v;
        if (k % 2 == 1) {
            int mn = *min_element(nums.begin(), nums.end());
            sum -= 2 * mn;
        }
        return sum;
    }
};
```

### Python

```python
class Solution:
    def largestSumAfterKNegations(self, nums: list[int], k: int) -> int:
        nums.sort()
        for i, v in enumerate(nums):
            if k > 0 and v < 0:
                nums[i] = -v
                k -= 1
        total = sum(nums)
        if k % 2 == 1:
            total -= 2 * min(nums)
        return total
```

## 8. 边界情况与易错点

1. **`k` 大于负数个数**：剩余的偶数次必须「浪费掉」，否则会多翻一次导致答案偏小。示例 2 里 $k=3$、仅一个负数，剩余 2 次正好抵消。
2. **`k` 剩余为奇数时取错最小值**：必须取**翻转之后**的最小值。例如 `nums = [-5, 1]`、$k = 2$：翻 `-5` 后数组 `[5,1]`，剩余 1 次应翻 `1`（和 $6-2=4$），而不是翻 `5`（和 $-4$）。
3. **排序后数组不再有序**：翻转负数破坏了有序性，`min` 必须重新扫，不能直接用 `nums[0]`。
4. **`k` 为奇数但数组里有 0**：翻 0 不花钱，答案不受影响——`min = 0` 时代价自然为 0。
5. **全是正数且 `k` 为偶数**：直接返回原和（所有操作两两抵消）。
6. **全是负数且 `k` 小于负数个数**：只翻最负的 `k` 个（绝对值最大的），不是翻最后 `k` 个。
7. **`k` 极大**：$k = 10^4$、$n = 1$ 时也只需一次排序 + 一次奇偶判断，不能真的循环 $k$ 次去操作（虽然本题 $10^4$ 次循环也能过，但思路要清楚）。
8. **数组长度为 1**：`min_element` 取到唯一元素，逻辑不变。
