# LeetCode 最长重复子串 题解

## 1. 题目概述

- **标题 / 题号**：最长重复子串（#1044，hard）
- **链接**：https://leetcode.cn/problems/longest-duplicate-substring/
- **来源**：LeetCode 第 136 场周赛 Q4
- **难度**：困难
- **标签**：字符串、二分查找、后缀数组、滑动窗口、哈希函数、滚动哈希

**题意**：给定字符串 `s`，考虑它的所有**重复子串**（在 `s` 中出现至少 2 次的连续子串，两次出现**可以重叠**）。返回**任意一个**长度最长的重复子串；若不存在重复子串，返回空串 `""`。

**约束**：

- $2 \le \lvert s \rvert \le 3 \times 10^4$
- `s` 仅由小写英文字母组成

## 2. 示例

**示例 1**

```text
输入：s = "banana"
输出："ana"
解释："ana" 出现在下标 1 和 3（两次出现重叠），长度 3；
      长度 4 及以上的子串都不重复，故答案为 "ana"。
```

**示例 2**

```text
输入：s = "abcd"
输出：""
解释：所有子串都只出现一次，没有重复子串。
```

## 3. 解题思路

### 3.1 暴力思路

枚举起点对 $(i,j)$ 与长度，逐字符比较：$O(n^3)$；用后缀自动机/后缀数组可以做到 $O(n)$，但代码量大。$n = 3\times10^4$ 时 $O(n^3)$ 完全不可行，$O(n^2)$ 的「枚举长度 + 哈希」也要 $10^9$ 次操作，同样过不去。

### 3.2 核心观察：长度具有单调性 → 二分

![二分长度 + 哈希判重](images/wc136_q4_binary_search_hash.svg)

**单调性**：若存在长度 $L$ 的重复子串，取它任意一个长度为 $L' < L$ 的前缀（或子串），这个前缀也会出现至少两次——因为原串的两次出现都各自包含它。所以

$$L \text{ 可行} \implies \text{所有 } L' < L \text{ 都可行}$$

这是一个典型的**二分答案**结构：在 $[1, n-1]$ 上二分长度，每次判定「是否存在长度为 $L$ 的重复子串」。

判定方式：把每个长度为 $L$ 的子串用**滚动哈希**映射成整数，放进哈希表；一旦某个哈希值第二次出现，就（在逐字符确认后）报告找到了。

### 3.3 判定与哈希细节

![滚动哈希：前缀哈希与区间公式](images/wc136_q4_rolling_hash.svg)

**前缀哈希**：取底数 $B$、模数 $M$，定义

$$h[k] = \Bigl(\sum_{i=0}^{k-1} s[i] \cdot B^{k-1-i}\Bigr) \bmod M$$

则子串 $s[l..r)$ 的哈希为

$$\text{hash}(l, r) = \bigl(h[r] - h[l] \cdot B^{r-l}\bigr) \bmod M$$

一次乘法、一次减法即可，$O(1)$。为了避免碰撞，用两套 $(B_i, M_i)$（如 $B_1 = 131, M_1 = 10^9+7$；$B_2 = 137, M_2 = 10^9+9$），把两个哈希拼成一个 64 位键：

$$\text{key} = h_1 \cdot M_2 + h_2$$

哈希表记录「键 → 首次出现的起点」。命中已有键时，**再逐字符比较**两个子串（`s.compare` / 切片比较），确认相等才返回——这样**假阳性被彻底排除**，正确性不再依赖「哈希无碰撞」的概率假设。

### 3.4 示例演算

对 `s = "banana"`（$n = 6$）：

| 二分长度 $L$ | 是否存在重复 | 判定说明 |
|--------------|--------------|----------|
| 3（mid） | 是 | "ana" 出现在下标 1 与 3 |
| 5 | 否 | 只有 "banan"、"anana" 两个候选，互不相同 |
| 4 | 否 | "bana"、"anan"、"nana" 互不相同 |

二分结束得到 $L = 3$，返回记录的起点（下标 1）对应的子串 `"ana"`。

## 4. 算法细节

1. **二分范围**：$lo = 1$，$hi = n-1$（长度 $n$ 的子串不可能重复）。用一个变量记录「最后一个可行的长度」及其起点，二分结束后用它切出答案。
2. **字符映射**：$s[i]$ 的 ASCII 值直接参与哈希即可；若担心值域太小导致哈希退化，可映射成 $s[i] - 'a' + 1$（避免 0 值，减少前导零歧义）。
3. **取模与负数**：C++ 中 `(h[r] - h[l] * p[len] % M + M) % M` 要加 $M$ 再取模，否则负数取模仍为负；Python 的 `%` 天然返回非负，可直接写。
4. **双哈希的必要性**：单模数在 $n = 3\times10^4$ 时有约 $10^{9}$ 量级的哈希桶，碰撞概率虽低但存在被构造数据针对的风险；双哈希把概率压到可忽略，且逐字符确认保证了**最终正确性**。
5. **哈希表选型**：C++ 用 `unordered_map<long long,int>` 并 `reserve(n*2)` 减少 rehash；Python 用 `dict`。
6. **不要在判定里构造子串**：每次判定的复杂度必须是 $O(n)$，若在循环里切片（Python 的 `s[i:i+L]`）会退化成 $O(nL)$。切片只用在「确认相等」那一步（最多命中常数次）。

## 5. 正确性证明

**引理 1（单调性）**：若存在长度为 $L$ 的重复子串，则对任意 $1 \le L' < L$，也存在长度为 $L'$ 的重复子串。

**证明**：设 $s[a..a+L) = s[b..b+L)$ 且 $a \ne b$。取前缀 $s[a..a+L')$ 与 $s[b..b+L')$，由相等子串的前缀仍相等，二者相同；且起点 $a \ne b$，故长度为 $L'$ 的子串重复。∎

**引理 2（判定正确）**：`check(L)` 返回 true $\iff$ 存在两个不同起点 $i < j$ 使 $s[i..i+L) = s[j..j+L)$。

**证明**：

- ($\Leftarrow$) 两个相等的子串哈希值必然相同（哈希是确定性函数），故遍历到 $j$ 时会在表中命中起点 $i$，逐字符比较也相等，返回 true。
- ($\Rightarrow$) `check(L)` 只有在逐字符比较相等时才返回 true，此时确实存在两个相同子串。∎

（注意：哈希碰撞只会造成「假阳性」，而假阳性被逐字符比较拦下；哈希值相同是相等的必要条件，所以不会漏掉真重复——除非两个相等子串的哈希不同，但那不可能，因为哈希函数确定性。）

**引理 3（二分不变量）**：二分过程中始终有「长度 $\le lo-1$ 均可行」与「长度 $\ge hi+1$ 均不可行」，且 `bestLen` 记录的是已验证可行的最大长度。

**证明**：初始 $lo=1$、$hi=n-1$ 时两个区间为空，成立。每次取 $mid$：若 `check(mid)` 为真，由引理 1 所有 $< mid$ 的长度可行，令 $lo = mid+1$ 并更新 `bestLen = mid`，不变量保持；若为假，由引理 1 的逆否命题所有 $> mid$ 的长度不可行，令 $hi = mid-1$，不变量保持。∎

**定理**：算法返回的子串是长度最长的重复子串（之一）。

**证明**：由引理 2，`check` 的判定是精确的；由引理 3，二分终止时 `bestLen` 是所有可行长度中的最大值，且 `bestStart` 是某次 `check(bestLen)` 确认过的起点，故 $s[\text{bestStart}..\text{bestStart}+\text{bestLen})$ 是重复子串，长度达到最大值。若不存在任何重复子串，二分返回 `bestLen = 0`，输出空串，符合题意。∎

## 6. 复杂度分析

- **时间**：$O(n \log n)$。预处理前缀哈希 $O(n)$；二分 $O(\log n)$ 轮，每轮 `check` 遍历 $O(n)$ 个子串、每个 $O(1)$ 哈希 + 一次哈希表操作，命中时额外 $O(L)$ 逐字符确认（命中即返回，最多发生常数次，最坏 $O(n)$ 但只出现在返回前）；总 $O(n \log n)$。
- **空间**：$O(n)$。前缀哈希与幂表各两套（$4n$ 个整数），哈希表最坏存 $n$ 个键。

## 7. 参考代码

### C++

```cpp
#include <string>
#include <vector>
#include <unordered_map>
using namespace std;

class Solution {
public:
    string longestDupSubstring(string s) {
        int n = s.size();
        const long long M1 = 1000000007LL, M2 = 1000000009LL, B1 = 131, B2 = 137;
        vector<long long> h1(n + 1, 0), h2(n + 1, 0), p1(n + 1, 1), p2(n + 1, 1);
        for (int i = 0; i < n; i++) {
            long long v = (unsigned char)s[i];
            h1[i + 1] = (h1[i] * B1 + v) % M1;
            h2[i + 1] = (h2[i] * B2 + v) % M2;
            p1[i + 1] = p1[i] * B1 % M1;
            p2[i + 1] = p2[i] * B2 % M2;
        }

        // 返回长度为 L 的重复子串起点，不存在返回 -1
        auto findDup = [&](int L) -> int {
            unordered_map<long long, int> seen;
            seen.reserve((size_t)n * 2);
            for (int i = 0; i + L <= n; i++) {
                long long a = (h1[i + L] - h1[i] * p1[L] % M1 + M1) % M1;
                long long b = (h2[i + L] - h2[i] * p2[L] % M2 + M2) % M2;
                long long key = a * M2 + b;
                auto it = seen.find(key);
                if (it == seen.end()) {
                    seen[key] = i;
                } else if (s.compare(i, L, s, it->second, L) == 0) {
                    return i;              // 双哈希命中后再逐字符确认
                }
            }
            return -1;
        };

        int lo = 1, hi = n - 1, bestLen = 0, bestStart = 0;
        while (lo <= hi) {
            int mid = (lo + hi) / 2;
            int pos = findDup(mid);
            if (pos >= 0) { bestLen = mid; bestStart = pos; lo = mid + 1; }
            else hi = mid - 1;
        }
        return bestLen ? s.substr(bestStart, bestLen) : string("");
    }
};
```

### Python

```python
class Solution:
    def longestDupSubstring(self, s: str) -> str:
        n = len(s)
        M1, M2, B1, B2 = 1000000007, 1000000009, 131, 137
        h1, h2 = [0] * (n + 1), [0] * (n + 1)
        p1, p2 = [1] * (n + 1), [1] * (n + 1)
        for i, ch in enumerate(s):
            v = ord(ch)
            h1[i + 1] = (h1[i] * B1 + v) % M1
            h2[i + 1] = (h2[i] * B2 + v) % M2
            p1[i + 1] = p1[i] * B1 % M1
            p2[i + 1] = p2[i] * B2 % M2

        def find_dup(length: int) -> int:
            seen = {}
            for i in range(n - length + 1):
                a = (h1[i + length] - h1[i] * p1[length]) % M1
                b = (h2[i + length] - h2[i] * p2[length]) % M2
                key = a * M2 + b
                j = seen.get(key)
                if j is None:
                    seen[key] = i
                elif s[i:i + length] == s[j:j + length]:
                    return i                 # 双哈希命中后再逐字符确认，杜绝哈希碰撞误判
            return -1

        lo, hi, best_len, best_start = 1, n - 1, 0, 0
        while lo <= hi:
            mid = (lo + hi) // 2
            pos = find_dup(mid)
            if pos >= 0:
                best_len, best_start = mid, pos
                lo = mid + 1
            else:
                hi = mid - 1
        return s[best_start:best_start + best_len]
```

## 8. 边界情况与易错点

1. **无重复子串**：`"abcd"` → 返回 `""`。注意 `bestLen` 初值为 0，最后要判空，不能用 `s.substr(0, 0)` 之外的写法踩越界。
2. **完全重复的字符串**：`"aaaa...a"`（$3\times10^4$ 个 a）→ 答案为去掉一个字符的全串，长度 $n-1$；二分上界取 $n-1$ 而不是 $n$。
3. **二分边界**：`lo = 1`（长度 1 也可能重复，如 `"aa"`），`hi = n-1`；若写成 `hi = n` 会白跑一轮且 `substr` 越界。
4. **溢出**：`h1[i] * p1[L]` 最大约 $10^9 \times 10^9 = 10^{18}$，正好在 `long long` 范围内（$9.2\times10^{18}$），但**不能用 `int`**；`key = a * M2 + b` 同样在 `long long` 范围内。
5. **Python 的负数取模**：`(h1[i+L] - h1[i]*p1[L]) % M1` 直接得到非负值，无需 `+M1`；C++ 则必须补 `+M1`。
6. **哈希表键冲突的假阳性**：只要命中后逐字符确认，就不会误报；若为了性能省掉确认，就必须接受「极小概率 WA」。
7. **不要在 `find_dup` 里切子串**：Python 的 `s[i:i+length]` 是 $O(L)$，放进循环会让复杂度退化成 $O(nL\log n)$；只有在确认那一步才切片。
