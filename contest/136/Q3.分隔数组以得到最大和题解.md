# LeetCode 分隔数组以得到最大和 题解

## 1. 题目概述

- **标题 / 题号**：分隔数组以得到最大和（#1043，medium）
- **链接**：https://leetcode.cn/problems/partition-array-for-maximum-sum/
- **来源**：LeetCode 第 136 场周赛 Q3
- **难度**：中等
- **标签**：数组、动态规划

**题意**：把数组 `arr` 分成若干个**连续**子数组，每个子数组长度**至多**为 $k$。分隔完成后，每个子数组内的所有元素都变成**该子数组的最大值**。求变换后数组元素之和的**最大**值。

**约束**：

- $1 \le \text{arr.length} \le 500$
- $0 \le \text{arr}[i] \le 10^9$
- $1 \le k \le \text{arr.length}$
- 题目保证答案在 32 位整数范围内

## 2. 示例

**示例 1**

```text
输入：arr = [1,15,7,9,2,5,10], k = 3
输出：84
解释：分成 [1,15,7]、[9]、[2,5,10]，变换为 [15,15,15]、[9]、[10,10,10]，
      和 = 45 + 9 + 30 = 84。
```

**示例 2**

```text
输入：arr = [1,4,1,5,7,3,6,1,9,9,3], k = 4
输出：83
```

**示例 3**

```text
输入：arr = [1], k = 1
输出：1
解释：只有一个元素，分段后仍为 1。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有「把 $n$ 个元素切成若干段、每段长度 $\le k$」的方案：切法数随 $n$ 指数增长（$k=2$ 时就是斐波那契级别，$n=500$ 时天文数字）。不可行。

### 3.2 核心观察：最后一段的枚举

![线性 DP：枚举最后一段长度](images/wc136_q3_partition_dp.svg)

定义 $dp[i]$ 为**前 $i$ 个元素**能得到的最大和（$dp[0] = 0$）。考虑最优划分的**最后一段**：它覆盖下标区间 $[i-j, i-1]$，长度 $j \in [1, \min(k, i)]$。这一段对答案的贡献是

$$\max\bigl(\text{arr}[i-j..i-1]\bigr) \times j$$

而它前面的部分 $[0, i-j-1]$ 是一个独立的子问题，最优值正是 $dp[i-j]$。于是

$$dp[i] = \max_{1 \le j \le \min(k,\,i)} \Bigl( dp[i-j] + \max\bigl(\text{arr}[i-j..i-1]\bigr) \cdot j \Bigr)$$

答案 $dp[n]$。

实现上还有个 **$O(1)$ 维护技巧**：对固定的 $i$，让 $j$ 从 1 增到 $k$，区间 $[i-j, i-1]$ 每次只向左扩展一格，故段内最大值 `mx` 可以在枚举过程中增量更新，不必每层重新扫一遍。

### 3.3 算法流程

```text
1. dp[0..n] 全 0
2. for i = 1 .. n:
       mx = 0
       for j = 1 .. k 且 i-j >= 0:
           mx = max(mx, arr[i-j])            # 增量更新段内最大值
           dp[i] = max(dp[i], dp[i-j] + mx*j)
3. 返回 dp[n]
```

### 3.4 示例演算

![示例 1 的 DP 表](images/wc136_q3_example_walkthrough.svg)

对 `arr = [1,15,7,9,2,5,10]`、$k = 3$，逐项计算（只列关键项）：

| $i$ | 转移来源（$j$，段内最大值） | $dp[i]$ |
|-----|------------------------------|---------|
| 1 | $j=1$：$dp[0] + 1\cdot1$ | 1 |
| 2 | $j=2$：$dp[0] + 15\cdot2$ | 30 |
| 3 | $j=3$：$dp[0] + 15\cdot3$ | 45 |
| 4 | $j=1$：$dp[3] + 9$ | 54 |
| 5 | $j=2$：$dp[3] + \max(9,2)\cdot2 = 45+18$ | 63 |
| 6 | $j=3$：$dp[3] + \max(9,2,5)\cdot3 = 45+27$ | 72 |
| 7 | $j=3$：$dp[4] + \max(2,5,10)\cdot3 = 54+30$ | **84** |

最优划分即 `[1,15,7] [9] [2,5,10]`，与示例解释完全一致。

## 4. 算法细节

1. **状态语义**：$dp[i]$ 指前 $i$ 个元素（下标 $[0, i-1]$），不是「第 $i$ 个元素」；用 $dp[0]=0$ 作为哨兵。
2. **枚举方向**：内层 $j$ 从小到大时，`arr[i-j]` 依次是 $i-1, i-2, \dots$，区间向左扩张，`mx` 直接 `max` 即可增量维护。
3. **`j` 的上界**：$j \le k$ 且 $j \le i$（不能越出前缀）。
4. **数值范围（务必用 64 位）**：单个元素可达 $10^9$，段长可达 500，单段贡献 $mx \cdot j$ 可达 $5\times10^{11}$，**中间量一定会超出 32 位**。题目只保证最终答案在 32 位内，但非最优候选值的乘积同样会先溢出、把 `max` 的比较结果带偏（有符号溢出在 C++ 中是未定义行为）。因此代码里 `mx` 与 `dp` 都用 `long long`，最后再转回 `int`（Python 无此问题）。
5. **空间**：只需一维 $dp$；不需要记录分段方案。

## 5. 正确性证明

**引理 1（最优子结构）**：设最优划分的最后一段为 $[i-j, i-1]$，则它前面的部分 $[0, i-j-1]$ 的划分必定是前缀 $i-j$ 的最优划分。

**证明**：反证。若前缀 $i-j$ 存在和更大的划分，把它与「最后一段」拼起来，仍是一个合法划分（段长约束不变、覆盖完整），而总和更大，与最优性矛盾。∎

**引理 2（最后一段的贡献只依赖段内最大值）**：对任意一段 $[l, r]$，变换后该段所有元素都变成 $\max(arr[l..r])$，贡献为 $\max(arr[l..r]) \cdot (r-l+1)$。

**证明**：由题意，段内每个元素都被替换为该段的最大值，共 $(r-l+1)$ 个元素，故总和如上。∎

**引理 3（转移覆盖所有方案）**：对每个 $i$ 与每个合法 $j$，$dp[i-j] + \max(arr[i-j..i-1]) \cdot j$ 对应至少一个合法的前 $i$ 个元素划分；且每个合法划分都被某个 $j$ 覆盖。

**证明**：给定 $j$，把前缀 $i-j$ 的最优划分与最后一段 $[i-j, i-1]$ 拼接，得到前 $i$ 个元素的合法划分（每段长度 $\le k$），其得分即该表达式，故候选值可实现。反之，任一合法划分的最后一段长度 $j \le \min(k,i)$ 唯一确定，其得分 = 「前缀划分得分 + 该段贡献」$\le dp[i-j] + \max(\cdot)\cdot j$，被该 $j$ 的候选值覆盖。∎

**定理**：算法返回 $dp[n]$，等于变换后数组元素和的最大值。

**证明**：对 $i$ 归纳。$i = 0$ 时 $dp[0]=0$ 正确。设 $i' < i$ 均正确。由引理 3，$dp[i]$ 的候选集恰好覆盖所有合法划分的得分上界，且每个候选可实现；由引理 1，最优划分的前缀部分必取 $dp[i-j]$（归纳假设已求出），故取最大值即得最优。最终 $dp[n]$ 为答案。∎

## 6. 复杂度分析

- **时间**：$O(nk)$。外层 $n$ 次，内层至多 $k$ 次，每次常数操作（含一次 `max` 更新与一次乘加）。$n \le 500$、$k \le 500$，最多 $2.5\times10^5$ 次转移。
- **空间**：$O(n)$ 的 $dp$ 数组。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int maxSumAfterPartitioning(vector<int>& arr, int k) {
        int n = arr.size();
        vector<long long> dp(n + 1, 0);        // dp[i]：前 i 个元素的最大和
        for (int i = 1; i <= n; i++) {
            long long mx = 0;
            for (int j = 1; j <= k && i - j >= 0; j++) {   // 枚举最后一段的长度 j
                mx = max(mx, (long long)arr[i - j]);
                dp[i] = max(dp[i], dp[i - j] + mx * j);
            }
        }
        return (int)dp[n];
    }
};
```

### Python

```python
class Solution:
    def maxSumAfterPartitioning(self, arr: list[int], k: int) -> int:
        n = len(arr)
        dp = [0] * (n + 1)          # dp[i]：前 i 个元素的最大和
        for i in range(1, n + 1):
            mx = 0
            for j in range(1, k + 1):        # 最后一段长度 j
                if i - j < 0:
                    break
                mx = max(mx, arr[i - j])
                dp[i] = max(dp[i], dp[i - j] + mx * j)
        return dp[n]
```

## 8. 边界情况与易错点

1. **中间量溢出**：`mx * j` 中 $mx$ 可达 $10^9$、$j$ 可达 500，乘积 $5\times10^{11}$ 超出 `int`。虽然题目保证**答案**在 32 位内，但用 `int` 计算乘积会先溢出再参与比较，结果可能错误。稳妥写法是用 `long long` 做中间计算（本题示例就能暴露：`arr=[10^9]`、$k=1$ 时值本身就在边界）。
2. **`j` 上界**：必须同时满足 $j \le k$ 和 $j \le i$，漏掉后者会读到 $dp$ 的负下标。
3. **`mx` 的增量方向**：内层 $j$ 递增时，加入区间的是 `arr[i-j]`（即更靠左的元素），不要写成 `arr[j-1]`。
4. **$k \ge n$ 的退化**：此时可以整段成一块，答案就是 $\max(arr)\cdot n$；DP 自然给出这个结果（$j=n$ 的候选值）。
5. **含 0 元素**：$arr[i]=0$ 不影响正确性，但要注意 `mx` 初值取 0 是安全的（本题元素非负）；若允许负数，初值应取负无穷。
6. **$n=1$**：返回 $arr[0]$，示例 3 即此情形。
