# LeetCode 不邻接植花 题解

## 1. 题目概述

- **标题 / 题号**：不邻接植花（#1042，medium）
- **链接**：https://leetcode.cn/problems/flower-planting-with-no-adjacent/
- **来源**：LeetCode 第 136 场周赛 Q2
- **难度**：中等
- **标签**：深度优先搜索、广度优先搜索、图、图的着色

**题意**：有 $n$ 个花园（编号 $1 \sim n$），`paths` 描述花园之间的双向路径，且**每个花园最多有 3 条路径**。给每个花园种四种花之一（用 $1,2,3,4$ 表示），要求任意两个有路径相连的花园种**不同**的花。返回**任意一个**可行方案，保证存在答案。

**约束**：

- $1 \le n \le 10^4$
- $0 \le \text{paths.length} \le 2 \times 10^4$
- $\text{paths}[i].\text{length} = 2$，$1 \le x_i, y_i \le n$，$x_i \ne y_i$
- 每个花园最多有 3 条路径进出

## 2. 示例

**示例 1**

```text
输入：n = 3, paths = [[1,2],[2,3],[3,1]]
输出：[1,2,3]
解释：三角形，三个花园两两相邻，必须三色；
      [1,2,4]、[1,4,2]、[3,2,1] 等也都合法。
```

**示例 2**

```text
输入：n = 4, paths = [[1,2],[3,4]]
输出：[1,2,1,2]
解释：两条互不相连的边；1 号与 3 号没有路径，可以同色。
```

**示例 3**

```text
输入：n = 4, paths = [[1,2],[2,3],[3,4],[4,1],[1,3],[2,4]]
输出：[1,2,3,4]
解释：4 个花园两两相邻（完全图 K4），必须用满 4 种颜色。
```

## 3. 解题思路

### 3.1 暴力思路

回溯搜索所有着色方案：最坏 $4^n$，不可行。也可以用「逐个试色 + 冲突回溯」，但**度数 ≤ 3** 这一条件已经保证贪心不会失败，回溯完全没必要。

### 3.2 核心观察：度数 ≤ 3 ⇒ 4 色贪心永不失败

![每点度 ≤ 3，4 色必有一种可用](images/wc136_q2_greedy_colors.svg)

按编号 $1 \sim n$ 顺序给花园染色。染第 $i$ 个花园时，只有**已经染色的邻居**会限制选择：

- 它最多有 3 个邻居（度数 ≤ 3），因此最多**被用掉 3 种颜色**；
- 而总共有 **4 种颜色**可用，
- 于是 $4 - 3 = 1$ 种颜色必定可用（若邻居更少，可用颜色更多）。

所以每个花园都能找到一个合法颜色，**一次顺序扫描即可**，不需要回溯、不需要图着色算法（如 DSATUR），也不需要连通性分析。

### 3.3 算法流程

```text
1. 建邻接表 adj[1..n]
2. color[1..n] = 0（未染色）
3. for i = 1 .. n:
       used = ∅
       for v in adj[i]:
           若 color[v] != 0: used.add(color[v])
       for c in 1..4:
           若 c ∉ used: color[i] = c; break
4. 返回 color[1..n]
```

### 3.4 示例演算

![示例 3 的着色过程](images/wc136_q2_example_coloring.svg)

示例 3 是完全图 $K_4$（6 条边，每点度 3）。顺序染色：

| 花园 | 已染色的邻居 | 已用颜色 | 选色 |
|------|--------------|----------|------|
| 1 | 无 | ∅ | 1 |
| 2 | {1} | {1} | 2 |
| 3 | {1, 2}（4 号还没染） | {1, 2} | 3 |
| 4 | {1, 2, 3} | {1, 2, 3} | 4 |

得到 `[1,2,3,4]`，与示例输出一致。示例 1（三角形）得 `[1,2,3]`，示例 2（两条独立边）得 `[1,2,1,2]`。

## 4. 算法细节

1. **只看向已染色的邻居**：`used` 集合只收集 `color[v] != 0` 的邻居颜色，未染色的邻居之后自然会避开当前颜色（对称性）。
2. **颜色编号从 1 开始**：结果数组用 0 表示「未染色」，这样「是否已染色」与颜色值不会混淆。
3. **度数条件的用途**：它只用来保证「可用颜色一定存在」，代码里并不需要检查度数；即使某点度数 > 3，代码也会得到 0 个可用颜色（此时应报错或回溯），本题保证不会发生。
4. **多解性**：题目接受任意合法方案，故不需要字典序最小或颜色数最少。
5. **边的重复**：若 `paths` 中出现重复边（数据一般不重复），邻接表里会有重复项，`used` 集合自动去重，结果仍然正确。

## 5. 正确性证明

**引理 1（每步都有可用颜色）**：设算法按 $1..n$ 顺序染色，给第 $i$ 个花园选择颜色时，集合 $\{1,2,3,4\} \setminus \text{used}$ 非空。

**证明**：$\lvert \text{used} \rvert$ 不超过 $i$ 的邻居个数，而每个花园最多有 3 条路径，故邻居数 $\le 3$，于是 $\lvert \text{used} \rvert \le 3$。$4 - \lvert \text{used} \rvert \ge 1$，即至少一种颜色未被使用。∎

**引理 2（每条边两端异色）**：算法结束时，对任意路径 $(u, v)$，`color[u] != color[v]`。

**证明**：不妨设 $u$ 先于 $v$ 被染色（编号小者先）。给 $u$ 染色时 $v$ 尚未着色，故 $u$ 的选择不受 $v$ 约束；而给 $v$ 染色时 $u$ 已着色，$u$ 的颜色被放入 `used`，因此 $v$ 的选色一定避开 `color[u]`。故两者不同。∎

**定理**：算法输出的长度为 $n$ 的数组是一个合法着色方案。

**证明**：由引理 1，每个花园都成功赋了 $1 \sim 4$ 中的某个值；由引理 2，每条路径两端颜色不同。故方案合法。∎

## 6. 复杂度分析

- **时间**：$O(n + \lvert \text{paths} \rvert)$。建图 $O(n + m)$；每个花园遍历其邻接表（总和 $2m$）并对至多 4 种颜色做常数检查。
- **空间**：$O(n + m)$。邻接表存 $2m$ 个端点，颜色数组 $n$，`used` 集合至多 4 个元素。

## 7. 参考代码

### C++

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> gardenNoAdj(int n, vector<vector<int>>& paths) {
        vector<vector<int>> adj(n);
        for (auto& p : paths) {
            adj[p[0] - 1].push_back(p[1] - 1);
            adj[p[1] - 1].push_back(p[0] - 1);
        }
        vector<int> color(n, 0);
        for (int i = 0; i < n; i++) {
            bool used[5] = {false, false, false, false, false};
            for (int v : adj[i]) {
                if (color[v]) used[color[v]] = true;
            }
            for (int c = 1; c <= 4; c++) {
                if (!used[c]) { color[i] = c; break; }
            }
        }
        return color;
    }
};
```

### Python

```python
class Solution:
    def gardenNoAdj(self, n: int, paths: list[list[int]]) -> list[int]:
        adj = [[] for _ in range(n)]
        for u, v in paths:
            adj[u - 1].append(v - 1)
            adj[v - 1].append(u - 1)
        color = [0] * n
        for i in range(n):
            used = set()
            for v in adj[i]:
                if color[v]:
                    used.add(color[v])
            for c in (1, 2, 3, 4):
                if c not in used:
                    color[i] = c
                    break
        return color
```

## 8. 边界情况与易错点

1. **度数条件被忽略**：如果误以为需要「四色定理」或复杂算法，会写出不必要的回溯；本题的关键恰恰是「度数 ≤ 3 保证贪心可行」。
2. **下标基准**：花园编号从 1 开始，数组下标从 0 开始，建图与返回时各转换一次，容易少减或多减 1。
3. **孤点**：$n$ 个花园里没有任何路径的孤立花园，`used` 为空 → 染色为 1，合法。
4. **`n = 1` 且 `paths = []`**：返回 `[1]`。
5. **重复边 / 自环**：题目保证 $x_i \ne y_i$；若出现重复边，`used` 去重后结果不变。
6. **不要修改输入**：有的写法会往 `paths` 里追加反向边，导致评测数据被污染（按值传入时无碍，但养成不改输入的习惯更好）。
