# LeetCode 让字符串成为回文串的最少插入次数 题解

## 1. 题目概述

- **标题 / 题号**：让字符串成为回文串的最少插入次数（#1312，hard）
- **链接**：https://leetcode.cn/problems/minimum-insertion-steps-to-make-a-string-palindrome/
- **来源**：LeetCode 第 170 场周赛 Q4
- **难度**：困难
- **标签**：字符串，动态规划

**题意**：给定字符串 $s$，每次操作可以在**任意位置**插入**任意字符**，求让 $s$ 变成回文串的最少操作次数。注意只能插入，不能删除、不能改动原有字符的相对顺序；插入的字符可以是任意小写字母。

**约束**：

- $1 \le \lvert s \rvert \le 500$
- $s$ 中所有字符都是小写英文字母

## 2. 示例

**示例 1**

```text
输入：s = "zzazz"
输出：0
解释：字符串 "zzazz" 本身就是回文串，不需要插入任何字符。
```

**示例 2**

```text
输入：s = "mbadm"
输出：2
解释：可以变成 "mbdadbm" 或 "mdbabdm"，两种方案都插入 2 个字符。
```

**示例 3**

```text
输入：s = "leetcode"
输出：5
解释：插入 5 个字符后得到 "leetcodocteel"，共 13 个字符。
```

## 3. 解题思路

### 3.1 暴力思路

**枚举插入方案**：每一步都有「插在哪个空位（$L+1$ 种）× 插入什么字符（26 种）」的选择，深度最多 $n-1$，状态数随长度指数爆炸，$n = 500$ 完全不可行。

**贪心也不对**：常见的错误写法是双指针扫描，两端字符不同就插入一个（或两边各插一个）然后收缩。以 `s = "aab"` 为例，两端 `a` 与 `b` 不同，贪心吃掉一端后剩 `"ab"`，还得分一次，共 2 次；但最优只要 1 次——在开头插入一个 `b` 得到 `"baab"`。原因是「哪一端该被吃掉」在贪心视角下没有任何信息可依据。

真正的突破口是：与其枚举插入，不如先决定**哪些原始字符可以原封不动地待在一对对称位置上**。

### 3.2 核心观察：答案 = n − 最长回文子序列长度

![答案 = n 减去最长回文子序列长度](images/wc170_q4_lps_reduction.svg)

设最终回文串为 $t$，长度 $L = n + k$（$k$ 是插入次数）。$s$ 的 $n$ 个字符按原顺序出现在 $t$ 中，$t$ 中其余 $k$ 个位置是插入字符。回文串的性质是**位置关于中心的镜像字符相同**，即 $t[p] = t[L-1-p]$。

现在只看 $s$ 的那 $n$ 个字符，并按下面的方式分类：

- **自带镜像**：它的镜像位置上也放着 $s$ 的字符（两个原始字符互为镜像）；
- **不自带镜像**：它的镜像位置上是一个插入字符。

不同的「不自带镜像」位置，其镜像位置互不相同，且必然被插入字符占据，所以这类位置**不超过 $k$ 个**；于是自带镜像的原始字符至少 $n - k$ 个。这些位置关于镜像封闭（镜像的镜像回到自身），把它们上面的字符按 $t$ 中的顺序读出，得到的正是一个**回文子序列**——而它全部由 $s$ 的字符构成。因此

$$\mathrm{LPS}(s) \ge n - k \quad\Longrightarrow\quad k \ge n - \mathrm{LPS}(s)$$

反过来，取一个长为 $L_0$ 的最长回文子序列，把它当成回文串的中轴骨架、在两侧补上缺失的镜像字符，就能得到长度 $n + (n - L_0)$ 的回文串，即 $n - L_0$ 次插入可行（具体构造见 §3.3 的递推与 §5 引理 3）。上下界重合，于是

$$\boxed{\ \text{ans} = n - \mathrm{LPS}(s)\ }$$

图 1 给出了 $s = \texttt{"leetcode"}$ 的实例：能互相配上对的原始字符只有 $e, d, e$ 三个（即 `"ede"`，长度为 3），其余 5 个字符各要插入 1 个镜像，故答案是 $8 - 3 = 5$。

### 3.3 算法流程：区间 DP 直接算最少插入次数

![区间 DP 的状态转移](images/wc170_q4_interval_dp_flow.svg)

$\mathrm{LPS}$ 是经典的区间 DP，但本题有一个更直接的写法：把「最少插入次数」本身作为状态**从区间内部定义**，不必先算 LPS。

设 $dp[i][j]$ 为把子串 $s[i..j]$ 变成回文串的最少插入次数，则

$$dp[i][j] = \begin{cases} 0, & i \ge j \\[2pt] dp[i+1][j-1], & s[i] = s[j] \\[2pt] 1 + \min\bigl(dp[i+1][j],\ dp[i][j-1]\bigr), & s[i] \ne s[j] \end{cases}$$

两个分支的含义：

- $s[i] = s[j]$：若内层 $s[i+1..j-1]$ 已经变成回文串 $P$，则 $s[i] + P + s[j]$ 仍是回文串，原有的插入方案原封不动，代价不变；
- $s[i] \ne s[j]$：两者字符不同，**不可能互为镜像**，所以在最终回文串里 $s[i]$ 的镜像与 $s[j]$ 的镜像至少有一个是插入字符。付掉这 1 次插入后，$s[i..j]$ 的问题就退化成「去掉左端」或「去掉右端」的同类子问题，取较小者。

依赖关系只有「更短的区间」，所以计算顺序是**区间长度递增**：$len = 2, 3, \dots, n$。答案为 $dp[0][n-1]$。

> 💡 两种视角是等价的：把 $dp[i][j] = (j-i+1) - \mathrm{LPS}(s[i..j])$ 代入上面的分段递推，化简后正好得到 LPS 的区间递推（见 §5 引理 1）。所以哪条路都能做，区间插入次数的写法代码更短、少一个「最后再减一次」的坑。

### 3.4 示例演算

![s = mbadm 的区间 DP 表格](images/wc170_q4_walkthrough.svg)

以 $s = \texttt{"mbadm"}$ 为例，只填 $i \le j$ 的上三角：

- $len = 1$：$dp[0][0] = dp[1][1] = \dots = dp[4][4] = 0$（单个字符本身是回文串）；
- $len = 2$：四对相邻字符全部不同，如 $dp[0][1]$（`m`、`b`）$= 1 + \min(0,0) = 1$；
- $len = 3, 4$：两端都不同，逐层取 $\min$ 再加 1，得到 $2, 2, 2$ 与 $3, 3$；
- $len = 5$：$s[0] = s[4] = \texttt{m}$，走相同分支，$dp[0][4] = dp[1][3] = 2$。

三个官方示例的对照：

| $s$ | $n$ | 最长回文子序列 | $n - \mathrm{LPS}$ |
|-----|-----|----------------|--------------------|
| `zzazz` | 5 | `zzazz`（5） | 0 |
| `mbadm` | 5 | `mam` 或 `mbm`（3） | 2 |
| `leetcode` | 8 | `eee` 或 `ede`（3） | 5 |

## 4. 算法细节

1. **base 与空区间**：$len = 1$ 时 $dp[i][i] = 0$；空区间的代价同样为 0。把二维表初始化为全 0，正好覆盖 $len = 2$ 且 $s[i] = s[j]$ 时访问到的 $dp[i+1][i]$（下三角），无需特判。
2. **下标边界**：外层 $len$ 从 2 到 $n$，内层 $i$ 满足 `i + len - 1 < n`，$j = i + len - 1$。$j - 1 = i \ge 0$、$i + 1 \le j < n$ 恒成立，不会越界。
3. **一维滚动（可选）**：处理第 $i$ 行时，`dp[j]` 还保留着第 $i+1$ 行的 $dp[i+1][j]$，`dp[j-1]` 已被本行更新为 $dp[i][j-1]$，而 $dp[i+1][j-1]$ 必须用 `prev_diag` 单独暂存；同时要把 `dp[i]` 显式置 0，否则 $j = i+1$ 时会读到第 $i-1$ 行残留的 $dp[i-1][i]$。
4. **等价路线**：$\mathrm{LPS}(s) = \mathrm{LCS}(s, \mathrm{reverse}(s))$，答案 $= n - \mathrm{LCS}$。实现更直白，但要额外存一份反转串，复杂度同样是 $O(n^2)$。
5. **不要混淆「子串」与「子序列」**：回文**子串**要求连续，回文**子序列**允许跳过字符。`"leetcode"` 的最长回文子串长度只有 1（单个 `e`），若错用它就会得到 $8 - 1 = 7$。
6. **不需要更优复杂度**：$n \le 500$ 时状态数约 $1.25 \times 10^5$，每个状态 $O(1)$ 转移，常数极小；不要写成 $O(n^3)$ 的「枚举中心 + 向两侧扩张」。
7. **数值范围**：答案不超过 $n - 1 \le 499$，`int` 足够，不需要 `long long`。

## 5. 正确性证明

**引理 1（LPS 的收缩递推）**：设 $\mathrm{LPS}(i,j)$ 表示 $s[i..j]$ 的最长回文子序列长度（约定空区间 $i > j$ 时为 0），则

$$\mathrm{LPS}(i,j) = \begin{cases} 1, & i = j \\ 2 + \mathrm{LPS}(i+1,j-1), & s[i] = s[j] \\ \max\bigl(\mathrm{LPS}(i+1,j),\ \mathrm{LPS}(i,j-1)\bigr), & s[i] \ne s[j] \end{cases}$$

**证明**：

- $s[i] = s[j]$：一方面，取内层最长回文子序列并在两端补上 $s[i]$、$s[j]$，得到长度 $2 + \mathrm{LPS}(i+1,j-1)$ 的回文子序列，故 $\ge$ 成立。另一方面，设 $P$ 是任一长为 $m$ 的回文子序列：若 $P$ 同时用到 $i$ 与 $j$，由于 $i$ 是最左下标、$j$ 是最右下标，它们必是 $P$ 的首尾，删掉后剩下 $s[i+1..j-1]$ 的长 $m-2$ 的回文子序列，故 $m \le 2 + \mathrm{LPS}(i+1,j-1)$；若 $P$ 没有同时用到两端，则 $P$ 落在某个更短区间内，$m \le \max\bigl(\mathrm{LPS}(i+1,j), \mathrm{LPS}(i,j-1)\bigr) \le \mathrm{LPS}(i+1,j-1) + 1 \le 2 + \mathrm{LPS}(i+1,j-1)$（去掉一个字符最多让 LPS 减 1）。两边夹逼得等号。
- $s[i] \ne s[j]$：回文子序列不可能同时用到 $i$ 与 $j$（首尾字符必须相同），故它必是某个更短区间的回文子序列，$\le \max$ 成立；而 $\mathrm{LPS}(i+1,j)$、$\mathrm{LPS}(i,j-1)$ 各自对应的子序列都是合法的，$\ge$ 也成立。∎

**引理 2（插入次数下界）**：设 $m = j - i + 1$，任何用 $k$ 次插入把 $s[i..j]$ 变成回文串的方案都满足 $k \ge m - \mathrm{LPS}(i,j)$。

**证明**：设最终回文串 $t$ 长度为 $L = m + k$。把每个原始字符在 $t$ 中的位置 $q$ 与它的镜像位置 $\bar q = L - 1 - q$ 对应起来，由回文性有 $t[q] = t[\bar q]$。称原始位置 $q$ 是「自配对」的，若 $\bar q$ 上也是原始字符。镜像映射是双射，不同的非自配对位置对应不同的镜像位置，而这些镜像位置全被 $k$ 个插入字符占据，故非自配对位置至多 $k$ 个，自配对位置至少 $m - k$ 个。自配对关系关于镜像封闭（$\bar{\bar q} = q$），把这 $m - k$ 个位置上的字符按顺序排成序列 $P$：反向读 $P$ 等价于把每个字符替换为其镜像位置上的字符，位置仍在集合内且字符相同，所以 $P$ 回文。$P$ 由 $s$ 的字符构成（相对顺序也保持），是 $s[i..j]$ 的回文子序列，故 $\mathrm{LPS}(i,j) \ge m - k$。∎

**引理 3（递推值可实现）**：记 $f(i,j)$ 为 §3.3 递推算出的值，$m = j - i + 1$，则存在只用 $f(i,j)$ 次插入的方案。

**证明**：对 $m$ 归纳。

- $m \le 1$：$f(i,j) = 0$，$s[i..j]$ 本身就是回文串；
- $s[i] = s[j]$：内层长 $m - 2$，由归纳假设存在含 $s[i+1..j-1]$、插入 $f(i+1,j-1)$ 次的回文串 $P$，则 $s[i] + P + s[j]$ 是回文串（两端字符相同）且包含 $s[i..j]$，插入次数仍为 $f(i+1,j-1) = f(i,j)$；
- $s[i] \ne s[j]$：不妨设 $f(i,j) = 1 + f(i,j-1)$。由归纳假设存在含 $s[i..j-1]$、插入 $f(i,j-1)$ 次的回文串 $P$，则 $s[j] + P + s[j]$ 是回文串，包含 $s[i..j]$（$s[i..j-1]$ 取自 $P$，$s[j]$ 取末尾那个），插入次数为 $f(i,j-1) + 1 = f(i,j)$。另一分支对称。∎

**定理**：$\text{ans} = f(0,n-1) = n - \mathrm{LPS}(0,n-1)$。

**证明**：由引理 3 得 $\text{ans} \le f(0,n-1)$；由引理 2 取 $(i,j) = (0,n-1)$ 得 $\text{ans} \ge n - \mathrm{LPS}(0,n-1)$。再证 $f(i,j) = m - \mathrm{LPS}(i,j)$（对 $m$ 归纳）：

- $s[i] = s[j]$ 时 $f(i,j) = f(i+1,j-1) = (m-2) - \mathrm{LPS}(i+1,j-1) = m - \bigl(2 + \mathrm{LPS}(i+1,j-1)\bigr) = m - \mathrm{LPS}(i,j)$；
- $s[i] \ne s[j]$ 时
  $$f(i,j) = 1 + \min\bigl((m-1) - \mathrm{LPS}(i+1,j),\ (m-1) - \mathrm{LPS}(i,j-1)\bigr) = m - \max\bigl(\mathrm{LPS}(i+1,j), \mathrm{LPS}(i,j-1)\bigr) = m - \mathrm{LPS}(i,j)$$

两处都用到引理 1。于是 $f(0,n-1) = n - \mathrm{LPS}(0,n-1)$，上下界重合，故答案为 $n - \mathrm{LPS}(s)$，且区间 DP 求出的 $dp[0][n-1]$ 就是答案。∎

## 6. 复杂度分析

- **时间**：$O(n^2)$。状态数为 $\frac{n(n+1)}{2}$，每个状态只做「比较两端 + 两次取 min」，$O(1)$；$n = 500$ 时约 $1.25 \times 10^5$ 次转移。
- **空间**：$O(n^2)$。二维表存 $n \times n$ 个 `int`，$n = 500$ 时约 1 MB；改用一维滚动数组可降到 $O(n)$。
- **对比**：暴力枚举插入方案是指数级；LCS 路线同为 $O(n^2)$ 时间，空间可做到 $O(n)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minInsertions(string s) {
        int n = s.size();
        if (n < 2) return 0;
        // dp[i][j]：把 s[i..j] 变成回文串的最少插入次数
        vector<vector<int>> dp(n, vector<int>(n, 0));
        for (int len = 2; len <= n; len++) {
            for (int i = 0; i + len - 1 < n; i++) {
                int j = i + len - 1;
                if (s[i] == s[j]) dp[i][j] = dp[i + 1][j - 1];   // 两端配成一对，代价 0
                else dp[i][j] = 1 + min(dp[i + 1][j], dp[i][j - 1]);
            }
        }
        return dp[0][n - 1];
    }
};
```

### Python

```python
class Solution:
    def minInsertions(self, s: str) -> int:
        n = len(s)
        if n < 2:
            return 0
        # dp[i][j]：把 s[i..j] 变成回文串的最少插入次数
        dp = [[0] * n for _ in range(n)]
        for length in range(2, n + 1):
            for i in range(n - length + 1):
                j = i + length - 1
                if s[i] == s[j]:
                    dp[i][j] = dp[i + 1][j - 1]      # 空区间（下三角）天然为 0
                else:
                    dp[i][j] = 1 + min(dp[i + 1][j], dp[i][j - 1])
        return dp[0][n - 1]
```

**空间优化版（$O(n)$）**，核心是「上一行 + 左邻 + 左上角暂存」：

```python
class Solution:
    def minInsertions(self, s: str) -> int:
        n = len(s)
        if n < 2:
            return 0
        dp = [0] * n              # 处理完第 i 行后 dp[j] = f(i, j)
        for i in range(n - 1, -1, -1):
            dp[i] = 0             # f(i, i) = 0，覆盖第 i-1 行留下的旧值
            prev_diag = 0         # f(i+1, j-1)，初值为空区间 f(i+1, i) = 0
            for j in range(i + 1, n):
                up = dp[j]        # 仍是第 i+1 行的值 f(i+1, j)
                if s[i] == s[j]:
                    cur = prev_diag
                else:
                    cur = 1 + min(up, dp[j - 1])
                prev_diag = up
                dp[j] = cur
        return dp[n - 1]
```

## 8. 边界情况与易错点

1. **$n = 1$**：答案是 0，两种写法都能自然得到 0（循环不执行，直接返回初值）；但显式写上 `if n < 2: return 0` 更稳，也省得再去讨论空区间。
2. **本身就是回文串**（`"zzazz"`、`"aaa"`）：$s[i] = s[j]$ 分支一路向内收缩，答案为 0，不会多付插入。
3. **空区间取值的来源**：$len = 2$ 且两端相同时会访问 $dp[i+1][i]$（下三角）。二维数组初始化为 0 即可；若用「只填上三角、其余留空」的其他实现，必须显式处理这个空区间。
4. **一维滚动忘记 `dp[i] = 0`**：$j = i+1$ 时 `dp[j-1]` 会读到上一行残留的 $f(i-1,i)$，答案偏大。用 `s = "ab"`（正确答案 1）就能暴露这个 bug。
5. **把答案写成「$n$ 减去最长回文子串长度」**：回文子串必须连续，`"leetcode"` 的最长回文子串长度只有 1，会错答 7；正确是 $8 - 3 = 5$。
6. **贪心「两端不同就两边各插一个」**：`"aab"` 会错答 2，正确是 1。
7. **性能**：$n = 500$ 时二维表是 $2.5 \times 10^5$ 个 int，安全；但不要写成 $O(n^3)$（枚举中心 + 扩张）或对每个区间重新扫描。

**延伸思考**：

1. **插入代价因字符而异**：设给 $s[j]$ 配一个镜像要花 $w(s[j])$。此时 $n - \mathrm{LPS}$ 不再成立（可能宁愿不配对），转移要变成三项取最小：
   $$dp[i][j] = \min\Bigl(dp[i+1][j-1],\ w(s[j]) + dp[i][j-1],\ w(s[i]) + dp[i+1][j]\Bigr)$$
   其中第一项只在 $s[i] = s[j]$ 时可用。等代价（$w \equiv 1$）时第一项总不劣于后两项，所以原题只保留一个分支就够。
2. **回溯构造答案**：只求长度时不需要方案；若要输出具体怎么插，可从 $dp[0][n-1]$ 出发按转移往回走，$O(n)$ 时间就能生成一个长度 $n + dp[0][n-1]$ 的回文串。
3. **与删除的对偶性**：允许删除时，最少删除次数也等于 $n - \mathrm{LPS}$（删掉所有不在某个 LPS 里的字符），所以「删」与「插」在这道题里给出同一个数字。
