# LeetCode 分裂二叉树的最大乘积 题解

## 1. 题目概述

- **标题 / 题号**：分裂二叉树的最大乘积（#1339，medium）
- **链接**：https://leetcode.cn/problems/maximum-product-of-splitted-binary-tree/
- **来源**：LeetCode 第 174 场周赛 Q3
- **难度**：中等
- **标签**：树、深度优先搜索、二叉树

**题意**：给定一棵节点值全为正整数的二叉树，**删掉恰好一条边**，让它分裂成两棵互不相连的子树（两个连通块）。设两块的节点值之和为 $s$ 与 $S-s$（$S$ 是整棵树的和），求所有删法中 $s\cdot(S-s)$ 的最大值，再把结果对 $10^9+7$ 取模返回。

关键点：**先比较出最大乘积，最后才取模**。取模会把大小关系打乱，边算边取模再比大小是错的。

**约束**：

- 节点数在 $[2,\,5\times 10^4]$ 之间
- $1 \le \text{Node.val} \le 10^4$，因此总和 $S \le 5\times 10^8$
- 返回类型为 `int`，取模后必然放得下

## 3. 解题思路

### 3.1 暴力思路

树上有 $n-1$ 条边。最直白的做法是枚举每条边：把它断开，然后对两侧各做一次遍历求和，算出乘积，取最大。单条边需要 $O(n)$ 时间，总复杂度 $O(n^2)$。$n = 5\times 10^4$ 时约有 $2.5\times 10^9$ 次基本操作，C++ 也过不去。

暴力慢在「每条边都重新求和」：相邻两条边切出来的两块，其实只差很小的一块局部结构，重复计算全被浪费了。

### 3.2 核心观察：删一条边 ⇔ 选一个非根节点

![删一条边只能切出一棵子树](images/wc174_q3_edge_cut_model.svg)

考察边 $(p, v)$，其中 $v$ 是 $p$ 的子节点。删掉这条边后，含 $v$ 的那一块连通块**恰好是以 $v$ 为根的整棵子树**：$v$ 与它所有后代之间的路径都不经过 $(p,v)$，而其余任何节点想走到 $v$ 都必须经过这条被删的边。于是

$$\text{乘积}(v) = s_v \cdot (S - s_v), \qquad s_v = \sum_{u \in \text{subtree}(v)} u.\text{val}$$

只要对每个非根节点 $v$ 求出它的子树和 $s_v$，「枚举边 + 重复求和」就变成了「枚举节点 + 一次子树和」，总和 $S = s_{root}$ 顺带算出。

> 💡 直觉：$f(s) = s(S-s)$ 是开口向下的抛物线，在 $s = S/2$ 处最大，所以最优切法的两块和通常接近。但 $s$ 只能取到「某棵子树的和」这些离散值，**不能**据此直接贪心挑一棵「看起来最接近一半」的子树——必须把所有候选都算出来再比较。

### 3.3 算法流程：两遍遍历

![两遍遍历流程](images/wc174_q3_postorder_flow.svg)

1. **第一遍（后序）**：自底向上累加子树和

   $$\text{sub}[x] = x.\text{val} + \text{sub}[x.\text{left}] + \text{sub}[x.\text{right}]$$

   累加到根即得 $S = \text{sub}[root]$。
2. **第二遍**：枚举每个非根节点 $x$，用 $\text{sub}[x]\cdot(S-\text{sub}[x])$ 更新答案。
3. **收尾**：返回 `ans % (10^9+7)`。

实现上不必真的写递归后序：先做一次**前序**把节点收进数组，再**倒序**处理这个数组，就等价于「子节点一定先于父节点」的累加顺序（前序里父在子前，倒过来自然子先父后）。

### 3.4 示例演算

![示例 1 演算](images/wc174_q3_walkthrough.svg)

对 `[1,2,3,4,5,6]`，$S = 21$。5 个非根节点的子树和分别是 $4, 5, 6, 11, 9$，对应乘积

$$4\times17 = 68,\quad 5\times16 = 80,\quad 6\times15 = 90,\quad 11\times10 = 110,\quad 9\times12 = 108$$

最大是 110，来自子树和为 11 的 2 号节点（切边 $1$–$2$）。

再看 `[1,null,2,3,4,null,null,5,6]`：结构为 $1\to2$（右孩子），$2\to\{3,4\}$，$4\to\{5,6\}$。子树和是 $\{3, 5, 6, 15, 20\}$，乘积依次为 $54, 80, 90, 90, 20$，最大 90，来自 4 号节点（$15\times6$，切边 $2$–$4$）。

## 4. 算法细节

1. **迭代而不是递归**：节点数可达 $5\times10^4$，退化成链时递归深度就是 $5\times10^4$，C++ 默认栈与 Python 的递归上限都扛不住。用显式栈做前序遍历最稳。
2. **逆前序的正确用法**：前序序列中父一定排在子之前，所以倒序扫描时，处理到 $x$ 时 $x$ 的左右孩子必然已经算过，可以直接取 `sub[left]`、`sub[right]`。
3. **子树和的存储**：C++ 用 `unordered_map<TreeNode*, long long>`，插入前 `reserve(2n)` 避免反复 rehash；Python 直接用 `dict`（以节点对象为键）。
4. **必须跳过根节点**：根没有父边，`sub[root] = S` 代入得到 $S\times0 = 0$。虽然节点值全为正时它不会影响最大值，但概念上它是非法方案，显式跳过更安全（一旦节点值允许为负，就会污染答案）。
5. **64 位与取模时机**：$S\le 5\times10^8$，最大乘积约 $2.5\times10^8 \times 2.5\times10^8 = 6.25\times10^{16}$，超过 `int`（$2.1\times10^9$），但在 `long long`（$9.2\times10^{18}$）内。取模只在最后一步做一次。
6. **空间可以再省**：不存 `sub` 表，改为两遍后序 DFS（第一遍只求 $S$，第二遍边求子树和边更新答案），空间从 $O(n)$ 降到 $O(h)$；但为了少写一遍遍历、代码更直观，下面给出的版本仍保留哈希表。
7. **答案初值**：所有节点值为正，任何合法乘积都 $>0$，`best = 0` 是安全下界。

## 5. 正确性证明

**引理 1（删边切出的正是子树）**：对任意非根节点 $v$，删除边 $(\text{parent}(v), v)$ 后，含 $v$ 的连通块恰好由 $v$ 及其所有后代组成。

**证明**：树删去一条边后恰有两个连通块。删掉 $(\text{parent}(v), v)$ 后，$v$ 与任一后代 $u$ 之间的唯一简单路径不经过这条边（否则该路径会先向上离开 $\text{subtree}(v)$，与后代关系矛盾），故 $u$ 仍在 $v$ 所在块。反之，若 $w \notin \text{subtree}(v)$，$v$ 到 $w$ 的唯一简单路径必经过边 $(\text{parent}(v), v)$，该边被删，故 $w$ 不在 $v$ 所在块。于是两块正是 $\text{subtree}(v)$ 与 $V \setminus \text{subtree}(v)$。∎

**引理 2（边与非根节点一一对应）**：树的每条边都可唯一写成 $(\text{parent}(v), v)$ 的形式，不同边对应不同的 $v$。

**证明**：除根外每个节点有且仅有一个父节点，因此每条边由它的下端 $v$ 唯一确定；反之每个非根节点 $v$ 也唯一确定一条父边。∎

**引理 3（逆前序累加合法）**：按「前序序列倒序」处理时，处理到节点 $x$ 时 $\text{sub}[x.\text{left}]$ 与 $\text{sub}[x.\text{right}]$ 均已计算完毕。

**证明**：前序遍历中，父节点在进入其子树前即被访问，故父在序列中的位置严格早于其任一子节点。倒序后父的位置严格晚于其子节点，处理父时子必已处理。∎

**定理（最优性）**：算法返回 $\left(\max_{v \ne root} s_v (S - s_v)\right) \bmod (10^9+7)$，它等于题目要求的最大乘积取模后的值。

**证明**：由引理 1 与引理 2，删边方案与「非根节点」一一对应，且方案 $v$ 的乘积就是 $s_v(S-s_v)$，所以所有合法乘积构成的集合正是 $\{s_v(S-s_v) : v \ne root\}$。引理 3 保证算法算出的 $s_v$ 都是真实子树和，第二遍枚举遍历了每个非根节点且逐一取 $\max$，故 `best` 等于该集合的最大值。最后对常数 $10^9+7$ 取模不改变「最大值」这一事实（因为取模发生在比较之后），命题成立。∎

## 6. 复杂度分析

- **时间**：$O(n)$。前序遍历每个节点进出各一次 $O(n)$；倒序累加 $O(n)$；枚举非根节点 $O(n)$；每步常数次加减乘与哈希表访问，总计 $O(n)$。
- **空间**：$O(n)$。`order` 数组存 $n$ 个指针，子树和哈希表存 $n$ 项；显式栈最深 $O(h)$，$h$ 最坏为 $n$（链）。若改为两遍后序 DFS，可把哈希表省掉，空间降到 $O(h)$。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <unordered_map>
#include <algorithm>
using namespace std;

/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    int maxProduct(TreeNode* root) {
        const long long MOD = 1000000007LL;

        // 前序遍历，收集所有节点
        vector<TreeNode*> order;
        vector<TreeNode*> st{root};
        while (!st.empty()) {
            TreeNode* cur = st.back();
            st.pop_back();
            order.push_back(cur);
            if (cur->left) st.push_back(cur->left);
            if (cur->right) st.push_back(cur->right);
        }

        // 倒序处理 = 子节点先于父节点，自底向上求子树和
        unordered_map<TreeNode*, long long> sub;
        sub.reserve(order.size() * 2);
        for (int i = (int)order.size() - 1; i >= 0; --i) {
            TreeNode* cur = order[i];
            long long s = cur->val;
            if (cur->left) s += sub[cur->left];
            if (cur->right) s += sub[cur->right];
            sub[cur] = s;
        }

        // 枚举每个非根节点：删掉它与其父节点之间的边
        long long total = sub[root], best = 0;
        for (TreeNode* cur : order) {
            if (cur == root) continue;          // 根没有父边
            long long s = sub[cur];
            best = max(best, s * (total - s));  // 先比较大小
        }
        return (int)(best % MOD);               // 最后取模
    }
};
```

### Python

```python
class Solution:
    def maxProduct(self, root: 'TreeNode') -> int:
        MOD = 10 ** 9 + 7

        # 前序遍历收集节点
        order, stack = [], [root]
        while stack:
            node = stack.pop()
            order.append(node)
            if node.left:
                stack.append(node.left)
            if node.right:
                stack.append(node.right)

        # 倒序 = 子节点先于父节点，自底向上累加子树和
        sub = {}
        for node in reversed(order):
            s = node.val
            if node.left:
                s += sub[node.left]
            if node.right:
                s += sub[node.right]
            sub[node] = s

        total = sub[root]
        best = 0
        for node in order:
            if node is root:                 # 根没有父边，跳过
                continue
            s = sub[node]
            best = max(best, s * (total - s))  # Python 整数不会溢出
        return best % MOD                    # 比较完才取模
```

## 8. 边界情况与易错点

1. **「先取模、后比较」是经典错误**：题目特意注明 *maximize the answer before taking the mod*。若在枚举过程中就存 `s * (total - s) % MOD`，大乘积会被压小、大小关系彻底打乱。
2. **`int` 溢出**：$S$ 可达 $5\times10^8$，乘积上限 $6.25\times10^{16}$，`int` 存不下。C++ 必须用 `long long`（Python 无此问题，但转写 C++ 时常忘）。
3. **最小规模 `[1,1]`**：只有一条边，两块和都是 1，答案 1。节点值全为正时任何合法乘积都 $\ge 1$，所以 `best = 0` 的初值安全，不需要为「只有一个候选」额外特判。
4. **链状树导致递归爆栈**：$5\times10^4$ 个节点排成链时递归深度即 $5\times10^4$，C++ 可能段错误、Python 会抛 `RecursionError`。务必用显式栈迭代。
5. **忘记跳过根节点**：把 `root` 也当作候选会得到 $S\times0 = 0$，正数输入下不改变答案，但一旦推广到负数权重就会出错，属于「能过但错」的隐患。
6. **遍历方向写反**：只做前序累加（父在子前）会拿到错误子树和；必须是后序，或用「前序 + 逆序处理」的技巧。
7. **返回值类型**：取模后 $< 10^9+7$，落在 `int` 范围内，直接强转即可，不必再开 64 位返回。
