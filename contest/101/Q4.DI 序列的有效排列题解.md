# LeetCode DI 序列的有效排列 题解

## 1. 题目概述

- **标题 / 题号**：DI 序列的有效排列（#903，hard）
- **链接**：https://leetcode.cn/problems/valid-permutations-for-di-sequence/
- **来源**：LeetCode 第 101 场周赛 Q4
- **难度**：困难
- **标签**：字符串、动态规划、前缀和

**题意**：给定长度为 $n$ 的字符串 $s$，其中 $s[i]$ 为 `'D'` 表示「减少」、`'I'` 表示「增加」。统计 $0..n$ 的排列 $\text{perm}$（共 $n+1$ 个数）中，满足下式的排列个数：

- 若 $s[i] = \text{'D'}$，则 $\text{perm}[i] > \text{perm}[i+1]$；
- 若 $s[i] = \text{'I'}$，则 $\text{perm}[i] < \text{perm}[i+1]$。

答案对 $10^9+7$ 取模。

**约束**：

- $n = s.length$，$1 \le n \le 200$
- $s[i]$ 只会是 `'I'` 或 `'D'`

> 💡 排列的**具体数值**并不重要，重要的只有「相邻两个数谁大谁小」。这提示我们只跟踪**相对排名**。

## 2. 示例

**示例 1**

```text
输入：s = "DID"
输出：5
解释：(0,1,2,3) 的五个有效排列是
(1,0,3,2)  (2,0,3,1)  (2,1,3,0)  (3,0,2,1)  (3,1,2,0)
```

**示例 2**

```text
输入：s = "D"
输出：1
解释：n = 1，需要 perm[0] > perm[1]，只有 (1,0) 一个。
```

```text
输出：1                     只有 (2,1,0)
```

## 3. 解题思路

### 3.1 暴力思路

枚举 $0..n$ 的全部 $(n+1)!$ 个排列，逐个检查 $n$ 条约束。$n = 200$ 时 $201!$ 是天文数字，完全不可行；即便 $n \le 10$ 也已是 $3.6 \times 10^6$ 量级。

### 3.2 核心观察：插入码（相对排名）是一一对应

![状态设计：只看末位的相对排名](images/wc101_q4_rank_dp_concept.svg)

从前往后构造排列。假设前 $i+1$ 个位置已经填好，我们**不关心它们具体取了哪些数**，只关心最后一位在这 $i+1$ 个数里的**排名** $j$（$0 \le j \le i$，$0$ 表示最小）。原因是：

1. 后面新填入的数只与「最后一位」比较大小；
2. 比较结果完全由**新数在扩展后的 $i+2$ 个数中的排名** $j'$ 决定——把大小为 $j'$ 的新数插入到 $i+1$ 个旧数的相对序列中后，旧末位的新排名是 $j$（若 $j < j'$）或 $j+1$（若 $j \ge j'$）。于是
   - $s[i] = \text{'I'}$（末位递增）$\iff j < j'$；
   - $s[i] = \text{'D'}$（末位递减）$\iff j \ge j'$。

而且「每步的相对排名序列」与「最终排列」是**一一对应**的：给定每步新元素在已填前缀中的排名 $(j_0, j_1, \dots, j_n)$（其中 $j_i \in [0, i]$），可以唯一还原排列；反之任一排列唯一给出这样一串排名。因此**数排名序列的个数就等于数排列的个数**。

> 这正是「插入码 / 相对排名编码」的思想：$n+1$ 个元素的排列共有 $\prod_{i=0}^{n} (i+1) = (n+1)!$ 个，与排名序列的个数完全相同。

### 3.3 算法流程 / 状态转移

![前缀和转移](images/wc101_q4_prefix_flow.svg)

设 $dp_i[j]$ 表示「已处理前 $i$ 条约束、当前末位排名为 $j$」的方案数，$j \in [0, i]$。初始 $dp_0[0] = 1$（只有一个数，排名只能是 0）。

转移时枚举新末位排名 $j' \in [0, i+1]$：

$$dp_{i+1}[j'] = \begin{cases} \displaystyle\sum_{j < j'} dp_i[j] & s[i] = \text{'I'} \\[6pt] \displaystyle\sum_{j \ge j'} dp_i[j] & s[i] = \text{'D'} \end{cases}$$

两个和式都是**前缀和**形式，预处理 $pre[j] = dp_i[0] + \cdots + dp_i[j-1]$ 后可 $O(1)$ 求出每个 $j'$ 的转移，整层 $O(n)$。最终答案为 $\sum_{j=0}^{n} dp_n[j]$。

```text
dp[0] = 1
for i = 0 .. n-1:
    pre[0] = 0
    for j = 0 .. i:  pre[j+1] = pre[j] + dp[j]        # 左闭右开前缀和
    total = pre[i+1]
    for j = 0 .. i+1:
        ndp[j] = pre[j]             若 s[i] == 'I'      # 旧排名 < j
        ndp[j] = total - pre[j]     若 s[i] == 'D'      # 旧排名 >= j
    dp = ndp
answer = sum(dp) mod 1e9+7
```

### 3.4 示例演算

![示例演算：DID 的三层 DP](images/wc101_q4_walkthrough.svg)

以 $s = \text{"DID"}$（$n = 3$）为例，每层 $dp$ 表示「当前长度下各末位排名的方案数」：

| 层 | 约束 | total | dp |
|----|------|-------|-----|
| 初始 | — | — | `[1]` |
| $i=0$ | `'D'` | 1 | `[1, 0]` |
| $i=1$ | `'I'` | 1 | `[0, 1, 1]` |
| $i=2$ | `'D'` | 2 | `[2, 2, 1, 0]` |

末层求和 $2 + 2 + 1 + 0 = 5$，与题面给出的 5 个有效排列一致。

## 4. 算法细节

1. **左闭右开前缀和**：`pre[j] = dp[0] + ... + dp[j-1]`，于是 `sum_{k<j} dp[k] = pre[j]`、`sum_{k>=j} dp[k] = total - pre[j]`，两种转移都不需要额外下标修正。
2. **数组长度**：第 $i$ 层下标 $0..i$，第 $i+1$ 层要写到 $i+1$，因此数组开到 $n+2$ 最省心；每层必须**完整重写** `ndp[0..i+1]`（C++ 里复用数组时要覆盖所有用到的位置）。
3. **取模**：`'D'` 分支是减法，C++ 必须 `(total - pre[j] + MOD) % MOD` 防止负数；Python 的 `%` 天然返回非负，但仍建议写成 `(total - pre[j]) % MOD` 保持习惯统一。
4. **正确性依赖的等价关系**：`s[i] = 'I'` 对应 $j < j'$，`'D'` 对应 $j \ge j'$。等号归到 `'D'` 一侧，因为「排名相等」在插入后会导致旧末位排名变成 $j+1 > j'$，即旧末位更大，属于递减。
5. **最终求和**：最后一层没有更多约束，任何末位排名都合法，因此把整个 $dp_n$ 求和。
6. **复杂度**：状态数 $O(n^2)$，转移 $O(1)$，总时间 $O(n^2)$，空间可用两行滚动到 $O(n)$。
7. **`n = 200` 时**：$O(n^2) = 4 \times 10^4$，常数极小，远低于时限要求。

## 5. 正确性证明

设 $P$ 为 $0..n$ 的全部排列，$P^\* \subseteq P$ 为满足 $s$ 的有效排列集合。对排列 $\text{perm} \in P$，定义**插入码** $j_i$ 为 $\text{perm}[i]$ 在 $\{\text{perm}[0], \dots, \text{perm}[i]\}$ 中的排名（$0$ 表示最小），$i = 0, \dots, n$。

**引理 1（插入码双射）**：映射 $\text{perm} \mapsto (j_0, j_1, \dots, j_n)$ 是 $P$ 与 $\{(j_0,\dots,j_n) : 0 \le j_i \le i\}$ 之间的双射。

**证明**：给定排列显然唯一确定各 $j_i$，且 $j_i \in [0, i]$。反过来给定满足 $0 \le j_i \le i$ 的序列，从 $i = n$ 倒推到 $0$ 可唯一还原：维护一个有序列表 $L$（初始为 $0..n$），第 $i$ 步取 $L$ 中第 $j_i$ 小的元素作为 $\text{perm}[i]$ 并从 $L$ 删除。该构造的每一步都有唯一结果，且还原出的排列的插入码恰为原序列（归纳：删除 $\text{perm}[i]$ 后剩下的正是前 $i$ 个元素，故排名一致）。于是双射成立；两侧元素个数同为 $\prod_{i=0}^{n}(i+1) = (n+1)!$。∎

**引理 2（比较关系翻译）**：对任意 $0 \le i < n$，$\text{perm}[i] < \text{perm}[i+1] \iff j_i < j_{i+1}$。

**证明**：$j_{i+1}$ 是 $\text{perm}[i+1]$ 在前 $i+2$ 个元素中的排名。把前 $i+1$ 个元素的相对序列看作已排好的列表，插入 $\text{perm}[i+1]$ 使其排名为 $j_{i+1}$：所有原排名 $k < j_{i+1}$ 的元素排名不变，所有 $k \ge j_{i+1}$ 的元素排名加 1。特别地，$\text{perm}[i]$ 的原排名是 $j_i$，插入后排名为 $j_i$（若 $j_i < j_{i+1}$）或 $j_i + 1$（若 $j_i \ge j_{i+1}$）。因此

- $j_i < j_{i+1}$ 时，$\text{perm}[i]$ 的新排名 $j_i < j_{i+1}$，即 $\text{perm}[i] < \text{perm}[i+1]$；
- $j_i \ge j_{i+1}$ 时，$\text{perm}[i]$ 的新排名 $j_i + 1 > j_{i+1}$，即 $\text{perm}[i] > \text{perm}[i+1]$。∎

**引理 3（状态语义）**：对每个 $i \in [0, n]$ 与 $j \in [0, i]$，$dp_i[j]$ 等于「插入码前缀 $(j_0, \dots, j_i)$ 中 $j_i = j$、且前 $i$ 条约束全部满足」的序列个数。

**证明**：对 $i$ 归纳。$i = 0$ 时只有 $j_0 = 0$，$dp_0[0] = 1$ 正确。设第 $i$ 层成立，考虑第 $i+1$ 层：任何合法前缀 $(j_0,\dots,j_{i+1})$ 由 $(j_0,\dots,j_i)$ 与 $j_{i+1} = j'$ 拼接而成，且由引理 2，新约束 $s[i]$ 成立 $\iff$（`'I'` 时 $j_i < j'$，`'D'` 时 $j_i \ge j'$）。转移式正是对满足该条件的 $j_i$ 求和，故 $dp_{i+1}[j']$ 精确计数。∎

**定理**：$\sum_{j=0}^{n} dp_n[j] = |P^\*|$。

**证明**：由引理 3，$dp_n[j]$ 计数「前 $n$ 条约束全部满足且 $j_n = j$」的插入码序列；对 $j$ 求和即计数所有满足全部 $n$ 条约束的插入码序列。由引理 1 的双射，这些序列与 $P^\*$ 一一对应，故和式等于 $|P^\*|$。∎

## 6. 复杂度分析

- **时间**：共 $n$ 层；第 $i$ 层计算前缀和 $O(i)$、枚举转移 $O(i)$，合计 $O(n^2)$。$n \le 200$ 时约 $4 \times 10^4$ 次基本运算。
- **空间**：若保留所有层为 $O(n^2)$；本题用两行滚动（`dp` 与 `ndp`）加一个前缀和数组，为 $O(n)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int numPermsDISequence(string s) {
        const long long MOD = 1000000007LL;
        int n = (int)s.size();
        // dp[j]：前 i+1 个位置排好、最后一位在已用数字中排名为 j 的方案数
        vector<long long> dp(n + 2, 0), ndp(n + 2, 0), pre(n + 2, 0);
        dp[0] = 1;
        for (int i = 0; i < n; i++) {
            pre[0] = 0;
            for (int j = 0; j <= i; j++) pre[j + 1] = (pre[j] + dp[j]) % MOD;
            long long total = pre[i + 1];
            for (int j = 0; j <= i + 1; j++) {
                if (s[i] == 'I') ndp[j] = pre[j];                    // 旧末位排名 < j
                else ndp[j] = (total - pre[j] + MOD) % MOD;          // 旧末位排名 >= j
            }
            dp.swap(ndp);
        }
        long long ans = 0;
        for (int j = 0; j <= n; j++) ans = (ans + dp[j]) % MOD;
        return (int)ans;
    }
};
```

### Python

```python
class Solution:
    def numPermsDISequence(self, s: str) -> int:
        MOD = 10 ** 9 + 7
        n = len(s)
        # dp[j]：前 i+1 个位置排好、最后一位在已用数字中排名为 j 的方案数
        dp = [0] * (n + 2)
        dp[0] = 1
        for i in range(n):
            pre = [0] * (n + 2)
            for j in range(i + 1):           # pre[j] = dp[0] + ... + dp[j-1]
                pre[j + 1] = (pre[j] + dp[j]) % MOD
            total = pre[i + 1]
            ndp = [0] * (n + 2)
            for j in range(i + 2):
                if s[i] == 'I':
                    ndp[j] = pre[j]          # 旧末位排名 < j
                else:
                    ndp[j] = (total - pre[j]) % MOD   # 旧末位排名 >= j
            dp = ndp
        return sum(dp) % MOD
```

## 8. 边界情况与易错点

1. **等号归属**：`j_i == j_{i+1}` 时旧末位排名会加 1 而变大，属于**递减**，因此 `'D'` 的条件是 $j_i \ge j_{i+1}$（含等号）。把等号放到 `'I'` 一侧会全盘错。
2. **`ndp` 的重用与清空**：C++ 里 `ndp` 跨层复用，必须保证每层把 `ndp[0..i+1]` 全部重写；漏写尾部会读到上一层的脏值（尤其是 `dp.swap` 之后 `ndp` 里是旧 `dp`）。
3. **前缀和的边界**：`pre` 是左闭右开，`pre[0] = 0`、`pre[i+1] = total`；`j = i+1` 时 `'D'` 分支为 0、`'I'` 分支为 `total`，正好符合「新末位最大 ⇒ 旧末位必然更小」。
4. **减法取模**：C++ 中 `total - pre[j]` 可能为负，必须 `+ MOD` 再取模；Python 的 `%` 结果非负，但显式取模更清晰。
5. **`n = 1`**：`'I'` 与 `'D'` 都只有 1 个排列，代码中首层 `dp` 长度 2、循环一次即结束，答案 1。
6. **全 `'I'` / 全 `'D'`**：答案都应为 1（只有单调排列），可作为快速自检；交替串则答案最大。
7. **下标越界**：最后一层 `dp` 有效下标是 $0..n$，求和时别写成 `0..n-1`。
8. **不要尝试枚举排列**：$201!$ 规模，任何暴力都不可能通过；本题必须用相对排名 DP。
