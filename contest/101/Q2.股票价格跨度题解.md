# LeetCode 股票价格跨度 题解

## 1. 题目概述

- **标题 / 题号**：股票价格跨度（#901，medium）
- **链接**：https://leetcode.cn/problems/online-stock-span/
- **来源**：LeetCode 第 101 场周赛 Q2
- **难度**：中等
- **标签**：栈、设计、数据流、单调栈

**题意**：按时间顺序不断收到某支股票的每日报价 `price`。某天的**价格跨度**定义为：从当天开始**向前**数，连续满足「价格 $\le$ 当天价格」的最大天数（含当天）。

实现 `StockSpanner` 类：

- `StockSpanner()`：初始化；
- `int next(int price)`：传入今天的价格，返回今天的跨度。

**约束**：

- $1 \le \text{price} \le 10^5$
- `next` 最多调用 $10^4$ 次

> 💡 「在线」二字是题眼：价格一条条到来，不能预知未来，但**过去的报价与跨度可以复用**。

## 2. 示例

**示例 1**

```text
输入：
["StockSpanner","next","next","next","next","next","next","next"]
[[],[100],[80],[60],[70],[60],[75],[85]]
输出：[null,1,1,1,2,1,4,6]

解释：
next(100) = 1                     序列 [100]
next(80)  = 1                     序列 [100,80]
next(60)  = 1                     序列 [100,80,60]
next(70)  = 2   70 罩住 60         序列 [100,80,60,70]
next(60)  = 1                     序列 [100,80,60,70,60]
next(75)  = 4   75 罩住 60,70,60   序列 [100,80,60,70,60,75]
next(85)  = 6   85 罩住 75,80 及其区间 ⇒ 6
```

**示例 2**

```text
输入：过去四天价格为 [7,2,1,2]，今天的价格为 2
输出：4
解释：从今天向前数：今天 2 ≤ 2、前一天 2 ≤ 2、前两天 1 ≤ 2、三天前 2 ≤ 2，
      再往前是 7 > 2 停止，连续 4 天符合要求。

对照：过去四天 [7,34,1,2]，今天 8 ⇒ 今天 8、2、1 合格，34 > 8 停止，跨度为 3。
```

## 3. 解题思路

### 3.1 暴力思路

每来一个新价格，就从后往前扫历史价格，直到遇到严格大于它的价格为止，计数即为跨度。单次 $O(t)$（$t$ 为已有天数），总计 $O(T^2)$，$T = 10^4$ 时约 $10^8$ 次比较，勉强能过但存在大量重复劳动。

### 3.2 核心观察：被「罩住」的区间可以整块合并

![单调栈：价格递减 + 跨度累加](images/wc101_q2_stack_merge_concept.svg)

考虑一个曾经出现过的价格 $p$，以及它当时的跨度 $s$。如果今天来了一个价格 $x \ge p$，那么：

- $p$ 那天以及它向后覆盖的 $s$ 天，**全部** $\le p \le x$，因此都被今天「罩住」；
- 以后再也不会有人需要单独去看这 $s$ 天了——任何询问都会被今天（或更晚的、更大或相等的价格）统一覆盖。

于是可以把这 $s$ 天**压缩成一个整体**，并把它的长度加进今天的跨度。用一个栈保存这些「尚未被吃掉的历史区间」，栈元素为 $(\text{price}, \text{span})$，并维护：

> **单调栈不变式**：栈内价格自底向上**严格递减**。

每来一个新价格，弹出所有价格 $\le$ 它的栈顶并把跨度累加，最后压入 $(x, \text{span})$。每个元素至多进栈、出栈各一次，均摊 $O(1)$。

### 3.3 算法流程

![next(price) 流程](images/wc101_q2_merge_flow.svg)

```text
next(price):
    span = 1                                  # 今天自己算 1 天
    当栈非空 且 栈顶.price <= price:
        span += 栈顶.span                     # 整块并入今天
        弹出栈顶
    压入 (price, span)
    return span
```

## 4. 算法细节

1. **栈元素同时存价格与跨度**：只存价格无法表达「这段区间有多长」，累加时会退化成逐天扫描。
2. **比较用 `<=`**：价格**相等**时今天也要罩住对方（题面是「小于或等于」），因此相等也要弹出并累加；若写成 `<` 会漏掉等值区间。
3. **先累加后弹出**：`span += st.top().span` 必须在 `pop` 之前读取，顺序写反会访问不到或丢掉跨度。
4. **栈的物理意义**：栈中每个元素代表一段「以该价格为右端点、尚未被更大价格覆盖」的连续区间；栈底到栈顶恰好把已到来的全部天数切分成若干段。
5. **单调性维护**：弹出所有 $\le x$ 的元素后，栈顶（若存在）必然 $> x$，压入 $x$ 后不变式继续成立。
6. **数据规模**：价格范围 $10^5$ 也允许开「价格 → 最后一天下标」的数组 + 并查集式跳跃，但单调栈更通用（价格是大整数时同样适用）。

## 5. 正确性证明

把第 $d$ 天（从 1 开始编号）的价格记为 $p_d$，其真实跨度记为 $S_d$。

**引理 1（区间分解）**：在调用 `next(p_d)` **之前**，栈中元素 $(q_1, s_1), \dots, (q_k, s_k)$（自底向上）满足：

1. $q_1 > q_2 > \cdots > q_k$；
2. 存在下标 $0 = t_0 < t_1 < \cdots < t_k = d-1$，使得第 $t_{j-1}+1$ 天到第 $t_j$ 天构成一段，这一段内所有价格都 $\le q_j$，且 $s_j = t_j - t_{j-1}$；同时 $q_j$ 是这一段内的**最后一个**价格，且它严格大于后一段的所有价格。

**证明**：对天数归纳。初始栈空，$k=0$，成立。假设第 $d-1$ 次调用后成立，第 $d$ 次调用弹出所有 $q_j \le p_d$ 的栈顶元素，设剩下 $q_1 > \cdots > q_m > p_d$。被弹出的段（第 $t_{m}+1$ 天到第 $d-1$ 天）全部满足价格 $\le p_d$：每段内部价格 $\le q_j \le p_d$，且段与段之间的分界正是被弹出的 $q_j$，同样 $\le p_d$。把它们与第 $d$ 天合并成新的一段，长度恰为 $1 + \sum_{j>m} s_j = \text{span}$，新段的最后一个价格是 $p_d$。剩余段不受影响，且 $q_m > p_d$ 保证严格递减。∎

**引理 2（跨度公式）**：`next(p_d)` 返回的 $\text{span} = 1 + \sum_{j:\,q_j \le p_d} s_j$ 恰好等于 $S_d$。

**证明**：由引理 1，第 $d$ 天之前的历史被切成若干段，每段的最后价格是 $q_j$ 且段内价格都 $\le q_j$。从第 $d$ 天向前数，只要当前段满足「最后价格 $\le p_d$」，由于段内价格都 $\le q_j \le p_d$，整个段都合格，可以整段跳过；一旦遇到 $q_j > p_d$，该段最后一个价格就不合格，扫描必须停止。因此跨度 = $1 +$（所有满足 $q_j \le p_d$ 的段长之和），正是算法累加的结果。∎

**定理**：对任意报价序列，`StockSpanner` 每次 `next` 的返回值都等于该天的真实价格跨度。

**证明**：引理 2 已给出单次调用的正确性；引理 1 保证每次调用后不变式仍成立，故可对全部调用归纳。∎

## 6. 复杂度分析

- **时间**：每次 `next` 的 `while` 循环弹出若干栈元素，每个元素一生只入栈一次、出栈一次，因此 $T$ 次调用的总弹出次数 $\le T$。总时间 $O(T)$，**均摊**每次 `next` 为 $O(1)$（单次最坏 $O(T)$）。
- **空间**：$O(T)$，栈最多保存 $T$ 个元素（价格严格递减时一个都不弹）。

## 7. 参考代码

### C++

```cpp
class StockSpanner {
    stack<pair<int, int>> st;        // (价格, 该价格负责的跨度)，价格自底向上严格递减

public:
    StockSpanner() {}

    int next(int price) {
        int span = 1;
        while (!st.empty() && st.top().first <= price) {
            span += st.top().second;  // 吃掉所有被今天价格"罩住"的历史区间
            st.pop();
        }
        st.push({price, span});
        return span;
    }
};
```

### Python

```python
class StockSpanner:
    def __init__(self):
        self.st = []                 # (价格, 跨度)：价格自底向上严格递减

    def next(self, price: int) -> int:
        span = 1
        while self.st and self.st[-1][0] <= price:
            span += self.st.pop()[1]  # 吃掉所有被今天价格"罩住"的历史区间
        self.st.append((price, span))
        return span
```

## 8. 边界情况与易错点

1. **等值价格**：必须用 `<=` 弹出。若用 `<`，`[5,5,5]` 会得到 $1,1,1$ 而不是 $1,2,3$。
2. **`span` 初值为 1**：忘记把今天自己算进去是最常见的 off-by-one。
3. **先取跨度再弹出**：`span += st.top().second` 与 `st.pop()` 的顺序写反会直接崩溃或读到脏值。
4. **单次最坏 $O(T)$**：价格严格递减时一次都不弹，栈会涨到 $T$；这不是 bug，均摊仍然 $O(1)$。
5. **空栈判断**：`while` 条件里 `!st.empty()` 必须在前，短路求值保证不会访问空栈顶。
6. **不要试图「预计算」未来**：本题是在线数据流，任何需要看后续价格的方案都不成立。
7. **只存价格不够**：只维护一个递减价格栈而不存跨度，累加时无法知道每段长度，会退化为暴力。
