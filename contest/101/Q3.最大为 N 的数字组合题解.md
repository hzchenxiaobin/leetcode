# LeetCode 最大为 N 的数字组合 题解

## 1. 题目概述

- **标题 / 题号**：最大为 N 的数字组合（#902，hard）
- **链接**：https://leetcode.cn/problems/numbers-at-most-n-given-digit-set/
- **来源**：LeetCode 第 101 场周赛 Q3
- **难度**：困难
- **标签**：数组、数学、字符串、二分查找、动态规划

**题意**：给定按非递减顺序排列的数字字符数组 `digits`（每个元素是 `'1'` 到 `'9'` 的单个字符），允许重复使用其中任意字符拼接正整数。返回**可以生成**的、**小于或等于** $n$ 的正整数个数。

**约束**：

- $1 \le \text{digits.length} \le 9$
- `digits[i].length == 1`，且只含 `'1'` 到 `'9'`，互不相同、非递减
- $1 \le n \le 10^9$

> 💡 `digits` 里**没有 `'0'`**，因此任何拼接结果都没有前导零问题，长度就是位数——这是本题所有计数公式成立的前提。

## 2. 示例

```text
输出：20
解释：可写出的 20 个数是

（1 位数 4 个、2 位数 16 个；3 位数最小 111 > 100，故为 0）
```

## 3. 解题思路

### 3.1 暴力思路

从 1 枚举到 $n$，逐个检查其十进制表示的每一位是否都在 `digits` 中。单次检查 $O(\log n)$，总 $O(n \log n)$。$n \le 10^9$ 时约 $10^{10}$ 次操作，必然超时。

### 3.2 核心观察：按位数分类，贴上界用「逐位收紧」

![按位数分两类统计](images/wc101_q3_length_split_concept.svg)

设 $n$ 的十进制长度为 $L$，`digits` 的大小为 $D$。

**第一类：位数 $k < L$。** 这类数无论怎么填都必然小于 $n$，且每一位都能独立任选 $D$ 个数字，共 $D^k$ 个。于是

$$\sum_{k=1}^{L-1} D^k$$

**第二类：位数恰好等于 $L$。** 这类数需要与 $n$ 逐位比较。从高位到低位扫描，维护「前缀与 $n$ 完全相同」这一前提：

- 在位置 $i$，若取一个**比 $n[i]$ 小**的数字：共有 $\text{less}_i$ 种选择，后面 $L-1-i$ 位可以随便填，产生 $\text{less}_i \cdot D^{L-1-i}$ 个数，它们全部 $< n$；
- 若取**等于** $n[i]$ 的数字：继续看下一位；
- 若 `digits` 中**没有**等于 $n[i]$ 的数字：收紧失败，后面不可能再有「贴紧」的数，直接结束。

扫描完所有 $L$ 位若仍未中断，说明 $n$ 本身也能被拼出，答案再 $+1$。

这两类互不重叠（位数不同），且并集恰好是全部合法数，所以直接相加即可。

### 3.3 算法流程

![逐位收紧的流程](images/wc101_q3_tight_flow.svg)

```text
p[0..L] = D 的幂次表（p[k] = D^k）
ans = p[1] + p[2] + ... + p[L-1]          # 第一类
for i = 0 .. L-1:                          # 第二类：逐位收紧
    less = count(d in digits: d < n[i])
    same = (n[i] in digits)
    ans += less * p[L-1-i]
    if not same: return ans                # 前缀已严格变小，低位随便填
return ans + 1                             # 全部位都相等 ⇒ n 本身合法
```

### 3.4 示例演算

![示例演算：digits 取 1,3,5,7，n 为 100](images/wc101_q3_walkthrough.svg)

$n = 100$，$L = 3$，$D = 4$，幂次表为 $1, 4, 16, 64$。

| 位数 | 计数 | 说明 |
|------|------|------|
| 1 位 | $4^1 = 4$ | 1, 3, 5, 7 |
| 2 位 | $4^2 = 16$ | 11 … 77 全部合法 |
| 3 位 | 0 | 最小 111 > 100 |

收紧过程：

| 位置 | $n[i]$ | less | same | 贡献 |
|------|--------|------|------|------|
| 0 | `'1'` | 0 | ✓ | 0，继续 |
| 1 | `'0'` | 0 | ✗（无 `'0'`） | 0，终止 |

合计 $4 + 16 + 0 = 20$，与题面一致。

## 4. 算法细节

1. **幂次表**：预先算 $p[k] = D^k$（$k = 0..L$），避免循环里反复乘；$D \le 9$、$L \le 10$，$D^L \le 9^{10} \approx 3.49 \times 10^9$，需要用 `long long` 存中间值。
2. **`less` 的统计**：`digits` 已排序，可用二分（`lower_bound(n[i]) - digits.begin()`），也可以直接遍历 $D \le 9$ 个元素，两者都很快。
3. **`same` 的判断**：等价于「`n[i]` 在 `digits` 中」，可用 `find` 或二分。
4. **终止时机**：一旦 `same` 为假，**当前位**仍需先累加 `less` 的贡献，再返回；顺序写反会漏掉「这一位取更小数字」的那一批。
5. **末尾 $+1$**：走到循环结束说明每一位都能取到与 $n$ 相同的数字，即 $n$ 本身可由 `digits` 拼出，必须计入。
6. **不需要去重**：不同位数、不同前缀产生的数字天然不同；同一数字也不可能被两条路径重复计数（收紧路径是唯一确定的）。
7. **返回值范围**：所有合法数都 $\le n \le 10^9$，答案不超过 $10^9$，`int` 足够；但中间乘法要用 64 位。
8. **为什么不能简单地对 $n$ 做普通数位 DP**：当然可以（`tight` 维度），但本题没有「数字和」之类的额外约束，纯组合计数更直接，状态只有一个「是否仍贴紧」。

## 5. 正确性证明

记 $\mathcal{S}$ 为所有由 `digits` 拼成的正整数集合，$A = \{x \in \mathcal{S} : x \le n\}$，算法输出为 `ans`。

**引理 1（短位数全覆盖）**：位数 $k < L$ 的合法数共有 $D^k$ 个，且全部小于 $n$。

**证明**：每个位置可独立从 $D$ 个字符中选一个，且 `digits` 不含 `'0'`，故不存在前导零问题，方案数为 $D^k$；首位非零保证它是 $k$ 位数。又 $k < L$ 意味着它至多 $L-1$ 位，而 $n$ 是 $L$ 位数，故严格小于 $n$。∎

**引理 2（收紧分支不重不漏）**：设位置 $i$ 之前的前缀与 $n$ 完全相同。则所有「长度为 $L$、首次在位置 $i$ 小于 $n$」且合法的数恰好有 $\text{less}_i \cdot D^{L-1-i}$ 个，且这些数两两不同、都小于 $n$。

**证明**：首次小于意味着前 $i$ 位与 $n$ 相同、第 $i$ 位取 $d < n[i]$（共 $\text{less}_i$ 种）、后 $L-1-i$ 位任取（$D^{L-1-i}$ 种），乘法原理给出计数。这些数的第 $i$ 位严格更小，故小于 $n$；不同选择组合出的数字在第 $i$ 位或之后某位不同，故互不相同。另外「首次小于的位置」对每个数唯一，因此不同 $i$ 的分支互不相交。∎

**引理 3（提前终止无遗漏）**：若在位置 $i$ 有 $\text{same}_i = \text{false}$，则不存在位数等于 $L$、前缀前 $i+1$ 位与 $n$ 相同的合法数。

**证明**：这样的数第 $i$ 位必须等于 $n[i]$，但 `digits` 中无此字符，矛盾。∎

**定理**：算法返回值恰为 $|A|$。

**证明**：由引理 1，第一类累加项精确覆盖 $A$ 中位数 $< L$ 的元素。由引理 2，循环中每个未终止位置累加的项精确覆盖「首次小于发生在该位置」的元素，且不同位置互不相交；由引理 3，终止后不存在被遗漏的「贴紧前缀」元素。若循环正常结束，说明 $n$ 的每一位都能取到相等字符，此时 $n \in \mathcal{S}$ 且 $n \le n$，故 $+1$ 恰好补上 $n$ 本身。三类元素互不相交且并集为 $A$，故总和为 $|A|$。∎

## 6. 复杂度分析

- **时间**：幂次表 $O(L)$；逐位收紧共 $L$ 轮，每轮统计 `less`/`same` 需 $O(D)$（二分则 $O(\log D)$），总计 $O(L \cdot D)$，即约 $10 \times 9 = 90$ 次操作，可视为 $O(\log n)$。
- **空间**：$O(L)$ 存幂次表与 $n$ 的字符串表示，$L \le 10$，即 $O(1)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int atMostNGivenDigitSet(vector<string>& digits, int n) {
        string s = to_string(n);
        int L = (int)s.size(), D = (int)digits.size();
        vector<long long> p(L + 1, 1);           // p[k] = D^k
        for (int k = 1; k <= L; k++) p[k] = p[k - 1] * D;

        long long ans = 0;
        for (int k = 1; k < L; k++) ans += p[k];  // 位数严格小于 L：每位数都能任选

        for (int i = 0; i < L; i++) {             // 位数等于 L：贴着上界逐位收紧
            int less = 0;                         // 本位取"更小数字"的个数
            bool same = false;                    // 能否本位取相等继续收紧
            for (const string& d : digits) {
                if (d[0] < s[i]) less++;
                else if (d[0] == s[i]) same = true;
            }
            ans += (long long)less * p[L - 1 - i];
            if (!same) return (int)ans;           // 前缀已严格变小，低位随便填
        }
        return (int)(ans + 1);                    // 逐位都相等 ⇒ n 本身可被构造
    }
};
```

### Python

```python
class Solution:
    def atMostNGivenDigitSet(self, digits: List[str], n: int) -> int:
        s = str(n)
        L, D = len(s), len(digits)
        p = [1] * (L + 1)                        # p[k] = D^k
        for k in range(1, L + 1):
            p[k] = p[k - 1] * D

        ans = sum(p[1:L])                        # 位数严格小于 L：每位数都能任选
        for i, ch in enumerate(s):               # 位数等于 L：贴着上界逐位收紧
            less = sum(1 for d in digits if d < ch)
            ans += less * p[L - 1 - i]
            if ch not in digits:
                return ans                       # 前缀已严格变小，低位随便填
        return ans + 1                           # 逐位都相等 ⇒ n 本身可被构造
```

## 8. 边界情况与易错点

1. **提前终止时先累加再返回**：位置 $i$ 的 `less` 贡献必须先加、再判断 `same`。以 `digits = ["2","3"]`、$n = 300$ 为例：第 0 位 `'3'` 有 `less = 1`、`same = true`，应先加 $1 \times 2^2 = 4$（对应 222、223、232、233），第 1 位 `'0'` 才终止；若把终止判断写在累加之前，这 4 个就漏了。
2. **结尾的 $+1$**：只有「每一位都相等」才会走到循环末尾，此时 $n$ 自身合法，漏掉它是最常见的 WA。
3. **`int` 溢出**：$D^{L}$ 可达 $3.49 \times 10^9$，超过 `int` 上限；幂次表与乘法必须用 `long long`。
4. **$n$ 只有一位**：此时第一类为空（$L-1 = 0$），答案完全由收紧过程决定，例如 `digits=["1","3"]`、$n=2$ 返回 1。
5. **`digits` 全部大于 $n$ 的首位**：如 `digits=["7"]`、$n=6$，第 0 位 `less = 0`、`same = false`，直接返回 0；而示例 3 的 `digits=["7"]`、$n=8$ 中 `'7' < '8'`，`less = 1`，贡献 $1 \times D^0 = 1$，两者只差一个比较方向，容易混淆。
6. **字符比较**：`digits` 是字符串数组，比较必须按字符（`d[0] < s[i]`），不要误转成数字以外的东西；`'1'` 到 `'9'` 的 ASCII 序与数字序一致，可以直接比。
7. **`n = 10^9`**：$L = 10$，幂次表要开到 $p[10]$，数组大小别写成 10。
8. **不要用 `pow` 返回浮点**：`pow(9, 10)` 虽在此范围内仍可精确表示，但用整数递推更稳妥、也无精度隐患。
