# LeetCode 判断字符串的两半是否相似 题解

## 1. 题目概述

- **标题 / 题号**：判断字符串的两半是否相似（#1704，easy）
- **链接**：https://leetcode.cn/problems/determine-if-string-halves-are-alike/
- **来源**：LeetCode 第 221 场周赛 Q1
- **难度**：简单
- **标签**：字符串、计数、双指针

**题意**：给定一个**偶数长度**的字符串 `s`，从正中切成等长的两半：前半 $a = s[0 \ldots n/2-1]$，后半 $b = s[n/2 \ldots n-1]$。若 $a$ 与 $b$ 含有**相同数量**的元音字母（`a e i o u` 及其大写，共 10 个），则称两半**相似**。相似返回 `true`，否则返回 `false`。

**约束**：

- $2 \le s.length \le 1000$
- $s.length$ 是偶数
- `s` 由大写和小写英文字母组成

> 💡 **读题关键**：签到题只需想清楚三件事——**在哪切**（下标 $n/2$，整数除法天然对齐）、**数什么**（10 个大小写元音，`y` 不算）、**比什么**（两个计数器是否相等）。从题面到代码的最短路径：不切片、一遍扫描、两个计数器。

## 2. 示例

**示例 1**

```text
输入：s = "book"
输出：true
解释：a = "bo"（1 个元音 o），b = "ok"（1 个元音 o），元音数相等 → 相似。
```

**示例 2**

```text
输入：s = "textbook"
输出：false
解释：a = "text"（1 个元音 e），b = "book"（2 个元音 o、o），1 ≠ 2 → 不相似。
注意同一个字母重复出现要重复计数。
```

**示例 3**（大小写混合）

```text
输入：s = "AbCd"
输出：false
解释：a = "Ab"（1 个元音 A），b = "Cd"（0 个元音）。大写 A 也是元音。
```

## 3. 解题思路

### 3.1 暴力思路：切片成两串，分别计数

最直白的写法：求出中点 $m = n/2$，切出两个子串各数一遍元音再比较：

```python
m = len(s) // 2
a, b = s[:m], s[m:]
return (sum(c in 'aeiouAEIOU' for c in a)
        == sum(c in 'aeiouAEIOU' for c in b))
```

正确性显然，$n \le 1000$ 也毫无性能压力，比赛时这么交完全没问题。但拆开看有两个小浪费：**切片各拷贝出一份 $O(n)$ 的临时串**，且两半**分开扫了两遍**。既然每个字符只属于某一半，一次扫描同时喂两个计数器就够了。

### 3.2 核心观察：对撞双指针，一次扫描

![核心观察：正中对切与对撞双指针一遍扫描](images/wc221_q1_two_halves_concept.svg)

三条观察：

**观察一：两半互斥且完备。** 下标 $< n/2$ 属于前半，$\ge n/2$ 属于后半，切点唯一、不重不漏，无需真的把字符串切开。

**观察二：配对视角。** 让 $i$ 从 $0$ 向右、$j$ 从 $n-1$ 向左同步前进，第 $k$ 轮恰好同时处理"前半的第 $k$ 个字符"和"后半的倒数第 $k$ 个字符"——一轮喂饱两个计数器，循环 $n/2$ 轮扫完整个串。

**观察三：只数元音。** 元音判定是 $O(1)$ 查表（10 个字符的集合），其余字符扫过即可，不需要任何预处理。

### 3.3 算法流程

![算法流程：对撞双指针、双计数器与判相等](images/wc221_q1_two_pointer_flow.svg)

```text
cntA ← 0, cntB ← 0, i ← 0, j ← n−1
while i < j:
    if s[i] ∈ {a,e,i,o,u,A,E,I,O,U}: cntA ← cntA + 1
    if s[j] ∈ {a,e,i,o,u,A,E,I,O,U}: cntB ← cntB + 1
    i ← i + 1, j ← j − 1
return cntA == cntB
```

### 3.4 示例演算

对 `s = "textbook"`（false）逐轮走查：

| 轮 | $i$ | $s[i]$ | $j$ | $s[j]$ | cntA | cntB |
|----|-----|--------|-----|--------|------|------|
| 1 | 0 | t | 7 | k | 0 | 0 |
| 2 | 1 | **e** | 6 | **o** | 1 | 1 |
| 3 | 2 | x | 5 | **o** | 1 | 2 |
| 4 | 3 | t | 4 | b | **1** | **2** |

$1 \ne 2$，返回 `false` ✓

![示例演算：book 与 textbook 的逐对扫描](images/wc221_q1_walkthrough.svg)

## 4. 算法细节

1. **元音集合要收满 10 个字符**：`aeiouAEIOU`。两种等价实现——哈希集合（`set('aeiouAEIOU')` / `unordered_set<char>`），或先 `tolower` 归一化再查 5 个小写。前者免运行时转换，常数更小。
2. **切分点**：$m = n/2$（整数除法）。题目保证 $n$ 为偶数，前半恰为 $s[0 \ldots m-1]$。双指针版用 `i < j` 作循环条件：偶数长度下 $i$、$j$ 的奇偶性互异、永不相等，循环恰好执行 $n/2$ 轮。
3. **对冲变体**：也可只用一个带符号计数器——$i < m$ 处的元音 `+1`、$i \ge m$ 处的元音 `-1`，最后判 `cnt == 0`。把"比较相等"转化为"判零"，少一个变量。
4. **Python 最短写法**（比赛抢时间用）：

```python
class Solution:
    def halvesAreAlike(self, s: str) -> bool:
        m = len(s) // 2
        return (sum(map(s[:m].count, 'aeiouAEIOU'))
                == sum(map(s[m:].count, 'aeiouAEIOU')))
```

## 5. 正确性证明

**引理 1**（划分）：设 $n$ 为偶数，$A = \{0, 1, \dots, n/2-1\}$，$B = \{n/2, \dots, n-1\}$，则 $A \cap B = \varnothing$ 且 $A \cup B = \{0, \dots, n-1\}$，$|A| = |B| = n/2$。

**证明**：$A$、$B$ 是连续整数区间 $[0, n-1]$ 在 $n/2$ 处的切分，端点不重叠、合并无缺口。∎

**引理 2**（配对覆盖）：循环第 $k$ 轮（$k = 0, 1, \dots, n/2-1$）处理下标对 $(k,\ n-1-k)$；这些下标两两不同，且 $k \in A \iff n-1-k \in B$。

**证明**：当 $k \le n/2 - 1$ 时 $n - 1 - k \ge n/2$，故前者落 $A$、后者落 $B$；又 $k$ 与 $n-1-k$ 之和恒为 $n-1$，不同的 $k$ 给出不同的对。$k$ 取遍 $A$ 时，$n-1-k$ 依序取遍 $n-1, n-2, \dots, n/2$，恰为 $B$。∎

**定理**：算法返回 `true` 当且仅当两半元音数相等（即 $a$、$b$ 相似）。

**证明**：由引理 2，循环把每个下标恰处理一次：$i$ 侧的元音全部计入 `cntA`，$j$ 侧的全部计入 `cntB`。记 $V$ 为 10 个元音组成的集合，循环结束时

$$\text{cntA} = \sum_{i \in A}[\,s_i \in V\,], \qquad \text{cntB} = \sum_{j \in B}[\,s_j \in V\,]$$

返回值 `cntA == cntB` 与"两半元音数相等"逐字等价。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。$n/2$ 轮循环，每轮两次 $O(1)$ 元音查表加常数次加减；$n \le 1000$，远低于任何限制。
- **空间复杂度**：$O(1)$。仅两个整型计数器与两个下标。对比切片暴力的 $O(n)$ 临时串，省掉了拷贝。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool halvesAreAlike(string s) {
        int cntA = 0, cntB = 0;
        for (int i = 0, j = (int)s.size() - 1; i < j; ++i, --j) {
            if (isVowel(s[i])) ++cntA;
            if (isVowel(s[j])) ++cntB;
        }
        return cntA == cntB;
    }
private:
    static bool isVowel(char c) {
        static const string V = "aeiouAEIOU";
        return V.find(c) != string::npos;
    }
};
```

### Python

```python
class Solution:
    def halvesAreAlike(self, s: str) -> bool:
        vowels = set('aeiouAEIOU')
        i, j = 0, len(s) - 1
        cnt_a = cnt_b = 0
        while i < j:
            if s[i] in vowels:
                cnt_a += 1
            if s[j] in vowels:
                cnt_b += 1
            i += 1
            j -= 1
        return cnt_a == cnt_b
```

## 8. 边界情况与易错点

1. **元音集合漏大写**：只写 `aeiou` 时，`"AbCd"` 会把前半的 `A` 数丢，误返回 `true`（正确为 `false`）。这是本题最经典的 WA 点。
2. **`y` 不是元音**：英文题按 `a e i o u` 算，`y` / `Y` 一律不计。
3. **最短输入 $n = 2$**：如 `"aA" → true`（两半各 1 个元音），双指针恰执行一轮。
4. **循环条件**：`i < j` 依赖偶数长度——奇数长度时 $i = j$ 的中位字符不会被处理（本题约束已排除奇数；即便出现，"不计入"与"计入两边"对相等性判断等价，见延伸思考）。
5. **切分点口诀**：前半是 $s[0 \ldots n/2-1]$，条件写 `i < n/2`；写成 `i <= n/2` 会把 $s[n/2]$（后半首字符）重复计入。
6. **无溢出风险**：计数上限 $n/2 = 500$，`int` 绰绰有余，无需特判。
