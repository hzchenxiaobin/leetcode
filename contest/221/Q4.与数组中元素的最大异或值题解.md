# LeetCode 与数组中元素的最大异或值 题解

## 1. 题目概述

- **标题 / 题号**：与数组中元素的最大异或值（#1707，hard）
- **链接**：https://leetcode.cn/problems/maximum-xor-with-an-element-from-array/
- **来源**：LeetCode 第 221 场周赛 Q4
- **难度**：困难
- **标签**：位运算、字典树（Trie）、数组、离线处理、排序

**题意**：给定非负整数数组 `nums` 和查询数组 `queries`，其中 `queries[i] = [xi, mi]`。第 $i$ 个查询的答案是

$$\max_{j:\ \text{nums}[j] \le m_i} \left( \text{nums}[j] \oplus x_i \right)$$

即在所有**不超过** $m_i$ 的元素中，找一个与 $x_i$ 按位异或后结果最大的数；若 `nums` 中所有元素都大于 $m_i$，该查询答案为 $-1$。返回所有查询的答案数组。

**约束**：

- $1 \le \text{nums.length},\ \text{queries.length} \le 10^5$
- $0 \le \text{nums}[j],\ x_i,\ m_i \le 10^9$

> 💡 **一句话抽象**：这是两道经典题的缝合——「421. 数组中两个数的最大异或值」的 **0-1 Trie 逐位贪心**，加上一道「$\le m_i$ 上界限制」。限制是**前缀性质**，离线排序后用双指针把元素**增量插入** Trie 即可。

## 2. 示例

**示例 1**

```text
输入：nums = [0,1,2,3,4], queries = [[3,1],[1,3],[5,6]]
输出：[3,3,7]

解释：
1) mi = 1，候选 {0,1}：0⊕3 = 3，1⊕3 = 2 → 3
2) mi = 3，候选 {0,1,2,3}：1⊕2 = 3 最大 → 3
3) mi = 6，候选 {0,1,2,3,4}：5⊕2 = 7 最大 → 7
```

**示例 2**

```text
输入：nums = [5,2,4,6,6,3], queries = [[12,4],[8,1],[6,3]]
输出：[15,-1,5]

解释：
1) mi = 4，候选 {2,3,4}：12⊕3 = 15 最大 → 15
2) mi = 1，无元素 ≤ 1（最小值是 2）→ -1
3) mi = 3，候选 {2,3}：6⊕3 = 5 最大 → 5
```

**示例 3**（$m_i = 0$ 的边界）

```text
输入：nums = [0,2], queries = [[7,0]]
输出：[7]

解释：0 ≤ 0 成立，候选 {0}，0⊕7 = 7。注意 0 是合法候选，不能输出 -1。
```

## 3. 解题思路

### 3.1 暴力思路

对每个查询线性扫描 `nums`，跳过大于 $m_i$ 的元素，逐一异或取最大值：

```text
for (x, m) in queries:
    best = -1
    for v in nums:
        if v <= m: best = max(best, v ^ x)
```

时间复杂度 $O(nq)$，最坏 $10^{10}$ 次运算，必然超时。

瓶颈有二：**「max 异或」**本身需要快速求解，**「$\le m_i$ 的过滤」**又让每个查询的候选集合各不相同。分别击破：

1. 子问题「固定集合 $S$ 中找 $\max_{s \in S} s \oplus x$」→ **0-1 Trie 逐位贪心**，单次 $O(B)$（$B$ 为位宽）；
2. 限制「$\text{nums}[j] \le m_i$」具有**单调性**：$m_i$ 越大候选越多 → **离线排序 + 双指针增量插入**。

### 3.2 核心观察一：0-1 字典树 + 逐位贪心

把每个数按二进制**从高位到低位**插入 0-1 Trie（每层 0/1 两个分支）。查询 $x$ 时从根出发逐位走：

- 设当前位 $x$ 的比特为 $d$，**优先走 $d \oplus 1$ 的子树**（异或后该位为 1）；不存在才走 $d$ 的子树（该位为 0）。

![0-1 Trie 逐位贪心](images/wc221_q4_trie_greedy_concept.svg)

**为什么高位优先是对的**：$2^b > 2^{b-1} + \cdots + 2^0$。让第 $b$ 位异或出 1，胜过把所有低位全凑成 1。所以从最高位开始，每一步「能拿 1 就拿 1」的贪心不会错过最优解。

### 3.3 核心观察二：离线排序 + 双指针增量插入

候选集合 $\{j : \text{nums}[j] \le m_i\}$ 在 `nums` **排序后是一个前缀**，且前缀长度随 $m_i$ 增大而单调不减。于是：

1. 将 `nums` 升序排序；
2. 将查询**带原始下标**按 $m_i$ 升序排序；
3. 依序处理每个查询：先把所有 $\le m_i$ 的元素插入 Trie（双指针只前进不回退），再做贪心查询；
4. 若处理某查询时一个元素都没插入过（$\min(\text{nums}) > m_i$），答案 $-1$。

![离线处理流程](images/wc221_q4_offline_flow.svg)

每个元素至多插入一次，每次插入 $O(B)$；每个查询一次贪心 $O(B)$。

> ⚠️ 本题不需要可持久化 Trie：查询顺序可以自由重排（离线），排完序后 Trie 内容只增不减，普通 0-1 Trie 足矣。若题目强制在线（按到达顺序即时回答），才需要主席树式的可持久化 Trie。

### 3.4 示例演算

![示例演算](images/wc221_q4_walkthrough.svg)

以示例 1 走一遍完整流程（查询已按 $m_i$ 排序）：

| 查询 | 新插入 | Trie 累计候选 | 最优对 | 答案 |
|------|--------|---------------|--------|------|
| $(x{=}3,\ m{=}1)$ | $0, 1$ | $\{0,1\}$ | $3 \oplus 0 = 3$ | $\text{ans}[0] = 3$ |
| $(x{=}1,\ m{=}3)$ | $2, 3$ | $\{0,1,2,3\}$ | $1 \oplus 2 = 3$ | $\text{ans}[1] = 3$ |

最终按原始下标写回，输出 $[3, 3, 7]$。

## 4. 算法细节

1. **位宽选择**：$10^9 < 2^{30}$，取 $B = 31$（比特 30 到 0）即可覆盖所有值；C++ 中 $1 \ll 30$ 在 `int` 范围内安全。
2. **Trie 实现**（C++）：用 `vector<array<int,2>>` 数组式 Trie 预分配，节点数上界 $nB + 1$，避免逐节点 `new`。本题只插不删，无需计数域。
3. **离线排序**：查询必须**携带原始下标** `idx`，按 $m_i$ 升序排；$m_i$ 相同的查询任意顺序皆可（双指针连续前进）。
4. **贪心查询**：`cur` 从根出发，对 $b = 30 \dots 0$：令 $d = (x \gg b) \& 1$，若 `ch[cur][d^1]` 存在则走它并 `res |= 1 << b`，否则走 `ch[cur][d]`。
5. **判空**：维护已插入元素个数（或指针 $j$），$j = 0$ 时输出 $-1$——空 Trie 上贪心会访问非法节点，必须先特判。
6. **恢复顺序**：答案写进 `ans[idx]` 而非 `ans[处理序]`。

## 5. 正确性证明

**引理 1**（高位占优）：对任意比特 $b \ge 0$，有 $2^b > \sum_{i=0}^{b-1} 2^i$。

**证明**：$\sum_{i=0}^{b-1} 2^i = 2^b - 1 < 2^b$。∎

**引理 2**（Trie 贪心正确性）：设 $S$ 为 Trie 中的数的集合，$x$ 为查询值。从最高位起，每步优先进入与 $x$ 当前位相异的子树（若存在），得到的 $res$ 满足 $res = \max_{s \in S} s \oplus x$。

**证明**：对位宽 $B$ 归纳。$B = 0$ 时集合只有 $0$，结论平凡。设最高位为 $b$：

- 若存在 $s \in S$ 的第 $b$ 位与 $x$ 的第 $b$ 位不同，则该子树中任何数与 $x$ 异或后第 $b$ 位为 1，结果至少 $2^b$；而第 $b$ 位相同的任何候选，其异或值至多为 $2^b - 1$（由引理 1）。故最优解必在相异子树中，贪心选择不损失最优性，余下 $b$ 位是同一子树内的同构子问题，由归纳假设成立。
- 若不存在，则所有候选第 $b$ 位异或结果均为 0，走相同位子树，同样归约为子问题。

∎

**引理 3**（离线等价性）：查询按 $m_i$ 升序处理时，处理到查询 $(x, m)$ 的贪心开始前，Trie 中恰包含多重集合 $\{\text{nums}[j] : \text{nums}[j] \le m\}$。

**证明**：`nums` 排序后满足 $\le m$ 的元素构成一个前缀；设其长度为 $k(m)$，它是 $m$ 的单调不减函数。双指针 $j$ 在 $m_i$ 单调不减的序列中只前进，处理当前查询时恰好执行到 $j = k(m)$，即前缀 $\text{nums}[0..k(m)-1]$ 全部插入且无其他元素。同一元素重复插入不影响贪心结果（存在性判断与重复次数无关）。∎

**定理**：算法对每个查询 $i$ 返回 $\max_{\text{nums}[j] \le m_i} \text{nums}[j] \oplus x_i$，候选为空时返回 $-1$。

**证明**：由引理 3，查询开始时 Trie 恰含全部合法候选；由引理 2，贪心返回该集合的最大异或值。候选为空当且仅当 $m_i < \min(\text{nums})$，此时 $j = 0$，算法特判返回 $-1$。∎

## 6. 复杂度分析

- **时间复杂度**：$O\big((n \log n + q \log q) + (n + q) \cdot B\big)$，其中 $B = 31$
  - 排序：$O(n \log n + q \log q)$；
  - 每个元素插入 Trie 一次，每次 $O(B)$，共 $O(nB)$；
  - 每个查询一次贪心走查，$O(B)$，共 $O(qB)$。
  - $n = q = 10^5$ 时 Trie 步进约 $6 \times 10^6$ 次，轻松通过。

- **空间复杂度**：$O(nB)$
  - Trie 节点数上界 $nB + 1 \approx 3.1 \times 10^6$，每个节点两个指针；
  - 离线排序的下标数组与答案数组 $O(q)$。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    vector<int> maximizeXor(vector<int>& nums, vector<vector<int>>& queries) {
        const int B = 31; // 1e9 < 2^30，比特 30..0 足够覆盖
        int n = nums.size(), q = queries.size();
        sort(nums.begin(), nums.end());

        // 离线：查询按 mi 升序，携带原始下标
        vector<int> idx(q);
        iota(idx.begin(), idx.end(), 0);
        sort(idx.begin(), idx.end(), [&](int a, int b) {
            return queries[a][1] < queries[b][1];
        });

        // 数组式 0-1 Trie：最多新增 n*B 个节点
        vector<array<int, 2>> ch(1, {-1, -1});
        ch.reserve((size_t)n * B + 1);
        auto insert = [&](int v) {
            int cur = 0;
            for (int b = B - 1; b >= 0; --b) {
                int d = (v >> b) & 1;
                if (ch[cur][d] == -1) {
                    ch[cur][d] = (int)ch.size();
                    ch.push_back({-1, -1});
                }
                cur = ch[cur][d];
            }
        };
        auto query = [&](int x) { // 调用前保证 Trie 非空
            int cur = 0, res = 0;
            for (int b = B - 1; b >= 0; --b) {
                int d = (x >> b) & 1;
                if (ch[cur][d ^ 1] != -1) {
                    res |= 1 << b;
                    cur = ch[cur][d ^ 1];
                } else {
                    cur = ch[cur][d];
                }
            }
            return res;
        };

        vector<int> ans(q);
        int j = 0;
        for (int i : idx) {
            int x = queries[i][0], m = queries[i][1];
            while (j < n && nums[j] <= m)
                insert(nums[j++]);
            ans[i] = (j == 0) ? -1 : query(x);
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maximizeXor(self, nums: List[int], queries: List[List[int]]) -> List[int]:
        B = 31
        nums.sort()
        order = sorted(range(len(queries)), key=lambda i: queries[i][1])

        trie = {}

        def insert(v: int) -> None:
            cur = trie
            for b in range(B - 1, -1, -1):
                cur = cur.setdefault((v >> b) & 1, {})

        def query(x: int) -> int:  # 调用前保证 Trie 非空
            cur = trie
            res = 0
            for b in range(B - 1, -1, -1):
                d = (x >> b) & 1
                if d ^ 1 in cur:
                    res |= 1 << b
                    cur = cur[d ^ 1]
                else:
                    cur = cur[d]
            return res

        ans = [0] * len(queries)
        j = 0
        for i in order:
            x, m = queries[i]
            while j < len(nums) and nums[j] <= m:
                insert(nums[j])
                j += 1
            ans[i] = query(x) if j > 0 else -1
        return ans
```

## 8. 边界情况与易错点

1. **候选为空输出 $-1$**：$m_i < \min(\text{nums})$ 时 Trie 为空，贪心查询会访问非法节点，必须先判空（示例 2 的 $(8,1)$）。
2. **$m_i = 0$ 且 nums 含 0**：$0 \le 0$ 成立，候选非空，答案是 $0 \oplus x = x$，别误判成 $-1$。
3. **位宽**：$10^9 < 2^{30}$，至少要用 30 位；写 $B = 31$ 或 32 保险，别照抄小规模模板的位数。$1 \ll 30$ 在 `int` 内安全。
4. **答案顺序**：离线排序打乱了查询顺序，必须按存储的原始下标写回 `ans[idx]`。
5. **$m_i$ 相同的查询**：会被连续处理，双指针天然兼容，无需特殊逻辑。
6. **重复元素**：多次插入无害——贪心只关心「某比特前缀路径是否存在」，与重复次数无关。
7. **溢出**：$x_i, \text{nums}[j] < 2^{30}$，异或结果 $< 2^{31}$，`int` 够用；但 C++ 里注意 `1 << b` 的 `b` 不要超过 30。
8. **别用「值域上最大」当候选**：与 $x$ 异或最大的数不是值最大的数，也不能只比较 $m_i$ 与 $\max(\text{nums})$，必须逐位贪心。

**延伸思考**：

- 若强制**在线**回答（查询按到达顺序、无法重排）怎么办？→ 对排序后的 `nums` 建**可持久化 0-1 Trie**（版本 $k$ 含前 $k$ 小的数），查询 $(x, m)$ 先二分出满足 $\text{nums}[k-1] \le m$ 的最大版本 $k$，再在版本 $k$ 上贪心，时间同阶但代码更重。
- 若限制改为**下界** $\text{nums}[j] \ge m_i$？→ 候选变成排序数组的**后缀**，同理可离线倒序处理。
- 若还要支持**删除**元素？→ 给每个节点加 `cnt` 计数域，插入/删除时沿路径 ±1，查询只认 `cnt > 0` 的子节点。
