# LeetCode 距离字典两次编辑以内的单词 题解

## 1. 题目概述

- **标题 / 题号**：距离字典两次编辑以内的单词（#2452，medium）
- **链接**：https://leetcode.cn/problems/words-within-two-edits-of-dictionary/
- **来源**：LeetCode 第 90 场双周赛 Q2
- **难度**：中等
- **标签**：字典树、数组、字符串

**题意**：给定两个字符串数组 `queries` 与 `dictionary`，**所有单词长度相同**、只含小写字母。一次编辑 = 把某个单词里**任意一个字母改成任何其他字母**（纯替换）。从 `queries` 中找出所有「至多两次编辑内能变成 `dictionary` 中某个单词」的字符串，按原顺序返回。

**约束**：

- $1 \le \text{queries.length}, \text{dictionary.length} \le 100$
- $1 \le n = \text{queries[i].length} = \text{dictionary[j].length} \le 100$
- 只含小写字母

## 2. 示例

**示例 1**

```text
输入：queries = ["word","note","ants","wood"], dictionary = ["wood","joke","moat"]
输出：["word","note","wood"]
解释：word→wood 改 1 处；note→joke 改 2 处；
      ants 与任何词差距 ≥ 3 处；wood 本身在字典中（0 处）。
```

**示例 2**

```text
输入：queries = ["yes"], dictionary = ["not"]
输出：[]
解释：yes → not 需要改 y→n、e→o、s→t 共 3 处，超过 2。
```

**补充：正好 2 处**

```text
输入：queries = ["abcd"], dictionary = ["aaxy"]
输出：["abcd"]
解释：b→a 与 c→x 恰好两处不同，允许保留；d 与 y 一致。
```

## 3. 解题思路

### 3.1 暴力思路

对每个 `queries[i]`，与每个 `dictionary[j]` 逐位比较统计不同位数，若 $\le 2$ 则入选。总量 $100 \times 100 \times 100 = 10^6$ 次字符比较，**直接就是正解**——本题数据范围刻意放小，考的是把「编辑」这个词正确翻译成「替换次数」，而不是算法优化。真正的坑在于：很多人一看到「编辑距离」四个字就去写 $O(n^2)$ 的 DP 编辑距离，既慢又多余——因为两串**等长**，只允许替换的编辑距离就是**汉明距离**。

### 3.2 核心观察：等长 + 只许替换 ⇒ 编辑距离 = 汉明距离

![核心观察：等长字符串的替换编辑距离就是汉明距离](images/bw90_q2_hamming_align.svg)

一次编辑只能「选一个位置，换成别的字母」，不能增删。于是把 `q` 变成 `d`（等长）：

- 每处 `q[i] ≠ d[i]` 的位置**必须**至少改一次（不改就不等）；
- 每次编辑至多修好一处（替换一个位置不影响其他位置）。

两者夹紧：最少编辑次数 = 不同位置的个数 = **汉明距离**。判定条件就是「逐位比较，不同处 $\le 2$ 即匹配」——一个计数循环，无需任何 DP。

### 3.3 算法流程

```text
ans = []
for q in queries:                       # 保持原顺序
    for d in dictionary:
        diff = 0
        for i in 0..n-1:
            if q[i] != d[i]: diff += 1
            if diff > 2: break          # 提前止损
        if diff <= 2:
            ans.append(q); break        # 命中一个即可，换下一个 query
返回 ans
```

两层循环 + 内层提前退出，最坏 $10^6$ 步。

### 3.4 示例演算

![示例 1 的逐位比较演算](images/bw90_q2_example_walkthrough.svg)

以 `"ants"` 对照 `"wood"` 为例（其余同理）：

```text
位置:      0    1    2    3
ants:      a    n    t    s
wood:      w    o    o    d
不同:      ✓    ✓    ✓    ✓     → diff = 4 > 2，提前退出，不匹配
```

`"word"` vs `"wood"` 只有位置 1（r/o）不同，`diff = 1 ≤ 2` 命中；`"note"` vs `"joke"` 位置 0、2 不同，`diff = 2` 恰好命中；`"wood"` vs `"wood"` 零编辑命中。三个命中按 `queries` 原顺序输出 `["word","note","wood"]`。

## 4. 算法细节

1. **「至多两次」含 0、1、2 三档**：字典里现成的单词（0 处）也算；边界 `diff == 2` 要用 `<=` 而非 `<`。
2. **提前止损**：内层统计一旦 `diff > 2` 立即 `break`；命中一个字典词后外层也 `break`（题目只需判定存在性，不必找最优匹配）。
3. **返回顺序**：遍历 `queries` 的顺序天然保证输出有序，别先排序再比对。
4. **位运算加速（可选）**：把每个单词按 26 bit × n 的位图存好、用按位异或 + popcount 算汉明距离，可将内层循环压缩成几个字操作；本题规模完全用不上，仅作思路备忘。官方标签里的 **Trie** 同理：在字典树上 DFS 维护「已用编辑数 ≤ 2」也能判定，是数据范围放大后的出路（§相关题目）。
5. **复杂度红线**：$O(Q \cdot D \cdot n) = 10^6$；若把 $n$、$Q$、$D$ 各放大到 $10^5$ 量级，需要 Trie 剪枝或位并行。

## 5. 正确性证明

**引理 1（替换编辑距离 = 汉明距离）**：设 $s$、$t$ 等长为 $n$，每次编辑可把 $s$ 的任一位置换成任意字母。则把 $s$ 变成 $t$ 的最少编辑次数 $= H(s, t)$，其中 $H$ 为不同位置个数。

**证明**：下界：对每个 $s[i] \ne t[i]$ 的位置，最终必须在该位置上发生一次「换掉原字母」的编辑（编辑是逐位置替换，不改变其他位置），而不同位置所需的编辑互不相同，故编辑次数 $\ge H(s,t)$。上界：对每个 $s[i] \ne t[i]$ 的位置执行一次编辑 $s[i] \to t[i]$（替换成什么字母不受限），$H(s,t)$ 次后 $s = t$。两个方向夹紧得等号。∎

**引理 2（判定的单调性）**：`q` 至多两次编辑可变成 `d` ⟺ $H(q, d) \le 2$。

**证明**：由引理 1，最少编辑次数即 $H(q,d)$，「至多两次」即该值 $\le 2$。∎

**定理（算法正确性）**：按 §3.3 输出的集合恰为 $\{\,q \in \text{queries} : \exists\, d \in \text{dictionary},\ H(q, d) \le 2\,\}$，且保持 `queries` 中的相对顺序。

**证明**：外层按 `queries` 顺序遍历，输出保序。对每个 $q$，内层枚举全部 $d$，由引理 2 逐对判定的结果与存在量词一致；「命中即 break」不改变存在性结论。∎

## 6. 复杂度分析

- **时间**：$O(Q \cdot D \cdot n)$，本题即 $10^6$ 次字符比较；提前止损在平均情形下大幅减少常数。
- **空间**：$O(1)$ 额外空间（不计返回数组）；无需建哈希、建 Trie。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<string> twoEditWords(vector<string>& queries, vector<string>& dictionary) {
        vector<string> ans;
        for (const string& q : queries) {
            for (const string& d : dictionary) {   // 长度相等，逐位比较即可
                int diff = 0;
                for (int i = 0; i < (int)q.size() && diff <= 2; ++i)
                    if (q[i] != d[i]) ++diff;
                if (diff <= 2) {                   // 编辑距离即不同位置数
                    ans.push_back(q);
                    break;
                }
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def twoEditWords(self, queries: list, dictionary: list) -> list:
        ans = []
        for q in queries:
            for d in dictionary:                    # 长度相等，逐位比较即可
                if sum(a != b for a, b in zip(q, d)) <= 2:
                    ans.append(q)
                    break
        return ans
```

> 💡 两份代码均通过官方示例（`["word","note","wood"]`、`[]`），并在 1000 组随机数据（字母表缩小到 `abc` 放大碰撞概率）下与独立实现的暴力一致。

## 8. 边界情况与易错点

1. **别写通用编辑距离 DP**：等长 + 只许替换时，$O(n^2)$ DP 不仅慢，还容易在初始化上出错；汉明距离一个循环完事。反之，若题目允许插入/删除，汉明距离立刻失效——先确认操作集。
2. **`<= 2` 不是 `< 2`**：示例里 `"note"→"joke"` 恰好 2 处也要收进来。
3. **零编辑**：字典中的原词命中（`"wood"`），别把「完全相同」排除在两次编辑之外。
4. **提前退出的边界**：C++ 版把 `diff <= 2` 写进循环条件做止损；Python 的 `sum(...)` 生成器虽然不提前退出，但短词下差异可忽略。
5. **输出顺序**：必须按 `queries` 原序；若先建「字典词 → 集合」再遍历，注意仍然要按 `queries` 顺序判定输出。
6. **空字典 / 空查询**：约束保证至少 1 个元素，但若放宽约束，空 `dictionary` 应返回空列表——双层循环天然如此。
