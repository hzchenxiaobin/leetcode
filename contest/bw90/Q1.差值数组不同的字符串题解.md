# LeetCode 差值数组不同的字符串 题解

## 1. 题目概述

- **标题 / 题号**：差值数组不同的字符串（#2451，easy）
- **链接**：https://leetcode.cn/problems/odd-string-difference/
- **来源**：LeetCode 第 90 场双周赛 Q1
- **难度**：简单
- **标签**：数组、哈希表、字符串

**题意**：给定字符串数组 `words`，所有字符串长度相同（设为 $n$）。每个字符串 `words[i]` 对应一个长度 $n-1$ 的**差值整数数组**：`difference[i][j] = words[i][j+1] - words[i][j]`（字母按 $a=0,\dots,z=25$ 编号）。已知 `words` 中**恰有一个**字符串的差值数组与其余全部不同，返回这个异类字符串。

**约束**：

- $3 \le \text{words.length} \le 100$
- $2 \le n \le 20$
- 只含小写字母，且保证异类恰有一个

## 2. 示例

**示例 1**

```text
输入：words = ["adc","wzy","abc"]
输出："abc"
解释：adc → [3,−1]，wzy → [3,−1]，abc → [1,1]。
      差值数组 [1,1] 只出现一次，返回 "abc"。
```

**示例 2**

```text
输入：words = ["aaa","bob","ccc","ddd"]
输出："bob"
解释：aaa/ccc/ddd → [0,0]，bob → [13,−13]。
```

**补充：异类在首位**

```text
输入：words = ["bob","aaa","ccc","ddd"]
输出："bob"
解释：aaa/ccc/ddd → [0,0]（多数派），bob → [13,−13] 落在首位。
      若实现只认「与第一个不同者」，异类排第一时会被漏判。
```

## 3. 解题思路

### 3.1 暴力思路

对每对字符串 $(i, j)$ 逐一比较差值数组，看谁的差值「与众不同」——$O(k^2 \cdot n)$ 且逻辑绕：不知道谁对谁错时，两两比较无法直接仲裁。更朴素地，把每个差值数组与「第一个」比较，统计不同者，再从数量上判断多数派——可行但容易在异类恰好排第一时写出反直觉的 bug。

### 3.2 核心观察：差值数组做键，哈希分组即见异类

![核心观察：差值数组做键，哈希分组，孤组即异类](images/bw90_q1_diff_grouping.svg)

把每个字符串的**差值数组（差值元组）**当作哈希键，把下标聚进桶里。因为恰有一个异类：

- 多数派至少有 $k - 1 \ge 2$ 个成员，聚成一个大小 $\ge 2$ 的桶；
- 异类独自成一个大小恰为 1 的桶。

于是「返回孤桶对应的字符串」即可。这也解释了为什么暴力两两比较别扭：**桶的大小**天然携带了「谁是多数」的投票信息，而两两比较需要额外的仲裁逻辑。

### 3.3 算法流程

```text
1. groups = 空哈希表（键：差值元组，值：下标列表）
2. for i, w in words:
       key = (w[1]−w[0], w[2]−w[1], ..., w[n−1]−w[n−2])
       groups[key].append(i)
3. 遍历所有桶：找到大小为 1 的桶，返回 words[桶中下标]
```

一次建表、一次扫桶，$O(k \cdot n)$。

### 3.4 示例演算

![示例一与示例二的分组演算](images/bw90_q1_example_walkthrough.svg)

以示例 1 为例：

| 字符串 | 差值数组（键） | 哈希桶 |
|--------|---------------|--------|
| `adc` | $[3, -1]$ | $\{0, 1\}$（与 `wzy` 同键） |
| `wzy` | $[3, -1]$ | ↑ |
| `abc` | $[1, 1]$ | $\{2\}$ ← 大小为 1，返回 `"abc"` |

示例 2 中 `[0,0]` 桶大小 3、`[13,-13]` 桶大小 1，返回 `"bob"`。两条规则顺带说明了鲁棒性：无论异类在开头、中间还是结尾，桶大小判定都不受位置影响。

## 4. 算法细节

1. **差值要用元组（tuple）做键**：Python 的 `list` 不可哈希，需 `tuple(...)`；C++ 用 `vector<int>` 配 `map`（`vector` 支持 `operator<`），或把差值编码成单个字符串/整数更快。
2. **差值域是 $[-25, 25]$**：可用偏移 $+26$ 压到 $[1, 51]$，把整条差值数组编码成 51 进制大整数（$n \le 20$，每项 6 bit，64 位以内），即把哈希键降为 `long long`——本文规模下两种做法都绰绰有余，参考代码取直观版。
3. **返回孤桶**：遍历桶找 `size == 1`；由题面保证存在且唯一，不必处理「全同」（无孤桶）的非法输入，但写一句兜底返回空串更稳。
4. **O(1) 空间替代**：只比较前两个的差值——若相同，多数派即它，扫一遍找不同者；若不同，两者之一是异类，用第三个的差值仲裁谁是多数派。适合追求常数空间的写法（§8 有详述）。
5. **负数差值的语言坑**：C++ 的 `char` 可能是有符号的，`w[j+1] - w[j]` 得到的负数没问题，但**不要**把差值直接存回 `char` 类型再比较（溢出/符号截断）；Python 中 `ord()` 转换后做差最稳。

## 5. 正确性证明

**引理 1（同构不变量）**：两个字符串 `s`、`t` 的差值数组相等，当且仅当存在整数 $c$ 使 $t[j] = s[j] + c$（对每个位置 $j$，字母移位后同加减 $c$，且不越出字母表）。

**证明**：差值数组相等即 $t[j+1] - t[j] = s[j+1] - s[j]$ 对所有 $j$，累加得 $t[j] - t[0] = s[j] - s[0]$，即 $t[j] = s[j] + (t[0] - s[0])$，取 $c = t[0] - s[0]$。反之显然。∎

**引理 2（桶大小的二分性）**：题面保证恰有一个异类。则按差值数组分组后，恰有两个不同的桶，其大小分别为 $1$ 与 $k - 1 \ge 2$。

**证明**：设异类为 $w^*$，其余 $k - 1$ 个字符串差值数组全相同，聚成同一个桶，大小 $k - 1 \ge 2$（因 $k \ge 3$）。$w^*$ 的差值数组与其余都不同，故不落入该桶；又只有它一个在此键上，其桶大小为 1。桶总数恰为 2。∎

**定理（算法正确性）**：返回唯一的大小为 1 的桶所对应的字符串，即为异类。

**证明**：由引理 2，大小为 1 的桶存在且唯一，对应字符串 $w^*$；由引理 2 前半，$w^*$ 恰是差值数组与众不同的那个，符合题目要求。∎

## 6. 复杂度分析

- **时间**：$O(k \cdot n)$。每个字符串求差值数组 $O(n)$、哈希插入均摊 $O(n)$（键长 $n-1$）；扫桶 $O(k)$。$k \le 100$、$n \le 20$，总量微不足道。
- **空间**：$O(k \cdot n)$。哈希表存 $k$ 个长度 $n - 1$ 的键；O(1) 空间仲裁法（§4 第 4 条）可省到 $O(n)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    string oddString(vector<string>& words) {
        map<vector<int>, vector<int>> groups;      // 差值数组 -> 下标列表
        for (int i = 0; i < (int)words.size(); ++i) {
            vector<int> d;
            const string& w = words[i];
            for (int j = 0; j + 1 < (int)w.size(); ++j)
                d.push_back(w[j + 1] - w[j]);
            groups[d].push_back(i);
        }
        for (auto& [d, idx] : groups)
            if ((int)idx.size() == 1) return words[idx[0]];
        return "";                                 // 题目保证存在，不会到达
    }
};
```

### Python

```python
class Solution:
    def oddString(self, words: list) -> str:
        groups = {}                                 # 差值元组 -> 下标列表
        for i, w in enumerate(words):
            key = tuple(ord(w[j + 1]) - ord(w[j]) for j in range(len(w) - 1))
            groups.setdefault(key, []).append(i)
        for idx in groups.values():
            if len(idx) == 1:
                return words[idx[0]]
        return ""                                   # 题目保证存在，不会到达
```

> 💡 两份代码均通过官方示例（`"abc"`、`"bob"`），并在 2000 组随机构造（多数派同键 + 恰一异类，异类位置随机）下与暴力分组仲裁一致。

## 8. 边界情况与易错点

1. **异类排在最前**：`["abm","abz","aby"]` 这类输入里，若实现只比较「与第一个不同」就直接返回，遇到异类在首位时会误伤——哈希分桶天然免疫，逐个比较法则需引理 2 式的仲裁（用第三个字符串投票）。
2. **$n = 2$ 最短**：差值数组长度仅 1，哈希键退化为单元素元组；`words.length = 3` 时两桶大小为 `1` 与 `2`，照常成立。
3. **`list` 不能做 Python 字典键**：必须 `tuple()`；忘了转会在运行时报 `unhashable type`。
4. **C++ 有符号 char 陷阱**：`w[j+1] - w[j]` 结果是 `int`，安全；但若贪快把差值塞回 `string`/`char` 存储，负数会截断，比较出错。
5. **「不同」的定义是整条差值数组**：不是「差值的和」也不是「字典序不同」——例如 `[1,2]` 与 `[2,1]` 的和相同但数组不同，是两个不同的键。
6. **题面保证恰一个异类**：若输入可能「全同」（无异类），孤桶不存在，代码会走到兜底返回；面试中应主动确认这一前置条件的处理策略。
