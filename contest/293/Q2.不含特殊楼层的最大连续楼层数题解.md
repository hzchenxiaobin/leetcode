# LeetCode 不含特殊楼层的最大连续楼层数 题解

## 1. 题目概述

- **标题 / 题号**：不含特殊楼层的最大连续楼层数（#2274，medium）
- **链接**：https://leetcode.cn/problems/maximum-consecutive-floors-without-special-floors/
- **来源**：LeetCode 第 293 场周赛 Q2
- **难度**：中等
- **标签**：数组、排序

**题意**：Alice 租下从 `bottom` 到 `top`（闭区间）的所有楼层，其中 `special[i]` 被指定为**特殊楼层**（仅用于放松）。要求返回**不含特殊楼层**的**最大连续楼层数**——即在 $[\text{bottom}, \text{top}]$ 上找一段最长的连续整数区间，使得区间内没有任何 `special` 中的值。

**约束**：

- $1 \le \text{special.length} \le 10^5$
- $1 \le \text{bottom} \le \text{special}[i] \le \text{top} \le 10^9$
- `special` 中的所有值**互不相同**

> 💡 **本题的胜负手**：值域高达 $10^9$，但特殊楼层至多 $10^5$ 个——信息集中在**稀疏的点**上，而不是整条数轴上。识别出这一点，就自然走向「排序 + 相邻空隙」的离散化视角，而不是逐层扫描。

## 2. 示例

**示例 1**

```text
输入：bottom = 2, top = 9, special = [4,6]
输出：3
解释：不含特殊楼层的连续楼层范围有：
- (2, 3) ，楼层数为 2
- (5, 5) ，楼层数为 1
- (7, 9) ，楼层数为 3
因此返回最大连续楼层数 3。
```

**示例 2**

```text
输入：bottom = 6, top = 8, special = [7,6,8]
输出：0
解释：每层楼都被规划为特殊楼层，所以返回 0。
```

**示例 3（自拟，覆盖"特殊楼层占据两端端点"）**

```text
输入：bottom = 1, top = 10, special = [1,3,10]
输出：6
解释：bottom 和 top 本身是特殊楼层；非特殊连续段只有 [2,2]（长 1）与 [4,9]（长 6），返回 6。
```

## 3. 解题思路

### 3.1 暴力思路：逐层扫描

用一个集合存下 `special`，从 `bottom` 逐层走到 `top`：非特殊楼层累加当前连续长度，特殊楼层归零并更新最大值——一趟 $O(\text{top} - \text{bottom} + n)$ 出答案。

- 本题 $\text{top} - \text{bottom}$ 可达 $10^9$，逐层循环**必然超时**；开值域布尔数组也一样爆空间。
- 浪费在哪？$10^9$ 层楼里只有 $\le 10^5$ 层是特殊的，**其余楼层全是"背景板"**——一段中间没有任何隔板的连续楼层，本身就是一个整体，逐层数它毫无必要。

> 💡 **关键观察**：决定连续段划分的只有**特殊楼层的相对位置**和**两端边界**。只要知道相邻两块"隔板"各在哪，中间这段的长度就是一个减法。

### 3.2 核心观察：特殊楼层是隔板，排序后看相邻空隙

把 `special` **升序排序**成 $s_0 < s_1 < \cdots < s_{n-1}$。这些特殊楼层像隔板一样，把 $[\text{bottom}, \text{top}]$ 切成至多 $n+1$ 段**不含特殊楼层的极大连续段**：

- **头段**：$[\text{bottom},\ s_0 - 1]$，长度 $s_0 - \text{bottom}$；
- **中间段**（$0 \le i < n-1$）：$[s_i + 1,\ s_{i+1} - 1]$，长度 $s_{i+1} - s_i - 1$；
- **尾段**：$[s_{n-1} + 1,\ \text{top}]$，长度 $\text{top} - s_{n-1}$。

答案就是这至多 $n+1$ 个长度中的最大值（空段长度为 0，不干扰 $\max$）。

![核心观察：特殊楼层是隔板，隔出空隙](images/wc293_q2_max_gap_concept.svg)

**统一视角（哨兵法）**：在序列两端各放一个**虚拟隔板** $\text{bottom} - 1$ 与 $\text{top} + 1$（它们不在租用范围内、天然不可能是特殊楼层），则头、中、尾三类段化为同一个公式——相邻隔板 $a, b$ 之间的空隙长度恒为 $b - a - 1$。三段分写与哨兵统一是同一思路的两种实现，比赛时哨兵法代码最短、最不容易错。

> ⚠️ **"$-1$" 从哪来**：中间段两侧**都是隔板（不含）**，覆盖 $[a+1, b-1]$，长度 $(b-1)-(a+1)+1 = b-a-1$；头段含 `bottom`、尾段含 `top`（边界不是隔板），故不减 1。哨兵法把边界也变成隔板，公式就统一了。

### 3.3 算法流程：排序 + 一趟扫描

![算法流程：排序 + 哨兵一趟扫描](images/wc293_q2_sort_gaps_flow.svg)

1. **排序**：`special` 升序排序，$O(n \log n)$；
2. **初始化**：`prev = bottom - 1`（左哨兵），`ans = 0`；
3. **扫描**：对每个 $s$，更新 $\text{ans} = \max(\text{ans},\ s - \text{prev} - 1)$，再令 $\text{prev} = s$；
4. **收尾**：补上尾段 $\text{ans} = \max(\text{ans},\ \text{top} - \text{prev})$（等价于右哨兵 $\text{top} + 1$ 与最后一个隔板的空隙）；
5. **返回** `ans`。

### 3.4 示例演算

以自拟的示例 3 演算：`bottom = 1, top = 10, special = [1, 3, 10]`，排序后仍为 `[1, 3, 10]`，加上哨兵 $0$ 与 $11$ 后，相邻隔板对共 4 组：

| 相邻隔板 $a \to b$ | 空隙段 | 长度 $b - a - 1$ |
|---|---|---|
| $0 \to 1$（左哨兵） | 空 | $0$ |
| $1 \to 3$ | $[2, 2]$ | $1$ |
| $3 \to 10$ | $[4, 9]$ | $\mathbf{6}$ ★ |
| $10 \to 11$（右哨兵） | 空 | $0$ |

$\text{ans} = \max(0, 1, 6, 0) = 6$，对应楼层 $[4, 9]$。

![示例演算：bottom=1, top=10, special=[1,3,10]](images/wc293_q2_gap_walkthrough.svg)

再验证示例 1：`bottom=2, top=9, special=[4,6]`，头段 $4-2=2$、中间段 $6-4-1=1$、尾段 $9-6=3$，$\max = 3$ ✓。示例 2 中排序后 `[6,7,8]`，头尾与中间段全部为 $0$，答案 $0$ ✓（全特殊时公式自然收敛，无需特判）。

## 4. 算法细节

1. **为什么必须先排序**：「相邻特殊楼层之间的空隙」只在**有序**序列中有定义。未排序时 `special` 里相邻两个元素在数轴上可能相距甚远，直接做差毫无意义。排序让"数轴上紧邻"与"数组中相邻"重合。
2. **两种等价写法**：
   - **三段式**：头段 $\times 1$ + 中间段 $\times (n-1)$ + 尾段 $\times 1$，各自套公式后取 $\max$；
   - **哨兵式**：`prev` 从 $\text{bottom}-1$ 起步，循环内统一 $s - \text{prev} - 1$，循环后补 $\text{top} - \text{prev}$。推荐哨兵式——分支最少，比赛敲得快、错不了。
3. **空段不需要特判**：$s_0 = \text{bottom}$ 时头段为 $0$；$s_{n-1} = \text{top}$ 时尾段为 $0$；$s_{i+1} = s_i + 1$ 时中间段为 $0$。长度都是非负数，$\max$ 自然吞掉，**任何特判反而容易画蛇添足**。
4. **$n = 1$**：循环体执行一次，得到头段 $s_0 - \text{bottom}$；收尾得到尾段 $\text{top} - s_0$。正确。
5. **溢出分析**：$\text{top} \le 10^9$，任意两个数的差 $< 10^9 < 2^{31} - 1 \approx 2.1 \times 10^9$，**32 位 `int` 安全**。但若值域升到 $10^{18}$（变体题常见），必须换 `long long`——顺手养成"做差先想类型"的习惯。
6. **允许原地排序**：`special` 是可修改的参数，直接 `sort` 不需要拷贝，额外空间 $O(1)$（不计排序栈）。

## 5. 正确性证明

**引理 1（极大段的结构刻画）**：设排序后 $s_0 < s_1 < \cdots < s_{n-1}$。区间 $[\text{bottom}, \text{top}]$ 上不含特殊楼层的**极大连续段**（无法向两侧扩展的连续非特殊段）恰为下列至多 $n+1$ 段（空段自动消失）：

$$[\text{bottom},\ s_0 - 1],\quad [s_i + 1,\ s_{i+1} - 1]\ (0 \le i < n - 1),\quad [s_{n-1} + 1,\ \text{top}]$$

**证明**：分三步。

（**无特殊性**）先证每段（若非空）内不含特殊楼层。取中间段内的整数 $x$，有 $s_i < x < s_{i+1}$；若 $x$ 是特殊楼层，则 $x = s_j$ 且 $j \notin \{i, i+1\}$，与排序后 $s_i < s_j < s_{i+1}$ 矛盾（$i$ 与 $i+1$ 之间不存在别的下标）。头段内 $x < s_0$、尾段内 $x > s_{n-1}$，而 $s_0$、$s_{n-1}$ 分别是最小、最大的特殊楼层，故亦无特殊楼层。

（**极大性**）中间段的左邻 $s_i$、右邻 $s_{i+1}$ 均为特殊楼层；头段左邻 $\text{bottom} - 1$ 越界、右邻为 $s_0$；尾段左邻为 $s_{n-1}$、右邻 $\text{top} + 1$ 越界。每个非空段的两侧（若在范围内）都被特殊楼层封死或直接越界，无法扩展。

（**无遗漏**）任何非特殊楼层 $x \in [\text{bottom}, \text{top}]$：特殊楼层集合恰为 $\{s_0, \ldots, s_{n-1}\}$（互异性保证排序后严格递增、无重复），$x$ 不在其中，则 $x$ 必落在排序序列的某个空隙里，即属于上列某段。故这些段之并恰为全体非特殊楼层，且两两不相交 □

**引理 2（长度公式）**：引理 1 中各段的长度依次为 $s_0 - \text{bottom}$、$s_{i+1} - s_i - 1$、$\text{top} - s_{n-1}$，且均 $\ge 0$。

**证明**：整数区间 $[l, r]$ 的长度为 $r - l + 1$，代入三组端点即得。由排序与约束 $\text{bottom} \le s_0$、$s_{n-1} \le \text{top}$、$s_i < s_{i+1}$，三个表达式都非负；为空段时取值恰为 $0$ □

**定理**：所求最大连续楼层数等于

$$\max\Big(s_0 - \text{bottom},\ \max_{0 \le i < n-1}\big(s_{i+1} - s_i - 1\big),\ \text{top} - s_{n-1}\Big)$$

且哨兵式算法输出的正是该值。

**证明**：任何不含特殊楼层的连续段都**包含于**某个极大段（把它向两侧扩展到无法扩展，即得包含它的极大段），因此最长非特殊连续段的长度等于极大段长度的最大值。由引理 1，极大段恰为所列 $n+1$ 段；由引理 2，其长度恰为所列 $n+1$ 个表达式。哨兵式算法从左到右依次对每对相邻隔板（含两个哨兵）计算 $b - a - 1$ 并取 $\max$，恰好遍历这 $n+1$ 个值 ∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \log n)$。排序主导 $O(n \log n)$，一趟扫描 $O(n)$。$n \le 10^5$，约 $1.7 \times 10^6$ 次比较，毫秒级。
- **空间复杂度**：$O(1)$ 额外空间（C++ `std::sort` 原地，递归栈 $O(\log n)$；Python Timsort 需 $O(n)$ 临时数组）。只用 `ans`、`prev` 两个标量。

> 💡 暴力 $O(\text{top} - \text{bottom})$ 在 $10^9$ 级别不可行；排序把"整条轴"压缩到"稀疏点集"上处理，是典型的**离散化**优化——值域大小不再进入复杂度。

## 7. 参考代码

### C++（哨兵式）

```cpp
class Solution {
  public:
    int maxConsecutive(int bottom, int top, vector<int>& special) {
        sort(special.begin(), special.end());
        int ans = 0, prev = bottom - 1; // 左哨兵
        for (int s : special) {
            ans = max(ans, s - prev - 1); // 中间隔板对（含左哨兵）
            prev = s;
        }
        ans = max(ans, top - prev); // 尾段 = (top+1) - prev - 1
        return ans;
    }
};
```

### Python（哨兵式 + 比赛最短版）

```python
class Solution:
    def maxConsecutive(self, bottom: int, top: int, special: List[int]) -> int:
        special.sort()
        ans, prev = 0, bottom - 1
        for s in special:
            ans = max(ans, s - prev - 1)
            prev = s
        return max(ans, top - prev)
```

比赛向最短版——直接把两个哨兵塞进数组，所有相邻对一视同仁：

```python
class Solution:
    def maxConsecutive(self, bottom: int, top: int, special: List[int]) -> int:
        special += [bottom - 1, top + 1]
        special.sort()
        return max(b - a - 1 for a, b in zip(special, special[1:]))
```

> ⚠️ 约束保证 `special` 非空且元素都在 $[\text{bottom}, \text{top}]$ 内，故无需空数组特判；各值 $\le 10^9$、差值 $< 10^9$，`int` 足够（见 §4.5）。

## 8. 边界情况与易错点

1. **忘排序**：`special` 无序时相邻元素之差不代表任何空隙，头/尾段也会取错。排序是正确性的前提（引理 1 依赖有序性）。
2. **中间段忘减 1**：$s_{i+1} - s_i$ 把右侧隔板楼层本身也算进去了，每个中间段多算 1。
3. **头尾段多减了 1**：把 `bottom`/`top` 误当成隔板。示例 1 中头段是 $4 - 2 = 2$（楼层 2、3），误写成 $4 - 2 - 1 = 1$ 就错了。
4. **`ans` 初值**：长度非负，初始化为 $0$ 安全；千万别初始化成 `INT_MIN` 之外的负哨兵再忘记覆盖——空段情形（全特殊）会返回错误值。
5. **special 覆盖端点 / 全特殊**：`special[0] == bottom`、`special[-1] == top`、甚至 $n = \text{top} - \text{bottom} + 1$（示例 2）时，公式自然给出 $0$，**不需要特判**。
6. **$n = 1$**：无中间段，只剩头段与尾段两个候选。
7. **不要开值域数组**：$10^9$ 的桶/`bitset` 直接 MLE；逐层循环 TLE。这题考的就是跳出"逐层"思维。
8. **做差的类型**：本题 `int` 安全，但值域上抬（如 $10^{18}$）即需 `long long` / Python 无此忧。

**延伸思考**：

- **在线版**：若 `special` 逐个加入、每次插入后询问当前最大空隙——用有序集合维护隔板，再用一个**对顶堆/多重集合**维护相邻差的最大值（延迟删除），即可 $O(\log n)$ 每次操作。
- **多区间租用版**：若楼层是若干不相交区间 $[\text{bottom}_i, \text{top}_i]$ 的并集，先把区间排序合并，再与排序后的 `special` 双指针同步推进，套用同一套头/中/尾空隙公式。
- **约束版**：求**恰好含 $k$ 个特殊楼层**的最长连续段——对排序后的 `special` 做长度为 $k$ 的滑动窗口，窗口两端向外延伸到相邻隔板，取最大跨度。
