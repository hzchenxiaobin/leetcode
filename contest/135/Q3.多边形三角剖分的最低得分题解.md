# LeetCode 多边形三角剖分的最低得分 题解

## 1. 题目概述

- **标题 / 题号**：多边形三角剖分的最低得分（#1039，medium）
- **链接**：https://leetcode.cn/problems/minimum-score-triangulation-of-polygon/
- **来源**：LeetCode 第 135 场周赛 Q3
- **难度**：中等
- **标签**：数组、动态规划、多边形、三角剖分

**题意**：给定凸 $n$ 边形顶点值 `values[i]`（按**顺时针**顺序给出）。用 $n-3$ 条不相交的对角线把它剖分成 $n-2$ 个三角形。每个三角形的得分是三个顶点值之积，剖分总得分为所有三角形得分之和。求**最小**总得分。

**约束**：

- $n = \text{values.length}$，$3 \le n \le 50$
- $1 \le \text{values}[i] \le 100$

**关键概念**：任意一个合法的三角剖分中，多边形的每条边（包括边界边与对角线）都**恰好属于一个三角形**。固定一条边后，枚举它的对角顶点，就能把大问题拆成两个互不影响的子多边形——这是区间 DP 的入口。

## 2. 示例

**示例 1**

```text
输入：values = [1,2,3]
输出：6
解释：n = 3，本身就是三角形，唯一得分 1×2×3 = 6。
```

**示例 2**

```text
输入：values = [3,7,4,5]
输出：144
解释：四边形只有两种剖分：
      连 (0,2)：3·7·4 + 3·4·5 = 84 + 60 = 144；
      连 (1,3)：7·4·5 + 3·7·5 = 140 + 105 = 245。取 144。
```

**示例 3**

```text
输入：values = [1,3,1,4,1,5]
输出：13
解释：最优剖分的四个三角形得分为 1·1·3、1·1·4、1·1·5、1·1·1，合计 13。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有三角剖分方案再取最小值。$n$ 个顶点的凸多边形剖分数是第 $n-2$ 个**卡特兰数**，$n = 50$ 时约为 $10^{27}$ 量级，完全不可行。即便写成记忆化搜索，也必须先把问题定义成「区间」，否则无法复用子解。

### 3.2 核心观察：固定一条边，枚举第三个顶点

![固定边 (i,j) 枚举第三个顶点](images/wc135_q3_interval_dp.svg)

设当前处理的子多边形是顶点区间 $[i, j]$（沿顺时针从 $i$ 到 $j$ 的连续顶点，且 $j \ge i+2$）。考虑多边形的边

$$(i,\ j)$$

它必然属于某个三角形，设该三角形第三个顶点为 $k$（$i < k < j$）。这条三角形把子多边形 $[i, j]$ 拆成：

- 三角形 $(i, k, j)$，得分 $values[i] \cdot values[k] \cdot values[j]$；
- 子多边形 $[i, k]$；
- 子多边形 $[k, j]$。

三个部分互不重叠、覆盖全部顶点，于是

$$dp[i][j] = \min_{i < k < j} \Bigl( dp[i][k] + dp[k][j] + values[i] \cdot values[k] \cdot values[j] \Bigr)$$

边界：$j - i < 2$ 时区间不是多边形（只是边或点），$dp[i][j] = 0$。答案 $dp[0][n-1]$。

### 3.3 算法流程

```text
1. n = len(values)，dp 为 n × n 的全 0 表
2. for span = 2 .. n-1:              # span = j - i，从短到长
       for i = 0 .. n-span-1:
           j = i + span
           dp[i][j] = min over k ∈ (i, j) of
                      dp[i][k] + dp[k][j] + values[i]*values[k]*values[j]
3. 返回 dp[0][n-1]
```

$span$ 从小到大的枚举顺序保证：计算 $dp[i][j]$ 时，$dp[i][k]$ 与 $dp[k][j]$ 的区间长度都严格小于 $span$，已经算好。

### 3.4 示例演算

![示例 2 的两种剖分](images/wc135_q3_example_walkthrough.svg)

对 `values = [3,7,4,5]`：

| 区间 | 转移 | 值 |
|------|------|-----|
| $[0,2]$ | $k=1$：$0+0+3\cdot7\cdot4$ | 84 |
| $[1,3]$ | $k=2$：$0+0+7\cdot4\cdot5$ | 140 |
| $[0,3]$ | $k=1$：$dp[0][1]+dp[1][3]+3\cdot7\cdot5 = 0+140+105$ | 245 |
| $[0,3]$ | $k=2$：$dp[0][2]+dp[2][3]+3\cdot4\cdot5 = 84+0+60$ | **144** |

取最小值 144，与示例一致。$k=1$ 对应连对角线 $(1,3)$，$k=2$ 对应连对角线 $(0,2)$——每一个 $k$ 恰好对应一种「第一条对角线」的选择。

## 4. 算法细节

1. **区间语义**：$dp[i][j]$ 指「顶点 $i, i+1, \ldots, j$ 按顺时针构成的多边形」的最小得分；当 $j = i+1$ 时它退化成一条边，没有三角形，得分为 0。
2. **循环顺序**：外层必须是**区间长度**而不是起点或终点，否则子问题未就绪。等价写法是「外层 $i$ 从大到小、内层 $j$ 从小到大」。
3. **哨兵初值**：全表置 0 即可，因为长度 $< 2$ 的区间合法值就是 0；计算时用一个大数（C++ `INT_MAX`、Python `float('inf')`）作临时最小值，$k$ 至少有一个取值所以一定会被覆盖。
4. **数值范围**：单个乘积 $\le 100^3 = 10^6$，共 $n-2 \le 48$ 个三角形，总和 $\le 4.8\times10^7$，`int` 足够（Python 无溢出问题）。
5. **一维压缩不可行**：$dp[i][j]$ 同时依赖「左侧区间」和「右侧区间」，不像 LCS 那样只依赖上一行，故只能用二维表，空间 $O(n^2)$ 完全可以接受。

## 5. 正确性证明

**引理 1（边必属于唯一三角形）**：在 $[i,j]$（$j \ge i+2$）的任一合法三角剖分中，边 $(i,j)$ 恰属于其中一个三角形，且该三角形的第三个顶点 $k$ 满足 $i < k < j$；同时 $k$ 的两侧分别只剩子多边形 $[i,k]$ 与 $[k,j]$。

**证明**：边 $(i,j)$ 是多边形的一条边（$j = i+2$ 时是边界边，否则是对角线），三角剖分把多边形划分为若干三角形且互不重叠，边 $(i,j)$ 的每一侧最多属于一个三角形。$[i,j]$ 是一个封闭多边形（$j\ge i+2$），故它必被剖分成至少一个三角形，$(i,j)$ 至少属于其中一个。设该三角形为 $(i,k,j)$：由三角形的边必须是多边形的边或对角线，$k$ 必在 $i$ 与 $j$ 之间（顺时针方向）；挖去该三角形后，剩余部分被对角线 $(i,k)$ 与 $(k,j)$ 分成两个互不相交的多边形 $[i,k]$ 与 $[k,j]$，且它们各自的剖分与原剖分在其顶点集上一致。∎

**引理 2（最优子结构）**：若 $T$ 是 $[i,j]$ 的最优剖分，$k$ 是含边 $(i,j)$ 的三角形的第三个顶点，则 $T$ 在 $[i,k]$ 与 $[k,j]$ 上的限制分别是这两个子多边形的最优剖分。

**证明**：反证。若 $[i,k]$ 上存在得分更小的剖分 $T'$，把 $T$ 在 $[i,k]$ 上的部分替换为 $T'$，其余部分不变，得到的仍是 $[i,j]$ 的合法剖分（子多边形互不重叠、公共边 $(i,k)$ 两边一致），而总得分严格下降，与 $T$ 最优矛盾。$[k,j]$ 同理。∎

**引理 3（转移覆盖所有方案）**：对每个 $k \in (i,j)$，$dp[i][k] + dp[k][j] + values[i]values[k]values[j]$ 对应至少一种合法的 $[i,j]$ 剖分；且 $[i,j]$ 的每种剖分都被某个 $k$ 覆盖。

**证明**：给定 $k$，把 $[i,k]$ 的最优剖分与 $[k,j]$ 的最优剖分加上三角形 $(i,k,j)$ 拼接，得到一个 $[i,j]$ 的合法剖分（引理 1 的逆过程），故该表达式是某个合法剖分的得分，是上界方向。反过来，任取 $[i,j]$ 的一个剖分，由引理 1 它确定唯一的 $k$，其得分恰为「两个子剖分得分 + 三角形得分」，故被该 $k$ 的表达式覆盖。∎

**定理**：算法返回 $dp[0][n-1]$，等于整个多边形的最小三角剖分得分。

**证明**：对区间长度归纳。长度 $< 2$ 时无三角形，得分 0，正确。设长度更短的区间均已正确，则由引理 3，$dp[i][j]$ 的候选集恰好覆盖全部剖分的得分集合（且每个候选都可实现），由引理 2，最优剖分的两个子部分各自最优、已由归纳假设求出，故取最小值即得最短；最终 $dp[0][n-1]$ 为答案。∎

## 6. 复杂度分析

- **时间**：$O(n^3)$。区间数 $O(n^2)$，每个区间枚举 $O(n)$ 个 $k$；$n = 50$ 时约 $1.25\times10^5$ 次乘法。
- **空间**：$O(n^2)$ 的 `dp` 表（$50\times50$ 个整数，约 10 KB）。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int minScoreTriangulation(vector<int>& values) {
        int n = values.size();
        vector<vector<int>> dp(n, vector<int>(n, 0));
        for (int span = 2; span < n; span++) {              // 顶点跨度
            for (int i = 0; i + span < n; i++) {
                int j = i + span;
                int best = INT_MAX;
                for (int k = i + 1; k < j; k++) {           // 与边 (i,j) 组成三角形的第三个顶点
                    best = min(best, dp[i][k] + dp[k][j] + values[i] * values[k] * values[j]);
                }
                dp[i][j] = best;
            }
        }
        return dp[0][n - 1];
    }
};
```

### Python

```python
class Solution:
    def minScoreTriangulation(self, values: list[int]) -> int:
        n = len(values)
        INF = float('inf')
        dp = [[0] * n for _ in range(n)]
        for span in range(2, n):                 # 区间长度（顶点跨度）
            for i in range(n - span):
                j = i + span
                best = INF
                for k in range(i + 1, j):        # 枚举与边 (i, j) 组成三角形的第三个顶点
                    cand = dp[i][k] + dp[k][j] + values[i] * values[k] * values[j]
                    if cand < best:
                        best = cand
                dp[i][j] = best
        return dp[0][n - 1]
```

## 8. 边界情况与易错点

1. **$n = 3$ 退化**：只有一个三角形，直接返回 $values[0]\cdot values[1]\cdot values[2]$；代码中 $span$ 从 2 开始、$k$ 只取中间那一个顶点，自然正确。
2. **循环顺序错误**：把 $i$ 放最外层（不按长度）会用到尚未计算的 $dp[k][j]$。
3. **$k$ 的范围**：必须是开区间 $(i,j)$，即 `k = i+1 .. j-1`；取到端点会构造出退化三角形（面积为 0 的多边形），得分无意义。
4. **`INT_MAX` 加法溢出**：本例中先比较再相加是安全的（`min(best, 表达式)` 里表达式不会溢出，因为各项都远小于 $10^9$）；若把 `INT_MAX` 也拿去参与加法则会溢出，务必注意写法。
5. **顺时针 / 逆时针无关**：得分只依赖三个顶点值的乘积，顺序无关；但子问题的区间划分必须与给定顺序一致（即用下标区间），不能对数组排序。
6. **顶点值可能为 1**：此时乘积小，容易让「少切几个三角形」的方案看起来更优——DP 会自动处理，不需要特判。
