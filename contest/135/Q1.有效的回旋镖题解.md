# LeetCode 有效的回旋镖 题解

## 1. 题目概述

- **标题 / 题号**：有效的回旋镖（#1037，easy）
- **链接**：https://leetcode.cn/problems/valid-boomerang/
- **来源**：LeetCode 第 135 场周赛 Q1
- **难度**：简单
- **标签**：几何、数组、数学

**题意**：给定平面上三个点 `points[i] = [x_i, y_i]`。若这三点**两两不同**且**不在同一直线上**，则称它们构成一个**回旋镖**，返回 `true`；否则返回 `false`。

**约束**：

- `points.length == 3`
- `points[i].length == 2`
- $0 \le x_i, y_i \le 100$

**一句话转化**：三点构成回旋镖 $\iff$ 由三点拼出的三角形**面积非零**。

## 2. 示例

**示例 1**

```text
输入：points = [[1,1],[2,3],[3,2]]
输出：true
解释：叉积 (2−1)·(2−1) − (3−1)·(3−1) = 1 − 4 = −3 ≠ 0，三点不共线。
```

**示例 2**

```text
输入：points = [[1,1],[2,2],[3,3]]
输出：false
解释：三点在同一条直线 y = x 上，叉积为 0，面积为 0。
```

**补充示例（重合点）**

```text
输入：points = [[0,0],[0,0],[1,1]]
输出：false
解释：前两点重合，而「各不相同」是回旋镖的必要条件；叉积同样为 0，一次判定即可覆盖。
```

## 3. 解题思路

### 3.1 暴力思路

可以按两个条件逐条判：先用集合去重判断三点是否互异，再分别求两条直线的斜率 $k_1 = \frac{y_2-y_1}{x_2-x_1}$、$k_2 = \frac{y_3-y_1}{x_3-x_1}$ 并比较。麻烦在于**竖直线**（$\Delta x = 0$，斜率无穷大）必须特判，代码分支多且容易漏。

### 3.2 核心观察：叉积为 0 ⟺ 共线

![叉积就是带符号的平行四边形面积](images/wc135_q1_cross_product.svg)

取 $P_1$ 为基准，构造两个向量

$$\vec{v_1} = P_2 - P_1 = (x_2 - x_1,\ y_2 - y_1), \qquad \vec{v_2} = P_3 - P_1 = (x_3 - x_1,\ y_3 - y_1)$$

二维叉积

$$\vec{v_1} \times \vec{v_2} = (x_2 - x_1)(y_3 - y_1) - (x_3 - x_1)(y_2 - y_1)$$

的绝对值等于以 $\vec{v_1}, \vec{v_2}$ 为邻边的**平行四边形面积**，三角形面积为它的一半。因此

$$\text{三点共线} \iff \vec{v_1} \times \vec{v_2} = 0$$

这个判据**同时**解决了两个条件：若两点重合，则叉积必然为 0，所以「叉积非 0」已经蕴含了「三点互异」。一次乘法、一次减法就能给出答案，竖直线也不再是特例。

### 3.3 算法流程

```text
1. 取出 (x1,y1), (x2,y2), (x3,y3)
2. cross = (x2-x1)*(y3-y1) - (x3-x1)*(y2-y1)
3. 返回 cross != 0
```

### 3.4 示例演算

![三类输入与判定结果](images/wc135_q1_degenerate.svg)

| 输入 | 叉积 | 结论 | 原因 |
|------|------|------|------|
| `[[1,1],[2,3],[3,2]]` | $1\cdot1 - 2\cdot2 = -3$ | `true` | 真三角形 |
| `[[1,1],[2,2],[3,3]]` | $1\cdot2 - 2\cdot1 = 0$ | `false` | 三点共线 |
| `[[0,0],[0,0],[1,1]]` | $0\cdot1 - 1\cdot0 = 0$ | `false` | 两点重合 |

## 4. 算法细节

1. **基准点选择**：以 $P_1$ 为基准即可，因为「共线」与基准点选取无关；不必先排序或求凸包。
2. **数据类型**：坐标 $\le 100$，差 $\le 100$，乘积 $\le 10^4$，`int` 足够；但工程上写 `long long` 可以避免坐标范围变化时溢出。
3. **不要用浮点**：斜率/面积用 `double` 比较会引入精度问题（尤其接近共线时），叉积是整数运算，判定零误差。
4. **乘法顺序**：写成 `(x2-x1)*(y3-y1) - (x3-x1)*(y2-y1)`，注意两个乘积的**下标对应关系**，写反一个下标就会变成「永远不为 0」或「恒为 0」。
5. **重合点无需额外判断**：这是叉积写法的额外收益，见引理 2。

## 5. 正确性证明

**引理 1（叉积判共线）**：三点 $P_1, P_2, P_3$ 共线 $\iff \vec{v_1} \times \vec{v_2} = 0$，其中 $\vec{v_1} = P_2 - P_1$、$\vec{v_2} = P_3 - P_1$。

**证明**：$\lvert \vec{v_1} \times \vec{v_2} \rvert$ 等于以 $\vec{v_1}, \vec{v_2}$ 为邻边的平行四边形面积。

- ($\Rightarrow$) 若三点共线，则 $\vec{v_1}$ 与 $\vec{v_2}$ 共线，平行四边形退化，面积为 0，故叉积为 0。
- ($\Leftarrow$) 若叉积为 0，则平行四边形面积为 0，两向量共线（若某个向量为零向量，则对应的两点重合，自然共线），即 $P_1, P_2, P_3$ 在同一直线上。∎

**引理 2（叉积非零 $\Rightarrow$ 三点互异）**：若 $\vec{v_1} \times \vec{v_2} \ne 0$，则 $P_1, P_2, P_3$ 两两不同。

**证明**：若 $P_1 = P_2$，则 $\vec{v_1} = 0$，叉积为 0，与假设矛盾；若 $P_1 = P_3$，则 $\vec{v_2} = 0$，同理矛盾；若 $P_2 = P_3$，则 $\vec{v_1} = \vec{v_2}$，叉积为 $\vec{v_1} \times \vec{v_1} = 0$，同样矛盾。故三点互异。∎

**定理**：算法返回 `true` $\iff$ 输入三点构成回旋镖。

**证明**：由引理 2，叉积非零时三点互异，再由引理 1 的逆否命题，三点不共线——满足回旋镖的两个条件。反之若三点构成回旋镖，则三点互异且不共线，由引理 1 叉积非零，算法返回 `true`。∎

## 6. 复杂度分析

- **时间**：$O(1)$。四次减法、两次乘法、一次比较。
- **空间**：$O(1)$。只用到几个整型变量（Python 解包时额外用了常数个引用）。

## 7. 参考代码

### C++

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    bool isBoomerang(vector<vector<int>>& points) {
        long long x1 = points[0][0], y1 = points[0][1];
        long long x2 = points[1][0], y2 = points[1][1];
        long long x3 = points[2][0], y3 = points[2][1];
        // 叉积为 0 等价于三点共线（含重合点）
        return (x2 - x1) * (y3 - y1) - (x3 - x1) * (y2 - y1) != 0;
    }
};
```

### Python

```python
class Solution:
    def isBoomerang(self, points: list[list[int]]) -> bool:
        (x1, y1), (x2, y2), (x3, y3) = points
        return (x2 - x1) * (y3 - y1) - (x3 - x1) * (y2 - y1) != 0
```

## 8. 边界情况与易错点

1. **两点重合**：如 `[[0,0],[0,0],[1,1]]`，叉积为 0 → `false`，无需单独写去重逻辑，但要理解「为什么可以省」。
2. **竖直线**：`[[0,0],[0,1],[0,2]]` 用斜率法会除零崩溃，叉积法是整数乘法，天然安全。
3. **乘法下标写错**：`(x2-x1)*(y3-y1)` 与 `(x3-x1)*(y2-y1)` 必须成对，若写成 `(x2-x1)*(y3-y1) - (x2-x1)*(y2-y1)` 之类，示例依然能过但逻辑全错；建议背下「交叉相乘再相减」的记忆法。
4. **返回类型**：C++ 用 `!= 0` 显式转 `bool`，不要写 `return cross;`（隐式转换在负数上虽正确，但可读性差）。
5. **坐标范围放大时的溢出**：本题 $\le 100$ 不会溢出；若坐标到 $10^9$，乘积会到 $10^{18}$，必须用 `long long`。
