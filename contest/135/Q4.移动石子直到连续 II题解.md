# LeetCode 移动石子直到连续 II 题解

## 1. 题目概述

- **标题 / 题号**：移动石子直到连续 II（#1040，medium）
- **链接**：https://leetcode.cn/problems/moving-stones-until-consecutive-ii/
- **来源**：LeetCode 第 135 场周赛 Q4
- **难度**：中等
- **标签**：数组、数学、排序、滑动窗口

**题意**：数轴上有 $n$ 颗位置互不相同的石子，位置由 `stones` 给出。每回合，你可以拿起一颗**端点石子**（位于当前最左或最右的石子），把它搬到某个**未被占用**的位置，要求搬完之后**这颗石子不再是端点**。当所有石子占据连续位置时游戏结束。返回 `[最小移动次数, 最大移动次数]`。

**约束**：

- $3 \le \text{stones.length} \le 10^4$
- $1 \le \text{stones}[i] \le 10^9$
- `stones` 中元素互不相同

**与 1033 题的区别**：1033 题只有 3 颗石子，且允许端点石子搬到**任意**空位（包括成为新端点）；本题石子数可变，且**搬完后不能是端点**——正是这一条限制让最小步数多出一个需要特判的情形。

## 2. 示例

**示例 1**

```text
输入：stones = [7,4,9]
输出：[1, 2]
解释：一次移动 4 → 8 即得 7,8,9；或分两步 9 → 5、4 → 6 得到 5,6,7。
```

**示例 2**

```text
输入：stones = [6,5,4,3,10]
输出：[2, 3]
解释：最少两步：3 → 8（8 在 4 与 10 之间，不是端点），10 → 7，得到 4,5,6,7,8；
      最多三步：3 → 7、4 → 8、5 → 9 逐步逼近。注意 10 → 2 是非法移动
      （10 是端点，搬到 2 后它仍是端点）。
```

## 3. 解题思路

### 3.1 暴力思路

把「已占位置集合」当状态做 BFS 求最短、DFS 求最长。状态数随 $n$ 与坐标范围指数增长，$n = 10^4$、坐标 $10^9$ 时完全不可行；即便只在局部搜索，也无法覆盖「先把外面的石子搬进来、再把窗口整体平移」这类多步策略。

### 3.2 核心观察（最小步数）：长度为 n 的窗口

![滑动窗口求最小步数](images/wc135_q4_window_min.svg)

最终局面必然是**某个长度为 $n$ 的连续区间**（记作窗口 $W$）被石子填满。设初始时 $W$ 里已有 $c$ 颗石子，则：

- **下界**：每次移动只搬运一颗石子，故 $W$ 内的石子数每步最多增加 1，至少需要 $n - c$ 步。
- **上界**：只要 $W$ 内空位不少于 2 个，就能把外面的石子逐个搬进来，每步把 $W$ 内石子数加 1（详见引理 2）。

于是最小步数基本等于 $n - c^*$，其中

$$c^* = \max_{\text{长度 } n \text{ 的窗口}} \bigl\lvert \text{窗口内的石子数} \bigr\rvert$$

用**排序 + 双指针滑动窗口**即可 $O(n)$ 求出 $c^*$：固定左端点 $i$，让右端点 $j$ 尽量右移但保持 $stones[j] - stones[i] \le n - 1$。

**唯一的例外**：若某个窗口内恰好有 $n-1$ 颗石子，且这 $n-1$ 颗石子**本身已经连续**（占据 $n-1$ 个连续位置），那么这唯一的空位落在窗口的**端点**上。把窗口外那颗石子搬进端点空位后，它立刻成为全体的最值——**非法**。这种窗口至少要 2 步才能补齐（见引理 4）。因此这类窗口的候选值取 2 而不是 1。

### 3.3 核心观察（最大步数）：丢弃最小的一侧

![最大步数：总空位减掉被放弃的一侧](images/wc135_q4_end_gaps_max.svg)

设排序后首尾为 $a_0, a_{n-1}$，记

$$E = (a_{n-1} - a_0 + 1) - n \quad (\text{跨度内的总空位数})$$

$$g_{\text{left}} = a_1 - a_0 - 1, \qquad g_{\text{right}} = a_{n-1} - a_{n-2} - 1$$

则

$$\text{max} = E - \min(g_{\text{left}},\ g_{\text{right}})$$

理由：第一步只能搬 $a_0$ 或 $a_{n-1}$。若搬 $a_0$，则新的最小值至少是 $a_1$，原先 $a_0$ 与 $a_1$ 之间的 $g_{\text{left}}$ 个空位**永远落在跨度之外**、再也填不到；此后每步可以恰好消耗 1 个空位。所以搬左侧的路线最多 $E - g_{\text{left}}$ 步，搬右侧最多 $E - g_{\text{right}}$ 步，取较大者即上式。

### 3.4 示例演算

对示例 2 的 `stones = [3,4,5,6,10]`（$n = 5$）：

**最小步数**：滑动窗口

| 左端点 $i$ | 窗口右界（$\le a_i + 4$） | 窗口内石子 | $n - c$ |
|-----------|--------------------------|-----------|---------|
| 3 | 7 | 3,4,5,6 → 4 颗 | 1（但 $c = n-1$ 且这 4 颗连续 → 改为 2） |
| 4 | 8 | 4,5,6 → 3 颗 | 2 |
| 5 | 9 | 5,6 → 2 颗 | 3 |
| 6 | 10 | 6,10 → 2 颗 | 3 |
| 10 | 14 | 10 → 1 颗 | 4 |

最小值为 2，与示例一致。若不做特判就会错答 1。

**最大步数**：$E = (10 - 3 + 1) - 5 = 3$，$g_{\text{left}} = 4-3-1 = 0$，$g_{\text{right}} = 10-6-1 = 3$，故 $\text{max} = 3 - 0 = 3$ ✓。

示例 1 的 `[4,7,9]`：$E = (9-4+1) - 3 = 3$，$g_{\text{left}} = 7-4-1 = 2$，$g_{\text{right}} = 9-7-1 = 1$，$\text{max} = 3 - 1 = 2$ ✓；最小步数窗口 $[4,8]$ 含 4、7 两颗 → $n - c = 1$ ✓。

## 4. 算法细节

1. **先排序**：输入无序（示例 1 是 `[7,4,9]`），所有公式都基于有序序列。
2. **滑窗右界的条件**：`a[j+1] - a[i] <= n - 1`，即窗口占据的位置数不超过 $n$；用 `n-1` 而不是 `n` 是最常见的 off-by-one。
3. **双指针不回退**：$i$ 递增时 $j$ 单调不减，整体 $O(n)$；不要写成对每个 $i$ 都重新从 $i$ 开始扫（那是 $O(n^2)$，$n = 10^4$ 也能过但没必要）。
4. **特判条件**：`cnt == n - 1 && a[j] - a[i] == n - 2`。前者表示窗口里已有 $n-1$ 颗，后者表示这 $n-1$ 颗**恰好连续**（占据长度 $n-1$）。等价写法是先判 `cnt == n-1` 再判首尾差。
5. **多个窗口取最小**：特判只影响「当前这个窗口」的候选值，其他窗口仍按 $n - c$ 计；最终答案取所有候选的最小。例如 `[1,2,3,5]`（$n=4$）虽然存在连续块 `{1,2,3}`，但窗口 `[2,5]` 含 `{2,3,5}` 给出候选 1，最终答案为 1。
6. **最大步数用 64 位**：坐标到 $10^9$，$E$ 可能到 $10^9$ 量级，Python 无溢出，C++ 中 `int` 也够（$10^9 < 2^{31}-1$），但写成 `long long` 更稳妥。

## 5. 正确性证明

**引理 1（最小步数的下界）**：设 $c^*$ 为任意长度为 $n$ 的窗口内的最大石子数，则至少需要 $n - c^*$ 步。

**证明**：设最终局面填满窗口 $W$（长度 $n$）。每一步只搬动一颗石子，因此 $\lvert S \cap W \rvert$ 每步最多增加 1（搬出 $W$ 会减 1，搬入才加 1）。初始时 $\lvert S_0 \cap W \rvert \le c^*$，结束时为 $n$，故步数 $\ge n - c^*$。∎

**引理 2（空位 ≥ 2 时可达下界）**：若某长度 $n$ 的窗口 $W$ 内有 $c \le n-2$ 颗石子，则恰能用 $n-c$ 步把它填满。

**证明**：$W$ 中空位不少于 2 个，记最左空位为 $p$、最右空位为 $q$（$p < q$）。每一步取 $W$ 外的一颗**端点**石子搬进某个空位 $r$，只需保证搬完后 $r$ 既非全局最小也非全局最大：

- 若 $W$ 外既有小于 $L$ 的石子、又有大于 $L+n-1$ 的石子（$L$ 为窗口左端），取 $r = p$：有更小的石子存在故 $p$ 不是最小，有更大的石子存在故 $p$ 不是最大，合法。
- 若 $W$ 外的石子全在左侧（都 $< L$）：取 $r = q$。此时 $q$ 不是最小（外侧石子更小）。若 $q < L+n-1$，则 $q$ 右侧在 $W$ 内还有石子，$q$ 也不是最大；若 $q = L+n-1$，则改取 $r = p$：$p > L$ 时其左侧 $W$ 内有石子、其右侧（$p$ 与 $q$ 之间至少有石子，因空位只有两个）也有石子；$p = L$ 时其右侧必有石子（$q > p$），且外侧有更小石子，同样合法。
- $W$ 外石子全在右侧的情形对称。

每步使 $W$ 内石子数加 1，且不破坏「至少 2 个空位」以外的任何性质（空位减少 1 个，直到只剩 1 个空位时 $c = n-1$，进入引理 3 或引理 4 的情形）；共 $n-c$ 步填满。∎

**引理 3（空位唯一但在内部）**：若 $W$ 内有 $n-1$ 颗石子、唯一空位在窗口**内部**（即这 $n-1$ 颗石子不连续，首尾差为 $n-1$），则 1 步可补齐。

**证明**：此时 $W$ 内空位 $r$ 的两侧都有 $W$ 内的石子，故 $L < r < L+n-1$。把 $W$ 外那颗石子搬进 $r$：搬完后 $r$ 既不是最小（$L$ 处有石子）也不是最大（$L+n-1$ 处有石子），合法，1 步结束。∎

**引理 4（空位唯一且在端点）**：若 $W$ 内 $n-1$ 颗石子连续（占据 $n-1$ 个连续位置），则用 $W$ 作为最终窗口至少需要 2 步；且 2 步一定够。

**证明**：设这 $n-1$ 颗占据 $[x, x+n-2]$，$W$ 的端点空位只能是 $x-1$ 或 $x+n-1$，窗口外那颗石子位于另一侧更远处。

- **至少 2 步**：一步结束要求最终 $n$ 个位置连续。未移动的 $n-1$ 颗连续石子只能落在最终窗口 $[x, x+n-1]$ 或 $[x-1, x+n-2]$ 中，故被移动的石子必须落到端点空位 $x+n-1$ 或 $x-1$。但 $W$ 外的石子比这两处都更靠外，搬过去后它成为全体最值（端点），违反「搬完后不能是端点」，故 1 步无解。
- **2 步可行**：把最外那颗石子搬到一个既非最小也非最大的空位（例如取连续块另一侧的相邻空位向外一格，若被占则取连续块与外部石子之间的任一空位），使窗口整体平移一格、空位变成内部空位，再由引理 3 用 1 步补齐。示例 2 的 `3 → 8`、`10 → 7` 正是这种走法。∎

**引理 5（最大步数）**：$\text{max} = E - \min(g_{\text{left}}, g_{\text{right}})$。

**证明**：设当前跨度为 $z - x$，内部空位数 $\Phi = (z-x+1) - n$，游戏结束时 $\Phi = 0$。一次移动把端点石子搬到跨度内的空位 $k$，新跨度 $= z - \min(k, a_1)$（搬左端时）$< z$，故 $\Phi$ 至少减 1。

- **上界**：第一步若搬 $a_0$，新最小值 $\ge a_1$，跨度至少缩短 $g_{\text{left}} + 1$，故 $\Phi$ 一步至少减少 $g_{\text{left}} + 1$，其后每步至少减少 1，总步数 $\le \Phi_0 - g_{\text{left}} = E - g_{\text{left}}$；搬右侧对称。取两路线中的较大上界得 $\text{max} \le E - \min(g_{\text{left}}, g_{\text{right}})$。
- **可达**：按上述路线，除第一步外每步都把端点石子搬进「紧贴内侧石子」的空位，使跨度恰好减 1（$\Phi$ 恰好减 1）；只要 $\Phi > 0$，跨度内就存在这样的空位，且落点两侧都有石子、不是端点，移动合法。故恰好能走满 $E - \min(g_{\text{left}}, g_{\text{right}})$ 步。∎

**定理**：算法输出的 `[min_moves, max_moves]` 正确。

**证明**：最大步数由引理 5 给出，代码第 3 组语句与之一致。最小步数：由引理 1 得下界 $n - c^*$；对每个窗口，引理 2/3/4 说明其候选值（$n-c$，或连续块特判的 2）都是可达的，取最小即得上界；两者相等，故最小步数正确。∎

## 6. 复杂度分析

- **时间**：$O(n \log n)$。排序占主导；滑动窗口双指针各移动 $O(n)$ 次，最大步数公式为 $O(1)$。
- **空间**：$O(n)$（排序所需的副本；Python 的 `sorted` 会新建列表，C++ 若原地排序则为 $O(\log n)$ 栈空间）。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    vector<int> numMovesStonesII(vector<int>& stones) {
        vector<int> a = stones;
        sort(a.begin(), a.end());
        int n = a.size();

        int minMoves = n, j = 0;
        for (int i = 0; i < n; i++) {
            if (j < i) j = i;
            while (j + 1 < n && a[j + 1] - a[i] <= n - 1) j++;
            int cnt = j - i + 1;
            if (cnt == n - 1 && a[j] - a[i] == n - 2) minMoves = min(minMoves, 2);
            else minMoves = min(minMoves, n - cnt);
        }

        int empty = a[n - 1] - a[0] + 1 - n;
        int maxMoves = empty - min(a[1] - a[0] - 1, a[n - 1] - a[n - 2] - 1);
        return {minMoves, maxMoves};
    }
};
```

### Python

```python
class Solution:
    def numMovesStonesII(self, stones: list[int]) -> list[int]:
        a = sorted(stones)
        n = len(a)

        # 最小：长度为 n 的滑动窗口内已有的最多石子数
        min_moves = n
        j = 0
        for i in range(n):
            if j < i:
                j = i
            while j + 1 < n and a[j + 1] - a[i] <= n - 1:
                j += 1
            cnt = j - i + 1
            if cnt == n - 1 and a[j] - a[i] == n - 2:
                min_moves = min(min_moves, 2)   # 只有 1 个空位且必须借外部石子，需 2 步
            else:
                min_moves = min(min_moves, n - cnt)

        # 最大：总空位数减去两端中被永久放弃的那一侧
        empty = a[-1] - a[0] + 1 - n
        max_moves = empty - min(a[1] - a[0] - 1, a[-1] - a[-2] - 1)
        return [min_moves, max_moves]
```

## 8. 边界情况与易错点

1. **漏掉特判**：`[1,2,3,4,10]`、`[3,4,5,6,10]` 这类「$n-1$ 颗已连续 + 一颗远在天边」的输入，若直接取 $n - c$ 会得到 1，正确答案是 2。
2. **特判条件写宽**：条件是「$n-1$ 颗且**首尾差 $= n-2$**」。若漏掉后半句，`[1,2,3,5]` 会被错判成 2（正确是 1），因为窗口 `[2,5]` 内 `{2,3,5}` 不连续、空位在内部。
3. **滑窗边界 $n-1$ vs $n$**：窗口允许占据 $n$ 个位置（位置差 $\le n-1$），写成 `<= n` 会把窗口放大一格，$c^*$ 偏大。
4. **最大步数别忘减 $g$**：直接返回 $E$ 会把「第一步必然放弃的那段空位」也算进去。示例 1 会得到 3 而不是 2。
5. **排序是前提**：输入可能乱序；且 $a_1, a_{n-2}$ 只有在有序时才代表「次小/次大」。
6. **重复元素**：题目保证位置互不相同；若允许重复，则需要先去重（两题语义不同）。
7. **坐标很大**：$a_i$ 可到 $10^9$，不要用「桶标记空位」的写法；所有量都要用公式算，不能模拟整个数轴。
