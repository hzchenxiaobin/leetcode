# LeetCode 划分数组使最大差为 K 题解

## 1. 题目概述

- **标题 / 题号**：划分数组使最大差为 K（#2294，medium）
- **链接**：https://leetcode.cn/problems/partition-array-such-that-maximum-difference-is-k/
- **来源**：LeetCode 第 296 场周赛 Q2
- **难度**：中等
- **标签**：贪心、排序、数组

**题意**：给定整数数组 `nums` 和整数 `k`，将 `nums` 划分成一个或多个子序列，使每个元素恰好出现在一个子序列中。要求每个子序列内最大值与最小值之差不超过 `k`，返回需要划分的**最少**子序列数目。

**约束**：

- `1 <= nums.length <= 10^5`
- `0 <= nums[i] <= 10^5`
- `0 <= k <= 10^5`

> 💡 本题在本仓库另有[每日题解 2294](../../solution/2201-2300/2294_划分数组使最大差为K.md)：以「排序后贪心分组」为主线，附断点计数的等价写法、计数排序 $O(n+V)$ 扩展与面试问答。本篇按**周赛复盘视角**展开，侧重"子序列 ⇒ 子集"这一步**去序化**观察的动机、交换论证 + 前缀结构的引理-定理证明与边界清单，两篇互为印证。

## 2. 示例

**示例 1**

```text
输入：nums = [3,6,1,2,5], k = 2
输出：2
解释：划分为 [3,1,2] 和 [6,5] 两个子序列。第一组 max−min = 3−1 = 2，第二组 max−min = 6−5 = 1，均不超过 k=2。
```

**示例 2**

```text
输入：nums = [1,2,3], k = 1
输出：2
解释：划分为 [1,2] 和 [3]。注意 [1] 和 [2,3] 也是一组合法的最优划分。
```

**示例 3**

```text
输入：nums = [2,2,4,5], k = 0
输出：3
解释：划分为 [2,2]、[4]、[5]。k=0 时只有相等的元素才能同组。
```

## 3. 解题思路

### 3.1 朴素思路：枚举划分 / 字面理解"子序列"

- 直接枚举所有划分方案：`n` 个元素的集合划分数是 Bell 数，`n = 10^5` 时是天文数字，不可行。
- 按题面字面理解"子序列"、去关注原数组的下标顺序，会误以为分组与位置有关，把问题想复杂。

> 💡 **破局点**：一个组是否合法，只取决于组内最大值与最小值之差，与元素在原数组中的位置**毫无关系**。

### 3.2 核心观察：与顺序无关 → 排序 + 贪心分段

**第一步简化**："子序列"只限制"取元素时不改变相对顺序"，但既然合法性只看值集合的 $\max - \min$，把组内元素换成任何顺序仍然合法。所以**问题本质是"把值集合划分成尽量少的组"**，与下标顺序完全无关，**排序不改变答案**。

**第二步观察**：排序后值相近的元素相邻。若某组里有 `1` 和 `3`，那么夹在中间的 `2` 放进这组一定不违法（$\max-\min$ 不变），反而能让 `2` 原来所在的那组更容易安排。跨段分组没有任何好处，最优解总可以取成排序数组的**连续段**。

于是得到贪心策略：**从剩余最小元素 `anchor` 出发开新组，把所有值不超过 `anchor + k` 的连续元素吞并进本组；遇到第一个超过的元素就切割，重新开组。**

![核心观察：排序后每组取连续一段](images/2294_sorted_interval_concept.svg)

### 3.3 算法流程

![贪心分段算法流程](images/2294_algorithm_flow.svg)

```text
1. 将 nums 升序排序
2. i ← 0，count ← 0
3. 循环：若 i < n
   a. anchor ← nums[i]，count ← count + 1（开新组）
   b. 只要 i < n 且 nums[i] - anchor ≤ k：i ← i + 1（扩组）
4. 扫描结束，count 即答案
```

### 3.4 示例演算

![示例演算](images/2294_example_walkthrough.svg)

以示例 1 为例：排序后 `[1,2,3,5,6]`。第一组 `anchor=1`，吞并 `1,2,3`；`5-1=4>2` 切割。第二组 `anchor=5`，吞并 `5,6`。答案 `2`。

## 4. 算法细节

- **排序**：升序排序后，切割位置只依赖值的大小关系，与原下标无关。
- **锚点即组内最小值**：组是从剩余最小的未分组元素开始建的，所以 `anchor` 永远是当前组的最小值。判定条件简化为 `nums[i] - anchor <= k`，**无需维护组内 max**——能吞并的元素都 ≤ `anchor + k`，组内 $\max-\min \le k$ 自动成立。
- **为什么可以切割**：`nums[i] - anchor > k` 说明 `nums[i]` 与当前组的最小元素差值已超限，必不能同组；又因为排序后后面的元素更大，也不可能同组，此时切割是安全的，且 `nums[i]` 恰好是下一组的锚点。
- **实现**：排序后一次线性扫描，外层 `while (i < n)` 开组、内层 `while` 扩组；也可合并成单层循环。

## 5. 正确性证明

设排序后 $a_0 \le a_1 \le \cdots \le a_{n-1}$。设 $j$ 为使 $a_j - a_0 \le k$ 成立的最大下标（即 $a_0, \dots, a_j$ 恰是值落在 $[a_0,\, a_0+k]$ 中的全部元素）。

**引理 1**：任何含有 $a_0$ 的合法组，其全部元素都落在 $\{a_0, a_1, \dots, a_j\}$ 中。

**证明**：设该组合有 $a_0$ 且合法。$a_0$ 是全局最小值，故组内 $\min = a_0$，组内每个元素 $x$ 满足 $x \le a_0 + k$；又 $x \ge a_0$。满足 $a_0 \le x \le a_0 + k$ 的元素恰为 $a_0..a_j$。∎

**引理 2（交换不变性）**：把 $\{a_0, \dots, a_j\}$ 中任何不在 $a_0$ 所在组 $G$ 里的元素移入 $G$，组数不变，且所有组仍合法。

**证明**：设 $a_t \in \{a_0,\dots,a_j\}$、$a_t \notin G$、$a_t$ 所在组为 $H$。

- 对 $G$：移入后 $\min(G \cup \{a_t\}) = a_0$（$a_0 \in G$ 且 $a_t \ge a_0$）；$\max(G \cup \{a_t\}) \le a_0 + k$（由引理 1，$G$ 中元素均 $\le a_0+k$，且 $a_t \le a_j \le a_0 + k$）。故差值仍 $\le k$。
- 对 $H$：去掉一个元素后 $\min$ 不减、$\max$ 不增，差值只会变小，仍合法。
- 组数未变。∎

**定理**：存在最优解，其第一组恰为 $\{a_0, a_1, \dots, a_j\}$；进而"贪心取最长合法前缀 + 对剩余后缀递归"得到的最小组数等于最优值。

**证明**：任取一个最优解，设 $a_0$ 所在组为 $G$。由引理 2，可把 $[0, j]$ 中所有不在 $G$ 的元素逐个移入 $G$（每次 $|G|$ 严格增加，有限步后停止），组数不变，得到仍最优的解，且 $G \supseteq \{a_0,\dots,a_j\}$；又由引理 1 $G \subseteq \{a_0,\dots,a_j\}$，故 $G = \{a_0,\dots,a_j\}$。固定第一组为前缀 $[0, j]$ 后，剩余元素 $a_{j+1}, \dots, a_{n-1}$ 的分组是原问题在**后缀上的同构子问题**，总组数 = $1 +$ 子问题最优值。这正是贪心的执行过程，对 $n$ 归纳即得贪心解 = 最优解。∎

> 💡 证明的核心是**交换论证 + 前缀结构**：第一组"吞得越满越好"——被吞掉的元素无论原本在哪个组，移入第一组都不违法（引理 2），而它们腾出的位置只会让后续分组更容易。

## 6. 复杂度分析

- **时间复杂度**：$O(n \log n)$。排序占 $O(n \log n)$；排序后每个元素在扫描中只被访问一次，扫描为 $O(n)$。
- **空间复杂度**：$O(\log n)$，为语言内置排序的栈开销；若不计排序，扫描本身只用常数个变量（$O(1)$）。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int partitionArray(vector<int>& nums, int k) {
        sort(nums.begin(), nums.end());
        int n = nums.size();
        int count = 0;
        int i = 0;
        while (i < n) {
            int anchor = nums[i];   // 新组的最小值
            count++;
            while (i < n && nums[i] - anchor <= k) {
                i++;                // 尽量向右吞并
            }
        }
        return count;
    }
};
```

### Python

```python
class Solution:
    def partitionArray(self, nums: List[int], k: int) -> int:
        nums.sort()
        n = len(nums)
        count = 0
        i = 0
        while i < n:
            anchor = nums[i]        # 新组的最小值
            count += 1
            while i < n and nums[i] - anchor <= k:
                i += 1              # 尽量向右吞并
        return count
```

## 8. 边界情况与易错点

1. **别被"子序列"带偏**：合法性只取决于组内 $\max - \min$，与元素下标、顺序无关。这是本题最重要的简化，它允许我们直接排序。
2. **`k = 0`**：只有相等的值才能同组，排序后相等值相邻，贪心自动处理（见示例 3）。
3. **单元素 / 全部相同**：单元素返回 1；全部相同（`k ≥ 0`）返回 1，扫描逻辑自然覆盖。
4. **锚点即组内最小值**：不要额外维护组内 `max`，判定 `nums[i] - anchor <= k` 已足够。
5. **溢出**：`nums[i], k ≤ 10^5`，`nums[i] - anchor` 与 `anchor + k` 都远在 `int` 范围内，无溢出风险。
6. **必须升序排序**：降序排序会让锚点取到最大值，逻辑完全错误。
7. **切割后 `nums[i]` 就是新锚点**：内层循环退出时 `nums[i]` 是第一个放不进的元素（或 `i == n`），外层直接以它为锚点开新组。不要先 `i++` 再取锚点，否则会跳过一个元素、使其未被分组。

**延伸思考**：

- 若要求每组在**原数组中连续**（子数组划分）："顺序无关"的简化失效，需要 $O(n^2)$ 区间 DP（或单调栈优化）：设 $dp[i]$ 为前 $i$ 个元素的最小组数，转移时枚举/二分最后一个合法段的左端点。

- 若值域很小（如 $0 \le nums[i] \le 10^5$）且要求**在线**插入并随时回答当前最少组数：可用值域计数桶，按值从小到大扫描维护切割点。
