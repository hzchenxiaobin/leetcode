# LeetCode 使数组为空的最少操作次数 题解

## 1. 题目概述

- **标题 / 题号**：使数组为空的最少操作次数（#2870，medium）
- **链接**：https://leetcode.cn/problems/minimum-number-of-operations-to-make-array-empty/
- **来源**：LeetCode 第 114 场双周赛 Q2
- **难度**：中等
- **标签**：贪心、数组、哈希表、计数

**题意**：正整数数组 `nums`，每次操作可选**两个**或**三个**值**相等**的元素删除。返回使数组为空的最少操作次数；无法为空返回 $-1$。

**约束**：

- $2 \le nums.length \le 10^5$
- $1 \le nums[i] \le 10^6$

## 2. 示例

**示例 1**

```text
输入：nums = [2,3,3,2,2,4,2,3,4]
输出：4
解释：删 (2,2)、(2,2)、(3,3,3)、(4,4)，共 4 次。
```

**示例 2**

```text
输入：nums = [2,1,2,2,3,3]
输出：-1
解释：值 1 只出现 1 次，凑不出「两个或三个相等」，永远删不掉。
```

## 3. 解题思路

### 3.1 暴力思路

操作只对**同值**元素生效，不同值之间完全独立——先计数，再对每个值的出现次数 $c$ 单独求最少操作数。暴力做法是对每个 $c$ 做 DP：$g(c) = \min(g(c-2)+1, g(c-3)+1)$，$g(0) = 0$，$g(1) = \infty$。频次种类至多 $n$ 个、最大频次 $10^5$，总复杂度 $O(n + \max c)$ 尚可，但既然 $g$ 有封闭形式，直接算更快也更不容易写错边界。

### 3.2 核心观察：模 3 分类——每次删得越多越好

![按频次模 3 分类：只和自己值分组](images/bw114_q2_mod3.svg)

对一个出现 $c$ 次的值，每次操作删 2 个或 3 个。想要次数最少，就**尽量多用三元组**：

- $c \bmod 3 = 0$：全用三元组，$c/3$ 次；
- $c \bmod 3 = 2$：$\lfloor c/3 \rfloor$ 个三元组 + 1 个二元组，共 $\lfloor c/3 \rfloor + 1$ 次；
- $c \bmod 3 = 1$：$c = 1$ 无解（1 个元素既凑不成 2 也凑不成 3）；$c \ge 4$ 时拆成 $\lfloor c/3 \rfloor - 1$ 个三元组 + **两个二元组**（$3q+1 = 3(q-1)+2+2$，$q \ge 1$），共 $\lfloor c/3 \rfloor + 1$ 次。

「余 1 时用两个二元组而不是一个」是唯一需要绕一下的地方：多删一组 3 就少删一组 2，净效果 $-1$，正好把余数从 1 补成 0。

### 3.3 算法流程

```text
1. freq = 哈希表统计每个值的出现次数
2. ans = 0
3. 对每个 c = freq[v]：
       若 c % 3 == 0：ans += c / 3
       否则若 c == 1：返回 −1
       否则：ans += c / 3 + 1        # 余 2 用一组对；余 1(≥4) 用两组对
4. 返回 ans
```

### 3.4 示例演算

![示例演算：[2,3,3,2,2,4,2,3,4]](images/bw114_q2_walkthrough.svg)

- `[2,3,3,2,2,4,2,3,4]`：频次 $2 \to 4$、$3 \to 3$、$4 \to 2$。$4 = 2+2$（2 次）、$3 = 3$（1 次）、$2$（1 次），合计 $4$；
- `[2,1,2,2,3,3]`：值 $1$ 频次为 1，返回 $-1$。

## 4. 算法细节

1. **独立性的严格理由**：一次操作删除的元素值全相等，因此任何操作序列按值划分成互不相交的子序列；总次数 = 各值的最少次数之和。这一步把全局问题拆成了单值问题，是整个解法的地基。
2. **余 1 的处理**：$c = 3q + 1$（$q \ge 1$）时用 $(q-1)$ 个三元组加 2 个二元组：$3(q-1) + 2 + 2 = 3q + 1$ ✓。写成代码就是 `c / 3 + 1`，但**必须**排除 `c == 1`（此时 $q = 0$，$-1$ 个三元组无意义）。
3. **整除判断用 `c % 3`**：频次范围 $1 \sim 10^5$，`int` 无溢出风险；答案上限 $n/2 = 5\times10^4$。
4. **计数容器**：值域 $10^6$ 可以开桶（`int` 数组 4MB），也可以哈希表；后者不受值域约束，两种都行。

## 5. 正确性证明

**引理 1（值的独立性）**：设值 $v$ 的频次为 $c_v$，则「删空整个数组」需要的最少次数 $= \sum_v g(c_v)$，其中 $g(c)$ 是删空 $c$ 个同值元素的最少操作数（不可行记 $+\infty$）。

**证明**：任何合法操作序列的每次操作只触碰一个值的元素，把它按值拆开得到各值各自的合法子序列（保持操作顺序），故总次数 $\ge \sum_v g(c_v)$；反之把各值的最优序列任意交错执行仍合法，得 $\le$。∎

**引理 2（单值公式）**：$g(c) = c/3$（$c \equiv 0$）、$\lfloor c/3 \rfloor + 1$（$c \equiv 2$，含 $c = 2$）、$\lfloor c/3 \rfloor + 1$（$c \equiv 1$ 且 $c \ge 4$）、$+\infty$（$c = 1$）。

**证明**：一次操作删 2 或 3 个，设总共用了 $a$ 次二元、$b$ 次三元操作，则 $2a + 3b = c$，总次数 $m = a + b$。（下界）每次操作至多删 3 个，故 $c \le 3m$，即 $m \ge \lceil c/3 \rceil$；三种余数下 $\lceil c/3 \rceil$ 分别为 $c/3$、$q+1$（$c = 3q+2$）、$q+1$（$c = 3q+1$，$q \ge 1$）。（构造）各余数的拆法见 §3.2，均达到对应下界；$c = 1$ 时 $2a + 3b \ge 2 > 1$ 无解。∎

**定理**：算法返回使数组为空的最少操作次数（或正确判定无解）。

**证明**：由引理 1 归结到单值，由引理 2 单值公式正确；某值频次为 1 时引理 2 给 $+\infty$，算法返回 $-1$。∎

## 6. 复杂度分析

- **时间**：$O(n)$。一次遍历计数，随后对每个不同值 $O(1)$ 计算；不同值个数至多 $n$。
- **空间**：$O(n)$（哈希表）或 $O(V)$（$V = 10^6$ 的值域桶）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minOperations(vector<int>& nums) {
        unordered_map<int, int> freq;
        for (int x : nums) ++freq[x];
        int ans = 0;
        for (auto& [v, c] : freq) {
            if (c % 3 == 0) ans += c / 3;          // 全用三元组
            else if (c == 1) return -1;           // 单个元素：2 个、3 个都凑不出
            else ans += c / 3 + 1;                // 余 2：一组对；余 1(≥4)：两个对
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def minOperations(self, nums: list[int]) -> int:
        freq = {}
        for x in nums:
            freq[x] = freq.get(x, 0) + 1
        ans = 0
        for c in freq.values():
            if c % 3 == 0:
                ans += c // 3                     # 全用三元组
            elif c == 1:
                return -1                         # 单个元素无法删除
            else:
                ans += c // 3 + 1                 # 余 2：一组对；余 1(≥4)：两个对
        return ans
```

> 💡 两份代码均通过全部官方示例（`4`、`-1`），并与「$g(c) = \min(g(c-2), g(c-3)) + 1$ 记忆化 DP」的暴力对拍 10000 组随机数据（小值域制造各种频次），`mismatch = 0`；$n = 10^5$ 单一值实测毫秒级。

## 8. 边界情况与易错点

1. **频次 1 是唯一的无解情形**：频次 $c \ge 2$ 总能删空（$c \equiv 1, c \ge 4$ 用两个二元组）。不要把「$c \bmod 3 = 1$」整体判成无解——$c = 4, 7, 10, \dots$ 都有解。
2. **余 1 的下界论证**：直观上「$c = 3q+1$ 用 $q+1$ 次」是因为必须有一次操作只删 2 个（否则总和模 3 对不上）；想通这一点就不会误写成 $\lceil c/3 \rceil$ 之外的形式——碰巧 $q+1 = \lceil (3q+1)/3 \rceil$，两写法数值相同，但 $c=1$ 例外（$\lceil 1/3 \rceil = 1 \ne \infty$），正是易错点。
3. **返回 $-1$ 要立刻返回**：发现某个值频次为 1 即可短路，继续累加无意义。
4. **溢出与类型**：频次与答案都不超过 $10^5 / 2$，`int` 足够。
5. **别混淆本题与 2856**：第 113 场双周赛 Q2（删除数对后的最小数组长度）删的是「值**不同**的两个」，方向恰好相反，两题的频次公式不可混用。
6. **多组删除的顺序**：不需要排序或按位置贪心——值独立后任何顺序都一样，别被「下标」迷惑。

**延伸思考**：设每次操作可删 $[l, r]$（本题 $l=2, r=3$）个同值元素，$g(c)$ 的通用形态是：能被表示的组合中选「最多三元」的贪心——当 $\gcd$ 不整除时余数需要回退若干个大组换小组。对 $(2,3)$ 恰好除 $c=1$ 外全部可解，这是 Frobenius/找零钱问题的雏形：面额 $\{2,3\}$ 表示不了的数只有 1。若允许删 2 或 5 个，则 $c \in \{1,3\}$ 无解、其余按模 5 讨论；一般情形可用 DP 预处理 $g$ 后 $O(1)$ 查询。
