# LeetCode 个位数字为 K 的整数之和 题解

## 1. 题目概述

- **标题 / 题号**：个位数字为 K 的整数之和（#2310，medium）
- **链接**：https://leetcode.cn/problems/sum-of-numbers-with-units-digit-k/
- **来源**：LeetCode 第 298 场周赛 Q2
- **难度**：中等
- **标签**：贪心、数学、动态规划、枚举

**题意**：给定整数 `num` 与 `k`，求一个**正整数多重集**（元素可重复），满足：

- 每个元素的**个位数字**都是 `k`；
- 所有元素之和恰为 `num`。

返回该多重集的**最小大小**；不存在则返回 `-1`。空多重集的和为 `0`（大小为 `0`）。

**约束**：

- $0 \le \text{num} \le 3000$
- $0 \le k \le 9$

> 💡 本题在本仓库另有[每日题解 2310](../../solution/2301-2400/2310_个位数字为K的整数之和.md)：以「完全背包 → 同余降维」为主线，含硬币家族对照表与面试问答。本篇按周赛复盘视角展开，侧重**赛场两条路线的取舍（DP 保底 vs 数学 $O(1)$）、可行性两条件的构造性证明（引理-定理）、`num=0` / `k=0` 边界清单与对拍自测**，两篇互为印证。

## 2. 示例

**示例 1**

```text
输入：num = 58, k = 9
输出：2
解释：多重集 [9,49] 满足题目条件，和为 58 且每个整数的个位数字是 9。
另一个满足条件的多重集是 [19,39]。最小大小为 2。
```

**示例 2**

```text
输入：num = 37, k = 2
输出：-1
解释：个位数字为 2 的整数无法相加得到 37。
```

**示例 3**

```text
输入：num = 0, k = 7
输出：0
解释：空多重集的和为 0。
```

**补充示例：k = 0 时 0 不是合法元素**

```text
输入：num = 20, k = 0
输出：1
解释：个位为 0 的正数从 10 开始，但单个 [20] 本身就满足条件。
```

**补充示例：个位对得上也会「透支」**

```text
输入：num = 4, k = 3
输出：-1
解释：需 3c ≡ 4 (mod 10)，最小 c = 8（24 的个位为 4）；
但每个数 ≥ 3，8 个数之和至少 24 > 4 —— 同余可达、余量不足，仍无解。
```

## 3. 解题思路

### 3.1 赛场保底思路：完全背包 DP

题面就是「用面额集合 {个位为 $k$ 的正数} 凑出 $\text{num}$ 的最少件数」——标准**完全背包**。物品为 $k, 10{+}k, 20{+}k, \ldots$（$k = 0$ 时为 $10, 20, \ldots$，注意 0 不是正数）：

```text
dp[0] = 0，其余 dp[s] = +∞
for s = 1 .. num:
    for v ∈ {v ≤ s : v 的个位为 k}:
        dp[s] = min(dp[s], dp[s - v] + 1)
return dp[num] ≤ num ? dp[num] : -1
```

约束下物品约 $\text{num}/10 \approx 300$ 种、状态 $3000$ 个，总量 $\approx 9 \times 10^5$——**赛场 5 分钟写完稳过**，是本题的保底路线。但它把力气浪费在「十位以上」的信息上：$dp[s]$ 与 $dp[s']$ 在 $s \equiv s' \pmod{10}$ 时行为几乎一致，真正的自由度只有**个位**与**件数**两个。

> 💡 转机：判定「和能否等于 num」只依赖每个数的**个位**与**个数**——「十位以上」的部分全是 10 的倍数，模 10 后彻底消失。

### 3.2 核心观察：模 10 塌缩——和的个位只由「个数 × k」决定

![核心观察：个位为 K 的数 = 10a+K，c 个之和的个位只由 c·K 决定](images/wc298_q2_units_digit_decomposition.svg)

个位为 $k$ 的正整数都形如 $10a + k$（$a \ge 0$；$k = 0$ 时须 $a \ge 1$，即数 $\ge 10$）。设选了 $c$ 个，则

$$\text{sum} = \sum_{i=1}^{c} (10a_i + k) = 10\underbrace{\sum_{i=1}^{c} a_i}_{\text{模 10 消失}} + \underbrace{c \cdot k}_{\text{决定个位}}$$

令 $\text{sum} = \text{num}$，立刻得到两个**必要条件**：

| 条件 | 形式 | 直觉 |
|------|------|------|
| ① 个位对齐 | $c \cdot k \equiv \text{num} \pmod{10}$ | 十位以上随便凑，个位必须严丝合缝 |
| ② 不透支 | $c \cdot k \le \text{num}$ | 每个数 $\ge k$，$c$ 个至少 $c \cdot k$ |

而这两条合起来竟是**充分**的（第 5 节引理 3 给出显式构造）：取 $c-1$ 个 $k$，再放一个 $x = \text{num} - (c-1)k$——它 $\ge k > 0$ 且个位恰为 $k$。例：$\text{num}=58, k=9, c=2$ 时 $\{9,\ 58-9\} = \{9, 49\}$ ✓。

> 💡 **关键转化**：最小化多重集大小 = 在 $c = 1, 2, \ldots$ 中找**最小的**同时满足 ①② 的 $c$。

### 3.3 算法流程：特判 num=0，升序枚举 c 至 10

![算法流程：特判 + 枚举 c=1..10，两条件把关](images/wc298_q2_algorithm_flow.svg)

$(c \cdot k) \bmod 10$ 随 $c$ 递增按周期 $10/\gcd(k,10) \le 10$ 循环，故**满足 ① 的最小 $c$ 若存在必 $\le 10$**：若某个 $c \ge 11$ 满足 ①，则 $c - 10$ 同样满足（$(c-10)k \equiv ck \pmod{10}$ 且 $c-10 \ge 1$）。于是：

1. **特判** $\text{num} = 0$：空多重集，返回 `0`；
2. **升序枚举** $c = 1 \ldots 10$，找**首个**满足 ① 的 $c$：
   - 再判 ②：$c \cdot k \le \text{num}$ 成立 → 返回 $c$；
   - 不成立 → 返回 `-1`——满足 ① 的 $c$ 全体是同一个等差类（步长 $10/\gcd(k,10)$），都 $\ge$ 首个，而 $c \cdot k$ 随 $c$ 单调不减，**首个透支则整类透支**；
3. ① 全程无匹配（如 $k=2$ 凑不出个位 7）→ 返回 `-1`。

### 3.4 示例演算

![示例演算：五组输入的逐 c 走查](images/wc298_q2_example_walkthrough.svg)

以**示例 1** `num=58, k=9` 走查：$\text{num} \bmod 10 = 8$；$c=1$：$9 \bmod 10 = 9 \ne 8$ ✗；$c=2$：$18 \bmod 10 = 8$ ✓ 且 $18 \le 58$ ✓ → 返回 2，构造 $\{9, 49\}$。

反例同样重要：`37, 2` 中 $2c \bmod 10 \in \{2,4,6,8,0\}$ 永不等于 7（奇偶错配）；`4, 3` 中 $c=8$ 个位对齐但 $24 > 4$ 透支——两种 `-1` 的**机理不同**：前者「同余不可达」，后者「同余可达但余量不足」。

## 4. 算法细节

1. **两条件的分工**：① 管「个位严丝合缝」，② 管「余量够不够」。构造 $x = \text{num} - (c-1)k$ 的正性恰由 ② 保证：$x \ge ck - (c-1)k = k$；个位恰由 ① 保证：$x \equiv ck - (c-1)k = k \pmod{10}$。
2. **上界是 10 不是 9**：$k=1, \text{num}=10$ 时最小 $c = 10$（十个 1 相加），`range(1, 10)` 会漏判误返 `-1`。$k$ 与 10 互素（$k \in \{1,3,7,9\}$）时周期恰为 10。
3. **首个匹配即最小**：升序枚举遇到的第一个满足 ① 的 $c$ 就是该同余类的最小代表；若它透支，整类全透支，直接 `-1`，不必继续扫。
4. **k = 0 无需分支**：① 化为 $\text{num} \bmod 10 = 0$（与 $c$ 无关），首匹配必为 $c=1$；② 恒为 $0 \le \text{num}$。返回 1 对应构造 $\{\text{num}\}$——num 是 10 的正倍数、个位为 0，合法（「0 不能当元素」已由 $\text{num} > 0$ 的特判挡在循环外）。
5. **num = 0 特判必须在循环前**：不特判则 $k=0$ 在 $c=1$ 因 $0 \equiv 0 \pmod{10}$ 的个位巧合误返 1；$k \ge 1$ 因 $ck \ge 1 > 0$ 恒不满足 ② 而误返 -1——两头都错，只有特判能救。
6. **无溢出**：$c \cdot k \le 10 \times 9 = 90$，`int` 富余。
7. **DP 保底版的物品集**：$k \ge 1$ 从 $k$ 起、$k = 0$ 从 $10$ 起（0 非正数）；`dp` 用哨兵 `inf` 或 `num+1`，末尾按哨兵判 `-1`；`num=0` 时 `dp[0]=0` 天然正确，无需特判。

## 5. 正确性证明

**引理 1（结构刻画）**：正整数 $x$ 的个位为 $k$ $\iff$ $x = 10a + k$，其中 $a \ge 0$（$k \ge 1$）或 $a \ge 1$（$k = 0$）。

**证明**：个位即 $x \bmod 10$。若 $x = 10a + k$ 且 $0 \le k \le 9$，则 $x \bmod 10 = k$；反之取 $a = \lfloor x/10 \rfloor$ 即得。正性：$k \ge 1$ 时对一切 $a \ge 0$ 有 $10a + k \ge 1$；$k = 0$ 时个位为 0 的最小正数是 10，等价于 $a \ge 1$。∎

**引理 2（必要性）**：若 $c$ 个合法正数之和为 $\text{num}$，则 $c \cdot k \le \text{num}$ 且 $\text{num} \equiv c \cdot k \pmod{10}$。

**证明**：设诸数为 $10a_i + k$（引理 1），和 $= 10\sum a_i + ck$。因 $\sum a_i \ge 0$，和 $\ge ck$，即条件 ②；又 $10 \sum a_i \equiv 0 \pmod{10}$，故和 $\equiv ck \pmod{10}$，即条件 ①。∎

**引理 3（充分性，构造证明）**：设 $\text{num} > 0$，$k \ge 1$，$c \ge 1$ 满足 ①②。则存在 $c$ 个合法正数之和为 $\text{num}$。

**证明**：取 $c-1$ 个 $k$ 与一个 $x = \text{num} - (c-1)k$。总和恰为 $\text{num}$；由 ②，$x \ge ck - (c-1)k = k \ge 1$ 为正；由 ①，$x \equiv \text{num} - (c-1)k \equiv ck - (c-1)k = k \pmod{10}$，结合 $x \ge 1$ 与引理 1 知其个位为 $k$。∎

**引理 4（k = 0 的刻画）**：$k = 0$ 时，合法多重集存在 $\iff$ $\text{num} = 0$ 或 $10 \mid \text{num}$；$\text{num} > 0$ 时最小大小为 1。

**证明**：此时元素皆为 10 的正倍数（引理 1），故非空和 $\ge 10$ 且是 10 的倍数；反之 $\text{num} \ge 10$ 且 $10 \mid \text{num}$ 时单元素集 $\{\text{num}\}$ 合法，且不存在更小的非空多重集。∎

**引理 5（枚举上界）**：若 $c \ge 11$ 满足 ①，则 $c - 10 \ge 1$ 也满足 ①；若 $c$ 还同时满足 ②，则 $c - 10$ 也同时满足 ②。从而满足 ①（或 ①②）的最小 $c$ 若存在必 $\le 10$。

**证明**：$(c-10)k \equiv ck \pmod{10}$，故 ① 对 $c-10$ 成立；又 $(c-10)k = ck - 10k \le ck \le \text{num}$，故 ② 亦对 $c-10$ 成立。∎

**定理**：算法返回合法多重集的最小大小；不存在时返回 `-1`。

**证明**：分三种情形。

- $\text{num} = 0$：特判返回 0，即空多重集的大小，且不存在比空更小的多重集，正确。
- $\text{num} > 0,\ k = 0$：① 与 $c$ 无关，等价于 $10 \mid \text{num}$。若 $10 \nmid \text{num}$，循环无命中返回 -1，与引理 4 一致；若 $10 \mid \text{num}$，首个命中 $c = 1$ 且 ② 成立（$0 \le \text{num}$），返回 1，与引理 4 给出的最小大小一致。
- $\text{num} > 0,\ k \ge 1$：由引理 2 与引理 3，「大小为 $c$ 的合法多重集存在」$\iff$「$c$ 满足 ①②」。设升序枚举中首个满足 ① 的为 $c_0$（由引理 5，若存在满足 ① 的 $c$ 则 $c_0 \le 10$，必被扫到；若不存在则循环耗尽返回 -1，由引理 2 知确实无解，正确）。满足 ① 的 $c$ 全体 $\ge c_0$，且 $k \ge 1$ 时 $ck$ 随 $c$ 严格递增：若 $c_0 k > \text{num}$，则全体透支，无 $c$ 同时满足 ①②，返回 -1 正确；若 $c_0 k \le \text{num}$，则 $c_0$ 同时满足 ①②，由引理 3 可行，又因任何可行 $c$ 必满足 ① 从而 $\ge c_0$，故 $c_0$ 即最小大小，返回 $c_0$ 正确。∎

## 6. 复杂度分析

- **时间复杂度**：$O(1)$。循环至多 10 轮、每轮常数次取模与比较，与 $\text{num}$、$k$ 的规模无关——即便 $\text{num}$ 放大到 $10^{18}$，本解依旧常数时间，而 DP 版会直接爆内存。
- **空间复杂度**：$O(1)$，仅常数个变量。
- **对照（DP 保底版）**：时间 $O(\text{num} \cdot \text{num}/10)$（状态数 × 物品数），空间 $O(\text{num})$；约束下约 $9 \times 10^5$ 次运算可过，但把「个位同余」这一真自由度埋进了大量冗余状态里。

## 7. 参考代码

### C++（主解：同余 + 两条件，O(1)）

```cpp
class Solution {
public:
    int minimumNumbers(int num, int k) {
        if (num == 0) return 0;                  // 空多重集
        for (int c = 1; c <= 10; ++c) {          // 周期 10/gcd(k,10) ≤ 10
            if ((c * k) % 10 == num % 10)        // ① 个位对齐
                return (c * k <= num) ? c : -1;  // ② 不透支；首个透支则整类透支
        }
        return -1;                               // 同余不可达
    }
};
```

### Python（主解）

```python
class Solution:
    def minimumNumbers(self, num: int, k: int) -> int:
        if num == 0:
            return 0
        for c in range(1, 11):
            if c * k % 10 == num % 10:
                return c if c * k <= num else -1
        return -1
```

### Python（DP 保底版：赛场先锁定分数，再回头优化）

```python
class Solution:
    def minimumNumbers(self, num: int, k: int) -> int:
        coins = [v for v in range(k if k else 10, num + 1, 10)]  # k=0 时从 10 起
        dp = [0] + [float('inf')] * num
        for s in range(1, num + 1):
            for v in coins:
                if v <= s and dp[s - v] + 1 < dp[s]:
                    dp[s] = dp[s - v] + 1
        return dp[num] if dp[num] <= num else -1
```

> 💡 赛场节奏建议：Q2 看到 $O(\text{num}^2/10)$ 可过的 DP 就先提交锁定分数，再回头想 $O(1)$；两版互为**对拍**工具——随机 $\text{num} \le 3000$、$k \le 9$ 各一千组比对，可验证主解无死角。

## 8. 边界情况与易错点

1. **num = 0 必须特判**：不判则 $k=0$ 误返 1（$0 \equiv 0 \pmod{10}$ 的个位巧合）、$k \ge 1$ 误返 -1（$ck \ge 1 > 0$ 恒透支）——两个方向都翻车，这是本题最大的陷阱。
2. **k = 0 时 0 不是合法元素**：个位为 0 的正数 $\ge 10$；但最小解取单元素 $\{\text{num}\}$ 即可，主解无需专门分支。
3. **枚举上界是 10 不能写成 9**：$k=1, \text{num}=10$ 的答案是 10（十个 1）。
4. **透支判定不能省**：`num=4, k=3` 个位可达（$c=8$）但 $24 > 4$，漏判 ② 会把 -1 错报成 8。
5. **同余类全体同生死**：首个匹配 $c_0$ 透支时直接 -1，不必继续枚举——更大的同位 $c$ 只会更透支。
6. **gcd 速判（赛场心算）**：$k$ 为偶数只能凑偶数个位；$k=5$ 只能凑 $\{0, 5\}$；$k \in \{1,3,7,9\}$ 与 10 互素，个位全可达（但下界卡在 $ck \le \text{num}$）。
7. **返回的是最小大小**，不是多重集本身；构造 $\{k \times (c{-}1),\ \text{num}-(c{-}1)k\}$ 仅用于证明与自查。
8. **DP 版两个坑**：$k=0$ 物品从 10 起步（0 非正数）；判 -1 时哨兵比较 `dp[num] <= num` 对 `num=0` 天然成立，别把返回条件写成 `dp[num] < num`。
