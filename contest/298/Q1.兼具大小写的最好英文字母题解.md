# LeetCode 兼具大小写的最好英文字母 题解

## 1. 题目概述

- **标题 / 题号**：兼具大小写的最好英文字母（#2309，easy）
- **链接**：https://leetcode.cn/problems/greatest-english-letter-in-upper-and-lower-case/
- **来源**：LeetCode 第 298 场周赛 Q1
- **难度**：简单
- **标签**：哈希表、字符串、枚举、位运算

**题意**：给定一个由大小写英文字母组成的字符串 `s`，找出其中的**最好**英文字母并以**大写形式**返回；若不存在则返回空串 `""`。

- **兼具大小写**：某字母的大写与小写形式**都**在 `s` 中出现；
- **更好**：字母表中 `b` 在 `a` **之后**，则 `b` 比 `a` 更好——即「最好」= 兼具大小写的字母中**最靠后**的那个。

**约束**：

- $1 \le \text{s.length} \le 1000$
- `s` 仅由小写和大写英文字母组成

> 💡 本题在本仓库另有[每日题解 2309](../../solution/2301-2400/2309_兼具大小写的最好英文字母.md)：以「出现性位掩码相与求交 + 取最高置位」为主线，含五种取最高置位写法、位运算集合运算表与面试问答。本篇按周赛复盘视角展开，侧重**签到题从题面到代码的最短路径、下标对齐细节、引理-定理证明与边界清单**，两篇互为印证。

## 3. 解题思路

### 3.1 暴力思路：倒序枚举 26 个候选，每个候选全串查找

最直译题面的写法：按「好」的优先级从 `z` 倒序枚举到 `a`，对每个候选字母 $c$ 检查 $c$ 与其大写形式是否都在 `s` 里：

```python
for c in "zyxwvutsrqponmlkjihgfedcba":
    if c in s and c.upper() in s:
        return c.upper()
return ""
```

每个 `in` 是一次 $O(n)$ 扫描，总计 $O(26n) \approx 2.6 \times 10^4$ 次字符比较——在 $n \le 1000$ 下**必然 AC**，作为签到提交完全够用。它的问题是信息重复计算：判定每个候选只需要「某字符**是否出现**」这一比特信息，却每次都重扫整串；若 $n$ 放大到 $10^6$ 就会吃紧。

> 💡 转机在于：判定只依赖**出现性**（与出现位置、次数统统无关），而字母表只有 26 个字母——一趟扫描就能把全部出现性收齐，之后每个候选的检查都是 $O(1)$ 查表。

### 3.2 核心观察：大小写折到同一「字母槽」，双真槽 = 兼具大小写

![核心观察：大小写折到同一字母槽，双真槽即兼具大小写](images/wc298_q1_index_align_concept.svg)

给 26 个字母各编一个**槽号** $i \in [0, 25]$，约定小写 `'a'+i` 与大写 `'A'+i` **共用槽 $i$**（ASCII 中 `'a'-'A'` 恒为 32，减去各自基址后恰好落到同一个 $i$）。一趟扫描维护两个布尔数组：

$$\text{lower}[i] = \text{true} \iff \text{'a'}+i \in s, \qquad \text{upper}[i] = \text{true} \iff \text{'A'}+i \in s$$

于是两个题面条件各塌缩成一次查表：

| 题面条件 | 数据结构刻画 |
|------|------|
| 字母 `'A'+i` **兼具大小写** | $\text{lower}[i] \wedge \text{upper}[i]$（**双真槽**） |
| `'A'+i` 比 `'A'+j` **更好**（$i > j$） | 槽号越大越好 |

「最好」= 双真槽中**槽号最大**者——从 $i = 25$ 倒序扫到 $0$，返回**首个双真槽**对应的大写字母即可；扫完仍无双真槽则返回 `""`。

> ⚠️ **下标对齐是双真有意义的前提**：小写必须减 `'a'`、大写必须减 `'A'`，两边才落在同一套槽号上。若混用（如都减 `'a'`），大写的槽号整体偏移，任何槽都永不可能双真——示例 3 的 `AbCdEfGhIjK` 正是「大小写都有、但不是同一字母」的天然反例，错位的写法会把它误判成有解。

### 3.3 算法流程

![算法流程：一趟扫描建双形态数组，倒序找首个双真槽](images/wc298_q1_algorithm_flow.svg)

1. 初始化 `lower[0..25]`、`upper[0..25]` 全为 `false`；
2. 逐字符扫描 `c ∈ s`：小写则 `lower[c-'a'] = true`，大写则 `upper[c-'A'] = true`；
3. `i` 从 25 倒序到 0：一旦 `lower[i] && upper[i]` 成立，立即返回 `'A' + i`（大写形式）；
4. 循环耗尽仍无命中，返回 `""`。

无预处理、无排序、无回溯，一趟扫描加常数 26 步倒序。

### 3.4 示例演算

![示例演算：示例2 逐槽走查与三例结果对照](images/wc298_q1_example_walkthrough.svg)

以**示例 2** `s = "arRAzFif"` 为例走一遍：

- **扫描**：小写 `a, r, z, f, i` 置位 `lower` 的槽 0, 17, 25, 5, 8；大写 `R, A, F` 置位 `upper` 的槽 17, 0, 5；
- **双真槽**：槽 0（A）、槽 5（F）、槽 17（R）——`i`（8）、`z`（25）仅小写出现，不双真；
- **倒序**：从 25 往下扫，最先命中的双真槽是 17 → 返回 `'A' + 17 = "R"` ✓

示例 1 `lEeTcOdE` 中双真槽只有 4（E）→ 返回 `"E"`；示例 3 `AbCdEfGhIjK` 中小写占的槽（1,3,5,7,9）与大写占的槽（0,2,4,6,8,10）**完全错开**，无双真槽 → 返回 `""`。

> 💡 例 3 的启示：「串里既有大写也有小写」不等于「某字母兼具两形态」——判定必须对齐到**同一字母**的两种形态上，这正是槽号对齐的价值。

## 4. 算法细节

1. **下标对齐公式**：小写 $i = c - \text{'a'}$、大写 $i = c - \text{'A'}$。ASCII 中 `'A'..'Z'` 为 65..90、`'a'..'z'` 为 97..122，差恒为 32，因此同一字母的两形态减各自基址后必然同槽。
2. **大小写判定可只判一侧**：字符集保证仅英文字母，`c >= 'a'`（或 `islower(c)`）为真即小写，否则必为大写，无需两个区间都写。
3. **位技巧彩蛋**：$32 = 1 \ll 5$，故 `c | 32` 归一为小写、`c & ~32` 归一为大写、`c & 31` 直接取出字母槽号、`(c >> 5) & 1` 区分形态（1 小写 / 0 大写）——连 `if` 分支都能省掉（详见文末每日题解与 [周赛 394 Q1](../394/Q1.统计特殊字母的数量I题解.md) 的展开）。
4. **倒序 vs 正序**：倒序找到即返回，天然表达「取最大槽号」；也可以正序扫并维护「当前最大双真槽」，语义等价，倒序版短路更早。
5. **返回大写单字符**：C++ 用 `string(1, 'A' + i)` 构造长度为 1 的串；Python 用 `chr(65 + i)`；无解返回空串 `""`。
6. **位掩码压缩版**：把两个布尔数组压成两个 `int`（第 `i` 位 = 槽 `i`），双真槽 = `lower & upper` 的置位，最大槽号 = 最高置位（Python `bit_length() - 1`，C++ `31 - __builtin_clz(x)`，调用前必须判非零）——见第 7 节与每日题解的完整对照。

## 5. 正确性证明

**引理 1（数组语义）**：扫描结束后，$\text{lower}[i] = \text{true} \iff \text{'a'}+i \in s$，$\text{upper}[i] = \text{true} \iff \text{'A'}+i \in s$。

**证明**：充分性：若字符 $c = \text{'a'}+i$ 在 `s` 中出现，循环必然访问到它并执行 `lower[i] = true`，布尔只增不减，结束时保持 true；`upper` 同理。必要性：置位 `lower[i]` 的唯一途径是访问到字符 $c$ 使 $c - \text{'a'} = i$，即 $c = \text{'a'}+i$ 出现过；初始全 false，故结束时为 true 蕴含该字符出现过。∎

**引理 2（答案刻画）**：字母 `'A'+i` 兼具大小写 $\iff$ 扫描后 $\text{lower}[i] \wedge \text{upper}[i]$；兼具字母非空时，「最好」= 其中槽号 $i$ 最大者。

**证明**：前半由定义直接代入引理 1：「`'A'+i` 的大写与小写都在 `s` 中」即「$\text{'A'}+i \in s$ 且 $\text{'a'}+i \in s$」。后半：题面定义 `b` 比 `a` 更好 $\iff$ `b` 在字母表中更靠后，而 `'A'+i` 的靠后程度由 $i$ 严格单调刻画（$i > j \iff$ `'A'+i` 在 `'A'+j` 之后），故最好者即槽号最大者。∎

**定理**：若 `s` 中存在兼具大小写的字母，算法返回其中最好者的大写形式；否则返回 `""`。

**证明**：倒序循环按 $i = 25, 24, \dots, 0$ 的降序访问槽号，首次满足 $\text{lower}[i] \wedge \text{upper}[i]$ 的 $i^*$ 即所有双真槽的最大槽号。由引理 2，`'A'+i^*` 是最好字母，算法返回 `'A'+i^*` 正是其大写形式。若循环耗尽（$i$ 减到 $-1$）仍无命中，说明双真槽集合为空，由引理 2 不存在兼具字母，算法返回 `""`。两种出口与题意一一对应。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n + 26) = O(n)$，$n = |s|$。一趟扫描每字符做一次比较加一次置位，$O(n)$；倒序判定至多 26 步、每步两次数组访问，为常数。相比暴力版 $O(26n)$，出现性只算一遍；读取输入本身即 $\Omega(n)$，已是下界。
- **空间复杂度**：$O(1)$。两个 26 长布尔数组（或位掩码版的两个 32 位整数）共 52 个布尔，与输入规模无关。

## 7. 参考代码

### C++（主解：一趟扫描 + 倒序取首个双真槽）

```cpp
class Solution {
public:
    string greatestLetter(string s) {
        bool lower[26] = {false}, upper[26] = {false};
        for (char c : s) {
            if (c >= 'a' && c <= 'z') lower[c - 'a'] = true;
            else                       upper[c - 'A'] = true;
        }
        for (int i = 25; i >= 0; --i)
            if (lower[i] && upper[i])
                return string(1, 'A' + i);
        return "";
    }
};
```

### C++（位掩码版：两个出现掩码相与，取最高置位）

```cpp
class Solution {
public:
    string greatestLetter(string s) {
        unsigned lower = 0, upper = 0;
        for (char c : s) {
            if (c >= 'a') lower |= 1u << (c - 'a');   // 字符集仅英文字母，一侧判定即可
            else          upper |= 1u << (c - 'A');
        }
        unsigned both = lower & upper;                 // 双真槽 = 置位
        return both ? string(1, 'A' + 31 - __builtin_clz(both)) : "";
    }
};
```

> ⚠️ `__builtin_clz(0)` 行为未定义，必须先判 `both != 0` 再取最高置位——这正是「先判空再取位」的守则。

### Python（集合版：查表实现倒序枚举）

```python
class Solution:
    def greatestLetter(self, s: str) -> str:
        seen = set(s)
        for i in range(25, -1, -1):
            if chr(65 + i) in seen and chr(97 + i) in seen:
                return chr(65 + i)
        return ""
```

### Python（交集版：出现集求交 + 取最大）

```python
class Solution:
    def greatestLetter(self, s: str) -> str:
        up = {c for c in s if c.isupper()}
        lo = {c.upper() for c in s if c.islower()}   # 小写统一转大写，键自然对齐
        both = up & lo                               # 交集 = 兼具大小写的字母
        return max(both) if both else ""             # 大写字母字典序 = 字母表序
```

> 💡 交集版与主解完全同构：`up & lo` 就是「双真槽」，`max` 就是「槽号最大」——大写字母的字典序与字母表序一致，故 `max` 直取最好。Python 亦可用位掩码：`both = lower & upper` 后 `chr(65 + both.bit_length() - 1)`（先判空），详见每日题解。

## 8. 边界情况与易错点

1. **返回大写形式**：题面对「大写」特意加粗——返回小写 `'r'` 而非 `'R'` 是本题最常见的 WA。
2. **无解返回空串**：返回 `""`，不是 `'0'`、不是空格；倒序循环耗尽后的兜底 `return ""` 别漏写。
3. **下标对齐**：小写减 `'a'`、大写减 `'A'`，混用即整体错位、双真恒假。提交前拿示例 3（错位天然反例）自测。
4. **两个常数别混**：字母表大小是 **26**（数组长度、循环边界），ASCII 大小写差是 **32**（大小写互转的偏移量）。
5. **$n = 1$ 必无解**：单字符不可能兼具两种形态，通用循环天然覆盖，无需特判。
6. **重复与顺序无关**：记录的是**出现性**而非次数或位置——不要被诱导去记「最后一次出现的下标」之类的多余信息。
7. **字符集保证仅英文字母**：分支只需判一侧；若题面放宽到含其它字符，需先过滤非字母再入槽。
8. **位掩码版判空**：`__builtin_clz(0)` 未定义、`bit_length()` 对 0 返回 0 导致 `-1` 错位——先判空再取最高置位。
