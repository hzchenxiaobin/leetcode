# LeetCode 卖木头块 题解

## 1. 题目概述

- **标题 / 题号**：卖木头块（#2312，hard）
- **链接**：https://leetcode.cn/problems/selling-pieces-of-wood/
- **来源**：LeetCode 第 298 场周赛 Q4
- **难度**：困难
- **标签**：动态规划、二维 DP、切分型 DP、记忆化搜索

**题意**：给定一块高为 $m$、宽为 $n$ 的矩形木块和价格表 `prices`，其中 `prices[i] = [hi, wi, pricei]` 表示一块 $h_i \times w_i$ 的小木块可以卖 $\text{price}_i$ 元。每次操作任选一个当前木块，执行一次**完全贯穿**的切割：

- 沿垂直方向按高度完全切割（切线贯穿整高，把**宽度**一分为二），或
- 沿水平方向按宽度完全切割（切线贯穿整宽，把**高度**一分为二），

得到两块更小的矩形。可以切任意多次，切好后按价格表卖出任意子集（同尺寸可重复卖、不必全卖、**不能旋转**木块交换高宽）。求 $m \times n$ 木块最终能换到的**最多钱数**。

**约束**：

- $1 \le m, n \le 200$
- $1 \le \text{prices.length} \le 2 \times 10^4$
- $1 \le h_i \le m$，$1 \le w_i \le n$，$1 \le \text{price}_i \le 10^6$
- 所有 $(h_i, w_i)$ **互不相同**

> 💡 本题在本仓库另有[每日题解 2312](../../solution/2301-2400/2312_卖木头块.md)：以「三决策转移 + 官方示例填表 + 面试问答」为主线。本篇按周赛复盘视角展开：**构造「单刀视角翻车」的最小反例**说明局部决策与单价贪心为何必然失效，沿「切割树」模型给出**引理—定理结构的完整正确性证明**，并覆盖贯穿切割、整型溢出等赛场易错点，两篇互为印证。

## 2. 示例

**示例 1**

```text
输入：m = 3, n = 5, prices = [[1,4,2],[2,2,7],[2,1,3]]
输出：19
解释：3×5 木块切成
  - 2 块 2×2  → 2 × 7 = 14 元
  - 1 块 2×1  → 1 × 3 = 3 元
  - 1 块 1×4  → 1 × 2 = 2 元
  合计 14 + 3 + 2 = 19 元，是最多能得到的钱数。
```

**示例 2**

```text
输入：m = 4, n = 6, prices = [[3,2,10],[1,4,2],[4,1,3]]
输出：32
解释：4×6 木块切成
  - 3 块 3×2  → 3 × 10 = 30 元
  - 1 块 1×4  → 1 × 2 = 2 元
  合计 30 + 2 = 32 元。注意 1×4 不能旋转成 4×1 来卖。
```

**补充示例：单刀视角翻车的最小反例（本文专用）**

```text
输入：m = 3, n = 3, prices = [[3,3,10],[1,3,4],[2,3,5],[2,1,3],[2,2,4]]
输出：13
解释：整块 3×3 报价 10；横切一刀只能得到 1×3 + 2×3 = 4 + 5 = 9，
  竖切一刀更是一无所有 —— 「只比一刀」的结论是不切，卖 10 元。
  但往下再切两层：1×3（卖 4）+ 下块 2×3 竖切成三个 2×1（卖 3+3+3），
  合计 4 + 3 + 3 + 3 = 13 ＞ 10，深切反超。
```

## 3. 解题思路

### 3.1 暴力思路：枚举切割方案

一个完整的切割方案是一棵**切割树**：根是 $m \times n$ 整块，每个内部节点是「对某块矩形切一刀」，叶子是最终小木块。树的形态随切割次数增长呈指数级，而切割次数又没有上界提示（全靠尺寸缩到 1 才被迫停），直接 DFS 枚举所有切法连复杂度都无法估计。

关键转折在于：**不同切割树会反复求解同一尺寸的子问题**。一块 $i \times j$ 的木块无论从哪条路径切出来，能卖的钱只依赖尺寸 $(i,j)$，与它在大块中的位置无关（价格表按尺寸报价）。子问题只有 $m \times n$ 个尺寸，把「方案空间」压成「状态空间」，就是记忆化 / 递推 DP。

### 3.2 核心观察：局部决策会翻车，子结构必须递归

困难题最先要排除的是「能不能贪」。两个直觉都会翻车：

![贪心陷阱：单刀视角与单价贪心都会翻车](images/wc298_q4_greedy_trap.svg)

**直觉一：「整块报价不小于任何一刀两半的报价和，就别切」** —— 补充示例直接打脸：整块 $3\times3$ 报 10，最好的一刀只值 $4+5=9$，看似不该切；但子块内部还能继续切（$2\times3$ 再竖切成三个 $2\times1$），深挖两层得 13。用「原始报价」比一刀是假象，必须用**子块自己的最优值**去比。

**直觉二：「按单价（元 / 面积）贪心地先切高单价块」** —— 同样没有正确性保证：如 $3\times3$ 整块报 11、$2\times2$ 报 8（单价 2.0 最高），先抢 $2\times2$ 会留下无报价的边角（如 $1\times3$、$2\times1$），总共只赚 8 ＜ 11，反而不如整块卖。

> 💡 **为什么只能 DP**：一刀切完，两块小木块**独立定价、互不影响**（这正是「完全贯穿 + 按尺寸报价」送上的**最优子结构**）。于是「一块 $i\times j$ 木块最多卖多少钱」$=$ 「整块报价」与「所有一刀的两半最优值之和」的最大值 —— 天然的递归结构，且子状态面积严格变小，无环。

### 3.3 状态设计与转移：三选一取最大

![状态转移：dp[i][j] = max(整块卖, 横切, 竖切) 与切割树模型](images/wc298_q4_dp_recurrence.svg)

设 $dp[i][j]$ 表示**高 $i$、宽 $j$ 的木块**能卖出的最多钱数，$\text{price}[i][j]$ 为该尺寸的报价（无报价记 0）。三类决策取最大：

$$dp[i][j] = \max\Big(\ \text{price}[i][j],\ \ \max_{1 \le k < i}\big(dp[k][j] + dp[i-k][j]\big),\ \ \max_{1 \le k < j}\big(dp[i][k] + dp[i][j-k]\big)\ \Big)$$

- **决策 ① 整块出售**：不切，直接卖 $\text{price}[i][j]$；
- **决策 ② 横切一刀**（切线贯穿整宽，分裂高度）：在高度 $k$ 处切开，得 $k\times j$ 与 $(i-k)\times j$，两者**独立**取最优再相加；
- **决策 ③ 竖切一刀**（切线贯穿整高，分裂宽度）：在宽度 $k$ 处切开，得 $i\times k$ 与 $i\times (j-k)$，同理。

任何切割树的根节点要么是叶（不切，整块卖或扔），要么横切一刀，要么竖切一刀 —— 三类决策**不重不漏**地覆盖了根的所有可能，这就是转移完备性的来源（严格论证见第 5 节）。

**填表顺序**：$dp[i][j]$ 依赖的 $dp[k][j]$（$k \lt i$）与 $dp[i][j-k]$（$j-k \lt j$）的面积都严格更小，外层 $i$ 从 1 到 $m$、内层 $j$ 从 1 到 $n$ 双升序填表，被依赖状态必然先算好。

### 3.4 示例演算

![示例演算：3×3 反例的 dp 表与最优切割树](images/wc298_q4_dp_walkthrough.svg)

以补充示例（$m=n=3$，报价 $3\times3\to10$、$1\times3\to4$、$2\times3\to5$、$2\times1\to3$、$2\times2\to4$）逐格填表：

| $i \backslash j$ | 1 | 2 | 3 |
|---|---|---|---|
| 1 | 0 | 0 | 4 |
| 2 | 3 | **6** | **9** |
| 3 | 3 | 6 | **13** |

- $dp[2][2] = 6$：竖切 $k=1$ → $dp[2][1]+dp[2][1] = 3+3$，胜过整块报价 4；
- $dp[2][3] = 9$：竖切 $k=1$ → $dp[2][1]+dp[2][2] = 3+6$，胜过横切 $4+4=8$ 与整块 5；
- $dp[3][3] = 13$：横切 $k=1$ → $dp[1][3]+dp[2][3] = 4+9$，胜过整块 10 与竖切 $3+6=9$。

从 $dp[3][3]$ 回溯最优切割树：$3\times3$ 横切成 $1\times3$（卖 4）$+\ 2\times3$；$2\times3$ 竖切成 $2\times1$（卖 3）$+\ 2\times2$；$2\times2$ 再竖切成两个 $2\times1$（各卖 3）。叶子合计 $4+3+3+3=13$ ✓。

## 4. 算法细节

1. **价格表**：用 $(m+1)\times(n+1)$ 二维数组 `price[h][w]`，无报价默认 0。$(h_i,w_i)$ 互不相同保证直接赋值即可；若数据可能含重复尺寸，取 `max` 更稳。
2. **基线先置**：每格先令 $dp[i][j] = \text{price}[i][j]$，再枚举切点取 max 更新 —— 「整块卖」天然成为候选之一，无报价即基线 0，无需任何特判。
3. **切点范围**：横切 $k \in [1, i-1]$、竖切 $k \in [1, j-1]$。$k=i$ 或 $k=j$ 会产生零尺寸的「矩形」，$k=0$ 同理非法。
4. **填表顺序**：外层 $i$ 升序、内层 $j$ 升序；依赖只有 $(k,j)$（更小行）与 $(i,j-k)$（同行更小列），一次双重循环即可，无需显式拓扑排序。
5. **整型溢出**：极端情形 $m=n=200$ 且 $1\times1$ 报价 $10^6$，总收入可达 $200\times200\times10^6 = 4\times10^{10}$，远超 `int` 上界 $2.1\times10^9$ —— C++ 中 `dp`、`price` 与返回值全程 `long long`。
6. **可选常数优化**：$k$ 与 $i-k$ 对称（$dp[k][j]+dp[i-k][j]$ 与交换后相同），横切只需枚举到 $\lfloor i/2 \rfloor$，竖切同理；注意 $i$ 为偶数时 $k=i/2$ 的「自对称切法」不能漏。渐近复杂度不变。
7. **记忆化搜索等价**：自顶向下 `dfs(i,j)` 配 `lru_cache` 与递推同构，$m,n\le200$ 时递归深度至多 $400$，Python 默认栈足够；赛场按习惯二选一即可。

## 5. 正确性证明

**记号**：一块高 $h$ 宽 $w$ 的矩形记作 $(h,w)$；$\text{price}[i][j]$ 为 $(i,j)$ 的报价（无则 0，恒 $\ge 0$）。称一棵二叉树为**切割树**，若：根标号 $(m,n)$；每个内部节点标号 $(i,j)$，其两个孩子标号为 $(k,j)$ 与 $(i-k,j)$（横切，$1\le k\lt i$）或 $(i,k)$ 与 $(i,j-k)$（竖切，$1\le k\lt j$）；每个叶子标号一块最终小木块，标记「卖」（得该尺寸报价）或「扔」（得 0）。

**引理 1（操作序列 ⟺ 切割树）**：对 $m\times n$ 木块任意有限次切割操作，最终木块集合恰为某棵切割树的叶子集合；反之，任何切割树都能被一组合法操作实现。

**证明**：对切割次数 $t$ 归纳。$t=0$：单节点树。设 $t$ 刀对应树 $T$；第 $t+1$ 刀作用于当前某块 $(i,j)$，它是 $T$ 的一个叶，该刀（完全贯穿）恰好给这个叶挂上两个新叶（切点 $k$ 与方向决定孩子尺寸），仍满足切割树定义。反之，对切割树 $T$ 按「父亲先于孩子」的次序（如自顶向下逐层）处理内部节点：每刀作用在当前尺寸恰为该节点标号的整块上，是合法贯穿切割，有限步实现 $T$。∎

**引理 2（叶子独立定价）**：固定切割树的形态后，可得的最大钱数 $= \sum_{\text{叶子}} \text{price}(\text{叶子})$。

**证明**：各叶子卖或不卖互不约束（题目允许卖任意子集、同尺寸可重复卖），收益按叶子可加；「扔」贡献 0，报价恒 $\ge 0$，故每片叶子的贡献为 $\max(\text{price}, 0) = \text{price}$。∎

**引理 3（最优子结构）**：设 $V(i,j)$ 为 $(i,j)$ 木块的真实最优收益，则

$$V(i,j) = \max\Big(\text{price}[i][j],\ \max_{1 \le k < i}\big(V(k,j)+V(i-k,j)\big),\ \max_{1 \le k < j}\big(V(i,k)+V(i,j-k)\big)\Big)$$

**证明**：（$\le$）任一可行方案对应一棵切割树（引理 1），其收益（引理 2）按根分类：根为叶（一刀未切）时收益 $\le \text{price}[i][j]$；根为内部节点且横切 $k$ 时，收益为左右子树叶子收益之和，而每棵子树本身就是其矩形上的一组可行方案，故 $\le V(k,j)+V(i-k,j)$；竖切同理。三类取最大即得右端。（$\ge$）右端每个候选均可实现：整块出售得 $\text{price}[i][j]$；先切一刀，在两块上分别执行各自的最优方案，由引理 2 收益可加，得 $V(k,j)+V(i-k,j)$（竖切同理）。∎

**定理**：按 $i$ 升序、$j$ 升序填表（每格基线为 $\text{price}[i][j]$，再枚举切点取 max）得到的 $dp[m][n]$ 等于 $V(m,n)$。

**证明**：对面积 $i\cdot j$ 作强归纳。$i\cdot j=1$：$i=j=1$，切点区间为空，$dp[1][1]=\text{price}[1][1]=V(1,1)$。设结论对一切面积 $\lt i\cdot j$ 的矩形成立。填表顺序保证计算 $dp[i][j]$ 时，$dp[k][j]$（$k\lt i$，面积 $kj\lt ij$）与 $dp[i][j-k]$（面积 $i(j-k)\lt ij$）均已求出，由归纳假设均等于真实最优值；于是 $dp[i][j]$ 的取值与引理 3 右端逐项相同，故 $dp[i][j]=V(i,j)$。∎

> 💡 **证明骨架**：引理 1 把「无限切的方案流」物化为有限的二叉树；引理 2 给出叶子收益可加（「不必全卖」由「扔 = 0 且报价 $\ge 0$」自动覆盖）；引理 3 由根的三分类得到最优子结构；定理再沿「面积严格递减 + 填表序」归纳，保证递推值就是全局最优。

## 6. 复杂度分析

- **时间复杂度**：$O\big(mn(m+n)\big)$。共 $mn$ 个状态，每状态枚举横切点 $O(i-1)$ 与竖切点 $O(j-1)$，合计 $O(i+j) \le O(m+n)$；$m=n=200$ 时约 $200\times200\times400 \approx 1.6\times10^7$ 次比较，毫秒级。
- **空间复杂度**：$O(mn)$，即 `dp` 与 `price` 两张 $(m+1)\times(n+1)$ 的表；记忆化搜索版另加 $O(m+n)$ 递归栈。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    long long sellingWood(int m, int n, vector<vector<int>>& prices) {
        vector<vector<long long>> price(m + 1, vector<long long>(n + 1, 0));
        for (auto& p : prices) {
            price[p[0]][p[1]] = p[2];
        }

        vector<vector<long long>> dp(m + 1, vector<long long>(n + 1, 0));
        for (int i = 1; i <= m; ++i) {
            for (int j = 1; j <= n; ++j) {
                dp[i][j] = price[i][j];              // 基线：整块卖（无报价则 0）
                for (int k = 1; k < i; ++k) {        // 横切：分裂高度
                    dp[i][j] = max(dp[i][j], dp[k][j] + dp[i - k][j]);
                }
                for (int k = 1; k < j; ++k) {        // 竖切：分裂宽度
                    dp[i][j] = max(dp[i][j], dp[i][k] + dp[i][j - k]);
                }
            }
        }
        return dp[m][n];
    }
};
```

### Python

```python
class Solution:
    def sellingWood(self, m: int, n: int, prices: List[List[int]]) -> int:
        price = [[0] * (n + 1) for _ in range(m + 1)]
        for h, w, p in prices:
            price[h][w] = p

        dp = [[0] * (n + 1) for _ in range(m + 1)]
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                dp[i][j] = price[i][j]                     # 基线：整块卖
                for k in range(1, i):                      # 横切：分裂高度
                    dp[i][j] = max(dp[i][j], dp[k][j] + dp[i - k][j])
                for k in range(1, j):                      # 竖切：分裂宽度
                    dp[i][j] = max(dp[i][j], dp[i][k] + dp[i][j - k])
        return dp[m][n]
```

## 8. 边界情况与易错点

1. **整型溢出（最大陷阱）**：总收入上界 $4\times10^{10}$，超出 `int` 约 $2.1\times10^9$ 的范围；C++ 中表和返回值都要 `long long`，写成 `int` 会在大数据上 WA 而非 RE，很难察觉。Python 无此问题。
2. **无报价 ≠ 无用**：基线 0 的格子仍要枚举切点 —— 大块的价值可能全靠「切穿无报价区」落到有报价的小块上（补充示例里 $2\times2$ 报价 4 都被三个 $2\times1$ 切赢）。切忌 `if (price == 0) continue;`。
3. **基线先置、切点后 max**：顺序颠倒或漏置基线，会把「整块出售」这个候选悄悄丢掉。
4. **切点边界**：$k \in [1, i-1]$ / $[1, j-1]$。把循环写成 `k <= i` 会产生 $0\times j$ 的零尺寸块（下标 0 行/列恰好是 0 值，未必报错，更隐蔽）。
5. **方向别搞反**：横切分裂的是**高度**（得 $k\times j$ 与 $(i-k)\times j$），竖切分裂的是**宽度**。方向写反不影响正确性（两类决策对称覆盖），但会误导复盘。
6. **m = n = 1**：两个切点区间均为空，答案 = 报价或 0，代码自然覆盖。
7. **「不必全卖」**：由基线 0 与报价 $\ge 0$ 自动覆盖（扔掉 = 贡献 0），无需特判（引理 2）。
8. **不能旋转**：$\text{price}[h][w]$ 与 $\text{price}[w][h]$ 是两条独立报价，读入时不要「归一化」成 $\big(\min,\max\big)$；示例 2 的 1×4 卖不了 4×1 的价。
9. **只能完全贯穿**：所有可达分块都是「贯通切割」（guillotine）分割，L 形、风车形等非贯穿拼法根本不可达，不要往「任意矩形划分」上想复杂了。

**延伸思考**：① 若**允许旋转**：报价需先对称化 $\text{price}[h][w] \leftarrow \max(\text{price}[h][w], \text{price}[w][h])$，且 $dp[i][j]$ 与 $dp[j][i]$ 相互引用，宜改用记忆化搜索或按「短边 $\le$ 长边」归一化填表；② 若要求**输出具体切法**：在每格旁记录 $\text{choice}[i][j]$（整卖 / 横切 $k$ / 竖切 $k$），从 $(m,n)$ 回溯即可还原一棵最优切割树；③ 切点枚举的 $O(m+n)$ 能否再降：转移是两个子状态之和，非凸非单调，四边形不等式等经典优化不适用，$O\big(mn(m+n)\big)$ 已是通行做法。
