# LeetCode 行列循环移位 题解

## 1. 题目概述

- **标题 / 题号**:行列循环移位(#4052,Easy)
- **链接**:https://leetcode.cn/problems/cyclically-shift-rows-and-columns/
- **来源**:LeetCode 第 519 场周赛 Q1
- **难度**:简单
- **标签**:数组、矩阵、模拟

**题意**:给定 $n \times n$ 的整数网格 `grid` 与两个长度为 $n$ 的数组 `rowShift`、`colShift`。先对每一行做**向左循环移位**:第 $i$ 行左移 `rowShift[i]` 位,该行原本第 $j$ 列的元素移动到第 $(j - k + n) \bmod n$ 列;再对每一列做**向上循环移位**:第 $j$ 列上移 `colShift[j]` 位,该列原本第 $i$ 行的元素移动到第 $(i - m + n) \bmod n$ 行。返回全部移位完成后的网格。

**约束**:

- $1 \le n = \mathrm{grid.length} = \mathrm{grid[i].length} \le 10$
- $1 \le \mathrm{grid[i][j]} \le 100$
- $\mathrm{rowShift.length} = \mathrm{colShift.length} = n$
- $0 \le \mathrm{rowShift[i]}, \mathrm{colShift[i]} < n$

## 2. 示例

**示例 1**

```text
输入:n = 2, grid = [[1,2],[3,4]], rowShift = [1,0], colShift = [0,1]
输出:[[2,4],[3,1]]
解释:行移位后 grid 变为 [[2,1],[3,4]];再让第 1 列上移 1 位,得到 [[2,4],[3,1]]。
```

**示例 2**

```text
输入:n = 3, grid = [[1,2,3],[4,5,6],[7,8,9]], rowShift = [1,2,0], colShift = [2,2,1]
输出:[[7,8,5],[2,3,9],[6,4,1]]
解释:行移位后得到 [[2,3,1],[6,4,5],[7,8,9]];再对第 0、1、2 列分别上移 2、2、1 位,得到 [[7,8,5],[2,3,9],[6,4,1]]。
```

## 3. 解题思路

### 3.1 朴素思路

这是标准模拟题:数据范围 $n \le 10$,总共至多 $100$ 个格子,任何正确写法都是 $O(n^2)$,复杂度上没有压力,难点全在**下标映射不写错**。

最朴素的写法是照题面"**推出**"的定义逐元素搬运:对行 $i$ 的每个元素,先算出目标列 $(j - k + n) \bmod n$ 再写入新行。这种写法要显式处理取模,一旦把 $j - k$ 写成 $j + k$、或忘记 $+n$,就会整体移错方向。

### 3.2 核心观察:用「拉取」公式代替「推出」

题面定义是"旧元素去哪里"(**推出**),写代码时把它反过来变成"新格子从哪里取数"(**拉取**),二者互为逆映射:

- 第 $i$ 行左移 $k$ 位后的新行 $b$ 满足 $b[j] = a[(j + k) \bmod n]$,其中 $a$ 为原行;
- 第 $j$ 列上移 $m$ 位后的新列 $d$ 满足 $d[i] = c[(i + m) \bmod n]$,其中 $c$ 为原列。

拉取式右边下标 $(j+k) \bmod n$ 恒在 $[0, n)$ 内,**天然无越界、无特判**,左移/上移方向也不会搞反。

![拉取公式示意](images/c519_shift_direction_concept.svg)

在此基础上,整个题就是**两遍扫描**:第一遍对每行拉取做行移位得到临时矩阵 `tmp`,第二遍对 `tmp` 的每列拉取做列移位得到答案。

> ⚠️ **顺序陷阱**:题目规定**先全体行移位、再全体列移位**,两次操作不可交换。更隐蔽的是:若想把两遍合成一遍直接写 `ans[i][j] = grid[...]`,答案格 $(i, j)$ 的来源行是 $r = (i + \mathrm{colShift}[j]) \bmod n$,而生效的行移位是 `rowShift[r]` 而**不是** `rowShift[i]`——列移位搬运的是"已经行移位过的行"。

### 3.3 算法流程

1. **第一遍(行左移)**:新建 $n \times n$ 矩阵 `tmp`,令
   $$\mathrm{tmp}[i][j] = \mathrm{grid}[i][(j + \mathrm{rowShift}[i]) \bmod n];$$
2. **第二遍(列上移)**:新建 $n \times n$ 矩阵 `ans`,令
   $$\mathrm{ans}[i][j] = \mathrm{tmp}[(i + \mathrm{colShift}[j]) \bmod n][j];$$
3. 返回 `ans`。

![两遍扫描流程](images/c519_two_pass_flow.svg)

### 3.4 示例演算

以示例 2($n = 3$)为例。

**第一遍:行左移**(`rowShift = [1,2,0]`)

- 行 0 左移 1 位:$[1,2,3] \to [2,3,1]$
- 行 1 左移 2 位:$[4,5,6] \to [6,4,5]$
- 行 2 左移 0 位:$[7,8,9] \to [7,8,9]$

得 `tmp = [[2,3,1],[6,4,5],[7,8,9]]`。

**第二遍:列上移**(`colShift = [2,2,1]`)

| 列 $j$ | 上移位数 | tmp 中该列(自上而下) | 上移后(自上而下) |
|--------|---------|----------------------|------------------|
| 0 | 2 | $2, 6, 7$ | $7, 2, 6$ |
| 1 | 2 | $3, 4, 8$ | $8, 3, 4$ |
| 2 | 1 | $1, 5, 9$ | $5, 9, 1$ |

得 `ans = [[7,8,5],[2,3,9],[6,4,1]]`,与题目输出一致。✓

## 4. 算法细节

1. **行移位遍**:双重循环枚举 $(i, j)$,直接套拉取公式 $\mathrm{tmp}[i][j] = \mathrm{grid}[i][(j + \mathrm{rowShift}[i]) \bmod n]$。注意 `rowShift[i]` 按**目标行**(也就是当前行)取——行移位时行号不变,来源行就是 $i$ 自己。

2. **列移位遍**:双重循环枚举 $(i, j)$,套 $\mathrm{ans}[i][j] = \mathrm{tmp}[(i + \mathrm{colShift}[j]) \bmod n][j]$。列移位时列号不变,来源列就是 $j$ 自己,变的只是行号。

3. **复合成一遍(可选)**:把两式代入合并,得
   $$\mathrm{ans}[i][j] = \mathrm{grid}\big[(i + \mathrm{colShift}[j]) \bmod n\big]\big[(j + \mathrm{rowShift}[(i + \mathrm{colShift}[j]) \bmod n]) \bmod n\big]$$
   内层 `rowShift` 的下标是**来源行** $r = (i + \mathrm{colShift}[j]) \bmod n$。比赛时建议老老实实写两遍,不易错。

4. **移位数先取模**:约束保证 $0 \le \mathrm{shift} < n$,无需额外归一化;防御性地对 $n$ 取模也无害(结果不变)。$k = 0$ 时公式退化为原样复制,自然成立。

## 5. 正确性证明

**引理 1(行拉取公式)**:把行 $a = a_0, a_1, \dots, a_{n-1}$ 向左循环移位 $k$ 位得到行 $b$,则对一切 $0 \le j < n$ 有 $b[j] = a[(j + k) \bmod n]$。

**证明**:按题面定义,$a$ 中第 $c$ 列的元素移动到第 $(c - k + n) \bmod n$ 列,即 $b[(c - k + n) \bmod n] = a[c]$。任取 $j \in [0, n)$,令 $c = (j + k) \bmod n$,则 $c \in [0, n)$ 且 $c \equiv j + k \pmod n$,于是 $(c - k + n) \bmod n = (j + k - k + n) \bmod n = j \bmod n = j$,代入得 $b[j] = a[(j + k) \bmod n]$。∎

**引理 2(列拉取公式)**:把列 $c$ 向上循环移位 $m$ 位得到列 $d$,则对一切 $0 \le i < n$ 有 $d[i] = c[(i + m) \bmod n]$。

**证明**:与引理 1 同构,把"行/左移/$k$/列号 $j$"逐字替换为"列/上移/$m$/行号 $i$"即得。∎

**定理**:两遍扫描结束后,`ans` 恰为题目要求的最终网格。

**证明**:第一遍对每个行号 $i$ 应用引理 1(移位量 `rowShift[i]`),得到的 `tmp` 与"全体行左移后的网格"逐格相等;且行移位只在行内搬运元素,各行互不影响,逐行独立应用引理即覆盖整个矩阵。第二遍在 `tmp` 上对每个列号 $j$ 应用引理 2(移位量 `colShift[j]`),同理得到的 `ans` 与"再对 `tmp` 全体列上移后的网格"逐格相等。两遍的先后次序与题目"先行移位、后列移位"的规定一致,而网格的最终状态由操作序列唯一确定,故 `ans` 即所求。∎

## 6. 复杂度分析

- **时间复杂度**:$O(n^2)$。两遍扫描各枚举全部 $n^2$ 个格子,每个格子 $O(1)$ 套拉取公式。$n \le 10$ 时至多约 $200$ 次赋值。
- **空间复杂度**:$O(n^2)$。`tmp` 与 `ans` 各占 $n^2$;若原地修改(行移位逐行用临时行缓冲、列移位逐列用临时列缓冲)可降到 $O(n)$,但 $n \le 10$ 下没有必要。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    vector<vector<int>> cyclicShift(int n, vector<vector<int>>& grid,
                                    vector<int>& rowShift, vector<int>& colShift) {
        // 第一遍:行左移 tmp[i][j] = grid[i][(j + rowShift[i]) % n]
        vector<vector<int>> tmp(n, vector<int>(n));
        for (int i = 0; i < n; i++)
            for (int j = 0; j < n; j++)
                tmp[i][j] = grid[i][(j + rowShift[i]) % n];
        // 第二遍:列上移 ans[i][j] = tmp[(i + colShift[j]) % n][j]
        vector<vector<int>> ans(n, vector<int>(n));
        for (int i = 0; i < n; i++)
            for (int j = 0; j < n; j++)
                ans[i][j] = tmp[(i + colShift[j]) % n][j];
        return ans;
    }
};
```

### Python

```python
class Solution:
    def cyclicShift(self, n: int, grid: List[List[int]],
                    rowShift: List[int], colShift: List[int]) -> List[List[int]]:
        # 第一遍:行左移 tmp[i][j] = grid[i][(j + rowShift[i]) % n]
        tmp = [[grid[i][(j + rowShift[i]) % n] for j in range(n)] for i in range(n)]
        # 第二遍:列上移 ans[i][j] = tmp[(i + colShift[j]) % n][j]
        return [[tmp[(i + colShift[j]) % n][j] for j in range(n)] for i in range(n)]
```

## 8. 边界情况与易错点

1. **方向写反**:"左移 $k$"对应 $b[j] = a[(j+k) \bmod n]$,把它写成 $b[(j+k) \bmod n] = a[j]$ 就成了右移。列移位同理。拉取式从"新格取数"出发,最不容易犯这个错。
2. **合成一遍时的 `rowShift` 行号陷阱**:来源行 $r = (i + \mathrm{colShift}[j]) \bmod n$,生效的行移位是 `rowShift[r]` 而非 `rowShift[i]`。这是本题最常见的 WA 来源,两遍写法天然规避。
3. **操作顺序不可交换**:题目规定先行后列。以 $n=2$、`grid=[[1,2],[3,4]]`、`rowShift=[1,0]`、`colShift=[0,1]` 为例,先行后列得 `[[2,4],[3,1]]`,先列后行得 `[[4,1],[3,2]]`,结果不同。
4. **忘记取模**:$j + k$ 可能达到 $2n - 2$,必须 $\bmod n$;虽然约束下 $k < n$ 不会让 $j - k$ 为负,"推出"式仍建议写 $(j - k + n) \bmod n$ 保险。
5. **$n = 1$ 的最小情形**:唯一格子所有移位都是 $0$ 位,网格不变,公式自动成立($\bmod 1$ 恒为 $0$),无需特判。
6. **原地修改的读写干扰**:若第一遍直接写回 `grid` 且逐格读写同一行,未写入的旧值可能已被覆盖,应整行拷贝到临时行再回写;直接用独立的 `tmp`、`ans` 两个矩阵最省心。
