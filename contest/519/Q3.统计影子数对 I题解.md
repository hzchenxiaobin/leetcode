# LeetCode 统计影子数对 I 题解

## 1. 题目概述

- **标题 / 题号**：统计影子数对 I（#4054）
- **链接**：https://leetcode.cn/problems/count-shadow-pairs-i/
- **来源**：LeetCode 第 519 场周赛 Q3
- **难度**：中等
- **标签**：单调栈、数组、计数

**题意**：给定长度为 $n$ 的整数数组 $nums$，统计同时满足以下条件的下标对 $(i, j)$（**影子对**）的数量：

1. $0 \le i < j < n$；
2. $nums[i] < nums[j]$；
3. 不存在下标 $k$ 满足 $i < k < j$ 且 $nums[k] < nums[i] < nums[j]$（中间没有比 $nums[i]$ 更小的元素「阻挡」）。

由于条件 2 已保证 $nums[i] < nums[j]$，条件 3 里的 $nums[k] < nums[i] < nums[j]$ 等价于 $nums[k] < nums[i]$。因此**影子对 $\iff nums[i] < nums[j]$ 且 $\min(nums[i+1..j-1]) \ge nums[i]$**——即 $nums[i]$ 恰好是子数组 $nums[i..j]$ 的最小值，且右端点严格更大。

**约束**：

- $3 \le n \le 10^5$
- $1 \le nums[i] \le 10^9$

## 3. 解题思路

### 3.1 暴力思路

三重循环：枚举 $i < j$，再扫一遍 $(i,j)$ 检查是否存在 $nums[k] < nums[i]$，$O(n^3)$。稍微优化：固定 $i$ 向右推进 $j$，维护区间最小值，一旦最小值 $< nums[i]$ 即可停止（后面的 $j$ 全被阻挡），最坏 $O(n^2)$（严格递增数组达到上界）。$n = 10^5$ 时约 $10^{10}$ 次操作，必然超时。

### 3.2 核心观察：候选左端点集合随 j 右移「单调收缩」

对固定的 $j$，去掉 $nums[i] < nums[j]$ 筛选前的合法左端点集合为

$$S_j = \{\, i < j : \min(nums[i+1..j-1]) \ge nums[i] \,\}$$

观察 $j \to j+1$ 时集合如何变化：新元素 $x = nums[j]$ 进入所有候选的右侧区间——

- **值 $> x$ 的候选 $i$**：$nums[j] = x < nums[i]$，从 $j+1$ 起被下标 $j$ **永久阻挡**，从集合中删除；
- **值 $\le x$ 的候选 $i$**：仍然合法，保留；
- **新下标 $j$ 本身**进入集合。

这正是「弹出严格大于当前值」的**单调栈**！栈中候选的值从栈底到栈顶**非降**。而以 $j$ 为右端点的影子对数 = 栈中（弹出后）**值严格小于 $nums[j]$** 的候选个数。

![影子对判定条件概念图](images/c519_shadow_pairs_block_concept.svg)

### 3.3 算法流程：单调栈 + 「值 × 个数」分块计数

若栈里逐个存值，则「值 $< x$ 的个数」要在非降序列上二分，$O(n\log n)$ 也能通过。更优雅：把**相同值压成（值, 个数）块**，块值从栈底到栈顶严格递增，每步 $O(1)$ 完成计数。处理 $nums[j] = x$：

1. **弹出**：不断弹出值 $> x$ 的块（被 $x$ 永久阻挡），同步扣减栈内元素总数 $total$；
2. **计数**：此时栈中值都 $\le x$。若栈顶块值 $= x$，本步答案增量 $= total - $ 栈顶块个数（值相等的候选不配对）；否则（栈空或栈顶值 $< x$）增量 $= total$；
3. **入栈**：栈顶块值 $= x$ 则个数 $+1$（合并），否则压入新块 $(x, 1)$，随后 $total$ 加一。

![候选栈分块计数模型](images/c519_shadow_pairs_stack_model.svg)

### 3.4 示例演算

对 $nums = [3,1,4,1,5]$（示例 1）逐步走查，栈写作「值×个数」列表（左底右顶）：

| $j$ | $x$ | 弹出 | 本步增量 | 入栈后的栈 | ans |
|-----|-----|------|---------|-----------|-----|
| 0 | 3 | —（栈空） | $+0$ | [3×1] | 0 |
| 1 | 1 | 弹 3×1（$3>1$） | $+0$ | [1×1] | 0 |

| 4 | 5 | 无 | $+2$ → (1,4),(3,4) | [1×2, 5×1] | 3 |

## 4. 算法细节

1. **两处「严格」不可混淆**：阻挡需要 $nums[k] < nums[i]$ **严格**小于（相等不阻挡，示例 2 的 (2,4)）；配对需要 $nums[i] < nums[j]$ **严格**小于（相等不配对）。因此弹出条件必须是「值 $> x$」，值 $= x$ 的候选要保留；计数时再把值 $= x$ 的块剔除。
2. **分块的正确性**：入栈时值与栈顶相同则合并，故任意时刻块值从栈底到栈顶严格递增；弹出后栈中值都 $\le x$，于是「值 $< x$ 的元素个数」$= total -$（栈顶块个数，仅当栈顶值 $= x$）。
3. **替代实现**：栈中直接存值（非降），每步弹出 $> x$ 的值后在栈上二分（`lower_bound`）数出「值 $< x$」的个数，$O(n\log n)$ 同样通过；但**不能**从栈顶线性数相等值——$[1,1,\dots,1,2]$ 这类数据会退化到 $O(n^2)$。
4. **答案用 64 位**：$n = 10^5$ 时答案上界 $\binom{n}{2} \approx 5\times10^9$，超出 `int32`（官方 C++ 签名即返回 `long long`）。

## 5. 正确性证明

**引理 1（无阻挡条件的刻画）**：对 $i < j$，「$nums[i] < nums[j]$ 且不存在 $k \in (i,j)$ 使 $nums[k] < nums[i] < nums[j]$」等价于「$nums[i] < nums[j]$ 且 $\min(nums[i+1..j-1]) \ge nums[i]$」。

**证明**：在 $nums[i] < nums[j]$ 成立的前提下，$nums[k] < nums[i] < nums[j] \iff nums[k] < nums[i]$，故「不存在阻挡」$\iff$ 所有 $k \in (i,j)$ 满足 $nums[k] \ge nums[i] \iff \min(nums[i+1..j-1]) \ge nums[i]$（$j = i+1$ 时空区间，视为自动成立）。∎

**引理 2（栈不变量）**：处理下标 $j$ 之前，栈中恰为集合 $S_j = \{\, i < j : \min(nums[i+1..j-1]) \ge nums[i] \,\}$（逐元素看值非降；分块表示下块值严格递增），$total = |S_j|$。

**证明**：对 $j$ 归纳。$j = 0$ 时栈空，$S_0 = \emptyset$，成立。设处理 $j$ 前栈 $= S_j$，记 $x = nums[j]$。对任意 $i < j$：

$$i \in S_{j+1} \iff \min(nums[i+1..j]) \ge nums[i] \iff i \in S_j \ \text{且}\ nums[i] \le x$$

即 $S_{j+1} = \{\, i \in S_j : nums[i] \le x \,\} \cup \{j\}$。算法第 1 步弹出的恰是 $S_j$ 中值 $> x$ 的候选；第 3 步把 $j$ 入栈（或与同值栈顶块合并）。归纳保持，且弹出、合并、入栈都不破坏「值非降」。∎

**引理 3（弹出的永久性）**：候选 $i$ 若因 $nums[i] > nums[j]$ 在处理 $j$ 时被弹出，则对一切 $j' > j$ 都有 $i \notin S_{j'}$。

**证明**：此时 $j \in (i, j')$ 且 $nums[j] < nums[i]$，故 $\min(nums[i+1..j'-1]) \le nums[j] < nums[i]$。∎

**定理**：算法返回值等于影子对总数。

**证明**：由引理 1，以 $j$ 为右端点的影子对集合 $= \{\, i \in S_j : nums[i] < nums[j] \,\}$。处理 $j$ 时先弹出值 $> x$ 的块，由引理 2 栈中剩下恰为 $\{\, i \in S_j : nums[i] \le x \,\}$，且值非降——值 $< x$ 的元素恰是「除栈顶同值块外」的全部元素，个数 $= total -$ 栈顶块个数（栈顶值 $= x$ 时），否则 $= total$，与第 2 步一致。由引理 3，被弹出的候选对任何后续右端点都不合法，弹出无损；由引理 2，留在栈中的候选一个不漏。对所有 $j$ 求和即得总数。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。每个元素恰产生一次压栈；每个块至多被弹出一次，弹出总代价均摊 $O(n)$；每步的计数、合并、压栈均为 $O(1)$。
- **空间复杂度**：$O(n)$。最坏情况（如严格递增数组，值两两不同）栈中存约 $n$ 个块；全相等数组则只有 1 个块。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    long long shadowPairs(vector<int>& nums) {
        vector<pair<int, int>> stk;  // (值, 个数)，块值从栈底到栈顶严格递增
        long long total = 0, ans = 0;  // total = 栈内元素总数
        for (int x : nums) {
            // ① 弹出值 > x 的块：被 x 永久阻挡
            while (!stk.empty() && stk.back().first > x) {
                total -= stk.back().second;
                stk.pop_back();
            }
            if (!stk.empty() && stk.back().first == x) {
                // ② 值 == x 的候选不配对，剔除后计数
                ans += total - stk.back().second;
                // ③ 与栈顶合并
                stk.back().second++;
            } else {
                // ②' 栈中值全部 < x，整体配对
                ans += total;
                stk.emplace_back(x, 1);
            }
            total++;
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def shadowPairs(self, nums: list[int]) -> int:
        stk: list[list[int]] = []  # [值, 个数]，块值从栈底到栈顶严格递增
        total = 0  # 栈内元素总数
        ans = 0
        for x in nums:
            # ① 弹出值 > x 的块：被 x 永久阻挡
            while stk and stk[-1][0] > x:
                total -= stk[-1][1]
                stk.pop()
            if stk and stk[-1][0] == x:
                # ② 值 == x 的候选不配对，剔除后计数
                ans += total - stk[-1][1]
                stk[-1][1] += 1  # ③ 与栈顶合并
            else:
                ans += total  # ②' 栈中值全部 < x，整体配对
                stk.append([x, 1])
            total += 1
        return ans
```

## 8. 边界情况与易错点

1. **答案溢出**：上界 $\binom{10^5}{2} \approx 5 \times 10^9$，C++ 必须用 `long long` 累加（`total`、`ans` 都别用 `int` 存计数再相减的中间结果也安全起见统一 64 位）。
2. **相等元素的两面性**：中间与 $nums[i]$ **相等**的元素不阻挡（阻挡要求严格小于）；与 $nums[j]$ **相等**的候选不配对（配对要求严格小于）。弹出条件写成 `>=` 会误删同值候选，导致后面漏数。
3. **弹出后栈空**：本步增量必为 0；代码里 `else` 分支要同时覆盖「栈空」与「栈顶值 $< x$」两种情形（上面的写法用 `stk and ...` 统一处理）。
4. **不要线性数同值**：见算法细节第 3 点，$[1,1,\dots,1,2]$ 会退化 $O(n^2)$；必须分块或二分。
5. **全相等数组**：答案为 0（不存在 $nums[i] < nums[j]$），栈始终只有一块，算法自然处理，无需特判。
6. **相邻对**（$j = i+1$）：中间为空自动满足无阻挡，只要 $nums[i] < nums[j]$ 即为影子对；单调栈框架下无需特判（上一步刚入栈的 $j-1$ 就在栈顶）。
