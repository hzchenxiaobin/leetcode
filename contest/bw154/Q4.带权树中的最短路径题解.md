# LeetCode 带权树中的最短路径 题解

## 1. 题目概述

- **标题 / 题号**：带权树中的最短路径（#3515，hard）
- **链接**：https://leetcode.cn/problems/shortest-path-in-a-weighted-tree/
- **来源**：LeetCode 第 154 场双周赛 Q4
- **难度**：困难
- **标签**：树、深度优先搜索、树状数组、线段树、数组

**题意**：给定 $n$ 个结点的带权无向树（结点编号 $1 \dots n$，以结点 1 为根），边由 `edges[i] = [u, v, w]` 给出。处理 $q$ 个查询，分两类：

- `[1, u, v, w']`：把边 $(u, v)$ 的权重改为 $w'$（保证这条边存在）。
- `[2, x]`：求从根节点 1 到结点 $x$ 的**最短路径距离**（树上路径唯一，即路径边权之和）。

按出现顺序输出所有第二类查询的答案。

**约束**：

- $1 \le n \le 10^5$，$edges.length = n - 1$
- $1 \le w_i \le 10^4$，边构成合法的树
- $1 \le q \le 10^5$，`queries[i]` 长度 2 或 4
- 更新操作保证 $(u, v)$ 是 `edges` 中的一条边，$1 \le w' \le 10^4$

## 2. 示例

**示例 1**

```text
输入：n = 2, edges = [[1,2,7]], queries = [[2,2],[1,1,2,4],[2,2]]
输出：[7,4]
解释：
  [2,2] → 根到 2 的距离 7
  [1,1,2,4] → 边 (1,2) 权重 7 → 4
  [2,2] → 距离 4
```

**示例 2**

```text
输入：n = 3, edges = [[1,2,2],[1,3,4]],
     queries = [[2,1],[2,3],[1,1,3,7],[2,2],[2,3]]
输出：[0,4,2,7]
解释：
  [2,1] → 到根自己是 0
  [2,3] → 4
  [1,1,3,7] → 边 (1,3) 权重 4 → 7
  [2,2] → 2（边 (1,2) 未受影响）
  [2,3] → 7
```

**示例 3**

```text
输入：n = 4, edges = [[1,2,2],[2,3,1],[3,4,5]],
     queries = [[2,4],[2,3],[1,2,3,3],[2,2],[2,3]]
输出：[8,3,2,5]
解释：
  [2,4] → 2 + 1 + 5 = 8
  [2,3] → 2 + 1 = 3
  [1,2,3,3] → 边 (2,3) 权重 1 → 3
  [2,2] → 2（在子树 3 之外，不受影响）
  [2,3] → 2 + 3 = 5
```

## 3. 解题思路

### 3.1 暴力思路

每次更新后从根跑一遍 DFS 重算所有 `dist`，单次 $O(n)$；$q = 10^5$、$n = 10^5$ 时最坏 $10^{10}$，不可行。

另一种思路是「更新时把该边之下所有点的距离都改一遍」，同样是 $O(n)$/次，还是太慢。

### 3.2 核心观察：改一条边权，只影响它下面的整棵子树

![Euler 序：把每棵子树压成一段连续区间](images/bw154_q4_euler.svg)

设边 $(u, v)$ 中 $v$ 是较深的一端（孩子），原权重 $w$，新权重 $w'$，**增量** $\delta = w' - w$。那么：

- 对于 $v$ 的子树内的任意结点 $x$，根到 $x$ 的路径必经过边 $(u,v)$，故 $dist[x]$ 全部 $+\delta$；
- 对于子树外的结点，路径不经过这条边，$dist$ 不变。

也就是说，**一次更新 = 对一棵子树做区间加法**。再配上「单点查询」，这就是经典的「区间加 + 单点查」模型。

为了把「子树」变成数组上的一段连续区间，做一次从根出发的 DFS，记录进入时间 `tin[u]` 与离开时间 `tout[u]`：子树 $u$ 恰好对应 $[tin[u], tout[u]]$（Euler 序 / 时间戳技巧）。

于是：

- 初始 `dist[x]` 用一次 DFS 算好（作为**基线**）；
- 每次更新：对区间 $[tin[v], tout[v]]$ 加 $\delta$；
- 每次查询：答案 $= dist[x] + (\text{位置 } tin[x] \text{ 上累积的增量})$。

「区间加 + 单点查」用**树状数组 + 差分**实现：在 $L$ 处 $+\delta$、在 $R+1$ 处 $-\delta$，单点值就是前缀和。每次 $O(\log n)$。

### 3.3 算法流程

![树状数组：区间加 delta + 单点求前缀和](images/bw154_q4_bit.svg)

```text
1. 建邻接表；从 1 出发做迭代式 DFS：
     - 记录 parent[u]、upWeight[u]（u 到父边的权）、tin[u]、tout[u]
     - 记录 dist[u] = dist[parent] + upWeight[u]
2. 初始化树状数组 bit（全 0）
3. for 每个查询 q:
4.     若 q[0] == 1:
5.         child ← (parent[u] == v) ? u : v        # 较深的一端
6.         δ ← q[3] − upWeight[child]；upWeight[child] ← q[3]
7.         add(tin[child], δ);  add(tout[child] + 1, −δ)
8.     否则:
9.         输出 dist[q[1]] + prefix(tin[q[1]])
```

### 3.4 示例演算

![示例 3 演算：n = 4 的链 1—2—3—4（权重 2, 1, 5）](images/bw154_q4_walkthrough.svg)

对示例 3：$n = 4$，链 $1 \xrightarrow{2} 2 \xrightarrow{1} 3 \xrightarrow{5} 4$，DFS 后 `tin = [1,2,3,4]`、`tout = [4,4,4,4]`（链上每个点的子树都是自己到最后），`dist = [0,2,3,8]`。

| 查询 | 处理 | 输出 |
|---|---|---|
| `[2,4]` | `dist[4] + prefix(4)` = 8 + 0 | 8 |
| `[2,3]` | 3 + 0 | 3 |
| `[1,2,3,3]` | child = 3，$\delta = 3-1 = 2$；对 $[tin[3], tout[3]] = [3,4]$ 加 2 | — |
| `[2,2]` | `dist[2] + prefix(2)` = 2 + 0（2 不在子树 3 内） | 2 |
| `[2,3]` | 3 + 2 | 5 |

输出 `[8,3,2,5]`，与题面一致。

## 4. 算法细节

1. **必须用迭代式 DFS**：$n = 10^5$ 的链会让递归深度达到 $10^5$，C++ 的默认栈会爆。用显式栈 + `iter[u]`（记录 $u$ 已扫描到第几个邻居）实现后序时间戳。
2. **`tout[u]` 的取法**：在「弹出 $u$」时令 `tout[u] = timer`，此时 `timer` 已推进到子树最后一个结点的时间戳，正好是区间右端。
3. **找 `child`**：无向边里哪个端点是孩子？用 `parent` 判定：`parent[u] == v` 则 $u$ 更深，否则 $v$ 更深（根结点 `parent[1] = 0`，不会误判）。
4. **维护旧权重**：`upWeight[child]` 存「孩子到父边」的当前权重，更新时先算 $\delta = w' - upWeight[child]$ 再覆盖。
5. **树状数组的差分**：`add(L, δ)` 与 `add(R+1, -δ)`；当 $R+1 = n+1$ 时，`add` 的循环条件 `i <= n` 直接跳过，不会越界（数组开 $n+2$ 更保险）。
6. **距离可能超过 `int`？** 最大 $10^5 \times 10^4 = 10^9$，仍在 `int` 范围内，但内部累加用 `long long` 更稳妥；最终答案转回 `int`。
7. **树状数组 vs 线段树**：本题只需「区间加 + 单点查」，树状数组（差分）常数最小；若改成「区间加 + 区间最值」才需要线段树（这也是题目标签同时给出两者的原因）。

## 5. 正确性证明

**引理 1（子树 = 连续区间）**：对任意结点 $u$，$\{tin[x] : x \in \text{subtree}(u)\} = [tin[u], tout[u]]$，且区间内每个整数恰对应子树中的一个结点。

**证明**：DFS 进入 $u$ 时分配 `tin[u]`，随后递归处理 $u$ 的每个孩子及其子树，期间时间戳只增不减；离开 $u$ 时 `timer` 恰好是「$u$ 子树内最后一个被赋值的结点」的时间戳，即 `tout[u]`。故子树内所有结点的时间戳恰好填满 $[tin[u], tout[u]]$，每个整数对应唯一结点（时间戳是全局唯一的分配）。∎

**引理 2（更新的影响范围）**：设边 $(u,v)$ 的深度较大端为 $v$，权重改变 $\delta$。则对任意结点 $x$：$x \in \text{subtree}(v) \Rightarrow \text{dist}(x)$ 增加 $\delta$；$x \notin \text{subtree}(v) \Rightarrow \text{dist}(x)$ 不变。

**证明**：树上两点路径唯一。根到 $x$ 的路径经过边 $(u,v)$ 当且仅当 $x$ 在 $v$ 的子树中（因为 $(u,v)$ 是把 $v$ 的子树与其余部分分开的桥）。经过时该边贡献变化 $\delta$，其余边不变，故 $\text{dist}$ 增加 $\delta$；不经过时整条路径的边集不变，故不变。∎

**引理 3（差分 BIT 的正确性）**：设 $A$ 为初始全 0 的数组，每次对 $[L,R]$ 执行「差分更新」`add(L,δ)`、`add(R+1,-δ)`。则任意时刻，位置 $i$ 的前缀和 $\sum_{j \le i} bit[j]$ 等于「所有覆盖 $i$ 的区间更新之和」。

**证明**：一次差分更新只在 $L$ 处加 $\delta$、$R+1$ 处减 $\delta$。对位置 $i$，前缀和包含 $L$ 处的 $+\delta$ 当且仅当 $L \le i$；包含 $R+1$ 处的 $-\delta$ 当且仅当 $R+1 \le i$，即 $R < i$。故该次更新对前缀和的净贡献为 $\delta \cdot [L \le i] - \delta \cdot [R < i] = \delta \cdot [L \le i \le R]$，恰好是「$i$ 被该区间覆盖」的指示。对多次更新求和即得结论。∎

**定理**：算法对每个 `[2, x]` 查询输出的值等于当前树上根到 $x$ 的距离。

**证明**：由引理 2，每次更新等价于对 $\text{subtree}(v)$ 内所有点的距离加 $\delta$，等价于对区间 $[tin[v], tout[v]]$ 做一次「覆盖该区间的加法」（引理 1 保证区间与子树一一对应）。由引理 3，查询时 `prefix(tin[x])` 恰为「$x$ 所经历的全部更新量之和」，即当前距离相对初始距离的增量。因此 `dist[x] + prefix(tin[x])` = 初始距离 + 累积增量 = 当前真实距离。∎

## 6. 复杂度分析

- **预处理**：建图 $O(n)$；迭代 DFS 分配 `tin/tout` 并计算 `dist` 共 $O(n)$；BIT 初始化为 $O(n)$。合计 $O(n)$。
- **单次更新**：找 `child` 与算 $\delta$ 为 $O(1)$，两次 BIT 单点加各 $O(\log n)$。合计 $O(\log n)$。
- **单次查询**：一次 BIT 前缀和 $O(\log n)$。
- **总时间**：$O\big((n + q)\log n\big)$。$n = q = 10^5$ 时约 $3.4\times 10^6$ 次基本操作，实测 C++ 0.56 s（含 I/O）。
- **空间**：$O(n)$。邻接表 $O(n)$、`parent/tin/tout/upWeight/dist` 各 $O(n)$、BIT $O(n)$、答案 $O(q)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> treeQueries(int n, vector<vector<int>>& edges, vector<vector<int>>& queries) {
        vector<vector<pair<int, int>>> g(n + 1);
        for (const auto& e : edges) {
            g[e[0]].push_back({e[1], e[2]});
            g[e[1]].push_back({e[0], e[2]});
        }
        // 迭代 DFS：求父亲、到父边的权重、Euler 序区间 [tin, tout]、根到每个点的距离
        vector<int> parent(n + 1, 0), tin(n + 1, 0), tout(n + 1, 0), upWeight(n + 1, 0);
        vector<long long> dist(n + 1, 0);
        vector<char> visited(n + 1, 0);
        vector<int> iter(n + 1, 0), stack_;
        int timer = 0;
        visited[1] = 1;
        tin[1] = ++timer;
        stack_.push_back(1);
        while (!stack_.empty()) {
            int u = stack_.back();
            if (iter[u] < (int)g[u].size()) {
                auto [v, w] = g[u][iter[u]++];
                if (visited[v]) continue;
                visited[v] = 1;
                parent[v] = u;
                upWeight[v] = w;
                dist[v] = dist[u] + w;
                tin[v] = ++timer;
                stack_.push_back(v);
            } else {
                tout[u] = timer;
                stack_.pop_back();
            }
        }
        // 树状数组：区间加 + 单点查（差分思想）
        vector<long long> bit(n + 2, 0);
        auto add = [&](int i, long long delta) {
            for (; i <= n; i += i & (-i)) bit[i] += delta;
        };
        auto point = [&](int i) {
            long long res = 0;
            for (; i > 0; i -= i & (-i)) res += bit[i];
            return res;
        };
        vector<int> ans;
        for (const auto& q : queries) {
            if (q[0] == 1) {
                // 把 (u, v) 的边权改为 nw：子树内所有点到根的距离整体加上 delta
                int u = q[1], v = q[2], nw = q[3];
                int child = (parent[u] == v) ? u : v;  // 更深的一端是孩子
                long long delta = (long long)nw - upWeight[child];
                upWeight[child] = nw;
                add(tin[child], delta);
                add(tout[child] + 1, -delta);
            } else {
                int x = q[1];
                ans.push_back((int)(dist[x] + point(tin[x])));
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def treeQueries(self, n: int, edges: list[list[int]], queries: list[list[int]]) -> list[int]:
        g = [[] for _ in range(n + 1)]
        for u, v, w in edges:
            g[u].append((v, w))
            g[v].append((u, w))
        # 迭代 DFS：求父亲、到父边的权重、Euler 序区间 [tin, tout]、根到每个点的距离
        parent = [0] * (n + 1)
        up_weight = [0] * (n + 1)
        tin = [0] * (n + 1)
        tout = [0] * (n + 1)
        dist = [0] * (n + 1)
        visited = [False] * (n + 1)
        it = [0] * (n + 1)
        timer = 0
        visited[1] = True
        timer += 1
        tin[1] = timer
        stack = [1]
        while stack:
            u = stack[-1]
            if it[u] < len(g[u]):
                v, w = g[u][it[u]]
                it[u] += 1
                if visited[v]:
                    continue
                visited[v] = True
                parent[v] = u
                up_weight[v] = w
                dist[v] = dist[u] + w
                timer += 1
                tin[v] = timer
                stack.append(v)
            else:
                tout[u] = timer
                stack.pop()
        # 树状数组：区间加 + 单点查（差分思想）
        bit = [0] * (n + 2)

        def add(i: int, delta: int) -> None:
            while i <= n:
                bit[i] += delta
                i += i & (-i)

        def point(i: int) -> int:
            res = 0
            while i > 0:
                res += bit[i]
                i -= i & (-i)
            return res

        ans = []
        for q in queries:
            if q[0] == 1:
                # 把 (u, v) 的边权改为 nw：子树内所有点到根的距离整体加上 delta
                _, u, v, nw = q
                child = u if parent[u] == v else v  # 更深的一端是孩子
                delta = nw - up_weight[child]
                up_weight[child] = nw
                add(tin[child], delta)
                add(tout[child] + 1, -delta)
            else:
                ans.append(dist[q[1]] + point(tin[q[1]]))
        return ans
```

## 8. 边界情况与易错点

1. **递归爆栈**：$n = 10^5$ 的链必须用迭代 DFS；这是本题最容易 RE 的地方。
2. **$n = 1$**：没有边、只有查询 `[2,1]`，`tin[1] = tout[1] = 1`，答案为 0。此时 `size` 相关的结构都不要假设非空。
3. **查询根节点**：`[2, 1]` 返回 0（`dist[1] = 0`、无更新覆盖时间戳 1），示例 2 已验证。
4. **`u, v` 顺序任意**：更新查询里 $(u,v)$ 的方向不保证是父→子，必须用 `parent` 判定 `child`，不能想当然取 `q[2]`。
5. **$\delta$ 可以是负数**：新权重可能小于旧权重，`bit` 必须能存负数（用 `long long`/Python int）。
6. **`tout[child] + 1` 越界**：当 `child` 的子树延伸到最后一个时间戳时 `R+1 = n+1`，C++ 中 `add` 的循环条件 `i <= n` 会直接跳过；BIT 数组开 `n+2` 更稳。
7. **忘记维护 `upWeight`**：不更新旧权重会导致第二次改同一条边时 $\delta$ 算错。
8. **用 `int` 存 `dist`**：最大 $10^9$ 虽在范围内，但「初始距离 + 增量」的中间量建议用 `long long`。
9. **DFS 中的 `visited`**：树无环，但仍建议用 `visited` 标记（或跳过 `parent`），避免把父边当成回边重复访问。
