# LeetCode 逐层排序二叉树所需的最少操作数目 题解

## 1. 题目概述

- **标题 / 题号**：逐层排序二叉树所需的最少操作数目（#2471，medium）
- **链接**：https://leetcode.cn/problems/minimum-number-of-operations-to-sort-a-binary-tree-by-level/
- **来源**：LeetCode 第 319 场周赛 Q3
- **难度**：中等
- **标签**：树、广度优先搜索、二叉树、排序、置换环

**题意**：给一棵**值互不相同**的二叉树的根节点 root。一步操作可以选择**同一层**上任意两个节点，交换它们的**值**。返回让每一层都从左到右**严格递增**所需的最少操作数目。节点的层数定义为该节点与根节点之间路径的边数。

**约束**：

- 树中节点数目 $1 \le N \le 10^5$
- $1 \le \text{Node.val} \le 10^5$，且树中所有值**互不相同**

> 💡 本题在本仓库另有[每日题解 2471](../../solution/2401-2500/2471_逐层排序二叉树的最少操作数.md)：侧重「`(值, 原下标)` 排序构造环」的实现细节、值有重复时的扩展与面试问答。本篇按周赛复盘视角展开，侧重**赛场上的模板识别路径**、**逆序对陷阱**、**上下界夹逼的完整证明（引理 + 定理）**与**免数环的贪心换位实现**，两篇互为印证。

> 💡 值互不相同 ⇒「严格递增」就是普通的升序；更关键的是它保证每个值的排序目标位置唯一（§3.2、§4），这正是题面强调它的原因。

## 3. 解题思路

### 3.1 朴素思路：两个方向都走不通

**方向一（错误）**：把「最少交换」想成逆序对数 / 冒泡排序次数——那是**只允许相邻交换**时的答案。本题允许同层**任意两点**交换。反例 $[7,6,5,4]$：逆序对有 6 个，但最优只需 2 次——先 $7 \leftrightarrow 4$ 得 $[4,6,5,7]$，再 $6 \leftrightarrow 5$ 得 $[4,5,6,7]$。按逆序对算不是「慢」，是直接**答案错误**，这是本题的头号 WA 点。

**方向二（正确但爆炸）**：把每层看成一个排列，在排列状态图上 BFS 求到有序排列的最短路。状态数 $O(n!)$，而本题最宽一层可达约 $5 \times 10^4$ 个节点，完全不可行。

> 💡 **赛场识别路径**：两个经典模板拼接即可——「树 + 按层」→ **BFS 分层**；「任意交换排序的最少次数」→ **置换环分解**（$n - c$）。识别出这两点后，本题没有剩余难点。

### 3.2 核心观察：层独立，单层归约为「任意交换排序」

![核心观察：层与层互相独立，逐层归约为任意交换排序](images/wc319_q3_levels_concept.svg)

**观察一（层与层独立）**：一次操作只交换同一层两个节点的值，既不改变其它层的值序列，也不改变节点间的父子结构；而目标条件本身就是逐层给出的（每层从左到右递增）。因此各层互不干扰：

$$\text{答案} \;=\; \sum_{\text{各层 } L} \text{minSwaps}(L)$$

**观察二（单层是经典问题）**：BFS 取出某层从左到右的值序列 $a$（长 $n$）。由于值互不相同，排序后的目标序列唯一，于是每个值的**目标位置**唯一。定义映射 $\sigma(i) = \text{pos}(a[i])$（位置 $i$ 上的值排好序后应在的位置），则 $a$ 有序当且仅当 $\sigma$ 为恒等映射。问题变成：**只用任意两元素交换，把 $\sigma$ 变成恒等映射的最少次数**——这就是经典的「任意交换排序」问题。

### 3.3 关键定理：最少交换 = n − c

![置换环定理：n 个元素、c 个环，最少交换 n−c 次](images/wc319_q3_cycle_theory.svg)

把每个位置 $i$ 向 $\sigma(i)$ 连一条箭头，会得到若干互不相交的**环**（自环 = 已归位的元素）。设环数为 $c$：

**定理（置换环）**：把 $a$ 排成有序的最少交换次数为 $n - c$。

- **上界**：长度 $k$ 的环，每次交换把一个值送到最终位置（裂出一个自环），$k - 1$ 次全部归位；各环位置互不相交、互不干扰，合计 $\sum_{\text{环}} (k - 1) = n - c$ 次。
- **下界**：一次交换对环数的影响恰为 $\pm 1$——同环两点交换 → 一环裂二（环数 $+1$）；异环两点交换 → 二环合一（环数 $-1$），即每步环数至多 $+1$；而有序状态是 $n$ 个自环，初始只有 $c$ 个环，故至少 $n - c$ 次。

上下界夹住，最少次数恰为 $n - c$。严格证明见 §5。

### 3.4 算法流程

```text
1. BFS 从根出发，逐层收集节点的值（从左到右）
2. 对每一层 a（长 n）：
   ① sorted = 将 a 排序
   ② pos[v] = v 在 sorted 中的下标（值互不相同 ⇒ 无冲突）
   ③ perm[i] = pos[a[i]]                  # 置换
   ④ visited 数组沿环跳跃，数出环数 c
   ⑤ ans += n - c                         # 最少交换次数
3. 返回 ans
```

**等价的贪心实现**（免显式数环）：从左到右扫描每个位置 $i$，只要 `pos[a[i]] != i`，就把 $a[i]$ 与其目标位置上的值交换——每次交换**至少归位一个元素**，且绝不破坏已归位的元素，总交换次数自动等于 $n - c$。

## 4. 算法细节

1. **BFS 分层**：队列标准写法——先快照 `n = q.size()`，本轮只出队 `n` 次，收集到的 `vals` 即该层从左到右的序列；空子节点判空再入队。
2. **置换的构造**：`pos` 用哈希表存「值 → 目标下标」。值互不相同保证映射良定义；C++ 中值域 $\le 10^5$，也可开 `int pos[100001]` 的值域数组省去哈希开销。
3. **环计数**：`visited` 数组 + 沿 `perm` 跳环，每个位置恰好访问一次，单层 $O(n)$。
4. **无需真的交换树上的值**：我们只统计**次数**。BFS 队列里存的是节点指针，层值快照进 `vals` 后，所有交换都发生在临时数组上模拟，树和队列原封不动（真去改 `node->val` 结果也一样——同层换值不影响其它层——但纯属多余，还容易把自己绕晕）。
5. **贪心变体的复杂度**：`while pos[vals[i]] != i` 的内层交换每执行一次就永久归位一个位置，单层总执行次数是 $O(n)$ 而非 $O(n^2)$；但若误写成「对每个 $i$ 从头线性扫找目标值」而不是查 `pos` 映射，才会退化到平方级。
6. **两份参考代码等价**：C++ 显式数环是定理的直译；Python 贪心换位是 §5 推论的直译，两者交换次数都恰为 $n - c$。

## 5. 正确性证明

固定某一层，从左到右的值为 $a_0, a_1, \dots, a_{n-1}$。因树中值互不相同，排序目标 $b$（$a$ 的升序排列）唯一，且值到下标的映射 $\text{pos}(b_j) = j$ 无歧义。定义置换 $\sigma(i) = \text{pos}(a_i)$。

**引理 1（层独立性）**：总最少操作数等于各层最少操作数之和。

**证明**：任一操作只交换同一层的两个值，不改变其它层的值序列；合法性条件（每层递增）按层拆分。任一全局可行方案按层分组即得各层的可行方案，反之各层的方案拼起来也是全局可行方案，且操作次数相同。两侧可行方案一一对应，最优值相等。∎

**引理 2（交换 = 复合对换，环数变化 ±1）**：交换位置 $i, j$ 上的值后，新置换为 $\sigma' = (i\ j) \circ \sigma$；且环数变化恰为 $+1$（$i, j$ 同环时）或 $-1$（$i, j$ 异环时）。

**证明**：交换后 $a'_i = a_j$，故 $\sigma'(i) = \text{pos}(a_j) = \sigma(j)$；同理 $\sigma'(j) = \sigma(i)$；其余位置不变，即 $\sigma' = (i\ j) \circ \sigma$。环数变化：若 $i, j$ 同属一个环，把该环从 $i$、$j$ 两处剪开重接，恰好裂成 $(i\ \sigma(j)\ \sigma^2(j)\ \cdots\ \sigma^{-1}(i))$ 与 $(j\ \sigma(i)\ \sigma^2(i)\ \cdots\ \sigma^{-1}(j))$ 两个环，环数 $+1$；若 $i, j$ 分属两个环，对称地两环缝合为一，环数 $-1$。∎

**引理 3（k-环上界）**：长度 $k \ge 2$ 的环可用 $k - 1$ 次交换使其上所有元素归位，且不影响其它环。

**证明**（归纳）：$k = 1$ 时 0 次显然。设环为 $i_1 \to i_2 \to \cdots \to i_k \to i_1$（即 $\sigma(i_t) = i_{t+1}$，下标模 $k$）。交换位置 $i_1, i_2$ 上的值：$a_{i_1}$ 归位到 $i_2$，成为自环；剩余 $i_1, i_3, \dots, i_k$ 构成长度 $k - 1$ 的环。由归纳假设再需 $k - 2$ 次，合计 $k - 1$ 次。整个过程中交换只发生在该环内部的位置上，其它环不受影响。∎

**定理**：长为 $n$、置换环数为 $c$ 的层，最少交换次数为 $n - c$。

**证明**：
- 上界：由引理 3，每个长度 $k$ 的环用 $k - 1$ 次，各环位置互不相交、互不干扰，合计 $\sum_{\text{环}} (k - 1) = \sum_{\text{环}} k - c = n - c$ 次。
- 下界：$a$ 有序当且仅当 $\sigma = \mathrm{id}$，即 $n$ 个自环（环数为 $n$）。初始环数为 $c$，由引理 2，每次交换环数至多增加 1，故任何方案至少需要 $n - c$ 次交换。∎

**推论**：贪心换位（反复把 $a[i]$ 交换到其目标位置）的总交换次数恰为 $n - c$。

**证明**：设 $j = \text{pos}(a[i]) \ne i$，交换后位置 $j$ 永久归位（贪心只交换「未归位」的位置：$a[j]$ 此前满足 $\sigma(j) \ne j$，故 $j$ 尚未被归位；此后 $j$ 不再被任何后续交换触碰）。于是一个长度 $k$ 的环恰执行 $k - 1$ 次（最后一次交换同时归位最后两个位置），全部环合计 $n - c$ 次，达到定理下界。∎

## 6. 复杂度分析

- **时间复杂度**：$O(N \log N)$。BFS 每个节点进出队一次，$O(N)$；每层排序 $\sum_i n_i \log n_i \le N \log(\max_i n_i) = O(N \log N)$；置换构造与环计数每层线性，合计 $O(N)$。若用值域数组代替「排序 + 哈希」（值 $\le 10^5$），可降到 $O(N + V)$，但 $N \le 10^5$ 下排序版已绰绰有余。
- **空间复杂度**：$O(N)$。BFS 队列最深约 $\lceil N/2 \rceil$；单层的 `vals / sorted / pos / perm / visited` 均不超过最宽层的大小。

## 7. 参考代码

### C++（显式环计数）

```cpp
class Solution {
  public:
    int minimumOperations(TreeNode *root) {
        int ans = 0;
        queue<TreeNode *> q;
        q.push(root);
        while (!q.empty()) {
            int n = q.size();                      // ① 本层节点数快照
            vector<int> vals;
            for (int i = 0; i < n; i++) {
                TreeNode *node = q.front();
                q.pop();
                vals.push_back(node->val);         // ② 从左到右收集本层
                if (node->left) q.push(node->left);
                if (node->right) q.push(node->right);
            }

            vector<int> sorted_vals(vals);           // ③ 排序目标
            sort(sorted_vals.begin(), sorted_vals.end());
            unordered_map<int, int> pos;
            for (int i = 0; i < n; i++)
                pos[sorted_vals[i]] = i;           //    值 → 目标位置（值互异 ⇒ 唯一）

            vector<int> perm(n);                     // ④ 置换：perm[i] = vals[i] 的目标位置
            for (int i = 0; i < n; i++)
                perm[i] = pos[vals[i]];

            vector<bool> vis(n, false);              // ⑤ 沿环标记，数出环数 c
            int cycles = 0;
            for (int i = 0; i < n; i++) {
                if (vis[i]) continue;
                cycles++;
                for (int j = i; !vis[j]; j = perm[j])
                    vis[j] = true;
            }
            ans += n - cycles;                       // ⑥ 最少交换 = n − c
        }
        return ans;
    }
};
```

### Python（贪心换位，免显式数环）

```python
from collections import deque
from typing import Optional


class Solution:
    def minimumOperations(self, root: Optional[TreeNode]) -> int:
        ans = 0
        q = deque([root])
        while q:
            vals = [node.val for node in q]              # ① 本层快照（树与队列不动）
            pos = {v: i for i, v in enumerate(sorted(vals))}
            for i in range(len(vals)):
                while pos[vals[i]] != i:                 # ② 位置 i 的值不在目标位置
                    j = pos[vals[i]]                     #    它该去的位置 j
                    vals[i], vals[j] = vals[j], vals[i]  # ③ 交换后位置 j 永久归位
                    ans += 1
            for _ in range(len(q)):                      # ④ 展开下一层
                node = q.popleft()
                if node.left:
                    q.append(node.left)
                if node.right:
                    q.append(node.right)
        return ans
```

## 8. 边界情况与易错点

1. **逆序对陷阱（本题主 WA 点）**：任意交换的最少次数是 $n - c$，**不是**逆序对数。$[7,6,5,4]$ 逆序对 6 个、答案 2 个。逆序对只在「相邻交换」的操作模型下才正确。
2. **单节点树**：只有层 0 且单元素天然有序，答案 0；代码无需特判。
3. **每层已有序**：全部自环，$c = n$，答案 0（示例 3）；环计数自然给出 0，同样无需特判。
4. **值互不相同是前提**：它保证「值 → 目标位置」映射唯一，置换与环分解良定义。若有重复值，目标位置不再唯一，需另行讨论（见延伸思考）。
5. **空子节点**：BFS 判空再入队；层序列只含实际存在的节点，`null` 不占位、不进层。
6. **答案规模**：每层至多 $n_i - 1$ 次，总计 $\le N - 1 < 10^5$，`int` 足够，无需 `long long`。
7. **贪心内层 while 不是平方级**：每次交换永久归位一个位置，单层摊还 $O(n)$。
8. **不要真去交换树上的值**：交换发生在层值的临时数组上，只累加计数即可（§4 第 4 点）。
