# LeetCode 最小公倍数等于 K 的子数组数目 题解

## 1. 题目概述

- **标题 / 题号**：最小公倍数等于 K 的子数组数目（#2470，medium）
- **链接**：https://leetcode.cn/problems/number-of-subarrays-with-lcm-equal-to-k/
- **来源**：LeetCode 第 319 场周赛 Q2
- **难度**：中等
- **标签**：数组、数学、数论

**题意**：给定整数数组 $\text{nums}$ 与整数 $k$，统计 $\text{nums}$ 中**元素最小公倍数（LCM）恰好等于 $k$** 的**连续非空子数组**数目。

**约束**：

- $1 \le \text{nums.length} \le 1000$
- $1 \le \text{nums[i]},\ k \le 1000$

> 💡 本题在本仓库另有[每日题解 2470](../../solution/2401-2500/2470_最小公倍数等于K的子数组数目.md)：侧重与 2447（gcd 版）的对偶视角、lcm 段表 $O(n \log V)$ 进阶与面试问答。本篇按周赛复盘视角展开，侧重**赛场上的模板识别路径**、**「先判后更」的溢出保护细节**、**不重不漏的完整证明**与**边界情况清单**，两篇互为印证。

## 2. 示例

**示例 1**

```text
输入：nums = [3,6,2,7,1], k = 6
输出：4
解释：lcm 等于 6 的子数组是 [3,6]、[3,6,2]、[6]、[6,2]，共 4 个。
```

**示例 2**

```text
输入：nums = [3], k = 2
输出：0
解释：不存在 lcm 等于 2 的子数组。
```

**示例 3**（自构造，覆盖「因子使 lcm 不变」与「末端命中」）

```text
输入：nums = [4,2,8], k = 8
输出：3
解释：[4,2,8] 的 lcm 为 lcm(4,2)=4 → lcm(4,8)=8；[2,8] lcm=8；[8] lcm=8。
加入因子 2 时 lcm 不变（4→4），说明「单调不减」而非「严格递增」。
```

## 3. 解题思路

### 3.1 暴力思路：枚举子数组 + 独立求 lcm

朴素做法是枚举全部 $O(n^2)$ 个子数组 $[i, j]$，每个子数组从头扫一遍求 lcm 再与 $k$ 比较，总计 $O(n^3)$。$n \le 1000$ 时约 $10^9$ 量级，超时。

第一个改进是**复用前缀 lcm**：固定左端点 $i$，让 $j$ 向右扩展，维护 $l \leftarrow \text{lcm}(l, \text{nums}[j])$。由 lcm 的结合律，$l$ 恰是 $\text{nums}[i..j]$ 的 lcm，无需重扫区间。单步 lcm 经 gcd 计算 $O(\log V)$（$V = \max \text{nums} \le 1000$），总 $O(n^2 \log V) \approx 10^7$，已经能 AC。

> ⚠️ 但「老实扫到底」仍有浪费：$i=0$ 起点扫到 $7$ 时，含 $7$ 的子数组 lcm 不可能是 $6$，后面每一步都是无效功。赛场视角下，$O(n^2)$ 预算既然花得起，这一版可以直接提交锁底分，再补两条性质剪枝。

### 3.2 核心观察：因子封闭 + 前缀 lcm 单调不减

![核心观察：因子封闭 + 前缀 lcm 单调不减，非因子即 break](images/wc319_subarray_lcm_concept.svg)

两条性质支撑起「早退」剪枝：

- **性质一（因子封闭）**：若 $\text{lcm}(\text{sub}) = k$，则 $k$ 是 sub 中每个元素的公倍数，即**每个元素都整除 $k$**。逆否命题：元素不整除 $k$ ⇒ 含它的任何子数组 lcm 必 $\ne k$ ⇒ **一票否决，立刻 `break`**。判据写成代码即 `k % nums[j] != 0`。
- **性质二（单调不减）**：扩展时 $l_{j+1} = \text{lcm}(l_j, \text{nums}[j+1])$，且 $l_j \mid l_{j+1}$（lcm 是其操作数的倍数），故 $l$ 只增不减。示例 3 中加入因子 2 时 $4 \to 4$ 不变，「不减」不要求严格递增。

两条性质合起来还有个**顺带的好处**：只在「整除 $k$ 的元素」之间扩展时，$l$ 始终是 $k$ 的因子的 lcm，而 $k$ 是它们的公倍数，故 $\text{lcm} \mid k$（§5 引理 3），即 $l \mid k$ 恒成立、$l \le k \le 1000$——**免去 `l > k` 判断，C++ `int` 也绝无溢出**。

**计数但不停止**：$l = k$ 时计数 $+1$，但**不能 break**——续加 $k$ 的因子时 $\text{lcm}(k, \text{因子}) = k$ 不变（§5 引理 4），更长的子数组同样合法。例如 $[3,6,2]$ 在 $l$ 到达 6 后，$[3,6,2]$ 本身也要计入。

> 💡 **赛场识别路径**：$n \le 1000$ 直接发 $O(n^2)$ 许可证；「子数组 + 聚合量等于定值」是 2447（gcd）/ 713（乘积）一族的标准骨架。与 2447 互为镜像：gcd 单调不增，早退判据是 $k \nmid g$（聚合量不再满足目标）；lcm 单调不减，早退判据更强，直接判**元素是否整除 $k$**。

### 3.3 算法流程

![算法流程：枚举起点 → 前缀 lcm → 非因子早退 → 命中计数但不停](images/wc319_subarray_lcm_flow.svg)

伪代码骨架：

```text
ans = 0
for i in 0..n-1:            # 枚举左端点
    l = 1                   # lcm(1, x) = x，首元素直接进位
    for j in i..n-1:        # 向右扩展
        if k % nums[j] != 0: break   # 非因子：含它的子数组 lcm 必 ≠ k
        l = lcm(l, nums[j])          # 先判后更：l | k 恒成立
        if l == k: ans += 1          # 命中；勿 break，续加因子仍 = k
return ans
```

> ⚠️ 三个易错点：① `l` 初值取 $1$；② **先判整除、后更新 lcm**（顺序颠倒在 C++ 有溢出风险，见 §8）；③ 命中后勿停。

### 3.4 示例演算

![示例演算：nums=[3,6,2,7,1]、k=6 逐起点的前缀 lcm 与命中子数组](images/wc319_subarray_lcm_walkthrough.svg)

以 $\text{nums}=[3,6,2,7,1]$、$k=6$ 逐起点展开（$l$ 初值 $1$）：

| $i$ | 扩展路径 $j$ | 前缀 lcm 序列 | 命中子数组 | 计数 |
|-----|-------------|--------------|-----------|-----|
| 0 | $0 \to 1 \to 2$（遇 $7$ 截停） | $1,\ 3,\ 6,\ 6$ | $[3,6],\ [3,6,2]$ | 2 |
| 1 | $1 \to 2$（遇 $7$ 截停） | $1,\ 6,\ 6$ | $[6],\ [6,2]$ | 2 |
| 2 | $2$（遇 $7$ 截停） | $1,\ 2$ | —（$l=2<6$） | 0 |
| 3 | $3$（首步即截停） | —（$7 \nmid 6$） | — | 0 |
| 4 | $4 \to$ 末尾 | $1,\ 1$ | —（$l=1<6$） | 0 |

合计 **4 个**，与官方输出一致。两个看点：$i=0$ 处 $l=6$ 命中后续加因子 2 仍命中（**命中勿停**）；下标 3 的 $7$ 像一堵「墙」，把起点 $0/1/2$ 的扫描全部截停（**早退剪枝**）。

## 4. 算法细节

1. **复杂度预算先行**：$n \le 1000$、$V \le 1000$ 双重小范围，$O(n^2 \log V) \approx 10^7$，C++/Python 双语言都能宽松通过，无需哈希、DP 等重型结构。
2. **前缀 lcm 与初值 1**：$l$ 语义是「$\text{nums}[i..j]$ 的 lcm」，由结合律 $\text{lcm}(\text{lcm}(a,b),c) = \text{lcm}(a,b,c)$ 逐步滚动维护。初值取 $1$，利用 $\text{lcm}(1,x)=x$ 让首元素自然进位，免去 $j=i$ 的特判。
3. **break 判据的方向**：判据是「$\text{nums}[j]$ **整除** $k$」，即 `k % nums[j] == 0` 通过、`!= 0` 截停。**方向写反**（`nums[j] % k != 0` 截停）语义变成「$\text{nums}[j]$ 是否为 $k$ 的倍数」：会把 $k$ 的真因子（如 $k=6$ 时的 $3$、$2$）误判非法而漏数，同时放过 $k$ 的倍数（如 $12$）让 $l$ 越滚越大——WA 与溢出双杀，见 §8 第 1 条。
4. **先判后更（溢出保护）**：`if (k % nums[j] != 0) break;` 必须放在 `l = lcm(l, nums[j]);` **之前**。因子判据把非因子挡在门外，$l$ 始终是 $k$ 的因子，$l \le k \le 1000$，`int` 稳。若反过来先更新再比较（例如用 `l > k` 做终止）：素数链 $[997, 991, 983, 977, \dots]$ 的前缀 lcm 三步约 $9.7 \times 10^8$ 尚在 `int` 内，第四步约 $9.5 \times 10^{11}$ 直接溢出（有符号溢出是 UB）。
5. **为何枚举左端点而非滑动窗口**：窗口收缩需要从左端**撤销**元素，乘积有逆运算（除法，713 因此能滑窗），lcm 与 gcd 都没有「反运算」——从 $\text{lcm}(l, x)$ 恢复 $l$ 不可行。聚合量不可逆的「子数组计数」一族，标准姿势就是**固定左端点向右聚合**。
6. **早退的实际威力**：$k$ 的因子在 $[1, 1000]$ 内至多 32 个（$\tau(840)=32$），非因子密度高，多数起点很快被「墙」截停；最坏情形（全因子数组）退化为完整 $O(n^2)$，但该情形答案本身即 $\Theta(n^2)$，任何算法都无法更快。

## 5. 正确性证明

**引理 1（因子封闭）**：若 $\text{lcm}(S) = k$，则任意 $x \in S$ 都整除 $k$。

**证明**：lcm 的定义是「能被每个元素整除的最小正整数」，故 $x \mid \text{lcm}(S) = k$。∎

**引理 2（单调不减）**：设 $l_j = \text{lcm}(\text{nums}[i..j])$，则 $l_j \mid l_{j+1}$，从而 $l_{j+1} \ge l_j$。

**证明**：$l_{j+1} = \text{lcm}(l_j, \text{nums}[j+1])$，而 lcm 能被其每个操作数整除，故 $l_j \mid l_{j+1}$；正整数的倍数不小于自身。∎

**引理 3（因子不变式）**：若 $l \mid k$ 且 $x \mid k$，则 $\text{lcm}(l, x) \mid k$。特别地，算法运行中「只对整除 $k$ 的元素更新 $l$」，故 $l \mid k$ 恒成立，$l \le k \le 1000$。

**证明**：按唯一分解，$\text{lcm}(l, x)$ 在每个素数 $p$ 上取指数 $\max(\alpha_p, \beta_p)$；$k$ 是 $l$ 与 $x$ 的公共倍数，其在 $p$ 上的指数 $\gamma_p \ge \alpha_p$ 且 $\gamma_p \ge \beta_p$，故 $\gamma_p \ge \max(\alpha_p, \beta_p)$，即 $\text{lcm}(l, x) \mid k$。对初值 $l = 1$（$1 \mid k$）归纳即得不变式。∎

**引理 4（命中保持）**：若 $l = k$ 且 $x \mid k$，则 $\text{lcm}(l, x) = k$。

**证明**：一方面 $\text{lcm}(k, x)$ 是 $k$ 的倍数，故 $\ge k$；另一方面由引理 3 得 $\text{lcm}(k, x) \mid k$，故 $\le k$。两者夹逼相等。∎

**定理（不重不漏）**：算法返回值恰为 lcm 等于 $k$ 的子数组数目。

**证明**：
- **不多计（不重）**：每次计数发生在唯一的二元组 $(i, j)$ 处，由 $l$ 的滚动定义与 lcm 结合律，当时 $l = \text{lcm}(\text{nums}[i..j])$，故计数条件 $l = k$ 即该子数组合法；不同 $(i, j)$ 对应不同子数组。
- **不少计（不漏）**：任取 lcm $= k$ 的子数组 $[i, j]$。由引理 1，其中每个元素都整除 $k$，故内层从 $i$ 扩展到 $j$ 的过程中**从不触发 break**；$l$ 逐步等于 $\text{lcm}(\text{nums}[i..t])$（$t = i, \dots, j$），到达 $t = j$ 时 $l = k$，该子数组恰好被计数一次。∎

> 💡 证明的关键分界：**break 只会跳过「必然非法」的起点组合**（引理 1 的逆否），因此剪枝不损失任何合法解；而**命中后继续**（引理 4）保证同一起点更长的合法子数组不被遗漏。

## 6. 复杂度分析

- **时间复杂度**：$O(n^2 \log V)$，$V = \max(\text{nums},\ k) \le 1000$。每个 $(i, j)$ 步一次 gcd，为 $O(\log V)$；最坏情形（数组全是 $k$ 的因子，如全 $1$ 数组）枚举全部 $n(n+1)/2 = 500500$ 个子数组——此时答案本身可达 $\Theta(n^2)$（全 $1$、$k=1$ 时答案恰为 500500），$O(n^2)$ 已是该情形的输出下界。一般情形下 $k$ 的因子稀疏（至多 32 个），非因子像墙一样截停内层，实际远快于上界。
- **空间复杂度**：$O(1)$。仅常数变量 $l,\ i,\ j,\ \text{ans}$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int subarrayLCM(vector<int>& nums, int k) {
        int n = nums.size(), ans = 0;
        for (int i = 0; i < n; ++i) {
            int l = 1;
            for (int j = i; j < n; ++j) {
                if (k % nums[j] != 0) break;   // 先判：非因子截停，且保住 l | k
                l = lcm(l, nums[j]);           // 后更：l <= k <= 1000，int 无溢出
                if (l == k) ++ans;             // 命中；勿 break，续加因子仍 = k
            }
        }
        return ans;
    }
};
```

> 💡 `std::lcm` 来自 `<numeric>`（C++17）。由于只对整除 $k$ 的元素求 lcm，$l \mid k$ 恒成立（§5 引理 3），`int` 绰绰有余。

### Python

```python
import math
from typing import List

class Solution:
    def subarrayLCM(self, nums: List[int], k: int) -> int:
        n = len(nums)
        ans = 0
        for i in range(n):
            l = 1
            for j in range(i, n):
                if k % nums[j] != 0:       # 非因子：含它的子数组 lcm 必 ≠ k
                    break
                l = math.lcm(l, nums[j])   # lcm(1, x) = x
                if l == k:                 # 命中；勿 break，续加因子仍 = k
                    ans += 1
        return ans
```

> 💡 `math.lcm` 需 Python 3.9+；更老的环境可写 `l = l * nums[j] // math.gcd(l, nums[j])`（Python 大整数无溢出，乘除顺序随意；C++ 则应写 `a / gcd(a, b) * b` 先除后乘）。

## 8. 边界情况与易错点

1. **break 判据方向（最高频 WA）**：正确写法是 `k % nums[j] != 0`（判「$\text{nums}[j]$ 整除 $k$」）。写反成 `nums[j] % k != 0` 会把 $k$ 的真因子（$k=6$ 时的 $3$、$2$）误判非法——$[3,6]$ 被 $i=0$ 首步截停，直接漏数；同时放过 $k$ 的倍数（如 $12$），$l$ 在 C++ 中一路膨胀直至溢出。
2. **先判后更的顺序**：先 `k % nums[j]` 再 `l = lcm(...)`。颠倒后用 `l > k` 兜底在 C++ 会溢出：素数链 $997 \times 991 \times 983 \times 977 \approx 9.5 \times 10^{11}$ 超 `int` 上限（UB）；Python 虽无溢出但白白浪费扫描。先判后更则 $l \le k \le 1000$ 恒成立。
3. **命中后勿 break**：续加 $k$ 的因子 lcm 保持 $k$（§5 引理 4），`break` 会漏数 $[3,6,2]$ 这类更长子数组。唯一的合法终止条件是非因子。
4. **`l` 初值取 1**：利用 $\text{lcm}(1,x)=x$ 免去首元素特判；误初始化为 $0$（lcm 定义域为正整数）或 `nums[i]`（破坏滚动式统一性）都是坑。
5. **$k = 1$ 的最坏情形**：只有元素 $1$ 整除 $1$，非 $1$ 元素一步截停；全 $1$ 数组时答案 $= n(n+1)/2 = 500500$，答案上界即子数组总数，`int` 安全。
6. **元素大于 $k$ 必被截停**：$k$ 的因子必然 $\le k$，故 $\text{nums}[j] > k$ 时 $k \% \text{nums}[j] \ne 0$ 自动成立（示例中的 $7 > 6$），无需单独写 `nums[j] > k` 判断。
7. **单元素子数组**：$\text{nums}[i] = k$ 时长度 1 的子数组命中（示例 1 的 $[6]$），循环结构天然覆盖，无需特判。
8. **别上滑动窗口**：lcm 没有逆运算，左端收缩无法撤销（对照 713 乘积可除回去）；误用滑窗是思路级错误而非实现细节。
