# LeetCode 找出数组中的 K-or 值 题解

## 1. 题目概述

- **标题 / 题号**：找出数组中的 K-or 值（#2917，easy）
- **链接**：https://leetcode.cn/problems/find-the-k-or-of-an-array/
- **来源**：LeetCode 第 369 场周赛 Q1
- **难度**：简单
- **标签**：位运算、数组、计数

**题意**：给定整数数组 `nums` 和整数 $k$，定义 **K-or** 操作：结果的第 $i$ 位为 1，当且仅当 `nums` 中**至少有 $k$ 个元素**的第 $i$ 位为 1。返回 `nums` 的 K-or 值。

**约束**：

- $1 \le \text{nums.length} \le 50$
- $0 \le \text{nums}[i] < 2^{31}$
- $1 \le k \le \text{nums.length}$

## 2. 示例

**示例 1**

```text
输入：nums = [7,12,9,8,9,15], k = 4
输出：9
解释：位 0 在 7, 9, 9, 15 中为 1（4 个 ≥ 4）；
     位 3 在 12, 9, 8, 9, 15 中为 1（5 个 ≥ 4）；
     位 1、位 2 的计数分别为 2、3，均 < 4。
     结果是 (1001)₂ = 9。
```

**示例 2**

```text
输入：nums = [2,12,1,11,4,5], k = 6
输出：0
解释：没有位在全部 6 个数中都为 1（k = n 退化为按位与），答案为 0。
```

**示例 3**

```text
输入：nums = [10,8,5,9,11,6,8], k = 1
输出：15
解释：k = 1 时 K-or 退化为普通按位或：
     10 OR 8 OR 5 OR 9 OR 11 OR 6 OR 8 = 15。
```

## 3. 解题思路

### 3.1 暴力思路

签到题，按定义直译就是最优解：**外层枚举每一个二进制位，内层扫一遍数组数一数该位有多少个 1，达到 $k$ 就把答案的该位点亮**。时间 $O(32n)$，本题 $n \le 50$，总共不超过 $32 \times 50 = 1600$ 次位运算，轻松通过。

> 💡 这题没有「暴力 → 优化」的跳跃：每个元素的每一位都可能影响对应位的计数，任何正确算法都必须看到全部 $32n$ 个「(元素, 位)」组合，信息量下界就是 $\Omega(32n)$。考点不在复杂度，而在**把定义干净利落地翻译成位运算代码**的三个基本功：取位、置位、位范围（见 §4）。

### 3.2 核心观察：按位独立 + 阈值计数

![按位投票核心观察](images/kor_bit_voting_concept.svg)

**观察 1（位独立性）**：把数组写成二进制竖式后，**每一列就是一个独立的子问题**——第 $i$ 列的判定只看该列 1 的个数 $\text{cnt}[i]$，与其他位、元素大小、出现顺序统统无关：

$$\text{K-or 的第 } i \text{ 位} = \begin{cases} 1, & \text{cnt}[i] \ge k \\ 0, & \text{cnt}[i] < k \end{cases}$$

**观察 2（$k$ 的三档语义）**：K-or 是「**按位投票**」，$k$ 就是每个位的票数门槛：

| $k$ 的取值 | 语义 | 等价操作 |
|-----------|------|----------|
| $k = 1$ | 至少 1 个元素该位为 1 | 普通按位**或** OR（示例 3） |
| $1 < k < n$ | 至少 $k$ 个元素该位为 1 | **阈值计数**（本题一般情形） |
| $k = n$ | 全部元素该位为 1 | 普通按位**与** AND（示例 2） |

> 💡 K-or 是 OR / AND 的统一推广。写完代码后拿示例 3 验证结果等于全体元素的 OR、拿示例 2 验证等于全体元素的 AND——两个天然锚点通过，中间的阈值逻辑基本不会错。

### 3.3 算法流程

![算法流程](images/kor_algorithm_flow.svg)

1. **初始化**：`ans = 0`。
2. **外层枚举位** $i$ 从 0 到 31：
   - **内层计数**：遍历每个 $x \in \text{nums}$，累加 `cnt += (x >> i) & 1`。
   - **阈值判定**：若 $\text{cnt} \ge k$，执行 `ans |= 1 << i` 点亮该位；否则跳过。
3. **收尾**：32 位全部处理完，返回 `ans`。

流程里藏着一个**循环不变式**：任何时刻 `ans` 中为 1 的位都是「计数已达标」的位——每个位被访问一次、判定一次、决定一次，位与位之间零交互。

### 3.4 示例演算

以 `nums = [7,12,9,8,9,15]`, `k = 4`（示例 1）为例：

![示例演算](images/kor_example_walkthrough.svg)

| 位 $i$ | 7 | 12 | 9 | 8 | 9 | 15 | cnt | $\text{cnt} \ge 4$？ | ans（更新后） |
|--------|---|----|---|---|---|----|-----|----------------------|----------------|
| 0 | 1 | 0 | 1 | 0 | 1 | 1 | **4** | ✓ 置位 | $0001_2$ |
| 1 | 1 | 0 | 0 | 0 | 0 | 1 | 2 | ✗ 跳过 | $0001_2$ |
| 2 | 1 | 1 | 0 | 0 | 0 | 1 | 3 | ✗ 跳过 | $0001_2$ |
| 3 | 0 | 1 | 1 | 1 | 1 | 1 | **5** | ✓ 置位 | $1001_2$ |
| 4~31 | — | — | — | — | — | — | 0 | ✗ 跳过 | $1001_2$ |

最终返回 $1001_2 = 8 + 1 = 9$ ✓

## 4. 算法细节

三个位运算基本功决定了这份代码能不能一遍写对：

1. **取位**：`x` 的第 $i$ 位是 0 还是 1，用 `(x >> i) & 1`——右移 $i$ 位把目标位送到最低位再 `& 1` 取出，得到 0/1 本身，可直接累加进 `cnt`。等价写法 `x & (1 << i)` 得到的是掩码值（0 或 $2^i$），只能判非零，不如前者顺手。
2. **置位**：把答案的第 $i$ 位点亮，用 `ans |= 1 << i`——`1 << i` 是只有第 $i$ 位为 1 的掩码，或上去即可；已点亮的位再或不变。
3. **位范围**：约束 $0 \le \text{nums}[i] < 2^{31}$ 说明最高有效位是第 30 位，枚举 $i \in [0, 31]$ 共 32 位必然覆盖（写 32 是覆盖 `int` 全部位宽的保险惯例，兼容负数情形；只枚举到 30 也对本题正确）。

## 5. 正确性证明

**引理 1（位判定独立性）**：K-or 结果的第 $i$ 位仅由「第 $i$ 位为 1 的元素个数」$\text{cnt}[i]$ 与 $k$ 的比较决定：该位为 1 $\iff \text{cnt}[i] \ge k$。

**证明**：按定义，第 $i$ 位为 1 当且仅当至少 $k$ 个元素的第 $i$ 位为 1。设第 $i$ 位为 1 的元素个数为 $\text{cnt}[i]$，则「至少 $k$ 个」即 $\text{cnt}[i] \ge k$。判定式中不出现任何其他位或其他统计量，故第 $i$ 位的取值与 $\text{cnt}[i]$、$k$ 之外的输入无关。∎

**定理**：算法返回值等于 `nums` 的 K-or 值。

**证明**：对每个 $i$，`(x >> i) & 1` 恰好取出 $x$ 二进制表示的第 $i$ 位，故内层循环结束时 `cnt` 精确等于 $\text{cnt}[i]$。算法当且仅当 $\text{cnt}[i] \ge k$ 时执行 `ans |= 1 << i`（置第 $i$ 位为 1），否则该位保持初值 0；由引理 1，每一位的判定均与定义一致。又整数的二进制表示唯一，各位置互不干扰，组装出的 `ans` 与 K-or 定义值逐位相同，故相等。∎

## 6. 复杂度分析

- **时间复杂度**：$O(32n)$，即 $O(n \log C)$（$C = 2^{31}$ 为值域上界，位数 $= \log C$）。外层 32 个位 × 内层 $n$ 个元素；$n \le 50$ 时总量 $\le 1600$ 次位运算。这也是信息量下界——每个 `(元素, 位)` 组合都必须被观察一次。
- **空间复杂度**：$O(1)$。只用 `ans`、`cnt`、循环变量等常数个额外变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int findKOr(vector<int>& nums, int k) {
        int ans = 0;
        for (int i = 0; i < 32; i++) {            // 枚举每一个二进制位
            int cnt = 0;
            for (int x : nums)                     // 数该位为 1 的元素个数
                cnt += (x >> i) & 1;
            if (cnt >= k) ans |= 1 << i;           // 票数达标，点亮该位
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def findKOr(self, nums: List[int], k: int) -> int:
        ans = 0
        for i in range(32):                        # 枚举每一个二进制位
            if sum(x >> i & 1 for x in nums) >= k: # 该位票数达标
                ans |= 1 << i                      # 点亮该位
        return ans
```

## 8. 边界情况与易错点

1. **「至少 $k$ 个」含等号**：$\text{cnt} = k$ 时该位也要点亮。示例 1 中 bit 0 恰好 4 个 = $k$，判定为 ✓；条件必须写 `cnt >= k` 而非 `cnt > k`。
2. **重复元素各计一票**：`9` 出现两次，在 bit 0 和 bit 3 各贡献 2 票——计数按元素出现次数，不去重。
3. **$k = n$ 时答案可为 0**：全体按位与可能为 0（示例 2），不要误以为结果至少有一个 1。
4. **位范围别写死 31 个**：$2^{31} - 1$ 的最高位是第 30 位，枚举 `[0, 31]`（32 位）是保险写法；若只枚举到 30，本题数据下也对，但遇到 64 位或负数输入就会漏位。
5. **运算符优先级**：C++ 中 `>>` 高于 `&`，`x >> i & 1` 解析为 `(x >> i) & 1` 恰好正确，但混入 `==`、`+` 等运算符时建议显式加括号，防止读错。
6. **单元素数组**：$n = 1$ 时 $k$ 只能取 1，K-or 就是该元素本身。
