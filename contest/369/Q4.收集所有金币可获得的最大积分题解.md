# LeetCode 收集所有金币可获得的最大积分 题解

## 1. 题目概述

- **标题 / 题号**：收集所有金币可获得的最大积分（#2920，hard）
- **链接**：https://leetcode.cn/problems/maximum-points-after-collecting-coins-from-all-nodes/
- **来源**：LeetCode 第 369 场周赛 Q4
- **难度**：困难
- **标签**：树形 DP、动态规划、位运算、深度优先搜索

**题意**：给定一棵以 $0$ 为根、$n$ 个节点的树（`edges` 给出无向边），节点 $i$ 有 $coins[i]$ 枚金币。从根出发收集**所有**节点的金币，且必须先收集节点的祖先、再收集该节点。每个节点二选一：

- **方法①（全收）**：得 $coins[i] - k$ 分（可为负，负了就是扣分）；
- **方法②（半收）**：得 $\lfloor coins[i]/2 \rfloor$ 分，但节点 $i$ **子树内所有节点**的金币都减半（向下取整）。

返回收集完全部金币后的最大总积分。

**约束**：

- $2 \le n \le 10^5$
- $0 \le coins[i] \le 10^4$
- $0 \le k \le 10^4$

## 2. 示例

**示例 1**

```text
输入：edges = [[0,1],[1,2],[2,3]], coins = [10,10,3,3], k = 5
输出：11
解释：节点 0、1 用方法①，各得 10−5 = 5 分；节点 2 用方法②，得 ⌊3/2⌋ = 1 分，
     同时节点 3 的金币减为 ⌊3/2⌋ = 1；节点 3 再用方法②，得 ⌊1/2⌋ = 0 分。
     总计 5 + 5 + 1 + 0 = 11。
```

**示例 2**

```text
输入：edges = [[0,1],[0,2]], coins = [8,4,4], k = 0
输出：16
解释：k = 0 时方法①无代价，全部用①：(8−0) + (4−0) + (4−0) = 16。
```

**示例 3（自拟，验证 $k$ 巨大的极端情形）**

```text
输入：edges = [[0,1]], coins = [10000,10000], k = 10000
输出：7500
解释：任何节点用方法①都得 0 分。最优：节点 0 用②得 5000 分，节点 1 的金币
     减为 5000；节点 1 再用②得 2500 分。总计 7500。
     —— k 巨大时「全收」颗粒无收，半收反而盆满钵满。
```

## 3. 解题思路

### 3.1 暴力思路：$2^n$ 枚举与贪心的失效

每个节点在①②中独立二选一，共 $2^n$ 种方案，$n \le 10^5$ 时是天文数字，不可行。

那贪心呢？也不行。**两种代价不在同一时间尺度**：方法①的代价 $-k$ **现在付**，方法②的代价（子树金币减半）**子孙付**，局部无法比较。反例就在示例 1 的根节点：方法①得 $10-5=5$、方法②得 $\lfloor 10/2 \rfloor=5$，**局部完全打平**；但方法①保住了节点 1 的 10 枚金币（其子树还能再得 6 分），方法②却把它砍半（子树只剩 2 分），全局差 4 分。决策相互纠缠 ⟹ 必须让子孙的损失通过 DP 自底向上传回来。

### 3.2 核心观察：祖先链上的「减半次数」是唯一需要记住的状态

![祖先链上的减半次数状态](images/coins_tree_halving_state.svg)

收集顺序自根向下，祖先**永远先于**子孙决策。方法②的影响范围虽是「整个子树」，但对任意节点 $u$ 来说，它感受到的全部历史只有一件事——**严格祖先中有多少个节点选了方法②**，记为 $j$：

- 祖先每选一次②，$u$ 及其子树的金币就整体减半一次；
- 嵌套的减半可**合并为一次右移**：$\lfloor \lfloor x/2 \rfloor /2 \rfloor = \lfloor x/2^2 \rfloor$（非负整数成立），故 $u$ 的**实际金币** $= coins[u] \gg j$；
- 与**具体哪些祖先**选了②无关（减半彼此可交换），只与**个数**有关。

再由 $coins[u] \le 10^4 < 2^{14}$：$j \ge 14$ 时实际金币恒为 $0$——**$j$ 只有 $0 \sim 14$ 共 15 个取值**！于是定义：

$$dp[u][j] = \text{当 } u \text{ 的严格祖先共选了 } j \text{ 次方法②时，子树 } u \text{ 能取得的最大积分}$$

答案即 $dp[0][0]$（根没有祖先）。

> 💡 状态设计的关键一步是「**效果的压缩**」：影响范围覆盖整棵子树的操作，沿根到节点的路径看只是一个可加计数器；又因为值域有限，计数器自动封顶在 $\log_2(\max coins)$。影响范围大 ≠ 状态必须高维。

### 3.3 算法流程：自底向上合并 + 迭代防爆栈

![dp 转移图](images/coins_tree_dp_transition.svg)

记 $c = coins[u] \gg j$ 为 $u$ 的实际金币，转移在「自己怎么收」与「孩子继承什么状态」两个层面展开：

$$dp[u][j] = \max\Big(\underbrace{(c - k) + \sum_{v} dp[v][j]}_{\text{方法①：孩子继承 } j},\ \underbrace{\big(coins[u] \gg (j{+}1)\big) + \sum_{v} dp[v][j{+}1]}_{\text{方法②：孩子继承 } j+1}\Big)$$

要点：

1. 方法②自己得 $\lfloor c/2 \rfloor = coins[u] \gg (j+1)$（再次用到嵌套减半合并）。
2. $j = 14$ 时 $coins[u] \gg 14 = 0$：方法①得 $-k \le 0$、方法②得 $0$，全零状态「自锁」，孩子下标用 $\min(j+1, 14)$ 封顶即可。
3. 计算 $u$ 前必须先算完所有孩子 ⟹ 从根 **BFS** 得到访问序，再**逆序**处理（逆 BFS 序中任意节点排在其全部子孙之后，等价于后序合并），同时天然规避 $n = 10^5$ 链形树的**递归爆栈**。

### 3.4 示例演算

![示例 1 演算](images/coins_tree_walkthrough.svg)

以示例 1（链 `0-1-2-3`，$T = 14$，仅列关键列）自底向上：

| 节点 | $dp[\cdot][0]$ | $dp[\cdot][1]$ | $j=0$ 最优 |
|------|----------------|----------------|------------|
| 3（叶） | $\max(3-5,\ 1) = 1$ | $\max(1-5,\ 0) = 0$ | ② |
| 2 | $\max(-2+1,\ 1+0) = 1$ | $0$ | ② |
| 1 | $\max(5+1,\ 5+0) = 6$ | $\max(0+0,\ 2+0) = 2$ | ① |
| 0（根） | $\max(5+6,\ 5+2) = \mathbf{11}$ | — | ① |

答案 $dp[0][0] = 11$。注意节点 1 在 $j=0$ 与 $j=1$ 两个状态下最优方法**不同**（前者①、后者②）——这正是「不能每点独立贪心、必须把 $j$ 带进状态」的直接证据。

## 4. 算法细节

1. **建图**：无向边双向加入邻接表；从根 $0$ 做 BFS，记录 `parent` 与访问序 `order`。
2. **定序**：按 `order` **逆序**处理——处理 $u$ 时其所有孩子均已算完，等价于后序遍历的合并顺序，两语言通吃且不爆栈。
3. **状态维度**：固定 $T = 14$（由 $10^4 < 2^{14}$ 保证），`dp` 为 $n \times 15$ 表；孩子状态下标用 `min(j+1, T)` 封顶（合法性见引理 3，全零状态自锁）。
4. **求和复用**：方法②的孩子和 $\sum_v dp[v][j+1]$ 恰是方法①在 $j+1$ 处的孩子和。先对每个 $j$ 累出 $s[j] = \sum_v dp[v][j]$，转移时直接取 $s[\min(j+1, T)]$，省一半累加。
5. **叶子**：无孩子，$s$ 全零，转移退化为二选一，天然成为递归边界。
6. **答案**：`dp[0][0]`，根的祖先数为 0。

## 5. 正确性证明

**引理 1（减半可合并为右移）**：对非负整数 $x$ 与正整数 $a, b$，$\Big\lfloor \dfrac{\lfloor x/2^a \rfloor}{2^b} \Big\rfloor = \Big\lfloor \dfrac{x}{2^{a+b}} \Big\rfloor$。

**证明**：记 $q = \lfloor x/2^a \rfloor$，则 $x = q \cdot 2^a + r$，$0 \le r < 2^a$；再记 $q' = \lfloor q/2^b \rfloor$，则 $q = q' \cdot 2^b + s$，$0 \le s < 2^b$。代入得 $x = q' \cdot 2^{a+b} + (s \cdot 2^a + r)$，且 $0 \le s \cdot 2^a + r < 2^{a+b}$，故 $\lfloor x/2^{a+b} \rfloor = q'$。∎

**推论 1**：祖先共选 $j$ 次方法②后，节点 $u$ 的实际金币为 $coins[u] \gg j$；节点 $u$ 自己选②时得分为 $coins[u] \gg (j+1)$。

**引理 2（状态充分性 / 无后效性）**：任何收集方案中，子树 $u$ 内部能取得的积分仅取决于 $j$（祖先选②的次数）与子树内部的后续决策，与「哪些祖先、沿哪条路径选了②」无关。

**证明**：由引理 1，祖先部分的 $j$ 次减半合并为一次右移；子树内每个节点的实际金币完全由 $coins$、$j$ 与子树内部决策决定，子树之外的信息无法再影响这些值，而子树积分恰由这些实际金币求和而来。∎

**引理 3（截断合法性）**：对一切 $j \ge 14$，$dp[u][j]$ 为与 $j$ 无关的常量，故转移中 $\min(j+1, 14)$ 的封顶不改变任何结果。

**证明**：对树自底向上归纳。叶子：$j \ge 14$ 时 $coins \gg j = 0$，$dp[u][j] = \max(0 - k,\ 0) = 0$ 为常量。内部节点：设所有孩子 $v$ 已满足 $dp[v][j] = dp[v][14]$（$j \ge 14$），则

$$dp[u][j] = \max\big(-k + \textstyle\sum_v dp[v][j],\ 0 + \textstyle\sum_v dp[v][j+1]\big) = \max(-k, 0) + \textstyle\sum_v dp[v][14] = \textstyle\sum_v dp[v][14]$$

（末步用了 $k \ge 0$），仍为常量。∎

**定理**：$dp[0][0]$ 等于收集所有金币可获得的最大积分。

**证明**：对子树高度归纳，证明 $dp[u][j]$ 恰为「祖先选②次数为 $j$ 的一切方案中子树 $u$ 的最大积分」。任一合法方案在 $u$ 处必选①或②：选①时 $u$ 得 $(coins[u] \gg j) - k$，各孩子以状态 $j$ 独立继续，由引理 2 子树内的最优后续为 $\sum_v dp[v][j]$（归纳假设）；选②时 $u$ 得 $coins[u] \gg (j+1)$（推论 1），各孩子以状态 $j+1$ 继续，最优后续为 $\sum_v dp[v][j+1]$（$j+1 > 14$ 时由引理 3 封顶合法）。两种选择取最大即转移方程；反之，任何方案都对应转移中的某条分支，不会超过该分支的最优值。根处 $j = 0$，即全局最大积分。∎

## 6. 复杂度分析

- **时间复杂度**：$O\big(n \log(\max coins)\big) = O(15n)$。每个节点转移 $15$ 个状态；每条边在累加 $s$ 时贡献至多 $15$ 次加法，$n = 10^5$ 时约 $3 \times 10^6$ 次基本操作。
- **空间复杂度**：$O(15n)$。`dp` 表 $n \times 15$（`long long` 约 12 MB）；邻接表、BFS 序、`parent` 共 $O(n)$。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    long long maximumPoints(vector<vector<int>>& edges, vector<int>& coins, int k) {
        int n = coins.size();
        vector<vector<int>> g(n);
        for (auto& e : edges) {
            g[e[0]].push_back(e[1]);
            g[e[1]].push_back(e[0]);
        }

        const int T = 14;  // coins[i] <= 10^4 < 2^14：减半 14 次后金币必为 0

        // BFS 定序并记父节点：n 可达 1e5，链形树递归会爆栈，改用迭代
        vector<int> parent(n, -1), order, seen(n, 0);
        order.reserve(n);
        seen[0] = 1;
        vector<int> q = {0};
        for (int i = 0; i < (int)q.size(); ++i) {
            int u = q[i];
            order.push_back(u);
            for (int v : g[u]) {
                if (!seen[v]) {
                    seen[v] = 1;
                    parent[v] = u;
                    q.push_back(v);
                }
            }
        }

        // dp[u][j]：u 的严格祖先共选了 j 次方法②时，子树 u 的最大积分
        vector<vector<long long>> dp(n, vector<long long>(T + 1, 0));
        for (int i = n - 1; i >= 0; --i) {  // 逆 BFS 序 = 自底向上
            int u = order[i];
            vector<long long> s(T + 1, 0);  // s[j] = Σ dp[v][j]（v 取遍 u 的孩子）
            for (int v : g[u]) {
                if (v == parent[u]) continue;
                for (int j = 0; j <= T; ++j) s[j] += dp[v][j];
            }
            for (int j = 0; j <= T; ++j) {
                int jc = min(j + 1, T);  // 方法②的孩子状态（j = T 时自锁）
                long long opt1 = (coins[u] >> j) - k + s[j];
                long long opt2 = (coins[u] >> jc) + s[jc];
                dp[u][j] = max(opt1, opt2);
            }
        }
        return dp[0][0];
    }
};
```

### Python

```python
class Solution:
    def maximumPoints(self, edges: List[List[int]], coins: List[int], k: int) -> int:
        n = len(coins)
        g = [[] for _ in range(n)]
        for a, b in edges:
            g[a].append(b)
            g[b].append(a)

        T = 14  # coins[i] <= 10^4 < 2^14：减半 14 次后金币必为 0

        # BFS 定序并记父节点：避免深链递归爆栈
        parent = [-1] * n
        order = []
        seen = [False] * n
        seen[0] = True
        q = deque([0])
        while q:
            u = q.popleft()
            order.append(u)
            for v in g[u]:
                if not seen[v]:
                    seen[v] = True
                    parent[v] = u
                    q.append(v)

        # dp[u][j]：u 的严格祖先共选了 j 次方法②时，子树 u 的最大积分
        dp = [[0] * (T + 1) for _ in range(n)]
        for u in reversed(order):  # 逆 BFS 序 = 自底向上
            s = [0] * (T + 1)  # s[j] = Σ dp[v][j]
            for v in g[u]:
                if v == parent[u]:
                    continue
                dv = dp[v]
                for j in range(T + 1):
                    s[j] += dv[j]
            du, cu = dp[u], coins[u]
            for j in range(T + 1):
                jc = min(j + 1, T)  # 方法②的孩子状态（j = T 时自锁）
                opt1 = (cu >> j) - k + s[j]
                opt2 = (cu >> jc) + s[jc]
                du[j] = max(opt1, opt2)
        return dp[0][0]
```

## 8. 边界情况与易错点

1. **递归爆栈**：$n \le 10^5$，链形树递归深度 $10^5$——Python 默认上限 1000 必炸，C++ 也逼近默认栈上限。统一用 BFS 定序 + 逆序处理的迭代写法。
2. **孩子状态下标越界**：$j = T$ 时 $j+1$ 越界，用 $\min(j+1, T)$ 封顶；其合法性依赖引理 3 的「全零状态自锁」，不是随手 hack。
3. **$T$ 的取值**：固定 $14$ 由 $10^4 < 2^{14}$ 保证，最省心；若改用 `bit_length(max(coins))` 动态计算，需留意全零输入时 `bit_length(0) = 0` 的边界。
4. **方法①可为负但不能不收**：题面要求收集所有金币，负分也必须收，代码里不要写「跳过」分支。
5. **无向边建图**：邻接表双向加边，BFS/合并时靠 `parent` 跳过父边，别把父亲当成孩子。
6. **溢出**：总积分上界 $\sum coins \le 10^9$，恰在 `int` 边缘；C++ 中间累加用 `long long`（官方签名也返回 `long long`），Python 无此虞。
7. **答案非负的 sanity check**：全部选②必然得 $\ge 0$（每次得 $\lfloor c/2 \rfloor \ge 0$），可作对拍基准；若算出负数，一定是转移写错。
