# LeetCode 打家劫舍 IV 题解

## 1. 题目概述

- **标题 / 题号**：打家劫舍 IV（#2560，medium）
- **链接**：https://leetcode.cn/problems/house-robber-iv/
- **来源**：LeetCode 第 331 场周赛 Q3
- **难度**：中等
- **标签**：二分答案、贪心、数组、动态规划（官方标签里的 DP 恰是本题最大的陷阱）

**题意**：沿街一排连续房屋，第 $i$ 间放有 `nums[i]` 美元。**相邻房屋装有连通的防盗系统，不能同时窃取**。小偷的**窃取能力**定义为窃取过程中从**单间**房屋窃得的**最大金额**。给定 $k$（至少要窃取的房屋数，题目保证总能窃取至少 $k$ 间），返回**最小**窃取能力。

**约束**：

- $1 \le \text{nums.length} \le 10^5$
- $1 \le \text{nums[i]} \le 10^9$
- $1 \le k \le \lfloor(\text{nums.length}+1)/2\rfloor = \lceil n/2 \rceil$（恰为不相邻约束下最多可选的间数）

> 💡 本题另有[每日题解 2560](../../solution/2501-2600/2560_打家劫舍IV.md)：侧重「二分答案骨架的思想提炼与面试表达」。本文作为周赛复盘，聚焦**赛场上的惯性陷阱（系列前三代都是 DP，这一代偏偏不是）**、**完整正确性证明（阈值等价 → 二段性 → 贪心最优性 → 答案落在数组中）**与**二分支收缩方向等易错点**，两篇互为印证。

## 2. 示例

**示例 1**

```text
输入：nums = [2,3,5,9], k = 2
输出：5
解释：至少抢 2 间、不相邻，共有 3 种方式：
     - 下标 0,2：能力 = max(2,5) = 5
     - 下标 0,3：能力 = max(2,9) = 9
     - 下标 1,3：能力 = max(3,9) = 9
     返回 min(5, 9, 9) = 5。
```

**示例 2**

```text
输入：nums = [2,7,9,3,1], k = 2
输出：2
解释：共 7 种窃取方式，能力最小的是抢下标 0,4：max(2,1) = 2。
```

**示例 3（自造：k = 1，答案是全局最小值）**

```text
输入：nums = [4,1,2], k = 1
输出：1
解释：只抢 1 间，当然抢金额最小的那间 nums[1] = 1；无需任何特判。
```

**示例 4（自造：k 拉满到 ⌈n/2⌉，选法几乎唯一）**

```text
输入：nums = [2,7,9,3,1], k = 3
输出：9
解释：n = 5、k = 3 时不相邻选 3 间只有 {0,2,4} 一种，能力 = max(2,9,1) = 9。
```

## 3. 解题思路

### 3.1 暴力思路与赛场惯性弯路

**暴力枚举**所有「不相邻、至少 $k$ 间」的选法，逐个求最大值再取最小。不相邻组合数最坏约为 $\binom{\lceil n/2\rceil}{k}$，$n = 10^5$ 时是天文数字，不可行。

**更值得复盘的是赛场上的第一反应**：「打家劫舍」系列前三代（198 线性、213 环形、337 树形）全部是 DP，肌肉记忆会直接往 `dp[i][抢/不抢]` 上套。但本题的优化目标是**最小化所选元素的最大值**，而不是最大化收益和：

1. **状态必须携带「当前能力」**：最优子结构要求知道历史最大值才能转移，状态变成 $(i, j, \text{当前能力})$，其中能力值域高达 $10^9$，无法枚举成状态维度；
2. **$k$ 还要占一维**：`dp[i][j]` 的 $j \le k \le \lceil n/2 \rceil$，就算能力能压进状态，$O(nk)$ 在 $n = 10^5$、$k = 5\times10^4$ 时也是 $5\times10^9$ 级别。

> ⚠️ **把「系列题 = 同一解法」当成反射是周赛掉分的高频原因**。打家劫舍系列的公共结构只有「不能相邻」，198/213/337 的目标是**求和型最值**（DP 可加、无后效性成立），2560 的目标是**阈值型最值**（max 不可加、历史会泄漏到未来）。识别目标函数的类型，比记住系列名重要得多。

### 3.2 核心观察：二分答案 + 贪心判定

![核心观察：最小化最大值 → 猜阈值 c，0/1 过滤后贪心判定，f(c) 单调给出二段性](images/robber4_331_binary_answer.svg)

题面里三个信号合起来几乎唯一地指向**二分答案**：

1. **「最小化……最大值」**——目标函数是 $\min_S \max_{i \in S} \text{nums}[i]$，max-threshold 型最值的标志性问法；
2. **能力只由所选房屋的最大金额决定**——一旦给定能力上限 $c$，「能力 $\le c$」就等价于「只抢金额 $\le c$ 的房」，max 约束瞬间坍缩成**逐间的 0/1 过滤**，与历史无关；
3. **候选答案可 $O(n)$ 验证**——问「只抢金额 $\le c$ 的房、互不相邻，最多能抢几间」可以贪心一扫而出。

于是把「求最小能力」反转成「**猜一个能力 $c$，判定它是否可行**」：

$$f(c) = \text{只在金额} \le c \text{ 的房中、互不相邻，最多能抢的间数}$$

$c$ 越大可选房越多，$f(c)$ **单调不降**——标准的**二段性**：$c < c^*$ 时 $f(c) < k$ 不可行，$c \ge c^*$ 时 $f(c) \ge k$ 可行。二分找到最小可行 $c^*$ 即答案。且 $f(c)$ 只依赖集合 $\{i : \text{nums}[i] \le c\}$，该集合只在 $c$ 跨过某个 `nums[i]` 时变化，所以 $c^*$ **必然等于数组中的某个金额**——这也是「直接在值域上二分，结果天然合法」的依据。

### 3.3 算法流程：贪心 check

![算法流程：check(c) 贪心一扫，能抢就抢 + 抢完 i+=2 跳过相邻，数够 k 间提前返回 true](images/robber4_331_greedy_check.svg)

**外层：值域二分** $c \in [1, \max(\text{nums})]$，`ans` 初始化为 $\max(\text{nums})$：

- `check(mid)` 为真 → `ans = mid; hi = mid - 1`（**可行向左收缩找更小**）；
- 为假 → `lo = mid + 1`（阈值太小，放大）。

**内层：check(c) 贪心一扫 $O(n)$**：`i = 0, cnt = 0`，从左到右扫——

- 若 `nums[i] <= c`：抢这间，`cnt++`（**`cnt >= k` 立即返回 true**），然后 `i += 2` **跳过相邻房**；
- 否则 `i += 1` 只挪一格；
- 扫完仍 `cnt < k` 返回 false。

「能抢就抢 + 抢完跳两格」的直觉：在阈值内**越早抢越给后缀留空间**——抢下标 $i$ 与抢下标 $i+1$（若都可抢）对后续的影响完全对称，但抢 $i$ 永远不会比抢 $i+1$ 差（严格证明见 §5 引理 3）。

### 3.4 示例演算

![示例 1 逐步演算：值域二分 4 轮，每轮贪心走查，最终收敛 ans=5](images/robber4_331_walkthrough.svg)

以示例 1 `nums = [2,3,5,9]`、`k = 2` 为例，值域 $[1, 9]$，`ans = 9`：

| 轮 | lo | hi | mid | check(mid) 贪心走查 | 判定 / 收缩 |
|----|----|----|-----|----------------------|-------------|
| 1 | 1 | 9 | 5 | $i{=}0$：$2\le5$ 抢 $cnt{=}1$，$i{=}2$；$5\le5$ 抢 $cnt{=}2$ | ✓ $cnt\ge k$ → **ans=5**，hi=4 |
| 2 | 1 | 4 | 2 | $i{=}0$：$2\le2$ 抢 $cnt{=}1$，$i{=}2$；$5{>}2$，$i{=}3$；$9{>}2$ | ✗ $cnt{=}1{<}2$ → lo=3 |
| 3 | 3 | 4 | 3 | $i{=}0$：$2\le3$ 抢 $cnt{=}1$，$i{=}2$；$5{>}3$，$i{=}3$；$9{>}3$ | ✗ → lo=4 |
| 4 | 4 | 4 | 4 | $i{=}0$：$2\le4$ 抢 $cnt{=}1$，$i{=}2$；$5{>}4$，$i{=}3$；$9{>}4$ | ✗ → lo=5 |

`lo=5 > hi=4` 区间缩空，返回 **ans = 5** ✓。对照验证：$c=5$ 时能力 $\le 5$ 的房 = $\{2, 5\}$（下标 0、2），不相邻恰好 2 间；$c=4$ 时只剩 $\{2\}$ 一间，$f(4)=1<k$——5 正是可行与不可行的分界。

## 4. 算法细节

1. **check 写法的三处关键**：能抢就抢（`nums[i] <= c`）；**抢完 `i += 2`**（跳过相邻房，满足约束的挪法）；**`cnt >= k` 提前终止**（后缀无需再扫，最坏 $O(n)$ 不变、平均常数更小）。
2. **二分支收缩方向**：本题求**最小**可行值，可行分支记下 `ans = mid` 后**向左收缩** `hi = mid - 1`。写反（可行向右扩）会收敛到 $\max(\text{nums})$——「最小化最大值」与「最大化最小值」（如 2517）的二分方向恰好互为镜像，赛场上默写模板前先想清楚往哪边缩。
3. **值域二分 vs 排序数组二分**：主解直接二分值域 $[1, \max]$，约 $\log_2 10^9 \approx 30$ 轮；也可以对**排序后的 `nums` 下标**二分（答案必是某个 `nums[i]`，见 §5 引理 4），约 $\log_2 n \approx 17$ 轮但需先 $O(n\log n)$ 排序。两者总量同阶，值域二分代码更短、不用排序，是赛场上更稳的选择。
4. **`ans` 为什么敢初始化为 $\max(\text{nums})$**：$c = \max$ 时所有房可选，贪心最多抢 $\lceil n/2\rceil \ge k$（约束 $k \le \lfloor(n+1)/2\rfloor$ 保证），`check(hi)` 必真，二分闭区间非空、循环至少记下一个可行值。
5. **`lo` 从 1 还是从 $\min(\text{nums})$ 起步都行**：$c < \min(\text{nums})$ 时 `check` 必假，多扫几轮而已；从 $\min$ 起步少几轮常数优化，可读性差别不大。

## 5. 正确性证明

**引理 1（阈值等价）**：存在窃取能力 $\le c$ 且抢至少 $k$ 间的合法方案，当且仅当 $f(c) \ge k$。

**证明**：（⇒）设合法方案 $S$ 能力 $\le c$ 且 $|S| \ge k$，则 $S$ 中每间房金额 $\le c$ 且互不相邻，故 $S$ 本身是「只在金额 $\le c$ 的房中不相邻选取」的一个方案，其大小 $\le f(c)$，得 $f(c) \ge |S| \ge k$。（⇐）若 $f(c) \ge k$，取达到 $f(c)$ 的方案 $S$：$|S| = f(c) \ge k$，且每间金额 $\le c$，故能力 $=\max_{i\in S}\text{nums}[i] \le c$，是一合法方案。∎

**引理 2（二段性）**：$f(c)$ 关于 $c$ 单调不降，故集合 $\{c \in [1, \max] : f(c) \ge k\}$ 是一段非空区间（若非空则形如 $[c^*, \max]$）。

**证明**：$c_1 \le c_2 \Rightarrow \{i : \text{nums}[i] \le c_1\} \subseteq \{i : \text{nums}[i] \le c_2\}$，前者中任何不相邻选法也是后者的合法选法，故 $f(c_1) \le f(c_2)$。又 $c = \max(\text{nums})$ 时所有房可选，贪心取 $0, 2, 4, \dots$ 可得 $\lceil n/2 \rceil \ge k$ 间，故 $f(\max) \ge k$，集合非空。∎

**引理 3（贪心最优性）**：`check(c)` 中贪心策略数出的间数恰等于 $f(c)$，即贪心既不漏判（可行判可行）也不误判（不可行判不可行）。

**证明**：记 $A = \{i : \text{nums}[i] \le c\}$，贪心选出的下标序列为 $g_1 < g_2 < \cdots$，任取 $A$ 中一个大小为 $m$ 的不相邻选法 $b_1 < b_2 < \cdots < b_m$。对 $j$ 归纳证明 $g_j \le b_j$（$j \le m$）：

- **基座**：$g_1$ 是 $A$ 的最小元素，而 $b_1 \in A$，故 $g_1 \le b_1$；
- **归纳步**：设 $g_{j} \le b_{j}$。$b_{j+1}$ 与 $b_j$ 不相邻故 $b_{j+1} \ge b_j + 2 \ge g_j + 2$，且 $b_{j+1} \in A$——即 $b_{j+1}$ 是「下标 $\ge g_j + 2$ 的 $A$ 中元素」；而贪心在 $g_j$ 抢完后恰好从 $g_j + 2$ 开始找 $A$ 的最小元素，故 $g_{j+1} \le b_{j+1}$。

归纳说明贪心选第 $j$ 个（$j \le m$）时恒有候选（$b_j$ 兜底），故贪心至少选出 $m$ 间，即贪心间数 $\ge m$ 对一切合法选法成立，从而 $\ge f(c)$；又贪心选法本身合法，其间数 $\le f(c)$。二者相等。∎

**引理 4（答案落在数组中）**：最小可行阈值 $c^* = \min\{c \in [1, \max] : f(c) \ge k\}$ 满足 $c^* \in \{\text{nums}[i]\}$。

**证明**：$f(c)$ 只依赖集合 $A(c) = \{i : \text{nums}[i] \le c\}$，而 $A$ 在 $c$ 取遍两个**相邻的不同数组值**之间保持不变，故 $f$ 在这样的开区间上为常数。于是 $f(c^*-1) < k \le f(c^*)$ 的翻转只能发生在 $c^*$ 等于某个数组值处（否则 $c^*-1$ 与 $c^*$ 落在同一常数段，$f$ 相等，矛盾）。∎

**定理**：算法返回值等于最小窃取能力。

**证明**：最小窃取能力 $= \min_{\text{合法 } S} \max_{i \in S} \text{nums}[i] = \min\{c : \text{存在能力} \le c \text{ 的合法方案}\} = \min\{c : f(c) \ge k\}$（末步用引理 1）。由引理 2 该集合是形如 $[c^*, \max]$ 的区间且非空；由引理 3，`check(c)` 与条件 $f(c) \ge k$ 等价；由引理 2 的非空性与 `ans` 初始化，二分过程是在单调谓词上求最小真值的闭式模板，恰好收敛到 $c^*$ 并记入 `ans`。故返回值为 $c^*$，即最小窃取能力。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \log M)$，$M = \max(\text{nums}) \le 10^9$。二分约 $\log_2 10^9 \approx 30$ 轮，每轮 `check` 至多完整扫描一遍数组 $O(n)$；`cnt >= k` 的提前终止让多数轮次远快于全扫。总计约 $30 \times 10^5 = 3 \times 10^6$ 次比较，任何语言都轻松通过。改用排序数组下标二分则为 $O(n \log n + n \log n)$，量级相同。
- **空间复杂度**：$O(1)$。二分与贪心都只用常数个变量，原地扫描，不额外开数组（排序数组二分变体需 $O(n)$ 存排序副本）。
- **对照暴力**：枚举组合 $\binom{\lceil n/2\rceil}{k}$ 天文级；惯性 DP 因状态含值域 $10^9$ 的「历史最大值」根本无法成型——本题的降维不是从暴力优化来的，而是**换提问方式**换来的。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minCapability(vector<int>& nums, int k) {
        int lo = 1, hi = *max_element(nums.begin(), nums.end());
        int ans = hi;                       // check(max) 必真，闭区间非空
        while (lo <= hi) {
            int mid = lo + (hi - lo) / 2;
            if (check(nums, mid, k)) {
                ans = mid;                  // 可行：记下，向左找更小
                hi = mid - 1;
            } else {
                lo = mid + 1;               // 不可行：放大阈值
            }
        }
        return ans;
    }
private:
    bool check(const vector<int>& nums, int c, int k) {
        int cnt = 0;
        for (int i = 0; i < (int)nums.size(); ) {
            if (nums[i] <= c) {
                if (++cnt >= k) return true; // 提前终止
                i += 2;                      // 抢了这间，跳过相邻的下一间
            } else {
                i += 1;                      // 抢不起，只挪一格
            }
        }
        return false;                        // 扫完仍不够 k 间
    }
};
```

### Python

```python
class Solution:
    def minCapability(self, nums: List[int], k: int) -> int:
        def check(c: int) -> bool:
            cnt, i, n = 0, 0, len(nums)
            while i < n:
                if nums[i] <= c:
                    cnt += 1
                    if cnt >= k:
                        return True          # 提前终止
                    i += 2                   # 抢了这间，跳过相邻的下一间
                else:
                    i += 1                   # 抢不起，只挪一格
            return False                     # 扫完仍不够 k 间

        lo, hi, ans = 1, max(nums), max(nums)
        while lo <= hi:
            mid = (lo + hi) // 2
            if check(mid):
                ans = mid                    # 可行：记下，向左找更小
                hi = mid - 1
            else:
                lo = mid + 1                 # 不可行：放大阈值
        return ans
```

## 8. 边界情况与易错点

1. **抢完必须 `i += 2`（本题最高频 WA）**：只 `cnt++` 不挪下标，会把相邻两间都数进去——计数偏大 → `check` 误判可行 → 返回偏小的假答案。示例 1 的 `check(2)` 若不跳格会数出 $cnt=2$，直接把答案错成 2。
2. **二分支收缩方向别写反**：求最小可行值，可行分支 `ans = mid; hi = mid - 1` 向**左**缩。写成 `lo = mid + 1` 会一路向右收敛到 $\max(\text{nums})$（示例 1 会返回 9）。
3. **`ans` 初始化为 `hi`（即 $\max$）而非 0**：`check(max)` 必真（约束 $k \le \lceil n/2\rceil$ 保证），初始化为 `hi` 时即使二分边界手抖漏记一轮，也仍持有「已知可行值」，鲁棒性更好。
4. **$k = 1$ 无需特判**：答案是 $\min(\text{nums})$，值域二分天然收敛过去（自造示例 3）；单独写 `if (k == 1) return *min_element(...)` 是画蛇添足，还多一处可能写错分支的代码。
5. **$n = 1$（必有 $k = 1$）**：答案就是 `nums[0]`，二分区间 $[\text{nums}[0], \text{nums}[0]]$ 单点收敛，同样无需特判。
6. **答案天然是数组元素，无需后处理**：由引理 4，值域二分收敛到的 $c^*$ 必等于某个 `nums[i]`；不要 paranoid 地再「向上取整到最近的数组值」。
7. **`int` 足够，别乱上 `long long`**：`nums[i] ≤ 10^9` 在 `int` 范围内（$2^{31}-1 \approx 2.1\times10^9$），二分中点与比较全程 `int` 安全——与同场 Q1（累加和达 $10^{12}$ 必须 `long long`）形成对照：**看是「比较阈值」还是「累加求和」再定类型**。
8. **提前终止别忘**：`cnt >= k` 立即 `return true`。不影响正确性（继续扫 `cnt` 只会更大），但 $n = 10^5$、30 轮二分下这是白送的常数优化；同理 `check` 里没必要先扫出完整 $f(c)$ 再比较。
9. **惯性 DP 是本题最大的坑**（§3.1）：状态需携带值域 $10^9$ 的历史最大值且 $O(nk)$ 超时——看到「打家劫舍」别条件反射上 DP，先看目标函数是**求和型**还是**阈值型**最值。

**延伸思考**：若同一街道要回答**多个不同 $k$ 的离线查询**，可先 $O(n\log n)$ 排序去重值数组，再对每个 $k$ 二分下标，总计 $O((n + q)\log n)$；若问「**恰好** $k$ 间」的最小能力，值域二分 + check 改成「记录贪心选中集合可否恰好凑 $k$」需要更细致的构造（贪心计的是最大值，恰好性要用「可放缩区间」论证）；更一般地，「min-max / max-min + 可单调验证」这一整族题，赛场上值得条件反射地默写出二分模板，把全部思考预算留给 check 的设计。
