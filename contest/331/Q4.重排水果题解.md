# LeetCode 重排水果 题解

## 1. 题目概述

- **标题 / 题号**：重排水果（#2561，hard）
- **链接**：https://leetcode.cn/problems/rearranging-fruits/
- **来源**：LeetCode 第 331 场周赛 Q4
- **难度**：困难
- **标签**：贪心、排序、数组、哈希表

**题意**：两个果篮 `basket1` 与 `basket2` 各有 $n$ 个水果，每个水果有一个成本。每次操作任选下标 $i,j$，交换 `basket1[i]` 与 `basket2[j]`，**交换成本** $=\min(\text{basket1}[i],\text{basket2}[j])$（只付两边较小者，大者白嫖）。目标：使两篮**排序后完全相同**（即两篮作为多重集合相等），求**最小总成本**；不可行返回 $-1$。

**约束**：

- $\text{basket1.length}=\text{basket2.length}=n$，$1\le n\le 10^5$
- $1\le \text{basket1}[i],\text{basket2}[i]\le 10^9$

> 💡 本题另有[每日题解 2561](../../solution/2501-2600/2561_重排水果.md)：侧重「配对最小化 + 封顶技巧」的思想提炼与面试表达。本文作为周赛复盘，聚焦**赛场上的三个典型 WA 点（忘中介封顶、配对方向、只在单侧出现的值）**、**完整正确性证明（交叉分解 → 链式不等式 → 匹配下界）**与 **64 位溢出**，两篇互为印证。

## 2. 示例

**示例 1**

```text
输入：basket1 = [4,2,2,2], basket2 = [1,4,1,2]
输出：1
解释：交换 basket1[1]=2 与 basket2[0]=1，成本 min(2,1)=1。
      交换后 basket1=[4,1,2,2]，basket2=[2,4,1,2]，排序后均为 [1,2,2,4]。
```

**示例 2**

```text
输入：basket1 = [2,3,4,1], basket2 = [3,2,5,1]
输出：-1
解释：值 4 总频 1（只在 basket1）、值 5 总频 1（只在 basket2），均为奇数，
      无法对半均分到两篮，无解。
```

**示例 3（自造：中介摆渡完胜直接交换）**

```text
输入：basket1 = [1,1,100,100], basket2 = [1,1,200,200]
输出：2
解释：值 100 需从篮 1 净移出 1 个，值 200 需从篮 2 净移出 1 个。
      直接换 100 ↔ 200 要付 min(100,200)=100；
      借值为 1 的水果当"摆渡车"：先 100 ↔ 1 付 1，再 1 ↔ 200 付 1，
      摆渡水果原位往返，合计只付 2。
```

**示例 4（自造：两篮本就相等）**

```text
输入：basket1 = [1,2], basket2 = [2,1]
输出：0
解释：两篮多重集合相同，什么都不用做。
```

## 3. 解题思路

### 3.1 暴力思路与赛场弯路

**暴力**：把两篮多重集合的有序对 $(B_1,B_2)$ 当状态，每次转移是 $n^2$ 种交换、边权 $\min$，Dijkstra 求最短路到 $B_1=B_2$。状态数天文级（多重组合的平方），$n=10^5$ 完全不可行。

**更值得复盘的是赛场上从「会配对」到「AC」之间的三道坎**：

1. **忘掉 $2\cdot\text{mn}$ 中介封顶**（最高频 WA）：发现「每次只付较小者 → 小配大」之后，很容易以为把两边的盈余水果**反向配对**直接求和就完了。但自造示例 3 里直接换 $100\leftrightarrow200$ 要付 $100$，正解只要 $2$——存在全局最小值 $\text{mn}$ 时，任何一次交换都可以拆成「经 $\text{mn}$ 摆渡」的两步，成本封顶 $2\,\text{mn}$。
2. **配对对象搞错**：被付的 $m$ 个元素应取**两篮所有盈余合并后最小的 $m$ 个**，而不是「篮 1 盈余取一半、篮 2 盈余取一半」或只对某一侧排序。
3. **可行性判定漏值**：奇偶检查必须覆盖**只在 basket2 出现**的值（示例 2 的值 5），只遍历 `Counter(basket1)` 会漏判。

### 3.2 核心观察：奇偶定可行 → 盈余配对 → 小者付费 + mn 中介封顶

![核心观察：频率均分后盈余水果小配大、小者付费；大值对借全局最小 mn 摆渡，单对成本封顶 2×mn](images/fruits_331_pairing_concept.svg)

**① 可行性 = 奇偶性。** 交换只搬运水果、不改每个值的总频次 $\text{cnt}[v]$。终态两篮相等 ⟹ 每篮各含 $\text{cnt}[v]/2$ 个 $v$ ⟹ $\text{cnt}[v]$ 必须为偶。任一奇频 → 返回 $-1$；全偶则必可行（§5 引理 1）。

**② 盈余配对。** 设 $c_1[v],c_2[v]$ 为 $v$ 在两篮的频次，$\text{target}[v]=\text{cnt}[v]/2$。篮 1 中每个 $v$ 多出 $c_1[v]-\text{target}[v]$ 份（若正）必须送走，全体送走的水果构成多重集 $E_1$；对称地篮 2 的盈余构成 $E_2$。**每个送走的元素恰有一个对侧元素接收**，故 $|E_1|=|E_2|=m$，共 $2m$ 个盈余水果等着搬家。

**③ 小者付费 → 小配大。** 每次交换付 $\min(a,b)$：大值免费搭车。要让被付的 $m$ 个尽量小，应让 $2m$ 个盈余里**最小的 $m$ 个**各自配一个大的当被付者。

**④ $\text{mn}$ 中介封顶。** 设 $\text{mn}$ 为**两篮全体水果**的最小值（注意：不必是盈余水果！）。一次「大换大」$a\leftrightarrow b$ 可以拆成两步：先 $a\leftrightarrow\text{mn}$（付 $\text{mn}$），再 $\text{mn}\leftrightarrow b$（付 $\text{mn}$），$\text{mn}$ 原位往返、净效果等同于 $a\leftrightarrow b$，合计 $2\,\text{mn}$。于是**每对盈余的成本封顶**：

$$\text{cost}(a,b)=\min\big(\min(a,b),\;2\,\text{mn}\big)$$

### 3.3 算法流程

![算法流程：差值统计 → 奇偶检查（含只在 b2 出现的值）→ 收集盈余 → 合并排序取最小 m 个 → 各封顶 2mn 求和](images/fruits_331_algorithm_flow.svg)

1. 哈希表统计差值 $\text{diff}[v]=c_1[v]-c_2[v]$；
2. 任一 $\text{diff}[v]$ 为奇数 → 返回 $-1$；
3. 每个值 $v$ 放 $\lvert\text{diff}[v]\rvert/2$ 份进盈余列表，共 $2m$ 个，排序；
4. 取最小的 $m$ 个，$\text{ans}=\sum\min(x,\,2\,\text{mn})$，$\text{mn}=\min(\text{两篮全体})$。

「合并取最小 $m$ 个」与「$d_1$ 升序配 $d_2$ 降序」两种写法等价：反向配对时每对的被付较小值恰为最小的 $m$ 个盈余（被付集合相同，见 §5 引理 4 的构造性讨论）。

### 3.4 示例演算

![示例演算：示例 1 走查频差表与配对成本；自造示例对比直接交换 100 与中介摆渡 2](images/fruits_331_walkthrough.svg)

**示例 1**：$[4,2,2,2]$ 对 $[1,4,1,2]$：

| 值 $v$ | $c_1$ | $c_2$ | $\text{diff}$ | 盈余归属 |
|--------|-------|-------|---------------|----------|
| 1 | 0 | 2 | $-2$ | $E_2$ 加 1 个 1 |
| 2 | 3 | 1 | $+2$ | $E_1$ 加 1 个 2 |
| 4 | 1 | 1 | $0$ | 平衡，不动 |

$\text{diff}$ 全偶 ✓。盈余排序 $=[1,2]$，$m=1$，$\text{mn}=1$。最小 1 个：$x_1=1$，成本 $\min(1,\,2\times1)=1$ ✓。

**自造示例 3**：$[1,1,100,100]$ 对 $[1,1,200,200]$：值 1 平衡，$E_1=\{100\}$、$E_2=\{200\}$，$m=1$，$\text{mn}=1$。成本 $=\min(\min(100,200),\,2)=\min(100,2)=2$ ✓——中介封顶正是为这种「大值对大值」的局面准备的。

## 4. 算法细节

1. **差值表一次成型**：`Counter(basket1)` 后 `subtract(Counter(basket2))`（或 C++ 里一遍 `++` 一遍 `--`），直接得到 $\text{diff}[v]=c_1[v]-c_2[v]$。奇偶检查**遍历差值表的全部键**，天然覆盖只在单侧出现的值。
2. **为什么放 $\lvert\text{diff}[v]\rvert/2$ 份**：篮 1 多出 $d$ 份时，只有 $d/2$ 份需要物理送走——另外 $d/2$ 份的「缺口」由篮 2 送来的水果补上。两侧盈余份数自动相等（$\sum_v \text{diff}[v]=0$），无需断言。
3. **取最小的 $m$ 个**：对合并列表排序后取前 $m$ 个即可，不必真的构造配对。若偏爱显式配对：$d_1$ 升序、$d_2$ 降序，第 $i$ 对付 $\min(\min(d_1[i],d_2[m-1-i]),\,2\,\text{mn})$，逐对求和与合并写法**逐项相同**。
4. **$\text{mn}$ 取两篮全局最小**：摆渡的水果可以是**任何**水果，包括频次平衡、本不需要搬家的——示例 3 里摆渡的 1 就是平衡值。只在盈余列表里找最小值是错误变体。
5. **封顶是逐对的，不是全局的**：$2\,\text{mn}$ 封的是**每一对**的成本上限（一次摆渡 = 两次交换），不是对总成本乘什么系数。
6. **溢出**：总成本上界 $\approx 2m\cdot\text{mn}\le 2\times10^5\times10^9=2\times10^{14}$，C++ 必须 `long long` 累加与返回；$2\times\text{mn}$ 在 $\text{mn}\approx10^9$ 时已超 `int`，先转 64 位再乘。

## 5. 正确性证明

**记号**：终态两篮相等且总数不变，故每篮必含 $\text{target}[v]=\text{cnt}[v]/2$ 个 $v$。$E_1$：篮 1 中需净移出的水果（每个 $v$ 放 $\max(0, c_1[v]-\text{target}[v])$ 份），$E_2$ 对称；$|E_1|=|E_2|=m$，$S=E_1\uplus E_2$ 共 $2m$ 个，排序 $x_1\le\cdots\le x_{2m}$；$\text{mn}$ 为两篮全体水果的最小值。

**引理 1（可行性）**：存在方案使两篮相等 $\iff$ 每个 $v$ 的 $\text{cnt}[v]$ 为偶数。

**证明**：（⇒）终态各篮含 $t_v$ 个 $v$，则 $\text{cnt}[v]=2t_v$ 为偶。（⇐）全偶时按 §5 定理的构造配对并逐对交换：每次交换使两篮各向 target 靠近一个单位，$m$ 次后每篮各值频次均为 target，两篮相等。∎

**引理 2（交叉分解）**：任取一个达成相等的方案。设第 $t$ 次交换把值 $\alpha_t$ 的水果从篮 1 移到篮 2、把值 $\beta_t$ 的从篮 2 移到篮 1，记多重集 $A=\{\alpha_t\}$、$B=\{\beta_t\}$。则存在多重集 $X$（"摆渡交叉"）使 $A=E_1\uplus X$、$B=E_2\uplus X$；且总成本 $C=\sum_t\min(\alpha_t,\beta_t)$，即 $A,B$ 间一个完美匹配（方案本身）的边权和，权为两端较小值。

**证明**：值 $v$ 的净交叉数（篮 1→篮 2 计 $+1$，反向计 $-1$）等于其频次净变化 $c_1[v]-\text{target}[v]=e_1[v]-e_2[v]$（$e_i[v]$ 为 $E_i$ 中 $v$ 的份数）。设 $a_v,b_v$ 为 $v$ 在 $A,B$ 中的次数，则 $a_v-b_v=e_1[v]-e_2[v]$；由 $b_v\ge0$ 得 $a_v\ge e_1[v]$，由 $a_v\ge0$ 得 $b_v\ge e_2[v]$。令 $\xi_v=a_v-e_1[v]=b_v-e_2[v]\ge0$，$X$ 每值 $v$ 取 $\xi_v$ 份即得分解。每次交换恰把一个 $A$ 元素与一个 $B$ 元素配对并付 $\min$。∎

**引理 3（链式不等式）**：对任意正值 $u,s,w$：$\min(u,s)+\min(s,w)\ \ge\ \min(u,w,2s)$。进而，任意链 $u\to v_1\to\cdots\to v_k\to w$ 的配对成本 $\min(u,v_1)+\sum_i\min(v_i,v_{i+1})+\min(v_k,w)\ \ge\ \min\big(\min(u,w),\ 2\min_i v_i\big)$。

**证明**：三项情形按 $s$ 与 $u,w$ 的大小分三类：$s\le\min(u,w)$ 时左边 $=2s$；$s\ge\max(u,w)$ 时左边 $=u+w\ge\min(u,w)$；$u\le s\le w$（或对称）时左边 $=u+s\ge u$。三类均不小于右边。链情形：设 $s=v_j$ 为链上最小值。**前半段**（$u$ 到 $v_j$）成本 $\ge\min(u,s)$：若 $u\le s$ 则 $v_1\ge s\ge u$，首项 $\min(u,v_1)=u$；若 $u>s$ 则含 $v_j$ 的项 $\min(v_{j-1},v_j)=s$（$j=1$ 时首项 $\min(u,s)=s$）。**后半段**（$v_j$ 到 $w$）对称地 $\ge\min(w,s)$。两段相加再用三项情形。∎

**引理 4（匹配下界）**：对 $E_1,E_2$ 间任意完美匹配 $\mu$：$\sum_{(u,w)\in\mu}\min\big(\min(u,w),2\,\text{mn}\big)\ \ge\ \sum_{i=1}^{m}\min(x_i,2\,\text{mn})$。

**证明**：把 $\mu$ 每对的被付较小值排成 $m_{(1)}\le\cdots\le m_{(m)}$（互不相同的 $S$ 中元素）。若 $m_{(i)}<x_i$，则 $m_{(1)},\dots,m_{(i)}$ 是 $i$ 个都严格小于 $x_i$ 的不同元素，而 $S$ 中严格小于 $x_i$ 者至多 $i-1$ 个（$x_i$ 是第 $i$ 小），矛盾。故 $m_{(i)}\ge x_i$ 逐项成立；$t\mapsto\min(t,2\,\text{mn})$ 单调不减，逐项相加即得。∎

**定理**：最小总成本 $=\displaystyle\sum_{i=1}^{m}\min(x_i,\,2\,\text{mn})$。

**证明**：

（**上界 / 构造**）$S$ 的 $m$ 个最小元素中设 $s$ 个来自 $E_1$、$m-s$ 个来自 $E_2$，则 $m$ 个最大元素中恰有 $m-s$ 个来自 $E_1$、$s$ 个来自 $E_2$（计数守恒）。把「小的 $E_1$」配「大的 $E_2$」、「小的 $E_2$」配「大的 $E_1$」，得完美匹配且每对被付较小值恰为 $x_1,\dots,x_m$。每对 $(u,w)$ 二选一：直接交换付 $\min(u,w)=x_i$；或任取一个值为 $\text{mn}$ 的水果摆渡（先 $u\leftrightarrow\text{mn}$ 再 $\text{mn}\leftrightarrow w$，两次各付 $\text{mn}$、$\text{mn}$ 原位往返）付 $2\,\text{mn}$。每对成本 $\min(x_i,2\,\text{mn})$，合计即上界。

（**下界**）任取方案，由引理 2 得 $A=E_1\uplus X$、$B=E_2\uplus X$ 及其上的交换匹配。把 $X$ 的篮 1→篮 2 交叉与篮 2→篮 1 交叉**按同值**两两连接（每值两侧份数同为 $\xi_v$），与交换匹配一起构成图 $\Gamma$：交换边与连接边都连接「A 侧元素 ↔ B 侧元素」，且 $E_1,E_2$ 元素度数为 1、$X$ 元素度数为 2。故 $\Gamma$ 分解为 $m$ 条 $E_1\to E_2$ 的链与若干纯 $X$ 环；环上交换成本非负，弃之只会更低。每条链形如 $u\to v_1\to\cdots\to v_k\to w$（$u\in E_1$，$w\in E_2$，链上相邻两项恰为一次交换、连接边同值保证摆渡值一致），由引理 3 其交换成本之和 $\ge\min(\min(u,w),\,2\min_i v_i)\ge\min(\min(u,w),\,2\,\text{mn})$。$m$ 条链在 $E_1,E_2$ 间诱导完美匹配，再由引理 4：$C\ge\sum_{i=1}^m\min(x_i,2\,\text{mn})$。∎

> 💡 **证明的三个层次恰好对应三招**：引理 1 给出 $-1$ 判定；引理 2 把任意方案「翻译」成盈余 + 摆渡的匹配结构——这是把自由方案规约成可分析对象的关键一步；引理 3 的三项不等式 $\min(u,s)+\min(s,w)\ge\min(u,w,2s)$ 正是「摆渡不亏」的代数化身；引理 4 说明无论怎么配，被付集合的排序逐项被「最小 $m$ 个」压制。

## 6. 复杂度分析

- **时间复杂度**：$O(n\log n)$。哈希计数 $O(n)$；盈余列表至多 $2m\le 2n$ 个元素，排序 $O(m\log m)$；封顶求和 $O(m)$。瓶颈在排序，$n=10^5$ 毫秒级。
- **空间复杂度**：$O(n)$。差值哈希表与盈余列表合计不超过 $O(n)$。
- **对照暴力**：Dijkstra 的状态是「多重集合有序对」，数量天文级；贪心把「选哪 $m$ 次交换、怎么配」的结构一次性定型，只剩排序开销。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long minCost(vector<int>& basket1, vector<int>& basket2) {
        unordered_map<int, long long> diff;            // diff[v] = c1[v] - c2[v]
        for (int x : basket1) diff[x]++;
        for (int x : basket2) diff[x]--;

        vector<long long> toMove;                      // 2m 个盈余水果
        for (auto& [v, d] : diff) {
            if (d % 2 != 0) return -1;                 // 奇差：无法均分到两篮
            toMove.insert(toMove.end(), abs(d) / 2, v);
        }
        sort(toMove.begin(), toMove.end());

        long long mn = min(*min_element(basket1.begin(), basket1.end()),
                           *min_element(basket2.begin(), basket2.end()));
        long long m = (long long)toMove.size() / 2, ans = 0;
        for (long long i = 0; i < m; i++)              // 最小的 m 个各封顶 2*mn
            ans += min(toMove[i], 2 * mn);
        return ans;
    }
};
```

### Python

```python
class Solution:
    def minCost(self, basket1: List[int], basket2: List[int]) -> int:
        diff = Counter(basket1)
        diff.subtract(Counter(basket2))        # diff[v] = c1[v] - c2[v]
        to_move = []
        for v, d in diff.items():
            if d % 2:
                return -1                      # 奇差：无法均分到两篮
            to_move.extend([v] * (abs(d) // 2))
        to_move.sort()
        mn = min(min(basket1), min(basket2))
        m = len(to_move) // 2
        return sum(min(x, 2 * mn) for x in to_move[:m])
```

## 8. 边界情况与易错点

1. **必须 64 位**（C++）：总成本上界约 $2\times10^{14}$；且 $2\times\text{mn}$ 在 $\text{mn}\approx10^9$ 时单独就超 `int`，乘法前先落 `long long`。本场 Q1（累加和 $10^{12}$ 必须 `long long`）、Q3（全程 `int` 足够）与本题构成同一场周赛的「溢出梯度」——**看是计数比较还是累加求和再定类型**。
2. **奇偶检查要覆盖单侧值**：示例 2 的值 5 只在 basket2 出现，只遍历 `Counter(basket1)` 会漏判成「可行」。用差值表（合并遍历）天然安全。
3. **忘 $2\,\text{mn}$ 封顶 → 答案偏大**：自造示例 3 会输出 $100$ 而非 $2$。反之也不必「全部走中介」——$\min(x_i,2\,\text{mn})$ 逐对自动择优，示例 1 中 $\min(1,2)=1$ 就选了直接换。
4. **$\text{mn}$ 是两篮全局最小，不是盈余最小**：摆渡水果可以是频次平衡、无需搬家的水果（示例 3 摆渡的 1 就是平衡值）。
5. **「最小 $m$ 个」要合并两侧盈余再排序取**：写成「每侧各取一半」或只排一侧都会漏掉更小的被付者。喜欢显式配对就用反向配对 $d_1[i]\leftrightarrow d_2[m-1-i]$，被付集合与合并取法逐项一致。
6. **$m=0$（两篮本就相等）无需特判**：列表为空，循环不执行，天然返回 0（自造示例 4）。
7. **C++ 负数取模**：`(-3) % 2 == -1`，判 `d % 2 != 0` 恰好安全；若手滑写成 `d % 2 == 1` 会漏掉负奇差（差值为负的奇数），Python 无此坑（`(-3) % 2 == 1`）。
8. **$\text{mn}$ 本身是盈余水果时公式不变**：它与某大值配对时被付值就是 $\text{mn}\le 2\,\text{mn}$，自然走直接交换；其余对仍可用它摆渡（先做完摆渡再搬它自己，或利用摆渡对「$\text{mn}$ 在哪一侧都行」的对称性任意排序）。
9. **别把「交换成本」记成 $\max$ 或平均值**：题面是 $\min(\text{basket1}[i],\text{basket2}[j])$——只付较小者，这是「小配大」全部直觉的来源。
