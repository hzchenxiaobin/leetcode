# LeetCode 回环句 题解

## 1. 题目概述

- **标题 / 题号**：回环句（#2490，easy）
- **链接**：https://leetcode.cn/problems/circular-sentence/
- **来源**：LeetCode 第 322 场周赛 Q1
- **难度**：简单
- **标签**：字符串

**题意**：句子是由**单个空格**分隔的单词序列，不含前导或尾随空格。若满足：① 每个单词的**末字符**等于**下一单词的首字符**；② **最后一个单词的末字符**等于**第一个单词的首字符**，则称其为**回环句**。给定字符串 `sentence`，判断它是否为回环句，是则返回 `true`，否则返回 `false`。

**约束**：

- $1 \le \text{sentence.length} \le 500$
- `sentence` 仅由大小写英文字母和空格组成，**大小写视为不同字符**
- 单词由**单个**空格分隔，不含前导或尾随空格

> 💡 签到题先抓两个信号：① $n \le 500$，任何 $O(n)$ 做法都绰绰有余，比拼的是**从题面到代码的最短路径**；②「单个空格 + 无前后导空格」意味着**空格位置与相邻单词对的「缝」一一对应**——这是免 split 一趟扫描的关键。

## 2. 示例

**示例 1**

```text
输入：sentence = "leetcode exercises sound delightful"
输出：true
解释：单词为 [leetcode, exercises, sound, delightful]
      leetcode 尾 e = exercises 首 e
      exercises 尾 s = sound 首 s
      sound 尾 d = delightful 首 d
      delightful 尾 l = leetcode 首 l（环绕缝）
```

**示例 2**

```text
输入：sentence = "eetcode"
输出：true
解释：只有一个单词，末字符 'e' 与首字符 'e' 相等，环绕缝成立。
```

**示例 3**

```text
输入：sentence = "Leetcode is cool"
输出：false
解释：Leetcode 尾 'e' 与 is 首 'i' 不相等，第一条缝即失败。
```

## 3. 解题思路

### 3.1 朴素思路：split 成单词表逐对检查

按空格把 `sentence` 切成单词数组 `words`，逐对验证 `words[i]` 的末字符与 `words[i+1]` 的首字符相等，最后补上 `words` 末元素的末字符与首元素首字符的比对。时间 $O(n)$、空间 $O(n)$，对 $n \le 500$ 毫无压力，是周赛现场最稳的出手。

本题不存在「暴力会超时」的问题——优化空间只在**额外空间与代码长度**上。

### 3.2 核心观察：句子是一条「环」，缝的检查无需建表

![核心观察：首尾相接成环，每条缝两侧字符相等](images/wc322_q1_circular_ring.svg)

把首单词接到末单词之后，句子闭合成**环**：回环句的定义恰好是「**环上每条缝两侧的字符相等**」。而环上的缝落回线性串只有两类位置：

- **单词间的缝** = 一个**空格**。由「单个空格、无前后导空格」保证，空格 $s[i]$ 的左邻 $s[i-1]$ 必是前一单词的末字符，右邻 $s[i+1]$ 必是后一单词的首字符；
- **末词 → 首词的环绕缝** = 串的**两端**，即 $s[0]$ 与 $s[n-1]$。

于是「相邻单词检查」⇔「扫描每个空格处比对左右字符」，「环绕检查」⇔「比对串首与串尾」——一趟扫描即可，无需构造单词表。

### 3.3 算法流程

![一趟扫描：空格缝比对与首尾环绕缝比对](images/wc322_q1_scan_space.svg)

1. 扫描每个位置 $i$：若 $s[i]$ 是空格且 $s[i-1] \ne s[i+1]$，返回 `false`；
2. 扫描结束后返回 $s[0] = s[n-1]$ 的比对结果。

整个判定是**纯条件拼图**：不存在任何选择与搜索，任何一处失配即出局。

### 3.4 示例演算

以 `"ab ba"` 为例（见上图）：扫描到 $i=2$ 的空格时比对 $s[1]=$'b' 与 $s[3]=$'b'，相等放行；扫描结束比对 $s[0]=$'a' 与 $s[4]=$'a'，相等返回 `true`。

再看 `"Leetcode is cool"`：扫到空格处左右为 'e' 与 'i'，失配立即返回 `false`。构造一个只被环绕缝拦下的例子 `"eo oo"`：唯一的空格缝 'o'=='o' 通过，但 $s[0]=$'e' $\ne s[4]=$'o'，返回 `false`——**漏写环绕缝检查是本题最高频的 WA 点**。

## 4. 算法细节

1. **两版写法**：单扫版（§3.3）依赖「单个空格 + 无前后导空格」的题面保证；split 版天然兼容连续空格、前后导空格等更宽松的输入。本题题面锁死了前者，两版皆正确。
2. **C++ 单扫的区间选择**：空格只可能出现在 $[1, n-2]$，循环写成 `for (int i = 1; i + 1 < n; ++i)`，从根源上排除 `s[i-1]`、`s[i+1]` 越界的可能。
3. **Python 的 `split()`**：无参 `split()` 按任意空白切分并自动丢弃空串，`zip(words, words[1:])` 逐对取相邻单词；$n \ge 1$ 且无前导空格保证 `words` 非空。
4. **大小写敏感**：'L' 与 'e'、'A' 与 'a' 都是不同字符，切勿做 `lower()` 归一化。

## 5. 正确性证明

**引理（缝与判定的等价性）**：`sentence` 是回环句，当且仅当所有空格位置 $i$ 满足 $s[i-1] = s[i+1]$，且 $s[0] = s[n-1]$。

**证明**：由约束「单词由单个空格分隔、不含前后导空格」，空格位置的集合与「相邻单词对」一一对应，且每个空格 $s[i]$ 满足 $1 \le i \le n-2$：$s[i-1]$ 是前一单词的末字符，$s[i+1]$ 是后一单词的首字符。故定义中的条件 ①（每个单词末字符等于下一单词首字符）等价于逐空格检查 $s[i-1] = s[i+1]$。又 $s[0]$ 是首单词的首字符、$s[n-1]$ 是末单词的末字符，条件 ② 等价于 $s[0] = s[n-1]$。∎

**定理（算法正确性）**：算法返回 `true` 当且仅当 `sentence` 是回环句。

**证明**：算法在发现任一空格缝失配时返回 `false`；否则以 $s[0] = s[n-1]$ 的比对结果作为返回值。由引理，这两组条件合起来恰为回环句的充要定义。∎

> 💡 **一句话**：判定类签到题的正确性往往就藏在「约束 ⇔ 检查项」的一一对应里——把题面约束翻译成等价检查，证明即完成。

## 6. 复杂度分析

- **时间复杂度**：$O(n)$，单趟扫描，$n \le 500$ 远离任何上限。
- **空间复杂度**：单扫版 $O(1)$，仅常数个下标与字符比较；split 版 $O(n)$ 存单词表，$n \le 500$ 时可忽略。
- **实战取舍**：周赛现场 Python 一行 `split` + `zip` 最快出手；C++ 单扫版最省内存、代码同样短，两者任选。

## 7. 参考代码

### C++（单趟扫描）

```cpp
class Solution {
public:
    bool isCircularSentence(string sentence) {
        int n = sentence.size();
        for (int i = 1; i + 1 < n; ++i)
            if (sentence[i] == ' ' && sentence[i - 1] != sentence[i + 1])
                return false;
        return sentence[0] == sentence[n - 1];
    }
};
```

### Python（split + zip）

```python
class Solution:
    def isCircularSentence(self, sentence: str) -> bool:
        words = sentence.split()
        return all(w[-1] == nw[0] for w, nw in zip(words, words[1:])) \
            and words[-1][-1] == words[0][0]
```

## 8. 边界情况与易错点

1. **单个单词（无空格）**：循环完全不触发，判定全靠 $s[0] = s[n-1]$。`"eetcode"` → `true`，`"Leetcode"` → `false`（'L' ≠ 'e'）。
2. **漏掉环绕缝检查（最高频 WA）**：只查相邻单词会放过 `"eo oo"` 这类「相邻全过、首尾不符」的串，收尾的 $s[0] = s[n-1]$ 不可省。
3. **大小写敏感**：题面明确大小写视为不同字符，`'A' != 'a'`；做了 `lower()` 反而出错。
4. **空格位置越界**：C++ 单扫版若把循环从 $i = 0$ 起写 `sentence[i-1]`，就依赖短路求值与「无前导空格」的题面保证；写成 $i \in [1, n-2]$ 更防御。
5. **`words` 非空**：$n \ge 1$ 且无前导空格保证 split 后至少一个单词，`words[0]`、`words[-1]` 访问安全。
6. **别做多余预处理**：无需 trim、无需合并空格——题面已保证输入格式规整，签到题反而要克制「顺手加固」的冲动，少一行少一个错。
