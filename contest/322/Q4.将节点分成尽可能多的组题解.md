# LeetCode 将节点分成尽可能多的组 题解

## 1. 题目概述

- **标题 / 题号**：将节点分成尽可能多的组（#2493，hard）
- **链接**：https://leetcode.cn/problems/divide-nodes-into-the-maximum-number-of-groups/
- **来源**：LeetCode 第 322 场周赛 Q4
- **难度**：困难
- **标签**：图、广度优先搜索、连通分量、二分图判定、直径

**题意**：给定 $n$ 个节点（编号 $1\sim n$）的无向图 `edges`（**可能不连通**，无自环无重边）。把所有节点划分为 $m$ 个组（组号从 $1$ 开始），要求：

- 每个节点恰好属于一个组；
- 对每条边 $[a_i, b_i]$：设两端所在组号为 $x$、$y$，则 $|y - x| = 1$（两端组号**必须相邻**）。

返回**最大的** $m$；无法分组返回 $-1$。

**约束**：

- $1 \le n \le 500$，$1 \le \text{edges.length} \le 10^4$
- $1 \le a_i, b_i \le n$，$a_i \ne b_i$，两点之间至多一条边

> 💡 **读题抓一个信号**：$|y-x|=1$ 说明沿任何一条边，组号**必变**且**只能变 1**——既不能原地踏步（同组），也不能跳级（差 2）。于是 $g(v) \bmod 2$ 沿每条边必翻转，天然是一张二着色；这张图**必须是二分图**，否则直接 $-1$。$n \le 500$ 则暗示「枚举所有源点跑 BFS」的 $O(n(n+E))$ 是预期复杂度。

> 💡 本题另有[每日题解 2493](../../solution/2401-2500/2493_将节点分成尽可能多的组.md)：主推「三句话总览」与面试问答。本篇按周赛复盘视角展开，侧重**组号连续性、直径上界、多分量求和**的完整引理-定理证明，以及「答案求和不是取最大」「两次 BFS 求直径失效」等赛时翻车点，两篇互为印证。

## 2. 示例

**示例 1**

```text
输入：n = 6, edges = [[1,2],[1,4],[1,5],[2,6],[2,3],[4,6]]
输出：4
解释：组 1={5}，组 2={1}，组 3={2,4}，组 4={3,6}。
     每条边两端组号差恰为 1（含非树边 4-6：|3−2|=1）。
```

**示例 2**

```text
输入：n = 3, edges = [[1,2],[2,3],[3,1]]
输出：-1
解释：1-2-3 是三角形（奇环）。设 g₁=1，则边(1,2) 逼 g₂=2；
     边(1,3) 逼 g₃=2，边(2,3) 却逼 g₃∈{1,3}，无交集 ⇒ 无解。
```

**示例 3（自制：多连通分量求和）**

```text
输入：n = 7, edges = [[1,2],[1,3],[1,4],[1,5],[6,7]]
输出：5
解释：分量 A 是 5 个点的星形（直径 2 → 3 组），分量 B 是一条边（直径 1 → 2 组），
     3 + 2 = 5 < n = 7。一种方案：组1={2}，组2={1}，组3={3,4,5}，组4={6}，组5={7}。
     关键：答案按分量**相加**——若误取各分量最大值，只会得到 3。
```

## 3. 解题思路

### 3.1 暴力思路：枚举组号赋值

朴素做法是枚举所有赋值 $g: V \to \{1,\dots,n\}$（共 $n^n$ 种），逐条边检查 $|g(u)-g(v)|=1$，取合法赋值中互异组号数的最大值。$n=500$ 时 $500^{500}$ 天文数字，完全不可行。

**转化方向**：与其「猜一个赋值再验证」，不如先问两个结构化问题——**什么时候有解？**（判定）与**有解时合法分组长什么样？**（刻画）。前者一步奇环判定解决；后者会发现合法分组有无穷多，且「BFS 分层」一定是其中之一，问题随之塌缩成纯几何量：**直径**。

### 3.2 核心观察：二分判定 + BFS 分层 + 直径上界

![核心观察：奇环无解；二分图的 BFS 分层天然合法](images/wc322_q4_bipartite_layering_concept.svg)

**① 必要性——图必须是二分图**。对每条边 $|g(u)-g(v)|=1$，故 $g \bmod 2$ 沿边必翻转，是合法二着色 ⟹ 图二分 ⟹ 无奇环。否则（示例 2 的三角形）返回 $-1$。判定用 [785 式](https://leetcode.cn/problems/is-graph-bipartite/)二着色 BFS，顺手收集连通分量。

**② 合法性——二分图的 BFS 分层天然合法**。任取源点 $s$，令 $g(v)=\text{dist}(s,v)$（组号即距离，整体 $+1$ 后从 1 开始）。对任意边 $(u,v)$：

- **距离差 $\le 1$**：最短路的三角不等式 $\text{dist}(s,v) \le \text{dist}(s,u)+1$（反之亦然）；
- **距离差是奇数**：二着色下任何走道每步换色，故 $\text{dist}(s,x) \bmod 2$ 由 $x$ 的颜色决定；边两端异色 ⟹ 两端距离**奇偶不同**。

$\{0,\pm1\}$ 中唯一的奇数是 $\pm1$，故差**恰为 1** ✓。这就是「夹逼」：两个弱条件合起来逼出恰好 1。

> 💡 **关键洞察**：合法性**不挑源点**——二分图里从**任何**节点出发的 BFS 分层都是合法分组。于是合法分组取之不尽，问题只剩「哪个源点分层最深」。

**③ 最值——每个连通分量的最大组数 = 直径 + 1**。上界：任意合法分组里，组号差沿路径每步只能 $\pm1$，故两点组号差 $\le$ 其距离 $\le$ 分量直径，于是组数 $\le \text{直径}+1$（引理 3 给出完整论证）。可达：取**直径端点** $s$ 为源，BFS 最深层恰为直径，组数 $= \text{直径}+1$ 顶到上界。

**④ 不连通——各分量独立求和**。分量之间没有边，$|y-x|=1$ 只约束同分量的点；把每个分量的分层各自**平移**到互不重叠的组号段再拼接即可。总组数 $=\sum$ 各分量（直径 $+1$）——是**求和**不是取最大（示例 3：$3+2=5$）。

### 3.3 算法流程

![算法流程：阶段一二着色判定，阶段二逐分量枚举源点求直径](images/wc322_q4_algorithm_flow.svg)

两阶段：

1. **阶段一（判定 + 收集）**：对每个未染色节点发起 BFS 交替染 `0/1`，边扫边查——一旦出现「同色相邻」即发现奇环，返回 `-1`；否则该次 BFS 访问到的节点构成一个连通分量，收进 `comps`。
2. **阶段二（求直径）**：对每个分量 `C`，枚举**分量内**每个源点 $s$ 跑 BFS 取最大深度，分量内取最大得 `best`（即直径），`ans += best + 1`。

### 3.4 示例演算

![示例 1 演算：枚举源点，最深 BFS 层 = 直径](images/wc322_q4_example_walkthrough.svg)

以示例 1（$n=6$）为例：

**阶段一**：从节点 1 发起二着色 BFS——$1$ 染 `0`；$2,4,5$ 染 `1`；$6,3$ 染 `0`。逐边核验两端异色全部通过（含非树边 $4\text{-}6$：`1` vs `0` ✓），无奇环，且 6 个点全在同一连通分量。

**阶段二**：枚举全部 6 个源点的 BFS 深度：

| 源 $s$ | BFS 深度 | 组数 = 深度+1 |
|--------|----------|--------------|
| 1 | 2 | 3 |
| 2 | 2 | 3 |
| 3 | 3 | **4** ✓ |
| 4 | 3 | **4** ✓ |
| 5 | 3 | **4** ✓ |
| 6 | 3 | **4** ✓ |

`best = 3`，`ans = 3 + 1 = 4`。以 $s=5$ 为例：组 $1=\{5\}$，组 $2=\{1\}$，组 $3=\{2,4\}$，组 $4=\{3,6\}$，6 条边两端距离差全为 1（非树边 $4\text{-}6$：$|2-3|=1$ ✓）。注意源 $1$、$2$ 给出的 3 组**同样合法**——合法不挑源，只是没顶到上界；而 $3,4,5,6$ 都是直径端点（$\text{dist}(5,3)=\text{dist}(5,6)=\text{dist}(3,4)=3$），深度恰为直径。

示例 3 走同套流程：阶段一得到两个分量 $\{1,2,3,4,5\}$ 与 $\{6,7\}$（均二分）；阶段二分量 A 枚举 5 个源点得 `best=2`（星形的中心与叶子距离 1，两片叶子距离 2），分量 B 得 `best=1`，`ans = 3 + 2 = 5`。

## 4. 算法细节

1. **编号统一**：内部转 `0-indexed`（`g[e[0]-1]` / `g[e[1]-1]`），输出时组数与编号无关，省去边界心智。
2. **阶段一一次 BFS 干三件事**：判二分（同色相邻即奇环）、收集连通分量、隐式确认「每个分量都可分层」。不要再为收集分量单独跑一遍遍历，两套 `vis` 容易不同步。
3. **阶段二的源点必须枚举分量内节点**（`for s in comp`）：BFS 本就出不了分量，但若误写成全局枚举，`best` 会被**其他分量**的直径污染——分量 A 直径 1、分量 B 直径 3 时，A 的 `best` 也会被刷成 3，答案从 $2+4=6$ 错成 $4+4=8$。
4. **`dist` 数组复用**：每次 BFS 前 `fill(-1)` 重置，$n$ 次重置合计 $O(n^2)=2.5\times10^5$，可忽略；不必上时间戳技巧。
5. **组号偏移**：距离从 0 起、组号从 1 起，组数 $=$ 深度 $+1$；「每分量贡献 $\text{best}+1$」这 $+1$ 别丢。
6. **直径 = $\max_s \text{ecc}(s)$**：即「枚举每个源点取最大 BFS 深度，再取最大」。树的「两次 BFS 找直径」技巧**对一般图不成立**（依赖「无环」性质），本题图含偶环（示例 1 就有四边形 $1\text{-}2\text{-}6\text{-}4$），必须老实枚举所有源点——$n \le 500$ 正是为此设计的规模。
7. **无需去重边/自环**：题面保证 $a_i \ne b_i$ 且无重边；若数据放宽出现自环，$|y-x|=1$ 无解，直接 $-1$。

## 5. 正确性证明

以下把「合法分组」记为函数 $g: V \to \mathbb{Z}^+$，满足每条边 $|g(u)-g(v)|=1$；$\text{diam}(C)$ 为连通分量 $C$ 的直径（最远两点距离）。

**引理 1（可分组 ⟹ 二分图）**：若存在合法分组，则每个连通分量都是二分图。

**证明**：令 $h(v)=g(v)\bmod 2$。任一边 $(u,v)$：$|g(u)-g(v)|=1$ 为奇数 ⟹ $h(u) \ne h(v)$。故 $h$ 是合法二着色，图二分。∎

**引理 2（BFS 分层的合法性）**：图二分时，任取 $s\in V$，$g(v)=\text{dist}(s,v)$ 满足：对每条边 $(u,v)$，$|\text{dist}(s,u)-\text{dist}(s,v)|=1$。

**证明**：任取边 $(u,v)$。
(i) $s\to u$ 的最短路再接一步 $(u,v)$ 是 $s\to v$ 的一条走道，故 $\text{dist}(s,v)\le \text{dist}(s,u)+1$；对称得 $|\text{dist}(s,u)-\text{dist}(s,v)|\le 1$。
(ii) 取二着色 $c:V\to\{0,1\}$。任何从 $s$ 到 $x$ 的走道每步切换 $c$ 的取值，故其长度 $\equiv c(x)\oplus c(s) \pmod 2$；最短路也是走道，故 $\text{dist}(s,x) \equiv c(x)\oplus c(s) \pmod 2$。边两端 $c(u)\ne c(v)$ ⟹ $\text{dist}(s,u)$ 与 $\text{dist}(s,v)$ 奇偶不同，差为奇数。
综合 (i)(ii)：差 $\in\{-1,0,1\}$ 且为奇数 ⟹ 差 $=\pm 1$，绝对值恰为 $1$。∎

**引理 3（组号连续 + 上界）**：若连通分量 $C$ 存在合法分组 $g$，则 $C$ 使用的组号集合是一段**连续区间**，且使用的组数 $\le \text{diam}(C)+1$。

**证明**：设 $x=\min_C g$、$y=\max_C g$，分别在 $u,v$ 处取得。$C$ 连通，取 $u$ 到 $v$ 的最短路 $u=w_0,w_1,\dots,w_k=v$（$k=\text{dist}(u,v)\le \text{diam}(C)$）。每步 $|g(w_{i+1})-g(w_i)|=1$，序列 $g(w_0),\dots,g(w_k)$ 从 $x$ 出发以 $\pm1$ 步到达 $y$，必经过 $[x,y]$ 内每个整数（离散介值定理）⟹ $C$ 使用的组号恰为 $\{x,\dots,y\}$，组数 $=y-x+1$。又
$$|y-x|=\Big|\sum_{i=0}^{k-1}\big(g(w_{i+1})-g(w_i)\big)\Big|\le k\le \text{diam}(C),$$
故组数 $=y-x+1\le \text{diam}(C)+1$。∎

**引理 4（可达性）**：图二分时，对每个连通分量 $C$，取 $s$ 为该分量直径端点（$\max_{v\in C}\text{dist}(s,v)=\text{diam}(C)$），则 $g(v)=\text{dist}(s,v)+1$ 是 $C$ 上使用恰 $\text{diam}(C)+1$ 个组的合法分组。

**证明**：由引理 2 合法（组号平移不影响边上的差）。最深层为 $\text{ecc}(s)=\text{diam}(C)$，故使用组号 $\{1,\dots,\text{diam}(C)+1\}$，恰 $\text{diam}(C)+1$ 个。∎

**定理**：存在合法分组 $\Leftrightarrow$ 每个连通分量都是二分图；此时最大组数

$$m^{*}=\sum_{C}\big(\text{diam}(C)+1\big).$$

**证明**：(⟸) 图二分时，对每个分量按引理 4 独立分层；分量之间没有边，$|y-x|=1$ 的约束只作用于分量内部的点，故把各分量组号整体平移到**互不重叠**的区间后拼接，得到全局合法分组，总组数为 $\sum(\text{diam}+1)$。
(⟹) 引理 1。
(最优性) 任取合法分组 $g$，其总组数 $m$ 是**全局互异组号**的个数。全局使用集合是各分量使用集合的并，而**并的大小不超过大小之和**，故 $m \le \sum_C |C\text{ 使用的组号}| \le \sum_C (\text{diam}(C)+1)$（末步用引理 3）。结合 (⟸) 的构造，$m^{*}=\sum_C(\text{diam}(C)+1)$。∎

> 💡 **两点澄清**（赛时容易含糊的地方）：① **合法分组远不止 BFS 分层**——星形分量的叶子可以任意分放在中心两侧的组里，那不是任何源点的分层；但求**最大**组数只需盯住「直径端点为源」的分层，因为引理 3 的上界对一切合法分组生效。② **不同分量本可以共用组号**（无约束），但共用只会让互异组号变少；最优解一定让各分量占满互不重叠的区间，所以「求和」既是对的也是紧的。

## 6. 复杂度分析

- **时间复杂度**：$O\big(n(n+E)\big)$。阶段一二着色一遍 $O(n+E)$；阶段二对每个源点做一次 BFS，分量 $C$ 内 $|C|$ 次各 $O(|C|+E_C)$，对所有分量求和 $\le n$ 次 BFS $\times\ O(n+E)$。$n=500$、$E=10^4$ 时约 $5\times10^6$，远低于时限。
- **空间复杂度**：$O(n+E)$。邻接表存 $2E$ 条有向边，`color`/`dist`/队列/分量列表各 $O(n)$。
- **规模设计**：一般图求直径没有低于 $O(n(n+E))$ 的简单精确算法（两次 BFS 仅对树成立），故 $n\le 500$ 是刻意放行的规模；若 $n\sim10^5$ 且图是树，可退化为两次 BFS 的 $O(n+E)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int magnificentSets(int n, vector<vector<int>>& edges) {
        vector<vector<int>> g(n);
        for (auto& e : edges) {
            g[e[0] - 1].push_back(e[1] - 1);
            g[e[1] - 1].push_back(e[0] - 1);
        }

        vector<int> color(n, -1);
        vector<vector<int>> comps;

        auto collect = [&](int start) -> bool {
            queue<int> q;
            q.push(start);
            color[start] = 0;
            vector<int> comp{start};
            while (!q.empty()) {
                int u = q.front(); q.pop();
                for (int v : g[u]) {
                    if (color[v] == -1) {
                        color[v] = color[u] ^ 1;
                        q.push(v);
                        comp.push_back(v);
                    } else if (color[v] == color[u]) {
                        return false;            // 同色相邻 = 奇环
                    }
                }
            }
            comps.push_back(move(comp));
            return true;
        };
        for (int i = 0; i < n; ++i)
            if (color[i] == -1 && !collect(i)) return -1;

        vector<int> dist(n);
        auto bfsDepth = [&](int s) -> int {
            fill(dist.begin(), dist.end(), -1);
            queue<int> q;
            dist[s] = 0;
            q.push(s);
            int depth = 0;
            while (!q.empty()) {
                int u = q.front(); q.pop();
                for (int v : g[u]) {
                    if (dist[v] == -1) {
                        dist[v] = dist[u] + 1;
                        depth = max(depth, dist[v]);
                        q.push(v);
                    }
                }
            }
            return depth;
        };

        int ans = 0;
        for (auto& comp : comps) {
            int best = 0;
            for (int s : comp) best = max(best, bfsDepth(s));
            ans += best + 1;
        }
        return ans;
    }
};
```

### Python

```python
from collections import deque

class Solution:
    def magnificentSets(self, n: int, edges: List[List[int]]) -> int:
        g = [[] for _ in range(n)]
        for a, b in edges:
            g[a - 1].append(b - 1)
            g[b - 1].append(a - 1)

        color = [-1] * n
        comps = []

        def collect(start):
            color[start] = 0
            comp = [start]
            q = deque([start])
            while q:
                u = q.popleft()
                for v in g[u]:
                    if color[v] == -1:
                        color[v] = color[u] ^ 1
                        q.append(v)
                        comp.append(v)
                    elif color[v] == color[u]:
                        return False            # 同色相邻 = 奇环
            comps.append(comp)
            return True

        for i in range(n):
            if color[i] == -1 and not collect(i):
                return -1

        def bfs_depth(s):
            dist = [-1] * n
            dist[s] = 0
            q = deque([s])
            depth = 0
            while q:
                u = q.popleft()
                for v in g[u]:
                    if dist[v] == -1:
                        dist[v] = dist[u] + 1
                        depth = max(depth, dist[v])
                        q.append(v)
            return depth

        ans = 0
        for comp in comps:
            best = max(bfs_depth(s) for s in comp)
            ans += best + 1
        return ans
```

## 8. 边界情况与易错点

1. **忘记判 $-1$（高频 WA）**：拿到图直接跑 BFS 求深度，奇环上会「算出一个答案」而不是报错。必须先做二着色判定（示例 2 的三角形是试金石），**顺序不能反**。
2. **多分量取最大而非求和（最高频 WA）**：示例 3 中答案 $3+2=5$，取各分量最大只得 $3$。分量间没有边、约束独立，各分量平移到不重叠组号段后拼接，组数是**加法**。
3. **两次 BFS 求直径（错误优化）**：「从任意点出发的最远点必是直径端点」只在**无环图**成立。示例 1 含四边形 $1\text{-}2\text{-}6\text{-}4$，两次 BFS 不保证命中真正的直径对。一般图必须枚举全部源点。
4. **源点全局枚举污染 `best`**：阶段二若把 `for s in comp` 写成 `for s in range(n)`，其他分量的直径会刷进本分量的 `best`，多分量时必然算多。
5. **$+1$ 丢失**：组数 $=$ 深度 $+1$ $=$ 直径 $+1$；「组号从 1 起、距离从 0 起」的错位最容易在最后一步丢 $+1$。
6. **孤立点**：自成一个分量、直径 0、贡献 1 组。$n=1$、`edges=[]` 答案 1；$n=6$ 只有一条边时答案 $2+1\times4=6$。阶段一的未染色循环天然覆盖，勿在阶段二跳过单点分量。
7. **组号连续性想当然**：有人会担心「组号留洞后组数怎么数」——引理 3 证明了同一分量使用的组号**必然连续**，无需特判；而**跨分量**共用组号合法但只会减少互异组号数，不影响「求和」的正确性。
8. **重置 `dist`**：复用数组时每次 BFS 前必须 `fill(-1)`；漏重置会把上一次 BFS 的访问标记带进来，深度偏小。

**延伸思考**：

- **输出具体分组方案**：本题只问最大组数；若要方案，记录每个分量取到 `best` 的源 $s^{*}$，令 $g(v)=\text{dist}(s^{*},v)+1$，再按分量顺序整体平移组号即可，代价仍是 $O(n(n+E))$。
- **规模放大后怎么办**：$n\sim10^5$ 的一般图上，$O(n(n+E))$ 的精确直径不可行，也没有已知简单精确替代（树可用两次 BFS，原因是其无环结构保证「任意点最远点必为直径端点」）；若题目保证是树/森林，本算法可整体换成两次 BFS 版，单分量 $O(n+E)$。
- **约束变体**：若把 $|y-x|=1$ 放宽为 $|y-x|\ge 1$（只要异组），每个点单独成组即合法，答案恒为 $n$，问题平凡化——对比之下可见「恰好 1」这个紧约束才是把问题推向二分图与直径的根源。
