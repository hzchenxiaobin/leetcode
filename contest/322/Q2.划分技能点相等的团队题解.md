# LeetCode 划分技能点相等的团队 题解

## 1. 题目概述

- **标题 / 题号**：划分技能点相等的团队（#2491，medium）
- **链接**：https://leetcode.cn/problems/divide-players-into-teams-of-equal-skill/
- **来源**：LeetCode 第 322 场周赛 Q2
- **难度**：中等
- **标签**：数组、排序、双指针、贪心

**题意**：给定长度为**偶数** $n$ 的正整数数组 `skill`，把 $n$ 名玩家分成 $n/2$ 个 **2 人团队**，要求每个团队的技能点**之和相等**。一个团队的「化学反应」定义为队内两人技能点的**乘积**。返回所有团队化学反应之和；若无法等和划分，返回 $-1$。

**约束**：

- $2 \le n \le 10^5$，且 $n$ 为偶数
- $1 \le \text{skill}[i] \le 1000$

> 💡 读题先抓两个信号：①「每队和相等」+ 队数固定 $\Rightarrow$ **目标和被总量唯一确定**，这是整除性与配对结构的来源；② $n \le 10^5$ 只允许 $O(n\log n)$ 以内的做法，$O(n^2)$ 起步的搜索直接放弃。

## 2. 示例

**示例 1**

```text
输入：skill = [3,2,5,1,3,4]
输出：22
解释：分成 3 队 (1,5)、(2,4)、(3,3)，每队技能点之和均为 6。
     化学反应 = 1×5 + 2×4 + 3×3 = 5 + 8 + 9 = 22。
```

**示例 2**

```text
输入：skill = [3,4]
输出：12
解释：只有一队 (3,4)，和为 7，化学反应 = 3×4 = 12。
```

**示例 3**

```text
输入：skill = [1,1,2,3]
输出：-1
解释：总和 7，需 2 队各和 3.5，非整数，无法等和划分。
```

## 3. 解题思路

### 3.1 暴力思路：枚举所有配对方案

把 $n$ 个人两两配对的方案数是 $(n-1)!!=(n-1)(n-3)\cdots1$，$n=10^5$ 时是天文数字，逐方案再验证「每队和相等」更是不可行。突破口在于认识到：**配对不是自由选择**——等和约束强到足以把配对方式唯一地「挤」出来，我们要做的是先推出它、再验证它。

### 3.2 核心观察：目标和唯一，排序后首尾配对

![核心观察：目标和唯一，排序后首尾配对](images/wc322_q2_pairing_concept.svg)

**第一步：先定目标。** $n/2$ 个队、每队和相等，设每队和为 $T$，则

$$
\frac{n}{2}\cdot T=\sum_i \text{skill}[i]=\text{total}
\quad\Longrightarrow\quad
T=\frac{\text{total}}{n/2}=\frac{2\cdot\text{total}}{n}
$$

$T$ **唯一确定**且必须为整数——`total` 不被 $n/2$ 整除时直接返回 $-1$，这是**第一道判定门**。

**第二步：配对被「锁死」。** 将数组升序排序后，**最小值必须配最大值**（§5 引理 2）：若 $a[0]$ 不与 $a[n-1]$ 同组，则「最小值所在队」与「最大值所在队」的和无法同时等于 $T$。剥掉 $(a[0],a[n-1])$ 后对剩余元素归纳，合法配对只剩**首尾配对**一种：$a[0]$ 配 $a[n-1]$、$a[1]$ 配 $a[n-2]$、……于是问题从「搜索配对方案」塌缩为「验证唯一方案」，双指针逐对验和即可。

### 3.3 算法流程：两道判定门

![算法流程：整除快门与逐对验和两道判定门](images/wc322_q2_two_gate_flow.svg)

- **第一道门（整除性）**：`total % (n/2) != 0` → 目标和非整数 → 无解，提前返回 $-1$；
- **第二道门（逐对验和）**：排序后双指针 $i=0$、$j=n-1$ 相向推进，任何一对 `a[i]+a[j] != target` → 无解；
- 两道门全过 → 答案就是各对乘积之和，全程不存在任何「选择」。

### 3.4 示例演算

![示例演算：排序后逐对验和累乘](images/wc322_q2_walkthrough.svg)

`skill=[3,2,5,1,3,4]`：`total=18`、`n/2=3`，整除通过，`target=6`；排序得 `[1,2,3,3,4,5]`，首尾配对 $(1,5)$、$(2,4)$、$(3,3)$ 的和均为 6，`ans = 5+8+9 = 22`。示例 3 的 `[1,1,2,3]` 则在第一道门即被挡下（$7\%2\ne0$）。

## 4. 算法细节

1. **目标计算**：`target = total / (n / 2)`，**不要写成** `total / n`（后者是「人均」技能点，差 2 倍）。先判 `total % (n / 2)` 再做除法。
2. **排序 + 双指针**：升序排序后，$i$ 从左端、$j$ 从右端相向推进，以 `i < j` 为循环条件；每轮验证 `a[i] + a[j] == target`，通过则 `ans += a[i] * a[j]`。
3. **溢出**：$n\le10^5$、$\text{skill}[i]\le1000$，`total ≤ 10^8` 未超 `int`，但 `ans ≤ (n/2)×1000² = 5×10^10` **远超 32 位 `int`**。C++ 中 `ans` 必须用 `long long`，乘积写 `(long long)skill[i] * skill[j]`，`accumulate` 初值用 `0LL`；Python 无此虑。
4. **免整除判定的等价写法**：排序后直接令 `target = a[0] + a[n-1]`（首对和），循环里只验和——若每对都等于首对和，「每队和相等」自动成立；若某对不等则返回 $-1$。省一个分支，但显式算 `total` 更能体现「目标和由总量唯一确定」的洞察。

## 5. 正确性证明

**引理 1（目标和唯一）**：若存在合法划分，则每队技能和均为 $T=\dfrac{2\cdot\text{total}}{n}$，且 $T$ 为整数。

**证明**：$n/2$ 个队每队和均为 $T$，求和得 $\dfrac{n}{2}\cdot T=\text{total}$，解出 $T=\dfrac{2\cdot\text{total}}{n}$。又技能点均为整数，队和 $T$ 必为整数，故 `total` 不被 $n/2$ 整除时无解。∎

**引理 2（最小必配最大）**：设升序数组 $a[0]\le\cdots\le a[n-1]$ 且存在合法划分，则 $a[0]$ 的搭档值必为最大值，$a[n-1]$ 的搭档值必为最小值。

**证明**：设合法划分中 $a[0]$ 与 $a[k]$ 同组、$a[n-1]$ 与 $a[j]$ 同组。由 $a[0]$ 是最小值、$a[n-1]$ 是最大值，有 $a[0]\le a[j]$ 且 $a[k]\le a[n-1]$，两式相加：

$$
\underbrace{a[0]+a[k]}_{=T}\;\le\;\underbrace{a[j]+a[n-1]}_{=T}
$$

两端都等于 $T$，故不等式必取等号，进而两个分量不等式同时取等：$a[0]=a[j]$ 且 $a[k]=a[n-1]$。即 $a[0]$ 的搭档值是最大值、$a[n-1]$ 的搭档值是最小值。∎

**定理（算法正确性）**：排序后首尾配对逐对验和全部通过，当且仅当存在合法划分；且答案若存在则唯一，为 $\sum_{i<n/2}a[i]\cdot a[n-1-i]$。

**证明**：

- **（充分性）** 若逐对验和全部通过，则每队和均为 $T$，构成合法划分；按题意求和即为返回值。
- **（必要性 + 唯一性）** 若存在合法划分，对 $n$ 归纳引用引理 2：$a[0]$ 与 $a[n-1]$（按值）同组，移除该对后剩余 $n-2$ 个元素仍构成每队和为 $T$ 的合法划分，归纳可得任何合法划分在**值的意义上**都与首尾配对相同。因此首尾配对验和必全过，且化学反应总和由这唯一配对决定，答案与划分方案无关。∎

> 💡 **一句话**：等和约束把配对自由度压到零——**目标和先被总量定死，配对再被极值定死**，剩下的只有 $O(n)$ 验证。

## 6. 复杂度分析

- **时间复杂度**：$O(n\log n)$，排序主导；求和、双指针验和累乘均为单趟 $O(n)$。
- **空间复杂度**：$O(\log n)$，仅排序递归栈；双指针原地推进，无额外数组。
- **可再优化**：值域 $U\le1000$ 极小，可用频次数组代替排序做到 $O(n+U)$，但需处理 $v=T-v$ 自配的偶数性与「只数一次」的去重，边界更多；周赛首选排序版，代码最短、最不易错。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long dividePlayers(vector<int>& skill) {
        int n = skill.size();
        sort(skill.begin(), skill.end());
        long long total = accumulate(skill.begin(), skill.end(), 0LL);
        if (total % (n / 2) != 0) return -1;              // 第一道门：整除性
        long long target = total / (n / 2);               // 每队目标和，唯一确定
        long long ans = 0;
        for (int i = 0, j = n - 1; i < j; ++i, --j) {
            if (skill[i] + skill[j] != target) return -1; // 第二道门：逐对验和
            ans += (long long)skill[i] * skill[j];
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def dividePlayers(self, skill: List[int]) -> int:
        n = len(skill)
        skill.sort()
        total = sum(skill)
        if total % (n // 2):
            return -1
        target = total // (n // 2)
        ans = 0
        i, j = 0, n - 1
        while i < j:
            if skill[i] + skill[j] != target:
                return -1
            ans += skill[i] * skill[j]
            i, j = i + 1, j - 1
        return ans
```

## 8. 边界情况与易错点

1. **`long long` 溢出（最高频 WA 点）**：`ans` 上界 $\frac{n}{2}\times1000^2=5\times10^{10}$，超 32 位 `int`（约 $2.1\times10^9$）。C++ 中 `ans`、`total`（`accumulate` 初值 `0LL`）都走 `long long`，乘积写 `(long long)skill[i] * skill[j]`；Python 无整数溢出问题。
2. **除数是 $n/2$ 不是 $n$**：`target = total / (n/2)`。写成 `total / n` 得到「人均」技能点，验和必然全错。
3. **最小规模 $n=2$**：只有一对，`total % 1 == 0` 恒成立，直接验首对并返回乘积。
4. **重复值**：证明全部按**值**进行（引理 2 中 $a[k]=a[n-1]$ 指值相等），排序后按下标配对自然处理，如示例 1 的两个 3 配成 $(3,3)$。
5. **全相同值**：如 `[5,5,5,5]`，`target=10`，首尾配对 $(5,5)$、$(5,5)$ 全过，返回 $25+25=50$。
6. **奇偶性不必特判**：题面保证 $n$ 为偶数；防御性可加 `if (n & 1) return -1;`，本题可省。
7. **两种 target 写法别都不用**：显式 `total / (n/2)` 与隐式「首对和作 target」等价（见 §4 第 4 点），但若两个都不做，循环里就没有目标可验。
