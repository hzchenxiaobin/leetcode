# LeetCode 两个城市间路径的最小分数 题解

## 1. 题目概述

- **标题 / 题号**：两个城市间路径的最小分数（#2492，medium）
- **链接**：https://leetcode.cn/problems/minimum-score-of-a-path-between-two-cities/
- **来源**：LeetCode 第 322 场周赛 Q3
- **难度**：中等
- **标签**：图、广度优先搜索、深度优先搜索、并查集、连通分量

**题意**：$n$ 座城市（编号 $1\sim n$）由 `roads` 给出的无向带权边连接，图**不一定连通**。一条路径（可以**重复经过同一条边、同一座城市**，即图论中的 walk）的「分数」定义为路径上边权的**最小值**。求城市 $1$ 到城市 $n$ 的所有路径分数的最小值。题目保证 $1$、$n$ 之间至少有一条路径。

**约束**：

- $2 \le n \le 10^5$，$1 \le \text{roads.length} \le 10^5$
- $1 \le a_i, b_i \le n$，$a_i \ne b_i$，无重复边
- $1 \le \text{distance}_i \le 10^4$
- 城市 $1$ 与城市 $n$ 连通

> 💡 读题抓两个信号：①「路径可多次包含同一条道路」是本题**题眼**——它把"路径优化"降级成"**连通块统计**"；②「图不一定连通」暗示必须先定位 $1$ 所在的连通块，块外的边与答案无关。$n,m\le10^5$ 只允许线性/近线性做法。

> 💡 本题另有[每日题解 2492](../../solution/2401-2500/2492_两个城市间路径的最小分数.md)：主推「先 BFS 标可达、再扫一遍 `roads`」的两遍式写法并附面试问答。本篇按周赛复盘视角展开，侧重**双侧夹逼的正确性证明**、BFS 一遍流与并查集先并后查的实现细节，以及「漏扫块内边」「死胡同支路」等赛时翻车点，两篇互为印证。

## 2. 示例

**示例 1**

```text
输入：n = 4, roads = [[1,2,9],[2,3,6],[2,4,5],[1,4,7]]
输出：5
解释：路径 1→2→4 的分数是 min(9,5) = 5，不存在分数更小的路径。
```

**示例 2**

```text
输入：n = 4, roads = [[1,2,2],[1,3,4],[3,4,7]]
输出：2
解释：分数最小的路径是 1→2→1→3→4，分数为 min(2,2,4,7) = 2。
     关键：去而复返把最小边 (1,2)=2 塞进了路径——任何简单路径（只有 1→3→4）
     的最优分数都只有 4，绕行才拿得到 2。
```

**示例 3（自制：最小边挂在死胡同上）**

```text
输入：n = 5, roads = [[1,2,10],[2,5,20],[5,3,1]]
输出：1
解释：最小边 (5,3)=1 连着叶子节点 3，任何简单路径都不含它；
     但路径 1→2→5→3→5 合法（末尾折返），score = min(10,20,1,1) = 1。
```

## 3. 解题思路

### 3.1 暴力思路：路径根本数不完

从 $1$ 到 $n$ 枚举所有路径、逐条求最小边？由于**允许重边**，路径条数是**无穷**的（任意绕圈都算一条新路径），枚举连"枚举完"都做不到；退一步只枚举简单路径，条数也是指数级，$n\le10^5$ 直接出局。

更隐蔽的错误本能是把它当最短路/瓶颈路套 Dijkstra——但分数是"路径**最小**边"，既不是边权和（Dijkstra），也不是"最小化路径**最大**边"（瓶颈路，1631 型），松弛方向没有着落。示例 2 就是试金石：简单路径视角最优只有 $4$，正确答案却是 $2$，模板当场翻车。真正要问的问题是：**哪些边有机会出现在某条 $1\to n$ 路径里？**

### 3.2 核心观察：可重走 ⇒ 答案 = 城市 1 所在连通块的最小边权

![核心观察：绕行把块内任意边塞进 1→n 路径](images/wc322_q3_component_min_concept.svg)

设城市 $1$ 所在连通块为 $C$，块内最小边权为 $w^*$。由题面保证 $1$、$n$ 连通知 $n\in C$。

- **下界**：从 $1$ 出发每步沿边走，永远出不了 $C$（连通块是"经边可达"的等价类，向外封闭），所以任何 $1\to n$ 路径的边集 $E_{\text{路径}}\subseteq E(C)$。**子集的最小值 $\ge$ 全集的最小值**，故 score $\ge w^*$。
- **上界**：取达到 $w^*$ 的块内边 $(u,v)$。$C$ 连通 $\Rightarrow$ 存在块内路线 $1\rightsquigarrow u$ 与 $v\rightsquigarrow n$，拼成 $1\rightsquigarrow u\to v\rightsquigarrow n$——两条子路线**允许重叠、允许原路折返**（正是"可重走"赋予的自由，示例 2、3 靠的就是它）。该路径含 $(u,v)$，故 score $\le w^*$。

两侧夹逼，**答案恰为 $w^*$**："选哪条路径"这个优化维度被彻底抹掉——**块内每条边都等价可达、且都能被塞进路径**，答案与"怎么走"完全无关：

$$\text{answer}=\min\{\text{distance}_i:\ \text{roads}[i]\text{ 的端点与城市 }1\text{ 同属一个连通块}\}$$

### 3.3 算法流程：定位连通块 → 块内边取最小

![算法流程：BFS 一遍流更新，或并查集先并后查](images/wc322_q3_algorithm_flow.svg)

两条等价实现，骨架都是"先定块、再取块内最小边"：

- **BFS 一遍流**：建邻接表，从 $1$ 出发 BFS；**每扫到一条边（无论对面点是否访问过）都用它更新 ans**；`vis` 只决定新点是否入队。
- **并查集**：先把每条边 `union` 完，再以 $\text{find}(1)$ 为基准扫一遍 `roads`，端点同根的边参与取 min。

### 3.4 示例演算

![示例演算：死胡同上的最小边靠折返进路径](images/wc322_q3_walkthrough.svg)

以自制示例 3 演算 BFS：出队序列 $1,2,5,3$，可达块 $\{1,2,3,5\}$（$n=5$ 恰为终点，必在块内）；ans 依次 $10\to10\to1$——死胡同边 $(5,3)=1$ 在 $u=5$ 出队时照常把答案拉到 $1$，对应路径 $1\to2\to5\to3\to5$。注意 $u=2$ 时扫到的 $(1,10)$、$u=3$ 时扫到的 $(5,1)$ 都面对**已访问**的点，却仍参与更新——这正是防漏边的写法要点（见 §8 第 1 条）。

## 4. 算法细节

1. **建图**：无向边两个方向各存一份 $(\text{邻居},w)$，邻接表 `vector<vector<pair<int,int>>>` 开 $n+1$ 个桶（节点从 1 编号，下标 0 空置）。
2. **BFS 的 ans 更新时机**：出队 $u$ 扫边 $(v,w)$ 时**无条件** `ans = min(ans, w)`；`vis[v]` 只决定 $v$ 是否入队。等价的"两遍式"（先整块标 `vis`，再扫 `roads` 按 `vis[a]` 过滤）见每日题解，两者难易相当。
3. **并查集要"先并后查"**：`find(1)` 的结果在 union 过程中会变，必须**全部 union 完成**后取 `root = find(1)`，再统一扫边判 `find(a) == root`；路径压缩/路径减半任选，本题无需按秩合并。
4. **ans 初值**：`INT_MAX`（或 $10^4{+}1$）。$1$、$n$ 连通 $\Rightarrow$ 块内至少一条边，ans 必被更新，不存在"空块"合法输入。
5. **判块只看一端**：无向边两端同块，`vis[a]` $\Leftrightarrow$ `vis[b]` $\Leftrightarrow$ 边在块内；并查集版用 `find(a) == root`（`find(b)` 同值）。
6. **DFS 慎用递归**：链状图递归深度达 $10^5$，C++ 默认栈可能溢出，Python 默认递归上限 1000 直接 RE——BFS 队列或显式栈才安全。

## 5. 正确性证明

**引理 1（下界）**：任何从 $1$ 到 $n$ 的路径（允许重边）的分数 $\ge w^*$，$w^*$ 为城市 $1$ 所在连通块 $C$ 的最小边权。

**证明**：路径从 $1$ 出发、每步沿一条边移动。对步数归纳：起始点 $1\in C$；若当前点 $x\in C$，则沿边 $(x,y)$ 到达的 $y$ 与 $x$ 连通，故 $y\in C$——$C$ 对"沿边移动"封闭。因此路径的边集 $E_{\text{路径}}\subseteq E(C)$。由子集关系，$\min E_{\text{路径}}\ge\min E(C)=w^*$。∎

**引理 2（上界）**：存在从 $1$ 到 $n$ 的路径，其分数 $\le w^*$。

**证明**：取块内边 $(u,v)$ 使 $w(u,v)=w^*$。题面保证 $1$、$n$ 间有路径，故 $n\in C$；$C$ 连通，故存在块内点序 $P_1:1\rightsquigarrow u$ 与 $P_2:v\rightsquigarrow n$。将 $P_1$、边 $(u,v)$、$P_2$ 顺序拼接得到一条 $1$ 到 $n$ 的路径（子路线重叠、折返均合法——题面明示可重复走边）。其边集含 $(u,v)$，故分数 $\le w^*$。∎

**定理**：所求最小分数等于 $w^*$；BFS 一遍流与并查集先并后查两版算法均返回 $w^*$。

**证明**：由引理 1、2 夹逼，答案 $=w^*$。**BFS 版**：从 $1$ 出发恰好访问 $C$ 的全部点——块内每点均从 $1$ 可达故必被访问；块外点与 $C$ 无边相连故不会被访问。块内每条边 $(x,y)$ 在 $x$（或 $y$）出队时被扫到且无条件参与取 min，故 ans 恰为 $\min E(C)=w^*$。**并查集版**：union 后同块点同根；块间无边即无 union 路径，异块点不同根；故 `find(a)==find(1)` 恰好筛出 $E(C)$，取 min 即 $w^*$。∎

> 💡 **一句话**：分数是"路径最小边"且**允许重走**，"选路径"这一优化维度被彻底抹掉——问题塌缩成"**$1$ 的连通块里最小的边是多少**"，一趟图遍历或一整套并查集收工。

## 6. 复杂度分析

- **时间复杂度**：BFS 版 $O(n+m)$——每点出入队一次，每条有向边扫一次（$m=\text{roads.length}$）；并查集版 $O((n+m)\,\alpha(n))$，$\alpha$ 为反阿克曼函数，实测近线性。$n,m\le10^5$ 两版都轻松通过。
- **空间复杂度**：BFS 版 $O(n+m)$（邻接表存 $2m$ 条有向边 + `vis` + 队列）；并查集版仅 $O(n)$（`fa` 数组，免建邻接表）。
- **选型**：单次查询两版皆可；若还有"逐条加边、随时问连通性"的后续询问，并查集免建图、扩展更顺手。

## 7. 参考代码

### C++（BFS 一遍流）

```cpp
class Solution {
public:
    int minScore(int n, vector<vector<int>>& roads) {
        vector<vector<pair<int,int>>> g(n + 1);
        for (auto& r : roads) {
            g[r[0]].push_back({r[1], r[2]});
            g[r[1]].push_back({r[0], r[2]});
        }
        vector<char> vis(n + 1, 0);
        queue<int> q;
        q.push(1);
        vis[1] = 1;
        int ans = INT_MAX;
        while (!q.empty()) {
            int u = q.front(); q.pop();
            for (auto [v, w] : g[u]) {
                ans = min(ans, w);          // 扫到的边必在 1 的连通块内，无条件更新
                if (!vis[v]) {
                    vis[v] = 1;
                    q.push(v);
                }
            }
        }
        return ans;                          // 1 与 n 连通 ⇒ 块非空，ans 必被更新
    }
};
```

### Python（并查集：先并后查）

```python
class Solution:
    def minScore(self, n: int, roads: List[List[int]]) -> int:
        fa = list(range(n + 1))

        def find(x: int) -> int:
            while fa[x] != x:
                fa[x] = fa[fa[x]]            # 路径减半
                x = fa[x]
            return x

        for a, b, _ in roads:
            fa[find(a)] = find(b)            # 先把所有边并完

        root = find(1)                       # 再取基准根
        return min(w for a, _, w in roads if find(a) == root)
```

> ⚠️ 两版代码已对拍验证：官方示例 1/2、自制死胡同样例、三角形漏边陷阱样例，以及 485 张随机图上与"两遍式 BFS + walk 枚举真值"交叉一致。

## 8. 边界情况与易错点

1. **只在 `!vis[v]` 时更新 ans（高频 WA）**：三角形 $1\!-\!2$、$1\!-\!3$、$2\!-\!3$（权 $10,10,1$）中，$(2,3)$ 的两端都已被 $1$ **直接发现**，若只在新发现点时取 min 会漏掉它，而它恰是块内最小边。扫到边就更新，`vis` 只管入队。
2. **并查集"边并边查"**：union 循环里拿 `find(1)` 当基准是错的——中途的根还在变；必须并完再统一扫边。
3. **把题做成最短路/瓶颈路**：分数是"路径**最小**边"，与 1631 型"最小化路径**最大**边"方向相反，与边权和 Dijkstra 更是两码事。示例 2 是试金石。
4. **忘记"图不连通"**：对全图直接取最小边会把别的连通块的边也算进去（如 `roads=[[1,4,5],[2,3,1]]` 答案是 5 不是 1）；必须按"与 1 同块"过滤。
5. **死胡同边不能丢**：最小边可能挂在叶子上（自制示例 3 的 $(5,3)=1$），任何简单路径都不含它——正因允许折返重走它才有效，这也是本思路成立的根基。
6. **递归 DFS 爆栈**：链状图深度 $10^5$；Python 递归深度默认 1000 必 RE。用 BFS 队列或显式栈。
7. **ans 初值**：`INT_MAX` 或 $10^4{+}1$ 均可；题目保证 $1$、$n$ 连通，块内至少一条边，不会返回初值。
8. **$n=2$ 单边**：块内仅一条边，答案即其权值，两版代码均自然覆盖。
