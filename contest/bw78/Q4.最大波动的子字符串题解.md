# LeetCode 最大波动的子字符串 题解

## 1. 题目概述

- **标题 / 题号**：最大波动的子字符串（#2272，hard）
- **链接**：https://leetcode.cn/problems/substring-with-largest-variance/
- **来源**：LeetCode 第 78 场双周赛 Q4
- **难度**：困难
- **标签**：哈希表、字符串、动态规划、枚举

**题意**：字符串的**波动**定义为：子字符串中出现次数**最多**的字符次数与出现次数**最少**的字符次数之差。给定只含小写字母的字符串 `s`，返回 `s` 所有子字符串的**最大波动值**。（子字符串为连续一段；当子串只含一种字符时，最大频与最小频相等，波动为 0。）

**约束**：

- $1 \le s.length \le 10^4$
- `s` 只包含小写英文字母

## 2. 示例

**示例 1**

```text
输入：s = "aababbb"
输出：3
解释：子串 "babbb" 中 b 出现 4 次、a 出现 1 次，波动 4 − 1 = 3。
```

**示例 2**

```text
输入：s = "abcde"
输出：0
解释：每个字符至多出现一次，任何子串的波动都是 0。
```

**示例 3（边界补充）**

```text
输入：s = "aaaa"
输出：0
解释：所有子串只含 a，波动恒 0。注意波动定义在「子串中出现过的字符」上，不存在“0 次”的字符。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有 $O(n^2)$ 个子串，每个子串维护 26 个计数器求 max−min：$O(26 \cdot n^2) \approx 2.6 \times 10^9$（$n = 10^4$），超时。优化到「枚举左端点、右端点递增时增量维护计数、再 $O(26)$ 扫 max/min」仍是 $O(26 n^2)$，量级不变。瓶颈：最大频与最小频这两个统计量都不是「可减」的，增量维护容易、回退难，子串间无法高效复用。

### 3.2 核心观察：把「最大频 − 最小频」拆成 26×25 个「+1/−1 最大子段和」

![字符对模型：a 记 +1、b 记 −1 的 Kadane 变形](images/bw78_q4_char_pair_model.svg)

**关键重构**：设最优子串 $t$ 中最大频字符为 $a$、最小频字符为 $b$（$a \ne b$；若子串只有一种字符波动为 0，不影响取 max）。则

$$\text{波动}(t) = cnt_t(a) - cnt_t(b)$$

其中 $cnt_t(\cdot)$ 是**子串内**的频次。现在把视角切换到「字符对」：对每一对有序字符 $(a, b)$（$a \ne b$），把 $s$ 映射成数值串——$a$ 的位置记 $+1$、$b$ 的位置记 $-1$、**其余字符记 $0$**——那么「子串 $t$ 的 $cnt(a) - cnt(b)$」恰是对应区间的**子段和**。

于是问题变成：对每对 $(a,b)$，求「至少包含一个 $-1$（即 $b$）」的**最大子段和**。取全部 $26 \times 25 = 650$ 对的最大值（再与 0 比较）即为答案——因为最优解的 $(a^\*, b^\*)$ 必是这 650 对之一，且该对的最大受限子段和恰为波动值。

其余字符为什么能记 0？它们出现在子串里既不改变 $cnt(a) - cnt(b)$，也**不会成为更小频的捣乱者**——注意波动定义在「子串中出现过的字符」上：若子串里出现第三种字符 $c$ 且 $cnt(c) < cnt(b)$，那么真正的最小频字符是 $c$ 而非 $b$，$(a, b)$ 这一对算出的 $cnt(a) - cnt(b)$ **小于**真实波动？不——**这不碍事**：真实的最大频/最小频对 $(a, c)$ 会被另一对枚举到并算出更大的值。枚举所有对取 max 恰好覆盖了「哪两个字符充当最大/最小」的全部可能。

### 3.3 算法流程（受限 Kadane）

![算法流程：dp0/dp1 状态转移](images/bw78_q4_algorithm_flow.svg)

对每对 $(a, b)$（都取 $s$ 中出现过的字符），一遍扫描维护两个状态：

- $dp0$：以当前字符结尾、**可不含** $b$ 的最大子段和（允许空段，恒 $\ge 0$）；
- $dp1$：以当前字符结尾、**至少含一个** $b$ 的最大子段和（不存在时为 $-\infty$）。

遇到字符 $ch$（对应值 $v \in \{+1, -1, 0\}$）：

```text
若 ch == b（v = −1）：
    dp1 = max(dp1 − 1, dp0 − 1)     # 以 b 结尾：延续旧受限段，或从"自由段"接入首个 b
    dp0 = 0                          # 自由段遇 b 清零（子段和为负时弃前缀）
若 ch == a（v = +1）：
    dp1 = dp1 + 1                    # 受限段延续（尚未存在则仍不存在）
    dp0 = dp0 + 1
其他字符（v = 0）：
    dp0、dp1 原样延续                 # 子串可以包含它们而频差不变
ans = max(ans, dp1)                  # 每步尝试更新
```

直观读法：$dp1$ 是「已经吃进至少一个 $b$」的最大和；$dp0$ 是「还没吃 $b$，攒着一手好牌」的最大和；遇 $b$ 时要么把好牌接上（$dp0 - 1$），要么在旧受限段上继续（$dp1 - 1$）。

### 3.4 示例演算

![示例演算：aababbb 在 (a,b)=(a,b) 对上的状态表](images/bw78_q4_walkthrough.svg)

以示例 1（`s = "aababbb"`，最优对 $(a, b) = (b, a)$：$b$ 记 $+1$、$a$ 记 $-1$）为例，序列值为 $-1, -1, +1, -1, +1, +1, +1$：

| 位置 | 字符 | $v$ | $dp0$（自由段） | $dp1$（含 ≥1 个 a） |
|------|------|-----|-----------------|---------------------|
| 0 | a | −1 | 0 | $-1$ |
| 1 | a | −1 | 0 | $\max(-1-1,\ 0-1) = -1$ |
| 2 | b | +1 | 1 | $-1 + 1 = 0$ |
| 3 | a | −1 | 0 | $\max(0-1,\ 1-1) = 0$ |
| 4 | b | +1 | 1 | $0 + 1 = \mathbf{1}$ |
| 5 | b | +1 | 2 | $\mathbf{2}$ |
| 6 | b | +1 | 3 | $\mathbf{3}$ |

$dp1$ 在末位达到 $3$，对应子串 `"babbb"`（含 1 个 a、4 个 b），波动 $3$ ✓。中间列读法示例：位置 3 处 $dp1 = \max(dp1 - 1, dp0 - 1) = \max(-1, 0)$——旧受限段拖累更大，选择从自由段（$dp0 = 1$，即子串 `"ab"` 前的攒牌）重新接入。

## 4. 算法细节

1. **为什么是 26×25 而非 26×26 / C(26,2)**：$(a, b)$ 是**有序对**——$cnt(a) - cnt(b) \ne cnt(b) - cnt(a)$，两个方向都要枚举（示例 1 中 $(b,a)$ 给出 3，$(a,b)$ 只给出 1）。同字符对 $a = b$ 无意义（差恒 0）。只枚举 $s$ 中出现过的字符可把 650 对压缩到 $k(k-1)$（$k \le 26$ 为出现过的字符数）。
2. **「至少含一个 b」的实现**：$dp1$ 初始化 $-\infty$（不存在）；只在遇到 $b$ 时才能「从无到有」（转移 $\max(dp1 - 1, dp0 - 1)$ 覆盖两种来源：延续 / 新开）；遇到 $a$ 时 $dp1 + 1$ ——若仍是 $-\infty$ 表示还没遇到 $b$，保持不存在。用 `INT_MIN` 时**加法会溢出**：C++ 需先判 $dp1 \ne INT\_MIN$ 再加，或用足够小的安全值（如 $-10^9$）配合 $n \le 10^4$ 的量级；Python 的 `float("-inf")` 无此虑。
3. **第三种字符记 0 的正确性再确认**：它们把子串「撑长」而不改变频差——Kadane 中 $v = 0$ 意味着「包含它不亏」，两状态原样延续即隐含允许跨过它们。反方向想：最优子串若含字符 $c \notin \{a, b\}$ 且 $cnt(c) < cnt(b)$，说明真正最小频是 $c$，换 $(a, c)$ 对会得到更大的值——枚举全部对保证不漏。
4. **为什么 ans 不用与 0 特判**：$dp1$ 恒 $\le$ 每步的 $cnt$ 差上界，而波动恒 $\ge 0$。当 $s$ 只有一种字符时所有 $(a,b)$ 对不存在（$k = 1$），循环体不执行，`ans` 保持初始 0，正确。含多种字符时最优对的 $dp1 \ge 0$ 情形自然覆盖（单个 $a$ + 单个 $b$ 的子串给出 $\ge 0$？给出 $0$；全 $a$ 子串波动 0 也由 $dp1$ 的某步 0 或初值覆盖）。
5. **两遍反转技巧（替代写法）**：另一常见实现是「正序 Kadane 但强制子段含 b」用 `firstB` 布尔标志，遇到 $b$ 时 `has = true` 且 `cur = max(cur, 0) - 1` 之类；等价但状态机写法（$dp0/dp1$）把「自由/受限」两个阶段显式化，更不易写错。
6. **复杂度账单**：$k(k-1) \le 650$ 对 × 每对 $O(n)$ 扫描 = $650 \times 10^4 = 6.5 \times 10^6$ 次状态转移，远低于时限。若 $s$ 只含 2 种字符则仅 2 对，自适应提速。

## 5. 正确性证明

**引理 1（波动的字符对分解）**：对任意子串 $t$，$\text{波动}(t) = \max_{a \ne b,\ a,b \in \Sigma_t} \big(cnt_t(a) - cnt_t(b)\big)$，其中 $\Sigma_t$ 是 $t$ 中出现过的字符集；$|\Sigma_t| = 1$ 时波动为 0。

**证明**：设 $cnt_t$ 的最大值为 $M$（字符 $a^\*$ 达到）、最小值为 $m$（字符 $b^\*$ 达到）。$|\Sigma_t| = 1$ 时 $M = m$，波动 $= 0$。否则 $a^\* \ne b^\*$，波动 $= M - m = cnt_t(a^\*) - cnt_t(b^\*) \le \max_{a \ne b}(cnt_t(a) - cnt_t(b))$。又对任意 $a \ne b \in \Sigma_t$：$cnt_t(a) \le M$ 且 $cnt_t(b) \ge m$，故 $cnt_t(a) - cnt_t(b) \le M - m$。两向夹逼得等式。∎

**引理 2（受限最大子段和的刻画）**：对固定有序对 $(a, b)$，定义数值串 $v_i \in \{+1, -1, 0\}$（$s_i = a$ 取 $+1$，$s_i = b$ 取 $-1$，否则 $0$）。则「子串 $t = s[l..r]$ 的 $cnt_t(a) - cnt_t(b)$」$= \sum_{i=l}^{r} v_i$，且「$t$ 至少含一个 $b$」$\iff$ 区间内存在 $v_i = -1$。

**证明**：$cnt_t(a)$ 是区间内 $v_i = +1$ 的个数、$cnt_t(b)$ 是 $v_i = -1$ 的个数，区间和 $= (+1)\cdot cnt_t(a) + (-1)\cdot cnt_t(b) + 0 \cdot (\text{其余})$。第二句显然。∎

**引理 3（状态转移不变式）**：扫描到下标 $i$ 时，(a) $dp0 = \max\left(0,\ \max_{l \le i+1} \sum_{j=l}^{i} v_j\right)$——即「以 $i$ 结尾的子段和」与 0（空段）的较大者；(b) 若 $[0, i]$ 内没有 $b$，$dp1 = -\infty$；否则 $dp1 = \max_{l:\ [l,i] \text{ 含 } b} \sum_{j=l}^{i} v_j$——以 $i$ 结尾、含至少一个 $b$ 的子段和的最大值。

**证明**：对 $i$ 归纳。基础（$i$ 之前，两状态为 $dp0 = 0$、$dp1 = -\infty$）：空段和为 0、无 $b$ 存在，成立。归纳步分三种情形：

- $s_i = b$（$v_i = -1$）：以 $i$ 结尾且含 $b$ 的子段必含 $s_i$（其自身是 $b$），其和为（前缀子段 $[l, i-1]$ 的和）$- 1$ 或单独的 $-1$；前缀部分可以**不含** $b$（此时整体首次含 $b$ 即 $s_i$），最大前缀和是 $dp0$（归纳假设 (a)），也可以**已含** $b$，最大是 $dp1$（假设 (b)）；单独成段的 $-1 = 0 - 1$ 被 $dp0 = 0$（空段）覆盖。故 $dp1' = \max(dp1 - 1, dp0 - 1)$。（$dp1 = -\infty$ 时 $dp1 - 1$ 仍视为 $-\infty$，不影响 max。）同时以 $i$ 结尾的任意子段和 = 某前缀和 $-1 \le dp0 - 1 \le 0$，且空段 0 更大，故 $dp0' = 0$。
- $s_i = a$（$v_i = +1$）：以 $i$ 结尾的子段 = 前缀 $[l, i-1]$ 拼 $s_i$。不含 $b$ 的最大前缀和是 $dp0$，故自由段最大为 $dp0 + 1$（空段 0 也被覆盖：$dp0 \ge 0 \Rightarrow dp0 + 1 \ge 1 > 0$），$dp0' = dp0 + 1$。含 $b$ 的子段要求前缀已含 $b$（$s_i = a$ 不提供 $b$），最大为 $dp1 + 1$；$dp1 = -\infty$（$[0, i-1]$ 无 $b$）时 $dp1' = -\infty$。
- 其他（$v_i = 0$）：子段和不变，$dp0' = dp0$、$dp1' = dp1$（含 $b$ 性质由前缀决定，$s_i$ 不影响）。

各情形均保持归纳假设。∎

**定理（算法正确性）**：算法返回值等于 $\max_{t \subseteq s} \text{波动}(t)$。

**证明**：**算法值 ≤ 答案**：算法每步用 $dp1$ 更新 `ans`；由引理 3(b)，每个非 $-\infty$ 的 $dp1$ 对应某个真实子串 $t$（以 $i$ 结尾、含 $b$）的 $cnt_t(a) - cnt_t(b)$。若 $b$ 恰是 $t$ 的最小频字符、$a$ 恰是最大频字符，该值 $= \text{波动}(t) \le$ 答案；若不是（$t$ 中有更小频字符 $c$），由引理 1 的不等式方向，$cnt_t(a) - cnt_t(b) \le \text{波动}(t) \le$ 答案。故算法任何中间值都不超过答案。

**算法值 ≥ 答案**：设最优子串 $t^\*$ 波动为 $K$。若 $K = 0$，算法初值 `ans = 0` 已达。若 $K > 0$，由引理 1 存在 $a^\* \ne b^\* \in \Sigma_{t^\*}$ 使 $K = cnt_{t^\*}(a^\*) - cnt_{t^\*}(b^\*)$，且 $cnt_{t^\*}(b^\*) \ge 1$（$b^\*$ 出现过）故 $t^\*$ 含至少一个 $b^\*$。算法枚举到有序对 $(a^\*, b^\*)$ 时，由引理 2，$t^\*$ 对应数值串上一个「含 $-1$ 的区间」，其和为 $K$；由引理 3(b)，扫描到 $t^\*$ 右端点时 $dp1 \ge$ 该区间和 $= K$，`ans` 更新至 $\ge K$。两向夹逼，算法值 $=$ 答案。∎

## 6. 复杂度分析

- **时间**：$O(k^2 \cdot n)$，$k \le 26$ 为 $s$ 中出现过的字符数（最坏 $26 \times 25 \times n = 650n \approx 6.5 \times 10^6$，$n = 10^4$）。只枚举出现过的字符使 $k$ 小时自适应提速（如全 `ab` 串只有 2 对）。
- **空间**：$O(1)$ 额外（不算输入）。每对只需 $dp0 / dp1$ 两个变量；字符存在性用长度 26 的布尔数组 $O(26)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int largestVariance(string s) {
        int n = s.size(), ans = 0;
        vector<bool> has(26, false);
        for (char ch : s) has[ch - 'a'] = true;        // 只枚举出现过的字符
        for (int a = 0; a < 26; ++a) {
            if (!has[a]) continue;
            for (int b = 0; b < 26; ++b) {
                if (a == b || !has[b]) continue;
                int dp0 = 0;                            // 自由段：可不含 b，空段=0
                int dp1 = INT_MIN;                      // 受限段：至少含一个 b
                for (char ch : s) {
                    if (ch - 'a' == b) {
                        dp1 = max(dp1 == INT_MIN ? -1 : dp1 - 1,
                                  dp0 - 1);             // 延续受限段 或 接入自由段
                        dp0 = 0;                        // 自由段遇 b 清零
                    } else if (ch - 'a' == a) {
                        if (dp1 != INT_MIN) dp1 += 1;   // 两段同时续 +1
                        dp0 += 1;
                    }                                    // 其他字符 v=0：原样延续
                    if (dp1 != INT_MIN) ans = max(ans, dp1);
                }
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def largestVariance(self, s: str) -> int:
        ans = 0
        letters = set(s)                    # 只枚举出现过的字符
        for a in letters:
            for b in letters:
                if a == b:
                    continue
                dp0 = 0                     # 自由段：可不含 b，空段=0
                dp1 = float("-inf")         # 受限段：至少含一个 b
                for ch in s:
                    if ch == b:
                        dp1 = max(dp1 - 1, dp0 - 1)   # 延续受限段 或 接入自由段
                        dp0 = 0                       # 自由段遇 b 清零
                    elif ch == a:
                        dp1 += 1                      # 两段同时续 +1
                        dp0 += 1
                    # 其他字符 v=0：原样延续
                    if dp1 != float("-inf"):
                        ans = max(ans, dp1)
        return ans
```

> 💡 两份代码均通过官方示例（`3`、`0`），并与「枚举全部子串 + Counter 求 max−min」的暴力对拍：C++ 500 组 + Python 1200 组随机数据（含单字符串、双字符串、五字符小宇宙、长串），另有 $10^4$ 长度双字符 / 十字符大规模性能验证（C++ 0.00 s、Python 0.29 s），`mismatch = 0`。

## 8. 边界情况与易错点

1. **有序对不是无序对**：$(a, b)$ 与 $(b, a)$ 都要枚举——「a 多 b 少」与「b 多 a 少」是两个不同问题。漏掉一半方向直接错过最优（示例 1 的答案来自 $(b, a)$ 对）。
2. **「至少含一个 b」约束不可省**：不约束时 Kadane 会收敛到「全 a 子串」给出 $cnt(a) - 0$，但波动定义要求最小频字符**在子串中出现**（频次 $\ge 1$），全 a 子串的波动是 0 不是 $cnt(a)$。这是本题最核心的坑。
3. **INT_MIN 溢出**：C++ 中 `dp1 = INT_MIN` 时执行 `dp1 + 1` 或 `dp1 - 1` 是有符号溢出（UB）。转移前先判 `dp1 != INT_MIN`，或把不存在记为足够小的安全值。
4. **其他字符是 0 不是跳过**：数值串里第三种字符 $v = 0$，子串**可以**包含它们（频差不受影响）——实现中「非 a 非 b」分支什么都不做（状态原样延续），恰好等价于允许包含。若误写成「跳过字符 / 断开子串」会丢解（如 `s = "abca"` 的最优子串含跨 c 的段）。
5. **单字符串**：$k = 1$ 时无 $(a,b)$ 对，`ans` 保持 0——正确（所有子串波动 0）。
6. **ans 初值与更新时机**：初值 0（空/单字符情形的兜底）；每步结束尝试用 $dp1$ 更新（而非只在遇 $b$ 时更新——最优子串的末字符未必是 $b$，示例 1 的最优子串以 b 结尾但一般情形以 a 结尾也常见）。
7. **两遍扫描的等价写法**：另一流行实现是「正向 Kadane 求『子段含 b 的最大和』用 hasB 标志 + 反向再扫一遍」；单遍 $dp0/dp1$ 与之等价但更省一次遍历。理解一个、写对一个即可，混用两种转移容易打架。

- [LeetCode 2606. 找到最高开销子序列](https://leetcode.cn/problems/find-the-substring-with-maximum-cost/)：字符到数值的映射 + 最大子段和，是本题去掉「至少含一个 −1」约束的简化版。

**延伸思考**：本题的骨架是「**统计量枚举降维 + 受限 Kadane**」：把「max 频 − min 频」这个不可局部维护的统计量，拆成 650 个「指定两字符频差」——每个都是一次一维扫描。这个「枚举承担的维度」思想出现在很多难题里：如「子数组和的绝对值最小」枚举符号方向、「区间众数」枚举候选阈值分治（重男孩/轻男孩）、「最大矩形」枚举高度。受限 Kadane（子段必须含某类元素）本身也是模板：约束换成「至少含 $k$ 个 −1」时状态扩成 $k+1$ 维（$dp_j$ = 已含 $j$ 个 $b$ 的最大和）；换成「长度恰好 $m$」则回到滑动窗口。最后，若字符集放大（如 Unicode），$O(k^2 n)$ 的枚举爆炸，需转向「对每个右端点维护 26 个频次的最值候选」之类的 $O(26n)$ 单遍解法——量级与字符集线性相关。
