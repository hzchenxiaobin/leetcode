# LeetCode 找到一个数字的K美丽值 题解

## 1. 题目概述

- **标题 / 题号**：找到一个数字的 K 美丽值（#2269，easy）
- **链接**：https://leetcode.cn/problems/find-the-k-beauty-of-a-number/
- **来源**：LeetCode 第 78 场双周赛 Q1
- **难度**：简单
- **标签**：数学、字符串、滑动窗口

**题意**：整数 `num` 的 **k 美丽值**定义为 `num` 中满足条件的**子字符串**数目：长度恰为 $k$，且（作为整数）能整除 `num`。注意允许前缀 0（如 `"04"` 视为 4），且 **0 不能整除任何数**。求 `num` 的 k 美丽值。

**约束**：

- $1 \le num \le 10^9$
- $1 \le k \le \lvert num \rvert$（`num` 视为字符串的长度，至多 10 位）

## 2. 示例

**示例 1**

```text
输入：num = 240, k = 2
输出：2
解释："24" 整除 240；"40" 整除 240。k 美丽值为 2。
```

**示例 2**

```text
输入：num = 430043, k = 2
输出：2
解释："43"✓、"30"✗、"00"（=0，不能作除数）✗、"04"（=4，430043 mod 4 = 3）✗、"43"✓。
```

**示例 3（边界补充）**

```text
输入：num = 1000000000, k = 10
输出：1
解释：唯一的长 10 子串是 "1000000000" 本身，1000000000 mod 1000000000 = 0 → 计 1。
```

## 3. 解题思路

### 3.1 暴力思路

把 `num` 转成字符串 `s`，枚举所有长度为 $k$ 的子串起点 $i \in [0, \lvert s \rvert - k]$，`int(s[i:i+k])` 转回整数判定整除。子串数 $\le 10$、每个 $O(k)$ 转换，总量 $O(\lvert s \rvert \cdot k) \le 100$——数据规模下直接暴力即可，这也是最不易错的写法。

### 3.2 核心观察：定长子串的滑动窗口取余

![滑动窗口模型：k 位窗口在数字串上滑动](images/bw78_q1_sliding_window.svg)

**关键事实**：窗口右移一位时，新窗口的数值可由旧窗口 $O(1)$ 推出：

$$v_{\text{new}} = (v_{\text{old}} - d_{\text{out}} \cdot 10^{k-1}) \cdot 10 + d_{\text{in}}$$

其中 $d_{\text{out}}$ 是滑出的最高位数字、$d_{\text{in}}$ 是滑入的新数字。这就是**定长滑动窗口**在「窗口值 = 数值」上的版本。虽然本题 $\lvert s \rvert \le 10$ 用不上这点优化，但它是模板沉淀点：当数字长 $10^5$ 位时（如大数取余题），逐子串重算 $O(nk)$ 会超时，滑窗 $O(n)$ 是正解。

另一处数学细节：判定 $v \mid num$ 需先排除 $v = 0$（除零）；而 $v \ne 0$ 时 $num \bmod v$ 是安全的——$v \le 10^9 - 1 < 2^{31}$，`int` 装得下（`num` 至多 10 位，窗口至多 9 位时 $v < 10^9$；$k = 10$ 时 $v = num$ 本身，也 $\le 10^9$）。

### 3.3 算法流程

```text
1. s = 十进制字符串(num)
2. ans = 0
3. 对 i = 0 .. len(s) − k：
       v = 整数(s[i .. i+k−1])     # 允许前缀 0，转整数自动消去
       若 v ≠ 0 且 num mod v == 0：ans += 1
4. 返回 ans
```

（滑窗版：维护 $v$ 与 $10^{k-1}$，右移时按 §3.2 公式更新。）

### 3.4 示例演算

![示例演算：430043 的五个窗口](images/bw78_q1_walkthrough.svg)

以示例 2（`num = 430043`，$k = 2$）为例，`s = "430043"`：

| 起点 $i$ | 子串 | 数值 $v$ | $430043 \bmod v$ | 计数 |
|---------|------|---------|------------------|------|
| 0 | `"43"` | 43 | $0$ | ✅ |
| 1 | `"30"` | 30 | $13$ | ❌ |
| 2 | `"00"` | 0 | 除数非法 | ❌ |
| 3 | `"04"` | 4 | $3$ | ❌ |
| 4 | `"43"` | 43 | $0$ | ✅ |

$k$ 美丽值为 $2$ ✓。注意第 4 行：`"04"` 转整数是 4（前缀 0 合法但值变小），判定按 $v = 4$ 进行。

## 4. 算法细节

1. **字符串切片 vs 数值滑窗**：`len(num) ≤ 10` 时直接切片 + `int()`/`stoi()` 最清晰；数值滑窗是为更大规模准备的模板，本题写入解是为沉淀套路（C++ 版给出滑窗实现）。
2. **除零防护**：$v = 0$（窗口全零）时跳过——「0 不能整除任何值」是题面规则，`num % 0` 在两门语言里都是运行时错误。
3. **前缀 0 的语义**：`"00"`、`"04"` 都是合法子串，但整除判定按其数值（0 与 4）进行；`int("04") == 4`、`stoi("04") == 4` 自动处理，无需手动去零。
4. **C++ 滑窗的取余时机**：`(v - d_out * base) * 10 + d_in` 中 `v` 最大 $\sim 10^9$，乘 10 前「减去最高位」把它压回 $k-1$ 位，全程不超 `long long`（用 `long long` 存 $v$ 与 `base` 最稳）。
5. **窗口数公式**：长 $L$ 的字符串有 $L - k + 1$ 个长 $k$ 子串；$k = L$ 时恰有 1 个（整串自身），$num \bmod num = 0$ 恒成立，直接计 1。
6. **`num` 自身整除自身**：$k$ 等于位数时窗口值就是 `num`，非零则必计数——别在「子串等于原串」上纠结，它就是普通窗口。

## 5. 正确性证明

**引理 1（子串枚举完备性）**：长度为 $L$ 的字符串 $s$ 的长度为 $k$ 的连续子串恰为 $s[i..i+k-1]$，$i = 0, 1, \dots, L-k$，共 $L - k + 1$ 个，无遗漏无重复。

**证明**：子串由起点唯一决定（长度固定）；起点 $i$ 合法当且仅当 $i \ge 0$ 且 $i + k - 1 \le L - 1$，即 $0 \le i \le L - k$。∎

**引理 2（滑窗递推正确性）**：设当前窗口 $s[i..i+k-1]$ 的数值为 $v_i = \sum_{j=0}^{k-1} d_{i+j} \cdot 10^{k-1-j}$，则 $v_{i+1} = (v_i - d_i \cdot 10^{k-1}) \cdot 10 + d_{i+k}$。

**证明**：按定义展开：
$$v_{i+1} = \sum_{j=0}^{k-1} d_{i+1+j} \cdot 10^{k-1-j} = \sum_{j=1}^{k} d_{i+j} \cdot 10^{k-j} = 10 \cdot \sum_{j=1}^{k-1} d_{i+j} \cdot 10^{k-1-j} + d_{i+k}$$
而 $\sum_{j=1}^{k-1} d_{i+j} \cdot 10^{k-1-j} = v_i - d_i \cdot 10^{k-1}$（从 $v_i$ 中去掉最高位项）。代入即得递推式。∎

**定理（算法正确性）**：遍历所有起点按「$v \ne 0$ 且 $num \bmod v = 0$」计数，返回值等于 `num` 的 k 美丽值。

**证明**：由引理 1 枚举覆盖全部长 $k$ 子串且互异。对每个子串，其数值 $v$（前缀 0 由按位权求值自然消去，与 `int`/`stoi` 语义一致）参与判定：题面定义「子字符串能整除 num」即 $v \mid num$，对 $v = 0$ 题面规定 0 不能整除任何值故排除；$v \ne 0$ 时 $v \mid num \iff num \bmod v = 0$。计数器对每个满足条件的子串加一，故终值即 k 美丽值。若采用滑窗实现，由引理 2 归纳可知每个窗口的数值与直接求值一致，判定等价。∎

## 6. 复杂度分析

- **时间**：$O(L)$（滑窗版）或 $O(L \cdot k)$（切片版），$L = \lvert num \rvert \le 10$。切片版每窗口一次 $O(k)$ 的字符串转整数；滑窗版每步 $O(1)$。本题规模下两者都是个位数微秒级。
- **空间**：$O(L)$。字符串 $s$ 本身；滑窗版另存常数个数值变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int divisorSubstrings(int num, int k) {
        string s = to_string(num);
        int L = s.size();
        long long base = 1;                     // 10^(k−1)
        for (int i = 0; i < k - 1; ++i) base *= 10;
        long long v = 0;                        // 当前窗口数值
        int ans = 0;
        for (int i = 0; i < L; ++i) {
            if (i >= k) v -= (s[i - k] - '0') * base;  // 滑出最高位
            v = v * 10 + (s[i] - '0');                 // 滑入新位
            if (i >= k - 1) {
                int x = (int)v;                        // k ≤ 10 位，v ≤ 1e9
                if (x != 0 && num % x == 0) ++ans;
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def divisorSubstrings(self, num: int, k: int) -> int:
        s = str(num)
        ans = 0
        for i in range(len(s) - k + 1):
            v = int(s[i:i + k])      # 前缀 0 自动消去，如 "04" → 4
            if v != 0 and num % v == 0:
                ans += 1
        return ans
```

> 💡 两份代码均通过官方示例（`2`、`2`），并与「逐子串重新转整数」的暴力对拍 2000 组随机数据（含全 0 窗口、$k$ 等于位数、`num = 10⁹` 边界），`mismatch = 0`。

## 8. 边界情况与易错点

1. **除零**：窗口全零时 $v = 0$，直接跳过；不判就崩（Python `ZeroDivisionError`、C++ 整除 0 未定义）。
2. **前缀 0 不是非法**：`"04"` 是合法子串，按数值 4 判定；误把前缀 0 子串整个排除会漏计（如 `num = 1000000000`、$k=2$ 的 `"00"` 无影响，但构造 `num = 1004`、$k=2$ 时 `"04" = 4$ 整除 1004 应计数）。
3. **窗口数值的溢出**：$k \le 10$、`num ≤ 10⁹` 时 $v \le 10^9$，`int` 恰好装下（$10^9 < 2^{31} - 1 \approx 2.147 \times 10^9$）；但 C++ 滑窗递推的中间量（乘 10 瞬间）会短暂超过，用 `long long` 存 $v$ 最稳。
4. **$k$ 等于位数**：唯一窗口是整串，恒计数 1（非零数自除）。循环边界 `L - k + 1 = 1` 自动处理。
5. **重复子串各计一次**：示例 2 中 `"43"` 出现两次计两次——不要对子串去重。
6. **`num` 是 1 位且 $k = 1$**：唯一窗口是自身，1 除 1 余 0，答案 1。
