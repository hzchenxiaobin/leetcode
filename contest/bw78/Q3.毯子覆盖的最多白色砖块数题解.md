# LeetCode 毯子覆盖的最多白色砖块数 题解

## 1. 题目概述

- **标题 / 题号**：毯子覆盖的最多白色砖块数（#2271，medium）
- **链接**：https://leetcode.cn/problems/maximum-white-tiles-covered-by-a-carpet/
- **来源**：LeetCode 第 78 场双周赛 Q3
- **难度**：中等
- **标签**：贪心、数组、二分查找、前缀和、排序、滑动窗口

**题意**：给定整数区间数组 `tiles`（`tiles[i] = [l_i, r_i]`，位置 $l_i \le j \le r_i$ 的每块瓷砖都是白色，区间**互不重叠**）与毯子长度 `carpetLen`。毯子可放在数轴上**任意位置**（必须连续），求最多能盖住多少块白色瓷砖。

**约束**：

- $1 \le tiles.length \le 5 \times 10^4$
- $1 \le l_i \le r_i \le 10^9$，区间互不重叠
- $1 \le carpetLen \le 10^9$

## 2. 示例

**示例 1**

```text
输入：tiles = [[1,5],[10,11],[12,18],[20,25],[30,32]], carpetLen = 10
输出：9
解释：毯子盖 [10,19]：[10,11] 共 2 块 + [12,18] 共 7 块 = 9。
```

**示例 2**

```text
输入：tiles = [[10,11],[1,1]], carpetLen = 2
输出：2
解释：毯子盖 [10,11]，两块全中。
```

**示例 3（边界补充）**

```text
输入：tiles = [[1,100]], carpetLen = 5
输出：5
解释：毯子比单段更短，只能盖住该段的 5 块（左端对齐段起点即可）。
```

## 3. 解题思路

### 3.1 暴力思路

毯子左端可放在 $1 \sim 10^9$ 的任何位置，对每个位置累加与所有区间的交集长度：$O(V \cdot T)$（$V$ 为值域、$T$ 为段数），$10^9 \times 5 \times 10^4$ 天文数字。缩小到「与段端点对齐」也是 $O(T^2) = 2.5 \times 10^9$，仍不可行。瓶颈：对每个候选位置都在全部段上重扫交集。

### 3.2 核心观察：最优毯子的左端必与某段起点对齐

![贪心模型：毯子左端对齐某段起点](images/bw78_q3_greedy_model.svg)

**贪心断言**：存在最优解，其毯子左端 $L$ 恰为某个 $tiles[i][0]$。

**直觉**：固定毯子「盖到哪些白色砖」这一集合不变，毯子在数轴上平移直到左端碰到集合中最左白砖（它必属某段的起点或内部）——若左端落在段内部，说明左端左侧（毯外）是空白，右移毯子不会丢任何白砖；持续右移到左端撞上段起点时覆盖集合不减。故只需枚举 $T$ 个「左端对齐 $l_i$」的位置（$T \le 5 \times 10^4$）。

对每个 $L = l_i$，毯子覆盖 $[L, L + carpetLen - 1]$，与**排序后**的段求交：设 $R = L + carpetLen - 1$，由于段互不重叠且已按左端排序，与毯子相交的段是连续的一段区间 $i \dots j$，其中

- 第 $i \dots j-1$ 段**整段**落在毯内（右端 $< l_j \le R$，见 §4）；
- 第 $j$ 段**整段或部分**：交集为 $[l_j, \min(R, r_j)]$。

「找 $j$」用**二分**（最后一个 $l_j \le R$ 的段）；「第 $i \dots j-1$ 段长度和」用**前缀和** $O(1)$ 取。单次判定 $O(\log T)$，总计 $O(T \log T)$。

### 3.3 算法流程

![算法流程：排序 → 前缀和 → 枚举起点 → 二分右端](images/bw78_q3_algorithm_flow.svg)

```text
1. tiles 按左端点升序排序
2. pre[0] = 0；pre[i+1] = pre[i] + (r_i − l_i + 1)     # 前 i+1 段的白砖总数
3. ans = 0
4. 对 i = 0 .. T−1：
       L = tiles[i][0]，R = L + carpetLen − 1
       二分找最大的 j 使 tiles[j][0] ≤ R（j ≥ i 恒成立）
       若 j == i：cover = min(R, r_i) − L + 1          # 只有第 i 段有交集
       否则：   cover = pre[j] − pre[i]                # 第 i..j−1 段整段
                    + min(R, r_j) − l_j + 1            # 第 j 段整段或部分
       ans = max(ans, cover)
5. 返回 ans
```

### 3.4 示例演算

![示例演算：示例 1 的五个候选位置](images/bw78_q3_walkthrough.svg)

以示例 1（排序后段为 `[1,5],[10,11],[12,18],[20,25],[30,32]`，前缀和 $pre = [0,5,7,14,20,23]$，$carpetLen = 10$）为例：

| 枚举段 $i$ | $L$ | $R = L+9$ | $j$（最后 $l_j \le R$） | 覆盖计算 | cover |
|-----------|-----|-----------|------------------------|----------|-------|
| 0 | 1 | 10 | 1（$l_1 = 10 \le 10$） | $pre[1]-pre[0] = 5$ + $\min(10,11)-10+1 = 1$ | 6 |
| 1 | 10 | 19 | 2（$l_2 = 12 \le 19$，$l_3 = 20 > 19$） | $pre[2]-pre[1] = 2$ + $\min(19,18)-12+1 = 7$ | **9** |
| 2 | 12 | 21 | 3（$l_3 = 20 \le 21$） | $pre[3]-pre[2] = 7$ + $\min(21,25)-20+1 = 2$ | 9 |
| 3 | 20 | 29 | 3 | $j = i$：$\min(29,25)-20+1 = 6$ | 6 |
| 4 | 30 | 39 | 4 | $j = i$：$\min(39,32)-30+1 = 3$ | 3 |

最大值 $9$ ✓（枚举段 1 与段 2 都达到）。注意段 1 行里 $j = 2$ 而 $r_2 = 18 < R = 19$：第 2 段整段在毯内，$\min$ 取到 $r_j$——两种情况（整段 / 部分）被 $\min(R, r_j)$ 统一处理。

## 4. 算法细节

1. **排序后段的自然性质**：段互不重叠，按左端点排序后右端点也严格递增（$r_i < l_{i+1}$）。于是「$l_j \le R$」的段构成前缀 $0..j$，二分的单调性成立；且第 $i \dots j-1$ 段右端 $r_{j-1} < l_j \le R$，**整段必在毯内**——这是 $pre[j] - pre[i]$ 直接可用的依据。
2. **二分的对象**：找最后一个满足 $l_j \le R$ 的下标 $j$（上取整模板）。$j \ge i$ 恒成立（$l_i = L \le R$，因 $carpetLen \ge 1$），故 $j == i$ 只是「交集段只有第 $i$ 段」的退化情形，公式统一为 $\min(R, r_i) - L + 1$。
3. **第 $j$ 段的两种情况统一**：整段在毯内（$r_j \le R$，$\min$ 取 $r_j$，得整段长）与部分在毯内（$r_j > R$，$\min$ 取 $R$，得 $R - l_j + 1$）。**切勿**写成 $pre[j+1] - pre[i]$——它默认第 $j$ 段整段在毯内，当 $r_j > R$ 时会把毯外的白砖也数进去（经典 WA，见 §8.1）。
4. **溢出**：$cover$ 上界 $\min(carpetLen, 10^9) \le 10^9$，`int` 勉强够；但 $R = L + carpetLen - 1$ 可达 $2 \times 10^9$ 超出 `int`，C++ 中 $L$、$R$、中间量用 `long long` 最稳（Python 无虑）。
5. **滑动窗口替代**：二分可换双指针——$i$ 递增时 $R$ 递增、$j$ 单调不降，均摊 $O(T)$；总复杂度从 $O(T \log T)$ 降到 $O(T)$（排序仍 $O(T \log T)$ 主导）。两种写法等价，二分版更直白。
6. **毯子可以盖空白**：毯子不必贴满白砖——左端对齐段起点后右侧可以伸出很远（如段 3 行 $R = 29$ 超过 $r_3 = 25$），空白部分白白浪费但无害；最优解自然不会让「最后一段之后全空白」的情形胜出。

## 5. 正确性证明

**引理 1（对齐化简）**：对任意毯子位置 $[L, L + len - 1]$，存在位置 $[L', L' + len - 1]$（$L'$ 为某段起点或 $L' \ge L$）使其覆盖的白砖数不减少。

**证明**：设原位置覆盖的白砖集合为 $S$（数轴上离散点的集合）。若 $L$ 不是 $S$ 中最左白砖所在段的起点，考察 $L$ 右移一格的新位置：丢掉的白砖至多为位置 $L$ 处的白砖（若 $L \in S$），新覆盖的为位置 $L + len$ 处的白砖。若 $L \notin S$（毯子左端在空白处），右移不丢任何白砖。持续右移直到 $L$ 撞上某白砖或某段起点：(a) 若先撞上段起点 $l_i$ 且 $l_i$ 是 $S$ 最左元素或其左邻段仍在毯内——此时左端在段起点上，得证；(b) 若左端每一步都在空白上，右移到「左端 = 某段起点」时覆盖集合不变或增大（毯子右端同右移，多盖右侧）。形式化地：取 $L' = \max\{l_i : l_i \le L + len - 1,\ l_i \text{ 是 } S \text{ 最左元素所在段起点}\}$，则 $L' \ge L$（该段起点不超过其内部白砖位置），毯子 $[L', L'+len-1]$ 至少盖住 $S$ 中从 $L'$ 起的全部白砖——而 $S$ 中在 $L'$ 左侧的白砖不存在（$L'$ 取的就是最左白砖所在段起点）。若 $S$ 为空，任何位置（含某段起点）都不劣。∎

**引理 2（覆盖公式）**：毯子 $[L, R]$ 与排序后段 $i \dots j$（$j$ 为最后一个 $l_j \le R$ 的段）的覆盖数 $= \sum_{t=i}^{j-1}(r_t - l_t + 1) + \big(\min(R, r_j) - l_j + 1\big)$，其中 $L = l_i$。

**证明**：与毯子相交的段 $t$ 满足 $l_t \le R$ 且 $r_t \ge L$。由 $l_t$ 升序，$l_t \le R$ 的段是前缀 $0..j$；由 $L = l_i$ 与段不重叠（$r_t < l_{t+1}$），$r_t \ge L$ 推出 $t \ge i$（$t < i$ 时 $r_t < l_i = L$）。故相交段恰为 $i..j$。对 $t < j$：$r_t < l_{t+1} \le l_j \le R$ 且 $l_t \ge l_i = L$，整段 $\subseteq [L, R]$，交集长 $r_t - l_t + 1$。对 $t = j$：交集为 $[\max(l_j, L), \min(r_j, R)] = [l_j, \min(r_j, R)]$（$l_j \ge l_i = L$），长 $\min(R, r_j) - l_j + 1$（非负：$l_j \le R$ 保证）。求和即得。∎

**定理（算法正确性）**：枚举 $L = l_i$（$i = 0..T-1$）按引理 2 计算覆盖数取最大，结果为全局最优。

**证明**：**最优可达**：设最优毯子覆盖 $K$ 块白砖。若 $K = 0$，任何枚举位置（覆盖 $\ge 0$）都不劣。若 $K > 0$，由引理 1 存在左端对齐某段起点 $l_{i^*}$ 的毯子覆盖 $\ge K$；左端对齐的毯子覆盖数以段起点为下标唯一参数化，算法枚举了全部 $T$ 个起点，含 $i^*$，由引理 2 计算的覆盖数准确，故算法结果 $\ge K$。**不越界**：算法的每个候选都是合法毯子位置，覆盖数由引理 2 精确计算，故结果 $\le$ 最优。二者夹逼，算法结果 $=$ 最优。∎

## 6. 复杂度分析

- **时间**：$O(T \log T)$。排序 $O(T \log T)$；前缀和 $O(T)$；枚举 $T$ 个起点、每个一次二分 $O(\log T)$。（双指针版可将枚举降到 $O(T)$，但排序仍是主导项。）
- **空间**：$O(T)$。前缀和数组（排序若原地则不计额外空间，Python `sort` 原地、C++ `sort` 原地）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maximumWhiteTiles(vector<vector<int>>& tiles, int carpetLen) {
        sort(tiles.begin(), tiles.end());              // 按左端点升序
        int T = tiles.size();
        vector<long long> pre(T + 1, 0);               // pre[i] = 前 i 段白砖总数
        for (int i = 0; i < T; ++i)
            pre[i + 1] = pre[i] + (tiles[i][1] - tiles[i][0] + 1);
        int ans = 0;
        for (int i = 0; i < T; ++i) {                  // 毯子左端贴 tiles[i] 起点
            long long L = tiles[i][0], R = L + carpetLen - 1;
            int lo = i, hi = T - 1, j = i;             // 二分：最后一个 l_j ≤ R
            while (lo <= hi) {
                int mid = (lo + hi) / 2;
                if (tiles[mid][0] <= R) { j = mid; lo = mid + 1; }
                else hi = mid - 1;
            }
            long long cover;
            if (j == i)                                // 只有第 i 段有交集
                cover = min(R, (long long)tiles[i][1]) - L + 1;
            else                                       // 第 i..j−1 段整段 + 第 j 段
                cover = pre[j] - pre[i]
                        + (min(R, (long long)tiles[j][1]) - tiles[j][0] + 1);
            ans = max(ans, (int)cover);
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maximumWhiteTiles(self, tiles: list[list[int]], carpetLen: int) -> int:
        tiles.sort()                                   # 按左端点升序
        T = len(tiles)
        pre = [0] * (T + 1)                            # pre[i] = 前 i 段白砖总数
        for i, (l, r) in enumerate(tiles):
            pre[i + 1] = pre[i] + (r - l + 1)
        ans = 0
        for i in range(T):                             # 毛毯左端贴 tiles[i] 起点
            L = tiles[i][0]
            R = L + carpetLen - 1
            lo, hi, j = i, T - 1, i                    # 二分：最后一个 l_j ≤ R
            while lo <= hi:
                mid = (lo + hi) // 2
                if tiles[mid][0] <= R:
                    j = mid
                    lo = mid + 1
                else:
                    hi = mid - 1
            if j == i:                                 # 只有第 i 段有交集
                cover = min(R, tiles[i][1]) - L + 1
            else:                                      # 第 i..j−1 段整段 + 第 j 段
                cover = pre[j] - pre[i] \
                        + (min(R, tiles[j][1]) - tiles[j][0] + 1)
            ans = max(ans, cover)
        return ans
```

> 💡 两份代码均通过官方示例（`9`、`2`），并与「枚举数轴上每个候选左端点 × 逐段求交集」的暴力对拍：C++ 500 组 + Python 1500 组随机数据（含毯子长于全部段、毯子短于单段、段间大间隔、单段边界），另有 5 万段 × $10^9$ 长度的大规模性能验证（0.06 s），`mismatch = 0`。

## 8. 边界情况与易错点

1. **第 $j$ 段溢出是头号陷阱**：找到 $j$ 后用 $pre[j+1] - pre[i]$ 会把第 $j$ 段毯外部分也计入。正确写法是 $pre[j] - pre[i] + \min(R, r_j) - l_j + 1$，让 $\min$ 处理「整段 / 部分」两态。对拍中首版就在此翻车（示例 1 输出 13 而非 9）。
2. **$j == i$ 的退化**：毯子整段落进第 $i$ 段内部（$R < l_{i+1}$），公式退化为 $\min(R, r_i) - L + 1$，恰好是毯长 $carpetLen$（$r_i \ge R$ 时）。别漏这个分支，也别把它并进通式算出负数。
3. **$R$ 的溢出**：$L + carpetLen - 1$ 最高 $2 \times 10^9 - 1$，超 `int`。C++ 里 $L$、$R$ 声明为 `long long`（或先转再加减）。
4. **毯子远长于所有段**：如 $carpetLen = 10^9$ 盖住全部，答案 = 白砖总数；枚举 $i = 0$ 时 $j = T-1$、$\min$ 取 $r_{T-1}$，公式自动正确。
5. **毯子短于最小段**：任何位置至多盖 $carpetLen$ 块；$j == i$ 分支给出 $\min(R, r_i) - L + 1 \le carpetLen$，自动封顶。
6. **段已按任意顺序输入**：必须先排序——二分的单调性与「$i..j-1$ 整段在毯内」都依赖左端升序。
7. **起点枚举 vs 端点枚举**：也只需考虑「左端对齐段起点」，不需要「右端对齐段终点」另枚举一遍——把每段镜像后与原问题等价，起点枚举已覆盖（对称性由引理 1 的右移论证保证）。
