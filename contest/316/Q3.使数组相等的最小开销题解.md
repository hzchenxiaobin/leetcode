# LeetCode 使数组相等的最小开销 题解

## 1. 题目概述

- **标题 / 题号**：使数组相等的最小开销（#2448，hard）
- **链接**：https://leetcode.cn/problems/minimum-cost-to-make-array-equal/
- **来源**：LeetCode 第 316 场周赛 Q3
- **难度**：困难
- **标签**：贪心、数组、排序、前缀和、二分查找

**题意**：给定长度均为 $n$ 的正整数数组 $\text{nums}$ 与 $\text{cost}$。一次操作可将 $\text{nums}$ 中**任意**元素 $+1$ 或 $-1$，对第 $i$ 个元素操作一次的开销为 $\text{cost}[i]$，操作次数不限。求使 $\text{nums}$ 中所有元素**相等**的**最少总开销**。

**约束**：

- $1 \le n \le 10^5$
- $1 \le \text{nums}[i],\ \text{cost}[i] \le 10^6$
- 测试用例保证输出不超过 $2^{53}-1$

> 💡 本题在本仓库另有[每日题解 2448](../../solution/2401-2500/2448_使数组相等的最小开销.md)：侧重**加权中位数的闭式定位**、前缀和 $O(1)$ 求值公式与凸优化 / 三分扩展。本篇按周赛复盘视角展开，主推赛场上最不容易写错的**增量递推（斜率扫描）**解法，并补全凸性、转移公式的完整证明与边界清单，两篇互为印证。

## 2. 示例

**示例 1**

```text
输入：nums = [1,3,5,2], cost = [2,3,1,14]
输出：8
解释：全部变成 2：1→2 操作 1 次开销 2；3→2 操作 1 次开销 3；5→2 操作 3 次开销 1×3 = 3。
合计 2 + 3 + 3 = 8，为最小开销。
```

**示例 2**

```text
输入：nums = [2,2,2,2,2], cost = [4,2,8,1,3]
输出：0
解释：所有元素已经相等，无需操作。
```

**示例 3**（自构造，覆盖「无视 cost 取普通中位数」的关键陷阱）

```text
输入：nums = [1,5,8], cost = [10,1,1]
输出：11
解释：最优目标是 1（元素 1 独占 10/12 的权重）：
  f(1) = 0 + 1×4 + 1×7 = 11；f(5) = 10×4 + 0 + 1×3 = 43；f(8) = 10×7 + 1×3 + 0 = 73。
  若无视 cost 取普通中位数 5，开销 43，接近最优值的 4 倍。
```

## 3. 解题思路

### 3.1 暴力思路：枚举目标值逐个求代价

设全体元素最终都变成目标值 $t$，则总开销是

$$
f(t) = \sum_{i} \text{cost}[i]\cdot|\text{nums}[i] - t|
$$

且这个下界可以取到——把每个元素直接一步步挪到 $t$ 即可。于是问题变为求 $f(t)$ 的最小值。

最朴素的做法是枚举候选目标并逐个求值。这里有一个必须先想清楚的问题：**候选集取多大？** 笼统地扫值域 $[1, 10^6]$ 是 $O(nV) \approx 10^{11}$，必 TLE；而由后文引理 2，$f$ 的极小点必然落在某个 $\text{nums}[i]$ 上，候选集只需取 $\text{nums}$ 的现有值——$n$ 个候选、每个 $O(n)$ 求值，总计 $O(n^2)$。对 $n = 10^5$ 约 $10^{10}$ 次乘加，仍然 TLE。

> 💡 **赛场识别路径**：「使所有元素相等 + 每次移动有单价」一眼就是 462「最少移动次数使数组元素相等 II」的**带权版**——462 的答案是普通中位数，本题把每个元素的移动次数乘上 $\text{cost}[i]$，最优目标随之升级为**加权中位数**。即使没背过「加权中位数」这个名词，只要想到「$f(t)$ 是凸的、从左往右挪目标值每一步的代价变化有规律」，就能现场推出下面的增量解法。

### 3.2 核心观察：$f(t)$ 是分段线性凸函数

![核心观察：f(t) 是分段线性凸函数，最小值在斜率变号处](images/wc316_q3_convex_slope.svg)

把数对 $(\text{nums}[i], \text{cost}[i])$ 按 $\text{nums}$ 升序排序，记排序后的值为 $v_0 \le v_1 \le \dots \le v_{n-1}$、权重为 $w_0, \dots, w_{n-1}$、总权重 $W = \sum w_i$。将元素看作数轴上带权重的点，考察 $t$ 从左到右扫过时 $f(t)$ 的形态：

- **相邻断点之间**（$v_k < t < v_{k+1}$）：左侧每个点距离增加、右侧每个点距离减少，$f$ 是线性函数，斜率为
  $$
  s_k = \underbrace{\textstyle\sum_{i \le k} w_i}_{L_k\ \text{（左权和）}} - \underbrace{\textstyle\sum_{i \ge k+1} w_i}_{R_k\ \text{（右权和）}}
  $$
- **跨过断点 $v_j$**：该点从「右侧」翻到「左侧」，斜率跳增 $2w_j$——每跨过一个点，斜率加两倍它的权重。
- 于是斜率从最左的 $-W$ **单调不减**地升到最右的 $+W$：$f$ 是**分段线性凸函数**，最小值出现在**斜率由负转正**的位置。

以示例 1 为例（$v = [1,2,3,5]$，$w = [2,14,3,1]$，$W = 20$）：斜率序列为 $-20 \xrightarrow{\text{跨}1} -16 \xrightarrow{\text{跨}2} +12 \xrightarrow{\text{跨}3} +18 \xrightarrow{\text{跨}5} +20$，在 $t = 2$ 处变号，$f(2) = 8$ 即答案。

斜率变号的条件「$L_k \ge R_k$」等价于「累计权重 $2 L_k \ge W$」，即**累计权重首次过半**——这个位置正是**加权中位数**。它是 462 普通中位数（所有 $w_i = 1$）的自然推广：权重大的点「更重」，会把最优目标拉向自己（示例 3 中权重 10 的点直接把目标锚定在 1）。

### 3.3 算法流程：增量递推（斜率扫描）

![算法流程：排序 → 起步 → 逐断点增量右移 → 取最小](images/wc316_q3_increment_flow.svg)

不求闭式、也不背前缀和公式，赛场上最稳的写法是把目标值从 $v_0$ 开始逐断点右移，维护增量：

1. **排序配对**：$(v_i, w_i)$ 按 $v$ 升序。
2. **起步**：以 $t = v_0$ 求初始代价 $f(v_0) = \sum_i w_i (v_i - v_0)$，一次 $O(n)$；此时左权和 $L = w_0$，右权和 $R = W - w_0$。
3. **递推**：目标从 $v_k$ 右移到 $v_{k+1}$（步长 $d = v_{k+1} - v_k$），代价变化为
   $$
   \Delta_k = f(v_{k+1}) - f(v_k) = (L_k - R_k)\cdot d
   $$
   更新 $f \mathrel{+}= \Delta_k$、$\text{ans} \leftarrow \min(\text{ans}, f)$，再把 $w_{k+1}$ 从右侧划入左侧：$L \mathrel{+}= w_{k+1}$，$R \mathrel{-}= w_{k+1}$。
4. 扫完全部断点输出 $\text{ans}$。

$\Delta_k$ 恰是凸函数在区间 $(v_k, v_{k+1})$ 上的「斜率 × 步长」：$L < R$ 时右移在省钱，$L \ge R$ 后右移只会更贵——$f$ 先降后升，`min` 自动选中谷底。事实上首次 $L \ge R$ 后即可提前终止（此后 $\Delta \ge 0$），但 $O(n)$ 全扫与提前终止同阶，全扫少一个分支、更不易写错。

### 3.4 示例演算

![示例演算：目标值逐断点右移，f 先降后升](images/wc316_q3_walkthrough.svg)

以示例 1 演算（$v = [1,2,3,5]$，$w = [2,14,3,1]$，$W = 20$）。表中「斜率 / 步长」指**到下一个断点**的转移量，$L$ 为含当前断点的累计权重：

| 目标 $t$ | 左和 $L$ | 右和 $R$ | 斜率 $L-R$ | 步长 $d$ | $f(t)$ |
|---------|---------|---------|-----------|---------|--------|
| 1 | 2 | 18 | $-16$ | 1 | 24 |
| **2** | **16** | **4** | $+12$ | 1 | **8 ✓ 最小** |
| 3 | 19 | 1 | $+18$ | 2 | 20 |
| 5 | 20 | 0 | — | — | 56 |

- **起步**：$f(1) = 14\times 1 + 3\times 2 + 1\times 4 = 24$。
- **$1 \to 2$**：$\Delta = (2-18)\times 1 = -16$，$f(2) = 8$；累计权重 $2 \to 16$ 首次过半（$\ge W/2 = 10$），斜率由 $-16$ 翻正为 $+12$——谷底。
- **$2 \to 3$**：$\Delta = (16-4)\times 1 = +12$，$f(3) = 20$；**$3 \to 5$**：$\Delta = (19-1)\times 2 = +36$，$f(5) = 56$。

全程最小 $\text{ans} = 8$，与「全部变成 2」的手算开销 $2+3+3=8$ 一致。

## 4. 算法细节

1. **排序时权重必须绑定**：对 $(\text{nums}[i], \text{cost}[i])$ 整体排序（`vector<pair>` 或 `sorted(zip(...))`），切勿只排 $\text{nums}$ 而丢了 $\text{cost}$ 的对应关系。
2. **$L$ 的语义与更新时机**：$L$ 是「已越过断点一侧」的权重和。循环不变式：处理转移 $v_k \to v_{k+1}$ **之前**，$L = L_k$、$R = R_k$。因此代码顺序必须是**先**用当前 $L, R$ 算 $\Delta$，**再**把 $w_{k+1}$ 并入 $L$——顺序写反会把「自身权重」提前计入左和（见 §8 第 5 条）。
3. **转移公式的三种身份**是同一件事的三个面：逐项差分（引理 3 的证明）、凸函数区间斜率（引理 1）、加权中位数判定（$L \ge R \iff$ 累计权重过半）。理解任一种都能独立写出正确代码。
4. **不必显式定位中位数**：增量法全扫断点，`min` 自动选中谷底；想省掉后半程，可在首次 $L \ge R$ 后 `break`；想一次定位，可在断点数组上**二分**找首个 $L \ge R$ 的位置（这正是标签里 Binary Search 的来历），或用前缀和公式 $O(1)$ 求值——即[每日题解 2448](../../solution/2401-2500/2448_使数组相等的最小开销.md)的做法。三者复杂度同为 $O(n\log n)$（排序主导），按熟练度任选。
5. **溢出上界估算**：$f(v_0) \le \sum w_i \cdot (v_{n-1} - v_0) \le 10^5 \times 10^6 \times 10^6 = 10^{17}$。虽然题目保证**答案** $\le 2^{53}-1 \approx 9\times 10^{15}$，但**中间量** $f(v_0)$ 完全可能更大（把全部权重堆在离 $v_0$ 最远处），C++ 必须全程 `long long`，乘法 `(long long)w * d` 显式转换；`double` 的 53 位尾数也存不下 $10^{17}$ 级中间量，别用浮点。
6. **重复值天然安全**：$v_k = v_{k+1}$ 时 $d = 0$、$\Delta = 0$，该步是空转，无需去重或特判。

## 5. 正确性证明

以下设 $v_0 \le \dots \le v_{n-1}$ 为排序后的值、$w_i$ 为对应权重、$W = \sum w_i$、$L_k = \sum_{i \le k} w_i$、$R_k = W - L_k$。

**引理 1（区间线性与斜率公式）**：对任意满足 $v_k < t < v_{k+1}$ 的 $t$，
$$
f(t) = \sum_{i \le k} w_i (t - v_i) + \sum_{i \ge k+1} w_i (v_i - t)
$$
是 $t$ 的线性函数，斜率 $s_k = L_k - R_k$。

**证明**：在该开区间内，对 $i \le k$ 有 $v_i \le v_k < t$，故 $|v_i - t| = t - v_i$；对 $i \ge k+1$ 有 $v_i \ge v_{k+1} > t$，故 $|v_i - t| = v_i - t$。代入 $f$ 的定义即得关于 $t$ 的一次表达式，其斜率为 $\sum_{i \le k} w_i - \sum_{i \ge k+1} w_i = L_k - R_k$。∎

**引理 2（凸性与极小点位置）**：$f$ 连续且分段线性凸；且存在某个 $k$ 使 $f(v_k) = \min_{t \in \mathbb{R}} f(t)$。

**证明**：$f$ 是 $n$ 个连续函数 $w_i|v_i - t|$ 之和，故连续。相邻区间斜率之差 $s_{k+1} - s_k = (L_{k+1} - R_{k+1}) - (L_k - R_k) = 2w_{k+1} > 0$（相等断点对应长度为 0 的退化区间，不影响），故斜率沿 $t$ 轴单调不减，$f$ 凸。再看极小点位置：设 $t^*$ 是 $f$ 的一个全局极小点。若 $t^*$ 落在某开区间 $(v_k, v_{k+1})$ 内部，则该区间斜率必为 $0$（否则沿下降方向移动可更小），此时区间端点 $v_k, v_{k+1}$ 也取到相同的最小值；若 $t^*$ 本身是断点则直接得证。两种情况都推出：存在 $k$ 使 $f(v_k)$ 等于全局最小值。∎

**引理 3（转移公式）**：对 $0 \le k < n-1$，
$$
f(v_{k+1}) - f(v_k) = (L_k - R_k)\,(v_{k+1} - v_k)
$$

**证明**：记 $d = v_{k+1} - v_k \ge 0$，逐项考察 $|v_i - v_{k+1}| - |v_i - v_k|$。若 $i \le k$：$v_i \le v_k \le v_{k+1}$，差 $= (v_{k+1} - v_i) - (v_k - v_i) = d$；若 $i \ge k+1$：$v_i \ge v_{k+1} \ge v_k$，差 $= (v_i - v_{k+1}) - (v_i - v_k) = -d$。按权重求和：$\Delta = d\cdot L_k - d\cdot R_k = (L_k - R_k)\,d$。∎

**定理**：算法返回 $\min_{t \in \mathbb{R}} f(t)$，即最少总开销。

**证明**：先证算法维护的 $f_k$ 满足 $f_k = f(v_k)$（归纳法）。$k = 0$：起步循环直接计算 $\sum_i w_i(v_i - v_0) = f(v_0)$。归纳步：由 §4 第 2 条的循环不变式，转移发生前 $L = L_k$、$R = R_k$，代码执行 $f \mathrel{+}= (L-R)\cdot d$，由引理 3 得 $f_{k+1} = f(v_{k+1})$。故 $\text{ans} = \min_{0 \le k < n} f(v_k)$。再由引理 2，断点集中存在全局极小点，故 $\text{ans} = \min_{t} f(t)$。最后，「所有元素都挪到 $t$」的方案开销恰为 $f(t)$，且任何使元素相等的方案最终都落在某个共同值 $t$ 上、开销不少于 $f(t)$（每元素至少移动 $|v_i - t|$ 次），故 $f$ 的最小值就是答案。∎

> 💡 引理 2 同时回答了 §3.1 的候选集问题：为什么只需枚举 $\text{nums}$ 中的值——因为极小点总能取在断点上，「最优目标不在数组里」的担心是多余的。

## 6. 复杂度分析

- **时间复杂度**：$O(n \log n)$。排序主导；起步求 $f(v_0)$ 为 $O(n)$，$n-1$ 次转移每次 $O(1)$，合计 $O(n)$。
- **空间复杂度**：$O(n)$，存储排序后的数对数组（Python 的 `sorted(zip(...))` 同为 $O(n)$）。
- **对照**：暴力枚举候选为 $O(n^2)$，$n = 10^5$ 必 TLE；值域三分为 $O(n \log V)$，每次求值 $O(n)$ 且整数三分边界易错（见每日题解第 5 节）；加权中位数定位 + 前缀和 $O(1)$ 求值与本解法同阶，是同一凸性的不同用法。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long minCost(vector<int>& nums, vector<int>& cost) {
        int n = nums.size();
        vector<pair<int, int>> a(n);
        for (int i = 0; i < n; ++i) a[i] = {nums[i], cost[i]};
        sort(a.begin(), a.end());                    // 按 nums 升序，权重绑定

        long long W = 0, f = 0;
        for (int i = 0; i < n; ++i) {                // 起步：t = v0
            W += a[i].second;
            f += (long long)a[i].second * (a[i].first - a[0].first);
        }
        long long L = a[0].second, R = W - L, ans = f;
        for (int k = 0; k + 1 < n; ++k) {            // 目标右移 vk -> vk+1
            long long d = a[k + 1].first - a[k].first;
            f += (L - R) * d;                        // 斜率 × 步长（先算再吸收）
            ans = min(ans, f);
            L += a[k + 1].second;
            R -= a[k + 1].second;
        }
        return ans;
    }
};
```

> 💡 全程 `long long`：$f$ 与 $\Delta$ 的上界 $10^{17}$（§4 第 5 条）。`(long long)` 强转放在乘法前，防 `int × int` 中途溢出。$n = 1$ 时循环不执行、$f = 0$，天然返回 0。

### Python

```python
class Solution:
    def minCost(self, nums: List[int], cost: List[int]) -> int:
        a = sorted(zip(nums, cost))                  # 按 nums 升序，权重绑定
        W = sum(w for _, w in a)
        f = sum(w * (v - a[0][0]) for v, w in a)     # 起步：t = v0
        L, R = a[0][1], W - a[0][1]
        ans = f
        for k in range(len(a) - 1):                  # 目标右移 vk -> vk+1
            d = a[k + 1][0] - a[k][0]
            f += (L - R) * d                         # 斜率 × 步长（先算再吸收）
            ans = min(ans, f)
            L += a[k + 1][1]
            R -= a[k + 1][1]
        return ans
```

> 💡 Python 大整数无溢出之忧，逻辑与 C++ 完全对齐；`zip + sorted` 自动按元组首键排序。

## 8. 边界情况与易错点

1. **32 位溢出（本题最大 WA 点）**：中间量上界 $f(v_0) \le 10^{17}$，超出 `int32` 五个数量级，也超出 `double` 的精确整数范围 $2^{53}-1$——题目只保证**答案**不超过 $2^{53}-1$，不保证中间的 $f(v_0)$ 不超。C++ 全程 `long long`，乘法显式强转。
2. **候选集取错**：不必扫 $1 \sim 10^6$ 全值域（$O(nV)$ 必 TLE）；也不必担心最优目标不在 $\text{nums}$ 里——引理 2 保证极小点总可取在断点上。
3. **普通中位数陷阱**：无视 $\text{cost}$ 取排序中位数，示例 3 即反例（43 对 11）。加权后「中位数」变为累计权重首次过半的位置。
4. **加权平均数陷阱**：$\frac{\sum w_i v_i}{W}$ 是 $L_2$（平方代价）的最优目标，不是 $L_1$ 的。反例：$\text{nums} = [1,11]$，$\text{cost} = [1,2]$，加权平均 $\approx 7.67$，$f(8) = 13 > f(11) = 10$。
5. **$L/R$ 更新时机写反**：必须先用当前 $L, R$ 算 $\Delta$ 再吸收 $w_{k+1}$。若先吸收，示例 1 第一步会算出 $(16-4)\times 1 = +12$ 而非 $-16$，方向整个反掉、直接错过谷底。
6. **忘记乘步长 $d$**：写成 `f += L - R` 只在断点等距时碰巧正确；示例 1 的 $3 \to 5$ 间距为 2，漏乘会把 $f(5)$ 算成 38 而非 56。
7. **$n = 1$ / 全相等**：答案 0。$n=1$ 时递推循环不执行；全相等时所有 $d = 0$——均无需特判。
8. **重复值**：$v_k = v_{k+1}$ 时 $d = 0$、$\Delta = 0$，空转无害，不必去重。
9. **提前终止是可选优化**：首次 $L \ge R$ 后可 `break`（此后 $\Delta \ge 0$），但与全扫同阶；赛场上少写一个分支更稳。

**延伸思考**：若把绝对值换成平方（$L_2$ 代价 $f(t) = \sum w_i(v_i - t)^2$），凸性仍在，极小点变为**加权平均数** $t^* = \frac{\sum w_i v_i}{W}$，求导为零即得闭式——$L_1$ 对应中位数（鲁棒）、$L_2$ 对应均值（最小二乘），同一优化框架下不同范数给出不同统计量。若最优目标被限制在给定集合 $S$ 中取值，则需在 $S$ 上二分 / 双指针定位距加权中位数最近的允许值。值域上的三分搜索与断点二分亦是凸性的两种用法，细节见[每日题解 2448 第 5 节](../../solution/2401-2500/2448_使数组相等的最小开销.md)。
