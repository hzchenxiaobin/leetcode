# LeetCode 使数组相似的最少操作次数 题解

## 1. 题目概述

- **标题 / 题号**：使数组相似的最少操作次数（#2449，hard）
- **链接**：https://leetcode.cn/problems/minimum-number-of-operations-to-make-arrays-similar/
- **来源**：LeetCode 第 316 场周赛 Q4
- **难度**：困难
- **标签**：贪心、数组、排序

**题意**：给定两个长度相等的正整数数组 $\text{nums}$ 和 $\text{target}$。一次操作可以选择两个**不同**的下标 $i, j$，同时执行 $\text{nums}[i] \mathrel{+}= 2$、$\text{nums}[j] \mathrel{-}= 2$——相当于把面额 $2$ 从一个元素搬给另一个元素。若两个数组中每个值出现的频率相同（互为**多重集**），则称它们**相似**。求把 $\text{nums}$ 变得与 $\text{target}$ 相似的最少操作次数。数据保证一定可达。

**约束**：

- $n = \text{nums.length} = \text{target.length}$，$1 \le n \le 10^5$
- $1 \le \text{nums}[i], \text{target}[i] \le 10^6$
- $\text{nums}$ 一定能变得与 $\text{target}$ 相似

> 💡 本题在本仓库另有[每日题解 2449](../../solution/2401-2500/2449_使数组相似的最少操作次数.md)：侧重**不变量的直觉提炼**与「mod 不变量」的扩展。本篇按周赛复盘视角展开，主推「**下界 + 构造**」的完整证明链：先证任何方案的操作数 $\ge D/4$，再给出一送一收的构造恰好达到下界，并附「整体排序配对」的反例与边界清单，两篇互为印证。

```text
- 选 i=1, j=2 → nums = [10,14,2]，排序后为 [2,10,14]，与 target 相似
```


## 3. 解题思路

### 3.1 暴力思路：枚举「谁变成谁」

「相似」意味着最终 $\text{nums}$ 是 $\text{target}$ 的某个排列，因此需要确定一个置换 $\pi$：第 $k$ 个元素最终变成 $\text{target}_{\pi(k)}$，再算出实现该置换的最少操作数。朴素枚举全部置换是 $O(n!)$；即使只算单个置换的成本，$n \le 10^5$ 也完全不可行。

> 💡 转机在于认清操作的本质：它不关心具体下标顺序，只关心**全局需要多少次「一处 $+2$、一处 $-2$」的成对搬运**。只要找到「总配对差」最小的置换，操作数就能**直接算出**——问题塌缩成带约束的最优匹配。

### 3.2 核心观察一：奇偶不变 ⇒ 配对必须「同类」

一次操作把面额 $2$ 从一个元素搬给另一个元素，立刻得到两条不变量：

1. **每个元素的奇偶性永不变**：$\pm 2$ 不改变奇偶；
2. **总和不变**：$+2$ 与 $-2$ 成对抵消。

第 1 条给出了匹配的硬约束：**$\text{nums}$ 中的奇数只能对上 $\text{target}$ 中的奇数，偶数只能对上偶数**（多重集意义上两类个数分别相等——这正是题目「保证可达」隐藏的前提）。第 2 条保证配对差之和为零（见 §4），从而使答案必为整数。

![奇偶不变量概念图](images/2449_parity_invariant_concept.svg)

> ⚠️ **赛场第一大坑**：对两个数组**整体**排序后按位配对。反例（自构造）：$\text{nums} = [1,4]$，$\text{target} = [3,2]$。整体排序后配对 $1 \leftrightarrow 2$、$4 \leftrightarrow 3$，奇偶错配，差为奇数，$\pm 2$ 永远无法归零；而正确做法是**先按奇偶分流，再在类内排序配对**，得到 $D = 4$、答案 $1$：

![分流配对反例与正解](images/2449_sort_match_counterexample.svg)

### 3.3 核心观察二：排序配对最优，一次操作抵 4 的总差

**类内为什么排序？** 固定奇偶类后，问题变为：两个等长序列如何配对使 $\sum_k |a_k - b_k|$ 最小？答案是**双双升序后按位配对**，交换论证见 §5 引理 3。

**操作数怎么算？** 设最优配对下的差值 $d_k = a_k - b_k$，总差 $D = \sum_k |d_k|$。

- **下界**：一次操作恰好让**一个**元素 $+2$、**一个**元素 $-2$，因此 $\sum_k |d_k|$ 每步至多下降 $4$（送方靠近 2、收方靠近 2），而终态 $\sum_k |d_k| = 0$，故操作数 $\ge D / 4$。
- **构造**：只要还存在盈余（$d_k > 0$）与亏损（$d_l < 0$），就取一盈一亏执行一次操作（盈方 $-2$、亏方 $+2$），$\sum_k |d_k|$ **恰好**下降 4。$D/4$ 步后全部归零。

两个方向夹逼，答案就是 $D/4$（$D$ 必被 4 整除，见 §4）。

![下界与构造](images/2449_lower_bound_units.svg)

**算法流程**（核心只有三步）：

```text
1. 按 x % 2 把 nums、target 各分成两组（奇数类 / 偶数类）
2. 四组分别升序排序
3. 答案 = Σ |同类配对差| ÷ 4
```

### 3.4 示例演算

**示例 1**：$\text{nums} = [8,12,6]$，$\text{target} = [2,14,10]$。全为偶数 → 单一类。排序配对：$6 \leftrightarrow 2$（差 4，送出 2 个单位）、$8 \leftrightarrow 10$（差 2，接收 1 个单位）、$12 \leftrightarrow 14$（差 2，接收 1 个单位）。$D = 8$，答案 $= 8 / 4 = 2$。

![示例1演算](images/2449_example_walkthrough.svg)

**示例 2**：$\text{nums} = [1,2,5]$，$\text{target} = [4,1,3]$。

| 类 | nums（排序） | target（排序） | 配对差 |
|----|----|----|----|
| 奇 | $[1, 5]$ | $[1, 3]$ | $0,\ 2$ |
| 偶 | $[2]$ | $[4]$ | $2$ |

$D = 0 + 2 + 2 = 4$，答案 $= 1$。对应的实际操作：元素 $2$ 送一个单位给元素 $5$（$i=2, j=1$），得 $[1,4,3]$。

## 4. 算法细节

1. **分流**：用 `x & 1` 把 `nums` 拆成 `a[1]`（奇）、`a[0]`（偶），`target` 同理拆成 `b[1]`、`b[0]`。题目保证可达 ⇒ 两类元素个数分别相等，无需特判。
2. **排序配对**：四组分别升序后按下标配对，累加 $D = \sum_p \sum_i |a_p[i] - b_p[i]|$。
3. **为什么 $D$ 一定能被 4 整除**：
   - 同类配对 ⇒ 每个 $d_k$ 为偶数；
   - 总和守恒 ⇒ $\sum_k d_k = \sum \text{nums} - \sum \text{target} = 0$；
   - 于是 $D = \sum |d_k| = 2 \sum_{d_k > 0} d_k$，而每个正 $d_k$ 均为偶数，故 $4 \mid D$，且 $D/4 = \sum_{d_k > 0} d_k / 2$ 恰是「盈余方需送出的单位总数」。
4. **口径换算**（最易错处）：$D$ 是按面额 1 计的总差；一次操作搬走**一个面额 2 的单位**，同时让送、收双方各自向目标靠近 2，等价于 $\sum |d|$ 每步 $-4$。若误以为每次操作只让总差 $-2$（只看到 $-2$ 的一侧），就会得到 $D/2$ 的两倍错误答案。
5. **溢出**：最坏 $n = 10^5$、每个差接近 $2 \times 10^6$，$D$ 可达 $2 \times 10^{11}$，超出 32 位范围。C++ 的累加变量与返回值都必须用 `long long`；Python 天然支持大整数。

## 5. 正确性证明

**引理 1（不变量）**：任何操作序列保持：① 每个元素的奇偶性；② 所有元素之和。特别地，若 $\text{nums}$ 可变得与 $\text{target}$ 相似，则 $\sum \text{nums} = \sum \text{target}$，且两数组的奇数、偶数个数分别相等。

**证明**：① $+2$ 与 $-2$ 均不改变奇偶性，逐元素传递即得；② 每次操作 $+2$ 与 $-2$ 成对出现，总和不变。相似意味着多重集相等，故总和、奇（偶）元素个数在两个数组中一致，均由不变量传递而来。∎

**引理 2（下界）**：设 $D^{\ast} = \min_\pi \sum_k \bigl|\text{nums}_k - \text{target}_{\pi(k)}\bigr|$，最小值取遍所有**同奇偶**配对 $\pi$。则任何把 `nums` 变得与 `target` 相似的操作序列长度 $m \ge D^{\ast}/4$。

**证明**：设操作结束后数组为 $S$，其多重集与 $\text{target}$ 相同，故存在双射 $\pi$ 使 $S_k = \text{target}_{\pi(k)}$；由引理 1①，$S_k$ 与 $\text{nums}_k$ 奇偶相同，故 $\pi$ 是同奇偶配对。记 $d_k = \text{nums}_k - \text{target}_{\pi(k)}$，则 $\sum_k d_k = 0$（引理 1②）。把「面额 2」记作一个单位：一次操作恰使**一个**元素获得一个单位，故 $m$ 次操作中全体元素的毛接收量（单位数）为 $m$；而净增量为正的元素至少要净接收

$$\sum_{e_k > 0} e_k = \sum_{d_k < 0} \frac{|d_k|}{2} = \frac{D_\pi}{4}$$

个单位（其中 $e_k = -d_k / 2$，第二个等号用到 $\sum_k d_k = 0$）。于是 $m \ge D_\pi / 4 \ge D^{\ast}/4$。∎

**引理 3（排序配对最优）**：在同一个奇偶类内，把两个序列分别升序排序后按位配对，总差最小。

**证明**（交换论证）：先证核心不等式：对 $a_1 \le a_2$、$b_1 \le b_2$，有

$$|a_1 - b_1| + |a_2 - b_2| \le |a_1 - b_2| + |a_2 - b_1|,$$

且两边之差恰为 $2 \times \bigl[\min(a_2, b_2) - \max(a_1, b_1)\bigr]^+ \ge 0$（即两段区间 $[a_1,a_2]$ 与 $[b_1,b_2]$ 重叠长度的两倍；按四个端点的 6 种本质位置关系逐一验证即可，均为恒等变形）。

据此，若某配对中存在两对「交叉」（数轴上区间相交且端点交错），把这两对解交叉（改为按序配对），由上述不等式总差不增，且配对中的逆序对严格减少；有限步后得到无交叉的配对。而类内无交叉的双射唯一，正是「双双升序按位配对」，故其总差最小。∎

**定理**：答案 $= D^{\ast}/4$，其中 $D^{\ast}$ 为奇偶分流后、类内升序按位配对的总差。

**证明**：

- **下界**：由引理 2，任何可行方案 $m \ge D^{\ast}/4$。
- **可达**：取引理 3 的最优配对，记 $d_k = \text{nums}_k - \text{target}_{\pi(k)}$（均为偶数，$\sum_k d_k = 0$）。只要不全为零，就存在 $d_k \ge 2$ 与 $d_l \le -2$，对这两个元素执行一次操作（$d_k$ 方为 $j$：$-2$；$d_l$ 方为 $i$：$+2$）。一正一负必为不同元素，$i \ne j$ 自动满足；每步 $\sum |d|$ 恰减 4，且每个元素单调趋向自己的目标值，数值始终介于 $\min(\text{nums}_k, \text{target}_k) \ge 1$ 与 $\max(\text{nums}_k, \text{target}_k)$ 之间，无越界之忧。恰好 $D^{\ast}/4$ 步后 $\sum|d| = 0$，即每个元素等于配对目标，多重集相等。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \log n)$。奇偶分流 $O(n)$，四组排序合计 $O(n \log n)$，逐对累加 $O(n)$；排序是唯一瓶颈，$n \le 10^5$ 毫无压力。
- **空间复杂度**：$O(n)$。四个分流数组共存放 $2n$ 个元素（排序递归栈另计 $O(\log n)$）。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    long long makeSimilar(vector<int>& nums, vector<int>& target) {
        vector<int> a[2], b[2];
        for (int x : nums) a[x & 1].push_back(x);
        for (int x : target) b[x & 1].push_back(x);
        long long d = 0;
        for (int p = 0; p < 2; p++) {
            sort(a[p].begin(), a[p].end());
            sort(b[p].begin(), b[p].end());
            for (int i = 0; i < (int)a[p].size(); i++)
                d += abs(a[p][i] - b[p][i]);
        }
        return d / 4;
    }
};
```

### Python

```python
class Solution:
    def makeSimilar(self, nums: List[int], target: List[int]) -> int:
        def split(arr):
            return sorted(x for x in arr if x % 2 == 0), sorted(x for x in arr if x % 2 == 1)

        (a0, a1), (b0, b1) = split(nums), split(target)
        d = sum(abs(x - y) for x, y in zip(a0, b0)) + sum(abs(x - y) for x, y in zip(a1, b1))
        return d // 4
```

## 8. 边界情况与易错点

1. **溢出（本题最大的坑）**：$D$ 最大约 $2 \times 10^{11}$，C++ 用 `int` 累加必然溢出；不仅返回值是 `long long`，累加变量也必须是 `long long`。Python 无此问题。
2. **忘记奇偶分流**：整体排序配对在样例里可能「侥幸」正确（示例 1 恰好全偶数），但奇偶混合时必然出错。反例见 §3.2：$\text{nums}=[1,4]$、$\text{target}=[3,2]$，整体配对得差 $1+1=2$，$2/4$ 不是整数，直接暴露错误。
3. **除以 2 而非除以 4**：一次操作同时完成「一送一收」，$\sum|\text{差}|$ 每步下降 4 而不是 2；除以 2 得到两倍的错误答案。
4. **$n = 1$**：无法选两个不同下标，无法操作。题目保证可达，此时必有 $\text{nums} = \text{target}$，答案 0，算法自然得出。
5. **「相似」≠「逐位相等」**：只要求多重集相等，允许元素自由「换位」，这正是排序配对合法性的来源。若误以为要逐位相等，会错误地按原下标配对。
6. **中间值越界？**：构造中每个元素单调趋向目标，数值始终落在 $[\min(\text{nums}_k, \text{target}_k), \max(\text{nums}_k, \text{target}_k)]$ 内，不会经过 0 或负数；题目对中间值也无约束。
7. **输入不保证可达时**：需先检查「总和相等 ∧ 奇数个数相等」再配对，否则类内个数不相等会导致配对越界。本题由题目保证，无需处理。
