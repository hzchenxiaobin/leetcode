# LeetCode 最短无序连续子数组 题解

## 1. 题目概述

- **标题 / 题号**：最短无序连续子数组（#581，medium）
- **链接**：https://leetcode.cn/problems/shortest-unsorted-continuous-subarray/
- **来源**：LeetCode 第 32 场周赛 Q1
- **难度**：中等
- **标签**：栈、贪心、数组、双指针、排序、单调栈

**题意**：给定整数数组 `nums`，找出最短的**连续子数组**，使得仅把它按升序（非降序）排序后，整个数组就变成非降序。返回这个最短子数组的长度；若原数组本来就有序，返回 `0`。注意排序的是**子数组**，不能移动区间之外的元素。

**约束**：

- $1 \le \text{nums.length} \le 10^4$
- $-10^5 \le \text{nums}[i] \le 10^5$
- 进阶要求：设计 $O(n)$ 的解法（官方数据只到 $10^4$，但 Q1 就该一步到位）

## 2. 示例

**示例 1**

```text
输入：nums = [2,6,4,8,10,9,15]
输出：5
解释：只需对 [6, 4, 8, 10, 9] 升序排序，整个数组即为升序；
      长度为 4 或更短的区间都无法让整串有序。
```

**示例 2**

```text
输入：nums = [1,2,3,4]
输出：0
解释：数组已经升序，无需排序任何子数组。
```

**示例 3**

```text
输入：nums = [1]
输出：0
解释：单元素数组天然有序，返回 0。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有区间 $[i,j]$，把它排序后检查整个数组是否非降：区间 $O(n^2)$ 个、每个 $O(n\log n)$，总计 $O(n^3\log n)$。更省一点的做法是**排序后逐位比对**：把 `nums` 复制一份升序排列，从左找第一个不同位置、从右找最后一个不同位置，两者之间就是答案，$O(n\log n)$。

排序法本身**是对的**，但有两个问题：一是 $O(n\log n)$ 没过掉进阶要求；二是它把「哪些位置**必须**动」这个结构信息完全丢掉了——而本期 Q1 真正想考的正是这个观察。

### 3.2 核心观察：只需两个「越界点」

![三段划分与左右越界点](images/wc32_q1_region_boundaries.svg)

最终数组必须非降，而区间外的元素**值不变、位置不变**。于是答案区间 $[i,j]$ 之外的部分一定是「原数组的一个有序前缀 + 原数组的一个有序后缀」。据此把注意力放在两类**越界点**上：

- **右界 $r$**：若位置 $p$ 左侧存在比它**更大**的数，即 $\text{nums}[p] < \max(\text{nums}[0..p-1])$，那么 $p$ 光靠「不动」是不可能变有序的，必被某个区间覆盖。
- **左界 $l$**：若位置 $p$ 右侧存在比它**更小**的数，即 $\text{nums}[p] > \min(\text{nums}[p+1..n-1])$，同理必被覆盖。

取最右、最左的那两个位置，即得边界：

$$r = \max\{\,p \mid \text{nums}[p] < \max(\text{nums}[0..p-1])\,\}, \qquad l = \min\{\,p \mid \text{nums}[p] > \min(\text{nums}[p+1..n-1])\,\}$$

两个判据都是「一遍扫描 + 一个滚动极值」，所以两遍 $O(n)$ 就能定出 $l, r$。**关键结论**是：答案长度恰为 $r-l+1$（$l$ 不存在即返回 $0$），既不需要真的排序，也不需要枚举区间。

### 3.3 算法流程：两遍扫描

![两遍线性扫描的流程](images/wc32_q1_two_pass_flow.svg)

1. **第一遍（左 → 右）求 $r$**：令 $mx = \text{nums}[0]$、$r = -1$；对 $i = 1 \ldots n-1$，若 $\text{nums}[i] < mx$ 则 $r = i$，否则 $mx = \text{nums}[i]$。由于下标递增，最后留下的必然是**最右**的越界点。
2. **剪枝**：若 $r = -1$，说明每个数都不小于其左侧最大值，数组本就非降，直接返回 `0`（此时第二遍没有必要）。
3. **第二遍（右 → 左）求 $l$**：令 $mn = \text{nums}[n-1]$、$l = n-1$；对 $i = n-2 \ldots 0$，若 $\text{nums}[i] > mn$ 则 $l = i$，否则 $mn = \text{nums}[i]$。倒序扫描中最后留下的必然是**最左**的越界点。
4. **返回** $r - l + 1$。区间 $[l,r]$ 内部的元素一个都不用挑，整段排序即可。

> 💡 与常见写法的区别：另一套模板是「先剥掉有序前缀与有序后缀，再在中段求 min/max，最后向两侧扩张」。它是正确的，但要额外维护三四个变量、容易漏边界；本写法只需两个滚动极值，且第 2 步的剪枝天然免费。

### 3.4 示例演算

![示例 [2,6,4,8,10,9,15] 的两遍走查](images/wc32_q1_walkthrough.svg)

以 `nums = [2,6,4,8,10,9,15]` 为例：

| 遍 | 被更新的下标 | 触发原因 | 最终结果 |
|----|--------------|----------|----------|
| 左 → 右 | $i=2$，随后 $i=5$ | $4<6$；$9<10$ | $r=5$（取最右） |
| 右 → 左 | $i=4$，随后 $i=1$ | $10>9$；$6>4$ | $l=1$（取最左） |

故长度为 $5-1+1=5$，对应子数组 $[6,4,8,10,9]$。可以验证：再短的区间都会留下某个「左边有更大值」或「右边有更小值」的位置在区间外，从而无法有序。

## 4. 算法细节

1. **哨兵初值**：$r=-1$ 表示「不存在越界点」，$l=n-1$ 只是占位——只要 $r \ne -1$，第二遍必定会至少更新一次 $l$（因为存在一对 $u<p$ 且 $\text{nums}[u]>\text{nums}[p]$，$u$ 处必然触发 $l$ 的更新），所以不会误用占位值。
2. **`if/else` 不能拆成两个独立 `if`**：`nums[i] < mx` 与「更新 `mx`」是互斥分支。若拆开并把第二个写成 `mx = nums[i]`，遇到 `nums[i] < mx` 时会把 `mx` 压低，之后所有比较都失真；即便侥幸写成 `mx = max(mx, nums[i])`，也丢掉了「要么记录越界、要么推进极值」的互斥语义。
3. **滚动极值只需一个变量**：$mx$ 是「严格左侧的最大值」，不需要数组；$mn$ 同理是「严格右侧的最小值」。这决定了额外空间是 $O(1)$ 而不是 $O(n)$。
4. **等号的方向**：判据用的是严格不等号 `nums[i] < mx` / `nums[i] > mn`。重复元素（如 `[1,2,2,3]`）等于左侧最大值时完全有序，不能算越界——写成 `<=` 会把有序数组误判成无序。
5. **另一种 $O(n)$ 写法：双向单调栈**。从左扫维护一个「下标单调、值递增」的栈，遇到 $\text{nums}[i] < \text{nums}[\text{栈顶}]$ 就不断弹栈并用弹出下标更新 $l$；再镜像地从右扫维护递减栈更新 $r$。思路同样是「找出被逆序对波及的位置」，但要 $O(n)$ 额外空间、常数更大，作为对照了解即可。
6. **排序法与本题的关系**：排序后逐位比对的第一个/最后一个差异位置，恰好就是本文的 $l$ 与 $r$——两种视角等价，但排序法要多花 $O(n\log n)$ 与被修改的副本。

## 5. 正确性证明

约定 $\min(\varnothing)=+\infty$、$\max(\varnothing)=-\infty$。

**引理 1（可行区间的充要条件）**：区间 $[i,j]$ 合法，当且仅当同时满足

1. $\text{nums}[0..i-1]$ 非降；
2. $\text{nums}[j+1..n-1]$ 非降；
3. $\max(\text{nums}[0..i-1]) \le \min(\text{nums}[i..j])$ 且 $\max(\text{nums}[i..j]) \le \min(\text{nums}[j+1..n-1])$。

**证明**：

($\Rightarrow$) 排序后整个数组非降，且区间外的值不变。对中段排序后，位置 $i$ 上放的是 $\min(\text{nums}[i..j])$，位置 $j$ 上放的是 $\max(\text{nums}[i..j])$。

- 若 (1) 失败，存在 $p<p+1\le i-1$ 使 $\text{nums}[p]>\text{nums}[p+1]$，两点都在区间外，值不变，与整体非降矛盾；
- 若 (3) 前半失败，取区间外的 $u<i$ 使 $\text{nums}[u]=\max(\text{nums}[0..i-1])>\min(\text{nums}[i..j])$（即最终的 $\text{nums}[i]$），则最终数组在 $u<i$ 处出现逆序，矛盾。

由对称性（把数组反转）得到 (2) 与 (3) 后半。

($\Leftarrow$) 三段各自非降；(3) 保证「前缀最大 $\le$ 中段最小」与「中段最大 $\le$ 后缀最小」，因此拼接后整体非降。∎

**引理 2（任何合法区间都必须覆盖 $l$ 与 $r$）**：若 $[i,j]$ 合法，则 $i \le l$ 且 $j \ge r$。

**证明**：设 $l$ 存在，取 $q>l$ 使 $\text{nums}[q]=\min(\text{nums}[l+1..n-1])<\text{nums}[l]$。反设 $i>l$，则 $l<i$，$l$ 落在前缀内。

- 若 $q<i$：$l<q$ 且 $\text{nums}[l]>\text{nums}[q]$，两者都在前缀内，违反引理 1 的 (1)。
- 若 $i\le q\le j$：则 $\min(\text{nums}[i..j])\le \text{nums}[q]<\text{nums}[l]\le \max(\text{nums}[0..i-1])$，违反引理 1 的 (3) 前半。
- 若 $q>j$：则 $\max(\text{nums}[i..j])\le \min(\text{nums}[j+1..n-1])\le \text{nums}[q]<\text{nums}[l]\le \max(\text{nums}[0..i-1])\le \min(\text{nums}[i..j])$，与 $\min\le\max$ 矛盾。

三种情形皆不成立，故 $i\le l$。把数组反转后同样论证（此时 $l$ 与 $r$ 角色互换）得 $j\ge r$。∎

**引理 3（$[l,r]$ 自身合法）**：当 $r\ne -1$ 时 $l<r$ 且 $[l,r]$ 满足引理 1 的三个条件。

**证明**：由 $l$ 的最小性，对任意 $p<l$ 有 $\text{nums}[p]\le \min(\text{nums}[p+1..n-1])\le \text{nums}[p+1]$，故前缀非降，条件 (1) 成立（$l=0$ 时前缀为空，自动成立）；特别地取 $p=l-1$（$l>0$ 时）得 $\text{nums}[l-1]\le\min(\text{nums}[l..n-1])\le\min(\text{nums}[l..r])$，而前缀非降说明 $\max(\text{nums}[0..l-1])=\text{nums}[l-1]$，故 (3) 前半成立。同理由 $r$ 的最大性，对任意 $p>r$ 有 $\text{nums}[p]\ge\max(\text{nums}[0..p-1])\ge\text{nums}[p-1]$，后缀非降且 $\min(\text{nums}[r+1..n-1])=\text{nums}[r+1]\ge\max(\text{nums}[0..r])\ge\max(\text{nums}[l..r])$，(2)(3) 后半成立。

又 $r\ne-1$ 意味着存在 $u<p$ 使 $\text{nums}[u]>\text{nums}[p]$，于是 $u$ 满足 $l$ 的判据（右侧有更小的数），得 $l\le u<p\le r$，故 $l<r$。∎

**定理**：算法返回的值等于最短合法子数组的长度。

**证明**：若 $r=-1$，对每个 $p\ge 1$ 都有 $\text{nums}[p]\ge\max(\text{nums}[0..p-1])\ge\text{nums}[p-1]$，数组非降，最短长度为 $0$，与返回值一致。否则由引理 3，$[l,r]$ 合法，长度 $r-l+1$ 可达；由引理 2，任何合法区间都包含 $[l,r]$，长度不小于 $r-l+1$。两者夹逼即得答案为 $r-l+1$（最短区间由此唯一）。∎

## 6. 复杂度分析

- **时间**：$O(n)$。第一遍从左到右 $n-1$ 次比较，第二遍从右到左 $n-1$ 次比较，每次均为常数操作；无排序、无嵌套循环。若 $r=-1$ 还会提前返回，实际更少。
- **空间**：$O(1)$。只用了 `mx`、`mn`、`l`、`r` 四个整型变量，没有复制数组、没有栈或哈希表。

## 7. 参考代码

### C++

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    int findUnsortedSubarray(vector<int>& nums) {
        int n = nums.size();
        if (n <= 1) return 0;

        // 第一遍：从左往右，用前缀最大值定位最右越界点 r
        int r = -1, mx = nums[0];
        for (int i = 1; i < n; ++i) {
            if (nums[i] < mx) r = i;   // 左边有更大的数，必须入区间
            else mx = nums[i];         // 否则抬高前缀最大值
        }
        if (r == -1) return 0;         // 整体已升序

        // 第二遍：从右往左，用后缀最小值定位最左越界点 l
        int l = n - 1, mn = nums[n - 1];
        for (int i = n - 2; i >= 0; --i) {
            if (nums[i] > mn) l = i;   // 右边有更小的数，必须入区间
            else mn = nums[i];         // 否则压低后缀最小值
        }
        return r - l + 1;
    }
};
```

### Python

```python
class Solution:
    def findUnsortedSubarray(self, nums: list[int]) -> int:
        n = len(nums)
        if n <= 1:
            return 0

        # 第一遍：从左往右，用前缀最大值定位最右越界点 r
        r = -1
        mx = nums[0]
        for i in range(1, n):
            if nums[i] < mx:
                r = i                 # 左边有更大的数，必须入区间
            else:
                mx = nums[i]          # 否则抬高前缀最大值
        if r == -1:
            return 0                  # 整体已升序

        # 第二遍：从右往左，用后缀最小值定位最左越界点 l
        l = n - 1
        mn = nums[n - 1]
        for i in range(n - 2, -1, -1):
            if nums[i] > mn:
                l = i                 # 右边有更小的数，必须入区间
            else:
                mn = nums[i]          # 否则压低后缀最小值

        return r - l + 1
```

## 8. 边界情况与易错点

1. **已升序 / 单元素**：`[1,2,3,4]`、`[1]` 都必须返回 `0`。靠 $r=-1$ 的剪枝统一处理，不要用「$l,r$ 都没更新」之类的双重判断，容易在 $n=1$ 时越界访问 `nums[1]`。
2. **逆序数组**：`[5,4,3,2,1]` 中每个位置都越界，$l=0$、$r=n-1$，答案是 $n$。此时两遍扫描的结果必须覆盖整段，别把上界写成 $n-1$。
3. **重复元素**：判据必须是严格不等号。`[1,2,2,3]` 返回 `0`，`[2,2,1]` 返回 `3`（$l=0,r=2$）。若误用 `<=` / `>=`，会把相等元素当成逆序。
4. **局部极小值位于中间**：`[1,3,2,4]` 的 $r$ 只在 $i=2$ 更新，$l$ 只在 $i=1$ 更新，答案为 `2`；不要以为「边界一定贴着数组端点」。
5. **元素跳跃造成的隐性越界**：`[1,4,2,3]` 中 $i=3$ 的值 `3` 虽与 `2` 有序，但仍小于左侧最大值 `4`，$r$ 必须更新到 `3`。这正是「用滚动最大值而非相邻比较」的原因。
6. **下标与长度混淆**：返回 $r-l+1$，不是 $r-l$。事实上答案非零时必有 $l<r$（见引理 3），因此最小可能答案是 `2`（如 `[2,1]`），不会出现 `1`。
