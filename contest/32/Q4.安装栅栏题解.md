# LeetCode 安装栅栏 题解

## 1. 题目概述

- **标题 / 题号**：安装栅栏（#587，hard）
- **链接**：https://leetcode.cn/problems/erect-the-fence/
- **来源**：LeetCode 第 32 场周赛 Q4
- **难度**：困难
- **标签**：几何、数组、数学、凸包、多边形

**题意**：花园里有 $n$ 棵树，坐标为 `trees[i] = [xi, yi]`。用一根首尾相接、绷紧的绳子把所有树围起来（长度最短），返回**恰好贴在这根绳子上**的每一棵树。

关键转换：最短的封闭绳套一定就是**点集的凸包**，所以答案 = 凸包**边界上**的所有点。它包含两类：

1. 凸包的**顶点**（拐角处的树）；
2. 落在凸包某条**边内部**的树（三点共线、中间那棵）。

第 2 类正是本题与「只求凸包顶点」的模板题的唯一区别，也是绝大多数人 WA 的地方。

**约束**：

- $1 \le n \le 3000$
- `trees[i].length == 2`，$0 \le x_i, y_i \le 100$
- 所有树的位置互不相同

> 💡 坐标只有 $0\sim100$，网格最多 $101 \times 101$ 个格点，但 $n$ 达 $3000$，解法仍应按 $n$ 的规模设计，目标 $O(n \log n)$。

## 2. 示例

**示例 1**

```text
输入：trees = [[1,1],[2,2],[2,0],[2,4],[3,3],[4,2]]
输出：[[1,1],[2,0],[3,3],[2,4],[4,2]]
解释：5 棵树贴绳，(2,2) 被围在内部；(3,3) 落在边 (4,2)-(2,4) 的中间，
      它不是拐角，但同样贴着绳子，必须返回。
```

**示例 2**

```text
输入：trees = [[1,2],[2,2],[4,2]]
输出：[[4,2],[2,2],[1,2]]
解释：三棵树共线，凸包退化成线段，绳子就是它，三个点都在绳子上。
```

返回顺序不限：判题按点集比较，示例输出中的顺序只是官方给出的一种排列。

## 3. 解题思路

### 3.1 暴力思路

最直白的判定是「支撑线」：树 $p$ 在围栏上 $\iff$ 存在一条过 $p$ 的直线，使所有树都在它的同一侧。枚举 $p$ 与另一个点确定方向，再检查其余点：$O(n^3)$，$n = 3000$ 时约 $2.7\times 10^{10}$ 次运算，必然超时。换成「对每个点判断是否严格在凸包内部」（枚举三角形）是 $O(n^4)$，更慢。真正的瓶颈是：**同一个凸包被重复计算了 $O(n)$ 次**。

### 3.2 核心观察：绳子 = 凸包边界

![围栏就是凸包的边界，边上的树也要返回](images/wc32_q4_convex_hull_concept.svg)

- 任何闭合绳套围出的区域都是**包含全部树的凸集**，其周长不小于凸包周长；把绳子沿凸包边界绷紧即可取到最小值。所以绳子 = 凸包边界。
- 「恰好位于围栏周边」= 在凸包边界上，即**顶点 + 边内部的共线点**，不是只取顶点。
- 于是问题变成：求凸包的完整边界点集，用 **Andrew 单调链**（Monotone Chain）$O(n \log n)$ 两遍扫描即可。

### 3.3 算法流程：Andrew 单调链

![叉积符号决定弹栈还是保留](images/wc32_q4_turn_direction.svg)

先按 $(x, y)$ 字典序排序，然后**从左到右**扫一遍得到下凸壳，再**从右到左**扫一遍得到上凸壳。扫描时维护一个栈，记

$$cross(A,B,C) = (B_x - A_x)(C_y - A_y) - (B_y - A_y)(C_x - A_x)$$

它等于三角形 $ABC$ 有向面积的两倍，符号说明 $C$ 落在有向直线 $AB$ 的哪一侧；扫描时把栈尾两点当作 $A,B$、新点当作 $C$：

| $cross(A,B,C)$ | 几何含义 | 操作 |
| --- | --- | --- |
| $> 0$ | 左转，$B$ 在弦 $AC$ 下方（下凸壳该有的形状） | 保留 $B$ |
| $< 0$ | 右转，$B$ 在弦 $AC$ 上方（$B$ 被「顶」出去） | 弹出 $B$ |
| $= 0$ | 三点共线，$B$ 正好在边 $AC$ 上 | **保留 $B$**（本题关键） |

流程：

```text
sort(points)                              // 按 (x, y) 字典序
for dir in [正序, 逆序]:                    // 第 1 遍：下凸壳；第 2 遍：上凸壳
    H ← 空栈
    for P in dir:
        while |H| ≥ 2 and cross(H[-2], H[-1], P) < 0: pop
        push P
    chain[dir] ← H
answer ← dedup(chain[正序] ∪ chain[逆序])
```

### 3.4 示例演算

![示例 1 的下凸壳与上凸壳走查](images/wc32_q4_monotone_chain_walkthrough.svg)

排序后：$(1,1),(2,0),(2,2),(2,4),(3,3),(4,2)$。

**下凸壳（左 → 右）**

| 步 | 当前点 | 栈内容 | 判定 |
| --- | --- | --- | --- |
| 1 | $(1,1)$ | $(1,1)$ | 入栈 |
| 2 | $(2,0)$ | $(1,1),(2,0)$ | 入栈 |
| 3 | $(2,2)$ | $(1,1),(2,0),(2,2)$ | $cross = 2 > 0$，保留 |
| 4 | $(2,4)$ | $\dots,(2,4)$ | $cross = 0$，共线，保留 |
| 5 | $(3,3)$ | $(1,1),(2,0),(3,3)$ | 连弹 $(2,4),(2,2)$，再判 $cross = 4 > 0$ |
| 6 | $(4,2)$ | $(1,1),(2,0),(4,2)$ | 弹出 $(3,3)$，$cross = 4 > 0$ |

**上凸壳（右 → 左）**

| 步 | 当前点 | 栈内容 | 判定 |
| --- | --- | --- | --- |
| 1 | $(4,2)$ | $(4,2)$ | 入栈 |
| 2 | $(3,3)$ | $(4,2),(3,3)$ | 入栈 |
| 3 | $(2,4)$ | $\dots,(2,4)$ | $cross = 0$，共线，**$(3,3)$ 因此留在链上** |
| 4 | $(2,2)$、$(2,0)$ | $\dots,(2,2),(2,0)$ | $cross = 2 > 0$ 保留；$cross = 0$ 共线，也保留 |
| 5 | $(1,1)$ | $(4,2),(3,3),(2,4),(1,1)$ | 弹掉 $(2,0),(2,2)$，$cross = 4 > 0$ |

并集去重：$(1,1),(2,0),(4,2),(3,3),(2,4)$ —— 与官方输出一致（顺序不同），$(2,2)$ 被两条链共同淘汰。

## 4. 算法细节

1. **排序键必须是 $(x, y)$ 全序**：只按 $x$ 排序时，同 $x$ 的点（垂直边）顺序不确定，链的凸性会被破坏。全序后最左点、最右点唯一，垂直段上的点也相邻。
2. **弹栈条件是严格的 $cross < 0$**：写成 `cross <= 0` 会连共线点一起弹掉，示例 1 的 $(3,3)$、示例 2 的 $(2,2)$ 就丢了，这是本题第一号坑。
3. **两遍扫描共用同一份排序数组**：第二遍直接逆序遍历（逆序不等于升序，不要重新 `sort`）；「左右转」的视觉直觉会翻转，但复用同一个 $cross(A,B,C) < 0$ 判据即可，不必手动取反。
4. **结果必须去重**：两条链共享最左点与最右点；当最左（或最右）是一整条垂直边时，边上的点会同时出现在两条链里，用 `set` 合并最省事。
5. **整数叉积，零浮点误差**：坐标 $\le 100$，叉积上界约 $2 \times 10^4$，`int` 足够；若坐标放大到 $10^9$，差值相乘需改用 `long long`。
6. **$n \le 2$ 直接返回**：一个点或两个点时凸包退化为点/线段，提前返回能省掉「栈长为 1 时去重」的边界讨论，也让代码意图更清楚。

## 5. 正确性证明

**引理 1（下凸壳的转向性质）**：按下标把点集 $Q$ 的下凸壳边界点依次记为 $v_0, v_1, \dots, v_m$（$x$ 递增），则对任意 $0 < j < m$ 都有 $cross(v_{j-1}, v_j, v_{j+1}) \ge 0$。

**证明**：记 $f(x) = \min\{\,y : (x,y) \in conv(Q)\,\}$。$conv(Q)$ 是凸集，故 $f$ 是凸函数，其图像恰好就是下凸壳。凸函数的差商单调不减，即对 $x_1 < x_2 < x_3$ 有

$$\frac{f(x_2)-f(x_1)}{x_2-x_1} \le \frac{f(x_3)-f(x_2)}{x_3-x_2}$$

记相邻两段的斜率 $k_1, k_2$，直接计算可得恒等式 $cross(v_{j-1}, v_j, v_{j+1}) = (x_j - x_{j-1})(x_{j+1} - x_j)(k_2 - k_1)$，于是 $k_2 \ge k_1$ 当且仅当叉积 $\ge 0$。∎

**引理 2（弹栈安全）**：设栈是前缀点集 $P$ 的下凸壳，新点 $C$ 的字典序大于栈中所有点，栈尾两点为 $A, B$。若 $cross(A,B,C) < 0$，则 $B$ 不在 $conv(P \cup \{C\})$ 的下凸壳上。

**证明**：由排序保证 $x_A \le x_B \le x_C$ 且 $x_A < x_C$。$cross(A,B,C) < 0$ 等价于 $B$ 严格位于弦 $AC$ 的上方。由引理 1 的凸性，下凸壳的图像在弦 $AC$ 的下方（$A, C$ 都属于点集），故 $f(x_B) \le \text{弦}(x_B) < y_B$，即 $B$ 严格高于下凸壳图像，不在下边界上。$x_A = x_B$ 或 $x_B = x_C$ 的垂直段情形同理，只需把弦在 $x_B$ 处的值换成端点值。∎

**引理 3（第一遍扫描得到下凸壳）**：第一遍扫描结束后，栈中元素恰为 $conv(Q)$ 下边界上的全部点（含共线点）。

**证明**：对前缀长度归纳。设处理 $C$ 前栈为前缀 $P$ 的下凸壳。由于 $C$ 是字典序最大点，$P \cup \{C\}$ 的下凸壳只可能在链尾变化，形如「旧链的某个前缀 $+\,C$」，被删除的旧点必然在链尾连续。由引理 2，每次弹出删掉的点都不在下凸壳上，故删除安全（不变量：栈始终是下凸壳的子序列）。弹栈终止时栈中任意相邻三点叉积 $\ge 0$，又该链连接 $P \cup \{C\}$ 的最左点与最右点、且每个被跳过的点都被判定为在弦的上方，故它就是下凸壳。∎

**引理 4（上凸壳对称）**：第二遍逆序扫描得到的栈恰为 $conv(Q)$ 上边界上的全部点。

**证明**：作变换 $y \mapsto -y$，上边界即变换后的下边界，字典序逆序也变成正序，引理 3 直接给出结论。∎

**引理 5（并集就是边界）**：下边界与上边界的并集恰为凸包边界；最左、最右的垂直边上的点分别被两条链收录，不会遗漏。

**证明**：凸包边界由下边界与上边界拼成，二者只在最左点、最右点相交；若最左（最右）是一整条垂直边，该边同时属于两条链的端点集合。∎

**定理**：算法输出的点集恰为所有位于围栏上的树。

**证明**：($\subseteq$) 由引理 3、4，栈中每个点都在凸包边界上，绳子必然经过它。($\supseteq$) 设树 $p$ 在凸包边界上：若在下边界，则 $p = (x, f(x))$，由引理 3 被下链收录；若在上边界，由引理 4 被上链收录；垂直边由引理 5 覆盖。而最短封闭绳套正是凸包边界（任何闭合绳套围出的凸集包含全部树，其周长不小于凸包周长，且凸包边界可由绳子绷紧实现），故两集合相等。∎

## 6. 复杂度分析

- **时间**：$O(n \log n)$。排序 $O(n \log n)$；两遍扫描中每个点至多入栈一次、出栈一次，合计 $O(n)$；并集去重 $O(n \log n)$（哈希集合可到 $O(n)$ 期望）。
- **空间**：$O(n)$。排序副本、两个栈与去重集合都至多持有 $n$ 个点，无额外开销。

## 7. 参考代码

### C++

```cpp
#include <algorithm>
#include <set>
#include <vector>
using namespace std;

class Solution {
public:
    vector<vector<int>> outerTrees(vector<vector<int>>& trees) {
        vector<vector<int>> p = trees;
        sort(p.begin(), p.end());                 // 按 (x, y) 全序排序
        int n = p.size();
        if (n <= 2) return p;

        auto cross = [](const vector<int>& o, const vector<int>& a, const vector<int>& b) {
            return (a[0] - o[0]) * (b[1] - o[1]) - (a[1] - o[1]) * (b[0] - o[0]);
        };
        // 只有严格右转（叉积 < 0）才弹栈，共线的边界点必须保留
        auto halfChain = [&](bool reversed) {
            vector<vector<int>> h;
            for (int i = 0; i < n; ++i) {
                const vector<int>& cur = p[reversed ? n - 1 - i : i];
                while (h.size() >= 2 && cross(h[h.size() - 2], h[h.size() - 1], cur) < 0)
                    h.pop_back();
                h.push_back(cur);
            }
            return h;
        };

        vector<vector<int>> lo = halfChain(false), up = halfChain(true);
        set<vector<int>> s(lo.begin(), lo.end());  // 两链共享端点、垂直边上的点，需去重
        s.insert(up.begin(), up.end());
        return vector<vector<int>>(s.begin(), s.end());
    }
};
```

### Python

```python
from typing import List


class Solution:
    def outerTrees(self, trees: List[List[int]]) -> List[List[int]]:
        pts = sorted(set(map(tuple, trees)))          # 按 (x, y) 排序，顺带防御重复点
        if len(pts) <= 2:
            return [list(p) for p in pts]

        def cross(o, a, b):
            return (a[0] - o[0]) * (b[1] - o[1]) - (a[1] - o[1]) * (b[0] - o[0])

        def half_chain(seq):
            h = []
            for p in seq:
                # 只有「严格右转」才弹栈，共线的边界点必须保留
                while len(h) >= 2 and cross(h[-2], h[-1], p) < 0:
                    h.pop()
                h.append(p)
            return h

        hull = set(half_chain(pts)) | set(half_chain(pts[::-1]))
        return [list(p) for p in sorted(hull)]
```

## 8. 边界情况与易错点

![共线点是否返回取决于它是否在边界上](images/wc32_q4_collinear_degenerate.svg)

1. **全部共线**：如 `[[0,0],[1,0],[2,0],[3,0]]`，凸包退化成线段，四个点都在绳子上，必须全部返回；若把弹栈条件写成 `<= 0`，下链只剩两个端点。
2. **$n = 1$ 或 $n = 2$**：没有三点可判转向，凸包就是点/线段，提前返回原数组最稳，不必让去重逻辑兜底。
3. **共线点被误删**：示例 1 的 $(3,3)$ 落在边 $(4,2)-(2,4)$ 的内部、示例 2 的 $(2,2)$ 落在边 $(1,2)-(4,2)$ 的内部，它们都在边界上，必须保留——这是本题与标准凸包模板的唯一分歧。
4. **弹栈时漏掉上边界**：只做一遍下链会漏掉「只在逆序扫描中出现」的点（示例 1 的 $(2,4)$ 就只在上链里保留），必须是两遍扫描。
5. **同 $x$ 多点的排序**：排序键只用 $x$ 时，同列点的相对顺序由实现决定，垂直边可能被判成右转而误删，必须按 $(x, y)$ 排序。
6. **输出重复**：两链并在最左、最右点处重复，垂直边上的点更可能重复两次，不去重会直接判错。
7. **返回顺序**：判题按点集比较，任何顺序都行；不要为了「看起来像示例」再排序或反转，白费时间还可能引入 bug。
8. **别被坐标范围误导**：「坐标只有 $0 \sim 100$」不代表能暴力，$O(n^3)$ 在 $n = 3000$ 时是 $2.7\times10^{10}$；坐标范围只影响叉积量级，与复杂度无关。
