# LeetCode 两个字符串的删除操作 题解

## 1. 题目概述

- **标题 / 题号**：两个字符串的删除操作（#583，medium）
- **链接**：https://leetcode.cn/problems/delete-operation-for-two-strings/
- **来源**：LeetCode 第 32 场周赛 Q3
- **难度**：中等
- **标签**：字符串，动态规划，最长公共子序列

**题意**：给定两个字符串 `word1` 和 `word2`，每步可以删除**任意一个字符串中的一个字符**。问最少需要多少步，才能让两个字符串变得**完全相同**（都变成同一个串，可以是空串）。

**约束**：

- $1 \le \lvert \text{word1} \rvert, \lvert \text{word2} \rvert \le 500$
- `word1`、`word2` 仅由小写英文字母组成

## 2. 示例

**示例 1**

```text
输入：word1 = "sea", word2 = "eat"
输出：2
解释：删掉 word1 的 's' 与 word2 的 't'，两边都剩下 "ea"，共 2 步。
```

**示例 2**

```text
输入：word1 = "leetcode", word2 = "etco"
输出：4
解释：删掉 "leetcode" 中的 'l'、'e'、'd'、'e' 得到 "etco"，与 word2 相同，共 4 步；
      word2 无需删除任何字符，因为它整体就是公共子序列 "etco"。
```

**补充示例（自测用）**

```text
输入：word1 = "abc", word2 = "xyz"
输出：6
解释：没有任何公共字符，两边只能全部删空，共 3 + 3 = 6 步。
```

## 3. 解题思路

### 3.1 暴力思路

把「删除」看成对两个字符串各选一个子序列：枚举 `word1` 的全部 $2^{m}$ 个子序列与 `word2` 的全部 $2^{n}$ 个子序列，取最长的那对相同子序列，答案即 $m+n-2 \cdot \text{LCS}$。$m,n \le 500$ 时指数级完全不可行。

另一种暴力是 BFS 搜索「(word1 剩余, word2 剩余)」状态对，状态数是两个串子序列数量之积，同样爆炸。问题在于大量状态被重复访问——这正是**动态规划**的着力点。

### 3.2 核心观察：最优保留部分就是最长公共子序列

![只保留公共子序列，其余全删](images/wc32_q3_lcs_concept.svg)

**关键转化**：无论怎么删，最终两个字符串都等于同一个串 $S$。这个 $S$ 同时是 `word1` 和 `word2` 的**子序列**，所以 $S$ 是它们的**公共子序列**。

设 $\lvert S \rvert = k$，则删除步数必然为

$$\text{step}(S) = (m - k) + (n - k) = m + n - 2k$$

要让步数最少，就要让 $k$ 最大，即取 $k = \text{LCS}(word1, word2)$（最长公共子序列长度）。于是

$$\boxed{\text{答案} = m + n - 2 \cdot \text{LCS}(word1, word2)}$$

**为什么可以直接对「删除步数」做 DP？** 既然答案由 LCS 唯一决定，也可以不显式求 LCS，而是定义 $dp[i][j]$ 为「让 `word1` 的前 $i$ 个字符与 `word2` 的前 $j$ 个字符相同的最小步数」，直接做二维 DP。两种写法等价，直接 DP 少一次乘法、边界也更直观。

### 3.3 算法流程 / 状态转移

![状态转移与边界条件](images/wc32_q3_dp_flow.svg)

**状态**：$dp[i][j]$ = 使 `word1[0..i)` 与 `word2[0..j)` 相同所需的最小删除步数。

**边界**（一侧为空串时，只能把另一侧全删）：

$$dp[0][j] = j,\qquad dp[i][0] = i$$

**转移**（比较两串末字符，$1 \le i \le m$，$1 \le j \le n$）：

$$
dp[i][j] =
\begin{cases}
dp[i-1][j-1], & word1[i-1] = word2[j-1] \\[2pt]
\min\bigl(dp[i-1][j],\; dp[i][j-1]\bigr) + 1, & \text{否则}
\end{cases}
$$

**返回**：$dp[m][n]$。

第二条转移的语义很直白：末字符不同时，这一步必须删掉其中一个——删 `word1[i-1]` 对应 $dp[i-1][j]+1$，删 `word2[j-1]` 对应 $dp[i][j-1]+1$，取较小者。第一条转移说明末字符相同就都保留，它对两个串的「结尾」贡献是免费的，因此不多花任何一步。

### 3.4 示例演算

![word1=sea，word2=eat 的填表过程](images/wc32_q3_walkthrough.svg)

以 `word1 = "sea"`、`word2 = "eat"` 为例，逐行填表（行 = `word1` 前缀，列 = `word2` 前缀）：

| $i \backslash j$ | $\varepsilon$ | e | a | t |
|---|---|---|---|---|
| $\varepsilon$ | 0 | 1 | 2 | 3 |
| s | 1 | 2 | 3 | 4 |
| e | 2 | **1** | 2 | 3 |
| a | 3 | 2 | **1** | **2** |

- $dp[1][1]$：`s` 与 `e` 不等，取 $\min(dp[0][1], dp[1][0]) + 1 = \min(1,1)+1 = 2$。
- $dp[2][1]$：`e` 与 `e` 相等，直接取左上 $dp[1][0] = 1$，因为这一对字符免费保留。
- $dp[3][2]$：`a` 与 `a` 相等，取左上 $dp[2][1] = 1$。
- $dp[3][3] = \min(dp[2][3], dp[3][2]) + 1 = \min(3,1)+1 = 2$，即答案。

校验：$\text{LCS} = 2$（`"ea"`），$m+n-2\cdot\text{LCS} = 3+3-4 = 2$，两条路径一致。

## 4. 算法细节

1. **下标从 1 开始**：$dp$ 用 $(m+1)\times(n+1)$ 的表格，$dp[i][j]$ 对应 `word1[i-1]` 与 `word2[j-1]` 的比较，避免 $i-1$ 越界。
2. **相等时不要 $+1$**：这是本题与编辑距离最大的区别。编辑距离里「相同」是 $dp[i-1][j-1]$，但「不同」时有**替换**这一选项；本题没有替换，只能删，所以不同时是 $\min(dp[i-1][j], dp[i][j-1]) + 1$，**不存在** $dp[i-1][j-1] + 1$ 这种转移（若写了就会把「两个都删」的 2 步误算成 1 步）。
3. **一维滚动数组**：$dp[i][\cdot]$ 只依赖 $dp[i-1][\cdot]$ 与同一行的 $dp[i][j-1]$，所以只需长度 $n+1$ 的数组。关键是保存**左上角** $dp[i-1][j-1]$：进入第 $i$ 行时 `diag = dp[0]`（即 $dp[i-1][0]$），内层先把旧的 `dp[j]`（$dp[i-1][j]$）存入 `up` 再覆写，最后 `diag = up`，供下一列使用。
4. **列方向取较短的串**：滚动数组空间是 $O(n)$，若先交换两串使 $n = \min(m,n)$，空间降为 $O(\min(m,n))$。长度只有 500，本题不交换也足够。
5. **与 LCS 版本互推**：若已写出 $lcs[i][j]$，则 $dp[i][j] = i + j - 2 \cdot lcs[i][j]$，两套 DP 完全等价；比赛中写更熟的那套即可，但要注意别把 $lcs$ 的转移（不等取 $\max$）与 $dp$ 的转移（不等取 $\min$ 再 $+1$）混用。
6. **规模核算**：$m n \le 2.5\times 10^{5}$ 个状态，每个 $O(1)$，在 Python 里也是毫秒级，无需任何额外优化。

## 5. 正确性证明

**引理 1**：设一种删除方案把两串都变成 $S$，则删除步数为 $m + n - 2\lvert S \rvert$，且 $S$ 是 `word1` 与 `word2` 的公共子序列。

**证明**：`word1` 只做删除操作，剩下的 $S$ 必是 `word1` 的子序列，同理是 `word2` 的子序列，故为公共子序列。`word1` 中保留了 $\lvert S \rvert$ 个字符，删除 $m - \lvert S \rvert$ 个；`word2` 删除 $n - \lvert S \rvert$ 个；总步数即二者之和。∎

**引理 2**：令 $lcs[i][j]$ 为 `word1[0..i)` 与 `word2[0..j)` 的 LCS 长度，则 $lcs$ 满足标准转移：$word1[i-1] = word2[j-1]$ 时 $lcs[i][j] = lcs[i-1][j-1] + 1$；否则 $lcs[i][j] = \max(lcs[i-1][j], lcs[i][j-1])$；且 $lcs[0][\cdot] = lcs[\cdot][0] = 0$。

**证明**：只证相等情形（不等情形是经典结论）。下界：取 $lcs[i-1][j-1]$ 对应的公共子序列并接上共同末字符，得到长度 $lcs[i-1][j-1]+1$ 的公共子序列。上界：设 $T$ 是任一公共子序列。若 $T$ 以该末字符 $c$ 结尾，去掉 $T$ 的末尾 $c$ 后 $T'$ 仍是 `word1[0..i-1)` 与 `word2[0..j-1)` 的公共子序列，故 $\lvert T \rvert \le lcs[i-1][j-1]+1$；若 $T$ 不以 $c$ 结尾，则 $T$ 的最后一个字符既不是 $word1[i-1]$ 也不是 $word2[j-1]$，说明 $T$ 的匹配位置全部落在前 $i-1$、前 $j-1$ 个字符内，于是 $\lvert T \rvert \le lcs[i-1][j-1] \le lcs[i-1][j-1]+1$。两种情况都成立。∎

**引理 3（DP 与 LCS 的关系）**：对任意 $0 \le i \le m$、$0 \le j \le n$，上述 $dp$ 转移算出的值满足 $dp[i][j] = i + j - 2\,lcs[i][j]$。

**证明**：对 $i+j$ 归纳。$i=0$ 或 $j=0$ 时 $dp[i][j] = i+j$，而 $lcs = 0$，成立。设 $i,j \ge 1$ 且更小规模均成立：

- 若 `word1[i-1] = word2[j-1]`：$dp[i][j] = dp[i-1][j-1] = (i-1)+(j-1)-2\,lcs[i-1][j-1] = i+j-2\,(lcs[i-1][j-1]+1) = i+j-2\,lcs[i][j]$，最后一步用了引理 2。
- 否则：$dp[i][j] = \min(dp[i-1][j], dp[i][j-1]) + 1 = \min\bigl((i-1)+j-2\,lcs[i-1][j],\; i+(j-1)-2\,lcs[i][j-1]\bigr) + 1 = i + j - 2\max(lcs[i-1][j], lcs[i][j-1]) = i+j-2\,lcs[i][j]$，同样用了引理 2。∎

**定理**：算法返回的 $dp[m][n]$ 等于使两串相同的最小删除步数。

**证明**：由引理 3，$dp[m][n] = m + n - 2\,lcs[m][n]$，即取 $S$ 为最长公共子序列时的步数，由引理 1 它是一个合法方案的步数。另一方面，任意合法方案对应某个公共子序列 $S$，步数 $m+n-2\lvert S \rvert \ge m+n-2\,lcs[m][n]$，故 $dp[m][n]$ 是下界且可达，即为最小值。∎

## 6. 复杂度分析

- **时间**：$O(mn)$。状态总数 $(m+1)(n+1)$，每个状态仅做一次字符比较与常数次取 $\min$ / 加法；$m=n=500$ 时约 $2.5\times10^{5}$ 次运算。
- **空间**：$O(n)$。一维滚动数组长度为 $n+1$，另加常数个临时变量（`diag`、`up`）；若先令 $n=\min(m,n)$ 则为 $O(\min(m,n))$。若不优化空间、直接开二维表则为 $O(mn) \approx 250$ KB（`int`）。

## 7. 参考代码

### C++

```cpp
#include <string>
#include <vector>
#include <algorithm>

class Solution {
public:
    int minDistance(std::string word1, std::string word2) {
        int m = word1.size(), n = word2.size();
        // dp[j] 表示当前行 dp[i][j]：使 word1 前 i 个字符与 word2 前 j 个字符相同的最小删除数
        std::vector<int> dp(n + 1);
        for (int j = 0; j <= n; ++j) dp[j] = j;   // dp[0][j] = j

        for (int i = 1; i <= m; ++i) {
            int diag = dp[0];   // dp[i-1][0]
            dp[0] = i;          // dp[i][0] = i
            for (int j = 1; j <= n; ++j) {
                int up = dp[j]; // dp[i-1][j]，先存下来再覆写
                if (word1[i - 1] == word2[j - 1]) {
                    dp[j] = diag;                       // 末字符相同，都保留
                } else {
                    dp[j] = std::min(up, dp[j - 1]) + 1; // 删掉其中一个
                }
                diag = up;      // 供下一列的左上角使用
            }
        }
        return dp[n];
    }
};
```

### Python

```python
class Solution:
    def minDistance(self, word1: str, word2: str) -> int:
        m, n = len(word1), len(word2)
        # dp[j] 为当前行：使 word1[:i] 与 word2[:j] 相同的最小删除数
        dp = list(range(n + 1))          # dp[0][j] = j
        for i in range(1, m + 1):
            diag = dp[0]                 # dp[i-1][0]
            dp[0] = i                    # dp[i][0] = i
            for j in range(1, n + 1):
                up = dp[j]               # dp[i-1][j]，尚未被覆写
                if word1[i - 1] == word2[j - 1]:
                    dp[j] = diag         # 末字符相同，都保留
                else:
                    dp[j] = min(up, dp[j - 1]) + 1
                diag = up                # 下一列要用的左上角
        return dp[n]
```

## 8. 边界情况与易错点

1. **一维滚动的更新顺序**：必须先用 `up` 保存旧的 `dp[j]`（即 $dp[i-1][j]$）再覆写 `dp[j]`，否则 `diag` 拿到的是本行刚算出的值，$dp[i-1][j-1]$ 被污染，答案会偏小。
2. **完全相同的串**：如 `"abc"` 与 `"abc"`，答案 0。检查时确认初始 $dp[0]=0$ 而不是 1，否则会多算。
3. **完全没有公共字符**：如 `"abc"` 与 `"xyz"`，答案 $m+n=6$；不要把答案初始化成 0。
4. **长度不等的串**：`"a"` 与 `"aa"` → 1（删掉 `word2` 多出的那个 `a`）；转移里 `min` 的两项分别对应删左、删右，缺一不可。
5. **不要照抄编辑距离的转移**：编辑距离的「不等」分支包含替换，等价于允许 $dp[i-1][j-1]+1$；本题没有替换，若误加该项，`"abc"` / `"xyz"` 会得到 3 而不是 6（错误地让一对不同字符「一次替换」就对齐）。
6. **空串**：题目保证长度 $\ge 1$，但转移天然支持空串（$dp[0][j]=j$）；若接口允许空串，代码也无需特判。
