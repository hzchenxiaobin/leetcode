# LeetCode 网格中的最小路径代价 题解

## 1. 题目概述

- **标题 / 题号**：网格中的最小路径代价（#2304，medium）
- **链接**：https://leetcode.cn/problems/minimum-path-cost-in-a-grid/
- **来源**：LeetCode 第 297 场周赛 Q2
- **难度**：中等
- **标签**：数组、动态规划、矩阵

**题意**：给定 $m \times n$ 的下标从 $0$ 开始的矩阵 `grid`，由 $0$ 到 $m \cdot n - 1$ 的**互异**整数组成（值与格子一一对应）。位于 $(x, y)$（$x < m-1$）时，可以移动到**下一行任意列** $(x+1, 0), (x+1, 1), \dots, (x+1, n-1)$；最后一行不能再移动。每次移动的代价由 $(m \cdot n) \times n$ 的二维数组 `moveCost` 给出：`moveCost[i][j]` 是从**值为 $i$** 的格子移动到下一行**第 $j$ 列**的代价——只由「出发格的**值** + 目标**列**」决定，与出发格的坐标无关。一条路径的代价 = 经过的所有格子**值之和** + 所有移动的**代价之和**。从**第一行任意格**出发、到达**最后一行任意格**，返回最小路径代价。

**约束**：

- $2 \le m, n \le 50$
- `grid` 由 $0$ 到 $m \cdot n - 1$ 的不同整数组成
- $\textit{moveCost.length} = m \cdot n$，$\textit{moveCost}[i].\textit{length} = n$
- $1 \le \textit{moveCost}[i][j] \le 100$

> 💡 本题在本仓库另有[每日题解 2304](../../solution/2301-2400/2304_网格中的最小路径代价.md)：以「关键转化 + 滚动数组 + 面试问答」为主线展开。本篇按**周赛复盘视角**展开，侧重从题面 30 秒锁定网格 DP 的最短切入、`moveCost` **值索引 / 坐标索引**这一头号 WA、引理-定理证明与边界清单，两篇互为印证。

## 2. 示例

**示例 1**

```text
输入：grid = [[5,3],[4,0],[2,1]],
      moveCost = [[9,8],[1,5],[10,12],[18,6],[2,4],[14,3]]
输出：17
解释：最小代价路径 5 -> 0 -> 1。
- 路径经过单元格值之和 5 + 0 + 1 = 6
- 从 5 移动到 0（下一行第 1 列）代价 moveCost[5][1] = 3
- 从 0 移动到 1（下一行第 1 列）代价 moveCost[0][1] = 8
- 总代价 6 + 3 + 8 = 17
```

**示例 2**

```text
输入：grid = [[5,1,2],[4,0,3]],
      moveCost = [[12,10,15],[20,23,8],[21,7,1],[8,1,13],[9,10,25],[5,3,2]]
输出：6
解释：最小代价路径 2 -> 3。
- 单元格值之和 2 + 3 = 5
- 从 2 移动到 3（下一行第 2 列）代价 moveCost[2][2] = 1
- 总代价 5 + 1 = 6
```

> ⚠️ 示例 2 的最优路径从**第 2 列**的格 $2$ 出发、到**第 2 列**的格 $3$ 结束——起点、终点都是**任意列**，不是 $(0,0)$ 到右下角；这决定了初始化是「整行 `dp[0][j] = grid[0][j]`」、答案是「末行取 $\min$」。

**补充示例：值索引与坐标索引的分野（头号 WA 复现）**

```text
输入：grid = [[1,0],[2,3]],
      moveCost = [[10,10],[3,3],[1,1],[1,1]]
正确输出：6（路径 1 -> 2：值和 3 + moveCost[1][0] = 3）
错误输出：5（把 moveCost 第一维误用列号 k 索引）
```

解释：第一行 `grid[0] = [1, 0]` 恰好与列号「错位」。正确做法中，从值为 $1$ 的格（第 0 列）出发查 `moveCost[1]`（便宜，$3$）、从值为 $0$ 的格（第 1 列）出发查 `moveCost[0]`（昂贵，$10$）；坐标索引版正好查反，把「值 $0$ 的格」误当成便宜格，算出 $5$。**同样的错误在示例 1 上恰好不改变答案**（$m$ 截成 2 后正误均为 $8$），极具迷惑性——不靠逐项核对很难当场发现。

## 3. 解题思路

### 3.1 暴力思路：枚举所有路径

最直译题面的做法：DFS 枚举每条从第一行到最后一行的路径再逐条计价。首行有 $n$ 个起点可选，之后每一步（共 $m-1$ 步）都有 $n$ 个去向，路径总数 $n^m$；$n = m = 50$ 时约 $50^{50} \approx 10^{85}$，完全不可行。

另一条「重武器」路线：把 $mn$ 个格子当节点、移动当边（边权查 `moveCost`）建图跑 Dijkstra。正确，但属于杀鸡用牛刀——「只能到下一行」使行号每步严格 $+1$，图**无环且天然按行分层**，行序就是拓扑序，按行序一遍递推就是最短路本身，连优先队列都不需要（何时才真正需要换挡到 Dijkstra，见文末延伸思考 ②）。

### 3.2 核心观察：只能逐行向下 → 无环拓扑序 → 逐层网格 DP

![核心观察：逐行向下无环，dp[i][j] 取上一行 n 条入边的最小](images/wc297_q2_dp_model_concept.svg)

三层观察，从题面到算法只需 30 秒：

1. **行号每步 $+1$，严格递增** → 路径无环，行序即拓扑序，可以**逐行递推**；
2. **代价可加且无后效性**：路径代价 = 格值和 + 移动代价和；而移动代价只看「当前格的**值** + 目标**列**」——未来怎么走与「怎么到达当前格」完全无关，状态 $(i, j)$ 足够；
3. **最优子结构**：到达 $(i,j)$ 的最优路径，去掉最后一格，必是到达上一行某格 $(i-1, k)$ 的最优路径。

**状态定义**：$dp[i][j]$ = 从第一行任意格出发、到达 $(i, j)$ 的最小路径代价（**包含** $(i,j)$ 自身的格值与一路上所有移动代价）。

**边界**（首行无移动，代价就是自身格值）：

$$dp[0][j] = \textit{grid}[0][j], \quad j = 0, \dots, n-1$$

**转移**（从上一行任意列 $k$ 走到本格）：上一行第 $k$ 列格的**值**是 $\textit{grid}[i-1][k]$，「从它走到第 $j$ 列」的移动代价查表得 $\textit{moveCost}[\textit{grid}[i-1][k]][j]$，于是

$$dp[i][j] = \textit{grid}[i][j] + \min_{0 \le k < n} \bigl\{\, dp[i-1][k] + \textit{moveCost}[\textit{grid}[i-1][k]][j] \,\bigr\}$$

**答案**：$\min_{0 \le j < n} dp[m-1][j]$。

> ⚠️ **`moveCost` 的第一维是「值」不是「列号」**：查表必须写 `moveCost[grid[i-1][k]][j]`。坐标 $k$ 与值 `grid[i-1][k]` 是两个不同维度（全矩阵互异使二者一一对应但**数值不等**），写错就是查到完全错误的行——这是本题头号 WA，补充示例 3 专门复现。

### 3.3 算法流程

![算法流程：逐行推进的网格 DP，滚动数组 prev/cur 整行翻面](images/wc297_q2_algorithm_flow.svg)

1. **初始化**：`prev[j] = grid[0][j]`（首行 dp 值）；
2. **逐行推进**：$i = 1, \dots, m-1$，对每个 $j = 0, \dots, n-1$：
   - 扫 $k = 0, \dots, n-1$，求 $\textit{best} = \min_k\bigl(\textit{prev}[k] + \textit{moveCost}[\textit{grid}[i-1][k]][j]\bigr)$；
   - 写入 $\textit{cur}[j] = \textit{grid}[i][j] + \textit{best}$；
   - **整行**算完后 `swap(prev, cur)`；
3. **取答案**：$\min_j \textit{prev}[j]$（此时 `prev` 已是末行 dp）。

### 3.4 示例演算

![示例 1 演算：dp 逐行走查，最优路径 5 → 0 → 1](images/wc297_q2_example_walkthrough.svg)

以**示例 1** `grid = [[5,3],[4,0],[2,1]]` 走查（$m = 3$，$n = 2$，值 $0 \sim 5$，`moveCost` 按值索引）：

**第 0 行**（边界）：$dp[0] = [5, 3]$。

**第 1 行**（$grid[1] = [4,0]$，上一行值 $grid[0] = [5,3]$）：

| $j$ | $k=0$：$dp[0][0] + \textit{moveCost}[5][j]$ | $k=1$：$dp[0][1] + \textit{moveCost}[3][j]$ | best | $dp[1][j]$ |
|-----|------|------|------|------|
| 0 | $5+14=19$ | $3+18=21$ | 19 | $4+19=23$ |
| 1 | $5+3=8$ | $3+6=9$ | 8 | $0+8=\mathbf{8}$ |

**第 2 行**（$grid[2] = [2,1]$，上一行值 $grid[1] = [4,0]$）：

| $j$ | $k=0$：$dp[1][0] + \textit{moveCost}[4][j]$ | $k=1$：$dp[1][1] + \textit{moveCost}[0][j]$ | best | $dp[2][j]$ |
|-----|------|------|------|------|
| 0 | $23+2=25$ | $8+9=17$ | 17 | $2+17=19$ |
| 1 | $23+4=27$ | $8+8=16$ | 16 | $1+16=\mathbf{17}$ |

**答案** $= \min(19, 17) = 17$ ✓，对应路径 $5 \to 0 \to 1$。

> 💡 **观察**：最优路径在 $(1,1)$ 处取的是 $dp[1][1] = 8$（从第 0 列「换列」而来），而非同行更早算出的 $dp[1][0] = 23$。这正是 DP 的价值——每格独立保留「到此为止的最小代价」，后续续推只认数值、不问来路。

## 4. 算法细节

1. **状态含自身格值**：$dp[i][j]$ 定义为「到达 $(i,j)$ 的代价（含该格值）」，好处是三段完全对称——边界 $dp[0][j] = \textit{grid}[0][j]$、转移末尾 $+\textit{grid}[i][j]$、答案 $\min_j dp[m-1][j]$ 直接可取，末行**无需再补加任何格值**。
2. **值索引的合法性**：`moveCost` 第一维长 $m \cdot n$，恰是值域 $0 \sim mn-1$ 的大小；`grid` 全矩阵互异 ⟹ 每个格子的值唯一映射到 `moveCost` 的一行，查表永远合法。反之，正因为「值」承担了索引职责，**坐标索引错误不会被越界暴露**，只会安静地算错数（补充示例 3）。
3. **滚动数组整行翻面**：第 $i$ 行只依赖第 $i-1$ 行，用 `prev` / `cur` 两个长 $n$ 的数组交替。要点是**算完整行再 `swap`**——若逐格原地写回 `prev`，先算的格会污染同行后续格要读的「上一行」数据，与「01 背包倒序遍历」是同一类坑。
4. **复杂度由入边数决定**：本题主「上一行全连」，每格 $n$ 条入边 → 单格转移 $O(n)$、总 $O(m \cdot n^2)$；对照 64 最小路径和（只能向右/下相邻走，入边 $O(1)$）总 $O(mn)$。拿到网格 DP 先数**每格入边数**，再定复杂度量级。
5. **为什么压不到 $O(mn)$**：转移项 $\textit{moveCost}[\textit{grid}[i-1][k]][j]$ 同时依赖 $k$（经值）与 $j$，二者**耦合在一张二维表里**，无法解耦成「先对 $k$ 取一次 min、再对 $j$ 查表」的单维预处理，所以每个 $j$ 都得老老实实扫一遍 $k$。所幸 $n \le 50$，$O(mn^2) \le 1.25 \times 10^5$ 毫无压力。
6. **整数类型**：格值 $\le mn - 1 \le 2499$，路径含 $m \le 50$ 格，值和 $\le 50 \times 2499 = 124950$；移动 $m - 1 \le 49$ 次、每次 $\le 100$，移动和 $\le 4900$；总代价上界 $\approx 1.3 \times 10^5$，`int` 绰绰有余，无需 `long long`。

## 5. 正确性证明

**引理 1（路径结构）**：任何合法路径恰含 $m$ 个格子，其中第 $t$ 个格子（$t = 0, \dots, m-1$）位于第 $t$ 行；反之，任取每行一个格子 $c_0, c_1, \dots, c_{m-1}$（$c_t$ 在第 $t$ 行），按序连接即为一条合法路径。

**证明**：移动规则限定行号 $x \to x+1$。路径从第 0 行出发、须到达第 $m-1$ 行且末行不能移动，故恰发生 $m-1$ 次移动，行号依次为 $0, 1, \dots, m-1$，每行恰落一格。反之，从第 $t$ 行任意格到第 $t+1$ 行任意格都是允许的一步移动，串接即得合法路径。∎

**引理 2（dp 的刻画）**：对一切 $0 \le i < m$、$0 \le j < n$，$dp[i][j]$ 恰等于「从首行任意格出发、终于 $(i,j)$ 的合法路径的最小代价」（含 $(i,j)$ 自身格值）。

**证明**：对 $i$ 归纳。$i = 0$：由引理 1，终于 $(0,j)$ 的路径只含 $(0,j)$ 一格、无移动，代价即 $\textit{grid}[0][j]$，与初始化一致。设对 $i - 1$ 成立。任取一条终于 $(i,j)$ 的路径 $P$，由引理 1 其倒数第二格形如 $(i-1, k)$。$P$ 的代价 =「$P$ 去掉最后一格与最后一步」的前缀代价 + $\textit{moveCost}[\textit{grid}[i-1][k]][j] + \textit{grid}[i][j]$；该前缀恰是终于 $(i-1,k)$ 的合法路径，代价 $\ge dp[i-1][k]$（归纳假设）。故对一切 $k$ 与一切 $P$：

$$\text{cost}(P) \ge \min_{0 \le k < n}\bigl\{dp[i-1][k] + \textit{moveCost}[\textit{grid}[i-1][k]][j]\bigr\} + \textit{grid}[i][j] = dp[i][j]$$

反向，取达最小值的 $k^\star$：由归纳假设存在代价恰为 $dp[i-1][k^\star]$、终于 $(i-1, k^\star)$ 的路径，将其延长一步「$(i-1,k^\star) \to (i,j)$」得到一条终于 $(i,j)$ 的真实路径，代价恰为递推右端。故 $dp[i][j]$ 是最小代价。∎

**定理**：$\min_{0 \le j < n} dp[m-1][j]$ 即为所求答案。

**证明**：一方面，任何合法路径终于末行某格 $(m-1, j)$，由引理 2 其代价 $\ge dp[m-1][j] \ge \min_j dp[m-1][j]$，故答案不小于该值；另一方面，引理 2 反向构造说明每个 $dp[m-1][j]$ 都被一条真实路径达到，故答案也不大于该值。∎

## 6. 复杂度分析

- **时间复杂度**：$O(m \cdot n^2)$。共 $m-1$ 行待推，每行 $n$ 个格，每格扫 $n$ 个入边取最小，总计 $(m-1) \cdot n \cdot n \le 49 \times 2500 \approx 1.25 \times 10^5$ 次基本运算；初始化与末行取 min 各 $O(n)$，可忽略。
- **空间复杂度**：$O(n)$。滚动数组只保留 `prev` / `cur` 两行（各长 $n$）；若保留整张 $m \times n$ 的 dp 表则为 $O(mn)$，代价是可顺便记录每格最优前驱用于还原路径。不计输入 `grid` 与 `moveCost`。

## 7. 参考代码

### C++（网格 DP + 滚动数组）

```cpp
class Solution {
public:
    int minPathCost(vector<vector<int>>& grid, vector<vector<int>>& moveCost) {
        int m = grid.size(), n = grid[0].size();
        vector<int> prev(grid[0].begin(), grid[0].end()); // dp[0][j] = grid[0][j]
        vector<int> cur(n);
        for (int i = 1; i < m; ++i) {
            for (int j = 0; j < n; ++j) {
                int best = INT_MAX;
                for (int k = 0; k < n; ++k)
                    best = min(best, prev[k] + moveCost[grid[i - 1][k]][j]);
                cur[j] = grid[i][j] + best;
            }
            prev.swap(cur); // 整行翻面：算完一行再换，勿逐格原地更新
        }
        return *min_element(prev.begin(), prev.end());
    }
};
```

> ⚠️ 转移中最容易笔误的一行是 `moveCost[grid[i - 1][k]][j]`：第一维是上一行第 $k$ 格的**值**。写成 `moveCost[k][j]` 在部分用例上**恰好不报错**（见补充示例 3），务必自查。

### Python（与 C++ 同构）

```python
class Solution:
    def minPathCost(self, grid: List[List[int]], moveCost: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        prev = grid[0][:]  # dp[0][j] = grid[0][j]
        for i in range(1, m):
            cur = [0] * n
            for j in range(n):
                best = min(prev[k] + moveCost[grid[i - 1][k]][j] for k in range(n))
                cur[j] = grid[i][j] + best
            prev = cur
        return min(prev)
```

## 8. 边界情况与易错点

1. **`moveCost` 用值索引（头号 WA）**：必须 `moveCost[grid[i-1][k]][j]`，不能 `moveCost[k][j]`。错误不会越界、不会抛异常，且在部分用例（如示例 1 截断为两行）上结果恰好不变——只能靠「值 ≠ 列号」的意识防住。
2. **首行初始化**：`dp[0][j] = grid[0][j]`，首行无移动、代价只有自身格值；不要给首行也套转移公式。
3. **转移别漏 `+ grid[i][j]`**：状态定义含自身格值，漏加则答案系统性偏小一格值。
4. **起点是首行任意格**：不要误读成固定从 $(0,0)$ 出发（那应把 $dp[0][0]$ 之外初始化为 $\infty$）；本题所有 `dp[0][j]` 一律合法。
5. **答案是末行整行取 min**：终点任意列，不是 $dp[m-1][n-1]$；示例 2 的最优终点在第 2 列。
6. **滚动数组整行翻面**：`cur` 写完整行后再 `swap(prev, cur)`；逐格原地更新会让同行后续格读到被覆盖的「上一行」数据（正确性证明引理 2 的归纳链随之断裂）。
7. **`m = 2` / `n = 2` 最小规模**：只有一次转移、每格只有 2 条入边，通用循环天然覆盖，无需特判；`n` 恒 $\ge 2$ 也保证 `min` 作用域非空。
8. **整数范围**：总代价上界 $\approx 1.3 \times 10^5$，`int` 足够；`INT_MAX` 作 `best` 初值也远大于任何真实转移项（$\le 1.3 \times 10^5$），无溢出风险。

**延伸思考**：① **路径还原**：若要求输出最小代价路径本身，保留整张 $dp$ 表并加 `pre[i][j]`（最优前驱列 $k$），在末行定答案格 $(m-1, j^\star)$ 后回溯到第 0 行即可，空间升到 $O(mn)$；② **何时必须换挡到 Dijkstra**：若把「只能到下一行」放开为四方向移动，行序不再是拓扑序、图带环（如 [LeetCode 4046. 至多 K 次转向的最小路径代价](https://leetcode.cn/problems/minimum-cost-path-with-at-most-k-turns/)，本站第 518 场周赛 Q4 题解有完整复盘），就必须改用最短路 / 分层图——体会 DP 与 Dijkstra 的换挡边界正在「有无拓扑序」；③ **转移能否解耦**：若 `moveCost[v][j] = a[v] + b[j]` 可分离，则 $\min_k\{dp[i-1][k] + a[\textit{grid}[i-1][k]]\}$ 与 $j$ 无关，单行先算一次再逐格 $+ b[j]$，总复杂度降到 $O(mn)$——本题难就难在「值 × 列」的二维耦合不可拆。
