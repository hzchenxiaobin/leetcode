# LeetCode 公平分发饼干 题解

## 1. 题目概述

- **标题 / 题号**：公平分发饼干（#2305，medium）
- **链接**：https://leetcode.cn/problems/fair-distribution-of-cookies/
- **来源**：LeetCode 第 297 场周赛 Q3
- **难度**：中等
- **标签**：位运算、动态规划、状态压缩、回溯、枚举

**题意**：给定长度为 $n$ 的数组 $\textit{cookies}$（第 $i$ 包有 $\textit{cookies}[i]$ 块饼干）与孩子数 $k$。所有包必须分完，且**每包不可拆分**——一包的全部饼干只给一个孩子。**不公平程度** = 所有孩子获得总数中的最大值。求最小不公平程度。本质是「把 $n$ 个数划分成 $k$ 组（允许空组），最小化最大组和」——即最小化最大子集和的划分问题（NP-hard，靠极小数据范围生存）。

**约束**：

- $2 \le n \le 8$
- $1 \le \textit{cookies}[i] \le 10^5$
- $2 \le k \le n$

> 💡 本题在本仓库另有[每日题解 2305](../../solution/2301-2400/2305_公平分发饼干.md)：以「回溯三件套剪枝」为主线、子集状压 DP 作扩展、附面试问答。本篇按**周赛复盘视角**展开：30 秒锁定指数甜区信号、贪心反例判死刑、回溯与 $k \cdot 3^n$ 状压 DP 的赛场取舍、引理-定理证明与边界清单，两篇互为印证。

## 2. 示例

**示例 1**

```text
输入：cookies = [8,15,10,20,8], k = 2
输出：31
解释：最优方案 [8,15,8] 和 [10,20]。
- 第 1 个孩子：8 + 15 + 8 = 31
- 第 2 个孩子：10 + 20 = 30
- 不公平程度 max(31, 30) = 31，不存在更小的方案。
```

**示例 2**

```text
输入：cookies = [6,1,3,2,2,4,1,2], k = 3
输出：7
解释：最优方案 [6,1]、[3,2,2]、[4,1,2]，三个孩子都得 7，max = 7。
```

**补充示例：下界取不到的情形**

```text
输入：cookies = [5,5,5], k = 2
输出：10
解释：总量 15，均摊下界 ⌈15/2⌉ = 8；但 3 包分 2 人必有一组 ≥ 2 包（鸽笼），
其和 ≥ 10。最优 [5,5] 与 [5]，max = 10 > 8——下界只是下界。
```

> ⚠️ 两个官方示例的总量分别是 $61$ 与 $21$，$\lceil 61/2 \rceil = 31$、$\lceil 21/3 \rceil = 7$——**都恰好取到均摊下界**。这是构造者的善意，不代表一般情形（见补充示例），下界只能用于剪枝提前终止与人工验算，不能当作答案。

## 3. 解题思路

### 3.1 暴力思路：先给贪心判死刑，再谈 $k^n$ 枚举

**贪心不可行**。最顺手的直觉是「每次把当前包给负载最轻的孩子」（调度理论里的 LPT 规则）。反例：$\textit{cookies} = [8,7,6,5,4]$，$k = 2$：

```text
贪心（每次给最轻的孩子）：A = 8+5+4 = 17，B = 7+6 = 13 → 17
最优：[8,7] = 15，[6,5,4] = 15 → 15
```

根因：**包不可拆分 + 目标是 $\max$**——先做的局部决定会绑架后面的选择，局部最优推不出全局最优（LPT 在 makespan 调度里也只有 $4/3$ 近似保证）。

**全枚举**：每个包独立地分给 $k$ 个孩子之一，共 $k^n$ 种方案，逐包增量维护 `loads` 数组即可 $O(1)$ 结算。$n = k = 8$ 时 $8^8 \approx 1.7 \times 10^7$，C++ 裸搜可过、Python 悬。赛内主流是回溯 + 三件套剪枝（**降序排列 / 超限剪枝 `loads[c] + cookies[idx] >= best` / 空桶对称剪枝**，逐条剖析见每日题解），实测毫秒级——但最坏复杂度仍是 $O(k^n)$，「能过」靠的是剪枝与数据运气，$n$ 再大一格就没救。本篇主线是复杂度**严格可控**的状压 DP，回溯版附在 §7。

### 3.2 核心观察：$n \le 8$ ⇒ 集合就是状态，子集就是转移

![核心观察：贪心反例与「孩子 × 已分集合」的子集 DP 模型](images/wc297_q3_dp_model_concept.svg)

三层观察，从题面到正解：

1. **指数甜区信号**：$n \le 8$ ⇒ $2^8 = 256$ 个集合、$3^8 = 6561$ 对「(状态, 子集)」——子集枚举型状压 DP 的标准甜区，看到就该条件反射；
2. **方案 = 集合划分**：一个分发方案把全集 $U$ 划分成 $k$ 个（可空）子集 $t_1, \dots, t_k$，不公平程度 $= \max_j \textit{sum}[t_j]$——「按包搜索」之外还存在「按集合整块划分」的视角；
3. **孩子作阶段、集合作状态**：$f[i][s]$ = 前 $i$ 个孩子合计恰好拿走集合 $s$ 时，这 $i$ 个孩子**最大负载的最小值**。转移枚举第 $i$ 个孩子整拿的子集 $t \subseteq s$：

$$f[i][s] = \min_{t \subseteq s} \max\bigl(\, f[i-1][s \setminus t],\; \textit{sum}[t] \,\bigr)$$

内层 $\max$ 是「不公平程度 = 最大值」的直接翻译，外层 $\min$ 在所有拆法里选最优。**允许 $t = \varnothing$**（孩子可以一包不拿）：$k \le n$ 保证「人人非空」的方案存在，而空孩子负载为 $0$ 不影响 $\max$，允许空集不损失最优值，却免去「恰好非空」的组合处理（§8 第 1 条会看到它的另一面）。

**边界**：$f[0][\varnothing] = 0$，$f[0][s \ne \varnothing] = \infty$（0 个孩子拿不走任何包）。**答案**：$f[k][U]$。

### 3.3 算法流程

![算法流程：预处理子集和 → k 层「状态 × 子集」递推 → f[U] 即答案](images/wc297_q3_algorithm_flow.svg)

1. **预处理**：$\textit{sum}[s] = \textit{sum}[s \,\&\, (s-1)] + \textit{cookies}[\mathrm{lowbit}(s)]$，一遍 $O(2^n)$；
2. **第 0 层**：$f[\varnothing] = 0$，其余 $\infty$；
3. **递推 $k$ 层**：每层对每个状态 $s = 0 \dots U$ 枚举其全部子集 $t$（含 $\varnothing$ 与 $s$），用 $\max(f[s \setminus t], \textit{sum}[t])$ 松弛 $\textit{newf}[s]$；
4. **滚动翻面**：整层算完才 `f = newf`（与 [Q2 网格 DP 的「整行翻面」](Q2.网格中的最小路径代价题解.md)是同一纪律）；
5. **答案**：$f[U]$。

### 3.4 示例演算

![示例 1 演算：k=2 时 DP 退化为最优对半分割](images/wc297_q3_example_walkthrough.svg)

以**示例 1** 走查（$n = 5$，$k = 2$）：$\textit{cookies}[0..4] = 8, 15, 10, 20, 8$ 对应 $b_0 \dots b_4$，$U = 11111_2$，总量 $61$。

**第 1 层**：只剩一个孩子，$s$ 只能整包全拿：$f[1][s] = \textit{sum}[s]$。

**第 2 层**：$f[2][U] = \min_{t \subseteq U} \max\bigl(\textit{sum}[U \setminus t], \textit{sum}[t]\bigr)$——$k = 2$ 时 DP 恰好退化为「最优对半分割」（balanced partition）：

| $t$（第 2 个孩子） | $\textit{sum}[t]$ | $U \setminus t$（第 1 个孩子） | $\textit{sum}$ | $\max$ |
|---|---|---|---|---|
| $\{10,20\}$ | $30$ | $\{8,15,8\}$ | $31$ | $\mathbf{31}$ |
| $\{20,15\}$ | $35$ | $\{8,10,8\}$ | $26$ | $35$ |
| $\{20,8\}$ | $28$ | $\{8,15,10\}$ | $33$ | $33$ |
| $\{8,15\}$ | $23$ | $\{10,20,8\}$ | $38$ | $38$ |
| $\{20,10,8\}$ | $38$ | $\{8,15\}$ | $23$ | $38$ |
| $U$（全拿） | $61$ | $\varnothing$ | $0$ | $61$ |

（表中只列代表性子集；$t$ 与 $U \setminus t$ 互补，每个无序划分被成对枚举两次，对 $\min$ 无害。）

**答案** $f[2][U] = 31$ ✓，对应 $[8,15,8]$ 与 $[10,20]$，且恰好命中下界 $\max(\lceil 61/2 \rceil, 20) = 31$。

> 💡 **通用下界**：答案 $\ge \max\bigl(\lceil S/k \rceil,\ \max_i \textit{cookies}[i]\bigr)$（均摊下界 + 单包不可拆下界）。回溯版可用它提前终止；DP 版可不用，但能用来人工验算。

## 4. 算法细节

1. **子集和的 $O(2^n)$ 递推**：$\textit{sum}[s] = \textit{sum}[s \,\&\, (s-1)] + \textit{cookies}[\mathrm{ctz}(s)]$——去掉最低位 $1$ 的集合更小、必已算好，每个集合 $O(1)$。逐位累加的 $O(n \cdot 2^n)$（$8 \times 256 = 2048$ 次）也能过，前者是应形成的肌肉记忆。
2. **子集枚举模板**：`t = s; do { 用 t 转移; t = (t - 1) & s; } while (t != s);`——按降序遍历 $s$ 的**全部**子集（含 $s$ 与 $\varnothing$）。头号易错是写成 `while (t)`：循环在 $t = 0$ 时提前退出，**漏掉空集**。
3. **$3^n$ 的由来**：每层枚举的 $(s, t)$ 对总数 $= \sum_{j=0}^{n} \binom{n}{j} 2^j = (1+2)^n = 3^n$（二项式定理；每个元素三态：$\in t$ / $\in s \setminus t$ / $\notin s$）。$n = 8$ 时 $6561$。
4. **$\infty$ 的传染与安全**：$f[0][s \ne \varnothing] = \infty$ 标记「0 个孩子拿不走非空集合」。转移只做 $\max$ 与 $\min$、**不做加法**，$\infty$ 既不溢出也不会污染有限值（$\min$ 会淘汰它）；取 `0x3f3f3f3f` 再留三分余量。从第 1 层起所有状态全有限（$f[1][s] = \textit{sum}[s]$）。
5. **滚动数组整层翻面**：`newf` 与 `f` 分开，本层全部算完再整体替换——逐状态原地写会读到「半新半旧」的混合层，归纳链（§5 引理 2）随之断裂。
6. **重复计算与去重**：同一分组的 $k!$ 种孩子标号排列会在 DP 中多次到达，但 $\min$ 对重复不敏感，**无需去重**；回溯版则必须剪掉空桶/同负载对称分支才不退化——这是两个解法的一大分野。
7. **孩子数只是层数**：$k$ 唯一的作用是外层循环次数；若变体允许 $k > n$，多出的孩子自动拿 $\varnothing$，DP 一字不改照样正确（回溯版同样天然正确）。

## 5. 正确性证明

**引理 1（子集和）**：对任意非空集合 $s$，$\textit{sum}[s] = \textit{sum}[s \setminus \{\mathrm{lowbit}(s)\}] + \textit{cookies}[\mathrm{lowbit}(s)]$。

**证明**：子集和按元素可加，去掉最低位元素后求和、再加回该元素，是恒等式。∎

**引理 2（$f$ 的组合刻画）**：定义 $g(i, s)$ = 把 $s$ 中的包分给前 $i$ 个孩子（每包恰给一个孩子、允许有孩子拿空）的所有方案中，这 $i$ 个孩子最大负载的最小值（无可行方案时记 $\infty$）。则对一切 $0 \le i \le k$、$s \subseteq U$：$f[i][s] = g(i, s)$。

**证明**：对 $i$ 归纳。$i = 0$：$g(0, \varnothing) = 0$（无人拿空集），$g(0, s \ne \varnothing)$ 无可行方案即 $\infty$，与初始化一致。设对 $i - 1$ 成立。任取一个分给前 $i$ 个孩子、合计恰为 $s$ 的方案 $\mathcal{P}$，设第 $i$ 个孩子拿 $t \subseteq s$：$\mathcal{P}$ 的前 $i - 1$ 个孩子构成「合计恰为 $s \setminus t$」的方案，其最大负载 $\ge g(i-1, s \setminus t)$（归纳假设），而第 $i$ 个孩子负载恰为 $\textit{sum}[t]$，故

$$\max(\mathcal{P}) \ge \max\bigl(g(i-1, s \setminus t),\ \textit{sum}[t]\bigr) \ge \min_{t' \subseteq s} \max\bigl(g(i-1, s \setminus t'),\ \textit{sum}[t']\bigr) = f[i][s].$$

反之，取达最小值的 $t^\star$：由归纳假设存在前 $i - 1$ 个孩子、合计 $s \setminus t^\star$、最大负载恰为 $f[i-1][s \setminus t^\star]$ 的方案；令第 $i$ 个孩子整拿 $t^\star$，拼得一个真实方案，其最大负载恰为递推右端。故 $f[i][s] = g(i, s)$。∎

**引理 3（空孩子等价）**：题目所求（所有包分完、每包不拆分、分给 $k$ 个孩子）等于 $g(k, U)$。

**证明**：$g(k, U)$ 的可行方案与题目可行方案逐字对应：题面只约束「包必须分完、不可拆分」，未要求每个孩子至少拿一包；空孩子负载为 $0$，不改变 $\max$。若按「每人至少一包」的严格口径理解：$k \le n$ 时，任何含空孩子的最优方案，必存在某个孩子拿 $\ge 2$ 包（总量 $n$ 包、人数 $k \le n$，若人人恰一包则无空孩子），把该组拆成两组、把其中一组给空孩子——拆组只会让各组和非增、$\max$ 不增，仍是相同最优值的方案；反复操作直至人人非空。故两种口径的最优值相同。∎

**定理**：$f[k][U]$ 即为所求答案。

**证明**：在引理 2 中取 $i = k$、$s = U$，得 $f[k][U] = g(k, U)$；再由引理 3，$g(k, U)$ 即题目所求。∎

## 6. 复杂度分析

- **时间复杂度**：$O(2^n) + O(k \cdot 3^n)$。预处理每个集合 $O(1)$；递推 $k$ 层，每层 $(s, t)$ 对总数 $3^n$（§4 第 3 条）。$n = 8$、$k = 8$ 时约 $256 + 8 \times 6561 \approx 5.3 \times 10^4$ 次基本运算——比回溯最坏 $k^n \approx 1.7 \times 10^7$ 低近三个数量级，且**不依赖剪枝与数据运气**。
- **空间复杂度**：$O(2^n)$。滚动数组两层 `f` / `newf` 各 $2^8 = 256$；若存全 $k$ 层表则 $O(k \cdot 2^n)$，可顺便回溯还原具体方案。

## 7. 参考代码

### C++（子集状压 DP + 滚动数组）

```cpp
class Solution {
public:
    int distributeCookies(vector<int>& cookies, int k) {
        int n = cookies.size(), U = 1 << n;
        vector<int> sum(U, 0);
        for (int s = 1; s < U; ++s)                 // O(2^n) 子集和
            sum[s] = sum[s & (s - 1)] + cookies[__builtin_ctz(s)];

        const int INF = 0x3f3f3f3f;
        vector<int> f(U, INF);
        f[0] = 0;                                    // 0 个孩子：只能拿空集
        for (int i = 1; i <= k; ++i) {              // 逐个孩子
            vector<int> g(U, INF);
            for (int s = 0; s < U; ++s) {
                for (int t = s; ; t = (t - 1) & s) { // 枚举全部子集，含 ∅
                    g[s] = min(g[s], max(f[s ^ t], sum[t]));
                    if (t == 0) break;               // do-while：空集算完才收工
                }
            }
            f = move(g);                             // 整层算完再翻面
        }
        return f[U - 1];
    }
};
```

### Python（与 C++ 同构）

```python
class Solution:
    def distributeCookies(self, cookies: List[int], k: int) -> int:
        n = len(cookies)
        U = 1 << n
        ssum = [0] * U
        for s in range(1, U):
            low = (s & -s).bit_length() - 1         # 最低位 1 的下标
            ssum[s] = ssum[s & (s - 1)] + cookies[low]

        INF = float('inf')
        f = [INF] * U
        f[0] = 0                                     # 0 个孩子：只能拿空集
        for _ in range(k):                           # 逐个孩子
            g = [INF] * U
            for s in range(U):
                t = s
                while True:                          # 枚举全部子集，含 ∅
                    cur = max(f[s ^ t], ssum[t])
                    if cur < g[s]:
                        g[s] = cur
                    if t == 0:
                        break
                    t = (t - 1) & s
            f = g                                    # 整层算完再翻面
        return f[U - 1]
```

### 附：回溯 + 剪枝（赛内主流写法，同样通过）

```python
class Solution:
    def distributeCookies(self, cookies: List[int], k: int) -> int:
        cookies.sort(reverse=True)                   # 降序：大包先放，best 落得快
        loads = [0] * k
        best = sum(cookies)                          # 可行上界：一人独拿全部

        def dfs(idx: int) -> None:
            nonlocal best
            if idx == len(cookies):
                best = min(best, max(loads))
                return
            for c in range(k):
                if loads[c] + cookies[idx] >= best:   # 超限剪枝：≥ 则无改善空间
                    continue
                loads[c] += cookies[idx]
                dfs(idx + 1)
                loads[c] -= cookies[idx]
                if loads[c] == 0:                    # 对称剪枝：空桶试一个就够
                    break
        dfs(0)
        return best
```

三件套剪枝（降序 / 超限 / 空桶对称）的逐条剖析见[每日题解 2305](../../solution/2301-2400/2305_公平分发饼干.md)。

## 8. 边界情况与易错点

1. **子集枚举必须覆盖 $t = \varnothing$**（头号易错）：`while (t)` 在 $t = 0$ 时提前退出、漏掉空集。有趣的是**漏掉空集在本题恰好不 WA**——$k \le n$ 时总存在「人人非空」的最优划分（引理 3 的拆组论证），限制 $t \ne \varnothing$ 仍得正确最优值；但这是侥幸，一旦变体允许 $k > n$ 或换到 1723 型问题就会翻车，do-while 模板一次写对最稳。
2. **答案取 $f[U]$ 而非 $\min_s f[k][s]$**：所有包必须分完，$U$ 是唯一合法终态；对 $s$ 取 $\min$ 会把「偷懒不分完」也算进来，系统性偏小（最小可退到单包最大值）。
3. **$\infty$ 只放第 0 层**：$f[0][s \ne \varnothing] = \infty$ 是「0 个孩子拿不走包」的语义；从第 1 层起全状态有限（$f[1][s] = \textit{sum}[s]$），不要层层重置 $\infty$ 又不转移。
4. **滚动翻面纪律**：`newf` 整层算完再赋回 `f`；逐状态原地写会读到本层未定值（与 Q2 的整行翻面、01 背包倒序遍历同类）。
5. **`s ^ t` 即 $s \setminus t$**：仅当 $t \subseteq s$ 时成立——子集枚举模板天然保证；别把 `(t - 1) & s` 写成 `t - 1`（会跑出 $s$ 之外，位运算含义全变）。
6. **lowbit 下标对应**：`__builtin_ctz(s)` 是最低位 $1$ 的**位号**，直接作 `cookies` 下标；Python 里 `(s & -s).bit_length() - 1` 等价。
7. **回溯版剪枝细节**：超限剪枝用 `>=`（等于也无改善空间）；空桶 `break` 必须放在**回溯之后**（先试一个空桶、试完不再试其余空桶）；`best` 初值取 `sum(cookies)` 即合法上界（一人独拿、其余拿 $0$），无需 `INT_MAX`。
8. **整数范围**：总和 $\le 8 \times 10^5$，`int` 足够；`0x3f3f3f3f` 与真实值域隔三个数量级，且转移只做 $\max/\min$ 不做加法，无溢出风险。
9. **示例的「善意」**：两个官方示例都恰好命中均摊下界，容易让人误以为答案 $= \lceil S/k \rceil$；补充示例 $[5,5,5]$、$k = 2$（下界 $8$、真解 $10$）一验即破。

**延伸思考**：① **为何不走二分答案**：判定「能否分成 $\le k$ 组、每组 $\le x$」本身是装箱问题（NP-hard），$n$ 小还得爆搜，两头不占——对照 410 的连续分段判定是 $O(n)$ 贪心，二分才划算；② **去重加速**：强制「每个新开的非空孩子必须拿走当前剩余集合的最低位包」，可把 $k!$ 的孩子标号排列压缩掉，回溯与 DP 皆可套用；③ **下界可解性**：答案何时等于 $\max(\lceil S/k \rceil, \max_i \textit{cookies}[i])$？两个官方示例都取到、$[5,5,5]$ 取不到——「完美划分」的存在性正是通往 number partitioning 的一扇门。
