# LeetCode 选出和最大的 K 个元素 题解

## 1. 题目概述

- **标题 / 题号**：选出和最大的 K 个元素（#3478，medium）
- **链接**：https://leetcode.cn/problems/choose-k-elements-with-maximum-sum/
- **来源**：LeetCode 第 440 场周赛 Q2
- **难度**：中等
- **标签**：数组、排序、堆（优先队列）

**题意**：给定长度均为 $n$ 的数组 `nums1`、`nums2` 与正整数 $k$。对每个下标 $i$：找出所有满足 `nums1[j] < nums1[i]` 的下标 $j$，从对应的 `nums2[j]` 中选出**至多** $k$ 个，使总和最大，记为 `answer[i]`。返回长度为 $n$ 的答案数组。

**约束**：

- $n == \text{nums1.length} == \text{nums2.length}$
- $1 \le n \le 10^5$
- $1 \le \text{nums1}[i], \text{nums2}[i] \le 10^6$
- $1 \le k \le n$

## 2. 示例

**示例 1**

```text
输入：nums1 = [4,2,1,5,3], nums2 = [10,20,30,40,50], k = 2
输出：[80,30,0,80,50]
解释：
- i = 0：nums1[j] < 4 的下标为 [1,2,4]，nums2 值 {20,30,50}，前 2 大和 50+30 = 80。
- i = 1：候选下标 [2]，只有 30。
- i = 2：无候选，结果 0。
- i = 3：候选下标 [0,1,2,4]，值 {10,20,30,50}，前 2 大和 50+30 = 80。
- i = 4：候选下标 [1,2]，值 {20,30}，不足 2 个全选 = 50。
```

**示例 2**

```text
输入：nums1 = [2,2,2,2], nums2 = [3,1,2,3], k = 1
输出：[0,0,0,0]
解释：所有 nums1 相等，任何 i 都不存在 nums1[j] < nums1[i]，答案全 0。
注意：相等不算小于！
```

**示例 3**（自造，验证"相等值互不可见"）

```text
输入：nums1 = [3,1,3,2], nums2 = [5,7,6,4], k = 2
输出：[11,0,11,7]
解释：
- i = 0：候选 j = 1,3（nums1 值 1、2 均小于 3），值 {7,4}，和 11。
- i = 2：候选同样是 j = 1,3 —— j = 0 与 i = 2 的 nums1 相等，互相不可见，答案同为 11。
- i = 3：候选 j = 1，值 {7}，和 7。
```

## 3. 解题思路

### 3.1 暴力思路

对每个 $i$ 扫一遍全数组，收集候选 $\{\text{nums2}[j] \mid \text{nums1}[j] < \text{nums1}[i]\}$，排序后取前 $\min(k, \cdot)$ 大求和。时间 $O(n^2 \log n)$，$n = 10^5$ 时约 $10^{10}$ 次操作，必然超时。

瓶颈在于：$n$ 个下标各自独立地重复收集**几乎同一批**候选。能否让每个元素只被"激活"一次？

### 3.2 核心观察：排序后候选集单调扩张，小根堆维护前 k 大

![核心观察：候选集只增不减，容量 k 的小根堆维护前 k 大](images/choose_k_max_sum_concept.svg)

1. **答案只依赖候选集**：`answer[i]` 仅由候选多重集合 $S_i = \{\text{nums2}[j] \mid \text{nums1}[j] < \text{nums1}[i]\}$ 决定，与处理顺序无关。
2. **候选集只增不减**：把下标按 `nums1` 值**升序**处理后，处理到值 $v$ 时，"已入堆"的恰好是 `nums1 < v` 的全部下标——每个元素只需激活一次，且激活集合随处理单调扩张。
3. **前 k 大用小根堆增量维护**："至多选 $k$ 个使和最大" = 候选集中前 $\min(k, |S|)$ 大的值之和。用一个**容量为 $k$ 的小根堆**：新元素入堆，若大小超过 $k$ 就弹出堆顶（最小的那个），同时增量维护堆内元素和 `sum`。堆里永远装着已激活元素的前 $k$ 大。

> ⚠️ **相等值是本题最大的坑**：候选条件是**严格小于**。若排序后逐个处理、处理完立即入堆，`nums1` 相等的元素会互相"看见"（例 2 会整体出错）。正确做法是**按值分组，整组先作答、再入堆**。

### 3.3 算法流程

![算法流程：按值分组，整组先作答后入堆](images/choose_k_max_sum_flow.svg)

1. 下标数组按 `nums1` 值升序排序。
2. 双指针扫过排序结果，把值相同的连续下标切成一组。
3. 对每一组（设组值为 $v$）：
   - **先作答**：组内每个下标 $i$，`answer[i] = sum`（此时堆中恰是 `nums1[j] < v` 的前 $k$ 大）；
   - **后入堆**：组内每个下标 $j$，`push(nums2[j])`、`sum` 加上该值；若堆大小超过 $k$，`sum` 减去堆顶并弹出。
4. 所有组处理完，返回 `answer`。

### 3.4 示例演算

![示例 1 逐组演算](images/choose_k_max_sum_walkthrough.svg)

对示例 1（$k = 2$）按值分组走查，注意每行"作答"发生在"入堆"**之前**：

| 组值 | 组内下标 (nums2) | 作答前堆 | answer | 入堆后（淘汰） |
|------|-----------------|----------|--------|----------------|
| 1 | 2 (30) | 空 | ans[2] = 0 | {30} |
| 2 | 1 (20) | {30} | ans[1] = 30 | {20,30} |
| 3 | 4 (50) | {20,30} | ans[4] = 50 | {30,50}（淘汰 20） |
| 4 | 0 (10) | {30,50} | ans[0] = 80 | {30,50}（淘汰 10） |
| 5 | 3 (40) | {30,50} | ans[3] = 80 | {40,50}（淘汰 30） |

回填原下标得 `answer = [80, 30, 0, 80, 50]`，与期望一致。

## 4. 算法细节

1. **排序对象是下标而非值**：作答要回填原下标位置，故对下标数组 `idx` 排序，比较器只比较 `nums1[a] < nums1[b]`，无需次级关键字（同组内处理顺序无关）。
2. **分组用双指针**：外层 `i` 停在组首，内层 `j` 推进到值不同的位置，区间 `[i, j)` 即同值组；先跑一趟"作答"，再跑一趟"入堆"，**两趟顺序不可交换**。
3. **sum 必须增量维护**：每次作答若现算堆内元素和是 $O(k)$，总计 $O(nk) = 10^{10}$ 会超时；入堆加、淘汰减，作答 $O(1)$。
4. **堆的实现**：C++ 用 `priority_queue<int, vector<int>, greater<int>>`（小根堆），Python 的 `heapq` 默认小根堆。堆大小至多 $k+1$，无需手写。
5. **答案类型**：$k \times \max(\text{nums2}) = 10^5 \times 10^6 = 10^{11}$ 超出 32 位 `int` 范围，C++ 中 `sum` 与返回值必须用 `long long`（题目签名已规定返回 `vector<long long>`）。
6. **等价替代**：也可对值域 $[1, 10^6]$ 建"计数 + 求和"两棵树状数组，二分定位第 $k$ 大分界来求前 $k$ 大和，复杂度 $O(n \log V)$；但代码量远大于堆法，比赛中堆法是最优选。

## 5. 正确性证明

**引理 1（最优选取刻画）**：对任意下标 $i$，`answer[i]` 等于候选多重集合 $S_i = \{\text{nums2}[j] \mid \text{nums1}[j] < \text{nums1}[i]\}$ 中最大的 $\min(k, |S_i|)$ 个元素之和。

**证明**：因 $\text{nums2}[j] \ge 1 > 0$，最优选取的元素个数应为 $\min(k, |S_i|)$：若选取个数不足且仍有未选候选，加入任意未选元素总和严格增大；若超过 $k$ 个则不合法。在个数确定的前提下，总和最大即选取值最大的那些元素。∎

**引理 2（堆的前 k 大不变量）**：向容量为 $k$ 的小根堆依次插入元素（插入后若大小超过 $k$ 则弹出堆顶），则任意时刻堆中元素恰为已插入元素（按值构成的多重集合）中最大的 $\min(k, m)$ 个，其中 $m$ 为已插入个数。

**证明**：对 $m$ 归纳。$m = 0$ 时堆空，成立。设插入 $m$ 个后结论成立，考虑插入第 $m+1$ 个元素 $x$：

- 若 $m < k$：归纳假设下堆恰含全部 $m$ 个元素；插入后大小 $m + 1 \le k$，不弹出，堆含全部 $m+1$ 个元素，即最大的 $\min(k, m+1)$ 个。
- 若 $m \ge k$：归纳假设堆 $H$ 恰为前 $k$ 大。临时集合 $H' = H \cup \{x\}$ 大小 $k + 1$，且包含新集合的前 $k+1$ 大（前 $k+1$ 大 $\subseteq$ 前 $k$ 大 $\cup \{x\}$，均含于 $H'$）。弹出 $H'$ 的最小值后，剩余 $k$ 个元素按值构成恰为新集合的前 $k$ 大。∎

**引理 3（候选集激活）**：设组的值严格递增 $v_1 < v_2 < \cdots$。处理组 $v_t$ **作答**时，已入堆元素恰为 $\{\text{nums2}[j] \mid \text{nums1}[j] < v_t\}$，且该组内所有下标共享此候选集。

**证明**：作答发生在组 $v_t$ 入堆之前，故已入堆的恰是前 $t-1$ 组的元素，即 $\{\text{nums2}[j] \mid \text{nums1}[j] \le v_{t-1}\}$。由组值严格递增且覆盖所有出现的值，$\text{nums1}[j] < v_t \iff \text{nums1}[j] \in \{v_1, \dots, v_{t-1}\}$，二者相等。同组内所有下标的 `nums1` 值相同，候选集相同。∎

**定理**：算法对每个 $i$ 输出 $S_i$ 中前 $\min(k, |S_i|)$ 大元素之和，即题意所求。

**证明**：处理 $i$ 所在组（值为 $\text{nums1}[i]$）作答时，由引理 3，已入堆元素恰为 $S_i$；由引理 2，堆中元素恰为 $S_i$ 的前 $\min(k, |S_i|)$ 大；`sum` 为堆内元素之和，故 `answer[i]` 即该和，由引理 1 即为所求。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \log n)$。排序 $O(n \log n)$；每个元素至多入堆一次、出堆一次，单次堆操作 $O(\log k)$，共 $O(n \log k)$；作答与维护 `sum` 均摊 $O(1)$。$n = 10^5$ 时总操作量约 $2 \times 10^6$，轻松通过。
- **空间复杂度**：$O(n)$。排序下标数组与答案数组各 $O(n)$，堆 $O(k) \subseteq O(n)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<long long> findMaxSum(vector<int>& nums1, vector<int>& nums2, int k) {
        int n = nums1.size();
        vector<int> idx(n);
        iota(idx.begin(), idx.end(), 0);
        sort(idx.begin(), idx.end(), [&](int a, int b) {
            return nums1[a] < nums1[b];
        });

        vector<long long> ans(n);
        priority_queue<int, vector<int>, greater<int>> pq;  // 小根堆：维护前 k 大
        long long sum = 0;                                  // 堆内元素和

        for (int i = 0; i < n;) {
            int j = i, v = nums1[idx[i]];
            while (j < n && nums1[idx[j]] == v) {   // 先：整组作答
                ans[idx[j]] = sum;
                j++;
            }
            for (int t = i; t < j; t++) {           // 后：整组入堆
                pq.push(nums2[idx[t]]);
                sum += nums2[idx[t]];
                if ((int)pq.size() > k) {
                    sum -= pq.top();
                    pq.pop();
                }
            }
            i = j;
        }
        return ans;
    }
};
```

### Python

```python
from typing import List
import heapq

class Solution:
    def findMaxSum(self, nums1: List[int], nums2: List[int], k: int) -> List[int]:
        n = len(nums1)
        idx = sorted(range(n), key=lambda i: nums1[i])
        ans = [0] * n
        heap = []  # 小根堆：维护前 k 大
        total = 0  # 堆内元素和
        i = 0
        while i < n:
            j, v = i, nums1[idx[i]]
            while j < n and nums1[idx[j]] == v:    # 先：整组作答
                ans[idx[j]] = total
                j += 1
            for t in range(i, j):                  # 后：整组入堆
                heapq.heappush(heap, nums2[idx[t]])
                total += nums2[idx[t]]
                if len(heap) > k:
                    total -= heapq.heappop(heap)
            i = j
        return ans
```

## 8. 边界情况与易错点

1. **相等值未分组**（最常见 WA）：排序后逐个"作答 + 立即入堆"，`nums1` 相等的元素互相可见，例 2 的全 0 会算成非 0。务必整组先作答、再入堆。
2. **C++ 溢出**：最大答案 $10^5 \times 10^6 = 10^{11} > 2^{31} - 1$，`sum` 与返回值用 `long long`（签名已固定 `vector<long long>`，但中间变量别误用 `int`）。
3. **"至多 k 个"而非"恰好 k 个"**：候选不足 $k$ 个时全选，堆大小自然小于 $k$，`sum` 直接可用，无需特判。
4. **现算堆内和**：每次作答遍历堆求和是 $O(nk) = 10^{10}$，超时；必须入堆加、淘汰减地增量维护。
5. **无候选**：全局最小值（含并列者）答案为 0，`sum` 初始为 0 天然正确。
6. **严格小于**：条件是 `<` 不是 `<=`；排序分组时相等值必须落进同一组。
7. **排序比较器只比值**：加下标次级关键字不影响正确性，但无必要。
