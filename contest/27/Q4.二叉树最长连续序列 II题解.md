# LeetCode 二叉树最长连续序列 II 题解

## 1. 题目概述

- **标题 / 题号**：二叉树最长连续序列 II（#549，medium）
- **链接**：https://leetcode.cn/problems/binary-tree-longest-consecutive-sequence-ii/
- **来源**：LeetCode 第 27 场周赛 Q4
- **难度**：中等
- **标签**：树、深度优先搜索、二叉树、树形 DP

**题意**：给定一棵二叉树，求「最长连续路径」包含的节点个数。一条路径连续，当且仅当沿路径每走一步节点值恰好变化 $1$，并且整条路径必须**单调**：要么一路 $+1$（如 $[1,2,3,4]$），要么一路 $-1$（如 $[4,3,2,1]$），$[1,2,4,3]$ 这种忽上忽下的不算。路径允许是「孩子 → 父亲 → 孩子」的形状，即折点可以落在路径中间。

**约束**：

- 节点值 $v \in [-10^7, 10^7]$：值域极大，不能把值当数组下标或桶
- 树可能为空（返回 $0$），也可能退化成一条链（递归深度可达 $n$）
- 节点总数按该题常见规模 $n \le 10^4$，需要 $O(n)$ 的解法
- 节点值**可以重复**（题面没有保证互不相同），这一点会影响写法

## 2. 示例

**示例 1**

```text
输入：root = [1,2,3]
      1
     / \
    2   3
输出：2
解释：最长连续路径是 [1,2] 或 [2,1]；
     3 与 1 相差 2，不能接在 [1,2] 后面。
```

**示例 2**

```text
输入：root = [2,1,3]
      2
     / \
    1   3
输出：3
解释：最长连续路径是 [1,2,3] 或 [3,2,1]；
     折点 2 的左孩子 1、右孩子 3 连起来恰好是 1 → 2 → 3，长度 3。
```

**示例 3（补充，用于演示「最高点拼接」）**

```text
输入：root = [3,2,4,1,null,null,5]
        3
       / \
      2   4
     /     \
    1       5
输出：5
解释：路径 1 → 2 → 3 → 4 → 5。以 3 为最高点，递减链 3→2→1 长 3，
     递增链 3→4→5 长 3，拼接后 3 + 3 − 1 = 5。
```

## 3. 解题思路

### 3.1 暴力思路

最直白的做法是把每个节点 $v$ 都当作折点：从 $v$ 分别向左右子树深搜，收集所有「向下递增」「向下递减」的连续链，再组合出答案。每个节点做一次 DFS，复杂度 $O(n^2)$，$n = 10^4$ 时是 $10^8$ 量级，Python 必然超时。更笨的「枚举所有点对 $(u,w)$、取出树上路径再逐点判定」是 $O(n^3)$，完全不可行。

暴力的浪费在于**同一条向下链被反复重算**：以 3 的某个孩子为起点的那条链，在「3 当折点」「孩子自己当折点」「孙子当折点」时都要重算一遍。它明明只和「起点 + 子树」有关。

### 3.2 核心观察：每个节点只报两个数

![最高点两侧各是一条单向链](images/wc27_q4_up_down_state.svg)

**观察 1：连续路径一定单调。** 沿路径每步值变化恰为 $1$。若中途变号，就会出现「先升后降」，此时相邻两步的变化不再是同号，路径也就不连续。所以整条路径要么全 $+1$、要么全 $-1$，值在路径上严格单调——**路径上所有节点值互不相同**。

**观察 2：路径在树上必有一个最高点。** 树上任意简单路径 $P$ 都能写成「从最高点 $a$（$P$ 中深度最小的节点）向两侧各走一条**向下**的链」。结合观察 1，设 $P$ 整体递增，则两条向下链中，一条从 $a$ 往下是 $a.val-1, a.val-2, \dots$（递减链），另一条往下是 $a.val+1, a.val+2, \dots$（递增链）。$a.val$ 恰好是路径值域的**中位数**，而不是最大值。

于是每条合法路径都被唯一描述成「$a$ 的一条向下递减链 + 一条向下递增链」，问题从「枚举路径」降维成「**每个节点向下的两条链**」。定义：

- $up[v]$：从 $v$ 出发、只向下走、每步恰好 $+1$ 的最长链长度（含 $v$ 自身）；
- $down[v]$：从 $v$ 出发、只向下走、每步恰好 $-1$ 的最长链长度（含 $v$ 自身）。

两者都只依赖 $v$ 的子树，可以自底向上递推，每个节点只算一次。

### 3.3 算法流程 / 状态转移

![后序 DFS 的状态转移](images/wc27_q4_transition_flow.svg)

对 $v$ 做**后序遍历**：先递归两个孩子拿到它们的 $(up, down)$，再按孩子值与 $v$ 值的关系决定把哪条链接上：

$$up[v] = \max\Bigl(1,\ \max_{c:\ c.val = v.val+1}\bigl(up[c] + 1\bigr)\Bigr)$$

$$down[v] = \max\Bigl(1,\ \max_{c:\ c.val = v.val-1}\bigl(down[c] + 1\bigr)\Bigr)$$

$$ans = \max_{v}\bigl(up[v] + down[v] - 1\bigr)$$

两处细节：

1. 必须写 $\max$，不能写成「条件成立就赋值」。题面**没有**保证值互不相同，两个孩子可能都等于 $v.val+1$（例如 `[1,2,2]`），此时只有更深的那条链能留下。
2. 求和之后要**减 1**，因为最高点 $v$ 被两条链各数了一次。

**为什么可以直接相加？** 能延长 $up[v]$ 的孩子值为 $v.val+1$，能延长 $down[v]$ 的孩子值为 $v.val-1$，两值不同，故必是**不同孩子**（二叉树一个孩子只有一个值）。两条链分别落在 $v$ 的两个不同子树里，只在 $v$ 处相交，拼起来仍是简单路径；再因一侧全 $< v.val$、一侧全 $> v.val$，拼接后整体单调。这两点保证了「相加」永远合法。

### 3.4 示例演算

以补充示例 `[3,2,4,1,null,null,5]` 为例，后序遍历的访问顺序是 1 → 2 → 4 → 3，每个节点只上报两个数：

![后序演算表](images/wc27_q4_walkthrough.svg)

| 处理顺序 | 节点 | $up$ | $down$ | $up+down-1$ | 该节点构成的最长路径 |
| --- | --- | --- | --- | --- | --- |
| 1 | 1 | 1 | 1 | 1 | 1 |
| 2 | 2 | 1 | 2 | 2 | 2 → 1 |
| 3 | 4 | 2 | 1 | 2 | 4 → 5 |
| 4 | 3 | 3 | 3 | **5** | 1 → 2 → 3 → 4 → 5 |

处理根节点 3 时：左孩子 2 的值是 $3-1$，故 $down[3] = 1 + down[2] = 3$，对应链 $3 \to 2 \to 1$；右孩子 4 的值是 $3+1$，故 $up[3] = 1 + up[4] = 3$，对应链 $3 \to 4 \to 5$。两者相加再减一得 $5$，这就是最终答案。

## 4. 算法细节

1. **返回值设计**：`dfs(node)` 返回二元组 `(up, down)`；空节点返回 `(0, 0)` 并且**不更新答案**，否则空子树的 $0$ 会污染 $up+down-1$。
2. **初值**：进入节点时 `up = down = 1`，即先把节点自身计入链长。
3. **只认差 1**：`child.val == node.val + 1` 才允许延长 `up`，`child.val == node.val - 1` 才允许延长 `down`；差 $0$、差 $2$ 及以上一律跳过。
4. **必须取 max**：见 3.3 的第 1 点，重复值场景下两个孩子可能同时满足同一条件。
5. **答案更新时机**：在两个孩子的信息都合并完、函数返回之前更新 `ans = max(ans, up + down - 1)`，保证每个「以 $v$ 为最高点」的候选恰好被检查一次。
6. **状态挂在返回值上**：不需要额外的 DP 数组或哈希表，每个节点只被访问一次，空间开销就是递归栈。
7. **递归深度**：退化成链时深度可达 $n$。C++ 通常无碍，Python 必须 `sys.setrecursionlimit(10**5)`，否则 `RecursionError`；也可以改写显式栈的迭代后序。
8. **值域处理**：`node.val ± 1` 最大到 $10^7+1$，仍在 `int` 范围内，直接比较即可，绝不能用值去开数组。

## 5. 正确性证明

**引理 1（递推正确）**：按 3.3 的递推算出的 $up[v]$ 等于「以 $v$ 为起点、只向下、每步 $+1$」的最长链长度；$down[v]$ 同理（每步 $-1$）。

**证明**：对子树高度归纳。叶子无孩子，$up = down = 1$，成立。设 $v$ 的所有孩子满足结论。任一从 $v$ 出发向下的 $+1$ 链，第一步必定走进某个孩子 $c$，且必须满足 $c.val = v.val + 1$；其后是从 $c$ 出发的 $+1$ 链，长度不超过 $up[c]$。故整条链长度不超过 $1 + \max_{c.val = v.val+1} up[c]$；又取到该最大值的 $c$，把 $v$ 接到它的链上即可达到这个长度，故等号成立。$down$ 完全对称。∎

**引理 2（上界）**：任一合法路径 $P$ 满足 $|P| \le up[a] + down[a] - 1$，其中 $a$ 是 $P$ 中深度最小的节点。

**证明**：设 $P$ 两端为 $x, y$。因 $a$ 深度最小，$P$ 由「$a$ 到 $x$ 的向下链」与「$a$ 到 $y$ 的向下链」组成，两条链只在 $a$ 处相交。由观察 1，$P$ 单调，不妨设沿 $x \to \dots \to a \to \dots \to y$ 值递增。于是 $a \to x$ 方向向下值递减，是每步 $-1$ 的链，长度 $\le down[a]$；$a \to y$ 方向向下值递增，长度 $\le up[a]$。因此 $|P| = |ax| + |ay| - 1 \le up[a] + down[a] - 1$。∎

**引理 3（可达）**：$up[v] + down[v] - 1$ 一定被某条合法路径取到。

**证明**：取实现 $up[v]$ 的递增链，它经过某个孩子 $c_1$，$c_1.val = v.val + 1$；取实现 $down[v]$ 的递减链，它经过某个孩子 $c_2$，$c_2.val = v.val - 1$。由 $c_1.val \ne c_2.val$ 得 $c_1 \ne c_2$，两条链位于不同子树，只在 $v$ 处相交，拼接后是一条简单路径。把递减链倒过来接上递增链，得到 $v-k, \dots, v-1, v, v+1, \dots, v+m$，每步恰好 $+1$，是一条合法连续路径，长度恰为 $up[v] + down[v] - 1$。∎

**定理**：$\max_{v}\bigl(up[v] + down[v] - 1\bigr)$ 等于最长连续路径的长度。

**证明**：记该最大值为 $ans$，最优路径长度为 $OPT$。由引理 2，任意合法路径 $P$ 都有 $|P| \le up[a]+down[a]-1 \le ans$，故 $OPT \le ans$；由引理 3，存在长度恰为某个 $up[v]+down[v]-1$ 的合法路径，故 $ans \le OPT$。两者夹逼得 $ans = OPT$。空树时 $ans$ 保持初值 $0$，与「无路径」的定义一致。∎

## 6. 复杂度分析

- **时间**：$O(n)$。每个节点在后序中被访问一次，内部只做常数次比较（至多两个孩子各一次）与一次加法，没有重复计算。
- **空间**：$O(h)$，$h$ 为树高。除递归栈外不使用任何辅助数组、哈希表。最坏情况（链状树）$h = n$，退化为 $O(n)$；平衡树上为 $O(\log n)$。

## 7. 参考代码

### C++

```cpp
#include <algorithm>
#include <utility>

// TreeNode 由评测系统提供：
// struct TreeNode { int val; TreeNode *left, *right; };

class Solution {
    int ans = 0;

    // 返回 {up, down}：以 node 为起点向下的最长递增 / 递减连续链长度
    std::pair<int, int> dfs(TreeNode* node) {
        if (!node) return {0, 0};
        int up = 1, down = 1;
        TreeNode* kids[2] = {node->left, node->right};
        for (TreeNode* c : kids) {
            if (!c) continue;
            auto [cu, cd] = dfs(c);                    // 先拿到孩子的两个状态
            if (c->val == node->val + 1) up = std::max(up, cu + 1);
            else if (c->val == node->val - 1) down = std::max(down, cd + 1);
        }
        ans = std::max(ans, up + down - 1);            // 以 node 为最高点拼接
        return {up, down};
    }

public:
    int longestConsecutive(TreeNode* root) {
        ans = 0;
        dfs(root);
        return ans;
    }
};
```

### Python

```python
import sys


class Solution:
    def longestConsecutive(self, root) -> int:
        sys.setrecursionlimit(10 ** 5)      # 链状树深度可达 n
        self.ans = 0

        def dfs(node):
            # 返回 (up, down)：以 node 为起点向下的最长递增 / 递减链长度
            if node is None:
                return 0, 0                 # 空树不参与答案更新
            up = down = 1
            for child in (node.left, node.right):
                if child is None:
                    continue
                cu, cd = dfs(child)
                if child.val == node.val + 1:
                    up = max(up, cu + 1)
                elif child.val == node.val - 1:
                    down = max(down, cd + 1)
            self.ans = max(self.ans, up + down - 1)   # 以 node 为最高点拼接
            return up, down

        dfs(root)
        return self.ans
```

## 8. 边界情况与易错点

1. **空树**：返回 $0$。`dfs(None)` 必须返回 `(0, 0)` 且**不更新** `ans`，否则会算出 $-1$。
2. **单节点**：`up = down = 1`，答案为 $1$，不需要特判。
3. **忘记减 1**：写成 $up + down$ 会把最高点数两次，答案恒偏大 $1$。
4. **覆盖式赋值**：`if (child->val == node->val + 1) up = cu + 1;` 在重复值（两个孩子都等于 $v.val+1$）时会丢掉更深的那条链，必须用 `max`。
5. **只沿父亲向下走**：示例 2 的答案来自折线 $1 \to 2 \to 3$，如果只考虑「父 → 子」单向链会得到 $2$，属于典型错误。
6. **值域误用**：节点值可达 $\pm 10^7$ 且可以重复，不能用值当数组下标、桶下标，也不能靠「值唯一」推出路径唯一。
7. **递归过深**：链状树 $n = 10^4$ 时 Python 默认递归上限 $1000$ 会直接 `RecursionError`。
8. **贪心地多接一条链**：若 $v$ 的两个孩子值都等于 $v.val+1$，不能把两条递增链都接上——拼接后会出现 $\dots, v+1, v, v+1, \dots$，相邻差为 $-1$ 再 $+1$，不再单调，路径非法。
