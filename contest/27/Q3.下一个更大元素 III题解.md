# LeetCode 下一个更大元素 III 题解

## 1. 题目概述

- **标题 / 题号**：下一个更大元素 III（#556，medium）
- **链接**：https://leetcode.cn/problems/next-greater-element-iii/
- **来源**：LeetCode 第 27 场周赛 Q3
- **难度**：中等
- **标签**：数学、双指针、字符串

**题意**：给定正整数 $n$，把 $n$ 的**所有十进制数位**重新排列，求**严格大于** $n$ 的**最小**整数。若不存在这样的重排，返回 `-1`；若存在但结果**超出 32 位有符号整数**范围（即大于 $2^{31}-1$），同样返回 `-1`。

**约束**：

- $1 \le n \le 2^{31}-1$
- 因此 $n$ 的位数 $m \le 10$，任何重排都落在 $[0, 10^{10})$ 内，用 64 位整数即可容纳

> 💡 本题本质是**字典序意义下的「下一个排列」**：把 $n$ 的各位数字看成一个长度为 $m$ 的序列，求比它大的最小排列。位数很少（$\le 10$），但正解不是枚举 $m!$ 种排列，而是一次 $O(m)$ 的贪心。

## 2. 示例

**示例 1**

```text
输入：n = 12
输出：21
解释：12 的重排有 12、21；大于 12 的最小者是 21。
```

**示例 2**

```text
输入：n = 21
输出：-1
解释：21 的重排只有 12 和 21，没有比 21 更大的，故返回 -1。
```

**示例 3（补充，覆盖 32 位边界）**

```text
输入：n = 12431
输出：13124
解释：12431 的下一个排列是 13124，这是所有大于它的重排中最小的一个。

输入：n = 1999999999
输出：-1
解释：其下一个排列是 9199999999 > 2^31-1 = 2147483647，超出 32 位，故返回 -1。
```

## 3. 解题思路

### 3.1 暴力思路

枚举 $n$ 的全部不同数位排列，筛出大于 $n$ 的那些，取最小值。位数 $m \le 10$ 时排列数为 $10! = 3628800$，虽然规模勉强能跑，但要点是：

- 需要先去重（`set<permutation>`），否则重复数字会让排列数多算；
- 需要**枚举完再取最小**，而不是找到一个就返回；
- 每次生成排列都是 $O(m)$ 的字符串操作，总代价 $O(m \cdot m!)$，在 Python 里会明显超时。

所以暴力只适合做对拍，正解要找结构。

### 3.2 核心观察：找最靠右的升序对

![下一个排列：最靠右的升序对](images/wc27_q3_next_permutation_concept.svg)

把 $n$ 的数位记为 $d[0..m-1]$（高位在左）。从右往左看，**总会有一段非递增的后缀**。设 $i$ 是**最靠右**的满足 $d[i] < d[i+1]$ 的下标，则：

- $d[i+1..m-1]$ **非递增**（否则会有更靠右的升序对），也就是说这段后缀**已经排成了它自己能排出的最大值**，再动它只会变小；
- 要让数**变大**，第一个变化的位置必须在 $i$ 或 $i$ 的左边；而为了让「变大」的幅度**尽可能小**，第一个变化的位置必须**尽可能靠右**，也就是恰好选 $i$。

于是问题被压成两件事：

1. 把 $d[i]$ 换成后缀中**比它大的最小数字**，使高位只升「最少的一格」；
2. 让它右边的后缀变成**升序**，即后缀能排出的**最小值**。

若整个序列就是非递增的（找不到任何升序对），说明 $n$ 已是最大排列，返回 `-1`（如 $n = 21$、$n = 11$、$n = 1$）。

### 3.3 算法流程

![算法流程：找枢纽、找交换点、交换、反转](images/wc27_q3_greedy_flow.svg)

1. **拆位**：把 $n$ 转成字符串（或 `vector<char>`），得到 $d[0..m-1]$。
2. **找枢纽 $i$**：$i$ 从 $m-2$ 开始左移，找到第一个满足 $d[i] < d[i+1]$ 的位置；若走到 $-1$，返回 `-1`。
3. **找交换点 $j$**：$j$ 从 $m-1$ 开始左移，找到第一个满足 $d[j] > d[i]$ 的位置。由于后缀非递增，**从右往左第一个**大于 $d[i]$ 的正是「后缀中大于 $d[i]$ 的最小值」，$j$ 一定存在（至少有 $i+1$）。
4. **交换** $d[i]$ 与 $d[j]$。
5. **反转** $d[i+1..m-1]$。交换后该后缀**仍然非递增**，反转即得升序，也就是后缀的最小排列。
6. **拼回整数并检查范围**：用 64 位整数承接，若大于 $2^{31}-1$ 返回 `-1`，否则返回该值。

### 3.4 示例演算

![示例演算：n = 12431 → 13124](images/wc27_q3_walkthrough_12431.svg)

以 $n = 12431$ 为例，数位为 `1 2 4 3 1`（下标 0~4）：

| 步骤 | 数位序列 | 说明 |
|------|----------|------|
| 原始 | `1 2 4 3 1` | — |
| 找枢纽 $i$ | `1 [2] 4 3 1` | $d[1]=2 < d[2]=4$，最靠右的升序对，$i=1$ |
| 找交换点 $j$ | `1 2 4 [3] 1` | 从右往左第一个 $> 2$ 的是 $d[3]=3$，$j=3$ |
| 交换 | `1 3 4 2 1` | 第 1 位由 2 升到 3，升幅最小 |
| 反转后缀 | `1 3 1 2 4` | 后缀 `4 2 1` 反转成升序 `1 2 4` |

答案为 $13124$。再走一遍边界：$n = 1999999999$，数位 `1 9 9 9 9 9 9 9 9 9`，枢纽 $i = 0$，交换点取最右的 `9`，交换后反转后缀得到 `9 1 9 9 9 9 9 9 9 9`，即 $9199999999 > 2^{31}-1$，返回 `-1`。

## 4. 算法细节

1. **用字符串操作，不要反复取模**：`to_string(n)` 后可直接按下标交换、`reverse` 后缀，比反复 `% 10`、`/ 10` 再倒序拼装清晰得多；Python 直接 `list(str(n))`。
2. **两个比较都必须严格**：枢纽判据是 $d[i] < d[i+1]$，交换点判据是 $d[j] > d[i]$。若把枢纽放松成 $d[i] \le d[i+1]$，$n = 11$ 这类「各位全相等」的数会被误判成有枢纽，交换后仍是 $11$，不满足「严格大于」；若把交换点放松成 $d[j] \ge d[i]$，$n = 121$ 会拿末位的 $1$ 去和首位交换，重排成 $112 < 121$，方向反了。

3. **交换后后缀仍非递增**（见引理 3），所以「反转」比「排序」更合适：反转是 $O(m)$ 且无需比较器；排序虽然也对，但多花了 $O(m \log m)$ 的思考成本。
4. **拼回整数必须用 64 位**：$m = 10$ 时最大可达 $9876543210 > 2^{31}-1$，`int` 会先溢出成负数再参与比较，判范围必然错。C++ 用 `long long` + `stoll`，Python 的 `int` 天然无溢出，但要显式比较 $2^{31}$。
5. **前导零不用特判**：第 0 位要么保持不变（$i > 0$），要么被换成严格更大的数字（$i = 0$），因此结果首位永远不为 `0`，可以放心整体转成整数。
6. **位数上界**：$n \le 2^{31}-1$ 只有 10 位，所以最坏情况下 $v < 10^{10}$，远小于 $2^{63}-1$，64 位足够。
7. **早退**：一旦在步骤 2 中找到枢纽，就不必再检查更左边；$j$ 的循环也必然在到达 $i+1$ 之前停下，无需额外判空。

## 5. 正确性证明

**引理 1（后缀非递增）**：设 $i$ 是最靠右的满足 $d[i] < d[i+1]$ 的下标，则子数组 $d[i+1..m-1]$ 非递增。

**证明**：反设存在 $k \in [i+1, m-2]$ 使 $d[k] < d[k+1]$，则 $k$ 也是升序对且 $k > i$，与 $i$ 最靠右矛盾。故对一切 $k \in [i+1, m-2]$ 都有 $d[k] \ge d[k+1]$，即后缀非递增。∎

**引理 2（第一个变化点不能越过 $i$）**：设 $x$ 是 $d$ 的任一重排且 $x > d$（按字典序比较，长度相同）。令 $p$ 为 $x$ 与 $d$ 的第一个不同下标，则 $p \le i$。

**证明**：反设 $p > i$。因前 $p$ 位相同，$x$ 的剩余部分 $x[p..m-1]$ 是 $d[p..m-1]$ 的一个排列，而由引理 1，$d[p..m-1]$ 作为非递增序列**已经是该多重集能排出的最大字典序**，故 $x[p..m-1] \le d[p..m-1]$，与 $x > d$（要求 $x[p] > d[p]$）矛盾。∎

**引理 3（交换后后缀仍非递增，反转即最小）**：设 $j$ 是从右往左第一个满足 $d[j] > d[i]$ 的下标，交换 $d[i], d[j]$ 后，$d[i+1..m-1]$ 仍然非递增。

**证明**：记交换后的后缀为 $e[i+1..m-1]$。由 $j$ 的取法：对一切 $k \in (i, j)$ 与 $k > j$ 都有 $d[k] \le d[i]$（否则会有更靠右的位置满足 $> d[i]$）；而 $d[i+1] \ge \dots \ge d[j] > d[i]$。分四段看：

- $j > i+1$ 时，区间 $(i, j)$ 内部与原序列一致，非递增；且 $d[j-1] \ge d[j] > d[i]$，交界也非递增；
- $d[i]$ 与 $d[j+1]$（$j < m-1$ 时）：$d[j+1] \le d[i]$，交界非递增；
- 区间 $(j, m)$ 内部与原序列一致，非递增；
- $j = i+1$ 时中间区间为空，只看后两条，同样成立。

四段拼起来即非递增，反转后为升序，是多重集 $d[i+1..m-1]$ 的最小排列。∎

**定理（算法正确）**：若 $i$ 存在，算法返回的整数 $y$ 是全部严格大于 $n$ 的重排中的最小值；若 $i$ 不存在，则不存在这样的重排，返回 `-1` 正确；若 $y > 2^{31}-1$，返回 `-1` 亦符合题意。

**证明**：

1. **$y > n$**：前 $i$ 位不变，第 $i$ 位由 $d[i]$ 变为 $d[j] > d[i]$，故 $y > n$。
2. **$y$ 最小**：由引理 2，任何更大的重排其第一个变化点满足 $p \le i$。
   - 若 $p < i$：$y$ 的前 $i$ 位与 $d$ 完全相同，故 $y[p] = d[p] < x[p]$，而前 $p-1$ 位 $x$ 与 $y$ 都等于 $d$ 的对应位，于是按字典序 $x > y$；
   - 若 $p = i$：第 $i$ 位必须取后缀中大于 $d[i]$ 的某个数字，其中最小值正是 $j$ 处的 $d[j]$；取定这个最小的高位后，由引理 3，后缀取升序即为最小排列，恰好是算法的输出。

   故 $y$ 是满足条件的重排中的最小值。
3. **无解情形**：若不存在升序对，则 $d$ 非递增、已是最大排列，没有更大的重排，返回 `-1` 正确；若算出的 $y$ 超出 32 位，题目规定返回 `-1`。∎

## 6. 复杂度分析

- **时间**：$O(m)$，其中 $m \le 10$ 是 $n$ 的位数。找枢纽、找交换点各一遍线性扫描，交换 $O(1)$，反转 $O(m)$，字符串转整数 $O(m)$；总共常数级，等价于 $O(\log n)$。
- **空间**：$O(m)$，只需存放数位的字符串/字符数组与少量下标变量，没有额外数据结构。

## 7. 参考代码

### C++

```cpp
#include <string>
#include <algorithm>
#include <climits>
using namespace std;

class Solution {
public:
    int nextGreaterElement(int n) {
        string s = to_string(n);
        int m = s.size();

        // 1. 从右往左找最靠右的升序对：s[i] < s[i+1]
        int i = m - 2;
        while (i >= 0 && s[i] >= s[i + 1]) i--;
        if (i < 0) return -1;          // 整体非递增，已是最大排列

        // 2. 从右往左找第一个严格大于 s[i] 的数字
        int j = m - 1;
        while (s[j] <= s[i]) j--;

        // 3. 交换，并把 i 之后的后缀反转成升序（即最小排列）
        swap(s[i], s[j]);
        reverse(s.begin() + i + 1, s.end());

        // 4. 用 64 位拼回整数，再判 32 位范围
        long long v = stoll(s);
        return v > INT_MAX ? -1 : (int)v;
    }
};
```

### Python

```python
class Solution:
    def nextGreaterElement(self, n: int) -> int:
        d = list(str(n))
        m = len(d)

        # 1. 从右往左找最靠右的升序对：d[i] < d[i+1]
        i = m - 2
        while i >= 0 and d[i] >= d[i + 1]:
            i -= 1
        if i < 0:                      # 整体非递增，已是最大排列
            return -1

        # 2. 从右往左找第一个严格大于 d[i] 的数字
        j = m - 1
        while d[j] <= d[i]:
            j -= 1

        # 3. 交换，并把 i 之后的后缀反转成升序（即最小排列）
        d[i], d[j] = d[j], d[i]
        d[i + 1:] = d[i + 1:][::-1]

        # 4. 拼回整数，判 32 位范围（Python 无溢出，但题目要求）
        res = int(''.join(d))
        return res if res < (1 << 31) else -1
```

## 8. 边界情况与易错点

1. **没有更大的重排**：$n = 1$、$n = 11$、$n = 21$、$n = 10$ 都返回 `-1`。判据是「找不到升序对」，不要用「位数等于 1」之类的特判。
2. **重复数字**：$n = 121$ 的枢纽是 $i=0$（$1<2$），交换点必须取**严格大于**的 $d[1]=2$ 而不是末尾的 $1$，答案是 $211$；若把比较写成 $\le$，会把 $1$ 也当成候选，得到错误结果。
3. **32 位溢出**：$n = 2147483647$ 的下一个排列是 $2147483674 > 2^{31}-1$，返回 `-1`；$n = 1999999999 \to 9199999999$ 同理。必须用 `long long` / `stoll` 承接后再比较，否则 `int` 溢出后判范围失效。
4. **恰好等于最大 32 位整数**：返回值的合法上界是 $2147483647$（含），判断应是 $v > \text{INT\_MAX}$，写成 $\ge$ 会误杀正确答案。
5. **前导零幻觉**：有人担心重排后首位为 `0`，但交换只可能让某位变大，首位要么不变、要么更大，永远不会出现前导零，无需额外处理。
6. **位数上界**：若把范围放宽到 64 位，$m$ 可到 19 位，此时 `long long` 拼装会溢出，需要换成字符串比较或 `__int128`；本题 $m \le 10$ 不存在此问题。
7. **反转而非排序**：交换后后缀已经非递增，`reverse` 即可；若用 `sort` 虽然结果相同，但会把 $O(m)$ 抬到 $O(m \log m)$，且需要额外写比较器。
