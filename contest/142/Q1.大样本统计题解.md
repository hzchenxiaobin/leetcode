# LeetCode 大样本统计 题解

## 1. 题目概述

- **标题 / 题号**：大样本统计（#1093，medium）
- **链接**：https://leetcode.cn/problems/statistics-from-a-large-sample/
- **来源**：LeetCode 第 142 场周赛 Q1
- **难度**：中等
- **标签**：数组、数学、概率与统计

**题意**：对 $[0,255]$ 内的整数采样，`count[k]` 表示整数 $k$ 在样本中出现的次数，样本总量 $N=\sum_k \text{count}[k]$。要求只依据 `count` 求出五个统计量，按 `[minimum, maximum, mean, median, mode]` 的浮点数组返回：最小值、最大值、均值（样本和 / $N$）、中位数（$N$ 为奇取中间元素，为偶取中间两个元素的平均）、众数（题面保证唯一）。

**约束**：

- `count.length == 256`
- $0 \le \text{count}[i] \le 10^9$
- $1 \le \sum \text{count} \le 10^9$
- 众数是唯一的
- 与真实答案误差 $10^{-5}$ 以内的结果都算正确

> 💡 注意题目最关键的设定：值域**固定只有 256 格**，而样本总量可达 $10^9$。所有统计量都必须在这 256 格上算出来，绝不能把样本真的展开。

## 2. 示例

**示例 1**

```text
输入：count = [0,1,3,4,0,0,...]（其余 252 格全 0）
输出：[1.00000, 3.00000, 2.37500, 2.50000, 3.00000]
解释：样本为 [1,2,2,2,3,3,3,3]，N = 8。
     min=1，max=3，mean=19/8=2.375；N 为偶数，中位数 (2+3)/2=2.5；众数 3。
```

**示例 2**

```text
输入：count = [0,4,3,2,2,0,0,...]
输出：[1.00000, 4.00000, 2.18182, 2.00000, 1.00000]
解释：样本为 [1,1,1,1,2,2,2,3,3,4,4]，N = 11。
     mean = 24/11 ≈ 2.181818；N 为奇数，中位数是第 6 个元素 2；众数 1。
```

**示例 3（自造，说明边界）**

```text
输入：count[7] = 1，其余为 0
输出：[7.0, 7.0, 7.0, 7.0, 7.0]
解释：单元素样本，最小值、最大值、均值、中位数、众数全部相同。
```

## 3. 解题思路

### 3.1 暴力思路

最直白的做法是按 `count` 把样本展开成长度为 $N$ 的数组，再排序、求前缀、取中间位置。问题是 $N$ 可达 $10^9$：光是存下来就要约 4 GB，排序更是 $O(N\log N)$，必然超限。即便只想「扫一遍」也不行，因为中位数要求按下标定位。突破点只能是「值域只有 256」这条被忽略的约束。

### 3.2 核心观察：count 就是「已排序的压缩样本」

![count 数组就是已排好序的压缩样本](images/wc142_q1_compress.svg)

`count` 本身就是**按值升序排列的样本的压缩表示**：值 $k$ 连续出现 $\text{count}[k]$ 次。于是五个量逐一被降维：

- **最小值 / 最大值**：最小的 / 最大的 $k$ 使 `count[k] > 0`，与出现次数无关；
- **均值**：样本和 $\sum_k k\cdot\text{count}[k]$ 除以 $N$，一趟 256 次乘加；
- **众数**：$\arg\max_k \text{count}[k]$，题面保证唯一；
- **中位数**：唯一需要动脑的量——它不是「中间那个值」，而是「第几个元素」。设 $P(k)=\sum_{j\le k}\text{count}[j]$ 表示值 $\le k$ 的元素个数，则排序后第 $r$ 个元素（$r$ 从 1 开始）为

$$\mathrm{kth}(r)=\min\{\,k \;:\; P(k)\ge r\,\}$$

于是 $N$ 为奇数时中位数 $=\mathrm{kth}\!\left(\frac{N+1}{2}\right)$，$N$ 为偶数时 $=\frac{1}{2}\left(\mathrm{kth}\!\left(\frac{N}{2}\right)+\mathrm{kth}\!\left(\frac{N}{2}+1\right)\right)$。

![中位数在计数前缀上定位第 rank 个元素](images/wc142_q1_median_rank.svg)

> 💡 这一步把「排序后取中位数」换成了「在单调不减的计数前缀上找第一个越过 rank 的位置」，把 $O(N)$ 的排序替换为 $O(256)$ 的扫描。

### 3.3 算法流程

![两个官方示例的五个统计量](images/wc142_q1_walkthrough.svg)

```text
1. 一趟扫描 k = 0..255：
       count[k] == 0 则跳过
       首个非零 k 记为 min，末个非零 k 记为 max
       total += count[k]，sum += k * count[k]
       用严格大于维护 mode = argmax count[k]
2. mean = sum / total
3. median：
       若 total 为奇数：kth((total + 1) / 2)
       否则：          (kth(total / 2) + kth(total / 2 + 1)) / 2
4. 返回 {min, max, mean, median, mode}
```

### 3.4 示例演算

对示例 1 的 `count`（只有 `count[1]=1`、`count[2]=3`、`count[3]=4` 非零）：

| 量 | 计算过程 | 结果 |
|---|---|---|
| min / max | 首个 / 末个非零下标 | 1 / 3 |
| total | $1+3+4$ | 8 |
| sum | $1\cdot1+2\cdot3+3\cdot4$ | 19 |
| mean | $19/8$ | 2.375 |
| 中位数 | $N$ 偶，rank 4 与 5：$P(1)=1<4\le P(2)=4\Rightarrow 2$，$P(3)=8\ge5\Rightarrow 3$ | $(2+3)/2=2.5$ |
| mode | `count[3]=4` 最大 | 3 |

示例 2 中 $N=11$ 为奇数，只需 rank 6：$P(1)=4<6\le P(2)=7$，故中位数为 2；均值 $24/11\approx2.18182$。

## 4. 算法细节

1. **min/max 用哨兵**：`count[0]` 与 `count[255]` 都可能为 0，所以用 `mn = -1` 表示「还没遇到非零」，不能被下标 0 误导。
2. **众数初值**：`mode = 0` 配合严格大于比较即可；若 `count[0] = 0` 而其它位置有正计数，第一次比较就会更新。
3. **避免整型溢出**：$k\cdot\text{count}[k] \le 255\times10^9 = 2.55\times10^{11}$，C++ 的 `sum` 必须用 `long long`；`total` 同理（Python 无此问题）。
4. **rank 公式**：奇数用 $\frac{N+1}{2}$（代码写 `total / 2 + 1`），偶数用 `total / 2` 与 `total / 2 + 1`。$N=11$ 时 `total/2+1 = 6`，写成 `total/2` 就错位成 5。
5. **kth 的边界**：题面保证 $N\ge1$，rank 必落在 $[1,N]$，循环一定能返回；末尾 `return 255.0` 只是编译器兜底。
6. **浮点精度**：`sum` 与 `total` 都是绝对值不超过 $2^{53}$ 的精确整数，一次除法即可，无需额外补偿；输出保留 5~6 位小数满足 $10^{-5}$。
7. **不必二分**：值域只有 256，线性前缀定位已经是常数级，写二分只会增加出错面。

## 5. 正确性证明

**引理 1（极值）**：设 $S=\{k:\text{count}[k]>0\}$，则样本的最小值 $=\min S$，最大值 $=\max S$。

**证明**：样本恰为多重集 $\{\,k \text{ 重复 } \text{count}[k] \text{ 次} : k\in S\,\}$，其元素取值集合正是 $S$，故最小值、最大值分别为 $\min S$ 与 $\max S$。算法取首个、末个非零下标，正是这两个值。∎

**引理 2（kth 正确）**：对任意 $1\le r\le N$，$\mathrm{kth}(r)$ 等于排序后的第 $r$ 个元素。

**证明**：$P(k)$ 是值 $\le k$ 的元素个数，故排序后前 $P(k)$ 个元素都 $\le k$，且第 $P(k)+1$ 个元素 $>k$。取最小的 $k^*$ 使 $P(k^*)\ge r$，则 $P(k^*-1)<r\le P(k^*)$，说明第 $r$ 个元素落在「值恰为 $k^*$ 的那一段」内，即等于 $k^*$。算法从 $k=0$ 起累加，在首个 $acc\ge r$ 时返回，返回的正是 $k^*$。∎

**引理 3（中位数公式）**：$N$ 为奇数时中位数为第 $(N+1)/2$ 个元素；$N$ 为偶数时为第 $N/2$ 与第 $N/2+1$ 个元素的平均。

**证明**：直接由中位数的定义（排序后取中间位置；偶数取中间两者平均）即得。∎

**定理**：算法返回的五元组分别等于题目定义的最小值、最大值、均值、中位数、众数。

**证明**：由引理 1 得前两项正确；`sum` 为样本和、`total` 为样本数，故 `mean = sum/total` 正确；由引理 2、3 得中位数正确；`mode` 取 `count` 最大值对应的下标，即出现次数最多的值，题面保证其唯一，故众数正确。五项各自与定义相符，定理成立。∎

## 6. 复杂度分析

- **时间**：$O(256)$。一趟 256 格聚合；中位数至多做两次 256 格的前缀定位。总开销与样本总量 $N$（可达 $10^9$）无关。
- **空间**：$O(1)$。除返回的 5 个 `double` 外只用了若干标量；输入数组不计。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<double> sampleStats(vector<int>& count) {
        long long total = 0, sum = 0;
        int mn = -1, mx = -1, mode = 0;
        for (int k = 0; k < 256; k++) {
            if (count[k] == 0) continue;
            if (mn == -1) mn = k;            // 第一个非零计数即最小值
            mx = k;                          // 扫描到最后一个非零即最大值
            total += count[k];
            sum += (long long)k * count[k];
            if (count[k] > count[mode]) mode = k;   // 众数唯一，取计数最大者
        }
        // 排序后第 rank 个元素（rank 从 1 开始），用计数前缀定位
        auto kth = [&](long long rank) -> double {
            long long acc = 0;
            for (int k = 0; k < 256; k++) {
                acc += count[k];
                if (acc >= rank) return (double)k;
            }
            return 255.0;
        };
        double mean = (double)sum / (double)total;
        double median = (total % 2 == 1)
                        ? kth(total / 2 + 1)
                        : (kth(total / 2) + kth(total / 2 + 1)) / 2.0;
        return {(double)mn, (double)mx, mean, median, (double)mode};
    }
};
```

### Python

```python
class Solution:
    def sampleStats(self, count: list[int]) -> list[float]:
        total = sum(count)
        mean = sum(k * c for k, c in enumerate(count)) / total
        lo = next(k for k in range(256) if count[k])
        hi = next(k for k in range(255, -1, -1) if count[k])
        mode = max(range(256), key=lambda k: count[k])   # 众数唯一，取计数最大者

        def kth(rank: int) -> float:
            """排序后第 rank 个元素（rank 从 1 开始）。"""
            acc = 0
            for k, c in enumerate(count):
                acc += c
                if acc >= rank:
                    return float(k)
            return 255.0

        if total % 2:
            median = kth(total // 2 + 1)
        else:
            median = (kth(total // 2) + kth(total // 2 + 1)) / 2.0
        return [float(lo), float(hi), mean, median, float(mode)]
```

## 8. 边界情况与易错点

1. **不能展开样本**：$N \le 10^9$，展开就是 MLE/TLE，这是本题第一道分水岭。
2. **`sum` 溢出**：$2.55\times10^{11}$ 超过 32 位，C++ 必须 `long long`（或用 `double` 但会丢精度）。
3. **极值不在端点**：`count[0]`、`count[255]` 都可能为 0，示例 1 的最小值就是 1，不能用下标 0 充当。
4. **中位数是「第几个」不是「哪个值」**：偶数样本要取两个 rank 再平均，少取一个就会得到整数而非 2.5。
5. **rank 的奇偶分支**：奇数分支要用 `N/2 + 1`，写成 `N/2` 会拿到下中位数。
6. **众数唯一性**：依赖题面「众数唯一」，因此严格大于取第一个最大值即可，不需要额外的字典序 tie-break。
7. **返回类型是 `double`**：min / max / mode 也要转成浮点，不能返回整型数组。
8. **$N=1$**：五个量全部等于那个唯一的值，rank 1 必然命中，任何分支都不应越界。
