# LeetCode 统计好三元组 题解

## 1. 题目概述

- **标题 / 题号**：统计好三元组（#1534，easy）
- **链接**：https://leetcode.cn/problems/count-good-triplets/
- **来源**：LeetCode 第 200 场周赛 Q1
- **难度**：简单
- **标签**：数组、枚举

**题意**：给定整数数组 `arr` 和三个整数 `a`、`b`、`c`。统计满足以下全部条件的三元组 `(arr[i], arr[j], arr[k])` 的数量：

- $0 \le i < j < k < arr.length$
- $|arr[i] - arr[j]| \le a$
- $|arr[j] - arr[k]| \le b$
- $|arr[i] - arr[k]| \le c$

返回好三元组的数量。注意三元组由**下标** $(i,j,k)$ 区分，值相同但下标不同的三元组分别计数。

**约束**：

- `3 <= arr.length <= 100`
- `0 <= arr[i] <= 1000`
- `0 <= a, b, c <= 1000`

## 2. 示例

**示例 1**

```text
输入：arr = [3,0,1,1,9,7], a = 7, b = 2, c = 3
输出：4
解释：一共有 4 个好三元组：[(3,0,1), (3,0,1), (3,1,1), (0,1,1)]。
```

**示例 2**

```text
输入：arr = [1,1,2,2,3], a = 0, b = 0, c = 1
输出：0
解释：不存在满足所有条件的三元组。
```

## 3. 解题思路

### 3.1 暴力思路

签到题，数据范围就是提示：$n \le 100$，所有下标三元组至多 $\binom{100}{3} = 161700$ 个。**三重循环枚举 $(i,j,k)$，逐一判定三个绝对值条件**就是正解，不需要任何数据结构。

### 3.2 核心观察：循环顺序保证下标条件 + 逐对判定

![三重循环枚举与三条件判定](images/good_triplets_enumeration.svg)

- 枚举顺序 `i < j < k` 天然满足下标条件，无需额外判下标；
- 三个条件相互独立，只与**下标对的值差**有关，逐一检查即可；
- **剪枝**：条件 $|arr[i] - arr[j]| \le a$ 只含 `i, j`，放在 `k` 循环之前判，不满足直接跳过整层 `k` 循环，能砍掉大量无效枚举（见 3.4 示例中 9 那一支被整层跳过）。

### 3.3 算法流程

```text
ans = 0
for i in 0 .. n-3:
    for j in i+1 .. n-2:
        if |arr[i] - arr[j]| > a:  continue      # 剪枝，跳过 k 层
        for k in j+1 .. n-1:
            if |arr[j] - arr[k]| <= b and |arr[i] - arr[k]| <= c:
                ans = ans + 1
返回 ans
```

### 3.4 示例演算

![示例一演算：4 个好三元组与 1 次剪枝](images/good_triplets_example_walkthrough.svg)

以 `arr = [3,0,1,1,9,7], a = 7, b = 2, c = 3` 演算，4 个好三元组与 1 次典型剪枝如下：

| 下标 $(i,j,k)$ | 值三元组 | $\lvert arr[i]-arr[j]\rvert \le a$ | $\lvert arr[j]-arr[k]\rvert \le b$ | $\lvert arr[i]-arr[k]\rvert \le c$ | 计数 |
|---|---|---|---|---|---|
| (0,1,2) | (3,0,1) | $3 \le 7$ ✓ | $1 \le 2$ ✓ | $2 \le 3$ ✓ | +1 |
| (0,1,3) | (3,0,1) | $3 \le 7$ ✓ | $1 \le 2$ ✓ | $2 \le 3$ ✓ | +1 |
| (0,2,3) | (3,1,1) | $2 \le 7$ ✓ | $0 \le 2$ ✓ | $2 \le 3$ ✓ | +1 |
| (1,2,3) | (0,1,1) | $1 \le 7$ ✓ | $0 \le 2$ ✓ | $1 \le 3$ ✓ | +1 |
| (0,1,4) | (3,0,9) | $3 \le 7$ ✓ | $9 > 2$ ✗ | — | 剪掉 |

最终 `ans = 4` ✓。注意前两行值都是 $(3,0,1)$ 但下标不同，各计一次。

## 4. 算法细节

1. **枚举顺序**：外层 `i` 从 0 到 `n-3`，中层 `j` 从 `i+1` 到 `n-2`，内层 `k` 从 `j+1` 到 `n-1`，保证 $i<j<k$ 不重不漏。
2. **计数器类型**：答案上界 $\binom{100}{3} = 161700$，`int` 足够，无溢出风险。
3. **剪枝位置**：`a` 条件只依赖 `(i, j)`，在进入 `k` 循环前判断；`b`、`c` 条件在 `k` 循环内判断，且用 `&&` 短路（`b` 条件通常先失败）。
4. **Python 写法**：三重循环最直观；也可以用 `itertools.combinations(arr, 3)` 一行统计，但无法剪枝，好在本题规模下无所谓。

## 5. 正确性证明

**引理 1**：三重循环按 `i < j < k` 枚举，每个满足下标条件的三元组被访问**恰好一次**。

**证明**：对任意下标三元组 $(i,j,k)$ 满足 $i<j<k$，循环变量取值 $(i,j,k)$ 唯一对应它；反之每组循环变量取值唯一对应一个下标三元组。不同的循环变量组对应不同的下标三元组，故枚举不重不漏。∎

**定理**：算法返回值等于好三元组的数量。

**证明**：由引理 1，所有满足 $0 \le i < j < k < n$ 的三元组均被枚举恰好一次。对每个被枚举的三元组，三个条件 $|arr[i]-arr[j]| \le a$、$|arr[j]-arr[k]| \le b$、$|arr[i]-arr[k]| \le c$ 与题意逐字对应，计数器当且仅当三条件同时成立时加一。剪枝只跳过 `a` 条件已失败的三元组，而这类三元组必然不是好三元组，不影响计数正确性。故计数器终值即好三元组总数。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n^3)$，其中 $n \le 100$，最坏约 $1.6 \times 10^5$ 次条件判定，远低于时限；剪枝后实际更快。
- **空间复杂度**：$O(1)$，仅使用常数个额外变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int countGoodTriplets(vector<int>& arr, int a, int b, int c) {
        int n = arr.size(), ans = 0;
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                if (abs(arr[i] - arr[j]) > a) continue;  // 剪枝：跳过整层 k
                for (int k = j + 1; k < n; k++) {
                    if (abs(arr[j] - arr[k]) <= b && abs(arr[i] - arr[k]) <= c) {
                        ans++;
                    }
                }
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def countGoodTriplets(self, arr: List[int], a: int, b: int, c: int) -> int:
        n = len(arr)
        ans = 0
        for i in range(n):
            for j in range(i + 1, n):
                if abs(arr[i] - arr[j]) > a:
                    continue  # 剪枝：跳过整层 k
                for k in range(j + 1, n):
                    if abs(arr[j] - arr[k]) <= b and abs(arr[i] - arr[k]) <= c:
                        ans += 1
        return ans
```

## 8. 边界情况与易错点

1. **三元组按值还是按下标区分**：按下标！示例 1 中 $(3,0,1)$ 出现两次都要计入，千万别去重。
2. **条件是 $\le$ 不是 $<$**：$|arr[i] - arr[j]| = a$ 时依然满足。
3. **`a, b, c` 可为 0**：此时要求对应两值**完全相等**，如示例 2 中 `a = b = 0` 逼出三个相等值，而数组里没有三元重复，答案为 0。
4. **剪枝别判错方向**：是 `> a` 时 `continue`（条件失败跳过），不是 `<= a`。
5. **循环边界**：`j` 从 `i+1` 开始、`k` 从 `j+1` 开始，写成 `i` 开始会枚举出下标非法或重复的三元组。
6. **无需排序**：条件只关于值差与下标顺序，排序会破坏下标约束 `i < j < k`。
