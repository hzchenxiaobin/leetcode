# LeetCode 三元素表达式的最大值 题解

## 1. 题目概述

- **标题 / 题号**：三元素表达式的最大值（#3745，easy）
- **链接**：https://leetcode.cn/problems/maximize-expression-of-three-elements/
- **来源**：LeetCode 第 476 场周赛 Q1
- **难度**：简单
- **标签**：贪心、数组、排序

**题意**：给定整数数组 `nums`，从中选择三个**下标互不相同**的元素，分别作为 $a$、$b$、$c$ 代入表达式 $a + b - c$，返回该表达式可能取得的最大值。

**约束**：

- $3 \le nums.length \le 100$
- $-100 \le nums[i] \le 100$

> 💡 数据范围极小（$n \le 100$），$O(n^3)$ 暴力也能过；但签到题追求"从题面到代码的最短路径"，贪心 $O(n)$ 更快更稳。

## 2. 示例

**示例 1**

```text
输入：nums = [1, 4, 2, 5]
输出：8
解释：选 a = 4，b = 5，c = 1，表达式值 = 4 + 5 - 1 = 8。
```

**示例 2**

```text
输入：nums = [-2, 0, 5, -2, 4]
输出：11
解释：选 a = 5，b = 4，c = -2，表达式值 = 5 + 4 - (-2) = 11。
```

**补充示例 3（全负数组）**

```text
输入：nums = [-5, -1, -3]
输出：1
解释：选 a = -1，b = -3，c = -5，表达式值 = -1 + (-3) - (-5) = 1。
减去最负的数反而是正贡献。
```

## 3. 解题思路

### 3.1 暴力思路

枚举三个互不相同的下标 $i$、$j$、$k$，计算 $nums[i] + nums[j] - nums[k]$ 后取最大值。有序三元组共 $100 \times 99 \times 98 \approx 10^6$ 个，赛时能过。

但三重循环加上"哪个数作减数"的角色分配容易写错，签到题不值得。

### 3.2 核心观察：加号吃大的，减号吃小的

表达式只有三个"槽位"：

- **两个加号槽位** $a$、$b$：放进去的数越大，表达式越大 → 应放**最大的两个数**；
- **一个减号槽位** $c$：放进去的数越小，表达式越大 → 应放**最小的数**。

![加号槽位与减号槽位的贪心分配](images/wc476_q1_plus_minus_slots.svg)

**合法性**：$n \ge 3$ 时，最小值与最大的两个数必然落在排序后三个互不相同的位置上，"下标互不相同"自动满足，无需任何特判。

> 💡 一句话：**答案 = 最大值 + 次大值 − 最小值**。$a$、$b$ 在表达式中完全对称，不必区分谁取最大谁取次大。

### 3.3 算法流程

两条实现路径任选其一：

**路径一：排序**

```text
将 nums 升序排序
答案 = nums[n-1] + nums[n-2] - nums[0]
```

时间 $O(n \log n)$，代码最短，赛时首选。

**路径二：一遍扫描**

维护最大值 $m_1$、次大值 $m_2$、最小值 $mn$，对每个 $x \in nums$：

1. 若 $x > m_1$：先 $m_2 \leftarrow m_1$，再 $m_1 \leftarrow x$；
2. 否则若 $x > m_2$：$m_2 \leftarrow x$；
3. 无条件 $mn \leftarrow \min(mn, x)$。

时间 $O(n)$、额外空间 $O(1)$，数据范围放大后依然稳。

### 3.4 示例演算

以示例 2（含负数，最有代表性）走一遍：`nums = [-2, 0, 5, -2, 4]`。

| 步骤 | 内容 | 结果 |
|------|------|------|
| ① 排序（降序） | `[5, 4, 0, -2, -2]` | 最大 5、次大 4、最小 −2 |
| ② 分配槽位 | a = 5，b = 4，c = −2 | 三个下标互异 ✓ |
| ③ 代入表达式 | $5 + 4 - (-2) = 9 + 2$ | **11** |

![示例 2 的完整演算](images/wc476_q1_example_walkthrough.svg)

## 4. 算法细节

1. **一遍扫描的更新顺序**：必须先把 $m_1$ 的旧值传给 $m_2$，再更新 $m_1$；顺序颠倒会丢失次大值。
2. **相等元素**：判断用严格大于。如 `[5, 5, 3]`，第二个 5 走"否则若 $x > m_2$"分支，$m_2$ 正确变为 5（两个 5 位于不同下标，合法）。
3. **贪心合法性完全依赖 $n \ge 3$**：这正是约束的下界，题目已保证，无需特判。
4. **无需取模**：结果直接返回。

## 5. 正确性证明

**引理 1（上界）**：设 $M_1$、$M_2$ 为数组中两个不同位置上的最大值与次大值，$m$ 为全局最小值，则任意合法方案满足 $a + b - c \le M_1 + M_2 - m$。

**证明**：$a$ 与 $b$ 位于不同位置，因此 $a + b$ 不超过"两个不同位置元素之和"的最大值，即 $a + b \le M_1 + M_2$；又 $c \ge m$，故 $-c \le -m$。两式相加即得。∎

**引理 2（可达性）**：取 $a = M_1$、$b = M_2$、$c = m$ 是合法方案（三个下标互不相同）。

**证明**：将数组排序为 $x_1 \le x_2 \le \cdots \le x_n$（$n \ge 3$）。$M_1 = x_n$ 位于位置 $n-1$，$M_2 = x_{n-1}$ 位于位置 $n-2$，$m = x_1$ 位于位置 $0$。由 $n \ge 3$ 得 $n-1 > n-2 > 0$，三个位置两两不同。∎

**定理**：表达式 $a + b - c$ 的最大值等于 $M_1 + M_2 - m$。

**证明**：由引理 1，$M_1 + M_2 - m$ 是所有合法方案值的上界；由引理 2，该值可以取到。上界可达即为最大值。∎

## 6. 复杂度分析

- **时间复杂度**：排序写法 $O(n \log n)$；一遍扫描写法 $O(n)$。$n \le 100$，两者均瞬间完成。
- **空间复杂度**：排序写法 $O(\log n)$（语言内置排序的递归栈）；一遍扫描写法 $O(1)$ 额外空间。

## 7. 参考代码

### C++

```cpp
// 排序写法：赛时最短路径
class Solution {
public:
    int maximizeExpressionOfThree(vector<int>& nums) {
        sort(nums.begin(), nums.end());
        int n = nums.size();
        return nums[n - 1] + nums[n - 2] - nums[0];
    }
};
```

```cpp
// 一遍扫描写法：O(n) 时间 + O(1) 空间
class Solution {
public:
    int maximizeExpressionOfThree(vector<int>& nums) {
        int m1 = INT_MIN, m2 = INT_MIN, mn = INT_MAX;
        for (int x : nums) {
            if (x > m1) {
                m2 = m1;
                m1 = x;
            } else if (x > m2) {
                m2 = x;
            }
            mn = min(mn, x);
        }
        return m1 + m2 - mn;
    }
};
```

### Python


```python
class Solution:
    def maximizeExpressionOfThree(self, nums: List[int]) -> int:
        m1 = m2 = float('-inf')
        mn = float('inf')
        for x in nums:
            if x > m1:
                m1, m2 = x, m1
            elif x > m2:
                m2 = x
            mn = min(mn, x)
        return m1 + m2 - mn
```

## 8. 边界情况与易错点

1. **全负数组**：$c$ 仍取最小（最负）值，$-c$ 反而是正贡献。如 `[-5, -1, -3]` 答案为 1，别把"取最大"误用到 $c$ 上。
2. **$a$、$b$ 对称**：两个 "+" 槽位不区分顺序，不要纠结"谁必须更大"。
3. **值相等**：最大的两个值可以数值相同（不同下标），照常取，互异性不受影响。
4. **$n = 3$**：排序后三个位置 $0, 1, 2$ 恰好分给 $c, b, a$，天然互异，是最小规模的自证。
5. **题目只要求下标互异**：不要求 $i < j < k$ 保序，别自加限制把贪心想复杂。
6. **溢出**：本题 $|nums[i]| \le 100$，`int` 足够；若范围放大到 $10^9$ 量级，C++ 需改用 `long long`。
