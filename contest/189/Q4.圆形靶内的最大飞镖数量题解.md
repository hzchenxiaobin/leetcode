# LeetCode 圆形靶内的最大飞镖数量 题解

## 1. 题目概述

- **标题 / 题号**：圆形靶内的最大飞镖数量（#1453，hard）
- **链接**：https://leetcode.cn/problems/maximum-number-of-darts-inside-of-a-circular-dartboard/
- **来源**：LeetCode 第 189 场周赛 Q4
- **难度**：困难
- **标签**：几何、数组、数学、枚举

**题意**：平面上给出 $n$ 个互不相同的飞镖落点 `darts[i] = [xi, yi]`，要求放置一个**半径固定为 $r$** 的圆（圆心可任选），使落在圆内或圆上的飞镖数最多，返回这个最大数量。

**约束**：

- $1 \le n = \text{darts.length} \le 100$
- $-10^4 \le x_i, y_i \le 10^4$
- `darts` 中元素互不相同
- $1 \le r \le 5000$

> 💡 一句话定位：**圆心是连续的，但最优圆心只需在「过某两个飞镖、半径为 $r$」的那至多两个点里找**——用一条几何引理把无穷候选压成 $O(n^2)$ 个。

## 2. 示例

**示例 1**

```text
输入：darts = [[-2,0],[2,0],[0,2],[0,-2]], r = 2
输出：4
解释：圆心取 (0,0)、半径 2，四枚飞镖到圆心的距离都恰为 2，全部落在靶上。
```

**示例 2**

```text
输入：darts = [[-3,0],[3,0],[2,6],[5,4],[0,9],[7,8]], r = 5
输出：5
解释：圆心取 (0,4)、半径 5，除 (7,8) 外的 5 枚飞镖都在靶内或靶上；
      (7,8) 到 (0,4) 的距离为 √65 ≈ 8.06 > 5，落在靶外。
```

## 3. 解题思路

### 3.1 暴力思路

圆心可以在平面上任意取，直接枚举不可行：

- **网格采样**：把坐标范围按步长 $\delta$ 离散化，枚举每个格点当圆心再 $O(n)$ 计数。步长取大了会错过只在小区域内才最优的圆（示例 2 的最优圆心是一个孤立点），取小了枚举量爆炸，且永远无法证明「没有漏」。
- **以飞镖为圆心**：只枚举 $n$ 个飞镖位置，$O(n^2)$。但示例 2 的最优圆心 $(0,4)$ 并不是任何一枚飞镖，这种做法直接漏掉答案 5。

所以关键不是「怎么更快地枚举圆心」，而是**先证明候选圆心只有有限个**。

### 3.2 核心观察：最优圆边界上必有两枚飞镖

![过两枚飞镖的两个候选圆心](images/wc189_q4_two_centers.svg)

**引理（边界规范化）**：若某个半径为 $r$ 的圆至少覆盖 $k$ 枚飞镖（$k\ge 2$），则一定存在另一个半径同为 $r$ 的圆，至少覆盖这 $k$ 枚飞镖，且**边界上至少落着其中 2 枚**。

直观操作分两步：

1. **平移**：从当前圆心出发，沿任意方向缓慢移动，直到这 $k$ 枚飞镖中第一枚碰到边界为止。碰到之前这 $k$ 枚始终在圆内，覆盖数只增不减。
2. **旋转**：固定这枚边界飞镖 $A$，让圆心沿「以 $A$ 为圆心、半径 $r$ 的圆」滑动（等价于靶绕 $A$ 滚动）。取除 $A$ 外第一枚到达边界的飞镖作为 $B$——它可能从圆内碰到边界，也可能正是即将滑出的那一枚；在 $B$ 到达边界之前，这 $k$ 枚中除 $A$、$B$ 外的飞镖都严格在圆内，因此这 $k$ 枚不会被挤出。停下时 $A$、$B$ 同时落在边界上。

于是最优解可以假设「至少两枚飞镖在边界上」。设这两枚为 $A=(x_1,y_1)$、$B=(x_2,y_2)$，令 $d=|AB|$。圆心 $C$ 满足 $|CA|=|CB|=r$，故 $C$ 在 $AB$ 的**中垂线**上。记中点 $M=\frac{A+B}{2}$，中点到圆心的距离由勾股定理给出：

$$h=\sqrt{r^{2}-\left(\frac{d}{2}\right)^{2}}$$

$AB$ 的单位垂直向量为 $u=\dfrac{(-\Delta y,\ \Delta x)}{d}$，其中 $\Delta x=x_2-x_1$、$\Delta y=y_2-y_1$。两个候选圆心就是

$$C_{1}=M+h\,u,\qquad C_{2}=M-h\,u$$

当 $d>2r$ 时根号内为负，两点不可能被同一个半径 $r$ 的圆同时覆盖，直接跳过；$d=2r$ 时 $h=0$，两圆心重合于中点，退化为一个候选。

### 3.3 算法流程

![枚举点对、解圆心、计数取最大](images/wc189_q4_enum_flow.svg)

1. **初始化** `ans = 1`：至少要覆盖 1 枚飞镖，处理「任意两点距离都大于 $2r$」的情形。
2. **枚举点对**：对所有 $i<j$ 计算 $d=|P_iP_j|$。
3. **剪枝**：若 $d>2r$（加浮点容差），跳过该点对。
4. **求圆心**：算中点 $M$、垂直单位向量 $u$、高度 $h$，得到 $C_1$、$C_2$。
5. **计数**：对每个候选圆心，$O(n)$ 统计满足 $\operatorname{dist}(P_k,C)\le r+\varepsilon$ 的飞镖数，用它更新 `ans`。

### 3.4 示例演算

![示例 2：圆心 (0,4) 覆盖 5 枚飞镖](images/wc189_q4_example_walkthrough.svg)

对示例 2 取点对 $(-3,0)$ 与 $(3,0)$：$d=6$，中点 $M=(0,0)$，$h=\sqrt{25-9}=4$，两个候选圆心为 $(0,4)$ 与 $(0,-4)$。

| 候选圆心 | 各飞镖到圆心的距离 | 覆盖数 |
|----------|--------------------|--------|
| $(0,4)$ | $5,\ 5,\ \sqrt{8},\ 5,\ 5,\ \sqrt{65}$ | $5$ |
| $(0,-4)$ | $5,\ 5,\ \sqrt{104},\ \sqrt{89},\ 13,\ \sqrt{193}$ | $2$ |

其中 $(0,4)$ 把 $(-3,0)$、$(3,0)$、$(5,4)$、$(0,9)$ 放在边界上，$(2,6)$ 在内部，只有 $(7,8)$ 在圆外，计数为 $5$，成为答案。$(0,4)$ 不是任何飞镖坐标，这正是「以飞镖为圆心」会漏解的直接证据。

## 4. 算法细节

1. **初始值必须是 1**：`ans` 不能从 0 开始，否则当所有点两两距离都大于 $2r$ 时会返回 0；题目保证 $n\ge 1$，至少能覆盖一枚。
2. **剪枝要带容差**：写成 `d > 2*r + eps` 而不是 `d > 2*r`。当 $d$ 恰好等于 $2r$ 时，浮点误差可能把合法的相切情况误判为无解。
3. **$d=2r$ 的退化**：此时 $h=0$，两个候选圆心相同，循环两次会重复计数，但结果不受影响；无需特判。
4. **垂直向量方向无所谓**：$u$ 取 $(-\Delta y,\Delta x)/d$ 还是 $(\Delta y,-\Delta x)/d$，配合 $\pm h$ 得到的仍是同一对圆心，只要两个符号都试即可。
5. **比较距离而不是距离平方**：圆心由开方与除法算出，本身带约 $10^{-9}$ 误差。直接比较 `hypot(...) <= r + eps` 时误差同量级，$10^{-7}$ 足够；若比较平方距离，误差被放大到约 $2r\delta$，需要更大的容差，容易误判。
6. **防除零**：`dd = max(d, eps)`。题目保证飞镖互不相同，正常不会出现 $d=0$；保留这一行可避免将来改动输入假设时除零。
7. **点对的数量**：$\binom{n}{2}\le 4950$，每对至多 2 个圆心，每个圆心扫 $n=100$ 个点，总计约 $10^6$ 次距离计算，无需任何数据结构优化。

## 5. 正确性证明

**引理 1（边界规范化）**：若半径为 $r$ 的圆覆盖集合 $S$ 且 $|S|\ge 2$，则存在半径 $r$ 的圆覆盖 $S$，且边界上至少有两枚 $S$ 中的飞镖。

**证明**：设当前圆心为 $c$。若 $S$ 中已有两枚在边界上，结论成立；否则 $S$ 中至多一枚在边界上。若一枚也不在边界上，先做平移：沿任一方向移动 $c$，直到某一枚 $A\in S$ 第一次到达边界；在这之前所有 $S$ 中的点到圆心的距离都小于 $r$，覆盖集合始终包含 $S$。若已有一枚在边界上，直接取它为 $A$。

接着固定 $A$ 在边界上，令圆心沿以 $A$ 为圆心、半径 $r$ 的圆连续滑动。取另一枚 $B\in S$，$B\ne A$。当圆心沿完整圆周滑动时，$B$ 到圆心的距离的最大值为 $|AB|+r>r$（因 $B\ne A$），故必存在某个时刻该距离等于 $r$，即 $B$ 到达边界。由连续性，滑动初期除 $A$ 外的点都严格在圆内。设 $t$ 为「除 $A$ 外第一枚 $S$ 中的点到达边界」的最早时刻；在 $t$ 之前除 $A$ 外的点距离都小于 $r$，覆盖集合始终包含 $S$。时刻 $t$ 时 $A$ 与另一枚飞镖同时在边界上，结论成立。∎

**引理 2（候选圆心公式完备）**：对任意两点 $A,B$，半径 $r$ 的圆同时经过 $A,B$ 的圆心集合，当 $d=|AB|\le 2r$ 时恰为 3.2 节给出的 $C_1,C_2$；当 $d>2r$ 时为空。

**证明**：圆心 $C$ 同时经过 $A,B$ 等价于 $|CA|=|CB|=r$。由 $|CA|=|CB|$ 知 $C$ 在 $AB$ 的中垂线上，可写成 $C=M+t\,u$，$t\in\mathbb{R}$。于是
$$|CA|^{2}=\left(\frac{d}{2}\right)^{2}+t^{2}=r^{2}\iff t^{2}=r^{2}-\frac{d^{2}}{4}.$$
当 $d\le 2r$ 时 $t=\pm h$，恰有两个解（$h=0$ 时两解重合）；当 $d>2r$ 时无实解。∎

**定理**：算法返回的 `ans` 等于最大可覆盖飞镖数。

**证明**：设最优覆盖数为 $OPT$。若 $OPT=1$，`ans` 初值 1 且不可能超过 $OPT$，成立。若 $OPT\ge 2$，由引理 1 存在一个覆盖数仍为 $OPT$（不可能更多）的圆，其边界上有两枚飞镖 $A,B$；由引理 2，该圆圆心必在算法枚举 $A,B$ 得到的 $C_1,C_2$ 之中。算法对该圆心计数恰为 $OPT$，故 `ans` 至少为 $OPT$；另一方面任何候选圆心覆盖的飞镖数都不可能超过 $OPT$，故 `ans` 恰为 $OPT$。∎

## 6. 复杂度分析

- **时间**：$O(n^3)$。共 $\binom{n}{2}$ 个点对，每对至多产生 2 个候选圆心，每个圆心用 $O(n)$ 统计覆盖数，故总操作数为 $\frac{n(n-1)}{2}\cdot 2\cdot n=O(n^3)$。$n=100$ 时约 $10^6$ 次距离计算，实测在毫秒级。
- **空间**：$O(1)$。除输入数组外只使用常数个浮点变量与计数变量，没有额外容器。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <cmath>
#include <algorithm>
using namespace std;

class Solution {
public:
    int numPoints(vector<vector<int>>& darts, int r) {
        int n = (int)darts.size();
        int ans = 1;                       // 至少覆盖 1 枚飞镖
        const double eps = 1e-7;
        const double R = r;
        for (int i = 0; i < n; ++i) {
            for (int j = i + 1; j < n; ++j) {
                double dx = (double)darts[j][0] - darts[i][0];
                double dy = (double)darts[j][1] - darts[i][1];
                double d = hypot(dx, dy);
                if (d > 2.0 * R + eps) continue;      // 不可能同时覆盖
                double mx = ((double)darts[i][0] + darts[j][0]) / 2.0;
                double my = ((double)darts[i][1] + darts[j][1]) / 2.0;
                double dd = max(d, eps);              // 防除零
                double h = sqrt(max(0.0, R * R - d * d / 4.0));
                double ux = -dy / dd, uy = dx / dd;   // AB 的单位垂直向量
                for (int side = 0; side < 2; ++side) {
                    double sgn = side ? -1.0 : 1.0;
                    double cx = mx + sgn * h * ux;
                    double cy = my + sgn * h * uy;
                    int cnt = 0;
                    for (int k = 0; k < n; ++k) {
                        double ex = (double)darts[k][0] - cx;
                        double ey = (double)darts[k][1] - cy;
                        if (hypot(ex, ey) <= R + eps) ++cnt;
                    }
                    ans = max(ans, cnt);
                }
            }
        }
        return ans;
    }
};
```

### Python

```python
import math
from typing import List


class Solution:
    def numPoints(self, darts: List[List[int]], r: int) -> int:
        n = len(darts)
        ans = 1                       # 至少覆盖 1 枚飞镖
        eps = 1e-7
        for i in range(n):
            x1, y1 = darts[i]
            for j in range(i + 1, n):
                x2, y2 = darts[j]
                dx, dy = x2 - x1, y2 - y1
                d = math.hypot(dx, dy)
                if d > 2 * r + eps:             # 不可能同时覆盖
                    continue
                mx, my = (x1 + x2) / 2.0, (y1 + y2) / 2.0
                dd = max(d, eps)                # 防除零
                h = math.sqrt(max(0.0, r * r - d * d / 4.0))
                ux, uy = -dy / dd, dx / dd      # AB 的单位垂直向量
                for sgn in (1.0, -1.0):         # 两个候选圆心
                    cx, cy = mx + sgn * h * ux, my + sgn * h * uy
                    cnt = 0
                    for x, y in darts:
                        if math.hypot(x - cx, y - cy) <= r + eps:
                            cnt += 1
                    if cnt > ans:
                        ans = cnt
        return ans
```

## 8. 边界情况与易错点

1. **只有一枚飞镖**：双重循环不执行，直接返回 `ans = 1`，正确。
2. **所有点对距离都大于 $2r$**：任何圆最多覆盖一枚，返回 1；这是最容易漏掉的兜底情形。
3. **两点恰好相距 $2r$**：$h=0$，两候选圆心重合于中点，该圆以这两点为直径端点，两点都在边界上，必须计入（剪枝容差和计数容差都要覆盖）。
4. **飞镖恰在圆上**：题目要求「内或上」，计数必须用 `<= r + eps`；若误写成 `< r`，示例 1 中四枚恰好压线的飞镖会全部漏计。
5. **浮点比较的容差**：$d>2r$ 与距离计数都要加容差；但容差不能过大，否则会把明显在圆外的点算进来。$10^{-7}$ 与坐标量级 $10^4$ 相比可以忽略，是安全的。
6. **大坐标**：$|x|,|y|\le 10^4$、$r\le 5000$，$d^2$ 最大约 $8\times10^8$，`int` 尚可但中间量用 `double` 更稳；C++ 中先把坐标差转成 `double`，避免整数平方溢出。
7. **重复坐标**：题面保证互不相同，但代码里保留 `dd = max(d, eps)` 可防未来输入变化导致的除零。
8. **答案上界**：`ans` 不会超过 $n$，无需额外截断；计数循环每轮重新归零，不能复用上一圆心的 `cnt`。
