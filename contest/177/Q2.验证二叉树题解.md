# LeetCode 验证二叉树 题解

## 1. 题目概述

- **标题 / 题号**：验证二叉树（#1361，medium）
- **链接**：https://leetcode.cn/problems/validate-binary-tree-nodes/
- **来源**：LeetCode 第 177 场周赛 Q2
- **难度**：中等
- **标签**：树、广度优先搜索、深度优先搜索、并查集、图

**题意**：$n$ 个节点编号 $0 \sim n-1$，`leftChild[i]` / `rightChild[i]` 给出节点 $i$ 的左右子节点（`-1` 表示没有）。判断这 $n$ 个节点是否**恰好构成一棵有效的二叉树**：每个节点至多两个子节点、至多一个父节点，全图连通、无环、恰有一个根。

**约束**：

- $1 \le n \le 10^4$，三个数组长度相同。
- $-1 \le leftChild[i], rightChild[i] \le n-1$。

## 2. 示例

**示例 1**

```text
输入：n = 4, leftChild = [1,-1,3,-1], rightChild = [2,-1,-1,-1]
输出：true
解释：0 为根，左右子为 1、2；2 的左子为 3。四个节点恰好构成一棵二叉树。
```

**示例 2**

```text
输入：n = 4, leftChild = [1,-1,3,-1], rightChild = [2,3,-1,-1]
输出：false
解释：节点 3 既是 2 的左子又是 1 的右子——两个爹，不是树。
```

**示例 3**

```text
输入：n = 2, leftChild = [1,0], rightChild = [-1,-1]
输出：false
解释：0 的左子是 1，1 的左子是 0，互相指成环，没有入度为 0 的根。
```

**补充用例（藏环陷阱，后文反复引用）**

```text
输入：n = 4, leftChild = [1,-1,3,-1], rightChild = [-1,-1,-1,2]
输出：false
解释：入度 [0,1,1,1] 全部 ≤ 1，根唯一为 0，边数 3 = n−1，
     但 2、3 互相指成孤立环——只有"从根访问不到全部节点"能查出它。
```

## 3. 解题思路

### 3.1 暴力思路

枚举每个节点当根：对每个候选根 $r$ 做一次 DFS/BFS，检查从 $r$ 出发能否恰好不重复地访问全部节点、且每个节点只被一条边指向。单次检查 $O(n)$，共 $n$ 个候选 → $O(n^2) \approx 10^8$，在 $n \le 10^4$ 下已经冒险；而且"多父""无根"这些毛病与根是谁无关，枚举根浪费了大量信息。

真正的问题：**树的结构信息（每个节点被几条边指向）可以一趟线性扫描全部拿到**——这就是入度。

### 3.2 核心观察：入度扫描 + 三段判定

![入度统计与定根概念](images/wc177_q2_indegree_root_concept.svg)

把 `leftChild` / `rightChild` 的每个非 `-1` 项看作一条父指向子的**有向边**，统计每个节点的入度 $d^{-}(v)$（即 $v$ 在两个数组中出现的次数）。一棵合法二叉树必须同时满足三个条件，每个都能 $O(n)$ 验证：

1. **条件①**：每个节点入度 $\le 1$——入度 $\ge 2$ 的节点有两个父节点，直接否决；
2. **条件②**：入度 $= 0$ 的节点**恰一个**——0 个说明没有根（例如整图成环），$\ge 2$ 个说明是森林；
3. **条件③**：从这个唯一的根出发，能访问到**全部 $n$ 个节点**——入度查不出的"藏环 / 断连"由这一步兜底。

> 💡 关键是**根不需要枚举**：入度为 0 的节点如果存在必是根，个数只能恰为 1。三步全部通过，当且仅当恰好构成一棵有效二叉树（证明见 §5）。

### 3.3 算法流程

![三步判定流程](images/wc177_q2_validate_flow.svg)

三关串行，任一关失败立即返回 `false`：

1. 扫描两个数组统计入度，途中遇到某节点入度将要变成 2 就直接失败；
2. 收集所有入度为 0 的节点，个数 $\ne 1$ 则失败，否则它就是根；
3. 从根 BFS（或 DFS），用 visited 数组防重复，最后比较**访问计数与 $n$**。

### 3.4 示例演算

![示例 1 与示例 2 演算](images/wc177_q2_example_walkthrough.svg)

- **示例 1**：入度 $[0,1,1,1]$——①过；根唯一为 0——②过；从 0 BFS 访问 $0,1,2,3$，计数 $4 = n$——③过 → `true`。
- **示例 2**：节点 3 被 2（左子）与 1（右子）各指一次，入度 $= 2$——卡在① → `false`。
- **示例 3**：$0 \to 1 \to 0$ 互指，两节点入度都是 1，入度为 0 的节点一个都没有——卡在② → `false`。

![藏环陷阱用例](images/wc177_q2_hidden_cycle_case.svg)

- **藏环陷阱**：入度 $[0,1,1,1]$ ①过、根唯一②过、连"边数 $= n-1$"都成立，但 $\{2,3\}$ 组成的孤立环使从根出发只能访问 2 个节点——只有③能拦下它。**所以第三步不可省略**。

## 4. 算法细节

1. **入度统计**：一趟遍历两个数组即可；遇到 $d^{-}(v)$ 将 $\ge 2$ 立即返回，省掉后续工作。注意"既是 $i$ 的左子又是 $i$ 的右子"同样算两次出现，被同一条件覆盖。
2. **定根**：再扫一遍入度数组，用计数变量顺带记下入度为 0 的那个节点，避免额外分配。
3. **可达性检查**：从根 BFS/DFS，**必须带 visited 标记**——若图有环（如陷阱用例），不带标记会在环上无限打转；计数 `seen == n` 即通过。
4. **为什么"边数 = n − 1"替代不了第三步**：陷阱用例中 $E = 3 = n-1$、入度全 $\le 1$、根唯一，三个"便宜检查"全过，却不是树。可达性是唯一能区分"树 + 孤立环"与"真树"的线性检查。
5. **并查集变体**（题目标签含 Union Find）：在入度检查之外逐条边合并，合并前发现两端已在同一集合 → 有环，失败；全部合并后要求整个图只剩一个连通块。**警告：裸并查集（只查"合并同根"）会漏多父**——反例 `0→1`、`2→1`：两次合并都成功、最终连通，却不是树，入度检查不能省。
6. **数据结构选择**：入度数组、visited 数组各 $O(n)$；队列用 `queue`/`deque`，栈用 `vector` 即可，$n \le 10^4$ 无性能压力。

## 5. 正确性证明

**引理 1（必要性）**：若节点构成一棵有效二叉树，则 (a) 每个节点入度 $\le 1$；(b) 恰有一个节点入度 $= 0$；(c) 从该节点出发可达全部 $n$ 个节点。

**证明**：树中每个节点至多一个父节点，即 (a)；根没有父节点、其余节点恰有一个父节点，即 (b)；树中所有节点都从根沿子指针可达，即 (c)。∎

**引理 2**：若 (a)(b)(c) 成立（记根为 $r$），则边数 $E = n - 1$。

**证明**：对任意 $v \ne r$，由 (c) 存在 $r \to \cdots \to v$ 的有向路径，其最后一条边是 $v$ 的入边，故 $d^{-}(v) \ge 1$；结合 (a) 得 $d^{-}(v) = 1$，而 $d^{-}(r) = 0$。于是 $E = \sum_{v} d^{-}(v) = n - 1$。∎

**引理 3**：若 (a)(b)(c) 成立，则图中无环。

**证明**：反证，设存在环 $C$。环上每个节点都有一条来自其环上前驱的入边，由 (a)（入度 $\le 1$）这必是它**唯一的**入边。任取环上节点 $v$，由 (c) 存在路径 $r = v_0 \to v_1 \to \cdots \to v_k = v$。边 $v_{k-1} \to v_k$ 是 $v_k$ 的入边，故 $v_{k-1}$ 即 $v_k$ 的环上前驱，$v_{k-1} \in C$；又边 $v_{k-2} \to v_{k-1}$ 是 $v_{k-1}$ 的入边，同理 $v_{k-2} \in C$；逐级回推得路径上所有节点都在 $C$ 上，特别地 $r = v_0 \in C$。但 $r$ 在环上意味着它有一条入边，$d^{-}(r) \ge 1$，与 (b) 矛盾。∎

**定理**：三步判定返回 `true`，当且仅当节点恰好构成一棵有效二叉树。

**证明**：

- 若构成有效二叉树，由引理 1，三步全过，返回 `true`。
- 反之，设三步全过，即 (a)(b)(c) 成立。由 (c)，把所有边视为无向边时，每个节点都与 $r$ 连通；由引理 3，图中无环。连通且无环的 $n$ 节点图是树（边数恰 $n-1$，与引理 2 吻合）。再看节点形状：节点 $i$ 至多带 `leftChild[i]`、`rightChild[i]` 两个子槽位；若两个槽位指向同一节点，该节点入度为 2，已被 (a) 排除，故两个子节点互异且带左右次序。因此这是一棵有效二叉树。∎

> 💡 引理 3 的直觉：环上节点的唯一入边来自环上前驱，"树边永远等不到它"——所以含环图中环上节点不可能从根可达，第三步的访问计数必然 $< n$。这也解释了藏环用例为何只能死在第三步。

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。入度统计一趟、找根一趟、BFS 一趟，每条边至多被扫两次（左右数组各一次），总量线性。
- **空间复杂度**：$O(n)$。入度数组、visited 数组与队列/栈，总量不超过 $2n$。

## 7. 参考代码

### C++

三步判定 + BFS，比赛中最稳的写法：

```cpp
class Solution {
public:
    bool validateBinaryTreeNodes(int n, vector<int>& leftChild, vector<int>& rightChild) {
        vector<int> indeg(n, 0);
        for (int i = 0; i < n; ++i)
            for (int c : {leftChild[i], rightChild[i]}) {
                if (c == -1) continue;
                if (++indeg[c] > 1) return false;      // 条件①：两个爹
            }

        int root = -1, roots = 0;
        for (int i = 0; i < n; ++i)
            if (indeg[i] == 0) { root = i; ++roots; }
        if (roots != 1) return false;                  // 条件②：无根或多根

        vector<char> vis(n, 0);
        queue<int> q;
        q.push(root);
        vis[root] = 1;
        int seen = 0;
        while (!q.empty()) {
            int u = q.front(); q.pop();
            ++seen;
            for (int c : {leftChild[u], rightChild[u]}) {
                if (c != -1 && !vis[c]) {
                    vis[c] = 1;
                    q.push(c);
                }
            }
        }
        return seen == n;                              // 条件③：全部可达
    }
};
```

### Python

显式栈做 DFS，逻辑与 C++ 版一一对应：

```python
class Solution:
    def validateBinaryTreeNodes(self, n: int, leftChild: List[int], rightChild: List[int]) -> bool:
        indeg = [0] * n
        for i in range(n):
            for c in (leftChild[i], rightChild[i]):
                if c != -1:
                    indeg[c] += 1
                    if indeg[c] > 1:          # 条件①
                        return False

        root, roots = -1, 0
        for i in range(n):
            if indeg[i] == 0:
                root, roots = i, roots + 1
        if roots != 1:                        # 条件②
            return False

        vis = [False] * n
        vis[root] = True
        stack = [root]
        seen = 0
        while stack:
            u = stack.pop()
            seen += 1
            for c in (leftChild[u], rightChild[u]):
                if c != -1 and not vis[c]:
                    vis[c] = True
                    stack.append(c)
        return seen == n                      # 条件③
```

并查集变体（复杂度 $O(n \alpha)$，注意入度检查不能省）：

```python
class Solution:
    def validateBinaryTreeNodes(self, n: int, leftChild: List[int], rightChild: List[int]) -> bool:
        indeg = [0] * n
        for i in range(n):
            for c in (leftChild[i], rightChild[i]):
                if c != -1:
                    indeg[c] += 1
                    if indeg[c] > 1:                 # 多父，必查
                        return False
        if indeg.count(0) != 1:                     # 无根 / 多根
            return False

        fa = list(range(n))

        def find(x: int) -> int:
            while fa[x] != x:
                fa[x] = fa[fa[x]]
                x = fa[x]
            return x

        comp = n
        for i in range(n):
            for c in (leftChild[i], rightChild[i]):
                if c == -1:
                    continue
                ri, rc = find(i), find(c)
                if ri == rc:                        # 合并同根 → 有环
                    return False
                fa[ri] = rc
                comp -= 1
        return comp == 1                            # 只剩一个连通块
```

## 8. 边界情况与易错点

1. **多父的两种形态都要想到**：同一节点出现在不同父的左右数组（示例 2），以及**同一个父的两个槽位指向它**（`leftChild[i] == rightChild[i] == j`）——都被"入度 ≤ 1"一次覆盖，别只盯其中一种。
2. **自环**（`leftChild[i] == i`）：入度恰为 1，条件①不报警；该节点有入边当不了根，只能被条件②/③拦下——所以别试图砍掉后面两步。
3. **无根 vs 多根**：整图成环（示例 3）→ 入度为 0 的节点个数是 0；两棵独立树（森林）→ 个数 $\ge 2$。两种情况都要求"个数恰为 1"。
4. **藏环是最大陷阱**：入度全 $\le 1$、根唯一、边数 $= n-1$ 全都成立时仍可能是"树 + 孤立环"（补充用例）——可达性检查不可省略。
5. **BFS/DFS 忘记 visited**：在环上无限循环（队列/栈永不空）；DFS 还要先标记再入栈，否则同一节点重复入栈爆内存。
6. **遍历孩子先判 `-1`**：跳过空槽，否则入度统计会把 `-1` 当下标访问，越界。
7. **裸并查集的坑**：只做"合并前同根 → 有环"会漏多父（`0→1`、`2→1` 反例），必须配合入度检查；同时最后要校验连通块恰一个（森林没有环、没有多父，但也不是一棵树）。
8. **$n = 1$**：`[-1], [-1]` → `true`；`[0], [-1]`（自环）→ 入度为 0 的节点个数是 0 → `false`。
9. **早退收益**：入度检查可以在扫描途中直接失败，不必等全部统计完——最坏仍是 $O(n)$，平均更快。
