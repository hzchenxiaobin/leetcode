# LeetCode 形成三的最大倍数 题解

## 1. 题目概述

- **标题 / 题号**：形成三的最大倍数（#1363，hard）
- **链接**：https://leetcode.cn/problems/largest-multiple-of-three/
- **来源**：LeetCode 第 177 场周赛 Q4
- **难度**：困难
- **标签**：贪心、数组、数学、动态规划、排序

**题意**：给定 $n$ 个十进制数字 `digits[i]`，从中挑选若干个（每个位置至多用一次），按任意顺序拼接成一个十进制整数，要求它是 $3$ 的倍数，并且数值尽可能大。返回该整数对应的字符串；若无法凑出任何 $3$ 的倍数，返回 `""`。答案不能带多余的前导零。

**约束**：

- $1 \le n \le 10^4$
- $0 \le \text{digits}[i] \le 9$
- 返回值是字符串，因为答案最多可能有 $10^4$ 位，远超 `int64`

## 2. 示例

```text
示例 1：digits = [8,1,9]           输出 "981"
        8+1+9 = 18 是 3 的倍数，三个数字全用上，降序拼接即最大。
示例 2：digits = [8,6,7,1,0]       输出 "8760"
        数字和 22 ≡ 1，删掉类 1 中最小的 1 后和为 21，剩余 {8,6,7,0} 降序拼接。
示例 3：digits = [1]               输出 ""
        1 本身不是 3 的倍数，删光后又没有数字可拼，只能返回空串。
示例 4：digits = [0,0,0,0,0,0]     输出 "0"
        数字全部保留，但拼接结果必须去掉多余的前导零，只留一个 "0"。
```

## 3. 解题思路

### 3.1 暴力思路

穷举所有子集，对每个子集算出数字和、判断是否为 $3$ 的倍数，再用「降序拼接」构造该子集能组成的最大数，最后取最大。子集共 $2^n$ 个，$n = 10^4$ 时完全不可行；即便只看「删掉哪些数字」，候选删法也有指数级多种。而真正要回答的问题很窄：**为了把数字和修成 $3$ 的倍数，最少要删几个数字、删哪几个**——它其实只需要看每个数字模 $3$ 的余数。

### 3.2 核心观察：按模 3 分类，只删 1 个或 2 个

![按模 3 余数分类与删除规则](images/wc177_q4_residue_classes.svg)

一个整数能被 $3$ 整除，当且仅当它的**数位和**能被 $3$ 整除（因为 $10 \equiv 1 \pmod 3$）。记

$$S = \sum_i \text{digits}[i], \qquad r = S \bmod 3$$

- $r = 0$：一个都不用删，全部保留位数最多，最优。
- $r = 1$：需要让「被删数字的和」$\equiv 1 \pmod 3$。最小的删除方案只有两种形状：删 **一个** $\equiv 1$ 的数字（$1,4,7$），或者删 **两个** $\equiv 2$ 的数字（$2,5,8$，因为 $2+2 = 4 \equiv 1$）。
- $r = 2$：对称地，删一个 $\equiv 2$ 的数字，或删两个 $\equiv 1$ 的数字。

**为什么最多只删 2 个？** 关键事实：若 $r = 1$ 而类 $1$ 的数字一个都没有，说明 $S$ 的余数全部由类 $2$ 贡献，设类 $2$ 有 $c$ 个，则 $c \equiv 2 \pmod 3$，必有 $c \ge 2$——两个类 $2$ 数字一定凑得出来。$r = 2$ 时同理。所以「删 1 个」或「删 2 个」中至少有一种可行，最小删除数永远不超过 $2$（严格证明见 §5 引理 3）。

另外两条贪心直觉：

- **位数优先**：少一位一定更小（除非剩下的数字全是 $0$，此时值都是 $0$），所以先让删除个数最少；
- **删小留大**：删除个数确定后，在同类数字里删掉最小的那几个，剩下的降序串最大。

> 💡 类 $0$ 的数字（$0,3,6,9$）永远不会被删——删它不改变余数，只会白白丢掉一位。

### 3.3 算法流程

![算法流程](images/wc177_q4_greedy_flow.svg)

1. 用 `cnt[0..9]` 统计每个数字出现次数，同时累加 $S$；
2. 按 $r = S \bmod 3$ 选择删除策略：
   - $r = 0$：不删；
   - $r = 1$：先尝试删一个最小的 `1/4/7`；若一个都没有，就删两个最小的 `2/5/8`；
   - $r = 2$：先尝试删一个最小的 `2/5/8`；若一个都没有，就删两个最小的 `1/4/7`；
3. 若剩余数字个数为 $0$，返回 `""`；
4. 若剩余全是 $0$（即 $1\sim 9$ 的计数全为 $0$ 而 $0$ 还有剩余），返回 `"0"`；
5. 否则从 $9$ 到 $0$ 依次把 `cnt[d]` 个数字追加到结果串，返回。

### 3.4 示例演算

![示例演算](images/wc177_q4_walkthrough.svg)

- **示例 2**（`[8,6,7,1,0]`）：$S = 22$，$r = 1$。类 $1$ 的数字是 $\{7,1\}$，删较小的 $1$，新和 $21$ 是 $3$ 的倍数。剩余 $\{8,6,7,0\}$ 降序拼接 → `8760`。若错删 $7$，剩下 $8610$，明显更小。
- **示例 1**（`[8,1,9]`）：$S = 18$，$r = 0$，一个都不删，降序拼接 → `981`。
- **示例 3**（`[1]`）：$S = 1$，$r = 1$，类 $1$ 中删掉唯一的 $1$，剩余为空 → `""`。
- **示例 4**（六个 $0$）：$r = 0$ 全部保留，但最高位是 $0$，只输出一个 `"0"`。

## 4. 算法细节

1. **一次遍历完成统计**：`cnt[digits[i]]++`、`sum += digits[i]` 同趟完成，$O(n)$；数字和最大 $9 \times 10^4$，`int` 足够，不必担心溢出。
2. **「删最小」用步长 3 的循环实现**：`for (d = r; d <= 9; d += 3)` 天然按从小到大枚举同类数字，第一个 `cnt[d] > 0` 的就是最小的那个，无需排序。
3. **删两个时不要重新写一套循环**：把「取一个」的内层 `while` 放进同一个步长循环，取够 $2$ 个即停；注意不能跨越余数类去补数。
4. **用返回值决定走哪条分支**：`removeOne(r)` 返回是否成功，失败才调 `removeTwo(3 - r)`。这样 $r = 1$ 与 $r = 2$ 共享同一段代码，只换参数。
5. **输出前先判两种退化**：`remain == 0` → `""`；`cnt[1..9]` 全为 $0$ → `"0"`。这两种情况都不能靠「拼接后去前导零」来补救，否则会改变数值或把 `"0"` 也删没。
6. **不必排序，也不逐字符追加**：桶计数已隐含降序信息，C++ 用 `ans.append(cnt[d], '0' + d)`、Python 用 `str(d) * cnt[d]` 批量拼接；排序写法 $O(n \log n)$ 也能过，但没有必要。
7. **DP 视角（可替代方案）**：令 $f[j]$ 表示「已处理部分数字、数字和 $\equiv j \pmod 3$ 时最多能保留几位」，转移保留 $f'[(j+d) \bmod 3] = \max(\cdot, f[j] + 1)$ 或丢弃 $f'[j] = \max(\cdot, f[j])$，$O(n)$ 时间 $O(1)$ 空间。它能求出最大位数，但要还原**具体是哪几个数字**（以及在位数相同时取最大字典序）还得额外记录方案，因此本题用贪心更直接。

## 5. 正确性证明

**引理 1（整除判定）**：对任意非负整数 $N = \sum_i d_i 10^i$，有 $3 \mid N \iff 3 \mid \sum_i d_i$。

**证明**：因 $10 \equiv 1 \pmod 3$，故 $10^i \equiv 1 \pmod 3$，于是 $N \equiv \sum_i d_i \pmod 3$。同余式两边能否被 $3$ 整除等价，结论成立。∎

**引理 2（位数优先）**：设两个可行解保留的数字个数分别为 $a > b$，对应数值为 $A, B$，则 $A \ge B$；且等号成立时 $A = B = 0$。

**证明**：$B$ 只有 $b$ 位，故 $B \le 10^b - 1 < 10^{a-1}$。若 $A$ 的保留数字不全为 $0$，则其首位非零，$A \ge 10^{a-1} > B$。若 $A$ 的保留数字全为 $0$，则 $A = 0$，此时只能有 $B = 0$（$B \ge 0$ 且 $b < a$ 位全零），等号成立。∎

**推论**：最优解一定在「删除个数最少」的方案中取得（全零退化时各方案值同为 $0$，不影响最优性）。

**引理 3（删除个数恰为 $0/1/2$）**：设 $r = S \bmod 3$。

- 若 $r = 0$，不删任何数字即合法，最小删除数 $k_{\min} = 0$；
- 若 $r \ne 0$ 且类 $r$ 的数字非空，删其中任意一个即合法，$k_{\min} = 1$；
- 若 $r \ne 0$ 且类 $r$ 的数字为空，则类 $3-r$ 的数字至少有 $2$ 个，删其中两个即合法，$k_{\min} = 2$。

**证明**：$r = 0$ 显然。$r \ne 0$ 时删 $0$ 个不合法，故 $k_{\min} \ge 1$；类 $r$ 非空时删一个该类数字 $d$ 得新和 $S - d \equiv r - r = 0$，故 $k_{\min} = 1$。

设类 $r$ 为空，记类 $3-r$ 的数字个数为 $c$（类 $0$ 的数字对 $S$ 无贡献）。由 $S \equiv r \pmod 3$ 与 $S \equiv c(3-r) \equiv -cr \pmod 3$ 得 $-cr \equiv r$；两边乘以 $r$（$r^2 \equiv 1 \pmod 3$）得 $-c \equiv 1$，即 $c \equiv 2 \pmod 3$，故 $c \ge 2$。

删两个类 $3-r$ 的数字后，被删和为 $2(3-r) \equiv -2r \pmod 3$，而 $-2r \equiv r \pmod 3$（因 $-2r - r = -3r \equiv 0$），新和 $\equiv S - r = 0$，合法，故 $k_{\min} \le 2$。又 $k = 1$ 不可行：类 $r$ 为空，删一个类 $0$ 数字不改变余数，删一个类 $3-r$ 数字会使新和 $\equiv r - (3-r) = 2r \not\equiv r$（$r \ne 0$），故 $k_{\min} = 2$。∎

**引理 4（删同类最小者最优）**：固定删除个数 $k$ 与「每个被删数字的余数类」，则在每一类中删除最小的若干个数字，得到的剩余数字降序拼接串最大。

**证明**（交换论证）：先注意，固定一组数字时降序拼接最大——若相邻两位 $u < v$ 逆序，交换后数值严格变大。设某方案删除了数字 $x$、保留了同类中更小的数字 $y < x$。把 $x$ 与 $y$ 交换（改为删 $y$、留 $x$）：被删数字的和不变（$x \equiv y \pmod 3$，且和的变化量为 $y - x$，模 $3$ 不变），位数不变，而剩余多重集中用 $x$ 替换了 $y$。两个剩余多重集降序排序后逐位比较，第一个不同位置正是 $y$ 原本所在的位置，该位置新方案为 $x > y$，故新串更大。反复交换直到每类删的都是最小者，串单调不降，结论成立。∎

**定理**：算法输出的字符串是「用给定数字能拼出的最大 $3$ 的倍数」的正确表示。

**证明**：由引理 1，合法解等价于保留数字和 $\equiv 0 \pmod 3$。由引理 3，算法在 $r = 0$ 时删 $0$ 个、$r \ne 0$ 时删除数恰为 $k_{\min} \in \{1,2\}$（且类 $r$ 为空时必然走「删两个」分支，因为此时类 $3-r$ 至少两个），故删除后的数字和 $\equiv 0$，输出是合法倍数；由引理 2 推论，其位数在所有合法解中最多；在位数相同的合法解中，由引理 4，删除各类最小者使剩余串最大。最后，剩余为空返回 `""`、全零返回 `"0"` 都与真实最优值一致，降序拼接本身就满足「无多余前导零」（非全零时首位非零）。故输出即最大 $3$ 的倍数。∎

## 6. 复杂度分析

- **时间**：$O(n)$。统计一趟 $O(n)$；删除逻辑最多扫描 $9$ 个桶的两轮（步长 $3$，每类至多 $3$ 个候选），$O(1)$；拼接输出 $O(n)$。总计 $O(n)$，$n = 10^4$ 时是 $10^4$ 量级。
- **空间**：$O(1)$ 辅助空间（`cnt` 只有 $10$ 个桶、若干整数变量）；若把返回的字符串计入，则为 $O(n)$。递归、排序、哈希表都不需要。

## 7. 参考代码

### C++

```cpp
#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    string largestMultipleOfThree(vector<int>& digits) {
        int cnt[10] = {0};
        int total = 0;
        for (int d : digits) {
            ++cnt[d];
            total += d;
        }

        // 删掉一个最小的、模 3 余 res 的数字；成功返回 true
        auto removeOne = [&](int res) -> bool {
            for (int d = res; d <= 9; d += 3) {   // 步长 3 → 同类数字从小到大
                if (cnt[d] > 0) {
                    --cnt[d];
                    return true;
                }
            }
            return false;
        };

        // 删掉两个最小的、模 3 余 res 的数字（调用前已保证够用）
        auto removeTwo = [&](int res) {
            int need = 2;
            for (int d = res; d <= 9 && need > 0; d += 3) {
                while (cnt[d] > 0 && need > 0) {
                    --cnt[d];
                    --need;
                }
            }
        };

        int r = total % 3;
        if (r == 1) {
            if (!removeOne(1)) removeTwo(2);      // 没有 1/4/7 时删两个 2/5/8
        } else if (r == 2) {
            if (!removeOne(2)) removeTwo(1);      // 没有 2/5/8 时删两个 1/4/7
        }

        int remain = 0;
        for (int d = 0; d <= 9; ++d) remain += cnt[d];
        if (remain == 0) return "";               // 一个数字都不剩

        bool allZero = true;
        for (int d = 1; d <= 9; ++d)
            if (cnt[d] > 0) allZero = false;
        if (allZero) return "0";                  // 只剩 0，去掉多余前导零

        string ans;
        for (int d = 9; d >= 0; --d) ans.append(cnt[d], char('0' + d));
        return ans;
    }
};
```

### Python

```python
class Solution:
    def largestMultipleOfThree(self, digits: list[int]) -> str:
        cnt = [0] * 10
        total = 0
        for d in digits:
            cnt[d] += 1
            total += d

        def remove_one(res: int) -> bool:
            """删掉一个最小的、模 3 余 res 的数字"""
            d = res
            while d <= 9:                 # 同类数字按 d, d+3, d+6 递增
                if cnt[d] > 0:
                    cnt[d] -= 1
                    return True
                d += 3
            return False

        def remove_two(res: int) -> None:
            """删掉两个最小的、模 3 余 res 的数字（调用前已保证够用）"""
            need = 2
            d = res
            while d <= 9 and need:
                while cnt[d] > 0 and need:
                    cnt[d] -= 1
                    need -= 1
                d += 3

        r = total % 3
        if r == 1:
            if not remove_one(1):
                remove_two(2)
        elif r == 2:
            if not remove_one(2):
                remove_two(1)

        if sum(cnt) == 0:
            return ""
        if all(cnt[d] == 0 for d in range(1, 10)):
            return "0"                    # 剩余全是 0，只保留一个零

        return "".join(str(d) * cnt[d] for d in range(9, -1, -1))
```

## 8. 边界情况与易错点

1. **全零**：`[0,0,0,0,0,0]` 的 $r = 0$、全部保留，但直接拼接会得到 `"000000"`。必须先判断「非零数字是否一个都不剩」，输出单个 `"0"`。
2. **无解**：`[1]`、`[2]`、`[1,1]`、`[2,2]` 这类只有一两个数字、删完即空的输入，必须返回 `""` 而不是 `"0"`——「空」与「零」是两种不同的答案。
3. **删完只剩零**：`[0,0,2,2]`，$S = 4$、$r = 1$，类 $1$ 为空，删掉两个最小的 `2`，剩 `[0,0]` → 正确答案是 `"0"`。
4. **长度优先于数字大小**：`[7,1,1,1]` 的 $S = 10$、$r = 1$，删一个最小的 `1` 得 `"7111"`；若为了「少一个 1」去删 `7`，只剩 `"111"`，虽然也是 $3$ 的倍数却小得多。
5. **类 $0$ 的数字不能为了修余数而删**：`[9,1]` 的 $S = 10$、$r = 1$，删 `1` 得 `"9"`；若删 `9` 得 `"1"`，既不合法也没必要。
6. **两个数字必须同一余数类**：$r = 1$ 时要删两个类 $2$ 的数字（$2+2 \equiv 1$），不能拿「一个类 $2$ + 一个类 $0$」凑数（$2 + 0 \equiv 2$）。
7. **不要靠去前导零补救**：先拼接再 `lstrip('0')` 在剩余全零时会把结果删成 `""`，与正确答案 `"0"` 不符；应在拼接前判断。另外 `str(d) * 0` 是空串，Python 循环里不必特判 `cnt[d] == 0`。
8. **复杂度陷阱**：$n = 10^4$ 时子集枚举、全排列、$O(n^2)$ 的逐个试删都会超时；本题正解只需扫一遍计数桶。

- [LeetCode 1262. 可被三整除的最大和](https://leetcode.cn/problems/greatest-sum-divisible-by-three/)：同样用「模 $3$ 余数」调整，但目标是**和最大**，贪心不再适用，需要 DP。
- [LeetCode 1015. 可被 K 整除的最小整数](https://leetcode.cn/problems/smallest-integer-divisible-by-k/)：只靠余数状态 + 鸽巢原理判断是否存在，和本题「只看余数」的视角相通。
- [LeetCode 1362. 最接近的因数](https://leetcode.cn/problems/closest-divisors/)：同场 Q3，考点是因数枚举，可与本题对照「规模决定枚举方式」。

**延伸思考**：

- **改成 $K$ 的倍数**：模 $3$ 时「删 1 个或 2 个」的结论来自 $3$ 很小，$K$ 较大时删除个数可能到 $K-1$，且同余组合不唯一，应改用 DP：$f[i][j]$ 表示前 $i$ 个数字、数字和 $\equiv j \pmod K$ 时最多保留几位，时间为 $O(nK)$。
- **改成和最大**：直接退化成 LC 1262 的背包式 DP，$f[j] = \max$ 可达到的数字和；本题的"位数优先"与它恰好是两种不同目标。
- **改成字典序最小**：把「删同类最小者」换成「删同类最大者」即可，其余框架完全不变。
- **若每个数字必须使用恰好一次**：则问题变成判断总和能否被 $3$ 整除，不能则无解，贪心部分彻底消失——这也说明本题的难点全在「可以丢弃数字」这一点上。
