# LeetCode 日期之间隔几天 题解

## 1. 题目概述

- **标题 / 题号**：日期之间隔几天（#1360，easy）
- **链接**：https://leetcode.cn/problems/number-of-days-between-two-dates/
- **来源**：LeetCode 第 177 场周赛 Q1
- **难度**：简单
- **标签**：数学、字符串、日期计算

**题意**：给定两个**合法日期字符串**（格式严格为 `YYYY-MM-DD`），计算两个日期之间隔了多少天。不区分谁先谁后，返回差值的绝对值。

**约束**：

- 日期均为 **1971 年到 2100 年之间**的有效日期。
- 字符串长度固定为 10，格式为 `YYYY-MM-DD`。

## 2. 示例

**示例 1**

```text
输入：date1 = "2019-06-29", date2 = "2019-06-30"
输出：1
解释：两个日期是相邻两天。
```

**示例 2**

```text
输入：date1 = "2020-01-15", date2 = "2019-12-31"
输出：15
解释：2019-12-31 的后一天是 2020-01-01，再过 14 天到 2020-01-15，共 15 天。
```

**补充用例（闰年规则的坑）**

```text
输入：date1 = "2100-03-01", date2 = "2100-02-28"
输出：1
解释：2100 被 100 整除但不被 400 整除，是平年，2 月只有 28 天。
```

## 3. 解题思路

### 3.1 暴力思路

从较早的日期开始**逐日模拟**：每过一天日数 +1，到月末进位到下月，到 12 月末进位到下年（闰年 2 月 29 天），直到追上另一个日期，计数即为答案。

- 最坏要跨约 130 年 ≈ 47,000 天，虽然不会超时，但大小月、闰年的进位规则很容易写错。
- 更稳的做法：**不要模拟"过程"，直接计算"坐标"**。

### 3.2 核心观察：日期 ↔ 整数（天数坐标）

![天数轴概念](images/wc177_q1_epoch_timeline_concept.svg)

定义 $f(\text{date})$：以 **1971-01-01 为第 1 天**，date 是第几天。例如 $f(1971\text{-}01\text{-}01) = 1$，$f(1971\text{-}01\text{-}02) = 2$。

于是：

$$\text{答案} = \big|\, f(\text{date}_1) - f(\text{date}_2) \,\big|$$

相邻两天的 $f$ 值恰好差 1，所以 $f$ 值之差就是间隔天数；**绝对值**保证不依赖输入顺序。

### 3.3 计算 f(date)：整年 + 整月 + 日

![f(date) 三段拆解](images/wc177_q1_days_decompose_flow.svg)

把一个日期走过的天数拆成三段：

$$f(y,m,d) = \underbrace{365\times(y-1971) + L(1971,\,y-1)}_{\text{整年块}} + \underbrace{\text{cum}(m) + \big[\,m>2 \wedge \text{leap}(y)\,\big]}_{\text{整月块}} + \underbrace{d}_{\text{日块}}$$

- **整年块**：$[1971, y-1]$ 中每个完整年份贡献 365 天，其中闰年多 1 天（2 月 29 日）；$L(a,b)$ 表示 $[a,b]$ 内闰年个数。
- **整月块**：$\text{cum}(m)$ 为 $1 \sim m-1$ 月的累计天数（月天数表 `31,28,31,30,31,30,31,31,30,31,30,31` 的前缀和）；**当年是闰年且 $m>2$** 时再 +1（补上当年已过的 2 月 29 日）。
- **日块**：当月已经走过的天数 $d$。

**闰年判定**（格里高利历）：

$$(y \bmod 4 = 0 \,\wedge\, y \bmod 100 \neq 0) \,\vee\, (y \bmod 400 = 0)$$

> ⚠️ 本题范围含 **2100 年**：它被 100 整除但不被 400 整除，是**平年**。若只写 `y % 4 == 0`，2100 年 3 月及之后的天数会算错。而 2000 年因被 400 整除是闰年。这是本题最大的坑。

### 3.4 示例演算

![示例 2 演算](images/wc177_q1_example2_walkthrough.svg)

以示例 2 为例：

| 分量 | 2019-12-31 | 2020-01-15 |
|------|-----------|-----------|
| 整年块 | $365\times48 + 12 = 17532$ | $365\times49 + 12 = 17897$ |
| 整月块 | $\text{cum}(12) = 334$（平年不补） | $\text{cum}(1) = 0$ |
| 日块 | $31$ | $15$ |
| $f$ 值 | $17897$ | $17912$ |

答案 $= |17912 - 17897| = 15$ ✓

## 4. 算法细节

1. **字符串解析**：格式固定 `YYYY-MM-DD`，直接按下标切分——C++ 用 `substr(0,4)` / `substr(5,2)` / `substr(8,2)` 配 `stoi`；Python 用 `split('-')`。
2. **整年块**：先累加 $365\times(y-1971)$，再加 $[1971, y-1]$ 中的闰年数。循环至多 130 次，可视为常数；也可用公式 $g(n) = \lfloor n/4 \rfloor - \lfloor n/100 \rfloor + \lfloor n/400 \rfloor$（$\le n$ 的闰年个数）做严格 $O(1)$ 差分：$L(1971, y-1) = g(y-1) - g(1970)$。
3. **整月块**：预置每月天数数组，累加前 $m-1$ 项；**闰年且 $m>2$ 时 +1**。注意 $m=2$ 不需要 +1——闰年的 2 月 29 日当天由日块 $d=29$ 计入。
4. **汇总**：两个日期各算一次 $f$，取绝对值相减。
5. **Python 捷径**：标准库 `datetime.date` 自带日期差，`abs((d1 - d2).days)` 一行解决（见参考代码）。

## 5. 正确性证明

**引理 1**：相邻两天 date 与 date⁺（date 的后一天）满足 $f(\text{date}^+) = f(\text{date}) + 1$。

**证明**：按日期进位的情形逐一验证 $f$ 的增量：

- **普通日 → 次日**（$d <$ 当月天数）：只有日块 $+1$，增量为 1。
- **普通月末 → 次月 1 日**（非 12 月、非 2 月末）：设当月有 $k$ 天，整月块增加 $k$，日块变为 1（减少 $k-1$），增量为 $k-(k-1)=1$。
- **平年 2 月末（2-28 → 3-1）**：整月块增加 28，日块 $1-28=-27$，闰补不变，增量 $28-27=1$。
- **闰年 2 月（2-28 → 2-29 → 3-1）**：2-28 → 2-29 仅日块 $+1$；2-29 → 3-1 时整月块增加 28、闰补 $0 \to 1$（$m$ 变为 3 且当年闰）、日块 $1-29=-28$，增量 $28+1-28=1$。
- **年末（12-31 → 次年 1-1）**：整年块增加 $365 + [\text{leap}(y)]$（区间 $[1971, y]$ 比 $[1971, y-1]$ 多计入当年闰不闰）；整月块减少 $\text{cum}(12)=334$；闰补由 $[\text{leap}(y)]$ 变为 0，恰好抵消整年块多出的 $[\text{leap}(y)]$（当年 2 月 29 日从"闰补"改记入"整年块"，不重不漏）；日块 $1-31=-30$。总增量 $365-334-30=1$。∎

**引理 2**：若 date$_a$ 早于 date$_b$，则 $f(\text{date}_b) - f(\text{date}_a)$ 等于两日期的间隔天数。

**证明**：从 date$_a$ 出发逐日前进到 date$_b$，共前进"间隔天数"步；由引理 1，每步 $f$ 恰好增加 1，故 $f$ 值之差等于步数。∎

**定理**：算法返回两个日期之间隔的天数。

**证明**：设两日期中较早者为 $a$、较晚者为 $b$（若相同，$f$ 值相等，答案为 0）。由引理 2，$|f(\text{date}_1) - f(\text{date}_2)| = f(b) - f(a) = $ 间隔天数，与输入顺序无关。∎

## 6. 复杂度分析

- **时间复杂度**：$O(1)$。字符串长度固定为 10；整年块的闰年循环至多约 130 次（用 $g(n)$ 公式可做到严格 $O(1)$）。
- **空间复杂度**：$O(1)$。仅用常数个变量和一张 12 元素的月天数表。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int daysBetweenDates(string date1, string date2) {
        return abs(toDays(date1) - toDays(date2));
    }

private:
    bool isLeap(int y) {
        return (y % 4 == 0 && y % 100 != 0) || y % 400 == 0;
    }

    int toDays(const string& s) {
        int y = stoi(s.substr(0, 4));
        int m = stoi(s.substr(5, 2));
        int d = stoi(s.substr(8, 2));

        int cnt = 365 * (y - 1971);          // 整年块：基础天数
        for (int i = 1971; i < y; ++i)       // 整年块：[1971, y-1] 的闰日
            cnt += isLeap(i);

        static const int mdays[13] = {0, 31, 28, 31, 30, 31,
                                      30, 31, 31, 30, 31, 30, 31};
        for (int i = 1; i < m; ++i)          // 整月块：前 m-1 个月
            cnt += mdays[i];
        if (m > 2 && isLeap(y)) ++cnt;       // 整月块：当年闰日（m > 2 才补）

        return cnt + d;                      // 日块
    }
};
```

### Python

手写三段拆解，与 C++ 版一一对应：

```python
class Solution:
    def daysBetweenDates(self, date1: str, date2: str) -> int:
        def is_leap(y: int) -> bool:
            return y % 4 == 0 and y % 100 != 0 or y % 400 == 0

        mdays = [31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31]

        def to_days(s: str) -> int:
            y, m, d = map(int, s.split('-'))
            cnt = 365 * (y - 1971) + sum(is_leap(i) for i in range(1971, y))
            cnt += sum(mdays[:m - 1])
            if m > 2 and is_leap(y):
                cnt += 1
            return cnt + d

        return abs(to_days(date1) - to_days(date2))
```

标准库一行版（比赛里最省事）：

```python
from datetime import date

class Solution:
    def daysBetweenDates(self, date1: str, date2: str) -> int:
        d1 = date(*map(int, date1.split('-')))
        d2 = date(*map(int, date2.split('-')))
        return abs((d1 - d2).days)
```

## 8. 边界情况与易错点

1. **输入顺序不定**：`date1` 可能比 `date2` 早也可能晚（示例 2 中 `date1` 更晚），必须取**绝对值**。
2. **两日期相同**：答案为 0，`abs(0)` 自然覆盖，无需特判。
3. **闰年判定要写全**：范围含 2100 年（平年）与 2000 年（闰年）。只写 `y % 4 == 0` 会在 2100 年 3 月及之后出错，这是本题最大的坑。
4. **闰年 2 月 29 日输入**（如 `"2020-02-29"`）合法：$m=2$ 不触发整月块 +1，当天由日块 $d=29$ 计入，公式天然正确。
5. **闰日不重不漏**：闰日要么记在整年块（闰年落在 $[1971, y-1]$），要么记在整月块（闰年是当年且 $m>2$），二者恰好互斥且完备。
6. **字符串下标**：`YYYY-MM-DD` 固定 10 位，年 `[0,4)`、月 `[5,7)`、日 `[8,10)`，别切错位置。
7. **Python `datetime`**：两个 `date` 相减得到 `timedelta`，要取 `.days`；构造参数顺序是 `(year, month, day)`。
8. **数值范围**：最大天数差约 $130\times366\approx 4.8\times10^4$，`int` 毫无溢出风险。

**延伸思考**：

- 若年份范围扩大到任意公元纪年，可用 Howard Hinnant 的 `days_from_civil` 公式（C++20 `chrono` 的实现基础），把 $y, m, d$ 经数学变换 $O(1)$ 映射为距 1970-01-01 的天数，无需任何循环。
