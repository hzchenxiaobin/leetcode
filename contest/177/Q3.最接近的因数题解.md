# LeetCode 最接近的因数 题解

## 1. 题目概述

- **标题 / 题号**：最接近的因数（#1362，medium）
- **链接**：https://leetcode.cn/problems/closest-divisors/
- **来源**：LeetCode 第 177 场周赛 Q3
- **难度**：中等
- **标签**：数学、质因数分解

**题意**：给定整数 num，在「乘积等于 num + 1」和「乘积等于 num + 2」的所有整数对中，找出**差的绝对值最小**的一对，顺序任意返回。

**约束**：

- $1 \le \text{num} \le 10^9$，即候选数 $m$ 最大为 $10^9 + 2$。
- 两个因数都必须是正整数，且乘积正好是 $m = \text{num}+1$ 或 $m = \text{num}+2$。
- 返回顺序任意，答案对中不一定小数在前。

## 2. 示例

**示例 1**

```text
输入：num = 8
输出：[3, 3]
解释：num+1 = 9 的最接近因数是 3 与 3（差 0）；num+2 = 10 的最接近因数是 2 与 5（差 3），故取 3 与 3。
```

**示例 2**

```text
输入：num = 123
输出：[5, 25]
解释：124 的最优对是 4 与 31（差 27）；125 的最优对是 5 与 25（差 20），取后者。
```

**示例 3**

```text
输入：num = 999
输出：[40, 25]
解释：1000 的最优对是 25 与 40（差 15）；1001 的最优对是 13 与 77（差 64），取前者（返回 [25, 40] 同样正确）。
```

## 3. 解题思路

### 3.1 暴力思路

对 $m = \text{num}+1$ 与 $m = \text{num}+2$ 各枚举 $i \in [1, m]$，若 $i \mid m$ 就得到一对 $(i,\, m/i)$，记录差值最小的一对。

- **正确**但太慢：$m$ 可达 $10^9$，单个候选就要 $10^9$ 次取模，两个候选约 $2 \times 10^9$ 次，必然超时。
- 关键浪费：**因数成对出现**，枚举到 $\sqrt{m}$ 就足以覆盖全部因数对，无需枚举到 $m$。

### 3.2 核心观察：因数对关于 √m 镜像，越靠内越接近

![因数对镜像与差值单调下降](images/wc177_q3_divisor_pairs_mirror.svg)

对固定的 $m$，任意因数对都可唯一写成 $(d,\, m/d)$，其中 $d \le \sqrt{m}$——因为若两因数都 $> \sqrt{m}$，乘积就 $> m$ 了。把 $d$ 从小到大排开，配对的大因数 $m/d$ 就从大到小，两数像照镜子一样往 $\sqrt{m}$ 靠拢，**差值随之严格单调缩小**。

对因数对定义差值函数：

$$g(d) = \frac{m}{d} - d, \qquad 0 < d \le \sqrt{m}$$

任取 $0 < a < b \le \sqrt{m}$：

$$g(a) - g(b) = m\left(\frac{1}{a} - \frac{1}{b}\right) + (b - a) = (b - a)\left(\frac{m}{ab} + 1\right) > 0$$

即 $g$ 在 $(0, \sqrt{m}]$ 上**严格递减**。于是：

> 💡 **只需找 $m$ 的不超过 $\sqrt{m}$ 的最大因数 $d^*$**，$(d^*, m/d^*)$ 就是 $m$ 的最优因数对。从 $\lfloor\sqrt{m}\rfloor$ 往下扫，**第一个能整除 $m$ 的 $i$** 正是这个 $d^*$。

由于 $1$ 永远整除 $m$，扫描必定在 $i = 1$ 之前停下，不会越界。

### 3.3 算法流程

![从 √m 往下扫的流程](images/wc177_q3_scan_down_flow.svg)

对 $m \in \{\text{num}+1,\ \text{num}+2\}$ 各做一次：

1. 取整数平方根 $i = \lfloor\sqrt{m}\rfloor$（浮点开方后修正，或直接用 `isqrt`）。
2. 若 $i \nmid m$ 则 $i \leftarrow i - 1$，重复直到 $m \bmod i = 0$。
3. 得到该候选的最优对 $(i,\, m/i)$ 与差值 $m/i - i$。
4. 比较两个候选的差值，返回较小者。

### 3.4 示例演算

![num = 123 的演算走查](images/wc177_q3_example_walkthrough.svg)

以示例 2（num = 123）为例：

| 候选 $m$ | $\lfloor\sqrt{m}\rfloor$ | 扫描过程 | 首次命中 | 差值 |
|---------|------------------------|---------|---------|------|
| 124 | 11 | 11, 10, 9, 8, 7, 6, 5 均不整除 | $i = 4$ | $31 - 4 = 27$ |
| 125 | 11 | 11, 10, 9, 8, 7, 6 均不整除 | $i = 5$ | $25 - 5 = 20$ |

$20 < 27$，所以返回 $[5, 25]$ ✓

再看示例 1（num = 8）：$9 = 3^2$，$i$ 从 $\lfloor\sqrt{9}\rfloor = 3$ 起就是因数，差值 $3 - 3 = 0$，直接胜出，返回 $[3, 3]$ ✓

## 4. 算法细节

1. **整数平方根必须修正**：`sqrt(double)` 在 $m$ 接近 $10^9$ 时可能返回 $s$ 使 $s^2 > m$ 或 $(s+1)^2 \le m$。C++ 用两个 `while` 分别向上、向下微调；Python 直接用 `math.isqrt` 一步到位。
2. **向下扫描的终止条件**：只需判断 `m % i`，不用事先求出所有因数；$i = 1$ 时必然整除，因此循环天然安全。
3. **命中即停**：第一次整除得到的 $i$ 就是「不超过 $\sqrt{m}$ 的最大因数」，再往下扫只会让差值变大，必须 `break`（或直接返回）。
4. **比较时用严格小于**：两个候选取差小者；差值相等时保留先算出的 $m = \text{num}+1$ 那一对，两者都合法。
5. **类型选择**：$m \le 10^9 + 2$ 虽在 `int` 范围内，但 `(i + 1) * (i + 1)` 这类平方运算建议用 `long long`（Python 无此问题），避免边界乘法踩坑。
6. **返回顺序**：题面允许任意顺序，代码统一返回「小因数在前」即可，不必为了对齐示例 3 的 `[40, 25]` 做额外处理。

## 5. 正确性证明

**引理 1**：对任意 $m \ge 2$，函数 $g(d) = m/d - d$ 在 $(0, \sqrt{m}]$ 上严格递减。

**证明**：任取 $0 < a < b \le \sqrt{m}$，有

$$g(a) - g(b) = \frac{m}{a} - a - \frac{m}{b} + b = (b - a)\left(\frac{m}{ab} + 1\right)$$

因 $b - a > 0$ 且 $m/(ab) + 1 > 0$，故 $g(a) > g(b)$，即 $g$ 严格递减。∎

**引理 2**：若 $d^*$ 是 $m$ 的不超过 $\sqrt{m}$ 的最大正因数，则 $(d^*,\, m/d^*)$ 是 $m$ 全部因数对中差值最小的一对。

**证明**：设 $(d,\, m/d)$ 是 $m$ 的任一因数对。若 $d \le \sqrt{m}$，由 $d \le d^*$ 与引理 1 得 $g(d) \ge g(d^*)$，等号当且仅当 $d = d^*$；若 $d > \sqrt{m}$，则同一对数可改写为 $(m/d,\, d)$，其中 $m/d < \sqrt{m}$，化为前一种情形。故所有因数对的差值都 $\ge g(d^*)$，且 $(d^*,\, m/d^*)$ 取到最小值。∎

**引理 3**：从 $i = \lfloor\sqrt{m}\rfloor$ 起逐个减 1，遇到的第一个 $m$ 的因数就是引理 2 中的 $d^*$。

**证明**：$\lfloor\sqrt{m}\rfloor \ge \sqrt{m} - 1$ 且 $\lfloor\sqrt{m}\rfloor \le \sqrt{m}$，扫描序列 $\lfloor\sqrt{m}\rfloor, \lfloor\sqrt{m}\rfloor - 1, \dots, 1$ 恰好按降序覆盖 $[1, \lfloor\sqrt{m}\rfloor]$ 的全部整数。第一个满足 $i \mid m$ 的 $i$ 即该区间内最大的因数。又因 $\lfloor\sqrt{m}\rfloor \le \sqrt{m}$，它也是不超过 $\sqrt{m}$ 的最大因数。$i = 1$ 必然整除 $m$，保证扫描一定终止。∎

**定理**：算法返回的整数对满足乘积为 $\text{num}+1$ 或 $\text{num}+2$，且差值在所有合法对中最小。

**证明**：设 $P_1$、$P_2$ 分别是 $m_1 = \text{num}+1$、$m_2 = \text{num}+2$ 的全部因数对集合。题面要求的两数必属于 $P_1 \cup P_2$。由引理 2、3，`best(m)` 返回 $P_i$ 中差值最小者。算法比较两者的差值并取较小的一对，故它在该并集上取下确界并实际取到，即为全局最优；其乘积显然等于对应候选数。∎

## 6. 复杂度分析

- **时间复杂度**：$O(\sqrt{\text{num}})$。两次扫描各至多 $\lfloor\sqrt{m}\rfloor \le 31623$ 步，总计约 $6.3 \times 10^4$ 次取模与比较，远低于时限。
- **空间复杂度**：$O(1)$。只用了常数个整型变量，无额外数组或哈希表。
- **数值安全**：所有中间量不超过 $10^9 + 2$，`long long` 内绰绰有余；差值 $m/i - i$ 恒非负，无符号问题。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> closestDivisors(int num) {
        // 返回 m 的最优因数对：不超过 sqrt(m) 的最大因数 d 与 m/d
        auto best = [](long long m) -> pair<long long, long long> {
            long long i = (long long)sqrt((double)m);
            while ((i + 1) * (i + 1) <= m) ++i;   // 修正浮点开方偏小
            while (i * i > m) --i;                // 修正浮点开方偏大
            while (m % i != 0) --i;               // 往下扫到第一个因数
            return {i, m / i};
        };

        pair<long long, long long> a = best((long long)num + 1);
        pair<long long, long long> b = best((long long)num + 2);

        if (a.second - a.first <= b.second - b.first)
            return {(int)a.first, (int)a.second};
        return {(int)b.first, (int)b.second};
    }
};
```

### Python

```python
import math


class Solution:
    def closestDivisors(self, num: int) -> list[int]:
        def best(m: int) -> list[int]:
            i = math.isqrt(m)          # 整数开方，无浮点误差
            while m % i:               # 往下扫到第一个因数
                i -= 1
            return [i, m // i]

        a = best(num + 1)
        b = best(num + 2)
        return a if a[1] - a[0] <= b[1] - b[0] else b
```

## 8. 边界情况与易错点

1. **num = 1**：候选数 2 与 3 都是质数，最优对分别是 $(1, 2)$（差 1）和 $(1, 3)$（差 2），答案 $[1, 2]$。扫描时 $i$ 直接落到 1，不会死循环。
2. **候选数本身是完全平方数**（如 num = 8 时的 9、num = 15 时的 16）：$i = \sqrt{m}$ 一次命中，差值为 0，一定是最优，别漏掉这种「零差」情形。
3. **浮点开方误差**：用 `sqrt((double)m)` 而不修正，在 $m$ 接近 $10^9$ 时可能得到 $s$ 使 $s^2 > m$（后面 `m % i` 逻辑仍对，但会多扫几次）或使 $(s+1)^2 \le m$（直接**漏掉**真正的最大因数，得到的差值偏大、答案错误）。务必用两个 `while` 卡紧或改用 `isqrt`。
4. **候选数为质数**：$m$ 是质数时唯一因数对是 $(1, m)$，差值 $m - 1$ 很大；它能自动被扫描到 $i = 1$ 处理，不需要特判。
5. **返回顺序**：示例 3 官方输出为 `[40, 25]`（大数在前），而本实现返回 `[25, 40]`，二者等价，判题按集合比较，不要为此写多余的反转逻辑。
6. **不要枚举到 $m$**：暴力的 $O(m)$ 在 $10^9$ 规模必然超时；只需枚举到 $\lfloor\sqrt{m}\rfloor$，这是本题的命门。
7. **两个候选的取舍**：必须分别求「各自最优」再比较，不能只算 $\text{num}+1$；示例 2 中 $\text{num}+2$ 的方案更优。
8. **循环必须能跳出**：`while (m % i)` 依赖 $i = 1$ 必整除的性质；质数候选只到 $i = 1$ 才命中，若把下界写成 $i \ge 2$，扫描会越过 1 变成 `m % 0`（除零崩溃）或越界。

**延伸思考**：

- 若把约束放大到 $\text{num} \le 10^{18}$，$\sqrt{m} \approx 10^9$ 的枚举就不可接受了。此时应先对 $m$ 做 **Pollard-Rho 质因数分解**，再在约数集合上搜索最接近 $\sqrt{m}$ 的组合——这也正是本题标签「质因数分解」在大数据范围下的真正用法。
- 若要求的是「两数之和最小」而非差值最小，结论恰好相同：$m/d + d$ 在 $(0, \sqrt{m}]$ 上同样单调递减，最优仍是 $d^*$。
- 若允许两数取负数（乘积为正），只需把每对再取相反数，差值不变，答案集翻倍但对结果无影响。
