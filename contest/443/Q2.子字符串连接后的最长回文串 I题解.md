# LeetCode 子字符串连接后的最长回文串 I 题解

## 1. 题目概述

- **标题 / 题号**：子字符串连接后的最长回文串 I（#3503，medium）
- **链接**：https://leetcode.cn/problems/longest-palindrome-after-substring-concatenation-i/
- **来源**：LeetCode 第 443 场周赛 Q2
- **难度**：中等
- **标签**：枚举、双指针、字符串、动态规划

**题意**：给你两个小写字符串 $s$ 和 $t$。从 $s$ 中选一个**子串** $A$（可为空），从 $t$ 中选一个**子串** $B$（可为空），按顺序拼接 $W = A + B$（$s$ 侧在前）。返回能拼出的**最长回文串** $W$ 的长度。

**约束**：

- $1 \le \text{s.length}, \text{t.length} \le 30$
- $s$ 和 $t$ 仅由小写英文字母组成

> 💡 **复盘定位**：本场是罕见的「一场双版」——本题与 Q3（#3504）题面**逐字相同**，仅数据范围 $30 \to 1000$，后者由中等升格为困难。本题存在清晰的三层做法梯度：① 纯暴力 $O\big(m^2n^2(m+n)\big)$，在 $30$ 的范围下可直接通过，这是本题定级中等的全部原因；② 「**锚点枚举 + 逐深度结算**」的结构化枚举 $O\big(mn\cdot\min(m,n)\big)$——把「整串判回文」拆成「镜像配对 + 单侧回文核」，是从暴力通往 DP 的中间台阶；③ Q3 的剥皮 DP $O(mn)$。比赛时的最优策略是①拿分走人；但赛后的价值在②——它正是③那条递推链的手动展开，是「枚举 → DP」升维范式的最好教具。

## 3. 解题思路

### 3.1 暴力思路：枚举全部子串对，直接判回文

$s$ 共有 $\frac{m(m+1)}{2} + 1$ 个子串（含空串，$m = |s|$），$t$ 同理。把两侧子串两两拼接、逐个判回文，取最长：

- 子串对数：$\big(\tfrac{m(m+1)}{2}+1\big)\big(\tfrac{n(n+1)}{2}+1\big) \approx 466 \times 466 \approx 2.2 \times 10^5$（$m = n = 30$）
- 每次判回文 $O(m+n) \le 60$，总计约 $1.3 \times 10^7$ 次字符比较

C++ / Python 都能瞬间通过——**I 版用暴力就能过关**。但同样的做法放到 Q3 的 $n, m \le 1000$ 上是 $10^{13}$ 量级，彻底不可行。真正值得复盘的问题是：**「判回文」这个动作能否被拆开，让所有构造共享计算？**

### 3.2 核心观察：回文 = 若干对镜像首尾 + 单侧回文核

设 $W = A + B$ 是回文，$A$ 以 $s[i_1]$ 开头、$B$ 以 $t[i_2]$ 结尾（记 $i_1$、$i_2$ 为**锚点**）。

- 若 $A$、$B$ **均非空**：$W$ 的首字符是 $s[i_1]$、尾字符是 $t[i_2]$，回文性迫使 $s[i_1] = t[i_2]$。**剥掉这对首尾**，剩下的 $W'$ 仍是回文，且形态完全同构（$A$ 去首、$B$ 去尾仍是子串）。逐层剥下去，直到某一侧被剥空；
- 剥空一侧后，剩下的**核**必然是**单侧**的：要么是 $s$ 中以 $i_1 + k$ 为起点的回文子串，要么是 $t$ 中以 $i_2 - k$ 为终点的回文子串，要么为空（双侧同时剥空）。

于是任何构造都可写成

$$W = \underbrace{s[i_1..i_1+k-1]}_{\text{镜像翼（}k\text{ 对）}} + \underbrace{P}_{\text{单侧回文核}} + \underbrace{t[i_2-k+1..i_2]}_{\text{镜像翼}}, \qquad |W| = 2k + |P|$$

其中配对条件 $s[i_1+h] = t[i_2-h]$ 对所有 $h < k$ 成立。**反过来**，只要配对条件成立、$P$ 是对应位置的单侧回文（或空），拼出来的 $W$ 必为回文。

据此把「枚举子串对 + 整串判回文」改写成「**枚举锚点 $(i_1, i_2)$ + 双向同步扩展 + 逐深度结算**」：

- 预处理两张核长表：$\text{midS}[x]$ = $s$ 中以 $x$ 为**起点**的最长回文长度（$\text{midS}[m] = 0$ 表示空核）；$\text{midT}[y]$ = $t$ 中以 $y$ 为**终点**的最长回文长度；
- 对每个锚点，$s$ 正读、$t$ 倒读逐对配对，每成功剥一层（深度 $k$）就**即时结算**
  $$2k + \max\big(\text{midS}[i_1+k],\ \text{midT}[i_2-k]\big)$$
- 深度 $k = 0$ 的结算（即 $\max(\text{midS}[i_1], \text{midT}[i_2])$）**不需要任何字符配对**，恰好覆盖 $A$、$B$ 有一侧为空的构造。

![锚点双向扩展与逐深度结算的结构分解](images/wc443_q2_anchor_peel_structure.svg)

> 💡 为什么**每个深度都要结算**，而不是只在链断时算一次？直觉上「多剥一层翼 +2，但核缩水」似乎可能亏。实际上固定锚点的结算值随 $k$ **单调不减**（见 §4 第 5 点），只在链断处结算也正确；但「逐深度结算」不需要想清这一点就能保证正确性，而且它正是 Q3 剥皮 DP 那条递推链的逐层展开形态——按层写，赛后对照 Q3 时能一眼看出「折叠」发生在哪里。

### 3.3 算法流程

![算法流程：预处理 + 枚举锚点 + 双向扩展逐深度结算](images/wc443_q2_algorithm_flow.svg)

**执行步骤**：

| 步骤 | 动作 | 说明 |
|------|------|------|
| ① | 区间 DP 预处理回文表 | $isPal[i][j] = (a[i] = a[j]) \wedge isPal[i{+}1][j{-}1]$，按长度递增填表，$O(m^2 + n^2)$ |
| ② | 导出核长表 | $\text{midS}[i]$：$s$ 中以 $i$ 为起点的最长回文；$\text{midT}[j]$ 借道反串（反串的「起点」= 正串的「终点」，翻转下标） |
| ③ | 枚举锚点 $(i_1, i_2)$，先做深度 0 结算 | $\text{ans} \leftarrow \max(\text{ans},\ \text{midS}[i_1],\ \text{midT}[i_2])$，覆盖单侧构造 |
| ④ | 双向同步扩展 | 循环判 $s[i_1{+}k] = t[i_2{-}k]$ 且 $i_1{+}k < m$、$i_2{-}k \ge 0$：成立则 $k \leftarrow k+1$，结算 $2k + \max(\text{midS}[i_1{+}k],\ \text{midT}[i_2{-}k])$（越界侧取 0） |
| ⑤ | 所有锚点枚举完 | 输出 $\text{ans}$（$n, m \ge 1$ 保证 $\text{ans} \ge 1$） |

### 3.4 示例演算

![示例 4 的锚点扩展与逐深度结算演算](images/wc443_q2_walkthrough.svg)

以示例 4（$s =$ `abcde`，$t =$ `ecdba`）演算。两串字符两两互异，没有长度 $> 1$ 的回文子串，故 $\text{midS}[0..4] = \text{midT}[0..4] = [1,1,1,1,1]$，$\text{midS}[5] = 0$。

**关键锚点 $(0, 4)$**（$A$ 的起点 $s[0] = $ `a`，$B$ 的终点 $t[4] = $ `a`）：配对 $s[0] = t[4]$（`a`）、$s[1] = t[3]$（`b`）相继成功，$s[2] = $ `c` $\ne$ `d` $= t[2]$ 链断，$K = 2$：

| 深度 $k$ | 结算 $2k + \max(\text{midS}[i_1{+}k], \text{midT}[i_2{-}k])$ | 长度 | 对应构造 |
|---|---|---|---|
| 0 | $\max(1, 1)$ | 1 | `a`（任一侧单字符） |
| 1 | $2 + \max(1, 1)$ | 3 | `ab` + `a` = `aba` |
| 2 | $4 + \max(1, 1)$ | **5** | `abc` + `ba` = `abcba` ← ans |

深度 2 时 $A$ 侧剩 `c`（以 $i_1 + 2 = 2$ 为起点的回文核），$B$ 侧剩 `d`（以 $i_2 - 2 = 2$ 为终点的回文核），两侧核长都是 1，结算 $4 + 1 = 5$ ✓。

**边界锚点 $(4, 0)$**：$s[4] = t[0] =$ `e` 配对成功，剥一层后 $i_1 + 1 = 5 = m$ 且 $i_2 - 1 = -1$——**双侧同时剥空**，空核结算 $2 \times 1 + \max(\text{midS}[5], \text{midT}[-1]) = 2 + 0 = 2$，即 `e` + `e` = `ee`。

再看 $s =$ `ab`、$t =$ `ba`：锚点 $(0, 1)$ 连剥两对后同样双侧剥空，结算 $4 + 0 = 4$，即 `ab` + `ba` = `abba`——整串对整串，全靠空核哨兵撑起答案。

## 4. 算法细节

1. **核长表必须取「真值」**：$\text{midS}[i]$ 是**恰好以 $i$ 为起点**的最长回文长度，要用区间回文表对每个起点取最右回文端点。**不能**拿中心扩展 / Manacher 的「极大回文」直接导出：极大回文的起点可能越过 $i$——如 `cabac` 中以 1 为起点的最长回文是 `aba`，而中心 2 的极大扩展是整串 `cabac`（起点 0）。以 $i$ 为锚的核必须**恰好**从 $i$ 开始。
2. **$\text{midT}$ 借道反串**：对 $t^{rev}$ 复用同一个「每起点的最长回文」函数，再翻转下标 $\text{midT}[j] = \text{mid}\big(n-1-j\big)$（反串中起点 $n-1-j$ 的回文 ⇔ 正串中终点 $j$ 的回文，长度相同），避免写两份对称代码。
3. **深度 0 的结算独立于扩展循环**：`ans ← max(ans, midS[i1], midT[i2])` 对**每个**锚点都执行——它覆盖 $A$、$B$ 有一侧为空的构造，且不要求 $s[i_1] = t[i_2]$。示例 3 中 $s=$`b`、$t=$`aaaa` 没有任何匹配锚点，答案 4 全靠 $k=0$ 结算的 $\text{midT}[3] = 4$。
4. **空核哨兵**：扩展循环因越界退出时，$i_1 + k = m$ 或 $i_2 - k = -1$ 可能成立，此时对应侧核长取 0。实现上 $\text{midS}$ 多开一格存 $\text{midS}[m] = 0$；$t$ 侧用 `i2 - k >= 0` 的条件判断兜底，不在数组外另开 $-1$ 下标。
5. **结算的单调性（彩蛋）**：回文去掉首尾仍是回文，故 $\text{midS}[i+1] \ge \text{midS}[i] - 2$、$\text{midT}[j-1] \ge \text{midT}[j] - 2$；于是 $2k + \text{midS}[i_1{+}k]$ 与 $2k + \text{midT}[i_2{-}k]$ 都随 $k$ 单调不减，max 亦然——**固定锚点的最优结算总在链断处**，逐深度结算与「只在链断处结算一次」等价（已用随机对拍二次验证）。主实现仍按层结算：不需要预证单调性就正确，且与 Q3 的递推链形态一一对应。
6. **循环内的结算顺序**：先 `k += 1` 再结算——结算发生在「已剥 $k$ 对」之时，配对条件恰为 $h < k$ 已验证；把结算写在配对判断之前会把深度错位一层。

## 5. 正确性证明

**引理 1（剥皮归约）**：设 $W = A + B$ 是回文，$A$、$B$ 均非空，$A$ 以 $s[i_1]$ 开头，$B$ 以 $t[i_2]$ 结尾。则 $s[i_1] = t[i_2]$，且 $W' = W[2..|W|]$（去掉首尾）是回文，并可写成 $W' = A' + B'$，其中 $A'$ 为空或是以 $s[i_1+1]$ 开头的 $s$ 子串，$B'$ 为空或是以 $t[i_2-1]$ 结尾的 $t$ 子串。

**证明**：$W$ 回文故首字符 $=$ 尾字符。$A$ 非空且是 $W$ 的前缀，故首字符为 $s[i_1]$；$B$ 非空且是 $W$ 的后缀，故尾字符为 $t[i_2]$，得 $s[i_1] = t[i_2]$。回文去掉一对首尾仍回文。$A' = A[2..]$ 从 $s$ 中去掉首字符，仍是连续子串（或空），起点变为 $s[i_1+1]$；$B' = B[1..|B|-1]$ 同理，终点变为 $t[i_2-1]$；且 $|W'| = |A'| + |B'|$，拼接关系保持。∎

**引理 2（镜像构造）**：设正整数 $k$ 满足 $s[i_1+h] = t[i_2-h]$ 对所有 $0 \le h < k$ 成立，$P$ 是 (a) $s$ 中以 $i_1+k$ 为起点的回文子串，或 (b) $t$ 中以 $i_2-k$ 为终点的回文子串，或 (c) 空串。则 $W = s[i_1..i_1+k-1] + P + t[i_2-k+1..i_2]$ 是回文，且是合法构造（前段与 $P$ 合计为 $s$ 的子串 $A$，后段为 $t$ 的子串 $B$）。

**证明**：对 $k$ 归纳。$k = 0$ 时 $W = P$，回文性即 $P$ 的回文性（空串视为回文）。$k \ge 1$ 时，$W$ 的首字符 $s[i_1]$ 与尾字符 $t[i_2]$ 由配对条件（$h = 0$）相等；剥掉后剩下 $s[i_1{+}1..i_1{+}k{-}1] + P + t[i_2{-}k{+}1..i_2{-}1]$，配对条件对 $1 \le h < k$ 仍成立（换成锚点 $(i_1+1, i_2-1)$、深度 $k-1$ 的情形），由归纳假设回文；首尾相等 + 内部回文 ⟹ $W$ 回文。$A = s[i_1..i_1+k-1] + P$ 中 $P$ 若非空则 (a) 情形 $P$ 紧接 $s$ 的第 $i_1+k$ 个字符之后，连续性保持（(b) 情形 $P$ 在 $t$ 中、$A$ 只有前段），$B$ 同理均为对应串的连续子串。∎

**定理（不虚不漏）**：算法输出的 $\text{ans}$ 等于全局最优长度。

**证明**：

- **不虚**：算法产生的每个结算值都对应一个真实构造。深度 $k$ 的结算只在循环内配对验证 $h < k$ 通过后发生（引理 2 的前提成立），取 $\text{midS}[i_1+k]$ 的实现核（该起点的最长回文）或 $\text{midT}[i_2-k]$ 的实现核（或两侧越界时的空核），由引理 2 拼出长度恰为结算值的回文。故 $\text{ans}$ 不超过真实最优。
- **不漏**：任取最优构造 $W = A + B$。
  - 若 $B$ 为空：$W = A$ 是以 $A$ 的起点为首的 $s$ 回文子串；取锚点 $(A\text{ 的起点},\ j_2)$（$n \ge 1$ 保证 $j_2$ 存在），深度 0 结算的 $\text{midS}$ 项 $\ge |W|$。$A$ 为空时对称取 $\text{midT}$ 项。
  - 若 $A$、$B$ 均非空：取 $i_1$ = $A$ 的起点、$i_2$ = $B$ 的终点，$k^* = \min(|A|, |B|)$。对 $h = 0, 1, \ldots, k^*-1$ 反复应用引理 1：每次剥皮后剩余部分仍是「$s$ 子串 + $t$ 子串」的回文且两侧非空，故 $s[i_1+h] = t[i_2-h]$ 成立——扩展循环在第 $k^*$ 层之前不会中断，深度 $k^*$ 的结算必然执行。此时恰有一侧剥空：若 $|A| \ge |B|$（$k^* = |B|$），剩料是 $A$ 去掉前 $k^*$ 个字符的回文子串、以 $i_1 + k^*$ 为起点、长度 $|A| - k^*$，故 $\text{midS}[i_1+k^*] \ge |A| - k^*$，结算值 $\ge 2k^* + (|A| - k^*) = |A| + |B| = |W|$；$|B| \ge |A|$ 时对 $\text{midT}[i_2-k^*]$ 对称同理。

  综上，任何最优构造都被某个结算覆盖，$\text{ans} \ge$ 最优。结合「不虚」，$\text{ans}$ 恰为最优。∎

**推论（每层结算的冗余是无害的）**：由 §4 第 5 点的单调性，同一锚点逐深度结算的最大值总在链断层取得，中间层的结算不改变结果、也不引入错误——「逐层」与「链断一次」两种写法等价。

## 6. 复杂度分析

- **时间复杂度**：$O(m^2 + n^2 + mn\cdot\min(m,n))$。两张区间回文表与核长表各 $O(m^2)$、$O(n^2)$；锚点 $mn$ 个，每个双向扩展至多 $\min(m, n)$ 层、每层 $O(1)$ 结算。$m = n = 30$ 时上界约 $2.7 \times 10^4$ 次结算（全 `a` 串达到最坏），Python 实测毫秒级；即使放到 $m = n = 100$ 也只有 $10^6$ 量级。
- **空间复杂度**：$O(m^2 + n^2)$，大头是两张回文判定表；若改用中心扩展求核长可降到 $O(m + n)$，但需小心 §4 第 1 点的真值坑，本题规模无必要。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int longestPalindrome(string s, string t) {
        int m = s.size(), n = t.size();

        auto midFromStart = [](const string& a) {   // mid[i]：a 中以 i 为起点的最长回文长度
            int L = a.size();
            vector<int> mid(L + 1, 0);              // mid[L] = 0：空核哨兵
            vector<vector<char>> isPal(L, vector<char>(L, 1));
            for (int i = 0; i + 1 < L; ++i) isPal[i][i + 1] = (a[i] == a[i + 1]);
            for (int len = 3; len <= L; ++len)
                for (int i = 0; i + len - 1 < L; ++i) {
                    int j = i + len - 1;
                    isPal[i][j] = (a[i] == a[j]) && isPal[i + 1][j - 1];
                }
            for (int i = 0; i < L; ++i)
                for (int j = L - 1; j >= i; --j)
                    if (isPal[i][j]) { mid[i] = j - i + 1; break; }
            return mid;
        };

        vector<int> midS = midFromStart(s);
        vector<int> midR = midFromStart(string(t.rbegin(), t.rend()));
        vector<int> midT(n);                        // midT[j]：t 中以 j 为终点的最长回文
        for (int j = 0; j < n; ++j) midT[j] = midR[n - 1 - j];

        int ans = 0;
        for (int i1 = 0; i1 < m; ++i1)
            for (int i2 = 0; i2 < n; ++i2) {
                ans = max({ans, midS[i1], midT[i2]});      // 深度 0：纯单侧核，无需配对
                int k = 0;
                while (i1 + k < m && i2 - k >= 0 && s[i1 + k] == t[i2 - k]) {
                    ++k;                                   // 剥掉一对镜像首尾
                    int core = midS[i1 + k];
                    if (i2 - k >= 0) core = max(core, midT[i2 - k]);
                    ans = max(ans, 2 * k + core);          // 深度 k 即时结算
                }
            }
        return ans;
    }
};
```

```python
class Solution:
    def longestPalindrome(self, s: str, t: str) -> int:
        m, n = len(s), len(t)

        def mid_from_start(a: str) -> list:
            # mid[i]：a 中以 i 为起点的最长回文长度；mid[L] = 0 为空核哨兵
            L = len(a)
            mid = [0] * (L + 1)
            is_pal = [[True] * L for _ in range(L)]
            for i in range(L - 1):
                is_pal[i][i + 1] = a[i] == a[i + 1]
            for length in range(3, L + 1):
                for i in range(L - length + 1):
                    j = i + length - 1
                    is_pal[i][j] = a[i] == a[j] and is_pal[i + 1][j - 1]
            for i in range(L):
                for j in range(L - 1, i - 1, -1):
                    if is_pal[i][j]:
                        mid[i] = j - i + 1
                        break
            return mid

        mid_s = mid_from_start(s)
        rev = mid_from_start(t[::-1])                 # 反串的「起点」= 正串的「终点」
        mid_t = [rev[n - 1 - j] for j in range(n)]    # midT[j]：t 中以 j 为终点的最长回文

        ans = 0
        for i1 in range(m):
            for i2 in range(n):
                ans = max(ans, mid_s[i1], mid_t[i2])  # 深度 0：纯单侧核，无需配对
                k = 0
                while i1 + k < m and i2 - k >= 0 and s[i1 + k] == t[i2 - k]:
                    k += 1                            # 剥掉一对镜像首尾
                    core = mid_s[i1 + k]
                    if i2 - k >= 0:
                        core = max(core, mid_t[i2 - k])
                    ans = max(ans, 2 * k + core)      # 深度 k 即时结算
        return ans
```

### 附：暴力对拍基准（Python，仅 I 版范围可过）

```python
def brute(s: str, t: str) -> int:
    subs = lambda a: [''] + [a[i:j] for i in range(len(a)) for j in range(i + 1, len(a) + 1)]
    return max(len(w) for a in subs(s) for b in subs(t)
               if (w := a + b) == w[::-1])
```

> 💡 两份主代码均通过官方 4 个示例 + 共 45000 组与 $O\big(m^2n^2(m+n)\big)$ 暴力的随机对拍（Python 25000 组、C++ 20000 组，字符集 1–5 个字母、长度 1–12），另通过全 `a` 最坏用例（$m = n = 30$，答案 60，Python 约 5ms）与「只在链断处结算」变体的 20000 组等价性对拍。

## 8. 边界情况与易错点

1. **核长表真值坑**：$\text{midS}[i]$ 必须是「恰好以 $i$ 为起点」的最长回文。中心扩展 / Manacher 的极大回文数组起点可能越过 $i$（`cabac` 的例子），直接用会系统性低估或错配核。
2. **深度 0 结算不能省**：它不依赖任何字符配对，是「$A$、$B$ 单侧为空」构造的唯一来源。示例 3（`b` + `aaaa`）没有任何匹配锚点，漏掉 $k=0$ 结算就会错答。
3. **空核哨兵**：`ab` + `ba` = `abba`（长度 4）这类「整串配整串、双侧同时剥空」的答案完全依赖 $i_1+k = m$ 时 $\text{midS}$ 取 0、$i_2-k = -1$ 时 $\text{midT}$ 取 0。少一个哨兵，这类构造全丢。
4. **$\text{midT}$ 的方向**：对反串求「每起点最长回文」后必须翻转下标（$\text{midT}[j] = \text{mid}[n-1-j]$），忘了翻转只有部分用例能暴露——示例 4 之外的用例会大规模出错。
5. **结算写在配对成功之后**：`++k` 之后再结算。若把结算写在循环条件判断之前，深度会错位一层，等于把 $k$ 层的答案按 $k-1$ 层的核长算。
6. **答案下界**：题目允许 $A$、$B$ 都为空，但 $n, m \ge 1$ 时任选单字符即得长度 1 的回文；深度 0 结算恒 $\ge 1$，`ans` 初值取 0 即可，无需特判。
7. **暴力别带进 Q3**：$O\big(m^2n^2(m+n)\big)$ 在 $30$ 的范围是 $10^7$、在 $1000$ 的范围是 $10^{13}$——I/II 的分水岭就在这里；同理本题的结构化枚举 $O\big(mn\cdot\min(m,n)\big)$ 在 II 版约 $10^9$，也过不了，必须再折叠成 Q3 的 $O(mn)$。

**延伸思考**：

- **结算单调性**：固定锚点时，结算值 $2k + \max(\text{midS}[i_1{+}k],\ \text{midT}[i_2{-}k])$ 随 $k$ 单调不减（核每深一层最多缩 2、翼必加 2）。因此「逐深度结算」可安全简化为「链断处一次结算」——但这需要多证一条引理（$\text{midS}[i+1] \ge \text{midS}[i]-2$）；而 Q3 的 DP 本质上把这条单调链交给了递推，无需显式用到单调性。
- **若数据范围再放大**：$10^5$ 量级下，瓶颈依次变为 $O(m^2)$ 的回文表（改 Manacher / 滚动哈希）与 $O(mn)$ 的双序列对齐（已是常态下界），详见 Q3 题解的延伸讨论。
- **比赛策略**：一场双版里，I 版用暴力 5 分钟拿分、把时间留给 Q4 是否划算？本题的四层梯度（暴力 → 结构化枚举 → 链断结算 → DP）给出一个通用的复盘框架：**赛后把暴力解升级成「能讲出结构」的解**，双版题的第二问就变成了免费的复习。
