# LeetCode 统计点对的数目 题解

## 1. 题目概述

- **标题 / 题号**：统计点对的数目（#1782，hard）
- **链接**：https://leetcode.cn/problems/count-pairs-of-nodes/
- **来源**：LeetCode 第 47 场双周赛 Q4
- **难度**：困难
- **标签**：图、数组、哈希表、双指针、二分查找、计数、排序

**题意**：给定 $n$ 个节点的无向图（可能有**重边**，无自环），边表 `edges[i] = [u_i, v_i]`，以及查询数组 `queries`。对第 $j$ 个查询，统计满足以下条件的点对 $(a, b)$ 的数目：

- $a < b$；
- **与 $a$ 或 $b$ 至少一端相连的边的总数** $\mathit{cnt}(a,b)$ **严格大于** $\mathit{queries}[j]$。

返回数组 `answers`，`answers[j]` 为第 $j$ 个查询的结果。

**约束**：

- $2 \le n \le 2 \times 10^4$
- $1 \le edges.length \le 10^5$
- $1 \le u_i, v_i \le n$ 且 $u_i \ne v_i$
- $1 \le queries.length \le 20$
- $0 \le queries[j] < edges.length$

## 2. 示例

**示例 1**

```text
输入：n = 4, edges = [[1,2],[2,4],[1,3],[2,3],[2,1]], queries = [2,3]
输出：[6,5]
解释：各点度数为 deg[1]=3, deg[2]=4, deg[3]=2, deg[4]=1；
     (1,2) 之间有 2 条重边。k=2 时 6 个点对全部满足；
     k=3 时除 (3,4)（恰好 3 条）外全部满足。
```

**示例 2**

```text
输入：n = 5, edges = [[1,5],[1,5],[3,4],[2,5],[1,3],[5,1],[2,3],[2,5]], queries = [1,2,3,4,5]
输出：[10,10,9,8,6]
```

## 3. 解题思路

### 3.1 暴力思路

对每个查询枚举全部 $\binom{n}{2} \approx 2 \times 10^8$ 个点对、再对每对扫一遍 $10^5$ 条边数 $\mathit{cnt}$，是 $O(Q \cdot n^2 \cdot E)$ 的天文数字；即便把"扫边"换成邻接集合的度数相减，$O(Q \cdot n^2)$ 也有 $4 \times 10^9$ 量级。瓶颈在于：**点对太多了**（$2 \times 10^8$），任何逐对统计的做法都不可行，必须先把点对按某种可排序、可聚合的标量"折叠"起来批量数。

### 3.2 核心观察一：cnt 是度数的和减去重边数（容斥）

![容斥：点对边数等于两端度数之和减去重边数](images/bw47_q4_inclusion_exclusion.svg)

把"与 $a$ 相连的边"看作集合 $A$、"与 $b$ 相连的边"看作集合 $B$，题目要数的 $\mathit{cnt}(a,b) = |A \cup B|$。显然 $A \cap B$ 恰是 **$a$、$b$ 之间的重边**（每条这样的边在 $A$、$B$ 中各计一次），设其条数为 $\mathit{mult}(a, b)$，则容斥给出：

$$\mathit{cnt}(a, b) = \deg[a] + \deg[b] - \mathit{mult}(a, b)$$

其中 $\deg[\cdot]$ 是含重边的度数。关键收益：$\deg[a] + \deg[b]$ 只依赖**两个标量**，而 $\mathit{mult}(a,b)$ 只有**相邻点对**才非零——不相邻的点对占绝大多数，它们的 $\mathit{cnt}$ 就是两个度数之和。于是查询转化为：

$$\text{答案}(k) = \#\{(a,b) : a < b,\ \deg[a] + \deg[b] - \mathit{mult}(a,b) > k\}$$

### 3.3 核心观察二：先按度数和批量数，再对相邻点对修正

![双指针：排序度数后数「deg 和 > k」的点对](images/bw47_q4_two_pointer.svg)

分两步走：

1. **基准计数（忽略 $\mathit{mult}$）**：把全部 $n$ 个点的度数排序得 $sd$，统计满足 $sd_l + sd_r > k$ 的**所有点对**。由于只看两个标量的和，排序后用**双指针**一趟即可：$O(n)$。此时相邻点对可能被"虚高"地计入（$a$、$b$ 之间的重边在度数和里被数了两次）。
2. **容斥修正**：只有**相邻点对**（$\mathit{mult} > 0$）才可能被算错。把重边按点对聚合（哈希表分桶），得到所有相邻点对 $(u, v)$ 及其重边数 $m$。逐个检查：

$$\text{若 } \deg[u] + \deg[v] > k \ \text{且}\ \deg[u] + \deg[v] - m \le k，\ \text{则该点对被多算了，减 } 1$$

不相邻点对 $\mathit{mult} = 0$，度数和与 $\mathit{cnt}$ 相等，基准计数天然正确，无需处理。相邻点对总数不超过边数 $E$，修正每查询 $O(E)$。

### 3.4 示例演算

![修正演算：k=5 时双指针得 7，修正 (2,3) 后得 6](images/bw47_q4_correction_walkthrough.svg)

以示例 2 查询 $k = 5$ 为例：度数排序后为 $[1, 3, 3, 4, 5]$（节点 $4, 2, 3, 1, 5$），双指针数出度数和 $> 5$ 的点对共 **7** 对。再扫 5 个相邻点对：$(1,5)$ 度数和 $9$、$9 - 3 = 6 > 5$ 实际合法不修正；$(2,5)$ 度数和 $8$、$8 - 2 = 6 > 5$ 不修正；$(3,4)$ 度数和 $4 \le 5$ 本就没计入；$(1,3)$ 度数和 $7$、$7 - 1 = 6 > 5$ 不修正；唯独 $(2,3)$ 度数和 $6 > 5$ 但 $6 - 1 = 5 \le 5$——**多算了**，减 1。最终 $7 - 1 = 6$，与官方输出一致。

## 4. 算法细节

1. **度数统计**：`deg[u]++、deg[v]++` 直接累加，重边自然计入（每条边独立计一次度）。
2. **重边聚合（分桶）**：把每条边归一化为 `(min(u,v), max(u,v))` 后放入哈希表计数，得到「相邻点对 → 重边数 $m$」的映射；同时导出全部相邻点对列表。用 `map<pair<int,int>,int>` 或哈希均可（$E \le 10^5$，红黑树也可接受）。
3. **双指针的记账方式**：`sd` 升序。`l = 0, r = n-1`；若 `sd[l] + sd[r] > k`，则 `sd[l..r-1]` 中任何数配 `sd[r]` 都超过 $k$（升序保证），一次性 `cnt += r - l` 后 `r--`；否则 `sd[l]` 连最大的 `sd[r]` 都凑不过，`l++`。
4. **修正的精确条件**：`s = deg[u] + deg[v]`，当且仅当 `s > k && s - m <= k` 时减一。两种"不减"的情形要分清：`s ≤ k`（根本没计入）与 `s - m > k`（减了重边仍然合法）。
5. **计数类型**：$\binom{2 \times 10^4}{2} \approx 2 \times 10^8$，接近但未超 `int` 上界；C++ 建议用 `long long` 累加再转回，Python 无此顾虑。
6. **同一对重边只修正一次**：修正量取决于聚合后的 $m$，**不能**对原始边表逐条修正——若按"每条边各减一次"处理，$m = 3$、$s - 1 > k$ 而 $s - 3 \le k$ 的点对会被漏减或错减多次。
7. **离线无关性**：各查询互相独立（双指针每查询重跑一遍即可），无需按 $k$ 排序；若把查询按 $k$ 排序，双指针也不能复用（指针移动方向取决于 $k$ 的单调性，值不一定单调），老老实实每个查询 $O(n + P)$ 最稳。

## 5. 正确性证明

**引理 1（容斥公式）**：对任意点对 $a < b$，与 $a$ 或 $b$ 相连的边数 $\mathit{cnt}(a,b) = \deg[a] + \deg[b] - \mathit{mult}(a,b)$，其中 $\mathit{mult}(a,b)$ 是 $a$、$b$ 之间重边的条数。

**证明**：按"边的另一端"给与 $a$ 相连的边分类：端点为 $b$ 的恰 $\mathit{mult}(a,b)$ 条，其余 $\deg[a] - \mathit{mult}(a,b)$ 条端点不在 $\{a,b\}$（无自环保证另一端 $\ne a$）。同理与 $b$ 相连的边中端点为 $a$ 的恰 $\mathit{mult}(a,b)$ 条、其余 $\deg[b] - \mathit{mult}(a,b)$ 条。与 $a$ 或 $b$ 相连的边 = {端点为 $a$ 的边} $\cup$ {端点为 $b$ 的边}，两类互斥地拆为：仅连 $a$ 的（$\deg[a] - \mathit{mult}$ 条）、仅连 $b$ 的（$\deg[b] - \mathit{mult}$ 条）、$a$—$b$ 间的（$\mathit{mult}$ 条）。三者相加得 $\deg[a] + \deg[b] - \mathit{mult}(a,b)$。∎

**引理 2（双指针计数正确）**：对升序数组 $sd$ 与阈值 $k$，双指针过程输出 $\#\{(l', r') : l' < r',\ sd[l'] + sd[r'] > k\}$，且每对恰被判定一次。

**证明**：维护不变量：所有"两端都在窗口 $[l, r]$ 外"涉及的点对均已被正确分类恰一次，窗口内部点对尚未分类。初始 $l=0, r=n-1$，窗口即全集，命题空成立。每步：若 $sd[l] + sd[r] > k$，则对每个 $i \in [l, r-1]$ 有 $sd[i] \ge sd[l]$，故 $sd[i] + sd[r] > k$——$r$ 与窗口内所有点组成的 $r - l$ 对全部合法，计入后丢弃 $r$，$r$ 的所有点对均分类完毕；若 $sd[l] + sd[r] \le k$，则对每个 $j \in [l+1, r]$ 有 $sd[j] \le sd[r]$，故 $sd[l] + sd[j] \le k$——$l$ 与窗口内所有点组成的点对全部非法，丢弃 $l$。两种情况均保持不变量，窗口每步严格缩小，终止时 $l = r$ 无剩余点对，全部点对各分类恰一次。∎

**定理（两步算法正确）**：对每个查询 $k$，"双指针基准计数减去修正数"恰为满足 $\mathit{cnt}(a,b) > k$ 的点对数。

**证明**：把点对按是否相邻分类。**不相邻点对**（$\mathit{mult} = 0$）：由引理 1，$\mathit{cnt} = \deg[a] + \deg[b]$，故其被双指针计入当且仅当 $\mathit{cnt} > k$，且不参与修正，贡献精确。**相邻点对**（$\mathit{mult} = m \ge 1$）：被双指针计入当且仅当 $s = \deg[a] + \deg[b] > k$；真实条件为 $s - m > k$。若 $s - m > k$，计入且不修正，正确；若 $s - m \le k$，真实不满足而基准计入了——修正条件 $s > k \wedge s - m \le k$ 恰在此情形成立，减 1 抵消；若 $s \le k$，基准未计入、修正条件也不成立（第一支不满足），保持不计入，正确。综上每对贡献恰为 $[\mathit{cnt}(a,b) > k]$，求和即答案。∎

## 6. 复杂度分析

- **时间**：预处理 $O(E + n \log n)$——度数累加与重边聚合各 $O(E)$，度数排序 $O(n \log n)$。每个查询双指针 $O(n)$、修正扫描 $O(P)$（$P$ 为相邻点对数，$P \le E$）。总计 $O(E + n \log n + Q(n + E))$，代入 $E = 10^5$、$n = 2 \times 10^4$、$Q = 20$ 约 $2.6 \times 10^6$ 次操作。
- **空间**：$O(n + E)$。度数数组 $O(n)$，重边哈希表与相邻点对列表 $O(P) \le O(E)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> countPairs(int n, vector<vector<int>>& edges, vector<int>& queries) {
        vector<int> deg(n + 1, 0);                    // 每个点的度数（含重边）
        map<pair<int,int>, int> mult;                 // 点对 (u,v) 之间的重边数
        for (auto& e : edges) {
            int u = e[0], v = e[1];
            ++deg[u]; ++deg[v];
            if (u > v) swap(u, v);
            ++mult[{u, v}];
        }
        vector<array<int,3>> pairs;                   // 所有相邻点对 (u, v, 重边数)
        for (auto& [pr, m] : mult) pairs.push_back({pr.first, pr.second, m});

        vector<int> sortedDeg(deg.begin() + 1, deg.end());
        sort(sortedDeg.begin(), sortedDeg.end());     // 度数排序，供双指针统计

        vector<int> ans;
        ans.reserve(queries.size());
        for (int k : queries) {
            long long cnt = 0;                        // 1) 先按 deg 和统计
            int l = 0, r = n - 1;
            while (l < r) {
                if (sortedDeg[l] + sortedDeg[r] > k) { cnt += r - l; --r; }
                else ++l;
            }
            for (auto& p : pairs) {                   // 2) 再对相邻点对容斥修正
                int s = deg[p[0]] + deg[p[1]];
                if (s > k && s - p[2] <= k) --cnt;     // 度数和虚高、实际不达标
            }
            ans.push_back((int)cnt);
        }
        return ans;
    }
};
```

### Python

```python
from collections import Counter

class Solution:
    def countPairs(self, n: int, edges: list[list[int]], queries: list[int]) -> list[int]:
        deg = [0] * (n + 1)
        mult = Counter()                          # 点对 -> 重边数（分桶聚合）
        for u, v in edges:
            deg[u] += 1
            deg[v] += 1
            mult[(min(u, v), max(u, v))] += 1
        pairs = [(u, v, m) for (u, v), m in mult.items()]

        sd = sorted(deg[1:])
        ans = []
        for k in queries:
            # 1) 双指针统计 deg 和 > k 的点对数
            cnt, l, r = 0, 0, n - 1
            while l < r:
                if sd[l] + sd[r] > k:
                    cnt += r - l
                    r -= 1
                else:
                    l += 1
            # 2) 相邻点对容斥修正
            for u, v, m in pairs:
                s = deg[u] + deg[v]
                if s > k and s - m <= k:
                    cnt -= 1
            ans.append(cnt)
        return ans
```

> 💡 两份代码均通过官方 2 组示例；另与「每对点对直接扫全部边数 $\mathit{cnt}$」的暴力对拍 **1500 组随机图**（$n \le 12$、$E \le 30$、含重边与孤立点）无一不同；$n = 2 \times 10^4$、$E = 10^5$、$Q = 20$ 满规模实测 C++ 约 160ms、Python 约 200ms。

## 8. 边界情况与易错点

1. **重边归一化**：聚合时必须把 $(u, v)$、$(v, u)$ 视为同一对（取 `min, max`），否则同一条重边被拆进两个桶，$\mathit{mult}$ 就错了。
2. **修正只做一次、且按聚合后的 $m$ 判**：对原始边表逐条修正会在 $m \ge 2$ 时出错——例如 $s = 8$、$m = 3$、$k = 5$：逐条判 "$s - 1 > k$" 不减，漏掉；按 $m$ 判 "$s - 3 = 5 \le k$" 才会正确减 1。
3. **别把不相邻点对也拉去修正**：修正表里只有相邻点对；若对全部 $\binom{n}{2}$ 对逐一算 $\mathit{mult}$，复杂度退回平方级。
4. **双指针边界**：`l < r` 严格小于（$l = r$ 不是点对）；`cnt += r - l` 是窗口内与 $r$ 配对的总数，别误写成 `r - l + 1`（把自己也算进去）。
5. **溢出**：答案上限 $\binom{2 \times 10^4}{2} \approx 2 \times 10^8$，贴近 `int` 上界；C++ 用 `long long` 中转最稳。
6. **$k = 0$ 与孤立点**：两个度数为 0 的点对 $\mathit{cnt} = 0$，对任何 $k \ge 0$ 都不满足（严格大于），双指针天然正确；度数 0 的点参与排序即可，不用剔除。
7. **无自环的保证**：题目保证 $u_i \ne v_i$，引理 1 依赖这一点（自环会让"另一端为 $b$"的分类失效）；无需额外防御。
8. **查询数很小是本题的"留活口"**：若 $Q$ 大到 $10^5$，$O(Q(n+E))$ 也不行，需要离线按 $k$ 排序 + 主席树/前缀统计等更重的结构；本题 $Q \le 20$，两步法是性价比最高的选择。
