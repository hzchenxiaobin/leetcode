# LeetCode 整数的镜像距离 题解

## 1. 题目概述

- **标题 / 题号**：整数的镜像距离（#3783，easy）
- **链接**：https://leetcode.cn/problems/mirror-distance-of-an-integer/
- **来源**：LeetCode 第 481 场周赛 Q1
- **难度**：简单
- **标签**：数学、模拟

**题意**：给定整数 `n`，定义它的**镜像距离**为 $\lvert n - \mathrm{reverse}(n) \rvert$，其中 $\mathrm{reverse}(n)$ 表示将 `n` 的十进制数字反转后得到的整数（前导零自动忽略，如 `reverse(10) = 01 = 1`）。返回 `n` 的镜像距离。

**约束**：

- `1 <= n <= 10^9`

## 2. 示例

**示例 1**

```text
输入：n = 25
输出：27
解释：reverse(25) = 52，答案为 abs(25 - 52) = 27。
```

**示例 2**

```text
输入：n = 10
输出：9
解释：reverse(10) = 01，即 1，答案为 abs(10 - 1) = 9。
```

**示例 3**

```text
输入：n = 7
输出：0
解释：reverse(7) = 7，答案为 abs(7 - 7) = 0。
```

## 3. 解题思路

### 3.1 快速切入：按定义直接模拟

签到题。题面本身就是算法描述：求出 $\mathrm{reverse}(n)$，再做差取绝对值即可，无需任何优化。唯一的考点是**把数字反转写对**，以及处理好**尾随零**——`n` 末尾的 `0` 反转后变成前导零，作为整数会自动消失（`reverse(10) = 1` 而不是 `01`）。

### 3.2 核心观察：算术法反转数字

![镜像距离概念：反转数字再做绝对差](images/mirror_distance_concept.svg)

反转数字的经典写法是逐位剥离：每次取出 `x` 的个位 `x % 10`，拼到 `rev` 的末尾：

```text
rev = rev * 10 + x % 10
x   = x / 10
```

循环 `x` 的位数次后，`rev` 即为 `reverse(n)`。另一种更短的写法是字符串法：`int(str(n)[::-1])`，直接把数字串翻转再转回整数——整数转换天然丢掉前导零，尾随零问题自动解决。

### 3.3 算法流程

```text
rev ← 0, x ← n
while x > 0:
    rev ← rev * 10 + x % 10
    x   ← x / 10
return abs(n - rev)
```

注意用副本 `x` 去消耗位数，**保留原值 `n`** 参与最后的做差。

### 3.4 示例演算

取 `n = 1050`（同时覆盖尾随零），逐步执行反转循环：

| 轮次 | x（循环前） | x % 10 | rev = rev×10 + x%10 | x /= 10 后 |
|------|------------|--------|---------------------|-----------|
| 初始 | 1050 | — | 0 | — |
| 1 | 1050 | 0 | 0×10 + 0 = 0 | 105 |
| 2 | 105 | 5 | 0×10 + 5 = 5 | 10 |
| 3 | 10 | 0 | 5×10 + 0 = 50 | 1 |
| 4 | 1 | 1 | 50×10 + 1 = 501 | 0 |

循环结束后 `rev = 501`（数字串 `"0501"` 的整数值，前导零消失），答案 $\lvert 1050 - 501 \rvert = 549$。

![示例演算：n=1050 的算术反转逐步走查](images/mirror_distance_reversal_loop.svg)

## 4. 算法细节

1. **两种实现任选**：
   - **算术法**：`rev = rev*10 + x%10; x /= 10` 循环，`O(k)`（`k` 为位数），无字符串开销；
   - **字符串法**：`int(str(n)[::-1])`（Python 一行），或 C++ 中 `to_string` + `reverse` + `stoi`。
   两者均天然处理尾随零：整数语境下 `"0501"` 与 `501` 是同一个数。
2. **保留原值**：反转循环会摧毁 `x`，务必先用副本 `x = n`，否则最后无 `n` 可做差。
3. **范围分析**：`n <= 10^9`，故 $\mathrm{reverse}(n) \in [1, 999999999]$（`reverse(10^9) = 1`）。于是 $\lvert n - \mathrm{reverse}(n) \rvert \le 10^9 - 1 = 999999999 < 2^{31} - 1$，**32 位有符号整数不会溢出**，C++ 用 `int` 即可。

## 5. 正确性证明

**引理 1**（循环不变量）：设 `n` 的十进制表示为 $d_{k-1} d_{k-2} \cdots d_1 d_0$（$d_{k-1} \ne 0$）。第 $t$ 轮循环开始时（$0 \le t \le k$），有 $x = \lfloor n / 10^t \rfloor$（即高位串 $d_{k-1} \cdots d_t$ 的整数值），且 $rev$ 等于数字串 $d_0 d_1 \cdots d_{t-1}$ 的整数值（$t = 0$ 时空串，值为 $0$）。

**证明**：对 $t$ 归纳。$t = 0$ 时 $x = n$、$rev = 0$，成立。设第 $t$ 轮成立：此时 $x$ 的个位恰为 $d_t$，即 $x \bmod 10 = d_t$；执行 `rev*10 + x%10` 后，`rev` 的数字串由 $d_0 \cdots d_{t-1}$ 变为 $d_0 \cdots d_{t-1} d_t$（在末尾追加一位）；执行 `x /= 10` 后 $x = \lfloor \lfloor n/10^t \rfloor / 10 \rfloor = \lfloor n / 10^{t+1} \rfloor$。故第 $t+1$ 轮开始时命题成立。∎

**定理**：循环执行恰好 $k$ 轮后终止，且 $rev = \mathrm{reverse}(n)$，从而算法返回 $\lvert n - \mathrm{reverse}(n) \rvert$。

**证明**：由引理 1，第 $k$ 轮开始时 $x = \lfloor n/10^k \rfloor = 0$，循环终止，此时 $rev$ 为数字串 $d_0 d_1 \cdots d_{k-1}$ 的整数值，正是 `n` 的反转。若 `n` 有尾随零（$d_0 = 0$），该串含前导零，但其**整数值**与去掉前导零后的值相同，符合题面 `reverse(10) = 01 = 1` 的定义。最后取 `abs(n - rev)` 即为所求。∎

## 6. 复杂度分析

- **时间复杂度**：$O(\log_{10} n)$。循环次数等于 `n` 的位数 `k`，本题 $k \le 10$，近似常数。字符串法为翻转与解析各 $O(k)$，同为 $O(\log_{10} n)$。
- **空间复杂度**：算术法 $O(1)$；字符串法需 $O(\log_{10} n)$ 存储数字串。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int mirrorDistance(int n) {
        int rev = 0, x = n;
        while (x) {
            rev = rev * 10 + x % 10;
            x /= 10;
        }
        return abs(n - rev);
    }
};
```

### Python

```python
class Solution:
    def mirrorDistance(self, n: int) -> int:
        return abs(n - int(str(n)[::-1]))
```

比赛中最快的写法是上面的字符串一行；若追求无字符串开销，可用算术法：

```python
class Solution:
    def mirrorDistance(self, n: int) -> int:
        rev, x = 0, n
        while x:
            rev = rev * 10 + x % 10
            x //= 10
        return abs(n - rev)
```

## 8. 边界情况与易错点

1. **尾随零**：`reverse(10) = 01 = 1`、`reverse(1050) = 501`。算术法与「字符串翻转后转整数」都天然正确；但若错误地用字符串比较或保留定长补零，会得到 `"01"` 之类的非法结果。
2. **个位数**：`reverse(7) = 7`，答案 `0`；循环恰好执行 1 轮，无需特判。
3. **回文数**：如 `999999999`、`1221`，镜像距离为 `0`，是答案的下界。
4. **最大输入 `n = 10^9`**：约束下唯一的 10 位数输入，`reverse = 1`，答案 `999999999`，已验证 `int` 不溢出（差值上界 $10^9 - 1 < 2^{31} - 1$）。
5. **摧毁原值**：反转循环消耗 `x`，必须用副本迭代，保留 `n` 做差。
6. **符号问题**：`n - rev` 可正可负（如 `25 - 52 = -27`），必须取绝对值后再返回。
