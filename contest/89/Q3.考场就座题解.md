# LeetCode 考场就座 题解

## 1. 题目概述

- **标题 / 题号**：考场就座（#855，medium）
- **链接**：https://leetcode.cn/problems/exam-room/
- **来源**：LeetCode 第 89 场周赛 Q3
- **难度**：中等
- **标签**：设计、有序集合、堆（优先队列）

**题意**：考场有 $n$ 个座位排成一行，编号 $0 \sim n-1$。学生入场时必须坐在**离最近的人最远**的座位上；若有多个座位并列，坐**编号最小**的那个；若考场空着，直接坐 0 号。要求实现一个类 `ExamRoom`：

- `ExamRoom(int n)`：初始化 $n$ 个座位的考场；
- `int seat()`：返回下一个学生会坐的座位编号；
- `void leave(int p)`：坐在 $p$ 的学生离开（保证 $p$ 上有人）。

**约束**：

- $1 \le n \le 10^9$ —— 座位数太大，**不能开长度为 $n$ 的数组**；
- `seat` 与 `leave` 合计最多被调用 $10^4$ 次 —— 允许每次操作 $O(\log q)$ 甚至 $O(q)$，但 $O(n)$ 绝对不行。

## 2. 示例

**示例 1**

```text
输入：
["ExamRoom", "seat", "seat", "seat", "seat", "leave", "seat"]
[[10], [], [], [], [], [4], []]

输出：[null, 0, 9, 4, 2, null, 5]

解释：
ExamRoom examRoom = new ExamRoom(10);
examRoom.seat();     // 空教室 → 0
examRoom.seat();     // 离 0 最远的是 9 → 9
examRoom.seat();     // 空隙 (0,9) 的中点 → 4
examRoom.seat();     // 空隙 (0,4) 与 (4,9) 都为 2，取小编号 → 2
examRoom.leave(4);   // 4 号离开
examRoom.seat();     // 空隙 (2,9) 的中点 → 5
```

**示例 2**

```text
输入：
["ExamRoom", "seat"]
[[1], []]

输出：[null, 0]
解释：只有一个座位，直接坐 0。
```

## 3. 解题思路

### 3.1 暴力思路

按定义模拟：每次 `seat()` 遍历 $0 \sim n-1$ 的每个空座位，计算它到所有已坐座位的最近距离，取最大者。单次 $O(n \cdot m)$，而 $n$ 可达 $10^9$，直接不可行。

退一步：只在**已坐座位的空隙**里找，维护一个有序的已坐集合，每次扫描相邻两人之间的空隙。单次 $O(m) \le O(10^4)$，总 $O(q \cdot m) \approx 10^8$，C++ 勉强能过；但对「找最大空隙」这类问题，标准做法是**用堆把最大空隙直接取到**，把单次代价降到 $O(\log q)$。难点在于 `leave` 会让已经入堆的空隙**失效**。

### 3.2 核心观察：候选座位只有三类

![三类候选座位：左边缘、内部间隙、右边缘](images/wc89_q3_gap_model.svg)

设当前已坐座位按编号排成 $s_1 < s_2 < \dots < s_m$。任何空座位 $x$ 的「到最近的人的距离」只取决于它**左右最近的已坐座位**：若 $s_k < x < s_{k+1}$，则

$$d(x) = \min(x - s_k,\ s_{k+1} - x).$$

于是所有空座位被已坐座位切成三类「空隙」，每类的最优候选可以直接算出来：

| 空隙 | 候选座位 | 距离 |
|------|----------|------|
| 左边缘 $[0, s_1)$ | $0$ | $s_1$ |
| 内部 $(s_k, s_{k+1})$ | $s_k + \lfloor (s_{k+1} - s_k)/2 \rfloor$ | $\lfloor (s_{k+1}-s_k)/2 \rfloor$ |
| 右边缘 $(s_m, n-1]$ | $n-1$ | $n-1-s_m$ |

内部空隙的候选为什么是向下取整？在 $(l, r)$ 内 $d(x) = \min(x-l,\ r-x)$ 是一个**先增后减**的折线，峰值在对称轴 $x = (l+r)/2$。当 $r-l$ 为奇数时左右各有一个等距最优座位，题面要求**取编号较小**的那个，所以取 $l + \lfloor (r-l)/2 \rfloor$。

**结论**：`seat()` 只需在「左边缘候选、堆顶内部候选、右边缘候选」三者中按 `(距离降序, 编号升序)` 选最优。

### 3.3 算法流程：最大堆 + 双向链表 + 懒删除

![懒删除：堆里只放内部间隙，出堆时用双向链表验真](images/wc89_q3_heap_lazy.svg)

数据结构：

1. **双向链表**（`nxt` / `prv` 两个哈希表）：键是已坐座位号，值是其左右邻居，用于 $O(1)$ 判断两个座位是否相邻；
2. **大顶堆**：存放内部空隙记录 $(-\text{dist},\ \text{cand},\ l,\ r)$，按 `(距离降序, 候选座位升序)` 排序；
3. `head` / `tail`：最小、最大的已坐座位号，用于算左右边缘候选。

`seat()`：

```text
1. 若教室为空：坐 0 号，返回 0
2. best = -1, bestDist = -1
3. 若 head > 0：best = 0, bestDist = head
4. 若 n-1 > tail 且 n-1-tail > bestDist：best = n-1, bestDist = n-1-tail
5. 循环查看堆顶 (l, r)：若 nxt[l] != r，说明该空隙已失效 → 弹出、继续
   否则若堆顶距离更大（或等距且候选编号更小）→ 弹出并坐该候选
6. 把选中的座位插入链表，并把新产生的两条内部空隙入堆
```

`leave(p)`：

```text
1. 取 p 的左邻 l、右邻 r，在链表中把 l 与 r 直接相连
2. 删除 p 的两个表项
3. 若 l、r 都存在且 r - l >= 2：把合并后的空隙 (l, r) 入堆
```

**懒删除的正确性**：空隙 (l, r) 只有两种失效方式——有人坐进了它内部（此时 `nxt[l]` 变成那个新座位），或它两端之一离开了（此时 `nxt[l]` 不再是 r）。两种情况下 `nxt[l] != r`，出堆时一验便知。而**每一个新产生的空隙都会被立即入堆**，所以「当前真实存在的最大空隙」一定在堆中且验证通过。

### 3.4 示例演算

![示例演算：n = 10 的六步操作](images/wc89_q3_walkthrough.svg)

$n = 10$，依次执行 `seat, seat, seat, seat, leave(4), seat`：

| 操作 | 已坐集合 | 候选与距离 | 决策 | 返回 |
|------|----------|-----------|------|------|
| ① seat | $\varnothing$ | 教室空 | 直接坐 0 | 0 |
| ② seat | {0} | 左边缘无 / 右边缘 9 | 9 最大 | 9 |
| ③ seat | {0, 9} | 内部 (0,9)：距离 4 | 4 最大 | 4 |
| ④ seat | {0, 4, 9} | 内部 (0,4)=2、(4,9)=2 | 并列取小编号 2 | 2 |
| ⑤ leave(4) | {0, 2, 9} | 合并出空隙 (2, 9) | — | — |
| ⑥ seat | {0, 2, 9} | 内部 (2,9)：距离 3 | 3 最大 | 5 |

与示例输出 `[null, 0, 9, 4, 2, null, 5]` 完全一致。

## 4. 算法细节

1. **只有 ``r - l >= 2`` 的空隙才入堆**：若 $r - l = 1$，两座位之间没有空位，候选不存在，入堆反而会产生非法候选。
2. **候选公式 `l + (r - l) // 2`**：向下取整同时解决了「奇数长度并列取小编号」与「偶数长度唯一中点」两种情况，不需要额外特判。
3. **`head` / `tail` 的维护**：插入时若 `left == -1` 说明插到了最左端，更新 `head`；若 `right == -1` 更新 `tail`。`leave` 时对称处理。
4. **堆的比较键**：C++ 自定义 `operator<` 让 `priority_queue` 的堆顶是「距离最大、候选最小」；Python 直接用元组 `(-dist, cand, l, r)`，`heapq` 是最小堆，负号把「最大距离」变成「最小键」，第二项 `cand` 自动完成并列取小。
5. **边缘候选不进堆**：左边缘的候选恒为 0、右边缘恒为 `n-1`，只有两个，每次 $O(1)$ 现算即可，没必要维护。
6. **`leave` 不需要删除堆里的旧记录**：只做惰性剔除，保证每次操作 $O(1)$ 次入堆、$O(\log q)$ 次弹出（均摊）。
7. **不要开 `vector<bool>`**：$n \le 10^9$，只能存「已坐的人」，这也是本题必须用有序结构的原因。

## 5. 正确性证明

设已坐座位集合为 $S$，空座位 $x$ 的最近距离 $d(x) = \min_{y \in S} |x - y|$。

**引理 1（距离局部化）**：设 $x \notin S$，$l < x < r$ 是 $x$ 左右最近的已坐座位（不存在则视为边界 $l = -1$ 或 $r = n$），则 $d(x) = \min(x - l,\ r - x)$。

**证明**：对任意 $y \in S$，若 $y \le l$ 则 $|x - y| = x - y \ge x - l$；若 $y \ge r$ 则 $|x-y| = y - x \ge r - x$。故最小值由 $l$、$r$ 之一取到，即 $\min(x-l, r-x)$。∎

**引理 2（空隙内最优候选）**：在空隙 $(l, r)$（$r - l \ge 2$）内，使 $d(x)$ 最大的座位是 $x^{*} = l + \lfloor (r-l)/2 \rfloor$，最大值为 $\lfloor (r-l)/2 \rfloor$，且它是所有取到最大值的座位中**编号最小**的。

**证明**：由引理 1，$d(x) = \min(x-l,\, r-x)$ 在区间上随 $x$ 增大而先在 $x \le (l+r)/2$ 时取 $x-l$（递增），后在 $x \ge (l+r)/2$ 时取 $r-x$（递减）。因此最大值出现在离 $(l+r)/2$ 最近的两个整数上，即 $\lfloor (l+r)/2 \rfloor$ 与 $\lceil (l+r)/2 \rceil$，二者取 $d$ 相同且为 $\lfloor (r-l)/2 \rfloor$（$r-l$ 为奇数时两者并列，为偶数时合一）。并列时题面要求编号最小，故取 $l + \lfloor (r-l)/2 \rfloor$。∎

**引理 3（堆中必有真间隙）**：任一时刻，若存在内部空隙 $(l, r)$ 且 $r - l \ge 2$，则堆中存在一条记录 $(l, r)$，且出堆时验证 `nxt[l] == r` 会通过。

**证明**：对空隙的产生做归纳。空隙只会在两种时刻产生：`place(c, l, r)` 把一个空隙劈成 $(l, c)$ 与 $(c, r)$；`leave(p)` 把 $(l, p)$、$(p, r)$ 合并成 $(l, r)$。两处代码都对**每个新空隙立即调用 pushGap**，且此后只要该空隙未被破坏，链表中 $l$ 的后继始终是 $r$（后续插入只会改变被插入的那个空隙的后继）。故该记录必然在堆中，且验真通过。∎

**引理 4（失效记录无害）**：堆顶若验证 `nxt[l] != r`，则它对应的候选座位一定不是当前最优候选。

**证明**：`nxt[l] != r` 说明 $(l,r)$ 已不再是相邻的已坐座位对：要么其间坐进了新的人 $c$，此时原候选 $l + \lfloor (r-l)/2 \rfloor$ 已被占用（不可能再选）；要么 $l$ 或 $r$ 之一已离开，此时该空隙被更大或不同的空隙取代，新空隙早已入堆（引理 3）。无论哪种，丢弃该记录都不影响最优候选的存在性。∎

**定理**：`seat()` 返回的座位号等于题面定义的最优座位（距离最大的座位中编号最小者）。

**证明**：所有空座位按引理 1 被划分为「左边缘、若干内部空隙、右边缘」，其中内部空隙可能不连续（中间夹着已坐座位）。由引理 2，每类空隙内的最优候选与距离可 $O(1)$ 算出，因此全局最优 = 三类候选中 `(距离, -编号)` 字典序最大者。

算法对左、右边缘直接计算候选，对内部空隙通过「堆顶 + 验真」取出**当前存在的最大空隙**的候选（引理 3 保证最优空隙在堆中且验真通过，引理 4 保证被丢弃的记录不影响最优），最后按 `(距离优先、编号其次)` 的比较规则在三者中取最优。

比较规则的实现：先取边缘候选作为初值（0 号候选最小编号，故等距时它自动胜出）；内部候选仅在「距离更大」或「距离相等且编号更小」时覆盖。这正是题面要求的排序，故返回值即最优座位。∎

## 6. 复杂度分析

设操作总次数为 $q$（$q \le 10^4$），已坐人数为 $m \le q$。

- **时间**：`seat()` 与 `leave()` 均摊 $O(\log q)$。每次操作最多产生 2 条新堆记录（$O(\log q)$ 入堆），而每条记录至多被弹出一次，因此所有弹出累计 $O(q)$ 次、每次 $O(\log q)$；双向链表的插入 / 删除是 $O(1)$ 的哈希操作。
- **空间**：$O(q)$。链表只存已坐的 $m$ 个座位，堆中记录数不超过 $2q$，与 $n$（可达 $10^9$）无关。

## 7. 参考代码

### C++

```cpp
class ExamRoom {
public:
    ExamRoom(int n) : n(n), head(-1), tail(-1) {}

    int seat() {
        if (head == -1) {
            return place(0, -1, -1);
        }

        int best = -1, bestDist = -1;
        if (head > 0) {
            best = 0;
            bestDist = head;
        }
        if (n - 1 > tail && n - 1 - tail > bestDist) {
            best = n - 1;
            bestDist = n - 1 - tail;
        }

        while (!heap.empty()) {
            Gap g = heap.top();
            auto it = nxt.find(g.left);
            if (it == nxt.end() || it->second != g.right) {
                heap.pop();
                continue;
            }
            int d = -g.negDist;
            if (d > bestDist || (d == bestDist && (best == -1 || g.cand < best))) {
                heap.pop();
                return place(g.cand, g.left, g.right);
            }
            break;
        }

        if (best == 0) {
            return place(0, -1, head);
        }
        return place(n - 1, tail, -1);
    }

    void leave(int p) {
        int left = prv[p], right = nxt[p];
        if (left == -1) {
            head = right;
        } else {
            nxt[left] = right;
        }
        if (right == -1) {
            tail = left;
        } else {
            prv[right] = left;
        }
        prv.erase(p);
        nxt.erase(p);
        if (left != -1 && right != -1 && right - left >= 2) {
            pushGap(left, right);
        }
    }

private:
    struct Gap {
        int negDist, cand, left, right;
        bool operator<(const Gap& o) const {
            if (negDist != o.negDist) return negDist > o.negDist;
            return cand > o.cand;
        }
    };

    void pushGap(int left, int right) {
        if (right - left < 2) return;
        int d = (right - left) / 2;
        heap.push({-d, left + d, left, right});
    }

    int place(int c, int left, int right) {
        prv[c] = left;
        nxt[c] = right;
        if (left == -1) {
            head = c;
        } else {
            nxt[left] = c;
        }
        if (right == -1) {
            tail = c;
        } else {
            prv[right] = c;
        }
        if (left != -1) pushGap(left, c);
        if (right != -1) pushGap(c, right);
        return c;
    }

    int n, head, tail;
    unordered_map<int, int> prv, nxt;
    priority_queue<Gap> heap;
};
```

### Python

```python
import heapq


class ExamRoom:
    def __init__(self, n: int):
        self.n = n
        self.head = None              # 最小已坐座位
        self.tail = None              # 最大已坐座位
        self.nxt = {}                 # 已坐座位上的有序双向链表
        self.prv = {}
        self.heap = []                # (-可留空距, 候选座位, 左, 右)，懒删除

    def seat(self) -> int:
        n = self.n
        if self.head is None:                       # 教室空着：坐 0 号
            return self._place(0, None, None)

        best, best_dist = -1, -1
        if self.head > 0:                           # 最左空段：坐 0 号
            best, best_dist = 0, self.head
        if n - 1 > self.tail and n - 1 - self.tail > best_dist:
            best, best_dist = n - 1, n - 1 - self.tail

        while self.heap:                            # 取出最大的真实间隙
            nd, cand, left, right = self.heap[0]
            if self.nxt.get(left) != right:         # 过期候选，丢弃
                heapq.heappop(self.heap)
                continue
            if -nd > best_dist or (-nd == best_dist and (best == -1 or cand < best)):
                heapq.heappop(self.heap)
                return self._place(cand, left, right)
            break

        if best == 0:
            return self._place(0, None, self.head)
        return self._place(n - 1, self.tail, None)

    def leave(self, p: int) -> None:
        left, right = self.prv[p], self.nxt[p]
        if left is None:
            self.head = right
        else:
            self.nxt[left] = right
        if right is None:
            self.tail = left
        else:
            self.prv[right] = left
        del self.prv[p], self.nxt[p]
        if left is not None and right is not None and right - left >= 2:
            heapq.heappush(self.heap, self._gap(left, right))

    def _place(self, c: int, left, right) -> int:
        self.prv[c] = left
        self.nxt[c] = right
        if left is None:
            self.head = c
        else:
            self.nxt[left] = c
        if right is None:
            self.tail = c
        else:
            self.prv[right] = c
        if left is not None and c - left >= 2:
            heapq.heappush(self.heap, self._gap(left, c))
        if right is not None and right - c >= 2:
            heapq.heappush(self.heap, self._gap(c, right))
        return c

    @staticmethod
    def _gap(left: int, right: int):
        return (-((right - left) // 2), left + (right - left) // 2, left, right)
```

## 8. 边界情况与易错点

1. **空教室必须坐 0**：此时「离最近的人最远」无定义，题面单独规定坐 0；漏掉这个特判会访问空链表的 `head`。
2. **`n = 1`**：`seat()` 第一次返回 0，之后教室满员，题目保证不会继续 `seat`。
3. **左边缘候选的前置条件**：只有 `head > 0` 时 0 号才空着；`head == 0` 时再选 0 就重复就座了。
4. **右边缘同理**：`tail == n - 1` 时 $n-1$ 已有人。
5. **等距并列取小编号**：这是最容易 WA 的点。实现上靠「先取边缘 0 号、内部候选只在严格更优或等距更小编号时覆盖」来保证；若改成 `>=` 比较，就会错误地取到较大的编号。
6. **奇数长度空隙的取整**：$(0, 9)$ 的距离是 $\lfloor 9/2 \rfloor = 4$，候选是 $0 + 4 = 4$；写成 `(l + r + 1) / 2` 会取到 5，与「编号最小」矛盾。
7. **懒删除必须验真**：`nxt[l] == r` 是唯一判据；只比较距离会把已被占用的座位再返回一次。
8. **`leave` 的边界**：离开的人是最左端时 `left == -1`，此时没有左边缘候选更新问题，但必须正确更新 `head`，否则左边缘距离会算错。
9. **不要用数组表示座位**：$n \le 10^9$，开 `vector<bool>` 会直接爆内存；本题的一切操作都必须只依赖「已坐的人」。
10. **堆的记录可以重复**：同一空隙可能因为多次 `leave` 被多次入堆，重复记录的验真都会通过，取其中任意一条效果相同，不影响正确性。

**延伸思考**：如果要求「同时支持查询当前最大距离是多少」，本题的堆顶（验真后）直接给出答案，无需额外结构。如果 $n$ 很小而调用次数极大（$q \gg n$），可以反过来用 $O(\log n)$ 的线段树维护每个座位的 $d(x)$，`seat` 时线段树二分找最大值。若题目放宽成「离最近的人至少 $k$ 米」，则候选判断只需把距离与 $k$ 比较，堆结构依然适用。
