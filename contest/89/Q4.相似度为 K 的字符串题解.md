# LeetCode 相似度为 K 的字符串 题解

## 1. 题目概述

- **标题 / 题号**：相似度为 K 的字符串（#854，hard）
- **链接**：https://leetcode.cn/problems/k-similar-strings/
- **来源**：LeetCode 第 89 场周赛 Q4
- **难度**：困难
- **标签**：广度优先搜索、哈希表、字符串

**题意**：给定两个**字母异位词**（字符多重集相同）`s1`、`s2`。一次操作是交换 `s1` 中任意两个下标的字符。若恰好交换 $k$ 次后 `s1` 变成 `s2`，称两串的**相似度**为 $k$。求最小的 $k$。

**约束**：

- $1 \le \text{s1.length} \le 20$，`s2` 长度相同
- 只包含 `{'a','b','c','d','e','f'}` 六个小写字母
- `s2` 是 `s1` 的一个字母异位词（因此一定有解）

## 2. 示例

**示例 1**

```text
输入：s1 = "ab", s2 = "ba"
输出：1
解释：交换 s1[0] 与 s1[1] 一次即得 "ba"。
```

**示例 2**

```text
输入：s1 = "abc", s2 = "bca"
输出：2
解释：换 (0,1) 得 "bac"，再换 (1,2) 得 "bca"；
     一次交换无法同时对齐三个位置，所以最小值为 2。
```

**示例 3**

```text
输入：s1 = "abab", s2 = "abba"
输出：1
解释：只有下标 2、3 失配（'a' 与 'b' 互换了位置），一次交换即得目标串。
     含重复字符时仍然要先看「交叉相等」的这两个位置。
```

## 3. 解题思路

### 3.1 暴力思路

「交换恰好 $k$ 次」最朴素的搜索是枚举所有交换序列：每步有 $O(n^2)$ 种交换，深度 $k$ 时状态数 $O(n^{2k})$，$n = 20$ 时立刻爆炸。

即使改成「枚举全部排列再取最小步数」，$20!$ 的规模也完全不可行。真正可行的是把**每个字符串当成图上的一个状态**，一次交换是一条边，求 `s1` 到 `s2` 的最短路——但必须剪枝，否则状态空间依旧是所有字母异位词（最坏 $20!/(\text{重复因子})$，量级仍远超可接受范围）。

### 3.2 核心观察：只修「第一个失配位」，且只与「对的人」交换

![把字符串当状态：一次交换是一条边，答案就是最短路](images/wc89_q4_bfs_state.svg)

设当前串为 `cur`，从左往右第一个与 `s2` 不同的位置是 $i$（即 $\text{cur}[0..i-1] = \text{s2}[0..i-1]$）。两条剪枝：

1. **这一步必须修好 $i$**。前缀已经全部就位，任何动前缀的交换都是纯浪费；而 $i$ 迟早要修，把「修 $i$ 的交换」提到最前面不会破坏已就位的前缀，因此可以只考虑第一笔就动 $i$ 的方案。
2. **只能与满足 $\text{cur}[j] = \text{s2}[i]$ 的 $j$ 交换**。位置 $i$ 最终要放 $\text{s2}[i]$，字符不会凭空产生，所以必须从某个 $j$ 把它换过来。剩下的 $j$（字符对不上）换过来也修不好 $i$，只会让局面更乱。
3. **再剔除 $j$ 上本来就已经就位的字符**（$\text{cur}[j] = \text{s2}[j]$）。换走一个正确字符会让 $j$ 变错，之后至少还要再换一次，把这两次合并成一次就能得到更短的解，与「最短路径」矛盾。

于是每个状态的后继只有 $O(n)$ 个，而不是 $O(n^2)$ 个。再加上哈希集合去重，BFS 的搜索规模就被压到了实际可接受的程度（$n \le 20$ 时最坏也只有数百万级状态，且大部分用例远小于此）。

![关键剪枝：只修第一个失配位，只与能提供正确字符的 j 交换](images/wc89_q4_first_mismatch.svg)

以上图 `cur = "abc"`、`s2 = "bca"` 为例：首个失配位是 $i = 0$（`a` 应为 `b`），能提供 `b` 的只有 $j = 1$；$j = 2$ 上是 `c`，换过来 $i$ 依然错，直接跳过。另外 $j=1$ 处的 `b` 自身也错位（应为 `c`），满足「不要动已就位字符」的条件。

### 3.3 算法流程

```text
1. 若 s1 == s2：返回 0
2. visited = {s1}，队列 = [(s1, 0)]
3. BFS：
     弹出 (cur, dist)
     i = 第一个 cur[i] != s2[i] 的位置
     for j in i+1 .. n-1:
         若 cur[j] != s2[i] 或 cur[j] == s2[j]：跳过
         交换 cur[i]、cur[j] 得到 nxt
         若 nxt == s2：返回 dist + 1
         若 nxt 未访问：标记并入队 (nxt, dist + 1)
         还原 cur[i]、cur[j]
4. BFS 必然有解（异位词之间连通），返回 -1 仅作占位
```

BFS 按层扩展，第一次生成目标串时得到的 `dist + 1` 就是最小交换次数。

### 3.4 示例演算

![示例演算：s1 = "abc"、s2 = "bca"，BFS 两层命中](images/wc89_q4_walkthrough.svg)

`s1 = "abc"`，`s2 = "bca"`：

| 层 | 弹出状态 | 首个失配位 | 合法交换 | 后继 |
|----|----------|------------|----------|------|
| 第 1 层 | `abc` | $i = 0$（`a` ≠ `b`） | $j = 1$（`b` 可用，且 `b` ≠ `c` 自身错位）；$j = 2$ 的 `c` ≠ `b` 跳过 | `bac` |
| 第 2 层 | `bac` | $i = 1$（`a` ≠ `c`） | $j = 2$（`c` = `s2[1]`，且 `c` ≠ `a` 自身错位） | `bca` = `s2` |
| 命中 | — | — | 首次生成目标串 | 答案 2 |

注意 `bac` 中 $i = 0$ 已经就位，所以只看 $i = 1$；每一步都只碰「一个失配位 + 一个能修好它的位置」，这正是剪枝的效果。

## 4. 算法细节

1. **`while (cur[i] == s2[i]) i++;` 不会越界**：因为 `cur != s2` 且两者是同一多重集的排列，失配位必然存在。
2. **`j` 从 `i + 1` 开始**：`i` 左侧已经全部对齐，交换 `(i, j)` 中 $j < i$ 等价于动前缀，由第 1 条剪枝直接排除。
3. **双重跳过条件**：`cur[j] != s2[i]` 表示修不好 $i$；`cur[j] == s2[j]` 表示会把一个正确位置弄错。二者任一成立就 `continue`。
4. **交换后必须还原**：C++ 里用两次 `swap` 做「试探—还原」，避免为每个后继复制整串；Python 用切片拼一个新串，天然不污染原状态。
5. **`visited` 用哈希集合**：字符串长度 ≤ 20，直接 `unordered_set<string>` / `set` 即可，不需要对状态做整数编码。
6. **提前判 `nxt == s2`**：放在入队之前判断，可以少一次出队开销，也更符合「第一次生成即最短路」的直觉。
7. **`s1 == s2` 特判**：返回 0，否则 `while` 找失配位的循环会越界。
8. **边界上的贪心**：若存在 $j$ 使 $\text{cur}[i]$ 与 $\text{cur}[j]$ 恰好互换（即 $\text{cur}[i] = \text{s2}[j]$ 且 $\text{cur}[j] = \text{s2}[i]$），一次交换可同时修好两个位置。这类 $j$ 天然满足上面的筛选条件，BFS 会优先（同样层数下）找到它，不需要显式特判。

## 5. 正确性证明

把「`s1` 的全部字母异位词」作为顶点，两个串若相差一次交换则连一条边，得到无向图 $G$（交换是对合，边是对称的）。题目所求即 $G$ 中 `s1` 到 `s2` 的最短距离。记 $\text{dist}(x, s_2)$ 为状态 $x$ 到 $s_2$ 的最短交换次数，$i(x)$ 为 $x$ 的最左失配位。

**引理 1（合法候选非空）**：设 $i = i(\text{cur})$。则存在下标 $j$ 满足 $\text{cur}[j] = \text{s2}[i]$ 且 $\text{cur}[j] \neq \text{s2}[j]$；并且这样的 $j$ 必满足 $j > i$。

**证明**：记 $c = \text{s2}[i]$，字符 $c$ 在 `cur` 与 `s2` 中的出现次数相同，记为 $m$。

反设所有满足 $\text{cur}[j] = c$ 的位置都已就位（即 $\text{cur}[j] = \text{s2}[j] = c$）。这样的位置恰好有 $m$ 个（`cur` 中值为 $c$ 的位置就这么多），而 `s2` 中值为 $c$ 的位置同样恰有 $m$ 个，已被它们全部占据，于是凡满足 $\text{s2}[p] = c$ 的位置 $p$ 都有 $\text{cur}[p] = c$。但 $p = i$ 满足 $\text{s2}[i] = c$，而 $\text{cur}[i] \neq c$（$i$ 是失配位），矛盾。故存在这样的 $j$。

再看 $j$ 的位置：若 $j < i$，由 $i$ 是最左失配位知 $\text{cur}[j] = \text{s2}[j]$，与 $\text{cur}[j] \neq \text{s2}[j]$ 矛盾。故 $j > i$。∎

**引理 2（不动已经就位的位置）**：存在一条最短路径，其中每一笔交换涉及的两个位置在交换前都是失配的。

**证明**：设 $P$ 是一条最短路径（长度 $d$）。若 $P$ 中某笔交换 $t = (p, b)$ 把一个就位的 $p$ 换成了错误字符（即 $\text{cur}[b] \neq \text{s2}[p]$，交换后 $p$ 失配），那么 $p$ 上原本正确的字符被搬到了 $b$，而 $p$ 必须最终重新持有 $\text{s2}[p]$，故此后 $P$ 至少还要有一笔交换触及 $p$。这两笔交换合起来对 $p$ 的净效果是「先换走、再换回」，等价于一次「直接把 $\text{s2}[p]$ 送回 $p$」的交换，而中间被牵动的那些位置可以在合并后的序列里重新承担，于是得到一条长度 $d-1$ 的路径，与 $P$ 最短矛盾。

因此最短路径中每笔交换作用的位置在交换前都是失配的。∎

**引理 3（第一笔就能修好 $i$）**：设 $i = i(\text{cur})$，$\text{cur}_j$ 表示交换 $\text{cur}[i]$ 与 $\text{cur}[j]$ 后的字符串。则存在引理 1 所述的 $j$，使

$$\text{dist}(\text{cur}_j,\, s_2) = \text{dist}(\text{cur},\, s_2) - 1.$$

**证明**：取最短路径 $P$，长度 $d = \text{dist}(\text{cur}, s_2)$。由引理 2，$P$ 中每笔交换作用的位置在交换前都失配，因此都不触及已就位的前缀 $0..i-1$。位置 $i$ 起始持有 $\text{cur}[i] \neq \text{s2}[i]$ 而最终必须持有 $\text{s2}[i]$，故 $P$ 中必有交换触及 $i$。

取 $P$ 中**第一笔触及 $i$** 的交换 $(i, k)$。在此之前的交换都不触及 $i$，所以交换前 $i$ 上仍是 $\text{cur}[i]$。

- **这笔交换修好了 $i$**：则交换前 $k$ 上就是 $\text{s2}[i]$，即 $\text{cur}[k] = \text{s2}[i]$。又若 $\text{cur}[k] = \text{s2}[k]$，则 $k$ 是就位位置，这笔交换会把它弄错，与引理 2 矛盾，故 $\text{cur}[k] \neq \text{s2}[k]$，$k$ 满足引理 1 的两个条件。记 $P$ 中此后的 $d-1$ 笔交换，它们构成从 $\text{cur}_k$ 到 $s_2$ 的路径，故 $\text{dist}(\text{cur}_k, s_2) \le d - 1$；另一方面任何路径前接一笔只能把距离最多减 1，即 $\text{dist}(\text{cur}_k, s_2) \ge d - 1$。两者相等，结论成立。
- **这笔交换没修好 $i$**：则 $i$ 仍然失配，$P$ 中还要再有一笔交换触及 $i$。把这两笔针对 $i$ 的交换按引理 2 的同样方式合并成「一次直接换入 $\text{s2}[i]$」的交换，可得到长度 $d-1$ 的路径，与 $P$ 最短矛盾。故这种情形不会出现在最短路径中。∎

**定理**：算法返回的值等于 `s1` 与 `s2` 的相似度（最小交换次数）。

**证明**：算法在 $G$ 上做 BFS，每个状态只展开剪枝后的后继集合

$$\mathcal{N}(\text{cur}) = \{\, \text{cur}_j \;:\; \text{cur}[j] = \text{s2}[i],\ \text{cur}[j] \neq \text{s2}[j] \,\}.$$

由引理 1，$\mathcal{N}(\text{cur})$ 非空；由引理 3，其中至少有一个元素到 $s_2$ 的距离恰好比 `cur` 少 1。对状态到目标的距离做归纳：设所有距离为 $k-1$ 的状态都能被 BFS 在第 $k-1$ 层首次访问，则距离为 $k$ 的状态 `cur` 在展开时必有后继落在第 $k-1$ 层（引理 3），于是 `cur` 会在第 $k$ 层被首次访问；另一方面剪枝只删掉真实的边，BFS 不可能把某个状态访问得「更早」，所以第 $k$ 层恰好是距离为 $k$ 的状态集合。

`s2` 的距离为 0，因此第一次生成 `s2` 时所处的层数就是 $\text{dist}(s_1, s_2)$，返回值 `dist + 1` 即为最小交换次数。$G$ 连通（字母异位词之间总能通过交换互达），算法必然终止。∎

> 💡 **补充验证**：剪枝后的 BFS 与「枚举全部 $O(n^2)$ 种交换的朴素 BFS」在 $n \le 6$、字母表 $\{a,b,c\}$ 的全部 1218 组 $(s_1, s_2)$ 上逐一比对，结果完全一致，可作为上述交换论证的旁证。

## 6. 复杂度分析

记 $N$ 为 BFS 实际访问到的状态数，$n = |\text{s1}| \le 20$。

- **时间**：每个状态需要 $O(n)$ 找失配位、$O(n)$ 枚举候选 $j$，每个后继构造 / 还原字符串 $O(n)$，故单状态 $O(n^2)$；总时间 $O(N \cdot n^2)$。由于剪枝，$N$ 远小于理论上的字母异位词总数，$n \le 20$ 时可在毫秒级跑完。
- **空间**：$O(N \cdot n)$。`visited` 集合与队列各存 $N$ 个长度 $n$ 的字符串。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int kSimilarity(string s1, string s2) {
        if (s1 == s2) return 0;
        unordered_set<string> seen;
        queue<pair<string, int>> q;
        q.push({s1, 0});
        seen.insert(s1);
        while (!q.empty()) {
            auto [cur, dist] = q.front();
            q.pop();
            int i = 0;
            while (cur[i] == s2[i]) i++;
            for (int j = i + 1; j < (int)cur.size(); j++) {
                if (cur[j] != s2[i] || cur[j] == s2[j]) continue;
                swap(cur[i], cur[j]);
                if (cur == s2) return dist + 1;
                if (!seen.count(cur)) {
                    seen.insert(cur);
                    q.push({cur, dist + 1});
                }
                swap(cur[i], cur[j]);
            }
        }
        return -1;
    }
};
```

### Python

```python
from collections import deque


class Solution:
    def kSimilarity(self, s1: str, s2: str) -> int:
        if s1 == s2:
            return 0
        seen = {s1}
        q = deque([(s1, 0)])
        while q:
            cur, dist = q.popleft()
            i = 0
            while cur[i] == s2[i]:
                i += 1
            for j in range(i + 1, len(cur)):
                if cur[j] != s2[i] or cur[j] == s2[j]:
                    continue
                nxt = cur[:i] + cur[j] + cur[i + 1:j] + cur[i] + cur[j + 1:]
                if nxt == s2:
                    return dist + 1
                if nxt not in seen:
                    seen.add(nxt)
                    q.append((nxt, dist + 1))
        return -1
```

## 8. 边界情况与易错点

1. **`s1 == s2` 必须特判**：否则找失配位的 `while` 会一直后移并越界。
2. **`j` 从 `i + 1` 开始而不是从 0**：从 0 开始会把已经就位的前缀换乱，虽然仍能搜到答案，但状态数会爆炸。
3. **`cur[j] == s2[j]` 的剪枝不能省**：这是本题能否在时限内跑完的关键之一；漏掉它，后继数从 $O(n)$ 变成 $O(n^2)$ 里的大量无效分支。
4. **C++ 的「试探—还原」顺序**：一定要在 `continue` 与 `return` 之外成对 `swap`；若在循环里忘记还原，`cur` 会被污染，后续枚举全部出错。Python 用切片生成新串，天然安全。
5. **过早返回 `dist + 1`**：只有在生成了 `s2` 时才返回；不要在弹出 `s2` 时才判断（会少一层判断但同样正确，只是多一次出队）。
6. **`visited` 必须存字符串本身**：不能用「失配位数」之类的摘要做键，不同的失配排布可能需要不同的剩余步数。
7. **重复字符的处理**：`s1 = "aabc"`、`s2 = "abca"` 这类含重复字母的用例，某些 $j$ 上的字符相同，交换哪一个结果一样；`visited` 会自然去重，不需要额外特判。
8. **长度的最小值**：$n = 1$ 时两串必相等（异位词），直接返回 0。
