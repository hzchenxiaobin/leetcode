# LeetCode 最大升序子数组和 题解

## 1. 题目概述

- **标题 / 题号**：最大升序子数组和（#1800，easy）
- **链接**：https://leetcode.cn/problems/maximum-ascending-subarray-sum/
- **来源**：LeetCode 第 233 场周赛 Q1
- **难度**：简单
- **标签**：数组、一次遍历、贪心

**题意**：给定一个**正整数**数组 `nums`，返回其中一个**严格递增连续子数组**的最大可能元素和。子数组是数组中的连续数字序列，长度为 1 的子数组也算升序。

**约束**：

- $1 \le \text{nums.length} \le 100$
- $1 \le \text{nums}[i] \le 100$

> 💡 **签到题的关键词**：「正整数」+「连续」+「严格递增」。正整数意味着段越长和越大（续接永远有利）；连续递增意味着能否续接只取决于**相邻一格**的比较。两个条件合起来，把问题退化为一趟扫描的「段内累加、断点重启」，从读题到提交不应超过 5 分钟。

输出：65

```

```

## 3. 解题思路

### 3.1 暴力思路：枚举所有子数组

枚举所有连续子数组 $[l, r]$，检查其内部是否严格递增，满足则求和并更新最大值：

```text
ans = 0
for l in 0 .. n-1:
    for r in l .. n-1:
        if [l..r] 严格递增:
            ans = max(ans, sum(nums[l..r]))
return ans
```

时间 $O(n^3)$，$n \le 100$ 时约 $10^6$ 次操作也能过。但对同一段递增区间**反复检查、反复求和**是明显浪费——递增本质是相邻两两的局部信息，一处断点就决定了所有跨越它的子数组全部非法。

### 3.2 核心观察：极大升序段切分，段内累加、断点重启

![核心观察：下降断点把数组切分为若干极大升序段](images/max_asc_sum_segment_split.svg)

两个关键洞察：

1. **正整数 → 最优解必是极大升序段**。所有 $\text{nums}[i] \ge 1$，把一个升序子数组向两侧扩展（只要仍保持升序）只会累加正数、增大和。因此和最大的升序子数组一定是某个不能再扩展的**极大升序段**，无需考虑它的内部子前缀。

2. **极大段由「断点」唯一切分**。从左到右扫描，遇到 $\text{nums}[i] > \text{nums}[i-1]$ 则当前段可续接；遇到 $\text{nums}[i] \le \text{nums}[i-1]$ 则递增断裂，当前元素另起一段。这些极大段**不重叠且覆盖整个数组**，一趟扫描即可全部识别。

于是算法归约为维护两个滚动变量：

$$
\text{cur}_i = \begin{cases} \text{cur}_{i-1} + \text{nums}[i], & \text{nums}[i] > \text{nums}[i-1] \\ \text{nums}[i], & \text{nums}[i] \le \text{nums}[i-1] \end{cases}, \qquad \text{ans} = \max_{0 \le i < n} \text{cur}_i
$$

### 3.3 算法流程

![算法流程：一趟扫描，升则续累、断则重启](images/max_asc_sum_flow.svg)

1. **初始化**：`cur = ans = nums[0]`（单元素自成一段），`i = 1`。
2. **循环** $i$ 从 $1$ 到 $n-1$：
   - 若 `nums[i] > nums[i-1]`：`cur += nums[i]`（续接当前段）。
   - 否则：`cur = nums[i]`（断点重启，以当前元素另起一段）。
   - 每步更新 `ans = max(ans, cur)`。
3. **终止**：返回 `ans`。

> ⚠️ 注意比较方向是 `nums[i] > nums[i-1]`（**严格大于**）。`[5,5]` 不构成升序子数组，相等同样触发重启——这是本题最典型的 WA 点。

### 3.4 示例演算

以示例 1 `nums = [10,20,30,5,10,50]` 走查：

![示例演算：cur 与 ans 的逐步滚动过程](images/max_asc_sum_walkthrough.svg)

| 步骤 $i$ | $\text{nums}[i]$ | 比较 | 动作 | `cur` | `ans` |
|----------|------|------|------|-------|-------|
| $0$ | $10$ | —（初始） | 单元素成段 | $10$ | $10$ |
| $1$ | $20$ | $20 > 10$ ✓ | `cur += 20` | $30$ | $30$ |
| $2$ | $30$ | $30 > 20$ ✓ | `cur += 30` | $60$ | $60$ |
| $3$ | $5$ | $5 < 30$ ✗ | `cur = 5` 重启 | $5$ | $60$ |
| $4$ | $10$ | $10 > 5$ ✓ | `cur += 10` | $15$ | $60$ |
| $5$ | $50$ | $50 > 10$ ✓ | `cur += 50` | $65$ | $65$ ★ |

最终 `ans = 65` ✓。断点重启时 `ans` 保留历史最大值，扫描结束即得答案。

## 4. 算法细节

1. **状态设计**：`cur` 即「以 `nums[i]` 结尾的升序子数组的最大和」——这正是一维 DP 的滚动形式。转移只依赖相邻一格，无需显式记录段边界。
2. **初始化用 `nums[0]` 而非 0**：单元素段也参与竞争。由于元素全正，初始化为 0 恰好不影响正确性，但用 `nums[0]` 语义更准确、且不依赖「正数」这一前提。
3. **断点判定**：`nums[i] <= nums[i-1]` 都要重启（小于、等于均断裂），对应「严格递增」的题设。
4. **`ans` 的更新时机**：续接与重启两个分支**汇合后**统一执行 `ans = max(ans, cur)`，避免在分支内各写一遍。

## 5. 正确性证明

**引理 1（切分性质）**：从左到右把每个满足 $\text{nums}[i] \le \text{nums}[i-1]$ 的位置 $i$（$i \ge 1$）称为断点，则断点把数组划分为 $k$ 个极大升序段 $S_1, \dots, S_k$（从左到右），满足：每段内部严格递增，且跨段的任意连续子数组不递增。任一严格递增子数组恰好完整落在某一段内。

**证明**：对段内：相邻位置均满足 $\text{nums}[i] > \text{nums}[i-1]$，故严格递增。对跨段：设子数组同时含某断点两侧的元素，则断点处的相邻对违反 $\text{nums}[i] > \text{nums}[i-1]$，不递增。对极大性：段边界两侧（若存在相邻元素）恰是断点，向外扩一格必破坏递增。再设某严格递增子数组 $T$ 跨越段 $S_j$ 与 $S_{j+1}$，则 $T$ 含断点处的相邻对，与 $T$ 递增矛盾，故 $T$ 完整落在某一段内。∎

**引理 2（贪心可扩展性）**：所有元素为正整数时，对任一升序子数组 $T$，设其所在极大段为 $S$，则 $\text{sum}(S) \ge \text{sum}(T)$。

**证明**：由引理 1，$T$ 的元素是 $S$ 的一个连续子区间，$S \setminus T$ 的元素全为正，故 $\text{sum}(S) = \text{sum}(T) + \text{sum}(S \setminus T) \ge \text{sum}(T)$。∎

**定理**：算法返回严格递增子数组的最大元素和。

**证明**：归纳可证扫描到位置 $i$ 时，`cur` 恰为「以 `nums[i]` 结尾的升序子数组的最大和」：$i = 0$ 时单元素成段成立；$i > 0$ 时若 $\text{nums}[i] > \text{nums}[i-1]$，以 $i$ 结尾的最长升序段是由以 $i-1$ 结尾的最长段续接一格而来（引理 1 保证升序段由断点唯一决定），其和最大；否则只能单元素成段。因此 `ans` 在扫描结束时为 $\max_i \text{cur}_i$ = 各极大段和的最大值。而最优解必为某极大段（引理 2 给出「存在最优的极大段」，且极大段本身是合法候选），故算法返回值等于最大升序子数组和。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。单趟遍历，每步一次相邻比较 + 一次加法或赋值 + 一次 `max`，均为常数开销。
- **空间复杂度**：$O(1)$。仅 `cur`、`ans` 两个整型变量，与输入规模无关（一维 DP 滚动优化的结果）。

> 💡 本题 $n \le 100$ 暴力也能过，但 $O(n)$ 单趟扫描的写法在 $n$ 升到 $10^7$ 时依然线性可解，是「相邻局部性 + 正数贪心」把立方降到线性的典型范式，值得作为模板沉淀。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maxAscendingSum(vector<int>& nums) {
        int cur = nums[0], ans = nums[0];
        for (int i = 1; i < (int)nums.size(); ++i) {
            if (nums[i] > nums[i - 1]) cur += nums[i];
            else                        cur = nums[i];
            ans = max(ans, cur);
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maxAscendingSum(self, nums: List[int]) -> int:
        cur = ans = nums[0]
        for i in range(1, len(nums)):
            if nums[i] > nums[i - 1]:
                cur += nums[i]
            else:
                cur = nums[i]
            ans = max(ans, cur)
        return ans
```

## 8. 边界情况与易错点

1. **相等也断裂**：严格递增要求 $\text{nums}[i] < \text{nums}[i+1]$，`[5,5,5]` 的答案是 5 而不是 15。比较必须写成 `nums[i] > nums[i-1]`，把小于和等于一并归入重启分支。
2. **$n = 1$**：循环不执行，初始化 `cur = ans = nums[0]` 直接覆盖，无需特判（对应「长度为 1 的子数组也算升序」）。
3. **初始化不要写成 0 的依赖**：`ans = 0` 在全正约束下碰巧正确，但语义上应是 `nums[0]`；若题目改成元素可为负，`ans = 0` 会直接出错。
4. **全递增数组**：如 `[10,20,30,40,50]`，整个数组是一段，答案是总和 150，算法自然处理。
5. **全不递增数组**：如 `[100,50,25]`，每段单元素，答案是最大元素 100——单元素段同样参与 `max` 竞争。
6. **溢出**：$n \le 100$、$\text{nums}[i] \le 100$，最大和 $10^4$，`int` 绰绰有余，无需 `long long`。
