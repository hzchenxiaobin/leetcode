# LeetCode 统计异或值在范围内的数对有多少 题解

## 1. 题目概述

- **标题 / 题号**：统计异或值在范围内的数对有多少（#1803，hard）
- **链接**：https://leetcode.cn/problems/count-pairs-with-xor-in-a-range/
- **来源**：LeetCode 第 233 场周赛 Q4
- **难度**：困难
- **标签**：位运算、字典树（Trie）、数组

**题意**：给定整数数组 `nums` 与两个整数 `low`、`high`，统计「漂亮数对」的数目：即满足 $0 \le i < j < n$ 且 $low \le nums[i] \oplus nums[j] \le high$ 的下标对 $(i, j)$ 的个数（$\oplus$ 为按位异或）。

**约束**：

- $1 \le n \le 2 \times 10^4$
- $1 \le nums[i] \le 2 \times 10^4$
- $1 \le low \le high \le 2 \times 10^4$

> 💡 **核心矛盾**：数对最多 $\binom{2 \times 10^4}{2} \approx 2 \times 10^8$ 个，逐对算异或必然超时；「$low \le \oplus \le high$」又是**双端**条件，排序 + 二分的老路也走不通。突破口有二：一是把双端条件**差分**成两个单端「严格小于」计数——这正是「区间和 = 前缀和之差」的计数版；二是「$x \oplus y < L$」的大小比较天然是**逐位**的——高位一旦分出胜负，低位就不再重要，这恰好能在 **01-Trie** 上把一整棵子树的贡献**整块累加**。两个观察合璧，就是本题的标准困难题套路。

## 2. 示例

**示例 1**

```text
输入：nums = [1,4,2,7], low = 2, high = 6
输出：6
解释：全部 6 个数对的异或值：
      (0,1): 1⊕4=5   (0,2): 1⊕2=3   (0,3): 1⊕7=6
      (1,2): 4⊕2=6   (1,3): 4⊕7=3   (2,3): 2⊕7=5
      异或值 5,3,6,6,3,5 全部落在 [2,6] 内，答案 6。
```

**示例 2**

```text
输入：nums = [9,8,4,2,1], low = 5, high = 14
输出：8
解释：异或值落在 [5,14] 的恰有 8 对（13,11,8,12,10,9,6,5）；
      (0,1): 9⊕8=1 与 (3,4): 2⊕1=3 两对落在区间外。
```

**示例 3（自造边界：相同元素）**

```text
输入：nums = [2,2], low = 1, high = 2
输出：0
解释：2⊕2 = 0 < low = 1。相同元素永不贡献——自异或值为 0，
      而题目保证 low ≥ 1，0 永远进不了 [low, high]。
```

**示例 4（自造边界：low == high 的单点区间）**

```text
输入：nums = [1,2], low = 3, high = 3
输出：1
解释：1⊕2 = 3 恰好压在区间端点上。差分后 ans = f(4) − f(3)：
      {xor < 4} 有 1 个，{xor < 3} 有 0 个，相减恰好留下 xor == 3 的对。
```

## 3. 解题思路

### 3.1 暴力思路：枚举所有数对

双重循环枚举 $(i, j)$，现算 $nums[i] \oplus nums[j]$，判断是否落在 $[low, high]$。

- 时间 $O(n^2)$：$n = 2 \times 10^4$ 时约 $2 \times 10^8$ 次异或 + 比较，C++ 都很勉强，赛场上不可接受。
- 瓶颈本质：「**与某个 $x$ 异或后小于给定阈值 $L$ 的元素有多少个**」这个查询没有任何索引结构支撑，只能对每个 $y$ 从零开始验证。

想要优化，先要解决两个拦路虎：双端条件怎么变成单端？单端条件怎么批量统计？

### 3.2 核心观察：前缀差分 + 01-Trie 逐位计数

![核心观察：双端区间差分为两个前缀计数](images/wc233_q4_prefix_diff_concept.svg)

**观察一（前缀差分）**：定义

$$
f(L) \;=\; \#\{\, (i,j) : 0 \le i < j < n,\ \ nums[i] \oplus nums[j] < L \,\}
$$

由于异或值是非负整数，$s \le high \iff s < high+1$，闭区间条件即可拆成两个**开区间上界**之差：

$$
ans \;=\; f(high+1) \;-\; f(low)
$$

双端化单端之后，只剩一个子问题要解：**已经插入的元素中，与 $x$ 异或后小于 $L$ 的有多少个**。

**观察二（逐位比较 → 子树整块计数）**：比较 $x \oplus y$ 与 $L$ 是从高位到低位进行的。设当前看第 $b$ 位，记 $x_b$、$L_b$ 为 $x$、$L$ 的该位，且此前各位 $x \oplus y$ 与 $L$ 的前缀完全相同（「贴着前缀」）：

- 若 $L_b = 1$：让 $y$ 的该位取 $x_b$（异或位为 $0$），则无论剩余低位取什么，$x \oplus y$ 在这一位已**严格更小** → `child[x_b]` 子树的**全部**元素一次性合格，个数就是该子树的计数 `cnt`；而让 $y$ 该位取 $x_b \oplus 1$（异或位为 $1$，与 $L_b$ 相同）则继续贴前缀，下探处理低位。
- 若 $L_b = 0$：异或位必须为 $0$（$y$ 该位取 $x_b$）才能贴住前缀，不产生任何整块计数，直接下探 `child[x_b]`；取 $1$ 的那枝整体超出 $L$，直接出局。

把这套规则放进按二进制位建立的 **01-Trie**——每个节点维护子树内已插入元素个数 `cnt`——一次查询就是一条从根出发、至多 $B$ 位的下探路径，沿途把若干子树的 `cnt` 整块搬进答案，代价 $O(B)$。

> 💡 **套路沉淀**：421「最大异或对」是同一棵 Trie 上的「贪心走相反位求最大」；本题换成「贴着 $L$ 走、逢 1 收子树」求**小于计数**。共同的心法是：**与异或有关的大小比较，都可以在 01-Trie 上逐位决策**——每一步要么整块收割（严格分出胜负），要么继续下探（保持相等前缀）。

### 3.3 算法流程

![算法流程：单趟扫描，先查后插](images/wc233_q4_query_flow.svg)

1. **初始化**：空 01-Trie（只含根），位宽 $B = 15$——$2^{15} = 32768 > 2 \times 10^4$，覆盖 $nums[i]$ 与 $high+1$ 的最大值。
2. **单趟扫描**：依次处理每个 $x = nums[j]$：
   - `ans += query(x, high+1) − query(x, low)`；
   - `insert(x)` 将 $x$ 插入 Trie（**先查后插**）。
3. **查询 `query(x, L)`**：从根出发，$b$ 从 $B-1$ 到 $0$：
   - $L_b = 1$：`res += cnt[child[xb]]`（该位异或取 0，已严格更小，整块计入），随后 `v = child[xb ⊕ 1]`；
   - $L_b = 0$：`v = child[xb]`（不累加）；
   - 若下探的子节点不存在，提前返回 `res`；
   - 走完全部位后**不再累加**——剩余子树对应 $x \oplus y = L$ 恰好相等，不满足严格小于。
4. **终止**：返回 `ans`。

> ⚠️ 「先查后插」保证查询时 Trie 恰含 $nums[0..j-1]$：每个数对 $(i,j)$（$i<j$）恰在处理 $j$ 时被统计一次，不重不漏。另外注意两个 limit 在同一趟里**先查后插**，Trie 只建一次，无需清空重建。

### 3.4 示例演算

![0-1 Trie 逐位查询演算](images/wc233_q4_trie_query_walkthrough.svg)

先看单次查询。示例 1 处理到最后一个元素 $x = 7$ 时，Trie 中已有 $\{1, 2, 4\}$（图中用 4 位示意，实际 15 位）。查询 $f(7) = query(7, 7)$，其中 $x = 7 = 0111_2$、$L = 7 = 0111_2$：

- **第 3 位**：$L$ 该位为 $0$ → 只能走 0 边下探（异或位须为 0），不累加；
- **第 2 位**：$L$ 该位为 $1$ → 先把 1 边子树 $\{4\}$ 的 `cnt = 1` 整块累加（$7 \oplus 4 = 3 < 7$ ✓），再走 0 边下探到 $\{1,2\}$；
- **第 1 位**：同为 $1$ → 累加 1 边子树 $\{2\}$ 的 $1$ 个（$7 \oplus 2 = 5 < 7$ ✓），走 0 边下探到 $\{1\}$；
- **第 0 位**：同为 $1$ → 累加 1 边 $\{1\}$ 的 $1$ 个（$7 \oplus 1 = 6 < 7$ ✓），走 0 边——子节点为空，终止。

$f(7) = 1 + 1 + 1 = 3$。三次「整块累加」分别收走 $\{4\}, \{2\}, \{1\}$——**没有任何元素被逐位比较第二遍**，这就是 $O(B)$ 查询的底气。

![示例逐元素累加表](images/wc233_q4_example_walkthrough.svg)

再看整趟累加（$low = 2$，$high = 6$）：

- $j=0$（$x=1$）：Trie 为空，$f(7) = f(2) = 0$，贡献 $0$；插入 $1$。
- $j=1$（$x=4$）：$4 \oplus 1 = 5$，$f(7) = 1$、$f(2) = 0$，贡献 $1$；插入 $4$。
- $j=2$（$x=2$）：$2 \oplus 1 = 3$、$2 \oplus 4 = 6$，$f(7) = 2$、$f(2) = 0$，贡献 $2$；插入 $2$。
- $j=3$（$x=7$）：即上图演算，$f(7) = 3$、$f(2) = 0$，贡献 $3$。

$ans = 0 + 1 + 2 + 3 = 6$ ✓，与直接枚举一致。

## 4. 算法细节

1. **位宽取 $B = 15$**：$nums[i] \le 2 \times 10^4 < 2^{15}$，且 $high + 1 \le 2 \times 10^4 + 1 < 2^{15}$；两个 15 位数的异或也 $< 2^{15}$，一位不漏。
2. **`cnt` 的语义**：以 $v$ 为根的子树里**已插入**元素的个数。插入时沿 15 位路径逐节点 `cnt++`（根不计数），查询时被整块累加的正是这个值。
3. **单趟复用**：先查 $f(high+1)$、再查 $f(low)$、最后 `insert(x)`，两个 limit 共享一趟扫描与同一棵 Trie。
4. **哨兵技巧（数组版 Trie）**：节点 0 固定为根、永不作为孩子出现，于是 `child == 0` 可兼作「子节点不存在」；又因根从不计数，`cnt[0]` 恒为 0，`res += cnt[child[xb]]` 在孩子缺席时天然加 0，无需判空。
5. **走完全部位不累加**：能一路贴前缀走到底的 $y$ 满足 $x \oplus y = L$ **恰好相等**，不属于严格小于，最后那个节点的 `cnt` 不能加进 `res`。
6. **溢出**：答案上限 $\binom{2 \times 10^4}{2} \approx 2 \times 10^8$，`int` 存得下（$< 2^{31} - 1$），但 C++ 建议用 `long long` 累加更稳；Python 无此顾虑。

## 5. 正确性证明

**引理 1（前缀差分恒等式）**：对任意非负整数 $s$，

$$
\mathbf{1}[\, low \le s \le high \,] \;=\; \mathbf{1}[\, s < high+1 \,] \;-\; \mathbf{1}[\, s < low \,]
$$

**证明**：$s$ 为整数，故 $s \le high \iff s < high+1$，于是 $[\,low \le s \le high\,] = [\,s < high+1\,] \setminus [\,s < low\,]$；又由 $low \le high$ 知 $[\,s < low\,] \subseteq [\,s < high+1\,]$，两个示性函数相减即得。对全体数对求和：$ans = f(high+1) - f(low)$。∎

**引理 2（单次查询的计数正确性）**：设 $1 \le L < 2^B$。`query(x, L)` 返回 Trie 中满足 $x \oplus y < L$ 的已插入元素个数。

**证明**：对位次 $b$ 自 $B-1$ 向 $0$ 归纳，维护不变量 $\mathcal{I}(b)$：处理第 $b$ 位之前，当前节点 $v$ 的子树恰为 $\{\, y : (x \oplus y) \gg (b+1) = L \gg (b+1) \,\}$（即 $x \oplus y$ 与 $L$ 在高于 $b$ 的所有位上相等，简称贴前缀；$v$ 不存在则该集合为空），且 `res` 恰等于子树外满足 $x \oplus y < L$ 的元素个数。初始 $b = B-1$ 时高位前缀为空，不变量平凡成立。归纳步：子树内元素按第 $b$ 位分为 `child[0]`、`child[1]` 两枝，异或位分别为 $x_b \oplus 0$ 与 $x_b \oplus 1$：

- $L_b = 1$：`child[x_b]` 枝的异或位为 $0 < 1 = L_b$ 且高位相等，故无论低位如何都有 $x \oplus y < L$，以 `cnt` 整块计入 `res`；`child[x_b ⊕ 1]` 枝异或位为 $1 = L_b$，保持贴前缀，下探后 $\mathcal{I}(b-1)$ 成立。
- $L_b = 0$：只有 `child[x_b]` 枝（异或位为 $0 = L_b$）保持贴前缀；`child[x_b ⊕ 1]` 枝高位相等、该位 $1 > 0$，整体 $x \oplus y > L$，永远不合格，理应出局；下探后不变量成立。

若应下探的子节点不存在，则贴前缀集合已空，提前返回的 `res` 即全部答案。走完全部位后剩余元素满足 $x \oplus y = L$ 恰好相等，不属于 $< L$，不计入——与实现「结尾不累加」一致。∎

**定理**：算法返回漂亮数对的个数。

**证明**：由「先查后插」，处理 $j$ 时 Trie 恰含 $nums[0..j-1]$；由引理 2，`query(nums[j], L)` 等于 $\#\{\, i < j : nums[i] \oplus nums[j] < L \,\}$。对 $j$ 求和，每个数对 $(i,j)$（$i<j$）恰在其右端点 $j$ 处被统计一次，故 $\sum_j query(nums[j], L) = f(L)$。结合引理 1，`ans = f(high+1) − f(low)` 即漂亮数对个数。∎

## 6. 复杂度分析

- **时间复杂度**：$O(nB)$，$B = 15$。每个元素执行 2 次查询 + 1 次插入，每次至多走 $B$ 位，总计约 $3nB \approx 9 \times 10^5$ 次位操作——比暴力的 $2 \times 10^8$ 缩小两个数量级以上。
- **空间复杂度**：$O(nB)$。Trie 至多 $nB + 1 \approx 3 \times 10^5$ 个节点，每节点 2 个孩子指针 + 1 个计数；大量前缀共享时实际更少。

> 💡 本题的降维打击在于 Trie 把「与 $x$ 异或后落在某范围」的**集合**按位前缀**预聚合**成子树，`cnt` 把「子树里有多少元素」提前存好，查询时整块搬运。「用结构把 $O(n)$ 统计降为 $O(\log)$」与树状数组的前缀和预聚合思想同源。

## 7. 参考代码

### C++

```cpp
class Solution {
    static constexpr int B = 15;  // 2^15 = 32768 > 2*10^4，覆盖 nums[i] 与 high+1

  public:
    int countPairs(vector<int>& nums, int low, int high) {
        const int n = nums.size();
        // ch[v][d]：孩子编号，0 表示不存在（0 号为根）；cnt[v]：子树内已插入元素数
        vector<array<int, 2>> ch(n * B + 1, {0, 0});
        vector<int> cnt(n * B + 1, 0);
        int tot = 0;  // 已分配的节点数

        // 插入 x：沿 15 位路径下行，途经节点 cnt++（根不计数）
        auto insert = [&](int x) {
            int v = 0;
            for (int b = B - 1; b >= 0; --b) {
                int d = (x >> b) & 1;
                if (ch[v][d] == 0) ch[v][d] = ++tot;
                v = ch[v][d];
                ++cnt[v];
            }
        };

        // 统计已插入的 y 中，x ^ y < limit 的个数
        auto query = [&](int x, int limit) -> long long {
            long long res = 0;
            int v = 0;
            for (int b = B - 1; b >= 0; --b) {
                int xb = (x >> b) & 1, lb = (limit >> b) & 1;
                if (lb) res += cnt[ch[v][xb]];  // 该位异或取 0：已严格更小，整块计入
                v = lb ? ch[v][xb ^ 1] : ch[v][xb];
                if (v == 0) return res;  // 贴前缀的子树为空，提前终止
            }
            return res;  // 剩余子树 x^y == limit，不累计（严格小于）
        };

        long long ans = 0;
        for (int x : nums) {
            ans += query(x, high + 1) - query(x, low);
            insert(x);  // 先查后插：查询时 Trie 恰含前 j 个元素
        }
        return (int)ans;
    }
};
```

### Python

```python
class Solution:
    B = 15  # 2^15 = 32768 > 2*10^4，覆盖 max(nums) 与 high+1

    def countPairs(self, nums: List[int], low: int, high: int) -> int:
        ch = [[0, 0]]  # ch[v][d]：孩子编号，0 表示不存在（0 号为根）
        cnt = [0]      # cnt[v]：子树内已插入元素个数

        def insert(x: int) -> None:
            v = 0
            for b in range(Solution.B - 1, -1, -1):
                d = (x >> b) & 1
                if ch[v][d] == 0:
                    ch[v][d] = len(ch)
                    ch.append([0, 0])
                    cnt.append(0)
                v = ch[v][d]
                cnt[v] += 1

        def query(x: int, limit: int) -> int:
            # 统计已插入的 y 中，x ^ y < limit 的个数
            res = 0
            v = 0
            for b in range(Solution.B - 1, -1, -1):
                xb = (x >> b) & 1
                lb = (limit >> b) & 1
                if lb:
                    res += cnt[ch[v][xb]]  # 该位异或取 0：已严格更小，整块计入
                v = ch[v][xb ^ 1] if lb else ch[v][xb]
                if v == 0:
                    return res  # 贴前缀的子树为空，提前终止
            return res  # 剩余子树 x^y == limit，不累计（严格小于）

        ans = 0
        for x in nums:
            ans += query(x, high + 1) - query(x, low)
            insert(x)  # 先查后插
        return ans
```

## 8. 边界情况与易错点

1. **位宽不足**：$B = 14$ 只能表示到 $16383$，而 $nums[i]$ 可达 $20000$、$high+1$ 可达 $20001$，高位被截断会整块漏统计；必须取 15。取 16 也不算错，只是多一层恒为 0 的前缀。
2. **差分端点**：$ans = f(high+1) - f(low)$。写成 $f(high)$ 会漏掉异或值**恰等于** $high$ 的数对；写成 $-f(low-1)$ 会把异或值等于 $low-1$ 的数对错误保留。两个端点都在「闭」上，差分后都要变「开」。
3. **结尾多加一次**：查询走完全部位后把当前节点 `cnt` 累加进去，会把 $x \oplus y = L$ 恰好相等的数对也数进来（症状：答案恰好偏大相等的对数）。
4. **「先查后插」写反（反直觉）**：实测**先插后查**本题也能通过——自异或 $0$ 同时被 $f(low)$（$low \ge 1 > 0$）与 $f(high+1)$ 数到，在差分中恰好抵消。但这是 $low \ge 1$ 的**约束巧合**：一旦允许 $low = 0$，$f(0)$ 数不到 0 而 $f(high+1)$ 数到，答案立刻多出 $n$。先查后插是与约束无关的干净写法，别依赖巧合。
5. **哨兵技巧的前提**：数组版 Trie 依赖「根永不计数」——插入循环必须先定位子节点再 `cnt++`；若把根也计入，`res += cnt[child[xb]]` 在孩子缺席时会加上根的总数，答案爆炸。
6. **$n = 1$**：无对可统计，循环自然返回 0。
7. **$low = high$**：区间退化为单点，$f(low+1) - f(low)$ 恰好留下异或值等于 $low$ 的数对，无需特判（见示例 4）。
8. **返回值类型**：C++ 建议用 `long long` 累加、最后转 `int` 返回（上限约 $2 \times 10^8$，`int` 可存但防御性写法更稳）。

- [LeetCode 2935. 找出强数对的最大异或值 II](https://leetcode.cn/problems/maximum-strong-pair-xor-ii/)：01-Trie 上批量统计的进阶应用（本仓库 371 场 Q4 已有题解），体会 `cnt` 维护与惰性删除的更多玩法。

**延伸思考**：其一，本题值域 $V = 2^{15}$ 很小，也可对值域计数数组 $a$ 做一次 $O(V \log V)$ 的 **Walsh–Hadamard 异或卷积** $c = a \otimes a$：$c[k]$ 是有序对（含自身）中异或等于 $k$ 的次数，则 $ans = \sum_{k=low}^{high} c[k] \,/\, 2$（$k \ge low \ge 1$，自身配对的异或 0 不会混入）——卷积视角与 Trie 视角殊途同归。其二，若 $nums[i]$ 达 $10^9$，只需把位宽换成 30，复杂度仍是 $O(nB)$；若还要求支持删除，给 `cnt` 做减法的**惰性删除**即可。其三，「不建 Trie」的等价实现是按高位前缀**逐位分桶**整块统计，空间更省、常数更小，本质与 Trie 完全相同。
