# LeetCode 有界数组中指定下标处的最大值 题解

## 1. 题目概述

- **标题 / 题号**：有界数组中指定下标处的最大值（#1802，medium）
- **链接**：https://leetcode.cn/problems/maximum-value-at-a-given-index-in-a-bounded-array/
- **来源**：LeetCode 第 233 场周赛 Q3
- **难度**：中等
- **标签**：贪心、数学、二分查找

**题意**：给定三个正整数 `n`、`index`、`maxSum`，构造一个长度为 `n` 的数组 `nums`，满足：

1. 所有元素是**正整数**；
2. 相邻元素之差的绝对值至多为 $1$（$\lvert \text{nums}[i] - \text{nums}[i+1] \rvert \le 1$）；
3. 元素总和不超过 $\maxSum$；
4. 在以上前提下，$\text{nums}[\text{index}]$ **尽可能大**。

返回 $\text{nums}[\text{index}]$ 的最大可能值。

**约束**：

- $1 \le n \le \maxSum \le 10^9$
- $0 \le \text{index} < n$

> 💡 **核心矛盾**：要在总和预算内把一个位置「堆」得尽量高，其余位置就该**尽量矮**。而「相邻差 $\le 1$」意味着高度只能逐 1 递减、且正整数有下限 $1$——这天然形成一个**山峰形**数组。问题于是转化为：**山峰的峰值最高能堆到多少？** 这是典型的「可行性单调 → 二分答案」套路题。

## 2. 示例

**示例 1**

```text
输入：n = 4, index = 2, maxSum = 6
输出：2
解释：数组 [1,1,2,1] 和 [1,2,2,1] 满足所有条件。
      不存在其他在指定下标处具有更大值的有效数组。
```

**示例 2**

```text
输入：n = 6, index = 1, maxSum = 10
输出：3
解释：山峰形构造 [2,3,2,1,1,1]，总和恰为 10 ≤ 10。
      若峰值取 4，最小和为 3+4+3+2+1+1 = 14 > 10，不可行。
```

**示例 3（自造边界：峰值在端点 + 预算刚好卡满）**

```text
输入：n = 4, index = 0, maxSum = 4
输出：1
解释：预算 maxSum = n，数组只能取 [1,1,1,1]（全 1 是唯一选择），nums[0] = 1。
```

## 3. 解题思路

### 3.1 暴力思路：枚举峰值逐个验证

从 $x = 1$ 开始逐个枚举峰值，对每个 $x$ 验证「$\text{nums}[\text{index}] = x$ 时数组最小和是否 $\le \maxSum$」：验证时贪心地从峰值向两侧逐 1 递减构造出和最小的数组再求和。

两个瓶颈：

1. $x$ 的范围可达 $10^9$，逐个枚举必然超时；
2. $n$ 也可达 $10^9$，即使只验证一个 $x$，逐元素构造求和的 $O(n)$ 也扛不住。

但「$x$ 越大，最小和越大」——可行性关于 $x$ **单调**，这是二分答案的信号；而「数组形状被贪心完全确定」意味着两侧的和可以用等差数列公式 $O(1)$ 算出。两个瓶颈各有一个对应的优化。

### 3.2 核心观察：山峰形最小和构造 + 二分答案

![核心观察：山峰形构造逐点取到下界](images/wc233_q3_bounded_peak_concept.svg)

关键洞察分三步：

**第一步：贪心确定数组形状（山峰形）。** 固定 $\text{nums}[\text{index}] = x$ 后，由相邻差约束逐格连锁可推出每个位置的**下界**：

$$
\text{nums}[j] \;\ge\; \max\bigl(1,\ x - \lvert\text{index} - j\rvert\bigr)
$$

即每远离峰值一步，值最多被迫降 $1$；降到正整数下限 $1$ 后保持 $1$。取 $\text{nums}[j] = \max(1,\ x - \lvert\text{index}-j\rvert)$ 得到的**山峰形数组**逐点取到该下界，因此是固定 $x$ 时总和最小的构造。

**第二步：等差数列公式 $O(1)$ 求一侧最小和。** 对一侧 `cnt` 个位置、从 $x-1$ 开始逐项减 $1$ 的序列，分两种情况：

- **完整下降**（$\text{cnt} \le x-1$）：序列为 $x-1, x-2, \dots, x-\text{cnt}$（均 $\ge 1$），等差数列求和：

$$
\text{sideSum} = \text{cnt} \cdot x - \frac{\text{cnt}(\text{cnt}+1)}{2}
$$

- **触底铺平**（$\text{cnt} > x-1$）：前 $x-1$ 项从 $x-1$ 降到 $1$，和为 $\frac{(x-1)x}{2}$；余下 $\text{cnt}-(x-1)$ 项全为 $1$：

$$
\text{sideSum} = \frac{(x-1)x}{2} + \bigl(\text{cnt} - (x-1)\bigr)
$$

于是固定 $x$ 时的最小总和为：

$$
\text{minSum}(x) = x + \text{sideSum}(\text{index},\ x) + \text{sideSum}(n - \text{index} - 1,\ x)
$$

**第三步：二分答案。** $\text{minSum}(x)$ 关于 $x$ 严格递增（峰值抬升 $1$，山峰整体只增不减），于是存在分界点 $x^*$：

```text
x ≤ x*  → minSum(x) ≤ maxSum   (可行)
x > x*  → minSum(x) > maxSum   (不可行)
```

这就是二段性。上界还可收紧：其余 $n-1$ 个位置至少为 $1$，故可行峰值必满足 $x + (n-1) \le \maxSum$，即 $x \le \maxSum - n + 1$。在 $[1,\ \maxSum - n + 1]$ 上二分即可。

> 💡 **套路沉淀**：看到「最大化某个量，且可行性关于该量单调」就要条件反射**二分答案**；随后追问 `check()` 能否更便宜——本题先把数组形状贪心确定（山峰形），再把「构造数组求和」升级为「等差数列公式」，`check()` 从 $O(n)$ 降到 $O(1)$。这与 875 珂珂吃香蕉的「逐堆模拟」形成鲜明对照。

### 3.3 算法流程

![算法流程：二分最大可行峰值](images/wc233_q3_bounded_peak_flow.svg)

1. **初始化**：`lo = 1`，`hi = maxSum - n + 1`（收紧的上界），`ans = 1`。
2. **循环** `lo <= hi`：
   - 取 `mid = (lo + hi) / 2`；
   - 用公式计算 `total = mid + sideSum(index, mid) + sideSum(n - index - 1, mid)`；
   - 若 `total <= maxSum`：`mid` 可行，记录 `ans = mid`，`lo = mid + 1`（向右找更大峰值）；
   - 否则：`hi = mid - 1`（峰值太大，收缩上界）。
3. **终止**：区间为空时返回 `ans`。

> ⚠️ 本题求的是**最大可行值**（与 875 求「最小可行速度」方向相反）：可行分支记录答案并**右移** `lo`，不可行分支**左移** `hi`。二分方向写反是本题最常见的 WA 点之一。

### 3.4 示例演算

![示例演算：二分峰值的过程](images/wc233_q3_bounded_peak_walkthrough.svg)

以 `n = 4, index = 2, maxSum = 6` 为例，二分区间 $[1, \maxSum - n + 1] = [1, 3]$：

- **mid = 2**：山峰 $[1,1,2,1]$，$\text{minSum} = 2 + \text{sideSum}(2, 2) + \text{sideSum}(1, 2) = 2 + 2 + 1 = 5 \le 6$ ✓ → `ans = 2`，`lo = 3`。
  （左侧 2 个位置：$x-1 = 1$ 只够降一步，第二格触底铺平，故 $\text{sideSum}(2,2) = \frac{1 \cdot 2}{2} + (2-1) = 2$；右侧 1 个位置：完整下降 $\text{sideSum}(1,2) = 1 \cdot 2 - 1 = 1$。）
- **mid = 3**：山峰 $[2,1,3,2]$，$\text{minSum} = 3 + 3 + 2 = 8 > 6$ ✗ → `hi = 2`。
- `lo = 3 > hi = 2`，循环结束，返回 `ans = 2`。✓

## 4. 算法细节

1. **下界的推导（三角不等式连锁）**：从 `index` 走到 $j$ 要跨 $\lvert\text{index}-j\rvert$ 步，每步值变化至多 $1$，故 $\lvert\text{nums}[j] - x\rvert \le \lvert\text{index}-j\rvert$，即 $\text{nums}[j] \ge x - \lvert\text{index}-j\rvert$；再与正整数下限 $1$ 取 $\max$。
2. **两侧和公式的分界**：以「下降是否触底」为界——一侧长度 $\text{cnt} \le x-1$ 时完整下降（等差数列求和），$\text{cnt} > x-1$ 时降到 $1$ 后铺平。两个公式在 $\text{cnt} = x-1$ 处相等（都是 $\frac{(x-1)x}{2}$），边界无缝衔接。
3. **统一写法**：令 $d = \min(\text{cnt},\ x-1)$，则 $\text{sideSum} = d \cdot x - \frac{d(d+1)}{2} + (\text{cnt} - d)$，两种情况合而为一，代码可以更短。
4. **二分上界的收紧**：用 $\maxSum - n + 1$ 而非 $\maxSum$，依据是 $\text{minSum}(x) \ge x + (n-1)$。题设 $n \le \maxSum$ 保证该上界 $\ge 1$，二分区间非空。
5. **溢出**：$\text{cnt} \cdot x$ 可达 $10^{18}$，C++ 中 `sideSum` 的参数、返回值与 `total` 都必须用 `long long`。

## 5. 正确性证明

**引理 1（逐点下界）**：设 `nums` 是合法数组且 $\text{nums}[\text{index}] = x$，则对任意 $0 \le j < n$：

$$
\text{nums}[j] \ge \max\bigl(1,\ x - \lvert\text{index} - j\rvert\bigr)
$$

**证明**：从 `index` 沿相邻位置走到 $j$ 共 $\lvert\text{index}-j\rvert$ 步，由相邻差约束与三角不等式，$\lvert\text{nums}[j] - x\rvert \le \lvert\text{index}-j\rvert \cdot 1$，故 $\text{nums}[j] \ge x - \lvert\text{index}-j\rvert$；又元素为正整数，$\text{nums}[j] \ge 1$，两者取 $\max$ 即得。∎

**引理 2（山峰形是取到下界的合法构造）**：定义 $A^*_x[j] = \max(1,\ x - \lvert\text{index}-j\rvert)$。则 (a) $A^*_x$ 是合法数组且 $A^*_x[\text{index}] = x$；(b) 任何满足 $\text{nums}[\text{index}] = x$ 的合法数组，其总和 $\ge \text{sum}(A^*_x) = \text{minSum}(x)$。

**证明**：(a) 每项 $\ge 1$ 为正整数；$A^*_x[\text{index}] = \max(1, x) = x$；对相邻位置 $j, j+1$，两处距离 $\lvert\text{index}-j\rvert$ 与 $\lvert\text{index}-(j+1)\rvert$ 至多差 $1$，而映射 $t \mapsto \max(1,\ x - t)$ 把相差 $1$ 的自变量映到相差至多 $1$ 的值（若两侧都被截到 $1$ 则差为 $0$；若只有一侧被截，另一侧值落在 $[1,\ x-t]$ 内，差仍 $\le 1$），故相邻差 $\le 1$。(b) 由引理 1 逐点 $\text{nums}[j] \ge A^*_x[j]$，求和即得；$\text{sum}(A^*_x)$ 展开即第 4 节的等差数列公式。∎

**引理 3（单调性 → 二段性）**：$\text{minSum}(x)$ 关于 $x$ 严格递增，且 $\text{minSum}(1) = n \le \maxSum$，$\text{minSum}(\maxSum - n + 2) \ge (\maxSum - n + 2) + (n-1) = \maxSum + 1 > \maxSum$。因此可行集 $\{x \ge 1 : \text{minSum}(x) \le \maxSum\}$ 是非空前缀 $\{1, 2, \dots, x^*\}$。

**证明**：$x$ 增加 $1$ 时，每个位置的 $\max(1,\ x+1-d)$ 不小于 $\max(1,\ x-d)$，且 `index` 处恰好增加 $1$，故 $\text{minSum}(x+1) \ge \text{minSum}(x) + 1$，严格递增。严格递增的谓词在整数上可行性显然为一段前缀；两端点的取值如上所示，故前缀非空且 $x^* \le \maxSum - n + 1$。∎

**定理**：算法返回 `nums[index]` 的最大可能值。

**证明**：由引理 3，$x^* \in [1,\ \maxSum - n + 1]$，且谓词 $\text{minSum}(x) \le \maxSum$ 在该区间上单调；「可行则记录 `ans = mid` 并右移 `lo`，不可行则左移 `hi`」的标准二分收敛到区间内最大可行值，即 `ans = x^*`。**可达性**：由引理 2(a)，山峰形 $A^*_{x^*}$ 是总和 $\le \maxSum$、$\text{nums}[\text{index}] = x^*$ 的合法构造。**最优性**：若某合法数组满足 $\text{nums}[\text{index}] = y > x^*$，由引理 2(b) 其总和 $\ge \text{minSum}(y) \ge \text{minSum}(x^* + 1) > \maxSum$（引理 3 的严格递增），与总和约束矛盾。故 $x^*$ 即最大可能值。∎

## 6. 复杂度分析

- **时间复杂度**：$O(\log(\maxSum - n + 1)) \approx O(\log \maxSum)$。二分约 $\log_2 10^9 \approx 30$ 次迭代，每次用等差数列公式 $O(1)$ 完成 `check()`，与 $n$ 无关——这是 $n$ 高达 $10^9$ 也能瞬间出解的关键。
- **空间复杂度**：$O(1)$。仅 `lo`、`hi`、`ans`、`total` 等常数个变量，不显式构造数组。

> 💡 本题的降维打击在于 `check()` 从暴力的 $O(n)$ 构造数组降为 $O(1)$ 公式计算。这得益于「山峰形」贪心把数组形状完全确定，左右两侧的和可用等差数列闭式表达——「形状确定时，从模拟升级为公式」是值得沉淀的优化意识。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    // 一侧 cnt 个位置、紧邻峰值逐 1 递减的最小和
    long long sideSum(long long cnt, long long x) {
        if (cnt <= x - 1) {
            // 完整下降：x-1, x-2, ..., x-cnt（均 >= 1）
            return cnt * x - cnt * (cnt + 1) / 2;
        } else {
            // 触底铺平：x-1, ..., 1 共 x-1 项，其余全为 1
            return (x - 1) * x / 2 + (cnt - (x - 1));
        }
    }

    int maxValue(int n, int index, int maxSum) {
        int lo = 1, hi = maxSum - n + 1, ans = 1;
        while (lo <= hi) {
            int mid = lo + (hi - lo) / 2;
            long long total = mid
                + sideSum(index, mid)
                + sideSum(n - index - 1LL, mid);
            if (total <= maxSum) {
                ans = mid;        // 可行，向右找更大的峰值
                lo = mid + 1;
            } else {
                hi = mid - 1;     // 峰值太大，收缩上界
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maxValue(self, n: int, index: int, maxSum: int) -> int:
        def side_sum(cnt: int, x: int) -> int:
            if cnt <= x - 1:
                # 完整下降：x-1, x-2, ..., x-cnt
                return cnt * x - cnt * (cnt + 1) // 2
            # 触底铺平：先降到 1，其余全为 1
            return (x - 1) * x // 2 + (cnt - (x - 1))

        lo, hi = 1, maxSum - n + 1
        ans = 1
        while lo <= hi:
            mid = (lo + hi) // 2
            total = mid + side_sum(index, mid) + side_sum(n - index - 1, mid)
            if total <= maxSum:
                ans = mid        # 可行，向右找更大的峰值
                lo = mid + 1
            else:
                hi = mid - 1     # 峰值太大，收缩上界
        return ans
```

## 8. 边界情况与易错点

1. **溢出（C++ 头号坑）**：$n, \maxSum \le 10^9$，`cnt * x` 可达 $10^{18}$，远超 `int`（约 $2.1 \times 10^9$）。`sideSum` 的参数与返回值、`total` 都必须用 `long long`；调用时写 `n - index - 1LL` 确保以 `long long` 传入。
2. **一侧长度为 0**：`index = 0` 或 `index = n-1` 时一侧 `cnt = 0`，两个分支的公式都返回 $0$，无需特判。
3. **触底铺平段别漏**：$\text{cnt} > x-1$ 时的 $(\text{cnt} - (x-1))$ 个 $1$ 最容易忘写，症状是大 $n$、大 $\maxSum$ 时答案偏大（最小和被算小了）。
4. **二分方向写反**：本题求「最大可行值」，可行时 `ans = mid; lo = mid + 1`；若照抄 875 的「可行时 `hi = mid - 1`」会直接得到最小可行值 $1$。
5. **上界初值**：用 `maxSum - n + 1` 而非 `maxSum`，既省一次二分，又与证明中的前缀上界一致；题设 $n \le \maxSum$ 保证 `hi >= 1`，区间非空。当 $\maxSum = n$ 时区间仅含 $1$，答案就是全 $1$ 数组。
6. **$x = 1$ 的退化**：触底分支中 $\frac{(x-1)x}{2} = 0$、铺平 $\text{cnt}$ 项，公式自然退化为「全 $1$」，无需特判。
7. **Python 整除**：用 `//` 且注意 `(x - 1) * x // 2` 先乘后除（此处恰好整除，顺序无碍，但保持习惯避免截断错误）。
