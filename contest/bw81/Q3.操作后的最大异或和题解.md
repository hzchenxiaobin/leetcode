# LeetCode 操作后的最大异或和 题解

## 1. 题目概述

- **标题 / 题号**：操作后的最大异或和（#2317，medium）
- **链接**：https://leetcode.cn/problems/maximum-xor-after-operations/
- **来源**：LeetCode 第 81 场双周赛 Q3
- **难度**：中等
- **标签**：位运算、数组、数学

**题意**：给定整数数组 `nums`。一次操作可以选择任意非负整数 $x$ 和下标 $i$，把 $nums[i]$ 更新为 $nums[i] \text{ AND } (nums[i] \text{ XOR } x)$。可以执行**任意次**操作，求最终数组所有元素**逐位异或和**的最大值。

**约束**：

- $1 \le nums.length \le 10^5$
- $0 \le nums[i] \le 10^8$（不足 $2^{27}$，27 个二进制位足够）

## 2. 示例

**示例 1**

```text
输入：nums = [3,2,4,6]
输出：7
解释：选 x = 4、i = 3：nums[3] = 6 AND (6 XOR 4) = 6 AND 2 = 2，
数组变 [3,2,4,2]，异或和 = 3 XOR 2 XOR 4 XOR 2 = 7。
```

**示例 2**

```text
输入：nums = [1,2,3,9,2]
输出：11
解释：不做任何操作，异或和 = 1 XOR 2 XOR 3 XOR 9 XOR 2 = 11。
```

**示例 3（边界补充）**

```text
输入：nums = [0]
输出：0
解释：0 无法通过操作变成非 0，异或和恒为 0。
```

## 3. 解题思路

### 3.1 暴力思路

注意到操作**只会让数值变小**（见 3.2），因此每个 $nums[i]$ 最终能取到的值是其二进制表示的某个**子掩码**（自己为 1 的位可以保留或清 0，为 0 的位不能变 1）。暴力枚举每个元素取哪个子掩码再求异或和最大值：单元素最多 $2^{27}$ 个子掩码，组合数是天文数字，不可行；即便 $n \le 3$、值 $\le 15$ 时可用于对拍（本文正是这么做验证的），正式解法必须挖掘结构。

### 3.2 核心观察一：操作的代数本质是「按位清除」

![核心观察：操作等价于按位清除](images/bw81_q3_bit_independence.svg)

对单个二进制位 $b$（设 $nums[i]$ 在该位为 $b$，$x$ 在该位为 $y$）：

$$
b \text{ AND } (b \text{ XOR } y)
$$

- $b = 1$：结果为 $1$ AND $\bar{y}$，即 $y = 0$ 时保持 1、$y = 1$ 时变 0；
- $b = 0$：结果恒为 0。

换言之 $nums[i] \text{ AND } (nums[i] \text{ XOR } x) = nums[i] \text{ AND } \lnot x$（按位）。**操作能把任意一个（或多个）为 1 的位清成 0，却永远不能把 0 变成 1**。特别地，取 $x = nums[i]$ 得 $nums[i]$ AND 0 = 0，单次操作可把整个数清零；取 $x = 0$ 则数值不变（操作次数可以随便用，做无用操作无妨）。

### 3.3 核心观察二：按位独立 + 「一个 1 传全队」

![位的多数派调整](images/bw81_q3_majority_adjust.svg)

异或是按位独立的：某一位上异或结果为 1，当且仅当该位为 1 的元素个数是**奇数**。对固定的二进制位 $t$：

- 若初始该位为 1 的元素有**奇数**个：什么都不做，异或后该位就是 1；
- 若有**偶数**个（至少 2 个）：任选其中一个元素，用一次操作把**仅该位**清 0（取 $x$ 为「只有第 $t$ 位为 1」的掩码，且该元素第 $t$ 位为 1；清位后其余位不变，因为其他位要么本就是 0 要么 $x$ 对应位为 0 保持原值）——1 的个数从偶数变奇数，异或后该位为 1。

关键在于**这次清位操作不影响其他位**：$x$ 只在第 $t$ 位为 1，其他位 $x$ 为 0 → 该元素其他位保持不变；更不影响其他元素。于是每一位都能独立调度。反之，某位**全为 0** 时没有任何 1 可供清零或保留，该位异或必为 0——这正是答案的上界。

**结论**：某位最终能为 1 ⇔ 该位初始**至少有一个**元素为 1。把所有这样的位拼起来：

$$
\text{最大异或和} = nums[0] \text{ OR } nums[1] \text{ OR } \cdots \text{ OR } nums[n-1]
$$

### 3.4 示例演算

![示例演算：按位 OR](images/bw81_q3_example_walkthrough.svg)

**示例 1**：$[3,2,4,6] = [011, 010, 100, 110]_2$。

| 位 | 含 1 的元素 | 1 的个数 | 奇偶 | 处理 |
|----|------------|---------|------|------|
| 位 0 | 3 | 1 | 奇 | 保持，异或位 = 1 |
| 位 1 | 3、2、6 | 3 | 奇 | 保持，异或位 = 1 |
| 位 2 | 4、6 | 2 | 偶 | 清掉 6 的该位（即官方的 $x=4, i=3$），异或位 = 1 |

按位 OR $= 111_2 = 7$ ✓。注意 $7 > \max(nums) = 6$：答案与单元素大小无关，只由「哪些位出现过 1」决定。

**示例 2**：$[1,2,3,9,2] = [0001, 0010, 0011, 1001, 0010]_2$，按位 OR $= 1011_2 = 11$，无需任何操作（位 0 三个 1、位 1 三个 1、位 3 一个 1，全为奇数）。

## 4. 算法细节

1. **一行求 OR**：`for (v : nums) orAll |= v;` 即答案，无需任何额外数据结构。
2. **为什么「偶数个 1」要清而不是「凑偶变奇」**：操作只能减不能增，把一个 1 清成 0 使计数 $-1$、奇偶翻转；这是唯一的方向，也正是充分的方向。
3. **操作次数无限制**：题目允许任意次（包括 0 次），做「清 0 的清位」永远可行；不需要记录用了多少次。
4. **值的范围**：$nums[i] \le 10^8 < 2^{27}$，`int` 足够，无溢出问题；异或和也不超过 $2^{27} - 1$。
5. **清位 $x$ 的构造**（证明与构造细节）：设位 $t$ 上有元素 $a$ 为 1，取 $x = 2^t$。则 $a \text{ AND } (a \text{ XOR } x)$ 只把 $a$ 的第 $t$ 位清 0，其余位不变（第 $t$ 位外 $x$ 均为 0，AND 上原值保持）。这说明「单点单清」总是可实现的原子操作。

## 5. 正确性证明

**引理 1（操作的不增性）**：对任意 $x$，$nums[i] \text{ AND } (nums[i] \text{ XOR } x)$ 逐位等于 $nums[i] \text{ AND } \lnot x$，是 $nums[i]$ 的子掩码（新值的每个为 1 的位在原值中也为 1）。

**证明**：逐位验证。位 $t$ 上设原值为 $b$、$x$ 为 $y$：结果位 $= b \text{ AND } (b \text{ XOR } y)$。若 $b = 0$：$0$ AND 任何值 $= 0$。若 $b = 1$：$1 \text{ XOR } y = \lnot y$，结果位 $= \lnot y$。故结果位 $= b \text{ AND } \lnot y$，即「$b$ 为 1 且 $y$ 为 0」时为 1，其余为 0。每位上结果位为 1 蕴含 $b = 1$，故新值是原值的子掩码。∎

**引理 2（单点单清可实现）**：若元素 $a$ 的第 $t$ 位为 1，则存在一次操作把 $a$ 变为「第 $t$ 位清 0、其余位不变」的值。

**证明**：取 $x = 2^t$。$x$ 仅第 $t$ 位为 1。由引理 1 的逐位公式，第 $t$ 位：$1$ AND $\lnot 1 = 0$；其他位 $t'$：$b_{t'}$ AND $\lnot 0 = b_{t'}$。故恰好只清第 $t$ 位。∎

**引理 3（上界）**：最终异或和的每个二进制位为 1 的必要条件是：初始至少一个元素在该位为 1。因此异或和 $\le$ 全体元素的按位 OR。

**证明**：由引理 1，任意时刻每个元素的每个为 1 的位在初始值中即为 1（子掩码关系传递）。若初始某位全为 0，则任意时刻该位全为 0，其异或（0 的偶数个或任意个的异或）为 0。故该位不可能贡献 1。∎

**定理**：最优异或和恰等于全体元素的按位 OR。

**证明**：上界由引理 3 给出，只需构造达到。对按位 OR 中每个为 1 的位 $t$：初始 1 的个数为 $k_t \ge 1$。若 $k_t$ 为奇数，不作操作，该位异或为 1；若 $k_t$ 为偶数（$\ge 2$），由引理 2 对任意一个该位为 1 的元素执行单点单清，使 $k_t$ 变为 $k_t - 1$（奇数）。各位的清位操作互不干扰（引理 2 保证只动目标位、且不同位的操作作用于同一元素时效果按位叠加：先清位 $t_1$ 再清位 $t_2$ 的复合仍是各目标位的清除，因为每次操作后的值仍是原值的子掩码且第 $t_2$ 位保持为 1——除非 $t_1 = t_2$，而每个位至多清一次）。全部处理完后，每个 OR 中为 1 的位上 1 的个数均为奇数，异或该位为 1；OR 中为 0 的位全为 0。故异或和逐位等于按位 OR。∎

## 6. 复杂度分析

- **时间**：$O(n)$——一遍求按位 OR，每个元素一次 OR 赋值；$n \le 10^5$ 毫秒级完成。
- **空间**：$O(1)$ 额外空间（一个累加变量）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maximumXOR(vector<int>& nums) {
        int orAll = 0;
        for (int v : nums) orAll |= v;   // 每个二进制位独立：只要有一个数为 1，该位最终可为 1
        return orAll;
    }
};
```

### Python

```python
class Solution:
    def maximumXOR(self, nums: list[int]) -> int:
        or_all = 0
        for v in nums:                    # 每个二进制位独立：只要有一个数为 1，该位最终可为 1
            or_all |= v
        return or_all
```

> 💡 两份代码均通过官方 2 个示例；并与「枚举每个元素的全部子掩码组合求最大异或」的暴力实现做了 **3000 组随机对拍**（$n \le 3$、值 $\le 15$，共 $16^3$ 种子掩码组合全枚举），`mismatch = 0`；另有 400 组大值（至 $10^8$）C++/Python 跨语言一致性验证。

## 8. 边界情况与易错点

1. **全 0 数组**：OR 为 0，答案 0——操作无法无中生有。
2. **单元素数组**：答案是它本身（可以不动它；任何子掩码的异或都不超过它，因为单元素异或和就是它自己）。
3. **误以为要做操作模拟**：题目问的是最大值而非具体操作序列，识别出「按位独立 + 只减不增」后直接 OR 收工；反过来若误以为可以置 1（把 AND 看成 OR），会得出错误答案 $2^{27}-1$ 之类的荒谬结论。
4. **`x` 的取值范围**：题目允许 $x$ 为任意非负整数，位级别的构造（$x = 2^t$）总在其内；不要把 $x$ 限制在数组元素里。
5. **与「最大异或对」题混淆**：本题是全体元素的异或，不是选两元素的异或对（那需要 01-Trie）——考场上读清题意能省半小时。
