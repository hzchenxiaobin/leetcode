# LeetCode k-avoiding 数组的最小总和 题解

## 1. 题目概述

- **标题 / 题号**：k-avoiding 数组的最小总和（#2829，medium）
- **链接**：https://leetcode.cn/problems/determine-the-minimum-sum-of-a-k-avoiding-array/
- **来源**：LeetCode 第 359 场周赛 Q2
- **难度**：中等
- **标签**：贪心、数学

**题意**：给定两个整数 $n$ 和 $k$。一个由**互不相同的正整数**组成的数组，若其中不存在任何**两个不同元素**之和恰好等于 $k$，则称其为 k-avoiding 数组。返回长度为 $n$ 的 k-avoiding 数组的可能的最小总和。

**约束**：

- $1 \le n, k \le 50$

> 💡 两处关键审题：
>
> 1. **「不同元素对」**——元素互异意味着 $x + x = k$ 需要**两个**值为 $k/2$ 的元素，而数组里每个值只有一个。所以 $k$ 为偶数时 $k/2$ **可以**入选。示例 1 的 $[1,2,4,5,6]$（$k = 4$）恰好印证：数组含 $2$，不必担心 $2 + 2 = 4$。
> 2. **数据范围极小**（$n, k \le 50$）——$O(n + k)$ 的贪心模拟轻松通过，但这题还能一步到位推出 $O(1)$ 闭式，值得复盘。

## 2. 示例

**示例 1**

```text
输入：n = 5, k = 4
输出：18
解释：k-avoiding 数组 [1,2,4,5,6] 的总和为 18。
3 被跳过：1 + 3 = 4，与已选的 1 冲突；4、5、6 的克星（0、−1、−2）都不是正整数，安全。
```

**示例 2**

```text
输入：n = 2, k = 6
输出：3
解释：[1,2] 即合法：1 + 2 = 3 ≠ 6，且不存在总和更小的方案。
```

**示例 3**（自造，覆盖 $n > \lfloor k/2 \rfloor$ 的结构）

```text
输入：n = 6, k = 5
输出：29
解释：前缀取 {1,2}（3 被 2 封锁、4 被 1 封锁），剩余从 k=5 起连续取 {5,6,7,8}，
总和 3 + 26 = 29。
```

## 3. 解题思路

### 3.1 暴力思路

最朴素的做法：从正整数中枚举 $n$ 个互异的数，检查所有数对之和 $\ne k$，取总和最小者。数值上界不难估计——最优解的每个元素都不超过贪心解的最大值 $k + n - 1 \le 99$，但组合数 $\binom{99}{50}$ 是天文数字，完全枚举只能验证 $n \le 8$ 左右的极小数据。

暴力低效的根源是**把约束当成黑盒做全枚举**。而本题的约束结构其实极其特殊：每个数至多与**一个**数冲突。

### 3.2 核心观察：冲突图是匹配 → 贪心 + 闭式

![核心观察：x 的唯一克星是 k−x，冲突对构成匹配](images/kavoid_pair_matching.svg)

三条观察：

1. **冲突结构是匹配**：$x$ 与 $y$ 冲突 $\iff x + y = k \iff y = k - x$。每个正整数至多有一个「克星」；$k$ 为偶数时 $k/2$ 的克星是它自己，但互异元素不存在自配对，等于**没有克星**。
2. **前缀安全**：$1 \sim \lfloor k/2 \rfloor$ 中任意两数之和 $\le \lfloor k/2 \rfloor - 1 + \lfloor k/2 \rfloor \le k - 1 < k$，可以**全部取走**，一个不漏。
3. **断带与续取**：前缀取满后，$x \in [k - \lfloor k/2 \rfloor,\; k - 1]$ 这一段全被封锁（克星 $k - x$ 落在前缀里），而 $x \ge k$ 时克星 $k - x \le 0$ 永不在数组中——所以剩余的数恰好从 $k$ 开始**连续**取：$k, k+1, \dots, k+r-1$。

于是最优数组的结构被唯一确定：

$$G = \{1, 2, \dots, t\} \cup \{k, k+1, \dots, k+r-1\}, \qquad t = \min\!\big(n,\ \lfloor k/2 \rfloor\big),\quad r = n - t$$

最小总和的闭式：

$$\text{ans} = \underbrace{\frac{t(t+1)}{2}}_{1 + 2 + \cdots + t} + \underbrace{rk + \frac{r(r-1)}{2}}_{k + (k+1) + \cdots + (k+r-1)}$$

> ⚠️ 两处最容易写错：前缀上界是 $\lfloor k/2 \rfloor$ 而**不是** $\lfloor (k-1)/2 \rfloor$（$k$ 偶数时 $k/2$ 可取）；剩余段从 $k$ 开始而**不是** $k+1$（$k$ 的克星是 $0$，不在数组中，$k$ 本身安全）。

### 3.3 算法流程

![算法流程：从小到大扫描，见安全数就取](images/kavoid_greedy_flow.svg)

比赛时推荐写**贪心模拟**，把上述结构当作自然涌现的结果而不是手推公式：

1. 维护已选集合 `picked`，候选 $x$ 从 $1$ 起递增；
2. 若 $k - x \notin \text{picked}$，则选入 $x$；
3. 选满 $n$ 个数即停止，返回总和。

条件 $k - x \notin \text{picked}$ **天然处理**了 $k$ 偶数的自配对：$x = k/2$ 时克星就是 $x$ 自己，尚未入集合，不会被误封。追求 $O(1)$ 则直接代入闭式。

### 3.4 示例演算

![示例演算：n=5, k=4 的贪心走查表](images/kavoid_example_walkthrough.svg)

以 $n = 5,\ k = 4$ 逐步走查：

| x | k−x | k−x 已选？ | 决策 | picked | sum |
|---|-----|-----------|------|--------|-----|
| 1 | 3 | 否 | 选 1 | {1} | 1 |
| 2 | 2 | 否（2 自己未选） | 选 2 | {1,2} | 3 |
| 3 | 1 | **是** | 跳过 | {1,2} | 3 |
| 4 | 0 | 否（0 非正整数） | 选 4 | {1,2,4} | 7 |
| 5 | −1 | 否（克星为负） | 选 5 | {1,2,4,5} | 12 |
| 6 | −2 | 否 | 选 6 | {1,2,4,5,6} | **18** |

选满 $n = 5$ 个，返回 $18$，与示例一致。注意 $x = 2$ 这一行：$k - x = x$ 的自配对情形被「未选」判定自然放行；$x = 3$ 这一行是被封锁的唯一情形。

## 4. 算法细节

1. **判定容器**：用哈希 `set` 维护已选数即可；值域 $\le k + n - 1 \le 99$，也可开长度 $k + n$ 的布尔数组换 $O(1)$ 判定。
2. **循环终止**：条件用「已选个数 $< n$」。候选 $x$ 至多扫到 $k + n - 1$：全程被封锁的数只有 $[k - \lfloor k/2 \rfloor,\ k - 1]$ 这至多 $\lfloor k/2 \rfloor$ 个，其余每步必进一个。
3. **闭式版**：$r = 0$（即 $n \le \lfloor k/2 \rfloor$）时第二项为 $0$，前缀 $1 \sim n$ 直接就是答案，公式无需特判。
4. **数值范围**：最大和出现在 $n = k = 50$：$t = 25$，$\text{ans} = 325 + 1250 + 300 = 1875$，`int` 足够。

## 5. 正确性证明

**引理 1（冲突唯一性与前缀安全）**：互异正整数 $x, y$ 冲突当且仅当 $y = k - x$；且 $1 \sim \lfloor k/2 \rfloor$ 中任意两个不同数之和不等于 $k$。

**证明**：$x + y = k \iff y = k - x$。对 $x < y \le \lfloor k/2 \rfloor$，有 $x + y \le (\lfloor k/2 \rfloor - 1) + \lfloor k/2 \rfloor \le k - 1 < k$。∎

**引理 2（构造合法性）**：$G = \{1..t\} \cup \{k..k+r-1\}$（$t = \min(n, \lfloor k/2 \rfloor)$，$r = n - t$）是 k-avoiding 的。

**证明**：任取 $G$ 中两个不同元素，分三类：

- **都在前缀**：$t \le 1$ 时不存在这样的数对；$t \ge 2$ 时两数之和 $\le t + (t - 1) \le 2\lfloor k/2 \rfloor - 1 \le k - 1 < k$；
- **都在后段**：两数之和 $\ge k + k = 2k > k$；
- **一小一大**：两数之和 $\ge 1 + k > k$。

三类之和均不等于 $k$，故 $G$ 合法。∎

**引理 3（小数配额）**：任何 k-avoiding 集合中，小于 $k$ 的元素至多 $\lfloor k/2 \rfloor$ 个。

**证明**：把 $1 \sim k-1$ 按和为 $k$ 配对。$k$ 为奇数时恰为 $\frac{k-1}{2}$ 对 $\{j,\ k-j\}$，划分全部 $k-1$ 个数；$k$ 为偶数时为 $\frac{k}{2} - 1$ 对，外加 $k/2$ 一个落单（它与自身之和为 $k$，但「不同元素对」取不到两个 $k/2$）。同一对中的两个数都在集合里即冲突，故集合最多含每对一个、外加落单的 $k/2$：奇数时 $\frac{k-1}{2} = \lfloor k/2 \rfloor$，偶数时 $\frac{k}{2} - 1 + 1 = \lfloor k/2 \rfloor$。∎

**定理**：$G$ 的总和是所有长度为 $n$ 的 k-avoiding 数组中最小的。

**证明**：设 $S$ 为任一 k-avoiding 数组，$|S| = n$。记 $a = |S \cap [1, k-1]|$，$b = n - a$。由引理 3 及 $a \le n$，得 $a \le t$，$b \ge r$。

- $S \cap [1, k-1]$ 是 $a$ 个互异正整数，总和 $\ge 1 + 2 + \cdots + a = \dfrac{a(a+1)}{2}$；
- $S \cap [k, \infty)$ 是 $b$ 个互异且 $\ge k$ 的整数，总和 $\ge k + (k+1) + \cdots + (k+b-1) = bk + \dfrac{b(b-1)}{2}$。

于是 $\text{sum}(S) \ge h(a) := \dfrac{a(a+1)}{2} + (n-a)k + \dfrac{(n-a)(n-a-1)}{2}$。对 $0 \le a \le t - 1$，由 $a + 1 \le t \le \lfloor k/2 \rfloor$ 得 $2a + 2 \le 2\lfloor k/2 \rfloor \le k$，故

$$h(a+1) - h(a) = (2a + 2 - k) - n \le -n < 0$$

即 $h$ 在 $[0, t]$ 上严格递减，最小值在 $a = t$ 处取得：$\text{sum}(S) \ge h(t) = \dfrac{t(t+1)}{2} + rk + \dfrac{r(r-1)}{2} = \text{sum}(G)$。结合引理 2，$G$ 合法且最优。∎

## 6. 复杂度分析

- **时间复杂度**：贪心模拟 $O(n + k)$——候选 $x$ 至多扫描到 $k + n - 1 \le 99$，每个数 $O(1)$ 判定；闭式版 $O(1)$。
- **空间复杂度**：模拟版 $O(n)$（已选集合；值域固定时可用 $O(n + k)$ 布尔数组）；闭式版 $O(1)$。

## 7. 参考代码

### C++（贪心模拟）

```cpp
class Solution {
public:
    int minimumSum(int n, int k) {
        unordered_set<int> picked;
        int sum = 0;
        for (int x = 1; (int)picked.size() < n; ++x) {
            if (!picked.count(k - x)) {   // 克星未选：x 安全
                picked.insert(x);
                sum += x;
            }
        }
        return sum;
    }
};
```

### Python（贪心模拟）

```python
class Solution:
    def minimumSum(self, n: int, k: int) -> int:
        picked = set()
        x = 1
        while len(picked) < n:
            if k - x not in picked:
                picked.add(x)
            x += 1
        return sum(picked)
```

### Python（O(1) 闭式）

```python
class Solution:
    def minimumSum(self, n: int, k: int) -> int:
        t = min(n, k // 2)
        r = n - t
        return t * (t + 1) // 2 + r * k + r * (r - 1) // 2
```

> 💡 比赛时优先写模拟版：不需要推导、不怕公式代错，$O(n+k)$ 在本题范围下与 $O(1)$ 无感知差异。闭式版的价值在于约束放大（见延伸思考）。

## 8. 边界情况与易错点

1. **$k = 1$**：任何两个不同正整数之和 $\ge 1 + 2 = 3 > 1$，无任何冲突，答案为 $1 + 2 + \cdots + n$；闭式中 $t = 0,\ r = n$，公式自然给出该结果。
2. **$k = 2$**：唯一和为 $2$ 的方式是 $1 + 1$（同一元素），同样无冲突；闭式 $t = 1$，也给出 $1 + 2 + \cdots + n$。
3. **$k$ 偶数误封 $k/2$**：把前缀上界写成 $\lfloor (k-1)/2 \rfloor$ 是最常见错误。$n = 3,\ k = 4$：正确答案 $[1,2,4]$ 和 $7$；误封 $2$ 后，$3$ 也被 $1$ 封锁，只能取 $[1,4,5]$ 和 $10$。
4. **剩余段从 $k+1$ 起取**：$k$ 的克星是 $0$，不是正整数，$k$ 本身安全。$n = 3,\ k = 4$：$[1,2,4]$ 和 $7$；若从 $k+1$ 起取则得 $[1,2,5]$ 和 $8$。
5. **循环终止条件**：用「已选个数 $< n$」控制，不要凭感觉写固定扫描上界，避免差一错误。
6. **溢出**：本题最大和 $1875$，`int` 足够；若约束放大需换 `long long`（Python 天然大整数无虞）。
