# LeetCode 销售利润最大化 题解

## 1. 题目概述

- **标题 / 题号**：销售利润最大化（#2830，medium）
- **链接**：https://leetcode.cn/problems/maximize-the-profit-as-the-salesman/
- **来源**：LeetCode 第 359 场周赛 Q3
- **难度**：中等
- **标签**：动态规划、二分查找、排序

**题意**：数轴上有 $n$ 个房屋，编号 $0 \sim n-1$。给定 $m$ 个购买要约 $\text{offers}[i] = [\text{start}_i, \text{end}_i, \text{gold}_i]$：接受要约 $i$ 就要把 $[\text{start}_i, \text{end}_i]$ 内**所有**房屋打包卖给买家 $i$，收入 $\text{gold}_i$ 枚金币。同一房屋不能卖给两个买家，允许部分房屋不出售。求最大总收入。

**约束**：

- $1 \le n \le 10^5$
- $1 \le m = \text{offers.length} \le 10^5$
- $0 \le \text{start}_i \le \text{end}_i \le n - 1$
- $1 \le \text{gold}_i \le 10^3$

> 💡 一句话建模：把每个要约看成数轴上的**闭区间 + 权值**，从中选出一组**两两不相交**的区间，使权值和最大——这就是经典的**带权区间调度**（Weighted Interval Scheduling）。$n$ 本身只是背景板，真正的主角是 $m$ 个区间。

## 2. 示例

**示例 1**

```text
输入：n = 5, offers = [[0,0,1],[0,2,2],[1,3,2]]
输出：3
解释：选 [0,0] 得 1 金 + [1,3] 得 2 金，两区间不相交，共 3 金。
[0,2] 与 [1,3] 共享房屋 1、2，互相冲突，只能二选一。
```

**示例 2**

```text
输入：n = 5, offers = [[0,0,1],[0,2,10],[1,3,2]]
输出：10
解释：只选 [0,2] 得 10 金。注意 [0,0] 与 [0,2] 也共享房屋 0，同样互斥；
「最早结束优先」的贪心会先选走 [0,0] 而错过 10 金——这正是贪心失效的信号。
```

**示例 3**（自造，覆盖「高权区间与后续区间拼接」的情形）

```text
输入：n = 6, offers = [[0,3,5],[1,2,3],[2,5,6],[4,5,4]]
输出：9
解释：[0,3] 得 5 金与 [4,5] 得 4 金不相交，合计 9。
单个 [2,5] 虽值 6 金，但与两个候选都冲突，不划算。
```

## 3. 解题思路

### 3.1 暴力思路

枚举 $2^m$ 个要约子集、检查两两不相交再取最大权值和。$m \le 10^5$，指数级完全不可行；即使 DFS + 剪枝，最坏情况（大量互相兼容的区间）仍会爆炸。低效的根源是**把「不相交」约束当成黑盒整体处理**，而区间冲突其实有很强的**有序结构**可以利用。

### 3.2 核心观察：带权区间调度——按 end 排序，兼容集是前缀

![核心观察：offer 即带权区间，共享房屋即冲突，需选两两不相交的区间](images/wc359_q3_interval_model.svg)

三条观察：

1. **区间建模**：offer $i \leftrightarrow$ 闭区间 $[s_i, e_i]$ 加权 $g_i$。两个 offer 兼容 $\iff$ 区间不相交 $\iff$ $e_j < s_i$ 或 $e_i < s_j$。
2. **带权后贪心失效**：若所有 $g_i$ 相等（无权版，如 LC 435 无重叠区间），「最早结束优先」的贪心是正确的。一旦权值不同就失效——示例 2 中最早结束的 $[0,0]$ 只值 1 金，而与它冲突的 $[0,2]$ 值 10 金。**必须 DP**。
3. **按 $e$ 排序 → 兼容集是前缀**：将 offer 按 $e_i$ 升序排序后，「与 offer $i$ 兼容的所有排在它前面的 offer」恰好是 $\{j : e_j < s_i\}$。由 $e$ 有序，这是一个**连续前缀** $\{1, \dots, p(i)\}$，其长度 $p(i)$ 可以在 end 数组上**二分**得到。这就是「排序 + 二分」的全部依据。

> ⚠️ 为什么不按 $s$ 排序？转移时需要把「所有 $e_j < s_i$」的收益汇总成一个子问题答案，按 $e$ 排序后这些 offer 恰好排成前缀、能二分定位；按 $s$ 排序则 $e$ 的顺序散乱，「前缀」性质不复存在。

### 3.3 算法流程：$dp[i] = \max(dp[i-1],\ dp[p(i)] + g_i)$

![算法流程：按 end 排序后逐 offer 决策，二分求兼容前缀再转移](images/wc359_q3_dp_flow.svg)

设排序后第 $i$ 个 offer 为 $(s_i, e_i, g_i)$（1-based），满足 $e_1 \le e_2 \le \cdots \le e_m$。

- **状态**：$dp[i]$ = 只考虑前 $i$ 个 offer 能取得的最大收益，$dp[0] = 0$。
- **转移**：
  - **不选** offer $i$：收益 $dp[i-1]$；
  - **选** offer $i$：与 $i$ 兼容的前缀是 $\{1..p(i)\}$，收益 $dp[p(i)] + g_i$；
  - $dp[i] = \max\big(dp[i-1],\ dp[p(i)] + g_i\big)$。
- **二分**：$p(i)$ = `lower_bound(ends, s_i)`，即 end 数组中**第一个 $\ge s_i$ 的位置**，恰等于「满足 $e_j < s_i$ 的 offer 个数」，可直接作 dp 下标。
- **答案**：$dp[m]$。

> 💡 换个视角的等价写法（不用二分）：令 $f[i]$ 为房屋 $0..i-1$ 全部处理完时的最大收益，则 $f[i] = f[i-1]$，再对所有 $e = i-1$ 的 offer $(s, g)$ 更新 $f[i] = \max(f[i], f[s] + g)$，答案 $f[n]$。复杂度 $O(n + m)$，代码更短——相当于把「求 $p(i)$」摊还到按位置的扫描里（见 §7 Python 按位置版）。

### 3.4 示例演算

![示例演算：n=5 三个 offer 的 dp 走查表](images/wc359_q3_dp_walkthrough.svg)

以示例 1 走查（先按 $e$ 排序：$(0,0,1) \to (0,2,2) \to (1,3,2)$）：

| i | offer $(s_i, e_i, g_i)$ | $p(i)$ | $\max(dp[i{-}1],\ dp[p]{+}g_i)$ | $dp[i]$ |
|---|------------------------|--------|-------------------------------|---------|
| 1 | $(0, 0, 1)$ | $0$（无 $e_j < 0$） | $\max(0,\ 0+1)$ | $1$ |
| 2 | $(0, 2, 2)$ | $0$（$e_1 = 0$ 不小于 $0$） | $\max(1,\ 0+2)$ | $2$ |
| 3 | $(1, 3, 2)$ | $1$（$e_1 = 0 < 1$） | $\max(2,\ 1+2)$ | $3$ |

返回 $dp[3] = 3$，与示例一致。注意第 2 行：$e_1 = 0 = s_2$，两者共享房屋 0，**等号不算兼容**，故 $p(2) = 0$ 而非 1——这正是二分必须用 `lower_bound` 的原因。

## 4. 算法细节

1. **排序键**：只按 $e$ 升序即可。同 $e$ 的两个 offer 必共享房屋 $e$、互相冲突，谁先谁后不影响正确性（见 §8 第 3 条）。
2. **二分的下标即 dp 下标**：`lower_bound` 返回 0-based 位置 $p$，含义是「前 $p$ 个 offer 的 $e$ 全部 $< s_i$」，恰好都是兼容的，$dp[p]$ 直接可用，**无需 ±1 调整**。
3. **无自引用风险**：$p(i) \le i-1$ 恒成立，因为 $e_i \ge s_i$ 使第 $i$ 个 offer 自己永远不会进入兼容前缀。
4. **数值范围**：收益上界 $10^5 \times 10^3 = 10^8 < 2^{31}$，`int` 足够；约束放大时换 `long long`。
5. **按位置版**：`groups[e]` 收集 $(s, g)$；$f$ 开 $n+1$ 长度；$s = 0$ 时 $f[0] = 0$ 天然正确，无需特判。

## 5. 正确性证明

记 $\mathrm{OPT}(i)$ 为只考虑排序后前 $i$ 个 offer 的最大收益（$\mathrm{OPT}(0) = 0$），$p(i) = \max\{j : e_j < s_i\}$（不存在则为 $0$）。

**引理 1（兼容集是前缀）**：设 $S \subseteq \{1..i\}$ 是包含 offer $i$ 的可行解（区间两两不相交），则 $S \setminus \{i\} \subseteq \{1, \dots, p(i)\}$。

**证明**：任取 $j \in S \setminus \{i\}$，则 $j < i$，故 $e_j \le e_i$。由不相交性，$e_j < s_i$ 与 $e_i < s_j$ 至少其一成立。若后者，则 $e_i < s_j \le e_j \le e_i$，矛盾。故必有 $e_j < s_i$，即 $j \le p(i)$。∎

**引理 2（最优子结构）**：对 $i \ge 1$，$\mathrm{OPT}(i) = \max\big(\mathrm{OPT}(i-1),\ \mathrm{OPT}(p(i)) + g_i\big)$。

**证明**：

- （$\ge$）一方面，$\{1..i-1\}$ 的最优解本身就是 $\{1..i\}$ 的可行解；另一方面，取 $\{1..p(i)\}$ 的最优解 $T$，由 $p(i)$ 的定义 $T$ 中所有 offer 满足 $e < s_i$，故 $T \cup \{i\}$ 仍两两不相交，是可行解，收益为 $\mathrm{OPT}(p(i)) + g_i$。
- （$\le$）设 $S$ 为 $\{1..i\}$ 的任一最优解。若 $i \notin S$，则 $S \subseteq \{1..i-1\}$，$|S| \le \mathrm{OPT}(i-1)$；若 $i \in S$，由引理 1，$S = T \cup \{i\}$ 且 $T$ 是 $\{1..p(i)\}$ 的可行解，故 $|S| = |T| + g_i \le \mathrm{OPT}(p(i)) + g_i$。∎

**定理**：对所有 $0 \le i \le m$ 有 $dp[i] = \mathrm{OPT}(i)$，特别地返回值 $dp[m]$ 为全局最优收益。

**证明**：先注意 $p(i) < i$：若 $j > i$ 且 $e_j < s_i$，则 $e_j < s_i \le e_i \le e_j$，矛盾；又 $e_i \ge s_i$ 排除 $j = i$。对 $i$ 归纳：$dp[0] = \mathrm{OPT}(0) = 0$；设结论对一切 $< i$ 成立，则由引理 2 与 $p(i) < i$，

$$dp[i] = \max\big(dp[i-1],\ dp[p(i)] + g_i\big) = \max\big(\mathrm{OPT}(i-1),\ \mathrm{OPT}(p(i)) + g_i\big) = \mathrm{OPT}(i). \qquad \blacksquare$$

> 💡 按位置版的正确性同构：$f[i]$ 恰是「只考虑 $e < i$ 的 offer 的最优值」。归纳于 $i$：转移只引用 $f[i-1]$ 与 $f[s]$（$s \le i-1$），均已算出；「接受 $(s, i-1, g)$」对应的最优子结构正是引理 2 的第二种情形，只是把 $p(\cdot)$ 的计算摊还进按位置的扫描。

## 6. 复杂度分析

- **时间复杂度**：排序 $O(m \log m)$；主循环 $m$ 次、每次二分 $O(\log m)$，共 $O(m \log m)$。**与 $n$ 无关**（按位置版为 $O(n + m)$）。
- **空间复杂度**：`ends` 与 `dp` 各 $O(m)$；排序递归栈 $O(\log m)$。按位置版为 `groups` 与 `f` 的 $O(n + m)$。

## 7. 参考代码

### C++（排序 + 二分）

```cpp
class Solution {
public:
    int maximizeTheProfit(int n, vector<vector<int>>& offers) {
        sort(offers.begin(), offers.end(),
             [](const vector<int>& a, const vector<int>& b) { return a[1] < b[1]; });
        int m = offers.size();
        vector<int> ends(m);
        for (int i = 0; i < m; ++i) ends[i] = offers[i][1];
        vector<int> dp(m + 1, 0);
        for (int i = 1; i <= m; ++i) {
            int s = offers[i - 1][0], g = offers[i - 1][2];
            // p = 首个 e_j >= s 的下标 = 「e_j < s 的 offer 个数」，即兼容前缀长度
            int p = lower_bound(ends.begin(), ends.end(), s) - ends.begin();
            dp[i] = max(dp[i - 1], dp[p] + g);
        }
        return dp[m];
    }
};
```

### Python（排序 + 二分）

```python
from bisect import bisect_left

class Solution:
    def maximizeTheProfit(self, n: int, offers: List[List[int]]) -> int:
        offers.sort(key=lambda o: o[1])
        ends = [o[1] for o in offers]
        m = len(offers)
        dp = [0] * (m + 1)
        for i, (s, e, g) in enumerate(offers):
            p = bisect_left(ends, s)          # 首个 e_j >= s 的下标
            dp[i + 1] = max(dp[i], dp[p] + g)
        return dp[m]
```

### Python（按位置扫描，免二分）

```python
class Solution:
    def maximizeTheProfit(self, n: int, offers: List[List[int]]) -> int:
        groups = [[] for _ in range(n)]
        for s, e, g in offers:
            groups[e].append((s, g))
        f = [0] * (n + 1)                     # f[i]：房屋 0..i-1 处理完毕的最大收益
        for i in range(1, n + 1):
            f[i] = f[i - 1]                   # 房屋 i-1 不卖
            for s, g in groups[i - 1]:        # 所有恰好终止于 i-1 的要约
                f[i] = max(f[i], f[s] + g)
        return f[n]
```

> 💡 比赛时的取舍：二分版是带权区间调度的**通用模板**（区间端点来自任意实数/稀疏大坐标时依然成立），按位置版代码更短但依赖坐标稠密（$O(n)$）。本题两者都轻松通过，建议掌握二分版以便迁移。

## 8. 边界情况与易错点

1. **二分必须用 `lower_bound` 而非 `upper_bound`**：$e_j = s_i$ 时两个 offer 共享房屋 $s_i$，**冲突**，必须排除在兼容前缀之外。`lower_bound(s)` 找第一个 $\ge s$ 的位置恰好排除等号；误用 `upper_bound` 会把 $e_j = s_i$ 的 offer 错误计入，示例 1 第 2 行（$e_1 = 0 = s_2$）即会算错为 $dp[2] = 3$。
2. **dp 下标偏移**：$dp$ 是 1-based（前 $i$ 个 offer），`ends` 是 0-based；`lower_bound` 的返回值直接可作 dp 下标，多写一次 `±1` 反而会错。
3. **同 end 的 offer 必互斥**：都包含房屋 $end$，排序时无需次级关键字，不影响正确性。
4. **无自引用**：$p(i) \le i-1$ 由 $e_i \ge s_i$ 保证，$dp[p(i)]$ 恒已初始化。
5. **全正权值**：$g_i \ge 1$，不存在「选了亏本」，$dp$ 单调不减，可用于自检。
6. **溢出**：上界 $10^5 \times 10^3 = 10^8 < 2^{31}$，`int` 足够；约束放大时换 `long long`（Python 无虞）。
7. **按位置版的数组边界**：`f` 长 $n+1$；`groups[e]` 的 $e$ 最大 $n-1$；$s = 0$ 时 $f[0] = 0$ 天然正确。
8. **$n$ 维度陷阱**：按位置版 $O(n + m)$ 在 $n$ 巨大（如 $10^9$）时不可行，应改用与 $n$ 无关的二分版。
