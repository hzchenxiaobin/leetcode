# LeetCode 判别首字母缩略词 题解

## 1. 题目概述

- **标题 / 题号**：判别首字母缩略词（#2828，easy）
- **链接**：https://leetcode.cn/problems/check-if-a-string-is-an-acronym-of-words/
- **来源**：LeetCode 第 359 场周赛 Q1
- **难度**：简单
- **标签**：数组、字符串

**题意**：给定字符串数组 `words` 和字符串 `s`。若**按顺序串联** `words` 中每个字符串的**第一个字符**恰好得到 `s`，则 `s` 是 `words` 的首字母缩略词。是则返回 `true`，否则返回 `false`。例如 `"ab"` 可以由 `["apple", "banana"]` 形成，但无法从 `["bear", "aardvark"]` 形成。

**约束**：

- $1 \le \text{words.length} \le 100$
- $1 \le \text{words[i].length} \le 10$
- $1 \le \text{s.length} \le 100$
- `words[i]` 和 `s` 由小写英文字母组成

> 💡 约束 $\text{words[i].length} \ge 1$ 保证每个单词**必然存在首字符**，`words[i][0]` 永不越界，签到时无需为空串写特判。

## 2. 示例

**示例 1**

```text
输入：words = ["alice","bob","charlie"], s = "abc"
输出：true
解释：三个单词的首字符分别是 'a'、'b'、'c'，串联得到 "abc"。
```

**示例 2**

```text
输入：words = ["an","apple"], s = "a"
输出：false
解释：两个单词的首字符串联得到 "aa"，长度 2 ≠ |s| = 1。
```

**示例 3**

```text
输入：words = ["never","gonna","give","up","on","you"], s = "ngguoy"
输出：true
解释：按序串联六个首字符，恰好得到 "ngguoy"。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的写法：把每个单词的首字符抽出来拼成新字符串 $t$，再整体比较 $t$ 是否等于 $s$。这已经是线性复杂度，能直接通过，但有两处可省的开销：

1. **拼接浪费空间**：构建 $t$ 需要 $O(n)$ 额外空间，而比较本质上只需逐位进行；
2. **长度不等时白拼**：如示例 2 中 $n = 2$、$|s| = 1$，拼完 $t = \text{"aa"}$ 再比较必然不等——长度这一必要条件可以在拼接**之前**以 $O(1)$ 代价排除。

### 3.2 核心观察：长度不变式 + 逐位比较

![核心观察：按序抽取首字符，与 s 逐位对齐](images/acronym_check_concept.svg)

两条关键观察：

1. **长度不变式**：缩略词由每个单词**恰好贡献 1 个字符**串联而成，因此 $s$ 是首字母缩略词的必要条件是 $|\text{words}| = |s|$。把长度检查放在最前面，可对示例 2 这类输入以 $O(1)$ 代价整体短路。

2. **无需显式拼接**：拼接结果 $t$ 的第 $i$ 位**就是** $\text{words}[i][0]$，因此逐位比较 $\text{words}[i][0]$ 与 $s[i]$ 即可，任何一位失配立即返回 `false`。

形式化地：

$$s \text{ 是 } \text{words} \text{ 的首字母缩略词} \iff |\text{words}| = |s| \;\land\; \forall i \in [0, n):\; \text{words}[i][0] = s[i]$$

> ⚠️ 与「子序列」类匹配不同，这里是**严格逐位对齐**：第 $i$ 个单词只对应 $s$ 的第 $i$ 位，不存在「跳过谁」的自由度，连双指针都不需要，单层下标循环即可。同时注意**顺序敏感**：`["bear","aardvark"]` 只能拼出 `"ba"`，拼不出 `"ab"`。

### 3.3 算法流程

![算法流程：长度短路 + 单趟逐位比对](images/acronym_check_flow.svg)

流程概括为三步：

1. **长度检查**：$|\text{words}| \ne |s|$ 直接返回 `false`（短路点①）；
2. **单趟逐位比对**：检查每个 $\text{words}[i][0]$ 是否等于 $s[i]$，失配立即返回 `false`（短路点②）；
3. **收尾**：$n$ 位全部通过，返回 `true`。

### 3.4 示例演算

![示例演算：单趟逐位比对 vs 长度短路](images/acronym_example_walkthrough.svg)

以示例 3 `words = ["never","gonna","give","up","on","you"]`、`s = "ngguoy"` 为例，逐位追踪：

| i | words[i] | 首字符 | s[i] | 匹配 |
|---|----------|--------|------|------|
| 0 | "never" | n | n | ✓ |
| 1 | "gonna" | g | g | ✓ |
| 2 | "give" | g | g | ✓ |
| 3 | "up" | u | u | ✓ |
| 4 | "on" | o | o | ✓ |
| 5 | "you" | y | y | ✓ |

六位全部通过，$i$ 走到 $n = 6$，返回 `true`。

而示例 2 在第一步就被拦下：$|\text{words}| = 2 \ne 1 = |s|$，长度不等，**一位都不用比**，直接返回 `false`。

## 4. 算法细节

1. **长度检查前置**：`len(words) == len(s)` 是 $O(1)$ 可得的必要条件，先比长度是最便宜的拒绝路径。
2. **逐位比较**：只需比较 $\text{words}[i][0]$ 与 $s[i]$，取首字符 $O(1)$，与单词长度无关；失配立即返回，实现提前退出。
3. **Python 一行写法的陷阱**：`zip` 会**静默截断**到较短的一方，且 `all()` 对空迭代返回 `True`——若去掉长度检查，`words = ["ab"]`、`s = "abcdefg"` 会因 `zip` 只配对 1 位而误判为 `True`，因此 `len(words) == len(s)` 前置条件不可省。
4. **空串特判可以省**：约束保证 `words[i]` 非空，直接下标 `[0]` 安全。

## 5. 正确性证明

**引理 1（长度不变式）**：若 $s$ 是 `words` 的首字母缩略词，则 $|\text{words}| = |s|$。

**证明**：缩略词由每个单词恰好一个首字符串联而成，$n = |\text{words}|$ 个单词贡献 $n$ 个字符，故缩略词长度为 $n$。若 $s$ 等于该缩略词，则 $|s| = n$。∎

**引理 2（逐位对应）**：设 $t$ 为按序串联 $\text{words}[i][0]$ 得到的字符串，则对任意 $i \in [0, n)$，$t[i] = \text{words}[i][0]$。

**证明**：对 $t$ 的归纳构造：$t$ 由首字符按数组顺序拼接，第 $i$ 个被拼接的字符即 $\text{words}[i][0]$，拼接不改变已有前缀，故 $t$ 的第 $i$ 位恰为第 $i$ 个被拼接的字符。∎

**定理**：算法返回 `true` 当且仅当 $s$ 是 `words` 的首字母缩略词。

**证明**：

- **必要性**：若 $s$ 是缩略词，由引理 1 长度检查通过；由引理 2 与 $s = t$ 得每一位 $\text{words}[i][0] = t[i] = s[i]$，逐位比较全部通过，算法返回 `true`。
- **充分性**：若算法返回 `true`，则长度检查通过且每位 $\text{words}[i][0] = s[i]$。由引理 2，拼接结果 $t$ 与 $s$ 长度相同（均为 $n$）且每一位相等，故 $t = s$，即 $s$ 是首字母缩略词。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$，其中 $n = |\text{words}|$。长度检查 $O(1)$；逐位比较至多 $n$ 次，每次只取首字符 $O(1)$，与单词长度无关。
- **空间复杂度**：$O(1)$。逐位比较版不构建新串，仅用下标与字符变量；若用 `join` 拼接后比较则需 $O(n)$ 额外空间。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool isAcronym(vector<string>& words, string s) {
        int n = words.size();
        if (n != (int)s.size()) return false;   // 短路点①：长度不变式
        for (int i = 0; i < n; i++) {
            if (words[i][0] != s[i]) return false;  // 短路点②：失配即退出
        }
        return true;
    }
};
```

### Python

```python
class Solution:
    def isAcronym(self, words: List[str], s: str) -> bool:
        return len(words) == len(s) and all(w[0] == c for w, c in zip(words, s))
```

> 💡 也可写 `"".join(w[0] for w in words) == s`，完全复述题意、可读性最佳，代价是 $O(n)$ 空间且无法提前退出。比赛时两种写法均可，先 A 再说。

## 8. 边界情况与易错点

1. **长度不等**：示例 2 的核心考点，$|\text{words}| \ne |s|$ 必须返回 `false`；用 `zip` 写法时尤为致命（静默截断 + `all` 空真值）。
2. **空单词**：约束保证 $\text{words[i].length} \ge 1$，`words[i][0]` 不会越界；若约束放宽需先判空串。
3. **顺序敏感**：`["bear","aardvark"]` 形成 `"ba"` 而非 `"ab"`，不能排序后比较。
4. **大小写**：题面限定小写字母，等值比较即可；若放开需先归一化。
5. **最小规模**：$n = 1$、$|s| = 1$，单字符也要逐位比，逻辑自然覆盖，无需特判。
