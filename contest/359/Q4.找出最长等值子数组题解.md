# LeetCode 找出最长等值子数组 题解

## 1. 题目概述

- **标题 / 题号**：找出最长等值子数组（#2831，medium）
- **链接**：https://leetcode.cn/problems/find-the-longest-equal-subarray/
- **来源**：LeetCode 第 359 场周赛 Q4
- **难度**：中等
- **标签**：数组、哈希表、双指针、滑动窗口

**题意**：给定长度为 $n$ 的整数数组 `nums` 与整数 $k$。若子数组中所有元素都相等，称其为**等值子数组**（空数组也算）。允许从 `nums` 中**删除最多 $k$ 个元素**，求删完后能得到的最大等值子数组长度。

> 💡 一句话建模：最终答案的等值子数组只含某个值 $v$——保留 $v$ 在原数组中的**一段出现**，把这段出现之间的"杂元素"删掉即可。问题变成：**选一个值 $v$ 和它出现下标列表的一段连续区间 $[i, j]$，使「跨度 − 保留个数」不超过 $k$**，最大化保留个数。

**约束**：

- $1 \le n \le 10^5$
- $1 \le \text{nums}[i] \le n$（值域恰为 $[1, n]$，可按值分桶）
- $0 \le k \le n$

## 2. 示例

**示例 1**

```text
输入：nums = [1,3,2,3,1,3], k = 3
输出：3
解释：删除下标 2（值 2）和下标 4（值 1），nums 变为 [1,3,3,3]，
最长等值子数组是三个 3，长度为 3。
```

**示例 2**

```text
输入：nums = [1,1,2,2,1,1], k = 2
输出：4
解释：删除下标 2、3 的两个 2，nums 变为 [1,1,1,1]，长度 4。
四个 1 分布在下标 [0,1] 与 [4,5]，跨度 6 − 保留 4 = 2 ≤ k。
```

**示例 3**（自造，覆盖 $k=0$ 的边界）

```text
输入：nums = [2,2,2,3,3], k = 0
输出：3
解释：一个元素都不能删，等值子数组只能来自原本连续的相同元素，
即最长连续相等段，这里是三个 2。
```

## 3. 解题思路

### 3.1 暴力思路

等值子数组的值一定是某个 `nums[i]`，设为 $v$。把 $v$ 的出现下标按升序存进列表 $p$，枚举保留段两端 $i, j$（保留 $p_i \sim p_j$ 这一段出现），代价为

$$\text{cost}(i, j) = (p_j - p_i + 1) - (j - i + 1)$$

若 $\text{cost}(i, j) \le k$，候选答案为 $j - i + 1$；对所有值取最大即为答案。单值枚举两端是 $O(m^2)$（$m$ 为该值出现次数），所有元素相同时退化为 $O(n^2) \approx 10^{10}$，不可行。利用「固定 $j$ 时 $\text{cost}$ 关于 $i$ 单调不增」还可对每个 $j$ 二分出最小的合法 $i$，做到 $O(n \log n)$，但仍有大量冗余——低效的根源是**把每个两端组合独立检查**，而代价关于两个端点都是**单调**的。

### 3.2 核心观察：按值分组，代价只取决于保留段两端

![核心观察：保留值 v 的一段出现，删除代价只取决于两端](images/wc359_q4_group_cost_model.svg)

三个关键观察：

1. **只删段内**：要使保留的 $v$ 连续，必须且只需删除「最左保留位置 $p_i$ 到最右保留位置 $p_j$ 之间」的所有非保留元素；**段外的元素一个都不用删**。
2. **段内的 $v$ 全保留**：保留段内的每个 $v$ 出现都让答案 +1、代价 −1，只赚不亏。因此最优保留集合一定是出现列表的一段**连续区间** $[i, j]$，无需枚举任意子集。
3. **代价只依赖两端**：$\text{cost}(i, j) = (p_j - p_i + 1) - (j - i + 1)$，即「跨度 − 保留数」，只由两个下标决定。

### 3.3 算法流程：出现列表上的双指针

![算法流程：出现列表上的双指针](images/wc359_q4_sliding_window_flow.svg)

对每个值 $v$ 的出现列表 $p$ 维护双指针 $i, j$：$j$ 从左到右枚举右端；一旦 $\text{cost}(i, j) > k$ 就右移 $i$ 收缩左端。由单调性（引理 3），$i$ 与 $j$ 都**只进不退**，每个值上均摊 $O(\text{len}(p))$，总计 $O(n)$。

### 3.4 示例演算

![示例演算：值 3 的双指针过程](images/wc359_q4_walkthrough.svg)

以示例 1 的值 $v = 3$（$p = [1, 3, 5]$）为例：右端扩张时代价 $0 \to 1 \to 2$ 始终 $\le k = 3$，左端不动，最长保留 3 个。值 $1$ 最多保留 2 个（代价 3 已顶满预算），值 $2$ 只有 1 个，全局答案为 3。

## 4. 算法细节

1. **分桶**：值域恰为 $[1, n]$，直接开 `pos` 数组（`vector<vector<int>>` 或 `defaultdict(list)`），一次遍历把下标 `i` 追加到 `pos[nums[i]]` 末尾，天然升序，比哈希表更快。
2. **双指针**：对每个 `p = pos[v]`，`i` 从 0 出发；`j` 从左到右枚举，`while cost(i,j) > k` 时 `i++`；每步用 `j - i + 1` 更新答案。
3. **代价的等价写法**：$\text{cost} = (p_j - p_i + 1) - (j - i + 1) = (p_j - p_i) - (j - i)$，即「保留段内的杂元素个数」。循环里用哪种都行，避免重复计算即可。
4. **答案下界**：$n \ge 1$ 且单元素段（$i = j$）代价恒为 $0 \le k$，答案至少为 1，无需特判空数组。

## 5. 正确性证明

以下设 $p$ 为值 $v$ 的出现下标列表（严格递增），$\text{cost}(i, j) = (p_j - p_i + 1) - (j - i + 1)$。

**引理 1（结构引理）**：存在最优方案，其等值子数组由「某个值 $v$ 在某区间 $[a, b]$ 内的全部出现」构成。

**证明**：取任意最优方案，设其最长等值子数组全由 $v$ 组成，元素原下标集合为 $P$，令 $a = \min P,\ b = \max P$。要使这些元素在删除后连续，$a$、$b$ 之间每个不在 $P$ 中的位置都必须被删除，故原方案删除数 $\ge (b - a + 1) - |P|$。构造新方案：删除 $[a, b]$ 内所有非 $v$ 元素、其余不删。其删除数为 $(b - a + 1) - \mathrm{occ}_v(a, b) \le (b - a + 1) - |P| \le k$，而保留的 $v$ 有 $\mathrm{occ}_v(a, b) \ge |P|$ 个且删后连续。新方案不劣于最优解，故也是最优解，且具有所述结构。∎

**引理 2（代价引理）**：保留 $v$ 在 $[a, b]$ 内的全部出现，最少删除数恰为 $(b - a + 1) - \mathrm{occ}_v(a, b)$。

**证明**：$[a, b]$ 内非 $v$ 的元素必须全部删除（否则夹杂在保留元素之间，无法连续），这是下界；只删它们即可让保留的 $v$ 两两紧邻，这是可达上界。对应到出现列表：$a = p_i,\ b = p_j$ 时 $\mathrm{occ}_v(a, b) = j - i + 1$，删除数即 $\text{cost}(i, j)$。∎

**引理 3（单调性引理）**：$\text{cost}(i, j)$ 关于 $i$ 单调不增、关于 $j$ 单调不减。

**证明**：$p$ 严格递增，故 $p_{i+1} - p_i \ge 1$，于是

$$\text{cost}(i+1, j) - \text{cost}(i, j) = 1 - (p_{i+1} - p_i) \le 0$$

同理 $\text{cost}(i, j+1) - \text{cost}(i, j) = (p_{j+1} - p_j) - 1 \ge 0$。∎

**定理**：双指针算法输出最长等值子数组的长度。

**证明**：由引理 3，固定 $j$ 时满足 $\text{cost} \le k$ 的 $i$ 构成后缀 $[i^*(j), j]$（$i = j$ 时 $\text{cost} = 0 \le k$ 恒成立，后缀非空），最优窗口长为 $j - i^*(j) + 1$。又 $j$ 增大时 $\text{cost}(i, j)$ 不减，原本不合法的 $i$ 仍不合法，故 $i^*(j)$ 单调不减。对 $j$ 归纳：算法在处理完 $j-1$ 后 $i = i^*(j-1) \le i^*(j)$，`while` 循环从该位置出发停在第一个合法位置，恰为 $i^*(j)$，故每个 $j$ 的候选 $j - i^*(j) + 1$ 都被正确计算并参与取最大。结合引理 1、2，全局最优 $= \max_v \max_j \big(j - i^*(j) + 1\big)$，即算法输出。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$
  - 分桶遍历 $O(n)$；
  - 每个值上 $i$、$j$ 的总移动量不超过该值出现次数，所有值合计 $\le n$；
  - 每步代价计算 $O(1)$。
- **空间复杂度**：$O(n)$，存所有出现下标。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int longestEqualSubarray(vector<int>& nums, int k) {
        int n = nums.size();
        vector<vector<int>> pos(n + 1);
        for (int i = 0; i < n; ++i)
            pos[nums[i]].push_back(i);

        int ans = 0;
        for (auto& p : pos) {
            int i = 0;
            for (int j = 0; j < (int)p.size(); ++j) {
                while ((p[j] - p[i] + 1) - (j - i + 1) > k)
                    ++i;
                ans = max(ans, j - i + 1);
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def longestEqualSubarray(self, nums: List[int], k: int) -> int:
        pos = defaultdict(list)
        for i, v in enumerate(nums):
            pos[v].append(i)

        ans = 0
        for p in pos.values():
            i = 0
            for j in range(len(p)):
                while (p[j] - p[i] + 1) - (j - i + 1) > k:
                    i += 1
                ans = max(ans, j - i + 1)
        return ans
```

## 8. 边界情况与易错点

1. **收缩条件是 `> k` 而非 `>= k`**：代价恰好等于 $k$ 时合法（预算用满），写成 `>=` 会漏解，典型 off-by-one。
2. **$k = 0$ 退化**：等价于最长连续相等段（$\text{cost} = 0$ 要求 $p_j - p_i = j - i$，即出现位置连续），双指针自然覆盖，无需特判。
3. **代价只算段内**：常见错误是把「整个数组中非 $v$ 元素的个数」当成删除代价；段外元素与目标子数组无关，一个都不用删。
4. **分桶方式**：值域恰为 $[1, n]$ 才能直接开 `n+1` 个桶；若值域放大（如 $10^9$）需改用 `unordered_map` / `defaultdict`，复杂度不变。
5. **别在段内"省着删"**：保留段内的 $v$ 出现一个都不删才是最优（引理 1），枚举出现列表的连续段即可，不必考虑跳着保留的子集。
6. **替代写法的坑**：也可用「整个数组的滑动窗口 + 窗口内众数」求解（答案取窗口内某值的真实频次，条件为窗口长 − 频次 $\le k$，与 LC 424 同款）。但注意 LC 424 的答案是窗口长度、本题答案是频次本身，照搬「历史最大频次不回退」的技巧时正确性论证更绕，且窗口收缩时维护真实最大频次需要额外结构（桶计数）；按值分组的双指针完全避开这些坑。
