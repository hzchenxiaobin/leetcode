# LeetCode 删除字符串中的所有相邻重复项 题解

## 1. 题目概述

- **标题 / 题号**：删除字符串中的所有相邻重复项（#1047，easy）
- **链接**：https://leetcode.cn/problems/remove-all-adjacent-duplicates-in-string/
- **来源**：LeetCode 第 137 场周赛 Q2
- **难度**：简单
- **标签**：栈、字符串

**题意**：给出由小写字母组成的字符串 `s`。「重复项删除操作」会选出**两个相邻且相同**的字母并删除它们。在 `s` 上反复执行该操作直到无法继续，返回最终字符串。题目保证答案唯一。

**约束**：

- $1 \le \lvert s \rvert \le 10^5$
- `s` 仅由小写英文字母组成

**关键概念**：删除一对相邻相同字符后，**原本被这对字符隔开的两侧会变成新的相邻对**——这个「回退」语义正好对应**栈**的 `pop`。

## 2. 示例

**示例 1**

```text
输入："abbaca"
输出："ca"
解释：先删 "bb" 得到 "aaca"，再删 "aa" 得到 "ca"，无法继续。
```

**示例 2**

```text
输入："azxxzy"
输出："ay"
解释：先删 "xx" 得到 "azzy"，再删 "zz" 得到 "ay"。
```

**示例 3（补充）**

```text
输入："aa"
输出：""
解释：一对相同字符直接消掉，结果为空串。
```

## 3. 解题思路

### 3.1 暴力思路

反复扫描字符串，找到相邻相同对就删除，然后**从头重扫**。最坏情况（例如 `"aabbaabb..."`）每删一对都要 $O(n)$ 重扫，总复杂度 $O(n^2)$，$n = 10^5$ 时会超时。

### 3.2 核心观察：栈就是「消去」的数据结构

![栈的消消乐流程](images/wc137_q2_stack_flow.svg)

从左到右扫描字符，维护一个栈表示「**已处理前缀消完后的结果**」：

- 若当前字符 $c$ 与**栈顶**相同，说明这两个字符在消去后必然相邻且相同 → 一起消失，执行 `pop`；
- 否则把 $c$ 压栈。

关键在于：删掉一对字符后，新暴露出来的相邻关系**恰好就是栈顶与下一个字符的关系**，栈天然记住了「回退位置」，所以**一遍扫描**即可，不需要回头重扫。

### 3.3 算法流程

```text
1. stack = 空
2. for c in s:
       若 stack 非空且 stack.top == c:  pop
       否则:                          push(c)
3. 返回 stack 拼成的字符串
```

### 3.4 示例演算

![示例 1 的逐字符演算](images/wc137_q2_example_walkthrough.svg)

对 `"abbaca"`：

| 字符 | 动作 | 栈（自底向上） |
|------|------|----------------|
| a | 压入 | a |
| b | 压入 | a b |
| b | 与栈顶相同 → 弹出 | a |
| a | 与栈顶相同 → 弹出 | （空） |
| c | 压入 | c |
| a | 压入 | c a |

最终栈内容 `"ca"`，与示例输出一致。注意第 4 步的 `a` 弹出，正是「删掉 bb 后原位置 0 与 3 的 a 变成相邻」的体现。

## 4. 算法细节

1. **用 `string` 当栈**：C++ 中用 `string st` 配合 `push_back` / `pop_back`，比 `stack<char>` 更快，最后直接返回 `st`。
2. **Python 用 `list`**：`append` / `pop` / `''.join`，避免字符串拼接的 $O(n^2)$ 开销。
3. **判空后再看栈顶**：`if st and st[-1] == c`，空栈时不能访问栈顶。
4. **一遍扫描的正确性依赖「相邻」语义**：只有**栈顶**可能和当前字符构成相邻对，不需要检查栈中更深的位置。
5. **答案唯一**：题面已保证；实际上这个消去系统是合流的（见引理 2），无论按哪种顺序删，最终范形相同。

## 5. 正确性证明

记 $R(t)$ 为「对前缀 $s[0..t]$ 执行任意次删除操作直到无法继续」得到的字符串（存在性由长度递减保证）。

**引理 1（栈内容即前缀的范形）**：扫描到第 $t$ 个字符后，栈中内容等于 $R(t)$。

**证明**：对 $t$ 归纳。$t = -1$（空前缀）时栈为空，成立。设扫描完前 $t$ 个字符后栈内容为 $R(t)$，考虑第 $t+1$ 个字符 $c$：

- 若栈顶不是 $c$（或栈为空），则 $R(t) + c$ 中 $c$ 与左侧字符不同，无法删除，故 $R(t+1) = R(t) + c$，正是压栈的结果。
- 若栈顶是 $c$，则 $R(t)$ 末尾的 $c$ 与 $c$ 相邻且相同，必被删除，删除后 $R(t)$ 去掉末尾字符，得到 $R(t+1) = R(t)[0..\lvert R(t)\rvert-2]$，正是弹出后的栈内容。

两种情形都与算法一致。∎

**引理 2（结果与删除顺序无关）**：对同一字符串，任意删除顺序得到的最终字符串相同。

**证明**：考虑删除操作的局部合流性。设两种删法分别删除了位置对 $(i, i+1)$ 与 $(j, j+1)$（两对都是相同字符）。若两对不相交，则它们互不影响，可以先删任意一对再删另一对，结果相同；若两对相交（即三段相同字符 $c\,c\,c$），删前两个或后两个都会得到同一个单字符 $c$，结果也相同。由 Newman 引理（局部合流 + 终止 ⇒ 合流），该重写系统合流，故最终范形唯一。∎

**定理**：算法返回的字符串等于把所有相邻重复项删尽后的结果。

**证明**：由引理 1，扫描结束时栈内容等于整个字符串的范形 $R(n-1)$；由引理 2，范形与删除顺序无关，即题面要求的「反复执行直到无法继续」的最终字符串。∎

## 6. 复杂度分析

- **时间**：$O(n)$。每个字符至多入栈一次、出栈一次，每次 $O(1)$。
- **空间**：$O(n)$。栈最坏存下全部字符（例如没有相邻重复时）。

## 7. 参考代码

### C++

```cpp
#include <string>
using namespace std;

class Solution {
public:
    string removeDuplicates(string s) {
        string st;                        // 用 string 当栈
        for (char c : s) {
            if (!st.empty() && st.back() == c) st.pop_back();
            else st.push_back(c);
        }
        return st;
    }
};
```

### Python

```python
class Solution:
    def removeDuplicates(self, s: str) -> str:
        stack = []
        for c in s:
            if stack and stack[-1] == c:
                stack.pop()          # 与前一个字符相同，一起消掉
            else:
                stack.append(c)
        return ''.join(stack)
```

## 8. 边界情况与易错点

1. **空栈访问栈顶**：`stack[-1]` 在空列表上会抛异常（C++ 的 `back()` 是未定义行为），必须先判空。
2. **删除后不回头**：很多人会写成「删除后把指针退回去重扫」，虽然也对，但没必要——栈已经保存了回退位置。
3. **全相同字符**：`"aaaa"` → 消成 `""`（偶数个）或 `"a"`（奇数个），答案长度是 $n \bmod 2$。
4. **含嵌套结构**：`"azxxzy"` 的 `zz` 是删掉 `xx` 之后才相邻的，验证了「回退」语义；忘记这一点会得到错误结果。
5. **`s.length = 1`**：直接返回 `s`。
6. **Python 的字符串拼接**：不要在循环里 `ans += c`（每次都新建字符串，退化为 $O(n^2)$），要用 `list` + `join`。
