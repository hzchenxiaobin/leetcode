# LeetCode 最长字符串链 题解

## 1. 题目概述

- **标题 / 题号**：最长字符串链（#1048，medium）
- **链接**：https://leetcode.cn/problems/longest-string-chain/
- **来源**：LeetCode 第 137 场周赛 Q3
- **难度**：中等
- **标签**：数组、哈希表、双指针、字符串、动态规划、排序

**题意**：给定单词数组 `words`（每个单词仅含小写字母）。若在 `wordA` 的任意位置**插入恰好一个字符**（不改变其余字符顺序）能得到 `wordB`，则称 `wordA` 是 `wordB` 的**前身**。**词链**是一串单词 $[w_1, w_2, \dots, w_k]$，满足 $w_i$ 是 $w_{i+1}$ 的前身。求从给定单词中能选出的**最长词链长度**。

**约束**：

- $1 \le \text{words.length} \le 1000$
- $1 \le \lvert \text{words}[i] \rvert \le 16$
- `words[i]` 仅含小写英文字母

## 2. 示例

**示例 1**

```text
输入：words = ["a","b","ba","bca","bda","bdca"]
输出：4
解释：最长链之一 a → ba → bda → bdca（长度 4）。
```

**示例 2**

```text
输入：words = ["xbc","pcxbcf","xb","cxbc","pcxbc"]
输出：5
解释：xb → xbc → cxbc → pcxbc → pcxbcf（每次插入一个字符）。
```

**示例 3**

```text
输入：words = ["abcd","dbqca"]
输出：1
解释：两个词长度相同，不可能互为前身（前身必须短恰好 1），故最长链长度为 1。
```

## 3. 解题思路

### 3.1 暴力思路

把「前身」关系建图后求最长路径：建图要两两比较 $O(n^2 \cdot L)$，之后在 DAG 上做最长路径。$n \le 1000$ 时 $10^6 \times 16$ 尚可，但建图这一步完全是多余的——**前身关系只可能发生在长度相差 1 的词之间**，而且可以直接由「删一个字符」枚举出来。

### 3.2 核心观察：删字符枚举前身 + 按长度排序

![按长度排序后做 DP](images/wc137_q3_chain_dp.svg)

两个关键点：

1. **前身判定的高效做法**：若 $A$ 是 $B$ 的前身，则 $B$ 的长度恰为 $A$ 的长度 $+1$，且 $A$ 可以由 $B$ **删掉恰好一个字符**得到。于是对每个词 $w$，枚举它的 $|w|$ 种「删一个字符」的结果，逐个到哈希表里查是否存在——比两两比较快得多，也天然避免了「插入位置」的歧义。
2. **按长度排序**：前身一定更短，所以按长度从小到大处理时，$w$ 的所有前身的 `dp` 值都已经算好。链长关系构成一个按长度分层的 DAG，无需拓扑排序，长度序就是拓扑序。

定义 `dp[w]` = 以 $w$ **结尾**的最长词链长度，则

$$dp[w] = 1 + \max_{w' \in \text{pre}(w)} dp[w']$$

其中 $\text{pre}(w)$ 是「删一个字符」得到的、存在于 `words` 中的词（若为空则 $dp[w] = 1$）。答案是所有 `dp[w]` 的最大值。

### 3.3 算法流程

```text
1. 把 words 按长度升序排序
2. dp = 空哈希表（词 → 最长链长）
3. ans = 0
4. for w in words:
       best = 1
       for i in 0 .. |w|-1:
           pre = w 删去第 i 个字符
           若 pre in dp: best = max(best, dp[pre] + 1)
       dp[w] = best
       ans = max(ans, best)
5. 返回 ans
```

### 3.4 示例演算

![示例 1 的分层 DP](images/wc137_q3_example_walkthrough.svg)

对 `["a","b","ba","bca","bda","bdca"]`，按长度排序后依次处理：

| 词 | 删一个字符得到的候选前身 | 存在的候选 | $dp$ |
|----|--------------------------|-----------|------|
| a | `""` | — | 1 |
| b | `""` | — | 1 |
| ba | `a`（删 b）、`b`（删 a） | a, b | 2 |
| bca | `ca`、`ba`、`bc` | ba | 3 |
| bda | `da`、`ba`、`bd` | ba | 3 |
| bdca | `dca`、`bca`、`bda`、`bdc` | bca, bda | **4** |

最大值为 4，对应链 `a → ba → bda → bdca`。

## 4. 算法细节

1. **`dp` 用哈希表**：键是字符串本身（长度 ≤ 16），查表 $O(1)$（均摊）；比用下标数组 + 映射更直观。
2. **重复单词**：若 `words` 中有重复词，`dp[w]` 会被覆盖成相同的值（因为它们长度为 $L$，不能互为前身），不影响答案；若担心，可以先去重。
3. **长度为 1 的词**：删成空串，`""` 一般不在 `dp` 中，故 $dp = 1$。
4. **复杂度来源**：每个词枚举 $|w|$ 次删除，每次构造新串 $O(|w|)$，故单次处理 $O(|w|^2)$；总 $O(\sum |w|^2) \le 1000 \times 16^2 = 2.56\times10^5$。
5. **排序稳定性无关**：同长度的词顺序任意，因为它们之间不存在前身关系。

## 5. 正确性证明

**引理 1（前身判定）**：$A$ 是 $B$ 的前身 $\iff$ $\lvert A \rvert = \lvert B \rvert - 1$ 且 $A$ 可由 $B$ 删除一个字符得到。

**证明**：($\Rightarrow$) 在 $A$ 中插入恰好一个字符得到 $B$，故长度增 1；反过来从 $B$ 中删去那个被插入的字符即得 $A$。($\Leftarrow$) 若 $A$ 由 $B$ 删去第 $i$ 个字符得到，则在 $A$ 的第 $i$ 个位置插入该字符即还原 $B$，故 $A$ 是 $B$ 的前身。∎

**引理 2（长度序是拓扑序）**：若 $A$ 是 $B$ 的前身，则 $\lvert A \rvert < \lvert B \rvert$。因此按长度升序处理时，处理到 $B$ 时 $A$ 的 `dp` 已确定。

**证明**：由引理 1，$\lvert A \rvert = \lvert B \rvert - 1 < \lvert B \rvert$。按长度升序排序保证 $A$ 排在 $B$ 之前。∎

**引理 3（最优子结构）**：设 $C = [w_1, \dots, w_k]$ 是以 $w_k = w$ 结尾的最长词链，则 $[w_1, \dots, w_{k-1}]$ 是以 $w_{k-1}$ 结尾的最长词链。

**证明**：反证。若存在以 $w_{k-1}$ 结尾的更长词链，把它接上 $w$（$w_{k-1}$ 是 $w$ 的前身，链仍合法）就得到比 $C$ 更长的以 $w$ 结尾的链，矛盾。∎

**定理**：算法返回的 `ans` 等于最长词链长度。

**证明**：对长度做归纳，证明每个词的 `dp[w]` 等于以 $w$ 结尾的最长词链长度。

- 长度为 1 的词没有前身，$dp = 1$，正确。
- 设所有更短的词已正确。由引理 1、2，$w$ 的前身只能是「删一个字符」得到的、位于 `words` 中的更短词，且它们的 `dp` 已算好。由引理 3，以 $w$ 结尾的最长链 = $1 + \max_{w' \in \text{pre}(w)} dp[w']$，与转移一致。

故 `ans = max dp[w]` 即全局最长链长度。∎

## 6. 复杂度分析

- **时间**：$O(n \log n + \sum_i \lvert w_i \rvert^2)$。排序 $O(n \log n)$；每个词枚举 $\lvert w_i \rvert$ 种删除、每次构造候选串 $O(\lvert w_i \rvert)$ 并做一次哈希查询（均摊 $O(\lvert w_i \rvert)$）。取 $\lvert w \rvert \le 16$ 时约 $2.6\times10^5$ 次字符操作。
- **空间**：$O(\sum_i \lvert w_i \rvert)$ 存哈希表与临时字符串，最坏约 $1.6\times10^4$ 字符。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <string>
#include <unordered_map>
#include <algorithm>
using namespace std;

class Solution {
public:
    int longestStrChain(vector<string>& words) {
        sort(words.begin(), words.end(), [](const string& a, const string& b) {
            return a.size() < b.size();
        });
        unordered_map<string, int> dp;          // dp[w]：以 w 结尾的最长词链长度
        int ans = 0;
        for (const string& w : words) {
            int best = 1;
            for (int i = 0; i < (int)w.size(); i++) {
                string pre = w.substr(0, i) + w.substr(i + 1);
                auto it = dp.find(pre);
                if (it != dp.end()) best = max(best, it->second + 1);
            }
            dp[w] = max(dp[w], best);
            ans = max(ans, best);
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def longestStrChain(self, words: list[str]) -> int:
        words = sorted(words, key=len)          # 按长度递增处理
        dp = {}                                 # dp[w]：以 w 结尾的最长词链长度
        ans = 0
        for w in words:
            best = 1
            for i in range(len(w)):
                pre = w[:i] + w[i + 1:]         # 删掉一个字符得到前身
                if pre in dp:
                    best = max(best, dp[pre] + 1)
            dp[w] = best
            ans = max(ans, best)
        return ans
```

## 8. 边界情况与易错点

1. **误用「子序列」判定**：前身要求**不改变其余字符顺序**且只插入一个字符，等价于「删一个字符后完全相等」，不是「子序列」。示例 3 的 `"abcd"` 与 `"dbqca"` 长度不同但 `"abcd"` 是 `"dbqca"` 的子序列——用子序列判定会得到错误的链长。
2. **长度必须相差 1**：`dp` 只查「删一个字符」的候选，天然满足；若手动建图，务必检查长度差。
3. **排序键**：必须按 `len` 排序（不是字典序）；用 `sorted(words, key=len)`，C++ 中自定义比较器。
4. **空串候选**：长度为 1 的词删成 `""`，`dp` 里通常没有它，故 `dp = 1`；不要初始化 `dp[""] = 0` 以外的特殊处理（若初始化了也正确，但要注意别让空串参与答案）。
5. **重复词**：`dp[w] = max(dp[w], best)` 覆盖安全；若直接 `dp[w] = best`，在重复词场景下结果相同（同长度不互为前身）。
6. **$n = 1$**：返回 1。

**延伸思考**：若允许每次插入**至多** $k$ 个字符（而不止 1 个），前身判定的候选从 $|w|$ 个变成 $\binom{|w|}{k}$ 个，复杂度上升为 $O(n \cdot L^k \cdot L)$；若要求链中相邻两词的**编辑距离**为 1（允许替换），则需要把「删一个字符」换成「编辑距离为 1」，用 DP 判定即可。
