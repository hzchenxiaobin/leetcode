# LeetCode 统计平方和三元组的数目 题解

## 1. 题目概述

- **标题 / 题号**：统计平方和三元组的数目（#1925，easy）
- **链接**：https://leetcode.cn/problems/count-square-sum-triples/
- **来源**：LeetCode 第 56 场双周赛 Q1
- **难度**：简单
- **标签**：数学、枚举

**题意**：**平方和三元组** $(a,b,c)$ 指满足 $a^2 + b^2 = c^2$ 的整数三元组。给定整数 $n$，统计满足 $1 \le a, b, c \le n$ 的平方和三元组个数。注意 $(a,b,c)$ 与 $(b,a,c)$ 视为不同三元组。

**约束**：

- $1 \le n \le 250$

## 2. 示例

**示例 1**

```text
输入：n = 5
输出：2
解释：(3,4,5) 与 (4,3,5)。
```

**示例 2**

```text
输入：n = 10
输出：4
解释：(3,4,5)、(4,3,5)、(6,8,10)、(8,6,10)。
```

## 3. 解题思路

### 3.1 暴力思路

三重循环枚举 $a, b, c$ 各自 $1 \sim n$，判定 $a^2+b^2=c^2$，$O(n^3)$ 在 $n = 250$ 时约 $1.6 \times 10^7$ 次乘加，可以通过但完全没有必要——$c$ 在 $a, b$ 确定后被**唯一**锁定（若存在），第三个自由度是假的。签到题的价值就在于把这个「降维」一眼看穿。

### 3.2 核心观察：枚举 $(a,b)$，$c$ 由平方和唯一确定

![勾股三元组：枚举两直角边 a,b，斜边 c 被唯一确定](images/bw56_q1_pythagoras_model.svg)

对固定的 $(a, b)$，$c$ 必须满足 $c^2 = a^2 + b^2$，即 $c = \sqrt{a^2+b^2}$——**至多一个候选**。所以只需双重循环枚举 $(a,b)$，判定两件事：$a^2+b^2$ 是不是完全平方数、以及 $c \le n$。判定完全平方数可用整数平方根（`llround(sqrt)` 后回代验证，或 Python 的 `math.isqrt`），也可以预先把 $1 \sim n$ 的所有平方数放进一个布尔表。

两个顺带的小观察：其一，$a \ne b$ 自动成立——若 $a = b$ 则 $c^2 = 2a^2$，即 $(c/a)^2 = 2$，与 $\sqrt 2$ 是无理数矛盾；其二，$(a,b)$ 与 $(b,a)$ 都要计入，双重循环**天然重复计数**，不需要任何去重操作，这反而是最不容易写错的方向。

### 3.3 算法流程

![算法流程：双重枚举 (a,b) → 求平方根 → 回代验证 → c≤n 计数](images/bw56_q1_algorithm_flow.svg)

```text
ans = 0
for a in 1..n:
    for b in 1..n:
        s = a*a + b*b
        c = isqrt(s)              # 向下取整的整数平方根
        若 c*c == s 且 c <= n:  ans += 1
返回 ans
```

### 3.4 示例演算

![示例演算：n = 10 命中的四组与未命中的代表](images/bw56_q1_example_walkthrough.svg)

以 $n = 10$ 为例，双重循环扫描 $100$ 对 $(a,b)$，命中 $4$ 对：

| $(a,b)$ | $a^2+b^2$ | $c$ | $c \le 10$? | 计入 |
|------|------|------|------|------|
| (3,4) | 25 | 5 | 是 | ✓ |
| (4,3) | 25 | 5 | 是 | ✓ |
| (6,8) | 100 | 10 | 是 | ✓ |
| (8,6) | 100 | 10 | 是 | ✓ |
| (1,7) | 50 | — | 不是平方数 | ✗ |
| (7,9) | 130 | — | 不是平方数 | ✗ |
| (10,10) | 200 | — | 不是平方数 | ✗ |

若 $n$ 更小（如 $n = 9$），则 (6,8) 与 (8,6) 因 $c = 10 > n$ 被第二个条件拦下，答案退化为 $2$——这就是 `c <= n` 判定不能省的原因。

## 4. 算法细节

1. **整数平方根判定**：C++ 中 $s \le 2 \times 250^2 = 125000$，`double` 精确表示毫无压力，但 `sqrt` 返回浮点后必须**回代验证** `c*c == s`，并 `c = llround(sqrt(s))` 修正舍入误差（直接 `int(sqrt(s))` 截断在极端边界可能差一）；Python 直接用 `math.isqrt`，零精度烦恼。
2. **预打表替代**：也可以先建 `isSquare[v]`（$v \le 2n^2$）布尔数组，把判定降到 $O(1)$——对本题规模是风格差异而非性能差异。
3. **计数方向**：双重循环对 $(a,b)$、$(b,a)$ 各扫一次，答案自动翻倍，无需乘 2 或去重（引理 1 保证 $a = b$ 的自对称对不存在，不用排除）。
4. **两个条件缺一不可**：`c*c == s` 管「是平方数」，`c <= n` 管「斜边不越界」；后者在 $n$ 落在某个勾股数斜边附近时决定成败（如 $n = 9$ vs $n = 10$）。

## 5. 正确性证明

**引理 1（斜边唯一性 / 直角边不等性）**：对任意 $1 \le a, b \le n$，至多存在一个正整数 $c$ 使 $a^2 + b^2 = c^2$；且该 $c$ 存在时必有 $a \ne b$。

**证明**：$c^2 = a^2 + b^2$ 把 $c$ 唯一确定为 $\sqrt{a^2+b^2}$（平方函数在正整数上严格单调），故至多一个。若 $a = b$，则 $c^2 = 2a^2$；设 $d = \gcd(c, a)$，$c = d c'$、$a = d a'$ 且 $\gcd(c', a') = 1$，则 $c'^2 = 2 a'^2$，于是 $c'^2$ 为偶数 $\Rightarrow$ $c'$ 为偶数，$c' = 2c''$，代回得 $2c''^2 = a'^2$，于是 $a'$ 也为偶数，与 $\gcd(c', a') = 1$ 矛盾。∎

**定理（计数正确性）**：算法返回的值恰为满足条件的平方和三元组个数。

**证明**：答案 $= \sum_{a=1}^{n} \sum_{b=1}^{n} [\exists c \in [1,n]: a^2+b^2=c^2]$（由引理 1，每个 $(a,b)$ 至多对应一个 $c$，且 $(a,b)$ 互异时三元组互异、$(a,b)$ 与 $(b,a)$ 对应的两个三元组不同——由引理 1 第二部分不会出现 $a = b$ 的自重复）。算法对每对 $(a,b)$ 恰好检查一次，且条件 `c*c == s 且 c <= n` 与谓词「存在 $c \in [1, n]$ 使 $c^2 = s$」逻辑等价（$s \ge 2 > 0$ 保证 $c \ge 1$ 自动满足）。故计数一一对应。∎

## 6. 复杂度分析

- **时间**：$O(n^2)$。$n \le 250$ 时约 $6.25 \times 10^4$ 对，每对一次平方根计算。
- **空间**：$O(1)$。只用常数个计数与临时变量（预打表版本为 $O(n^2)$ 布尔位）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int countTriples(int n) {
        int ans = 0;
        for (int a = 1; a <= n; ++a) {
            for (int b = 1; b <= n; ++b) {
                long long s = (long long)a * a + (long long)b * b;
                long long c = llround(sqrt((double)s));   // 整数平方根候选
                if (c <= n && c * c == s) ++ans;          // 回代验证 + 上界判定
            }
        }
        return ans;
    }
};
```

### Python

```python
from math import isqrt

class Solution:
    def countTriples(self, n: int) -> int:
        ans = 0
        for a in range(1, n + 1):
            for b in range(1, n + 1):
                c = isqrt(a * a + b * b)          # 精确整数平方根
                if c <= n and c * c == a * a + b * b:
                    ans += 1
        return ans
```

> 💡 两份代码均通过官方示例（$n=5 \to 2$、$n=10 \to 4$）；并与**真·三重循环**暴力（$O(n^3)$，直接验证 $a^2+b^2=c^2$）在 $n = 1 \sim 250$ 的**全范围**上逐一对拍（C++），以及三重循环（$n \le 40$）+ 平方数集合判定的独立实现（$n \le 250$，Python），`mismatch = 0`。

## 8. 边界情况与易错点

1. **最小答案区间**：$n < 5$ 时答案为 $0$——最小勾股三元组是 $(3,4,5)$；$n = 1, 2, 3, 4$ 的输出都必须是 0。
2. **浮点平方根的差一**：`int(sqrt(s))` 直接截断在 $s$ 恰为平方数时可能因浮点误差得到 $c-1$；务必回代验证 $c \times c = s$（并在必要时对候选 $\pm 1$ 修正）。Python 用 `isqrt` 一劳永逸。
3. **`c <= n` 不能漏**：$(6,8,10)$ 在 $n = 9$ 时不应计入；只验证「是完全平方数」会把 $c > n$ 的对错算进来。
4. **溢出小心中招**：$a^2 + b^2 \le 125000$ 本题不会溢出 `int`，但如果照抄到 $n \sim 10^5$ 的变体题，务必换 `long long`，养成本题就用 `long long` 累加的习惯更稳。
5. **不要去重**：$(a,b)$、$(b,a)$ 是不同三元组，双重循环天然把它们各计一次；「先只算 $a < b$ 再乘 $2$」也能对（引理 1 排除了 $a = b$），但多一步脑内转换不如直接循环。
6. **计数是「有序对」**：题目问的是三元组个数而 $c$ 被唯一确定，答案恒为偶数（每对互异直角边贡献 2）——这个小性质可以当对拍断言。
