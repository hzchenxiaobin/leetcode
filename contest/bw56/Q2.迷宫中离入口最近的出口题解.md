# LeetCode 迷宫中离入口最近的出口 题解

## 1. 题目概述

- **标题 / 题号**：迷宫中离入口最近的出口（#1926，medium）
- **链接**：https://leetcode.cn/problems/nearest-exit-from-entrance-in-maze/
- **来源**：LeetCode 第 56 场双周赛 Q2
- **难度**：中等
- **标签**：广度优先搜索、数组、矩阵

**题意**：给定 $m \times n$ 迷宫（`.` 为空格、`+` 为墙）与入口坐标 $\mathit{entrance}$。每步可上下左右移动一格，不能穿墙、不能出界。**出口**定义为**边界上的空格子**，且**入口本身不算出口**。求从入口到最近出口的最短步数，不可达返回 $-1$。

**约束**：

- $\mathit{maze.length} = m$，$\mathit{maze}[i].\mathit{length} = n$，$1 \le m, n \le 100$
- $\mathit{maze}[i][j] \in \{$ `.`，`+` $\}$
- $0 \le \mathit{entrance}_{\mathit{row}} < m$，$0 \le \mathit{entrance}_{\mathit{col}} < n$，入口一定是空格子

## 2. 示例

**示例 1**

```text
输入：maze = [["+","+",".","+"],[".",".",".","+"],["+","+","+","."]], entrance = [1,2]
输出：1
解释：出口有 (1,0)、(0,2)、(2,3) 三处；从 (1,2) 向上 1 步到 (0,2) 即最近。
```

**示例 2**

```text
输入：maze = [["+","+","+"],[".",".","."],["+","+","+"]], entrance = [1,0]
输出：2
解释：唯一出口在 (1,2)；入口 (1,0) 在边界但不算出口，需向右走 2 步。
```

**示例 3**

```text
输入：maze = [[".","+"]], entrance = [0,0]
输出：-1
解释：唯一空格是入口自己，没有出口。
```

## 3. 解题思路

### 3.1 暴力思路

DFS 枚举所有路径取最短——网格无环时路径数也会随长度指数增长，且要走遍所有出口才知道谁最近。正确但完全没有必要的复杂化。求**无权图单源最短距离**，BFS 是标准答案：它按「离起点的距离」一圈圈向外扩散，第一次碰到目标时的圈数就是最短距离。本题的全部考点其实是**「出口」的定义**：边界上的空格、排除入口自身。

### 3.2 核心观察：入口先标「已访问」，出口判定就干净了

![出口模型：边界空格为出口，入口在边界但被排除](images/bw56_q2_exit_model.svg)

把每个空格看作节点、相邻空格连边，得到一张无权图，目标集合是「边界空格 $\setminus$ {入口}」。BFS 初始化时**先把入口标记为已访问**再入队——这一个动作同时解决两件事：

- 入口永远不会再作为「新格子」被触达，因此**首次触达边界空格即出口**的判定不会把入口自己误报为出口（示例 2 的陷阱：入口 (1,0) 就在边界上）；
- 每个格子只入队一次，队列规模 $O(mn)$。

剩下唯一的实现选择：**在出队时判定出口还是入队（扩展邻居）时判定**？两者都对（BFS 首达即最短），入队时判定少一层循环更利落——当某个邻居被首次访问且它位于边界时，直接返回「当前距离 + 1」。

### 3.3 算法流程

![算法流程：入口入队并标记 → 逐层扩展 → 首次触达边界空格即返回](images/bw56_q2_bfs_flow.svg)

```text
dist[入口] = 0，标记入口已访问，入队
while 队列非空:
    (x, y) 出队
    for 四个方向 (nx, ny):
        越界 / 墙 / 已访问 → 跳过
        dist[nx][ny] = dist[x][y] + 1，标记已访问
        若 (nx,ny) 在边界：返回 dist[nx][ny]     # 入口已访问，绝不会被误判
        (nx,ny) 入队
返回 -1
```

### 3.4 示例演算

![示例 1 的迷宫与 BFS 扩散过程](images/bw56_q2_example_walkthrough.svg)

以示例 1（$3 \times 4$，入口 $(1,2)$）为例：

| 层 | 出队格子 | 新触达 | 说明 |
|------|------|------|------|
| 0 | $(1,2)$ | $(1,1)$；$(0,2)$ | $(1,3)$ 是墙跳过；$(0,2)$ 在边界 → **返回 1** |

扩散在第 1 层就撞上边界空格 $(0,2)$，返回 $1$。若把它堵住（把 $(0,2)$ 改成 `+`），下一层会从 $(1,1)$ 触达 $(1,0)$（边界）返回 $2$——出口 $(2,3)$ 因被墙围住永远不可达，但 BFS 无需关心不可达的出口。

## 4. 算法细节

1. **入口先标记再入队**：`dist[entrance] = 0` 与「已访问」合一（距离数组初始化为 $-1$，非 $-1$ 即已访问），一步完成去重与出口排除。
2. **出口判定放在入队时**：邻居合法且首次访问后，若是边界格立即返回——返回值是 `dist[x][y] + 1`，不必等它出队。
3. **边界判定**：$x = 0$ 或 $x = m-1$ 或 $y = 0$ 或 $y = n-1$；$1 \times n$ 的迷宫里整行都是边界，判定同样成立。
4. **visited 时机**：必须在**入队时**标记。出队才标记的话，同一格会被多个邻居重复入队，队列退化到 $O((mn)^2)$ 级。
5. **不要修改 `maze` 数组来当 visited**：把访问过的格子改成 `+` 固然省内存，但会破坏输入；用独立 `dist` 数组既清晰又顺带存了答案所需的步数。
6. **数据结构**：C++ `queue<pair<int,int>>`；Python `collections.deque` + `popleft()`（`list.pop(0)` 是 $O(n)$，千万别用）。

## 5. 正确性证明

**引理 1（BFS 层序性质）**：BFS 中格子出队的顺序按其 `dist` 值单调不减；且每个格子首次被触达时得到的 `dist` 等于从入口到它的最短步数。

**证明**：对出队序归纳。队列任意时刻至多包含两个相邻的 `dist` 层（新入队元素的距离至多比刚出队元素大 1，而队首元素距离不小于任何先出队者），故出队序按距离单调不减。归纳基础：入口以距离 0 首达。设距离 $\le k$ 的格子首达值都等于最短距离；考察最短距离为 $k+1$ 的格子 $u$，其最短路径上存在距离为 $k$ 的前驱 $v$，$v$ 出队时会把 $u$ 以 $k+1$ 触达（若 $u$ 尚未被触达）；而任何触达只能沿邻接传来，触达值 $\ge$ 最短距离 $k+1$，故首达值恰为 $k+1$。∎

**定理**：算法返回入口到「边界空格且非入口」的最短步数最小值；不存在这样的出口时返回 $-1$。

**证明**：入口在入队前即被标记已访问，此后任何「首次触达」都不可能是入口，故算法返回触发时的判定条件恰为「触达了一个不同于入口的边界空格」。由引理 1，触达顺序按最短距离单调不减，因此**第一个**满足判定条件的格子实现了所有合法出口中的最小距离，返回值正确。若扫描穷尽（队列空）仍未触发返回，说明从入口可达的空格中不存在合法出口，图连通性已枚举完备，返回 $-1$ 正确。∎

## 6. 复杂度分析

- **时间**：$O(mn)$。每个空格至多入队、出队一次，每次出队做常数次邻居检查；$m, n \le 100$ 时最多 $10^4$ 次操作。
- **空间**：$O(mn)$。距离数组与队列同阶（队列中至多是「两层」的格子，仍为 $O(mn)$ 最坏）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int nearestExit(vector<vector<char>>& maze, vector<int>& entrance) {
        int m = maze.size(), n = maze[0].size();
        vector<vector<int>> dist(m, vector<int>(n, -1));
        queue<pair<int,int>> q;
        int sx = entrance[0], sy = entrance[1];
        dist[sx][sy] = 0;                          // 入口先标记 → 不会把自己当出口
        q.push({sx, sy});
        const int dx[4] = {0, 0, 1, -1};
        const int dy[4] = {1, -1, 0, 0};
        while (!q.empty()) {
            auto [x, y] = q.front();
            q.pop();
            for (int d = 0; d < 4; ++d) {
                int nx = x + dx[d], ny = y + dy[d];
                if (nx < 0 || nx >= m || ny < 0 || ny >= n) continue;
                if (maze[nx][ny] == '+' || dist[nx][ny] != -1) continue;
                dist[nx][ny] = dist[x][y] + 1;
                if (nx == 0 || nx == m - 1 || ny == 0 || ny == n - 1)
                    return dist[nx][ny];           // 首次触达的边界空格即最近出口
                q.push({nx, ny});
            }
        }
        return -1;
    }
};
```

### Python

```python
from collections import deque

class Solution:
    def nearestExit(self, maze: list[list[str]], entrance: list[int]) -> int:
        m, n = len(maze), len(maze[0])
        dist = [[-1] * n for _ in range(m)]
        sx, sy = entrance
        dist[sx][sy] = 0                           # 入口先标记 → 不会把自己当出口
        q = deque([(sx, sy)])
        while q:
            x, y = q.popleft()
            for nx, ny in ((x, y + 1), (x, y - 1), (x + 1, y), (x - 1, y)):
                if 0 <= nx < m and 0 <= ny < n \
                        and maze[nx][ny] == '.' and dist[nx][ny] == -1:
                    dist[nx][ny] = dist[x][y] + 1
                    if nx == 0 or nx == m - 1 or ny == 0 or ny == n - 1:
                        return dist[nx][ny]        # 首次触达的边界空格即最近出口
                    q.append((nx, ny))
        return -1
```

> 💡 两份代码均通过全部官方示例（`1`、`2`、`-1`）；另与「堆优化 Dijkstra 全图算距 + 扫描全部出口取最小」的独立参照在 $m, n \le 3$ 的**全部** $2^{mn} \times$ 入口组合（2700+ 组）及 275 组（C++）/ 300 组（Python）随机迷宫上对拍，`mismatch = 0`；$100 \times 100$ 大迷宫冒烟通过。

## 8. 边界情况与易错点

1. **入口在边界**：示例 2 的核心陷阱——入口 $(1,0)$ 在边界但**不算出口**。「先标记再入队」天然排除；若用「出队时判定是否出口」的写法，必须显式加 `且 (x,y) != entrance` 的判断。
2. **$1 \times 1$ 迷宫**：唯一格子是入口，无出口 → $-1$（示例 3 的单行版本）；同理 `1 × n` 单行迷宫整行都是边界，除入口外的边界空格都是出口。
3. **入口四周全是墙**：邻居扩展一步都失败，队列清空返回 $-1$，无需特判。
4. **多出口取最近**：BFS 首达自动取最小；手工挑「最近的边界方向」贪心是错的——墙的存在可能让远端出口更近（示例 1 中 (2,3) 不可达）。
5. **标记时机**：入队时标记，否则同一格重复入队，最坏爆队列；Python 端 `pop(0)` 也是常见超时元凶，用 `deque.popleft()`。
6. **入口坐标的顺序**：`entrance = [row, col]`，先行后列；与 `(x, y)` 混淆是最常见的下标 bug。
