# LeetCode 求和游戏 题解

## 1. 题目概述

- **标题 / 题号**：求和游戏（#1927，medium）
- **链接**：https://leetcode.cn/problems/sum-game/
- **来源**：LeetCode 第 56 场双周赛 Q3
- **难度**：中等
- **标签**：贪心、数学、字符串、博弈

**题意**：Alice 与 Bob 轮流行动，**Alice 先手**。给定偶数长度字符串 $\mathit{num}$（数字字符与 `?`），只要还有 `?`，每次操作必须选一个 `?` 并替换成 $0 \sim 9$ 中的一个数字。`?` 耗尽时游戏结束：**前一半数字和 = 后一半数字和则 Bob 获胜，否则 Alice 获胜**。两人都采取最优策略，Alice 获胜返回 `true`，Bob 获胜返回 `false`。

**约束**：

- $2 \le \mathit{num.length} \le 10^5$，长度为偶数
- $\mathit{num}$ 只包含数字字符和 `?`

## 2. 示例

**示例 1**

```text
输入：num = "5023"
输出：false
解释：没有 '?'，无法操作；5 + 0 = 2 + 3，Bob 获胜。
```

**示例 2**

```text
输入：num = "25??"
输出：true
解释：Alice 把一个 '?' 填成 9，此后 Bob 无论怎么填都无法让两边相等。
```

**示例 3**

```text
输入：num = "?3295???"
输出：false
解释：Bob 总能获胜。一种过程：Alice 填 9 → 93295???，Bob 在右半填 9，
      Alice 填 2，Bob 填 7 → 93295927，9+3+2+9 = 5+9+2+7。
```

## 3. 解题思路

### 3.1 暴力思路

标准的博弈做法是记忆化搜索：状态为「左半剩余 `?` 数 $q_L$、右半剩余 `?` 数 $q_R$、当前左右和之差 $d$」，轮到谁由已走步数决定，每步枚举（填左/填右）×（10 个数字）转移，胜负取 $\max / \min$。状态数 $O(q \times q \times (9n))$、转移 $O(20)$——在 $\mathit{num.length} = 10^5$ 时状态空间爆到 $10^{11}$ 量级，完全不可行。它只配当**对拍基准**（短串下足够快），真正的解法必须找到状态的**不变量**。

### 3.2 核心观察：每个 `?` 的「期望贡献」是 ±4.5，定义势能 $\Phi$

![势能模型：每个 ? 视作 4.5 的期望贡献，天平的总偏差 Φ](images/bw56_q3_potential_model.svg)

设 $d$ = 左半数字和 $-$ 右半数字和（已填部分），$q_L, q_R$ 为左右剩余 `?` 数。一个未填的 `?` 最终会贡献 $0 \sim 9$ 之间的某个数：左边的往 $d$ 里**加**、右边的从 $d$ 里**减**。把每个 `?` 看成「期望值 $4.5$」（$0 \sim 9$ 的中点），定义**势能**：

$$
\Phi \;=\; d \;+\; \frac{9}{2}\,(q_L - q_R)
$$

$\Phi$ 的直观含义：**若所有 `?` 都按 4.5「公平地」填满，最终的左右差**。它把「数字和」与「问号数」拧成一个量，而每次操作对 $\Phi$ 的影响极其规整：

- 在**左**边填数字 $a$：$d \to d + a$、$q_L \to q_L - 1$，故 $\Phi \to \Phi + (a - 4.5)$；
- 在**右**边填数字 $a$：$d \to d - a$、$q_R \to q_R - 1$，故 $\Phi \to \Phi + (4.5 - a)$。

**任何一步对 $\Phi$ 的改变量 $c$ 都满足 $|c| \le 4.5$**，且一步能取到的改变量恰是 $\{a - 4.5\} \cup \{4.5 - a\} = [-4.5, 4.5]$ 中的全部半整数——左右两边的选项关于 $0$ 对称，**填哪边不重要，重要的是把 $\Phi$ 拉到哪**。这把博弈从「在字符串上填数字」抽象成「两个玩家轮流把一根数轴上的指针 $\Phi$ 拨动至多 $4.5$，Alice 想让终值非零、Bob 想让终值为零」。

胜负的临界线随之浮现（记初始 $\Phi_0 = d_0 + \frac{9}{2}(q_L - q_R)$，并令 $q = q_L + q_R$）：

- **$q$ 为偶数**：$\Phi_0$ 是整数。若 $\Phi_0 = 0$，Bob 有「守恒策略」——Alice 每拨一步，Bob 精确拨回 $\Phi = 0$，终局必为零；若 $\Phi_0 \ne 0$，Alice 一步就能把 $|\Phi|$ 拉过 $4.5$（比如 $\Phi_0 \ge 1$ 时往正方向拨 $4.5$），此后 Bob 每步最多拉回 $4.5$、永远够不着零。
- **$q$ 为奇数**：$q_L - q_R$ 是奇数，$\Phi_0$ 是**半整数**，永远不等于零；且 Alice 拿到最后一手，她同样能先手把指针拉离危险区。

### 3.3 判定流程

![判定流程：统计 d 与 qL−qR，检验 2d + 9(qL−qR) 是否为零](images/bw56_q3_decision_flow.svg)

为避开半整数，给 $\Phi_0 = 0$ 两边乘 $2$，得到纯整数判据：

$$
\boxed{\;\mathit{Alice\ 获胜} \iff 2d + 9\,(q_L - q_R) \ne 0\;}
$$

（$q$ 为奇数时 $9(q_L - q_R)$ 为奇数、$2d$ 为偶数，两者之和必为奇数 $\ne 0$，与「Alice 必胜」一致；$q$ 为偶数时 $2d + 9(q_L - q_R) = 0 \iff \Phi_0 = 0$。）

```text
一趟扫描：d = Σ(左数字) − Σ(右数字)，q = (左?数) − (右?数)
返回 2*d + 9*q != 0
```

### 3.4 示例演算

![示例演算：?3295??? 中 Bob 的守恒策略逐步回放](images/bw56_q3_strategy_walkthrough.svg)

**示例 3**（`?3295???`）：左半 `?329` 得 $d = 0+3+2+9 - 5 = 9$（右半只有数字 5），$q_L = 1$、$q_R = 3$。判据 $2 \times 9 + 9 \times (1 - 3) = 18 - 18 = 0$ → **Bob 获胜**。守恒策略逐回合验证（$\Phi = d + 4.5\,(q_L - q_R)$）：

| 回合 | 操作 | $d$ | $(q_L, q_R)$ | $\Phi$ |
|------|------|-----|------|------|
| 初始 | — | $9$ | $(1, 3)$ | $9 + 4.5 \times (-2) = 0$ |
| Alice 填左 9 | $\Phi + (9-4.5)$ | $18$ | $(0, 3)$ | $4.5$ |
| Bob 填右 9 | $\Phi + (4.5-9)$ | $9$ | $(0, 2)$ | $0$ ← 拨回 |
| Alice 填右 2 | $\Phi + (4.5-2)$ | $7$ | $(0, 1)$ | $2.5$ |
| Bob 填右 7 | $\Phi + (4.5-7)$ | $0$ | $(0, 0)$ | $0$ ← 终局相等 |

注意 Bob 的应手并非照抄数字，而是按「把 $\Phi$ 拨回 $0$」选值：Alice 让 $\Phi = 4.5$，Bob 需要 $c = -4.5$，右边填 $a$ 使 $4.5 - a = -4.5$，即 $a = 9$。

**示例 2**（`25??`）：$d = 7 - 0 = 7$，$q_L = 0$、$q_R = 2$，判据 $14 + 9 \times (-2) = -4 \ne 0$ → **Alice 获胜**（官方解释「Alice 填 9」与此吻合）。用势能复盘她的制胜一手：$\Phi_0 = 7 - 9 = -2$（负值表示右半「期望容量」更大）。左边没有 `?`，Alice 只能在右边填 $a$，改变量 $c = 4.5 - a$；她取 $a = 9$ 得 $c = -4.5$，$\Phi \to -6.5$，而 $|\Phi| = 6.5$ 已超出 Bob 一步的射程（$4.5$）——Bob 填任何数字都无法归零，终局左右和不等。若她随手填小数字（比如 $a = 0$，$\Phi \to 2.5 \le 4.5$），Bob 反而能一步拨回 $0$：可见「必胜」依赖**按 $\Phi$ 的符号选方向**，而不是无脑填 9 或填 0。

## 4. 算法细节

1. **一趟扫描合并统计**：遍历一次字符串，左边字符对 $d$ 加、对 $q$ 加；右边对 $d$ 减、对 $q$ 减。判据 $2d + 9(q_L - q_R)$ 中 $d$ 可达 $9 \times 5 \times 10^4 \approx 4.5 \times 10^5$、$q$ 达 $10^5$，乘 9 后约 $10^6$，32 位整数绰绰有余（Python 无虞）。
2. **为什么判据对「$q$ 奇数」自动给出 Alice 胜**：$2d$ 偶、$9(q_L - q_R)$ 奇（$q_L - q_R$ 与 $q_L + q_R$ 同奇偶），和为奇数必非零——不必单独写分支。
3. **势能的公平填充视角**：$\Phi_0 = 0$ 的另一读法是「把每个 `?` 都填成 4.5 时左右恰好平衡」，即两边「未定容量」与「既有差额」互相抵消。这也是为什么 Bob 的策略总在对称位置补偿。
4. **对拍基准**：记忆化搜索的状态按 $(q_L, q_R, d)$ 做键，**轮次由「已走步数 = 总 `?` 数 − 剩余数」决定**，不要用「剩余数的奇偶」判断轮次——那是本题暴力最容易写错的地方（我在验证时就栽过这一跤）。
5. **不要试图贪心模拟对局**：判据是「存在必胜策略」的闭式解，逐回合模拟双方贪心（Alice 填 9、Bob 补差）既慢又在边界态下不可靠。

## 5. 正确性证明

以下总设初始 `?` 总数为 $q$，已走步数为 $q - (q_L + q_R)$，其为偶数时轮到 Alice。记状态势能 $\Phi = d + \frac{9}{2}(q_L - q_R)$，则**终局**（无 `?`）时 $\Phi = d$，Bob 获胜当且仅当终局 $\Phi = 0$。每步操作使 $\Phi$ 改变 $c \in \{-4.5, -3.5, \dots, 4.5\}$（左填 $a$ 得 $c = a - 4.5$，右填得 $c = 4.5 - a$；两边选项集合相同），且只要还有 `?`，**两侧（或任一存在 `?` 的一侧）都能实现任意一个这样的 $c$**。

**引理 1（奇偶结构）**：$\Phi \equiv \frac{9}{2}(q_L + q_R) \pmod 1$，即剩余 `?` 数为偶数时 $\Phi$ 是整数、为奇数时 $\Phi$ 是半整数；特别地，Alice 行动前的状态 $\Phi$ 恒为整数（当 $q$ 为偶数）。

**证明**：初始时若 $q$ 为偶数，$q_L - q_R$ 与 $q_L + q_R$ 同奇偶故为偶数，$d$ 为整数，$\Phi = d + \frac{9}{2} \cdot (\text{偶})$ 为整数。每步 $q_L + q_R$ 减一，而 $c$ 是半整数，两者奇偶同时翻转，归纳得 $\Phi$ 的整数性与 $q_L + q_R$ 的奇偶绑定；Alice 在已走步数为偶数（即剩余数为偶，若 $q$ 为偶数）时行动。∎

**引理 2（Alice 破防）**：轮到 Alice 且 $\Phi \ne 0$ 时（$q$ 为偶数则 $\Phi$ 是整数、$|\Phi| \ge 1$；$q$ 为奇数则 $\Phi$ 是半整数、$|\Phi| \ge 0.5$），Alice 可一步使 $|\Phi'| > 4.5$。

**证明**：她取 $c = 4.5 \cdot \mathit{sign}(\Phi)$：若 $\Phi > 0$，在左边填 $9$ 或在右边填 $0$；若 $\Phi < 0$，在左边填 $0$ 或在右边填 $9$——任一存在 `?` 的侧都能实现（轮到 Alice 即意味着还有 `?`）。此时 $|\Phi'| = |\Phi| + 4.5 \ge 5 > 4.5$，超出任何单步的射程。若这一步恰好用尽所有 `?`，终局 $\Phi' \ne 0$，Alice 直接获胜。∎

**引理 3（Alice 保势）**：轮到 Bob 且 $|\Phi| > 4.5$ 时，Alice 必胜。

**证明**：对剩余 `?` 数归纳。Bob 的任意一步使 $\Phi'' = \Phi + c'$、$|c'| \le 4.5$，由反向三角不等式 $|\Phi''| \ge |\Phi| - |c'| > 0$，故 $\Phi'' \ne 0$。若此后 `?` 耗尽，终局 $\Phi'' \ne 0$，Alice 胜。否则轮到 Alice 且 $\Phi'' \ne 0$，她按引理 2 的方式同号拨动 $4.5$，得 $|\Phi'''| = |\Phi''| + 4.5 > 4.5$，回到「轮到 Bob 且 $|\Phi| > 4.5$」的前提。归纳成立。∎

**引理 4（Bob 守恒）**：$q$ 为偶数时，轮到 Bob 且 $|\Phi| \le 4.5$（此时 $\Phi$ 为半整数），Bob 总能一步使 $\Phi$ 回到 $0$。

**证明**：Bob 需要 $c = -\Phi$。若左边有 `?`，填 $a = 4.5 - \Phi$；若右边有 `?`，填 $a = 4.5 + \Phi$。由 $|\Phi| \le 4.5$ 且 $\Phi$ 为半整数，两个 $a$ 都是 $[0, 9]$ 中的整数，相应地 $c = a - 4.5 = -\Phi$ 或 $c = 4.5 - a = -\Phi$。轮到 Bob 说明至少一侧有 `?`，必有一种实现可用。∎

**定理（主判定）**：Alice 获胜当且仅当 $2d + 9(q_L - q_R) \ne 0$。

**证明**：

*（$q$ 偶，$2d + 9(q_L - q_R) = 0$，即 $\Phi_0 = 0$，证 Bob 胜）*：对 Bob 的回合数归纳。Alice 每走一步，$\Phi$ 从 $0$ 变为半整数、$|\Phi| = |c| \le 4.5$，由引理 4，Bob 把 $\Phi$ 拨回 $0$（此后 $\Phi$ 恢复整数，归纳前提保持）。$q$ 为偶数故最后一手属于 Bob，终局时 `?` 耗尽、$\Phi = d = 0$，Bob 胜。

*（$q$ 偶，$\Phi_0 \ne 0$，证 Alice 胜）*：$\Phi_0$ 为非零整数，由引理 2，Alice 第一步使 $|\Phi| > 4.5$ 且轮到 Bob，再由引理 3，终局 $\Phi \ne 0$，Alice 胜。

*（$q$ 奇，证 Alice 胜）*：$q_L - q_R$ 与 $q_L + q_R$ 同奇偶，故为奇数，$\Phi_0 = d + \frac{9}{2}(q_L - q_R)$ 是**非零半整数**（整数 $d$ 加半整数），判据左端 $2d + 9(q_L - q_R)$ 为「偶 + 奇」必为奇数、恒不为零。由引理 2，Alice 第一步使 $|\Phi| > 4.5$ 且轮到 Bob，再由引理 3，终局 $\Phi \ne 0$，Alice 胜。∎

## 6. 复杂度分析

- **时间**：$O(n)$。一趟扫描统计 $d$ 与 $q_L - q_R$，一次乘加比较。
- **空间**：$O(1)$。两个整数计数器。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool sumGame(string num) {
        int n = num.size(), half = n / 2;
        long long d = 0, q = 0;                    // d=左和−右和；q=左?数−右?数
        for (int i = 0; i < n; ++i) {
            if (num[i] == '?') q += (i < half ? 1 : -1);
            else d += (i < half ? 1 : -1) * (num[i] - '0');
        }
        return 2 * d + 9 * q != 0;                 // Alice 获胜 ⟺ 此式 ≠ 0
    }
};
```

### Python

```python
class Solution:
    def sumGame(self, num: str) -> bool:
        half = len(num) // 2
        d = q = 0                                  # d=左和−右和；q=左?数−右?数
        for i, c in enumerate(num):
            if c == '?':
                q += 1 if i < half else -1
            else:
                d += (1 if i < half else -1) * int(c)
        return 2 * d + 9 * q != 0                  # Alice 获胜 ⟺ 此式 ≠ 0
```

> 💡 两份代码均通过全部官方示例（`false`、`true`、`false`），另与「记忆化博弈搜索」（状态 $(q_L, q_R, d)$、每步 20 个分支、轮次按已走步数判定）在 4000 组（C++）/ 1500 组（Python）随机串（长度 $2 \sim 10$、`?` 与数字随机混合）上对拍，`mismatch = 0`；全 `?` 串（长度 2/4/6/8）均判 Bob 胜，与手推一致。

## 8. 边界情况与易错点

1. **没有 `?`**：判据退化为 $2d \ne 0$，即直接比较左右和——示例 1。
2. **`?` 全在一侧**：如 `25??`，$q = -2$ 让 $9q = -18$ 参与判定；只看「和差」不看「问号分布」是本题最典型的错法（`25??` 的和差是 7，貌似 Bob 用两个 `?` 能补 7？实际 Alice 先手直接破坏）。
3. **`?` 总数为奇数**：判据恒判 Alice 胜（奇偶论证），不要试图枚举最后一手；官方提示里的「mod 9」视角也能得到同结论，但推导更绕。
4. **判据乘 2 的必要性**：$\Phi_0 = 0$ 即 $d = \frac{9}{2}(q_R - q_L)$，$q$ 偶时右边是整数但写 $9/2$ 易引入浮点；用 $2d + 9(q_L - q_R) = 0$ 保持纯整数。
5. **暴力对拍的轮次 bug**：记忆化搜索判断「轮到谁」必须用**已走步数**（总 `?` 数 − 剩余），用「剩余数奇偶」会在 $q$ 奇数时把先手后手弄反，对拍全军覆没却查不出公式错。
6. **别把「Alice 填 9」当万能策略**：`25??` 里 Alice 第一步在右边填 9（把 $\Phi$ 拉到 $-6.5$）才制胜；填 0 方向相反会让 Bob 归零。必胜策略的存在性由判据保证，具体着法需按 $\Phi$ 的符号选方向。
