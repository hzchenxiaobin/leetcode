# LeetCode 严格回文的数字 题解

## 1. 题目概述

- **标题 / 题号**：严格回文的数字（#2396，medium）
- **链接**：https://leetcode.cn/problems/strictly-palindromic-number/
- **来源**：LeetCode 第 86 场双周赛 Q2
- **难度**：中等
- **标签**：脑筋急转弯、数学、双指针

**题意**：若整数 $n$ 在 $b$ 进制下的表示（$b$ 取遍 $2$ 到 $n-2$ 的**所有**整数）**全部**是回文串，则称 $n$ 是"严格回文的"。给定 $n$，判断它是否严格回文。

**约束**：

- $4 \le n \le 10^5$

## 2. 示例

**示例 1**

```text
输入：n = 9
输出：false
解释：2 进制 9 = 1001 回文；但 3 进制 9 = 100 不回文（4,5,6,7 进制下也都不是回文）。
```

**示例 2**

```text
输入：n = 4
输出：false
解释：只需检查 2 进制：4 = 100，不回文。
```

**边界补充**

```text
输入：n = 5    输出：false   # 唯一要查的 b = 3：5 = 12₃，"12" 不回文
输入：n = 6    输出：false   # b=2: 110 不回文；b=3: 20 不回文；b=4: 12 不回文
```

## 3. 解题思路

### 3.1 暴力思路

对每个 $b \in [2, n-2]$ 做**进制转换**得到数字串，再**双指针**判回文，全部通过才返回 `true`。单个 $b$ 转换 $O(\log_b n)$，总时间 $O(n \log n)$。$n \le 10^5$ 时约 $10^5 \times 17 \approx 2 \times 10^6$ 步，能过——但这正是题目的"陷阱面"：它诱导你写模拟，而存在一行解。

### 3.2 核心观察：只需看 $b = n - 2$，答案恒为 false

![核心观察：n 在 b = n−2 进制下恒为 "12"，而 "12" 不是回文](images/bw86_q2_base_n_minus_2.svg)

对任意 $n \ge 4$，取 $b = n - 2 \ge 2$（在题目要求的进制范围内）。做带余除法：

$$n = 1 \cdot (n-2) + 2$$

且 $2 < n - 2$（即 $n \ge 5$；$n = 4$ 时 $b = 2$，$4 = 100_2$ 也不是回文，单独看）。于是 $n$ 在 $b = n-2$ 进制下的表示是**两位数** $\overline{12}$：高位 $1$、低位 $2$。两位数回文要求两数字相等，$1 \ne 2$，故 $\overline{12}$ **永不回文**。既然"全部进制都要回文"的要求在 $b = n-2$ 这一处就破产了，答案对所有 $n \ge 4$ 恒为 `false`——连 $n$ 都不用读（当然函数签名还是要接）。

> 💡 为什么偏偏是 $b = n - 2$？进制越大、位数越少，$b \ge \sqrt{n}$ 后表示至多两位；而 $b = n - 2$ 恰好把 $n$ 压成最小位数（两位）且数字 exposes 出 $1$ 与 $2$ 这两个必然不等的小数字。这是"**在判定的全称量词里挑一个必然失败的证人**"的典型脑筋急转弯。

### 3.3 算法流程

```text
return false
```

（严格地说，还应在题解层面说明 $n \ge 4$ 时 $b = n-2 \in [2, n-2]$ 恒在检查范围内，见 §5。）

### 3.4 示例演算

![示例演算：9 与 5 在若干进制下的表示，b = n−2 处一律不是回文](images/bw86_q2_example_walkthrough.svg)

以 $n = 9$ 为例：$b = 7 = n - 2$ 时 $9 = 1 \times 7 + 2 = \overline{12}_7$，不回文，立刻否决——不必像官方示例那样逐个检查 $3,4,5,6,7$ 进制。再如 $n = 5$：$b = 3$ 时 $5 = \overline{12}_3$；$n = 10^5$：$b = 99998$ 时 $10^5 = \overline{12}_{99998}$。**任何** $n \ge 5$ 都逃不过这个"两位陷阱"，$n = 4$ 则死在 $b = 2$ 的 $100$ 上。

## 4. 算法细节

1. **除法分解的唯一性**：$n = q b + r$（$0 \le r < b$）中 $q, r$ 唯一。取 $b = n - 2$ 得 $q = 1, r = 2$，且需验证 $q < b$（$1 < n-2$）与 $r < b$（$2 < n-2$，即 $n \ge 5$）保证这就是**完整**的两位表示（没有第三位）。
2. **$n = 4$ 的单独确认**：$b = n - 2 = 2$，$4 = 100_2$，三位、首尾 $1$ 与 $0$ 不等，不回文。结论对 $n = 4$ 同样成立，只是推导走的是另一个式子。
3. **如果非要写暴力**：进制转换用 `while (n) { digits.push_back(n % b); n /= b; }`，回文判定双指针从两端向中间；任何 $b$ 失败即可 `return false`（短路）。
4. **返回类型**：LeetCode 的 `boolean`/`bool`；C++ 直接 `return false;` 会触发"未用参数"警告，无伤大雅（可 `(void)n;` 消除）。
5. **别把 $b$ 的范围记错**：题目要求 $2 \le b \le n - 2$，**含** $n-2$ 这个端点——正是这一"含端点"让一位数表示（$b > n$ 才会出现）不可能发生，两位的 $\overline{12}$ 成为必然形态。

## 5. 正确性证明

**引理 1（两位表示）**：设 $n \ge 5$，$b = n - 2$，则 $n$ 在 $b$ 进制下的表示恰为两位数字 $(1, 2)$，即 $n = 1 \cdot b^1 + 2 \cdot b^0$。

**证明**：带余除法 $n = q b + r$（$0 \le r < b$）的商余唯一。代入 $b = n - 2$：$n = 1 \cdot (n-2) + 2$，其中商 $q = 1$ 满足 $0 \le q < b$（$b = n - 2 \ge 3 > 1$），余数 $r = 2$ 满足 $0 \le 2 < b$（$n - 2 > 2 \iff n > 4$）。商 $q = 1 < b$ 说明表示恰好两位：高位 $q = 1$、低位 $r = 2$，无更高位。∎

**引理 2（两位回文条件）**：$b$ 进制下的两位数 $\overline{d_1 d_2}$（$d_1 \ne 0$）是回文串当且仅当 $d_1 = d_2$。

**证明**：回文串定义为首尾对称：$\overline{d_1 d_2}$ 回文 $\iff$ 第 1 位 $=$ 第 2 位 $\iff d_1 = d_2$。∎

**定理**：对一切 $n \ge 4$，`isStrictlyPalindromic(n)` 的正确返回值为 `false`。

**证明**："严格回文"要求**所有** $b \in [2, n-2]$ 的表示都回文。我们给出一个必然失败的证人：

- 若 $n \ge 5$：取 $b = n - 2 \in [2, n-2]$（合法）。由引理 1，表示为 $\overline{12}$；由引理 2，$1 \ne 2$ 故不回文。全称命题被违反，$n$ 不严格回文。
- 若 $n = 4$：检查范围只有 $b = 2$。$4 = (100)_2$：三位，第 1 位 $1 \ne$ 第 3 位 $0$，不回文。同样违反。

综上，任何 $n \ge 4$ 都不严格回文，返回 `false` 恒正确。∎

**反证视角**（换个方式说服自己）：假设存在严格回文的 $n \ge 5$，则它在 $b = n-2$ 下的表示 $\overline{12}$ 必须回文，即 $1 = 2$，荒谬；$n = 4$ 则要求 $(100)_2$ 回文，即 $1 = 0$，同样荒谬。矛盾说明不存在——这正是"**全称命题只需一个反例即可否决**"的逻辑结构。

## 6. 复杂度分析

- **时间**：$O(1)$。不做任何进制转换，直接返回常量。对比暴力的 $O(n \log n)$（$n \le 10^5$ 时约 $2 \times 10^6$ 步）——不是"快一点"，而是**根本不计算**。
- **空间**：$O(1)$。无任何辅助结构。

## 8. 边界情况与易错点

1. **$n = 4$ 是唯一特例**：$b$ 范围退化为 $\{2\}$，$b = n - 2$ 的"两位推导"不适用（$2 = n-2$ 时余数 $2$ 不满足 $< b$），须单独验证 $100_2$ 不回文。题解推导别写成"对一切 $n$ 用 $\overline{12}$"，会在这露出马脚。
2. **进制范围含端点**：$b \le n - 2$ **包含** $n-2$；若误记成 $b < n-2$，证人进制不在检查范围内，一行解就不成立了。
3. **"全部"与"存在"的逻辑方向**：严格回文是**全称**条件（每个 $b$ 都要回文），否决只需**一个**失败进制；反过来若题目问"是否存在某进制回文"，一行解失效，必须真搜。
4. **别顺手 return true**：赛场上最常见的翻车是把逻辑想反（"找不到反例 → true"），而本题恰是"必然存在反例 → 恒 false"。
5. **想验证自己的推理时**：写个定义法暴力穷举小范围（本文 $n \le 2 \times 10^4$）是最踏实的自检——若暴力找到任何一个返回 `true` 的 $n$，说明推理有洞。
6. **约束下界就是 4**：题目保证 $n \ge 4$，不需要处理 $n \le 3$（此时 $b$ 范围为空，"空全称为真"会诡异地返回 `true`——幸好题目排除了这个语义陷阱）。

**延伸思考**：本题的元教训是「**全称命题的最弱环节**」：要证"对所有 $b$ 都回文"为假，攻击最极端的 $b$ 即可；而最极端进制（$b = n-2$）把 $n$ 的表示压缩到最短——**位数最短时回文约束最容易暴露矛盾**（两位要求相等，$1 \ne 2$ 一眼假）。推广开去："$n$ 在所有 $b \in [2, n-2]$ 下都不是回文"这类**存在性变体**就没有免费午餐了（例如 $n = 3$ 恰好处处……范围又为空），必须回到搜索。另一条支线是"哪个 $n$ 在最多的进制下回文"（如 $n = 3$ 空范围、$n = 5$ 零个、$n = 10$ 在 $b = 3$ 下 $101$ 回文）——这是 Project Euler 式的计数趣味，考的则是进制表示与整除性的深层互动。
