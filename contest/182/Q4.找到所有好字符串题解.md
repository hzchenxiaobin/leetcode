# LeetCode 找到所有好字符串 题解

## 1. 题目概述

- **标题 / 题号**：找到所有好字符串（#1397，hard）
- **链接**：https://leetcode.cn/problems/find-all-good-strings/
- **来源**：LeetCode 第 182 场周赛 Q4
- **难度**：困难
- **标签**：字符串、动态规划、数位 DP、KMP、状态机

**题意**：给定长度为 $n$ 的字符串 `s1`、`s2`（$s1 \le s2$）与模式串 `evil`，统计同时满足以下三个条件的字符串 `x` 的数目，答案对 $10^9 + 7$ 取模：

1. `x` 的长度为 $n$；
2. $s1 \le x \le s2$（字典序）；
3. `evil` 不是 `x` 的子串。

**约束**：

- $1 \le n \le 500$
- $1 \le \text{evil.length} \le 50$
- `s1.length == s2.length == n`，`s1 <= s2`
- 所有字符串只含小写字母

> 💡 两个约束恰好正交：字典序约束限制**每一位可选字符的区间**，`evil` 约束限制**已填前缀的匹配状态**——这是「数位 DP + 自动机」的标准组合场景。

## 2. 示例

**示例 1**

```text
输入：n = 2, s1 = "aa", s2 = "da", evil = "b"
输出：51

解释：以 'a' 开头：第二位去掉 'b' 后有 25 种（"aa","ac",…,"az"）；
以 'c' 开头：同样 25 种；
以 'd' 开头且不超过 "da"：只有 "da" 本身。
合计 25 + 25 + 1 = 51。
```

**示例 2**

```text
输入：n = 8, s1 = "leetcode", s2 = "leetgoes", evil = "leet"
输出：0

解释：s1、s2 的前 4 位同为 "leet"，区间内任何字符串都被迫以
"leet" 开头，因而都包含 evil，答案为 0。
```

**示例 3**

```text
输入：n = 2, s1 = "gx", s2 = "gz", evil = "x"
输出：2

解释：区间内只有 "gx","gy","gz"，去掉含 'x' 的 "gx"，剩 "gy","gz"。
```

## 3. 解题思路

### 3.1 暴力思路

逐个枚举长度为 $n$ 的小写字母串再检查：共 $26^n$ 个，$n = 500$ 时是天文数字。

更本质的困难在于：**答案本身就是天文数字**（只在对 $10^9+7$ 取模的意义下求解）——一旦构造中的 `x` 脱离了上下界，后面每一位都近乎自由，合法串可有 $26^{498}$ 量级。因此任何「枚举每个串再验证」的做法都注定失败，必须换成分组**计数**。

### 3.2 核心观察：数位 DP 套 KMP 自动机

把两个约束分别翻译成 DP 的两个部件。

**字典序约束 → 逐位填 + 贴界标志（数位 DP）**

从左往右逐位构造 `x`。任意时刻，已填部分相对两界只有两种姿态：仍与界的同长前缀**完全相等**（「贴界」），或已经**严格脱离**。于是维护两个布尔量：

- `lo = 1`：已填部分仍等于 `s1` 的前缀，当前位必须 $\ge s1[i]$；
- `hi = 1`：已填部分仍等于 `s2` 的前缀，当前位必须 $\le s2[i]$。

某位一旦严格大于 $s1[i]$（或严格小于 $s2[i]$），该界永久解除，之后任选。这正是经典的**数位 DP**。

**evil 约束 → KMP 自动机状态**

「`x` 不含 `evil` 子串」等价于「把 `x` 逐字符喂给 `evil` 的 KMP 自动机，状态永远到不了 $m = |\text{evil}|$」。于是把「当前已匹配的 `evil` 前缀长度 $j$」作为 DP 的一维，转移查预处理的转移表 $\delta(j, c)$；状态一旦到达 $m$，整条分支剪掉。

![数位 DP 双贴界模型](images/1397_digitdp_bounds_model.svg)

两个部件互不干扰：贴界标志决定**每位可选的字符集合**，KMP 状态决定**转移去向与剪枝**——合起来就是一个 $O(26nm)$ 的 DP。

### 3.3 状态设计与转移

**状态**：$dp[i][j][lo][hi]$ = 已填前 $i$ 位、匹配状态为 $j$、是否仍贴住下界 / 上界的方案数。

**初始化**：$dp[0][0][1][1] = 1$（空前缀同时贴住两界，尚未匹配任何字符）。

**转移**：填第 $i$ 位字符 $c$（记 $a = s1[i]$，$b = s2[i]$）：

1. 若 `lo=1` 且 $c < a$：`x` 将小于 `s1`，跳过；
2. 若 `hi=1` 且 $c > b$：`x` 将大于 `s2`，跳过；
3. $j' = \delta(j, c)$；若 $j' = m$：前缀已出现 `evil`，跳过（剪枝）；
4. 否则累加：

```text
dp[i+1][j'][lo && c == a][hi && c == b] += dp[i][j][lo][hi]
```

**答案**：第 $n$ 层全部状态求和——能活到第 $n$ 层的分支自动满足两个约束。

转移中用到的 $\delta$ 来自 `evil` 的 KMP 自动机：

![evil 的 KMP 自动机](images/1397_kmp_automaton.svg)

### 3.4 示例演算

以示例 1 走一遍完整 DP（$m=1$：$\delta(0,\texttt{'b'}) = 1 = m$，其余 25 个字符 $\delta(0, \cdot) = 0$）：第 0 位 `'b'` 分支被剪枝；第 1 位三个存活状态各自展开，合计 $1 + 24 + 25 + 1 = 51$。

![示例 1 的 DP 演算](images/1397_dp_walkthrough_51.svg)

### 3.5 另一种等价写法：前缀差分

也可以只维护一个贴界标志，定义 $f(s)$ = 合法且 $x \le s$ 的串数，答案 $= f(s2) - f(s1) + [\,s1\ \text{本身合法}\,]$。两种写法复杂度同阶；本文采用**双界一次 DP**：全程只有加法，不需要减法修正，取模也更不易出错。

## 4. 算法细节

### 4.1 KMP fail 数组与转移表

对 `evil` 计算 `fail`（失配指针）：`fail[i]` = `evil[0..i]` 的最长相等真前后缀长度。转移表只需 $j \in [0, m)$ 的行：

```text
δ(j, c)：
    while j > 0 且 evil[j] != c:  j = fail[j-1]
    return (evil[j] == c) ? j+1 : 0      // 结果可能等于 m（死亡）
```

预计算 `nx[m][26]` 共 $26m$ 个表项，DP 中 $O(1)$ 查表。**不需要**为 $j = m$ 建行——到达即被丢弃。

### 4.2 滚动数组

`dp` 只依赖上一层，两层 $m \times 2 \times 2$ 的数组滚动即可，空间 $O(4m)$。

### 4.3 逐位转移的顺序

对每个状态先做**上下界过滤**（确定当前位允许的字符集合），再做 **KMP 转移**（筛掉 $j' = m$ 的字符），最后用「是否等于界字符」更新 `lo` / `hi`。三步顺序不影响正确性，但先过滤可少做无效转移。

## 5. 正确性证明

**引理 1（贴界不变式）**：对 $0 \le i \le n$，`dp[i][·][lo][hi]` 所计数的每个前缀 $p$（长 $i$）都满足「`s1` 的前 $i$ 位 $\le p \le$ `s2` 的前 $i$ 位」；且 `lo=1` 当且仅当 $p$ 与 `s1` 的前 $i$ 位完全相等，`lo=0` 蕴含 $p$ 严格大于之（`hi` 相对 `s2` 对称）。

**证明**：对 $i$ 归纳。$i = 0$：空前缀与两界的前缀相等，$dp[0][0][1][1] = 1$，成立。设 $i$ 时成立，看第 $i$ 位选 $c$：

- 若 `lo=1`：转移规则禁止 $c < s1[i]$，故新前缀 $\ge$ `s1` 的前 $i+1$ 位；$c = s1[i]$ 时 `lo'=1`（仍相等），$c > s1[i]$ 时 `lo'=0` 且严格大于。
- 若 `lo=0`：归纳假设 $p$ 已严格大于 `s1` 的前 $i$ 位，任意 $c$ 都保持新前缀严格大于。

`hi` 侧对称。∎

**引理 2（KMP 状态刻画）**：把文本的前 $i$ 个字符依次喂入自动机得到状态 $j_i$，则 $j_i$ 是「前 $i$ 个字符的后缀与 `evil` 前缀相等」的最大长度；且文本包含 `evil` 子串 $\iff$ 某个 $j_i = m$。

**证明**：对 $i$ 归纳。读入 $c$ 后，新前缀的匹配后缀若长为 $\ell \ge 2$，则其前 $\ell - 1$ 个字符是旧前缀的后缀且匹配 `evil` 的前 $\ell - 1$ 位，即旧状态 fail 链上的某个候选。转移 $\delta$ 先尝试顺延 $j + 1$，再沿 fail 链从长到短尝试，恰好取到最大可行长度。若 `evil` 在文本中最早结束于第 $i$ 位，则前 $i$ 个字符拥有长 $m$ 的后缀等于 `evil`，故 $j_i = m$；反之 $j_i = m$ 时该后缀本身就是一个 `evil` 出现。∎

**引理 3（路径与好字符串双射）**：DP 中存活到第 $n$ 层的路径与好字符串一一对应。

**证明**：路径即逐位选择序列，唯一确定字符串 `x`。由引理 1 得 $s1 \le x \le s2$。由引理 2 及剪枝规则，路径存活 $\iff$ 全程 $j < m$ $\iff$ `x` 的每个前缀都不含 `evil` $\iff$ `x` 不含 `evil`（若含，取其最早结束位置，对应前缀必含）。不同的 `x` 对应不同的选择序列，计数不重不漏。∎

**定理**：算法返回好字符串的数目（$\bmod\ 10^9 + 7$）。

**证明**：由引理 3，第 $n$ 层所有状态之和恰为好字符串个数；DP 转移是精确计数（无近似），取模保持同余。∎

## 6. 复杂度分析

- **时间复杂度**：$O(26m + 26 \cdot n \cdot m \cdot 4) = O(26nm)$
  - fail 数组与转移表：$O(26m)$；
  - DP 主循环：$n$ 层 $\times$ $m$ 个状态 $\times$ 4 种标志组合 $\times$ 26 个字符；
  - $n = 500$、$m = 50$ 时约 $2.6 \times 10^6$ 次转移，非常宽裕。
- **空间复杂度**：$O(26m)$（转移表）$+$ $O(4m)$（滚动数组），不计输入。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int findGoodStrings(int n, string s1, string s2, string evil) {
        const long long MOD = 1e9 + 7;
        int m = evil.size();

        // KMP fail 数组
        vector<int> fail(m, 0);
        for (int i = 1, k = 0; i < m; ++i) {
            while (k && evil[i] != evil[k]) k = fail[k - 1];
            fail[i] = (evil[i] == evil[k]) ? ++k : 0;
        }

        // 转移表 nx[j][c]：状态 j 读入字符 c 后的新状态（= m 表示死亡）
        vector<array<int, 26>> nx(m);
        for (int j = 0; j < m; ++j) {
            for (int c = 0; c < 26; ++c) {
                int k = j;
                while (k && evil[k] != 'a' + c) k = fail[k - 1];
                nx[j][c] = (evil[k] == 'a' + c) ? k + 1 : 0;
            }
        }

        // dp[j][lo][hi]，滚动数组
        vector<vector<array<long long, 2>>> dp(
            m, vector<array<long long, 2>>(2));
        dp[0][1][1] = 1;

        for (int i = 0; i < n; ++i) {
            vector<vector<array<long long, 2>>> ndp(
                m, vector<array<long long, 2>>(2));
            int a = s1[i] - 'a', b = s2[i] - 'a';
            for (int j = 0; j < m; ++j) {
                for (int lo = 0; lo < 2; ++lo) {
                    for (int hi = 0; hi < 2; ++hi) {
                        long long cur = dp[j][lo][hi];
                        if (!cur) continue;
                        for (int c = 0; c < 26; ++c) {
                            if (lo && c < a) continue;  // 低于下界
                            if (hi && c > b) continue;  // 超出上界
                            int nj = nx[j][c];
                            if (nj == m) continue;      // 出现 evil
                            long long &to = ndp[nj][lo && c == a][hi && c == b];
                            to = (to + cur) % MOD;
                        }
                    }
                }
            }
            swap(dp, ndp);
        }

        long long ans = 0;
        for (int j = 0; j < m; ++j)
            for (int lo = 0; lo < 2; ++lo)
                for (int hi = 0; hi < 2; ++hi)
                    ans = (ans + dp[j][lo][hi]) % MOD;
        return (int)ans;
    }
};
```

### Python

```python
class Solution:
    def findGoodStrings(self, n: int, s1: str, s2: str, evil: str) -> int:
        MOD = 10 ** 9 + 7
        m = len(evil)

        fail = [0] * m
        k = 0
        for i in range(1, m):
            while k and evil[i] != evil[k]:
                k = fail[k - 1]
            if evil[i] == evil[k]:
                k += 1
            fail[i] = k

        nx = [[0] * 26 for _ in range(m)]
        for j in range(m):
            for c in range(26):
                k = j
                ch = chr(97 + c)
                while k and evil[k] != ch:
                    k = fail[k - 1]
                nx[j][c] = k + 1 if evil[k] == ch else 0

        # dp[j][lo][hi]
        dp = [[[0, 0], [0, 0]] for _ in range(m)]
        dp[0][1][1] = 1

        for i in range(n):
            ndp = [[[0, 0], [0, 0]] for _ in range(m)]
            a, b = ord(s1[i]) - 97, ord(s2[i]) - 97
            for j in range(m):
                for lo in range(2):
                    for hi in range(2):
                        cur = dp[j][lo][hi]
                        if not cur:
                            continue
                        for c in range(26):
                            if lo and c < a:
                                continue
                            if hi and c > b:
                                continue
                            nj = nx[j][c]
                            if nj == m:
                                continue
                            ndp[nj][lo and c == a][hi and c == b] = (
                                ndp[nj][lo and c == a][hi and c == b] + cur
                            ) % MOD
            dp = ndp

        return sum(dp[j][lo][hi] for j in range(m)
                   for lo in range(2) for hi in range(2)) % MOD
```

## 8. 边界情况与易错点

1. **evil 比 n 长**（如 $n = 1$、`evil = "abc"`）：任何串都装不下 `evil`。状态每步至多 $+1$，$n < m$ 时永远到不了 $m$，DP 自动处理，无需特判。
2. **s1 / s2 自身含 evil**（示例 2）：贴界路径中途死亡即可，同样无需特判。
3. **死亡不可复活**：$j$ 到达 $m$ 后必须整支剪掉——`evil` 已出现在前缀里，之后无论填什么都含 `evil`，不存在「失配退回来」的说法。
4. **lo/hi 的语义是「与界的前缀相等」**，不是「大于 / 小于」：只有仍相等才限制当前位，一旦脱离即永久自由。若误写成「每位恒需 $c \ge s1[i]$」会直接漏解。
5. **转移表只建 $j < m$ 的行**：$\delta$ 结果等于 $m$ 时在 DP 里跳过，不要给死亡状态建转移。
6. **取模**：双界写法全程加法，C++ 用 `long long` 累加即可；若改用 $f(s2) - f(s1)$ 差分写法，减法后记得补模。
7. **fail 计算的边界**：`fail[0]` 恒为 0；`while` 回退与 `k` 的复用顺序写错是常见 bug（见参考代码的写法）。
