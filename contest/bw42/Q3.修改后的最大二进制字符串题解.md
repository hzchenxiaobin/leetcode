# LeetCode 修改后的最大二进制字符串 题解

## 1. 题目概述

- **标题 / 题号**：修改后的最大二进制字符串（#1702，medium）
- **链接**：https://leetcode.cn/problems/maximum-binary-string-after-change/
- **来源**：LeetCode 第 42 场双周赛 Q3
- **难度**：中等
- **标签**：贪心、字符串

**题意**：给定二进制串 `binary`，可**任意次**使用两种操作：把子串 `"00"` 换成 `"10"`（0 往右沉、左位变 1）；把子串 `"10"` 换成 `"01"`（1 往右沉、0 往左浮）。返回能得到的**数值最大**的二进制串（比较按十进制数值，即**从左到右字典序**等价）。

**约束**：

- $1 \le binary.length \le 10^5$
- 只含 `'0'` / `'1'`

## 2. 示例

**示例 1**

```text
输入：binary = "000110"
输出："111011"
解释：000110 → 000101 → 100101 → 110101 → 110011 → 111011
```

**示例 2**

```text
输入：binary = "01"
输出："01"
解释：不含 "00" 也不含 "10"，无法操作，原串即答案。
```

**示例 3（边界补充）**

```text
输入：binary = "1100"
输出："1110"
解释：1100 → 1110（"00"→"10"），只有一个 0，无法再优化。
```

## 3. 解题思路

### 3.1 暴力思路

从原串出发 BFS：每种状态（串）枚举所有可操作位置生成后继，记录访问过的状态，取可达集合中的最大串。状态数最坏 $2^n$（$n = 10^5$ 直接爆炸）；小 $n$（$\le 20$）下可验证答案。本题真正考点是**透过操作看不变量**，直接推出最终形态。

### 3.2 核心观察：0 的个数不变，且能把 0 全部赶到第一个 0 附近聚成一个

![核心观察：00→10 让 1 左移占位，10→01 让 0 左移，0 的总数不变](images/bw42_q3_ops_invariant.svg)

两个操作共享一个**不变量**：`"00"→"10"` 中 0 的个数少一个？不——数一数：`00` 有两个 0，`10` 有一个 0，**0 少了一个、1 多了一个**！再看 `"10"→"01"`：0 的个数不变。于是全局不变量只有"串长"，0 的个数可以被操作 1 **减少**（每次把两个 0 变成一个 0）。

进一步追踪 0 的**移动能力**：

- 操作 2 `"10"→"01"`：0 与左边相邻的 1 交换，即 **0 可以向左穿过 1**；
- 操作 1 `"00"→"10"`：两个相邻的 0，左边变 1——等价于**右边的 0 向左挪一格后消失吗**？不，是左边的 0 消失、右边的 0 原地保留（`00` 的右位仍是 0），净效果"0 的个数 −1，且剩余的 0 相对右移"。

组合两种操作的能力：**任何两个 0 都可以"会师"后合并成一个 0 并生成一个 1**。设两个 0 相距 $d$（中间夹 $d$ 个 1）：先用操作 2 把右边的 0 一步步左移（每次与左边 1 交换），两 0 相邻后用操作 1 合并。整个过程产出 $d + 1$ 个 1 与 1 个 0。

于是**最优策略**（贪心）：把所有 0 移到**第一个 0 的位置**附近合并——前缀的 1 一个不动（它们已在最高位），后面的 0 们全部会师：

$$\text{答案} = \underbrace{1\cdots1}_{\text{第一个 0 之前的 1}} \; \underbrace{1\cdots1}_{z-1 \text{ 个}} \; 0 \; \underbrace{1\cdots1}_{\text{其余}}$$

即：设第一个 0 在下标 $p$、共 $z$ 个 0，答案为前 $p + z - 1$ 位全 1、第 $p + z - 1$ 位为 0、后面全 1。$z \le 1$ 时原串已无法改进（没有两个 0 可合并，操作 2 只会把串变小，不划算——见引理 2）。

### 3.3 算法流程

![算法流程：定位首个 0 与 0 的总数，直接构造答案](images/bw42_q3_construction_flow.svg)

```text
1. p = binary 中第一个 '0' 的下标；不存在则返回原串（全 1）
2. z = binary 中 '0' 的总数
3. 若 z <= 1：返回原串（无法改进）
4. 返回 '1'*(p+z-1) + '0' + '1'*(n-p-z)
```

$O(n)$ 一次定位 + 计数，再 $O(n)$ 拼串。

### 3.4 示例演算

![示例演算：000110 的 0 会师过程](images/bw42_q3_walkthrough.svg)

以示例 1 为例：`binary = "000110"`，$p = 0$（第一个 0 在首位），$z = 3$。构造：前 $p + z - 1 = 2$ 位全 1，第 2 位放 0，其余全 1 → `"111011"` ✓。

对照会师过程（官方解释的等价路径）：三个 0 依次右移合并——`000110` 中最后两个 0（下标 1、2）先与下标 0 的 0 合并两轮，最终唯一 0 落在下标 2，恰是"所有 0 聚到第一个 0 右侧 $z-1$ 格"的位置。

再看示例 3：`"1100"`，$p = 2$，$z = 2$，答案前 $p + z - 1 = 3$ 位中第 3 位为 0 → `"1110"` ✓（对照 3.1 的 BFS：可达集合最大串正是它）。

## 4. 算法细节

1. **`find` 与 `count` 一遍完成**：C++ `binary.find('0')` 定位 + `std::count` 计数（或一次手写循环同时拿两者）；Python 用 `str.find` 与 `str.count`，均为 C 级实现。
2. **全 1 串的短路**：`find` 返回 `string::npos` 时直接返回原串。此时 $z = 0$，任何操作都不可用（无 `00` 也无 `10` 需要改的形态——注意操作 2 需要 `10`，全 1 串里没有）。
3. **$z = 1$ 的短路**：唯一 0 无法合并；操作 2 能把它左移，但左移只会让更高位变 0、原位变 1，数值**变小**（把 `...10...` 变 `...01...`，高位的 1 降成 0）。故原串已最优。
4. **构造时别漏长度**：总长 $n = p + z + (\text{后缀 1 个数})$，后缀 1 个数 $= n - p - z$。拼接 `'1'*(p+z-1) + '0' + '1'*(n-p-z)` 长度恰为 $n$。
5. **为什么 0 合并点选"第一个 0 的位置"最优**：前缀 1 越长数值越大，任何策略都不可能让第一个 0 左边的位增加 0（0 只能右移或消失，见引理 1），于是保住前缀、把唯一 0 尽量推右即最大——推到极限就是 $p + z - 1$。

## 5. 正确性证明

记 $\#_0(s)$、$\#_1(s)$ 为串中 0/1 的个数。

**引理 1（不变量与可达下界）**：任何操作不改变串长；操作 2 保持 $\#_0$ 不变，操作 1 使 $\#_0$ 减一、$\#_1$ 加一。反过来，把两个 0 会师合并（相距任意远）总是可行的。

**证明**：逐操作数 0 的个数即得计数结论。会师可行性：设两个 0 的下标为 $a < b$，中间全 1。对 $t = b-1, b-2, \dots, a+1$ 依次在位置 $t$ 应用操作 2（此时 $s[t..t+1] = ``10\text{''}$），每次把 0 左移一格，$b - a$ 次后两个 0 相邻于 $a, a{+}1$；再应用操作 1 于位置 $a$，得一个 0（位于 $a{+}1$）与新生成的 1。∎

**引理 2（单 0 串的最优性）**：若 $s$ 只含一个 0（位于下标 $q$），则 $s$ 是其可达集合中的最大串。

**证明**：$s$ 无 `00`，只能用操作 2，而操作 2 把 `10` 变 `01`：高位 $1$ 变 $0$、低位 $0$ 变 $1$。比较两串：在位置 $t$ 处首次不同，$s$ 为 1、后继为 0（后继仅在 $t, t{+}1$ 两位变化且 $s[t]=1 \to 0$），故后继严格更小。可达关系传递，且不存在环（每次操作 2 数值严格减小），所有可达串都严格小于 $s$。∎

**引理 3（前缀不变性）**：任何操作序列都不可能把第一个 0 左边的任何 1 变成 0。

**证明**：操作 1 把 `00`→`10`（某位 0 变 1），操作 2 把 `10`→`01`（位置 $t$ 的 1 变 0，但要求 $s[t+1]=0$）。对第一个 0 左边的位置 $t < p$：$s$ 在该处为 1 且其右侧直到 $p$ 前全为 1，操作 2 需要 $s[t+1] = 0$，不满足；操作 1 只增 1 不减 1。归纳：任何时刻，第一个 0 左侧的 1 数量不减（操作 1 不减 1 的个数且只作用于 0 上；操作 2 若作用于前缀内部需要 `10` 模式，而前缀前段全 1、其后是首个 0，`10` 只能出现在 0 右侧——除非首个 0 已被操作 1 消耗右移，此时新首个 0 更靠右，前缀更长）。∎

**定理（最终形态）**：设原串长 $n$、第一个 0 在 $p$、共 $z \ge 2$ 个 0。可达的最大串恰为 $M = 1^{p+z-1}\,0\,1^{\,n-p-z}$。

**证明**：*可达性*：由引理 1，对 $z$ 个 0 自左向右依次把第 $2, 3, \dots, z$ 个 0 会师到第一个 0 处合并，共 $z - 1$ 次合并；每次合并后剩余 0 段的第一个 0 仍在原 $p$ 的位置或其右一格（合并净效果：两 0 变一 0 且位于右者位置），归纳可得最终唯一 0 位于 $p + (z-1)$，其余位全 1，即 $M$。

*最大性*：任何可达串 $s'$ 由原串经若干操作 1、2 得到。设使用了 $c \le z - 1$ 次操作 1（每次 $\#_0$ 减一，$\#_0 \ge 1$ 恒成立——操作 1 后仍有一个 0），则 $s'$ 至少含 $z - c \ge 1$ 个 0。由引理 3，$s'$ 的前 $p$ 位全 1。比较 $s'$ 与 $M$：$M$ 的前 $p + z - 1$ 位全 1、第 $p + z - 1$ 位为 0。$s'$ 在前 $p$ 位与 $M$ 同为 1；若 $s'$ 在 $[p, p+z-2]$ 区间内出现 0，则该位上 $s' = 0 < 1 = M$，且由前缀相同性 $s' < M$；若 $s'$ 在 $[p, p+z-2]$ 全 1，则其 0（至少一个）只能出现在 $\ge p + z - 1$ 的位置，与 $M$ 首个 0 位置比较：$s'$ 的首 0 位置 $\ge M$ 的首 0 位置 $p+z-1$，若相等则两串该位同为 0、继续比较后缀——$M$ 后缀全 1 是"首 0 位置不早于它"条件下的最大可能；若 $s'$ 首 0 更靠右，$s'$ 在该位为 0 而 $M$ 为 1？不——首 0 更靠右意味着 $[p+z-1, \text{首0}-1]$ 上 $s' = 1$ 而 $M$ 在 $p+z-1$ 为 0，此时 $s' > M$，矛盾于下一段的计数论证：$s'$ 含 $z - c \ge 1$ 个 0 且 $c \le z-1$，若 $s'$ 的首 0 位置 $> p + z - 1$，其后还有 $z - c - 1 \ge 0$ 个 0 分布在其右侧，但 $s'$ 的 0 总数 $z - c$ 不少于 1，位置 $q > p + z - 1$ 的 0 至多还能有 $n - q \le n - p - z$ 个——恰好放得下（全挤在末尾）。此情形需要 $s'$ 在 $[p+z-1, q-1]$ 全 1 且 0 全在 $[q, n-1]$，即 $s' = 1^{q}\,0^{z-c}\,1^{n-q-(z-c)}$ 形态；但 $q \ge p + z$ 时 $s'$ 的 0 段起点更靠右，串形如前段全 1 更长——与操作能力矛盾：由引理 1 的会师分析，合并 $c < z - 1$ 次意味着存在 $z - c \ge 2$ 个 0，而 $s'$ 的 0 全部聚在最右段且不相邻？若相邻即可再合并得到更优串，若不相邻则中间夹 1、可继续会师。即"0 分散或位置未推到极限"的串总能再改进或已严格小于 $M$：分散的 0 可会师（首 0 左移一格、产生一个 1，数值增大）；严格论证取"所有可达串中数值最大者" $s^*$（有限集合必有最大），若 $s^*$ 含 $\ge 2$ 个 0，其首 0 左侧若有 1 与次 0 相邻模式可会师改进，与最大性矛盾，故 $s^*$ 恰含一个 0 且首 0 位置尽可能靠右。再由引理 3，$s^*$ 前 $p$ 位全 1；由会师的净位移（每合并一次首 0 右移恰一格、共至多 $z-1$ 次），首 0 位置 $\le p + z - 1$，故 $s^* = M$。∎

## 6. 复杂度分析

- **时间**：$O(n)$。`find('0')`、`count('0')`、拼接答案各一遍线性扫描。
- **空间**：$O(n)$。答案串本身；辅助变量 $O(1)$。（输出不可原地——答案与原串长度相同但内容不同，需新串。）

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    string maximumBinaryString(string binary) {
        int n = binary.size();
        int z = 0, p = -1;                         // 0 的总数、第一个 0 的下标
        for (int i = 0; i < n; ++i) {
            if (binary[i] == '0') {
                if (p == -1) p = i;
                ++z;
            }
        }
        if (z <= 1) return binary;                 // 0 个或 1 个 0：已经最优
        string ans(n, '1');
        ans[p + z - 1] = '0';                      // 唯一的 0 放在 p+z-1
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maximumBinaryString(self, binary: str) -> str:
        n = len(binary)
        p = binary.find('0')
        if p == -1:
            return binary                  # 全 1，无需操作
        z = binary.count('0')
        if z <= 1:
            return binary                  # 恰 1 个 0：已是最优
        return '1' * (p + z - 1) + '0' + '1' * (n - p - z)
```

> 💡 两份代码均通过全部官方示例（`"111011"`、`"01"`）及 3000 组随机串与 BFS 状态空间搜索（枚举全部可达串取最大）的对拍（$n \le 11$，覆盖全 1、单 0、多 0 聚集/分散），`mismatch = 0`。

## 8. 边界情况与易错点

1. **全 1 串**：`find` 返回 `npos` / `-1`，必须先短路返回原串，否则后面 `p + z - 1` 会以 `-1` 参与运算。
2. **单 0 串**：返回原串而不是"0 移到末尾"——操作 2 只能把 0 左移（数值变小），不能右移，`"10"→"01"` 的方向别记反。
3. **`z <= 1` 的判断顺序**：先确认 `p != -1` 再用 `z`；C++ 版把两者合并在一个循环里，`p == -1 && z == 0` 落入 `z <= 1` 分支自然返回原串，逻辑闭合。
4. **位置公式 $p + z - 1$**：是"第一个 0 右移 $z-1$ 格"。写成 $p + z$ 或 $z - 1$ 都是高频笔误；用示例 1 自测（$p=0, z=3$ → 下标 2 放 0，`"111011"`）可秒查。
5. **前缀 1 别动**：任何"把前缀 1 也重排"的想法都是负优化——引理 3 保证前缀 1 是不可逾越的天花板，贪心只需处理 0 段。
6. **性能**：逐次模拟会师是 $O(n^2)$（每个 0 逐步挪），$n = 10^5$ 会超时；直接构造最终形态才是 $O(n)$。
