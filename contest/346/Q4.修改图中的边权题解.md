# LeetCode 修改图中的边权 题解

## 1. 题目概述

- **标题 / 题号**：修改图中的边权（#2699，hard）
- **链接**：https://leetcode.cn/problems/modify-graph-edge-weights/
- **来源**：LeetCode 第 346 场周赛 Q4
- **难度**：困难
- **标签**：图、最短路径、贪心、堆（优先队列）、Dijkstra

**题意**：给定 $n$ 个节点的**无向带权连通**图（无自环、无重边），`edges[i] = [ai, bi, wi]`。部分边权为 $-1$（**可修改**），其余为正数（**固定**）。需要把每条 $-1$ 边都修改为 $[1, 2\times10^9]$ 中的正整数，使 `source` 到 `destination` 的**最短距离恰为** `target`。存在方案时返回**所有边**（含固定边）组成的数组，任意合法方案均可；不存在则返回空数组。固定边一律不可修改。

**约束**：

- $1 \le n \le 100$
- $1 \le \text{edges.length} \le \dfrac{n(n-1)}{2} \le 4950$
- $w_i = -1$ 或 $1 \le w_i \le 10^7$；$a_i \ne b_i$
- $0 \le \text{source}, \text{destination} \lt n$ 且 $\text{source} \ne \text{destination}$
- $1 \le \text{target} \le 10^9$
- 图连通

> 💡 **困难题题眼**：「$-1$ 边只能改成 $[1, 2\times10^9]$ 的正数、固定边动不了」⇒ 相对于「把 $-1$ 边视作不存在」，加回可改边只会让最短路**更短或不变**，于是最短路被夹在「全 $1$」与「全 $2\times10^9$」两个极端之间。本文走官方题解的「**上界试探 + 逐条下压 + 跌破回调**」路线，与[每日题解 2699](../../solution/2601-2700/2699_修改图中的边权.md)的「**下界试探 + 最短路上逐条抬升**」互为对偶，两篇互为印证；本文按周赛复盘主线，重点补齐「回调为何必然恰好命中」的循环不变式证明（§5），并给出「自顶向下 / 自底向上」两种贪心的对照（延伸思考）。

## 3. 解题思路

### 3.1 暴力思路

可改边的权取值于 $[1, 2\times10^9]$，条数最多 $4950$，赋值组合空间是 $(2\times10^9)^{4950}$，穷举不可行；即使离散化候选权，也说不清哪些值可能出现在合法方案里——`target` 的缺口可能要**分摊**到一条路径的多条可改边上（如示例 1：$5 = 1+3+1$），单看某一条边无从定值。

> ⚠️ 关键转化：题目**不要求求出全部合法方案，只要求构造一个**。与其「搜索一组权」，不如「让某条最短路恰好落在 `target` 上、其余路径全部 ≥ `target`」——把搜索问题变成**构造**问题。

### 3.2 核心观察：上界试探 + 逐条下压 + 跌破回调

![核心观察：上界试探三分支与逐条下压回调](images/wc346_q4_press_down_concept.svg)

三个观察层层递进：

1. **双极端夹逼**：可改边只能赋正权（≥ 1），全部取 $1$ 是「最快」状态；全部取 $W = 2\times10^9$（题目上界）是「最慢」状态——而 $W > 10^9 \ge \text{target}$，含可改边的路径全被**冻结**在 `target` 之上，等价于「几乎不存在」。于是一次 Dijkstra 就能判定上界状态。

2. **上界试探三分支**：全置 $W$ 跑 Dijkstra 得 $d$：
   - $d \lt \text{target}$：取得 $d$ 的最短路**必不含可改边**（含则 $\ge W \gt \text{target} \gt d$），即固定边路径已比 `target` 短且**永远动不了** ⇒ 无解，返回 `[]`；
   - $d == \text{target}$：运气好直接命中，全部保持 $W$ 返回；
   - $d \gt \text{target}$：缺口必须由可改边弥补，转入逐条下压。

3. **逐条下压 + 跌破回调**：按固定顺序把可改边逐条**压到 1**，每压一条重跑 Dijkstra：
   - 仍 $\gt \text{target}$：还不够短，这条边**留在 1**，压下一条；
   - 恰 $== \text{target}$：收工，未压到的边保持 $W$；
   - $\lt \text{target}$：**压过头了**——但跌破只会由刚压的这条边 $e$ 造成（压之前最短路 $\gt \text{target}$，所有不含 $e$ 的路径长度不变、仍 $\gt \text{target}$，所以跌破后的最短路**必经过 $e$**）。把 $e$ 回调到 $\text{target} - d + 1$：这条最短路恰好补到 $\text{target}$，其余路径仍全部 $\ge \text{target}$，精确命中收工。

> 💡 一句话：**把「自由度」逐条收掉（$W \to 1$），收过头就用差值精确回吐**。回调的正确性完全由循环不变式「压每条边之前最短路恒 $\gt \text{target}$」托底（§5 引理 2、引理 3）。

### 3.3 算法流程

![算法流程：上界试探、逐条下压、跌破回调](images/wc346_q4_algorithm_flow.svg)

```text
记录可改边（w = −1），全部置 W = 2×10⁹，建邻接表（存边下标）
d ← Dijkstra(source → destination)
① d <  target → 返回 []（固定边路径已太短，无解）
② d == target → 返回 edges（可改边全为 W，合法）
   d >  target → 逐条下压：
     对每条可改边 e（按下标顺序）：
        e ← 1；d ← Dijkstra
③      d >  target → 保持 1，压下一条
④      d == target → 返回 edges（未压到的保持 W）
⑤      d <  target → e ← target − d + 1，返回 edges
   全部压到 1 仍 > target → 返回 []（下界都不够近，无解）
```

五个出口：①②③⑤ 判定 / 构造的合法性由 §5 的引理逐一托底；④ 的「回调为何恰好命中」是本题证明的核心。

### 3.4 示例演算

![示例演算：示例 1 的逐条下压全过程](images/wc346_q4_example_walkthrough.svg)

以**示例 1**（$n=5$，四条边全可改，$\text{source}=0$，$\text{dest}=1$，$\text{target}=5$；唯一通路 $0\text{-}3\text{-}4\text{-}1$）走一遍，$W = 2\times10^9$：

| 步骤 | 操作 | $(4,1)(2,0)(0,3)(4,3)$ 当前权 | $d(0\to1)$ | 判定 |
|------|------|------------------------------|-----------|------|
| ① 上界试探 | $-1$ 全置 $W$ | $(W, W, W, W)$ | $2W+1$ | $>5$，转入下压 |
| ② 试探 $(4,1)$ | 置 1 | $(1, W, W, W)$ | $2W+1$ | $>5$，保持 1 |
| ③ 试探 $(2,0)$ | 置 1 | $(1, 1, W, W)$ | $2W+1$ | $>5$，保持 1 |
| ④ 试探 $(0,3)$ | 置 1 | $(1, 1, 1, W)$ | $W+2$ | $>5$，保持 1 |
| ⑤ 试探 $(4,3)$ | 置 1 | $(1, 1, 1, 1)$ | $3$ | $\lt 5$，压过头 |
| ⑥ 回调 | $(4,3) \leftarrow 5-3+1=3$ | $(1, 1, 1, 3)$ | $5$ | $==5$ ✓ 返回 |

返回 $[[4,1,1],[2,0,1],[0,3,1],[4,3,3]]$——与官方示例输出 $[[4,1,1],[2,0,1],[0,3,3],[4,3,1]]$（把 3 放在 $(0,3)$ 上）是**两种都合法**的方案，判题只验证最短路。

其余示例的落点：

- **示例 2**：上界试探即出局——$(0,1)=W$ 时 $d=\text{dist}(0\to2)=5$（固定边 $0\text{-}2$ 直接可达）$\lt 6$，出口①判无解。
- **示例 3**：上界试探 $d=7\gt6$ 转入下压；压 $(0,3)$ 为 1 后 $d=\min(7,\ 1+5)=6$，出口④恰好命中。
- **自拟示例 4**：下压完全部三条边后 $d=3\gt2$，出口⑤判无解。

## 4. 算法细节

1. **邻接表存「边下标」而非边权**：边权在 `edges` 数组上**原地修改**，Dijkstra 每轮直接读 `edges[i][2]` 的最新值，避免每轮重建邻接表。
2. **距离必须用 64 位**：路径长可达 $n \cdot W \approx 100 \times 2\times10^9 = 2\times10^{11}$，远超 32 位 `int` 上限（$\approx 2.1\times10^9$）；C++ 用 `long long`，Python 天然大整数。
3. **Dijkstra 提前出队**：正权图中小根堆**弹出即最短**，只关心 `source → destination`，弹出 `destination` 即可返回，实测提速明显。
4. **回调值的范围自动合法**：$d \lt \text{target} \Rightarrow w = \text{target} - d + 1 \ge 2$，且 $w \le \text{target} \le 10^9 \lt W$，天然落在 $[1, 2\times10^9]$ 内，无需额外判断。
5. **处理顺序任意**：证明（§5）不依赖可改边的处理顺序，按下标顺序最简单；顺序只影响 Dijkstra 的轮数，不影响正确性。
6. **未压到的边必须保持 $W$ 返回**：$W = 2\times10^9$ 本身就在允许区间内，且保证「含这些边的路径 $\ge W \gt \text{target}$」的地位不被破坏；若顺手把它们也置 1，可能把其他路径压短，破坏「恰好命中」。
7. **只改 $w = -1$ 的边**：固定边（$1 \le w \le 10^7$）一律不碰，返回时原样带回。

## 5. 正确性证明

约定：$W = 2\times10^9$，「方案」指给每条 $-1$ 边赋 $[1, W]$ 内正整数的完整赋值。

**引理 1（上界无解判据）**：所有 $-1$ 边置 $W$ 后最短路 $d \lt \text{target}$，则任何方案下最短路 $\le d \lt \text{target}$，无解。

**证明**：由 $\text{target} \le 10^9 \lt W$ 与 $d \lt \text{target}$ 知 $d \lt W$。取得 $d$ 的最短路 $P$ 若含任一可改边（此时权为 $W$），则 $\text{len}(P) \ge W \gt d$，矛盾，故 $P$ 全由固定边组成。固定边在任何方案下不变，故任何方案下 $\text{len}(P) = d \lt \text{target}$，最短路 $\le \text{len}(P) \lt \text{target}$ ∎

**引理 2（循环不变式）**：逐边下压阶段，处理任一条边 $e$ 之前，当前最短路 $d_{\text{prev}} \gt \text{target}$（或算法已返回）。

**证明**：归纳法。奠基：进入逐边阶段的前提是上界试探得 $d \gt \text{target}$（$<$、$==$ 已各自返回）。归纳步：处理 $e$ 时试探置 1 得 $d$——若 $d \gt \text{target}$，$e$ 定格为 1，新的最短路即 $d \gt \text{target}$，不变式传递给下一条边；若 $d = \text{target}$ 或 $d \lt \text{target}$，算法返回，不变式无需再成立 ∎

**引理 3（回调精确命中）**：设处理 $e$ 前最短路 $d_{\text{prev}} \gt \text{target}$（引理 2），把 $e$ 置 1 后最短路 $d \lt \text{target}$。令 $w = \text{target} - d + 1$，把 $e$ 定格为 $w$、未处理的 $-1$ 边保持 $W$，则最终最短路恰为 $\text{target}$。

**证明**：

1. **不含 $e$ 的路径**：长度与 $e$ 的权无关，在「试探 1」前后不变，均 $\ge d_{\text{prev}} \gt \text{target}$（整权，故 $\ge \text{target}+1$）。
2. 故取得 $d$ 的最短路 $P^*$ **必含 $e$**（否则 $d \ge d_{\text{prev}} \gt \text{target}$，与 $d \lt \text{target}$ 矛盾）；正权图最短路是简单路径，$P^*$ **恰含 $e$ 一次**。
3. $e$ 定格为 $w$ 后：不含 $e$ 的路径不变，仍 $\gt \text{target}$；含 $e$ 的简单路径长度 $=$ 原长 $+ (w-1) \ge d + (\text{target}-d) = \text{target}$；而 $P^*$ 恰为 $d + (w-1) = \text{target}$。故最短路 $= \text{target}$。
4. 合法性：$2 \le w \le \text{target} \le 10^9 \lt W$，赋值落在 $[1, W]$ 内 ∎

**引理 4（下界无解判据）**：所有 $-1$ 边置 1 后仍 $d \gt \text{target}$，则无解。

**证明**：任何方案中每条 $-1$ 边权 $\ge 1$，故每条路径在任意方案下的长度 $\ge$ 全 1 状态下的长度，最短路 $\ge d \gt \text{target}$，不可能等于 $\text{target}$ ∎

**定理**：算法在有限步内终止；返回非空当且仅当存在合法方案，且返回方案的最短路恰为 $\text{target}$。

**证明**：终止性：逐边阶段每条 $-1$ 边至多处理一次，至多 $m$ 轮。出口完备枚举：

- ① 上界试探 $d \lt \text{target}$：由引理 1，判无解正确；
- ② 上界试探 $d == \text{target}$：可改边全为 $W \in [1, W]$，固定边未动，当前最短路即 $\text{target}$，方案合法；
- ③ 下压中 $d \gt \text{target}$：保持 1 继续循环，非出口；
- ④ 下压中 $d == \text{target}$：当前赋值最短路 $= \text{target}$，未压到的边保持 $W$ 合法，方案合法；
- ⑤ 下压中 $d \lt \text{target}$：由引理 3，回调后最短路恰为 $\text{target}$，方案合法；
- ⑥ 全部压 1 仍 $\gt \text{target}$：由引理 4，判无解正确。

反证必要性：若存在合法方案而算法返回空——出口①与引理 1 矛盾（固定边路径 $d \lt \text{target}$ 在任何方案下都压着最短路）；出口⑥与引理 4 矛盾。故存在合法方案时算法必返回非空 ∎

> 💡 证明的脊梁是**引理 2 的不变式**：它把「压过头」从事故变成了「跌幅唯一归因于刚压的边」的凭据，引理 3 的精确回调才有落点。这是「先维持安全余量，再一次性花掉」贪心的标准论证范式。

## 6. 复杂度分析

- **时间复杂度**：$O(m^2 \log n)$。初始试探 1 次 + 逐条下压至多 $m$ 次 Dijkstra，每次堆优化 Dijkstra 为 $O(m \log n)$；$m \le 4950$、$n \le 100$，理论上界约 $10^8$ 量级，但「提前出队」与「多数用例极早命中」让实测远低于上界。
- **空间复杂度**：$O(n + m)$。邻接表 $O(m)$、距离数组 $O(n)$、堆 $O(m)$。

### C++

```cpp
class Solution {
public:
    vector<vector<int>> modifiedGraphEdges(int n, vector<vector<int>>& edges,
                                            int source, int destination, int target) {
        const long long W = 2e9;                      // 题目允许的权上界
        int m = edges.size();
        vector<char> isMod(m, 0);                     // 哪些边原本是 -1（可改）
        vector<vector<pair<int, int>>> adj(n);        // (邻点, 边下标)
        for (int i = 0; i < m; ++i) {
            if (edges[i][2] == -1) { isMod[i] = 1; edges[i][2] = (int)W; }
            adj[edges[i][0]].push_back({edges[i][1], i});
            adj[edges[i][1]].push_back({edges[i][0], i});
        }
        auto dijkstra = [&]() -> long long {          // 只关心 source → destination
            vector<long long> dist(n, LLONG_MAX);
            priority_queue<pair<long long, int>, vector<pair<long long, int>>, greater<>> pq;
            dist[source] = 0;
            pq.push({0, source});
            while (!pq.empty()) {
                auto [d, u] = pq.top(); pq.pop();
                if (d > dist[u]) continue;
                if (u == destination) break;          // 正权图：弹出即最短
                for (auto [v, i] : adj[u]) {
                    long long nd = d + edges[i][2];   // 读最新权，原地生效
                    if (nd < dist[v]) { dist[v] = nd; pq.push({nd, v}); }
                }
            }
            return dist[destination];
        };

        long long d = dijkstra();                     // ① 上界试探
        if (d < target) return {};                   // 固定边路径已太短，无解
        if (d == target) return edges;                // 全保持 2×10⁹，直接返回

        for (int i = 0; i < m; ++i) {                 // ② 逐条下压
            if (!isMod[i]) continue;
            edges[i][2] = 1;                          // 试探压到下界 1
            d = dijkstra();
            if (d > target) continue;                 // 还不够短，保持 1 压下一条
            if (d == target) return edges;            // 恰好命中，其余保持 2×10⁹
            edges[i][2] = target - (int)d + 1;        // 压过头：回调补齐缺口
            return edges;
        }
        return {};                                    // ③ 全压到 1 仍 > target，无解
    }
};
```

### Python

```python
import heapq

class Solution:
    def modifiedGraphEdges(self, n: int, edges: List[List[int]],
                           source: int, destination: int, target: int) -> List[List[int]]:
        W = 2 * 10 ** 9
        adj = [[] for _ in range(n)]                  # (邻点, 边下标)
        is_mod = [e[2] == -1 for e in edges]
        for i, (a, b, w) in enumerate(edges):
            if w == -1:
                edges[i][2] = W                       # ① 上界试探：全压到上界
            adj[a].append((b, i))
            adj[b].append((a, i))

        def dijkstra() -> int:
            done = [False] * n
            h = [(0, source)]
            while h:
                d, u = heapq.heappop(h)
                if u == destination:
                    return d                          # 正权图：弹出即最短
                if done[u]:
                    continue
                done[u] = True
                for v, i in adj[u]:
                    if not done[v]:
                        heapq.heappush(h, (d + edges[i][2], v))
            return -1                                 # 图连通，走不到这一行

        d = dijkstra()
        if d < target:
            return []                                # 固定边路径已太短，无解
        if d == target:
            return edges

        for i in range(len(edges)):                   # ② 逐条下压
            if not is_mod[i]:
                continue
            edges[i][2] = 1                           # 试探压到下界 1
            d = dijkstra()
            if d > target:
                continue                              # 还不够短，保持 1 压下一条
            if d == target:
                return edges                          # 恰好命中，其余保持 2×10⁹
            edges[i][2] = target - d + 1              # 压过头：回调补齐缺口
            return edges
        return []                                     # ③ 全压到 1 仍 > target，无解
```

> 💡 两版逻辑完全一致：上界试探三分支 → 逐条下压三分支 → 两个无解出口兜底。C++ 的 `dijkstra` 用 `long long` 距离 + 「弹出 `destination` 即返回」；Python 版 `dijkstra` 以「弹出即最短」直接 `return d`，天然提前收工。

## 8. 边界情况与易错点

1. **32 位溢出**：路径长可达 $\approx 2\times10^{11}$（$n \cdot W$），C++ 距离数组与返回值必须 `long long`；用 `int` 会回绕成负数，三分支判定全乱。
2. **回调的 off-by-one**：$w = \text{target} - d + 1$，不是 $\text{target} - d$——回调后路径长是 $d + (w-1)$，少写 $+1$ 最短路就是 $\text{target}-1$。
3. **未压到的边必须保持 $2\times10^9$**：既满足合法区间，又保住「含它们的路径 $\gt \text{target}$」的冻结地位；顺手置 1 或置别的值都可能把其他路径压短、破坏精确命中。
4. **无解有两个出口，别只写一个**：① 上界试探 $d \lt \text{target}$（固定边太短）；② 全压到 1 仍 $d \gt \text{target}$（下界都不够近）。
5. **固定边不能动**：只有 $w = -1$ 的边可改，误改固定边直接判错；返回数组要**包含所有边**（固定边原样带回）。
6. **答案不唯一，别去比对官方输出**：判题只验证最短路是否恰为 `target`，构造出的任何合法方案都行（示例 1 本解与官方示例输出就不同）。
7. **提前出队的正确性**：正权图中小根堆「弹出即最短」，所以 `u == destination` 时直接 `break` / `return` 是安全的；图保证连通，`destination` 必然可达。
8. **Dijkstra 惰性删除**：`if (d > dist[u]) continue` 是堆优化的标准写法，别在入堆时判重导致漏松弛。

**延伸思考**：

- **对偶视角**：本文（官方题解路线）「全 $W$ 起步、逐条压 1、跌破回调」维护的不变式是「最短路 $\gt \text{target}$ 直至命中」；每日题解路线「全 1 起步、每轮在**最短路上**找一条可改边抬升 $\text{deficit}$、循环复验」维护的不变式是「最短路 $\lt \text{target}$ 直至抬平」。前者逐边处理、每轮一次 Dijkstra；后者逐**路径**处理、每轮两次 Dijkstra（两端各一）。两者都是「保持安全余量、把缺口一次性花掉」的贪心，对照着看能提炼出同一套证明模板（不变式 + 单次花掉余量 + 复验终止）。
- **$W$ 为什么取 $2\times10^9$**：它必须**严格大于 $\text{target}$ 的上界** $10^9$，「含可改边的路径被冻结在 $\text{target}$ 之上」才成立，引理 1、3 全靠这一条。若题目把权的上界改成 $\le 10^9$（可能不超过 `target`），三分支与回调证明都要重做。
- **更紧的复杂度**：逐条下压每轮只有一条边变化，理论上可用「一次 Dijkstra + 受影响子树的增量更新」把总复杂度摊还到接近单次 Dijkstra；但 $n \le 100$、$m \le 4950$，$O(m^2\log n)$ 已绰绰有余。
- **变体：最短路「不超过 target」**：可行性等价于「全 1 下界 $\le \text{target}$」，上界试探与回调都可省去，只留下界判据 + 全 1（或直接命中）构造，难度骤降——可见「**恰好等于**」才是本题全部难度所在。
