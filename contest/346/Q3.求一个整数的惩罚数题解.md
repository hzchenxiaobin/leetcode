# LeetCode 求一个整数的惩罚数 题解

## 1. 题目概述

- **标题 / 题号**:求一个整数的惩罚数(#2698,medium)
- **链接**:https://leetcode.cn/problems/find-the-punishment-number-of-an-integer/
- **来源**:LeetCode 第 346 场周赛 Q3
- **难度**:中等
- **标签**:数学、回溯、剪枝

**题意**:给定正整数 $n$,返回 $n$ 的**惩罚数**——所有满足如下条件的 $i$($1 \le i \le n$)的**平方和**:$i^2$ 的十进制表示串可以分割成若干**连续子串**,且各子串对应整数值之**和恰好等于 $i$**。

**约束**:

- $1 \le n \le 1000$ ⇒ $i^2 \le 10^6$:数字串至多 **7 位**、至多 **6 个间隙**,单串切法至多 $2^6 = 64$ 种

> 💡 **题眼**:标准的「数字串连续分段 + 段和等于定值」判定题,与复原 IP、分割回文串同族。每个间隙只有「切 / 不切」两种选择,$2^{L-1}$ 级别的搜索空间配上**超上剪枝**就是最自然的写法。本题与[每日题解 2698](../../solution/2601-2700/2698_求一个整数的惩罚数.md)是同一道题:那篇侧重**递归走查与面试问答**,本篇按周赛复盘主线,补上**位掩码暴力 → 回溯剪枝**的推导、**引理-定理式证明**与**打表 / 记忆化扩展**。

## 3. 解题思路

### 3.1 暴力思路:位掩码枚举所有切法

对每个 $i$,记 $s = \text{str}(i^2)$。长度 $L$ 的串有 $L-1$ 个间隙,每个间隙「切 / 不切」二选一,共 $2^{L-1}$ 种切法——直接用一个 $L-1$ 位**位掩码**逐种枚举、求和判等:

```text
for mask in 0 .. 2^(L-1) - 1:
    按 mask 二进制位决定各间隙切或不切
    把 s 切成若干连续段,累加段值得 sum
    若 sum == i:i 合格,答案累加 i²
```

$L \le 7$ ⇒ 单个 $i$ 至多 $64$ 种切法,$n = 1000$ 时总判定 $\le 6.4\times10^4$ 次,**比赛时完全能过**。但它有两个缺点:每种切法都要重新解析子串;更关键的是**毫无结构性**——「首段越长、段值越大」的单调性被完全浪费,大量早已超上的分支照样走满。

### 3.2 核心观察:回溯切分 + 超上剪枝

![核心观察:把 i² 的数字串切成连续段,段值之和恰好等于 i](images/wc346_q3_partition_concept.svg)

把「$i$ 是否合格」的判定写成递归函数 $\text{canSplit}(\text{pos},\ \text{target})$:从 $s$ 的第 $\text{pos}$ 位起,能否切出若干连续段,使段值之和**恰好为** $\text{target}$(初始 $\text{target} = i$)。每层只有三个动作:

1. **两步决策**:吃下首段 $s[\text{pos}..j]$,得段值 $\text{val}$;递归判定 $\text{canSplit}(j+1,\ \text{target} - \text{val})$。
2. **超上剪枝**:$\text{val}$ 随 $j$ 逐位 $\times 10 + d$ **单调不减**,一旦 $\text{val} > \text{target}$ 立即 `break`——更长的首段只会更大,该分支整体作废。
3. **终止判定**:$\text{pos}$ 抵达串尾时返回 $\text{target} == 0$:整串已被连续段覆盖完,看剩余目标是否恰好归零。

> ⚠️ 两个易漏点:其一,段**允许前导 0**($100 = 10 + 0$ 的第二段 `"0"` 值为 0,与复原 IP 不同,无需特判);其二,剪枝条件必须**严格大于**——$\text{val} = \text{target}$ 时后面还可能跟着 `"0"` 段把它们零消耗地消耗掉,写成 $\ge$ 会漏掉**全部**合格数(见 §8 第 2 条)。

### 3.3 算法流程

![算法流程:canSplit 的回溯递归树与短路](images/wc346_q3_backtrack_tree.svg)

以 $i = 36$、$s = \texttt{1296}$、初始 $\text{target} = 36$ 展开递归树:

- 首段「1」($\text{val} = 1 \le 36$)→ 子问题 $(\text{pos}=1,\ t=35)$:
  - 段「2」→ $(2,\ 33)$:段「9」→ $(3,\ 24)$:段「6」→ 串尾剩 $24 - 6 = 18 \ne 0$,**死路**(红),回溯;
  - 回溯换段「29」($29 \le 35$)→ $(3,\ 6)$:段「6」→ 串尾 $6 - 6 = 0$,**命中**(绿),逐层短路返回 true;
  - 「296」:$296 > 35$,属于该层的剪枝分支——但因「29」支已命中,**循环未及到达**;
- 首段「12」「129」「1296**:首段「1」的分支命中后 `return true` 逐层短路,**这些分支一次都没跑**(图中虚线框)。

**回退在哪**:某层递归返回 false 后,`for j` 循环自然推进——**换一种首段长度再试**,这就是回溯;每层只用局部变量 `val`,无需显式撤销。**判定型的关键提速**:找到**任一**可行切分即逐层 `return true`,与复原 IP 等「枚举所有方案」的题型不同,搜索树往往只走一小片。

把镜头拉远:$[1, 1000]$ 的合格集合是**固定有限集**,共 **29** 个:

```text

657, 675, 703, 756, 792, 909, 918, 945, 964, 990, 991, 999, 1000
```

(用 §7 代码本地跑一遍即可复现。)两个可迁移的观察:$9/10/99/100/999/1000$ 这类 $10^k \pm 1$ 形的数**全部合格**($81 = 8+1$、$100 = 10+0$、$9801 = 98+01$、$998001 = 998+0+01$、$1000000 = 1000+0$);合格密度极稀(29/1000),绝大多数 $i$ 在回溯的前几层就被剪干净。

## 4. 算法细节

1. **逐位累乘构造段值**:$\text{val} \leftarrow \text{val}\times10 + d$,一条 for 同时完成「试吃每种首段长度 + 增量求值」,避免每次 `substr` 再转 int 的重复解析。
2. **剪枝严格大于**:$\text{val} > \text{target}$ 才 `break`;$\text{val} = \text{target}$ 必须继续递归收尾(§8 第 2 条)。
3. **判定与累加解耦**:`canSplit` 只回答能否;外层统一累加 $i^2$——是**平方和**,不是 $i$ 之和。
4. **访问序即剪枝友好序**:按 $j$ 从小到大试首段,`break` 后同层更长首段全部跳过;不同首段之间靠递归返回 false 自然回溯,顺序不影响正确性(引理 3 与顺序无关)。
5. **提前短路**:任一层命中即逐层返回,只有最坏情形(不合格的 $i$)才走满剪枝后的搜索树。

## 5. 正确性证明

**引理 1(段值单调性)**:固定起点 $\text{pos}$,记 $\text{val}(j)$ 为子串 $s[\text{pos}..j]$ 的整数值,则 $j$ 增大时 $\text{val}(j)$ 单调不减。

**证明**:$\text{val}(j+1) = \text{val}(j)\times10 + d_{j+1}$,其中数字 $d_{j+1} \ge 0$,故 $\text{val}(j+1) \ge \text{val}(j)$ ∎

**引理 2(剪枝安全)**:若 $\text{val}(j) > \text{target}$,则首段取 $s[\text{pos}..j']$($j' \ge j$)的**任何**分割,段值之和都 $> \text{target}$。

**证明**:由引理 1,首段值 $\text{val}(j') \ge \text{val}(j) > \text{target}$;其余段值皆为非负整数,故总和 $\ge \text{val}(j') > \text{target}$,不可能等于 $\text{target}$。故 `break` 砍掉的分支中不含任何可行解 ∎

**引理 3(判定等价)**:对任意 $0 \le \text{pos} \le L$ 与 $\text{target} \ge 0$,$\text{canSplit}(\text{pos},\ \text{target})$ 返回 true,当且仅当 $s[\text{pos}..]$ 存在段值之和等于 $\text{target}$ 的连续段划分。

**证明**:对 $L - \text{pos}$ 归纳。奠基 $\text{pos} = L$:后缀为空,唯一划分(空划分)之和为 $0$,代码返回 $\text{target} == 0$,恰与定义一致。归纳步 $\text{pos} < L$:非空划分的首段唯一形如 $s[\text{pos}..j]$;由引理 2,只需考察 $\text{val}(j) \le \text{target}$ 的 $j$(其余必无解,代码也恰好对这些 $j$ 之前 break)。对该范围内每个 $j$:划分之和为 $\text{target}$ $\iff$ $\text{val}(j) + (\text{后缀划分之和}) = \text{target}$ $\iff$ $\text{canSplit}(j+1,\ \text{target} - \text{val}(j))$ 返回 true(归纳假设)。for 循环恰对这些 $j$ 取「或」并短路,返回值与存在性一致。终止性:每层递归 $\text{pos}$ 严格增大,至多 $L+1$ 层 ∎

**定理**:算法返回值等于 $n$ 的惩罚数。

**证明**:外层枚举 $i = 1, \dots, n$ 完备;由引理 3,$\text{canSplit}(0,\ i)$ 为 true $\iff$ $i$ 合格;合格者累加 $i^2$。故返回值为全部合格 $i$ 的平方和,即惩罚数 ∎

> 💡 证明的脊梁是**引理 2**:单调性让「超上即弃」一刀切掉大片无解区域、且切口不伤任何解——这套「单调 → 超上剪枝 → 安全性引理」的论证模板,在组合总和、划分等和子集等回溯题里可原样复用。

## 6. 复杂度分析

- **时间复杂度**:$O\!\left(n \cdot 2^{L-1}\right)$,$L \le 7$ 为 $i^2$ 的位数。单次判定至多遍历 $2^{L-1} \le 64$ 种切法(剪枝后远小于此),$n = 1000$ 时总操作 $\le 6.4\times10^4$。由 $2^{L-1} = n^{o(1)}$,渐近亦可写成 $O\!\left(n^{1+o(1)}\right)$;把 $L$ 当常数即 $O(n)$。
- **空间复杂度**:$O(L)$。递归深度等于数字串长度($L \le 7$),另有 $O(L)$ 临时串。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int punishmentNumber(int n) {
        int ans = 0;
        for (int i = 1; i <= n; ++i) {
            int sq = i * i;
            if (canSplit(to_string(sq), 0, i)) {
                ans += sq;                      // 累加的是 i² 不是 i
            }
        }
        return ans;
    }

private:
    // s[pos..] 能否切成若干连续段,使段值之和 == target
    bool canSplit(const string& s, int pos, int target) {
        if (pos == (int)s.size()) {
            return target == 0;                 // 整串覆盖完,看是否归零
        }
        int val = 0;
        for (int j = pos; j < (int)s.size(); ++j) {
            val = val * 10 + (s[j] - '0');      // 逐位吃成一段
            if (val > target) break;            // 超上剪枝:严格大于才 break
            if (canSplit(s, j + 1, target - val)) {
                return true;                    // 判定型:命中即短路
            }
        }
        return false;
    }
};
```

### Python

```python
class Solution:
    def punishmentNumber(self, n: int) -> int:
        def can_split(s: str, pos: int, target: int) -> bool:
            if pos == len(s):
                return target == 0              # 整串覆盖完,看是否归零
            val = 0
            for j in range(pos, len(s)):
                val = val * 10 + (ord(s[j]) - 48)   # 逐位吃成一段
                if val > target:
                    break                       # 超上剪枝:严格大于才 break
                if can_split(s, j + 1, target - val):
                    return True                 # 判定型:命中即短路
            return False

        return sum(i * i for i in range(1, n + 1)
                   if can_split(str(i * i), 0, i))
```

> 💡 两版逻辑一致:外层枚举 + 内层「逐位累乘、超上剪枝、递归剩余目标」。比赛时若怕手滑,§3.1 的位掩码枚举(约十行)同样能过;回溯版只是把同一棵搜索树剪得更干净、写得更快。

## 8. 边界情况与易错点

1. **贡献是 $i^2$ 不是 $i$**:求的是平方和,判定合格后累加 `i * i`,这是最冤的 WA 点。
2. **剪枝必须严格大于**:若写成 $\text{val} \ge \text{target}$ 就 break,会漏掉**全部** 29 个合格数——命中路径的最后一段必然有 $\text{val} = \text{target}$(如 $10 + 0$ 中首段 `"10"` 恰等于 $\text{target} = 10$),$=$ 被砍就永远递归不到串尾。实测:`>` 判出 29 个合格数,`>=` 判出 0 个。
3. **整串必须覆盖完**:只有 $\text{pos}$ 到达串尾才能下结论;中途 $\text{target}$ 归零不算命中(还有数字没切)。
4. **段允许前导 0**:`"0"`、`"00"` 段合法且值为 0,累乘 $0\times10 + d$ 自动处理,别照抄复原 IP 的「禁前导 0」剪枝。
5. **$n = 1$ 下界**:$i = 1$、单字符 `"1"`、整段 $[1] \to 1 = 1$ ✓,答案为 1。
6. **无溢出风险**:$i^2 \le 10^6$,$\text{val}$ 超过 $\text{target} \le 1000$ 前就会 break,`int` 足够。
7. **位掩码写法的对应关系**:$L-1$ 个间隙与 mask 的二进制位一一对应,每段至少含一位、不存在空段;若手写暴力解析,注意切点与段边界的错位问题。

**延伸思考**:

- **打表**:$[1, 1000]$ 的合格集合固定(29 个),可离线跑一遍算法、存成有序数组与前缀和,在线查询二分 + 前缀和 $O(\log)$ 搞定——数据范围小、查询多时值得。
- **记忆化 DP**:状态 $(\text{pos}, \text{target})$ 的可行性可记忆化(本质是可行性背包),状态数 $O(L \cdot i) \le 7000$;但剪枝后的搜索树本就极小,记忆化收益有限、反增哈希开销——「判定型小数据用回溯,大数据或多查询才上 DP / 打表」。
- **约束放大的方向**:若 $n \to 10^9$,$i^2$ 长达 19 位、单串 $2^{18}$ 种切法,逐 $i$ 回溯总量爆炸;而合格数极稀疏(密度 2.9%),值得研究**正向构造**——枚举 $i^2$ 的分割方式反推 $i$,把判定问题翻转成生成问题,这是与本题对偶的视角。
