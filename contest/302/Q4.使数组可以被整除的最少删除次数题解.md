# LeetCode 使数组可以被整除的最少删除次数 题解

## 1. 题目概述

- **标题 / 题号**：使数组可以被整除的最少删除次数（#2344，hard）
- **链接**：https://leetcode.cn/problems/minimum-deletions-to-make-array-divisible/
- **来源**：LeetCode 第 302 场周赛 Q4
- **难度**：困难
- **标签**：数组、数学、数论、最大公约数、欧几里得算法、排序、堆（优先队列）

**题意**：给定两个正整数数组 `nums` 和 `numsDivide`，允许从 `nums` 中删除任意数目的元素。目标是让剩余 `nums` 的**最小元素**能整除 `numsDivide` 中的**每一个**元素，求最少删除次数；若无法做到返回 $-1$。（若 $y \bmod x = 0$，称 $x$ 整除 $y$，记 $x \mid y$。）

**约束**：

- $1 \le \text{nums.length},\ \text{numsDivide.length} \le 10^5$
- $1 \le \text{nums}[i],\ \text{numsDivide}[i] \le 10^9$

> 💡 赛时快速切入信号：题面里"最小元素……整除**所有**元素"的"所有"二字，是**逐元素验证**的伪装——数论里"$x$ 整除一组数的每一个"等价于"$x$ 整除它们的最大公约数"。一次 gcd 折叠把 $O(m)$ 的验证塌缩成一次取模；再注意到**只有最小值需要合格**，"删除"就退化成"计数"。识别出这两点后，这是一道 15 分钟内可落地的压轴题。

## 2. 示例

**示例 1**

```text
输入：nums = [2,3,2,4,3], numsDivide = [9,6,9,3,15]
输出：2
解释：最小元素 2 不能整除 numsDivide 的全部元素；
     删除 2 个值为 2 的元素后 nums = [3,4,3]，最小元素 3 整除 9,6,9,3,15。
```

**示例 2**

```text
输入：nums = [4,3,6], numsDivide = [8,2,6,10]
输出：-1
解释：g = gcd(8,2,6,10) = 2，nums 中没有任何元素整除 2，无解。
```

**示例 3**（补充：答案为 0，且不整除 g 的大元素不必删）

```text
输入：nums = [2,5,7], numsDivide = [12,18]
输出：0
解释：最小元素 2 整除 g = gcd(12,18) = 6，从而整除 12 与 18，一步不用删；
     5、7 虽不整除任何元素，但它们大于最小值，去留不影响合法性。
```

## 3. 解题思路

### 3.1 暴力思路

枚举 `nums` 中每个元素 $x$ 充当"幸存最小值"：

- 验证 $x$ 整除 `numsDivide` 的每个元素：$O(m)$ 次取模；
- 若合格，统计使 $x$ 成为最小值需要删除的元素个数（严格小于 $x$ 的元素数）：$O(n)$。

总复杂度 $O(n \cdot (n + m))$，$n = m = 10^5$ 时约 $4 \times 10^{10}$，必然超时。即便先用一次 gcd 把整除验证降到 $O(1)$，对每个候选重复计数仍是 $O(n^2)$——**瓶颈在于"对每个候选重复统计"，而答案其实只取决于一个数：最小合格元素**。

### 3.2 核心观察：gcd 折叠 + 只看最小合格元素

![gcd 折叠与整除判定的概念图](images/wc302_q4_gcd_fold_concept.svg)

**观察 1（整除全体 ⟺ 整除 gcd）**：设 $g = \gcd(\text{numsDivide})$，则正整数 $x$ 整除 `numsDivide` 的每个元素，当且仅当 $x \mid g$。

- "$\Leftarrow$"：$g$ 本身是公因子，$x \mid g \mid d_i$ 由传递性得 $x \mid d_i$；
- "$\Rightarrow$"：由 Bézout 等式，$g$ 是各 $d_i$ 的整系数组合，$x$ 整除每一项则整除其组合。

一次 $O(m \log V)$ 的折叠后，合格判定从 $O(m)$ 降为**一次取模**。

**观察 2（合法当且仅当最小值合格）**：操作后数组是否合法，只取决于**剩余数组的最小元素**是否整除 $g$——比它大的元素去留完全无关（见示例 3）。于是设 $x^{*}$ 为 `nums` 中整除 $g$ 的最小元素，则：

- 所有严格小于 $x^{*}$ 的元素**必须**删——它们都不整除 $g$，一旦留下，最小值的位置就被不合格者占据；
- 删完后 $x^{*}$ 恰好成为最小值，数组合法。

**答案 $= \#\{y \in \text{nums} : y < x^{*}\}$，与"具体保留哪些大元素"无关。**

**观察 3（排序扫描一步到位）**：把 `nums` 升序排序后从左扫描，**第一个**满足 $g \bmod \text{nums}[i] = 0$ 的下标 $i$ 就是答案——排序保证前 $i$ 个元素严格更小；等于 $x^{*}$ 的元素同值、同样整除 $g$，扫描必然停在 $x^{*}$ 的**首次出现处**。扫完仍无命中则返回 $-1$。

### 3.3 算法流程

![算法流程图](images/wc302_q4_scan_flow.svg)

1. 折叠 $g = \gcd(d_1, \dots, d_m)$：$g$ 从 $0$ 出发（$\gcd(0, d) = d$），逐个并入；
2. `nums` 升序排序；
3. 从左扫描：若 $g \bmod \text{nums}[i] = 0$，返回 $i$；若 $\text{nums}[i] > g$，直接返回 $-1$（正整数 $x \mid g \Rightarrow x \le g$，其后元素只会更大）；
4. 扫描结束无命中，返回 $-1$。

> ⚠️ 全程没有任何"删除"动作——答案只是一个计数。赛时把"删除"当真去模拟（开新数组、逐个搬移）是无谓的工程负担，也是压轴题里罕见的"实现零风险"。

### 3.4 示例演算

![示例演算图](images/wc302_q4_example_walkthrough.svg)

以示例 1 演算：`numsDivide = [9,6,9,3,15]` 折叠得 $g = 3$；`nums` 排序为 $[2,2,3,3,4]$：

| $i$ | $\text{nums}[i]$ | $g \bmod \text{nums}[i]$ | 判定 |
|-----|------------------|---------------------------|------|
| 0 | 2 | $3 \bmod 2 = 1$ | ✗，继续 |
| 1 | 2 | $3 \bmod 2 = 1$ | ✗，继续 |
| 2 | 3 | $3 \bmod 3 = 0$ | ✓ 命中，返回 2 |

删去两个 2 后剩余 $[3,3,4]$，最小元素 3 整除 $9,6,9,3,15$ 全部成立 ✓。对照示例 2：$g = 2$，排序后 $[3,4,6]$ 无一整除 2（且全部大于 2，提前终止即可发现无解），返回 $-1$。

## 4. 算法细节

1. **gcd 折叠**：$g$ 初始为 $0$，逐个 $g = \gcd(g, d_i)$。C++ 用 `<numeric>` 的 `std::gcd`（或 `__gcd`），Python 用 `math.gcd`，二者均满足 $\gcd(0, d) = d$，无需特判首元素。总代价 $O(m \log V)$，$V = 10^9$。
2. **判定方向**：合格条件是 $g \bmod x = 0$（$x$ 整除 $g$），**不是** $x \bmod g = 0$（详见 §8 第 1 条，本题最高频 WA 点）。
3. **下标即计数**：升序数组中首个命中下标 $i$ 恰等于严格小于 $x^{*}$ 的元素个数——排序让"计数"退化为"位置"，这正是官方标签里排序与堆的共同来源。堆版本：小根堆不断弹出最小值，弹到整除 $g$ 为止，答案 = 弹出个数；与排序版等价但常数更大，价值在于**流式**输入时无需预先全量排序。
4. **提前终止**：升序扫描一旦 $\text{nums}[i] > g$，其后元素只会更大、更不可能整除 $g$，可直接返回 $-1$。它同时给出一条有用的先验：**大于 $g$ 的元素永远不合格**。
5. **两遍线性变体（不排序）**：一次遍历求 $x^{*} = \min\{x \in \text{nums} : g \bmod x = 0\}$，再一次遍历数 $\#\{y : y < x^{*}\}$，时间 $O(n + m \log V)$、额外空间 $O(1)$：

```python
g = 0
for d in numsDivide:
    g = gcd(g, d)
cand = [x for x in nums if g % x == 0]
return -1 if not cand else sum(y < min(cand) for y in nums)
```

6. **因子枚举视角**：合格元素必是 $g$ 的因子，也可 $O(\sqrt{g})$ 枚举 $g$ 的全部因子、哈希查询是否在 `nums` 中出现，取最小者——$g \le 10^9$ 时 $\sqrt{g} \approx 3.2 \times 10^4$，因子总数至多约 1344。写法更长，仅在 $g$ 很小而 $n$ 极大时略优（daily 版题解对此有完整展开）。
7. **无溢出**：值域 $\le 10^9$，`int` 全程安全；gcd 的中间结果不超过两参数的较大者，这是 gcd 族相对 lcm 族的天然优势。

## 5. 正确性证明

**引理 1（gcd 等价判定）**：设 $g = \gcd(d_1, \dots, d_m)$，$x$ 为正整数，则 $x \mid d_i\ (\forall i)$ 当且仅当 $x \mid g$。

**证明**：($\Leftarrow$) $g$ 是 $d_1, \dots, d_m$ 的公约数，即 $g \mid d_i$ 对每个 $i$ 成立；与 $x \mid g$ 链式传递得 $x \mid d_i$。($\Rightarrow$) 由 Bézout 等式，存在整数 $u, v$ 使 $\gcd(a, b) = ua + vb$；gcd 满足结合律，对多个数归纳可得存在整数 $c_1, \dots, c_m$ 使 $g = \sum_i c_i d_i$。若 $x \mid d_i$ 对每个 $i$ 成立，则 $x$ 整除该整系数组合，即 $x \mid g$。∎

**引理 2（合法删除集的结构刻画）**：视 `nums` 为多重集，记删除集 $D$，剩余 $R = \text{nums} \setminus D$。$D$ 合法（$R$ 非空且其最小元素整除所有 $d_i$）当且仅当：存在 $x \in R$ 使得 $x \mid g$ 且 $\{y \in \text{nums} : y < x\} \subseteq D$。

**证明**：($\Rightarrow$) 设 $D$ 合法，取 $x = \min R$，则 $x \in R$ 且由引理 1 知 $x \mid g$；若某个 $y < x$ 未被删（$y \in R$），则 $\min R \le y < x$，与 $x = \min R$ 矛盾，故 $\{y : y < x\} \subseteq D$。($\Leftarrow$) 设 $x \in R$，$x \mid g$，且所有小于 $x$ 的元素均在 $D$ 中，则 $R \subseteq \{y \in \text{nums} : y \ge x\}$ 且 $x \in R$，故 $\min R = x$；由引理 1，$x$ 整除所有 $d_i$，$D$ 合法。∎

**定理（最优删除次数）**：设 $x^{*} = \min\{x \in \text{nums} : x \mid g\}$（若该集合非空），则最少删除次数恰为 $\mathrm{cnt} = \#\{y \in \text{nums} : y < x^{*}\}$；若集合为空，返回 $-1$。

**证明**：设 $D$ 为任意合法删除集，由引理 2（$\Rightarrow$）存在 $x \in R = \text{nums} \setminus D$ 满足 $x \mid g$，故 $x \ge x^{*}$（$x^{*}$ 是 `nums` 中整除 $g$ 的最小元素），于是

$$D \supseteq \{y : y < x\} \supseteq \{y : y < x^{*}\} \implies |D| \ge \mathrm{cnt}.$$

反之取 $D_0 = \{y \in \text{nums} : y < x^{*}\}$：$x^{*} \notin D_0$（$x^{*} \not< x^{*}$）且 $x^{*} \mid g$，由引理 2（$\Leftarrow$）知 $D_0$ 合法，且 $|D_0| = \mathrm{cnt}$。故最优值 $= \mathrm{cnt}$。若集合为空：合法集要求剩余最小元整除 $g$，即 `nums` 中存在整除 $g$ 的元素，矛盾，故无合法方案，返回 $-1$。∎

**推论（排序扫描的正确性）**：升序排序后，首个满足 $g \bmod \text{nums}[i] = 0$ 的元素值恰为 $x^{*}$，其下标恰为 $\mathrm{cnt}$。

**证明**：设扫描在下标 $i$ 首次命中，值 $v = \text{nums}[i]$。下标 $< i$ 的元素均不整除 $g$ 且升序排列，故都严格小于 $v$；又 $v \mid g$，由 $x^{*}$ 的最小性有 $x^{*} \le v$。若 $x^{*} < v$，排序后 $x^{*}$ 的某次出现应位于 $v$ 之前且使扫描命中，与"首次命中在 $i$"矛盾，故 $v = x^{*}$。等于 $x^{*}$ 的元素与 $x^{*}$ 同值、同样整除 $g$，故首个命中必是 $x^{*}$ 的**首次出现**，其前的元素全部严格小于 $x^{*}$，即 $i = \mathrm{cnt}$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \log n + m \log V)$。排序 $O(n \log n)$ 主导；gcd 折叠 $O(m \log V)$（每次欧几里得 $O(\log V)$，$V = \max\, \text{numsDivide} \le 10^9$）；扫描 $O(n)$ 且常因提前终止更短。以 $n = m = 10^5$ 计约 $3 \times 10^6$ 基本操作，比暴力的 $4 \times 10^{10}$ 低四个数量级。
- **空间复杂度**：$O(1)$ 额外空间（原地排序，语言排序实现的递归栈 $O(\log n)$ 不计）。两遍线性变体免排序后时间 $O(n + m \log V)$、空间严格 $O(1)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minOperations(vector<int>& nums, vector<int>& numsDivide) {
        int g = 0;
        for (int d : numsDivide) g = __gcd(g, d);   // gcd(0, d) = d，起点无需特判
        sort(nums.begin(), nums.end());
        for (int i = 0; i < (int)nums.size(); ++i) {
            if (g % nums[i] == 0) return i;         // 首个整除 g 者：前 i 个更小元素全删
            if (nums[i] > g) return -1;             // 升序下其后只会更大，提前出局
        }
        return -1;
    }
};
```

### Python

```python
from math import gcd

class Solution:
    def minOperations(self, nums: List[int], numsDivide: List[int]) -> int:
        g = 0
        for d in numsDivide:
            g = gcd(g, d)                    # gcd(0, d) = d
        for i, x in enumerate(sorted(nums)):
            if g % x == 0:
                return i                     # 答案 = 已跳过的更小元素个数
            if x > g:
                break                        # 其后只会更大，无解
        return -1
```

## 8. 边界情况与易错点

1. **取模方向写反（本题最高频 WA）**：合格判定是 `g % x == 0`（$x$ 整除 $g$），不是 `x % g == 0`。反例 $g = 6, x = 3$：正确判"能"（$3 \mid 6$），反写 $3 \bmod 6 = 3$ 判"不能"。$x > g$ 时 `x % g` 的值与"$x$ 是否整除 $g$"毫无关系。
2. **只需最小值合格**：不要顺手删掉"不整除 $g$ 的大元素"——它们大于最小值，去留不影响合法性（示例 3 答 0）。把目标误读成"让数组整体变干净"是常见的语义偏差。
3. **$g = 1$**：此时仅 $x = 1$ 可能合格。若 $1 \in \text{nums}$，排序后必居首位，答案为 0（没有比 1 更小的正整数）；否则无解返回 $-1$。
4. **大于 $g$ 的元素永不合格**：正整数 $x \mid g \Rightarrow x \le g$。升序扫描据此可提前终止；"无解"的常见形态正是全体元素大于 $g$ 或与 $g$ 互质。
5. **重复元素**：答案统计的是**严格小于** $x^{*}$ 的个数，等于 $x^{*}$ 的副本全部保留；排序扫描天然停在首次出现处，无需去重。
6. **gcd 折叠起点**：$g$ 从 $0$ 起步并依赖 $\gcd(0, d) = d$；`std::gcd` / `math.gcd` 均满足该约定，手写辗转相除 `gcd(a, b) = b ? gcd(b, a % b) : a` 也自动保持。
7. **$-1$ 的语义**：是"`nums` 中不存在能整除 $g$ 的元素"，与"删得不够多"无关——删得越多，能当最小值的候选只会变少不会变多。
8. **别模拟删除**：答案只是计数；开辅助数组逐个 `erase` 会额外叠加 $O(n)$ 搬移，纯开销。
9. **单元素数组**：$n = 1$ 时合格答 0、不合格答 $-1$，排序扫描天然覆盖，无需特判。
