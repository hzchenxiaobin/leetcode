# LeetCode 每棵子树内缺失的最小基因值 题解

## 1. 题目概述

- **标题 / 题号**：每棵子树内缺失的最小基因值（#2003，hard）
- **链接**：https://leetcode.cn/problems/smallest-missing-genetic-value-in-each-subtree/
- **来源**：LeetCode 第 258 场周赛 Q4
- **难度**：困难
- **标签**：树、深度优先搜索、欧拉序、双指针、mex

**题意**：一棵以节点 $0$ 为根的家族树共 $n$ 个节点，`parents[i]` 给出节点 $i$ 的父节点（`parents[0] == -1`）。每个节点带一个**互不相同**的基因值 `nums[i]`（取值 $[1, 10^5]$）。对每个节点 $i$，求以 $i$ 为根的**子树**（$i$ 及其全部后代）的基因值集合中**缺失的最小正整数**，返回长度为 $n$ 的数组 `ans`。

**约束**：

- $n == \text{parents.length} == \text{nums.length}$，$2 \le n \le 10^5$
- `parents[0] == -1`，其余 $0 \le \text{parents}[i] \le n-1$，构成一棵合法的树
- $1 \le \text{nums}[i] \le 10^5$，且**互不相同**

> 💡 **审题关键**：① 「互不相同」是全场最强的一条约束——它意味着值 $1$ 全树**唯一**，而 mex $\ge 2$ 的子树必须含值 $1$，含 $1$ 的子树恰好排布在一条路径上；② $n$ 高达 $10^5$，对每个节点独立收集子树值再求 mex 的 $O(n^2)$ 必然超时；③ mex 的上界由**元素个数**决定而非值域：$n$ 个互异值 ⟹ $\text{mex} \le n+1$，值 $> n+1$ 的基因值永远当不上答案。

## 3. 解题思路

### 3.1 暴力思路：逐节点收集子树值

最直观的做法：对每个节点 $i$，DFS 收集子树内全部基因值放入集合，再从 $1$ 起递增找到第一个不在集合中的正整数。单个节点代价 $O(\text{子树大小})$，全体求和为 $O(n^2)$（每个节点被它的每个祖先各访问一次）；$n = 10^5$ 时约 $10^{10}$ 次操作，必然超时。改成自底向上「小并大」合并孩子集合（启发式合并，$O(n \log n)$）虽然能过，代码却偏重。

**浪费所在**：① 父节点子树 = 路径孩子子树 ∪ 侧子树，暴力对父节点从头收集，重复劳动；② **完全没利用「基因值互不相同」**——这正是把全树问题压缩到一条路径的钥匙。

### 3.2 核心观察：一条路径 + 一个只前进的指针

![核心观察：答案大于 1 的节点只分布在 node1 到根的路径上](images/wc258_q4_path_concept.svg)

**观察一（值 1 唯一 ⟹ 路径剪枝）**：基因值互不相同 ⟹ 值 $1$ 只出现在唯一节点 $\text{node}_1$。子树含 $1$ ⟺ 该节点是 $\text{node}_1$ 的祖先或自身 ⟺ 位于 $\text{node}_1 \to$ 根的路径上。**不在路径上的节点子树不含 1，答案直接为 1**（示例 3 的全 1 输出是这一观察的极端形态）——全树只剩一条长度 $\le n$ 的路径需要真正计算。

**观察二（子树沿路径只增 ⟹ mex 单调不减）**：从 $\text{node}_1$ 沿父指针向上，子树集合**单调增大**（每上一层并入当前节点本身与各侧兄弟子树，只增不减）。集合只增 ⟹ 缺失的最小正整数只增不减。于是可以维护一个**值域双指针** $j$（「下一个候选缺失值」），沿路径向上时**只前进、不回退**，全程总推进量 $\le n+1$。

**观察三（子树 ⟺ 欧拉序区间 ⟹ $O(1)$ 成员判定）**：值互不相同还给出「值 $j$ ↔ 节点 $\text{pos}[j]$」的双射。做一次 DFS 记录每个节点的进入时间 $\text{tin}$ 与 $\text{tout}$（子树内最大的 $\text{tin}$），则

$$\text{值 } j \in \text{subtree}(u) \iff \text{tin}[u] \le \text{tin}[\text{pos}[j]] \le \text{tout}[u]$$

**「值在不在子树里」变成两次时间戳比较**。路径节点的答案，就是第一个使该判定失败（或该值根本不存在）的 $j$（从 $2$ 起查，因为路径节点的子树必含 $1$）。

> 💡 **等价的「公共祖先」视角**：$\text{ans}[u] \ge k+1 \iff \text{subtree}(u) \supseteq \{1,\dots,k\} \iff u$ 是 $\text{node}_1,\dots,\text{node}_k$ 的公共祖先 $\iff u$ 位于根到 $\text{LCA}(\text{node}_1,\dots,\text{node}_k)$ 的路径上。$k$ 增大时这条路径**自底向上逐段萎缩**——正是观察二中双指针单调性的几何解释。沿此视角用倍增 LCA「剥落」实现可得 $O(n \log n)$ 的另一版本，本文选更轻的欧拉序版。

### 3.3 算法流程：欧拉序 + 值域双指针

![算法流程：建树与时间戳、定位 node1、沿路径向上推进双指针](images/wc258_q4_euler_flow.svg)

1. **建树**：由 `parents` 构造 `children` 邻接表；建 `pos`（值 → 节点映射，仅登记 $\le n+1$ 的值）。
2. **特判**：`pos[1] == -1`（全树无值 1）⟹ 返回全 1 数组。
3. **一次迭代 DFS**：求 `tin` / `tout`（欧拉序时间戳，链状树防爆栈）。
4. **沿路径向上推进双指针**：$j = 2$，$u$ 从 $\text{node}_1$ 出发：
   - 推进：`while j ≤ n+1 且 pos[j] ≠ -1 且 tin[u] ≤ tin[pos[j]] ≤ tout[u]`：`j++`；
   - 记录：`ans[u] = j`；
   - 上移：`u = parents[u]`，直到走出根。
5. **返回** `ans`（路径外节点保持默认值 1）。

> ⚠️ **与姊妹篇的分工**：每日题解版沿同一条路径**自底向上显式 DFS 侧子树**、把值并进 `seen` 布尔数组来推进 mex；本文**完全不做侧子树 DFS、不维护任何集合**——「值在不在子树里」被欧拉区间的两次比较虚拟化。两版同为 $O(n)$，是「显式集合合并」与「虚拟区间判定」两种风味的镜像对照。

### 3.4 示例演算

![示例演算：示例 2 的欧拉序时间轴与双指针推进过程](images/wc258_q4_walkthrough.svg)

以示例 2 `parents = [-1,0,1,0,3,3], nums = [5,4,6,2,1,3]` 为例：$\text{node}_1 = 4$，路径 $4 \to 3 \to 0$。一次 DFS 按进入顺序得到时间轴 `0(5), 1(4), 2(6), 3(2), 4(1), 5(3)`，即 $\text{tin} = [0,1,2,3,4,5]$、$\text{tout} = [5,2,2,5,4,5]$：

| 阶段 | 当前 $u$ | 子树区间 | $j$ 的推进 | $\text{ans}[u]$ |
|------|---------|---------|-----------|------|
| ① | 4（$\text{node}_1$） | $[4,4]$ | $j{=}2$：值 2 在节点 3，$\text{tin}[3]{=}3 \notin [4,4]$ → 停 | 2 |
| ② | 3 | $[3,5]$ | $j{=}2$：$\text{tin}[3]{=}3 \in$；$j{=}3$：值 3 在节点 5，$\text{tin}[5]{=}5 \in$；$j{=}4$：值 4 在节点 1，$\text{tin}[1]{=}1 \notin$ → 停 | 4 |
| ③ | 0（根） | $[0,5]$ | $j{=}4$：值 4 在节点 1，$\in$；$j{=}5$：值 5 在节点 0，$\in$；$j{=}6$：值 6 在节点 2，$\in$；$j{=}7$：值 7 不存在 → 停 | 7 |

路径外节点 1、2、5 的子树不含 1，保持默认值 1。最终 `ans = [7,1,1,4,2,1]` ✓。

> 💡 **注意 $j$ 从不回退**：阶段 ② 的答案 4 在阶段 ③ 直接作为起点继续推进——子树从 $[3,5]$ 扩到 $[0,5]$ 只可能放进更多值，之前缺的不会凭空补上。这正是双指针合法性的直观来源（§5 引理 3/4）。

## 4. 算法细节

1. **迭代式欧拉序**：栈中节点配一个孩子游标 `it[u]`；**首次**到达时记 `tin[u] = timer++`，孩子耗尽时记 `tout[u] = timer - 1`（即子树内最大的 `tin`）。相比「进入/离开都计时」的写法省一半事件，判定式也统一只用 `tin[v]`。$n = 10^5$ 的链状树递归会爆栈，必须迭代。
2. **`pos` 只开 `n + 2`**：基因值虽可达 $10^5$，但 $n$ 个互异值 ⟹ $1..n+1$ 中必有缺失 ⟹ $\text{mex} \le n+1$（§5 引理 5）。值 $> n+1$ 的基因值既不会被指针查询、也不可能成为答案，登记时直接跳过——空间从 $O(\max \text{nums})$ 压到 $O(n)$。
3. **推进条件的三段短路顺序**：先 `j ≤ n+1`（防数组越界），再 `pos[j] != -1`（存在性），最后时间戳区间判定（最贵）——把廉价检查放前面。
4. **`pos` 与 `nums` 互为逆映射**：互不相同保证「值 → 节点」是良定义函数，这是观察三成立的前提；若值可重复则双射崩塌（见延伸思考）。
5. **路径遍历的终止**：`for (u = pos[1]; u != -1; u = parents[u])`——`parents[根] == -1` 天然作为循环出口，无需单独判根。
6. **路径外节点零访问**：侧子树整体不 DFS、不标记——剪枝不只是「答案为 1」的推理，更是复杂度的直接来源：全算法只走一条路径 + 一趟时间戳 DFS。

## 5. 正确性证明

**引理 1（子树的欧拉区间刻画）**：一次从根出发的 DFS 为每个节点记录进入时间 $\text{tin}[u]$，令 $\text{tout}[u]$ 为 $u$ 子树内最大的进入时间。则对任意节点 $u, v$：

$$v \in \text{subtree}(u) \iff \text{tin}[u] \le \text{tin}[v] \le \text{tout}[u]$$

**证明**：DFS 按「进入 $u$ → 依次完整访问 $u$ 各孩子的子树 → 离开 $u$」进行，$u$ 的整棵子树在时间轴上占据连续一段 $[\text{tin}[u], \text{tout}[u]]$（离开 $u$ 之前不会进入子树外的任何节点）。⟹：$v$ 为 $u$ 自身或后代时，$\text{tin}[v]$ 必落在该区间。⟸：若 $\text{tin}[v]$ 落在区间内，则 $v$ 是在「进入 $u$ 之后、离开 $u$ 之前」被访问的，此窗口内被访问的节点恰为 $\text{subtree}(u)$，故 $v \in \text{subtree}(u)$。∎

**引理 2（路径剪枝）**：基因值互不相同 ⟹ 值 $1$ 全树唯一，记其所在节点为 $\text{node}_1$。对任意节点 $u$：$\text{ans}[u] \ge 2 \iff \text{subtree}(u) \ni 1 \iff u \in \text{path}(\text{node}_1 \to \text{root})$；路径外的节点 $\text{ans}[u] = 1$。

**证明**：mex $\ge 2$ ⟺ 值 $1$ 属于子树值集；值互不相同 ⟹「子树值集含 1」⟺「$\text{node}_1 \in \text{subtree}(u)$」⟺ $u$ 是 $\text{node}_1$ 的祖先或自身（后代关系与子树包含关系一一对应）。路径外 ⟹ 不含 1 ⟹ 缺失的最小正整数恰为 1。∎

**引理 3（$f$ 沿路径单调不减）**：对路径节点 $u$ 定义 $f(u) = \min\{\, j \ge 2 : \text{pos}[j] = -1 \ \lor\ \text{pos}[j] \notin \text{subtree}(u) \,\}$（即 $u$ 的子树从 $2$ 起第一个「不存在或不在子树内」的值），则 $\text{ans}[u] = f(u)$；且若 $p = \text{parents}[u]$，则 $f(u) \le f(p)$。

**证明**：先证 $\text{ans}[u] = f(u)$：路径节点的子树含 1，故其 mex 是从 $2$ 起第一个不在子树值集中的 $j$，即 $f(u)$（「值不存在」已并入「不在子树内」）。再证单调性：$u \in \text{subtree}(p)$ ⟹ $\text{subtree}(u) \subseteq \text{subtree}(p)$；若 $\text{pos}[j]$ 存在且 $\text{pos}[j] \in \text{subtree}(u)$，则 $\text{pos}[j] \in \text{subtree}(p)$，即 $p$ 的失败集合是 $u$ 的失败集合的子集，其最小值相应不小：$f(p) \ge f(u)$。∎

**引理 4（双指针不变量）**：设算法自底向上依次处理路径节点 $u_0 = \text{node}_1, u_1 = \text{parents}[u_0], \dots$，处理 $u_i$ 前的指针值为 $j_0 = 2$、处理完 $u_i$ 后为 $j_{i+1}$。若 $j_i \le f(u_i)$，则 while 循环恰好把指针推进到 $f(u_i)$（故 $\text{ans}[u_i] = f(u_i)$），且 $j_{i+1} = f(u_i) \le f(u_{i+1})$。

**证明**：对 $i$ 归纳。基础：$j_0 = 2 \le f(u_0)$（$f$ 的候选从 2 起）。归纳步：由 $f$ 的定义，一切 $j' \in [2, f(u_i))$ 都「存在且 $\text{pos}[j'] \in \text{subtree}(u_i)$」——由引理 1，这正是 while 的推进条件；又 $j_i \le f(u_i)$，故指针从 $j_i$ 出发无阻拦地越过 $[j_i, f(u_i))$，在 $f(u_i)$ 处条件失败（$f(u_i)$ 对应的值要么不存在、要么不在子树内）而停下，得 $j_{i+1} = f(u_i)$，赋值正确。再由引理 3，$f(u_i) \le f(u_{i+1})$，归纳前提传递给下一步。∎

**引理 5（值域上界）**：全程 $j \le n+1$；算法写出的每个答案 $\le n+1$，且 `pos` 永不被越界访问。

**证明**：反设某轮 while 把 $j$ 推过了 $n+1$，即 $2..n+1$ 这 $n$ 个值全部存在且都落在当前子树内；当前节点在路径上，其子树又必含值 1——子树共含 $n+1$ 个互异值，超过其节点数（$\le n$），矛盾。故指针至多推进到 $n+1$（途中必有缺失值截停）。∎

**定理**：算法返回的数组中，$\text{ans}[u]$ 恰为每个节点子树的 mex。

**证明**：路径外节点由引理 2 得 1（初值未被覆盖）；路径上每个节点 $u_i$ 由引理 4 得 $\text{ans}[u_i] = f(u_i)$，而由引理 3 前半部分，$f(u_i)$ 正是该子树从 $2$ 起的第一个缺失值、即 mex（其子树含 1）；由引理 5 无越界且答案有界。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。建邻接表与 `pos` 各一趟 $O(n)$；迭代 DFS 每个节点进出栈一次、每条边压栈一次，$O(n)$；路径遍历至多 $n$ 步；值域双指针 $j$ 单调不减、全程总推进 $\le n+1$（引理 5）；每次指针判定为常数次比较（引理 1）。
- **空间复杂度**：$O(n)$。`children` 邻接表、`tin`/`tout`、`pos`（只开 $n+2$）、`ans` 与显式 DFS 栈均为线性。
- **对照**：逐节点暴力 $O(n^2)$ 在 $n = 10^5$ 下约 $10^{10}$ 次操作必超时；「小并大」集合合并 $O(n \log n)$ 可过但更重；本文与姊妹篇同为 $O(n)$——前者以「合并集合」推进 mex，本文以「区间判定」推进 mex。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    vector<int> smallestMissingValueSubtrees(vector<int>& parents, vector<int>& nums) {
        int n = parents.size();
        vector<vector<int>> children(n);
        for (int i = 1; i < n; ++i)
            children[parents[i]].push_back(i);

        vector<int> pos(n + 2, -1);              // 值 -> 节点；值 > n+1 当不上 mex，不登记
        for (int i = 0; i < n; ++i)
            if (nums[i] <= n + 1) pos[nums[i]] = i;

        vector<int> ans(n, 1);                   // 路径外节点默认 1
        if (pos[1] == -1) return ans;            // 全树无值 1 -> 全 1

        vector<int> tin(n), tout(n);             // 欧拉序：进入时间 / 子树内最大 tin
        int timer = 0;
        vector<int> stk = {0}, it(n, 0);
        while (!stk.empty()) {
            int u = stk.back();
            if (it[u] == 0) tin[u] = timer++;
            if (it[u] < (int)children[u].size()) {
                stk.push_back(children[u][it[u]++]);
            } else {
                tout[u] = timer - 1;             // 孩子耗尽：子树内最大的 tin
                stk.pop_back();
            }
        }

        int j = 2;                               // 值域双指针，全程只前进
        for (int u = pos[1]; u != -1; u = parents[u]) {
            while (j <= n + 1 && pos[j] != -1
                   && tin[u] <= tin[pos[j]] && tin[pos[j]] <= tout[u]) ++j;
            ans[u] = j;
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def smallestMissingValueSubtree(self, parents: List[int], nums: List[int]) -> List[int]:
        n = len(parents)
        children = [[] for _ in range(n)]
        for i in range(1, n):
            children[parents[i]].append(i)

        pos = [-1] * (n + 2)                     # 值 -> 节点；值 > n+1 当不上 mex，不登记
        for i, v in enumerate(nums):
            if v <= n + 1:
                pos[v] = i

        ans = [1] * n                            # 路径外节点默认 1
        if pos[1] == -1:                         # 全树无值 1 -> 全 1
            return ans

        tin = [0] * n                            # 欧拉序：进入时间 / 子树内最大 tin
        tout = [0] * n
        timer = 0
        stk, it = [0], [0] * n
        while stk:
            u = stk[-1]
            if it[u] == 0:
                tin[u] = timer
                timer += 1
            if it[u] < len(children[u]):
                stk.append(children[u][it[u]])
                it[u] += 1
            else:
                tout[u] = timer - 1              # 孩子耗尽：子树内最大的 tin
                stk.pop()

        j = 2                                    # 值域双指针，全程只前进
        u = pos[1]
        while u != -1:
            while j <= n + 1 and pos[j] != -1 and tin[u] <= tin[pos[j]] <= tout[u]:
                j += 1
            ans[u] = j
            u = parents[u]
        return ans
```

> 💡 两版等价，均用**迭代 DFS** 求时间戳以避免链状树（$n = 10^5$）递归爆栈；`pos` 只开 `n + 2` 并跳过大值，把空间钉死在 $O(n)$。参考实现已对拍验证：C++ 与 Python 各自通过 2000+/3000+ 轮随机树（含链、星、毛毛虫与无值 1 等用例）对照逐节点暴力，官方三示例全数通过。

## 8. 边界情况与易错点

1. **全树无值 1**（示例 3）：所有子树 mex 都是 1。本实现的路径循环恰好因起点 `pos[1] == -1` 而空转、侥幸返回正确结果，但把正确性寄托在这种「巧合」上很脆弱——显式特判 `pos[1] == -1` 提前返回才是稳妥写法。
2. **`pos` 只开 `n + 2` 且跳过值 $> n+1$**：别按值域 $10^5$ 开数组（浪费空间）；也别忘了 `while` 先判 `j <= n + 1` 再访问 `pos[j]`——由引理 5，越过 $n+1$ 的推进在数学上不可能发生，先判界就不会越界。
3. **`tout` 的语义**：本文约定 `tout[u] = 子树内最大的 tin`（不是「离开时刻」），判定式两处都用 `tin[v]`。若改用「进入/离开都计时」的约定，判定式与端点开闭要随之调整——两套约定各自都能写对，混着用才会错。
4. **双指针 $j$ 绝不在路径节点之间重置**：重置回 2 会退化到 $O(\text{路径长} \times n)$；引理 3 的单调性是不重置的合法性依据。
5. **递归爆栈**：链状树深度可达 $10^5$（Python 必炸），时间戳 DFS 必须迭代（栈 + 孩子游标）。
6. **路径外节点零处理**：不要「顺手」DFS 侧子树做标记——那会把剪枝的复杂度收益还回去（姊妹篇的合并版才需要访问侧子树，本文完全不需要）。
7. **`node1` 恰为根**：路径长度 1，循环体只执行一次，`ans[根]` 为第一个 $\ge 2$ 的缺失值；`parents[根] == -1` 自然终止循环。
8. **C++ 细节**：`children[u].size()` 是无符号数，与 `int` 游标比较时显式转换（保持 `-Wall -Wextra` 干净）；`ans` 初值为 1 而非 0（mex 最小也是 1）。
