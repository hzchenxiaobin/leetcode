# LeetCode 可互换矩形的组数 题解

## 1. 题目概述

- **标题 / 题号**：可互换矩形的组数（#2001，medium）
- **链接**：https://leetcode.cn/problems/number-of-pairs-of-interchangeable-rectangles/
- **来源**：LeetCode 第 258 场周赛 Q2
- **难度**：中等
- **标签**：数组、哈希表、数学、计数、数论

**题意**：给定下标从 0 开始的二维整数数组 `rectangles`，其中 `rectangles[i] = [width_i, height_i]` 表示第 `i` 个矩形的宽与高。若矩形 `i` 与 `j`（`i < j`）满足 $\dfrac{width_i}{height_i} = \dfrac{width_j}{height_j}$（**实数除法**），则称二者**可互换**。计算并返回可互换矩形的对数。

**约束**：

- $n = \text{rectangles.length}$，$1 \le n \le 10^5$
- `rectangles[i].length == 2`
- $1 \le width_i, height_i \le 10^5$

> 💡 **审题关键**：① 「可互换」只看**宽高比**，与绝对尺寸无关——`[4,8]` 与 `[15,30]` 比例一致即可互换；② 同比例的 $k$ 个矩形两两互换，贡献 $C(k,2)$ 对而非 1 对；③ $n = 10^5$ 全同比例时答案约 $5 \times 10^9$，**超出 32 位整数范围**，C++ 必须用 `long long`。

## 2. 示例

**示例 1**

```text
输入：rectangles = [[4,8],[3,6],[10,20],[15,30]]
输出：6
解释：四个矩形的宽高比均为 1:2，任意两个都可互换，共 C(4,2) = 6 对：
(0,1) (0,2) (0,3) (1,2) (1,3) (2,3)
```

**示例 2**

```text
输入：rectangles = [[4,5],[7,8]]
输出：0
解释：4/5 ≠ 7/8，不存在可互换的矩形对。
```

**示例 3**

```text
输入：rectangles = [[4,3],[8,6],[12,9],[6,4]]
输出：3
解释：前三个矩形宽高比均为 4:3，贡献 C(3,2) = 3 对；[6,4] 的比例 3:2 单独成组，贡献 0 对。
```

## 3. 解题思路

### 3.1 暴力思路：两两判定

双重循环枚举所有数对 $(i, j)$，用**交叉相乘** $w_i h_j = h_i w_j$ 判定（规避除法与浮点误差），满足则计数。

- **正确性**：穷举所有数对并逐个判定，显然正确。
- **效率**：$O(n^2)$。$n = 10^5$ 时约 $5 \times 10^9$ 次判定，**远超时限**。

> ⚠️ 暴力法的浪费在于「同比例的矩形被重复比较」：若 $k$ 个矩形比例相同，它们形成的 $C(k,2)$ 个数对判定条件完全一致，却各自独立计算。破局思路：**先按比例分组，再在组内用组合数一次性统计**。

### 3.2 核心观察：宽高比是矩形的「比例指纹」

![可互换矩形：宽高比相同即同组](images/wc258_q2_ratio_group_concept.svg)

三步转换：

1. **归约**：可互换 $\Leftrightarrow$ 宽高比相同。每个矩形对应一个比例 $w : h$，比例相同者互相可互换。
2. **归一化**：令 $g = \gcd(w, h)$，用**最简分数** $\left(\dfrac{w}{g}, \dfrac{h}{g}\right)$ 作为比例的精确表示。两个比例相等 $\Leftrightarrow$ 最简分数相同（§5 引理 1），纯整数运算，零精度风险。
3. **计数**：哈希表统计每个最简比例出现的次数 $k$，该组贡献 $C(k,2) = \dfrac{k(k-1)}{2}$ 对，累加即为答案。

> 💡 **与 149. 直线上最多的点数 同构**：149 用 $\gcd$ 化简斜率 $(\Delta y, \Delta x)$ 作哈希键，本题用 $\gcd$ 化简宽高比 $(w, h)$ 作哈希键——同一套「**GCD 归一化 + 哈希分组**」范式。区别仅在：149 求最大组大小，本题求所有组的组合数之和。

### 3.3 算法流程：单次遍历，边分组边累加

![GCD 归一化与哈希分组流程](images/wc258_q2_gcd_hash_flow.svg)

遍历每个矩形 `[w, h]`：

1. 计算 $g = \gcd(w, h)$，得键 `key = (w/g, h/g)`
2. `ans += count[key]`——当前矩形与**已入组**的每个同比例矩形恰好配成一对
3. `count[key] += 1`

设某组共 $k$ 个矩形，第 $t$ 个（$t$ 从 1 计）入组时 `count[key]` 恰为 $t - 1$，故组内累计 $0 + 1 + \cdots + (k-1) = C(k,2)$，与「先分组再逐组求 $C(k,2)$」完全等价，但省去二次遍历。

### 3.4 示例演算

![示例逐步演算：归一化、入组、累加](images/wc258_q2_walkthrough.svg)

以 `rectangles = [[4,8],[3,6],[10,20],[15,30]]` 走查：

| 步骤 | 矩形 | $g=\gcd(w,h)$ | 键 $(w/g,\ h/g)$ | 入组前 count | ans 增加 | 累计 ans |
|------|------|---------------|------------------|--------------|----------|----------|
| ① | [4,8] | 4 | (1,2) | 0 | +0 | 0 |
| ② | [3,6] | 3 | (1,2) | 1 | +1 | 1 |
| ③ | [10,20] | 10 | (1,2) | 2 | +2 | 3 |
| ④ | [15,30] | 15 | (1,2) | 3 | +3 | 6 |

四个矩形尺寸各异，但 $\gcd$ 归一化后全部落入键 $(1,2)$ 同一组：$ans = 0 + 1 + 2 + 3 = 6 = C(4,2)$ ✓

## 4. 算法细节

1. **归一化键的表示**：Python 直接用元组 `(w // g, h // g)` 作 `dict` 键，最简洁。C++ 的 `unordered_map` 不支持 `pair` 键，把两个分量编码进一个 64 位整数：`key = (w/g) * 100001 + (h/g)`——分量上界 $10^5 < 100001$，编码是单射不会碰撞；也可改用 `map<pair<int,int>, int>`（有序，多一个 $\log$）或自定义哈希。
2. **先加后增**：`ans += count[key]` 必须发生在 `count[key] += 1` **之前**。顺序颠倒会让第 $t$ 个入组者加 $t$ 而非 $t-1$（相当于自己与自己配对），每组多算 $k$ 对。
3. **为什么不用浮点数作键**：`double` 只有 53 位有效尾数，不同分数的浮点商可能舍入到同一值。有趣的是，本题 $w, h \le 10^5$ 时不同分数之差至少 $\dfrac{1}{h_i h_j} \ge 10^{-10}$，仍大于商的最大舍入误差（约 $7 \times 10^{-12}$），`double` 理论上恰好够用——但这是刀尖上的平衡，数据加强到 $10^9$ 立刻失效。$\gcd$ 归一化是普适的精确做法。
4. **溢出**：全同比例时答案 $C(10^5, 2) \approx 4.99995 \times 10^9 > 2^{31} - 1$。C++ 中 `ans` 必须声明为 `long long`（题目返回类型已是 `long long`）；单个 `count[key] \le 10^5` 不会溢出，但累加必须落到 64 位。Python 整数任意精度，无此问题。

## 5. 正确性证明

**引理 1（最简分数是比例的规范形式）**：对正整数 $w, h$，记 $g = \gcd(w, h)$。矩形 $(w_1, h_1)$ 与 $(w_2, h_2)$ 宽高比相等，当且仅当 $\left(\dfrac{w_1}{g_1}, \dfrac{h_1}{g_1}\right) = \left(\dfrac{w_2}{g_2}, \dfrac{h_2}{g_2}\right)$。

**证明**：记 $a_i = w_i / g_i$，$b_i = h_i / g_i$。先证 $\gcd(a_i, b_i) = 1$：若 $d > 1$ 是 $a_i, b_i$ 的公因子，则 $g_i d$ 同时整除 $w_i, h_i$，与 $g_i$ 是最大公约数矛盾。
（⇐）若 $(a_1, b_1) = (a_2, b_2)$，则 $\dfrac{w_1}{h_1} = \dfrac{a_1}{b_1} = \dfrac{a_2}{b_2} = \dfrac{w_2}{h_2}$，比例相等。
（⇒）比例相等即 $w_1 h_2 = w_2 h_1$，两边同除 $g_1 g_2$ 得 $a_1 b_2 = a_2 b_1$。由 $\gcd(a_1, b_1) = 1$ 与 $a_1 \mid a_2 b_1$，据 Euclid 引理得 $a_1 \mid a_2$；对称地（交换下标 1、2）得 $a_2 \mid a_1$，故 $a_1 = a_2$，代回得 $b_1 = b_2$。∎

**引理 2（分组贡献）**：按宽高比将矩形划分为等价类，大小为 $k$ 的类内部恰有 $C(k, 2)$ 个可互换对；不同类的矩形之间不可互换。

**证明**：同类中任两矩形比例相同，构成可互换对；反之类内任一可互换对即从 $k$ 个矩形中选 2 个，共 $C(k, 2)$ 个。不同类的矩形比例不同，由引理 1 的逆否命题，不构成可互换对。∎

**定理**：算法返回可互换矩形对的总数。

**证明**：由引理 1，键 $(w/g, h/g)$ 相同 $\Leftrightarrow$ 宽高比相同，故哈希表按键分组与按比例划分等价类完全一致。对大小为 $k$ 的组，第 $t$ 个入组的矩形在自增前读到 $\text{count}[key] = t - 1$，使 `ans` 增加 $t - 1$；组内合计 $\sum_{t=1}^{k} (t-1) = \dfrac{k(k-1)}{2} = C(k, 2)$，恰为引理 2 给出的该组贡献。各组贡献相加即得全部可互换对数，不重不漏。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \log M)$，其中 $M = \max(w, h) \le 10^5$。遍历 $n$ 个矩形，每个做一次辗转相除（$\log M \approx 17$ 次迭代）与一次均摊 $O(1)$ 的哈希操作；$n = 10^5$ 时总量约 $2 \times 10^6$，远在时限内，通常简记 $O(n)$。
- **空间复杂度**：$O(n)$。哈希表最坏存储 $n$ 个互不相同的比例键。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long interchangeableRectangles(vector<vector<int>>& rectangles) {
        unordered_map<long long, int> count;
        long long ans = 0;
        for (const auto& r : rectangles) {
            int w = r[0], h = r[1];
            int g = gcd(w, h);
            long long key = (long long)(w / g) * 100001LL + (h / g);
            ans += count[key];
            count[key]++;
        }
        return ans;
    }
};
```

### Python

```python
from math import gcd
from collections import defaultdict

class Solution:
    def interchangeableRectangles(self, rectangles: list[list[int]]) -> int:
        count = defaultdict(int)
        ans = 0
        for w, h in rectangles:
            g = gcd(w, h)
            key = (w // g, h // g)
            ans += count[key]
            count[key] += 1
        return ans
```

## 8. 边界情况与易错点

1. **答案溢出 32 位**：$n = 10^5$ 且全部同比例时，答案 $C(10^5, 2) \approx 4.99995 \times 10^9$，超过 `int` 上限（约 $2.1 \times 10^9$）。C++ 的 `ans` 必须 `long long`；Python 无此问题。
2. **浮点键陷阱**：用 `double` 存 `w / h` 作键在更强数据下必然出错（见 §4 第 3 点的量化分析），坚持 $\gcd$ 归一化。
3. **键编码基数**：`100001` 必须严格大于分量上界 $10^5$，否则不同的二元组可能编码到同一整数。若数据加强到 $w, h \le 10^9$，改用 `(unsigned long long)a << 32 | b` 或 `pair` + 自定义哈希。
4. **先加后增**：顺序颠倒则每个矩形先与自己「配对」，每组多算 $k$ 对（见 §4 第 2 点）。
5. **`n = 1`**：单个矩形无配对，首次 `ans += count[key]` 加 0，自然返回 0，无需特判。
6. **正方形**：`w == h` 时 $g = w$，键为 $(1, 1)$，所有正方形落入同组，逻辑无需特判。
7. **C++ 的 `gcd`**：C++17 起位于 `<numeric>` 的 `std::gcd`，LeetCode 环境可直接调用 `gcd(w, h)`。
