# LeetCode 两个回文子序列长度的最大乘积 题解

## 1. 题目概述

- **标题 / 题号**：两个回文子序列长度的最大乘积（#2002，medium）
- **链接**：https://leetcode.cn/problems/maximum-product-of-the-length-of-two-palindromic-subsequences/
- **来源**：LeetCode 第 258 场周赛 Q3
- **难度**：中等
- **标签**：位运算、状态压缩、动态规划、回文

**题意**：给定字符串 $s$，找出两个**不相交**的回文子序列，使二者长度的**乘积最大**。「不相交」指两个子序列不共享任何相同下标（内容可以相同）。返回可达成的最大乘积。**子序列**是从原串删除若干字符（可不删）后保持原序的结果；**回文**是从前往后与从后往前读完全相同的字符串。

**约束**：

- $2 \le s.length \le 12$
- $s$ 只含有小写英文字母。

> 💡 **审题关键**：① 「不相交」约束的是**下标**而非内容——`"bb"` 里两个 `b` 内容一样、下标不同，是合法的一对；② $n \le 12$ 是最强的信号：全部子序列只有 $2^{12} = 4096$ 个，**指数级枚举与状压都在射程内**；③ **乘积最大 ≠ 各自最长**：把字符全塞进一个子序列会让另一边长度归零（乘积 0），示例 2 的 `"bb"` 最优是拆成 $1 \times 1$ 而非合并成 $2 \times 0$。

## 2. 示例

**示例 1**

```text
输入：s = "leetcodecom"
输出：9
解释：选 "ete"（下标 1,3,7）与 "cdc"（下标 4,6,8），两个都是回文且下标不相交，
      乘积 3 × 3 = 9。
```

**示例 2**

```text
输入：s = "bb"
输出：1
解释：选两个 "b"（下标 0 与 1），乘积 1 × 1 = 1。
      若把两个 b 合并进同一子序列 "bb"，另一边只能为空，乘积 2 × 0 = 0，反而更差。
```

**示例 3**

```text
输入：s = "accbcaxxcxx"
输出：25
解释：选 "accca"（下标 0,1,2,4,5）与 "xxcxx"（下标 6,7,8,9,10），乘积 5 × 5 = 25。
```

## 3. 解题思路

### 3.1 暴力思路：DFS 三分支

逐位决定每个字符的去向——**跳过、给子序列 ①、给子序列 ②**——走到末尾时判定两个构造出的串是否均为回文，用合法者的长度乘积更新答案。

- **正确性**：三个去向穷尽了「一对不相交子序列」的所有构造方式。
- **效率**：$3^n$ 个叶子，每叶 $O(n)$ 判回文，$n = 12$ 时约 $6 \times 10^6$，勉强可过。
- **浪费所在**：「选下标」与「判回文」耦合在同一条搜索路径里，同一组下标在不同路径中被反复判定；更关键的是，配对信息没有沉淀——算法在反复回答同一个问题「**这批下标能凑出的最长回文是多长**」，却从不缓存答案。

> ⚠️ 另一种朴素做法是双重循环枚举所有掩码对 $(m_1, m_2)$，用 $m_1 \mathbin{\&} m_2 = 0$ 过滤相交对，共 $4^n \approx 1.7 \times 10^7$ 次判定，也能过但更浪费。**破局点**：把「下标集合」升格为一等公民——回文性、最长回文长度、与谁不相交，全是集合的属性，都能按集合**预计算一次、反复复用**。

### 3.2 核心观察：子序列 ↔ 位掩码，不相交 ↔ 补集

![核心观察：子序列对应位掩码，不相交即按位与为 0](images/wc258_q3_bitmask_disjoint_concept.svg)

1. **子序列 ↔ 掩码**：bit $i$ 为 1 表示选中下标 $i$，每个子序列唯一对应一个 $n$ 位掩码，全集共 $2^n$ 个。
2. **不相交 ↔ 位运算**：$m_1 \mathbin{\&} m_2 = 0$，即 $m_2$ 只需取 $m_1$ 补集 $\text{FULL} \oplus m_1$ 的子集。「不相交」从集合比较变成 $O(1)$ 位运算。
3. **回文属性只依赖掩码本身**：一个下标集合内能凑出的**最长回文子序列长度**是集合的固有属性，与配对无关——这正是可以**预计算**并**聚合**的部分。

基于前两条可得到 $O(3^n)$ 解法：预处理所有掩码的回文性与长度，外层枚举回文掩码 $m_1$、内层对补集做子掩码枚举 $m_2$（详见相关题目中的姊妹篇）。但第 3 条暗示还能更进一步：既然「补集内最优回文长度」是一个只关于补集的函数，何必在配对时逐个扫描子掩码？**直接为每个集合算一次最优值**，配对阶段就只剩 $O(1)$ 查表。

### 3.3 状态转移：$O(2^n)$ 状压 DP

![dp[mask] 的端点决策与最终划分枚举流程](images/wc258_q3_dp_transfer_flow.svg)

**状态定义**：$dp[\text{mask}]$ = 只用 $\text{mask}$ 内的下标（保持原序）能取到的**最长回文子序列**长度。

**转移**：设 $i$ 为 mask 的最低位 1、$j$ 为最高位 1（即集合的最小/最大下标），对「回文两端」做决策：

- $i = j$（仅一位）：$dp[\text{mask}] = 1$；
- $s[i] = s[j]$：两端字符相同，配成回文外壳，$dp[\text{mask}] = dp[\text{mask} \oplus 2^i \oplus 2^j] + 2$；
- $s[i] \ne s[j]$：最优解必弃掉至少一端，$dp[\text{mask}] = \max\big(dp[\text{mask} \oplus 2^i],\ dp[\text{mask} \oplus 2^j]\big)$。

这与区间 DP 求最长回文子序列（516 题）的端点决策完全同构，只是「区间两端」换成了「集合的最低/最高位」。三个转移目标的数值都严格小于 mask，**按数值递增一趟枚举即完成递推，无环**。

**配对**：$ans = \max_m dp[m] \times dp[\text{FULL} \oplus m]$。最优解 $(p_1^*, p_2^*)$ 一定被划分 $m = \text{idx}(p_1^*)$ 覆盖（§5 引理 3），因此枚举 $2^n$ 个划分足够，无需 $3^n$ 对子集逐一配对。

### 3.4 示例演算

![示例演算：bb 的划分对比与 leetcodecom 的转移链](images/wc258_q3_walkthrough.svg)

**示例 2 `"bb"`**：$dp[01] = 1$，$dp[10] = 1$，$dp[11] = dp[00] + 2 = 2$。配对：全并一边 $2 \times 0 = 0$，拆成两半 $1 \times 1 = 1$ → 答案 1。**合并出更长回文反而输给拆分**，印证「乘积最大 ≠ 各自最长」。

**示例 1 `"leetcodecom"`**：取 $m_1 = \{1,3,7\}$（"ete"）：最低位 1、最高位 7，$s[1] = s[7] = e$ → 外壳配对，$dp[m_1] = dp[\{3\}] + 2 = 3$；补集 $\text{FULL} \oplus m_1$ 含 $\{4,6,8\}$（"cdc"），故 $dp[\text{FULL} \oplus m_1] \ge 3$，乘积 $3 \times 3 = 9$。字符串中不存在长度 $\ge 4$ 的回文子序列（$e \times 3$、$c \times 2$、$o \times 2$ 的两两配对都无法在原序下嵌套成 abba 型），最长只有 3，故 9 即为答案。

## 4. 算法细节

1. **最低位 / 最高位的 $O(1)$ 求法**：最低位 `lowbit = mask & (-mask)`，下标 $i$ 用 `__builtin_ctz(mask)`（C++）或 `(mask & -mask).bit_length() - 1`（Python）；最高位 $j$ 用 `31 - __builtin_clz(mask)` 或 `mask.bit_length() - 1`。单状态转移 $O(1)$。
2. **递推顺序**：三个转移目标（去掉一或两个 1 位）的 popcount 与数值都严格小于 mask，因此 `for mask = 1 … 2^n − 1` 一趟完成，不需要记忆化递归。
3. **配对只枚举一个掩码**：$dp[\text{FULL} \oplus m]$ 把「补集内所有可能伙伴」聚合为一个数，配对复杂度从 $3^n$ 对子集降为 $2^n$ 个划分。由对称性 $m \leftrightarrow \text{FULL} \oplus m$ 还可折半枚举，但无必要。
4. **dp 语义是「集合内最优」而非「mask 本身回文」**：最终枚举的 $m$ 不必是回文掩码——$dp[m]$ 已替它选好内部最优回文。若误用 `isPalin[m]` 过滤最终循环会漏解。
5. **与 $O(3^n)$ 写法的关系**：两者共享「掩码 = 子序列身份」的观察；$O(3^n)$ 版把回文判定放进预处理、把配对留给子集枚举，$O(2^n)$ 版连配对也被 $dp$ 聚合吸收——相当于把内层子集枚举「预处理成一张表」。

## 5. 正确性证明

**引理 1（外壳引理）**：设 mask 至少含两个下标，$i$、$j$ 分别为其最低/最高位。若 $s[i] = s[j]$，则 $dp[\text{mask}] = dp[\text{mask}'] + 2$，其中 $\text{mask}' = \text{mask} \oplus 2^i \oplus 2^j$。

**证明**：（≥）在 $\text{mask}'$ 的最优回文子序列 $P$ 两侧拼上 $s[i]$、$s[j]$：$i$ 小于 mask 中其余一切下标、$j$ 大于其余一切下标，下标序列仍严格递增，且 $s[i]\,P\,s[j]$ 是回文，故 $dp[\text{mask}] \ge |P| + 2$。
（≤）设 $P$ 为 mask 内任一最长回文子序列，$|P| \le 1$ 时结论显然。否则记 $P^-$ 为 $P$ 去掉首尾字符后的内部部分（回文去掉首尾仍是回文）。

- **若 $P$ 同时用到 $i$ 与 $j$**：$i$ 是 mask 最小下标，若被使用必为 $P$ 的首字符；同理 $j$ 必为末字符。于是 $P = s[i]\,P^-\,s[j]$，且 $P^- \subseteq \text{mask}'$，得 $|P| \le dp[\text{mask}'] + 2$。
- **若 $P$ 缺 $i$ 或缺 $j$（至少其一）**：不妨设缺 $i$（缺 $j$ 的情形对称）：$P$ 的所有下标都大于 $i$，故 $P^-$ 的下标全部 $> i$；再看 $j$——若 $P$ 用 $j$ 则 $j$ 必是末字符（$P$ 不用则所有下标都 $< j$），两种情况 $P^-$ 的下标都严格小于 $j$。故 $P^- \subseteq \text{mask}'$。构造 $Q = s[i]\,P^-\,s[j]$：下标递增、内部回文、两端相同，是 mask 内合法回文子序列，且 $|Q| = |P^-| + 2 = |P| \le dp[\text{mask}'] + 2$。

两种情况均有 $dp[\text{mask}] \le dp[\text{mask}'] + 2$。∎

**引理 2（弃端引理）**：同上设 mask 至少两位。若 $s[i] \ne s[j]$，则 $dp[\text{mask}] = \max\big(dp[\text{mask} \oplus 2^i],\ dp[\text{mask} \oplus 2^j]\big)$。

**证明**：（≥）子集内的回文子序列仍是原集合内的回文子序列（下标仍属 mask、顺序不变），故 $dp$ 关于集合包含单调，$dp[\text{mask}]$ 不小于右端两项。
（≤）设 $P$ 为 mask 内最长回文子序列。若 $P$ 不用 $i$，则 $P \subseteq \text{mask} \oplus 2^i$；若 $P$ 用 $i$，则 $i$ 是 $P$ 的首字符，回文性迫使 $P$ 的末字符等于 $s[i] \ne s[j]$，故末字符不在 $j$，即 $P$ 不用 $j$，$P \subseteq \text{mask} \oplus 2^j$。两种情况 $|P|$ 均不超过右端某一项。∎

**定理 1**：按引理 1/2 递推算出的 $dp[\text{mask}]$ 恰为「在 mask 内取子序列的最长回文长度」。

**证明**：对 $\text{popcount}(\text{mask})$ 强归纳。popcount $= 0$：空集长度 0；popcount $= 1$：单字符回文长度 1。popcount $\ge 2$ 时 $i \ne j$，递推右端只出现 popcount 更小的 mask（至少去掉一位），由归纳假设其 dp 值已正确；引理 1/2 证明的正是「真实最优值 = 递推右端」，故递推值正确。∎

**引理 3（划分覆盖引理）**：$\text{ans} = \max_{m \subseteq \text{FULL}} dp[m] \cdot dp[\text{FULL} \oplus m]$。

**证明**：（≤）任取 $m$：取 $m$ 内与 $\text{FULL} \oplus m$ 内各自达到 dp 值的回文子序列 $P_1$、$P_2$，二者下标分属互补的两半、互不相交，故乘积 $dp[m] \cdot dp[\text{FULL} \oplus m]$ 是某个合法方案的乘积，不超过 ans。
（≥）设 $(p_1^*, p_2^*)$ 为任一最优不相交回文对，取 $m = \text{idx}(p_1^*)$。则 $dp[m] \ge |p_1^*|$；又 $p_2^*$ 与 $\text{idx}(p_1^*)$ 不相交，即 $p_2^* \subseteq \text{FULL} \oplus m$，故 $dp[\text{FULL} \oplus m] \ge |p_2^*$，于是该划分的乘积 $\ge |p_1^*| \cdot |p_2^*| = \text{ans}$。∎

**定理 2**：算法返回两个不相交回文子序列长度乘积的最大值。

**证明**：由定理 1 全部 dp 值精确；由引理 3 的两个方向：循环中每个乘积都对应合法方案（不超过 ans），而最优方案的乘积必被某个 $m$ 覆盖（不小于 ans），故 max 恰为 ans。∎

## 6. 复杂度分析

- **时间复杂度**：$O(2^n)$。阶段一递推 $2^n$ 个状态、每状态 $O(1)$（求 lowbit/最高位、比较一次字符、查表）；阶段二枚举 $2^n$ 个划分、每步 $O(1)$。$n = 12$ 时全程约 $8 \times 10^3$ 次操作——比 $O(3^n) \approx 5.3 \times 10^5$（子集配对版）快约 65 倍，比朴素 $O(4^n) \approx 1.7 \times 10^7$ 快四个数量级。
- **空间复杂度**：$O(2^n)$，即 dp 数组本身（$2^{12} = 4096$ 个整数）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maxProduct(string s) {
        int n = s.size();
        int FULL = (1 << n) - 1;
        vector<int> dp(1 << n, 0);
        for (int mask = 1; mask <= FULL; mask++) {
            int i = __builtin_ctz(mask);
            int j = 31 - __builtin_clz(mask);
            if (i == j) {
                dp[mask] = 1;
            } else if (s[i] == s[j]) {
                dp[mask] = dp[mask ^ (1 << i) ^ (1 << j)] + 2;
            } else {
                dp[mask] = max(dp[mask ^ (1 << i)], dp[mask ^ (1 << j)]);
            }
        }
        int ans = 0;
        for (int m = 1; m <= FULL; m++) {
            ans = max(ans, dp[m] * dp[FULL ^ m]);
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maxProduct(self, s: str) -> int:
        n = len(s)
        FULL = (1 << n) - 1
        dp = [0] * (1 << n)
        for mask in range(1, 1 << n):
            i = (mask & -mask).bit_length() - 1
            j = mask.bit_length() - 1
            if i == j:
                dp[mask] = 1
            elif s[i] == s[j]:
                dp[mask] = dp[mask ^ (1 << i) ^ (1 << j)] + 2
            else:
                dp[mask] = max(dp[mask ^ (1 << i)], dp[mask ^ (1 << j)])
        return max(dp[m] * dp[FULL ^ m] for m in range(1, 1 << n))
```

## 8. 边界情况与易错点

1. **`i == j` 必须特判**：popcount 为 1 的 mask 若误入配对分支，`mask ^ (1 << i) ^ (1 << j)` 等于 mask 自身，得到 `dp[mask] = dp[mask] + 2` 的自引用错误（且 `s[i] == s[j]` 恒真）。
2. **最高位公式只对 mask > 0 合法**：`__builtin_clz(0)` 未定义；循环从 1 开始即安全，别把 mask = 0 纳入。
3. **dp[0] = 0 自然处理「全并一边」**：$dp[\text{FULL}] \times dp[\emptyset] = 0$ 自动出局，空子序列无需特判；$n \ge 2$ 保证答案至少为 1。
4. **乘积最大 ≠ 各自最长**（示例 2 陷阱）：不能只取 $dp[\text{FULL}]$ 或「最长 × 次长」；引理 3 保证枚举 $m$ 就够，但也**要求**把 $2^n$ 个划分枚举完整。
5. **别把 $m$ 过滤成回文掩码**：dp 的语义是「集合内最优」，最终循环对每个 $m$ 都有效；用回文性过滤反而漏解。
6. **溢出无虞**：最大乘积 $12 \times 12 = 144$，`int` 足够，无需 64 位。
7. **转移顺序**：按 mask 数值递增即可，依赖「转移目标严格变小」（§5 定理 1）；改写成记忆化递归同样正确，仅常数略大。
