# LeetCode 数组序号转换 题解

## 1. 题目概述

- **标题 / 题号**：数组序号转换（#1331，easy）
- **链接**：https://leetcode.cn/problems/rank-transform-of-an-array/
- **来源**：LeetCode 第 18 场双周赛 Q1
- **难度**：简单
- **标签**：数组、哈希表、排序

**题意**：把数组 `arr` 的每个元素替换成它的**序号**。序号规则：从 $1$ 开始编号；元素越大序号越大；**相等元素序号相同**；在不违反前两条的前提下每个数字的序号**尽可能小**。

换句话说，元素 $v$ 的序号等于「数组中严格小于 $v$ 的**不同**元素个数 $+ 1$」。

**约束**：

- $0 \le n = \textit{arr.length} \le 10^5$
- $-10^9 \le \textit{arr}[i] \le 10^9$

## 2. 示例

**示例 1**

```text
输入：arr = [40,10,20,30]
输出： [4,1,2,3]
解释：10 最小 → 1；20 第二小 → 2；30 → 3；40 最大 → 4。
```

**示例 2**

```text
输入：arr = [100,100,100]
输出： [1,1,1]
解释：三个元素相等，共享最小序号 1。
```

**示例 3**

```text
输入：arr = [37,12,28,9,100,56,80,5,12]
输出： [5,3,4,2,8,6,7,1,3]
解释：5 最小 → 1；9 → 2；12 出现两次，都取 3；……
```

## 3. 解题思路

### 3.1 暴力思路

对每个元素 $v$，遍历一遍数组统计「有多少个不同的值小于 $v$」：

```text
for v in arr:
    rank[v] = 1 + 比 v 小的不同值个数
```

单次统计需要 $O(n)$（或用集合去重后 $O(n)$），总体 $O(n^2)$。$n = 10^5$ 时是 $10^{10}$ 级别，超时。

### 3.2 核心观察：序号 = 去重排序后的下标 + 1

![排序去重后建立「值 → 序号」映射](images/bw18_q1_rank.svg)

把数组**排序并去重**，得到一个严格递增的序列 $u_0 < u_1 < \cdots < u_{k-1}$。由于它是严格递增的，$u_i$ 恰好有 $i$ 个不同的值比它小，故

$$\text{rank}(u_i) = i + 1$$

这正好满足「序号尽可能小」的要求：相等元素共享同一序号，且中间不跳号。于是问题化为两步：

1. 排序 + 去重，得到每个不同值的序号；
2. 用**哈希表**把这个映射记住，再按原顺序回填。

复杂度 $O(n \log n)$（排序主导），哈希查询均摊 $O(1)$。

### 3.3 算法流程

![算法流程：一次排序 + 一次哈希回填](images/bw18_q1_flow.svg)

```text
1. sorted_unique = 对 arr 排序后去重
2. rank = 空哈希表
3. for i = 0 .. len(sorted_unique)-1:
4.     rank[sorted_unique[i]] = i + 1
5. return [rank[v] for v in arr]
```

### 3.4 示例演算

以 `arr = [40,10,20,30]` 为例：

| 步骤 | 内容 |
|------|------|
| 原数组 | `[40, 10, 20, 30]` |
| 排序 | `[10, 20, 30, 40]` |
| 去重 | `[10, 20, 30, 40]`（无重复） |
| 映射 | `10→1, 20→2, 30→3, 40→4` |
| 回填 | `[4, 1, 2, 3]` |

再看 `arr = [37,12,28,9,100,56,80,5,12]`：去重排序为 `[5,9,12,28,37,56,80,100]`，映射 `5→1, 9→2, 12→3, 28→4, 37→5, 56→6, 80→7, 100→8`。注意 **12 出现两次，两处都映射到 3**，这正是「相等元素同序号」的体现。

## 4. 算法细节

1. **空数组**：$n = 0$ 时排序去重得到空序列，直接返回空数组，不要特判以外的额外逻辑。
2. **负数**：值域含 $-10^9$，哈希表的键必须能存负数（`unordered_map<int,int>` 没问题）；不要试图用「值当数组下标」。
3. **去重的两种写法**：C++ 用 `sort + unique + erase`（原地去重）；Python 用 `sorted(set(arr))`（一次性构造）。
4. **哈希表预估容量**：C++ 里 `rank.reserve(n * 2)` 可以减少 rehash；本题 $n \le 10^5$ 影响不大，但值得养成习惯。
5. **不要原地排序后回填**：排序会打乱原始顺序，必须保留一份原数组（或按下标记录）才能回填。
6. **序号从 1 开始**：循环里写 `i + 1`，容易漏掉 `+1` 而得到 0-based 的错误答案。

## 5. 正确性证明

设 $U = \{u_0 < u_1 < \cdots < u_{k-1}\}$ 为 `arr` 中所有不同值构成的集合（升序）。

**引理 1（序号的等价刻画）**：对任意 $v \in U$，满足题面四条规则的序号唯一，且等于 $1 + \big|\{u \in U : u < v\}\big|$。

**证明**：题面要求「元素越大序号越大」且「相等元素序号相同」，因此序号函数 $r$ 在 $U$ 上严格递增；又要求「每个数字的序号尽可能小」，即在满足严格递增的前提下逐项取最小值，从 $1$ 开始不跳号。任何严格递增且取最小值的映射只能是 $r(u_i) = i + 1$。而 $u_i$ 之前恰有 $i$ 个更小的不同值，故 $r(v) = 1 + |\{u \in U: u < v\}|$。唯一性由「严格递增 + 从 1 开始 + 不跳号」共同确定。∎

**引理 2（映射构造正确）**：算法建立的哈希表满足 `rank[sorted_unique[i]] = i + 1`，即对每个 $v = u_i$ 有 `rank[v] = 1 + |{u ∈ U : u < v}|`。

**证明**：`sorted_unique` 是 $U$ 的升序排列，故 `sorted_unique[i] = u_i`，由引理 1 即得。∎

**定理**：算法返回的数组恰为按要求转换后的数组。

**证明**：输出数组的第 $j$ 项为 `rank[arr[j]]`。由于 `arr[j] ∈ U`，由引理 2 该值等于 $1 + |\{u \in U : u < \textit{arr}[j]\}|$，由引理 1 正是 `arr[j]` 的唯一合法序号。逐项成立，故整个数组正确。∎

## 6. 复杂度分析

- **时间**：$O(n \log n)$。排序 $O(n \log n)$；去重 $O(n)$；建表 $O(k) \le O(n)$；回填 $O(n)$ 次哈希查询，均摊 $O(1)$ 每次。
- **空间**：$O(n)$。`sorted_unique` 与哈希表各 $O(n)$，输出数组 $O(n)$。

## 7. 参考代码

### C++

```cpp
#include <algorithm>
#include <unordered_map>
#include <vector>

using namespace std;

class Solution {
public:
    vector<int> arrayRankTransform(vector<int>& arr) {
        vector<int> sorted = arr;
        sort(sorted.begin(), sorted.end());
        sorted.erase(unique(sorted.begin(), sorted.end()), sorted.end());
        unordered_map<int, int> rank;
        rank.reserve(sorted.size() * 2 + 1);
        for (int i = 0; i < (int)sorted.size(); i++) {
            rank[sorted[i]] = i + 1;
        }
        vector<int> res;
        res.reserve(arr.size());
        for (int v : arr) {
            res.push_back(rank[v]);
        }
        return res;
    }
};
```

### Python

```python
from typing import List

class Solution:
    def arrayRankTransform(self, arr: List[int]) -> List[int]:
        order = {v: i + 1 for i, v in enumerate(sorted(set(arr)))}
        return [order[v] for v in arr]
```

## 8. 边界情况与易错点

1. **空数组**：返回 `[]`，不要对空序列取 `min`/`max` 或访问下标。
2. **全部元素相等**：全部返回 1（示例 2），因为去重后只有一个值。
3. **负数与极值**：$-10^9 \sim 10^9$，哈希表键用有符号整型；不要用「值为下标」的桶数组。
4. **漏掉 `+1`**：序号从 1 开始，`i` 从 0 开始，必须写 `i + 1`。
5. **对原数组原地排序**：排序后原始顺序丢失，回填会全错；务必复制一份。
6. **重复元素的序号**：`12` 出现两次都映射到同一个序号（示例 3），哈希表天然满足，不要用「出现次数」参与序号计算。
7. **「尽可能小」的含义**：不是「越小越好」的自由选择，而是「严格递增 + 从 1 起 + 不跳号」，等价于去重排序后的位次。
