# LeetCode 翻转子数组得到最大的数组值 题解

## 1. 题目概述

- **标题 / 题号**：翻转子数组得到最大的数组值（#1330，hard）
- **链接**：https://leetcode.cn/problems/reverse-subarray-to-maximize-array-value/
- **来源**：LeetCode 第 18 场双周赛 Q4
- **难度**：困难
- **标签**：贪心、数组、数学

**题意**：定义数组的**数组值**为所有相邻元素差的绝对值之和：

$$\text{value}(a) = \sum_{i=0}^{n-2} |a[i+1] - a[i]|$$

你可以选择 `nums` 的**任意一个子数组**并把它**翻转**（只能操作一次，子数组长度可以为 1 即不变）。求操作后能得到的最大数组值。

**约束**：

- $2 \le n \le 3 \times 10^4$
- $-10^5 \le \textit{nums}[i] \le 10^5$
- 答案保证在 32 位整数范围内

## 2. 示例

**示例 1**

```text
输入：nums = [2,3,1,5,4]
输出：10
解释：翻转 [3,1,5] → [2,5,1,3,4]，数组值 = 3+4+2+1 = 10。
```

**示例 2**

```text
输入：nums = [2,4,9,24,2,1,10]
输出：68
解释：翻转 [24,2] → [2,4,9,2,24,1,10]，数组值 = 2+5+7+22+23+9 = 68。
```

**示例 3**

```text
输入：nums = [5,5,5]
输出：0
解释：任何翻转都不改变数组值，全为 0。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有 $(L, R)$ 共 $O(n^2)$ 个子数组，每次翻转后重算数组值 $O(n)$，总 $O(n^3)$。即便用「翻转只影响两条边界边」把单次评估降到 $O(1)$，枚举本身仍是 $O(n^2)$：$n = 3\times10^4$ 时约 $4.5 \times 10^8$ 对，仍然太慢。

所以需要**不枚举 $(L,R)$**，而是把「最大增益」写成一个可以直接扫一遍求出的量。

### 3.2 核心观察：只有两条边界边会变

![翻转区间只改变两条边界边](images/bw18_q4_boundary.svg)

翻转子数组 $[L, R]$ 后，内部相邻元素只是**顺序颠倒**，它们的差的绝对值之和完全不变：

$$\sum_{i=L}^{R-1} |a[i+1]-a[i]| = \sum_{i=L}^{R-1} |a[i]-a[i+1]|$$

真正变化的只有两条**跨越边界**的边：

- 左边：$(a[L-1], a[L]) \longrightarrow (a[L-1], a[R])$（$L \ge 1$ 时存在）
- 右边：$(a[R], a[R+1]) \longrightarrow (a[L], a[R+1])$（$R \le n-2$ 时存在）

于是增益（记 $a$ 为原数组）

$$\Delta = |a[L-1]-a[R]| + |a[L]-a[R+1]| - |a[L-1]-a[L]| - |a[R]-a[R+1]|$$

**只在一侧有边界**时（即翻转的是前缀或后缀），只有一个 $|{\cdot}|$ 项发生变化。

![三类翻转，分别取最大增益](images/bw18_q4_cases.svg)

按 $L, R$ 的位置分三类：

**① 前缀翻转**（$L = 0$，$R \le n-2$）：只有右边变化，

$$\Delta = |a[R+1] - a[0]| - |a[R+1] - a[R]|$$

扫一遍 $R$ 即可，$O(n)$。

**② 后缀翻转**（$L \ge 1$，$R = n-1$）：只有左边变化，

$$\Delta = |a[L-1] - a[n-1]| - |a[L] - a[L-1]|$$

同样 $O(n)$。

**③ 内部翻转**（$1 \le L \le R \le n-2$）：两条边界都变，需要新的洞察。

对内部翻转，把涉及的两条相邻对记作

$$P_1 = (a[L-1], a[L]), \qquad P_2 = (a[R], a[R+1])$$

并记 $\textit{lo}_1 = \min P_1$、$\textit{hi}_1 = \max P_1$、$\textit{lo}_2, \textit{hi}_2$ 同理。四点 $a[L-1], a[L], a[R], a[R+1]$ 在数轴上排成一列，把它们从小到大记为 $p_1 \le p_2 \le p_3 \le p_4$。四种「两点配对」的方式只有三种本质不同的匹配，代价分别是

$$A = (p_2-p_1) + (p_4-p_3),\quad B = (p_3-p_1)+(p_4-p_2),\quad C = (p_4-p_1)+(p_3-p_2)$$

直接相减得

$$B - A = 2(p_3-p_2), \qquad C - B = 0$$

而 $\Delta$ 正是「交叉配对的代价」减去「原有配对（$P_1, P_2$）的代价」。于是：

- 若原有配对是 $A$（即两条相邻对分别是 $(p_1,p_2)$ 与 $(p_3,p_4)$，两段**分离**），则 $\Delta = 2(p_3-p_2)$；
- 否则 $\Delta \le 0$（原本的配对已是最优或并列最优）。

注意 $p_3$ 是「上方那条对」的较小值、$p_2$ 是「下方那条对」的较大值，因此

$$\Delta \le 2(p_3 - p_2) \le 2\big(\max_{\text{所有相邻对}} \textit{lo} - \min_{\text{所有相邻对}} \textit{hi}\big)$$

也就是说，**内部翻转的最大增益就是**

$$\boxed{2 \cdot \big(\max_i \min(a[i], a[i+1]) - \min_i \max(a[i], a[i+1])\big)}$$

若该值为负（所有相邻对的值域互相重叠），说明内部翻转不可能带来正收益，取 $0$。

### 3.3 算法流程

```text
1. base = Σ |a[i+1] − a[i]|
2. best = 0
3. // ① 前缀
   for R = 0 .. n-2: best = max(best, |a[R+1] − a[0]| − |a[R+1] − a[R]|)
4. // ② 后缀
   for L = 1 .. n-1: best = max(best, |a[L−1] − a[n−1]| − |a[L] − a[L−1]|)
5. // ③ 内部
   maxLow = max over i of min(a[i], a[i+1])
   minHigh = min over i of max(a[i], a[i+1])
   best = max(best, 2 * (maxLow − minHigh))
6. return base + best
```

### 3.4 示例演算

![示例 1 的翻转前后逐项对比](images/bw18_q4_example.svg)

**示例 1**：`nums = [2,3,1,5,4]`，基准值

$$\text{base} = 1 + 2 + 4 + 1 = 8$$

三类增益：

| 类别 | 最优选择 | 增益 |
|------|---------|------|
| 前缀 | $R = 3$：$\lvert a[4]-a[0]\rvert - \lvert a[4]-a[3]\rvert = 2-1 = 1$ | 1 |
| 后缀 | $L = 1$：$\lvert a[0]-a[4]\rvert - \lvert a[1]-a[0]\rvert = 2-1 = 1$ | 1 |
| 内部 | $\max \textit{lo} = 4$（对 $(5,4)$）、$\min \textit{hi} = 3$（对 $(2,3)$） | $2(4-3) = 2$ |

取最大增益 $2$，答案 $8 + 2 = 10$，对应翻转 $[1..3]$（即 `[3,1,5]`），与示例一致。

**示例 2**：`nums = [2,4,9,24,2,1,10]`，`base = 2+5+15+22+1+9 = 54`。内部：$\max\textit{lo} = 9$（对 $(9,24)$）、$\min\textit{hi} = 2$（对 $(2,1)$），增益 $2 \times (9-2) = 14$；前缀/后缀都只给出 $7$。故答案 $54 + 14 = 68$，对应翻转 $[3..4]$（即 `[24,2]`），与示例一致。

**示例 3**：`[5,5,5]`，所有相邻对 $\textit{lo} = \textit{hi} = 5$，内部增益 $0$；前缀/后缀增益也为 $0$；答案 $0$。

## 4. 算法细节

1. **`best` 初值为 $0$**：翻转长度为 1 的子数组等于不操作，增益 $0$，因此「不翻转」始终是合法选项。
2. **内部增益可能为负**：$\max\textit{lo} < \min\textit{hi}$ 时公式给出负数，与 $0$ 取 `max` 即可，不要漏这个 clamp。
3. **`|x|` 用 `abs` 且注意类型**：$\textit{nums}[i] \in [-10^5, 10^5]$，差值最大 $2\times10^5$，$\sum$ 最大约 $6\times10^9$？——不，题目保证答案在 32 位范围内，但中间量建议用 `long long` 以免边界溢出（C++ 里 `abs(int)` 已够，累加用 `long long` 更稳）。
4. **前缀/后缀循环的边界**：前缀的 $R$ 取 $0 \sim n-2$（$R = n-1$ 是整体翻转，增益 $0$）；后缀的 $L$ 取 $1 \sim n-1$（$L = 0$ 同样是整体翻转）。
5. **内部增益与具体下标无关**：公式只用到「所有相邻对的 min/max」的极值，所以只需一遍扫描维护两个极值，不需要记录是哪一对（但若需要输出方案，则要额外记录下标，用于构造翻转区间 $[\alpha+1, \beta]$）。
6. **$n = 2$**：没有内部翻转，前缀/后缀的增益都是 $0$，答案为 $|a[1]-a[0]|$。

## 5. 正确性证明

记 $a$ 为原数组，$V(\cdot)$ 为数组值。

**引理 1（增益公式）**：翻转 $[L,R]$ 后的数组值减去原数组值等于

$$\Delta(L,R) = \begin{cases}
|a[R+1]-a[0]| - |a[R+1]-a[R]|, & L = 0,\ R \le n-2\\
|a[L-1]-a[n-1]| - |a[L]-a[L-1]|, & L \ge 1,\ R = n-1\\
|a[L-1]-a[R]| + |a[L]-a[R+1]| - |a[L-1]-a[L]| - |a[R]-a[R+1]|, & \text{其他}
\end{cases}$$

**证明**：翻转只重排 $[L,R]$ 内部元素，内部相邻差的绝对值之和不变（顺序颠倒不改变 $|x-y|$）。剩下的边只有跨越 $L-1/L$ 与 $R/R+1$ 的两条；$L = 0$ 时左边不存在，$R = n-1$ 时右边不存在，逐项相减即得。∎

**引理 2（四点匹配的代价关系）**：设四个实数排序为 $p_1 \le p_2 \le p_3 \le p_4$，三种完美匹配的代价为 $A = (p_2-p_1)+(p_4-p_3)$、$B = (p_3-p_1)+(p_4-p_2)$、$C = (p_4-p_1)+(p_3-p_2)$，则 $A \le B = C$，且 $B - A = 2(p_3-p_2)$。

**证明**：$B - A = (p_3-p_1)+(p_4-p_2)-(p_2-p_1)-(p_4-p_3) = 2p_3 - 2p_2 = 2(p_3-p_2) \ge 0$；$C - B = (p_4-p_1)+(p_3-p_2)-(p_3-p_1)-(p_4-p_2) = 0$。∎

**引理 3（内部增益的上界）**：对任意内部翻转，$\Delta \le 2\big(\max_i \textit{lo}_i - \min_i \textit{hi}_i\big)$，其中 $\textit{lo}_i = \min(a[i],a[i+1])$、$\textit{hi}_i = \max(a[i],a[i+1])$。

**证明**：内部翻转的 $\Delta$ 是「交叉配对 $\{(a[L-1],a[R+1]), (a[L],a[R])\}$ 的代价」减「原有配对 $\{(a[L-1],a[L]), (a[R],a[R+1])\}$ 的代价」。对这四个点排序后，设原有配对是 $X$、交叉配对是 $Y$，它们必是引理 2 中三种匹配里的两个。若 $X = A$（两条相邻对分别是 $(p_1,p_2)$ 与 $(p_3,p_4)$），则 $Y$ 是 $B$ 或 $C$，$\Delta = 2(p_3-p_2)$；否则由 $A \le B = C$ 知 $\Delta \le 0 \le 2(p_3-p_2)$。

又因为 $(p_1,p_2)$ 与 $(p_3,p_4)$ 都是数组中真实存在的相邻对，故

$$p_3 = \textit{lo}\big((p_3,p_4)\big) \le \max_i \textit{lo}_i,\qquad p_2 = \textit{hi}\big((p_1,p_2)\big) \ge \min_i \textit{hi}_i$$

于是 $2(p_3-p_2) \le 2(\max_i \textit{lo}_i - \min_i \textit{hi}_i)$。∎

**引理 4（内部增益可取到上界）**：若 $\max_i \textit{lo}_i > \min_i \textit{hi}_i$，则存在内部翻转使 $\Delta = 2(\max_i \textit{lo}_i - \min_i \textit{hi}_i)$。

**证明**：取相邻对 $P$（下标 $\alpha$）使 $\textit{lo}_\alpha = \max_i \textit{lo}_i$，相邻对 $Q$（下标 $\beta$）使 $\textit{hi}_\beta = \min_i \textit{hi}_i$。

- $\alpha \ne \beta$：否则同一个对里 $\textit{lo} \le \textit{hi}$，与该不等式矛盾。
- $|\alpha - \beta| \ne 1$：相邻两对共享一个元素 $x$，则 $\textit{lo}_\alpha \le x \le \textit{hi}_\beta$，同样矛盾。

故 $|\alpha - \beta| \ge 2$。若 $\alpha < \beta$，取翻转区间 $[L, R] = [\alpha+1, \beta]$，则 $L = \alpha+1 \ge 1$、$R = \beta \le n-2$，且 $L \le R$，是合法的内部翻转；由引理 1，其边界对正是 $P$ 与 $Q$，且 $P$ 的所有元素都 $\ge \textit{lo}_\alpha > \textit{hi}_\beta \ge Q$ 的所有元素，两点互不交错，因此原有配对是「相邻配对 $A$」、交叉配对是 $B$ 或 $C$，由引理 2 得 $\Delta = 2(p_3 - p_2) = 2(\textit{lo}_\alpha - \textit{hi}_\beta)$。$\beta < \alpha$ 时对称地取 $[L,R] = [\beta+1, \alpha]$ 即可。∎

**定理**：算法返回的是「翻转至多一个子数组」后能得到的最大数组值。

**证明**：由引理 1，任何翻转的增益必属于「前缀 / 后缀 / 内部」三类之一（翻转长度为 1 时增益为 $0$，被 `best` 初值覆盖）。前缀、后缀两类算法各自枚举了全部可能并取最大值；内部一类的最大值由引理 3 给出上界、引理 4 证明该上界可达，故算法取到的恰是三类的最大增益。最终答案 = 基准值 + 最大增益，即最大值。∎

## 6. 复杂度分析

- **时间**：$O(n)$。计算基准值一遍 $O(n)$；前缀、后缀各一遍 $O(n)$；内部极值再一遍 $O(n)$。常数很小（四遍线性扫描可合并成两遍）。
- **空间**：$O(1)$。只用若干标量（`base`、`best`、`maxLow`、`minHigh`），不需要额外数组。

## 7. 参考代码

### C++

```cpp
#include <algorithm>
#include <climits>
#include <cstdlib>
#include <vector>

using namespace std;

class Solution {
public:
    int maxValueAfterReverse(vector<int>& nums) {
        int n = (int)nums.size();
        long long base = 0;
        for (int i = 0; i + 1 < n; i++) {
            base += abs(nums[i + 1] - nums[i]);
        }
        long long best = 0;
        // 反转前缀 [0..i]: 只有边 (i, i+1) 改变
        for (int i = 0; i + 1 < n; i++) {
            best = max(best, (long long)abs(nums[i + 1] - nums[0]) - abs(nums[i + 1] - nums[i]));
        }
        // 反转后缀 [i..n-1]: 只有边 (i-1, i) 改变
        for (int i = 1; i < n; i++) {
            best = max(best, (long long)abs(nums[i - 1] - nums[n - 1]) - abs(nums[i] - nums[i - 1]));
        }
        // 反转内部区间: 2 * (max 段内较小值 - min 段内较大值)
        long long maxLow = LLONG_MIN, minHigh = LLONG_MAX;
        for (int i = 0; i + 1 < n; i++) {
            int lo = min(nums[i], nums[i + 1]), hi = max(nums[i], nums[i + 1]);
            maxLow = max(maxLow, (long long)lo);
            minHigh = min(minHigh, (long long)hi);
        }
        best = max(best, 2 * (maxLow - minHigh));
        return (int)(base + best);
    }
};
```

### Python

```python
from typing import List

class Solution:
    def maxValueAfterReverse(self, nums: List[int]) -> int:
        n = len(nums)
        base = sum(abs(nums[i + 1] - nums[i]) for i in range(n - 1))
        best = 0
        # 反转前缀 [0..i]: 只影响边 (i, i+1)
        for i in range(n - 1):
            best = max(best, abs(nums[i + 1] - nums[0]) - abs(nums[i + 1] - nums[i]))
        # 反转后缀 [i..n-1]: 只影响边 (i-1, i)
        for i in range(1, n):
            best = max(best, abs(nums[i - 1] - nums[n - 1]) - abs(nums[i] - nums[i - 1]))
        # 反转内部区间: 2 * (max 每段较小值 - min 每段较大值)
        max_low, min_high = -10 ** 18, 10 ** 18
        for i in range(n - 1):
            lo, hi = min(nums[i], nums[i + 1]), max(nums[i], nums[i + 1])
            max_low = max(max_low, lo)
            min_high = min(min_high, hi)
        best = max(best, 2 * (max_low - min_high))
        return base + best
```

## 8. 边界情况与易错点

1. **`best` 必须从 0 开始**：可能任何翻转都不会带来正收益（如 `[5,5,5]`、`[1,2,1]`），此时答案就是基准值。
2. **内部公式要 clamp**：`max_low < min_high` 时 `2*(max_low-min_high)` 为负，必须与 0 取 max，否则会给出比基准值更小的答案。
3. **前缀与后缀不要重复整体翻转**：$R = n-1$ 与 $L = 0$ 对应整体翻转，增益恒为 0，可以纳入循环但不会改变结果；注意不要在循环中访问越界下标。
4. **$n = 2$**：只有一条边，答案就是 `|a[1]-a[0]|`；内部循环不执行。
5. **负数值**：`abs` 要作用于差值而不是元素本身；用 `min/max` 求每段的 lo/hi 时，负数也能正确处理。
6. **误以为「内部翻转必优于边界翻转」**：反例 `[1,2,3]`：内部无区间，前缀/后缀增益也都是 0；再如 `[10,1,2]` 后缀翻转增益为正而内部为负。
7. **用 `int` 存累加和**：虽然题目保证答案在 32 位内，但中间量用 `long long` 更安全；C++ 中 `abs(nums[i+1]-nums[i])` 是 `int`，参与 `long long` 累加会自动提升。
8. **只改一处**：本题只能翻转**一次**，不要写成「可以翻转多次」的最优化（那会变成另一个问题）。
