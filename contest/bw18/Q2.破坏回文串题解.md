# LeetCode 破坏回文串 题解

## 1. 题目概述

- **标题 / 题号**：破坏回文串（#1328，medium）
- **链接**：https://leetcode.cn/problems/break-a-palindrome/
- **来源**：LeetCode 第 18 场双周赛 Q2
- **难度**：中等
- **标签**：贪心、字符串

**题意**：给定一个**回文**字符串 `palindrome`。把其中**恰好一个**字符替换成任意小写字母，使得结果字符串**不是回文**且**字典序最小**。若无法做到则返回空串。

**约束**：

- $1 \le |\textit{palindrome}| \le 1000$
- 只含小写英文字母
- 输入保证是回文

## 2. 示例

**示例 1**

```text
输入：palindrome = "abccba"
输出："aaccba"
解释：把下标 1 的 'b' 改成 'a'，得到 "aaccba"，它不再是回文（下标 1 处
     为 'a'，镜像位置下标 4 处仍为 'b'），且是字典序最小的可行结果。
```

**示例 2**

```text
输入：palindrome = "a"
输出：""
解释：长度为 1 的字符串替换任意字符后仍是回文，无法破坏。
```

**示例 3**

```text
输入：palindrome = "aba"
输出："abb"
解释：前半部分只有 'a'，只能把最后一位改成 'b'。
```

## 3. 解题思路

### 3.1 暴力思路

枚举「替换哪个下标」× 「替换成 26 个字母」，对每个结果检查是否回文，取字典序最小者。单次回文检查 $O(n)$，总复杂度 $O(26 n^2)$。$n \le 1000$ 时约 $2.6 \times 10^7$ 次字符比较，勉强能过，但显然不是本题的意图。

不过这正好说明：**答案的形式极其有限**，可以贪心直接构造。

### 3.2 核心观察：越靠前的位置越「值钱」

![在前半部分找到第一个非 'a' 的字符并降为 'a'](images/bw18_q2_first_non_a.svg)

字典序比较是**从前往后**逐位比较的，所以要让结果最小，应该让**最靠前的可改变位置**变得尽量小。

由于原串是回文，改动必须成对考虑：

- 若只改**前半部分**（下标 $0 \sim \lfloor n/2 \rfloor - 1$）的某一位，它的镜像位保持原字符不变，两侧立刻不相等 ⇒ **一定破坏回文**；
- 若只改**后半部分**的某一位，同样会破坏回文（镜像位不变），但由于位置更靠后，得到的串字典序更大；
- 若改的是**最中间**那位（$n$ 为奇数时下标 $n/2$），它在回文里没有镜像伙伴，改它**不会**破坏回文。

于是贪心策略非常明确：

1. **$n = 1$**：只有一个字符，改与不改都还是回文 → 返回空串；
2. **在前半部分从左到右找第一个不为 `'a'` 的字符**，把它改成 `'a'`。这是能得到的字典序最小的结果：更靠前的位置全是 `'a'`，无法再降低；而这一位从大于 `'a'` 的字符降到 `'a'`，是「能降低的最靠前位置」；
3. **若前半部分全是 `'a'`**，说明任何改动都只能让字符变**大**。为了让字典序尽可能小，应改动**最靠后**的位置，并且只增加最小的一步：把最后一个字符改成 `'b'`。

![前半全为 'a' 时改最后一位](images/bw18_q2_all_a.svg)

### 3.3 算法流程

```text
1. n = len(palindrome)
2. if n == 1: return ""
3. s = list(palindrome)
4. for i = 0 .. n/2 - 1:
5.     if s[i] != 'a':
6.         s[i] = 'a'
7.         return "".join(s)
8. s[n-1] = 'b'
9. return "".join(s)
```

### 3.4 示例演算

**示例 1**：`"abccba"`，$n = 6$，前半是下标 $0,1,2$ 即 `a b c`。第一个非 `'a'` 的是下标 1 的 `'b'`，改为 `'a'` 得 `"aaccba"`。此时下标 1 为 `'a'`、镜像下标 4 为 `'b'`，不相等 ⇒ 非回文 ✓。

**示例 3**：`"aba"`，$n = 3$，前半只有下标 0 的 `'a'`，全是 `'a'`。于是把最后一位（下标 2）改成 `'b'`，得 `"abb"`。下标 0 是 `'a'`、下标 2 是 `'b'`，非回文 ✓。

**再验证一个边界**：`"aa"`，$n = 2$，前半只有下标 0 的 `'a'` → 走第二条分支，把下标 1 改成 `'b'`，得 `"ab"` ✓（长度为 2 时 `"ab"` 确实不是回文）。

## 4. 算法细节

1. **前半的范围是 `n/2`**：$n$ 为偶数时前半是 $0 \sim n/2-1$；$n$ 为奇数时中间位 $n/2$ 不计入（改它不破坏回文）。
2. **字符串要可变**：C++ 直接修改 `string`（传值拷贝即可），Python 转成 `list` 再 `join`，或用切片拼接。
3. **只改一处**：找到第一个非 `'a'` 后立刻返回，不能继续往后改。
4. **全 `'a'` 时改 `s[n-1] = 'b'`**：`'b'` 是比 `'a'` 大的最小字母，改最后一位对字典序的影响最小。
5. **$n = 1$ 必须特判**：否则会把唯一的字符改成 `'b'`，得到 `"b"`——它仍是回文，违反题意。
6. **修改一定成功**：第 2 步改的位与镜像位原本相同、改后不同，故必然非回文；第 3 步改最后一位，其镜像位是第一位（$n \ge 2$ 时下标 $0 \ne n-1$），原本都是 `'a'`，改后不同，也必然非回文。

## 5. 正确性证明

记原串为 $p$（长度 $n$，回文），答案串为 $r$。

**引理 1（改前半必破坏回文）**：若 $n \ge 2$，把下标 $i < n/2$ 改为与 $p[i]$ 不同的字符、其余位不变，则结果不是回文。

**证明**：镜像位 $n-1-i > i$ 未改变，仍为 $p[n-1-i] = p[i]$（回文性质），而新串在下标 $i$ 处的字符 $\ne p[i]$，故两处不等，非回文。∎

**引理 2（改最后一位必破坏回文）**：若 $n \ge 2$，把下标 $n-1$ 改为 `'b'`（$p[n-1] = $ `'a'` 时）其余位不变，则结果不是回文。

**证明**：镜像位下标 $0$ 仍为 `'a'`（前半全 `'a'` 的前提），而新串末位为 `'b'`，$0 \ne n-1$（$n \ge 2$），两处不等，非回文。∎

**引理 3（前半有非 `'a'` 时的最优性）**：设 $i^{*}$ 是前半中第一个 $p[i] \ne$ `'a'` 的下标。则所有合法结果中，词典序最小者恰为「把 $i^{*}$ 改为 `'a'`、其余不变」。

**证明**：设 $r'$ 是任一合法结果，与 $p$ 恰差一个位置 $j$。

- 若 $j < i^{*}$：由于 $j$ 在前半且 $j < i^{*}$，有 $p[j] = $ `'a'`，只能把它改成更大的字符，于是 $r'$ 在前 $j$ 位与 $p$ 相同、在第 $j$ 位更大；而候选串在第 $j$ 位仍为 `'a'`，故候选串更小。
- 若 $j > i^{*}$：候选串与 $r'$ 在前 $i^{*}$ 位相同（均为 $p[0..i^{*}-1]$，全为 `'a'`）；在第 $i^{*}$ 位，候选串为 `'a'`，而 $r'$ 仍为 $p[i^{*}] \ne$ `'a'`，故候选串更小。
- 若 $j = i^{*}$：合法改动中能取到的最小字符是 `'a'`，候选串正取到它，故 $r'$ 不可能更小。

综上候选串字典序最小；由引理 1 它确实合法。∎

**引理 4（前半全为 `'a'` 时的最优性）**：若前半全为 `'a'`，则所有改动只能使某位变大。改变位置越靠后、增大的幅度越小，字典序越小；故最优是「把最后一位改成 `'b'`」。

**证明**：前半全 `'a'` 意味着 $p$ 的每个字符都是 `'a'`（回文且前半全 `'a'`，后半亦然）；中间位（若存在）也是 `'a'`。故任何改动都把某位从 `'a'` 变为 $>$ `'a'` 的字符。设改的是下标 $j$，则结果与 `"a...a"` 在前 $j$ 位相同、第 $j$ 位变大，因此 $j$ 越大字典序越小；同一下标下 `'b'` 最小。取 $j = n-1$ 与 `'b'` 即得最小。由引理 2 它合法。∎

**定理**：算法返回字典序最小的非回文结果；$n = 1$ 时返回空串。

**证明**：$n = 1$ 时任何单字符替换的结果长度仍为 1，必然回文，故无解，返回空串正确。$n \ge 2$ 时按前半是否存在非 `'a'` 分两种情形，分别由引理 3、引理 4 得最优性与合法性。∎

## 6. 复杂度分析

- **时间**：$O(n)$。最多扫描前半 $n/2$ 个字符，找到即返回；全 `'a'` 时再改一个字符。
- **空间**：$O(n)$。需要构造长度为 $n$ 的结果字符串（Python 的 `list` 中间态也是 $O(n)$）。

## 7. 参考代码

### C++

```cpp
#include <string>

using namespace std;

class Solution {
public:
    string breakPalindrome(string palindrome) {
        int n = (int)palindrome.size();
        if (n == 1) {
            return "";
        }
        for (int i = 0; i < n / 2; i++) {
            if (palindrome[i] != 'a') {
                palindrome[i] = 'a';
                return palindrome;
            }
        }
        palindrome[n - 1] = 'b';
        return palindrome;
    }
};
```

### Python

```python
class Solution:
    def breakPalindrome(self, palindrome: str) -> str:
        n = len(palindrome)
        if n == 1:
            return ""
        s = list(palindrome)
        for i in range(n // 2):
            if s[i] != 'a':
                s[i] = 'a'
                return "".join(s)
        s[n - 1] = 'b'
        return "".join(s)
```

## 8. 边界情况与易错点

1. **$n = 1$**：必须返回空串。若漏判，会返回 `"b"`，而 `"b"` 是回文，答案错误。
2. **$n = 2$**：前半只有下标 0。`"aa"` 走第二条分支得 `"ab"`；`"bb"` 走第一条分支得 `"ab"`。两者都正确。
3. **只改前半**：改后半虽然也能破坏回文，但位置更靠后、字典序更大；改中间位则**根本不破坏回文**（没有镜像位）。
4. **全 `'a'` 的串（长度 $\ge 2$）**：必须走第二条分支；若试图把某位改成 `'a'`（不变）则没有改动，不合法。
5. **不要改最后一位为 `'a'`**：最后一位本来就是 `'a'`（全 `'a'` 的情形），必须改成 `'b'` 才产生变化。
6. **`'b'` 不是随便挑的**：它是大于 `'a'` 的最小字母，改它带来的字典序增量最小。
7. **返回值是「恰好改一个字符」**：不能返回原串（即使原串非回文——但本题输入保证是回文，所以也不用考虑这种情形）。
