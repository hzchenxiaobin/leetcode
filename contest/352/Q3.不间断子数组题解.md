# LeetCode 不间断子数组 题解

## 1. 题目概述

- **标题 / 题号**：不间断子数组（#2762，medium）
- **链接**：https://leetcode.cn/problems/continuous-subarrays/
- **来源**：LeetCode 第 352 场周赛 Q3
- **难度**：中等
- **标签**：数组、滑动窗口、单调队列、有序集合

**题意**：

给定下标从 $0$ 开始的整数数组 `nums`。一个子数组 $[i, j]$ 是**不间断的**，当且仅当其中**任意**两个下标 $i_1, i_2$（$i \le i_1, i_2 \le j$）都满足 $|nums[i_1] - nums[i_2]| \le 2$。返回不间断子数组的总数目。

**约束**：

- $1 \le nums.length \le 10^5$
- $1 \le nums[i] \le 10^9$

> ⚠️ **读题易错**：条件是**任意两个下标**（包括不相邻的），不是"相邻元素之差 ≤ 2"。这直接决定了合法判据是整个窗口的 $\max - \min \le 2$。

## 2. 示例

**示例 1**

```text
输入：nums = [5,4,2,4]
输出：8

解释：
大小为 1 的：[5], [4], [2], [4] —— 4 个
大小为 2 的：[5,4], [4,2], [2,4] —— 3 个
大小为 3 的：[4,2,4] —— 1 个（max − min = 2）
[5,4,2] 因 5 − 2 = 3 > 2 不合法。
总计 4 + 3 + 1 = 8。
```

**示例 2**

```text
输入：nums = [1,2,3]
输出：6

解释：任何子数组的 max − min ≤ 2，全部 n(n+1)/2 = 6 个子数组都合法。
（这也是答案的上界情形：答案 ≤ n(n+1)/2，n = 1e5 时约 5×10^9，必须用 64 位。）
```

**示例 3（自编，覆盖多次回缩）**

```text
输入：nums = [65,66,67,66,66,67,69,68]
输出：26

解释：r = 0..5 时窗口一路扩张到 [0,5]，贡献 1+2+3+4+5+6；
r = 6 (69) 加入后 max − min = 4，l 从 0 一路缩到 5，贡献 2；
r = 7 (68) 时窗口 [5,7] 差为 2，贡献 3。
总计 1+2+3+4+5+6+2+3 = 26。
```

## 3. 解题思路

### 3.1 暴力思路

枚举全部 $O(n^2)$ 个子数组，每个子数组扫一遍求 $\max - \min$ 判断合法性，时间 $O(n^3)$。

稍作改进：固定左端点 $l$，右端点 $r$ 向右扩张时**增量维护** $\max$ 和 $\min$，一旦 $\max - \min > 2$ 就 `break`（再扩张只会更差）。但最坏情形（如全相等数组）每个 $l$ 都要扫到结尾，仍是 $O(n^2)$，$n = 10^5$ 时约 $5 \times 10^9$ 次操作，不可接受。

> 💡 暴力失败的根源：同一个右端点被不同左端点反复扫描。突破口是把枚举方式改成**每个右端点只统计一次**。

### 3.2 核心观察一：任意对条件 ⟺ max − min ≤ 2

定义要求检查所有下标对，$O(k^2)$ 对。但注意到：窗口内所有元素都落在 $[\min, \max]$ 之间，**两两之差的上确界就是 $\max - \min$**（由取得最大、最小值的两个位置达到）。于是：

$$\text{合法} \iff \max(nums[l..r]) - \min(nums[l..r]) \le 2$$

判断从 $O(k^2)$ 对降为两个数之差。

![任意两元素之差等价于max减min](images/continuous_subarrays_window_concept.svg)

### 3.3 核心观察二：合法性对收缩封闭 → 滑动窗口计数

**封闭性**：若 $[l, r]$ 合法，则其任意子区间 $[l', r'] \subseteq [l, r]$ 也合法——子区间的 $\max$ 只会变小、$\min$ 只会变大，差值只会收缩。

由此得到两个直接推论：

1. **左端点单调**：设 $f(r)$ 为使 $[l, r]$ 合法的最小 $l$，则 $f(r)$ 随 $r$ 单调不减（右端收缩回去仍合法）；
2. **按右端点计数**：以 $r$ 为右端点的合法子数组恰好是 $[l, r]$（$f(r) \le l \le r$）这**连续**一段，共 $r - f(r) + 1$ 个；$l < f(r)$ 时由 $f$ 的最小性不合法。

于是标准双指针模板适用：$r$ 从左到右扫，维护窗口合法的最小 $l$，每个 $r$ 贡献 $r - l + 1$。

### 3.4 维护窗口 max / min：单调队列

窗口每次变化只有一端进出，用两个**单调双端队列**维护：`maxD` 存下标、对应值严格递减（队首即窗口最大值），`minD` 对应值严格递增（队首即最小值）。新元素从尾部入队时弹掉被"淹没"的元素；左端收缩时，若队首下标滑出窗口就弹队首。

![单调队列维护窗口最大最小值](images/continuous_subarrays_monotonic_queue.svg)

> 💡 也可用 `multiset` / `SortedList`（$O(n \log n)$）或惰性堆维护 $\max/\min$；单调队列是唯一能做到 $O(n)$ 的。另一个有趣观察：合法窗口内所有值落在 $[\min, \min+2]$，至多 $3$ 个不同整数值，理论上还能用计数哈希表 + 懒删除做，但实现不如单调队列干净。

## 4. 算法细节

1. **两个 deque 存下标**而非值：左端收缩时需要判断"队首是否滑出窗口"，只有下标能回答；值相同时也可能需要区分。
2. **入队弹尾条件**：`maxD` 弹掉对应值 $\le nums[r]$ 的（相等也弹，保留下标**更新**的，过期更晚）；`minD` 对称弹对应值 $\ge nums[r]$ 的。
3. **收缩循环**：`while (nums[maxD.front()] - nums[minD.front()] > 2)`，循环体内：若 `maxD.front() == l` 弹队首；若 `minD.front() == l` 弹队首；`l++`。顺序是**先判断过期再移动 l**。
4. **计数**：每个 $r$ 结束后 `ans += r - l + 1`。
5. **四步循环骨架**：入队 → 查差收缩 → 计数 → $r$ 右移，每轮 $O(1)$ 均摊。

## 5. 正确性证明

**引理 1**（判据等价）：子数组 $T$ 合法 $\iff \max(T) - \min(T) \le 2$。

**证明**：（⇐）对任意 $a, b \in T$，有 $\min(T) \le a, b \le \max(T)$，故 $|a - b| \le \max(T) - \min(T) \le 2$。（⇒）若 $\max(T) - \min(T) > 2$，取 $i_1$ 为取得 $\max$ 的下标、$i_2$ 为取得 $\min$ 的下标，则 $|nums[i_1] - nums[i_2]| = \max(T) - \min(T) > 2$，违反定义。∎

**引理 2**（封闭性）：若 $[l, r]$ 合法且 $[l', r'] \subseteq [l, r]$，则 $[l', r']$ 合法。

**证明**：$\max([l', r']) \le \max([l, r])$，$\min([l', r']) \ge \min([l, r])$，故差值 $\le 2$，由引理 1 即得。∎

**引理 3**（$f$ 单调）：设 $f(r) = \min\{l : [l, r] \text{ 合法}\}$，则 $f$ 单调不减。

**证明**：对 $r' < r$，$[f(r), r'] \subseteq [f(r), r]$，由引理 2 合法，故 $f(r') \le f(r)$。∎

**定理**（计数正确）：$\text{ans} = \sum_{r=0}^{n-1} \big(r - f(r) + 1\big)$，且算法中双指针恰好维护 $l = f(r)$。

**证明**：以 $r$ 为右端点的子数组共 $r + 1$ 个（$0 \le l \le r$）。由 $f(r)$ 的最小性，$l < f(r)$ 时 $[l, r]$ 不合法；$l \ge f(r)$ 时 $[l, r] \subseteq [f(r), r]$，由引理 2 合法。故以 $r$ 为右端的合法子数组恰 $r - f(r) + 1$ 个，按右端点分类不重不漏，求和即得。算法中收缩循环终止时窗口 $[l, r]$ 合法且 $[l-1, r]$ 已被弹出（或 $l = 0$），故 $l = f(r)$。∎

**引理 4**（单调队列正确性）：在每次收缩循环判断时，`maxD.front()`、`minD.front()` 恰为当前窗口 $[l, r]$ 的最大、最小值。

**证明**：归纳于操作序列。（入队）弹尾条件保证队列对应值严格递减，新元素入队后队首仍是 $[l, r]$ 内最大值的**最晚出现**下标——被弹出的元素下标更早且值 $\le nums[r]$，不可能再成为"存活于窗口中的最大"。（收缩）`l++` 前弹出队首仅当下标 $< l$ 即将离开窗口，弹出的队首下标 $< l$ 不在窗口内；若队首 $\ge l$ 则仍是窗口内最大。$\min$ 侧对称。∎

**推论**（复杂度）：每个下标至多入队、出队各一次（弹尾 + 弹队首），总操作 $O(n)$。

## 6. 复杂度分析

- **时间复杂度**：$O(n)$
  - 外层 $r$ 扫一遍，每个下标最多进/出每个 deque 各一次，收缩的总步数 $\le n$（$l$ 单调不减），均摊每轮 $O(1)$。
- **空间复杂度**：$O(n)$
  - 两个 deque 最坏各存全部下标（如严格递减数组之于 `maxD`）。

（若用 `SortedList` / `multiset` 替代，时间 $O(n \log n)$、空间 $O(n)$，在本题 $n \le 10^5$ 下同样通过。）

## 7. 参考代码

### C++（单调队列，O(n)）

```cpp
class Solution {
  public:
    long long continuousSubarrays(vector<int>& nums) {
        int n = nums.size();
        deque<int> maxD, minD; // 存下标：maxD 对应值递减，minD 对应值递增
        long long ans = 0;
        int l = 0;
        for (int r = 0; r < n; ++r) {
            while (!maxD.empty() && nums[maxD.back()] <= nums[r]) maxD.pop_back();
            maxD.push_back(r);
            while (!minD.empty() && nums[minD.back()] >= nums[r]) minD.pop_back();
            minD.push_back(r);

            while (nums[maxD.front()] - nums[minD.front()] > 2) {
                if (maxD.front() == l) maxD.pop_front(); // 队首滑出窗口
                if (minD.front() == l) minD.pop_front();
                ++l;
            }
            ans += r - l + 1; // 以 r 为右端点的合法子数组个数
        }
        return ans;
    }
};
```

### Python（单调队列，O(n)）

```python
from collections import deque

class Solution:
    def continuousSubarrays(self, nums: List[int]) -> int:
        n = len(nums)
        max_d = deque()  # 下标，对应值递减，队首 = 窗口 max
        min_d = deque()  # 下标，对应值递增，队首 = 窗口 min
        ans = 0
        l = 0
        for r, v in enumerate(nums):
            while max_d and nums[max_d[-1]] <= v:
                max_d.pop()
            max_d.append(r)
            while min_d and nums[min_d[-1]] >= v:
                min_d.pop()
            min_d.append(r)

            while nums[max_d[0]] - nums[min_d[0]] > 2:
                if max_d[0] == l:
                    max_d.popleft()
                if min_d[0] == l:
                    min_d.popleft()
                l += 1
            ans += r - l + 1
        return ans
```

### Python（SortedList，O(n log n)，赛内更快写出）

```python
from sortedcontainers import SortedList

class Solution:
    def continuousSubarrays(self, nums: List[int]) -> int:
        sl = SortedList()
        ans = 0
        l = 0
        for r, v in enumerate(nums):
            sl.add(v)
            while sl[-1] - sl[0] > 2:  # max − min
                sl.remove(nums[l])
                l += 1
            ans += r - l + 1
        return ans
```

## 8. 边界情况与易错点

1. **必须用 64 位**：答案上界是 $\frac{n(n+1)}{2} \approx 5 \times 10^9$（全相等数组时取到，见示例 2），超出 `int32`。C++ 返回类型与累加器都要 `long long`。
2. **deque 存下标不存值**：收缩时靠"队首下标是否等于 $l$"判断过期，存值无法判断。
3. **弹尾用 `<=` / `>=`（相等也弹）**：相等值保留下标更新者，过期更晚，不会丢失信息；若用严格不等也能算对，但队列更长。
4. **收缩循环内先判过期再 `++l`**：顺序颠倒会把队首下标 $> l$ 的元素误判过期。
5. **终止性**：单元素窗口 $\max - \min = 0$，收缩循环最坏退到 $l = r$ 必然停止，不会越界。
6. **值域 $10^9$ 无需离散化**：单调队列只做相邻比较，与值域无关；不要开值域桶。
7. **别被"下标对"骗了**：条件是任意两下标（即 $\max - \min \le 2$），不是相邻元素差 $\le 2$——后者是另一道模板（LC 2762 的邻居 LC 978、LC 2464 型），判据完全不同。
8. **Python `SortedList.remove` 是删值**：`remove(nums[l])` 删除的是第一个等于 `nums[l]` 的元素，恰好对应"左端点滑出"，与 multiset 语义一致，勿写成 `discard` 之外的索引删除。
