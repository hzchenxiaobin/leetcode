# LeetCode 最长奇偶子数组 题解

## 1. 题目概述

- **标题 / 题号**：最长奇偶子数组（#2866，easy）
- **链接**：https://leetcode.cn/problems/longest-even-odd-subarray-with-threshold/
- **来源**：LeetCode 第 352 场周赛 Q1
- **难度**：简单
- **标签**：数组、动态规划、滑动窗口

**题意**：给定下标从 0 开始的整数数组 `nums` 和整数 `threshold`。求最长连续子数组 `[l, r]`，满足三个条件：

1. **开头是偶数**：`nums[l] % 2 == 0`；
2. **相邻奇偶交替**：对 `[l, r-1]` 内所有 `i`，`nums[i]` 与 `nums[i+1]` 的奇偶性不同（一奇一偶相间）；
3. **不超阈值**：对 `[l, r]` 内所有 `i`，`nums[i] <= threshold`。

返回满足条件的最长子数组长度。注意：只要存在合法子数组，至少长度为 1 的 `[i, i]` 都算。

**约束**：

- `1 <= nums.length <= 100`
- `1 <= nums[i] <= 100`
- `1 <= threshold <= 100`

## 2. 示例

**示例 1**

```text
输入：nums = [3,2,5,4], threshold = 5
输出：3
解释：选 l=1, r=3 的子数组 [2,5,4]：
      2 是偶数开头；2→5→4 奇偶交替；全部 ≤ 5。
```

**示例 2**

```text
输入：nums = [1,2], threshold = 2
输出：1
解释：[1,2] 开头是奇数 1，不合法；只能选 [2]，长度 1。
```

**示例 3**

```text
输入：nums = [2,3,4,5], threshold = 4
输出：3
解释：[2,3,4] 合法（长度 3）；[2,3,4,5] 中 5 > 4 不合法。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有子数组 `[l, r]` 共 `O(n²)` 对，每对从头检查三个条件需 `O(n)`，总复杂度 `O(n³)`。`n <= 100` 时仅 `10^6` 量级，作为签到保底写法完全够用。

稍加观察可得 `O(n²)` 版本：**左端点 `l` 必须是偶数且 `<= threshold`**，枚举这样的 `l` 后，`r` 向右一路延伸直到条件破坏即可：

```text
for l = 0 .. n-1:
    if nums[l] 是奇数 或 nums[l] > threshold:  # 开头条件筛掉大部分 l
        continue
    r = l
    while r+1 < n 且 nums[r+1] <= threshold 且 nums[r+1] 与 nums[r] 奇偶不同:
        r = r + 1
    ans = max(ans, r - l + 1)
```

这是「从题面到代码的最短路径」，比赛时 Q1 建议先写这个保底。下面把它优化到一遍扫描。

### 3.2 核心观察：以 i 结尾的「接龙」DP

三个条件全是**局部条件**：开头条件只看 `l`，交替条件只看**相邻对**，阈值条件**逐元素**判断。因此：

> **合法子数组去掉最后一个元素，剩余部分仍然合法。**

这就是**最优子结构**。定义：

$$f(i) = \text{以 } i \text{ 结尾的最长合法子数组长度（不存在则为 } 0\text{）}$$

设 `x = nums[i]`，`f(i)` 只依赖 `f(i-1)`、`x` 和 `nums[i-1]` 的奇偶性，分三个分支：

1. **超阈值**：`x > threshold` → `f(i) = 0`，链条在此强制断裂；
2. **接龙延伸**：`f(i-1) > 0` 且 `x` 与 `nums[i-1]` 奇偶不同 → `f(i) = f(i-1) + 1`；
3. **重开新链**：其它情况接不上龙，只能自身另起炉灶 → `f(i) = x` 为偶数 ? 1 : 0（**奇数不能当开头**）。

答案为 `max f(i)`。用示例 1 看一遍定义：

![「以 i 结尾」的接龙 DP 模型](images/wc352_q1_even_odd_dp_model.svg)

### 3.3 算法流程

一遍遍历，用滚动变量 `cnt` 代替 `f` 数组：处理 `x = nums[i]` 之前 `cnt` 恰为 `f(i-1)`，处理后更新为 `f(i)`，同时随时用 `ans = max(ans, cnt)` 记录答案：

![一次遍历的决策流程](images/wc352_q1_even_odd_flow.svg)

## 4. 算法细节

1. **滚动变量**：`cnt` 即 `f(i-1)`，无需 `f` 数组，空间 `O(1)`。
2. **分支顺序**：先判阈值（一票否决），再判接龙延伸，最后重开——顺序与逻辑上「先排除、再延伸、兜底重开」一致。
3. **延伸条件是「与前一元素奇偶不同」**，不是「与链头距离的奇偶」：交替性是相邻对的性质，只要 `x` 与 `nums[i-1]` 奇偶不同且前面有链（`cnt > 0`），接上去必然保持交替。
4. **重开分支必须检查偶数**：`cnt = x % 2 == 0 ? 1 : 0`，因为奇数不能单独开头；漏掉这一步会把 `[1,2]` 误判成长度 2。
5. **`i = 0` 自然落入重开分支**：无前驱元素，延伸条件 `i > 0` 不成立，无需特判。
6. **`ans` 在循环内随时更新**，不要只在循环结束后取一次。

## 5. 正确性证明

**引理 1（子结构）**：长度 `>= 2` 的合法子数组去掉最后一个元素后仍合法。

**证明**：设 `[l, r]` 合法且 `l < r`。考察 `[l, r-1]`：开头 `nums[l]` 偶性不变；其相邻对集合是 `[l, r]` 相邻对集合去掉 `(r-1, r)`，逐对奇偶交替保持；逐元素 `<= threshold` 保持。∎

**引理 2（延伸的必要条件）**：若存在长度 `>= 2` 且以 `i` 结尾的合法子数组，则 `nums[i] <= threshold`、`f(i-1) >= 1`，且 `nums[i]` 与 `nums[i-1]` 奇偶不同。

**证明**：设 `[l, i]` 合法且 `l < i`。阈值条件直接给出 `nums[i] <= threshold`；由引理 1，`[l, i-1]` 合法，故 `f(i-1) >= i-1-l+1 >= 1`；`(i-1, i)` 是 `[l, i]` 的相邻对，奇偶不同。∎

**定理**：按三分支递推得到的 `f(i)` 等于以 `i` 结尾的最长合法子数组长度（不存在则为 0），故 `max_i f(i)` 为答案。

**证明**（对 `i` 归纳，同时证可行性与最优性）：

- **可行性（递推值不超过真实值）**：分支②给 `f(i-1)+1`，由归纳假设存在以 `i-1` 结尾、长 `f(i-1) >= 1` 的合法子数组，其元素均 `<= threshold` 且首元素为偶；接上 `nums[i] <= threshold`（分支前提）且与 `nums[i-1]` 奇偶不同，仍合法。分支③给 1 时 `nums[i]` 为偶数且 `<= threshold`，`[i, i]` 合法；给 0 则无对应子数组。分支①给 0，因为任何以 `i` 结尾的子数组都含超阈值的 `nums[i]`，必不合法。
- **最优性（真实值不超过递推值）**：设以 `i` 结尾的最长合法子数组长度为 `L`。若 `L = 0`，三个分支给出的值均为 0（分支②③不触发或与 `L = 0` 矛盾：若 `nums[i] <= threshold` 且为偶数则 `[i,i]` 合法，`L >= 1`；若为奇数且分支②成立，则由归纳假设有以 `i-1` 结尾的合法链可延伸，`L >= 2`，均矛盾）。若 `L = 1`，则 `nums[i]` 为偶数且 `<= threshold`；由引理 2，长度 `>= 2` 不存在（否则 `L >= 2`），故延伸条件不成立，落入分支③得 1。若 `L >= 2`，由引理 2 延伸条件成立，落入分支②，且以 `i` 结尾长度 `L` 的链去掉末尾是以 `i-1` 结尾、长 `L-1` 的合法链，由归纳假设 `f(i-1) >= L-1`，故 `f(i) = f(i-1)+1 >= L`；结合可行性得 `f(i) = L`。∎

最优子结构（引理 1）+ 无后效性（`f(i)` 只依赖 `f(i-1)` 与前一个元素）保证了一遍线性递推的正确性。

## 6. 复杂度分析

- **时间复杂度**：`O(n)`。单次遍历，每个元素做常数次比较（阈值、奇偶、取 max）。
- **空间复杂度**：`O(1)`。仅 `ans`、`cnt` 两个滚动变量，无需 DP 数组。

对比：枚举左端点延伸为 `O(n²)` 时间 `O(1)` 空间；纯暴力三重循环 `O(n³)`。`n <= 100` 三者都能过，但接龙 DP 是可迁移到大数据量的模板。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int longestAlternatingSubarray(vector<int>& nums, int threshold) {
        int ans = 0, cnt = 0;
        int n = nums.size();
        for (int i = 0; i < n; i++) {
            int x = nums[i];
            if (x > threshold) {
                cnt = 0;
            } else if (i > 0 && cnt > 0 && x % 2 != nums[i - 1] % 2) {
                cnt++;
            } else {
                cnt = (x % 2 == 0);
            }
            ans = max(ans, cnt);
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def longestAlternatingSubarray(self, nums: List[int], threshold: int) -> int:
        ans = cnt = 0
        for i, x in enumerate(nums):
            if x > threshold:
                cnt = 0
            elif i and cnt and x % 2 != nums[i - 1] % 2:
                cnt += 1
            else:
                cnt = 1 if x % 2 == 0 else 0
            ans = max(ans, cnt)
        return ans
```

## 8. 边界情况与易错点

1. **答案可以为 0**：数组中不存在任何「偶数且 `<= threshold`」的元素时（如全是奇数，或偶数全部超阈值），无合法子数组，返回 **0** 而不是 1。
2. **重开时必须检查偶数**：分支③是 `cnt = (x 为偶数)`，漏掉奇偶检查会把 `[1,2]` 误判为 2。
3. **延伸不能丢掉 `cnt > 0` 的守卫**：`nums = [3,8,5]`、`threshold = 5` 时正确答案是 0（无偶数 `<= 5`）。若漏掉 `cnt > 0`，`i = 2` 处 5 与 8 奇偶不同会误接成 `cnt = 1`，错判出长度 1。
4. **先判阈值再判奇偶**：超阈值一票否决，即使 `x` 是偶数也不能作为开头或链内元素（如 `[2,8]`、`threshold = 5` 中 8 直接把链清零）。
5. **奇偶相同必须断链**：`[2,4]` 中 4 与 2 都是偶数，不能延伸，只能重开为 `[4]`，答案 1；误判延伸会得到非法的 `[2,4]`。
6. **`i = 0` 无前驱**：直接落入重开分支，延伸条件中的 `i > 0` 守卫即可覆盖，无需额外特判。
