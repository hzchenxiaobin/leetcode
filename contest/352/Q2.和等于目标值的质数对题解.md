# LeetCode 和等于目标值的质数对 题解

## 1. 题目概述

- **标题 / 题号**：和等于目标值的质数对（#2761，medium）
- **链接**：https://leetcode.cn/problems/prime-pairs-with-target-sum/
- **来源**：LeetCode 第 352 场周赛 Q2
- **难度**：中等
- **标签**：数组、数学、枚举、数论

**题意**：给定整数 $n$，找出所有同时满足以下三个条件的数对 $[x, y]$：

1. $1 \le x \le y \le n$；
2. $x + y = n$；
3. $x$ 和 $y$ 都是质数。

以二维列表形式返回所有 $[x_i, y_i]$，按 $x_i$ **非递减**排序；不存在则返回空数组。注意：质数是大于 1 且只有 1 和它本身两个因子的自然数（**1 不是质数**）。

**约束**：

- $1 \le n \le 10^6$

## 2. 示例

**示例 1**

```text
输入：n = 10
输出：[[3,7],[5,5]]
解释：3 + 7 = 10 且 5 + 5 = 10，两对都是质数对，按 x 非递减返回。
```

**示例 2**

```text
输入：n = 2
输出：[]
解释：只有 1 + 1 = 2，而 1 不是质数，返回空数组。
```

**示例 3**

```text
输入：n = 11
输出：[]
解释：11 是奇数，唯一候选是 [2, 9]；但 9 = 3×3 是合数，故无解。
```

## 3. 解题思路

### 3.1 暴力思路：逐个试除判质

最直接的做法：枚举 $x \in [2, n/2]$，令 $y = n - x$，对 $x$、$y$ 分别做 $O(\sqrt n)$ 的试除判质，都为质数则收入答案：

```text
for x = 2 .. n/2:
    if isPrime(x) and isPrime(n - x):     # 每次判质要试除到 √n
        ans.append([x, n - x])
```

总复杂度 $O(n\sqrt n)$：$n = 10^6$ 时约 $10^9$ 次除法，**必然超时**。瓶颈不在「枚举配对」，而在**同一个数被反复判质**——比如 $y = 999983$ 会随不同的 $x$ 被查询多次，每次都从头试除。

### 3.2 核心观察：埃氏筛预处理 + $O(1)$ 双查表

> 💡 配对判定只依赖「某个数是不是质数」这一**布尔信息**。与其每次花 $O(\sqrt n)$ 现算，不如花 $O(n \log \log n)$ **一次性筛出** $[2, n]$ 内所有数的质性，之后每次判定只需两次数组访问。

再配合两条结构性观察，把枚举量压到最小：

1. **对称性**：$x + y = n$ 意味着 $y = n - x$，$x$ 与 $y$ 关于 $n/2$ 对称。规定 $x \le y$ 后，只需枚举**左半边** $x \in [2, \lfloor n/2 \rfloor]$，不重不漏；
2. **奇偶性**（比赛加速点）：
   - $n$ 为**奇数** ⇒ $x, y$ 必一奇一偶 ⇒ 偶的那方只能是唯一的偶质数 $2$ ⇒ **唯一候选** $[2, n-2]$，一次查表即可出答案；
   - $n$ 为**偶数** ⇒ $x, y$ 同为奇质数——这正是**哥德巴赫猜想**的计算版，没有捷径，老老实实枚举。

## 4. 算法细节

1. **埃氏筛的两个减法**：外层 $i$ 只需到 $\sqrt n$（任何 $\le n$ 的合数必有 $\le \sqrt n$ 的质因子）；内层从 $i \cdot i$ 起划（更小的倍数 $2i, \ldots, (i-1)i$ 已被更小的质因子划过）。这两点不影响正确性，只影响常数，但 $n = 10^6$ 时值得写对。
2. **$x$ 的上界是 $\lfloor n/2 \rfloor$ 且含等号**：$n = 10$ 时 $x = 5$ 对应 $[5,5]$，$n = 4$ 时 $x = 2$ 对应 $[2,2]$，漏掉等号会丢失 $x = y$ 的解。
3. **无需排序**：$x$ 从 $2$ 递增扫描，命中即 `append`，结果天然按 $x$ 非递减，直接满足输出要求。
4. **`n < 4` 特判**：最小的质数是 $2$，故最小的质数对和为 $4$；$n \le 3$ 直接返回空列表，顺便省掉建数组（不做特判让循环空跑也不错，但显式剪枝意图更清晰）。
5. **溢出防御**：筛的外层条件写成 `(long long)i * i <= n`。本题 $n \le 10^6$、$i \le 10^3$ 不会溢出，但这是值域扩大后的保命习惯。
6. **空间形态**：C++ 用 `vector<bool>`（位压缩，$n = 10^6$ 约 125 KB）；Python 用 `bytearray` 比列表更省。

## 5. 正确性证明

**引理 1（筛的正确性）**：埃氏筛结束后，对任意 $v \in [2, n]$，`isPrime[v]` 为 `true` 当且仅当 $v$ 是质数。

**证明**：
（⇐）设 $v$ 是质数但被划掉，则存在质数 $p$ 与整数 $k \ge p$ 使 $v = k \cdot p$（内层从 $p \cdot p$ 起划，故被划掉的数都 $\ge p^2$，即 $k \ge p \ge 2$）。于是 $v$ 有真因子 $p$，与 $v$ 是质数矛盾。故质数永不被划。
（⇒）设 $v \in [2, n]$ 是合数，取其最小质因子 $p$，记 $v = p \cdot m$。因 $p$ 最小，$m$ 的所有质因子 $\ge p$，故 $m \ge p$，从而 $p^2 \le v \le n$，即 $p \le \sqrt n$，外层循环会到达 $i = p$。此时内层从 $p^2$ 起以步长 $p$ 划数，而 $v = p \cdot m \ge p^2$ 且 $v \equiv 0 \pmod p$，必被划掉。∎

**引理 2（枚举不重不漏）**：合法质数对集合恰为 $\{(x,\, n - x) : 2 \le x \le \lfloor n/2 \rfloor,\ x \text{ 与 } n - x \text{ 均为质数}\}$。

**证明**：设 $(x, y)$ 合法，则 $y = n - x$ 且 $x \le y$，故 $2x \le x + y = n$，即 $x \le \lfloor n/2 \rfloor$；又 $x$ 是质数故 $x \ge 2$。反之，对满足 $2 \le x \le \lfloor n/2 \rfloor$ 的 $x$，有 $2 \le x \le n - x \le n - 2 < n$，故 $(x, n-x)$ 满足题面全部三个条件（当二者均为质数时）。映射 $(x, y) \mapsto x$ 是两集合间的双射。∎

**定理**：算法输出恰为全部合法质数对，且按 $x_i$ 非递减排列。

**证明**：由引理 1，`isPrime[x] && isPrime[n-x]` 等价于「$x$ 与 $n-x$ 均为质数」；由引理 2，枚举范围覆盖且仅覆盖每个合法对一次。$x$ 从 $2$ 递增取值，命中时按序追加，故输出完备且有序。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \log \log n)$。埃氏筛主导（$n = 10^6$ 时 $\log \log n \approx 2.6$，约 $2.6 \times 10^6$ 次标记）；配对扫描严格 $O(n/2)$ 次查表，是低阶项。对比暴力的 $O(n\sqrt n) \approx 10^9$，快约三个数量级。
- **空间复杂度**：$O(n)$。`isPrime` 布尔数组（`vector<bool>` 位压缩下约 $n/8$ 字节，$n = 10^6$ 时约 125 KB）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<vector<int>> findPrimePairs(int n) {
        vector<vector<int>> ans;
        if (n < 4) return ans;                    // 最小质数对 2+2=4

        // ① 埃氏筛：标记 [0, n] 的质性
        vector<bool> isPrime(n + 1, true);
        isPrime[0] = isPrime[1] = false;
        for (int i = 2; (long long)i * i <= n; ++i) {
            if (isPrime[i]) {
                for (int j = i * i; j <= n; j += i) {   // 从 i*i 起划
                    isPrime[j] = false;
                }
            }
        }

        // ② 枚举 x ∈ [2, n/2]，双查表配对（x 递增 ⇒ 天然非递减）
        for (int x = 2; x <= n / 2; ++x) {
            int y = n - x;
            if (isPrime[x] && isPrime[y]) {
                ans.push_back({x, y});
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def findPrimePairs(self, n: int) -> List[List[int]]:
        if n < 4:                                 # 最小质数对 2+2=4
            return []

        # ① 埃氏筛：标记 [0, n] 的质性
        is_prime = bytearray([1]) * (n + 1)
        is_prime[0] = is_prime[1] = 0
        i = 2
        while i * i <= n:                         # 外层只到 √n
            if is_prime[i]:
                for j in range(i * i, n + 1, i):  # 从 i*i 起划
                    is_prime[j] = 0
            i += 1

        # ② 枚举 x ∈ [2, n/2]，双查表配对
        ans = []
        for x in range(2, n // 2 + 1):
            if is_prime[x] and is_prime[n - x]:
                ans.append([x, n - x])
        return ans
```

## 8. 边界情况与易错点

1. **`n < 4` 必空**：$n = 1, 2, 3$ 都无法拆成两个 $\ge 2$ 的质数之和（$2 = 1+1$，$3 = 1+2$，而 1 不是质数）。$n = 4$ 是最小的非空情形，输出 `[[2,2]]`。
2. **`x` 上界必须带等号**：`x <= n/2` 用整数除法天然含 $[5,5]$、$[2,2]$ 这类 $x = y$ 的解；写成 `x < n/2` 会丢解。
3. **奇数 `n` 至多一个解**：即 $[2, n-2]$，判一次 `isPrime[n-2]` 即可。比赛时先想通这点，可以对奇数输入直接出答案（对正解而言是常数优化，更是验算手段）。
4. **不要对结果排序**：递增枚举已保证非递减；画蛇添足的排序不影响正确性但浪费 $O(k \log k)$。
5. **筛的边界**：数组开 `n + 1` 大小；外层 `i * i <= n` 建议用 `long long` 写法防值域扩大后溢出；内层起点写 `i * i` 而非 `2 * i`（后者正确但会重复划）。
6. **别把 1 当质数**：`isPrime[0] = isPrime[1] = false` 必须显式置位，否则 $x + 1 = n$ 型的假对会混入。
7. **`n = 2` 时 `n / 2 = 1`**：即使不做 `n < 4` 特判，循环 `for x = 2 .. 1` 也自然空跑，双保险不会越界。
