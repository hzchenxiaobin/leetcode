# LeetCode 所有子数组中不平衡数字之和 题解

## 1. 题目概述

- **标题 / 题号**：所有子数组中不平衡数字之和（#2763，hard）
- **链接**：https://leetcode.cn/problems/sum-of-imbalance-numbers-of-all-subarrays/
- **来源**：LeetCode 第 352 场周赛 Q4
- **难度**：困难
- **标签**：数组、哈希表、枚举、贡献法

**题意**：

定义长度为 $n$ 的数组 `arr` 的**不平衡数字**：将 `arr` 排序得 `sarr`，统计满足 $0 \le i < n-1$ 且 $sarr[i+1] - sarr[i] > 1$ 的下标 $i$ 的数目。即排序后相邻两个元素之差超过 $1$ 的"断口"个数。

给定数组 `nums`，返回其**所有子数组**的不平衡数字之和。

**约束**：

- $1 \le nums.length \le 1000$
- $1 \le nums[i] \le nums.length$（元素值落在 $[1, n]$ 内，这是本题的关键条件）

## 2. 示例

**示例 1**

```text
输入：nums = [2,3,1,4]
输出：3

解释：有 3 个子数组不平衡数字非 0：
- [3, 1]   → sorted = [1, 3]，gap = 2 > 1，不平衡数字 1
- [3, 1, 4] → sorted = [1, 3, 4]，3 − 1 = 2 > 1，不平衡数字 1
- [1, 4]   → sorted = [1, 4]，gap = 3 > 1，不平衡数字 1
其余子数组不平衡数字均为 0，总和为 3。
```

**示例 2**

```text
输入：nums = [1,3,3,3,5]
输出：8

解释：值 1 与 3 之间（差 2）、3 与 5 之间（差 2）各形成断口，
含 "1 不含 2" 或 "含 5 不含 4" 的子数组逐个累加，共 8。
```

## 3. 解题思路

### 3.1 暴力思路

枚举全部 $O(n^2)$ 个子数组，每个排序后数相邻差大于 $1$ 的位置：

- 时间复杂度 $O(n^3 \log n)$，$n = 1000$ 时约 $10^{10}$，不可接受。

一个稍优的暴力：固定左端点 $l$，右端点 $r$ 从左往右扩张，用有序结构维护当前子数组的去重集合并增量维护断口数，可做到 $O(n^2 \log n)$。但本题有更优美的两个观察，下面逐步推出。

### 3.2 核心观察一：不平衡数字 = 断点计数 − 1

设子数组的**去重值集合**为 $S$，定义

$$D = \#\{\, v \in S : v - 1 \notin S \,\}$$

即 $S$ 中"左邻值缺席"的值个数。把 $S$ 画在数轴上，会形成若干段**极大连续段**，每段的段首恰好是一个"左邻缺席"的值，因此 $D$ 就是连续段的段数，而**不平衡数字正是段与段之间的空隙个数**：

$$\text{imbalance} = D - 1$$

![断点分解示意图](images/imbalance_runs_decomposition.svg)

> 💡 **关键收益**：判断某个值 $v$ 是否是"断点"，只依赖 $v-1$ 这**一个**值是否出现在子数组中，与子数组中其他大小关系无关。于是"对每个子数组排序数 gap"被改写为"对每个值 $v$ 检查 $v-1$ 是否缺席"。

### 3.3 优化一：O(n²) 增量维护

利用观察一，固定左端点 $l$，右端点右移时只需 $O(1)$ 维护 $D$：

当加入一个**此前未出现**的值 $v$ 时，只有 $v$ 自己和 $v+1$ 的断点状态会改变：

- 若 $v - 1$ 不在场：$v$ 成为新断点，$D \mathrel{+}= 1$；
- 若 $v + 1$ 已在场：$v$ 的出现抹掉了 $v+1$ 的断点，$D \mathrel{-}= 1$。

$$\Delta D = [\,v-1 \notin S\,] - [\,v+1 \in S\,]$$

![增量更新规则](images/imbalance_incremental_delta.svg)

每步把 $D - 1$ 累加进答案即可，总复杂度 $O(n^2)$，$n = 1000$ 时约 $10^6$ 次操作，可以 AC。

### 3.4 优化二：贡献法 O(n log n)（正解）

再进一步：与其按子数组枚举，不如直接计算**每个下标 $j$ 对答案的贡献**。

把 $\sum_{\text{子数组}} D(\text{子数组})$ 拆开：每个"子数组 × 断点值 $v$"对，唯一归属到 $v$ 在该子数组中的**首次出现位置** $j$。于是对每个下标 $j$（值 $v = nums[j]$），统计满足以下条件的子数组 $[l, r]$ 个数 $f(j)$：

1. **包含 $j$ 且 $j$ 是 $v$ 的首次出现**：$l \in (p_j,\, j]$，其中 $p_j$ 是 $j$ 左边最近的同值下标（无则 $-1$）；
2. **$v - 1$ 缺席**：$[l, r]$ 中不能出现值 $v-1$。

对左端点的额外限制来自 $v-1$：设 $L_j = \max(p_j,\, [p_j+1,\, j-1] \text{ 内最右的 } v-1 \text{ 的下标})$，则 $l$ 只能取 $(L_j,\, j]$；设 $q_j$ 为 $j$ 右边第一个 $v-1$ 的下标（无则 $n$），则 $r$ 只能取 $[j,\, q_j - 1]$。两个方向独立，直接乘起来：

$$f(j) = (j - L_j) \times (q_j - j)$$

![贡献法窗口](images/imbalance_contribution_window.svg)

最后，由于每个子数组都被"段首 − 1"多算了恰好 $1$（即 $D-1$ 中的那个 $1$），减去子数组总数：

$$\text{ans} = \sum_{j=0}^{n-1} f(j) \;-\; \frac{n(n+1)}{2}$$

### 3.5 示例演算

对 `nums = [2,3,1,4]` 逐下标演算：

![示例演算表](images/imbalance_walkthrough.svg)

$2 + 3 + 6 + 2 = 13$，减去子数组总数 $10$，得 $3$，与示例一致。

## 4. 算法细节

1. **预处理出现位置**：`pos[w]` 存每个值 $w$ 的所有下标（升序）。由于 $1 \le nums[i] \le n$，桶大小 $O(n)$。
2. **对每个 $j$ 三次二分**：
   - 在 `pos[v]` 中二分找 $p_j$：最后一个 $< j$ 的下标；
   - 在 `pos[v-1]` 中二分找左边最近的 $v-1$：最后一个 $< j$ 的下标，若 $> p_j$ 则作为左阻碍 $L_j$，否则 $L_j = p_j$；
   - 同一次二分的右侧结果即为 $q_j$：第一个 $\ge j$ 的下标（$j$ 本身不可能是 $v-1$，故即第一个 $> j$）。
3. **特判 $v = 1$**：$v - 1 = 0$ 永不出现，自然退化为 $L_j = p_j$、$q_j = n$，无需特殊分支之外的处理（代码中 `if v > 1` 即可）。
4. **汇总**：累加 $(j - L_j)(q_j - j)$，最后减去 $\frac{n(n+1)}{2}$。

## 5. 正确性证明

**引理 1**：对任意非空子数组，$\text{imbalance} = D - 1$，其中 $D = \#\{v \in S : v-1 \notin S\}$，$S$ 为去重值集合。

**证明**：将 $S$ 的值按大小排成若干极大连续段。每个连续段的段首 $v$ 满足 $v-1 \notin S$（否则可向左扩展，与极大性矛盾）；反之每个 $v \in S$ 且 $v-1 \notin S$ 的值必是某段段首。故 $D$ = 连续段数。排序后，断口（相邻差 $> 1$）恰好出现在相邻两段之间，共"段数 $-\ 1$"个；段内相邻差为 $1$，同值相邻差为 $0$，均不产生断口。∎

**引理 2**（归属唯一性）：$\sum_{\text{子数组 } T} D(T) = \sum_{j=0}^{n-1} f(j)$。

**证明**：$D(T) = \#\{v \in S(T) : v-1 \notin S(T)\}$。对每一对 $(T, v)$（$v$ 是 $T$ 的断点值），$v$ 在 $T$ 中至少出现一次，将其归属到 $T$ 中 $v$ 的**最小下标** $j$。这是一个双射：给定 $j$，$T$ 恰好是所有满足「$p_j < l \le j \le r$ 且 $[l,r]$ 内无 $v-1$」的区间 $[l,r]$，这正是 $f(j)$ 的定义。∎

**引理 3**（窗口公式）：$f(j) = (j - L_j)(q_j - j)$，其中 $L_j = \max(p_j, m_j)$，$m_j$ 为 $[p_j+1,\, j-1]$ 内最右的 $v-1$ 下标（无则 $-\infty$），$q_j$ 为 $j$ 右边第一个 $v-1$ 下标（无则 $n$）。

**证明**：合法的 $l$ 需满足 $l > p_j$（首次出现）且 $[l, j]$ 内无 $v-1$。$[l, j]$ 含 $v-1$ 当且仅当 $l \le m_j$（$m_j$ 是 $j$ 左边最近的 $v-1$，若 $m_j \le p_j$ 则该约束被 $l > p_j$ 覆盖）。故 $l \in (L_j, j]$，共 $j - L_j$ 个。合法的 $r$ 需满足 $[j, r]$ 内无 $v-1$，而 $j$ 右边第一个 $v-1$ 在 $q_j$，故 $r \in [j, q_j - 1]$，共 $q_j - j$ 个。$l$ 与 $r$ 的约束互相独立（前者只涉及 $\le j$ 的位置，后者只涉及 $> j$ 的位置），相乘即得。∎

**定理**：$\text{ans} = \sum_j f(j) - \frac{n(n+1)}{2}$。

**证明**：由引理 1，$\text{ans} = \sum_T (D(T) - 1) = \sum_T D(T) - \#\{T\}$。子数组总数为 $\frac{n(n+1)}{2}$；由引理 2、3，$\sum_T D(T) = \sum_j f(j) = \sum_j (j - L_j)(q_j - j)$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \log n)$
  - 预处理每个值的出现位置：$O(n)$；
  - 每个下标 $j$ 做两次二分：$O(\log n)$，共 $O(n \log n)$。
- **空间复杂度**：$O(n)$
  - `pos` 桶合计存 $n$ 个下标。

（若采用 3.3 节的增量写法则为 $O(n^2)$ 时间、$O(n)$ 空间，在本题规模下同样通过。）

## 7. 参考代码

### C++（贡献法，O(n log n)）

```cpp
class Solution {
  public:
    int sumImbalanceNumbers(vector<int>& nums) {
        int n = nums.size();
        // pos[w]：值 w 的所有出现下标（升序）
        vector<vector<int>> pos(n + 1);
        for (int i = 0; i < n; ++i) pos[nums[i]].push_back(i);

        long long total = 0;
        for (int j = 0; j < n; ++j) {
            int v = nums[j];
            // p：j 左边最近的同值下标（保证 j 是子数组中 v 的首次出现）
            auto& pv = pos[v];
            int t = lower_bound(pv.begin(), pv.end(), j) - pv.begin();
            int p = (t > 0) ? pv[t - 1] : -1;

            int L = p, q = n;
            if (v > 1) {
                auto& pw = pos[v - 1];
                int t2 = lower_bound(pw.begin(), pw.end(), j) - pw.begin();
                if (t2 > 0 && pw[t2 - 1] > p) L = pw[t2 - 1]; // 左边最近的 v-1
                if (t2 < (int)pw.size()) q = pw[t2];           // 右边第一个 v-1
            }
            total += 1LL * (j - L) * (q - j);
        }
        // 每个子数组在 D 中多算了 1（段首 − 段首 − 1），减去子数组总数
        return total - 1LL * n * (n + 1) / 2;
    }
};
```

### Python（贡献法，O(n log n)）

```python
from bisect import bisect_left

class Solution:
    def sumImbalanceNumbers(self, nums: List[int]) -> int:
        n = len(nums)
        pos = [[] for _ in range(n + 1)]
        for i, v in enumerate(nums):
            pos[v].append(i)

        total = 0
        for j, v in enumerate(nums):
            pv = pos[v]
            t = bisect_left(pv, j)
            p = pv[t - 1] if t > 0 else -1

            L, q = p, n
            if v > 1:
                pw = pos[v - 1]
                t2 = bisect_left(pw, j)
                if t2 > 0 and pw[t2 - 1] > p:
                    L = pw[t2 - 1]
                if t2 < len(pw):
                    q = pw[t2]
            total += (j - L) * (q - j)

        return total - n * (n + 1) // 2
```

### Python（增量法，O(n²)，赛内更易写出）

```python
class Solution:
    def sumImbalanceNumbers(self, nums: List[int]) -> int:
        n = len(nums)
        ans = 0
        for l in range(n):
            present = [False] * (n + 2)
            present[nums[l]] = True
            d = 1  # D：{v ∈ S : v−1 ∉ S} 的个数，单元素时为 1
            ans += d - 1
            for r in range(l + 1, n):
                v = nums[r]
                if not present[v]:
                    present[v] = True
                    d += (0 if present[v - 1] else 1) - (1 if present[v + 1] else 0)
                ans += d - 1
        return ans
```

## 8. 边界情况与易错点

1. **减子数组总数不要忘**：$\sum f(j)$ 统计的是 $\sum D$，而答案要的是 $\sum (D-1)$，最后必须减去 $\frac{n(n+1)}{2}$。漏减是本解法最典型的错误。
2. **首次出现的归属**：$l$ 的下界由 $p_j$（同值前驱）与 $m_j$（左边最近 $v-1$）**共同**决定，取 $\max$。只考虑 $p_j$ 会把"$v-1$ 在 $l$ 与 $j$ 之间"的非法子数组算进来。
3. **$L_j$ 的判定方向**：左边最近的 $v-1$ 必须严格大于 $p_j$ 才构成额外阻碍；若它 $\le p_j$，则已被"$l > p_j$"覆盖，$L_j = p_j$。
4. **$v = 1$ 的退化**：$v - 1 = 0$ 永不出现，自动退化为 $L_j = p_j$、$q_j = n$。利用值域下界 $nums[i] \ge 1$，无需额外判空。
5. **溢出**：$n = 1000$ 时 $\sum f(j)$ 可达约 $2.5 \times 10^8$，勉强在 `int` 范围内，但乘法 $(j-L)(q-j)$ 与累加建议用 `long long`（Python 无此问题）。
6. **增量法的数组越界**：`present` 开到 $n+2$，避免查询 `present[v+1]` 当 $v = n$ 时越界。
7. **重复元素**：同一值多次出现时，只有"子数组内的首次出现"才归属贡献，`bisect_left(pos[v], j)` 取到的正是 $j$ 左边最近同值，天然处理了重复。
