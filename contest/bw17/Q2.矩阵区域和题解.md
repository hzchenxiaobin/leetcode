# LeetCode 矩阵区域和 题解

## 1. 题目概述

- **标题 / 题号**：矩阵区域和（#1314，medium）
- **链接**：https://leetcode.cn/problems/matrix-block-sum/
- **来源**：LeetCode 第 17 场双周赛 Q2
- **难度**：中等
- **标签**：数组、矩阵、前缀和

**题意**：给定 $m \times n$ 矩阵 `mat` 与整数 `k`，返回矩阵 `answer`，其中 $answer[i][j]$ 是所有满足 $|r - i| \le k$ 且 $|c - j| \le k$ 且仍在矩阵内的元素 $mat[r][c]$ 之和——即以 $(i,j)$ 为中心、边长 $2k+1$ 的正方形窗口（越界部分裁掉）内的元素和。

**约束**：

- $1 \le m, n \le 100$（$m == mat.length$，$n == mat[i].length$）
- $1 \le k \le 100$
- $mat[i][j]$ 取值范围见题面（本题按非负处理亦不影响算法）

## 2. 示例

**示例 1**

```text
输入：mat = [[1,2,3],[4,5,6],[7,8,9]], k = 1
输出：[[12,21,16],[27,45,33],[24,39,28]]
解释：answer[1][1] 窗口覆盖整个 3×3，和 45；
     answer[0][0] 窗口裁成 2×2，1+2+4+5 = 12。
```

**示例 2**

```text
输入：mat = [[1,2,3],[4,5,6],[7,8,9]], k = 2
输出：[[45,45,45],[45,45,45],[45,45,45]]
解释：k=2 时每个窗口都被裁成整张矩阵。
```

**补充示例**

```text
输入：mat = [[1]], k = 100
输出：[[1]]
解释：窗口远大于矩阵，全部裁剪后只剩整个矩阵。
```

## 3. 解题思路

### 3.1 暴力思路

对每个 $(i, j)$ 双重循环扫窗口 $[i-k, i+k] \times [j-k, j+k]$ 内的元素求和：$O(m n k^2)$，$m = n = k = 100$ 时达 $10^{10}$，必然超时。即使 $k$ 较小时能过，也无从应对更大的约束——必须把「矩形求和」降到 $O(1)$。

### 3.2 核心观察：二维前缀和 + 容斥，矩形和 O(1) 查询

![二维前缀和的容斥结构](images/bw17_q2_prefix_window.svg)

定义（多留一行一列 0 方便边界）：

$$pre[i][j] = \sum_{0 \le r < i,\ 0 \le c < j} mat[r][c]$$

递推 $pre[i][j] = mat[i-1][j-1] + pre[i-1][j] + pre[i][j-1] - pre[i-1][j-1]$。任意子矩形（行区间 $[r_1, r_2]$、列区间 $[c_1, c_2]$，闭区间）的和为：

$$S = pre[r_2+1][c_2+1] - pre[r_1][c_2+1] - pre[r_2+1][c_1] + pre[r_1][c_1]$$

减法把左、上两块多减的「左上角」加了回来一次——容斥原理的二维形态。于是每个查询 $O(1)$，瓶颈消失。

### 3.3 算法流程：先裁窗口边界，再套容斥公式

```text
1. 建 (m+1)×(n+1) 的 pre，全 0；按递推式填满
2. for i = 0..m-1, j = 0..n-1:
       r1 = max(i−k, 0),  r2 = min(i+k, m−1)      # 行窗口裁剪
       c1 = max(j−k, 0),  c2 = min(j+k, n−1)      # 列窗口裁剪
       answer[i][j] = pre[r2+1][c2+1] − pre[r1][c2+1]
                    − pre[r2+1][c1] + pre[r1][c1]
3. 返回 answer
```

### 3.4 示例演算

![k=1 时 (1,1) 与角格 (0,0) 的窗口](images/bw17_q2_block_window.svg)

以示例 1（$3 \times 3$，$k = 1$）演算，$pre$（$4 \times 4$，首行首列为 0）非零部分：

| pre | c=1 | c=2 | c=3 |
|-----|-----|-----|-----|
| r=1 | 1 | 3 | 6 |
| r=2 | 5 | 12 | 21 |
| r=3 | 12 | 27 | 45 |

- $answer[1][1]$：窗口 $[0,2] \times [0,2]$，$S = pre[3][3] - pre[0][3] - pre[3][0] + pre[0][0] = 45$。✓
- $answer[0][0]$：窗口裁为 $[0,1] \times [0,1]$，$S = pre[2][2] - pre[0][2] - pre[2][0] + pre[0][0] = 12$。✓
- $answer[0][1]$：窗口 $[0,1] \times [0,2]$，$S = pre[2][3] - pre[0][3] - pre[2][0] + pre[0][0] = 21$。✓

$k = 2$ 时所有窗口裁成 $[0,2] \times [0,2]$，每格都是 45。✓

## 4. 算法细节

1. **`pre` 为什么要多留一行一列**：让 $r_1 = 0$ 或 $c_1 = 0$ 的查询无需特判——$pre[0][\cdot] = pre[\cdot][0] = 0$ 自动让减项消失。省去大量 `if`。
2. **闭区间与 +1 的换算**：$pre$ 的下标是「开区间右端」语义（$pre[i][j]$ 覆盖行 $0..i-1$），查询闭区间 $[r_1, r_2]$ 时右端下标要 $+1$。这是本题最高频的错点：漏掉 $+1$ 会系统性少算一行/列。
3. **窗口裁剪用 `max`/`min` 成对出现**：$r_1 = \max(i-k, 0)$ 与 $r_2 = \min(i+k, m-1)$ 缺一不可；只裁一边在角格处越界。
4. **`k ≥ max(m, n)` 时**：窗口必然覆盖全矩阵，所有格答案相同（都是总和），公式自动成立（$r_1 = c_1 = 0$，$r_2 = m-1$，$c_2 = n-1$）。
5. **数值范围**：$100 \times 100$ 格、按题面约束 $mat[i][j] \le 100$ 量级计，总和 $\le 10^6$，`int` 富余；即便做泛化（元素 $\pm 10^4$），总和 $10^8$ 仍在 `int` 内。C++ 用 `int` 即可，Python 无虑。
6. **别忘矩阵可能非方阵**：$m \ne n$ 时行、列裁剪的上界分别是 $m-1$、$n-1$，别共用一个。

## 5. 正确性证明

**引理 1（前缀和递推）**：按定义 $pre[i][j] = \sum_{r<i, c<j} mat[r][c]$，则对 $i, j \ge 1$：

$$pre[i][j] = mat[i-1][j-1] + pre[i-1][j] + pre[i][j-1] - pre[i-1][j-1]$$

**证明**：按最后一行、最后一列拆分。$pre[i][j]$ 覆盖的矩形 = 「行 $0..i-2$、列 $0..j-1$」（即 $pre[i-1][j]$）∪「行 $i-1$、列 $0..j-2$」（即 $pre[i][j-1]$ 减去 $pre[i-1][j-1]$ 的部分）∪ 单格 $mat[i-1][j-1]$。其中 $pre[i-1][j]$ 与 $pre[i][j-1]$ 的交集恰为 $pre[i-1][j-1]$（行 $0..i-2$、列 $0..j-2$），被加了两次、应减一次。整理即得。∎

**引理 2（矩形查询公式）**：闭子矩形行 $[r_1, r_2]$、列 $[c_1, c_2]$（$0 \le r_1 \le r_2 < m$，$0 \le c_1 \le c_2 < n$）的元素和

$$S = pre[r_2+1][c_2+1] - pre[r_1][c_2+1] - pre[r_2+1][c_1] + pre[r_1][c_1]$$

**证明**：以 $\chi(A)$ 表示集合 $A$ 的元素和。上式右端按容斥对应四个矩形（行 $<r_2+1$ 列 $<c_2+1$ 减去行 $<r_1$ 与列 $<c_1$ 的两个大块、加回同时满足两者的交集）。逐格验证指示函数：格 $(r, c)$ 被计入当且仅当 $r < r_2+1$ 且 $c < c_2+1$ 且（$r \ge r_1$ 或 $c \ge c_1$ 之一按减项抵消后）——精确地，四个系数之和为 $[r \le r_2][c \le c_2] - [r < r_1][c \le c_2] - [r \le r_2][c < c_1] + [r < r_1][c < c_1]$，逐一枚举 $r$ 与 $r_1, r_2$、$c$ 与 $c_1, c_2$ 的相对位置（9 种组合）可验证该式在且仅在 $r_1 \le r \le r_2$ 且 $c_1 \le c \le c_2$ 时取 1，其余取 0。∎

**定理**：算法返回的 `answer` 满足题意——$answer[i][j]$ 等于 $\{mat[r][c] : |r-i| \le k, |c-j| \le k, 0 \le r < m, 0 \le c < n\}$ 的元素和。

**证明**：条件 $|r - i| \le k$ 且在矩阵内等价于 $r \in [\max(i-k, 0), \min(i+k, m-1)]$（列同理），即算法算出的 $[r_1, r_2] \times [c_1, c_2]$ 闭矩形；由引理 2，容斥公式给出该矩形元素和。∎

## 6. 复杂度分析

- **时间**：$O(mn)$。预处理 $O(mn)$，查询 $m n$ 次、每次 $O(1)$；$m = n = 100$ 时约 $2 \times 10^4$ 次操作。
- **空间**：$O(mn)$。前缀和矩阵（$+1$ 行列）；输出矩阵不计入额外空间。对比暴力 $O(mn k^2)$：$k = 100$ 时快 $10^4$ 倍。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<vector<int>> matrixBlockSum(vector<vector<int>>& mat, int k) {
        int m = (int)mat.size(), n = (int)mat[0].size();
        // pre[i][j] = 以 (0,0) 为左上、(i-1,j-1) 为右下的矩形和（多留一行一列 0）
        vector<vector<int>> pre(m + 1, vector<int>(n + 1, 0));
        for (int i = 0; i < m; ++i)
            for (int j = 0; j < n; ++j)
                pre[i + 1][j + 1] = mat[i][j] + pre[i][j + 1] + pre[i + 1][j] - pre[i][j];

        vector<vector<int>> ans(m, vector<int>(n));
        for (int i = 0; i < m; ++i)
            for (int j = 0; j < n; ++j) {
                // 行区间 [max(i-k,0), min(i+k,m-1)]，列区间同理，闭区间
                int r1 = max(i - k, 0), r2 = min(i + k, m - 1);
                int c1 = max(j - k, 0), c2 = min(j + k, n - 1);
                // 前缀和下标整体 +1
                ans[i][j] = pre[r2 + 1][c2 + 1] - pre[r1][c2 + 1]
                          - pre[r2 + 1][c1] + pre[r1][c1];
            }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def matrixBlockSum(self, mat: List[List[int]], k: int) -> List[List[int]]:
        m, n = len(mat), len(mat[0])
        pre = [[0] * (n + 1) for _ in range(m + 1)]
        for i in range(m):
            row_pre, row_prev = pre[i + 1], pre[i]
            for j in range(n):
                row_pre[j + 1] = mat[i][j] + row_prev[j + 1] + row_pre[j] - row_prev[j]

        ans = [[0] * n for _ in range(m)]
        for i in range(m):
            r1, r2 = max(i - k, 0), min(i + k, m - 1)
            for j in range(n):
                c1, c2 = max(j - k, 0), min(j + k, n - 1)
                ans[i][j] = (pre[r2 + 1][c2 + 1] - pre[r1][c2 + 1]
                             - pre[r2 + 1][c1] + pre[r1][c1])
        return ans
```

> 💡 两份代码均通过官方示例（$k=1$ 的 9 个值、$k=2$ 的全 45）与边界（$1\times1$ 矩阵 $k=0$、$k=100$ 全覆盖），并与「四重循环直接求窗口和」的暴力对拍 3000 组（C++）/ 2000 组（Python）随机矩阵（含负元素、$m \ne n$、$k$ 远超尺寸），`mismatch = 0`。

## 8. 边界情况与易错点

1. **`+1` 换算错**：查询公式的四个下标里**右端两个**（$r_2+1$、$c_2+1$）要加一，**左端两个**（$r_1$、$c_1$）不加。四项全加或全不加都会系统性地偏一行/列。
2. **只裁一边窗口**：`max(i-k, 0)` 与 `min(i+k, m-1)` 必须成对；角格处只做 `min` 不做 `max` 会得到负下标（C++ 越界、Python 负索引静默取末尾——更隐蔽！Python 的负索引不报错但取到对侧元素，错误结果难以察觉）。
3. **$k \ge \max(m, n)$**：无需特判，裁剪自动退化为整矩阵；但别把 `k` 当成窗口边长（边长是 $2k+1$）。
4. **非方阵**：行用 $m-1$、列用 $n-1$ 裁剪；复制粘贴示例代码时容易把两个上界写混。
5. **`pre` 尺寸 $(m+1) \times (n+1)$**：开成 $m \times n$ 会在 $r_2 = m - 1$ 时越界访问 `pre[m][...]`。
6. **Python 负索引的静默错误**：如上所述，`pre[r1]` 若 `r1` 为负不会抛异常而是取到倒数第几行——对拍时务必覆盖负值不可能出现的情形（本算法 `max(..., 0)` 保证非负，写对即安全）。
7. **原地覆盖 `mat` 的诱惑**：把 `pre` 建在 `mat` 上（令 `mat[i][j]` 逐步变成前缀和）可省一个矩阵，但查询时原值已丢失——本题查询只用 `pre`，可行但可读性差，不建议。
