# LeetCode 祖父节点值为偶数的节点和 题解

## 1. 题目概述

- **标题 / 题号**：祖父节点值为偶数的节点和（#1315，medium）
- **链接**：https://leetcode.cn/problems/sum-of-nodes-with-even-valued-grandparent/
- **来源**：LeetCode 第 17 场双周赛 Q3
- **难度**：中等
- **标签**：树、深度优先搜索、广度优先搜索、二叉树

**题意**：给定二叉树根节点 `root`，返回所有「祖父节点值为偶数」的节点值之和。祖父节点指父节点的父节点；不存在祖父（深度 $< 2$）或祖父值为奇数的节点不计入。不存在任何满足条件的节点时返回 0。

**约束**：

- 树中节点数目在 $[1, 10^4]$ 之间
- $1 \le Node.val \le 100$

## 2. 示例

**示例 1**

```text
输入：root = [6,7,8,2,7,1,3,9,null,1,4,null,null,null,5]
输出：18
解释：祖父为偶数的节点是 2、7、1、3（祖父均为根 6）与 5（祖父 8），
     和为 2+7+1+3+5 = 18。结构细节见 §3.4。
```

**示例 2**

```text
输入：root = [1]
输出：0
解释：单节点无祖父。
```

## 3. 解题思路

### 3.1 暴力思路

对每个节点 $v$，向上走两步找祖父、判断偶数、累加。但**指针树的节点没有父指针**——要么先做一遍 DFS 给每个节点挂上「父/祖父」信息（等价于下面的做法），要么按层序数组的下标关系换算（见 3.3 备选）。朴素地「每个节点独立向上找」在指针树上不可直接实现。

### 3.2 核心观察：DFS 自顶向下，把 (parentVal, grandVal) 一路下传

![三代链与递归参数](images/bw17_q3_grandparent_chain.svg)

判断「我是否计入」只依赖**祖父的值**。DFS 从根出发，每递归一层就把参数滚动一格：

$$dfs(node,\ parentVal,\ grandVal) \to dfs(child,\ node.val,\ parentVal)$$

——「我的父值」变成「孩子的父值」，「我的祖父值」变成「孩子的祖父值」，恰好滚动三代窗口。节点 $v$ 被计入当且仅当它的 $grandVal$（即「父的父值」）为偶数。**不存在的祖先用奇数 1 当哨兵**：深度不足的节点其祖父参数是哨兵，永不触发偶数判断，天然排除。

### 3.3 算法流程（含数组下标备选）

```text
dfs(node, parentVal, grandVal):
    若 node 为空：返回 0
    add = (grandVal 为偶数) ? node.val : 0
    返回 add + dfs(node.left,  node.val, parentVal)
             + dfs(node.right, node.val, parentVal)

主调用：dfs(root, 1, 1)        # 哨兵 1：根与其孩子不可能有祖父
```

> 💡 若输入是**层序数组**（含 `null` 占位、按完全二叉树下标存放），则无需传参：$parent(i) = (i-1)/2$，$grand(i) = ((i-1)/2 - 1)/2$，直接按数组下标 $i \ge 3$ 判断 $arr[grand(i)]$ 的奇偶即可。**LeetCode 接口给的是指针树**，该做法仅在拿到原始数组时可用（见下图与 §8 第 5 点）。

![数组下标关系与适用边界](images/bw17_q3_array_index_model.svg)

### 3.4 示例演算

按层序数组 `[6,7,8,2,7,1,3,9,null,1,4,null,null,null,5]` 建树后的**真实结构**：

```text
6
├─ 7
│  ├─ 2
│  │  └─ 9        （2 的左孩子）
│  └─ 7
│     ├─ 1
│     └─ 4
└─ 8
   ├─ 1
   └─ 3
      └─ 5        （3 的右孩子）
```

逐一列出「有祖父的节点」及其祖父值：

| 节点 | 父 | 祖父 | 祖父为偶？ | 计入 |
|------|----|------|-----------|------|
| 2 | 7 | 6 | ✓ | 2 |
| 7 | 7 | 6 | ✓ | 7 |
| 1 | 8 | 6 | ✓ | 1 |
| 3 | 8 | 6 | ✓ | 3 |
| 9 | 2 | 7 | ✗ | — |
| 1 | 7 | 7 | ✗ | — |
| 4 | 7 | 7 | ✗ | — |
| 5 | 3 | 8 | ✓ | 5 |

合计 $2+7+1+3+5 = 18$。✓

> ⚠️ **易错提醒**：若按「第 3 层 = 层序数组下标 7..14」去数祖父，很容易把 9、1、4 的祖父认错——`null` 占位使「下标连续」与「真实兄弟关系」脱钩。**必须按建树后的真实父子链判断**，这是本示例最经典的陷阱（详见 §8 第 5 点）。

## 4. 算法细节

1. **哨兵值选奇数**：初始调用 `dfs(root, 1, 1)`。约束 $val \ge 1$，取 1（奇）保证「无父/无祖父」永不触发偶数判断；用 0 也行（0 是偶数！会误判根的孩子），**0 是陷阱，1 是安全值**。
2. **参数滚动方向**：孩子的 `grandVal` = 我的 `parentVal`、孩子的 `parentVal` = 我的 `node.val`。写反会把「父值」当「祖父值」判断。
3. **不修改树结构**：传值（而非挂父指针）保证 $O(h)$ 栈空间之外零额外内存、也绝无污染输入树的风险。
4. **BFS 版本等价**：队列元素存 `(node, parentVal, grandVal)` 三元组，逐层弹出累加——与 DFS 同构，仅遍历顺序不同；层序遍历还能顺带利用「同层节点祖父相同」的事实，但无性能差别。
5. **`n = 10^4` 链状树**：DFS 递归深 $10^4$，C++ 默认栈安全（每帧很小），Python 需 `sys.setrecursionlimit(20000)` 或改 BFS。
6. **和的范围**：$\le 10^4 \times 100 = 10^6$，`int` 充足。

## 5. 正确性证明

**引理 1（三代窗口滚动）**：设 $\mathrm{par}(v)$、$\mathrm{gran}(v)$ 分别为 $v$ 的父、祖父（不存在则为哨兵 $\bot = 1$）。DFS 调用 $dfs(v, p, g)$ 满足不变式：$p = \mathrm{par}(v)$ 的值（或 $\bot$），$g = \mathrm{gran}(v)$ 的值（或 $\bot$）。

**证明**：对调用链归纳。主调用 $dfs(root, \bot, \bot)$：根无父无祖父，成立。设 $dfs(v, p, g)$ 满足不变式且 $u$ 是 $v$ 的孩子；算法递归调用 $dfs(u, v.val, p)$。此时 $\mathrm{par}(u) = v$，其值恰为 $v.val$，即新参数 $p' = v.val$ 正确；$\mathrm{gran}(u) = \mathrm{par}(v)$，其值 $= p$（归纳假设），即新参数 $g' = p$ 正确；$v$ 无父时 $p = \bot$，$u$ 的祖父不存在，$g' = \bot$ 亦正确。∎

**引理 2（哨兵安全性）**：哨兵 $1$ 为奇数，故任何「祖父不存在」的节点不会被计入。

**证明**：计入条件为 $g \bmod 2 = 0$；哨兵 $1 \bmod 2 = 1$，条件为假。∎

**定理**：算法返回 $\sum \{v.val : \mathrm{gran}(v) \text{ 存在且值为偶数}\}$。

**证明**：DFS 遍历每个节点恰好一次。对节点 $v$，由引理 1 其调用参数 $g$ 恰为祖父值（或 $\bot$），由引理 2 后者必不触发；前者为偶数时累加 $v.val$，为奇数时不加。求和项与题意逐点吻合。∎

## 6. 复杂度分析

- **时间**：$O(n)$。每节点一次访问、常数判断与两次递归调用；$n = 10^4$ 毫秒级。
- **空间**：$O(h)$ 递归栈（$h$ 为树高），最坏链状 $O(n) = 10^4$；平衡时 $O(\log n)$。BFS 版本为 $O(w)$（最大层宽）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int sumEvenGrandparent(TreeNode* root) {
        // DFS 自顶向下，把「父值、祖父值」一路下传；
        // 1 起到"奇数哨兵"的作用：不存在的祖先视为奇数，永不会被计入
        return dfs(root, 1, 1);
    }
private:
    int dfs(TreeNode* node, int parentVal, int grandVal) {
        if (!node) return 0;
        int add = (grandVal % 2 == 0) ? node->val : 0;   // 祖父值为偶数才计入
        return add + dfs(node->left, node->val, parentVal)
                    + dfs(node->right, node->val, parentVal);
    }
};
```

### Python

```python
class Solution:
    def sumEvenGrandparent(self, root: Optional[TreeNode]) -> int:
        def dfs(node: Optional[TreeNode], parent_val: int, grand_val: int) -> int:
            if node is None:
                return 0
            add = node.val if grand_val % 2 == 0 else 0
            return (add
                    + dfs(node.left, node.val, parent_val)
                    + dfs(node.right, node.val, parent_val))
        # 不存在的祖先视为奇数（1 作哨兵），保证不被计入
        return dfs(root, 1, 1)
```

> 💡 两份代码均通过官方示例（`[6,7,8,2,7,1,3,9,null,1,4,null,null,null,5]` → `18`、`[1]` → `0`），并与「BFS 携带 (node, parent, grandparent) 指针三元组」的独立参考实现随机对拍 3000 组（C++）/ 2000 组（Python）随机形状树（节点 $\le 60$，值 $\le 100$），`mismatch = 0`。

## 8. 边界情况与易错点

1. **哨兵别用 0**：0 是偶数！`dfs(root, 0, 0)` 会让根与第一层被误判「祖父为偶」而多算。必须用奇数（1 即可）。
2. **参数滚动别写反**：孩子调用是 `dfs(child, node.val, parentVal)`——「祖父参数」接收的是**当前层的父值**，不是当前层自己的值。
3. **判断的是祖父不是父**：`grandVal % 2 == 0` 判偶的对象是 `grandVal`；误用 `parentVal` 会把条件放宽一代。
4. **单节点 / 两层树**：所有节点祖父皆哨兵，返回 0，无需特判。
5. **层序下标法的适用边界**：`grand(i) = ((i-1)/2 - 1)/2` 仅当数组是**含 null 占位的完全层序**且你手里真有这个数组时才对；接口给指针树时别想着「下标换算」，且注意稀疏层序里 `null` 的孩子不占真实节点（占位会错位——示例 1 的走查陷阱即源于此）。
6. **Python 递归深度**：链状 $10^4$ 深度超出默认限制，BFS 或调 `recursionlimit` 二选一。
7. **不必真的建父指针**：给每个节点挂 `parent` 指针再向上找两步也能做，但既改结构又慢（两次遍历），传参版一遍搞定。
