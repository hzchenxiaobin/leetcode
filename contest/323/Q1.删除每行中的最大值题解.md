# LeetCode 删除每行中的最大值 题解

## 1. 题目概述

- **标题 / 题号**：删除每行中的最大值（#2500，easy）
- **链接**：https://leetcode.cn/problems/delete-greatest-value-in-each-row/
- **来源**：LeetCode 第 323 场周赛 Q1
- **难度**：简单
- **标签**：数组、矩阵、排序、模拟

**题意**：给定 $m \times n$ 的正整数矩阵 `grid`，重复执行下述操作直到矩阵为空：每一行删除该行的最大元素（若并列最大，删任一个均可），然后把**本轮删除元素中的最大值**累加进答案。返回最终答案。

**约束**：

- `m == grid.length`，`n == grid[i].length`
- $1 \le m, n \le 50$
- $1 \le \text{grid}[i][j] \le 100$

## 2. 示例

**示例 1**

```text
输入：grid = [[1,2,4],[3,3,1]]
输出：8
解释：
- 第 1 轮：第 1 行删 4，第 2 行删 3（两个 3 任删其一），本轮 max = 4，ans = 4
- 第 2 轮：第 1 行删 2，第 2 行删 3，本轮 max = 3，ans = 7
- 第 3 轮：第 1 行删 1，第 2 行删 1，本轮 max = 1，ans = 8
```

**示例 2**

```text
输入：grid = [[10]]
输出：10
解释：仅一轮，删 10，ans = 10。
```

## 3. 解题思路

### 3.1 暴力思路：逐轮模拟

忠实模拟：矩阵非空时共执行 $n$ 轮，每轮对 $m$ 行各自扫一遍找出当前最大并删除（置标记或交换到行尾），再对 $m$ 个删除值取 max 累加。每轮 $O(mn)$，总计 $O(mn^2)$；在 $m,n \le 50$ 时约 $1.25 \times 10^5$ 次操作，**能过**。

> ⚠️ 暴力的问题不在复杂度而在**实现负担**：要维护每行剩余元素的结构、处理并列最大时任删其一、再对每轮删除值求跨行 max——逻辑分支多，签到题容易在这里浪费时间和写错。更亏的是它浪费了问题本身的可塌缩结构。

### 3.2 核心观察：每行删最大 ⇔ 排序后按列取最大

![核心观察：每行删最大等价于排序后逐列取最大](images/delmax_sort_columns.svg)

**关键不变量**：对任意一行，每轮删的都是「当前剩余中的最大」，所以该行各轮删掉的值按轮次连起来**恰好是该行元素的降序排列**。并列时任删哪个格子，删掉的**值**都相同——选择自由度不影响值序列。

于是把每行升序排序后：

- 第 $t$ 轮从第 $i$ 行删除的值 = 排序后的 $\text{grid}[i][n-t]$（第 $t$ 大在倒数第 $t$ 列）；
- 第 $t$ 轮的删除集合就是排序后矩阵的**一整列**，本轮贡献 = 该列的列最大值。

$$
\text{ans} = \sum_{j=0}^{n-1} \max_{0 \le i < m} \text{grid}[i][j] \quad (\text{每行已升序排序})
$$

$O(mn^2)$ 的逐轮模拟塌缩为 $O(mn \log n)$，且代码只剩「排序 + 列最大求和」两步，没有任何删除细节。

### 3.3 算法流程

1. 对每一行**就地升序排序**；
2. 遍历每一列 $j$，取该列 $m$ 个元素的最大值；
3. 将列最大值累加进答案，处理完所有列即得结果。

### 3.4 示例演算

![三轮删除演算：4+3+1=8](images/delmax_round_simulation.svg)

`grid = [[1,2,4],[3,3,1]]` 的逐轮过程：

| 轮次 | 第 1 行删 | 第 2 行删 | 本轮 max | ans |
|------|-----------|-----------|----------|-----|
| 1 | 4 | 3 | 4 | 4 |
| 2 | 2 | 3 | 3 | 7 |
| 3 | 1 | 1 | 1 | 8 |

排序后两行为 `[1,2,4]` 与 `[1,3,3]`，三列的列最大值分别为 $1$、$3$、$4$，求和 $1+3+4=8$，与逐轮模拟结果一致。✓

## 4. 算法细节

1. **就地排序**：直接对 `grid` 的每行 `sort`，不建新矩阵（LeetCode 允许修改输入）。
2. **列最大值**：C++ 用外层 `j`、内层 `i` 的双层循环；Python 用 `zip(*grid)` 把行转成列，`max(col)` 即列最大。
3. **数据结构选择**：不用堆。堆做法（每行一个小顶堆，弹出 $n$ 次）复杂度同为 $O(mn\log n)$ 但代码更长；值域 $1 \sim 100$ 也可用计数排序做到 $O(mn + 100)$，在本题规模下没有必要。
4. **答案上界**：$50 \times 50 \times 100 = 250000$，`int` 足够。

## 5. 正确性证明

**引理 1**：无论并列时删哪个格子，第 $i$ 行在第 $t$ 轮被删除的值是唯一确定的，等于该行第 $t$ 大的元素。

**证明**：对 $t$ 归纳。$t=1$ 时删当前最大值，即第 1 大。设前 $t-1$ 轮删掉了该行前 $t-1$ 大的值——并列时任删其一不改变剩余元素的**值多重集**——则第 $t$ 轮删的是剩余元素的最大值，即原行的第 $t$ 大。∎

**定理**：将每行升序排序后，$\text{ans} = \sum_{j=0}^{n-1} \max_{0 \le i < m} \text{grid}[i][j]$。

**证明**：由引理 1，第 $t$ 轮的删除集合为 $\{\text{grid}[i][n-t] : 0 \le i < m\}$（排序后第 $t$ 大位于下标 $n-t$），本轮累加 $\max_i \text{grid}[i][n-t]$。令 $j = n-t$，当 $t$ 取遍 $1..n$ 时 $j$ 恰好取遍 $n-1..0$，故

$$
\text{ans} = \sum_{t=1}^{n} \max_i \text{grid}[i][n-t] = \sum_{j=0}^{n-1} \max_i \text{grid}[i][j]. \; \blacksquare
$$

## 6. 复杂度分析

- **时间复杂度**：$O(mn\log n)$。排序 $m$ 行各 $O(n\log n)$ 共 $O(mn\log n)$，逐列取最大 $O(mn)$，后者被前者吸收。
- **空间复杂度**：$O(1)$ 额外空间（就地排序；Python 的 `zip(*grid)` 会生成 $O(mn)$ 的转置，若严格计较可改写下标双层循环）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int deleteGreatestValue(vector<vector<int>>& grid) {
        for (auto& row : grid) {
            sort(row.begin(), row.end());
        }
        int m = grid.size(), n = grid[0].size();
        int ans = 0;
        for (int j = 0; j < n; j++) {
            int mx = grid[0][j];
            for (int i = 1; i < m; i++) {
                mx = max(mx, grid[i][j]);
            }
            ans += mx;
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def deleteGreatestValue(self, grid: List[List[int]]) -> int:
        for row in grid:
            row.sort()
        return sum(max(col) for col in zip(*grid))
```

## 8. 边界情况与易错点

1. **并列最大**：题面允许任删其一——由引理 1，删哪个不影响每轮删除的「值集合」，排序做法天然规避该分支；直接模拟时若手工挑格子反而易错。
2. **单行矩阵（$m=1$）**：每轮只有一行，答案 = 该行所有元素之和（排序后逐列 max 就是元素自身）。
3. **单列矩阵（$n=1$）**：仅执行一轮，答案 = 全矩阵最大值（各行唯一元素取 max）。
4. **直接模拟的删除标记**：若用「置 0 / 置 -1」标记已删元素，因值域 $\ge 1$ 可行，但每轮找最大时必须跳过已标记位，漏跳会重复计数。
5. **溢出**：答案上界 $250000$，`int` 安全，无需 `long long`。
