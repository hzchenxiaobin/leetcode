# LeetCode 数组中最长的方波 题解

## 1. 题目概述

- **标题 / 题号**：数组中最长的方波（#2501，medium）
- **链接**：https://leetcode.cn/problems/longest-square-streak-in-an-array/
- **来源**：LeetCode 第 323 场周赛 Q2
- **难度**：中等
- **标签**：数组、哈希表、动态规划、排序

**题意**：给定整数数组 `nums`。若某个子序列在**从小到大排序后**，除首元素外每个元素都是前一个元素的**平方**，且长度至少为 $2$，则称之为**方波**。返回 `nums` 中最长方波的长度；若不存在方波则返回 $-1$。

**约束**：

- $2 \le \text{nums.length} \le 10^5$
- $2 \le \text{nums[i]} \le 10^5$

> 💡 本题在本仓库另有[每日题解 2501](../../solution/2501-2600/2501_数组中最长的方波.md)：以「与 128 最长连续序列同构」为主线，主推值域数组 + 逆序 DP 的 $O(n)$ 写法并附面试问答。本篇按周赛复盘视角展开，侧重**赛时从信号到代码的最短路径**（「子序列排序后判定」→ 顺序无关 → 值集合链 DP）、**降序扫描免开方**的实现技巧，以及**引理-定理式证明与溢出、$-1$ 判定等边界复盘**，两篇互为印证。

## 2. 示例

**示例 1**

```text
输入：nums = [4, 3, 6, 16, 8, 2]
输出：3
解释：选出子序列 [4, 16, 2]，排序后得到 [2, 4, 16]：
      4 = 2²，16 = 4²，是长度为 3 的方波；
      可以证明不存在长度为 4 的方波。
```

**示例 2**

```text
输入：nums = [2, 3, 5, 6, 7]
输出：-1
解释：任何两个元素都不满足平方关系，不存在方波。
```

**补充示例 3**

```text
输入：nums = [65536, 2, 16, 4, 256, 3]
输出：5
解释：链 2 → 4 → 16 → 256 → 65536，长度 5。
      这正是本题值域下链长的上界：65536² ≈ 4.3 × 10⁹ 已出界。
```

## 3. 解题思路

### 3.1 暴力思路：枚举子序列

最直白的做法是枚举 `nums` 的所有子序列（$2^n$ 个），逐一排序验证。$n = 10^5$ 时这是天文数字，不可行。

> ⚠️ 暴力的根因是把「子序列」当成**组合选择**问题。但题面白纸黑字写着「将子序列**从小到大排序之后**……」——判定只看排序后的值序列，与元素在 `nums` 中的**原始下标顺序无关**；又因链严格递增（$v \ge 2 \Rightarrow v^2 > v$），重复元素在链中也至多占一位。意识到这一点，问题立刻从「$2^n$ 组合搜索」塌缩为「**去重值集合上找最长链**」——这是 128 最长连续序列家族的经典信号：子序列 + 排序后相邻关系 = 值集合上的链结构。

### 3.2 核心观察：后继唯一 → 平方链森林

![平方关系把值集合织成链森林](images/sqstreak_chain_forest.svg)

把 `nums` 去重成值集合 $S$，在 $S$ 上连有向边 $v \to v^2$（若 $v^2 \in S$）。三个层层递进的观察：

1. **顺序无关**：方波 ⟺ 排序后成平方链 ⟺ 选出的值构成 $\{x, x^2, x^4, \ldots\}$——只依赖**哪些值出现过**，不依赖顺序与重复次数。
2. **后继唯一**：$v$ 在链中的下一位被唯一确定为 $v^2$，不存在分叉。链一旦起点确定就**整条确定**，「跟着 $v^2$ 走」即可，无需在组合空间搜索——这把指数问题压成线性。
3. **无环链森林**：$v \ge 2 \Rightarrow v^2 > v$，边只指向更大的值，不可能成环；又每个节点至多一个后继（$v^2$）、至多一个前驱（$\sqrt{v}$），故整张图是**若干条互不相交的链**。最长方波 = 最长链。

> 💡 **值域 $10^5$ 是甜区**：从最小起点 $v=2$ 出发，链为 $2 \to 4 \to 16 \to 256 \to 65536$，再平方就出界（$65536^2 \approx 4.3 \times 10^9$），**链长上界仅 5**。这既保证任何「跟随」写法都极快，也让值域数组成为可选优化（见每日题解版）。

### 3.3 算法流程：降序扫描 + 一趟 DP

![降序扫描的算法流程](images/sqstreak_desc_dp_flow.svg)

定义 $dp[v]$ = 以 $v$ 为起点、沿平方关系**向后**延伸的链长。状态转移：

$$
dp[v] = \begin{cases} 1 + dp[v^2] & \text{若 } v^2 \in S \\ 1 & \text{否则（链在 } v \text{ 处断裂）} \end{cases}
$$

**为什么降序遍历**：转移只依赖**更大的** $v^2$。从大到小处理时，$v^2$ 必已算好——这是**反向拓扑序**，一趟填充即可，无递归、无记忆化。更妙的是全程**不判断「$v$ 是不是完全平方数」**：我们只查 $v^2$ 在不在，而不是问 $\sqrt{v}$ 是谁，天然绕开浮点 `sqrt` 在完全平方数附近差一的精度陷阱。

流程：

1. `nums` 去重入集合；
2. 按值**从大到小**遍历每个 $v$；
3. $dp[v] = 1 + dp[v^2]$（$v^2 \notin S$ 则后项取 $0$）；
4. $\text{ans} = \max(\text{ans},\ dp[v])$；
5. 返回 $\text{ans} \ge 2$ ? $\text{ans}$ : $-1$。

**哈希表即判定器**：降序处理时，`dp` 的键集恰好是「已处理的（$\ge$ 当前 $v$ 的）出现过的值」。因 $v^2 > v$，故 $v^2 \in S \iff v^2 \in dp$——一次哈希查询同时完成「存在性判定」与「取后继链长」。

### 3.4 示例演算

![示例一降序填表演算](images/sqstreak_walkthrough.svg)

以示例 1 `nums = [4,3,6,16,8,2]` 演算（$S = \{2,3,4,6,8,16\}$，降序处理）：

| $v$ | $v^2$ | $v^2 \in S$? | $dp[v]$ | ans |
|-----|-------|--------------|---------|-----|
| 16 | 256 | ✗ | $1$ | $1$ |
| 8 | 64 | ✗ | $1$ | $1$ |
| 6 | 36 | ✗ | $1$ | $1$ |
| 4 | 16 | ✓ | $1 + dp[16] = 2$ | $2$ |
| 3 | 9 | ✗ | $1$ | $2$ |
| 2 | 4 | ✓ | $1 + dp[4] = 3$ | $3$ |

$\text{ans} = 3 \ge 2$ → 返回 `3`。示例 2 中所有 $v^2$ 都不在 $S$，$dp$ 全为 $1$，$\text{ans} = 1 < 2$ → 返回 `-1`。

## 4. 算法细节

1. **排序方向是正确性的一部分**：必须**降序**。升序处理 $v$ 时 $dp[v^2]$ 尚未计算，得补记忆化递归或改判前驱 $\sqrt{v}$（引入开方）。
2. **C++ 溢出**：$v$ 最大 $10^5$，$v^2 = 10^{10}$ 超出 32 位 `int`（约 $2.1 \times 10^9$），必须 `1LL * v * v`；也可先判 $v \le 316$（$317^2 > 10^5$）再相乘。
3. **去重与否都正确**：重复值只是把同一个 $dp[v]$ 原样重算一遍，结果不变；去重可少做几次哈希，更干净。
4. **无需显式找链头**：非链头的 $dp[v]$ 只是某条链的后缀长度，不会超过该链全长，`max` 全体仍取到链头处的整链长。128 必须靠「只从真起点走」保线性（链可长达 $n$），本题链长 $\le 5$，DP 版每个值只算一次，天然线性。
5. **与值域数组版的对比**：值域 $\le 10^5$ 可开 `has`/`dp` 定长数组，整体 $O(n + V)$（每日题解主推）；赛时哈希 + 排序版 $O(n \log n)$ 足够过题，且不依赖值域假设，值域放宽时仍可用。

## 5. 正确性证明

**引理 1（顺序与重复无关）**：`nums` 存在长度 $\ge 2$ 的方波 $\iff$ 去重值集合 $S$ 中存在长度 $\ge 2$ 的平方链 $x, x^2, x^4, \ldots$。

**证明**：(⟸) 设链 $a_1, \ldots, a_k$（$k \ge 2$，$a_{i+1} = a_i^2$）各值都在 $S$ 中出现，各取一次出现按下标任意排成子序列，其排序结果即 $a_1, \ldots, a_k$，满足方波定义。(⟹) 方波排序后为 $b_1, \ldots, b_k$ 且 $b_{i+1} = b_i^2$；由 $b_i \ge 2$ 得 $b_i^2 > b_i$，链严格递增、各元素互异，这些互异值构成 $S$ 中一条长度 $k$ 的平方链。∎

**引理 2（链森林结构）**：在 $S$ 上连边 $v \to v^2$（若 $v^2 \in S$），则每个节点出度 $\le 1$、入度 $\le 1$，且无环。

**证明**：出度唯一显然（后继只能是 $v^2$）。入度：若 $w^2 = u$，由正整数上平方映射的单射性 $w$ 唯一（且需 $u$ 为完全平方数），故 $u$ 的前驱至多一个。无环：沿任意边走值严格增大（$v \ge 2 \Rightarrow v^2 > v$），有限集合中不可能回到起点。故该图是不相交链的并。∎

**定理**：降序扫描算法返回的 `ans` 等于 $S$ 中最长平方链的长度；无长度 $\ge 2$ 的链时返回 $-1$。

**证明**：沿降序处理顺序强归纳：处理 $v$ 时，一切 $> v$ 的值均已处理完毕且由归纳假设其 `dp` 值等于从该值出发的唯一链长。由后继唯一性，从 $v$ 出发的链 = $v$ 接上从 $v^2$ 出发的链（若 $v^2 \in S$），故转移 $dp[v] = 1 + dp[v^2]$（或 $1$）恰好算出该唯一链长；$v^2 \in S \iff v^2 \in dp$（算法细节第 5 点之前的论证），查询合法。于是 $\text{ans} = \max_v dp[v]$：任一长度 $\ge 2$ 的方波对应一条链，其链头处的 `dp` 即全长，故 `ans` 达到最长链长；反之达到 `max` 的 $v$ 给出一条实链。由引理 1，最长链长即最长方波长度；所有 $dp[v] = 1 \iff$ 无长度 $\ge 2$ 的链 $\iff$ 返回 $-1$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \log n)$——排序主导；去重后每个值做 $O(1)$ 次哈希查询与转移。换值域数组（`has`/`dp` 定长表 + 值域倒序扫）可降到 $O(n + V)$，$V = 10^5$。
- **空间复杂度**：$O(n)$——哈希表存放去重值与 `dp`；值域数组版为 $O(V)$，约 0.5 MB。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int longestSquareStreak(vector<int>& nums) {
        sort(nums.begin(), nums.end(), greater<int>());   // 降序：处理 v 时 v² 已算好
        unordered_map<long long, int> dp;
        int ans = 0;
        for (int v : nums) {
            long long nxt = 1LL * v * v;                  // 防 32 位溢出
            int len = 1;
            if (dp.count(nxt)) len += dp[nxt];            // v² ∈ S ⟺ 已入 dp
            dp[v] = len;
            ans = max(ans, len);
        }
        return ans >= 2 ? ans : -1;
    }
};
```

### Python

```python
class Solution:
    def longestSquareStreak(self, nums: List[int]) -> int:
        dp = {}
        ans = 0
        for v in sorted(set(nums), reverse=True):  # 去重 + 降序
            dp[v] = 1 + dp.get(v * v, 0)           # v² 不在集合 → 取 0
            ans = max(ans, dp[v])
        return ans if ans >= 2 else -1
```

## 8. 边界情况与易错点

1. **C++ 溢出**：`v * v` 直接用 `int` 计算，$10^5$ 平方 $= 10^{10}$ 溢出为未定义行为；写 `1LL * v * v` 或先判 `v <= 316`。
2. **$-1$ 判据是 `ans < 2` 而非 `ans == 0`**：单元素链的 $dp$ 恒为 $1$，`ans` 最小也是 $1$；「不存在方波」意味着所有链长为 $1$。
3. **浮点开方陷阱**：若改走「升序 + 查 $\sqrt{v}$ 是否出现过」，`(int)sqrt(v)` 在完全平方数附近可能差一，需 `math.isqrt`（Python）或平方回验；降序版只查 $v^2$，完全不碰开方。
4. **重复元素**：链严格递增，重复值不能在链中占两位（如 `[2,2]` 排序后 $2 \ne 2^2$，不是方波）；去重与否答案一致。
5. **值域含 1 的假想陷阱**：若允许 $v = 1$ 则 $1^2 = 1$ 出现自环，`[1,1]` 是合法方波（$1 = 1^2$），链长应按 $1$ 的出现次数计——本题约束 $\text{nums[i]} \ge 2$ 恰好封死该分支，复用代码到改题面时需警惕。
6. **答案上界**：链长 $\le 5$（$2 \to 4 \to 16 \to 256 \to 65536$），返回值用 `int` 无溢出风险。
