# LeetCode 将数组划分成相等数对 题解

## 1. 题目概述

- **标题 / 题号**：将数组划分成相等数对（#2206，easy）
- **链接**：https://leetcode.cn/problems/divide-array-into-equal-pairs/
- **来源**：LeetCode 第 74 场双周赛 Q1
- **难度**：简单
- **标签**：位运算、数组、哈希表、计数

**题意**：给定包含 $2n$ 个整数的数组 `nums`，判断能否把它划分成 $n$ 个数对，使得每个元素恰好属于一个数对，且**同一数对内的两个元素相等**。

**约束**：

- `nums.length == 2 * n`
- $1 \le n \le 500$
- $1 \le nums[i] \le 500$

## 2. 示例

**示例 1**

```text
输入：nums = [3,2,3,2,2,2]
输出：true
解释：6 个元素划分成 3 对：(2,2)、(3,3)、(2,2)，每对内两数相等。
```

**示例 2**

```text
输入：nums = [1,2,3,4]
输出：false
解释：4 个元素要划分成 2 对，但任何两个元素都不相等，无法满足要求。
```

**示例 3（边界补充：全部相同）**

```text
输入：nums = [7,7,7,7,7,7]
输出：true
解释：6 个 7 两两配对成 3 个 (7,7)。
```

## 3. 解题思路

### 3.1 暴力思路

直接模拟配对：每次取还没配对的第一个元素 $x$，在剩余元素里找一个等于 $x$ 的元素配成一对，找不到就返回 `false`。最坏每次线性查找，时间 $O(n^2)$；$n = 500$ 时约 $2.5\times10^5$ 次操作，能过但完全没有必要——配对的结构其实只取决于「每个值出现次数的奇偶性」。

### 3.2 核心观察：能两两配对 ⇔ 每个值的出现次数都是偶数

![核心观察：按值分桶，每个桶的计数必须是偶数](images/bw74_q1_count_parity_concept.svg)

数对只能由**相等的两个数**组成，所以配对完全发生在「同一个值的内部」：值 $v$ 的出现次数是 $c_v$，它最多贡献 $\lfloor c_v / 2 \rfloor$ 对；要让全部 $2n$ 个元素入对，必须每个 $c_v$ 都是偶数。反过来，若所有 $c_v$ 均为偶数，把每个值的元素两两相邻配对即可得到 $n$ 对。于是问题化为**逐值判奇偶**：值域 $1 \sim 500$，开一个长度 501 的计数数组扫一遍即可。

### 3.3 算法流程

```text
1. cnt[1..500] 清零
2. for x in nums：cnt[x] += 1
3. 若存在 v 使 cnt[v] 为奇数，返回 false；否则返回 true
```

### 3.4 示例演算

![示例演算：[3,2,3,2,2,2] 的计数与配对](images/bw74_q1_example_walkthrough.svg)

以示例 1（`nums = [3,2,3,2,2,2]`）为例：

| 值 $v$ | 计数 $c_v$ | 奇偶 | 可配对数 |
|--------|-----------|------|----------|
| 2 | 4 | 偶 | 2 |
| 3 | 2 | 偶 | 1 |

所有计数均为偶数，配对数 $2 + 1 = 3 = n$，返回 `true`。示例 2 中四个值计数全为 1（奇），立刻返回 `false`。

## 4. 算法细节

1. **值域数组**：$1 \le nums[i] \le 500$，`cnt` 开 501 长度（下标 0 弃用）即可，一次线性扫描加一次值域扫描，$O(n + V)$。
2. **判奇偶的时机**：可以先数完再统一检查，也可以边数边用「奇偶翻转」技巧：`cnt[x] ^= 1`，最后看是否全 0——等价于只用一个比特存奇偶性，这正是「位运算」标签的来历（值域小的时候可用 64 位整数按位存全部奇偶）。
3. **提前返回**：计数阶段不必提前退出（总长是偶数不能保证逐值偶数）；检查阶段遇到第一个奇数即可返回 `false`。
4. **总长为偶数没用**：`2n` 已由输入保证，它不提供任何「可划分」的信息——可划分性完全由逐值计数的奇偶决定，与整体长度、总和无关。
5. **哈希表替代**：若值域不是 $1\sim500$ 而是任意整数，改用 `unordered_map`/`Counter`，逻辑不变，复杂度 $O(n)$。

## 5. 正确性证明

**引理 1（必要性）**：若 `nums` 能划分成 $n$ 个相等数对，则每个值的出现次数为偶数。

**证明**：每个数对由两个相等的值构成，故每个数对给某个值 $v$ 贡献恰好 2 次出现。各数对互不相交且覆盖全部元素，值 $v$ 的出现次数 $c_v = 2 \times (\text{包含 } v \text{ 的数对个数})$，必为偶数。∎

**引理 2（充分性）**：若每个值的出现次数均为偶数，则可以划分成 $n$ 个相等数对。

**证明**：对每个值 $v$，把它的 $c_v$ 次出现按出现顺序两两相邻分组，得到 $c_v / 2$ 个数对；不同值的数对互不相同。总对数 $\sum_v c_v / 2 = (2n)/2 = n$，且每个元素恰属于一对、对内两数相等，构成合法划分。∎

**定理**：算法返回 `true` 当且仅当 `nums` 可以划分成 $n$ 个相等数对。

**证明**：算法检查的恰是「所有 $c_v$ 为偶数」。由引理 1，合法划分蕴含该条件（此时算法返回 `true` 正确）；由引理 2，该条件蕴含合法划分（此时不存在划分的话算法返回 `true` 会出错，但引理 2 排除了这一点）。两个方向合一。∎

## 6. 复杂度分析

- **时间**：$O(n + V)$，$n$ 为元素个数、$V = 501$ 为值域大小。一次计数扫描加一次值域检查，至多约 1500 步。
- **空间**：$O(V)$，即计数数组；用哈希表时为 $O(\min(n, V))$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool divideArray(vector<int>& nums) {
        vector<int> cnt(501, 0);
        for (int x : nums) ++cnt[x];
        for (int v = 1; v <= 500; ++v)
            if (cnt[v] & 1) return false;
        return true;
    }
};
```

### Python

```python
class Solution:
    def divideArray(self, nums: list) -> bool:
        cnt = [0] * 501
        for x in nums:
            cnt[x] += 1
        return all(v % 2 == 0 for v in cnt)
```

> 💡 两份代码均通过官方示例（`true`、`false`）与全同值等边界；另与「递归枚举所有完美匹配」的暴力对拍，随机 5 万组（C++）+ 3000 组（Python）零失配。

## 8. 边界情况与易错点

1. **长度必然是偶数**：`2*n` 已由输入保证，无需再判；但「长度为偶」**不等于**「可划分」，别把总长检查当成本题解。
2. **值域从 1 开始**：`cnt` 大小 501 覆盖下标 500；若误开 500 会越界。
3. **不要用异或和判整体**：合法划分意味着每个值成对出现，同值两两抵消，故异或和必为 0；但**反过来不成立**——`[1,1,4,5,2,3]` 的异或和为 0，而 4、5、2、3 的计数都是奇数，无法划分。异或和只能当必要条件用，逐值计数才是充要判定。
4. **单个值独占全场**：如 `[5,5]`，计数 2 为偶，合法；`n = 1` 是最小规模。
5. **提前返回的位置**：检查循环里 `return false` 可以提前，但计数阶段不能只数到一半就下结论。
