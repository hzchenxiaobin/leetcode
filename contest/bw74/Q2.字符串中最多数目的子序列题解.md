# LeetCode 字符串中最多数目的子序列 题解

## 1. 题目概述

- **标题 / 题号**：字符串中最多数目的子序列（#2207，medium）
- **链接**：https://leetcode.cn/problems/maximize-number-of-subsequences-in-a-string/
- **来源**：LeetCode 第 74 场双周赛 Q2
- **难度**：中等
- **标签**：贪心、字符串、前缀和

**题意**：给定字符串 `text` 与长度为 2 的 `pattern`（均只含小写字母）。你可以在 `text` 的**任意位置**（包括开头和结尾）插入**一个**字符，且这个字符必须是 `pattern[0]` 或 `pattern[1]`。返回插入后 `text` 中等于 `pattern` 的**子序列**个数的最大值。子序列允许不连续但必须保持原相对顺序。

**约束**：

- $1 \le text.length \le 10^5$
- `pattern.length == 2`，均只含小写字母
- 注意 `pattern[0]` 与 `pattern[1]` 可以相同（如 `"aa"`）

## 2. 示例

**示例 1**

```text
输入：text = "abdcdbc", pattern = "ac"
输出：4
解释：在 text[1] 与 text[2] 之间插入 'a' 得 "abadcdbc"，其中 "ac" 作为子序列出现 4 次。
     插在开头（"aabdcdbc"）同样得到 4 次。
```

**示例 2**

```text
输入：text = "aabb", pattern = "ab"
输出：6
解释：插入 'a' 在开头得 "aaabb"，"ab" 子序列出现 3×2 = 6 次。
```

**示例 3（边界补充：pattern 两字符相同）**

```text
输入：text = "aaa", pattern = "aa"
输出：6
解释：插入一个 'a' 后共 4 个 'a'，任取两个有序对即 C(4,2) = 6 个 "aa" 子序列。
```

## 3. 解题思路

### 3.1 暴力思路

枚举插入位置（$n + 1$ 个）与插入字符（2 种），对每个候选串跑一遍 $O(n)$ 的子序列计数，取最大值——总时间 $O(n^2)$，$n = 10^5$ 时约 $10^{10}$ 次操作，超时三个数量级。暴力的问题在于它把「插入一个字符带来的增量」与「原有的子序列数」混在一起重复计算。

### 3.2 核心观察：插入只增不减，最优位置必在两端

![核心观察：插 pattern[0] 到最左 / pattern[1] 到最右](images/bw74_q2_insert_position_concept.svg)

两个基本事实把问题拆开：

**其一，原有的子序列一个都不会少。** 插入字符只会增加字符而不删除，任何原有子序列在新串中依然是子序列。所以总数 = 原有数 + 新增数，二者可以分别计算。

**其二，新增数只与「插入字符和谁配对」有关。** 若插入的是 `pattern[0] = a`，它能与**每个出现在它右边的** `pattern[1] = b` 配成一个新子序列；插得越靠左，右边的 `b` 越多。设 `text` 中 `b` 的个数为 $\mathrm{cnt}_b$，插到最左端时新增恰为 $\mathrm{cnt}_b$，这是上界。同理插入 `b` 的新增数至多为 `a` 的个数 $\mathrm{cnt}_a$（插到最右端取到）。

于是答案 = 原有子序列数 $+ \max(\mathrm{cnt}_a, \mathrm{cnt}_b)$，完全不需要枚举位置。

### 3.3 算法流程：一遍扫描同时统计三项

![算法流程：一遍扫描维护 a 的前缀计数、b 的计数与已有 pattern 数](images/bw74_q2_onepass_count_flow.svg)

原有的 `pattern` 子序列数同样一遍可得：从左到右扫描，维护「已出现的 `a` 的个数」，每遇到一个 `b`，就以它结尾的子序列数恰好是当前的 `a` 计数，累加即可：

```text
1. a = b = 0（text 中 pattern[0]、pattern[1] 的计数），both = 0（原有子序列数）
2. for c in text：
       若 c == pattern[1]：both += a；b += 1
       若 c == pattern[0]：a += 1
       （两字符相同时，先结算 both 再自增 a，保证配对不重复计数）
3. 返回 both + max(a, b)
```

### 3.4 示例演算

![示例演算：abdcdbc 一遍扫描与两种插入方案](images/bw74_q2_example_walkthrough.svg)

以示例 1（`text = "abdcdbc"`，`pattern = "ac"`）为例：

| 扫描到 | `a` 计数 | 结算（遇到 `c` 时 both += a） | `b`（`c`）计数 |
|--------|---------|-------------------------------|----------------|
| `a` | 1 | — | 0 |
| `b` `d` | 1 | — | 0 |
| `c` | 1 | both = 1 | 1 |
| `d` `b` | 1 | — | 1 |
| `c` | 1 | both = 2 | 2 |

原有 2 个；$\max(\mathrm{cnt}_a, \mathrm{cnt}_b) = \max(1, 2) = 2$，答案 $2 + 2 = 4$。验证：在开头插 `a` 得 `"aabdcdbc"`，每个 `c`（2 个）都能与两个 `a` 配对，共 $2\times2 = 4$ ✓。

## 4. 算法细节

1. **结算顺序处理 `pattern[0] == pattern[1]`**：扫描中先做「`c == pattern[1]` 则 `both += a`」，再做「`c == pattern[0]` 则 `a += 1`」。两字符相同时，当前字符先以 `pattern[1]` 身份与**严格在它左边**的 `a` 配对，再以 `pattern[0]` 身份入列，`"aaa"` 顺序结算出 $\binom{3}{2} = 3$，正是去重后的有序对数。
2. **插入增益的独立性**：插 `pattern[0]` 在最左，新增 $= \mathrm{cnt}_b$，与原有多少无关（新字符与原有每个 `b` 恰好配一次，原有的配对不受影响）；这一步无需真的构造新串。
3. **返回类型**：$\mathrm{cnt}_a, \mathrm{cnt}_b \le 10^5$，总数可达 $\dfrac{n(n+1)}{2} \approx 5\times10^9$，超出 32 位 `int`，C++ 返回 `long long`（题面签名即 `long long`）。
4. **一遍扫描的三个量**：`a`、`b`、`both` 在同一次遍历中维护，避免三次扫串；`a` 实际上就是「当前前缀中 `pattern[0]` 的个数」——一个最朴素的前缀和。
5. **为什么不用枚举中间位置**：插 `pattern[0]` 在位置 $i$，新增 = 它右边的 `b` 个数 $\le \mathrm{cnt}_b$，且严格小于当且仅当左边存在 `b`；既然插最左不劣，中间位置只在「放弃更优的另一侧插入」时才有讨论价值，而另一侧对称。两端必是全局最优。

## 5. 正确性证明

**引理 1（插入不减）**：在 `text` 位置 $i$ 插入字符 $c$ 得到 $text'$，则 `pattern` 在 `text` 中的每个子序列在 $text'$ 中仍是子序列。

**证明**：子序列由一组递增下标刻画。插入不改变原有字符的相对顺序，把该组下标中 $\ge i$ 的每个加一，仍递增且对应相同字符，故在 $text'$ 中有效。∎

**引理 2（新增子序列的计数）**：插入 `pattern[0]` 于位置 $i$（新增字符记作 $a^*$），新增的 `pattern` 子序列个数 = 位置 $i$ 右侧 `pattern[1]` 的个数；插入 `pattern[1]` 于位置 $i$，新增个数 = 位置 $i$ 左侧 `pattern[0]` 的个数。

**证明**：新增子序列必须用到 $a^*$（否则由引理 1 它在原串中已存在，不「新」）。$a^*$ 与某个 `pattern[1]` 出现位置 $j$ 构成子序列当且仅当 $a^*$ 在 $j$ 左侧，即 $j > i$。每个右侧的 `pattern[1]` 与 $a^*$ 恰构成一个子序列，不同 $j$ 互不相同，故个数恰为右侧计数。`pattern[1]` 的情形对称。∎

**定理**：答案 = 原有子序列数 $+ \max(\mathrm{cnt}_a, \mathrm{cnt}_b)$，其中 $\mathrm{cnt}_a, \mathrm{cnt}_b$ 为两字符在 `text` 中的总个数。

**证明**：由引理 1，任意插入方案的总数 = 原有数 + 新增数；由引理 2，新增数的最大值在「插 `pattern[0]` 于最左」时取 $\mathrm{cnt}_b$、「插 `pattern[1]` 于最右」时取 $\mathrm{cnt}_a$，两者都可达，其余方案的新增数均不超过这两个上界（位置移动只会减少另一侧的配对数）。取两种可达方案的较优者，总数 = 原有数 $+ \max(\mathrm{cnt}_a, \mathrm{cnt}_b)$，且不可能更大。原有数由一遍扫描正确累计（每个 `pattern[1]` 结尾的子序列数 = 其左侧 `pattern[0]` 数，求和即总数，当两字符相同时结算先于自增保证每个有序对恰计一次）。∎

## 6. 复杂度分析

- **时间**：$O(n)$。一次线性扫描同时维护 `a`、`b`、`both` 三个计数器。
- **空间**：$O(1)$。除三个整数变量外无额外存储。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long maximumSubsequenceCount(string text, string pattern) {
        long long a = 0, b = 0, both = 0;
        for (char c : text) {
            if (c == pattern[1]) { both += a; ++b; }   // 先结算以 c 结尾的完整 pattern
            if (c == pattern[0]) ++a;
        }
        return both + max(a, b);
    }
};
```

### Python

```python
class Solution:
    def maximumSubsequenceCount(self, text: str, pattern: str) -> int:
        a = b = both = 0
        for c in text:
            if c == pattern[1]:
                both += a
                b += 1
            if c == pattern[0]:
                a += 1
        return both + max(a, b)
```

> 💡 两份代码均通过官方示例（`4`、`6`）与 `pattern` 两字符相同（`"aa"`）等边界；另与「枚举全部 $2(n+1)$ 种插入方案 + $O(n^2)$ DP 计数」的暴力对拍，随机 2 万组（C++）+ 3000 组（Python）零失配。

## 8. 边界情况与易错点

1. **`pattern[0] == pattern[1]`**：扫描顺序（先结算 `both += a` 再 `a += 1`）保证不把「字符自己配自己」计进去；插任意侧的增益都是 $\mathrm{cnt}$，答案为 $\binom{n+1}{2}$ 的形式。
2. **溢出**：`n = 10^5` 全同字符时答案约 $5\times10^9$，C++ 必须用 `long long`；Python 天然大整数无碍。
3. **别真去构造字符串**：插入位置虽是枚举变量，但由引理 2 最优位置必在两端，直接用计数即可；构造新串再计数是 $O(n^2)$ 的弯路。
4. **结算别用后缀**：`both` 累加的是「以当前 `pattern[1]` 结尾」的个数，即其左侧的 `pattern[0]` 数；若误写成右侧，`"ab"` 与 `"ba"` 的结果会颠倒。
5. **空串与单字符**：题面保证 $n \ge 1$；单字符 `text` 时原有数为 0，答案为 $\max(\mathrm{cnt}_a, \mathrm{cnt}_b) = 1$。
6. **只允许插一个字符**：题目问的是单次插入；若误以为可以插多个，会推出 $\max$ 之外的多步规划，超出题意。
