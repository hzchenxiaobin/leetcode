# LeetCode 负二进制数相加 题解

## 1. 题目概述

- **标题 / 题号**：负二进制数相加（#1073，medium）
- **链接**：https://leetcode.cn/problems/adding-two-negabinary-numbers/
- **来源**：LeetCode 第 139 场周赛 Q3
- **难度**：中等
- **标签**：数组、数学

**题意**：给定两个以 $-2$ 为基数的数 `arr1`、`arr2`，用数组表示（高位在前，每项为 0 或 1，无前导零）。返回两数之和的同样表示形式。

$$v(\text{arr}) = \sum_{k} \text{arr}[k] \cdot (-2)^{\lvert \text{arr} \rvert - 1 - k}$$

**约束**：

- $1 \le \text{arr1.length}, \text{arr2.length} \le 1000$
- $\text{arr1}[i], \text{arr2}[i] \in \{0, 1\}$
- 两个数组都没有前导零（即等于 `[0]` 或首项为 1）

**一句话转化**：竖式加法 + **允许负数进位**。逐位处理，把「本位留什么、往高位进多少」用一张小表固定下来即可。

## 2. 示例

**示例 1**

```text
输入：arr1 = [1,1,1,1,1], arr2 = [1,0,1]
输出：[1,0,0,0,0]
解释：arr1 = 16 - 8 + 4 - 2 + 1 = 11，arr2 = 4 + 1 = 5，和为 16。
      16 = (−2)⁴，即 [1,0,0,0,0]。
```

**示例 2**

```text
输入：arr1 = [0], arr2 = [0]
输出：[0]
解释：0 + 0 = 0，规范形式是 [0]。
```

**示例 3**

```text
输入：arr1 = [0], arr2 = [1]
输出：[1]
```

**补充示例（结果变长）**

```text
输入：arr1 = [1], arr2 = [1]
输出：[1,1,0]
解释：1 + 1 = 2 = 0 + (−2)·(−1) → 本位 0、进位 −1；
      下一位 −1 → 本位 1、进位 1；再下一位 1 → 本位 1、进位 0。
      结果 [1,1,0] = 4 − 2 = 2 ✓
```

## 3. 解题思路

### 3.1 暴力思路

把数组还原成整数，相加后再转回负二进制。这条路线在 Python 上可以（大整数天然支持），但在 C++ 里 $10^3$ 位、数值高达 $2^{1000}$，必须手写高精度，代码量与出错率都远超原题；而且「负基数」的除法还要求余数非负，属于另一套高精度取模逻辑。

逐位竖式才是本题的本意：两个 $10^3$ 位的数，$O(n)$ 一次扫描即可。

### 3.2 核心观察：进位可以是负数

![进位的五种取值](images/wc139_q3_carry_table.svg)

设当前位两个比特之和为 $s$（加上进位前的值可能是 $-1$ 到 $3$）。我们需要挑「本位数字 $d \in \{0,1\}$」与「进位 $c$」，使

$$s = d + (-2)\cdot c$$

也就是高一位的权重是 $-2$ 倍，所以 $c$ 的含义是「向高位交付的量」。枚举 $s \in \{-1,0,1,2,3\}$ 得到唯一的合法解：

| $s$ | $d = s \bmod 2$ | $c = -\frac{s-d}{2}$ | 校验 |
|-----|-----------------|----------------------|------|
| $-1$ | 1 | 1 | $1 + (-2)\cdot 1 = -1$ ✓ |
| $0$ | 0 | 0 | $0 + 0 = 0$ ✓ |
| $1$ | 1 | 0 | $1 + 0 = 1$ ✓ |
| $2$ | 0 | $-1$ | $0 + (-2)(-1) = 2$ ✓ |
| $3$ | 1 | $-1$ | $1 + (-2)(-1) = 3$ ✓ |

关键点：**$s = 2$ 时进位是 $-1$ 而不是 $+1$**，$s = 3$ 时也是 $-1$。这是负二进制与普通二进制全部差异的来源。

实现上 $d = s \bmod 2$ 需要注意负数取模：C++ 的 `-1 % 2` 是 $-1$，Python 的 $-1 \% 2$ 是 $1$。统一写成 `d = ((s % 2) + 2) % 2`（C++）或 `d = s & 1`（两语言下 $-1 \& 1 = 1$），随后 $c = -(s - d)/2$ 是精确整除，不会出现负数右移的实现依赖。

### 3.3 算法流程

![从最低位向高位的列加法](images/wc139_q3_flow.svg)

```text
1. i = |arr1|-1，j = |arr2|-1，carry = 0，out = []
2. while i >= 0 或 j >= 0 或 carry != 0:
       s = carry + (i>=0 ? arr1[i] : 0) + (j>=0 ? arr2[j] : 0)
       d = s & 1
       carry = -(s - d) / 2
       out.push(d)；i--；j--
3. 去掉 out 末尾（即高位）的 0，最后反转即为答案
```

循环条件里的 `carry != 0` 不能省：两个数都处理完后进位仍可能非零（例如示例 4 的 `[1]+[1]`）。

### 3.4 示例演算

![示例 1 逐位走查](images/wc139_q3_walkthrough.svg)

`arr1 = [1,1,1,1,1]`、`arr2 = [1,0,1]`，把 `arr2` 左补零对齐到 5 位：`[0,0,1,0,1]`。

| 处理位（从低到高） | 位权 | $a$ | $b$ | 进位 | $s$ | $d$ | 新进位 | 结果低位 |
|--------------------|------|-----|-----|------|-----|-----|--------|----------|
| 第 5 位（最低） | 1 | 1 | 1 | 0 | 2 | 0 | $-1$ | 0 |
| 第 4 位 | $-2$ | 1 | 0 | $-1$ | 0 | 0 | 0 | 0 |
| 第 3 位 | 4 | 1 | 1 | 0 | 2 | 0 | $-1$ | 0 |
| 第 2 位 | $-8$ | 1 | 0 | $-1$ | 0 | 0 | 0 | 0 |
| 第 1 位 | 16 | 1 | 0 | 0 | 1 | 1 | 0 | 1 |

逆序输出 `[1,0,0,0,0]`，即 $16$ ✓。

## 4. 算法细节

1. **对齐方式**：不真的补零，用 `i >= 0 ? arr1[i] : 0` 判断越界，省一次数组拷贝。也可以用双指针从尾部走。
2. **负数取模**：C++ 中 `-1 % 2 == -1`，必须先修正成 `((s % 2) + 2) % 2`；`s & 1` 在补码实现下对负数也返回 1，但语义依赖补码，显式修正更稳。
3. **进位递推用 `-(s - d) / 2`**：`s - d` 必为偶数，整除无歧义；避免用 `s >> 1`（负数右移在 C++17 是实现定义行为）。
4. **结果长度**：最多 $\max(\lvert arr1 \rvert, \lvert arr2 \rvert) + 2$（进位最多连续传播两位，见引理 3）。
5. **去前导零**：`out` 是低位在前的，末尾的 0 对应高位前导零，弹出后再反转；保留至少一位（`[0]` 的情形）。
6. **复杂度**：一次扫描，$O(\max(n, m))$ 时间、$O(\max(n, m))$ 空间。

## 5. 正确性证明

记数组 $a$ 从低到高第 $k$ 位为 $a_k$（$k = 0$ 是最低位），数值 $v(a) = \sum_k a_k (-2)^k$。

**引理 1（拆分表唯一）**：对任意整数 $s$，存在唯一的 $d \in \{0,1\}$ 与整数 $c$ 使 $s = d - 2c$，且当 $s \in \{-1,0,1,2,3\}$ 时 $c \in \{-1,0,1\}$。

**证明**：模 2 意义下 $s \equiv d \pmod 2$，故 $d$ 只能是 $s$ 的奇偶性决定的那一个值（$s$ 偶则 $d = 0$，奇则 $d = 1$）。$d$ 确定后 $c = (d - s)/2$ 唯一。对 $s$ 的五个取值直接代入即得表中结果。∎

**引理 2（不变式）**：设处理到第 $k$ 位之前，已输出的低 $k$ 位为 $o_0, \ldots, o_{k-1}$，进位为 $c$。则

$$v(\text{arr1}) + v(\text{arr2}) = \sum_{t<k} o_t (-2)^t + (-2)^k \big(c + \text{剩余部分}\big)$$

其中「剩余部分」指两个输入第 $k$ 位及以上部分的加权和（权重按原基 $-2$ 计）。

**证明**：对 $k$ 归纳。$k = 0$ 时 $c = 0$，等式显然。设第 $k$ 位成立，该位输入为 $a_k, b_k$，令 $s = c + a_k + b_k$，由引理 1 取 $d, c'$ 使 $s = d - 2c'$。则

$$\sum_{t<k} o_t(-2)^t + (-2)^k(c + a_k + b_k + R) = \sum_{t<k} o_t(-2)^t + (-2)^k(d - 2c' + R) = \sum_{t\le k} o_t(-2)^t + (-2)^{k+1}(c' + R)$$

其中 $R$ 为第 $k+1$ 位及以上的输入加权和（相对第 $k$ 位的缩放）。正是 $k+1$ 的不变式。∎

**引理 3（终止性）**：循环至多执行 $\max(n,m) + 2$ 轮。

**证明**：当 $i, j$ 都越界后，每轮只处理 `carry`。由引理 1，若进位 $c = 1$，则 $s = 1$ → $d = 1, c' = 0$，一轮归零；若 $c = -1$，则 $s = -1$ → $d = 1, c' = 1$，再一轮（$s = 1$）归零。故进位最多再传播 2 轮。∎

**定理**：算法输出是 $\text{arr1} + \text{arr2}$ 的规范负二进制表示（无前导零）。

**证明**：由引理 2 取 $k$ 超过所有位（此时「剩余部分」为 0、进位为 0），得 $v(\text{arr1}) + v(\text{arr2}) = \sum_t o_t (-2)^t$，即输出数组的值等于两数之和。每轮由引理 1 保证 $o_t \in \{0,1\}$；由引理 3 循环终止且终止时进位为 0。去前导零后最高位必为 1（除非数值为 0，此时保留 `[0]`），满足规范表示的要求。∎

## 6. 复杂度分析

- **时间**：$O(\max(n, m))$。每轮常数次算术运算，总轮数 $\le \max(n,m) + 2$。
- **空间**：$O(\max(n, m))$ 存放输出数组（不含输入）。

## 7. 参考代码

### C++

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> addNegabinary(vector<int>& arr1, vector<int>& arr2) {
        int i = (int)arr1.size() - 1, j = (int)arr2.size() - 1;
        int carry = 0;
        vector<int> out;
        while (i >= 0 || j >= 0 || carry != 0) {
            int total = carry;
            if (i >= 0) total += arr1[i--];
            if (j >= 0) total += arr2[j--];
            int digit = ((total % 2) + 2) % 2;
            out.push_back(digit);
            carry = -(total - digit) / 2;
        }
        while (out.size() > 1 && out.back() == 0) out.pop_back();
        vector<int> res(out.rbegin(), out.rend());
        return res;
    }
};
```

### Python

```python
class Solution:
    def addNegabinary(self, arr1: list[int], arr2: list[int]) -> list[int]:
        i, j = len(arr1) - 1, len(arr2) - 1
        carry = 0
        out = []
        while i >= 0 or j >= 0 or carry:
            total = carry
            if i >= 0:
                total += arr1[i]
                i -= 1
            if j >= 0:
                total += arr2[j]
                j -= 1
            digit = total & 1
            out.append(digit)
            carry = -(total - digit) // 2
        while len(out) > 1 and out[-1] == 0:
            out.pop()
        return out[::-1]
```

## 8. 边界情况与易错点

1. **`[0] + [0]`**：循环执行一轮，`out = [0]`，去前导零时保留一位，返回 `[0]`。若写成 `while (out.size() && out.back() == 0)` 会得到空数组。
2. **长度不等**：短的那个数高位按 0 处理，不要下标越界；`i >= 0` 的判断必须在取 `arr1[i]` 之前。
3. **进位为负**：$s = 2$ 时进位是 $-1$。若照搬普通二进制的 `carry = s >> 1` 会得到 $+1$，结果错误且可能死循环。
4. **负数取模**：C++ 的 `%` 对负数返回负值，必须修正；Python 的 `%` 已经返回非负，可直接用 `total % 2`。
5. **`-1 >> 1` 是负数右移**：C++17 中是实现定义行为，改用 `-(total - digit) / 2`。
6. **结果可能比两个输入都长**：`[1] + [1] = [1,1,0]`（长度 3 > 1），不要按 `max(len)` 预分配。
7. **输入保证无前导零**，但输出也必须无前导零；若不去零，`[0]+[0]` 之类的用例会输出 `[0,0]`。
8. **不要用 `int` 转换整个数组**：$10^3$ 位远超 `long long`。
