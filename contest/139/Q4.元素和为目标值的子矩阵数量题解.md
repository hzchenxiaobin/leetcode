# LeetCode 元素和为目标值的子矩阵数量 题解

## 1. 题目概述

- **标题 / 题号**：元素和为目标值的子矩阵数量（#1074，hard）
- **链接**：https://leetcode.cn/problems/number-of-submatrices-that-sum-to-target/
- **来源**：LeetCode 第 139 场周赛 Q4
- **难度**：困难
- **标签**：数组、哈希表、矩阵、前缀和

**题意**：给定矩阵 `matrix` 与目标值 `target`，统计**元素和恰好等于 `target` 的非空子矩阵**个数。子矩阵由 $(x_1, y_1, x_2, y_2)$ 唯一确定，坐标不同即视为不同子矩阵。

**约束**：

- $1 \le m = \text{matrix.length} \le 100$，$1 \le n = \text{matrix}[0]\text{.length} \le 100$
- $-1000 \le \text{matrix}[i][j] \le 1000$（**可以为负**）
- $-10^8 \le \text{target} \le 10^8$

**一句话转化**：枚举上下边界把二维压成一维，再用「前缀和 + 哈希表」统计和等于 `target` 的**连续子数组**个数。

## 2. 示例

**示例 1**

```text
输入：matrix = [[0,1,0],[1,1,1],[0,1,0]], target = 0
输出：4
解释：四个只含 0 的 1×1 子矩阵（四个角）。
```

**示例 2**

```text
输入：matrix = [[1,-1],[-1,1]], target = 0
输出：5
解释：两个 1×2 子矩阵、两个 2×1 子矩阵、一个 2×2 子矩阵，和都是 0。
```

**示例 3**

```text
输入：matrix = [[904]], target = 0
输出：0
解释：唯一的子矩阵和为 904。
```

## 3. 解题思路

### 3.1 暴力思路

用二维前缀和在 $O(1)$ 内求出任意子矩阵的和，再枚举四元组 $(x_1, y_1, x_2, y_2)$。方案数约 $\left(\frac{m(m+1)}{2}\right)\left(\frac{n(n+1)}{2}\right)$，$m = n = 100$ 时约 $2.5 \times 10^7$——恰好卡在时间边界上，而且每一步都要做 4 次数组访问与加减，常数不小。更关键的是，这个做法完全没有利用「一维子数组计数可以做到线性」这一结构。

### 3.2 核心观察：固定上下边界后降维

![固定上下边界，把二维压成列和数组](images/wc139_q4_compress.svg)

固定子矩阵的**上下边界** $(\text{top}, \text{bottom})$ 后，记

$$\text{colSum}[c] = \sum_{r=\text{top}}^{\text{bottom}} \text{matrix}[r][c]$$

此时任何以 $[\text{top}, \text{bottom}]$ 为上下界的子矩阵，其左右边界 $(l, r)$ 对应的和恰好是 $\text{colSum}$ 在 $[l, r]$ 上的**子数组和**。于是二维计数被拆成 $O(m^2)$ 个一维问题：

$$\text{ans} = \sum_{\text{top} \le \text{bottom}} \#\{(l, r) : \text{colSum}[l..r] \text{ 之和} = \text{target}\}$$

一维问题用**前缀和 + 哈希表**在 $O(n)$ 内解决：设 $P[k] = \text{colSum}[0..k-1]$，则 $\text{colSum}[l..r]$ 的和 $= P[r+1] - P[l]$，条件变成 $P[l] = P[r+1] - \text{target}$，只需边扫边查哈希表。

**为什么不能用双指针？** 因为元素可以为负，前缀和不再单调，滑动窗口的收缩条件失效——必须用哈希计数。

### 3.3 算法流程

![一维子数组计数：前缀和 + 哈希表](images/wc139_q4_prefix_hash.svg)

```text
1. ans = 0
2. for top in 0 .. m-1:
       colSum = [0]*n
       for bottom in top .. m-1:
           colSum[c] += matrix[bottom][c]        # 增量维护列和
           cnt = {0: 1}；pre = 0
           for c in 0 .. n-1:
               pre += colSum[c]
               ans += cnt[pre - target]          # 以 c 结尾的合法子数组个数
               cnt[pre] += 1
3. 返回 ans
```

`cnt` 的初值 `{0: 1}` 表示「空前缀」，用来覆盖从第 0 列开始的子数组。

### 3.4 示例演算

![示例 1 的 4 个答案](images/wc139_q4_walkthrough.svg)

`matrix = [[0,1,0],[1,1,1],[0,1,0]]`，`target = 0`。逐对枚举上下边界，得到列和数组：

| top | bottom | colSum | 和为 0 的子数组 |
|-----|--------|--------|-----------------|
| 0 | 0 | `[0,1,0]` | `[0]`（第 1 列）、`[0]`（第 3 列）→ 2 |
| 0 | 1 | `[1,2,1]` | 无（全正）→ 0 |
| 0 | 2 | `[1,3,1]` | 无 → 0 |
| 1 | 1 | `[1,1,1]` | 无 → 0 |
| 1 | 2 | `[1,2,1]` | 无 → 0 |
| 2 | 2 | `[0,1,0]` | 2 |

合计 4 ✓（对应四个角上的 0）。

再看示例 2：`[[1,-1],[-1,1]]`，`target = 0`。
- `top=0,bottom=0`：colSum = `[1,-1]`，子数组 `[1,1]` 和为 0 → 1 个；
- `top=0,bottom=1`：colSum = `[0,0]`，子数组和：`[0]`、`[0,0]`、`[0]` → 3 个；
- `top=1,bottom=1`：colSum = `[-1,1]`，`[1,1]` 和为 0 → 1 个。

合计 5 ✓。

## 4. 算法细节

1. **列和的增量维护**：`bottom` 每增加 1，只需把新的一行加到 `colSum` 上，$O(n)$；不要为每个 `(top, bottom)` 重新求和（那会多一个 $O(m)$ 因子）。
2. **哈希表每对边界重建**：`cnt` 必须在外层 `bottom` 循环内重新初始化，否则会把上一对边界的统计带进来。
3. **`pre - target` 可能重复**：由于存在负值与 0，前缀和会重复出现，`cnt` 必须记录**次数**而不是布尔值。
4. **累加顺序**：先 `ans += cnt[pre - target]`，再 `cnt[pre] += 1`；反过来会把「长度为 0 的子数组」算进去（当 `target = 0` 时多算）。
5. **数值范围**：单个前缀和最大 $100 \times 100 \times 1000 = 10^7$，`target` 到 $10^8$，差值在 `int` 范围内，不会溢出；若值域放大到 $10^9$ 需用 `long long`。
6. **可转置优化**：把矩阵转置后让 $n \le m$，复杂度从 $O(m^2 n)$ 变为 $O(\min(m,n)^2 \cdot \max(m,n))$。$100 \times 100$ 时无必要，但作为习惯值得记住。
7. **哈希实现**：C++ 用 `unordered_map<int,int>`；$10^8$ 的键值范围不适合数组桶。Python 用 `dict` 或 `defaultdict(int)`。

## 5. 正确性证明

**引理 1（降维等价）**：固定 $(\text{top}, \text{bottom})$ 后，子矩阵 $\{\text{top} \le r \le \text{bottom},\ l \le c \le r'\}$ 的元素和等于 $\sum_{c=l}^{r'} \text{colSum}[c]$。

**证明**：交换求和顺序：$\sum_{r=\text{top}}^{\text{bottom}}\sum_{c=l}^{r'} \text{matrix}[r][c] = \sum_{c=l}^{r'}\left(\sum_{r=\text{top}}^{\text{bottom}} \text{matrix}[r][c]\right) = \sum_{c=l}^{r'} \text{colSum}[c]$。∎

**引理 2（一维计数正确）**：设 $P[0] = 0$、$P[k] = \sum_{c<k}\text{colSum}[c]$。则 $\sum_{c=l}^{r'}\text{colSum}[c] = \text{target} \iff P[l] = P[r'+1] - \text{target}$。

**证明**：$\sum_{c=l}^{r'} = P[r'+1] - P[l]$，移项即得。∎

**引理 3（哈希计数不重不漏）**：扫描到下标 $k$（对应 $P[k+1]$）时，`cnt[P[k+1] - target]` 恰为满足 $r' = k$ 且合法的子数组个数；所有 $k$ 累加后覆盖全部子数组且每个只算一次。

**证明**：由引理 2，满足条件的子数组由其右端点 $r'$ 与左端点 $l$ 唯一确定，且 $l \le r'$。扫描到 $k$ 时 `cnt` 中已记录 $P[0..k]$ 的出现次数（$P[0]$ 来自初值 `{0:1}`，$P[1..k]$ 来自前几轮插入），故 `cnt[P[k+1] - target]` 统计了所有满足 $P[l] = P[k+1] - \text{target}$ 的 $l \le k$，即所有以 $k$ 结尾的合法子数组；每个子数组的右端点唯一，因此不重不漏。∎

**引理 4（枚举完备）**：任意非空子矩阵都有唯一的 $(\text{top}, \text{bottom})$ 与唯一的 $(l, r')$。

**证明**：子矩阵由四个边界决定，$(\text{top}, \text{bottom})$ 与 $(l, r')$ 都是它的组成部分，故唯一；算法外层枚举所有 $\text{top} \le \text{bottom}$，内层枚举所有 $l \le r'$，故每个子矩阵恰好被统计一次。∎

**定理**：算法返回值等于元素和等于 `target` 的非空子矩阵个数。

**证明**：由引理 4，所有非空子矩阵被 $(\text{top}, \text{bottom}, l, r')$ 的枚举覆盖且每个恰好一次；由引理 1、2、3，对每对 $(\text{top}, \text{bottom})$，内层累加值恰为该边界下合法子矩阵的个数。求和即得答案。∎

## 6. 复杂度分析

- **时间**：$O(m^2 n)$。外层 $O(m^2)$ 对边界，每对做 $O(n)$ 的列和更新与 $O(n)$ 的哈希扫描，合计 $O(m^2 n)$；$m = n = 100$ 时约 $10^6$ 次操作。
- **空间**：$O(n)$ 存放列和数组，$O(n)$ 存放哈希表（不同前缀和至多 $n + 1$ 个）；不计输入时总空间 $O(n)$。

## 7. 参考代码

### C++

```cpp
#include <algorithm>
#include <unordered_map>
#include <vector>
using namespace std;

class Solution {
public:
    int numSubmatrixSumTarget(vector<vector<int>>& matrix, int target) {
        int rows = (int)matrix.size(), cols = (int)matrix[0].size();
        int ans = 0;
        vector<int> colSum(cols, 0);
        for (int top = 0; top < rows; top++) {
            fill(colSum.begin(), colSum.end(), 0);
            for (int bottom = top; bottom < rows; bottom++) {
                for (int c = 0; c < cols; c++) colSum[c] += matrix[bottom][c];
                unordered_map<int, int> seen;
                seen[0] = 1;
                int pre = 0;
                for (int c = 0; c < cols; c++) {
                    pre += colSum[c];
                    auto it = seen.find(pre - target);
                    if (it != seen.end()) ans += it->second;
                    seen[pre]++;
                }
            }
        }
        return ans;
    }
};
```

### Python

```python
from collections import defaultdict


class Solution:
    def numSubmatrixSumTarget(self, matrix: list[list[int]], target: int) -> int:
        rows, cols = len(matrix), len(matrix[0])
        ans = 0
        for top in range(rows):
            col_sum = [0] * cols
            for bottom in range(top, rows):
                for c in range(cols):
                    col_sum[c] += matrix[bottom][c]
                seen = defaultdict(int)
                seen[0] = 1
                pre = 0
                for x in col_sum:
                    pre += x
                    ans += seen[pre - target]
                    seen[pre] += 1
        return ans
```

## 8. 边界情况与易错点

1. **$1 \times 1$ 矩阵**：只有 `(0,0,0,0)` 一个子矩阵，直接比较 `matrix[0][0] == target`；算法自然给出该结果。
2. **单行 / 单列**：退化为「一维子数组和等于 target 的个数」，仍走同一套循环。
3. **全 0 矩阵且 `target = 0`**：答案是全部子矩阵数 $\frac{m(m+1)}{2} \cdot \frac{n(n+1)}{2}$，用于检验计数是否重复或遗漏。
4. **负值导致前缀和重复**：`[[1,-1],[-1,1]]` 的 `colSum` 前缀和有重复值，必须用哈希计数而非双指针。
5. **累加顺序写反**：先 `cnt[pre] += 1` 再查表，会把长度 0 的空区间算进去，`target = 0` 时答案偏大。
6. **`cnt` 未重置**：哈希表在外层 `top` 循环之外初始化会导致跨边界污染。
7. **`target` 极大或极小**：$10^8$ 量级用 `int` 仍安全，但若 `target` 超出 `int` 需用 `long long` 比较；Python 无此问题。
8. **性能常数**：$10^6$ 次 `unordered_map` 操作在 1 秒内可完成；若卡常数，可改用排序 + 二分或手写哈希。
