# LeetCode 字符串的最大公因子 题解

## 1. 题目概述

- **标题 / 题号**：字符串的最大公因子（#1071，easy）
- **链接**：https://leetcode.cn/problems/greatest-common-divisor-of-strings/
- **来源**：LeetCode 第 139 场周赛 Q1
- **难度**：简单
- **标签**：数学、字符串、最大公约数、欧几里得算法

**题意**：若字符串 $s$ 可以由 $t$ 原样重复若干次拼成（$s = t + t + \cdots + t$），称「$t$ 能除尽 $s$」。给定 `str1`、`str2`，返回**最长的**能同时除尽两者的字符串 $x$；不存在则返回空串。

**约束**：

- $1 \le \text{str1.length}, \text{str2.length} \le 1000$
- 只含大写英文字母

**一句话转化**：求两个字符串的「周期」的**最大公因子**——候选答案一定是两者的公共前缀，且长度整除两个串长。

## 2. 示例

**示例 1**

```text
输入：str1 = "ABCABC", str2 = "ABC"
输出："ABC"
解释："ABC" 重复 2 次得 str1，重复 1 次得 str2。
```

**示例 2**

```text
输入：str1 = "ABABAB", str2 = "ABAB"
输出："AB"
解释：|str1| = 6，|str2| = 4，gcd = 2；"AB" 同时除尽两者。"ABAB" 除不尽 "ABABAB"。
```

**示例 3**

```text
输入：str1 = "LEET", str2 = "CODE"
输出：""
解释：两者没有公共周期（拼接后也不相等）。
```

**示例 4**

```text
输入：str1 = "AAAAAB", str2 = "AAA"
输出：""
解释：长度 gcd 为 3，前缀 "AAA" 能除尽 str2，但 "AAA" 重复 2 次是 "AAAAAA" ≠ "AAAAAB"，
      说明 str1 并非由 "AAA" 构成，答案是空串。
```

## 3. 解题思路

### 3.1 暴力思路

枚举 `str1` 的所有前缀（长度 $1 \sim \lvert \text{str1} \rvert$），对每个前缀检查它是否同时除尽两个串，取最长者。每次检查需要 $O(\lvert s \rvert)$，总复杂度 $O(n \cdot (n + m))$，$n = m = 1000$ 时约 $10^6$，可以通过，但没有利用「周期长度必须整除」这一强约束，白做了大量无效检查。

### 3.2 核心观察：两次拼接的交换律

![能除尽的含义：整块重复](images/wc139_q1_divide_concept.svg)

设 $x$ 同时除尽 `str1` 与 `str2`，则 $\text{str1} = x^{a}$、$\text{str2} = x^{b}$，于是

$$\text{str1} + \text{str2} = x^{a+b} = \text{str2} + \text{str1}$$

这是一个**必要条件**：拼接可交换。它的逆命题也成立（见引理 2），于是判定就变成一次 $O(n+m)$ 的字符串比较。

当拼接相等时，公共周期的长度 $p$ 必须同时整除 $\lvert \text{str1} \rvert$ 与 $\lvert \text{str2} \rvert$，因此 $p$ 是 $\gcd(\lvert \text{str1} \rvert, \lvert \text{str2} \rvert)$ 的因子。而「最长的公共因子」就取 $p = \gcd$——因为若存在长度为 $p_0$ 的公共因子，则 $\gcd$ 长度也能整除两个串（两者都是 $x$ 的重复，周期结构一致），长度更长的候选反而更优。

答案即 `str1` 的前 $g = \gcd(\lvert \text{str1} \rvert, \lvert \text{str2} \rvert)$ 个字符。

### 3.3 算法流程

![三步判定](images/wc139_q1_flow.svg)

```text
1. 若 str1 + str2 != str2 + str1：返回 ""
2. g = gcd(len(str1), len(str2))
3. 返回 str1 的前 g 个字符
```

### 3.4 示例演算

| str1 | str2 | 拼接相等？ | g | 答案 |
|------|------|-----------|---|------|
| `ABCABC` | `ABC` | `ABCABCABC` = `ABCABCABC` ✓ | $\gcd(6,3)=3$ | `ABC` |
| `ABABAB` | `ABAB` | ✓ | $\gcd(6,4)=2$ | `AB` |
| `LEET` | `CODE` | `LEETCODE` ≠ `CODELEET` ✗ | — | `""` |
| `AAAAAB` | `AAA` | `AAAAABAAA` ≠ `AAAAAAAB` ✗ | — | `""` |

## 4. 算法细节

1. **拼接用 `+`**：C++ 里 `str1 + str2` 会产生 $O(n+m)$ 的临时串，长度 $\le 2000$，开销可忽略。
2. **gcd 用现成实现**：C++ 用 `std::gcd`（需 `<numeric>`，C++17），Python 用 `math.gcd`，也可手写欧几里得。
3. **只取前缀**：`str1.substr(0, g)` / `str1[:g]`，不用再去 `str2` 里取——若拼接相等，两者的前缀在这 $g$ 个字符上必然一致（见引理 4）。
4. **不要用 `str1.find(str2)` 之类的包含关系**：题目要求「整块重复」，`x` 是子串并不够。
5. **空串处理**：返回 `""` 是合法答案，调用方不需要特判。

## 5. 正确性证明

**引理 1（必要性）**：若 $x$ 同时除尽 `str1`、`str2`，则 $\text{str1} + \text{str2} = \text{str2} + \text{str1}$。

**证明**：由定义存在正整数 $a, b$ 使 $\text{str1} = x^a$、$\text{str2} = x^b$。于是 $\text{str1} + \text{str2} = x^{a+b} = x^{b+a} = \text{str2} + \text{str1}$。∎

**引理 2（充分性）**：若 $\text{str1} + \text{str2} = \text{str2} + \text{str1}$，令 $g = \gcd(\lvert \text{str1} \rvert, \lvert \text{str2} \rvert)$，则 `str1` 的前 $g$ 个字符同时除尽两者。

**证明**：设 $n = \lvert \text{str1} \rvert$、$m = \lvert \text{str2} \rvert$，$S = \text{str1} + \text{str2}$（长度 $n+m$）。由拼接相等可知 $S$ 以 $\text{str2}$ 为周期且以 $\text{str1}$ 为周期：对 $0 \le i < n$ 有 $S[i] = S[i+m]$，对 $0 \le i < m$ 有 $S[i] = S[i+n]$（下标不越界处）。由**周期引理**（若长度 $L$ 的串同时具有周期 $p$、$q$ 且 $p+q \le L$，则它有周期 $\gcd(p,q)$；此处 $L = n+m \ge p+q$），$S$ 具有周期 $g = \gcd(n, m)$。

取 $x = \text{str1}[0..g-1]$。对任意 $0 \le i < n$，把 $i$ 写成 $i = qg + r$（$0 \le r < g$）。由于 $g \mid n$，可用周期 $g$ 逐步回退：$\text{str1}[i] = S[i] = S[i - g] = \cdots = S[r] = x[r]$，故 $\text{str1} = x^{n/g}$。同法对 `str2` 得 $\text{str2} = x^{m/g}$。∎

**引理 3（最长性）**：若存在公共因子，则最长者的长度为 $g = \gcd(n, m)$。

**证明**：设公共因子 $x$ 长度为 $p$，则 $p \mid n$、$p \mid m$，故 $p \mid g$，于是 $p \le g$。而引理 2 说明长度 $g$ 的公共因子确实存在，故最长者是长度 $g$ 的那个。∎

**引理 4（前缀一致）**：在拼接相等的条件下，`str1` 与 `str2` 的前 $g$ 个字符相同。

**证明**：由引理 2 的证明，两者都是同一个 $x = S[0..g-1]$ 的重复。∎

**定理**：算法输出等于题目要求的最长公共因子（不存在时为空串）。

**证明**：若拼接不等，由引理 1 的逆否命题不存在公共因子，算法返回 `""` 正确。若拼接相等，引理 2 表明 `str1` 的前 $g$ 个字符是公共因子，引理 4 表明它同时是 `str2` 的前缀，引理 3 表明它最长，故算法输出正确。∎

## 6. 复杂度分析

- **时间**：$O(n + m)$。拼接与比较各 $O(n+m)$，`gcd` 为 $O(\log \min(n,m))$，取前缀 $O(g)$。
- **空间**：$O(n + m)$ 用于拼接产生的临时字符串；若改为逐位比较（不真正拼接）可降到 $O(1)$。

## 7. 参考代码

### C++

```cpp
#include <numeric>
#include <string>
using namespace std;

class Solution {
public:
    string gcdOfStrings(string str1, string str2) {
        if (str1 + str2 != str2 + str1) return "";
        return str1.substr(0, gcd((int)str1.size(), (int)str2.size()));
    }
};
```

### Python

```python
from math import gcd


class Solution:
    def gcdOfStrings(self, str1: str, str2: str) -> str:
        if str1 + str2 != str2 + str1:
            return ""
        return str1[:gcd(len(str1), len(str2))]
```

## 8. 边界情况与易错点

1. **两串相等**：如 `ABC` / `ABC`，拼接相等，$g = 3$，返回 `ABC` 本身。
2. **其中一个是另一个的重复**：如 `ABAB` / `AB`，$g = 2$，返回 `AB`；不要误返回 `ABAB`。
3. **长度整除但结构不符**：`AAAAAB` / `AAA`，$g = 3$ 且长度都整除，但拼接不等，必须返回 `""`。这是最容易只判长度就出错的用例。
4. **单字符**：`A` / `A` → `A`；`A` / `AA` → `A`；`A` / `B` → `""`。
5. **`std::gcd` 需要 `<numeric>`**：C++17 起可用，漏头文件会编译失败；也可以手写 `while (b) { int t = a % b; a = b; b = t; }`。
6. **不要只比较前缀**：`str1 == str2` 不成立时仍可能有公共因子，必须检查整串的重复结构。
7. **返回空串而非 `nullptr`**：C++ 返回 `string`，`return ""` 即可。
