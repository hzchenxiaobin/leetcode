# LeetCode 使字符串中不同字符的数目相等 题解

## 1. 题目概述

- **标题 / 题号**：使字符串中不同字符的数目相等（#2531，medium）
- **链接**：https://leetcode.cn/problems/make-number-of-distinct-characters-equal/
- **来源**：LeetCode 第 327 场周赛 Q3
- **难度**：中等
- **标签**：哈希表、字符串、计数、枚举

**题意**：给定两个下标从 $0$ 开始的字符串 `word1` 和 `word2`。一次**移动**：任选下标 $i \in [0, n_1)$ 与 $j \in [0, n_2)$，交换 `word1[i]` 与 `word2[j]`。问能否通过**恰好一次移动**，使 `word1` 与 `word2` 中**不同字符的数目相等**；能返回 `true`，否则 `false`。

**约束**：

- $1 \le \text{word1.length},\ \text{word2.length} \le 10^5$
- `word1`、`word2` 仅由小写英文字母组成

> 💡 **赛场信号**：串长高达 $10^5$，但字符集只有 $26$ 个小写字母；而「不同字符数」是**频次的函数**、与字符所处下标无关——这把 $10^5 \times 10^5$ 的下标对搜索直接压缩成 $26 \times 26 = 676$ 个**字符对**枚举。识别出「小字符集 + 位置无关的聚合量」这对信号，本题就只剩实现细节与两个分支陷阱。

> 💡 本题另有[每日题解 2531](../../solution/2501-2600/2531_使字符串中不同字符的数目相等.md)，侧重「增量判定与空操作陷阱」的直觉铺陈与面试问答。本文作为周赛复盘，聚焦**从信号到代码的最短路径**与**枚举完备性的引理-定理证明**，两篇互为印证。

## 2. 示例

**示例 1**

```text
输入：word1 = "ac", word2 = "b"
输出：false
解释：任何交换后 word1 恒有 2 种字符、word2 恒有 1 种，永不相等。
```

**示例 2**

```text
输入：word1 = "abcc", word2 = "aab"
输出：true
解释：交换 word1[2]='c' 与 word2[0]='a'，得 word1="abac"（3 种）、word2="cab"（3 种）。
```

**示例 3**

```text
输入：word1 = "abcde", word2 = "fghij"
输出：true
解释：两串各 5 种、无公共字符且频次全为 1，任意交换后仍各 5 种。
```

**示例 4（自构造：本就相等却无解）**

```text
输入：word1 = "ab", word2 = "ccdd"
输出：false
解释：两串本就各 2 种，但无公共字符可做「空操作」交换；任意 x≠y 交换使 word1 仍 2 种、word2 变 3 种。
```

## 3. 解题思路

### 3.1 暴力思路：枚举所有下标对 (i, j)

双重循环枚举 $i$、$j$，真的交换 `word1[i]` 与 `word2[j]`，再各扫一遍统计两串不同字符数是否相等（回溯恢复）。下标对共 $n_1 n_2 \le 10^{10}$ 个、每对统计 $O(n_1+n_2)$，总量约 $10^{15}$，必然超时。即便用频次表把「统计」降到 $O(26)$，$10^{10}$ 对的枚举本身就不可行。

> ⚠️ 暴力暴露的浪费：拿 `word1` 中任意两个同为 $x$ 的下标去交换，结果完全一样——「不同字符数」只认**字符**不认**位置**，同一字符对 $(x, y)$ 的所有下标组合被重复枚举了千万次。

### 3.2 核心观察：位置无关 ⇒ 下标对降维成字符对 + 频次增量

![核心观察：不同字符数与位置无关，10^10 个下标对压缩为 676 个字符对](images/wc327_q3_dimension_reduction.svg)

**第一步（降维）**：一次移动的全部效果 =「`word1` 交出字符 $x$、收进字符 $y$；`word2` 反之」，其中 $x=$ `word1[i]`、$y=$ `word2[j]`。设 $cnt_1[\cdot]$、$cnt_2[\cdot]$ 为两串频次表，$d_1$、$d_2$ 为两串不同字符数，则只需枚举满足 $cnt_1[x]>0$、$cnt_2[y]>0$ 的字符对 $(x, y)$——每个这样的字符对都能找到真实下标落地，且覆盖全部下标对、不重不漏（§5 引理 1）。$26 \times 26 = 676$ 对，每对 $O(1)$ 判定。

**第二步（增量）**：对 $x \neq y$，交换后两串不同数只有四个频次桶各跨一次「存在性」门槛：

![交换字符对时四个频次桶各自跨越 0 与 1 门槛的增量判定](images/wc327_q3_bucket_thresholds.svg)

$$
\text{nd}_1 = d_1 - [\,cnt_1[x]=1\,] + [\,cnt_1[y]=0\,],\qquad
\text{nd}_2 = d_2 - [\,cnt_2[y]=1\,] + [\,cnt_2[x]=0\,].
$$

「失 $x$」让 $cnt_1[x]$ 减 $1$，只有从 $1$ 跨到 $0$ 才少一种；「得 $y$」让 $cnt_1[y]$ 加 $1$，只有从 $0$ 跨到 $1$ 才多一种。$x \neq y$ 时四个判定落在四个互不相同的（串, 桶）格子里，**两两独立、可直接相加**。只要 $\text{nd}_1 = \text{nd}_2$ 即返回 `true`。

> ⚠️ **$x = y$ 是空操作，必须单独分流**：交换两个相同字符是**合法移动**（题面未禁止），此时 `word1` 失一个 $x$ 又得一个 $x$、`word2` 同理，频次与不同数**原封不动**。若对 $x=y$ 套增量公式，「失判 $cnt[x]=1$」与「得判 $cnt[x]=0$」针对同一桶、互相矛盾，必然算错。故 $x=y$ 分支只判：本就 $d_1 = d_2$ 则返回 `true`，否则跳过。

### 3.3 算法流程

![算法流程：统计频次、枚举字符对、空操作分支与增量判定](images/wc327_q3_flow.svg)

```text
预处理：cnt1/cnt2 频次表，d1/d2 不同字符数
for x in 'a'..'z' if cnt1[x] > 0:
    for y in 'a'..'z' if cnt2[y] > 0:
        if x == y:
            if d1 == d2: return true     # 空操作，本就相等
            continue
        nd1 = d1 - (cnt1[x]==1) + (cnt1[y]==0)
        nd2 = d2 - (cnt2[y]==1) + (cnt2[x]==0)
        if nd1 == nd2: return true
return false
```

瓶颈在初始建频次表 $O(n_1+n_2)$；双层循环至多 $676$ 次、每次 $O(1)$，与串长无关。

### 3.4 示例演算

![示例演算：abcc 与 aab 交换 c 和 a 的四项判定与两个对照案例](images/wc327_q3_walkthrough.svg)

以**示例 2** 演算（$cnt_1$：a1 b1 c2，$d_1=3$；$cnt_2$：a2 b1，$d_2=2$）。枚举到 $x=$ `c`、$y=$ `a`（$x \neq y$）：

| 增量项 | 判定 | 值 | 说明 |
|--------|------|----|------|
| word1 失 c | $cnt_1[c]=2 \neq 1$ | $0$ | 还剩 1 个 c，不少一种 |
| word1 得 a | $cnt_1[a]=1 \neq 0$ | $0$ | a 原本就在，不多一种 |
| word2 失 a | $cnt_2[a]=2 \neq 1$ | $0$ | 还剩 1 个 a，不少一种 |
| word2 得 c | $cnt_2[c]=0$ | $+1$ | word2 原无 c，多一种 |

$\text{nd}_1 = 3 + 0 + 0 = 3$、$\text{nd}_2 = 2 + 0 + 1 = 3$，相等 → `true`。交换后 `word1="abac"`（3 种）、`word2="cab"`（3 种），印证。

- **例 3**（`abcde`/`fghij`）：无公共字符、频次全 $1$，任意 $x \neq y$ 都有 $\text{nd}_1 = 5-1+1 = 5$、$\text{nd}_2 = 5-1+1 = 5$ → `true`。
- **例 4**（`ab`/`ccdd`）：$d_1=d_2=2$ 但无公共字符，$x=y$ 分支不可达；任意 $x \neq y$ 有 $\text{nd}_1 = 2-1+1=2$、$\text{nd}_2 = 2-0+1=3$ → `false`。**本就相等 ≠ 有解**。

## 4. 算法细节

1. **频次表用定长数组**：`array<int,26>` / `[0]*26`，下标 $O(1)$ 访问，比 `unordered_map` / `Counter` 常数更小、代码更短。
2. **$d_1$、$d_2$ 预处理一次**：循环内只算四项**增量**、不重扫频次表，保证每字符对 $O(1)$。若每对重扫 $O(26)$ 也能过（$676 \times 26$ 的常数），但没必要。
3. **$x=y$ 分支放在最前**：先 `continue` 掉空操作对，避免落入增量公式被双重计数。
4. **枚举范围带存在性过滤**：外层只遍历 $cnt_1[x]>0$、内层只遍历 $cnt_2[y]>0$ 的字符，最坏 $26 \times 26$ 对，实际往往更少。
5. **「恰好一次」的语义**：题目要求必须做一次移动，但**交换两个相同字符也是合法移动**——这正是空操作分支存在的理由，也是「$d_1=d_2$ 时仍可能有解」的唯一通道（见示例 4 的反面：无公共字符时该通道关闭）。

## 5. 正确性证明

**引理 1（归约完备性）**：一次移动后的不同字符数 $(d_1', d_2')$ 只依赖被交换的字符对 $(x, y) = (\text{word1}[i],\ \text{word2}[j])$，与具体下标无关；反之，任一满足 $cnt_1[x]>0$、$cnt_2[y]>0$ 的字符对 $(x, y)$ 都存在合法下标 $(i, j)$ 实现之。

**证明**：交换只使 $cnt_1[x]$、$cnt_1[y]$、$cnt_2[y]$、$cnt_2[x]$ 各变化 $\pm 1$，其余桶不变，而不同字符数是频次向量的函数，故 $(d_1', d_2')$ 由 $(x, y)$ 完全决定。存在性：$cnt_1[x]>0$ 说明 `word1` 中存在下标 $i$ 使 `word1[i]` $= x$，$cnt_2[y]>0$ 同理，取这组 $(i, j)$ 即为合法移动。∎

**引理 2（增量公式）**：$x \neq y$ 时，交换后两串不同数恰为

$$
\text{nd}_1 = d_1 - [cnt_1[x]=1] + [cnt_1[y]=0],\qquad
\text{nd}_2 = d_2 - [cnt_2[y]=1] + [cnt_2[x]=0].
$$

**证明**：以 `word1` 为例。失 $x$ 使 $cnt_1[x]$ 减 $1$：当且仅当 $cnt_1[x]=1$（桶从非空变空）时 $d_1$ 减 $1$，否则不变。得 $y$ 使 $cnt_1[y]$ 加 $1$：当且仅当 $cnt_1[y]=0$（桶从空变非空）时 $d_1$ 加 $1$，否则不变。$x \neq y$ 保证这两个桶不同，两个判定独立、可相加；`word2` 一侧对称。∎

**引理 3（空操作）**：$x = y$ 时，交换后两串的频次向量与不同数均不变，即 $(\text{nd}_1, \text{nd}_2) = (d_1, d_2)$。

**证明**：`word1` 失一个 $x$ 的同时得一个 $x$，$cnt_1[x]$ 不变、其余桶不受影响；`word2` 同理。频次向量不变，其函数（不同数）自然不变。∎

**定理**：算法返回 `true` 当且仅当存在合法的一次移动使两串不同字符数相等。

**证明**：（⇐）设移动 $(i, j)$ 使相等。令 $(x, y) = (\text{word1}[i], \text{word2}[j])$，则 $cnt_1[x]>0$、$cnt_2[y]>0$，该字符对必被枚举到；由引理 2、3，算法对它算出的 $(\text{nd}_1, \text{nd}_2)$ 即该次移动后的真实不同数，二者相等，算法返回 `true`。（⇒）设算法因某字符对 $(x, y)$ 判定 $\text{nd}_1 = \text{nd}_2$ 而返回 `true`。由引理 1，存在合法下标实现该字符对的交换；由引理 2、3，交换后的真实不同数恰为 $(\text{nd}_1, \text{nd}_2)$，相等。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n_1 + n_2 + 26^2) = O(n_1 + n_2)$。建两张频次表线性扫描；字符对至多 $676$ 个、每对四项 $O(1)$ 判定，是与串长无关的常数。代入 $10^5$ 级串长约 $2 \times 10^5 + 676$ 次基本操作，毫秒级。
- **空间复杂度**：$O(1)$。两张 $26$ 元频次表与常数个标量，与输入规模无关。
- **对照暴力**：$O(n_1 n_2 (n_1 + n_2))$ 最坏约 $10^{15}$；即便统计优化到 $O(26)$，$10^{10}$ 的枚举量仍不可行——降维是唯一出路。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool isItPossible(string word1, string word2) {
        array<int, 26> c1{}, c2{};
        for (char ch : word1) ++c1[ch - 'a'];
        for (char ch : word2) ++c2[ch - 'a'];
        int d1 = 0, d2 = 0;
        for (int i = 0; i < 26; ++i) {
            d1 += c1[i] > 0;
            d2 += c2[i] > 0;
        }
        for (int x = 0; x < 26; ++x) {
            if (!c1[x]) continue;
            for (int y = 0; y < 26; ++y) {
                if (!c2[y]) continue;
                if (x == y) {                       // 空操作：失即得，频次不动
                    if (d1 == d2) return true;
                    continue;
                }
                int nd1 = d1 - (c1[x] == 1) + (c1[y] == 0);
                int nd2 = d2 - (c2[y] == 1) + (c2[x] == 0);
                if (nd1 == nd2) return true;
            }
        }
        return false;
    }
};
```

> 💡 布尔表达式 `c1[x] == 1` 在 C++ 中自动转 $0/1$，增量公式可直译成一行。频次表用 `array<int,26>` 并以 `{}` 值初始化清零，避免 `vector` 的堆分配。

### Python

```python
class Solution:
    def isItPossible(self, word1: str, word2: str) -> bool:
        c1, c2 = [0] * 26, [0] * 26
        for ch in word1:
            c1[ord(ch) - 97] += 1
        for ch in word2:
            c2[ord(ch) - 97] += 1
        d1 = sum(v > 0 for v in c1)
        d2 = sum(v > 0 for v in c2)
        for x in range(26):
            if not c1[x]:
                continue
            for y in range(26):
                if not c2[y]:
                    continue
                if x == y:                          # 空操作：失即得，频次不动
                    if d1 == d2:
                        return True
                    continue
                nd1 = d1 - (c1[x] == 1) + (c1[y] == 0)
                nd2 = d2 - (c2[y] == 1) + (c2[x] == 0)
                if nd1 == nd2:
                    return True
        return False
```

> 💡 Python 中 `True`/`False` 参与算术时即 $1/0$，`(c1[x] == 1)` 可直接进增量公式。两版逻辑一致，均 $O(n_1+n_2+26^2)$ 时间、$O(1)$ 空间。

## 8. 边界情况与易错点

1. **$x=y$ 空操作分支不可省**：`word1="a"`、`word2="a"` 时唯一可交换的就是同一个字符 `a`，无任何 $x \neq y$ 对，全靠空操作分支命中「本就相等」。若把 $x=y$ 也套增量公式，`cnt[a]==1` 与 `cnt[a]==0` 两个判定互相矛盾，必然算错。
2. **$d_1=d_2$ 不能直接返回 true**：见示例 4（`ab`/`ccdd`）——两串本就相等，但既无公共字符做空操作、任何 $x \neq y$ 交换又把 `word2` 撑到 $3$ 种。必须逐对枚举验证：「恰好一次移动」是硬约束，不是可选装饰。
3. **四个判定别写反**：失判 $cnt=1$（频次归零才减）、得判 $cnt=0$（从无到有才增）。写成失判 $cnt=0$ / 得判 $cnt=1$ 是方向搞反，示例 2 都过不了。
4. **内外层字符的归属别串门**：$x$ 必须来自 `word1`（$cnt_1[x]>0$）、$y$ 来自 `word2`（$cnt_2[y]>0$）；$\text{nd}_2$ 里判的是 $cnt_2[y]$（失）与 $cnt_2[x]$（得），交叉引用极易写错。
5. **「不同字符数」与「出现次数」别混淆**：判定的门槛是频次跨 $0$ 的存在性边界，与频次具体多大（$2$ 还是 $10^5$）无关——失一个 $c$ 后剩不剩 $c$ 才是关键。
6. **无溢出风险**：计数 $\le 10^5$、增量 $|\Delta d| \le 2$，`int` 足够，无需 `long long`。
