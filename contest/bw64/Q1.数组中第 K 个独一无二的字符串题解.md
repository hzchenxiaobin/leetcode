# LeetCode 数组中第 K 个独一无二的字符串 题解

## 1. 题目概述

- **标题 / 题号**：数组中第 K 个独一无二的字符串（#2053，easy）
- **链接**：https://leetcode.cn/problems/kth-distinct-string-in-an-array/
- **来源**：LeetCode 第 64 场双周赛 Q1
- **难度**：简单
- **标签**：数组、哈希表、字符串、计数

**题意**：字符串数组 `arr` 中，**独一无二**的字符串指在 `arr` 中恰好出现一次的字符串。给定整数 $k$，返回 `arr` 中第 $k$ 个独一无二的字符串（按**原数组出现顺序**计）；若独一无二的字符串少于 $k$ 个，返回空字符串 `""`。

**约束**：

- $1 \le k \le arr.length \le 1000$
- $1 \le arr[i].length \le 5$，`arr[i]` 只含小写英文字母

## 2. 示例

**示例 1**

```text
输入：arr = ["d","b","c","b","c","a"], k = 2
输出："a"
解释："d" 与 "a" 各出现一次，是全部独一无二字符串。
按出现顺序第 1 个是 "d"，第 2 个是 "a"，故返回 "a"。
```

**示例 2**

```text
输入：arr = ["aaa","aa","a"], k = 1
输出："aaa"
解释：三个字符串都只出现一次，第 1 个是 "aaa"。
```

**示例 3**

```text
输入：arr = ["a","b","a"], k = 3
输出：""
解释：独一无二的字符串只有 "b" 一个，不足 3 个，返回空串。
```

## 3. 解题思路

### 3.1 暴力思路

对每个 `arr[i]`，用 `arr.count(arr[i])`（或双重循环）统计出现次数，为 1 时计入独一无二的序列，数到第 $k$ 个返回。时间 $O(n^2 \cdot L)$（$L$ 为串长，字符串比较开销），$n \le 1000$ 时约 $10^6$ 次比较，可以通过但毫无必要——瓶颈在**重复统计**：同一个字符串被反复数了多遍。

### 3.2 核心观察：先一遍计数，再一遍按序筛选

![核心观察：两遍扫描——先建频次表，再按原序数第 k 个唯一串](images/bw64_q1_two_pass.svg)

出现次数是**全数组的属性**，与位置无关，所以可以第一遍用哈希表把每个字符串的频次一次性统计完（$O(n)$）；第二遍按原顺序扫描，遇到频次恰为 1 的字符串就把计数器减一，减到 0 时它就是答案。两遍都是线性，总 $O(n)$。

这里的通用套路是"**计数与查询分离**"：任何"按条件筛选 + 保序输出"的问题，都可以拆成"预处理频次（或前缀信息）+ 顺序遍历判定"，避免在遍历中做昂贵的重复统计。

### 3.3 算法流程

```text
1. cnt ← 空哈希表
2. for s in arr: cnt[s] += 1          # 第一遍：统计频次
3. for s in arr:                        # 第二遍：按原序筛选
       若 cnt[s] == 1：
           k -= 1
           若 k == 0：返回 s
4. 返回 ""
```

### 3.4 示例演算

![示例演算：频次表过滤出第 k 个唯一串](images/bw64_q1_walkthrough.svg)

以示例 1（`arr = ["d","b","c","b","c","a"]`，$k = 2$）为例：

| 步骤 | 当前串 | 频次表状态（第一遍结束后） | 是否唯一 | $k$ 变化 |
|------|--------|---------------------------|----------|----------|
| 第一遍 | — | d:1, b:2, c:2, a:1 | — | — |
| 第二遍 1 | "d" | d:1 | ✓ | 2 → 1 |
| 第二遍 2 | "b" | b:2 | ✗ | 1 |
| 第二遍 3 | "c" | c:2 | ✗ | 1 |
| 第二遍 4 | "b" | b:2 | ✗ | 1 |
| 第二遍 5 | "c" | c:2 | ✗ | 1 |
| 第二遍 6 | "a" | a:1 | ✓ | 1 → 0，返回 "a" |

## 4. 算法细节

1. **哈希表选择**：Python `collections.Counter` / `dict`，C++ `unordered_map<string, int>`，平均 $O(1)$ 每次。$n \le 1000$、串长 $\le 5$，即使 `map`（红黑树，$O(\log n)$）也绰绰有余。
2. **第二遍必须按原顺序**：题目要求"按字符串在原数组中的顺序"找第 $k$ 个，哈希表本身无序，不能直接对表遍历。
3. **重复串只在其第一次出现时也会被跳过**：频次 $\ge 2$ 的串在所有出现位置都被筛掉，不会误计。
4. **空串返回值**：不足 $k$ 个时返回 `""`。注意 `arr[i]` 本身长度 $\ge 1$，空串不可能与元素混淆。
5. **一遍半写法（可选）**：也可以第一遍计数、第二遍把唯一串收进列表再取第 $k$ 个，等价；直接边扫边减 $k$ 少建一个列表。

## 5. 正确性证明

**引理 1（频次表正确性）**：第一遍扫描后，$cnt[s]$ 等于 $s$ 在 `arr` 中的出现次数。

**证明**：初始 $cnt$ 为空。逐个处理 `arr[i]` 时执行 $cnt[arr[i]] \mathrel{+}= 1$，归纳可知处理完前 $t$ 个元素后 $cnt[s]$ 等于 $s$ 在前 $t$ 个元素中的出现次数；$t = n$ 时即全局出现次数。∎

**引理 2（筛选序列刻画）**：第二遍扫描中，被标记"唯一"的字符串恰好构成"按原序排列的独一无二的字符串序列"，且每个这样的字符串恰被标记一次（在其每个出现位置上判定，频次为 1 时它只有一个出现位置）。

**证明**：某字符串 $s$ 在扫描中被判定为唯一 ⇔ $cnt[s] = 1$ ⇔（由引理 1）$s$ 在 `arr` 中恰好出现一次 ⇔ $s$ 是独一无二的字符串。独一无二字符串只有一个出现位置，故其判定只发生一次；扫描顺序与原数组顺序一致，故判定序列 = 独一无二字符串的原序序列。∎

**定理（算法正确）**：若独一无二字符串不少于 $k$ 个，算法返回其原序第 $k$ 个；否则返回 `""`。

**证明**：由引理 2，第二遍中对第 $j$ 个独一无二的字符串判定时计数器从 $k - j + 1$ 减为 $k - j$。当独一无二字符串总数 $m \ge k$ 时，第 $k$ 个的判定使计数器恰减为 $0$，算法在该位置返回该字符串，且之前的判定都不会触发返回（计数器 $> 0$）。当 $m < k$ 时，扫描结束后计数器 $= k - m > 0$，从未触发返回，算法执行到第 4 步返回 `""`。∎

## 6. 复杂度分析

- **时间**：$O(n)$ 次哈希操作，每次涉及长度 $\le 5$ 的字符串哈希/比较，总计 $O(n \cdot L)$（$L \le 5$ 视作常数即 $O(n)$）。暴力 $O(n^2 \cdot L)$ 的优化点在于每串只统计一次。
- **空间**：$O(n \cdot L)$。哈希表至多存 $n$ 个键，每个键长度 $\le L$；最坏（全部唯一）即 $O(n)$ 个条目。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    string kthDistinct(vector<string>& arr, int k) {
        unordered_map<string, int> cnt;
        for (const string& s : arr) ++cnt[s];
        for (const string& s : arr)
            if (cnt[s] == 1 && --k == 0) return s;
        return "";
    }
};
```

### Python

```python
class Solution:
    def kthDistinct(self, arr: List[str], k: int) -> str:
        cnt = Counter(arr)
        for s in arr:
            if cnt[s] == 1:
                k -= 1
                if k == 0:
                    return s
        return ""
```

> 💡 两份代码均通过官方全部 3 组示例，并与"逐串 `list.count` + 按序收集唯一串取第 k 个"的暴力实现做了 300 组随机对拍（含全部重复、全部唯一、$k$ 越界等边界），结果完全一致。

## 8. 边界情况与易错点

1. **$k$ 大于唯一串个数**：返回 `""`，不要返回最后一个唯一串或越界访问。
2. **全部字符串都重复 / 都唯一**：前者直接落到返回 `""`；后者答案是原数组第 $k$ 个元素。
3. **"独一无二"是全局频次，不是相邻去重**：`["a","b","a"]` 中 "b" 唯一，别用相邻比较（`arr[i] != arr[i-1]`）的思路，那是错误的去重语义。
4. **保持原序**：第二遍遍历必须走原数组而不是遍历哈希表——哈希表遍历顺序不确定（Python 3.7+ 的 dict 保插入序，但 `Counter` 上取"第 k 个"的写法仍不如显式两遍清晰可靠）。
5. **C++ 哈希表参数**：`unordered_map<string,int>` 默认哈希对短串已足够快；$n = 1000$ 无需自定义哈希或预留桶。
6. **空串与输出**：返回类型是 `string`，`""` 即空串；Python 侧 `""` 同理，不要返回 `None`。
