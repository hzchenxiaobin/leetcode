# LeetCode 数组元素相等的最小操作次数 题解

## 1. 题目概述

- **标题 / 题号**：数组元素相等的最小操作次数（#3674，easy）
- **链接**：https://leetcode.cn/problems/minimum-operations-to-equalize-array/
- **来源**：LeetCode 第 466 场周赛 Q1
- **难度**：简单
- **标签**：位运算、脑筋急转弯、数组

**题意**：给定长度为 $n$ 的整数数组 `nums`。一次操作可以任选一个子数组 `nums[l...r]`（$0 \le l \le r < n$），把该子数组中的**每个元素**都替换成子数组内**所有元素的按位与（AND）**。返回使数组所有元素相等的最小操作次数。

**约束**：

- $1 \le n = \text{nums.length} \le 100$
- $1 \le \text{nums}[i] \le 10^5$

## 2. 示例

**示例 1**

```text
输入：nums = [1,2]
输出：1
解释：选择 nums[0...1]：(1 AND 2) = 0，数组变为 [0, 0]，一次操作后全部相等。
```

**示例 2**

```text
输入：nums = [5,5,5]
输出：0
解释：数组本身已全部相等，无需任何操作。
```

**示例 3（补充）**

```text
输入：nums = [1,2,4]
输出：1
解释：选整个数组：1 AND 2 AND 4 = 0，数组变为 [0, 0, 0]。
```

## 3. 解题思路

### 3.1 暴力思路

容易把问题想复杂：枚举每次操作选哪段子数组、操作后数组状态如何演化，BFS/记忆化搜索所有可达状态求最短路。$n \le 100$ 时状态空间是天文数字，完全不可行——也完全没有必要。

### 3.2 核心观察：整个数组就是一个合法的子数组

![整个数组也是合法子数组，一次操作即全相等](images/equalize_and_operation.svg)

操作允许 $l = 0,\ r = n-1$，即**整个数组**本身就是一种合法选择。对整个数组做一次操作，所有元素都变成同一个值 $\text{AND}(\text{nums}[0..n-1])$——一次操作必然让全部元素相等。

于是答案只有两种可能：

$$\text{ans} = \begin{cases} 0, & \text{初始已全部相等} \\ 1, & \text{否则} \end{cases}$$

### 3.3 算法流程

![决策流程：判断是否已全相等](images/equalize_and_decision_flow.svg)

1. 遍历数组，检查是否存在 `nums[i] != nums[0]`；
2. 若存在不相等的元素，返回 `1`；
3. 否则返回 `0`。

### 3.4 示例演算

| 输入 | 是否已全相等 | 一次操作（选 $[0, n-1]$） | 答案 |
|------|--------------|---------------------------|------|
| `[5,5,5]` | 是 | — | 0 |
| `[1,2]` | 否 | `1 AND 2 = 0` → `[0,0]` | 1 |
| `[1,2,4]` | 否 | `1 AND 2 AND 4 = 0` → `[0,0,0]` | 1 |
| `[6,7,6]` | 否 | `6 AND 7 AND 6 = 6` → `[6,6,6]` | 1 |

注意 `[6,7,6]` 这个例子：最终相等值不一定变成 `0`，AND 结果是多少无所谓，只要全相等即可。

## 4. 算法细节

1. **只需判等**：整个算法只需回答"数组是否已经全部相等"，一个线性扫描 `all(x == nums[0] for x in nums)` 即可。
2. **不需要真的计算 AND**：虽然操作语义是按位与，但最终值不影响操作次数，无需求出它。
3. **单元素数组**：$n = 1$ 时天然全相等，答案为 0，扫描逻辑自动覆盖。
4. **数值范围**：$1 \le \text{nums}[i] \le 10^5$，`int` 足够，且元素均正数，与常见"非负"陷阱无关。

## 5. 正确性证明

**引理 1**：对整个数组（$l=0,\ r=n-1$）执行一次操作后，所有元素相等。

**证明**：设 $V = \text{nums}[0] \wedge \text{nums}[1] \wedge \cdots \wedge \text{nums}[n-1]$（$\wedge$ 为按位与）。由操作定义，子数组 $[0, n-1]$ 内每个元素都被替换为该子数组所有元素的 AND，即 $V$。故操作后数组为 $[V, V, \ldots, V]$，全部相等。∎

**引理 2**：0 次操作可行，当且仅当初始数组已全部相等。

**证明**：0 次操作意味着数组保持原样，"所有元素相等"成立当且仅当初始时就成立。∎

**定理**：最小操作次数为 0（若初始全相等），否则为 1。

**证明**：初始全相等时，由引理 2 知 0 次可行且次数非负，答案为 0。初始不全相等时，由引理 2 知 0 次不可行，故答案 $\ge 1$；由引理 1 知 1 次可行，故答案 $\le 1$。两者结合，答案恰为 1。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。单次遍历判断所有元素是否等于 `nums[0]`。
- **空间复杂度**：$O(1)$。仅使用常数个额外变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minOperations(vector<int>& nums) {
        for (int x : nums) {
            if (x != nums[0]) {
                return 1;
            }
        }
        return 0;
    }
};
```

### Python

```python
class Solution:
    def minOperations(self, nums: List[int]) -> int:
        return 0 if all(x == nums[0] for x in nums) else 1
```

## 8. 边界情况与易错点

1. **想复杂了**：本题是脑筋急转弯。纠结"选哪段子数组最优""AND 之后会不会破坏其他部分"都会走进死胡同——整个数组一次选完即终结游戏。
2. **误以为答案是 0 或"必须变成 0"**：最终相等值可以是任意 AND 结果（如 `[6,7,6]` 变成 `[6,6,6]`），题目只要求相等，不要求特定值。
3. **单元素 / 全相同**：$n = 1$ 或所有元素相同时返回 0，不要漏判。
4. **子数组定义**：$0 \le l \le r < n$ 明确允许 $l = 0, r = n-1$，"整个数组是不是子数组"不需要任何额外讨论。
