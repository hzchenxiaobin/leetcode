# LeetCode 最大和最小 K 个元素的绝对差 题解

## 1. 题目概述

- **标题 / 题号**：最大和最小 K 个元素的绝对差（#3774，easy）
- **链接**：https://leetcode.cn/problems/absolute-difference-between-maximum-and-minimum-k-elements/
- **来源**：LeetCode 第 480 场周赛 Q1
- **难度**：简单
- **标签**：数组、排序

**题意**：给定整数数组 `nums` 和整数 `k`，分别计算数组中 **k 个最大元素的总和**与 **k 个最小元素的总和**，返回两者的绝对差。

**约束**：

- `1 <= n == nums.length <= 100`
- `1 <= nums[i] <= 100`
- `1 <= k <= n`

> 💡 **读题关键**："k 个最大/最小元素"按**出现次数计重**选取，不是去重后的值——示例 1 中 `[5,2,2,4]` 的 `k=2` 个最小元素是 `2` 和 `2`（两个 2 都要选）。

## 2. 示例

**示例 1**

```text
输入：nums = [5,2,2,4], k = 2
输出：5
解释：k=2 个最大元素是 4 和 5，总和为 9；
      k=2 个最小元素是 2 和 2，总和为 4；
      绝对差 = |9 - 4| = 5
```

**示例 2**

```text
输入：nums = [100], k = 1
输出：0
解释：最大元素与最小元素都是 100，|100 - 100| = 0
```

**补充示例 3**（两端窗口重叠的情况）

```text
输入：nums = [1,3,5,7,9], k = 3
输出：12
解释：k=3 个最大元素是 5、7、9，总和为 21；
      k=3 个最小元素是 1、3、5，总和为 9；
      绝对差 = 21 - 9 = 12
      注意 5 同时出现在两个和里，做差时被抵消
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有大小为 `k` 的子集，分别求和后取最大、最小。子集数为 $\binom{100}{50} \approx 10^{29}$，显然不可行。

其实"选 k 个数使和最大/最小"本身就是**贪心**可解的：和最大就选最大的 k 个，和最小就选最小的 k 个——根本不需要枚举。

### 3.2 核心观察：排序后，答案就在两端

![排序后两端各取 k 个](images/w480_q1_sorted_ends.svg)

将数组升序排序后：

- **最小的 k 个**恰是前缀 `a[0..k-1]`，其和记为 $S_{\min}$
- **最大的 k 个**恰是后缀 `a[n-k..n-1]`，其和记为 $S_{\max}$

$$\text{answer} = S_{\max} - S_{\min} = \sum_{i=0}^{k-1} a[n-1-i] - \sum_{i=0}^{k-1} a[i]$$

由于 $S_{\max}$ 与 $S_{\min}$ 分别是所有 k 元子集和的**最大值**与**最小值**，必有 $S_{\max} \ge S_{\min}$，**绝对值符号可以直接去掉**。

**更进一步——配对视角**：把第 i 小与第 i 大配对相减。当 $2k > n$ 时两个窗口在中间重叠，重叠部分同时出现在两个和里，**做差时自动抵消**：

$$\text{answer} = \sum_{t=0}^{m-1} \big(a[n-1-t] - a[t]\big), \quad m = \min(k,\ n-k)$$

即答案只取决于两窗口的**对称差**。这直接解释了为什么 `k = n` 时答案恒为 0（对称差为空）。

![配对相减与重叠抵消](images/w480_q1_pairing_cancel.svg)

### 3.3 算法流程

1. 将 `nums` 升序排序；
2. 计算 `minSum`（前 `k` 个元素之和）与 `maxSum`（后 `k` 个元素之和）；
3. 返回 `maxSum - minSum`。

### 3.4 示例演算

以示例 1 为例，`nums = [5,2,2,4], k = 2`：

| 步骤 | 内容 | 结果 |
|------|------|------|
| 排序 | `[5,2,2,4]` → `[2,2,4,5]` | 升序 |
| 最小 k=2 | `2 + 2` | 4 |
| 最大 k=2 | `4 + 5` | 9 |
| 做差 | `9 - 4` | 5 |

用配对公式验证：$m = \min(2,2) = 2$，答案 $= (a_3 - a_0) + (a_2 - a_1) = (5-2) + (4-2) = 5$ ✓

补充示例 3：$m = \min(3,2) = 2$，答案 $= (9-1) + (7-3) = 12$ ✓（中间的 5 被抵消）。

## 4. 算法细节

1. **排序**：对 `nums` 原地升序排序，C++ 用 `sort`，Python 用 `list.sort()`。
2. **求和**：前 k 项与后 k 项分别累加；Python 可直接写 `sum(nums[:k])` 与 `sum(nums[-k:])`。
3. **数据规模**：$n \le 100$、$nums[i] \le 100$，最大和不超过 $10^4$，`int` 完全够用。
4. **可选优化**：值域仅 $[1,100]$，可用计数排序做到 $O(n + V)$；C++ 也可用 `nth_element` 平均 $O(n)$ 划分后分别对两段求和。对本题规模都属于杀鸡用牛刀。

## 5. 正确性证明

**引理 1（贪心选取）**：数组升序排序后，前 k 个元素之和是所有 k 元子集之和的最小值，后 k 个元素之和是最大值。

**证明**：交换论证。设某子集 $S$ 的和大于前 k 个元素之和，则 $S$ 中必含某下标 $j \ge k$ 的元素 $a[j]$，且某下标 $i < k$ 的元素 $a[i]$ 不在 $S$ 中。由排序 $a[i] \le a[j]$，把 $a[j]$ 换成 $a[i]$ 后和新子集之和不超过 $S$。反复交换直至 $S$ 恰为前 k 个元素，故前 k 个元素之和最小。对"后 k 个元素之和最大"同理（对称地将小元素换为大元素）。∎

**引理 2（非负性）**：$S_{\max} \ge S_{\min}$，绝对值符号可省略。

**证明**：由引理 1，$S_{\max}$ 与 $S_{\min}$ 是同一族数（所有 k 元子集之和，因 $k \le n$ 该族非空）的最大值与最小值，而一族数的最大值不小于其最小值。∎

**定理（对称差公式）**：$\text{answer} = \sum_{t=0}^{m-1} \big(a[n-1-t] - a[t]\big)$，其中 $m = \min(k, n-k)$，且每项非负。

**证明**：$S_{\max}$ 覆盖下标区间 $[n-k, n-1]$，$S_{\min}$ 覆盖 $[0, k-1]$。若 $2k > n$，两区间在 $[n-k, k-1]$ 上重叠，重叠区间的每个 $a[j]$ 在 $S_{\max} - S_{\min}$ 中一加一减、逐项抵消；若 $2k \le n$ 则两区间不交。两种情形下做差后剩余的下标配对恰为 $t$ 与 $n-1-t$（$t \in [0, m)$），即公式成立。又由 $t < m \le \lfloor n/2 \rfloor$ 得 $n-1-t > t$，由排序有 $a[n-1-t] \ge a[t]$，故每项非负。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \log n)$，排序主导；两次求和共 $O(k)$。改用计数排序可降为 $O(n + V)$（$V = 100$ 为值域）。
- **空间复杂度**：$O(1)$，原地排序仅需常数额外空间（忽略语言排序的递归栈开销）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int absDifference(vector<int>& nums, int k) {
        sort(nums.begin(), nums.end());
        int n = nums.size();
        int minSum = 0, maxSum = 0;
        for (int i = 0; i < k; i++) {
            minSum += nums[i];
            maxSum += nums[n - 1 - i];
        }
        return maxSum - minSum;
    }
};
```

### Python

```python
class Solution:
    def absDifference(self, nums: List[int], k: int) -> int:
        nums.sort()
        return sum(nums[-k:]) - sum(nums[:k])
```

## 8. 边界情况与易错点

1. **k = n**：两个窗口都是整个数组，答案恒为 0（对称差为空），无需特判。
2. **单元素**：`n = 1, k = 1`，最大最小都是该元素，答案为 0。
3. **重复元素计重**：`[5,2,2,4], k=2` 的最小两个是 `2` 和 `2`，不要按"去重后的值"误解成 `2` 和 `4`。
4. **绝对值可省**：$S_{\max} \ge S_{\min}$ 恒成立，直接相减即可；比赛时保留 `abs` 作为双保险也不失为稳妥写法。
5. **溢出**：本题最大和 $10^4$，`int` 足够；若值域扩大到 $10^9$ 且 $n$ 到 $10^5$，C++ 需改用 `long long`。
6. **别想复杂**：签到题的最短路径就是"排序 + 两端求和"，无需堆、快速选择等重武器。
