# LeetCode 竖直打印单词 题解

## 1. 题目概述

- **标题 / 题号**：竖直打印单词（#1324，medium）
- **链接**：https://leetcode.cn/problems/print-words-vertically/
- **来源**：LeetCode 第 172 场周赛 Q2
- **难度**：中等
- **标签**：数组、字符串、模拟

**题意**：给定一个只含大写字母、单词之间恰好一个空格的字符串 `s`，按单词出现的顺序把它们**竖着**排成若干列：第 $i$ 个单词占第 $i$ 列，它的第 $r$ 个字符落在第 $r$ 行的第 $i$ 列。若某个单词长度不足 $r+1$，该位置用空格补位；输出时**去掉每行末尾的空格**，返回按行号升序排列的字符串列表。

**约束**：

- `1 <= s.length <= 200`
- `s` 仅含大写英文字母
- 保证两个单词之间只有一个空格
- 返回值的长度等于**最长单词的长度**，每个字符串长度不超过单词数

> 💡 一句话抓住本质：把「单词列表」看成一个**按列存放的字符矩阵**，答案就是它按行读取的结果，只是每行要裁掉尾部的空格。

## 2. 示例

**示例 1**

```text
输入：s = "HOW ARE YOU"
输出：["HAY","ORO","WEU"]
解释：三个单词各占一列，行数 = 3（最长单词长度）
  H A Y   → "HAY"
  O R O   → "ORO"
  W E U   → "WEU"
```

**示例 2**

```text
输入：s = "TO BE OR NOT TO BE"
输出：["TBONTB","OEROOE","   T"]
解释：最长单词 "NOT" 长度为 3，共 3 行
  T B O N T B   → "TBONTB"
  O E R O O E   → "OEROOE"
        T       → "   T"（三个前导空格保留，尾部空格删除）
```

**示例 3**

```text
输入：s = "CONTEST IS COMING"
输出：["CIC","OSO","N M","T I","E N","S G","T"]
解释：共 7 行；"N M" 中间的空格是列对齐占位符，必须保留；
      最后一行拼出 "T  " 后去掉两个尾空格，只剩 "T"
```

## 3. 解题思路

### 3.1 暴力思路

最直白的做法是**真的把矩阵造出来**：

1. 切分出单词 `words`，令 `maxLen = max(len(w))`；
2. 造一个 `len(words) × maxLen` 的字符矩阵，把每个单词逐字符填入第 0 行到第 `len(w)-1` 行，其余格子填 `' '`；
3. 逐行拼接，再对每行做一次去尾空格。

这样时间 $O(n + W \cdot \text{maxLen})$，空间额外 $O(W \cdot \text{maxLen})$，其中 $W$ 是单词数。它完全能过（$n \le 200$，矩阵最多几千格），但**多了一次完整复制**：每个字符先写进矩阵、再读出来，纯属搬运。

更笨的写法还有两种常见弯路：

- 对每个单词先 `ljust(maxLen)` 补齐，再「按行」切片拼接——补出来的空格还得再删，一步没省；
- 用 `zip` 把单词列表转置后直接 `join`——`zip` 会在**最短**单词处截断，除非用 `zip_longest` 并指定 `fillvalue=' '`，否则行数就错了。

### 3.2 核心观察：列是单词，行是下标

![单词按列排列，逐行读取](images/wc172_q2_word_columns.svg)

关键在于**位置公式**。设 `words[i]` 是第 $i$ 个单词，答案的第 $r$ 个字符串为 `row[r]`，那么 `row[r]` 的第 $i$ 个字符是

$$
\text{row}[r][i] =
\begin{cases}
\text{words}[i][r], & r < \lvert \text{words}[i] \rvert \\
\text{' '}, & \text{否则}
\end{cases}
$$

也就是：**不需要补空格，只需要判断「越界就用空格」**。补位和裁剪是两个可以合并的动作——先在逻辑上补齐（用条件表达式），再在行尾统一裁掉。

行数同样由公式给出：只有 $r < \text{maxLen}$ 时，最长单词在第 $r$ 位才有字符，该行才非空。所以

$$\text{答案长度} = \max_i \lvert \text{words}[i] \rvert$$

> 💡 这就是本题的全部难点：**别把「补空格」当成字符串操作，把它当成一次数组越界判断**。

### 3.3 算法流程

![切词 → 求最长 → 逐行拼装 → 去尾空格](images/wc172_q2_simulation_flow.svg)

1. 按空格切分得到 `words`（题目保证单词之间只有一个空格，用 `split` 即可）；
2. `maxLen = max(len(w) for w in words)`；
3. 对 $r = 0, 1, \dots, \text{maxLen}-1$，顺序遍历每个单词，追加 `w[r]`（存在）或 `' '`（不存在）；
4. 对拼好的整行**去掉尾部空格**，追加进答案；
5. 返回答案列表。

顺序不能反：**先按列对齐拼完，再裁剪行尾**。如果先裁掉每个单词右侧的空白，再去拼行，中间那些「本该是空格」的位置就会错位——`"N M"` 会退化成 `"NM"`。

### 3.4 示例演算

![示例演算：CONTEST IS COMING](images/wc172_q2_walkthrough.svg)

以示例 3 为例，`words = ["CONTEST", "IS", "COMING"]`，`maxLen = 7`：

| 行 $r$ | CONTEST | IS | COMING | 拼出的原始行 | 去尾空格后 |
|--------|---------|----|--------|--------------|------------|
| 0 | C | I | C | `CIC` | `CIC` |
| 1 | O | S | O | `OSO` | `OSO` |
| 2 | N | ' ' | M | `N M` | `N M` |
| 3 | T | ' ' | I | `T I` | `T I` |
| 4 | E | ' ' | N | `E N` | `E N` |
| 5 | S | ' ' | G | `S G` | `S G` |
| 6 | T | ' ' | ' ' | `T  ` | `T` |

两个细节：第 2 行的空格处于**行中间**，是列对齐的必需品，所以保留；第 6 行末尾的两个空格在**行尾**，所以删掉，得到 `"T"`。

## 4. 算法细节

1. **切分方式**：Python 用 `s.split()`（默认按任意空白切分，天然丢弃多余空格，比 `split(' ')` 更稳）；C++ 没有现成的 split，用 `stringstream` 或手写一遍「遇空格收词、收尾补最后一个词」。注意**循环结束后要再判一次** `cur` 是否非空，否则最后一个单词会丢。
2. **行数取最长**：`maxLen` 必须遍历所有单词取最大值，不能用第一个或最后一个单词的长度；本题中「最长单词」决定了补位范围。
3. **越界判断的写法**：`r < len(w) ? w[r] : ' '`，等价于 `(w + ' ' * maxLen)[r]` 但省掉了补齐的复制；不要写成 `r <= len(w)-1`（在 `len(w)=0` 时会出错，虽然本题不会出现空词）。
4. **去尾空格的精确性**：Python 的 `s.rstrip()` 不带参数会连 `\t`、`\n` 一起删，本题只有大写字母和空格，写成 `s.rstrip(' ')` 语义更明确；C++ 用 `while (!row.empty() && row.back() == ' ') row.pop_back();`，**判空必须在前面**。
5. **中间空格不能删**：`"TO BE OR NOT TO BE"` 的第三行是 `"   T"`，前导空格必须保留；任何 `strip()`、`lstrip()`、`replace(" ", "")` 都会出错。
6. **预先 reserve**：C++ 里每行 `row.reserve(maxLen)`，整张答案 `ans.reserve(maxLen)`，避免频繁扩容（$n$ 小，属于习惯而非必需）。
7. **循环嵌套顺序**：外层枚举行 $r$、内层枚举单词 $i$，与公式一致；两层写反的话每行只能取到同一个单词的连续字符，结果完全不同。
8. **直接返回字符串列表**：不要额外排序或去重——单词顺序、行顺序都由题面固定，任何重排都是错的。

## 5. 正确性证明

**引理 1（列对齐）**：对每个 $r \in [0, \text{maxLen})$ 与每个 $i \in [0, W)$，算法在构造第 $r$ 行时追加的第 $i$ 个字符，等于「把 `words[i]` 右补空格到 `maxLen` 后」的第 $r$ 个字符。

**证明**：若 $r < \lvert \text{words}[i] \rvert$，算法追加 `words[i][r]`，而补空格后的第 $r$ 个字符仍是原字符，二者相同；若 $r \ge \lvert \text{words}[i] \rvert$，算法追加 `' '`，补空格后的第 $r$ 个字符恰好也是补出来的空格，二者相同。∎

**引理 2（行数正确）**：答案的行数恰好是 $\text{maxLen}$。

**证明**：设 $k$ 是使 $\lvert \text{words}[k] \rvert = \text{maxLen}$ 的下标。

- 对任意 $r < \text{maxLen}$，第 $r$ 行在第 $k$ 列处有字符 `words[k][r]`，故该行去掉尾空格后至少含一个字符，非空；
- 对任意 $r \ge \text{maxLen}$，所有单词都满足 $r \ge \lvert \text{words}[i] \rvert$，该行全为空格，去掉尾空格后是空串，题面要求的行中不含它。

故输出的行构成集合恰为 $[0, \text{maxLen})$。∎

**引理 3（行内无尾空格，且内部空格不被误删）**：算法输出的每个字符串都不以空格结尾，且原本位于行内部的空格全部保留。

**证明**：去尾空格只从右端删除连续的 `' '`，删除后右端不再是空格；而行内部（右侧仍存在字母）的空格不会被从右端删除，故保留。∎

**定理**：算法返回的列表与题面定义的竖直打印结果完全一致。

**证明**：由引理 2，行数与要求一致；对每个 $r$，由引理 1，第 $r$ 行在去尾空格前与「所有单词补空格后按列取第 $r$ 个字符」的拼接结果逐位相同，再配合引理 3 的裁剪规则，得到的字符串正是题面所要求的第 $r$ 个答案；外层循环按 $r$ 递增收集，顺序也一致。∎

## 6. 复杂度分析

- **时间**：$O(n + W \cdot \text{maxLen})$。切分单词扫一遍 $s$，$O(n)$；构造答案要输出 $W \cdot \text{maxLen}$ 个字符（含补位空格），每个字符 $O(1)$ 写入。由于 $n \le 200$，最坏也在 $10^4$ 次操作量级，远小于时间限制。注意这里**无法严格写成 $O(n)$**：补位空格的数量 $W \cdot \text{maxLen}$ 可以超过 $\lvert s \rvert$（例如一个长单词配很多单字符单词）。
- **空间**：$O(W + \text{maxLen})$ 的辅助空间（单词列表与单行缓冲），不含输出；若计入返回值则为 $O(W \cdot \text{maxLen})$。相比 3.1 的显式矩阵，省掉了整整一个二维数组。

## 7. 参考代码

### C++

```cpp
#include <string>
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    vector<string> printVertically(string s) {
        // 1. 手动切分：题目保证单词间只有一个空格
        vector<string> words;
        string cur;
        for (char c : s) {
            if (c == ' ') {
                if (!cur.empty()) { words.push_back(cur); cur.clear(); }
            } else {
                cur += c;
            }
        }
        if (!cur.empty()) words.push_back(cur);   // 别忘了最后一个单词

        // 2. 行数 = 最长单词长度
        int maxLen = 0;
        for (const auto& w : words) maxLen = max(maxLen, (int)w.size());

        // 3. 逐行拼装 + 去行尾空格
        vector<string> ans;
        ans.reserve(maxLen);
        for (int r = 0; r < maxLen; ++r) {
            string row;
            row.reserve(words.size());
            for (const auto& w : words) {
                row += (r < (int)w.size()) ? w[r] : ' ';   // 越界补空格
            }
            while (!row.empty() && row.back() == ' ') row.pop_back();  // 先判空
            ans.push_back(row);
        }
        return ans;
    }
};
```

### Python

```python
from typing import List


class Solution:
    def printVertically(self, s: str) -> List[str]:
        words = s.split()                    # 默认按空白切分，丢弃多余空格
        max_len = max(len(w) for w in words)  # 答案行数

        ans = []
        for r in range(max_len):
            # 越界就用空格占位，保证字符仍落在原来的列上
            row = [w[r] if r < len(w) else ' ' for w in words]
            ans.append(''.join(row).rstrip(' '))   # 只删行尾空格
        return ans
```

## 8. 边界情况与易错点

1. **单单词**：`s = "HELLO"` → `["H","E","L","L","O"]`。行数等于单词长度，每行只有一个字符，不能返回 `["HELLO"]`。
2. **全是单字符单词**：`s = "A B C"` → `["ABC"]`；`maxLen = 1`，只有一行，此时不需要任何补位。
3. **前导空格必须保留**：`"TO BE OR NOT TO BE"` 的答案是 `["TBONTB","OEROOE","   T"]`，第三个串以 3 个空格开头。误用 `strip()` 会得到 `"T"`，直接判错。
4. **行中间的空格必须保留**：`"CONTEST IS COMING"` 的 `"N M"`、`"T I"` 依赖中间空格对齐；先删空格再拼、或对每个单词做替换，都会破坏列结构。
5. **去尾空格要放到整行拼完之后**：先裁后拼会丢失列对齐信息；只有拼接完成，尾部空格才等价于「右侧没有更多字符」。
6. **C++ 切分漏掉最后一个单词**：循环里只处理了「遇到空格」的情况，循环结束后必须再 `push_back` 一次 `cur`，否则 `"HOW"` 这类没有尾部空格的输入会丢词。
7. **可能产生空行的错觉**：只要 $r < \text{maxLen}$，最长单词在该位必有字符，所以任何一行去尾空格后都非空；若真的写出空行，说明行数上界算错了（比如用了 `maxLen+1`）。
8. **不要额外排序或去重**：答案与单词顺序、行序严格对应，任何重排都会改变结果。

**延伸思考**：

1. 如果要求**所有行等长**（用空格补齐到单词数 $W$），只需把 `rstrip` 换成 `ljust(W)`，答案变成规整的 $ \text{maxLen} \times W $ 矩阵——这也是「转置后再补齐」的通用写法。
