# LeetCode 字符串解码 题解

## 1. 题目概述

- **标题 / 题号**：字符串解码（#394，medium）
- **链接**：https://leetcode.cn/problems/decode-string/
- **来源**：LeetCode 第 3 场周赛 Q3
- **难度**：中等
- **标签**：栈、递归、字符串

**题意**：给定一个合法的编码串，其中 `k[encoded_string]` 表示方括号内的内容**恰好重复** $k$ 次（$k$ 为正整数），且这种编码可以**任意嵌套**。串中其余字母原样保留，返回解码后的字符串。原串保证不含多余空格，数字只表示重复次数（不会出现 `3a`、`2[4]` 这类形式），括号总是成对合法。

**约束**：

- $1 \le \lvert s \rvert \le 30$
- `s` 仅由小写英文字母、数字和 `'['`、`']'` 组成
- `s` 保证是**有效**输入，所有整数的取值范围为 $[1, 300]$
- 测试用例保证**输出长度**不超过 $10^5$

## 2. 示例

**示例 1**

```text
输入：s = "3[a]2[bc]"
输出："aaabcbc"
解释：3[a] → "aaa"，2[bc] → "bcbc"，两段并列拼接。
```

**示例 2**

```text
输入：s = "3[a2[c]]"
输出："accaccacc"
解释：先解内层 2[c] → "cc"，与外层字母 a 拼成 "acc"，再整体重复 3 次。
```

**示例 3**

```text
输入：s = "2[abc]3[cd]ef"
输出："abcabccdcdcdef"
解释：末尾的 ef 不属于任何括号，直接接在解码结果之后。
```

**示例 4**

```text
输入：s = "abc3[cd]xyz"
输出："abccdcdcdxyz"
解释：括号前的 abc 属于外层前缀，原样保留在最前面。
```

## 3. 解题思路

### 3.1 暴力思路

最直白的做法是**反复替换最内层**：每轮用正则（或手写查找）找出形如 `k[纯字母]` 的最内层片段，原地展开，直到串中不再有方括号。它确实能过题（$\lvert s\rvert \le 30$），但要扫 $d$ 遍（$d$ 为嵌套深度），每遍都要重建整串，复杂度 $O(d \cdot \lvert ans \rvert)$，还得自己维护「哪个 `[` 和哪个 `]` 配对」——下标稍不留神就越界。

另一条朴素路线是**递归匹配括号**：遇到 `[` 就往后找与它配对的 `]`，递归解码括号内部。思路正确，但每个 `[` 都要做一次 $O(\lvert s\rvert)$ 的配对扫描，且返回后还要拼接，总复杂度 $O(\lvert s\rvert^2 + d \cdot \lvert ans \rvert)$。

两种写法都在做同一件事：**一遍又一遍地重新解析同一段字符串**。而括号结构本身就是「先入后出」的，这提示我们用栈把多遍扫描压成一遍。

### 3.2 核心观察：括号嵌套就是调用栈

![嵌套结构即调用栈](images/wc3_q3_nested_stack_model.svg)

观察编码串的文法，它是**递归定义**的：

$$S \;\to\; \varepsilon \;\mid\; c\,S \;\mid\; k\,[\,S\,]\,S$$

也就是说，读到 `k[` 时，我们开始「进入下一层」，此时**只需记住两件事**：

1. **外层已解码的前缀** $base$（比如 `"abc"` 或 `"acc"`），将来要接在展开结果的后面；
2. **本层的乘数** $k$。

读完内层、遇到配对的 `]` 时，把这一层结算成 $base + \text{内层结果} \times k$，就回到了上一层。这正是**函数调用的语义**：`[` 是 call，`]` 是 return，返回值就是内层展开后的字符串。

因此我们只需要：

- 一个数字累加器 `num`（可能有多位，如 `100[leetcode]`）；
- 一个「当前层已解码内容」缓冲区 `cur`；
- 一个栈，每层存一对 $(base, k)$。

从左到右**扫一遍**，遇到 `[` 入栈、遇到 `]` 出栈，就结束了——不需要回溯，也不需要重新扫描。

> 💡 一句话记忆：`[` 时把当前 $(cur, num)$ 压栈并清空，`]` 时弹出 $(base, k)$，令 $cur \gets base + cur \times k$。

### 3.3 算法流程

![扫描流程：四种字符四个动作](images/wc3_q3_stack_flow.svg)

维护两个同步的栈 `numStk` 与 `strStk`（等价于一个存 `pair<string,int>` 的栈），外加 `cur`、`num`：

1. **数字** $d$：令 $num \gets num \times 10 + d$，用于支持多位数 $k$；
2. **`[`**：`numStk.push(num)`、`strStk.push(cur)`，然后令 $num \gets 0$、$cur \gets \varepsilon$——保存现场并进入新的一层；
3. **`]`**：先取 $k = \mathrm{numStk.pop()}$、$base = \mathrm{strStk.pop()}$，再令 $cur \gets base + cur \times k$——结算本层并接回外层；
4. **普通字母**：`cur += ch`，直接留在当前层；
5. 扫描结束返回 `cur`。此时两个栈必然为空，因为括号合法且成对。

若改成**递归**写法，就是把 2、3 两步换成「递归调用 / 返回后拼接」，本质上是同一棵调用树，只是把栈交给了程序运行时。栈写法不占用递归栈，且不需要预先求括号配对。

### 3.4 示例演算

![示例 3[a2[c]] 的栈状态走查](images/wc3_q3_walkthrough.svg)

以 `s = "3[a2[c]]"` 为例，逐字符走查如上图。关键在最后两步：

- 读到第 7 个字符 `]`：栈顶为 `base = "a"`、`k = 2`，内层 `cur` 是 `"c"`，按 $cur \gets base + cur \times k$ 拼成 `"acc"`；
- 读到第 8 个字符 `]`：栈顶为 `base = ""`、`k = 3`，代入同一式子得到 `"accaccacc"`，栈空，返回。

再看示例 3 的 `"2[abc]3[cd]ef"`：第二段 `3[cd]` 结算后，外层前缀 `"abcabc"` 与重复三次的 `cd` 相接，得到 `"abcabccdcdcd"`；随后的 `e`、`f` 位于**最外层**（栈已空），直接 `cur += ch` 即可，于是得到 `"abcabccdcdcdef"`——这正是示例 3 末尾 `ef` 的来源。

## 4. 算法细节

1. **多位数必须逐位累积**：`k` 最大到 300，可能是 2~3 位。写 `num = num * 10 + (ch - '0')`；若只把 `ch - '0'` 赋给 `num`，`100[leetcode]` 读到 `[` 时 `num` 只剩 0，答案会直接变成空串。
2. **`push` 的顺序要一致**：两个栈必须**成对**出入。用两个独立栈时先 `numStk.push(num)` 再 `strStk.push(cur)`；用 `stack<pair<string,int>>` 时把 `(cur, num)` 作为一个整体压入，取用时 `base` 与 `k` 一定来自同一层。
3. **`]` 分支先取后算**：先 `base = pop`、`k = pop`，再 `cur = base + cur * k`。不要先 `cur.clear()`，否则重复的内容就丢了；也不要写成 `cur = cur * k + base`（顺序反了，示例 4 会立刻暴露）。
4. **`[` 之后必须清零 `num`**：`num` 是「尚未使用的乘数」，被 `[` 消费掉后要置 0，否则同一层的下一个 `k` 会拼成一个巨大的数。`cur` 则要**先入栈再清空**，顺序不能反。
5. **拼接代价与 `reserve`**：C++ 中 `for (int i = 0; i < k; ++i) rep += cur;` 前可以 `rep.reserve(cur.size() * k)`，避免反复扩容；`cur.size() * k` 是 `size_t` 运算，不要强转成 `int` 以免溢出。Python 里 `cur * k` 已由解释器优化。
6. **栈不必存「当前深度」**：因为弹栈顺序天然对应括号的嵌套顺序，深度信息隐含在栈的结构里，无需额外维护。
7. **不需要跳过空格**：题目保证输入无多余空格，循环里不必特判 `' '`；但要保证四个分支覆盖所有字符，避免落空。

## 5. 正确性证明

先给记号：设 $D(s)$ 表示按文法解出的字符串，递归定义为

$$D(\varepsilon) = \varepsilon,\quad D(cS) = c\,D(S),\quad D(k[S]S') = D(S)^k\,D(S')$$

**引理 1（数字累积正确）**：连续读入数字字符 $d_1 d_2 \cdots d_m$ 后，`num` 等于整数 $\overline{d_1 d_2 \cdots d_m}$。

**证明**：对 $m$ 归纳。$m = 1$ 时 `num = d_1`，成立。设读完前 $m-1$ 位后 `num` 为 $\overline{d_1\cdots d_{m-1}}$，则执行 `num = num * 10 + d_m` 得到 $10 \cdot \overline{d_1\cdots d_{m-1}} + d_m = \overline{d_1\cdots d_m}$。∎

**引理 2（栈不变量）**：扫描到任意位置 $i$ 时，设当前括号深度为 $d$，则：

- (a) 栈中自底向上第 $j$ 个元素等于 $\bigl(base_j,\, k_j\bigr)$，其中 $k_j$ 是第 $j$ 层 `[` 之前读到的乘数，$base_j$ 是第 $j$ 层 `[` 之前**外层**已解码的前缀；
- (b) 记 $p$ 为当前层内**最后一个完整原子**（单个字母，或一个已闭合的 $k[\cdots]$）之后的结束位置，则 `cur` 等于当前层起始位置到 $p$ 这段字符的解码结果；当前层起始位置在 $d = 0$ 时为 0，否则为第 $d$ 层 `[` 的下一个位置。

**证明**：对已处理字符数归纳。初始 $i=0$、$d=0$、栈空、`cur` 为空串，成立。

设处理字符 $s[i]$ 前不变量成立，考察 $s[i]$：

- 若 $s[i]$ 是字母，`cur += ch`，同时 $p$ 推进到 $i+1$；由 $D(cS) = c\,D(S)$，(b) 保持；栈未变，(a) 保持。
- 若 $s[i]$ 是数字，只改变 `num`，$p$ 与 `cur` 都不动，故 (a)(b) 保持；由引理 1，`num` 就是这段连续数字的值。
- 若 $s[i] = \texttt{[}$，入栈 $(cur, num)$ 后 $d$ 增至 $d+1$、`cur` 置空。新栈的第 $d+1$ 个元素恰为「新层之前外层的前缀与乘数」，且新层的起始位置与 $p$ 都正是 $i+1$、`cur` 为空串，故 (a)(b) 对新深度成立。
- 若 $s[i] = \texttt{]}$，由括号合法性，当前层必有一个匹配的左括号，且更深层已全部结算完毕（否则 `]` 会提前关闭更深层，与配对矛盾）。故栈顶正是本层的 $(base, k)$，出栈后 $d$ 减 1、$p$ 推进到 $i+1$，并令 $cur \gets base + cur \cdot k$：右端第一项是外层前缀，第二项是本层内容的 $k$ 次重复，合起来正是外层到 $i+1$ 为止的解码结果，(a)(b) 保持。

归纳完成。∎

**定理**：算法返回的 `cur` 等于 $D(s)$。

**证明**：扫描结束时 $i = \lvert s\rvert$。由于 `s` 合法，所有 `[` 都被匹配的 `]` 关闭，最终深度 $d = 0$，栈为空（每次入栈都有对应出栈，且没有多余出栈）。由引理 2(b)，$d = 0$ 时 `cur` 等于从位置 0 到 $\lvert s\rvert$ 的整串解码结果，即 $D(s)$。算法恰在此时返回 `cur`。∎

## 6. 复杂度分析

- **时间**：扫描每个字符一次，$O(\lvert s\rvert)$ 次基本操作；此外，每次遇到 `]` 需要复制长度为 $\lvert base\rvert + \lvert cur\rvert \cdot k$ 的字符串，代价不超过 $O(\lvert ans\rvert)$，最多 $\lvert s\rvert/2$ 次出栈，因此字符串复制总代价 $O(d \cdot \lvert ans\rvert)$（$d$ 为最大嵌套深度，$d \le \lvert s\rvert / 2$）。合计 $O(\lvert s\rvert + d \cdot \lvert ans\rvert)$，最坏 $O(\lvert s\rvert \cdot \lvert ans\rvert)$；在 $\lvert s\rvert \le 30$、$\lvert ans\rvert \le 10^5$ 的约束下远低于时限。
- **空间**：栈的深度不超过 $\lvert s\rvert/2$，每层保存一个前缀字符串与一个整数，前缀总长度不超过 $O(\lvert ans\rvert)$；加上输出缓冲区，空间 $O(\lvert s\rvert + \lvert ans\rvert)$。

## 7. 参考代码

### C++

```cpp
#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    string decodeString(string s) {
        vector<int> numStk;        // 每层待乘的 k
        vector<string> strStk;     // 每层 '[' 之前已解码的前缀 base
        string cur;                // 当前层已解码的内容
        int num = 0;               // 正在读的乘数（可能多位）

        for (char ch : s) {
            if (ch >= '0' && ch <= '9') {
                num = num * 10 + (ch - '0');
            } else if (ch == '[') {
                numStk.push_back(num);
                strStk.push_back(cur);
                num = 0;
                cur.clear();
            } else if (ch == ']') {
                int k = numStk.back();
                numStk.pop_back();
                string base = strStk.back();
                strStk.pop_back();
                string rep;
                rep.reserve(cur.size() * static_cast<size_t>(k));
                for (int i = 0; i < k; ++i) rep += cur;
                cur = base + rep;  // 接回外层前缀
            } else {
                cur += ch;         // 普通字母直接拼
            }
        }
        return cur;
    }
};
```

### Python

```python
class Solution:
    def decodeString(self, s: str) -> str:
        num_stk = []      # 每层待乘的 k
        str_stk = []      # 每层 '[' 之前已解码的前缀 base
        cur = ""          # 当前层已解码的内容
        num = 0           # 正在读的乘数（可能多位）

        for ch in s:
            if ch.isdigit():
                num = num * 10 + int(ch)
            elif ch == '[':
                num_stk.append(num)
                str_stk.append(cur)
                num, cur = 0, ""
            elif ch == ']':
                cur = str_stk.pop() + cur * num_stk.pop()
            else:
                cur += ch

        return cur
```

## 8. 边界情况与易错点

1. **多位数乘数**：`"100[leetcode]"`、`"12[ab]"`。必须逐位累积，且在 `[` 处才消费 `num` 并清零。
2. **连续出栈**：`"3[a2[c]]"` 结尾是两个 `]`。每次 `]` 只结算一层，不能试图在第一次 `]` 就把外层也顺带处理掉；连着的两个 `]` 各自走一次出栈分支即可。
3. **括号外的字母要保留**：示例 3 的 `ef`、示例 4 的 `abc` 与 `xyz` 都在括号外，靠「字母直接 `cur += ch`」保留，不能只在括号内拼接。
4. **`k = 1`**：`"1[a]"` 重复一次即 `"a"`，代码无需特判；重复次数为 1 时也不能跳过（`cur * 1` 就是 `cur`）。
5. **无括号的纯字母串**：`"abcd"` 全程走字母分支，`cur` 即为答案。
6. **`[` 处清空顺序**：必须先把旧 `cur` 压栈再清空，否则前缀丢失；`num` 同理，先压栈后归零。
7. **输出上限 10^5**：嵌套深时字符串复制量约 $d \cdot \lvert ans\rvert$，C++ 建议 `reserve`；不要用递归写法去处理更长的输入（本题每层至少占 3 个字符，深度 $\le 9$，递归安全；但一般化后会爆栈）。
8. **字符判断的细节**：输入只含 `0-9`、小写字母与方括号。C++ 里若用 `isdigit(ch)`，应写成 `isdigit(static_cast<unsigned char>(ch))`（或直接比较 `'0' <= ch && ch <= '9'`），否则 `char` 为有符号类型时传入负值是未定义行为。
