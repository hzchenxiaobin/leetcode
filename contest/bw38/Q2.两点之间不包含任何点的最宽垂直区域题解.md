# LeetCode 两点之间不包含任何点的最宽垂直区域 题解

## 1. 题目概述

- **标题 / 题号**：两点之间不包含任何点的最宽垂直区域（#1637，easy）
- **链接**：https://leetcode.cn/problems/widest-vertical-area-between-two-points-containing-no-points/
- **来源**：LeetCode 第 38 场双周赛 Q2
- **难度**：简单
- **标签**：数组、排序

**题意**：给定平面上 $n$ 个点 `points[i] = [x_i, y_i]`。**垂直区域**指左右两条竖直边界围成、上下无限延伸的条带；区域**边界上**的点不算在区域内。求「内部不含任何点」的**最宽垂直区域**的宽度（两条边界 x 坐标之差）。

**约束**：

- $2 \le n \le 10^5$
- $0 \le x_i, y_i \le 10^9$

> 💡 一句话破题：区域上下无限延伸，**y 坐标完全无关**——问题退化为一维：在数轴 $\{x_i\}$ 上找相邻两点间的最大空隙。

## 2. 示例

**示例 1**

```text
输入：points = [[8,7],[9,9],[7,4],[9,7]]
输出：1
解释：x 坐标排序后为 7, 8, 9, 9；相邻间隙分别为 1, 1, 0，最宽为 1。
```

**示例 2**

```text
输入：points = [[3,1],[9,0],[1,0],[1,4],[5,3],[8,8]]
输出：3
解释：x 坐标排序后为 1, 1, 3, 5, 8, 9；相邻间隙为 0, 2, 2, 3, 1，最宽为 3
     （介于 x=5 与 x=8 之间，内部无任何点）。
```

## 3. 解题思路

### 3.1 暴力思路

对每对点 $(i, j)$ 检查「$x_i < x_j$ 且区间 $(x_i, x_j)$ 内没有其他点的 x 坐标」，取最大宽度——$O(n^2)$ 甚至 $O(n^3)$（每对再扫一遍内部）。$n \le 10^5$ 时 $O(n^2) = 10^{10}$ 必然超时。突破口在于观察到**一维化**：条带上下无限，任何点只要其 x 落在条带内就在条带内部，与 y 无关。

### 3.2 核心观察：排序后答案 = 相邻 x 差的最大值

![核心观察：垂直条带与相邻 x 空隙](images/bw38_q2_vertical_area.svg)

「内部无点的条带」两条边界必须分别**贴着**两个点的 x 坐标（否则可以继续外扩，宽度更大）。于是候选条带完全由「排序后相邻的两个不同 x 值」决定：

- 把所有 $x_i$ 升序排序为 $x_{(0)} \le x_{(1)} \le \cdots \le x_{(n-1)}$；
- 相邻差 $\delta_i = x_{(i+1)} - x_{(i)}$ 中，「相邻两个**不同**值」之间的差就是一个无点条带的宽度；
- 答案 $= \max_i \delta_i$（相同值相邻时 $\delta = 0$，不影响最大值）。

直觉：若条带左边界左边还有更远的同类空隙……更严谨地说，任何内部无点的条带，其宽度不会超过某个相邻空隙（§5 定理）。

### 3.3 算法流程

```text
1. xs = [p[0] for p in points]        # 只取 x，丢弃 y
2. sort(xs)
3. ans = max(xs[i+1] - xs[i])         # 相邻差最大值（n>=2 必存在）
4. 返回 ans
```

### 3.4 示例演算

![示例演算：示例 2 的排序与间隙](images/bw38_q2_walkthrough.svg)

示例 2：`points = [[3,1],[9,0],[1,0],[1,4],[5,3],[8,8]]`

```text
x 坐标：3, 9, 1, 1, 5, 8
排序后：1, 1, 3, 5, 8, 9
相邻差：   0  2  2  3  1
最大相邻差 = 3（在 x=5 与 x=8 之间）
```

两个 $x=1$ 的点贡献间隙 0；最宽条带是 $(5, 8)$，宽 3，内部（开区间）确无任何点。

## 4. 算法细节

1. **只需 x 坐标**：提取时直接丢弃 y；不必对 `points` 整体排序（那会多做 $O(\log n)$ 的向量比较，虽不致错但慢一截）。
2. **重复 x 自动处理**：排序后相同值相邻、差为 0；「相邻不同值」的差在最大值意义下不受影响，无需显式去重（去重后答案不变）。
3. **数据范围与溢出**：$0 \le x_i \le 10^9$，相邻差 $\le 10^9$，`int`（上界约 $2.1 \times 10^9$）放得下，但已经贴近，用 `long long` 更安心；C++ 中两个 `int` 相减先提升再比较即可。
4. **$n = 2$ 的最简情形**：答案就是 $|x_0 - x_1|$，公式自然覆盖。
5. **答案下界**：若所有点 x 相同，最大相邻差为 0——最宽「无点条带」宽度为 0（任何正宽度条带都会包含点，而宽度 0 的退化条带边界重合，题目数据保证 $n \ge 2$ 时输出 0 是被接受的）。

## 5. 正确性证明

**引理（无点条带的刻画）**：开区间 $(a, b)$（$a < b$）内没有任何点的 x 坐标，当且仅当排序后的 x 序列中存在相邻元素 $x_{(i)} \le a < b \le x_{(i+1)}$（允许 $x_{(i)} = x_{(i+1)}$ 仅当 $a = b$，此情形宽度为 0）。

**证明**：（⟸）$(a,b) \subseteq (x_{(i)}, x_{(i+1)})$ 或与之相交为空：排序保证任何点的 x 要么 $\le x_{(i)} \le a$、要么 $\ge x_{(i+1)} \ge b$，均不在开区间 $(a, b)$ 内。（⟹）设 $(a,b)$ 内无点。取 $x_{(i)}$ 为 $\le a$ 的最大 x（若不存在，说明所有 $x > a$，则取排序首元素 $x_{(0)} \ge b > a$，令 $a' = x_{(0)}$ 前移左边界只会更宽，化为存在情形）；取 $x_{(j)}$ 为 $\ge b$ 的最小 x。则 $x_{(i)}$ 与 $x_{(j)}$ 之间（排序序列中）没有其他元素——否则该元素的 x 严格介于 $x_{(i)} \le a$ 与 $x_{(j)} \ge b$ 之间，即落在 $(a, b)$ 内，矛盾——故 $j = i + 1$ 且 $x_{(i)} \le a < b \le x_{(i+1)}$。∎

**定理**：最宽无点条带的宽度 $= \max_{0 \le i < n-1} (x_{(i+1)} - x_{(i)})$。

**证明**：（下界）取差最大的相邻对 $x_{(i)} < x_{(i+1)}$（若最大差为 0，答案为 0 显然成立），条带 $(x_{(i)}, x_{(i+1)})$ 宽度为该差且由引理（$a = x_{(i)}, b = x_{(i+1)}$）知其内部无点，故答案 $\ge$ 最大相邻差。（上界）任何内部无点的条带 $(a, b)$，由引理存在相邻对 $x_{(i)} \le a < b \le x_{(i+1)}$，其宽度 $b - a \le x_{(i+1)} - x_{(i)} \le$ 最大相邻差。两侧夹逼得证。∎

## 6. 复杂度分析

- **时间**：$O(n \log n)$，排序主导；一遍扫相邻差 $O(n)$。$n = 10^5$ 时毫无压力。
- **空间**：$O(n)$ 存提取的 x 数组（若允许原地重排 `points` 可降到 $O(1)$，无必要）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maxWidthOfVerticalArea(vector<vector<int>>& points) {
        vector<int> xs;
        xs.reserve(points.size());
        for (const auto& p : points) xs.push_back(p[0]);   // 只留 x
        sort(xs.begin(), xs.end());
        int best = 0;
        for (size_t i = 1; i < xs.size(); ++i)
            best = max(best, xs[i] - xs[i - 1]);            // 相邻差最大值
        return best;
    }
};
```

### Python

```python
class Solution:
    def maxWidthOfVerticalArea(self, points: list[list[int]]) -> int:
        xs = sorted(p[0] for p in points)
        return max(b - a for a, b in zip(xs, xs[1:]))
```

> 💡 两份代码均通过官方 2 个示例（`1`、`3`），并补充重合 x、$n=2$、坐标达 $10^9$ 的边界用例；另与「枚举点对并检查区间内无点」的暴力对拍 150 组随机数据（$n \le 60$），以及 $n = 10^5$ 的性能验证，全部一致。

## 8. 边界情况与易错点

1. **别用 y**：区域上下无限，y 无关；把点对距离、y 范围扯进来都是歧路。
2. **边界上的点不算**：条带边界恰好穿过点是允许的——这正是「相邻 x」而不是「任意远点对」的原因。
3. **重复 x 坐标**：相邻差出现 0，不影响最大值；不需要去重，但去重也不改变答案。
4. **溢出**：$10^9 - 0 = 10^9$ 在 `int` 内（$< 2^{31} - 1 \approx 2.147 \times 10^9$），但已贴近上界，谨慎起见可用 64 位。
5. **`xs[1:]` 空序列**：$n \ge 2$ 保证至少一个相邻对；若防御性编码，Python 可用 `max(..., default=0)`。
6. **误答「任意两点最大差」**：宽度最大的无点条带未必由最左、最右点夹成——中间可能有别的点；必须取**相邻**差。
