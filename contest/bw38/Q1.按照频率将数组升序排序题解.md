# LeetCode 按照频率将数组升序排序 题解

## 1. 题目概述

- **标题 / 题号**：按照频率将数组升序排序（#1636，easy）
- **链接**：https://leetcode.cn/problems/sort-array-by-increasing-frequency/
- **来源**：LeetCode 第 38 场双周赛 Q1
- **难度**：简单
- **标签**：数组、哈希表、排序

**题意**：给定整数数组 `nums`，将数组按每个值的**出现频率升序**排序；多个值频率相同时，这些值之间按**数值本身降序**排序。返回排序后的数组。

**约束**：

- $1 \le nums.length \le 100$
- $-100 \le nums[i] \le 100$

> 💡 值域被压到 $[-100, 100]$，暗示「计数数组」比哈希表更直接；但两个方向的实现都要会。

## 2. 示例

**示例 1**

```text
输入：nums = [1,1,2,2,2,3]
输出：[3,1,1,2,2,2]
解释：'3' 频率为 1，'1' 频率为 2，'2' 频率为 3，按频率升序排列。
```

**示例 2**

```text
输入：nums = [2,3,1,3,2]
输出：[1,3,3,2,2]
解释：'2' 与 '3' 频率同为 2，按数值本身降序，故 3 排在 2 前面。
```

**示例 3**

```text
输入：nums = [-1,1,-6,4,5,-6,1,4,1]
输出：[5,-1,4,4,-6,-6,1,1,1]
解释：频率：5→1，-1→1，4→2，-6→2，1→3。
  频率 1 组内降序：5, -1；频率 2 组内降序：4, 4（同值），-6, -6……注意同频不同值按值降序：4 > -6，4 组在前。
```

## 3. 解题思路

### 3.1 暴力思路

对每个元素数频率是绕不开的第一步：朴素 $O(n^2)$ 双重循环（对每个 $x$ 扫全数组数 $\text{cnt}(x)$）在 $n \le 100$ 时也能过，但既然值域只有 $201$ 个整数，一次遍历用 `cnt[201]` 计数即可 $O(n + V)$。排序本身 $O(n \log n)$。总体思路一句话：**把「频率」算出来，然后按自定义键排序**。

### 3.2 核心观察：排序键就是二元组 (频率, −数值)

![核心观察：计数与排序键 (freq, −val)](images/bw38_q1_sort_key.svg)

题意的排序规则可以合并成一个**二元组键**：

$$key(x) = (\ freq(x),\ -x\ ).$$

按 $key$ 升序排序时：

- 先比频率：频率小者在前（升序）✓；
- 频率相同再比 $-x$：$-x$ 小即 $x$ 大者在前（降序）✓。

Python 的元组天然支持逐项比较，`sorted(nums, key=lambda x: (freq[x], -x))` 一步到位；C++ 在比较器里写「频率不同按频率；相同按 $a > b$」。

### 3.3 算法流程

```text
1. cnt[x+100] 计数（值域平移，避免负下标）        O(n)
2. 对 nums 原地排序，比较器 cmp(a, b)：
     fa = cnt[a+100], fb = cnt[b+100]
     若 fa != fb：返回 fa < fb          # 频率升序
     否则：        返回 a > b           # 数值降序
3. 返回 nums
```

### 3.4 示例演算

![示例演算：nums 为 2,3,1,3,2](images/bw38_q1_walkthrough.svg)

以示例 2 `nums = [2,3,1,3,2]` 为例：

| 值 | 频率 | 排序键 $(freq, -val)$ |
|----|------|----------------------|
| 1 | 1 | $(1, -1)$ |
| 3 | 2 | $(2, -3)$ |
| 2 | 2 | $(2, -2)$ |

按键升序：$(1,-1) < (2,-3) < (2,-2)$，故输出 `[1, 3, 3, 2, 2]`——频率 1 的 1 排最前；同为频率 2 的 3（键 $-3$ 更小）排在 2 前，组内降序。

## 4. 算法细节

1. **负值偏移**：值域 $[-100, 100]$ 映射到下标 $[0, 200]$，用 `cnt[x + 100]`。
2. **比较器必须满足严格弱序**：`a == b` 时必须返回 `false`（两个键相等时既不 `a < b` 也不 `b < a`）。本题每个元素和自身比较时频率、数值全等，天然返回 false；但若手滑写成 `fa <= fb` 之类的非严格比较，`std::sort` 可能越界崩溃。
3. **C++ 比较器捕获计数数组**：lambda 用 `[&]` 引用捕获即可，无需拷贝。
4. **同频同值的多个副本**：键完全相同，排序结果与输入顺序无关（本题不要求稳定）。
5. **哈希表替代计数数组**：`Counter` / `unordered_map` 同样 $O(n)$，值域不受限时更通用；本题值域小，数组更快。
6. **为什么要 $-x$ 而不是倒着排**：若先按频率升序排、再对同频段单独降序排，需要分段识别，多一层逻辑；二元组键一次排序解决。

## 5. 正确性证明

**引理（键与题意等价）**：设 $key(x) = (freq(x), -x)$。对任意两个**值** $a \ne b$：题意要求 $a$ 排在 $b$ 之前 $\iff$ $key(a) <_{lex} key(b)$。

**证明**：分情形。若 $freq(a) \ne freq(b)$：题意按频率升序，$a$ 在前 $\iff freq(a) < freq(b) \iff key(a) < key(b)$（元组首分量分出大小）。若 $freq(a) = freq(b)$：题意同频按值降序，$a$ 在前 $\iff a > b \iff -a < -b \iff key(a) < key(b)$（首分量相等，比较第二分量）。∎

**定理**：按 $key$ 对数组排序后，输出满足题意。

**证明**：数组中同值元素键相同，可视为按值分组的块。由引理，任意两个不同值的块之间的相对顺序符合题意；同值块内部元素相同，顺序无影响。故整体输出即题意要求的排列。∎

> 💡 注：LeetCode 判题接受任何满足「频率升序 + 同频数值降序」的合法排列；由于同频同值的副本不可区分，本题的合法排列实际唯一（就是官方示例给出的那种）。

## 6. 复杂度分析

- **时间**：$O(n + V + n \log n)$——计数 $O(n)$（$V = 201$ 的清零可忽略），排序 $O(n \log n)$。$n \le 100$，总量微不足道。
- **空间**：$O(V)$ 计数数组（C++ 原地排序）；Python `sorted` 另需 $O(n)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> frequencySort(vector<int>& nums) {
        int cnt[201] = {0};
        for (int x : nums) ++cnt[x + 100];
        sort(nums.begin(), nums.end(), [&](int a, int b) {
            int fa = cnt[a + 100], fb = cnt[b + 100];
            if (fa != fb) return fa < fb;   // 频率升序
            return a > b;                    // 同频率，数值降序
        });
        return nums;
    }
};
```

### Python

```python
from collections import Counter

class Solution:
    def frequencySort(self, nums: list[int]) -> list[int]:
        freq = Counter(nums)
        return sorted(nums, key=lambda x: (freq[x], -x))
```

> 💡 两份代码均通过官方 3 个示例（`[3,1,1,2,2,2]`、`[1,3,3,2,2]`、`[5,-1,4,4,-6,-6,1,1,1]`）；另做 300 组随机性质自检：输出是原数组重排（多重集合相等）、频率非降、同频段数值非升，全部通过。

## 8. 边界情况与易错点

1. **负数与下标偏移**：`cnt[x + 100]`，`x = -100` 映射到 0；忘记偏移会越界。
2. **同频降序别写反**：频率相同按**数值降序**（示例 2 中 3 在 2 前），写成升序会在示例 2、3 上答错。
3. **比较器的严格性**：`fa != fb` 分支返回严格小于；`a > b` 分支在 `a == b` 时返回 false——这正是严格弱序的要求。
4. **单元素数组**：`n = 1` 时排序无操作，直接返回。
5. **全同值数组**：所有键相同，输出与输入一致（值都一样，无所谓顺序）。
6. **Python 的 `Counter` 重复计数**：`freq[x]` 对每个副本查到同一频率，键正确；不要误用 `freq.items()`（那会把「值」去重后只剩一份）。
