# LeetCode 统计只差一个字符的子串数目 题解

## 1. 题目概述

- **标题 / 题号**：统计只差一个字符的子串数目（#1638，medium）
- **链接**：https://leetcode.cn/problems/count-substrings-that-differ-by-one-character/
- **来源**：LeetCode 第 38 场双周赛 Q3
- **难度**：中等
- **标签**：字符串、动态规划、枚举、哈希表

**题意**：给定两个字符串 $s$ 和 $t$，统计满足以下条件的**子串对** $(A, B)$ 数目：$A$ 是 $s$ 的非空子串，$B$ 是 $t$ 的非空子串，$|A| = |B|$，且两者**恰好有一个位置**上的字符不同。

**约束**：

- $1 \le s.length, t.length \le 100$
- $s$、$t$ 只包含小写英文字母

> ⚠️ 数的是**有序对且按位置计**——同一对子串若起点不同则算不同的对；子串内容相同但位置不同算两次（从示例可验证：长度 1 的对也计入）。

## 2. 示例

**示例 1**

```text
输入：s = "aba", t = "baba"
输出：6
解释：6 对子串都恰好差一个字符：
("a","b"), ("a","b"), ("b","a"), ("b","a"), ("a","b"), ("a","b")
（本例中 6 对恰好都是长度为 1 的子串，按位置计。）
```

**示例 2**

```text
输入：s = "ab", t = "bb"
输出：3
解释：("a","b")，("a","b")，("ab","bb")
```

**示例 3**

```text
输入：s = "a", t = "a"
输出：0
解释：唯一的一对子串完全相同，差 0 个字符，不计入。
```

**示例 4**

```text
输入：s = "abe", t = "bbc"
输出：10
```

## 3. 解题思路

### 3.1 暴力思路

枚举 $s$ 的子串起点 $i$、$t$ 的子串起点 $j$，同步向右延伸并逐位比较，维护差异计数 `diff`，`diff == 1` 时答案加一，`diff > 1` 立刻 break。复杂度 $O(|s| \cdot |t| \cdot \min(|s|, |t|))$，上界 $100^3 = 10^6$，完全可过——这是本题的「保底解法」，也是对拍的基准。官方提示中的另一条暴力路线是把 $t$ 的所有子串塞进 Trie，枚举 $s$ 每个前缀在 Trie 上的匹配并在失配处换 26 种字符，复杂度 $O\left(\sum_{i,j}(i+j) \cdot 26\right)$ 量级，同样可行但实现繁琐。

### 3.2 核心观察：按「失配位置」贡献计数

![核心观察：固定失配位，左右延伸乘积](images/bw38_q3_concept.svg)

每对满足条件的 $(A, B)$ 恰有**唯一**一个失配位置。反过来枚举：设失配发生在 $s$ 的第 $i$ 位与 $t$ 的第 $j$ 位（$s[i] \ne t[j]$），那么 $(A, B)$ 由三个自由度决定：

- **左端**：$A$、$B$ 的失配位左侧必须**逐位相等**，公共长度可以是 $0 \dots L$，其中 $L$ 是「以 $s[i-1], t[j-1]$ 结尾的最长公共后缀长度」——左侧共 $L + 1$ 种取法；
- **右端**：失配位右侧同理，公共长度 $0 \dots R$，$R$ 是「从 $s[i+1], t[j+1]$ 开始的最长公共前缀长度」——右侧共 $R + 1$ 种取法；
- 左右独立，失配位本身固定为 $(i, j)$。

于是总答案为

$$\text{ans} = \sum_{\substack{i, j \\ s[i] \ne t[j]}} \big(\,pre[i][j] + 1\,\big) \cdot \big(\,suf[i+1][j+1] + 1\,\big)$$

其中 $pre[i][j]$ 定义为「以 $s[i-1]$、$t[j-1]$ 结尾的最长公共后缀长度」，$suf[i][j]$ 为「从 $s[i]$、$t[j]$ 开始的最长公共前缀长度」。两表都能 $O(|s| \cdot |t|)$ 递推出来，总复杂度从 $O(n^3)$ 降到 $O(n^2)$。

### 3.3 状态转移：两张表的递推

![pre 表与 suf 表的递推方向](images/bw38_q3_tables.svg)

$$\begin{aligned}
pre[i][j] &= \begin{cases} pre[i-1][j-1] + 1, & s[i-1] = t[j-1] \\ 0, & \text{否则} \end{cases} &&\text{（正向填，边界 } pre[0][\cdot] = pre[\cdot][0] = 0\text{）}\\[6pt]
suf[i][j] &= \begin{cases} suf[i+1][j+1] + 1, & s[i] = t[j] \\ 0, & \text{否则} \end{cases} &&\text{（反向填，边界 } suf[|\cdot s|][\cdot] = 0\text{）}
\end{aligned}$$

两表含义相同（对齐位置的公共长度），只是一个向左看后缀、一个向右看前缀；「边界为 0」对应空串公共长度为 0。

### 3.4 示例演算

![示例演算：s=ab, t=bb 的两表与计数](images/bw38_q3_walkthrough.svg)

以示例 2（$s = $ "ab"，$t = $ "bb"）为例。先填表（行列按 $i, j$ 从 0 开始，表值为 $pre[i][j]$ / $suf[i][j]$）：

| $pre$ | $j{=}0$ | $j{=}1$ | $j{=}2$ |  | $suf$ | $j{=}0$ | $j{=}1$ | $j{=}2$ |
|-------|---------|---------|---------|---|-------|---------|---------|---------|
| $i{=}0$ | 0 | 0 | 0 |  | $i{=}0$ | 0 | 0 | — |
| $i{=}1$ | 0 | 0 | 0 |  | $i{=}1$ | 1 | 1 | — |
| $i{=}2$ | — | 1 | 1 |  | $i{=}2$ | 0 | 0 | — |

（$pre[2][1] = pre[2][2] = 1$ 来自 $s[1] = t[0] = t[1] = $ "b"；$suf[1][0] = suf[1][1] = 1$ 同理。）

失配位只有 $s[0] = $ "a" $\ne$ $t[j] = $ "b"（$j = 0, 1$）：

- $(i, j) = (0, 0)$：$(pre[0][0]+1) \cdot (suf[1][1]+1) = 1 \cdot 2 = 2$，对应子串对 ("a","b") 与 ("ab","bb")；
- $(i, j) = (0, 1)$：$(pre[0][1]+1) \cdot (suf[1][2]+1) = 1 \cdot 1 = 1$，对应 ("a","b")。

合计 $2 + 1 = 3$ ✓。

## 4. 算法细节

1. **索引约定是最大易错点**：失配位 $(i, j)$ 对应「左侧看 $pre[i][j]$（下标含 $i-1, j-1$ 的字符）、「右侧看 $suf[i+1][j+1]$。建议 $pre$ 表开 $(n+1) \times (m+1)$、$suf$ 表开 $(n+1) \times (m+1)$，边界行列自然为 0，避免特判。
2. **乘积不取模也不溢出**：$pre, suf \le 100$，单项 $\le 101^2$，总和 $\le 10^4 \cdot 101^2 \approx 10^8$，`int` 够用；`long long` 更稳。
3. **为什么左、右取法独立**：左侧公共后缀长度与右侧公共前缀长度互不干涉（失配位固定），组合计数直接相乘；而失配位 $(i,j)$ 在每对 $(A,B)$ 中唯一，不同 $(i,j)$ 的计数两两不重叠。
4. **同字符位置跳过**：只有 $s[i] \ne t[j]$ 才累加——完全相等的对齐位置不贡献（差 0 个字符的子串不计）。
5. **空间可滚动**：$pre$ 的递推只依赖左上对角线，$suf$ 依赖右下对角线，若要压空间可按对角线滚动到 $O(\min(n,m))$；本题 $100 \times 100$ 的小表无需优化。

## 5. 正确性证明

**引理 1（失配位唯一分解）**：对每一对满足题意的 $(A, B)$（$A = s[i-l \dots i+r]$，$B = t[j-l \dots j+r]$，失配发生在对齐位置 $(i, j)$，左右各有 $l, r \ge 0$ 个字符且全部相等），其对应的五元组 $(i, j, l, r, \text{失配标志})$ 唯一；反之每个满足 $0 \le l \le pre[i][j]$、$0 \le r \le suf[i+1][j+1]$、$s[i] \ne t[j]$ 的 $(i, j, l, r)$ 都产生唯一一对合法 $(A, B)$。

**证明**：（分解唯一性）$(A,B)$ 逐位对齐后恰好一个位置不同，该位置即 $(i, j)$，由 $(A,B)$ 的起点与失配点唯一决定 $l, r$。（重构合法性）给定 $(i, j, l, r)$：$l \le pre[i][j]$ 保证 $s[i-l \dots i-1]$ 与 $t[j-l \dots j-1]$ 逐位相等（$pre$ 的定义恰是「最长公共后缀」，$l$ 不超过它即全程相等）；$r \le suf[i+1][j+1]$ 同理保证右侧相等；$s[i] \ne t[j]$ 保证恰有一处不同；长度 $l + r + 1 \ge 1$ 非空。重构与分解互逆。∎

**引理 2（$pre$ / $suf$ 递推正确）**：$pre[i][j]$ 等于以 $s[i-1]$、$t[j-1]$ 结尾的最长公共后缀长度，且递推式成立。

**证明**：若 $s[i-1] \ne t[j-1]$，任何非空后缀末位即失配，公共后缀长为 0。若相等：长为 $k$ 的公共后缀去掉末位后是「以 $s[i-2], t[j-2]$ 结尾的公共后缀」，故最长值 $= pre[i-1][j-1] + 1$（截断到边界时 $pre[0][\cdot] = 0$ 正确处理空串）。归纳即得。$suf$ 对称（前缀方向、反向归纳）。∎

**定理**：$\text{ans} = \sum_{s[i] \ne t[j]} (pre[i][j] + 1)(suf[i+1][j+1] + 1)$。

**证明**：由引理 1，答案集合与四元组集合 $\{(i,j,l,r)\}$ 之间存在双射；由引理 1 的约束条件，对固定 $(i, j)$（$s[i] \ne t[j]$），合法的 $l$ 有 $pre[i][j] + 1$ 个（$0 \dots pre[i][j]$），合法的 $r$ 有 $suf[i+1][j+1] + 1$ 个，乘法原理得该失配位贡献两者之积；对不同 $(i,j)$ 求和即得。∎

## 6. 复杂度分析

- **时间**：填两张表各 $O(nm)$，枚举失配位 $O(nm)$，总计 $O(|s| \cdot |t|) \le 10^4$。
- **空间**：两张 $(n+1) \times (m+1)$ 表，$O(nm)$；滚动对角线可压至 $O(\min(n, m) + 1)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int countSubstrings(string s, string t) {
        int n = (int)s.size(), m = (int)t.size();
        // pre[i][j]：以 s[i-1]、t[j-1] 结尾的最长公共后缀长度
        // suf[i][j]：从 s[i]、t[j] 开始的最长公共前缀长度
        vector<vector<int>> pre(n + 1, vector<int>(m + 1, 0)), suf(n + 1, vector<int>(m + 1, 0));
        for (int i = 1; i <= n; ++i)
            for (int j = 1; j <= m; ++j)
                pre[i][j] = (s[i - 1] == t[j - 1]) ? pre[i - 1][j - 1] + 1 : 0;
        for (int i = n - 1; i >= 0; --i)
            for (int j = m - 1; j >= 0; --j)
                suf[i][j] = (s[i] == t[j]) ? suf[i + 1][j + 1] + 1 : 0;
        long long ans = 0;
        for (int i = 0; i < n; ++i)
            for (int j = 0; j < m; ++j)
                if (s[i] != t[j])
                    ans += (long long)(pre[i][j] + 1) * (suf[i + 1][j + 1] + 1);
        return (int)ans;
    }
};
```

### Python

```python
class Solution:
    def countSubstrings(self, s: str, t: str) -> int:
        n, m = len(s), len(t)
        pre = [[0] * (m + 1) for _ in range(n + 1)]
        suf = [[0] * (m + 1) for _ in range(n + 1)]
        for i in range(1, n + 1):
            for j in range(1, m + 1):
                pre[i][j] = pre[i - 1][j - 1] + 1 if s[i - 1] == t[j - 1] else 0
        for i in range(n - 1, -1, -1):
            for j in range(m - 1, -1, -1):
                suf[i][j] = suf[i + 1][j + 1] + 1 if s[i] == t[j] else 0
        return sum((pre[i][j] + 1) * (suf[i + 1][j + 1] + 1)
                   for i in range(n) for j in range(m) if s[i] != t[j])
```

> 💡 两份代码均通过官方 4 个示例（`6`、`3`、`0`、`10`）；另与「枚举起点对 + 逐位延伸、差异超 1 即 break」的 $O(n^3)$ 暴力对拍 400 组随机数据（字母表大小 $1/2/3/26$ 全覆盖，含 $s = t$、单字符、$100 \times 100$ 满规模），并做 200 组 C++/Python 互拍，全部一致，`mismatch = 0`。

## 8. 边界情况与易错点

1. **$s = t$ 时答案未必为 0**：若 $s = t = $ "ab"，("a"@0, "b"@1) 与 ("b"@1, "a"@0) 是两对**内容不同**的子串，各差一个字符，答案为 2。官方示例 3 输出 0 只是因为 $s = t = $ "a"——唯一的一对子串完全相同。**不要**写「$s = t$ 直接返回 0」这种特判。
2. **索引偏移**：$pre$ 用 $s[i-1]$ 比较、$suf$ 用 $s[i]$ 比较；失配位查 $pre[i][j]$ 与 $suf[i+1][j+1]$——三处偏移务必分清，这是本题 WA 的头号来源。
3. **「+1」的含义**：左右公共长度可以为 0（失配位贴边），取法数是「长度 0..L」共 $L+1$ 种，不是 $L$ 种。
4. **完全相同的对齐位置不贡献**：条件 `s[i] != t[j]` 不能漏。
5. **长度 1 的子串对**：满足「恰好差一个字符」当且仅当两字符不同，公式中对应 $pre = suf = 0$、贡献 $1 \cdot 1 = 1$，自然覆盖。
6. **答案规模**：最坏 $10^8$ 量级，C++ 用 `long long` 累加最稳（`int` 实际也放得下，$10^4$ 项、每项 $\le 10201$，总和 $\le 1.02 \times 10^8$）。
