# LeetCode 通过给定词典构造目标字符串的方案数 题解

## 1. 题目概述

- **标题 / 题号**：通过给定词典构造目标字符串的方案数（#1639，hard）
- **链接**：https://leetcode.cn/problems/number-of-ways-to-form-a-target-string-given-a-dictionary/
- **来源**：LeetCode 第 38 场双周赛 Q4
- **难度**：困难
- **标签**：数组、字符串、动态规划

**题意**：给定字符串列表 `words`（所有单词**长度相同**，记列数 $L$）与目标串 `target`（长度 $m$）。构造方式为：从左到右依次确定 `target` 的每个字符；第 $i$ 个字符可以从任意单词的第 $k$ 列取（要求 `words[j][k] = target[i]`），但一旦用了第 $k$ 列，**之后所有单词中小于等于 $k$ 的列都不能再用**——等价于所选列下标必须**严格递增**。同一个单词的多个字符可以多次使用（不同列之间）。求构造方案数，对 $10^9+7$ 取余。

**约束**：

- $1 \le words.length \le 1000$
- $1 \le words[i].length,\ target.length \le 1000$，`words` 中所有单词等长
- `words[i]` 与 `target` 仅含小写字母

> ⚠️ 「方案」是**完整的选取序列**：不仅列下标序列 $k_1 < k_2 < \cdots < k_m$ 要确定，每一步选用**哪个单词**的该列字符也计入方案（示例 1 中列序列同为 $(0,1,3)$ 的不同单词组合算不同方案）。这正是答案能到 $6$ 而非 $3$ 的原因。

## 2. 示例

**示例 1**

```text
输入：words = ["acca","bbbb","caca"], target = "aba"
输出：6
解释：合法的 (列序列, 单词选择) 共 6 种，例如：
  列 (0,1,3)：'a' 取自 acca[0]，'b' 取自 bbbb[1]，'a' 取自 caca[3] 或 acca[3] —— 2 种；
  列 (0,2,3)：同样 2 种；
  列 (1,2,3)：'a' 取自 caca[1]，'b' 取自 bbbb[2]，'a' 取自 caca[3] 或 acca[3] —— 2 种。
```

**示例 2**

```text
输入：words = ["abba","baab"], target = "bab"
输出：4
解释：4 种列+单词组合：
  (0,1,2), (0,1,3), (0,2,3), (1,2,3) 各 1 种。
```

**示例 3**

```text
输入：words = ["abcd"], target = "abcd"

```

```text

输出：16
```

## 3. 解题思路

### 3.1 暴力思路

DFS 枚举每个 target 字符选哪一列：状态为（已拼到 target 第几位，上一列下标），转移枚举所有严格更大的列。状态数 $O(m \cdot L)$、每步转移 $O(L)$，总量 $O(m L^2) \approx 10^9$，会超时；更致命的是它没有利用「**单词之间彼此独立**」这一结构。注意到一个方案是否合法、以及它的数量，只取决于「第 $k$ 列上有多少个单词的字符是 $c$」——先把整个 `words` 压缩成一张 $L \times 26$ 的计数表 $cnt$，信息量从 $1000 \times 1000$ 字符降到 $1000 \times 26$ 个整数。

### 3.2 核心观察：列计数表 + 「跳过列」型 DP

![核心观察：列字符计数表 cnt 与 DP 状态](images/bw38_q4_column_cnt.svg)

定义

$$f[i][j] = \text{只用前 } j \text{ 列、拼出 } target[0..i-1] \text{ 的方案数}.$$

边界 $f[0][j] = 1$（拼空串恒有 1 种方案），$f[i][0] = 0$（$i \ge 1$，没有列可用）。按「第 $j$ 列是否被第 $i$ 个字符使用」二分：

$$f[i][j] = \underbrace{f[i][j-1]}_{\text{第 } j \text{ 列不用}} + \underbrace{f[i-1][j-1] \cdot cnt[j-1][target[i-1]]}_{\text{在第 } j \text{ 列取 } target[i-1]}$$

答案为 $f[m][L]$。直觉核对：每往右挪一列，「要么跳过它，要么消费一个 target 字符」；消费时的方案数乘上「该列上正确字符的单词个数」，单词选择就完整计入——不需要枚举具体选了哪个单词，乘法原理替我们数完了。

> 💡 一个有用的直觉：把 $L$ 列想成 $L$ 道闸门从左到右排开，target 的字符必须按顺序从**递增**的闸门取；DP 的第二维 $j$ 是「闸门进度条」，这就是「区间型」计数 DP 的经典形状（同 115. 不同的子序列）。

### 3.3 状态转移与滚动数组

![状态转移：f[i][j] 的两来源与倒序滚动](images/bw38_q4_dp_transition.svg)

$f$ 的第 $j$ 维只依赖 $j-1$ 维，可以滚动掉：记 $f[i]$ 为「处理完当前列后拼出前 $i$ 个字符的方案数」，每处理新的一列时**倒序**更新 $i$（从 $m$ 到 $1$）：

$$f[i] \mathrel{+}= f[i-1] \cdot cnt[\text{当前列}][target[i-1]]$$

倒序的原因与 01 背包完全一致：$f[i-1]$ 必须还是「上一列」的旧值，若正序更新，$f[i-1]$ 已混入当前列的贡献，等于允许同一列被重复使用。

### 3.4 示例演算

![示例演算：示例 1 的 cnt 表与 f 演化](images/bw38_q4_walkthrough.svg)

示例 1：`words = ["acca","bbbb","caca"]`，`target = "aba"`。先统计列计数表（只列出现的字母）：

| 列 $j$ | a | b | c |
|--------|---|---|---|
| 0 | 1（acca） | 1（bbbb） | 1（caca） |
| 1 | 1（caca） | 1（bbbb） | 1（acca） |
| 2 | 0 | 1（bbbb） | 2（acca, caca） |
| 3 | 2（acca, caca） | 1（bbbb） | 0 |

滚动数组 $f$ 初始为 $[1, 0, 0, 0]$（$f[i]$ = 拼出 `target` 前 $i$ 位的方案数），逐列**倒序**更新（$i$ 从 $m=3$ 降到 1，用字符 $target[i-1]$ 查表）：

```text
第 0 列：i=3 ('a',计数1)：f[3]+=0；i=2 ('b',计数1)：f[2]+=0；i=1 ('a',计数1)：f[1]+=1·1=1
        → f = [1,1,0,0]
第 1 列：i=3 ('a',计数1)：f[3]+=f[2]·1=0；i=2 ('b',计数1)：f[2]+=f[1]·1=1；
        i=1 ('a',计数1)：f[1]+=f[0]·1 → f[1]=2
        → f = [1,2,1,0]
第 2 列：i=3 ('a',计数0)：跳过；i=2 ('b',计数1)：f[2]+=f[1]·1=2 → f[2]=3；
        i=1 ('a',计数0)：跳过
        → f = [1,2,3,0]
第 3 列：i=3 ('a',计数2)：f[3]+=f[2]·2=3·2=6 → f[3]=6 ✓
        （i=2、i=1 的更新不再影响 f[3]）
```

最终 $f[3] = 6$ ✓。对照引理 2 复核：用前 3 列拼出前缀 "ab" 的方案 $f[2] = 3$，恰对应列序列 $(0,1), (0,2), (1,2)$ 各 1 种；第 3 个字符 'a' 从列 3 取有 2 个单词可选，$3 \times 2 = 6$，与 $(0,1,3), (0,2,3), (1,2,3)$ 三条列序列各 2 种的枚举一致。

## 4. 算法细节

1. **cnt 表构建**：`cnt[j][c] = #{w : w[j] = c}`，一次遍历所有单词 $O(\sum |words[i]|) \le 10^6$。
2. **滚动数组倒序更新**：外层列、内层 $i$ **从 $m$ 降到 $1$**。正序会把「本列已用」的值泄漏给后面的 $i$，等于同一列用两次。
3. **$m > L$ 直接返回 0**：严格递增序列最长 $L$，拼不出更长的 target；DP 不提前判也能得到 0，但提前判省时。
4. **取模节奏**：每次乘法后立刻 `% MOD`；C++ 中 $f[i-1] \cdot cnt$ 两数均 $< 10^9+7$，乘积达 $10^{18}$，`long long` 恰好容纳（上界约 $9.2 \times 10^{18}$），必须先取模再累加。
5. **消费 0 方案列的自动短路**：若某列上 `cnt[c] = 0`，转移项为 0，`f` 不变——不需要显式跳过。
6. **空间**：$cnt$ 为 $O(26L)$，滚动 $f$ 为 $O(m)$，总空间远小于存整个 DP 表的 $O(mL)$。

## 5. 正确性证明

**引理 1（方案的规范化）**：每个合法方案恰对应一个五元组序列 $\big((k_1, w_1), (k_2, w_2), \dots, (k_m, w_m)\big)$，满足

$$1 \le k_1 < k_2 < \cdots < k_m \le L,\qquad words[w_i][k_i] = target[i-1]\ (1 \le w_i \le |\text{words}|).$$

**证明**：方案由「target 第 $i$ 位所用的列与单词」逐位记录而成；「用过第 $k$ 列后更小的列全被禁用」⟺ 所选列按使用顺序严格递增（target 从左到右构造，列序即使用序）。反之，任何满足上式的序列都给出一个合法方案：列严格递增保证不违反禁用规则，字符匹配保证拼出 target。两个方向的构造互逆，计数对象相同。∎

**引理 2（按列序列合并计数）**：对固定列序列 $k_1 < \cdots < k_m$，合法方案数为 $\prod_{i=1}^{m} cnt[k_i - 1][target[i-1]]$；不同列序列的方案集互不相交。

**证明**：列序列固定后，各位的单词选择相互独立（不同位置可用同一个或不同单词，无约束联动），乘法原理即得乘积；方案集合不相交因为列序列是方案的一部分（引理 1），不同列序列的方案在「第一位使用的列」等处必不相同。∎

**定理（DP 正确）**：$f[i][j]$ 的递推计算的是「在所有长度为 $i$、末列 $< j$ 的列选择上的 $\prod cnt$ 总和」，即引理 2 意义下拼出 $target[0..i-1]$ 的方案数；特别地 $f[m][L]$ 为答案。

**证明**：对 $(i, j)$ 双重归纳。基础：$f[0][j] = 1$（空序列，唯一方案，乘积为空积 1）；$f[i][0] = 0$（$i \ge 1$，没有列可选）。归纳步：末列 $< j$ 的方案按「是否使用第 $j-1$ 列**作为最后一个字符的列**」划分为不交的两类——(a) 未使用：列选择全部落在前 $j-1$ 列，计 $f[i][j-1]$；(b) 使用：第 $i$ 个字符取自第 $j-1$ 列，则前 $i-1$ 个字符的列选择在前 $j-1$ 列，计 $f[i-1][j-1]$；第 $j-1$ 列的单词选择有 $cnt[j-1][target[i-1]]$ 种，与前缀独立相乘。两类之和即递推式。滚动数组倒序更新保持了「$f[i-1]$ 取自上一列」的语义，与二维递推等价。∎

## 6. 复杂度分析

- **时间**：$O\left(\sum_i |words[i]| + L \cdot m\right)$——建表 $O(10^6)$，DP $O(1000 \times 1000) = 10^6$，总量约 $2 \times 10^6$，远优于暴力的 $O(mL^2)$。
- **空间**：$O(26L + m)$——cnt 表加滚动数组；不压维的写法 $O(mL)$ 也能过（$10^6$ 个 `long long` 约 8 MB），但压维后只剩 0.13 MB 量级。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int numWays(vector<string>& words, string target) {
        const long long MOD = 1000000007LL;
        int L = (int)words[0].size(), m = (int)target.size();
        if (m > L) return 0;
        // cnt[j][c]：第 j 列上字符 c 出现的单词数
        vector<vector<int>> cnt(L, vector<int>(26, 0));
        for (const auto& w : words)
            for (int j = 0; j < L; ++j) ++cnt[j][w[j] - 'a'];
        // f[i]：用「已处理的列」拼出 target 前 i 个字符的方案数（滚动）
        vector<long long> f(m + 1, 0);
        f[0] = 1;
        for (int j = 0; j < L; ++j) {
            for (int i = m; i >= 1; --i) {              // 倒序：f[i-1] 保持上一列的值
                int c = target[i - 1] - 'a';
                f[i] = (f[i] + f[i - 1] * cnt[j][c]) % MOD;
            }
        }
        return (int)f[m];
    }
};
```

### Python

```python
class Solution:
    def numWays(self, words: list[str], target: str) -> int:
        MOD = 10 ** 9 + 7
        L, m = len(words[0]), len(target)
        if m > L:
            return 0
        cnt = [[0] * 26 for _ in range(L)]
        for w in words:
            for j, ch in enumerate(w):
                cnt[j][ord(ch) - 97] += 1
        f = [0] * (m + 1)
        f[0] = 1
        for j in range(L):
            for i in range(m, 0, -1):                   # 倒序：f[i-1] 保持上一列的值
                c = ord(target[i - 1]) - 97
                f[i] = (f[i] + f[i - 1] * cnt[j][c]) % MOD
        return f[m]
```

> 💡 两份代码均通过官方 4 个示例（`6`、`4`、`1`、`16`）；并与「DFS 穷举所有 (列序列, 单词选择)」的暴力对拍 400 组小规模随机数据（单词数 $\le 6$、长度 $\le 8$，字母表 $\{a,b,c\}$ / $\{a,b\}$ 均测），另做 200 组中规模 C++/Python 互拍与 $1000 \times 1000$ 满规模性能验证，全部一致，`mismatch = 0`。

## 8. 边界情况与易错点

1. **「方案」包含单词选择**：只数列序列会得到示例 1 答案 3 而非 6。计数时每个位置的方案数要乘上该列正确字符的单词个数（`cnt`），而不是「能不能取」的 0/1。
2. **滚动数组必须倒序更新**：正序会让同列贡献串联——本列给 $f[i-1]$ 的增量立即又被 $f[i]$ 用上，等于允许同一列被多个字符取用。示例 1 上正序更新最终会算出 $22$ 而非 $6$（第 0 列正序甚至直接拼出 $f[3]=1$，即 "aba" 全取自第 0 列的非法方案）。
3. **$m > L$ 返回 0**：严格递增的列序列长度封顶 $L$；不判也能自然得 0，但提前返回省一轮 DP。
4. **模乘溢出**：C++ 中 `f[i-1] * cnt[j][c]` 两个数 $< 10^9 + 7$，乘积 $\le (10^9+6)^2 \approx 10^{18} < 9.2 \times 10^{18}$，`long long` 安全；若用 `int` 必炸。
5. **cnt 表下标**：`cnt[j][c]` 的 $j$ 是列（0 基），转移里 `target[i-1]` 与 `f[i-1]` 的下标偏移别混。
6. **单词等长**：约束保证所有 `words[i]` 同长，取 `words[0]` 的长度即可；若不放心可用 `min`（本题无需）。
7. **target 含某列完全缺失的字符**：转移项为 0，自动短路；无需特判「无解」。
8. **答案中途为 0 不代表失败**：前几列可能拼不出前缀，后列补上即可——不要在中途「发现 $f[m] = 0$ 提前退出」。
