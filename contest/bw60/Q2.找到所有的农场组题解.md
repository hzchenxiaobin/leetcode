# LeetCode 找到所有的农场组 题解

## 1. 题目概述

- **标题 / 题号**：找到所有的农场组（#1992，medium）
- **链接**：https://leetcode.cn/problems/find-all-groups-of-farmland/
- **来源**：LeetCode 第 60 场双周赛 Q2
- **难度**：中等
- **标签**：深度优先搜索、广度优先搜索、数组、矩阵

**题意**：给定 $m \times n$ 二进制矩阵 `land`，1 表示农场土地、0 表示森林。农场土地以**矩形**的农场组形式存在，且题目保证**任意两个农场组不相邻**（四方向）。请找出所有农场组，每组用其**左上角** $(r_1, c_1)$ 与**右下角** $(r_2, c_2)$ 表示，返回数组 $[r_1, c_1, r_2, c_2]$ 的列表，顺序不限。

**约束**：

- $m = land.length$，$n = land[i].length$，$1 \le m, n \le 300$
- `land` 只含 0 和 1
- 农场组都是矩形形状

## 2. 示例

**示例 1**

```text
输入：land = [[1,0,0],[0,1,1],[0,1,1]]
输出：[[0,0,0,0],[1,1,2,2]]
解释：第一组只有左上角 (0,0) 单格；第二组为 (1,1)~(2,2) 的 2×2 方块。
```

**示例 2**

```text
输入：land = [[1,1],[1,1]]
输出：[[0,0,1,1]]
解释：整个矩阵是一个农场组。
```

**示例 3**

```text
输入：land = [[0]]
输出：[]
解释：没有任何农场土地。
```

## 3. 解题思路

### 3.1 暴力思路（DFS/BFS 连通块）

最朴素的做法是把「农场组」当一般连通块：扫描全图，遇到未访问的 1 就 DFS/BFS 整块，过程中维护 $(min_r, min_c, max_r, max_c)$，访问过的格子置 0 或打标记。正确性毋庸置疑，复杂度 $O(mn)$，也能过。但这套写法**没有用到本题最关键的保证**——组是矩形且互不相邻；通用连通块代码在矩形输入上做了大量「白跑」：明明从左上角一步就能定位边界，却要把整块格子都走一遍。

### 3.2 核心观察：矩形组 ⇒ 「左上角 + 双向探测」就够

![核心观察：左上角判据与行列探测](images/bw60_q2_rectangle_scan.svg)

**左上角判据**：格子 $(i, j)$ 是某个组的左上角，当且仅当 $land[i][j] = 1$，且其**上方**与**左侧**都不是农场土地（出界视为非农场）：

$$land[i][j] = 1 \;\wedge\; (i = 0 \lor land[i-1][j] = 0) \;\wedge\; (j = 0 \lor land[i][j-1] = 0)$$

理由：组是矩形，$(i, j)$ 若非组内第一行第一列，其上/左邻格必属同一组且为 1；反之组的最小行列格子必满足判据。**组互不相邻**保证两个不同组的格子不会上下左右贴着，判据不会把「别的组的边缘」误认成本组的延伸。

**边界探测**：从左上角 $(i, j)$ 出发，沿**第一列**向下走到底得 $r_2$（首个 $land[r_2+1][j] = 0$ 或出界），沿**第一行**向右走到边得 $c_2$。矩形性保证组内每行同宽、每列同高，第一行/列的连续 1 恰好框出整个组——无需访问内部格子，更无需 DFS。

### 3.3 算法流程

```text
1. 按行主序扫描每个格子 (i, j)
2. 若 land[i][j] != 1：跳过
3. 若 (i > 0 且 land[i-1][j] == 1) 或 (j > 0 且 land[i][j-1] == 1)：跳过（非左上角）
4. r2 = i；while r2+1 < m 且 land[r2+1][j] == 1：r2++     # 向下探底
5. c2 = j；while c2+1 < n 且 land[i][c2+1] == 1：c2++     # 向右探边
6. 记录 [i, j, r2, c2]
```

### 3.4 示例演算

![示例演算：逐格扫描与两个组的探测过程](images/bw60_q2_walkthrough.svg)

以示例 1（$3\times 3$）走查：扫描 $(0,0)$：是 1，上/左均出界 → 左上角；向下探：$land[1][0]=0$，故 $r_2=0$；向右探：$land[0][1]=0$，故 $c_2=0$；记录 $[0,0,0,0]$。继续扫 $(0,1), (0,2), (1,0)$ 都是 0。扫到 $(1,1)$：是 1，上方 $(0,1)=0$、左侧 $(1,0)=0$ → 左上角；向下 $land[2][1]=1$ 而 $land[3][1]$ 出界，$r_2=2$；向右 $land[1][2]=1$ 而 $land[1][3]$ 出界，$c_2=2$；记录 $[1,1,2,2]$。剩余格子 $(1,2), (2,1), (2,2)$ 虽为 1，但上/左邻为 1，被左上角判据跳过。输出恰为 $[[0,0,0,0],[1,1,2,2]]$，与官方一致。

## 4. 算法细节

1. **行主序扫描的天然好处**：答案组按左上角字典序输出，恰好与官方示例顺序一致（题目虽允许任意顺序，但对拍时省去排序）。
2. **探测只走「十字」两条线**：向下沿第 $j$ 列、向右沿第 $i$ 行；中间格子一概不看。最坏情形（整图全 1）探测总步数也是 $O(m + n)$ 每组，总体仍 $O(mn)$。
3. **不修改输入**：无需 visited 数组、无需把走过的格子清零——左上角判据本身就把组内非左上角格子排除，探测只读不写。
4. **返回类型**：`vector<vector<int>>`，每组 4 个元素；空图返回空列表（示例 3）。
5. **为什么 DFS 版也能过但要防坑**：DFS 需要递归或显式栈，$m, n \le 300$ 时全 1 图递归深度可达 90000，Python 默认递归上限 1000 会爆栈（需 `sys.setrecursionlimit` 或改 BFS/迭代）；本解法完全无递归。
6. **判据里的「或」与「且」**：上出界或上为 0 **均可**（`i == 0 || land[i-1][j] == 0`）；两条件（上、左）须同时成立。写成 `&&`/`||` 混用错误会漏判或误判左上角。

## 5. 正确性证明

**引理 1（左上角存在且唯一）**：每个农场组 $G$（矩形 $r_1..r_2 \times c_1..c_2$）中，$(r_1, c_1)$ 满足左上角判据，且组内其他格子不满足。

**证明**：$(r_1, c_1)$ 是 $G$ 中行列均最小的格子。若 $r_1 > 0$，则 $(r_1 - 1, c_1)$ 与 $G$ 上下相邻，由组间不相邻知它不属于其他组，故为森林即 $land[r_1-1][c_1] = 0$（$r_1 = 0$ 时出界）；同理左侧为 0 或出界。故判据成立。组内其他格子 $(i, j) \ne (r_1, c_1)$：或 $i > r_1$，此时 $(i-1, j)$ 属于同一矩形组（$r_1 \le i-1 \le r_2$、$c_1 \le j \le c_2$）故为 1；或 $j > c_1$，同理 $(i, j-1)$ 为 1——两种情形都使判据失败。∎

**引理 2（探测正确）**：从满足判据的 $(i, j)$ 出发，沿第 $j$ 列向下的连续 1 恰好终止于 $r_2$（组底行），沿第 $i$ 行向右的连续 1 恰好终止于 $c_2$（组右列）。

**证明**：由引理 1 的对称版（判据保证 $(i,j)$ 是组左上角，即 $i = r_1, j = c_1$）：矩形组内第 $c_1$ 列的 $r_1..r_2$ 行全为 1，而 $(r_2 + 1, c_1)$ 在矩形之外——它若为 1 则要么属于本组（与 $r_2$ 为底矛盾）要么属于别的组（与本组垂直相邻，违反不相邻），故为 0 或出界，向下探测停在 $r_2$。向右探测同理停在 $c_2$。∎

**定理**：算法输出的四元组集合与全部农场组一一对应。

**证明**：**不重**：由引理 1，每个组恰产生一个通过判据的左上角；不同组的左上角互不相同，故每组恰被记录一次。**不漏**：任何通过判据的格子由引理 1 只能是某组的左上角；算法扫描覆盖全部格子，故每组都会被触发记录。**正确**：由引理 2，记录的 $(r_1, c_1, r_2, c_2)$ 恰为组的边界四元组。∎

## 6. 复杂度分析

- **时间**：$O(mn)$。主体是行主序扫描每个格子做 $O(1)$ 判定；每组的探测最多 $O(m + n)$ 步且各组的探测段互不重叠（都在本组的第一行/列上），总计不超过 $O(mn)$。
- **空间**：$O(1)$ 额外空间（不计输出）。没有 visited 数组、没有递归栈、不复制矩阵——这是相对 DFS/BFS 版本的空间优势。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<vector<int>> findFarmland(vector<vector<int>>& land) {
        int m = (int)land.size(), n = (int)land[0].size();
        vector<vector<int>> ans;
        for (int i = 0; i < m; ++i)
            for (int j = 0; j < n; ++j) {
                if (land[i][j] != 1) continue;                 // 只认左上角
                if (i > 0 && land[i - 1][j] == 1) continue;    // 上方已是农场 → 非左上角
                if (j > 0 && land[i][j - 1] == 1) continue;    // 左侧已是农场 → 非左上角
                int r2 = i;                                    // 向下探底
                while (r2 + 1 < m && land[r2 + 1][j] == 1) ++r2;
                int c2 = j;                                    // 向右探边
                while (c2 + 1 < n && land[i][c2 + 1] == 1) ++c2;
                ans.push_back({i, j, r2, c2});
            }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def findFarmland(self, land: list[list[int]]) -> list[list[int]]:
        m, n = len(land), len(land[0])
        ans = []
        for i in range(m):
            for j in range(n):
                if land[i][j] != 1:
                    continue                          # 只认左上角
                if i > 0 and land[i - 1][j] == 1:
                    continue                          # 上方已是农场 → 非左上角
                if j > 0 and land[i][j - 1] == 1:
                    continue                          # 左侧已是农场 → 非左上角
                r2 = i                                # 向下探底
                while r2 + 1 < m and land[r2 + 1][j] == 1:
                    r2 += 1
                c2 = j                                # 向右探边
                while c2 + 1 < n and land[i][c2 + 1] == 1:
                    c2 += 1
                ans.append([i, j, r2, c2])
        return ans
```

> 💡 两份代码均通过官方示例（`[[0,0,0,0],[1,1,2,2]]`、`[[0,0,1,1]]`、`[]`），并与 **DFS 连通块暴力**（四方向泛洪、维护 min/max 边界）对拍 403 组随机合法地图（$m, n \le 9$、随机放置互不相邻矩形组，另含单格、单行、单列全 1 等边界），全部一致。

## 8. 边界情况与易错点

1. **全 0 图**：返回空列表（示例 3），循环体不触发，无需特判。
2. **全 1 图**：一个大组 $[0, 0, m-1, n-1]$；探测走到边界自然停住，`while` 条件里先判界再取值（`r2 + 1 < m && land[r2+1][j] == 1`），顺序颠倒会越界。
3. **单行 / 单列全 1**：$1 \times n$ 或 $m \times 1$ 的组，探测只剩一个方向有效，另一方向立即停止；`[[1]]` 输出 `[[0,0,0,0]]`。
4. **把「组不相邻」当废话**：它是左上角判据成立的前提（引理 2 用到）。若输入退化为一般连通块（如 L 形），本做法会给出错误边界，必须回到 DFS/BFS——比赛时读题务必确认这条保证。
5. **DFS 版的爆栈风险**：$300 \times 300$ 全 1 图递归深度 90000，Python 必须调大递归限制或改迭代；这也是推荐「扫描 + 探测」写法的现实理由。
6. **探测用错行列**：向下必须沿**第 $j$ 列**（`land[r2+1][j]`），向右沿**第 $i$ 行**（`land[i][c2+1]`）；写反成 `land[i][c2+1]` / `land[r2+1][j]` 的镜像错误会得到对角线扩张的错误边界。
