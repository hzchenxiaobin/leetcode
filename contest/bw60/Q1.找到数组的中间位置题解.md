# LeetCode 找到数组的中间位置 题解

## 1. 题目概述

- **标题 / 题号**：找到数组的中间位置（#1991，easy）
- **链接**：https://leetcode.cn/problems/find-the-middle-index-in-array/
- **来源**：LeetCode 第 60 场双周赛 Q1
- **难度**：简单
- **标签**：数组、前缀和

**题意**：给定下标从 0 开始的整数数组 `nums`。中间位置 `middleIndex` 定义为满足「左侧元素之和 == 右侧元素之和」的下标（下标 $i$ 左侧和为 $nums[0] + \dots + nums[i-1]$，右侧和为 $nums[i+1] + \dots + nums[n-1]$；边界处和为 0）。返回**最左边**的 `middleIndex`；不存在则返回 $-1$。本题与主站 724 题（寻找数组的中心下标）相同。

**约束**：

- $1 \le nums.length \le 100$
- $-1000 \le nums[i] \le 1000$

## 2. 示例

**示例 1**

```text
输入：nums = [2,3,-1,8,4]
输出：3
解释：下标 3 左侧和 = 2 + 3 + (−1) = 4，右侧和 = 4，相等。
```

**示例 2**

```text
输入：nums = [1,-1,4]
输出：2
解释：下标 2 左侧和 = 1 + (−1) = 0，右侧和（空）= 0，相等。
```

**示例 3**

```text
输入：nums = [2,5]
输出：-1
解释：i=0：左 0 vs 右 5；i=1：左 2 vs 右 0，均不相等。
```

**示例 4**

```text
输入：nums = [1]
输出：0
解释：单元素数组，左右两侧均为空、和都为 0。
```

## 3. 解题思路

### 3.1 暴力思路

对每个下标 $i$ 分别累加左侧和与右侧和再比较，$O(n)$ 判定一个、$O(n^2)$ 总耗时。$n \le 100$ 时不过 $10^4$ 次加法，能过但难看——而且它重复计算了大量子段和：$i$ 从左到右推进时，左侧和只需加一个数、右侧和只需减一个数。

### 3.2 核心观察：恒等式把双和问题变成单和问题

![核心恒等式：左和与右和的关系](images/bw60_q1_prefix_balance.svg)

记 $total = \sum_j nums[j]$，$left(i) = \sum_{j<i} nums[j]$。则右侧和

$$right(i) = total - left(i) - nums[i]$$

于是判定条件 $left(i) = right(i)$ 等价于一个**单变量**条件：

$$2 \cdot left(i) + nums[i] = total$$

$tota$l 一趟求出后，扫描时维护 $left$：在检查下标 $i$ **之前** $left$ 恰为左侧和；检查完再把 $nums[i]$ 累加进 $left$ 推进到 $i+1$。每个下标 $O(1)$ 判定，整体一趟扫描。

### 3.3 算法流程

```text
1. total = Σ nums
2. left = 0
3. 对 i = 0 .. n−1 依次：
       若 left == total − left − nums[i]：返回 i     # 最左命中即返回
       left += nums[i]                              # 推进到下一位置
4. 扫描完仍无命中：返回 −1
```

### 3.4 示例演算

![示例演算：[2,3,−1,8,4] 的逐下标判定表](images/bw60_q1_walkthrough.svg)

以 `nums = [2,3,-1,8,4]`（$total = 16$）为例：$i=0$ 时 $left=0$、$right=14$，不等；$i=1$ 时 $left=2$、$right=11$；$i=2$ 时 $left=5$、$right=12$；$i=3$ 时 $left=4$、$right=4$ **命中**，返回 3。对照 `[1,-1,4]`（$total=4$）：$i=2$ 时 $left=0=right$，说明最右端也可能是答案（右侧为空的情形）；而 `[2,5]`（$total=7$）两个下标都不满足，返回 $-1$——三种输出形态都有官方示例兜底。

## 4. 算法细节

1. **先求 $total$ 再扫描**：两次遍历各 $O(n)$；也可以只遍历一次（`right` 从 $total$ 起步逐个减），语义等价，先求和的写法最不易错。
2. **判定在累加之前**：进入下标 $i$ 的判定时 `left` 必须是「$i$ 左侧」的和；判定后才 `left += nums[i]`。顺序写反会把自身算进左和。
3. **最左即返回**：题目要求最左边，从 $i=0$ 起扫、命中立即 `return i`，天然最左。
4. **负数与零**：值域含负数（示例 2 的 $1 + (-1) = 0$）与全零数组（此时下标 0 即命中），恒等式对任意整数成立，无需特判。
5. **$n = 1$**：$left=0$、$right=0$，下标 0 直接命中返回 0，循环边界（`total - 0 - nums[0]`）自动正确。

## 5. 正确性证明

**引理（恒等式）**：对任意下标 $i$，$right(i) = total - left(i) - nums[i]$。

**证明**：$total = \sum_{j<i} nums[j] + nums[i] + \sum_{j>i} nums[j] = left(i) + nums[i] + right(i)$，移项即得。∎

**定理**：算法返回的下标是满足条件的全部下标中最小者；若无满足者返回 $-1$。

**证明**：由引理，判定条件 $left(i) = right(i)$ 与 $left(i) = total - left(i) - nums[i]$ 等价，算法检查的正是后者，故每个下标的判定结果与定义一致。算法按 $i = 0, 1, \dots, n-1$ 升序检查且首个命中即返回，由升序性返回的是最小命中下标；全部未命中时返回 $-1$。∎

## 6. 复杂度分析

- **时间**：$O(n)$。一趟求和 + 一趟扫描，每个元素常数次加法与比较；$n \le 100$ 绰绰有余。
- **空间**：$O(1)$。只有 `total`、`left` 两个累加变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int findMiddleIndex(vector<int>& nums) {
        int total = 0;                          // 数组总和
        for (int x : nums) total += x;
        int left = 0;                           // 当前下标左侧元素之和
        for (int i = 0; i < (int)nums.size(); ++i) {
            if (left == total - left - nums[i]) // 右和 = 总和 − 左和 − 自身
                return i;
            left += nums[i];
        }
        return -1;
    }
};
```

### Python

```python
class Solution:
    def findMiddleIndex(self, nums: list[int]) -> int:
        total = sum(nums)                 # 数组总和
        left = 0                          # 当前下标左侧元素之和
        for i, x in enumerate(nums):
            if left == total - left - x:  # 右和 = 总和 − 左和 − 自身
                return i
            left += x
        return -1
```

> 💡 两份代码均通过官方示例（`3`、`2`、`-1`、`0`），并与 **O(n²) 逐下标暴力**（每个下标直接 `sum(nums[:i])` 与 `sum(nums[i+1:])`）对拍 504 组随机数组（含全零、正负混合、单元素），全部一致。

## 8. 边界情况与易错点

1. **判定顺序**：`left` 的累加必须放在判定**之后**，否则左和会把 $nums[i]$ 自身计入（错误地变成 $2 \cdot left + 2 \cdot nums[i] = total$ 型条件）。
2. **单元素数组**：`[7]` 应返回 0（左右都为空）；`[0]` 同样返回 0。别对 $n=1$ 特判返回 $-1$。
3. **负数让「中间位置」不止一个**：如 `[0, 0, 0]` 下标 0 就命中，必须取最左——升序扫描 + 立即返回已覆盖。
4. **无解输出**：返回 $-1$ 而非 0 / 异常；`[2,5]` 是官方给出的无解样例，注意别把它错判成 0。
5. **溢出**：$n \le 100$、$|nums[i]| \le 1000$，$|total| \le 10^5$，`int` 完全够用（Python 无此虑）。
