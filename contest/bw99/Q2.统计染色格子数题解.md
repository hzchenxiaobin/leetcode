# LeetCode 统计染色格子数 题解

## 1. 题目概述

- **标题 / 题号**：统计染色格子数（#2579，medium）
- **链接**：https://leetcode.cn/problems/count-total-number-of-colored-cells/
- **来源**：LeetCode 第 99 场双周赛 Q2
- **难度**：中等
- **标签**：数学

**题意**：无穷大的二维网格，初始全未染色。第 $1$ 分钟把任意一格染成蓝色；之后每分钟把**与蓝色格子相邻**（四连通）的所有未染色格子染成蓝色。求 $n$ 分钟后被染色格子的总数。

**约束**：

- $1 \le n \le 10^5$
- 返回值类型为 `long`（提示结果会超出 32 位整数）

## 2. 示例

**示例 1**

```text
输入：n = 1
输出：1
解释：1 分钟后只有 1 个蓝色格子。
```

**示例 2**

```text
输入：n = 2
输出：5
解释：2 分钟后有 4 个边缘格与 1 个中心格，共 5 个。
```

**示例 3（边界补充）**

```text
输入：n = 3
输出：13
解释：1 + 4 + 8 = 13。
```

## 3. 解题思路

### 3.1 暴力思路

直接在 $(2n+1) \times (2n+1)$ 的有限网格上模拟扩散（中心周围 $n-1$ 步内出不了界），逐分钟 BFS 染色并计数，$O(n^2)$。对 $n \le 10^5$ 是 $10^{10}$ 个格子，时间空间双双爆炸；不过它是小范围验证公式的绝佳对拍工具。比赛正解需要看穿染**色区域的形状**，一步写出闭式。

### 3.2 核心观察：染色区域是不断长大的菱形

![染色区域是逐分钟长大的菱形](images/bw99_q2_diamond_growth.svg)

以初始格为原点，"相邻"是四连通，因此第 $i$ 分钟后染色的恰是所有满足**曼哈顿距离** $|x| + |y| \le i-1$ 的格子 $(x, y)$——一个以原点为中心、半径 $i-1$ 的"斜正方形"（菱形）。第 $i$ 分钟新染上的，正是距离**恰好**为 $i-1$ 的一圈，共 $4(i-1)$ 个。

### 3.3 算法流程 / 公式推导

![一层一层加起来的闭式推导](images/bw99_q2_layer_sum.svg)

逐分钟把新圈累加：

$$f(n) = 1 + 4\cdot 1 + 4\cdot 2 + \dots + 4\cdot(n-1) = 1 + 4\cdot\frac{n(n-1)}{2} = 2n^2 - 2n + 1$$

也可以写成递推 $f(1) = 1$、$f(i) = f(i-1) + 4(i-1)$，两种形式等价，闭式一步算完：

```text
答案 = 2n² − 2n + 1
```

### 3.4 示例演算

| $n$ | 逐层求和 | 闭式 $2n^2-2n+1$ |
|-----|----------|------------------|
| 1   | $1$ | $1$ |
| 2   | $1+4$ | $5$ |
| 3   | $1+4+8$ | $13$ |
| 10  | $1+4+\dots+36$ | $181$ |

最大情形 $n = 10^5$：$2 \times 10^{10} - 2\times 10^5 + 1 = 19\,999\,800\,001$，远超 32 位 `int` 上界，必须用 64 位整数。

## 4. 算法细节

1. **"半径 $r$ 的菱形有多少格"**：$|x|+|y| \le r$ 的整点个数为 $2r^2 + 2r + 1$（$r \ge 0$）。逐层求和时半径取 $r = n-1$，得 $2(n-1)^2 + 2(n-1) + 1 = 2n^2 - 2n + 1$。
2. **一圈为什么是 $4(i-1)$**：$|x| + |y| = r$（$r \ge 1$）的整点：$4$ 个在坐标轴上，其余按四个象限成对，共 $4r$ 个。可直接用小 $r$ 枚举验证。
3. **溢出是本题唯一的"算法外"陷阱**：$n \le 10^5$ 时答案约 $2 \times 10^{10}$，C++ 必须乘之前先转 `long long`（写成 `2LL * n * n`），Python 天然大整数无碍。
4. **为什么可以只看形状**：扩散过程与初始格子选在哪无关（无穷网格平移不变），不妨设原点，画图找规律即可。

## 5. 正确性证明

**引理 1（形状）**：第 $i$ 分钟结束时，染色集合恰为 $B_i = \{(x,y) : |x| + |y| \le i-1\}$。

**证明**：对 $i$ 归纳。$i=1$ 时 $B_1 = \{(0,0)\}$，即第 1 分钟染的那格，成立。设第 $i$ 分钟后为 $B_i$。第 $i+1$ 分钟染上所有与 $B_i$ 四相邻的未染色格；一个未染色格 $p$ 与 $B_i$ 相邻，等价于存在 $q \in B_i$ 使 $|p-q|_1 = 1$（曼哈顿距离 1），即 $|p|_1 \le |q|_1 + 1 \le i$；反之任何 $|p|_1 \le i$ 的格 $p$，取从原点到 $p$ 的最短四向路径上倒数第二个点 $q$，则 $|q|_1 = |p|_1 - 1 \le i-1$，即 $q \in B_i$ 且 $p$ 与 $q$ 相邻。故第 $i+1$ 分钟后恰为 $B_{i+1}$。∎

**引理 2（每圈计数）**：对 $r \ge 1$，$|x|+|y| = r$ 的整点恰有 $4r$ 个。

**证明**：按 $x$ 分类。$x = \pm r$ 时 $y = 0$，贡献 $2$ 点；$x = 0$ 时 $y = \pm r$，贡献 $2$ 点；对其余每个 $0 < |x| < r$，$y = \pm(r - |x|)$，贡献 $2$ 点，共 $2(r-1)$ 个 $x$ 值贡献 $4(r-1)$ 点。合计 $4 + 4(r-1) = 4r$。∎

**定理**：$n$ 分钟后被染色格子数为 $2n^2 - 2n + 1$。

**证明**：$n$ 分钟后区域为 $B_n$（引理 1，半径 $n-1$）。按半径分层：半径 $0$ 贡献 $1$ 格，半径 $r = 1, \dots, n-1$ 各贡献 $4r$ 格（引理 2），故总数
$$1 + \sum_{r=1}^{n-1} 4r = 1 + 4 \cdot \frac{(n-1)n}{2} = 2n^2 - 2n + 1. \qquad \blacksquare$$

## 6. 复杂度分析

- **时间**：$O(1)$，闭式直接计算（递推写法则是 $O(n)$）。
- **空间**：$O(1)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long coloredCells(int n) {
        return 2LL * n * n - 2LL * n + 1;   // 2n^2 - 2n + 1
    }
};
```

### Python

```python
class Solution:
    def coloredCells(self, n: int) -> int:
        return 2 * n * n - 2 * n + 1
```

> 💡 两份代码均通过官方示例（`1`、`5`）与 $n = 3$、$n = 10^5$（$19\,999\,800\,001$）检查；并与独立实现三方对拍：递推式 $f(i) = f(i-1) + 4(i-1)$ 在 $n = 1 \sim 10^5$ 全范围逐点一致，真实网格 BFS 模拟在 $n = 1 \sim 60$ 逐点一致，`mismatch = 0`。

## 8. 边界情况与易错点

1. **$n = 1$**：公式给 $2 - 2 + 1 = 1$，不要在 $n=1$ 上手滑写出 $0$。
2. **溢出（最大陷阱）**：`2 * n * n` 在 C++ 里若 `n` 是 `int`，`2*n*n` 以 `int` 参与计算，$n = 10^5$ 时 $2 \times 10^{10}$ 直接溢出；必须 `2LL * n * n` 或提前转型。题面 metaData 的返回类型 `long` 就是在提示这一点。
3. **别把"相邻"理解成八连通**：八连通扩散出的区域是正方形，第 $i$ 分钟后是 $(2i-1)^2$ 格，公式完全不同；本题是四连通。
4. **闭式别背错符号**：$2n^2 - 2n + 1$ 与 $2(n-1)^2 + 2(n-1) + 1$ 恒等，但粗心容易写成 $2n^2 + 2n + 1$（那是半径为 $n$ 的版本）。
5. **无需取模**：题目要求返回精确值而非取模结果。
