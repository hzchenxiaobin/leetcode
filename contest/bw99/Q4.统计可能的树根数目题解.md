# LeetCode 统计可能的树根数目 题解

## 1. 题目概述

- **标题 / 题号**：统计可能的树根数目（#2581，hard）
- **链接**：https://leetcode.cn/problems/count-number-of-possible-root-nodes/
- **来源**：LeetCode 第 99 场双周赛 Q4
- **难度**：困难
- **标签**：树、深度优先搜索、数组、哈希表、动态规划

**题意**：Alice 有一棵 $n$ 个节点（编号 $0 \sim n-1$）的树，用边表 `edges` 给出。Bob 对树给出若干**猜测** `guesses[j] = [u_j, v_j]`（表示 Bob 猜"$u_j$ 是 $v_j$ 的父节点"，每个猜测对应树中一条真实存在的边）。树根未知；以 $r$ 为根时，一个猜测**命中**当且仅当在该根向下定向后 $u_j$ 恰是 $v_j$ 的父节点。Alice 只告诉 Bob"至少 $k$ 个猜测为真"。求有多少个节点**可能**是树根（即命中数 $\ge k$ 的根的数目）。

**约束**：

- $2 \le n \le 10^5$，`edges.length = n − 1`
- $1 \le guesses.length \le 10^5$，猜测互不相同，且每条猜测都是树中一条边（$u_j \ne v_j$）
- $0 \le k \le guesses.length$

## 2. 示例

**示例 1**

```text
输入：edges = [[0,1],[1,2],[1,3],[4,2]], guesses = [[1,3],[0,1],[1,0],[2,4]], k = 3
输出：3
解释：根 0/1/2 各命中 3 个猜测（≥ k）；根 3、根 4 只命中 2 个。
```

**示例 2**

```text
输入：edges = [[0,1],[1,2],[2,3],[3,4]], guesses = [[1,0],[3,4],[2,1],[3,2]], k = 1
输出：5
解释：链树上每个根都至少命中 1 个猜测。
```

**示例 3（边界补充）**

```text
输入：edges = [[0,1]], guesses = [[1,0],[0,1]], k = 1
输出：2
解释：两个方向都猜了。根 0 命中 (0,1)，根 1 命中 (1,0)，各 1 次 ≥ 1 → 两个根都可行。
```

## 3. 解题思路

### 3.1 暴力思路

对每个节点 $r$ 依次当根：一次 DFS/BFS 求出 `parent[]` 数组（$O(n)$），再扫一遍 `guesses` 统计命中数（$O(m)$），判断是否 $\ge k$。总计 $O(n \cdot (n + m))$，$n, m \le 10^5$ 时约 $2 \times 10^{10}$，必然超时。瓶颈在于：**换一个根就全部重算**。事实上换根时命中数只发生极小的局部变化——这就是本题的核心。

### 3.2 核心观察：换根时只有跨越边的两条猜测翻转

![换根观察：只有跨越边的两条猜测翻转](images/bw99_q4_guess_edge.svg)

固定树边 $e = (p, v)$（$p$ 是以节点 0 为根时 $v$ 的父亲）。把根从 $p$ **移到相邻的** $v$，整棵树里**只有**边 $e$ 的父子方向反了：

- 根在 $p$ 一侧时：$p$ 是 $v$ 的父节点 → 猜测 $(p, v)$ 命中，$(v, p)$ 不命中；
- 根在 $v$ 一侧时：$v$ 是 $p$ 的父节点 → 猜测 $(v, p)$ 命中，$(p, v)$ 不命中。

其余所有树边两侧"根在哪边"没有变化，其对应猜测的命中状态全部保持。于是得到**增量公式**：

$$hit(v) = hit(p) - [(p,v) \in G] + [(v,p) \in G]$$

其中 $G$ 是猜测集合，$[\cdot]$ 为指示函数。一次换根只需 $O(1)$ 次集合查询！

### 3.3 算法流程：两次 DFS（换根 DP）

![两次 DFS 的换根 DP 流程](images/bw99_q4_dfs_flow.svg)

```text
1. 建邻接表；把每条猜测 (u,v) 编码为 u·n+v 存入哈希集合 G
2. 第一次 DFS（以 0 为根，非递归）：
   - 求 parent[]（0 的父亲记为 -1）
   - 记录先序序列 order（保证父先于子）
3. 统计根 0 的命中数 cnt0 = Σ [ parent[v] = u ]（遍历 guesses）
4. 第二次"DFS"：按 order 逐个处理节点 v（其父 p 已处理完）：
       c(v) = c(p) − [ (p,v) ∈ G ] + [ (v,p) ∈ G ]
       答案 += [ c(v) ≥ k ]
5. 返回答案（含根 0 自身的判断）
```

### 3.4 示例演算

![示例 1 的换根走查](images/bw99_q4_example_walk.svg)

**示例 1**：以 0 为根，`p[1]=0, p[2]=1, p[3]=1, p[4]=2`。猜测 $(1,3),(0,1),(2,4)$ 命中（$(1,0)$ 不命中），$hit(0) = 3$。按 `order = 0,1,2,3,4`（其一）换根：

| 根 $r$ | 计算 | $hit(r)$ | $\ge k=3$? |
|---------|------|-----------|------------|
| 0 | 初值 | 3 | ✓ |
| 1 | $3 - [(0,1)\in G] + [(1,0)\in G] = 3-1+1$ | 3 | ✓ |
| 2 | $3 - 0 + 0$（边 (1,2) 无猜测） | 3 | ✓ |
| 3 | $3 - [(1,3)\in G] + 0 = 3-1$ | 2 | ✗ |
| 4 | $3 - [(2,4)\in G] + 0 = 3-1$ | 2 | ✗ |

答案 $3$ ✓（与题面逐根枚举的解释一致）。

**示例 2**（链 $0-1-2-3-4$，$k=1$）：$hit(0)=1$（仅 $(3,4)$），每次换根只翻转相邻边上的一对猜测，各根命中数为 $1,2,3,4,3$，全部 $\ge 1$，答案 $5$ ✓。

## 4. 算法细节

1. **猜测的存储**：$m \le 10^5$，用哈希集合存编码 $u \cdot n + v$（`long long`，$n \le 10^5$ 编码值 $< 10^{10}$ 不溢出），换根时两次 $O(1)$ 查询。也可排序后二分或用自定义哈希的 `unordered_set`。
2. **非递归 DFS**：$n = 10^5$ 时递归深度可达链状树的 $10^5$，Python 必须迭代；C++ 也建议用显式栈，稳妥省心。
3. **order 序列**：pop 栈时把节点追加进 `order`，保证父节点先于子节点出现（这是"第二遍按序递推"的前提）；用 BFS 序代替同样可行。
4. **cnt0 的计算**：直接遍历 `guesses` 检查 `parent[v] == u`，$O(m)$；不要对每条边查两个方向的集合（那要先有 parent，等价但绕）。
5. **双向猜测**：`guesses` 中可以同时出现 $(u,v)$ 与 $(v,u)$（猜测唯一性只约束有序对），二者在换根时一减一加，公式自动处理。
6. **$k = 0$**：命中数 $\ge 0$ 恒真，答案是全体 $n$ 个节点；公式无需特判。
7. **防重复计数**：`hit[v]` 只在其被 `order` 遍历到时统计一次；根 0 的判断写在循环外。

## 5. 正确性证明

**引理 1（命中的方向刻画）**：猜测 $(u, v)$（树边 $\{u,v\}$）在根 $r$ 下命中，当且仅当去掉边 $\{u,v\}$ 后，$r$ 落在 $u$ 一侧的连通分量（等价地，$r \to v$ 的路径先经过 $u$，即 $parent_r(v) = u$）。

**证明**：以 $r$ 为根定向后，$parent_r(v)$ 是 $r \to v$ 路径上 $v$ 的前驱节点，且该前驱在边 $\{u,v\}$ 上。边 $\{u,v\}$ 把树分成两个连通分量，$r \to v$ 的路径必经此边；路径先抵达的一端就是 $v$ 在该边上的父亲。路径从 $u$ 一侧进入 $\iff r$ 在 $u$ 一侧 $\iff parent_r(v) = u$。∎

**引理 2（增量公式）**：设 $p = parent_0(v)$（以 0 为根时 $v$ 的父亲）。则 $hit(v) = hit(p) - [(p,v) \in G] + [(v,p) \in G]$。

**证明**：根从 $p$ 换成 $v$，只有根的位置从边 $\{p,v\}$ 的 $p$ 侧移到 $v$ 侧；对**任何**其他树边 $\{a,b\}$，根始终在同一侧（除 $\{p,v\}$ 外没有任何边的两侧划分改变），由引理 1，这些边上的全部猜测命中状态不变。边 $\{p,v\}$ 上的两条猜测（若存在）按引理 1：根在 $p$ 侧时 $(p,v)$ 命中、$(v,p)$ 不命中；根在 $v$ 侧时相反。故命中数的变化恰为 $-[(p,v)\in G] + [(v,p)\in G]$。∎

**定理**：算法输出等于 $\#\{r : hit(r) \ge k\}$，其中 $hit(r)$ 是以 $r$ 为根时的命中猜测数。

**证明**：先证 $hit(0)$ 正确：第一次 DFS 得到以 0 为根的 `parent`，第 3 步按"父指针相等"逐条统计，正是命中定义。再证递推覆盖所有节点：树以 0 为根构成有根树，`order` 为先序序列，每个非根节点 $v$ 在其父 $p$ 之后出现，且 $(p, v)$ 是树边，引理 2 的前提成立；按 `order` 顺序归纳，处理 $v$ 时 $hit(p)$ 已算好，故 $hit(v)$ 被正确递推。最后，循环中对每个节点（含根 0）各判断一次 $hit \ge k$ 并累加，恰为目标计数。∎

## 6. 复杂度分析

- **时间**：$O(n + m)$。建表与两次遍历各 $O(n)$；猜测建哈希集合与算 $cnt_0$ 各 $O(m)$；换根递推每步 $O(1)$ 共 $n - 1$ 步。
- **空间**：$O(n + m)$。邻接表 $O(n)$，猜测哈希集合 $O(m)$，辅助数组 `parent/order/hit` 各 $O(n)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int rootCount(vector<vector<int>>& edges, vector<vector<int>>& guesses, int k) {
        int n = edges.size() + 1;
        vector<vector<int>> g(n);
        for (const auto& e : edges) {
            g[e[0]].push_back(e[1]);
            g[e[1]].push_back(e[0]);
        }
        unordered_set<long long> gs;                  // 猜测 (u,v) 编码为 u*n+v
        gs.reserve(guesses.size() * 2);
        for (const auto& gu : guesses) gs.insert((long long)gu[0] * n + gu[1]);

        vector<int> parent(n, -1), order;             // 非递归 DFS，order 中父先于子
        order.reserve(n);
        vector<int> stk{0};
        vector<char> vis(n, 0);
        vis[0] = 1;
        while (!stk.empty()) {
            int u = stk.back(); stk.pop_back();
            order.push_back(u);
            for (int v : g[u]) if (!vis[v]) {
                vis[v] = 1;
                parent[v] = u;
                stk.push_back(v);
            }
        }
        long long cnt = 0;
        for (const auto& gu : guesses)                // 以 0 为根时命中的猜测数
            if (parent[gu[1]] == gu[0]) ++cnt;

        vector<long long> hit(n);
        hit[0] = cnt;
        long long ans = (cnt >= k) ? 1 : 0;
        for (int i = 1; i < n; ++i) {                 // 换根：order 保证父先算好
            int v = order[i], p = parent[v];
            long long c = hit[p];
            if (gs.count((long long)p * n + v)) --c;  // 猜测 (p,v) 由真变假
            if (gs.count((long long)v * n + p)) ++c;  // 猜测 (v,p) 由假变真
            hit[v] = c;
            ans += (c >= k) ? 1 : 0;
        }
        return (int)ans;
    }
};
```

### Python

```python
class Solution:
    def rootCount(self, edges: list[list[int]], guesses: list[list[int]], k: int) -> int:
        n = len(edges) + 1
        g = [[] for _ in range(n)]
        for a, b in edges:
            g[a].append(b)
            g[b].append(a)
        gs = {u * n + v for u, v in guesses}       # 猜测 (u,v) 编码为 u*n+v

        parent = [-1] * n                          # 非递归 DFS，父先于子进 order
        order = []
        vis = [False] * n
        vis[0] = True
        stk = [0]
        while stk:
            u = stk.pop()
            order.append(u)
            for v in g[u]:
                if not vis[v]:
                    vis[v] = True
                    parent[v] = u
                    stk.append(v)

        cnt = sum(1 for u, v in guesses if parent[v] == u)   # 以 0 为根的命中数
        hit = [0] * n
        hit[0] = cnt
        ans = 1 if cnt >= k else 0
        for v in order[1:]:                        # 换根：父节点先算好
            p = parent[v]
            c = hit[p]
            if p * n + v in gs:
                c -= 1                             # 猜测 (p,v) 由真变假
            if v * n + p in gs:
                c += 1                             # 猜测 (v,p) 由假变真
            hit[v] = c
            if c >= k:
                ans += 1
        return ans
```

> 💡 两份代码均通过官方示例（`3`、`5`）、双向猜测与 $k=0$ 用例，$n = 10^5$ 链状树大规模测试 0.4 秒内通过；并与"逐根 BFS 重算父指针"的独立暴力对拍 400 组随机树（$n \le 9$、双向猜测、随机 $k$），`mismatch = 0`。

## 8. 边界情况与易错点

1. **$k = 0$**：任何根都满足（命中数非负），答案为 $n$；不要因为"至少 0 个为真"语义而漏判。
2. **$k > m$ 或 $k >$ 任一根可达命中数**：答案为 0，公式自然给出，无需特判。
3. **猜测是树边但方向任意**：同一条无向边 $(a,b)$ 可能只被猜成 $(b,a)$，也可能双向都被猜；换根公式的一减一加对两个方向独立处理，别只考虑单方向。
4. **递归爆栈**：链状树深度 $10^5$，Python 默认递归上限 1000 必炸，C++ 也有栈风险；务必显式栈或 BFS。
5. **`order` 的先序性质**：换根循环必须按"父先于子"的顺序处理；若随手按节点编号 $1..n-1$ 递推，父亲可能还没算好（编号顺序与树深度无关），这是一个非常典型的实现错误。
6. **编码冲突**：$u \cdot n + v$ 用 64 位（$n \le 10^5$ 时最大 $10^{10}$）；若用 32 位会溢出/冲突。
7. **`hit` 与根 0 的判断**：根 0 的 $hit \ge k$ 判断在递推循环之外单独完成，别重复或遗漏。
8. **哈希常数**：`unordered_set` 在 $10^5$ 规模足够；若卡常可换成对编码数组排序 + `binary_search`，或按 `vector<vector<int>>` 邻接表存边定向标记（每条边两个布尔）。
