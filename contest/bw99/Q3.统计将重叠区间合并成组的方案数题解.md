# LeetCode 统计将重叠区间合并成组的方案数 题解

## 1. 题目概述

- **标题 / 题号**：统计将重叠区间合并成组的方案数（#2580，medium）
- **链接**：https://leetcode.cn/problems/count-ways-to-group-overlapping-ranges/
- **来源**：LeetCode 第 99 场双周赛 Q3
- **难度**：中等
- **标签**：数组、排序

**题意**：给定二维整数数组 `ranges`，`ranges[i] = [start_i, end_i]` 表示**闭区间** $[start_i, end_i]$。把所有区间分成**两个组**（可以为空），要求**有交集的区间必须落在同一组**（两个区间有至少一个公共整数即算有交集）。求总方案数，对 $10^9+7$ 取模。

**约束**：

- $1 \le ranges.length \le 10^5$
- $0 \le start_i \le end_i \le 10^9$（区间可退化为单点，可以互相嵌套、重复）

## 2. 示例

**示例 1**

```text
输入：ranges = [[6,10],[5,15]]
输出：2
解释：两区间有交集，必须同组。方案：全放第 1 组，或全放第 2 组。
```

**示例 2**

```text
输入：ranges = [[1,3],[10,20],[2,5],[4,8]]
输出：4
解释：[1,3]、[2,5]、[4,8] 链式相交必须同组；[10,20] 与它们无交集。
方案：{全组1}、{全组2}、{链组1+ [10,20] 组2}、{链组2 + [10,20] 组1}。
```

**示例 3（边界补充）**

```text
输入：ranges = [[1,3],[4,5]]
输出：4
解释：1 < 4，两闭区间无公共整数，互不约束 → 2×2 = 4 种。
而 [[1,3],[3,5]] 输出 2：3 同时属于两区间，有交集，必须同组。
```

## 3. 解题思路

### 3.1 暴力思路

把 $m$ 个区间两两之间"是否相交"建图（$O(m^2)$ 次相交判定），显然 $m = 10^5$ 时 $10^{10}$ 次比较不可行。退一步，用**并查集**或**传递闭包**把"链式相交"的区间缩成连通块，块数 $g$，答案 $2^g$——这已经可行（$O(m \log m)$）；但本题有更顺手的写法：**排序后一遍扫描合并**，逻辑更短，也不需要显式建图。

### 3.2 核心观察：排序扫描合并出 $g$ 个"组块"，每个组块二选一

![排序扫描：相交就并入当前组](images/bw99_q3_merge_groups.svg)

把区间按左端点升序排序后从左往右扫，维护**当前组块的右端点** `curEnd`：

- 若新区间 `start > curEnd`：它与左边所有区间都无交集，**新开一个组块**；
- 否则（`start ≤ curEnd`）：它与当前组块相交，**并入**并把 `curEnd` 扩张为 $\max(curEnd, end)$。

扫描结束后得到 $g$ 个**两两无交集**的组块。组与组之间没有任何约束，每个组块独立地选择进第 1 组还是第 2 组：

![每个组块两个去向，方案数为 2^g](images/bw99_q3_two_choice.svg)

$$\text{答案} = 2^g \bmod (10^9 + 7)$$

> ⚠️ 注意**闭区间**的细节：$[1,3]$ 与 $[3,5]$ 共享整数 $3$，属于有交集，必须同组——所以合并条件是 `start <= curEnd` 而不是 `start <= curEnd + 1`，更不是严格小于。

### 3.3 算法流程

```text
1. ranges 按 (start, end) 升序排序
2. groups = 0, curEnd = −1
3. 对每个区间 [s, e]：
       若 s > curEnd：groups++，curEnd = e        # 新组块
       否则：curEnd = max(curEnd, e)              # 并入并扩张
4. 输出 2^groups mod 1e9+7（快速幂）
```

### 3.4 示例演算

**示例 2**（`[[1,3],[10,20],[2,5],[4,8]]`）：排序得 `[1,3],[2,5],[4,8],[10,20]`。

| 步骤 | 区间 | 判定 | 动作 | curEnd | 组块 |
|------|------|------|------|-------|------|
| 1 | [1,3] | 1 > −1 | 新组块 | 3 | 1 |
| 2 | [2,5] | 2 ≤ 3 | 并入 | 5 | 1 |
| 3 | [4,8] | 4 ≤ 5 | 并入 | 8 | 1 |
| 4 | [10,20] | 10 > 8 | 新组块 | 20 | 2 |

$g = 2$，答案 $2^2 = 4$ ✓。

**示例 1**：`[5,15]` 先入（curEnd=15），`[6,10]` 有 6 ≤ 15 并入 → $g = 1$，答案 $2$ ✓。

## 4. 算法细节

1. **排序关键字**：按左端点升序即可（左端相同时右端顺序不影响结果，因为 `curEnd` 取 max）。
2. **`curEnd` 在新开组块时要重置为新区间的右端**，而不是保留历史最大值——历史组块整体位于新组块左侧且无交，无需再比较。
3. **闭区间相交判定**：$[a,b]$ 与 $[c,d]$（$a \le c$）相交 $\iff c \le b$。共享端点也算相交，这正是本题与"合并区间"类题里 `start <= curEnd` 的经典坑点。
4. **取模**：$g$ 可达 $10^5$，$2^g$ 天文数字，必须用快速幂（Python 直接 `pow(2, g, mod)`）边乘边模。
5. **数据类型**：端点 $\le 10^9$、区间数 $\le 10^5$，计数与端点比较都在 `int/long long` 舒适范围内。
6. **为什么排序扫描等价于并查集**：见 §5 引理 1——排序后"与当前组块相交"与"与任何历史区间相交"同时成立或同时不成立。

## 5. 正确性证明

**引理 1（扫描正确性）**：设区间按左端点升序排列为 $I_1, \dots, I_m$。处理到 $I_j$ 时，令 $curEnd_j = \max\{e_i : i < j,\ I_i$ 与 $I_j$ 当前所在组块同块 $\}$（新开组块时为其自身右端的扩张）。则：$I_j$ 与某个更早的区间有交集 $\iff s_j \le \max_{i<j} e_i'$，其中 $e_i'$ 是各"历史组块"的最大右端；且这些历史组块的右端都 $\le$ 当前组块首个区间的左端，从而 $I_j$ 若与当前组块无交，则与所有历史组块无交。

**证明**：对扫描步骤归纳。新开组块的瞬间，组块首区间 $I_t$ 满足 $s_t > \max_{i<t} e_i$（超过此前所有区间右端的最大值），因此一切历史组块的整段都落在 $s_t$ 左侧；当前组块内后续区间的左端 $\ge s_t$，故历史组块与当前组块（以及此后所有区间，因为后续 $s_j \ge s_t > $ 历史右端）永远无交。于是对新区间 $I_j$ 只需与**当前组块**比较：闭区间 $I_j = [s_j, e_j]$ 与组块并集 $[\text{块首}, curEnd]$ 相交 $\iff s_j \le curEnd$（$s_j \ge \text{块首}$ 恒成立）。∎

**引理 2（组块 = 相交关系的连通块）**：任一时刻，一个组块内任意两个区间在"有交集"图上连通；不同组块之间两两无交集。

**证明**：组块内区间按并入顺序与前面至少一个区间直接相交（$s_j \le curEnd$ 时，$[s_j, curEnd]$ 这段被组块覆盖，必存在组内某区间与 $I_j$ 有公共整数——具体地，达到 $curEnd$ 的那个区间 $I_t$ 满足 $e_t = curEnd \ge s_j$ 且 $s_t \le s_j$，故 $I_j \cap I_t \supseteq [s_j, \min(e_j, e_t)] \ne \emptyset$）。故组内两两经链连通。组块之间无交已由引理 1 给出。∎

**定理（计数公式）**：合法分组方案数 $= 2^g$，其中 $g$ 为扫描得到的组块数。

**证明**：合法性条件是"每对相交区间同组"。由引理 2，同一组块的区间集合必须**整体**落入同一个组（连通性传递约束：组块内任两点有链，链上相邻必须同组，传递得整块同组）；不同组块之间无任何相交对，彼此选择互不影响。于是每个组块独立地有"进组 1 / 进组 2"两个选择，方案数恰为 $2^g$。两个组允许为空（题面明说），故"全部区间都进组 1""全部进组 2"等极端方案都被计入，无需扣除。∎

## 6. 复杂度分析

- **时间**：$O(m \log m)$。排序主导；一遍扫描 $O(m)$；快速幂 $O(\log g)$。
- **空间**：$O(1)$ 额外（C++ 原地排序）；Python 排序需 $O(m)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int countWays(vector<vector<int>>& ranges) {
        const long long MOD = 1'000'000'007;
        sort(ranges.begin(), ranges.end());
        long long groups = 0, curEnd = -1;
        for (const auto& r : ranges) {
            if (r[0] > curEnd) {                     // 与左侧已合并的组无交集 → 新组
                ++groups;
                curEnd = r[1];
            } else {                                 // 有交集 → 并入当前组
                curEnd = max(curEnd, (long long)r[1]);
            }
        }
        long long ans = 1, base = 2, e = groups;     // 快速幂求 2^groups
        while (e) {
            if (e & 1) ans = ans * base % MOD;
            base = base * base % MOD;
            e >>= 1;
        }
        return (int)ans;
    }
};
```

### Python

```python
class Solution:
    def countWays(self, ranges: list[list[int]]) -> int:
        ranges.sort()
        groups, cur_end = 0, -1
        for s, e in ranges:
            if s > cur_end:              # 与已合并的组都不相交 → 新开一组
                groups += 1
                cur_end = e
            else:                        # 与当前组有交集 → 并入
                cur_end = max(cur_end, e)
        return pow(2, groups, 10**9 + 7)
```

> 💡 两份代码均通过官方示例（`2`、`4`）；并与"枚举 $2^m$ 种分组、逐对校验相交同组"的独立暴力对拍 300 组随机数据（$m \le 10$、含单点、嵌套、端点相贴等情形），`mismatch = 0`。

## 8. 边界情况与易错点

1. **端点相贴的闭区间**：$[1,3]$ 与 $[3,5]$ 有公共整数 3，**必须合并**。合并条件写 `s > curEnd` 时才分块，别手滑写成 `s >= curEnd` 或 `s > curEnd + 1`。
2. **单点区间与重复区间**：`[5,5]`、完全相同的区间彼此相交，自然并入同组，无需特判。
3. **初始 `curEnd`**：端点非负（$\ge 0$），初始化为 $-1$ 即可保证第一个区间必然开新组；若端点可能为负数则需要更小的哨兵。
4. **忘记取模 / 忘记快速幂**：$g$ 最大 $10^5$，直接 `1 << groups` 会溢出到天上去；C++ 手写快速幂，Python 用三参 `pow`。
5. **组可以为空**：全放一组也是合法方案（示例 1 的答案 2 正说明了这点），不要额外去重或减 1。
6. **不要混淆"区间数"与"组块数"**：答案是 $2^{\text{组块数}}$ 而非 $2^{\text{区间数}}$；链式相交的 $10^5$ 个区间可能只有 1 个组块。
7. **并查集写法的坑**：若按"相邻排序区间相交则合并"写，逻辑同样正确（排序后不相交的区间对必然隔着不相交链），但要意识到排序扫描已经隐式完成了这件事。
