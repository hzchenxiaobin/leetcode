# LeetCode 人员站位的方案数 I 题解

## 1. 题目概述

- **标题 / 题号**：人员站位的方案数 I（#3025，medium）
- **链接**：https://leetcode.cn/problems/find-the-number-of-ways-to-place-people-i/
- **来源**：LeetCode 第 123 场双周赛 Q2
- **难度**：中等
- **标签**：几何、数组、数学、枚举、排序

**题意**：给出 $n$ 个人在平面上的坐标 `points[i] = [xi, yi]`，每个人占一个点。Alice 要以自己的坐标为**左上角**、Bob 的坐标为**右下角**围一个矩形围栏（可能退化成一个点或一条线段），要求围栏**内部与边界**上除 Alice、Bob 外没有别人。求合法的有序点对 (Alice, Bob) 数量。

**约束**：

- $2 \le n \le 50$
- points[i].length == 2
- $0 \le points[i][0], points[i][1] \le 50$
- points 中所有点两两不同

## 2. 示例

**示例 1**

```text
输入：points = [[1,1],[2,2],[3,3]]
输出：0
解释：三点都在直线 y = x 上，x 变大时 y 也变大。任取两点，x 较小的那个 y 也更小，
      于是「x 不减」与「y 不增」无法同时成立，没有任何一对满足左上→右下的方位关系。
```

**示例 2**

```text
输入：points = [[6,2],[4,4],[2,6]]
输出：2
解释：合法对为 (4,4)→(6,2) 与 (2,6)→(4,4)；
      (2,6)→(6,2) 不合法，因为 (4,4) 落在围栏内部。
```

**示例 3**

```text
输入：points = [[3,1],[1,3],[1,1]]
输出：2
解释：合法对为 (1,3)→(1,1)（竖直线段）与 (1,1)→(3,1)（水平线段）；
      (1,3)→(3,1) 不合法，因为 (1,1) 落在围栏边界上。
```

## 3. 解题思路

### 3.1 暴力思路

直接按题意翻译即可：枚举所有**有序对** $(A, B)$（$A \ne B$），先检查 $A$ 是否在 $B$ 的左上角，再扫描其余 $n - 2$ 个点看有没有人落在矩形里。复杂度 $O(n^3)$。

$n \le 50$ 时 $n^3 = 1.25 \times 10^5$，完全够用。本题是 Q4 的小数据版，考的就是能否把题面的几何语言准确翻译成坐标不等式——**越是签到式的枚举题，越容易在等号上翻车**。

### 3.2 核心观察：把「左上 / 右下」与「矩形为空」写成不等式

![A 必须左上、B 必须右下，且闭矩形内不能再有人](images/bw123_q2_rectangle_model.svg)

设 $A = (x_1, y_1)$、$B = (x_2, y_2)$，坐标轴 $x$ 向右、$y$ 向上。两个条件分别翻译为：

1. **方位**：Alice 是左上角，所以她的 $x$ 不能更大、$y$ 不能更小，即
$$x_1 \le x_2 \quad \text{且} \quad y_1 \ge y_2.$$
这里必须用 $\le$、$\ge$ 而不是严格不等号——题面明确说围栏可以「不包含任何面积」，也就是退化成水平或竖直的线段，此时 $y_1 = y_2$ 或 $x_1 = x_2$ 依然合法（示例 3 的两个答案都是这种退化情形）。

2. **矩形为空**：围栏覆盖的闭区域是
$$\{(x, y) \mid x_1 \le x \le x_2,\ y_2 \le y \le y_1\},$$
除 $A$、$B$ 外不能有其它点落进去。注意是**闭区间**：边界上的点也算「有人」，示例 3 里 $(1,3)\to(3,1)$ 正是被边界上的 $(1,1)$ 判死的。

### 3.3 算法流程

![枚举 A、B，再扫一遍其余点](images/bw123_q2_algorithm_flow.svg)

```text
ans = 0
for i in 0..n-1:                       # i 扮演 Alice
    for j in 0..n-1, j != i:           # j 扮演 Bob
        若 x_i > x_j 或 y_i < y_j: 跳过
        empty = true
        for k in 0..n-1, k != i, k != j:
            若 x_i <= x_k <= x_j 且 y_j <= y_k <= y_i:
                empty = false; 跳出
        若 empty: ans += 1
返回 ans
```

三层循环，外层两层枚举有序对（$n(n-1)$ 种），内层扫描 $n - 2$ 个点，总判断量约 $n^3$。

### 3.4 示例演算

![示例 3 逐个有序对走查](images/bw123_q2_example_walkthrough.svg)

以示例 3 的 `[[3,1],[1,3],[1,1]]` 为例，六个有序对逐一检查：

| A | B | 方位 | 矩形内其它点 | 是否计数 |
|---|---|------|--------------|----------|
| (3,1) | (1,3) | $x$ 变小，方向反了 | — | 否 |
| (3,1) | (1,1) | $A$ 在 $B$ 右侧 | — | 否 |
| (1,3) | (1,1) | 竖直线段 | 无 | **是** |
| (1,3) | (3,1) | 整块矩形 | (1,1) 在边界 | 否 |
| (1,1) | (3,1) | 水平线段 | 无 | **是** |
| (1,1) | (1,3) | $A$ 在 $B$ 下方 | — | 否 |

答案为 2，与题面一致。注意第三行与第五行都是「退化矩形」，说明等号必须允许。

## 4. 算法细节

1. **有序对而非组合**：$(A, B)$ 与 $(B, A)$ 角色不同，所以内层循环从 $0$ 开始且跳过 $j = i$，而不是写成 $j = i + 1$。
2. **先筛方位再扫点**：方位不满足时直接 `continue`，省掉一次 $O(n)$ 扫描；$n$ 小的时候这点优化无所谓，但习惯值得保留。
3. **闭区间判定**：`x1 <= x && x <= x2 && y2 <= y && y <= y1`，四个边都取等号。写成开区间会漏掉「点在边界上」的情形，示例 3 立刻出错。
4. **点两两不同**：题目保证 `points` 中不存在重复点，因此不必担心 $A$、$B$ 坐标相同导致矩形退化成一个点。
5. **计数用 `int`**：答案上界是 $n(n-1) \le 2450$，`int` 足够。
6. **提前跳出**：内层一旦发现入侵点就 `break`，用 `for (int k = 0; k < n && empty; ++k)` 这类写法更整洁。

## 5. 正确性证明

**引理 1**：$A$ 是矩形左上角、$B$ 是右下角，当且仅当 $x_1 \le x_2$ 且 $y_1 \ge y_2$；此时围栏覆盖的闭区域恰为 $R = \{(x,y) \mid x_1 \le x \le x_2,\ y_2 \le y \le y_1\}$。

**证明**：按题意，矩形四条边分别平行于坐标轴，左上角取 $(\min x, \max y)$、右下角取 $(\max x, \min y)$。若 $A$ 是左上角、$B$ 是右下角，则 $x_1 = \min(x_1,x_2) \le x_2$ 且 $y_1 = \max(y_1,y_2) \ge y_2$。反之若 $x_1 \le x_2$ 且 $y_1 \ge y_2$，则 $\min x = x_1$、$\max x = x_2$、$\max y = y_1$、$\min y = y_2$，故 $A$ 是左上角、$B$ 是右下角，围栏区域即 $R$（当 $x_1 = x_2$ 或 $y_1 = y_2$ 时 $R$ 退化为线段，仍符合题意）。∎

**引理 2**：算法对有序对 $(A, B)$ 计数的充要条件是：$(A, B)$ 是一组合法站位。

**证明**：算法计数当且仅当方位条件成立（引理 1 给出 $A$ 左上、$B$ 右下）且内层扫描未发现任何 $k \notin \{i, j\}$ 使 $points[k] \in R$，即 $R$ 中除 $A$、$B$ 外无其它点，这正是「Alice 不会难过」的定义。∎

**定理**：算法返回的 `ans` 等于合法站位方案数。

**证明**：由引理 2，`ans` 每次自增都对应一个合法方案，故 `ans` 不超过方案总数。反过来，任取一个合法方案，它确定唯一的有序对 $(A, B)$（人是可区分的，Alice 与 Bob 的角色由方位唯一决定），该有序对在双重循环中恰被枚举一次（外层取 $i$ 为 $A$ 的下标、内层取 $j$ 为 $B$ 的下标，组合唯一），且由引理 2 会被计数。故 `ans` 恰好等于方案总数。∎

## 6. 复杂度分析

- **时间**：$O(n^3)$。外层 $n(n-1)$ 个有序对，每个最多扫描 $n-2$ 个点；$n = 50$ 时约 $1.2 \times 10^5$ 次坐标比较。
- **空间**：$O(1)$。除循环变量外不需要额外空间（不修改输入）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int numberOfPairs(vector<vector<int>>& points) {
        int n = points.size(), ans = 0;
        for (int i = 0; i < n; ++i) {
            int x1 = points[i][0], y1 = points[i][1];          // Alice：左上角
            for (int j = 0; j < n; ++j) {
                if (i == j) continue;
                int x2 = points[j][0], y2 = points[j][1];      // Bob：右下角
                if (x1 > x2 || y1 < y2) continue;              // 必须 x 不减、y 不增
                bool empty = true;
                for (int k = 0; k < n && empty; ++k) {
                    if (k == i || k == j) continue;
                    int x = points[k][0], y = points[k][1];
                    if (x1 <= x && x <= x2 && y2 <= y && y <= y1) empty = false;
                }
                if (empty) ++ans;
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def numberOfPairs(self, points: list[list[int]]) -> int:
        n = len(points)
        ans = 0
        for i in range(n):
            x1, y1 = points[i]
            for j in range(n):
                if i == j:
                    continue
                x2, y2 = points[j]
                if x1 > x2 or y1 < y2:
                    continue
                ok = True
                for k in range(n):
                    if k == i or k == j:
                        continue
                    x, y = points[k]
                    if x1 <= x <= x2 and y2 <= y <= y1:
                        ok = False
                        break
                if ok:
                    ans += 1
        return ans
```

> 💡 两份代码通过三个官方示例（`0`、`2`、`2`）；此外与 Q4 的 $O(n^2)$ 扫描版在 300 组 $n \le 60$ 的随机点集上对拍，`mismatch = 0`，说明两版对「边界上有点」的判定完全一致。

## 8. 边界情况与易错点

1. **等号必须放行**：$x_1 = x_2$ 或 $y_1 = y_2$ 时围栏退化成线段，题面明确允许，示例 3 的两个答案都属于此类。写成严格不等号会漏掉一半答案。
2. **点对是有序的**：$A$、$B$ 交换后方位关系通常相反，不能只枚举 $i < j$ 再乘 2（只有对称的情形才恰好相反，一般并不对称）。
3. **边界上的点算「有人」**：闭区间判定，四个比较都要带等号。这是示例 3 中 $(1,3)\to(3,1)$ 被判无效的原因。
4. **$n = 2$**：只有一对有序对可能合法，答案只能是 $0$ 或 $1$；此时内层扫描的 $k$ 循环一次都不执行，`empty` 保持 `true`。
5. **别把自己算成入侵者**：内层必须跳过 $i$、$j$，否则每对都会被自己判死，答案恒为 0。
6. **坐标范围小但别依赖**：$0 \le x, y \le 50$ 会诱使人开 $51 \times 51$ 的网格标记，本题可行，但 Q4 的坐标是 $\pm 10^9$，同一套代码若直接迁移会溢出，还是老老实实扫描点集更稳妥。
7. **`int` 足够**：答案上界 $n(n-1) = 2450$，不必用 `long long`。
