# LeetCode 人员站位的方案数 II 题解

## 1. 题目概述

- **标题 / 题号**：人员站位的方案数 II（#3027，hard）
- **链接**：https://leetcode.cn/problems/find-the-number-of-ways-to-place-people-ii/
- **来源**：LeetCode 第 123 场双周赛 Q4
- **难度**：困难
- **标签**：几何、数组、数学、枚举、排序

**题意**：给出 $n$ 个互不相同的点 `points[i] = [xi, yi]`，每个点站一个人。Alice 以自己的坐标为**左上角**、Bob 的坐标为**右下角**围一个矩形围栏（可以退化为线段），要求围栏内部与边界上除这两人外没有别人。求合法有序点对数量。

与 Q2 的题面完全相同，只是数据规模从 $n \le 50$、坐标 $\le 50$ 放大到 $n \le 1000$、坐标 $\pm 10^9$：$O(n^3)$ 的暴力会到 $10^9$ 量级，必须降到 $O(n^2)$。

**约束**：

- $2 \le n \le 1000$
- points[i].length == 2
- $-10^9 \le points[i][0], points[i][1] \le 10^9$
- points 中所有点两两不同

## 2. 示例

**示例 1**

```text
输入：points = [[1,1],[2,2],[3,3]]
输出：0
解释：三点共线于 y = x，x 增大时 y 也增大，
      「x 不减」与「y 不增」无法同时成立，没有合法的方位组合。
```

**示例 2**

```text
输入：points = [[6,2],[4,4],[2,6]]
输出：2
解释：合法的两对是 (4,4)→(6,2) 与 (2,6)→(4,4)；
      (2,6)→(6,2) 因 (4,4) 落在围栏内部而不合法。
```

**示例 3**

```text
输入：points = [[3,1],[1,3],[1,1]]
输出：2
解释：合法的两对是退化矩形：(1,3)→(1,1) 与 (1,1)→(3,1)；
      (1,3)→(3,1) 因 (1,1) 落在围栏边界上而不合法。
```

## 3. 解题思路

### 3.1 暴力思路

沿用 Q2 的做法：枚举有序对 $(A, B)$，再扫描其余 $n - 2$ 个点判断是否有人落进矩形。复杂度 $O(n^3)$。

$n = 1000$ 时约 $10^9$ 次判断，常数再小也过不去。优化的方向是：**固定 $A$ 后，把「矩形是否为空」的检查均摊到一次扫描里**，这样每个 $A$ 只需 $O(n)$。

### 3.2 核心观察：固定 A 后，合法 B 就是不断刷新「最高 y」

![固定 A 后，只有不断刷新最高 y 的点才是合法 B](images/bw123_q4_sort_scan_model.svg)

先排序：$x$ 升序，$x$ 相同时 $y$ **降序**。排序后，若 $i < j$，则 $x_i \le x_j$ 必然成立，并且同一列的点按从上到下排列。

固定 $i$（Alice），只考虑 $j > i$ 且 $y_j \le y_i$ 的点（$y_j > y_i$ 的点在围栏上方，本来就不构成威胁）。设

$$mx_j = \max\{\,y_k \;\big|\; i < k < j,\ y_k \le y_i\,\},$$

即「已扫描点里、位于 Alice 水平线以下（含）的最大 $y$」。那么

$$\text{矩形 } [x_i, x_j] \times [y_j, y_i] \text{ 为空} \iff y_j > mx_j.$$

直观理解：$mx$ 是「当前已经挡在面前、最靠上的人」。$j$ 想在围栏里独处，就必须比这个最高障碍还要高（$y$ 更大）。一旦 $y_j > mx$，$j$ 自己就变成了新的最高障碍，于是 $mx \leftarrow y_j$，继续往右扫。因为 $mx$ 只增不减，一次扫描就能判定所有 $j$。

等号的处理是本题的细节：必须严格 $y_j > mx$。若 $y_j = mx$，说明某个更靠左的点与 $j$ 同高，它正压在围栏的上边界（或 $y = y_j$ 这条线上），围栏不空。

### 3.3 算法流程

![把「查矩形是否为空」换成「维护最大 y」](images/bw123_q4_sweep_flow.svg)

```text
按 (x 升序, y 降序) 排序
ans = 0
for i = 0 .. n-1:
    mx = -∞
    for j = i+1 .. n-1:
        若 y_j <= y_i 且 y_j > mx:
            ans += 1
            mx = y_j
返回 ans
```

内层只做比较与赋值，$O(1)$ 摊还，总复杂度 $O(n^2)$。$n = 1000$ 时约 $5 \times 10^5$ 次内层迭代。

### 3.4 示例演算

![示例 2 走查](images/bw123_q4_example_walkthrough.svg)

以示例 2 的 `[[6,2],[4,4],[2,6]]` 为例，排序后为 $(2,6), (4,4), (6,2)$：

| $i$ | $A$ | $j$ | $B$ | 判断 | $mx$ | ans |
|-----|-----|-----|-----|------|------|-----|
| 0 | (2,6) | 1 | (4,4) | $4 \le 6$ ✓，$4 > -\infty$ ✓ | $-\infty \to 4$ | 1 |
| 0 | (2,6) | 2 | (6,2) | $2 \le 6$ ✓，$2 > 4$ ✗ | 4 | 1 |
| 1 | (4,4) | 2 | (6,2) | $2 \le 4$ ✓，$2 > -\infty$ ✓ | $-\infty \to 2$ | 2 |
| 2 | (6,2) | — | 无人 | 循环不进入 | — | 2 |

$i = 0$ 时 $(6,2)$ 被 $(4,4)$ 挡住（$4 > 2$），所以 $(2,6) \to (6,2)$ 不计。最终答案 2。

## 4. 算法细节

1. **排序的并列规则**：$x$ 升序、$y$ 降序。同一列（$x$ 相同）时上方的点排前面，这样「上方的点当 Alice、下方的点当 Bob」才会按 $i < j$ 的顺序出现，否则竖直线段那一类答案会被漏掉。
2. **只处理 $y_j \le y_i$**：$y_j > y_i$ 的点在矩形上方，无论 $mx$ 是多少都不该计入，也不该更新 $mx$（它不在「矩形竖直范围」内）。
3. **严格大于**：$y_j > mx$ 而不是 $\ge$。相等意味着有人与 $j$ 同高且更靠左，正好压在围栏边界上。
4. **`mx` 初值取负无穷**：C++ 用 `INT_MIN`，Python 用 `float('-inf')`，也可以用 $-\infty$ 的替代值 $-2 \times 10^9$（坐标下界是 $-10^9$）。
5. **每个 $i$ 都重置 `mx`**：$mx$ 是「相对当前 Alice」的量，换一个 $A$ 就要清零，不能跨 $i$ 复用。
6. **只往右扫**：$j > i$ 保证 $x_j \ge x_i$，这正是「Bob 在 Alice 右侧（含同列）」的要求；向左扫是多余的。
7. **坐标不参与运算**：坐标只用于比较，$\pm 10^9$ 不会溢出，但若想算差值需用 64 位。
8. **答案为 `int`**：每个有序对至多贡献一次，答案不超过 $n(n-1) \approx 10^6$，远小于 $2^{31}$，`int` 足够。

## 5. 正确性证明

**引理 1（排序后的下标与方位）**：按上述规则排序后，对任意 $i < j$ 有 $x_i \le x_j$；且若 $x_i = x_j$，则 $y_i \ge y_j$。进一步，若 $x_i \le x_j$ 且 $y_i \ge y_j$（即 $(i,j)$ 方位合法），则必有 $i < j$。

**证明**：前两句由排序规则直接得到。第三句：若 $x_i < x_j$，排序按 $x$ 升序给出 $i < j$；若 $x_i = x_j$，由 $y_i \ge y_j$ 且两点不同得 $y_i > y_j$，而同一列按 $y$ 降序排列，故 $i < j$。∎

**引理 2（核心判定）**：固定 $i$，设 $j > i$ 且 $y_j \le y_i$，记 $mx_j = \max\{y_k \mid i < k < j,\ y_k \le y_i\}$（空集时为 $-\infty$）。则点对 $(i, j)$ 合法（围栏内除二者外无点）当且仅当 $y_j > mx_j$。

**证明**：

*必要性*：设 $(i,j)$ 合法。任取 $k$ 满足 $i < k < j$ 且 $y_k \le y_i$。由引理 1，$x_i \le x_k \le x_j$；若再有 $y_k \ge y_j$，则 $y_j \le y_k \le y_i$，即 $k$ 落在闭矩形 $[x_i, x_j] \times [y_j, y_i]$ 内，与「围栏内除 $A$、$B$ 无人」矛盾。故所有这样的 $k$ 都满足 $y_k < y_j$，即 $mx_j < y_j$。

*充分性*：设 $y_j > mx_j$，即不存在 $i < k < j$ 使 $y_j \le y_k \le y_i$。反设存在点 $m \notin \{i,j\}$ 落在闭矩形 $R = [x_i, x_j] \times [y_j, y_i]$ 内，即 $x_i \le x_m \le x_j$ 且 $y_j \le y_m \le y_i$。分三种情况：

1. $i < m < j$：则 $y_m \le y_i$ 且 $y_m \ge y_j > mx_j$，与 $mx_j$ 是这类 $y$ 的最大值矛盾。
2. $m < i$：由 $x_m \ge x_i$ 与引理 1（$m < i \Rightarrow x_m \le x_i$）得 $x_m = x_i$；同列按 $y$ 降序、$m < i$，故 $y_m \ge y_i$，结合 $y_m \le y_i$ 得 $y_m = y_i$，于是 $m$ 与 $i$ 坐标相同，与「点两两不同」矛盾。
3. $m > j$：由 $x_m \le x_j$ 与 $x_m \ge x_j$（$m > j$）得 $x_m = x_j$；同列降序、$m > j$，故 $y_m \le y_j$，结合 $y_m \ge y_j$ 得 $y_m = y_j$，与点互异矛盾。

三种情况都矛盾，故 $R$ 内除 $A$、$B$ 无人，$(i,j)$ 合法。∎

**定理**：算法返回的 `ans` 等于合法有序点对的总数。

**证明**：由引理 1，任一合法有序对 $(A,B)$ 在排序后的下标满足 $i_A < i_B$，故它会在外层取 $i = i_A$、内层取 $j = i_B$ 时被考查，且此时 $y_j \le y_i$ 成立。由引理 2，该对合法当且仅当 $y_j > mx_j$，而算法正是在此条件下计数。另一方面，算法每次 `ans += 1` 都对应一个满足引理 2 条件的点对，即合法对。又因为每个有序对 $(i,j)$ 只会在唯一的一次 $(i,j)$ 循环组合中被考查，计数不重不漏。故 `ans` 恰为合法方案总数。∎

## 6. 复杂度分析

- **时间**：$O(n \log n + n^2)$。排序 $O(n \log n)$；外层 $n$ 次、内层平均 $n/2$ 次，每次常数操作，共 $O(n^2)$。$n = 1000$ 时内层约 $5 \times 10^5$ 次。
- **空间**：$O(1)$ 额外空间（C++ 的 `sort` 为原地排序，递归栈 $O(\log n)$）；Python 的 `sorted` 需要 $O(n)$ 存放新列表。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int numberOfPairs(vector<vector<int>>& points) {
        // x 升序；x 相同则 y 降序，保证同一列内「上方的点」排在前面
        sort(points.begin(), points.end(), [](const vector<int>& a, const vector<int>& b) {
            return a[0] != b[0] ? a[0] < b[0] : a[1] > b[1];
        });
        int n = points.size(), ans = 0;
        for (int i = 0; i < n; ++i) {
            int yi = points[i][1];
            int mx = INT_MIN;                       // 已扫描点中 y <= yi 的最大 y
            for (int j = i + 1; j < n; ++j) {
                int yj = points[j][1];
                if (yj <= yi && yj > mx) {           // 比之前所有候选都更靠上 → 矩形为空
                    ++ans;
                    mx = yj;
                }
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def numberOfPairs(self, points: list[list[int]]) -> int:
        pts = sorted(points, key=lambda p: (p[0], -p[1]))
        n = len(pts)
        ans = 0
        for i in range(n):
            yi = pts[i][1]
            mx = float('-inf')          # 已扫描点中 y <= yi 的最大 y
            for j in range(i + 1, n):
                yj = pts[j][1]
                if yj <= yi and yj > mx:
                    ans += 1
                    mx = yj
        return ans
```

> 💡 两份代码通过三个官方示例（`0`、`2`、`2`），并与 Q2 的 $O(n^3)$ 暴力在 300 组 $n \le 60$ 的随机点集（坐标含重复 $x$、重复 $y$）上对拍，`mismatch = 0`；$n = 1000$ 的随机数据在 C++ 下耗时远小于 $10$ 毫秒。

## 8. 边界情况与易错点

1. **同列必须 $y$ 降序**：若 $x$ 相同时按 $y$ 升序，Alice 会先遇到下方的点，竖直线段那一类答案（示例 3 的第一个答案）会被判成方位颠倒。
2. **严格大于 `mx`**：$y_j = mx$ 表示有人与 $j$ 同高且更靠左，正压在围栏边界上，必须排除。
3. **$y_j > y_i$ 的点既不计数也不更新 `mx`**：它在围栏上方，与矩形无关；若误更新 `mx`，会把后面本来合法的点全部挡掉。
4. **`mx` 每个 $i$ 重置**：忘记重置会让答案偏小。
5. **退化矩形合法**：$x_i = x_j$（竖直线段）或 $y_i = y_j$（水平线段）都要计数，这依赖排序规则与 `<=`/`>=` 的正确使用。
6. **不能只枚举 $i < j$ 再乘 2**：$(i,j)$ 与 $(j,i)$ 通常不能同时合法，答案不是「组合数的两倍」。
7. **坐标 $\pm 10^9$**：只做比较不溢出；若试图用坐标直接开桶或做差累加，务必用 64 位。
8. **$n = 2$**：内层只有一次迭代，答案是 $0$ 或 $1$；注意 `mx` 初值必须小于任何合法 $y$。
9. **排序会改动输入**：C++ 版直接对 `points` 排序，若后续还要用原始顺序需先拷贝；本题无此要求。
