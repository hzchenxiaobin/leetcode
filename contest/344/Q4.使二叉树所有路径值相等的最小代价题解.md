# LeetCode 使二叉树所有路径值相等的最小代价 题解

## 1. 题目概述

- **标题 / 题号**：使二叉树所有路径值相等的最小代价（#2673，medium）
- **链接**：https://leetcode.cn/problems/make-costs-of-paths-equal-in-a-binary-tree/
- **来源**：LeetCode 第 344 场周赛 Q4
- **难度**：中等
- **标签**：贪心、树、数组、动态规划、二叉树

**题意**：给定一棵 $n$ 个节点的**满二叉树**（节点编号 $1 \sim n$，非叶节点 $i$ 的左右孩子恰为 $2i$ 与 $2i+1$），每个节点有值 $\text{cost}[i]$。每次操作可把**任意**节点的值 $+1$，次数不限。目标是让所有**根到叶子的路径值**（路径上节点值之和）相等，求最少操作次数。

**约束**：

- $3 \le n \le 10^5$
- $n + 1$ 是 $2$ 的幂
- $\text{cost.length} = n$
- $1 \le \text{cost}[i] \le 10^4$

> 📚 本题在本仓库另有[每日题解 2673](../../solution/2601-2700/2673_使二叉树所有路径值相等的最小代价.md)：含原地更新细节的面试问答与同类练习表；本篇侧重赛时切入路径、贪心正确性的完整证明（逐层下界引理）与边界复盘。

> 💡 **审题关键**：① 「$n+1$ 是 $2$ 的幂」+「每个非叶节点都有两个孩子」⇒ **完美二叉树**，可数组隐式表示——内部节点恰好是 $1 \sim n/2$，叶子恰好是 $n/2+1 \sim n$，无单孩子节点；② 「只能增加」⇒ 每条路径终值 $\ge$ 初值，公共终值只能向**最大**路径看齐；③ 一次操作只 $+1$，**在哪个节点花这一次**（能同时抬高几条路径）是唯一的优化维度。

> ⚠️ **规模信号**：$n \le 10^5$ ⇒ 需要 $O(n)$ / $O(n \log n)$。叶子多达 $(n+1)/2 \approx 3.3$ 万条路径，任何「枚举路径对」或「逐路径独立补差」的想法要么超时、要么次优——信息必须压缩成**每棵子树一个数**。

## 2. 示例

**示例 1**

```text
输入：n = 7, cost = [1,5,2,2,3,3,1]
输出：6

解释：四条根→叶路径值：①②④ = 1+5+2 = 8、①②⑤ = 1+5+3 = 9、
      ①③⑥ = 1+2+3 = 6、①③⑦ = 1+2+1 = 4，最大 9。
      增 ④ 1 次、⑦ 2 次、③ 3 次后，四条路径全部 = 9，共 1+2+3 = 6 次。
```

**示例 2**

```text
输入：n = 3, cost = [5,3,3]
输出：0

解释：两条路径 5+3 = 5+3 = 8，天然相等，无需操作。
```

**示例 3（自造：覆盖「差额为 0」与「增量落在叶子」两种形态）**

```text
输入：n = 7, cost = [3,1,2,4,1,1,1]
输出：5

解释：四条路径值 = 8、5、6、6。节点 ③ 处 ⑥⑦ 天然相等（差额 0）；
      节点 ② 处 |4−1| = 3（增 ⑤ 3 次）、根处 |5−3| = 2（增 ③ 2 次），
      四条路径全部 = 8，共 5 次——增量既可能落在叶子（⑤），也可能落在内部节点（③）。
```

## 3. 解题思路

### 3.1 暴力思路

**暴力一：逐路径补差（可行但次优）**。DFS 收集全部根→叶路径和，取 $T = \max$，再对每条路径在其**独有**的叶子处补 $T - \text{pathSum}$。所有路径终值都等于 $T$，方案可行，总代价 $\sum_j (T - P_j)$。示例 1 中 $= 1+0+3+5 = 9 > 6$——它把增量全花在叶子这种「一次只覆盖一条路径」的位置，完全放弃了**共享祖先一次抬一片**的杠杆。$O(n)$ 能算完，但答案是错的。

**暴力二：搜索增量组合**。每个节点的增量取值 $0 \sim T$（$T$ 可达 $1.6 \times 10^5$），组合空间天文数字；改 DP 把「子树公共值 $W$」当状态，值域同样巨大，状态爆炸。

> 💡 **破局点**：操作的**覆盖面**由节点位置唯一决定——增节点 $v$ 一次，$v$ 子树内所有路径同步 $+1$，子树外不动。于是「补一片子树的公共差额」的最便宜落点是**该子树的根**；逐层向上看，每对兄弟的差额恰好可以在「兄弟相遇」处就地消化。

### 3.2 核心观察：自底向上，兄弟子树往最大看齐

![核心观察：兄弟子树往最大看齐，增较小的子树根一次抬一片](images/wc344_q4_sibling_align_concept.svg)

三个环环相扣的观察：

**观察 1（操作的树形效应）**：增节点 $v$ 一次 $\iff$ $v$ 子树内所有根→叶路径同步 $+1$。要把某棵子树的所有路径整体抬高 $t$，放在**子树根**上恰好 $t$ 次；放得越深，单次覆盖的路径越少——叶子是覆盖面最小的位置（一次只抬一条）。

**观察 2（终态的层级刻画）**：所有根→叶路径相等 $\iff$ 对**每个**节点 $v$，$v$ 子树内所有 $v \to$ 叶路径相等（两条过 $v$ 的根→叶路径共享 root $\to v$ 前缀，前缀相同 ⇒ $v$ 以下部分相等）。这是**自底向上合并**的许可证：孩子子树先在内部对齐成一个公共值，父层只需面对两个数 $a$、$b$。

**观察 3（只增不减 ⇒ 差额躲不掉）**：设处理节点 $i$ 时，左右孩子子树已分别对齐为 $a$、$b$。终态中两个孩子子树的公共值必须相等（观察 2 应用于 $i$）；而增 $i$ 或更高的祖先会**同时**抬高 $a$、$b$，差额不变——所以差额必须由**较小方子树内部**消化；由观察 1，最便宜的方式是**增较小孩子本身** $|a-b|$ 次（一次抬整片）。

于是得到自底向上的递推（叶子 $\text{sum}[j] = \text{cost}[j]$）：

$$\text{ans} \mathrel{+}= \big|\text{sum}[2i] - \text{sum}[2i+1]\big|, \qquad \text{sum}[i] = \text{cost}[i] + \max\big(\text{sum}[2i],\ \text{sum}[2i+1]\big)$$

直觉：把「往最大看齐」逐层下放——每个内部节点付一次**兄弟差额**，较小方整片追平较大方。

### 3.3 算法流程：一趟倒序扫描 + 原地更新

![算法流程：i 从 n/2 倒序扫到 1，一趟原地更新](images/wc344_q4_inplace_bottomup_flow.svg)

1. **遍历对象**：内部节点 $1 \sim n/2$。由 $n+1 = 2^k$ 保证叶子恰好是 $n/2+1 \sim n$，任何内部节点都有两个孩子，循环体无需存在性判断。
2. **方向**：$i$ 从 $n/2$ **递减**到 $1$——节点编号大的更深，处理 $i$ 时其孩子（编号更大）已处理完毕，$\text{cost}$ 里存的就是「对齐后的子树公共值」。
3. **每个内部节点三步**：
   - 读孩子：$l = \text{cost}[2i-1]$、$r = \text{cost}[2i]$（1-indexed 节点 ↔ 0-indexed 数组）；
   - 累加差额：$\text{ans} \mathrel{+}= |l - r|$；
   - 上传公共值：$\text{cost}[i-1] \mathrel{+}= \max(l, r)$。
4. **原地更新的含义**：$\text{cost}[i-1] \mathrel{+}= \max(l, r)$ 等价于「先把差额 $|l-r|$ 打在较小孩子上（此时两个孩子相等），再把孩子的值累加上来」——增量**不必真的写回**，只以计数进入 $\text{ans}$，因为此后无人再读孩子的值。

### 3.4 示例演算

![示例演算：n=7 自底向上三步，原地更新 cost](images/wc344_q4_bottomup_walkthrough.svg)

以示例 1 走查（数组格为 0-indexed 下标）：

| 步 | $i$ | 读孩子（当前值） | 差额 | ans | 写回 |
|----|-----|------------------|------|-----|------|
| ① | 3 | ⑥ = 3、⑦ = 1 | $\|3-1\| = 2$ | 2 | cost[2] ← 2 + 3 = 5 |
| ② | 2 | ④ = 2、⑤ = 3 | $\|2-3\| = 1$ | 3 | cost[1] ← 5 + 3 = 8 |
| ③ | 1 | ② = 8、③ = 5 | $\|8-5\| = 3$ | 6 | cost[0] ← 1 + 8 = 9 |

三次差额 $2+1+3 = 6$ 恰好对应官方解释的增量方案：⑦ + 2、④ + 1、③ + 3——**每一笔都打在较小的一方**。终态四条路径全部 $= 9 = $ 原地更新后的 cost[0]。

## 4. 算法细节

1. **编号映射（本题最大坑源）**：节点 1-indexed，数组 0-indexed。节点 $i$ ↔ $\text{cost}[i-1]$；孩子 $2i$、$2i+1$ ↔ $\text{cost}[2i-1]$、$\text{cost}[2i]$。循环变量用节点编号、访存时换算，映射关系在草稿上写死再动手。
2. **内部节点范围免判空**：$n+1$ 是 $2$ 的幂 ⇒ 内部节点恰好是 $1 \sim n/2$、叶子恰好是 $n/2+1 \sim n$，循环体无需判断孩子是否存在。若去掉该约束（一般完全二叉树），最深一层可能只有左孩子，需特判。
3. **原地数组的双重身份**：处理前 $\text{cost}[j]$ 是原始值；一旦节点 $j+1$ 被其父处理过，$\text{cost}[j]$ 就变成「对齐后的子树公共值」。倒序扫描保证读孩子时身份已切换完毕。
4. **为什么不需要真的写回增量**：差额 $|l-r|$ 计入 ans 后，两个孩子的「逻辑值」应同为 $\max(l,r)$；但父节点只关心 $\max$，且孩子的值此后无人再读——**计数即写回**。若要求输出具体方案，把差额记在较小孩子头上即可（见延伸思考）。
5. **递归版同理**：后序 DFS 返回子树公共值也行（树高 $\le 16$，无爆栈风险）；但数组倒序循环更短、无函数调用开销，赛时手速优先。
6. **与孪生题 3593 的同构**：同为「后序 + 孩子往最大孩子看齐 + 差额打在孩子根上」，差别只在目标函数——本题数**总增量金额**（差额直接加进 ans），3593 数**被加价的节点数**（整片一起加也只算 1 个节点）。

## 5. 正确性证明

设某方案给各节点的增量为 $\text{inc}(x) \ge 0$。记**初始**树中 $v$ 到其子树内叶子的最大路径和为 $M(v)$（叶子 $M(v) = \text{cost}(v)$，内部 $M(v) = \text{cost}(v) + \max(M(2v),\ M(2v{+}1))$）。

**引理 1（层级刻画）**：方案可行 $\iff$ 对每个节点 $v$，终态中 $v$ 子树内所有 $v \to$ 叶路径的和相等（记该公共值为 $D(v)$）。

**证明**：（⇐）取 $v =$ 根即「所有根→叶路径相等」。（⇒）任取 $v$ 子树内两条 $v\to$ 叶路径 $P_1, P_2$，各自前接 root $\to v$ 前缀得两条根→叶路径；两路径共享前缀且整条和相等，故 $P_1, P_2$ 的和相等。∎

**引理 2（看齐下界）**：对任意可行方案与任意节点 $v$，$D(v) \ge M(v)$。

**证明**：增量非负 ⇒ 任一 $v \to$ 叶路径的终值 $\ge$ 初值；$D(v)$ 等于其中**每条**路径的终值，故 $D(v) \ge \max$ 初值 $= M(v)$。∎

**引理 3（逐层下界）**：对任意可行方案与任意节点 $v$，$v$ 子树内（含 $v$）的总增量 $g(v)$ 满足

$$g(v) \;\ge\; \big(D(v) - M(v)\big) + \sum_{u \in \mathrm{int}(v)} \delta(u), \qquad \delta(u) := \big|M(2u) - M(2u{+}1)\big|$$

其中 $\mathrm{int}(v)$ 为 $v$ 子树内的内部节点集合（含 $v$）。

**证明**：对 $v$ 归纳。**$v$ 为叶子**：$g(v) = \text{inc}(v) = D(v) - \text{cost}(v) = D(v) - M(v)$，右侧求和为空。**$v$ 为内部节点**，孩子 $l = 2v$、$r = 2v{+}1$：由归纳假设，

$$g(v) = \text{inc}(v) + g(l) + g(r) \;\ge\; \text{inc}(v) + \big(D(l) - M(l)\big) + \big(D(r) - M(r)\big) + \!\!\sum_{u \in \mathrm{int}(l) \cup \mathrm{int}(r)}\!\! \delta(u)$$

由引理 1 应用于孩子，$D(l) = D(r) =: d$（且 $D(v) = \text{cost}(v) + \text{inc}(v) + d$）。由引理 2，$d \ge M(l)$ 且 $d \ge M(r)$；不妨 $M(l) \ge M(r)$，则

$$\big(d - M(l)\big) + \big(d - M(r)\big) \;\ge\; \big(d - M(l)\big) + \big(M(l) - M(r)\big)$$

又 $M(v) = \text{cost}(v) + \max(M(l), M(r))$，故

$$\text{inc}(v) + d - \max\big(M(l), M(r)\big) \;=\; \text{inc}(v) + d - \big(M(v) - \text{cost}(v)\big) \;=\; D(v) - M(v)$$

将以上两式代回即得 $g(v) \ge (D(v) - M(v)) + \delta(v) + \sum_{u \in \mathrm{int}(l) \cup \mathrm{int}(r)} \delta(u)$。∎

**定理**：最少操作数 $= \sum_{v\,\text{内部}} \delta(v)$，且自底向上贪心恰好达到。

**证明**：

- **下界**：引理 3 取 $v =$ 根：总操作数 $g(\text{root}) \ge (D(\text{root}) - M(\text{root})) + \sum_v \delta(v) \ge \sum_v \delta(v)$（引理 2）。
- **可达**：对贪心归纳：处理完节点 $v$ 后，$v$ 子树内所有路径的公共值恰为 $M(v)$，且 $v$ 子树内累计操作数恰为 $\sum_{u \in \mathrm{int}(v)} \delta(u)$。叶子平凡（$\text{sum} = \text{cost} = M$）；内部节点：归纳设孩子公共值分别为 $M(l)$、$M(r)$，贪心在 $v$ 处增较小孩子 $\delta(v) = |M(l) - M(r)|$ 次，较小方公共值整片升至 $\max(M(l), M(r))$，于是 $v$ 子树公共值 $= \text{cost}(v) + \max(M(l), M(r)) = M(v)$，累计操作数 $= \delta(v) + \sum_{u \in \mathrm{int}(l) \cup \mathrm{int}(r)} \delta(u)$。∎

> 💡 **引理 3 的直观读法**：$\delta(u) = |M(2u) - M(2u{+}1)|$ 是每对兄弟「初始就存在、任何方案都躲不掉」的差额；$(D(v) - M(v))$ 是子树被抬过初始最大值的「超额」。子树内每多花 $t$ 的超额，父层差额至多省 $t$（收支打平），因此一分不超、恰好停在 $M(v)$ 的贪心不会更差——引理 3 把这个直觉变成了逐层可加的下界。

## 6. 复杂度分析

- **时间**：$O(n)$。恰遍历 $n/2$ 个内部节点，每个 $O(1)$（两次读、一次比较、一次加法）；叶子不进循环。
- **空间**：$O(1)$ 额外——原地复用 cost 数组，仅常数个变量；若不允许修改输入，复制一份为 $O(n)$。
- **对照**：暴力一同样 $O(n)$ 但给出次优解 9（示例 1）——本题难点不在复杂度而在「增量落点」的最优性；贪心与暴力同为 $O(n)$，复杂度不变、正确性升级。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minIncrements(int n, vector<int>& cost) {
        long long ans = 0;
        // i 为节点编号（1-indexed），倒序扫全部内部节点 1..n/2
        for (int i = n / 2; i >= 1; --i) {
            long long l = cost[2 * i - 1], r = cost[2 * i];  // 孩子 2i、2i+1
            ans += abs(l - r);        // 较小方追平的差额，必付
            cost[i - 1] += max(l, r); // 对齐后的子树公共值上传给父
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def minIncrements(self, n: int, cost: List[int]) -> int:
        ans = 0
        # i 为节点编号（1-indexed），倒序扫全部内部节点 1..n/2
        for i in range(n // 2, 0, -1):
            l, r = cost[2 * i - 1], cost[2 * i]  # 孩子 2i、2i+1
            ans += abs(l - r)                    # 较小方追平的差额，必付
            cost[i - 1] += max(l, r)             # 对齐后的子树公共值上传给父
        return ans
```

## 8. 边界情况与易错点

1. **正序循环 = WA 而非 TLE**：若 $i$ 从 1 递增到 $n/2$，父节点先处理，读孩子时孩子尚未对齐，读到「原始值」当「公共值」用。阴在示例 1 上碰巧也算 6（$|5-2|$ 碰巧等于 $|8-5|$），换 cost = [3,1,2,4,1,1,1] 就得 4 ≠ 5 才暴露。方向必须**倒序**（自底向上）。
2. **编号映射错位**：节点 $i$ ↔ cost[i−1]；把 cost[2i]、cost[2i+1] 当孩子的下标（漏 −1）是最常见笔误，小样例直接 WA，务必自查。
3. **循环起点**：从 $i = n/2$ 开始——$n/2$ 是**最深内部节点**的编号，叶子 $n/2+1 \sim n$ 不进循环；误写 $n-1$ 或 $n$ 会越界或多算。
4. **原地修改输入**：LeetCode 不会复用输入数组，可安全改写；本地对拍时记得先拷贝再跑。
5. **对齐目标最大而非平均**：只增不减 ⇒ 公共终值 $\ge$ 最大初始路径和；一旦想「取平均 / 中位数」，说明没吃透单调性——那是对称操作（可增可减）下的直觉，本题不适用。
6. **答案上界与 int**：路径和 $\le 16 \times 10^4$（树高 $\le 16$ 层），逐层放缩 $\sum \delta \le \sum_d 2^d \cdot (15-d) \cdot 10^4 \approx 6.6 \times 10^8$ 未超 int；但朴素粗算 $\frac{n}{2} \times 1.6 \times 10^5 \approx 5 \times 10^9$ 会误判溢出——赛场上用 `long long` 一劳永逸。
7. **n = 3 最小规模**：只循环一次（$i=1$），答案 $= |\text{cost}[1] - \text{cost}[2]|$；示例 2 的 0 说明天然相同时应直接得 0，无需特判。
8. **差额为 0 的兄弟**：天然相等的兄弟（示例 3 的 ⑥⑦）差额为 0，循环自然跳过——但**别**写「相等就 break」，后面还有别的兄弟对。

- [LeetCode 979. 在二叉树中分配硬币](https://leetcode.cn/problems/distribute-coins-in-binary-tree/)：同族后序贪心——每个节点向父汇报子树盈余/缺口，父只做 $O(1)$ 的「过路统计」。

**延伸思考**：

1. **多叉推广**：节点度数不限时结论不变——每个内部节点把孩子对齐到 $\max_c M(c)$，差额 $\sum_c (\max M - M(c))$ 打在各较小孩子根上；引理 3 的归纳逐字照搬（对全体孩子求和即可）。
2. **输出具体方案**：自底向上处理时，把 $\delta(i)$ 记在「较小孩子」头上即可——每个节点至多被父记一次，$O(n)$ 还原每个节点的加量。
3. **允许增减会怎样**：对称操作打破「往最大看齐」的单调性——子树公共值既可上调也可下调（都打在子树根上、每平移 1 花一次），兄弟差额的「方向」出现选择，各层公共值的选取互相耦合，简单贪心不再显然成立，值得动手试一试的进阶变体。
