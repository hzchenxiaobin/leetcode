# LeetCode 二叉搜索树的范围和 题解

## 1. 题目概述

- **标题 / 题号**：二叉搜索树的范围和（#938，easy）
- **链接**：https://leetcode.cn/problems/range-sum-of-bst/
- **来源**：LeetCode 第 110 场周赛 Q2
- **难度**：简单
- **标签**：树、深度优先搜索、二叉搜索树、二叉树

**题意**：给定一棵**二叉搜索树**的根节点 `root` 与闭区间 $[low, high]$，求所有满足 $low \le val \le high$ 的节点值之和。BST 的性质是：对任意节点，**左子树全部小于它，右子树全部大于它**。

**约束**：

- 节点数在 $[1, 2 \times 10^4]$ 内
- $1 \le Node.val \le 10^5$
- 所有节点值**互不相同**

## 2. 示例

**示例 1**

```text
输入：root = [10,5,15,3,7,null,18], low = 7, high = 15
输出：32
解释：区间内的节点是 7、10、15，和为 32。
```

**示例 2**

```text
输入：root = [10,5,15,3,7,13,18,1,null,6], low = 6, high = 10
输出：23
解释：区间内的节点是 6、7、10，和为 23；3 与 1 太小，13 与 15、18 太大。
```

**示例 3（补充，检验剪枝方向）**

```text
输入：root = [10,5,15,3,7,null,18], low = 1, high = 5
输出：8
解释：区间内的节点是 3、5；根 10 > high，整棵右子树（15、18）都可跳过。
```

## 3. 解题思路

### 3.1 暴力思路

遍历整棵树，遇到落在区间内的节点就累加。时间复杂度 $O(n)$，$n \le 2\times 10^4$ 也能过。

但它**完全没有利用 BST 的性质**：如果根节点的值是 $100$，而区间是 $[1, 5]$，那么"根 $>$ high"就已经说明**右子树里所有值都 $> 5$**，整棵右子树一个都不用看。暴力做法仍然会把它们全部访问一遍，白白浪费。

### 3.2 核心观察：按 BST 有序性剪枝（三分支）

![BST 范围求和：只往可能落在区间内的子树走](images/wc110_q2_bst_prune.svg)

设当前节点值为 $v$，BST 性质给出两条**单调性**：

- 左子树所有值 $< v$，右子树所有值 $> v$；
- 因此"值 $\ge low$" 在**中序**意义上是**后缀**，"值 $\le high$" 是**前缀**，两者交集正好是一段连续中序区间。

据此，递归到节点 $v$ 时只有三种情形：

| 情形 | 结论 | 动作 |
|------|------|------|
| $v < low$ | $v$ 与整个**左子树**都 $< low$，必须舍弃 | **只递归右子树** |
| $v > high$ | $v$ 与整个**右子树**都 $> high$，必须舍弃 | **只递归左子树** |
| $low \le v \le high$ | $v$ 计入答案，两侧都可能有合法节点 | 计入 $v$ + **同时递归左右** |

于是每层至多走"一条边"或"两条边但立即收获一个节点"，实测访问节点数 $O(k + h)$（$k$ 为区间内节点数，$h$ 为树高），最坏仍是 $O(n)$，但常数与访问量远小于全树遍历。

### 3.3 算法流程

![rangeSumBST 的三个分支](images/wc110_q2_three_branches.svg)

```text
rangeSumBST(node, low, high):
    若 node 为空：return 0
    若 node.val < low ：return rangeSumBST(node.right, low, high)
    若 node.val > high：return rangeSumBST(node.left , low, high)
    否则              ：return node.val
                              + rangeSumBST(node.left , low, high)
                              + rangeSumBST(node.right, low, high)
```

### 3.4 示例演算

以示例 1（`root = [10,5,15,3,7,null,18]`，$low=7$，$high=15$）为例：

| 访问节点 | 与区间关系 | 处理 |
|----------|-----------|------|
| 10 | $7 \le 10 \le 15$ | 计 10，递归两侧 |
| 5 | $5 < 7$ | 舍弃 5 与左子树（3），只进右子树 |
| 7 | 在区间内 | 计 7，其左右子树为空 |
| 15 | 在区间内 | 计 15，递归两侧 |
| 18 | $18 > 15$ | 舍弃 18 与其右子树，只进左子树（空） |

累加 $10 + 7 + 15 = 32$，与输出一致。注意 3 从未被访问——它被"$5 < low$"这一条剪枝整棵裁掉。

## 4. 算法细节

1. **判定顺序**：先判空，再判 $v < low$，最后判 $v > high$，剩余情形即"在区间内"，代码最短。
2. **剪枝方向易写反**：$v < low$ 时合法值只会更大，所以只去**右**子树；$v > high$ 时只去**左**子树。写成相反方向会在示例 1 上直接挂。
3. **中序遍历也可行**：BST 中序是升序序列，遇到 $> high$ 立即 `break`，也可 $O(n)$ 通过；但剪枝法不必访问全部节点，且不需要额外数组。
4. **迭代写法**：用一个栈（或队列）做 DFS，把 $v \in [low, high]$ 才入栈的孩子挑出来，同样保持剪枝；队列会退化为 BFS，剪枝效果略差但结果正确。
5. **返回类型**：$n \le 2\times 10^4$、$val \le 10^5$，和最大约 $2\times 10^9$，**接近 32 位有符号上界**（$2.147\times 10^9$）。为稳妥，C++ 可用 `long long` 累加再转回 `int`；本题官方数据保证不溢出。
6. **递归深度**：BST 可能退化成链，深度达 $2\times 10^4$，C++ 与 Python 均需注意栈深（Python 默认递归限制 1000，链状输入会 `RecursionError`，见 §8）。

## 5. 正确性证明

**引理 1（子树值域）**：对 BST 中任意节点 $u$，其左子树所有值 $< u.val$，右子树所有值 $> u.val$。

**证明**：BST 的定义即：任意节点的左子树只含严格更小的值，右子树只含严格更大的值。∎

**引理 2（剪枝不丢合法节点）**：递归到节点 $v$ 时，若 $v < low$，则 $v$ 与 $v$ 的整棵左子树中不存在值落在 $[low, high]$ 的节点。

**证明**：由引理 1，左子树所有值 $< v < low$，加上 $v$ 本身，全部严格小于 $low$，不可能落在区间内。∎

**引理 3（对称剪枝）**：若 $v > high$，则 $v$ 与其整棵右子树中不存在落在 $[low, high]$ 的节点。

**证明**：由引理 1，右子树所有值 $> v > high$，全部严格大于 $high$。∎

**定理**：算法返回所有满足 $low \le val \le high$ 的节点值之和。

**证明**：对树高归纳。设 $S(T)$ 是子树 $T$ 中落在区间的值之和。

- 空树：返回 0，$S = 0$，成立。
- $v < low$：由引理 2，$S(T) = S(T.right)$（左子树与根贡献均为 0），算法恰好返回 `rangeSumBST(T.right)`，成立。
- $v > high$：由引理 3，$S(T) = S(T.left)$，算法返回 `rangeSumBST(T.left)`，成立。
- $low \le v \le high$：$S(T) = v + S(T.left) + S(T.right)$，算法三项相加，由归纳假设两个子调用分别返回 $S(T.left)$ 与 $S(T.right)$，成立。∎

## 6. 复杂度分析

- **时间**：最坏 $O(n)$（区间覆盖全部节点）；有剪枝时实际访问量是 $O(k + h)$ 级别，其中 $k$ 为区间内节点数、$h$ 为树高。每个被访问节点只做 $O(1)$ 工作。
- **空间**：递归栈 $O(h)$，$h$ 最坏为 $n$（退化链），平均为 $O(\log n)$；无额外数组开销。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int rangeSumBST(TreeNode* root, int low, int high) {
        if (!root) return 0;
        if (root->val < low) return rangeSumBST(root->right, low, high);
        if (root->val > high) return rangeSumBST(root->left, low, high);
        return root->val + rangeSumBST(root->left, low, high)
                        + rangeSumBST(root->right, low, high);
    }
};
```

### Python

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right


class Solution:
    def rangeSumBST(self, root: "TreeNode | None", low: int, high: int) -> int:
        # 迭代 DFS，避免退化链导致的递归深度爆栈
        ans, stack = 0, [root]
        while stack:
            node = stack.pop()
            if node is None:
                continue
            if node.val < low:            # 只需向右找
                stack.append(node.right)
            elif node.val > high:         # 只需向左找
                stack.append(node.left)
            else:                         # 在区间内：累加并两侧都探
                ans += node.val
                stack.append(node.left)
                stack.append(node.right)
        return ans
```

## 8. 边界情况与易错点

1. **$v < low$ 时只走右子树**：方向写反是本题第一号错误（示例 1 的节点 5 会因此漏掉 7）。
2. **闭区间**：$low$、$high$ 本身都算在内，判定必须是 `low <= val <= high`，不要写成严格不等。
3. **空树 / 单节点**：`root` 可能为空指针，必须先判空；单节点树在区间内时返回自身。
4. **区间完全覆盖**：$low$ 极小、$high$ 极大时退化为整棵树求和，复杂度 $O(n)$，属正常。
5. **退化链导致递归爆栈**：BST 可以是 $2\times 10^4$ 深的链。C++ 通常能过，**Python 建议改用迭代版**（见参考代码），或把 `sys.setrecursionlimit(10**6)` 调大。
6. **求和溢出**：$2\times 10^4 \times 10^5 = 2\times 10^9$ 逼近 `int` 上界，若题目放宽到 $10^5$ 个节点就应改用 `long long`。
7. **不必中序遍历**：中序遍历 + `break` 也能过，但那是 $O(n)$ 而非剪枝；两者都对，剪枝版更贴合 BST 有序性。
8. **不要在中途返回**：$low \le v \le high$ 时两侧都可能有合法节点，漏掉一侧会少算。
