# LeetCode 最小面积矩形 题解

## 1. 题目概述

- **标题 / 题号**：最小面积矩形（#939，medium）
- **链接**：https://leetcode.cn/problems/minimum-area-rectangle/
- **来源**：LeetCode 第 110 场周赛 Q3
- **难度**：中等
- **标签**：几何、数组、哈希表、数学、排序

**题意**：给定平面上 $n$ 个**互不相同**的整点 `points[i] = [x_i, y_i]`，从中挑出四个点，使它们构成一个**边与坐标轴平行**的矩形（允许面积为 0 的退化情形不算），求这样的矩形的**最小面积**；若不存在则返回 `0`。

**约束**：

- $1 \le points.length \le 500$
- $0 \le x_i, y_i \le 4 \times 10^4$
- 所有给定点互不相同

## 2. 示例

**示例 1**

```text
输入：points = [[1,1],[1,3],[3,1],[3,3],[2,2]]
输出：4
解释：四个角 (1,1)(1,3)(3,3)(3,1) 构成 2×2 的矩形；(2,2) 是孤点，用不上。
```

**示例 2**

```text
输入：points = [[1,1],[1,3],[3,1],[3,3],[4,1],[4,3]]
输出：2
解释：候选矩形有两个——x∈{1,3} 面积 4，x∈{3,4} 面积 1×2=2，取最小 2。
```

**示例 3（补充，无解情形）**

```text
输入：points = [[1,1],[2,2],[3,3]]
输出：0
解释：所有点共线，找不到两条不同的 x 与两条不同的 y，返回 0。
```

## 3. 解题思路

### 3.1 暴力思路

枚举四个点，判定它们是否构成轴平行矩形：组合数 $O(n^4) = 500^4 \approx 6.25\times 10^{10}$，不可行。

换个角度枚举"矩形"本身：枚举两条横线 $y_1 < y_2$ 与两条竖线 $x_1 < x_2$，检查四个角是否都在点集里。坐标值域是 $4\times 10^4$，枚举量 $O(V^4)$ 更加爆炸。

唯一可用的"暴力"是 $O(n^2)$ 打底的多项式做法，但朴素地把点对当"一条边"（同行或同列）再去配对另一边，会退化到 $O(n^3)$ 甚至 $O(n^4)$。

### 3.2 核心观察：矩形 ⟺ 一条对角线的两点 + 另两角存在

![枚举一条对角线的两点，其余两角必须存在](images/wc110_q3_diagonal.svg)

轴平行矩形有一个极强的性质：**它的四个角完全由任意一条对角线的两个端点决定**。设对角端点为 $P_1=(x_1,y_1)$、$P_2=(x_2,y_2)$ 且 $x_1 \ne x_2,\ y_1 \ne y_2$，那么另外两个角**只能是**

$$P_3 = (x_1, y_2), \qquad P_4 = (x_2, y_1).$$

于是判定一个矩形"存在"只需两步：

1. 枚举所有点对 $(P_1, P_2)$，跳过 $x_1 = x_2$ 或 $y_1 = y_2$ 的退化对；
2. 用**哈希集合** $O(1)$ 查询 $P_3$、$P_4$ 是否都在点集中。

若都在，该矩形面积

$$S = \lvert x_1 - x_2 \rvert \cdot \lvert y_1 - y_2 \rvert,$$

对所有可行矩形取最小值即可。

**为什么不用枚举"两条边"**：以点对为边需要按"同一行/同一列"分组再笛卡尔积配对，最坏仍是 $O(n^2)$ 次配对，但额外需要分组与去重，代码复杂度更高；"对角线"视角把 4 个点压成 2 个自由点，是最省参数化的形式。

### 3.3 算法流程

![minAreaRect：O(n²) 对角线枚举](images/wc110_q3_flow.svg)

```text
1. 预处理：S = { (x, y) | (x, y) ∈ points }
2. best = ∞
3. for i in 0..n-1:
       for j in i+1..n-1:
           若 x_i == x_j 或 y_i == y_j: continue        // 退化对，不可能是对角线
           若 (x_i, y_j) ∉ S 或 (x_j, y_i) ∉ S: continue
           best = min(best, |x_i - x_j| * |y_i - y_j|)
4. return best == ∞ ? 0 : best
```

### 3.4 示例演算

![示例 2：三个候选矩形，取面积 2](images/wc110_q3_example.svg)

对示例 2 的 `points = [[1,1],[1,3],[3,1],[3,3],[4,1],[4,3]]`：

| 对角线端点 | 另两角 | 是否都在点集 | 面积 |
|-----------|--------|-------------|------|
| (1,1)-(3,3) | (1,3), (3,1) | 是 | $2 \times 2 = 4$ |
| (1,1)-(4,3) | (1,3), (4,1) | 是 | $3 \times 2 = 6$ |
| (3,1)-(4,3) | (3,3), (4,1) | 是 | $1 \times 2 = 2$ ★ |
| (1,1)-(3,1) | — | 同行，跳过 | — |

最小面积 $2$，与输出一致。示例 1 中只有 `(1,1)-(3,3)` 与它"倒过来"的对角线可行，面积同为 $4$；`(2,2)` 与任何点配对都缺角。

## 4. 算法细节

1. **点编码**：C++ 用 `long long key = x * 40001 + y` 压成一个整数（$x,y < 40001$ 保证不碰撞），比 `unordered_set<pair<int,int>>` 免去自定义哈希。也可直接用 `set<pair<int,int>>`，代价是多一个 $\log n$。
2. **退化对跳过**：$x_1 = x_2$ 或 $y_1 = y_2$ 时"另两角"会与端点重合，面积恒为 0，必须显式跳过，否则会错误地把 0 当作候选答案。
3. **面积类型**：$|x_1-x_2| \cdot |y_1-y_2| \le 4\times10^4 \times 4\times10^4 = 1.6\times10^9$，仍在 32 位有符号范围内，但乘之前用 `long long` 更保险（若坐标放宽就溢出）。
4. **初值**：用 `-1` 或 `INT_MAX` 都可以，但返回前要统一处理"没有矩形"的情形，返回 `0` 而不是 `INT_MAX`。
5. **对称重复**：同一条对角线会被 $(i,j)$ 与 $(j,i)$ 各枚举一次，得到同一矩形同一面积，不影响最小值，无需去重。
6. **剪枝**：若当前 `best` 已很小，仍无法提前跳过枚举（面积与点对无单调关系）；但可以按 $x$ 排序后利用"同 x 的点"分块枚举，常数略优。
7. **哈希劣化**：`unordered_set` 在极端数据下可能退化，`reserve` 一下可缓解；本题 $n\le500$ 无压力。

## 5. 正确性证明

**引理 1（轴平行矩形四角都在点集）**：若四点构成轴平行矩形，则它们必为 $(x_1,y_1),(x_1,y_2),(x_2,y_1),(x_2,y_2)$ 的形式，其中 $x_1\ne x_2$、$y_1\ne y_2$。

**证明**：轴平行矩形的四条边分别平行于 $x$ 轴与 $y$ 轴，故四个顶点的 $x$ 坐标只取两个值（对应两条竖边）、$y$ 坐标只取两个值（对应两条横边），且这两个值各自不同，四条边才有正长度。四个顶点即两个 $x$ 值与两个 $y$ 值的全部四种组合。∎

**引理 2（对角线决定矩形）**：任取引理 1 中矩形的一条对角线端点 $(x_1,y_1)$、$(x_2,y_2)$（$x_1\ne x_2,\ y_1\ne y_2$），则另外两角必为 $(x_1,y_2)$ 与 $(x_2,y_1)$，且矩形面积 $= \lvert x_1-x_2\rvert\cdot\lvert y_1-y_2\rvert$。

**证明**：由引理 1 四角为两个 $x$ 值与两个 $y$ 值的全组合；已知两个点是"一横一竖"配对（$x$ 不同、$y$ 不同），它们必然取自不同的 $x$ 值与不同的 $y$ 值，故剩余两个组合正是交叉配对。面积 = 宽 × 高 = $\lvert x_1-x_2\rvert \cdot \lvert y_1-y_2\rvert$。∎

**引理 3（枚举完备）**：算法枚举的点对集合包含每个可行矩形的至少一条对角线。

**证明**：设存在可行矩形，由引理 1 其四角均在点集中；取其中任意一条对角线端点 $i<j$（点按输入下标编号），该点对满足 $x_i\ne x_j$、$y_i\ne y_j$，不会被跳过，故被双循环枚举到。∎

**定理**：算法返回所有轴平行矩形的最小面积；不存在时返回 0。

**证明**：

- 每个被更新的候选面积都来自一个真实矩形：由算法条件，$(x_i,y_j)$ 与 $(x_j,y_i)$ 均在点集，与端点合起来正是引理 1 形式的四角，故面积为真实矩形的面积。因此 `best` 是某个真实矩形面积。
- 每个真实矩形都会被考虑：由引理 3，其对角线被枚举；由引理 2，算法查的另两角正是该矩形的角，必命中，面积被计入 `best`。
- 二者合起来，`best` 恰为全部可行矩形面积的最小值；若无可行矩形则始终为初值，返回 0。∎

## 6. 复杂度分析

- **时间**：$O(n^2)$。建集合 $O(n)$，双循环 $\binom{n}{2}$ 次，每次两次哈希查询 $O(1)$。$n=500$ 时约 $1.25\times10^5$ 次判定。
- **空间**：$O(n)$ 的哈希集合（存 $n$ 个点编码），其余为常数。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minAreaRect(vector<vector<int>>& points) {
        unordered_set<long long> S;
        S.reserve(points.size() * 2);
        for (auto& p : points) S.insert((long long)p[0] * 40001 + p[1]);
        auto has = [&](int x, int y) {
            return S.count((long long)x * 40001 + y) > 0;
        };

        long long best = -1;
        int n = points.size();
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                int x1 = points[i][0], y1 = points[i][1];
                int x2 = points[j][0], y2 = points[j][1];
                if (x1 == x2 || y1 == y2) continue;          // 退化对：不可能是对角线
                if (!has(x1, y2) || !has(x2, y1)) continue;   // 另两角必须都存在
                long long area = (long long)abs(x1 - x2) * abs(y1 - y2);
                if (best < 0 || area < best) best = area;
            }
        }
        return best < 0 ? 0 : (int)best;
    }
};
```

### Python

```python
class Solution:
    def minAreaRect(self, points: list[list[int]]) -> int:
        S = {(x, y) for x, y in points}
        best = None
        n = len(points)
        for i in range(n):
            x1, y1 = points[i]
            for j in range(i + 1, n):
                x2, y2 = points[j]
                if x1 == x2 or y1 == y2:          # 退化对，跳过
                    continue
                if (x1, y2) not in S or (x2, y1) not in S:
                    continue
                area = abs(x1 - x2) * abs(y1 - y2)
                if best is None or area < best:
                    best = area
        return 0 if best is None else best
```

## 8. 边界情况与易错点

1. **退化对不跳过**：$x_1=x_2$（同一竖线）时"另两角"就是端点自身，会算出面积 0 并把答案错成 0。
2. **无矩形返回 0**：不能用 `INT_MAX` 或 `float('inf')` 直接返回，否则输出错误。
3. **点互不相同**：题面保证无重复点；若有重复点，`S` 去重后计数不受影响，仍正确。
4. **面积溢出**：坐标上限 $4\times10^4$，面积可达 $1.6\times10^9$，乘之前转 `long long`；Python 无此问题。
5. **编码碰撞**：用 `x * 40001 + y` 时乘数必须**严格大于** $y$ 的最大值（题目是 $4\times10^4$），写成 `x * 40000 + y` 会在 $y=40000$ 时与 $x+1, y=0$ 碰撞。
6. **矩形必须在点集内**：只判定对角线端点存在是**不够**的，必须查交叉两角，"任意两点定矩形"是错的。
7. **一个矩形有两条对角线**：同矩形被算两次，面积相同，对 `min` 无影响，不用去重。
8. **列表输入可能很大但 n 很小**：$n=1$ 时双循环不执行，直接返回 0。
