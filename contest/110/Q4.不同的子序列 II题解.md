# LeetCode 不同的子序列 II 题解

## 1. 题目概述

- **标题 / 题号**：不同的子序列 II（#940，hard）
- **链接**：https://leetcode.cn/problems/distinct-subsequences-ii/
- **来源**：LeetCode 第 110 场周赛 Q4
- **难度**：困难
- **标签**：字符串、动态规划

**题意**：给定字符串 $s$（全小写字母），统计 $s$ 的**不同非空子序列**的个数，答案对 $10^9+7$ 取模。子序列是删除若干（可以 $0$ 个）字符后**保持相对顺序**得到的串；两个子序列只要内容相同就只算一个。

**约束**：

- $1 \le s.length \le 2000$
- $s$ 仅由小写英文字母组成

> 💡 与经典题 #115「不同的子序列」的区别：那里是"有多少种**取法**得到 $t$"，本题是"有多少个**不同的串**"，去重方式完全不同。

## 2. 示例

**示例 1**

```text
输入：s = "abc"
输出：7
解释：7 个不同子序列是 "a","b","c","ab","ac","bc","abc"（每个字符只出现一次，不会重复）。
```

**示例 2**

```text
输入：s = "aba"
输出：6
解释：6 个不同子序列是 "a","b","ab","ba","aa","aba"。
     注意后缀的 "a" 与前缀的 "a" 只能算一个，这正是本题的去重难点。
```

**示例 3**

```text
输入：s = "aaa"
输出：3
解释：只有 "a","aa","aaa"。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有 $2^n$ 个子集，把拼出来的串丢进哈希集合去重：$n = 2000$ 时 $2^{2000}$ 完全不可能。

退一步的"暴力 DP"是：设 `dp[i]` 为前缀 $s[0..i)$ 的不同子序列**集合**，则 `dp[i] = dp[i-1] ∪ {x + s[i] : x ∈ dp[i-1] ∪ {ε}}`。这个递推**完全正确**，但集合大小是指数级的，同样不可行。

### 3.2 核心观察：按「结尾字符」分组，集合只被"覆盖"一次

![状态：按结尾字符给子序列分组](images/wc110_q4_dp_state.svg)

把前缀 $s[0..i)$ 的全部不同**非空**子序列按**结尾字符**分成 26 组，设

$$\text{dp}[c] = \#\{\text{以字符 } c \text{ 结尾的不同非空子序列}\}, \qquad \text{total} = \sum_{c} \text{dp}[c].$$

现在读入新字符 $c$，考虑"新出现的子序列"：把**已有的任意子序列**（以及**空串**）末尾接上 $c$，得到

$$\mathcal{N} = \{\, t + c \;:\; t \in \mathcal{S} \cup \{\varepsilon\} \,\},$$

其中 $\mathcal{S}$ 是当前全部不同非空子序列。两件事同时成立：

1. $\lvert \mathcal{N} \rvert = \text{total} + 1$（空串贡献单独的那个 `"c"`）；
2. $\mathcal{N}$ 恰好**等于**"加入 $c$ 之后以 $c$ 结尾的全部子序列"集合——因为任何以 $c$ 结尾的子序列，去掉末尾的 $c$ 后必然是一个更短的子序列（或空串），都在 $\mathcal{S} \cup \{\varepsilon\}$ 中。

第 2 条是关键：以 $c$ 结尾的**旧**集合被新集合**整体覆盖**，于是只保留新值：

$$\text{dp}_{\text{new}}[c] = \text{total} + 1,\qquad \text{dp}_{\text{new}}[c'] = \text{dp}_{\text{old}}[c'] \; (c' \ne c).$$

刷新 `total`：

$$\text{total} \leftarrow \big(\text{total} - \text{dp}_{\text{old}}[c]\big) + \big(\text{total} + 1\big) = 2\cdot\text{total} + 1 - \text{dp}_{\text{old}}[c].$$

全部状态只有 26 个槽 + 1 个 `total`，**时间 $O(n)$、空间 $O(1)$**。

### 3.3 算法流程 / 状态转移

![转移：全部旧子序列 + 空串，末尾接上 c](images/wc110_q4_recurrence.svg)

```text
1. last[26] = {0}, total = 0
2. for ch in s:
       c   = ch - 'a'
       old = last[c]
       ndp = total + 1                 // 以 c 结尾的新集合大小
       last[c] = ndp % MOD
       total = (total - old + ndp) mod MOD
3. return total mod MOD
```

**等价写法（经典前缀式）**：若把 `f[i]` 记为前缀 $i$ 个字符的答案、$p$ 为 $c$ 上一次出现的下标（$0$ 基，无则 $-1$），由上面的推导可以写成

$$f[i] = 2 f[i-1] - f[p-1], \qquad f[-1] = 0,\, f[0]=0,$$

其中 $f[p-1]$ 就是"$c$ 上一次出现时被覆盖的旧 `dp[c]`"。26 槽版本不需要存整个 $f$ 数组，常数更小。

### 3.4 示例演算

![示例 "aba" 的逐步演算](images/wc110_q4_walkthrough.svg)

对 $s = \texttt{"aba"}$：

| 步骤 | 读入 | dp 更新 | total |
|------|------|---------|-------|
| 初始 | — | `dp[a]=dp[b]=0` | 0 |
| 1 | a | `dp[a] = 0+1 = 1` | $0-0+1 = 1$ |
| 2 | b | `dp[b] = 1+1 = 2` | $1-0+2 = 3$ |
| 3 | a | `dp[a] = 3+1 = 4` | $3-1+4 = 6$ |

第 1 步后 $\{a\}$；第 2 步后 $\{a,b,ab\}$（`dp[b]` 的 2 个是 `b`、`ab`）；第 3 步把 `dp[a]` 从 1 覆盖为 4，即以 `a` 结尾的只有 $\{a, ba, aa, aba\}$——旧的 `a` 被新的 `a` 覆盖掉，避免重复。最终 `total = 6`，与题面一致。

## 4. 算法细节

1. **两个量就够**：`total`（全部不同非空子序列数）与 `last[26]`（按结尾字符的分布）。不需要任何二维 DP 表。
2. **先存 `old` 再覆盖**：`last[c]` 必须在新值写入**之前**取出，顺序写反就会少减一项。
3. **取模与负数**：C++ 里 `(total - old + ndp) % MOD` 可能为负，必须 `((x % MOD) + MOD) % MOD`；Python 的 `%` 自带非负语义，直接 `% MOD` 即可。
4. **`ndp` 先取模**：`total + 1` 在 `total < MOD` 时不会溢出，但参与后续加减前统一取模更安全。
5. **答案不含空串**：`total` 的定义已排除空串，因此直接返回 `total`，不要再减 1。
6. **`last` 的语义**：存的是"该字符上一次刷新后的 `dp[c]`"，不是"上一次的下标"，也不是"该字符出现次数"。
7. **与 #115 的分野**：#115 求取法数，重复字符要"乘法累加"；本题求不同串数，重复字符要"减法覆盖"。两者模板不可互换。
8. **字符集**：题面限定小写字母，用长度 26 的定长数组最快；若字符集变大改用哈希表，复杂度变 $O(n)$ 期望。

## 5. 正确性证明

记 $\mathcal{S}_i$ 为前缀 $s[0..i)$ 的全部不同**非空**子序列集合，$\mathcal{S}_0 = \varnothing$；$\text{dp}_i[c]$ 为其中以 $c$ 结尾的子集大小，$\text{total}_i = \lvert \mathcal{S}_i\rvert$。

**引理 1（分组不重不漏）**：$\{\,t \in \mathcal{S}_i : t \text{ 以 } c \text{ 结尾}\,\}$ 两两不交，并对 $c$ 求和恰为 $\mathcal{S}_i$；故 $\text{total}_i = \sum_c \text{dp}_i[c]$。

**证明**：每个非空串都有且仅有一个结尾字符，故按结尾字符划分是 $\mathcal{S}_i$ 的一个划分。∎

**引理 2（覆盖性）**：设读入 $s[i] = c$，则 $\mathcal{S}_{i+1}$ 中以 $c$ 结尾的子序列集合

$$\mathcal{T}_{i+1}(c) = \{\, t + c : t \in \mathcal{S}_i \cup \{\varepsilon\} \,\}.$$

**证明**：

- "$\subseteq$"：任何 $u \in \mathcal{S}_{i+1}$ 以 $c$ 结尾。若 $u$ 的最后一个字符取自位置 $i$，去掉它得 $t \in \mathcal{S}_i \cup \{\varepsilon\}$；若 $u$ 的字符全部来自前缀 $i$，则 $u \in \mathcal{S}_i$ 且以 $c$ 结尾，此时 $u = t + c$ 其中 $t = u$ 去掉末字符 $\in \mathcal{S}_i \cup \{\varepsilon\}$。两种情形都形如 $t+c$。
- "$\supseteq$"：任取 $t \in \mathcal{S}_i \cup \{\varepsilon\}$，$t+c$ 是前缀 $i+1$ 的子序列且以 $c$ 结尾，故属于 $\mathcal{T}_{i+1}(c)$。∎

**引理 3（计数式）**：$\text{dp}_{i+1}[c] = \text{total}_i + 1$，且对 $c' \ne c$ 有 $\text{dp}_{i+1}[c'] = \text{dp}_i[c']$。

**证明**：由引理 2，$\mathcal{T}_{i+1}(c) = \{t + c\}$。映射 $t \mapsto t+c$ 是**单射**（在同一位置追加同一字符，长度加 1 后可唯一还原 $t$），故 $\lvert \mathcal{T}_{i+1}(c)\rvert = \lvert \mathcal{S}_i\rvert + 1 = \text{total}_i + 1$。对 $c' \ne c$，以 $c'$ 结尾的子序列最后一个字符不是 $c$，其字符全部来自前缀 $i$，故与 $\mathcal{S}_i$ 中以 $c'$ 结尾者完全一致。∎

**定理**：对每个 $i$，$\text{total}_i$ 等于前缀 $s[0..i)$ 的不同非空子序列个数；算法最终返回 $\text{total}_n \bmod (10^9+7)$。

**证明**：对 $i$ 归纳。$i=0$ 时 $\mathcal{S}_0=\varnothing$，`total` $=0$，成立。设对 $i$ 成立，读入 $c=s[i]$：

$$\text{total}_{i+1} = \sum_{c'}\text{dp}_{i+1}[c'] = \text{dp}_{i+1}[c] + \sum_{c'\ne c}\text{dp}_i[c'] = (\text{total}_i+1) + (\text{total}_i - \text{dp}_i[c]) = 2\,\text{total}_i + 1 - \text{dp}_i[c],$$

（第一个等号用引理 1，第二个用引理 3，第三个用引理 1 展开 $\text{total}_i$）。这正是算法第 $i+1$ 轮的更新式，且 `last[c]` 保存的值由归纳假设恰为 $\text{dp}_i[c]$。故归纳成立。取 $i=n$ 即得结论；取模是线性运算，不影响正确性。∎

**推论（规模估计）**：$s$ 中字符互不相同时答案为 $2^n-1$，与组合直觉一致（此时引理 3 的"覆盖"从不发生，`dp[c]` 恒为刷新前 `total`+1，`total` 每轮翻倍再加 1）。

## 6. 复杂度分析

- **时间**：$O(n)$，每轮只做常数次整数运算（一次数组读写、两次加减、一次取模）。$n \le 2000$ 时远低于限制；即便 $n = 10^7$ 也可接受。
- **空间**：$O(1)$，固定 26 个 `long long` 槽；不随 $n$ 增长。
- **对比 O(n²) 前缀式**：若按 $f[i] = 2f[i-1]-f[p-1]$ 实现，需 $O(n)$ 的 $f$ 数组与 $O(n)$ 的字母最后位置；26 槽写法把空间压到常数。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int distinctSubseqII(string s) {
        const int MOD = 1000000007;
        long long last[26] = {0};   // last[c] = 以 c 结尾的不同非空子序列数
        long long total = 0;        // 当前全部不同非空子序列数
        for (char ch : s) {
            int c = ch - 'a';
            long long old = last[c];
            long long ndp = (total + 1) % MOD;        // 新集合：旧子序列 + 空串，末尾接 c
            last[c] = ndp;                            // 覆盖旧的 dp[c]
            total = ((total - old + ndp) % MOD + MOD) % MOD;
        }
        return (int)(total % MOD);
    }
};
```

### Python

```python
class Solution:
    def distinctSubseqII(self, s: str) -> int:
        MOD = 10 ** 9 + 7
        last = [0] * 26          # last[c]：以字符 c 结尾的不同非空子序列数
        total = 0                # 全部不同非空子序列数
        for ch in s:
            c = ord(ch) - ord('a')
            old = last[c]
            ndp = total + 1      # 旧子序列与空串末尾接上 c
            last[c] = ndp
            total = (total - old + ndp) % MOD
        return total % MOD
```

## 8. 边界情况与易错点

1. **忘记减去旧的 `dp[c]`**：得到的是"子序列取法数"而不是"不同子序列数"，`"aba"` 会算成 7 而不是 6。
2. **`last[c]` 读取顺序**：一定要先取出旧值再覆盖；写成 `last[c] = ndp; total += ndp - last[c];` 就永远减掉 0。
3. **C++ 取模负数**：`(total - old + ndp)` 可能为负，必须加 `MOD` 再取模，否则返回负数。
4. **空串不能计入**：`total` 从 0 开始且每次加的是 `+1`（空串只用来生成 `"c"`），最终答案不需要 `-1`。
5. **单字符**：`s = "a"` 时 `total = 1`，正确；不要额外特判。
6. **全同字符**：`s = "aaa"` 应得 3，这是检验"覆盖"逻辑是否生效的最快用例。
7. **`ndp` 与 `total` 的模**：$n$ 大时 `total` 可能接近 $10^9$，`total + 1` 不会溢出 `long long`，但若用 `int` 会；统一用 `long long` 累加。
8. **字符集假设**：数组长度必须是 26；若误按 128 开数组而只用到 26，逻辑仍对，但若要支持大写/其它字符必须同步改下标映射。
9. **与 #115 混淆**：那题要输出"取法数"，重复字符要乘加；本题是"不同串数"，重复字符要覆盖。
