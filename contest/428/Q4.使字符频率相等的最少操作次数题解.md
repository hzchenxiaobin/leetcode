# LeetCode 使字符频率相等的最少操作次数 题解

## 1. 题目概述

- **标题 / 题号**：使字符频率相等的最少操作次数（#3389，hard）
- **链接**：https://leetcode.cn/problems/minimum-operations-to-make-character-frequencies-equal/
- **来源**：LeetCode 第 428 场周赛 Q4
- **难度**：困难
- **标签**：哈希表、字符串、动态规划、计数、枚举

**题意**：若字符串中**每个出现的字符出现次数相等**，则称其为「好的」。给定 `s`，可执行以下操作任意次：① 从 `s` 中删除一个字符；② 往 `s` 中添加一个字符；③ 将一个字母变成字母表中**下一个**字母（`'z'` 不能变成 `'a'`）。求把 `s` 变好的最少操作次数。

**约束**：

- $1 \le s.length \le 2 \times 10^4$
- `s` 只包含小写英文字母

> 💡 **读题关键**：① 三种操作与「好坏」判定都**不挑位置**——真正有意义的只有 26 维**频次数组**，问题规模从 $2 \times 10^4$ 坍缩到 26；② 好串由隐含参数「公共频次 $c$」刻画：每个 $\mathrm{occ}_x \in \{0, c\}$，$c$ 未知就枚举它；③ 操作 3 **只能变大、一次一格**的单向性，决定了「盈余只能向右流」，也决定了 DP 沿 `a`→`z` 的推进方向。

## 2. 示例

**示例 1**

```text
输入：s = "acab"
输出：1
解释：删掉一个字符 'a'（剩余 a:1, c:1, b:1），s 变为好的。
```

**示例 2**

```text
输入：s = "wddw"
输出：0
解释：w:2, d:2，s 一开始就是好的。
```

**示例 3**

```text
输入：s = "aaabc"
输出：2
解释：将一个 'a' 变为 'b'（a:2, b:2, c:1），再往 s 中插入一个 'c'（a:2, b:2, c:2）。
```

## 3. 解题思路

### 3.1 暴力思路：在字符串上搜索

最朴素的想法是把 `s` 的所有可达状态跑 BFS。但「添加」让状态空间无界，26 维频次向量的取值组合也是天文数字，彻底不可行。正确的切入是先做**建模坍缩**——三种操作在频次数组上的映像：

- 删除一个字符 $\iff \mathrm{occ}[x] - 1$
- 添加一个字符 $\iff \mathrm{occ}[x] + 1$
- 变成下一个字母 $\iff \mathrm{occ}[x] - 1$ 且 $\mathrm{occ}[x+1] + 1$（`'z'` 无出边）

于是问题变成：**用最少的单位操作把 26 维频次向量整形成「每位取值 $\in \{0, c\}$」的形状**。

### 3.2 核心观察：固定 c，代价 = 逐位调整 − 相邻搭桥

![固定 c 后的代价模型：盈余右移搭桥、缺口补增](images/charfreq_bridge_model.svg)

**第一步：枚举公共频次 $c$**。好串 $\iff$ 存在 $c \ge 1$ 使每个 $\mathrm{occ}_x \in \{0, c\}$。$c$ 是最优解的隐含参数——不确定的参数就枚举它，且只需枚举到 $c \le \max(\mathrm{occ})$（引理 4）。

**第二步：不看操作 3 的基础代价**。固定 $c$ 与每个字母的目标 $t_x \in \{0, c\}$：盈余的删掉、缺口的补上，代价为 $\sum_x |\mathrm{occ}_x - t_x|$。

**第三步：操作 3 的本质是「相邻搭桥」，每搬 1 个净省 1**。两个关键观察：

> **观察 1（每个被移动的字符至多右移一格）**：把一个字符连移两格花 2 次，与「起点删 1 + 终点增 1」的效果和代价**完全相同**——「穿流」可以被等价替换掉，不妨设搬运只发生在相邻字母对 $(x, x+1)$ 之间。

> **观察 2（盈余只能流向右邻的缺口，搬满最优）**：字母只能变大不能变小，盈余无法倒流。若 $x$ 盈余 $s$、$x+1$ 缺口 $d$，右移 $k$ 个的总代价为 $(s-k)$ 删 $+\ k$ 搬 $+\ (d-k)$ 增 $= s + d - k$，随 $k$ 线性下降——搬满 $k = \min(s, d)$，净省 $\min(s, d)$。若 $x$ 无盈余或 $x+1$ 无缺口，交换论证表明搬运无利可图（省 0）。

> 💡 **推论**：固定 $c$ 与目标 $t$ 后，最小操作数为
> $$\sum_x |\mathrm{occ}_x - t_x| \;-\; \sum_{x=0}^{24} \min\big(\text{盈余}_x,\ \text{缺口}_{x+1}\big)$$
> 其中盈余$_x = \max(0, \mathrm{occ}_x - t_x)$、缺口$_x = \max(0, t_x - \mathrm{occ}_x)$。两项均非负，任一边为 0 时节省自动归零，无需特判。

### 3.3 算法流程：枚举 c × 26 位两状态线性 DP

![算法流程与 DP 状态转移](images/charfreq_dp_transition.svg)

节省项只依赖**相邻两个字母**的目标，满足无后效性——令 $dp_i(j)$ 表示处理完前 $i+1$ 个字母、第 $i$ 个字母目标为 $j \cdot c$（$j \in \{0,1\}$）时的最小代价：

$$
dp_i(j) = \min_{j' \in \{0,1\}} \Big( dp_{i-1}(j') + \big|\mathrm{occ}_i - jc\big| - \min\big(\text{盈余}_{i-1}(j'),\ \text{缺口}_i(j)\big) \Big)
$$

边界 $dp_0(j) = |\mathrm{occ}_0 - jc|$（字母 `a` 无前驱盈余）；固定 $c$ 的答案为 $\min_j dp_{25}(j)$；再对 $c \in [1, \max(\mathrm{occ})]$ 取最小。完整流程：

1. 统计频次 $\mathrm{occ}[26]$，记 $M = \max(\mathrm{occ})$；
2. 枚举公共频次 $c = 1 \dots M$；
3. 沿 `a`→`z` 扫描做两状态 DP，处理字母 $i$ 时结算边 $(i-1, i)$ 的搭桥节省 $\min(\text{盈余}_{i-1}, \text{缺口}_i)$；
4. 每个 $c$ 结束后用 $\min(dp_0, dp_1)$ 更新全局答案。

### 3.4 示例演算

![示例 3 演算：aaabc 取 c=2](images/charfreq_example_walkthrough.svg)

对 `s = "aaabc"`：$\mathrm{occ} = [3, 1, 1, 0, \dots]$。取 $c = 2$、目标 $t = [2, 2, 2, 0, \dots]$：

- 基础代价 $|3-2| + |1-2| + |1-2| = 3$；
- 边 (a, b)：盈余$_a = 1$、缺口$_b = 1$ → 搭桥省 $\min(1, 1) = 1$；
- 边 (b, c)：盈余$_b = 0$ → 省 0；
- 总代价 $3 - 1 = \mathbf{2}$ ✓，恰好对应官方解释「一个 a 变 b（搭桥）＋ 插入一个 c（补缺口）」。

顺带一提，$c = 1$（删两个 `a` 得 `abc`）与 $c = 3$（删 `b`、`c` 得 `aaa`）同样得到 2——多解并列最优，取 min 不受影响。示例 1 `"acab"`（$\mathrm{occ} = [2,1,0,1]$）：$c = 1$ 时基础代价 1，a 的盈余 1 右邻 b 无缺口、省 0，答案 **1** ✓。示例 2 `"wddw"`：$c = 2$ 时 $\mathrm{occ}_w = \mathrm{occ}_d = 2$ 全部达标，答案 **0** ✓。

## 4. 算法细节

1. **频次统计与枚举上界**：`occ[26]` 计数；$M = \max_x \mathrm{occ}_x$，枚举 $c \in [1, M]$（引理 4 保证足够；写成 $[1, n]$ 也正确，只是多跑几轮）。
2. **DP 状态设计**：目标只有「0 / $c$」两档（好串的充要条件决定），每位 2 个状态、4 个转移；滚动掉字母维后仅剩 `dp[2]`。
3. **盈余 / 缺口现算**：$\text{盈余}_{i-1}(j') = \max(0, \mathrm{occ}_{i-1} - j'c)$、$\text{缺口}_i(j) = \max(0, jc - \mathrm{occ}_i)$，无需额外数组。
4. **边的结算时机**：处理字母 $i$ 时才结算边 $(i-1, i)$ 的节省，25 条边各恰好一次，不重不漏。
5. **哨兵与溢出**：`INF` 只作 `min` 累积初值；每个状态都有有限代价（至多 $n + 26c \le 2n$ 量级），加减不会触碰 `int` 上限。
6. **「全删成空串」无需特判**：$t \equiv 0$ 的路径在 DP 中自然被枚举（代价恰为 $n$），但它永不最优（见 §8 第 1 条）。

## 5. 正确性证明

**引理 1（频次坍缩）**：对任意 $k \ge 0$，$s$ 可经 $k$ 次操作变好 $\iff$ 频次向量 $\mathrm{occ}$ 可经 $k$ 次「频次操作」（任一分量 $\pm 1$；分量 $x$ 减 1 且 $x+1$ 加 1，$x \le 24$）变为每位取值 $\in \{0, c\}$（$c \ge 1$）的向量。

**证明**：三种操作与位置无关、只与字符种类有关：删除字符 $x$ 使 $\mathrm{occ}[x]$ 减 1；插入使 $\mathrm{occ}[x]$ 加 1；把字符 $x$ 变成 $x+1$ 使 $\mathrm{occ}[x]$ 减 1 且 $\mathrm{occ}[x+1]$ 加 1。反向亦然：每个频次操作都由对应的字符串操作实现（分量减 / 转移要求当前计数 $> 0$，恰好对应串中存在可删 / 可变的字符）。于是两类操作序列互相翻译、操作数相等、频次轨迹相同；而「好」只取决于频次。∎

**引理 2（规范化）**：存在最优操作序列，满足：每个被操作 3 移动的字符恰好移动一格；被移动的都是**原生**字符；移入的字符**不再被删**；同一字母上「移入」与「移出」不同时发生。

**证明**：反复应用下列交换，每次要么总代价严格下降，要么流量 / 移动次数严格减少，必然终止：

- (a) **移两格**（$x \to x{+}1 \to x{+}2$，2 次）⟹ 替换为「在 $x$ 删除该字符 + 在 $x{+}2$ 插入」（2 次，等价）；
- (b) **先插后移**（插入 $x$ 再移到 $x{+}1$，2 次）⟹ 替换为「直接插入 $x{+}1$」（1 次，更优）；
- (c) **移后删**（移到 $x{+}1$ 再删除，2 次）⟹ 替换为「在 $x$ 原地删除」（1 次，更优）；
- (d) **穿流对**（$v$ 从 $x{-}1$ 移入 $x$、同时原生字符 $u$ 从 $x$ 移出）⟹ 替换为「$u$ 留守 $x$、$v$ 在 $x{-}1$ 删除、在 $u$ 的目的地插入」（2 次 ⟹ 2 次，等价，消除「移入且移出」）。∎

**引理 3（搭桥公式）**：固定 $c \ge 1$ 与目标 $t \in \{0, c\}^{26}$，最小操作数为

$$C(t) = \sum_x |\mathrm{occ}_x - t_x| - \sum_{x=0}^{24} \min(\text{盈余}_x, \text{缺口}_{x+1})$$

**证明**：设规范形（引理 2）中最优解在边 $(x, x{+}1)$ 上的流量为 $f_x$、删除 $d_x$、插入 $a_x$。

*规范化约束*：由 (b)，被移动的均为原生字符且盈余字母的流出 $f_x \le \text{盈余}_x$（超出即「先插后搬」）；由 (c)，流入缺口字母的 $f_{x-1} \le \text{缺口}_x$（超出即「搬过去再删」）；由 (d)，无盈余 / 无缺口的字母两侧流量均为 0。故 $f_x \le \min(\text{盈余}_x, \text{缺口}_{x+1})$，且流量只出现在「盈余 → 右邻缺口」的边上。

*代价核算*：对盈余字母 $x$（盈余 $s_x$，流入为 0）：其原生字符的去向为删除或流出，$d_x = s_x - f_x$，贡献 $d_x + f_x = s_x$；对缺口字母 $x$（缺口 $g_x$，流出为 0）：$a_x = g_x - f_{x-1}$，贡献 $a_x$ 加上边 $(x{-}1, x)$ 上的 $f_{x-1}$ 合计 $g_x$；其余字母无操作。于是

$$\text{代价} = \sum_x |\mathrm{occ}_x - t_x| - \sum_{x=0}^{24} f_x$$

且每单位流量恰净省 1（替代「删 1 + 增 1」）。各边约束独立，逐边取满 $f_x = \min(\text{盈余}_x, \text{缺口}_{x+1})$ 即得最小值 $C(t)$，且取满是同时可行的。∎

**引理 4（枚举上界）**：设 $M = \max_x \mathrm{occ}_x$，则存在公共频次 $c \le M$ 的最优解。

**证明**：固定「存在集」$P = \{x : t_x = c\}$，考察 $c \ge M$ 时代价 $C(c, P)$ 随 $c$ 的变化。$P$ 中字母恒为缺口（$\mathrm{occ}_x \le M \le c$），$c$ 每 $+1$，基础代价恰增加 $|P|$；节省只出现在「左邻缺席（盈余为 $\mathrm{occ}_x$，与 $c$ 无关）→ 右邻在场」的边上，每条边的缺口随 $c$ 每 $+1$ 至多 $+1$，而这样的边至多 $|P|$ 条（每个在场字母只有一条左邻边）。故 $C(c+1, P) - C(c, P) \ge |P| - |P| = 0$，即固定 $P$ 时代价在 $c \ge M$ 上单调不减。任何 $c > M$ 的方案都被同一 $P$ 在 $c = M$ 处覆盖，枚举 $c \in [1, M]$ 即含全局最优。∎

**定理**：算法输出将 $s$ 变好的最少操作次数。

**证明**：由引理 1，只需在频次向量上求最优；由引理 4，最优公共频次落在 $[1, M]$ 内被枚举；固定 $c$ 后，由引理 3，每个目标分配 $t \in \{0, c\}^{26}$ 的代价是链式可分解的表达式 $\sum_x f_x(t_x) - \sum_x g(t_x, t_{x+1})$，二状态线性 DP 恰枚举全部 $2^{26}$ 种分配并取最小。三层合并即得全局最优。∎

## 6. 复杂度分析

- **时间复杂度**：$O(26\,M) \le O(26\,n)$，其中 $M = \max(\mathrm{occ})$。外层至多 $M \le n = 2 \times 10^4$ 个 $c$，内层 26 个字母、每位 4 个转移，最坏约 $2 \times 10^6$ 次转移——C++ 实测毫秒级（1~2 ms），纯 Python 约 0.5 s。
- **空间复杂度**：$O(1)$——26 个计数 + 常数个 DP 变量。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int makeStringGood(string s) {
        int occ[26] = {0};
        for (char ch : s) ++occ[ch - 'a'];
        int M = *max_element(occ, occ + 26);
        const int INF = 1e9;
        int ans = INF;
        // 枚举公共频次 c（引理 4：c > max(occ) 必不更优）
        for (int c = 1; c <= M; ++c) {
            // dp[j]：处理完当前字母、其目标为 j*c 的最小代价
            int dp[2] = {occ[0], abs(occ[0] - c)};   // 字母 a 无前驱盈余
            for (int i = 1; i < 26; ++i) {
                int ndp[2] = {INF, INF};
                for (int j = 0; j < 2; ++j) {
                    int ti = j ? c : 0;                    // 当前字母目标
                    int ci = abs(occ[i] - ti);             // 本位调整代价
                    int gap = max(0, ti - occ[i]);         // 当前字母缺口
                    for (int jp = 0; jp < 2; ++jp) {
                        int tp = jp ? c : 0;
                        int sup = max(0, occ[i - 1] - tp); // 前一字母盈余
                        // 相邻搭桥：盈余流向缺口，每个字符省 1
                        ndp[j] = min(ndp[j], dp[jp] + ci - min(sup, gap));
                    }
                }
                dp[0] = ndp[0];
                dp[1] = ndp[1];
            }
            ans = min(ans, min(dp[0], dp[1]));
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def makeStringGood(self, s: str) -> int:
        occ = [0] * 26
        for ch in s:
            occ[ord(ch) - 97] += 1
        ans = len(s)
        for c in range(1, max(occ) + 1):            # 引理 4：枚举到 max(occ) 即可
            dp0, dp1 = occ[0], abs(occ[0] - c)      # 字母 a：无前驱盈余
            for i in range(1, 26):
                o, op = occ[i], occ[i - 1]
                gap = c - o if o < c else 0         # 目标 c 的缺口
                # 目标 0：缺口为 0，搭桥节省必为 0
                ndp0 = min(dp0, dp1) + o
                # 目标 c：两个前驱状态都要与缺口取 min 后再扣节省
                ndp1 = abs(o - c) + min(dp0 - min(op, gap),
                                         dp1 - min(max(0, op - c), gap))
                dp0, dp1 = ndp0, ndp1
            ans = min(ans, dp0, dp1)
        return ans
```

> 💡 **性能**：最坏情形（单个字母占满全串，$M = n = 2\times10^4$）纯 Python 约 0.5 s，无需 numpy 向量化；若想再快，可把「枚举 $c$」做成 numpy 的一个轴整列并行，只剩 26 轮向量运算。

## 8. 边界情况与易错点

1. **「全删成空串」不必特判**：代价恰为 $n$；而 $c = 1$（每个出现过的字母各留一个）代价 $\le n - D$（$D \ge 1$ 为不同字母数），严格更省——空串永不最优。DP 中 $t \equiv 0$ 的路径自然被枚举且不会胜出。
2. **$j'=1$ 分支的节省必须同样与缺口取 min**（本题最隐蔽的坑）：`dp1` 转移里搭桥节省是 $\min(\text{盈余}, \text{缺口})$，不是盈余本身。反例 `"acab"`、$c=1$：边 (a, b) 的盈余为 1、缺口为 0，若误减盈余会得出 0 的荒谬答案（正确答案 1）。
3. **枚举上界**：用 $\max(\mathrm{occ})$（引理 4）或 $n$ 均正确；别误写成 26 之类（$c$ 是频次不是字母数）。
4. **`'z'` 无右邻**：只有 $(a,b), \dots, (y,z)$ 共 25 条边；`'z'` 不能变 `'a'`，循环 `i = 1..25` 天然正确。
5. **DP 初始化**：字母 `a` 没有前驱盈余，直接 `dp(j) = |occ[0] - j*c|`；别给 `a` 也做一次带节省的转移。
6. **每条边恰好结算一次**：处理字母 $i$ 时结算 $(i-1, i)$；重复扣或漏扣都会错（尤其手写展开 4 个转移时）。
7. **别被位置带偏**：三种操作与判定均与位置无关，任何基于前缀 / 子串 / 具体下标的思路都是歧路；先坍缩到 26 维频次再动手。

**延伸思考**：

- 若操作 3 允许**双向**变换（也能变成上一个字母），盈余便可左右两向流动，链式 DP 失效——需按「节点 = 字母、边 = 相邻搬运、源汇 = 增删」建模跑**最小费用流**。本题的单向性正是简单 DP 成立的根源。
- 若操作 3 变成「一步变成任意更大的字母」（仍 1 次），搬运可跨多格且每单位仍省 1，相邻耦合消失——代价函数还保持链式可分解吗？能否贪心求解？值得动手推一推。
