# LeetCode 检查两个字符串数组是否相等 题解

## 1. 题目概述

- **标题 / 题号**：检查两个字符串数组是否相等（#1662，easy）
- **链接**：https://leetcode.cn/problems/check-if-two-string-arrays-are-equivalent/
- **来源**：LeetCode 第 216 场周赛 Q1
- **难度**：简单
- **标签**：数组、字符串、双指针

**题意**：给定两个字符串数组 `word1` 与 `word2`。**数组表示的字符串**是把数组中所有元素**按顺序拼接**形成的串。若两个数组表示的字符串相同，返回 `true`；否则返回 `false`。

**约束**：

- `1 <= word1.length, word2.length <= 1000`
- `1 <= word1[i].length, word2[i].length <= 1000`
- `1 <= sum(word1[i].length), sum(word2[i].length) <= 1000`
- `word1[i]` 和 `word2[i]` 由小写字母组成

## 2. 示例

**示例 1**

```text
输入：word1 = ["ab", "c"], word2 = ["a", "bc"]
输出：true
解释：word1 表示 "ab" + "c" -> "abc"，word2 表示 "a" + "bc" -> "abc"，两串相同。
```

**示例 2**

```text
输入：word1 = ["a", "cb"], word2 = ["ab", "c"]
输出：false
解释："acb" != "abc"。
```

**示例 3**

```text
输入：word1 = ["abc", "d", "defg"], word2 = ["abcddefg"]
输出：true
解释：两侧拼接后均为 "abcddefg"。
```

## 3. 解题思路

### 3.1 直接做法：拼接后比较

签到题的最短路径：把两个数组各自拼接成完整字符串再整体比较。

- C++：把元素依次 `+=` 到两个 `string`，再 `a == b`；
- Python：`"".join(word1) == "".join(word2)` 一行解决。

时间已是线性 $O(N+M)$（$N,M$ 为两数组的**字符总数**），不可能更快——最坏情况下每个字符都影响答案，必须读到。唯一的"浪费"是空间：两个中间串共占 $O(N+M)$。本题 $\sum |\text{word}_i| \le 1000$，拼接完全无压力；但这道题的本质是**流式等值判断**，可以做到 $O(1)$ 额外空间。

### 3.2 核心观察：比较是"顺序只读"的

拼接串 $S_1$、$S_2$ 在比较时只被**从左到右、每个字符恰好读一次**，且中途一旦遇到不等即可立刻返回 `false`。也就是说，根本**不需要物化** $S_1$、$S_2$——用两对下标在原数组上"虚拟拼接"地同步前进即可：

- $(i, j)$：`word1[i]` 的第 `j` 个字符；
- $(x, y)$：`word2[x]` 的第 `y` 个字符。

![核心观察：拼接结果逐字符比较，与分块方式无关](images/1662_concat_equals_concept.svg)

> 💡 **一句话总结**：数组 = 字符流的分段存储；判断两个流相等只需双指针同步走，不必先攒成整串。

### 3.3 算法流程：双指针同步前进

1. 初始化 `i = j = x = y = 0`；
2. 循环：当两侧都还有字符（`i < word1.size()` 且 `x < word2.size()`）：
   - 若 `word1[i][j] != word2[x][y]` → 返回 `false`；
   - 两侧各前进一个字符：`j` 加 1，若 `j` 走到 `word1[i]` 末尾则 `i` 加 1、`j` 归 0；`(x, y)` 同理；
3. 循环退出（至少一侧耗尽）：返回**两侧是否同时耗尽**，即 `i == word1.size() && x == word2.size()`。

![算法流程：双指针同步前进](images/1662_two_pointer_flow.svg)

### 3.4 示例演算

以 `word1 = ["ab", "c"]`、`word2 = ["a", "bc"]` 为例（两侧虚拟拼接均为 `"abc"`）：

| 步 | word1 当前字符 | word2 当前字符 | 是否相等 | 指针变化 |
|----|---------------|---------------|---------|----------|
| 0 | word1[0][0] = 'a' | word2[0][0] = 'a' | ✓ | (0,0)→(0,1)，(0,0)→(0,1) |
| 1 | word1[0][1] = 'b' | word2[1][0] = 'b' | ✓ | (0,1)→(1,0)，(0,1)→(1,1) |
| 2 | word1[1][0] = 'c' | word2[1][1] = 'c' | ✓ | (1,0)→(1,1)，(1,1)→(2,0) |
| 3 | i = 2，word1 耗尽 | x = 2，word2 耗尽 | — | 两侧同时耗尽 → 返回 true |

注意第 1 步：`word1` 的 'b' 在元素 0 **内**前进，而 `word2` 的 'b' 已**跳到**元素 1——下标对的推进与分块方式完全解耦。

![示例演算：双指针逐步推进](images/1662_two_pointer_walkthrough.svg)

## 4. 算法细节

1. **坐标编码**：状态 $(i,j)$ 唯一对应已消耗的字符数 $k = \sum_{t<i} |\text{word1}[t]| + j$；前进规则保证 $(i,j)$ 永不越界（除非已耗尽）。
2. **前进的对称性**：两侧前进逻辑完全独立、完全对称，可封装成 `advance` 子过程，或用迭代器统一处理。
3. **长度不同必不等**：若拼接串长度不同，短的一侧先耗尽，循环退出时另一侧未耗尽 → 返回 `false`，无需单独预比较总长度（先比总长度可提前剪枝，但复杂度不变）。
4. **提前终止**：遇到第一对不等字符立即返回，最好情况 $O(1)$。
5. **迭代器视角**（Python）：`itertools.chain` 把数组摊平成字符流，两个流配对比较即是本算法的声明式写法（见参考代码）。

## 5. 正确性证明

**引理 1**：两数组表示的字符串相同，当且仅当拼接串 $S_1$、$S_2$ 长度相等且每个位置字符相等。

**证明**：字符串相等即逐位置相等；若长度不等，则较长串存在较短串没有的字符位置，二者互为充要。∎

**引理 2**（循环不变量）：第 $k$ 轮比较前，两侧已消耗的字符数均为 $k$，$(i,j)$ 恰指向 $S_1$ 的第 $k$ 个字符（$k = |S_1|$ 时 $i$ 恰为元素个数、已耗尽），$(x,y)$ 恰指向 $S_2$ 的第 $k$ 个字符（或恰耗尽），且前 $k$ 轮比较全部相等。

**证明**：对 $k$ 归纳。$k=0$ 时 $i=j=x=y=0$；由约束元素非空，$(0,0)$ 恰指向首字符，命题成立。设第 $k$ 轮成立且比较相等，执行前进：`j+1` 后若 `j == |word1[i]|` 则 `i+1、j=0`，由前缀和拆分的唯一性，新 $(i,j)$ 恰消耗 $k+1$ 个字符，即指向第 $k+1$ 个字符（或恰耗尽）；$(x,y)$ 同理。且每轮两侧**各**前进一格，故两侧消耗数始终相等。∎

**定理**：算法返回 `true` 当且仅当两数组表示的字符串相同。

**证明**：（充分）设 $S_1 = S_2$。由引理 2，每轮比较均相等，不会触发字符不等的返回；又两侧消耗数始终相等、$|S_1| = |S_2|$，故两侧同时耗尽，循环退出时 $i$ 与 $x$ 同时到达各自数组末尾，返回 `true`。（必要）若返回 `true`，则循环未经字符不等退出且两侧同时耗尽，由引理 2，前 $k$ 轮逐位相等，且此时 $k = |S_1| = |S_2|$，故 $S_1 = S_2$。若返回 `false`：要么某轮字符不等（由引理 2 该位置是首个差异，前面均相等），要么一侧先耗尽而另一侧未耗尽（由引理 2 两侧消耗数相等，故 $|S_1| \ne |S_2|$）；由引理 1 均有 $S_1 \ne S_2$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(N + M)$，$N,M$ 为两数组字符总数。每个字符至多被访问一次；遇到不等字符可提前终止。
- **空间复杂度**：$O(1)$。仅 `i, j, x, y` 四个下标变量（拼接做法需 $O(N+M)$ 存中间串）。

## 7. 参考代码

### C++（双指针，O(1) 空间）

```cpp
class Solution {
public:
    bool arrayStringsAreEqual(vector<string>& word1, vector<string>& word2) {
        int n1 = word1.size(), n2 = word2.size();
        int i = 0, j = 0, x = 0, y = 0;
        while (i < n1 && x < n2) {
            if (word1[i][j] != word2[x][y]) return false;
            if (++j == (int)word1[i].size()) ++i, j = 0;
            if (++y == (int)word2[x].size()) ++x, y = 0;
        }
        return i == n1 && x == n2;
    }
};
```

### C++（拼接，比赛速写）

```cpp
class Solution {
public:
    bool arrayStringsAreEqual(vector<string>& word1, vector<string>& word2) {
        string a, b;
        for (auto& s : word1) a += s;
        for (auto& s : word2) b += s;
        return a == b;
    }
};
```

### Python（双指针）

```python
class Solution:
    def arrayStringsAreEqual(self, word1: List[str], word2: List[str]) -> bool:
        n1, n2 = len(word1), len(word2)
        i = j = x = y = 0
        while i < n1 and x < n2:
            if word1[i][j] != word2[x][y]:
                return False
            j += 1
            if j == len(word1[i]):
                i, j = i + 1, 0
            y += 1
            if y == len(word2[x]):
                x, y = x + 1, 0
        return i == n1 and x == n2
```

### Python（迭代器写法，声明式的 O(1) 空间）

```python
from itertools import chain, zip_longest

class Solution:
    def arrayStringsAreEqual(self, word1: List[str], word2: List[str]) -> bool:
        s1 = chain.from_iterable(word1)
        s2 = chain.from_iterable(word2)
        return all(a == b for a, b in zip_longest(s1, s2))
```

### Python（一行拼接）

```python
class Solution:
    def arrayStringsAreEqual(self, word1: List[str], word2: List[str]) -> bool:
        return ''.join(word1) == ''.join(word2)
```

## 8. 边界情况与易错点

1. **循环出口必须检查"双方同时耗尽"**：如 `word1 = ["abc"]`、`word2 = ["ab"]`，word2 先耗尽时退出循环，若顺手 `return true` 就错了；出口必须写 `i == n1 && x == n2`。这是本题最常见的 WA 点。
2. **不要逐元素比较**：示例 1 中两数组的元素完全不同，却表示同一字符串；逐元素 `word1[t] == word2[t]` 会误判。
3. **前进顺序**：先比较、后前进；两侧前进相互独立，不要共用变量或写反 `i/j` 与 `x/y` 的更新。
4. **空串元素**：本题约束元素非空。若变体允许 `word1[i] = ""`，双指针在 `j` 归 0 后会立刻越界（读 `""[0]`），前进时需跳过空元素；拼接做法则天然免疫。
5. **规模无忧**：总长 $\le 1000$，拼接做法稳过；双指针的价值在于 $O(1)$ 空间与"数据只能单遍读取"的流式场景。
