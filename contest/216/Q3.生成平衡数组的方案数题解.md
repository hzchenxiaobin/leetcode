# LeetCode 生成平衡数组的方案数 题解

## 1. 题目概述

- **标题 / 题号**：生成平衡数组的方案数（#1664，medium）
- **链接**：https://leetcode.cn/problems/ways-to-make-a-fair-array/
- **来源**：LeetCode 第 216 场周赛 Q3
- **难度**：中等
- **标签**：数组、前缀和

**题意**：给定整数数组 `nums`，必须**恰好选择一个下标**并删除对应元素（剩余元素下标前移补位）。若剩余数组中**奇数下标元素之和等于偶数下标元素之和**，则称其为**平衡数组**。求有多少种删除方案使剩余数组是平衡数组。

**约束**：

- $1 \le \text{nums.length} \le 10^5$
- $1 \le \text{nums[i]} \le 10^4$

## 2. 示例

**示例 1**

```text
输入：nums = [2,1,6,4]
输出：1
解释：
删除下标 0：[1,6,4] → 偶位 1+4=5，奇位 6，不平衡。
删除下标 1：[2,6,4] → 偶位 2+4=6，奇位 6，平衡 ✓
删除下标 2：[2,1,4] → 偶位 2+4=6，奇位 1，不平衡。
删除下标 3：[2,1,6] → 偶位 2+6=8，奇位 1，不平衡。
只有 1 种方案。
```

**示例 2**

```text
输入：nums = [1,1,1]
输出：3
解释：删除任意一个元素，剩余数组都是平衡数组。
```

**示例 3**

```text
输入：nums = [1,2,3]
输出：0
解释：无论删除哪个元素，剩余数组都不是平衡数组。
```

## 3. 解题思路

### 3.1 暴力思路：枚举删除位置重算

枚举每个下标 $i$：删除后用 $O(n)$ 重新计算奇偶和并比较，总时间 $O(n^2)$。$n = 10^5$ 时约 $10^{10}$ 次基本操作，必然超时。

> 💡 瓶颈在于"每换一个删除位置就全部重算"。但相邻删除位置之间，数组的绝大部分**没有变化**——删除只影响一个局部结构，应当寻找增量关系。

### 3.2 核心观察：删除 i 后，i 之后的元素奇偶翻转

![核心观察：删除下标 i 后，i 之后的元素奇偶翻转](images/1664_concept.svg)

删除下标 $i$ 后，新数组中：

- **$i$ 之前的元素**：下标不变，奇偶性**不变**；
- **$i$ 之后的元素**：下标集体减 1，奇偶性**翻转**（原偶位变奇位，原奇位变偶位）；
- **$nums[i]$ 自身**：被删除，不产生任何贡献。

于是新数组的奇偶和可由**原数组的奇偶前缀量**拼出。记：

- $\text{leftEven} / \text{leftOdd}$：下标 $< i$ 的元素中，原偶位 / 奇位之和；
- $\text{rightEven} / \text{rightOdd}$：下标 $> i$ 的元素中，原偶位 / 奇位之和。

则：

$$
\text{新偶和} = \text{leftEven} + \text{rightOdd}, \qquad \text{新奇和} = \text{leftOdd} + \text{rightEven}
$$

（左侧原样进、右侧交叉进——正是"翻转"的体现。）平衡条件即：

$$
\text{leftEven} + \text{rightOdd} = \text{leftOdd} + \text{rightEven}
$$

右侧和无需后缀数组，用**总量减法**即时推出（$[\cdot]$ 为指示量，条件成立取 1、否则取 0）：

$$
\text{rightEven} = \text{totalEven} - \text{leftEven} - [i \text{ 为偶}] \cdot \text{nums}[i]
$$

$$
\text{rightOdd} = \text{totalOdd} - \text{leftOdd} - [i \text{ 为奇}] \cdot \text{nums}[i]
$$

> ⚠️ $nums[i]$ 被删除，既不属于左侧也不属于右侧，计算右侧和时必须**按 $i$ 的奇偶从对应总量中扣除它自身**——这是本题最容易写错的一步。

### 3.3 算法流程：一遍扫描 + O(1) 判定

![算法流程：奇偶前缀和一遍扫描，逐位置 O(1) 判定](images/1664_algorithm_flow.svg)

流程要点：

1. 第一遍遍历统计 $\text{totalEven} / \text{totalOdd}$；
2. 第二遍遍历，对每个 $i$：先由总量减法得出 $\text{rightEven} / \text{rightOdd}$，判定平衡条件并计数，**然后**才把 $nums[i]$ 按 $i$ 的奇偶累入左侧；
3. 全程只用 5 个变量，空间 $O(1)$。

### 3.4 示例演算

以示例 1 `nums = [2,1,6,4]` 为例，$\text{totalEven} = 2+6 = 8$，$\text{totalOdd} = 1+4 = 5$：

![示例演算：逐位置计算左右奇偶和并判定](images/1664_example_walkthrough.svg)

| $i$ | $nums[i]$ | leftEven | leftOdd | rightEven | rightOdd | 新偶和 | 新奇和 | 平衡？ |
|----|----------|----------|---------|-----------|----------|--------|--------|--------|
| 0 | 2（偶） | 0 | 0 | $8-0-2=6$ | $5-0-0=5$ | $0+5=5$ | $0+6=6$ | 否 |
| 1 | 1（奇） | 2 | 0 | $8-2-0=6$ | $5-0-1=4$ | $2+4=6$ | $0+6=6$ | **是** |
| 2 | 6（偶） | 2 | 1 | $8-2-6=0$ | $5-1-0=4$ | $2+4=6$ | $1+0=1$ | 否 |
| 3 | 4（奇） | 8 | 1 | $8-8-0=0$ | $5-1-4=0$ | $8+0=8$ | $1+0=1$ | 否 |

仅 $i=1$ 平衡（剩余 $[2,6,4]$，偶位 $2+4=6$ 恰等于奇位 $6$），故答案为 $1$。注意每行都是**先判定、后累入**：第 2 行的 leftEven $= 2$ 正是第 1 行判定后累入的结果。

## 4. 算法细节

1. **两次遍历的分工**：第一遍按 `i & 1` 分流统计 `totalEven` / `totalOdd`；第二遍完成全部判定与计数。也可合并成一次遍历（先累总量，判定时再"撤销"当前位置的影响），但两次遍历的写法更清晰、不易错。
2. **"先判定、后累入"的顺序**：判定时 `nums[i]` 尚未进入 `leftEven / leftOdd`，恰好对应"它已被删除"；若先累入再判定，左侧会错误地包含被删元素。
3. **右侧和的推导**：`rightEven = totalEven - leftEven - (i 为偶 ? nums[i] : 0)`。三项分别是全量、左侧、被删自身——被删元素从哪个总量里扣，由 $i$ 的奇偶决定。
4. **判定的差分变形**：平衡条件可移项为 $\text{leftEven} - \text{leftOdd} = \text{rightEven} - \text{rightOdd}$，即"**左侧偶奇差 = 右侧偶奇差**"。令 $D_i$ 为前 $i$ 个元素的偶奇差，条件即 $D_i = D_n - D_{i+1}$——四个量压缩成一条前缀差分，本质相同。
5. **等价的显式前后缀写法**：预计算 `preEven[i] / preOdd[i]`（下标严格小于 $i$ 的原偶/奇位和）与 `sufEven[i] / sufOdd[i]`（下标严格大于 $i$ 的原偶/奇位和），判定 `preEven[i] + sufOdd[i] == preOdd[i] + sufEven[i]`。空间 $O(n)$，更直观但没有必要。

## 5. 正确性证明

**引理 1（下标平移）**：删除下标 $i$ 后，原下标 $j < i$ 的元素新下标仍为 $j$；原下标 $j > i$ 的元素新下标为 $j - 1$。

**证明**：新数组是原数组去掉第 $i$ 个元素后依次排列。对 $j < i$，其前方元素个数不变，新下标仍为 $j$；对 $j > i$，其前方少了一个元素（第 $i$ 个），新下标为 $j-1$。∎

**引理 2（奇偶和重构）**：删除 $i$ 后，新数组的偶下标和为 $\text{leftEven} + \text{rightOdd}$，奇下标和为 $\text{leftOdd} + \text{rightEven}$。

**证明**：由引理 1：$j < i$ 的元素奇偶性不变，其中原偶位元素落入新偶位，合计贡献 $\text{leftEven}$；原奇位元素落入新奇位，贡献 $\text{leftOdd}$。$j > i$ 的元素下标减 1，奇偶性翻转：原奇位元素（合计 $\text{rightOdd}$）落入新偶位，原偶位元素（合计 $\text{rightEven}$）落入新奇位。被删的 $nums[i]$ 无贡献。两个方向分别相加即得。∎

**引理 3（循环不变量）**：主循环第 $i$ 轮**判定前**，`leftEven` / `leftOdd` 恰等于下标 $< i$ 的元素中原偶位 / 奇位之和。

**证明**：对 $i$ 归纳。$i = 0$ 时左侧为空，二者均为 0，成立。设第 $i$ 轮判定前成立；判定后执行累入：$i$ 为偶则 `leftEven += nums[i]`，$i$ 为奇则 `leftOdd += nums[i]`，恰好把下标 $i$ 的元素归入其原奇偶类，故第 $i+1$ 轮判定前命题对 $i+1$ 成立。∎

**定理**：算法返回值等于使删除后剩余数组平衡的下标个数。

**证明**：由引理 3，第 $i$ 轮判定时 `leftEven / leftOdd` 恰为定义中的左侧和；`rightEven / rightOdd` 由全量减左侧减自身得到，全量由第一遍遍历正确统计，左侧由引理 3 正确，扣除项按 $i$ 的奇偶归属正确，故四个量均与定义一致。由引理 2，判定条件 $\text{leftEven} + \text{rightOdd} = \text{leftOdd} + \text{rightEven}$ 恒等于"删除 $i$ 后新数组偶位和等于奇位和"，即该方案平衡。算法对 $i = 0, 1, \dots, n-1$ 各判定恰一次且互不影响，计数无重无漏。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。统计奇偶总量一遍 $O(n)$；主循环每个位置 $O(1)$ 判定，共 $O(n)$。
- **空间复杂度**：$O(1)$。仅 `totalEven / totalOdd / leftEven / leftOdd / ans` 五个变量（显式前后缀写法为 $O(n)$，无必要）。

## 7. 参考代码

### C++（O(1) 空间）

```cpp
class Solution {
public:
    int waysToMakeFair(vector<int>& nums) {
        int totalEven = 0, totalOdd = 0;
        for (int i = 0; i < (int)nums.size(); ++i) {
            if (i & 1) totalOdd += nums[i];
            else       totalEven += nums[i];
        }

        int leftEven = 0, leftOdd = 0, ans = 0;
        for (int i = 0; i < (int)nums.size(); ++i) {
            int rightEven = totalEven - leftEven - (i % 2 == 0 ? nums[i] : 0);
            int rightOdd  = totalOdd  - leftOdd  - (i % 2 == 1 ? nums[i] : 0);
            if (leftEven + rightOdd == leftOdd + rightEven) ++ans;
            if (i & 1) leftOdd += nums[i];
            else       leftEven += nums[i];
        }
        return ans;
    }
};
```

### Python（O(1) 空间）

```python
class Solution:
    def waysToMakeFair(self, nums: List[int]) -> int:
        total_even = sum(nums[::2])
        total_odd = sum(nums[1::2])

        left_even = left_odd = ans = 0
        for i, x in enumerate(nums):
            right_even = total_even - left_even - (x if i % 2 == 0 else 0)
            right_odd = total_odd - left_odd - (x if i % 2 == 1 else 0)
            if left_even + right_odd == left_odd + right_even:
                ans += 1
            if i % 2 == 0:
                left_even += x
            else:
                left_odd += x
        return ans
```

## 8. 边界情况与易错点

1. **n = 1**：删除唯一元素后为空数组，偶位和 = 奇位和 = 0，天然平衡，答案为 1。公式自动给出该结果（四个量全为 0，$0 = 0$ 成立），无需特判。
2. **先判定后累入**：顺序写反是最常见的 WA 原因——先累入会使左侧多算被删元素，右侧的扣除逻辑也随之失去意义。
3. **自身扣除的奇偶归属**：$i$ 为偶从 `totalEven` 扣 `nums[i]`，$i$ 为奇从 `totalOdd` 扣。扣错位置会直接算错右侧和。
4. **不要真的模拟删除**：每删一个就挪一次数组或重建奇偶和是 $O(n^2)$，$n = 10^5$ 会超时；也不要为每个 $i$ 物化新数组。
5. **溢出**：总和至多 $10^5 \times 10^4 = 10^9$，判定式两侧各不超过总和，`int`（上限约 $2.1 \times 10^9$）够用；若范围放大，改用 `long long`。
6. **判的是下标不是元素**：奇偶分流看 `i` 的奇偶，不要误用 `nums[i]` 的奇偶。
