# LeetCode 金字塔转换矩阵 题解

## 1. 题目概述

- **标题 / 题号**：金字塔转换矩阵（#756，medium）
- **链接**：https://leetcode.cn/problems/pyramid-transition-matrix/
- **来源**：LeetCode 第 65 场周赛 Q3
- **难度**：中等
- **标签**：位运算、哈希表、字符串、回溯

**题意**：积木的颜色用字母 `A`–`F` 表示。`allowed` 里的每个三字符模式 `"XYZ"` 规定了一个合法三角形：**左底块 X、右底块 Y 之上可以放顶块 Z**，顺序敏感（`"XYZ"` 与 `"YXZ"` 是两条不同的规则）。从底层 `bottom` 出发，每向上一层就由下一行的**相邻两块**决定一个顶块，行长度每次减 1。问能否一直堆到只剩 1 块，且金字塔中**每一个三角形**都命中 `allowed`。

**约束**：

- $2 \le \lvert \text{bottom} \rvert \le 6$
- $0 \le \lvert \text{allowed} \rvert \le 216$（$6^3$ 即全部可能的三角形）
- `allowed[i].length == 3`，所有字母取自 $\{A,B,C,D,E,F\}$，模式互不重复

## 2. 示例

**示例 1**

```text
输入：bottom = "BCD", allowed = ["BCC","CDE","CEA","FFF"]
输出：true
解释：BCD → CE → A，共三个三角形：BCC、CDE、CEA，全部在 allowed 中
```

**示例 2**

```text
输入：bottom = "AAAA", allowed = ["AAB","AAC","BCD","BBE","DEF"]
输出：false
解释：第 3 层有 8 种造法，逐条试下去都会在造出第 1 层之前断掉
```

## 3. 解题思路

### 3.1 暴力思路

最直白的方法是**枚举金字塔的每一种搭法**：从底层开始，对每个位置枚举至多 6 种顶块，得到下一行后再继续，直到某支路径堆到 1 块。底层长度 $n$ 时，金字塔共有 $\frac{n(n-1)}{2}$ 个三角形，$n = 6$ 时是 15 个，路径总数最坏 $6^{15} \approx 4.7 \times 10^{11}$——单看数量级就已经不可接受。更关键的是**重复子问题**：不同的顶块选择经常在中间层汇合到同一个行字符串（如 `AAAA` 的 8 种第 3 层，最终只汇成 `EE`、`ED` 两种第 2 层），朴素回溯会把这些相同的行一遍遍重算。

### 3.2 核心观察：规则只看相邻两块

![三角形规则与逐层收缩模型](images/wc65_q3_pyramid_model.svg)

**观察 1（局部性）**：给定某一行 `row`，下一行第 $i$ 个字符的候选集合只由 `row[i]` 与 `row[i+1]` 决定，与其他位置无关。于是

$$\text{cand}(i) = \text{mask}\big[\text{row}[i]\big]\big[\text{row}[i+1]\big]$$

把 `allowed` 预处理成 $6 \times 6$ 的表，每个格子是一个**位掩码**：第 $c$ 位为 1 表示「这一对底块之上可以放字母 $c$」。查一次是 $O(1)$，枚举候选时反复取最低位即可。

**观察 2（马尔可夫性）**：金字塔能否建到顶，只取决于**当前行字符串**——层高由 $n - \lvert \text{row} \rvert$ 唯一确定，之前选了哪些顶块、走过哪条路径，都不影响「从 `row` 往上还能不能到顶」。所以状态就是 `row` 本身，用记忆化把指数级搜索压成对状态图的遍历。

> ⚠️ 注意：正因为规则对**左右顺序敏感**，查表时必须严格按 `(row[i], row[i+1])` 的顺序取掩码。若把一对底块当成无序对（例如对两个字母排序后再当 key），`bottom = "AB", allowed = ["ACB"]` 这种本应返回 `false` 的用例会被错判成 `true`——`"ACB"` 的左右底块是 A、B，只是顺序与 `(A,B)` 相反。

### 3.3 算法流程 / 状态转移

![位掩码预处理 + 记忆化回溯流程](images/wc65_q3_bitmask_flow.svg)

记 $\text{gen}(row)$ 为 `row` 之后**所有合法的下一行**，它是若干个候选集合的笛卡尔积：

$$\text{gen}(row) = \prod_{i=0}^{k-2} \text{mask}\big[\text{row}[i]\big]\big[\text{row}[i+1]\big]$$

其中 $k = \lvert \text{row} \rvert$；只要任一因子为空，$\text{gen}(row) = \varnothing$。于是判定函数满足递推

$$\text{dfs}(row)=\begin{cases}\text{true}, & k = 1\\[2pt] \bigvee_{next \in \text{gen}(row)} \text{dfs}(next), & k \ge 2\end{cases}$$

完整流程：

1. 预处理：对每个 `p = "XYZ"` 执行 `mask[X][Y] |= 1 << Z`。
2. `dfs(row)`：长度为 1 立刻返回 `true`；否则先查 `memo`。
3. 扫一遍 $k-1$ 个位置算掩码，**任一为 0 立即返回 `false`**（整层无解，无需回溯）。
4. 回溯填行：第 $i$ 位从 `mask` 里枚举候选字符写入缓冲区，填满后递归 `dfs(next)`；任一分支成功即返回 `true`，全部失败则 `memo[row] = false`。

### 3.4 示例演算

![两个示例的逐层走查](images/wc65_q3_walkthrough.svg)

**示例 1**（`bottom = "BCD"`）：底层两个位置分别查 (B,C) 与 (C,D)，各只有一个候选，第 2 层唯一确定为 `CE`；再查 (C,E) 得 `A`，堆到 1 块。

| 层 | 行 | 用到的三角形 | 是否在 `allowed` |
|----|-----|--------------|------------------|
| 3（底） | B C D | — | — |
| 2 | C E | BCC、CDE | 是 |
| 1 | A | CEA | 是 |

**示例 2**（`bottom = "AAAA"`）：(A,A) 有两个候选（AAB→B、AAC→C），故第 3 层是 $\{B,C\}^3$ 的全部 8 种。其中 6 种含有 (C,B) 或 (C,C) 这对底块，查表为空，当场失败；剩下两种也都断在第 2 层：

| 第 3 层 | 第 2 层 | 卡住的位置 |
|---------|---------|------------|
| BBB | EE | (E,E) 无规则 |
| BBC | ED | (E,D) 无规则（只有 DE→F） |

答案是 `false`。注意 `ED` 与 `DE` 只差顺序，却一个合法一个不合法——这正是"方向敏感"的直观例子。

## 4. 算法细节

1. **位掩码而不是 `set`**：候选顶块只有 6 种可能，用一个 `int` 存全部候选（`mask[a][b] |= 1 << c`），判空就是 `m == 0`，枚举就是循环取最低位，常数极小。
2. **枚举最低位的写法**：`low = m & -m`；字母 = `low.bit_length() - 1`；消去用 `m ^= low`（或 `m &= m - 1`）。C++ 里对应 `__builtin_ctz(m)` 与 `m &= m - 1`。
3. **先剪枝再回溯**：生成下一行之前先把 $k-1$ 个掩码全算出来，遇到 0 直接 `false`，避免为一行根本无解的 `row` 白跑所有排列。
4. **共享缓冲区**：回溯用同一个 `string` / `list` 做 push-pop，只在"填满一行"时才物化成新字符串（Python 里 `''.join(nxt)`），避免每个递归分支都复制整行。
5. **记忆化键只放 `row`**：层高由长度唯一确定，不需要把层号、下标写进 key；否则状态数会被无谓放大。
6. **递归结构**：外层 `dfs(row)` 负责"层间跳跃"，内层 `build(i)` 负责"行内逐位置填字符"，两者分离后代码最短，也便于把剪枝、回溯各归其位。
7. **只在失败时也必须写缓存**：`memo[row] = false` 是剪枝的关键；若只在成功时记录，遇到大规模无解数据会退化回指数搜索。

## 5. 正确性证明

**引理 1（生成集合正确）**：对任意 $k \ge 2$ 的行 `row`，$\text{gen}(row)$ 恰好是题目允许的全部下一行。

**证明**：

- ($\subseteq$) 任取 $next \in \text{gen}(row)$，则对每个位置 $i$，$next[i]$ 取自 $\text{mask}[\text{row}[i]][\text{row}[i+1]]$，即三元组 `(row[i], row[i+1], next[i])` 在 `allowed` 中，所以 `next` 的每个三角形都合法。
- ($\supseteq$) 设 `next` 是合法的下一行，则每个位置的三元组都在 `allowed` 中，按预处理规则，`next[i]` 的对应位必然被置入 $\text{mask}[\text{row}[i]][\text{row}[i+1]]$，因此 $next$ 属于该笛卡尔积。∎

**引理 2（状态充分性）**：`dfs(row)` 的返回值只依赖字符串 `row`，与到达它的路径无关。

**证明**：$\text{gen}$ 只由 `row` 决定（引理 1），递归调用 `dfs(next)` 的参数也只由 `row` 与 `next` 决定；对 $k$ 归纳即知整个搜索子树由 `row` 唯一确定，故记忆化命中时直接返回缓存值与重新计算等价。∎

**定理**：`dfs(bottom)` 返回 `true` 当且仅当存在一座从 `bottom` 堆到顶、所有三角形都合法的金字塔（递归因行长度每次减 1 而必然终止）。

**证明**：

- ($\Leftarrow$) 对金字塔高度归纳。若已存在合法金字塔且底层为 `bottom`，则其第 2 层必属于 $\text{gen}(bottom)$（引理 1），而其余部分正是以该第 2 层为底层的合法金字塔；由归纳假设 `dfs` 在该分支上返回 `true`，故整体返回 `true`。
- ($\Rightarrow$) 若 `dfs(bottom)` 返回 `true`，则存在一条"底层→第 2 层→…→顶"的链，每步都被 `gen` 接受。由引理 1，链上每个三角形都合法，这条链就是题目要的金字塔。∎

## 6. 复杂度分析

- **时间**：设底层长度为 $n \le 6$。不同行字符串的数量上界为 $\sum_{k=1}^{n} 6^k$（$n=6$ 时为 $6+36+216+1296+7776+46656 = 55986$）。每个状态要做 $O(k)$ 次掩码查询，并有至多 $6(k-1)$ 条出边（每条对应一次子状态调用），故总时间为 $O\!\left(n \cdot 6^{n}\right)$，实际远小于该上界；作为对比，朴素回溯约为 $O\!\left(6^{n(n-1)/2}\right)$。
- **空间**：记忆化表最多存 $O(6^n)$ 个长度 $O(n)$ 的字符串键，即 $O(n \cdot 6^n)$；回溯缓冲区与递归栈各 $O(n)$。

## 7. 参考代码

### C++

```cpp
#include <string>
#include <vector>
#include <unordered_map>
using namespace std;

class Solution {
public:
    int mask[6][6];
    unordered_map<string, bool> memo;
    bool dfs(const string &row) {
        int n = (int)row.size();
        if (n == 1) return true;                 // 只剩一块，堆到顶了
        auto it = memo.find(row);
        if (it != memo.end()) return it->second;

        vector<int> opts(n - 1);
        for (int i = 0; i + 1 < n; i++) {
            int m = mask[row[i] - 'A'][row[i + 1] - 'A'];   // 顺序敏感：左、右
            if (m == 0) return memo[row] = false;           // 该位置无规则，整行剪枝
            opts[i] = m;
        }

        string nxt;
        nxt.reserve(n - 1);
        // 逐位置枚举候选顶块
        auto build = [&](auto &&self, int i) -> bool {
            if (i == n - 1) return dfs(nxt);     // 填满 → 递归上一层
            unsigned m = (unsigned)opts[i];
            while (m) {
                int low = __builtin_ctz(m);      // 最低位的字母下标
                nxt.push_back((char)('A' + low));
                if (self(self, i + 1)) return true;
                nxt.pop_back();                  // 回溯
                m &= m - 1;                      // 去掉最低位，试下一个候选
            }
            return false;
        };
        bool res = build(build, 0);
        memo[row] = res;
        return res;
    }
    bool pyramidTransition(string bottom, vector<string> &allowed) {
        for (auto &cell : mask)
            for (int &v : cell) v = 0;
        memo.clear();
        for (const string &p : allowed)
            mask[p[0] - 'A'][p[1] - 'A'] |= 1 << (p[2] - 'A');
        return dfs(bottom);
    }
};
```

### Python

```python
from typing import List


class Solution:
    def pyramidTransition(self, bottom: str, allowed: List[str]) -> bool:
        # mask[a][b] 的第 c 位为 1 表示三角形 "abc" 合法
        mask = [[0] * 6 for _ in range(6)]
        for pat in allowed:
            a, b, c = (ord(ch) - 65 for ch in pat)
            mask[a][b] |= 1 << c

        memo = {}

        def dfs(row: str) -> bool:
            if len(row) == 1:                  # 只剩一块，成功
                return True
            if row in memo:
                return memo[row]

            opts = []
            for i in range(len(row) - 1):
                m = mask[ord(row[i]) - 65][ord(row[i + 1]) - 65]
                if m == 0:                     # 该位置无规则，整行无解
                    memo[row] = False
                    return False
                opts.append(m)

            nxt = []

            def build(i: int) -> bool:
                if i == len(opts):             # 填满一行 → 递归上一层
                    return dfs(''.join(nxt))
                m = opts[i]
                while m:
                    low = m & -m               # 最低位的候选
                    nxt.append(chr(65 + low.bit_length() - 1))
                    if build(i + 1):
                        return True
                    nxt.pop()                  # 回溯
                    m ^= low                   # 去掉最低位
                return False

            res = build(0)
            memo[row] = res
            return res

        return dfs(bottom)
```

## 8. 边界情况与易错点

1. **`allowed` 为空或底部长度为 2 且无对应规则**：`bottom = "AA", allowed = []` 应返回 `false`；查表得到 `mask = 0`，由剪枝直接返回，不会越界。
2. **方向敏感**：`"ABC"` 与 `"BAC"` 是两条规则。若把查表写成 `mask[min][max]`、或把两个字母排序后再存模式，`bottom = "AB", allowed = ["ACB"]` 会被误判为 `true`。
3. **底层长度为 2 也要判**：题目允许 $\lvert bottom \rvert = 2$，此时只需一个三角形就能到顶，不要在代码里写死"至少三层"。
4. **到达长度为 1 就返回 `true`**：这是唯一的成功出口，别漏掉；否则会继续用长度 1 的行去生成"长度 0 的行"而访问越界。
5. **掩码位与字母的换算**：`1 << (ch - 'A')`（C++）与 `chr(65 + bit)`（Python）必须严格互逆；建议统一用 $0..5$ 的下标，不要混用 ASCII 值。
6. **必须先剪枝再回溯**：若省掉"掩码为 0 立即 `false`"这一步，最坏情况要为一行生成 $6^{k-1}$ 个候选（大多注定失败），白白浪费。
7. **缓存失败结果**：只缓存成功会让无解数据退化成指数搜索，`memo[row] = false` 与成功缓存同等重要。

**延伸思考**：

1. **正向逐层推进**：把记忆化 DFS 换成"从底层出发、维护可达行集合"的 BFS，每层记录所有能造出的行，一旦集合为空即 `false`，顶层剩 1 个元素即 `true`。它与本题等价，但天然按层合并重复状态。
2. **整行打包成整数**：把行按 6 进制编码成 `long long`（$n \le 6$ 时 $\le 6^6$），用数组而不是哈希表做记忆化，可再省一个常数。
3. **输出任意一座金字塔**：把 `memo` 里"哪条分支成功"的抉择记下来（或让 `dfs` 返回构造结果），即可在 $O(n \cdot 6^n)$ 内输出一整座合法金字塔。
