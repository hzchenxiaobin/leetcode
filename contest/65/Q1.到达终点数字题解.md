# LeetCode 到达终点数字 题解

## 1. 题目概述

- **标题 / 题号**：到达终点数字（#754，medium）
- **链接**：https://leetcode.cn/problems/reach-a-number/
- **来源**：LeetCode 第 65 场周赛 Q1
- **难度**：中等
- **标签**：数学，二分查找

**题意**：站在无限长数轴的 $0$ 处，终点在 `target`。第 $i$ 次移动（$i = 1,2,\dots$）必须在选定方向上走**恰好** $i$ 步。求到达 `target` 所需的**最少移动次数**。

**约束**：

- $-10^9 \le \text{target} \le 10^9$，且 $\text{target} \ne 0$
- 第 $i$ 步的步长固定为 $i$，只能选择方向，不能改变步长
- 移动次数不受限制，答案的量级是 $O(\sqrt{\lvert \text{target}\rvert})$：$\lvert \text{target}\rvert = 10^9$ 时答案为 $44723$

## 2. 示例

**示例 1**

```text
输入：target = 2
输出：3
解释：第 1 步 0 → 1（+1）
      第 2 步 1 → -1（-2）
      第 3 步 -1 → 2（+3）
      2 步时能到达的位置只有 -3、-1、1、3，躲开了 2，所以 3 步是最少。
```

**示例 2**

```text
输入：target = 3
输出：2
解释：第 1 步 0 → 1（+1），第 2 步 1 → 3（+2）；两步步长 1 + 2 = 3 恰好等于 target。
```

**示例 3（补充，题面未给出，用于覆盖 $+2$ 分支）**

```text
输入：target = 5
输出：5
解释：S(3) = 6、S(4) = 10 与 5 的差分别是 1、5，都是奇数，3 步和 4 步都不可达；
      5 步时 S(5) = 15，差 10 为偶数，把第 5 步反向即 1+2+3+4-5 = 5。
```

## 3. 解题思路

### 3.1 暴力思路

最直白的做法是「从 $n = 1$ 开始试」：第 $i$ 步有两种选择，$n$ 步就对应 $2^n$ 条路径，逐条枚举判断终点是否为 `target`。$n$ 到 $40$ 时 $2^{40}$ 已经不可接受，而本题答案最大约 $4.5 \times 10^4$，枚举路径完全没有希望。

换一种「按层 BFS + 位置去重」的写法：第 $n$ 层可达位置的个数约为 $S(n) = \frac{n(n+1)}{2}$，到 $n = 44723$ 时单层就有约 $10^9$ 个位置，时间与空间都爆掉。即便是「枚举 $n$ 后做一次子集和判定」，$O(n \cdot S(n))$ 的 DP 同样是 $10^9$ 量级。

所以暴力只能处理 $\lvert \text{target}\rvert$ 很小的数据，必须把「$n$ 步能否到达 $t$」这个判定压缩成 $O(1)$。

### 3.2 核心观察：上界与奇偶这两条硬约束

![n 步可达位置的上界与奇偶约束](images/wc65_q1_parity_model.svg)

记 $S(n) = 1 + 2 + \cdots + n$，$t = \lvert \text{target}\rvert$。设有符号和 $x = \sum_{i=1}^{n} s_i i$，其中 $s_i \in \{+1, -1\}$，则终点就是 $x$。两条约束立刻浮出水面：

1. **上界**：$\lvert x\rvert \le \sum_{i=1}^n i = S(n)$。$S(n) < \lvert \text{target}\rvert$ 时前 $n$ 步无论如何都到不了。
2. **奇偶**：由 $-i \equiv i \pmod 2$ 得 $s_i i \equiv i \pmod 2$，于是

$$x \equiv \sum_{i=1}^{n} i = S(n) \pmod 2$$

即**终点与 $S(n)$ 必须同奇偶**。直观解释：把第 $k$ 步从 $+k$ 翻成 $-k$，终点只变化 $2k$，一次性调整的永远是偶数，所以「$S(n)$ 与 $t$ 的差值」必须是偶数。

这两条不只是必要条件，也是**充分条件**：只要 $S(n) \ge t$ 且差值为偶数，令 $d = \frac{S(n) - t}{2}$，把和为 $d$ 的那几步反向，终点就正好是 $S(n) - 2d = t$。而「$1,2,\dots,n$ 的子集能拼出 $[0, S(n)]$ 里的任意整数」正是第 5 节引理 3 保证的。

于是问题从「$2^n$ 条路径」坍缩成「找最小的 $n$，使 $S(n)$ 足够大且与 $t$ 同奇偶」，而这正是一个二分答案的结构：$S(n)$ 严格递增。

### 3.3 算法流程

![二分下界加奇偶校正的流程](images/wc65_q1_binary_search_flow.svg)

1. 取 $t = \lvert \text{target}\rvert$（左右对称，负号可以扔掉）；
2. **倍增定上界**：从 $hi = 1$ 出发，只要 $S(hi) < t$ 就令 $hi \leftarrow 2\,hi$，得到首个满足 $S(hi) \ge t$ 的倍增上界；
3. **二分**：在 $[0, hi]$ 上找最小的 $n_0$，使 $S(n_0) = \frac{n_0(n_0+1)}{2} \ge t$；
4. 令 $\text{gap} = S(n_0) - t$：
   - $\text{gap}$ 为偶数 → 答案就是 $n_0$；
   - $\text{gap}$ 为奇数且 $n_0$ 为偶数 → 答案 $n_0 + 1$；
   - 否则 → 答案 $n_0 + 2$。

第 4 步三种情况的来源：从 $n$ 步到 $n+1$ 步，$S$ 增加 $n+1$，所以

$$S(n_0+1) - t = \text{gap} + (n_0 + 1)$$

**奇偶是否翻转，取决于 $n_0 + 1$ 的奇偶**，也就是取决于 $n_0$ 的奇偶。$n_0$ 偶数时加一步就能把差值变成偶数；$n_0$ 奇数时 $n_0+1$ 仍是奇数，差值奇偶不变，只能再加一步到 $n_0 + 2$（此时 $n_0+2$ 为奇数，翻转成功）。

### 3.4 示例演算

![target = 2 与 target = 3 的判定表](images/wc65_q1_walkthrough.svg)

对 `target = 2`（$t = 2$）：

| $n$ | $S(n)$ | $S(n) - t$ | 奇偶 | 结论 |
|-----|--------|-----------|------|------|
| 1 | 1 | $-1$ | — | $S(n) < t$，上界不足 |
| 2 | 3 | 1 | 奇 | 差值为奇数，2 步不可达 |
| 3 | 6 | 4 | 偶 | 可行，答案 $3$ |

对 `target = 3`（$t = 3$）：$n = 1$ 时 $S = 1 < 3$；$n = 2$ 时 $S = 3$、差 $0$ 为偶数，答案是 $2$。

对 `target = 5`（走 $+2$ 分支）：$n_0 = 3$（$S(3) = 6 \ge 5$），差 $1$ 为奇数且 $n_0 = 3$ 为奇数，故 $3+1 = 4$ 步仍不可达（$S(4) = 10$，差 $5$ 为奇数），答案为 $3 + 2 = 5$。构造也的确存在：$1+2+3+4-5 = 5$。

## 4. 算法细节

1. **先取绝对值**：由对称性，答案只依赖 $\lvert \text{target}\rvert$；C++ 里若直接对 `INT_MIN` 取负会溢出，应先转 `long long` 再 `llabs`。
2. **上界用倍增而不是 `sqrt`**：`(int)sqrt(t)` 在 $t$ 接近平方数时可能因浮点误差少 1，需要 `+1` / `+2` 兜底；倍增只需 $O(\log n)$ 次判断且没有精度问题。
3. **二分区间从 $0$ 开始**：$lo = 0$、$hi$ 为倍增上界，循环用 `while (lo < hi)` 取 `mid = (lo+hi)/2`，收缩成「首个满足 $S(mid) \ge t$ 的位置」，这样 $\text{target} = 0$ 也能安全返回 $0$。
4. **乘法用 64 位**：$n_0 \approx 44721$ 时 $S(n_0) \approx 10^9$，但倍增过程中 $hi$ 可能到 $65536$，此时 $\frac{hi(hi+1)}{2} \approx 2.1 \times 10^9 > 2^{31}-1$，用 `int` 会溢出成负数导致二分跑偏。
5. **判定只需一次奇偶检查**：`gap % 2` 即可，不需要再做任何搜索；三种答案的差别只在最后一行。
6. **顺序递增也能过，但没必要**：从 $n = 1$ 一路累加到 $S(n) \ge t$ 最多 $4.5 \times 10^4$ 次，实际上也能过；本题刻意用二分是为了 $O(\log)$ 与标签一致，同时验证「单调性」这一核心事实。
7. **闭式解可作对照**：由 $\frac{n(n+1)}{2} \ge t$ 解出 $n_0 = \left\lceil \frac{\sqrt{8t+1}-1}{2} \right\rceil$，可与二分结果互相校验（误差 ±1 时取满足 $S(n_0) \ge t$ 的最小值）。

## 5. 正确性证明

**引理 1（对称性）**：到达 $t$ 与到达 $-t$ 的最少步数相同。

**证明**：把任意一条到达 $t$ 的走法中每一步的方向全部取反，得到的走法终点为 $-t$，步数不变；反向同理。故两个方向的最少步数相等。∎

**引理 2（必要条件）**：若 $n$ 步后位于 $x$，则 $\lvert x\rvert \le S(n)$ 且 $x \equiv S(n) \pmod 2$。

**证明**：$x = \sum_{i=1}^n s_i i$，由三角不等式 $\lvert x\rvert \le \sum_{i=1}^n i = S(n)$。又 $s_i \in \{+1,-1\}$，故 $s_i i \equiv i \pmod 2$，逐项相加得 $x \equiv \sum_{i=1}^n i = S(n) \pmod 2$。∎

**引理 3（子集和覆盖整个区间）**：对任意整数 $d$ 满足 $0 \le d \le S(n)$，都存在子集 $A \subseteq \{1,2,\dots,n\}$，使 $\sum_{i \in A} i = d$。

**证明**：对 $n$ 归纳。$n = 1$ 时 $d \in \{0,1\}$，取 $\varnothing$ 或 $\{1\}$ 即可。设命题对 $n-1$ 成立，即 $\{1,\dots,n-1\}$ 的子集和覆盖 $[0, S(n-1)]$；而含有 $n$ 的子集和恰好覆盖 $[n,\, n + S(n-1)] = [n, S(n)]$。两段要拼成整段 $[0, S(n)]$，只需 $n \le S(n-1) + 1$，即

$$n \le \frac{n(n-1)}{2} + 1 \iff (n-1)(n-2) \ge 0$$

这对一切 $n \ge 2$ 成立，故并集覆盖 $[0, S(n)]$。∎

**引理 4（充分条件）**：若 $S(n) \ge t$ 且 $S(n) \equiv t \pmod 2$（$t \ge 0$），则恰好 $n$ 步可以到达 $t$。

**证明**：由奇偶相同知 $d = \frac{S(n)-t}{2}$ 是非负整数，且 $d \le \frac{S(n)}{2} \le S(n)$。由引理 3 存在子集 $A$ 满足 $\sum_{i \in A} i = d$。令 $i \in A$ 的步反向、其余正向，则终点为

$$S(n) - 2\sum_{i \in A} i = S(n) - 2d = t$$

即 $n$ 步恰好落在 $t$。∎

**定理 1（可达的充要条件）**：$n$ 步能到达 $t$ $\iff$ $S(n) \ge t$ 且 $S(n) \equiv t \pmod 2$。

**证明**：必要性由引理 2 给出，充分性由引理 4 给出。∎

**定理 2（算法输出最优）**：设 $n_0 = \min\{n : S(n) \ge t\}$，则算法第 4 步给出的值是到达 $t$ 的最少步数。

**证明**：$S(n)$ 严格递增，故二分得到的 $n_0$ 正确。由定理 1，任何可行步数 $n$ 都满足 $S(n) \ge t$，因此 $n \ge n_0$，$n_0$ 之前的所有步数一律不可行。

- 若 $\text{gap} = S(n_0)-t$ 为偶数，定理 1 表明 $n_0$ 本身可行，又 $n_0$ 已是最小候选，故最优；
- 若 $\text{gap}$ 为奇数，$n_0$ 不可行。此时 $S(n_0+1) - t = \text{gap} + n_0 + 1$，当 $n_0$ 为偶数时 $n_0+1$ 为奇数，差值翻转成偶数，$n_0+1$ 可行且是剩余候选中最小的，故最优；
- 当 $n_0$ 为奇数时，$n_0+1$ 为偶数，$S(n_0+1)-t$ 的奇偶不变、仍为奇数，$n_0+1$ 不可行；再看 $n_0+2$，此时 $n_0+2$ 为奇数，$S(n_0+2)-t = \text{gap}+(n_0+1)+(n_0+2)$ 的奇偶翻转成偶数，可行，且 $n_0$、$n_0+1$ 均已排除，故最优。

三种情形都返回了最小可行步数；其中 $n_0+1$、$n_0+2$ 的上界条件 $S(n) \ge t$ 由 $S$ 的单调性自动满足。∎

## 6. 复杂度分析

- **时间**：$O(\log t)$。倍增定上界 $O(\log n)$ 次判断；二分共 $O(\log n)$ 轮，每轮只做一次乘法与一次比较；末尾的奇偶校正 $O(1)$。$t = 10^9$ 时总运算量不到 $60$ 次。
- **空间**：$O(1)$。只用 `lo`、`hi`、`mid`、`n`、`gap` 等常数个变量，没有数组、没有哈希表，递归也不需要。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int reachNumber(int target) {
        long long t = llabs((long long)target);   // 负号对称，且避免 INT_MIN 溢出
        long long lo = 0, hi = 1;
        while (hi * (hi + 1) / 2 < t) hi <<= 1;   // 倍增定上界
        while (lo < hi) {                          // 二分最小的 n 使 S(n) >= t
            long long mid = (lo + hi) / 2;
            if (mid * (mid + 1) / 2 >= t) hi = mid;
            else lo = mid + 1;
        }
        long long n = lo;
        long long gap = n * (n + 1) / 2 - t;       // 需要被「反向」吃掉的差值
        if (gap % 2 == 0) return (int)n;           // 差值已是偶数
        return (int)(n % 2 == 0 ? n + 1 : n + 2);  // 再加 1 或 2 步翻转奇偶
    }
};
```

### Python

```python
class Solution:
    def reachNumber(self, target: int) -> int:
        t = abs(target)                      # 左右对称，负号可去掉
        lo, hi = 0, 1
        while hi * (hi + 1) // 2 < t:        # 倍增定上界
            hi <<= 1
        while lo < hi:                       # 二分最小的 n 使 S(n) >= t
            mid = (lo + hi) // 2
            if mid * (mid + 1) // 2 >= t:
                hi = mid
            else:
                lo = mid + 1
        n = lo
        gap = n * (n + 1) // 2 - t
        if gap % 2 == 0:
            return n                         # 差值已是偶数，n 步可达
        return n + 1 if n % 2 == 0 else n + 2  # 加 1 或 2 步把奇偶翻过来
```

## 8. 边界情况与易错点

1. **`target` 为负**：`target = -2` 的答案是 $3$，与 `2` 相同。忘记取绝对值会得到错误结果；C++ 还要防 `INT_MIN` 取负溢出。
2. **`target = 0`（约束外）**：$n_0 = 0$、`gap = 0`，返回 $0$，不会死循环；若把 $lo$ 初始化成 $1$ 就会错答 $3$。
3. **差值奇数时只加 1 步**：`target = 5` 会算成 $4$，但 $S(4) = 10$ 与 $5$ 的差是 $5$（奇数），4 步根本到不了，正确答案是 $5$。
4. **`int` 乘法溢出**：倍增时 $hi$ 会到 $65536$，$hi(hi+1)/2 \approx 2.1 \times 10^9$ 已超过 `int` 上限，必须用 `long long`（Python 无此问题）。
5. **用 `sqrt` 定上界**：`sqrt(t)` 取整后可能在完全平方数附近偏小，导致 $n_0$ 少算一位；稳妥做法是倍增，或对 $n_0$ 做一次「不足则 +1」的修正。
6. **别把「恰好 $n$ 步」读成「至多 $n$ 步」**：题目要求走满 `numMoves` 移动，判定式 $S(n) \ge t$ 加奇偶条件刻画的是**恰好 $n$ 步**的可达性。$t = 3$ 至多 $3$ 步可达（$2$ 步就到），但恰好 $3$ 步到不了：$S(3) = 6$、差 $3$ 为奇数。若按「至多」理解，这套判定立刻失效。
7. **负数的取模**：Python 中 `-3 % 2 == 1`、C++ 中 `-3 % 2 == -1`；先 `abs` 再判奇偶，可彻底绕开这个坑。
8. **返回值类型**：`reachNumber` 返回 `int`，$n_0 + 2 \le 44725$ 远在范围内，把 `long long` 结果强转回 `int` 是安全的。
