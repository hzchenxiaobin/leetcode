# LeetCode 全局倒置与局部倒置 题解

## 1. 题目概述

- **标题 / 题号**：全局倒置与局部倒置（#775，medium）
- **链接**：https://leetcode.cn/problems/global-and-local-inversions/
- **来源**：LeetCode 第 69 场周赛 Q2
- **难度**：中等
- **标签**：数组、数学

**题意**：`nums` 是 $[0, n-1]$ 的一个排列。**全局倒置**指数对 $(i,j)$ 满足 $i<j$ 且 $nums[i]>nums[j]$；**局部倒置**指下标 $i$ 满足 $nums[i] > nums[i+1]$（即相邻两个位置构成逆序）。若两者**数量相等**返回 `true`，否则返回 `false`。

**约束**：

- $1 \le n \le 10^5$
- `nums` 是 $[0, n-1]$ 内所有整数组成的一个排列（值域恰好铺满、两两不同）

## 2. 示例

**示例 1**

```text
输入：nums = [1,0,2]
输出：true
解释：全局倒置只有 (0,1)：1 > 0，共 1 个；
      局部倒置只有 i = 0：1 > 0，共 1 个。两者相等。
```

**示例 2**

```text
输入：nums = [1,2,0]
输出：false
解释：全局倒置 2 个：(0,2) 即 1 > 0，(1,2) 即 2 > 0；
      局部倒置 1 个：(1,2) 即 2 > 0。
      多出来的 (0,2) 跨距为 2，不是局部倒置。
```

**示例 3**（补充小例）

```text
输入：nums = [1,0,3,2]
输出：true
解释：逆序对只有 (0,1) 和 (2,3)，全都相邻，共 2 个；
      局部倒置也是这 2 个，相等。
```

## 3. 解题思路

### 3.1 暴力思路

按定义分别计数：局部倒置扫一遍 $O(n)$；全局倒置枚举所有 $i<j$，$O(n^2)$。$n = 10^5$ 时约有 $5\times10^9$ 个数对，必然超时。

用归并排序或树状数组计数全局倒置可以做到 $O(n\log n)$，但代码量陡增。而本题只要**判断是否相等**，并不需要真的把两个数数出来——这提示我们先看清两类倒置之间的包含关系。

### 3.2 核心观察：局部倒置一定是全局倒置

![局部倒置是全局倒置的子集](images/wc69_q2_inversion_subset.svg)

每个局部倒置涉及的下标对是 $(i,\,i+1)$，它天然满足 $i<j$ 与 $nums[i]>nums[j]$，所以**局部倒置一定是全局倒置**：

$$|G| = |L| + D,\qquad D = \#\{(i,j): j \ge i+2,\ nums[i] > nums[j]\}$$

其中 $D$ 是「跨距至少 2」的逆序对个数（$G$ 为全局倒置集合，$L$ 为局部倒置集合）。于是：

$$|G| = |L| \iff D = 0 \iff \text{不存在跨距} \ge 2 \text{ 的逆序对}$$

这一步把「数两遍」降成了「查一次存在性」。更妙的是，题目保证 `nums` 是**排列**，而排列上「无跨距 ≥ 2 的逆序对」有一个极简的等价刻画：

$$\forall i:\ |nums[i] - i| \le 1$$

直观上，某位置的值比下标大至少 2，说明它「抢」了别人的数，必然有更小的数被挤到它右边更远处；反之值比下标小至少 2，说明它「被抢」，左边必有比它大的数。两个方向的严格证明见 §5 引理 2。等价地说：这样的排列只能由若干**互不相邻的相邻对换**拼成，例如 `[1,0,3,2]` 就是 $(0,1)$ 与 $(2,3)$ 两个对换。

### 3.3 算法流程

![一次线性扫描](images/wc69_q2_scan_flow.svg)

从左到右扫一遍，对每个位置 $i$ 检查 $|nums[i]-i| \le 1$，一旦越位超过 1 格就直接返回 `false`；全部通过则返回 `true`。

等价写法（不用 `abs`，也顺便说明了 $D=0$ 的含义）：维护 $nums[0..i-2]$ 的最大值 $mx$，若 $mx > nums[i]$ 则说明存在一个结束于 $i$、起点 $\le i-2$ 的逆序对。注意只能把 $nums[i-2]$ 纳入 $mx$——起点为 $i-1$ 的那一对正是**允许**的局部倒置。

两种写法都是 $O(n)$ 时间、$O(1)$ 额外空间。

### 3.4 示例演算

![示例演算](images/wc69_q2_walkthrough.svg)

以 `[1,2,0]` 为例，逐位计算 $nums[i]-i$：

| $i$ | $nums[i]$ | $nums[i]-i$ | 是否合格 |
|-----|-----------|-------------|----------|
| 0 | 1 | $+1$ | 合格 |
| 1 | 2 | $+1$ | 合格 |
| 2 | 0 | $-2$ | **不合格**（越位 2 格） |

在 $i=2$ 处失败，对应跨距为 2 的那对 $(0,2)$：$nums[0]=1>0=nums[2]$。所以全局 2 个、局部 1 个，返回 `false`。

再看 `[1,0,3,2]`：各位置的偏移依次是 $+1,-1,+1,-1$，全部合格，返回 `true`。此时逆序对恰好是 $(0,1)$ 与 $(2,3)$，全都相邻，$|G|=|L|=2$。

## 4. 算法细节

1. **先立包含关系**：局部倒置 $\subseteq$ 全局倒置，所以恒有 $|G| \ge |L|$，只需检查「有没有多出来的跨距 ≥ 2 的逆序对」。
2. **`abs` 判据的两侧都要查**：既要查 $nums[i] \ge i+2$，也要查 $nums[i] \le i-2$。只查一侧会漏判，例如 `[2,0,1]`（值偏大）和 `[1,2,0]`（值偏小）分别踩到两边。
3. **前缀最大值写法要错位**：判断位置 $i$ 时 $mx$ 只能含 $nums[0..i-2]$，必须在取用**之后**才把 $nums[i-1]$ 并入；若提前并入，合法的相邻交换会被误判成 `false`。$i<2$ 时把 $mx$ 初始化为 $-1$（值域从 0 开始，$-1$ 恒小于任何元素）。
4. **严格不等号**：逆序对定义是 $nums[i] > nums[j]$，前缀最大值判据必须写 `mx > nums[i]`。本题元素互异，`>=` 恰好不会出错；但若题目放宽为可重复元素，`>=` 会把「相等」当成逆序，立刻 WA。
5. **不要真的去数**：计数需要 $O(n\log n)$ 且常数不小；既然只要判等，$O(n)$ 的判定就是下界最优（至少要读入整个数组）。
6. **计数法的溢出风险**（若坚持用）：$n=10^5$ 时全局倒置最多约 $5\times10^9$，超过 32 位有符号整数上限，$D$ 与 $|G|$ 都得用 `long long`。
7. **不要排序**：排序会抹掉下标信息，而本题的判据完全依赖「值」与「下标」的对应关系。
8. **`abs` 判据依赖排列前提**：值域必须恰好是 $[0,n-1]$ 且互不相同；本题约束已保证，无需额外校验。

## 5. 正确性证明

**引理 1（子集关系）**：对任意数组，每个局部倒置都是全局倒置；且全局倒置中除掉局部倒置后，剩下的恰是全部跨距 $\ge 2$ 的逆序对。因此 $|G| = |L| + D$。

**证明**：局部倒置取 $(i,j)=(i,i+1)$ 即满足 $i<j$ 且 $nums[i]>nums[j]$。反之，任一全局倒置对 $(i,j)$ 要么 $j=i+1$（局部倒置），要么 $j \ge i+2$（跨距 $\ge 2$），两类互斥且穷尽。按类计数即得 $|G| = |L| + D$。∎

**引理 2（排列上的等价刻画）**：设 $p$ 是 $[0,n-1]$ 的排列，则 $D=0$（不存在跨距 $\ge 2$ 的逆序对）当且仅当 $\forall i,\ |p[i]-i| \le 1$。

**证明**：

**充分性**：设 $\forall i,\ |p[i]-i|\le 1$。先证 $p$ 由若干互不相邻的相邻对换组成。位置 0 只能放 0 或 1：若 $p[0]=1$，则值 0 只能落在位置 1（$|pos(0)-0|\le 1$ 且位置 0 已被占），前两位构成对换 $(1,0)$，删去后对剩余部分归纳；若 $p[0]=0$，直接删去位置 0 归纳。于是任取 $i<j$ 且 $j\ge i+2$，都有 $p[i] \le i+1 \le j-1 \le p[j]$，故 $p[i] > p[j]$ 不可能成立，$D=0$。

**必要性**：反设存在 $i$ 使 $p[i] \ge i+2$，记 $v=p[i]$。值 $0,1,\dots,v-1$ 共 $v \ge i+2$ 个数都不能放在位置 $i$，而位置 $<i$ 只有 $i$ 个，故其中至少 $v-i \ge 2$ 个落在位置 $>i$；两个不同位置中必有一个 $j \ge i+2$，且 $p[j] < v = p[i]$，得到跨距 $\ge 2$ 的逆序对，矛盾。再设存在 $i$ 使 $p[i] \le i-2$，记 $v=p[i]$。位置 $0..i-1$ 上共 $i$ 个数，其中小于 $v$ 的数至多 $v$ 个（值 $0..v-1$），故至少有 $i-v \ge 2$ 个位置 $q<i$ 满足 $p[q] > v = p[i]$；这两个位置中较小者 $q \le i-2$，于是 $(q,i)$ 是跨距 $\ge 2$ 的逆序对，矛盾。∎

**引理 3（前缀最大值判据）**：记 $m_i = \max(p[0..i-2])$（$i<2$ 时取 $-\infty$），则 $D>0$ 当且仅当存在 $i$ 使 $m_i > p[i]$。

**证明**：若 $m_i > p[i]$，取 $\arg\max$ 的位置 $q \le i-2$，则 $(q,i)$ 是跨距 $\ge 2$ 的逆序对；反之若 $(q,i)$ 是跨距 $\ge 2$ 的逆序对（$q \le i-2$），则 $m_i \ge p[q] > p[i]$。∎

**定理**：`isIdealPermutation` 返回 `true` 当且仅当全局倒置数等于局部倒置数。

**证明**：算法返回 `false` $\iff$ 存在 $i$ 使 $|nums[i]-i| > 1$ $\iff$（引理 2）$D>0$ $\iff$（引理 1）$|G| > |L| \iff |G| \ne |L|$。两边取反即得结论。前缀最大值写法由引理 3 给出同一结论。∎

## 6. 复杂度分析

- **时间**：$O(n)$。只扫描数组一遍，每个位置做一次减法、一次比较（前缀最大值写法多做一次取 `max`）。
- **空间**：$O(1)$。除循环变量外不申请任何与 $n$ 相关的空间。
- **对比**：归并 / 树状数组计数为 $O(n\log n)$ 时间、$O(n)$ 空间；本题的判等需求比计数弱，才能压到线性。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <cstdlib>
using namespace std;

class Solution {
public:
    bool isIdealPermutation(vector<int>& nums) {
        // 局部倒置一定是全局倒置；两者相等 <=> 不存在跨距 >= 2 的逆序对
        // 对 [0, n-1] 的排列，这等价于每个元素都只在原位或相邻位
        for (int i = 0; i < (int)nums.size(); ++i) {
            if (abs(nums[i] - i) > 1) return false;
        }
        return true;
    }
};
```

### Python

```python
class Solution:
    def isIdealPermutation(self, nums: list[int]) -> bool:
        # 逐位检查「值」与「下标」的偏移量，超过 1 就说明存在跨距 >= 2 的逆序对
        for i, v in enumerate(nums):
            if abs(v - i) > 1:
                return False
        return True
```

## 8. 边界情况与易错点

1. **$n=1$ 与 $n=2$**：`[0]` 没有任何数对，返回 `true`；`[1,0]` 的全局、局部倒置都是 1 个，返回 `true`。循环自然地覆盖这两种情况，不需要特判。
2. **偏移量的两个方向**：`[2,0,1]` 在 $i=0$ 处偏大 2（$2-0=2$），`[1,2,0]` 在 $i=2$ 处偏小 2（$0-2=-2$），都要靠 `abs` 拦住；只写 `nums[i] > i + 1` 会漏掉后者。
3. **误以为「局部 ≤ 全局」就够了**：包含关系只给出必要条件，`[1,2,0]` 的 $1 \le 2$ 成立却是 `false`，必须查「跨距 ≥ 2 的逆序对」是否为空。
4. **前缀最大值的错位**：若在判断 $nums[i]$ 之前就把 $nums[i-1]$ 并入 $mx$，`[1,0,3,2]` 会在 $i=1$ 处被 `mx = 1 > 0` 误判为 `false`。$mx$ 只允许覆盖到 $i-2$。
5. **`>=` 与 `>` 的区别**：判据要写严格大于。排列中元素互异使得两者结果相同，但一旦允许重复（如扩展题），`mx >= nums[i]` 会把相等也当成逆序。
6. **计数时用 `int`**：$n=10^5$ 时逆序对最多 $n(n-1)/2 \approx 5\times10^9$，`int` 溢出；应使用 `long long`。
7. **把 `abs` 判据套到非排列数据上**：该判据的等价性依赖「$nums$ 是 $[0,n-1]$ 的排列」。若值域或取值个数变了，应回到「无跨距 ≥ 2 的逆序对」的原始定义，用前缀最大值判定。

**延伸思考**：

1. **跨距阈值推广**：若把「相邻」换成「距离 $\le k$」，则判等条件变成「不存在跨距 $>k$ 的逆序对」，用单调队列维护窗口 $[0,\,i-k-1]$ 的最大值即可 $O(n)$ 判定；若要计数，则需按 $i$ 的顺序延迟插入 $nums[i-k]$ 到树状数组，$O(n\log n)$。
2. **允许重复元素**：$|nums[i]-i| \le 1$ 立即失效（重复值不需要移动位置），但「无跨距 ≥ 2 的逆序对」与「前缀最大值 + 严格大于」的判据仍然成立。
3. **换个角度**：本题本质是在问「两类关系（相邻 / 任意）上的逆序计数是否相等」。同一套「先证包含、再找差集」的思路，可以迁移到「区间逆序对」「局部极值」等许多「局部 vs 全局」的计数题上。
