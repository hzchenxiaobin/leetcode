# LeetCode 优质数对的总数 II 题解

## 1. 题目概述

- **标题 / 题号**：优质数对的总数 II（#3164，medium）
- **链接**：https://leetcode.cn/problems/find-the-number-of-good-pairs-ii/
- **来源**：LeetCode 第 399 场周赛 Q3
- **难度**：中等
- **标签**：数组、哈希表、数论、枚举

**题意**：给定长度分别为 $n$、$m$ 的正整数数组 `nums1` 与 `nums2`，以及正整数 $k$。若 $nums_2[j] \cdot k$ **整除** $nums_1[i]$，则称下标对 $(i, j)$ 为**优质数对**。返回优质数对的总数。数对按**下标**计数：值相同、下标不同的元素各自参与配对。

**约束**：

- $1 \le n, m \le 10^5$
- $1 \le nums_1[i], nums_2[j] \le 10^6$
- $1 \le k \le 10^3$

> 💡 **读题关键**：题面与同场 Q1（3162）逐字相同，变的只有数据范围——而范围一变，解法天差地别：数对总数 $n \cdot m$ 最高 $10^{10}$（$Q1$ 里只有 $2500$），双重循环必超时；答案上界同样是 $10^{10}$，`int` 必然溢出。判定方向不变：被除数是 $nums_1[i]$，$k$ 乘在 $nums_2[j]$ 上、取模之前。

## 2. 示例

**示例 1**

```text
输入：nums1 = [1,3,4], nums2 = [1,3,4], k = 1
输出：5
解释：5 个优质数对分别是 (0,0), (1,0), (1,1), (2,0) 和 (2,2)。
      注意 (0,1) 不是优质数对：3·1 = 3 除不尽 1。
```

**示例 2**

```text
输入：nums1 = [1,2,4,12], nums2 = [2,4], k = 3
输出：2
解释：2 个优质数对分别是 (3,0) 和 (3,1)——12 除尽 2×3=6 与 4×3=12。
```

**示例 3（自造，覆盖「值全重复 → 频次乘法」）**

```text
输入：nums1 = [6,6], nums2 = [2,2], k = 3
输出：4
解释：四个下标对 (i,j) 全部优质。若只按「值对」去重后计 1 个就错了——
      值对 (6,2) 只有一组，但 cnt1[6] × cnt2[2] = 2 × 2 = 4。
```

## 3. 解题思路

### 3.1 暴力思路：为什么 $O(nm)$ 彻底失效

Q1 的双重循环搬过来：枚举每个下标对做一次取模，$n \cdot m$ 最高 $10^{10}$，按每秒 $10^8$ 次取模估算也要跑上百秒——**超时三个数量级**，枚举「下标对」这条路被范围直接堵死。

中途能想到的朴素改进也救不回来：比如先把 `nums2` 桶计数、再对每个 $x = nums_1[i]$ 枚举约数 $d$、查「桶键 $= d$」并要求 $k \mid d$。这仍是 $O(n\sqrt{V})$ 级别的试除，却**既不剪枝、上界还更大**（枚举的是 $x$ 的约数而非 $x/k$ 的）。真正的出路是下面这条等价改写。

### 3.2 核心观察：计数换向——下标对降维成值对 + 整除判定拆两步

![核心概念：整除换向，枚举 x/k 的约数查频次表](images/wc399_q3_divisor_rewrite_concept.svg)

一切从这条等价改写出发（把「乘积的整除」拆成两步）：

$$nums_2[j] \cdot k \mid x \iff k \mid x \;\wedge\; nums_2[j] \,\Big|\, \frac{x}{k}$$

- **正向**：$nums_2[j] \cdot k$ 本身是 $k$ 的倍数，它若整除 $x$，自然 $k \mid x$；且商 $\dfrac{x}{nums_2[j] \cdot k} = \dfrac{x/k}{nums_2[j]}$ 是整数，即 $nums_2[j] \mid x/k$；
- **反向**：若 $x = k \cdot z$ 且 $z = nums_2[j] \cdot t$，则 $x = nums_2[j] \cdot k \cdot t$，整除成立。

于是「$x$ 能与哪些 `nums2[j]` 配对」被拆成：**先过滤 $k \mid x$（不成立的值与谁都配不成，整支剪掉），再在 $y = x/k$ 的约数集合里数出 `nums2` 中等于这些约数的元素个数**。约数集合怎么来？从 $1$ 试除到 $\sqrt{y}$，每发现一个小约数 $d$，就白得一个对称大约数 $y/d$。

配上两张频次表（$cnt_1$、$cnt_2$ 分别为 `nums1`、`nums2` 的值频次表，顺带完成值去重），计数闭环：

$$ans = \sum_{\text{去重值 } x,\; k \mid x} cnt_1[x] \cdot \sum_{d \,\big|\, x/k} cnt_2[d]$$

四个要点：

- **先除后枚举**：枚举 $x/k$ 的约数而不是枚举 $x$ 的约数再判 $k \mid d$——试除上界从 $\sqrt{x}$ 缩到 $\sqrt{x/k}$（$k = 10^3$ 时约缩小 $31$ 倍），且 $k \nmid x$ 的值整支剪掉；
- **两个方向都去重**：`nums1` 按值去重后每个值只做一次试除；`nums2` 折叠进频次表后重复值只占一行；
- **去重只是省枚举，计数要乘回频次**：数对按下标计，值相同的下标各算一个，贡献是 $cnt_1[x] \cdot cnt_2[d]$ 的**乘法展开**（见自造示例 3）；
- **答案用 `long long`**：上界 $n \cdot m = 10^{10} > 2^{31} - 1$——「计数放大版」续作的共同考点。

### 3.3 算法流程

![算法流程：频次表 + 枚举约数](images/wc399_q3_algorithm_flow.svg)

1. 线性扫两个数组，建频次表 $cnt_1$、$cnt_2$；
2. 遍历 $cnt_1$ 的每个键值对 $(x, c)$：若 $k \nmid x$，剪枝跳过；
3. 令 $y = x / k$，试除 $d = 1 \ldots \lfloor\sqrt{y}\rfloor$：命中 $d \mid y$ 就累加 $c \cdot cnt_2[d]$；若 $d^2 < y$ 再累加对称约数的 $c \cdot cnt_2[y/d]$（$d^2 = y$ 即完全平方时**只计一次**）；
4. 全部键遍历完，返回 `ans`（注意类型）。

### 3.4 示例演算

![示例 2 逐值查表演算](images/wc399_q3_example_walkthrough.svg)

以示例 2（`nums1 = [1,2,4,12]`，`nums2 = [2,4]`，`k = 3`）演算，$cnt_2 = \{2{:}1,\ 4{:}1\}$，`nums1` 无重复值：

| 去重值 $x$ | $x \bmod k$ | $y = x/k$ | 约数查表 | 贡献 |
|------|------|------|------|------|
| 1 | $1 \ne 0$ ✗ | — | 剪枝跳过 | 0 |
| 2 | $2 \ne 0$ ✗ | — | 剪枝跳过 | 0 |
| 4 | $1 \ne 0$ ✗ | — | 剪枝跳过 | 0 |
| 12 | $0$ ✓ | $4$ | $cnt_2[1]{=}0$、$cnt_2[2]{=}1$（$d^2{=}y$ 只计一次）、对称 $cnt_2[4]{=}1$ | $1 \times 2 = 2$ |

- $x = 12$：$y = 4$，试除 $d = 1$（命中，查 $cnt_2[1]$ 与对称约数 $cnt_2[4]$）、$d = 2$（命中，$d^2 = y$，只查 $cnt_2[2]$ 一次）；
- 其余三个值被 $k \nmid x$ 剪掉，$ans = 2$，与示例一致。

再验示例 1（$k = 1$，$cnt_2 = \{1{:}1, 3{:}1, 4{:}1\}$）：$x=1$ 的约数 $\{1\}$ 贡献 $1$；$x=3$ 的 $\{1,3\}$ 贡献 $2$；$x=4$ 的 $\{1,2,4\}$ 贡献 $2$；合计 $1 + 2 + 2 = 5$ ✓。

### 3.5 对偶方向：枚举倍数（Python 首选）

![对偶方向：枚举倍数](images/wc399_q3_multiples_duality.svg)

整除计数有一对天然对偶的方向：**枚举约数**（对每个 $x$ 问「谁是它的约数」）与**枚举倍数**（对每个 $b$ 问「谁是 $b \cdot k$ 的倍数」）。把主解整个反过来写：

1. 把 `nums1` 计数到**值域数组** $cnt_1[\,]$（长度 $\max(nums_1) + 1$，$V \le 10^6$）；
2. 对 `nums2` 的每个去重值 $b$（频次 $c$）：令步长 $t = b \cdot k$，若 $t > \max(nums_1)$ 直接跳过；否则枚举 $t, 2t, 3t, \ldots$ 直到越过 $\max(nums_1)$，每步累加 $c \cdot cnt_1[v]$。

倍数法的总步数是**调和级数**：$\sum_{\text{去重 } b} \lfloor V/(b \cdot k) \rfloor \le \frac{V}{k}\big(1 + \ln m'\big)$——即便 $k = 1$、去重值恰为 $1 \sim 10^5$ 的最坏情形也只有约 $1.2 \times 10^7$ 步，且全是数组访问，**纯 Python 也能轻松通过**（约数法最坏 $10^8$ 次试除对 Python 太重，C++ 无压力）。有趣的互补关系：$k$ 越大，倍数法步长越大、跳得越快；约数法则相反，$k$ 越大 $x/k$ 越小、试除越省。

## 4. 算法细节

1. **判定改写是全部优化的支点**（§3.2）：先判 $k \mid x$ 再枚举 $x/k$ 的约数，一举两得——剪掉配不成的整支、把试除上界从 $\sqrt{x}$ 压到 $\sqrt{x/k}$；
2. **频次表 + 双向去重**：$cnt_1$ 用哈希表（键即去重值），遍历键值对时 $c$ 就是该值的下标个数；$cnt_2$ 同理折叠重复值；
3. **试除枚举约数**：循环条件 `d * d <= y`（防 $d$ 越过 $\sqrt{y}$ 漏掉/重算对称部分）；命中 $d$ 后对称约数是 $y / d$；$d^2 = y$（完全平方）时只计一次；
4. **贡献是乘法不是加一**：每命中一个约数 $d$，累加 $c \cdot cnt_2[d]$；`nums2` 中等于 $d$ 的每个下标与 `nums1` 中等于 $x$ 的每个下标各成一个数对；
5. **溢出防御**：答案与中间乘积都可能到 $10^{10}$，C++ 写 `ans += 1LL * c * it->second`，`1LL` 必须在最前——先乘后转时中间结果已溢出；
6. **倍数法实现要点**（§3.5）：`nums1` 折进 $O(V)$ 值域数组；步长 $t = b \cdot k$ 可达 $10^9$，恰在 `int` 边缘，用 `long long` 稳妥；$t > \max(nums_1)$ 时该 $b$ 贡献为零，直接跳过。

## 5. 正确性证明

**引理 1（判定等价）**：对正整数 $x, b, k$，有 $b \cdot k \mid x \iff (k \mid x) \wedge \big(b \mid x/k\big)$。

**证明**：($\Rightarrow$) 设 $b \cdot k \mid x$，则存在正整数 $t$ 使 $x = b \cdot k \cdot t$。于是 $x = k \cdot (b t)$，故 $k \mid x$；且 $x / k = b \cdot t$，故 $b \mid x/k$。($\Leftarrow$) 设 $x = k z$ 且 $z = b t$，则 $x = b \cdot k \cdot t$，即 $b \cdot k \mid x$。∎

**引理 2（试除枚举不重不漏）**：对任意正整数 $y$，集合 $\{(d, y/d) : d \in \mathbb{Z}^+,\ d^2 \le y,\ d \mid y\}$ 把 $y$ 的每个约数恰好覆盖一次，其中 $d = y/d$（$y$ 为完全平方）时该对只含一个约数。

**证明**：$y$ 的约数可配对为 $(d, e)$，$d \cdot e = y$，每对中 $\min(d, e) \le \sqrt{y} \le \max(d, e)$ 且恰有一端 $\le \sqrt{y}$（$d = e$ 时两端重合）。试除循环只取 $d \le \sqrt{y}$ 这一端，另一端 $y/d$ 由对称性给出，故每个约数对恰好产出一次；$d = e = \sqrt{y}$ 时两端重合为同一个约数，若不特判会计两次。∎

**定理（计数公式）**：算法返回值等于优质数对总数，且

$$ans = \sum_{\text{去重值 } x,\; k \mid x} cnt_1[x] \cdot \sum_{d \,\big|\, x/k} cnt_2[d]$$

**证明**：把全部下标对按值分组：$(i, j)$ 归入值对 $(x, b) = (nums_1[i], nums_2[j])$。由引理 1，$(i, j)$ 是否优质只取决于 $(x, b)$，故优质下标对总数 $= \sum_{\text{优质值对 } (x,b)} cnt_1[x] \cdot cnt_2[b]$（同值不同下标的配对数恰为频次之积）。又由引理 1，值对 $(x, b)$ 优质 $\iff k \mid x \wedge b \mid x/k$，故可先对 $b$ 求和：$ans = \sum_{x:\, k \mid x} cnt_1[x] \sum_{b \,\mid\, x/k} cnt_2[b]$。内层求和的键集合恰是 $x/k$ 的约数集合，由引理 2，试除循环把它不重不漏地枚举一遍，每次查表累加 $c \cdot cnt_2[d]$ 与公式逐项一致。∎

## 6. 复杂度分析

- **时间复杂度（枚举约数，主解）**：$O\big(n + m + D\sqrt{V/k}\big)$，$D$ 为 `nums1` 去重后的值个数（$D \le \min(n, V)$）。最坏 $k = 1$、$D = 10^5$、$V = 10^6$ 时约 $10^8$ 次试除，C++ 可过；
- **时间复杂度（枚举倍数，§3.5）**：$O\big(n + m + \sum_{\text{去重 } b} \lfloor V/(bk) \rfloor\big) \le O\big(n + m + \frac{V}{k}(1 + \ln m')\big)$，约 $1.2 \times 10^7$ 步，Python 首选；
- **空间复杂度**：约数法两张哈希频次表 $O(D + m')$；倍数法额外值域数组 $O(V)$，$V \le 10^6$。

## 7. 参考代码

### C++（枚举约数，主解）

```cpp
class Solution {
  public:
    long long numberOfPairs(vector<int>& nums1, vector<int>& nums2, int k) {
        unordered_map<int, int> cnt1, cnt2;
        for (int x : nums1) cnt1[x]++;                  // nums1 值频次（顺带去重）
        for (int y : nums2) cnt2[y]++;                  // nums2 值频次

        long long ans = 0;
        for (auto& [x, c] : cnt1) {                     // 只枚举去重后的值
            if (x % k) continue;                        // k ∤ x：整支剪掉
            int y = x / k;
            for (int d = 1; d * d <= y; d++) {
                if (y % d) continue;                    // d 不是 y 的约数
                auto it = cnt2.find(d);
                if (it != cnt2.end()) ans += 1LL * c * it->second;
                if (d * d == y) continue;                // 完全平方：对称约数只计一次
                it = cnt2.find(y / d);                   // 对称大约数 y/d
                if (it != cnt2.end()) ans += 1LL * c * it->second;
            }
        }
        return ans;
    }
};
```

### Python（枚举倍数，Python 实战推荐）

```python
class Solution:
    def numberOfPairs(self, nums1: List[int], nums2: List[int], k: int) -> int:
        max_v = max(nums1)
        cnt1 = [0] * (max_v + 1)                     # nums1 值域频次数组
        for x in nums1:
            cnt1[x] += 1

        ans = 0
        for b, c in Counter(nums2).items():          # 只枚举去重后的 b
            t = b * k                                # 步长 b·k
            if t > max_v:
                continue                             # 最小倍数已越界
            for v in range(t, max_v + 1, t):          # t, 2t, 3t, ...
                if cnt1[v]:
                    ans += c * cnt1[v]
        return ans
```

> 💡 两份代码同一答案、两条对偶路线：C++ 版按 §3.3 流程走「约数方向」；Python 版走 §3.5 的「倍数方向」，避开 $10^8$ 次试除的纯 Python 超时风险。Python 的 `Counter` 下标访问不存在的键返回 $0$，省掉判空；C++ 的 `unordered_map` 必须先 `find` 再解引用，且下标 `[]` 会顺手插入 $0$ 值键污染表。

## 8. 边界情况与易错点

1. **答案溢出 `int`**：上界 $n \cdot m = 10^{10} > 2^{31} - 1$，返回类型 `long long`（Python 天然大整数无虞）；C++ 中间乘积写 `1LL * c * it->second`，`1LL` 在最前，先乘后转已溢出。
2. **去重后漏乘频次**：数对按下标计，命中一个约数的贡献是 $cnt_1[x] \cdot cnt_2[d]$，不是查到就 +1。自造示例 3 中答案是 $4$ 而不是 $1$，专门踩这一点。
3. **完全平方的对称约数重复计**：$d^2 = y$ 时 $d$ 与 $y/d$ 是同一个数，只计一次。示例 2 中 $y = 4$、$d = 2$ 正踩这一点，多算会得 $3$ 而非 $2$。
4. **试除边界写错**：循环条件是 `d * d <= y`；写成 `d < y` 再同时累加 $d$ 与 $y/d$ 会整倍翻车（小约数的对称全被重算）；写成 `d * d < y` 会漏掉平方根约数。
5. **判定方向与括号（同 Q1）**：被除数是 `nums1[i]`，`k` 乘在 `nums2[j]` 上、取模之前，混用 `%` 与 `*` 时括号显式加。
6. **倍数法的步长边缘**：$t = b \cdot k$ 可达 $10^9$，恰在 `int32` 边缘，C++ 建议用 `long long` 承接；$t > \max(nums_1)$ 的 $b$ 贡献为零，直接跳过（顺带省掉无意义的空转判断）。
7. **极端规模选错路线**：$k = 1$、`nums1` 去重后仍有大量接近 $10^6$ 的大值时，约数法约 $10^8$ 次试除——C++ 无压力，**纯 Python 必须换倍数法**（§3.5）。
8. **哈希表查询姿势**：C++ `unordered_map` 用 `find`/判迭代器，不要用 `[]` 查询（会插入默认键）；Python `Counter` 缺键返回 $0$，可直接下标。
