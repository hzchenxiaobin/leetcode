# LeetCode 优质数对的总数 I 题解

## 1. 题目概述

- **标题 / 题号**：优质数对的总数 I（#3162，easy）
- **链接**：https://leetcode.cn/problems/find-the-number-of-good-pairs-i/
- **来源**：LeetCode 第 399 场周赛 Q1
- **难度**：简单
- **标签**：数组、枚举、暴力

**题意**：给定长度分别为 $n$ 和 $m$ 的正整数数组 `nums1` 与 `nums2`，以及一个正整数 $k$。若 `nums1[i]` 可以**除尽** `nums2[j] * k`（即 `nums2[j] * k` 整除 `nums1[i]`），则称下标对 $(i, j)$（$0 \le i \le n-1$，$0 \le j \le m-1$）为**优质数对**。返回优质数对的总数。注意：数对按**下标**计数，值相同、下标不同的元素各自参与配对。

**约束**：

- $1 \le n, m \le 50$，故数对总数 $n \cdot m \le 2500$
- $1 \le nums_1[i], nums_2[j] \le 50$
- $1 \le k \le 50$

> 💡 **读题关键**：$n \cdot m \le 2500$ 的规模已经把解法「写在脸上」——双重循环逐对判定即可。真正要当真的是**判定方向**：「A 可以除尽 B」= B 是 A 的约数 = `A % B == 0`，本题被除数是 `nums1[i]`，除数是 `nums2[j] * k`。

## 2. 示例

**示例 1**

```text
输入：nums1 = [1,3,4], nums2 = [1,3,4], k = 1
输出：5
解释：5 个优质数对分别是 (0,0), (1,0), (1,1), (2,0) 和 (2,2)。
      注意 (0,1) 不是优质数对：1 除不尽 3。
```

**示例 2**

```text
输入：nums1 = [1,2,4,12], nums2 = [2,4], k = 3
输出：2
解释：2 个优质数对分别是 (3,0) 和 (3,1)——只有 12 除尽 2×3=6 与 4×3=12。
```

**示例 3（自造，覆盖「全是 ✗」的情况）**

```text
输入：nums1 = [4], nums2 = [2], k = 4
输出：0
解释：列头 = 2×4 = 8，而 4 mod 8 = 4 ≠ 0，唯一的数对也不是优质数对。
      k 越大列头越大，✓ 格子只会更少。
```

## 3. 解题思路

### 3.1 签到题的切入路径：从范围直接读出算法

Q1 的目标是把「从读题到 AC」的路径压到最短，三步走：

1. **读范围**：$n, m \le 50$ → 数对总数 $\le 2500$，官方提示（hint）也只说 "The constraints are small. Check all pairs."——双重枚举就是预期解；
2. **翻译判定**：「`nums1[i]` 可以除尽 `nums2[j] * k`」即 $nums_2[j] \cdot k$ 是 $nums_1[i]$ 的约数，写成一行判定式：`nums1[i] % (nums2[j] * k) == 0`；
3. **落地成码**：两层 `for` 加一个 `if` 计数，复杂度 $O(nm) \le 2500$，稳过。

真正值得慢下来的是第 2 步的两个易错点——**方向**与**括号**，见 §8。

### 3.2 核心观察：数对网格——答案是「整除格子」的个数

![核心概念：数对网格，✓ 格子即优质数对](images/wc399_q1_good_pairs_grid.svg)

把 $n \times m$ 个数对摆成一张**网格**：第 $i$ 行放行值 $nums_1[i]$，第 $j$ 列的列头是 $nums_2[j] \cdot k$；格子 $(i, j)$ 标 $\checkmark$ 当且仅当行值除尽列头。于是：

$$ans = \sum_{i=0}^{n-1} \sum_{j=0}^{m-1} \Big[\, nums_1[i] \bmod \big(nums_2[j] \cdot k\big) = 0 \,\Big]$$

三个值得记住的观察：

- **数对是两个数组的全组合**（笛卡尔积）：$i, j$ 各自独立取遍所有下标，没有 $i < j$ 的限制，$i = j$ 的对同样合法——这是与「同一个数组内配对」（如 1512）最大的口径区别；
- **格子彼此独立**：每个格子只依赖自己的行值与列头，不存在单调性、滑窗之类的结构可利用——这正是「无脑枚举」既是最短路径、也是本题没有更花哨做法的原因；
- **计数可以换向**：固定 $nums_1[i]$ 时，$\checkmark$ 的列头全是它的约数；用频次表查约数能把复杂度降到 $O(n\sqrt{V} + m)$。本题完全用不上，但**同场 Q3（3164）正是本题的放大版**，非它不可。

### 3.3 算法流程

![O(n·m) 双重循环判定流程](images/wc399_q1_brute_flow.svg)

1. 外层枚举 $i \in [0, n)$，内层枚举 $j \in [0, m)$，每个数对恰好访问一次；
2. 每对做一次乘法 $nums_2[j] \cdot k$、一次取模 $nums_1[i] \bmod (\cdot)$；
3. 余数为 $0$ 则 `ans` 加一；
4. 循环自然结束，返回 `ans`。$n, m \ge 1$ 保证循环体至少执行一次，全程无任何特判分支。

### 3.4 示例演算

![示例 2 逐格取模演算](images/wc399_q1_example_walkthrough.svg)

以示例 2（`nums1 = [1,2,4,12]`，`nums2 = [2,4]`，`k = 3`）演算，两列的列头分别是 $2 \times 3 = 6$ 与 $4 \times 3 = 12$：

- 前 3 行：$x = 1, 2, 4$ 都小于 $6$（更小于 $12$），余数就是 $x$ 自身，全部 $\times$；
- 第 4 行：$12 \bmod 6 = 0$ ✓、$12 \bmod 12 = 0$ ✓，`ans` 从 $0$ 跳到 $2$。

最终答案 $2$，两个 ✓ 恰对应数对 $(3, 0)$ 与 $(3, 1)$。

## 4. 算法细节

1. **判定式**：`nums1[i] % (nums2[j] * k) == 0`。被除数是 `nums1[i]`，除数是乘积 `nums2[j] * k`；
2. **括号必须显式加**：`%` 与 `*` 同优先级、左结合，`x % y * k` 实际计算 `(x % y) * k`，语义完全跑偏；
3. **循环范围**：$i \in [0, n)$、$j \in [0, m)$ 的全组合，既不是 $j > i$，也不做任何值去重；
4. **计数器类型**：答案上界 $n \cdot m = 2500$，`int` 足够（续作 3164 中同样的答案上界达 $10^{10}$，必须 `long long`）；
5. **零特判**：$n, m \ge 1$ 无空数组；$nums_2[j] \cdot k \ge 1$ 无除零风险。

## 5. 正确性证明

**引理**：数对 $(i, j)$ 是优质数对 $\iff$ $nums_1[i] \bmod (nums_2[j] \cdot k) = 0$。

**证明**：「$a$ 可以除尽 $b$」即 $b$ 是 $a$ 的约数，即存在整数 $q$ 使 $a = q\,b$。由 $a = nums_1[i] \ge 1$、$b = nums_2[j] \cdot k \ge 1$，取模良定义，且对正整数恒有 $a \bmod b = 0 \iff b \mid a$。∎

**定理**：算法返回的计数等于优质数对的总数。

**证明**：双重循环枚举出的数对集合恰为 $\{(i, j) : 0 \le i < n,\ 0 \le j < m\}$，每个数对恰好判定一次且判定互相独立。由引理，`if` 条件成立当且仅当该数对为优质数对，故计数器对每个优质数对恰好加一、对非优质数对不加。返回值即优质数对总数。∎

## 6. 复杂度分析

- **时间复杂度**：$O(nm)$。枚举 $n \cdot m \le 2500$ 个数对，每对一次乘法 + 一次取模，总运算量微秒级。
- **空间复杂度**：$O(1)$。仅累积器与循环变量，不随输入规模增长。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int numberOfPairs(vector<int>& nums1, vector<int>& nums2, int k) {
        int ans = 0;
        for (int x : nums1) {
            for (int y : nums2) {
                if (x % (y * k) == 0) {  // 括号必须有：k 乘在 y 上、取模之前
                    ans++;
                }
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def numberOfPairs(self, nums1: List[int], nums2: List[int], k: int) -> int:
        # 括号必须有：k 乘在 y 上、取模之前
        return sum(x % (y * k) == 0 for x in nums1 for y in nums2)
```

> 💡 两份代码同一逻辑，Python 版把计数压成一行生成器求和（`True` 按 1 计）。提交前先跑示例 2：方向写反会得 6、漏括号会得 5，正确答案 2——用示例给判定式做「单元测试」是签到题防翻车的最有效手段。

## 8. 边界情况与易错点

1. **除尽方向写反**：写成 `nums2[j] * k % nums1[i] == 0` 是最常见的翻车点，示例 2 会算出 6 而不是 2。口诀：**除得尽的（被除数）是 `nums1[i]`**。
2. **漏括号**：`x % y * k` 因 `%` 与 `*` 同优先级、左结合，实际算 `(x % y) * k`，判定退化为「$y$ 整除 $x$」即 **k 被完全忽略**（等价于按 $k = 1$ 判定），示例 2 会算出 5 而不是 2。取模与乘法混用时永远显式加括号。
3. **数对口径**：是两个数组的**全组合**，没有 $i < j$ 的限制，也不按值去重。示例 1 中 $(0,0)$、$(2,2)$ 这类 $i = j$（且值相等）的对都合法且各算一个。
4. **k 只乘在 `nums2[j]` 上**：不要把 k 加到 `nums1[i]` 头上，也不要「先取模再乘」。k 越大列头越大、✓ 只会更少（见自造示例 3）。
5. **最小规模**：$n = m = 1$ 时只有一个数对，答案只能是 0 或 1，可用心算对拍。
6. **溢出预警**：本题 `int` 足够；但续作 3164（同场 Q3）答案上界 $10^{10}$，必须 `long long`——「计数放大版」续作的共同考点。
