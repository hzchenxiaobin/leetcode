# LeetCode 成为 K 特殊字符串需要删除的最少字符数 题解

## 1. 题目概述

- **标题 / 题号**：成为 K 特殊字符串需要删除的最少字符数（#3085，medium）
- **链接**：https://leetcode.cn/problems/minimum-deletions-to-make-string-k-special/
- **来源**：LeetCode 第 389 场周赛 Q3
- **难度**：中等
- **标签**：贪心、哈希表、字符串、计数、排序

**题意**：给定字符串 `word` 和整数 $k$，每次操作可以删除 `word` 中的一个字符。若对所有下标 $i, j$ 都有 $|\mathrm{freq}(word[i]) - \mathrm{freq}(word[j])| \le k$（$\mathrm{freq}$ 为字符出现频率），则称 `word` 为 **k 特殊字符串**。求使 `word` 变成 k 特殊字符串的最少删除次数。

**约束**：

- $1 \le \text{word.length} \le 10^5$
- $0 \le k \le 10^5$
- `word` 仅由小写英文字母组成

> 💡 读题关键：条件写的是「所有下标对」，等价于**出现过的字母的频率两两作差都 $\le k$**，即频率的**极差** $\max - \min \le k$。删除只影响频率、与位置无关，问题只取决于 26 个字母的频率向量。$n \le 10^5$ 封死了按字符位置的搜索，但字母只有 26 个——这是一道披着字符串外衣的**频率向量优化题**。

## 2. 示例

**示例 1**

```text
输入：word = "aabcaba", k = 0
输出：3

解释：删除 2 个 'a' 和 1 个 'c'，word 变为 "baba"，
freq('a') == freq('b') == 2，是 0 特殊字符串。
```

**示例 2**

```text
输入：word = "dabdcbdcdcd", k = 2
输出：2

解释：删除 1 个 'a' 和 1 个 'd'，word 变为 "bdcbdcdcd"，
freq('b') == 2，freq('c') == 3，freq('d') == 4，极差 2 ≤ k。
```

**示例 3**

```text
输入：word = "aaabaaa", k = 2
输出：1

解释：删除 1 个 'b'，word 变为 "aaaaaa"，每个字母频率都是 6。
注意：低频字母 'b' 无法「补」到 6——只有删除操作，只能把它删光。
```

## 3. 解题思路

### 3.1 暴力思路

删除方案由「每个字母删多少个」决定，即 26 维向量 $(d_a, d_b, \dots, d_z)$，$0 \le d_c \le \mathrm{freq}(c)$。朴素枚举所有删除组合，状态数为 $\prod_c (\mathrm{freq}(c)+1)$，最坏情况下是天文数字；每次判定还要 $O(26)$ 检查极差，彻底不可行。改枚举「每个字母的最终保留量」同样爆炸。

**枚举删除状态本身没有出路，必须先做等价变换压缩状态**——把「所有频率两两接近」这个全局约束，压缩成一个可枚举的参数。

### 3.2 核心观察：所有频率落进一个长度为 k 的窗口

![核心观察：频率数轴上长度为 k 的窗口](images/kspecial_window_concept.svg)

推理链三步：

1. **等价转化**：k 特殊 $\iff$ 出现字母的频率极差 $\le k$ $\iff$ 存在左端点 $L \ge 1$，使所有频率落在窗口 $[L, L+k]$ 内（取 $L = \min f$ 即可）。全局约束被压成一个参数 $L$。
2. **只删不加**：频率只能降、不能升。于是固定 $L$ 后，**每个字母的代价互相独立**：
   - $f < L$：无法提升到 $L$，只能**全删**，贡献 $f$；
   - $L \le f \le L+k$：**不动**，贡献 $0$；
   - $f > L+k$：**削顶**到 $L+k$，保留得越多删得越少，贡献 $f - (L+k)$。
3. **候选归约**：$L$ 不必从 1 枚举到 $10^5$——最优 $L$ 一定等于某个字母的**原始频率值**（$\mathrm{cost}(L)$ 在相邻频率值之间是分段线性且非增的，见 §5 引理 3）。

$$\mathrm{cost}(L) \;=\; \sum_{f_i < L} f_i \;+\; \sum_{f_i > L+k} \bigl(f_i - L - k\bigr)$$

> 💡 **一句话结论**：把 26 个频率排序做前缀和，枚举每个原始频率值当窗口左端，三段式算代价取最小。示例 3 删掉 'b' 而不是「补 'b'」，正是「只删不加」的体现。

### 3.3 算法流程：排序 + 前缀和 + 枚举窗口左端

![算法流程：计数、排序前缀和、枚举窗口左端](images/kspecial_algorithm_flow.svg)

1. **计数**：一趟扫描统计 26 桶频率，丢弃 $f = 0$，得到长度 $m \le 26$ 的列表 $a$；
2. **排序 + 前缀和**：$a$ 升序排列，$pre[i+1] = pre[i] + a[i]$，让「区间求和」变成 $O(1)$；
3. **枚举**：对每个候选 $L = a[i]$，二分定位两条边界——$t$ 为第一个 $\ge L$ 的下标（左侧 $a[0..t-1]$ 全删，代价 $pre[t]$），$p$ 为第一个 $> L+k$ 的下标（右侧 $a[p..m-1]$ 削顶，代价 $(pre[m]-pre[p]) - (m-p)\cdot(L+k)$）；
4. 答案取所有 $\mathrm{cost}(L)$ 的最小值。

### 3.4 示例演算

![示例演算：dabdcbdcdcd 枚举四个候选左端](images/kspecial_example_walkthrough.svg)

对示例 2 走一遍：频率 $a=1, b=2, c=3, d=5$，升序 $[1,2,3,5]$。四个候选 $L$ 的代价如上图：$L=1$（d 削 2 个）与 $L=2$（a 全删 + d 削 1 个）并列最优，代价 2，与官方解释一致。

再快查示例 1：频率 $[1,2,4]$（c=1, b=2, a=4），$k=0$。$L=1$：削 b、a 各到 1，共删 $1+3=4$；$L=2$：全删 c=1，削 a 到 2 删 2，共 3；$L=4$：全删 c+b=3。最优 3 ✓。

示例 3：频率 $[1,6]$（b=1, a=6），$k=2$。$L=1$：削 a 到 3，删 3；$L=6$：全删 b，删 1。最优 1 ✓。

## 4. 算法细节

1. **计数**：`cnt[26]` 桶计数一趟 $O(n)$；只收集 $f > 0$ 的频率，$m \le 26$。
2. **前缀和**：排序后 $pre$ 把「左侧全删总和」与「右侧削顶区总和」都变成 $O(1)$ 查询。
3. **二分边界**：`lower_bound(a, L)` 给出严格小于 $L$ 的前缀长度 $t$（贡献 $pre[t]$）；`upper_bound(a, L+k)` 给出严格大于 $L+k$ 的起点 $p$（贡献 $(pre[m]-pre[p]) - (m-p)\cdot(L+k)$）。恰好等于边界的值属于「区间内不动」，两条边界一左一右，不重不漏。
4. **重复频率值**：枚举到重复的 $L$ 得到相同代价，重复计算不影响正确性，无需去重。
5. **候选集足够小**：$m \le 26$，即使朴素地「枚举 $L \in [1, \max f]$、每次扫 26 桶」也只有 $O(26 \cdot \max f) \approx 2.6\times10^6$，同样能过；排序 + 二分是更紧的 $O(m\log m)$ 写法。
6. **返回类型**：官方签名返回 `long long`。答案 $\le n \le 10^5$，`int` 其实装得下，但中间量 $(m-p)\cdot(L+k)$ 等统一用 `long long` 更稳。

## 5. 正确性证明

**引理 1（窗口刻画）**：非空字符串是 k 特殊 $\iff$ 存在 $L \ge 1$ 使所有出现字母的频率 $\in [L, L+k]$。

**证明**：设出现字母频率的最大、最小值为 $M, m_0$（均 $\ge 1$）。k 特殊即 $M - m_0 \le k$。取 $L = m_0$，则所有频率 $\in [m_0, m_0+k]$；反之若所有频率 $\in [L, L+k]$，则 $M - m_0 \le (L+k) - L = k$。∎

（把字符串删空也合法，但代价为 $n$；而 $L$ 取最大频率 $a_m$ 时代价 $\sum_{f_i < a_m} f_i < n$，故最优解必非空，以下只考虑非空情形。）

**引理 2（固定 L 的最优代价）**：固定窗口 $[L, L+k]$（$L \ge 1$）时，最少删除数为 $\mathrm{cost}(L) = \sum_{f_i < L} f_i + \sum_{f_i > L+k} (f_i - L - k)$。

**证明**：固定 $L$ 后，合法性只要求每个字母的最终频率**各自**落入 $\{0\} \cup [L, L+k]$（0 表示删光，删光的字母不参与条件），字母之间无耦合，故可逐字母独立最小化。字母 $i$（原频率 $f_i \ge 1$）的可行最终频率集合为：若 $f_i \ge L$，为 $\{0\} \cup [L, \min(f_i, L+k)]$；若 $f_i < L$，只剩 $\{0\}$（频率无法提升）。删除量 = $f_i - $ 最终频率，故最小删除量即最大化最终频率：$f_i \ge L$ 时取 $\min(f_i, L+k)$，删除量 $\max(0,\, f_i - L - k)$；$f_i < L$ 时取 $0$，删除量 $f_i$。对 $i$ 求和即得 $\mathrm{cost}(L)$，且各字母取值可同时达成。∎

**引理 3（候选集归约）**：设出现字母的频率升序为 $a_1 \le a_2 \le \cdots \le a_m$，则 $\min_{1 \le L \le a_m} \mathrm{cost}(L)$ 在某个 $L = a_i$ 处取得。

**证明**：考察 $\mathrm{cost}$ 在相邻频率值之间开区间 $(a_j, a_{j+1})$ 内的形态。第一项 $\sum_{f_i < L} f_i$：开区间内没有 $f_i$ 落入，故对一切 $L \in (a_j, a_{j+1})$，$\{i : f_i < L\} = \{i : f_i \le a_j\}$ 恒定，该项为常数。第二项 $\sum_{f_i > L+k}(f_i - L - k)$：每个满足 $f_i > L+k$ 的字母贡献 $f_i - L - k$，是关于 $L$ 的线性函数、斜率 $-1$；其余字母贡献为 $0$，且在 $L = f_i - k$ 处贡献连续过渡为 0。故第二项是斜率为 $-|\{i : f_i > L+k\}| \le 0$ 的线性函数，开区间内**非增**。于是 $\mathrm{cost}$ 在 $(a_j, a_{j+1}]$ 上非增，且第一项在 $L = a_{j+1}$ 处的取值（$f_i < a_{j+1} \iff f_i \le a_j$）与开区间内一致、第二项连续，故 $\mathrm{cost}(a_{j+1}) \le \mathrm{cost}(L)$ 对一切 $L \in (a_j, a_{j+1}]$ 成立。又对 $L > a_m$：所有 $f_i < L$，$\mathrm{cost}(L) = n > \mathrm{cost}(a_m) \ge \min_i \mathrm{cost}(a_i)$。故全局最小在 $\{a_i\}$ 中取得。∎

**定理**：算法返回的 $\min_i \mathrm{cost}(a_i)$ 即为使 `word` 成为 k 特殊字符串的最少删除数。

**证明**：由引理 1，最少删除数 $= \min_{L \ge 1} \mathrm{cost}(L)$（非空最优必存在；空串情形代价劣于 $L = a_m$，不影响最小值）；由引理 3，该最小值在候选集 $\{a_i\}$ 上取得；由引理 2，$\mathrm{cost}(a_i)$ 是窗口取 $a_i$ 时的精确最小代价。算法枚举的正是全部 $\{a_i\}$ 并取最小。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n + m \log m)$，$m$ 为出现过的字母数（$m \le 26$）。
  - 一趟计数 $O(n)$；
  - 排序 $O(m \log m)$；
  - 枚举 $m$ 个左端点，每个两次二分 $O(\log m)$；
  - $m \le 26$ 视为常数时整体为 $O(n)$，瓶颈只在读入。
- **空间复杂度**：$O(m) = O(1)$。
  - 频率数组、排序临时空间、前缀和数组均为常数大小（26 以内）。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    long long minimumDeletions(string word, int k) {
        long long cnt[26] = {};
        for (char c : word) cnt[c - 'a']++;

        vector<long long> a;                 // 出现字母的频率
        for (long long f : cnt)
            if (f > 0) a.push_back(f);
        sort(a.begin(), a.end());            // 升序，供二分使用
        int m = a.size();

        vector<long long> pre(m + 1);         // 升序 + 前缀和
        for (int i = 0; i < m; i++) pre[i + 1] = pre[i] + a[i];

        long long ans = LLONG_MAX;
        for (long long L : a) {               // 枚举窗口左端 L
            long long hi = L + k;
            int t = lower_bound(a.begin(), a.end(), L) - a.begin();  // a[t..] >= L
            int p = upper_bound(a.begin(), a.end(), hi) - a.begin(); // a[p..] > hi
            long long cost = pre[t]                                // 左侧全删
                           + (pre[m] - pre[p]) - (m - p) * hi;     // 右侧削顶
            ans = min(ans, cost);
        }
        return ans;
    }
};
```

### Python

```python
from bisect import bisect_left, bisect_right
from collections import Counter
from math import inf


class Solution:
    def minimumDeletions(self, word: str, k: int) -> int:
        a = sorted(f for f in Counter(word).values() if f > 0)
        m = len(a)
        pre = [0] * (m + 1)
        for i, f in enumerate(a):
            pre[i + 1] = pre[i] + f

        ans = inf
        for L in a:                             # 枚举窗口左端 L
            hi = L + k
            t = bisect_left(a, L)               # a[:t] < L：全删
            p = bisect_right(a, hi)             # a[p:] > hi：削顶
            cost = pre[t] + (pre[m] - pre[p]) - (m - p) * hi
            ans = min(ans, cost)
        return ans
```

## 8. 边界情况与易错点

1. **想「补」低频字母**：只有删除操作，$f < L$ 的字母无法提升、只能全删。示例 3 若想着把 'b' 补到 6 就方向错了。
2. **候选集写错**：枚举 $L$ 只需出现过的频率值（共 $m \le 26$ 个）；从 1 到 $\max f$ 全枚举也能过（$O(26\max f)$），但别漏掉「等于某个原始频率」这一关键归约，也别只枚举前 26 个整数。
3. **k = 0**：窗口退化为单点 $[L, L]$，代码无需特判。
4. **二分边界方向**：左侧用 `lower_bound`（严格 $< L$ 的前缀），右侧用 `upper_bound`（严格 $> L+k$ 的后缀）；写反会把「恰好等于边界」的字母误算进删除/削顶。
5. **重复频率**：多个字母同频时同进同出三段，二分写对则自然正确；手动去重反而容易错。
6. **全部同频 / 单一字母**：$L$ 取该频率时 $\mathrm{cost} = 0$，自动覆盖。
7. **删成空串**：合法但代价 $n$，永远不优于保留方案，无需特判。
8. **溢出**：答案 $\le 10^5$，`int` 够用；C++ 按官方签名用 `long long`，中间量 $(m-p)(L+k) \le 26 \cdot 2\times10^5$ 也很小——本题的坑不在数值范围，在思路转化。

**延伸思考**：

- **允许「添加」字符**：$f < L$ 的字母多一个选项「补到 $L$，代价 $L - f$」，与「全删 $f$」取较小者；整体仍是枚举 $L$ 的三段式，代价函数变 $\sum_i \min(f_i,\ L - f_i,\ \ldots)$ 形态。

- **k = 0 的特例**：等价于「最少删除使所有频率相等」，仍可用枚举目标频率 $\in$ 原频率集合的套路，体会候选归约的普适性。
- **范式总结**：见到「频率约束 + 删除类操作」，先转 26 维频率向量，再把全局约束（极差 / 互异 / 上限）压缩成可枚举的参数，最后贪心地让每个字母独立达标。
