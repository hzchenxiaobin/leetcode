# LeetCode 统计以给定字符开头和结尾的子字符串总数 题解

## 1. 题目概述

- **标题 / 题号**：统计以给定字符开头和结尾的子字符串总数（#3084，medium）
- **链接**：https://leetcode.cn/problems/count-substrings-starting-and-ending-with-given-character/
- **来源**：LeetCode 第 389 场周赛 Q2
- **难度**：中等
- **标签**：数学、字符串、计数

**题意**：给定字符串 `s` 和字符 `c`，返回 `s` 中以 `c` 开头**且**以 `c` 结尾的**非空子字符串**总数。子字符串按**出现位置**计数——内容相同、位置不同的子串各算一个。

**约束**：

- $1 \le \text{s.length} \le 10^5$
- `s` 和 `c` 均由小写英文字母组成

> 💡 读题关键：题目只约束**两端**，中间字符完全任意；单个字符 `c` 自身既是开头又是结尾，天然合法。两个约束条件各埋一个坑——$n \le 10^5$ 封死 $O(n^2)$ 枚举，「按位置计数」把最坏答案推到 $5\times10^9$，逼出 64 位整数。

## 2. 示例

**示例 1**

```text
输入：s = "abada", c = "a"
输出：6

解释：'a' 出现在下标 0、2、4。6 个合法子串为：
"a"(0)、"aba"(0..2)、"abada"(0..4)、"a"(2)、"ada"(2..4)、"a"(4)。
```

**示例 2**

```text
输入：s = "zzz", c = "z"
输出：6

解释：s 的全部 6 个子串（3 个 "z"、2 个 "zz"、1 个 "zzz"）都以 'z' 开头结尾。
注意 3 个 "z" 内容相同但位置不同，各算一个。
```

**示例 3（补充）**

```text
输入：s = "abc", c = "d"
输出：0

解释：c 在 s 中一次都不出现，没有合法子串。
```

## 3. 解题思路

### 3.1 暴力思路

按题面直接模拟：两层循环枚举子串左右端点 $(l, r)$，判定 `s[l] == c && s[r] == c`：

```python
n = len(s)
ans = sum(s[l] == c and s[r] == c for l in range(n) for r in range(l, n))
```

$n = 10^5$ 时子串总数 $\binom{n+1}{2} \approx 5\times10^9$，必然超时。小优化：合法子串的两端只能落在 `c` 的出现位置上，于是「枚举所有下标对」可以收缩为「枚举 `c` 的位置对」——但最坏情况 `s` 全是 `c`（如示例 2），位置数 $m = n$，仍是 $O(m^2) \approx 5\times10^9$ 对。**枚举这条路被数量级本身封死**，出路是根本不枚举子串，而是**数位置对**——组合计数。

### 3.2 核心观察：合法子串 ⇔ 从 c 的位置中选一对 (i ≤ j)

![核心观察：合法子串与 c 的位置对一一对应](images/csub_pairs_concept.svg)

推理链只有三步：

1. 子串由首尾下标 $(l, r)$（$l \le r$）**唯一确定**；
2. 合法当且仅当两端都是 `c`——**中间是什么字符完全无关**；
3. 因此每个合法子串 ⟺ 从 `c` 的出现位置集合 $\{p_1 < p_2 < \cdots < p_m\}$ 中选出一对 $(p_i, p_j)$，允许 $i = j$（对应单字符子串）。

「从 $m$ 个位置中选 $i \le j$ 的有序对」正是**可重复组合**：

$$\text{ans} \;=\; \underbrace{m}_{i=j\text{，单字符}} + \underbrace{\binom{m}{2}}_{i<j\text{，长度}\ge2} \;=\; \frac{m(m+1)}{2} \;=\; 1 + 2 + \cdots + m$$

> 💡 **一句话结论**：数出 `c` 在 `s` 中出现 $m$ 次，答案就是 $\frac{m(m+1)}{2}$。$m = 0$（`c` 不出现）时公式自然给出 0，无需特判。

### 3.3 算法流程：一趟计数 + 套公式

![算法流程：扫描计数、套公式、防溢出](images/csub_count_flow.svg)

把结论翻译成算法只需两步：

1. **一趟扫描** `s` 统计 `c` 的出现次数 `m`——一个计数变量足够，连哈希表都不用建；
2. **套公式**返回 `m * (m + 1) / 2`。

> ⚠️ 溢出是本题最大的实现陷阱：$m \le 10^5 \Rightarrow \frac{m(m+1)}{2} \approx 5\times10^9 > 2^{31}-1 \approx 2.1\times10^9$。C++ 中若 `m` 声明为 `int`，`m * (m + 1)` 在**乘法发生的那一刻**就已经溢出，必须让 `m` 本身是 `long long`（官方函数签名也返回 `long long`）；Python 原生大整数无此烦恼。

### 3.4 示例演算：按结尾位置拆贡献

![示例演算：第 j 个 c 结尾贡献 j 个子串](images/csub_abada_walkthrough.svg)

除组合视角外还有一个同样重要的**前缀视角**：以第 $j$ 个 `c` 结尾的合法子串**恰好有 $j$ 个**——开头可以从第 $1 \sim j$ 个 `c` 中任选。对 `s = "abada"`、`c = 'a'` 走一遍（`'a'` 出现在下标 0、2、4，$m = 3$）：

| 结尾位置 | 是第几个 a | 以它结尾的合法子串 | 贡献 |
|----------|-----------|--------------------|------|
| 下标 0 | 第 1 个 | `"a"` | 1 |
| 下标 2 | 第 2 个 | `"a"`、`"aba"` | 2 |
| 下标 4 | 第 3 个 | `"a"`、`"ada"`、`"abada"` | 3 |

合计 $1 + 2 + 3 = 6 = \frac{3\times4}{2}$，与示例 1 一致。示例 2 `"zzz"` 同理：$m = 3$，六个子串 `"z"`×3、`"zz"`×2、`"zzz"` 全部合法，答案同为 6。

## 4. 算法细节

1. **计数方式**：C++ 用 `std::count(s.begin(), s.end(), c)`（或手写循环），Python 用 `str.count(c)`，一趟 $O(n)$。
2. **公式实现**：`m * (m + 1) / 2`——**先乘后除**：$m$ 与 $m+1$ 一奇一偶，乘积必为偶数，整除无损；若写成 `m / 2 * (m + 1)`，$m$ 为奇数时整除向下取整会丢精度（$m=3$ 时得 4 而非 6）。
3. **溢出处理**：最大答案 $\frac{10^5 \times (10^5+1)}{2} = 5{,}000{,}050{,}000$，超 32 位 `int`。C++ 中 `m` 必须是 `long long`——`(long long)(m * (m + 1))` 这种「先乘后转」是先溢出再转换，照样错。
4. **逐位累加版**：扫到 `c` 就执行 `ans += ++m`，即边扫边加 $1+2+\cdots+j$，与公式版等价；它把「按结尾拆贡献」写显式，遇到变体（如 2083 任意字母版）直接照搬这个骨架。
5. **为什么不用哈希表**：只关心**一个**字符的出现次数，一个计数变量足够；26 桶计数表是泛化到「首尾是同一个任意字母」时才需要的东西。

## 5. 正确性证明

**引理 1（子串与下标对双射）**：非空子字符串集合与 $\{(l, r) : 0 \le l \le r < n\}$ 之间存在双射 $(l, r) \mapsto s[l..r]$。

**证明**：子串定义为连续非空字符序列，由起始下标 $l$ 与结束下标 $r$（$l \le r$）唯一确定；反之每对 $(l, r)$（$l \le r$）都唯一确定一个非空子串 $s[l..r]$。两个方向的映射互逆。∎

**引理 2（合法性判定）**：子串 $s[l..r]$ 合法 $\iff$ $l, r \in P$，其中 $P$ 是 `c` 的出现下标集合。

**证明**：合法性即 $s[l] = c$ 且 $s[r] = c$，按 $P$ 的定义等价于 $l, r \in P$。∎

**定理（计数公式）**：设 $m = |P|$，则答案为 $\dfrac{m(m+1)}{2}$。

**证明**：由引理 1 与引理 2，答案等于 $\#\{(l, r) : l \le r,\ l, r \in P\}$。将 $P$ 升序编号为 $p_1 < p_2 < \cdots < p_m$，则映射 $(p_i, p_j) \mapsto (i, j)$ 是该集合到 $\{(i, j) : 1 \le i \le j \le m\}$ 的双射（$l \le r$ 与 $i \le j$ 等价是因为编号保序）。后者按 $i = j$ 与 $i < j$ 分拆：$i = j$ 的对恰 $m$ 个，$i < j$ 的对恰 $\binom{m}{2}$ 个，合计 $m + \frac{m(m-1)}{2} = \frac{m(m+1)}{2}$。∎

**引理 3（前缀视角 / 逐位累加等价）**：以 $p_j$ 结尾的合法子串恰有 $j$ 个；按右端点分组不重不漏，故逐位累加版返回 $\sum_{j=1}^{m} j = \frac{m(m+1)}{2}$，与公式版一致。

**证明**：以 $p_j$ 结尾的合法子串形如 $s[l..p_j]$ 且 $l \in P$；由 $l \le p_j$ 与 $P$ 保序，$l$ 只能取 $p_1, \dots, p_j$ 中之一，共 $j$ 个选择，且不同 $l$ 给出不同子串（右端点相同、左端点不同）。每个合法子串恰有一个右端点，故按右端点分组是不重不漏的划分；对 $j$ 求和即等差数列求和公式。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$，$n = \text{s.length}$。
  - 一趟扫描统计 `c` 的出现次数，每个字符一次比较；
  - 公式计算与返回为 $O(1)$。
- **空间复杂度**：$O(1)$。
  - 公式版只需一个计数变量；逐位累加版再加一个答案变量，仍是常数个。

对比暴力的 $O(n^2) \approx 5\times10^9$ 次判定，线性扫描快了 5 个数量级——$n = 10^5$ 轻松通过。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    long long countSubstrings(string s, char c) {
        long long m = count(s.begin(), s.end(), c);  // c 的出现次数
        return m * (m + 1) / 2;                      // m + C(m,2)
    }
};
```

### Python

```python
class Solution:
    def countSubstrings(self, s: str, c: str) -> int:
        m = s.count(c)
        return m * (m + 1) // 2
```

逐位累加版（对应 3.4 的前缀视角，骨架更能推广到变体）：

```python
class Solution:
    def countSubstrings(self, s: str, c: str) -> int:
        ans = m = 0
        for ch in s:
            if ch == c:
                m += 1        # ch 是第 m 个 c
                ans += m      # 以它结尾的合法子串恰有 m 个
        return ans
```

## 8. 边界情况与易错点

1. **32 位溢出**：最大答案 $5{,}000{,}050{,}000 > 2^{31}-1 \approx 2.1\times10^9$。C++ 用 `long long`，且类型要在**乘法发生前**就正确——`int m` 先乘后转、先转后写都救不了。这是本题第一大 WA 点。
2. **漏掉 $i = j$（单字符子串）**：`c` 自己就是合法子串。只算 $\binom{m}{2}$ 会把示例 1、2 都错算成 3。
3. **误按内容去重**：`"zzz"` 的三个 `"z"` 各算一个；题目按位置计数，不要把子串内容塞进集合去重。
4. **`c` 不出现**：$m = 0$ 时公式自然给出 0，无需特判；逐位累加版同样返回 0。
5. **$n = 1$**：`s[0] == c` 时答案 1，否则 0，公式自动覆盖。
6. **整除顺序**：保持 `m*(m+1)/2` 先乘后除；改成 `m/2*(m+1)` 在 $m$ 为奇数时会因整除截断算错。

**延伸思考**：

- **要求长度 $\ge 2$**：去掉 $i = j$ 的单字符贡献，答案变为 $\frac{m(m-1)}{2}$。
- **改问「内容不同」的合法子串数**：配对计数失效（同内容子串会重复），需后缀自动机 / 后缀数组去重，难度陡增——体会「按位置计数」这一条件省了多少事。
- **`c` 推广为子串 `t`**（子串以 `t` 开头且以 `t` 结尾）：用 KMP / Z 函数找出 `t` 的所有出现位置，再数「不相交的出现对」，是本题的直接进阶形态。
- **范式总结**：配对计数先问「允许 $i = j$ 吗」——允许则 $\binom{m+1}{2} = \frac{m(m+1)}{2}$，不允许则 $\binom{m}{2} = \frac{m(m-1)}{2}$。
