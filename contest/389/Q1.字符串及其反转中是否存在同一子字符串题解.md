# LeetCode 字符串及其反转中是否存在同一子字符串 题解

## 1. 题目概述

- **标题 / 题号**：字符串及其反转中是否存在同一子字符串（#3083，easy）
- **链接**：https://leetcode.cn/problems/existence-of-a-substring-in-a-string-and-its-reverse/
- **来源**：LeetCode 第 389 场周赛 Q1
- **难度**：简单
- **标签**：哈希表、字符串

**题意**：给定字符串 `s`，判断是否存在一个**长度为 2** 的子字符串，它既出现在 `s` 中，也出现在 `s` 反转后的字符串中。存在返回 `true`，否则返回 `false`。

**约束**：

- `1 <= s.length <= 100`
- `s` 仅由小写英文字母组成

> 💡 读题关键：问的**不是**「`s` 是否回文」，而是「某个长度 2 子串是否在 `s` 与 `reverse(s)` 中**同时**出现」。突破口在于：`reverse(s)` 里没有新的字符对，只有原串字符对的**镜像**。

## 2. 示例

**示例 1**

```text
输入：s = "leetcode"
输出：true

解释：子字符串 "ee" 的长度为 2，它也出现在 reverse(s) == "edocteel" 中。
```

**示例 2**

```text
输入：s = "abcba"
输出：true

解释：所有长度为 2 的子字符串 "ab"、"bc"、"cb"、"ba" 也都出现在
reverse(s) == "abcba" 中。
```

**示例 3**

```text
输入：s = "abcd"
输出：false

解释：s 中不存在满足「在其反转后的字符串中也出现」且长度为 2 的子字符串。
```

## 3. 解题思路

### 3.1 暴力思路

按题面直接模拟：先构造 `rev = reverse(s)`，再枚举 `s` 的 $n-1$ 个长度 2 子串，逐个判断是否为 `rev` 的子串：

```python
rev = s[::-1]
ans = any(s[i:i + 2] in rev for i in range(len(s) - 1))
```

枚举 $O(n)$ 个子串、每次子串包含判定 $O(n)$，总时间 $O(n^2)$。$n \le 100$ 时约 $10^4$ 次操作，赛时可以直接交。但这个写法**完全没利用「反转」的结构性质**——反转并不产生新的字符对，只是把已有的对**颠倒顺序**。抓住这一点，就能把「跨字符串的包含判定」压成「单字符串内的查表」。

### 3.2 核心观察：镜像二元组——不必真造反转串

![核心观察：整串反转等于每个相邻对各自镜像](images/rev_substring_mirror_concept.svg)

设 $r = \text{reverse}(s)$，$n = |s|$，则 $r[j] = s[n-1-j]$，于是 $r$ 的每个长度 2 子串满足：

$$r[j]\,r[j+1] \;=\; s[n-1-j]\,s[n-2-j]$$

即 $r$ 的相邻对集合，恰好是 $s$ 的相邻对集合**逐对取反序**。于是得到等价刻画：

$$\text{"ab" 是 } r \text{ 的子串} \iff \text{"ba" 是 } s \text{ 的子串}$$

> 💡 **问题转化**：原条件「子串 "ab" 既在 `s` 中也在 `r` 中」等价于——**`s` 的相邻对集合中 "ab" 与 "ba" 同时出现**。特别地，"aa" 这类**自镜像**对的出现本身就满足条件。

小写字母只有 26 个，长度 2 的二元组至多 $26^2 = 676$ 种，用 `bool seen[26][26]` 做 $O(1)$ 记录与查询，**根本不需要显式构造反转串**。

### 3.3 算法流程

![算法流程：一遍扫描，先判后记](images/rev_substring_scan_flow.svg)

一遍扫描，对每个相邻对 $(a, b) = (s[i-1], s[i])$ 依次执行：

```text
seen[26][26] ← 全 false
for i = 1 .. n-1:
    (a, b) = (s[i-1], s[i])
    若 a == b:            # 自镜像对，出现即满足
        返回 true
    若 seen[b][a] 为真:   # 镜像对 "ba" 之前出现过
        返回 true
    seen[a][b] ← true     # 先判定，后记录
返回 false
```

> ⚠️ **顺序不能颠倒**：必须**先判定、后记录**，且 $a=b$ 要单独前置判断。否则处理 "ee" 这种自镜像对时，查询 `seen[e][e]` 发现它自己还没进表，会漏判——示例 1 恰好是这种情形，也是本题最常见的 WA 点。

### 3.4 示例演算

![示例演算：leetcode、abcba、abcd 三用例逐对扫描](images/rev_substring_walkthrough.svg)

- `s = "leetcode"`：$i=1$ 记录 "le"；$i=2$ 遇到 $(e,e)$，自镜像命中，返回 **true**；
- `s = "abcba"`：依次记录 "ab"、"bc"；$i=3$ 遇到 $(c,b)$，查 `seen[b][a]` 即 `seen[b][c]`——"bc" 已在表中，返回 **true**（$i=4$ 的 "ba" 不会再被处理）；
- `s = "abcd"`："ab"、"bc"、"cd" 两两互不为镜像，也无自镜像对，扫描结束返回 **false**。

## 4. 算法细节

1. **数据结构**：`bool seen[26][26]`，键为相邻对 $(a, b) = (s[i-1],\, s[i])$（代码里减 `'a'` 把字符映射到 $0..25$）；Python 用字符串集合存 `"ab"` 即可，元素至多 $\min(n-1,\, 676)$ 个。
2. **判定三连**：每个位置依次做 ① `a == b`？② `seen[b][a]`？③ `seen[a][b] = true`。前两步任一命中立即返回，第三步永远最后做。
3. **查表方向**：当前对是 $(a,b)$，要查的是**镜像** $(b,a)$ 是否出现过，即 `seen[b][a]`；写成 `seen[a][b]` 就退化成「判重」——`"abcabc"` 正确答案是 `false`（无任何镜像对），判重写法会在第二个 "ab" 处误返回 `true`。
4. **两阶段写法**：先把全部相邻对收进集合、再查询是否存在 $p$ 满足 $\text{reverse}(p)$ 也在集合中，无需 $a=b$ 特判——集合先**完整建好**再查，"ee" 查它自己的镜像（还是 "ee"）自然命中：
   ```python
   seen = {s[i:i + 2] for i in range(len(s) - 1)}
   ans = any(p[::-1] in seen for p in seen)
   ```
5. **复杂度上界来自字母表**：记录与查询都是 $O(1)$，瓶颈只剩扫描本身的 $O(n)$。

## 5. 正确性证明

**引理 1（反转的相邻对镜像）**：设 $n = |s|$，$r = \text{reverse}(s)$，则对每个 $0 \le j \le n-2$ 有 $r[j]\,r[j+1] = s[n-1-j]\,s[n-2-j]$，且 $j$ 遍历 $[0, n-2]$ 时，下标对 $(n-2-j,\, n-1-j)$ 恰好遍历 $s$ 的全部相邻下标对。

**证明**：由反转定义 $r[j] = s[n-1-j]$，逐字符代入即得等式。令 $i = n-2-j$，则 $j$ 从 $0$ 到 $n-2$ 时 $i$ 从 $n-2$ 到 $0$，是 $[0, n-2]$ 上的一一对应。∎

**推论**：对任意字符对 $(x, y)$："xy" 是 $r$ 的子串 $\iff$ "yx" 是 $s$ 的子串。

**证明**："xy" 是 $r$ 的子串，当且仅当存在 $j$ 使 $r[j]r[j+1] = $ "xy"，由引理 1 当且仅当存在 $i$ 使 $s[i]s[i+1] = $ "yx"。∎

**定理（判定准则）**：答案为 `true` $\iff$ 存在字符对 $(a, b)$ 使 "ab" 与 "ba" 都是 $s$ 的子串（$a = b$ 时两者相同，即自镜像对出现一次即可）。

**证明**：
（⇐）设 "ab" 与 "ba" 都是 $s$ 的子串。前者说明 "ab" 出现在 $s$ 中；后者由推论说明 "ab" 出现在 $r$ 中。故 "ab" 同时出现在两者中，答案为 `true`。
（⇒）设 "ab" 同时出现在 $s$ 与 $r$ 中。前者给出 "ab" 是 $s$ 的子串；后者由推论给出 "ba" 是 $s$ 的子串。∎

**引理 2（一遍扫描等价）**：§3.3 的一遍扫描返回 `true` 当且仅当定理条件成立。

**证明**：记第 $k$ 个相邻对为 $P_k = (s[k], s[k+1])$，归纳易知处理 $P_i$ 时 `seen` 中恰含 $P_0, \dots, P_{i-1}$。
若在 $P_i$ 处返回 `true`：要么 $a = b$，此时 $P_i = (a,a)$ 自身同时充当 $(a,b)$ 与 $(b,a)$；要么 `seen[b][a]` 为真，即存在 $k < i$ 使 $P_k = (b,a)$，与当前 $P_i = (a,b)$ 成对。两种情形定理条件均成立。
反之设定理条件成立：若某 $P_i = (a,a)$，处理到它时第一步即命中；否则存在 $p \ne q$ 使 $\{P_p, P_q\} = \{(a,b), (b,a)\}$，不妨 $p < q$、$P_q = (a,b)$、$P_p = (b,a)$，处理 $P_q$ 时 $P_p$ 已入表，第二步 `seen[b][a]` 命中。故扫描必在某处返回 `true`。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n + |\Sigma|^2) = O(n)$。
  - 一遍扫描 $n-1$ 个相邻对，每对做常数次查表与记录；
  - `seen` 表初始化 $26^2 = 676$ 个布尔，为常数开销。
- **空间复杂度**：$O(|\Sigma|^2) = O(1)$。
  - `bool[26][26]` 固定 676 个布尔，与 $n$ 无关；Python 集合版至多存 $\min(n-1, 676)$ 个二元组，同样是常数上界。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    bool isSubstringPresent(string s) {
        bool seen[26][26] = {};
        for (int i = 1; i < (int)s.size(); ++i) {
            int a = s[i - 1] - 'a', b = s[i] - 'a';
            if (a == b || seen[b][a]) return true;  // 先判定：自镜像 / 镜像已现
            seen[a][b] = true;                      // 后记录
        }
        return false;
    }
};
```

### Python

```python
class Solution:
    def isSubstringPresent(self, s: str) -> bool:
        seen = set()
        for a, b in zip(s, s[1:]):
            if a == b or b + a in seen:   # 先判定：自镜像 / 镜像对已出现
                return True
            seen.add(a + b)               # 后记录
        return False
```

## 8. 边界情况与易错点

1. **最小输入**：$n = 1$ 时没有长度 2 子串，循环体不执行，返回 `false`；$n = 2$ 时 `"aa"` → `true`、`"ab"` → `false`，一组最小用例即可同时覆盖自镜像与无镜像两种结局。
2. **漏写 `a == b` 特判**：一遍扫描「先判后记」，处理 "ee" 时 $(e,e)$ 尚未入表，只查 `seen[e][e]` 必为假——示例 1 会被错杀成 `false`。这是本题第一大 WA 点。
3. **查表方向写反**：要查的是镜像 `seen[b][a]`；写成 `seen[a][b]` 退化成判重，`"abcabc"`（正确 `false`）会被误判成 `true`。
4. **误读题意**：不是判断 `s` 是否回文——`"abcba"` 是回文且答案为 `true`，但 `"abab"` 不是回文、答案同样为 `true`；子串长度**固定为 2**，不是任意长度的公共子串。
5. **两阶段 vs 一遍扫描**：先建全集合再查镜像的写法天然覆盖自镜像对，不需要特判；一遍扫描版必须特判。这是「判定时机 vs 数据完备性」的经典取舍。
6. **数据范围提示**：$n \le 100$，暴力 $O(n^2)$ 完全可过——赛时先保底提交，复盘时再沉淀 $O(n)$ 写法。
