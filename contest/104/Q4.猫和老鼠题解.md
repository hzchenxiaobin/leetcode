# LeetCode 猫和老鼠 题解

## 1. 题目概述

- **标题 / 题号**：猫和老鼠（#913，hard）
- **链接**：https://leetcode.cn/problems/cat-and-mouse/
- **来源**：LeetCode 第 104 场周赛 Q4
- **难度**：困难
- **标签**：图、拓扑排序、记忆化、极小化极大、数学、动态规划、博弈、零和博弈

**题意**：无向图 `graph`，`graph[a]` 是与 $a$ 相邻的所有节点。老鼠从节点 1 出发、**先手**；猫从节点 2 出发、后手；节点 0 是洞。双方轮流**必须**沿一条边移动；猫**不能**移动到节点 0。游戏在三种情形之一结束时：

- 猫与老鼠在同一个节点（含老鼠自己走进猫的位置）→ **猫胜**；
- 老鼠到达节点 0 → **老鼠胜**；
- 某个「双方位置 + 轮到谁」的状态重复出现 → **平局**。

双方都采用最优策略，返回 1（鼠胜）、2（猫胜）或 0（平局）。

**约束**：

- $3 \le graph.length \le 50$
- $1 \le graph[i].length < graph.length$，$0 \le graph[i][j] < graph.length$，$graph[i][j] \ne i$
- 猫和老鼠在游戏中总是可以移动（每个节点的度数至少为 1，且猫所在节点总有不含 0 的邻边）

## 2. 示例

**示例 1**

```text
输入：graph = [[2,5],[3],[0,4,5],[1,4,5],[2,3],[0,2,3]]
输出：0
解释：这是本题最经典的局面——双方都能无限躲避，谁也无法强迫对方进入自己的胜利条件，故平局。
```

**示例 2**

```text
输入：graph = [[1,3],[0],[3],[0,2]]
输出：1
解释：老鼠在 1，唯一邻点是 0（洞），先手一步即获胜。
```

**示例 3（自造，老鼠被迫送死）**

```text
输入：graph = [[3],[2],[1,3],[0,2]]
输出：2
解释：老鼠在 1，唯一邻点是 2（猫所在位置）；双方轮流必须移动，老鼠只能走进猫的格子，立即猫胜。
```

## 3. 解题思路

### 3.1 暴力思路

把「双方位置 + 轮到谁」当作一个局面，直接 DFS 枚举所有走法：分支因子最大 50，深度可能无限（双方来回走），会陷入死循环；即使加上「访问过就返回」的记忆化，也会把「当前路径上正在计算」与「真正平局」混为一谈，得到错误答案。

也就是说，**这不是一棵树，而是一张有环的图**：普通记忆化 DFS 的「后序返回」在这里不成立，必须用**逆向归纳**（retrograde analysis）从确定的终局倒推。

### 3.2 核心观察：状态空间有限，且胜负可以倒推

![博弈状态：(老鼠位置, 猫位置, 该谁走)](images/wc104_q4_state_graph_concept.svg)

局面可以用三元组 $(m, c, t)$ 完整描述：老鼠在 $m$、猫在 $c$、$t = 0$ 表示轮到老鼠走、$t = 1$ 表示轮到猫走。状态总数是 $2n^2$，$n \le 50$ 时最多 5000 个——**有限**。

终局是显然的：

- $m = 0$：老鼠已经进洞 → 鼠胜；
- $m = c \ne 0$：同格 → 猫胜。

其余状态的结果由后继决定：

- 轮到老鼠走时，老鼠会挑一个**对它最有利**的后继（有鼠胜就选鼠胜）；
- 轮到猫走时，猫会挑一个**对老鼠最不利**的后继（有猫胜就选猫胜）。

于是可以做逆向归纳：先把终局标好，然后不断用规则推出新状态：

1. 若状态 $s$ 的**走子方**能走到一个「自己获胜」的后继，则 $s$ 直接判为该方获胜；
2. 若 $s$ 的**所有**后继都是「对方获胜」，则 $s$ 判为对方获胜；
3. 反复执行 1、2 直到无法推出新状态，**剩下的就是平局**（双方都能永远躲开失败）。

第 2 条需要知道「还有多少个后继没被判定」，因此为每个状态维护一个**剩余度数**，一旦减到 0 就说明「所有走法都输了」。

![反向 BFS：从终局倒推每个状态的结果](images/wc104_q4_retrograde_flow.svg)

### 3.3 算法流程

```text
1. 状态编号 id(m, c, t) = (m * n + c) * 2 + t，共 2n² 个
2. 建反向边 rev[]：对每个状态枚举它的后继 s，把当前状态压入 rev[s]
3. deg[s] = 该状态走子方的合法走法数
4. 终局入队：所有 m = 0 的状态标 1（鼠胜）；所有 m = c ≠ 0 的状态标 2（猫胜）
5. BFS：
6.     s = 出队，r = res[s]
7.     for p in rev[s]:
8.         若 res[p] 已定，跳过
9.         若 r 等于 p 的走子方的胜利编号:  res[p] = r，入队
10.        否则:  deg[p] -= 1；若 deg[p] == 0:  res[p] = 对方胜利编号，入队
11. 返回 res[id(1, 2, 0)]（0 表示平局）
```

### 3.4 示例演算

![示例 2：老鼠一步进洞](images/wc104_q4_walkthrough.svg)

示例 2 的图是 `0-1`、`0-3`、`2-3`。起点状态是 $(m, c, t) = (1, 2, 0)$（老鼠先走）：

- 老鼠在 1，唯一邻点是 0（洞），走到 0 后状态变为 $(0, 2, 1)$；
- $m = 0$ 是鼠胜终局，且走子方是老鼠、胜者也是老鼠 → $(1,2,0)$ 被判鼠胜。

返回 1。示例 3 则是反向情形：老鼠唯一的邻点就是猫所在的 2，走进去立刻变成 $m = c$ → 猫胜，故返回 2。示例 1 的局面里双方都有足够的活动空间，倒推时始终无法把起点判定为任何一方的胜利，最终保留为 0。

## 4. 算法细节

1. **状态编码**：`id = (m * n + c) * 2 + t`，$t \in \{0,1\}$。用一维数组即可，$n = 50$ 时长度 5000。
2. **反向边**：正着枚举每个状态的后继，把「谁指向我」记录下来。这样 BFS 时能从已判定的状态反推前驱，避免反复扫描。
3. **度数只数合法走法**：老鼠走时度数是 `graph[m].size()`；猫走时是 `graph[c]` 中**非 0** 邻点的个数。猫不能进洞，这一步漏掉会导致状态永远无法被判负。
4. **终局优先级**：`m == 0` 判鼠胜、`m == c` 判猫胜。两者不可能同时成立（猫不能在 0），但代码里仍建议先判 $m = 0$。
5. **判定规则的方向**：`res[p] = r` 的前提是「`r` 是 `p` 的走子方的胜利编号」。老鼠走时鼠胜编号 1，猫走时猫胜编号 2；写反会把必胜判成必败。
6. **入队即定案**：每个状态只会被标一次（`res[p] != 0` 时跳过），因此队列总长度不超过 $2n^2$。
7. **起点**：老鼠 1、猫 2、老鼠先手 → `id(1, 2, 0)`；返回 0 表示平局。

## 5. 正确性证明

先给出形式化定义。记状态集合 $\mathcal{S} = \{(m,c,t)\}$，走子方 $\mathrm{mover}(s)$ 在 $t=0$ 时是老鼠、$t=1$ 时是猫；后继关系 $s \to s'$ 表示「走子方按规则走一步」。终局集合

$$\mathcal{T}_M = \{(0,c,t)\}, \qquad \mathcal{T}_C = \{(m,m,t) : m \ne 0\}.$$

对 $k \ge 0$ 递归定义「$k$ 步内可强制获胜」的集合：

- $W_M^0 = \mathcal{T}_M$，$W_C^0 = \mathcal{T}_C$；
- $W_M^{k+1} = W_M^k \cup \{s : \mathrm{mover}(s) = \text{鼠},\ \exists s \to s' \in W_M^k\} \cup \{s : \mathrm{mover}(s) = \text{猫},\ \forall s \to s' \in W_M^k\}$；
- $W_C^{k+1}$ 对称定义。

记 $W_M = \bigcup_k W_M^k$、$W_C = \bigcup_k W_C^k$。

**引理 1（单调性与不相交）**：$W_M^k \subseteq W_M^{k+1}$、$W_C^k \subseteq W_C^{k+1}$，且 $W_M \cap W_C = \emptyset$。

**证明**：单调性由定义中的并集直接得到。

不相交性对 $k$ 归纳。$k = 0$ 时 $\mathcal{T}_M \cap \mathcal{T}_C = \emptyset$，因为 $m = 0$ 与 $m = c \ne 0$ 不能同时成立。设 $s \in W_M^{k} \cap W_C^{k}$。$W_M^k$ 中的状态老鼠有「至多 $k$ 步必胜」的策略，$W_C^k$ 中的状态猫有「至多 $k$ 步必胜」的策略；让双方分别执行各自策略对弈，对局必在有限步内结束，而终局结果不可能同时是「老鼠胜」与「猫胜」，矛盾。故每个 $W_M^k \cap W_C^k = \emptyset$。再由单调性：若 $s \in W_M \cap W_C$，设 $s \in W_M^{j}$ 且 $s \in W_C^{k}$，不妨 $j \le k$，则 $s \in W_M^{k} \cap W_C^{k} = \emptyset$，矛盾。故 $W_M \cap W_C = \emptyset$。∎

**引理 2（标记的正确性）**：算法标记为 1 的状态都属于 $W_M$，标记为 2 的状态都属于 $W_C$。

**证明**：按入队顺序归纳。终局状态显然属于 $W_M^0$ 或 $W_C^0$。设状态 $p$ 因后继 $s$ 被判为 $r$ 而标记：

- 情形 A（`r == 走子方胜利编号`）：$s \in W_r^{k}$，且 $\mathrm{mover}(p)$ 就是 $r$ 方的玩家，它可以主动走到 $s$，于是 $p \in W_r^{k+1}$；
- 情形 B（度数归零）：$p$ 的每个后继都已被标记，且标记 $r$ 与 $p$ 的走子方相反（否则会走情形 A），即所有后继都在 $W_r^{k}$ 中（$k$ 取这些标记的最大步数）。此时无论走子方怎么走都会进入「$r$ 方必胜」的区域，故 $p \in W_r^{k+1}$，而 $r$ 正是 $p$ 走子方的对手，与算法赋值 `res[p] = 3 - moverWin` 一致。

由于每个状态的标记都来自更早已标记的状态，归纳是良基的。∎

**引理 3（未标记即平局）**：算法结束时未被标记的状态 $s$，双方都存在策略使游戏永远停留在未标记状态中。

**证明**：设 $s$ 未标记，分两种情形。

- $\mathrm{mover}(s) = $ 鼠：若 $s$ 有后继被标为鼠胜，则按标记规则 A，$s$ 会被标为鼠胜，矛盾；故 $s$ 的后继要么未标记、要么被标为猫胜。若所有后继都被标为猫胜，则按规则 B（度数减到 0）$s$ 会被标为猫胜，矛盾。因此 $s$ 至少有一个**未标记**的后继，老鼠走到它即可。
- $\mathrm{mover}(s) = $ 猫：对称地，$s$ 的后继要么未标记、要么被标为鼠胜；若全为鼠胜则 $s$ 会被标为鼠胜，矛盾。故猫总能走到一个未标记的后继。

于是双方轮流选择未标记的后继，游戏状态始终在有限的未标记集合内；由抽屉原理，某个「位置 + 走子方」的状态必然重复出现，按规则判为平局。∎

**定理**：`catMouseGame` 的返回值等于最优对弈下的结果。

**证明**：先说明「标记集合 $=$ 可强制获胜集合」。由引理 2，被标记为 $r$ 的状态都属于 $W_r$；反过来，若某状态 $s \in W_M$ 却未被标记，则由引理 3，双方都能把游戏永远保持在未标记状态，这与「老鼠能强制获胜」矛盾，故 $W_M$ 完全包含于「标记为 1」的集合，同理 $W_C$ 完全包含于「标记为 2」的集合。两者合起来即为相等。

于是对起点 $s_0 = (1,2,0)$：若 $s_0 \in W_M$，老鼠有必胜策略，算法标 1，返回 1 正确；若 $s_0 \in W_C$，返回 2 正确；若 $s_0$ 未被标记，由引理 3 双方都能避免失败，故为平局，返回 0 正确。又由引理 1，三类互斥且穷尽，返回值唯一确定。∎

> 💡 **一句话总结**：胜负是「吸引域」，从终局做反向 BFS 一层层扩张；扩张不到的状态，双方都能永远躲开，就是平局。

## 6. 复杂度分析

- **时间**：$O(n^3)$。状态数 $2n^2$；每个状态的后继数不超过 $n$（老鼠走时 $\le n$，猫走时 $\le n$），建反向边与 BFS 各扫一遍所有边，总边数 $O(n^3)$。$n = 50$ 时约 $2.5\times 10^5$ 条边，非常轻。
- **空间**：$O(n^3)$。反向边表存所有边（约 $2.5\times 10^5$ 个整数），`res` 与 `deg` 各 $2n^2$ 个整数；队列最多 $2n^2$ 个元素。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int catMouseGame(vector<vector<int>>& graph) {
        int n = (int)graph.size();
        int S = n * n * 2;
        auto id = [n](int m, int c, int t) { return (m * n + c) * 2 + t; };

        vector<int> res(S, 0), deg(S, 0);
        vector<vector<int>> rev(S);

        // 建反向边与出度
        for (int m = 0; m < n; m++) {
            for (int c = 0; c < n; c++) {
                for (int t = 0; t < 2; t++) {
                    int s = id(m, c, t);
                    if (t == 0) {                       // 老鼠走
                        for (int nm : graph[m]) {
                            rev[id(nm, c, 1)].push_back(s);
                            deg[s]++;
                        }
                    } else {                            // 猫走，不能进洞
                        for (int nc : graph[c]) {
                            if (nc == 0) continue;
                            rev[id(m, nc, 0)].push_back(s);
                            deg[s]++;
                        }
                    }
                }
            }
        }

        queue<int> q;
        for (int m = 0; m < n; m++) {
            for (int c = 0; c < n; c++) {
                for (int t = 0; t < 2; t++) {
                    int s = id(m, c, t);
                    if (m == 0) { res[s] = 1; q.push(s); }          // 老鼠进洞
                    else if (m == c) { res[s] = 2; q.push(s); }     // 猫抓到老鼠
                }
            }
        }

        while (!q.empty()) {
            int s = q.front();
            q.pop();
            int r = res[s];
            for (int p : rev[s]) {
                if (res[p] != 0) continue;
                int moverWin = (p % 2 == 0) ? 1 : 2;   // 老鼠走→1，猫走→2
                if (r == moverWin) {
                    res[p] = r;                        // 走子方可以走进胜利状态
                    q.push(p);
                } else if (--deg[p] == 0) {
                    res[p] = 3 - moverWin;             // 所有走法都输
                    q.push(p);
                }
            }
        }
        return res[id(1, 2, 0)];
    }
};
```

### Python

```python
from collections import deque


class Solution:
    def catMouseGame(self, graph: list[list[int]]) -> int:
        n = len(graph)

        def sid(m: int, c: int, t: int) -> int:
            return (m * n + c) * 2 + t

        total = n * n * 2
        res = [0] * total
        deg = [0] * total
        rev = [[] for _ in range(total)]

        for m in range(n):
            for c in range(n):
                for t in range(2):
                    s = sid(m, c, t)
                    if t == 0:
                        for nm in graph[m]:
                            rev[sid(nm, c, 1)].append(s)
                            deg[s] += 1
                    else:
                        for nc in graph[c]:
                            if nc == 0:
                                continue
                            rev[sid(m, nc, 0)].append(s)
                            deg[s] += 1

        q = deque()
        for m in range(n):
            for c in range(n):
                for t in range(2):
                    s = sid(m, c, t)
                    if m == 0:
                        res[s] = 1
                        q.append(s)
                    elif m == c:
                        res[s] = 2
                        q.append(s)

        while q:
            s = q.popleft()
            r = res[s]
            for p in rev[s]:
                if res[p] != 0:
                    continue
                mover_win = 1 if p % 2 == 0 else 2
                if r == mover_win:
                    res[p] = r
                    q.append(p)
                else:
                    deg[p] -= 1
                    if deg[p] == 0:
                        res[p] = 3 - mover_win
                        q.append(p)

        return res[sid(1, 2, 0)]
```

## 8. 边界情况与易错点

1. **猫不能进 0**：建图时猫的走法要排除邻点 0，同时 `deg` 也不能把它算进去；否则终局「鼠在洞」的判定会被绕过。
2. **状态编码漏掉 `t`**：状态必须是「位置 + 走子方」三元组，只编码 $(m,c)$ 会把两个不同的局面混成一个。
3. **终局初始化顺序**：`m == 0` 与 `m == c` 互斥（猫不能在 0），但代码里建议先判 $m=0$；同时注意 $m = c = 0$ 不会出现。
4. **度数归零的语义**：只有「所有后继都是对方胜」才判负，不能把「有一个后继未知」当成输。
5. **`moverWin` 的编号**：$t = 0$（鼠走）对应鼠胜 1，$t = 1$（猫走）对应猫胜 2；写反会把胜负颠倒。
6. **平局返回 0**：`res` 初值 0 同时表示「未定」与「平局」，这是本题的巧处——BFS 结束后仍未定的就是平局，不需要额外标记。
7. **不要用记忆化 DFS**：有环图上「正在访问」不等于「平局」，必须用逆向归纳。
8. **$n = 3$ 的最小图**：如 `[[1,2],[0,2],[0,1]]`，老鼠一步进洞，答案是 1，可用来自测。
