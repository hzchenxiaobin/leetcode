# LeetCode 最小体力消耗路径 题解

## 1. 题目概述

- **标题 / 题号**：最小体力消耗路径（#1631，medium）
- **链接**：https://leetcode.cn/problems/path-with-minimum-effort/
- **来源**：LeetCode 第 212 场周赛 Q3
- **难度**：中等
- **标签**：Dijkstra 算法、堆（优先队列）、二分查找、广度优先搜索、并查集

**题意**：给定 $m \times n$ 的矩阵 `heights`，从左上角 $(0,0)$ 出发，每步可向上、下、左、右移动一格，走到右下角 $(m-1,n-1)$。一条路径的**体力消耗**定义为路径上相邻两格**高度差绝对值的最大值**。求所有路径中体力消耗的最小值。

**约束**：

- $m = \text{heights}.\text{length}$，$n = \text{heights}[i].\text{length}$
- $1 \le m, n \le 100$
- $1 \le \text{heights}[i][j] \le 10^6$

## 2. 示例

**示例 1**

```text
输入：heights = [[1,2,2],[3,8,2],[5,3,5]]
输出：2
解释：路径 [1,3,5,3,5]（先下、再下、再右、再右）的相邻差值依次为
     2,2,2,2，最大值 2；
     而路径 [1,2,2,2,5] 的最大差值为 3，更差。
```

**示例 2**

```text
输入：heights = [[1,2,3],[3,8,4],[5,3,5]]
输出：1
解释：路径 [1,2,3,4,5] 沿上边和右边走，相邻差值最大为 1。
```

**示例 3**

```text
输入：heights = [[1,2,1,1,1],[1,2,1,2,1],[1,2,1,2,1],[1,2,1,2,1],[1,1,1,2,1]]
输出：0
解释：存在一条全部由高度 1 组成的路径，最大差值为 0。
```

## 3. 解题思路

### 3.1 暴力思路及其两个"邻居"都失效

两条直觉路线都不可行：

1. **枚举所有路径**：网格中从起点到终点的路径数是指数级的（每格至多 4 个方向），$m,n \le 100$ 时远超时限。
2. **套普通 Dijkstra（边权求和）**：路径的体力消耗不是边权**之和**而是**最大值**。"总和最小"的路径不一定是"最大值最小"的路径——示例 1 就是现成的反例：沿上、右方向的路径 A 高度 $1\to2\to2\to2\to5$，边权和 $1+0+0+3=4$，小于左侧路径 B 的 $2+2+2+2=8$；但 A 的最大边权为 3，反而大于 B 的 2。**按求和跑 Dijkstra 会选错路径。**

### 3.2 核心观察：瓶颈最短路（max 松弛的 Dijkstra 变体）

把每个格子看成节点，四相邻格之间连无向边，边权 $w(u,v) = |h[u] - h[v]| \ge 0$。问题即：找一条 $(0,0) \to (m-1,n-1)$ 的路径，**最小化路径上的最大边权**。这是经典的**瓶颈最短路**（minimax path）问题。

关键观察：Dijkstra 的贪心正确性**只用到两条性质**，与"代价是否可加"无关：

- **代价单调不减**：路径每延长一步，代价不减小。max 松弛满足 $\max(\text{dist}[u], w) \ge \text{dist}[u]$；
- **边权非负**：$|h[u]-h[v]| \ge 0$。

因此把松弛算子从求和换成取最大：

$$\text{dist}[v] \leftarrow \min\bigl(\text{dist}[v],\ \max(\text{dist}[u],\ w(u,v))\bigr)$$

其余（小根堆、每次弹出全局最小、弹出即确定）与标准 Dijkstra 完全一致，算法依然正确（严格证明见 §5）。

![瓶颈最短路核心概念：代价是最大边权，松弛用 max](images/1631_bottleneck_dijkstra_concept.svg)

> 💡 **识别信号**：题目求「最小的最大值」，且图上任意相邻格可自由移动 → 想到「瓶颈最短路 / minimax path」一题三解：max-Dijkstra、二分答案 + BFS、边权排序 + 并查集，三者比较见 §4。

### 3.3 算法流程

```text
1. dist[x][y] ← +∞；dist[0][0] ← 0；小根堆放入 (0, 0, 0)
2. 重复直到堆空：
   a. 弹出键值最小的 (d, x, y)
   b. 若 d > dist[x][y]：过期条目，跳过
   c. 若 (x,y) 为终点：d 即答案，返回
   d. 对四个邻居 (nx,ny)：
        nd = max(d, |h[x][y] − h[nx][ny]|)
        若 nd < dist[nx][ny]：更新并 push (nd, nx, ny)
```

### 3.4 示例演算

以示例 1 的 `heights = [[1,2,2],[3,8,2],[5,3,5]]` 为例，max-Dijkstra 的弹出序列与关键松弛如下，最终 $\text{dist}$ 矩阵为 $\begin{bmatrix}0&1&1\\2&5&1\\2&2&2\end{bmatrix}$：

- 弹出 $(0,0)$，$d=0$：松弛 $(0,1)=1$、$(1,0)=2$；
- 弹出 $(0,1)$，$d=1$：松弛 $(0,2)=1$、$(1,1)=6$；
- 弹出 $(0,2)$，$d=1$：松弛 $(1,2)=1$；
- 弹出 $(1,2)$，$d=1$：松弛 $(2,2)=4$（**暂时值**）；
- 弹出 $(1,0)$，$d=2$：松弛 $(2,0)=2$，并把 $(1,1)$ 从 6 改进为 5；
- 弹出 $(2,0)$，$d=2$：松弛 $(2,1)=2$；
- 弹出 $(2,1)$，$d=2$：$\max(2,|3-5|)=2<4$，把 $(2,2)$ **从 4 改写为 2**；
- 弹出 $(2,2)$，$d=2$：终点，返回答案 $2$。

![示例 1 的 max-Dijkstra 演算：弹出顺序与关键松弛](images/1631_dijkstra_walkthrough.svg)

> 💡 $(2,2)$ 先被暂时记为 4，之后经 $(2,1)$ 改写为 2——这说明 max-Dijkstra 中一个点的 dist 在**被弹出之前**仍可能被改进，只有弹出（确定）之后才是最终值。这也是"过期条目检查"必须保留的原因。

## 4. 算法细节

### 4.1 主解：max-Dijkstra 的实现要点

1. **堆中存三元组** $(d, x, y)$，以 $d$ 为键的小根堆；
2. **允许堆中出现同一节点的多个条目**（lazy deletion）：弹出时若 $d > \text{dist}[x][y]$ 则为过期条目，直接跳过，无需 decrease-key；
3. **终点判定放在弹出时**：第一次弹出 $(m-1,n-1)$ 时其键值已是最终瓶颈距离，立即返回。若在松弛（入堆）时就返回，可能拿到未改进的暂时值（如演算中 $(2,2)$ 的 4）；
4. **dist 初值**取 $+\infty$（如 `INT_MAX`）。真实键值不超过 $10^6-1$，`int` 不会溢出。

### 4.2 另解一：二分答案 + BFS 判连通

定义 $\text{reachable}(t)$ = 只允许走高度差 $\le t$ 的边时，$(0,0)$ 能否到达 $(m-1,n-1)$。阈值 $t$ 越大可走的边越多，$\text{reachable}$ 关于 $t$ **单调不减**，存在分界点 $t^*$——在 $[0,\ \max h - \min h]$ 上二分 $t$，每次用一次 $O(mn)$ 的 BFS 判连通即可。时间 $O(mn\log D)$，其中 $D \le 10^6$。

### 4.3 另解二：边权排序 + 并查集

把全部约 $2mn$ 条边按权值升序排序，依次加入并查集；每加一条边就查询 $(0,0)$ 与 $(m-1,n-1)$ 是否连通，**首次连通瞬间当前边的权值即为答案**。因为按升序加边时，任何时刻块内最大边权 $\le$ 当前权值；若阈值小于该权值，最后这条边不存在，起终点必不连通。时间 $O(mn\log(mn))$，排序主导。

![另解：按边权升序并查集加边，起终点首次连通即答案](images/1631_unionfind_timeline.svg)

### 4.4 三种解法对比

| 解法 | 核心思想 | 时间复杂度 | 比赛中的评价 |
|------|----------|-----------|--------------|
| max-Dijkstra（本题主解） | 松弛算子 + 换 max，堆取最小 | $O(mn\log(mn))$ | 一遍循环写完，边界最少，不易写错 |
| 二分答案 + BFS | 阈值单调 → 二分最小可行阈值 | $O(mn\log D)$ | 思路最模板化，check 换 DFS 亦可 |
| 排序 + 并查集 | 升序加边，首次连通即答案 | $O(mn\log(mn))$ | 与 Kruskal 同源，代码量略大 |

三者复杂度同级，$mn \le 10^4$ 时均为毫秒级。

## 5. 正确性证明

记 $s=(0,0)$，$t=(m-1,n-1)$。对一条路径 $P$，定义其代价 $\text{cost}(P)$ 为路径上最大边权（单格路径代价为 $0$）。记瓶颈距离 $\delta(v) = \min_{P:\ s\to v} \text{cost}(P)$，即算法要计算的量。

**引理 1（代价单调）**：若路径 $P'$ 是路径 $P$ 的前缀（均从 $s$ 出发），则 $\text{cost}(P') \le \text{cost}(P)$。

**证明**：$P'$ 的边集是 $P$ 边集的子集，最大值不超过全集的最大值。特别地，对任意松弛有 $\max(\text{dist}[u],\, w(u,v)) \ge \text{dist}[u]$，即键值沿传播不减小——这正对应普通 Dijkstra 中"边权非负"的作用。∎

**引理 2（弹出即最优）**：算法每次从堆中弹出一个尚未确定的节点 $u$，设其键值为 $d$，则 $d = \delta(u)$。

**证明**（对弹出次数归纳，归纳假设：已确定节点的 dist 均等于其 $\delta$）：反设弹出 $u$ 时 $\delta(u) < d$。取一条 $s \to u$ 的瓶颈最优路径 $P$（$\text{cost}(P) = \delta(u)$）。沿 $P$ 从 $s$ 走，$s$ 已确定、$u$ 尚未确定，故 $P$ 上存在第一条"未确定"的节点 $y$，其前驱 $x$ 已确定。由归纳假设 $\text{dist}[x] = \delta(x)$；$x$ 被确定时松弛过边 $(x,y)$，故

$$\text{dist}[y] \le \max(\text{dist}[x],\ w(x,y)) = \max(\delta(x),\ w(x,y)).$$

由引理 1，$P$ 的 $s \to x$ 前缀是一条到达 $x$ 的路径且代价 $\le \text{cost}(P)$，故 $\delta(x) \le \text{cost}(P) = \delta(u)$；又 $(x,y)$ 是 $P$ 上的边，$w(x,y) \le \text{cost}(P) = \delta(u)$。于是 $\text{dist}[y] \le \delta(u) < d$。而 $y$ 未确定，其最小键条目（键值等于当前 $\text{dist}[y]$）仍在堆中存活，键 $\le \delta(u) < d$，与 $u$ 是当前堆中键值最小的未确定节点矛盾。∎

**定理**：算法返回 $\delta(t)$，即从 $(0,0)$ 到 $(m-1,n-1)$ 的最小体力消耗。

**证明**：堆中条目有限，每次弹出要么跳过过期条目要么确定一个节点，算法必终止。$t$ 第一次被弹出时，由引理 2，其键值 $d = \delta(t)$，算法返回 $d$。而 $\delta(t)$ 的定义恰是所有 $s \to t$ 路径上"相邻格高度差绝对值的最大值"的最小值，即最小体力消耗。∎

## 6. 复杂度分析

- **时间复杂度**：$O(mn\log(mn))$。网格约有 $E \approx 2mn$ 条无向边；每条边至多引起一次成功松弛从而入堆一个新条目，堆中条目 $O(E)$ 个，每次堆操作 $O(\log E)$。$m,n\le100$ 时约 $2\times10^4$ 个条目，毫秒级。
- **空间复杂度**：$O(mn)$。`dist` 矩阵与堆中至多 $O(mn)$ 个条目；无需单独的 vis 数组（过期检查即可）。

## 7. 参考代码

### C++

```cpp
class Solution {
    static constexpr int dx[4] = {1, -1, 0, 0};
    static constexpr int dy[4] = {0, 0, 1, -1};

  public:
    int minimumEffortPath(vector<vector<int>>& heights) {
        int m = heights.size(), n = heights[0].size();
        vector<vector<int>> dist(m, vector<int>(n, INT_MAX));
        priority_queue<tuple<int, int, int>, vector<tuple<int, int, int>>, greater<>> pq;
        dist[0][0] = 0;
        pq.emplace(0, 0, 0);
        while (!pq.empty()) {
            auto [d, x, y] = pq.top();
            pq.pop();
            if (d > dist[x][y]) continue;             // 过期条目
            if (x == m - 1 && y == n - 1) return d;   // 弹出终点即答案
            for (int k = 0; k < 4; ++k) {
                int nx = x + dx[k], ny = y + dy[k];
                if (nx < 0 || nx >= m || ny < 0 || ny >= n) continue;
                int nd = max(d, abs(heights[x][y] - heights[nx][ny]));
                if (nd < dist[nx][ny]) {
                    dist[nx][ny] = nd;
                    pq.emplace(nd, nx, ny);
                }
            }
        }
        return dist[m - 1][n - 1];
    }
};
```

### Python

```python
from heapq import heappush, heappop

class Solution:
    def minimumEffortPath(self, heights: List[List[int]]) -> int:
        m, n = len(heights), len(heights[0])
        INF = float('inf')
        dist = [[INF] * n for _ in range(m)]
        dist[0][0] = 0
        pq = [(0, 0, 0)]
        while pq:
            d, x, y = heappop(pq)
            if d > dist[x][y]:
                continue
            if x == m - 1 and y == n - 1:
                return d
            for nx, ny in ((x + 1, y), (x - 1, y), (x, y + 1), (x, y - 1)):
                if 0 <= nx < m and 0 <= ny < n:
                    nd = max(d, abs(heights[x][y] - heights[nx][ny]))
                    if nd < dist[nx][ny]:
                        dist[nx][ny] = nd
                        heappush(pq, (nd, nx, ny))
        return dist[m - 1][n - 1]
```

## 8. 边界情况与易错点

1. **$1\times1$ 网格**：起点即终点，体力为 0。算法中 $(0,0)$ 第一次弹出即命中终点判定返回 0；若把终点判定只写在松弛处，单格网格可能漏判。
2. **全等高网格**（示例 3）：所有边权为 0，答案 0。起点 dist 为 0，其余格全部经 $\max(0,0)=0$ 松弛，自然正确。
3. **不要套求和 Dijkstra**：路径代价是"最大边权"而非"边权和"。示例 1 中求和更小的路径 A（和 4）的最大边权 3 反而大于路径 B（和 8）的 2。**这是本题最常见的 WA 原因。**
4. **终点判定必须在弹出时**：入堆时的值是暂时值，可能稍后被改小（演算中 $(2,2)$ 从 4 改到 2）。弹出时的键值才等于最终瓶颈距离。
5. **过期条目必须跳过**：lazy deletion 写法下堆中同一节点可有多个条目，弹出时须检查 $d > \text{dist}[x][y]$ 跳过，否则会破坏"弹出即最优"的归纳前提（引理 2 中 $u$ 必须是未确定节点）。
6. **堆元素顺序**：C++ 用 `tuple<int,int,int>` 配 `greater<>`，键值 $d$ 必须放元组首位；误把坐标放首位会按坐标排序，结果全错。
7. **单行 / 单列网格**：路径唯一，答案是沿途最大高度差；无需特判，算法自然处理。
8. **另解的细节**：二分解法下界取 0（全等高时答案为 0）、上界取 $\max h - \min h$ 比取 $10^6$ 少几次二分；并查集解法中格子编号 $x\cdot n + y$，别把 $m,n$ 写反。
