# LeetCode 矩阵转换后的排名 题解

## 1. 题目概述

- **标题 / 题号**：矩阵转换后的排名（#1632，hard）
- **链接**：https://leetcode.cn/problems/rank-transform-of-a-matrix/
- **来源**：LeetCode 第 212 场周赛 Q4
- **难度**：困难
- **标签**：并查集、贪心、排序、矩阵、拓扑排序

**题意**：给定 $m \times n$ 的整数矩阵 `matrix`，返回同型矩阵 `answer`，其中 `answer[row][col]` 是 `matrix[row][col]` 的**排名**。排名是从 $1$ 开始的整数，须满足：若两个元素 $p$、$q$ 在**同一行或同一列**，则

- $p < q \Rightarrow \text{rank}(p) < \text{rank}(q)$；
- $p = q \Rightarrow \text{rank}(p) = \text{rank}(q)$；
- $p > q \Rightarrow \text{rank}(p) > \text{rank}(q)$。

在满足上述约束的前提下，每个元素的排名都要**尽可能小**。题目保证答案唯一。

**约束**：

- $1 \le m, n \le 500$
- $-10^9 \le \text{matrix}[i][j] \le 10^9$

> 💡 读题第一眼就要圈住「**同一行或同一列**」：既不同行也不同列的两个元素之间**没有任何约束**。因此同一个值完全可以拥有不同的排名——这是本题最反直觉、也最容易被漏掉的一句话。

## 2. 示例

**示例 1**

```text
输入：matrix = [[1,2],[3,4]]
输出：[[1,2],
       [2,3]]
解释：每行每列严格递增，按相对大小直接赋秩。
```

**示例 2**

```text
输入：matrix = [[7,7],[7,7]]
输出：[[1,1],
       [1,1]]
解释：四个 7 通过共享的行、列「传染」成一个等价类——(0,0) 与 (0,1) 同行，
     (0,0) 与 (1,0) 同列，于是四个格子必须同秩；又没有更小的元素，全为 1。
```

**示例 3**

```text
输入：matrix = [[20,-21,14],[-19,4,19],[22,-47,24],[-19,4,19]]
输出：[[4,2,3],
       [1,3,4],
       [5,1,6],
       [1,3,4]]
解释：注意两个 -19 与两个 4、两个 19 各自同列绑定而同秩；
     而 -19 与 14 一个秩为 1、一个秩为 3，互不影响。
```

**示例 4（自制，检验理解）**

```text
输入：matrix = [[5,4,0],[0,0,5],[1,0,2]]
输出：[[3,2,1],
       [1,1,4],
       [2,1,3]]
解释：两个 5 位于 (0,0) 与 (1,2)，不同行不同列、互不连通：
     (0,0) 的下界来自第 0 行/第 0 列的历史秩 → 秩 3；
     (1,2) 的下界来自第 2 列的秩 3（那个 2）→ 秩 4。
     等值 ≠ 等秩，只有「连通」才强制同秩。
```

## 3. 解题思路

### 3.1 暴力思路：逐格贪心为什么翻车

最直觉的做法：把所有格子按值排序，逐格赋秩，每次取「$1 + $ 同行同列已赋秩的最大值」。用示例 2 一测就崩：

- 处理 $(0,0)$：无历史，秩 $1$，并更新第 0 行、第 0 列的最大秩为 $1$；
- 处理 $(0,1)$：同行已有 $7$（秩 $1$），得秩 $2$——**错**，正确答案是 $1$。

失败根因有二：

1. **同秩约束会「传染」**：$(0,0)$ 与 $(0,1)$ 同行必须同秩，$(0,1)$ 又与 $(1,1)$ 同列必须同秩……等值格子经「同行 / 同列」交替接力，可以把相距很远的格子绑成一个**等价类**。逐格赋值时，处理 $(0,1)$ 根本不知道 $(1,1)$ 的存在，无法确定它属于哪个类。
2. **秩的正确值只对「整类」有意义**：类内所有格子必须共用一个秩，而这个秩取决于类中**所有**格子触达的行、列的历史下界。逐格贪心把类拆散了，怎么补丁都补不严。

> 💡 转换视角：不要「逐格赋秩」，而要**按值升序成批处理**——每个值内部的等值格子先打包成「同秩连通分量」，再以分量为单位一次性赋秩。

### 3.2 核心观察：按值升序 + 行/列二部图并查集

三个层层递进的观察：

1. **按值升序处理**：秩反映相对大小，值小的先定秩，才能为大值提供「下界」。处理值 $v$ 时，所有 $< v$ 的格子已赋秩，它们施加的约束全部记录在 $\text{rowMax}[i]$（第 $i$ 行已出现的最大秩）与 $\text{colMax}[j]$（第 $j$ 列已出现的最大秩）中。
2. **等值同秩传染**：值同为 $v$ 且同行/同列的格子必须同秩，且约束经传递闭包扩散——$(r_1,c_1)$ 与 $(r_1,c_2)$ 同行绑定，$(r_1,c_2)$ 又与 $(r_2,c_2)$ 同列绑定，于是 $(r_1,c_1)$ 与 $(r_2,c_2)$ 也被绑定为同秩。等价类 $=$ 传染链的连通块。
3. **行列二部图建模**：把每个**行号** $i$ 与每个**列号** $m{+}j$ 都作为并查集节点（共 $m{+}n$ 个），值同为 $v$ 的格子 $(i,j)$ 就是一条连接「行 $i$」与「列 $m{+}j$」的**边**。组内对每个格子执行 `union(i, m+j)`，凡被等值格子串起来的行、列都落入同一连通分量——**一个分量，一个秩**。

于是分量的秩取「满足所有同行/同列历史约束的最小值」：

$$\text{rank}(C) \;=\; 1 + \max_{(i,j)\in C}\ \max\bigl(\text{rowMax}[i],\ \text{colMax}[j]\bigr)$$

「$+1$」来自约束的**严格性**：必须严格大于同行同列中所有更小元素的秩。

![核心观察：等值格子经行/列传染成一个连通分量，同分量同秩；同值不同分量可不同秩](images/rank_transform_union_concept.svg)

> ⚠️ **同值 $\ne$ 同秩**：不同分量之间没有任何共享的行/列（见 §5 引理 2），互不约束，各取各的下界。自制示例 4 里两个 5 分别拿到秩 3 与 4。反过来，**同分量一定同秩**——这是任何合法赋值都躲不开的硬约束。

### 3.3 算法流程

```text
1. 遍历矩阵，用 map 收集「值 v → 格子列表」（遍历自动按值升序）
2. 对每个值 v 的格子组（升序处理）：
   a. 重置：组内每个 (i,j) 令 parent[i] = i、parent[m+j] = m+j
   b. 合并：每个 (i,j) 执行 union(行 i, 列 m+j)
   c. 分组：按 find(行 i) 的根把格子归入各连通分量
   d. 定秩：每分量 rank ← 1 + max(rowMax[i], colMax[j])（对分量内所有格子取 max）
   e. 落笔：分量内所有格子 ans[i][j] ← rank，
            并更新 rowMax[i] = colMax[j] = rank
3. 全部值组处理完，返回 ans
```

![算法流程：按值升序，每组「重置 → union → 分组定秩 → 更新」循环](images/rank_transform_group_flow.svg)

## 4. 算法细节

1. **节点编号**：行 $0 \sim m{-}1$，列 $m \sim m{+}n{-}1$，共 $m{+}n$ 个节点。把「行」「列」抽象成节点后，每个格子只需一次 `union`，无需显式建图。
2. **每组重置，绝不跨组复用**：同秩约束**只在等值格子间**成立。若全程共用并查集，值 $2$ 连起来的行、列会把值 $3$ 的格子错误吸入同一分量，被赋成与值 $2$ **相同**的秩，直接违反严格递增。重置只恢复组内触达的行/列节点，代价 $O(\text{组内格子数})$。
3. **职责分离**：并查集只负责**组内**的「同秩传染」；**组间**的大小约束全部由 $\text{rowMax}/\text{colMax}$ 承载。因此重置并查集不丢失任何信息。
4. **分量同时落笔**：同一值的不同分量触达的行/列**两两不相交**（§5 引理 2），一个分量更新 $\text{rowMax}/\text{colMax}$ 不会污染另一个分量的下界。所以分量之间处理顺序无关，甚至可以「同时」赋秩。反之，若在同一分量内**逐格**更新 `rowMax` 再计算下一格，同组的格子会被自己的更新污染——这就退化成了 §3.1 的错误做法。
5. **另解：拓扑排序 / 最长链视角**：把每个连通分量缩成超源点；每行（每列）把其中出现过的分量按值排序，相邻分量间连「小值分量 → 大值分量」的边。分量按值升序天然是拓扑序，某分量的秩恰等于**以它为终点的最长链节点数**，沿拓扑序递推 $\text{rank}(c) = \max(\text{rank}(pred)+1,\ 1)$ 即可。

| 解法 | 核心思想 | 复杂度 | 比赛中的评价 |
|------|----------|--------|--------------|
| 按值分组 + 并查集（主解） | 行列作节点，分量共享秩，下界 $1+\max$ | $O(mn\log mn)$ | 思路一旦想到，代码直白不易错 |
| 拓扑排序 + 最长链 | 分量缩点后求 DAG 最长路 | $O(mn\log mn)$ | 建边较繁琐，赛时更容易写挂 |
| 逐格贪心（无分组） | 见 §3.1 | — | **错误做法**，示例 2 即反例 |

## 5. 正确性证明

对固定矩阵，称映射 $R$（格子 → 正整数）为**合法赋值**，若对任意同行或同列的格子对 $x,y$：$\text{val}(x) < \text{val}(y) \Rightarrow R(x) < R(y)$，且 $\text{val}(x) = \text{val}(y) \Rightarrow R(x) = R(y)$（「$>$」情形是前者的对称）。固定值 $v$，记 $G_v$ 为以 $m$ 个行节点、$n$ 个列节点为点集、以所有值等于 $v$ 的格子 $(i,j)$（作为边 $i$—$m{+}j$）为边集的二部图。

**引理 1（同秩传染）**：值同为 $v$ 的两格在 $G_v$ 中连通，当且仅当存在格子序列 $x_0,\dots,x_k$（值均为 $v$）使得相邻两格同行或同列；且**任何**合法赋值中，$G_v$ 同一分量的所有格子秩相等。

**证明**：连通即存在首尾相接的边链，相邻两边共享节点 ⟺ 对应格子同行或同列。设分量内两格由链 $x_0,\dots,x_k$ 相连：相邻两格 $x_t,x_{t+1}$ 同行或同列且值相等，由合法性定义得 $R(x_t) = R(x_{t+1})$，沿链传递得两端相等。∎

**引理 2（分量隔离）**：值 $v$ 的两个不同分量触达的行集合互不相交，列集合亦然。

**证明**：反设分量 $C_1 \ne C_2$ 都触达行 $i$，则两者各含一条关联行节点 $i$ 的边，这两条边经由节点 $i$ 在 $G_v$ 中连通，与 $C_1 \ne C_2$ 矛盾。列同理。∎

**推论**：同值不同分量之间无任何直接约束；且同值组内某分量更新 $\text{rowMax}/\text{colMax}$ 不会改变其他分量的下界（各自只读自己触达的行/列，而这些行/列互不相交）。

**引理 3（贪心赋值合法）**：按值升序逐组处理，每个分量 $C$ 赋秩 $r(C) = 1 + \max_{(i,j)\in C}\max(\text{rowMax}[i],\ \text{colMax}[j])$，所得 $R^\*$ 是合法赋值。

**证明**：对已处理的值组数归纳。设处理值 $v$ 时，所有更小值的赋值已合法。考察分量 $C$ 中的格子 $(i,j)$ 与任一同行格子 $(x,y)$（$(x,y)$ 同列同理）：

- 若 $\text{val}(x,y) < v$：其秩 $\le \text{rowMax}[i]$，而 $r(C) \ge 1 + \text{rowMax}[i]$，故 $r(C) > R^\*(x,y)$；
- 若 $\text{val}(x,y) = v$：同行等值 ⟹ 与 $(i,j)$ 在 $G_v$ 中连通（共享行节点 $i$）⟹ 同属 $C$ ⟹ 同秩；
- 若 $\text{val}(x,y) > v$：尚未赋秩，等其所在值组处理时反向验证（此时 $(i,j)$ 已计入该组的下界）。

故加入组 $v$ 后赋值仍合法；又由引理 2 的推论，同组各分量同时赋秩互不冲突。归纳完成。∎

**定理（逐点最优）**：对任意合法赋值 $R$ 与任意格子 $x$，有 $R^\*(x) \le R(x)$。从而 $R^\*$ 是逐点最小的合法赋值；结合题目「答案唯一」的保证，$R^\*$ 即为所求。

**证明**：对值组升序强归纳。首组（最小值）：所有行/列无历史秩，每个分量取秩 $1$，已是最小正整数。设所有 $< v$ 的组已证 $R^\* \le R$，考察组 $v$ 的分量 $C$：由引理 1，$R$ 中 $C$ 的所有格子同秩，记为 $\rho_C$。对 $C$ 触达的任意行 $i$ 与该行中更小值的格子 $y$：归纳假设 $R(y) \ge R^\*(y)$，而 $R$ 合法要求 $\rho_C > R(y) \ge R^\*(y)$。对 $C$ 触达的所有行列取最大（由引理 2，$\text{rowMax}^\*/\text{colMax}^\*$ 只含更小值的秩，组内互不污染）：

$$\rho_C \;\ge\; 1 + \max_{(i,j)\in C}\max\bigl(\text{rowMax}^\*[i],\ \text{colMax}^\*[j]\bigr) \;=\; r(C) \;=\; R^\*\big|_C.$$

对组内每个分量成立，归纳完成。∎

> 💡 一句话：**合法性与最优性都不需要全局视角**——合法性靠下界公式严格盖住同行同列的历史秩，最优性靠逐点归纳 + 分量隔离（引理 2）。若两个合法赋值都逐点最优，它们逐点相等，这就是「答案唯一」的算法侧注脚。

## 6. 复杂度分析

- **时间复杂度**：$O\bigl(mn\log(mn)\bigr)$。收集格子用 `map`（或排序）为 $O(mn\log(mn))$；每个格子只做常数次并查集操作，带路径压缩近乎 $O\bigl(\alpha(m{+}n)\bigr)$；组内重置、分组、赋值都是每格 $O(1)$ 均摊。$m,n \le 500$ 时 $mn \le 2.5\times10^5$，$\log(mn) \approx 18$，毫秒级通过。
- **空间复杂度**：额外 $O(m+n)$ 的并查集与 $\text{rowMax}/\text{colMax}$，外加 $O(mn)$ 的值分组容器与答案矩阵（不计输出则 $O(m+n)$ 之外仅 $O(mn)$ 的桶/映射开销）。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    vector<vector<int>> matrixRankTransform(vector<vector<int>>& matrix) {
        int m = matrix.size(), n = matrix[0].size();
        vector<int> parent(m + n), rowMax(m, 0), colMax(n, 0);
        iota(parent.begin(), parent.end(), 0);
        function<int(int)> find = [&](int x) {
            return parent[x] == x ? x : parent[x] = find(parent[x]);
        };

        map<int, vector<pair<int, int>>> byValue;   // 值 → 格子列表，升序遍历
        for (int i = 0; i < m; ++i)
            for (int j = 0; j < n; ++j)
                byValue[matrix[i][j]].emplace_back(i, j);

        vector<vector<int>> ans(m, vector<int>(n));
        for (auto& [v, cells] : byValue) {
            for (auto& [i, j] : cells) {            // 组内重置：同秩约束只在等值格子间成立
                parent[i] = i;
                parent[m + j] = m + j;
            }
            for (auto& [i, j] : cells) {            // 行节点 i ↔ 列节点 m+j 连边
                int fi = find(i), fj = find(m + j);
                if (fi != fj) parent[fi] = fj;
            }
            unordered_map<int, vector<pair<int, int>>> comps;
            for (auto& [i, j] : cells)              // 按根把格子归入连通分量
                comps[find(i)].emplace_back(i, j);
            for (auto& [root, mem] : comps) {
                int rank = 1;
                for (auto& [i, j] : mem)            // 分量级下界，先算后写
                    rank = max(rank, 1 + max(rowMax[i], colMax[j]));
                for (auto& [i, j] : mem) {
                    ans[i][j] = rank;
                    rowMax[i] = colMax[j] = rank;
                }
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def matrixRankTransform(self, matrix: List[List[int]]) -> List[List[int]]:
        m, n = len(matrix), len(matrix[0])
        parent = list(range(m + n))

        def find(x):
            while parent[x] != x:
                parent[x] = parent[parent[x]]      # 路径减半
                x = parent[x]
            return x

        by_value = defaultdict(list)
        for i, row in enumerate(matrix):
            for j, v in enumerate(row):
                by_value[v].append((i, j))

        row_max = [0] * m
        col_max = [0] * n
        ans = [[0] * n for _ in range(m)]

        for v in sorted(by_value):
            cells = by_value[v]
            for i, j in cells:                    # 组内重置
                parent[i] = i
                parent[m + j] = m + j
            for i, j in cells:                    # 行 i ↔ 列 m+j 连边
                fi, fj = find(i), find(m + j)
                if fi != fj:
                    parent[fi] = fj
            comps = defaultdict(list)
            for i, j in cells:                    # 按根分组
                comps[find(i)].append((i, j))
            for mem in comps.values():
                rank = 1 + max(max(row_max[i], col_max[j]) for i, j in mem)
                for i, j in mem:                  # 分量统一落笔，再更新行列下界
                    ans[i][j] = rank
                    row_max[i] = rank
                    col_max[j] = rank
        return ans
```

## 8. 边界情况与易错点

1. **全矩阵同一值**（示例 2）：整个矩阵一个分量，答案全为 $1$。逐格贪心在此必挂，可作对拍用例。
2. **等值但不同分量**：秩可以不同（自制示例 4 的两个 5）。千万不能「同值全局同秩」——下界由各自触达的行/列决定。
3. **并查集绝不跨值组复用**：不同值之间是严格大小关系，共用 DSU 会把不同值错绑成同秩。每组开头只重置组内触达的行/列节点。
4. **分量内必须「先算后写」**：先把整个分量的秩算出来再统一落笔、统一更新 `rowMax/colMax`。若边写边更新，同分量的后续格子会读到被自己人抬高的下界（等价于退化为逐格贪心）。
5. **值域陷阱**：$-10^9 \le v \le 10^9$ 且可为负——不能用值直接当数组下标（桶排序需离散化），`map` / 排序最稳妥；`rowMax/colMax` 初值 $0$ 表示「该行/列还没有更小的值」，配合 $+1$ 恰好产出最小秩 $1$，与值域正负无关。
6. **秩的规模**：秩不超过分量链长上界，$\le mn \le 2.5\times10^5$，`int` 足够；但注意它是「排名」不是值本身，别用 $\max |\text{matrix}|$ 之类的量估计。
7. **单行 / 单列矩阵**：传染链退化为「同一行里的相等段」，等值段同秩、段间严格递增；算法自然处理，无需特判。
8. **递归 find 的深度**：$m{+}n \le 1000$，路径压缩下递归版不会爆栈；Python 用路径减半迭代版更稳。
9. **遍历顺序**：C++ 的 `map` 按键升序天然有序；Python 的 `dict` 无序，必须 `sorted(by_value)` 显式排序，漏排序在大值乱序用例上直接错。

**延伸思考**：

- **约束放松为非严格**（$p \le q \Rightarrow \text{rank}(p) \le \text{rank}(q)$）：等值仍强制同秩，但「大于」变「不小于」，分量秩公式去掉 $+1$ 并与 $1$ 取 max 即可；试着重新走一遍 §5 的证明，哪一步需要改写？
- **秩 $=$ 偏序集高度**：拓扑解揭示了本质——把「同行同列严格小于」看作偏序，秩就是以该元素为顶点的最长链长度（Mirsky 定理的分层视角）。任何能建成有限 DAG 的约束系统都可以这样求「最小可行层数」。
- **强制输出唯一 vs 本题**：本题答案唯一来自「逐点最小」。若去掉最小性只要求合法，秩的方案数有多少？这等价于对分量 DAG 的分层计数，可用 DAG 上的动态规划求解。
