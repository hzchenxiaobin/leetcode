# LeetCode 等差子数组 题解

## 1. 题目概述

- **标题 / 题号**：等差子数组（#1630，medium）
- **链接**：https://leetcode.cn/problems/arithmetic-subarrays/
- **来源**：LeetCode 第 212 场周赛 Q2
- **难度**：中等
- **标签**：数组、排序、哈希表

**题意**：给定长度为 $n$ 的数组 `nums` 与长度为 $m$ 的数组 `l`、`r`。第 $i$ 个查询取出子数组 $\text{nums}[l[i]..r[i]]$，问这个子数组**能否重新排列**成等差数列（即是否存在一种排列，使每对相邻元素之差都相同）。返回 $m$ 个布尔值构成的列表 `answer`。

**约束**：

- $n = \text{nums}.\text{length}$，$m = l.\text{length} = r.\text{length}$
- $2 \le n \le 500$，$1 \le m \le 500$
- $0 \le l[i] < r[i] < n$（每个查询的子数组长度 $L \ge 2$）
- $-10^5 \le \text{nums}[i] \le 10^5$

> 💡 本题 = 「1502. 判断能否形成等差数列」加上**区间查询**外壳：$m$ 次独立的「多重集能否重排成等差」判定。$m, n \le 500$ 时怎么写都能过，赛时求稳可无脑排序；真正值得沉淀的是把单次判定从 $O(L\log L)$ 降到 $O(L)$ 的**槽位双射**技巧——它同时是 1502 官方进阶解法。

## 2. 示例

**示例 1**

```text
输入：nums = [4,6,5,9,3,7], l = [0,0,2], r = [2,3,5]
输出：[true, false, true]
解释：
第 0 个查询对应子数组 [4,6,5]，可重排为 [4,5,6]（公差 1）→ true；
第 1 个查询对应子数组 [4,6,5,9]，mn=4、mx=9，9−4=5 不能被 3 整除，
      连整数公差都不存在 → false；
第 2 个查询对应子数组 [5,9,3,7]，可重排为 [3,5,7,9]（公差 2）→ true。
```

**示例 2**

```text
输入：nums = [-12,-9,-3,-12,-6,15,20,-25,-20,-15,-10],
      l = [0,1,6,4,8,7], r = [4,4,9,7,9,10]
输出：[false, true, false, false, true, true]
解释：注意元素可以为负。例如第 5 个查询子数组 [-25,-20,-15,-10]，
      mn=−25、mx=−10，d=(−10+25)/3=5，恰好是 {−25,−20,−15,−10} → true。
```

**示例 3（槽位撞车陷阱）**

```text
输入：nums = [0,2,2,6], l = [0], r = [3]
输出：[false]
解释：mn=0、mx=6，(6−0) 能被 3 整除，d=2；每个元素减 mn 都是偶数——
      前两道闸门全过。但两个 2 都要落进槽位 k=1（值 2），而 k=2（值 4）空着：
      排不出 {0,2,4,6} → false。这是「只查整除、不查撞车」的经典 WA。
```

## 3. 解题思路

### 3.1 暴力思路

最朴素的念头是**枚举重排**：长度 $L$ 的子数组有 $L!$ 种排列，$L=500$ 时天文数字，直接排除。

落到可写的版本：每个查询把子数组**拷贝出来排序**，再检查相邻差是否全相等。单次 $O(L\log L)$，总计 $O(m \cdot L\log L) \le 500 \times 500 \times 9 \approx 2.2\times10^6$，稳过——这是赛时性价比最高的写法。但它没有利用问题的结构：

1. 判断「能否重排成等差」**不需要整体顺序**，排序做了多余的工作；
2. 等差数列被**最小值与公差唯一确定**，多重集只有「恰好等于 $\{mn + kd\}$」这一种成功形态。

把这两点用满，单次判定可以降到 $O(L)$ 且完全无需排序。

### 3.2 核心观察：等差数列由 (mn, d) 唯一确定 → 槽位双射

设子数组（作为**多重集** $S$）长度为 $L \ge 2$，$\text{mn} = \min S$，$\text{mx} = \max S$。若 $S$ 能排成等差数列，则排成**非降**等差后首项必为 $\text{mn}$、末项必为 $\text{mx}$，于是公差被迫唯一：

$$d = \frac{\text{mx} - \text{mn}}{L - 1}$$

且 $S$ 必须恰好等于 $\{\,\text{mn} + kd : k = 0, 1, \dots, L-1\,\}$——把这 $L$ 个值看成 $L$ 个**槽位**，判定就是三道闸门：

1. **全等闸门**：$\text{mx} = \text{mn}$ ⇔ 所有元素相等 ⇔ $d=0$，任意排列都是公差 0 的等差数列 → true；
2. **整除闸门**：$(\text{mx} - \text{mn}) \bmod (L-1) \ne 0$ → 连整数公差都不存在 → false；
3. **落槽闸门**：$d \ge 1$ 时，逐元素检查 $\text{off} = x - \text{mn}$ 是否整除 $d$，且槽位 $k = \text{off}/d$ **互不相同**。$L$ 个元素单射进 $L$ 个槽位，由鸽笼原理恰为双射——每个槽位恰好一个元素，排出来就是等差数列。

![核心观察：等差数列由 (mn, d) 唯一确定，槽位双射判定](images/wc212_q2_slot_concept.svg)

> 💡 **识别信号**：「多重集能否重排成等差 / 等比」类问题，先问*谁被唯一确定*——等差情形 $(\text{mn}, d)$ 唯一确定整个集合，于是判定退化为「逐元素落槽 + 查重」，$O(L)$ 无排序。

### 3.3 算法流程

![单查询判定流程：三个闸门加一趟落槽](images/wc212_q2_check_flow.svg)

```text
对每个查询 (lo, hi)：
  L ← hi − lo + 1                      # 约束保证 L ≥ 2
  第一趟扫描：求段内 mn 与 mx
  若 mx == mn：answer[i] ← true，继续下一查询        # d = 0，全相等
  若 (mx − mn) mod (L − 1) ≠ 0：answer[i] ← false，继续
  d ← (mx − mn) / (L − 1)              # 此时 d ≥ 1
  seen[0..L−1] ← false
  第二趟扫描：对段内每个 x：
    off ← x − mn                       # 恒 ≥ 0，负数元素也安全
    若 off mod d ≠ 0 或 seen[off / d]：answer[i] ← false，跳出
    seen[off / d] ← true
  若未提前跳出：answer[i] ← true
```

### 3.4 示例演算

以示例 1 的三个查询走一遍（$d = (\text{mx}-\text{mn})/(L-1)$）：

- **查询 0** `[4,6,5]`：$\text{mn}=4$，$\text{mx}=6$，$(6-4)\bmod 2=0$，$d=1$；落槽 $4\to k{=}0$、$6\to k{=}2$、$5\to k{=}1$，三槽各归其位 → **true**；
- **查询 1** `[4,6,5,9]`：$\text{mn}=4$，$\text{mx}=9$，$5 \bmod 3 = 2 \ne 0$，整除闸门直接拦下 → **false**（根本走不到落槽）；
- **查询 2** `[5,9,3,7]`：$\text{mn}=3$，$\text{mx}=9$，$6\bmod 3=0$，$d=2$；落槽 $5\to k{=}1$、$9\to k{=}3$、$3\to k{=}0$、$7\to k{=}2$，四槽占满 → **true**。

![示例 1 三查询演算：两道闸门加落槽](images/wc212_q2_walkthrough.svg)

再看示例 3 的 `[0,2,2,6]`：$d=2$，两个闸门全过，但两个 $2$ 同抢 $k{=}1$、$k{=}2$（值 4）空——**只有落槽查重能拦住它**。

## 4. 算法细节

1. **每个查询两趟扫描**：先求 $\text{mn}/\text{mx}$ 定出 $d$，再逐元素落槽。不能合成一趟——$d$ 依赖 $\text{mx}$，必须先扫完才知道。两趟仍是 $O(L)$。
2. **槽位范围自动合法**：$\text{mn} \le x \le \text{mx} = \text{mn} + (L-1)d$ ⇒ $0 \le \text{off} \le (L-1)d$ ⇒ $k = \text{off}/d \in [0, L-1]$，**无需任何判界**，`seen` 开 $L$ 格即可。
3. **全等闸门必须在整除闸门之前**：$\text{mx}=\text{mn}$ 时 $d=0$，任何 `% d`、`/ d` 都是除零崩溃。这一步不是优化，是生死线。
4. **负数安全**：$\text{off} = x - \text{mn} \ge 0$ 恒成立，规避了 C++/Java 负数取模的语义陷阱（$-7 \bmod 2$ 在不同语言结果不同）；**不要**直接对原值 $x$ 取模。
5. **查重缓冲**：C++ 每查询 `fill` 清零一段 `vector<char>`（或开 $O(L)$ 新数组），本题 $m, L \le 500$ 随便造；追求极致可用「时间戳」复用——`seenMark[k] == i` 才算本查询标记过，省去清零。
6. **查询彼此独立**：区间可以任意重叠、重复，互不影响；不要复用上一查询的 `seen` 残留状态（跨查询不清零是典型 bug 源）。
7. **为什么不预处理**：等差性不是可合并的区间性质（左右两段的答案合并不出整段的答案），ST 表 / 前缀和那套区间查询加速全部失效；好在 $L \le 500$，逐查询判定已经足够快。
8. **溢出**：$\text{mx}-\text{mn} \le 2\times10^5$，$k \le 499$，`int` 绰绰有余。
9. **赛时快写版**：不求 $O(L)$ 的话，Python 四行 `sorted` 判定足以通过（代码见 §7 末）。

## 5. 正确性证明

以下「等差数列」均指至少两项、公差为整数的数列；$L \ge 2$ 由约束 $l[i] < r[i]$ 保证，故 $L-1 \ge 1$，除法良定义。

**引理 1（排序归一化）**：多重集 $S$ 可重排成等差数列，当且仅当 $S$ 的非降排列 $a_0 \le a_1 \le \dots \le a_{L-1}$ 本身是公差 $d \ge 0$ 的等差数列。

**证明**：（⇐）非降排列就是一种排列，显然。（⇒）设 $S$ 的某排列 $b$ 是公差 $\delta$ 的等差数列。若 $\delta \ge 0$，则 $b$ 非降，而多重集的非降排列唯一，故 $a = b$；若 $\delta < 0$，将 $b$ 反转，得公差 $-\delta > 0$ 的等差数列，同理 $a$ 等于反转后的 $b$。∎

**引理 2（等差结构的必要条件）**：若非降数列 $a$ 是公差 $d$ 的等差数列，则 $d = (a_{L-1} - a_0)/(L-1)$ 为非负整数，且：$d = 0$ 时所有项相等；$d \ge 1$ 时各项互异，$S$ 恰等于 $\{a_0 + kd : k = 0..L-1\}$（每个值出现一次）。

**证明**：通项 $a_i = a_0 + i\,d$。取 $i = L-1$ 得 $a_{L-1} - a_0 = (L-1)d$，故 $d = (a_{L-1}-a_0)/(L-1)$；又 $a_{L-1} - a_0$ 是 $(L-1)d$ 的整数倍，$d$ 为整数，非降保证 $d \ge 0$。$d = 0$ 时 $a_i \equiv a_0$；$d \ge 1$ 时 $a_0 + kd$ 随 $k$ 严格递增，$L$ 个下标对应 $L$ 个互异值。∎

**引理 3（槽位双射的充分性）**：设 $\text{mx} - \text{mn} = (L-1)d$ 且 $d \ge 1$。若 $S$ 中每个元素 $x$ 满足 $\text{off}(x) = x - \text{mn}$ 是 $d$ 的倍数，且任意两个元素的槽位 $k(x) = \text{off}(x)/d$ 互不相同，则 $S = \{\text{mn} + kd : k = 0..L-1\}$，可排成等差数列。

**证明**：由 $\text{mn} \le x \le \text{mx}$ 得 $0 \le \text{off}(x) \le (L-1)d$，故 $k(x) \in \{0, 1, \dots, L-1\}$。元素到槽位的映射 $x \mapsto k(x)$ 是 $L$ 个元素到 $L$ 个槽位的单射，由**鸽笼原理**它是双射：每个槽位恰被一个元素占据。槽位 $k$ 上的元素满足 $x = \text{mn} + k\,d$，故 $S$（作为多重集）恰为 $\{\text{mn} + kd\}$；按槽位顺序输出即公差 $d$ 的等差数列。∎

**定理**：算法对每个查询返回 true，当且仅当对应子数组可重排成等差数列。

**证明**：记查询子数组为 $S$，长度 $L$。

- 若算法返回 true：
  - 全等闸门命中（$\text{mx} = \text{mn}$）：$S$ 的所有元素相等，任意排列都是公差 0 的等差数列；
  - 否则通过整除闸门与落槽闸门：$d = (\text{mx}-\text{mn})/(L-1) \ge 1$ 且引理 3 的条件全部成立，$S$ 可排成等差数列。
- 若 $S$ 可重排成等差数列：由引理 1，设其非降排列 $a$ 为公差 $d^*$ 的等差数列，其中 $d^* = (\text{mx}-\text{mn})/(L-1)$——与算法计算的 $d$ 是同一个值，整除闸门必过。若 $d^* = 0$，则 $\text{mx} = \text{mn}$，算法在全等闸门返回 true。若 $d^* \ge 1$：由引理 2，$S$ 的每个元素形如 $\text{mn} + k\,d^*$ 且 $L$ 个 $k$ 互异，于是每个 $\text{off}(x)$ 整除 $d^*$、槽位互不相同——落槽闸门的所有检查通过，算法返回 true。∎

## 6. 复杂度分析

- **时间复杂度**：每个查询两趟扫描 $O(L)$，总计 $O\bigl(\sum_i (r_i - l_i + 1)\bigr) \le O(mn) = 2.5\times10^5$。排序版为 $O(m \cdot L\log L) \approx 2.2\times10^6$，同样毫秒级——数据范围决定了本题「优化与否都能过」，$O(L)$ 版本的价值在方法论（1502 的进阶解法）。
- **空间复杂度**：$O(L)$——`seen` 查重缓冲（时间戳复用时仍为 $O(L)$ 上限），另加输出 $O(m)$。排序版需 $O(L)$ 的拷贝。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    vector<bool> checkArithmeticSubarrays(vector<int>& nums, vector<int>& l, vector<int>& r) {
        int m = l.size();
        vector<bool> ans(m);
        vector<char> seen(500);
        for (int i = 0; i < m; ++i) {
            int len = r[i] - l[i] + 1;
            int mn = INT_MAX, mx = INT_MIN;
            for (int j = l[i]; j <= r[i]; ++j) {
                mn = min(mn, nums[j]);
                mx = max(mx, nums[j]);
            }
            if (mn == mx) {                       // 闸门 1：d = 0，全相等
                ans[i] = true;
                continue;
            }
            if ((mx - mn) % (len - 1) != 0) {     // 闸门 2：无整数公差
                ans[i] = false;
                continue;
            }
            int d = (mx - mn) / (len - 1);        // 此时 d ≥ 1
            fill(seen.begin(), seen.begin() + len, 0);
            bool ok = true;
            for (int j = l[i]; j <= r[i]; ++j) {
                int off = nums[j] - mn;           // 恒 ≥ 0，负数元素也安全
                if (off % d != 0) { ok = false; break; }
                int k = off / d;                  // 自动落在 [0, len-1]
                if (seen[k]) { ok = false; break; }   // 闸门 3：槽位撞车
                seen[k] = 1;
            }
            ans[i] = ok;
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def checkArithmeticSubarrays(self, nums: List[int], l: List[int], r: List[int]) -> List[bool]:
        ans = []
        for lo, hi in zip(l, r):
            length = hi - lo + 1
            mn = mx = nums[lo]
            for x in nums[lo:hi + 1]:
                if x < mn:
                    mn = x
                elif x > mx:
                    mx = x
            if mn == mx:                          # 闸门 1：全相等
                ans.append(True)
                continue
            if (mx - mn) % (length - 1):          # 闸门 2：无整数公差
                ans.append(False)
                continue
            d = (mx - mn) // (length - 1)
            seen = set()
            ok = True
            for x in nums[lo:hi + 1]:             # 闸门 3：落槽 + 查重
                off = x - mn
                if off % d or off // d in seen:
                    ok = False
                    break
                seen.add(off // d)
            ans.append(ok)
        return ans
```

赛时快写版（排序判定，$O(m \cdot L\log L)$ 也稳过）：

```python
class Solution:
    def checkArithmeticSubarrays(self, nums: List[int], l: List[int], r: List[int]) -> List[bool]:
        def ok(seg):
            seg = sorted(seg)
            return all(b - a == seg[1] - seg[0] for a, b in zip(seg, seg[1:]))
        return [ok(nums[lo:hi + 1]) for lo, hi in zip(l, r)]
```

## 8. 边界情况与易错点

1. **除零**：$\text{mx} = \text{mn}$ 时 $d = 0$，任何 `% d`、`/ d` 都会崩溃——全等闸门必须放在最前面分支，顺序错了不是 WA 是 RE。
2. **槽位查重不可省略**：示例 3 `[0,2,2,6]` 通过整除闸门（$d=2$）且每个 $\text{off}$ 都是偶数，但两个 $2$ 撞在 $k{=}1$、$k{=}2$ 空。只查「整除」不查「撞车」必 WA。
3. **负数取模**：`off = x - mn ≥ 0` 恒成立，规避 C++/Java 负数取模语义；对原值 `x % d` 直接取模是埋雷写法。
4. **$L = 2$ 恒真**：任何两个数都构成等差数列。算法自然覆盖——$1 \mid (\text{mx}-\text{mn})$ 恒成立，两个槽位 $0/1$ 必不撞，无需特判。
5. **查询可重叠、可重复**：彼此完全独立；`seen` 缓冲每查询必须清零（或用 `set`、或时间戳），跨查询残留是隐蔽 bug。
6. **别把 `l`、`r` 当成左右端点数组以外的东西**：第 $i$ 个查询是闭区间 $[l[i], r[i]]$，`r` 是**包含**在内的右端点，切片时用 `hi + 1`。
7. **溢出**：$\text{mx}-\text{mn} \le 2\times10^5$、$k \le 499$，`int` 安全；排序版中差值同样无溢出风险。
8. **返回值**：按查询顺序的 $m$ 个布尔值；C++ 返回 `vector<bool>`，注意它不是普通 `vector`（无 `[]` 引用），本题只做逐位赋值无碍。
