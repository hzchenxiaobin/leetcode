# LeetCode 腐烂的橘子 题解

## 1. 题目概述

- **标题 / 题号**：腐烂的橘子（#994，medium）
- **链接**：https://leetcode.cn/problems/rotting-oranges/
- **来源**：LeetCode 第 124 场周赛 Q2
- **难度**：中等
- **标签**：广度优先搜索、数组、矩阵

**题意**：给定 $m \times n$ 的网格，`0` 表示空格、`1` 表示新鲜橘子、`2` 表示腐烂橘子。**每分钟**，每个腐烂橘子会让上下左右四个方向上**相邻**的新鲜橘子腐烂。返回让网格中不再有新鲜橘子所需的**最少分钟数**；若不可能，返回 $-1$。

**约束**：

- $1 \le m, n \le 10$
- `grid[i][j]` 仅取 $0, 1, 2$

> 💡 三个必须处理的细节：**初始没有新鲜橘子**时答案是 $0$（而不是 $-1$）；**多个腐烂源**要同时入队；**被空格隔断**的新鲜橘子永远无法腐烂，返回 $-1$。

## 2. 示例

**示例 1**

```text
输入：grid = [[2,1,1],[1,1,0],[0,1,1]]
输出：4
解释：0 分钟时只有 (0,0) 腐烂，逐层扩散，第 4 分钟 (2,2) 变腐烂。
```

**示例 2**

```text
输入：grid = [[2,1,1],[0,1,1],[1,0,1]]
输出：-1
解释：左下角的橘子 (2,0) 被空格包围，永远无法腐烂。
```

**示例 3**

```text
输入：grid = [[0,2]]
输出：0
解释：网格里没有新鲜橘子，0 分钟即可满足要求。
```

## 3. 解题思路

### 3.1 暴力思路

按分钟模拟：每一分钟扫描整个网格，把「腐烂橘子旁边的新鲜橘子」标记为腐烂；若某一分钟没有任何变化而仍有新鲜橘子，返回 $-1$。正确但每次都要 $O(mn)$ 扫描，总复杂度 $O(mn \cdot T)$，其中 $T$ 是答案（可达 $O(mn)$），最坏 $O(m^2 n^2)$。$m, n \le 10$ 时能过，但完全没有利用「每分钟只影响上一层邻接点」这一结构。

### 3.2 核心观察：多源 BFS，层号就是分钟数

![多源 BFS：一层等于一分钟](images/wc124_q2_bfs_layers.svg)

把每个「腐烂橘子」看成图中的一个**源点**，相邻格子之间有边。那么：

- 一格新鲜橘子变成腐烂的时刻，恰好是它到**最近源点**的**最短距离**（按上下左右四连通计）；
- 所有源点同时扩散，等价于把**全部源点一次性入队**，做一次多源 BFS，第 $d$ 层就是第 $d$ 分钟被感染的格子。

于是答案就是 BFS 的最大层号；如果 BFS 结束后仍有新鲜橘子，说明它们与所有源点都不连通，返回 $-1$。

多源 BFS 与「对每个源点分别 BFS 再取最小值」结果相同，但只需遍历一次网格，复杂度从 $O(S \cdot mn)$ 降到 $O(mn)$。

### 3.3 算法流程

```text
1. 扫描网格：把所有值为 2 的格子入队，统计新鲜橘子数 fresh
2. 若 fresh == 0: 直接返回 0
3. ans = 0
4. while 队列非空:
       记录当前队列长度 sz（= 本层结点数）
       弹出 sz 个结点，对每个结点的四个邻居:
           若邻居是新鲜橘子: 置为 2，fresh 减一，入队
       若本轮有入队: ans 加一
5. 返回 fresh == 0 ? ans : -1
```

也可以把「分钟数」作为队列元素的第三维（`(i, j, t)`），效果相同；按层处理更省空间。

### 3.4 示例演算

![示例 1 的分钟标注](images/wc124_q2_walkthrough.svg)

对示例 1 的网格：

| 分钟 | 新腐烂的格子 | 说明 |
|------|--------------|------|
| 0 | $(0,0)$ | 初始唯一的腐烂源 |
| 1 | $(0,1)$、$(1,0)$ | 从 $(0,0)$ 向两个方向扩散 |
| 2 | $(0,2)$、$(1,1)$ | 分别来自 $(0,1)$ 与两条路径 |
| 3 | $(2,1)$ | $(1,2)$ 是空格，只能走 $(1,1) \to (2,1)$ |
| 4 | $(2,2)$ | 最后一格，来自 $(2,1)$ |

所有新鲜橘子都被覆盖，最大分钟数为 $4$，答案 $4$。

## 4. 算法细节

1. **多源入队**：初始化时把**所有** `2` 都放入队列，而不是只放第一个——这是本题最关键的实现点。
2. **fresh 计数**：单独维护新鲜橘子数量，比每次重新扫描网格判断「是否还有 1」快得多，也避免了「BFS 后仍残留」的误判。
3. **就地标记**：访问到新鲜橘子时立即把 `grid` 改成 `2` 并入队，保证每个格子只入队一次（等价于 visited 数组）。
4. **按层计数**：`sz = q.size()` 取的是**本层**的结点数，循环内新入队的结点属于下一层，不会被本轮消费。
5. **ans 的自增条件**：只在「本轮确实感染了新的橘子」时加一，避免最后空跑一层导致答案多 1。
6. **边界判定**：邻居坐标要同时满足 `0 <= ni < m` 与 `0 <= nj < n`。
7. **空格的邻居**：`0` 不满足「是新鲜橘子」，自然被跳过，无需特判。

## 5. 正确性证明

把网格看成图 $G$：每个非空格子是一个顶点，上下左右相邻的非空格子之间有边。设源点集合为 $S = \{v : \text{grid}(v) = 2\}$（初始腐烂的格子），$d(v) = \min_{s \in S} \operatorname{dist}(s, v)$（若 $v$ 与所有源点都不连通则记为 $\infty$）。

**引理 1（感染时刻等于距离）**：对任意初始新鲜的非空格子 $v$，它在第 $d(v)$ 分钟变腐烂（$d(v) = \infty$ 时永不腐烂）。

**证明**：对 $d(v)$ 归纳。$d(v) = 1$ 时 $v$ 与某个源点相邻，第 1 分钟必被感染；且不可能在第 0 分钟被感染（它初始是新鲜的）。设结论对 $d(v) \le k$ 成立，取 $d(v) = k+1$，则存在源点 $s$ 与路径 $s = v_0, v_1, \dots, v_{k+1} = v$。于是 $\operatorname{dist}(s, v_k) = k$，由归纳假设 $v_k$ 在第 $k$ 分钟腐烂，故 $v$ 在第 $k+1$ 分钟被感染（上界）。另一方面，若 $v$ 在第 $t$ 分钟腐烂，则存在一条从源点到 $v$ 的传播链，链上每步耗时 1 分钟，故 $t \ge d(v)$（下界）。上下界合并得等号。∎

**引理 2（多源 BFS 计算距离）**：把 $S$ 全部入队后执行的 BFS，第 $k$ 层恰好是满足 $d(v) = k$ 的全部顶点。

**证明**：多源 BFS 等价于在图中加入一个「超级源点」$s^*$，它与每个 $s \in S$ 连一条长度 0 的边，然后从 $s^*$ 做 BFS。此时 $\operatorname{dist}(s^*, v) = d(v) + 0 = d(v)$，而 BFS 按层展开，第 $k$ 层正是距离为 $k$ 的顶点集合。∎

**定理**：算法返回的分钟数等于「让网格中不再有新鲜橘子」的最少分钟数；若不可能则为 $-1$。

**证明**：由引理 1，所有新鲜橘子都在各自的 $d(v)$ 时刻腐烂，故全部腐烂的时刻为 $\max_v d(v)$，这也是最少分钟数（任何策略都无法让某个格子早于其最短距离腐烂）。由引理 2，BFS 的层数正是 $\max_v d(v)$，而算法中的 `ans` 统计的正是实际展开的层数。若存在 $d(v) = \infty$ 的新鲜橘子，`fresh` 在 BFS 结束后仍大于 0，算法返回 $-1$，与「不可能」一致。初始 `fresh == 0` 时最短时间为 0，算法直接返回 0。∎

## 6. 复杂度分析

- **时间**：$O(mn)$。每个格子至多入队一次、出队一次，出队时检查 4 个邻居，总操作数为 $O(mn)$。初始扫描也是 $O(mn)$。
- **空间**：$O(mn)$。队列最坏容纳全部格子；网格是原地修改，不需要额外的 visited 数组。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int orangesRotting(vector<vector<int>>& grid) {
        int m = grid.size(), n = grid[0].size();
        queue<pair<int, int>> q;
        int fresh = 0;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == 2) q.push({i, j});
                else if (grid[i][j] == 1) fresh++;
            }
        }
        if (fresh == 0) return 0;
        int ans = 0;
        const int di[4] = {1, -1, 0, 0};
        const int dj[4] = {0, 0, 1, -1};
        while (!q.empty()) {
            int sz = q.size();
            for (int k = 0; k < sz; k++) {
                pair<int, int> cur = q.front();
                q.pop();
                int i = cur.first, j = cur.second;
                for (int d = 0; d < 4; d++) {
                    int ni = i + di[d], nj = j + dj[d];
                    if (ni >= 0 && ni < m && nj >= 0 && nj < n && grid[ni][nj] == 1) {
                        grid[ni][nj] = 2;
                        fresh--;
                        q.push({ni, nj});
                    }
                }
            }
            if (!q.empty()) ans++;
        }
        return fresh == 0 ? ans : -1;
    }
};
```

### Python

```python
class Solution:
    def orangesRotting(self, grid: list[list[int]]) -> int:
        from collections import deque
        m, n = len(grid), len(grid[0])
        q = deque()
        fresh = 0
        for i in range(m):
            for j in range(n):
                if grid[i][j] == 2:
                    q.append((i, j, 0))
                elif grid[i][j] == 1:
                    fresh += 1
        if fresh == 0:
            return 0
        ans = 0
        while q:
            i, j, t = q.popleft()
            for di, dj in ((1, 0), (-1, 0), (0, 1), (0, -1)):
                ni, nj = i + di, j + dj
                if 0 <= ni < m and 0 <= nj < n and grid[ni][nj] == 1:
                    grid[ni][nj] = 2
                    fresh -= 1
                    ans = max(ans, t + 1)
                    q.append((ni, nj, t + 1))
        return ans if fresh == 0 else -1
```

Python 版把「分钟」放进队列元素，与 C++ 的按层写法等价：`t` 就是该格子的最短距离，取最大值即答案。

## 8. 边界情况与易错点

1. **没有新鲜橘子**：`[[0,2]]` → 0（示例 3），必须先判 `fresh == 0`，否则会返回别的值。
2. **没有腐烂橘子但有新鲜橘子**：队列为空、`fresh > 0`，循环不执行，返回 $-1$，正确。
3. **多个源点**：只把第一个 `2` 入队是经典错误，会导致部分区域延迟腐烂、答案偏大。
4. **被隔断的新鲜橘子**：示例 2 的 $(2,0)$ 四邻是 `0`，BFS 结束后 `fresh > 0`，返回 $-1$。
5. **多算一分钟**：若在每轮开始就 `ans++`，最后一轮可能没有新感染，答案会大 1；只在「本轮确实感染了」时加一。
6. **重复入队**：入队时立即把格子改成 `2`，否则同一个格子可能被多个邻居重复入队。
7. **单行/单列**：$m = 1$ 或 $n = 1$ 时邻居判断的越界条件必须完整，不能只判行或列。
8. **网格全空**：`[[0]]` → 0。
