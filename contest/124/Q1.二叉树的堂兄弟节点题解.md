# LeetCode 二叉树的堂兄弟节点 题解

## 1. 题目概述

- **标题 / 题号**：二叉树的堂兄弟节点（#993，easy）
- **链接**：https://leetcode.cn/problems/cousins-in-binary-tree/
- **来源**：LeetCode 第 124 场周赛 Q1
- **难度**：简单
- **标签**：树、深度优先搜索、广度优先搜索、二叉树

**题意**：二叉树的根结点深度为 $0$，深度为 $k$ 的结点的子结点深度为 $k+1$。若两个结点**深度相同**但**父亲不同**，则称它们是一对**堂兄弟**。给定结点值互不相同的一棵二叉树与两个不同的值 $x, y$，判断对应的两个结点是否为堂兄弟。

**约束**：

- 结点数在 $[2, 100]$ 内
- 每个结点的值唯一，范围 $[1, 100]$
- $x \ne y$，且两者都在树中

> 💡 两个条件缺一不可：只看深度会把**亲兄弟**误判成堂兄弟；只看父亲不同又会把不同层级的结点算进来。示例 3 就是「父亲相同」的反例。

## 2. 示例

**示例 1**

```text
输入：root = [1,2,3,4], x = 4, y = 3
输出：false
解释：4 在深度 2（父为 2），3 在深度 1（父为 1），深度不同。
```

**示例 2**

```text
输入：root = [1,2,3,null,4,null,5], x = 5, y = 4
输出：true
解释：4 与 5 深度都是 2，父亲分别是 2 和 3。
```

**示例 3**

```text
输入：root = [1,2,3,null,4], x = 2, y = 3
输出：false
解释：2 与 3 深度相同（都是 1），但父亲都是根结点 1，是亲兄弟。
```

## 3. 解题思路

### 3.1 暴力思路

对 $x$ 与 $y$ 分别做一次「从根出发找目标结点」的搜索，沿路径记录深度与父结点，再比较。两次 $O(n)$ 搜索，总复杂度 $O(n)$，本身可行；但代码要写两遍相似逻辑，或者写一个带返回值的递归函数再调用两次，容易在「找到就返回」与「继续遍历」之间写错。

### 3.2 核心观察：一次遍历同时记录两个信息

![堂兄弟的定义：深度相同且父亲不同](images/wc124_q1_cousins_def.svg)

由于**结点值互不相同**，可以只遍历一次树，遇到值为 $x$ 或 $y$ 的结点就把它记进字典：

$$\text{info}[v] = (\text{depth}(v),\ \text{parent}(v))$$

因为只需要两个结点的信息，字典最多两项。遍历结束后：

$$\text{answer} = \bigl[\text{depth}(x) = \text{depth}(y)\bigr] \wedge \bigl[\text{parent}(x) \ne \text{parent}(y)\bigr]$$

父结点比较用**结点指针（或对象引用）比较**而不是比较值：虽然本题值唯一，用值比较也对，但用引用更贴合定义，也不受「值可能重复」的变体影响。

### 3.3 算法流程

```text
1. info = 空字典
2. dfs(node, depth, parent):
       若 node 为空: 返回
       若 node.val 是 x 或 y: info[node.val] = (depth, parent)
       dfs(node.left,  depth + 1, node)
       dfs(node.right, depth + 1, node)
3. dfs(root, 0, null)
4. 返回 info[x].depth == info[y].depth 且 info[x].parent != info[y].parent
```

### 3.4 示例演算

![示例 2 的树与推导](images/wc124_q1_walkthrough.svg)

对示例 2 的 `[1,2,3,null,4,null,5]`：

| 结点 | 路径 | 深度 | 父亲 |
|------|------|------|------|
| 4 | $1 \to 2 \to 4$ | 2 | 2 |
| 5 | $1 \to 3 \to 5$ | 2 | 3 |

深度相等、父亲不同 → 返回 `true`。再用示例 3 检验：结点 2 与 3 的深度都是 1，父亲都是 1，第二个条件不成立 → `false`。

## 4. 算法细节

1. **深度从 0 开始**：题面明确规定根结点深度为 $0$，递归入口传 `0`，子结点传 `depth + 1`。
2. **父结点传参**：用 `parent` 参数而非回溯查找，既省空间也避免写错。
3. **提前剪枝**：若两个值都找到了可以提前返回，但 $n \le 100$，遍历完整棵树代价可忽略，代码更简单。
4. **字典最多两项**：只记录 $x$ 与 $y$，不需要存全部结点的信息。
5. **引用比较**：C++ 用 `TreeNode*` 指针比较，Python 用 `is not`；若改成比较 `val`，在本题也对，但语义上不如引用直接。
6. **空结点的处理**：递归入口判空返回，避免访问 `node.left` 时崩溃。

## 5. 正确性证明

**引理 1（记录的深度正确）**：`dfs` 调用 `dfs(node, d, p)` 时，`node` 的深度恰为 $d$。

**证明**：对递归深度归纳。根结点由入口 `dfs(root, 0, null)` 调用，深度为 $0$，与题面一致。若 `node` 深度为 $d$，它的子结点深度为 $d+1$，递归调用传的正是 `d + 1`，归纳成立。∎

**引理 2（记录的父结点正确）**：`dfs(node, d, p)` 中 `p` 恰为 `node` 的父结点（根结点为 `null`）。

**证明**：子结点由 `dfs(node.left, d+1, node)` 与 `dfs(node.right, d+1, node)` 访问，第三个参数传的就是当前结点 `node`，即子结点的父结点；根结点没有父结点，入口传 `null`。∎

**引理 3（信息完整）**：遍历结束后，`info[x]` 与 `info[y]` 都存在且内容正确。

**证明**：由题面，$x$、$y$ 都是树中结点的值；遍历会访问每个结点恰好一次（二叉树的每个结点只有一条从根出发的路径），访问到值为 $x$（或 $y$）的结点时写入字典。由引理 1、2，写入的深度与父结点正确。又因值互不相同，每个值只被写入一次，不会覆盖。∎

**定理**：算法返回 `true` 当且仅当 $x$ 与 $y$ 对应的结点是堂兄弟。

**证明**：由引理 3，返回值等价于「$\text{depth}(x)=\text{depth}(y)$ 且 $\text{parent}(x)\ne\text{parent}(y)$」，而题面对堂兄弟的定义正是「深度相同且父结点不同」，两者逐字对应。∎

## 6. 复杂度分析

- **时间**：$O(n)$。每个结点访问一次，字典写入 $O(1)$，比较 $O(1)$。
- **空间**：$O(n)$ 最坏（链状树时递归栈深度为 $n$）；字典只存 2 项，故额外空间 $O(1)$。若改写成显式栈或 BFS，空间同样为 $O(n)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool isCousins(TreeNode* root, int x, int y) {
        map<int, pair<int, TreeNode*>> info;
        dfs(root, 0, NULL, x, y, info);
        return info[x].first == info[y].first && info[x].second != info[y].second;
    }

private:
    void dfs(TreeNode* node, int depth, TreeNode* parent, int x, int y,
             map<int, pair<int, TreeNode*>>& info) {
        if (!node) return;
        if (node->val == x || node->val == y) info[node->val] = {depth, parent};
        dfs(node->left, depth + 1, node, x, y, info);
        dfs(node->right, depth + 1, node, x, y, info);
    }
};
```

### Python

```python
class Solution:
    def isCousins(self, root, x: int, y: int) -> bool:
        info = {}

        def dfs(node, depth, parent):
            if node is None:
                return
            if node.val == x or node.val == y:
                info[node.val] = (depth, parent)
            dfs(node.left, depth + 1, node)
            dfs(node.right, depth + 1, node)

        dfs(root, 0, None)
        return info[x][0] == info[y][0] and info[x][1] is not info[y][1]
```

## 8. 边界情况与易错点

1. **亲兄弟陷阱**：示例 3 的 2 与 3 深度相同但同父，必须靠第二个条件排除。
2. **层级不同**：示例 1 的 4 与 3，深度不同，第一个条件直接否决。
3. **根结点作为目标**：根的深度为 $0$、父为 `null`；若 $x$ 是根，另一个结点深度不可能为 $0$，结果必为 `false`。
4. **深度起点**：题面从 $0$ 开始计数，若从 $1$ 开始，两个条件都会平移，虽然比较结果不变，但写进注释容易误导。
5. **父结点比较方式**：用指针/引用比较，别用「父结点的值」这种间接写法（本题值唯一时碰巧等价）。
6. **递归深度**：$n \le 100$，链状树也只有 100 层，递归安全。
7. **空树**：题面保证结点数 $\ge 2$，不必处理。
