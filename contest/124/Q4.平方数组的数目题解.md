# LeetCode 平方数组的数目 题解

## 1. 题目概述

- **标题 / 题号**：平方数组的数目（#996，hard）
- **链接**：https://leetcode.cn/problems/number-of-squareful-arrays/
- **来源**：LeetCode 第 124 场周赛 Q4
- **难度**：困难
- **标签**：位运算、数组、哈希表、数学、动态规划、回溯、位掩码

**题意**：若一个数组的**任意两个相邻元素之和都是完全平方数**，则称它为**平方数组**。给定数组 `nums`，返回它的**排列**中平方数组的个数。两个排列只要有一个位置不同就算不同。

**约束**：

- $1 \le nums.length \le 12$
- $0 \le nums[i] \le 10^9$

> 💡 `nums` 中可能有**重复元素**（示例 2 的 `[2,2,2]` 答案是 1 而不是 6），所以「值相同的元素互换」不能算作新排列。这是本题最主要的坑，比「判断平方数」更容易写错。

## 2. 示例

**示例 1**

```text
输入：nums = [1,17,8]
输出：2
解释：[1,8,17] 与 [17,8,1] 合法；1+17=18 不是平方数，所以 1、17 不能相邻。
```

**示例 2**

```text
输入：nums = [2,2,2]
输出：1
解释：三个 2 怎么排都是同一个排列，且 2+2=4 是平方数，故只有 1 个。
```

## 3. 解题思路

### 3.1 暴力思路

枚举 `nums` 的全部排列（最多 $12! \approx 4.8 \times 10^8$ 个），逐个检查相邻和是否为平方数。即便不考虑重复元素，规模也太大了；而且重复元素会带来大量重复计数，需要额外的 `set` 去重，内存也吃不消。

### 3.2 核心观察：建图 + 回溯

![把相邻和为平方数翻译成图上的边](images/wc124_q4_graph_model.svg)

把每个下标看成图的一个顶点，若 `nums[i] + nums[j]` 是完全平方数就在 $i, j$ 之间连边。那么：

- 一个合法排列，就是把所有顶点各走一次的一条路径（**哈密顿路径**），路径上相邻顶点必须相连；
- 反之，任何哈密顿路径按经过顺序取值，都给出一个合法排列。

于是问题变成「**在图上数哈密顿路径**」。一般的哈密顿路径计数是 NP 难问题，但 $n \le 12$，回溯 + 剪枝完全够用。

**判断完全平方数**：$s \le 2 \times 10^9$，用整数开方后回代验证，避免浮点误差：

$$\text{isSquare}(s) \iff \lfloor \sqrt{s} \rfloor^2 = s .$$

Python 用 `math.isqrt`（精确整数开方）；C++ 用 `sqrtl` 得到近似值后再做 $\pm 1$ 的修正循环。

### 3.3 算法流程

![排序后按值去重](images/wc124_q4_dedup.svg)

```text
1. nums 升序排序
2. used[0..n-1] 全 false，ans = 0
3. dfs(depth, last):
       若 depth == n: ans += 1; 返回
       for i in 0..n-1:
           若 used[i]: 继续
           若 i > 0 且 nums[i] == nums[i-1] 且 not used[i-1]: 继续     # 去重
           若 depth > 0 且 nums[i] + last 不是平方数: 继续             # 剪枝
           used[i] = true
           dfs(depth + 1, nums[i])
           used[i] = false
4. dfs(0, 0) 后返回 ans
```

**去重原理**：排序后，相同值的元素连续排列。规则「前一个同值元素还没被使用就跳过当前元素」强制同值元素**按下标递增的顺序**被选取。这样，对于任意一个值序列（如 `2,2,2`），只有一种下标选取顺序被允许，重复计数被彻底消除。

### 3.4 示例演算

![示例 1 的回溯树](images/wc124_q4_walkthrough.svg)

对 `nums = [1,17,8]`：$1+8 = 9 = 3^2$、$8+17 = 25 = 5^2$、$1+17 = 18$（不是平方数）。回溯过程：

| 分支 | 过程 | 结果 |
|------|------|------|
| 以 1 开头 | $1 \to 8$（和 9 ✓）$\to 17$（和 25 ✓） | 合法，计 1 |
| 以 8 开头，接 1 | $8 \to 1 \to 17$，但 $1+17=18$ ✗ | 剪枝 |
| 以 8 开头，接 17 | $8 \to 17 \to 1$，但 $17+1=18$ ✗ | 剪枝 |
| 以 17 开头 | $17 \to 8 \to 1$（和 25 ✓、9 ✓） | 合法，计 2 |

答案 2。注意「以 8 开头」的两个分支都在最后一层被剪掉，这正是剪枝的价值。

## 4. 算法细节

1. **排序是去重的前提**：不排序就无法用「相邻同值」判断重复，必须先 `sort`。
2. **`last` 参数**：只需要上一个选中的值，不需要恢复整条路径，省内存。
3. **`depth == 0` 时不判相邻**：第一个元素没有前驱，要单独放行。
4. **整数开方**：C++ 中 `sqrtl` 对 $2 \times 10^9$ 的误差可能使结果差 1，必须用 `while` 修正；Python 的 `math.isqrt` 是精确的，无需修正。
5. **去重条件写全**：`i > 0 && nums[i] == nums[i-1] && !used[i-1]`，三个条件缺一不可——少了 `!used[i-1]` 会把合法的「同值连续使用」也剪掉。
6. **剪枝顺序**：先去重再判平方数，能少算很多 `isSquare`。
7. **答案规模**：$n \le 12$ 时最多约 $12!$，但实际受限于相邻约束，`int` 足够（LeetCode 官方答案上界远小于 $2^{31}$）。

## 5. 正确性证明

设排序后的数组为 $a_0 \le a_1 \le \dots \le a_{n-1}$，图 $G$ 的顶点集为 $\{0, \dots, n-1\}$，边 $(i,j)$ 当且仅当 $a_i + a_j$ 是完全平方数（$i \ne j$）。

**引理 1（排列与路径对应）**：值序列 $(v_1, \dots, v_n)$ 是平方数组，当且仅当存在一条哈密顿路径按顺序取值为 $v_1, \dots, v_n$。

**证明**：若排列合法，则对每个相邻对 $v_t + v_{t+1}$ 是完全平方数，故存在下标 $i_t$ 使 $a_{i_t} = v_t$，且 $i_t$ 与 $i_{t+1}$ 之间有边；下标互不相同（每个值只取一次），构成一条哈密顿路径。反之，哈密顿路径上相邻顶点有边，即相邻值之和为平方数，按序取值即为合法排列。∎

**引理 2（去重规则刻画唯一代表）**：对任一值序列 $\sigma = (v_1, \dots, v_n)$，满足「同值按下标递增使用」的下标分配**恰好存在一个**。

**证明**：设值 $v$ 在 $\sigma$ 中出现的位置为 $t_1 < t_2 < \dots < t_m$，$v$ 在 $a$ 中的下标为 $j_1 < j_2 < \dots < j_m$（排序保证这些下标连续且对应 $v$）。唯一可行的分配是 $i_{t_r} = j_r$：因为必须用尽 $v$ 的全部 $m$ 个下标，而规则要求递增，故只能是这个对应。存在性显然，唯一性由递增顺序强制。∎

**引理 3（DFS 叶子与代表一一对应）**：DFS 产生的每个叶子对应一个下标序列，且该序列恰好是它所代表的值序列的「唯一代表」；不同叶子对应的值序列互不相同。

**证明**：DFS 的每个叶子是一条从空到用完所有下标的路径，其中每个下标用一次，故是一个下标排列。由于剪枝规则要求「同值按下标递增使用」，叶子对应的下标序列必满足引理 2 中的规范形式，因此它是其值序列的唯一代表。若两个叶子的值序列相同，则它们的规范代表相同（引理 2 的唯一性），故下标序列相同，即叶子相同。∎

**引理 4（剪枝不剪掉合法解）**：平方数剪枝只在「当前最后一个值与待选值之和不是平方数」时跳过，这恰好违反平方数组的定义。

**证明**：若 $a_i + last$ 不是完全平方数，则任何以当前已选前缀开头、接着选 $a_i$ 的排列都不合法（这两个元素相邻且和不是平方数），故该分支下不可能有合法解，剪掉它不影响答案。反之，若和是平方数，剪枝不触发，分支保留。∎

**定理**：算法返回的 `ans` 恰为 `nums` 的平方数组排列个数（按值序列去重）。

**证明**：由引理 3，DFS 的叶子与「值序列的去重代表」一一对应；由引理 4，剪枝只删去不可能是平方数组的分支；而 DFS 走完所有长度为 $n$ 的路径，即遍历了全部下标排列。于是保留下来的每个叶子都是合法的平方数组代表，且每个平方数组的值序列恰有一个叶子与之对应。故 `ans` 正是不同平方数组的个数。∎

## 6. 复杂度分析

- **时间**：最坏 $O(n! \cdot n)$——每个叶子（长度 $n$ 的路径）最多有 $n$ 个选择点，每次判断平方数 $O(1)$。实际上相邻约束很强，剪枝后枚举量远小于 $n!$；$n \le 12$ 时可在时限内完成。
- **空间**：$O(n)$。递归深度 $n$，`used` 数组 $n$ 项，无额外结构。若改用「预处理邻接矩阵」的写法，额外 $O(n^2)$ 空间，可把每次平方数判断换成 $O(1)$ 查表。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int numSquarefulPerms(vector<int>& nums) {
        sort(nums.begin(), nums.end());
        n = nums.size();
        this->nums = nums;
        used.assign(n, false);
        ans = 0;
        dfs(0, 0);
        return ans;
    }

private:
    int n;
    int ans;
    vector<int> nums;
    vector<bool> used;

    bool isSquare(long long s) {
        long long r = (long long)sqrtl((long double)s);
        while ((r + 1) * (r + 1) <= s) r++;
        while (r * r > s) r--;
        return r * r == s;
    }

    void dfs(int depth, int last) {
        if (depth == n) {
            ans++;
            return;
        }
        for (int i = 0; i < n; i++) {
            if (used[i]) continue;
            if (i > 0 && nums[i] == nums[i - 1] && !used[i - 1]) continue;
            if (depth > 0 && !isSquare((long long)last + nums[i])) continue;
            used[i] = true;
            dfs(depth + 1, nums[i]);
            used[i] = false;
        }
    }
};
```

### Python

```python
import math


class Solution:
    def numSquarefulPerms(self, nums: list[int]) -> int:
        n = len(nums)
        nums = sorted(nums)
        used = [False] * n
        ans = 0

        def is_square(s: int) -> bool:
            r = math.isqrt(s)
            return r * r == s

        def dfs(depth: int, last: int) -> None:
            nonlocal ans
            if depth == n:
                ans += 1
                return
            for i in range(n):
                if used[i]:
                    continue
                if i > 0 and nums[i] == nums[i - 1] and not used[i - 1]:
                    continue
                if depth > 0 and not is_square(last + nums[i]):
                    continue
                used[i] = True
                dfs(depth + 1, nums[i])
                used[i] = False

        dfs(0, 0)
        return ans
```

## 8. 边界情况与易错点

1. **重复元素**：`[2,2,2]` 答案是 1。若只按 `used` 数组枚举下标、不去重，会得到 6，这是最高频 WA。
2. **去重三条件**：`i > 0`、`nums[i] == nums[i-1]`、`!used[i-1]` 必须同时成立才 `continue`；漏掉第三个会把 `[2,2,2]` 剪成 0。
3. **单个元素**：$n = 1$ 时没有相邻对，约定答案为 1（空约束视为满足），递归第一层即 `depth == n`。
4. **整数开方误差**：C++ 的 `sqrtl` 对 $2 \times 10^9$ 可能返回偏小 1 的值，必须用 `while` 双向修正；Python 用 `math.isqrt`。
5. **和的溢出**：$nums[i] \le 10^9$，两数之和可达 $2 \times 10^9$，超过 `int` 上限，C++ 中必须转 `long long` 再开方。
6. **$0$ 的处理**：$0 + 0 = 0 = 0^2$ 是平方数，所以全 0 数组的答案按去重后是 1。
7. **剪枝顺序**：先判重再判平方数，既正确又少算。
8. **不需要记忆化**：状态是「已用集合 + 上一个值」，若用哈希记忆化要注意值相等但下标不同的情况，容易出错；$n \le 12$ 直接回溯更稳。
