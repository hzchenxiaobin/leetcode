# LeetCode 将数组转换为交替质数数组的最少操作次数 题解

## 1. 题目概述

- **标题 / 题号**：将数组转换为交替质数数组的最少操作次数（#3896，medium）
- **链接**：https://leetcode.cn/problems/minimum-operations-to-transform-array-into-alternating-prime/
- **来源**：LeetCode 第 180 场双周赛 Q3
- **难度**：中等
- **标签**：数组、数学、双指针、二分查找、数论、排序

**题意**：称数组是**交替质数**数组，若：

- **偶数下标**（从 0 开始）处的元素是**质数**；
- **奇数下标**处的元素是**非质数**。

一次操作可以把任意元素**加 1**。返回把 `nums` 变成交替质数数组所需的**最少操作次数**。

质数的定义：大于 1 且只有 1 和自身两个因数的自然数。因此 0 和 1 **都不是质数**。

**约束**：

- $1 \le \text{nums.length} \le 10^5$
- $1 \le nums[i] \le 10^5$

## 2. 示例

**示例 1**

```text
输入：nums = [1,2,3,4]
输出：3
解释：i=0 要质数：1 → 2，+1；
      i=1 要非质数：2 是质数 → 3 还是质数 → 4 非质数，+2；
      i=2 的 3 已是质数，0 次；i=3 的 4 已是非质数，0 次。合计 1+2+0+0 = 3。
```

**示例 2**

```text
输入：nums = [5,6,7,8]
输出：0
解释：5、7 是质数，6、8 是非质数，已经满足要求。
```

**示例 3**

```text
输入：nums = [4,4]
输出：1
解释：i=0 要质数：4 → 5，+1；i=1 要非质数：4 已满足。合计 1。
```

## 3. 解题思路

### 3.1 暴力思路

对每个位置，从 $nums[i]$ 开始逐个 $+1$ 试，直到奇偶位要求满足为止，把步数累加。因为只能加 1，每个位置的选择**不影响**其它位置，所以「逐个位置贪心」就是最优。

朴素实现里判断质数用试除法，单次 $O(\sqrt{nums[i]})$，加上可能多次尝试，最坏 $O(n\sqrt{V})$，$n = 10^5$、$V = 10^5$ 时约 $3\times10^7$，勉强能过但没必要——用筛法预处理后每次判断 $O(1)$。

### 3.2 核心观察：位置之间互不影响，只需「向右找第一个合法值」

![两种「向右找第一个合法值」的代价](images/bw180_q3_next_prime.svg)

由于操作只能 **加 1**（不能减），对每个位置：

- **偶数下标**：需要质数 → 取 $\ge nums[i]$ 的**最小质数**，代价为它与 $nums[i]$ 之差；
- **奇数下标**：需要非质数 → 取 $\ge nums[i]$ 的**最小非质数**，代价同理。

各位置的代价互不干扰（一次操作只作用于一个元素），所以**总代价就是各位置代价之和**——这是本题的核心，不需要任何搜索。

两个关键的量级结论：

1. **偶数下标**：质数之间的间隔很小（$10^5$ 以内最大间隔不到 100），所以循环最多几十步。
2. **奇数下标**：最多 **2 步**。因为除 2 以外的质数都是奇数，$p + 1$ 是大于 2 的偶数 → 一定非质数；唯一例外是 $p = 2$，$2+1 = 3$ 仍是质数，需再加 1 到 4。

### 3.3 算法流程

```text
1. 用埃氏筛求出 [0, LIM] 的质数标记，LIM = 200000（覆盖 nums[i] ≤ 10^5 以及加 1 后越界）
2. total = 0
3. for i, v in enumerate(nums):
4.     x = v
5.     若 i 是偶数:  while not is_prime[x]:  x += 1        # 找最小质数
6.     否则:         while is_prime[x]:      x += 1        # 找最小非质数
7.     total += x - v
8. 返回 total
```

### 3.4 示例演算

![示例演算：nums 依次为 1、2、3、4 时共 3 次操作](images/bw180_q3_walkthrough.svg)

对示例 1 的 `nums = [1,2,3,4]`：

| 下标 | 值 | 要求 | 目标值 | 代价 |
|------|----|------|--------|------|
| 0 | 1 | 质数 | 2（1 不是质数） | +1 |
| 1 | 2 | 非质数 | 4（2、3 都是质数） | +2 |
| 2 | 3 | 质数 | 3（已是质数） | 0 |
| 3 | 4 | 非质数 | 4（已是非质数） | 0 |

总代价 $1 + 2 + 0 + 0 = 3$ ✓。示例 3 的 `[4,4]`：下标 0 的 4 要变质数 → 5，+1；下标 1 的 4 已是非质数 → 0；合计 1 ✓。

## 4. 算法细节

1. **筛法范围**：$nums[i] \le 10^5$，偶数下标可能要找下一个质数，$10^5$ 之后最近的质数是 100003，再远也不会超过 $10^5 + 200$，所以筛到 $2\times10^5$ 绝对安全。
2. **筛法实现**：`is_prime[0] = is_prime[1] = false`，从 2 开始把倍数标记为非质数。注意 1 必须显式设为非质数（否则会被误判为质数，导致 `[1]` 这类输入出错）。
3. **C++ 用 `static` 只筛一次**：函数内 `static const vector<char> isPrime = buildSieve();`，多次调用不会重复计算。
4. **代价累加用 64 位**：单个位置最多加几十，$n = 10^5$，总和远小于 $10^9$，`int` 也够；但用 `long long` 更保险（尤其扩展到更大值域时）。
5. **循环终止性**：`while (!is_prime[x]) x++;` 一定终止，因为质数有无穷多个且间隔有限；实践中几步就能撞上。
6. **不要用「奇偶」代替「质数」**：2 是偶数但它是质数，奇数位上的 2 需要 +2；这是最容易踩的坑。

## 5. 正确性证明

**引理 1（可分解性）**：设 $c_i$ 为把第 $i$ 个元素变为满足其奇偶位要求所需的最少操作数，则总最少操作数 $= \sum_i c_i$。

**证明**：每次操作只改变一个元素，且每个元素的最终取值只受它自己的操作次数影响，因此各元素的约束相互独立。任何合法方案对第 $i$ 个元素至少做了 $c_i$ 次操作（因为 $c_i$ 是单点最小），所以总次数 $\ge \sum c_i$；反之，对每个元素各做 $c_i$ 次即得合法方案，总次数 $= \sum c_i$。∎

**引理 2（$c_i$ 的刻画）**：若 $i$ 为偶数，$c_i = p - nums[i]$，其中 $p$ 是 $\ge nums[i]$ 的最小质数；若 $i$ 为奇数，$c_i = q - nums[i]$，其中 $q$ 是 $\ge nums[i]$ 的最小非质数。

**证明**：只能做加法，所以 $k$ 次操作后元素值为 $nums[i] + k$。需要它满足奇偶位要求，于是 $k$ 必须使 $nums[i]+k$ 落在目标集合里；最小可行 $k$ 即「目标集合中不小于 $nums[i]$ 的最小值」与 $nums[i]$ 的差。∎

**引理 3（循环确实找到该值）**：`while` 循环结束时 $x$ 恰为「目标集合中 $\ge nums[i]$ 的最小值」。

**证明**：循环每次把 $x$ 加 1 直到条件满足，从 $x = nums[i]$ 开始，故结束时的 $x$ 是第一个满足条件的值，也就是最小值。终止性由上文的间隔结论保证。∎

**定理**：算法返回把 `nums` 变为交替质数数组的最少操作次数。

**证明**：由引理 3，算法对每个位置算出引理 2 中的 $c_i$，并累加；由引理 1，该和即总最少操作数。∎

## 6. 复杂度分析

- **时间**：筛法 $O(LIM \log \log LIM)$，其中 $LIM = 2\times10^5$；逐位置处理 $O(n \cdot g)$，$g$ 为「到下一个合法值」的步数（偶数下标 $g$ 很小，奇数下标 $g \le 2$）。总体 $O(LIM \log\log LIM + n)$，实际运行中 $n$ 项占主导。
- **空间**：$O(LIM)$ 的质数标记数组（约 200 KB），与 $n$ 无关。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minOperations(vector<int>& nums) {
        static const vector<char> isPrime = buildSieve();
        long long total = 0;
        for (int i = 0; i < (int)nums.size(); i++) {
            long long x = nums[i];
            if (i % 2 == 0) {
                while (!isPrime[x]) x++;
            } else {
                while (isPrime[x]) x++;
            }
            total += x - nums[i];
        }
        return (int)total;
    }

private:
    static vector<char> buildSieve() {
        const int LIM = 200000;
        vector<char> p(LIM + 1, 1);
        p[0] = p[1] = 0;
        for (long long i = 2; i * i <= LIM; i++) {
            if (!p[i]) continue;
            for (long long j = i * i; j <= LIM; j += i) p[j] = 0;
        }
        return p;
    }
};
```

### Python

```python
class Solution:
    def minOperations(self, nums: list[int]) -> int:
        LIMIT = 200000
        is_prime = [True] * (LIMIT + 1)
        is_prime[0] = is_prime[1] = False
        p = 2
        while p * p <= LIMIT:
            if is_prime[p]:
                for q in range(p * p, LIMIT + 1, p):
                    is_prime[q] = False
            p += 1

        total = 0
        for i, v in enumerate(nums):
            x = v
            if i % 2 == 0:
                while not is_prime[x]:
                    x += 1
            else:
                while is_prime[x]:
                    x += 1
            total += x - v
        return total
```

## 8. 边界情况与易错点

1. **1 不是质数**：`nums[i] = 1` 且在偶数下标时要 +1 到 2；若筛法里忘了把 1 标成非质数，会得出 0 次操作，答案偏小。
2. **2 是质数**：奇数下标上的 2 要 +2 到 4，而不是 +1 到 3。这是本题最经典的 WA 点。
3. **0 不是质数**：虽然约束里 $nums[i] \ge 1$，但如果扩展到 0，要注意 0 也是非质数。
4. **下标从 0 开始**：偶数下标要质数。若把规则记反（奇数下标要质数），示例 1 的答案会变成别的数。
5. **筛法上界**：只筛到 $10^5$ 可能在「$nums[i]$ 就是 $10^5$ 附近的最大质数」时越界，务必留出余量（本文筛到 $2\times10^5$）。
6. **重复调用**：C++ 里如果每次都重建筛子，$10^5$ 次调用会退化；用 `static` 只构建一次。
7. **答案类型**：最大约 $n \times 100 = 10^7$，`int` 足够，但用 `long long` 更稳。
