# LeetCode 统计数字出现总次数 题解

## 1. 题目概述

- **标题 / 题号**：统计数字出现总次数（#3895，medium）
- **链接**：https://leetcode.cn/problems/count-digit-appearances/
- **来源**：LeetCode 第 180 场双周赛 Q2
- **难度**：中等
- **标签**：数组、数学

**题意**：给定整数数组 `nums` 和一个数字 `digit`（$0 \sim 9$），统计 `digit` 在所有元素的**十进制表示**中出现的**总次数**。例如 `12` 中数字 `2` 出现 1 次，`22` 中出现 2 次。

**约束**：

- $1 \le \text{nums.length} \le 1000$
- $1 \le nums[i] \le 10^6$
- $0 \le digit \le 9$

## 2. 示例

**示例 1**

```text
输入：nums = [12,54,32,22], digit = 2
输出：4
解释：12 → 1 次；54 → 0 次；32 → 1 次；22 → 2 次。合计 1+0+1+2 = 4。
```

**示例 2**

```text
输入：nums = [1,34,7], digit = 9
输出：0
解释：所有数里都没有数字 9。
```

**示例 3（自测）**

```text
输入：nums = [1000000], digit = 0
输出：6
解释：1000000 中间有 6 个 0。
```

## 3. 解题思路

### 3.1 暴力思路

本题「暴力」就是正解：把每个数转成十进制字符串，逐字符比较并计数。总位数不超过 $1000 \times 7 = 7000$，任何语言都是瞬间完成。

真正需要注意的是**枚举粒度**：既可以把每个数拆成字符串（实现最简单），也可以反复取模 10 逐位剥离（不需要额外内存）。两者复杂度同为 $O(\text{总位数})$。

### 3.2 核心观察：按「位」统计，逐个元素独立累加

![统计数字出现总次数：每个数拆成十进制串逐个字符比对](images/bw180_q2_digits.svg)

- **可加性**：总次数 = 每个数中该数字出现次数之和。各元素之间互不影响，一个循环累加即可。
- **十进制表示唯一**：每个数只有一种写法，不存在歧义（注意题面给的是**正整数**，没有前导零；若允许 0，`to_string(0)` 是 `"0"`，也天然正确）。
- **`digit = 0` 的处理**：转字符串后 `"0"` 参与比较，零的个数自然被统计；用取模剥离法时要注意「数本身是 0」的边界（本题 $nums[i] \ge 1$，不会出现）。

### 3.3 算法流程

![算法流程：外层遍历数组，内层遍历字符](images/bw180_q2_flow.svg)

```text
1. target = digit 对应的字符（'0' + digit）
2. total = 0
3. for x in nums:
4.     s = 十进制字符串(x)
5.     for c in s:
6.         若 c == target: total += 1
7. 返回 total
```

### 3.4 示例演算

对示例 1 的 `nums = [12,54,32,22]`、`digit = 2`：

| 元素 | 十进制 | 逐位 | 命中次数 | 累计 |
|------|--------|------|---------|------|
| 12 | `"12"` | 1, 2 | 1（末位） | 1 |
| 54 | `"54"` | 5, 4 | 0 | 1 |
| 32 | `"32"` | 3, 2 | 1（末位） | 2 |
| 22 | `"22"` | 2, 2 | 2 | **4** |

返回 4 ✓。示例 2 中 `digit = 9`，三个数分别是 `"1"`、`"34"`、`"7"`，没有字符 `'9'`，返回 0 ✓。

## 4. 算法细节

1. **字符串路线**：C++ `to_string(x)` 后逐字符比较；Python 直接 `str(x).count(str(digit))`，一行即可。
2. **取模路线**：`while (x > 0) { if (x % 10 == digit) total++; x /= 10; }`。注意它对 $x = 0$ 不产生任何计数，需要单独处理（本题 $nums[i] \ge 1$，可忽略）。
3. **`digit` 转字符**：C++ 里 `char('0' + digit)`；Python 里 `str(digit)`。别把整数 `digit` 直接与字符比较。
4. **累加类型**：最多 $1000 \times 7 = 7000$ 次命中，`int` 足够。
5. **不要把「数字出现次数」理解成「包含该数字的元素个数」**：`22` 要算 2 次，这是本题唯一的语义陷阱。

## 5. 正确性证明

**引理 1（按元素可加）**：设 $f(x)$ 为数字 $d$ 在 $x$ 的十进制表示中出现的次数，则所有元素中 $d$ 的总出现次数为 $\sum_{x \in nums} f(x)$。

**证明**：元素之间互相独立，每个元素贡献它自己那部分，累加即为全体计数。∎

**引理 2（字符比较等价于数位比较）**：对正整数 $x$，$x$ 的十进制字符串的第 $k$ 个字符恰为 $x$ 的第 $k$ 位数字；因此「字符 $c = $ `'0'+d` 出现的次数」等于「数位等于 $d$ 的个数」。

**证明**：十进制表示的唯一性保证了字符串与数位序列一一对应，字符编码 `'0'+d` 与数字 $d$ 一一对应（$0 \le d \le 9$）。∎

**定理**：算法返回 `digit` 在 `nums` 所有元素十进制表示中的总出现次数。

**证明**：算法对每个元素统计其字符串中 `target` 的出现次数并累加；由引理 1 与引理 2，该累加值等于所有元素中数位等于 `digit` 的总个数，即所求。∎

## 6. 复杂度分析

- **时间**：$O(\sum_i \log_{10} nums[i])$，即总位数。最大约 $1000 \times 7 = 7000$ 次字符比较。
- **空间**：$O(1)$ 额外空间（字符串副本长度为 $O(\log nums[i])$，可视作常数或 $O(\log \max nums)$）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int countDigitOccurrences(vector<int>& nums, int digit) {
        char target = (char)('0' + digit);
        int total = 0;
        for (int x : nums) {
            string s = to_string(x);
            for (char c : s)
                if (c == target) total++;
        }
        return total;
    }
};
```

### Python

```python
class Solution:
    def countDigitOccurrences(self, nums: list[int], digit: int) -> int:
        target = str(digit)
        return sum(str(x).count(target) for x in nums)
```

## 8. 边界情况与易错点

1. **一个数里出现多次**：`22` 中 `2` 出现 2 次，必须逐位计数，不能只判「包含」。
2. **`digit = 0`**：`1000000` 贡献 6 次。若用取模法，注意 `nums[i] = 0` 的情况（本题不会出现，但扩展时要考虑）。
3. **统计的是字符不是子串**：`digit` 是单个数字，与 `"12"` 中的 `"12"` 子串无关。
4. **不要把 `digit` 当整数比较**：`x % 10 == digit` 是整数比较，`char c == digit` 则是字符与整数比较，`'2' != 2`，很容易写混。
5. **元素个数与位数**：$nums[i]$ 最大 $10^6$（7 位），不要用 `int` 的位数上限（10 位）去估算数组大小。
6. **返回值类型**：`int` 足够；若数据规模放大到 $10^5$ 个 $10^{18}$ 的数，总量约 $1.9\times10^6$，仍是 `int` 范围（但建议用 `long long` 保守处理）。
