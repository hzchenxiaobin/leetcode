# LeetCode 连接二进制片段得到的最大值 题解

## 1. 题目概述

- **标题 / 题号**：连接二进制片段得到的最大值（#3897，hard）
- **链接**：https://leetcode.cn/problems/maximum-value-of-concatenated-binary-segments/
- **来源**：LeetCode 第 180 场双周赛 Q4
- **难度**：困难
- **标签**：贪心、数组、排序

**题意**：给定两个长度都为 $n$ 的数组 `nums1`、`nums0`。对每个下标 $i$，构造一个二进制片段：**先 `nums1[i]` 个 `1`，再 `nums0[i]` 个 `0`**（记作 $1^{a}0^{b}$，其中 $a = nums1[i]$、$b = nums0[i]$）。

可以把这些片段以**任意顺序**重新排列，然后拼接成一个长二进制串，求这个二进制串所能表示的**最大整数值**，对 $10^9+7$ 取模后返回。

**约束**：

- $1 \le n \le 10^5$
- $0 \le nums1[i], nums0[i] \le 10^4$，且 $nums1[i] + nums0[i] > 0$
- `nums1` 与 `nums0` 的元素总和不超过 $2\times10^5$

## 2. 示例

**示例 1**

```text
输入：nums1 = [1,2], nums0 = [1,0]
输出：14
解释：片段为 "10" 与 "11"。排成 "11"+"10" = "1110"₂ = 14；
      "10"+"11" = "1011"₂ = 11。最大值 14。
```

**示例 2**

```text
输入：nums1 = [3,1], nums0 = [0,3]
输出：120
解释：片段为 "111" 与 "1000"。排成 "111"+"1000" = "1111000"₂ = 120；
      反过来是 "1000111"₂ = 71。最大值 120。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有 $n!$ 种排列，逐个拼接求值。$n \le 10^5$ 时完全不可行；即使 $n \le 8$ 也只能用来对拍。

暴力的失败也提示了正确的方向：排列数虽多，但**任意排列的总长度相同**（都是 $\sum(a+b)$），所以「最大整数」等价于「字典序最大的二进制串」。而字典序比较是可以**局部化**的——只要两两比较，就能用排序解决。

### 3.2 核心观察：相邻两段谁在前，只需比较 $A{+}B$ 与 $B{+}A$

![每个片段是 1^a 0^b，重排顺序决定最终二进制数](images/bw180_q4_segments.svg)

**观察 1：总长固定 ⇒ 比的是字典序。** 所有排列拼出来长度一样，二进制串长度相同时，字典序大 ⟺ 数值大。

**观察 2：只需要两两比较。** 对于相邻的两段 $A = 1^{a_1}0^{b_1}$、$B = 1^{a_2}0^{b_2}$，「$A$ 在前」是否优于「$B$ 在前」，只取决于 $A{+}B$ 与 $B{+}A$ 的大小。这是经典的「排序后拼接最优」范式：定义比较器 $A \prec B \iff A{+}B \le B{+}A$，按它排序即可（下文证明它确实是全序，且排序结果最优）。

**观察 3：这个比较可以写成 $O(1)$ 的封闭规则。** 直接逐字符比较 $A{+}B$ 与 $B{+}A$（长度可能上万，排序时反复比较会超时）不如用下面这套规则：

| 情形 | 谁在前 |
|------|--------|
| $b_1 = b_2 = 0$（都是全 1） | 相等，随便 |
| $b_1 = 0,\ b_2 > 0$ | $A$ 在前 |
| $b_2 = 0,\ b_1 > 0$ | $B$ 在前 |
| $b_1, b_2 > 0$，$a_1 \ne a_2$ | $a$ 大的在前 |
| $b_1, b_2 > 0$，$a_1 = a_2$ | $b$ 小的在前 |

![排序规则：按 S^∞ = (1^a 0^b)^∞ 从大到小](images/bw180_q4_order.svg)

直觉上可以用「无限重复串」来理解：把每段视为无限串 $(1^{a}0^{b})^{\infty}$，谁的无限串字典序更大就排前面。原因很直观——拼接后每段后面还会接更多片段，而「后面接什么」正是无限串在比较的东西。上表的规则就是把这种比较落地成 $O(1)$ 的判断。

> ⚠️ **只按 $a$ 降序排是错的**：全 1 段（$b = 0$）必须排在最前面，即使它的 $a$ 不是最大的。示例 1 里 `"11"`（$a=2,b=0$）就排在 `"10"`（$a=1,b=1$）前面；而如果两段分别是 $(a{=}5,b{=}5)$ 与 $(a{=}3,b{=}0)$，答案是后者在前——因为全 1 段没有任何 0 来「拖后腿」。

### 3.3 算法流程

![拼接求值：每段 O(log) 地乘进去](images/bw180_q4_concat.svg)

```text
1. 把 (nums1[i], nums0[i]) 视作片段，用上面的 O(1) 比较器排序（按索引排序，避免复制长串）
2. res = 0
3. for (a, b) in 排序后的片段:
4.     block = (2^a − 1) · 2^b        mod MOD        # 该段的二进制值
5.     res = res · 2^(a+b) + block   mod MOD        # 旧串整体左移，再接上新段
6. 返回 res
```

第 4 步的依据：$1^{a}0^{b}$ 的二进制值就是 $2^{a}-1$ 再左移 $b$ 位。第 5 步是标准的「拼接 = 旧的左移 + 新的」。

### 3.4 示例演算

对示例 1 的 `nums1 = [1,2]`、`nums0 = [1,0]`，两段是 $A=(1,1)$、$B=(2,0)$：

- 比较：$b_2 = 0$ 且 $b_1 = 1 > 0$ ⇒ $B$ 在前（全 1 段优先）。
- 拼接：`"11" + "10" = "1110"`。
- 求值：$\text{block}(B) = (2^2-1)\cdot 2^0 = 3$，于是 $res = 0\cdot 2^2 + 3 = 3$；再处理 $A$：$\text{block}(A) = (2^1-1)\cdot 2^1 = 2$，$res = 3\cdot 2^2 + 2 = 14$ ✓。

对示例 2：$A=(3,0)$、$B=(1,3)$，$b_1 = 0$ ⇒ $A$ 在前。$res = 0\cdot 2^3 + 7 = 7$，再 $res = 7\cdot 2^4 + \text{block}(1,3)$，而 $\text{block}(1,3) = (2-1)\cdot 2^3 = 8$，得 $7\times 16 + 8 = 120$ ✓。

## 4. 算法细节

1. **比较器必须是严格弱序**：`cmp(A,B)` 在「两段相等」或「都全 1」时返回 `false`（不认为 A 严格小于 B），保证 `sort` 行为良好。C++ 里建议对**下标**排序，避免移动长度上万的字符串。
2. **不能真的拼字符串**：总长可达 $2\times10^5$，排序时若每次都拼接比较，单次比较就是 $O(a+b)$，总计 $O(n\log n \cdot \text{len})$ 会超时（虽然本题 $\sum$ 只有 $2\times10^5$，理论上还能过，但不是好习惯）。
3. **求值公式**：`block(a,b) = (2^a − 1) · 2^b`，注意 `(2^a − 1)` 在取模后要用 `+MOD` 修正成非负。
4. **快速幂**：$a+b \le 2\times10^4$，快速幂每次 $O(\log(a+b))$，总 $O(n \log)$。也可以预处理到 $2\times10^5$ 的 2 的幂表，$O(1)$ 查询。
5. **取模**：`res` 每次先乘 `2^(a+b)` 再加 `block`，两步都要取模；中间值 $<10^{18}$，`long long` 安全。
6. **答案类型**：返回 `int`（模 $10^9+7$ 后的值），但中间计算必须 64 位。

## 5. 正确性证明

**记号**：片段 $A = 1^{a_1}0^{b_1}$（$a_1+b_1>0$），$B = 1^{a_2}0^{b_2}$。记 $\text{val}(S)$ 为二进制串 $S$ 的数值。

**引理 1（等长 ⟹ 字典序即大小）**：若两个二进制串长度相同，则 $\text{val}(S) > \text{val}(T) \iff S$ 字典序大于 $T$。

**证明**：长度相同时，字典序比较从最高位到最低位，第一个不同位上的 1 决定大小，这正好对应数值大小（低位的权重总和不足以抵消一个高位差：$2^k > \sum_{j<k}2^j$）。∎

**引理 2（两段比较的封闭形式）**：$A{+}B$ 与 $B{+}A$ 的大小关系由 3.2 节的表给出。

**证明**：逐情形比较两串。

- $b_1=b_2=0$：$A{+}B = B{+}A = 1^{a_1+a_2}$，相等。
- $b_1=0,\ b_2>0$：$A{+}B = 1^{a_1+a_2}0^{b_2}$，$B{+}A = 1^{a_2}0^{b_2}1^{a_1}$。前 $a_2$ 位都是 1；第 $a_2+1$ 位上 $A{+}B$ 仍是 1（因为 $a_1>0$，$A$ 非空且全 1），而 $B{+}A$ 是 0（$b_2>0$）。故 $A{+}B > B{+}A$。
- $b_2=0,\ b_1>0$：与上一条对称，$B{+}A > A{+}B$。
- $b_1,b_2>0$ 且 $a_1>a_2$：前 $a_2$ 位都是 1；第 $a_2+1$ 位上 $A{+}B$ 是 1（$A$ 还有 1），$B{+}A$ 是 0（$B$ 进入 0 段）。故 $A{+}B > B{+}A$。$a_1<a_2$ 对称。
- $b_1,b_2>0$ 且 $a_1=a_2=a$：前 $a$ 位都是 1；之后 $A{+}B$ 有 $b_1$ 个 0、$B{+}A$ 有 $b_2$ 个 0。若 $b_1<b_2$，则在第 $a+b_1+1$ 位 $A{+}B$ 是 1（$B$ 的 1 段，$a_2=a\ge1$）而 $B{+}A$ 还是 0，故 $A{+}B > B{+}A$；若 $b_1=b_2$ 则两串相同。∎

**引理 3（比较器是全序）**：关系 $A \preceq B \iff A{+}B \le B{+}A$ 是定义在所有片段上的全预序（自反、传递、完全）。

**证明**：对每段取键 $\big(\text{是否全 1 段},\ -a,\ b\big)$（全 1 段取 1，否则取 0）。由引理 2：若两段不都是全 1 段，则 $A{+}B \le B{+}A$ 恰好等价于「$A$ 的键字典序不大于 $B$ 的键」；若两段都是全 1 段，则不论键如何，$A{+}B = B{+}A$，视为等价。元组字典序是全序，而等价类（拼接结果相同的段）内部互换不影响任何拼接值，故 $\preceq$ 是良定义的全预序，可安全地交给 `sort` 使用。∎

**引理 4（相邻交换不降低结果）**：若在某排列中相邻两段 $A$（前）$B$（后）满足 $B{+}A > A{+}B$，则交换这两段后，整个拼接串的**数值不减**。

**证明**：交换前后，两段之外的其它片段位置与内容都不变，且 $A$、$B$ 的总长度不变，所以拼接串只有中间这一段从 $A{+}B$ 变成 $B{+}A$，前后缀完全相同且长度相同。由引理 1，数值比较等价于字典序；字典序在相同前缀后由中间块决定，故新串 $\ge$ 旧串。∎

**定理**：按引理 3 的比较器排序得到的排列，其拼接串数值最大。

**证明**：设排序结果为 $\sigma^\*$，任取另一排列 $\sigma$。把 $\sigma$ 通过**相邻交换**逐步变换为 $\sigma^\*$：标准结论是，只要存在逆序对（相邻且 $A \preceq B$ 但 A 在后），就可以交换它们并使排列更接近有序，重复有限次即可到达 $\sigma^\*$。每次交换的都是「$B$ 应在前」的逆序对，由引理 4 数值不减。因此 $\text{val}(\sigma^\*) \ge \text{val}(\sigma)$。由 $\sigma$ 的任意性，$\sigma^\*$ 最大。∎

**引理 5（求值递推正确）**：按顺序依次执行 `res ← res·2^(a+b) + (2^a−1)·2^b`，最终 `res` 等于拼接串的数值。

**证明**：对片段的个数归纳。设当前 `res` 是已拼接前缀的数值，长度为 $L$。新段 $1^a0^b$ 长度为 $a+b$，其数值为 $(2^a-1)2^b$。把新段接在长度为 $L$ 的前缀后面，相当于把前缀左移 $a+b$ 位后再加上新段，即 $\text{res}\cdot 2^{a+b} + (2^a-1)2^b$。取模保持同余，故最终 `res` 与真实数值同余。∎

## 6. 复杂度分析

- **时间**：排序 $O(n \log n)$ 次 $O(1)$ 比较；求值 $n$ 次快速幂，每次 $O(\log(a+b))$，即 $O(n \log \max(a+b))$。总计 $O(n\log n + n\log \max L)$。
- **空间**：$O(n)$ 存索引与片段信息（若原地排序可省）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maxValue(vector<int>& nums1, vector<int>& nums0) {
        const long long MOD = 1000000007LL;
        int n = (int)nums1.size();
        vector<int> idx(n);
        for (int i = 0; i < n; i++) idx[i] = i;
        sort(idx.begin(), idx.end(), [&](int i, int j) {
            int a1 = nums1[i], b1 = nums0[i];
            int a2 = nums1[j], b2 = nums0[j];
            if (b1 == 0 && b2 == 0) return false;
            if (b1 == 0) return true;
            if (b2 == 0) return false;
            if (a1 != a2) return a1 > a2;
            if (b1 != b2) return b1 < b2;
            return false;
        });

        long long res = 0;
        for (int i : idx) {
            long long a = nums1[i], b = nums0[i];
            long long block = (modPow(2, a) - 1 + MOD) % MOD * modPow(2, b) % MOD;
            res = (res * modPow(2, a + b) % MOD + block) % MOD;
        }
        return (int)(res % MOD);
    }

private:
    long long modPow(long long base, long long exp) {
        const long long MOD = 1000000007LL;
        long long res = 1;
        base %= MOD;
        while (exp > 0) {
            if (exp & 1) res = res * base % MOD;
            base = base * base % MOD;
            exp >>= 1;
        }
        return res;
    }
};
```

### Python

```python
from functools import cmp_to_key

class Solution:
    def maxValue(self, nums1: list[int], nums0: list[int]) -> int:
        MOD = 10 ** 9 + 7

        def cmp(x, y):
            a1, b1 = x
            a2, b2 = y
            if b1 == 0 and b2 == 0:
                return 0
            if b1 == 0:
                return -1
            if b2 == 0:
                return 1
            if a1 != a2:
                return -1 if a1 > a2 else 1
            if b1 != b2:
                return -1 if b1 < b2 else 1
            return 0

        segs = sorted(zip(nums1, nums0), key=cmp_to_key(cmp))
        res = 0
        for a, b in segs:
            res = (res * pow(2, a + b, MOD) + (pow(2, a, MOD) - 1) * pow(2, b, MOD)) % MOD
        return res % MOD
```

## 8. 边界情况与易错点

1. **全 1 段必须最前**：$b = 0$ 的片段不含 0，把它排在前面能立刻抬高高位。只按 $a$ 降序会把它埋在后面（示例 1 就是反例：$(a{=}2,b{=}0)$ 与 $(a{=}1,b{=}1)$）。
2. **全 0 段必须最后**：$a = 0$（片段全是 0）时它的无限串是 $0^\infty$，最小，应排在末尾。代码里由「$a$ 降序」自然满足（$a=0$ 最小）。
3. **比较器不能用「拼接字符串」实现**：虽然本题总长只有 $2\times10^5$，但排序中反复拼接仍是浪费；更重要的是要意识到 $a$、$b$ 可以到 $10^4$，必须用封闭形式。
4. **严格弱序**：两个相同片段之间比较必须返回 `false`，否则 `std::sort` 可能越界。
5. **取模位置**：`(2^a − 1)` 可能取模后为 0（例如 $2^a \equiv 1$），要保证结果非负；`res` 与 `block` 相加后再取模。
6. **单段情形**：$n = 1$ 时无需排序，直接算 `block`。代码无需特判。
7. **片段非空**：约束保证 $a+b>0$，所以不会出现空串；但若扩展允许空串，比较器需要额外处理。
8. **总长与指数**：$\sum(a+b) \le 2\times10^5$，单段 $a+b \le 2\times10^4$，快速幂指数不会溢出 `int`。
