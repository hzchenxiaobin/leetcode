# LeetCode 祖玛游戏 题解

## 1. 题目概述
- **标题 / 题号**：祖玛游戏（#488，hard）
- **链接**：https://leetcode.cn/problems/zuma-game/
- **来源**：LeetCode 第 15 场周赛 Q3
- **难度**：困难
- **标签**：栈、广度优先搜索、记忆化搜索、字符串、动态规划

**题意**：桌面一排彩球 `board`，手中一袋球 `hand`（颜色只有 `R/Y/B/G/W`）。每回合从手中取**一颗**插入桌面任意位置（两球间或两端）；若出现连续 $\ge 3$ 颗同色球就整段移除，移除后两侧同色球合并成 $\ge 3$ 连则继续移除（**连锁**）直到稳定。求清空桌面所需**最少**球数，清不空返回 `-1`。

**约束**：$1 \le \lvert\texttt{board}\rvert \le 16$，$1 \le \lvert\texttt{hand}\rvert \le 5$，只含 `'R' 'Y' 'B' 'G' 'W'`；初始盘面**不存在**连续 $\ge 3$ 颗同色球。
> 💡 **题眼**：手牌最多 5 颗，搜索深度很浅；难点是**枚举哪些插入**——既能砍掉废步，又不能漏解。

## 2. 示例
**示例 1**
```text
输入：board = "WRRBBW", hand = "RB"
输出：-1
解释：最好只能做到 WRRRBBW → WBBW → WW，仍剩球，两颗粒手牌用尽。
```

**示例 2**
```text
输入：board = "WWRRBBWW", hand = "WRBRW"
输出：2
解释：插 R 得 WWRRRBBWW → WWBBWW；再插 B 得 WWBBBWW → WWWW → 空。
```

## 3. 解题思路

### 3.1 暴力思路

把「盘面 + 剩余手牌」当状态做 BFS：每步枚举「插入位置 $i \in [0,n]$」×「手中某颗球」再模拟连锁消除。分支最多 $(n+1)\lvert\texttt{hand}\rvert \le 110$，深度 $\le 5$，朴素搜索树上界 $110^5\approx1.6\times10^{10}$，不可行；只加记忆化也不够——绝大多数分支是「插进去什么都不消」的废步，状态数照样被撑爆，必须剪枝。

### 3.2 核心观察：候选插入只有两类

![候选插入只有两类](images/wc15_q3_insert_rule.svg)

稳定盘面里没有 $\ge 3$ 的段，所以每段长度只有 1 或 2：**单球**或**对子**。能改变局面结构的插入只有两种：

1. **贴同色**：$c$ 与左邻或右邻同色。某段长度 $+1$——对子变三连立即消除，单球变对子为后续铺路。
2. **拆对子**：把异色球插进对子中间，`RR` 变成 `R?R`。一对球被拆成两个单球，既阻止它们日后合并，也改变了相邻段合并时的算术。

而**异色停在两个异色段之间**不必试：左右两段颜色不同，本来就不会合并；这颗球既不拆对子、也不让任何段变长，插入后是孤立球。它要消失只能靠「同色球被插到它旁边」或「左/右段先被整段消掉、它接上更远的同色段」，两种时机都能把这次插入**推迟过去**；而它被消除后只是把「异色—异色」的相邻关系原样还原，净收益为零。

> ⚠️ 因此「只贴同色」并不是完备剪枝。反例：`board = "RRYRRYYRR"`、`hand = "YYYBB"` 答案是 $3$，第一步必须把 `Y` 插进 `RR` 中间（左右都不同色）：`RRYRRYYRR → RYRYRRYYRR → RYRYYRRYYRR → 空`。只按「贴同色」枚举会误判成 `-1`。

再加两条纯优化剪枝：**盘面上不存在的颜色一次都不插**（它永远凑不出 3 连，最后必然留在桌上）；**某颜色「盘面数 + 手牌数」$<3$ 时直接无解**。同位置同色去重、结果盘面去重也都要做。

### 3.3 算法流程

![记忆化 DFS 流程](images/wc15_q3_search_flow.svg)

定义 $\mathrm{dfs}(b,h)$ = 从「盘面 $b$、手牌多重集 $h$」出发清空桌面所需的最少球数：

1. $b$ 为空 → 返回 $0$；$h$ 为空而 $b$ 非空 → 返回 $\infty$。
2. 枚举候选 $(i,c)$：贴同色的段边界，或对子中间的缝配异色；跳过盘面无此色的 $c$，同色手牌只试一次。
3. 插入得 $b'=b[:i]+c+b[i:]$、手牌删去一颗 $c$ 得 $h'$，对 $b'$ 做 $\mathrm{shrink}$；$b'$ 已空候选值为 $1$，否则为 $1+\mathrm{dfs}(b',h')$；同一局面用 `seen` 去重，所有候选取最小写入记忆化表，最终 $\ge\infty$ 输出 `-1`。

> ⚠️ 必须**先插入、再消除**：消除会让盘面变短甚至为空，之后的递归才有意义。

### 3.4 示例演算

![示例 2 两步走查](images/wc15_q3_example_walkthrough.svg)

以 `board = "WWRRBBWW"`、`hand = "WRBRW"` 为例：

| 步骤 | 操作 | 插入后盘面 | 连锁消除结果 |
|------|------|------------|--------------|
| 1 | 在 `RR` 中间插 `R` | `WW RRR BB WW` | 删 `RRR` → `WW BB WW` |
| 2 | 在 `BB` 中间插 `B` | `WW BBB WW` | 删 `BBB` → `WWWW` → 再删 → 空 |

第 2 步之后两侧 `WW` 合并成四连 `WWWW`，必须**继续消除**才能清空——这就是「连锁」，最易写漏，答案 $2$。示例 1 的 `WRRBBW` 则相反：手牌只有 `RB` 两颗，先插哪颗都只能让一段凑够 3，另一段必然残留（`WRRBBW → WRRRBBW → WBBW → WW`），故返回 `-1`。

## 4. 算法细节
1. **消除模拟**：每次只删「第一段长度 $\ge 3$ 的段」再重扫。稳定局面没有 $\ge 3$ 段，一次插入至多造出一个新的 $\ge 3$ 段，删掉它也只可能合并出一个新段，所以任一时刻至多一段 $\ge 3$——「一次性删光所有 $\ge 3$ 段」与逐段删除等价，Python 用正则 `re.sub` 就是安全的。
2. **两类候选**：段边界 $i=0$、$i=n$、或 `b[i-1] != b[i]`，此时只取 $c$ 等于左邻或右邻的颜色；对子的缝 $0<i<n$ 且 `b[i-1] == b[i]`，此时只取 $c$ 不等于该颜色（等于就退化成段首插入）。
3. **去重三板斧**：同位置同色只试一次（先排序手牌）；同一状态下相同的结果盘面 `b'` 只搜一次；记忆化键用 `board + "#" + sorted(hand)`。必要性剪枝（某颜色总数 $<3$ 直接无解）根节点判一次即可，也可每层都判。
4. **不可行用 $\infty$**：C++ 取 `const int INF = 1e9`，比较前先确认 `sub < INF`，否则 `INF + 1` 参与 `min` 会被误当可行；最后 `ans >= INF` 才输出 `-1`。最小答案不可能小于 1，某分支得 1 即提前返回；长度 $\le21$，直接切片拼接即可，别改成引用加回溯。

## 5. 正确性证明

**引理 1（消除过程确定且正确）**：对「无 $\ge 3$ 段」的盘面插入一颗球后，反复删除长度 $\ge 3$ 的同色段，最终盘面唯一，与删除顺序无关。

**证明**：初始无 $\ge 3$ 段，插入一颗球只让插入点所在那一段长度 $+1$，故**至多一段**达到 $\ge 3$。删除这一段后，其左右两段若同色则合并成**一段**，其余段长度不变，因此删完仍是「至多一段 $\ge 3$」。每一步可删的段唯一，过程确定；又每步严格缩短盘面，过程必然终止，终止盘面即 $\mathrm{shrink}$ 的结果。∎

**引理 2（剪枝不丢最优解）**：若从 $(B,H)$ 出发存在用 $k$ 颗球的解法，则存在用 $k$ 颗球的解法，其中每一步都满足：(a) 同色球不插进自己那段内部；(b) 不插盘面上不存在的颜色；(c) 异色球不停在两个不同颜色的段之间。

**证明**：由任一 $k$ 步解出发，逐个消除违规插入。

- (a) 同色球插在段 $T$ 内部，与插在 $T$ 的段首产生完全相同的盘面（段长 $+1$，两侧结构不变），后续过程逐字相同，步数不变。
- (b) 若 $c$ 不在盘面上，则插入的每颗 $c$ 最终只能与同为插入的 $c$ 球组成 $\ge 3$ 的段。把「插入这些 $c$ 球」与「删除它们所在的整段」一起删去：整段的删除会把该处的左右邻接关系还原（与从未插入时一致），于是剩下的步骤仍然是合法解，且用球更少，与 $k$ 的最小性矛盾。
- (c) 设某步把 $c$ 插在左邻 $p$、右邻 $q$ 之间，$p\ne c$、$q\ne c$、$p\ne q$。这颗球插入后是孤立球：它不在任何段内部，也不改变任何段长；而 $p\ne q$，它挡住的两个段本来就不会合并，所以它**不影响**任何一次消除。设它最终被删除，则在此之前必有一刻它首次与同色球相邻，只可能来自「某颗 $c$ 球被插到它旁边」或「$p$ 段 / $q$ 段先被整段删掉，它接上更远的 $c$ 段」。把这次插入推迟到那一刻、直接插在当场的同色球旁，其余步骤原序执行：它在等待期内对盘面毫无影响，故逐时刻盘面相同、步数不变，而违规插入被消去。反复把「第一个违规插入」往右推，即得全程满足 (a)(b)(c) 的 $k$ 步解。∎

**引理 3（$\mathrm{dfs}$ 返回最优值）**：对任意 $(b,h)$，$\mathrm{dfs}(b,h)$ 返回清空桌面所需最少球数，不可行时返回 $\infty$。

**证明**：对 $\lvert h\rvert$ 归纳。基础情形正确；设 $\lvert h\rvert=m$ 时结论对 $\le m-1$ 成立。若存在解法，由引理 2 有满足剪枝的最优解，其首步必在枚举范围内，$\mathrm{dfs}$ 会试到它；插入并 $\mathrm{shrink}$ 后的盘面由引理 1 唯一确定，其余最优值由归纳假设给出，取最小即最优。若无解，全部分支返回 $\infty$。∎

**定理**：`findMinStep(board, hand)` 返回清空桌面所需最少球数，无法清空时返回 `-1`。

**证明**：由引理 3，$\mathrm{dfs}$ 返回最少球数或 $\infty$；函数把 $\ge\infty$ 映射为 `-1`，其余原样输出，与题目要求一致。∎

## 6. 复杂度分析

- **时间**：单状态候选数 $O(n)$（段边界 $\times\le2$ 种颜色、对子缝 $\times\le4$ 种异色，合计 $\le 8n$ 量级），每个候选一次 $O(n)$ 插入加一次 $\mathrm{shrink}$（每轮 $O(n)$、最多 $O(n)$ 轮，故 $O(n^2)$）。记忆化后每个状态只算一次，总时间 $O\big(S\cdot n^2\big)$，$S$ 为可达状态数，最坏上界是搜索树规模 $O\big((8(n+1))^m\big)$；$n\le16$、$m\le5$，实际远小于上界（随机 $n=16,m=5$ 输入：Python 最坏约 $0.2$ s、多数 $<5$ ms，C++ 约 $3$ ms）。
- **空间**：$O\big(S\cdot(n+m)\big)$ 存记忆化表的盘面与手牌，另有 $O(m)$ 递归栈与每层 $O(n)$ 的 `seen` 集合。

## 7. 参考代码

### C++
```cpp
#include <algorithm>
#include <string>
#include <unordered_map>
#include <unordered_set>
using namespace std;

class Solution {
public:
    int findMinStep(string board, string hand) {
        // 必要性剪枝：某颜色在盘面 + 手牌中不足 3 颗，永远凑不出 3 连
        for (char c : string("RYBGW")) {
            int cnt = (int)count(board.begin(), board.end(), c) +
                      (int)count(hand.begin(), hand.end(), c);
            if (cnt > 0 && cnt < 3 && board.find(c) != string::npos) return -1;
        }
        sort(hand.begin(), hand.end());                 // 同色球不可区分
        unordered_map<string, int> memo;
        int ans = dfs(board, hand, memo);
        return ans >= INF ? -1 : ans;
    }
private:
    static const int INF = 1000000000;
    // 删掉第一段长度 >= 3 的同色球；没有则原样返回
    static string removeOnce(const string &s) {
        int n = (int)s.size();
        for (int i = 0; i < n;) {
            int j = i;
            while (j < n && s[j] == s[i]) j++;
            if (j - i >= 3) return s.substr(0, i) + s.substr(j);
            i = j;
        }
        return s;
    }

    static string shrink(string s) {                 // 连锁消除
        while (true) {
            string t = removeOnce(s);
            if (t == s) return s;
            s = t;
        }
    }

    int dfs(const string &b, const string &h, unordered_map<string, int> &memo) {
        if (b.empty()) return 0;
        if (h.empty()) return INF;
        string key = b + "#" + h;
        auto it = memo.find(key);
        if (it != memo.end()) return it->second;
        int best = INF, n = (int)b.size();
        unordered_set<string> seen;
        for (int i = 0; i <= n; i++) {
            bool pairGap = (i > 0 && i < n && b[i - 1] == b[i]);   // 对子中间的缝
            for (int k = 0; k < (int)h.size(); k++) {
                if (k > 0 && h[k] == h[k - 1]) continue;           // 同色只试一次
                char c = h[k];
                if (b.find(c) == string::npos) continue;           // 盘面没有的颜色
                if (pairGap) {
                    if (c == b[i - 1]) continue;                   // 同色插自己那段
                } else if (!((i < n && b[i] == c) || (i > 0 && b[i - 1] == c))) {
                    continue;                                      // 异色停异色边界
                }
                string nb = shrink(b.substr(0, i) + c + b.substr(i));
                if (!seen.insert(nb).second) continue;             // 同一局面只搜一次
                int sub = dfs(nb, h.substr(0, k) + h.substr(k + 1), memo);
                if (sub < INF) best = min(best, sub + 1);
                if (best == 1) break;                              // 不可能更小
            }
            if (best == 1) break;
        }
        memo[key] = best;
        return best;
    }
};
```

### Python
```python
import re
from functools import lru_cache
INF = 10 ** 9
_GROUP = re.compile(r'(.)\1{2,}')          # 长度 >= 3 的同色段


class Solution:
    def findMinStep(self, board: str, hand: str) -> int:
        def shrink(s):
            # 稳定局面没有 >=3 段，一次插入至多造出一个新 >=3 段，
            # 所以「一次删光所有 >=3 段」与「删一段再重扫」结果相同。
            while True:
                t = _GROUP.sub('', s)
                if t == s:
                    return s
                s = t

        # 必要性剪枝：盘面上的颜色若 盘面数 + 手牌数 < 3，永远凑不出 3 连
        for c in set(board):
            if board.count(c) + hand.count(c) < 3:
                return -1

        @lru_cache(maxsize=None)
        def dfs(b, h):
            if not b:
                return 0
            if not h:
                return INF
            on_board = set(b)
            best, n, seen = INF, len(b), set()
            for i in range(n + 1):
                pair_gap = 0 < i < n and b[i - 1] == b[i]      # 对子中间的缝
                last = None
                for k, c in enumerate(h):
                    if c == last:                              # 同色手牌只试一次
                        continue
                    last = c
                    if c not in on_board:                      # 盘面没有的颜色不插
                        continue
                    if pair_gap:
                        if c == b[i - 1]:                      # 同色插自己那段
                            continue
                    elif not ((i < n and b[i] == c) or (0 < i and b[i - 1] == c)):
                        continue                               # 异色停异色边界
                    nb = shrink(b[:i] + c + b[i:])
                    if nb in seen:                             # 同一局面只搜一次
                        continue
                    seen.add(nb)
                    sub = dfs(nb, h[:k] + h[k + 1:])
                    if sub + 1 < best:
                        best = sub + 1
                        if best == 1:
                            return best
            return best

        ans = dfs(board, tuple(sorted(hand)))
        return -1 if ans >= INF else ans
```

## 8. 边界情况与易错点
1. **「只贴同色」剪枝会漏解**：反例 `board = "RRYRRYYRR"`、`hand = "YYYBB"`，正确答案 $3$，而第一步要插在 `RR` 中间。凡是丢掉「拆对子」这一类候选的写法都可能 WA。
2. **必须连锁消除**：`WWBBBWW` 删掉 `BBB` 后两侧 `WW` 合并成 `WWWW`，还要继续删；只删一轮会得到错误答案（示例 2 会变成 -1）。
3. **`hand` 必须排序去重**：同色球不可区分，忘记排序会让记忆化键失去合并能力；Python 的 `list` 不能做缓存键，要转 `tuple`。**`-1` 与 $\infty$ 别混用**：不可行用 $\infty$ 传播，最后统一映射成 `-1`；若中途把 `-1` 当步数参与 `+1`，会得到 `0` 这类假答案。另外 `i == n` 时 `board[i]` 越界、只能看左邻，`i == 0` 反之，用带短路的条件最稳。
4. **单球盘面**：`board = "G"`、`hand = "GGGGG"` 答案是 `2` 而不是 `1`——一颗球只让它变成 2 连，够不到 3。
