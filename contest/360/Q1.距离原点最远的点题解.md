# LeetCode 距离原点最远的点 题解

## 1. 题目概述

- **标题 / 题号**：距离原点最远的点（#2833，easy）
- **链接**：https://leetcode.cn/problems/furthest-point-from-origin/
- **来源**：LeetCode 第 360 场周赛 Q1
- **难度**：简单
- **标签**：字符串、计数、贪心、数学

**题意**：在一条原点为 0 的数轴上，从原点出发，按字符串 `moves` 依次移动 $n$ 步。第 $i$ 步：若 `moves[i] = 'L'`，必须向左移 1 个单位；若 `moves[i] = 'R'`，必须向右移 1 个单位；若 `moves[i] = '_'`，向左向右任选其一。求 $n$ 步后可达的点中，距离原点**最远**的距离。

**约束**：

- $1 \le \text{moves.length} = n \le 50$
- `moves` 仅由 `'L'`、`'R'`、`'_'` 组成

## 2. 示例

**示例 1**

```text
输入：moves = "L_RL__R"
输出：3
解释：可以到达的距离原点 0 最远的点是 -3，移动的序列为 "LLRLLLR"。
```

**示例 2**

```text
输入：moves = "_R__LL_"
输出：5
解释：可以到达的距离原点 0 最远的点是 -5，移动的序列为 "LRLLLLL"。
```

**示例 3**

```text
输入：moves = "_______"
输出：7
解释：可以到达的距离原点 0 最远的点是 7，移动的序列为 "RRRRRRR"。
```

## 3. 解题思路

### 3.1 暴力思路

枚举每个 `'_'` 的方向，共 $2^{\text{cntU}}$ 种组合（cntU 为下划线个数），每种组合模拟一遍取最终位置的绝对值最大。最坏 $n = 50$ 全是下划线时需要枚举 $2^{50}$ 种方案，不可行；且本题完全不需要搜索——一步计数就能出答案。

### 3.2 核心观察：只有 `'_'` 有自由度

![三类字符的移动自由度](images/wc360_q1_moves_freedom.svg)

- `'L'` 和 `'R'` 的方向是**固定**的，它们对最终位置的贡献只与**个数**有关，与顺序无关：`'L'` 个数记为 $\text{cntL}$，每个贡献 $-1$；`'R'` 个数记为 $\text{cntR}$，每个贡献 $+1$。
- `'_'` 的方向**由你决定**，每个可贡献 $\pm 1$。

因此**不需要关心字符顺序，只需三个计数**：$\text{cntL}$、$\text{cntR}$、$\text{cntU} = n - \text{cntL} - \text{cntR}$。

> 💡 **一句话总结**：固定步决定"净位移" $d = \text{cntR} - \text{cntL}$，自由步全部押到同一侧，就能把距离推到最远。

### 3.3 算法流程

1. 一遍扫描 `moves`，统计 $\text{cntL}$、$\text{cntR}$、$\text{cntU}$；
2. 返回 $\lvert \text{cntL} - \text{cntR} \rvert + \text{cntU}$。

贪心策略：设固定部分的净位移 $d = \text{cntR} - \text{cntL}$。把所有 $\text{cntU}$ 个 `'_'` 全部移向与 $d$ **同号**的一侧（$d = 0$ 时任选一侧），最终位置为 $d \pm \text{cntU}$，距离即 $\lvert d \rvert + \text{cntU}$。

### 3.4 示例演算

以示例 2 `moves = "_R__LL_"` 为例：$\text{cntL} = 2$，$\text{cntR} = 1$，$\text{cntU} = 4$。

![示例 _R__LL_ 的贪心演算](images/wc360_q1_greedy_split.svg)

- 固定净位移 $d = 1 - 2 = -1$；
- 4 个 `'_'` 全部向左（与 $d$ 同号）：位置 $= -1 - 4 = -5$；
- 最远距离 $= \lvert -5 \rvert = 5$，与公式 $\lvert 2 - 1 \rvert + 4 = 5$ 一致 ✓。

再验证示例 1 `"L_RL__R"`：$\text{cntL} = 2$，$\text{cntR} = 2$，$\text{cntU} = 3$，答案 $= \lvert 2 - 2 \rvert + 3 = 3$ ✓。

## 4. 算法细节

1. **只计数、不模拟**：`'L'`/`'R'` 的贡献与出现顺序无关（位置是各步位移的代数和，加法交换律），一次遍历统计三个量即可。
2. **贪心分配**：`'_'` 彼此独立，每个对位置贡献 $\pm 1$；要最大化 $\lvert \text{位置} \rvert$，全部押同一侧、且与固定净位移同号。
3. **公式**：$\text{ans} = \lvert \text{cntL} - \text{cntR} \rvert + \text{cntU}$，等价写法 $\max(\text{cntL}, \text{cntR}) + \text{cntU}$。
4. **奇偶不变量**（本题用不到但值得注意）：最终位置 $P \equiv n \pmod 2$，与 `'_'` 的分配方式无关——因为改变一个 `'_'` 的方向会使 $P$ 变动 $\pm 2$。这解释了为什么可达位置跳着分布。

## 5. 正确性证明

**引理 1**（可达位置刻画）：设 $d = \text{cntR} - \text{cntL}$，$u = \text{cntU}$。任一移动方案的最终位置为 $P = d + s$，其中 $s \in \{-u, -u+2, \ldots, u-2, u\}$；反之每个这样的 $s$ 都可达。

**证明**：`'R'` 共贡献 $+\text{cntR}$，`'L'` 共贡献 $-\text{cntL}$，固定部分合计 $d$。设 $x$ 个 `'_'` 向右、$u - x$ 个向左，则自由部分 $s = x - (u - x) = 2x - u$，$x \in [0, u]$ 取整数，故 $s$ 取遍 $\{-u, -u+2, \ldots, u\}$。反之对任意该集合中的 $s = 2x - u$，令恰好 $x$ 个 `'_'` 向右即可实现。∎

**定理**：可达点距原点的最远距离为 $\lvert \text{cntL} - \text{cntR} \rvert + \text{cntU}$。

**证明**：对任意方案，由三角不等式

$$\lvert P \rvert = \lvert d + s \rvert \le \lvert d \rvert + \lvert s \rvert \le \lvert d \rvert + u,$$

故 $\lvert d \rvert + u$ 是上界。又由引理 1，$s = \pm u$ 可达：若 $d \ge 0$ 取 $s = u$，得 $P = d + u$；若 $d < 0$ 取 $s = -u$，得 $P = d - u$。两种情况均有 $\lvert P \rvert = \lvert d \rvert + u$，上界可以取到。因此最远距离为 $\lvert d \rvert + u = \lvert \text{cntL} - \text{cntR} \rvert + \text{cntU}$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。一次遍历统计三个计数，$n \le 50$ 实际是常数级。
- **空间复杂度**：$O(1)$。只使用三个计数变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int furthestDistanceFromOrigin(string moves) {
        int cntL = 0, cntR = 0, cntU = 0;
        for (char c : moves) {
            if (c == 'L') cntL++;
            else if (c == 'R') cntR++;
            else cntU++;
        }
        return abs(cntL - cntR) + cntU;
    }
};
```

### Python

```python
class Solution:
    def furthestDistanceFromOrigin(self, moves: str) -> int:
        cnt_l = moves.count('L')
        cnt_r = moves.count('R')
        cnt_u = moves.count('_')
        return abs(cnt_l - cnt_r) + cnt_u
```

## 8. 边界情况与易错点

1. **全是 `'_'`**（示例 3）：$\text{cntL} = \text{cntR} = 0$，答案 $= n$。
2. **$\text{cntL} = \text{cntR}$**：固定部分互相抵消，答案 $= \text{cntU}$，"自由步全押一侧"。
3. **返回的是距离不是坐标**：答案非负，不要返回带符号的位置。
4. **别写成 $\max(\text{cntL}, \text{cntR}) - \min(\text{cntL}, \text{cntR}) + \text{cntU}$ 之外的复杂分支**：公式一步到位，多写分支反而易错。
5. **无溢出风险**：$n \le 50$，`int` 足够。
6. **顺序无关**：不要试图按前缀和模拟找"最远时刻"，题目问的是最终位置，不是过程中的最远点。
