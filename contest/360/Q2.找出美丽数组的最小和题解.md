# LeetCode 找出美丽数组的最小和 题解

## 1. 题目概述

- **标题 / 题号**：找出美丽数组的最小和（#2834，medium）
- **链接**：https://leetcode.cn/problems/find-the-minimum-possible-sum-of-a-beautiful-array/
- **来源**：LeetCode 第 360 场周赛 Q2
- **难度**：中等
- **标签**：贪心、数学

**题意**：给定两个正整数 $n$ 和 $\text{target}$。称数组 $\text{nums}$ 为**美丽数组**，若它满足：

1. $\text{nums.length} = n$；
2. $\text{nums}$ 由**两两互不相同**的正整数组成；
3. 不存在两个**不同**的下标 $i \ne j$，使得 $\text{nums}[i] + \text{nums}[j] = \text{target}$。

返回美丽数组元素之和的**最小值**，并对 $10^9 + 7$ 取模。

**约束**：

- $1 \le n \le 10^9$
- $1 \le \text{target} \le 10^9$

> ⚠️ $n$ 与 $\text{target}$ 都高达 $10^9$：既不能枚举数组，也不能 $O(n)$ 逐个模拟选数——必须把贪心过程**压缩成 $O(1)$ 公式**。

## 2. 示例

**示例 1**

```text
输入：n = 2, target = 3
输出：4
解释：nums = [1,3] 是美丽数组：长度为 2，元素互不相同，
      且不存在两个不同下标的元素之和为 3。可以证明 4 是最小和。
```

**示例 2**

```text
输入：n = 3, target = 3
输出：8
解释：nums = [1,3,4]。1+3=4、1+4=5、3+4=7 均不为 3，是美丽数组，和为 8。
```

**示例 3**

```text
输入：n = 1, target = 1
输出：1
解释：nums = [1]。只有一个元素，谈不上"两个不同下标"，天然美丽。
```

## 3. 解题思路

### 3.1 暴力思路

$n$ 与 $\text{target}$ 都到 $10^9$：

- 枚举数组本身不可能（组合爆炸）；
- 即使退一步，用"从 1 开始逐个试数、哈希表记录已选值、冲突就跳过"的贪心模拟，也是 $O(n)$ 时间与内存，$n = 10^9$ 时既超时也爆内存。

出路只有一条：先看清**冲突的结构**，再数清楚每一段选了多少个数，把选数过程直接写成等差数列求和公式。

### 3.2 核心观察：冲突是"成对配对"的

![冲突的配对结构](images/wc360_q2_pair_structure.svg)

记 $\text{half} = \lfloor \text{target}/2 \rfloor$，把正整数按与 $\text{target}$ 的关系分成三段：

1. **小的一半 $[1, \text{half}]$**：任意两个**不同**的数 $x, y \le \text{half}$ 满足 $x + y \le 2\,\text{half} \le \text{target}$，而取等当且仅当 $\text{target}$ 为偶数且 $x = y = \text{target}/2$——与互异性矛盾。所以**这一段内部两两兼容，可以全选**。
2. **中段 $[\text{half}+1, \text{target}-1]$**：其中每个数 $b$ 与 $a = \text{target} - b \in [1, \text{half}]$ **配成一对**，这一对里**至多选一个**。既然求最小和，当然选小的 $a$——中段整段跳过。
3. **大段 $[\text{target}, +\infty)$**：任何两个正数之和 $\ge \text{target} + 1 > \text{target}$（大段内部则 $\ge 2\,\text{target}$），**永不过冲突**，是从 $\text{target}$ 开始的"后备池"。

> ⚠️ **易被忽略的点**：$\text{target}$ 为偶数时，$\text{target}/2$ 落在小的一半里。它"自己配自己"（$\text{target}/2 + \text{target}/2 = \text{target}$），但冲突条件要求**两个不同下标**——互异性保证它至多出现一次，因此 $\text{target}/2$ **可以选**，别把它误删。

> 💡 **一句话总结**：冲突对 $\{a, \text{target}-a\}$ 每对至多贡献一个元素，贪心永远选小的那端；最优选法就是 $\{1, 2, \ldots, \text{half}\}$ 接上 $\{\text{target}, \text{target}+1, \ldots\}$。

### 3.3 算法流程：直接算公式

![O(1) 公式流程](images/wc360_q2_algorithm_flow.svg)

记 $\text{half} = \lfloor \text{target}/2 \rfloor$：

1. **若 $n \le \text{half}$**：直接取最小的 $n$ 个正整数 $1 \sim n$（全落在兼容段内），和为 $\frac{n(n+1)}{2}$。
2. **否则**：先取满小的一半 $1 \sim \text{half}$（共 $\text{half}$ 个），剩下 $k = n - \text{half}$ 个从 $\text{target}$ 起依次取 $\text{target}, \text{target}+1, \ldots, \text{target}+k-1$，和为
   $$\frac{\text{half}(\text{half}+1)}{2} + k \cdot \text{target} + \frac{k(k-1)}{2}.$$
3. 对 $10^9 + 7$ 取模返回。

### 3.4 示例演算

![示例演算](images/wc360_q2_example_walkthrough.svg)

以示例 2（$n = 3$，$\text{target} = 3$）为例：$\text{half} = 1$。

- 从 1 开始扫：选 **1**；
- 轮到 2：其伙伴 $\text{target} - 2 = 1$ 已选 → **跳过**；
- 轮到 3：$\ge \text{target}$，无冲突 → **选**；
- 还差一个：接着选 **4**。

选出 $\{1, 3, 4\}$，和 $= 8$。对照公式：$k = n - \text{half} = 2$，$\frac{1 \times 2}{2} + 2 \times 3 + \frac{2 \times 1}{2} = 1 + 6 + 1 = 8$ ✓。

示例 1（$n = 2$）：$k = 1$，选 $\{1, 3\}$，和 $= 1 + 3 = 4$ ✓。示例 3（$n = 1$，$\text{target} = 1$）：$\text{half} = 0$，$k = 1$，从 $\text{target} = 1$ 起取 $\{1\}$，和 $= 1$ ✓。

## 4. 算法细节

1. **分段依据**：前缀 $[1, \text{half}]$ 内部无冲突对**对一切 $\text{target}$ 成立**（3.2 的论证）。当 $\text{target} \ge 3$ 时它还是**极大**兼容前缀：$[1, \text{half}+1]$ 必含冲突对（$\text{target} = 2m+1$ 奇时 $m + (m+1) = \text{target}$；$\text{target} = 2m$ 偶时 $(m-1) + (m+1) = \text{target}$）。$\text{target} \le 2$ 时后备池恰从 $\text{half}+1$ 无缝接上（$\text{target}=2$：$\{1\} \cup \{2,3,\ldots\}$；$\text{target}=1$：$\{1,2,\ldots\}$），公式不需要特判。
2. **公式推导**（$n > \text{half}$ 时）：前缀和 $1 + 2 + \cdots + \text{half} = \frac{\text{half}(\text{half}+1)}{2}$；后备段是首项 $\text{target}$、公差 1、项数 $k = n - \text{half}$ 的等差数列，和 $= k \cdot \text{target} + \frac{k(k-1)}{2}$。
3. **为什么中段整段跳过**：中段每个数 $b$ 的伙伴 $\text{target} - b$ 是 $[1, \text{half}]$ 里更小的数。每对预算只有 1 个，选 $b$ 弃 $a$ 只会让总和变大（每对贡献 $\min(a, b) = a$ 最优）。此外中段不与除伙伴外的任何数冲突，弃 $a$ 选 $b$ 解锁不了任何额外收益。
4. **取模时机**：三项原始值分别至多约 $1.25 \times 10^{17}$、$5 \times 10^{17}$、$5 \times 10^{17}$，总和 $\approx 1.1 \times 10^{18} < 2^{63} - 1 \approx 9.2 \times 10^{18}$，C++ 的 `long long` 可以**加完再取一次模**；Python 大整数无此顾虑。注意 $\frac{x(x+1)}{2}$ 的整除必须在取模**之前**做（$x(x+1)$ 必为偶数，整除精确）。

## 5. 正确性证明

**引理 1**（冲突刻画）：互不相同的正整数 $x \ne y$ 满足 $x + y = \text{target}$，当且仅当 $x, y \in [1, \text{target}-1]$ 且 $y = \text{target} - x$。

**证明**：若 $x + y = \text{target}$ 且 $x, y \ge 1$，则 $x, y \le \text{target} - 1$ 且 $y = \text{target} - x$；反之显然。∎

**引理 2**（配对预算）：记 $q = \lfloor (\text{target}-1)/2 \rfloor$。对每个 $a \in [1, q]$ 定义配对 $P_a = \{a,\ \text{target}-a\}$，则这些配对两两不相交，且任何美丽数组的元素集合 $S$ 满足 $|S \cap P_a| \le 1$。

**证明**：$a < \text{target} - a \iff a < \text{target}/2 \iff a \le q$，故每对内部两数不等。$a$ 侧取值 $[1, q]$、$b$ 侧取值 $[\text{target}-q,\ \text{target}-1]$，且 $q \le \lfloor \text{target}/2 \rfloor < \text{target} - q$（$\text{target} \ge 2$ 时；$\text{target} = 1$ 时 $q = 0$ 无配对），两侧不相交，配对两两不交；偶数 $\text{target}$ 的中点 $\text{target}/2$ 不属于任何配对。若 $S$ 同时含 $a$ 与 $\text{target}-a$，两值不等必占两个不同下标，其和为 $\text{target}$，违反美丽条件。∎

**引理 3**（贪心集合合法）：算法选出的集合

$$G = \begin{cases} \{1, 2, \ldots, n\}, & n \le \text{half}, \\ \{1, \ldots, \text{half}\} \cup \{\text{target}, \ldots, \text{target}+k-1\}, & k = n - \text{half} > 0, \end{cases}$$

（其中 $\text{half} = \lfloor \text{target}/2 \rfloor$）是 $n$ 个互不相同的正整数，且不含任何冲突对。

**证明**：元素互异、个数恰为 $n$ 显然。无冲突分三类验证：

- **前缀内部**：不同的 $x, y \le \text{half}$ 有 $x + y \le 2\,\text{half} \le \text{target}$，取等需 $x = y = \text{target}/2$（$\text{target}$ 偶），与 $x \ne y$ 矛盾，故 $x + y < \text{target}$；
- **后备段内部**：任意两数 $\ge \text{target}$，和 $\ge 2\,\text{target} > \text{target}$；
- **跨段**：小侧 $\ge 1$、大侧 $\ge \text{target}$，和 $\ge \text{target} + 1 > \text{target}$。

$n \le \text{half}$ 时只有前缀，第一类已覆盖。∎

**定理**（最优性）：对任意 $n$ 元素有效集合 $O$（互异正整数、无冲突对），有 $\operatorname{sum}(G) \le \operatorname{sum}(O)$。

**证明**（逐点占优）：先证对一切整数 $t \ge 1$，

$$|O \cap [1, t]| \le |G \cap [1, t]|. \tag{$\ast$}$$

1. **$t \le \text{half}$**：$O$ 元素互异，$|O \cap [1,t]| \le t$，且 $\le n$；而 $|G \cap [1,t]| = \min(t, n)$（$n \le \text{half}$ 时 $G = \{1..n\}$；$n > \text{half}$ 时前缀全在）。
2. **$\text{half} < t < \text{target}$**：若 $n \le \text{half}$，则 $|O \cap [1,t]| \le |O| = n = |G \cap [1,t]|$。若 $n > \text{half}$：由引理 1、2，$[1, t] \subseteq [1, \text{target}-1]$ 中的值恰由 $q$ 个配对的元素（每对至多贡献 1）加上可能的中点 $\text{target}/2$（至多 1 个）组成，故 $|O \cap [1,t]| \le q + [\text{target 为偶}]$。$\text{target} = 2m$ 偶时 $q = m - 1$，上界 $= m = \text{half}$；$\text{target} = 2m+1$ 奇时 $q = m$，上界 $= m = \text{half}$。而 $G$ 在 $[1,t]$ 内恰有 $\text{half}$ 个元素（前缀全选、中段全空）。
3. **$t \ge \text{target}$**：拆 $O \cap [1,t] = (O \cap [1, \text{target}-1]) \cup (O \cap [\text{target}, t])$。前者由情况 2 知 $\le \text{half}$（或 $n \le \text{half}$ 时 $\le n$）；后者是互异整数落在长为 $t - \text{target} + 1$ 的区间内，至多 $t - \text{target} + 1$ 个。故 $|O \cap [1,t]| \le \text{half} + (t - \text{target} + 1) = |G \cap [1,t]|$（$G$ 在 $[\text{target}, t]$ 内恰有 $\min(k,\ t - \text{target} + 1)$ 个；当 $t \ge \text{target} + k - 1$ 时右侧即为 $n \ge |O|$）。

最后用恒等式 $\operatorname{sum}(S) = \sum_{t \ge 1} |S \cap [t, \infty)|$（元素 $x$ 被计数 $x$ 次）。由 $|O| = |G| = n$ 与 $(\ast)$（取 $t-1$），对每个 $t$ 有 $|O \cap [t, \infty)| = n - |O \cap [1, t-1]| \ge n - |G \cap [1, t-1]| = |G \cap [t, \infty)|$，逐项求和得 $\operatorname{sum}(O) \ge \operatorname{sum}(G)$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(1)$。只做常数次算术运算与一次取模。
- **空间复杂度**：$O(1)$。仅若干变量。

（对比：不做公式化、逐数模拟的贪心是 $O(n)$ 时间与空间，$n \le 10^9$ 时约 $10^9$ 次运算 + 哈希表，必然超时超内存——"想到贪心"与"把贪心写成公式"正是本题作为 Q2 的区分点。）

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minimumPossibleSum(int n, int target) {
        const long long MOD = 1'000'000'007LL;
        long long half = target / 2;
        long long sum;
        if ((long long)n <= half) {
            sum = 1LL * n * (n + 1) / 2;
        } else {
            long long k = n - half;
            sum = half * (half + 1) / 2 + k * (long long)target + k * (k - 1) / 2;
        }
        return (int)(sum % MOD);
    }
};
```

### Python

```python
class Solution:
    def minimumPossibleSum(self, n: int, target: int) -> int:
        MOD = 10**9 + 7
        half = target // 2
        if n <= half:
            return n * (n + 1) // 2 % MOD
        k = n - half
        return (half * (half + 1) // 2 + k * target + k * (k - 1) // 2) % MOD
```

## 8. 边界情况与易错点

1. **$\text{target}/2$ 不要误删**（最高频错误）：偶数 $\text{target}$ 时中点可以被选。反例：$n = 2$，$\text{target} = 4$，正确答案是 $\{1, 2\}$、和 $3$（$2 = \text{target}/2$ 只出现一次，安全）；误删中点会去选 $\{1, 4\}$ 或在 $\{1, 3\}$ 上翻车（$1 + 3 = 4$ 冲突）。
2. **$n \le \text{half}$ 分支**：直接 $n(n+1)/2$，别把中段/后备段的修正项带进来。
3. **必须取模、防溢出**：真实最小和最大约 $1.1 \times 10^{18}$，远超 32 位。C++ 中 `n`、`target` 是 `int`，乘法前必须转 `long long`（`1LL *` 或强转），否则 $n \cdot (n+1)$ 在 `int` 域直接溢出。
4. **整除在取模前**：$\frac{x(x+1)}{2}$ 要先算 $x(x+1)$（偶数）、整除 2，再取模；先取模再除 2 是错的（丢失因子 2）。
5. **$\text{target} = 1$ 或 $2$**：任何两个不同正整数之和 $\ge 3$，约束自动满足，答案即 $n(n+1)/2$。公式自动覆盖（$\text{half} = 0$ 或 $1$，后备池从 $\text{target}$ 起恰与前缀无缝相接），无需特判。
6. **$n = 1$**：单元素无配对可言，答案恒为 1。
7. **用整数除法算 $\text{half}$**：`target / 2` 即 $\lfloor \text{target}/2 \rfloor$，别用浮点（精度隐患）。
