# LeetCode 仅执行一次字符串交换能否使两个字符串相等 题解

## 1. 题目概述

- **标题 / 题号**：仅执行一次字符串交换能否使两个字符串相等（#1790，easy）
- **链接**：https://leetcode.cn/problems/check-if-one-string-swap-can-make-strings-equal/
- **来源**：LeetCode 第 232 场周赛 Q1
- **难度**：简单
- **标签**：字符串、计数、哈希表

**题意**：给定长度相等的两个字符串 $s1$ 与 $s2$。一次**字符串交换**是指：在**某一个**字符串中选出两个下标（**不必不同**），交换这两个下标上的字符。若对其中一个字符串执行**最多一次**交换就能使两串相等，返回 `true`；否则返回 `false`。

**约束**：

- $1 \le s1.length, s2.length \le 100$
- $s1.length = s2.length$
- $s1$ 与 $s2$ 仅由小写英文字母组成

## 2. 示例

**示例 1**

```text
输入：s1 = "bank", s2 = "kanb"
输出：true
解释：交换 s2 的第 0、3 两个字符得到 "bank"，两串相等。
```

**示例 2**

```text
输入：s1 = "attack", s2 = "defend"
输出：false
解释：6 个位置全部不同，一次交换无法使两串相等。
```

**示例 3**

```text
输入：s1 = "kelb", s2 = "kelb"
输出：true
解释：两串已经相等，"最多一次"包含 0 次，无需交换。
```

**示例 4（补充：多重集相同也救不回的情形）**

```text
输入：s1 = "abcd", s2 = "dcba"
输出：false
解释：4 个位置全不同，|D| = 4 > 2；虽然两串字符组成相同，一次交换也修不完。
```

## 3. 解题思路

### 3.1 暴力思路：枚举交换对

最朴素的做法是枚举 $s1$ 中所有下标对 $(i, j)$（$O(n^2)$ 对），交换后逐位比较（$O(n)$），总复杂度 $O(n^3)$；$n \le 100$ 时约 $10^6$ 次字符操作，也能通过。但签到题的目标是**从题面到代码的最短路径**——逐位比较产生的**差异位置集合**本身就携带了判定所需的全部信息，根本不需要枚举。

### 3.2 核心观察：差异集的大小只有 0 和 2 可行

![核心观察：差异位置的个数只有 0 和 2 可行](images/wc232_q1_diff_concept.svg)

逐位比较，收集**差异集** $D = \{k : s1[k] \ne s2[k]\}$，按 $|D|$ 分类：

- $|D| = 0$：两串本来就相等，「最多一次」包含 0 次，返回 `true`（示例 3）。
- $|D| = 2$：设 $D = \{i, j\}$，当且仅当**交叉相等**——$s1[i] = s2[j]$ 且 $s1[j] = s2[i]$——时，交换 $s1$（或 $s2$）的第 $i$、$j$ 位即可全等（示例 1）。
- $|D| = 1$：**必败**。设唯一差异位为 $k$，则两串的字符**多重集**不同（其余位置一一相同，多重集之差恰为 $s1[k]$ 与 $s2[k]$）；而交换只是把 $s1$ 已有的字符对调，**不改变多重集**，怎么换都救不回。
- $|D| \ge 3$：一次交换至多改变 2 个下标上的字符，至少剩 1 个差异位，**必败**（示例 2、4）。

> 💡 **一句话**：答案为 `true` 当且仅当 $|D| \in \{0, 2\}$，且 $|D|=2$ 时两位字符交叉相等。

### 3.3 算法流程

![算法流程：一次扫描加三个判定](images/wc232_q1_flow.svg)

1. **一次线性扫描**：比较 $s1[k]$ 与 $s2[k]$，把不同的下标存入 $D$；一旦 $|D| > 2$ 立即返回 `false`（提前剪枝）。
2. **判定 $|D| = 0$**：返回 `true`。
3. **判定 $|D| = 2$**：设 $D = \{i, j\}$，检查 $s1[i] = s2[j]$ 且 $s1[j] = s2[i]$，成立返回 `true`；其余情况（$|D| = 1$ 或交叉不等）返回 `false`。

### 3.4 示例演算

![示例演算：四个示例分别走四条分支](images/wc232_q1_walkthrough.svg)

| 示例 | $s1$ / $s2$ | $D$ | 判定 | 返回 |
|------|-------------|-----|------|------|
| 1 | `bank` / `kanb` | $\{0, 3\}$ | 交叉相等：$b \leftrightarrow b$、$k \leftrightarrow k$ | $\mathbf{true}$ |
| 2 | `attack` / `defend` | $\{0,1,2,3,4,5\}$ | $\lvert D \rvert = 6 > 2$ | $\mathbf{false}$ |
| 3 | `kelb` / `kelb` | $\varnothing$ | 已相等，0 次交换 | $\mathbf{true}$ |
| 4 | `abcd` / `dcba` | $\{0,1,2,3\}$ | $\lvert D \rvert = 4 > 2$ | $\mathbf{false}$ |

示例 1 走「交叉相等」分支：交换 $s1$ 的第 0、3 位后 `bank` 不变（换回自身），准确说是交换 $s1$ 得 `kanb`，或交换 $s2$ 得 `bank`，两串相等。示例 4 值得注意：两串字符组成**完全相同**（多重集相等），但差异位置有 4 处，一次交换修不完——这说明「多重集相等」只是必要条件，不是充分条件。

## 4. 算法细节

1. **提前剪枝**：扫描中差异下标一旦超过 2 个即可返回 `false`，存储只需两个下标变量，无需完整列表。
2. **交叉相等的紧凑写法**：Python 中把每个差异位记成字符对 $(a, b) = (s1[k], s2[k])$，则「$|D|=2$ 且交叉相等」等价于 `len(diff) == 2 and diff[0] == diff[1][::-1]`（即 $(a_1, b_1) = (b_2, a_2)$）。
3. **多重集等价刻画**：答案为 `true` $\iff$ `Counter(s1) == Counter(s2)` 且 $\lvert D \rvert \le 2$。$|D|=2$ 时多重集相等会强制两位字符交叉配对（因 $s1[i] \ne s2[i]$ 排除了平行配对）；而 $|D|=1$ 时多重集必不等，不会误判。
4. **「最多一次」与「其中一个字符串」**：前者包含 0 次交换（$|D|=0$ 直接 `true`）；后者意味着不能 $s1$、$s2$ 各换一次，但判定条件对两串完全对称（$s1[i]=s2[j] \wedge s1[j]=s2[i]$ 交换哪一侧都一样），对实现无影响。
5. **下标可以相同**：题面明确「不必不同」，选 $i = j$ 的交换等于什么都没做，这与「不执行交换」效果一致，无需单独处理。

## 5. 正确性证明

**引理 1**（多重集不变性）：对字符串执行一次交换（任意两个下标，可相同）不改变其字符多重集。

**证明**：交换只是将串中两个已有字符的位置对调，每个字符的出现次数不变。选取相同下标时串完全不变，结论同样成立。∎

**引理 2**（$|D| = 1$ 必败）：若 $|D| = 1$，则无论对哪个串执行至多一次交换，两串都不可能相等。

**证明**：设唯一差异位为 $k$。除 $k$ 外每个位置两串字符相同，故两串的字符多重集之差恰为 $s1[k]$ 与 $s2[k]$，而 $s1[k] \ne s2[k]$，多重集不同。由引理 1，交换后的串字符多重集不变，永不能与另一串的多重集相等；逐位相等蕴含多重集相等，故不可能相等。∎

**定理**：返回 `true` 当且仅当 $|D| = 0$，或 $|D| = 2$ 且交叉相等（$D = \{i, j\}$ 满足 $s1[i] = s2[j]$ 且 $s1[j] = s2[i]$）。

**证明**：

（充分性）$|D| = 0$ 时执行 0 次交换即相等。$|D| = 2$ 且交叉相等时，交换 $s1$ 的第 $i$、$j$ 位：其余位置不变且本已相等；位置 $i$ 变为 $s1[j] = s2[i]$，位置 $j$ 变为 $s1[i] = s2[j]$，两串全等。

（必要性）设对某一个串执行至多一次交换后两串相等，不妨设交换在 $s1$ 上（在 $s2$ 上对称）。若不执行交换或选取相同下标，则 $s1$ 不变，即 $|D| = 0$。否则设交换的不同下标为 $i, j$：$s1$ 中只有位置 $i, j$ 的字符可能改变，其余位置 $k \notin \{i, j\}$ 保持 $s1[k] = s2[k]$,即 $D \subseteq \{i, j\}$，$|D| \le 2$。由引理 2 排除 $|D| = 1$：若 $|D| = 0$ 得第一种情形；若 $|D| = 2$，则 $D = \{i, j\}$，且由交换后相等得 $s1'[i] = s1[j] = s2[i]$、$s1'[j] = s1[i] = s2[j]$，即交叉相等。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。一次线性扫描收集差异下标（常数次比较），$n \le 100$ 下远优于暴力的 $O(n^3)$。
- **空间复杂度**：$O(1)$。只维护至多两个差异下标（Python 写法存两个字符对，仍为常数），无额外数据结构。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool areAlmostEqual(string s1, string s2) {
        int i = -1, j = -1;
        for (int k = 0; k < (int)s1.size(); ++k) {
            if (s1[k] == s2[k]) continue;
            if (i == -1) i = k;
            else if (j == -1) j = k;
            else return false;
        }
        if (i == -1) return true;
        if (j == -1) return false;
        return s1[i] == s2[j] && s1[j] == s2[i];
    }
};
```

### Python

```python
class Solution:
    def areAlmostEqual(self, s1: str, s2: str) -> bool:
        diff = [(a, b) for a, b in zip(s1, s2) if a != b]
        return diff == [] or (len(diff) == 2 and diff[0] == diff[1][::-1])
```

## 8. 边界情况与易错点

1. **「最多一次」包含 0 次**：$s1 = s2$ 时返回 `true`（示例 3），不要误判为必须交换一次。
2. **$|D| = 1$ 必 `false`**：容易漏掉这个分支而只写 `len(diff) <= 2`；恰一处差异时多重集已不同，无解。
3. **交叉相等是两个条件**：必须同时检查 $s1[i] = s2[j]$ **和** $s1[j] = s2[i]$，写成单个 `s1[i] == s2[j]` 在非对称输入上出错。
4. **多重集相等 ≠ 可行**：示例 4 `abcd / dcba` 字符组成相同，但 $|D| = 4$，仍为 `false`；反过来用 `Counter` 判等必须叠加 $|D| \le 2$。
5. **只能改一个串**：题面限定「对其中一个字符串」执行交换，不能两边各换一次；好在判定对称，实现无感。
6. **最小规模 $n = 1$**：要么两字符相同（$|D| = 0$，`true`），要么不同（$|D| = 1$，`false`），自然被分类覆盖。
7. **下标可相同**：$i = j$ 的交换是合法但无效的操作，等价于不交换，无需特判。

**延伸思考**：

- **「最多一次」vs「恰好一次」**：本题的 0 次免费；859 要求恰好一次且 $i \ne j$，于是相等串需要重复字符（如 `"aa"` 换两个 `a`），差异集的合法大小仍是 $\{0, 2\}$ 但 $|D|=0$ 的条件完全不同——同一框架，边界含义随题面微调。
