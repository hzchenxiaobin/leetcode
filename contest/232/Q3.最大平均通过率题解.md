# LeetCode 最大平均通过率 题解

## 1. 题目概述

- **标题 / 题号**：最大平均通过率（#1792，medium）
- **链接**：https://leetcode.cn/problems/maximum-average-pass-ratio/
- **来源**：LeetCode 第 232 场周赛 Q3
- **难度**：中等
- **标签**：贪心、数组、堆（优先队列）

**题意**：一所学校有 $n$ 个班级，第 $i$ 个班共 $\text{total}_i$ 名学生，其中 $\text{pass}_i$ 人能通过期末考试。另有 $E = \text{extraStudents}$ 名「聪明学生」，他们**一定**能通过任何班的考试。把这 $E$ 名学生**每人分到一个班**（允许多人进同一个班），使**所有班级的平均通过率最大**，返回该最大平均通过率。

- **班级通过率** = $\text{pass} / \text{total}$
- **平均通过率** = 所有班级通过率之和 $\div$ 班级数 $n$

**约束**：

- $1 \le n = \text{classes.length} \le 10^5$
- $\text{classes}[i] = [\text{pass}_i, \text{total}_i]$，且 $1 \le \text{pass}_i \le \text{total}_i \le 10^5$
- $1 \le \text{extraStudents} \le 10^5$

## 2. 示例

**示例 1**

```text
输入：classes = [[1,2],[3,5],[2,2]], extraStudents = 2
输出：0.78333
解释：两名学生都分给第 0 个班（允许同班），
      平均 = (3/4 + 3/5 + 2/2) / 3 = 2.35 / 3 ≈ 0.78333。
```

**示例 2**

```text
输入：classes = [[2,4],[3,9],[4,5],[2,10]], extraStudents = 4
输出：0.53485
```

**示例 3（补充：已满班级与集中分配）**

```text
输入：classes = [[5,5],[2,3]], extraStudents = 3
输出：0.91667
解释：班 0 已全员通过（增益为 0），3 名学生全部塞进班 1：
      (1 + 5/6) / 2 = (11/6) / 2 = 11/12 ≈ 0.91667。
```

## 3. 解题思路

### 3.1 暴力思路：每轮线性扫描找最大增益

平均值的分母 $n$ 固定，所以**最大化平均 ⟺ 最大化各班通过率之和**。于是问题变成：$E$ 个名额逐个发放，每个名额发给哪个班收益最大。

最直觉的暴力：每发一个名额前，**线性扫描**所有班，计算「加一人后的增益」，选最大的班发放：

```text
重复 E 次：
    best = argmax_i [ (pass_i+1)/(total_i+1) − pass_i/total_i ]
    pass_best++, total_best++
答案 = Σ pass_i/total_i / n
```

单轮 $O(n)$、共 $E$ 轮，总计 $O(nE)$；$n, E$ 均可达 $10^5$，约 $10^{10}$ 次运算，**必然超时**。（枚举所有分配方案更是天文数字。）

> ⚠️ 暴力的瓶颈在于「每轮重新扫描全部班级」。但每轮其实只改了**一个班**——其余 $n-1$ 个班的增益分毫未变，根本没必要重算。这正是堆的用武之地。

### 3.2 核心观察：边际增益递减，大顶堆每轮取最大

![核心观察：边际增益递减与大顶堆增量分配](images/wc232_q3_gain_concept.svg)

关键洞察分三步：

1. **量化「加一人的收益」**。给班 $(p, t)$ 加一名必过学生，通过率从 $p/t$ 变为 $(p+1)/(t+1)$，**边际增益**为

   $$
   \Delta(p, t) = \frac{p+1}{t+1} - \frac{p}{t} = \frac{t - p}{t(t+1)}
   $$

   通分后形式极简：分子是「未通过人数」$t-p$，分母是 $t(t+1)$。当 $t = p$（全员已过）时增益为 $0$，堆顶天然不会选中它。

2. **增益随加的人数递减（凹性）**。对同一个班反复加人，$p$ 与 $t$ 同步 $+1$，而 $\Delta(p+1, t+1) = \frac{t-p}{(t+1)(t+2)} < \frac{t-p}{t(t+1)} = \Delta(p, t)$（分子不变、分母变大）。也就是说收益递减——**把所有学生无脑塞进一个班未必最优**，要在「收益最高」与「递减后是否仍高于其他班」之间权衡。

3. **大顶堆维护当前最大增益**。每轮弹出堆顶（增益最大的班），加一人后重算增益回推入堆。堆保证每次选的都是当前最优，且只对**被改动的那个班**重算，其余班的增益原封不动。

> 💡 **为什么不是「优先补通过率最低的班」？** 因为目标量是**边际增益**而非通过率本身。反例：班 A $(1, 100)$ 通过率 $0.01$，增益 $\frac{99}{10100} \approx 0.0098$；班 B $(1, 2)$ 通过率 $0.5$，增益 $\frac{1}{6} \approx 0.167$。B 通过率**更高**但增益**远更大**——增益分母 $t(t+1)$ 对大班严重惩罚，给 100 人的班加一人几乎不动通过率，给 2 人的班加一人却能从 $0.5$ 跳到 $0.667$。必须用 $(t-p)/[t(t+1)]$ 作为堆的优先级。

### 3.3 算法流程

![算法流程：建堆、E 轮堆顶更新、汇总返回](images/wc232_q3_heap_flow.svg)

```text
1. 对每个班 (p, t) 计算 g = (t−p) / (t(t+1))，将 (g, p, t) 入大顶堆
2. 重复 E = extraStudents 次：
   a. 弹出堆顶 (g, p, t)            ← 当前加一人收益最大的班
   b. p++, t++                        ← 加一名必过学生
   c. 重算 g = (t−p) / (t(t+1))，回推入堆
3. 遍历堆中所有班，sum = Σ p/t
4. 返回 sum / n
```

> 💡 **关键不变量**：每轮结束后，堆顶永远是「当前加一人收益最大」的班。全程只对一个班做「弹出—修改—回推」，这正是堆把「找最大」从 $O(n)$ 降到 $O(\log n)$ 的来源。

### 3.4 示例演算

![示例 2 演算：四步堆顶轮换与平局破开](images/wc232_q3_walkthrough.svg)

以示例 2 `classes = [[2,4],[3,9],[4,5],[2,10]], E = 4` 为例，四个班记为 A、B、C、D，初始增益：

- A $(2,4)$：$\frac{4-2}{4 \cdot 5} = 0.100$
- B $(3,9)$：$\frac{9-3}{9 \cdot 10} \approx 0.067$
- C $(4,5)$：$\frac{5-4}{5 \cdot 6} \approx 0.033$
- D $(2,10)$：$\frac{10-2}{10 \cdot 11} \approx 0.073$

| 步 | 堆顶 | 动作 | 动作后的班 | 新增益 |
|----|------|------|-----------|--------|
| 1 | A（0.100） | 给 A 加 1 人 | A $(3,5)$ | $2/30 \approx 0.067$ |
| 2 | D（0.073） | 给 D 加 1 人 | D $(3,11)$ | $8/132 \approx 0.061$ |
| 3 | A（0.067，与 B 平局） | 给 A 加 1 人 | A $(4,6)$ | $2/42 \approx 0.048$ |
| 4 | B（0.067） | 给 B 加 1 人 | B $(4,10)$ | —（名额用完） |

最终各班：A $= 4/6$、B $= 4/10$、C $= 4/5$、D $= 3/11$，总和

$$
\frac{4}{6} + \frac{4}{10} + \frac{4}{5} + \frac{3}{11} = \frac{353}{165} \approx 2.1394, \qquad \text{平均} = \frac{353}{660} \approx 0.53485 \ ✓
$$

> 💡 第 3 步 A、B 增益同为 $1/15$（平局）：先给 A 还是先给 B，最终各班人数完全相同（另一者必然在第 4 步被选中）。这不是巧合——**最优值与平局破开方式无关**，见 §5 定理 (iii)。

## 4. 算法细节

1. **目标转化**：分母 $n$ 固定，最大化平均值 ⟺ 最大化 $\sum_i p_i / t_i$。循环内只维护增益与堆，最后一步才除以 $n$，避免逐轮维护平均值引入的误差与开销。
2. **增益公式的实现**：直接按定义算两次除法再相减也可以，但通分式 $\frac{t-p}{t(t+1)}$ 只有一次除法、数值更稳，且分子分母的语义（未过人数、体量平方级）直观。C++ 实现必须防整除截断与 `t*(t+1)` 的 int 溢出（见 §8 第 1、2 条）。
3. **堆元素设计**：存三元组 $(g, p, t)$，以 $g$ 为比较键。班不需要记下标——弹出后由 $(p, t)$ 即可重算增益。
4. **平局无需处理**：多个班增益相同时先弹谁都得到同样的最优值（§5），比较器不必附加次键。
5. **满班自动沉底**：$p = t$ 时 $g = 0$，照常入堆；即便被选中，$(p+1)/(t+1) = 1$ 通过率不变，无害。
6. **汇总方式**：$E$ 轮结束后堆中就是各班最终 $(p, t)$。Python 直接迭代 `heap` 列表即可（$O(n)$）；C++ 逐个 `top()/pop()` 累加（$O(n \log n)$，不改变总复杂度量级）。

## 5. 正确性证明

**引理 1**（增益公式与边际递减）：设 $\Delta(p, t) = \frac{p+1}{t+1} - \frac{p}{t}$。

(a) $\Delta(p, t) = \frac{t-p}{t(t+1)} \ge 0$，等号当且仅当 $t = p$；
(b) $\Delta(p+1, t+1) = \frac{t-p}{(t+1)(t+2)} \le \Delta(p, t)$，$t > p$ 时严格小于。

**证明**：(a) 通分 $\frac{t(p+1) - p(t+1)}{t(t+1)} = \frac{t-p}{t(t+1)}$；由 $1 \le p \le t$ 知 $t - p \ge 0$。(b) 两式分子同为 $t-p$，分母 $(t+1)(t+2) > t(t+1)$（$t \ge 1$）。∎

**引理 2**（前缀分离表示）：设方案给班 $i$ 分配 $x_i$ 名学生（$\sum_i x_i = E$）。记 $f_i(k) = \frac{p_i + k}{t_i + k}$、$\delta_i(k) = f_i(k) - f_i(k-1)$（班 $i$ 的第 $k$ 个名额的边际增益），则

$$
\sum_{i=1}^{n} \frac{p_i + x_i}{t_i + x_i} = \sum_{i=1}^{n} \frac{p_i}{t_i} + \sum_{i=1}^{n} \sum_{k=1}^{x_i} \delta_i(k),
$$

且由引理 1(b)，对每个 $i$ 序列 $\delta_i(1) \ge \delta_i(2) \ge \cdots$ 非增。于是最大化总和等价于：**在 $n$ 条非增序列中各取一个前缀、共取 $E$ 项，使取出项之和最大**。

**证明**：对每个班，$\frac{p_i + x_i}{t_i + x_i} - \frac{p_i}{t_i} = \sum_{k=1}^{x_i} [f_i(k) - f_i(k-1)]$（望远镜求和），而 $f_i(k) - f_i(k-1) = \Delta(p_i + k - 1,\, t_i + k - 1) = \delta_i(k)$。常数项 $\sum_i p_i / t_i$ 与方案无关。∎

**定理**（贪心最优）：「每轮给当前边际增益最大的班（堆顶）加一人，共 $E$ 轮」得到的分配达到最优值，且**最优值与平局破开方式无关**。

**证明**：将全体格点 $(i, k)$（$1 \le k \le E$）的 $\delta$ 值降序排列为 $g_1 \ge g_2 \ge \cdots \ge g_{nE}$（平局处任意定序）。

**上界**：任何前缀可行的 $E$ 项集合 $T$，其第 $j$ 大项不超过 $g_j$，故 $\text{sum}(T) \le \sum_{j \le E} g_j$。

**(i) 上界可达**：取「$E$ 个 $\delta$ 值最大的格点」构成的集合 $M$。若 $M$ 含 $(i, k)$ 而不含 $(i, k-1)$，由非增性 $\delta_i(k-1) \ge \delta_i(k)$，用 $(i, k-1)$ 替换 $(i, k)$ 后和不减。反复替换消除「跳格」，$M$ 被调整为每列前缀的集合 $M'$，且 $\text{sum}(M') \ge \sum_{j \le E} g_j$；结合上界，$M'$ 恰为最优，最优值 $= \sum_{j \le E} g_j$。

**(ii) 贪心取到上界**：归纳证明贪心前 $k$ 轮取出的 $k$ 个值恰为 $\{g_1, \dots, g_k\}$。$k=0$ 显然。设前 $k$ 轮成立，则已取格点是若干列的前缀且值恰为前 $k$ 大。第 $k+1$ 轮的候选是各列「下一格」；由每列非增，**任何**未取格点 $(i, k')$ 的值 $\le \delta_i(\text{列 } i \text{ 当前行首}) \le$ 贪心本轮取值，而贪心本轮取值本身也是未取格点之一，故它就是全部未取格点中的最大值 $g_{k+1}$。归纳完成：贪心 $E$ 轮之和 $= \sum_{j \le E} g_j$ = 最优值。

**(iii) 平局无关**：上界 $\sum_{j \le E} g_j$ 只依赖 $\delta$ 值的多重集合，与降序排列时平局如何定序无关；由 (ii)，任何破平规则下的贪心都取到这组值。∎

## 6. 复杂度分析

- **时间复杂度**：$O((n + E) \log n)$。建堆：Python `heapify` 为 $O(n)$，C++ 逐个 push 为 $O(n \log n)$；$E$ 轮循环各一次 pop + push 共 $O(E \log n)$；汇总 $O(n)$（Python 直接遍历）或 $O(n \log n)$（C++ 逐个弹出）。本题 $n, E \le 10^5$，总操作约 $(2 \times 10^5) \times 17 \approx 3.4 \times 10^6$ 次堆运算，远在时限内——关键是用堆把暴力每轮 $O(n)$ 的「找最大」降为 $O(\log n)$，避开 $O(nE) = 10^{10}$。
- **空间复杂度**：$O(n)$。堆中始终存 $n$ 个班的 $(g, p, t)$ 三元组。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    double maxAverageRatio(vector<vector<int>>& classes, int extraStudents) {
        using Node = tuple<double, int, int>; // (增益, pass, total)
        auto cmp = [](const Node& a, const Node& b) {
            return get<0>(a) < get<0>(b); // 增益小者沉底 → 大顶堆
        };
        priority_queue<Node, vector<Node>, decltype(cmp)> pq(cmp);

        for (const auto& c : classes) {
            int p = c[0], t = c[1];
            double g = (double)(t - p) / ((double)t * (t + 1));
            pq.emplace(g, p, t);
        }

        for (int i = 0; i < extraStudents; ++i) {
            auto [g, p, t] = pq.top();
            pq.pop();
            ++p;
            ++t; // 加一名必过学生
            double ng = (double)(t - p) / ((double)t * (t + 1));
            pq.emplace(ng, p, t);
        }

        double sum = 0;
        while (!pq.empty()) {
            auto [g, p, t] = pq.top();
            pq.pop();
            sum += (double)p / t;
        }
        return sum / classes.size();
    }
};
```

### Python

```python
class Solution:
    def maxAverageRatio(self, classes: List[List[int]], extraStudents: int) -> float:
        def gain(p: int, t: int) -> float:
            return (t - p) / (t * (t + 1))

        heap = [(-gain(p, t), p, t) for p, t in classes]
        heapq.heapify(heap) # O(n) 自底向上建堆

        for _ in range(extraStudents):
            _, p, t = heapq.heappop(heap) # -g 最小 = g 最大
            p += 1
            t += 1
            heapq.heappush(heap, (-gain(p, t), p, t))

        return sum(p / t for _, p, t in heap) / len(heap)
```

## 8. 边界情况与易错点

1. **C++ 整数除法截断**：`(t - p) / (t * (t + 1))` 是 int 除 int，结果恒为 0，增益完全失真。必须先转 `double`：`(double)(t - p) / ((double)t * (t + 1))`。Python 的 `/` 天然浮点除，无此问题。
2. **C++ int 溢出**：$t \le 10^5$ 时 $t(t+1) \approx 10^{10}$，超出 `INT_MAX`（约 $2.1 \times 10^9$）。任何 int × int 的写法（如 `t * (t + 1)` 再转 double）都溢出；正确写法是让其中一个操作数先成为 `double`。
3. **平均的分母是班级数 $n$**，不是学生总人数——题面明确「通过率之和除以班级数目」。
4. **允许多名学生进同一个班**（示例 1 两名都进班 0），不要误加「每班至多一人」的限制。
5. **满班 $p = t$**：增益为 0，加人后 $(p+1)/(t+1) = 1$ 通过率不变，结果依然正确；若所有班全满，$E$ 轮空转也无害。
6. **最终统计要用更新后的 $(p, t)$**：$E$ 轮结束后堆里才是各班最终状态，别拿初始 `classes` 累加。
7. **返回值与精度**：误差 $10^{-5}$ 内判对，`double`（约 15–16 位有效数字）绰绰有余，无需 `long double`。
8. **C++ `priority_queue` 比较器语义与 `sort` 相反**：`cmp(a, b)` 为 true 表示 a 优先级**低**（沉底），故 `return get<0>(a) < get<0>(b)` 得到大顶堆；lambda 无默认构造，`decltype(cmp)` 作模板参数的同时构造时要传入 `cmp`。
9. **Python 大顶堆用负数模拟**：`heapq` 是小顶堆，存 `-g` 后堆顶即增益最大者。
