# LeetCode 找出数组中的第一个回文字符串 题解

## 1. 题目概述

- **标题 / 题号**：找出数组中的第一个回文字符串（#2108，easy）
- **链接**：https://leetcode.cn/problems/find-first-palindromic-string-in-the-array/
- **来源**：LeetCode 第 272 场周赛 Q1
- **难度**：简单
- **标签**：数组、双指针、字符串

**题意**：给定字符串数组 `words`，按**数组顺序**找出其中**第一个**满足「正读 = 反读」的回文串并返回；若不存在，返回空串 `""`。

**约束**：

- $1 \leq \text{words.length} \leq 100$
- $1 \leq \text{words[i].length} \leq 100$
- $\text{words[i]}$ 仅由小写英文字母组成

## 2. 示例

**示例 1**

```text
输入：words = ["abc","car","ada","racecar","cool"]
输出："ada"
解释：第一个回文串是 "ada"。"racecar" 也是回文，但不是第一个。
```

**示例 2**

```text
输入：words = ["notapalindrome","racecar"]
输出："racecar"
解释：第一个也是唯一一个回文串。
```

**示例 3**

```text
输入：words = ["def","ghi"]
输出：""
解释：不存在回文串，返回空字符串。
```

## 3. 解题思路

### 3.1 暴力思路

对每个词构造反转串再比较：`w == reverse(w)`。逐词尝试，命中即返回。

- **正确性**：直接照抄回文定义，显然正确。
- **效率**：整体 $O(nm)$ 时间，但每个词需要 $O(m)$ **额外空间**存反转串，且**没有提前终止**——即使首字符就不匹配，也要把整串反转完。
- **判定**：数据规模 $n, m \leq 100$，任何正确做法都能 AC；但签到题也应给出 $O(1)$ 空间 + 提前终止的写法，这是本篇要沉淀的模板。

### 3.2 核心观察：回文 = 关于中心对称

![核心观察：回文 = 关于中心对称](images/wc272_q1_palindrome_concept.svg)

回文的本质是**位置对称**：$s$ 是回文，当且仅当每一对对称位置 $i$ 与 $m-1-i$ 上的字符相等。因此不必构造反转串，只需**双指针对撞**：`l` 从左端、`r` 从右端向中间收拢，逐对比较；一旦 `s[l] != s[r]` 立即否定（**首对否定**），循环正常结束（`l >= r`）即为回文。奇数长度时中间字符与自己对称，天然无需比较，`l < r` 这一循环条件**统一处理奇偶长度**。

### 3.3 算法流程

![算法流程：外层短路遍历 + 内层双指针判定](images/wc272_q1_palindrome_flow.svg)

1. **外层**从左到右遍历 `words`——「找第一个」类题目的通用模式是**命中即 `return`** 的短路遍历；
2. **内层**对当前词 `w` 双指针判定：`l = 0`，`r = m-1`；`l < r` 期间逐对比较，不等则否定；
3. 判定为回文 → 返回该词；遍历结束仍未命中 → 返回 `""`。

### 3.4 示例演算

![示例演算：第三个词 ada 命中](images/wc272_q1_palindrome_walkthrough.svg)

以 `words = ["abc","car","ada","racecar","cool"]` 走查：

| $i$ | 词 | 首对比较 | 结果 |
|----|------|---------|------|
| 0 | `"abc"` | `'a' != 'c'` | 否定，1 次比较 |
| 1 | `"car"` | `'c' != 'r'` | 否定，1 次比较 |
| 2 | `"ada"` | `'a' == 'a'` → `l=1, r=1` 停止 | **是回文，返回 `"ada"`** |

实际只比较了 3 对字符；`"racecar"` 与 `"cool"` 因短路**根本不会被检查**。对照示例 3：所有词均被首对否定，遍历结束返回 `""` ✓。

## 4. 算法细节

1. **判定封装**：回文判定抽成独立函数 `isPalindrome`，外层只做「遍历 + 命中即返回」，职责单一。
2. **循环条件取 `l < r`**：奇数长度在 `l == r` 处停止、偶数长度擦肩而过（`l > r`），中间字符无需特判。
3. **短路返回**：找到第一个回文后，后面的词**不再判定**——这是「找第一个」与「统计所有」的关键差异（后者必须扫完，且不能提前终止内层）。
4. **竞速写法**：比赛现场 Python 可用生成器一行 `next((w for w in words if w == w[::-1]), "")`；C++ 可用 `equal(w.begin(), w.begin() + w.size()/2, w.rbegin())` 让前半与逆序后半逐对比较，同样无需反转整串。两者与双指针等价，本篇代码以双指针为主。
5. **传参**：C++ 用 `const string&` 避免逐词拷贝。

## 5. 正确性证明

**引理 1**（判定引理）：长度为 $m$ 的串 $s$ 是回文 $\iff$ 对所有 $0 \leq i < \lfloor m/2 \rfloor$，$s[i] = s[m-1-i]$。

**证明**：回文定义即 $s = \text{reverse}(s)$，逐位写出即 $s[i] = s[m-1-i]$ 对**所有** $i$ 成立。该条件关于中心对称自反：$i$ 与 $m-1-i$ 互换后条件不变，故只需约束一半位置 $i < m/2$。当 $m$ 为奇数时 $i = m-1-i$ 的中间字符条件 $s[i] = s[i]$ 恒真，可略去。∎

**引理 2**（循环不变式）：双指针循环每轮开始时，$s[0..l-1]$ 与 $s[r+1..m-1]$ 已验证互为镜像，即对所有 $j < l$ 有 $s[j] = s[m-1-j]$。

**证明**：归纳。初始 $l = 0$，已验证区间为空，平凡成立。每轮若 $s[l] = s[r]$，则第 $l$ 对称位（$r = m-1-l$，由 $l < r$ 保证）验证通过，随后 $l{+}{+}$、$r{-}{-}$，不变式在下一轮保持；若不等则立即返回 `false`，不变式无需维护。∎

**定理**：算法返回 `words` 中第一个回文串；若不存在，返回 `""`。

**证明**：内层判定由引理 1 + 引理 2：循环以 `l >= r` 正常退出时，已验证前 $\lfloor m/2 \rfloor$ 对全部相等（每轮恰好推进一对，退出时验证对数足够覆盖引理 1 的全部条件），故判定为回文正确；中途返回 `false` 时引理 1 的某一条件被违反，否定也正确。外层按数组下标 $0, 1, \dots$ 顺序遍历且命中即返回，故返回者必是**最靠前**的回文串；若全无回文，循环自然耗尽后返回 `""`。∎

## 6. 复杂度分析

- **时间复杂度**：$O(nm)$。最坏遍历全部 $n$ 个词、每词内层至多 $\lfloor m/2 \rfloor$ 次比较。由于「首对否定 + 短路返回」，平均比较量远低于该上界；且可以证明 $O(nm)$ 在最坏情况下**不可改进**——若某词存在一对未读的对称字符且此前各词均已判定为非回文，对手可以让这一对相等或不等，从而翻转「是否存在回文」的答案，任何算法最坏必须读完关键词的全部对称对。
- **空间复杂度**：$O(1)$。双指针仅用两个下标，返回值不计入。Python 切片写法 `w == w[::-1]` 需 $O(m)$ 构造反转串，是签到提速的代价。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    string firstPalindrome(vector<string>& words) {
        for (const string& w : words) {
            if (isPalindrome(w)) return w;
        }
        return "";
    }
private:
    bool isPalindrome(const string& s) {
        int l = 0, r = s.size() - 1;
        while (l < r) {
            if (s[l] != s[r]) return false;
            ++l;
            --r;
        }
        return true;
    }
};
```

### Python

```python
class Solution:
    def firstPalindrome(self, words: list[str]) -> str:
        for w in words:
            if self._is_palindrome(w):
                return w
        return ""

    def _is_palindrome(self, s: str) -> bool:
        l, r = 0, len(s) - 1
        while l < r:
            if s[l] != s[r]:
                return False
            l += 1
            r -= 1
        return True
```

竞速一行版（`next` + 切片，供比赛现场参考）：

```python
class Solution:
    def firstPalindrome(self, words: list[str]) -> str:
        return next((w for w in words if w == w[::-1]), "")
```

## 8. 边界情况与易错点

1. **长度为 1 的词必是回文**：约束 $m \geq 1$，若首词就是单字符（如 `["x","y"]`），答案即 `"x"`——`l < r` 一次都不进循环直接判真，无需特判。
2. **「第一个」指数组顺序而非字典序**：示例 1 中 `"racecar"` 更长更「典型」，但答案是位置靠前的 `"ada"`。
3. **找不到必须返回空串 `""`**，不是 `None` 或不返回；Python 的 `next(..., "")` 默认值、C++ 的循环兜底 `return ""` 都为此服务。
4. **循环条件写成 `l < r` 而非 `l <= r`**：后者对奇数长度会多一次中间字符的自比较，不影响正确性但冗余；更糟的写法是拿 `l <= m/2` 当边界，在偶数长度会越界读 `s[m/2]` 与 `s[m/2]` 之外的比较逻辑。
5. **短路别写成扫完再挑**：先收集所有回文再取第一个（`[w for w in words if ...][0]`）功能等价但白白判定了后面的词；「找第一个」的语义本身许可提前返回。
6. **全否定样例自测**：`["def","ghi"]` 每词 1 次比较即否定，验证空串返回路径。
