# LeetCode 使数组 K 递增的最少操作次数 题解

## 1. 题目概述

- **标题 / 题号**：使数组 K 递增的最少操作次数（#2111，hard）
- **链接**：https://leetcode.cn/problems/minimum-operations-to-make-the-array-k-increasing/
- **来源**：LeetCode 第 272 场周赛 Q4
- **难度**：困难
- **标签**：数组、二分查找、最长非递减子序列（LNIS）

**题意**：给定下标从 0 开始、长度为 $n$ 的正整数数组 `arr` 与正整数 $k$。若对**每个**满足 $k \le i \le n-1$ 的下标 $i$ 都有 $\text{arr}[i-k] \le \text{arr}[i]$，则称 `arr` 是 **K 递增** 的。每次**操作**可任选一个下标，把该位置改成**任意正整数**。求使数组变成 K 递增的**最少操作次数**。

**约束**：

- $1 \le \text{arr.length} \le 10^5$
- $1 \le \text{arr}[i], k \le \text{arr.length}$

> 💡 **审题锚点**：① 约束只连**相隔恰为 $k$** 的下标对 $(i-k,\, i)$，**不要求相邻有序**；② $\le$ 是**非严格**的——相等合法；③ 「改成任意正整数」意味着保留元素之间的空位几乎总能填上——这是「保留最多 = 改动最少」转化的前提。

## 2. 示例

**示例 1**

```text
输入：arr = [5,4,3,2,1], k = 1
输出：4
解释：k = 1 时整个数组必须非递减。保留任意一个元素、改其余 4 个即可，
      如 [5,6,7,8,9]（保留 5）或 [1,1,1,1,1]（保留任一个 1）。
```

**示例 2**

```text
输入：arr = [4,1,5,2,6,2], k = 2
输出：0
解释：模 2 同余的两条链都已非递减——
  链0（下标 0,2,4）：[4,5,6] ✓
  链1（下标 1,3,5）：[1,2,2] ✓（相等合法）
注意 arr[0]=4 > arr[1]=1 相邻逆序，但 K 递增完全不受影响。
```

**示例 3**

```text
输入：arr = [4,1,5,2,6,2], k = 3
输出：2
解释：模 3 分三条链——
  链0（下标 0,3）：[4,2] → 保留 4，改 arr[3]（如 2→4）
  链1（下标 1,4）：[1,6] → 已非递减，不改
  链2（下标 2,5）：[5,2] → 保留 5，改 arr[5]（如 2→5）
改后如 [4,1,5,4,6,5]，共 2 次操作。
```

## 3. 解题思路

### 3.1 朴素尝试：就地修复贪心（错）与逐链 DP（超时）

**尝试一：从左到右「就地修复」**。最本能的写法：扫 $i$ 从 $k$ 到 $n-1$，一旦发现 $\text{arr}[i-k] > \text{arr}[i]$，就把它「修好」——比如把 $\text{arr}[i]$ 改成 $\text{arr}[i-k]$，计数加一。反例：链 $[3,1,2]$（即 $k=1$ 的子问题）——

- 就地修复：$3 > 1$，把 1 改成 3 得 $[3,3,2]$；$3 > 2$，再改一次，共 **2** 次；
- 最优：改掉开头的 3 得 $[1,1,2]$，只要 **1** 次。

毛病出在「改谁」：修复当前违规对时选错了保谁改谁，**局部最优 ≠ 全局最优**，而且改后的值还会连锁影响后续判定。

**尝试二：分组后对每条链做 $O(m^2)$ DP**。看出按 $\bmod k$ 分链（见 3.2）之后，对每条链用经典 DP 求 LNIS：$f[j] = \max_{i<j,\ \text{arr}[i] \le \text{arr}[j]} f[i] + 1$。单链 $O(m^2)$，$k = 1$ 时 $m = n = 10^5$，总计约 $10^{10}$ 次比较——**必然超时**。

> ⚠️ 两条路各给一个教训：就地修复**错在策略**（没想清楚保谁改谁），$O(m^2)$ DP **对但慢**（LNIS 有 $O(m \log m)$ 的贪心 + 二分）。共同突破口在分链之后认清「保留最多 = 改动最少」这一等价转化，然后套 LIS 家族模板一次收掉。

### 3.2 核心观察：约束按 $\bmod k$ 解耦成 $k$ 条独立链，链上「保留最多 = 改动最少」

![核心观察：按 mod k 切成 k 条独立链](images/wc272_q4_modk_decompose.svg)

三个关键事实：

1. **约束两端必同余**。条件 $\text{arr}[i-k] \le \text{arr}[i]$ 连接的下标满足 $(i-k) \equiv i \pmod k$，因此全部约束恰好落在「下标模 $k$ 同余」的链 $S_r = [\text{arr}[r],\, \text{arr}[r+k],\, \text{arr}[r+2k],\, \dots]$ 的**相邻两元素**上；链上所有约束成立 $\iff$ $S_r$ **非递减**。而不同链之间**没有任何约束相连**（任何约束的两端都同余），改一条链上的元素也绝不会影响另一条链的判定——问题**完全可分**。

2. **保留最多 = 改动最少**。固定一条长 $m$ 的链，最优策略是尽量**不动**那些本来就排好了的元素：所有不动的位置按链上顺序读出的值必须构成**非递减子序列**（否则两处保留值前 $>$ 后，改后依旧违规）；反过来，只要保留段非递减，其余位置总能用「恰当的正整数」一次改对（引理 3 给出显式构造）。于是：

$$\text{单链最少改动} = m - \text{LNIS}(S_r)$$

3. **总答案可加**。各链下标互不相交、判定互不干扰，把每条链的最少改动直接相加：

$$\boxed{\ \text{ans} = \sum_{r=0}^{k-1} \big(\, |S_r| - \text{LNIS}(S_r) \,\big)\ }$$

> 💡 **一句话总结**：K 递增的约束图是 $k$ 条互不相连的链 → 问题塌缩成 $k$ 个独立的「最少改动使非递减」；后者 = 链长 − 最长非递减子序列，正是 300 题 LIS 模板的非严格版。

### 3.3 算法流程：逐链「贪心 + 二分」求 LNIS

![算法流程：分组 → 贪心+upper_bound 求 LNIS → 累加](images/wc272_q4_lnis_flow.svg)

对每条链用「贪心 + 二分」求 LNIS 长度：维护数组 `tail`，**不变量**为 `tail[c]` = 当前前缀中「长度为 $c+1$ 的非递减子序列」的**最小可能结尾**（`tail` 自身非递减）。对链上每个 $x$：

1. `p = upper_bound(tail, x)`：找 `tail` 中**第一个严格大于** $x$ 的下标；
2. 若 `p == len(tail)`（全部 $\le x$）：$x$ 可接在当前最长子序列后，**追加**；
3. 否则 `tail[p] ← x`：把长度 $p+1$ 的最小结尾**换小**，给后续留更多余地。

链扫完后 `len(tail)` 即 $\text{LNIS}(S_r)$，累加 $|S_r| - \text{len(tail)}$；所有链处理完即得答案。

### 3.4 示例演算

![示例演算：arr=[4,1,5,2,6,2], k=3](images/wc272_q4_walkthrough.svg)

以示例 3 演算（见上图）：三条链 `[4,2]`、`[1,6]`、`[5,2]` 的 `tail` 演化、LNIS 与改动数依次为：

| 链 $r$ | $S_r$ | `tail` 演化（`upper_bound`） | LNIS | 改动 |
|--------|--------|------------------------------|------|------|
| 0 | `[4,2]` | `x=4`→`[4]`；`x=2`：`4>2` 替换→`[2]` | 1 | $2-1=1$ |
| 1 | `[1,6]` | `x=1`→`[1]`；`x=6`：全 $\le 6$ 追加→`[1,6]` | 2 | $2-2=0$ |
| 2 | `[5,2]` | `x=5`→`[5]`；`x=2`：`5>2` 替换→`[2]` | 1 | $2-1=1$ |

$\text{ans} = 1 + 0 + 1 = 2$ ✓，与示例输出一致；对应的一种改法是 $\text{arr}[3] = 4$、$\text{arr}[5] = 5$，得 `[4,1,5,4,6,5]`。

**对照示例 1**（`[5,4,3,2,1]`，$k=1$）：唯一一条链全程递减，每个新值都比 `tail[0]` 小、不停替换，`tail` 长度恒为 1，$\text{LNIS}=1$，答案 $5-1=4$。

**对照示例 2**（`[4,1,5,2,6,2]`，$k=2$）：链 `[4,5,6]` 与 `[1,2,2]` 都整体非递减，LNIS 分别等于链长，答案 $0+0=0$——算法对「已满足」的输入天然返回 0，无需特判。

## 4. 算法细节

1. **分组零成本**：不真的切数组。外层枚举余数 $r \in [0, k)$，内层 `for (i = r; i < n; i += k)` 步长遍历，天然完成「按下标模 $k$ 分链」。
2. **`tail` 的不变量**：`tail[c]` = 「长度 $c+1$ 的非递减子序列」的最小结尾。替换操作满足 $\text{tail}[p-1] \le x < \text{tail}[p] \le \text{tail}[p+1]$，故替换后 `tail` 仍非递减；替换只「改善」长度 $p+1$ 的结尾，不破坏其他长度（见 §5 引理 4 的逐段验证）。
3. **非递减 ⇒ `upper_bound`（`bisect_right`）**：处理 $x$ 时要跳过所有等值元素、找第一个 $> x$ 的位置。等值 $x$ 落在末尾时被**追加**，等值链得以延长——这是与严格 LIS（`lower_bound`）**唯一的**差别，也是本题最高频的 WA 点：

![upper_bound 与 lower_bound 对比](images/wc272_q4_upper_vs_lower.svg)

4. **`tail` 跨链复用**：每条链开始前 `clear()`（或重新开表），否则上一条链的残留会污染本链的 LNIS；`tail` 长度不超过 $\lceil n/k \rceil$，空间压力很小。
5. **答案不会溢出**：$0 \le \text{ans} \le n \le 10^5$，`int` 足够——对比同场 Q3 的 $\frac{n(n+1)}{2} \approx 5 \times 10^9$ 必须开 `long long`，本题是「反向提醒」：先算答案上界再定类型，能省掉一次无谓的排查。

## 5. 正确性证明

**引理 1**（链分解）：`arr` 是 K 递增的 $\iff$ 对每个 $r \in [0, k)$，链 $S_r$ 非递减。

**证明**：（⇒）任取链 $S_r$ 上相邻两元素 $\text{arr}[j],\ \text{arr}[j+k]$（$j \equiv r \pmod k$，$j+k \le n-1$）：取 $i = j+k$，则 $k \le i \le n-1$，K 递增给出 $\text{arr}[i-k] = \text{arr}[j] \le \text{arr}[j+k]$。链上每对相邻元素都满足 $\le$，即链非递减。（⇐）任取满足 $k \le i \le n-1$ 的 $i$：下标 $i-k$ 与 $i$ 同余（同属链 $S_{i \bmod k}$）且在链上**恰好相邻**（中间再无同余下标），链非递减给出 $\text{arr}[i-k] \le \text{arr}[i]$。所有约束成立。∎

**引理 2**（改动下界）：设某链长 $m$，任一使其非递减的改动方案中，**未被改动**的下标集 $U$ 按链上顺序读出的值序列非递减。故改动数 $= m - |U| \ge m - \text{LNIS}(S)$。

**证明**：方案改后链非递减。任取 $u, v \in U$ 且 $u$ 位于 $v$ 之前：非递减经传递给出 $\text{final}[u] \le \text{final}[v]$；而 $u, v$ 均未改动，$\text{final}[u] = \text{arr}[u]$、$\text{final}[v] = \text{arr}[v]$，故 $\text{arr}[u] \le \text{arr}[v]$。即 $U$ 按链序读出的值是一条非递减子序列，$|U| \le \text{LNIS}(S)$。∎

**引理 3**（可达性 / 显式构造）：保留链上任一非递减子序列 $a_1 \le a_2 \le \dots \le a_t$（按链序）不动，其余 $m - t$ 个位置各改一次即可使链非递减。

**证明**：构造：首个保留元素**之前**的空位全填 $1$（$1 \le a_1$，合法正整数）；$a_p$ 与 $a_{p+1}$ **之间**的空位全填 $a_p$（落在 $[a_p,\, a_{p+1}]$ 内）；末个保留元素**之后**的空位全填 $a_t$（$\ge a_t$）。逐段拼接为 $1\le \dots \le a_1 \le \dots \le a_t \le \dots$，整链非递减，且每个被改位置恰操作一次，共 $m - t$ 次。∎

**定理**：使 `arr` 变为 K 递增的最少操作次数为 $\text{ans} = \sum_{r=0}^{k-1} \big(|S_r| - \text{LNIS}(S_r)\big)$。

**证明**：由引理 1，方案可行 $\iff$ 每条链改后非递减；各链下标集互不相交，总操作数为各链操作数之和。对每条链：引理 2 给出下界 $|S_r| - \text{LNIS}(S_r)$；引理 3 取 $t = \text{LNIS}(S_r)$（LNIS 本身是一条非递减子序列）给出恰好达到该下界的方案。各链的构造互不冲突（一条链的改动不进入另一条链的判定），可同时取到各自下界，故总和下界可达，即最优值。∎

**引理 4**（贪心 + 二分求 LNIS）：扫描链的过程中保持不变量 $\mathcal{I}$——`tail` 非递减，且 `tail[c]` = 已扫描前缀中「长度 $c+1$ 的非递减子序列」的最小结尾（$0 \le c < L$，$L$ 为前缀 LNIS 长度）。从而任意时刻 $\text{len(tail)} = L$，扫完整条链即得 $\text{LNIS}(S_r)$。

**证明**：对已扫描元素个数 $j$ 归纳。$j=0$：`tail` 为空，$\mathcal{I}$ 平凡成立。设 $j$ 时成立，处理 $x$，记 $L = \text{len(tail)}$、$p$ = `upper_bound` 找到的第一个 $> x$ 的下标。

**情形 1：$p = L$（全部 $\le x$）**。新前缀中长 $L+1$ 的子序列必然存在（由 $\text{tail}[L-1] \le x$，把以最小结尾收尾的长 $L$ 子序列接上 $x$ 即得）；而任何长 $L+2$ 的非递减子序列：若不含 $x$，则落在旧前缀中，与 $L$ 的最大性矛盾；若含 $x$——$x$ 是前缀最后一个元素，必为其结尾——其前 $L+1$ 个元素构成旧前缀中长 $L+1$ 的非递减子序列，同样矛盾。故新 $L' = L+1$。又长 $L+1$ 的子序列都必以 $x$ 结尾，最小结尾就是 $x$：`push_back(x)` 保持 $\mathcal{I}$；原有位置不变，且 $x \ge \text{tail}[L-1]$ 使 `tail` 仍非递减。

**情形 2：$p < L$**。由 `tail` 非递减知 $\text{tail}[L-1] \ge \text{tail}[p] > x$。先证 $L' = L$：若新前缀有长 $L+1$ 的非递减子序列，它必以 $x$ 结尾，其前 $L$ 个元素是旧前缀中长 $L$ 的子序列且结尾 $\le x$，由 $\mathcal{I}$ 该结尾 $\ge \text{tail}[L-1] > x$，矛盾。再逐段验证 `tail[p] ← x` 保持 $\mathcal{I}$：

- **长度 $p+1$**：由 $\text{tail}[p-1] \le x$（$p = 0$ 时空链平凡），「最小结尾为 $\text{tail}[p-1]$ 的长 $p$ 子序列」接上 $x$ 得长 $p+1$、结尾恰为 $x$ 的子序列，故新最小结尾 $\le x$；反之旧前缀中任何长 $p+1$ 子序列的结尾 $\ge \text{tail}[p] > x$（$\mathcal{I}$），新前缀中以 $x$ 结尾者结尾为 $x$，故新最小结尾 $= x$，替换正确。
- **长度 $c \le p$**：不以 $x$ 结尾者仍在旧前缀中，最小结尾不变；以 $x$ 结尾者结尾为 $x \ge \text{tail}[p-1] \ge \text{tail}[c-1]$（非递减），不会更优。故不变。
- **长度 $c \ge p+2$**：若新前缀有此长度且以 $x$ 结尾的子序列，其前 $c-1$ 个元素是旧前缀中长 $c-1$ 的子序列、结尾 $\le x$；由 $\mathcal{I}$ 该结尾 $\ge \text{tail}[c-2] \ge \text{tail}[p] > x$，矛盾。故此类子序列仍全落在旧前缀，最小结尾不变。
- 替换后 $\text{tail}[p-1] \le x < \text{tail}[p] \le \text{tail}[p+1]$，`tail` 仍非递减。∎

**推论**：算法对每条链返回 $|S_r| - \text{len(tail)}$，由引理 4 等于 $|S_r| - \text{LNIS}(S_r)$；再由定理，累加结果即最少操作次数。

## 6. 复杂度分析

- **时间复杂度**：$O(n \log n)$。每个元素恰进入一条链一次，并在该链的 `tail` 上做一次二分：链 $r$ 长 $m_r = \lceil (n-r)/k \rceil$，单链 $O(m_r \log m_r)$；由 $\sum_r m_r = n$ 及 $\log$ 单调性，总计 $\sum_r m_r \log m_r \le n \log \lceil n/k \rceil \le O(n \log n)$。$k = 1$ 时取上界（$n = 10^5$ 时约 $1.7 \times 10^6$ 次比较，稳过）；$k$ 越大链越短，总耗时反而越小。
- **空间复杂度**：$O(\lceil n/k \rceil)$。`tail` 峰值长度不超过最长链的 LNIS，至多 $\lceil n/k \rceil$；逐链处理并 `clear()` 复用即可。$k = 1$ 时退化为 $O(n)$（约 0.4 MB）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int kIncreasing(vector<int>& arr, int k) {
        int n = arr.size(), ans = 0;
        vector<int> tail;                        // tail[c]：长度 c+1 的非递减子序列的最小结尾
        for (int r = 0; r < k; ++r) {             // ① 枚举链：下标 ≡ r (mod k)
            tail.clear();
            int m = 0;
            for (int i = r; i < n; i += k) {     // ② 链内贪心 + 二分求 LNIS
                ++m;
                int x = arr[i];
                auto it = upper_bound(tail.begin(), tail.end(), x);  // 第一个 > x
                if (it == tail.end()) {
                    tail.push_back(x);            // 全部 ≤ x：延长子序列
                } else {
                    *it = x;                      // 否则：换更小的结尾
                }
            }
            ans += m - (int)tail.size();          // ③ 该链最少改动 = m − LNIS
        }
        return ans;
    }
};
```

### Python

```python
import bisect

class Solution:
    def kIncreasing(self, arr: List[int], k: int) -> int:
        n, ans = len(arr), 0
        for r in range(k):                        # ① 枚举链：下标 ≡ r (mod k)
            tail = []                             # tail[c]：长度 c+1 的非递减子序列的最小结尾
            m = 0
            for i in range(r, n, k):              # ② 链内贪心 + 二分求 LNIS
                m += 1
                x = arr[i]
                p = bisect.bisect_right(tail, x)  # 第一个 > x 的位置（非递减用 right！）
                if p == len(tail):
                    tail.append(x)                # 全部 ≤ x：延长子序列
                else:
                    tail[p] = x                   # 否则：换更小的结尾
            ans += m - len(tail)                  # ③ 该链最少改动 = m − LNIS
        return ans
```

> 💡 **写法要点**：① 外层枚举余数、内层步长 $k$ 遍历，分组零成本；② `upper_bound` / `bisect_right` 是非递减的命门（§4 第 3 点）；③ `m` 在内层顺手计数，链扫完即得链长，避免再除再取整。

## 8. 边界情况与易错点

1. **`lower_bound` / `bisect_left` 是头号 WA 点**：非递减必须用 `upper_bound` / `bisect_right`。最小反例链 $[2,2]$：`upper_bound` 得 LNIS $= 2$（答案 0，正确）；`lower_bound` 在处理第二个 2 时命中等值替换，得 1（答案 1，错）。更完整的对比见 §4 配图。
2. **「就地修复」贪心是错的**：链 $[3,1,2]$ 上就地修 1 得 $[3,3,2]$、连锁再修 2 共 2 次；最优是改开头的 3 得 $[1,1,2]$ 只要 1 次。保谁改谁必须全局地想（= 谁落在 LNIS 里）。
3. **$k = n$ 时约束集为空，答案 0**：条件 $k \le i \le n-1$ 无可行下标。分组算法天然给出 0（每条链长 1，LNIS $=$ 1），**无需特判**——别手滑加特判反而改错。
4. **相邻逆序不是违规**：$k \ge 2$ 时 $\text{arr}[i] > \text{arr}[i+1]$ 完全合法（示例 2 的 $4 > 1$）。判定只看相隔恰为 $k$ 的对，审题别被「递增」二字带偏。
5. **`tail` 忘清空**：跨链复用 `tail` 而不 `clear()` / 重建，上一条链的残留会污染本链 LNIS（通常导致答案偏小 → WA）。
6. **链长不齐**：链 $r$ 的长度为 $\lceil (n-r)/k \rceil$，前 $n \bmod k$ 条恰好多 1 个元素；`for (i = r; i < n; i += k)` 天然处理，无需手动对齐。
7. **溢出判断是「反向考点」**：$\text{ans} \le n \le 10^5$，`int` 足够。与同场 Q3（$\sum \text{dp}$ 达 $5 \times 10^9$ 必须 `long long`）对照记忆：先估答案上界，再定类型。
8. **「任意正整数」是引理 3 的前提**：若改动值域受限（如上限 $10^9$ 且保留段需要填出超出值域的值），或操作改成「只能交换相邻元素」，结论与算法都要重新推导，不能照搬。
