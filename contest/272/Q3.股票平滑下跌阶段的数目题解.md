# LeetCode 股票平滑下跌阶段的数目 题解

## 1. 题目概述

- **标题 / 题号**：股票平滑下跌阶段的数目（#2110，medium）
- **链接**：https://leetcode.cn/problems/number-of-smooth-descent-periods-of-a-stock/
- **来源**：LeetCode 第 272 场周赛 Q3
- **难度**：中等
- **标签**：数组、动态规划、数学、计数

**题意**：给定整数数组 `prices` 表示一支股票的历史每日股价。一个**平滑下降的阶段**定义为连续一天或多天，其中**每日股价都比前一日恰好少 1**（阶段第一天的股价没有限制，单天也算）。请返回 `prices` 中平滑下降阶段的**总数**。

**约束**：

- $1 \leq \text{prices.length} \leq 10^5$
- $1 \leq \text{prices[i]} \leq 10^5$

> ⚠️ 审题锚点：判定条件是**相邻对**的布尔函数——$\text{prices}[i] = \text{prices}[i-1] - 1$，**恰好少 1**。差为 $0$（相等）、$-2$、$+1$ 等都算断链；这一点由示例 2 的 $7 \to 7$ 明确背书。

## 2. 示例

**示例 1**

```text
输入：prices = [3,2,1,4]
输出：7
解释：7 个平滑下降阶段为：
  [3], [2], [1], [4], [3,2], [2,1], [3,2,1]
  相邻差：3→2 为 −1 ✓，2→1 为 −1 ✓，1→4 为 +3 ✗
```

**示例 2**

```text
输入：prices = [8,6,7,7]
输出：4
解释：4 个平滑下降阶段：[8], [6], [7], [7]
  相邻差：8→6 为 −2 ✗，6→7 为 +1 ✗，7→7 为 0 ✗（相等不算）
```

**示例 3**

```text
输入：prices = [1]
输出：1
解释：单天自身就是一个平滑下降阶段。
```

## 3. 解题思路

### 3.1 暴力思路：枚举子数组 + 提前剪枝，最坏平方超时

最直观的做法：枚举左端点 $i$，向右扩展右端点 $j$，边扩展边检查相邻差是否为 $-1$；一旦不合法就停止扩展（再往右的子数组必然跨过这个非法对，一定不合法）。

```text
ans = 0
for i in 0..n-1:
    ans += 1                     # 单元素 [i] 必合法
    for j in i+1..n-1:
        if prices[j] == prices[j-1] - 1:
            ans += 1             # [i..j] 合法
        else:
            break                # 跨过非法对，停止
return ans
```

最坏情况是全程严格递减（如 $[10^5, 10^5-1, \dots, 1]$），内层循环累计执行 $\frac{n(n-1)}{2}$ 次，$n = 10^5$ 时约 $5 \times 10^9$——**必然超时**。

> ⚠️ 注意暴力法其实已经用对了「局部性」：提前 `break` 正是利用了「非法对是一刀刀口」的性质来剪枝。它输在**统计层面**——仍在按子数组逐个计数。突破口是翻转视角：不问「一共有多少个合法子数组」，而问「**以每个位置 $i$ 结尾**的合法子数组有几个」，把求和从子数组层降到元素层。

### 3.2 核心观察：判定局部性 → 刀口分段 + 按右端点计数

![核心观察：刀口分段与按右端点计数](images/wc272_q3_run_dp_concept.svg)

两个关键事实：

1. **非法相邻对是「刀口」**。判定只依赖相邻两个元素，与更远的元素无关。一旦某相邻对 $k-1 \to k$ 不满足「恰好少 1」，**任何同时包含 $k-1$ 和 $k$ 的子数组都不合法**——数组在此处被切了一刀，合法子数组绝不跨刀口。于是数组被切成若干**极大平滑段**，段内相邻差全为 $-1$，问题按段独立。

2. **按右端点计数，免重免漏**。定义 $\text{dp}[i]$ = **以 $i$ 结尾的最长平滑下降阶段长度**。以 $i$ 结尾的合法子数组，恰好是这个最长段的**全部后缀**——$[i]$、$[i-1, i]$、……、$[i - \text{dp}[i] + 1, \dots, i]$，共 $\text{dp}[i]$ 个；向左再多延伸一步就会引入非法对（否则 $\text{dp}[i]$ 还能更长）。因此：

$$\text{ans} = \sum_{i=0}^{n-1} \text{dp}[i]$$

每个子数组按**右端点**恰归一次，不重不漏。

由刀口分段还可得到等价的**分组视角**：长为 $m$ 的极大段内，$\text{dp}$ 值依次为 $1, 2, \dots, m$，段贡献即等差数列求和 $\frac{m(m+1)}{2}$；跨段子数组全不合法，无需统计。两个视角数值恒相等（见 §5 推论）。

> 💡 **一句话总结**：条件局部 ⇒ 刀口分段；按右端点计数 ⇒ $\text{ans} = \sum \text{dp}[i] = \sum \frac{m_j(m_j+1)}{2}$。前者是「为什么能 $O(n)$」，后者是「怎么数才不重不漏」。

### 3.3 算法流程：一次遍历 + 滚动变量

![算法流程：一次遍历，滚动变量 dp](images/wc272_q3_dp_flow.svg)

递推只依赖 $\text{dp}[i-1]$，无需开数组，一个滚动变量即可：

1. 初始化 $\text{ans} = 1$、$\text{dp} = 1$（把 $i = 0$ 的单元素阶段计入）；
2. $i$ 从 $1$ 到 $n-1$，每轮做一次 $O(1)$ 判断：
   - 若 $\text{prices}[i] = \text{prices}[i-1] - 1$：**续接**，$\text{dp} \gets \text{dp} + 1$；
   - 否则：**断链**，$\text{dp} \gets 1$（只剩自己一个单日）；
3. 每轮把 $\text{dp}$ 累加进 $\text{ans}$；
4. 循环结束返回 $\text{ans}$（**用 `long long`**，见 §8）。

**分组变体**：双指针扫出每个极大段 $[i, j)$，长 $m = j - i$，累加 $\frac{m(m+1)}{2}$，然后 $i \gets j$ 跳到下一段。两种写法复杂度相同，见 §7。

### 3.4 示例演算

![示例演算：dp 与 ans 逐步推进](images/wc272_q3_walkthrough.svg)

**示例 1** `prices = [3,2,1,4]`：

| $i$ | $\text{prices}[i]$ | 相邻差 | $\text{dp}$ | $\text{ans}$ |
|-----|--------------------|--------|-------------|--------------|
| 0 | 3 | — | 1 | 1 |
| 1 | 2 | $-1$ ✓ | 2 | 3 |
| 2 | 1 | $-1$ ✓ | 3 | 6 |
| 3 | 4 | $+3$ ✗ | 1 | **7** |

$i = 0..2$ 构成长 3 的段 $[3,2,1]$，贡献 $1+2+3 = 6 = \frac{3 \times 4}{2}$；$i = 3$ 断链归 1，贡献 1，合计 7。

**示例 2** `prices = [8,6,7,7]`：三个相邻差 $-2, +1, 0$ 都 $\neq -1$，全程断链，$\text{dp}$ 恒为 1，合计 4 个单日阶段——注意 $7 \to 7$（差 $0$）也断链。

**再看一个双段的例子** `prices = [3,2,1,4,3]`（示例 1 的扩展）：刀口在 $1 \to 4$，切成段 $[3,2,1]$（$m=3$，贡献 6）与 $[4,3]$（$m=2$，贡献 3），$\text{dp} = [1,2,3,1,2]$，两种视角都得到 $\text{ans} = 9$。

## 4. 算法细节

1. **$\text{dp}[i]$ 的双重身份**：它既是「以 $i$ 结尾的最长段长度」，又是「以 $i$ 结尾的合法子数组个数」（最长段的全部后缀，一一对应）。前者便于递推，后者便于求和——一个定义两头用，是本题最值得沉淀的观察。
2. **滚动变量**：递推 $\text{dp}[i] = f(\text{dp}[i-1], \text{prices}[i-1], \text{prices}[i])$ 只依赖前一项，用单个变量滚动即可，空间 $O(1)$。
3. **初始化的两种等价写法**：要么 $\text{ans} = \text{dp} = 1$ 且循环从 $i = 1$ 开始；要么 $\text{ans} = 0$、循环从 $i = 0$ 开始（首轮必走「断链」分支）。**两套写法不可混搭**——`ans = 0` 配「循环从 1 开始」会漏掉 $i = 0$ 的那 1 个。
4. **分组变体的指针细节**：内层 `j` 从 `i + 1` 起，条件为 $\text{prices}[j] = \text{prices}[j-1] - 1$；段长 $m = j - i$，累加后 $i \gets j$ 直接跳到下一段起点，两指针都不回退。
5. **暴力剪枝与本解的关系**：暴力的提前 `break` 已经隐含「刀口」思想，缺的只是把逐子数组计数聚合成按右端点求和——从「数出每个子数组」到「算出每个右端点的贡献」，正是 $O(n^2) \to O(n)$ 的一步。

## 5. 正确性证明

**引理 1**（后缀刻画）：设 $[a..i]$ 为以 $i$ 结尾的最长平滑段（$a$ 为最小合法左端点）。则以 $i$ 结尾的平滑下降阶段恰为 $[l..i]$，$a \leq l \leq i$，共 $\text{dp}[i] = i - a + 1$ 个。

**证明**：$[a..i]$ 内部所有相邻对合法，故其任一后缀 $[l..i]$（$a \leq l \leq i$）也是平滑下降阶段。反之，设 $[l..i]$ 是任一平滑下降阶段：若 $l < a$，则 $[l..i]$ 本身就是以 $i$ 结尾、比 $[a..i]$ 更长的平滑段，与 $a$ 的最小性矛盾；故 $l \geq a$。两侧合起来恰是 $\text{dp}[i]$ 个，不多不少。∎

**引理 2**（递推）：$\text{dp}[0] = 1$；对 $i \geq 1$：

$$\text{dp}[i] = \begin{cases} \text{dp}[i-1] + 1, & \text{prices}[i] = \text{prices}[i-1] - 1 \\ 1, & \text{否则} \end{cases}$$

**证明**：**情形 A**（差为 $-1$）：设 $[a..i-1]$ 为以 $i-1$ 结尾的最长平滑段。新对 $i-1 \to i$ 合法，故 $[a..i]$ 平滑，得 $\text{dp}[i] \geq \text{dp}[i-1] + 1$；另一方面，任何以 $i$ 结尾且长度 $\geq 2$ 的平滑段 $[l..i]$ 都包含对 $i-1 \to i$（合法）且去掉 $i$ 后 $[l..i-1]$ 仍平滑，故 $l \geq a$，得 $\text{dp}[i] \leq i - a + 1 = \text{dp}[i-1] + 1$。两不等式夹出等号。**情形 B**（差 $\neq -1$）：任何以 $i$ 结尾且长度 $\geq 2$ 的段都包含这个非法对，不合法；只剩 $[i]$ 自身，$\text{dp}[i] = 1$。∎

**定理**：算法返回值等于 `prices` 中平滑下降阶段的数目。

**证明**：把全部平滑下降阶段按**右端点**划分为 $n$ 组。第 $i$ 组由引理 1 恰含 $\text{dp}[i]$ 个；各 $\text{dp}[i]$ 由引理 2 可在一次线性递推中全部得出，且算法每轮把当前 $\text{dp}$ 累加进 `ans`（含 $i = 0$ 的初始 1）。分组互不相交、并集为全体阶段，故计数不重不漏，$\text{ans} = \sum_{i=0}^{n-1} \text{dp}[i]$ 即为所求。∎

**推论**（分组视角等价）：设刀口把数组切成极大平滑段，长度为 $m_1, \dots, m_k$，则 $\text{ans} = \sum_{j=1}^{k} \frac{m_j(m_j+1)}{2}$。

**证明**：跨段的子数组必含某个刀口处的非法对，不合法，故按段独立。段 $j$ 内 $\text{dp}$ 值依次为 $1, 2, \dots, m_j$（引理 2 在段内逐项续接、段首归 1），段贡献 $\sum_{t=1}^{m_j} t = \frac{m_j(m_j+1)}{2}$。与定理的 $\sum \text{dp}[i]$ 逐段相加即一致。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。DP 版一次遍历，每个元素一次 $O(1)$ 判断 + 一次累加；分组版双指针各只前进不回退，每个元素至多作为段内成员与段尾判定被访问两次，仍为线性。
- **空间复杂度**：$O(1)$。仅 `dp`、`ans` 两个滚动变量，无任何额外数组（暴力若用递归/栈也不需要，但时间上不可行）。

## 7. 参考代码

### C++：一次遍历 DP

```cpp
class Solution {
public:
    long long getDescentPeriods(vector<int>& prices) {
        int n = prices.size();
        long long ans = 1;          // 计入 i = 0 的单元素阶段
        long long dp = 1;           // 滚动记录 dp[i-1]
        for (int i = 1; i < n; ++i) {
            if (prices[i] == prices[i - 1] - 1) {
                ++dp;               // 续接：以 i 结尾的后缀数 +1
            } else {
                dp = 1;             // 断链：只剩自己
            }
            ans += dp;              // 累加以 i 结尾的 dp[i] 个阶段
        }
        return ans;
    }
};
```

### Python：一次遍历 DP

```python
class Solution:
    def getDescentPeriods(self, prices: List[int]) -> int:
        ans = 1                     # 计入 i = 0
        dp = 1                      # 滚动记录 dp[i-1]
        for i in range(1, len(prices)):
            if prices[i] == prices[i - 1] - 1:
                dp += 1             # 续接
            else:
                dp = 1              # 断链
            ans += dp
        return ans
```

### 变体：极大段分组 + 等差数列求和（C++）

```cpp
class Solution {
public:
    long long getDescentPeriods(vector<int>& prices) {
        int n = prices.size();
        long long ans = 0;
        int i = 0;
        while (i < n) {
            int j = i + 1;
            while (j < n && prices[j] == prices[j - 1] - 1) {
                ++j;                // 扩展出极大平滑段 [i, j)
            }
            long long m = j - i;    // 段长用 long long，防 m*(m+1) 溢出
            ans += m * (m + 1) / 2; // 段内 dp 为 1..m，等差求和
            i = j;                  // 跳到下一段起点
        }
        return ans;
    }
};
```

### 变体：极大段分组（Python）

```python
class Solution:
    def getDescentPeriods(self, prices: List[int]) -> int:
        ans = 0
        i, n = 0, len(prices)
        while i < n:
            j = i + 1
            while j < n and prices[j] == prices[j - 1] - 1:
                j += 1
            m = j - i
            ans += m * (m + 1) // 2
            i = j
        return ans
```

> 💡 **选型建议**：DP 版代码最短、模板最通用（换判定条件即适用于「非递增」「差至多 k」等变体）；分组版把「刀口分段」的几何直觉写得最直白。比赛任选其一，复杂度均为 $O(n) / O(1)$。

## 8. 边界情况与易错点

1. **答案溢出是头号坑**：全程递减（$10^5, 10^5-1, \dots, 1$）时 $\text{ans} = \frac{n(n+1)}{2} \approx 5 \times 10^9$，**超过 32 位 `int`**（$\approx 2.1 \times 10^9$）。C++ 的 `ans` 必须 `long long`；分组变体里 $m(m+1)$ 在 $m = 10^5$ 时约 $10^{10}$，同样必须先转 `long long` 再相乘（`m` 声明为 `long long`，或写 `1LL * m * (m + 1) / 2`）。Python 整数任意精度，无此虑。
2. **漏掉 $i = 0$**：`ans = 0` 却让循环从 $i = 1$ 开始，会少算第 0 天的单元素阶段（对 `n = 1` 直接输出 0，WA）。两套初始化（§4 第 3 点）切忌混搭。
3. **「恰好少 1」不含相等**：示例 2 的 $7 \to 7$（差 $0$）断链。把条件写成 `prices[i] <= prices[i - 1]`（非递增）或 `abs(差) == 1` 都是审题错误。
4. **判定方向别写反**：是 $\text{prices}[i] = \text{prices}[i-1] - 1$（下降），写成 $\text{prices}[i-1] = \text{prices}[i] - 1$ 就变成了「平滑上升」，对单调输入全错。
5. **$n = 1$ 无需特判**：初始化 `ans = 1`，循环体不执行，直接返回 1，与示例 3 一致。
6. **`int` 比较本身安全**：$\text{prices}[i-1] \geq 1$，故 $\text{prices}[i-1] - 1 \geq 0$，不会下溢；真正的雷只在答案累加（第 1 点）。
7. **暴力剪枝救不了复杂度**：提前 `break` 后仍是 $O(n^2)$ 最坏（全程递减），$n = 10^5$ 必 TLE——刀口思想要用在**计数聚合**上，而不是枚举剪枝上。
8. **分组变体的跳段**：累加后是 `i = j`（跳到段尾后第一个位置），写成 `i = j + 1` 会跳过下一段首元素、`i += 1` 则退化成平方级。
