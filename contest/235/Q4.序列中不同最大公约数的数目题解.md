# LeetCode 序列中不同最大公约数的数目 题解

## 1. 题目概述

- **标题 / 题号**：序列中不同最大公约数的数目（#1819，hard）
- **链接**：https://leetcode.cn/problems/number-of-different-subsequences-gcds/
- **来源**：LeetCode 第 235 场周赛 Q4
- **难度**：困难
- **标签**：数组、数学、数论、计数、枚举（调和级数）、最大公约数

**题意**：给定正整数数组 `nums`。子序列指删掉若干元素（或不删）得到的序列。对每个**非空**子序列求其全体元素的最大公约数，统计这些 gcd 中**互异的值**有多少个。

**约束**：

- $1 \le n \le 10^5$
- $1 \le \text{nums}[i] \le 2 \times 10^5$

> 💡 **审题关键**：两行约束定死了打法——$n \le 10^5$ 意味着 $2^n$ 个子序列**一个都不能碰**，而问的又只是「不同值有多少个」而非「每个值怎么构造」，这是把枚举对象从**子序列**搬到**值域**的信号；$\text{nums}[i] \le 2\times10^5$ 的超小值域则是「值域当桶 + 枚举倍数（调和级数）」的招牌信号（同款套路见 952 按公因数计算最大组件大小）。赛时另一个方向性提醒：**可行 gcd 集合 ≠ 整体 gcd 的约数集**（反例 $[4,8]$：整体 gcd 为 4，其约数 2 却造不出来），任何「先算整体 gcd 再筛约数」的思路都是歧途，必须逐值独立判定可达性。

> 💡 本题在本仓库另有[每日题解 1819](../../solution/1801-1900/1819_序列中不同最大公约数的数目.md)：以「审题直觉、调和级数技巧的通用性、面试问答」展开。本篇按**周赛复盘视角**重写：侧重**赛时信号识别**（从 $2^n$ 到值域判据的转化路径）、**引理—定理完整证明链**与「判据 / 哨兵 / 早停」的**踩坑清单**，两篇互为印证。

```text
      互异值 {6,10,3,2,1}，共 5 个。
```

```text
      互异值 {5,6,15,40,1,2,3}，共 7 个。
```

## 3. 解题思路

### 3.1 暴力思路：枚举全部子序列

枚举全部 $2^n - 1$ 个非空子序列，逐一求 gcd 丢进哈希集合，最后返回集合大小：

```text
ans_set = ∅
for 每个非空子序列 S ⊆ nums:
    ans_set.add(gcd(S))
return |ans_set|
```

$n = 10^5$ 时 $2^n$ 是天文数字（$n = 30$ 就已是十亿量级），完全不可行。瓶颈极其明确：**子序列维度指数爆炸**。

> 💡 **转化**：任何可能出现的 gcd 都是某个元素的约数，候选值至多 $V = \max(\text{nums}) \le 2\times10^5$ 个。应该反过来——**枚举候选值 g，判定它是否可达**。但「判定 g 可达」朴素做也不轻：可挑的子序列仍是指数多个，需要一个把「所有子序列」一次性压缩掉的判据。

### 3.2 核心观察：在场倍数判据 gcd(M(g)) = g

![核心观察：g 可达当且仅当所有在场 g 的倍数的 gcd 等于 g](images/wc235_q4_multiples_gcd_concept.svg)

对值域内每个 $g$，定义 $M(g)$ 为 `nums` 中**是 $g$ 的倍数**的元素全体——它本身就是一个子序列（把所有非 $g$ 倍数的元素删掉即可）。

**判据**：$g$ 可作为某非空子序列的 gcd $\iff$ $M(g) \ne \varnothing$ 且 $\gcd(M(g)) = g$。

直觉是一副「手牌」模型：想凑出 gcd $= g$，能用的手牌只有 $g$ 的倍数（$S$ 的每个元素都被 $g$ 整除）。把这些手牌**全部打出**（取 $S = M(g)$）时 gcd 压到最低点 $\gcd(M(g))$；而元素越多 gcd 只小不大（$A \subseteq B \Rightarrow \gcd(B) \mid \gcd(A)$），所以 $M(g)$ 的任何子集的 gcd 都被 $\gcd(M(g))$ 整除。于是：

- 最低点恰好是 $g$ ⟹ 全打出去就直接实现 $g$（**充分性**，取 $S = M(g)$）；
- 最低点是 $kg\ (k \ge 2)$ ⟹ 任何挑法都至少多带一个因子 $k$，$g$ 永远造不出（**必要性**的逆否）。

判据的价值：**把 $2^n$ 个子序列一次性压成「值域内每个 $g$ 一条 gcd 链」**。顺带一个轻松的推论（证明见 §5）：凡是**在场**的值 $v$ 必然计入——$v \in M(v)$ 且 $v$ 整除 $M(v)$ 中一切元素，故 $\gcd(M(v)) = v$；真正需要判据把关的，是那些**不在场**的约数（示例 2 里的 1、2、3）。

### 3.3 算法流程：值域桶 + 调和级数扫描

![算法流程：建桶后逐 g 枚举在场倍数，运行 gcd 一旦等于 g 提前退出](images/wc235_q4_sieve_flow.svg)

1. **建桶**：$V = \max(\text{nums})$，布尔桶 $\text{exist}[1..V]$（天然去重），$O(n)$；
2. **外层** $g = 1 \dots V$：初始化运行 gcd $G \leftarrow 0$；
3. **内层**枚举倍数 $m = g, 2g, 3g, \dots \le V$：若 $\text{exist}[m]$，则 $G \leftarrow \gcd(G, m)$（$\gcd(0,m) = m$ 让首个命中无缝入链）；**一旦 $G = g$ 立即 break**——$G$ 只减不增且始终是 $g$ 的倍数，触底即封口；
4. **判定**：内层结束后若 $G = g$ 则计数（$M(g)$ 为空时 $G$ 保持 $0 \ne g$，自动落选）；
5. 返回计数值。

内层对每个 $g$ 扫 $\lfloor V/g \rfloor$ 个槽位，总扫描量 $\sum_{g=1}^{V} \lfloor V/g \rfloor \approx V \ln V \approx 2.4\times10^6$（$V = 2\times10^5$）——正是埃氏筛同款的**调和级数**形状，值域题的标配套路。

### 3.4 示例演算

![示例演算：nums=[5,15,40,5,6] 的逐 g 判定走查表](images/wc235_q4_walkthrough.svg)

以示例 2 走查（$V = 40$，在场 $\{5,6,15,40\}$），三个看点：

- **g = 5**：首个在场倍数就是 5 自己，$G = 5 = g$ 立即 break——「单元素子序列」的场景被早停天然覆盖，15、40 根本不用扫；
- **g = 1**：$G$ 走到 5 → $\gcd(5,6) = 1$ 封底，两个元素就够；
- **g = 4**：唯一在场倍数是 40，$G = 40 \ne 4$，扫完全程落选。

计入 $\{1,2,3,5,6,15,40\}$，答案 7 ✓。对照暴力：全部 $2^5 - 1 = 31$ 个非空子序列逐一求 gcd，结果同为 7。

## 4. 算法细节

1. **$V$ 取 $\max(\text{nums})$ 而非题面上限 $2\times10^5$**：数组很小时扫描量骤减（如 $\max = 100$ 时 $\sum \lfloor V/g \rfloor$ 只有几百），代价仅一次 $O(n)$ 求 max。
2. **$G$ 的哨兵值必须是 0**：数学惯例 $\gcd(0, m) = m$（0 是 gcd 运算的单位元），C++ `std::gcd` 与 Python `math.gcd` 都遵守。「第一个在场倍数」因此无需特判直接入链；$M(g)$ 为空时 $G$ 保持 0，因 $g \ge 1$ 而 $0 \ne g$，**空集情况零特判**。
3. **早停的正确性与收益**：链上每个 $m$ 都是 $g$ 的倍数，故 $G$ 始终是 $g$ 的倍数且单调不增；一旦 $G = g$，后续任何 gcd 都不会再变——早停**不影响结果，只影响速度**。收益巨大：$g$ 本身在场时第一次命中就退出；最坏用例下 Python 没有它基本必超时。
4. **gcd 调用次数的精确账**：gcd 只发生在「在场合数」上。每个在场值 $v$ 恰被它的每个约数 $g$ 的扫描各命中一次，故总 gcd 次数 $= \sum_{v \text{ 在场}} d(v)$（约数个数函数）；即使 $1..V$ 全在场也只有 $\approx V \ln V \approx 2.4\times10^6$ 次。
5. **Python 微优化**：`from math import gcd` 放循环外、`exist` 保持局部变量、内层用 `range(g, V+1, g)` 原生步长生成倍数——循环体在 $2.4\times10^6$ 次量级下，解释器开销不可忽视。
6. **备选写法（一般不必）**：先对每个在场值枚举约数、只对「确有在场倍数」的候选 $g$ 执行验证。它省掉的只是不做 gcd 的空扫部分，主线复杂度不变，代码反而更长。

## 5. 正确性证明

**引理 1**（必要性）：设非空子序列 $S$ 满足 $\gcd(S) = g$，则 $M(g) \ne \varnothing$ 且 $\gcd(M(g)) = g$。

**证明**：$\gcd(S) = g$ 意味着 $g$ 整除 $S$ 中每个元素，故 $S \subseteq M(g)$，特别地 $M(g) \ne \varnothing$。一方面，$M(g)$ 中每个元素都是 $g$ 的倍数，故 $g$ 是它们的公共约数，$g \mid \gcd(M(g))$。另一方面，$\gcd(M(g))$ 整除 $M(g)$ 中每个元素，特别地整除 $S$ 中每个元素，即它是 $S$ 的公共约数，故整除 $S$ 的最大公约数：$\gcd(M(g)) \mid g$。两式夹逼得 $\gcd(M(g)) = g$。∎

**引理 2**（充分性）：若 $M(g) \ne \varnothing$ 且 $\gcd(M(g)) = g$，则存在 gcd 恰为 $g$ 的非空子序列。

**证明**：$M(g)$ 由 `nums` 删去所有非 $g$ 倍数的元素得到，是非空子序列；其全体元素的最大公约数即 $\gcd(M(g)) = g$。∎

**定理**：`nums` 的非空子序列可取得的互异 gcd 集合恰为 $\{\, g \in [1, V] : \gcd(M(g)) = g \,\}$，其中 $V = \max(\text{nums})$；算法返回该集合的大小。

**证明**：「⊆」设 $g$ 可取得，取见证子序列 $S$：$g$ 整除 $S$ 的某个元素（$S$ 非空），故 $g \le V$，落在枚举范围内；由引理 1，$\gcd(M(g)) = g$。「⊇」设 $\gcd(M(g)) = g$，则 $M(g) \ne \varnothing$（否则 $\gcd(M(g))$ 无定义，亦可视为不满足等式），由引理 2，$g$ 可取得。故两集合相等。算法对每个 $1 \le g \le V$ 以运行 gcd 链计算 $\gcd(M(g))$——由 gcd 的结合律 $\gcd(a,b,c) = \gcd(\gcd(a,b),c)$ 与单位元性质 $\gcd(0,m) = m$，链的终态恰为全部在场倍数的 gcd；与 $g$ 比较后计数，返回值即集合大小。∎

**推论 1**：答案 $\ge$ `nums` 中互异值的个数；特别地答案 $\ge 1$。

**证明**：设值 $v$ 在场。$M(v)$ 中每个元素都是 $v$ 的倍数，故 $v \mid \gcd(M(v))$；又 $v \in M(v)$，故 $\gcd(M(v)) \mid v$。于是 $\gcd(M(v)) = v$，$v$ 被计入。∎

## 6. 复杂度分析

- **时间复杂度**：宽松上界 $O(V \log^2 V)$，实际远低。拆开看：建桶 $O(n)$；内层扫描总量 $\sum_{g=1}^{V} \lfloor V/g \rfloor = O(V \ln V) \approx 2.4\times10^6$ 次 $O(1)$ 桶查询；gcd 调用至多 $\sum_{v \text{ 在场}} d(v) = O(V \ln V)$ 次、每次欧几里得 $O(\log V)$。早停把大量 $g$ 的验证剪到一两次 gcd。$V = 2\times10^5$ 时 C++ 毫秒级，Python 依赖早停在 1s 量级内。
- **空间复杂度**：$O(V)$。`exist` 布尔桶约 200KB（`vector<char>`），远优于任何基于哈希集合存子序列 gcd 的方案。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int countDifferentSubsequenceGCDs(vector<int>& nums) {
        int V = *max_element(nums.begin(), nums.end());
        vector<char> exist(V + 1, 0);
        for (int x : nums) exist[x] = 1;

        int ans = 0;
        for (int g = 1; g <= V; ++g) {
            int G = 0;                      // gcd(0, m) = m：单位元哨兵
            for (int m = g; m <= V; m += g) {
                if (exist[m]) {
                    G = gcd(G, m);
                    if (G == g) break;      // G 只减不增且是 g 的倍数：触底即封口
                }
            }
            ans += (G == g);                // M(g) 为空 => G 保持 0，自动落选
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def countDifferentSubsequenceGCDs(self, nums: List[int]) -> int:
        from math import gcd
        V = max(nums)
        exist = [False] * (V + 1)
        for x in nums:
            exist[x] = True

        ans = 0
        for g in range(1, V + 1):
            G = 0                           # gcd(0, m) = m：单位元哨兵
            for m in range(g, V + 1, g):
                if exist[m]:
                    G = gcd(G, m)
                    if G == g:              # 触底即封口（Python 的性能生死线）
                        break
            if G == g:
                ans += 1
        return ans
```

> ⚠️ 两版刻意同构，三处关键点互为补充：`G = 0` 哨兵同时消化「首个命中」与「空集」两种边界；早停 `G == g` 是纯性能优化（不影响正确性，见 §4 第 3 条）；终态 `ans += (G == g)` 完成判据比较。

## 8. 边界情况与易错点

1. **方向性陷阱（本题最高频翻车点）**：可行 gcd 集 ≠「整体 gcd 的约数集」。反例 $[4,8]$：整体 gcd $= 4$，其约数 2 整除一切元素，但 $M(2) = \{4,8\}$、$\gcd = 4 \ne 2$，2 不可达，答案仅 2。反过来，比整体 gcd **大**的值（如 $[6,10]$ 中的 6、10）也照样可达。任何「先算整体 gcd 再筛」的预处理都是错的。
2. **哨兵初始化**：`G` 必须为 0。初始化成 1 会让 $\gcd(1, m) = 1$ 把一切判成可达；初始化成 −1 或「首元素」则要么未定义要么漏判首个命中。
3. **空 $M(g)$ 不需要特判**：`G` 保持 0，与 $g \ge 1$ 永不相等。若画蛇添足先判 $M(g)$ 非空，反而多一个分支、多一次扫描。
4. **早停别漏写**：不影响正确性（触底后 gcd 不再变化），但最坏用例下它是 Python TLE 与 AC 的分界线；$g$ 在场时还能把整条链剪到一次 gcd。
5. **别把「在场值」单独统计**：判据天然覆盖（推论 1），「先数互异值、再判不在场约数」的写法容易在去重或边界上翻车，且并不更快。
6. **重复元素**：桶天然去重；示例 2 的两个 5 对判据零影响（$\gcd(5,5) = 5$）。
7. **数值范围无忧**：全程值 $\le 2\times10^5$、答案 $\le V$，`int` 安然无恙，无取模、无 64 位问题——与同场 Q3 的 `long long` 恰成对照。
8. **$V$ 别写死 $2\times10^5$**：小值域用例（如全部元素 $\le 100$）会被白拖几个数量级；`max(nums)` 一次 $O(n)$ 把扫描量从 $2.4\times10^6$ 降到几百。
