# LeetCode 分割数组 题解

## 1. 题目概述

- **标题 / 题号**：分割数组（#3046，easy）
- **链接**：https://leetcode.cn/problems/split-the-array/
- **来源**：LeetCode 第 386 场周赛 Q1
- **难度**：简单
- **标签**：数组、哈希表、计数

**题意**：给定一个长度为**偶数**的整数数组 `nums`，把它分割成 `nums1` 和 `nums2` 两部分，要求：

- 长度对半：$\text{nums1.length} = \text{nums2.length} = n / 2$；
- `nums1` **内部**元素互不相同，`nums2` **内部**元素互不相同（两组**之间**允许重复）。

能分割返回 `true`，否则返回 `false`。

**约束**：

- $1 \le n \le 100$，且 $n \bmod 2 = 0$
- $1 \le \text{nums}[i] \le 100$

> 💡 读题关键：这是只问**可行性**、不要求输出方案的判定题。注意「互不相同」的作用范围是**各组内部**——示例 1 里 `nums1` 和 `nums2` 都含有 1 和 2，照样合法。

## 2. 示例

**示例 1**

```text
输入：nums = [1,1,2,2,3,4]
输出：true
解释：分割 nums 的可行方案之一是 nums1 = [1,2,3] 和 nums2 = [1,2,4]。
```

**示例 2**

```text
输入：nums = [1,1,1,1]
输出：false
解释：分割 nums 的唯一可行方案是 nums1 = [1,1] 和 nums2 = [1,1]。但 nums1 和 nums2 都不是由互不相同的元素构成。因此，返回 false。
```

**示例 3**（补充：全部由成对值构成，没有单值需要配平）

```text
输入：nums = [2,2,5,5]
输出：true
解释：nums1 = [2,5]，nums2 = [2,5]。d = 2、s = 0，两侧自动各占 n/2 = 2 个。
```

## 3. 解题思路

### 3.1 暴力思路：枚举对半划分

把「可行性」当成搜索问题：从 $n$ 个位置里选 $n/2$ 个归入 `nums1`、其余归入 `nums2`，共 $\binom{n}{n/2}$ 种选法；每种选法再用哈希集合检查两侧各自有无重复。

- $n = 100$ 时 $\binom{100}{50} \approx 10^{29}$，完全不可行；
- 即使回溯 + 判重剪枝，本质上仍在指数级的划分空间里找路径。

暴力失败的根源：**把判定问题当成了构造问题**。可行性其实由一个极简单的统计量——**每个值的出现次数**——完全决定，与元素顺序、位置毫无关系。

### 3.2 核心观察：鸽巢原理给出频次天花板 2

![核心观察：出现次数与可划分性的双向判定](images/split_array_frequency_rule.svg)

**必要性（某值出现 $\ge 3$ 次必失败）**：设值 $v$ 出现 $k \ge 3$ 次。$k$ 个 $v$ 要分进 `nums1`、`nums2` 两个「巢」，由**鸽巢原理**，必有一侧分到 $\lceil k/2 \rceil \ge 2$ 个 $v$——该侧内部重复，方案非法。**无论怎么分都躲不开**，直接 `false`。

**充分性（所有值 $\le 2$ 次必成功）**：设出现 2 次的值有 $d$ 个、出现 1 次的值有 $s$ 个，则 $n = 2d + s$。构造划分：

1. 每个出现 2 次的值**一左一右**各放一个，两侧各得 $d$ 个且无重复；
2. 两侧还差 $n/2 - d = s/2$ 个名额，把 $s$ 个单值**对半**分进去。

关键在于 $s = n - 2d$：$n$ 是偶数、$2d$ 是偶数，所以 $s$ **必为偶数**，恰好能对半——「两侧各 $n/2$ 个」的长度约束永远自动满足，不会额外卡人。

> 💡 结论一句话：**答案 $\iff$ 所有值的出现次数 $\le 2$**。判定只与频次有关，与顺序无关。

> ⚠️ 常见误区：担心「长度对半」带来额外失败 case。不会——$s$ 为偶数的论证保证频次条件满足时总能配平；反过来，频次条件不满足时怎么分都救不回来。

### 3.3 算法流程：一趟计数、超 2 即剪枝

![算法流程：计数与提前剪枝](images/split_array_algorithm_flow.svg)

1. 建计数表（值域 $1 \le x \le 100$，开长度 101 的定长数组即可）；
2. 遍历 `nums`，对每个 $x$ 执行 `++cnt[x]`；
3. 若自增后 `cnt[x] > 2`，说明**第 3 个同值出现**，鸽巢必撞，立即 `return false`（提前剪枝，剩余元素不必再看）；
4. 顺利扫完，说明所有频次 $\le 2$，`return true`。

### 3.4 示例演算

![构造划分：成对一左一右、单值对半分](images/split_array_pair_split_construction.svg)

| 输入 | 频次表 | 最大频次 | 判定 | 说明 |
|------|--------|----------|------|------|
| `[1,1,2,2,3,4]` | `1→2, 2→2, 3→1, 4→1` | $2$ | `true` | 成对的 1、2 一左一右，单值 3、4 对半分：`nums1=[1,2,3]`、`nums2=[1,2,4]` |
| `[2,2,5,5]` | `2→2, 5→2` | $2$ | `true` | 无单值（$s=0$），两组自动各 $n/2=2$ 个 |
| `[1,1,1,1]` | `1→4` | $4 > 2$ | `false` | 4 个 1 挤 2 个巢，任一划分必有一侧 $\ge 2$ 个；扫到第 3 个 `1` 时即可剪枝 |

## 4. 算法细节

1. **计数结构选择**：值域 $1 \le \text{nums}[i] \le 100$，用定长数组 `int cnt[101]`，无哈希开销、空间 $O(1)$；值域放大（如 $10^9$）时换 `unordered_map` / `dict`，判定逻辑完全不变。
2. **提前剪枝的位置**：判断放在自增之后——`++cnt[x] > 2` 语义是「第 3 个同值出现」；若误写成 `cnt[x] >= 2` 会在第 2 个同值时误杀。
3. **等价判定**：排序后检查「不存在三个相邻相等元素」，或用 `Counter` 查最大频次，均与本流程等价。核心不变量始终是 $\max_v \text{cnt}[v] \le 2$。
4. **如需输出具体划分**：按 3.4 的构造——成对值一左一右，单值（偶数个）对半分，$O(n)$ 构造。

## 5. 正确性证明

**引理 1（必要性）**：若存在值 $v$ 出现 $k \ge 3$ 次，则任何对半划分都不合法。

**证明**：任取一个划分，$k$ 个 $v$ 被分入 `nums1`、`nums2` 两个组。由鸽巢原理，至少一组分到 $\lceil k/2 \rceil \ge 2$ 个 $v$，该组内部出现重复，违反互异约束。划分是任取的，故对所有划分均不合法。∎

**引理 2（配平）**：设出现 2 次的值有 $d$ 个、出现 1 次的值有 $s$ 个，且所有频次 $\le 2$，则 $s = n - 2d$ 为偶数。

**证明**：题目保证 $n$ 为偶数，$2d$ 显然为偶数，两偶数之差 $s$ 为偶数。∎

**定理**：存在合法划分 $\iff$ 每个值的出现次数 $\le 2$。

**证明**：

- **充分性（$\Leftarrow$）**：构造——每个出现 2 次的值向两组各放一个（两组各得 $d$ 个）；由引理 2，$s$ 个单值为偶数个，任取一半放入 `nums1`、其余放入 `nums2`。两组大小均为 $d + s/2 = (2d + s)/2 = n/2$；每组内每个值至多出现一次（成对值每侧恰一个、单值每侧至多一个），互异成立，故该构造合法。
- **必要性（$\Rightarrow$）**：逆否命题即引理 1。

∎

## 6. 复杂度分析

- **时间复杂度**：$O(n + V)$，其中 $V$ 为值域（本题 $V = 101$）。单趟遍历每个元素 $O(1)$ 计数；提前剪枝不改变最坏界，只让失败样例平均更快返回。$V$ 与 $n$ 无关时可视为 $O(n)$。
- **空间复杂度**：$O(V)$，定长计数数组；值域大改用哈希表则为 $O(\min(n, V))$。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    bool isPossibleToSplit(vector<int>& nums) {
        int cnt[101] = {0};
        for (int x : nums) {
            if (++cnt[x] > 2) return false;  // 第 3 个同值出现，鸽巢必撞
        }
        return true;  // 所有频次 ≤ 2，必可构造划分
    }
};
```

### Python

```python
class Solution:
    def isPossibleToSplit(self, nums: List[int]) -> bool:
        cnt = Counter(nums)
        return all(c <= 2 for c in cnt.values())
```

> 💡 两种写法等价：C++ 版利用 $1 \le \text{nums}[i] \le 100$ 开定长数组并边数边判、可提前退出；Python 版把「计数 + 判定」交给 `Counter` 与 `all`，语义最短。

## 8. 边界情况与易错点

1. **`n = 2` 恒真**：两个元素各归一侧，任何值都不可能在一侧出现两次，最小规模无需特判，通用逻辑直接通过。
2. **「互不相同」的作用范围**：只约束**各组内部**，两组之间可以重复（示例 1 的 1、2 同时出现在两侧）。误读成「全局不重复」会把大量 `true` 错判成 `false`。
3. **不能只数不同值的个数**：反例 `[1,1,1,2,3,4]` 有 4 个不同值 $\ge n/2 = 3$，但值 1 出现 3 次，答案是 `false`。判定必须落到「每个值的频次」上。
4. **长度约束不用单独检查**：由引理 2，$s$ 必为偶数，频次条件满足时两侧总能精确配平到 $n/2$。
5. **计数数组大小**：值域 $1 \sim 100$ 对应开 `cnt[101]`；下标从 1 开始用，无偏移问题。
6. **剪枝条件的边界**：`> 2` 而非 `>= 2`——出现 2 次是允许的，第 3 次才否决。
