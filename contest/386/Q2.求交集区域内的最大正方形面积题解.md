# LeetCode 求交集区域内的最大正方形面积 题解

## 1. 题目概述

- **标题 / 题号**：求交集区域内的最大正方形面积（#3047，medium）
- **链接**：https://leetcode.cn/problems/find-the-largest-area-of-square-inside-two-rectangles/
- **来源**：LeetCode 第 386 场周赛 Q2
- **难度**：中等
- **标签**：几何、数组、数学、枚举

**题意**：平面上有 $n$ 个**轴对齐**矩形，第 $i$ 个由左下角 $\text{bottomLeft}[i]$ 和右上角 $\text{topRight}[i]$ 确定。选择一个由矩形的**交集**形成的区域，求能完全放进该区域内部的**最大正方形面积**；若不存在任何交集区域，返回 $0$。

**约束**：

- $2 \le n \le 10^3$ → 矩形对数 $\binom{n}{2} \le 5 \times 10^5$，$O(n^2)$ 可行
- $1 \le$ 坐标 $\le 10^7$ → 最大边长接近 $10^7$，**面积可达 $\approx 10^{14}$**，超出 32 位整数
- $\text{bottomLeft}[i][0] < \text{topRight}[i][0]$，$y$ 同理 → 每个矩形自身非退化（有正的宽和高）

> 💡 读题关键：示例 2 的 note 明确说「区域可以由多于两个矩形的交集构成」——这句话是本题最大的文字陷阱。它听起来像要处理任意子集的交集，但 §3.2 会证明：**只需枚举两两配对**。

## 2. 示例

**示例 1**

```text
输入：bottomLeft = [[1,1],[2,2],[3,1]], topRight = [[3,3],[4,4],[6,6]]
输出：1
解释：矩形 0 与矩形 1 的交集是 [2,3]×[2,3]（1×1）；矩形 1 与矩形 2 的交集是
[3,4]×[2,4]（1×2）。两处都能放下边长 1 的正方形，最大面积 1。
```

**示例 2**

```text
输入：bottomLeft = [[1,1],[2,2],[1,2]], topRight = [[3,3],[4,4],[3,4]]
输出：1
解释：三个矩形两两相交，公共交集为 [2,2]×[3,3]，仍是 1×1，最大面积 1。
注意：区域可以由多于两个矩形的交集构成。
```

**示例 3**

```text
输入：bottomLeft = [[1,1],[3,3],[3,1]], topRight = [[2,2],[4,4],[4,2]]
输出：0
解释：任何两个矩形都不相交，不存在交集区域，返回 0。
```

## 3. 解题思路

### 3.1 暴力思路：两种想偏的方向

- **方向一：网格 / 坐标扫描**。坐标上限 $10^7$，若想按单位格子扫描平面、找「能放下正方形的交集区域」，要面对 $10^{14}$ 个格子，直接爆炸；对正方形位置做坐标离散化或浮点二分也无从下手。
- **方向二：枚举矩形子集**。被示例 2 的 note 带偏，认为「区域可由多个矩形交集构成」就要枚举 $2^n$ 个子集分别求交集——$n = 1000$ 时是天方夜谭。

两个方向的共同误区：**把「区域的构造方式」当成了枚举对象**。真正决定答案的只是一个「能放下正方形的点集」，而每个这样的点集都能被**两个**矩形完全刻画。

### 3.2 核心观察：多重交集归约到两两配对

![核心观察：多矩形交集归约到两两配对](images/wc386_q2_pairwise_reduction.svg)

设合法区域是矩形集合 $S$（$|S| \ge 2$）中所有矩形的公共交集，双向夹逼：

- **上界方向**：区域内的任何正方形同时落在 $S$ 中**每一对**矩形的交集里，因此该区域的最优正方形不会超过任何一个两两配对的成绩；
- **下界方向**：任取两个矩形 $i, j$，它们的交集**本身**就满足「由矩形的交集形成」，是合法区域。

于是：**答案 = 所有 $\binom{n}{2}$ 个矩形对中，两两交集内最大正方形面积的最大值**。子集、多重交集全部不需要单独考虑。$O(n^2)$ 枚举矩形对，恰好不多不少。

### 3.3 交集与最大内接正方形：两个 $O(1)$ 公式

![交集矩形与最大内接正方形的O(1)公式](images/wc386_q2_intersection_square_formula.svg)

**公式一（交集矩形）**：轴对齐矩形的交集逐维独立，两维各自做区间交集。记 $(lx, ly)$ 为左下角、$(rx, ry)$ 为右上角，则

$$w = \min(rx_i, rx_j) - \max(lx_i, lx_j), \qquad h = \min(ry_i, ry_j) - \max(ly_i, ly_j)$$

当 $w \le 0$ 或 $h \le 0$ 时，交集为空或退化为线段 / 点，这一对贡献 $0$。

**公式二（最大内接正方形）**：$w \times h$（$w, h > 0$）的矩形内能放下的最大正方形边长为 $d = \min(w, h)$，贴着交集的任一角放置即可；面积 $= d^2$。

### 3.4 示例演算

![示例1演算：三对逐一求交集](images/wc386_q2_example_walkthrough.svg)

以示例 1 为例，三个矩形分别为 $R_0 = [1,3]\times[1,3]$、$R_1 = [2,4]\times[2,4]$、$R_2 = [3,6]\times[1,6]$：

| 矩形对 | 交集 | $w \times h$ | 最大边长 | 面积 |
|--------|------|--------------|----------|------|
| $(0,1)$ | $[2,3]\times[2,3]$ | $1\times1$ | $1$ | $1$ |
| $(0,2)$ | $[3,3]\times[1,3]$（$x$ 相切） | $0\times2$ | — | $0$ |
| $(1,2)$ | $[3,4]\times[2,4]$ | $1\times2$ | $\min(1,2)=1$ | $1$ |

答案 $= \max\{1, 0, 1\} = 1$。

**示例 2 的印证**：三个矩形的公共交集 $[2,2]\times[3,3]$ 是 $1\times1$，而三对两两交集的最优成绩同样是 $1\times1$——多重交集没有带来任何额外收益，正是 §5 定理的直观体现。

## 4. 算法细节

1. **枚举结构**：双重循环 $i < j$ 遍历所有矩形对；$i = j$ 的「交集」是矩形自身，不符合「至少两个矩形」的要求且会虚增答案，$(i,j)$ 与 $(j,i)$ 重复，都要避免。
2. **每对 $O(1)$**：先按公式一算 $w, h$，再判 $w > 0 \wedge h > 0$，最后取 $d = \min(w, h)$、更新 $\text{ans} \gets \max(\text{ans}, d^2)$。
3. **溢出处理**：$w, h \le 10^7 - 1$ 在 `int` 范围内，但 $d^2$ 最大约 $10^{14}$。C++ 中必须先把边长转成 `long long` 再平方（`(long long)d * d`），且返回类型为 `long long`；Python 的整数无此问题。
4. **无需预处理**：矩形顺序、大小、嵌套、相切全部由公式统一处理——完全嵌套时交集就是小矩形，$\min(\text{外右上}) - \max(\text{内左下})$ 自动正确，无任何特判分支。

## 5. 正确性证明

**引理 1（区间交集）**：闭区间 $[a,b]$ 与 $[c,d]$（$a<b,\ c<d$）的交集为 $[\max(a,c), \min(b,d)]$，其长度为正当且仅当 $\min(b,d) > \max(a,c)$。

**证明**：$x$ 同时属于两区间 $\iff x \ge a \wedge x \ge c \wedge x \le b \wedge x \le d \iff \max(a,c) \le x \le \min(b,d)$。该区间长度 $\min(b,d) - \max(a,c) > 0$ 时非退化。∎

**引理 2（矩形交集）**：轴对齐矩形 $R_i = [lx_i, rx_i] \times [ly_i, ry_i]$ 与 $R_j$ 的交集为 $[\max(lx_i, lx_j), \min(rx_i, rx_j)] \times [\max(ly_i, ly_j), \min(ry_i, ry_j)]$。

**证明**：$(x, y) \in R_i \cap R_j \iff x \in [lx_i, rx_i] \cap [lx_j, rx_j]$ 且 $y \in [ly_i, ry_i] \cap [ly_j, ry_j]$。笛卡尔积结构使两维独立，逐维套用引理 1 即得。∎

**引理 3（最大内接正方形）**：$w \times h$（$w, h > 0$）的轴对齐矩形内能放下的最大正方形边长为 $\min(w, h)$。

**证明**：边长 $d$ 的轴对齐正方形含于该矩形 $\iff$ 它在两坐标轴上的投影（长度均为 $d$）分别含于长度 $w$、$h$ 的区间 $\iff d \le w \wedge d \le h$，故 $d \le \min(w, h)$。取 $d = \min(w, h)$ 并贴矩形左下角放置即达到上界。（旋转也不能更优：边长 $s$、转角 $\theta$ 的正方形在两轴上的投影均为 $s(\cos\theta + \sin\theta) \ge s$，故 $s \le \min(w,h)$，见延伸思考。）∎

**定理**：所求答案 $= \max_{0 \le i < j < n} f(i,j)$，其中 $f(i,j)$ 为矩形 $i, j$ 交集中最大内接正方形的面积（交集退化时为 $0$）。

**证明**：

- **$\ge$**：对任意 $i < j$，$R_i \cap R_j$ 本身就是「由矩形的交集形成」的合法区域，故全局最优解 $\ge f(i,j)$，对右边取最大仍成立。
- **$\le$**：任取一个合法区域 $A$，它是某矩形集合 $S$（$|S| \ge 2$）中全部矩形的公共交集。若 $A$ 中放得下边长 $d$ 的正方形，则该正方形 $\subseteq A \subseteq R_i \cap R_j$ 对 $S$ 中任意一对 $i, j$ 成立（取定一对即可），由引理 3 得 $d^2 \le f(i,j)$。故任何合法区域的最优解都被某个 $f(i,j)$ 控制，全局最优 $\le \max f(i,j)$。

两个方向合并即得。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n^2)$。双重循环枚举 $\binom{n}{2} \approx 5 \times 10^5$ 个矩形对，每对只做常数次 `min` / `max` 与比较。$n \le 10^3$ 下远低于时限。
- **空间复杂度**：$O(1)$。只随机访问输入数组，不建立任何辅助结构。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    long long largestSquareArea(vector<vector<int>>& bottomLeft,
                                vector<vector<int>>& topRight) {
        long long ans = 0;
        int n = bottomLeft.size();
        for (int i = 0; i < n; ++i) {
            for (int j = i + 1; j < n; ++j) {
                int w = min(topRight[i][0], topRight[j][0]) -
                        max(bottomLeft[i][0], bottomLeft[j][0]);
                int h = min(topRight[i][1], topRight[j][1]) -
                        max(bottomLeft[i][1], bottomLeft[j][1]);
                if (w > 0 && h > 0) {
                    long long d = min(w, h);
                    ans = max(ans, d * d);
                }
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def largestSquareArea(self, bottomLeft: List[List[int]], topRight: List[List[int]]) -> int:
        ans = 0
        for i in range(len(bottomLeft)):
            lx1, ly1 = bottomLeft[i]
            rx1, ry1 = topRight[i]
            for j in range(i + 1, len(bottomLeft)):
                w = min(rx1, topRight[j][0]) - max(lx1, bottomLeft[j][0])
                h = min(ry1, topRight[j][1]) - max(ly1, bottomLeft[j][1])
                if w > 0 and h > 0:
                    ans = max(ans, min(w, h) ** 2)
        return ans
```

> 💡 C++ 里 `d * d` 必须发生在 64 位上：若 `d` 是 `int`，`d * d` 先按 32 位溢出再赋值，$10^{14}$ 级别的答案会算错。Python 原生大整数无此问题。

## 8. 边界情况与易错点

1. **面积溢出（最高频错误）**：$d$ 最大接近 $10^7$，$d^2 \approx 10^{14} > 2^{31} - 1$。C++ 中「平方前先转 `long long`」与「返回类型 `long long`」缺一不可。
2. **相切不算交集**：$w = 0$（如示例 1 中矩形 0 与矩形 2 仅在 $x = 3$ 相切）或 $h = 0$ 时交集退化为线段，放不下任何正面积的正方形，必须用**严格大于**判断。
3. **别被 note 带偏**：「区域可由多于两个矩形的交集构成」不要求枚举子集——定理保证两两配对足够；反过来只按「恰好两个矩形」理解也不会漏解，因为多重交集的成绩已被某一对完全覆盖。
4. **循环边界**：内层从 $i + 1$ 开始，避免自身配对与重复配对。
5. **矩形完全嵌套**：小矩形整个在大矩形内部时交集就是小矩形，公式自动正确，不需要任何特判。
6. **不要假设输入有序**：矩形的排列、大小、位置均无保证，直接双层循环即可。

**延伸思考**：

- **允许正方形旋转呢？** 结论不变：转角 $\theta \in [0, \pi/2)$、边长 $s$ 的正方形在 $x$、 $y$ 两轴上的投影都是 $s(\cos\theta + \sin\theta) \ge s$，要塞进 $w \times h$ 需 $s(\cos\theta + \sin\theta) \le \min(w, h)$，故 $s \le \min(w, h)$——轴对齐放置已是最优。
