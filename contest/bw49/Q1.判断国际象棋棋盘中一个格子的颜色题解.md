# LeetCode 判断国际象棋棋盘中一个格子的颜色 题解

## 1. 题目概述

- **标题 / 题号**：判断国际象棋棋盘中一个格子的颜色（#1812，easy）
- **链接**：https://leetcode.cn/problems/determine-color-of-a-chessboard-square/
- **来源**：LeetCode 第 49 场双周赛 Q1
- **难度**：简单
- **标签**：数学、字符串

**题意**：给定一个长度为 2 的字符串 `coordinates`，表示国际象棋棋盘上一个格子的坐标：第一个字符是列字母 `'a'`~`'h'`，第二个字符是行数字 `'1'`~`'8'`。国际象棋棋盘左下角 `a1` 是**黑色**，相邻格子颜色交替。若该格是白色返回 `true`，是黑色返回 `false`。

**约束**：

- `coordinates.length == 2`
- `'a' <= coordinates[0] <= 'h'`
- `'1' <= coordinates[1] <= '8'`

## 2. 示例

**示例 1**

```text
输入：coordinates = "a1"
输出：false
解释：a1 位于棋盘左下角，是黑色格子。
```

**示例 2**

```text
输入：coordinates = "h3"
输出：true
解释：h3 是白色格子。
```

**示例 3**

```text
输入：coordinates = "c7"
输出：false
解释：c7 是黑色格子。
```

## 3. 解题思路

### 3.1 暴力思路

最朴素的做法是把 $8 \times 8$ 棋盘整个"建"出来：从 `a1` 为黑开始，按相邻交替规则逐格填色，再查表。这样做完全正确，但既占代码量又没必要——签到题应该寻找"从坐标直接算颜色"的捷径。

### 3.2 核心观察：颜色由（列号 + 行号）的奇偶性决定

![棋盘配色规律：列号加行号的奇偶性决定颜色](images/bw49_q1_board_parity.svg)

把坐标转成 1 起始的数字：列号 $\text{col} = coordinates[0] - \texttt{'a'} + 1$（a→1 … h→8），行号 $\text{row} = coordinates[1] - \texttt{'0'}$。从 `a1`（$\text{col}+\text{row}=1+1=2$，黑）出发：

- 向右走一格，$\text{col}$ 加 1，$\text{col}+\text{row}$ 的奇偶性**翻转**，颜色也翻转；
- 向上走一格，$\text{row}$ 加 1，奇偶性同样翻转，颜色同样翻转。

于是颜色恰好由 $\text{col}+\text{row}$ 的奇偶性唯一刻画：

$$\text{col}+\text{row} \text{ 为偶数} \Rightarrow \text{黑色（返回 false）}，\quad \text{col}+\text{row} \text{ 为奇数} \Rightarrow \text{白色（返回 true）}$$

用两个官方样例自检：$a1$：$1+1=2$ 偶 → 黑 → `false` ✓；$h3$：$8+3=11$ 奇 → 白 → `true` ✓；$c7$：$3+7=10$ 偶 → 黑 → `false` ✓。

### 3.3 算法流程

![同色对角线：沿对角线移动行列和不变、颜色不变](images/bw49_q1_diagonal_same_color.svg)

```text
1. col = coordinates[0] - 'a' + 1     # 列号 1..8
2. row = coordinates[1] - '0'         # 行号 1..8
3. 返回 (col + row) % 2 == 1          # 奇 → 白 true，偶 → 黑 false
```

从"对角线"的视角看这条规律也很直观：沿 $45°$ 对角线走一步是"列 +1、行 −1"，$\text{col}+\text{row}$ 不变，颜色不变——所以每条对角线（$\text{col}+\text{row}=\text{常数}$）整条同色，相邻两条对角线异色。

### 3.4 示例演算

| 坐标 | col | row | col+row | 奇偶 | 颜色 | 返回 |
|------|-----|-----|---------|------|------|------|
| a1 | 1 | 1 | 2 | 偶 | 黑 | false |
| h3 | 8 | 3 | 11 | 奇 | 白 | true |
| c7 | 3 | 7 | 10 | 偶 | 黑 | false |

三个官方示例全部命中，规律成立。

## 4. 算法细节

1. **字符转数字**：列用 `coordinates[0] - 'a' + 1`（注意 `+1`，转成 1 起始更符合棋盘直觉）；行用 `coordinates[1] - '0'`。
2. **奇偶判断**：`(col + row) % 2 == 1`。等价写法是 `(coordinates[0] - coordinates[1]) % 2 == 1`——因为 $\text{col}+\text{row}$ 与 $\text{col}-\text{row}$ 奇偶性相同（两者相差 $2 \cdot \text{row}$），后者连 `+1` 都不用加，C++ 里直接对字符相减取模即可。
3. **不需要建棋盘**：$O(1)$ 公式直接出答案，常数次整数运算。
4. **0 起始也行**：若用 $\text{col}' = coordinates[0]-\texttt{'a'}$（0 起始），则 $\text{col}'+\text{row}'$ 与 $\text{col}+\text{row}$ 相差常数 2，奇偶性不变，结论同样成立——只是 1 起始配合 `a1 为黑` 这个事实最不容易绕晕。

## 5. 正确性证明

**引理 1（相邻翻转）**：棋盘中任意两个水平相邻或垂直相邻的格子颜色相反。

**证明**：由棋盘构造规则直接得出：同行的相邻格列号差 1，同列的相邻格行号差 1，题目规定相邻格颜色交替。∎

**引理 2（奇偶刻画）**：格子的颜色只依赖于 $\text{col}+\text{row}$ 的奇偶性；且 $\text{col}+\text{row}$ 为偶 ⇔ 黑色。

**证明**：从 $a1$（$\text{col}+\text{row}=2$，黑）到任意格子 $(\text{col},\text{row})$ 走一条路径：先向右 $\text{col}-1$ 步、再向上 $\text{row}-1$ 步，共 $\text{col}+\text{row}-2$ 步。由引理 1，每步颜色翻转一次，故最终颜色是黑色当且仅当翻转偶数次，即 $\text{col}+\text{row}-2$ 为偶数，等价于 $\text{col}+\text{row}$ 为偶数。∎

**定理**：`squareIsWhite` 返回 `true` 当且仅当该格为白色。

**证明**：由引理 2，白色 ⇔ $\text{col}+\text{row}$ 为奇 ⇔ 代码中 `(col + row) % 2 == 1` 为真，返回值与颜色一一对应。∎

## 6. 复杂度分析

- **时间**：$O(1)$。两次字符减法、一次加法、一次取模。
- **空间**：$O(1)$。仅常数个整型变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool squareIsWhite(string coordinates) {
        int col = coordinates[0] - 'a' + 1;   // 列号 1..8
        int row = coordinates[1] - '0';       // 行号 1..8
        return (col + row) % 2 == 1;          // 奇 → 白，偶 → 黑
    }
};
```

### Python

```python
class Solution:
    def squareIsWhite(self, coordinates: str) -> bool:
        col = ord(coordinates[0]) - ord('a') + 1
        row = ord(coordinates[1]) - ord('0')
        return (col + row) % 2 == 1
```

> 💡 两份代码对全部 $8\times8=64$ 个合法坐标逐一与真实棋盘（`a1` 为黑）核对一致，官方 3 个示例输出 `false / true / false` 全部命中；C++ 与 Python 结果完全一致。

## 8. 边界情况与易错点

1. **`a1` 返回 `false`**：黑色对应 `false`、白色对应 `true`，别把布尔含义弄反。记住基准点 `a1` 是黑即可校验。
2. **`'1'` 是字符不是数字**：行号要 `coordinates[1] - '0'`，直接把字符当整数用会得到 ASCII 码（如 `'1'` 是 49），奇偶性结论直接报废。
3. **1 起始与 0 起始的奇偶一致性**：`col` 忘记 `+1` 并不会错（差 2 不改奇偶），但混合使用（列 1 起始、行 0 起始）就会差 1 导致全盘翻色——两边的"起点"必须统一。
4. **输入一定合法**：题目保证 `coordinates` 是棋盘上真实存在的格子，无需做范围校验；若要防御式编程，可检查列在 `'a'..'h'`、行在 `'1'..'8'`。
5. **不要被棋盘示意图干扰**：有的资料把左上角画成黑色，但国际象棋坐标 `a1` 在左下角且必为黑色——以题目官方图与 `a1` 为黑为准。
