# LeetCode 转换字符串的最小成本 II 题解

## 1. 题目概述

- **标题 / 题号**：转换字符串的最小成本 II（#2977，hard）
- **链接**：https://leetcode.cn/problems/minimum-cost-to-convert-string-ii/
- **来源**：LeetCode 第 377 场周赛 Q4
- **难度**：困难
- **标签**：字典树（Trie）、图、最短路、Floyd-Warshall、动态规划、字符串

**题意**：给定两个等长（$n$）的小写串 `source` 与 `target`，以及 $m$ 条**子串转换规则**：花 $\text{cost}[j]$ 的代价可以把当前串中一段**完全等于** $\text{original}[j]$ 的子串整体改成 $\text{changed}[j]$。规则可用任意多次，但**任意两次操作**所选的下标区间必须满足以下之一：**要么不相交，要么完全相同**。求把 `source` 变成 `target` 的最小总成本；无法完成返回 $-1$。

**约束**：

- $1 \le n = \text{source.length} = \text{target.length} \le 1000$
- `source`、`target` 均由小写英文字母组成
- $1 \le m = \text{cost.length} = \text{original.length} = \text{changed.length} \le 100$
- $1 \le \text{original}[i].\text{length} = \text{changed}[i].\text{length} \le n$（**规则两端等长**）
- `original[i]`、`changed[i]` 均由小写英文字母组成，且 $\text{original}[i] \ne \text{changed}[i]$
- $1 \le \text{cost}[i] \le 10^6$

> 💡 读题先抓四个信号：**① 规则两端等长**（藏在约束里）→ 任何操作不改变总串长，下标全程稳定；**② 「不相交 或 完全相同」是对任意两次操作的约束** → 操作按区间分组，组内是链；**③ 规则串至多 $2m = 200$ 个** → 「值得操作的子串」值域极小，可用 Trie / 哈希识别；**④ $n \le 1000$** → $O(n^2)$ 的区间划分 DP 可行。四个信号合起来几乎唯一确定了做法：**Trie + Floyd + 前缀 DP**。

## 2. 示例

**示例 1**

```text
输入：source = "abcd", target = "acbe",
     original = ["a","b","c","c","e","d"], changed = ["b","c","b","e","b","e"],
     cost = [2,5,5,1,2,20]
输出：28
解释：位置 1：b→c 花 5；位置 2：先 c→e 花 1 再 e→b 花 2（两次操作下标完全相同，合法）；
     位置 3：d→e 花 20。总计 5 + 1 + 2 + 20 = 28。
```

**示例 2**

```text
输入：source = "abcdefgh", target = "acdeeghh",
     original = ["bcd","fgh","thh"], changed = ["cde","thh","ghh"], cost = [1,3,5]
输出：9
解释：区间 [1,3]：bcd→cde 花 1；区间 [5,7]：先 fgh→thh 花 3，再 thh→ghh 花 5
     （两次操作下标都是 [5,7]，合法）。总计 1 + 3 + 5 = 9。
```

**示例 3**

```text
输入：source = "abcdefgh", target = "addddddd",
     original = ["bcd","defgh"], changed = ["ddd","ddddd"], cost = [100,1578]
输出：-1
解释：区间 [1,3] 与 [3,7] 共用下标 3——既不相交也不相同，只能取其一；
     无论先做哪个，另一个都无法执行，整体无解。
```

## 3. 解题思路

### 3.1 暴力思路：三个走不通的方向

- **照搬 Q3 的逐位独立**：把子串规则按首字符拆开、逐位查最短路。**逻辑错误**——示例 2 的 `bcd→cde`、`fgh→thh` 是多字符整体替换，单字符规则根本不存在，逐位模型连合法方案都表达不出来。
- **模拟操作序列搜索**：从 `source` 出发，每步枚举「所有规则 × 所有匹配位置」，BFS / Dijkstra 找 `target`。状态是「当前串 + 已用区间集合」，其中「已用区间集合」是指数级的（示例 3 的困境正来自两个区间不能同时用），状态空间爆炸。
- **裸区间 DP + 逐个子串哈希**：枚举起点 $i$ 与长度 $L$，把 $\text{source}[i..i{+}L{-}1]$、$\text{target}[i..i{+}L{-}1]$ 切出来查哈希表再查最短路。提取子串每个代价 $O(L)$，总计约 $n^3/6 \approx 1.7 \times 10^8$ 次字符操作，C++ 勉强、Python 必挂，而且哈希还有碰撞隐患。

> ⚠️ 三个方向的共同盲点是没有利用**值域缩减**：虽然 $\text{source}$ 的子串有 $O(n^2) = 10^6$ 个，但**值得作为操作对象的串只有 $\le 200$ 个**（必须出现在 `original`/`changed` 里）。把这 200 个串建成 Trie，「枚举所有子串」就坍缩成「沿 Trie 下探」——每一步 $O(1)$，总量 $O(n^2)$ 次下探。

### 3.2 核心观察：操作按区间分组，区间成本 = 字符串图最短路

![核心观察：不同区间两两不相交，同区间串成链，链成本=图上最短路](images/wc377_q4_interval_chain.svg)

三步拆解：

1. **结构定理**：把所有操作按「所选区间」分组。约束「任两次操作要么不相交、要么完全相同」意味着：**不同组的区间两两不相交；同组的操作作用在同一区间上、在时间上串成一条链**（后一次的输入是前一次的输出）。反过来，任何「两两不相交的区间 + 各自的链」都是合法方案。于是整个问题 = **选一组不相交区间、每条区间上走一条链**。
2. **等长性 → 下标稳定**：约束保证 $\text{original}[j]$ 与 $\text{changed}[j]$ 等长，链上每个中间串都与区间等长，总串长与下标全程不变。区间 $[a,b]$ 上的链形如 $x_0 \to x_1 \to \cdots \to x_k$，其中 $x_0 = \text{source}[a..b]$，$x_k = \text{target}[a..b]$。
3. **链 = 字符串图上的路径**：把 `original` ∪ `changed` 里出现的**去重串**（至多 $200$ 个）作为节点，每条规则作为有向边（重边取 min），跑一遍 Floyd——**这正是 Q3 的建图套路，只是节点从 26 个字母换成了 200 个串**。区间 $[a,b]$ 的最小成本就是 $\text{dist}(\text{source}[a..b],\ \text{target}[a..b])$，且链的两端（乃至中间每一步）都必须是图中节点。

剩下的自由度只有「区间怎么切」：不被区间覆盖的位置必须满足 $\text{source}[i] = \text{target}[i]$。这是一个经典的前缀划分问题。

### 3.3 算法流程：Trie 识别 + Floyd + 前缀 DP

![算法流程：离散化建图Floyd、Trie识别子串、前缀DP两种转移](images/wc377_q4_pipeline.svg)

定义 $dp[i]$ = 把前缀 $\text{source}[0..i{-}1]$ 变成 $\text{target}[0..i{-}1]$ 的最小成本，$dp[0] = 0$。转移只有两种：

- **转移 A（自由位）**：若 $\text{source}[i] = \text{target}[i]$，则 $dp[i{+}1] \gets \min(dp[i{+}1],\ dp[i])$；
- **转移 B（区间跳转）**：从位置 $i$ 起枚举区间长度 $L$，若 $\text{source}[i..i{+}L{-}1]$、$\text{target}[i..i{+}L{-}1]$ 都是图节点（编号 $u, v$），则
  $$dp[i+L] \gets \min(dp[i+L],\ dp[i] + \text{dist}[u][v]).$$

枚举 $(i, L)$ 靠 **Trie 双游标**完成：把 200 个规则串插入 Trie 并在终点标记图节点编号，然后从位置 $i$ 起，**两个游标沿同一棵 Trie 分别跟着 `source` 和 `target` 一步步下探**——深度 $L$ 时若两个游标都停在终点，就得到一对 $(u, v)$；任一游标走死（无对应子节点）立即 `break`。答案为 $dp[n]$（若为 $\infty$ 则返回 $-1$）。

### 3.4 示例演算

![示例演算：dp数组走查，dp0→dp1→dp4→dp5→dp8=9](images/wc377_q4_dp_walkthrough.svg)

以示例 2 为例。图节点为 $\{\text{bcd}, \text{cde}, \text{fgh}, \text{thh}, \text{ghh}\}$，唯一的「绕行」最短路是 $\text{dist}[\text{fgh}][\text{ghh}] = 3 + 5 = 8$（`fgh→ghh` 无直连边）。dp 依次推出：

| $i$ | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|----|---|---|---|---|---|---|---|---|---|
| 转移 | 起点 | a==a | — | — | 区间[1,3] | e==e | — | — | 区间[5,7] |
| $dp[i]$ | 0 | 0 | ∞ | ∞ | 1 | 1 | ∞ | ∞ | 9 |

- $dp[1] = 0$：位置 0 两边都是 `a`，自由步；
- $dp[4] = dp[1] + 1$：位置 1 处 `b≠c` 走不了自由步，从 1 出发双游标下探，深度 3 时两侧分别到终点 `bcd`、`cde`，$+1$ 整体跳到 4；
- $dp[5] = dp[4]$：位置 4 两边都是 `e`；
- $dp[8] = dp[5] + 8$：区间 $[5,7]$ 上 `fgh` 变 `ghh`，链成本取最短路 $3+5$。

$dp[2], dp[3], dp[6], dp[7]$ 均为 $\infty$——这些位置必须被区间整体覆盖，而以它们为起点的可行区间不存在。最终答案 $dp[8] = 9$ ✓。示例 3 里区间 $[1,3]$ 与 $[3,7]$ 相交又不同，DP 中 $dp[4]$ 与「从 3 开始的区间」无法同时成立，$dp[8] = \infty$，返回 $-1$ ✓。

## 4. 算法细节

### 4.1 建图：离散化、重边、Floyd

- 用哈希表把 `original`、`changed` 中的串去重编号，节点数 $P \le 2m \le 200$；
- 邻接矩阵初始化 $\text{dist}[u][u] = 0$、其余 $\infty$，逐条规则 $\text{dist}[u][v] = \min(\text{dist}[u][v], \text{cost}[j])$——题面明说可能存在重复的 $(x, y)$ 规则，**必须取 min**；
- Floyd 三重循环，$200^3 = 8 \times 10^6$ 次松弛，复杂度主导项但完全可接受。$\infty$ 取 $10^{18}$，两个 $\infty$ 相加仍在 `long long` 范围内。

### 4.2 Trie：终点标记与「前缀串」共存

![双游标Trie下探：一次走查枚举起点为i的所有区间，走死即break](images/wc377_q4_trie_detail.svg)

- 插入 200 个串，**终点标记用独立数组存图节点编号**（初值 $-1$）。注意一个串可能是另一个串的前缀（如规则同时含 `"b"` 与 `"bcd"`），所以「是否终点」必须挂在 Trie 节点上、与「子节点指针」分开存，不能只看「有无孩子」；
- **双游标共享同一棵 Trie**：`su` 跟着 `source` 走、`tu` 跟着 `target` 走。二者每次同步下降一层（对应同一段下标），深度天然就是区间长度 $L$；
- **走死即停**：若 `source[i..j]` 已不是任何规则串的前缀，则更长的 `source[i..j']` 也不是——起点为 $i$、长度 $\ge j-i+1$ 的子串全都不可能是图节点，`su < 0` 即 `break`；`tu` 侧同理（链的终点必须是某条规则的 `changed` 串）。提前退出不漏任何解；
- 对照：逐 $(i, L)$ 切子串再哈希需要 $O(n^3)$ 次字符操作，Trie 下探把它压到 $O(n^2)$ 次 $O(1)$ 转移，且无哈希碰撞之忧。

### 4.3 前缀 DP：转移的完备性

- 两种转移**并列尝试而不是 if-else**：即使 $\text{source}[i] = \text{target}[i]$，从 $i$ 切一条更长的区间（跨过 $i$）仍可能更优，转移 A、B 都要执行；
- 处理顺序：外层 $i$ 从小到大。所有转移都从 $i$ 指向前方（$i+1$ 或 $i+L$），一趟扫描即可；
- $dp[i] = \infty$ 的起点直接跳过（前缀 $[0, i)$ 已无解），但这不代表全局无解——其他路径可能绕过死点；
- 判 $-1$ 只看最终 $dp[n]$。

## 5. 正确性证明

**引理 1（结构定理）**：一个操作序列合法，当且仅当它可整理为「一组两两不相交的区间，每个区间上依次执行一条替换链」。

**证明**：（⇒）把序列中所有操作按所选区间分组。「任意两次操作要么区间不相交、要么完全相同」保证不同组的区间两两不相交；同组内按时间先后排序，每次操作的输入恰为前一次的输出，构成链。（⇐）任取这样一组区间与链，把所有操作按任意顺序交错执行：同组两次操作的区间完全相同，异组两次操作的区间不相交，均满足约束。∎

**引理 2（长度与下标稳定性）**：任意时刻当前串长度恒为 $n$，且各操作的区间下标在同一坐标系下可直接比较。

**证明**：约束保证每条规则两端等长，故每次替换不改变区间长度、也不改变串的总长；对操作次数归纳即得任意时刻串长为 $n$，操作选取的下标始终有意义且不漂移。∎

**引理 3（链 = 图上最短路）**：设 $u, v$ 是图 $G$ 中两个等长节点串，则在区间上把 $u$ 变成 $v$ 的最小成本等于 $\text{dist}[u][v]$（$u = v$ 时为 $0$，即不操作）。

**证明**：区间上任意替换链 $u = x_0 \to x_1 \to \cdots \to x_k = v$ 对应 $G$ 中一条途径，总成本为边权之和 $\ge \text{dist}[u][v]$。反之，任取 $u$ 到 $v$ 的最短路径（正权下可取简单路径），按边序在区间上依次执行，得到合法的链，成本恰为路径长。两端夹逼得证（不可达时不存在任何链，成本视为 $+\infty$）。∎

**引理 4（端点节点性）**：若某区间 $[a,b]$ 上至少执行了一次操作，则 $\text{source}[a..b]$ 与 $\text{target}[a..b]$ 都是 $G$ 中节点。

**证明**：链的首步操作要求当前内容等于某条规则的 $\text{original}$，故 $x_0 = \text{source}[a..b]$ 是节点；末步操作的输出是某条规则的 $\text{changed}$，故 $x_k = \text{target}[a..b]$ 是节点。∎

**引理 5（Trie 枚举与 break 的完备性）**：对每个起点 $i$，双游标下探恰好枚举出所有满足「两端均为节点」的区间 $[i, i+L-1]$，且提前 `break` 不丢失任何可行转移。

**证明**：深度 $L$ 的 `su` 停留的 Trie 节点对应前缀 $\text{source}[i..i{+}L{-}1]$，它是节点串当且仅当该 Trie 节点带终点标记，`tu` 同理——枚举不重不漏。若 `su` 在深度 $L$ 走死，则 $\text{source}[i..i{+}L{-}1]$ 不是任何节点串的前缀，从而对一切 $L' \ge L$，$\text{source}[i..i{+}L'{-}1]$ 也不是节点串（它以死者为前缀），由引理 4 这些长度全部无法产生转移，`break` 安全；`tu` 侧同理。∎

**定理**：上述 DP 返回的 $dp[n]$ 等于把 `source` 变为 `target` 的最小成本（不存在时为 $-1$）。

**证明**：（可行性，$dp[n] \ge \text{OPT}$ 方向）对 $j$ 归纳：每个有限值 $dp[j]$ 都对应一个把 $\text{source}[0..j{-}1]$ 变为 $\text{target}[0..j{-}1]$ 的合法方案。$j=0$ 平凡。归纳步看最后一步转移：若为转移 A，则 $\text{source}[j{-}1] = \text{target}[j{-}1]$，在 $dp[j{-}1]$ 的方案后不动该位即可；若为转移 B，由引理 5 枚举到的 $(u, v)$ 都是节点、由引理 3 成本 $\text{dist}[u][v]$ 可以实现为区间 $[i, j{-}1]$ 上的一条链，与 $dp[i]$ 的方案（区间全部落在 $[0, i)$ 内）区间不相交，由引理 1 拼接仍合法。（最优性，$dp[n] \le \text{OPT}$ 方向）取一个最优合法方案，由引理 1 整理为不相交区间 + 链；将区间按左端点排序，未被覆盖的位置满足 $\text{source}[i] = \text{target}[i]$，可走转移 A；每个区间 $[a,b]$ 的链成本由引理 3 不小于 $\text{dist}[\text{source}[a..b]][\text{target}[a..b]]$，且由引理 4 其两端是节点、由引理 5 该转移恰被枚举到，故 DP 能以不超过该链成本的价格完成同样的划分。归纳可得 $dp[b{+}1] \le$（该前缀上的方案成本），特别地 $dp[n] \le \text{OPT}$。若 $dp[n] = \infty$，则不存在任何合法方案（否则由上一段它给 出有限值），返回 $-1$ 正确。∎

## 6. 复杂度分析

- **时间复杂度**：$O(\Sigma L + P^3 + n^2)$，其中 $\Sigma L \le 2 \times 10^5$ 为规则串总长（离散化、建 Trie），$P \le 200$ 为去重串数（Floyd，$8 \times 10^6$ 次松弛，主导项），DP 每个起点 $i$ 至多双游标下探 $n - i$ 步、总步数 $\le 2n^2 = 2 \times 10^6$。全程约 $10^7$ 量级，远低于限时。
- **空间复杂度**：$O(P^2 + \Sigma L)$。距离矩阵 $200^2 = 4 \times 10^4$；Trie 采用数组式子节点时上界 $26 \cdot \Sigma L \approx 5 \times 10^6$ 个 `int`（约 20 MB，可接受），Python 版用字典式子节点则与串总长同阶；dp 数组 $O(n)$。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    long long minimumCost(string source, string target, vector<string>& original,
                          vector<string>& changed, vector<int>& cost) {
        int n = source.size();

        // 1. 离散化：规则串去重编号，建有向图（重边取 min）
        unordered_map<string, int> id;
        auto getId = [&](const string& s) {
            auto it = id.find(s);
            if (it != id.end()) return it->second;
            int x = id.size();
            id.emplace(s, x);
            return x;
        };
        for (auto& s : original) getId(s);
        for (auto& s : changed) getId(s);
        int m = id.size();

        const long long INF = 1e18;
        vector<vector<long long>> dist(m, vector<long long>(m, INF));
        for (int i = 0; i < m; i++) dist[i][i] = 0;
        for (int j = 0; j < (int)original.size(); j++) {
            int u = id[original[j]], v = id[changed[j]];
            dist[u][v] = min(dist[u][v], (long long)cost[j]);
        }
        for (int k = 0; k < m; k++)
            for (int i = 0; i < m; i++) {
                if (dist[i][k] == INF) continue;
                for (int j = 0; j < m; j++)
                    if (dist[i][k] + dist[k][j] < dist[i][j])
                        dist[i][j] = dist[i][k] + dist[k][j];
            }

        // 2. Trie：终点标记 = 图节点编号
        vector<array<int, 26>> ch(1);
        ch[0].fill(-1);
        vector<int> endId(1, -1);
        for (auto& [s, x] : id) {
            int cur = 0;
            for (char c : s) {
                int d = c - 'a';
                if (ch[cur][d] < 0) {
                    ch[cur][d] = ch.size();
                    ch.emplace_back();
                    ch.back().fill(-1);
                    endId.push_back(-1);
                }
                cur = ch[cur][d];
            }
            endId[cur] = x;
        }

        // 3. 前缀 DP：转移 A 自由位 / 转移 B 区间跳转
        vector<long long> dp(n + 1, INF);
        dp[0] = 0;
        for (int i = 0; i < n; i++) {
            if (dp[i] == INF) continue;
            if (source[i] == target[i]) dp[i + 1] = min(dp[i + 1], dp[i]);
            int su = 0, tu = 0;
            for (int L = 1; i + L <= n; L++) {
                su = ch[su][source[i + L - 1] - 'a'];
                tu = ch[tu][target[i + L - 1] - 'a'];
                if (su < 0 || tu < 0) break;   // 走死：更长的子串不可能是节点
                int u = endId[su], v = endId[tu];
                if (u >= 0 && v >= 0 && dist[u][v] < INF)
                    dp[i + L] = min(dp[i + L], dp[i] + dist[u][v]);
            }
        }
        return dp[n] == INF ? -1 : dp[n];
    }
};
```

### Python

```python
class Solution:
    def minimumCost(self, source: str, target: str, original: List[str],
                    changed: List[str], cost: List[int]) -> int:
        n = len(source)
        INF = float('inf')

        # 1. 离散化 + 建图（重边取 min）
        ids = {}
        for s in original:
            if s not in ids:
                ids[s] = len(ids)
        for s in changed:
            if s not in ids:
                ids[s] = len(ids)
        m = len(ids)
        dist = [[INF] * m for _ in range(m)]
        for i in range(m):
            dist[i][i] = 0
        for x, y, c in zip(original, changed, cost):
            u, v = ids[x], ids[y]
            if c < dist[u][v]:
                dist[u][v] = c

        # 2. Floyd 全源最短路
        for k in range(m):
            dk = dist[k]
            for di in dist:
                via = di[k]
                if via == INF:
                    continue
                for j in range(m):
                    if via + dk[j] < di[j]:
                        di[j] = via + dk[j]

        # 3. Trie：字典式子节点 + 终点标记
        ch = [{}]
        end_id = [-1]
        for s, x in ids.items():
            cur = 0
            for c in s:
                nxt = ch[cur].get(c)
                if nxt is None:
                    ch.append({})
                    end_id.append(-1)
                    nxt = len(ch) - 1
                    ch[cur][c] = nxt
                cur = nxt
            end_id[cur] = x

        # 4. 前缀 DP
        dp = [INF] * (n + 1)
        dp[0] = 0
        for i in range(n):
            if dp[i] == INF:
                continue
            base = dp[i]
            if source[i] == target[i] and base < dp[i + 1]:
                dp[i + 1] = base
            su = tu = 0
            for j in range(i, n):
                su = ch[su].get(source[j], -1)
                tu = ch[tu].get(target[j], -1)
                if su < 0 or tu < 0:
                    break
                u, v = end_id[su], end_id[tu]
                if u >= 0 and v >= 0:
                    d = dist[u][v]
                    if d < INF and base + d < dp[j + 1]:
                        dp[j + 1] = base + d
        return dp[n] if dp[n] < INF else -1
```

> 💡 语言细节：C++ 用 `array<int,26>` 做子节点、下标 $-1$ 表示「走死」；Python 用字典做子节点更省内存。Python 的 Floyd 内层缓存行引用 `di`、`dk` 并跳过 `via == INF`，把 $200^3$ 的常数压低。

## 8. 边界情况与易错点

1. **「规则两端等长」是隐形地基**：它保证串长不变、下标稳定，区间 DP 才成立。若规则可不等长，区间会漂移、链上对齐关系随之改变，本题模型直接崩塌（那将是另一道更难的题）。
2. **两种转移不是 if-else**：$\text{source}[i] = \text{target}[i]$ 时仍要尝试从 $i$ 切区间（跨越式替换可能更便宜）；漏掉转移 A 或把两者写成互斥都会 WA。
3. **自由位不能「硬闯」**：$\text{source}[i] \ne \text{target}[i]$ 且从 $i$ 出发无可行区间时，该 dp 路径到此为止（$dp[i{+}1]$ 保持 $\infty$），不是全局返回 $-1$——别的路径可能绕过。
4. **终点标记与前缀共存**：规则串可能互为前缀（`"b"` 与 `"bcd"`），「是否节点」必须存独立标记，不能拿「有无子节点」当终点判据。
5. **重边取 min**：同一 $(x, y)$ 可能有多条规则，直接覆盖会丢便宜边。
6. **有向图**：$x \to y$ 不能反着用，别建成无向图。
7. **溢出**：链成本上界约 $199 \times 10^6 \approx 2 \times 10^8$，$dp$ 上界约 $10^3 \times 2 \times 10^8 = 2 \times 10^{11}$，C++ 全程 `long long`；$\infty$ 取 $10^{18}$ 这类「大而能加」的哨兵。
8. **`break` 的两个方向都要判**：source 游标或 target 游标任一走死都停，只判一侧会多走（不 WA 但浪费），判错方向（比如走死仍继续）会数组越界。
9. **规则串长于可用长度**：Trie 走查天然处理（到不了终点），无需特判；`n = 1` 时也只有单字符规则可能生效，逻辑自然覆盖。
10. **返回值口径**：只看 $dp[n]$ 是否为 $\infty$；中途死掉的路径不影响结论。

**延伸思考**：

- **若规则两端可不等长**：替换会改变总串长、后续下标整体漂移，「不相交或相同」的约束还需明确按哪个时刻的下标解释，需要重量级的区间 DP 甚至更复杂的模型——这也是本题把等长写进约束的原因。
- **若 $n$ 达到 $10^5$**：$O(n^2)$ 下探不可行。可改用 AC 自动机一次性找出 `source`、`target` 中所有规则串的出现位置，只在「区间事件点」之间做转移；最坏情况下出现次数仍是平方级，需结合规则串总长的限制才能保证复杂度。
- **识别与查询的分离**：本题的框架是「小值域预处理（Floyd）+ 大输入流式消费（Trie + DP）」——当查询值域远小于查询次数时，先离散化再预计算，是比逐次现算更普适的思路。
