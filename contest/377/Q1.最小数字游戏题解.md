# LeetCode 最小数字游戏 题解

## 1. 题目概述

- **标题 / 题号**：最小数字游戏（#2974，easy）
- **链接**：https://leetcode.cn/problems/minimum-number-game/
- **来源**：LeetCode 第 377 场周赛 Q1
- **难度**：简单
- **标签**：数组、排序、模拟、堆

**题意**：给定一个长度为**偶数**、下标从 0 开始的整数数组 `nums` 和一个空数组 `arr`，Alice 与 Bob 反复游戏直到 `nums` 为空。每一轮：

1. Alice 先从 `nums` 中移除**最小**的元素，随后 Bob 也移除一个**最小**的元素（即剩余中的最小）；
2. 接着 Bob 把自己移除的元素加入 `arr`，Alice 随后也这样做。

返回最终的数组 `arr`。

**约束**：

- `1 <= nums.length <= 100`
- `1 <= nums[i] <= 100`
- `nums.length % 2 == 0`（长度必为偶数，恰好进行 n/2 轮）

## 2. 示例

**示例 1**

```text
输入：nums = [5,4,2,3]
输出：[3,2,5,4]
解释：第一轮 Alice 移除 2、Bob 移除 3，Bob 先放 3、Alice 再放 2，arr = [3,2]；
      第二轮 Alice 移除 4、Bob 移除 5，Bob 先放 5、Alice 再放 4，arr = [3,2,5,4]。
```

**示例 2**

```text
输入：nums = [2,5]
输出：[5,2]
解释：Alice 移除 2，Bob 移除 5；Bob 先放 5，Alice 再放 2，arr = [5,2]。
```

**示例 3（自造，覆盖重复值）**

```text
输入：nums = [1,1,2,2]
输出：[1,1,2,2]
解释：第一轮两人各移除一个 1，按 Bob 先放入 (1,1)；第二轮各移除一个 2，放入 (2,2)。
```

## 3. 解题思路

### 3.1 暴力模拟

最直接的做法是照题面逐步模拟：每轮从 `nums` 中线性扫描出最小的两个元素并移除，再按「Bob 先、Alice 后」的顺序加入 `arr`。每轮 $O(n)$，共 $n/2$ 轮，总时间 $O(n^2)$；$n \le 100$ 时完全可以通过，也可以用小根堆做到 $O(n \log n)$。

作为签到题这样写最稳，但观察一下规则会发现一条更短的路径。

### 3.2 核心观察：排序 + 相邻两两交换

两个关键观察：

1. **移除只看「当前最小」**：每一轮移除哪些元素，只取决于当前集合里最小的两个值，与元素在数组中的**位置**无关。因此「逐轮移除」与「先整体排序、再按顺序分组移除」**等价**——排序后第 k 轮（k 从 0 开始）恰好移除 `s[2k]`（Alice）和 `s[2k+1]`（Bob）。
2. **放入顺序反转**：每组内 Alice 拿到的是较小值 x、Bob 拿到的是较大值 y，而放入时 **Bob 在前**，所以每组向 `arr` 贡献的是 `(y, x)`——**大值在前、小值在后**。

两条合起来：**把 `nums` 升序排序，再把相邻元素两两交换**，得到的就是答案 `arr`。

![核心观察：每轮流程与排序两两交换的等价性](images/min_number_game_observation.svg)

### 3.3 算法流程

1. 对 `nums` 升序排序；
2. 从下标 0 开始、步长为 2，交换 `nums[i]` 与 `nums[i+1]`；
3. 返回 `nums`。

排序保证每组内 `nums[i] <= nums[i+1]`，交换后每组变为 `(大, 小)`，与逐轮模拟的输出逐位一致。

### 3.4 示例演算

以 `nums = [5,4,2,3]` 为例，逐轮模拟的过程如下：

| 轮次 | Alice 移除 | Bob 移除 | 本轮追加到 arr | arr |
|------|-----------|---------|---------------|-----|
| 1 | 2 | 3 | (3, 2) | [3,2] |
| 2 | 4 | 5 | (5, 4) | [3,2,5,4] |

等价做法：排序得 `[2,3,4,5]`，分组 `(2,3)`、`(4,5)`，组内交换得 `[3,2,5,4]`，与模拟结果一致。

![示例演算：模拟与排序交换两条路径结果一致](images/min_number_game_walkthrough.svg)

## 4. 算法细节

- **等价性的本质**：把 `nums` 看作多重集合，「每轮移除最小两个」是集合层面的操作，与下标顺序无关，因此预排序不改变结果；排序只是把「每轮找最小」一次性完成。
- **组内角色固定**：排序后 `s[2k] <= s[2k+1]`，Alice（先移除）必然拿到 `s[2k]`，Bob 拿到 `s[2k+1]`；两值相等时谁拿哪个都一样，无需特判。
- **实现方式**：排序后原地交换相邻对即可，无需新建 `arr`；题目允许修改输入数组，直接返回 `nums`。
- **堆视角**：等价的模拟写法是用小根堆，每轮弹出两次得到 x（Alice 的，较小）与 y（Bob 的，较大），再**先压入 y、后压入 x**。两种写法结果一致，排序交换法代码最短。

## 5. 正确性证明

**引理 1**：设排序后的数组为 $s_0 \le s_1 \le \cdots \le s_{n-1}$，则第 k 轮（k 从 0 开始）移除的元素恰为 $s_{2k}$ 与 $s_{2k+1}$。

**证明**（对 k 归纳）：第 0 轮移除当前最小的两个元素，即全体最小的两个 $s_0, s_1$，命题成立。归纳假设前 k 轮共移除了 $s_0, \cdots, s_{2k-1}$，则剩余集合为 $\{s_{2k}, \cdots, s_{n-1}\}$，其最小的两个元素即 $s_{2k}$ 与 $s_{2k+1}$。∎

**定理**：`arr` 依次为 $s_1, s_0, s_3, s_2, \cdots, s_{n-1}, s_{n-2}$，即「排序后相邻元素两两交换」的结果。

**证明**：由引理 1，第 k 轮 Alice 移除 $s_{2k}$、Bob 移除 $s_{2k+1}$；再放入阶段 Bob 先于 Alice，故该轮向 `arr` 依次追加 $s_{2k+1}, s_{2k}$。对所有 $k = 0, 1, \cdots, n/2 - 1$ 拼接即得结论。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \log n)$，排序主导；随后的两两交换仅需 $O(n)$。本题 $n \le 100$，即使逐轮暴力模拟的 $O(n^2)$ 也绰绰有余。
- **空间复杂度**：$O(1)$ 额外空间（原地排序 + 原地交换；不计排序内部使用的栈/缓冲）。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    vector<int> numberGame(vector<int>& nums) {
        sort(nums.begin(), nums.end());
        for (int i = 0; i + 1 < (int)nums.size(); i += 2) {
            swap(nums[i], nums[i + 1]);
        }
        return nums;
    }
};
```

### Python

```python
class Solution:
    def numberGame(self, nums: List[int]) -> List[int]:
        nums.sort()
        for i in range(0, len(nums), 2):
            nums[i], nums[i + 1] = nums[i + 1], nums[i]
        return nums
```

## 8. 边界情况与易错点

1. **顺序别记反**：放入 `arr` 时是 **Bob 先**，因此每组内是「大值在前、小值在后」。若误按 `(x, y)` 放入，得到的就是排序数组本身 `[2,3,4,5]`，示例 1 直接出错。
2. **最小规模 n = 2**：只有一轮，输出 `[max, min]`，如示例 2 的 `[5,2]`。
3. **重复元素**：组内两值相等时交换前后不变（如 `[1,1,2,2]` → `[1,1,2,2]`），算法天然正确，无需特判。
4. **偶数长度保证**：约束保证 `n` 为偶数，`i + 1` 不会越界；循环条件写 `i + 1 < n` 或 `i < n`（步长 2）均可。
5. **原地修改**：直接在 `nums` 上排序、交换并返回即可，不必新建 `arr`，避免多余的空间开销。
6. **堆写法的弹出顺序**：先弹出的给 Alice（较小），后弹出的给 Bob（较大），而压入顺序相反（先 y 后 x），别弄颠倒。

- 若放入顺序改为 **Alice 先**，答案会变成什么？（每组内按 `(小, 大)` 放入，最终 `arr` 就是排序数组本身。）
