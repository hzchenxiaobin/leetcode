# LeetCode 移除栅栏得到的正方形田地的最大面积 题解

## 1. 题目概述

- **标题 / 题号**：移除栅栏得到的正方形田地的最大面积（#2975，medium）
- **链接**：https://leetcode.cn/problems/maximum-square-area-by-removing-fences-from-a-field/
- **来源**：LeetCode 第 377 场周赛 Q2
- **难度**：中等
- **标签**：数组、哈希表、枚举

**题意**：有一块 $(m-1) \times (n-1)$ 的矩形田地，两个对角为 $(1, 1)$ 与 $(m, n)$。田地内部有若干**整条**栅栏：水平栅栏 $i$ 从 $(\text{hFences}[i], 1)$ 铺到 $(\text{hFences}[i], n)$，垂直栅栏 $i$ 从 $(1, \text{vFences}[i])$ 铺到 $(m, \text{vFences}[i])$。外围四条栅栏（$y = 1$、$y = m$、$x = 1$、$x = n$）**不能移除**。可以移除任意若干条内部栅栏（整条移除），返回移除后所能形成的最大面积**正方形**田地的面积；无法形成正方形则返回 $-1$。答案对 $10^9 + 7$ 取余。

**约束**：

- $3 \le m, n \le 10^9$
- $1 \le \text{hFences.length}, \text{vFences.length} \le 600$
- $1 < \text{hFences}[i] < m$，$1 < \text{vFences}[i] < n$
- `hFences` 与 `vFences` 内部元素互不相同

> 💡 读题先抓两个反差：**值域巨大**（$m, n$ 高达 $10^9$，田地本身画不出来）但**栅栏极少**（每侧至多 600 条）。正方形的四条边只能落在**留下的栅栏**上——于是「移除哪些栅栏」是幌子，真正的问题是「**选哪两条水平线 + 哪两条垂直线**围正方形」。$600^2 \approx 3.6 \times 10^5$ 的对数枚举正是本题甜区。

## 2. 示例

**示例 1**

```text
输入：m = 4, n = 3, hFences = [2,3], vFences = [2]
输出：4
解释：移除位于 y=2 的水平栅栏和位于 x=2 的垂直栅栏，
      剩余栅栏围出 [1,3] × [1,3] 的 2×2 正方形，面积为 4。
```

**示例 2**

```text
输入：m = 6, n = 7, hFences = [2], vFences = [4]
输出：-1
解释：水平方向可达边长 {1,4,5}，垂直方向 {3,6}，无公共值，无法形成正方形。
```

**示例 3（自造，专测取模）**

```text
输入：m = 1000000000, n = 1000000000, hFences = [500000000], vFences = [500000000]
输出：64
解释：H = V = {1, 5×10⁸, 10⁹}，最大公共边长 best = 10⁹ − 1 = 999999999，
      面积 = 999999999² = 999999998000000001 ≈ 10¹⁸，模 10⁹ + 7 后恰为 64。
```

## 3. 解题思路

### 3.1 暴力思路：正向枚举边长为何是死路

边长 $d$ 合法 ⟺ 水平方向存在两条线（含外围）之差为 $d$，**且**垂直方向也存在两条线之差为 $d$。最朴素的想法是**正向枚举答案**：$d$ 从 $\min(m, n) - 1$ 往下扫，逐个判定。但 $d$ 的值域高达 $10^9$，即使每次判定用排序 + 双指针只花 $O(k)$（$k \le 602$），总量也是 $10^9 \times 1200 \approx 10^{12}$ 级别，直接爆炸。

> ⚠️ 死结在于**方向反了**：答案值域 $\sim 10^9$，但真正能被栅栏差凑出的边长**至多** $\binom{602}{2} = 180901$ 个。枚举对象应该是「**栅栏对**」而不是「边长值」——把 $O(\text{值域})$ 的搜索空间压缩成 $O(k^2)$ 的生成空间。

### 3.2 核心观察：移除 = 任选四条线，正方形 = 对差集合求交

![核心观察：移除是幌子，本质是选两条水平线与两条垂直线围正方形](images/wc377_q2_fence_square_observation.svg)

三步拆解：

1. **「移除」等价于「任选」**：选定上边 $y=b$、下边 $y=a$、左边 $x=c$、右边 $x=e$ 四条栅栏后，夹在中间的其他栅栏一律拆掉即可，不构成任何限制。**外围栅栏不能拆但永远在场**，完全可以充当正方形的边——必须把它们并入线集合参与配对：

$$H = \{1, m\} \cup \text{hFences}, \qquad V = \{1, n\} \cup \text{vFences}$$

2. **边长候选 = 对差集合**：$H$ 中任意两数之差构成水平方向可达边长集合 $S_h = \{h_j - h_i \mid h_i < h_j\}$；同理垂直方向 $S_v$。两者大小均 $\le \binom{602}{2} \approx 1.8 \times 10^5$。

3. **正方形边长 = 两个集合的公共元素**：$d \in S_h \cap S_v$ 时四条线围出边长 $d$ 的正方形。答案即：

$$\max(S_h \cap S_v)^2 \bmod (10^9 + 7) \quad (\text{交集为空则返回 } -1)$$

实现上**不必真求交集**：把 $S_h$ 全部插入哈希集合，再枚举 $V$ 的对差查询命中、顺手维护最大值——「枚举一边 + 哈希查另一边」正是 [1. 两数之和](https://leetcode.cn/problems/two-sum/) 的反查套路。

### 3.3 算法流程

![算法流程：一侧对差入哈希集合，另一侧查询取最大，最后判空取模](images/wc377_q2_diff_sets_intersect.svg)

1. **加边界**：`h = hFences + [1, m]`，`v = vFences + [1, n]`，各自**排序**（排序后枚举 $j > i$ 的对，差恒为正，省去绝对值）；
2. **建集合**：双重循环枚举 $H$ 的所有数对，把 $h_j - h_i$ 插入哈希集合 `diffs`；
3. **查交集**：双重循环枚举 $V$ 的所有数对，若 $d = v_j - v_i$ 命中 `diffs`，用 $d$ 更新最大边长 `best`；
4. **收尾**：`best` 仍为 $-1$ 说明交集为空，返回 $-1$；否则返回 $best^2 \bmod (10^9+7)$。

### 3.4 示例演算

![示例演算：H 与 V 的对差展开，交集取最大，含取模示例](images/wc377_q2_example_walkthrough.svg)

以示例 1（$m=4, n=3$，`hFences=[2,3]`，`vFences=[2]`）为例。

**水平方向**：$H = \{1, 2, 3, 4\}$，$\binom{4}{2} = 6$ 对：

| 数对 | (1,2) | (1,3) | (1,4) | (2,3) | (2,4) | (3,4) |
|------|-------|-------|-------|-------|-------|-------|
| 差 $d$ | 1 | 2 | 3 | 1 | 2 | 1 |

$S_h = \{1, 2, 3\}$（最大可达边长恰为 $m - 1 = 3$）。

**垂直方向**：$V = \{1, 2, 3\}$，3 对的差为 $1, 2, 1$，$S_v = \{1, 2\}$。

**交集**：$S_h \cap S_v = \{1, 2\}$，最大边长 $best = 2$，面积 $= 2^2 = 4$ ✓（对应移除 $y=2$ 的水平栅栏与 $x=2$ 的垂直栅栏）。

示例 2：$H = \{1, 2, 6\} \Rightarrow S_h = \{1, 4, 5\}$；$V = \{1, 4, 7\} \Rightarrow S_v = \{3, 6\}$。交集为空，返回 $-1$ ✓。

## 4. 算法细节

- **外围必须并入**：$1 < \text{hFences}[i] < m$ 保证内部栅栏与 $1, m$ 不重合，并入后 $H$ 无重复元素。不并入会漏掉所有**贴边**的正方形——示例 1 的 $2\times2$ 正方形就贴着 $y=1$ 与 $x=1$，漏并边界的话答案直接从 $4$ 错成 $-1$。
- **排序的作用**：枚举 $j > i$ 时差恒为正，免去绝对值讨论；同时把「线」从乱序坐标变成有序序列。
- **哈希求交的方向**：一侧对差全部 `insert`、另一侧枚举 `count`，单次 $O(1)$。集合应建在**较小**的一侧，空间 $O(\min(k_1, k_2)^2)$（本题两侧都 $\le 602$，无所谓）。
- **溢出的三层防线**：差值 $d \le \max(m,n) - 1 < 2^{31}$，`int` / `unordered_set<int>` 安全；面积 $d^2 < 10^{18}$，超出 32 位范围，C++ 中间量必须 `long long`；**取模时机放在返回前**，比较边长时用原值（先取模再比较会破坏大小关系）。
- **$m, n$ 不参与复杂度**：它们只是栅栏坐标的上界，算法只吃栅栏数量 $k \le 600$——「值域大、实体少」题目的标准形态。

## 5. 正确性证明

**引理 1（边的来源）**：任一移除方案下形成的每个矩形区域，其上、下边各落在一条**保留的**水平栅栏或不可移除外围栅栏所在直线上，左、右边各落在一条保留的垂直栅栏或外围栅栏所在直线上。

**证明**：区域上边界是水平线段，必须由保留栅栏覆盖。垂直栅栏是竖直线段，不能覆盖任何正长度的水平段，故覆盖它的一定是某条 $y = b$ 上的保留水平栅栏（或外围），即 $b \in H$。其余三边对称同理。∎

**引理 2（可行 $\Rightarrow$ 边长在交集）**：若某移除方案形成了边长 $d$ 的正方形，则 $d \in S_h \cap S_v$。

**证明**：由引理 1，设四边所在直线为 $y = a, y = b, x = c, x = e$（$a < b$，$c < e$），则 $a, b \in H$，$c, e \in V$，且 $b - a = e - c = d$。故 $d = b - a \in S_h$ 且 $d = e - c \in S_v$。∎

**引理 3（交集 $\Rightarrow$ 可行）**：若 $d \in S_h \cap S_v$，则存在移除方案形成边长 $d$ 的正方形。

**证明**：取 $a, b \in H$（$a < b$，$b - a = d$）与 $c, e \in V$（$c < e$，$e - c = d$）。方案：只保留 $y = a$、$y = b$ 处与 $x = c$、$x = e$ 处的栅栏（若是外围则天然在场），移除其余全部内部栅栏。此时场内水平直线仅 $y \in \{a, b\}$（及外围 $1, m$），垂直直线仅 $x \in \{c, e\}$（及外围 $1, n$），它们把大矩形划分为若干区域，其中恰有 $[a,b] \times [c,e]$：四边均为保留栅栏、内部无任何栅栏穿过，是边长 $d$ 的正方形区域。∎

**定理**：最大正方形面积为 $\left(\max(S_h \cap S_v)\right)^2 \bmod (10^9+7)$；交集为空时无解，返回 $-1$。

**证明**：由引理 2，一切可行边长都落在 $S_h \cap S_v$ 中，故最优边长 $\le \max(S_h \cap S_v)$；由引理 3，$\max(S_h \cap S_v)$（若存在）可行，故最优边长 $\ge \max(S_h \cap S_v)$。两者相等，又面积关于边长严格递增，故最优面积即其平方，按题意取模输出。∎

## 6. 复杂度分析

- **时间复杂度**：$O(k_1^2 + k_2^2)$，其中 $k_1, k_2 \le 602$ 为两侧线数。建集合与查询各约 $1.8 \times 10^5$ 次哈希操作，排序 $O(k \log k)$ 可忽略；总量远低于限时。
- **空间复杂度**：$O(k_1^2)$，哈希集合 `diffs` 至多 $\binom{602}{2} = 180901$ 个差值。若两侧线数悬殊，可让较小一侧建集合，降到 $O(\min(k_1, k_2)^2)$。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int maximizeSquareArea(int m, int n, vector<int>& hFences, vector<int>& vFences) {
        const long long MOD = 1e9 + 7;
        vector<int> h = hFences, v = vFences;
        h.push_back(1);
        h.push_back(m);
        v.push_back(1);
        v.push_back(n);
        sort(h.begin(), h.end());
        sort(v.begin(), v.end());

        int kh = h.size();
        unordered_set<int> diffs;
        diffs.reserve(kh * (kh - 1) / 2);
        for (int i = 0; i < kh; i++)
            for (int j = i + 1; j < kh; j++)
                diffs.insert(h[j] - h[i]);

        long long best = -1;
        int kv = v.size();
        for (int i = 0; i < kv; i++)
            for (int j = i + 1; j < kv; j++) {
                long long d = v[j] - v[i];
                if (diffs.count((int)d) && d > best) best = d;
            }

        return best < 0 ? -1 : (int)(best * best % MOD);
    }
};
```

### Python

```python
class Solution:
    def maximizeSquareArea(self, m: int, n: int, hFences: List[int], vFences: List[int]) -> int:
        MOD = 10 ** 9 + 7
        h = sorted(hFences + [1, m])
        v = sorted(vFences + [1, n])

        diffs = {h[j] - h[i]
                 for i in range(len(h)) for j in range(i + 1, len(h))}

        best = -1
        for i in range(len(v)):
            for j in range(i + 1, len(v)):
                d = v[j] - v[i]
                if d in diffs and d > best:
                    best = d

        return -1 if best < 0 else best * best % MOD
```

> 💡 语言细节：C++ 先 `reserve` 预留 $\binom{602}{2}$ 个桶避免反复 rehash；`diffs.count((int)d)` 把 `long long` 转回 `int` 查询（差值上界 $< 10^9$ 安全）。Python 集合推导式一行生成 $S_h$，原生大整数连溢出都不用操心。

## 8. 边界情况与易错点

1. **忘记并入外围 $1, m$（与 $1, n$）**：贴边的正方形全被漏掉。示例 1 若不并边界，$H = \{2,3\}$ 差集 $\{1\}$、$V = \{2\}$ 无对，会错答 $-1$ 而非 $4$——这是本题最大的坑。
2. **$d^2$ 溢出 32 位**：$d$ 接近 $10^9$ 时 $d^2 \approx 10^{18}$，C++ 全程 `long long` 存面积中间量；示例 3 的 $999999999^2 = 999999998000000001$ 直接验证。
3. **对 $-1$ 取模**：`best` 初值 $-1$ 是哨兵，交集为空时必须原样返回 $-1$；若直接 `best * best % MOD`，$(-1)^2 \bmod p = 1$，错得悄无声息。
4. **先取模再比较**：取模会破坏大小关系，必须先比完边长、最后一步才取模。
5. **最小规模单栅栏**：`hFences=[x]`、`vFences=[y]` 时各只有 3 条线，仍有 $(1, m)$、$(1, n)$ 等外围配对参与候选，代码天然覆盖，无需特判。
6. **$m \ne n$**：边长上限自动受 $\min(m, n) - 1$ 约束（较大一侧的差值在交集中匹配不上），无需显式判断。
7. **元素唯一性**：约束保证 `hFences` 内部无重复且严格落在 $(1, m)$ 开区间内，与并入的 $1, m$ 不冲突，排序后枚举不会产生重复线。

**延伸思考**：
