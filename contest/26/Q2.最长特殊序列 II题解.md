# LeetCode 最长特殊序列 II 题解

## 1. 题目概述

- **标题 / 题号**：最长特殊序列 II（#522，medium）
- **链接**：https://leetcode.cn/problems/longest-uncommon-subsequence-ii/
- **来源**：LeetCode 第 26 场周赛 Q2
- **难度**：中等
- **标签**：数组、哈希表、双指针、字符串、排序

**题意**：给定字符串数组 `strs`，返回其中最长的**特殊序列**的长度；不存在则返回 $-1$。称序列 $t$ 是特殊的，当且仅当：存在某个 $i$ 使 $t$ 是 `strs[i]` 的**子序列**，且对任意 $j \ne i$，$t$ 都**不是** `strs[j]` 的子序列。子序列由原串删去若干（可删 0 个）字符得到，**不要求连续**。

**约束**：

- $2 \le \lvert strs \rvert \le 50$
- $1 \le \lvert strs[i] \rvert \le 10$
- `strs[i]` 仅由小写英文字母组成

> 💡 与 #521 的区别：那题只有两个串，答案只能是 $\max(\lvert a \rvert, \lvert b \rvert)$ 或 $-1$；本题有 $n$ 个串，「谁包含谁」的组合更多，必须逐个判定。

## 2. 示例

**示例 1**

```text
输入：strs = ["aba","cdc","eae"]
输出：3
解释：三个串两两互不为子序列（"aba" 无法从 "cdc" 或 "eae" 中凑出），
      所以任意一个串本身都是特殊序列，长度 3 即最大值。
```

**示例 2**

```text
输入：strs = ["aaa","aaa","aa"]
输出：-1
解释："aaa" 出现两次，第 0 个 "aaa" 是第 1 个 "aaa" 的子序列，反之亦然；
      "aa" 是 "aaa" 删掉 1 个 a 的结果。所有串都被别的串覆盖，故无解。
```

**补充示例（自拟，帮助理解「覆盖」）**

```text
输入：strs = ["a","b"]
输出：1
解释："a" 不是 "b" 的子序列，长度 1 可行。

输入：strs = ["abcd","ab","abc"]
输出：4
解释：只有 "abcd" 不被其他串包含；"ab"、"abc" 都是它的子序列，故被覆盖。
```

## 3. 解题思路

### 3.1 暴力思路

按定义硬做：对每个串生成它的全部子序列（长度 $L$ 的串有 $2^L$ 个），放进集合去重得到候选集，再对每个候选统计「有多少个串包含它」，取「恰好被 1 个串包含」的最长长度。

在本题 $L \le 10$ 的限制下，单个串最多 $2^{10} = 1024$ 个子序列，候选总量约 $5\times10^{4}$，每个候选再与 $n$ 个串做 $O(L)$ 判定，约 $2.5\times10^{7}$ 次操作——**勉强能过**，但缺点明显：

- 时间复杂度关于 $\lvert strs[i] \rvert$ 是**指数级**的，长度上限抬到 20 就会爆；
- 生成子序列 + 字符串集合去重，代码冗长、常数巨大；
- 题目只问「最长」，枚举全部候选属于纯浪费。

### 3.2 核心观察：答案一定是某个原串本身

![答案必是原串本身：子序列特殊则可扩展成整串](images/wc26_q2_subsequence_concept.svg)

设 $t$ 是**长度最大**的特殊序列，由定义它必是某个 `strs[i]` 的子序列。关键断言：**`strs[i]` 本身也特殊**。

反证：若存在 $j \ne i$ 使 `strs[i]` 是 `strs[j]` 的子序列，则由子序列关系的**传递性**，$t$ 也是 `strs[j]` 的子序列，与 $t$ 特殊矛盾。于是 `strs[i]` 不被任何其他串包含，它是特殊的，并且 $\lvert strs[i] \rvert \ge \lvert t \rvert$。

由于 $t$ 已是长度最大者，故 $\lvert strs[i] \rvert = \lvert t \rvert$。于是

$$\text{answer} = \max\{\, \lvert strs[i] \rvert \;:\; strs[i] \text{ 不是任何 } strs[j]\ (j \ne i) \text{ 的子序列} \,\}$$

搜索空间从「指数个子序列」塌缩成「$n$ 个原串」，只需 $n(n-1)$ 次子序列判定。

### 3.3 算法流程

![算法流程：降序排序后逐个判定，首个可行即返回](images/wc26_q2_check_flow.svg)

1. 把 `strs` 按**长度降序**排序。这一步只为让「第一个可行的串」就是最优解，从而可以提前返回。
2. 依次取 $t = strs[i]$ 作为候选，与所有 $j \ne i$ 的 `strs[j]` 做子序列判定。
3. 只要有一个 `strs[j]` 包含 $t$，$t$ 就被「覆盖」，跳过。
4. 若某个 $t$ 不被任何其他串包含，直接返回 $\lvert t \rvert$——降序保证它是最大长度。
5. 全部被覆盖，返回 $-1$。

子序列判定用**双指针贪心**：

```text
p = 0
for ch in s:
    if p < len(t) and ch == t[p]: p += 1
return p == len(t)
```

`s` 从左到右扫一遍，遇到与 `t[p]` 相同的字符就推进 `p`；扫完时 `p == |t|` 即 $t \subseteq s$。单次 $O(\lvert t \rvert + \lvert s \rvert)$。

### 3.4 示例演算

![两组示例的逐串判定走查表](images/wc26_q2_walkthrough.svg)

对 `strs = ["aba","cdc","eae"]`：

| $i$ | $t$ | 与其余串比较 | 被包含？ | 候选 |
|-----|-----|--------------|----------|------|
| 0 | `"aba"` | `"cdc"` ✗，`"eae"` ✗ | 否 | 3 |
| 1 | `"cdc"` | `"aba"` ✗，`"eae"` ✗ | 否 | 3 |
| 2 | `"eae"` | `"aba"` ✗，`"cdc"` ✗ | 否 | 3 |

三串互不包含，$\text{best} = \max(3,3,3) = 3$。

对 `strs = ["aaa","aaa","aa"]`：

- $i=0$：`"aaa"` 是 $i=1$ 那个 `"aaa"` 的子序列（相等串互相包含）→ 被覆盖；
- $i=1$：与 $i=0$ 同理 → 被覆盖；
- $i=2$：`"aa"` 由 `"aaa"` 删掉 1 个 `a` 得到 → 被覆盖。

全部被覆盖，返回 $-1$。

## 4. 算法细节

1. **必须跳过 `i == j`**：任何串都是自己的子序列。漏掉这个判断，所有串都会被「自己」覆盖，答案恒为 $-1$。
2. **排序不改变答案，只改变顺序**：按长度降序后，第一个「不被覆盖」的串必然就是最长候选，可以直接 `return`，不必遍历全部；等长串之间顺序任意，返回值相同。
3. **相等串互为覆盖**：`"aaa"` 与 `"aaa"` 互相是子序列，故重复出现的串永远不是答案。用哈希表把相同串分组、把计数 $\ge 2$ 的组直接判否，可省掉大量比较——题目标签里的 Hash Table 说的就是这种去重加速。
4. **双指针判定是贪心的**：扫描 `s` 时能匹配就立即匹配（取最靠前的可用字符），不会让后续字符更难匹配，因此不会漏解（见引理 3）。
5. **子序列 ≠ 子串**：`"ab"` 是 `"acb"` 的子序列（跳过 `c`），却不是它的连续子串。若把判定写成 `find` / `substr` 式的连续匹配，`["ab","acb","acb"]` 会被错算成 2，而正确答案是 $-1$（`"ab"` 被两个 `"acb"` 覆盖，`"acb"` 又被彼此覆盖）。
6. **等价剪枝**：不排序时可用 `best` 记录当前最优，并加 `if len(t) <= best: continue`；排序后提前返回等价于更强的剪枝，代码也更短。
7. **量级估算**：$n(n-1) \le 2450$ 次判定，每次最多比 20 个字符，总操作数不到 $5\times10^{4}$，即使 Python 也是毫秒级。

## 5. 正确性证明

**引理 1（子序列关系传递）**：若 $t$ 是 $u$ 的子序列、$u$ 是 $s$ 的子序列，则 $t$ 是 $s$ 的子序列。

**证明**：$t$ 的字符依次出现在 $u$ 的某些位置，$u$ 的每个字符又依次出现在 $s$ 的某些位置。把两段嵌入复合起来，即得到 $t$ 的字符在 $s$ 中一份保持先后顺序的出现位置，故 $t \subseteq s$。∎

**引理 2（最优解可取整串）**：若存在特殊序列，则存在长度相等的特殊序列是 `strs` 中的某个原串。

**证明**：取长度最大的特殊序列 $t$，由定义存在 $i$ 使 $t \subseteq strs[i]$。若存在 $j \ne i$ 使 $strs[i] \subseteq strs[j]$，由引理 1 得 $t \subseteq strs[j]$，与 $t$ 特殊矛盾；故 `strs[i]` 不被任何其他串包含，即 `strs[i]` 特殊。又 $\lvert strs[i] \rvert \ge \lvert t \rvert$，由 $t$ 的最大性得等号成立。∎

**引理 3（双指针判定正确）**：`is_sub(t, s)` 返回 true，当且仅当 $t$ 是 $s$ 的子序列。

**证明**：

- （返回 true $\Rightarrow$）算法每推进一次 `p`，都对应 `s` 中一个严格更靠后、且字符等于 `t[p]` 的位置；这些位置按顺序构成 $t$ 在 $s$ 中的一个嵌入，故 $t \subseteq s$。
- （$t \subseteq s \Rightarrow$ 返回 true）设 $p_1 < p_2 < \cdots < p_m$ 是 $t$ 在 $s$ 中的一组嵌入下标。对 $k$ 归纳可证：算法扫到 $s$ 的第 $p_k$ 个字符时，指针 `p` 至少已推进到 $k$——因为贪心总是匹配最靠前的可行位置，不会落后于任何合法嵌入。故最终 `p` 达到 $m$，返回 true。∎

**定理**：算法返回最长特殊序列的长度；不存在时返回 $-1$。

**证明**：记 $S$ 为所有「不被任何其他串包含」的原串下标集合。

- 若 $S = \varnothing$：任意 `strs[i]` 都被某个 `strs[j]` 包含。对任意子序列 $t \subseteq strs[i]$，由引理 1 得 $t \subseteq strs[j]$，故 $t$ 不特殊；特殊序列集合为空，返回 $-1$ 正确。
- 若 $S \ne \varnothing$：对 $i \in S$，`strs[i]` 不被任何其他串包含，由引理 3 判定准确，故算法会把它识别为可行候选；降序排列后遇到的第一个可行串长度即 $\max_{i \in S} \lvert strs[i] \rvert$，正是算法返回值。由引理 2，最长特殊序列的长度等于该最大值，故返回值正确。∎

## 6. 复杂度分析

- **时间**：$O(n^2 L)$，其中 $n = \lvert strs \rvert$、$L = \max_i \lvert strs[i] \rvert$。每个候选串与其余 $n-1$ 个串各做一次 $O(L)$ 的双指针判定；排序的 $O(n \log n)$ 被 $n^2 L$ 吸收。最坏 $50 \times 49$ 对判定，每对最多比 $2L \le 20$ 个字符，约 $5\times10^{4}$ 次字符比较；提前返回后通常远小于此上界。
- **空间**：$O(1)$ 额外空间（不计输入与排序副本）；C++ 中 `sort` 为原地排序，Python 的 `sorted` 会新建 $O(n)$ 的列表。

## 7. 参考代码

### C++

```cpp
#include <string>
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int findLUSlength(vector<string>& strs) {
        int n = strs.size();
        // t 是否为 s 的子序列（双指针贪心）
        auto isSub = [](const string& t, const string& s) {
            size_t p = 0;
            for (size_t i = 0; i < s.size() && p < t.size(); i++)
                if (s[i] == t[p]) p++;
            return p == t.size();
        };

        // 长度降序：第一个不被任意其他串包含的串就是答案
        sort(strs.begin(), strs.end(), [](const string& a, const string& b) {
            return a.size() > b.size();
        });

        for (int i = 0; i < n; i++) {
            bool ok = true;
            for (int j = 0; j < n && ok; j++) {
                if (i != j && isSub(strs[i], strs[j])) ok = false;
            }
            if (ok) return (int)strs[i].size();
        }
        return -1;
    }
};
```

### Python

```python
from typing import List

class Solution:
    def findLUSlength(self, strs: List[str]) -> int:
        def is_sub(t: str, s: str) -> bool:
            p = 0
            for ch in s:
                if p < len(t) and ch == t[p]:
                    p += 1
            return p == len(t)

        strs = sorted(strs, key=len, reverse=True)   # 长度降序，首个可行即最优
        for i, t in enumerate(strs):
            if not any(j != i and is_sub(t, s) for j, s in enumerate(strs)):
                return len(t)
        return -1
```

## 8. 边界情况与易错点

1. **全部串相同**：`["a","a"]`、`["abc","abc","abc"]` 都返回 $-1$，因为每个串都被同值的另一份覆盖。
2. **答案可以是 1**：`["a","b"]` 返回 1，`["ab","ab","c"]` 也返回 1（`"c"` 不被 `"ab"` 覆盖）。不要把合法答案 1 与「无解」混淆。
3. **`i == j` 自比较**：漏写 `i != j` 会让所有串被自己覆盖，答案恒为 $-1$，这是最常见的 WA 原因。
4. **无解返回 $-1$ 而不是 0**：空序列虽是任何串的子序列，却不被任何串「独有」，题意不会取它，哨兵必须用 $-1$。
5. **子序列判定别写成子串**：`["ab","acb","acb"]` 的正确答案是 $-1$（`"ab"` 是 `"acb"` 的子序列），但用连续子串判定会得到 2——「跳过字符」正是子序列的题眼。
6. **提前返回依赖排序**：若不排序就直接返回第一个可行串，得到的是「某个」可行长度而非最长；要么先排序，要么全程取 $\max$。
7. **去重加速时别漏比重复串**：计数 $\ge 2$ 的串可以被判否，但计数为 1 的候选仍必须与**所有**其他下标（含重复出现的串）比较，因为被任意一个其他串包含就不再特殊。
