# LeetCode 省份数量 题解

## 1. 题目概述

- **标题 / 题号**：省份数量（#547，medium）
- **链接**：https://leetcode.cn/problems/number-of-provinces/
- **来源**：LeetCode 第 26 场周赛 Q3
- **难度**：中等
- **标签**：深度优先搜索，广度优先搜索，并查集，图

**题意**：给定 $n \times n$ 的 0/1 矩阵 `isConnected`，`isConnected[i][j] = 1` 表示城市 $i$ 与城市 $j$ **直接相连**；而「直接相连」具有传递性（$a$ 连 $b$、$b$ 连 $c$，则 $a$ 与 $c$ 间接相连）。省份是「一组直接或间接相连的城市」，且组内不含其它未相连的城市。求**省份的个数**，也就是这个无向图的**连通分量数**。

**约束**：

- $1 \le n \le 200$
- $n = \text{isConnected.length} = \text{isConnected}[i]\text{.length}$
- `isConnected[i][j]` 非 0 即 1，且 `isConnected[i][i] = 1`
- `isConnected[i][j] = isConnected[j][i]`（矩阵对称，边无向）

## 2. 示例

**示例 1**

```text
输入：isConnected = [[1,1,0],[1,1,0],[0,0,1]]
输出：2
解释：城市 0 与 1 直接相连，构成第 1 个省；城市 2 谁也不连，自成一个省。
```

**示例 2**

```text
输入：isConnected = [[1,0,0],[0,1,0],[0,0,1]]
输出：3
解释：三个城市两两不相连，各自独立成省。
```

**补充示例（链状传递）**

```text
输入：isConnected = [[1,1,0,0],[1,1,1,0],[0,1,1,0],[0,0,0,1]]
输出：2
解释：0-1、1-2 相连，故 {0,1,2} 同省（0 与 2 虽不直接相连，但间接相连）；城市 3 独立。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的做法是对每个城市跑一次 DFS/BFS：`visited` 数组标记，遇到未访问的城市就计数并整块遍历。这已经是 $O(n^2)$，但需要额外维护 `visited` 与（隐式或显式）邻接表。

还可以更笨一点：先用 Floyd 求传递闭包，把「间接相连」也填成 1，再统计矩阵里互相为 1 的块数——时间 $O(n^3) = 8 \times 10^6$，$n = 200$ 时勉强能过，但纯属浪费；空间还要再开一个 $n \times n$ 矩阵。

关键问题是：题目要的**不是「路径可达性」，而是「把点划分成等价类」**。既然如此，就该用一个只维护「划分」的数据结构，而不是反复做图搜索。

### 3.2 核心观察：省份就是并查集里的等价类

![邻接矩阵 → 无向图 → 等价类](images/wc26_q3_union_find_model.svg)

「同省」这个关系满足三条性质：

- **自反**：城市 $i$ 与自己同省；
- **对称**：$i$ 与 $j$ 同省 $\iff$ $j$ 与 $i$ 同省（无向图）；
- **传递**：$i$ 与 $j$ 同省、$j$ 与 $k$ 同省 $\Rightarrow$ $i$ 与 $k$ 同省（连通具有传递性）。

这正是**等价关系**的定义，省份就是它的**等价类**。而「合并两个等价类」的最轻量工具是**并查集（DSU）**：

- 初始时每个城市自成一类，共 $n$ 个省；
- 每读到一条「$i$ 与 $j$ 相连」的边，若二者根不同，就合并两类，**省份数恰好减 1**；
- 扫完所有边，剩下的类数就是答案。

矩阵对称，因此只需扫描**上三角** $j < i$ 的 $\frac{n(n-1)}{2}$ 个位置，每条边只处理一次。

### 3.3 算法流程

![并查集流程](images/wc26_q3_dsu_flow.svg)

1. 初始化 `parent[i] = i`、`size[i] = 1`、`cnt = n`；
2. 双重循环 `i = 0..n-1`、`j = 0..i-1`，跳过 `isConnected[i][j] == 0` 的位置；
3. 对每条边求两个端点所在树的根 `ri = find(i)`、`rj = find(j)`；
4. 若 `ri == rj`，说明已在同一省，什么都不做；否则**按大小合并**（把小树挂到大树下），`cnt -= 1`；
5. 循环结束后返回 `cnt`。

`find` 采用**路径压缩**（隔代压缩 `parent[x] = parent[parent[x]]`），配合按大小合并，单次操作均摊 $O(\alpha(n))$，$\alpha$ 为反阿克曼函数，实际可视为常数。

### 3.4 示例演算

![示例 1 的逐步走查](images/wc26_q3_walkthrough.svg)

对官方示例 1 的矩阵，上三角共 3 条候选边：

| 步骤 | 检查的边 | 根 | 动作 | `cnt` |
| --- | --- | --- | --- | --- |
| 初始 | — | `parent = [0,1,2]` | — | 3 |
| 1 | `isConnected[1][0] = 1` | `find(1)=1`，`find(0)=0` | 合并 {0,1} | 2 |
| 2 | `isConnected[2][0] = 0` | 不调用 | 跳过 | 2 |
| 3 | `isConnected[2][1] = 0` | 不调用 | 跳过 | 2 |

总共只成功合并 1 次，故 $cnt = 3 - 1 = 2$，与输出一致。

## 4. 算法细节

1. **只扫上三角**：题目保证矩阵对称，扫 $j < i$ 把边数从 $n^2$ 降到 $\frac{n(n-1)}{2}$，且不会重复合并同一条边。
2. **`cnt` 的语义**：它表示「当前等价类的个数」，初值 $n$；只有 `find(i) != find(j)` 时才自减，重复边或环边不会多减（否则全连通图会被减成负数）。
3. **路径压缩的正确写法**：迭代版 `while (parent[x] != x) { parent[x] = parent[parent[x]]; x = parent[x]; }` 是隔代压缩，效果与完全压缩同阶；Python 若用递归版，对 `cnt` 的修改需要 `nonlocal`，改用循环可省掉这一层。
4. **按大小合并**：`size` 记录每棵树的结点数，把小的根指向大的根，保证树高 $O(\log n)$；配合路径压缩后均摊到 $O(\alpha(n))$。按秩（rank）合并等价，`size` 更直观。
5. **不必建邻接表**：矩阵本身就是邻接矩阵，`isConnected[i][j]` 是 $O(1)$ 查询；另建 `vector<vector<int>>` 只会多出 $O(n^2)$ 的常数开销。
6. **不要动态维护 `set`**：每次合并都遍历、删除、重组集合是 $O(n^2)$ 甚至 $O(n^3)$，DSU 的 `parent` 数组才是 $O(n)$ 空间的正解。
7. **DFS 写法也可**：外层枚举起点，未访问就 `dfs(i)` 把整个连通块染掉并计数，复杂度同为 $O(n^2)$；本题选 DSU 是为了强调「等价类合并」这个可迁移模板，且 DSU 天然支持在线加边。

## 5. 正确性证明

记号：`find(x)` 返回 `x` 在 `parent` 森林中的根；「操作」指对某条边执行一次成功的 `union`。

**引理 1（根的唯一性）**：在任意时刻，`x` 与 `y` 属于同一棵 `parent` 树，当且仅当它们被一系列成功的 `union` 操作连在了一起。

**证明**：初始时每棵树只含自己，结论成立。每次 `union(ri, rj)` 把根 `rj` 的父亲改成 `ri`，两棵树合并成一棵，原来各自内部的结点两两之间本就同树，合并后跨树的两个结点也变得同树——正是「被这次 union 连在一起」。归纳即得。∎

**引理 2（合并计数精确）**：一次成功的 `union` 恰好使等价类个数减 1；一次失败的 `union`（两端同根）不改变等价类个数。

**证明**：根不同意味着两个类互不相交，合并后它们的并成为一个类，类数 $k \to k-1$；根相同说明两个端点已在同一类，合并不做任何修改。∎

**引理 3（扫完所有边后，同根 $\iff$ 连通）**：算法扫描完全部 $j < i$ 的边之后，对任意城市 $u$、$v$，$u$ 与 $v$ 在图中连通当且仅当 `find(u) == find(v)`。

**证明**：

- ($\Leftarrow$) 由引理 1，`find(u) == find(v)` 意味着存在一串联通它们的成功 `union`，而每次成功 `union` 都对应矩阵中一条值为 1 的边，这些边串联起来就是图中一条 $u$ 到 $v$ 的路径，故连通。
- ($\Rightarrow$) 设 $u = w_0, w_1, \dots, w_m = v$ 是图中的一条路径。对路径长度 $m$ 归纳：$m = 0$ 时 $u = v$，同根。设 $m \ge 1$，边 $(w_0, w_1)$ 在扫描中被处理过（矩阵对称，必然出现在上三角的某个位置），处理后 $w_0$ 与 $w_1$ 同根；由归纳假设 $w_1$ 与 $w_m$ 同根；根的相等关系传递，故 $w_0$ 与 $w_m$ 同根。∎

**定理**：算法返回的 `cnt` 等于矩阵所描述无向图的连通分量数。

**证明**：初始 $cnt = n$，等于 $n$ 个孤立点的分量数。由引理 2，每次成功合并使分量数恰好减 1，且算法恰好对每条「有效边」尝试一次、对每个不同类只合并一次，因此扫描结束时分量数仍等于 $cnt$——因为按引理 3，此时每个连通分量内的城市同根、不同分量的城市不同根，二者一一对应。∎

## 6. 复杂度分析

- **时间**：$O(n^2 \alpha(n))$。矩阵扫描 $\frac{n(n-1)}{2}$ 次比较；每条边至多 2 次 `find`，成功合并至多 $n-1$ 次，单次均摊 $O(\alpha(n))$。$n = 200$ 时约 $2 \times 10^4$ 次比较，可忽略不计。
- **空间**：$O(n)$。`parent` 与 `size` 各 $n$ 个整数，无递归栈（迭代 `find`）；输入矩阵不计入算法空间。
- 对比 DFS：时间同为 $O(n^2)$，但 DFS 还需 `visited` 数组（$O(n)$）与递归栈（最坏 $O(n)$），且不能在线回答「新加一条边后省份数是多少」。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <functional>
#include <algorithm>
using namespace std;

class Solution {
public:
    int findCircleNum(vector<vector<int>>& isConnected) {
        int n = isConnected.size();
        vector<int> parent(n), sz(n, 1);
        for (int i = 0; i < n; i++) parent[i] = i;

        // 路径压缩（隔代压缩），迭代实现，避免递归栈
        function<int(int)> find = [&](int x) -> int {
            while (parent[x] != x) {
                parent[x] = parent[parent[x]];
                x = parent[x];
            }
            return x;
        };

        int cnt = n;                              // 初始 n 个省
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < i; j++) {         // 只扫上三角
                if (isConnected[i][j] != 1) continue;
                int ri = find(i), rj = find(j);
                if (ri == rj) continue;           // 已在同一省
                if (sz[ri] < sz[rj]) swap(ri, rj); // 小树挂到大树下
                parent[rj] = ri;
                sz[ri] += sz[rj];
                cnt--;                            // 成功合并才减一
            }
        }
        return cnt;
    }
};
```

### Python

```python
class Solution:
    def findCircleNum(self, isConnected: List[List[int]]) -> int:
        n = len(isConnected)
        parent = list(range(n))
        size = [1] * n

        def find(x: int) -> int:
            while parent[x] != x:          # 隔代路径压缩
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x

        cnt = n
        for i in range(n):
            for j in range(i):             # 只扫上三角，矩阵对称
                if isConnected[i][j] != 1:
                    continue
                ri, rj = find(i), find(j)
                if ri == rj:               # 同一省份，跳过
                    continue
                if size[ri] < size[rj]:    # 小树挂到大树下
                    ri, rj = rj, ri
                parent[rj] = ri
                size[ri] += size[rj]
                cnt -= 1
        return cnt
```

## 8. 边界情况与易错点

1. **$n = 1$**：循环不执行，直接返回 `cnt = 1`，与「一个城市自成一省」一致。
2. **全孤立 / 全连通**：对角全 1、其余全 0 时返回 $n$；矩阵全 1 时只合并 $n-1$ 次，返回 1，注意 `cnt` 不会被减到 0 以下。
3. **只扫上三角依赖对称性**：题目保证 `isConnected[i][j] == isConnected[j][i]`；若在变体题中矩阵不对称，必须扫全矩阵（或至少保证两个方向都处理），否则会漏边。
4. **别把答案写成边数**：统计 `isConnected[i][j] == 1` 的个数得到的是「有向边数」，与省份数无关；也不要统计 $i \ne j$ 的 1 的个数除以 2，那仍是边数而不是连通块数。
5. **重复边重复减一**：环边（如三角形 0-1-2 全连）上后面的边 `find` 相等，必须 `continue`，否则 `cnt` 会多减。
6. **递归 `find` 的深度**：不按大小合并时 `parent` 可能退化成链，深度 $O(n)$；$n = 200$ 尚不至于爆栈，但养成按大小合并的习惯，深度稳定在 $O(\log n)$。
7. **在 Python 里修改闭包变量**：若把 `cnt` 写进嵌套函数并用递归 `find`，必须声明 `nonlocal cnt`；本解法把 `find` 写成纯函数、`cnt` 留在外层作用域，避开这个坑。
