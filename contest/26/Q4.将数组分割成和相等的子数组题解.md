# LeetCode 将数组分割成和相等的子数组 题解

## 1. 题目概述

- **标题 / 题号**：将数组分割成和相等的子数组（#548，hard）
- **链接**：https://leetcode.cn/problems/split-array-with-equal-sum/
- **来源**：LeetCode 第 26 场周赛 Q4
- **难度**：困难
- **标签**：数组、哈希表、前缀和

**题意**：给定长度 $n$ 的整数数组 `nums`，判断是否存在满足

$$0 < i,\qquad i+1 < j,\qquad j+1 < k < n-1$$

的三元组 $(i,j,k)$，使得除被下标 $i$、$j$、$k$ **跳过的三个元素**之外，剩下元素按原顺序拼成的四段连续子数组和完全相等：

$$\text{sum}(0,i-1)=\text{sum}(i+1,j-1)=\text{sum}(j+1,k-1)=\text{sum}(k+1,n-1).$$

存在返回 `true`，否则返回 `false`。

**约束**：

- $1 \le n \le 2000$，$-10^6 \le nums[i] \le 10^6$
- $0<i,\ i+1<j,\ j+1<k<n-1$ 蕴含四段都**非空**，因此 $n<7$ 时答案必为 `false`
- 前缀和绝对值可达 $2\times 10^9$，C++ 必须用 `long long`，`int` 会溢出
- 元素可正可负可零，前缀和**不单调**，一切「和越来越大」的剪枝直觉都失效

> 💡 最不容易读错的记法：$i,j,k$ 是「被扔掉的三个元素的下标」，剩下的元素按原顺序恰好拼成四段，要求四段和相等。

## 2. 示例

**示例 1**

```text
输入：nums = [1,2,1,2,1,2,1]
输出：true
解释：i = 1, j = 3, k = 5
sum(0, i-1)   = sum(0, 0) = 1
sum(i+1, j-1) = sum(2, 2) = 1
sum(j+1, k-1) = sum(4, 4) = 1
sum(k+1, n-1) = sum(6, 6) = 1
```

**示例 2**

```text
输入：nums = [1,2,1,2,1,2,1,2]
输出：false
解释：n = 8 时 j 只能取 3 或 4。j = 3 时 k = 5 得第三段 1、第四段 3，
      k = 6 得两段都是 2，但左侧公共值只有 1；j = 4 时左侧凑不出相等的
      两段，故不存在合法的 (i, j, k)。
```

**示例 3（补充：等值放大版）**

```text
输入：nums = [3,1,3,1,3,1,3]
输出：true
解释：i = 1, j = 3, k = 5，四段各含一个 3，和都为 3。
```

## 3. 解题思路

### 3.1 暴力思路

枚举三个切点 $i<j<k$，先用前缀和把每段和在 $O(1)$ 内算出再比较，总复杂度 $O(n^3)$。$n=2000$ 时合法三元组数量在 $10^{9}$ 量级，远超时限；若不对每段预处理前缀和、而是在循环里重新求和，则退化成 $O(n^4)$。

暴力之所以慢，是因为它把「四段和相等」当成一个整体约束，同时枚举了**三个**自由度。其实真正需要固定住的只有**中切点 $j$**——它是唯一同时被左右两侧使用的下标。

### 3.2 核心观察：固定 $j$，把四段拆成左右两半

![三个切点把数组切成四段，被跳过的三个元素不参与求和](images/wc26_q4_four_parts.svg)

令 $pre[m]=\sum_{t<m} nums[t]$（$pre[0]=0$），四段和分别是

$$S_1=pre[i],\quad S_2=pre[j]-pre[i+1],\quad S_3=pre[k]-pre[j+1],\quad S_4=pre[n]-pre[k+1].$$

注意四条式子里变量的归属：

- $S_1,S_2$ 只依赖 $(i,j)$，所以 $S_1=S_2$ 是**只与 $i$、$j$ 有关**的条件；
- $S_3,S_4$ 只依赖 $(j,k)$，所以 $S_3=S_4$ 是**只与 $j$、$k$ 有关**的条件；
- 唯一把两半黏在一起的下标就是 $j$。

于是固定 $j$ 之后，问题拆成两个互不干扰的一维问题，再要求**两侧的公共值相同**。左侧能提供的公共值集合是

$$C(j)=\{\,pre[i]\;:\;1\le i\le j-2,\ pre[i]=pre[j]-pre[i+1]\,\},$$

右侧对每个 $k\in[j+2,n-2]$ 先算 $v=pre[k]-pre[j+1]$，只要 $v=pre[n]-pre[k+1]$ 且 $v\in C(j)$，就命中一组解。

$C(j)$ 用哈希集合维护，则 $v\in C(j)$ 的判定是 $O(1)$：每个 $j$ 花 $O(j)$ 建集合、花 $O(n-j)$ 扫右侧，总复杂度 $O(n^2)$，比暴力的 $O(n^3)$ 整整降一个量级。

> 💡 两个等式的等价化简（少一次数组访问，写起来也更短）：
> $$pre[i]=pre[j]-pre[i+1]\iff 2\,pre[i]+nums[i]=pre[j],$$
> $$pre[k]-pre[j+1]=pre[n]-pre[k+1]\iff 2\,pre[k]+nums[k]=pre[n]+pre[j+1].$$
> 但它们**只化简等式本身**；「左侧的段和必须等于右侧的段和」这件事仍然只能靠集合完成，见 §8 第 4 条的反例。

### 3.3 算法流程

![按 j 分治：左边建集合，右边扫一遍](images/wc26_q4_pivot_flow.svg)

```text
pre[0..n] ← 前缀和，pre[0] = 0，pre[m] = pre[m-1] + nums[m-1]
if n < 7: return false
for j = 3 .. n-4:
    C ← 空哈希集合
    for i = 1 .. j-2:
        if pre[i] == pre[j] - pre[i+1]: C.add(pre[i])
    if C 为空: continue
    for k = j+2 .. n-2:
        v ← pre[k] - pre[j+1]
        if v == pre[n] - pre[k+1] and v ∈ C: return true
return false
```

原来的三层枚举被压成「一层 $j$ + 两个线性扫描」，第三层嵌套彻底消失。

### 3.4 示例演算

![示例 1 与示例 2 的逐 j 走查](images/wc26_q4_walkthrough.svg)

**示例 1**：`nums = [1,2,1,2,1,2,1]`，$n=7$，前缀和 $pre=[0,1,3,4,6,7,9,10]$。$j$ 只在 $[3,n-4]=[3,3]$ 里取值，即仅有 $j=3$：

| 步骤 | 计算 | 结果 |
|------|------|------|
| 建集合 | $i\in[1,1]$：$pre[1]=1$，$pre[3]-pre[2]=4-3=1$，相等 | $C(3)=\{1\}$ |
| 扫 $k$ | $k\in[5,5]$：$v=pre[5]-pre[4]=7-6=1$，$S_4=pre[7]-pre[6]=10-9=1$ | $v=S_4$ 且 $1\in C(3)$ → `true` |

命中的正是 $(i,j,k)=(1,3,5)$，四段各含一个 $1$。

**示例 2**：`nums = [1,2,1,2,1,2,1,2]`，$n=8$，$pre=[0,1,3,4,6,7,9,10,12]$，$j\in[3,4]$：

| $j$ | 左集合 $C(j)$ | 右侧扫描 |
|-----|----------------|----------|
| 3 | $i=1$：$pre[1]=1=pre[3]-pre[2]$，得 $\{1\}$ | $k=5$：$v=1$，$S_4=12-9=3$，不等；$k=6$：$v=9-7=2$，$S_4=12-10=2$，相等但 $2\notin C(3)$ |
| 4 | $i=1$：$1\ne 6-3=3$；$i=2$：$3\ne 6-4=2$，集合为空 | 空集直接跳过 |

两个 $j$ 都没命中，返回 `false`，与官方输出一致。

## 4. 算法细节

1. **前缀和下标约定**：$pre[m]$ 表示**前 $m$ 个**元素之和，于是 $pre[i+1]=pre[i]+nums[i]$，任意段 $(l,r)$ 的和为 $pre[r+1]-pre[l]$。四条段和公式全部按此约定推导，代码里不要再混用 $pre[r]-pre[l-1]$ 的写法。
2. **$j$ 的范围是 $[3,\,n-4]$**：$j\ge 3$ 来自 $i\ge 1$ 且 $i\le j-2$；$j\le n-4$ 来自 $k\le n-2$ 且 $k\ge j+2$。写成 `for (int j = 3; j <= n - 4; ++j)` 既不会越界也不会漏掉边界。
3. **$i$ 取到 $j-2$、$k$ 从 $j+2$ 起**：$i+1<j$ 与 $j+1<k$ 要求中间两段至少各有 1 个元素；若把 $i$ 放到 $j-1$（或 $k$ 放到 $j+1$），等于允许空段并把它的和记成 $0$，会让含 $0$ 的数据多判 `true`。
4. **集合必须在每个 $j$ 重新构建**：$C(j)$ 的判据里含有 $pre[j]$，$j$ 一变判据就变。把集合提到循环外复用，等于把「$j'$ 时刻合法的 $i$」错当成 $j$ 时刻的候选，会产生假阳性。
5. **整型宽度**：$n\cdot\max|nums[i]|=2\times 10^{9}$ 已经越过 `int` 的安全范围，前缀和与段和统一用 `long long`；Python 整数无上限，无需关心。
6. **先判空再扫右侧**：$C(j)$ 为空说明左侧没有任何合法 $i$，右侧无论怎么扫都拼不出解，直接 `continue`——在随机数据上这一步能省掉大量无效扫描。
7. **哈希集合只存「值」**：$j$ 固定后，$i$ 的合法性已经被 $C(j)$ 的定义吸收，没必要再存下标，也不需要去重以外的任何结构。C++ 用 `unordered_set<long long>` 并 `reserve` 到 $2n$ 降低 rehash 开销。
8. **不要引入除法或浮点**：四段和相等是纯整数等式。若用 $S=(total-nums[i]-nums[j]-nums[k])/4$ 做剪枝，既要处理整除性、又要处理负数取整，收益远小于风险。

## 5. 正确性证明

**引理 1（段和公式）**：对 $0\le l\le r\le n-1$，有 $\sum_{t=l}^{r}nums[t]=pre[r+1]-pre[l]$。

**证明**：由 $pre[m]=\sum_{t<m}nums[t]$，两式相减时 $t<l$ 的项与 $t>r$ 的项恰好成对抵消，只剩下 $nums[l..r]$。特别地，题目四段分别取 $(0,i-1)$、$(i+1,j-1)$、$(j+1,k-1)$、$(k+1,n-1)$，代入即得 §3.2 的四条式子。∎

**引理 2（左集合的刻画）**：对固定 $j$ 与 $i\in[1,j-2]$，$S_1=S_2$ 当且仅当 $pre[i]\in C(j)$。

**证明**：由引理 1，$S_1=pre[i]$、$S_2=pre[j]-pre[i+1]$，故 $S_1=S_2\iff pre[i]=pre[j]-pre[i+1]$，这正是 $C(j)$ 的入集条件；而 $C(j)$ 收集的值就是 $pre[i]$ 本身，所以等价。∎

**引理 3（右判定的精确性）**：对固定 $j$ 与 $k\in[j+2,n-2]$，令 $v=pre[k]-pre[j+1]$，则 $S_3=S_4$ 当且仅当 $v=pre[n]-pre[k+1]$；且此时 $S_3=S_4=v$。

**证明**：$S_3=pre[k]-pre[j+1]=v$，$S_4=pre[n]-pre[k+1]$，二者相等即 $v=pre[n]-pre[k+1]$，相等的值自然就是 $v$。∎

**定理**：算法返回 `true` 当且仅当存在满足 $0<i,\ i+1<j,\ j+1<k<n-1$ 且四段和相等的三元组 $(i,j,k)$。

**证明**：

- （$\Leftarrow$）设存在合法三元组 $(i,j,k)$。由下标约束得 $j\in[3,n-4]$、$i\in[1,j-2]$、$k\in[j+2,n-2]$，故算法会枚举到该 $j$。由 $S_1=S_2$ 与引理 2，$pre[i]\in C(j)$，集合非空；又由 $S_3=S_4$ 与引理 3，$v=pre[k]-pre[j+1]=S_3=S_1=pre[i]\in C(j)$，于是算法在该 $k$ 处判定成立并返回 `true`。
- （$\Rightarrow$）若算法返回 `true`，则存在 $j\in[3,n-4]$ 与 $i\in[1,j-2]$ 使 $pre[i]\in C(j)$，并存在 $k\in[j+2,n-2]$ 使 $v=pre[k]-pre[j+1]=pre[n]-pre[k+1]$ 且 $v\in C(j)$。取这组 $i,k$：引理 2 给出 $S_1=S_2=pre[i]=v$，引理 3 给出 $S_3=S_4=v$，四个和全部相等，下标也满足全部约束，故 $(i,j,k)$ 合法。

当 $n<7$ 时区间 $[3,n-4]$ 为空、算法返回 `false`，而此时四段非空的要求已无法满足，确实不存在合法三元组。两个方向合起来即得结论。∎

## 6. 复杂度分析

- **时间**：$O(n^2)$。前缀和预处理 $O(n)$；外层 $j$ 有 $O(n)$ 个取值，每个 $j$ 用 $O(j)$ 建集合、$O(n-j)$ 扫右侧，合计 $\sum_j O(n)=O(n^2)$；集合插入与查询均为期望 $O(1)$。$n=2000$ 时约 $4\times 10^6$ 次基本操作。
- **空间**：$O(n)$。前缀和数组 $O(n)$，哈希集合最多存 $O(n)$ 个不同的段和，其余只有常数个标量。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <unordered_set>
using namespace std;

class Solution {
public:
    bool splitArray(vector<int>& nums) {
        int n = (int)nums.size();
        if (n < 7) return false;                  // 四段非空 + 三个切点，至少 7 个元素
        vector<long long> pre(n + 1, 0);
        for (int t = 0; t < n; ++t) pre[t + 1] = pre[t] + nums[t];
        long long total = pre[n];

        for (int j = 3; j <= n - 4; ++j) {
            unordered_set<long long> cand;        // C(j)：满足 S1 == S2 的段和
            cand.reserve((size_t)2 * n);
            for (int i = 1; i <= j - 2; ++i)
                if (pre[i] == pre[j] - pre[i + 1]) cand.insert(pre[i]);
            if (cand.empty()) continue;           // 左侧拼不出相等的两段

            for (int k = j + 2; k <= n - 2; ++k) {
                long long third = pre[k] - pre[j + 1];
                if (third == total - pre[k + 1] && cand.count(third)) return true;
            }
        }
        return false;
    }
};
```

### Python

```python
from typing import List


class Solution:
    def splitArray(self, nums: List[int]) -> bool:
        n = len(nums)
        if n < 7:                      # 四段非空 + 三个切点，至少 7 个元素
            return False
        pre = [0] * (n + 1)
        for t, v in enumerate(nums):
            pre[t + 1] = pre[t] + v
        total = pre[n]

        for j in range(3, n - 3):      # j ∈ [3, n-4]
            cand = set()               # C(j)：满足前两段相等的段和
            for i in range(1, j - 1):  # i ∈ [1, j-2]
                if pre[i] == pre[j] - pre[i + 1]:
                    cand.add(pre[i])
            if not cand:
                continue               # 左侧没有候选值，跳过
            for k in range(j + 2, n - 1):   # k ∈ [j+2, n-2]
                third = pre[k] - pre[j + 1]
                if third == total - pre[k + 1] and third in cand:
                    return True
        return False
```

## 8. 边界情况与易错点

1. **$n<7$ 直接返回 `false`**：四段各至少 1 个元素、再加 3 个被跳过的元素，至少需要 $4+3=7$ 个位置。显式特判既省去空区间判断，也避免超短数组上的下标错乱。
2. **$j$ 的上界是 $n-4$**：$j=n-3$ 时右侧要求 $k\ge j+2=n-1$ 同时 $k\le n-2$，区间为空、该 $j$ 必无解，写成 $n-3$ 只是多跑一轮空转；但若顺带把 $k$ 的上界放宽到 $n-1$，第四段就变成空段（和恒为 $0$），判定直接被破坏。
3. **集合跨 $j$ 复用会假阳性**：$C(j)$ 的判据依赖 $pre[j]$。把 `unordered_set` 提到外层循环之外，$j'$ 的候选会污染 $j$，随机数据上就能测出错误答案。
4. **只验证两个「两两相等」，忘了跨左右配对**：若只检查「左边两段相等」「右边两段相等」就返回 `true`，`nums = [0,-2,-2,2,-2,1,-2,0,1]` 会被误判——$j=4,i=1$ 时左边两段都是 $0$，$j=4,k=6$ 时右边两段都是 $1$，但 $0\ne 1$，正确答案是 `false`。这正是 $C(j)$ 必须存「值」、而不能只存布尔的理由。
5. **`int` 溢出**：$2000\times 10^6=2\times 10^9$ 已逼近 `int` 上界，且 $pre[j]-pre[i+1]$ 这类减法可能先算出约 $-2\times 10^9$ 再参与比较，一律用 `long long`（Python 无此问题）。
6. **别把前缀和当单调函数**：元素可为负，「和太大 / 太小」「四段和必落在 $[0,\,total/4]$」之类的直觉全部不成立。$[-1,-1,-1,-1,-1,-1,-1]$ 的正确答案是 `true`（四段和都是 $-1$）。
7. **空段语义**：若把 $i$ 取到 $j-1$ 或 $k$ 取到 $j+1$，中间段为空、和记 $0$，与题面 $i+1<j,\ j+1<k$ 冲突，会在含 $0$ 的数据上多判 `true`。
8. **$k$ 的上界是 $n-2$**：这保证第四段 $[k+1,\,n-1]$ 至少含 $nums[n-1]$ 一个元素；写成 $k\le n-1$ 就变成空段，第四段和恒为 $0$。
