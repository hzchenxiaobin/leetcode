# LeetCode 最长特殊序列 Ⅰ 题解

## 1. 题目概述

- **标题 / 题号**：最长特殊序列 Ⅰ（#521，easy）
- **链接**：https://leetcode.cn/problems/longest-uncommon-subsequence-i/
- **来源**：LeetCode 第 26 场周赛 Q1
- **难度**：简单
- **标签**：字符串

**题意**：给定两个字符串 $a$、$b$，返回二者的**最长特殊序列**的长度；若不存在则返回 $-1$。这里「特殊序列」指的是：它是**某一个字符串的子序列**，但**不是另一个字符串的子序列**。子序列由原串删除任意数量（含 0 个）字符得到，不要求连续。

**约束**：

- $1 \le |a|, |b| \le 100$
- $a$、$b$ 仅由小写英文字母组成

> 💡 本题是标准的「签到题」，但题意容易被误读成「最长公共子序列」或「长度差」。关键在于：答案的取值范围只有两个数——$\max(|a|,|b|)$ 或 $-1$。

## 2. 示例

**示例 1**

```text
输入：a = "aba", b = "cdc"
输出：3
解释：最长特殊序列可为 "aba"（或 "cdc"），两者均为自身的子序列，
      且都不是对方的子序列。
```

**示例 2**

```text
输入：a = "aaa", b = "bbb"
输出：3
解释：最长特殊序列是 "aaa" 和 "bbb"。
```

**示例 3**

```text
输入：a = "aaa", b = "aaa"
输出：-1
解释：字符串 a 的每个子序列也是 b 的子序列，反之亦然，不存在特殊序列。
```

## 3. 解题思路

### 3.1 暴力思路

按定义直接枚举：先列出 $a$ 的全部子序列（共 $2^{|a|}$ 个）与 $b$ 的全部子序列（共 $2^{|b|}$ 个），对每个候选串用双指针 $O(|a|+|b|)$ 判定它是否为对方的子序列，最后在所有合法候选中取最大长度。判定本身不难，难在候选数量：$|a| = 100$ 时 $2^{100} \approx 1.27\times 10^{30}$，任何剪枝都救不回来。

另一条常见弯路是「求最长公共子序列（LCS）再做减法」，或者按 $|a|-|b|$ 猜答案——这两条思路都和正解无关。正确的方向是**先把答案的上界卡死**，再检查上界能否被直接构造出来。

### 3.2 核心观察：长度上界 + 相等判定

![长度上界与两种情形](images/wc26_q1_prefix_bound.svg)

**第一步：卡上界。** 特殊序列 $t$ 按定义必须是 $a$ 或 $b$ 的子序列，而子序列不会比原串更长，于是

$$|t| \le |a| \quad \text{或} \quad |t| \le |b| \quad \Longrightarrow \quad |t| \le \max(|a|, |b|).$$

**第二步：看这个上界能否取到。** 候选串不必费心构造，**较长者自己**就是最好的候选。设 $|a| \ge |b|$：

- 若 $|a| > |b|$：任何 $b$ 的子序列长度都不超过 $|b| < |a|$，所以 $a$ 不可能是 $b$ 的子序列，$a$ 就是合法特殊序列，长度为 $|a| = \max(|a|,|b|)$；
- 若 $|a| = |b|$ 且 $a \ne b$：长度等于 $|b|$ 的 $b$ 的子序列只能是 $b$ 本身（子序列必须取满全部字符），而 $a \ne b$，故 $a$ 仍不是 $b$ 的子序列，同样取到上界。

**第三步：唯一无解的情形。** 当 $a = b$ 时，两者是同一个字符串，子序列集合完全相同，任何子序列都同时是双方的子序列，差集为空，答案只能是 $-1$。

> 💡 一句话：**答案 $\in \{\max(|a|,|b|), -1\}$**，判据只取决于两串是否相等，与内容、字母、长度差都无关。

### 3.3 算法流程

![算法流程](images/wc26_q1_flow.svg)

```text
1. 若 a == b：返回 -1          // 差集为空，无特殊序列
2. 否则：返回 max(|a|, |b|)    // 较长者本身即为最长特殊序列
```

等价地也可以压成一行 C++ 表达式：`return a == b ? -1 : (int)max(a.size(), b.size());`。两种分支互斥且穷尽，没有第三种情况需要考虑。

### 3.4 示例演算

![三个官方示例与一个自造示例的走查](images/wc26_q1_walkthrough.svg)

以示例 1（$a = \text{"aba"}$，$b = \text{"cdc"}$）为例，把两个子序列集合真正展开看一遍。长度为 3 的串有 $2^3 = 8$ 种取法，$a$ 去重后得到 7 个不同子序列：

$$\mathrm{Sub}(a) = \{\varnothing,\ \text{"a"},\ \text{"b"},\ \text{"ab"},\ \text{"aa"},\ \text{"ba"},\ \text{"aba"}\}$$

（下标 0 与下标 2 都可以单独取出字符 "a"，故按取法计 8 个、按内容计 7 个。）同理

$$\mathrm{Sub}(b) = \{\varnothing,\ \text{"c"},\ \text{"d"},\ \text{"cc"},\ \text{"cd"},\ \text{"dc"},\ \text{"cdc"}\}.$$

两个集合的交集只有空串——而空串是任何串的子序列，按定义永远不合格。于是差集共 $6+6 = 12$ 个候选，其中最长的是 "aba" 与 "cdc"，长度 $3 = \max(3,3)$，与「直接返回较长者长度」完全吻合。

再看自造示例 $a = \text{"abc"}$、$b = \text{"ab"}$：$a$ 更长，而 "abc" 的长度 3 已经超过 $|b| = 2$，不可能成为 $b$ 的子序列，故答案是 $3$ 而不是 $3 - 2 = 1$。示例 3 是唯一返回 $-1$ 的形态——两串逐字符相同。

## 4. 算法细节

1. **用语言内置的字符串相等比较**：C++ 的 `a == b`、Python 的 `a == b` 已经是优化过的逐字符比较（先比长度，不等立即返回 false），不要自己写循环，那只会引入边界错误。
2. **取长度用 `max`，不要做减法**：`max(a.size(), b.size())` 的语义就是「较长者的长度」；写成 `a.size() - (a.size() - b.size())` 之类的等价式，只是在给无符号下溢制造机会。
3. **注意 C++ 的 `size_t`**：`std::max(a.size(), b.size())` 返回 `size_t`，函数签名要求 `int`，需要显式 `(int)` 转换；若直接 `return max(a.size(), b.size());` 多数编译器能隐式收窄，但开 `-Wconversion` 会告警。
4. **分支顺序**：先判相等再取长度，语义最清晰；不要写成「长度相等就返回 -1」——长度相等但内容不同（如 "ab" / "ba"）时答案是 $2$。
5. **不要引入 LCS**：若用 $O(|a||b|)$ 的动态规划求最长公共子序列再判断，是把 $O(1)$ 的问题做成 $O(|a||b|)$；虽然 $100\times100$ 也能过，但属于典型的「用大炮打蚊子」。
6. **不要返回 0**：题目保证两串长度都 $\ge 1$，所以 $\max \ge 1$；只有 $a = b$ 这一个分支返回 $-1$，不存在返回 $0$ 的路径。

## 5. 正确性证明

记 $\mathrm{Sub}(s)$ 为字符串 $s$ 的全部子序列构成的集合，$\mathrm{US}(a,b) = \bigl(\mathrm{Sub}(a)\setminus\mathrm{Sub}(b)\bigr) \cup \bigl(\mathrm{Sub}(b)\setminus\mathrm{Sub}(a)\bigr)$ 为全部特殊序列。

**引理 1（长度上界）**：对任意 $t \in \mathrm{US}(a,b)$，有 $|t| \le \max(|a|,|b|)$。

**证明**：由定义 $t \in \mathrm{Sub}(a)$ 或 $t \in \mathrm{Sub}(b)$。子序列是从原串删字符得到的，长度不可能超过原串，故 $|t| \le |a|$ 或 $|t| \le |b|$，两者都蕴含 $|t| \le \max(|a|,|b|)$。∎

**引理 2（不等的构造）**：若 $a \ne b$，则 $\max(|a|,|b|) \in \{|t| : t \in \mathrm{US}(a,b)\}$，即上界可达。

**证明**：不妨 $|a| \ge |b|$（$|b| > |a|$ 时对称地把 $a$、$b$ 互换）。

- 情形 $|a| > |b|$：若 $a \in \mathrm{Sub}(b)$，则 $|a| \le |b|$，与 $|a| > |b|$ 矛盾，故 $a \notin \mathrm{Sub}(b)$。而 $a \in \mathrm{Sub}(a)$ 显然，于是 $a \in \mathrm{US}(a,b)$，$|a| = \max(|a|,|b|)$。
- 情形 $|a| = |b|$ 且 $a \ne b$：若 $a \in \mathrm{Sub}(b)$，则存在下标序列 $0 \le i_1 < \dots < i_{|a|} < |b| = |a|$ 使 $a$ 等于 $b$ 在这些位置上的拼接。长度为 $|a|$ 的严格递增下标序列在 $\{0,\dots,|b|-1\}$ 中唯一，只能是 $0,1,\dots,|b|-1$，于是 $a = b$，矛盾。故 $a \notin \mathrm{Sub}(b)$，同样 $a \in \mathrm{US}(a,b)$，$|a| = \max(|a|,|b|)$。

两种情形都构造出了一个长度恰为上界的特殊序列。∎

**引理 3（相等时无解）**：若 $a = b$，则 $\mathrm{US}(a,b) = \varnothing$。

**证明**：$a = b$ 蕴含 $\mathrm{Sub}(a) = \mathrm{Sub}(b)$（子序列集合只由字符串内容决定），两个差集都为空，故并集为空。∎

**定理**：算法返回最长特殊序列的长度。

**证明**：

- 若 $a = b$：由引理 3 集合为空，不存在特殊序列，算法返回 $-1$，与题面「不存在则返回 $-1$」一致。
- 若 $a \ne b$：由引理 2 存在长度为 $\max(|a|,|b|)$ 的特殊序列，由引理 1 不存在更长的特殊序列，故最长长度为 $\max(|a|,|b|)$，算法恰好返回该值。

两种情况覆盖了全部输入，故算法输出恒等于正确答案。∎

## 6. 复杂度分析

- **时间**：$O(\min(|a|,|b|))$。字符串相等比较先比长度（$O(1)$），长度相同时最坏逐字符比较 $\min$ 次即停；取 `max` 是 $O(1)$。因为 $|a|,|b| \le 100$，实际是一次极短的比较。
- **空间**：$O(1)$。只用到长度与一个布尔判定结果，没有开辟任何辅助数组或字符串。

## 7. 参考代码

### C++

```cpp
#include <string>
#include <algorithm>
using namespace std;

class Solution {
public:
    int findLUSlength(string a, string b) {
        // 两串完全相同：任何子序列都同时属于双方，不存在特殊序列
        if (a == b) return -1;
        // 否则较长者本身就不是另一串的子序列，直接取到长度上界
        return (int)max(a.size(), b.size());
    }
};
```

### Python

```python
class Solution:
    def findLUSlength(self, a: str, b: str) -> int:
        # 完全相同 → 子序列集合相同，差集为空
        if a == b:
            return -1
        # 否则较长者本身就是最长特殊序列
        return max(len(a), len(b))
```

## 8. 边界情况与易错点

1. **完全相同必须返回 $-1$**：`a = "aaa"`, `b = "aaa"` → $-1$。写成 `return max(len(a), len(b))` 会得到 3，是最常见的 WA。
2. **等长但内容不同不等于无解**：`a = "ab"`, `b = "ba"` → 返回 2（"ab" 是 $a$ 的子序列，但不是 $b$ 的子序列）。判据是**内容相等**，不是长度相等。
3. **答案不是长度差**：`a = "abc"`, `b = "ab"` → 3 而不是 1。$a$ 比 $b$ 长的部分并不是「独有的子序列」这个概念的全部。
4. **也不要返回 $\mathrm{LCS}$ 相关量**：本题与最长公共子序列无关。若一定要用 LCS 表述，正确的等价命题是「$a = b \iff \mathrm{LCS}(a,b) = |a| = |b|$」，而不是用它算答案。
5. **C++ 无符号数陷阱**：`a.size() - b.size()` 在 $|a| < |b|$ 时下溢成巨大的 `size_t`，再转 `int` 得到负数或实现相关的值；一律用 `max(a.size(), b.size())`。
6. **子序列不是子串**：`a = "ace"`, `b = "abcde"` 时 $a$ 是 $b$ 的子序列，但答案仍是 5——因为 $b$ 自己不可能是 $a$ 的子序列。不要试图判断「谁包含谁」，本题只需要一次相等比较。
7. **全同字符的长短串**：`a = "a"*100`, `b = "a"*99` → 100。虽然 $a$ 看起来「几乎」是 $b$ 的子序列，但长度已经超标，无法成为其子序列。

**延伸思考**：把问题从两个串推广到 $n$ 个串（即 522 题），上界不再是 $\max_i |s_i|$，因为最长的串也可能是另一个更长串的子序列；此时必须对每个候选串检查「是否被其余串的子序列关系覆盖」。再进一步，若允许最多删除 $k$ 个字符来「制造」一个特殊序列，问题就变成在子序列偏序集上的最优化，需要用 DP 在自动机上处理——那时「一次相等比较」的捷径彻底消失。
