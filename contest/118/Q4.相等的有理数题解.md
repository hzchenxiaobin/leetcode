# LeetCode 相等的有理数 题解

## 1. 题目概述

- **标题 / 题号**：相等的有理数（#972，hard）
- **链接**：https://leetcode.cn/problems/equal-rational-numbers/
- **来源**：LeetCode 第 118 场周赛 Q4
- **难度**：困难
- **标签**：数学、字符串

**题意**：给定两个字符串 $s$ 和 $t$，每个串表示一个**非负有理数**，合法格式只有三种：

1. `<IntegerPart>`，如 `0`、`12`、`123`；
2. `<IntegerPart>.<NonRepeatingPart>`，如 `0.5`、`1.`（小数部分为空）、`123.0001`；
3. `<IntegerPart>.<NonRepeatingPart>(<RepeatingPart>)`，如 `0.1(6)`、`1.(9)`、`123.00(1212)`。

括号里的部分**无限循环**。判断两个字符串是否表示**同一个数**。

**约束**：

- 每部分仅由数字组成；整数部分不以 $0$ 开头（$0$ 本身除外）
- $1 \le \text{IntegerPart.length} \le 4$
- $0 \le \text{NonRepeatingPart.length} \le 4$
- $1 \le \text{RepeatingPart.length} \le 4$

> ⚠️ 这是**精度陷阱题**：`0.9(9)` 与 `1.` 必须判等，用 `double` 存值再比较一定会挂。

## 2. 示例

**示例 1**

```text
输入：s = "0.(52)", t = "0.5(25)"
输出：true
解释：0.(52) = 0.52525252...，0.5(25) = 0.525252525...
      两者循环节不同（"52" 与 "25"），展开后却是同一个无限小数。
```

**示例 2**

```text
输入：s = "0.1666(6)", t = "0.166(66)"
输出：true
解释：两者都等于 1/6 ≈ 0.16666666...
```

**示例 3**

```text
输入：s = "0.9(9)", t = "1."
输出：true
解释：0.999999... = 1。这是本题最经典的伪装：循环节全是 9 时，
      小数部分「进位」成整数 1，必须靠精确算术才能识别。
```

**示例 4**

```text
输入：s = "0", t = "0.0(0)"
输出：true
解释：0.000... 就是 0；整数表示与「带循环节的 0」必须判等。
```

## 3. 解题思路

### 3.1 暴力思路

最直觉的做法：把字符串转成 `double` 再比较。但 `0.9(9)` 只可能被截断成 `0.9999999999`，与 `1.0` 差 $10^{-10}$ 量级——**不可能相等**。把精度提到 `long double` 也只是把错误藏得更深：循环小数的值本身就是无穷级数的极限，浮点表示在原理上就丢失了「无限」这一信息。

另一条暴力路线：把两个数都展开成足够长的小数（比如 $10^4$ 位）再逐位比较。长度是够的（分母最大约 $10^8$，两个不等有理数的差至少 $10^{-16}$），但判定「足够长」这件事需要额外证明，且遇到 `0.9(9)` vs `1.` 还要处理进位归一化，不如直接做**精确分数运算**。

### 3.2 核心观察：循环小数 = 有限部分 + 等比级数

![循环小数拆成有限部分与等比级数](images/wc118_q4_fraction_formula.svg)

设整数部分为 $I$，非重复部分为数字串 $N$（长度 $l_n$），循环节为 $R$（长度 $l_r$，$R$ 视为整数）。那么

$$x = I + \frac{N}{10^{l_n}} + \frac{R}{10^{l_n}} \cdot \left(\frac{1}{10^{l_r}} + \frac{1}{10^{2l_r}} + \cdots\right)$$

括号里是公比 $q = 10^{-l_r}$ 的等比级数，和为 $\dfrac{1}{1 - q} = \dfrac{10^{l_r}}{10^{l_r} - 1}$，于是

$$x = I + \frac{N}{10^{l_n}} + \frac{R}{10^{l_n}\,(10^{l_r} - 1)}$$

通分后得到**单一的分数**：

$$x = \frac{\big(I \cdot 10^{l_n} + N\big)\,(10^{l_r} - 1) + R}{10^{l_n}\,(10^{l_r} - 1)}$$

（若没有小数部分则 $l_n = 0, N = 0, 10^{l_n} = 1$；若没有循环节则直接令分母为 $10^{l_n}$。）

所有运算都是整数运算，$l_n, l_r \le 4$ 时分母最大 $10^4 \times (10^4 - 1) \approx 10^8$，分子最大约 $10^{12}$——用 64 位整数存得下，**比较用交叉相乘即可**，全程零精度损失。

### 3.3 算法流程

![解析流水线：字符串 → 整数部分/非重复/循环节 → 分数 → 交叉相乘](images/wc118_q4_parse_pipeline.svg)

```text
parse(s):
    I = 读整数部分
    若遇到 '.':  读非重复部分 N（可能为空），l_n = len(N)
                 若遇到 '(': 读循环节 R，l_r = len(R)
    若 l_r == 0:  num = I * 10^l_n + N,  den = 10^l_n
    否则:        num = (I * 10^l_n + N) * (10^l_r - 1) + R
                 den = 10^l_n * (10^l_r - 1)
    约分（除以 gcd），返回 (num, den)

isRationalEqual(s, t):
    (p1, q1) = parse(s);  (p2, q2) = parse(t)
    return p1 * q2 == p2 * q1
```

### 3.4 示例演算

![演算：两种写法的 l_n 不同，却落在同一个 52/99](images/wc118_q4_walkthrough.svg)

对示例 1 的两个串分别解析，再交叉相乘：

| 串 | $I$ | $N$ | $l_n$ | $R$ | $l_r$ | 分子 | 分母 | 约分后 |
|---|---|---|---|---|---|---|---|---|
| `0.(52)` | 0 | — | 0 | 52 | 2 | $0 \cdot 99 + 52 = 52$ | $1 \cdot 99 = 99$ | $52/99$ |
| `0.5(25)` | 0 | 5 | 1 | 25 | 2 | $(0 \cdot 10 + 5)\cdot 99 + 25 = 520$ | $10 \cdot 99 = 990$ | $52/99$ |

交叉相乘：$52 \times 990 = 51480 = 520 \times 99$ ✓ 相等，输出 `true`。

再看 `0.9(9)` 与 `1.`：前者 $l_n = 1, N = 9, l_r = 1, R = 9$，分子 $(0 \cdot 10 + 9) \cdot 9 + 9 = 90$，分母 $10 \cdot 9 = 90$，约分得 $1/1$；后者 $I = 1$、无小数部分，得 $1/1$。相等 ✓。

## 4. 算法细节

1. **解析顺序**：先把整数部分读完；`'.'` 之后先读非重复段（**可以为空**，如 `1.`），只有遇到 `'('` 才继续读循环节。`1.` 与 `1` 必须解析成同一个值。
2. **空非重复段**：`0.(52)` 的 $N = 0$、$l_n = 0$，此时 $10^{l_n} = 1$，公式自然退化为 $R/(10^{l_r} - 1)$，无需特判。
3. **空循环节（无括号）**：分母只保留 $10^{l_n}$，不能再乘 $(10^{l_r} - 1)$，否则会人为缩小 $10^{l_r} - 1$ 倍。
4. **先约分再比较**：不约分直接交叉相乘，最大可达 $10^{12} \times 10^{8} = 10^{20}$，超出 64 位范围；约分后仍可能溢出，所以比较时用 `__int128`（Python 天然大整数，无此问题）。
5. **`0.9(9)` 的进位**：不要试图「规范化尾数 9」，那是浮点思维；精确公式会把 $90/90$ 自动算成 $1$。
6. **`10^{l_r} - 1` 的溢出风险**：$l_r \le 4$ 时它 $\le 9999$，安全；若题目放宽到 $l_r = 9$ 仍可用 `long long`，更长的循环节需要大整数。

## 5. 正确性证明

**引理 1（解析公式正确）**：设串形如 $I.N(R)$（$N$ 可为空、$R$ 可不存在），则 `parse` 计算出的分数值等于该无限小数的值。

**证明**：无限小数可写成
$$x = I + \sum_{i=1}^{l_n} \frac{N_i}{10^i} + \sum_{k\ge 0}\sum_{j=1}^{l_r} \frac{R_j}{10^{l_n + k\,l_r + j}}$$
其中 $N_i$、$R_j$ 为对应位数字。前两项即 $I + N/10^{l_n}$。第三项按周期分组：
$$\sum_{j=1}^{l_r}\frac{R_j}{10^{l_n+j}}\sum_{k \ge 0} 10^{-k\,l_r} = \frac{R}{10^{l_n}}\cdot\frac{1}{10^{l_r}}\cdot\frac{1}{1 - 10^{-l_r}} = \frac{R}{10^{l_n}(10^{l_r}-1)}$$
（用到 $R = \sum_j R_j 10^{l_r - j}$ 与等比级数求和 $\sum_{k\ge0} q^k = 1/(1-q)$，$q = 10^{-l_r} < 1$ 保证收敛。）三者相加并通分即得 `parse` 中的公式。$R$ 不存在时第三项为 $0$，与代码分支一致。∎

**引理 2（约分不改变值、且不破坏相等判定）**：设 $g = \gcd(num, den)$，则 $num/den = (num/g)/(den/g)$，且对任意两数，$p_1 q_2 = p_2 q_1$ 在约分前后等价。

**证明**：$num = g\,n'$、$den = g\,d'$，故 $num/den = n'/d'$。交叉相乘判据来自 $p_1/q_1 = p_2/q_2 \iff p_1 q_2 = p_2 q_1$（$q_1, q_2 > 0$，分母恒正），两边同除以 $g_1 g_2 > 0$ 不改变等式真假。∎

**定理**：`isRationalEqual(s, t)` 返回 `true` 当且仅当 $s$、$t$ 表示同一个有理数。

**证明**：由引理 1，`parse` 返回的 $(p, q)$ 满足 $p/q$ 等于对应字符串的值，$q > 0$。由引理 2，交叉相乘判据与实数相等等价：
$$\frac{p_1}{q_1} = \frac{p_2}{q_2} \iff p_1 q_2 = p_2 q_1$$
由于所有运算均在整数域精确完成（C++ 用 `__int128` 承载乘积，Python 用大整数），不存在舍入误差，故返回值与「两数相等」严格等价。∎

## 6. 复杂度分析

- **时间**：$O(L)$，$L \le 13$ 为串长。解析逐字符扫描一遍，$10^{l_r}$ 与 gcd 均为常数级整数运算（$l_r \le 4$）；比较 $O(1)$。
- **空间**：$O(1)$，只存两个分数与几个计数变量。

## 7. 参考代码

### C++

```cpp
class Solution {
    long long gcdll(long long a, long long b) {
        while (b) { long long t = a % b; a = b; b = t; }
        return a;
    }

    // 把有理数字符串解析成精确分数 num/den（den > 0，已约分）
    pair<long long, long long> parse(const string& s) {
        long long I = 0, N = 0, R = 0;
        long long p10 = 1, r10 = 1;          // p10 = 10^l_n, r10 = 10^l_r
        size_t i = 0;
        while (i < s.size() && isdigit((unsigned char)s[i])) I = I * 10 + (s[i++] - '0');
        if (i < s.size() && s[i] == '.') {
            i++;
            while (i < s.size() && isdigit((unsigned char)s[i])) {
                N = N * 10 + (s[i] - '0');
                p10 *= 10;
                i++;
            }
            if (i < s.size() && s[i] == '(') {
                i++;
                while (i < s.size() && isdigit((unsigned char)s[i])) {
                    R = R * 10 + (s[i] - '0');
                    r10 *= 10;
                    i++;
                }
            }
        }
        long long num, den;
        if (r10 == 1) {                      // 没有循环节
            num = I * p10 + N;
            den = p10;
        } else {                             // 有循环节：等比级数求和
            num = (I * p10 + N) * (r10 - 1) + R;
            den = p10 * (r10 - 1);
        }
        long long g = gcdll(num, den);
        return {num / g, den / g};
    }

public:
    bool isRationalEqual(string s, string t) {
        auto [p1, q1] = parse(s);
        auto [p2, q2] = parse(t);
        return (__int128)p1 * q2 == (__int128)p2 * q1;
    }
};
```

### Python

```python
from math import gcd


class Solution:
    def _parse(self, s: str) -> tuple[int, int]:
        """把有理数字符串解析成精确分数 (num, den)，den > 0 且已约分。"""
        i, n = 0, len(s)
        integer = 0
        while i < n and s[i].isdigit():
            integer = integer * 10 + int(s[i])
            i += 1
        non_rep, rep = "", ""
        if i < n and s[i] == '.':
            i += 1
            while i < n and s[i].isdigit():
                non_rep += s[i]
                i += 1
            if i < n and s[i] == '(':
                i += 1
                while i < n and s[i] != ')':
                    rep += s[i]
                    i += 1
        ln, lr = len(non_rep), len(rep)
        p10 = 10 ** ln
        n_val = int(non_rep) if non_rep else 0
        if lr == 0:
            num, den = integer * p10 + n_val, p10
        else:
            r10 = 10 ** lr
            num = (integer * p10 + n_val) * (r10 - 1) + int(rep)
            den = p10 * (r10 - 1)
        g = gcd(num, den)
        return num // g, den // g

    def isRationalEqual(self, s: str, t: str) -> bool:
        p1, q1 = self._parse(s)
        p2, q2 = self._parse(t)
        return p1 * q2 == p2 * q1
```

## 8. 边界情况与易错点

1. **`0.9(9)` 与 `1.`**：循环节全为 9 会「进位」，必须靠精确分数识别；用浮点必挂（示例 3）。
2. **`1.` 这种「空小数部分」**：`'.'` 后没有数字、也没有括号，$l_n = 0$，值就是整数部分，不能解析失败。
3. **循环节被非重复部分“移位”**：`0.(52)` 与 `0.5(25)` 展开相同，但 $l_n$ 不同，公式必须把 $10^{l_n}$ 同时作用到 $R$ 的分母上（见引理 1）。
4. **无循环节时误乘 $(10^{l_r} - 1)$**：$l_r = 0$ 时 $10^0 - 1 = 0$，会直接除零。
5. **交叉相乘溢出**：分子可达 $10^{12}$、分母 $10^8$，乘积 $10^{20}$ 超过 `long long`；用 `__int128`（或先约分 + 大整数）。
6. **`0` 的多种写法**：`0`、`0.0`、`0.(0)`、`0.0(0)` 都应判等——公式天然统一，不需要特判。
7. **`isdigit` 收到负的 `char`**：C++ 里传入非 ASCII 字节是未定义行为，保险写法 `isdigit((unsigned char)c)`。
8. **循环节长度 4、非重复长度 4 同时出现**：$l_n = l_r = 4$ 时 $den = 10^4 \times 9999 \approx 10^8$，仍在安全范围内，不要因为「看起来很大」就改用浮点。
9. **`123.0001` 这类超长小数**：没有循环节，$den = 10^4$，属常规路径，注意别把 $N$ 的前导零丢掉后当成「更短的小数」——前导零影响 $10^{l_n}$。
