# LeetCode 煎饼排序 题解

## 1. 题目概述

- **标题 / 题号**：煎饼排序（#969，medium）
- **链接**：https://leetcode.cn/problems/pancake-sorting/
- **来源**：LeetCode 第 118 场周赛 Q2
- **难度**：中等
- **标签**：贪心、数组、双指针、排序

**题意**：`arr` 是 $1 \sim n$ 的一个排列。一次**煎饼翻转**指：选一个整数 $k$（$1 \le k \le arr.length$），把前缀子数组 `arr[0...k-1]` **整体反转**。

要求返回一串 $k$ 值，按顺序执行这些翻转后 `arr` 升序排列。翻转次数必须不超过 $10 \cdot n$；**答案不唯一**，任何合法序列都算对。

**约束**：

- $1 \le arr.length \le 100$
- $arr$ 中的所有整数**互不相同**（$1 \sim n$ 的排列）

> ⚠️ 这是**构造题**：判题器会真的按你给的 $k$ 序列模拟翻转再检查结果，所以「答案不唯一」意味着不能照抄示例输出，必须自己造一个合法序列。

## 2. 示例

**示例 1**

```text
输入：[3,2,4,1]
输出：[3,4,2,3,2]     （官方给的 [4,2,4,3] 同样正确）
解释（按本解法的序列）：
  k=3 → [4,2,3,1]     把 4 翻到最前面
  k=4 → [1,3,2,4]     再把 4 翻到末尾，最大元归位
  k=2 → [3,1,2,4]     size=3 内最大元 3 翻到最前面
  k=3 → [2,1,3,4]     3 归位到下标 2
  k=2 → [1,2,3,4]     剩下两个元素一次翻转搞定
```

**示例 2**

```text
输入：[1,2,3]
输出：[]
解释：已经有序，不需要任何翻转。
```

**示例 3**

```text
输入：[2,1]
输出：[2]
解释：一次整段翻转即可（k 必须 ≥ 1，所以不能返回空序列）。
```

## 3. 解题思路

### 3.1 暴力思路

把「数组的当前排列」当作状态做 BFS/DFS，每次尝试 $n$ 种 $k$，搜索到升序为止。状态空间是 $n!$，$n = 100$ 时完全不可行——而且这题根本不需要搜索：**每一轮只盯一个元素**就够了。

### 3.2 核心观察：一轮把「当前最大值」摁到末尾

![两次翻转把最大值从中间搬到末尾](images/wc118_q2_pancake_flip.svg)

煎饼翻转只能动**前缀**，所以它天然适合「从后往前归位」：假如未排序部分是 `arr[0...size-1]`，其中的最大值 $M$ 位于下标 $idx$，那么

1. 若 $idx > 0$，翻转 $k = idx + 1$：$M$ 被搬到**下标 0**；
2. 再翻转 $k = size$：$M$ 被搬到**下标 $size - 1$**，正好是它在有序数组里的最终位置。

之后把 `size` 减一，问题规模缩小，最大值再也不会被后面的操作碰到（因为后面所有翻转的 $k \le size-1$，只动前缀）。每轮最多 2 次翻转，$n-1$ 轮共 $2(n-1) < 10n$，稳过次数限制。

### 3.3 算法流程

```text
1. res = []
2. for size = n down to 2:
       idx = 未排序前缀 arr[0...size-1] 中最大值所在下标
       if idx == size - 1: continue          # 已经在位，跳过
       if idx > 0:                            # 只有不在开头才需要先翻到顶
           翻转 arr[0...idx]，res 追加 idx + 1
       翻转 arr[0...size-1]，res 追加 size
3. 返回 res
```

### 3.4 示例演算

![演算：6 个状态、5 次翻转](images/wc118_q2_walkthrough.svg)

以 `[3,2,4,1]` 为例，每轮的最大值、下标与两次翻转效果：

| 轮次 | size | 前缀 | 最大值 / idx | 翻转序列 | 翻转后前缀 |
|---|---|---|---|---|---|
| 1 | 4 | [3,2,4,1] | 4 / 2 | k=3, k=4 | [1,3,2,**4**] |
| 2 | 3 | [1,3,2] | 3 / 1 | k=2, k=3 | [2,1,**3**,4] |
| 3 | 2 | [2,1] | 2 / 0 | k=2 | [**1**,**2**,3,4] |

得到 $k$ 序列 $[3,4,2,3,2]$，共 5 次翻转，远小于 $10 \times 4 = 40$。注意最后一轮 $idx = 0$ 已在开头，跳过第一次翻转，只花 1 次。

## 4. 算法细节

1. **下标 vs 长度**：`idx` 是 0 基下标，翻转长度是 `idx + 1`；这是本题最常见的差一错误。
2. **`idx == size - 1` 直接跳过**：最大值已在末尾，白翻两次纯属浪费配额（虽然不会错，但答案会变长）。
3. **`idx == 0` 时省略第一次翻转**：最大值已在开头，只需一次 $k = size$；这能把最坏次数从 $2(n-1)$ 压到更少。
4. **翻转的区间边界**：C++ 用 `reverse(arr.begin(), arr.begin() + k)`；Python 用切片 `arr[:k] = arr[k-1::-1]`，切片右端是开区间，别写成 `arr[k::-1]`。
5. **原地修改**：题目只要求返回 $k$ 序列，但算法内部必须真的把 `arr` 翻过来，否则下一轮找最大值会找错。
6. **次数配额**：最坏 $2(n-1)$ 次 < $10n$，无需优化；若想更短可对 `idx == 0` 与「已在位」两种情形做剪枝（本解法已做）。

## 5. 正确性证明

**引理 1（一次前缀翻转可以把最大值搬到首或尾）**：设未排序前缀为 $A[0 \dots size-1]$，最大值 $M$ 位于下标 $idx$。

- 若 $idx > 0$，执行 $k = idx + 1$ 的翻转后，$M$ 位于下标 $0$；
- 随后执行 $k = size$ 的翻转后，$M$ 位于下标 $size - 1$。

**证明**：翻转 $k$ 把 $A[0 \dots k-1]$ 逆序映射为 $A'[t] = A[k-1-t]$。对 $k = idx+1$：$t = 0$ 时 $A'[0] = A[idx] = M$，即 $M$ 移到首位。接着对整段 $k = size$ 翻转，此时 $M$ 在首位，逆序后落在下标 $size - 1$。∎

**引理 2（每轮结束时后缀有序且不再被扰动）**：第 $r$ 轮（$size = n - r + 1$）结束后，$A[size-1 \dots n-1]$ 升序且恰为最大的 $n - size + 1$ 个元素；此后所有翻转的 $k \le size - 1$，只作用于前缀 $A[0 \dots size-2]$。

**证明**：对 $r$ 归纳。$r = 1$ 时由引理 1，$M = \max A[0 \dots n-1]$ 落到下标 $n-1$，后缀 $[n-1, n-1]$ 显然有序且为最大元素。设第 $r-1$ 轮后后缀 $A[size \dots n-1]$ 已是最大的若干元素且升序；第 $r$ 轮在 $A[0 \dots size-1]$ 中取最大值，它小于等于后缀中的最小值（后缀元素都更大），因此它就是「剩下元素中的最大值」，由引理 1 落到下标 $size-1$，与后缀拼接后仍升序。轮内翻转的 $k$ 取值为 $idx+1 \le size$ 与 $size$，都不超过当前 $size$，故不触碰下标 $\ge size$ 的后缀；下一轮 $size$ 减一后，翻转 $k \le size-1$，同样不触碰已经归位的部分。∎

**定理**：算法返回的 $k$ 序列能让 `arr` 升序排列，且长度不超过 $10n$。

**证明**：$size$ 从 $n$ 递减到 $2$，共 $n-1$ 轮。由引理 2，每轮把当前最大值放到下标 $size-1$，$n-1$ 轮后下标 $1 \dots n-1$ 都已就位，剩下下标 $0$ 的元素只能是剩下那个最小值，整个数组升序。每轮最多 2 次翻转，总次数 $\le 2(n-1) < 10n$（$n \ge 1$）。∎

## 6. 复杂度分析

- **时间**：$O(n^2)$。$n-1$ 轮，每轮找最大值 $O(size)$、两次翻转各 $O(size)$，求和 $\sum_{size=2}^{n} O(size) = O(n^2)$；$n \le 100$ 时不足 $10^4$ 次操作。
- **空间**：$O(1)$ 额外空间（不计返回的 $k$ 序列，其长度 $O(n)$）；翻转原地进行。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> pancakeSort(vector<int>& arr) {
        vector<int> res;
        for (int size = (int)arr.size(); size > 1; size--) {
            int idx = (int)(max_element(arr.begin(), arr.begin() + size) - arr.begin());
            if (idx == size - 1) continue;           // 已在位
            if (idx > 0) {
                reverse(arr.begin(), arr.begin() + idx + 1);
                res.push_back(idx + 1);
            }
            reverse(arr.begin(), arr.begin() + size);
            res.push_back(size);
        }
        return res;
    }
};
```

### Python

```python
class Solution:
    def pancakeSort(self, arr: list[int]) -> list[int]:
        res = []
        for size in range(len(arr), 1, -1):
            idx = arr.index(max(arr[:size]))
            if idx == size - 1:
                continue
            if idx > 0:
                arr[:idx + 1] = arr[idx::-1]
                res.append(idx + 1)
            arr[:size] = arr[size - 1::-1]
            res.append(size)
        return res
```

## 8. 边界情况与易错点

1. **`n = 1`**：循环 `size > 1` 一次也不进，返回 `[]`——单个元素本来就有序。
2. **已升序**：每轮 `idx == size - 1`，全部跳过，返回 `[]`（示例 2）。
3. **严格降序**：最大值总在开头（`idx = 0`），一次 $k = n$ 的翻转就把整个数组逆成升序，答案长度为 1——这是最快的情形，也说明「翻转次数」对输入形状很敏感。
4. **差一错误**：翻转长度写 `idx + 1`，C++ 的 `reverse` 右端是开区间，Python 切片同理；写成 `idx` 会把最大值漏掉一格。
5. **忘记真的修改 `arr`**：只在 `res` 里记录 $k$ 而不执行翻转，下一轮就会用错的最大值。
6. **判题语义**：本题是 special judge，**不要**按示例输出做字符串比对；提交前可以用「模拟翻转后是否升序、次数是否 $\le 10n$」自检。
7. **`max(arr[:size])` 的拷贝开销**：Python 每轮切片 $O(size)$，总体仍是 $O(n^2)$，$n \le 100$ 无压力。
