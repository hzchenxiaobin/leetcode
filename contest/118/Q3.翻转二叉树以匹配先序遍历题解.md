# LeetCode 翻转二叉树以匹配先序遍历 题解

## 1. 题目概述

- **标题 / 题号**：翻转二叉树以匹配先序遍历（#971，medium）
- **链接**：https://leetcode.cn/problems/flip-binary-tree-to-match-preorder-traversal/
- **来源**：LeetCode 第 118 场周赛 Q3
- **难度**：中等
- **标签**：树、深度优先搜索、二叉树

**题意**：给定二叉树 `root`（$n$ 个节点，值互不相同，取值为 $1 \sim n$）和一个长为 $n$ 的序列 `voyage`，它表示**期望的先序遍历**。允许的操作是：对任意节点**交换其左右子树**（称为翻转该节点）。

请翻转**最少**的节点，使树的先序遍历恰好等于 `voyage`：

- 可以做到，返回所有被翻转节点的**值**（顺序任意）；
- 做不到，返回 `[-1]`。

**约束**：

- $n \ge 1$，$n = voyage.length$
- 树中所有值互不相同，`voyage` 中所有值互不相同
- 节点取值 $1 \le val \le n$

> 💡 **来源**：LeetCode 第 118 场周赛 Q3。

## 2. 示例

**示例 1**

```text
输入：root = [1,2], voyage = [2,1]
输出：[-1]
解释：根节点固定是 1，先序遍历的第一个值必须是 1，而 voyage 以 2 开头，
      无论怎么翻转都不可能匹配。
```

**示例 2**

```text
输入：root = [1,2,3], voyage = [1,3,2]
输出：[1]
解释：翻转节点 1（交换左右子树）后，先序遍历为 1,3,2，匹配成功。
```

**示例 3**

```text
输入：root = [1,2,3], voyage = [1,2,3]
输出：[]
解释：先序已经匹配，不需要任何翻转。
```

**示例 4**

```text
输入：root = [1,2,3,4,5], voyage = [1,2,4,5,3]
输出：[]
解释：节点 2 的左子树先序是 4,5，右子树为空；本就不需要翻转。
```

## 3. 解题思路

### 3.1 暴力思路

共有 $n$ 个节点，每个节点「翻 / 不翻」两种选择，朴素枚举 $2^n$ 种组合，每种组合重新求一次先序（$O(n)$），总复杂度 $O(2^n n)$。$n$ 稍大就爆。而且绝大多数组合在**前两个位置**就露馅了——暴力把「早就能判死的分支」也枚举了一遍。

### 3.2 核心观察：每个节点的翻转决策是被唯一确定的

![先序遍历决定了下一个该是谁，从而唯一确定是否翻转](images/wc118_q3_flip_decision.svg)

先序遍历按「**根 → 左 → 右**」访问。设当前访问到节点 $u$，指针 `idx` 指向 `voyage` 中**下一个待匹配**的位置，那么 `voyage[idx]` 只能是：

- $u$ 的**左孩子**的值（不翻转），或
- $u$ 的**右孩子**的值（翻转后，右子树变成新的左子树）。

因为**所有节点的值互不相同**，`voyage[idx]` 至多与其中一个孩子相等，于是：

| 情况 | 结论 |
|---|---|
| 左孩子存在且 `left->val == voyage[idx]` | **不能翻**（翻了下一个就是右孩子，值不等，必错） |
| 左孩子存在且 `left->val != voyage[idx]` | **必须翻**（下一个只能是右孩子） |
| 无左孩子（`left == null`） | 无需翻转，直接走右子树 |

也就是说——**没有选择，只有判定**。沿先序 DFS 走一遍，每次决策都唯一，走的正是「最少翻转」的那条路。

### 3.3 算法流程

![DFS 判定流程：值不匹配立即失败，左孩子值不匹配则翻转](images/wc118_q3_dfs_walkthrough.svg)

```text
dfs(u):
    if u == null: return true
    if idx >= n 或 u->val != voyage[idx]: return false
    idx += 1                                    # 匹配根
    if u->left != null 且 idx < n 且 u->left->val != voyage[idx]:
        res.append(u->val)                      # 必须翻转
        return dfs(u->right) 且 dfs(u->left)     # 先右后左
    return dfs(u->left) 且 dfs(u->right)         # 不翻转

主函数：
    idx = 0，res = []
    返回 dfs(root) ? res : [-1]
```

关键点：`dfs` 在**进入时**就把 `u->val` 与 `voyage[idx]` 对齐，因此「下一个该是谁」永远由 `voyage[idx]` 给出，判定与递归天然同步。

### 3.4 示例演算

对示例 2（`root = [1,2,3]`，`voyage = [1,3,2]`）走一遍：

| 步骤 | 当前节点 | `idx` | `voyage[idx]` | 左孩子 | 决策 | 结果 |
|---|---|---|---|---|---|---|
| 1 | 1 | 0 | 1 | 2 | `1 == voyage[0]` ✓，`left->val = 2`，而 `voyage[1] = 3` | 必须翻转 → `res = [1]` |
| 2 | 3（翻转后先走右） | 1 | 3 | null | 匹配 ✓ | 无翻转 |
| 3 | 2 | 2 | 2 | null | 匹配 ✓ | 无翻转 |

`idx` 走到 3 结束，`res = [1]`，与示例输出一致。

再对示例 1（`root = [1,2]`，`voyage = [2,1]`）：进入根节点 1，`voyage[0] = 2 ≠ 1`，直接返回 `false` → 输出 `[-1]`。

## 4. 算法细节

1. **`idx` 用成员变量/引用共享**：DFS 是「边走边推进指针」的，指针必须全局唯一；用返回值传下标也行，但共享更简洁（C++ 用成员 `idx`，Python 用 `self.idx`，注意每次调用 `flipMatchVoyage` 要重置）。
2. **先判空再判值**：空节点直接返回 `true`（空树对先序没有贡献），不能去读 `u->val`。
3. **边界保护 `idx < n`**：如果树比 `voyage` 长（或提前耗尽），`voyage[idx]` 会越界；`idx >= voyage.size()` 时直接判 `false`。
4. **翻转后递归顺序**：先 `dfs(u->right)` 再 `dfs(u->left)`——翻转后右子树成为新的「左」，先序里先出现。
5. **短路求值**：`dfs(left) && dfs(right)` 依赖 C++/Python 的短路语义，一旦左子树失败就不再试右子树，天然剪枝。
6. **返回 `[-1]`**：只在整体失败时返回，不能在递归中途返回，否则会丢掉已经做出的翻转记录。

## 5. 正确性证明

**引理 1（下一步唯一）**：设当前节点 $u$ 的左孩子为 $L$、右孩子为 $R$，`voyage[idx]` 是下一个期望值（`idx` 为进入 $u$ 之后的值）。则：

- 若 $L \ne \text{null}$ 且 $L.val = voyage[idx]$，则任何可行方案在 $u$ 上**不能翻转**；
- 若 $L \ne \text{null}$ 且 $L.val \ne voyage[idx]$，则任何可行方案在 $u$ 上**必须翻转**；
- 若 $L = \text{null}$，则翻转与否对先序无影响（右子树无论如何都是下一个）。

**证明**：先序在访问完 $u$ 之后，紧接着访问的是当前「左孩子」子树的根。不翻转时该值是 $L.val$（$L$ 为空则直接是 $R.val$）；翻转后该值是 $R.val$（$R$ 为空时先序仍是 $u, L\ldots$，因为空右子树不产生任何节点）。由于树中所有值互不相同，$L.val \ne R.val$，两种选择在 $R$ 非空时给出不同的下一个值。

- **情形一**：$L.val = voyage[idx]$。不翻转时下一个值恰为期望值；若翻转且 $R$ 非空，下一个值是 $R.val \ne voyage[idx]$，立即失配；若 $R$ 为空，翻转与不翻转产生**完全相同**的先序序列，翻转是多余的。故任何最优方案在 $u$ 上都不翻转。
- **情形二**：$L.val \ne voyage[idx]$。不翻转时下一个值必为 $L.val \ne voyage[idx]$，与期望冲突；若 $R$ 非空，翻转后下一个值为 $R.val$，这是唯一可能匹配的选项，故必须翻转；若 $R$ 为空，翻转后下一个值仍是 $L.val$，依旧冲突，说明本情形无解，由递归返回 `false` 报出。∎

**引理 2（递归失败即无解）**：若 `dfs(u)` 返回 `false`，则任何翻转方案都无法让以 $u$ 为根的子树先序等于 `voyage[idx...]` 这一段。

**证明**：对子树高度归纳。基础情形（$u = \text{null}$）返回 `true`，不产生 `false`。若 $u$ 非空：

- 若 $u.val \ne voyage[idx]$，则任何方案的先序首元素都是 $u.val$，必然不匹配，无解；
- 若值匹配，`idx` 后移一位。由引理 1，翻转决策被唯一确定（或两种选择等价，取不翻）。若按该唯一决策递归后返回 `false`，由归纳假设对应子树无解，而 $u$ 上的决策又是被迫的，故整体无解。∎

**定理**：算法在可行时返回的节点集合恰好是唯一的最小翻转方案，不可行时返回 `[-1]`。

**证明**：唯一性来自引理 1：除「$L$ 为空」这种翻转等价的情形外，每个节点的决策都被 `voyage` 唯一确定；而「$L$ 为空」时翻转不改变任何先序输出，最小方案自然不翻（算法也不翻）。因此可行解至多一个，算法沿这条唯一路径前进，若全程成功就得到了它，故也是最小翻转。不可行时由引理 2，`dfs(root)` 返回 `false`，算法返回 `[-1]`。∎

## 6. 复杂度分析

- **时间**：$O(n)$。每个节点被访问恰好一次（失败的短路只会更少），每次判定 $O(1)$；朴素做法是 $O(2^n n)$，这里把指数降到了线性。
- **空间**：$O(n)$ 最坏（结果数组）+ $O(h)$ 递归栈，$h$ 为树高；链状树 $h = n$，故最坏 $O(n)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> res;
    int idx = 0;

    bool dfs(TreeNode* u, vector<int>& voyage) {
        if (!u) return true;
        if (idx >= (int)voyage.size() || u->val != voyage[idx]) return false;
        idx++;
        if (u->left && idx < (int)voyage.size() && u->left->val != voyage[idx]) {
            res.push_back(u->val);              // 必须翻转
            return dfs(u->right, voyage) && dfs(u->left, voyage);
        }
        return dfs(u->left, voyage) && dfs(u->right, voyage);
    }

    vector<int> flipMatchVoyage(TreeNode* root, vector<int>& voyage) {
        res.clear();
        idx = 0;
        if (dfs(root, voyage)) return res;
        return vector<int>{-1};
    }
};
```

### Python

```python
class Solution:
    def flipMatchVoyage(self, root, voyage: list[int]) -> list[int]:
        self.res = []
        self.idx = 0
        self.voyage = voyage

        def dfs(u) -> bool:
            if u is None:
                return True
            if self.idx >= len(voyage) or u.val != voyage[self.idx]:
                return False
            self.idx += 1
            if u.left and self.idx < len(voyage) and u.left.val != voyage[self.idx]:
                self.res.append(u.val)          # 必须翻转
                return dfs(u.right) and dfs(u.left)
            return dfs(u.left) and dfs(u.right)

        return self.res if dfs(root) else [-1]
```

## 8. 边界情况与易错点

1. **根节点值就必须匹配**：先序第一个值恒为根的值，不匹配立刻 `[-1]`（示例 1）。
2. **空树**：题目保证 $n \ge 1$，但若传入 `null`，`dfs` 返回 `true`、`res` 为空，返回 `[]` 也合理。
3. **只有左孩子 / 只有右孩子**：单孩子节点翻转不影响先序，算法因「`u->left` 是否存在」判断而正确地不翻（`left == null` 时直接走第三分支）。注意不能写成「`u->right` 存在就翻」，那会多翻。
4. **`idx` 越界**：树比 `voyage` 长时不加 `idx < n` 保护会读越界（C++ 未定义行为、Python 抛异常）。
5. **多次调用同一对象**：`res`、`idx` 是成员变量，必须每次进入 `flipMatchVoyage` 时重置，否则上一组用例的残留会污染结果。
6. **翻转后递归顺序写反**：翻转后必须先 `right` 后 `left`，否则 `idx` 的推进顺序与真实先序不一致，会误判为失败。
7. **返回 `[-1]` 而不是空列表**：无解时题目要求返回 `[-1]`，返回 `[]` 会被判错。
8. **「最少」不是「最少次数」的额外优化**：由于决策唯一，不需要排序、不需要回溯，直接一遍 DFS 即可。
