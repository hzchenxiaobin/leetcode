# LeetCode 找到最大开销的子字符串 题解

## 1. 题目概述

- **标题 / 题号**：找到最大开销的子字符串（#2606，medium）
- **链接**：https://leetcode.cn/problems/find-the-substring-with-maximum-cost/
- **来源**：LeetCode 第 101 场双周赛 Q2
- **难度**：中等
- **标签**：数组、哈希表、字符串、动态规划

**题意**：给定字符串 $s$、互不相同的字符集 `chars` 与价值数组 `vals`。每个字符的**价值**定义为：若它不在 `chars` 中，则为它在字母表中的位置（`a` = 1 … `z` = 26）；若它在 `chars` 中下标为 $i$，则为 $vals[i]$。**子字符串的开销**是其所有字符价值之和（空串开销为 0）。求 $s$ 的所有子字符串中的最大开销。

**约束**：

- $1 \le s.length \le 10^5$，$s$ 只含小写字母
- $1 \le chars.length \le 26$，`chars` 只含互不相同的小写字母
- $vals.length = chars.length$
- $-1000 \le vals[i] \le 1000$

## 2. 示例

**示例 1**

```text
输入：s = "adaa", chars = "d", vals = [-1000]
输出：2
解释：'a' 价值 1，'d' 价值 -1000。最大开销子串是 "aa"，开销 1 + 1 = 2。
```

**示例 2**

```text
输入：s = "abc", chars = "abc", vals = [-1,-1,-1]
输出：0
解释：所有字符价值都是 -1，任何非空子串开销为负；取空串，开销 0。
```

**示例 3（边界补充）**

```text
输入：s = "ab", chars = "a", vals = [3]
输出：5
解释：价值数组为 [3, 2]，最优子串是整串 "ab"，开销 3 + 2 = 5。
```

> 💡 注意最优子串可以**整段拼接**：正价值的前缀与后缀都该带上，不要在正价值处习惯性截断。

## 3. 解题思路

### 3.1 暴力思路

把 $s$ 的每个子串开销都算一遍：枚举起点 $O(n)$、枚举终点 $O(n)$、求和 $O(n)$，总计 $O(n^3)$；用前缀和把求和降到 $O(1)$ 也是 $O(n^2)$，在 $n = 10^5$ 下约 $10^{10}$ 次操作，必然超时。优化的方向不在枚举上，而在于**识别出本题的本质**：价值数组上的最大子段和。

### 3.2 核心观察：价值映射 + 最大子段和（Kadane）

![核心观察：先映射成价值数组，再做最大子段和](images/bw101_q2_value_mapping.svg)

第一步是**把字符串翻译成整数数组** $v[0..n-1]$：$v[i] = val(s[i])$，其中不在 `chars` 里的字符价值为字母序。这一步用长度 26 的价值表（哈希表或数组）$O(26)$ 初始化为 $1 \sim 26$，再用 `chars` 与 `vals` 覆盖对应位置即可，$O(|chars|)$。

第二步是经典问题「最大子数组和」（LeetCode 53）：求 $\max_{\text{子段}} \sum v_i$，并允许空子段（答案是 $\max(0, \dots)$，因为空串开销为 0）。Kadane 算法一遍扫描解决：维护"以 $i$ 结尾的最大子段和" $cur$，若前面的累积 $cur < 0$，接上只会拖累后面的子段，不如舍弃——$cur = \max(cur, 0) + v[i]$。

> 💡 本题是典型的"**皮 + 经典内核**"结构：比赛时先花 30 秒把皮剥掉（映射），剩下的就是肌肉记忆。

### 3.3 算法流程（Kadane 状态转移）

![算法流程：一遍扫描的 Kadane 转移](images/bw101_q2_kadane_flow.svg)

```text
1. 建价值表 val[26]：默认 val[c] = c 的字母序（1..26）
   对每个 chars[i]：val[chars[i] - 'a'] = vals[i]      # 覆盖
2. ans = 0, cur = 0                                    # 空串保证答案 ≥ 0
3. 对 s 中每个字符 c（价值 x = val[c]）：
       cur = max(cur, 0) + x        # 负前缀丢弃，从当前字符重新起段
       ans = max(ans, cur)
4. 返回 ans
```

### 3.4 示例演算

![示例演算：adaa 的价值数组与 Kadane 逐步状态](images/bw101_q2_example_walkthrough.svg)

以示例 1（$s = $ `adaa`，价值数组 $v = [1, -1000, 1, 1]$）为例：

| $i$ | 字符 | $v[i]$ | $cur = \max(cur,0) + v[i]$ | $ans$ |
|-----|------|--------|---------------------------|-------|
| 0 | a | 1 | $\max(0,0)+1 = 1$ | 1 |
| 1 | d | $-1000$ | $\max(1,0)-1000 = -999$ | 1 |
| 2 | a | 1 | $\max(-999,0)+1 = 1$（舍弃负前缀） | 1 |
| 3 | a | 1 | $1 + 1 = 2$ | **2** |

答案 2，对应子串 `"aa"`。

以示例 2（$v = [-1,-1,-1]$）为例：$cur$ 始终 $\le -1 < 0$，$ans$ 从未被更新，保持 0，对应空串。✅

## 4. 算法细节

1. **价值表的两段初始化**：先把 26 个字母全部赋成字母序 $1 \sim 26$，再用 `chars`/`vals` 覆盖——顺序不能反，覆盖必须是最后一步。
2. **`max(cur, 0)` 的含义**：等价于"以 $i-1$ 结尾的最优子段若为负，则丢弃前缀、让 $[i, i]$ 单独成段"。这个写法比"分类讨论是否接上"更短且不易错。
3. **答案下界 0**：空串开销为 0，因此 `ans` 初值为 0 且**永不为负**；当所有价值都为负时自然返回 0，不需要任何特判。
4. **取值范围**：$|v[i]| \le 1000$，子段和的量级 $\le 10^5 \times 1000 = 10^8$，`int` 放得下（$< 2^{31}$），但比赛里若把价值范围看错（例如误以为可达 $10^9$）就会犹豫，用 `long long` 累加是最省心的选择。
5. **Python 的映射写法**：用字典推导 `{chr(...): i+1}` 生成默认表，再 `zip(chars, vals)` 覆盖；注意 `chars` 互不相同保证了覆盖无冲突。

## 5. 正确性证明

**引理 1（问题等价）**：设 $v[0..n-1]$ 为按题意映射出的价值数组，则"子字符串开销"恰为"子段和"，所求即 $\max(0, \max_{0 \le l \le r \le n-1} \sum_{i=l}^{r} v[i])$。

**证明**：子字符串与子下标区间一一对应，其开销按定义为区间内价值之和；空串对应空区间，和为 0。∎

**引理 2（Kadane 的最优子结构）**：记 $f(i)$ 为以 $i$ 结尾的**非空**子段的最大和，则 $f(i) = v[i] + \max(f(i-1), 0)$（约定 $f(-1)$ 不存在，即 $i = 0$ 时 $f(0) = v[0]$）。

**证明**：对 $i$ 归纳。$i = 0$ 时唯一非空子段是 $[0,0]$，$f(0) = v[0]$。设结论对 $i-1$ 成立。以 $i$ 结尾的非空子段 $[l, i]$ 分两类：$l = i$ 时和为 $v[i]$；$l < i$ 时和为 $v[i] + \big(\text{以 } i-1 \text{ 结尾、长度} \ge 1 \text{ 的子段和}\big)$，后者最大值即 $f(i-1)$。故 $f(i) = \max(v[i],\; v[i] + f(i-1)) = v[i] + \max(f(i-1), 0)$。∎

**定理**：算法返回 $\max(0, \max_i f(i))$，即所有子字符串开销的最大值。

**证明**：算法中 `cur` 在处理完位置 $i$ 后恰为 $f(i)$：初值 0，且更新式 `cur = max(cur, 0) + v[i]` 与引理 2 一致（归纳：`max(cur,0)` 即 $\max(f(i-1),0)$）。`ans` 为历史 `cur` 的最大值与 0 的较大者，即 $\max(0, \max_{0 \le i \le n-1} f(i))$；而任何子段和都等于某个 $f(i)$（区间 $[l, r]$ 的和 $\le$ 以 $r$ 结尾的最优和 $f(r)$），且最大子段和一定在某个结尾处取到。结合引理 1，算法正确。∎

## 6. 复杂度分析

- **时间**：$O(n + 26)$。建表 $O(26)$（常数），映射与 Kadane 一遍扫描 $O(n)$，$n = |s| \le 10^5$。
- **空间**：$O(26)$（价值表）+ $O(1)$ 滚动变量；不存整个 $v$ 数组，边扫边查表即可（存数组也是 $O(n)$，量级不变）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maximumCostSubstring(string s, string chars, vector<int>& vals) {
        int val[26];
        for (int i = 0; i < 26; ++i) val[i] = i + 1;   // 默认价值 = 字母表位置
        for (int i = 0; i < (int)chars.size(); ++i)
            val[chars[i] - 'a'] = vals[i];             // chars 中字符改用 vals 覆盖
        int ans = 0, cur = 0;                         // 空串开销 0，答案下界 0
        for (char c : s) {
            cur = max(cur, 0) + val[c - 'a'];         // Kadane：负的前缀直接舍弃
            ans = max(ans, cur);
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maximumCostSubstring(self, s: str, chars: str, vals: list[int]) -> int:
        val = {chr(ord('a') + i): i + 1 for i in range(26)}  # 默认价值 = 字母表位置
        for c, v in zip(chars, vals):                        # 指定字符改用 vals
            val[c] = v
        ans = cur = 0                                        # 空串开销 0
        for c in s:
            cur = max(cur, 0) + val[c]                       # Kadane：负前缀舍弃
            ans = max(ans, cur)
        return ans
```

> 💡 两份代码均通过官方示例（`2`、`0`）与自定义边界 `s = "ab", chars = "a", vals = [3]`（输出 5），并与"枚举全部 $O(n^2)$ 个子串"的暴力对拍 3000 组随机数据（C++ 与 Python 双侧交叉核对），`mismatch = 0`。

## 8. 边界情况与易错点

1. **答案可以为 0**：全负价值时返回 0（空串），初值必须是 0 而不是 $-∞$ 或 $v[0]$；用 `ans = max(ans, cur)` 而非 `ans = cur` 起步。
2. **默认价值别记错**：不在 `chars` 中的字符价值是**字母序**（`a` = 1），不是 0，也不是 ASCII 码。
3. **覆盖方向**：先写默认表、再用 `vals` 覆盖；写反会把默认值盖回指定值。
4. **`chars` 为空串？** 约束保证 $|chars| \ge 1$，但即便为空，代码也天然退化为"全部按字母序"的最大子段和，依然正确。
5. **Kadane 变体的边界**：写法 `cur = max(cur + v[i], 0)` 在本题（允许空串、答案下界 0）下与本文写法等价；但换成要求**非空**子段的变体（如 LeetCode 53 的全负数组），它会把"必须选一段"的约束丢掉，必须改用 `ans` 初值为 $-\infty$ 的经典版本——两种写法的适用边界要分清。
6. **大写/非字母字符**：本题 $s$ 只含小写字母，无需防御式检查；若做变体题，映射前需要先检查下标 `c - 'a'` 是否越界。
