# LeetCode 使子数组元素和相等 题解

## 1. 题目概述

- **标题 / 题号**：使子数组元素和相等（#2607，medium）
- **链接**：https://leetcode.cn/problems/make-k-subarray-sums-equal/
- **来源**：LeetCode 第 101 场双周赛 Q3
- **难度**：中等
- **标签**：贪心、数组、数学、数论、排序

**题意**：给定长度为 $n$ 的**循环**整数数组 `arr`（最后一个元素的下一个是第一个元素）与整数 $k$。每次操作可任选一个元素使其值 $+1$ 或 $-1$。要求让**每个长度为 $k$ 的循环子数组**（共有 $n$ 个，分别以每个下标为起点）的元素总和都相等，返回最少操作次数。

**约束**：

- $1 \le k \le n \le 10^5$
- $1 \le arr[i] \le 10^9$

## 2. 示例

**示例 1**

```text
输入：arr = [1,4,1,3], k = 2
输出：1
解释：把下标 1 的元素从 4 改成 3（一次操作），数组变为 [1,3,1,3]，
四个长度为 2 的循环子数组和都是 4。
```

**示例 2**

```text
输入：arr = [2,5,5,7], k = 3
输出：5
解释：下标 0 的 2 加三次到 5，下标 3 的 7 减两次到 5，数组变为 [5,5,5,5]，
四个长度为 3 的循环子数组和都是 15。
```

**示例 3（边界补充）**

```text
输入：arr = [4,1,6], k = 3
输出：0
解释：k = n 时每个"窗口"都是整个数组，条件天然满足，无需任何操作。
```

## 3. 解题思路

### 3.1 暴力思路

最原始的想法是"搜索"：枚举/调整每个元素的最终值使所有窗口和相等，再最小化总操作数——但最终值是整数、无上界，搜索空间无限。一个可行的"正确暴力"是先把**可行终态**刻画出来（见 3.2 的推导：终态 = 按下标 $\bmod\ g$ 分组后每组取常值），再在每组内枚举所有可能的目标值 $t$（取值只需扫过组内最小值到最大值）算代价，$O(n \cdot \text{值域})$。真正的难点不在暴力本身，而在**发现"和相等"到底意味着什么结构**。

### 3.2 核心观察：窗口和相等 ⟺ 数组有周期 $\gcd(n, k)$

![核心观察：循环数组上的相邻窗口只差两个元素](images/bw101_q3_cyclic_windows.svg)

记 $W_i$ 为以下标 $i$ 开头、长度为 $k$ 的循环窗口和。关键一步是把**相邻**窗口作差：

$$W_i - W_{i+1} = \big(a_i + a_{i+1} + \cdots + a_{i+k-1}\big) - \big(a_{i+1} + \cdots + a_{i+k}\big) = a_i - a_{(i+k) \bmod n}$$

于是：

$$\text{所有 } W_i \text{ 相等} \iff W_i = W_{i+1}\ (\forall i) \iff a_i = a_{(i+k) \bmod n}\ (\forall i)$$

即**数组沿"下标 $+k$"的循环跳跃取常值**。下标跳跃 $i \mapsto (i+k) \bmod n$ 的轨道是什么？由裴蜀定理，$\{0, k, 2k, \dots\} \bmod\ n$ 恰是 $\gcd(n, k)$ 的倍数构成的子群，于是轨道就是**模 $g = \gcd(n,k)$ 的同余类**：

$$\text{所有窗口和相等} \iff a_i = a_j \text{ 只要 } i \equiv j \pmod{g},\qquad g = \gcd(n, k)$$

![分组：模 g 同余的下标构成一组，组内取齐](images/bw101_q3_groups.svg)

于是问题裂解为 $g$ 个**互不相关**的子问题：把每个剩余类 $\{a_r, a_{r+g}, a_{r+2g}, \dots\}$ 用最少的 $\pm 1$ 操作改成同一值。这是经典的中位数贪心：组内排序后取**中位数**为目标，代价 $\sum |a_i - \text{mid}|$ 最小。

> 💡 一句话：**条件 ⟹ 周期 $g = \gcd(n,k)$ ⟹ 分 $g$ 组 ⟹ 每组取中位数**。$k = n$ 时 $g = n$，每组只有一个元素，答案自然是 0。

### 3.3 算法流程

```text
1. g = gcd(n, k)
2. 对每个剩余类 r = 0, 1, …, g-1：
       取出 group = [a[r], a[r+g], a[r+2g], …]
       排序，取 mid = group[组内元素数 / 2]        # 中位数
       ans += Σ |x − mid|（对组内每个 x）
3. 返回 ans
```

### 3.4 示例演算

![中位数代价与两个官方示例的演算](images/bw101_q3_median_cost.svg)

**示例 1**（$arr = [1,4,1,3]$，$k=2$）：$g = \gcd(4,2) = 2$。

| 组 | 元素（原顺序） | 排序后 | 中位数 | 代价 |
|----|---------------|--------|--------|------|
| $r=0$（下标 0,2） | $1, 1$ | $[1,1]$ | $1$ | $0$ |
| $r=1$（下标 1,3） | $4, 3$ | $[3,4]$ | $4$ | $|3-4| = 1$ |

总代价 $0 + 1 = 1$。✅（对应官方解释：把 4 改成 3；这里目标是 4、把 3 改成 4 同样花 1 次操作，殊途同归。）

**示例 2**（$arr = [2,5,5,7]$，$k=3$）：$g = \gcd(4,3) = 1$，全表一组：排序 $[2,5,5,7]$，中位数 $= 5$，代价 $3 + 0 + 0 + 2 = 5$。✅

## 4. 算法细节

1. **组的取法**：`for (int i = r; i < n; i += g)` 逐个收集，无需显式下标取模；Python 直接切片 `arr[r::g]`。
2. **中位数取"上中位"还是"下中位"**：偶数个元素时，闭区间 $[\text{sorted}[m-1], \text{sorted}[m]]$ 内任何整数目标代价相同（凸函数平台段），取 `sorted[size/2]` 即可，无需纠结。
3. **目标必须可整实现**：操作是 $\pm 1$，最终值必为整数；中位数本身就是组内已有元素，天然是整数，无四舍五入问题。
4. **组内代价不必真的逐项减中位数再求和吗**：也可以用"前缀和 + 排序后两指针"把每组代价 $O(m)$ 求出，但直接求和已是 $O(m)$，无需优化。
5. **答案类型**：最坏 $n = 10^5$、每个 $|a_i - mid| \le 10^9$，总量级 $10^{14}$，C++ 必须 `long long`（`llabs` 配套），Python 天然大整数。
6. **gcd 的来源**：$g = \gcd(n, k)$ 而不是 $k$ 或 $n/k$；写错成 $k$ 时示例 2（$g=1$ 而非 3）会立刻暴露——它就是最好的反例。
7. **快速选择优化（可选）**：排序总耗时 $O(n \log n)$ 已足够；若卡常可对每组用 `nth_element` / 快速选择求中位数并 $O(m)$ 累计代价，总体 $O(n)$，本题无此必要。

## 5. 正确性证明

**引理 1（窗口和条件的刻画）**：所有循环 $k$ 窗口和相等，当且仅当对每个下标 $i$ 都有 $a_i = a_{(i+k) \bmod n}$。

**证明**：窗口和共 $n$ 个（起点 $0 \sim n-1$），"全部相等"等价于"沿环每相邻一对相等"：$W_i = W_{i+1 \bmod n}$ 对所有 $i$ 成立（$n$ 个等式构成一个环，若相邻全等则传递到全等）。而相邻窗口除首尾外完全重叠，$W_i - W_{i+1} = a_i - a_{(i+k) \bmod n}$，故等式组恰为 $a_i = a_{(i+k) \bmod n}$。∎

**引理 2（轨道 = 模 $g$ 同余类）**：设 $g = \gcd(n,k)$。条件"$a_i = a_{(i+k) \bmod n}\ (\forall i)$"等价于"$a_i = a_j$ 只要 $i \equiv j \pmod{g}$"。

**证明**：考虑映射 $\sigma(i) = (i+k) \bmod n$，它是循环群 $\mathbb{Z}_n$ 上的置换，条件即 $a$ 在 $\sigma$ 的每条轨道上恒定。$\sigma$ 生成的循环子群是 $\{0, k, 2k, \dots\} \bmod\ n$；由裴蜀定理，模 $n$ 下 $k$ 的整数倍全体恰是 $g$ 的倍数全体（$g$ 是可写成 $kx + ny$ 的最小正整数，而 $\{kx + ny\} = \{g z\}$），故该子群为 $\{0, g, 2g, \dots\}$，大小 $n/g$，其陪集恰为模 $g$ 的 $g$ 个同余类。轨道（陪集）内下标互相可达 ⟹ 值相等；不同轨道无约束。∎

**引理 3（中位数最优）**：对整数 $b_1 \le b_2 \le \cdots \le b_m$，$\phi(t) = \sum_{i=1}^{m} |b_i - t|$ 在 $t = b_{\lceil m/2 \rceil}$ 处取到 $\min_{t \in \mathbb{Z}} \phi(t)$；且 $m$ 为偶数时 $[b_{m/2}, b_{m/2+1}]$ 内每个整数都是最优点。

**证明**：$\phi$ 是分段线性凸函数，斜率为"小于 $t$ 的个数减大于 $t$ 的个数"。设 $t$ 与 $t+1$ 之间斜率为 $s(t) = \#\{i: b_i \le t\} - \#\{i: b_i > t\}$。当 $t < b_{\lceil m/2 \rceil}$ 时超过一半的 $b_i > t$，$s(t) < 0$，$\phi$ 下降；当 $t \ge b_{\lceil m/2 \rceil}$ 时 $s(t) > 0$（奇数 $m$）或 $s(t) \ge 0$（偶数 $m$，中位段斜率为 0 的平台），$\phi$ 不降。故最小值恰在中位数处（偶数时为整个平台段）取得；且最优点是组内元素，为整数。∎

**定理**：算法返回最少操作次数。

**证明**：一次操作改变某个 $a_i$ 一单位，总操作次数 $= \sum_i |a'_i - a_i|$，其中 $a'$ 为终态。终态可行 $\iff$ 所有窗口和相等 $\iff$（引理 1、2）$a'$ 在每个模 $g$ 剩余类上取常值 $t_r$。于是

$$\min \sum_i |a'_i - a_i| = \sum_{r=0}^{g-1} \; \min_{t_r \in \mathbb{Z}} \sum_{i \equiv r \ ( \bmod\ g )} |a_i - t_r|$$

各组之间变量不交、约束不交，最小化可分组独立进行；每组内部由引理 3 在中位数处取最优。算法逐组求和，得全局最优。∎

## 6. 复杂度分析

- **时间**：$O(n \log n)$。每组收集 $O(n/g)$、排序合计 $O\big(\sum m_r \log m_r\big) \le O(n \log n)$，代价求和 $O(n)$；求 $g$ 是 $O(\log n)$。若用快速选择代替排序可降到 $O(n)$（本题不必要）。
- **空间**：$O(n/g)$——单组的临时数组（最大组大小 $n/g \le n$）；若把所有组一次性存下也是 $O(n)$。滚动使用单组数组即可。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long makeSubKSumEqual(vector<int>& arr, int k) {
        int n = arr.size(), g = gcd(n, k);         // 组数 = gcd(n, k)
        long long ans = 0;
        vector<int> group;
        for (int r = 0; r < g; ++r) {              // 组 = 下标模 g 同余的元素
            group.clear();
            for (int i = r; i < n; i += g) group.push_back(arr[i]);
            sort(group.begin(), group.end());
            int mid = group[group.size() / 2];     // 组内中位数
            for (int x : group) ans += llabs((long long)x - mid);
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def makeSubKSumEqual(self, arr: list[int], k: int) -> int:
        n = len(arr)
        g = self._gcd(n, k)                       # 组数 = gcd(n, k)
        ans = 0
        for r in range(g):                         # 组 = 下标模 g 同余的元素
            group = sorted(arr[r::g])
            mid = group[len(group) // 2]           # 组内中位数
            ans += sum(abs(x - mid) for x in group)
        return ans

    @staticmethod
    def _gcd(a: int, b: int) -> int:               # 辗转相除
        while b:
            a, b = b, a % b
        return a
```

> 💡 两份代码均通过官方示例（`1`、`5`）与边界 `k = n`（输出 0）。对拍分两层：① 结构层——2 万组随机小数组验证"所有窗口和相等 ⟺ $a_i = a_{i+k}$"这一等价刻画；② 数值层——每组内枚举全部整数目标 $t$ 的暴力与中位数解法对拍 3000 组随机数据（C++ 与 Python 双侧交叉核对），`mismatch = 0`；另以 $n = 10^5$、$k = 7$、$a_i \le 10^9$ 做了压力测试（0.02 秒）。

## 8. 边界情况与易错点

1. **$k = n$ 时答案为 0**：$g = \gcd(n, n) = n$，每组单元素、代价为 0；这也是检验"分组数是 $g$ 而非 $k$"的最好样例。
2. **$k = 1$ 时**：$g = 1$，全表一组取中位数——每个元素单独成窗口，所有窗口和相等即所有元素相等，与直觉一致。
3. **$\gcd$ 写错**：常见笔误是把组数写成 $k$、$n/k$ 或 $\gcd(n, k \bmod n)$ 之外的变体；示例 2（$n=4, k=3, g=1$）能拦住大多数错法。
4. **溢出（C++）**：答案量级 $10^{14}$，必须 `long long` 累加；`abs(x - mid)` 在 `int` 上先相减再取绝对值不会溢出（$\le 10^9$），但转 `long long` 后再取 `llabs` 是更稳的习惯写法。
5. **中位数索引**：`group[size/2]` 是排序后的**上中位**；偶数组取 `size/2 - 1`（下中位）同样正确，代价一致，别在两处取了不同定义又混用。
6. **窗口是"循环"的**：不要按普通数组把窗口数算成 $n - k + 1$ 个；起点有 $n$ 个，引理 1 的推导正依赖于循环结构（否则 $W_0 = W_{n-1+1}$ 不闭合，等价性会多出/缺失约束）。
7. **负数目标合法吗**：操作只有 $\pm 1$、无下界约束，最终值可以越过 $0$ 变负；本题元素 $\ge 1$ 且目标取组内中位数（必为正），不会出现，但变体题里要留意。
