# LeetCode 统计有效后缀排序的数量 II 题解

## 1. 题目概述

- **标题 / 题号**：统计有效后缀排序的数量 II（#4109，hard）
- **链接**：https://leetcode.cn/problems/count-valid-suffix-sorts-ii/
- **来源**：LeetCode 第 527 场周赛 Q4
- **难度**：困难
- **标签**：Z 函数（字符串匹配）、滑动窗口、多重集、计数

**题意**：给定长度为 $n$ 的数组 $\mathrm{nums}$ 与长度为 $m$ 的数组 $\mathrm{target}$（$n \le m$）。对每个下标 $i \in [0, n-1]$，把后缀 $\mathrm{nums}[i..n-1]$ 按**非递增**顺序排序，前缀 $\mathrm{nums}[0..i-1]$ 原样不动，得到数组 $O_i$。返回长度为 $m-n+1$ 的数组 $\mathrm{ans}$，其中 $\mathrm{ans}[k]$ 是满足 $O_i$ 与子数组 $\mathrm{target}[k..k+n-1]$ 逐位相等的下标 $i$ 的数量。

**约束**：

- $1 \le n \le m \le 10^5$ → 窗口数与下标数都是 $10^5$ 量级，二维 $(k, i)$ 判定对数可达 $10^{10}$，必须把逐点判定整体消去
- $1 \le \mathrm{nums}[i], \mathrm{target}[i] \le 10^5$ → 值域有限，频差桶可用；同时保证分隔符取 $0$ 时不会与元素冲突

## 2. 示例

**示例 1**

```text
输入：nums = [2,2,3], target = [2,2,3,2,1,3,2,2]
输出：[1,1,0,0,0,1]
解释：i=0,1,2 依次得到 O = [3,2,2]、[2,3,2]、[2,2,3]。
      k=0 时 O_2 = [2,2,3]；k=1 时 O_1 = [2,3,2]；k=5 时 O_0 = [3,2,2]。
```

**示例 2**

```text
输入：nums = [5,6,5], target = [5,6,5,5,6,5]
输出：[2,1,0,2]
解释：i=0 得 [6,5,5]；i=1、i=2 均得 [5,6,5]。
      k=0 与 k=3 的窗口 [5,6,5] 匹配 2 个；k=1 的 [6,5,5] 匹配 1 个。
```

## 3. 解题思路

### 3.1 暴力思路

最朴素：对每个 $k$、每个 $i$ 单独判定 $O_i$ 是否等于窗口 $W_k$，单次比较 $O(n)$，总计 $O(n^2 m)$。即使预处理出全部 $O_i$（空间 $O(n^2)$ 也不可行），比较仍是 $O(nm)$ 对、每对 $O(n)$。

更聪明的暴力是**继承 Q2 的三条件分解**（见下），对每个窗口 $k$ 反向扫一遍、用频差桶对每个 $i$ 增量判定多重集条件——但单窗仍需 $O(n + V)$（桶要重灌），总计 $O(m \cdot (n + V)) \approx 2 \times 10^{10}$，照样超时。

> ⚠️ 瓶颈本质：多重集条件 $C(k, i)$ 看似是**二维**的——$k$ 定窗口、$i$ 定切分点，每个 $(k, i)$ 都要单独验证。要想线性，必须找到让某一维「塌缩」的结构。

### 3.2 核心观察：匹配前缀内，多重集条件是「常定」的

![核心观察：常定性](images/suffix_sorts_ii_constancy.svg)

固定窗口 $k$，记 $W_k = \mathrm{target}[k..k+n-1]$。与 Q2 完全同构，$O_i = W_k$ 可以分解为三个独立条件（Q2 题解已证）：

- **条件 A（前缀逐位相等）**：$\mathrm{nums}[t] = W_k[t]$ 对一切 $t < i$。设 $m(k)$ 为 $\mathrm{nums}$ 与 $W_k$ 的**首个失配下标**（全等则 $n$），该条件 $\iff i \le m(k)$；
- **条件 B（后缀形状）**：$W_k[i..n-1] = \mathrm{target}[k+i..k+n-1]$ 非递增。设 $s(k)$ 为满足此形状的最小 $i$，该条件 $\iff i \ge s(k)$；
- **条件 C（后缀内容）**：$\mathrm{multiset}(\mathrm{nums}[i..n-1]) = \mathrm{multiset}(W_k[i..n-1])$。

真正的困难在条件 C：它同时依赖 $k$ 和 $i$。而本题的钥匙是下面的**常定性**：

> **固定 $k$，只要 $i$ 落在前缀匹配范围内，条件 C 对所有这样的 $i$ 同真同假。**

原因：若 $i \le i' \le m(k)$，则 $[i, i')$ 整段落在匹配区间内，$\mathrm{nums}[t] = W_k[t]$ 逐位成立，于是两段的多重集 $D = \mathrm{multiset}(\mathrm{nums}[i..i'-1]) = \mathrm{multiset}(W_k[i..i'-1])$ **完全相同**。把后缀多重集拆成「公共段 + 尾巴」：

$$\mathrm{ms}(X[i..n-1]) = \mathrm{ms}(X[i..i'-1]) \uplus \mathrm{ms}(X[i'..n-1])$$

两边同时去掉（或加上）同一个 $D$，相等性显然不变——多重集的**消去律**。

于是条件 C 在整个可行域 $i \le \min(m(k), n-1)$ 上恒等于它在 $i = 0$ 处的实例：

$$C(k, \cdot) \equiv C(k, 0) = \big[\mathrm{multiset}(\mathrm{nums}) = \mathrm{multiset}(W_k)\big]$$

**与 $i$ 彻底无关，只依赖窗口整体**。而「整窗多重集是否等于 $\mathrm{nums}$」正是经典的滑动窗口频差计数（同 438. 找到字符串中所有字母异位词），$O(1)$ 增量判定。

> 💡 一句话：前缀匹配段内，任意两个切分点之间隔着的都是**逐位相等的公共多重集**，加加减减互相抵消——于是「每个 $i$ 的多重集条件」坍缩成「每个窗口的整窗条件」，二维判定塌缩成三个一维扫描。

### 3.3 算法流程

![算法流程](images/suffix_sorts_ii_toolbox.svg)

```text
输入：nums（长 n）、target（长 m），n ≤ m
1. Z 函数：拼接 s = nums ⊕ [0] ⊕ target，计算 z[i] = LCP(s, s[i..])
   → m(k) = z[n+1+k]，即 LCP(nums, target[k..])
2. 一遍扫描 start[e]（target[p..e] 非递增的最小 p）：
   start[0]=0；start[e] = target[e-1] ≥ target[e] ? start[e-1] : e
   → s(k) = max(0, start[k+n-1] − k)
3. 滑窗频差桶：cnt = 窗口内频次 − nums 频次，bad = 非零频差值个数
   → bad(k) = 0 ⟺ multiset(nums) = multiset(W_k)
4. 对 k = 0 … m−n：
   hi = min(m(k), n−1)                    ← 上界取 min，i 至多 n−1
   ans[k] = (bad==0) ? max(0, hi − s(k) + 1) : 0
   滑动窗口：cnt[target[k]]−−，cnt[target[k+n]]++（若未到末尾）
```

| 0 | $[2,2,3]$ | $3 \to 2$ | 2 | ✓ 相同 | $[2,2]$ → 1 个 | 1 |
| 1 | $[2,3,2]$ | $1 \to 1$ | 1 | ✓ 相同 | $[1,1]$ → 1 个 | 1 |
| 2 | $[3,2,1]$ | $0 \to 0$ | 0 | ✗ $\{3,2,1\}$ | $[0,0]$ 非空但被否决 | 0 |
| 3 | $[2,1,3]$ | $1 \to 1$ | 2 | ✗ $\{2,1,3\}$ | $[2,1]$ 空 | 0 |
| 4 | $[1,3,2]$ | $0 \to 0$ | 1 | ✗ $\{1,3,2\}$ | $[1,0]$ 空 | 0 |
| 5 | $[3,2,2]$ | $0 \to 0$ | 0 | ✓ $\{3,2,2\}$ | $[0,0]$ → 1 个 | 1 |

三个窗口各有教学价值：$k=0$ 处 $m(k) = n$ 被 $n-1$ 截断（$i = n$ 的空后缀不存在）；$k=2$ 处区间非空但整窗多重集不同，一票否决；$k=5$ 处 $m(k) = 0$（第一位就失配）却仍有答案——因为 $i = 0$ 时前缀为空、条件 A 天然成立。

## 4. 算法细节

1. **$m(k)$ 用 Z 函数**：拼接 $s = \mathrm{nums} \oplus [0] \oplus \mathrm{target}$，则 $z[n+1+k] = \mathrm{LCP}(s, s[n+1+k..]) = \mathrm{LCP}(\mathrm{nums}, \mathrm{target}[k..])$。分隔符取 $0$——值域下界是 $1$，$0$ 不会出现在两边，保证 LCP 不会把 $\mathrm{target}$ 误接在 $\mathrm{nums}$ 后面。$z[0]$ 本身用不到，无需赋值。
2. **$\mathrm{start}$ 的递推**：$\mathrm{start}[e]$ 是「以 $e$ 结尾的最长非递增段」的左端点。若 $\mathrm{target}[e-1] \ge \mathrm{target}[e]$，段向左延展一格，$\mathrm{start}[e] = \mathrm{start}[e-1]$；否则 $e$ 自成一段，$\mathrm{start}[e] = e$。
3. **$s(k)$ 的来历**：$W_k$ 的后缀 $W_k[i..]$ 就是 $\mathrm{target}[k+i..k+n-1]$，**右端点固定**为 $e = k+n-1$。由 $\mathrm{start}$ 的定义，$\mathrm{target}[a..e]$ 非递增 $\iff a \ge \mathrm{start}[e]$，故形状条件 $\iff k+i \ge \mathrm{start}[k+n-1] \iff i \ge \mathrm{start}[k+n-1] - k$；再与 $i \ge 0$ 取交，$s(k) = \max(0,\ \mathrm{start}[k+n-1] - k)$。
4. **滑窗方向**：维护 $\mathrm{cnt}[v] = $ (窗口内 $v$ 的频次) $-$ ($\mathrm{nums}$ 中 $v$ 的频次)，$\mathrm{bad} = \#\{v : \mathrm{cnt}[v] \ne 0\}$。窗口右移一位：离开的 $\mathrm{target}[k]$ 做 $\mathrm{cnt}{-}{-}$、进入的 $\mathrm{target}[k+n]$ 做 $\mathrm{cnt}{+}{+}$，**先判定再滑动**。方向写反（拿 $\mathrm{cnt} = \mathrm{nums} -$ 窗口却按另一方向更新）会让每个窗口的判定全错。
5. **`add` 封装四种转移**：频差跨越 $0$ 才影响 $\mathrm{bad}$——$0 \to \pm 1$ 时 $\mathrm{bad}{+}{+}$，$\pm 1 \to 0$ 时 $\mathrm{bad}{-}{-}$。一个双向 `add(v, d)` 同时覆盖加减两侧，比手写四个分支更不易错。
6. **上界 $\min(m(k), n-1)$**：$i$ 的取值范围是 $[0, n-1]$（下标），而 $m(k)$ 可以取到 $n$（窗口与 $\mathrm{nums}$ 全等）。忘掉 $\min$ 会把不存在的 $i = n$ 计入，答案恰好多 1——示例 1 的 $k=0$ 就是这个坑。
7. **公式整合**：$\mathrm{ans}[k] = 0$ 若 $\mathrm{bad} \ne 0$；否则 $\max(0, \mathrm{hi} - s(k) + 1)$，其中 $\mathrm{hi} = \min(m(k), n-1)$。区间为空（$\mathrm{hi} < s(k)$）时自然得 0。

## 5. 正确性证明

**引理 1（形状-内容分解）**：对任意序列 $A$，记 $\mathrm{desc}(A)$ 为其非递增排序。对任意序列 $B$：

$$\mathrm{desc}(A) = B \iff B \text{ 非递增} \wedge \mathrm{multiset}(A) = \mathrm{multiset}(B)$$

**证明**：（⇒）$\mathrm{desc}(A)$ 非递增，排序不改变多重集。（⇐）非递增排列是**唯一**的：对非递增序列 $B$ 与阈值 $t$，值 $\ge t$ 的元素恰好占据 $B$ 的一个前缀，故 $B[j] \ge t \iff N_B(t) \ge j+1$，其中 $N_B(t) = \sum_{v \ge t} \#_B(v)$ 只依赖多重集。于是每一位 $B[j] = \max\{t : N_B(t) \ge j+1\}$ 被多重集完全决定，非递增且多重集相同的两个序列逐位相等。∎

**引理 2（前缀保留）**：操作只重排 $\mathrm{nums}[i..n-1]$，故 $O_i = W_k$ 蕴含 $\mathrm{nums}[t] = W_k[t]$ 对一切 $t < i$，即 $i \le m(k)$。

**引理 3（常定性）**：固定 $k$。对任意 $0 \le i \le i' \le \min(m(k),\, n-1)$：

$$\mathrm{ms}(\mathrm{nums}[i..n{-}1]) = \mathrm{ms}(W_k[i..n{-}1]) \iff \mathrm{ms}(\mathrm{nums}[i'..n{-}1]) = \mathrm{ms}(W_k[i'..n{-}1])$$

**证明**：由 $i' \le m(k)$ 知 $\mathrm{nums}[t] = W_k[t]$ 对一切 $t < i'$，特别地对 $t \in [i, i')$ 成立，故两段逐位相等，记公共多重集 $D = \mathrm{ms}(\mathrm{nums}[i..i'-1]) = \mathrm{ms}(W_k[i..i'-1])$。多重集分解满足 $\mathrm{ms}(X[i..n-1]) = \mathrm{ms}(X[i..i'-1]) \uplus \mathrm{ms}(X[i'..n-1])$（不交并），于是

$$\mathrm{ms}(\mathrm{nums}[i..n{-}1]) = \mathrm{ms}(W_k[i..n{-}1]) \iff D \uplus \mathrm{ms}(\mathrm{nums}[i'..n{-}1]) = D \uplus \mathrm{ms}(W_k[i'..n{-}1])$$

多重集在 $\mathbb{N}^{V}$ 向量加法下满足消去律，右式 $\iff \mathrm{ms}(\mathrm{nums}[i'..n-1]) = \mathrm{ms}(W_k[i'..n-1])$。∎

**定理**：对每个 $k$，合法下标集合恰为

$$\{\, i : s(k) \le i \le \min(m(k), n-1) \,\} \quad \text{（当 } \mathrm{multiset}(\mathrm{nums}) = \mathrm{multiset}(W_k) \text{时）}$$

否则为空；从而 $\mathrm{ans}[k] = [\mathrm{bad}(k) = 0] \cdot \max\big(0,\ \min(m(k), n-1) - s(k) + 1\big)$。

**证明**：对 $i \in [0, n-1]$：由引理 2 与引理 1，$O_i = W_k \iff$ 「$i \le m(k)$」 ∧ 「$W_k[i..]$ 非递增」 ∧ 「$C(k, i)$」。前两项分别给出上界 $m(k)$ 与下界 $s(k)$（$s(k)$ 的等价性见 §4 第 3 点：$\mathrm{target}[a..e]$ 非递增 $\iff a \ge \mathrm{start}[e]$，由 $\mathrm{start}$ 是「以 $e$ 结尾的非递增段的最小起点」立得）。若存在任一合法 $i$，则 $i \le \min(m(k), n-1)$，由引理 3，$C(k, i)$ 在整个区间 $[0, \min(m(k), n-1)]$ 上恒等于 $C(k, 0) = [\mathrm{multiset}(\mathrm{nums}) = \mathrm{multiset}(W_k)]$，与具体 $i$ 无关。故当整窗多重集相等时合法集合即上述区间（区间内每个 $i$ 三条件齐备），计数为区间长度；不等时为空。再核对三个组件：Z 函数标准性质给出 $m(k) = \mathrm{LCP}(\mathrm{nums}, \mathrm{target}[k..])$（分隔符 $0$ 不在值域内，前 $n$ 个字符即 $\mathrm{nums}$，故 LCP 截断在 $\mathrm{nums}$ 内部）；$\mathrm{start}$ 递推由归纳保证（$\mathrm{target}[e-1] \ge \mathrm{target}[e]$ 时段向左延展仍非递增，否则任何 $p < e$ 的段都含坏相邻对 $(e-1, e)$）；滑窗 $\mathrm{bad}$ 归纳可得每步恰为当前窗口与 $\mathrm{nums}$ 的频差非零值个数。∎

> 💡 **推论（区间结构）**：合法下标构成连续区间——这正是 Q2 引理 3 的窗口版。Q2 靠它提示「区间两端」的结构，本题更进一步：区间上的多重集条件**常定**，连两端都不用找，整窗判一次即可。

## 6. 复杂度分析

- **时间复杂度**：$O(n + m + V)$，其中 $V = 10^5$ 为值域大小。Z 函数一趟 $O(n+m)$；$\mathrm{start}$ 一趟 $O(m)$；频差桶初始化 $O(n + V)$，$m-n+1$ 次滑动每次 $O(1)$。全程线性，$n = m = 10^5$ 时轻松通过。
- **空间复杂度**：$O(n + m + V)$：拼接串与 Z 数组 $O(n+m)$，频差桶 $O(V)$。若值域无界，桶换成哈希表则为 $O(n+m)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> countSuffix(vector<int>& nums, vector<int>& target) {
        int n = nums.size(), m = target.size();
        vector<int> s;                    // s = nums ⊕ [0] ⊕ target
        s.reserve(n + 1 + m);
        for (int x : nums) s.push_back(x);
        s.push_back(0);                   // 分隔符：值域 ≥ 1，0 安全
        for (int x : target) s.push_back(x);
        int L = s.size();
        vector<int> z(L, 0);              // z[i] = LCP(s, s[i..])
        for (int i = 1, l = 0, r = 0; i < L; i++) {
            if (i < r) z[i] = min(r - i, z[i - l]);
            while (i + z[i] < L && s[z[i]] == s[i + z[i]]) z[i]++;
            if (i + z[i] > r) { l = i; r = i + z[i]; }
        }
        vector<int> start(m);             // start[e] = target[p..e] 非递增的最小 p
        for (int e = 1; e < m; e++)
            start[e] = (target[e - 1] >= target[e]) ? start[e - 1] : e;
        vector<int> cnt(100001, 0);       // cnt = 窗口频次 − nums 频次
        int bad = 0;                      // 频差非零的值个数
        auto add = [&](int v, int d) {
            if (cnt[v] == 0) bad++;       // 0 → ±1
            cnt[v] += d;
            if (cnt[v] == 0) bad--;       // ±1 → 0
        };
        for (int x : nums) add(x, -1);
        for (int i = 0; i < n; i++) add(target[i], +1);
        vector<int> ans(m - n + 1);
        for (int k = 0; k <= m - n; k++) {
            int hi = min(z[n + 1 + k], n - 1);       // i 至多取 n−1
            int sk = max(0, start[k + n - 1] - k);  // 形状下界
            ans[k] = (bad == 0) ? max(0, hi - sk + 1) : 0;
            if (k + n < m) {                         // 先判定，再滑动
                add(target[k], -1);                  // 左端离开
                add(target[k + n], +1);              // 右端进入
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def countSuffix(self, nums: list[int], target: list[int]) -> list[int]:
        n, m = len(nums), len(target)
        s = nums + [0] + target          # 分隔符 0 不在值域内
        L = len(s)
        z = [0] * L
        l = r = 0
        for i in range(1, L):
            if i < r:
                z[i] = min(r - i, z[i - l])
            while i + z[i] < L and s[z[i]] == s[i + z[i]]:
                z[i] += 1
            if i + z[i] > r:
                l, r = i, i + z[i]
        start = [0] * m                   # start[e] = target[p..e] 非递增的最小 p
        for e in range(1, m):
            start[e] = start[e - 1] if target[e - 1] >= target[e] else e
        cnt = [0] * 100001                # cnt = 窗口频次 − nums 频次
        bad = 0
        def add(v: int, d: int) -> None:
            nonlocal bad
            if cnt[v] == 0: bad += 1      # 0 → ±1
            cnt[v] += d
            if cnt[v] == 0: bad -= 1      # ±1 → 0
        for x in nums:
            add(x, -1)
        for i in range(n):
            add(target[i], +1)
        ans = []
        for k in range(m - n + 1):
            hi = min(z[n + 1 + k], n - 1)
            sk = max(0, start[k + n - 1] - k)
            ans.append(max(0, hi - sk + 1) if bad == 0 else 0)
            if k + n < m:                 # 先判定，再滑动
                add(target[k], -1)
                add(target[k + n], +1)
        return ans
```

## 8. 边界情况与易错点

1. **上界必须 $\min(m(k), n-1)$**：窗口与 $\mathrm{nums}$ 全等时 $m(k) = n$，但 $i$ 只取到 $n-1$——$i = n$ 对应空后缀，不存在。忘截断每个全等窗口的答案恰好多 1（示例 1 的 $k=0$ 正好踩中）。
2. **$s(k)$ 要夹 $\max(0, \cdot)$**：非递增段可能从窗口左边界之外延伸进来（$\mathrm{start}[k+n-1] < k$），此时整个窗口非递增，$s(k) = 0$。
3. **Z 函数分隔符**：必须取值域外的值（本题 $0$）。用值域内的数做分隔符，LCP 可能「越过」$\mathrm{nums}$ 边界把窗口误判为全等。
4. **滑窗方向与判定时机**：$\mathrm{cnt}$ 定义为「窗口 − $\mathrm{nums}$」，滑动时**离开**窗口的元素做减、**进入**的做加，且当前窗口的 $\mathrm{bad}$ 判定要在滑动**之前**——先滑后判会把窗口整体错位一格。
5. **$\mathrm{bad}$ 的四种转移**：$0 \to +1$、$+1 \to 0$、$0 \to -1$、$-1 \to 0$ 都要跨越零检测；只维护一侧会让 $\mathrm{bad}$ 虚高、答案系统性偏小。
6. **$m(k) = 0$ 的窗口仍可能有答案**：$i = 0$ 无前缀要求，条件 A 天然成立。别在 $m(k) = 0$ 时提前跳过（示例 1 的 $k=5$ 靠它得分）。
7. **$n = m$ 退化为 Q2**：单窗口、公式与 Q2 的三条件计数完全一致，可用 Q2 的用例交叉验证。
8. **越界与规模**：输出长度 $m - n + 1$；查询 $\mathrm{start}[k+n-1]$、$\mathrm{target}[k+n]$ 前注意 $k+n \le m$ 的边界分支。单个 $\mathrm{ans}[k] \le n \le 10^5$，`int` 足够。
