# LeetCode 统计有效后缀排序的数量 I 题解

## 1. 题目概述

- **标题 / 题号**：统计有效后缀排序的数量 I（#4107，medium）
- **链接**：https://leetcode.cn/problems/count-valid-suffix-sorts-i/
- **来源**：LeetCode 第 527 场周赛 Q2
- **难度**：中等
- **标签**：排序、哈希表、后缀扫描、频差计数

**题意**：给定长度均为 $n$ 的数组 $\mathrm{nums}$ 与 $\mathrm{target}$。对每个下标 $i$，**只**把后缀 $\mathrm{nums}[i..n-1]$ 按**非递增**顺序（从大到小、相等允许）排序，前缀 $\mathrm{nums}[0..i-1]$ 原样不动。统计有多少个下标 $i$ 使操作后的整个数组与 $\mathrm{target}$ 逐位相等。

**约束**：

- $1 \le n = |\mathrm{nums}| = |\mathrm{target}| \le 10^5$ → $O(n^2)$ 必超时，需要线性或线性对数做法
- $1 \le \mathrm{nums}[i], \mathrm{target}[i] \le 10^5$ → 值域只有 $10^5$，允许开桶做频差计数

## 2. 示例

**示例 1**

```text
输入：nums = [1,2,3], target = [3,2,1]
输出：1
解释：i=0 排序后得 [3,2,1]，等于 target；
      i=1 得 [1,3,2]，i=2 得 [1,2,3]，均不相等。
```

**示例 2**

```text
输入：nums = [1,5,6,4,6], target = [1,5,6,6,4]
输出：2
解释：i=2 与 i=3 排序后都得 [1,5,6,6,4]，其余下标不行。
```

**示例 3**

```text
输入：nums = [7,6,8], target = [8,6,7]
输出：0
解释：i=0,1,2 依次得到 [8,7,6]、[7,8,6]、[7,6,8]，都不等于 target。
```

## 3. 解题思路

### 3.1 暴力思路

对每个 $i$：复制一份数组、把后缀排序、与 $\mathrm{target}$ 整体比较，单次 $O(n \log n)$，总计 $O(n^2 \log n)$。即使改成从右往左增量维护「已排序后缀」（每步把 $\mathrm{nums}[i]$ 插入有序序列），单步插入也可能移动 $O(n)$ 个元素，总计仍是 $O(n^2)$。$n = 10^5$ 时两者都不可行。

瓶颈在于：**「排序后的后缀」随 $i$ 整体重算、整体比较**。要想线性，必须把「排序后逐位相等」翻译成一组**随 $i$ 单步变化、可 $O(1)$ 增量维护**的等价条件。

### 3.2 核心观察：前缀 + 形状 + 内容，三个独立条件

![核心观察：三条件分解](images/suffix_sorts_three_conditions.svg)

固定 $i$，操作后的数组是两段拼接：原样的前缀 $\mathrm{nums}[0..i-1]$，加上非递增排序的后缀 $\mathrm{desc}(\mathrm{nums}[i..n-1])$。它逐位等于 $\mathrm{target}$，当且仅当：

- **条件 A（前缀逐位相等）**：前缀不参与排序、原样保留，故必须 $\mathrm{nums}[j] = \mathrm{target}[j]$ 对一切 $j < i$。设 $m$ 为两数组**第一个失配下标**（全程相等则 $m = n$），该条件 $\iff i \le m$——一个关于 $i$ 的上界约束。
- **条件 B（后缀形状）**：$\mathrm{desc}(\mathrm{nums}[i..])$ 天然**非递增**，与之逐位相等的 $\mathrm{target}[i..]$ 也必须非递增。而非递增后缀的后缀仍非递增，故设 $s$ 为 $\mathrm{target}$ **最长非递增后缀**的起点，该条件 $\iff i \ge s$——一个下界约束，可用一个布尔量从右往左传递。
- **条件 C（后缀内容）**：排序只是重排、不改变元素组成，故两后缀的**多重集**（可重集合）必须相同：$\mathrm{multiset}(\mathrm{nums}[i..n-1]) = \mathrm{multiset}(\mathrm{target}[i..n-1])$。

由引理 1（§5），**B ∧ C 恰好等价于「排序后逐位相等」**——非递增序列是其多重集唯一的非递增排列。

条件 C 的**增量维护**是本题的点睛之笔：从 $i+1$ 推进到 $i$ 时，两个多重集各变动一个元素（$\mathrm{nums}[i]$ 放入、$\mathrm{target}[i]$ 取出）。开一个值域桶维护频差

$$\mathrm{cnt}[v] = \big(\mathrm{nums}[i..] \text{ 中 } v \text{ 的个数}\big) - \big(\mathrm{target}[i..] \text{ 中 } v \text{ 的个数}\big)$$

再维护 $\mathrm{bad} = \#\{v : \mathrm{cnt}[v] \ne 0\}$（频差非零的值个数），则每步只动两个桶、$O(1)$ 更新，且

$$\mathrm{bad} = 0 \iff \text{条件 C 成立}$$

> 💡 一句话：排序把「逐位相等」拆成**形状**（非递增）与**内容**（多重集）两个正交条件；前者一个布尔量从右往左传递，后者一个频差桶计数。于是三个条件全部可 $O(1)$ 增量，一趟扫描完成计数。

### 3.3 算法流程

![算法流程](images/suffix_sorts_sweep_flow.svg)

```text
输入：nums, target（长度 n）
1. 正向扫一遍：m ← 第一个 nums[i] ≠ target[i] 的下标（无则 m = n）
2. 反向扫描 i = n−1 … 0，维护频差桶 cnt、失配值数 bad、非递增标志 nonincr（初值 true）：
   a. cnt[nums[i]]++：若 0→1 则 bad++；若 −1→0 则 bad−−
   b. cnt[target[i]]−−：若 0→−1 则 bad++；若 1→0 则 bad−−
   c. 若 i < n−1 且 target[i] < target[i+1]：nonincr ← false
   d. 若 i ≤ m 且 bad = 0 且 nonincr：ans++
3. 返回 ans
```

## 4. 算法细节

1. **m 的计算**：正向一趟即可。两数组完全相等时 $m = n$，前缀条件对**所有** $i$ 成立，答案退化为「$\mathrm{target}$ 非递增后缀中、且多重集匹配的下标数」。
2. **bad 的四种转移**（其余转移不跨越 $0$，bad 不变）：

   | 操作 | 转移 | bad 变化 |
   |---|---|---|
   | $\mathrm{cnt}[\mathrm{nums}[i]]{+}{+}$ | $0 \to 1$ | $+1$ |
   | $\mathrm{cnt}[\mathrm{nums}[i]]{+}{+}$ | $-1 \to 0$ | $-1$ |
   | $\mathrm{cnt}[\mathrm{target}[i]]{-}{-}$ | $0 \to -1$ | $+1$ |
   | $\mathrm{cnt}[\mathrm{target}[i]]{-}{-}$ | $1 \to 0$ | $-1$ |

3. **同值自消与查询时机**：$\mathrm{nums}[i] = \mathrm{target}[i]$ 时一加一减净效果为零，但**中间状态瞬时非零**——判定 $\mathrm{bad} = 0$ 必须放在两步桶更新**之后**，否则会把合法 $i$ 误杀。
4. **nonincr 的边界**：单元素后缀视为非递增，初值为真；比较 $\mathrm{target}[i] < \mathrm{target}[i+1]$ 前先判 $i < n - 1$ 防越界。该标志只会单调地由真变假，从右往左传递 $O(1)$。
5. **桶大小**：值域上界 $10^5$ 且可取到，桶开 $10^5 + 1$；值域无界时（姊妹题 II）改用哈希表或离散化。
6. **答案规模**：至多 $n \le 10^5$，`int` 足够。

## 5. 正确性证明

**引理 1（形状-内容分解）**：对任意序列 $A$，记 $\mathrm{desc}(A)$ 为其非递增排序。对任意序列 $B$：

$$\mathrm{desc}(A) = B \iff B \text{ 非递增} \wedge \mathrm{multiset}(A) = \mathrm{multiset}(B)$$

**证明**：（⇒）$\mathrm{desc}(A)$ 非递增，故与之逐位相等的 $B$ 非递增；排序是元素的重排，多重集不变。（⇐）关键是非递增排列的**唯一性**：对非递增序列 $B$ 与阈值 $t$，值 $\ge t$ 的元素恰好占据 $B$ 的一个前缀，故 $B[j] \ge t \iff N_B(t) \ge j+1$，其中 $N_B(t) = \sum_{v \ge t} \#_B(v)$ 只依赖 $B$ 的多重集。于是每个 $B[j] = \max\{t : N_B(t) \ge j+1\}$ 被多重集完全决定。$\mathrm{desc}(A)$ 与 $B$ 均非递增且多重集相同（都等于 $\mathrm{multiset}(A)$），故逐位相等。∎

**引理 2（前缀保留）**：操作只重排 $\mathrm{nums}[i..n-1]$，因此操作后的数组等于 $\mathrm{target}$ 蕴含 $\mathrm{nums}[j] = \mathrm{target}[j]$ 对一切 $j < i$。

**定理**：算法返回值等于合法下标的个数。

**证明**：对任一 $i$：由引理 2，操作后数组 $= \mathrm{target}$ $\iff$ 「前缀逐位相等」∧「$\mathrm{desc}(\mathrm{nums}[i..]) = \mathrm{target}[i..]$」；由引理 1，后者 $\iff$ 条件 B ∧ C。再核对算法维护的三个量：归纳易证反向扫描处理完下标 $i$ 时，$\mathrm{cnt}[\cdot]$ 恰为两后缀的频差，故 $\mathrm{bad} = 0 \iff$ 条件 C；`nonincr` 为真 $\iff \mathrm{target}[i..]$ 非递增 $\iff$ 条件 B；而 $i \le m$ $\iff$ 前缀逐位相等（$i \le m$ 时前缀下标全在首个失配点之前，$i > m$ 时失配点落在前缀内）。算法恰在三者同时成立时对 $i$ 计数一次，与充要条件一一对应。∎

**引理 3（结构：合法下标构成连续区间）**：若 $i < j$ 均合法，则任意 $k \in [i, j]$ 也合法。

**证明**：① $j$ 合法 $\Rightarrow j \le m$，故 $k < j \le m$，$k$ 的前缀条件成立；② $i$ 合法 $\Rightarrow i \ge s$，故 $k > i \ge s$，$\mathrm{target}[k..]$ 非递增；③ 记 $g(x)$ 为「$\mathrm{multiset}(\mathrm{nums}[x..]) = \mathrm{multiset}(\mathrm{target}[x..])$」。由 $g(i) \wedge g(j)$ 两式相减得 $\mathrm{multiset}(\mathrm{nums}[i..j-1]) = \mathrm{multiset}(\mathrm{target}[i..j-1])$；又 $j \le m$ 使 $[i, j)$ 内逐位相等，其前段 $[i, k)$ 的多重集两边也相等；再相减得 $\mathrm{multiset}(\mathrm{nums}[k..j-1]) = \mathrm{multiset}(\mathrm{target}[k..j-1])$，与 $g(j)$ 合并即 $g(k)$。∎

> 💡 引理 3 本题用不上（一趟全扫已是线性），但它揭示答案集合是**连续区间**——姊妹题 Q4（Hard）值域放大、频差桶失效时，「区间结构 + 单点判定」正是破局方向。

## 6. 复杂度分析

- **时间复杂度**：$O(n + V)$，其中 $V = 10^5$ 为值域大小。正向求 $m$ 一趟 $O(n)$；反向扫描每步 $O(1)$ 共 $O(n)$；频差桶初始化 $O(V)$。
- **空间复杂度**：$O(V)$，即频差桶。若改用哈希表则 $O(n)$，与值域脱钩。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int countSuffix(vector<int>& nums, vector<int>& target) {
        int n = nums.size();
        int m = n;                       // 首个失配下标，无则 n
        for (int i = 0; i < n; i++) {
            if (nums[i] != target[i]) { m = i; break; }
        }
        vector<int> cnt(100001, 0);      // 频差桶：nums 后缀 − target 后缀
        int bad = 0;                     // 频差非零的值个数
        bool nonincr = true;             // target[i..n-1] 非递增？
        int ans = 0;
        for (int i = n - 1; i >= 0; i--) {
            if (++cnt[nums[i]] == 1) bad++;        // 0 → 1
            else if (cnt[nums[i]] == 0) bad--;     // −1 → 0
            if (--cnt[target[i]] == -1) bad++;     // 0 → −1
            else if (cnt[target[i]] == 0) bad--;   // 1 → 0
            if (i + 1 < n && target[i] < target[i + 1]) nonincr = false;
            if (i <= m && bad == 0 && nonincr) ans++;
        }
        return ans;
    }
};
```

### Python

```python
from collections import defaultdict

class Solution:
    def countSuffix(self, nums: list[int], target: list[int]) -> int:
        n = len(nums)
        m = n                             # 首个失配下标，无则 n
        for i in range(n):
            if nums[i] != target[i]:
                m = i
                break
        cnt = defaultdict(int)            # 频差桶
        bad = 0
        nonincr = True
        ans = 0
        for i in range(n - 1, -1, -1):
            cnt[nums[i]] += 1
            if cnt[nums[i]] == 1:         # 0 → 1
                bad += 1
            elif cnt[nums[i]] == 0:       # −1 → 0
                bad -= 1
            cnt[target[i]] -= 1
            if cnt[target[i]] == -1:      # 0 → −1
                bad += 1
            elif cnt[target[i]] == 0:     # 1 → 0
                bad -= 1
            if i + 1 < n and target[i] < target[i + 1]:
                nonincr = False
            if i <= m and bad == 0 and nonincr:
                ans += 1
        return ans
```

## 8. 边界情况与易错点

1. **m 必须初始化为 n**：两数组完全相等时没有失配点，所有 $i$ 的前缀条件都成立；初始化成 $0$ 或 $-1$ 会把答案清零。
2. **bad 的负侧转移**：$\mathrm{cnt}$ 从 $-1 \to 0$ 要 `bad−−`、从 $0 \to -1$ 要 `bad++`。只维护正侧会让 bad 虚高，答案系统性偏小。
3. **判定时机**：$\mathrm{nums}[i] = \mathrm{target}[i]$ 时一加一减自消，但瞬时频差非零——`bad == 0` 的查询必须放在两步桶更新之后。
4. **非递增允许相等**：破坏非递增的判据是严格小于（`target[i] < target[i+1]`），写成 `<=` 会误杀 $[6,6,4]$ 这类合法后缀——示例 2 的 $i=2$ 恰好卡在 $6 \ge 6$ 上。
5. **i = n−1 的越界**：访问 `target[i+1]` 前先判 `i + 1 < n`；单元素后缀视为非递增。
6. **排序方向**：题面是**非递增**（从大到小）而非非递减——示例 1 的 $[1,2,3] \to [3,2,1]$ 可确认，方向写反全盘皆错。
7. **桶容量**：值可以取到 $10^5$，桶大小至少 $10^5 + 1$，否则数组越界。
