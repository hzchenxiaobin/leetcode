# LeetCode 使红色节点连通的最小代价 题解

## 1. 题目概述

- **标题 / 题号**：使红色节点连通的最小代价（#4108，medium）
- **链接**：https://leetcode.cn/problems/minimum-cost-to-make-red-nodes-connected/
- **来源**：LeetCode 第 527 场周赛 Q3
- **难度**：中等
- **标签**：树、树形 DP、DFS、贪心

**题意**：给定一棵 $n$ 个节点的**有根树**（根为 $0$，`edges` 为无向边）与颜色串 $\mathrm{colors}$（`'R'` 红 / `'B'` 蓝）。可以翻转任意节点的颜色，翻转节点 $u$ 的代价等于**以 $u$ 为根的子树的大小** $\mathrm{sz}(u)$。要求翻转后所有红色节点形成**恰好一个连通分量**（没有红色节点也算合法），求最小总代价。

**约束**：

- $1 \le n \le 10^5$ → 必须 $O(n)$ 或 $O(n \log n)$，且**链形树深度可达 $n$**，递归 DFS 有爆栈风险，需迭代
- 代价总和最坏 $\sum_u \mathrm{sz}(u) = O(n^2) \approx 10^{10}$（链形全红）→ **必须 64 位整数**，接口返回 `long long` 也印证了这点

## 2. 示例

输入：n = 3, colors = "RBR", edges = [[0,1],[1,2]]
输出：1
解释：红点 0、2 不连通；把叶节点 2 翻蓝（子树大小 1），
      只剩红点 0，恰好一个连通分量。
```

```

```

**示例 4**

```

## 3. 解题思路

### 3.1 暴力思路

最朴素：枚举每个节点翻或不翻（$2^n$ 种组合），对每种组合检查红色集合是否连通（树上 $k$ 个红点连通 $\iff$ 红红边恰有 $k-1$ 条），取最小代价——指数级，仅用于对拍。

改进的 $O(n^2)$ 做法：先想清楚「最终红色集合 $S$ 只要是空集或连通块即可」（见 3.2 的记账变换），于是**枚举连通块的最高点 $c$**，从 $c$ 出发对 $\mathrm{subtree}(c)$ 做一次 DFS，求「包含 $c$ 的最小权连通块」。单次 $O(n)$，全体 $c$ 共 $O(n^2)$，$n = 10^5$ 时约 $10^{10}$ 次操作，超时。

瓶颈在于：**对每个 $c$ 都重复搜索其子树**，而这些子问题 $\mathrm{subtree}(v) \subset \mathrm{subtree}(c)$ 完美嵌套——这正是自底向上一次 DFS 能解决的结构（3.3）。

### 3.2 核心观察：翻色「记账」——红点记 $-\mathrm{sz}$，蓝点记 $+\mathrm{sz}$

![核心观察：翻色记账模型](images/red_conn_cost_model.svg)

记初始红点集合为 $R_0$，最终红点集合为 $S$。真正被翻转的节点恰是对称差 $R_0 \triangle S$ 中的点，故

$$\mathrm{cost}(S) \;=\; \sum_{u \in R_0 \triangle S} \mathrm{sz}(u) \;=\; \underbrace{\sum_{u \in R_0} \mathrm{sz}(u)}_{\text{base：全翻蓝的账底}} \;+\; \sum_{u \in S} \mathrm{val}(u)$$

其中**记账权值**

$$\mathrm{val}(u) = \begin{cases} -\mathrm{sz}(u), & u \text{ 原本是红（保留} = \text{免付）} \\[2pt] +\mathrm{sz}(u), & u \text{ 原本是蓝（翻红} = \text{再付）} \end{cases}$$

直觉上：先假设把**所有红点全部翻蓝**付一遍账底 $\mathrm{base}$；此后每**保留**一个红点，从账底里**减回** $\mathrm{sz}(u)$；每**新染**一个蓝点，再**加付** $\mathrm{sz}(u)$。

> 💡 一句话：翻转代价是对称的（红→蓝、蓝→红同价），于是「代价」被改写成 $\mathrm{base} + \sum_{u \in S} \mathrm{val}(u)$，**问题变成：在树上选一个（可为空的）连通块 $S$，最小化其 $\mathrm{val}$ 权值和**。空集对应代价 $\mathrm{base}$（全翻蓝）。

### 3.3 算法流程：按最高点分解 + 自底向上一次 DFS

![连通块按最高点分解与递推](images/red_conn_dp_decomposition.svg)

非空连通块 $S$ 有唯一的**最高点** $c$（$S$ 中离根最近的点），且 $S \subseteq \mathrm{subtree}(c)$。$S$ 沿 $c$ 的每个孩子 $v$ 的方向要么不延伸，要么延伸成 $\mathrm{subtree}(v)$ 内一个**包含 $v$ 的连通块**——各分支**独立**、权值可加。于是定义

$$f(c) \;=\; \text{「包含 } c \text{ 且} \subseteq \mathrm{subtree}(c) \text{ 的连通块」的最小 } \mathrm{val} \text{ 和}$$

则有树形递推（$v$ 取遍 $c$ 的孩子，叶子处 $f = \mathrm{val}$）：

$$f(c) \;=\; \mathrm{val}(c) \;+\; \sum_{v} \min\bigl(0,\; f(v)\bigr)$$

$\min(0, \cdot)$ 的含义：某个分支最优块权值为负才「带上」，否则整个分支不要（贡献 $0$）——这是树上连通块权值和问题的标准贪心。最终

$$\boxed{\;\mathrm{ans} \;=\; \mathrm{base} \;+\; \min\Bigl(0,\; \min_{c} f(c)\Bigr)\;}$$

其中 $\min$ 里的 $0$ 对应空集（把红点全翻蓝）。

```text
输入：n, colors, edges
1. 建邻接表，从根 0 迭代 BFS 得 parent[] 与层序 order[]
2. 逆序遍历 order（自底向上）：
   a. f[u] += colors[u]=='R' ? −sz[u] : +sz[u]   （此时 sz[u] 已被孩子累加完整）
   b. 向父亲上交：sz[p] += sz[u]；若 f[u] < 0 则 f[p] += f[u]
3. base ← Σ sz[u]（u 为红点）；ans ← base + min(0, min f)
4. 返回 ans
```

### 3.4 示例演算

![示例演算：七节点树自底向上计算 f](images/red_conn_walkthrough.svg)

以 $n=7$，$\mathrm{colors} = \texttt{BRBRBRR}$，$\mathrm{edges} = [[0,1],[0,2],[1,3],[1,4],[2,5],[2,6]]$（红点 $\{1,3,5,6\}$）为例。自底向上逐点计算：

| $u$ | $\mathrm{sz}$ | $\mathrm{val}$ | $f(u)$ | 说明 |
|---|---|---|---|---|
| 6 | 1 | $-1$ | $-1$ | 叶子 |
| 5 | 1 | $-1$ | $-1$ | 叶子 |
| 4 | 1 | $+1$ | $+1$ | 叶子 |
| 3 | 1 | $-1$ | $-1$ | 叶子 |
| 2 | 3 | $+3$ | $+1$ | $3 + (-1) + (-1)$，负分支全带上仍为正 |
| 1 | 3 | $-3$ | $-4$ | $-3 + (-1) + \min(0,+1)$ |
| 0 | 7 | $+7$ | $+3$ | $+7 + \min(0,-4) + \min(0,+1)$ |

$\mathrm{base} = 3+1+1+1 = 6$，$\min_c f(c) = f(1) = -4$，故 $\mathrm{ans} = 6 - 4 = 2$：从 $c=1$ 出发的最优连通块是 $\{1,3\}$（沿负分支 $v=3$ 延伸、丢弃正分支 $v=4$），对应方案「保留 $\{1,3\}$ 为红，把 $5,6$ 翻蓝」，代价 $1+1=2$。注意 $f(5) = f(6) = -1$ 告诉我们「保 $5$ 单点」或「保 $6$ 单点」也各有 $-1$ 的收益，但 $f(1) = -4$ 更优——**三个红色碎片中整体保留最便宜的一块**。

## 4. 算法细节

1. **建图与定根**：`edges` 是无向边，从 $0$ 迭代 BFS（`order` 边扩展边遍历）求 `parent[]` 与层序；`if (v != parent[u])` 完成无向边的父子定向。
2. **两量合一趟**：逆序遍历 `order` 时，$u$ 的孩子必然先于 $u$ 被处理，因此处理 $u$ 时 `sz[u]` 已累加完整、`f[u]` 已收齐所有孩子上交的 $\min(0, f(v))$，只需再补上自身 $\mathrm{val}(u)$ 并向父亲上交。`sz`、`f` 合并成一趟循环。
3. **`base` 必须在 `sz` 完整后统计**（逆序循环之后），初学者容易在 BFS 后立刻用 `sz[u]=1` 统计而整体算错。
4. **`f` 的语义不含「向父亲延伸」**：$f(c)$ 限制在 $\mathrm{subtree}(c)$ 内，天然禁止连到父亲之上——这保证每个非空 $S$ 恰被其最高点枚举一次，不重不漏。
5. **答案合并**：`ans = base + min(0, *min_element(f))`；`min` 与 $0$ 比较一步完成「空集 vs 最优非空块」的取舍。
6. **溢出**：链形全红时 $\mathrm{base} = \sum_{i}(n-i) \approx n^2/2 \approx 5 \times 10^9 > 2^{31}$，C++ 必须全程 `long long`（接口签名即 `long long`）；Python 无需处理。

## 5. 正确性证明

**引理 1（记账恒等式）**：对任意最终红点集合 $S$，翻转代价 $\mathrm{cost}(S) = \mathrm{base} + \sum_{u \in S} \mathrm{val}(u)$。

**证明**：被翻转的点恰为 $R_0 \triangle S$，故
$\mathrm{cost}(S) = \sum_{R_0 \setminus S} \mathrm{sz} + \sum_{S \setminus R_0} \mathrm{sz} = \bigl(\sum_{R_0} \mathrm{sz} - \sum_{R_0 \cap S} \mathrm{sz}\bigr) + \bigl(\sum_{S} \mathrm{sz} - \sum_{R_0 \cap S} \mathrm{sz}\bigr) = \mathrm{base} + \sum_{u \in S}\bigl(\mathrm{sz}(u) - 2 \cdot \mathrm{sz}(u) \cdot [u \in R_0]\bigr)$，末式括号内即 $\mathrm{val}(u)$。∎

**引理 2（最高点分解）**：任何非空连通集合 $S$ 存在唯一最高点 $c$（$S$ 中深度最小者），且 $S \subseteq \mathrm{subtree}(c)$；对 $c$ 的每个孩子 $v$，$S \cap \mathrm{subtree}(v)$ 或为空，或为**包含 $v$ 的连通块**。

**证明**：树上两点间路径唯一。$S$ 连通 $\Rightarrow$ $S$ 内任一点到 $c$ 的路径全在 $S$ 内；该路径不经过 $c$ 的父亲（否则父亲 $\in S$ 且深度更小，与 $c$ 的最小性矛盾），故 $S \subseteq \mathrm{subtree}(c)$。若 $x \in S \cap \mathrm{subtree}(v)$，则 $x$ 到 $c$ 的路径经过 $v$ 且含于 $S$，故 $v \in S \cap \mathrm{subtree}(v)$ 且该交集继承 $S$ 的连通性。最高点唯一性由深度最小者的唯一性直接得到（深度并列时仍唯一：若 $c' \ne c$ 同为最深最小深度，$c'$ 到 $c$ 的路径上有一点深度更小且属于 $S$，矛盾）。∎

**引理 3（递推正确性）**：$f(c)$ 等于「包含 $c$ 且 $\subseteq \mathrm{subtree}(c)$ 的连通块」的最小 $\mathrm{val}$ 和，且 $f(c) = \mathrm{val}(c) + \sum_v \min(0, f(v))$。

**证明**：对子树高度归纳。$c$ 为叶时唯一候选是 $\{c\}$，$f(c) = \mathrm{val}(c)$，成立。设 $c$ 有孩子 $v_1, \dots, v_k$：任一候选 $S \supseteq \{c\}$，由引理 2 可写 $S = \{c\} \cup \bigcup_i B_i$，$B_i = S \cap \mathrm{subtree}(v_i)$ 为空或含 $v_i$ 的连通块；反之任意这样的拼合都连通、含 $c$ 且 $\subseteq \mathrm{subtree}(c)$。权值可加且各 $B_i$ 取值互不约束，由归纳假设每个分支的最优贡献为 $\min(0, f(v_i))$（为负取最优块 $f(v_i)$，否则取空贡献 $0$）。∎

**定理**：算法返回值 $\mathrm{base} + \min(0, \min_c f(c))$ 等于最小代价。

**证明**：合法的 $S$ 分两类。空集：代价 $\mathrm{base}$，对应式中 $\min$ 的 $0$。非空连通：由引理 2 按 $S$ 的最高点 $c$ 分类，由引理 1 与引理 3，该类最小代价为 $\mathrm{base} + f(c)$；对全体 $c$ 取 $\min$。两类再取 $\min$ 即得。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。迭代 BFS 建序一趟，逆序合并一趟（每条无向边恰好两次邻接访问），统计 `base` 与 `min f` 各一趟，均为线性。
- **空间复杂度**：$O(n)$。邻接表 $O(n)$，`parent / order / sz / f` 各 $O(n)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long minCost(int n, string colors, vector<vector<int>>& edges) {
        vector<vector<int>> adj(n);
        for (auto& e : edges) {
            adj[e[0]].push_back(e[1]);
            adj[e[1]].push_back(e[0]);
        }
        vector<int> parent(n, -1), order;
        order.reserve(n);
        order.push_back(0);
        for (int i = 0; i < (int)order.size(); i++) {   // 迭代 BFS：链形树不爆栈
            int u = order[i];
            for (int v : adj[u]) {
                if (v != parent[u]) {
                    parent[v] = u;
                    order.push_back(v);
                }
            }
        }
        vector<long long> sz(n, 1), f(n, 0);
        for (int i = n - 1; i >= 0; i--) {              // 自底向上：孩子先于父亲
            int u = order[i];
            f[u] += (colors[u] == 'R') ? -sz[u] : sz[u]; // 此时 sz[u] 已完整
            int p = parent[u];
            if (p >= 0) {
                sz[p] += sz[u];
                if (f[u] < 0) f[p] += f[u];              // min(0, f[u]) 上交
            }
        }
        long long base = 0;
        for (int u = 0; u < n; u++)
            if (colors[u] == 'R') base += sz[u];
        long long best = 0;
        for (long long x : f) best = min(best, x);
        return base + best;
    }
};
```

### Python

```python
class Solution:
    def minCost(self, n: int, colors: str, edges: List[List[int]]) -> int:
        adj = [[] for _ in range(n)]
        for u, v in edges:
            adj[u].append(v)
            adj[v].append(u)

        parent = [-1] * n
        order = [0]
        for u in order:                      # 迭代 BFS：链形树也不会爆栈
            for v in adj[u]:
                if v != parent[u]:
                    parent[v] = u
                    order.append(v)

        sz = [1] * n
        f = [0] * n
        for u in reversed(order):            # 自底向上：孩子先于父亲
            f[u] += -sz[u] if colors[u] == 'R' else sz[u]
            p = parent[u]
            if p >= 0:
                sz[p] += sz[u]
                if f[u] < 0:
                    f[p] += f[u]             # min(0, f[u]) 上交

        base = sum(sz[u] for u in range(n) if colors[u] == 'R')
        return base + min(0, min(f))
```

## 8. 边界情况与易错点

1. **64 位整数**：链形全红时 $\mathrm{base} \approx n^2/2 \approx 5 \times 10^9$，`int` 直接溢出；C++ 中 `sz`、`f`、`base` 全部用 `long long`（一个常用 trick 是 `f[u] += ±sz[u]` 处用 `-(long long)sz[u]` 防中途溢出，本题 `sz` 本身已是 `long long` 则无虞）。
2. **爆栈**：$n = 10^5$ 的链形树递归深度 $10^5$，递归 DFS 在 C++/Python 都可能栈溢出，务必迭代 BFS + 逆序合并。
3. **无向边定向**：邻接表里每个邻居都可能是父亲，必须 `v != parent[u]` 过滤；根的 `parent = -1` 天然不被误过滤。
4. **`base` 的统计时机**：必须等逆序循环把 `sz` 累加完整后再统计，提前统计会拿到一堆 $1$。
5. **别忘空集**：`min(0, min f)` 里的 $0$ 对应「全翻蓝」，全部 $f \ge 0$（如全蓝树）时答案就是 $0$ 而不是负数；同时它保证答案非负——代价恒 $\ge 0$，可用作 sanity check。
6. **$n = 1$**：无边，单点红或蓝都合法，答案 $0$；上述代码 `order = [0]`，逆序循环父亲为 $-1$ 自动跳过上交，行为正确。
7. **负号与减号的混淆**：$\mathrm{val}$ 的符号完全由**初始颜色**决定（红 $-\mathrm{sz}$、蓝 $+\mathrm{sz}$），与「最终想不想保留」无关——保留与否是 $\min(0, f)$ 的职责，两层逻辑不要混在一起。
8. **红红连通判据只用于暴力**：树上 $k$ 个点的集合连通 $\iff$ 导出边数恰 $k-1$，对拍时可据此 $O(k)$ 判定，避免再跑 BFS/DFS。
