# LeetCode 找出两个字符串的不匹配片段 题解

## 1. 题目概述

- **标题 / 题号**：找出两个字符串的不匹配片段（#4106，medium）
- **链接**：https://leetcode.cn/problems/find-mismatched-segments-between-two-strings/
- **来源**：LeetCode 第 527 场周赛 Q1
- **难度**：中等
- **标签**：字符串、双指针、分组循环、一次遍历

**题意**：给定两个长度相同的字符串 $s_1$ 与 $s_2$。**不匹配片段**是一个**极大**的连续下标区间 $[l, r]$：区间内每个下标 $s_1$ 与 $s_2$ 的字符都不同，且区间两侧（若存在）不能再扩展（即边界外侧是匹配位）。对每个片段返回 $[\mathrm{sub}_1, \mathrm{sub}_2]$，即 $s_1[l..r]$ 与 $s_2[l..r]$ 这一对子串，按片段起始下标递增排列；若无失配返回空数组。

**约束**：

- $1 \le n = |s_1| = |s_2| \le 100$ → 规模极小，任何做法都能过；但「分组循环」是可迁移的线性模板，值得按 $O(n)$ 沉淀
- 两串仅由小写英文字母组成 → 逐位字符比较即可，无特殊字符处理

## 2. 示例

**示例 1**

```text
输入：s1 = "earth", s2 = "empty"
输出：[["ar","mp"],["h","y"]]
解释：下标 1、2 连续失配（a≠m、r≠p），构成片段 ["ar","mp"]；
      下标 3 匹配（t=t）截断；下标 4 失配（h≠y）且到末端，构成片段 ["h","y"]。
```

**示例 2**

```text
输入：s1 = "action", s2 = "nation"
输出：[["ac","na"]]
解释：下标 0、1 失配构成一个片段；其余位置字符均相同。
```

**示例 3**

```text
输入：s1 = "hot", s2 = "hot"
输出：[]
解释：两个字符串完全相同，没有不匹配片段。
```

## 3. 解题思路

### 3.1 朴素思路：标记数组 + 第二遍切段

最直接的写法分两趟：先扫一遍构造布尔数组 $\mathrm{diff}[i] = (s_1[i] \ne s_2[i])$，再扫一遍把连续 `true` 段 $[l, r]$ 逐个切出、追加 $[s_1[l..r],\ s_2[l..r]]$ 到答案。

两趟共 $O(n)$ 时间、额外 $O(n)$ 空间，对本题 $n \le 100$ 绰绰有余。但标记数组是**多余的中间产物**——失配信息在扫描时当场可得，存下来再读一遍纯属浪费。签到题的目标是把「题面 → 代码」压到最短，顺手沉淀一个不依赖辅助数组的模板。

### 3.2 核心观察：极大失配段「顺次排队出现」

![核心观察：极大失配段](images/wc527_q1_mismatch_segments_concept.svg)

把每个下标的匹配/失配看作红绿两色，**失配下标集合 $D = \{i : s_1[i] \ne s_2[i]\}$ 的极大连续段**就是答案的全部片段——这是一一对应：段内全失配、边界（若在界内）全匹配，恰为「极大性」的定义。

于是得到两个关键性质：

- **起点判定只需局部信息**：$i$ 是某片段左端点 $\iff s_1[i] \ne s_2[i]$ 且（$i = 0$ 或 $s_1[i-1] = s_2[i-1]$）。判定只依赖「当下 + 前一个位置」，无需回看更早的字符。
- **片段互不嵌套、按起点递增出现**：两个相邻极大段之间至少隔一个匹配位。扫完一段后外层指针直接跳到段后，绝不会回头，也不会遗漏。

> 💡 一句话：失配片段像排队一样按起点递增出现——**外层定位失配起点，内层右扩到首个匹配位，收割一段、指针跳到段后**，一趟扫完。这就是「分组循环」（grouping loop）模板的典型形态。

### 3.3 算法流程

![双指针扫描流程](images/wc527_q1_mismatch_segments_flow.svg)

```text
输入：s1, s2（长度 n）
1. ans ← [ ]，i ← 0
2. 当 i < n：
   a. 若 s1[i] ≠ s2[i]：            # 失配起点
      j ← i
      while j < n 且 s1[j] ≠ s2[j]： # 右扩到首个匹配位或末端
         j ← j + 1
      ans 追加 [s1[i:j], s2[i:j]]    # 收割片段 [i, j−1]
      i ← j                          # 跳过整个片段
   b. 否则：i ← i + 1                 # 匹配位逐个前进
3. 返回 ans
```

以示例 1 走一遍（$s_1 = $ `earth`，$s_2 = $ `empty`，$n = 5$）：

| 步 | 指针 | 比对 | 动作 | ans |

| 1 | $i=0$ | $e = e$ | 匹配，$i \to 1$ | $[\ ]$ |
| 2 | $i=1$ | $a \ne m$ | 失配起点，$j \gets 1$ | $[\ ]$ |
| 3 | $j=2$ | $r \ne p$ | 继续扩展，$j \to 3$ | $[\ ]$ |
| 4 | $j=3$ | $t = t$ | 停止，收割 $[1,2]$，$i \gets 3$ | $+$ `["ar","mp"]` |
| 5 | $i=3$ | $t = t$ | 匹配，$i \to 4$ | ⋯ |

| 7 | $j=5$ | $j = n$ | 到末端，收割 $[4,4]$，$i \gets 5$ | $+$ `["h","y"]` |
| 8 | $i=5$ | $i = n$ | 循环结束 | 最终答案 |

## 4. 算法细节

1. **外层定位起点**：理论判定要查「$i=0$ 或 $s_1[i-1] = s_2[i-1]$」，实现里无需显式判断——外层指针只在匹配位上自增（或收割后落在匹配位/末端），**推进规则隐式保证了失配起点处的左邻必是匹配位或越界**。
2. **内层扩展**：$j$ 从 $i$ 出发，`while j < n && s1[j] != s2[j]` 右移。停止时 $j$ 是片段右端点 $+1$（首个匹配位或 $n$）。
3. **切片**：Python 用 `s1[i:j]`（$j$ 可为 $n$，天然安全）；C++ 用 `s1.substr(i, j - i)`——第二个参数是**长度**。
4. **指针回收**：`i = j` 跳过整段而非 `i++`，这是保证每个下标至多进一次内层的关键。
5. **答案顺序**：外层 $i$ 单调不减，片段按起点自然递增，无需排序。

## 5. 正确性证明

**引理 1（片段集合唯一）**：失配下标集 $D$ 的极大连续区间分解唯一，且按左端点递增排列后即题目要求的输出顺序。

**证明**：对 $i \in D$，定义 $\mathrm{seg}(i)$ 为从 $i$ 向两侧极大扩展所得的连续区间（向左到首个匹配位或 $-1$，向右到首个匹配位或 $n$）。对任意 $i < j \in D$：若 $[i, j)$ 内存在匹配位，则 $\mathrm{seg}(i)$ 与 $\mathrm{seg}(j)$ 不相交；否则 $[i, j] \subseteq D$，两侧扩展过程对 $i$ 与 $j$ 完全相同，故 $\mathrm{seg}(i) = \mathrm{seg}(j)$。因此 $\{\mathrm{seg}(i) : i \in D\}$ 中互异的区间两两不交、并为 $D$，且每个都左右极大——即 $D$ 的极大连续段族，由 $D$ 唯一决定。左端点互不相同，排序唯一。∎

**引理 2（循环不变式）**：外层循环每轮开始时，$[0, i)$ 内的失配下标均已按极大段完整收割并输出。

**证明**：对循环轮数归纳。初态 $i = 0$，区间为空，成立。设某轮开始时成立。若 $s_1[i] = s_2[i]$：执行 $i \gets i+1$，$[0, i+1)$ 内失配下标集合不变，仍成立。若 $s_1[i] \ne s_2[i]$：由归纳假设，$i-1$ 已被收割或为匹配位（否则外层不会推进到 $i$），故 $i$ 是一个极大段的左端点；内层扩展到首个匹配位 $j$（或 $j = n$），则 $[i, j-1]$ 内全失配且右端被 $j$ 截断，恰为以 $i$ 为左端点的极大段；收割后 $i \gets j$，$[0, j)$ 内所有失配下标收割完毕，成立。∎

**定理**：算法返回的数组恰为全部不匹配片段，按起始下标递增排列。

**证明**：由引理 2，循环结束时 $[0, n)$ 内全部失配下标被收割；每轮收割的恰是一个极大失配段（引理 2 内层论证）；外层 $i$ 单调不减，故输出按左端点递增。由引理 1，极大失配段族唯一，故输出集合与顺序均与题目要求一致，且每段格式 $[s_1[l..r],\ s_2[l..r]]$ 与定义吻合。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。外层 $i$ 与内层 $j$ 都单调向右且从不回退，视作同一前进方向的两个游标：每个下标至多被外层判一次、内层扫一次，共 $O(1)$ 次访问。切片与追加的总量不超过输出体积 $O(n)$。
- **空间复杂度**：$O(1)$（不计输出）。相比朴素标记数组省掉 $O(n)$ 辅助空间；输出本身片段数至多 $\lceil n/2 \rceil$（相邻片段至少隔一个匹配位）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<vector<string>> findMismatchedSegments(string s1, string s2) {
        int n = s1.size();
        vector<vector<string>> ans;
        int i = 0;
        while (i < n) {
            if (s1[i] != s2[i]) {              // 失配起点
                int j = i;
                while (j < n && s1[j] != s2[j]) j++;
                ans.push_back({s1.substr(i, j - i), s2.substr(i, j - i)});
                i = j;                          // 跳过整个片段
            } else {
                i++;
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def findMismatchedSegments(self, s1: str, s2: str) -> list[list[str]]:
        n = len(s1)
        ans = []
        i = 0
        while i < n:
            if s1[i] != s2[i]:                 # 失配起点
                j = i
                while j < n and s1[j] != s2[j]:
                    j += 1
                ans.append([s1[i:j], s2[i:j]])
                i = j                          # 跳过整个片段
            else:
                i += 1
        return ans
```

## 8. 边界情况与易错点

1. **完全相等**：返回 `[]`（示例 3）。外层一路 `i++` 自然结束，无需特判。
2. **全部失配**：整个 $[0, n-1]$ 是一个极大段，输出一对完整字符串——别按单下标拆开。
3. **「极大」的两个踩法**：
   - **拆小**：把每个失配位单独输出（如把 `["ar","mp"]` 拆成 `["a","m"]` 与 `["r","p"]`）→ 违反极大性；
   - **拼大**：把中间只隔一个匹配位的两段合并（如把 $[1,2]$ 与 $[4,4]$ 拼成 $[1,4]$）→ 区间内混入匹配位 $t = t$，违反「每个下标处都不同」。
4. **C++ `substr` 语义**：第二参是**长度**，`s1.substr(i, j - i)` 正确；误写成 `substr(i, j)`（右端点语义）当 $i > 0$ 时会多切字符，且越界行为易错。
5. **顺序保证**：按起始下标递增输出——扫描顺序天然有序，切勿再排序或用无序结构收集。
6. **单字符串**（$n = 1$）：失配时返回 `[["x","y"]]`，匹配时返回 `[]`，模板无需改动。
7. **同段子串等长**：$|s_1| = |s_2|$ 由题面保证，故每对 $\mathrm{sub}_1, \mathrm{sub}_2$ 长度必然相同，无需长度校验。
