# LeetCode 七进制数 题解

## 1. 题目概述

- **标题 / 题号**：七进制数（#504，easy）
- **链接**：https://leetcode.cn/problems/base-7/
- **来源**：LeetCode 第 19 场周赛 Q1
- **难度**：简单
- **标签**：数学、字符串

**题意**：给定一个整数 $\text{num}$，把它转换成 $7$ 进制，并以字符串形式返回。负数的结果需要在最前面带一个 `'-'`，$0$ 的结果是 `"0"`。返回串不含前导零，每一位取值 $0 \sim 6$。

**约束**：

- $-10^7 \le \text{num} \le 10^7$
- 返回值是字符串：负数带 `'-'` 前缀，$0$ 返回 `"0"`，无前导零

> 💡 本题是「进制转换」类问题的母题：函数体需手写短除法，多数语言并没有内置的 7 进制转换可用。

## 2. 示例

**示例 1**

```text
输入：num = 100
输出："202"
解释：2 × 7² + 0 × 7¹ + 2 × 7⁰ = 98 + 0 + 2 = 100。
```

**示例 2**

```text
输入：num = -7
输出："-10"
解释：|-7| = 7 = 1 × 7¹ + 0 × 7⁰，正数部分为 "10"，再补负号。
```

**示例 3**（补充边界，非官方用例）

```text
输入：num = 0
输出："0"
解释：0 无法用「循环取余」产出任何一位，必须单独返回 "0"，不能返回空串。
```

## 3. 解题思路

### 3.1 暴力思路

两种朴素做法都能过本题，但都没有抓住数值与位权的结构：

1. **枚举所有候选串**：按长度从小到大枚举由 `'0'~'6'` 组成的串，逐个按位权求值并与 $|\text{num}|$ 比较。长度为 $L$ 的串有 $6\cdot 7^{L-1}$ 个，而 $L \approx \log_7 |\text{num}|$，候选总数 $\sum_{L} 6\cdot 7^{L-1} = 7^{9}-1 \approx 4\times 10^7$（本题上界），每个候选还要 $O(L)$ 求值，虽勉强能过，但完全浪费了「每一位独立确定」这一信息。
2. **从 $7$ 的幂试位**：先找最大的满足 $7^k \le |\text{num}|$ 的 $k$，然后每一位从 $6$ 往下试减，复杂度 $O(\log^2 |\text{num}|)$。这已经接近正解，但每位都要重复试错。

正解只用一个恒等式 $n = 7q + r$，把「试位」变成「直接算」，复杂度降到 $O(\log |\text{num}|)$，且位数与数值无关地逐步剥离。

### 3.2 核心观察：短除法（除 7 取余，逆序拼接）

![短除法：除 7 取余，余数从低位到高位](images/wc19_q1_short_division.svg)

设 $n \ge 0$ 的 7 进制表示为

$$n = \sum_{i=0}^{m} d_i \, 7^i, \qquad d_i \in \{0,1,\dots,6\},\; d_m \ne 0$$

对它做一次带余除法 $n = 7q + r$（$0 \le r < 7$），对比两边的个位（常数项）可知 $r = d_0$，即**余数就是最低位**；而商

$$q = \sum_{i=1}^{m} d_i \, 7^{\,i-1} = d_1 + d_2 \cdot 7 + \cdots + d_m \cdot 7^{m-1}$$

恰好是「把最低位砍掉」后剩下的数。于是对 $q$ 重复同样的动作，就能依次得到 $d_1, d_2, \dots$，直到商为 $0$。

> 💡 关键点：短除法**先产出低位、后产出高位**，因此收集到的数字序列是反的，最后必须整体反转（或改用头插，但字符串头插是 $O(L)$ 一次，代价更高）。

### 3.3 算法流程

![算法流程：特判 0、符号外提、短除、反转](images/wc19_q1_algorithm_flow.svg)

1. 若 $\text{num} = 0$，直接返回 `"0"`（否则循环一次都不执行，会返回空串）。
2. 记录符号 $\text{neg} = [\text{num} < 0]$，令 $n = |\text{num}|$，并准备一个空的结果序列。
3. 当 $n > 0$ 时循环：把 $n \bmod 7$ 对应的字符追加进序列，再令 $n \leftarrow \lfloor n/7 \rfloor$。
4. 循环结束后若 $\text{neg}$ 为真，在序列末尾追加 `'-'`（反转后它会跑到最前面）。
5. 反转整个序列并返回。

### 3.4 示例演算

![示例演算：100 → "202"，-7 → "-10"，0 → "0"](images/wc19_q1_example_walkthrough.svg)

对 $\text{num} = 100$：

| 轮次 | $n$ | $n \div 7$ | 商 $q$ | 余数 $r$ |
|------|-----|------------|--------|----------|
| 1 | 100 | 14 … 2 | 14 | 2（最低位） |
| 2 | 14 | 2 … 0 | 2 | 0 |
| 3 | 2 | 0 … 2 | 0 | 2（最高位） |

余数序列为 $2,0,2$（低位在前），反转后得到 `"202"`；验证 $2 \times 49 + 0 \times 7 + 2 = 100$。

对 $\text{num} = -7$：取绝对值 $7$，两轮得到余数 $0, 1$，反转得 `"10"`，再补负号得 `"-10"`。

## 4. 算法细节

1. **零必须特判**：`while (n)` 在 $n = 0$ 时一次都不进，若不特判就返回空串，而正确答案是 `"0"`。这是本题唯一的高频 WA 点。
2. **符号外提，不要对负数取模**：C++/Java/Go 的 `%` 向零截断（`-100 % 7 == -2`），会直接产出负数字符；Python 的 `%` 则返回非负（`-100 % 7 == 5`）。同一套逻辑跨语言移植时会分叉，统一「先取绝对值、只对非负数做短除」最稳。
3. **绝对值用宽类型**：`-2^31` 取反会溢出 `int`，写成 `-(long long)num` 或先转 `long long`。本题 $|\text{num}| \le 10^7$ 不会触发，但模板应通用；Python 整数任意精度，无此问题。
4. **低位先出，末尾补负号再反转**：把 `'-'` 追加在数字序列尾部，`reverse` 之后它自然落在首位，省去一次头插。
5. **字符转换**：C++ 用 `char('0' + r)` 比 `to_string(r)` 少一次分配；Python 用 `str(r)` 即可，再 `"".join(...)` 一次性拼接，避免循环里反复 `s += d`。
6. **位数上界**：$|\text{num}| \le 10^7 < 7^9 = 40\,353\,607$，所以答案最多 $9$ 位（$10^7$ 的 7 进制是 9 位数），缓冲开 $16$ 足够；递归写法栈深也只有 $9$。

## 5. 正确性证明

**引理 1（余数即最低位）**：设 $n \ge 0$ 的 7 进制表示为 $n = \sum_{i=0}^{m} d_i 7^i$，$d_i \in [0,6]$。若 $n = 7q + r$ 且 $0 \le r < 7$，则 $r = d_0$，且 $q = \sum_{i=1}^{m} d_i 7^{i-1}$。

**证明**：代入得 $r = d_0 + 7\bigl(\sum_{i \ge 1} d_i 7^{i-1} - q\bigr)$，故 $r \equiv d_0 \pmod 7$。又 $0 \le r < 7$ 且 $0 \le d_0 \le 6$，区间内同余的两个数必相等，所以 $r = d_0$。代回原式得 $q = \sum_{i \ge 1} d_i 7^{i-1}$，正是去掉最低位后的值。∎

**引理 2（迭代不变量）**：设 $n_0 = |\text{num}| > 0$。第 $k$ 轮循环开始时（$k = 0,1,\dots$），剩余值 $n = \lfloor n_0 / 7^k \rfloor$，且已收集的序列恰为 $n_0$ 的 7 进制表示的低 $k$ 位（低位在前）。

**证明**：对 $k$ 归纳。$k = 0$ 时 $n = n_0$、序列为空，成立。设 $k$ 时成立，本轮由引理 1（对 $n = \lfloor n_0/7^k \rfloor$ 使用）得到余数正是 $n$ 的最低位，也就是 $n_0$ 的第 $k$ 位，序列长度加一；下一轮剩余 $\lfloor n/7 \rfloor = \lfloor n_0 / 7^{k+1} \rfloor$。不变量保持。∎

**引理 3（终止与轮数）**：$n_0 > 0$ 时循环恰好执行 $L = \lfloor \log_7 n_0 \rfloor + 1$ 轮。

**证明**：由 $L$ 的定义有 $7^{L-1} \le n_0 < 7^{L}$。第 $k$ 轮前剩余 $\lfloor n_0/7^k \rfloor$：当 $k = L$ 时该值为 $0$（因 $n_0 < 7^L$），循环结束；当 $k < L$ 时该值 $\ge 1$（因 $n_0 \ge 7^{L-1}$），循环继续。故恰好 $L$ 轮。∎

**定理**：算法返回的字符串是 $\text{num}$ 的 7 进制表示，且是唯一的规范表示（各位在 $0\sim6$、无前导零、负数带 `'-'`）。

**证明**：设 $n_0 = |\text{num}|$。

- 若 $n_0 = 0$，特判返回 `"0"`，正确。
- 若 $n_0 > 0$：由引理 2、3，循环产出长度 $L$ 的低位在前序列，反转后为 $d_{L-1}\cdots d_0$，其值等于 $n_0$；最高位 $d_{L-1} = \lfloor n_0/7^{L-1} \rfloor \ge 1$，故无前导零。符号由 $\text{neg}$ 补上，得到 $\text{num}$ 的表示。
- 唯一性：设有两个仅由 $0\sim6$ 组成、无前导零且等值的串，取最高位起第一个不同的位置 $j$，两串在该位至少相差 $1$，即数值差 $\ge 7^j$；而更低的所有位最多贡献 $\sum_{i<j} 6 \cdot 7^i = 7^j - 1 < 7^j$，矛盾，故两串相同。∎

## 6. 复杂度分析

- **时间**：$O(\log_7 |\text{num}|)$。循环 $L = \lfloor \log_7|\text{num}| \rfloor + 1 \le 9$ 轮，每轮一次取余、一次整除，均为 $O(1)$；最后反转（或用 `reversed` 拼接）$O(L)$。
- **空间**：$O(L)$，用于存放结果序列，$L \le 9$；若不计返回值，额外空间 $O(1)$（迭代版）。递归写法另需 $O(L)$ 的调用栈。

## 7. 参考代码

### C++

```cpp
#include <string>
#include <algorithm>
using namespace std;

class Solution {
public:
    string convertToBase7(int num) {
        if (num == 0) return "0";                     // 0 必须特判，否则循环不执行会返回空串
        bool neg = num < 0;                           // 符号外提，只对非负数做短除
        long long n = neg ? -(long long)num : num;    // 先转 long long 再取反，规避 INT_MIN 溢出
        string res;
        while (n > 0) {
            res.push_back(char('0' + n % 7));         // 余数即最低位，先入串（低位在前）
            n /= 7;
        }
        if (neg) res.push_back('-');                  // 负号放尾部，反转后自然落到首位
        reverse(res.begin(), res.end());              // 整体反转，得到高位在前
        return res;
    }
};
```

### Python

```python
class Solution:
    def convertToBase7(self, num: int) -> str:
        if num == 0:
            return "0"                      # 唯一一个循环不会执行的情况
        neg = num < 0
        n = -num if neg else num            # Python 整数任意精度，取反不会溢出
        digits = []
        while n:
            digits.append(str(n % 7))       # 低位先出
            n //= 7                         # 整除，商作为下一轮的 n
        return ("-" if neg else "") + "".join(reversed(digits))
```

## 8. 边界情况与易错点

1. **`num = 0`**：必须返回 `"0"`。若只写 `while (n)` 而不特判，会返回空串，这是本题最常见的错误。
2. **负数取模语义不同**：C++ 中 `-100 % 7 == -2`，直接转字符会得到错误符号；必须先取绝对值。Python 的 `%` 返回非负，看似「没问题」，但把结论搬到 C++ 就会踩坑，务必在思维上区分「取模」与「数学上的最小非负余数」。
3. **`INT_MIN` 取反溢出**：`-(-2147483648)` 在 `int` 上是未定义行为。本题 $|\text{num}| \le 10^7$ 不会遇到，但作为进制转换模板，应统一提升到 `long long`。
4. **忘记反转**：短除法得到的是「低位在前」的镜像串。$100$ 恰好是回文，看不出问题；换成 $99$ 就会把 `"201"` 错写成 `"102"`。
5. **负号位置**：把 `'-'` 追加在数字序列尾部再统一反转，比手动拼 `"-" + 结果` 少一次字符串拼接；注意不要反过来先补负号再反转，那会把负号翻到末尾。
6. **不要依赖库函数**：C++17 的 `std::to_chars(buf, buf+n, num, 7)` 确实支持 $2\sim36$ 进制且会带负号，但负基数（如 1017 的 $-2$）它就无能为力了；面试与通用模板仍应手写短除法，把「除 $k$ 取余 + 反转」的骨架握在手里。Python 的 `int(s, 7)` 只能解析、不能输出。
