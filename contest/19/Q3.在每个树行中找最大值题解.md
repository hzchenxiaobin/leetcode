# LeetCode 在每个树行中找最大值 题解

## 1. 题目概述

- **标题 / 题号**：在每个树行中找最大值（#515，medium）
- **链接**：https://leetcode.cn/problems/find-largest-value-in-each-tree-row/
- **来源**：LeetCode 第 19 场周赛 Q3
- **难度**：中等
- **标签**：树、二叉树、广度优先搜索、深度优先搜索

**题意**：给定一棵二叉树的根节点 `root`，返回一个数组，其中第 $k$ 项是这棵树**第 $k$ 层**（根为第 0 层）所有节点值的**最大值**。若树为空，返回空数组。

**约束**：

- 节点个数在 $[0, 10^4]$ 内
- $-2^{31} \le \text{Node.val} \le 2^{31} - 1$，即节点值**可能全为负数**，也可能取到 `INT_MIN` / `INT_MAX`
- 返回值长度等于树高，而不是 $2^{h}$ 这种「完全二叉树宽度」

## 2. 示例

**示例 1**

```text
输入：root = [1,3,2,5,3,null,9]
              1
             / \
            3   2
           / \   \
          5   3   9
输出：[1,3,9]
解释：
  第 0 层：{1}        → max = 1
  第 1 层：{3, 2}     → max = 3
  第 2 层：{5, 3, 9}  → max = 9
```

**示例 2**

```text
输入：root = [1,2,3]
        1
       / \
      2   3
输出：[1,3]
解释：第 0 层 max = 1；第 1 层 max = max(2,3) = 3。
```

**示例 3（补充用例，非官方，用于覆盖负数边界）**

```text
输入：root = [-1,-2,-3,-4,null,null,-5]
           -1
          /  \
        -2    -3
        /       \
      -4        -5
输出：[-1,-2,-4]
解释：若把 best 的初值写成 0，答案会退化成 [0,0,0]，
      这是本题最常见的错误。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的想法：先求树高 $H$，再对每个深度 $d = 0,1,\dots,H-1$ 做一次 DFS，收集所有深度为 $d$ 的节点取最大值。

- 每求一层就要完整遍历一次树，时间 $O(nH)$；
- 最坏情况是长度为 $10^4$ 的链，$H = n$，复杂度退化为 $O(n^2) = 10^8$，并且大量重复访问；
- 另一种「两次遍历」写法：先用 DFS 记录每个节点的深度存进数组，再对每个深度求最大值。时间 $O(n)$，但需要额外保存 $O(n)$ 个 `(depth, val)` 对，且要处理「深度 → 下标」的映射。

**瓶颈在于**：反复确认「这个节点属于哪一层」。如果让遍历顺序本身就把层分好，就不需要额外结构了。

### 3.2 核心观察：BFS 队列天然按层分段

![BFS 队列天然按层分段](images/wc19_q3_level_bfs_concept.svg)

用队列做广度优先搜索时，节点是**严格按深度非降**出队的：深度 $d$ 的节点全部出完，才会轮到深度 $d+1$。于是在每次外层循环开始时，队列里**只剩同一层**的节点，`len(q)` 恰好就是这一层的节点个数。

由此得到「快照切层」技巧：

1. 进入外层循环后先取 $sz = \lvert q \rvert$，此后**不再重新读取**队列长度；
2. 连续出队 $sz$ 次，这 $sz$ 个节点就是当前层全部节点；
3. 这期间新压入的孩子深度都是 $d+1$，被排在队尾，绝不会混进这 $sz$ 次出队中。

于是「分层」这件事由循环结构本身保证，不需要层标记、不需要 $(node, depth)$ 二元组，也不需要深度数组。

### 3.3 算法流程

![按层 BFS 算法流程](images/wc19_q3_bfs_flow.svg)

```text
ans ← []
若 root 为空：返回 ans
q ← [root]
当 q 非空：
    sz   ← len(q)              # 快照，本层节点数
    best ← −∞                  # 不能用 0
    重复 sz 次：
        node ← q.pop_front()
        best ← max(best, node.val)
        若 node.left  非空：q.push_back(node.left)
        若 node.right 非空：q.push_back(node.right)
    ans.push_back(best)        # 本层答案落盘
返回 ans
```

关键的三个不变量：**出队顺序按层非降**、**每轮队列同层**、**孩子总是排到队尾**。三者共同保证「$sz$ 次出队 = 一整层」。

### 3.4 示例演算

![示例演算：root = [1,3,2,5,3,null,9]](images/wc19_q3_walkthrough.svg)

| 轮次 $k$ | 进入循环时队列 | $sz$ | 出队序列 | `best` 变化 | 答案 |
|----------|----------------|------|----------|-------------|------|
| 0 | `[1]` | 1 | 1 | $-\infty \to 1$ | `[1]` |
| 1 | `[3, 2]` | 2 | 3, 2 | $-\infty \to 3 \to 3$ | `[1, 3]` |
| 2 | `[5, 3, 9]` | 3 | 5, 3, 9 | $-\infty \to 5 \to 5 \to 9$ | `[1, 3, 9]` |

第 2 轮的三个节点是连续三次出队（图中的 `#4`、`#5`、`#6`），中间没有插入上层节点，这正是「快照切层」的直接体现。第 2 轮结束时队列为空，循环终止。

## 4. 算法细节

1. **`best` 的初值必须是 $-\infty$（`INT_MIN` / `float('-inf')`）**，不能是 0。节点值可以全为负，写 0 会让每一层答案都被 0 顶替。
2. **`sz` 必须在循环开始前取一次**。若写成 `for i in range(len(q))` 却在中途追加节点，Python 的 `range(len(q))` 只在开始时求值还算安全；但 C++ 若写成 `for (int i = 0; i < q.size(); ++i)`，`q.size()` 每轮都会变大，会把下一层节点也吞进来，直接错。
3. **空树要单独返回空数组**。`root == nullptr` 时若直接入队会解引用空指针；按题意「节点个数可以为 0」，返回 `[]`。
4. **只压入非空孩子**。压入 `nullptr` 会在后续出队时崩，而且会让 `sz` 的语义被污染（空槽也算进「一层节点数」）。
5. **Python 用 `collections.deque`，不要用 `list`**。`list.pop(0)` 是 $O(n)$ 搬移，整体会退化成 $O(n^2)$；`deque.popleft()` 是 $O(1)$。
6. **C++ 的 `q.size()` 返回 `size_t`**，与 `int` 比较会有符号警告，先转成 `int sz = (int)q.size()` 更干净，也顺手完成快照。
7. **返回类型是 `vector<int>` / `list[int]`**，每个节点值都在 `int` 范围内，不需要 64 位；但如果把「初值」写成 `INT_MIN - 1` 就会溢出，用 `INT_MIN` 即可（`max` 与自身比较安全）。
8. **层数上界是 $10^4$**，答案数组最多 $10^4$ 项，链状树也不会爆内存（但递归 DFS 会爆栈，见 §8）。

## 5. 正确性证明

**引理 1（分层不变量）**：每轮外层循环开始时，队列中所有节点的深度相同，且它们恰好是当前层的全部节点，并按从左到右的顺序排列。

**证明**：对轮次归纳。第 0 轮开始时队列只有根，深度 0，是第 0 层全部节点，成立。

设第 $d$ 轮开始时队列恰为第 $d$ 层的全部节点，按从左到右排列，共 $sz$ 个。由引理 2（见下），这 $sz$ 次出队弹出的正是这 $sz$ 个节点，且不弹出任何孩子；孩子按「父节点从左到右、每个父节点先左后右」的顺序压到队尾。队列中所有非空孩子恰好是第 $d+1$ 层的全部节点，而这个压入顺序正是第 $d+1$ 层从左到右的顺序。故第 $d+1$ 轮开始时队列满足引理。∎

**引理 2（快照切层）**：若进入某轮时队列为同一层 $d$ 的 $sz$ 个节点（按从左到右），则执行 $sz$ 次「出队 + 压入非空孩子」后，弹出的恰好是这 $sz$ 个节点，压入的是它们全部非空孩子（深度 $d+1$），且按从左到右排列。

**证明**：记这 $sz$ 个节点为 $v_1,\dots,v_{sz}$（左→右）。对出队次数 $i$ 归纳：第 $i$ 次出队时，队头是 $v_i$（前 $i-1$ 次已按序弹出 $v_1..v_{i-1}$，且它们的孩子都排在所有 $v_j$ 之后）。弹出 $v_i$ 后把它的孩子压到队尾，深度为 $d+1$，排在尚未出队的 $v_{i+1..sz}$ 之后，因此不会影响后续 $v$ 的出队顺序。$sz$ 次后 $v_1..v_{sz}$ 全部弹出，队列中只剩下 $sz$ 个子节点按父子顺序排列。∎

**引理 3（逐层取最大值）**：一轮循环结束时 `best` 等于本层所有节点值的最大值。

**证明**：$best$ 初值为 $-\infty$，每弹出一个节点就执行 $best \leftarrow \max(best, val)$。由 $\max$ 的结合律与交换律，无论求和顺序如何，$\max$ 作用于整个多重集的结果都是该集合的最大元素；本层节点非空（$sz \ge 1$），故 $best$ 最终恰为本层最大值。∎

**定理**：算法返回的数组长度为树高 $H$，且第 $k$ 项恰为第 $k$ 层的最大值。

**证明**：由引理 1，第 $k$ 轮循环处理的正是第 $k$ 层的全部节点，不漏不重；由引理 3，该轮写入 `ans` 的 `best` 是第 $k$ 层最大值。第 0 轮处理根，之后每轮层数加 1，直到某轮队列为空——此时所有层都已处理完，共 $H$ 轮，`ans` 长度 $H$，第 $k$ 项正确。空树不进入循环，返回空数组，与题意一致。∎

## 6. 复杂度分析

- **时间**：$O(n)$，$n$ 为节点数。每个节点恰好入队一次、出队一次；出队时做一次 `max`、最多两次判空与入队，均为 $O(1)$。外层循环共 $H$ 轮，但循环控制的开销可以被「每轮至少处理一个节点」摊还掉，总时间仍为 $O(n)$。
- **空间**：$O(w + H) \subseteq O(n)$，$w$ 为树的最大宽度。队列入队峰值是「当前层 + 下一层」，为 $O(w)$；答案数组长度是树高 $H$。链状树 $w = 1$、$H = n$；完全二叉树 $w \approx n/2$、$H = \log n$，两种极端都是 $O(n)$。
- **对比 DFS**：DFS 递归空间是 $O(H)$，链状树上 $H = 10^4$ 会栈溢出（尤其 Python 默认递归上限 1000），所以本题**必须用 BFS 或显式栈的 DFS**。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <queue>
#include <climits>
#include <algorithm>
using namespace std;

/**
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    vector<int> largestValues(TreeNode* root) {
        vector<int> ans;
        if (root == nullptr) return ans;          // 空树：直接返回空数组

        queue<TreeNode*> q;
        q.push(root);
        while (!q.empty()) {
            int sz = (int)q.size();               // 快照：本层节点数
            int best = INT_MIN;                   // 不能用 0，节点值可能全为负
            for (int i = 0; i < sz; ++i) {
                TreeNode* node = q.front();
                q.pop();
                best = max(best, node->val);
                if (node->left)  q.push(node->left);   // 孩子排到队尾，属于下一层
                if (node->right) q.push(node->right);
            }
            ans.push_back(best);
        }
        return ans;
    }
};
```

### Python

```python
from collections import deque
from typing import List, Optional


class Solution:
    def largestValues(self, root: Optional[TreeNode]) -> List[int]:
        if root is None:
            return []

        ans: List[int] = []
        q = deque([root])
        while q:
            sz = len(q)                      # 快照：本层节点数
            best = float('-inf')             # 不能用 0，节点值可能全为负
            for _ in range(sz):
                node = q.popleft()           # deque.popleft 是 O(1)
                if node.val > best:
                    best = node.val
                if node.left:
                    q.append(node.left)
                if node.right:
                    q.append(node.right)
            ans.append(best)
        return ans
```

## 8. 边界情况与易错点

1. **空树**：`root = []` → 返回 `[]`。不特判会让 BFS 在 `q.popleft()` 前就拿到 `None`，或直接解引用空指针。
2. **全负 / 极小值**：`best` 初值写成 0 是本题最高频 WA；写 `-1` 同样错。C++ 用 `INT_MIN`，Python 用 `float('-inf')`。
3. **`sz` 被反复求值**：C++ 写成 `for (int i = 0; i < q.size(); ++i)` 会把刚压入的下一层节点也处理掉；Python 若把内层写成 `while len(q):`，会边压入边出队、永不终止。必须一次性取快照。
4. **单链退化**：$10^4$ 个节点的左斜链，答案长度等于 $10^4$（每层一个节点），不是 1；DFS 递归写法在这里栈溢出（Python 默认递归深度 1000）。
5. **完全二叉树的宽度**：答案长度是树高 $\lfloor \log_2 n \rfloor + 1$，不是宽度；把答案数组按宽度预留会浪费空间且不改变正确性。
6. **`null` 的语义**：层序序列里的 `null` 只是「该位置没有孩子」，不是值为 0 的节点，不能参与最大值比较。
7. **队列里塞空指针**：`q.push(node->left)` 不判空，后续 `node->val` 直接崩溃；空槽也不应计入本层节点数。
8. **只返回每层最大值，不要求顺序以外的信息**：无需记录层号；若误加 `(node, depth)` 二元组，空间常数变大但结果不变，属于不必要的复杂化。

**延伸思考**：

- 若要求「每一列的最大值」（按 $row + col$ 分组，即反对角线），BFS 的分层快照不再够用，应改用 DFS 传坐标，或用哈希表以 $row+col$ 为键；这也是「层」与「列」两种切分方式的典型区别。
- 若要**同时**返回每层的最大值、最小值、平均值，只需要在同一轮里多维护几个聚合变量，仍是 $O(n)$，不要为每个指标重跑一遍 BFS。
- 若树大到无法一次放进内存（流式 / 磁盘存储），BFS 需要 $O(w)$ 的队列，最坏 $w = O(n)$；此时用「显式栈 DFS + 深度下标数组」把空间压到 $O(H)$ 更划算，代价是要先知道树高或使用可增长的答案数组。
- 本题的「快照切层」可以抽象成模板：**任何按层聚合的树问题 = BFS + `len(q)` 快照 + 层内聚合**，把聚合函数替换掉即可通杀一大类题。
