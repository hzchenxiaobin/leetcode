# LeetCode 找树左下角的值 题解

## 1. 题目概述

- **标题 / 题号**：找树左下角的值（#513，medium）
- **链接**：https://leetcode.cn/problems/find-bottom-left-tree-value/
- **来源**：LeetCode 第 19 场周赛 Q2
- **难度**：中等
- **标签**：树、深度优先搜索、广度优先搜索、二叉树

**题意**：给定一棵二叉树的根节点 `root`，返回**最底层**中**最靠左**的那个节点的值。换一种说法：设根在第 1 层，树共有 $h$ 层，则返回第 $h$ 层从左到右数第一个节点的值。节点值可以重复、可以为负，因此「最左」是一个**位置**概念，与值的大小无关。

**约束**：

- 节点个数 $1 \le n \le 10^4$
- $-2^{31} \le \text{Node.val} \le 2^{31} - 1$
- 树不一定是满二叉树，某层可能只有 1 个节点；最底层最左节点也可能是某个父节点的**右**孩子

## 2. 示例

**示例 1**

```text
输入：root = [2,1,3]
输出：1
解释：根 2 的两个孩子是 1（左）和 3（右），最后一层是 [1, 3]；
      从左到右第一个是 1，故答案为 1。
```

**示例 2**

```text
输入：root = [1,2,3,4,null,5,6,null,null,7]
输出：7
解释：按层看这棵树是
      第 1 层：1
      第 2 层：2, 3
      第 3 层：4, 5, 6      （4 没有右孩子，5 只有右孩子 7）
      第 4 层：7
      最后一层只有 7，所以答案是 7。
```

## 3. 解题思路

### 3.1 暴力思路

最直白的做法是「先求最大深度，再找该层最左节点」：DFS 一遍求出 $H$，再按层序或按堆式编号遍历一遍找深度为 $H$ 且位置最靠左的节点。这样做能过，但要**两遍遍历**，还要额外讨论「位置」怎么表示：

- 用 `levels[d]` 存第 $d$ 层的所有节点：时间 $O(n)$，空间 $O(n)$。
- 用堆式编号（根为 1，左孩子 $2i$，右孩子 $2i+1$）：同层中编号最小者即最左，也能得到正确答案，但需要额外字段/结构，代码不够直接。

更常见的错误是**把「最左」理解成「值最小」**：节点值有负数、有重复，`[-2,1,3]` 的答案是 1 而不是 $-2$。

真正的瓶颈在于顺序：只有让「同一层的节点连续出现」，才可能用一次遍历、一个变量就拿到答案。

### 3.2 核心观察：层序遍历天然分层

![层序遍历暴露分层结构](images/wc19_q2_layer_concept.svg)

BFS 队列有一个非常好的性质：**某一时刻队列里的节点，恰好按「层」分块排列**。于是只要在每一轮循环开始时把当前队列长度 `sz` 记下来，接下来**只弹出 `sz` 个节点**、并把它们的孩子入队，这 `sz` 个节点就正好是这一层的全部节点。

而这一层的**弹出顺序是从左到右**：根单独成层；处理上一层时我们按「先左后右」把每个节点的孩子入队，上一层本身又是从左到右出队的，所以下一层入队顺序天然就是从左到右。

于是每一层的**第一个**弹出的节点（`i == 0`）就是该层最左节点。用一个变量 `ans` 每层覆盖一次，BFS 结束时 `ans` 就是**最深层（最后一轮）的队首**——正是题目所求。

> 💡 一句话：**队列分层 + 每层取队首**。不需要记录所有层，也不需要第二次遍历。

### 3.3 算法流程

![按层 BFS 流程](images/wc19_q2_bfs_flow.svg)

1. `q = [root]`，`ans = root.val`（保证单节点树也有答案）。
2. 当 `q` 非空时循环：
   - `sz = q.size()`，把**本层节点数**固定下来；
   - 弹出 `sz` 个节点：`i == 0` 时执行 `ans = node.val`；每个节点把非空左孩子、非空右孩子依次入队。
3. 队列为空，返回 `ans`。

**三种等价写法**（都 $O(n)$，差别在空间与代码长度）：

| 写法 | 答案更新时机 | 空间 |
|------|--------------|------|
| 按层 BFS | 每层第 1 个出队节点 | $O(w)$，$w$ 为最大宽度 |
| 左优先 DFS | `depth > best` 时 | $O(h)$，$h$ 为树高 |
| 反向 BFS | 每次出队都更新 | $O(w)$，代码最短 |

- **左优先 DFS**：先序遍历（根 → 左 → 右）中，同层节点正是从左到右出现；因此当 `depth` 首次超过历史最大深度时遇到的节点，就是新一层的最左节点。
- **反向 BFS**：入队时先右后左，那么出队顺序是「每层从右往左、层号从小到大」，最后一个出队的节点就是最底层最左节点。

本题 $n \le 10^4$，$w$ 最坏约 $n/2$，BFS 的空间完全够用；而 DFS 在「一条长链」上递归深度可达 $10^4$，Python 里反而要调大递归上限。所以主推 BFS。

### 3.4 示例演算

![示例 2 的逐层走查](images/wc19_q2_example_walkthrough.svg)

对 `root = [1,2,3,4,null,5,6,null,null,7]`：

| 轮次 | 本层节点（出队顺序） | 队首 → `ans` |
|------|----------------------|--------------|
| 第 1 轮 | `1` | 1 |
| 第 2 轮 | `2, 3` | 2 |
| 第 3 轮 | `4, 5, 6` | 4 |
| 第 4 轮 | `7` | 7 |

第 4 轮后队列为空，`ans = 7`，与官方输出一致。注意第 3 轮 `4` 没有右孩子、`5` 只有右孩子 `7`，`null` 不占位，所以第 4 层只剩 `7` 一个节点——它既是该层最左，也是该层最右。

## 4. 算法细节

1. **先固定层大小，再入队孩子**：必须写成 `sz = q.size(); for (i = 0; i < sz; i++) { ... }`。如果在 `while` 里边弹边判、顺手入队，下一层节点会混进本轮，答案会退化成「最后一层的最后一个节点」（即最右）。
2. **答案在 `i == 0` 更新，不是最后一次**：每层只覆盖一次，`ans` 始终是「当前已处理的最深层的队首」。
3. **初值取根值**：`ans = root->val`，避免单节点树或只有一条链时读到未初始化值；约束保证 $n \ge 1$，但模板里保留 `if (!root) return 0;` 的习惯写法也无坏处。
4. **只把非空孩子入队**：队列里永远不存 `nullptr`，主循环不需要判空，也省掉一层缩进。
5. **左优先 DFS 的判据**：`if (depth > best) { best = depth; ans = node->val; }`，必须 `>` 而不是 `>=`——`>=` 会让同层靠右的节点覆盖答案。递归时先 `dfs(left)` 再 `dfs(right)`，顺序不能反。
6. **反向 BFS 的入队顺序**：`push(right)` 必须在 `push(left)` 之前；每次出队都执行 `ans = node->val`，循环结束时最后一个出队者即答案。
7. **Python 用 `collections.deque`**：`list.pop(0)` 是 $O(n)$ 的搬移，整体会退化到 $O(n^2)$；`deque.popleft()` 才是 $O(1)$。
8. **数值类型**：答案只是读出某个节点的值，C++ 用 `int` 即可（值域 $[-2^{31}, 2^{31}-1]$ 正好是 `int` 范围）；只有当后续要做加减运算时才需要 `long long`。
9. **不要用 `queue.size()` 期间修改队列**：`sz` 一旦取到就与队列解耦，循环内继续 `push` 不会影响 `sz`，这正是分层的关键。

## 5. 正确性证明

**引理 1（层内出队顺序）**：BFS 中第 $d$ 层节点的出队顺序就是该层从左到右的顺序。

**证明**：对 $d$ 归纳。$d = 0$ 时只有根，结论成立。设第 $d$ 层按从左到右出队，处理第 $d$ 层每个节点时按「先左孩子、后右孩子」入队，得到第 $d+1$ 层的节点序列：对第 $d$ 层的相邻两个节点 $u$（左）与 $v$（右），$u$ 的所有孩子都排在 $v$ 的所有孩子之前，而 $u$ 的两个孩子之间左孩子在右孩子之前，故此序列恰好是第 $d+1$ 层从左到右的顺序。队列先进先出，保证它被完整、按序弹出。∎

**引理 2（每轮恰好一层）**：每一轮循环处理的 `sz` 个节点恰好构成完整的一层，且第 1 个是该层最左节点。

**证明**：归纳可知，循环开始时队列中只含第 $d$ 层的全部节点（初始时 $d=0$，只有根）。取 `sz = q.size()` 即为第 $d$ 层节点数；本轮内新入队的孩子都排在 `sz` 个旧节点之后，因此本轮的 `sz` 次弹出恰好取完第 $d$ 层，且由引理 1，第 1 个弹出者即该层最左节点。∎

**引理 3（`ans` 的终值）**：循环结束时 `ans` 等于最深层队首节点的值。

**证明**：由引理 2，每轮对应一个递增的层号，且每轮在 `i == 0` 时把 `ans` 覆盖为该层队首值。BFS 处理完所有节点，最后一轮处理的是层号最大的层（最深层），此后不再有覆盖，故终值为最深层队首值。∎

**定理**：算法返回的 `ans` 是最底层最左节点的值。

**证明**：由引理 2 与引理 3，`ans` 的终值是最深层的第一个节点值，而由引理 1，该层第 1 个出队节点正是该层最左节点；每个节点恰好入队、出队一次，故循环必然终止于处理完最深层之后。因此返回值符合题意。∎

## 6. 复杂度分析

- **时间**：$O(n)$。每个节点入队一次、出队一次，循环体内是常数次比较与指针操作；外层轮数为树高 $h \le n$，`sz` 的取用是 $O(1)$。总计 $O(n)$。
- **空间**：$O(w)$，$w$ 为队列的最大宽度（同一时刻最多存一层节点）。满二叉树时 $w = \lceil n/2 \rceil$，一般情况 $w \le n$，故最坏 $O(n)$；DFS 写法则为 $O(h)$，长链最坏 $O(n)$。除队列外只用常数个变量。

## 7. 参考代码

### C++

```cpp
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    int findBottomLeftValue(TreeNode* root) {
        queue<TreeNode*> q;
        q.push(root);
        int ans = root->val;              // 单节点树也能直接返回
        while (!q.empty()) {
            int sz = q.size();            // 固定本层节点数
            for (int i = 0; i < sz; i++) {
                TreeNode* cur = q.front();
                q.pop();
                if (i == 0) ans = cur->val;   // 本层最左 → 覆盖答案
                if (cur->left) q.push(cur->left);
                if (cur->right) q.push(cur->right);
            }
        }
        return ans;
    }
};
```

### Python

```python
from collections import deque
from typing import Optional

# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def findBottomLeftValue(self, root: Optional['TreeNode']) -> int:
        q = deque([root])
        ans = root.val
        while q:
            sz = len(q)                  # 固定本层节点数
            for i in range(sz):
                node = q.popleft()
                if i == 0:
                    ans = node.val       # 本层最左 → 覆盖答案
                if node.left:
                    q.append(node.left)
                if node.right:
                    q.append(node.right)
        return ans
```

## 8. 边界情况与易错点

1. **单节点树**：`root = [0]` 或 `[-1]`，循环只跑一轮，返回根值；`ans` 必须以 `root.val` 初始化，否则会拿到未定义值。
2. **最底层最左节点是右孩子**：如 `[1,null,2,null,3]`，每层只有一个节点，答案是最深的 `3`；把「最左」实现成「一路往左走」会错。
3. **长左链 / 长右链**：`[1,2,null,3]` 的答案是 3 而不是 2；链状树会让递归 DFS 深度达到 $10^4$，Python 需 `sys.setrecursionlimit` 或改迭代——BFS 无此风险。
4. **值为负或重复**：`[-2,1,3]` 的答案是 1；同值节点很常见，绝不能靠比较值来找「最左」。
5. **漏掉 `sz` 的快照**：在同一层里边弹边入队，下一层节点会混进本轮，`ans` 就变成整个队列里最后出队的节点。例如 `[1,2,3,4,5,6,7]` 应返回 4，漏掉快照会得到 7（最右），且小数据上未必暴露。
6. **DFS 用 `>=` 更新**：同层靠右的节点会覆盖答案，必须用严格大于。
7. **Python 用 `list.pop(0)`**：$O(n)$ 搬移让总复杂度退化到 $O(n^2)$，$n = 10^4$ 时会明显变慢，务必用 `deque`。
8. **空树**：题目约束 $n \ge 1$，但若自行加鲁棒性判断，返回 `0` 或 `-1` 前要在题解里说明约定，别让 `root->val` 直接解引用空指针。
