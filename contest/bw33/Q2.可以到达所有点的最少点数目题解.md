# LeetCode 可以到达所有点的最少点数目 题解

## 1. 题目概述

- **标题 / 题号**：可以到达所有点的最少点数目（#1557，medium）
- **链接**：https://leetcode.cn/problems/minimum-number-of-vertices-to-reach-all-nodes/
- **来源**：LeetCode 第 33 场双周赛 Q2
- **难度**：中等
- **标签**：图、有向无环图

**题意**：给定一个 $n$ 个节点（编号 $0 \sim n-1$）的**有向无环图（DAG）**与边表 `edges[i] = [from_i, to_i]`，求一个**最小点集** $S$，使得从 $S$ 中出发的点沿有向边能到达图中**所有**节点。题目保证解存在且唯一，答案可以任意顺序返回。

**约束**：

- $2 \le n \le 10^5$，$1 \le edges.length \le \min(10^5, n(n-1)/2)$；
- 所有边 $(from_i, to_i)$ 互不相同（无重边），图保证无环。

## 2. 示例

**示例 1**

```text
输入：n = 6, edges = [[0,1],[0,2],[2,5],[3,4],[4,2]]
输出：[0,3]
解释：从 0 出发可达 {0,1,2,5}，从 3 出发可达 {3,4,2,5}，两者并起来覆盖全部 6 个点；
     任何单个点都无法覆盖全部。
```

**示例 2**

```text
输入：n = 5, edges = [[0,1],[2,1],[3,1],[1,4],[2,4]]
输出：[0,2,3]
解释：0、2、3 都没有任何入边，只能由自己到达自己，必须选；选齐后 1 与 4 均可达。
```

## 3. 解题思路

### 3.1 暴力思路：可达闭包 + 最小覆盖

对每个点 $v$ 做一次 BFS/DFS 求可达集合 $R(v)$，得到 $n$ 个集合后再解「最少集合覆盖全集」问题。前者 $O(n(n+m))$ 已不可承受（$n = 10^5$）；后者本身是 NP 难的集合覆盖问题。这条路的每一半都走不通——必须利用 **DAG** 这一关键条件。

### 3.2 核心观察：答案就是所有入度为 0 的点

![入度为零的点必须选且选它就够](images/bw33_q2_indegree_zero_concept.svg)

两个方向的观察：

1. **必选**：点 $v$ 若入度为 0，则没有任何边指向 $v$，从别的点出发**永远到不了** $v$——$v$ 只能靠「自己出发」覆盖。所以任何可行点集都必须包含全部入度为 0 的点。
2. **够用**：对任意点 $u$，若 $u$ 入度为 0 则已覆盖；否则 $u$ 有入边 $(v, u)$，从 $v$ 出发可达 $u$。对 $v$ 重复这个回溯：**图无环，回溯链上的点互不相同**，链不可能无限延长，必然终止于某个入度为 0 的点 $w$，而 $w \rightsquigarrow v \rightsquigarrow u$ 是一条真实路径。

于是「入度为 0 的点集 $Z$」**恰好是**最小点集：任何可行集 $\supseteq Z$，而 $Z$ 本身可行。

### 3.3 算法流程

![算法流程：统计入度并收集为零的点](images/bw33_q2_algorithm_flow.svg)

```text
1. hasIn[v] = false 对所有 v
2. 对每条边 (from, to)：hasIn[to] = true        # 只需布尔标记，无需计数
3. 依编号升序收集所有 hasIn[v] == false 的 v
4. 返回收集结果
```

不需要邻接表、不需要拓扑排序——一遍扫边、一遍扫点即可。

### 3.4 示例演算

![示例 1 中入度为零的点 0 与 3 覆盖全图](images/bw33_q2_example_reachability.svg)

以示例 1 为例，入度标记：点 1、2、4、5 各有入边（`hasIn` 为真），点 0、3 无任何入边。回溯验证：$5 \leftarrow 2 \leftarrow \{0, 4\}$，$4 \leftarrow 3$，即从 0 与 3 出发可以覆盖 $2, 4, 5$；输出 $[0, 3]$。示例 2 中 0、2、3 均无入边，1 由 0/2/3 三条边指向、4 由 1 或 2 指向，输出 $[0, 2, 3]$。

## 4. 算法细节

1. **只要布尔标记，不要入度数组**：题目不需要入度的具体数值，`hasIn[to]` 一个 `char`/`bool` 数组即可，省去递增操作。
2. **不用建图**：边只被扫一遍，无随机访问需求，直接流式处理，缓存友好。
3. **返回顺序**：按编号升序收集（循环 $v = 0 \dots n-1$），虽然题目允许任意顺序，升序最便于肉眼比对与调试。
4. **DAG 条件是「够用」方向的关键**：在有环图上该结论会失效——环上的每个点都有入边，回溯可能绕环无限循环，最小点集也未必是「入度 0 点集」（例如 1→2、2→1 的双点环，入度 0 点集为空但空集不可行）。本题输入保证无环，放心使用。
5. **数据规模**：$n, m \le 10^5$，`vector` 一次分配即可；结果集大小 $\le n$。

## 5. 正确性证明

**引理 1（必选性）**：设 $Z$ 为全体入度为 0 的点集。任何可行点集 $S$（即 $\bigcup_{s \in S} R(s) = V$）都满足 $Z \subseteq S$。

**证明**：反证。设 $z \in Z$ 但 $z \notin S$。$z$ 入度为 0，即不存在边 $(u, z)$。任何一条到达 $z$ 的路径的**最后一步**必须经过某条指向 $z$ 的边，而这样的边不存在，故 $z \notin R(s)$ 对所有 $s \in S$ 成立，与 $\bigcup_{s \in S} R(s) = V$ 矛盾。∎

**引理 2（充分性）**：$Z$ 本身是可行点集，即 $\bigcup_{z \in Z} R(z) = V$。

**证明**：对任意 $u \in V$，若 $u \in Z$ 则 $u \in R(u)$（长度为 0 的路径）。否则归纳构造回溯链：$u_0 = u$；对 $k \ge 0$，若 $u_k$ 入度非 0，取一条入边 $(u_{k+1}, u_k)$，由无环性，$u_{k+1} \notin \{u_0, \dots, u_k\}$（否则 $u_{k+1} \to u_k \to \cdots \to u_{k+1}$ 构成有向环）。链上的点两两不同而 $V$ 有限，故链在有限步终止于某入度为 0 的点 $w \in Z$，把链倒过来即得路径 $w \to u_{k+1} \to \cdots \to u_0 = u$，故 $u \in R(w)$。∎

**定理**：$Z$ 是唯一的最小可行点集。

**证明**：由引理 1 任意可行集 $S \supseteq Z$；由引理 2 $Z$ 可行，故 $|Z| \le |S|$ 对一切可行集成立，$Z$ 是最小。又设 $T$ 是任一最小可行集，则 $T \supseteq Z$ 且 $|T| = |Z|$，得 $T = Z$，即最小集唯一。∎

## 6. 复杂度分析

- **时间**：$O(n + m)$。扫一遍边表打标记为 $O(m)$，扫一遍点集收集为 $O(n)$，线性。
- **空间**：$O(n)$（结果数组与入度标记数组，不计输入）。没有建任何邻接结构。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> findSmallestSetOfVertices(int n, vector<vector<int>>& edges) {
        vector<char> hasIn(n, 0);
        for (const auto& e : edges) hasIn[e[1]] = 1;   // 只需标记「有没有入边」
        vector<int> ans;
        for (int i = 0; i < n; ++i)
            if (!hasIn[i]) ans.push_back(i);
        return ans;
    }
};
```

### Python

```python
class Solution:
    def findSmallestSetOfVertices(self, n: int, edges: list[list[int]]) -> list[int]:
        has_in = [False] * n
        for _, v in edges:
            has_in[v] = True
        return [i for i in range(n) if not has_in[i]]
```

> 💡 两份代码均通过官方示例（`[0,3]`、`[0,2,3]`）以及无边图（返回全部点）、单链图（返回链头）等自造边界，C++ 与 Python 输出一致。

## 8. 边界情况与易错点

1. **无边输入**：约束下 `edges.length ≥ 1`，但即便为空，所有点入度均为 0，返回全部点，代码天然正确。
2. **不要把结论滥用到有环图**：环上的点入度均非 0，此时入度 0 点集可能不可行（最小点集问题在有环图上与支配树/SCC 收缩有关，复杂得多）。
3. **输出是「点的集合」而非计数**：题目要具体编号；按升序收集是最省心的输出。
4. **内存**：$n = 10^5$ 的标记数组用 `char`/`bool` 均可，无须 `int` 入度表；更无须 `unordered_set`。
5. **节点从 0 编号**：数组大小恰为 $n$，不要按 $n+1$ 开（那是 1 编号图的习惯，会引入无意义的下标 0）。

**延伸思考**：若图可能有环，「最小点集使全图可达」等价于把每个强连通分量缩成一个点后求缩点 DAG 的入度 0 点集（缩点后是 DAG，结论重新适用）——这正是竞赛图论里「缩点 + 入度统计」的标准组合。再进一步，若允许「经过集合中转」（即从 $S$ 中任意点出发、途中经过的点也视为出发点），问题会退化成「每个连通分量选一个点」，难度反而降低。
