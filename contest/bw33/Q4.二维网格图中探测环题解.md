# LeetCode 二维网格图中探测环 题解

## 1. 题目概述

- **标题 / 题号**：二维网格图中探测环（#1559，medium）
- **链接**：https://leetcode.cn/problems/detect-cycles-in-2d-grid/
- **来源**：LeetCode 第 33 场双周赛 Q4
- **难度**：中等
- **标签**：深度优先搜索、广度优先搜索、并查集、数组、矩阵

**题意**：给定 $m \times n$ 的小写字母网格 `grid`，判断是否存在由**相同字符**构成的**环**：一条起点与终点相同的路径，长度 $\ge 4$，每一步移动到上下左右相邻且字符相同的格子，且**不允许回到上一次移动时所在的格子**（禁止立刻掉头）。存在返回 `true`，否则 `false`。

**约束**：

- $1 \le m, n \le 500$（最多 $2.5 \times 10^5$ 个格子）；
- `grid` 只含小写字母。

## 2. 示例

**示例 1**

```text
输入：grid = [["a","a","a","a"],
             ["a","b","b","a"],
             ["a","b","b","a"],
             ["a","a","a","a"]]
输出：true
解释：外圈一圈 'a'、中间 2x2 的 'b' 各构成一个长度 8 / 4 的环。
```

**示例 2**

```text
输入：grid = [["c","c","c","a"],
             ["c","d","c","c"],
             ["c","c","e","c"],
             ["f","c","c","c"]]
输出：true
解释：外围的 'c' 构成一个长度 ≥ 4 的合法环，中间的 'd'、'e' 被环「包住」但不属于环。
```

**示例 3**

```text
输入：grid = [["a","b","b"],
             ["b","z","b"],
             ["b","b","a"]]
输出：false
解释：所有能走成闭合路径的地方都会被迫立刻掉头或长度不足 4。
```

## 3. 解题思路

### 3.1 暴力思路：每个点当起点找回到自身的路径

对每个格子做一次 DFS，寻找一条「不立刻掉头、回到起点的路径」，找到即返回。问题是同一批格子会被不同起点反复搜索，最坏 $O((mn)^2)$；并且「允许中途重复经过、只有终点必须是起点」的路径搜索状态管理复杂。更关键的是，**环根本不依附于特定起点**——同一个环从环上任意格子出发都能被发现，按起点枚举是大量重复劳动。

### 3.2 核心观察：问题等价于「同字符连通块里是否有图论环」

![DFS 模型：记录父方向，遇到已访问的非父同色格即有环](images/bw33_q4_parent_dfs_model.svg)

把每个格子看成顶点、上下左右**字符相同**的相邻格之间连一条边，得到若干个同字符诱导子图。则：

- 题目定义的合法环 ⟺ 某个同字符子图里存在（简单）环。

理由分两头：有图论环就沿环走一圈，环长 $\ge 4$（网格图是二分图，简单环全是偶环且无重边，最短为 4）、相邻同字符、无需掉头——是合法环；反之，一条合法的不掉头闭合路径若自交，可在重复顶点处「剪开」取出一条更短的闭合路径，极端情形就是简单环。于是判「有无环」即可，**起点在哪里、环长具体是多少都无所谓**。

判无向图有没有环是入门问题：一遍 DFS，若访问到**已访问过且不是当前节点父节点**的顶点，就有环；否则（森林）无环。「不是父节点」这一条件恰好实现题目的「不许回到上一步」。

### 3.3 算法流程：迭代式 DFS（防爆栈）

![算法流程：遍历未访问格子、栈式 DFS、四方向扩展](images/bw33_q4_algorithm_flow.svg)

```text
1. vis[m*n] = false
2. 对每个未访问格子 s：
       vis[s] = true；栈压入 (s, parent = -1)
       只要栈非空：
           (cur, par) 出栈
           对 cur 的四邻居 nb（同字符）：
               若 nb == par：跳过（不许掉头）
               若 vis[nb]：返回 true（撞到非父已访问点 → 有环）
               否则 vis[nb] = true，压入 (nb, cur)
3. 所有连通块扫完仍无发现：返回 false
```

用显式栈而不是递归：$500 \times 500$ 全同字符时 DFS 深度可达 $2.5 \times 10^5$，递归有爆栈风险（Python 尤甚），迭代版稳定。

### 3.4 示例演算

![示例 2 中 c 环的搜索示意](images/bw33_q4_example_cycles.svg)

示例 2 中从 $(0,0)$ 出发沿 'c' 扩展：一路向右到 $(0,2)$、向下到 $(2,2)$ 附近时，'c' 连通块自身含环——DFS 过程中，某条边（例如 $(1,0)$–$(2,0)$ 附近）会把「已访问的两个同色格」再次连起来，命中 `vis[nb] && nb != par` 条件立即返回 `true`。示例 3 中任何字符的连通块都是「毛刺状」的树结构（'b' 的连通块是一条折线而非环），DFS 遍历完无冲突，返回 `false`。

## 4. 算法细节

1. **父节点的表示**：栈元素存 `(cur, par)` 两个格子的下标（`x * n + y` 一维化），`par = -1` 表示起点。**必须比较格子坐标**，不能比较字符——比较字符无法区分同一字符的两个不同格子，是致命错误。
2. **visited 全局共享**：不需要每个连通块单独开 `vis`。从 $s$ 出发能走到的同色格都在本次 DFS 中标记完毕；别的连通块（无论字符是否相同）不会误入——扩展时同字符判断天然把搜索圈死在当前块里。
3. **入栈即标记**：邻居在压栈的同时置 `vis`，保证同一格子只入栈一次；出栈时直接扫描四邻居即可。若「出栈才标记」会导致同一格子被压多次，逻辑仍对但多做事，且要小心 `vis` 判定时环条件会误报自环方向的重复入栈——入栈即标记是最省心的写法。
4. **`true` 的快速返回**：题目只问「是否存在」，在环被发现的瞬间直接 `return true`，无需继续搜索或找最短环。
5. **一维化下标**：`id = x * n + y` 把二维压成一维，栈存 `pair<int,int>`（当前格与父格），比存四个坐标更紧凑。
6. **并查集替代方案**：扫描每个格子的右、下两个方向（每条边恰好被考察一次），同字符则并查集合并，发现两端已连通即有环——同样 $O(mn \alpha)$，代码量相当，可作为对拍实现。

## 5. 正确性证明

**引理 1（等价性）**：网格中存在题目定义的合法环，当且仅当某个同字符诱导子图含（简单）环。

**证明**：（⇐）设子图有简单环 $v_1 v_2 \cdots v_k v_1$。网格图按 $(i+j) \bmod 2$ 染色是**二分图**，无奇环、无重边，故 $k$ 为偶数且 $k \ge 4$；沿环走一圈即是合法环（相邻同字符、四邻接、不掉头）。（⇒）反证：设存在合法环 $P = p_0 p_1 \cdots p_L = p_0$（$L \ge 4$、任意内部步 $p_{i+1} \ne p_{i-1}$），但所有同字符子图都无环——即 $P$ 经过的顶点导出的子图是**森林**。考察 $P$ 中「第一次重访」：取最小的 $t$ 使 $p_t \in \{p_0, \dots, p_{t-2}\}$（$t = L$ 必然入选，故存在）。由 $t$ 的最小性，$p_0, \dots, p_{t-1}$ 两两不同。设 $p_t = p_j$（$j \le t-2$）：若 $j \le t - 3$，则 $p_j p_{j+1} \cdots p_t$ 是一个简单环，与森林矛盾；故只能 $j = t - 2$，即 $p_t = p_{t-2}$——这正是「在 $p_{t-1}$ 处回到上一次移动时所在的格子 $p_{t-2}$」，与 $P$ 不掉头矛盾。∎

**引理 2（DFS 判环）**：从任一起点对无向连通块做上述栈式 DFS，返回 `true` 当且仅当该块含简单环。

**证明**：DFS 中每格仅被标记一次，压栈边构成一棵生成树 $T$（块连通，故生成）。（⇐）设块含简单环 $C$。$C$ 有 $|C|$ 条边，而 $T$ 的边集无环，若 $C$ 的边全是树边则其自身导出环，矛盾；故 $C$ 至少有一条非树边 $(u, v)$。当 $u$ 出栈扫描到邻居 $v$ 时：$v$ 已访问（否则 $(u,v)$ 会被压成树边）；$v \ne par(u)$（$par(u)$ 与 $u$ 之间只有唯一的边，即那条树边，而 $(u,v)$ 非树边）。于是算法命中 `vis[v]` 分支返回 `true`。（⇒）若算法在 $u$ 出栈、邻居 $v$ 处发现 `vis[v]` 且 $v \ne par(u)$：$v$ 不可能是 $u$ 的树孩子（孩子都是 $u$ 出栈时才标记，而 $u$ 此刻才出栈），故边 $(u, v)$ 不是树边；$u, v$ 同属 $T$，其间有唯一的树路径，加上边 $(u, v)$ 闭成一个简单环。∎

**定理**：算法对整个网格返回 `true` 当且仅当存在合法环。

**证明**：算法依次对每个未被访问的格子启动 DFS，即按同字符连通块遍历全部格子。若任一块返回 `true`，由引理 2 该块有环，由引理 1 存在合法环；若所有块都不触发，由引理 2 每块皆为森林，由引理 1 无合法环，算法返回 `false`。∎

## 6. 复杂度分析

- **时间**：$O(mn)$。每个格子入栈、出栈各一次，出栈时扫描 4 个邻居，总代价 $O(4mn)$；字符比较均为 $O(1)$。注意这是**所有连通块共享一遍遍历**的结果，而非按起点重复搜索的 $O((mn)^2)$。
- **空间**：$O(mn)$。`vis` 数组与显式栈（栈最坏同时容纳 $O(mn)$ 级别的待扩展节点，如螺旋形长蛇块）。

## 7. 参考代码

### C++

```cpp
class Solution {
    static constexpr int DX[4] = {1, -1, 0, 0};
    static constexpr int DY[4] = {0, 0, 1, -1};
public:
    bool containsCycle(vector<vector<char>>& grid) {
        int m = (int)grid.size(), n = (int)grid[0].size();
        vector<char> vis(m * n, 0);
        vector<pair<int,int>> stk;                    // (当前格下标, 父格下标)
        for (int s = 0; s < m * n; ++s) {
            if (vis[s]) continue;
            vis[s] = 1;
            stk.push_back({s, -1});
            while (!stk.empty()) {
                auto [cur, par] = stk.back();
                stk.pop_back();
                int x = cur / n, y = cur % n;
                for (int d = 0; d < 4; ++d) {
                    int nx = x + DX[d], ny = y + DY[d];
                    if (nx < 0 || nx >= m || ny < 0 || ny >= n) continue;
                    if (grid[nx][ny] != grid[x][y]) continue;   // 只走同字符邻居
                    int nid = nx * n + ny;
                    if (nid == par) continue;                    // 不掉头
                    if (vis[nid]) return true;                   // 撞到非父已访问格
                    vis[nid] = 1;
                    stk.push_back({nid, cur});
                }
            }
        }
        return false;
    }
};
```

### Python

```python
class Solution:
    def containsCycle(self, grid: list[list[str]]) -> bool:
        m, n = len(grid), len(grid[0])
        DX = (1, -1, 0, 0)
        DY = (0, 0, 1, -1)
        vis = [[False] * n for _ in range(m)]
        for si in range(m):
            for sj in range(n):
                if vis[si][sj]:
                    continue
                stack = [(si, sj, -1, -1)]            # (x, y, 父格 x, 父格 y)
                vis[si][sj] = True
                while stack:
                    x, y, px, py = stack.pop()
                    for d in range(4):
                        nx, ny = x + DX[d], y + DY[d]
                        if not (0 <= nx < m and 0 <= ny < n):
                            continue
                        if grid[nx][ny] != grid[x][y]:
                            continue
                        if (nx, ny) == (px, py):      # 不回到上一步的格子
                            continue
                        if vis[nx][ny]:               # 非父的已访问同色格 → 有环
                            return True
                        vis[nx][ny] = True
                        stack.append((nx, ny, x, y))
        return False
```

> 💡 两份代码均通过全部官方示例（`true` / `true` / `false`）与 3600 组随机网格对拍（对手为**并查集判环**与**经典递归 DFS** 两个独立实现，含 $1 \times n$、$n \times 1$、小字母表高频环、$500 \times 500$ 全同字符等极端），`mismatch = 0`；$500 \times 500$ 最坏用例下迭代栈平稳运行。

## 8. 边界情况与易错点

1. **递归爆栈**：$500 \times 500$ 全 `'a'` 的 DFS 深度可达 $2.5 \times 10^5$。Python 递归上限默认 1000，必炸；C++ 也接近常见栈限制。务必用显式栈（或 BFS）。
2. **父判断必须比较坐标**：`nb == par` 用的是格子下标；若误写成「字符相同就跳过邻居」会连合法环一起跳掉。
3. **不要把「长度 ≥ 4」当额外条件去检查**：网格二分性保证任何简单环长 $\ge 4$（2 格往返被父判定排除），无需维护路径长度。
4. **$1 \times n$ 与 $n \times 1$ 网格**：路径图，必然无环，算法自然返回 `false`，无须特判。
5. **`vis` 的重置**：全局一块 `vis` 即可，切勿每个起点重开（$O((mn)^2)$ 内存与时间都会炸）；也不要在块内回溯时取消标记——判环需要「是否曾被访问」的持久信息，取消标记会把真环放走。
6. **只判「字符相同」不判「是否同一连通块」**：不同块的同色格子互不相邻，天然不会串门；无须按块编号预处理。
