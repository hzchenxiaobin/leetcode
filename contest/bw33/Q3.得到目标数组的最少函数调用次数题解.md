# LeetCode 得到目标数组的最少函数调用次数 题解

## 1. 题目概述

- **标题 / 题号**：得到目标数组的最少函数调用次数（#1558，medium）
- **链接**：https://leetcode.cn/problems/minimum-numbers-of-function-calls-to-make-target-array/
- **来源**：LeetCode 第 33 场双周赛 Q3
- **难度**：中等
- **标签**：贪心、位运算、数组

**题意**：给定目标数组 `nums`。另有一个与它等长、初始**全为 0** 的数组 `arr`，可以反复调用两个函数：

- `addOne(i)`：把**单个元素** `arr[i]` 加 $1$；
- `double()`：把**所有元素**乘 $2$。

每次调用计一次，求把 `arr` 变成 `nums` 的**最少函数调用次数**。

**约束**：

- $1 \le nums.length \le 10^5$；
- $0 \le nums[i] \le 10^9$；
- 答案保证在 32 位有符号整数范围内。

## 2. 示例

**示例 1**

```text
输入：nums = [1,5]
输出：5
解释：[0,0] ->(单点+1)-> [0,1] ->(×2)-> [0,2] ->(×2)-> [0,4] ->(单点+1)-> [1,4] ->(单点+1)-> [1,5]
     共 1 + 2 + 2 = 5 次调用。
```

**示例 2**

```text
输入：nums = [2,2]
输出：3
解释：先把两个元素各加 1（2 次单点 +1）：[0,0] -> [0,1] -> [1,1]；再全体乘 2（1 次）：[1,1] -> [2,2]。
     共 2 + 1 = 3 次调用。
```

**示例 3**

```text
输入：nums = [4,2,5]
输出：6
```

**示例 4 / 5**

```text
输入：nums = [3,2,2,4]      输出：7
输入：nums = [2,4,8,16]     输出：8
```

## 3. 解题思路

### 3.1 暴力思路：正向 BFS 状态搜索

把 `arr` 的每种取值看作状态，`addOne`/`double` 是转移，BFS 求最短步数。状态空间是 $\prod (nums_i + 1)$ 量级的乘积空间，哪怕 $n = 2$、值域到 $10^9$ 也完全存不下；而且正向「先加后乘」的组合方式指数爆炸。正向模拟注定走不通，必须**倒过来想**。

### 3.2 核心观察：逆向思考——把 nums 变回全 0

![逆向思考：奇数各减一，全体偶数则除以二](images/bw33_q3_reverse_greedy.svg)

两个操作都是**可逆**的，且操作序列反演后与原序列一一对应，于是「从全 0 到 `nums` 的最少调用」=「从 `nums` 到全 0 的最少调用」，后者只允许：

- **单点减 1**（`addOne` 的逆）：把某个元素减 $1$；
- **全体除以 2**（`double` 的逆）：把所有元素同时除以 $2$，**仅当全部为偶数**时可用。

逆向过程的贪心非常自然：**有奇数时必须先修奇数**（除法对奇数不可用），每个奇数都只能靠单点减 1 变偶；全部变偶且仍有非零元素时，除以 2 把问题规模整体砍半。每个元素 $x$ 在整个过程中被减 1 的次数恰好是它二进制表示中 1 的个数（每除一轮就暴露出更低的一位），全体除以 2 的轮数由**最大值**决定。

### 3.3 状态转移：按二进制位统计

![按二进制位统计：popcount 之和加最高位](images/bw33_q3_bit_counting.svg)

把逆向贪心翻译成按位的计数公式：设 $M = \max_i nums_i$，则

$$
ans \;=\; \sum_{i} \operatorname{popcount}(nums_i) \;+\; \max\bigl(0,\ \lfloor \log_2 M \rfloor\bigr)
$$

直观理解（正向视角）：把每个 $nums_i$ 的二进制逐位写出，**每一个值为 1 的二进制位对应一次 `addOne`**（在该位升到最低位时把它加上去），**每一轮整体左移对应一次 `double`**，而轮数只需迁就「位最长」的那个元素——其余元素在多余的轮次里保持 0 参与翻倍，不花代价。

### 3.4 示例演算

![nums=4,2,5 的逆向演算表](images/bw33_q3_walkthrough.svg)

以 $nums = [4, 2, 5]$（二进制 $100, 010, 101$）为例：$popcount$ 之和 $= 1 + 1 + 2 = 4$；$M = 5$ 的最高位在第 2 位（$\lfloor \log_2 5 \rfloor = 2$），需要 2 轮全体翻倍。总计 $4 + 2 = 6$，与示例一致。逆向模拟验证：$[4,2,5] \to$ (5 减 1) $\to [4,2,4] \to$ (÷2) $\to [2,1,2] \to$ (减 1) $\to [2,0,2] \to$ (÷2) $\to [1,0,1] \to$ (各减 1，2 次) $\to [0,0,0]$，共 $1 + 1 + 1 + 1 + 2 = 6$ 次 ✓。

## 4. 算法细节

1. **实现两条路线等价**：逐轮模拟（奇数各减 1、全偶则除 2）与直接公式（$popcount$ 求和 + 最高位）结果相同；公式版一次线性扫描 $O(n \log M)$ 或 $O(n)$（位技巧），代码最短。
2. **除法轮数取「最大值」的位长减 1**：`while (mx > 1) { ++rounds; mx >>= 1; }`——$M = 1$ 时轮数为 0（不需要翻倍），$M = 0$ 时也为 0。
3. **答案上界**：$n \le 10^5$ 个元素、每个 $popcount \le 30$，和 $\le 3 \times 10^6 + 30$，`int` 完全够用；C++ 中间累加用 `long long` 更稳。
4. **Python 计数**：`bin(x).count('1')` 在 3.9 可用（`int.bit_count()` 需 3.10+，LeetCode 环境两者皆可，前者兼容性最好）。
5. **不要正向贪心「先加后乘乱序」**：正向写法必须先把「最低位阶段」的所有 `addOne` 做完再翻倍，等价于逆向的位对齐；直接逆向或按位统计可以避免这类顺序细节。

## 5. 正确性证明

设一个（正向）方案共调用 $I$ 次单点加 1 与 $D$ 次全体乘 2。对元素 $i$ 的某次 `addOne`，若其后还剩 $k$ 次全体乘 2，则它对最终值的贡献是 $2^k$。于是每个元素都满足

$$
nums_i \;=\; \sum_{j=1}^{t_i} 2^{k_{ij}}, \qquad 0 \le k_{ij} \le D .
$$

**引理 1（popcount 下界）**：若干（可重复的）2 的幂之和 $x = \sum_{j=1}^{t} 2^{k_j}$ 必满足 $t \ge \operatorname{popcount}(x)$。

**证明**：对 $t$ 归纳。$t = 0$ 时 $x = 0$ 成立。由 popcount 的次可加性 $\operatorname{popcount}(a + b) \le \operatorname{popcount}(a) + \operatorname{popcount}(b)$（二进制加法每位最多产生 1 个 1 的净增加），得 $\operatorname{popcount}(x) \le \sum_j \operatorname{popcount}(2^{k_j}) = t$。∎

**引理 2（位长贴现下界）**：若还要求所有 $k_j \le D$ 且 $x \ge 1$，则 $t \ge \operatorname{popcount}(x) + \max\bigl(0,\ \lfloor \log_2 x \rfloor - D\bigr)$。

**证明**：$D \ge \lfloor \log_2 x \rfloor$ 时由引理 1 直接成立。设 $D < \lfloor \log_2 x \rfloor$。对指数做**进位归一化**：若同一指数 $k < D$ 出现至少两次，把两项 $2^k$ 合成一项 $2^{k+1}$——和不变、项数减一。归一化后低位各指数（$< D$）至多一项，恰为 $x \bmod 2^D$ 的二进制表示；令 $y = \lfloor x / 2^D \rfloor$，高位剩 $y$ 项。于是

$$
t \;\ge\; y + \operatorname{popcount}(x \bmod 2^D) .
$$

再把 $y$ 按二进制拆开 $y = \sum_{b \in B} 2^{b} = \sum_{b \in B} (2^{b} - 1) + \operatorname{popcount}(y)$，其中最大指数 $b_{\max} = \lfloor \log_2 y \rfloor$，故 $y - \operatorname{popcount}(y) \ge 2^{b_{\max}} - 1 \ge b_{\max} = \lfloor \log_2 y \rfloor$。又 $y \ge 2^{\lfloor \log_2 x \rfloor - D}$ 给出 $\lfloor \log_2 y \rfloor \ge \lfloor \log_2 x \rfloor - D$，且 $\operatorname{popcount}(x) = \operatorname{popcount}(y) + \operatorname{popcount}(x \bmod 2^D)$（高低位不重叠）。串联即得

$$
t \ge \operatorname{popcount}(y) + \bigl(\lfloor \log_2 x \rfloor - D\bigr) + \operatorname{popcount}(x \bmod 2^D) = \operatorname{popcount}(x) + \lfloor \log_2 x \rfloor - D . \;\blacksquare
$$

**定理**：最少调用次数为 $\displaystyle \sum_i \operatorname{popcount}(nums_i) + \Bigl(\bigl\lfloor \log_2 \max_i nums_i \bigr\rfloor\Bigr)$（最大值为 0 时为 0）。

**证明**：先证可达（上界）。取 $D = \lfloor \log_2 M \rfloor$（$M = \max nums_i$）。按逆向贪心执行：每轮把所有奇数各减 1、若仍有非零再全体除 2。第 $r$ 轮（$r = 0, 1, \dots$）各元素被减 1 的条件是其第 $r$ 个二进制位为 1，故元素 $i$ 总共被减 $\operatorname{popcount}(nums_i)$ 次；除法轮数直到最大值归零为止，即 $\lfloor \log_2 M \rfloor$ 轮。逆向可行 ⟺ 正向可行，总次数如公式。

再证下界。任取方案，设其 $D$ 次全体乘 2、单点加 1 共 $I$ 次，元素 $i$ 上的次数 $t_i$。令 $M' = \max_i nums_i$（对应元素 $i^*$）。由引理 2，

$$
I = \sum_i t_i \;\ge\; \sum_i \Bigl[\operatorname{popcount}(nums_i) + \max\bigl(0, \lfloor \log_2 nums_i \rfloor - D\bigr)\Bigr] \;\ge\; \sum_i \operatorname{popcount}(nums_i) + \bigl(\lfloor \log_2 M' \rfloor - D\bigr),
$$

（对 $i^*$ 应用第二项）。于是 $I + D \ge \sum_i \operatorname{popcount}(nums_i) + \lfloor \log_2 M' \rfloor$，与构造值相等，故公式值即最小值。∎

## 6. 复杂度分析

- **时间**：$O(n \log M)$，$M \le 10^9$、$\log M \le 30$——每个元素拆一次二进制；等价地说一遍「逐轮减奇数」的模拟也是 $O(n \log M)$。
- **空间**：$O(1)$ 额外（只维护累加器与最大值，不修改输入也能算）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minOperations(vector<int>& nums) {
        long long ones = 0;              // 每个二进制 1 都对应一次「单点 +1」
        int mx = 0;
        for (int x : nums) {
            if (x > mx) mx = x;
            while (x > 0) { ones += x & 1; x >>= 1; }
        }
        long long rounds = 0;            // 「全体 ×2」的次数 = 最大值的最高位位置
        while (mx > 1) { ++rounds; mx >>= 1; }
        return (int)(ones + rounds);
    }
};
```

### Python

```python
class Solution:
    def minOperations(self, nums: list[int]) -> int:
        ones = 0                          # 每个二进制 1 对应一次单点 +1
        mx = 0
        for x in nums:
            if x > mx:
                mx = x
            ones += bin(x).count('1')
        rounds = 0                        # 全体 ×2 的次数 = 最高位位置
        while mx > 1:
            rounds += 1
            mx >>= 1
        return ones + rounds
```

> 💡 两份代码均通过全部 5 个官方示例，并与**独立 BFS 状态搜索暴力**（8000 组随机小数组，含 0 与重复值）以及**逆向逐轮模拟**（20000 组随机数组，含 $10^9$ 级大值）对拍，`mismatch = 0`。

## 8. 边界情况与易错点

1. **全 0 数组**：$\sum popcount = 0$、$M = 0$、轮数 0，答案 0——`while (mx > 1)` 天然处理，不要对 0 做对数运算。
2. **最大值为 1**（如 $[1, 1]$）：轮数为 0，答案即元素个数 2；`> 1` 的判断避免了多算一轮。
3. **位长而非值本身**：轮数是 $\lfloor \log_2 M \rfloor$（最大值的最高位下标），不是 $M$ 的位数再减什么别的量，容易和「位长」差一混淆。
4. **溢出**：$10^5 \times 30 \approx 3 \times 10^6$，`int` 足够；但若改成 `long long` 值域（$10^{18}$，60 位），累加器必须换 `long long`。
5. **别把「单点加 1」误读成「全体加 1」**：若是全体加 1，公式会完全不同（那就是另一道题了），读题时务必确认操作作用范围。
