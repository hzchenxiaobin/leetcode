# LeetCode 子数组按位与值为 K 的数目 题解

## 1. 题目概述

- **标题 / 题号**：子数组按位与值为 K 的数目（#3209，hard）
- **链接**：https://leetcode.cn/problems/number-of-subarrays-with-and-value-of-k/
- **来源**：LeetCode 第 134 场双周赛 Q4
- **难度**：困难
- **标签**：位运算、线段树、数组、二分查找

**题意**：给定整数数组 $nums$ 与整数 $k$，统计有多少个**连续子数组**满足「其中所有元素的按位与结果恰为 $k$」。

**约束**：

- $1 \le nums.length \le 10^5$
- $0 \le nums[i], k \le 10^9$（即 $nums[i] < 2^{30}$）
- 返回值是计数，最坏可达 $\frac{n(n+1)}{2} \approx 5 \times 10^{9}$，C++ 必须用 `long long`

**关键点**：按位与**只有「1 变 0」、没有「0 变 1」**，所以区间越长、AND 值越小（按位包含关系）。这一单调性使得「固定一个端点后，不同的 AND 取值只有 $O(\log V)$ 个」，从而把 $O(n^2)$ 压到 $O(n \log V)$。

## 2. 示例

**示例 1**

```text
输入：nums = [1,1,1], k = 1
输出：6
解释：全部元素都是 1，任意子数组的 AND 都是 1，共 3×4/2 = 6 个。
```

**示例 2**

```text
输入：nums = [1,1,2], k = 1
输出：3
解释：合格的子数组是 [1]（下标 0）、[1]（下标 1）、[1,1]；
      [2] 的 AND 为 2，[1,2]、[1,1,2] 的 AND 都是 0。
```

**示例 3**

```text
输入：nums = [1,2,3], k = 2
输出：2
解释：逐个列出 6 个子数组的 AND：
  [1] = 1     [1,2] = 0    [1,2,3] = 0
  [2] = 2 ✓   [2,3] = 2 ✓  [3] = 3
恰有两个等于 2，故答案为 2。
```

**示例 4（边界补充，$k = 0$）**

```text
输入：nums = [0,1], k = 0
输出：2
解释：[0] 的 AND 为 0、[0,1] 的 AND 为 0&1 = 0，均合格；[1] 的 AND 为 1。
```

## 3. 解题思路

### 3.1 暴力思路

枚举左右端点，边扩展边累与：$O(n^2)$。$n = 10^5$ 时约 $5 \times 10^9$ 次运算，超时。另一种常见暴力是「固定左端点，二分找 AND 变化的区间」——这正是官方提示（稀疏表 + 二分）的思路，但它需要 $O(n \log n \log V)$；本篇给出更直接的 $O(n \log V)$ 做法。

### 3.2 核心观察：AND 关于区间长度单调

![AND 只会把 1 变成 0：值随区间变长单调不增](images/bw134_q4_and_monotone.svg)

按位与有两个基本事实：

1. $x \& y$ 的二进制 1 位集合是 $x$ 与 $y$ 的 1 位集合的**交集**，所以 $x \& y$ 的 1 位只会比 $x$ 少、不会多。
2. 因此对固定的右端点 $r$，随着左端点 $l$ 从 $r$ 往左移动，$AND(l..r)$ 的值**只会变小（位集合不断缩小）**。

关键推论：**每变化一次，至少有一个二进制位从 1 变成 0**。而 $nums[i] \le 10^9 < 2^{30}$，最多 30 位，所以

> 以 $r$ 结尾的所有子数组中，不同的 AND 取值**至多 31 个**（$r$ 自己的值 + 至多 30 次变化）。

于是一个朴素但极快的算法浮出水面：对每个右端点，只维护这张「值 → 出现次数」的小表。

### 3.3 算法流程：滚动小表

![按右端点维护「AND 值 → 子数组个数」](images/bw134_q4_distinct_set.svg)

设处理完 $r-1$ 后，表 $cur$ 的内容是「以 $r-1$ 结尾的子数组」按 AND 值分组的计数，且值**严格递减**。处理 $nums[r] = x$ 时：

1. 新建表 $nxt$，先放入单元素项 $(x, 1)$——它对应子数组 $[r, r]$。
2. 依次取 $cur$ 中的 $(v, c)$：这些子数组再接上 $x$ 后 AND 变为 $v \& x$，个数仍为 $c$。若 $v \& x$ 与 $nxt$ 末尾的值相同，就把计数相加（合并）；否则追加为新的一项。
3. 遍历 $nxt$，把值等于 $k$ 的项的计数累加到答案。
4. 令 $cur \leftarrow nxt$，继续下一个 $r$。

由于 $v \& x$ 关于 $v$ 单调，相等的值必然相邻，所以「只与表尾比较」的合并就是完备的。

```text
ans = 0, cur = []
for x in nums:
    nxt = [(x, 1)]
    for (v, c) in cur:
        nv = v & x
        if nxt[-1].value == nv:  nxt[-1].count += c
        else:                    nxt.append((nv, c))
    for (v, c) in nxt:
        if v == k:  ans += c
    cur = nxt
return ans
```

### 3.4 示例演算

![示例走查：三个右端点的小表与命中计数](images/bw134_q4_example_walk.svg)

$nums = [1,1,2]$，$k = 1$：

| 右端点 $r$ | $x$ | 处理后的表 $cur$（值, 个数） | 命中 $k=1$ | 累计 ans |
|---|---|---|---|---|
| 0 | 1 | (1, 1) | +1 | 1 |
| 1 | 1 | (1, 2) | +2 | 3 |
| 2 | 2 | (2, 1), (0, 2) | 0 | 3 |

第 1 步的细节：$cur = [(1,1)]$，$x = 1$，先放 $(1,1)$，再算 $1 \& 1 = 1$ 与表尾相同 → 合并成 $(1,2)$。这对应「以 1 结尾的两个子数组 $[1]$ 与 $[1,1]$ 的 AND 都是 1」。

第 2 步：$x = 2$，先放 $(2,1)$，再算 $1 \& 2 = 0$，与表尾 $2$ 不同 → 追加 $(0,2)$，对应 $[1,2]$ 与 $[1,1,2]$ 两个子数组的 AND 都是 0。

答案 3，与示例一致。

## 4. 算法细节

1. **表长有上界**：值严格递减且每次至少丢一位，故长度 $\le 31$；即使不做任何优化，内层循环也不会超过 31 次，总复杂度 $O(31n)$。
2. **合并只与表尾比较**：依赖「$v \& x$ 随 $v$ 单调不增」，因此相同值一定相邻。安全起见也可以用小数组 + 线性查找，但没必要。
3. **计数必须在建完表后累加**：如果一边合并一边累加，被合并掉的项会被漏算或重算。先建完、再扫一遍最不容易出错。
4. **`long long` 不可省**：全 1 的数组（$k = 0$ 之外的极端情况）答案可达 $n(n+1)/2 \approx 5 \times 10^{9}$，超出 `int`。
5. **`k = 0` 完全合法**：此时统计的是「AND 结果不含任何 1 位」的子数组，逻辑无需特判。
6. **`nums[i] = 0` 会把表迅速压成单项**：$0 \&$ 任何值为 0，表长退化为 1，性能自动变好。
7. **另外两种等价实现**：其一，用 `map` 代替 `vector`，代价是多一个 $\log$；其二，对每个左端点二分出「AND 等于 $k$ 的右端点区间」，需要稀疏表支持 $O(1)$ 区间 AND，复杂度 $O(n \log n \log V)$——这也是官方提示的做法，但常数更大。
8. **内存**：两张长度 $\le 31$ 的小表，空间 $O(\log V)$。

## 5. 正确性证明

**引理 1（单调性）**：固定 $r$，令 $g(l) = nums[l] \& nums[l+1] \& \cdots \& nums[r]$。则 $g$ 在 $l$ 递减时按位「不减反减」：若 $l_1 < l_2 \le r$，则 $g(l_1)$ 的 1 位集合 $\subseteq g(l_2)$ 的 1 位集合，即 $g(l_1) \& g(l_2) = g(l_1)$。

**证明**：$g(l_1)$ 是在 $g(l_2)$ 的基础上再与上 $nums[l_1], \dots, nums[l_2 - 1]$，而按位与只会清除 1 位、不会产生新的 1 位，故 1 位集合单调缩小。∎

**引理 2（表长上界）**：以 $r$ 结尾的子数组中，不同的 AND 取值至多 $31$ 个。

**证明**：由引理 1，把 $l$ 从 $r$ 递减到 $0$ 时 $g(l)$ 的 1 位集合单调缩小。每取到一个与前面不同的新值，1 位集合必然严格缩小，即至少失去一个二进制位。$nums[i] \le 10^9 < 2^{30}$，1 位最多 30 个，故「严格缩小」至多发生 30 次，加上初始值，不同取值至多 31 个。∎

**引理 3（表的语义与顺序）**：处理完下标 $r$ 后，表 $cur$ 恰好包含所有形如 $(v, c)$ 的项，其中 $v$ 是某个子数组 $nums[l..r]$ 的 AND 值，$c$ 是使 $g(l) = v$ 的 $l$ 的个数；且各项的 $v$ 严格递减。

**证明**：对 $r$ 归纳。$r$ 处先放入 $(x, 1)$，对应唯一的 $l = r$。归纳假设 $r-1$ 处的表正确且 $v$ 严格递减。对表中第 $k$ 项 $(v_k, c_k)$，它对应一组连续的左端点区间 $L_k$，这些子数组接上 $nums[r]$ 后 AND 为 $v_k \& x$，个数仍为 $c_k$。所有的 $l \le r-1$ 被这些区间恰好覆盖一次，故新表覆盖全部左端点、计数之和为 $r+1$，语义正确。又由引理 1，$v_1 > v_2 > \dots$ 推出 $v_1 \& x \ge v_2 \& x \ge \dots$（按位包含关系），故新表的值单调不增，合并相邻相等项后严格递减，维持不变式。∎

**定理**：算法输出的 `ans` 等于 AND 值恰为 $k$ 的子数组个数。

**证明**：每个子数组由其右端点 $r$ 唯一归类，故只需证：在处理 $r$ 的那一轮，`ans` 恰好增加了「以 $r$ 结尾且 AND 为 $k$ 的子数组个数」。由引理 3，第 $r$ 轮的 $nxt$ 中值等于 $k$ 的项（唯一存在，因值严格递减）的计数恰为满足 $g(l) = k$ 的左端点个数，算法正是把这一个计数加到 `ans`；若不存在这样的项则加 0，也正确。各轮互不重叠地覆盖全部子数组，求和即为答案。∎

## 6. 复杂度分析

- **时间**：$O(n \log V)$，其中 $V = \max nums[i] < 2^{30}$，即每轮内层至多 31 次「与 + 比较 + 合并」。严格说每轮还要扫一遍新表累加答案（同样 $\le 31$ 项）。总计约 $60n$ 次基本操作。
- **空间**：$O(\log V)$，两张长度不超过 31 的小表；若用 `vector` 反复分配，注意 `swap` 复用而不是每轮重新 `new`。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long countSubarrays(vector<int>& nums, int k) {
        long long ans = 0;
        vector<pair<int, int>> cur;              // (AND 值, 出现次数)，值严格递减
        for (int x : nums) {
            vector<pair<int, int>> nxt;
            nxt.push_back({x, 1});               // 子数组 [r, r]
            for (const auto& p : cur) {
                int nv = p.first & x;            // 接上 x 后的 AND
                if (nxt.back().first == nv) nxt.back().second += p.second;
                else nxt.push_back({nv, p.second});
            }
            for (const auto& p : nxt)            // 建完表再统计，避免合并时漏算
                if (p.first == k) ans += p.second;
            cur.swap(nxt);
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def countSubarrays(self, nums: list[int], k: int) -> int:
        ans = 0
        cur = []                       # [(AND 值, 出现次数)]，值严格递减
        for x in nums:
            nxt = [(x, 1)]             # 子数组 [r, r]
            for v, c in cur:
                nv = v & x             # 接上 x 后的 AND
                if nxt[-1][0] == nv:
                    nxt[-1] = (nv, nxt[-1][1] + c)
                else:
                    nxt.append((nv, c))
            for v, c in nxt:           # 建完表再统计
                if v == k:
                    ans += c
            cur = nxt
        return ans
```

> 💡 两段代码通过全部官方示例（`6`、`3`、`2`）与 $k = 0$、$nums[i] = 0$ 等边界；并与 $O(n^2)$ 暴力在 $n \le 9$（小值域 $0..15$）上对拍 400 组、在 $n \le 800$（值域 $0..7$，AND 命中密集）上对拍 6 组，`mismatch = 0`。$n = 10^5$、值域 $10^9$ 的极限输入耗时约 0.1 秒。

## 8. 边界情况与易错点

1. **`int` 溢出**：答案最坏 $5 \times 10^{9}$，函数返回类型是 `long`，C++ 的累加变量必须是 `long long`。
2. **先建表后统计**：边合并边统计时，被合并进表尾的那部分计数会被漏掉（或重复），务必分两步。
3. **合并只比表尾不够「保险」时**：可以额外加一层「线性查找」，但正确性依赖单调性，已由引理 3 保证；若不放心，可用 `map<int,int>` 换取确定性（代价是多一个 $\log$）。
4. **$k$ 比所有元素都大**：任何 AND 都不可能等于 $k$，返回 0——不要因为「$k$ 必须是某个元素的子集」而做特判，算法自然给出 0。
5. **$nums[i] = 0$**：单个 0 会让所有跨过它的区间 AND 都为 0，此时若 $k = 0$ 会一次性贡献大量答案，逻辑正常。
6. **不要用「AND 值单调」去二分**：虽然 $g(l)$ 单调，但它在一个右端点上的取值是「阶梯状」的，二分只能找到边界，仍需配合稀疏表；$O(n\log V)$ 的滚动表更简单也更快。
7. **空表初始化**：第一轮 `cur` 为空，`nxt` 只剩 `(x,1)`，注意别在这里越界访问 `nxt.back()`（代码里是先 `push_back` 再进入循环，安全）。
8. **`cur = nxt` 的开销**：C++ 用 `swap` 复用已分配的容量；Python 直接重新绑定即可（旧表会被回收）。
