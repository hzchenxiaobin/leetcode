# LeetCode 统计一致子数组数目 II 题解

## 1. 题目概述

- **标题 / 题号**：统计一致子数组数目 II（#4114，hard）
- **链接**：https://leetcode.cn/problems/count-consistent-subarrays-ii/
- **来源**：LeetCode 第 528 场周赛 Q4
- **难度**：困难
- **标签**：位运算、数组、哈希表、枚举

**题意**：给定长度为 $n$ 的整数数组 nums。若一个**非空连续子数组**所有元素的**按位与**恰好等于该子数组的**最小值**，就称它是「一致子数组」。统计一致子数组的个数。本题与同场 Q1（#4111）同题，只是把 $n$ 从 $100$ 放大到 $2\times10^5$，暴力枚举就此失效。

**约束**：

- $1 \le \text{nums.length} \le 2 \times 10^5$
- $0 \le \text{nums}[i] \le 10^6$，即 $< 2^{20}$，位宽只有 $20$
- 答案最大为 $\frac{n(n+1)}{2} \approx 2 \times 10^{10}$，必须使用 64 位整数

## 2. 示例

**示例 1**

```text
输入：nums = [5,3,1,2]
输出：6
解释：4 个单元素子数组本身一致；此外 nums[1..2] = [3,1] 的 AND = 1 = min，
      nums[0..2] = [5,3,1] 的 AND = 1 = min，共 6 个。
```

**示例 2**

```text
输入：nums = [1,1,1]
输出：6
解释：6 个子数组的 AND 与最小值都等于 1。
```

**示例 3**

```text
输入：nums = [0]
输出：1
解释：唯一的子数组 [0] 满足 AND = min = 0。
```

## 3. 解题思路

### 3.1 暴力思路

枚举左端点 $i$，再向右扩展右端点 $j$：扩展时 AND 可以增量维护 $x \leftarrow x \,\&\, \text{nums}[j]$，最小值也可以增量维护 $m \leftarrow \min(m, \text{nums}[j])$，两件事都是 $O(1)$。于是枚举全部 $O(n^2)$ 个子数组是 $O(n^2)$ 的；但 $n = 2\times10^5$ 时约有 $2\times10^{10}$ 个子数组，必然超时。

瓶颈在于**逐个枚举了起点**。能否把行为相同的起点合并起来一次算完？可以——按子数组的 AND 值分段。

### 3.2 核心观察：按 AND 值把起点切成段

![固定右端点后按 AND 值分段](images/wc528_q4_and_groups.svg)

先记一个基本事实：按位与只会**清除**比特，所以子数组的 AND 是其中每个元素的**子掩码**，数值上不超过最小值：

$$x = \text{nums}[i] \,\&\, \cdots \,\&\, \text{nums}[j] \;\le\; \min_{i \le k \le j} \text{nums}[k]$$

（证明见「5. 正确性证明」中的引理 1。）因此「一致」等价于「最小值恰好等于 AND」。

固定右端点 $j$，令 $f(i)$ 表示 nums[i..j] 的 AND。当 $i$ 左移（子数组变长）时 $f$ 只会丢掉比特；反过来，$f(0), f(1), \dots, f(j)$ 随 $i$ 增大而按位包含单调递增，数值单调不减。每次严格变化至少清掉一个比特，而 $\text{nums}[i] < 2^{20}$，所以每个 $j$ 只有**至多 21 段**取值相同的 AND。段数只与值域位宽有关，与 $n$ 无关：

$$\#\text{段} \le 20 + 1 = 21$$

这就是全部优化空间：每个右端点只处理 21 段，而不是 $j+1$ 个起点。

### 3.3 段内计数规则：看 x 的最后一次出现

![段内计数：只有 i 不超过 p 的起点有效](images/wc528_q4_count_rule.svg)

设某一段覆盖起点区间 $[lo, hi]$，段内 AND 统一为 $x$。段内每个元素都是 $x$ 的超集掩码，所以都 $\ge x$，最小值也 $\ge x$。于是

$$\text{nums}[i..j] \text{ 一致} \iff \text{最小值} = x \iff \text{子数组内存在值恰好为 } x \text{ 的元素}$$

记 $p$ 为 $x$ 在 nums[0..j] 中**最后一次**出现的下标（从未出现则记 $p = -1$）。任何值为 $x$ 且落在 $[i,j]$ 中的元素，其下标都不超过 $p$，所以「子数组含 $x$」当且仅当 $i \le p$。该段贡献为

$$\#\{\, i \in [lo, hi] : i \le p \,\} = \max\bigl(0,\ \min(hi, p) - lo + 1\bigr)$$

$p$ 用一张「值 → 最近下标」的哈希表，在扫描 $j$ 时顺带维护即可，无需区间查询。

### 3.4 算法流程

![算法流程：滚动维护 AND 分段](images/wc528_q4_flow.svg)

用一个列表保存分段，每项是三元组 $(x, lo, hi)$，按 $lo$ 升序（即起点升序）。进入右端点 $j$、读入 $v = \text{nums}[j]$ 之后：

1. 先更新 `last[v] = j`，保证稍后查询 $x = v$ 时能看见本次出现；
2. 旧段全部 AND 上 $v$：$x \leftarrow x \,\&\, v$，相邻且同值的段合并（区间取并）；
3. 追加单元素段 $(v, j, j)$，若与末段同值就并入（把末段右端改成 $j$）；
4. 遍历新列表，对每段取 $p = \text{last}[x]$，若 $p \ge lo$ 就累加 $\min(hi, p) - lo + 1$。

```text
last = {}                        # 值 -> 最近下标
groups = []                      # [(x, lo, hi)]，按起点升序
ans = 0
for j, v in enumerate(nums):
    last[v] = j
    ng = []
    for (x, lo, hi) in groups:
        nx = x & v
        if ng 非空 且 ng[-1].x == nx: ng[-1].hi = hi
        else: ng.append((nx, lo, hi))
    if ng 非空 且 ng[-1].x == v: ng[-1].hi = j
    else: ng.append((v, j, j))
    groups = ng
    for (x, lo, hi) in groups:
        p = last.get(x, -1)
        if p >= lo: ans += min(hi, p) - lo + 1
```

### 3.5 示例演算

![示例演算表：nums = [5,3,1,2]](images/wc528_q4_walkthrough.svg)

对 nums = [5,3,1,2]：

| $j$ | nums[j] | 分段 $(x,[lo,hi])$ | 最近出现 $p$ | 本步新增 | 累计 |
|-----|---------|---------------------|--------------|----------|------|
| 0 | 5 | $(5,[0,0])$ | $x=5,\ p=0$ | 1 | 1 |
| 1 | 3 | $(1,[0,0]),\ (3,[1,1])$ | $x=1,\ p=-1$；$x=3,\ p=1$ | $0+1$ | 2 |
| 2 | 1 | $(1,[0,2])$ | $x=1,\ p=2$ | $\min(2,2)-0+1=3$ | 5 |
| 3 | 2 | $(0,[0,2]),\ (2,[3,3])$ | $x=0,\ p=-1$；$x=2,\ p=3$ | $0+1$ | 6 |

第 2 步值得注意：旧段 $(1,[0,0])$ 与 $(3,[1,1])$ 同时 AND 上 1 后都变成 1，合并成 $[0,1]$；再并上单元素段 $(1,[2,2])$ 后整段变成 $[0,2]$，一次贡献 3 个。第 3 步 AND = 0 的那段贡献 0，因为 0 在 $[0,3]$ 中从未出现，而 $[5,3,1,2]$、$[3,1,2]$、$[1,2]$ 的最小值分别是 1、1、1，都不等于 0。终值 $1+1+3+1 = 6$，与官方输出一致。

## 4. 算法细节

1. **段必须保持连续覆盖**。段是 $[0, j]$ 的一个划分，合并时区间取并（`hi` 取旧段右端），不能只改 `lo` 或另起一段，否则会漏起点或重复计数。
2. **只和「上一段」比较就够**。$f(i)$ 随起点升序单调不减，等值段必然相邻，所以一次线性扫描的相邻合并即可，不需要哈希去重。
3. **先更新 `last` 再统计**。单元素段 $(v,j,j)$ 的贡献依赖 $p = j$；若先统计后更新，会漏掉起点 $j$。
4. **查表不要写坏哈希表**。C++ 用 `find` 而不是 `last[x]`（后者会插入键 0），Python 用 `dict.get(x, -1)`。
5. **贡献公式要夹紧**。$p$ 可能落在 $hi$ 右侧（整段都算，取 $hi$），也可能落在 $lo$ 左侧（一个都不算），统一写成 $\min(hi,p) - lo + 1$ 再判正。
6. **位宽决定段数上限**。$\text{nums}[i] < 2^{20}$，任何 AND 值最多 20 个 1，段数 $\le 21$；不要用「值域 $10^6$ 个不同值」估计循环次数。
7. **答案用 64 位、哈希表留足容量**。$n = 2\times10^5$ 且全为 1 时答案是 $20000100000$，超出 32 位 `int`，Python 的 `int` 天然安全；C++ 的 `unordered_map` 建议 `reserve(2n)` 减少 rehash，也可以直接开 $10^6+1$ 的 `int` 数组当 `last`（4 MB，更快）。

## 5. 正确性证明

**引理 1（AND 不超过最小值）**：对任意子数组，设其 AND 为 $x$、最小值为 $m$，则 $x \le m$。

**证明**：$x$ 的每个为 1 的比特在该子数组的所有元素中均为 1，故每个元素 $a$ 都满足 $a \,\&\, x = x$，即 $a$ 是 $x$ 的超集掩码，数值上 $a \ge x$。对所有 $a$ 取下界得 $m \ge x$。∎

**引理 2（分段数量上界）**：固定 $j$，$f(i) = \text{nums}[i] \,\&\, \cdots \,\&\, \text{nums}[j]$ 在 $i = 0,1,\dots,j$ 上单调不减，且不同取值个数不超过 $21$。

**证明**：若 $i_1 < i_2$，则 $f(i_1) = f(i_2) \,\&\, (\text{nums}[i_1..i_2-1]$ 的 AND$)$，是 $f(i_2)$ 的子掩码，故 $f(i_1) \le f(i_2)$。取值严格变化时，新掩码至少多包含一个比特，而 $2^{20}$ 以内的数最多 20 个比特位，所以从 $f(0)$ 到 $f(j)$ 至多严格变化 20 次，不同取值至多 21 个。∎

**引理 3（段内一致判据）**：设某段覆盖起点 $[lo,hi]$、AND 值为 $x$，$p$ 是 $x$ 在 nums[0..j] 中最后一次出现的下标（不存在记 $-1$）。则对任意 $i \in [lo,hi]$，nums[i..j] 一致当且仅当 $i \le p$。

**证明**：

- 充分性：$i \le p \le j$ 说明 nums[p] = x 落在子数组内。该段 AND 为 $x$，由引理 1 的证明过程知段内每个元素都 $\ge x$，故最小值 $= x = $ AND，子数组一致。
- 必要性：若子数组一致，则最小值等于 AND $= x$，最小值必在某个下标 $q \in [i,j]$ 处取到，即 nums[q] = x。由于 $p$ 是 $[0,j]$ 内 $x$ 的最后一次出现，必有 $q \le p$；又 $q \ge i$，所以 $i \le q \le p$。∎

**引理 4（分段维护不变量）**：每一轮结束后，`groups` 恰好是 $f$ 的极大等值段划分，按 $lo$ 升序且覆盖 $[0,j]$。

**证明**：对 $j$ 归纳。$j = 0$ 时只有单元素段 $(v,0,0)$，成立。设第 $j-1$ 轮结束时不变量成立，则对旧起点 $i < j$ 有 $f_{\text{new}}(i) = f_{\text{old}}(i) \,\&\, v$，而 $f_{\text{new}}(j) = v$。步骤 2、3 先逐段计算 $x \,\&\, v$，再追加 $(v,j,j)$ 并把相邻同值段合并；由引理 2 的单调性，等值段只可能相邻，因此合并后得到的正是新函数的极大等值段划分。∎

**定理**：算法返回的值等于一致子数组的总数。

**证明**：任一子数组由右端点 $j$ 唯一确定，在第 $j$ 轮恰好落在唯一的段内（引理 4），故该轮各段贡献之和就是以 $j$ 结尾的一致子数组个数（引理 3）。又统计前 `last` 已记录 $[0,j]$ 中每个值的最后位置：第 $j$ 轮先写入 $v$，而此前各轮写入的正是 $[0,j-1]$ 中的最新位置，所以 $p$ 的取值正确。对 $j = 0,1,\dots,n-1$ 求和即得总数。∎

## 6. 复杂度分析

- **时间**：每轮遍历段列表，段数 $\le 21$，段内只做一次 AND、一次相邻比较、一次哈希查询，均为 $O(1)$；因此总时间 $O(20n) = O(n \log C)$，其中 $C = 10^6$ 为值域上界。$n = 2\times10^5$ 时约 $4\times10^6$ 次基本操作。
- **空间**：分段列表至多 21 个三元组，$O(1)$；`last` 哈希表最多存 $\min(n, C+1)$ 个键，$O(n)$（若改成数组则固定 $O(C)$）。总计 $O(n)$。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <array>
#include <unordered_map>
#include <algorithm>
using namespace std;

class Solution {
public:
    long long countConsistent(vector<int>& nums) {
        int n = (int)nums.size();
        vector<array<int, 3>> groups, ng;      // (AND 值, lo, hi)
        groups.reserve(64);
        ng.reserve(64);
        unordered_map<int, int> last;          // 值 -> 最近下标
        last.reserve((size_t)n * 2 + 8);
        long long ans = 0;
        for (int j = 0; j < n; j++) {
            int v = nums[j];
            last[v] = j;                       // 先更新，单元素段要用到 p = j
            ng.clear();
            for (auto &g : groups) {
                int x = g[0] & v;
                if (!ng.empty() && ng.back()[0] == x) ng.back()[2] = g[2];  // 区间取并
                else ng.push_back({x, g[1], g[2]});
            }
            if (!ng.empty() && ng.back()[0] == v) ng.back()[2] = j;
            else ng.push_back({v, j, j});
            swap(groups, ng);
            for (auto &g : groups) {
                auto it = last.find(g[0]);
                if (it == last.end()) continue;            // x 从未出现
                int p = it->second;
                if (p >= g[1]) ans += (long long)min(g[2], p) - g[1] + 1;
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def countConsistent(self, nums: List[int]) -> int:
        last = {}                 # 值 -> 最近下标
        groups = []               # (AND 值, lo, hi)，按起点升序
        ans = 0
        for j, v in enumerate(nums):
            last[v] = j
            ng = []
            for x, lo, hi in groups:
                nx = x & v
                if ng and ng[-1][0] == nx:
                    ng[-1] = (nx, ng[-1][1], hi)       # 区间取并
                else:
                    ng.append((nx, lo, hi))
            if ng and ng[-1][0] == v:
                ng[-1] = (v, ng[-1][1], j)
            else:
                ng.append((v, j, j))
            groups = ng
            for x, lo, hi in groups:
                p = last.get(x, -1)
                if p >= lo:
                    ans += min(hi, p) - lo + 1
        return ans
```

## 8. 边界情况与易错点

1. **单元素数组**：$n = 1$ 时唯一子数组必然一致，应返回 1；算法中单元素段 $(v,j,j)$ 因 `last[v] = j` 贡献 1，自然正确。
2. **全 0 / 全 1 数组**：所有子数组都一致，答案是 $\frac{n(n+1)}{2} = 20000100000$，32 位 `int` 必然溢出，必须 `long long`。
3. **值 0 的特殊性**：0 不含任何比特，AND 为 0 的段可能一个元素都不等于 0；此时只能靠「0 是否出现过」判断，不能凭数值大小推测。
4. **`p` 必须取最近一次**：若记录的是首次出现，含更靠右的 $x$ 的起点会被漏算；C++ 用 `find` 判空、Python 用 `get(x, -1)`，别把 $-1$ 直接代入长度公式。
5. **结构维护别偷懒**：只更新 AND 值而不合并区间，会让段之间出现空洞；漏掉每轮的 $(v,j,j)$ 则会把所有单元素子数组一起丢掉。
6. **不要用「AND 与最小值的差」做近似**：例如 $[6,3]$ 的 AND = 2、min = 3，两者不等但只差 1，没有可用的数值规律，必须走「分段 + 最近出现」的精确判据。
