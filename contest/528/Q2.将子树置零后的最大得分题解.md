# LeetCode 将子树置零后的最大得分 题解

## 1. 题目概述

- **标题 / 题号**：将子树置零后的最大得分（#4112，medium）
- **链接**：https://leetcode.cn/problems/maximize-score-after-zeroing-subtrees/
- **来源**：LeetCode 第 528 场周赛 Q2
- **难度**：中等
- **标签**：树、深度优先搜索、动态规划、贪心

**题意**：给定一棵以节点 0 为根、共 $n$ 个节点的有根树（用 `parent` 表示，`parent[0] = -1`）。每个节点 $i$ 有操作类型 `op[i]` 和分数 `score[i]`。所有**非叶节点**都必须处理恰好一次，顺序任意：

- `op[i] = 0`：可以（至多）选择一个孩子，把以该孩子为根的**整棵子树**分数全部置 0；
- `op[i] = 1`：必须选择恰好一个孩子，把以该孩子为根的整棵子树分数全部置 0。

求所有操作结束后，全部节点分数之和的**最大值**。

**约束**：

- $1 \le n \le 10^5$
- `n == parent.length == op.length == score.length`
- `parent[0] == -1`，其余 $0 \le$ `parent[i]` $\le n-1$
- $0 \le$ `op[i]` $\le 1$，$-10^4 \le$ `score[i]` $\le 10^4$
- 输入保证 `parent` 描述的是一棵以 0 为根的合法树

> ⚠️ 注意：`parent[i]` 只是父亲编号，**不保证**小于 $i$，所以不能按下标倒推 DP，必须真正建孩子表后按树序处理。

## 2. 示例

**示例 1**

```text
输入：parent = [-1,0,0,0,1,2,3,3]
     op     = [1,1,0,0,1,1,0,1]
     score  = [5,6,1,2,3,2,3,-3]
输出：16
解释：树形 0 -> {1,2,3}，1 -> {4}，2 -> {5}，3 -> {6,7}；叶子 4、5、6、7 不处理。
      节点 1（op=1）必须零掉孩子 4；节点 2（op=0）不动；节点 3（op=0）零掉分数为负的孩子 7；
      节点 0（op=1）零掉孩子 2 的整棵子树 {2,5}。最终分数 [5,6,0,2,0,0,3,0]，和为 16。
```

**示例 2**

```text
输入：parent = [-1,0,0], op = [0,0,0], score = [1,2,3]
输出：6
解释：只有节点 0 需要处理，且 op[0] = 0 允许「不操作」，于是所有分数保留，答案为 1 + 2 + 3 = 6。
```

**示例 3**

```text
输入：parent = [-1], op = [1], score = [-10]
输出：-10
解释：唯一的节点就是叶子，没有任何操作可执行，所以最大总和就是 -10 本身。
```

## 3. 解题思路

### 3.1 暴力思路

直接按题意搜索，每个非叶节点 $i$ 有 $\deg(i)+1$（`op=0`）或 $\deg(i)$（`op=1`）种选择，组合总数在 $\prod_i (\deg(i)+1)$ 量级。星形树（根带 $n-1$ 个叶子、根 `op = 0`）就是 $2^{n-1}$，$n = 10^5$ 时完全不可行。

暴力之所以难，是因为把「操作顺序」也当成了搜索维度。只要看清**顺序无关**、且每次操作都是「整棵子树归零」，问题就能坍缩成自底向上的树形 DP。

### 3.2 核心观察：整棵归零是原子操作

![核心观察：子树整棵归零](images/wc528_q2_tree_dp_state.svg)

**观察 1（顺序无关）**：操作只有「把某棵子树全部置 0」这一种效果，而置 0 幂等且只减不增。所以节点 $x$ 的最终分数只有两种可能：有某次操作作用于包含 $x$ 的子树 → 0；否则 → `score[x]`。这与处理顺序完全无关。

**观察 2（原子性）**：节点 $u$ 的操作对孩子 $c$ 只有两种结果——**整棵**子树 $c$ 保留，贡献为 $c$ 子树的最优值；或**整棵**归零，贡献为 0。没有「零掉一半」的中间状态。

**观察 3（子问题独立）**：每个孩子只有「全留 / 全零」两态，且 $u$ 至多（或恰好）只能对一个孩子动手，不同孩子的选择互不影响。于是定义

$$dp[u] = \text{无祖先清零子树 } u \text{ 时，子树 } u \text{ 能贡献的最大分数}$$

答案就是 $dp[0]$（根没有祖先，天然满足前提）。

**为什么只需看「最小的孩子」**：零掉孩子 $c$ 会让它的贡献从 $dp[c]$ 变成 0，**损失恰好是 $dp[c]$**。所以 `op[u] = 1` 时挑 $dp$ 最小的孩子损失最小；`op[u] = 0` 时只有某个孩子 $dp < 0$ 才值得零（能「赚」回来），否则不动。

### 3.3 状态转移与实现顺序

![算法流程：建表、先序、逆序 DP](images/wc528_q2_dp_flow.svg)

设 $S = \text{score}[u] + \sum_{c} dp[c]$、$m = \min_{c} dp[c]$，则

$$
dp[u] =
\begin{cases}
\text{score}[u], & u \text{ 是叶子} \\[4pt]
S - \min(0, m), & \text{op}[u] = 0 \\[4pt]
S - m, & \text{op}[u] = 1
\end{cases}
$$

实现分三步：

1. **建孩子表**：`i = 1..n-1`，把 $i$ 挂到 `children[parent[i]]`，$O(n)$；
2. **求树序**：从根 0 用**显式栈**做先序遍历得到 `order`，保证父亲排在孩子之前（链状树深 $10^5$，递归必爆栈）；
3. **逆序 DP**：`for k = n-1 .. 0`，处理 `u = order[k]` 时它的孩子全部已算完，套转移即可。

### 3.4 示例演算

![示例 1 演算表](images/wc528_q2_walkthrough.svg)

按逆先序 $4,5,6,7,1,2,3,0$ 逐行填表：

| 节点 $u$ | `score` | `op` | 孩子的 $dp$ | 决策 | $dp[u]$ |
|---|---|---|---|---|---|
| 4 | 3 | 1 | — | 叶子，不处理 | 3 |
| 5 | 2 | 1 | — | 叶子，不处理 | 2 |
| 6 | 3 | 0 | — | 叶子，不处理 | 3 |
| 7 | -3 | 1 | — | 叶子，不处理 | -3 |
| 1 | 6 | 1 | {3} | $S=9,\ m=3$，必须零掉 4 | 6 |
| 2 | 1 | 0 | {2} | $S=3,\ m=2 \ge 0$，不动 | 3 |
| 3 | 2 | 0 | {3, -3} | $S=2,\ m=-3$，零掉 7 反而赚 3 | 5 |
| 0 | 5 | 1 | {6, 3, 5} | $S=19,\ m=3$，零掉孩子 2 | 16 |

根节点 $dp[0] = 16$，与官方输出一致。注意节点 3 这行：$S = 2 + 3 + (-3) = 2$，因 $m = -3 < 0$，减去 $m$ 后变成 $5$——这就是「零掉负贡献子树」的收益。

## 4. 算法细节

1. **孩子表用 `vector<vector<int>>`**：总边数 $n-1$，均摊 $O(n)$ 空间；不要用 $O(n^2)$ 的邻接矩阵。
2. **遍历必须用显式栈**：叶子判定写 `children[u].empty()`；先序 `order` 长度必等于 $n$（树连通），逆序循环可直接写 `for (int k = n - 1; k >= 0; k--)`。
3. **`m` 的初值**取第一个孩子的 $dp$ 再逐个 `min`，比用哨兵更直观；注意**不能**用 0 初始化后取 min，否则全正孩子的节点会得到错误的 $m = 0$。
4. **`op = 0` 的条件减法**写成 `if (m < 0) S -= m;`，严格等价于 $S - \min(0, m)$；无条件写 `S -= m` 会在孩子全为正时白丢分数。
5. **`op = 1` 必须无条件减 `m`**：即使孩子个个都是正贡献，也必须零掉一个，这是本题最容易漏的强制约束。
6. **溢出**：$|dp| \le n \times 10^4 = 10^9$ 本身在 `int` 内，但中间量用 `long long` 累加、返回时再转回 `int` 更稳。
7. **单孩子自检**：只有一个孩子且 `op = 1` 时，$dp[u] = S - m = \text{score}[u] + m - m = \text{score}[u]$，可用它快速验证转移有没有写反。

## 5. 正确性证明

**引理 1（顺序无关，可归约为选择族）**：任取一组合法选择——每个非叶节点 $u$ 选出一个孩子 $c_u$（`op[u] = 1` 时必选，`op[u] = 0` 时可空）——则不论以何种顺序处理，最终分数都等于 $\sum_{x \notin \bigcup_u \text{subtree}(c_u)} \text{score}[x]$。

**证明**：每个操作只把一棵子树内的分数置 0，置 0 幂等且只减不增，故节点 $x$ 最终为 0 当且仅当某个被选中的子树包含 $x$。对每个 $x$ 成立，求和即得。反之，任意一组上述选择都可直接按「每个非叶节点执行其选择」实现（规则不依赖当前分数），故选择族就是全部自由度。∎

**引理 2（子问题分解）**：设子树 $u$ 未被任何祖先清零，则

$$dp[u] = \text{score}[u] + \max_{|T| \le 1,\ T \subseteq \text{child}(u)} \sum_{c \notin T} dp[c]$$

其中 $T$ 是被零掉的孩子集合，`op[u] = 1` 时要求 $|T| = 1$。

**证明**：$u$ 自身不被祖先清零，$\text{score}[u]$ 必然计入。对每个孩子 $c$：由引理 1 与观察 2，$c$ 只有「整棵保留」或「整棵归零」两态。归零时贡献为 0（$c$ 内部即便被强制操作，也只是在已全零的子树里置 0，不改变贡献，且该操作总能执行）；保留时，$c$ 的子树内部结构与整个问题在子树 $c$ 上的实例同构（$c$ 也要按自己的 `op[c]` 处理），故最大贡献不超过 $dp[c]$ 且能取到。不同孩子的决策互不重叠、互不约束，可分别取最优再相加；$u$ 自己的操作恰给出 $T$ 的约束。∎

**引理 3（合并公式）**：记 $S = \text{score}[u] + \sum_c dp[c]$、$m = \min_c dp[c]$，则引理 2 中的最大值在 `op[u] = 0` 时为 $S - \min(0, m)$，在 `op[u] = 1` 时为 $S - m$。

**证明**：零掉孩子 $c$ 的收益是 $S - dp[c]$，故只需让被零掉孩子的 $dp$ 尽量小。`op[u] = 1`：必须选一个，取 $c^* = \arg\min_c dp[c]$，得 $S - m$。`op[u] = 0`：可在「不选」($S$) 与「选 $c^*$」($S - m$) 中取大者，即 $S - \min(0, m)$；$m \ge 0$ 时不选更优，$m < 0$ 时选 $c^*$ 更优。∎

**定理**：算法返回的 $dp[0]$ 等于题目所求的最大可能分数总和。

**证明**：对子树高度归纳证明「$dp[u]$ 恰为子树 $u$ 未被祖先清零时的最大贡献」。基：$u$ 为叶子，无操作可做，贡献只能是 `score[u]`，成立。归纳：设所有孩子的 $dp$ 均正确，由引理 2、3，$dp[u]$ 是 $u$ 处所有合法选择下的最大值。根节点 0 没有祖先，前提自动满足，由引理 1 该最大值正是所求。∎

## 6. 复杂度分析

- **时间**：$O(n)$。建孩子表 $O(n)$；先序遍历每点入栈出栈一次 $O(n)$；逆序 DP 中每条父子边只被访问常数次 $O(n)$。$n = 10^5$ 轻松通过。
- **空间**：$O(n)$。孩子表存 $n-1$ 条边；`order`、`dp` 各 $n$ 个元素；显式栈最坏 $O(n)$（星形树根节点一次压入 $n-1$ 个孩子）。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int maxScore(vector<int>& parent, vector<int>& op, vector<int>& score) {
        int n = parent.size();
        // 1. 建孩子表（parent[i] 不保证小于 i，必须真正建树）
        vector<vector<int>> children(n);
        for (int i = 1; i < n; i++) children[parent[i]].push_back(i);
        // 2. 显式栈先序遍历：父节点一定排在孩子之前，避免深链爆栈
        vector<int> order, st{0};
        order.reserve(n);
        while (!st.empty()) {
            int u = st.back();
            st.pop_back();
            order.push_back(u);
            for (int c : children[u]) st.push_back(c);
        }
        // 3. 逆序自底向上 DP
        vector<long long> dp(n, 0);
        for (int k = n - 1; k >= 0; k--) {
            int u = order[k];
            if (children[u].empty()) {          // 叶子：不执行任何操作
                dp[u] = score[u];
                continue;
            }
            long long S = score[u];
            long long m = dp[children[u][0]];
            for (int c : children[u]) {
                S += dp[c];
                m = min(m, dp[c]);
            }
            if (op[u] == 1) S -= m;                        // 必须零掉 dp 最小的孩子
            if (op[u] == 0 && m < 0) S -= m;               // op=0 时仅在负收益时零
            dp[u] = S;
        }
        return (int)dp[0];
    }
};
```

### Python

```python
class Solution:
    def maxScore(self, parent: list[int], op: list[int], score: list[int]) -> int:
        n = len(parent)
        # 1. 建孩子表
        children = [[] for _ in range(n)]
        for i in range(1, n):
            children[parent[i]].append(i)
        # 2. 显式栈先序遍历（不能用递归，深链会超出递归上限）
        order, stack = [], [0]
        while stack:
            u = stack.pop()
            order.append(u)
            stack.extend(children[u])
        # 3. 逆序 DP：孩子先算完，再算自己
        dp = [0] * n
        for u in reversed(order):
            if not children[u]:
                dp[u] = score[u]
                continue
            s = score[u]
            m = dp[children[u][0]]
            for c in children[u]:
                s += dp[c]
                m = min(m, dp[c])
            if op[u] == 0:
                if m < 0:
                    s -= m          # 等价于 s - min(0, m)
            else:
                s -= m              # 必选，零掉 dp 最小的孩子
            dp[u] = s
        return dp[0]
```

## 8. 边界情况与易错点

1. **$n = 1$（单节点即叶子）**：没有任何操作可执行，直接返回 `score[0]`，即使它等于 $-10$、即使 `op[0] = 1`（示例 3）；代码靠「叶子分支」自然处理。
2. **`op = 1` 但只有一个孩子**：必须零掉这个唯一孩子，$dp[u] = \text{score}[u]$；把「必须」误当成可选会得到偏大的错误答案。
3. **`op = 0` 且所有孩子 $dp \ge 0$**：不能零，$S - \min(0, m) = S$；写成无条件 `S -= m` 会白白丢掉正分数。
4. **孩子 $dp$ 为负时的方向**：零掉负贡献子树会**增加**总分（减去负数），`op = 0` 时恰恰要主动去零，别反着写。
5. **深链爆栈**：$n = 10^5$ 的链，Python 默认递归上限 1000、C++ 默认栈约 8 MB，递归 DFS 都会崩，必须显式栈。
6. **不能假设 `parent[i] < i`**：约束只保证 $0 \le$ `parent[i]` $\le n-1$，按编号倒序 DP 在反例上会算错。
7. **答案范围**：$|dp[0]| \le 10^9$，`int` 够用；若放宽约束，先按 $n \times 10^4$ 估算再决定位宽，中间累加一律用 64 位更稳妥。
