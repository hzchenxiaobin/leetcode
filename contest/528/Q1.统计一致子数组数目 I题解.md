# LeetCode 统计一致子数组数目 I 题解

## 1. 题目概述

- **标题 / 题号**：统计一致子数组数目 I（#4111，easy）
- **链接**：https://leetcode.cn/problems/count-consistent-subarrays-i/
- **来源**：LeetCode 第 528 场周赛 Q1
- **难度**：简单
- **标签**：位运算、数组、枚举、子数组

**题意**：给定整数数组 `nums`。若一个子数组内**所有元素的按位与**恰好等于该子数组的**最小值**，则称它「一致」。返回 `nums` 中一致子数组的个数，子数组指连续、非空的元素序列。

**约束**：

- $1 \le nums.length \le 100$ → 子数组总数上界 $\frac{n(n+1)}{2} = 5050$，$O(n^2)$ 枚举绰绰有余
- $0 \le nums[i] \le 100$ → 二进制至多 7 位（$100 < 128$），AND 与 min 都落在 $[0, 100]$，`int` 足够
- 元素非负 → 「子掩码 ⇒ 数值不大于原数」这条性质可直接使用

## 2. 示例

**示例 1**

```text
输入：nums = [5,3,1,2]
输出：6
解释：一致的子数组为
      nums[0..0] = [5]          按位与 5      最小值 5
      nums[1..1] = [3]          按位与 3      最小值 3
      nums[2..2] = [1]          按位与 1      最小值 1
      nums[3..3] = [2]          按位与 2      最小值 2
      nums[1..2] = [3,1]        按位与 1      最小值 1
      nums[0..2] = [5,3,1]      按位与 1      最小值 1
其余 4 个子数组均不满足，例如 nums[1..3] = [3,1,2] 按位与 0、最小值 1。
```

**示例 2**

```text
输入：nums = [1,1,1]
输出：6
解释：任意子数组的按位与与最小值都等于 1，故 3 + 2 + 1 = 6 个全部一致。
```

**示例 3**

```text
输入：nums = [0]
输出：1
解释：唯一的子数组 [0] 按位与与最小值均为 0。
```

## 3. 解题思路

### 3.1 暴力思路

最直白的写法是枚举左右端点 $0 \le l \le r < n$，对每个区间**重新扫一遍**分别求按位与与最小值，再比较是否相等。总操作数

$$\sum_{l \le r} (r-l+1) = \sum_{k=1}^{n} k\,(n-k+1) \approx \frac{n^3}{6}$$

$n = 100$ 时约 $1.7 \times 10^5$ 次元素访问，签到题时限下也能过。但它把同一段前缀算了一遍又一遍：区间 $[l, r]$ 的全部信息都藏在 $[l, r-1]$ 里，重扫纯属浪费。

于是优化方向非常明确：**固定左端点 $l$，让右端点 $r$ 从 $l$ 一格一格向右挪，每次只吸收新元素 $nums[r]$，用 $O(1)$ 增量维护两个量**，总代价降到 $O(n^2)$。

### 3.2 核心观察：固定左端点，增量维护 AND 与 min

![核心观察：AND 不超过最小值，相等可失而复得](images/wc528_q1_and_le_min_model.svg)

**观察一：按位与永远不超过最小值。** 按位与只会把比特「清零」，所以结果 $a$ 的每个 1 比特必然在原数里也是 1，即 $a$ 是任意元素的**子掩码**；对非负整数，子掩码的数值不会更大。于是对任意非空子数组

$$\mathrm{AND}(l,r) \le \min_{l \le i \le r} nums[i]$$

**观察二：一致 $\iff$ 两个量相等，且只可能 AND 偏小。** 既然 AND 恒不大于 min，「一致」就退化为一次 `cur_and == cur_min` 的比较，代码里根本不需要处理 AND 比 min 大的分支。

**观察三（真正的坑）：相等可以「失而复得」。** 右扩时 AND 只减不增、min 也只减不增，但两者的差**并不单调**。取 $nums = [6,3,2]$、$l = 0$：$r=1$ 时 AND 为 $6 \ \mathrm{AND}\ 3 = 2$，而 min 为 3，$2 < 3$ 不一致；再右扩一格把 2 收进来，AND 仍是 $2 \ \mathrm{AND}\ 2 = 2$，min 恰好降到 2，两者**重新相等**。所以任何「AND < min 就 break / continue 到下一个 $l$」的剪枝都会漏解，内层必须老老实实走完 $r = l \dots n-1$。

> 💡 一句话：固定左端点 $l$，用 `cur_and`、`cur_min` 两个变量边右扩边维护，每到一格比较一次，相等就计数。$n \le 100$ 时一共只有 5050 个区间，这就是本题的最优写法。

### 3.3 算法流程

![算法流程：固定左端点，右端点逐个右扩](images/wc528_q1_scan_flow.svg)

```text
输入：nums，长度 n
1. ans ← 0
2. 对每个左端点 l = 0 … n−1：
   a. cur_and ← nums[l]，cur_min ← nums[l]        # 单元素区间天然一致
   b. 对每个右端点 r = l … n−1：
      i.   若 r > l：
                cur_and ← cur_and AND nums[r]
                cur_min ← min(cur_min, nums[r])
      ii.  若 cur_and == cur_min：ans ← ans + 1
3. 返回 ans
```

两层循环，内层不做任何提前退出；每轮只做一次按位与、一次取最小、一次相等判定，全部是 $O(1)$ 操作。

### 3.4 示例演算

![示例 1 走查：逐格比较 AND 与 min](images/wc528_q1_walkthrough.svg)

以 `nums = [5, 3, 1, 2]` 为例，逐行固定左端点、逐列右扩（绿格为一致）。表中「按位与」一列按**增量**写法列出，每格只把新元素并入上一格的结果：

| $l$ | $r$ | 子数组 | 按位与 | 最小值 | 一致 |
|---|---|---|---|---|---|
| 0 | 0 | [5] | 5 | 5 | ✓ |
| 0 | 1 | [5,3] | 5 AND 3 = 1 | 3 | ✗ |
| 0 | 2 | [5,3,1] | 1 AND 1 = 1 | 1 | ✓ |
| 0 | 3 | [5,3,1,2] | 1 AND 2 = 0 | 1 | ✗ |
| 1 | 1 | [3] | 3 | 3 | ✓ |
| 1 | 2 | [3,1] | 3 AND 1 = 1 | 1 | ✓ |
| 1 | 3 | [3,1,2] | 1 AND 2 = 0 | 1 | ✗ |
| 2 | 2 | [1] | 1 | 1 | ✓ |
| 2 | 3 | [1,2] | 1 AND 2 = 0 | 1 | ✗ |
| 3 | 3 | [2] | 2 | 2 | ✓ |

各行计数为 $2 + 2 + 1 + 1 = 6$，与示例输出一致。注意第 0 行：$r=1$ 失配后 $r=2$ 又重新相等，若在 $r=1$ 处剪枝就会漏掉 `[5,3,1]`。

## 4. 算法细节

1. **初值就设在 $r = l$**：内层起点取 `cur_and = cur_min = nums[l]`，单元素区间自动满足 AND = min，无需在外层再单独 `ans += 1`，少一处可能漏写的分支。
2. **「先更新、后判定」的顺序**：第 $r$ 轮必须先把 $nums[r]$ 吸收进两个变量再比较，否则比较的是 $[l, r-1]$ 的旧值。`r > l` 的判断只是为了不重复吸收首元素。
3. **内层绝不剪枝**：`AND < min` 既不是终止条件，也不是「之后永远不相等」的信号（见 3.2 观察三）。
4. **取最小的写法**：`cur_min = min(cur_min, nums[r])` 与 `if (nums[r] < cur_min) cur_min = nums[r];` 等价；前者短、后者在 Python 里少一次函数调用，本题规模下两者无差别。
5. **类型选择**：$nums[i] \le 100$，AND 与 min 都在 $[0, 100]$；答案上界 $5050$，`int` 足够。若换成 $n = 10^5$ 的 II 题，答案可达 $5 \times 10^9$，必须 `long long`（Python 无此问题）。
6. **接口名**：按题目给出的签名写 `int countConsistent(vector<int>& nums)` / `countConsistent(self, nums: list[int]) -> int`，C++ 用引用传参避免拷贝。
7. **闭区间下标**：$[l, r]$ 两端都含，Python 写 `range(l, n)`；若写成 `range(l + 1, n)`，单元素区间就全丢了。

## 5. 正确性证明

**引理 1（按位与不超过最小值）**：对任意非空非负整数集合 $S$，有 $\mathrm{AND}(S) \le \min S$。

**证明**：设 $a = \mathrm{AND}(S)$，$m = \min S \in S$。按位看，$a$ 的第 $k$ 位为 1 当且仅当 $S$ 中所有元素的第 $k$ 位都为 1，故 $a$ 的 1 比特集合是 $m$ 的 1 比特集合的子集。把 $m$ 中不在 $a$ 里的比特逐个清零即得到 $a$，每清一位数值只减不增，故 $a \le m = \min S$。∎

**引理 2（增量维护正确）**：内层第 $r$ 轮判定之前，恒有 $cur\_and = \mathrm{AND}(nums[l..r])$、$cur\_min = \min(nums[l..r])$。

**证明**：对 $r$ 归纳。$r = l$ 时二者初始化为 $nums[l]$，与 $[l,l]$ 的 AND、min 相同。设第 $r-1$ 轮判定前成立。第 $r$ 轮先做 $cur\_and \leftarrow cur\_and \ \mathrm{AND}\ nums[r]$，由归纳假设即 $\mathrm{AND}(nums[l..r-1]) \ \mathrm{AND}\ nums[r]$，而按位与满足结合律，等于 $\mathrm{AND}(nums[l..r])$；同理 $cur\_min \leftarrow \min(cur\_min, nums[r]) = \min(nums[l..r])$。故第 $r$ 轮判定前成立。∎

**引理 3（不能提前终止）**：存在数据使得某个 $r$ 处不相等，而更大的 $r$ 处相等。

**证明**：取 $nums = [6,3,2]$、$l = 0$。$r = 1$ 时 AND 为 $6 \ \mathrm{AND}\ 3 = 2$、min 为 3，$2 < 3$ 不一致；$r = 2$ 时 AND 为 $2 \ \mathrm{AND}\ 2 = 2$、min 为 2，相等。故「一旦不相等就跳出内层」会漏掉 $[0,2]$。∎

**定理**：算法返回的值恰为 `nums` 中一致子数组的个数。

**证明**：外层枚举全部 $n$ 个左端点、内层枚举 $r \in [l, n-1]$，故恰好遍历全部 $\frac{n(n+1)}{2}$ 个非空子数组，每个区间只访问一次，不重不漏。对每个区间，引理 2 保证两个变量的值正确；由引理 1 知 $cur\_and \le cur\_min$ 恒成立，故判定式 `cur_and == cur_min` 与「按位与等于最小值」等价——这正是「一致」的定义，计数条件准确。引理 3 说明内层不会因暂时不相等而提前退出，因此每个右端点都被考察。综上，计数结果与题目定义完全一致。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n^2)$。内层共执行 $\frac{n(n+1)}{2}$ 轮，每轮为一次按位与、一次取最小、一次比较，均为 $O(1)$；$n = 100$ 时最多 5050 轮，远低于任何时限。
- **空间复杂度**：$O(1)$。除计数器与两个游标变量外不需要额外空间，不申请与 $n$ 相关的数组（不计输入本身）。
- **与朴素做法对比**：朴素做法每个区间重扫，约 $1.7 \times 10^5$ 次元素访问；本做法把每个区间的代价摊成 $O(1)$，常数极小。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int countConsistent(vector<int>& nums) {
        int n = (int)nums.size();
        int ans = 0;
        for (int l = 0; l < n; ++l) {
            int curAnd = nums[l];
            int curMin = nums[l];              // 单元素区间天然一致
            for (int r = l; r < n; ++r) {
                if (r > l) {                   // 先吸收新元素，再判定
                    curAnd &= nums[r];
                    curMin = min(curMin, nums[r]);
                }
                if (curAnd == curMin) ++ans;   // 只需判断相等
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def countConsistent(self, nums: list[int]) -> int:
        n = len(nums)
        ans = 0
        for l in range(n):
            cur_and = nums[l]
            cur_min = nums[l]                  # 单元素区间天然一致
            for r in range(l, n):
                if r > l:                      # 先吸收新元素，再判定
                    cur_and &= nums[r]
                    cur_min = min(cur_min, nums[r])
                if cur_and == cur_min:         # 只需判断相等
                    ans += 1
        return ans
```

## 8. 边界情况与易错点

1. **单元素数组**：$n = 1$ 时唯一子数组的 AND 与 min 都是 $nums[0]$，答案必为 1；把初值设在 $r = l$ 的写法天然覆盖，无需特判。
2. **全 0 数组**：任意区间的 AND 与 min 都是 0，答案就是 $\frac{n(n+1)}{2}$（$n=100$ 时为 5050）。别把 0 当成「未赋值」而跳过初值。
3. **含 0 的数组**：0 是按位与的吸收元，$[1,2]$ 的 AND 为 0 而 min 为 1，所以「AND 等于 0」并不等于一致。
4. **提前 break 会漏解**：$[6,3,2]$ 说明 AND < min 之后仍可能重新相等；一旦剪枝，答案会偏小。
5. **min 的初值必须取 $nums[l]$**：不能拿 0 当「空值」哨兵（元素可以为 0，全正数组上直接算错）；若习惯用 `INT_MAX` 起手，也要在 $r = l$ 时立刻吸收首元素。
6. **答案类型**：$n = 100$ 时上界 5050 在 `int` 内；若把规模放大到 $10^5$（II 题），答案需要 64 位整数。
7. **区间端点**：内层是 `l … n-1`，写成 `l+1 … n` 会同时漏掉单元素区间并越界。
