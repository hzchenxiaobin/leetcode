# LeetCode 参加考试的最大学生数 题解

## 1. 题目概述

- **标题 / 题号**：参加考试的最大学生数（#1349，hard）
- **链接**：https://leetcode.cn/problems/maximum-students-taking-exam/
- **来源**：LeetCode 第 175 场周赛 Q4
- **难度**：困难
- **标签**：位运算、数组、动态规划、状态压缩、矩阵、二分图、最大匹配、最小割、最大流、网络流

**题意**：给出 $m \times n$ 的座位表 `seats`，`'#'` 是坏座位（不能坐人），`'.'` 是可用座位。学生能偷看**左侧、右侧、左上、右上**四个方向上紧邻的同学，但看不到正前方与正后方（即同一列上下相邻的两人互不影响）。要求在可用座位上安排尽量多的学生，使**任意两人都互相看不到**，返回最多人数。

换句话说，被选中的格子集合必须满足：同一行内相邻两列不同时选，相邻两行之间也不允许对角相邻；而同一列上下相邻是允许的。

**约束**：

- $1 \le m \le 8$，$1 \le n \le 8$，座位表最多 $8 \times 8 = 64$ 格
- `seats` 只含字符 `'.'` 与 `'#'`
- 官方提示：第 $i$ 行的学生只会看到第 $i+1$ 行的答卷；于是用「(当前行, 上一行坐了人的比特掩码)」做 DP

## 2. 示例

**示例 1**

```text
输入：seats = [["#",".","#","#",".","#"],
               [".","#","#","#","#","."],
               ["#",".","#","#",".","#"]]
输出：4
解释：让第 0、2 行的第 1、4 列坐人（第 1 行留空），四人互相看不到。
```

**示例 2**

```text
输入：seats = [[".","#"],["#","#"],["#","."],["#","#"],[".","#"]]
输出：3
解释：三个可用座位两两都不同行相邻、也不同行对角相邻，可以全部坐满。
```

**示例 3**

```text
输入：seats = [["#",".",".",".","#"],
               [".","#",".","#","."],
               [".",".","#",".","."],
               [".","#",".","#","."],
               ["#",".",".",".","#"]]
输出：10
解释：让学生坐在第 1、3、5 列（1 起）的可用座位上，每行分别 1、3、2、3、1 人。
```

## 3. 解题思路

### 3.1 暴力思路

最朴素的做法是枚举「每个可用座位坐或不坐」，共 $2^{k}$ 种方案（$k$ 为可用座位数，最多 64），每种方案 $O(mn)$ 检查冲突，总计 $2^{64}$ 量级；即便改成「按行枚举 $2^n$ 种掩码再拼接」，方案数仍是 $(2^n)^m = 2^{nm} \le 2^{64}$，同样爆炸。但对本问题有一个关键的结构性事实：**隔了一行的人根本看不到彼此**，于是问题从「全局子集选择」变成「逐行递推」，每行只需和上一行对齐。

### 3.2 核心观察：冲突只在同一行与相邻两行 → 按行状压 DP

![视野与冲突模型](images/wc175_q4_conflict_model.svg)

把第 $r$ 行「哪些列坐了人」编码成整数掩码 $s$（bit $j$ = 1 表示第 $j$ 列坐人）。三种约束都可以用位运算表达：

1. **只能坐在可用座位上**：$s \subseteq \text{avail}[r]$，即 $s \,\&\, \text{avail}[r] = s$。
2. **行内不能左右相邻**：$s \,\&\, (s \ll 1) = 0$（等价于 $s \,\&\, (s \gg 1) = 0$）。
3. **相邻两行不能对角相邻**：对上一行掩码 $p$ 与本行掩码 $s$，要求 $s \,\&\, (p \ll 1) = 0$ 且 $s \,\&\, (p \gg 1) = 0$；合并成一条即 $s \,\&\, ((p \ll 1) \mid (p \gg 1)) = 0$。

> 💡 注意第 3 条里 $p$ 本身**不**参与掩码：同一列上下相邻（正前方/正后方）不在视野内，这正是本题与「皇后/车」类问题最大的区别，也是最容易写错的一步。

满足 1、2 的掩码称为**行合法掩码**。$n$ 列时个数是 $F_{n+2}$（斐波那契数）：$n=6$ 有 21 个，$n=8$ 只有 55 个，远小于 $2^n = 256$。于是「当前行状态 × 上一行状态」的枚举量是 $55 \times 55$ 量级，$m=8$ 时也不过两万多次转移。

因为第 $r$ 行只与第 $r-1$ 行冲突，**第 $r-2$ 行的信息可以安全丢弃**，状态只需保留「上一行的掩码」，于是有了

$$dp[r][s] = \operatorname{popcount}(s) + \max_{\substack{p \text{ 行合法} \\ s \,\&\, ((p \ll 1) \mid (p \gg 1)) = 0}} dp[r-1][p]$$

### 3.3 算法流程与状态转移

![两重合法性检查与状态转移](images/wc175_q4_mask_transition.svg)

**状态定义**：$dp[r][s]$ 表示「第 $0 \sim r$ 行都已安排完，且第 $r$ 行恰好坐了掩码 $s$」时的最大人数；不可达状态记为 $-1$。

**初始化**：把第 $-1$ 行视为空行，$dp[-1][0] = 0$，其余为 $-1$。

**转移**：对第 $r$ 行，枚举所有行合法且 $s \subseteq \text{avail}[r]$ 的 $s$，再枚举上一行的所有可行状态 $p$，只保留满足对角条件的 $p$，取 $dp[r-1][p]$ 的最大值，加上 $\operatorname{popcount}(s)$ 得到 $dp[r][s]$。

**答案**：$\max_s dp[m-1][s]$。最后一行之外没有学生，所以取该行所有可达状态的最大值，而不是某个固定状态。

整体流程是四步：枚举本行掩码 → 检查是否全落在可用座位上 → 检查行内不左右相邻 → 与上一行的所有状态比对并累加人数。

### 3.4 示例演算

![示例 1 的逐行走查](images/wc175_q4_walkthrough.svg)

以示例 1 为例（$m=3$，$n=6$，列号 0 起）：第 0、2 行的可用列是 $\{1,4\}$，第 1 行的可用列是 $\{0,5\}$。

| 行 | 可用列 | 该行掩码 → $dp$ 值 | 该行最大 |
|----|--------|--------------------|----------|
| $r=0$ | $\{1,4\}$ | $\varnothing \to 0$，$\{1\} \to 1$，$\{4\} \to 1$，$\{1,4\} \to 2$ | 2 |
| $r=1$ | $\{0,5\}$ | $\varnothing \to 2$，$\{0\} \to 2$，$\{5\} \to 2$，$\{0,5\} \to 2$ | 2 |
| $r=2$ | $\{1,4\}$ | $\varnothing \to 2$，$\{1\} \to 3$，$\{4\} \to 3$，$\{1,4\} \to 4$ | **4** |

看点在第 1 行：$\{0,5\}$ 一次坐满两人，但它与第 0 行的 $\{1,4\}$ 全部对角冲突（0 对 1、5 对 4），只能接在空行之后，只得 2；而第 2 行的 $\{1,4\}$ 正需要第 1 行留空，于是 $\{1,4\} \to \varnothing \to \{1,4\}$ 这条路径拿到 $2+0+2=4$，正是最优解。

## 4. 算法细节

1. **可用掩码预处理**：把每行的 `'.'` 位置置 1 得到 $\text{avail}[r]$。转移时用 $s \,\&\, \text{avail}[r] = s$ 判子集，避免对每个格子单独判断。
2. **行合法掩码表**：先对 $0 \le s < 2^n$ 筛出 $s \,\&\, (s \ll 1) = 0$ 的掩码缓存成数组，每行只在这个数组里枚举。
3. **对角检查合并成一个掩码**：$\text{ban} = (p \ll 1) \mid (p \gg 1)$，只需一次与运算。注意 $p \ll 1$ 会越过第 $n$ 位，但在 `int` 范围内不影响结果（越界位不可能与 $s$ 相交）。
4. **不把 $p$ 本身并入 ban**：正上下相邻不算冲突，写成 $(p \ll 1) \mid p \mid (p \gg 1)$ 会把合法的「同列相邻」也禁掉，答案偏小。
5. **不可达状态与滚动数组**：用 $-1$ 表示不可达，取 `max` 前先判 $dp[r-1][p] \ge 0$；$s = 0$ 与任何 $p$ 都兼容，故第 0 行总有状态可达。只需上一行与当前行两个长度 $2^n$ 的数组，每行 `fill` 重置后交换。
6. **答案取值**：$m-1$ 行所有可达状态的最大值；不要只读 $dp[m-1][0]$（那意味着最后一行空着，通常不是最优）。

## 5. 正确性证明

**引理 1（行内合法性的掩码刻画）**：一行掩码 $s$ 在可用座位 $\text{avail}$ 上不违反「左右相邻」规则 $\iff$ $s \subseteq \text{avail}$ 且 $s \,\&\, (s \ll 1) = 0$。

**证明**：$s \subseteq \text{avail}$ 显然等价于每个人都坐在可用座位上。若某位 $j$ 与 $j+1$ 同时为 1，则 $s \,\&\, (s \ll 1)$ 的第 $j+1$ 位为 1，反之若该式非零，设其最低为 1 的位是 $j+1$，则 $s$ 的第 $j$、$j+1$ 位同时为 1，即存在左右相邻的两人。故二者等价。∎

**引理 2（跨行冲突的掩码刻画）**：上一行掩码 $p$ 与当前行掩码 $s$ 不存在对角相邻的学生对 $\iff$ $s \,\&\, (p \ll 1) = 0$ 且 $s \,\&\, (p \gg 1) = 0$。

**证明**：$p \ll 1$ 的第 $j+1$ 位等于 $p$ 的第 $j$ 位。因此 $s \,\&\, (p \ll 1) \ne 0$ 当且仅当存在 $j$ 使 $p$ 在第 $j$ 列有人且 $s$ 在第 $j+1$ 列有人，即 $(r-1,j)$ 与 $(r,j+1)$ 是右上-左下的对角对。同理 $s \,\&\, (p \gg 1) \ne 0$ 当且仅当存在 $(r-1,j+1)$ 与 $(r,j)$ 的对角对。两条都为 0 恰好排除了所有对角对。∎

**引理 3（局部性）**：若每一对相邻行都满足引理 1 与引理 2，则整个安排合法。

**证明**：任取两名学生，设其行号为 $r_1 \le r_2$。若 $r_1 = r_2$，由引理 1 二者不相邻，不会互相看到。若 $r_2 - r_1 \ge 2$，视野只覆盖紧邻的左右与上下相邻行，故二者互相看不到，无冲突。若 $r_2 = r_1 + 1$，由引理 2 二者不是对角对；又因为不同行，不可能左右相邻，也不可能是同一列（同一列不算冲突），故无冲突。综上任意两人都不冲突。∎

**定理（DP 正确性）**：对每个 $r$ 与每个行合法掩码 $s$，$dp[r][s]$ 恰好等于「前 $r+1$ 行安排完毕、第 $r$ 行坐法为 $s$」时的最大人数；因此 $\max_s dp[m-1][s]$ 就是题目所求。

**证明**：对 $r$ 归纳。$r=0$ 时空行没有任何约束，$dp[0][s] = \operatorname{popcount}(s)$，正确。

设 $r-1$ 行结论成立。任取一个前 $r+1$ 行合法、第 $r$ 行掩码为 $s$ 的安排，其第 $r-1$ 行掩码记为 $p$。截掉第 $r$ 行后，前 $r$ 行仍满足引理 1、2（约束只会变少），故该安排的人数 $\le dp[r-1][p] + \operatorname{popcount}(s)$，且由引理 2，$s \,\&\, ((p \ll 1) \mid (p \gg 1)) = 0$，所以 $p$ 在转移的候选集合中，人数 $\le dp[r][s]$。

反过来，取达到 $dp[r][s]$ 的那个 $p$ 及其对应的合法安排（存在性由归纳假设保证），在末尾拼接第 $r$ 行的 $s$。新拼接的两行满足引理 1、2；而前面的行对仍然满足，由引理 3 整体合法，人数正好是 $dp[r-1][p] + \operatorname{popcount}(s) = dp[r][s]$。

两个方向合起来，$dp[r][s]$ 就是最大值。最后一行之外没有学生，故全局最优为 $\max_s dp[m-1][s]$。∎

## 6. 复杂度分析

- **时间**：设 $V = F_{n+2}$ 为行合法掩码个数（$n \le 8$ 时 $V \le 55$）。预处理 $O(mn + 2^n)$；每行枚举 $V$ 个当前掩码、每个扫 $V$ 个上一行掩码，共 $O(m V^2)$，最坏 $8 \times 55^2 \approx 2.4 \times 10^4$ 次位运算。若不做掩码预筛选、直接枚举 $0 \sim 2^n$，则为 $O(m \cdot 4^n) \approx 5 \times 10^5$，同样能过。
- **空间**：滚动数组两个长度 $2^n$ 的整型数组，加行合法掩码表，$O(2^n)$，$n=8$ 时不到 1 KB。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <algorithm>

using namespace std;

class Solution {
public:
    int maxStudents(vector<vector<char>>& seats) {
        int m = (int)seats.size(), n = (int)seats[0].size();

        // 行合法掩码：没有左右相邻的两个 1
        vector<int> valid;
        for (int s = 0; s < (1 << n); s++)
            if ((s & (s >> 1)) == 0) valid.push_back(s);

        // 每行可用座位掩码
        vector<int> avail(m, 0);
        for (int i = 0; i < m; i++)
            for (int j = 0; j < n; j++)
                if (seats[i][j] == '.') avail[i] |= 1 << j;

        vector<int> prev(1 << n, -1), cur(1 << n, -1);
        prev[0] = 0;                       // 第 -1 行视为空行

        for (int i = 0; i < m; i++) {
            fill(cur.begin(), cur.end(), -1);
            for (int s : valid) {
                if ((s & avail[i]) != s) continue;   // 有人坐在坏座位上
                int best = -1;
                int ban = 0;
                for (int p : valid) {
                    if (prev[p] < 0) continue;       // 上一行不可达
                    ban = (p << 1) | (p >> 1);       // 注意不含 p 本身
                    if ((s & ban) == 0) best = max(best, prev[p]);
                }
                if (best >= 0)
                    cur[s] = best + __builtin_popcount((unsigned)s);
            }
            prev.swap(cur);
        }

        int ans = 0;
        for (int s = 0; s < (1 << n); s++) ans = max(ans, prev[s]);
        return ans;
    }
};
```

### Python

```python
from typing import List


class Solution:
    def maxStudents(self, seats: List[List[str]]) -> int:
        m, n = len(seats), len(seats[0])

        # 每行可用座位掩码
        avail = []
        for row in seats:
            mask = 0
            for j, ch in enumerate(row):
                if ch == '.':
                    mask |= 1 << j
            avail.append(mask)

        # 行合法掩码：没有左右相邻的两个 1
        valid = [s for s in range(1 << n) if (s & (s << 1)) == 0]

        prev = {0: 0}                      # 第 -1 行视为空行
        for r in range(m):
            cur = {}
            for s in valid:
                if (s & avail[r]) != s:    # 有人坐在坏座位上
                    continue
                best = -1
                for p, val in prev.items():
                    # 左上 / 右上都不能有人（正上下可以）
                    if (s & ((p << 1) | (p >> 1))) == 0:
                        if val > best:
                            best = val
                if best >= 0:
                    cur[s] = best + bin(s).count('1')
            prev = cur

        return max(prev.values())
```

## 8. 边界情况与易错点

1. **整行都是坏座位**：该行只有 $s=0$ 合法，且 $0$ 与任何 $p$ 都兼容，人数不增；只要初始 $dp[-1][0]=0$，就不会出现「整行不可达」。
2. **$n=1$**：既没有左右相邻也没有对角相邻，答案是该列可用座位数（每行至多 1 人）。此时 $p \ll 1$ 把唯一的第 0 位移出有效位、$p \gg 1 = 0$，转移自然放行，不需要特判。
3. **$m=1$**：只需在该行内挑最大独立集，答案等于可选掩码的最大 $\operatorname{popcount}$；注意答案要对最后一行取 $\max$，不能读成 $dp[m-1][0]$。
4. **正上下不做禁用**：把 $p$ 本身并进 ban 掩码是本题最常见的错误，会漏掉「同列相邻」的合法坐法（示例 3 的第 1、3、5 列就是同列相邻）。
5. **只漏一个对角方向**：只写 $s \,\&\, (p \ll 1)$ 而漏掉 $s \,\&\, (p \gg 1)$ 会多算人数；用合并掩码可一次写对。
6. **位宽与越界**：$p \ll 1$ 可跨过第 $n$ 位，但不会与 $s$ 相交（$s$ 只有低 $n$ 位为 1），因此无需掩掉高位；若改用 `unsigned char` 等窄类型则要小心截断。
7. **自测数据**：$8 \times 8$ 全为 `'.'` 时答案应为 32（隔行、隔列交错坐），可作为 sanity check；全为 `'#'` 时答案 0。

**延伸思考**：本题其实还存在一个**不需要状压**的多项式解法。把每个可用座位看作点，冲突关系看作边（同行左右相邻、邻行对角相邻）。注意每条冲突边都会让**列号变化 $\pm 1$**，因此按列号奇偶染色就得到一张**二分图**，所求即这张二分图的最大独立集，由 König 定理

$$\text{最大独立集} = |V| - \text{最大匹配}$$

其中 $|V|$ 是可用座位数。于是用 Kuhn 算法 $O(|V| \cdot |E|)$ 或 Hopcroft–Karp 即可求解，完全不必枚举 $2^n$ 个掩码；这在 $m, n$ 都取到 20 量级时会明显快于状压 DP。作为交叉验证，我在 $5 \times 5$ 以内的随机棋盘上把两种实现各跑了数百组，结果完全一致。

另一类自然的变体是**改变视野**：若允许看到正前方（同列相邻也冲突），只需在 ban 掩码里补上 $p$ 本身；若允许看到前两行的对角（跨度更大），状态就得升级为 $dp[r][s][p]$，同时记住两行掩码，转移代价从 $V^2$ 变成 $V^3$。这正是这类「按行递推 + 掩码」题目的通用扩展套路：**视野跨度决定要记住几行**。
