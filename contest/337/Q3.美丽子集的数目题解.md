# LeetCode 美丽子集的数目 题解

## 1. 题目概述

- **标题 / 题号**：美丽子集的数目（#2597，medium）
- **链接**：https://leetcode.cn/problems/the-number-of-beautiful-subsets/
- **来源**：LeetCode 第 337 场周赛 Q3
- **难度**：中等
- **标签**：数组、哈希表、回溯、排序、动态规划、组合数学

**题意**：给定正整数数组 `nums` 与正整数 $k$。若 `nums` 的某个子集中**任意两个**整数的绝对差都**不等于** $k$，则称其为**美丽子集**。返回**非空**美丽子集的数目。子集按下标区分：所选下标不同即为不同子集，即使元素值完全相同。

**约束**：

- $1 \le \text{nums.length} \le 18$
- $1 \le \text{nums[i]},\, k \le 1000$

> 💡 **两个信号**：① $n \le 18$，$2^n \le 262\,144$——子集枚举/回溯的甜区，赛场上这是「保底能过」的承诺；② 冲突条件 $|a-b| = k$ **只依赖两个元素的值**而与下标无关——这既是回溯 $O(1)$ 增量判冲突的钥匙，也是赛后升级到 $O(n\log n)$ DP 的入口。

## 2. 示例

**示例 1**

```text
输入：nums = [2,4,6], k = 2
输出：4
解释：美丽子集为 [2]、[4]、[6]、[2,6]。
      含相差 2 的对（[2,4]、[4,6]、[2,4,6]）的子集全部非法。
```

**示例 2**

```text
输入：nums = [1], k = 1
输出：1
解释：唯一非空子集 [1] 不含任何元素对，自动美丽。
```

**示例 3**（自造，覆盖「重复值 + 跨余类冲突」两个关键情况）

```text
输入：nums = [2,5,7,2], k = 5
输出：9
解释：7 与 2 冲突（差 5）；5 与任何数差都不为 5；两个 2 互不冲突（差 0 ≠ 5）。
      不含 7 的非空子集：在 {2a, 2b, 5} 中任取非空 → 2³ − 1 = 7 个；
      含 7 且不含任何 2：{7}、{5,7} → 2 个；合计 9。
```

## 3. 解题思路

### 3.1 暴力思路：枚举子集 + 逐对校验

枚举全部 $2^n$ 个下标子集，对每个子集枚举所有 $\binom{|S|}{2}$ 个数对检查 $|a-b| \ne k$。时间 $O(2^n \cdot n^2)$，$n = 18$ 时约 $8.5 \times 10^7$ 次比较——C++ 勉强可过，Python 有超时风险。更糟的是它是**纯浪费**：同一个前缀里的数对，在每个后缀方向上都被反复重验。既然冲突只与「值」有关，就该把「已选值的集合」作为状态**增量维护**，让每个新元素 $O(1)$ 完成判定。

### 3.2 核心观察：冲突只看值 + 遗传性

![核心观察：升序处理后，冲突只可能来自左边的 v−k](images/wc337_q3_one_sided_check.svg)

**观察一（冲突是值的性质）**：$|a - b| = k$ 只依赖两个元素的**值**。维护「当前已选值 → 份数」的计数表 $chosen[\cdot]$，判断新元素 $v$ 能否加入，只需看 $chosen[v-k]$ 与 $chosen[v+k]$ 是否非零——与选了哪些**下标**完全无关。

**观察二（排序 ⟹ 单侧检查）**：先把 `nums` **升序排序**，回溯处理到 $nums[i] = v$ 时，已选元素的值都 $\le v$。若 $v$ 与某个已选值冲突，对方只能是 $v - k$（$v + k > v$ 尚未被处理，必然未选）。于是**每步只查一次 $chosen[v-k]$**，$O(1)$ 完成判定。

**观察三（遗传性）**：美丽子集的任何子集仍然美丽——冲突对不会因为删元素而凭空出现。这条性质是回溯剪枝「不重不漏」的直觉来源：被剪掉的分支里全是非美丽子集，而美丽子集对应的路径从头到尾都能通过检查（§5 引理 2、引理 3）。

### 3.3 算法流程：排序 + 按下标回溯

![算法流程：每层决定一个下标的去留，选之前单侧查 chosen[v−k]](images/wc337_q3_backtrack_flow.svg)

```text
排序 nums（升序）
答案 = dfs(0) − 1                # dfs 统计含空集，末尾扣除

dfs(i)：
    若 i == n：return 1           # 当前已选集合本身即一个方案（含空集）
    res = dfs(i + 1)              # 分支一：不选 nums[i]
    v = nums[i]
    若 v − k < 1 或 chosen[v−k] == 0：   # 升序下 v+k 必未选
        chosen[v] += 1            # 分支二：选 nums[i]
        res += dfs(i + 1)
        chosen[v] −= 1            # 回溯还原现场
    return res
```

每个下标在路径上恰被决定一次「选 / 不选」，故 `dfs(0)` = 回溯树存活叶子数 = 美丽子集数（**含空集**），减 1 即答案。全树至多 $2^{n+1} - 1 \approx 5.2\times10^5$ 个结点、每结点 $O(1)$，$n \le 18$ 下 C++ 微秒级、Python 几十毫秒级。

> 💡 **中场优化：按值去重 + 权重**。同值的多份与外部的冲突关系完全相同，可把决策树从「每下标一层」压缩成「每**值**一层」：对去重升序后的每个值 $v$，要么「整个跳过」，要么「取至少一份」——后者有 $2^{cnt[v]} - 1$ 种下标选法（同值两份差 $0 \ne k$，可共存）。重复元素越多树越小；无重复时与按下标版同规模。

### 3.4 示例演算

![示例演算：[2,4,6], k=2 的回溯决策树，2 个分支被剪、5 片叶存活](images/wc337_q3_backtrack_tree.svg)

以示例 1 为例（三值互异，按下标与按值决策一致），排序后依次决定值 $2, 4, 6$ 的去留：

| 决定序列（2→4→6） | 选时检查 | 叶子 | 计入 |
|---|---|---|---|
| 跳、跳、跳 | — | $\varnothing$ | 空集（最后扣除） |
| 跳、跳、选 6 | $6-2=4$ 未选 ✓ | $\{6\}$ | ✓ |
| 跳、选 4、跳 | $4-2=2$ 无此值 ✓ | $\{4\}$ | ✓ |
| 跳、选 4、选 6 | $6-2=4$ **已选** ✗ | — | 剪枝 |
| 选 2、跳、跳 | $2-2=0$ 无此值 ✓ | $\{2\}$ | ✓ |
| 选 2、跳、选 6 | $6-2=4$ 未选 ✓ | $\{2,6\}$ | ✓ |
| 选 2、选 4、… | $4-2=2$ **已选** ✗ | — | 剪枝（子树不再展开） |

`dfs(0) = 5` 片存活叶子，答案 $5 - 1 = 4$ ✓。注意「选 2 再选 4」在第二层就被剪掉，其下「跳 6 / 选 6」两条路径**根本不会展开**——这正是剪枝省时的来源。

### 3.5 复盘升级：冲突图是不相交的链 → $O(n\log n)$ DP

![复盘升级：按 v mod k 分组，组内成链，打家劫舍计数后乘起来](images/wc337_q3_chain_dp.svg)

赛后复盘还能更快。$|a - b| = k$ 意味着 $a \equiv b \pmod{k}$，**冲突边只存在于同一余类之内**；余类 $r$ 内的值按序为 $r, r+k, r+2k, \dots$，相邻差 $k$ 者连边，形成一条条**链**。链上「相邻值不可同取」正是 [198. 打家劫舍](https://leetcode.cn/problems/house-robber/) 的计数版：设组内升序去重值为 $vals$、频次 $cnt$、权重 $w = 2^{cnt[v]} - 1$，两状态滚动

$$f_0,\, f_1 = \text{组内上一值「未选 / 已选（至少一份）」的方案数}$$

- 跳过当前值：$f_0' = f_0 + f_1$；
- 取当前值：$gap = k$（链相邻，上一值必须未选）时 $f_1' = w \cdot f_0$；$gap \ne k$（断链，两段独立）时 $f_1' = w \cdot (f_0 + f_1)$。

各余类互不冲突，组方案数 $(f_0 + f_1)$ 依**乘法原理**相乘，最后扣全局空集：

$$\text{ans} = \prod_{\text{组}} \,(f_0 + f_1) \;-\; 1$$

> ⚠️ **为什么必须先分组？** 全局排序中同余类的两个值未必相邻：如 $nums = [2,4,5,6]$、$k = 2$ 时 $4$ 与 $6$ 冲突，中间却隔着余 $1$ 类的 $5$——只看「全局前驱」会漏检。按 $v \bmod k$ 分组、组内保持升序后，组内前驱当且仅当 $gap = k$ 时才是链上邻居。该 DP 的完整推导与逐状态演算见文末每日题解，此处作为复盘结论简述。

## 4. 算法细节

1. **排序是单侧检查的前提**：`chosen[v-k]` 这一次查询之所以充分，是因为升序保证已选值 $\le v$；若不排序，必须双侧查 $v \pm k$。
2. **两张表别混用**：`chosen[]` 记录**当前路径**已选各值的份数（进入 `+1`、回溯 `−1`）；输入频次表 `cnt` 是**静态**的，只用于按值版的权重 $(1 \ll cnt[v]) - 1$。把频次表当选择状态用，既误判冲突又算错权重。
3. **值域小用数组**：$1 \le nums[i] \le 1000$，`chosen` 开成 1001 的定长数组代替哈希表；$v - k < 1$ 时值域内不存在冲突方，直接放行（顺带防下标越界）。
4. **按值版仍只需单侧查**：去重值序列同样升序，已选值 $< v$，$v + k$ 必未选；写双侧 $v \pm k$ 是更稳健但冗余的写法。
5. **权重 $2^{cnt[v]} - 1$**：同值 $cnt$ 份中选**至少一份**的下标子集数；两份同值差 $0 \ne k$（$k \ge 1$）可共存，故不是 $cnt$ 而是 $2^{cnt[v]} - 1$，别漏「同值多份共选」。
6. **口径统一「含空、末尾减一」**：回溯 `dfs` 与 DP 每组都把「什么都不选」计入，乘积/计数后统一 $-1$ 扣全局空集，避免多处扣重或漏扣。
7. **DP 组内有序的免费保证**：全局升序遍历去重值、按 $v \bmod k$ 追加入组，各组天然升序，无需组内再排。

## 5. 正确性证明

**引理 1**（单侧检查等价）：升序处理到 $nums[i] = v$ 时，「$chosen[v-k] = 0$」与「$v$ 与所有已选元素均无冲突」等价。

**证明**：（⇒）设已选元素 $u$ 与 $v$ 冲突，则 $|v - u| = k$；排序保证 $u \le v$，故 $u = v - k$（$u = v + k$ 不可能，因 $u \le v < v+k$），即 $chosen[v-k] > 0$，矛盾。（⇐）$chosen[v-k] > 0$ 时存在已选值 $v-k$，与 $v$ 之差恰为 $k$，冲突。∎

**引理 2**（遗传性）：美丽子集的任何子集仍美丽。

**证明**：设 $T \subseteq S$ 且 $S$ 美丽。若 $T$ 含冲突对 $(a, b)$，则由 $T \subseteq S$ 知 $(a,b)$ 也是 $S$ 中的冲突对，与 $S$ 美丽矛盾。∎

**引理 3**（剪枝不重不漏）：
（a）**安全性**——被剪「选 $nums[i]$」分支中的任何子集都不美丽；
（b）**完备性**——美丽子集对应的回溯路径永不入剪。

**证明**：（a）剪枝发生当且仅当 $chosen[v-k] > 0$，即当前前缀已含值为 $v-k$ 的元素 $u$；该分支里的子集都包含前缀与 $nums[i]$，故都含冲突对 $(u,\, nums[i])$（差恰为 $k$），由引理 2 的逆否命题知它们不美丽。（b）设美丽子集 $S$ 的路径在某层决定选 $nums[i] = v$ 时检查失败，则前缀中存在值 $v-k$ 的元素 $u$；$u$ 与 $nums[i]$ 都属于 $S$ 且差为 $k$，即 $S$ 含冲突对，与 $S$ 美丽矛盾。∎

**定理**：`dfs(0) − 1` 等于非空美丽子集的数目。

**证明**：回溯树中每条根到叶的路径对第 $0 \sim n-1$ 层各做一个「选 / 不选」决定，故存活路径与「全程通过检查的下标子集」一一对应。一方面，存活叶子上的已选集合美丽：它由空集逐个加入元素构成，每次加入前经引理 1 的等价检查确认与所有已选元素无冲突，任一潜在冲突对都会在较后元素加入时被检出（归纳，中间态是其子集，由引理 2 亦为美丽部分解）。另一方面，每个美丽子集的路径由引理 3(b) 保证存活。故 `dfs(0)` = 美丽子集数（含空集；「全跳」路径不做任何检查、必然存活），减 1 即非空数目。∎

**推论**（无冲突上界）：若数组中不存在值差恰为 $k$ 的两个元素（特别地，$k > \max(nums) - \min(nums)$），答案 $= 2^n - 1$。

**证明**：此时任意子集都无冲突对，全部 $2^n$ 个子集美丽，非空者 $2^n - 1$ 个。∎

## 6. 复杂度分析

- **时间复杂度**：主解 $O(n \log n + 2^n)$——排序 + 回溯树至多 $2^{n+1} - 1 \approx 5.2 \times 10^5$ 个结点（$n = 18$），每结点 $O(1)$（一次数组读写 + 常数次递归调用）。按值去重版叶子至多 $2^m$（$m$ 为去重值数），重复元素越多越小。复盘 DP 为 $O(n \log n)$：排序分组 + 一遍线性转移。
- **空间复杂度**：回溯 $O(n)$ 递归栈 + $O(V)$ 计数表（$V = 1001$，值域固定可视为常数）；DP $O(n)$ 存各组去重值。
- **数值范围**：答案上界 $2^{18} - 1 = 262\,143$，`int` 足够，全程无取模——这是与「子集计数取模题」的关键区别。

## 7. 参考代码

### C++（主解：排序 + 按下标回溯，单侧检查）

```cpp
class Solution {
public:
    int beautifulSubsets(vector<int>& nums, int k) {
        sort(nums.begin(), nums.end());
        vector<int> chosen(1001);              // chosen[v]：当前路径已选值 v 的份数
        return dfs(nums, k, chosen, 0) - 1;
    }
private:
    int dfs(vector<int>& nums, int k, vector<int>& chosen, int i) {
        if (i == (int)nums.size()) return 1;   // 当前已选集合本身（含空集）
        int res = dfs(nums, k, chosen, i + 1); // 不选 nums[i]
        int v = nums[i];
        if (v - k < 1 || chosen[v - k] == 0) { // 升序下 v+k 必未选
            ++chosen[v];                       // 选 nums[i]
            res += dfs(nums, k, chosen, i + 1);
            --chosen[v];                       // 回溯还原
        }
        return res;
    }
};
```

### C++（优化：按值去重回溯 + 权重 $2^{cnt}-1$）

```cpp
class Solution {
public:
    int beautifulSubsets(vector<int>& nums, int k) {
        map<int, int> cnt;                           // 值 → 输入频次（静态）
        for (int x : nums) ++cnt[x];
        vector<int> vals;
        for (auto& p : cnt) vals.push_back(p.first);  // map 天然升序
        unordered_set<int> selected;                 // 当前路径已选的「值」
        function<long long(int)> dfs = [&](int i) -> long long {
            if (i == (int)vals.size()) return 1;
            int v = vals[i];
            long long res = dfs(i + 1);              // 整个跳过值 v
            if (!selected.count(v - k) && !selected.count(v + k)) {
                selected.insert(v);                  // 取 v（至少一份）
                res += ((1LL << cnt[v]) - 1) * dfs(i + 1);
                selected.erase(v);
            }
            return res;
        };
        return dfs(0) - 1;
    }
};
```

### Python（主解：排序 + 按下标回溯）

```python
class Solution:
    def beautifulSubsets(self, nums: List[int], k: int) -> int:
        nums.sort()
        n = len(nums)
        chosen = [0] * 1001          # chosen[v]：当前路径已选值 v 的份数

        def dfs(i: int) -> int:
            if i == n:
                return 1             # 当前已选集合本身（含空集）
            res = dfs(i + 1)         # 不选 nums[i]
            v = nums[i]
            if v - k < 1 or chosen[v - k] == 0:   # 升序下 v+k 必未选
                chosen[v] += 1       # 选 nums[i]
                res += dfs(i + 1)
                chosen[v] -= 1       # 回溯还原
            return res

        return dfs(0) - 1
```

### Python（复盘升级：余类分组链 DP，$O(n\log n)$）

```python
class Solution:
    def beautifulSubsets(self, nums: List[int], k: int) -> int:
        from collections import Counter, defaultdict
        cnt = Counter(nums)
        groups = defaultdict(list)
        for v in sorted(cnt):                    # 全局升序入组，组内天然有序
            groups[v % k].append(v)
        ans = 1
        for vals in groups.values():
            # f0/f1：组内当前值「未选 / 已选（至少一份）」的方案数
            f0, f1 = 1, (1 << cnt[vals[0]]) - 1
            for a, b in zip(vals, vals[1:]):     # a=前值，b=当前值
                w = (1 << cnt[b]) - 1
                f0, f1 = (f0 + f1,
                          w * f0 if b - a == k else w * (f0 + f1))
            ans *= f0 + f1                       # 余类互不冲突 → 乘法原理
        return ans - 1                           # 扣全局空集
```

## 8. 边界情况与易错点

1. **忘减 1 扣空集**（最高频 WA）：`dfs(0)` 与 DP 乘积都含空集，末尾必须 $-1$。
2. **不排序就只查 $v-k$**：单侧检查的前提是升序（已选值 $\le v$）；未排序必须双侧查 $v \pm k$。
3. **两张表混用**：`chosen` 是「当前路径选择状态」（回溯要 $\pm 1$），输入频次 `Counter` 是静态权重来源，职责不同，混用即错。
4. **重复值权重**：同值 $cnt$ 份可共存（差 $0 \ne k$），按值版权重是 $2^{cnt} - 1$ 而非 $cnt$，否则漏掉「同值多份共选」（示例 3 的两个 2）。
5. **DP 全局前驱陷阱**：$[2,4,5,6]$、$k=2$ 中 $4$、$6$ 冲突却被 $5$ 隔开——必须按 $v \bmod k$ 分组后组内看前驱，只看全局排序前驱必 WA。
6. **无冲突哨兵**：$k > \max(\text{nums}) - \min(\text{nums})$ 时无任何冲突，答案 $= 2^n - 1$（§5 推论），适合当对拍用例。
7. **最小输入**：$n = 1$ 答案恒为 1（单元素无对）。
8. **下标越界**：`chosen[v-k]` 须在 $v - k \ge 1$ 时才可访问；值域 $[1,1000]$，数组开 1001 即可，`v+k` 永远不查、无需扩容。
9. **C++ 成员状态残留**（隐蔽 WA）：LeetCode 会用**同一个** `Solution` 实例连续跑多个用例，把 `cnt`/`vals` 存成成员变量又不在入口清空，第二个用例就带着上一例的旧状态计算（实测 $[2,4,6]$ 后接 $[1]$ 会错成 95）。参考代码全部用局部状态 + 递归 lambda，天然免疫。

- [LeetCode 2638. 统计 K-Free 子集的总数](https://leetcode.cn/problems/count-the-number-of-k-free-subsets/)：元素互异 + 空集计入的镜像题（本站 `solution/2601-2700/` 有题解），对照频次与空集口径的处理。

**延伸思考**：若把「差 $\ne k$」加强为「差不是 $k$ 的倍数」，同余类内**任意**两值都冲突（类内成完全图），每类至多取一个值，答案变成 $\prod_r \bigl(1 + \sum_{v \equiv r \,( \mathrm{mod}\ k)} (2^{cnt[v]}-1)\bigr) - 1$；若改问「恰好含 $t$ 个元素的美丽子集数」，链 DP 需再卷上元素个数一维（生成函数视角：每个值贡献 $(1 + w\,x)$，链上转移做多项式卷积）。本题在 `solution/2501-2600/` 另有一篇每日题解（主推余类分组链 DP 的 $O(n\log n)$ 视角与逐状态演算），可对照阅读。
