# LeetCode 奇偶位数 题解

## 1. 题目概述

- **标题 / 题号**：奇偶位数（#2595，easy）
- **链接**：https://leetcode.cn/problems/number-of-even-and-odd-bits/
- **来源**：LeetCode 第 337 场周赛 Q1
- **难度**：简单
- **标签**：位运算

**题意**：给定正整数 $n$。在 $n$ 的二进制表示中，位下标**从 0 开始、从右往左**递增（最右位是下标 0）。统计值为 $1$ 的位里，落在**偶数下标**的个数 `even` 与落在**奇数下标**的个数 `odd`，返回 `[even, odd]`。

**约束**：

- $1 \le n \le 1000$，即 $n < 2^{10}$，二进制至多 10 位（下标 $0 \sim 9$）

> 💡 **读题第一件事**：把"下标从右往左"圈出来——这是本题唯一的坑。第 $i$ 位就是 $2^i$ 那一位，与位运算里 `n >> i & 1` 的语义天然对齐。

## 2. 示例

**示例 1**

```text
输入：n = 50
输出：[1, 2]
解释：50 的二进制表示是 110010。
      下标 1、4、5 处的值为 1：
      even = 1（下标 4），odd = 2（下标 1、5）。
```

**示例 2**

```text
输入：n = 2
输出：[0, 1]
解释：2 的二进制表示是 10。只有下标 1 处的值为 1。
      even = 0，odd = 1。
```

**示例 3**（覆盖数据范围上界）

```text
输入：n = 1000
输出：[2, 4]
解释：1000 = 1111101000₂，为 1 的下标是 3、5、6、7、8、9。
      偶数下标：6、8 → even = 2；奇数下标：3、5、7、9 → odd = 4。
```

## 3. 解题思路

### 3.1 签到最短路径：转字符串数下标

赛场上的第一反应往往是 `bin(n)[2:]` 得到 `"110010"`，然后 `enumerate` 数下标。但注意：**字符串下标 0 在最左，而题目位下标 0 在最右**——必须先反转再枚举，否则 `even` 与 `odd` 恰好整体互换。这是本题最常见的罚时来源。

```python
b = bin(n)[2:][::-1]   # 反转后，字符串下标 == 位下标
even = sum(1 for i, c in enumerate(b) if c == '1' and i % 2 == 0)
odd  = sum(1 for i, c in enumerate(b) if c == '1' and i % 2 == 1)
```

时间 $O(B)$、空间 $O(B)$（$B$ 为二进制位数，$B \le 10$）。完全能过，但多了一次字符串构造，且"反转"这一步只要忘了就 WA。

### 3.2 核心观察：第 $i$ 位就是 `(n >> i) & 1`

![核心观察：位下标从右往左数，偶/奇位交错](images/wc337_q1_bit_index_concept.svg)

**关键直觉**：题目定义的"下标从右往左、从 0 开始"正是位运算的标准约定——第 $i$ 位就是 $2^i$ 那一位。于是不需要任何字符串：

- `n & 1` 取出**当前最低位**（即当前轮次对应下标的位）；
- `n >>= 1` 丢弃它，让下一位对齐到最低位；
- 轮次计数器 `i` 每轮 `+1`，与位下标**天然同步**，`i % 2` 即该位的奇偶。

再进一步：偶数下标位与奇数下标位在二进制中**交错排列**，可以用两把"梳子掩码"一步分离（`0x55555555 = 0101…0101` 选偶位，`0xAAAAAAAA = 1010…1010` 选奇位），按位与后各做一次 **popcount** 即得答案。本题 $n \le 1000$，两种写法都是常数级，移位扫描是赛场最短路径，掩码法是更"位运算味"的写法。

### 3.3 算法流程

![算法流程：移位扫描，按下标奇偶分桶计数](images/wc337_q1_scan_flow.svg)

```text
even = odd = 0, i = 0
while n != 0:
    if n & 1 == 1:            # 当前最低位为 1
        if i % 2 == 0: even += 1
        else:          odd  += 1
    n >>= 1                   # 丢掉已处理的位
    i += 1                    # 下标随移位同步 +1
return [even, odd]
```

### 3.4 示例演算

![示例演算：n=50 移位扫描全过程](images/wc337_q1_walkthrough.svg)

以 $n = 50 = 110010_2$ 为例，逐轮走查：

| 轮次 $i$ | $n$（二进制） | $n\ \&\ 1$ | 动作 | even | odd |
|----------|---------------|-----------|------|------|-----|
| 0 | $110010$ | 0 | 跳过 | 0 | 0 |
| 1 | $11001$ | 1 | `odd += 1` | 0 | 1 |
| 2 | $1100$ | 0 | 跳过 | 0 | 1 |
| 3 | $110$ | 0 | 跳过 | 0 | 1 |
| 4 | $11$ | 1 | `even += 1` | 1 | 1 |
| 5 | $1$ | 1 | `odd += 1` | 1 | 2 |
| 结束 | $0$ | — | 返回 | **1** | **2** |

返回 $[1, 2]$，与示例 1 一致 ✓。对照示例 2：$n=2=10_2$，第 1 轮取到下标 1 的 $1$，返回 $[0,1]$ ✓。

## 4. 算法细节

1. **取位**：`n & 1` 取当前最低位；`n >>= 1` 右移丢弃之。轮次计数器 `i` 从 0 起、每轮自增，恰好等于当前位下标。
2. **分桶**：仅当该位为 $1$ 时计数，按 `i % 2 == 0`（等价 `!(i & 1)`）分入 `even` / `odd`。
3. **循环条件**：`while (n)`——高位连续的 0 无需扫描；$n \le 1000 < 2^{10}$，至多 10 轮。
4. **掩码法常数**：$5 = 0101_2$、$\text{A} = 1010_2$，故 `0x55555555` 的第 $i$ 位为 1 当且仅当 $i$ 为偶数，`0xAAAAAAAA` 恰为其按位取反（32 位内）。两把掩码与 $n$ 按位与后 popcount，即 `even` / `odd`。
5. **返回顺序**：先 `even` 后 `odd`，别写反。

## 5. 正确性证明

**引理 1**（取位公式）：设 $n = \sum_{i \ge 0} b_i 2^i$（$b_i \in \{0,1\}$），则从右起第 $i$ 位的值 $b_i = (n \gg i)\ \&\ 1$。

**证明**：右移满足 $n \gg i = \lfloor n / 2^i \rfloor = \sum_{j \ge 0} b_{i+j} 2^j = b_i + 2\sum_{j \ge 1} b_{i+j} 2^{j-1}$，后者为 $b_i$ 加上一个偶数，故其最低位即 $b_i$。∎

**引理 2**（轮次-下标同步）：循环第 $k$ 轮开始时（$k = 0,1,2,\ldots$），变量 $n$ 的值等于 $\lfloor n_0 / 2^k \rfloor$（$n_0$ 为初始值），因此该轮 `n & 1` 取到的正是位下标 $k$。

**证明**：对 $k$ 归纳。$k=0$ 时未移位，$n = n_0$。设第 $k$ 轮开始时 $n = \lfloor n_0/2^k \rfloor$，则该轮末执行 `n >>= 1` 后 $n' = \lfloor n/2 \rfloor = \lfloor n_0 / 2^{k+1} \rfloor$，命题对 $k+1$ 成立。∎

**定理**：移位扫描算法返回 $[\text{even}, \text{odd}]$，其中 $\text{even} = \#\{i : b_i = 1,\ i \equiv 0 \pmod 2\}$，$\text{odd} = \#\{i : b_i = 1,\ i \equiv 1 \pmod 2\}$。

**证明**：循环不变量：完成 $k$ 轮后，$\text{even} = \#\{i < k : b_i = 1,\ i \text{ 偶}\}$，$\text{odd}$ 同理。由引理 2，第 $k$ 轮取到 $b_k$，为 1 时按 $k$ 的奇偶入桶，不变量保持。又 $n_0 < 2^{10}$，故 $k = 10$ 前必有 $\lfloor n_0/2^k \rfloor = 0$，循环终止；所有为 1 的位各被统计恰好一次。∎

**推论**（掩码法正确）：$\text{even} = \operatorname{popcount}(n\ \&\ \texttt{0x55555555})$，$\text{odd} = \operatorname{popcount}(n\ \&\ \texttt{0xAAAAAAAA})$。

**证明**：`0x55555555` 的第 $i$ 位为 1 当且仅当 $i \equiv 0 \pmod 2$（$5 = 0101_2$ 以 2 位为周期），故 $n\ \&\ \texttt{0x55555555}$ 恰保留 $n$ 的偶下标位、清零奇下标位，popcount 即偶下标 1 的个数；`0xAAAAAAAA` 为其在 32 位内的按位取反，同理得 $\text{odd}$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(B)$，$B = \lfloor \log_2 n \rfloor + 1 \le 10$。每轮处理一个位，$n \le 1000$ 至多 10 轮。掩码法为两次按位与 + 两次 popcount，$O(1)$。
- **空间复杂度**：$O(1)$。仅 `even`、`odd`、`i` 三个变量；对照字符串法需 $O(B)$ 存反转串。

> 💡 签到题的最短路径：读题 → 圈出"下标从右起" → `n & 1` / `n >>= 1` / `i++` 三件套循环 → 返回 `[even, odd]`。

## 7. 参考代码

### C++（移位扫描，赛场最短路径）

```cpp
class Solution {
public:
    vector<int> evenOddBit(int n) {
        int even = 0, odd = 0, i = 0;
        while (n) {
            if (n & 1) {
                if (i % 2 == 0) even++;
                else odd++;
            }
            n >>= 1;
            i++;
        }
        return {even, odd};
    }
};
```

### C++（掩码 + `__builtin_popcount`）

```cpp
class Solution {
public:
    vector<int> evenOddBit(int n) {
        return {__builtin_popcount(n & 0x55555555),   // 偶位 0101...
                __builtin_popcount(n & 0xAAAAAAAA)};  // 奇位 1010...
    }
};
```

### Python（移位扫描）

```python
class Solution:
    def evenOddBit(self, n: int) -> list[int]:
        even = odd = 0
        i = 0
        while n:
            if n & 1:
                if i % 2 == 0:
                    even += 1
                else:
                    odd += 1
            n >>= 1
            i += 1
        return [even, odd]
```

### Python（掩码一行流）

```python
class Solution:
    def evenOddBit(self, n: int) -> list[int]:
        return [(n & 0x55555555).bit_count(),
                (n & 0xAAAAAAAA).bit_count()]
```

> 💡 `int.bit_count()` 为 Python 3.10+ 内置；更低版本用 `bin(x).count('1')` 替换。C++20 起也可用 `std::popcount`（`<bit>` 头）。

## 8. 边界情况与易错点

1. **下标方向**（最大坑）：位下标从**右**往左数，下标 0 是最低位。字符串法忘了 `[::-1]` 反转，`even` 与 `odd` 会整体互换（如 $n=50$ 错成 `[2,1]$）。
2. **返回顺序**：`[even, odd]` 先偶后奇，别写成 `[odd, even]`。
3. **最小 / 最大输入**：$n=1 \to [1,0]$；$n=2 \to [0,1]$；$n=1000 \to [2,4]$（见示例 3，覆盖 10 位上界）。
4. **掩码位宽**：$n \le 1000 < 2^{10}$，32 位交错掩码绰绰有余；若数据放大到 64 位整数，需换 `0x5555555555555555` / `0xAAAAAAAAAAAAAAAA`。
5. **只数 1 不数 0**：值为 0 的位跳过，不要见到偶下标就 `even++`。
6. **C++ 类型细节**：`0xAAAAAAAA` 超出 `int` 范围、按 `unsigned` 处理，与非负 $n$ 做按位与无歧义；返回用初始化列表构造 `vector<int>` 即可。
