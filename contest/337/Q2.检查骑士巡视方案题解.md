# LeetCode 检查骑士巡视方案 题解

## 1. 题目概述

- **标题 / 题号**：检查骑士巡视方案（#2596，medium）
- **链接**：https://leetcode.cn/problems/check-knight-tour-configuration/
- **来源**：LeetCode 第 337 场周赛 Q2
- **难度**：中等
- **标签**：数组、矩阵、模拟、深度优先搜索、广度优先搜索

**题意**：骑士在 $n \times n$ 的棋盘上巡视，**有效**方案要求从**左上角** $(0,0)$ 出发，访问每个格子**恰好一次**。给定矩阵 $grid$，其中 $grid[row][col]$ 表示格子 $(row, col)$ 是骑士访问的第几个单元格（下标从 0 开始）。判断 $grid$ 是否表示一个有效巡视方案。骑士每步可走「日」字：竖直 2 格 + 水平 1 格，或水平 2 格 + 竖直 1 格。

**约束**：

- $n = grid.length = grid[i].length$，$3 \le n \le 7$，故 $n^2 \le 49$
- $0 \le grid[row][col] < n \cdot n$，且所有整数**互不相同**

> 💡 **读题第一件事**：把两条隐含条件圈出来——「值互不相同」+「值域恰为 $[0, n^2-1]$」意味着 $n^2$ 个格子的值**恰好是 $0 \sim n^2-1$ 的一个排列**。于是「每个格子恰好访问一次」已被输入编码保证，算法只需校验两件事：**起点在左上角**、**每对相邻步是骑士走法**。

## 2. 示例

**示例 1**

```text
输入：grid = [[0,11,16,5,20],[17,4,19,10,15],[12,1,8,21,6],[3,18,23,14,9],[24,13,2,7,22]]
输出：true
解释：从 (0,0) 出发，按 0→1→…→24 的顺序走查，
      每一步的坐标差都是 (±1,±2) 或 (±2,±1)，是有效巡视方案。
```

**示例 2**

```text
输入：grid = [[0,3,6],[5,8,1],[2,7,4]]
输出：false
解释：前 7 步 0→1→…→7 都是合法骑士走法；
      第 8 步从 (2,1) 到 (1,1)，坐标差 (−1,0)，不是骑士走法。
```

**示例 3**（自造，起点陷阱）

```text
输入：grid = [[8,3,6],[5,0,1],[2,7,4]]
输出：false
解释：值 1..8 恰好连成一条合法骑士链，但 0 号格在中心 (1,1) ≠ (0,0)，
      起点不在左上角，直接判负——起点校验是独立条件，不能指望相邻步校验顺带查出。
```

## 3. 解题思路

### 3.1 暴力思路：对每个序号全盘扫描

对每个序号 $k$（$0 \sim n^2-1$），在整张 $grid$ 里扫一遍找到 $grid[r][c] = k$ 的格子，再与 $k-1$ 的格子比较坐标差。每次定位 $O(n^2)$、共 $n^2$ 步，总时间 $O(n^4) \le 49^2 \approx 2400$，$n \le 7$ 下当然能过。但这是「把每次查询都付一遍全表扫描钱」的写法——要么模拟走棋时直接利用骑士只能走 8 个方向的事实，要么一次遍历把「按值查坐标」的表建好。

### 3.2 核心观察一：排列保证 + 只需校验「起点 + 相邻步」

**关键转化**：由读题观察，$grid$ 的值是 $0 \sim n^2-1$ 的排列，所以「每个格子恰好一次」自动成立，待校验的只有：

1. **起点**：$pos[0] = (0,0)$，即 $grid[0][0] = 0$；
2. **走法**：对每个 $k = 0 \sim n^2-2$，第 $k$ 步格子到第 $k+1$ 步格子的位移是骑士走法。

**核心观察二：骑士一步 ⇔ 坐标差平方和为 5**

![核心观察：骑士 8 个走法，坐标差平方和恒为 5](images/wc337_q2_knight_moves_dist.svg)

设相邻两步的坐标差为 $(dr, dc)$。骑士的 8 个方向是 $(\pm1, \pm2)$ 与 $(\pm2, \pm1)$，无论哪个方向都有

$$dr^2 + dc^2 = 1 + 4 = 5$$

反之，若 $dr^2 + dc^2 = 5$（$dr, dc$ 为整数），平方和拆分只能是 $1+4$，即 $\{|dr|, |dc|\} = \{1, 2\}$，恰好落回 8 个方向。于是**一个整数等式判定骑士走法**，无方向表、无浮点开方。这与勾股数 $(1, 2, \sqrt5)$ 对应——骑士一步的欧氏距离恒为 $\sqrt5$。（对照：$|dr| \cdot |dc| = 2$ 亦充要，两式等价，本题解采用平方和式。）

### 3.3 算法流程：按值模拟

![算法流程：从 (0,0) 出发按值模拟，8 个骑士邻居中找下一步](images/wc337_q2_sim_flow.svg)

赛场直觉写法是**骑士视角的模拟**：站在当前格子上，只看 8 个骑士邻居，找值为 $k$ 的那个格子作为下一步。由于值互异，候选邻居**至多一个**，找到即走、找不到即判负：

```text
若 grid[0][0] != 0：return false
cur = (0,0), k = 1
循环 k = 1 … n²−1：
    在 cur 的 8 个骑士邻居中找 grid 值为 k 的格子
    找不到 → return false
    cur ← 该邻居，k ← k + 1
return true
```

**复盘优化**：也可以一次遍历建**反查表** $pos[k] = (r, c)$，把内层 8 邻居探测替换为 $O(1)$ 查表，整个校验变成一次线性扫描。两版复杂度见 §6，$n \le 7$ 下都是瞬间，模拟版少一张表、更贴「走棋」直觉。

### 3.4 示例演算

![示例 2 演算：前 7 步平方和均为 5，第 8 步 1 ≠ 5](images/wc337_q2_walkthrough.svg)

以示例 2 的 $3 \times 3$ 棋盘为例，先反查坐标再逐步走查：

| 步 $k$ | 从 → 到 | $(dr,\,dc)$ | $dr^2+dc^2$ | 判定 |
|--------|---------|------------|------------|------|
| 1 | $(0,0) \to (1,2)$ | $(1,2)$ | $5$ | ✓ |
| 2 | $(1,2) \to (2,0)$ | $(1,-2)$ | $5$ | ✓ |
| 3 | $(2,0) \to (0,1)$ | $(-2,1)$ | $5$ | ✓ |
| 4 | $(0,1) \to (2,2)$ | $(2,1)$ | $5$ | ✓ |
| 5 | $(2,2) \to (1,0)$ | $(-1,-2)$ | $5$ | ✓ |
| 6 | $(1,0) \to (0,2)$ | $(-1,2)$ | $5$ | ✓ |
| 7 | $(0,2) \to (2,1)$ | $(2,-1)$ | $5$ | ✓ |
| 8 | $(2,1) \to (1,1)$ | $(-1,0)$ | $1$ | ✗ |

第 8 步平方和 $1 \ne 5$，返回 `false`，与示例一致 ✓。顺带一个有趣的事实：$3 \times 3$ 棋盘上**不存在**任何有效巡视方案（见 §5 推论），示例 2 注定 `false`。

## 4. 算法细节

1. **起点校验先行**：`grid[0][0] == 0` 是独立于走法校验的必要条件，漏写即错（示例 3）。模拟法若不查起点，从 $(0,0)$ 值为 8 的格子出发找值 9 会「碰巧」返回 false，掩盖逻辑漏洞。
2. **方向数组**：模拟法用 $dr[8] = \{\pm1, \pm1, \pm2, \pm2\}$、$dc[8] = \{\pm2, \mp2, \pm1, \mp1\}$ 的 8 组方向探测邻居，注意越界判断 $0 \le nr, nc < n$。
3. **候选唯一性**：值互异 ⇒ 8 个邻居中值为 $k$ 的格子**至多一个**，模拟法无需处理「多个候选」的歧义。
4. **判定式选择**：`dr*dr + dc*dc == 5` 整数运算，无方向表；等价写法 `abs(dr)*abs(dc) == 2` 或 `max(|dr|,|dc|)==2 && min(|dr|,|dc|)==1`。切忌只判 `dr+dc==3`（$(0,3)$ 是反例）。
5. **反查表版**：`pos[grid[r][c]] = (r,c)` 一次双循环建表；循环上界 $k+1 < n^2$，共 $n^2-1$ 对相邻步，防止 `pos[n²]` 越界。

## 5. 正确性证明

**引理 1**（骑士走法刻画）：整数对 $(dr, dc)$ 是骑士位移，当且仅当 $dr^2 + dc^2 = 5$。

**证明**：（⇒）骑士位移为 $(\pm1,\pm2)$ 或 $(\pm2,\pm1)$，平方和 $1 + 4 = 5$。（⇐）设 $dr^2 + dc^2 = 5$。5 拆成两个非负整数平方和的方式只有 $1 + 4$（$0 + 5$ 不行，5 非完全平方数；$4+1$ 同前），故 $\{|dr|,|dc|\} = \{1,2\}$，恰为 8 个骑士方向之一。∎

**引理 2**（排列性质）：$grid$ 的 $n^2$ 个值互异且都落在 $[0, n^2-1]$ 内，而该区间恰有 $n^2$ 个整数，故 $grid$ 的值集恰为 $\{0, 1, \ldots, n^2-1\}$，即每个序号 $k$ 恰有一个持有它的格子 $pos[k]$。

**引理 3**（候选唯一性）：模拟法每一步，8 个骑士邻居中值为 $k$ 的格子至多一个。

**证明**：邻居中若有两个格子值均为 $k$，与值互异矛盾。∎

**定理**：算法返回 `true` 当且仅当 $grid$ 表示有效巡视方案。

**证明**：（⇐）若 $grid$ 有效，则起点 $pos[0] = (0,0)$，且对每个 $k$，第 $k$ 步到第 $k+1$ 步是骑士走法；由引理 1，所有平方和校验通过，返回 `true`。（⇒）返回 `true` 时：起点校验保证 $pos[0]=(0,0)$；由引理 2，$pos[0], pos[1], \ldots, pos[n^2-1]$ 是 $n^2$ 个**互不相同**的格子（每个序号恰一个格子），且相邻步均为骑士走法——即从左上角出发、每格恰好一次、步步合法，是有效巡视方案。∎

**推论**（$3\times3$ 恒 `false`）：$n = 3$ 时，无论输入如何，答案均为 `false`。

**证明**：由引理 2，中心格 $(1,1)$ 持有某个序号 $k$。若 $k = 0$，则 $pos[0] = (1,1) \ne (0,0)$，判负。若 $k > 0$，则第 $k-1$ 步必须以骑士走法**进入**中心，即中心存在棋盘内的骑士邻居；但 $(1\pm1, 1\pm2)$ 与 $(1\pm2, 1\pm1)$ 中，$1 \pm 2 \in \{-1, 3\}$ 全部越出 $\{0,1,2\}$，即 $3\times3$ 内中心格**没有任何骑士邻居**，矛盾。∎

## 6. 复杂度分析

- **时间复杂度**：模拟法 $O(8 n^2)$——每步探测至多 8 个邻居，共 $n^2 - 1$ 步；反查表法 $O(n^2)$——建表一次遍历 + 校验 $n^2 - 1$ 对相邻步。$n \le 7$ 时 $n^2 \le 49$，两者均为微秒级。
- **空间复杂度**：模拟法 $O(1)$——只存当前坐标与步号，这是它相对反查表的优势；反查表法 $O(n^2)$——额外存 $pos$ 数组。

## 7. 参考代码

### C++（按值模拟，$O(1)$ 空间）

```cpp
class Solution {
public:
    bool checkValidGrid(vector<vector<int>>& grid) {
        int n = grid.size();
        if (grid[0][0] != 0) return false;
        const int dr[8] = {1, 1, -1, -1, 2, 2, -2, -2};
        const int dc[8] = {2, -2, 2, -2, 1, -1, 1, -1};
        int r = 0, c = 0;
        for (int k = 1; k < n * n; k++) {
            bool found = false;
            for (int d = 0; d < 8; d++) {
                int nr = r + dr[d], nc = c + dc[d];
                if (nr >= 0 && nr < n && nc >= 0 && nc < n && grid[nr][nc] == k) {
                    r = nr, c = nc, found = true;
                    break;
                }
            }
            if (!found) return false;
        }
        return true;
    }
};
```

### C++（反查表 + 平方和判定）

```cpp
class Solution {
public:
    bool checkValidGrid(vector<vector<int>>& grid) {
        int n = grid.size();
        vector<pair<int, int>> pos(n * n);
        for (int i = 0; i < n; i++)
            for (int j = 0; j < n; j++)
                pos[grid[i][j]] = {i, j};
        if (pos[0] != make_pair(0, 0)) return false;
        for (int k = 0; k + 1 < n * n; k++) {
            int dr = pos[k].first - pos[k + 1].first;
            int dc = pos[k].second - pos[k + 1].second;
            if (dr * dr + dc * dc != 5) return false;
        }
        return true;
    }
};
```

### Python（按值模拟，$O(1)$ 空间）

```python
class Solution:
    def checkValidGrid(self, grid: List[List[int]]) -> bool:
        n = len(grid)
        if grid[0][0] != 0:
            return False
        moves = [(1, 2), (1, -2), (-1, 2), (-1, -2),
                 (2, 1), (2, -1), (-2, 1), (-2, -1)]
        r = c = 0
        for k in range(1, n * n):
            for dr, dc in moves:
                nr, nc = r + dr, c + dc
                if 0 <= nr < n and 0 <= nc < n and grid[nr][nc] == k:
                    r, c = nr, nc
                    break
            else:
                return False
        return True
```

### Python（反查表 + 平方和判定）

```python
class Solution:
    def checkValidGrid(self, grid: List[List[int]]) -> bool:
        n = len(grid)
        pos = [None] * (n * n)
        for i in range(n):
            for j in range(n):
                pos[grid[i][j]] = (i, j)
        if pos[0] != (0, 0):
            return False
        for k in range(n * n - 1):
            dr = pos[k][0] - pos[k + 1][0]
            dc = pos[k][1] - pos[k + 1][1]
            if dr * dr + dc * dc != 5:
                return False
        return True
```

## 8. 边界情况与易错点

1. **起点漏查**（最大坑）：只校验相邻步走法、不查 $grid[0][0] = 0$，起点错位的输入可能侥幸通过走法链校验（见示例 3 的说明），起点是独立必要条件，必须显式单查。
2. **判定式不充分**：`dr + dc == 3` 之类的弱判定会被 $(0, 3)$ 这类非骑士位移骗过；用平方和 $dr^2+dc^2 = 5$ 或乘积 $|dr| \cdot |dc| = 2$ 这类**充要**判定。
3. **循环边界**：相邻步共 $n^2 - 1$ 对，循环写 `k + 1 < n * n`，防止访问 `pos[n²]` 越界。
4. **$n = 3$ 恒 `false`**：由 §5 推论，$3\times3$ 棋盘中心格无骑士邻居，任何输入都判负——赛场遇到 $n=3$ 的 hack 用例不必怀疑人生。
5. **越界判断**：模拟法探测邻居必须先判 $0 \le nr, nc < n$ 再取 `grid[nr][nc]`，C++ 里先访问后判界是未定义行为。
6. **不要用浮点**：判 `sqrt(dr*dr+dc*dc) == sqrt(5)` 引入浮点误差，整数平方和直接比较即可。
7. **值域与互异是免费保证**：本题无需查重、无需查值域；若题目放宽约束（允许重复或越界值），建反查表前须先做合法性预校验（参见每日题解的扩展节）。
