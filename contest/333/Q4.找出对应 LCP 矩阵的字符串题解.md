# LeetCode 找出对应 LCP 矩阵的字符串 题解

## 1. 题目概述

- **标题 / 题号**：找出对应 LCP 矩阵的字符串（#2573，hard）
- **链接**：https://leetcode.cn/problems/find-the-string-with-lcp/
- **来源**：LeetCode 第 333 场周赛 Q4
- **难度**：困难
- **标签**：贪心、并查集、数组、字符串、动态规划、矩阵

**题意**：对长度为 $n$ 的小写串 `word` 定义 $n \times n$ 矩阵：$\text{lcp}[i][j]$ 等于后缀 $\text{word}[i..n-1]$ 与 $\text{word}[j..n-1]$ 的**最长公共前缀**长度。现在反过来：给定矩阵 `lcp`，求出与它匹配的、**字典序最小**的 `word`；不存在这样的字符串则返回空串。

**约束**：

- $1 \le n = \text{lcp.length} = \text{lcp}[i].\text{length} \le 1000$
- $0 \le \text{lcp}[i][j] \le n$

> 💡 这是一道**逆问题**：正常方向是「串 → LCP 矩阵」，本题是「矩阵 → 串」。$n \le 1000$ 意味着 $O(n^2)$（约 $10^6$ 格）是预期复杂度，$O(n^3)$ 不可行。逆问题的通用套路是：找到原方向的**局部刻画**（LCP 的 $O(1)$ 递推），用它一次性完成构造与验证。

## 2. 示例

```text
解释：该 lcp 对应任意由两个交替字母组成的 4 字母串，
      如 "abab"、"baba"、"cdcd"，字典序最小的是 "abab"。
```

```text
输出："aaaa"
解释：矩阵中所有格子都大于 0，所有位置必须同字符，字典序最小取 "aaaa"。
```

**示例 3**

```text
输出：""
解释：lcp[3][3] = 3，但后缀 word[3..3] 只有一个字符，
```

## 3. 解题思路

### 3.1 暴力思路：枚举字符串 / 逐对重算 LCP

最直接的暴力是枚举所有 $26^n$ 个字符串逐一验证——$n = 1000$ 时是天文数字。

更现实的暴力：先用某种方式构造一个「满足首字符约束」的候选串（见 §3.2），再逐对 $(i,j)$ 用双指针求出候选串的**真实** LCP 与矩阵比对。求一对最坏 $O(n)$，共 $n^2$ 对，总复杂度 $O(n^3)$，$n = 1000$ 时约 $10^9$ 次字符比较，超时。

> ⚠️ 暴力的浪费在于「每对独立重算」。LCP 的相邻格子之间有 $O(1)$ 的递推关系，顺着递推检查就能把每格的验证降到 $O(1)$——这既是验证的加速，也是本题的题眼。

### 3.2 核心观察：正负号划分「相等类」

![核心观察：lcp 矩阵中大于 0 的格子把下标划分成字符相等类，示例 1 中位置 {0,2} 分到 'a'、{1,3} 分到 'b'，构造出 "abab"](images/lcp333_class_assign.svg)

**观察一（首字符等价）**：$\text{lcp}[i][j] \ge 1 \iff \text{word}[i] = \text{word}[j]$。

公共前缀非空，当且仅当两个后缀的**首字符相同**。于是矩阵每个格子的**正负号**（$>0$ 还是 $=0$）给出一条「相等 / 不等」约束——这与 [990. 等式可满足性](https://leetcode.cn/problems/satisfiability-of-equality-equations/) 的结构同源。

**观察二（关系传递封闭）**：合法矩阵中，若 $\text{lcp}[i][k] > 0$ 且 $\text{lcp}[k][j] > 0$，则 $\text{word}[i] = \text{word}[k] = \text{word}[j]$，故 $\text{lcp}[i][j] \ge 1 > 0$。

即「直接相连」的 $>0$ 关系**天然传递封闭**，把下标划分成若干**字符相等类**后，跨类的任意一对 $(i, j)$ 必有 $\text{lcp}[i][j] = 0$，即**跨类字符必须不同**。两个推论：

1. 不同类不能复用同一个字母，因此**类数 $\le 26$**，超过即无解；
2. 类的划分只需要一遍扫描「代表行」即可完成，无需显式并查集做闭包（用并查集也一样，见 §4）。

**观察三（模式决定矩阵）**：LCP 矩阵只依赖「哪些位置的字符相等」这一**模式**，与具体用哪个字母无关。`"abab"`、`"baba"`、`"cdcd"` 的 lcp 矩阵完全相同。

因此，**若解存在**，把各个类按**首次出现顺序**依次分配 `'a'`, `'b'`, `'c'`, …，就得到字典序最小的解——这是字典序最小性的来源（严格证明见 §5）。

### 3.3 算法流程：贪心构造 + 五条件验证

![算法流程：i 从小到大，word[i] 未定则分配递增新字母并传播给 lcp 大于 0 的未定位置；构造完成后 O(n²) 全矩阵验证对角线、对称、上界、正格递推、零格异字符五项条件，通过则输出，否则返回空串](images/lcp333_greedy_flow.svg)

**第一步：贪心构造（只用正负号信息）**。$i$ 从 $0$ 到 $n-1$：

- 若 $\text{word}[i]$ 已被传播设置，跳过；
- 否则分配**最小未用过的新字母**（第 1 个类 `'a'`，第 2 个类 `'b'`……）；需要第 27 个类时直接返回 `""`；
- 把该字母**传播**给所有 $j > i$ 且 $\text{lcp}[i][j] > 0$ 且未设置的 $j$。

**第二步：全矩阵验证（兜底数值信息）**。构造只保证了「正负号约束」，矩阵的**数值**（LCP 到底多长）、对称性、对角线都可能自相矛盾，必须逐格检查五项**局部条件**，每项 $O(1)$：

1. 对角线：$\text{lcp}[i][i] = n - i$（后缀与自身的 LCP 就是自身长度）；
2. 对称：$\text{lcp}[i][j] = \text{lcp}[j][i]$；
3. 上界：$\text{lcp}[i][j] \le \min(n-i,\ n-j)$（公共前缀不能长于任一后缀）；
4. **正格**（$\text{lcp}[i][j] > 0$）：$\text{word}[i] = \text{word}[j]$，且未越界时 $\text{lcp}[i+1][j+1] = \text{lcp}[i][j] - 1$；
5. **零格**（$\text{lcp}[i][j] = 0$）：$\text{word}[i] \ne \text{word}[j]$。

五项全部通过输出 `word`，任何一项失败返回 `""`。

> 💡 构造与验证各司其职：构造回答「**如果**有解，它长什么样」；验证回答「这个候选**究竟**合不合法」。非法矩阵五花八门（不对称、对角线错、数值越界、递推链断裂），逐一在构造阶段排除既难又漏，一次性全量验证最稳。

### 3.4 示例演算：示例 1 的矩阵

![验证递推：正格沿对角线每步减一，零格要求字符不同；word 为 abab 时后缀 0 与后缀 2 对齐，公共前缀 ab 长度 2，与 lcp[0][2] 一致](images/lcp333_verify_recurrence.svg)

**构造阶段**：

| 步骤 | $i$ | 动作 | word 状态 |
|:---:|:---:|------|:---:|
| 1 | 0 | 未定 → 新类 A 分配 `'a'`；扫行 $0$：$\text{lcp}[0][2]=2>0$ 传播 `word[2]='a'`；$\text{lcp}[0][1]=\text{lcp}[0][3]=0$ 不传播 | `a _ a _` |
| 2 | 1 | 未定 → 新类 B 分配 `'b'`；扫行 $1$：$\text{lcp}[1][3]=1>0$ 传播 `word[3]='b'` | `a b a b` |
| 3 | 2 | 已定（`'a'`），跳过 | `a b a b` |
| 4 | 3 | 已定（`'b'`），跳过 | `a b a b` |

**验证阶段**（抽样）：

- 对角线 $4,3,2,1$ 恰为 $n-i$ ✓；
- $(0,2)$：值 $2$，对称 ✓，上界 $\min(4,2)=2$ ✓，`'a'='a'` ✓，递推 $\text{lcp}[1][3] = 1 = 2-1$ ✓；
- $(0,1)$：值 $0$，`'a' ≠ 'b'` ✓；
- $(1,3)$：值 $1$，$j+1 = 4 = n$ 后缀到底，不再要求递推 ✓。

全部通过，输出 `"abab"`。反过来直观核对：`"abab"` 的后缀 $0$（`abab`）与后缀 $2$（`ab`）公共前缀 `"ab"` 长度 $2$，正是 $\text{lcp}[0][2]$。

## 4. 算法细节

1. **传播只扫 $j > i$**：处理完位置 $0..i$ 后它们必已设值，所以代表 $i$ 的传播只需看更晚的下标；每个代表扫一行 $O(n)$，而**代表至多出现 27 个**（第 27 个触发返回 `""`），构造阶段实际是 $O(26n)$，总复杂度由验证的 $O(n^2)$ 主导。
2. **为什么「只看正负号」就够定字符**：构造只消费了矩阵的符号信息，数值正确性完全交给验证。反例：`lcp = [[2,2],[2,1]]`，构造得到 `"aa"` 且所有「正负号」约束满足，但 $(0,1) = 2 > \min(n-0, n-1) = 1$ 越界，无解——没有验证就会误输出。
3. **五条件与引理 1 的等价性**：§5 引理 1 证明「匹配 $\iff$ (a) 上界、(b) 正格递推、(c) 零格异字符，对**全部** $(i,j)$ 成立」。代码中显式检查对称与对角线后，(a)(b)(c) 只需扫 $i < j$ 的下三角；此时 $\min(n-i, n-j) = n-j$，上界条件简化为 $v \le n-j$。
4. **递推链的完整性**：正格条件 ④ 沿对角线逐格减一，$\text{lcp}[i][j] \to \text{lcp}[i+1][j+1] \to \cdots$，链的终点必是「某个格子的值为 $0$」（由条件 ⑤ 查字符不等）或「$i$ 或 $j$ 到达 $n-1$」（后缀耗尽，该格值由上界条件钉死为 $1$）。链式检查保证矩阵声称的每个 LCP 长度都被完整走了一遍，不会出现「声称 3 实际只能匹配 2」的漏网。
5. **并查集等价写法**：官方标签里的并查集做法是先把所有 $\text{lcp}[i][j] > 0$ 的 $(i,j)$ `union`，再按每个连通块**首次出现的下标**分配递增字母。由观察二的传递封闭性，它与「代表行传播法」得到完全相同的划分，二者可任选。

## 5. 正确性证明

记 $n$ 为串长，$f_w(i,j)$ 表示串 $w$ 的后缀 $w[i..]$ 与 $w[j..]$ 的真实 LCP（约定 $i = n$ 或 $j = n$ 时为 $0$）。称矩阵 $L$ 与 $w$ **匹配**，若 $\forall i, j:\ L[i][j] = f_w(i,j)$。

**引理 1（局部刻画）**：$L$ 与 $w$ 匹配，当且仅当对**所有** $0 \le i, j < n$：

- (a) $L[i][j] \le \min(n-i,\ n-j)$；
- (b) 若 $L[i][j] > 0$，则 $w[i] = w[j]$，且当 $i+1 < n$ 且 $j+1 < n$ 时 $L[i+1][j+1] = L[i][j] - 1$；
- (c) 若 $L[i][j] = 0$，则 $w[i] \ne w[j]$。

**证明**：(⇒) 设 $L \equiv f_w$。(a)：公共前缀不能长于任一后缀。(b)：$f_w(i,j) = k \ge 1$ 说明 $w[i] = w[j]$，且两后缀各去掉首字符后公共前缀长为 $k-1$，即 $f_w(i+1, j+1) = k - 1$（若 $i+1 < n$ 且 $j+1 < n$；否则 $k \le \min(n-i, n-j) = 1$，无需递推）。(c)：若 $w[i] = w[j]$，公共前缀至少含 $1$ 个字符，$f_w(i,j) \ge 1 \ne 0$。

(⇐) 设 (a)(b)(c) 成立，对 $i + j$ **从大到小**归纳证明 $L[i][j] = f_w(i,j)$。归纳依赖沿对角线向右下走、$i+j$ 严格增大，链有限终止，无循环。

- 若 $w[i] \ne w[j]$：$f_w(i,j) = 0$；(b) 的逆否给出 $L[i][j] \le 0$，即 $L[i][j] = 0$ ✓。
- 若 $w[i] = w[j]$：(c) 的逆否给出 $L[i][j] \ge 1$。
  - 若 $i+1 < n$ 且 $j+1 < n$：$f_w(i,j) = 1 + f_w(i+1, j+1)$；由 (b) 与归纳假设 $L[i+1][j+1] = f_w(i+1, j+1)$，故 $L[i][j] = 1 + L[i+1][j+1] = f_w(i,j)$ ✓。
  - 若 $i = n-1$ 或 $j = n-1$：$f_w(i,j) = 1$（首字符相等，较短后缀随即耗尽）；由 (a) $L[i][j] \le 1$，结合 $L[i][j] \ge 1$ 得 $L[i][j] = 1 = f_w(i,j)$ ✓。∎

**引理 2（模式不变性）**：若串 $u, v$（等长 $n$）满足 $\forall a, b:\ u[a] = u[b] \iff v[a] = v[b]$，则 $u$ 与 $v$ 的 LCP 矩阵相同。

**证明**：$f_u(i,j) = \max\{k \le \min(n-i, n-j) : \forall t < k,\ u[i+t] = u[j+t]\}$。由模式一致，$u[i+t] = u[j+t] \iff v[i+t] = v[j+t]$ 对一切 $t$ 成立，故两个 $\max$ 的可行 $k$ 集合相同。∎

**引理 3（构造的刻画）**：若存在与 $L$ 匹配的串 $w$，则算法构造出的 `word` 与 $w$ 模式一致（从而由引理 2，`word` 也与 $L$ 匹配）。

**证明**：$w$ 匹配时，断言 $w[i] = w[j] \iff L[i][j] > 0$（⇐ 即观察一；⇒ 因 $w[i]=w[j]$ 时 $f_w(i,j) \ge 1$）。对 $i$ 归纳证明：处理完位置 $0..i$ 后，(P1) 这些位置全部设值；(P2) 对 $p, q \le i$：$\text{word}[p] = \text{word}[q] \iff w[p] = w[q]$。

- (P1) 显然：处理 $i$ 时未定则设值。
- (P2)：设对 $< i$ 成立，考察位置 $i$。
  - **情形 A（$i$ 被传播，$\text{word}[i] = c$）**：存在代表 $p < i$ 使 $L[p][i] > 0$，由断言 $w[p] = w[i]$。归纳假设下 $c$ 恰是「$w[\cdot] = w[p]$ 的那些更早位置」的公共字母，故对任意 $q < i$：$\text{word}[q] = c \iff w[q] = w[p] \iff w[q] = w[i]$。若 $w[q] = w[i]$，则 $q$ 与 $p$ 同值，$L[q][i] > 0$，构造时 $i$ 会被其中最早扫到的代表传播为同类字母 $c$，与 $\text{word}[q] = c$ 一致 ✓；若 $w[q] \ne w[i]$，则 $\text{word}[q] \ne c = \text{word}[i]$ ✓。
  - **情形 B（$i$ 作为新代表，分到新字母 $c$）**：$i$ 未被任何更早代表传播，即对所有代表 $p < i$ 有 $L[p][i] = 0$，由断言 $w[p] \ne w[i]$；而更早的每个 $q$ 都与某代表 $p$ 同值（断言 + 归纳），故 $w[q] \ne w[i]$ 对一切 $q < i$ 成立。新字母 $c$ 与之前用过的字母都不同，故 $\text{word}[i] = c \ne \text{word}[q]$，模式一致 ✓。

归纳完成，加上 (P2) 在构造结束时对全部下标成立，即 `word` 与 $w$ 模式一致。∎

**定理（正确性与字典序最小性）**：(1) 若存在匹配串，算法输出其中字典序最小者；(2) 若不存在，算法输出 `""`。

**证明**：

(1) 设 $w$ 为任一匹配串。由引理 3 与引理 2，构造出的 `word` 也匹配，且五条件（引理 1 的 (a)(b)(c) 全矩阵形式）逐格成立，验证必通过，算法输出 `word`。再证最小性。设构造的相等类按**最小下标**升序为 $C_0, C_1, \dots, C_{m-1}$，`word` 在 $C_t$ 上取字母 $\gamma_t = $ `'a'`$+ t$。由引理 3 的论证对 $w$ 同样适用：$w$ 在每个 $C_t$ 上恒定（记值 $v_t$），且 $v_0, \dots, v_{m-1}$ 两两不同——跨类任一对 $(q, r)$ 有 $L[q][r] = 0$（构造中 $r$ 所在类的代表未从更早类收到传播，合法矩阵下类内成员不会漏传），匹配性迫使 $w[q] \ne w[r]$。

设 $t^*$ 为最小的满足 $v_{t^*} \ne \gamma_{t^*}$ 的下标（不存在则 $w = $ `word`）。对 $s < t^*$ 有 $v_s = \gamma_s$。记 $p$ 为 $C_{t^*}$ 的最小下标：由类按最小下标排序，所有下标 $< p$ 的位置都属于更早的类 $C_s\ (s < t^*)$，这些位置上 $w$ 与 `word` 逐位相同；而 $v_{t^*}, \gamma_{t^*}$ 是位置 $p$ 上两串的字符。由 $v_0, \dots, v_{t^*}$ 两两不同且 $v_s = \gamma_s\ (s < t^*)$，知 $v_{t^*} \notin \{$'a'$, \dots, \text{'a'}+t^*-1\}$，又 $v_{t^*} \ne \gamma_{t^*} = \text{'a'}+t^*$，故 $v_{t^*} > \gamma_{t^*}$。于是两串的第一个不同位置是 $p$，且 `word`$[p] < w[p]$，即 `word` $< w$。∎

(2) 不存在匹配串时：若构造阶段需要第 27 个新类而返回 `""`——由 (1) 中「跨类字符两两不同」的论证，任何匹配串需要 $m$ 个两两不同的字母，$m > 26$ 时确实无解 ✓。若构造完成，验证必不通过：反设通过，则 `word` 满足引理 1 的全部条件，由引理 1 `word` 与矩阵匹配，与无解矛盾。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n^2)$。构造阶段只有「代表」才执行内层扫描，而代表至多 27 个（第 27 个触发返回），故构造实为 $O(26n)$；验证阶段扫描 $i < j$ 的约 $n^2/2$ 个格子，每格 $O(1)$——内层 $j$ 递增时对 `lcp[i+1][j+1]` 的访问在内存中连续，cache 友好。$n = 1000$ 时约 $5 \times 10^5$ 次检查，远优于暴力的 $O(n^3)$。
- **空间复杂度**：$O(n)$ 额外空间，即长度 $n$ 的 `word`（不计输入矩阵本身的 $O(n^2)$）。验证是就地逐格判断，不构建真实 LCP 矩阵，这是与「先算矩阵再比对」做法的关键差别。

## 7. 参考代码

### C++（贪心构造 + 五条件验证，$O(n^2)$ / $O(n)$）

```cpp
class Solution {
public:
    string findTheString(vector<vector<int>>& lcp) {
        int n = lcp.size();
        string word(n, '?');
        int nxt = 0;                                    // 下一个可分配的字母编号
        for (int i = 0; i < n; i++) {
            if (word[i] != '?') continue;               // 已被传播设置
            if (nxt == 26) return "";                   // 第 27 个相等类：无解
            char ch = 'a' + nxt++;
            word[i] = ch;
            for (int j = i + 1; j < n; j++)             // 只扫代表行，传播相等
                if (lcp[i][j] > 0 && word[j] == '?') word[j] = ch;
        }
        for (int i = 0; i < n; i++) {
            if (lcp[i][i] != n - i) return "";          // 对角线 = 后缀自身长度
            for (int j = i + 1; j < n; j++) {
                int v = lcp[i][j];
                if (v != lcp[j][i] || v > n - j) return "";   // 对称 + 上界(j>i 时 n-j 更小)
                if (v == 0) {
                    if (word[i] == word[j]) return "";  // 零格：字符必须不同
                } else {
                    if (word[i] != word[j]) return "";  // 正格：首字符必须相同
                    if (i + 1 < n && j + 1 < n && lcp[i + 1][j + 1] != v - 1)
                        return "";                      // 沿对角线递推减一
                }
            }
        }
        return word;
    }
};
```

```python
class Solution:
    def findTheString(self, lcp: List[List[int]]) -> str:
        n = len(lcp)
        word = [''] * n
        nxt = 0                                          # 下一个可分配的字母编号
        for i in range(n):
            if word[i]:
                continue                                 # 已被传播设置
            if nxt == 26:                                # 第 27 个相等类：无解
                return ""
            ch = chr(ord('a') + nxt)
            nxt += 1
            word[i] = ch
            for j in range(i + 1, n):                    # 只扫代表行，传播相等
                if lcp[i][j] > 0 and not word[j]:
                    word[j] = ch

        for i in range(n):
            if lcp[i][i] != n - i:                       # 对角线 = 后缀自身长度
                return ""
            for j in range(i + 1, n):
                v = lcp[i][j]
                if v != lcp[j][i] or v > n - j:          # 对称 + 上界(j>i 时 n-j 更小)
                    return ""
                if v == 0:
                    if word[i] == word[j]:               # 零格：字符必须不同
                        return ""
                else:
                    if word[i] != word[j]:               # 正格：首字符必须相同
                        return ""
                    if i + 1 < n and j + 1 < n and lcp[i + 1][j + 1] != v - 1:
                        return ""                        # 沿对角线递推减一
        return ''.join(word)
```

## 8. 边界情况与易错点

1. **只验证字符、不验证数值**：`lcp = [[2,2],[2,1]]` 的所有正负号约束都能满足（构造出 `"aa"`），但 $(0,1)=2$ 越过 $\min(2,1)=1$，无解。只查「正格字符相等、零格字符不等」会误判合法。
2. **对角线**：$\text{lcp}[i][i]$ 必须等于 $n-i$（示例 3 的 `lcp[3][3]=3` 即由此抓出）。它虽然也能由「正格递推 + 上界」链式推出，但显式检查更直接。
3. **不对称矩阵**：如 `[[2,1],[0,1]]`。构造阶段只看了一侧（$j > i$），若验证也只扫下三角而不比对 $\text{lcp}[j][i]$，就会漏判。
4. **类数超过 26**：$n$ 个位置两两不同类时（如单位矩阵外的全零矩阵，$n = 27$），需要 27 个两两不同的字母，必须返回 `""`；忘记这个上限会越界分配字母。
5. **传播覆盖已设置位置**：传播时必须加「未定才设置」的判断，否则可能把已分好的更早类字母改掉（矩阵非法时的自保护）。
6. **构造「漏掉」的约束正是无解的证据**：若 $\text{lcp}[j][i] > 0\ (j<i)$ 却没在处理 $j$ 时传播到 $i$（说明矩阵非法），构造会给 $i$ 一个新字母，验证的条件 ④（正格字符相等）必然抓住——无需在构造阶段额外处理 $j<i$ 的格子。
7. **$n = 1$**：循环体不执行，仅要求 $\text{lcp}[0][0] = 1$，成立则输出 `"a"`。
8. **返回值语义**：无解返回**空串** `""`，不是 `" "` 也不是 `None`；C++ 中 `word(n, '?')` 只作未定标记，正常路径下必被填满。
