# LeetCode 将整数减少到零需要的最少操作数 题解

## 1. 题目概述

- **标题 / 题号**：将整数减少到零需要的最少操作数（#2571，medium）
- **链接**：https://leetcode.cn/problems/minimum-operations-to-reduce-an-integer-to-0/
- **来源**：LeetCode 第 333 场周赛 Q2
- **难度**：中等
- **标签**：贪心、位运算、动态规划

**题意**：给定正整数 $n$，每次操作可以给 $n$ **加上或减去** $2$ 的某个幂（$2^i,\ i \ge 0$），幂次任选、可重复使用。求把 $n$ 变成 $0$ 的**最少操作数**。

**约束**：

- $1 \le n \le 10^5$

> 💡 「加或减」是本题的题眼。若只能减，答案就是二进制里 $1$ 的个数（popcount）；正是「允许加」打开了**进位**这条路，让连续一段 $1$ 能被一次操作整体塌缩。同时也要警惕：进位可能把相邻的段**桥接**起来，不能静态地数段。

## 2. 示例

**示例 1**

```text
输入：n = 39
输出：3
解释：
- n 加上 2⁰ = 1，得到 n = 40
- n 减去 2³ = 8，得到 n = 32
- n 减去 2⁵ = 32，得到 n = 0
```

**示例 2**

```text
输入：n = 54
输出：3
解释：
- n 加上 2¹ = 2，得到 n = 56
- n 加上 2³ = 8，得到 n = 64
- n 减去 2⁶ = 64，得到 n = 0
```

**示例 3**（自造，覆盖「全 1 进位冲破最高位」）

```text
输入：n = 7
输出：2
解释：7 + 1 = 8，8 - 8 = 0。逐位减（4+2+1）要 3 次，进位只要 2 次。
```

## 3. 解题思路

### 3.1 暴力思路：BFS 最短路

把每个非负整数当节点，「$\pm 2^i$」当边，从 $n$ 出发 BFS，首次到达 $0$ 的层数即答案。由于 $n \le 10^5 < 2^{17}$，途中值域不超过 $[0, 2^{18}]$，状态约 $2.6\times 10^5$ 个、每个 $18$ 条出边，BFS 可以 AC。

但它把「$2$ 的幂」当成黑盒边权，**完全没有利用二进制结构**：状态数与边数都随 $n$ 线性膨胀，若 $n$ 放大到 $10^{18}$ 直接爆炸。理应顺着二进制的骨架，把复杂度压到 $O(\log n)$。

### 3.2 核心观察：带符号幂之和 + 折半递推

![核心观察：一次操作等价于 ±2^i，最少操作数即带符号幂表示的最小项数；连续 1 段用 +1 进位塌缩比逐位减省，且进位会桥接只隔一个 0 的相邻段](images/reduce333_signed_powers.svg)

**观察一（操作 ↔ 带符号幂之和）**：把每步操作按符号搬进求和式，$k$ 次操作把 $n$ 变 $0$ 当且仅当

$$n = \varepsilon_1 2^{i_1} + \varepsilon_2 2^{i_2} + \cdots + \varepsilon_k 2^{i_k},\qquad \varepsilon_j \in \{+1, -1\}.$$

问题化为：**用最少的带符号 $2$ 的幂表示 $n$**（§5 引理 1 给出严格证明）。

**观察二（连续 $1$ 段进位塌缩）**：一段长 $L \ge 2$ 的连续 $1$（位于位 $i \sim i{+}L{-}1$）逐位减要 $L$ 次；改在**最低位加 $2^i$**，由 $2^i + (2^i + \cdots + 2^{i+L-1}) = 2^{i+L}$ 可知整段塌缩成高位一个 $1$，只花 $1$ 次。孤立的 $1$（两侧是 $0$）则直接减，$1$ 次。

**观察三（折半递推）**：把视角移到**最低位**，可得到一条严格的递推（证明见 §5）：

- $n$ 为**偶数**：最低位本就是 $0$，最优方案不会去动 $2^0$，$f(n) = f(n/2)$；
- $n$ 为**奇数**：最低位的 $1$ 必须消掉，只有 $-2^0$（$n \to n-1$）或 $+2^0$（$n \to n+1$）两种选择，各花 $1$ 次，随后变偶数折半：

$$f(n) = 1 + \min\bigl(f(\tfrac{n-1}{2}),\ f(\tfrac{n+1}{2})\bigr).$$

两条分支孰优，由**末两位**一眼判定：$n \bmod 4 = 1$（孤立 $1$）取 $-1$，$n \bmod 4 = 3$（连续 $1$）取 $+1$——这正是观察二的贪心在递推中的化身。

### 3.3 算法流程：按 $n \bmod 4$ 决策

![算法流程：while n>0 循环，最低位为 0 免费折半；最低位为 1 时看次低位，≡3 mod 4 则 +1 进位计一次，≡1 mod 4 则 −1 消位计一次，随后折半回到循环](images/reduce333_flow.svg)

一个 `while n > 0` 循环内的三分支决策：

1. 初始化 $\text{ans} = 0$；
2. 若 $n = 0$，结束返回 `ans`；
3. 若最低位为 $0$（$n\&1=0$）：`n >>= 1`，**不计操作**；
4. 否则最低位为 $1$，看次低位：
   - 次低位为 $1$（$n \equiv 3 \pmod 4$，连续段）：`ans += 1`，`n += 1`（进位塌缩），`n >>= 1`；
   - 次低位为 $0$（$n \equiv 1 \pmod 4$，孤立位）：`ans += 1`，`n −= 1`（消位），`n >>= 1`；
5. 回到步骤 2。

> ⚠️ 进位要用 `n += 1` 让进位**自然向高位传播**，不要手工构造 $2^i$。`n = 7` 时 $+1$ 会冲破原最高位变成 $8$，由循环条件 `n > 0` 与后续右移自然消化。

### 3.4 示例演算：54 的进位桥接

![示例演算：n=54=110110₂，7 步循环，两处 +1 进位桥接两段 1，最终 ans=3，对应 +2¹、+2³、−2⁶](images/reduce333_walkthrough.svg)

以 $n = 54 = 110110_2$ 为例（含两段连续 $1$，是「桥接」的典型）：

| 步 | $n$ | 二进制 | 末两位 | 动作 | ans |
|----|-----|--------|--------|------|-----|
| 1 | $54$ | $110110$ | $10$ | $n \gg 1 \to 27$ | $0$ |
| 2 | $27$ | $11011$ | $\mathbf{11}$ | $+1$ 进位 $\to 28$，再 $\gg 1 \to 14$ | $1$ |
| 3 | $14$ | $1110$ | $10$ | $n \gg 1 \to 7$ | $1$ |
| 4 | $7$ | $111$ | $\mathbf{11}$ | $+1$ 进位 $\to 8$，再 $\gg 1 \to 4$ | $2$ |
| 5 | $4$ | $100$ | $00$ | $n \gg 1 \to 2$ | $2$ |
| 6 | $2$ | $10$ | $10$ | $n \gg 1 \to 1$ | $2$ |
| 7 | $1$ | $1$ | $01$ | $-1$ 消位 $\to 0$ | $3$ |

折半会把循环内的 $+1$ 放大回原数尺度：三处操作对应 $+2^1$、$+2^3$、$-2^6$，即 $54 + 2 + 8 = 64$、$64 - 64 = 0$，与官方示例 2 完全一致。注意第 2 步的 $+2^1$ 让低位段「11」塌缩时，进位恰好落在两段之间**唯一的 $0$** 上，把两段焊成「111」——这正是「不能静态数段」的实例。而 $n = 39 = 100111_2$ 只有底部一段「111」，进位落在隔了两个 $0$ 的空位上不引发桥接，得 $+2^0$、$-2^3$、$-2^5$ 共 $3$ 次。

## 4. 算法细节

1. **三分支判据**：`n & 1` 区分奇偶；奇数时 `n & 2` 区分 $n \bmod 4 = 3$（进位）与 $n \bmod 4 = 1$（消位）。判据只依赖末两位，进位连锁与段桥接全部由 `n += 1` 的进位传播自动完成。
2. **操作的隐式记录**：循环里只维护 `ans`，不显式记录每步用的幂。第 $t$ 轮循环时已右移 $t$ 位，本轮的 $\pm 1$ 对应原数上的 $\pm 2^{t'}$（$t'$ 为累计折半次数），示例演算中的 $+2^1, +2^3, -2^6$ 即由此还原。
3. **备选实现：记忆化递推**。直接按 §3.2 观察三实现 $f$（边界 $f(0)=0$、$f(1)=1$），`lru_cache` 记忆化。可达状态沿「$\approx n/2^t \pm 1$」分布，每层至多常数个，共 $O(\log n)$ 个状态，与贪心同为对数级，可作对拍验证。
4. **C++ / Python 细节**：$n \le 10^5$，进位后至多 $2^{17}$，`int` 远够；Python 无溢出之虞。循环每轮至少消耗一个二进制位，$\le \lceil \log_2 n \rceil + 1$ 轮。

## 5. 正确性证明

记 $f(n)$ 为把 $n$ 变 $0$ 的最少操作数，$W(n)$ 为能把 $n$ 写成的**带符号幂之和**的最少项数。

**引理 1（操作 ↔ 带符号幂之和）**：$f(n) = W(n)$。

**证明**：给一列操作，设第 $j$ 步把当前的数加上 $\varepsilon_j 2^{i_j}$（$\varepsilon_j = \pm 1$）。把这些增量按序求和，$n + \sum_j \varepsilon_j 2^{i_j} = 0$，即 $n = -\sum_j \varepsilon_j 2^{i_j}$，是 $k$ 项带符号幂之和，故 $W(n) \le f(n)$。反之，给一个 $k$ 项的带符号幂之和 $n = \sum_j \varepsilon'_j 2^{i_j}$，依序执行「$n \mathrel{-}= \varepsilon'_j 2^{i_j}$」共 $k$ 步即归零，故 $f(n) \le W(n)$。∎

**引理 2（最优表示指数互异）**：任何项数为 $W(n)$ 的表示中，任意两项的指数互不相同。

**证明**：反证。若两项同为 $+2^i$，把它们替换成单项 $+2^{i+1}$，和不变、项数减一，得 $W(n) - 1$ 项的表示，与 $W$ 最小矛盾；若一项 $+2^i$ 与一项 $-2^i$ 并存，直接删去这两项，项数减二，同样矛盾。∎

**引理 3（偶数折半）**：$n$ 为正偶数时，$W(n) = W(n/2)$。

**证明**：「$\le$」：把 $n/2$ 的最优表示每项指数加 $1$，即得 $n$ 的表示。「$\ge$」：取 $n$ 的最优表示（引理 2，指数互异）。各项按奇偶分：奇数项只能是 $\pm 2^0$，指数互异至多两项。全部偶数项之和 $\equiv 0 \pmod 2$，而 $n$ 为偶数，故奇数项之和为偶：奇数项要么不存在，要么 $+2^0$ 与 $-2^0$ 并存（单个必为奇）；后者由引理 2 排除。于是全部指数 $\ge 1$，各项除以 $2$ 得 $n/2$ 的表示，项数不变，$W(n/2) \le W(n)$。∎

**引理 4（奇数消一位）**：$n$ 为奇数时，$W(n) = 1 + \min\bigl(W(\tfrac{n-1}{2}),\ W(\tfrac{n+1}{2})\bigr)$。

**证明**：取 $n$ 的最优表示（指数互异）。同引理 3 的奇偶分析：奇数项之和 $\equiv n \equiv 1 \pmod 2$，且 $+2^0, -2^0$ 不能并存（引理 2）、也不能为零个，故**恰有一项** $\varepsilon \cdot 2^0$。删去它，其余各项指数 $\ge 1$，整体除以 $2$，得 $\tfrac{n-\varepsilon}{2}$ 的 $W(n)-1$ 项表示。故 $\min\bigl(W(\tfrac{n-1}{2}), W(\tfrac{n+1}{2})\bigr) \le W(n) - 1$。反之，对 $m \in \{\tfrac{n-1}{2}, \tfrac{n+1}{2}\}$，把 $W(m)$ 项最优表示每项指数加 $1$，再添一项 $(n - 2m)\cdot 2^0 \in \{+2^0, -2^0\}$，得 $n$ 的 $W(m)+1$ 项表示，即 $W(n) \le W(m) + 1$。两方向合并即得等式。∎

**引理 5（1-Lipschitz）**：对一切 $x \ge 0$，$W(x+1) \le W(x) + 1$ 且 $W(x) \le W(x+1) + 1$。

**证明**：在 $x$ 的任一表示上添一项 $+2^0$ 即得 $x+1$ 的表示（不要求互异），故 $W(x+1) \le W(x)+1$；在 $x+1$ 的表示上添一项 $-2^0$ 得 $x$ 的表示，对称成立。∎

**定理（mod 4 贪心）**：设 $n \ge 2$ 为奇数，则

- (a) $n \equiv 1 \pmod 4$ 时，$W(n) = 1 + W(\tfrac{n-1}{2})$；
- (b) $n \equiv 3 \pmod 4$ 时，$W(n) = 1 + W(\tfrac{n+1}{2})$。

**证明**：(a) 记 $a = \tfrac{n-1}{2}$（偶）、$b = \tfrac{n+1}{2} = a+1$（奇）。由引理 4 只需证 $W(a) \le W(b)$。$a$ 偶，$W(a) = W(a/2)$（引理 3）；$b$ 奇，$W(b) = 1 + \min\bigl(W(\tfrac{b-1}{2}), W(\tfrac{b+1}{2})\bigr) = 1 + \min\bigl(W(\tfrac{a}{2}), W(\tfrac{a}{2}+1)\bigr) \ge 1 + (W(\tfrac{a}{2}) - 1) = W(a)$（引理 5）。(b) 记 $a = \tfrac{n-1}{2}$（奇）、$b = \tfrac{n+1}{2} = a+1$（偶）。只需证 $W(b) \le W(a)$：$W(b) = W(\tfrac{b}{2}) = W(\tfrac{a+1}{2})$（引理 3），而 $W(a) = 1 + \min\bigl(W(\tfrac{a-1}{2}), W(\tfrac{a+1}{2})\bigr) \ge 1 + \bigl(W(\tfrac{a+1}{2}) - 1\bigr) = W(b)$（引理 5）。∎

**推论**：算法返回 $f(n)$。对 $n$ 强归纳：$n = 0$ 返回 $0$。$n > 0$ 时每轮循环把 $n$ 映到 $m < n$（偶数 $m = n/2$；奇数取 $m = \tfrac{n-1}{2}$ 或 $\tfrac{n+1}{2}$，均严格小于 $n$，$n = 1$ 时取 $-1$ 分支得 $m = 0$），由引理 3/4 与定理，`ans` 的增量恰为 $W(n) - W(m)$，归纳得返回值 $= W(n) = f(n)$（引理 1）。每轮 $n$ 严格减小，算法终止。∎

## 6. 复杂度分析

- **时间复杂度**：$O(\log n)$。每轮循环消耗一个二进制位（奇数先 $\pm 1$ 变偶再右移），总轮数 $\le \lceil \log_2 n \rceil + 1$；$n \le 10^5$ 时不超过 $18$ 轮。对照 BFS 的 $O(n \log n)$ 时间——贪心把「$\pm 2^i$」翻译成「末两位 + 进位」后，规模从 $n$ 降到 $\log n$。
- **空间复杂度**：$O(1)$。仅 `ans` 与 `n` 两个变量，原地迭代。记忆化递推版本为 $O(\log n)$ 状态空间。

## 7. 参考代码

### C++（mod 4 贪心，$O(\log n)$ / $O(1)$）

```cpp
class Solution {
public:
    int minOperations(int n) {
        int ans = 0;
        while (n > 0) {
            if (n & 1) {                    // 最低位为 1，必须花 1 次消掉
                ++ans;
                n += (n & 2) ? 1 : -1;      // ≡3 mod 4：+1 进位；≡1 mod 4：-1 消位
            }
            n >>= 1;                        // 偶数：免费折半
        }
        return ans;
    }
};
```

### Python（同款贪心）

```python
class Solution:
    def minOperations(self, n: int) -> int:
        ans = 0
        while n > 0:
            if n & 1:
                ans += 1
                n += 1 if n & 2 else -1
            n >>= 1
        return ans
```

### Python（备选：记忆化递推，用于对拍验证）

```python
from functools import lru_cache

class Solution:
    def minOperations(self, n: int) -> int:
        @lru_cache(None)
        def f(m: int) -> int:
            if m <= 1:
                return m                    # f(0)=0, f(1)=1
            if m % 2 == 0:
                return f(m // 2)
            return 1 + min(f((m - 1) // 2), f((m + 1) // 2))
        return f(n)
```

## 8. 边界情况与易错点

1. **$n = 1$ 的自指陷阱**：递推 $f(1) = 1 + \min(f(0), f(1))$ 会在 $+1$ 分支无限自递归，必须单列边界 $f(1) = 1$。贪心无此问题（$1 \equiv 1 \bmod 4$ 自然走 $-1$ 分支）。
2. **$n = 2^k - 1$（全 1）**：答案 $2$（$+1$ 进位到 $2^k$，再 $-2^k$）。$n = 7, 15, 31$ 均如此——进位冲破原最高位由 `while (n > 0)` 与右移自然消化，不需要特判。
3. **贪心方向搞反**：$n \equiv 3 \pmod 4$ 时误取 $-1$，如 $n = 7$ 走 $7 \to 6 \to 3 \to 2 \to 1 \to 0$ 要 $3$ 次（正确 $2$ 次）。方向由 $n \bmod 4$ 唯一确定，不要凭「减总能变小」的直觉选。
4. **静态数段**：把答案当作「孤立段 $1$ 次 + 长段 $2$ 次」的静态计数，会在 $54$ 这类**桥接**样例上算出 $2 + 2 = 4$（正确 $3$）。必须让 `n += 1` 的进位传播动态处理，而非对初始二进制数段。
5. **进位溢出担忧**：$n \le 10^5$，$+1$ 后至多 $2^{17}$，`int` 安全；若数据范围放到 $10^{18}$，`long long` 同样够（进位至多 $2^{63}$，临界但不出界；更稳妥可用 `unsigned` 或提前判全 $1$）。
6. **与 397 整数替换混淆**：两者递推同形，但 397 目标是缩到 $1$，$n = 3$ 时须特判取 $-1$；本题目标是 $0$，$n = 3$ 取 $+1$ 才对（$3 + 1 = 4 \to 2 \to 1 \to 0$ 共 $2$ 次）。
