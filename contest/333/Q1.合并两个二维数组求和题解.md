# LeetCode 合并两个二维数组求和 题解

## 1. 题目概述

- **标题 / 题号**：合并两个二维数组求和（#2570，easy）
- **链接**：https://leetcode.cn/problems/merge-two-2d-arrays-by-summing-values/
- **来源**：LeetCode 第 333 场周赛 Q1
- **难度**：简单
- **标签**：数组、哈希表、双指针

**题意**：给定两个二维整数数组 `nums1` 与 `nums2`，每个元素形如 `[id, val]`。两数组内部的 id **互不相同**，且各自按 id **严格递增**排列。要求把它们合并成一个按 id 递增的结果数组：

- 只要某 id 在**至少一个数组**出现过，就纳入结果；
- 每个 id 在结果中**只出现一次**，其值等于两数组中该 id 对应值之和（只在一边出现则另一边按 $0$ 计）。

**约束**：

- $1 \le \text{nums1.length},\ \text{nums2.length} \le 200$
- $\text{nums1[i].length} = \text{nums2[j].length} = 2$
- $1 \le \text{idi},\ \text{vali} \le 1000$
- 每个数组内 id 互不相同，且按 id **严格递增**排列

> 💡 「两侧均已按 id 升序」是本题的题眼。签到题的目标就是**最快识别这个性质**并写出无 bug 的归并，而不是套哈希表模板。

## 2. 示例

**示例 1**

```text
输入：nums1 = [[1,2],[2,3],[4,5]], nums2 = [[1,4],[3,2],[4,1]]
输出：[[1,6],[2,3],[3,2],[4,6]]
解释：
- id=1：2 + 4 = 6
- id=2：仅 nums1 有，值 3
- id=3：仅 nums2 有，值 2
- id=4：5 + 1 = 6
```

**示例 2**

```text
输入：nums1 = [[2,4],[3,6],[5,5]], nums2 = [[1,3],[4,3]]
输出：[[1,3],[2,4],[3,6],[4,3],[5,5]]
解释：无共同 id，结果为两侧 id 的并集，各自原值。
```

**示例 3（补充：覆盖扫尾）**

```text
输入：nums1 = [[1,2],[4,5]], nums2 = [[4,1],[9,9]]
输出：[[1,2],[4,6],[9,9]]
解释：id=4 合并后 nums1 耗尽，nums2 剩余的 [9,9] 由扫尾整段拷入。
```

## 3. 解题思路

### 3.1 暴力思路：哈希表累加 + 排序

用哈希表以 id 为键累加 val，遍历完两个数组后按键排序输出：

```python
from collections import defaultdict
d = defaultdict(int)
for id_, val in nums1: d[id_] += val
for id_, val in nums2: d[id_] += val
return [[id_, d[id_]] for id_ in sorted(d)]
```

时间 $O((n+m)\log(n+m))$、空间 $O(n+m)$，在 $n,m \le 200$ 下轻松 AC。但它**完全无视「两侧已按 id 升序」**这一关键性质，白付了排序与哈希的开销——既然两侧都有序，就该用归并把时间压到线性、额外空间压到 $O(1)$。

### 3.2 核心观察：双指针归并求和

![核心观察：两条按 id 升序的 (id, val) 队列，双指针比较当前 id，同 id 求和、不同 id 取小者](images/merge_arrays_sum_concept.svg)

两个按 id 升序的数组就是**两条排好序的队列**。各取游标 $i, j$ 从队首出发，比较两侧当前 id：

- $\text{id}_1 < \text{id}_2$：`nums1` 当前 id 偏小，`nums2` 之后只会更大、不可能再有匹配，**直接收下 `nums1[i]`**，$i \mathrel{+}= 1$；
- $\text{id}_1 > \text{id}_2$：对称地收下 `nums2[j]`，$j \mathrel{+}= 1$；
- $\text{id}_1 = \text{id}_2$：两侧共同拥有此 id，**合并为 $[\text{id},\ v_1 + v_2]$ 收下**，$i, j$ 各前进一格。

这就是归并排序 merge 步骤的「并集 + 求和」版：**收入顺序天然按 id 升序，结果无需再排序**。

### 3.3 算法流程

![算法流程：初始化 → 循环条件 → 三分支比较 id → 扫尾 → 返回](images/merge_arrays_sum_flow.svg)

1. 初始化 $i = 0,\ j = 0,\ \text{ans} = []$；
2. 当 $i < n$ 且 $j < m$，按 3.2 的三分支处理；
3. 循环退出（至少一侧耗尽）后，把**未耗尽一侧的剩余整段**追加进 `ans`（扫尾）；
4. 返回 `ans`。

> ⚠️ 比较条件要写成严格 $<$ 与 $>$，让 $=$ **单独成支**。若写成 `id1 <= id2` 一刀切，相等时会只收一侧、漏掉另一侧的值与游标前进。

### 3.4 示例演算

![示例 1 演算：四步三分支 + 扫尾，得到 [[1,6],[2,3],[3,2],[4,6]]](images/merge_arrays_sum_walkthrough.svg)

以示例 1 `nums1=[[1,2],[2,3],[4,5]]`、`nums2=[[1,4],[3,2],[4,1]]` 为例：

| 步 | $i,j$ | 比较 | 动作 | ans |
|----|-------|------|------|-----|
| 0 | 0,0 | $1=1$ | 合并 $[1,\ 2+4=6]$ | $[[1,6]]$ |
| 1 | 1,1 | $2<3$ | 收 $[2,3]$ | $[[1,6],[2,3]]$ |
| 2 | 2,1 | $4>3$ | 收 $[3,2]$ | $\dots,[3,2]$ |
| 3 | 2,2 | $4=4$ | 合并 $[4,\ 5+1=6]$ | $\dots,[4,6]$ |
| 4 | 3,3 | $i{=}n,\ j{=}m$ | 两侧均空，扫尾结束 | $[[1,6],[2,3],[3,2],[4,6]]$ |

补充示例 3 则演示了**单侧扫尾**：`id=4` 合并后 `nums1` 耗尽，`nums2` 剩余的 `[9,9]` 整段拷入。示例 2 无共同 id，全程落在「取小者」两分支，交错并入即得升序并集。

## 4. 算法细节

1. **三分支严格对应** $<$、$>$、$=$，相等分支单独处理，收入 $[\text{id},\ v_1+v_2]$ 后 $i, j$ **同时**前进——两侧的该 id 都已消费完。
2. **扫尾写两个独立循环**：`while (i < n)` 与 `while (j < m)`，谁剩余拷谁（退出时最多一侧非空）。Python 用切片 `ans.extend(nums1[i:])` 一次扫尾更地道。
3. **结果不需要 `sort`**：由引理 1，收入顺序天然升序；排序只会白花 $O((n+m)\log(n+m))$。
4. **C++ 实现细节**：`ans.push_back(nums1[i++])` 直接搬整行；相等分支用聚合初始化 `{id1, v1 + v2}` 构造一行。
5. **备选：值域桶**。$1 \le \text{id} \le 1000$ 且 $val \ge 1$，可开大小 $1001$ 的桶以下标为 id 累加，最后输出所有非零桶。$O(C+n+m)$ 时间、$O(C)$ 空间，不依赖输入有序，代码最短；但 id 值域一大就失效，且失去 $O(1)$ 额外空间。

## 5. 正确性证明

**引理 1（升序收入）**：每次被收入 `ans` 的 id 严格大于上一次收入的 id。

**证明**：两数组内部 id 严格递增，游标只前进不后退，故任一时刻每侧「当前 id」严格大于该侧已被收入的所有 id；而每次收入的元素取自两侧当前 id（较小者或相等者），因此严格大于此前收入的一切 id。归纳即得。∎

**引理 2（循环不变量）**：每次循环条件判断前，`ans` 恰包含前缀 $\text{nums1}[0..i-1]$ 与 $\text{nums2}[0..j-1]$ 中出现过的所有 id——每个恰一次、值为两侧之和（缺失按 $0$）、按 id 升序。

**证明**（对循环轮数归纳）：初始 $i=j=0$，前缀为空，成立。设某轮判断前成立，考察三分支：收入后前缀恰好扩张（相等分支两侧各扩一格）；由引理 1 升序保持。若被收入的 id 仅属于一侧前缀，则另一侧当前 id 已大于它且该侧严格递增，此侧永远不会再次收入它——「缺失按 $0$」且不重复；若两侧当前 id 相等，合并分支同时消费两侧，恰收入一次且值为和。故下一轮判断前不变量仍成立。∎

**引理 3（扫尾安全）**：循环退出时，未耗尽一侧剩余的所有 id 严格大于 `ans` 中已有的每个 id。

**证明**：设退出时 $i = n$，取剩余元素 $x = \text{nums2}[k]$（$k \ge j$）与 `ans` 中任一已收入 id $y$。若 $y$ 来自 `nums1`：$y$ 被收入那一刻，`nums2` 的当前元素位于下标 $\le j \le k$，由三分支逻辑其 id $> y$（$<$ 分支）或 $= y$（$=$ 分支，且双侧消费后 $k$ 必严格大于该下标），无论哪种情形由严格递增得 $x > y$；若 $y$ 来自 `nums2` 的已处理前缀，同样由严格递增得 $x > y$。∎

**定理**：算法输出的数组按 id 严格递增，恰为两数组 id 的并集，每个 id 出现一次且值为两侧之和。

**证明**：循环部分由引理 2 覆盖；循环至多 $n+m$ 轮（每轮至少一个游标前进）。退出后由引理 3，扫尾整段追加保持升序且不重复；追加的 id 只出现于一侧，其和即原值。两部分拼接即为所求。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n+m)$。循环每轮至少一个游标前进，至多 $n+m$ 轮；扫尾拷贝的总元素数也不超过 $n+m$。这已是最优——最坏情形两数组 id 完全不重叠，必须读完两侧才能确定并集。
- **空间复杂度**：$O(1)$ 额外空间（仅游标与常数临时量，结果数组按惯例不计入）。对照：哈希表版 $O(n+m)$ 额外空间 + 排序 $O((n+m)\log(n+m))$ 时间；值域桶 $O(C)$ 空间（$C = 1001$）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<vector<int>> mergeArrays(vector<vector<int>>& nums1, vector<vector<int>>& nums2) {
        int n = nums1.size(), m = nums2.size();
        int i = 0, j = 0;
        vector<vector<int>> ans;
        while (i < n && j < m) {
            int id1 = nums1[i][0], id2 = nums2[j][0];
            if (id1 < id2) {
                ans.push_back(nums1[i++]);
            } else if (id1 > id2) {
                ans.push_back(nums2[j++]);
            } else {
                ans.push_back({id1, nums1[i][1] + nums2[j][1]});
                ++i; ++j;
            }
        }
        while (i < n) ans.push_back(nums1[i++]);
        while (j < m) ans.push_back(nums2[j++]);
        return ans;
    }
};
```

### Python

```python
class Solution:
    def mergeArrays(self, nums1: List[List[int]], nums2: List[List[int]]) -> List[List[int]]:
        n, m = len(nums1), len(nums2)
        i = j = 0
        ans = []
        while i < n and j < m:
            id1, v1 = nums1[i]
            id2, v2 = nums2[j]
            if id1 < id2:
                ans.append([id1, v1]); i += 1
            elif id1 > id2:
                ans.append([id2, v2]); j += 1
            else:
                ans.append([id1, v1 + v2]); i += 1; j += 1
        if i < n: ans.extend(nums1[i:])
        if j < m: ans.extend(nums2[j:])
        return ans
```

## 8. 边界情况与易错点

1. **相等分支只推进一侧游标**：同一 id 会被再次比较，导致重复收入或和翻倍——`=` 分支必须 $i, j$ 同时 $+1$。
2. **把 `<` 与 `=` 合并成 `<=`**：相等时只收 `nums1` 一侧，漏掉 `nums2` 的值与前进，输出错误且可能死循环。
3. **忘记扫尾**：漏掉一侧尾部的 id（补充示例 3 中会缺 `[9,9]`）；两段扫尾循环都要写，退出时最多一侧非空。
4. **哈希表暴力法忘记排序**：字典遍历顺序不保证按 id 递增，必须 `sorted(d)` 后输出。
5. **值域桶的存在性判断**：依赖 $val \ge 1$ 才能「桶值非零 ⇔ 出现过」；若值可为 $0$ 需另设布尔标记。
6. **无溢出风险**：$n, m \le 200$、$val \le 1000$，和不超过 $2000$，`int` / `int` 默认类型足够。
