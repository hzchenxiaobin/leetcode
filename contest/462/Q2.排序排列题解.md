# LeetCode 排序排列 题解

## 1. 题目概述

- **标题 / 题号**：排序排列（#3644，medium）
- **链接**：https://leetcode.cn/problems/maximum-k-to-sort-a-permutation/
- **来源**：LeetCode 第 462 场周赛 Q2
- **难度**：中等
- **标签**：位运算、排列、置换环、图连通性

**题意**：给定 `[0, n-1]` 的一个排列 `nums`。先选定一个非负整数 `k`，之后可以任意多次交换下标 `i` 和 `j` 处的元素，但每次交换必须满足**当时** `nums[i] AND nums[j] == k`（按位与恰好等于 `k`）。求能把数组排成非递减顺序（排列元素互异，即排成 `0, 1, ..., n-1`）的最大 `k`；若数组已经有序，返回 `0`。

**约束**：

- `1 <= n == nums.length <= 10^5`
- `0 <= nums[i] <= n - 1`
- `nums` 是 `0` 到 `n - 1` 的一个排列

## 2. 示例

**示例 1**

```text
输入：nums = [0,3,2,1]
输出：1
解释：选 k = 1。交换 nums[1] = 3 和 nums[3] = 1，因为 3 AND 1 = 1，得到 [0,1,2,3]。
```

**示例 2**

```text
输入：nums = [0,1,3,2]
输出：2
解释：选 k = 2。交换 nums[2] = 3 和 nums[3] = 2，因为 3 AND 2 = 2，得到 [0,1,2,3]。
```

**示例 3**

```text
输入：nums = [3,2,1,0]
输出：0
解释：只有 k = 0 时才能完成排序，因为没有更大的 k 能够满足 nums[i] AND nums[j] == k 的交换条件。
```

## 3. 解题思路

### 3.1 朴素思路：枚举 k，逐个判定

真正发生的交换满足 $k = a \text{ AND } b \le \max(a, b) \le n-1$，所以候选 $k$ 只有 $O(n)$ 个。逐个枚举 $k$、每个用 BFS 搜索所有可达排列来判定能否排序，状态数是 $n!$，完全不可行；即便把单次判定优化到 $O(n)$（例如下文的图连通性判定），总体也是 $O(n^2) \approx 10^{10}$，依然超时。

正确的打开方式：先把**判定问题**（给定 $k$ 能否排序）做透，会发现判定条件有一个封闭形式，答案可以直接算出来，一次遍历搞定。

### 3.2 核心观察一：交换只看「值」，错位值给出 k 的上界

**交换条件里没有下标什么事**：`nums[i] AND nums[j]` 看的是两个**值**。值的位置在变，但值的集合（$0..n-1$，每个恰好一次）不变，因此「哪两个值可以互换」在整个过程中是**固定**的。

把排列看成**置换环**：值 $v$ 当前在下标 $\mathrm{pos}(v)$，要回到下标 $v$。$\mathrm{pos}(v) = v$ 的值是**固定点**，不用动；其余**错位值**分成若干个环，环内互相占位。

> 💡 一个小事实：错位值集合与错位下标集合是**同一个集合**——$v$ 错位 $\iff \mathrm{pos}(v) \ne v \iff nums[v] \ne v$。

**上界论证**：错位值 $v$ 的位置要变化，所以它**至少参与一次交换**。设那一刻与它交换的值是 $w$，则 $v \text{ AND } w = k$。按位与的基本性质：

$$v \text{ AND } w = k \implies k \subseteq v \text{ 且 } k \subseteq w$$

（$k$ 的每一个二进制位都必须同时在 $v$ 和 $w$ 中，即 $k$ 是两者的公共子掩码。）于是 **$k$ 必须是每一个错位值的子掩码**。令

$$M = \bigwedge_{nums[i] \ne i} nums[i] \qquad (\text{所有错位值的按位与})$$

则任何可行的 $k$ 都满足 $k \subseteq M$，从而 $k \le M$。

![置换环与错位值：k 的上界](images/sortperm_cycles.svg)

### 3.3 核心观察二：交换图是「星形」，k = M 一定可行

反过来，$k = M$ 真的可行吗？固定 $k$，建**交换图** $G_k$：以值集 $\{0..n-1\}$ 为点集，$a \text{ AND } b = k$ 时连边 $a \leftrightarrow b$，一次合法交换就是互换一对有边的值。$G_k$ 的结构非常简单：

- 若 $k \not\subseteq v$：$v$ 缺了 $k$ 的某一位，与任何值按位与都不可能等于 $k$，是**孤立点**；
- 若 $k \subseteq v$：$k \text{ AND } v = k$，即 $v$ 与中心 $k$ 之间**必有边**——所有超集挂在 $k$ 上，形成以 $k$ 为中心的**星形连通块** $S_k = \{v : k \subseteq v\}$。

星形块内可以完成**任意重排**：对块内任意两点 $u, v$，用三条星形边即可实现一次对换

$$(u\ v) = (u\ k)(k\ v)(u\ k)$$

（共轭技巧 $\sigma\tau\sigma^{-1} = (\sigma(a)\ \sigma(b))$ 的直接应用。）于是

$$k \text{ 可行} \iff \text{每个错位值 } v \text{ 都满足 } k \subseteq v \iff \text{每个置换环整体落在同一个星形块内}$$

而 $k = M$ 恰好是每个错位值的子掩码，可行！

> ⚠️ 注意枢纽 $k$ 自己即使本来是**固定点**，也可以被拉出来当中转站——交换条件只看值，不要求参与者「本来就该动」。错位值两两之间未必能直接交换（例如错位值 $\{3, 7\}$ 取 $k = 2$ 时 $3 \text{ AND } 7 = 3 \ne 2$），但都能各自与枢纽 $k$ 换，借助 $k$ 中转即可完成排序。这是本题最容易被忽略的一点。

![交换图 G_k 的星形结构](images/sortperm_swap_graph.svg)

### 3.4 综合：答案就是错位值的按位与

上界（3.2）与可行性（3.3）合起来：

> **答案 $=$ 所有错位值的按位与 $M$；若数组已排序（无错位值），返回 $0$。**

进一步，可行的 $k$ 恰好是 $M$ 的全部子掩码（$k$ 可行 $\iff k \subseteq M$），$M$ 是其中最大的一个。特别地 $k = 0$ 恒可行——值 $0$ 与任何值按位与都是 $0$，$G_0$ 以 $0$ 为中心连通全图。

![三个示例的演算](images/sortperm_walkthrough.svg)

以示例 1 走查：`nums = [0,3,2,1]`，错位值 $\{3, 1\}$，$M = 011_2 \text{ AND } 001_2 = 001_2 = 1$，答案 $1$。若取 $k = 2$：值 $1$ 不含第 $1$ 位，$1 \text{ AND } w \le 1 < 2$ 恒成立，值 $1$ 根本动不了，不可行——与上界 $M = 1$ 一致。

## 4. 算法细节

1. **一次遍历**：`ans` 初始化为按位与的单位元「全 1」（C++ 用 `-1`，Python 直接 `-1`），对每个满足 `i != nums[i]` 的下标执行 `ans &= nums[i]`。
2. **已排序特判**：若遍历结束后 `ans` 仍为 `-1`，说明没有错位值，按题意返回 `0`。（$n \le 10^5$ 时错位值 $< 2^{17}$，只要 AND 过至少一个值，`ans` 必然 $< 2^{30}$，不会与哨兵混淆。）
3. **为什么不用真的建图**：$G_k$ 的「星形 + 孤立点」结构已把连通性判定约化为**子掩码判定**，连并查集都不需要。
4. **枢纽中转的直觉**（理解可行性用）：把每个错位值逐一与 $k$ 交换、再经 $k$ 归位，等价于在星形块内实现任意排列；即使 $k$ 本来已就位也无妨，最后把它换回去即可。

## 5. 正确性证明

**引理 1（上界 / 子掩码必要性）**：若 $k$ 可行且数组未排序，则 $k$ 是每个错位值的子掩码。

**证明**：设 $v$ 是任一错位值，其位置由 $\mathrm{pos}(v) \ne v$ 变为 $v$，故 $v$ 至少参与一次交换；设那一刻与它交换的值为 $w$，则 $v \text{ AND } w = k$。按位与结果的每一位都来自两个操作数的公共位，故 $k \subseteq v$（且 $k \subseteq w$）。对全部错位值成立。∎

**引理 2（星形结构）**：交换图 $G_k$ 的连通块为：星形块 $S_k = \{v \in [0, n) : k \subseteq v\}$（当 $S_k \ne \varnothing$ 时以 $k$ 为中心），其余每个点各自成孤立块。

**证明**：边 $(a, b)$ 存在即 $a \text{ AND } b = k$，要求 $k$ 的每位同时在 $a, b$ 中，故所有边都在 $S_k$ 内部，$S_k$ 之外的点无边。对任意 $v \in S_k$ 且 $v \ne k$，有 $k \text{ AND } v = k$，即 $v$ 与 $k$ 相邻，故 $S_k$ 内部经中心 $k$ 连通。∎

**定理**：若 `nums` 未排序，答案为 $M = \bigwedge_{nums[i] \ne i} nums[i]$。

**证明**：

- **最优性**：由引理 1，可行的 $k$ 满足 $k \subseteq v$ 对每个错位值 $v$ 成立，故 $k$ 是全体错位值按位与的子掩码，即 $k \subseteq M$，数值上 $k \le M$。
- **可行性**：数组未排序时错位值至少有两个（置换环长度 $\ge 2$），$M$ 有定义，且 $M \subseteq v \le n-1$，故 $M$ 本身是图中的一个值、$S_M \ne \varnothing$。把排序所需的置换按环分解：每个环 $(c_0\ c_1\ \cdots\ c_{t-1})$ 可写成 $t-1$ 个环内元素的对换 $(c_0\ c_{t-1})\cdots(c_0\ c_1)$，只涉及错位值。每个这样的对换 $(u\ v)$ 中 $u, v$ 都是 $M$ 的超集，由引理 2 与 $M$ 之间有边，用 $(u\ M)(M\ v)(u\ M)$ 三次合法交换实现（$u \text{ AND } M = M$，$M \text{ AND } v = M$）。故 $k = M$ 能完成排序。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。一次遍历，每个位置做一次比较和一次按位与。
- **空间复杂度**：$O(1)$。只维护一个 `ans` 变量，不建图、不开额外数组。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int sortPermutation(vector<int>& nums) {
        int ans = -1; // 全 1，作为 AND 的单位元
        for (int i = 0; i < (int)nums.size(); i++) {
            if (nums[i] != i) {
                ans &= nums[i]; // 错位值才参与 AND
            }
        }
        return ans == -1 ? 0 : ans; // 无错位值：已排序，返回 0
    }
};
```

### Python

```python
class Solution:
    def sortPermutation(self, nums: List[int]) -> int:
        ans = -1  # 全 1，作为 AND 的单位元
        for i, v in enumerate(nums):
            if v != i:
                ans &= v  # 错位值才参与 AND
        return 0 if ans == -1 else ans  # 无错位值：已排序，返回 0
```

## 8. 边界情况与易错点

1. **已排序**（含 $n = 1$）：没有错位值，按题意返回 `0`，不要把 AND 哨兵 `-1` 泄漏出去。
2. **错位值含 0**：$0$ 的子掩码只有 $0$，$M$ 必为 $0$（示例 3）。但此时数组**仍可排序**（$k=0$ 时 $0$ 与任何值可交换），不要误判成无解。
3. **答案可能是 0 但数组未排序**：别假设答案 $\ge 1$。
4. **方向别搞反**：是 $k \subseteq v$（$k$ 是每个错位值的**子**掩码），所以答案是错位值的 **AND**（越并越大的 OR 是错的）。
5. **混淆「错位下标」与「错位值」**：两者恰为同一集合（$nums[v] \ne v \iff \mathrm{pos}(v) \ne v$），遍历 `i != nums[i]` 时 AND `nums[i]` 或 `i` 结果相同，但语义上要想清楚。
6. **以为固定点不能参与交换**：交换条件只看值，枢纽 $M$ 即使已就位也可作为中转站，可行性证明正依赖于此；同理，环内两值**不能直接交换**（AND 不等于 $k$）不代表环解不开。
7. **别试图枚举 k**：$O(n)$ 个候选 × $O(n)$ 判定 = $O(n^2)$ 会超时；可行 $k$ 的集合（$M$ 的子掩码）有封闭形式，直接取 $M$。
