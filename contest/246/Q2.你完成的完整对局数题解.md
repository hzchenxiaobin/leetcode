# LeetCode 你完成的完整对局数 题解

## 1. 题目概述

- **标题 / 题号**：你完成的完整对局数（#1904，medium）
- **链接**：https://leetcode.cn/problems/the-number-of-full-rounds-you-have-played/
- **来源**：LeetCode 第 246 场周赛 Q2
- **难度**：中等
- **标签**：数学、字符串

**题意**：一款游戏以 15 分钟为一局，每天在 `HH:00`、`HH:15`、`HH:30`、`HH:45` 准点开局。给定你进入和退出游戏的时刻 `startTime`、`finishTime`（`"HH:MM"` 格式，24 小时制），统计整个会话中**从头到尾完整经历**的对局数；若 `finishTime` 早于 `startTime`，说明玩了个通宵（从 `startTime` 玩到午夜，再从午夜玩到 `finishTime`）。

**约束**：

- `startTime`、`finishTime` 均为合法 `"HH:MM"`，取值 `00:00` ~ `23:59`
- `startTime ≠ finishTime`

> 💡 **套路题切入**：本题是标准的「**网格对齐计数**」模板——把时间轴看成 15 分钟一格的网格，会话 $[s, f]$ 覆盖的**完整格子数**就是答案。进入时刻要**向上取整**吸附到格子左端，退出时刻要**向下取整**吸附到格子右端，两式相减即得 $O(1)$ 公式。唯一需要小心的分支是**通宵（环形时间）的展开**。

## 2. 示例

**示例 1**

```text
输入：startTime = "12:01", finishTime = "12:44"
输出：1
解释：只完整经历了 12:15 → 12:30 这一局。
12:00 开局的那局，进入晚于开局，不计；12:30 开局的那局，退出早于 12:45 的结束时刻，不计。
```

**示例 2**

```text
输入：startTime = "20:00", finishTime = "06:00"
输出：40
解释：通宵会话。20:00 → 00:00 完整经历 16 局，00:00 → 06:00 完整经历 24 局，共 40 局。
```

**示例 3**

```text
输入：startTime = "00:00", finishTime = "23:59"
输出：95
解释：除最后一个刻钟只完整经历 3 局外，每个整小时都完整经历 4 局。
（23:45 → 24:00 这局因 23:59 提前退出而不完整。）
```

## 3. 解题思路

### 3.1 朴素思路

一天恰有 $96$ 个候选对局 $[15k,\ 15k+15]$（$k = 0, 1, \dots, 95$）。朴素做法是先把（可能跨午夜的）会话展开成线性区间，再逐一检查每个对局是否被会话完整覆盖：$15k \ge s$ 且 $15k + 15 \le f$。单次询问 $O(96)$，本题当然能过；但它只是把「检查」逐个做一遍，没有提炼出结构——一旦询问次数增多或需要变形推广，逐个检查就显得笨重。

> ⚠️ 朴素做法的真正陷阱不在复杂度，而在两处边界：①通宵会话要先**展开成线性区间**再做包含判断；②进入/退出恰好压在对局边界时的开闭语义。这两点正是下面 $O(1)$ 公式要一次性解决掉的。

### 3.2 核心观察：网格对齐计数——$\lfloor f/15 \rfloor - \lceil s/15 \rceil$

![核心观察：进入上取整、退出下取整，中间夹住的完整格子数即答案](images/wc246_q2_grid_rounding_concept.svg)

把时间轴按 15 分钟切成网格，第 $k$ 局就是格子 $[15k, 15k+15]$。一局被**完整经历**，当且仅当它的**两端**都落在会话区间 $[s, f]$ 内（端点重合算完整——退出时刻恰为某局结束时刻时该局计入；进入晚于开局哪怕一分钟就不计入）：

- 左端不早于进入：$15k \ge s \iff k \ge \lceil s/15 \rceil$；
- 右端不晚于退出：$15k + 15 \le f \iff k \le \lfloor f/15 \rfloor - 1$。

满足条件的整数 $k$ 共有

$$\boxed{\text{完整对局数} = \max\!\bigl(0,\ \lfloor f/15 \rfloor - \lceil s/15 \rceil\bigr)}$$

**几何直觉**：进入时刻**向右吸附**到最近的格子左端，退出时刻**向左吸附**到最近的格子右端，两根吸附线之间夹住的完整格子数就是答案——被进入/退出时刻「切了一刀」的格子全部作废。

> ⚠️ **赛场高频 WA：方向搞反**。进入时刻必须**上取整**（12:01 → 12:15，12:00 开局那局已迟到），退出时刻必须**下取整**（12:44 → 12:30，之后开局那局等不到结束）。两个方向都写反，会恰好把不完整的局算进去、完整的扔掉。

### 3.3 算法流程：解析 → 展开通宵 → 取整相减

![算法流程：解析、通宵展开、取整相减三步](images/wc246_q2_overnight_flow.svg)

1. **解析**：`"HH:MM"` → 分钟数 $s = 60 \cdot HH + MM$，同理得 $f$。
2. **展开通宵**：若 $f < s$，令 $f \mathrel{+}= 1440$（一天 $24 \times 60$ 分钟），把环形时钟「剪开拉直」——次日的 $00{:}00$ 接在今天的 $24{:}00$ 之后，会话变成普通线性区间 $[s, f]$。
3. **取整相减**：答案 $= \max(0, \lfloor f/15 \rfloor - \lceil s/15 \rceil)$，其中上取整用整数除法 $\lceil s/15 \rceil = (s + 14) \,/\, 15$ 实现，全程无浮点、无分支。

> 💡 **为什么加一次 1440 就够了？** 题面保证 $s \ne f$，所以 $f < s$ 时会话一定**不足 24 小时**，展开一次即可；若 $f \ge s$ 则是同日会话，直接进入第 3 步。两种情形最终被同一个 $O(1)$ 公式统一处理。

### 3.4 示例演算

![示例演算：三组样例在网格上的走查](images/wc246_q2_examples_walkthrough.svg)

| 示例 | $s$ | $f$（展开后） | $\lceil s/15 \rceil$ | $\lfloor f/15 \rfloor$ | 答案 |
|------|-----|---------------|----------------------|------------------------|------|
| ① `"12:01"` → `"12:44"` | 721 | 764 | 49（12:15） | 50（12:30） | $50 - 49 = 1$ |
| ② `"20:00"` → `"06:00"` | 1200 | $360 + 1440 = 1800$ | 80（20:00） | 120（次日 06:00） | $120 - 80 = 40$ |
| ③ `"00:00"` → `"23:59"` | 0 | 1439 | 0（00:00） | 95（23:45） | $95 - 0 = 95$ |

**变体走查**：`"12:01"` → `"12:10"` 落在同一个刻钟里，$\lfloor 730/15 \rfloor - \lceil 721/15 \rceil = 48 - 49 = -1$，负数说明没有任何完整对局，用 $\max(0, \cdot)$ 截断为 $0$。

## 4. 算法细节

1. **解析字符串**：`"HH:MM"` 固定 5 字符，小时占 $[0, 2)$、冒号占位 2、分钟占 $[3, 5)$。C++ 用 `stoi(s.substr(0, 2)) * 60 + stoi(s.substr(3))`；Python 用 `int(s[:2]) * 60 + int(s[3:])`，也可 `h, m = map(int, s.split(":"))`。
2. **通宵判定用严格小于** `f < s`：题面保证 $s \ne f$，相等情形不存在；即使防御性地把 $f = s$（整整一天）也纳入加 1440，得到 96 局，同样自洽。
3. **上取整的整除实现**：$\lceil s/15 \rceil = (s + 14) \,/\, 15$（整数除法）。当 $s$ 恰是 15 的倍数时 $(s + 14)/15 = s/15$ **不进位**，压线进入的那局照样计入（对应示例 ② 的 20:00）。
4. **$\max(0, \cdot)$ 不可省**：会话短于一个刻钟时公式为负，直接相减会输出 $-1$ 这类负数——本题最常见的 WA。
5. **两端压线语义**：进入时刻 = 开局时刻 → 该局计入（$15k \ge s$ 取等号）；退出时刻 = 结束时刻 → 该局也计入（$15k + 15 \le f$ 取等号）。公式中的 $\ge$ / $\le$ 天然编码了这两个语义，无需额外分支。

## 5. 正确性证明

**引理 1**（通宵展开）：设 $f < s$，环形会话（今天 $[s, 1440)$ 段 + 明天 $[0, f]$ 段）中完整对局的数目，等于线性区间 $[s, f + 1440]$ 中完整对局的数目。

**证明**：把明天的时刻 $t$ 平移为 $t + 1440$，环形会话双射地映为线性区间 $[s, f + 1440]$。任一开局时刻 $15k$ 是 15 的倍数，故对局区间形如 $[15k, 15k + 15]$，其端点要么都落在今天、要么都落在（平移后的）明天，永不横跨午夜两侧。因此对局在环形意义下完整 $\iff$ 平移后的区间满足 $15k \ge s$ 且 $15k + 15 \le f + 1440$，这正是线性意义下的完整条件，两侧逐字相同，计数相等。∎

**引理 2**（计数公式）：对 $s \le f$，区间 $[s, f]$ 完整包含的对局数为 $\max(0, \lfloor f/15 \rfloor - \lceil s/15 \rceil)$。

**证明**：对局 $k$（区间 $[15k, 15k+15]$）被完整包含 $\iff 15k \ge s$ 且 $15k + 15 \le f \iff \lceil s/15 \rceil \le k \le \lfloor f/15 \rfloor - 1$。满足条件的整数 $k$ 的个数为

$$\max\bigl(0,\ (\lfloor f/15 \rfloor - 1) - \lceil s/15 \rceil + 1\bigr) = \max\bigl(0,\ \lfloor f/15 \rfloor - \lceil s/15 \rceil\bigr). \quad \blacksquare$$

**定理**：算法的返回值等于会话期间完成的完整对局数。

**证明**：若 $f \ge s$，返回值即引理 2 的公式。若 $f < s$，算法中的 `f += 1440` 正是引理 1 的展开，把环形会话化为线性区间 $[s, f + 1440]$，再由引理 2 得证。∎

## 6. 复杂度分析

- **时间复杂度**：$O(1)$。解析 5 个字符加常数次整数算术，无循环。
- **空间复杂度**：$O(1)$。仅常数个整型变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int numberOfRounds(string startTime, string finishTime) {
        int s = stoi(startTime.substr(0, 2)) * 60 + stoi(startTime.substr(3));
        int f = stoi(finishTime.substr(0, 2)) * 60 + stoi(finishTime.substr(3));
        if (f < s) f += 24 * 60;
        return max(0, f / 15 - (s + 14) / 15);
    }
};
```

### Python

```python
class Solution:
    def numberOfRounds(self, startTime: str, finishTime: str) -> int:
        s = int(startTime[:2]) * 60 + int(startTime[3:])
        f = int(finishTime[:2]) * 60 + int(finishTime[3:])
        if f < s:
            f += 24 * 60
        return max(0, f // 15 - (s + 14) // 15)
```

## 8. 边界情况与易错点

1. **同一刻钟内的短会话**（`"12:01"` → `"12:10"`）：公式给 $48 - 49 = -1$，忘记 $\max(0, \cdot)$ 会直接输出负数——本题最高频 WA。
2. **通宵漏判**：`"20:00"` → `"06:00"` 忘加 1440 时 $f < s$ 相减为负被 max 截成 0，必错；通宵分支必须显式处理。
3. **压线进入**（`"20:00"`）：恰在网格线上，上取整不得进位，$(1200 + 14)/15 = 80$ 正确吸附在原位；手写「不在格点就推后一格」的逻辑时勿把压线时刻也推后。
4. **压线退出**（`"12:15"`、`"23:45"`）：退出时刻恰为某局结束时刻，该局**计入**——下取整天然满足；误对退出端用上取整会丢掉这一局。
5. **跨午夜 + 短会话叠加**（`"23:58"` → `"00:07"`）：加 1440 后 $f = 1447$，$\lfloor 1447/15 \rfloor = \lceil 1438/15 \rceil = 96$，答案 0——午夜前后各被截断一局。
6. **一天满量程**（`"00:00"` → `"23:59"`）：95 局而非直觉的 96 局，最后一局差一分钟；确认 $\lfloor 1439/15 \rfloor = 95$。
7. **解析下标**：分钟在 `[3:]`，误写 `[2:]` 会把冒号卷进来（C++ `stoi` 停在非数字处得 0，Python 直接抛异常）。
