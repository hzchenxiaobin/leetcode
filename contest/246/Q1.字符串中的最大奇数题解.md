# LeetCode 字符串中的最大奇数 题解

## 1. 题目概述

- **标题 / 题号**：字符串中的最大奇数（#1903，easy）
- **链接**：https://leetcode.cn/problems/largest-odd-number-in-string/
- **来源**：LeetCode 第 246 场周赛 Q1
- **难度**：简单
- **标签**：贪心、数学、字符串

**题意**：给定表示大整数的字符串 `num`，在它的所有**非空子字符串**中找出**值最大的奇数**，以字符串形式返回；若不存在奇数，返回空字符串 `""`。

**约束**：

- $1 \le \text{num.length} \le 10^5$
- `num` 仅由数字组成且**不含前导零**

> 💡 **签到题切入**：两个题面条件直接决定解法形态——①「奇数」只与**末位**有关，判断是 $O(1)$ 的；②「不含前导零」保证**位数越多数值越大**，把「值最大」转化为「位最长」。抓住这两点，本题可在 1 分钟内定位到 $O(n)$ 做法。

## 2. 示例

**示例 1**

```text
输入：num = "52"
输出："5"
解释：非空子字符串有 "5"、"2"、"52"，其中唯一的奇数是 "5"。
```

**示例 2**

```text
输入：num = "4206"
输出：""
解释："4206" 中不存在奇数（所有子串都以偶数位结尾）。
```

**示例 3**

```text
输入：num = "35427"
输出："35427"
解释："35427" 本身就是奇数，且是值最大的奇子串。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有 $O(n^2)$ 个非空子串 `num[l..r]`，检查末位 `num[r]` 是否为奇数，是则与当前最大值做字符串比较。比较最坏 $O(n)$，总计 $O(n^3)$，对 $n \le 10^5$ 完全不可行。

> ⚠️ 暴力的瓶颈在于「盲目枚举所有子串」。事实上奇偶性由末位**唯一**决定——只有末位落在奇数字符上的子串才可能是奇数，其余全部可以剪掉。

### 3.2 核心观察：最右奇位的前缀即答案

![核心观察：奇偶性只看末位，最右奇位的前缀即答案](images/wc246_q1_odd_prefix_concept.svg)

三步推出结论：

**第一步：奇子串的末位必是奇数字符。** 数值 $N$ 的奇偶性等价于其十进制末位数字的奇偶性，因此所有奇子串必然以某个奇数位（下标 $i$ 满足 `num[i]` ∈ {1,3,5,7,9}）结尾。

**第二步：对每个奇数位 $i$，以它结尾的最大子串是前缀 `num[0..i]`。** `num` 无前导零，故前缀 `num[0..i]` 是 $i+1$ 位的合法正整数；任何同末位、更短的子串位数更少，数值必然更小。所以「以 $i$ 结尾的最大奇子串」就是「以 $i$ 结尾的最长子串」。

**第三步：全局最大 = 最右奇位的前缀。** 各奇数位对应的最优候选 `num[0..i]` 中，$i$ 越大位数越多、数值越大，故取**最右**奇位 $i^*$：

$$\boxed{\text{答案} = \text{num}[0..i^*], \quad i^* = \text{最右奇数字符的下标}}$$

若不存在奇数位（全偶串），返回 `""`。

> ⚠️ **赛场上最高频的 WA**：把「最大奇数」当成「最大奇数字符」。例如 `num = "2419"`，最大奇数字符是 `9`，但正确答案是 `"2419"`——以最右奇位 `9` 结尾的前缀有 4 位，数值远大于单字符 `"9"`。正确转化是「最右奇位的**前缀**」，而非「最右/最大奇位**字符**」。

### 3.3 算法流程：逆序扫描

![算法流程：从右向左扫描，命中即返回](images/wc246_q1_scan_flow.svg)

1. **初始化**：`i = n − 1`，从串尾开始。
2. **逆序扫描**：只要 `i ≥ 0`：
   - 若 `num[i]` 为奇（`num[i] % 2 == 1`）：命中最右奇位，**立即返回** `num[0..i]`；
   - 否则 `i -= 1`，继续向左。
3. **扫描结束**：循环自然退出（`i < 0`）说明全串无奇位，返回 `""`。

> 💡 **为什么逆序而不是正序？** 逆序扫描时「第一个命中的奇位」就是「最右奇位」，命中即可返回，无需扫完；正向扫描则必须扫到头才能确定「最后一个奇位」。两者最坏都是 $O(n)$，但逆序版代码最短、平均提前终止，是赛场上最快的写法。

### 3.4 示例演算

![示例演算：三组样例的逆序扫描轨迹](images/wc246_q1_walkthrough.svg)

| 示例 | `num` | 奇数位下标 | 最右奇位 $i^*$ | 返回 |
|------|-------|-----------|----------------|------|
| 1 | `"52"` | $\{0\}$（字符 `5`） | $0$ | `"5"` |
| 2 | `"4206"` | $\varnothing$（全偶） | — | `""` |
| 3 | `"35427"` | $\{0, 1, 4\}$（字符 `3, 5, 7`） | $4$ | `"35427"` |

**变体走查**：把示例 3 改成 `"35420"`（末位改偶），则 $i=4, 3, 2$ 均为偶，需扫到 $i=1$（字符 `5`）才命中，返回 `num[0..1]` = `"35"`。

## 4. 算法细节

1. **扫描方向**：从右向左，第一个奇位即目标，命中即返回；等价的正向写法是扫一遍记录「最后出现的奇位下标」，最后统一切片，但多一个变量且无提前终止。
2. **奇偶判定**：数字字符 `'0'`~`'9'` 的 ASCII 码为 48~57，奇偶性与数字本身一致（奇数字符的 ASCII 恰为奇数），故 `num[i] % 2 == 1` 或 `num[i] & 1` 可直接判定，无需先减 `'0'`；`(num[i] - '0') % 2` 更显式，两者皆可。
3. **取前缀**：C++ 用 `num.substr(0, i + 1)`——注意第二个参数是**长度** $i+1$，不是下标；Python 用切片 `num[:i + 1]`。
4. **全程字符串处理**：$n$ 可达 $10^5$ 位，远超 64 位整数范围，**任何转 `int`/`long long` 的尝试都会溢出**；好在算法只需要末位奇偶与长度，天然无需数值化。

## 5. 正确性证明

**引理 1**：正整数 $N$ 为奇数，当且仅当其十进制表示的末位数字为奇数。

**证明**：设 $N = 10q + r$，其中 $r$ 为末位数字。$10q$ 为偶数，故 $N$ 与 $r$ 的奇偶性相同，即 $N$ 为奇 $\iff r$ 为奇。∎

**引理 2**：`num` 无前导零时，对任意下标 $i$，以 `num[i]` 结尾的所有子串中，前缀 `num[0..i]` 的数值最大。

**证明**：任一以 $i$ 结尾的子串 `num[l..i]`（$l \ge 1$）有 $i - l + 1 \le i$ 位，而 `num[0..i]` 因首位 `num[0]` ≠ '0' 是 $i + 1$ 位的合法正整数。位数多的正整数严格大于位数少的正整数，故前缀最大。∎

**定理**：值最大的奇子串为 `num[0..i*]`，其中 $i^*$ 是最右奇数字符的下标；若不存在奇数字符，则不存在奇子串。

**证明**：子串为奇数当且仅当其末位下标 $i$ 是奇数位（引理 1）。对每个奇数位 $i$，其最大奇子串为 `num[0..i]`（引理 2）。这些候选的位数分别为 $i + 1$，位数随 $i$ 递增而递增，仍由引理 2 的位数比较知最大者在 $i$ 最大即 $i^*$ 处取得。若全串无奇数字符，则任何子串末位为偶数字符，由引理 1 所有子串均为偶数，不存在奇子串，返回 `""`。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。逆序扫描最坏遍历整串一次；`substr` / 切片复制至多 $n$ 个字符，与扫描合计仍为 $O(n)$。
- **空间复杂度**：$O(1)$ 额外空间，仅循环变量 `i`；若计入返回的子串则最坏 $O(n)$（输出不可避免）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    string largestOddNumber(string num) {
        for (int i = (int)num.size() - 1; i >= 0; --i) {
            if ((num[i] - '0') % 2 == 1) {
                return num.substr(0, i + 1);
            }
        }
        return "";
    }
};
```

### Python

```python
class Solution:
    def largestOddNumber(self, num: str) -> str:
        for i in range(len(num) - 1, -1, -1):
            if int(num[i]) % 2 == 1:
                return num[:i + 1]
        return ""
```

> 💡 **Pythonic 变体**：`str.rfind` 一次定位每个奇数字符的最右下标，取最大值即为 $i^*$：

>         return num[:i + 1] if i >= 0 else ""
> ```

## 8. 边界情况与易错点

1. **全偶串**（如 `"4206"`、`"24680"`）：扫描到 `i = −1` 越界退出，返回 `""`，勿忘循环外兜底返回。
2. **末位即奇**（如 `"35427"`）：一步命中，返回整串，无需特判。
3. **最大奇数 ≠ 最大奇数字符**：`"2419"` 的答案是 `"2419"` 而非 `"9"`——答案取的是**最右奇位的前缀**，与该位字符本身数值大小无关（哪怕它是 `1`）。
4. **C++ `substr` 参数**：第二参是长度 $i + 1$，误写成下标 $i$ 会少取一位。
5. **勿转整数**：$n \le 10^5$ 位，`long long` 必溢出；全程按字符串处理。
6. **奇偶判定的字符陷阱**：`num[i] % 2` 判的是 ASCII 码（48~57），恰好与数字奇偶一致才可直接用；写 `(num[i] - '0') % 2` 最稳妥。
7. **单字符输入**（`"5"` / `"2"`）：扫描一步出结果，天然覆盖，无需单独分支。
