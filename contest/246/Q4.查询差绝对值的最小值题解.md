# LeetCode 查询差绝对值的最小值 题解

## 1. 题目概述

- **标题 / 题号**：查询差绝对值的最小值（#1906，medium）
- **链接**：https://leetcode.cn/problems/minimum-absolute-difference-queries/
- **来源**：LeetCode 第 246 场周赛 Q4
- **难度**：中等
- **标签**：数组、前缀和、值域计数

**题意**：定义数组 `a` 的「差绝对值的最小值」为所有满足 $i \ne j$ **且** $a_i \ne a_j$ 的 $|a_i - a_j|$ 的最小值；若所有元素都相同，则定义为 $-1$。给定数组 `nums` 和查询数组 `queries`（`queries[i] = [l_i, r_i]`），对每个查询求**连续子数组** `nums[l_i..r_i]`（闭区间）的差绝对值的最小值，返回答案数组 `ans`。

**约束**：

- `2 <= nums.length <= 10^5`
- `1 <= nums[i] <= 100`
- `1 <= queries.length <= 2 * 10^4`
- `0 <= queries[i][0] < queries[i][1] < nums.length`

> 💡 **套路题切入**：本题是「**小值域 + 静态区间查询**」的标准模板。数据范围里 `1 <= nums[i] <= 100` 是题眼——值域只有 100，立刻锁定**值域前缀计数**：对每个值 $v$ 维护出现次数的前缀和，一次 $O(100)$ 的扫描就能回答「区间里出现了哪些值」。解法的另一半是经典观察「**排序数组的最小差取自相邻对**」。两个套路拼接即可。本题名义上是 Q4，主站评级却只有中等——是典型的「看到值域就该秒」的送分压轴。

## 2. 示例

**示例 1**

```text
输入：nums = [1,3,4,8], queries = [[0,1],[1,2],[2,3],[0,3]]
输出：[2,1,4,1]

解释：
- [0,1]：子数组 [1,3]，最小差 |1-3| = 2
- [1,2]：子数组 [3,4]，最小差 |3-4| = 1
- [2,3]：子数组 [4,8]，最小差 |4-8| = 4
- [0,3]：子数组 [1,3,4,8]，最小差 |3-4| = 1
```

**示例 2**

```text
输入：nums = [4,5,2,2,7,10], queries = [[2,3],[0,2],[0,5],[3,5]]
输出：[-1,1,1,3]

解释：
- [2,3]：子数组 [2,2]，所有元素相等，答案 -1
- [0,2]：子数组 [4,5,2]，最小差 |4-5| = 1
- [0,5]：子数组 [4,5,2,2,7,10]，最小差 |4-5| = 1
- [3,5]：子数组 [2,7,10]，最小差 |7-10| = 3
```

## 3. 解题思路

### 3.1 暴力思路

对每个查询，取出子数组 `nums[l..r]`，**去重后排序**，再线性扫一遍相邻差取最小。单次查询 $O(n \log n)$，总计

$$q \cdot n \log n \approx 2 \times 10^4 \times 10^5 \times 17 \approx 3.4 \times 10^{10}$$

次操作，远超时限。瓶颈在于：每次查询都把整段子数组「从零开始」读一遍，完全没有复用任何预处理信息。

> ⚠️ 注意暴力也必须**先去重**（或跳过排序后相等的相邻元素）：定义要求 $a_i \ne a_j$，若直接对含重复值的排序数组扫相邻差，`[2,2,7,10]` 中 `2,2` 的差 $0$ 会被误当成答案。这是本题最阴的语义陷阱，后文详述。

### 3.2 核心观察一：值域前缀计数

![核心观察一：对每个值建出现次数前缀和](images/wc246_q4_value_prefix_concept.svg)

值域只有 $[1, 100]$，共 $V = 100$ 个值。对每个值 $v$ 维护**出现次数的前缀和**：

$$\text{pre}[v][i] = \text{nums}[0..i-1] \text{ 中 } v \text{ 的出现次数}$$

则子数组 `nums[l..r]` 中值 $v$ 的出现次数为**两列相减**：

$$\text{cnt}(l, r, v) = \text{pre}[v][r+1] - \text{pre}[v][l]$$

于是「区间里出现了哪些值」不需要读原数组，只需把 $v$ 从 $1$ 到 $100$ 扫一遍、检查 $\text{cnt} > 0$ 即可。值域循环天然按升序枚举、天然去重——这正是我们需要的**有序 distinct 值序列**。

> 💡 这个「对值域每个桶建前缀和」的骨架在周赛中反复出现：字符版（26 个字母）如 1177. 使回文子串重排的最少修改，位版（32 个位）如 2564. 子数组的按位异或查询。看到「小值域 + 区间询问」，条件反射地建 $V$ 行前缀表。

### 3.3 核心观察二：最小差只取相邻对

![核心观察二：去重排序后最小差取自相邻对](images/wc246_q4_adjacent_gap.svg)

设查询区间内出现的 distinct 值升序排列为 $v_1 < v_2 < \dots < v_k$（$k \ge 2$ 才有答案）。则

$$\min_{i \ne j,\ a_i \ne a_j} |a_i - a_j| = \min_{1 \le t < k}\, \bigl(v_{t+1} - v_t\bigr)$$

**直觉**：任取一个跨度大的对 $v_i < v_j$，其差可以拆成中间每一段相邻差的和——和不会小于其中最小的一段。因此最优解一定「落在相邻」，只需一次线性扫描。证明见 §5 引理 2。

结合两个观察，单次查询的流程是：扫 $v = 1 \dots 100$，筛出 $\text{cnt}(l,r,v) > 0$ 的值（升序、无重复），对相邻对求差取最小；若 distinct 值不足 $2$ 个则返回 $-1$。

### 3.4 示例演算

![示例演算：示例 2 的四个查询走查](images/wc246_q4_walkthrough.svg)

以 `nums = [4,5,2,2,7,10]`（示例 2）为例，先建 5 行前缀计数表（只列出现过的值）：

| $i$（前 $i$ 个） | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|---|
| $v=2$  | 0 | 0 | 1 | 2 | 2 | 2 | 2 |
| $v=4$  | 0 | 1 | 1 | 1 | 1 | 1 | 1 |
| $v=5$  | 0 | 0 | 1 | 1 | 1 | 1 | 1 |
| $v=7$  | 0 | 0 | 0 | 0 | 1 | 1 | 1 |
| $v=10$ | 0 | 0 | 0 | 0 | 0 | 1 | 1 |

四个查询的走查（$k$ 为 distinct 值个数）：

| 查询 | 子数组 | $\text{cnt}>0$ 的值 | 相邻差 | 答案 |
|------|--------|--------------------|--------|------|
| $[2,3]$ | $[2,2]$ | $\{2\}$（$k=1$） | — | $-1$ |
| $[0,2]$ | $[4,5,2]$ | $\{2,4,5\}$ | $2,\ \mathbf{1}$ | $1$ |
| $[0,5]$ | $[4,5,2,2,7,10]$ | $\{2,4,5,7,10\}$ | $2,\ \mathbf{1},\ 2,\ 3$ | $1$ |
| $[3,5]$ | $[2,7,10]$ | $\{2,7,10\}$ | $5,\ \mathbf{3}$ | $3$ |

以 $[3,5]$ 为例核对两列相减：$v=2$ 取 $\text{pre}[2][6] - \text{pre}[2][3] = 2 - 1 = 1 > 0$ ✓；$v=4$ 取 $1 - 1 = 0$ ✗（值 4 只出现在下标 0，不在区间内）；$v=7$ 取 $1 - 0 = 1$ ✓；$v=10$ 取 $1 - 0 = 1$ ✓。出现的值即 $\{2,7,10\}$，相邻差 $5, 3$，答案 $3$。

## 4. 算法细节

1. **前缀表的存储方向**：`pre[i][v]`（行 = 位置，`array<int, 101>` 一行）比 `pre[v][i]`（行 = 值）更优——转移 `pre[i+1] = pre[i]; pre[i+1][nums[i]]++` 是一整行 404 字节的顺序拷贝加一次自增，cache 友好；查询时 `pre[l]`、`pre[r+1]` 各是连续 101 个 int，对 $v$ 的扫描也只碰两段连续内存。
2. **闭区间到前缀下标的偏移**：`nums[l..r]` 对应前缀表的第 $l$ 列与第 $r+1$ 列之差。数组开 $n+1$ 列，`pre[0]` 全零。差一偏移是本题高频 WA。
3. **查询内的一次扫描**：维护 `prev`（上一个出现过的值，初值 $-1$）与 `best`（初值 $+\infty$）。对 $v = 1 \dots 100$：若 $\text{cnt} > 0$，则 `best = min(best, v - prev)`（`prev` 有效时）并更新 `prev = v`。扫描结束 `best` 仍为 $+\infty$ 说明 distinct 值不足 $2$ 个，输出 $-1$。
4. **内存账**：C++ 的 $(n+1) \times 101$ 个 int 约 $40\,\mathrm{MB}$，在题目的空间限制内；若卡内存，可换成**每个值存出现下标表** `pos[v]`，判定「$v$ 是否出现在 $[l,r]$」用一次 `bisect` / `upper_bound`，空间 $O(n)$，单查询 $O(V \log n)$。
5. **Python 的效率要点**：纯 Python 双层循环建表是 $O(nV) = 10^7$ 次解释器循环，偏慢；只对 `set(nums)` 中出现过的值建行，且每行用 `itertools.accumulate`（C 实现）生成，可把内层交给 C。
6. **不要排序子数组本身**：一切「先 `sorted(nums[l:r+1])` 再扫」的写法都退回暴力复杂度；distinct 值序列由值域循环直接给出，本身就是升序。

## 5. 正确性证明

**引理 1**（前缀计数）：对任意 $0 \le l \le r < n$ 与值 $v$，$\text{pre}[v][r+1] - \text{pre}[v][l]$ 等于子数组 $\text{nums}[l..r]$ 中 $v$ 的出现次数。

**证明**：对 $i$ 归纳：$\text{pre}[v][0] = 0$ 成立；由递推 $\text{pre}[v][i+1] = \text{pre}[v][i] + [\text{nums}[i] = v]$，知 $\text{pre}[v][i]$ 恰为前 $i$ 个元素中 $v$ 的个数。于是差式 $= (\text{前 } r+1 \text{ 个中 } v \text{ 的个数}) - (\text{前 } l \text{ 个中 } v \text{ 的个数})$，恰好是下标落在 $[l, r]$ 内的出现次数。∎

**引理 2**（相邻最优）：设 $S$ 为查询区间内出现的 distinct 值集合，升序为 $v_1 < v_2 < \dots < v_k$（$k \ge 2$），则 $S$ 上不同值对之差的最小值等于相邻对之差的最小值：$\min_{i<j}(v_j - v_i) = \min_{1 \le t < k}(v_{t+1} - v_t)$。

**证明**：记左边为 $A$、右边为 $B$。相邻对是所有对的子集，故 $A \le B$。反之对任意 $i < j$，

$$v_j - v_i = \sum_{t=i}^{j-1} (v_{t+1} - v_t) \ \ge\ \min_{1 \le t < k}(v_{t+1} - v_t) = B,$$

取最小后得 $A \ge B$。两向合并不等式即 $A = B$。∎

**引理 3**（原数组与 distinct 集合等价）：当区间内 distinct 值个数 $k \ge 2$ 时，原数组上满足 $a_i \ne a_j$ 的对的最小差等于 $S$ 上不同值对的最差最小值；当 $k = 1$ 时答案为 $-1$。

**证明**：值不同的下标对 $(i, j)$ 与「$a_i, a_j$ 构成的无序值对」一一对应差值 $|a_i - a_j| > 0$，而每个这样的值对都属于 $S \times S$ 且两值不同；反之 $S$ 中任取两个不同值，区间内各存在一个下标取到它们。故两边的候选差值集合相同，最小值相同。$k = 1$ 时所有元素相等，按定义返回 $-1$。∎

**定理**：算法对每个查询返回的值等于该子数组差绝对值的最小值。

**证明**：由引理 1，扫描 $v = 1 \dots 100$ 筛出的恰为区间内 distinct 值集合 $S$，且按升序枚举；由引理 3，答案在 $|S| \ge 2$ 时化为 $S$ 上不同值对的最小差；由引理 2，它等于相邻对差的最小值，即算法中 `best` 的终值。$|S| < 2$ 时 `best` 保持 $+\infty$，算法输出 $-1$，与引理 3 的后半一致。∎

## 6. 复杂度分析

- **时间复杂度**：$O\bigl((n + q) \cdot V\bigr)$，其中 $V = 100$ 为值域大小。
  - 预处理：$n$ 次行拷贝 + 自增，每次 $O(V)$，共 $O(nV) = 10^7$。
  - 查询：$q$ 次，每次扫 $v = 1 \dots 100$，共 $O(qV) = 2 \times 10^6$。
  - 本题数据规模下总计约 $1.2 \times 10^7$，轻松通过。
- **空间复杂度**：$O(n \cdot V)$，即 $(n+1) \times 101$ 的前缀表，约 $40\,\mathrm{MB}$（int）。换「`pos[v]` 下标表 + 二分」实现可降到 $O(n)$，代价是查询变为 $O(V \log n)$。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    vector<int> minDifference(vector<int>& nums, vector<vector<int>>& queries) {
        int n = nums.size();
        const int V = 100;
        // pre[i][v]：前 i 个元素中值 v 的出现次数
        vector<array<int, V + 1>> pre(n + 1);
        for (int i = 0; i < n; ++i) {
            pre[i + 1] = pre[i];
            pre[i + 1][nums[i]]++;
        }

        vector<int> ans;
        ans.reserve(queries.size());
        for (auto& q : queries) {
            int l = q[0], r = q[1] + 1; // 闭区间 -> 前缀下标
            int best = INT_MAX, prev = -1;
            for (int v = 1; v <= V; ++v) {
                if (pre[r][v] - pre[l][v] > 0) {
                    if (prev != -1) best = min(best, v - prev);
                    prev = v;
                }
            }
            ans.push_back(best == INT_MAX ? -1 : best);
        }
        return ans;
    }
};
```

### Python

```python
from itertools import accumulate

class Solution:
    def minDifference(self, nums: List[int], queries: List[List[int]]) -> List[int]:
        # 只对出现过的值建行，accumulate 在 C 层求前缀和
        pre = {v: [0] + list(accumulate((x == v) for x in nums)) for v in set(nums)}

        ans = []
        for l, r in queries:
            vals = sorted(v for v, row in pre.items() if row[r + 1] > row[l])
            if len(vals) < 2:
                ans.append(-1)
            else:
                ans.append(min(b - a for a, b in zip(vals, vals[1:])))
        return ans
```

> 💡 **省内存变体**：不建 $n \times V$ 的前缀表，改为每个值存出现下标 `pos[v]`，用二分判定「$v$ 是否出现在 $[l, r]$」。时间 $O(n + qV\log n)$、额外空间 $O(n)$，值域变大时这是唯一可行的方向：
>
> ```python
> from bisect import bisect_left
> from collections import defaultdict
>
> class Solution:
>     def minDifference(self, nums: List[int], queries: List[List[int]]) -> List[int]:
>         pos = defaultdict(list)
>         for i, x in enumerate(nums):
>             pos[x].append(i)
>
>         ans = []
>         for l, r in queries:
>             vals = []
>             for v, ps in pos.items():
>                 i = bisect_left(ps, l)
>                 if i < len(ps) and ps[i] <= r:
>                     vals.append(v)
>             if len(vals) < 2:
>                 ans.append(-1)
>             else:
>                 vals.sort()
>                 ans.append(min(b - a for a, b in zip(vals, vals[1:])))
>         return ans
> ```

## 8. 边界情况与易错点

1. **全同值区间返回 $-1$**：distinct 值不足 $2$ 个（示例 2 的 $[2,2]$）。区间长度至少为 $2$（保证 $l_i < r_i$），但「至少两个元素」不等于「至少两个不同的值」。
2. **忘记去重 / 忽略 $a_i \ne a_j$ 约束**：对含重复的排序数组直接扫相邻差会得到 $0$（如 $[2,2,7,10]$ 的 `2,2`），而定义明确排除同值对。值域桶天然只保留「出现过」的值，规避了这个坑；暴力排序做法必须显式跳过相等的相邻元素。
3. **前缀下标偏移**：闭区间 $[l, r]$ 对应 `pre` 的第 $l$ 列与第 $r+1$ 列；表开 $n+1$ 列。写成 `pre[r] - pre[l]` 会漏掉 `nums[r]`。
4. **哨兵值选择**：`best` 初值取 $+\infty$，勿用 $0$ 当「无解」——虽然本题值域为整数、distinct 值之差至少为 $1$，$0$ 恰好不会是合法答案，但这是巧合而非保证，换个题面（如实数值域）就会翻车。
5. **`prev` 只在值出现时更新**：`prev = v` 必须放在 `cnt > 0` 分支内；放在循环外层会把「没出现过的值」也当作相邻候选。
6. **C++ 内存**：`vector<array<int, 101>>` 约 $40\,\mathrm{MB}$，注意不要顺手再复制一份表（比如按值传参）。
7. **值域边界**：本题 $v \in [1, 100]$，循环从 $1$ 到 $100$；若值域含 $0$ 需把 `pre` 行宽开到 $101$ 并调整循环起点，`prev = -1` 的哨兵要避开合法值 $0$。
