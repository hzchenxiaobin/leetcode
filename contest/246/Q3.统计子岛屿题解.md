# LeetCode 统计子岛屿 题解

## 1. 题目概述

- **标题 / 题号**：统计子岛屿（#1905，medium）
- **链接**：https://leetcode.cn/problems/count-sub-islands/
- **来源**：LeetCode 第 246 场周赛 Q3
- **难度**：中等
- **标签**：深度优先搜索、广度优先搜索、连通分量、网格

**题意**：给定两张 $m \times n$ 的二进制网格 `grid1` 与 `grid2`（`0` 表示水、`1` 表示陆地），**岛屿**是由上下左右四方向相邻的 `1` 组成的连通块。若 `grid2` 的某座岛屿的**每一个格子**在 `grid1` 中都是陆地（即被 `grid1` 中**同一座**岛屿完全包含），则称 `grid2` 中的这座岛为**子岛屿**。返回 `grid2` 中子岛屿的数目。

**约束**：

- $m = \text{grid1.length} = \text{grid2.length}$，$n = \text{grid1[i].length} = \text{grid2[i].length}$
- $1 \le m, n \le 500$
- `grid1[i][j]` 与 `grid2[i][j]` 取值均为 `0` 或 `1`

> 💡 本题在本仓库另有[每日题解 1905](../../solution/1901-2000/1905_统计子岛屿.md)：以「单趟递归 DFS 沉岛 + flag」为主线，展开两趟预处理变体与面试问答。本篇按**周赛复盘视角**重写：侧重**赛时实现选型**（为什么主推 BFS——$mn = 25$ 万格的栈深度账）、**「逐格覆盖 ⇔ 同岛包含」的等价性证明**（题面定义的化简，即引理 1），以及引理-定理结构的**计数正确性链**。两篇互为印证。

> 💡 **套路题切入**：一眼「两张网格对照 + 连通块」——[200. 岛屿数量](https://leetcode.cn/problems/number-of-islands/) 的沉岛模板上叠一个「逐格合法性」维度。本题的难点不在想到算法，而在两处严谨性：判定单位是**整座岛**（一损俱损、失配不中断漫灌），以及 $500 \times 500$ 网格下**递归爆栈**的工程风险。想清楚这两点，BFS 十分钟稳定落笔。

## 3. 解题思路

### 3.1 暴力思路：两阶段分离，甚至想给两图编号

朴素做法分两阶段：先用一遍漫灌把 `grid2` 的岛全部找出来，每座岛存成坐标列表；再逐岛遍历坐标，核对每个格子 `grid1[i][j] == 1`。时间 $O(mn)$、额外空间 $O(mn)$（坐标列表），复杂度上完全能过，但两趟遍历、两份状态，赛时写起来偏重。

更诱人的歧路是**给两张图都编号**：题面说「被 grid1 的**同一座**岛屿完全包含」，似乎必须先给 `grid1` 的岛编号（再一次漫灌 + id 数组），再对每座 `grid2` 岛查它的格子在 `grid1` 中的编号是否一致——两套编号、两个数组、一层映射，代码量和出错面都翻倍。

> ⚠️ 实际上编号完全是多余的（见引理 1）：`grid2` 的岛四连通，它的相邻两格在 `grid1` 中也相邻——只要每格都是 `grid1` 陆地，它们就自动连成**同一座** `grid1` 岛。「同一座」是被连通性免费保证的，不需要显式编号。

### 3.2 核心观察：整岛判定，一损俱损

![核心观察：整岛判定——逐格对照 grid1，一损俱损](images/wc246_q3_overlay_concept.svg)

两个观察把算法定型：

1. **判定化简**（引理 1）：「子岛屿」$\Leftrightarrow$「岛上每格 `grid1[i][j] == 1`」。逐格核对即可，无需任何编号与映射。
2. **判定单位是整座岛**：一格失配，整座作废。于是给「当前岛」挂一个 `flag`：漫灌过程中遇到失配格就把 `flag` 置 `false`；**但漫灌不能中断**——沉岛置 0 兼做 visited，半途而废会让残格被外层当成新岛，判定与计数全部错乱。

这两条把「发现岛屿」与「判定合法性」融合成**同一趟漫灌**：外层扫 `grid2`，遇到未沉的 1 就漫灌整座岛并维护 `flag`，岛沉完看 `flag` 决定是否计数。

### 3.3 算法流程：单趟 BFS 沉岛 + flag

![算法流程：单趟 BFS 沉岛与 flag 判定](images/wc246_q3_bfs_flag_flow.svg)

1. 双层扫描 `grid2`，遇到未沉的 1：置 `flag = true`，把该格置 0 并入队。
2. BFS 循环：出队 $(x, y)$；若 `grid1[x][y] == 0` 则 `flag = false`（**只记账，不 break**）；把四方向内未沉的 1 逐个**置 0 后入队**。
3. 队列空 = 整岛沉完：`flag` 仍为 `true` 则 `count++`。
4. 全部格子扫完，返回 `count`。

DFS 递归、DFS 显式栈、BFS 队列三者完全同构，只影响栈安全与峰值内存，不影响判定结果（引理 3 保证 `flag` 与漫灌顺序无关）。赛时主推 BFS 的理由见 §4。

### 3.4 示例演算

![示例 1 演算：grid2 五座岛逐个核对，得到 3 座子岛屿](images/wc246_q3_walkthrough.svg)

以示例 1 走查，`grid2` 共 5 座岛（按行扫描首次触达顺序编号）：

| 岛 | grid2 中的格子 | 关键核对（对照 grid1） | flag | 计入 |
|---|---|---|---|---|
| ① | (0,0)(0,1)(0,2)(1,2)(1,3)(1,4) | 6 格全为 1 | true | ✓ +1 |
| ② | (2,1) | grid1[2][1] = 0 | false | ✗ |
| ③ | (3,0) | grid1[3][0] = 1 | true | ✓ +1 |
| ④ | (3,2)(3,3)(4,3) | grid1[3][2] = 0 | false | ✗ |
| ⑤ | (4,1) | grid1[4][1] = 1 | true | ✓ +1 |

$count = 3$。注意 ④ 号岛：(3,3)、(4,3) 两格各自对上，但判定单位是整座岛——一损俱损。示例 2 同理：中部大岛跨过 `grid1` 的整行水线而失配作废，只剩两座单格岛计入。

## 4. 算法细节

1. **入队即沉**：格子必须在入队前（而非出队时）置 0，否则同一格会被多个邻居重复入队，队列膨胀甚至死循环。「先标记、再扩散」是漫灌的黄金律。
2. **失配只记账**：`flag = false` 后不中断漫灌，也不需要在失配时做任何额外动作——记完账继续走完四方向扩散。
3. **flag 的传递方式**：C++ 传 `bool&` 引用参数；Python 闭包用 `nonlocal`（或单元素列表模拟引用）；更函数式的写法是让递归返回「本子树是否全合法」，逐层做逻辑与——注意这里的 `&&` 只是合并返回值，漫灌早已完成，不影响访问完整性。
4. **为什么赛时主推 BFS**：最坏情形是 $500 \times 500$ 全 1 网格，构成一条约 25 万格的蛇形链，递归深度 25 万层。C++ 每帧约 40–60 字节，合计 10–15 MB，超出常见的默认栈（约 8 MB），有爆栈风险；Python 默认 `recursionlimit = 1000` 必炸，调大后仍受底层 C 栈约束。BFS 把「深度」换成「队列」，峰值仅 $O(\min(m, n))$。
5. **原地沉岛的合法性**：LeetCode 判题不复用输入数组，直接沉 `grid2` 即省掉 visited 矩阵；若场景要求保护输入，加一个 $O(mn)$ 的 `visited` 即可，逻辑不变。
6. **两趟预处理变体**：第一趟把一切「`grid2[i][j] == 1` 且 `grid1[i][j] == 0`」的格子所在岛整座沉掉（它们必非子岛屿），第二趟对剩余 `grid2` 跑纯 200 数岛模板。判定与计数彻底解耦、两趟全是熟模板，代价是格子最多被扫两遍（仍是 $O(mn)$）。

## 5. 正确性证明

**引理 1**（判定化简）：设 $C$ 是 `grid2` 的一座岛屿（四连通的 1-格集合），则「$C$ 是子岛屿」当且仅当「$C$ 中每个格子 $(i, j)$ 都满足 $\text{grid1}[i][j] = 1$」。

**证明**：（⇒）子岛屿要求被某座 `grid1` 岛完全包含，「包含」即每格都是该岛的格子，故每格 `grid1` 值为 1。（⇐）设 $C$ 中每格 `grid1` 值均为 1。任取 $C$ 内四相邻的两格 $u, v$：它们在 `grid1` 中同样是一对四相邻的陆地格，必属同一座 `grid1` 岛屿。又 $C$ 四连通，其中任意两格之间存在 $C$ 内的相邻序列，沿序列逐段应用上式，得 $C$ 的全部格子同属同一座 `grid1` 岛，即 $C$ 被该岛完全包含。∎

**引理 2**（漫灌恰走整座岛）：从 $C$ 内任意一格出发，按「只向四方向移动、只进入 `grid2` 值为 1 且未沉的格、进入即置 0」的规则漫灌（DFS 或 BFS），访问的格子集合恰为 $C$，且每格的漫灌体执行恰一次。

**证明**：先证访问集合 $\subseteq C$：漫灌只在 `grid2` 的 1-格之间沿四方向移动且起点属于 $C$，对步数归纳可知每个被访问格都与起点在 `grid2` 中四连通，故属于起点的连通块 $C$。再证 $C \subseteq$ 访问集合：对格子 $c \in C$ 与起点的 $C$ 内四邻距离 $d$ 归纳——$d = 0$ 即起点；$d = k + 1$ 时 $c$ 有一个距离为 $k$ 的邻居已被访问，而出队时必扫描其全部四邻居，故 $c$ 被触及并入队。最后证每格一次：格子进入漫灌体（入队）前被置 0，此后守卫条件 `grid2 == 1` 失败，不再第二次入队。∎

**引理 3**（flag 与遍历顺序无关）：每次漫灌结束后，`flag` 的值等于 $[\,C$ 中每格 $\text{grid1}[i][j] = 1\,]$，与漫灌采用 DFS 还是 BFS、起点选择、邻居扫描顺序均无关。

**证明**：`flag` 初值为 `true`，执行过程中唯一的改写动作是「访问到失配格时置 `false`」。由引理 2，无论顺序如何，访问集合都恰为 $C$，故 `flag` 是否被改写由集合 $C$ 唯一决定，终值也与顺序无关。∎

**定理**：算法返回值等于 `grid2` 中子岛屿的个数。

**证明**：外层按行扫描，仅在 `grid2[i][j] == 1` 时启动漫灌，且启动前该格即被置 0，故每格至多充当一次起点。由引理 2，每次漫灌恰好沉掉一整座岛，于是每座岛恰好被启动一次、判定一次。由引理 3 与引理 1，计数的充要条件 `flag == true` 等价于「该岛为子岛屿」。因此每座子岛屿恰被计入 1 次、每座非子岛屿恰被计入 0 次，无遗漏亦无重复。∎

## 6. 复杂度分析

- **时间复杂度**：$O(mn)$。外层扫描 $mn$ 个格子；漫灌中每格至多入队一次（入队即沉），出队时检查 4 个邻居，邻居检查总数 $4mn$。$m, n \le 500$ 时约 $2.5 \times 10^5$ 格、$10^6$ 次邻居检查，远低于任何限制。
- **空间复杂度**：BFS 队列最坏 $O(\min(m, n))$——满网格漫灌时队列恰好盛放一条反对角线；改用递归 DFS 则最坏栈深 $O(mn)$（25 万层，见 §4 第 4 点）。原地沉 `grid2` 不额外开 visited；若保护输入则加 $O(mn)$ 的 visited 矩阵。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int countSubIslands(vector<vector<int>>& grid1, vector<vector<int>>& grid2) {
        int m = grid1.size(), n = grid1[0].size();
        const int dx[4] = {0, 0, 1, -1};
        const int dy[4] = {1, -1, 0, 0};
        int count = 0;
        for (int i = 0; i < m; ++i)
            for (int j = 0; j < n; ++j)
                if (grid2[i][j] == 1) {
                    bool flag = true;
                    queue<pair<int, int>> q;
                    grid2[i][j] = 0;            // 入队即沉，兼做 visited
                    q.emplace(i, j);
                    while (!q.empty()) {
                        auto [x, y] = q.front();
                        q.pop();
                        if (grid1[x][y] == 0)   // 一损俱损
                            flag = false;       // 只记账，不中断漫灌
                        for (int d = 0; d < 4; ++d) {
                            int nx = x + dx[d], ny = y + dy[d];
                            if (nx >= 0 && nx < m && ny >= 0 && ny < n
                                && grid2[nx][ny] == 1) {
                                grid2[nx][ny] = 0;   // 先沉再入队
                                q.emplace(nx, ny);
                            }
                        }
                    }
                    if (flag) ++count;
                }
        return count;
    }
};
```

### Python

```python
from collections import deque

class Solution:
    def countSubIslands(self, grid1: List[List[int]], grid2: List[List[int]]) -> int:
        m, n = len(grid1), len(grid1[0])
        count = 0
        for i in range(m):
            for j in range(n):
                if grid2[i][j] == 1:
                    flag = True
                    grid2[i][j] = 0
                    q = deque([(i, j)])
                    while q:
                        x, y = q.popleft()
                        if grid1[x][y] == 0:    # 一损俱损
                            flag = False        # 只记账，不中断漫灌
                        for nx, ny in ((x, y + 1), (x, y - 1), (x + 1, y), (x - 1, y)):
                            if 0 <= nx < m and 0 <= ny < n and grid2[nx][ny] == 1:
                                grid2[nx][ny] = 0   # 先沉再入队
                                q.append((nx, ny))
                    if flag:
                        count += 1
        return count
```

> 💡 **两趟预处理变体**：先用纯 200 模板把所有「`grid2 = 1` 且 `grid1 = 0`」格所在的岛整座沉掉（必非子岛屿），再对剩余 `grid2` 做一遍标准数岛——两趟全是熟模板，代价只是格子最多被扫两遍，仍为 $O(mn)$。递归 DFS 版（`bool& flag` 与 Python `nonlocal` 等三种传递写法）见[每日版](../../solution/1901-2000/1905_统计子岛屿.md)，注意其最坏递归深度 $mn = 25$ 万层，赛时慎用。

## 8. 边界情况与易错点

1. **失配后中断漫灌（最经典 WA）**：`flag = false` 就 `return` / `break`，会让岛的残格被外层再次当作新岛启动——重复计数且判定错乱。失配只记账，岛必须整座沉完。
2. **出队才置 0（队列爆炸）**：同一格被多个邻居重复入队，队列膨胀甚至死循环。必须「入队前置 0」。同理，递归 DFS 必须「递归前置 0」而非递归后。
3. **单格岛**：既是岛也可能同时是失配格（示例 1 的 ②），`flag` 逻辑天然覆盖，无需特判。
4. **极端输入**：`grid2` 全 0 返回 0；`grid1` 全 1 时答案退化为 `grid2` 的岛屿总数——这两个样例是手写对拍的好选择；$m = n = 1$ 时只有一座可能的单格岛。
5. **递归栈深度**：$500 \times 500$ 全 1 网格递归深度 25 万层，C++ 有爆栈风险、Python 必炸默认限制——直接 BFS 或显式栈最稳（§4 第 4 点）。
6. **四连通不含对角**：邻居只取上下左右四个；写成 8 方向会连出错误的岛划分，判定从根上就错。
7. **闭包变量作用域**：Python 的 `bool` 不可变，递归闭包里改写外层变量需 `nonlocal`（或单元素列表模拟引用）；BFS 版无此问题——这也是赛时选 BFS 的隐性加分项。
8. **修改输入的边界**：原地沉 `grid2` 依赖「判题不复用输入」这一前提；工程代码或面试中先声明，必要时换 `visited` 矩阵。

**延伸思考**：① 把布尔 `flag` 换成失配计数 `cnt`，允许「至多 $k$ 格失配也算子岛屿」——漫灌时收集计数、判定改 `cnt <= k` 即可；② **并查集解法**：`grid2` 按 1-格合并，失配格把根标记进坏集合，最后数非坏根，$O(mn \cdot \alpha)$，适合岛屿结构需要留到查询阶段复用的变体；③ **反向问题**「`grid1` 中有多少座岛完整包含至少一座 `grid2` 岛」：给 `grid1` 编号后，由引理 1 每座合法的 `grid2` 岛唯一对应一个 `grid1` 岛编号，对编号去重计数即可——引理 1 的「同岛传导」正是它免去歧义的关键。
