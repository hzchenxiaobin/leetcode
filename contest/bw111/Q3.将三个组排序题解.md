# LeetCode 将三个组排序 题解

## 1. 题目概述

- **标题 / 题号**：将三个组排序（#2826，medium）
- **链接**：https://leetcode.cn/problems/sorting-three-groups/
- **来源**：LeetCode 第 111 场双周赛 Q3
- **难度**：中等
- **标签**：数组、动态规划、二分查找

**题意**：给定数组 `nums`，每个元素是 $1$、$2$ 或 $3$。每次操作可以删除 `nums` 中的一个元素。返回使 `nums` 变成**非递减**所需的最少删除次数。

**约束**：

- $1 \le n \le 100$
- $1 \le nums[i] \le 3$

**进阶**：你能用 $O(n)$ 时间解决吗？

## 2. 示例

**示例 1**

```text
输入：nums = [2,1,3,2,1]
输出：3
解释：删除 nums[0]、nums[2]、nums[3]，剩下 [1,1] 非递减。
```

**示例 2**

```text
输入：nums = [1,3,2,1,3,3]
输出：2
解释：删除 nums[1]、nums[2]，剩下 [1,1,3,3] 非递减。
```

**示例 3**

```text
输入：nums = [2,2,2,2,3,3]
输出：0
解释：数组已非递减。
```

## 3. 解题思路

### 3.1 暴力思路

枚举「保留哪些元素」的全部子集（$2^n$ 种），检查保留序列非递减并最大化保留数——指数级不可行。题面提示的正经暴力是：枚举分组切点 $0 \le i \le j \le n$，把 $[0,i)$ 的目标值定为 $1$、$[i,j)$ 定为 $2$、$[j,n)$ 定为 $3$（三段都可为空），答案为「不等于目标值的位置数」的最小值，$O(n^3)$；用前缀和优化到 $O(n^2)$。这条路可行但绕——它把「删除」翻译成「改写目标值」，而更直接的翻译是：**删除若干元素 ⇔ 保留一个子序列**。

### 3.2 核心观察：最少删除 = n − 最长非降子序列

![核心观察：删除最少 ⇔ 保留最长非降子序列](images/bw111_q3_lnds_concept.svg)

删除 $d$ 个元素后剩下的恰好是原数组的一个**子序列**（保序、连续性不要求），数组非递减当且仅当保留的子序列非降。于是：

$$\text{最少删除数} = n - \text{最长非降子序列（LNDS）长度}$$

这是「最长递增子序列（LIS）」的**非严格**版本——值域只有 $\{1,2,3\}$，相等的元素可以相邻共存（如示例 3 的 `[2,2,2,2,3,3]` 本身就非降）。正因为值域只有 3，LIS 的 $O(n \log n)$ 贪心 + 二分解法可以进一步压成 $O(n)$：维护 $dp[1..3]$ 三个值即可。

### 3.3 算法流程（O(n) 值域 DP）

![算法流程：dp[v] 的更新与状态含义](images/bw111_q3_dp_flow.svg)

```text
dp[1] = dp[2] = dp[3] = 0        # dp[v]: 以值 v 结尾的最长非降子序列长度
for x in nums:
    dp[x] = max(dp[1..x]) + 1    # 前驱可以是任何 ≤ x 的值
return n − max(dp[1..3])
```

例如 $x = 2$ 时，$dp[2] \gets \max(dp[1], dp[2]) + 1$——以 2 结尾的非降子序列，前一个元素可以是 1 或 2（不能是 3）。

**为何这就是 LNDS**：经典 LIS 的 $O(n \log n)$ 解法维护「长度为 $i$ 的上升子序列的最小结尾」，而值域压缩后直接维护「以值 $v$ 结尾的最长长度」，转移 $dp[x] = \max_{v \le x} dp[v] + 1$ 是「非严格递增」条件（$v \le x$）的直译。值域 $C = 3$ 时 $\max_{v \le x}$ 常数时间可查，总复杂度 $O(nC) = O(n)$。

### 3.4 示例演算

以示例 1 `nums = [2,1,3,2,1]` 为例：

| 元素 x | dp[1] | dp[2] | dp[3] | 说明 |
|--------|-------|-------|-------|------|
| 初始 | 0 | 0 | 0 | — |
| 2 | 0 | **1** | 0 | dp[2]=max(dp[1],dp[2])+1=1 |
| 1 | **1** | 1 | 0 | dp[1]=max(dp[1])+1=1 |
| 3 | 1 | 1 | **2** | dp[3]=max(dp[1],dp[2],dp[3])+1=2 |
| 2 | 1 | **2** | 2 | dp[2]=max(dp[1],dp[2])+1=2（子序列 [1,2]） |
| 1 | **2** | 2 | 2 | dp[1]=2（子序列 [2,1]? 非！是 [1] 接 1 → [1,1]） |

最终 $\max dp = 2$（如子序列 $[2,2]$：下标 0 与 3；或 $[1,1]$：下标 1 与 4），删除 $5 - 2 = 3$ 个，与官方答案一致。注意最后一步 $dp[1] = 2$ 对应的子序列是 $[1,1]$（下标 1、4）——以 $1$ 结尾时前驱必须 $\le 1$，只有 $dp[1]$ 能接上。

## 4. 算法细节

1. **非严格 vs 严格**：本题是**非降**（$\le$），转移用 $\max_{v \le x} dp[v]$；若误写成 $v < x$（严格递增），示例 3 的 `[2,2,2,2,3,3]` 会错误地算出 LNDS = 2（$[2,3]$），返回 4 而非 0。
2. **dp 的语义**：$dp[v]$ 是「**以值 $v$ 结尾**」的最长长度，不是「前 $i$ 个元素里值恰好 $v$ 的个数」；更新发生在每个元素到达时，逐元素滚动。
3. **O(n²) 通用版**：值域若不止 3（比如 2826 的英文原题变体「Sorting Three Groups」泛化为任意值），用经典 $dp[i] = \max\{dp[j]+1 : j<i, nums[j] \le nums[i]\}$，$O(n^2)$ 或二分 $O(n \log n)$（`upper_bound` 对应非严格版）。本题值域 3 是其特例。
4. **分组切点法（题面提示的 $O(n^2)$ 法）**：枚举 $0 \le i \le j \le n$，代价 = $\#\{p < i : nums[p] \ne 1\} + \#\{i \le p < j : nums[p] \ne 2\} + \#\{p \ge j : nums[p] \ne 3\}$。用三个前缀计数数组可 $O(1)$ 查每组的代价。它与 LNDS 法等价（见 §5 引理 2 的证明思路），可作交叉验证。
5. **初始化**：$dp$ 全 0；$n = 1$ 时任何单元素非降，答案 0（$1 - 1 = 0$），无需特判。
6. **无溢出**：计数与长度都 $\le 100$，`int` 足够。

## 5. 正确性证明

**引理 1（删除 ⇔ 保留子序列）**：删除若干元素后得到的数组是原数组的一个子序列；反之任何子序列都可经删除其余元素得到。数组剩余部分非递减 ⇔ 该子序列非降。

**证明**：删除保序，剩余元素按原下标排列即子序列定义；逆操作显然。「非递减」作用在剩余序列上，与子序列的逐项比较是同一件事。∎

**引理 2（最优保留 = LNDS）**：设 $L$ 为 `nums` 最长非降子序列的长度，则最少删除数为 $n - L$。

**证明**：（≤）保留一个长度为 $L$ 的非降子序列、删除其余 $n - L$ 个元素，所得数组非递减，故最少删除数 $\le n - L$。（≥）设某方案删除 $d$ 个元素后非递减，由引理 1 保留部分是一个长度为 $n - d$ 的非降子序列，故 $n - d \le L$，即 $d \ge n - L$。两端合并得 $d_{\min} = n - L$。∎

**引理 3（dp 计算的正是 LNDS）**：处理完前 $i$ 个元素后，$dp[v]$ 等于「前 $i$ 个元素中以值 $v$ 结尾的非降子序列的最大长度」。

**证明**：对 $i$ 归纳。$i = 0$ 时所有 $dp[v] = 0$（无元素，长度 0）成立。设处理完前 $i$ 个元素时命题成立，第 $i+1$ 个元素为 $x$：以 $x$ 结尾、长度 $\ge 2$ 的非降子序列去掉末尾 $x$ 后是「以某个 $v \le x$ 结尾」的非降子序列（非降条件要求前驱值 $\le x$，且前驱取值范围 $[1, x]$）；反之把 $x$ 接到任何「以 $v \le x$ 结尾」的非降子序列尾部仍非降。因此新 $dp[x]$ 应为 $\max(\max_{v \le x} dp[v] + 1,\ 1) = \max_{v \le x} dp[v] + 1$（$dp \ge 0$ 已涵盖单元素情形）。其他 $dp[v']$（$v' \ne x$）不受影响：以 $v'$ 结尾的子序列若不含第 $i+1$ 个元素，长度上界不变；若含它则结尾值是 $x \ne v'$，矛盾，故不改变。归纳完成。∎

**定理**：算法返回最少删除次数。

**证明**：由引理 3，终止时 $\max_{v} dp[v]$ 为全数组 LNDS 长度 $L$；由引理 2，$n - L$ 即最少删除数，算法返回该值。∎

## 6. 复杂度分析

- **时间**：$O(nC) = O(n)$（$C = 3$ 为值域大小）。每个元素做一次 $\le 3$ 项的取 max 与一次自增；$n = 100$ 远低于上限，即使值域放大到 $C$，复杂度 $O(nC)$，或改用二分贪心 $O(n \log C)$。
- **空间**：$O(C) = O(1)$，仅三个整型变量（或长度 4 的数组）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minimumOperations(vector<int>& nums) {
        int dp[4] = {0, 0, 0, 0};          // dp[v]: 以值 v 结尾的最长非降子序列长度
        for (int x : nums) {
            int best = 0;
            for (int v = 1; v <= x; ++v) best = max(best, dp[v]);
            dp[x] = best + 1;
        }
        int keep = max({dp[1], dp[2], dp[3]});
        return (int)nums.size() - keep;
    }
};
```

### Python

```python
class Solution:
    def minimumOperations(self, nums: list[int]) -> int:
        dp = [0] * 4                        # dp[v]: 以值 v 结尾的最长非降子序列长度
        for x in nums:
            dp[x] = max(dp[:x + 1]) + 1
        return len(nums) - max(dp[1:4])
```

> 💡 两份代码均通过官方示例（`3`、`2`、`0`），并与两种独立暴力——「枚举 $2^n$ 保留子集」与「枚举分组切点 $0 \le i \le j \le n$」——各做了 20 万组（C++）/ 2 万组（Python）随机对拍（$n \le 12$，值域 $\{1,2,3\}$），另与 $O(n^2)$ 标准 LNDS 在 $n = 100$ 大数组上交叉验证，失配数为 0。

## 8. 边界情况与易错点

1. **非严格递增**：相等元素可以共存，转移必须允许 $v = x$（`dp[:x+1]` 含 $dp[x]$ 自己）；写成严格版会在全同数组（如 `[2,2,2,2,3,3]`）上直接错。
2. **`dp[x] = max(...) + 1` 而非 `max(...+1, dp[x])`**：后者把旧值一起比较，等价于允许「跳过当前元素更新以 $x$ 结尾的长度」——但以 $x$ 结尾且不含当前元素的子序列在上一次以 $x$ 出现时已统计，此处再取 max 不会错却也无益；标准写法是直接覆盖（两种写法结果相同，覆盖版语义更清晰，见 §5 引理 3 的归纳）。
3. **答案方向**：是「删除数」$n - L$，不是「保留数」$L$；提交前用示例 1（$5 - 2 = 3$）自检。
4. **值域下标**：`dp` 开 4 个格子（下标 0 弃用），避免 $x = 3$ 越界；Python 切片 `dp[:x+1]` 右端开区间，恰好覆盖 $1..x$。
5. **单元素 / 全部相同**：$n = 1$ 返回 0；`[1,1,1]` 返回 0（LNDS = 3），无需特判。
6. **进阶误导**：题目进阶问 $O(n)$，别为了「进阶」硬上 $O(n \log n)$ 的 tails 数组 + 二分——值域 3 时直接值域 DP 更简单也更快；二分版是非降 LIS 用 `upper_bound` 的通用套路，值得记住但本题用不上。
