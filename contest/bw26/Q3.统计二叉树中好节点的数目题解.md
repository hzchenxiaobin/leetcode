# LeetCode 统计二叉树中好节点的数目 题解

## 1. 题目概述

- **标题 / 题号**：统计二叉树中好节点的数目（#1448，medium）
- **链接**：https://leetcode.cn/problems/count-good-nodes-in-binary-tree/
- **来源**：LeetCode 第 26 场双周赛 Q3
- **难度**：中等
- **标签**：树、深度优先搜索、广度优先搜索、二叉树

**题意**：给定二叉树根 `root`。节点 X 是「好节点」，当且仅当**从根到 X 的路径上**（含 X 自身）没有任何节点的值**大于** X 的值。返回树中好节点的数目。

**约束**：

- 二叉树节点数目范围 $[1, 10^5]$
- 每个节点权值范围 $[-10^4, 10^4]$

## 2. 示例

**示例 1**

```text
输入：root = [3,1,4,3,null,1,5]
输出：4
解释：根 3 总是好节点；节点 4（路径 3→4）、节点 5（路径 3→4→5）、
节点 3（路径 3→1→3，没有比它大的）是好节点，共 4 个。
```

**示例 2**

```text
输入：root = [3,3,null,4,2]
输出：3
解释：节点 2 不是好节点：路径 3→3→2 中，根 3 大于 2。
```

**示例 3**

```text
输入：root = [1]
输出：1
解释：单节点树，根本身是好节点。
```

## 3. 解题思路

### 3.1 暴力思路

对每个节点，从根**重新走一遍**到它的路径、检查路径最大值是否不超过它——$O(n^2)$（链状树退化最坏），$n = 10^5$ 时约 $10^{10}$ 次操作，超时。观察浪费：从根走到某个节点的那条路径，其前缀信息在遍历中**本来就是现成的**，没必要每个节点重算。

### 3.2 核心观察：DFS 携带「路径最大值」即可判定

![DFS 携带路径最大值：进入节点时更新并判定](images/bw26_q3_pathmax_concept.svg)

好节点的判定只依赖**根到该节点路径上的最大值**。做一次 DFS，把"当前路径的最大值 `pathMax`"作为参数**沿递归下传**：

- 进入节点 `node` 时，若 `node->val >= pathMax`，它是好节点（路径上无人比它**大**），计数加一；
- 更新 `pathMax = max(pathMax, node->val)`，继续递归左右子树；
- 每个节点恰好被访问一次，判定 $O(1)$。

回溯时**无需撤销** `pathMax`——因为它是值传递（或递归返回后自动恢复），兄弟子树各自拿到的是自己路径上的最大值，互不污染。

### 3.3 算法流程

![算法流程：递归三步——判定、更新、下传](images/bw26_q3_algorithm_flow.svg)

```text
dfs(node, pathMax):
    若 node 为空：返回 0
    cnt = (node.val >= pathMax) ? 1 : 0
    nxt = max(pathMax, node.val)
    返回 cnt + dfs(node.left, nxt) + dfs(node.right, nxt)

主函数：返回 dfs(root, -∞)
```

初始 `pathMax` 取 $-\infty$（如 `-inf` / `INT_MIN`），保证根节点必然计数（根路径上只有它自己）。

### 3.4 示例演算

![示例演算：示例 1 树的逐节点判定](images/bw26_q3_example_walkthrough.svg)

以示例 1（`root = [3,1,4,3,null,1,5]`）为例：

| 节点 | 根到该节点路径 | pathMax（到达前） | 判定 |
|------|---------------|------------------|------|
| 3（根） | 3 | $-\infty$ | ✓ 好 |
| 1（左子） | 3,1 | 3 | ✗（1 < 3） |
| 3（左左叶） | 3,1,3 | 3 | ✓（3 ≥ 3，等于不算"大于"） |
| 4（右子） | 3,4 | 3 | ✓（4 ≥ 3） |
| 1（4 的左子） | 3,4,1 | 4 | ✗（1 < 4） |
| 5（4 的右子） | 3,4,5 | 4 | ✓（5 ≥ 4） |

好节点共 4 个：根 3、左左叶 3、右子 4、右右叶 5，与示例输出一致。

## 4. 算法细节

1. **判定用 `>=` 不是 `>`**：定义是"没有任何节点**大于** X"，等于 X 的前驱不破坏好节点资格（示例 2 中路径 3→3 的第二个 3 是好节点）。
2. **`pathMax` 更新时机**：先判定再更新（或同步），进入孩子前必须更新；顺序写反会把"等于当前最大值"的节点误杀。
3. **初始值**：用 $-\infty$（`INT_MIN` 够用，因为 $val \ge -10^4 > INT\_MIN$）而非 `root->val` 特判根——统一入口少一个分支。Python 可用 `float("-inf")`。
4. **递归深度**：$n = 10^5$ 的链状树递归深 $10^5$ 层，Python 默认递归栈（1000）会溢出：要么 `sys.setrecursionlimit(2 * 10^5)`，要么改写为**显式栈/队列的迭代版**（BFS 带路径最大值，队列元素存 `(node, pathMax)`）。
5. **无需全局变量回溯**：`pathMax` 作为参数传递天然"各路径独立"；若用成员变量保存，进入子树前压栈、退出后弹栈，反而易错。

## 5. 正确性证明

**引理 1（路径前缀的单调性）**：从根到节点 $X$ 的路径上，任何前缀路径的最大值不超过整条路径的最大值；且把考察范围从"整条路径"换成"到达 $X$ 前的前缀"后，`pathMax` 传到 $X$ 处的值恰为 $X$ 之前所有节点值的最大值。

**证明**：归纳于递归深度。根调用时 `pathMax = -∞`，"根之前无节点"成立。设进入节点 $u$ 时 `pathMax` 等于根到 $u$ 的路径（不含 $u$）上节点值的最大值。递归进入孩子 $v$ 时传入 `nxt = max(pathMax, u.val)`，即根到 $v$ 的路径（不含 $v$）上值的最大值。归纳成立。∎

**定理**：DFS 返回的计数等于树中好节点数目。

**证明**：每个节点恰被访问一次（树无环，DFS 恰好遍历每个节点一次）。对节点 $X$，由引理 1，判定时刻的 `pathMax` 是根到 $X$ 路径上除 $X$ 外所有节点值的最大值 $m$。"路径上没有任何节点的值大于 $X$ 的值" ⇔ "$X$ 之前的部分最大值 $m \le X.val$ 且 $X$ 自身不大于自己（恒真）" ⇔ `$X.val >= pathMax`。故每个节点的计数条件与好节点定义逐点等价，计数之和即好节点总数。∎

## 6. 复杂度分析

- **时间**：$O(n)$。每个节点恰好一次访问、常数次比较。
- **空间**：$O(h)$，$h$ 为树高——递归栈深度；最坏（链状树）$O(n)$，平衡时 $O(\log n)$。迭代 BFS 版为队列开销 $O(w)$（$w$ 为最大宽度，最坏 $O(n)$）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int goodNodes(TreeNode* root) {
        return dfs(root, INT_MIN);
    }
private:
    int dfs(TreeNode* node, int pathMax) {    // pathMax：根到当前节点路径上的最大值
        if (!node) return 0;
        int cnt = node->val >= pathMax ? 1 : 0;
        int nxt = max(pathMax, node->val);
        return cnt + dfs(node->left, nxt) + dfs(node->right, nxt);
    }
};
```

### Python

```python
class Solution:
    def goodNodes(self, root: TreeNode) -> int:
        def dfs(node, path_max):              # path_max：根到当前节点路径上的最大值
            if node is None:
                return 0
            cnt = 1 if node.val >= path_max else 0
            nxt = path_max if path_max > node.val else node.val
            return cnt + dfs(node.left, nxt) + dfs(node.right, nxt)
        return dfs(root, float("-inf"))
```

> 💡 两份代码均通过全部官方示例（3 组）；并与「枚举所有根到叶路径、逐位置检查前缀最大值」的独立暴力在 800 组随机二叉树（$n \le 40$，权值含负数与重复）上对拍，`mismatch = 0`。Python 递归版在 $n = 10^5$ 的链状树上需先调大递归深度（见 §8）。

## 8. 边界情况与易错点

1. **负权值**：节点值可以低至 $-10^4$，初始 `pathMax` 必须小于一切可能值（`INT_MIN` 恰可，因其严格小于 $-10^4$）；误用 0 初始化会把全负树数错。
2. **`>=` 判定**：路径上"等于我"的前驱不算破坏（示例 2 的第二个 3），用 `>` 会漏计。
3. **更新与判定的顺序**：`cnt` 用的是**未包含自身**的 `pathMax`；若先更新再判定，等于自身的节点会被漏计（例如根）。两处顺序颠倒是对拍最容易抓出来的 bug。
4. **Python 递归深度**：$n = 10^5$ 链状树超默认栈；`sys.setrecursionlimit(300000)` 或改迭代。C++ 栈深 $10^5$ 一般安全（每帧很小），但保守可同样改迭代。
5. **空树**：约束保证 $n \ge 1$；若复用到可空树场景，`dfs(nullptr, ...)` 返回 0 已天然处理。
6. **不要用全局最大值**：判定是"**路径**上的最大值"，不是"全树最大值"——全树最大值会把所有非最大值节点的左子树全部误杀。

**延伸思考**：「DFS 携带路径信息」是一类通用模式——携带的聚合量随题目变化：最大值（本题）、最大值与最小值（1026）、上下界（BST 验证）、路径和（路径总和系列）、异或值（1457. 二叉树中的伪回文路径）。它们的共同点是把 $O(n)$ 条路径的共享前缀**增量维护**成 $O(1)$ 的下传参数，从而把朴素的 $O(n^2)$ 逐路径检查压缩到一次 $O(n)$ 遍历。若好节点的定义改成"严格大于路径上所有前驱"（`>` 语义），只需把判定改成 `val > pathMax` 并注意等于时的口径——引理/定理的证明结构原样保留。
