# LeetCode 连续字符 题解

## 1. 题目概述

- **标题 / 题号**：连续字符（#1446，easy）
- **链接**：https://leetcode.cn/problems/consecutive-characters/
- **来源**：LeetCode 第 26 场双周赛 Q1
- **难度**：简单
- **标签**：字符串

**题意**：字符串的「能量」定义为：**只包含一种字符**的最长非空子字符串的长度。给定字符串 $s$，返回它的能量。

**约束**：

- $1 \le |s| \le 500$
- $s$ 只含小写英文字母

## 2. 示例

**示例 1**

```text
输入：s = "leetcode"
输出：2
解释："ee" 是最长的只含一种字符的子串，长度 2。
```

**示例 2**

```text
输入：s = "abbcccddddeeeeedcba"
输出：5
解释："eeeee" 是最长的只含一种字符的子串，长度 5。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有子串 $O(n^2)$ 个、逐个检查是否单一字符——$O(n^3)$；稍加观察可以按每个起点向右扩展到不同字符为止，$O(n^2)$。$n \le 500$ 都能过，但完全没有必要：字符串天然被"字符变化处"切成若干**游程（run）**，答案是游程长度的最大值。

### 3.2 核心观察：字符串 = 若干极大同字符游程的拼接

![游程切分：字符串被字符变化处切成连续段](images/bw26_q1_runs_concept.svg)

只含一种字符的子串不可能跨越两个不同的字符，所以"只含一种字符的最长子串"一定**完整落在某一个极大游程内部**，且就等于该游程本身的长度（游程内全同字符，越长越好）。于是答案就是：

$$\max_{\text{游程 } R} |R|$$

一次线性扫描即可：维护当前游程长度 `run`，$s_i = s_{i-1}$ 时加一、否则重置为 1，顺手维护最大值。

### 3.3 算法流程

![一趟扫描的流程：延长或重置当前游程](images/bw26_q1_algorithm_flow.svg)

```text
1. best = run = 1（首字符自成一段）
2. 对 i = 1..n-1：
       若 s[i] == s[i-1]：run = run + 1
       否则：run = 1
       best = max(best, run)
3. 返回 best
```

### 3.4 示例演算

![示例演算：leetcode 与 abbcccddddeeeeedcba](images/bw26_q1_example_walkthrough.svg)

以 `"leetcode"` 为例：游程为 `l`、`ee`、`t`、`c`、`o`、`d`、`e`，长度 $1,2,1,1,1,1,1$，最大值 $2$。以 `"abbcccddddeeeeedcba"` 为例：游程长度 $1,2,3,4,5,1,1,1$，最大值 $5$。

## 4. 算法细节

1. **`run` 的初值是 1 不是 0**：单个字符本身就是长度为 1 的游程；$n \ge 1$ 保证答案至少为 1。
2. **重置为 1 而不是 0**：遇到新字符时，新游程以该字符开头，长度从 1 重新计数。
3. **比较对象是相邻字符**：`s[i] == s[i-1]`，不要误写成 `s[i] == s[0]` 或与游程起点比较（虽然结果等价，但相邻比较实现最简）。
4. **无需记录游程的"字符是谁"**：只关心长度；换字符时旧游程作废，天然由重置处理。
5. **空间可以压到两个变量**：`best` 与 `run`，$O(1)$。

## 5. 正确性证明

**引理 1**：任何只含一种字符的子串 $T$ 必然完整落在某个极大同字符游程内。

**证明**：设 $T = s[l..r]$ 只含字符 $c$。极大游程把 $[0, n)$ 划分成若干**极大**同字符区间（每个区间内字符相同，相邻区间字符不同）。若 $[l, r]$ 跨越两个区间 $A, B$ 的边界，则存在 $j \in [l, r]$ 使 $s_j \ne s_{j+1}$，而 $T$ 内所有字符相同，矛盾。故 $[l, r]$ 落在单一区间内；该区间全为字符 $c$，是合法游程。∎

**定理**：字符串的能量 $= \max_{\text{极大游程 } R} |R|$。

**证明**：一方面，每个极大游程 $R$ 本身是只含一种字符的子串，故能量 $\ge \max_R |R|$。另一方面，任取只含一种字符的子串 $T$，由引理 1，$T$ 落在某个极大游程 $R$ 内，故 $|T| \le |R| \le \max_R |R|$；对 $T$ 取最大得能量 $\le \max_R |R|$。两边夹得证。∎

**推论**：一趟扫描算法返回 $\max_R |R|$。

**证明**：归纳：处理完前缀 $s[0..i]$ 后，`run` 等于 $s[0..i]$ 末尾所在的极大游程（截断到末尾）的长度，`best` 等于 $s[0..i]$ 中所有完整出现过的游程的最大长度。$i = 0$ 时 `run = best = 1` 成立。若 $s_i = s_{i-1}$，末游程延长 1，转移正确；若 $s_i \ne s_{i-1}$，末游程在 $i-1$ 处封口（其长度已计入 `best`），新游程以 $s_i$ 开头长度 1，重置正确。处理完 $s[0..n-1]$ 后 `best` 即全串最大游程长度，由定理即为答案。∎

## 6. 复杂度分析

- **时间**：$O(n)$。单趟扫描，每个字符一次比较与常数次更新。
- **空间**：$O(1)$。仅 `best`、`run` 两个整型变量（不计输入）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maxPower(string s) {
        int best = 1, run = 1;                // 单字符也是一个游程
        for (size_t i = 1; i < s.size(); ++i) {
            run = (s[i] == s[i - 1]) ? run + 1 : 1;
            best = max(best, run);
        }
        return best;
    }
};
```

### Python

```python
class Solution:
    def maxPower(self, s: str) -> int:
        best = run = 1                        # 单字符也是一个游程
        for i in range(1, len(s)):
            run = run + 1 if s[i] == s[i - 1] else 1
            best = max(best, run)
        return best
```

> 💡 两份代码均通过全部官方示例（2 组），并与「记录每个位置游程长度再取最大」的分组双重实现在 2000 组随机串（`ab` 字母表制造高频切换）上对拍，`mismatch = 0`。

## 8. 边界情况与易错点

1. **全串同字符**（`"aaaa"`）：只有一个游程，答案 $n$；循环里 `run` 一路加到 $n$，`best` 同步更新，无需特判。
2. **全串无重复**（`"abcdef"`）：答案 1；`run` 反复重置为 1，`best` 保持 1。
3. **初值**：`best = run = 1`。若初始化为 0，单字符输入 `"a"` 会错误返回 0。
4. **比较相邻字符**：写 `s[i] == s[i-1]`；与"游程首字符"比较虽然等价但需多维护一个变量，徒增出错面。
5. **`size_t` 与 `int` 混用**：C++ 中 `s.size() - 1` 在空串时下溢；本题 $n \ge 1$ 安全，但循环从下标 1 开始可以完全避开下溢。
