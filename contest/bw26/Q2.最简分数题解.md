# LeetCode 最简分数 题解

## 1. 题目概述

- **标题 / 题号**：最简分数（#1447，medium）
- **链接**：https://leetcode.cn/problems/simplified-fractions/
- **来源**：LeetCode 第 26 场双周赛 Q2
- **难度**：中等
- **标签**：数学、字符串、最大公约数、数论、欧几里得算法

**题意**：给定整数 $n$，返回所有**严格介于 0 和 1 之间**（不含两端）且分母不超过 $n$ 的**最简分数**，以字符串 `"分子/分母"` 表示，任意顺序均可。最简分数指分子分母的最大公约数为 1。

**约束**：

- $1 \le n \le 100$

## 2. 示例

**示例 1**

```text
输入：n = 2
输出：["1/2"]
解释：分母不超过 2 的 0 到 1 之间的最简分数只有 1/2。
```

**示例 2**

```text
输入：n = 3
输出：["1/2","1/3","2/3"]
```

**示例 3**

```text
输入：n = 4
输出：["1/2","1/3","1/4","2/3","3/4"]
解释："2/4" 不是最简分数，可约成 "1/2"。
```

**示例 4**

```text
输入：n = 1
输出：[]
解释：分母为 1 时不存在 0 与 1 之间的分数。
```

## 3. 解题思路

### 3.1 暴力思路

枚举分母 $d \le n$、分子 $j < d$，检查 $\gcd(j, d) = 1$ 后输出——$O(n^2 \log n)$，$n \le 100$ 至多约一万次 gcd，正是标程做法。若想进一步"省 gcd"，可对每个分母 $d$ 用**埃氏筛思想**：从小到大枚举 $d$，只把"未被更小分母筛掉"的分子留下——但实现复杂度反而更高，本题规模下直接 gcd 最干净。

### 3.2 核心观察：分母固定时，恰有 φ(d) 个最简分数

![法里序列点阵：每行分母 d 恰有 φ(d) 个互质分子](images/bw26_q2_coprime_concept.svg)

对固定分母 $d$，分子 $j \in [1, d-1]$ 中与 $d$ 互质的恰有 $\varphi(d)$ 个（欧拉函数）。全体答案即 $\sum_{d=2}^{n} \varphi(d)$ 个，按行拼起来就是著名的**法里数列（Farey sequence）** $F_n$。这个视角有两个用处：

1. **答案规模**：$\sum_{d \le 100} \varphi(d) \approx 3000$，任何 $O(n^2)$ 以下的做法都绰绰有余；
2. **验证手段**：条数必须精确等于 $\sum \varphi(d)$，可作为代码正确性的独立断言（本文 §7 的对拍正是用了它）。

### 3.3 算法流程

![枚举流程：分母从 2 到 n，分子小于分母，互质才收集](images/bw26_q2_gcd_flow.svg)

```text
1. res = []
2. 对 d = 2..n：              # 分母从 2 起（d=1 无解）
       对 j = 1..d-1：        # 分子严格小于分母（值在 0、1 之间）
           若 gcd(j, d) == 1：res.append("j/d")
3. 返回 res
```

`gcd` 用辗转相除（欧几里得算法），C++ 可直接调 `std::gcd`（`<numeric>`），Python 用 `math.gcd`。

### 3.4 示例演算

![示例演算：n=4 逐行筛出最简分数](images/bw26_q2_example_walkthrough.svg)

以 $n = 4$ 为例：

| 分母 $d$ | 候选分子 | 保留（$\gcd = 1$） |
|---------|---------|-------------------|
| 2 | 1 | $1/2$ |
| 3 | 1, 2 | $1/3,\ 2/3$ |
| 4 | 1, 2, 3 | $1/4,\ 3/4$（$2/4$ 被约去） |

共 $1 + 2 + 2 = 5$ 个，与 $\varphi(2) + \varphi(3) + \varphi(4) = 1 + 2 + 2 = 5$ 吻合。

## 4. 算法细节

1. **分母从 2 开始**：$d = 1$ 时没有合法分子（$j \in [1, 0]$ 为空），$n = 1$ 自然返回空表。
2. **分子上界是 $d - 1$**：$j = d$ 得 1（含端点，非法），$j > d$ 超过 1。
3. **gcd 判等 1**：$\gcd(j, d) = 1$ 等价于分数不可约分——因为任何公因子 $g$ 必整除 $\gcd$；反之 $\gcd = g > 1$ 时分子分母同除 $g$ 可得等值更简分数，违反"最简"定义。
4. **字符串拼接顺序**：题目允许任意顺序，但按"分母升序、分子升序"输出最规整，也方便对拍时比对。
5. **欧拉函数视角的正确断言**：结果条数应等于 $\sum_{d=2}^{n}\varphi(d)$，且互不相同（$\frac{j}{d} = \frac{j'}{d'} \wedge$ 均最简 $\Rightarrow j = j', d = d'$）。

## 5. 正确性证明

**引理 1（最简分数的唯一表示）**：分数 $\frac{j}{d}$（$1 \le j < d$）是最简分数当且仅当 $\gcd(j, d) = 1$；且每个 $0$ 与 $1$ 之间的有理数有唯一的"最简分数"表示 $\frac{j}{d}$（$\gcd(j,d)=1$）。

**证明**：设 $g = \gcd(j, d) > 1$，则 $\frac{j/g}{d/g}$ 是与 $\frac{j}{d}$ 等值的分数且分母更小，故 $\frac{j}{d}$ 非最简。反之设 $\gcd(j, d) = 1$ 而 $\frac{j}{d} = \frac{j'}{d'}$ 是某个分母 $d' \le d$ 的表示，则 $j d' = j' d$；由 $d \mid j d'$ 与 $\gcd(d, j) = 1$ 得 $d \mid d'$，故 $d \le d'$，结合 $d' \le d$ 得 $d = d'$，进而 $j = j'$。即最简表示的分母最小且唯一。∎

**定理**：算法返回的集合恰为所有满足条件的字符串表示。

**证明**：题意要求的集合 $S = \{ \text{“}j/d\text{”} : 2 \le d \le n,\ 1 \le j < d,\ \gcd(j, d) = 1 \}$。枚举覆盖且仅覆盖 $(d, j)$ 的全部取值：$d = 1$ 被排除（无分子）；$j \ge d$ 或 $j = 0$ 被分子上界排除（值为 $\ge 1$ 或 $0$，在闭区间外）；$j < d$ 且 $\gcd = 1$ 被收集。由引理 1，每个收集到的串是最简分数、每个 $0$ 与 $1$ 之间的最简分数分母不超过 $n$ 时都会以其唯一表示被收集一次，无重复无遗漏。∎

## 6. 复杂度分析

- **时间**：$O(n^2 \log n)$。$\sum_{d=2}^{n} (d-1) \approx n^2/2$ 次 gcd 调用，每次 gcd 为 $O(\log(\min(j,d)))$。$n = 100$ 时约 $5 \times 10^3$ 次，毫秒级。
- **空间**：$O(n^2)$ 个输出字符串（答案本身的大小 $\sum \varphi(d)$），辅助空间 $O(1)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<string> simplifiedFractions(int n) {
        vector<string> res;
        for (int d = 2; d <= n; ++d)          // 分母 d
            for (int j = 1; j < d; ++j)       // 分子 j
                if (gcd(j, d) == 1)           // 互质才是最简分数
                    res.push_back(to_string(j) + "/" + to_string(d));
        return res;
    }
};
```

### Python

```python
class Solution:
    def simplifiedFractions(self, n: int) -> list[str]:
        res = []
        for d in range(2, n + 1):               # 分母 d
            for j in range(1, d):               # 分子 j
                if gcd(j, d) == 1:              # 互质才是最简分数
                    res.append(f"{j}/{d}")
        return res
```

> 💡 两份代码均通过全部官方示例（4 组，含 $n = 1$ 空表）；并做了 $n = 1 \dots 100$ 的**全量附加校验**：结果条数恰等于 $\sum_{d=2}^{n} \varphi(d)$（独立用定义式欧拉函数计数）、每个分数分子分母互质、$0 < j < d \le n$、且无重复元素，全部通过。

## 8. 边界情况与易错点

1. **$n = 1$**：没有分母 $\ge 2$ 的分数，返回 `[]`——循环从 $d = 2$ 起天然处理，不要额外特判出错。
2. **不要包含 0/1 端点**：分子从 1 起、严格小于分母，$\frac{0}{d}$ 与 $\frac{d}{d} = 1$ 都非法。
3. **重复表示**：$\frac{1}{2}$ 与 $\frac{2}{4}$ 是同一个数，后者非最简会被 gcd 过滤；若不过滤会重复输出同一数值。
4. **输出格式**：`"分子/分母"` 中间是 ASCII 斜杠，拼接时别漏引号里的 `/`。
5. **`std::gcd` 需要 C++17**：`<numeric>` 头文件；老环境可用手写辗转相除 `while (b) { int t = a % b; a = b; b = t; } return a;`。
6. **顺序无关但建议有序**：题目判定器按集合比对；但本地对拍时先排序可避免顺序差异误报。
