# LeetCode 最长相邻不相等子序列 I 题解

## 1. 题目概述

- **标题 / 题号**：最长相邻不相等子序列 I（#2900，easy）
- **链接**：https://leetcode.cn/problems/longest-unequal-adjacent-groups-subsequence-i/
- **来源**：LeetCode 第 115 场双周赛 Q2
- **难度**：简单
- **标签**：贪心、数组、字符串、动态规划

**题意**：给定长度均为 $n$ 的字符串数组 `words` 与**二进制**数组 `groups`。从 `words` 中选出一个**子序列**，使得子序列中任意**相邻两个**元素在 `groups` 中对应位置的值**不同**（即不存在相邻的 $0,0$ 或 $1,1$），求**最长**的这样的子序列，返回该子序列本身（任意合法答案均可）。`words` 中元素互不相同。

**约束**：

- $1 \le n = \texttt{words.length} = \texttt{groups.length} \le 100$
- $1 \le \texttt{words}[i]\texttt{.length} \le 10$
- `groups[i]` 是 0 或 1
- `words` 中字符串互不相同，只含小写字母

## 2. 示例

**示例 1**

```text
输入：words = ["e","a","b"], groups = [0,0,1]
输出：["e","b"]
解释：子序列 [0,2] 满足 groups[0]=0 ≠ groups[2]=1；
也可选 [1,2] 得 ["a","b"]。最长长度为 2。
```

**示例 2**

```text
输入：words = ["a","b","c","d"], groups = [1,0,1,1]
输出：["a","b","c"]
解释：子序列 [0,1,2] 满足 1≠0 且 0≠1，长度 3；
[0,1,3]（["a","b","d"]）同样合法。
```

**示例 3（边界补充）**

```text
输入：words = ["c"], groups = [0]
输出：["c"]
解释：单个元素没有相邻对，天然合法；n=1 时最长就是 1。
```

## 3. 解题思路

### 3.1 暴力思路

枚举全部 $2^n$ 个下标子集、检查相邻 `groups` 值是否交替——指数级。也可以写 $O(n^2)$ 的 LIS 型 DP（见本题 Q3 版本），但这题 `groups` 只有 0/1 两个值，存在更直接的**线性贪心**。

### 3.2 核心观察：同色段内挑 1 个，相邻段值必不同

![贪心选法与上界](images/bw115_q2_greedy_pick.svg)

把序列按 `groups` 切成 $m$ 个**极长同值段**（如 $[0,0,1,1,0]$ → 段 $00|11|0$，$m=3$）：

- **上界**：子序列中相邻元素的 `groups` 值必须不同，而同一段内任意两个下标的值相同，**每个段最多贡献 1 个元素**，故长度 $\le m$；
- **可达**：每个段各取 1 个元素。由于 `groups` 只有 0/1 两值，**相邻极长段的值必然不同**（否则会合并成同一段），所以「每段取一个」得到的子序列自动满足相邻不同，长度恰为 $m$。

于是答案长度就是段数 $m$，构造只需一次扫描：**保留每个下标 $i$，当且仅当 $i=0$ 或 `groups[i] != groups[i-1]`**——这正是「每段第一个元素」。

### 3.3 算法流程

```text
1. ans ← 空列表
2. for i = 0 .. n−1:
       若 i = 0 或 groups[i] ≠ groups[i−1]：
           ans ← ans + [words[i]]      # 该下标是其所在段的首个元素
3. 返回 ans
```

等价说法：扫描时维护「上一个已选元素的组值」，只要当前组值与之不同就选入。

### 3.4 示例演算

**示例 2**（`groups = [1,0,1,1]`）：

| i | groups[i] | 与前一个不同？ | 动作 | ans |
|---|-----------|----------------|------|-----|
| 0 | 1 | （首元素） | 选 | [a] |
| 1 | 0 | 1 ≠ 0 ✓ | 选 | [a, b] |
| 2 | 1 | 0 ≠ 1 ✓ | 选 | [a, b, c] |
| 3 | 1 | 1 = 1 ✗ | 跳过 | [a, b, c] |

段划分为 $1|0|11$，共 3 段，答案长度 3 ✓。

## 4. 算法细节

1. **判定条件用相邻下标即可**：`groups[i] != groups[i-1]` 与「与上一个已选的不同」等价——若 `groups[i] == groups[i-1]`，则 $i-1$ 与 $i$ 同段，$i$ 不是段首；若不同，$i$ 必是段首。两种写法结果一致。
2. **首元素必选**：$i=0$ 无前驱，任何单元素子序列都合法，选上只增不减（$n \ge 1$）。
3. **返回的是 words 不是下标**：题目要字符串数组；下标只是构造手段。
4. **与 Q3 的区别**：本题只有「相邻组值不同」一个约束；Q3（#2901）额外要求等长 + 汉明距离 1，贪心失效必须 DP。两题对照能看清「约束越强，可用结构越少」。
5. **任意答案均可**：段内取哪个元素不影响长度；本题贪心固定取段首，判定器（若用于对拍）只需验证「合法性 + 长度 = 段数」。

## 5. 正确性证明

**引理 1（上界）**：任何合法子序列的长度不超过极长同值段数 $m$。

**证明**：设合法子序列选中的下标为 $i_1 < i_2 < \dots < i_k$。若 $i_t$ 与 $i_{t+1}$ 落在同一个同值段，则 `groups[i_t] = groups[i_{t+1}]`，与合法性矛盾。故相邻两个选中下标必属不同段，而段在序列中是有序排列的，$k$ 个下标至少分布在 $k$ 个不同段中，即 $k \le m$。∎

**引理 2（可达）**：每个段各取一个元素（如段首）构成的子序列合法，长度为 $m$。

**证明**：极长同值段从左到右依次为 $B_1, B_2, \dots, B_m$。若存在相邻两段 $B_t, B_{t+1}$ 值相同，则它们中间无其他段且物理相邻（极长性），会合并为一个段，与「极长」矛盾；故相邻段值互异。取每段任意元素（下标严格递增），相邻两个选中元素的组值即相邻段的值，互不相同，子序列合法；共取 $m$ 个元素，长度为 $m$。∎

**定理**：上述贪心算法返回长度为 $m$ 的合法子序列，即最优解。

**证明**：算法恰在每个段的首个下标处选入（$i=0$ 或与前一元素组值不同 ⇔ 该下标是其所在段中最小下标），每段恰选 1 个，共 $m$ 个，且这些下标按段序递增。由引理 2 该子序列合法且长度为 $m$；由引理 1 没有更长者，故最优。∎

## 6. 复杂度分析

- **时间**：$O(n)$。单次扫描，每个下标 $O(1)$ 判定与追加（字符串本身不复制则更优，`push_back` 引用/拷贝长度 $\le 10$ 的串总量 $O(\sum |\texttt{words}[i]|)$）。
- **空间**：$O(n)$ 存答案（不计输出则 $O(1)$ 额外）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<string> getLongestSubsequence(vector<string>& words, vector<int>& groups) {
        vector<string> ans;
        int n = (int)words.size();
        for (int i = 0; i < n; ++i) {
            if (i == 0 || groups[i] != groups[i - 1])   // 段首（含首元素）
                ans.push_back(words[i]);
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def getLongestSubsequence(self, words: list[str], groups: list[int]) -> list[str]:
        ans = []
        for i, (w, g) in enumerate(zip(words, groups)):
            if i == 0 or g != groups[i - 1]:            # 段首（含首元素）
                ans.append(w)
        return ans
```

> 💡 两份代码均通过官方示例与 2000 组随机对拍（与 $2^n$ 枚举子序列的暴力比「合法性 + 最优长度」），`mismatch = 0`。

## 8. 边界情况与易错点

1. **$n = 1$**：无相邻对，直接返回 `[words[0]]`；条件 `i == 0` 保证首元素入选。
2. **全部同值**（`groups` 全 0 或全 1）：只有 1 个段，答案长度 1，返回任意一个元素——不要误以为要返回空。
3. **比较对象是「前一个元素」不是「上一个已选的」**：本题两种写法等价（见 §4.1），但若照抄 Q3 的 DP 框架容易把比较写错对象；线性扫描版用 `groups[i] != groups[i-1]` 最稳。
4. **groups 是 0/1**：本题贪心依赖「二值 ⇒ 相邻段必不同」。若值域扩大（如 Q3 的 $1 \le \texttt{groups}[i] \le n$），相邻段值可能相同，贪心**失效**，必须回到 DP——这是 I/II 两题的本质分界。
5. **返回任意合法答案**：对拍或评测时不能只比字符串内容，应校验「是子序列、相邻组值不同、长度等于段数」。

**延伸思考**：本题是「**交替约束下的最长子序列**」家族的最简成员。当约束是二值交替时，答案长度 = 极长段数，线性可解；当约束是「差值符号交替」（摆动序列）时仍可线性贪心；当约束涉及两两元素间的任意关系（如 Q3 的汉明距离）时，一般只能 $O(n^2)$ DP 或借助邻接结构优化。识别「约束局部且值域小」是找到线性解的钥匙。
