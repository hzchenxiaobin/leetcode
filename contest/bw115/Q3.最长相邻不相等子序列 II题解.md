# LeetCode 最长相邻不相等子序列 II 题解

## 1. 题目概述

- **标题 / 题号**：最长相邻不相等子序列 II（#2901，medium）
- **链接**：https://leetcode.cn/problems/longest-unequal-adjacent-groups-subsequence-ii/
- **来源**：LeetCode 第 115 场双周赛 Q3
- **难度**：中等
- **标签**：数组、字符串、动态规划

**题意**：给定长度均为 $n$ 的字符串数组 `words` 与整数数组 `groups`。两个**等长**字符串的**汉明距离**定义为对应位置字符不同的数目。要从下标 $[0, n-1]$ 中选出最长子序列 $[i_0, i_1, \dots, i_{k-1}]$，满足对每个相邻对：

1. `groups[i_j] != groups[i_{j+1}]`（组值不同）；
2. `words[i_j]` 与 `words[i_{j+1}]` **长度相等**且**汉明距离恰为 1**。

返回该子序列对应的字符串数组（任意合法答案均可）。

**约束**：

- $1 \le n = \texttt{words.length} = \texttt{groups.length} \le 1000$
- $1 \le \texttt{words}[i]\texttt{.length} \le 10$
- $1 \le \texttt{groups}[i] \le n$
- `words` 中字符串互不相同，只含小写字母

## 2. 示例

**示例 1**

```text
输入：words = ["bab","dab","cab"], groups = [1,2,2]
输出：["bab","cab"]
解释：子序列 [0,2]：组值 1≠2，等长且 bab↔cab 汉明距离 1。
[0,1]（bab,dab）同样合法。最长长度 2。
```

**示例 2**

```text
输入：words = ["a","b","c","d"], groups = [1,2,3,4]
输出：["a","b","c","d"]
解释：相邻都等长（都是 1）、汉明距离 1、组值互异，四连合法。
```

**示例 3（边界补充）**

```text
输入：words = ["abcd","a"], groups = [1,2]
输出：["abcd"]（或 ["a"]）
解释：两词长度不同，任何含两元素的子序列都不合法；最长为 1。
```

## 3. 解题思路

### 3.1 暴力思路

枚举 $2^n$ 个下标子集并逐对检查——$n = 1000$ 时天文数字。Q1（#2900）里「组值二值交替」的线性贪心在这里**失效**：即便相邻段组值不同，段内/跨段的词还必须等长且汉明距离 1，这个约束是**两两之间**的，无法只看段结构。需要 LIS 型 DP。

### 3.2 核心观察：LIS 型 DP，「以 i 结尾」记录最优

![DP 模型与转移条件](images/bw115_q3_dp_model.svg)

**关键**：最优子序列的「后缀」仍是最优子结构的载体。定义

$$dp[i] = \text{以 } i \text{ 结尾的合法子序列的最大长度}$$

则 $dp[i] = 1 + \max\{dp[j] : j < i,\ \texttt{ok}(i, j)\}$（无可行 $j$ 时为 1），其中可行条件为：

$$\texttt{ok}(i,j) \iff \texttt{groups}[i] \ne \texttt{groups}[j] \ \wedge\ |\texttt{words}[i]| = |\texttt{words}[j]| \ \wedge\ \mathrm{hamming}(\texttt{words}[i], \texttt{words}[j]) = 1$$

汉明距离 1 的检查至多扫 10 个字符，$O(L)$；总转移 $O(n^2 L) = 1000^2 \times 10 = 10^7$，轻松通过。

**为什么不能像 Q1 一样贪心**：值域 $1 \le \texttt{groups}[i] \le n$ 不再是二值，相邻段组值可能相同；且等长 + 汉明约束与「段」无关。DP 把所有两两关系显式编码进转移，才不漏最优。

### 3.3 算法流程

```text
1. dp[i] ← 1, pre[i] ← −1（i = 0..n−1）
2. for i = 0..n−1:
       for j = 0..i−1:
           若 ok(i, j) 且 dp[j] + 1 > dp[i]:
               dp[i] ← dp[j] + 1；pre[i] ← j
3. best ← argmax dp[i]
4. 从 best 沿 pre 回溯收集 words，反转即为答案
```

`pre[i]` 记录取得最优时的前驱下标，用于重建方案。

### 3.4 示例演算

![示例 1 走查](images/bw115_q3_walkthrough.svg)

**示例 1**（`words = [bab, dab, cab]`，`groups = [1,2,2]`）：

| i | 词（组） | 候选 j | ok？ | dp[i] | pre[i] |
|---|---------|--------|------|-------|--------|
| 0 | bab (1) | — | — | 1 | −1 |
| 1 | dab (2) | 0 | 组 1≠2 ✓ 等长 ✓ hamming(bab,dab)=1 ✓ | 2 | 0 |
| 2 | cab (2) | 1 | 组 2=2 ✗ | 2（由 j=0） | 0 |
|   |         | 0 | 组 1≠2 ✓ 等长 ✓ hamming(bab,cab)=1 ✓ | | |

$dp = [1,2,2]$，从 $i=2$ 回溯得 `bab → cab`；从 $i=1$ 回溯得 `bab → dab`，两者长度都是 2，返回任一。

## 4. 算法细节

1. **汉明距离「恰好 1」**：常见笔误是写成 $\le 1$——两词相同时距离为 0，但本题 `words` 互不相同，距离 0 不会出现；不过若写 $\le 1$ 且输入有重复词就会放错，严谨起见判 `== 1`。检查时**先长度后逐位**，遇到第二个不同位即可提前返回 false。
2. **先判组值（最便宜）**：`groups[i] == groups[j]` 是 $O(1)$ 剪枝，放在最前，能省掉大量逐字符比较。
3. **等长是必要条件**：长度不同的词汉明距离无定义（按不可接处理），务必在逐位比较前拦截，否则会越界。
4. **重建路径用 pre 数组**：`pre[i] = -1` 表示链到此为止；从 $\arg\max dp$ 回溯到根再反转。不要从前往前「贪心拼」，容易拼出错链。
5. **多个最优时任取**：取第一个最大值即可；LeetCode 判题用 special judge。
6. **实现上的小优化（可选）**：按 (长度, 组值) 分桶或按「词长」分层再转移可降低常数，但 $n \le 1000$ 下朴素 $O(n^2 L)$ 已足够，不值得引入复杂度。

## 5. 正确性证明

**引理 1（子结构）**：设 $S = [i_0, \dots, i_{k-1}]$ 是合法子序列，则其任意后缀 $[i_t, \dots, i_{k-1}]$ 也是合法子序列。

**证明**：合法性只约束相邻对，后缀中的相邻对都在 $S$ 中相邻，条件照旧满足。∎

**引理 2（转移完备）**：以 $i$ 结尾的最优子序列长度 $dp[i]$ 满足：若其长度 $k \ge 2$，则去掉末尾 $i$ 后是「以某个 $j < i$ 结尾、$\texttt{ok}(i,j)$ 成立的合法子序列」，长度 $k-1 \le dp[j]$；反之任何可行的 $j$ 都能拼出长度 $dp[j] + 1$ 的合法子序列。

**证明**：前者由引理 1，前缀 $[i_0, \dots, i_{k-2}]$ 合法且末元素 $j = i_{k-2}$ 满足 $\texttt{ok}(i, j)$（$S$ 的最后一对相邻即它），其长度为 $k-1$，不超过 $dp[j]$。后者：取以 $j$ 结尾长度 $dp[j]$ 的合法子序列 $T$，其元素下标都 $< i$（因 $j < i$ 且下标递增），把 $i$ 接在 $T$ 之后：新的唯一相邻对是 $(j, i)$，由 $\texttt{ok}(i,j)$ 合法，故得到长度 $dp[j]+1$ 的合法子序列。∎

**定理**：算法终止时 $\max_i dp[i]$ 即最长合法子序列长度，且沿 `pre` 回溯得到的序列合法且达到该长度。

**证明**：对 $i$ 归纳可证 $dp[i]$ 恰为以 $i$ 结尾的最优长度：$i = 0$ 时显然为 1；$i > 0$ 时由引理 2，$dp[i] = \max(1, \max\{\,dp[j]+1 : j<i, \texttt{ok}(i,j)\,\})$，正是算法的计算式。全局最优必以某个 $i$ 结尾，故 $\max dp$ 为答案长度。回溯链上每对相邻 $(pre[i], i)$ 都经过 $\texttt{ok}$ 检查，合法；链长恰为 $dp[best]$。∎

## 6. 复杂度分析

- **时间**：$O(n^2 L)$，其中 $L = \max |\texttt{words}[i]| \le 10$。最坏 $1000^2 \times 10 = 10^7$ 次字符比较，远低于时限。组值剪枝会显著降低实际常数。
- **空间**：$O(n)$。`dp`、`pre` 各 $n$ 个整数；答案数组不超过 $n$ 个字符串引用。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<string> getWordsInLongestSubsequence(vector<string>& words, vector<int>& groups) {
        int n = (int)words.size();
        vector<int> dp(n, 1), pre(n, -1);
        auto ok = [&](int i, int j) {              // words[i] 能否接在 words[j] 之后
            if (groups[i] == groups[j]) return false;
            const string& a = words[i];
            const string& b = words[j];
            if (a.size() != b.size()) return false;
            int diff = 0;
            for (size_t t = 0; t < a.size(); ++t)
                if (a[t] != b[t] && ++diff > 1) return false;
            return diff == 1;                      // 汉明距离恰为 1
        };
        for (int i = 0; i < n; ++i)
            for (int j = 0; j < i; ++j)
                if (ok(i, j) && dp[j] + 1 > dp[i]) {
                    dp[i] = dp[j] + 1;
                    pre[i] = j;
                }
        int best = 0;
        for (int i = 1; i < n; ++i)
            if (dp[i] > dp[best]) best = i;
        vector<string> ans;
        for (int i = best; i != -1; i = pre[i]) ans.push_back(words[i]);
        reverse(ans.begin(), ans.end());
        return ans;
    }
};
```

### Python

```python
class Solution:
    def getWordsInLongestSubsequence(self, words: list[str], groups: list[int]) -> list[str]:
        n = len(words)

        def ok(i: int, j: int) -> bool:            # words[i] 能否接在 words[j] 之后
            if groups[i] == groups[j]:
                return False
            a, b = words[i], words[j]
            if len(a) != len(b):
                return False
            return sum(x != y for x, y in zip(a, b)) == 1   # 汉明距离恰为 1

        dp = [1] * n
        pre = [-1] * n
        for i in range(n):
            for j in range(i):
                if ok(i, j) and dp[j] + 1 > dp[i]:
                    dp[i] = dp[j] + 1
                    pre[i] = j
        best = max(range(n), key=lambda i: dp[i])
        ans = []
        while best != -1:
            ans.append(words[best])
            best = pre[best]
        return ans[::-1]
```

> 💡 两份代码均通过官方示例，并与「$2^n$ 枚举子序列」的暴力对拍 1500 组随机数据（校验合法性 + 最优长度一致），`mismatch = 0`。

## 8. 边界情况与易错点

1. **长度不同的词永不能相邻**：`ok` 里先判长度再逐位，避免越界/误判。示例 3（`["abcd","a"]`）即考察此点。
2. **汉明距离是「恰 1」不是「至多 1」**：两词相同距离为 0 不允许（本题数据保证词互异，但逻辑上仍应写 `== 1` 防御）。
3. **组值相同必不合法**：即使两词等长、距离 1，组值相同也不能相邻（示例 1 中 dab 与 cab 同组 2，不能连）。
4. **n = 1**：`dp[0] = 1`，返回 `[words[0]]`；循环体不执行，注意 `best` 初始化为 0 而不是未定义。
5. **回溯方向**：`pre` 是「从后往前」，收集到的序列要**反转**再返回。
6. **性能错觉**：$O(n^2 L)$ 中最坏情形是大量等长词——例如 1000 个长度 10 的词、组值交替，`ok` 每次都要扫完 10 位，共 $10^7$ 次，稳。但若把汉明检查写成逐位构造新串再比较，常数会翻几倍，没必要。
