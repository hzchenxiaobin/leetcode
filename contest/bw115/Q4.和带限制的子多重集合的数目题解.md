# LeetCode 和带限制的子多重集合的数目 题解

## 1. 题目概述

- **标题 / 题号**：和带限制的子多重集合的数目（#2902，hard）
- **链接**：https://leetcode.cn/problems/count-of-sub-multisets-with-bounded-sum/
- **来源**：LeetCode 第 115 场双周赛 Q4
- **难度**：困难
- **标签**：数组、哈希表、动态规划、背包问题、滑动窗口、多重背包

**题意**：给定非负整数数组 `nums` 与整数 $l, r$。**子多重集合**指从数组中选出一些元素构成的无序集合，每个值 $x$ 可出现 $0 \sim \texttt{occ}[x]$ 次（$\texttt{occ}[x]$ 为 $x$ 在数组中的出现次数）。统计**元素和落在闭区间 $[l, r]$ 内**的子多重集合数目，对 $10^9 + 7$ 取模返回。空集合的和为 0；两个子多重集合当且仅当排序后完全相同才视为同一个。

**约束**：

- $1 \le \texttt{nums.length} \le 2 \times 10^4$
- $0 \le \texttt{nums}[i] \le 2 \times 10^4$
- `nums` 的元素和不超过 $2 \times 10^4$
- $0 \le l \le r \le 2 \times 10^4$

## 2. 示例

**示例 1**

```text
输入：nums = [1,2,2,3], l = 6, r = 6
输出：1
解释：唯一和为 6 的子多重集合是 {1, 2, 3}。
```

**示例 2**

```text
输入：nums = [2,1,4,2,7], l = 1, r = 5
输出：7
解释：{1}，{2}，{4}，{2,2}，{1,2}，{1,4}，{1,2,2}。
```

**示例 3**

```text
输入：nums = [1,2,1,3,5,2], l = 3, r = 5
输出：9
解释：{3}，{5}，{1,2}，{1,3}，{2,2}，{2,3}，{1,1,2}，{1,1,3}，{1,2,2}。
```

## 3. 解题思路

### 3.1 暴力思路

枚举 $2^n$ 个子集再去重计数，$n = 2\times 10^4$ 直接爆炸。注意到「无序 + 按值计数」的结构，正确的朴素版是**按值分组的多重背包**：值 $v$ 出现 $c$ 次，就是「体积 $v$、件数 $c$」的物品组。但若对每组**逐件**转移（$c$ 件做 $c$ 次完全背包式滚动），总代价 $\sum_v c_v \times r = n \times r$，最坏 $2\times 10^4 \times 2\times 10^4 = 4\times 10^8$——会超时，需要优化。

### 3.2 核心观察一：按值分组 + 上界压缩

![按值分组的多重背包](images/bw115_q4_group_knapsack.svg)

两个关键压缩：

1. **不同值最多 $\sqrt{2S}$ 个**（$S = \sum \texttt{nums} \le 2\times 10^4$ 为总和上界）：若互不相同的值有 $k$ 个，则 $1 + 2 + \dots + k \le S$，故 $k \le O(\sqrt S) \approx 200$。组数很少！
2. **值 $> r$ 的组直接丢弃**：取任何件数都使和超过 $r$，对 $[l, r]$ 内的计数无贡献（但注意 $v = 0$ 除外，见核心观察二）。于是背包容量只需 $r$，每组转移规模与 $r$ 同阶。

### 3.3 核心观察二：值 0 是纯乘数

$v = 0$ 的元素取 $0, 1, \dots, c_0$ 件都不改变和。于是每个「非零部分和为 $s$」的方案配上任意数量的 0 都得到不同的子多重集合，总方案数恰好乘上 $(c_0 + 1)$。**因此 $v = 0$ 不进背包，答案最后统一乘 $(\texttt{cnt}[0] + 1)$**。这也解释了为什么容量按 $r$ 截断时唯独 0 要拎出来：它对和没有贡献，却线性地复制方案数。

### 3.4 核心观察三：模 $v$ 余数类上的滑窗前缀和

设处理某组（值 $v$、件数 $c$）之前的 DP 数组为 $\texttt{old}$，之后为 $\texttt{new}$。按 **$s \bmod v$ 的余数类**分开看：类 $m$ 中的下标为 $m, m+v, m+2v, \dots$，记 $\texttt{old}_t = \texttt{old}[m + tv]$。取 $t' \le c$ 件等价于从「窗口宽度 $c+1$」的历史滑窗里求和：

$$\texttt{new}_t = \sum_{t' = \max(0,\, t-c)}^{t} \texttt{old}_{t'}$$

用**前缀和 + 窗口右端进、左端出**即可 $O(1)$ 均摊算出每个 $\texttt{new}_t$，整组转移 $O(r)$，与件数 $c$ 无关！这就是多重背包的「二进制拆分 / 单调队列 / 前缀和滑窗」三兄弟中的前缀和版，计数问题（转移是求和而非 max）用它最自然。

**总复杂度**：组数 $\times r \approx 200 \times 2\times 10^4 = 4\times 10^6$，加上初始 $O(n)$ 计数，稳过。

### 3.5 算法流程

```text
1. 统计每个值的出现次数 cnt（哈希表）
2. zero ← cnt[0] + 1（0 是乘数，不进背包）
3. dp[0..r]，dp[0] = 1，其余 0
4. 对每个 v ≥ 1 且 v ≤ r 的组，件数 c = cnt[v]：
       对每个余数 m ∈ [0, v)：
           old ← dp[m], dp[m+v], dp[m+2v], …
           滑窗（宽 c+1）前缀和覆写回该余数类
5. 答案 = (Σ_{s=l}^{r} dp[s]) × zero  (mod 1e9+7)
```

### 3.6 示例演算

![示例 1 的 dp 演化](images/bw115_q4_walkthrough.svg)

**示例 1**（`nums = [1,2,2,3]`，$l = r = 6$）：

| 阶段 | dp[0..6] |
|------|----------|
| 初始 | [1, 0, 0, 0, 0, 0, 0] |
| $v{=}1, c{=}1$ | [1, 1, 0, 0, 0, 0, 0] |
| $v{=}2, c{=}2$ | [1, 1, 1, 1, 1, 1, 0] |
| $v{=}3, c{=}1$ | [1, 1, 1, 2, 2, 2, 1] |

$dp[6] = 1$（即 $\{1,2,3\}$），无 0，答案 $1 \times 1 = 1$ ✓。注意 $v{=}2$ 那步：$s=6$ 处为 0，因为 $2\times 2 = 4 < 6$ 且窗口里 $s-4=2$ 位置的 old 值为 0（1 的方案凑不出 2）——滑窗天然处理了「件数用尽」。

## 4. 算法细节

1. **dp 只开到 $r$**：$s > r$ 的方案数永远不被询问，处理组时滑窗也只需扫到 $\le r$，这正是复杂度里的 $r$ 而非 $S$。
2. **余数类独立滑窗的实现**：`old = dp[m::v]`（Python 切片）或 C++ 循环 `for (s = m; s <= r; s += v)` 收集；随后对 $t = 0, 1, \dots$ 维护窗口和 $w$：进入 old$_t$，若 $t - c - 1 \ge 0$ 减去 old$_{t-c-1}$，写回 $\texttt{dp}[m + tv] = w$。**先加后减再写**的顺序保证窗口恰宽 $c+1$。
3. **取模细节**：窗口和可能出现负（减法后），C++ 需 `+ MOD` 再取模；Python 负数取模天然非负但仍应控制数值大小避免大整数运算变慢。
4. **0 值乘数放最后**：`zero = cnt[0] + 1`，最后 `ans = ans * zero % MOD`。若 0 进背包，转移会退化（$v=0$ 的余数类只有一个点，窗口宽度 $c_0+1$ 反而正确但浪费；更重要的是滑窗写法假设 $v \ge 1$，$v = 0$ 会除零/死循环）。
5. **答案求和范围**：$\sum_{s=l}^{r} dp[s]$，$l = 0$ 时包含空集方案（$dp[0] = 1$），符合题意。
6. **为什么不用二进制拆分**：拆分后组数 $\sum_v \log c_v$ 可能到 $200 \times 15 = 3000$ 组，每组 $O(r)$ 得 $6\times 10^7$，常数大且代码更长；前缀和滑窗一组 $O(r)$ 直接到位，是计数型多重背包的最优写法。

## 5. 正确性证明

**引理 1（分组等价）**：子多重集合与「为每个值 $v$ 指定个数 $t_v \in [0, \texttt{cnt}[v]]$」一一对应。

**证明**：子多重集合按定义由每个值的出现次数唯一决定；反之任何满足 $0 \le t_v \le \texttt{cnt}[v]$ 的选取都合法。两组选取不同 ⇔ 存在 $v$ 使 $t_v$ 不同 ⇔ 排序后序列不同。∎

**引理 2（单组转移）**：设处理值 $v$（件数 $c$）之前，$dp[s]$ 是「仅用已处理过的值凑出和 $s$」的方案数。处理后正确的 $dp'[s]$ 应为 $\sum_{j=0}^{\min(c,\, \lfloor s/v \rfloor)} dp[s - jv]$，而滑窗计算的结果与之相等。

**证明**：按引理 1，加入值 $v$ 后方案由 $j$（取多少件 $v$）分类，互斥且完备，故求和式成立。按余数 $m = s \bmod v$ 分解，令 $t = \lfloor s/v \rfloor$，则 $dp[s - jv] = \texttt{old}_{t - j}$，求和范围 $j \in [0, \min(c, t)]$ 即 $t - j \in [\max(0, t-c), t]$，正是宽度 $c+1$ 的窗口 $\texttt{old}_{\max(0, t-c)} + \dots + \texttt{old}_t$。滑窗逐步维护的正是该窗口和（归纳于 $t$：右端进入 old$_t$，左端在 $t - c - 1 < \max(0, t+1-c)$ 时离开）。∎

**引理 3（0 值乘数）**：设非零值构成的方案数为 $A(s)$（按和分类），则总方案数为 $\sum_{s=l}^{r} A(s) \times (\texttt{cnt}[0] + 1)$。

**证明**：任何子多重集合唯一分解为「非零部分 + 若干个 0」。非零部分和为 $s \in [l, r]$ 的方案数是 $A(s)$；对每个非零部分，0 可取 $0 \dots \texttt{cnt}[0]$ 件共 $\texttt{cnt}[0]+1$ 种，且不同 0 的个数给出不同子多重集合（排序后长度/内容不同）。乘法原理相乘并对 $s$ 求和。∎

**定理**：算法输出 $\sum_{s=l}^{r} dp[s] \times (\texttt{cnt}[0]+1) \bmod (10^9+7)$，恰为所求计数。

**证明**：对处理过的组归纳：初始 $dp = [1, 0, \dots, 0]$ 对应「不取任何值、和 0」的恰 1 种方案；每次处理一组由引理 2 保持「dp[s] = 用已处理值组和为 s 的方案数」；值 $> r$ 的组取任何正件数都使和超 $r$，其方案数对 $s \le r$ 的贡献为恒等（只取 0 件），跳过等价；处理完全部非零组后 $dp[s] = A(s)$（$s \le r$），再由引理 3 得最终计数。所有运算在模 $10^9+7$ 下封闭。∎

## 6. 复杂度分析

- **时间**：$O(n + d \cdot r)$，$n$ 为数组长度（计数），$d \le O(\sqrt S)$ 为互异非零值个数（$\le 200$），$r \le 2\times 10^4$。总计约 $4\times 10^6$ 次模加法，实测 C++ 36 ms、Python 约 1 s（Python 组循环用切片摊平较快）。
- **空间**：$O(r)$。DP 数组一个，滑窗临时数组每组复用（$O(r/v)$）。

## 7. 参考代码

### C++

```cpp
class Solution {
    static constexpr long long MOD = 1'000'000'007LL;
public:
    int countSubMultisets(vector<int>& nums, int l, int r) {
        unordered_map<int, int> cnt;
        for (int x : nums) ++cnt[x];
        long long zero = cnt.count(0) ? cnt[0] + 1 : 1;  // 值 0 是纯乘数
        vector<long long> dp(r + 1, 0);
        dp[0] = 1;
        for (auto& [v, c] : cnt) {
            if (v == 0 || v > r) continue;               // 0 单独处理；v>r 无贡献
            for (int m = 0; m < v; ++m) {                // 模 v 余数类滑窗
                vector<long long> old;
                for (int s = m; s <= r; s += v) old.push_back(dp[s]);
                long long w = 0;
                for (size_t t = 0; t < old.size(); ++t) {
                    w = (w + old[t]) % MOD;
                    if ((int)t - c - 1 >= 0)
                        w = (w - old[t - c - 1] + MOD) % MOD;
                    dp[m + (int)t * v] = w;              // w = old[max(0,t-c)..t] 之和
                }
            }
        }
        long long ans = 0;
        for (int s = l; s <= r; ++s) ans = (ans + dp[s]) % MOD;
        return (int)(ans * zero % MOD);
    }
};
```

### Python

```python
class Solution:
    def countSubMultisets(self, nums: list[int], l: int, r: int) -> int:
        MOD = 10 ** 9 + 7
        cnt = {}
        for x in nums:
            cnt[x] = cnt.get(x, 0) + 1
        zero = cnt.get(0, 0) + 1                  # 值 0 是纯乘数
        dp = [0] * (r + 1)
        dp[0] = 1
        for v, c in cnt.items():
            if v == 0 or v > r:
                continue
            for m in range(v):                    # 模 v 余数类滑窗
                old = dp[m::v]
                w = 0
                for t, val in enumerate(old):
                    w += val
                    if t - c - 1 >= 0:
                        w -= old[t - c - 1]
                    dp[m + t * v] = w % MOD       # 窗口宽 c+1 的和
        return sum(dp[l:r + 1]) * zero % MOD
```

> 💡 两份代码均通过官方示例（`1`、`7`、`9`）、全 0 数组、$l = 0$、$v > r$ 等边界，并与「$2^n$ 枚举子集去重计数」的暴力对拍 600 组随机数据，`mismatch = 0`；C++ 在 $n = 2\times 10^4$、含 199 个互异值 + 大量 0 的极端构造下 36 ms 完成。

## 8. 边界情况与易错点

1. **全 0 数组**：背包恒为 $dp = [1, 0, \dots]$，答案 $= (c_0+1)$（当 $l = 0$）——0 的个数本身乘进方案数，最易漏。
2. **$v > r$ 的组**：直接跳过。若不跳过而滑窗，`old` 只有 $s = v > r$ 不存在，循环体实际为空，但代码上易在 `dp[m::v]` 越界处出错，显式 `continue` 最清晰。
3. **$v = 0$ 千万别进滑窗**：余数类循环 `range(v)` 为空（Python 静默跳过）但 C++ `for (m = 0; m < 0)` 同样为空——看似无害，然而 `dp[m::0]` 在 Python 里是**整表切片**会出错，且逻辑上 0 不该按体积处理。务必显式排除。
4. **滑窗窗口宽度是 $c+1$ 不是 $c$**：可取件数 $\in [0, c]$ 共 $c+1$ 种，减法条件是 `t - c - 1 >= 0`（弹出下标 $t-c-1$）。差一错误会导致少算/多算一件。
5. **减法取模**：C++ 的 `w - old[...]` 可能为负，须 `+ MOD`；Python 天然非负但建议每步 `% MOD` 控制大整数。
6. **$l = 0$ 含空集**：$dp[0] = 1$ 会被计入，这是正确的（空集合和为 0）。
7. **答案相乘后再取模**：`sum(dp[l:r+1])` 可能已达 $10^9$ 量级，再乘 $c_0 + 1$（可到 $2\times10^4+1$）会溢出 32 位，C++ 全程 `long long`。
8. **别用「排序后双指针」等无关套路**：这是计数 DP，不是判断/构造题；看到「无序 + 每值限量」应条件反射到多重背包计数。
