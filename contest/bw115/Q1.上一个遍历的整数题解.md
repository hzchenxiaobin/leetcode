# LeetCode 上一个遍历的整数 题解

## 1. 题目概述

- **标题 / 题号**：上一个遍历的整数（#2899，easy）
- **链接**：https://leetcode.cn/problems/last-visited-integers/
- **来源**：LeetCode 第 115 场双周赛 Q1
- **难度**：简单
- **标签**：数组、模拟、栈

**题意**：给定数组 `nums`，元素要么是正整数，要么是 $-1$。维护一个 `seen` 列表和一个答案列表 `ans`，从头到尾扫描 `nums`：

- 遇到**正整数**：把它插入 `seen` 的**头部**；
- 遇到 $-1$：设 $k$ 为**到目前为止连续出现的 $-1$ 个数**（含当前这个）。若 $k \le |\texttt{seen}|$，把 `seen` 的第 $k$ 个元素（从头部数起）加入 `ans`；否则把 $-1$ 加入 `ans`。

返回 `ans`。

**约束**：

- $1 \le \texttt{nums.length} \le 100$
- `nums[i] == -1` 或 $1 \le \texttt{nums}[i] \le 100$

## 2. 示例

**示例 1**

```text
输入：nums = [1,2,-1,-1,-1]
输出：[2,1,-1]
解释：seen 依次演化为 [1] → [2,1]（2 插头部）；
三个连续 -1 的 k 分别为 1、2、3，取 seen[0]=2、seen[1]=1，
第三次 k=3 超过 |seen|=2，补 -1。
```

**示例 2**

```text
输入：nums = [1,-1,2,-1,-1]
输出：[1,2,1]
解释：第 2 个 -1 之前出现了正整数 2，连续计数 k 被清零重数，
两段 -1 分别取 seen 顶部的 1 与 (2, 1)。
```

**示例 3（边界补充）**

```text
输入：nums = [-1,-1,5,-1]
输出：[-1,-1,5]
解释：开头 seen 为空，两个 -1 都因 k > |seen| 补 -1；
随后 5 入栈，最后一个 -1 的 k=1 取 seen[0]=5。
```

## 3. 解题思路

### 3.1 暴力思路

「照着题面写」就是暴力：每个 $-1$ 都从头重新数一遍前面连续的 $-1$ 个数、再重新模拟一遍 `seen` 的构建。这在 $n \le 100$ 时完全可行（$O(n^2)$），但完全没有必要——**连续 $-1$ 的个数 $k$ 可以用一个计数器增量维护**，`seen` 也可以只维护一次。

### 3.2 核心观察：seen 是「最近者在前」的栈，k 是连续计数器

![核心观察：seen 头插栈与 k 计数](images/bw115_q1_stack_model.svg)

把 `seen` 看成一个**头部即栈顶的栈**：

- 正整数到来 → **压栈顶**（最新访问的在最前），同时连续 $-1$ 计数 $k$ **清零**（被正整数打断）；
- $-1$ 到来 → $k \mathrel{+}= 1$，「取 `seen` 第 $k$ 个元素」就是**从栈顶往下数第 $k$ 个**，即下标 $k-1$；$k > |\texttt{seen}|$ 时栈被「问穿」，补 $-1$。

于是整个过程是**一次线性扫描**，每个元素 $O(1)$（或均摊 $O(1)$）处理。

### 3.3 算法流程

![算法流程图](images/bw115_q1_flow.svg)

```text
1. seen ← 空列表（头 = 顶），ans ← 空列表，k ← 0
2. 依次读 x = nums[i]：
       若 x > 0：x 插入 seen 头部；k ← 0
       否则（x = −1）：
           k ← k + 1
           若 k ≤ |seen|：ans ← ans + [seen[k−1]]
           否则：        ans ← ans + [−1]
3. 返回 ans
```

### 3.4 示例演算

![示例演算表](images/bw115_q1_walkthrough.svg)

**示例 1**（`nums = [1,2,-1,-1,-1]`）：

| 步 | x | seen（顶在前） | k | 取值 | ans |
|----|-----|------------|---|------|-----|
| 1 | 1 | [1] | 0 | — | [] |
| 2 | 2 | [2, 1] | 0 | — | [] |
| 3 | −1 | [2, 1] | 1 | seen[0] = 2 | [2] |
| 4 | −1 | [2, 1] | 2 | seen[1] = 1 | [2, 1] |
| 5 | −1 | [2, 1] | 3 | 越界 → −1 | [2, 1, −1] |

**示例 2**（`nums = [1,-1,2,-1,-1]`）：中间的正整数 2 把 $k$ 清零，两段 $-1$ 各自从 1 数起，得 `[1, 2, 1]`。

## 4. 算法细节

1. **`seen` 的「头部插入」实现**：C++ 可用 `vector::insert(begin(), x)`（$O(|\texttt{seen}|)$，总量 $\le 100$ 无所谓）；更优雅的做法是**尾插 + 反向下标**——把新元素 `push_back` 到尾部，取「第 k 个」时用 `seen[|seen| − k]`，全部操作 $O(1)$。Python 同理（`seen.insert(0, x)` 为 $O(n)$，但 $n \le 100$）。
2. **k 的清零时机**：只在遇到**正整数**时清零。$-1$ 之间夹着的正整数是唯一的打断条件；扫描开始时 $k=0$。
3. **越界判定**：$k \le |\texttt{seen}|$ 取 `seen[k−1]`，严格大于才补 $-1$。注意 $k$ 与 `seen` 长度都在变，判定要用**当前时刻**的长度。
4. **ans 与 seen 分离**：`ans` 只在遇到 $-1$ 时增长，长度 = $-1$ 的总个数；`seen` 只在正整数时增长，长度 = 正整数总个数。两者不需要相互同步。
5. **不需要真的删元素**：题面没有弹出操作，`seen` 单调增长，越界情形下也不回退——只是「问穿」补 $-1$。

## 5. 正确性证明

**引理 1（k 的语义）**：扫描到下标 $i$ 且 `nums[i] = -1` 时，计数器 $k$ 的值恰等于「以 $i$ 结尾的极长 $-1$ 段的长度」。

**证明**：对 $i$ 归纳。若 `nums[i−1] ≠ -1`（或 $i = 0$），则该段长度为 1；由算法，上一次处理正整数时 $k$ 已被清零，本步 $k \mathrel{+}= 1$ 后为 1，成立。若 `nums[i−1] = -1`，极长段长度比「以 $i-1$ 结尾的段长度」多 1；由归纳假设处理 $i-1$ 后 $k$ 等于该段长，且中间无正整数清零，本步 $k \mathrel{+}= 1$ 后恰好多 1。∎

**引理 2（seen 的内容）**：处理完下标 $i$ 后，`seen` 从头到尾依次是「$[0, i]$ 内出现的正整数，按出现时间从晚到早」。

**证明**：归纳。初始为空。处理正整数 $x$ 时 $x$ 被插入头部且其余相对顺序不变，头部恰是最新出现的；处理 $-1$ 不改变 `seen`。∎

**定理**：上述算法输出的 `ans` 与题面定义一致。

**证明**：只需考察每个 $-1$ 位置 $i$。由引理 1，算法中 $k$ 即题面定义的连续 $-1$ 个数；由引理 2，`seen` 的第 $k$ 个元素（从头数起）即「最近第 $k$ 个被访问的正整数」，正是题面要求的取值；$k > |\texttt{seen}|$ 时该元素不存在，题面规定补 $-1$，算法同样输出 $-1$。逐位置一致，故整体一致。∎

## 6. 复杂度分析

- **时间**：$O(n)$（若用头插实现则单次插入 $O(n)$、总计 $O(n^2)$，在 $n \le 100$ 下同样轻松通过；尾插 + 反向下标可做到严格 $O(n)$）。每个元素至多触发一次入栈与一次取值。
- **空间**：$O(n)$。`seen` 最多存全部正整数，`ans` 最多存全部 $-1$，合计不超过 $n$ 个元素。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> lastVisitedIntegers(vector<int>& nums) {
        vector<int> seen, ans;
        int k = 0;                            // 当前连续 -1 的个数
        for (int x : nums) {
            if (x > 0) {
                seen.insert(seen.begin(), x);  // 插入头部（最近访问的在前）
                k = 0;                         // 正整数打断连续 -1
            } else {
                ++k;
                ans.push_back(k <= (int)seen.size() ? seen[k - 1] : -1);
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def lastVisitedIntegers(self, nums: list[int]) -> list[int]:
        seen, ans = [], []
        k = 0                                  # 当前连续 -1 的个数
        for x in nums:
            if x > 0:
                seen.insert(0, x)              # 头插 = 最近访问的在前
                k = 0                          # 正整数打断连续段
            else:
                k += 1
                ans.append(seen[k - 1] if k <= len(seen) else -1)
        return ans
```

> 💡 两份代码均通过官方示例（`[2,1,-1]`、`[1,2,1]`）、全 $-1$、`[-1,...]` 开头等边界用例。

## 8. 边界情况与易错点

1. **开头就是 $-1$**：`seen` 为空，$k=1 > 0 = |\texttt{seen}|$，必须补 $-1$ 而不是越界访问。
2. **k 忘记清零**：最常见的错误是把 `k = 0` 漏掉或写在错误分支里。示例 2 专门考察这一点：`[1,-1,2,-1,-1]` 若不清零会得到 `[1, 1, 2]` 而非 `[1, 2, 1]`。
3. **「第 k 个」从头部数**：题面说 seen 头部插入、取第 $k$ 个，即下标 $k-1$（头部为下标 0）。若用尾插实现要换成 `seen[|seen| − k]`，两套下标别混用。
4. **越界判定是严格大于**：$k = |\texttt{seen}|$ 时仍可取到最后一个元素（下标 $k-1$），不要写成 $\ge$。
5. **$-1$ 不清零 k**：清零只由正整数触发；连续 $-1$ 中间没有正整数，$k$ 持续累加。
6. **数据类型**：值域 $\le 100$，`int` 足够，无溢出风险。
