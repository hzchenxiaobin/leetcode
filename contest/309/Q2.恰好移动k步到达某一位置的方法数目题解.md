# LeetCode 恰好移动 k 步到达某一位置的方法数目 题解

## 1. 题目概述

- **标题 / 题号**：恰好移动 k 步到达某一位置的方法数目（#2400，medium）
- **链接**：https://leetcode.cn/problems/number-of-ways-to-reach-a-position-after-exactly-k-steps/
- **来源**：LeetCode 第 309 场周赛 Q2
- **难度**：中等
- **标签**：数学、动态规划、组合数学

**题意**：站在**无限**数轴上的 `startPos` 处，每步可以向左或向右移动一个位置。求**恰好**移动 `k` 步后到达 `endPos` 的不同方法数，答案对 $10^9+7$ 取余。移动顺序不同即算不同方法（数轴含负整数）。

**约束**：

- $1 \le \text{startPos}, \text{endPos}, k \le 1000$
- 答案对 $10^9+7$ 取模

> 💡 **切入信号**：每步只有 $\pm 1$ 两个选择，**与路径形状无关**——一条路径唯一由「哪几步朝目标、哪几步背离」决定。这是「路径计数 ⟹ 组合计数」的标志性转化；同时 $k \le 1000$ 也放行了 $O(k^2)$ 的区间 DP 保底写法，属于周赛 Q2 典型的「双解法都该会」题。

## 2. 示例

**示例 1**

```text
输入：startPos = 1, endPos = 2, k = 3
输出：3
解释：3 种从 1 到 2 且恰好移动 3 步的方法：
  - 1 -> 2 -> 3 -> 2   (→, →, ←)
  - 1 -> 2 -> 1 -> 2   (→, ←, →)
  - 1 -> 0 -> 1 -> 2   (←, →, →)
```

**示例 2**

```text
输入：startPos = 2, endPos = 5, k = 10
输出：0
解释：d = 3，k = 10，k − d = 7 为奇数，奇偶不匹配，不存在可行走法。
```

**示例 3**（自构造：覆盖「步数刚好够直达」的 $d=k$ 极端情形）

```text
输入：startPos = 3, endPos = 7, k = 4
输出：1
解释：d = 4 = k，每一步都必须朝目标方向，唯一走法 3→4→5→6→7，即 C(4, 4) = 1。
```

## 3. 解题思路

### 3.1 暴力思路：区间 DP

最直观的做法：令 $dp[i][j]$ 表示走 $i$ 步后位于位置 $j$ 的方法数。$k$ 步内可达位置范围为 $[\text{startPos}-k,\ \text{startPos}+k]$，把位置整体平移 $+k$ 落到 $[0, 2k]$ 防负下标：

- **初值**：$dp[0][\text{startPos}+k]=1$；
- **转移**：$dp[i][j]=dp[i-1][j-1]+dp[i-1][j+1]$（边界列只有单侧邻居）；
- **答案**：$dp[k][\text{endPos}+k]$。

时间 $O(k^2) \approx 2\times10^6$（$k=1000$），比赛现场完全能过，且不需要任何数学推导，是**保底解**。但它把「本可一步算出的组合数」逐格展开——若 $k$ 放大到 $10^5$ 就会超时，而组合数法仍是 $O(k)$。根因：位置维的线性递推存在闭式解，无需枚举。

### 3.2 核心观察：方向步数分解 ⟹ $\binom{k}{r}$

![核心观察：路径 ⟺ 朝目标/背离步数分配 ⟺ 组合数](images/wc309_q2_direction_decomposition.svg)

**第一步：路径 ⟺ 方向步数分配。** 设 $d = |\text{endPos} - \text{startPos}|$ 为距离。一条 $k$ 步路径中，设 $r$ 步**朝目标**方向、$l$ 步**背离**目标方向，则净推进为 $r - l$，到达终点当且仅当：

$$r + l = k, \qquad r - l = d$$

**第二步：解出步数。** 二元一次方程组有唯一解：

$$r = \frac{k+d}{2}, \qquad l = \frac{k-d}{2}$$

**第三步：可行性两条件。** $r, l$ 必须是非负整数，等价于：

1. **奇偶匹配**：$k - d$ 为偶数（即 $k$ 与 $d$ 同奇偶），否则 $r$ 不是整数；
2. **步数充足**：$d \le k$，否则 $l < 0$。

任一不满足，答案直接为 $0$——示例 2 正是死在条件 1（$d=3$ 奇、$k=10$ 偶）。

**第四步：转化为组合数。** 一条合法路径恰是「$r$ 步朝目标、$l$ 步背离」的一个**排列**：从 $k$ 个步槽中选 $r$ 个放「朝目标」步，其余自动是「背离」步。故：

$$\text{ans} = \binom{k}{r} = \binom{k}{\tfrac{k+d}{2}} \bmod (10^9+7)$$

> 💡 **对称性**：$\binom{k}{r}=\binom{k}{l}$，且 $d$ 与方向无关——把数轴沿 `startPos` 镜像，向右走与向左走的路径一一对应。所以参数虽是绝对位置，问题却退化为**纯距离**问题。

### 3.3 算法流程

![算法流程：可行性剪枝、定 r、组合数取模](images/wc309_q2_algorithm_flow.svg)

1. 计算 $d = |\text{endPos} - \text{startPos}|$；
2. 若 $(k-d)$ 为奇数**或** $d > k$，返回 $0$；
3. 令 $r = (k+d)/2$，必有 $0 \le r \le k$，无需越界判断；
4. 计算 $\binom{k}{r} \bmod (10^9+7)$：**杨辉三角递推**（$C(i,j)=C(i-1,j-1)+C(i-1,j)$，免逆元）或**预处理阶乘 + 费马小定理求逆元**（$p=10^9+7$ 为素数，$C(k,r)=\text{fact}[k]\cdot\text{invFact}[r]\cdot\text{invFact}[k-r]$）。

### 3.4 示例演算

![示例演算：DP 表每行都是杨辉三角](images/wc309_q2_dp_walkthrough.svg)

以示例 1（`startPos=1, endPos=2, k=3`）为例，两种解法在此汇合：

| 解法 | 演算 | 结果 |
|------|------|------|
| 区间 DP | $dp[0][1]=1$；$dp[1][0]=dp[1][2]=1$；$dp[2][-1]=1,\ dp[2][1]=2,\ dp[2][3]=1$；$dp[3][2]=dp[2][1]+dp[2][3]=3$ | $3$ |
| 组合数 | $d=1$，$(k-d)=2$ 为偶、$d\le k$ ✓；$r=(3+1)/2=2$；$\binom{3}{2}=3$ | $3$ |

注意 DP 表的每一行非零项恰是**杨辉三角**（$1$ / $1,1$ / $1,2,1$ / $1,3,3,1$），闭式为 $dp[i][j]=\binom{i}{(i+(j-\text{startPos}))/2}$——两种解法**同源**，组合数法只是把递推预先算成了闭式。这也解释了为什么按列看转移 $C(i,j)=C(i-1,j-1)+C(i-1,j)$ 正是帕斯卡恒等式。

## 4. 算法细节

1. **可行性判断合并**：`if ((k - d) % 2 != 0 || d > k) return 0;`。C++ 中 `d > k` 时 `k - d` 为负，`(k-d) % 2` 可能得 $-1$，用 `!= 0` 判断依然正确（见 §8 陷阱 1）。
2. **r 的范围自动合法**：通过可行性检查后 $d \le k$，故 $0 \le r = (k+d)/2 \le k$，组合数下标无需再判。
3. **杨辉三角一维滚动**：递推 $C(j) \mathrel{+}= C(j-1)$ 时 $j$ 必须**倒序**枚举，否则本行刚更新的 $C(j-1)$ 会污染 $C(j)$ 的计算（01 背包同理）；数组只需开到 $r+1$，空间 $O(r)$。
4. **阶乘 + 逆元模板**：$\text{invFact}[k] = \text{fact}[k]^{p-2} \bmod p$（费马小定理，仅调一次快速幂），再由 $\text{invFact}[i-1]=\text{invFact}[i]\cdot i \bmod p$ 线性回推，整体 $O(k+\log p)$。
5. **DP 法的实现要点**：位置统一 $+k$ 平移到 $[0,2k]$ 防负下标；用滚动数组把空间压到 $O(k)$；$j=0$ 与 $j=2k$ 两列只有单侧转移。
6. **Python 捷径**：`math.comb(k, r) % MOD`——$k \le 1000$ 时 $\binom{k}{r}$ 至多约 $10^{300}$，Python 大整数直接算再取模，赛场敲得最快。

## 5. 正确性证明

**引理 1**（镜像对称）：`endPos > startPos` 与 `endPos < startPos` 两类输入的答案相同，故不妨设 $\text{endPos} \ge \text{startPos}$（向右即朝目标）。

**证明**：把数轴沿 `startPos` 作镜像反射 $x \mapsto 2\cdot\text{startPos} - x$，则「从 `startPos` 出发在原数轴上的 $k$ 步路径」与「在镜像数轴上的 $k$ 步路径」一一对应（每步左 ↔ 右互换），终点 `endPos` 与其镜像互抵。故两类输入的合法路径数相等，答案只依赖 $d$。∎

**引理 2**（步数分配的刻画）：设 $\text{endPos} \ge \text{startPos}$，一条 $k$ 步路径到达 `endPos` 当且仅当其中向右步数 $r$ 与向左步数 $l$ 满足 $r + l = k$ 且 $r - l = d$；且此时 $r = (k+d)/2,\ l = (k-d)/2$ 由路径唯一确定。

**证明**：$k$ 步每步位移为 $\pm 1$，净位移 $= r - l$，到达 `endPos` $\iff$ 净位移 $= d$。又总步数 $r + l = k$ 恒成立。解此线性方程组得唯一解 $r = (k+d)/2,\ l = (k-d)/2$，由路径的向右步数唯一决定。∎

**引理 3**（可行性）：满足引理 2 条件的路径存在 $\iff$ $d \le k$ 且 $k \equiv d \pmod 2$。

**证明**：路径存在 $\iff$ 存在非负整数 $r, l$ 使 $r+l=k,\ r-l=d$。解方程组得 $r=(k+d)/2,\ l=(k-d)/2$，它们是非负整数 $\iff$ $k+d$ 与 $k-d$ 均为偶且 $k - d \ge 0$，即 $k \equiv d \pmod 2$ 且 $d \le k$（奇偶条件中两式等价）。∎

**引理 4**（双射计数）：恰好含 $r$ 步向右的 $k$ 步序列个数为 $\binom{k}{r}$。

**证明**：每个 such 序列对应集合 $\{1,\dots,k\}$ 的一个 $r$ 元子集（向右步所在的位置集合）；反之任给 $r$ 元子集，把对应位置放向右步、其余放向左步，得到唯一序列。此映射是双射，故计数为 $\binom{k}{r}$。∎

**定理**：答案为 $\binom{k}{(k+d)/2} \bmod (10^9+7)$；当 $d > k$ 或 $k \not\equiv d \pmod 2$ 时答案为 $0$。

**证明**：由引理 1 不妨设向右为朝目标。由引理 3，不可行时无合法路径，答案 $0$。可行时，合法路径集合 = 恰含 $r=(k+d)/2$ 步向右的 $k$ 步序列集合（引理 2），其大小由引理 4 为 $\binom{k}{r}$。∎

> 💡 顺带证明了 §3.4 的观察：对 DP 闭式 $dp[i][j]=\binom{i}{(i+(j-\text{startPos}))/2}$ 用帕斯卡恒等式展开，恰得转移方程 $dp[i][j]=dp[i-1][j-1]+dp[i-1][j+1]$，故 DP 表每行非零项构成杨辉三角。

## 6. 复杂度分析

- **时间复杂度**：$O(k)$（阶乘 + 逆元法：$O(k)$ 预处理 + 一次 $O(\log p)$ 快速幂）；杨辉递推法为 $O(k \cdot r) \le O(k^2)$，$k \le 1000$ 同样轻松通过。DP 法为 $O(k^2)$。
- **空间复杂度**：$O(k)$（阶乘/逆阶乘数组，或杨辉一维滚动、DP 滚动数组）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int numberOfWays(int startPos, int endPos, int k) {
        const int MOD = 1e9 + 7;
        int d = abs(endPos - startPos);          // 距离
        if ((k - d) % 2 != 0 || d > k) return 0; // 奇偶不匹配或步数不足
        int r = (k + d) / 2;                     // 朝目标步数，必有 0 <= r <= k

        // 杨辉三角一维滚动递推 C(k, r)，免逆元
        vector<int> C(r + 1, 0);
        C[0] = 1;
        for (int i = 1; i <= k; ++i)
            for (int j = min(i, r); j >= 1; --j) // 倒序：防止本行污染
                C[j] = (C[j] + C[j - 1]) % MOD;
        return C[r];
    }
};
```

### Python

```python
class Solution:
    def numberOfWays(self, startPos: int, endPos: int, k: int) -> int:
        MOD = 10**9 + 7
        d = abs(endPos - startPos)              # 距离
        if (k - d) % 2 != 0 or d > k:           # 奇偶不匹配或步数不足
            return 0
        r = (k + d) // 2                        # 朝目标步数

        # 阶乘 + 费马小定理求逆元（通用模板）
        fact = [1] * (k + 1)
        for i in range(1, k + 1):
            fact[i] = fact[i - 1] * i % MOD
        inv_fact = [1] * (k + 1)
        inv_fact[k] = pow(fact[k], MOD - 2, MOD)
        for i in range(k, 0, -1):
            inv_fact[i - 1] = inv_fact[i] * i % MOD

        return fact[k] * inv_fact[r] % MOD * inv_fact[k - r] % MOD
        # 赛场更快的写法：return math.comb(k, r) % MOD
```

## 8. 边界情况与易错点

1. **负数取模陷阱（C++）**：$d > k$ 时 `k - d` 为负，C++ 中 `(-3) % 2 == -1`。判断必须写 `(k - d) % 2 != 0`，**不能写 `== 1`**（会漏掉 $-1$ 的情况）；先判 `d > k` 或改用 `((k - d) & 1)` 也可。Python 的 `%` 恒非负，无此问题。
2. **$d = k$ 极端情形**：只有「全程朝目标」一条路，答案 $\binom{k}{k} = 1$（示例 3）。
3. **$d = 0$ 且 $k$ 为奇数**：原地往返奇数步回不到原点，答案 $0$；$k$ 为偶数时答案 $\binom{k}{k/2}$（一半朝右一半朝左）。
4. **溢出**：中间乘法 `fact * i`、`C[j] + C[j-1]` 均需 `long long`/取模；$\binom{1000}{500} \approx 2.7 \times 10^{299}$，**绝不能用 `double`**（精度只有约 15 位）。
5. **模数是 $10^9+7$ 不是 $10^9+9$**，题面明确给出，抄错直接 WA。
6. **DP 法的负下标**：可达区间含负位置（如 $\text{startPos}-k < 0$），必须整体 $+k$ 平移；首尾两列（$j=0$ 与 $j=2k$）只有单侧邻居，转移要加边界判断。
7. **杨辉滚动必须倒序**：正序枚举 $j$ 会把本行刚算出的 $C(j-1)$ 当上行值使用，结果错。
