# LeetCode 可被 K 整除的最小整数 题解

## 1. 题目概述

- **标题 / 题号**：可被 K 整除的最小整数（#1015，medium）
- **链接**：https://leetcode.cn/problems/smallest-integer-divisible-by-k/
- **来源**：LeetCode 第 129 场周赛 Q2
- **难度**：中等
- **标签**：数学、哈希表、抽屉原理

**题意**：给定正整数 $k$，找出**只由数字 1 组成**的正整数 $n$（$1, 11, 111, \dots$）中能被 $k$ 整除的**最小**者，返回它的**长度**；不存在则返回 $-1$。

注意 $n$ 本身可能超出 64 位整数范围，所以题目要的是**长度**而不是数值。

**约束**：

- $1 \le k \le 10^5$

## 2. 示例

**示例 1**

```text
输入：k = 1
输出：1
解释：最小的答案是 n = 1，长度 1。
```

**示例 2**

```text
输入：k = 2
输出：-1
解释：任何只由 1 组成的数都是奇数，不可能被 2 整除。
```

**示例 3**

```text
输入：k = 3
输出：3
解释：111 = 3 × 37，长度 3。
```

**示例 4**

```text
输入：k = 7
输出：6
解释：111111 = 7 × 15873。
```

## 3. 解题思路

### 3.1 暴力思路

依次构造 $1, 11, 111, \dots$，对每个数判断 `% k == 0`。

问题在于**长度可能非常大**：$k = 10^5$ 时答案长度可达 $10^5$ 位，BigInteger 每次乘 10 加 1 是 $O(L)$，总共 $O(L^2)$，在需要判 $k$ 次的情况下不可接受（何况 Python 的大整数虽然够用，但循环次数一多也很慢）。

暴力的启示是：**答案的长度不会超过 $k$**。因为长度为 $1, 2, \dots, k$ 的全 1 数只有 $k$ 个余数，若都不为 0 就必然出现重复，此后序列进入循环（详见 3.2 的抽屉原理）。

### 3.2 核心观察：只需要余数，且余数必然循环

![全 1 数模 k 的余数序列：0 出现即答案，重复即死循环](images/wc129_q2_mod_cycle.svg)

设 $R_L$ 为长度 $L$ 的全 1 数 $11\cdots1$（$L$ 个 1）模 $k$ 的余数。构造上满足

$$R_L = (10 \cdot R_{L-1} + 1) \bmod k, \qquad R_0 = 0$$

**关键点**：求 $R_L \bmod k$ 只需知道 $R_{L-1} \bmod k$，**不需要保存整个大整数**。于是算法变成：

```text
r = 0
for L = 1, 2, 3, ...:
    r = (r * 10 + 1) % k
    若 r == 0: 返回 L
```

**什么时候返回 -1？** 余数只有 $k$ 种取值（$0 \sim k-1$）。若前 $k$ 步都没有出现 0，那么 $k$ 个余数 $\{R_1, \dots, R_k\}$ 落在 $k-1$ 个非零余数上，由**抽屉原理**必有两个相等，设为 $R_a = R_b$（$a < b$）。此后 $R_{b+1} = (10R_b + 1) \bmod k = (10R_a + 1) \bmod k = R_{a+1}$，序列进入**周期循环**，永远不会再出现 0。所以循环上限取 $k$ 即可。

还有一个 $O(1)$ 的快速否决条件：

$$k \text{ 是 } 2 \text{ 或 } 5 \text{ 的倍数} \implies \text{无解}$$

因为全 1 数的个位是 1，它是奇数且不被 5 整除，自然不可能被 $k$ 的因子 2 或 5 整除。

反过来，若 $\gcd(k, 10) = 1$，由欧拉定理（取 $L = \varphi(9k)$，则 $10^L \equiv 1 \pmod{9k}$，即 $9k \mid 10^L - 1$）必有解——所以 $-1$ 当且仅当 $k$ 是 2 或 5 的倍数。

### 3.3 算法流程

![算法流程：余数递推，遇 0 返回长度，最多试 k 次](images/wc129_q2_flow.svg)

```text
1. 若 k % 2 == 0 或 k % 5 == 0：返回 -1
2. r = 0
3. for L = 1 .. k:
       r = (r * 10 + 1) % k
       若 r == 0：返回 L
4. 返回 -1
```

第 1 步不是必需的（第 3 步循环 $k$ 次后同样会返回 -1），但它把「一眼可见无解」的情况压缩成 $O(1)$。

### 3.4 示例演算

![示例演算：k = 3 时余数在 3 步内归零，k = 2 时余数恒为 1](images/wc129_q2_walkthrough.svg)

**$k = 3$**：

| $L$ | $10 R_{L-1} + 1$ | $R_L = \cdot \bmod 3$ |
|---|---|---|
| 1 | 1 | 1 |
| 2 | 11 | 2 |
| 3 | 21 | **0** → 返回 3 |

验证：$111 = 3 \times 37$ ✓。

**$k = 2$**：$R_1 = 1$，$R_2 = (10+1) \bmod 2 = 1$，$R_3 = 1$……余数恒为 1，永不归零 → $-1$ ✓。

**$k = 7$**：

| $L$ | $R_L$ | | $L$ | $R_L$ |
|---|---|---|---|---|
| 1 | 1 | | 4 | 5 |
| 2 | 4 | | 5 | 2 |
| 3 | 6 | | 6 | **0** → 返回 6 |

验证：$111111 = 7 \times 15873$ ✓。

## 4. 算法细节

1. **只算余数**：`r = (r * 10 + 1) % k`，`r` 始终小于 $k$，不会溢出（$k \le 10^5$ 时 `int` 足够，$r \cdot 10 \le 10^6$）。
2. **循环上限**：`k` 次。注意 $k = 1$ 时第 1 步就会得到 $r = 1 \bmod 1 = 0$，返回 1。
3. **提前否决**：`k % 2 == 0 || k % 5 == 0` 直接 $-1$，与循环的结论一致，属于纯优化。
4. **为什么不需要哈希集合**：序列一旦重复就进入循环，因此「试满 $k$ 次」与「检测到重复」等价；不需要真的记录访问过的余数。
5. **数学补充**：$R_L = (10^L - 1)/9$，所以 $k \mid R_L \iff 9k \mid 10^L - 1$，这给出了用「10 在模 $9k$ 下的阶」求答案的理论路径，但阶的计算（分解 $\varphi(9k)$）比直接迭代复杂得多，仅适合作为正确性论证。
6. **不要用大整数枚举**：$k = 10^5$ 时长度可达 $10^5$ 位，构造字符串/大整数会非常慢。

## 5. 正确性证明

**引理 1（递推正确）**：对任意 $L \ge 1$，$R_L \equiv 10 R_{L-1} + 1 \pmod k$，其中 $R_L$ 是 $L$ 位全 1 数。

**证明**：$L$ 位全 1 数等于「$L-1$ 位全 1 数乘 10 再加 1」，即 $N_L = 10 N_{L-1} + 1$。两边模 $k$ 即得。∎

**引理 2（无解判据）**：若前 $k$ 步都没有出现 $R_L \equiv 0$，则对所有 $L$ 都有 $R_L \not\equiv 0$。

**证明**：$R_1, \dots, R_k$ 共 $k$ 个数，落在 $\{0, 1, \dots, k-1\}$ 中。若都非零，则落在 $k-1$ 个非零余数上，由抽屉原理存在 $1 \le a < b \le k$ 使 $R_a = R_b$。由引理 1，$R_{b+1} \equiv 10R_b + 1 \equiv 10R_a + 1 \equiv R_{a+1} \pmod k$，如此递推得：对任意 $t \ge 0$，$R_{b+t} \equiv R_{a+t}$。即序列从 $a$ 起以 $b-a$ 为周期循环，而 $R_1, \dots, R_k$ 均非零，故所有项都不为零。∎

**引理 3（2 或 5 的倍数无解）**：若 $2 \mid k$ 或 $5 \mid k$，则不存在只由 1 组成的正整数被 $k$ 整除。

**证明**：全 1 数 $N_L$ 的个位是 1，故 $N_L$ 为奇数，不被 2 整除；又 $N_L \equiv 1 \pmod 5$，不被 5 整除。若 $2 \mid k$ 则 $k \mid N_L$ 要求 $2 \mid N_L$，矛盾；若 $5 \mid k$ 同理矛盾。∎

**引理 4（$\gcd(k,10)=1$ 必有解）**：若 $\gcd(k, 10) = 1$，则存在 $L \ge 1$ 使 $k \mid N_L$。

**证明**：令 $M = 9k$，则 $\gcd(10, M) = 1$（$10$ 与 $9$、$k$ 都互素）。由欧拉定理，取 $L = \varphi(M)$ 有 $10^L \equiv 1 \pmod{M}$，即 $9k \mid 10^L - 1$。于是 $k \mid (10^L - 1)/9 = N_L$。∎

**定理**：算法返回最小长度，无解时返回 $-1$。

**证明**：算法按 $L = 1, 2, \dots$ 递增枚举，第一个满足 $R_L = 0$ 的 $L$ 就是最小长度（引理 1 保证递推正确）。若前 $k$ 步无 0，由引理 2 永远无 0，返回 $-1$ 正确。提前否决条件由引理 3 保证是真正的无解；结合引理 4，$-1$ 恰好当且仅当 $2 \mid k$ 或 $5 \mid k$。∎

## 6. 复杂度分析

- **时间**：$O(k)$。最多迭代 $k$ 次，每次一次乘法、一次加法、一次取模，都是 $O(1)$。$k \le 10^5$ 时非常快；提前否决可把 2/5 倍数的情况降到 $O(1)$。
- **空间**：$O(1)$。只保存当前余数 `r` 与长度计数。
- 对比：大整数枚举是 $O(L^2)$ 且 $L$ 可达 $10^5$（即 $10^{10}$ 级），不可行。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int smallestRepunitDivByK(int k) {
        if (k % 2 == 0 || k % 5 == 0) return -1;
        int r = 0;
        for (int len = 1; len <= k; len++) {
            r = (r * 10 + 1) % k;
            if (r == 0) return len;
        }
        return -1;
    }
};
```

### Python

```python
class Solution:
    def smallestRepunitDivByK(self, k: int) -> int:
        if k % 2 == 0 or k % 5 == 0:
            return -1
        r = 0
        for length in range(1, k + 1):
            r = (r * 10 + 1) % k
            if r == 0:
                return length
        return -1
```

## 8. 边界情况与易错点

1. **`k = 1`**：第 1 轮 `r = 1 % 1 = 0`，返回 1。注意 `1 % 1 == 0`，不要写成 `if (r == 0 && len > 1)`。
2. **`k = 2` 或 `5`**：返回 -1。注意 $k = 10$、$k = 15$ 等含因子 2 或 5 的合数同样无解。
3. **循环上限写成 `k - 1`**：抽屉原理保证在 $k$ 步内必出现 0 或重复，写 `k - 1` 可能少判一步（例如 $k = 3$ 的答案是 3，会被漏掉）。
4. **用大整数直接求值**：`n = n * 10 + 1` 在长度 $10^5$ 时会变成天文数字，C++ 直接溢出，Python 虽然能算但极慢。
5. **误以为「$k$ 与 10 互素就一定有解」是充分必要条件**：它等价于「$k$ 不是 2 或 5 的倍数」，本题成立；但若把题目换成「由数字 2 组成」，判据会变成 $k$ 不是 5 的倍数（2 的幂因子仍可整除），需重新推导。
6. **提前返回 0 长度**：`R_0 = 0`，若循环从 `L = 0` 开始会直接返回 0，答案错误。长度必须从 1 起算。
7. **`r * 10 + 1` 溢出**：$r < k \le 10^5$，乘积 $\le 10^6$，`int` 安全；若 $k$ 放大到 $10^9$ 需用 `long long`。
8. **`-1` 与 0 混淆**：题目要求无解返回 -1，不要返回 0。
