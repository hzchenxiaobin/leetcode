# LeetCode 最佳观光组合 题解

## 1. 题目概述

- **标题 / 题号**：最佳观光组合（#1014，medium）
- **链接**：https://leetcode.cn/problems/best-sightseeing-pair/
- **来源**：LeetCode 第 129 场周赛 Q3
- **难度**：中等
- **标签**：数组、动态规划

**题意**：给定正整数数组 `values`，任选一对景点 $i < j$，得分定义为

$$\text{score}(i, j) = values[i] + values[j] + i - j$$

求所有 $i < j$ 中可能的**最高得分**。

**约束**：

- $2 \le values.length \le 5 \times 10^4$
- $1 \le values[i] \le 1000$

> 💡 得分里的 $+i - j$ 不是「距离惩罚」的笔误：$i < j$ 时 $i - j < 0$，所以距离越远扣得越多。把 $+i$ 与 $-j$ 分别归到两个景点，问题就解耦了。

## 2. 示例

**示例 1**

```text
输入：values = [8,1,5,2,6]
输出：11
解释：i = 0, j = 2 时得分 = 8 + 5 + 0 - 2 = 11，最高。
```

**示例 2**

```text
输入：values = [1,2]
输出：2
解释：i = 0, j = 1，得分 = 1 + 2 + 0 - 1 = 2。
```

**示例 3**

```text
输入：values = [1,1,1,1]
输出：1
解释：只有相邻的两个能得 1（1+1−1），隔得越远扣得越多。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有 $i < j$，算分取最大。共 $\binom{n}{2} = O(n^2)$ 对，$n = 5\times10^4$ 时约 $1.25\times10^9$ 次运算，超时。

### 3.2 核心观察：把得分拆成「只含 i」与「只含 j」两部分

![得分拆解：(values[i] + i) + (values[j] − j)](images/wc129_q3_decompose_concept.svg)

把式子重排：

$$\text{score}(i,j) = \underbrace{(values[i] + i)}_{A(i)} + \underbrace{(values[j] - j)}_{B(j)}$$

这一步是本题的全部关键：**原本耦合的 $i, j$ 被拆成了两个只依赖单个下标的部分**。于是对固定的 $j$：

$$\max_{i < j} \text{score}(i,j) = B(j) + \max_{i < j} A(i)$$

也就是说，只要在从左到右扫描的过程中**维护「$j$ 之前所有 $A(i)$ 的最大值」**，就能对每个 $j$ 在 $O(1)$ 时间内得到「以 $j$ 结尾的最优组合」。

扫描时维护

$$\text{best} = \max_{i < j}\bigl(values[i] + i\bigr)$$

每到一个新的 $j$：

1. 先用当前的 `best` 更新答案：`ans = max(ans, best + values[j] - j)`；
2. 再把 $j$ 自己纳入候选：`best = max(best, values[j] + j)`。

**顺序不能颠倒**：必须先用 $j$ 之前的 `best` 算答案，再把 $j$ 加进 `best`，否则会出现 $i = j$ 的非法组合（自己和自己配对）。

### 3.3 算法流程

![算法流程：一次扫描，先算答案再更新 best](images/wc129_q3_flow.svg)

```text
1. best = values[0] + 0，ans = 0
2. for j = 1 .. n-1:
       ans = max(ans, best + values[j] - j)
       best = max(best, values[j] + j)
3. 返回 ans
```

用一个变量 `best` 代替「维护一个前缀最大值数组」，空间从 $O(n)$ 降到 $O(1)$。

### 3.4 示例演算

![示例演算：values = [8,1,5,2,6] 的逐列走查](images/wc129_q3_walkthrough.svg)

对示例 1 的 `values = [8,1,5,2,6]`：

| $j$ | $values[j]$ | 当前 `best` | `best + values[j] − j` | `ans` | 更新后 `best` |
|---|---|---|---|---|---|
| 0 | 8 | 8 | — | 0 | 8 |
| 1 | 1 | 8 | $8 + 1 - 1 = 8$ | 8 | $\max(8, 2) = 8$ |
| 2 | 5 | 8 | $8 + 5 - 2 = 11$ | **11** | $\max(8, 7) = 8$ |
| 3 | 2 | 8 | $8 + 2 - 3 = 7$ | 11 | $\max(8, 5) = 8$ |
| 4 | 6 | 8 | $8 + 6 - 4 = 10$ | 11 | $\max(8, 10) = 10$ |

最高分 11，对应 $i = 0, j = 2$ ✓。

注意第 4 行 `best` 更新为 10（来自 $values[4] + 4 = 10$），但它已经没有后续下标可使用——这正说明「更新 `best` 必须在算答案之后」，否则答案会用到不存在的位置。

## 4. 算法细节

1. **初始化**：`best = values[0] + 0`，即先把下标 0 放入候选；`ans` 可以初始化为 0（因为 $i<j$ 且 $values \ge 1$，得分至少为 1），更稳妥的是 `INT_MIN`。
2. **循环起点**：$j$ 从 1 开始，保证 $i < j$ 至少有一个候选。
3. **先算后更新**：这是双指针/滚动 DP 的通用纪律，等价于「用 $j$ 之前的信息回答 $j$ 的问题」。
4. **`ans` 与 `best` 的类型**：`values[i] + i \le 1000 + 5\times10^4$，`int` 足够。
5. **不要用「距离」的直觉**：$i - j$ 是负数，得分不是「评分和减距离」而是「评分和减差值」；$values[i] + i$ 与 $values[j] - j$ 的拆分正是把「位置奖励」给了左边、「位置惩罚」给了右边。
6. **推广**：把 $i - j$ 换成 $c \cdot (i - j)$ 或换成 $i \cdot j$ 的题，拆分方式会变（例如 $i \cdot j$ 无法拆成两独立项，需要凸包/分数规划），可见本题的线性系数是能用 $O(1)$ 状态的关键。

## 5. 正确性证明

记 $A(i) = values[i] + i$，$B(j) = values[j] - j$。

**引理 1（分解）**：对任意 $i, j$，$\text{score}(i,j) = A(i) + B(j)$。

**证明**：$values[i] + values[j] + i - j = (values[i] + i) + (values[j] - j)$，直接代数变形。∎

**引理 2（扫描不变式）**：循环到下标 $j$（$j \ge 1$）时，`best` $= \max_{0 \le i < j} A(i)$。

**证明**：对 $j$ 归纳。$j = 1$ 时 `best = A(0)`，即 $\max_{i<1} A(i)$。设处理完 $j-1$ 后 `best` $= \max_{i<j-1} A(i)$ 且结束时已更新为 $\max_{i<j} A(i)$；则处理 $j$ 时，`best` 先保持 $\max_{i<j}A(i)$（用于第 1 步），第 2 步更新为 $\max(\max_{i<j}A(i), A(j)) = \max_{i<j+1}A(i)$，归纳成立。∎

**引理 3（每步最优）**：第 $j$ 轮计算的 `best + values[j] - j` 等于 $\max_{i<j}\text{score}(i,j)$。

**证明**：由引理 2，`best` $= \max_{i<j}A(i)$；又 $B(j)$ 与 $i$ 无关，故 $\max_{i<j}(A(i)+B(j)) = \max_{i<j}A(i) + B(j) = $ `best + values[j] - j`。∎

**定理**：算法返回全局最高得分。

**证明**：由引理 3，每一轮得到的值恰为「以 $j$ 为右端点的最高得分」；`ans` 对所有 $j \in [1, n-1]$ 取最大，即覆盖了所有 $i < j$ 的组合，故 `ans` 为全局最高分。∎

## 6. 复杂度分析

- **时间**：$O(n)$。每个下标一次加法、一次减法、两次比较，共 $n-1$ 轮。
- **空间**：$O(1)$。只用 `best`、`ans` 两个变量；若展开成「前缀最大值数组」则 $O(n)$，没有必要。
- 对比：暴力 $O(n^2)$；分治（每次取左半最大 $A$ 与右半最大 $B$ 合并）是 $O(n \log n)$，虽正确但更慢。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maxScoreSightseeingPair(vector<int>& values) {
        int n = (int)values.size();
        int best = values[0] + 0;
        int ans = INT_MIN;
        for (int j = 1; j < n; j++) {
            ans = max(ans, best + values[j] - j);
            best = max(best, values[j] + j);
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maxScoreSightseeingPair(self, values: list[int]) -> int:
        best = values[0]
        ans = float('-inf')
        for j in range(1, len(values)):
            ans = max(ans, best + values[j] - j)
            best = max(best, values[j] + j)
        return ans
```

## 8. 边界情况与易错点

1. **先更新 `best` 再算答案**：会用 $i = j$ 的组合，得分变成 $2 \cdot values[j] + j - j = 2values[j]$，明显偏大。
2. **`ans` 初始化为 0**：本题 $values \ge 1$，得分至少 1，不初始化成 0 也能过；但如果 `values` 可能为负，必须用 `INT_MIN`/`-inf`。
3. **`j` 从 0 开始**：第一轮 `best` 还没初始化或被误用，会得到非法结果。
4. **`best` 忘记加 `i`**：只维护 $\max values[i]$ 会丢掉 $+i$ 项，答案偏小。
5. **`j` 的符号写错**：$B(j) = values[j] - j$，不是 $values[j] + j$；$+j$ 只出现在更新 `best` 时。
6. **数组长度 2**：循环执行一次，答案 $= values[0] + values[1] - 1$，与示例 2 一致。
7. **全相同元素**：得分随距离递减，最优一定是相邻两项，答案 $= 2v - 1$。
8. **整数范围**：`best` 最大 $1000 + 5\times10^4$，`ans` 最大约 $2\times10^3$，`int` 完全足够。
