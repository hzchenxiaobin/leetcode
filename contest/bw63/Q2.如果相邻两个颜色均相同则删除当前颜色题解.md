# LeetCode 如果相邻两个颜色均相同则删除当前颜色 题解

## 1. 题目概述

- **标题 / 题号**：如果相邻两个颜色均相同则删除当前颜色（#2038，medium）
- **链接**：https://leetcode.cn/problems/remove-colored-pieces-if-both-neighbors-are-the-same-color/
- **来源**：LeetCode 第 63 场双周赛 Q2
- **难度**：中等
- **标签**：贪心、数学、字符串、博弈

**题意**：给定长度为 $n$ 的字符串 `colors`，仅含 `'A'` 和 `'B'`。Alice 与 Bob 轮流删除片段，Alice 先手：

- Alice 只能删除**某个 'A' 片段**，且它的**左右相邻**片段（删除那一瞬间的字符串中）都必须是 `'A'`；
- Bob 只能删除某个 `'B'` 片段，且左右相邻片段都必须是 `'B'`；
- 两端的位置不能作为被删片段（因为它们没有两侧邻居）。

谁无法操作谁输。假设双方都采取最优策略，Alice 获胜返回 `true`，否则返回 `false`。

**约束**：

- $1 \le colors.length \le 10^5$
- `colors` 只包含字母 `'A'` 和 `'B'`

## 2. 示例

**示例 1**

```text
输入：colors = "AAABABB"
输出：true
解释：Alice 删除从左数第二个 'A'（唯一可删的 A），字符串变为 "AABABB"。
轮到 Bob：不存在左右都是 'B' 的 'B' 片段（B 段最长只有 2），Bob 无法操作，Alice 获胜。
```

**示例 2**

```text
输入：colors = "AA"
输出：false
解释：长度为 2 的 A 段没有"内部"片段可删，Alice 先手即无操作，直接落败。
```

**示例 3**

```text
输入：colors = "ABBBBBBBAAA"
输出：false
解释：Alice 全局只有 1 步可走（AAA 段的中间那个 A）；Bob 的 B 段长 7，可走 5 步。
走完各自的步数后 Alice 先耗尽，Bob 获胜。
```

## 3. 解题思路

### 3.1 暴力思路

直接模拟博弈：每一步枚举当前玩家所有可删位置，删除后递归到下一状态，用记忆化搜索求必胜态。状态数最坏是 $2^n$ 级别（每次删一个字符，剩余字符的相对形态组合爆炸），$n = 10^5$ 完全不可行；即便记忆化，状态空间仍是指数级，因为"哪些位置被删了"本质是子集枚举。

突破口在于注意到：**Alice 的操作对象永远是 A 段的"内部"，Bob 的操作对象永远是 B 段的"内部"，两人的操作互不干扰**——这可以把博弈拆成两个独立的计数问题。

### 3.2 核心观察：双方的可操作总数是不变量

![核心观察：同色连续段计数，A 只能消耗 A 段、B 只能消耗 B 段](images/bw63_q2_runs_count.svg)

把 `colors` 切分成**极大同色连续段**（run）：如 `"AAABABB"` = `AAA | B | A | BB`。对每一段：

- 长度为 $L$ 的 A 段中，Alice 可删的只有段内"非端点"的 $L - 2$ 个位置（长度 $\le 2$ 的段无可删位置）；
- **删除段内一个 A 后段长变为 $L - 1$，段不消失、也不与别的段合并**——因为删掉一个字符后左右邻居自动贴拢，段仍然连续，只是短了一点。

关键的不变量是：**Alice 每走一步，A 段的世界就确定性地"少一步可走"；Bob 的操作完全不改变 A 段的形态，反之亦然**。于是：

$$\text{Alice 总步数} = \sum_{\text{A 段}} \max(0, L - 2), \qquad \text{Bob 总步数} = \sum_{\text{B 段}} \max(0, L - 2).$$

两个数字与双方的策略**完全无关**，博弈退化为比较两个计数：Alice 先手，谁的总步数多谁就后耗尽，Alice 获胜当且仅当 $a > b$。

### 3.3 算法流程

![算法流程：一次线性扫描统计各色段贡献](images/bw63_q2_scan_flow.svg)

```text
1. a = b = 0, i = 0
2. while i < n:
     j = 从 i 开始向右延伸到极大同色段末尾
     若段为 'A'：a += max(0, j − i − 2)
     若段为 'B'：b += max(0, j − i − 2)
     i = j
3. 返回 a > b
```

一遍扫描、两个计数器，没有任何博弈搜索。

### 3.4 示例演算

以示例 3 `"ABBBBBBBAAA"`（A 段 1 + B 段 7 + A 段 3）为例：

| 段 | 颜色 | 长度 $L$ | 贡献 $\max(0, L-2)$ |
|----|------|----------|---------------------|
| 位置 0 | A | 1 | 0 |
| 位置 1–7 | B | 7 | 5 |
| 位置 8–10 | A | 3 | 1 |

$a = 0 + 1 = 1$，$b = 5$，$a \le b$，Alice 先手先耗尽，返回 `false`，与官方答案一致。注意"策略"在这里没有任何作用：哪怕 Bob 故意删"错"位置，他能走的步数也恒等于 5 步。

## 4. 算法细节

1. **段的切分**：双指针 `i, j`：`j` 从 `i` 出发走到第一个 `colors[j] != colors[i]` 处，段长 `j - i`。这是最朴素的实现；也可用 `itertools.groupby`（Python）一句话完成。
2. **贡献公式**：段长 $L \le 2$ 时贡献 $0$，公式 $\max(0, L-2)$ 已含此判断，无需 `if`。
3. **计数用长整型**：$n \le 10^5$，$L - 2$ 求和上界 $\le 10^5$，其实 `int` 也够；但养成"博弈计数用 `long long`"的习惯无害。
4. **奇偶性陷阱**：本题**不是** Nim 博弈，没有异或解法；答案只取决于两个计数的大小比较，与先后手交替中的奇偶无关（Alice 恰好比 Bob 多一步才赢，相等也是输——因为轮到 Alice 时她已无路可走）。
5. **为什么"删中间不删端点"不影响计数**：可删位置必须左右同色，即段内非端点。每次删除使段长减 1，段内非端点数从 $\max(0, L-2)$ 变为 $\max(0, L-3)$，恰好减 1；无论删段内哪个非端点，效果相同。

## 5. 正确性证明

**引理 1（操作不改变对方段结构）**：Alice 删除一个合法的 A 片段后，所有 B 段的长度与个数完全不变；Bob 对 A 段同理。

**证明**：Alice 删的是某个长 $L \ge 3$ 的 A 段的内部片段。删除后该 A 段两端仍是 A（内部片段的左右邻居都是 A，删掉后它们贴拢仍是 A 的邻居），段长变为 $L - 1 \ge 2$，即**该 A 段不会消失**。又因为 A 段长度始终 $\ge 2$，夹在两个 B 段之间的 A 段永远不会被删空，因此任意两个 B 段永远不会因 A 段消失而合并；A 段自身也不可能"分裂"（删除内部片段只缩短段长，段依旧连续）。B 段的个数、长度、相对顺序全部不变。由对称性，Bob 的操作也不改变 A 段结构。∎

**引理 2（势函数精确递减）**：定义势函数 $\Phi_A = \sum_{\text{A 段}} \max(0, L - 2)$。则

- Alice 能操作当且仅当 $\Phi_A > 0$；
- Alice 每操作一次，$\Phi_A$ 恰好减少 $1$；
- Bob 的操作不改变 $\Phi_A$。

**证明**：$\Phi_A > 0$ 当且仅当存在长 $L \ge 3$ 的 A 段，当且仅当存在左右均为 A 的内部片段（即可删位置），第一条得证。Alice 在长 $L \ge 3$ 的 A 段删除一个内部片段，由引理 1 该段变为长 $L - 1$ 的段、其余 A 段不变，故 $\Phi_A$ 的变化量为 $\max(0, L - 3) - \max(0, L - 2) = -1$（因 $L \ge 3$），第二条得证。第三条是引理 1 的直接推论。∎

**定理（胜负判定）**：记 $a = \Phi_A$（初始时刻）、$b = \Phi_B$。双方任意策略下，Alice 恰好走 $a$ 步、Bob 恰好走 $b$ 步；Alice 获胜当且仅当 $a > b$。

**证明**：由引理 2，$a$ 与 $b$ 是与策略无关的定值。按引理 2，某玩家在自己的回合无操作当且仅当他此刻的势为 $0$；由于势只被本人的操作消耗、每次恰减 1，故第 $i$ 轮 Alice 有操作当且仅当 $i \le a$，Bob 有操作当且仅当 $i \le b$。若 $a > b$：第 $b + 1$ 轮轮到 Bob 时其势已为 $0$，而 Alice 在前 $a \ge b + 1$ 轮均有操作，Bob 先无路可走，Alice 胜。若 $a \le b$：第 $a + 1$ 轮轮到 Alice 时其势为 $0$（若 $a = b$，两人各走 $a$ 步后轮到 Alice 先无操作；若 $a < b$，Alice 更早耗尽），Alice 败。∎

## 6. 复杂度分析

- **时间**：$O(n)$。双指针切分所有极大同色段，每个字符最多被 `j` 指针扫过一次。
- **空间**：$O(1)$。只有两个计数器与扫描指针（Python 不建段列表时同样 $O(1)$ 额外空间）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool winnerOfGame(string colors) {
        long long a = 0, b = 0;
        int i = 0, n = (int)colors.size();
        while (i < n) {
            int j = i;
            while (j < n && colors[j] == colors[i]) ++j;
            long long len = j - i;
            if (colors[i] == 'A') a += max(0LL, len - 2);
            else b += max(0LL, len - 2);
            i = j;
        }
        return a > b;
    }
};
```

### Python

```python
class Solution:
    def winnerOfGame(self, colors: str) -> bool:
        a = b = 0
        i, n = 0, len(colors)
        while i < n:
            j = i
            while j < n and colors[j] == colors[i]:
                j += 1
            if colors[i] == 'A':
                a += max(0, j - i - 2)
            else:
                b += max(0, j - i - 2)
            i = j
        return a > b
```

> 💡 两份代码均通过官方全部 3 组示例，并与"逐状态 minimax 记忆化搜索"的暴力博弈实现做了 400 组随机对拍（长度 $\le 14$，覆盖先手即败、势均力敌、大段 A/B 等情形），结果完全一致。

## 8. 边界情况与易错点

1. **$n = 1, 2$ 或全段长度 $\le 2$**：$a = b = 0$，Alice 先手即输，返回 `false`。`max(0, L-2)` 天然处理。
2. **势相等时 Alice 输**：判断条件是 $a > b$ 而非 $a \ge b$。`"AAABBB"` 中 $a = b = 1$，Alice 走完唯一一步后 Bob 走他那步，随后 Alice 无路，Alice 败。
3. **误当 Nim 博弈做异或**：本题每方步数是**独立定额**，不是双方共享棋堆的 Nim，`a ^ b` 之类的判定完全错误。
4. **误以为删中间能"多创造机会"**：常见错误想法是"删 A 段正中间把一段劈成两段"。注意删除后字符串贴拢，段长只减 1，**不会分裂成两段**；所有删除等价，步数固定。
5. **大整数**：$n = 10^5$ 时 $a, b \le 10^5 - 2$，C++ `int` 也能装下，但用 `long long` 表述势函数更严谨（若值域放大即无溢出之虞）。
6. **两端片段永不可删**：切分统计已隐含此规则——长度 1 的段贡献 0，切勿为"边缘 A"单独加特判。

**延伸思考**：本题属于**疲劳博弈（exhaustion game / counting game）**——双方各自拥有独立的"行动配额"，胜负只由配额比较决定，代表性结论是"先手赢当且仅当配额严格更多"。它与 Nim 的本质区别在于：Nim 中一步操作会同时改变对方后续可选的操作集合，而这里操作集合被颜色隔离，互不相扰。若把规则改成"Alice 也能删 B 片段"（双方共享操作集），不变量立即失效，问题回到真正的组合博弈，需要 Sprague-Grundy 理论处理；若改成"删掉的片段得分、得分高者胜"，则变成带偏好的疲劳博弈，仍可用类似势函数做差分析。
