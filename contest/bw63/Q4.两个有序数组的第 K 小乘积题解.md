# LeetCode 两个有序数组的第 K 小乘积 题解

## 1. 题目概述

- **标题 / 题号**：两个有序数组的第 K 小乘积（#2040，hard）
- **链接**：https://leetcode.cn/problems/kth-smallest-product-of-two-sorted-arrays/
- **来源**：LeetCode 第 63 场双周赛 Q4
- **难度**：困难
- **标签**：数组、二分查找

**题意**：给定两个**升序**整数数组 `nums1`、`nums2` 和整数 $k$，把所有 $nums1[i] \times nums2[j]$（共 $n_1 \times n_2$ 个，按值从小到大、相同值重复计数）排成序列，返回其中第 $k$ 小（1 编号）的乘积值。

**约束**：

- $1 \le n_1, n_2 \le 5 \times 10^4$，故乘积总数至多 $2.5 \times 10^9$ 个
- $-10^5 \le nums1[i], nums2[j] \le 10^5$，故单个乘积值域为 $[-10^{10}, 10^{10}]$
- $1 \le k \le n_1 \times n_2$

## 2. 示例

**示例 1**

```text
输入：nums1 = [2,5], nums2 = [3,4], k = 2
输出：8
解释：全体乘积为 {6, 8, 15, 20}，升序第 2 个是 8。
```

**示例 2**

```text
输入：nums1 = [-4,-2,0,3], nums2 = [2,4], k = 6
输出：0
解释：乘积升序前几个：−16, −8, −8, −4, 0, 0, ...，第 6 个是 0。
（两个 0 来自 0×2 与 0×4，重复值按重数计。）
```

**示例 3**

```text
输入：nums1 = [-2,-1,0,1,2], nums2 = [-3,-1,2,4,5], k = 3
输出：-6
解释：乘积升序前几个：−10, −8, −6, ...，第 3 个是 −6。
```

## 3. 解题思路

### 3.1 暴力思路

生成全部 $n_1 \times n_2 \le 2.5 \times 10^9$ 个乘积再排序——时间与空间都爆炸，不可行。退一步的"对拍暴力"是生成后 `nth_element`/排序，仅适用于 $n_1, n_2 \le 8$ 的随机小数据（本文对拍即用此法）。

常见的错误优化是"归并 $k$ 路"：由于数组含**负数**，$nums1[i]$ 越大乘积未必越大（乘上负数时反号），双数组乘积没有单调的归并序，堆做法需要小心处理方向且最坏仍是 $O(k \log n)$，$k$ 可达 $2.5 \times 10^9$，同样不可行。

正确方向是**值域二分**：不找"第 k 个乘积在哪个位置"，而是问"有多少个乘积 $\le x$"。

### 3.2 核心观察：计数函数单调，答案是最小可行值

![核心观察：count(x) 是不减阶梯函数，二分找最小可行值](images/bw63_q4_binary_search.svg)

定义计数函数

$$count(x) = \left|\{(i, j) : nums1[i] \times nums2[j] \le x\}\right|.$$

它是关于 $x$ **单调不减**的阶梯函数：$x$ 越大，满足条件的对数只增不减。而"第 $k$ 小乘积" $p_k$ 恰好是最小的使得 $count(x) \ge k$ 的 $x$——因为比 $p_k$ 小的值至多容纳 $k-1$ 个乘积，而 $count(p_k) \ge k$。

于是在值域 $[-10^{10}, 10^{10}]$ 上二分：每次用 $O(n_1 + n_2)$ 计算 $count(mid)$，共 $\log(2 \times 10^{10}) \approx 35$ 次。剩下的全部难点集中在：**如何快速计算 $count(x)$**。

### 3.3 计数 $count(x)$：按符号分四段 + 单调双指针

![四段符号分类：负负/正正产生正乘积，负正/正负产生负乘积，含零因子恒为 0](images/bw63_q4_sign_segments.svg)

把两个数组各拆成三部分：负数段 `neg`（升序，即绝对值**降序**）、零的个数 `z`、正数段 `pos`（升序）。乘积的符号由两因子符号决定，分五种情况：

1. **含零因子**（$a = 0$ 或 $b = 0$）：乘积恒为 $0$，当 $x \ge 0$ 时全部计入，共 $z_1 n_2 + z_2 n_1 - z_1 z_2$ 对（两个都为零的对被数了两次，减去 $z_1 z_2$）。
2. **正×正**（$> 0$）：$a b \le x$ 当且仅当 $b \le x / a$。固定 $x$ 后，$a$ 越小阈值越大。把 `pos1` **从大到小**扫，阈值单调升，`pos2` 上的合法集合是从头开始的**前缀**，前缀长度单调不减 → 双指针。
3. **负×负**（$> 0$）：即 $|a| |b| \le x$。`neg1` 升序意味着 $|a|$ **降序**，阈值 $x/|a|$ 单调升；`neg2` 升序意味着 $|b|$ **降序**，合法集合是**尾部**（小绝对值一端），且该尾段随阈值升而变长 → 双指针从末尾向前扩张。
4. **负×正**（$< 0$）：$a b \le x \iff |a| b \ge -x$（记 $need = -x$）。$|a|$ 降序扫 `neg1`，阈值 $need/|a|$ 单调**升**，`pos2` 上合法集合是 $b \ge need/|a|$ 的**后缀**，随阈值升而**收缩**；非法集合（前缀）单调扩张 → 双指针。
5. **正×负**（$< 0$）：$a b \le x \iff a |b| \ge need$。`pos1` 升序扫，阈值 $need/a$ 单调**降**，`neg2` 上合法集合是 $|b| \ge need/a$ 的**前缀**（大绝对值一端），随阈值降而扩张 → 双指针。

四种非零情形的双指针都是**单向移动**，每次计数总计 $O(n_1 + n_2)$。

### 3.4 示例演算（示例 3，$x = -6$）

`nums1 = [-2,-1,0,1,2]` → `neg1 = [-2,-1]`（$|a| = 2,1$），`pos1 = [1,2]`，$z_1 = 1$；`nums2 = [-3,-1,2,4,5]` → `neg2 = [-3,-1]`（$|b| = 3,1$），`pos2 = [2,4,5]`，$z_2 = 0$。

| 段 | 条件（$need = 6$） | 逐项计算 | 小计 |
|----|--------------------|----------|------|
| 含零 | $x = -6 < 0$ | 不计 | 0 |
| 负负 | $x < 0$ | 不计 | 0 |
| 正正 | $x < 0$ | 不计 | 0 |
| 负×正 | $\|a\| b \ge 6$ | $\|a\|=2$: $b \in \{4,5\}$；$\|a\|=1$: 无 | 2 |
| 正×负 | $a\|b\| \ge 6$ | $a=1$: 无；$a=2$: $\|b\| = 3$（$2 \times 3 = 6 \ge 6$） | 1 |

$count(-6) = 3 \ge k = 3$，而 $count(-7) = 2 < 3$（负×正只剩 $-2 \times 4, -2 \times 5$，正×负全灭），故第 3 小乘积为 $-6$，与官方答案一致。

## 4. 算法细节

1. **二分边界与不变量**：值域 $[-10^{10}, 10^{10}]$。取 $lo = -10^{10} - 1$（$count(lo) = 0 < k$ 恒成立，因最小乘积 $\ge -10^{10}$），$hi = 10^{10}$（$count(hi) = n_1 n_2 \ge k$）。循环保持不变量 $count(lo) < k \le count(hi)$，收敛后 $hi$ 即答案。
2. **开闭区间的写法**：`while (lo + 1 < hi)` 配 `mid = lo + (hi-lo)/2`，避免闭区间写法在 `count(mid) == k` 时的边界纠结——我们要的是**最小**满足值，不是任一满足值。
3. **双指针方向速记**：每次都是"让合法集合从数组的一端单调生长"。正正（前缀，`pos2` 头部）、负负（尾段，`neg2` 尾部）、负正（后缀收缩 = 非法前缀生长，`pos2` 头部）、正负（前缀生长，`neg2` 头部，因 `neg2` 头部是**大绝对值**）。四段指针均只前进不回退，复杂度 $O(n_1 + n_2)$。
4. **除法一律改乘法**：阈值判断写成 `pos2[j] * a <= x` 而非 `pos2[j] <= x / a`，避免整除截断与符号反转的坑（C++ 整数除法向零取整，负数时与数学下取整不一致）。
5. **溢出（C++ 关键）**：乘积可达 $\pm 10^{10}$、计数可达 $2.5 \times 10^9$，双双超过 `int`（约 $2.1 \times 10^9$）。计数函数返回 `long long`；分段数组直接存 `long long`，比较时先乘后比（乘积 $\le 10^{10}$ 在 `long long` 内安全）。Python 无此问题。
6. **$k$ 的类型**：$k \le 2.5 \times 10^9$ 也超 `int`，C++ 形参用 `long long`（metaData 即如此声明）。
7. **内层二分的替代写法**：不拆符号、对每个 `a` 在 `nums2` 上二分"满足 $ab \le x$ 的 $b$ 个数"也可，复杂度 $O(n_2 \log n_2 \cdot \log V)$，约 $5 \times 10^4 \times 17 \times 35 \approx 3 \times 10^7$，也能通过；分段双指针是它的常数与正确性双优化。

## 5. 正确性证明

**引理 1（计数函数刻画第 k 小）**：设 $p_k$ 为全体乘积（按重数）升序排列后的第 $k$ 个值，则 $count(x) \ge k \iff x \ge p_k$。特别地，$p_k$ 是最小的满足 $count(x) \ge k$ 的整数。

**证明**：$count(x) \ge k$ 表示至少有 $k$ 个乘积值 $\le x$，即升序序列的第 $k$ 个值 $p_k \le x$；反之若 $p_k \le x$，则前 $k$ 个乘积全部 $\le x$，$count(x) \ge k$。故 $count(x) \ge k \iff x \ge p_k$，最小满足整数即 $p_k$（$count$ 只在整数值处跳变）。∎

**引理 2（分段计数完备且不重）**：$count(x) = Z(x) + C_{PP}(x) + C_{NN}(x) + C_{NP}(x) + C_{PN}(x)$，其中各项依次统计"含零因子""正×正""负×负""负×正""正×负"中乘积 $\le x$ 的对数。

**证明**：任一下标对 $(i, j)$ 按 $nums1[i]$ 与 $nums2[j]$ 的符号（正、零、负）分类：两因子都非零时，符号组合恰为 $++, --, -+, +-$ 四种之一，落入且仅落入 $C_{PP}, C_{NN}, C_{NP}, C_{PN}$ 之一；至少一个因子为零时落入 $Z(x)$。五类两两不交且覆盖全部 $n_1 n_2$ 对。$Z(x) = \mathbf{1}[x \ge 0] (z_1 n_2 + z_2 n_1 - z_1 z_2)$ 由容斥（两个零因子之对被 $z_1 n_2$ 与 $z_2 n_1$ 各数一次）直接得出。∎

**引理 3（四段双指针的单调性）**：对固定的 $x$，四段各自的"合法集合"随外层遍历变量的推进沿数组一端单调生长，故双指针正确计数。

**证明**：以**负×正**段为例（其余同理）。记 $need = -x$，合法条件为 $|a| \, b \ge need$。外层按 `neg1` 升序遍历，$|a|$ 严格不增。设 $|a'| \le |a|$，则对任何 $b$：$b \ge need/|a'| \Rightarrow b \ge need/|a|$（因 $need > 0$ 时除以更小的数给出更大阈值；$need \le 0$ 时全体合法，平凡成立），即较小 $|a|$ 的合法集合是较大 $|a|$ 合法集合的子集。故"非法前缀"$\{b : b|a| < need\}$ 随遍历单调不减，指针 $j$ 只前进；每步计入的 $m - j$ 恰为当前合法 $b$ 的个数。**正×负**段对称：`pos1` 升序、$a$ 不减，$need/a$ 不增，合法前缀 $\{|b| \ge need/a\}$ 单调不减。**正×正**段：`pos1` 从大到小、$a$ 不增，$x/a$（$x > 0$）不减，前缀 $\{b \le x/a\}$ 单调不减。**负×负**段：$|a|$ 不增（`neg1` 升序），$x/|a|$ 不减，尾段 $\{|b| \le x/|a|\}$（`neg2` 尾部为小 $|b|$）单调不减。四段指针均单向移动且每步计入的数量恰为该 $a$ 下的合法对数，求和即各段总数。∎

**定理（算法正确）**：值域二分返回的 $hi$ 等于第 $k$ 小乘积 $p_k$。

**证明**：由引理 2、3，$count(mid)$ 被 $O(n_1 + n_2)$ 精确计算。二分初始化满足 $count(lo) < k \le count(hi)$（$lo = -10^{10} - 1$ 小于最小可能乘积，$count(lo) = 0 < k$；$hi = 10^{10}$ 不小于最大可能乘积，$count(hi) = n_1 n_2 \ge k$）。归纳保持该不变量：`count(mid) >= k` 时收缩上界至 `mid`，否则收缩下界至 `mid`，两者均维持不等式。循环终止于 $lo + 1 = hi$，此时 $count(hi) \ge k$ 且 $count(hi - 1) \le count(lo) < k$，即 $hi$ 是最小满足 $count \ge k$ 的整数。由引理 1，$hi = p_k$。∎

## 6. 复杂度分析

- **时间**：$O\big((n_1 + n_2) \log V\big)$，$V = 2 \times 10^{10} + 1$ 为值域宽度，二分约 35 轮，每轮四段双指针共 $O(n_1 + n_2)$。$n_1 = n_2 = 5 \times 10^4$ 时约 $3.5 \times 10^6$ 次基本操作，实测 C++ 0.05s、Python 0.31s。
- **空间**：$O(n_1 + n_2)$，四个符号分段数组的拷贝；若原地复用下标区间可降到 $O(1)$ 额外空间（实现更繁琐，本题不必）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long kthSmallestProduct(vector<int>& nums1, vector<int>& nums2, long long k) {
        for (int x : nums1) { if (x < 0) neg1.push_back(x); else if (x > 0) pos1.push_back(x); else ++z1; }
        for (int x : nums2) { if (x < 0) neg2.push_back(x); else if (x > 0) pos2.push_back(x); else ++z2; }
        n1 = (long long)nums1.size(); n2 = (long long)nums2.size();
        long long lo = -100000000000LL - 1, hi = 100000000000LL;   // 乘积值域 ±1e10
        while (lo + 1 < hi) {
            long long mid = lo + (hi - lo) / 2;
            if (countLE(mid) >= k) hi = mid; else lo = mid;
        }
        return hi;                                                  // 最小的满足 count>=k 的值
    }
private:
    vector<long long> neg1, pos1, neg2, pos2;
    long long z1 = 0, z2 = 0, n1 = 0, n2 = 0;

    long long countLE(long long x) {                 // 乘积 <= x 的下标对个数
        long long cnt = 0;
        if (x >= 0) cnt += z1 * n2 + z2 * n1 - z1 * z2;   // 含 0 因子的乘积全为 0
        cnt += countNN(x);                           // 负×负 > 0
        cnt += countPP(x);                           // 正×正 > 0
        cnt += countNP(x);                           // 负×正 < 0
        cnt += countPN(x);                           // 正×负 < 0
        return cnt;
    }
    long long countPP(long long x) {                 // a>0,b>0：a*b<=x
        if (x <= 0) return 0;
        long long cnt = 0; int j = 0, m = (int)pos2.size();
        for (int i = (int)pos1.size() - 1; i >= 0; --i) {   // a 从大到小，阈值 x/a 升
            while (j < m && pos2[j] * pos1[i] <= x) ++j;
            cnt += j;
        }
        return cnt;
    }
    long long countNN(long long x) {                 // a<0,b<0：|a|*|b|<=x
        if (x <= 0) return 0;
        long long cnt = 0; int m = (int)neg2.size(), j = m;
        for (long long a : neg1) {                   // a 升序 => |a| 降序，阈值升
            while (j > 0 && (-neg2[j - 1]) * (-a) <= x) --j;
            cnt += m - j;
        }
        return cnt;
    }
    long long countNP(long long x) {                 // a<0,b>0：|a|*b >= -x
        long long need = -x, cnt = 0; int j = 0, m = (int)pos2.size();
        for (long long a : neg1) {                   // a 升序 => |a| 降序，阈值升
            while (j < m && pos2[j] * (-a) < need) ++j;
            cnt += m - j;
        }
        return cnt;
    }
    long long countPN(long long x) {                 // a>0,b<0：a*|b| >= -x
        long long need = -x, cnt = 0; int j = 0, m = (int)neg2.size();
        for (long long a : pos1) {                   // a 升序，阈值 need/a 降
            while (j < m && a * (-neg2[j]) >= need) ++j;
            cnt += j;
        }
        return cnt;
    }
};
```

### Python

```python
class Solution:
    def kthSmallestProduct(self, nums1: List[int], nums2: List[int], k: int) -> int:
        neg1 = [x for x in nums1 if x < 0]
        pos1 = [x for x in nums1 if x > 0]
        z1 = nums1.count(0)
        neg2 = [x for x in nums2 if x < 0]
        pos2 = [x for x in nums2 if x > 0]
        z2 = nums2.count(0)
        n1, n2 = len(nums1), len(nums2)

        def count_pp(x):                       # a>0,b>0：a*b<=x
            if x <= 0:
                return 0
            cnt, j, m = 0, 0, len(pos2)
            for a in reversed(pos1):           # a 从大到小，阈值 x/a 升
                while j < m and pos2[j] * a <= x:
                    j += 1
                cnt += j
            return cnt

        def count_nn(x):                       # a<0,b<0：|a|*|b|<=x
            if x <= 0:
                return 0
            cnt, m, j = 0, len(neg2), len(neg2)
            for a in neg1:                     # a 升序 => |a| 降序，阈值升
                na = -a
                while j > 0 and -neg2[j - 1] * na <= x:
                    j -= 1
                cnt += m - j
            return cnt

        def count_np(x):                       # a<0,b>0：|a|*b >= -x
            need, cnt, j, m = -x, 0, 0, len(pos2)
            for a in neg1:                     # a 升序 => |a| 降序，阈值升
                na = -a
                while j < m and pos2[j] * na < need:
                    j += 1
                cnt += m - j
            return cnt

        def count_pn(x):                       # a>0,b<0：a*|b| >= -x
            need, cnt, j, m = -x, 0, 0, len(neg2)
            for a in pos1:                     # a 升序，阈值 need/a 降
                while j < m and a * -neg2[j] >= need:
                    j += 1
                cnt += j
            return cnt

        def count_le(x):
            cnt = z1 * n2 + z2 * n1 - z1 * z2 if x >= 0 else 0   # 含 0 因子的乘积为 0
            return cnt + count_nn(x) + count_pp(x) + count_np(x) + count_pn(x)

        lo, hi = -10**10 - 1, 10**10
        while lo + 1 < hi:
            mid = (lo + hi) // 2
            if count_le(mid) >= k:
                hi = mid
            else:
                lo = mid
        return hi
```

## 8. 边界情况与易错点

1. **`int` 溢出是本题第一大坑**：计数上界 $n_1 n_2 = 2.5 \times 10^9 > 2^{31} - 1$，乘积值域 $\pm 10^{10}$ 更是远超。C++ 中计数必须 `long long`，$k$ 形参也是 `long long`（接口如此），分段数组存 `long long` 最省心。
2. **正×负段的双指针方向**：合法集合是 `neg2` 的**头部**（大绝对值端）而非尾部，指针条件是 `a * |neg2[j]| >= need`（合法才前进）。本文初版曾把该段写成"非法才前进"，官方示例 3 立刻暴露错误——负数段的两个"反向段"（负×正、正×负）极易搞混，务必用小样例手验。
3. **阈值判断用乘法不用除法**：`b * a <= x` 而非 `b <= x / a`。C++ 负数整除向零截断，与数学下取整不同；乘法形式还顺带规避了阈值恰好落在整数边界时的 off-by-one。
4. **零因子的容斥**：$z_1 n_2 + z_2 n_1$ 把"零×零"数了两遍，必须减 $z_1 z_2$；且仅当 $x \ge 0$ 时才计入。
5. **$k = 1$ 与 $k = n_1 n_2$**：分别落在值域两端，二分边界 $lo = -10^{10} - 1$、$hi = 10^{10}$ 必须真的覆盖（最小乘积恰可为 $-10^{10}$，最大恰可为 $10^{10}$）。
6. **二分收敛条件**：`while (lo + 1 < hi)` 配"可行收缩上界"，最后返回 `hi`。若误用闭区间 `lo <= hi` 并在 `count(mid) == k` 时提前返回 `mid`，会返回一个"恰好有 k 个 ≤ mid"但非最小的中间值。
7. **一个数组全负 / 全正**：四段中某些段为空，双指针循环自然跳过，无需特判；但要保证空段返回 0 而不是误入循环（`m = 0` 时 while 条件直接为假）。
8. **乘积并列**：同一值可出现多次（如两个 $-8$），$count$ 按对数（重数）累计，公式天然正确；对拍暴力同样按重数排序即可对齐。

**延伸思考**：值域二分 + 计数是"第 k 小"问题的通用范式，关键永远在 $count(x)$ 的快速计算——本题把 $count$ 拆成符号四段后每段都是一次单调双指针。若把乘法换成别的二元运算 $f(a,b)$，只要 $count(x)$ 能 $O(n \log n)$ 内求出，框架照搬：如 $|a - b|$（LC 719）、$a / b$（需按分母正负分段）、$\max(a,b)$（排序后前缀计数）。进阶方向是 **Frank–Tardos / 对数凸性**：若 $count(x)$ 关于 $x$ 满足某种凸性，可用牛顿迭代代替二分；而"输出第 k 小的**对**而非值"则需要在一分中额外记录（二分定位值后，再按段枚举出恰好 k 个对）。
