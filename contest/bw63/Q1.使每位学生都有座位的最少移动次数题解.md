# LeetCode 使每位学生都有座位的最少移动次数 题解

## 1. 题目概述

- **标题 / 题号**：使每位学生都有座位的最少移动次数（#2037，easy）
- **链接**：https://leetcode.cn/problems/minimum-number-of-moves-to-seat-everyone/
- **来源**：LeetCode 第 63 场双周赛 Q1
- **难度**：简单
- **标签**：贪心、数组、排序、计数排序

**题意**：数轴上有 $n$ 个座位和 $n$ 名学生，`seats[i]` 是第 $i$ 个座位的位置，`students[j]` 是第 $j$ 位学生的位置。每次操作可以把某位学生向左或向右移动 $1$ 个单位。要求给每位学生分配一个**互不相同**的座位，使得所有学生移动总次数最少，返回这个最小值。初始时座位可以重合、学生也可以重合。

**约束**：

- $n = seats.length = students.length$，$1 \le n \le 100$
- $1 \le seats[i], students[j] \le 100$

> 💡 位置值域只有 $[1, 100]$，这提示除了比较排序，还可以用**计数排序**做到 $O(n + V)$，虽然本题 $n \le 100$ 两种做法没有实际差别。

## 2. 示例

**示例 1**

```text
输入：seats = [3,1,5], students = [2,7,4]
输出：4
解释：排序后 seats = [1,3,5]，students = [2,4,7]。
最矮位置的学生 2 → 座位 1（1 次），4 → 3（1 次），7 → 5（2 次），共 4 次。
```

**示例 2**

```text
输入：seats = [4,1,5,9], students = [1,3,2,6]
输出：7
解释：排序后 seats = [1,4,5,9]，students = [1,2,3,6]。
|1−1| + |2−4| + |3−5| + |6−9| = 0 + 2 + 2 + 3 = 7。
```

**示例 3（重合位置）**

```text
输入：seats = [2,2,6,6], students = [1,3,2,6]
输出：4
解释：排序后 seats = [2,2,6,6]，students = [1,2,3,6]。
|1−2| + |2−2| + |3−6| + |6−6| = 1 + 0 + 3 + 0 = 4。
座位与学生的初始重合不影响"排序后按序配对"的正确性。
```

## 3. 解题思路

### 3.1 暴力思路

枚举学生到座位的每一个**排列**（双射），共 $n!$ 种，每种计算 $\sum |student - seat|$ 取最小。$n \le 100$ 时 $100!$ 天文数字，显然不可行。反过来想：位置值域只有 $[1,100]$，也可以把问题建图跑最小费用最大流（学生 → 座位，容量 1，费用为距离），正确但严重杀鸡用牛刀。

其实有一个关键直觉：**位置小的学生应该去位置小的座位**。这能把 $n!$ 的搜索空间直接压缩成唯一一种配对——排序后按序配对。

### 3.2 核心观察：排序后按序配对（同序匹配）

![核心观察：排序后同序配对，交叉配对可通过交换变优](images/bw63_q1_sort_match.svg)

把两个数组分别升序排序后，让第 $i$ 小的学生坐第 $i$ 小的座位。直觉上这是"不交叉"的匹配：如果两名学生的移动路径在数轴上"交叉"（位置小的学生去了位置大的座位，位置大的学生反而去位置小的座位），那么两人交换座位目标后，总移动距离不会增加，通常还会减少。

这就是经典的**同序匹配（ordered matching）**结论：两组一维点做最小代价配对（代价为距离）时，按序配对最优。证明用**交换论证（exchange argument）**：任何存在"逆序对"的匹配都可以在不增加总代价的前提下消去逆序，而唯一无逆序的匹配就是按序配对（见 §5）。

### 3.3 算法流程

![算法流程：双数组排序 + 逐位差绝对值求和](images/bw63_q1_flow.svg)

```text
1. seats 升序排序
2. students 升序排序
3. ans = Σ |seats[i] − students[i]|  （i = 0..n−1）
4. 返回 ans
```

由于值域 $V \le 100$，步骤 1-2 也可用计数排序：对每个位置值统计出现次数，再按值从小到大依次配对，总复杂度 $O(n + V)$。

### 3.4 示例演算

以示例 2 为例（seats = [4,1,5,9]，students = [1,3,2,6]）：

| 配对（升序） | 学生位置 | 座位位置 | 移动次数 |
|--------------|----------|----------|----------|
| 第 1 小 | 1 | 1 | 0 |
| 第 2 小 | 2 | 4 | 2 |
| 第 3 小 | 3 | 5 | 2 |
| 第 4 小 | 6 | 9 | 3 |

总计 $0 + 2 + 2 + 3 = 7$，与官方答案一致。注意如果强行交叉配对（例如学生 1 → 座位 9），总代价必然更大。

## 4. 算法细节

1. **排序方向必须一致**：两个数组都升序（或都降序），不要一个升一个降。
2. **答案上界**：$n \le 100$、位置差 $\le 99$，总和 $\le 9900$，`int` 毫无溢出风险。
3. **计数排序写法**：值域 $[1,100]$，开长度 101 的桶，`cnt1[v]`、`cnt2[v]` 统计后双指针从 $v=1$ 扫到 $100$，每次各取一个配对。比较排序在本题规模下已足够快，计数排序是"更优复杂度"的展示。
4. **重合位置的处理**：排序天然处理了重合——座位 [2,2] 与学生 [1,3] 排序后按序配对为 |1−2| + |3−2| = 2，无需任何特判。
5. **为什么"互不相同的座位"不用额外约束**：座位本身就是 $n$ 个独立对象，按序配对天然把不同座位分给不同学生；学生初始重合也没有限制（他们可以走到同一个座位吗？不可以——但按序配对保证每人拿到不同的座位目标）。

## 5. 正确性证明

**引理 1（反序不等式 / 交叉代价不减）**：设 $a \le b$（两名学生的位置），$c \le d$（两个座位的位置），则

$$|a - c| + |b - d| \le |a - d| + |b - c|.$$

**证明**：按 $c, d$ 与区间 $[a, b]$ 的相对位置分情况验证。核心情形是"真交叉"：$a \le c \le d \le b$ 之外的所有情形，不等式两边至多差一个常数项，可逐一展开验证；真交叉时左边 $= (c - a) + (b - d)$，右边 $= (d - a) + (b - c)$，两者之和都含 $(b - a)$，但左边比右边少 $2(d - c) \ge 0$，故左边 $\le$ 右边。对其余情形（如 $c \le a \le b \le d$、$a \le b \le c \le d$ 等），两边相等或左边严格更小，展开绝对值即可逐一验证。∎

**定理（同序匹配最优）**：将 `seats` 与 `students` 分别升序排序后，按序配对 $\sum_i |seats_i - students_i|$ 是全体配对方案中的最小总代价。

**证明**：设某个最优配对 $\pi$ 中存在逆序对，即存在 $i < j$（$students_i \le students_j$）但 $\pi$ 把 $students_i$ 配到座位 $x$、$students_j$ 配到座位 $y$ 且 $x > y$。由引理 1（取 $a = students_i \le b = students_j$，$c = y \le d = x$）：

$$|students_i - y| + |students_j - x| \le |students_i - x| + |students_j - y|,$$

即交换这两名学生的座位目标后总代价不增。交换后逆序对个数严格减少（该对被消除，其余对的逆序关系不变或按定义可验证不增）。重复此交换至多 $\binom{n}{2}$ 次后得到无逆序的配对——无逆序的配对恰是"第 $i$ 小学生配第 $i$ 小座位"，即按序配对——且总代价始终不增，故按序配对的总代价不超过原最优解，即它也是最优解。∎

**推论**：算法返回值就是最少移动总次数。∎

## 6. 复杂度分析

- **时间**：比较排序版本 $O(n \log n)$，排序主导，逐位求和 $O(n)$；计数排序版本 $O(n + V)$，$V = 100$ 为值域上界。本题 $n \le 100$，两者都瞬间完成。
- **空间**：比较排序 $O(\log n)$（排序栈）或 $O(n)$（Python `sorted` 返回新数组）；计数排序 $O(V)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minMovesToSeat(vector<int>& seats, vector<int>& students) {
        sort(seats.begin(), seats.end());
        sort(students.begin(), students.end());
        int ans = 0;
        for (int i = 0; i < (int)seats.size(); ++i)
            ans += abs(seats[i] - students[i]);
        return ans;
    }
};
```

### Python

```python
class Solution:
    def minMovesToSeat(self, seats: List[int], students: List[int]) -> int:
        seats.sort()
        students.sort()
        return sum(abs(a - b) for a, b in zip(seats, students))
```

> 💡 两份代码均通过官方全部 3 组示例，并与"枚举全体排列取最小"的暴力实现做了 400 组随机对拍（含重合位置、$n = 1$ 等边界），结果完全一致。

## 8. 边界情况与易错点

1. **$n = 1$**：只有一个座位一名学生，答案就是 $|seats[0] - students[0]|$，排序后循环自然处理。
2. **座位重合 / 学生重合**：排序按序配对即可，无需去重或特判——座位是 $n$ 个独立个体，即使位置相同也各占一个名额。
3. **两个数组排序方向要一致**：一个升序一个降序会把最小配最大的位置，得到完全错误的答案（这也是初学者最容易犯的笔误）。
4. **不要被"互不相同的座位"带偏**：题目保证的是最终每人的座位不同，这由配对是双射自动保证，不需要额外去重逻辑或并查集。
5. **溢出**：总代价上界 $100 \times 99 = 9900$，任何整型都够用；若值域放大到 $10^9$、$n = 10^5$，需要 `long long`（总和可达 $10^{14}$）。
6. **混淆"移动学生"与"移动座位"**：只有学生能动，座位固定；代价只累加学生位置的变化。
