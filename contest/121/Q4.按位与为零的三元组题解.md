# LeetCode 按位与为零的三元组 题解

## 1. 题目概述

- **标题 / 题号**：按位与为零的三元组（#982，hard）
- **链接**：https://leetcode.cn/problems/triples-with-bitwise-and-equal-to-zero/
- **来源**：LeetCode 第 121 场周赛 Q4
- **难度**：困难
- **标签**：位运算、数组、哈希表

**题意**：给定整数数组 `nums`，统计满足下述条件的**有序**三元组 $(i, j, k)$ 的个数：

- $0 \le i, j, k < nums.length$（下标可以重复）；
- `nums[i] & nums[j] & nums[k] == 0`。

**约束**：

- $1 \le nums.length \le 1000$
- $0 \le nums[i] < 2^{16}$

> 💡 注意是**有序三元组**：$(0,1,2)$ 与 $(1,0,2)$ 算两个；下标相等也允许。所以 $[0,0,0]$ 的答案是 $3^3 = 27$。

## 2. 示例

**示例 1**

```text
输入：nums = [2,1,3]
输出：12
解释：共 27 个有序三元组，其中与值为 0 的 12 个，例如
      (0,0,1): 2 & 2 & 1 = 0，(1,2,0): 1 & 3 & 2 = 0。
```

**示例 2**

```text
输入：nums = [0,0,0]
输出：27
解释：任何组合的与值都是 0，共 3 × 3 × 3 = 27 个有序三元组。
```

**示例 3**

```text
输入：nums = [1,1]
输出：0
解释：1 & 1 & 1 = 1 ≠ 0；数组里只有 1，任何三元组（含重复下标）与值都是 1。
```

## 3. 解题思路

### 3.1 暴力思路

三重循环枚举 $(i,j,k)$：$O(n^3) = 10^9$，语言层面几乎不可能在限制内跑完。稍微优化成「先枚举 $i,j$ 算出 $m = nums[i]\&nums[j]$，再枚举 $k$ 判定 $m \& nums[k]$」：$O(n^3)$ 不变，但常数小很多——仍然是 $10^9$。

### 3.2 核心观察：把 $(i,j)$ 的与值按「值」聚合

![先聚合 (i,j) 的与值，再用子集和回答「谁和 m 与为 0」](images/wc121_q4_pair_and_map.svg)

关键在最后一步的判定：$m \& nums[k] == 0$ 等价于「$nums[k]$ 的二进制位图是 $m$ 的**补集**的子集」。也就是说，对固定的 $m$，满足条件的 $k$ 只取决于**值**，与下标无关。于是：

1. 用 $O(n^2)$ 枚举所有有序对 $(i,j)$，把 $m = nums[i]\&nums[j]$ 的出现次数记进桶 `pairCnt[m]`；
2. 对每个出现的 $m$，统计「有多少个数组元素是 $\sim m$ 的子集」，两者相乘再求和。

第 2 步如果对每个 $m$ 都扫一遍数组，复杂度是 $O(n^2 + n \cdot 2^{16})$，最坏 $6.5 \times 10^7$，C++ 能过但不够漂亮。注意到这是一类**子集计数**问题，可以用 **SOS DP（Sum Over Subsets）** 在 $O(16 \cdot 2^{16})$ 内一次算出所有 $v$ 的「子集元素个数」：

$$\text{sub}[v] = \#\{k : nums[k] \subseteq v\}$$

其中「$nums[k] \subseteq v$」指 $nums[k]$ 的每一个为 1 的位在 $v$ 中也必须为 1，即 $nums[k] \,\&\, \sim v = 0$。有了 `sub`，对任意 $m$，答案贡献就是

$$pairCnt[m] \times sub[\,(2^{16}-1) \oplus m\,]$$

因为 $(2^{16}-1) \oplus m$ 恰好是 $m$ 在 16 位内的补集。

### 3.3 算法流程

![SOS DP：逐位把「少一个 1」的子集累加进来](images/wc121_q4_sos_subset_dp.svg)

```text
1. freq[x] = x 在 nums 中出现的次数
2. sub = freq
   for b = 0 .. 15:                       # 逐位做子集和
       for mask = 0 .. 2^16-1:
           若 mask 的第 b 位为 1:
               sub[mask] += sub[mask ^ (1 << b)]
3. pairCnt[m] = #{(i,j) : nums[i] & nums[j] == m}      # O(n^2)
4. ans = Σ_m pairCnt[m] * sub[full ^ m]，full = 2^16 - 1
5. 返回 ans
```

SOS DP 的正确直觉：`sub[v]` 初始只含「恰好等于 $v$」的元素；第 $b$ 轮把「第 $b$ 位为 0 的版本」累加到「第 $b$ 位为 1 的版本」，每轮放宽一位，$16$ 轮后所有「$\subseteq v$」的元素都被累加进来。

### 3.4 示例演算

![演算：把 9 个有序对聚合成 4 个与值，再逐个查子集计数](images/wc121_q4_walkthrough.svg)

对示例 1 的 `nums = [2,1,3]`，先枚举 9 个有序对的与值：

| $(i,j)$ | 与值 | | $(i,j)$ | 与值 |
|---|---|---|---|---|
| (0,0) | 2 | | (1,2) | 1 |
| (0,1) | 0 | | (2,0) | 2 |
| (0,2) | 2 | | (2,1) | 1 |
| (1,0) | 0 | | (2,2) | 3 |
| (1,1) | 1 | | | |

得到 `pairCnt`：$0 \to 2$，$1 \to 3$，$2 \to 3$，$3 \to 1$。再算每个 $m$ 的补集子集计数 $sub[\overline{m}]$：

| $m$ | `pairCnt[m]` | 满足 `nums[k] & m == 0` 的元素 | $sub[\overline{m}]$ | 贡献 |
|---|---|---|---|---|
| 0 | 2 | 全部 {2,1,3} | 3 | 6 |
| 1 | 3 | {2} | 1 | 3 |
| 2 | 3 | {1} | 1 | 3 |
| 3 | 1 | 无 | 0 | 0 |

合计 $6 + 3 + 3 = 12$ ✓，与示例输出一致。

## 4. 算法细节

1. **位宽取 16**：$nums[i] < 2^{16}$，`full = (1 << 16) - 1`；若题目值域变成 $2^{20}$，只需把 `BITS` 改成 20（内存 $2^{20}$ 个 `int` ≈ 4MB，仍可接受）。
2. **`pairCnt` 用数组而非哈希表**：值域只有 $65536$，数组桶比 `unordered_map` 快且省内存。
3. **SOS 的循环顺序**：外层枚举位、内层枚举 mask，保证每个子集恰好被累加一次；反过来（先 mask 后位）会重复累加。
4. **`sub` 初值复制 `freq`**：`sub` 就是「恰好等于」的计数，加上子集和之后变成「子集」的计数。
5. **ans 用 `long long`**：最坏 $n^3 = 10^9$，`int` 能装但接近上限，用 `long long` 更安全（返回值仍是 `int`）。
6. **下标可重复**：$i=j=k$ 都合法，所以 `pairCnt` 枚举的是 $n^2$ 个**有序对**（不是组合），别写成 `j = i+1`。
7. **0 的特殊性**：$nums[i] = 0$ 时与值恒为 0，`pairCnt[0]` 会很大，公式自动处理，无需特判。

## 5. 正确性证明

**引理 1（按与值聚合）**：$\text{答案} = \sum_{m} pairCnt[m] \cdot C(m)$，其中 $C(m) = \#\{k : nums[k] \,\&\, m = 0\}$。

**证明**：每个有序三元组 $(i,j,k)$ 唯一对应「一对 $(i,j)$ 及其与值 $m = nums[i]\&nums[j]$」加一个 $k$，且 $(i,j)$ 与 $k$ 的选择互相独立。三元组合法 $\iff nums[k] \& m = 0$。按 $m$ 分组求和即得。∎

**引理 2（SOS DP 正确性）**：经过 16 轮上述迭代后，$sub[v] = \#\{k : nums[k] \subseteq v\}$。

**证明**：对轮数 $t$ 归纳。设 $sub_t[v]$ 表示「只允许 $v$ 与被累加元素在低 $t$ 位上不同」时的计数，即 $sub_t[v] = \#\{k : nums[k] \text{ 与 } v \text{ 在第 } t \text{ 位以上的所有位相同，且低位任意为 } v \text{ 的子集}\}$。初始 $t = 0$ 时 $sub_0[v] = freq[v]$（要求完全相同）。第 $t$ 轮把 $sub_{t-1}$ 中「第 $t$ 位为 0 的版本」加到「第 $t$ 位为 1 的版本」上：若 $v$ 的第 $t$ 位为 1，则子集可以选择第 $t$ 位为 0 或 1，两种都合法，正是所加的项；若为 0，则子集第 $t$ 位必须为 0，等价于原值，不需要加。归纳到 $t = 16$，得到所有子集。∎

**引理 3（补集对应）**：$nums[k] \,\&\, m = 0 \iff nums[k] \subseteq full \oplus m$（$full = 2^{16}-1$）。

**证明**：$nums[k] \& m = 0$ 表示对每一位 $b$，$nums[k]$ 与 $m$ 不同时为 1。由于 $nums[k] < 2^{16}$，其所有 1 位都在 16 位内，这等价于「$nums[k]$ 为 1 的位在 $m$ 中都是 0」，即这些位都在 $full \oplus m$ 中为 1，也就是 $nums[k] \subseteq full\oplus m$。∎

**定理**：算法返回有序三元组中与值为 0 的个数。

**证明**：由引理 1，答案等于按 $m$ 分组的贡献之和；由引理 2、3，`sub[full ^ m]` 恰为 $C(m)$；`pairCnt[m]` 由 $O(n^2)$ 枚举全部有序对得到，计数精确。故求和结果即所求。∎

## 6. 复杂度分析

- **时间**：$O(n^2 + 16 \cdot 2^{16})$。$n^2 = 10^6$ 次与运算与桶自增；SOS DP 约 $10^6$ 次加法；最后一遍 $2^{16}$ 次乘加。总计约 $2 \times 10^6$ 级别。
- **空间**：$O(2^{16})$，两个长度 $65536$ 的 `int` 数组（`freq`/`sub` 可复用、`pairCnt` 一个），约 512KB。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int countTriplets(vector<int>& nums) {
        const int BITS = 16;
        const int SIZE = 1 << BITS;          // 65536
        const int FULL = SIZE - 1;

        vector<int> freq(SIZE, 0);
        for (int x : nums) freq[x]++;

        // sub[v] = # { k : nums[k] 是 v 的子集 }，即 nums[k] & ~v == 0
        vector<int> sub = freq;
        for (int b = 0; b < BITS; b++) {
            int bit = 1 << b;
            for (int mask = 0; mask < SIZE; mask++) {
                if (mask & bit) sub[mask] += sub[mask ^ bit];
            }
        }

        // pairCnt[m] = # 有序对 (i, j) 使 nums[i] & nums[j] == m
        vector<int> pairCnt(SIZE, 0);
        int n = (int)nums.size();
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                pairCnt[nums[i] & nums[j]]++;
            }
        }

        long long ans = 0;
        for (int m = 0; m < SIZE; m++) {
            if (pairCnt[m]) ans += (long long)pairCnt[m] * sub[FULL ^ m];
        }
        return (int)ans;
    }
};
```

### Python

```python
class Solution:
    def countTriplets(self, nums: list[int]) -> int:
        BITS, SIZE = 16, 1 << 16
        FULL = SIZE - 1

        freq = [0] * SIZE
        for x in nums:
            freq[x] += 1

        # sub[v] = # { k : nums[k] 是 v 的子集 }
        sub = freq[:]
        for b in range(BITS):
            step = 1 << b
            for base in range(0, SIZE, step << 1):
                for v in range(base + step, base + (step << 1)):
                    sub[v] += sub[v - step]

        pair_cnt = [0] * SIZE
        for x in nums:
            for y in nums:
                pair_cnt[x & y] += 1

        ans = 0
        for m in range(SIZE):
            c = pair_cnt[m]
            if c:
                ans += c * sub[FULL ^ m]
        return ans
```

## 8. 边界情况与易错点

1. **有序 vs 无序**：题目要的是**有序**三元组，下标可重复；枚举对时用双层完整循环（含 $i=j$），不要写成 `j = i+1`。
2. **`full ^ m` 而不是 `~m`**：C++ 的 `~m` 是无限位补码，必须用 `FULL ^ m` 截断到 16 位；Python 的 `~m` 会变成负数。
3. **SOS 的循环方向**：外层必须是「位」，内层是 mask；顺序颠倒会重复累加子集。
4. **数组初始化**：`vector<int> sub = freq;` 要深拷贝，别写成引用。
5. **答案溢出**：$n^3 = 10^9$ 在 `int` 上限内，但 `pairCnt[m] * sub[...]` 的中间乘积可能到 $10^9$ 量级，用 `long long` 累加最稳。
6. **全 0 数组**：`freq[0] = n`，`sub[0] = n`（0 的子集只有 0），`FULL ^ 0 = FULL` 的 `sub` 是 $n$，贡献 $n^2 \cdot n = n^3$ ✓（$n = 3$ 时 27）。
7. **值恰好为 $2^{16}-1$**：合法（$< 2^{16}$），`FULL ^ m = 0`，只有 $nums[k] = 0$ 才满足，逻辑正确。
8. **时间常数**：Python 里 $n^2$ 的双层循环是 $10^6$ 次，SOS 也是 $10^6$ 次，注意用局部变量缓存、避免函数调用开销。
