# LeetCode 基于时间的键值存储 题解

## 1. 题目概述

- **标题 / 题号**：基于时间的键值存储（#981，medium）
- **链接**：https://leetcode.cn/problems/time-based-key-value-store/
- **来源**：LeetCode 第 121 场周赛 Q2
- **难度**：中等
- **标签**：设计、哈希表、字符串、二分查找

**题意**：设计数据结构 `TimeMap`，同一个键可以在**不同时间戳**上存多个值：

- `TimeMap()`：初始化；
- `void set(String key, String value, int timestamp)`：在时间戳 `timestamp` 存储 `key → value`；
- `String get(String key, int timestamp)`：返回值，该值来自**此前**某次 `set`，且那次 `set` 的时间戳 `timestamp_prev <= timestamp`；若有多个满足，取 `timestamp_prev` **最大**的那次；若不存在，返回 `""`。

**约束**：

- $1 \le key.length, value.length \le 100$；键值由小写字母与数字组成
- $1 \le timestamp \le 10^7$
- **`set` 的时间戳严格递增**
- `set` 与 `get` 总调用次数 $\le 2 \times 10^5$

> 💡 「`set` 时间戳严格递增」是关键约束：同一个键的历史记录天然按时间有序，可以直接二分。

## 2. 示例

**示例 1**

```text
输入：
["TimeMap", "set", "get", "get", "set", "get", "get"]
[[], ["foo","bar",1], ["foo",1], ["foo",3], ["foo","bar2",4], ["foo",4], ["foo",5]]

输出：[null, null, "bar", "bar", null, "bar2", "bar2"]

解释：
  set("foo","bar",1)   → 存下 (1, "bar")
  get("foo",1)         → 时间戳 1 有值 → "bar"
  get("foo",3)         → 1 是 ≤3 的最大时间戳 → "bar"
  set("foo","bar2",4)  → 追加 (4, "bar2")
  get("foo",4)         → "bar2"
  get("foo",5)         → 4 是 ≤5 的最大时间戳 → "bar2"
```

**示例 2**

```text
输入：
["TimeMap", "set", "set", "get", "get", "get"]
[[], ["k","v1",5], ["k","v2",10], ["k",4], ["k",5], ["k",7]]

输出：[null, null, null, "", "v1", "v1"]

解释：get("k",4) 时还没有任何 ≤4 的记录 → 空串；
      5 与 7 都命中时间戳 5 的 "v1"。
```

## 3. 解题思路

### 3.1 暴力思路

最简单的实现是一个全局列表，`get` 时**倒序**扫描所有 `set` 记录，找到第一个「键匹配且时间戳 ≤ 给定值」的记录。单次 `get` 是 $O(total)$，总调用 $2 \times 10^5$ 次时最坏 $4 \times 10^{10}$，超时。即便按「键」分组，单键的历史也可能很长。

### 3.2 核心观察：按 key 分桶 + 桶内时间戳天然有序

![按 key 分组，每个桶里是按时间戳递增的 (timestamp, value) 列表](images/wc121_q2_timemap_struct.svg)

由于 `set` 的 `timestamp` **严格递增**，对同一个 `key` 追加记录时，桶内自然保持**时间戳升序**，不需要任何排序。于是 `get(key, t)` 变成：

> 在 `data[key]` 中找**最后一个**时间戳 $\le t$ 的元素，返回它的 value；找不到则返回空串。

这就是「有序数组中找右边界」的标准二分，单次 $O(\log m)$（$m$ 为该键的记录数）。

### 3.3 算法流程

![二分找最后一个 ≤ timestamp 的位置](images/wc121_q2_binary_search.svg)

```text
set(key, value, timestamp):
    data[key].append((timestamp, value))       # 追加即有序

get(key, timestamp):
    若 data 中没有 key: return ""
    arr = data[key]
    lo = 0, hi = len(arr) - 1, pos = -1
    while lo <= hi:
        mid = (lo + hi) // 2
        若 arr[mid].timestamp <= timestamp: pos = mid；lo = mid + 1    # 记下候选，继续往右
        否则: hi = mid - 1
    return pos == -1 ? "" : arr[pos].value
```

### 3.4 示例演算

对示例 1 的 `"foo"` 桶：$[(1,"bar"), (4,"bar2")]$。

| 查询 | `timestamp` | 二分过程 | 结果 |
|---|---|---|---|
| get("foo",1) | 1 | `arr[0].t=1 ≤ 1` → pos=0，右侧无更小 | `"bar"` |
| get("foo",3) | 3 | `arr[0].t=1 ≤ 3` → pos=0；`arr[1].t=4 > 3` | `"bar"` |
| get("foo",4) | 4 | `arr[1].t=4 ≤ 4` → pos=1 | `"bar2"` |
| get("foo",5) | 5 | 同上，pos=1 | `"bar2"` |

## 4. 算法细节

1. **追加即有序**：不要用 `map<int,string>` 之类的排序结构，`vector<pair<int,string>>` 顺序追加即可，靠题目保证的时间戳递增性。
2. **`pos = -1` 哨兵**：区分「没找到」与「找到下标 0」，避免把「时间戳 0」误当空串（虽然时间戳 $\ge 1$，但语义上要严谨）。
3. **二分边界**：用「记录最后一个 ≤ 目标的位置」这种写法，比 `upper_bound` 再回退一格更不容易写错。
4. **哈希表选型**：`unordered_map<string, vector<pair<int,string>>>`，键的哈希只在 `get/set` 入口算一次。
5. **Python 可用 `bisect`**：`bisect_right(ts_list, t) - 1` 一行即可，但因为要同步维护时间戳列表，手写二分反而更直接。
6. **空桶与缺失键**：`get` 未出现过的键直接返回 `""`，不要先 `data[key]`（C++ 会插入空桶，Python 用 `setdefault` 会污染）。

## 5. 正确性证明

**引理 1（桶内有序）**：对任意键 $k$，`data[k]` 中的记录按时间戳严格递增。

**证明**：每次 `set` 只向末尾追加，而题目保证所有 `set` 的 `timestamp` 严格递增，故后追加的记录时间戳必然大于此前所有记录。∎

**引理 2（二分的返回值正确）**：在有序数组 `arr` 上执行上述二分后，若存在 $arr[i].t \le T$，则 `pos` 等于满足该条件的**最大**下标。

**证明**：二分维持「答案在 `[lo, hi]` 内」的不变式：当 `arr[mid].t ≤ T` 时，`mid` 是候选，且所有 $\le mid$ 的下标都不可能比它更大，故令 `pos = mid`、`lo = mid + 1`；当 `arr[mid].t > T` 时，由有序性，$\ge mid$ 的下标都不满足，令 `hi = mid - 1`。循环结束时 `pos` 是最后被确认满足条件的下标，由有序性它即最大满足下标。∎

**定理**：`get(key, T)` 返回题目要求的字符串。

**证明**：由引理 1，桶内有序；由引理 2，`pos` 是时间戳 $\le T$ 的最大下标。若 `pos = -1`，说明没有满足 `timestamp_prev ≤ T` 的记录，返回 `""` 正确；否则 `arr[pos].value` 正是「时间戳 $\le T$ 且最大」的那次 `set` 所存的值，即题目要求的返回值。∎

## 6. 复杂度分析

- **时间**：`set` 为 $O(1)$（哈希 + 尾插）；`get` 为 $O(\log m)$，$m$ 为该键的历史记录数。总调用 $2 \times 10^5$ 时，最坏约 $2 \times 10^5 \times 17$ 次比较，非常轻松。
- **空间**：$O(N)$，$N$ 为 `set` 总次数，每条记录占一个 `(timestamp, value)`。

## 7. 参考代码

### C++

```cpp
class TimeMap {
public:
    TimeMap() {}

    void set(string key, string value, int timestamp) {
        // 题目保证 timestamp 严格递增，直接尾插即有序
        data[key].push_back({timestamp, value});
    }

    string get(string key, int timestamp) {
        auto it = data.find(key);
        if (it == data.end()) return "";
        const vector<pair<int, string>>& arr = it->second;
        int lo = 0, hi = (int)arr.size() - 1, pos = -1;
        while (lo <= hi) {
            int mid = lo + (hi - lo) / 2;
            if (arr[mid].first <= timestamp) {
                pos = mid;          // 候选，继续往右找更大的时间戳
                lo = mid + 1;
            } else {
                hi = mid - 1;
            }
        }
        return pos == -1 ? "" : arr[pos].second;
    }

private:
    unordered_map<string, vector<pair<int, string>>> data;
};
```

### Python

```python
class TimeMap:
    def __init__(self):
        self.data = {}

    def set(self, key: str, value: str, timestamp: int) -> None:
        # 题目保证 timestamp 严格递增，直接尾插即有序
        self.data.setdefault(key, []).append((timestamp, value))

    def get(self, key: str, timestamp: int) -> str:
        arr = self.data.get(key)
        if not arr:
            return ""
        lo, hi, pos = 0, len(arr) - 1, -1
        while lo <= hi:
            mid = (lo + hi) // 2
            if arr[mid][0] <= timestamp:
                pos = mid           # 候选，继续往右
                lo = mid + 1
            else:
                hi = mid - 1
        return "" if pos == -1 else arr[pos][1]
```

## 8. 边界情况与易错点

1. **查询不存在的键**：必须返回 `""`，不能因为「桶为空」而访问 `arr[0]`。
2. **时间戳全部大于查询值**：`pos` 保持 $-1$，返回 `""`（示例 2 的 `get("k",4)`）。
3. **重复键不同时间戳**：桶内追加，靠二分取「最后一个 ≤ T」，不会取到更晚的记录。
4. **`set` 时间戳递增是前提**：若题面允许乱序时间戳，就必须插入排序或改用有序容器；本题不用。
5. **`get` 不改状态**：不要在 `get` 里 `data[key]` 隐式创建桶（C++ 会插入空 vector，浪费内存但不影响正确性；Python 用 `setdefault` 同理）。
6. **二分死循环**：`mid = lo + (hi - lo) / 2` 与 `lo = mid + 1` 配套使用；写成 `lo = mid` 会在两个元素时死循环。
7. **返回引用 vs 拷贝**：C++ 里 `const vector<...>& arr = it->second` 避免拷贝整个桶。
8. **字符串空值**：`value` 不会是空串（题目保证长度 ≥ 1），所以「空串」可以安全地用来说明「没有记录」。
