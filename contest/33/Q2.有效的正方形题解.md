# LeetCode 有效的正方形 题解

## 1. 题目概述

- **标题 / 题号**：有效的正方形（#593，medium）
- **链接**：https://leetcode.cn/problems/valid-square/
- **来源**：LeetCode 第 33 场周赛 Q2
- **难度**：中等
- **标签**：几何、数学

**题意**：平面上给出四个点的坐标 $p_1,p_2,p_3,p_4$，判断它们能否围成一个正方形。四个点**无序**给出，谁是相邻顶点、谁是对角顶点都不知道；正方形的定义是四条边等长且四个内角都是 $90^\circ$。

**约束**：

- `p1.length == p2.length == p3.length == p4.length == 2`
- $-10^4 \le x_i, y_i \le 10^4$
- 输入没有顺序；点之间**不保证互不相同**

> 💡 本题唯一的难点就是「无序」：任何默认 $p_1 \to p_2 \to p_3 \to p_4$ 依次相邻的写法，连示例 1 都过不了。

## 2. 示例

**示例 1**

```text
输入：p1 = [0,0], p2 = [1,1], p3 = [1,0], p4 = [0,1]
输出：true
解释：四个点恰好是单位正方形的四个顶点，只是输入顺序被打乱了：
      按 (0,0) → (1,0) → (1,1) → (0,1) 排列即可看出是正方形。
```

**示例 2**

```text
输入：p1 = [0,0], p2 = [1,1], p3 = [1,0], p4 = [0,12]
输出：false
解释：把最后一个点从 (0,1) 拉到 (0,12)，距离谱被彻底破坏，无法围成正方形。
```

**示例 3**

```text
输入：p1 = [1,0], p2 = [-1,0], p3 = [0,1], p4 = [0,-1]
输出：true
解释：这是一个绕原点旋转了 45° 的正方形，对角线正好与坐标轴重合，
      所以「边必须平行于坐标轴」之类的额外假设是错的。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的想法是枚举「谁挨着谁」：把四个点当成一个循环 $A \to B \to C \to D \to A$，验证

$$|AB| = |BC| = |CD| = |DA| > 0,\qquad |AC| = |BD| = \sqrt{2}\,|AB|$$

由于输入无序，$A,B,C,D$ 的对应关系本身是未知的，必须枚举 $4! = 24$ 种排列才能覆盖。这个做法**是对的**，复杂度也只是常数级的 $O(4! \times 6)$，但它有三个毛病：

- 把「顺序」这个题面里根本不存在的自由度显式展开，代码量翻几倍；
- 分支多，退化情形（点重合、三点共线、四点共线）容易漏判；
- 需要开方或比较 $\sqrt{2}$ 倍关系，浮点判等要自己定 `eps`，边界数据上有翻车风险。

### 3.2 核心观察：只看「距离谱」

![距离谱：6 个两两平方距离的多重集](images/wc33_q2_distance_spectrum_concept.svg)

真正的关键是换一个和顺序无关的量：**四点之间全部 $\binom{4}{2}=6$ 个两两距离**。

若 $ABCD$ 是边长为 $a$ 的正方形，用勾股定理，6 个**平方距离**恰好是：

- 4 条边：各 $a^2$；
- 2 条对角线：各 $a^2 + a^2 = 2a^2$。

于是把这 6 个数升序排好，得到的多重集恒为

$$\{\,a^2,\ a^2,\ a^2,\ a^2,\ 2a^2,\ 2a^2\,\}$$

而「排序后的多重集」与点被标成 $p_1,\dots,p_4$ 的哪一份完全无关——顺序问题自动消失。

反过来也成立，而且这一步**并不显然**：只要排序后形如 $[s,s,s,s,2s,2s]$ 且 $s>0$，四个点就一定是正方形（证明见第 5 节引理 2，那里要单独排除「两条长线段共享端点」的假配置）。所以判据就是三条：

1. $s > 0$（四点互不相同）；
2. 前 4 小全相等（四条边等长）；
3. 后 2 大相等，且等于 $2s$（两条对角线等长、且是对角线该有的长度）。

> 💡 全程用**平方距离**：坐标是整数，平方距离也是整数，$O(1)$ 精确比较，既不用 `sqrt`，也不用关心 $\sqrt{2}$ 这种无理数怎么表示。

### 3.3 算法流程

![算法流程：算 6 个平方距离 → 排序 → 三重条件](images/wc33_q2_algorithm_flow.svg)

1. 用两层循环枚举 $i<j$ 的 6 个点对，计算 $d = (x_i-x_j)^2 + (y_i-y_j)^2$，放进长度 6 的数组；
2. 升序排序；
3. 判定：`d[0] > 0`、`d[0]==d[1]==d[2]==d[3]`、`d[4]==d[5] && d[4]==2*d[0]`。

三个条件同时成立返回 `true`，否则返回 `false`。排序之后位置本身就说明了身份：前 4 个是边，后 2 个是对角线，不需要再猜。

### 3.4 示例演算

![三组官方示例的距离谱走查](images/wc33_q2_walkthrough.svg)

| 示例 | 6 个平方距离 | 升序后 | 判定过程 |
|------|--------------|--------|----------|
| 1 | $2,1,1,1,2,1$ | $[1,1,1,1,2,2]$ | $s=1>0$，前四相等，$2s=2=d_4=d_5$ ⇒ `true` |
| 2 | $2,1,144,1,122,145$ | $[1,1,2,122,144,145]$ | $d_2=2 \ne d_1=1$，第二条就失败 ⇒ `false` |
| 3 | $4,2,2,2,2,2$ | $[2,2,2,2,4,4]$ | $s=2>0$，前四相等，$2s=4=d_4=d_5$ ⇒ `true` |

示例 2 的谱里出现了 5 个不同的值，一眼就能看出不可能只由两种长度（边、对角线）组成；示例 3 的谱与示例 1 形状完全相同，只是整体放大 $\sqrt2$ 倍再旋转，说明距离谱天然对旋转、平移、缩放免疫。

> ⚠️ 一个必须记住的反例：四点全部重合，即 $p_1=p_2=p_3=p_4=(0,0)$，6 个距离全是 $0$，此时「前四相等」「$d_4=d_5=2d_0$」两条都成立，只有 `d[0] > 0` 能拦住它。

## 4. 算法细节

1. **只算 $i<j$ 的 6 对**：矩阵只取上三角，$4\times3/2=6$ 次计算；写成 6 条手写语句时最容易把 `p3`、`p4` 写串，用两层 `for` 生成更稳。
2. **用平方距离，绝不开方**：边长比较等价于平方比较（距离非负），而平方距离是整数，比较是精确的。一旦引入 `sqrt`，就得自己挑 `eps` 并处理「差一点点」的边界，判等逻辑立刻变脆。
3. **整数范围**：$|\Delta x|,|\Delta y| \le 2\times10^4$，故单个平方距离 $\le 2 \times (2\times10^4)^2 = 8\times10^8$，`int` 存得下；但 $2s$ 可达 $1.6\times10^9$，已逼近 `INT_MAX`（约 $2.15\times10^9$），所以统一用 `long long` 更稳妥。
4. **排序后按位置解读**：排序把「谁是边、谁是对角线」这件麻烦事变成了下标 $0\sim3$ 与 $4\sim5$ 的划分，这是本解最省事的地方。
5. **`d[0] > 0` 不能省**：题面没有保证四点互异，重合点会让判据在 $s=0$ 时退化成恒真。
6. **对角线条件写全**：`d[4]==d[5] && d[4]==2*d[0]`。在「前四相等且 $d_4=2d_0$」的前提下，$d_5>d_4$ 的点集实际上凑不出来（距离谱的可行域约束），所以 `d[4]==d[5]` 是冗余的；但把它写上，判据才对称、自解释，代价为零。
7. **不要试图先找「相邻点」**：例如「取距离 $p_1$ 最近的点当邻居」看似聪明，一旦出现重合点或等距点就要写一堆特判，反而比距离谱复杂。

## 5. 正确性证明

**引理 1（必要性）**：若四点构成边长为 $a$ 的正方形，则 6 个平方距离升序后为 $[a^2,a^2,a^2,a^2,2a^2,2a^2]$，且 $a>0$。

**证明**：正方形四边等长，故 4 条边的平方距离都是 $a^2$；两条对角线在直角三角形中用勾股定理得 $a^2+a^2=2a^2$ 且对角线长 $a\sqrt2 >0$，故 $a>0$。四点共 6 对，正好是 4 条边加 2 条对角线。∎

**引理 2（充分性）**：若 6 个平方距离升序后满足 $d_0=d_1=d_2=d_3=s>0$、$d_4=d_5=2s$，则四点构成正方形。

![充分性证明：两条长线段不可能共享端点](images/wc33_q2_long_edge_lemma.svg)

**证明**：记边长为 $t=\sqrt{s}$。由 $s>0$ 知任意两点的平方距离都 $\ge s>0$，故**四点两两不同**。

把平方距离为 $2s$ 的两条线段称为**长线段**，它们长为 $\sqrt{2s}=\sqrt2\,t$，其余 4 条短线段长为 $t$。两条长线段要么共享端点，要么不共享，分两种情形。

**(i) 两条长线段不共享端点。** 设长线段为 $AC$、$BD$，则剩下的 $AB,BC,CD,DA$ 正好是全部 4 条短线段，长度都是 $t$。又

$$|AB|^2+|BC|^2 = s+s = 2s = |AC|^2$$

由勾股定理的逆定理，$\angle ABC = 90^\circ$；同理 $\angle BCD=\angle CDA=\angle DAB=90^\circ$。四边等长且四个内角皆为直角的四边形就是正方形，结论成立。

**(ii) 两条长线段共享端点。** 反设长线段为 $AC$、$AD$，则 $AB,BC,CD,DB$ 都是短线段，长 $t$。于是 $BC=BD=CD=t$，$\triangle BCD$ 是正三角形；而 $AB=t$，$AC=AD=\sqrt2\,t$，由

$$|AB|^2+|BC|^2 = 2s = |AC|^2,\qquad |AB|^2+|BD|^2 = 2s = |AD|^2$$

得 $\angle ABC=\angle ABD=90^\circ$。过 $B$ 作 $AB$ 的垂线只有唯一一条，故 $C$、$D$ 都落在这条垂线上，即 $C,B,D$ 共线。$C,D$ 到 $B$ 的距离都是 $t$，所以 $|CD|$ 只能是 $0$ 或 $2t$——但正三角形 $BCD$ 要求 $|CD|=t$，矛盾。故情形 (ii) 不可能出现。∎

**定理**：`validSquare` 返回 `true` 当且仅当四个点构成正方形。

**证明**：

- （$\Leftarrow$）若构成正方形，由引理 1 距离谱为 $[a^2,a^2,a^2,a^2,2a^2,2a^2]$ 且 $a>0$，三条判定条件全部成立，返回 `true`。
- （$\Rightarrow$）若返回 `true`，则三条判定条件同时成立：$d_0=s>0$ 排除了重合点，其余两条正是引理 2 的前提，由引理 2 四点构成正方形。∎

## 6. 复杂度分析

- **时间**：$O(1)$。固定 4 个点，距离计算恰好 $\binom{4}{2}=6$ 次，排序 6 个元素也是常数（可写 $O(4^2 + 6\log 6)$），与坐标大小、输入规模无关。
- **空间**：$O(1)$。只用一个长度为 6 的数组，无哈希表、无递归。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    bool validSquare(vector<int>& p1, vector<int>& p2, vector<int>& p3, vector<int>& p4) {
        vector<vector<int>> p = {p1, p2, p3, p4};
        vector<long long> d;
        d.reserve(6);
        for (int i = 0; i < 4; i++) {
            for (int j = i + 1; j < 4; j++) {
                long long dx = (long long)p[i][0] - p[j][0];
                long long dy = (long long)p[i][1] - p[j][1];
                d.push_back(dx * dx + dy * dy);
            }
        }
        sort(d.begin(), d.end());
        // d[0..3] 是四条边，d[4..5] 是两条对角线
        return d[0] > 0
            && d[0] == d[1] && d[1] == d[2] && d[2] == d[3]
            && d[4] == d[5] && d[4] == 2 * d[0];
    }
};
```

### Python

```python
from itertools import combinations


class Solution:
    def validSquare(self, p1, p2, p3, p4) -> bool:
        pts = [p1, p2, p3, p4]
        d = []
        for i, j in combinations(range(4), 2):
            dx = pts[i][0] - pts[j][0]
            dy = pts[i][1] - pts[j][1]
            d.append(dx * dx + dy * dy)
        d.sort()
        # d[0..3] 四条边，d[4..5] 两条对角线
        return (d[0] > 0
                and d[0] == d[1] == d[2] == d[3]
                and d[4] == d[5] == 2 * d[0])
```

## 8. 边界情况与易错点

1. **四点重合**：`[0,0],[0,0],[0,0],[0,0]` 的距离谱是 6 个 $0$，若漏掉 `d[0] > 0` 会误判为 `true`。这就是判据第一条不能省的原因。
2. **输入顺序被打乱**：示例 1 的顺序 $(0,0),(1,1),(1,0),(0,1)$，按输入顺序连边得到 $\sqrt2,1,\sqrt2,1$，四条边并不等长——所有「按顺序连边」的写法都会在这里挂掉。
3. **旋转 45° 的正方形**：如 $(1,0),(-1,0),(0,1),(0,-1)$，边不平行于坐标轴。距离谱判断天然正确；若额外假设「边与坐标轴平行」，就会漏解。
4. **矩形不是正方形**：$[0,0],[2,0],[2,1],[0,1]$ 的谱是 $[1,1,4,4,5,5]$，两短两中两长，「前 4 小相等」立刻失败。**只比较「两对相等」是判矩形的判据，不是判正方形的判据。**
5. **菱形不是正方形**：$(0,0),(3,4),(0,8),(-3,4)$ 的谱是 $[25,25,25,25,36,64]$，四条边全部等长，但 $d_4=36 \ne 2\cdot 25=50$，对角线长度不对，返回 `false`。
6. **浮点误差**：坐标到 $10^4$ 时平方距离最大 $8\times10^8$，开方后的量级约 $2.8\times10^4$，双精度舍入误差虽小（$10^{-11}$ 级），但**判等**必须自己给 `eps`，且要额外论证 `eps` 的选取不会把非正方形放过。平方距离是纯整数运算，这类讨论全部消失。
7. **整数溢出**：单条平方距离最大 $8\times10^8$，`int` 够；但 $2s$ 可达 $1.6\times10^9$，且 `dx*dx` 在更大坐标下会先溢出。统一 `long long`（Python 无此问题）。

**延伸思考**：

1. **判矩形**：距离谱同样好用——矩形需满足 $d_0=d_1,\ d_2=d_3,\ d_4=d_5$ 且 $d_4=d_0+d_2$（对角线平方 = 两邻边平方和）。把它和本题的判据并排放，能看清「距离谱 + 勾股关系」这套模板的普适性。
2. **判菱形**：四边等长就够了（$d_0=d_1=d_2=d_3>0$），本题的距离谱条件在菱形上恰好只因 $d_4 \ne 2d_0$ 而失败（见易错点 5 的反例），可见「边长条件」与「对角线条件」是两件必须分别检查的事。
3. **从 4 个点扩展到 $n$ 个点**：给定 $n$ 个点，问能否选出 4 个构成正方形。此时枚举「对角线」更划算：任意两点 $A,C$ 作为对角线，正方形另外两个顶点只有两种取法
   $$B=\Bigl(\tfrac{x_A+x_C \mp (y_C-y_A)}{2},\ \tfrac{y_A+y_C \pm (x_C-x_A)}{2}\Bigr),$$
   用哈希集合 $O(1)$ 查这两点是否存在，总体 $O(n^2)$。这也解释了为什么「枚举对角线」是计数类正方形题的标准套路。
4. **距离谱的边界**：距离谱只刻画「全等类」里很强的信息，但它不是万能的——例如判断两个点集是否全等，$n$ 大时距离谱相同未必全等。对 $n=4$ 这样的小规模，距离谱加勾股关系刚好够用，这也是本题能 $O(1)$ 解决的原因。
