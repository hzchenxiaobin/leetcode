# LeetCode 最长和谐子序列 题解

## 1. 题目概述

- **标题 / 题号**：最长和谐子序列（#594，easy）
- **链接**：https://leetcode.cn/problems/longest-harmonious-subsequence/
- **来源**：LeetCode 第 33 场周赛 Q1
- **难度**：简单
- **标签**：数组、哈希表、计数、排序、滑动窗口

**题意**：若一个数组的**最大值与最小值之差恰好为 1**，则称它为**和谐数组**。给定整数数组 `nums`，在所有子序列中找出最长的和谐子序列，返回其长度；不存在则返回 `0`。子序列可以由原数组删去若干元素得到，**保持相对顺序但不要求连续**。

**约束**：

- $1 \le \lvert nums \rvert \le 2 \times 10^4$
- $-10^9 \le nums[i] \le 10^9$

> 💡 关键信号：元素都是**整数**，而「差恰好 1」意味着和谐子序列里的值只可能是某两个**相邻整数** $x$ 与 $x+1$。子序列不要求连续，于是「选哪些元素」这件事与顺序无关，只需要**按值计数**。

## 2. 示例

**示例 1**

```text
输入：nums = [1,3,2,2,5,2,3,7]
输出：5
解释：最长和谐子序列是 [3,2,2,2,3]，最大值 3、最小值 2，差为 1。
```

**示例 2**

```text
输入：nums = [1,2,3,4]
输出：2
解释：最长和谐子序列为 [1,2]、[2,3]、[3,4]，长度都是 2。
```

**示例 3**

```text
输入：nums = [1,1,1,1]
输出：0
解释：所有值相同，最大值与最小值之差为 0，不存在和谐子序列。
```

## 3. 解题思路

### 3.1 暴力思路

最朴素的做法是枚举所有 $2^n$ 个子序列，逐个求最大值、最小值并判断差是否为 1，复杂度 $O(2^n \cdot n)$。$n$ 最大 $2 \times 10^4$，完全不可行。

退一步：枚举「最小值为 $x$」的候选（$x$ 取遍数组中的值），再扫一遍数组收集所有等于 $x$ 或 $x+1$ 的元素——这仍是 $O(n^2)$（最坏有 $n$ 个不同值），$4 \times 10^8$ 次操作在 Python 下必然超时。瓶颈在于**对每个 $x$ 都重新扫描数组**。

### 3.2 核心观察：答案 = 某对相邻值的出现次数之和

![和谐子序列只含两个相邻值，长度等于两者计数之和](images/wc33_q1_pair_concept.svg)

把「选元素」换成「选值对」，可以立刻得到三条结论：

1. **值集合被锁死**：若子序列和谐，设其最小值为 $x$、最大值为 $x+1$。元素都是整数且都落在 $[x, x+1]$ 内，区间里只有 $x$、$x+1$ 两个整数，所以子序列只含这两种值。
2. **两个值都必须出现**：只取 $x$ 而不取 $x+1$ 时最大最小值都是 $x$，差为 $0$，不是和谐数组。这一点是本题最容易漏的边界。
3. **同值可以全取**：取走所有等于 $x$ 与 $x+1$ 的元素后，它们按原下标排列仍是 `nums` 的子序列，顺序天然保持，长度达到这个值对能给的上限。

于是对固定的值对 $\{x, x+1\}$，最优长度就是 $cnt[x] + cnt[x+1]$，答案即

$$\text{ans} = \max_{x}\ \{\, cnt[x] + cnt[x+1] \;:\; cnt[x] > 0 \ \text{且}\ cnt[x+1] > 0 \,\}$$

### 3.3 算法流程：一次计数 + 一次查表

![哈希表计数后遍历键，查 x+1 是否存在的流程图](images/wc33_q1_counting_flow.svg)

1. **计数**：用哈希表 `cnt` 记录每个值出现的次数，一次遍历 $O(n)$。
2. **枚举键**：遍历 `cnt` 中**实际出现过的值** $x$，查 `cnt` 里是否存在 $x+1$；存在则用 $cnt[x] + cnt[x+1]$ 更新答案。只遍历键而不是遍历值域，是因为值域跨度可达 $2 \times 10^9$。
3. **返回**：`ans` 初值取 0，全程没有合法值对时正好返回 0。

若想用**排序**：把 `nums` 排序后，相同值聚成连续块；顺序扫描相邻两块，若块值满足 $v_{\text{右}} = v_{\text{左}} + 1$ 就把两块长度相加取最大，时间 $O(n \log n)$、只需 $O(1)$ 额外空间。另有**滑动窗口**写法：排序后维护「窗口内最大值 − 最小值 $\le 1$」的最长窗口，右端为 $r$ 时若 `nums[r] - nums[l] == 1` 则更新 $r-l+1$。

### 3.4 示例演算

![示例 nums = [1,3,2,2,5,2,3,7] 的逐值演算表](images/wc33_q1_example_walkthrough.svg)

`nums = [1,3,2,2,5,2,3,7]` 的计数为 $cnt = \{1{:}1,\ 2{:}3,\ 3{:}2,\ 5{:}1,\ 7{:}1\}$：

| 值 $x$ | $cnt[x]$ | $cnt[x+1]$ | 候选长度 | `ans` |
|:---:|:---:|:---:|:---|:---:|
| 1 | 1 | 3 | $1+3=4$ | 4 |
| 2 | 3 | 2 | $3+2=5$ ⭐ | 5 |
| 3 | 2 | 0（无 4） | 无效 | 5 |
| 5 | 1 | 0（无 6） | 无效 | 5 |
| 7 | 1 | 0（无 8） | 无效 | 5 |

最终 `ans = 5`，对应取走全部 3 个 `2` 与全部 2 个 `3`，得到 $[3,2,2,2,3]$。注意 $x=1$ 的候选只用到了 1 个 `1` 和 3 个 `2`，比它多出的 2 个 `3` 因为会让差值变成 2 而被排除。

## 4. 算法细节

1. **数据结构选择**：值域是 $[-10^9, 10^9]$，**不能**用数组当桶（会申请 $2 \times 10^9$ 个槽位），必须用哈希表；C++ 用 `unordered_map<int,int>`，Python 用 `dict`/`Counter`。
2. **只枚举出现的值**：循环对象是 `cnt` 的键集合（大小 $d \le n$），复杂度与值域跨度无关。若写成 `for (int x = -1e9; ...)` 会直接超时。
3. **C++ 遍历时禁止用 `cnt[x+1]`**：`unordered_map::operator[]` 在键不存在时会**插入**新键，循环中插入可能触发 rehash，令迭代器失效（未定义行为），还会让后面遍历到刚插入的假键。必须用 `find` / `at`（`at` 找不到会抛异常，故用 `find`）。
4. **Python 判存在**：`if x + 1 in cnt` 或 `cnt.get(x + 1)`；直接写 `cnt[x + 1]` 在 $x$ 是最大值时会 `KeyError`。遍历 `cnt.items()` 期间不要修改 `cnt`。
5. **「恰好 1」的判定位置**：差距条件由「$cnt[x+1] > 0$」这一条承担，因此不能顺手写 `ans = max(ans, c)` 去兼容单值情形——那会把示例 3 的答案错算成 4。
6. **等价写法**：① 排序 + 相邻值块合并（时间 $O(n \log n)$，空间 $O(1)$）；② 排序 + 滑动窗口（窗口内差 $\le 1$，相等时结算）；③ 计数后用 `Counter` 的 `most_common` 之类排序键（不必要）。周赛推荐哈希计数，最短且最快。
7. **整数溢出**：$cnt[x] + cnt[x+1] \le n \le 2 \times 10^4$，远小于 `int` 上限；$x+1$ 在 $x = 10^9$ 时仍然安全，无需特判。

## 5. 正确性证明

**引理 1（值集合刻画）**：非空子序列 $S$ 是和谐的，当且仅当存在整数 $x$，使 $S$ 中出现的值恰好构成集合 $\{x, x+1\}$。

**证明**：(⇒) 令 $m = \min S$、$M = \max S$，和谐给出 $M - m = 1$。$S$ 的元素均为整数且落在 $[m, m+1]$ 内，该区间仅含整数 $m, m+1$；又 $m, M$ 都在 $S$ 中出现，故值集合恰为 $\{m, m+1\}$。(⇐) 若值集合为 $\{x, x+1\}$ 且两者都出现，则最小值 $x$、最大值 $x+1$，差为 1。∎

**引理 2（候选可达）**：对任意整数 $x$，若 $cnt[x] > 0$ 且 $cnt[x+1] > 0$，则存在长度为 $cnt[x] + cnt[x+1]$ 的和谐子序列。

**证明**：取 `nums` 中所有值等于 $x$ 或 $x+1$ 的元素，按原下标升序排列得到序列 $S$。$S$ 是 `nums` 的子序列；由两种值均非空，$\min S = x$、$\max S = x+1$，差为 1；长度恰为 $cnt[x] + cnt[x+1]$。∎

**引理 3（候选为上界）**：任一和谐子序列的长度不超过 $\max\{cnt[x] + cnt[x+1]\}$（取遍所有 $cnt[x] > 0$ 且 $cnt[x+1] > 0$ 的 $x$）。

**证明**：设和谐子序列 $S$ 的长度为 $L$。由引理 1，存在 $x$ 使其值集合为 $\{x, x+1\}$，故 $cnt[x] \ge 1$、$cnt[x+1] \ge 1$，该 $x$ 会被算法枚举；而 $S$ 中值为 $x$ 的元素至多 $cnt[x]$ 个、值为 $x+1$ 的至多 $cnt[x+1]$ 个，于是 $L \le cnt[x] + cnt[x+1] \le \max$。∎

**定理**：算法返回的值等于 `nums` 中最长和谐子序列的长度。

**证明**：算法遍历 `cnt` 的全部键，恰好覆盖所有「两个计数都为正」的 $x$（键集合就是出现过的值集合，$x+1$ 的判定用 `find` 精确判断存在性），并对每个合法 $x$ 取 $cnt[x] + cnt[x+1]$ 的最大值。由引理 2，答案不小于真实最优值；由引理 3，答案不大于真实最优值；两者夹逼即相等。若不存在任何合法值对（如所有元素相同、或只有一个元素），`ans` 保持初值 0，与「不存在和谐子序列时返回 0」一致。∎

## 6. 复杂度分析

- **时间**：$O(n)$（期望）。计数一遍 $O(n)$；枚举键 $O(d)$，$d \le n$ 为不同值个数，每次哈希查找期望 $O(1)$；合计 $O(n)$。排序写法为 $O(n \log n)$。
- **空间**：$O(d) \le O(n)$。哈希表存放至多 $d$ 个「值 → 次数」条目；排序写法额外空间 $O(1)$（不计排序内部开销），但时间更贵。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <unordered_map>
#include <algorithm>
using namespace std;

class Solution {
public:
    int findLHS(vector<int>& nums) {
        unordered_map<int, int> cnt;
        cnt.reserve(nums.size() * 2);          // 预留桶，减少 rehash
        for (int v : nums) ++cnt[v];

        int ans = 0;
        for (const auto& [x, c] : cnt) {
            auto it = cnt.find(x + 1);         // 不能用 cnt[x+1]：会插入新键使迭代器失效
            if (it != cnt.end()) ans = max(ans, c + it->second);
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def findLHS(self, nums: list[int]) -> int:
        cnt = {}
        for v in nums:
            cnt[v] = cnt.get(v, 0) + 1

        ans = 0
        for x, c in cnt.items():          # 只遍历出现过的值
            if x + 1 in cnt:              # 必须两个值都存在，否则差为 0
                ans = max(ans, c + cnt[x + 1])
        return ans
```

## 8. 边界情况与易错点

1. **所有元素相同**：如 `[1,1,1,1]`，没有 $x+1$，答案 0；不要因为「最长子序列是 4」就返回 4。`ans` 初值 0 天然兜底。
2. **单元素数组**：`[5]` 只有一个值，差为 0，返回 0；代码不需要额外特判。
3. **只有一对相邻值**：如 `[1,2,2,3,3,3]`，$x=1$ 给 3、$x=2$ 给 5，答案 5——注意不是「取全部」，因为 1 与 3 相差 2，不能同框。
4. **漏掉「两值都存在」的判定**：写成 `ans = max(ans, c)` 会把单值计数当成答案，示例 3 直接输出 4；这是本题最高频 WA。
5. **C++ 用 `operator[]` 边遍历边查**：`cnt[x+1]` 会插入 0 值键，可能 rehash 导致迭代器失效（UB），也可能让刚插入的键被后续遍历到并再次查表。务必 `find`。
6. **Python 直接下标访问**：`cnt[x + 1]` 在最大值处 `KeyError`；用 `in` / `get`。
7. **用数组当桶**：值域 $2 \times 10^9$，开桶必然 MLE；即便用 `nums[i] + 10^9` 偏移也不行。
8. **排序滑窗写错收缩条件**：窗口内 `nums[r] - nums[l] <= 1` 才继续扩张；结算答案时必须要求 `== 1`，否则单值窗口会被误算成候选。
