# LeetCode 反转后字典序最小的字符串 题解

## 1. 题目概述

- **标题 / 题号**：反转后字典序最小的字符串（#3722，medium）
- **链接**：https://leetcode.cn/problems/lexicographically-smallest-string-after-reverse/
- **来源**：LeetCode 第 168 场双周赛 Q1
- **难度**：中等
- **标签**：字符串、枚举、双指针

**题意**：给定长度为 $n$ 的小写字符串 $s$。必须**恰好执行一次**操作：选一个整数 $k$（$1 \le k \le n$），然后二选一：

1. 反转 $s$ 的**前** $k$ 个字符；
2. 反转 $s$ 的**后** $k$ 个字符。

求操作后能得到的**字典序最小**的字符串。注意「恰好一次」：即使原串已经最小，也必须做一次操作。

**约束**：

- $1 \le n = s.length \le 1000$
- $s$ 只包含小写英文字母

## 2. 示例

**示例 1**

```text
输入：s = "dcab"
输出："acdb"
解释：k = 3 反转前 3 个字符："dca" → "acd"，得 "acdb"，是所有结果中最小的。
```

**示例 2**

```text
输入：s = "abba"
输出："aabb"
解释：k = 3 反转后 3 个字符："bba" → "abb"，得 "aabb"。
     （若反转前 3 个字符则得 "bba" + "a" = "bbaa"，更大。）
```

**示例 3**

```text
输入：s = "zxy"
输出："xzy"
解释：k = 2 反转前 2 个字符："zx" → "xz"，得 "xzy"。
```

## 3. 解题思路

### 3.1 暴力思路

候选方案的数量极其有限：$k$ 有 $n$ 种取值，方向有 2 种，共 $2n$ 个候选；每个候选的构造是 $O(n)$ 的字符串拼接。总复杂度 $O(n^2)$，$n = 1000$ 时约 $2 \times 10^6$ 个字符操作，完全可过。**这就是本题的正解**——题目本身不要求更优，关键在于写对「枚举对象」和「比较方式」。

### 3.2 核心观察：答案只会在这 2n 个候选里

![两种操作：反转前 k 个或后 k 个字符](images/bw168_q1_two_operations.svg)

先把两种操作写成统一形式。记 $s = A\,B$：

- **反转前 $k$ 个**：结果 = $\operatorname{rev}(s[0..k-1]) + s[k..n-1]$；
- **反转后 $k$ 个**：结果 = $s[0..n-k-1] + \operatorname{rev}(s[n-k..n-1])$。

两点观察让枚举更清晰：

1. **$k = n$ 时两种操作相同**（都反转整个串），所以有重复候选，但去重对答案无影响。
2. **$k = 1$ 时两种操作都是原串**——这正是「恰好一次」的边界：如果原串已经最小，也必须选 $k=1$（反转长度 1 不改变任何东西），所以答案一定在候选集合中。

比较时直接按字典序取最小即可，无需手写比较函数（C++ 的 `std::string` 与 Python 的 `str` 都自带字典序比较）。

![算法流程：2n 个候选，逐个取最小](images/bw168_q1_algorithm_flow.svg)

### 3.3 算法流程

```text
1. best = s
2. for k = 1 .. n:
       cand1 = reverse(s[0..k-1]) + s[k..n-1]
       cand2 = s[0..n-k-1] + reverse(s[n-k..n-1])
       best = min(best, cand1, cand2)
3. 返回 best
```

### 3.4 示例演算

![示例 1 的候选与比较](images/bw168_q1_example_walkthrough.svg)

示例 1：$s = \text{"dcab"}$，$n = 4$。列出所有候选（相同结果去重）：

| $k$ | 反转前 $k$ 个 | 反转后 $k$ 个 |
|-----|----------------|----------------|
| 1 | `dcab` | `dcab` |
| 2 | `cdab` | `dcba` |
| 3 | `acdb` ← 最小 | `dacb` |
| 4 | `bacd` | `bacd` |

最小的是 `acdb`（$k=3$ 反转前 3 个），与题面一致。

示例 2：$s = \text{"abba"}$。$k=1$ 得 `abba`；$k=2$ 反转前得 `baab`，反转后得 `abab`；$k=3$ 反转前得 `bbaa`，反转后得 `aabb` ← 最小；$k=4$ 得 `abba`。答案 `aabb` ✓。

## 4. 算法细节

1. **候选构造**：C++ 用 `string` 的 `substr` + `reverse`；Python 用切片 `s[k-1::-1] + s[k:]` 与 `s[:n-k] + s[n-k:][::-1]`。
2. **字典序比较**：`min` 直接作用于字符串即可，长度相同（都是 $n$），无需担心前缀关系。
3. **初始化 `best = s`**：$k=1$ 的两个候选都等于 $s$，所以初值一定在候选集中，不会出现「返回了未经过操作的结果」这种逻辑错误。
4. **复杂度**：$2n$ 个候选，各 $O(n)$ 构造与比较，总 $O(n^2)$ 时间、$O(n)$ 额外空间。
5. **能否更快**：注意到答案的第一位必然等于 $\min(s[0], s[0..k-1] 的最小值...)$——想更快需要分析「把哪个更小的字符搬到队首」，可以做到 $O(n)$ 或 $O(n\log n)$，但本题 $n \le 1000$，没有必要。
6. **不要漏掉方向**：两种操作必须都试；示例 2 的正解来自「反转后 $k$ 个」。

## 5. 正确性证明

**引理 1（候选完备）**：任何一次合法操作的结果都属于算法枚举的 $2n$ 个候选。

**证明**：合法操作由「方向 ∈ {前, 后}」与「$k \in [1, n]$」唯一确定，共 $2n$ 种组合；算法对这 $2n$ 种组合逐一计算了结果（候选可能重复，但不遗漏）。∎

**引理 2（候选合法）**：算法枚举的每个候选都是某个合法操作的结果。

**证明**：`cand1` 恰为「反转前 $k$ 个字符」的结果，`cand2` 恰为「反转后 $k$ 个字符」的结果，两者都满足「恰好执行一次」的要求（$k \ge 1$，操作确实发生，只是 $k=1$ 时长度 1 的反转不改变字符串）。∎

**定理**：算法返回的字符串是所有合法操作结果中字典序最小的。

**证明**：由引理 1、2，候选集合与合法结果集合相同（作为集合）。算法对候选集取字典序最小元，故返回值 ≤ 任何合法结果；又它本身是合法结果，故它就是最小值。∎

## 6. 复杂度分析

- **时间**：$O(n^2)$。共 $2n$ 个候选，每个构造需要 $O(n)$ 的字符复制，字符串比较也是 $O(n)$。
- **空间**：$O(n)$。同时只保留当前最优候选与一个临时候选（若把 $2n$ 个候选都存下来则是 $O(n^2)$，没必要）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    string lexSmallest(string s) {
        int n = (int)s.size();
        string best = s;
        for (int k = 1; k <= n; k++) {
            string a = s.substr(0, k);
            reverse(a.begin(), a.end());
            a += s.substr(k);
            if (a < best) best = a;

            string b = s.substr(0, n - k);
            string tail = s.substr(n - k);
            reverse(tail.begin(), tail.end());
            b += tail;
            if (b < best) best = b;
        }
        return best;
    }
};
```

### Python

```python
class Solution:
    def lexSmallest(self, s: str) -> str:
        n = len(s)
        best = s
        for k in range(1, n + 1):
            cand1 = s[k - 1::-1] + s[k:]        # 反转前 k 个
            cand2 = s[:n - k] + s[n - k:][::-1]  # 反转后 k 个
            if cand1 < best:
                best = cand1
            if cand2 < best:
                best = cand2
        return best
```

## 8. 边界情况与易错点

1. **「恰好一次」不是「至多一次」**：不能直接返回原串，必须从候选里取最小；好在 $k=1$ 的候选就是原串，所以 `best` 初值设为 `s` 不会出错。
2. **两种方向都要枚举**：示例 2 的答案来自「反转后 $k$ 个」，只枚举前 $k$ 个会得到 `bbaa`。
3. **$k = n$ 的重复**：两个方向结果相同，重复计算不影响正确性，也可以特判跳过。
4. **$n = 1$**：唯一候选就是原串（$k=1$ 反转 1 个字符），返回 `s`。
5. **切片下标**：Python 的 `s[k-1::-1]` 是「下标 $k-1$ 往前到 0 反转」，等价于 `s[:k][::-1]`，写错成 `s[k::-1]` 会多取一个字符。
6. **比较时长度相同**：所有候选都是长度 $n$ 的串，字典序比较不会遇到「前缀相同但长短不同」的情形，无需额外处理。
