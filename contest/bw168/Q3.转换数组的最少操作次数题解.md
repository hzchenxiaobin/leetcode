# LeetCode 转换数组的最少操作次数 题解

## 1. 题目概述

- **标题 / 题号**：转换数组的最少操作次数（#3724，medium）
- **链接**：https://leetcode.cn/problems/minimum-operations-to-transform-array/
- **来源**：LeetCode 第 168 场双周赛 Q3
- **难度**：中等
- **标签**：贪心、数组、数学（绝对值最小值）

**题意**：给定长度为 $n$ 的数组 $nums1$ 与长度为 $n+1$ 的数组 $nums2$。每次操作可以选一个下标 $i$，执行三者之一：

1. `nums1[i] += 1`；
2. `nums1[i] -= 1`；
3. 把 `nums1[i]` **追加**到数组末尾（操作本身算 1 次）。

求把 $nums1$ 变成 $nums2$ 所需的**最少**操作次数。

**约束**：

- $1 \le n = nums1.length \le 10^5$
- $nums2.length = n + 1$
- $1 \le nums1[i], nums2[i] \le 10^5$

## 2. 示例

**示例 1**

```text
输入：nums1 = [2,8], nums2 = [1,7,3]
输出：4
解释：append nums1[0]（值 2）→ [2,8,2]；把 nums1[0] 减到 1；把 nums1[1] 减到 7；
     把末尾的 2 加到 3。共 4 次操作。
```

**示例 2**

```text
输入：nums1 = [1,3,6], nums2 = [2,4,5,3]
输出：4
解释：append nums1[1]（值 3）→ [1,3,6,3]；再把三个原位置分别调成 2、4、5。
```

**示例 3**

```text
输入：nums1 = [2], nums2 = [3,4]
输出：3
解释：把 2 加到 3；append 这个 3；把末尾的 3 加到 4。共 3 次。
```

## 3. 解题思路

### 3.1 暴力思路

枚举「追加哪个下标 $j$」与「追加时的值 $w$」，再计算所有调整代价，复杂度 $O(n \cdot V)$（$V$ 为值域 $10^5$），$n = 10^5$ 时是 $10^{10}$，不可行。不过这个暴力描述了问题的真实结构：**追加哪一个、追加成什么值**是仅有的两个自由度。

### 3.2 核心观察：恰好追加一次，且三个目标值确定了中位数

![追加一次后，原位置与副本各自独立地朝两个目标值收敛](images/bw168_q3_append_model.svg)

先定结构：$nums1$ 长度 $n$、$nums2$ 长度 $n+1$，而 append 只能让长度 $+1$、没有任何删除操作，所以**恰好执行一次 append**，它产生的新元素最终位于下标 $n$，目标值是 $T = nums2[n]$（即 `nums2.back()`）。

设被追加的是下标 $j$，追加那一刻它的值为 $w$：

- 追加前要把 $nums1[j]$ 从 $a_j$ 调成 $w$：代价 $|a_j - w|$；
- 追加操作本身：代价 $1$；
- 追加后，**原位置**继续调整到 $b_j$（$b_j = nums2[j]$）：代价 $|w - b_j|$ —— 注意副本是「快照」，此后两者互不影响；
- **副本**调整到 $T$：代价 $|w - T|$；
- 其他下标 $i \ne j$ 各自调整：代价 $|a_i - b_i|$。

于是总代价为

$$\underbrace{\sum_{i} |a_i - b_i|}_{\text{基础代价}} + 1 + \Bigl( \underbrace{|a_j - w| + |w - b_j| + |w - T|}_{\text{记作 } g_j(w)} - |a_j - b_j| \Bigr).$$

**$g_j(w)$ 的最小值有闭式**：三个绝对值之和在 $w$ 取这三个数的**中位数**时最小，最小值为

$$\min_w g_j(w) = \max(a_j, b_j, T) - \min(a_j, b_j, T).$$

（这是「到三点距离之和最小」的经典结论：取中位数即可，此时总距离恰为首尾之差。）

于是答案只需在 $j = 0..n-1$ 中取最优：

$$ans = \sum_i |a_i - b_i| + 1 + \min_j \bigl( \max(a_j,b_j,T) - \min(a_j,b_j,T) - |a_j - b_j| \bigr).$$

![算法流程：基础代价 + 1 + 每个下标的额外代价](images/bw168_q3_algorithm_flow.svg)

### 3.3 算法流程

```text
1. base = Σ |nums1[i] - nums2[i]|（i = 0..n-1）
2. T = nums2[n]（= nums2.back()）
3. best = +∞
4. for j = 0 .. n-1:
       lo = min(nums1[j], nums2[j], T)
       hi = max(nums1[j], nums2[j], T)
       extra = (hi - lo) - |nums1[j] - nums2[j]|
       best = min(best, extra)
5. 返回 base + 1 + best
```

### 3.4 示例演算

![示例 1 与示例 2 的下标选择](images/bw168_q3_example_walkthrough.svg)

示例 1：`nums1 = [2,8]`、`nums2 = [1,7,3]`，$T = 3$。

- 基础代价：$|2-1| + |8-7| = 1 + 1 = 2$；
- $j=0$：三点 $\{2, 1, 3\}$，$\max - \min = 3 - 1 = 2$，减去 $|2-1|=1$ → extra $= 1$；
- $j=1$：三点 $\{8, 7, 3\}$，$\max - \min = 8 - 3 = 5$，减去 $|8-7|=1$ → extra $= 4$；
- 取最小 extra $= 1$，答案 $= 2 + 1 + 1 = 4$ ✓。

示例 2：`nums1 = [1,3,6]`、`nums2 = [2,4,5,3]`，$T = 3$。基础代价 $= 1+1+1 = 3$。

| $j$ | $a_j$ | $b_j$ | 三点 | $\max-\min$ | $|a_j-b_j|$ | extra |
|-----|-------|-------|------|-------------|--------------|-------|
| 0 | 1 | 2 | {1,2,3} | 2 | 1 | 1 |
| 1 | 3 | 4 | {3,4,3} | 1 | 1 | **0** |
| 2 | 6 | 5 | {6,5,3} | 3 | 1 | 2 |

最小 extra $= 0$（选 $j=1$，因为 $a_1 = 3$ 恰好等于 $T$，追加无需任何调整），答案 $= 3 + 1 + 0 = 4$ ✓。

示例 3：`nums1 = [2]`、`nums2 = [3,4]`，$T = 4$。基础代价 $|2-3| = 1$；$j=0$：三点 $\{2,3,4\}$，$\max-\min = 2$，减 $|2-3| = 1$ → extra $= 1$；答案 $= 1+1+1 = 3$ ✓。

## 4. 算法细节

1. **恰好一次 append**：长度差为 1，且 append 是唯一的「增长」操作、没有删除，故必须且只能 append 一次。若 $nums2$ 长度不是 $n+1$，本题模型就不成立。
2. **$T$ 的定义**：末位目标值必须是 `nums2[n]`（0-indexed 的最后一位），不要误用 `nums2[n-1]`。
3. **中位数公式**：$\min_w \sum |w - x_k| = \max x_k - \min x_k$（奇数个点），因此不必真的枚举 $w$。
4. **`extra` 可能为 0 或正**：由三角不等式 $|a_j-T| + |T-b_j| \ge |a_j-b_j|$，可知 $\max-\min \ge |a_j-b_j|$，故 `extra >= 0`，加 1 后答案至少是「基础代价 + 1」。
5. **64 位整数**：$n \le 10^5$、值域 $10^5$，基础代价最大 $10^{10}$，必须用 `long long`。
6. **一次遍历即可**：把 `base` 与 `best` 在同一个循环里维护，$O(n)$、$O(1)$ 额外空间。

## 5. 正确性证明

**引理 1（恰好一次追加）**：任何把 $nums1$（长度 $n$）变成 $nums2$（长度 $n+1$）的操作序列中，append 操作恰好出现一次。

**证明**：只有 append 会增加数组长度（每次 $+1$），`+= 1` 与 `-= 1` 不改变长度，也没有删除操作，故长度最终为 $n + k$，其中 $k$ 是 append 次数。要求最终长度 $n+1$，得 $k = 1$。∎

**引理 2（代价分解）**：对固定的追加下标 $j$ 与追加时的值 $w$，最小总代价为
$$C_j(w) = \sum_{i \ne j} |a_i - b_i| \;+\; \bigl(|a_j - w| + 1 + |w - b_j| + |w - T|\bigr).$$

**证明**：各下标的值只受「针对该下标的加减操作」影响，且 append 产生的副本与原下标在 append 之后互不影响（副本是那一刻的快照，之后对原下标的修改不反映到副本）。因此总代价是各部分之和：其他下标必须从 $a_i$ 调到 $b_i$，最小 $|a_i - b_i|$ 次（每次改变 1，下界由三角不等式给出且可达）；下标 $j$ 需先把值从 $a_j$ 调到 $w$（$|a_j - w|$ 次），执行 1 次 append，然后把原位置从 $w$ 调到 $b_j$（$|w - b_j|$ 次），把副本从 $w$ 调到 $T$（$|w - T|$ 次）。这些操作互不干扰、可独立完成，故求和即为最小代价。∎

**引理 3（三绝对值最小值）**：对任意整数 $x, y, z$，$\min_{w \in \mathbb{Z}} (|w-x| + |w-y| + |w-z|) = \max(x,y,z) - \min(x,y,z)$。

**证明**：不妨设 $x \le y \le z$。则 $|w-x| + |w-z| \ge z - x$（三角不等式，等号当 $w \in [x,z]$），且 $|w-y| \ge 0$，故和 $\ge z - x$。取 $w = y$（中位数，落在 $[x,z]$ 内）时，$|y-x| + |y-y| + |y-z| = (y-x) + 0 + (z-y) = z-x$，达到下界。∎

**定理**：算法输出等于最少操作次数。

**证明**：由引理 1，任一可行序列恰含一次 append，设其追加下标为 $j$、追加时值为 $w$，则由引理 2 其代价 $\ge C_j(w)$。故最少操作数 $= \min_{j, w} C_j(w) = \sum_i |a_i - b_i| + 1 + \min_j \bigl(\min_w g_j(w) - |a_j - b_j|\bigr)$。由引理 3，$\min_w g_j(w) = \max(a_j,b_j,T) - \min(a_j,b_j,T)$。算法正是枚举 $j$ 求该最小值，故输出正确；且每个 $j$ 的最优 $w$ 取中位数时可实际构造出对应操作序列，说明下界可达。∎

## 6. 复杂度分析

- **时间**：$O(n)$。一次遍历同时计算基础代价与每个下标的额外代价，每个下标 $O(1)$。
- **空间**：$O(1)$。只用 `base`、`best`、`T` 等常数个变量（不计输入数组）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long minOperations(vector<int>& nums1, vector<int>& nums2) {
        int n = (int)nums1.size();
        long long base = 0;
        for (int i = 0; i < n; i++) {
            long long d = (long long)nums1[i] - nums2[i];
            base += (d >= 0 ? d : -d);
        }
        long long T = nums2[n];
        long long best = (long long)4e18;
        for (int j = 0; j < n; j++) {
            long long a = nums1[j], b = nums2[j];
            long long lo = min(a, min(b, T));
            long long hi = max(a, max(b, T));
            long long diff = a - b;
            if (diff < 0) diff = -diff;
            long long extra = (hi - lo) - diff;
            best = min(best, extra);
        }
        return base + 1 + best;
    }
};
```

### Python

```python
class Solution:
    def minOperations(self, nums1: list[int], nums2: list[int]) -> int:
        n = len(nums1)
        base = sum(abs(nums1[i] - nums2[i]) for i in range(n))
        T = nums2[n]
        best = None
        for j in range(n):
            a, b = nums1[j], nums2[j]
            span = max(a, b, T) - min(a, b, T)
            extra = span - abs(a - b)
            if best is None or extra < best:
                best = extra
        return base + 1 + best
```

## 8. 边界情况与易错点

1. **$T$ 不能取错**：$T = nums2[n]$（末位），不是 $nums2$ 的某个中间元素；示例 1 中 $T=3$，若误取 $nums2[n-1]=7$ 会得到错误答案。
2. **「恰好一次」不能省**：即使 $a_j$ 已经等于 $T$，append 仍要花 1 次操作（示例 2 的 $j=1$ 就是这种情况，extra 为 0 但总数仍 +1）。
3. **`extra` 的下界**：由三角不等式保证非负，可以用它做自检；若算出负数说明公式写错（例如把 $\max-\min$ 写成了 $|a_j - T|$）。
4. **`long long`**：基础代价上界 $10^5 \times 10^5 = 10^{10}$，`int` 溢出。C++ 里做差时要先强转成 `long long` 再取绝对值，避免 `int` 中间结果溢出。
5. **$n = 1$**：只有一个下标可选，公式退化为 $|a_0-b_0| + 1 + (\max(a_0,b_0,T) - \min(a_0,b_0,T) - |a_0-b_0|)$，示例 3 验证为 3。
6. **不要贪心选 $|a_j - T|$ 最小者**：真正影响答案的是三元组的极差再减去基础代价，贪心指标与目标不完全一致（示例 1 中 $j=0$ 的 $|a_j - T| = 1$、$j=1$ 是 5，恰好一致，但一般情形不一定）。
7. **复制语义**：追加后副本与原位置互不影响，这是「同一元素可以有两个不同目标值」的关键；若错误地认为副本会跟随原位置变化，会少算代价。
