# LeetCode 统计每一行选择互质整数的方案数 题解

## 1. 题目概述

- **标题 / 题号**：统计每一行选择互质整数的方案数（#3725，hard）
- **链接**：https://leetcode.cn/problems/count-ways-to-choose-coprime-integers-from-rows/
- **来源**：LeetCode 第 168 场双周赛 Q4
- **难度**：困难
- **标签**：动态规划、数学、数论、组合计数、矩阵

**题意**：给定 $m \times n$ 的正整数矩阵 $mat$。从**每一行**中**恰好选一个**整数，要求所有被选整数的**最大公约数为 1**。求方案数，结果对 $10^9+7$ 取模。

**约束**：

- $1 \le m = mat.length \le 150$
- $1 \le n = mat[i].length \le 150$
- $1 \le mat[i][j] \le 150$

## 2. 示例

**示例 1**

```text
输入：mat = [[1,2],[3,4]]
输出：3
解释：四种选法的 gcd：
     1&3 → 1 ✓   1&4 → 1 ✓   2&3 → 1 ✓   2&4 → 2 ✗
     共 3 种。
```

**示例 2**

```text
输入：mat = [[2,2],[2,2]]
输出：0
解释：所有选法的 gcd 都是 2，没有合法方案。
```

**示例 3（补充例子）**

```text
输入：mat = [[1,1],[1,1]]
输出：4
解释：任何选法的 gcd 都是 1，共 2 × 2 = 4 种。
```

## 3. 解题思路

### 3.1 暴力思路

枚举每一行的选择，共 $n^m$ 种组合（最坏 $150^{150}$），对每种组合求 $m$ 个数的 gcd。这是天文数字，绝无可能。即便用「逐行合并 gcd」的暴力，状态数仍是 $\prod n_i$。

### 3.2 核心观察：gcd 的取值只有 150 种

![gcd 状态空间被值域锁死：任意选择的 gcd 一定 ≤ 150](images/bw168_q4_gcd_state_space.svg)

这是本题的题眼：**因为所有元素都 $\le 150$，所以任意选择得到的 gcd 也 $\le 150$**（gcd 一定整除每个被选元素）。状态数从「指数级」被压缩到「常数 150」。

于是可以按行做 DP：

$$dp[g] = \text{已处理的行中，选出的一组数 gcd 恰为 } g \text{ 的方案数}.$$

转移时枚举当前行的每个取值 $v$：

$$ndp[\gcd(g, v)] \mathrel{+}= dp[g] \times cnt[v],$$

其中 $cnt[v]$ 是 $v$ 在当前行出现的次数（先对每行去重计数，避免重复枚举相同的值）。

初值：第 0 行直接 $dp[v] \mathrel{+}= cnt_0[v]$。答案：$dp[1]$（全部选完且 gcd 为 1）。

![DP 转移：上一行状态 g 与当前行的值 v 合成 gcd(g, v)](images/bw168_q4_dp_transition.svg)

### 3.3 算法流程

```text
1. MOD = 1e9 + 7；dp[1..150] = 0
2. 第一行：统计每个值 v 的出现次数 cnt，dp[v] += cnt
3. for i = 1 .. m-1:
       统计当前行的值频次 cnt
       ndp[1..150] = 0
       for g = 1 .. 150（dp[g] > 0）:
           for v（当前行出现过的值）:
               ng = gcd(g, v)
               ndp[ng] = (ndp[ng] + dp[g] * cnt[v]) % MOD
       dp = ndp
4. 返回 dp[1] % MOD
```

### 3.4 示例演算

![示例 1 的状态转移过程](images/bw168_q4_example_walkthrough.svg)

示例 1：$mat = [[1,2],[3,4]]$。

**第一行** $\{1,2\}$：$dp[1] = 1$、$dp[2] = 1$，其余为 0。

**第二行** $\{3,4\}$：

| 上一状态 $g$ | $dp[g]$ | $v=3$ → $\gcd$ | $v=4$ → $\gcd$ |
|--------------|---------|-----------------|-----------------|
| 1 | 1 | 1（贡献 1） | 1（贡献 1） |
| 2 | 1 | 1（贡献 1） | 2（贡献 1） |

汇总：$ndp[1] = 1+1+1 = 3$，$ndp[2] = 1$。答案 $dp[1] = 3$ ✓（与题面的 3 种吻合，$2\&4$ 落在 $dp[2]$ 被排除）。

示例 2：第一行 $\{2,2\}$ → $dp[2] = 2$；第二行只有 2，$\gcd(2,2)=2$ → $ndp[2] = 4$，$dp[1] = 0$ ✓。

## 4. 算法细节

1. **状态上界**：值域上限 $V = 150$，数组开到 $V+1$。若值域更大（如 $10^9$），这个 DP 就不成立，必须换数论方法（见「延伸思考」）。
2. **每行先去重计数**：`cnt[v]` 把 $n$ 个取值压缩到不超过 150 个不同值；否则同一行内相同值会被重复枚举，$n = 150$ 时只是常数问题，但去重后更清晰。
3. **gcd 预计算**：可以预先算一张 $151 \times 151$ 的 `gcd` 表，把每次转移的 `gcd` 调用换成一次查表，常数更小。
4. **取模时机**：`dp[g] * cnt[v]` 最大约 $(10^9) \times 150 \approx 1.5 \times 10^{11}$，用 `long long` 存中间值再取模；Python 无溢出问题。
5. **只枚举非零状态**：`dp[g] == 0` 的状态直接跳过，实测能省掉大部分无用转移。
6. **初值不要漏**：第一行必须用频次初始化，不能统一设成 1（否则重复元素会被少算）。
7. **答案下标是 1**：gcd 为 1 表示互质，不是 0。

## 5. 正确性证明

**引理 1（状态空间有界）**：任意选择方案得到的 gcd 都是 $[1, 150]$ 内的整数。

**证明**：设选择为 $v_1, \dots, v_m$，$g = \gcd(v_1,\dots,v_m)$。由 gcd 定义 $g \mid v_1$，而 $1 \le v_1 \le 150$，故 $1 \le g \le 150$。∎

**引理 2（转移完备且不重不漏）**：处理完前 $i$ 行后，$dp[g]$ 等于「从前 $i$ 行各选一个数、且这 $i$ 个数的 gcd 恰为 $g$」的方案数。

**证明**：对 $i$ 归纳。$i = 1$：只能选第 0 行的一个数 $v$，其 gcd 为 $v$，故 $dp[v]$ 应等于 $v$ 的出现次数，与初始化一致。

归纳步：若 $i-1$ 行的 $dp$ 正确，考虑前 $i$ 行的任一方案。设前 $i-1$ 行的选择 gcd 为 $g$、第 $i$ 行选 $v$，则整体 gcd $= \gcd(g, v)$，由归纳假设这类方案被 $dp[g]$ 计数；对每个 $v$ 的每一次出现（共 $cnt[v]$ 次）都产生一个不同方案，故转移到 $ndp[\gcd(g,v)]$ 的贡献恰为 $dp[g] \times cnt[v]$。所有方案都对应唯一的 $(g, v)$ 且被恰好计数一次，因此 $ndp$ 正确。∎

**定理**：算法返回的方案数等于「每行选一个数且总 gcd 为 1」的方案数（模 $10^9+7$）。

**证明**：由引理 2（取 $i = m$），$dp[1]$ 恰为「每行选一个、gcd 为 1」的方案数。由引理 1，所有 gcd 都在状态范围内，没有状态被漏掉。取模在每一步加法处保持同余，故输出为答案模 $10^9+7$。∎

## 6. 复杂度分析

- **时间**：$O(m \cdot V \cdot V')$，其中 $V = 150$ 为状态数、$V' \le 150$ 为单行不同取值数。最坏 $150 \times 150 \times 150 \approx 3.4 \times 10^6$ 次 gcd 运算，非常轻。
- **空间**：$O(V)$，两个长度 151 的 DP 数组（滚动）；若预计算 gcd 表再加 $O(V^2) = 22500$ 个整数。
- **预处理**：每行计数 $O(n)$，共 $O(mn)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int countCoprime(vector<vector<int>>& mat) {
        const int MOD = 1000000007;
        const int V = 150;
        vector<long long> dp(V + 1, 0), ndp(V + 1, 0);
        // 第一行
        vector<int> cnt(V + 1, 0);
        for (int v : mat[0]) cnt[v]++;
        for (int v = 1; v <= V; v++) {
            if (cnt[v]) dp[v] = cnt[v];
        }
        for (int i = 1; i < (int)mat.size(); i++) {
            fill(cnt.begin(), cnt.end(), 0);
            for (int v : mat[i]) cnt[v]++;
            fill(ndp.begin(), ndp.end(), 0);
            for (int g = 1; g <= V; g++) {
                if (dp[g] == 0) continue;
                for (int v = 1; v <= V; v++) {
                    if (cnt[v] == 0) continue;
                    int ng = std::gcd(g, v);
                    ndp[ng] = (ndp[ng] + dp[g] * cnt[v]) % MOD;
                }
            }
            dp.swap(ndp);
        }
        return (int)(dp[1] % MOD);
    }
};
```

### Python

```python
from math import gcd

class Solution:
    def countCoprime(self, mat: list[list[int]]) -> int:
        MOD = 10**9 + 7
        V = 150
        dp = [0] * (V + 1)
        for v in mat[0]:
            dp[v] += 1
        for row in mat[1:]:
            cnt = [0] * (V + 1)
            for v in row:
                cnt[v] += 1
            ndp = [0] * (V + 1)
            for g in range(1, V + 1):
                if dp[g] == 0:
                    continue
                for v in range(1, V + 1):
                    if cnt[v] == 0:
                        continue
                    ng = gcd(g, v)
                    ndp[ng] = (ndp[ng] + dp[g] * cnt[v]) % MOD
            dp = ndp
        return dp[1] % MOD
```

## 8. 边界情况与易错点

1. **$m = 1$**：只有一行，答案就是该行中值为 1 的个数（gcd 为 1 当且仅当选 1）。代码里第一行初始化后直接返回 $dp[1]$ ✓。
2. **某行含 1**：$\gcd(1, g) = 1$ 对所有 $g$ 成立，等价于「前面随便选」——DP 会自动处理，无需特判。
3. **取模**：`dp[g] * cnt[v]` 要用 `long long`（C++）或 Python 大整数；`MOD` 常量写错成 $10^9+9$ 会全错。
4. **gcd 状态下标从 1 开始**：0 不是合法 gcd；若代码里出现 `dp[0]` 说明初始化写错了（比如把所有值都累加到 0）。
5. **每行去重计数**：`mat[i]` 可能有大量重复值，用频次相乘而不是多次枚举，既省时又避免重复计数。
6. **全部行都是 2**：答案 0（示例 2），DP 会自然得到 $dp[2] > 0$、$dp[1] = 0$。
7. **用 `std::gcd` 而不是自己写**：C++17 的 `std::gcd` 在 `<numeric>` 中，语义清晰且对 0 的处理标准；`std::__gcd` 是 GCC 扩展，移植性差，不建议。

**延伸思考**：本题之所以能 $O(V^2)$ 转移，全靠值域 $\le 150$。若值域放到 $10^9$，状态数不可枚举，就要用**莫比乌斯反演 + 容斥**：设 $f(d)$ = 每行都选 $d$ 的倍数的方案数（可逐行相乘），则由反演

$$\text{答案} = \sum_{d=1}^{V} \mu(d)\, f(d),$$

其中 $f(d) = \prod_{i} \bigl(\text{第 } i \text{ 行中 } d \text{ 的倍数的个数}\bigr)$。不过这要求 $d$ 只取到值域上界 $150$，本质仍是「按 divisor 分桶」——可见本题与 1735 是同一套数论工具的不同切面。若再把「每行恰好一个」改成「每行选任意多个」，则需要用矩阵快速幂或生成函数，复杂度与 $m$ 解耦。
