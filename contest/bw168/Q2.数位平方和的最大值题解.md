# LeetCode 数位平方和的最大值 题解

## 1. 题目概述

- **标题 / 题号**：数位平方和的最大值（#3723，medium）
- **链接**：https://leetcode.cn/problems/maximize-sum-of-squares-of-digits/
- **来源**：LeetCode 第 168 场双周赛 Q2
- **难度**：中等
- **标签**：贪心、数学、构造

**题意**：给定两个正整数 $num$ 与 $sum$。若正整数 $n$ 满足「位数恰好为 $num$」且「各位数字之和恰好为 $sum$」，则称 $n$ 是**好整数**，其**分数**为各位数字的**平方和**。

要求返回一个字符串，表示分数最大的好整数；若有多个好整数分数并列最大，返回其中**数值最大**的那个；若不存在好整数，返回空字符串。

**约束**：

- $1 \le num \le 2 \times 10^5$
- $1 \le sum \le 2 \times 10^6$

## 2. 示例

**示例 1**

```text
输入：num = 2, sum = 3
输出："30"
解释：好整数有 12、21、30。分数：1²+2²=5、2²+1²=5、3²+0²=9。
     最大分数 9 由 30 取得，答案是 "30"。
```

**示例 2**

```text
输入：num = 2, sum = 17
输出："98"
解释：好整数只有 89、98（9+8=17）。两者分数都是 8²+9²=145，
     并列时取较大的数 → "98"。
```

**示例 3**

```text
输入：num = 1, sum = 10
输出：""
解释：一位数字最大是 9，凑不出数字和 10，故不存在好整数。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有 $num$ 位、数字和为 $sum$ 的整数，计算分数取最大。$num$ 位整数的数量是 $10^{num}$，$num$ 可达 $2 \times 10^5$，完全不可行。即使只枚举「数字和的分配方案」，数量也是 $O(\binom{sum + num}{num})$ 级。

### 3.2 核心观察：平方是凸函数，最优解把数字「挤到两端」

![数字在 0～9 之间：把一个数减 1、另一个加 1，平方和会变大](images/bw168_q2_convex_exchange.svg)

关键不等式：设两个数字 $0 < b \le a < 9$，把 $b$ 减 1、$a$ 加 1（数字和不变），平方和的变化为

$$\bigl[(a+1)^2 + (b-1)^2\bigr] - \bigl[a^2 + b^2\bigr] = 2(a-b) + 2 > 0 .$$

也就是说，**只要有两个数字都严格落在 $1 \sim 8$ 之间，就能通过「劫富济贫」让分数严格变大**。于是最优解里**至多有一个数字**取值在 $1 \sim 8$ 之间，其余数字只能是 $0$ 或 $9$。

进一步，把所有能变成 9 的都变成 9（每次把 $r \ge 1$ 的部分往上推），得到唯一候选结构：

$$\underbrace{9,\dots,9}_{q \text{ 个}},\quad r,\quad \underbrace{0,\dots,0}_{\text{其余}} \qquad q = \left\lfloor \frac{sum}{9} \right\rfloor,\quad r = sum \bmod 9 .$$

- 若 $r > 0$：位数占用 $q + 1$，要求 $q + 1 \le num$；
- 若 $r = 0$：位数占用 $q$，要求 $q \le num$。

两条合起来就是**存在性条件** $1 \le sum \le 9 \cdot num$（$sum \ge 1$ 由约束保证）。

最后处理并列：结构固定后，把数字按**降序**排列（先 $q$ 个 9，再 $r$，再补 0）即可得到同分数下数值最大的数。

![算法流程：可行性判定 → 9 的个数 → 余数 → 补零](images/bw168_q2_algorithm_flow.svg)

### 3.3 算法流程

```text
1. 若 sum > 9 * num：返回 ""
2. q = sum // 9，r = sum % 9
3. 结果 = "9" * q
4. 若 r > 0：结果 += str(r)
5. 结果 += "0" * (num - q - (1 if r > 0 else 0))
6. 返回结果
```

### 3.4 示例演算

![三个示例的构造过程](images/bw168_q2_example_walkthrough.svg)

| 输入 | $9 \cdot num$ | 可行？ | $q$ | $r$ | 构造 | 输出 |
|------|---------------|--------|-----|-----|------|------|
| $num=2, sum=3$ | 18 | 是 | 0 | 3 | "3" + 1 个 0 | `30` |
| $num=2, sum=17$ | 18 | 是 | 1 | 8 | "9" + "8" | `98` |
| $num=1, sum=10$ | 9 | 否（10 > 9） | — | — | — | `""` |

再验证分数：`30` → $9+0 = 9$，`98` → $81+64 = 145$，与题面一致。

## 4. 算法细节

1. **可行性只需一条判据**：$sum \le 9 \cdot num$。因为 $sum \ge 1$ 时总能构造出 $num$ 位数（首位放 $r$ 或 9，其余补 0）。
2. **不要真的逐位模拟**：$num$ 可达 $2 \times 10^5$，用字符串重复（`string(q, '9')`、`'0' * k`）直接构造，$O(num)$。
3. **$r = 0$ 时不加余数位**：`sum = 9` 且 $num = 3$ 时结果是 `900`（$q=1, r=0$，补 2 个 0），不是 `909`。
4. **$q = num$ 的情形**：$sum = 9 \cdot num$，结果是 $num$ 个 9，补零个数为 0。
5. **$q = 0$ 且 $r > 0$**：首位就是 $r$，天然满足「不能有前导零」。
6. **并列规则**：结构唯一，按降序排列即最大；不需要额外比较。
7. **大数不参与运算**：结果是字符串，$2 \times 10^5$ 位也不会溢出；只要 $q, r, num$ 用整数算。

## 5. 正确性证明

**引理 1（挤压引理）**：设一串数字满足 $0 < b \le a < 9$，把 $a$ 加 1、$b$ 减 1 后，数字和不变且平方和严格增大。

**证明**：数字和显然不变。平方和之差为 $(a+1)^2 + (b-1)^2 - a^2 - b^2 = 2a + 1 - 2b + 1 = 2(a-b) + 2 \ge 2 > 0$。∎

**引理 2（最优解至多一个「中间数字」）**：若某组数字使平方和最大，则其中至多一个数字落在 $1 \sim 8$ 之间，其余数字只能是 $0$ 或 $9$。

**证明**：若有两个数字都落在 $1 \sim 8$ 内，取较大的 $a$ 与较小的 $b$（$0 < b \le a < 9$），由引理 1 把 $b$ 减 1、$a$ 加 1 可使数字和不变而平方和严格增大，与最大性矛盾。故除至多一个数字外，其余数字必须取边界值 $0$ 或 $9$。∎

**引理 3（构造唯一）**：设 $q = \lfloor sum/9 \rfloor$、$r = sum \bmod 9$，则任何达到最大平方和的数字串恰由 $q$ 个 9、（$r>0$ 时）一个 $r$、以及 $num - q - [r>0]$ 个 0 组成。

**证明**：由引理 2，数字只能取 $0, 9$ 和至多一个 $r \in [1,8]$。设 9 的个数为 $q'$、中间值为 $r'$（可为 0）、0 的个数为 $z$，则 $9q' + r' = sum$ 且 $q' + [r' > 0] + z = num$。由 $0 \le r' \le 8$ 知 $q' = \lfloor sum/9 \rfloor = q$、$r' = sum \bmod 9 = r$，从而 $z$ 被唯一确定。∎

**定理**：算法输出为分数最大的好整数中数值最大者；无解时输出空串。

**证明**：若 $sum > 9num$，则任何 $num$ 位数的数字和都不超过 $9num$，无好整数，返回空串正确。否则算法按引理 3 的唯一最优结构构造，且把 9、$r$、0 按降序排列——对固定数字多重集，降序排列得到数值最大的排列；由于最优多重集唯一，它也就是分数并列最大者中最大的数。故输出正确。∎

## 6. 复杂度分析

- **时间**：$O(num)$。只做常数次整数运算与长度为 $num$ 的字符串构造。
- **空间**：$O(num)$。输出字符串本身；额外变量为常数个。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    string maxSumOfSquares(int num, int sum) {
        if ((long long)sum > 9LL * num) return "";
        int q = sum / 9, r = sum % 9;
        string res;
        res.append(q, '9');
        if (r > 0) res.push_back(char('0' + r));
        int zeros = num - q - (r > 0 ? 1 : 0);
        res.append(zeros, '0');
        return res;
    }
};
```

### Python

```python
class Solution:
    def maxSumOfSquares(self, num: int, sum: int) -> str:
        if sum > 9 * num:
            return ""
        q, r = divmod(sum, 9)
        res = "9" * q
        if r > 0:
            res += str(r)
        res += "0" * (num - q - (1 if r > 0 else 0))
        return res
```

## 8. 边界情况与易错点

1. **不可行判据**：只有 $sum > 9 \cdot num$ 一种。$sum \ge 1$ 是约束保证的；若 $sum = 0$ 且 $num \ge 2$，理论上还可以是 `10…0`（数字和 1）——不适用本题。
2. **$r = 0$ 时不要多加一位**：$num=3, sum=9$ 的答案是 `900`（$q=1$，补 2 个 0），写成 `909` 会让数字和变成 18。
3. **$q = num$**：$sum = 9num$ 时补零个数为 0，不能出现负数（C++ 的 `append(负数)` 会抛异常，Python 的 `"0" * 负数` 得到空串，行为不一致，务必保证 $num - q - [r>0] \ge 0$）。
4. **$num = 1$**：$sum \le 9$ 时输出单个数字；$sum > 9$ 输出空串。
5. **前导零**：构造总是先放 9 或 $r$（$\ge 1$），不会产生前导零。
6. **并列取最大**：不要输出升序（如 `09`），必须是降序（`90`）。
7. **位数与字符串长度一致**：返回前可用 `res.size() == num` 自查，这是最有效的本地断言。

**延伸思考**：若目标改成**最小化**平方和，方向相反——应让各位数字尽量平均（差不超过 1），这是一个经典的「均分」构造：先令每位数取 $\lfloor sum/num \rfloor$，再把余数分给前几位。若把平方换成 $k$ 次方，$k > 1$ 时凸性仍成立，结论不变；$k = 1$ 时所有好整数分数相同，直接返回降序排列的最大数即可。若限制某些数位不能取某些值，问题会变成带约束的可行性判定，通常需要从高位贪心 + 后缀可行性检查（数位 DP 的贪心形式）。
