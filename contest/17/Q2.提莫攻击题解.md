# LeetCode 提莫攻击 题解

## 1. 题目概述

- **标题 / 题号**：提莫攻击（#495，easy）
- **链接**：https://leetcode.cn/problems/teemo-attacking/
- **来源**：LeetCode 第 17 场周赛 Q2
- **难度**：简单
- **标签**：数组、模拟

**题意**：提莫在第 $t$ 秒攻击艾希，会让艾希在**闭区间** $[t,\ t + \text{duration} - 1]$ 内中毒。若在下一次中毒计时结束**前**再次攻击，计时器会**重置**，从新的攻击时刻起重新计 $\text{duration}$ 秒。给定**非递减**的攻击时刻数组 `timeSeries` 与持续时间 `duration`，求艾希处于中毒状态的**总秒数**。

**约束**：

- $1 \le \text{timeSeries.length} \le 10^4$
- $0 \le \text{timeSeries}[i],\ \text{duration} \le 10^7$
- `timeSeries` 按**非递减**顺序排列（允许相邻相等）

> 💡 一句话：答案就是所有区间 $[t_i,\ t_i + \text{duration} - 1]$ 的**并集长度**。所谓「重置」只是说：重叠的那部分不要重复计数。

## 2. 示例

**示例 1**

```text
输入：timeSeries = [1,4], duration = 2
输出：4
解释：第 1 秒攻击覆盖 [1,2]；第 4 秒攻击覆盖 [4,5]。
      两段之间有空档，不重叠，共 2 + 2 = 4 秒。
```

**示例 2**

```text
输入：timeSeries = [1,2], duration = 2
输出：3
解释：第 1 秒攻击覆盖 [1,2]；第 2 秒再次攻击使计时器重置，覆盖 [2,3]。
      第 2 秒被两段同时覆盖，只算一次，共 2 + 1 = 3 秒。
```

**补充示例（非官方，用来说明「空档」）**

```text
输入：timeSeries = [1,2,5], duration = 2
输出：5
解释：覆盖区间为 [1,2]、[2,3]、[5,6]，并集是 {1,2,3,5,6}；
      第 4 秒没有任何攻击覆盖，共 2 + 1 + 2 = 5 秒。
```

## 3. 解题思路

### 3.1 暴力思路

最直白的做法是**按秒模拟**：开一个布尔数组或哈希集合，对每次攻击把 $[t,\ t + \text{duration} - 1]$ 里的每一秒都标记为「中毒」，最后数标记的个数。这个做法完全正确，但对每次攻击都要写 $d = \text{duration}$ 次，最坏 $n \cdot d = 10^4 \times 10^7 = 10^{11}$ 次写入，必然超时；即便换成「只扫时间轴上的每一个时刻」，也有约 $2 \times 10^7$ 次操作，是「刚好能过」而不是正解。

另一条朴素路线是**真的合并区间**：按顺序维护当前段的右端点，逐段判断是否重叠、累加长度。它已经是 $O(n)$ 的正确解法，但需要维护右端点和额外的分支判断。本题所有区间长度都等于 $\text{duration}$，因此可以进一步化简成一行加法公式。

### 3.2 核心观察：只看相邻两次的间隔

![区间重叠与相邻间隔的关系](images/wc17_q2_interval_merge_concept.svg)

记 $d = \text{duration}$，第 $i$ 次攻击覆盖 $I_i = [t_i,\ t_i + d - 1]$。因为 `timeSeries` 非递减，前 $i-1$ 次攻击覆盖的**最右端点**一定来自**最近一次**攻击：

$$R_{i-1} = \max_{j < i}\bigl(t_j + d - 1\bigr) = t_{i-1} + d - 1$$

（$t_{i-1}$ 是所有 $t_j$ 中最大的，加上同一个 $d - 1$ 后仍最大。）于是第 $i$ 次攻击「新增」的秒数，就是 $I_i$ 中落在 $R_{i-1}$ **右侧**的那一截：

$$\bigl[\max(t_i,\ R_{i-1} + 1),\ t_i + d - 1\bigr]$$

它的长度是

$$\text{new}_i = t_i + d - 1 - \max\bigl(t_i,\ R_{i-1} + 1\bigr) + 1 = \min\bigl(d,\ t_i - t_{i-1}\bigr)$$

**怎么读这个式子**：设间隔 $g = t_i - t_{i-1}$。

- $g < d$：上一次的毒性还没结束，本次前 $d - g$ 秒落在已覆盖区域内，只有后面 $g$ 秒是新的，新增 $g$ 秒；
- $g \ge d$：上一次早已结束，本次整段 $d$ 秒都是新的，新增 $d$ 秒。

两种情形被 $\min(d, g)$ 一个式子统一起来。于是总中毒秒数为

$$\text{ans} = d + \sum_{i=1}^{n-1}\min\bigl(d,\ t_i - t_{i-1}\bigr)$$

其中第一项是第一次攻击的完整 $d$ 秒。

### 3.3 算法流程

![线性扫描的流程](images/wc17_q2_contribution_flow.svg)

```text
1. ans = duration                      // 第一次攻击整段都算
2. for i = 1 .. n-1:
       gap = timeSeries[i] - timeSeries[i-1]
       ans = ans + min(duration, gap)
3. 返回 ans
```

注意循环里**不需要**保存「当前覆盖到哪一秒」——非递减保证覆盖的最右端点就是上一次攻击的右端点，这个信息完全隐含在 `gap` 里。这正是把「区间并」降成「相邻差」的关键。

### 3.4 示例演算

![示例 [1,2,5] 的逐次走查](images/wc17_q2_walkthrough.svg)

对 `timeSeries = [1,2,5]`、`duration = 2`：

| $i$ | $t_i$ | $t_i - t_{i-1}$ | $\min(2,\ \cdot)$ | 累计 ans |
|-----|-------|-----------------|-------------------|----------|
| 0 | 1 | — | +2（基准） | 2 |
| 1 | 2 | 1 | +1 | 3 |
| 2 | 5 | 3 | +2 | 5 |

覆盖区间为 [1,2]、[2,3]、[5,6]，并集 {1,2,3,5,6} 共 5 秒；第 4 秒落在 $g = 3 > d = 2$ 留下的空档里，与公式结果一致。

## 4. 算法细节

1. **基准项**：`ans` 初值取 `duration`，对应 $i = 0$。题目保证 $n \ge 1$，第一次攻击一定存在；若把该函数复用到允许空数组的场景，需要先判空返回 0。
2. **`gap` 可以为 0**：同一秒内多次攻击是合法的（非递减允许相等），此时 $\min(d, 0) = 0$，表示这次攻击整段落在已覆盖区域内、不新增任何秒数——不要写成「每次至少加 1 秒」。
3. **端点恰好相接**：$g = d$ 时 $I_{i-1} = [t_{i-1},\ t_i - 1]$ 与 $I_i = [t_i,\ t_i + d - 1]$ 并不重叠，本次应新增 $d$ 秒；$\min$ 在 $g = d$ 处恰取 $d$，等号天然正确，不必特判。
4. **不要写成分支**：`if gap < duration: ans += gap else: ans += duration` 与 $\min$ 等价，但多分支容易漏掉等号、也更容易写错；直接 `min` 最稳。
5. **整数宽度**：所有区间都落在 $[0,\ t_{n-1} + d - 1]$ 内，答案上界为 $t_{n-1} + d \le 2 \times 10^7$，32 位有符号整数足够；但 C++ 里仍建议用 `long long` 累加、并用 `min<long long>`，避免 `size_t` 与 `int` 混算时的隐式转换隐患（Python 大整数无此顾虑）。
6. **不要排序**：输入已非递减，再排序是 $O(n \log n)$ 的纯浪费；同理也不必构造区间数组，直接读相邻两项即可。
7. **对拍公式**：等价写法 $\text{ans} = n \cdot d - \sum_{i \ge 1}\max(0,\ d - g_i)$ 把「重叠部分」显式扣掉，写暴力自检时可以拿来交叉验证。
8. **只读输入**：算法只线性扫描一次 `timeSeries`，不修改原数组，额外空间 $O(1)$。

## 5. 正确性证明

**引理 1（最右端点）**：对任意 $j < i$，有 $t_j + d - 1 \le t_{i-1} + d - 1$；因此前 $i-1$ 次攻击覆盖的并集包含于 $(-\infty,\ t_{i-1} + d - 1]$。

**证明**：由 `timeSeries` 非递减得 $t_j \le t_{i-1}$，两边同加 $d - 1$ 即得。并集中任一元素都属于某个 $I_j$，故它不超过 $t_j + d - 1 \le t_{i-1} + d - 1$。∎

**引理 2（单次新增量）**：对 $i \ge 1$，第 $i$ 次攻击相对前 $i-1$ 次攻击新增的中毒秒数为 $\min\bigl(d,\ t_i - t_{i-1}\bigr)$。

**证明**：记 $R = t_{i-1} + d - 1$。由引理 1，前 $i-1$ 次覆盖的部分都在 $(-\infty,\ R]$ 中，故新增部分为

$$\bigl[\max(t_i,\ R + 1),\ t_i + d - 1\bigr]$$

（区间长度按「下端点大于上端点则为 0」理解）。分两种情形：

- 若 $t_i \le R$，新增长度 $= t_i + d - 1 - (R + 1) + 1 = t_i - t_{i-1}$，且此时 $t_i - t_{i-1} \le d - 1 < d$，即 $\min(d,\ t_i - t_{i-1}) = t_i - t_{i-1}$；
- 若 $t_i > R$，整个 $I_i$ 都是新的，新增长度 $= d$，而此时 $t_i - t_{i-1} \ge d$，故 $\min(d,\ t_i - t_{i-1}) = d$。

合并两种情形即得新增量为 $\min(d,\ t_i - t_{i-1})$。∎

**定理（公式正确）**：$\text{ans} = d + \sum_{i=1}^{n-1}\min\bigl(d,\ t_i - t_{i-1}\bigr)$ 等于 $\bigl|\bigcup_{i=0}^{n-1} I_i\bigr|$。

**证明**：对攻击次数 $k$ 归纳证明「前 $k$ 次攻击的并集大小为 $d + \sum_{i=1}^{k-1}\min(d,\ t_i - t_{i-1})$」。$k = 1$ 时并集就是 $I_0$，大小为 $d$，成立。设 $k-1$ 时成立，加入 $I_{k-1}$ 后，新增部分与旧并集不相交（旧并集在 $(-\infty, R]$ 内，新增部分在 $R+1$ 之后），故并集基数等于旧基数加上由引理 2 给出的 $\min(d,\ t_{k-1} - t_{k-2})$，恰好是公式中新增的一项。归纳完成，取 $k = n$ 即得结论。∎

**推论**：若所有间隔都 $\ge d$，答案为 $n \cdot d$；若所有攻击都发生在同一秒，答案为 $d$。

## 6. 复杂度分析

- **时间**：$O(n)$。一次遍历共 $n - 1$ 轮，循环体只有一次减法、一次取 $\min$、一次加法；相比「逐秒标记」的 $O(n \cdot d)$ 快了多个数量级。
- **空间**：$O(1)$。除输入数组外只用常数个整型变量（`ans`、`gap`、下标），不构造区间列表、不使用集合或哈希表。
- **常数**：全部是整数加减与比较，无乘除、无取模、无哈希，$n = 10^4$ 时实际运行为微秒级。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int findPoisonedDuration(vector<int>& timeSeries, int duration) {
        long long ans = duration;                  // 第一次攻击完整贡献 duration 秒
        for (size_t i = 1; i < timeSeries.size(); ++i) {
            long long gap = (long long)timeSeries[i] - timeSeries[i - 1];
            ans += min<long long>(duration, gap);  // 只累加「上一次没覆盖到」的部分
        }
        return (int)ans;
    }
};
```

### Python

```python
class Solution:
    def findPoisonedDuration(self, timeSeries: list[int], duration: int) -> int:
        ans = duration                          # 第一次攻击整段都算
        for prev, cur in zip(timeSeries, timeSeries[1:]):
            ans += min(duration, cur - prev)    # 间隔小于 duration 时只新增 gap 秒
        return ans
```

## 8. 边界情况与易错点

1. **同一秒多次攻击**：`timeSeries = [1,1,1]`、`duration = 3` 的答案是 3 而不是 9。若写成「每次无条件加 $d$、再把重叠扣掉」，重叠项会重复扣减；$\min(d, 0) = 0$ 的写法天然正确。
2. **`duration = 0`**：任何攻击都不产生中毒秒，答案为 0；此时 $\min(0,\ g) = 0$，公式自洽，不需要额外特判。
3. **只有一次攻击**：$n = 1$ 时循环不执行，直接返回 `duration`；若错误地从 $i = 0$ 开始循环，会把第一次攻击算两遍。
4. **端点恰好相接**：$g = d$ 时两段不重叠、新增 $d$ 秒；若写成 `gap < duration` 才加 `gap`、否则加 `duration`，也能对，但漏掉等号就会少算。
5. **空数组**：本题约束 $n \ge 1$，无需判空；若把函数复用到允许空输入的场景，应显式返回 0（当前实现会返回 `duration`）。
6. **类型与溢出**：答案上界是 $t_{n-1} + d \le 2 \times 10^7$，`int` 够用；但 `timeSeries[i] - timeSeries[i-1]` 若在无符号语境下运算会回绕，显式转 `long long` 更稳妥。
7. **误以为要严格递增**：题面是「非递减」，相等元素合法，读题时不要自行加假设；否则会误写「重复时刻需要去重」之类的多余逻辑。
8. **复杂度误判**：按秒标记的复杂度是 $O(n \cdot d)$ 而不是 $O(n)$；$d \le 10^7$、$n \le 10^4$ 时操作数可达 $10^{11}$，直接超时。

**延伸思考**：

- 若每次攻击的持续时间不同（第 $i$ 次为 $d_i$），「只看上一次」不再成立——一次很早但持续极长的攻击可能覆盖到很晚。此时应维护 $\text{maxR} = \max(\text{maxR},\ t_i + d_i - 1)$，新增量在更新前计算为 $\max(0,\ t_i + d_i - 1 - \text{maxR})$，复杂度仍是 $O(n)$。
- 若输入不保证有序，先排序变成 $O(n \log n)$，或改用差分数组做到 $O(n + \text{值域})$。
- 若把「是否中毒」换成「中毒层数」（可叠加伤害），问题变成对区间做 $+1$ 的区间加，用差分/扫描线统计每一秒的层数，再用前缀和求总伤害。
