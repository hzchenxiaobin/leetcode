# LeetCode 二叉搜索树中的众数 题解

## 1. 题目概述

- **标题 / 题号**：二叉搜索树中的众数（#501，easy）
- **链接**：https://leetcode.cn/problems/find-mode-in-binary-search-tree/
- **来源**：LeetCode 第 17 场周赛 Q1
- **难度**：简单
- **标签**：树、深度优先搜索、二叉搜索树、二叉树

**题意**：给定一棵**含重复值**的二叉搜索树（BST）的根 `root`，返回树中**出现频率最高**的所有元素（众数）。若有多个众数，按**任意顺序**返回。

> BST 的定义在此题里被放宽为「左子树 $\le$ 根 $\le$ 右子树」，所以重复值会出现在根的同侧，中序遍历依然是非降序的。

**约束**：

- 结点数在 $[1, 10^4]$ 内
- $-10^5 \le \text{Node.val} \le 10^5$
- 进阶要求：不使用额外空间（递归隐式栈不计）

## 2. 示例

**示例 1**

```text
输入：root = [1,null,2,2]
输出：[2]
解释：中序序列为 1, 2, 2，值 2 出现 2 次、值 1 出现 1 次，故众数为 [2]。
```

**示例 2**

```text
输入：root = [0]
输出：[0]
单结点，唯一的值就是众数。
```

**补充示例（并列众数）**

```text
输入：root = [4,2,6,2,2,6,6]    输出：[2,6]（顺序任意）
解释：中序序列 2,2,2,4,6,6,6，值 2 与 6 各出现 3 次，并列众数。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的做法：遍历整棵树，用哈希表 `cnt[val]` 统计频次，再取最大值对应的所有 $val$；时间 $O(n)$、空间 $O(n)$。若改成「全部取出后排序再扫描」，则是 $O(n\log n)$ 时间、$O(n)$ 空间。

**问题**：完全没有用到「这是一棵 BST」这一条件，而且进阶要求「不使用额外空间」时，哈希表本身就成了瓶颈。

### 3.2 核心观察：中序遍历把树拍成有序数组

![BST 中序遍历得到非降序序列](images/wc17_q1_inorder_sorted.svg)

**观察**：BST 的中序遍历序列**非降序**。于是同一个值的所有出现必然**连续排在一起**，形成若干「等值连续段」。

设中序序列为 $a_1 \le a_2 \le \cdots \le a_n$，则每个值的总频次恰好等于它所在连续段的长度：

$$\text{freq}(v) = \bigl|\{\,i : a_i = v\,\}\bigr| = \text{段长}$$

所以**众数问题退化为「在非降序序列里找最长等值连续段」**，而这只需要一边扫描一边维护三个量：

- `cnt`：当前值已经连续出现几次；
- `best`：目前为止见过的最大频次；
- `res`：频次恰好等于 `best` 的所有值。

于是既不需要哈希表，也不需要排序。

### 3.3 算法流程：Morris 线索化中序遍历

![Morris 中序遍历的建线索与拆线索](images/wc17_q1_morris_thread.svg)

即使不用哈希表，递归/显式栈仍要 $O(h)$ 空间；$h$ 最坏是 $10^4$（退化成链），Python 默认递归上限只有 1000，直接递归会 `RecursionError`。**Morris 遍历**用「借指针」的办法把空间也压到 $O(1)$。

对当前结点 `cur`：

1. 若 `cur.left` 为空：**访问** `cur`，然后 `cur = cur.right`（可能是线索，直接回到祖先）。
2. 否则找 `cur` 左子树中的最右结点 `pre`（即中序前驱）：
   - `pre.right` 为空 → 令 `pre.right = cur`（**建线索**），`cur = cur.left`，本步**不访问**；
   - `pre.right == cur` → 说明左子树已走完，令 `pre.right = null`（**拆线索**），**访问** `cur`，再 `cur = cur.right`。

线索恢复的判据必须是**指针相等** `pre.right == cur`；本题值可以重复，用值来比较会误判。

单次「访问」时的状态转移（与 §3.2 的规则一致）：

```text
cnt = (prev == cur.val) ? cnt + 1 : 1
if cnt > best:   best = cnt; res = [cur.val]        # 出现更强的候选
elif cnt == best: res.append(cur.val)               # 追平，追加为并列众数
prev = cur.val
```

### 3.4 示例演算

![示例 1 的逐步走查](images/wc17_q1_walkthrough.svg)

对 `root = [1,null,2,2]`，中序访问顺序是 $1,2,2$：

| 访问值 | `cnt` | `best` | `res` | 说明 |
|--------|-------|--------|-------|------|
| 1 | 1 | 1 | `[1]` | 第一个值，`cnt = 1 > best = 0`，清空后放入 |
| 2 | 1 | 1 | `[1,2]` | 新值 `cnt = 1 == best`，追加为并列候选 |
| 2 | 2 | 2 | `[2]` | 同值 `cnt = 2 > best`，旧的 `[1,2]` 全部作废，只留 `[2]` |

最终 `res = [2]`。全程没有使用哈希表，也没有使用栈：`1` 的右指针在中序遍历时被临时指向 `2`，访问完又被还原，所以额外空间是 $O(1)$（不计输出数组）。

## 4. 算法细节

1. **哨兵与前驱**：`prev` 初值不硬编码特殊值（值域含 $-10^5$，看似安全但不可靠）。C++ 用 `bool hasPrev` 配 `long long prev`，Python 用 `None`；空树也自然返回空数组。
2. **`best` 从 0 开始是安全的**：第一次访问时 `cnt = 1 > 0`，一定走「清空 + 放入」分支，不会把空数组状态漏到结果里。
3. **Morris 的两个 `continue`**：建线索后必须 `continue`（此时不能访问 `cur`，否则顺序就错了）；拆线索后要**继续往下执行访问逻辑**，不能 `continue`。
4. **线索判据用指针**：`pre.right == cur` 而不是 `pre.val == cur.val`。重复值场景下值比较会立刻失效。
5. **不要写递归**：$10^4$ 个结点的有序链深度为 $10^4$，C++ 可能爆栈、Python 必然超过默认递归上限；Morris 是纯迭代，天然免疫。
6. **输出无序**：题目允许任意顺序，`res` 按「首次达到当前最大频次的顺序」收集，无需再排序；若需要升序，直接对 `res` 排序即可（`res` 实际上天然升序，因为中序序列非降序）。

## 5. 正确性证明

**引理 1（中序非降序）**：对任意满足「左 $\le$ 根 $\le$ 右」的 BST，其中序遍历序列 $a_1 \le a_2 \le \cdots \le a_n$。

**证明**：对树高归纳。叶结点序列长度为 1，成立。设根为 $r$，左子树中序序列 $L$、右子树中序序列 $R$，整树中序为 $L \cdot [r] \cdot R$。由归纳假设 $L$ 与 $R$ 各自非降序；由 BST 定义，$L$ 中每个值 $\le r$，$R$ 中每个值 $\ge r$，故拼接处也满足非降序。∎

**引理 2（等值连续）**：在非降序序列中，若 $a_i = a_j$ 且 $i < k < j$，则 $a_k = a_i$。

**证明**：由非降序有 $a_i \le a_k \le a_j$，而 $a_i = a_j$，夹逼得 $a_k = a_i$。∎

**引理 3（状态不变量）**：每次「访问」结束后，设已访问前缀为 $a_1..a_m$，则

- `cnt` $= \max\{\,t : a_{m-t+1} = \cdots = a_m\,\}$，即当前值在前缀末尾的连续出现次数；
- `best` $= \max_{v} \text{freq}_{\text{prefix}}(v)$；
- `res` $= \{\,v : \text{freq}_{\text{prefix}}(v) = \text{best}\,\}$，每个值恰好出现一次。

**证明**：对 $m$ 归纳。$m = 1$ 时 `cnt = best = 1`，`res = {a_1}`，成立。设前缀 $a_1..a_{m-1}$ 满足不变量，访问 $a_m$：

- 若 $a_m = a_{m-1}$，则 `cnt` 加一，恰好是新的末尾连续长度；若 $a_m \ne a_{m-1}$，由非降序知 $a_m > a_{m-1}$，故 $a_m$ 严格大于此前所有值、是首次出现，`cnt = 1` 也正确。
- 若 `cnt > best`，说明 $a_m$ 的频次严格超过旧最大值，旧 `res` 中的值全部不再是众数，清空后放入 $a_m$，新 `best = cnt`，成立；
- 若 `cnt == best`，$a_m$ 与现有众数并列，追加，成立；
- 若 `cnt < best`，$a_m$ 不是众数，不动作，成立。∎

**定理**：算法返回的 `res` 恰为树中所有众数（频次最大者）构成的集合。

**证明**：Morris 遍历按中序访问每个结点恰好一次（线索建一次、拆一次，不改变访问顺序），故遍历结束时前缀即完整序列。由引理 1、2，每个值的频次等于其连续段长度，遍历中每个值只在段内首次出现时被计入一次，段内后续出现通过 `cnt` 累加，因此 `best` 与各值频次一致。由引理 3，结束时 `best` 为全局最大频次，`res` 恰为频次等于 `best` 的全部值，无遗漏、无多余。∎

## 6. 复杂度分析

- **时间**：$O(n)$。Morris 遍历中每条树边至多被走两遍（一次建线索、一次拆线索），访问逻辑是 $O(1)$ 的状态更新；$n \le 10^4$ 时远低于时限。
- **空间**：$O(1)$ 额外空间（不计输出）。不使用哈希表、栈或递归，只临时改写已有结点的 `right` 指针，遍历结束时全部还原；输出数组 `res` 属于答案本身，不计入。

## 7. 参考代码

### C++

```cpp
// TreeNode 结构由题目给出：int val; TreeNode *left, *right;
class Solution {
public:
    vector<int> findMode(TreeNode* root) {
        vector<int> res;
        TreeNode* cur = root;
        long long prev = 0;
        bool hasPrev = false;
        int cnt = 0, best = 0;

        while (cur) {
            if (cur->left) {
                TreeNode* pre = cur->left;
                while (pre->right && pre->right != cur) pre = pre->right;   // 找中序前驱
                if (!pre->right) {                 // 建线索：借右空指针当回程路
                    pre->right = cur;
                    cur = cur->left;
                    continue;                      // 本步不访问
                }
                pre->right = nullptr;              // 拆线索，恢复原树
            }
            // —— 访问 cur ——
            if (hasPrev && prev == cur->val) ++cnt;
            else cnt = 1;
            if (cnt > best) {
                best = cnt;
                res.clear();
                res.push_back(cur->val);
            } else if (cnt == best) {
                res.push_back(cur->val);
            }
            prev = cur->val;
            hasPrev = true;
            cur = cur->right;                      // 可能是线索，直接回到祖先
        }
        return res;
    }
};
```

### Python

```python
# TreeNode 结构由题目给出：self.val, self.left, self.right
class Solution:
    def findMode(self, root: "TreeNode | None") -> list[int]:
        res = []
        cur, prev = root, None
        cnt = best = 0            # cnt：当前值的末尾连续次数；best：历史最大频次

        while cur:
            if cur.left:
                pre = cur.left
                while pre.right and pre.right is not cur:
                    pre = pre.right
                if pre.right is None:      # 建线索，钻进左子树
                    pre.right = cur
                    cur = cur.left
                    continue
                pre.right = None           # 拆线索，恢复原树，继续访问 cur

            # —— 访问 cur ——
            if prev is not None and prev == cur.val:
                cnt += 1
            else:
                cnt = 1
            if cnt > best:
                best = cnt
                res = [cur.val]
            elif cnt == best:
                res.append(cur.val)
            prev = cur.val
            cur = cur.right                # 可能是线索，O(1) 回到祖先

        return res
```

## 8. 边界情况与易错点

1. **只有一个结点**：`[0]` → `[0]`。`best` 初值 0 保证第一次访问一定进入「清空 + 放入」分支。
2. **全部结点同值**：如 `[5,5,5]` 或 $10^4$ 个 42 组成的链，`best = n`，`res` 只含一个值；此时递归写法最容易爆栈（深度 $10^4$），Morris 不受影响。
3. **多个并列众数**：如 `[4,2,6,2,2,6,6]` → `[2,6]`。注意 `cnt == best` 时只能**追加**，不能清空；返回顺序任意，评测按集合比较。
4. **`cnt > best` 必须清空**：曾经收集到的众数在更强者出现后全部失效，只清 `best` 不清 `res` 会多输出。
5. **中序前驱的定义**：必须走到左子树的**最右**结点，而不是左孩子本身；写错会破坏遍历顺序甚至死循环。
6. **线索判据用值比较会死循环**：重复值下 `pre.val == cur.val` 恒成立，必须先建后拆的判断就会永远走「建线索」分支。
7. **`cur = cur.right` 有两种含义**：真实右孩子或刚建好的线索，两者都恰指向「中序下一个结点」，无需区分；但**不要**为了图省事复制树或存数组，那会退化回 $O(n)$ 空间。
