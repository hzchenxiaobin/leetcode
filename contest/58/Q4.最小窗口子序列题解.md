# LeetCode 最小窗口子序列 题解

## 1. 题目概述

- **标题 / 题号**：最小窗口子序列（#727，hard）
- **链接**：https://leetcode.cn/problems/minimum-window-subsequence/
- **来源**：LeetCode 第 58 场周赛 Q4
- **难度**：困难
- **标签**：字符串, 动态规划, 滑动窗口

**题意**：给定两个字符串 `s1` 和 `s2`，在 `s1` 中找一个**连续子串** $w$，使得 `s2` 是 $w$ 的**子序列**（只要求字符出现的先后顺序一致，不要求连续）。在所有合法的 $w$ 中取**长度最短**者；长度相同时取**起点最靠左**者；若不存在则返回空串 `""`。

**约束**：

- $1 \le \lvert s1 \rvert \le 20000$
- $1 \le \lvert s2 \rvert \le 100$
- `s1`、`s2` 仅由小写英文字母组成
- 无合法窗口时返回 `""`

> 💡 本题为会员题，题面以英文镜像给出，上文已按题意翻译整理。

## 2. 示例

**示例 1**

```text
输入：s1 = "abcdebdde", s2 = "bde"
输出："bcde"
解释：窗口 [1,4] 的 "bcde" 与窗口 [5,8] 的 "bdde" 长度都是 4，
      取起点更小的 "bcde"；"deb" 里虽有 b、d、e，但顺序不对，不是合法窗口。
```

**示例 2**

```text
输入：s1 = "jmeqksfrsdcmsiwvaovztaqenprvpnbstl", s2 = "u"
输出：""
解释：s1 中根本没有字符 'u'，不存在任何合法窗口。
```

**示例 3（补充）**

```text
输入：s1 = "aaabbbccc", s2 = "abc"
输出："abbbc"
解释：窗口 [2,6] 中 a、b、c 依次出现，长度 5；再往里缩就会丢掉某个字符。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有窗口 $[l, r]$（共 $O(n^2)$ 个），对每个窗口用双指针判断 `s2` 是否为它的子序列（$O(m)$），总复杂度 $O(n^2 m)$。$n = 2\times 10^4$、$m = 100$ 时约 $4\times 10^{10}$ 次操作，必然超时。

即使改成「固定左端 $l$，贪心向右匹配一次」，也要对 $n$ 个起点各扫一遍 `s1`，最坏仍是 $O(nm)$ 起步，而窗口的右端完全没被复用。

### 3.2 核心观察：固定右端，起点越靠右窗口越短

![窗口与子序列的匹配模型](images/wc58_q4_window_subsequence_model.svg)

两个关键性质：

1. **两端可以贴紧**：最优窗口的左端一定是某个 `s2[0]` 的落点，右端一定是某个 `s2[m-1]` 的落点，否则还能再往里缩一格。因此候选窗口由「`s2[0]` 的落点 $k$」与「`s2[m-1]` 的落点 $i$」唯一确定。
2. **起点单调**：固定右端 $i$ 时，合法窗口形如 $[k, i]$，长度 $i - k + 1$ 随 $k$ 增大而减小。**于是每个 $i$ 只需关心「能取到的最大起点」。**

这样一来，问题从「比较 $O(n^2)$ 个窗口」变成「对每个 $i$ 维护 $m$ 个状态」，总状态数 $O(nm)$，正好卡进 $20000 \times 100$。

### 3.3 算法流程：最大起点 DP

![dp 状态与转移](images/wc58_q4_dp_transition.svg)

定义

$$dp_i[j] = \max\{\,k \;\mid\; s2[0..j] \text{ 是 } s1[k..i] \text{ 的子序列}\,\}$$

不存在这样的 $k$ 时记 $dp_i[j] = -1$。设 $c = s1[i]$，转移为

$$dp_i[j] = \begin{cases}
dp_{i-1}[j-1], & j \ge 1,\ c = s2[j],\ dp_{i-1}[j-1] \ne -1 \\[2pt]
dp_{i-1}[j], & \text{其他情况}
\end{cases}$$

$$dp_i[0] = \begin{cases} i, & c = s2[0] \\ dp_{i-1}[0], & \text{否则} \end{cases}$$

当 $dp_i[m-1] \ne -1$ 时得到一个候选窗口 $[dp_i[m-1], i]$，用它更新答案：**只有严格更短才覆盖**，于是等长时保留更靠左的起点。

实现上只需一维数组 `dp[0..m-1]` 滚动，并且 $j$ 必须从 $m-1$ **递减**到 $1$ 地原地更新——这样读到 $dp[j-1]$ 时它还是第 $i-1$ 轮的旧值。

### 3.4 示例演算

![示例演算走查表](images/wc58_q4_walkthrough.svg)

对 `s1 = "abcdebdde"`、`s2 = "bde"`（$m = 3$），逐位更新如下：

| $i$ | `s1[i]` | $dp[0]$ | $dp[1]$ | $dp[2]$ | 候选窗口 |
|-----|---------|---------|---------|---------|----------|
| 0 | a | −1 | −1 | −1 | — |
| 1 | b | 1 | −1 | −1 | — |
| 2 | c | 1 | −1 | −1 | — |
| 3 | d | 1 | 1 | −1 | — |
| 4 | e | 1 | 1 | **1** | `[1,4] = bcde`，长 4 ✔ |
| 5 | b | 5 | 1 | 1 | `[1,5]`，长 5 |
| 6 | d | 5 | 5 | 1 | `[1,6]`，长 6 |
| 7 | d | 5 | 5 | 1 | `[1,7]`，长 7 |
| 8 | e | 5 | 5 | 5 | `[5,8] = bdde`，长 4（等长不覆盖） |

第 4 位首次凑齐窗口，长度 4；第 8 位又冒出一个等长的窗口，但起点更大，按「等长不覆盖」的规则保留 `bcde`。

## 4. 算法细节

1. **下标语义**：$dp[j]$ 存的是窗口最左字符在 `s1` 中的下标，所以窗口长度是 $i - dp[j] + 1$，容易漏掉这个 $+1$。
2. **哨兵 −1**：数组初值全为 −1；当 $dp[j-1] = -1$ 时前缀尚未匹配，不能把 −1 当起点传下去，必须显式判断 `dp[j-1] >= 0`。
3. **$dp[0]$ 必须最后更新**：$dp[0]$ 的赋值要放在 $j$ 递减循环**之后**。若放在循环之前，$j=1$ 会读到本轮刚写入的 $dp[0] = i$，相当于让同一个 `s1[i]` 同时匹配 `s2[0]` 和 `s2[1]`，答案会偏短。
4. **倒序原地更新**：$j$ 从 $m-1$ 降到 $1$，保证 $dp[j-1]$ 仍是上一位的旧值；正序会踩到刚被覆盖的格子，和上一条是同一类错误。
5. **等长取最左**：用 `cur < bestLen` 严格小于来更新，长度相同时不覆盖已有记录。由于 $i$ 递增、长度固定时起点随 $i$ 递增，先记录的一定更靠左。
6. **特判**：$m > n$ 时 `s2` 不可能成为子序列，直接返回 `""`；$m = 1$ 时内层循环不执行，$dp[0]$ 本身就是答案，无需额外分支。
7. **不构造子串**：全程只维护 `bestLen` 与 `bestStart`，最后切一次 `s1.substr(bestStart, bestLen)`，避免在循环里反复构造字符串。

## 5. 正确性证明

**引理 1（状态语义）**：$dp_i[j]$ 恰等于集合 $S_{i,j} = \{\,k \mid s2[0..j] \text{ 是 } s1[k..i] \text{ 的子序列}\,\}$ 的最大值；集合为空时 $dp_i[j] = -1$。

**证明**：对 $i$ 归纳。$i < 0$ 时集合为空，初值 −1 成立。设第 $i-1$ 轮结论成立，考察第 $i$ 轮、$j \ge 1$：

- 若 $s1[i] \ne s2[j]$：把 $s2[0..j]$ 嵌入 $s1[k..i]$ 的任何方案都不会用到 $s1[i]$（末字符对不上），故 $S_{i,j} = S_{i-1,j}$，最大值为 $dp_{i-1}[j]$，正是「保留旧值」。
- 若 $s1[i] = s2[j]$：设 $k \in S_{i,j}$。若方案不用 $s1[i]$，则 $k \in S_{i-1,j}$，有 $k \le dp_{i-1}[j]$；若方案用 $s1[i]$ 匹配 $s2[j]$，则 $s2[0..j-1]$ 可嵌入 $s1[k..i-1]$，即 $k \in S_{i-1,j-1}$，有 $k \le dp_{i-1}[j-1]$。反过来 $dp_{i-1}[j-1]$ 一定可行（把 $s1[i]$ 接在其后）。由引理 2，$dp_{i-1}[j] \le dp_{i-1}[j-1]$，故最大值为 $dp_{i-1}[j-1]$，与转移 $dp[j] \leftarrow dp[j-1]$ 一致。

$j = 0$ 时 $S_{i,0}$ 等于 $\{i\}$（当 $s1[i] = s2[0]$）或 $S_{i-1,0}$，与 $dp[0]$ 的转移一致。归纳完成。∎

**引理 2（单调性）**：对任意 $i$ 和 $1 \le j \le m-1$，有 $dp_i[j] \le dp_i[j-1]$。

**证明**：若 $s2[0..j]$ 是 $s1[k..i]$ 的子序列，去掉最后一个字符后 $s2[0..j-1]$ 仍是 $s1[k..i]$ 的子序列，故 $S_{i,j} \subseteq S_{i,j-1}$，前者的最大值不大于后者。∎

**引理 3（答案最优）**：算法记录的窗口长度等于最优长度 $\mathrm{opt}$；在长度达到 $\mathrm{opt}$ 的候选中，记录的起点最小。

**证明**：每个候选 $[dp_i[m-1], i]$ 由引理 1 合法，故记录长度不会小于 $\mathrm{opt}$。设最优窗口为 $[l^*, r^*]$，取 $i = r^*$：$l^* \in S_{r^*,m-1}$，由引理 1 得 $dp_{r^*}[m-1] \ge l^*$，该轮候选长度 $r^* - dp_{r^*}[m-1] + 1 \le r^* - l^* + 1 = \mathrm{opt}$，于是等号成立，记录长度恰为 $\mathrm{opt}$。

再证最左：若 $i_1 < i_2$ 两轮都产生长度 $\mathrm{opt}$ 的候选，其起点分别为 $i_1 - \mathrm{opt} + 1 < i_2 - \mathrm{opt} + 1$，即遍历顺序靠前的那轮起点更小；算法用严格小于更新，保留先记录者，故记录的正是最左起点。∎

**定理**：`minWindow` 返回最短且最靠左的合法窗口；无解时返回空串。

**证明**：由引理 3，长度与起点均达到最优。若全程 $dp_i[m-1] = -1$，则不存在任何合法窗口（否则该窗口右端那一轮必令 $dp[m-1]$ 有效），此时 `bestStart` 仍为 −1，函数返回 `""`，符合题意。∎

## 6. 复杂度分析

- **时间**：$O(nm)$。外层遍历 `s1` 的 $n$ 个位置，内层倒序更新 $m-1$ 个状态，每次转移 $O(1)$；末尾切子串 $O(m)$ 只做一次。$n = 2\times10^4$、$m = 100$ 时约 $2\times10^6$ 次基本操作。
- **空间**：$O(m)$。只用一个长度 $m$ 的一维 `dp` 数组和常数个标量；返回的子串长度最多 $O(n)$，属于输出本身，不计入辅助空间。

## 7. 参考代码

### C++

```cpp
#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    string minWindow(string s1, string s2) {
        int n = s1.size(), m = s2.size();
        if (m > n) return "";

        // dp[j] = 使 s2[0..j] 成为 s1[k..i] 子序列的最大起点 k，-1 表示不存在
        vector<int> dp(m, -1);
        int bestLen = n + 1, bestStart = -1;

        for (int i = 0; i < n; i++) {
            // 倒序原地更新：读到 dp[j-1] 时它还是第 i-1 轮的旧值
            for (int j = m - 1; j >= 1; j--) {
                if (s1[i] == s2[j] && dp[j - 1] >= 0) dp[j] = dp[j - 1];
                // 否则保持不变（旧窗口在 [k, i] 中依旧合法）
            }
            // dp[0] 必须在循环之后更新，否则同一字符会被用两次
            if (s1[i] == s2[0]) dp[0] = i;

            if (dp[m - 1] >= 0) {
                int cur = i - dp[m - 1] + 1;
                if (cur < bestLen) {          // 严格小于 => 等长时保留更左的起点
                    bestLen = cur;
                    bestStart = dp[m - 1];
                }
            }
        }
        return bestStart < 0 ? string("") : s1.substr(bestStart, bestLen);
    }
};
```

### Python

```python
class Solution:
    def minWindow(self, s1: str, s2: str) -> str:
        n, m = len(s1), len(s2)
        if m > n:
            return ""

        # dp[j] = 使 s2[0..j] 成为 s1[k..i] 子序列的最大起点 k，-1 表示不存在
        dp = [-1] * m
        best_len = n + 1
        best_start = -1

        for i, ch in enumerate(s1):
            # 倒序原地更新：读 dp[j-1] 时它还是上一位的旧值
            for j in range(m - 1, 0, -1):
                if ch == s2[j] and dp[j - 1] >= 0:
                    dp[j] = dp[j - 1]
            # dp[0] 最后更新，避免同一个字符被匹配两次
            if ch == s2[0]:
                dp[0] = i

            if dp[m - 1] >= 0:
                cur = i - dp[m - 1] + 1
                if cur < best_len:            # 严格小于 => 等长时保留最左起点
                    best_len = cur
                    best_start = dp[m - 1]

        return s1[best_start:best_start + best_len] if best_start >= 0 else ""
```

## 8. 边界情况与易错点

1. **`s2` 比 `s1` 长**：$m > n$ 时不可能成为子序列，直接返回 `""`，省掉一整轮无效 DP。
2. **$m = 1$**：内层循环一次都不执行，`dp[0]` 就是「最近一次出现 `s2[0]` 的下标」，窗口长度恒为 1；从未出现则返回 `""`。
3. **等长多解**：`s1 = "abcdebdde"`、`s2 = "bde"` 有 `bcde` 与 `bdde` 两个长度 4 的解，若用 `cur <= best_len` 更新就会返回 `bdde`，直接 WA。
4. **把 −1 当起点**：省略 `dp[j-1] >= 0` 判断时，−1 会被当作起点写入，长度算成 $i+2$，还可能切出越界子串。
5. **$dp[0]$ 提前更新**：若把 `dp[0] = i` 写在 $j$ 循环之前，$j=1$ 会读到刚更新的值，等于让同一个字符同时匹配 `s2[0]`、`s2[1]`，答案偏短。
6. **正序更新**：$j$ 递增同样会读到本轮被覆盖的 $dp[j-1]$，症状与上一条相同。
7. **循环里切子串**：`s1[best_start:best_start + best_len]` 若放进循环，每次 $O(n)$，总复杂度退化到 $O(n^2 m)$ 量级。
8. **无解必须判空**：`bestStart` 初值 −1，返回前不判断就会在 C++ 里触发 `substr` 越界（`std::out_of_range`）。
