# LeetCode 吃掉所有兵需要的最多移动次数 题解

## 1. 题目概述

- **标题 / 题号**：吃掉所有兵需要的最多移动次数（#3283，hard）
- **链接**：https://leetcode.cn/problems/maximum-number-of-moves-to-kill-all-pawns/
- **来源**：LeetCode 第 414 场周赛 Q4
- **难度**：困难
- **标签**：广度优先搜索、状态压缩、动态规划、博弈论

**题意**：$50 \times 50$ 的国际象棋棋盘上有一个马（位于 $(kx, ky)$）和 $n \le 15$ 个互不相同的兵。Alice 与 Bob 轮流操作，Alice 先手。每个回合：玩家**任选**一个还活着的兵，操纵马以**最少步数**走过去吃掉它——途中经过的其他兵不会被吃。Alice 的目标是**最大化**吃完所有兵的总移动步数，Bob 的目标是**最小化**它。求双方都采取最优策略时的总移动步数。

**约束**：

- $0 \le kx, ky \le 49$
- $1 \le positions.length \le 15$
- $0 \le positions[i][0], positions[i][1] \le 49$
- 兵两两互不相同，且均不与马的起点重合

> 💡 **读题关键**：① $n \le 15$ 几乎是在明示**状态压缩**；② "经过的兵不会被吃"意味着**兵不是障碍物**，马步距离是纯几何量，与吃兵顺序无关；③ Alice **不一定**选当前最近的兵——她要的是全局总和最大，甚至常常故意绕远。

## 2. 示例

**示例 1**

```text
输入：kx = 1, ky = 1, positions = [[0,0]]
输出：4
解释：只有一个兵，马走 4 步吃掉它，别无选择。
```

**示例 2**

```text
输入：kx = 0, ky = 2, positions = [[1,1],[2,2],[3,3]]
输出：8
解释：Alice 先吃中间的 (2,2)（2 步）；Bob 吃 (3,3)（2 步）；
      Alice 最后吃 (1,1)，从 (3,3) 出发需要 4 步。总计 2+2+4 = 8。
```

**示例 3**

```text
输入：kx = 0, ky = 0, positions = [[1,2],[2,4]]
输出：3
解释：Alice 先吃较远的 (2,4)（2 步），Bob 只能吃 (1,2)（1 步），总计 3；
      若 Alice 先吃 (1,2)（1 步），总计只有 1+1 = 2。
```

## 3. 解题思路

### 3.1 暴力思路

游戏是一棵**博弈搜索树**：每个节点轮到某位玩家，分支为"当前还剩几个兵就有几种选择"，树的深度为 $n$。直接搜索要遍历所有吃兵**排列**，叶子数 $n! = 15! \approx 1.3 \times 10^{12}$，必然超时。

但注意：**不同顺序到达的相同局面，其后续博弈完全一样**。例如"先吃 A 再吃 B"与"先吃 B 再吃 A"之后，都处于"马在 B、剩 C"的同一局面。把局面折叠进记忆化，就是状态压缩 DP 的切入点。

### 3.2 核心观察一：兵不是障碍——先把距离做成一张小表

![马步 BFS 距离矩阵](images/kill_pawns_bfs_distance.svg)

吃兵的代价是"马从当前位置到目标兵的最少马步数"。由题面，**途经的兵不会被吃掉**，所以兵不构成障碍，任意两点间的马步距离就是**纯几何量**，与剩余哪些兵无关。

马在整个游戏里只会停在两类位置上：**起点**或**刚被吃掉的兵**。于是只需对 $n+1 \le 16$ 个关键点各做一次 $50 \times 50$ 的 BFS，得到距离表 $dist[i][j]$（$i$ 为关键点编号，$j$ 为兵编号），整局游戏的代价就由这张 $(n+1) \times n$ 的小表完全决定。

> ⚠️ 注意马步距离的坑：水平/竖直位移 $(1,0)$ 型要 3 步、$(2,2)$ 对角型要 4 步（示例 2 中 $(1,1) \leftrightarrow (3,3)$ 距离是 4 而非 2）。别手推公式，老老实实 BFS。

### 3.3 核心观察二：状态压缩 + minimax 博弈 DP

![状态压缩与 minimax 模型](images/kill_pawns_state_model.svg)

把局面编码为 $dp[mask][i]$：已吃掉的兵集合为二进制 $mask$，马当前停在关键点 $i$（$i < n$ 表示兵 $i$，$i = n$ 表示起点），在此局面下**双方都最优**时、到游戏结束为止的剩余总步数。

- **轮到谁**由 $\mathrm{popcount}(mask)$ 的奇偶自动决定：已吃偶数个（含开局 $mask = \varnothing$）轮到 Alice，奇数个轮到 Bob——回合无需存入状态。
- **转移**：枚举一个未吃的兵 $j$，本回合花费 $dist[i][j]$，进入 $dp[mask \mid 2^j][j]$：

$$
dp[mask][i] =
\begin{cases}
0, & mask \text{ 已满（兵吃光，游戏结束）} \\[4pt]
\max\limits_{j \notin mask} \Big( dist[i][j] + dp[mask \mid 2^j][j] \Big), & \text{Alice 回合} \\[8pt]
\min\limits_{j \notin mask} \Big( dist[i][j] + dp[mask \mid 2^j][j] \Big), & \text{Bob 回合}
\end{cases}
$$

答案是 $dp[\varnothing][n]$。

为什么**不能贪心**？Alice 的选择会改变 Bob 后续的选择空间：她挑的兵决定了马下一轮的落脚点，也决定了哪些"长距离"会被 Bob 提前斩断。示例 2 正是反例——三个兵从起点出发距离都是 2，贪心无从区分，但"先吃中间的兵"严格更优。零和博弈必须整树取 $\max / \min$。

### 3.4 示例演算

![示例 2 博弈树走查](images/kill_pawns_game_tree.svg)

**示例 2**（$kx=0, ky=2$，兵 $A=(1,1)$、$B=(2,2)$、$C=(3,3)$）的完整博弈树如上图。距离表：从起点到三个兵均为 2；$A \leftrightarrow C$ 为 4（对角型），其余兵两两之间为 2。

- Alice 若先吃 $A$（或 $C$）：Bob 会立刻吃掉对角另一端，把"4"斩成两个"2"， subtree 值为 $6$；
- Alice 先吃中间的 $B$：剩下 $A$、$C$ 互相距离 4，无论 Bob 先吃哪个，最后一跳必然付 4 步，subtree 值为 $8$。

$dp[\varnothing][起] = \max(6, 8, 6) = 8$ ✓。

**示例 3**：Alice 先吃远兵 $(2,4)$（2 步），Bob 只剩 $(1,2)$（1 步），$\max(1+1,\ 2+1) = 3$ ✓。

## 4. 算法细节

1. **关键点编号**：兵编号 $0 .. n-1$，马起点编号 $n$。BFS 源点取这 $n+1$ 个，每次 BFS 在 $50 \times 50$ 网格上跑 8 方向，单次 $O(50^2 \cdot 8)$。
2. **距离表**：$dist$ 为 $(n+1) \times n$；$dist[n][j]$ 即开局吃兵 $j$ 的代价，$dist[i][j]$（$i<n$）为站在兵 $i$ 上吃兵 $j$ 的代价。
3. **记忆化搜索**：$dp$ 开成 $2^n \times (n+1)$，初值 $-1$ 表示未计算；`mask` 满时直接返回 0。每次吃兵 $\mathrm{popcount}$ 恰好 $+1$，递归天然无环、深度 $\le n+1$。
4. **轮次判定**：`popcount(mask) % 2 == 0` → Alice 取 $\max$，否则 Bob 取 $\min$。
5. **答案量级**：$50 \times 50$ 棋盘上最远马步距离为 34，总步数上界 $15 \times 34 = 510$，`int` 绰绰有余。
6. **入口**：`dfs(0, n)`——空集合、马在起点。

## 5. 正确性证明

**引理 1**（状态充分性）：游戏的后续演变只由三元组（马的当前位置、剩余兵集合、轮到谁）决定，与到达该局面的历史无关。

**证明**：每回合的可行决策是"从剩余兵中任选一个"，其代价由马的当前位置与目标兵唯一决定（引理 2）；总步数是各回合代价之和，不含任何依赖历史顺序的项。轮到谁恰为已吃兵数的奇偶，即 $\mathrm{popcount}(mask)$。而马的位置必为起点或最近被吃的兵，属于 $n+1$ 个关键点之一。故 $(mask, i)$ 是充分的状态编码。∎

**引理 2**（单步代价）：在状态 $(mask, i)$ 选择吃兵 $j$，该回合的步数恰为 $dist[i][j]$。

**证明**：题面规定马按最少步数移动，且途经的兵不会被吃掉——即兵不阻挡马的移动，马步最短路在纯空棋盘上取到，与 $mask$ 无关。BFS 在空棋盘上计算的即此几何最短距离。∎

**定理**：$dp[mask][i]$ 为局面 $(mask, i)$ 下双方最优时的剩余总步数，特别地 $dp[\varnothing][n]$ 为所求答案。

**证明**：对剩余兵数 $r = n - \mathrm{popcount}(mask)$ 归纳，并同时强化证明两个命题：

- $P_1(s)$：Alice 存在策略，使得从局面 $s$ 出发（对抗任意 Bob），总步数 $\ge V(s)$；
- $P_2(s)$：Bob 存在策略，使得从局面 $s$ 出发（对抗任意 Alice），总步数 $\le V(s)$。

其中 $V$ 即递归式定义的 $dp$ 值。

**归纳基础** $r = 0$：$V = 0$，游戏已结束，两命题显然成立。

**归纳步**：设结论对所有 $r+1$ 的局面成立，考虑 $r$ 的局面 $s = (mask, i)$。

- 若轮到 **Alice**：取 $j^\ast = \arg\max_j \big(dist[i][j] + V(mask \cup \{j\}, j)\big)$。
  - $P_1$：Alice 选 $j^\ast$，此后无论 Bob 如何行动，局面进入 $s' = (mask \cup \{j^\ast\}, j^\ast)$。由归纳假设 $P_1(s')$，Alice 的后续策略保证剩余步数 $\ge V(s')$，故总步数 $\ge dist[i][j^\ast] + V(s') = V(s)$。✓
  - $P_2$：对 Alice 的任意选择 $j$，由归纳假设 $P_2(s')$，Bob 有策略使总步数 $\le dist[i][j] + V(s') \le V(s)$（因 $V(s)$ 是对 $j$ 的最大值）。✓
- 若轮到 **Bob**：取 $j^\ast = \arg\min_j \big(dist[i][j] + V(mask \cup \{j\}, j)\big)$，对称地：$P_2$ 中 Bob 选 $j^\ast$ 后总步数 $\le dist[i][j^\ast] + V(s') = V(s)$；$P_1$ 中对 Bob 的任意选择 $j$，由 $P_1(s')$，总步数 $\ge dist[i][j] + V(s') \ge V(s)$（$V(s)$ 是对 $j$ 的最小值）。✓

归纳完成。$P_1$ 与 $P_2$ 结合：Alice 无法迫使总步数超过 $V(s)$，Bob 无法压到低于 $V(s)$，双方最优时总步数恰为 $V(s)$。取 $s = (\varnothing, n)$ 即得定理。∎

## 6. 复杂度分析

- **时间复杂度**：BFS 预处理 $O\big((n+1) \cdot 50^2 \cdot 8\big) \approx 3.2 \times 10^5$；博弈 DP 有 $2^n \cdot (n+1) \approx 5.2 \times 10^5$ 个状态，每个状态转移枚举至多 $n = 15$ 个兵，共 $O\big(2^n \cdot n^2\big) \approx 7.9 \times 10^6$。总计约 $10^7$ 量级，轻松通过。
- **空间复杂度**：距离表 $O(n^2)$；DP 数组 $O\big(2^n \cdot (n+1)\big) \approx 5 \times 10^5$ 个 `int`（约 2 MB）；递归栈深 $O(n)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maxMoves(int kx, int ky, vector<vector<int>>& positions) {
        int n = positions.size();
        // 关键点：n 个兵（0..n-1）+ 马的起点（编号 n）
        vector<pair<int,int>> src;
        for (auto& p : positions) src.emplace_back(p[0], p[1]);
        src.emplace_back(kx, ky);
        int m = n + 1;
        static constexpr int DIR[8][2] = {
            {1,2},{2,1},{2,-1},{1,-2},{-1,-2},{-2,-1},{-2,1},{-1,2}};

        vector<vector<int>> dist(m, vector<int>(n));
        for (int i = 0; i < m; i++) {
            vector<vector<int>> d(50, vector<int>(50, -1));
            queue<pair<int,int>> q;
            d[src[i].first][src[i].second] = 0;
            q.emplace(src[i].first, src[i].second);
            while (!q.empty()) {
                auto [x, y] = q.front(); q.pop();
                for (auto& [dx, dy] : DIR) {
                    int nx = x + dx, ny = y + dy;
                    if (nx >= 0 && nx < 50 && ny >= 0 && ny < 50 && d[nx][ny] < 0) {
                        d[nx][ny] = d[x][y] + 1;
                        q.emplace(nx, ny);
                    }
                }
            }
            for (int j = 0; j < n; j++)
                dist[i][j] = d[positions[j][0]][positions[j][1]];
        }

        // dp[mask][i]：已吃集合 mask、马停在关键点 i 时的最优剩余总步数
        vector<vector<int>> dp(1 << n, vector<int>(m, -1));
        const int FULL = (1 << n) - 1;
        function<int(int,int)> dfs = [&](int mask, int i) -> int {
            if (mask == FULL) return 0;
            int& res = dp[mask][i];
            if (res != -1) return res;
            bool alice = __builtin_popcount(mask) % 2 == 0;
            res = alice ? INT_MIN : INT_MAX;
            for (int j = 0; j < n; j++) {
                if (mask >> j & 1) continue;
                int v = dist[i][j] + dfs(mask | 1 << j, j);
                res = alice ? max(res, v) : min(res, v);
            }
            return res;
        };
        return dfs(0, n);
    }
};
```

### Python

```python
class Solution:
    def maxMoves(self, kx: int, ky: int, positions: List[List[int]]) -> int:
        n = len(positions)
        srcs = [tuple(p) for p in positions] + [(kx, ky)]  # 编号 n = 起点
        dirs = [(1,2),(2,1),(2,-1),(1,-2),(-1,-2),(-2,-1),(-2,1),(-1,2)]

        dist = []
        for sx, sy in srcs:
            d = [[-1] * 50 for _ in range(50)]
            d[sx][sy] = 0
            q = deque([(sx, sy)])
            while q:
                x, y = q.popleft()
                for dx, dy in dirs:
                    nx, ny = x + dx, y + dy
                    if 0 <= nx < 50 and 0 <= ny < 50 and d[nx][ny] < 0:
                        d[nx][ny] = d[x][y] + 1
                        q.append((nx, ny))
            dist.append([d[x][y] for x, y in positions])

        full = (1 << n) - 1

        @lru_cache(None)
        def dfs(mask: int, i: int) -> int:
            if mask == full:
                return 0
            alice = mask.bit_count() % 2 == 0
            best = -1 if alice else float('inf')
            for j in range(n):
                if mask >> j & 1:
                    continue
                v = dist[i][j] + dfs(mask | 1 << j, j)
                best = max(best, v) if alice else min(best, v)
            return best

        return dfs(0, n)
```

## 8. 边界情况与易错点

1. **别把兵当障碍**：马途经其他兵时它们不会被吃，因此 BFS 在**空棋盘**上做即可；若误把兵当障碍（或试图在状态里带上"途经吃掉"逻辑），既复杂又错。
2. **马步距离的反直觉值**：$(1,0)$ 位移需 3 步、$(2,2)$ 对角需 4 步（示例 2 的 $A \leftrightarrow C = 4$ 是全题胜负手）。不要手推距离公式，一律 BFS。
3. **轮次搞反**：`popcount(mask)` 为**偶**时是 Alice（开局 $mask = \varnothing$，popcount 为 0）。若写反，得到的是 Bob 先手视角的答案。一个自检技巧：$n=1$ 时答案应为起点到该兵的距离（Alice 一步吃完、无人能干预）。
4. **起点要占一个编号**：马开局不在任何兵上，距离表必须是 $(n+1)$ 行；漏掉第 $n$ 行会导致初始转移无处查距离。
5. **贪心陷阱**：Alice 不一定先吃最远的兵，甚至不一定吃"让自己下一步更远"的兵（示例 2 她吃的是**中间**的兵）。同理 Bob 也不是简单吃最近的。零和目标下必须完整 minimax。
6. **`mask` 满态**：返回 0 而非剩余兵距离——此时已无兵可吃。记忆化数组的合法值 $\ge 0$，初值 $-1$ 可安全区分"未计算"。
7. **溢出无忧但要有数**：$50 \times 50$ 棋盘最远马步 34 步，总步数上界 $15 \times 34 = 510$，`int` 足够；若改用更粗暴的累加写法仍建议心里过一遍上界。
8. **起点与兵重合 / 兵重合**：题面保证不发生，无需特判；但自测代码时若构造这样的输入，BFS 会出现 $dist = 0$ 的合法值，逻辑上也能正确处理（吃它花费 0 步）。
