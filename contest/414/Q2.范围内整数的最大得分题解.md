# LeetCode 范围内整数的最大得分 题解

## 1. 题目概述

- **标题 / 题号**：范围内整数的最大得分（#3281，medium）
- **链接**：https://leetcode.cn/problems/maximize-score-of-numbers-in-ranges/
- **来源**：LeetCode 第 414 场周赛 Q2
- **难度**：中等
- **标签**：贪心、数组、二分查找、排序

**题意**：给定整数数组 $start$ 与整数 $d$，表示 $n$ 个**等长**区间 $[start[i],\, start[i]+d]$。需要从**每个**区间里各选一个整数，得分为所选 $n$ 个整数**两两之间的最小绝对差**。求得分的最大值。

**约束**：

- $2 \le start.length \le 10^5$
- $0 \le start[i] \le 10^9$
- $0 \le d \le 10^9$

> 💡 **读题关键**：这是标准的"**最大化最小值**"（max-min）形态——得分是"最小差"，要让它尽量大。此类问题几乎总是转化为**二分答案 + 贪心判定**。另一个隐藏要点：区间给定的顺序与答案无关，排序后处理是第一步。

## 2. 示例

**示例 1**

```text
输入：start = [6,0,3], d = 2
输出：4
解释：排序后区间为 [0,2]、[3,5]、[6,8]；分别选 0、4、8，
      两两差为 4、8、4，得分 = min = 4。
```

**示例 2**

```text
输入：start = [2,6,13,13], d = 5
输出：5
解释：区间 [2,7]、[6,11]、[13,18]、[13,18]（两个重复区间）；
      分别选 2、7、13、18，最小差 = 5。
```

**补充示例**（区间退化为点）

```text
输入：start = [5,5], d = 0
输出：0
解释：两个区间都退化为单点 {5}，只能都选 5，最小差为 0。
```

## 3. 解题思路

### 3.1 暴力思路

每个区间的候选值是连续整数（多达 $2\times10^9$ 个），直接枚举选法不可行。即便把视角换成"直接优化"，也会卡住：得分由**最紧的那一对**选点决定，$n$ 个选择互相耦合，局部调整无从下手——最小值函数 $\min$ 对自变量不可导、不光滑，常规 DP 或贪心都没有明显的决策结构。

> 💡 **套路切换**：当"直接求最优值"困难时，改问"**判定**：给定阈值 $x$，能否做到得分 $\ge x$？"——判定问题往往有简单的贪心结构，且其答案关于 $x$ **单调**，于是可以二分。

### 3.2 核心观察：排序 + 二分答案 + 贪心判定

![二分答案概念图](images/ranges_max_score_binary_search.svg)

三个观察环环相扣：

1. **观察 A（排序后只需看相邻）**：区间顺序与答案无关，且存在"选点随区间排序而单调"的最优解（§5 引理 2）。对一组有序选点 $y_1 \le y_2 \le \cdots \le y_n$，两两最小差就是**相邻差的最小值**（§5 引理 1）——检验从 $O(n^2)$ 对降到 $O(n)$ 对。
2. **观察 B（可行性单调）**：若存在选法使所有相邻差 $\ge x$，则同一组选点对任何 $x' < x$ 也合法。因此"可行性"关于 $x$ 单调，**答案 = 最大的可行 $x$**，可以二分。
3. **观察 C（判定用贪心）**：固定 $x$ 后，从最左区间开始，每个区间取"被迫能取的**最左**点" $cur = \max(prev + x,\ start[i])$，一旦超过上界 $start[i]+d$ 即判定失败（§5 引理 3 保证贪心判定与可行性等价）。

$$\boxed{\ \text{答案} = \max\{\,x :\ \text{check}(x)\ \text{为真}\,\},\quad \text{check}(x):\ cur_i = \max(prev + x,\ start_i),\ \forall i,\ cur_i \le start_i + d\ }$$

### 3.3 判定流程：每个区间尽量选最左

![贪心判定流程图](images/ranges_max_score_greedy_check.svg)

直觉：当前区间把选点放得越靠左，给**后面**区间留的余量就越大；前面"多让"一步，后面只会更宽裕，绝不会更差——每个人都尽量往区间左端站，只在被前面的人逼着时才右移。这正是引理 3 交换论证的贪心直觉。

流程（对排序后的区间）：

1. $prev \leftarrow start[0]$（第一个区间无左侧约束，取最左端点最优）。
2. 对 $i = 1, \dots, n-1$：$cur \leftarrow \max(prev + x,\ start[i])$。
3. 若 $cur > start[i] + d$：返回 `false`（$x$ 太大，被迫越界）。
4. 否则 $prev \leftarrow cur$，继续；全部处理完返回 `true`。

### 3.4 示例演算

![示例演算图](images/ranges_max_score_walkthrough.svg)

**示例 1**：$start = [6,0,3]$，$d=2$，排序后 $[0,3,6]$：

- $\text{check}(4)$：选 $0 \to \max(0+4,3)=4 \to \max(4+4,6)=8$，$8 \le 6+2$ ✓ 可行；
- $\text{check}(5)$：选 $0 \to \max(0+5,3)=5 \to \max(5+5,6)=10 > 8$ ✗ 不可行。

二分收敛到最大可行值 **4**。

**示例 2**：$start = [2,6,13,13]$，$d=5$：

- $\text{check}(5)$：$2 \to 7 \to 13 \to 18$，末点恰在 $13+5=18$ ✓ 可行；
- $\text{check}(6)$：$2 \to 8 \to 14 \to \max(14+6,13)=20 > 18$ ✗ 不可行。

答案 **5**。注意两个重复区间 $[13,18]$ 被贪心自动错开（取 $13$ 与 $18$），无需任何特判。

## 4. 算法细节

1. **先排序**：区间等长，按 $start$ 排序即按区间位置排序；这是贪心判定正确性的前提（输入顺序是任意的）。
2. **二分区间**：$lo = 0$（$check(0)$ 恒真：逐个取 $start[i]$ 总在区间内），$hi = start[n-1] + d - start[0]$（首尾区间的最大可能间距，答案不会超过它）。
3. **模板选择**：求"最大可行值"用**上取整** $mid = \lfloor(lo+hi+1)/2\rfloor$：可行则 $lo = mid$，否则 $hi = mid - 1$，避免 $lo = hi - 1$ 时死循环。
4. **判定实现**：$prev$ 初始化为排序后 $start[0]$，从 $i=1$ 起循环，避免 $-\infty$ 哨兵的溢出麻烦。
5. **溢出核算**：$start[i] + d$ 最高 $2\times10^9$，$prev + x$ 最高约 $4\times10^9$，都超出 32 位 `int`，C++ 判定内部必须用 `long long`；返回值本身 $\le 2\times10^9$，恰在 `int` 范围内。
6. **无需数对枚举**：由引理 1，判定只比较相邻选点，一轮 $O(n)$。

## 5. 正确性证明

**引理 1**（相邻即最小）：设 $y_1 \le y_2 \le \cdots \le y_n$，则 $\min_{i<j}|y_j - y_i| = \min_{1 \le i < n}(y_{i+1} - y_i)$。

**证明**：相邻对是所有数对的子集，故左边 $\le$ 右边。反之对任意 $i < j$，$y_j - y_i = \sum_{t=i}^{j-1}(y_{t+1} - y_t) \ge \min_t (y_{t+1} - y_t)$，即每个数对差都不小于最小相邻差，故左边 $\ge$ 右边。两边夹逼相等。∎

**引理 2**（交换成序）：将区间按左端点排序后，存在选点与区间**同序**（$y_1 \le y_2 \le \cdots \le y_n$）的最优解。

**证明**：区间等长均为 $d$。设某最优解在排序后第 $i$、$j$（$i < j$，$start[i] \le start[j]$）个区间上的选点满足 $x_i > x_j$，交换这两个选点：

- $x_j$ 放入区间 $i$：$start[i] \le start[j] \le x_j$ 且 $x_j < x_i \le start[i] + d$，合法；
- $x_i$ 放入区间 $j$：$x_i > x_j \ge start[j]$ 且 $x_i \le start[i] + d \le start[j] + d$，合法。

交换只改变选点与区间的配对、不改变选点的**多重集**，由引理 1 得分不变，仍为最优。所有逆序对可通过有限次此类冒泡交换消除，得到同序的最优解。∎

**引理 3**（贪心判定等价）：对排序后区间与阈值 $x$，贪心序列（$g_1 = start[1]$，$g_{k+1} = \max(g_k + x,\ start[k+1])$，任一步 $g_k > start[k] + d$ 即宣告失败）能够完整生成，当且仅当存在满足"所有相邻差 $\ge x$"的合法选点。

**证明**：（$\Leftarrow$）设合法选点 $y_1 \le \cdots \le y_n$（由引理 2 只需考虑同序解），归纳证明 $g_k \le y_k$：$g_1 = start[1] \le y_1$；若 $g_k \le y_k$，则
$$g_{k+1} = \max(g_k + x,\ start[k+1]) \le \max(y_k + x,\ start[k+1]) \le \max(y_{k+1},\ y_{k+1}) = y_{k+1} \le start[k+1] + d,$$
（其中用到 $y_{k+1} \ge y_k + x$ 与 $y_{k+1} \ge start[k+1]$）故贪心每步都不越界，完整生成。（$\Rightarrow$）贪心生成的序列本身就是满足所有相邻差 $\ge x$ 的合法选点。∎

**定理**：算法返回的即为最大得分。

**证明**：由引理 2，最优解可设为同序选点，其得分由引理 1 等于相邻差的最小值，记为 $t$。由引理 3，$check(x)$ 为真 $\iff$ 存在相邻差均 $\ge x$ 的选点 $\iff t \ge x$。故可行 $x$ 的集合为 $\{0, 1, \dots, t\}$（非空，因 $check(0)$ 恒真），二分找到的最大可行值恰为 $t$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \log n + n \log U)$。排序 $O(n \log n)$；二分判定 $O(\log U)$ 轮，每轮贪心 $O(n)$，其中 $U = start[n-1] + d - start[0] \le 2\times10^9$，$\log U \approx 31$。
- **空间复杂度**：$O(1)$。排序原地（递归栈 $O(\log n)$），判定只用常数个变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maxPossibleScore(vector<int>& start, int d) {
        sort(start.begin(), start.end());
        int n = start.size();

        auto check = [&](long long x) -> bool {
            long long prev = start[0];
            for (int i = 1; i < n; i++) {
                long long cur = max(prev + x, (long long) start[i]);
                if (cur > (long long) start[i] + d) return false;
                prev = cur;
            }
            return true;
        };

        long long lo = 0, hi = (long long) start[n - 1] + d - start[0];
        while (lo < hi) {
            long long mid = lo + (hi - lo + 1) / 2;
            if (check(mid)) lo = mid;
            else hi = mid - 1;
        }
        return lo;
    }
};
```

### Python

```python
class Solution:
    def maxPossibleScore(self, start: List[int], d: int) -> int:
        start.sort()

        def check(x: int) -> bool:
            prev = start[0]
            for s in start[1:]:
                cur = max(prev + x, s)
                if cur > s + d:
                    return False
                prev = cur
            return True

        lo, hi = 0, start[-1] + d - start[0]
        while lo < hi:
            mid = (lo + hi + 1) // 2
            if check(mid):
                lo = mid
            else:
                hi = mid - 1
        return lo
```

## 8. 边界情况与易错点

1. **忘排序**：输入顺序任意，贪心判定必须按左端点排序后进行，直接在原数组上贪心会得到错误判定。
2. **溢出**：判定中 $prev + x$ 最高约 $4\times10^9$、$start[i] + d$ 最高 $2\times10^9$，均超 `int`；C++ 内部用 `long long`（返回值恰在 `int` 内，但全程 `long long` 最稳妥），Python 无此虑。
3. **$d = 0$**：区间退化为点，答案即排序后相邻 $start$ 差的最小值，算法自然覆盖，无需特判。
4. **重复区间**：如示例 2 的两个 $[13,18]$，贪心自动错开取值，不要误以为相同区间只能取相同点。
5. **二分模板**：求最大可行值必须 $mid$ 上取整 `(lo + hi + 1) / 2`；若用下取整且可行时执行 `lo = mid`，在 $hi = lo + 1$ 处会死循环。
6. **答案可为 0**：区间高度重叠（如补充示例）时答案为 0；$lo$ 初值取 0 且 $check(0)$ 恒真，天然覆盖，不需额外特判。
7. **检验相邻而非全部数对**：由引理 1，判定只看相邻差；若在 check 里对两两数对取 $\min$，单轮复杂度退化为 $O(n^2)$，必然超时。
