# LeetCode 将日期转换为二进制表示 题解

## 1. 题目概述

- **标题 / 题号**：将日期转换为二进制表示（#3280，easy）
- **链接**：https://leetcode.cn/problems/convert-date-to-binary/
- **来源**：LeetCode 第 414 场周赛 Q1
- **难度**：简单
- **标签**：数学、字符串、位运算

**题意**：给定格式为 `yyyy-mm-dd` 的公历日期字符串 `date`，将**年、月、日三段分别**转换为二进制表示（**不带前导零**），再用 `-` 按原顺序拼接，返回结果。

**约束**：

- $date.length = 10$
- $date[4] = date[7] = \texttt{-}$，其余 $date[i]$ 均为数字
- 输入保证是有效日期，范围 1900-01-01 到 2100-12-31（含两端）

> 💡 **读题关键**：① 三段**各自独立**转二进制，不是把整个数值转；② "不带前导零"——`"02"` 转出的是 `"10"` 而非 `"0010"`；③ 约束保证年月日均 $\ge 1$，不存在 0 值字段。

## 2. 示例

**示例 1**

```text
输入：date = "2080-02-29"
输出："100000100000-10-11101"
解释：100000100000、10、11101 分别是 2080、02、29 的二进制表示。
```

**示例 2**

```text
输入：date = "1900-01-01"
输出："11101101100-1-1"
解释：11101101100、1、1 分别是 1900、01、01 的二进制表示。
```

## 3. 解题思路

### 3.1 暴力思路

签到题，没有可优化的算法结构，唯一目标是**从题面到 AC 的最短路径**。朴素做法即所求：按 `-` 切成三段 → 每段转 `int` → 每段转二进制 → 用 `-` 拼回。全程 $O(1)$，任何"更优"写法只是常数级别的代码长短差异。

### 3.2 核心观察：分段解析 + 进制转换，`int` 天然剥前导零

![分段解析转换概念图](images/date_binary_split_concept.svg)

- `'-'` 是天然分隔符：`split('-')` 一刀切三段（约束保证 `date[4]`、`date[7]` 恰为分隔符）。
- **前导零不用专门处理**：`"02"` 经 `int()` 归一化为数值 $2$，再转二进制即 `"10"`。数值化本身就把 `"02"` 与 `"2"` 拉平，输出自然无前导零。
- 十进制转二进制是标准短除法：Python 一行 `bin(x)[2:]`，C++ 手写循环。

### 3.3 算法流程：一次遍历 + 短除法

![短除法演算图](images/date_binary_short_division.svg)

**短除法**（除 2 取余，逆序输出）：

1. 从高位往低位**一次遍历**字符串：遇数字就 `num = num*10 + (c-'0')` 累计；遇 `-` 就把累计的 `num` 转成二进制串并落一段。
2. **单段转二进制**：`x > 0` 时反复取 `x & 1` 追加到结果末尾、`x >>= 1`——余数是**从低位到高位**生成的，最后 `reverse`。
3. 三段转完用 `-` 拼接，末段后不带 `-`。

### 3.4 示例演算

**示例 1**：`date = "2080-02-29"`

| 字段 | 原文 | int 归一化 | 二进制（无前导零） |
|------|------|-----------|--------------------|
| 年 | `"2080"` | 2080 | `100000100000`（12 位，$2^{11}+2^6$） |
| 月 | `"02"` | 2 | `10` |
| 日 | `"29"` | 29 | `11101`（$2^4+2^3+2^2+2^0$） |

输出 = `"100000100000-10-11101"` ✓

**示例 2**：`date = "1900-01-01"`

| 字段 | 原文 | int 归一化 | 二进制 |
|------|------|-----------|--------|
| 年 | `"1900"` | 1900 | `11101101100`（11 位） |
| 月 | `"01"` | 1 | `1` |
| 日 | `"01"` | 1 | `1` |

输出 = `"11101101100-1-1"` ✓

## 4. 算法细节

1. **解析方式任选**：`split('-')` 最省心；也可按固定位置 `substr(0,4) / substr(5,2) / substr(8,2)`；或一次遍历累计 `num`、遇 `-` 结算（C++ 参考代码用这种，无需 split 的中间数组）。
2. **单段转二进制**：Python 用 `bin(x)[2:]`（`bin(2)` 返回 `'0b10'`，须切掉 `'0b'`），等价写法 `f"{x:b}"`；C++ 手写短除法，或 C++20 的 `std::format("{:b}", x)`。
3. **值域核算**：年 $\le 2100 < 2^{12}$（最多 12 位），月日 $\le 31 < 2^5$（最多 5 位），全部远小于 `int` 上限，无溢出顾虑。
4. **输出长度上界**：$12 + 1 + 4 + 1 + 5 = 23$ 字符，加上两个 `-` 分隔符内的开销也是常数。

## 5. 正确性证明

**引理 1**（短除法正确性）：对任意正整数 $x$，反复执行"除 2 记余数"直到商为 0，将余数序列**逆序**排列即得 $x$ 的无前导零二进制表示。

**证明**：设 $x = \sum_{i=0}^{k-1} b_i 2^i$，其中 $b_{k-1} = 1$。第一次除 2：余数为 $x \bmod 2 = b_0$（因 $\sum_{i \ge 1} b_i 2^i$ 是偶数），商为 $\lfloor x/2 \rfloor = \sum_{i=1}^{k-1} b_i 2^{i-1}$，恰好是 $b_{k-1} b_{k-2} \cdots b_1$ 的值。对商递归应用同一论证，第 $j$ 次除法的余数即 $b_{j-1}$，且恰在第 $k$ 次后商归 0。余数依次为 $b_0, b_1, \ldots, b_{k-1}$，逆序排列得 $b_{k-1} \cdots b_1 b_0$，最高位 $b_{k-1} = 1$，无前导零。∎

**定理**：算法对约束内任意输入 `date` 返回正确的二进制日期表示。

**证明**：解析正确性：由约束 `date[4] = date[7] = '-'` 且其余字符为数字，一次遍历累计数值、在 `-` 处切分，得到的三个整数恰为年、月、日的值，且字符串前导零（如 `"02"`）在数值化时天然剥离。由引理 1，三段各自转换为无前导零的二进制串。按 `year-month-day` 顺序以 `-` 连接，与题面要求一致。∎

## 6. 复杂度分析

- **时间复杂度**：$O(1)$。输入长度固定为 10；转换开销为年 $\lfloor \log_2 2100 \rfloor + 1 = 12$ 次、月日各至多 5 次除法，输出至多 23 字符。更一般地是 $O(n + L)$（$n$ 输入长度、$L$ 输出长度），本题均为常数。
- **空间复杂度**：$O(1)$（除输出字符串外仅用常数个临时变量；若计输出则为 $O(L)$）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    string convertDateToBinary(string date) {
        string ans;
        int num = 0;
        for (char c : date) {
            if (c == '-') {
                ans += toBinary(num);
                ans += '-';
                num = 0;
            } else {
                num = num * 10 + (c - '0');
            }
        }
        ans += toBinary(num);
        return ans;
    }
private:
    string toBinary(int x) {
        string s;
        for (; x > 0; x >>= 1) {
            s += '0' + (x & 1);
        }
        reverse(s.begin(), s.end());
        return s;
    }
};
```

### Python

```python
class Solution:
    def convertDateToBinary(self, date: str) -> str:
        return '-'.join(bin(int(p))[2:] for p in date.split('-'))
```

## 8. 边界情况与易错点

1. **前导零**：必须先 `int()` 再转二进制，`"02"` → `2` → `"10"`；若直接对字符串操作会输出 `"010"` 之类的错误结果。
2. **`bin()` 的 `'0b'` 前缀**：`bin(2) == '0b10'`，必须 `[2:]` 切掉，或用 `f"{x:b}"` / `format(x, 'b')`。
3. **C++ 无内置十转二**：手写短除法时余数**从低位到高位**生成，写完记得 `reverse`；C++20 可直接 `std::format("{:b}", x)`。
4. **无 0 值字段**：约束保证年月日 $\ge 1$，`while (x > 0)` 循环不会遇到空串问题；若题目放宽到允许 0，需特判输出 `"0"`（本题不用）。
5. **尾部分隔符**：最后一段之后不要再补 `-`。
6. **无需日期校验**：题面保证输入是 1900–2100 间的有效日期，闰年 2 月 29 等情况直接按数值转换即可，不做合法性判断。
