# LeetCode 到达数组末尾的最大得分 题解

## 1. 题目概述

- **标题 / 题号**：到达数组末尾的最大得分（#3282，medium）
- **链接**：https://leetcode.cn/problems/reach-end-of-array-with-max-score/
- **来源**：LeetCode 第 414 场周赛 Q3
- **难度**：中等
- **标签**：贪心、数组

**题意**：给定长度为 $n$ 的正整数数组 $nums$。从下标 $0$ 出发，每次跳跃只能落在**更大的下标**处（落点的值无所谓）；从下标 $i$ 跳到下标 $j$ 得 $(j-i)\cdot nums[i]$ 分。求到达下标 $n-1$ 时的**最大总得分**。

**约束**：

- $1 \le nums.length \le 10^5$
- $1 \le nums[i] \le 10^5$

> 💡 **读题关键**：约束的是"下标严格增大"，**不是"值增大"**——中途落在值更小的位置完全合法（示例 2 里 $[4,3,1,3,2]$ 从 $4$ 直跳到底，中途全是更小值）。另一个易漏点：得分公式只乘**起跳点**的值，落点值不参与本跳计分。

## 2. 示例

**示例 1**

```text
输入：nums = [1,3,1,5]
输出：7
解释：先跳到下标 1，再跳到最后：1×1 + 2×3 = 7。
```

**示例 2**

```text
输入：nums = [4,3,1,3,2]
输出：16
解释：直接跳到最后：4×4 = 16。
```

**补充示例**（单元素）

```text
输入：nums = [5]
输出：0
解释：起点即终点，无跳跃，得分为 0。
```

## 3. 解题思路

### 3.1 暴力思路

定义 $dp[j]$ 为到达下标 $j$ 的最大得分，则 $dp[j] = \max_{i<j}\big(dp[i] + (j-i)\cdot nums[i]\big)$，答案是 $dp[n-1]$。

- 时间 $O(n^2)$：$n = 10^5$ 时约 $10^{10}$ 次基本操作，**必然超时**。
- 瓶颈在于每一步都在重复比较"从哪个历史位置起跳最划算"。与其问"跳到哪"，不如换个视角问"每一段路该由谁付钱"。

### 3.2 核心观察：拆贡献——把一次长跳拆成逐格走

![拆分贡献概念图](images/reach_end_max_score_decompose.svg)

关键恒等式：从 $i$ 跳到 $j$ 的得分可以**拆开**——

$$(j-i)\cdot nums[i] = \underbrace{nums[i] + nums[i] + \cdots + nums[i]}_{j-i\ \text{项}}$$

即把一次长跳看成"从 $i$ 出发逐格挪到 $j$"：**每跨越一个相邻间隔**（位置 $s$ 与 $s+1$ 之间，记为间隔 $s$），就累加一次 $nums[i]$。于是任意路径的总得分都可以按"间隔"重新记账：

$$\text{总得分} = \sum_{s=0}^{n-2} nums[i(s)]$$

其中 $i(s)$ 是跨越间隔 $s$ 时所在的起跳点，必有 $i(s) \le s$。

> 💡 这一步是全题的胜负手：得分公式 $(j-i)\cdot nums[i]$ 中"步数 $\times$ 单价"的形态，天然适合**按步拆开**；拆开后每个间隔独立计价，优化目标就从"整条路径"退化成"每个间隔各自取最优"。

### 3.3 贪心决策：每个间隔都取前缀最大值

由 $i(s) \le s$，跨越间隔 $s$ 的单步贡献 $nums[i(s)] \le \max(nums[0..s])$（前缀最大值）。于是：

$$\text{总得分} \le \sum_{s=0}^{n-2} \max(nums[0..s])$$

这个上界**可以取到**：构造路径为"只在**下一个更大元素**处换脚"——从 $0$ 出发，一路直跳到下一个值严格更大的位置，直到没有更大值时（当前位置已是全局最大）一跳直达 $n-1$。对这条路径，跨越间隔 $s$ 的起跳点恰好是 $\max(nums[0..s])$ 的位置（见 §5 定理证明）。

因此：

$$\boxed{\ \text{答案} = \sum_{s=0}^{n-2} \max(nums[0..s])\ }$$

等价的 DP 直觉：$dp[j] = dp[j-1] + \max(nums[0..j-1])$——最优方案在"进入 $j$ 之前的那一步"可以一直停在历史最大值处多白嫖一格。

### 3.4 示例演算

![前缀最大值累加演算图](images/reach_end_max_score_walkthrough.svg)

**示例 1**：`nums = [1,3,1,5]`，逐位维护前缀最大并累加（只累加前 $n-1$ 位）：

| $s$ | 0 | 1 | 2 |
|------|---|---|---|
| $\max(nums[0..s])$ | 1 | 3 | 3 |

答案 $= 1 + 3 + 3 = 7$ ✓（对应路径 $0 \to 1 \to 3$：在值 3 处"多待一格"再走）

**示例 2**：`nums = [4,3,1,3,2]`：

| $s$ | 0 | 1 | 2 | 3 |
|------|---|---|---|---|
| $\max(nums[0..s])$ | 4 | 4 | 4 | 4 |

答案 $= 4+4+4+4 = 16$ ✓（开头已是全局最大，全程不换脚，直跳到底）

## 4. 算法细节

1. **一次遍历**：从左到右扫 $i \in [0, n-2]$，维护 $mx = \max(nums[0..i])$，每步 `ans += mx`。间隔 $s$ 与位置 $i$ 一一对应（间隔 $s$ 的贡献恰是 $\max(nums[0..s])$），所以"扫到位置 $i$ 就累加一次当前前缀最大"恰好完成求和。
2. **终点不贡献**：位置 $n-1$ 只作落点，不产生任何间隔的计价，循环上界是 $i+1 < n$（Python 用 `nums[:-1]`）。
3. **增量维护前缀最大**：$mx$ 只需与新元素取 $\max$，无需前缀和数组或单调结构。
4. **求和上界核算**：$n-1$ 个间隔，每个 $\le 10^5$，总量 $\le 10^{10}$，**超出 32 位 int**，C++ 必须用 `long long`。
5. **特判消失**：$n=1$ 时循环体不执行，自然返回 $0$，无需单独分支。

## 5. 正确性证明

**引理 1**（拆分恒等式）：设任意可行路径为 $0 = i_0 < i_1 < \cdots < i_k = n-1$，定义 $i(s)$ 为唯一满足 $i_t \le s < i_{t+1}$ 的 $i_t$（跨越间隔 $s$ 的起跳点）。则总得分

$$\sum_{t=0}^{k-1} (i_{t+1}-i_t)\cdot nums[i_t] = \sum_{s=0}^{n-2} nums[i(s)]$$

**证明**：对每个 $t$，$(i_{t+1}-i_t)\cdot nums[i_t] = \sum_{s=i_t}^{i_{t+1}-1} nums[i_t]$，即这跳的得分等于它跨越的每个间隔各计一次 $nums[i_t]$。区间 $[i_t,\, i_{t+1}-1]$（$t = 0,\ldots,k-1$）两两不交且并集恰为 $[0, n-2]$，逐项求和再合并即得右式。∎

**引理 2**（逐间隔上界）：对任意可行路径与任意间隔 $s \in [0, n-2]$，$nums[i(s)] \le \max(nums[0..s])$。

**证明**：由定义 $i(s) = i_t \le s < i_{t+1}$，故起跳点下标不超过 $s$，其值不超过前 $s+1$ 个元素的最大值。∎

**定理**：最大总得分恰为 $\displaystyle\sum_{s=0}^{n-2} \max(nums[0..s])$。

**证明**：**上界**：由引理 1，总得分 $= \sum_{s} nums[i(s)] \le \sum_{s} \max(nums[0..s])$（引理 2）。**可达**：构造路径 $p_0 = 0$；归纳地令 $p_{t+1}$ 为 $p_t$ 之后**第一个**满足 $nums[j] > nums[p_t]$ 的下标，若不存在则令 $p_{t+1} = n-1$ 并结束（此时 $p_t$ 已是全局最大值位置）。归纳可知 $nums[p_t] = \max(nums[0..p_t])$，且由"第一个更大"的定义，开区间 $(p_t, p_{t+1})$ 内（终跳时为 $(p_t, n-1)$）没有元素超过 $nums[p_t]$。于是对任意间隔 $s \in [p_t, p_{t+1}-1]$，都有 $\max(nums[0..s]) = nums[p_t]$，即该路径跨越间隔 $s$ 时恰好取到上界。由引理 1，其总得分 $= \sum_{s=0}^{n-2} \max(nums[0..s])$，上界取等。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。单次遍历，每个位置只做一次取 $\max$ 与一次累加。
- **空间复杂度**：$O(1)$。只用常数个变量（`mx`、`ans`），不随输入规模增长。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long findMaximumScore(vector<int>& nums) {
        long long ans = 0;
        long long mx = 0;
        for (int i = 0; i + 1 < nums.size(); i++) {
            mx = max(mx, (long long) nums[i]);
            ans += mx;
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def findMaximumScore(self, nums: List[int]) -> int:
        ans = mx = 0
        for x in nums[:-1]:
            mx = max(mx, x)
            ans += mx
        return ans
```

## 8. 边界情况与易错点

1. **读题**：只能移动到更大的**下标**，与落点的值无关。若误读成"值也必须更大"，会把示例 2 判成不可行或另写一套逻辑。
2. **溢出**：答案上界约 $10^5 \times 10^5 = 10^{10}$，超过 `int`（约 $2.1\times10^9$），C++ 必须全程 `long long`；Python 无此虑。
3. **求和不含最后一位**：位置 $n-1$ 只作落点。循环写成 `i <= n-1` 或忘了 `nums[:-1]` 切片会多算一项。
4. **单元素**：$n = 1$ 时答案为 $0$；上述写法循环自然不执行，无需特判，但若用别的循环写法要自查。
5. **贪心不是交换论证**：本题的最优性来自"拆贡献后各间隔**独立**取最优"（§5 定理），不是常见的"相邻交换不影响答案"式贪心——想清楚这一点，才敢在赛中直接写前缀最大值。
6. **与暴力 DP 互验**：$dp[j] = dp[j-1] + \max(nums[0..j-1])$ 与前缀最大值求和形式完全一致（对 $j$ 从 1 到 $n-1$ 求和即得），对拍可快速确认。
