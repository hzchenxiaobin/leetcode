# LeetCode 找出不同的二进制字符串 题解

## 1. 题目概述

- **标题 / 题号**:找出不同的二进制字符串(#1980,Medium)
- **链接**:https://leetcode.cn/problems/find-unique-binary-string/
- **来源**:LeetCode 第 255 场周赛 Q2
- **难度**:中等
- **标签**:数组、哈希表、字符串、回溯、对角线论证

**题意**:给定字符串数组 `nums`,由 $n$ 个**互不相同**的二进制串组成,每个串长度均为 $n$。返回**任意一个**长度为 $n$ 且**没有出现在** `nums` 中的二进制串。

**约束**:

- $1 \le n \le 16$
- $\mathrm{nums}[i]$ 只由 `'0'`/`'1'` 组成,长度恰为 $n$
- 所有串互不相同

**关键背景**:长度为 $n$ 的二进制串共 $2^n$ 个,而 `nums` 只占用其中 $n$ 个——空位永远存在($2^n - n \ge 1$),且占比极高($n = 16$ 时空位占 $99.98\%$)。问题本质是**构造存在性**:不必去数空位,可以直接"造"出一个缺席者。

## 2. 示例

**示例 1**

```text
输入:nums = ["01","10"]
输出:"11"
解释:"11" 没有出现在 nums 中。"00" 也是正确答案。
```

**示例 2**

```text
输入:nums = ["00","01"]
输出:"11"
解释:"11" 没有出现在 nums 中。"10" 也是正确答案。
```

**示例 3**

```text
输入:nums = ["111","011","001"]
输出:"101"
解释:"101" 没有出现在 nums 中。"000"、"010"、"100"、"110" 也是正确答案。
```

> 💡 注意示例输出**不唯一**:判题只校验合法性,任意不在 `nums` 中的长度为 $n$ 的串都算对。

## 3. 解题思路

### 3.1 朴素思路:哈希 + 枚举

最直接的做法:把 $n$ 个串全部塞进**哈希集合**,再从整数 $0$ 到 $2^n - 1$ 逐个生成 $n$ 位二进制串,返回第一个不在集合中的。

- 时间:$O(n^2 + 2^n \cdot n)$(读入 + 枚举查询),$n \le 16$ 时约 $10^6$ 量级,轻松通过;
- 缺陷:复杂度带着 $2^n$。本题 $n \le 16$ 无感,一旦 $n$ 放大到 $30$ 就直接爆炸——没有利用"空位占 $99.98\%$"的结构性质。

另一个"歪招"是**随机生成**后查集合:随机串命中 `nums` 的概率只有 $n / 2^n \le \tfrac{1}{2}$,期望尝试次数不超过 $2$。能过,但随机算法比赛里总要多一道概率论证,不如一个 $O(n)$ 的确定性构造来得稳。

### 3.2 核心观察:康托对角线——用 nums 自己拼出缺席者

把 `nums` 看成 $n \times n$ 的字符矩阵,第 $i$ 行就是 $\mathrm{nums}[i]$。构造:

$$\mathrm{ans}[i] = \begin{cases} '1', & \mathrm{nums}[i][i] = '0' \\ '0', & \mathrm{nums}[i][i] = '1' \end{cases}$$

即把**主对角线**上的字符逐个**取反**后拼成 `ans`。于是对每个下标 $i$:

- $\mathrm{ans}[i] \ne \mathrm{nums}[i][i]$,即 `ans` 与第 $i$ 行**在第 $i$ 位必然不同**(其他位无需关心);
- 一行对一个位置,第 $i$ 行被第 $i$ 位"堵死"——任何一行想与 `ans` 相等,都会被自己对应的对角位否决。

![核心观察](images/c1980_diagonal_concept.svg)

> 💡 这正是集合论中**康托对角线论证**(证明实数不可数)的有限版:任何 $n$ 行的列表都无法覆盖对角线取反得到的那一行。区别只在于康托面对无限列表,我们只有 $n$ 行。

顺带一个漂亮的事实:这个构造**根本没用到"互不相同"**——哪怕 `nums` 里有重复串,对角线取反串依然与下标 $i$ 对应的行在第 $i$ 位不同,照样缺席。题面条件只是"空位足够多"的另一种说法。

### 3.3 算法流程

1. 初始化空串 `ans`;
2. $i$ 从 $0$ 到 $n-1$:取对角字符 $c = \mathrm{nums}[i][i]$,取反后拼到 `ans` 末尾;
3. 返回 `ans`。

![算法流程](images/c1980_construct_flow.svg)

### 3.4 示例演算

以示例 3(`nums = ["111","011","001"]`)为例:

| $i$ | $\mathrm{nums}[i]$ | 对角字符 $\mathrm{nums}[i][i]$ | 取反 | `ans`(逐步) |
|-----|--------|------------|------|--------------|
| 0 | `"111"` | `'1'` | `'0'` | `"0"` |
| 1 | `"011"` | `'1'` | `'0'` | `"00"` |
| 2 | `"001"` | `'1'` | `'0'` | `"000"` |

构造结果 `"000"`——与示例输出 `"101"` 不同,但同样不在 `nums` 中,合法。

示例 1(`nums = ["01","10"]`):对角线 `'0','0'`,取反得 `"11"`,恰与示例输出一致。

![示例演算](images/c1980_example_walkthrough.svg)

## 4. 算法细节

1. **取反的写法**:
   - 判断式:`c == '0' ? '1' : '0'`,最直白;
   - 字符算术:`'1' - c + '0'`(C/C++ 中 `'1' - '0' = 1`,再加回 `'0'`);
   - **异或技巧**:`'0'` 与 `'1'` 的 ASCII 码是相邻整数(48/49),`c ^ 1` 恰好在两者间翻转——C++ 一行 `ans.push_back(nums[i][i] ^ 1)`;Python 对应 `chr(ord(c) ^ 1)`。
   - ⚠️ 常见笔误是写成 `c ^ '1'`(结果是整数 $0$/$1$ 而非字符)或 `'1' - c`(整数),拼串前记得转回字符。
2. **只碰对角线**:整个过程只读 `nums` 的 $n$ 个字符,连任意一整行都不需要读完,矩阵其余 $n^2 - n$ 个字符与答案无关。
3. **与哈希解法对比**:哈希要 $O(n^2)$ 读入 + $O(2^n)$ 枚举;对角线 $O(n)$ 出解,且不依赖 $n \le 16$ 的数据范围,天然抗数据加强。
4. **为什么与"第 $i$ 位"绑定**:相等是逐位判等,`ans` 与第 $i$ 行在第 $i$ 位已经不同,其余 $n-1$ 位**是什么都无所谓**——不必也不能再去管其他位,这正是构造简单的根源。

## 5. 正确性证明

**引理 1(对角位不同)**:对每个 $0 \le i < n$,构造出的 `ans` 满足 $\mathrm{ans}[i] \ne \mathrm{nums}[i][i]$。

**证明**:$\mathrm{ans}[i]$ 定义为 $\mathrm{nums}[i][i]$ 的取反,而字符只有 `'0'`/`'1'` 两种取值,取反后必然变成另一个字符,故二者不等。∎

**引理 2(一位不同则串不同)**:若两个长度相等的字符串在某一位上字符不同,则两串不相等。

**证明**:字符串相等当且仅当逐位字符相同,此为其逆否命题。∎

**定理**:上述算法返回的 `ans` 是一个长度为 $n$ 的二进制串,且 $\mathrm{ans} \notin \mathrm{nums}$。

**证明**:**长度与字符集**:恰好拼接 $n$ 次,每次追加一个 `'0'` 或 `'1'`,故 `ans` 是长度为 $n$ 的二进制串。**缺席性**:任取下标 $i$,由引理 1,`ans` 与 $\mathrm{nums}[i]$ 在第 $i$ 位字符不同;由引理 2,$\mathrm{ans} \ne \mathrm{nums}[i]$。这对所有 $i$ 成立,而 `nums` 的元素恰以 $0 \le i < n$ 为全部下标,故 `ans` 不等于其中任何一个。∎

> 💡 **注记**:证明全程未使用"互不相同",也未使用 $n \le 16$。结论对任意 $n$ 个(允许重复的)长度为 $n$ 的二进制串都成立——对角线构造比题面要求的更强。

## 6. 复杂度分析

- **时间复杂度**:$O(n)$。$n$ 次字符访问 + $n$ 次拼接;即便计入输入本身的 $O(n^2)$ 规模,算法也只触碰对角线上的 $n$ 个字符。
- **空间复杂度**:$O(n)$ 存储答案串(若不计输出,仅 $O(1)$ 额外空间)。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    string findDifferentBinaryString(vector<string>& nums) {
        int n = nums.size();
        string ans;
        ans.reserve(n);
        for (int i = 0; i < n; ++i) {
            // '0' 与 '1' 的 ASCII 码相邻,异或 1 恰好翻转
            ans.push_back(nums[i][i] ^ 1);
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def findDifferentBinaryString(self, nums: List[str]) -> str:
        ans = []
        for i, s in enumerate(nums):
            ans.append('1' if s[i] == '0' else '0')
        return ''.join(ans)
```

## 8. 边界情况与易错点

1. **n = 1**:`nums = ["0"]` → `ans = "1"`;`nums = ["1"]` → `ans = "0"`。对角线只有一格,翻转即得,无需特判。
2. **答案不唯一**:对角线构造的输出可能与示例不同(示例 3 得 `"000"` 而非 `"101"`),题目明确"任意一个即可",判题按合法性校验,不要对着示例输出硬凑。
3. **取反笔误**:`c ^ 1` 是字符翻转,`c ^ '1'`、`'1' - c` 都得到整数 $0$/$1$,直接拼进字符串会出问题;Python 里 `ord`/`chr` 要配对使用。
4. **别用错对角线**:是 `nums[i][i]`(第 $i$ 行第 $i$ 列),不是 `nums[0][i]`(第一行)——后者取反只保证与第一行不同,可能与别的行撞车。
5. **哈希枚举的坑**(若走朴素路线):按整数枚举时要**补前导零**到 $n$ 位(Python `format(x, '0{}b'.format(n))`,C++ `bitset<16>(x).to_string().substr(16 - n)`),否则生成的串长度不对。
6. **不必利用"互不相同"**:构造对重复串同样成立,因此不需要先去重或判重。
7. **复杂度错觉**:输入规模是 $O(n^2)$ 个字符,但算法是 $O(n)$——不要想当然地认为必须读完整个输入。

**延伸思考**:

- **字典序最小**的缺席串怎么求?对角线构造不保证字典序,需改用位数组标记占用(仅 $2^n$ 位、$n = 16$ 时 8KB),再从整数 $0$ 向上找第一个空位。
- **字母表推广**:把 01 串换成字母表大小为 $m$、长度为 $n$ 的串,只要 $m \ge 2$,对角线法依然成立——第 $i$ 位任取一个 $\ne \mathrm{nums}[i][i]$ 的字符即可。这说明 $n$ 行名单永远盖不住 $m^n$ 的空间($m \ge 2$)。
- **回到康托**:对角线论证的原始形态是证明 $(0,1)$ 内实数不可数:对任意实数列表 $r_1, r_2, \dots$,构造 $s$ 使其第 $i$ 位与 $r_i$ 的第 $i$ 位不同,则 $s$ 不在列表中。无限版本需小心 $0.0999\cdots = 0.1$ 的表示不唯一问题,康托用避开数字 $0$/$9$ 化解;本题的二进制有限版则完全没有这种歧义。
