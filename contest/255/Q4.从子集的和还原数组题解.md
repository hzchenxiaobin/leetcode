# LeetCode 从子集的和还原数组 题解

## 1. 题目概述

- **标题 / 题号**：从子集的和还原数组（#1982，hard）
- **链接**：https://leetcode.cn/problems/find-array-given-subset-sums/
- **来源**：LeetCode 第 255 场周赛 Q4
- **难度**：困难
- **标签**：数组、哈希表、计数、排序、子集和

**题意**：存在一个未知的长度为 $n$ 的整数数组 `arr`。给定 `sums`，它由 `arr` 的**全部** $2^n$ 个子集和构成（顺序打乱、含空集的 $0$、含重复）。还原出**任意一个**合法的 `arr`。

**约束**：

- $1 \le n \le 15$
- $\text{sums.length} = 2^n$
- $-10^4 \le \text{sums}[i] \le 10^4$
- 保证至少存在一个正确答案

> 💡 关键数据画像：$n \le 15 \Rightarrow 2^n \le 32768$，输入规模本身就是"指数级但有限"；题目把 $2^n$ 个子集和**一个不漏**地交给我们——信息是完备的，这是"可重构"的根源。注意元素可正、可负、可为零，且**答案不唯一**（题面明说任意合法解都接受）。

## 2. 示例

**示例 1**

```text
输入：n = 3, sums = [-3,-2,-1,0,0,1,2,3]
输出：[1,2,-3]
解释：[1,2,-3] 的全部子集和恰好是给出的 8 个数。
注意 [-1,-2,3] 的任何排列同样正确——答案不唯一。
```

**示例 2**

```text
输入：n = 2, sums = [0,0,0,0]
输出：[0,0]
解释：唯一合法答案是 [0,0]。
```

**示例 3**

```text
输入：n = 4, sums = [0,0,5,5,4,-1,4,9,9,-1,4,3,4,8,3,8]
输出：[0,-1,4,5]
解释：[0,-1,4,5] 的全部子集和与输入一致。
```

> ⚠️ 三个示例各暗藏一个考点：示例 1 有负数；示例 2 全零（$x$ 会取到 $0$，配对退化）；示例 3 同时有零、负数和大量重复子集和（两个 $0$、三个 $4$……多重集的"重数"必须精确处理）。

## 3. 解题思路

### 3.1 暴力思路：猜元素 + 回溯剥离

**值域枚举**：每个元素从 $[-10^4, 10^4]$ 取值，组合数 $(2 \times 10^4 + 1)^{15} \approx 10^{64}$，完全不可行。

**逐个剥离**：如果已知数组里有元素 $x$，理论上可以把 `sums` 分成两半——不含 $x$ 的子集和集合 $B$，与含 $x$ 的 $B + x$——递归处理 $B$。问题是：**$x$ 是谁不知道、两半的归属也不知道**。朴素做法要对每个候选 $x$（`sums` 中两两之差，最多 $4^n$ 个）逐一试错、归属还要回溯，指数叠指数。

真正的出路不是"试"，而是"读"：`sums` 的**结构**直接告诉我们该剥离谁、怎么分，全程无分支、无回溯。下面按三步展开。

### 3.2 核心观察①：最小子集和 = 所有负数之和，平移即绝对值化

设 `arr` 中负数元素全体为 $N$、非负元素全体为 $P$。任意子集和 $s = \text{sum}(S \cap N) + \text{sum}(S \cap P) \ge \text{sum}(N)$（去掉负数只增、加上非负不减），且 $S = N$ 时取等。所以**排序后 `sums[0]` 就是所有负数元素之和 `neg`**。

关键推论：把每个子集和 $s$ 替换为 $s - \text{neg}$，得到的多重集**恰好是"全部元素取绝对值后"的数组 $X = [|a_1|, \dots, |a_n|]$ 的子集和多重集**（引理 2 严格证明）。负号信息被压缩进一个整数 `neg`，世界从"有正有负"化归为"全非负"。

![平移绝对值化](images/c1982_abs_shift_concept.svg)

### 3.3 核心观察②：提取最小元素 x = M[1]，配对 (v, v+x) 减半

在"全非负"的世界里，子集和多重集 $M$（升序）满足：

- $M[0] = 0$（空集；若数组含 $0$ 元素则 $0$ 的重数更多）；
- $M[1] = $ 数组的最小元素 $x$（最小的非空子集和 = 最小元素，引理 4）。

每一轮取出 $x = M[1]$，把 $M$ 按**配对 $(v,\ v+x)$** 分成两半：不含 $x$ 的子集构成 $B$、含 $x$ 的是 $B + x$，而 $B$ 恰是"去掉一个 $x$ 后"数组的子集和多重集（引理 5）。配对用一个哈希计数 + **升序扫描**即可完成：扫到 $v$ 且计数仍大于 $0$，则 $v$ 必属"不含 $x$"侧，消耗一个 $v$ 和一个 $v+x$。

循环 $n$ 轮，$M$ 的规模 $2^n \to 2^{n-1} \to \dots \to 1$，剥离出全部 $|a_i|$。

![配对提取流程](images/c1982_pair_split_flow.svg)

### 3.4 符号恢复：解一个 n ≤ 15 的子集和

拿到绝对值 $X$ 后只剩最后一步：给哪些数分配负号？标准只有一个——**负号部分的绝对值之和必须等于 $-\text{neg}$**（这样才能还原出原始的最小子集和）。即从 $X$ 中选子集 $T$ 使 $\text{sum}(T) = -\text{neg}$。

妙处在于**任选一个满足条件的 $T$ 都行**：子集和多重集只依赖 $(X, \text{sum}(T))$，与具体选了哪些数无关（引理 3 的"翻转双射"）。而真正的负数集合必然存在，所以这个小规模子集和（$n \le 15$）一定有解，DP / bitset / 折半搜索均可。

![符号恢复](images/c1982_sign_recovery_lemma.svg)

### 3.5 示例演算

以示例 3（$n=4$）为例，全程演算如下：

![示例演算](images/c1982_example_walkthrough.svg)

| 阶段 | 取值 | 操作 | 新的 M |
|------|------|------|--------|
| 平移 | neg = −1 | 全体 +1 | 0,0,1,1,4,4,5,5,5,5,6,6,9,9,10,10 |
| 第 1 轮 | x = 0 | 配对 (v, v) 自配对 | 0,1,4,5,5,6,9,10 |
| 第 2 轮 | x = 1 | (0,1)(4,5)(5,6)(9,10) | 0,4,5,9 |
| 第 3 轮 | x = 4 | (0,4)(5,9) | 0,5 |
| 第 4 轮 | x = 5 | (0,5) | 0 |
| 符号 | target = 1 | T = {1} | ans = [0,−1,4,5] ✓ |

> 💡 两个耐人寻味的瞬间：第 1 轮的 $x=0$ 对应"数组里有 $0$ 元素"，配对退化成同值自配对，每种值留下一半，**代码无需任何特判**；而第 2 轮里值 $5$ 出现两次、一次当基（绿色）一次当配对（灰色），正是**必须用计数而非集合**的原因。

## 4. 算法细节

1. **三段式结构**：平移（依赖引理 1、2）→ $n$ 轮配对剥离（依赖引理 4、5）→ 符号恢复（依赖引理 3）。每一步都是确定性的，无回溯。
2. **平移方向**：是 $s \leftarrow s - \text{neg}$。注意 $\text{neg} \le 0$，所以等价于加上 $|\text{neg}|$；写反成 $s + \text{neg}$ 会把最小值推到 $2 \cdot \text{neg}$。
3. **为什么取 M[1] 而不是 M[0]**：空集贡献的 $0$ 永远占据最小位。$M[1]$ 才是最小元素——包括"最小元素就是 $0$"的情形（此时 $0$ 的重数 $\ge 2$，$M[1]$ 仍取到 $0$，逻辑自洽）。
4. **配对为什么用哈希计数而非双指针**：同一个值 $v$ 可能**同时**出现在 $B$ 侧和 $B+x$ 侧（如示例演算第 2 轮的两个 $5$），归属无法由值本身判断，只有"升序扫描 + 计数消耗"能表达这种重数交叉。扫描升序保证"最小未消耗值必为基本身"（引理 5）。
5. **每轮不必重新排序**：`nxt` 由升序扫描生成，天然升序；重排序不致错但白费 $O(2^k \log 2^k)$。
6. **符号恢复的实现**：$|a_i| \le 10^4$（单元素子集和也在 `sums` 中），故 $\text{sum}(X) \le 1.5 \times 10^5$。C++ 用 `bitset<150001>` 逐前缀记录可达和再回溯；Python 用字典 $\{\text{可达和} \to \text{选法掩码}\}$ 一步到位。
7. **输出顺序无关**：答案的任何排列都被接受，不必刻意排序。

## 5. 正确性证明

**引理 1（最小子集和）**：排序后 $\text{sums}[0] = \text{neg}$，即 `arr` 中所有负数元素之和。

**证明**：任取子集 $S$，记 $N$ 为全体负数元素之集、$P$ 为全体非负元素之集。$s = \text{sum}(S \cap N) + \text{sum}(S \cap P)$。由 $S \cap N \subseteq N$ 且每个元素为负，去掉负元素只会变大，故 $\text{sum}(S \cap N) \ge \text{sum}(N)$；又元素非负故 $\text{sum}(S \cap P) \ge 0$。于是 $s \ge \text{sum}(N)$，且 $S = N$ 时取等。即所有子集和 $\ge \text{neg}$ 且 $\text{neg}$ 本身是子集和。∎

**引理 2（平移 = 绝对值化）**：记 $X = [|a_1|, \dots, |a_n|]$，则多重集 $\{s - \text{neg} \mid s \in \text{sums}\}$ 等于 $X$ 的子集和多重集。

**证明**：任取 $X$ 的子集 $U$，其和为
$$t = \sum_{i \in U \cap P} a_i + \sum_{i \in U \cap N} |a_i| = \sum_{i \in U \cap P} a_i - \sum_{i \in U \cap N} a_i.$$
构造原数组的子集 $S = (U \cap P) \cup (N \setminus (U \cap N))$，则
$$\text{sum}(S) - \text{neg} = \sum_{U \cap P} a_i + \sum_{N \setminus (U \cap N)} a_i - \sum_{N} a_i = \sum_{U \cap P} a_i - \sum_{U \cap N} a_i = t.$$
反之，对任意子集 $S$，取 $U = (S \cap P) \cup (N \setminus S)$，可验证两个构造互为逆映射（$U \mapsto S \mapsto U$ 复合为恒等），故 $U \leftrightarrow S$ 是双射，两个多重集逐元素相等。∎

**引理 3（符号无关性）**：对 $X$ 的任意子集 $T$，令 $\text{ans}_T$ 为"$i \in T$ 取 $-|a_i|$、否则取 $+|a_i|$"的数组，则 $\text{ans}_T$ 的子集和多重集 $= \{u - \text{sum}(T) \mid u \in X\text{ 的子集和多重集}\}$。

**证明**：$\text{ans}_T$ 的子集 $S$ 之和为 $\sum_{i \in S \setminus T} x_i - \sum_{i \in S \cap T} x_i$。令 $S^* = S \oplus T$（对称差），则
$$\sum_{i \in S^*} x_i = \sum_{i \in S \setminus T} x_i + \sum_{i \in T \setminus S} x_i = \sum_{i \in S \setminus T} x_i + \Big(\text{sum}(T) - \sum_{i \in S \cap T} x_i\Big),$$
移项即得 $S$ 的和 $= \sum_{i \in S^*} x_i - \text{sum}(T)$。$S \mapsto S^*$ 是子集间的双射。∎

> 💡 **推论**：若 $\text{sum}(T) = -\text{neg}$，则 $\text{ans}_T$ 的子集和多重集 $= \{u + \text{neg}\} \stackrel{\text{引理 2}}{=} \text{sums}$。真正的负数集合 $T^*$ 满足 $\text{sum}(T^*) = -\text{neg}$，故子集和搜索必有解；**搜到的任何 $T$ 都给出合法答案**。这也解释了示例 1 中 $[1,2,-3]$ 与 $[-1,-2,3]$ 的等价性。

**引理 4（M[1] = 最小元素）**：全非负数组 $A$ 的子集和多重集 $M$ 升序后，$M[0] = 0$，$M[1] = \min(A)$。

**证明**：空集给 $0$，且所有元素 $\ge 0$ 意味着任何子集和 $\ge 0$，故 $M[0] = 0$。任何非空子集和是若干个 $\ge \min(A)$ 的数之和，故 $\ge \min(A)$；单元素子集 $\{\min(A)\}$ 取等。若 $\min(A) = 0$，则 $0$ 的重数 $\ge 2$（空集与该元素），$M[1] = 0$；否则 $0$ 的重数恰为 $1$（仅空集），$M[1] = $ 最小非空子集和 $= \min(A)$。∎

**引理 5（配对分解与贪心）**：设 $A$ 全非负、$x = \min(A)$、$B$ 为 $A$ 删去一个 $x$ 后的子集和多重集，则 (i) $M = B \uplus (B + x)$（多重集不相交并）；(ii) 升序计数贪心恰好输出 $B$。

**证明**：(i) $A$ 的每个子集要么不含被删的那个 $x$（和落在 $B$ 中）、要么含它（和落在 $B + x$ 中），二分不重不漏。(ii) 设 $x > 0$（$x = 0$ 时 $M = B \uplus B$ 每种重数翻倍，同值自配对每次消耗两份，显然成立）。对扫描进度归纳，证明**到达值 $v$ 时 $\text{cnt}[v] = \text{mult}_B(v)$**：值的副本只会因"基 $w$ 被输出"（消耗 $w$ 与 $w+x$）而减少。到达 $v$ 前，只有基 $v - x < v$ 的输出会消耗 $v$ 的副本，由归纳假设基 $v-x$ 已全部输出（$\text{mult}_B(v-x)$ 个）；而由 (i)，$v$ 在 $M$ 中的总重数 $= \text{mult}_B(v) + \text{mult}_B(v-x)$，故剩余恰为 $\text{mult}_B(v)$。随后循环输出这 $\text{mult}_B(v)$ 个基，每个消耗一份 $v + x$；此刻 $v+x$ 的剩余数 $= \text{mult}_B(v+x) + \text{mult}_B(v) \ge \text{mult}_B(v)$，**恰好够用**，用完后剩余 $\text{mult}_B(v+x)$ 份，归纳性质传递给值 $v + x$。∎

**定理（算法正确性）**：算法输出的 `ans` 的子集和多重集与输入 `sums` 相等。

**证明**：对轮数 $k$ 归纳：第 $k$ 轮开始时，$M$ 恰为"尚未剥离的 $n-k$ 个绝对值元素"的子集和多重集——$k=0$ 由引理 2 成立，每轮由引理 5 保持。$n$ 轮后 $M = \{0\}$（空数组的子集和），`xs` 收齐全部 $|a_i|$。最后一步找到 $\text{sum}(T) = -\text{neg}$ 的子集（$T^*$ 的存在性保证可找到），由引理 3 的推论，输出的 `ans` 合法。∎

## 6. 复杂度分析

- **时间复杂度**：$O(2^n \cdot n)$。排序 $O(2^n \log 2^n)$；$n$ 轮配对各遍历当前规模一轮，合计 $\sum_{k=1}^{n} 2 \cdot 2^k = O(2^{n+1})$ 次哈希操作；符号恢复 $O(n \cdot \text{sum}(X) / w)$（bitset，$w$ 为字长）或 $O(n \cdot 2^n)$（枚举）。代入 $n = 15$：约 $6.6 \times 10^4$ 次配对 + $5 \times 10^5$ 次排序比较，实测 C++ 数毫秒、Python 约 65ms。
- **空间复杂度**：$O(2^n)$ 存多重集与计数哈希；bitset 版本额外 $O(n \cdot 1.5 \times 10^5 / 8) \approx 300\text{KB}$。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    vector<int> recoverArray(int n, vector<int>& sums) {
        sort(sums.begin(), sums.end());
        int neg = sums[0];                    // 所有负数元素之和(引理 1)
        for (int& s : sums) s -= neg;         // 平移成绝对值数组的子集和(引理 2)
        vector<int> xs;                       // 依次剥离出的 |a_i|
        for (int i = 0; i < n; ++i) {
            int x = sums[1];                  // 当前最小元素(引理 4)
            unordered_map<int, int> cnt;
            for (int s : sums) ++cnt[s];
            vector<int> nxt;
            for (int v : sums) {              // 升序扫描:配对 (v, v+x)(引理 5)
                if (cnt[v] > 0) {
                    --cnt[v];
                    --cnt[v + x];             // 保证必然存在
                    nxt.push_back(v);
                }
            }
            sums = move(nxt);                 // 规模减半,天然升序
            xs.push_back(x);
        }
        int target = -neg;                    // 负数元素绝对值之和
        vector<bitset<150001>> reach(n + 1);  // reach[i] = 前 i 个数可凑出的和
        reach[0][0] = 1;
        for (int i = 0; i < n; ++i)
            reach[i + 1] = reach[i] | (reach[i] << xs[i]);
        vector<int> ans;
        int t = target;
        for (int i = n - 1; i >= 0; --i)      // 回溯选出子集 T(引理 3:任选即可)
            if (reach[i][t]) ans.push_back(xs[i]);
            else { t -= xs[i]; ans.push_back(-xs[i]); }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def recoverArray(self, n: int, sums: List[int]) -> List[int]:
        sums.sort()
        neg = sums[0]                        # 所有负数元素之和(引理 1)
        sums = [s - neg for s in sums]       # 平移成绝对值数组的子集和(引理 2)
        xs = []                              # 依次剥离出的 |a_i|
        for _ in range(n):
            x = sums[1]                      # 当前最小元素(引理 4)
            cnt = Counter(sums)
            nxt = []
            for v in sums:                   # 升序扫描:配对 (v, v+x)(引理 5)
                if cnt[v] > 0:
                    cnt[v] -= 1
                    cnt[v + x] -= 1
                    nxt.append(v)
            sums = nxt
            xs.append(x)
        target = -neg
        dp = {0: 0}                          # 可达和 -> 一种选法掩码
        for i, x in enumerate(xs):
            for s, m in list(dp.items()):    # 快照保证每个数只用一次
                if s + x not in dp:
                    dp[s + x] = m | (1 << i)
        mask = dp[target]                    # 引理 3 保证必存在
        return [-x if mask >> i & 1 else x for i, x in enumerate(xs)]
```

> 两份代码均通过：官方示例 1/2/3、$n \le 8$ 共 24000 组随机数组（含全零、全负、极值 $\pm 10^4$、重复元素）与暴力子集和对拍、$n = 15$ 大规模压测。

## 8. 边界情况与易错点

1. **取 M[1] 而非 M[0]**：空集的 $0$ 永远占最小位。数组含 $0$ 元素时 $x = 0$、配对退化为 $(v, v)$ 自配对——计数对同值连续减两次即可，**千万别写 `if v + x in cnt` 之类的特判把 $x=0$ 排除掉**。
2. **平移方向写反**：应为 $s - \text{neg}$（即加 $|\text{neg}|$）。判据很简单：平移后最小值必须变成 $0$。
3. **符号恢复的目标是 $-\text{neg}$ 而非 $\text{neg}$**：要凑的是"负数元素的绝对值之和"。
4. **空集 T 必须被允许**：原数组全非负时 $\text{neg} = 0$、target $= 0$，空集即解；DP 初值 $\{0\}$ 天然覆盖，但若手写搜索别忘了"什么都不选"这个分支。
5. **bitset 大小 150001 的由来**：$|a_i| \le 10^4$（单元素子集和也在 `sums` 里），$n \le 15$，故 $\text{sum}(X) \le 1.5 \times 10^5$。若题目加强数据需同步扩容。
6. **消耗 `v + x` 时的静默负数**：哈希表 `operator[]` 会隐式建键，逻辑一旦有错计数会悄悄变负而不报错——本地对拍时不妨加 `assert(cnt[v + x] > 0)`（引理 5 保证正确实现下永不触发）。
7. **函数会消耗入参**：`recoverArray` 按引用接收 `sums` 并将其排序、平移、逐轮缩小；本地测试若还要用原始输入做校验，**务必先留副本**（笔者对拍时就栽在这里）。
8. **本地对拍比什么**：答案不唯一，不能比较数组本身，要比较**排序后的子集和多重集**。
9. **不要在每轮重新排序**：`nxt` 天然升序；每轮 `sort` 一遍不致错，但白白多出 $O(2^n \log 2^n)$。

- [LeetCode 1755. 最接近目标值的子序列和](https://leetcode.cn/problems/closest-subsequence-sum/)：$n \le 40$ 的子集和问题，必须 meet in the middle——子集和家族的"大数据版"对照。
- [LeetCode 805. 数组的均值分割](https://leetcode.cn/problems/split-array-with-same-average/)：子集和判定 + 数学剪枝。
- [LeetCode 698. 划分为k个相等的子集](https://leetcode.cn/problems/partition-to-k-equal-sum-subsets/)：子集和搜索 + 状态压缩，$n$ 小时枚举子集的又一范例。

**延伸思考**：

- **$n$ 更大怎么办**：$n = 20$ 时 $2^{20} \approx 10^6$ 个数，配对部分仍是 $O(2^n)$、勉强可行，符号恢复的 bitset 也要扩到 $2 \times 10^5$ 位；$n$ 再大题目连输入都给不出——这正是本题 $n \le 15$ 的原因。
- **多项式视角**：子集和多重集就是乘积 $(1 + x^{a_1})(1 + x^{a_2}) \cdots (1 + x^{a_n})$ 展开后非零项的指数集合，本题等价于"由多项式的支集反推因式分解"。由此可理解答案为何不唯一——分解不唯一、以及引理 3 描述的"整体乘 $x^{\text{sum}(T)}$ 平移"不变性。
- **唯一性刻画**：答案唯一当且仅当绝对值分解唯一且满足 $\text{sum}(T) = -\text{neg}$ 的子集唯一；例如 $[1, 2]$ 唯一，而 $[1, 2, 3]$ 至少有 $[1,2,-3]$ 与 $[-1,-2,3]$ 两种合法还原。
- **带噪声的重构**：若 `sums` 丢失或多余若干值，确定性配对立刻崩溃，需要统计与容错意义下的完全不同的算法——有兴趣可以检索"subset sum reconstruction"相关文献。
