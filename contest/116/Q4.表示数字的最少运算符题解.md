# LeetCode 表示数字的最少运算符 题解

## 1. 题目概述

- **标题 / 题号**：表示数字的最少运算符（#964，hard）
- **链接**：https://leetcode.cn/problems/least-operators-to-express-number/
- **来源**：LeetCode 第 116 场周赛 Q4
- **难度**：困难
- **标签**：记忆化、数学、动态规划

**题意**：给定正整数 $x$，我们要写出形如 `x (op1) x (op2) x ... x` 的表达式，其中每个 `op` 是 `+`、`-`、`*`、`/` 之一。规则是：

- 除法返回**有理数**（不取整）；
- **不允许括号**，按通常优先级（先乘除、后加减）计算；
- **不允许一元负号**（`x - x` 合法，`-x + x` 不合法）。

求使表达式值等于 `target` 的**最少运算符个数**。

**约束**：

- $2 \le x \le 100$
- $1 \le target \le 2\times10^8$

## 2. 示例

**示例 1**

```text
输入：x = 3, target = 19
输出：5
解释：3 * 3 + 3 * 3 + 3 / 3 = 9 + 9 + 1 = 19，共 5 个运算符。
```

**示例 2**

```text
输入：x = 5, target = 501
输出：8
解释：5 * 5 * 5 * 5 - 5 * 5 * 5 + 5 / 5 = 625 - 125 + 1 = 501，共 8 个运算符。
```

**示例 3**

```text
输入：x = 100, target = 100000000
输出：3
解释：100 * 100 * 100 * 100 = 10^8，用 3 个乘号。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的想法是 BFS/DFS 搜索所有表达式，按运算符个数逐层扩展。问题是：

- 除法会产生**有理数**，状态空间是无限（稠密）的；
- 表达式长度没有先验上界，分支因子是 4，很快就会爆炸；
- 即使限定"最多用 $L$ 个运算符"，候选表达式的数量也是 $4^L$ 级别，$L$ 只要到 10 就无法承受。

必须先把表达式的**结构**刻画清楚，把"搜索字符串"变成"枚举整数参数"。

### 3.2 核心观察：表达式 = 带符号的 $x$ 的幂之和

![无括号 + 乘除优先 ⟹ 表达式是若干 ±x^e 的和](images/wc116_q4_normal_form.svg)

**观察 1（正规形）**：没有括号、且乘除优先于加减，所以任何表达式都可以按顶层 `+`/`-` 切成若干段，每一段是若干个 $x$ 的连乘/连除，值为 $x$ 的某个整数次幂。于是

$$\text{表达式的值} = \sum_{j=1}^{m} s_j\, x^{e_j}, \qquad s_j \in \{+1, -1\},\ e_j \ge 0.$$

（实际允许负指数，但可以证明最优解不需要它们，见引理 3。）

**观察 2（单项式的代价）**：

| 单项式 | 需要的 $x$ 个数 | 运算符个数 |
|--------|-----------------|------------|
| $x^1 = x$ | 1 | $0$ |
| $x^2 = x \cdot x$ | 2 | $1$ |
| $x^e\ (e \ge 1)$ | $e$ | $e-1$ |
| $x^0 = 1 = x / x$ | 2 | $1$ |

把 $m$ 个单项式用 `+`/`-` 连接起来，还要额外 $m - 1$ 个运算符。所以总代价为

$$\text{cost} = \sum_{j=1}^{m} \text{ops}(e_j) + (m - 1), \qquad \text{ops}(e) = \begin{cases} 1, & e = 0,\\ e - 1, & e \ge 1.\end{cases}$$

**观察 3（主项只能是 $x^k$ 或 $x^{k+1}$）**：设 $x^k \le t < x^{k+1}$（$t \ge x$）。

- 若 $t$ 恰为 $x^k$：直接用 $k$ 个 $x$ 连乘，代价 $k - 1$，显然最优；
- 否则，最优表达式的"最大项"要么是 $+x^k$（再把差额 $t - x^k$ 递归表示），要么是 $-x^{k+1}$（再用 $x^{k+1} - t$ 去减）。**用更大或更小的幂都会更贵**——用 $x^{k+2}$ 需要额外付出至少 $k+1$ 个运算符构造主项，还要付出更多项去抵消；而所有项都不超过 $x^{k-1}$ 时，至少需要 $\lceil t/x^{k-1}\rceil \ge x$ 个正项，代价同样超过按 $x^k$ 分解。

**观察 4（小目标的封闭形式）**：当 $1 \le t < x$ 时，可用的幂只有 $x^0 = 1$ 和 $x^1 = x$：

- 用 $t$ 个 $1$ 累加：代价 $t \cdot 1 + (t-1) = 2t - 1$；
- 用 $x$ 减去 $(x - t)$ 个 $1$：代价 $0 + (x-t)\cdot 1 + (x-t) = 2(x-t)$。

因此 $f(t) = \min(2t - 1,\ 2(x - t))$。

### 3.3 递归式

![递归分解：t ≥ x 时二分叉，t < x 时用封闭形式](images/wc116_q4_recursion.svg)

设 $f(t)$ 为表示 $t$ 的最少运算符数，$k$ 由 $x^k \le t < x^{k+1}$ 确定：

$$
f(t) =
\begin{cases}
\min(2t - 1,\ 2(x - t)), & 1 \le t < x,\\[4pt]
k - 1, & t = x^k,\\[4pt]
\min\big(k + f(t - x^k),\ k + 1 + f(x^{k+1} - t)\big), & \text{其他 } t \ge x.
\end{cases}
$$

用记忆化搜索实现，递归深度只有 $O(\log_x t)$。

### 3.4 示例演算

![x = 3, target = 19 的递归分解](images/wc116_q4_walkthrough.svg)

以 `x = 3, target = 19` 为例，$3^2 = 9 \le 19 < 27 = 3^3$，故 $k = 2$：

| 分解方式 | 子问题 | 子问题答案 | 总代价 |
|----------|--------|------------|--------|
| $19 = 9 + 10$ | $f(10)$：$9 \le 10 < 27$，$k=2$，$10 = 9 + 1$，$f(1) = \min(1, 4) = 1$ | $f(10) = 2 + 1 = 3$ | $2 + 3 = 5$ ✓ |
| $19 = 27 - 8$ | $f(8)$：$3 \le 8 < 9$，$k=1$；$8 = 9 - 1 \Rightarrow f(8) = 2 + f(1) = 3$ | $f(8) = 3$ | $2 + 1 + 3 = 6$ |

取较小者得 $f(19) = 5$，对应 `3*3 + 3*3 + 3/3`。

对 `x = 5, target = 501`：$5^3 = 125 \le 501 < 625$，$k = 3$。

- $501 = 125 + 376$：继续递归，代价 $\ge 3 + 5 = 8$ 量级；
- $501 = 625 - 124$：$f(124)$ 中 $5^2 = 25 \le 124 < 125$，$124 = 125 - 1 \Rightarrow f(124) = 2 + 1 + f(1) = 4$，故总代价 $3 + 1 + 4 = 8$ ✓，对应 `5*5*5*5 - 5*5*5 + 5/5`。

对 `x = 100, target = 10^8`：$10^8 = 100^4$ 恰为幂，直接返回 $4 - 1 = 3$ ✓。

## 4. 算法细节

1. **记忆化**：同一个 $t$ 会被不同分支重复访问（例如 $t - x^k$ 与 $x^{k+1} - t$ 可能同值），用哈希表缓存，状态数只有 $O(\log_x^2 t)$ 级别。
2. **求 $k$ 与 $x^k$**：从 `p = x, k = 1` 开始，`while p * x <= t: p *= x, k++`，循环结束时 $p = x^k \le t < p \cdot x$。$t \le 2\times10^8$、$x \ge 2$ 时循环至多 28 次。
3. **整除判定**：`p == t` 时直接返回 $k - 1$；注意 $k$ 是"$x$ 的个数"，乘号是 $k - 1$ 个（$x$ 本身不需要运算符）。
4. **两个子问题都必为正**：$t - x^k > 0$（因为 $p \ne t$ 且 $p \le t$），$x^{k+1} - t > 0$（因为 $t < x^{k+1}$），所以递归不会进入 $t \le 0$。
5. **注意递归可能"变大"甚至成环**：$x^{k+1} - t$ 未必小于 $t$（如 $x = 3$、$t = 4$ 时 $9 - 4 = 5 > 4$），继续分解 5 又会得到 $9 - 5 = 4$，形成 2-循环。这类环每绕一圈都要多付至少两个运算符，因此**不可能出现在最优解里**；实现上用 DFS 栈标记 `onStack`，重复进入祖先状态时返回 $+\infty$ 即可，既保证终止也保证正确。
6. **小目标公式的下标**：$f(1) = \min(1, 2(x-1)) = 1$，对应 $x/x$；$x = 2$ 时 $f(1) = \min(1, 2) = 1$ 仍然正确。
7. **数值范围**：$t \le 2\times10^8$，`int` 足够；但 `p * x` 可能达到 $x^{k+1} > 2\times10^8$，用 `long long` 保险。
8. **递归深度**：沿"用 $x^k$ 补差"的分支 $t$ 严格减小；"用 $x^{k+1}$ 减差"的分支可能暂时变大，但配合 `onStack` 断环后状态集合有限（不同 $k$ 只有 $O(\log_x t)$ 档），递归深度同样是 $O(\log_x t) \le 30$ 量级，不会爆栈。
9. **不需要构造表达式**：只返回运算符个数；若要输出方案，则在每个状态记录选择了哪种分解。

## 5. 正确性证明

**引理 1（正规形与代价公式）**：任何合法表达式的值都可写成 $\sum_{j=1}^m s_j x^{e_j}$（$s_j \in \{\pm 1\}$，$e_j \in \mathbb{Z}$），且其运算符个数至少为 $\sum_j \mathrm{ops}(e_j) + (m-1)$，其中 $\mathrm{ops}(0) = 1$、$\mathrm{ops}(e) = \lvert e\rvert - 1$（$e \ne 0$）；当所有 $e_j \ge 0$ 时取等。

**证明**：对表达式的语法结构归纳。乘除优先且无括号，故表达式在顶层被 `+`/`-` 切成 $m$ 段，每段是 $x$ 的乘除链，值为 $\pm x^e$（$e$ 为乘号数减除号数）。构造 $x^e$（$e \ge 1$）至少需要 $e-1$ 个运算符，构造 $x^0$ 至少需要 1 个（$x/x$），构造 $x^{-e}$ 至少需要 $e+1$ 个；连接 $m$ 段至少需要 $m - 1$ 个运算符。各段运算符互不共享，故总数下界成立；按"每段最省 + 一个连接符"构造即可取等。∎

**引理 2（小目标公式）**：$1 \le t < x$ 时，$f(t) = \min(2t-1,\ 2(x-t))$。

**证明**：此时可用的非负幂只有 $x^0 = 1$ 与 $x^1 = x$。设表达式用了 $a$ 个 $\pm x$ 项与 $b$ 个 $\pm 1$ 项（$m = a + b$）。

- $a = 0$：只能用 $1$ 的加减凑出 $t$，至少需要 $t$ 个 $1$，代价 $\ge t + (t-1) = 2t-1$；
- $a = 1$：若符号为 $+$，则剩余 $1$ 项需凑出 $t - x < 0$，即至少 $x - t$ 个 $-1$，代价 $\ge (x-t) + (x-t) = 2(x-t)$；若符号为 $-$，则需凑 $t + x > x$，代价更大；
- $a \ge 2$：值至少为 $2x - (x-1) > x > t$（需要更多负项抵消），代价严格大于上述两种。

故最优值即 $\min(2t-1, 2(x-t))$，且两种情况都能构造达到。∎

**引理 3（最优解不需要负指数）**：存在最优表达式，其所有单项式的指数 $e_j \ge 0$。

**证明（交换论证）**：设某最优表达式中出现了指数 $e < 0$ 的项 $x^{e}$，其绝对值 $\le 1/x$。由引理 1，构造它至少要 $\lvert e\rvert + 1 \ge 2$ 个运算符；而把所有负指数项的和记为 $q$，则 $q$ 的分母整除 $x^{E}$（$E = \max \lvert e_j\rvert$ 取负指数部分），要使总和为整数，这些项至少贡献 $x^{E}$ 量级的分母约分，需要至少 $x^{E} \ge 2$ 个负指数项参与抵消。用 $1 = x/x$（代价仅 1）替换这一整块，可把代价严格降低，与"最优"矛盾。故最优解的指数都非负。∎

**引理 4（递推完备）**：设 $t \ge x$、$x^k \le t < x^{k+1}$ 且 $t \ne x^k$，则

$$f(t) = \min\big(k + f(t - x^k),\ k+1 + f(x^{k+1} - t)\big).$$

**证明**：

- **"$\le$"（构造）**：用 $k$ 个 $x$ 连乘得到 $x^k$（$k-1$ 个运算符），再用 $1$ 个 `+` 接上 $t - x^k$ 的最优表示，共 $k + f(t - x^k)$ 个；同理，用 $x^{k+1}$（$k$ 个运算符）减去 $x^{k+1} - t$ 的最优表示，共 $k + 1 + f(x^{k+1} - t)$ 个。故 $f(t)$ 不超过两者较小值。
- **"$\ge$"（下界）**：取最优表达式，由引理 3 其项都是 $\pm x^{e}$（$e \ge 0$）。设最大指数为 $e_{\max}$，且各项按同号合并后最高项为 $s\,x^{e_{\max}}$。
  - 若 $e_{\max} = k$：最高项必为 $+x^k$（若为 $-x^k$，则其余项之和须为 $t + x^k > x^{k+1}$，至少要多一个 $\ge x^{k}$ 的正项，代价更高）。去掉最高项后，其余项构成 $t - x^k$ 的合法表示，故总代价 $\ge k + f(t - x^k)$。
  - 若 $e_{\max} = k+1$：最高项必为 $-x^{k+1}$（$+x^{k+1} > t$ 无法被更低阶项抵消到 $t$ 而不增加一个 $\ge x^{k+1}$ 的负项，代价更高）。去掉它后其余项构成 $x^{k+1} - t$ 的合法表示，代价 $\ge k + 1 + f(x^{k+1} - t)$。
  - 若 $e_{\max} \ge k+2$：最高项绝对值 $\ge x^{k+2}$，其余项之和的绝对值 $\ge x^{k+2} - t > x^{k+1}$，需要至少一个 $x^{k+1}$ 级反向项；构造主项至少 $k+1$ 个运算符、反向项至少 $k$ 个，合计已超过上面两种分解的上界（可用归纳证明 $\le 2k+1$），不可能最优。
  - 若 $e_{\max} \le k-1$：所有项 $\le x^{k-1}$，凑出 $t \ge x^k$ 至少需要 $\lceil t/x^{k-1}\rceil \ge x$ 个正项，代价 $\ge x(k-2) + (x-1) > 2k + 1$，同样不可能最优。

  故最优表达式的最大指数只能是 $k$ 或 $k+1$，两种情形的代价分别不小于 $k + f(t - x^k)$ 与 $k + 1 + f(x^{k+1} - t)$，取较小者即得下界。∎

**定理**：记忆化递归算法返回的 $f(\text{target})$ 等于表示 `target` 所需的最少运算符数。

**证明**：对 $t$ 归纳（$t$ 从 $1$ 递增到 `target`；递归中 $t$ 严格减小，因为 $t - x^k < t$ 且 $x^{k+1} - t < x^{k+1} - x^k \le t$ 对 $k \ge 1$ 成立）。

- 基础：$t < x$ 由引理 2 成立；$t = x^k$ 由引理 1（直接构造 $k-1$ 个运算符）与引理 4 的下界论证（最高项只能取 $x^k$）成立。
- 归纳步：$t \ge x$ 且非幂时，由引理 4 的等式，$f(t)$ 等于两个子问题的组合，而子问题自变量更小，由归纳假设递归返回的是真实最优值，故组合结果正确。

算法对所有 $t$ 精确计算 $f$（哈希表保证不重复计算），故返回值为所求。∎

## 6. 复杂度分析

- **时间**：状态数为 $O(\log^2 target)$（$target \le 2\times10^8$ 时不到 $10^3$ 个），每个状态求 $k$ 需 $O(\log_x t)$ 次乘法和两次递归，故总时间约 $O(\log^3 target)$，$x = 2$ 时也仅数百次运算。
- **空间**：$O(\log^2 target)$ 的记忆化表 + $O(\log target)$ 的递归栈。

## 7. 参考代码

### C++

```cpp
#include <unordered_map>
#include <unordered_set>
#include <algorithm>

using namespace std;

class Solution {
public:
    int leastOpsExpressTarget(int x, int target) {
        this->x = x;
        memo.clear();
        onStack.clear();
        return dfs(target);
    }

private:
    int x;
    static const int INF = 1000000000;
    unordered_map<int, int> memo;    // 记忆化：t -> 最少运算符数
    unordered_set<int> onStack;      // DFS 栈上的状态，用于切断环

    int dfs(int t) {
        if (t < x) return min(2 * t - 1, 2 * (x - t));   // 只用 1 或 x 的加减

        auto it = memo.find(t);
        if (it != memo.end()) return it->second;
        if (onStack.count(t)) return INF;                // 回到祖先：成环，必非最优
        onStack.insert(t);

        long long p = x;                                  // p = x^k <= t
        int k = 1;
        while (p * x <= t) {
            p *= x;
            k++;
        }

        int best;
        if (p == t) {
            best = k - 1;                                 // 恰好 x^k：k-1 个乘号
        } else {
            best = k + dfs(t - (int)p);                   // 用 x^k 再补差额（严格变小）
            best = min(best, k + 1 + dfs((int)(p * x - t)));   // 用 x^(k+1) 再减差额
        }

        onStack.erase(t);
        memo[t] = best;
        return best;
    }
};
```

### Python

```python
class Solution:
    def leastOpsExpressTarget(self, x: int, target: int) -> int:
        INF = float("inf")
        memo = {}                    # 记忆化：t -> 最少运算符数
        on_stack = set()             # DFS 栈上的状态，用于切断环

        def f(t: int) -> int:
            if t < x:
                # 用 t 个 1 累加，或用 x 减去 (x - t) 个 1
                return min(2 * t - 1, 2 * (x - t))

            if t in memo:
                return memo[t]
            if t in on_stack:
                return INF           # 回到祖先：成环，必非最优
            on_stack.add(t)

            p, k = x, 1                  # p = x^k <= t
            while p * x <= t:
                p *= x
                k += 1

            if p == t:
                best = k - 1             # 恰好 x^k
            else:
                best = k + f(t - p)                  # 用 x^k 再补差额
                best = min(best, k + 1 + f(p * x - t))   # 用 x^(k+1) 再减差额

            on_stack.discard(t)
            memo[t] = best
            return best

        return f(target)
```

## 8. 边界情况与易错点

1. **`target = 1`**：走 $t < x$ 分支，返回 $\min(1, 2(x-1)) = 1$，对应 `x / x`，正确。
2. **`target = x`**：$p = x = t$，返回 $k - 1 = 0$，即表达式就是单个 `x`，0 个运算符。
3. **`target` 恰为 $x^k$**：返回 $k-1$（不是 $k$）。这是最常见的差一错误——$k$ 个 $x$ 只需要 $k-1$ 个乘号。
4. **`x = 2`**：小目标公式退化为 $\min(2t-1, 2(2-t))$，$t = 1$ 时两个值分别是 1 和 2，取 1（`2/2`）正确。
5. **`p * x` 溢出**：$t$ 接近 $2\times10^8$ 时 $p\cdot x$ 可能超过 `int` 范围，用 `long long` 计算再判断。
6. **递归基的写法**：一定要先判 $t < x$ 再查记忆化，否则 $t < x$ 的小值不会进入缓存（虽然不影响正确性，但会重复计算）。
7. **不要用"贪心取最近幂"**：示例 2 表明"取 $x^{k+1}$ 再减"可能优于"取 $x^k$ 再加"（也常常相反），必须两种都试。
8. **不要忘记 `+1`**：走 $x^{k+1}$ 分支时，构造 $x^{k+1}$ 要用 $k$ 个乘号，再加一个减号，共 $k+1$ 个"额外"运算符，容易漏写。

- [LeetCode 282. 给表达式添加运算符](https://leetcode.cn/problems/expression-add-operators/)：在数字串中插入运算符凑目标值，属于"表达式构造"的搜索类问题。
- [LeetCode 964. 表示数字的最少运算符](https://leetcode.cn/problems/least-operators-to-express-number/)：本题自身；同类的"以 $x$ 为底的带符号数字分解"也出现在负数进制、平衡三进制等题目中。

**延伸思考**：本题的递归本质上是在求"以 $x$ 为基、数字允许为 $\pm 1$ 且代价按位权计算"的最小代价表示，可以改写成按位 DP（从低位到高位决定"进位/借位"），复杂度同为 $O(\log t)$ 级别但无需记忆化。若允许**括号**，表达式的能力会质变（可表示任意四则运算组合），问题变成一般的最短表达式搜索，NP 难；若允许**混用多种底数**，则要在每个状态下枚举所有底数的幂，状态空间与底数个数成正比。
