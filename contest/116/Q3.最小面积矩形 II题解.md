# LeetCode 最小面积矩形 II 题解

## 1. 题目概述

- **标题 / 题号**：最小面积矩形 II（#963，medium）
- **链接**：https://leetcode.cn/problems/minimum-area-rectangle-ii/
- **来源**：LeetCode 第 116 场周赛 Q3
- **难度**：中等
- **标签**：几何、数组、哈希表、数学

**题意**：给定平面上 $n$ 个**互不相同**的整点 `points`，其中 `points[i] = [xi, yi]`。求由这些点作为四个顶点构成的**任意矩形**（边不要求平行于坐标轴）的**最小面积**；若不存在矩形，返回 0。答案误差在 $10^{-5}$ 内即可。

**约束**：

- $1 \le n \le 50$
- $0 \le x_i, y_i \le 4\times10^4$
- 所有点互不相同

## 2. 示例

**示例 1**

```text
输入：points = [[1,2],[2,1],[1,0],[0,1]]
输出：2.00000
解释：四个点恰好是一个正方形的四个顶点（中心 (1,1)），边长 sqrt(2)，面积 2。
```

**示例 2**

```text
输入：points = [[0,1],[2,1],[1,1],[1,0],[2,0]]
输出：1.00000
解释：取 (1,0)、(1,1)、(2,1)、(2,0)，是一个轴对齐的单位正方形，面积 1。
     （虽然 (0,1)、(1,1)、(2,1) 共线，但它们不是矩形顶点。）
```

**示例 3**

```text
输入：points = [[0,3],[1,2],[3,1],[1,3],[2,1]]
输出：0
解释：这些点里不存在任何矩形，返回 0。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有四元组，判断它们能否构成矩形，取最小面积。

- 组合数 $\binom{50}{4} = 230300$，其实**勉强能过**，但每个四元组还要做"判断四点是否共圆且中心一致"的判定，实现繁琐；若再枚举排列则是 $50^4 \approx 6.25\times10^6$ 次，虽然也能过，但需要为每个四元组找到正确的顶点顺序，容易写错；
- 更关键的是：**矩形的判定可以只用三条边**（一个直角 + 平行关系），没必要枚举四个点。

### 3.2 核心观察：直角顶点 + 两个邻点 + 查表找第四点

![矩形的三条边刻画：直角 + 平行四边形自动补齐第四点](images/wc116_q3_right_angle.svg)

**引理（直角 + 第四点 ⟹ 矩形）**：设 $A, B, C$ 是三个不同点，满足

$$\overrightarrow{BA} \cdot \overrightarrow{BC} = 0 \quad(\text{即 } AB \perp BC),$$

并令 $D = A + C - B$（向量运算，逐坐标做）。则 $A, B, C, D$ 四个点构成一个以 $B$ 为直角顶点的矩形。

**证明**：由 $D = A + C - B$ 得

$$\overrightarrow{AD} = D - A = C - B = \overrightarrow{BC}, \qquad \overrightarrow{CD} = D - C = A - B = \overrightarrow{BA}.$$

对边平行且相等，故 $ABCD$ 是平行四边形；又 $\angle ABC = 90^\circ$，有一个直角的平行四边形就是矩形。∎

于是算法思路：

1. 把所有点放进哈希集合，查询 $O(1)$；
2. 枚举**直角顶点** $B$ 与另外两点 $A, C$（$A \ne B$、$C \ne B$、$A \ne C$）；
3. 检查 $\overrightarrow{BA} \cdot \overrightarrow{BC} = 0$（整数点积，零误差）；
4. 计算 $D = A + C - B$，若 $D$ 在集合中就找到了一个矩形，面积为

$$S = \lvert AB \rvert \cdot \lvert BC \rvert = \sqrt{\big((A_x - B_x)^2 + (A_y - B_y)^2\big)\big((C_x - B_x)^2 + (C_y - B_y)^2\big)}.$$

5. 取所有面积的最小值。

**枚举次数**：$O(n^3) = 1.25\times10^5$（$n = 50$），非常轻量。

![每个矩形会被它的 4 个直角顶点各枚举一次](images/wc116_q3_enumeration.svg)

> 💡 **每个矩形会被数到 4 次**：它的 4 个顶点都是直角顶点，枚举 $B$ 时都会找到它。这只带来常数倍（甚至 4 倍以内）的重复计算，取最小值不受影响，不需要去重。

### 3.3 算法流程

```text
1. 所有点放入哈希集合 S
2. ans = +∞
3. for B in points:
       for A in points, A != B:
           for C in points, C != B, C != A:
               若 (A - B)·(C - B) != 0:  continue       // 不是直角
               D = A + C - B
               若 D 不在 S 中:  continue                // 第四点缺失
               S_area = sqrt(dist2(A,B) * dist2(B,C))
               ans = min(ans, S_area)
4. return ans 若为 +∞ 则 0
```

### 3.4 示例演算

![示例 1：以 (1,2) 为直角顶点，第四点 (1,0) 恰好存在](images/wc116_q3_walkthrough.svg)

对示例 1 的 `points = [[1,2],[2,1],[1,0],[0,1]]`，取直角顶点 $B = (1,2)$：

| 步骤 | 计算 | 结果 |
|------|------|------|
| 取 $A = (2,1)$，$C = (0,1)$ | $\overrightarrow{BA} = (1,-1)$，$\overrightarrow{BC} = (-1,-1)$ | — |
| 点积 | $1\cdot(-1) + (-1)\cdot(-1) = -1 + 1$ | $0$ ✓ 直角 |
| 第四点 | $D = A + C - B = (2+0-1,\ 1+1-2)$ | $(1,0)$ ✓ 在集合中 |
| 面积 | $\lvert AB \rvert = \sqrt2$，$\lvert BC \rvert = \sqrt2$ | $\sqrt2\cdot\sqrt2 = 2$ |

对其他直角顶点重复，得到的都是同一个正方形（面积 2）；示例 2 中会枚举到面积为 1 的轴对齐正方形，取最小得 1；示例 3 中所有候选的第四点都不在集合里，`ans` 保持 $+\infty$，返回 0。

## 4. 算法细节

1. **点的编码**：把 $(x,y)$ 编码成 `long long` 的 `x * 40001 + y` 或 `x * 100000 + y`（$x, y \le 4\times10^4$，不会冲突，也不会溢出 `long long`），放进 `unordered_set`；Python 直接用 `set` 存元组。
2. **点积用整数**：$\overrightarrow{BA} \cdot \overrightarrow{BC} = (A_x - B_x)(C_x - B_x) + (A_y - B_y)(C_y - B_y)$，全程整数运算，判定"是否为 0"零误差，避免浮点比较。
3. **第四点也是整数**：$D = A + C - B$ 的两坐标都是整数，可以精确查表；坐标范围在 $[-4\times10^4, 8\times10^4]$ 内，用 `int` 足够。
4. **跳过退化情形**：$A = B$ 或 $C = B$ 会产生零向量、点积恒为 0，必须排除；$A = C$ 时面积必为 0，也要排除。
5. **面积用 `double`**：$S = \sqrt{d_1 d_2}$，其中 $d_1, d_2$ 是两条邻边的平方长度（整数），先乘后开方比两次开方再乘误差更小，也能避免中间溢出（$d \le (4\times10^4)^2 \times 2 \approx 3.2\times10^9$，需用 `long long`）。
6. **不要用 `float`**：坐标平方和可达 $3.2\times10^9$，`float` 只有 24 位有效位，会丢精度；用 `double` 或 `long double`。
7. **无需去重**：同一矩形被枚举 4 次（4 个直角顶点）或 8 次（$A, C$ 交换），取 `min` 时无影响；若想减少重复，可强制 $A$ 的下标小于 $C$，但没必要。
8. **提前剪枝（可选）**：若当前最小面积已经很小，可在枚举时用"两条邻边长度下界"跳过，但 $n \le 50$ 时没有必要。

## 5. 正确性证明

记点集为 $P$，算法枚举的每个候选是三元组 $(B, A, C)$，其中 $A, B, C$ 互不相同、$\overrightarrow{BA} \perp \overrightarrow{BC}$ 且 $D = A + C - B \in P$。

**引理 1（候选 ⟹ 矩形）**：每个通过检查的候选 $(B, A, C)$ 都对应一个由 $P$ 中四点构成、面积为 $\lvert AB\rvert\cdot\lvert BC\rvert$ 的矩形。

**证明**：由 3.2 的引理，$A, B, C, D$ 构成以 $B$ 为直角的矩形，其两条邻边为 $BA$ 与 $BC$，故面积 $= \lvert AB \rvert\cdot\lvert BC \rvert$。又 $A, B, C \in P$ 且 $D \in P$（通过了集合查询），四点均在 $P$ 中，且互不相同（$A\ne B$、$C\ne B$、$A \ne C$；若 $D = A$ 则 $C = B$，矛盾；同理 $D \ne B, C$）。∎

**引理 2（每个矩形都会被枚举到）**：设 $P_1P_2P_3P_4$ 是按顺序排列的矩形顶点（$P_2$ 的邻点是 $P_1, P_3$），则算法在 $B = P_2$、$A = P_1$、$C = P_3$ 时会接受该候选。

**证明**：矩形的每个内角都是 $90^\circ$，故 $\overrightarrow{P_2P_1} \perp \overrightarrow{P_2P_3}$，点积为 0。矩形的对角线互相平分，故 $P_1 + P_3 = P_2 + P_4$（中点相同），即

$$D = P_1 + P_3 - P_2 = P_4 \in P,$$

集合查询通过。故算法接受该候选并记录面积 $\lvert P_1P_2\rvert\cdot\lvert P_2P_3\rvert$，正是该矩形的面积。∎

**定理**：算法输出的最小面积等于由 $P$ 中四点构成的所有矩形的最小面积。

**证明**：

- 由引理 1，`ans` 的每个候选值都是某个真实矩形的面积，故 `ans` 不小于真实最小值。
- 由引理 2，任一矩形 $R$ 都会被枚举到并记录其面积，故 `ans` 不大于 $R$ 的面积；对最小矩形取 $R$ 即得 `ans` 不大于真实最小值。

两者合并，`ans` 恰为最小面积。若没有任何矩形，则所有候选都被过滤，`ans` 保持 $+\infty$，按约定返回 0。∎

## 6. 复杂度分析

- **时间**：$O(n^3)$。三层循环枚举直角顶点与两条邻边的端点，共 $O(n^3)$ 个三元组，每个做 $O(1)$ 的点积、查表与开方。$n = 50$ 时约 $1.25\times10^5$ 次迭代。
- **空间**：$O(n)$，即点集的哈希集合；不需要存储点对或矩形。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <unordered_set>
#include <cmath>
#include <algorithm>

using namespace std;

class Solution {
public:
    double minAreaFreeRect(vector<vector<int>>& points) {
        const long long BASE = 100000;          // 坐标 ≤ 4e4，编码不冲突
        unordered_set<long long> has;
        for (auto& p : points) has.insert((long long)p[0] * BASE + p[1]);

        auto key = [&](long long x, long long y) { return x * BASE + y; };

        double ans = 1e18;
        int n = points.size();
        for (int b = 0; b < n; b++) {
            int bx = points[b][0], by = points[b][1];
            for (int a = 0; a < n; a++) {
                if (a == b) continue;
                int ax = points[a][0], ay = points[a][1];
                for (int c = 0; c < n; c++) {
                    if (c == b || c == a) continue;
                    int cx = points[c][0], cy = points[c][1];

                    long long v1x = ax - bx, v1y = ay - by;   // BA
                    long long v2x = cx - bx, v2y = cy - by;   // BC
                    if (v1x * v2x + v1y * v2y != 0) continue; // 不是直角

                    long long dx = (long long)ax + cx - bx;   // D = A + C - B
                    long long dy = (long long)ay + cy - by;
                    if (!has.count(key(dx, dy))) continue;    // 第四点不存在

                    long long d1 = v1x * v1x + v1y * v1y;     // |AB|^2
                    long long d2 = v2x * v2x + v2y * v2y;     // |BC|^2
                    ans = min(ans, sqrt((double)d1 * (double)d2));
                }
            }
        }
        return ans > 1e17 ? 0.0 : ans;
    }
};
```

### Python

```python
import math

class Solution:
    def minAreaFreeRect(self, points: list[list[int]]) -> float:
        pts = {tuple(p) for p in points}
        n = len(points)
        ans = float("inf")

        for b in range(n):
            bx, by = points[b]
            for a in range(n):
                if a == b:
                    continue
                ax, ay = points[a]
                for c in range(n):
                    if c == b or c == a:
                        continue
                    cx, cy = points[c]

                    v1x, v1y = ax - bx, ay - by          # BA
                    v2x, v2y = cx - bx, cy - by          # BC
                    if v1x * v2x + v1y * v2y != 0:       # 不是直角
                        continue

                    dx, dy = ax + cx - bx, ay + cy - by  # D = A + C - B
                    if (dx, dy) not in pts:              # 第四点不存在
                        continue

                    d1 = v1x * v1x + v1y * v1y           # |AB|^2
                    d2 = v2x * v2x + v2y * v2y           # |BC|^2
                    ans = min(ans, math.sqrt(d1 * d2))

        return 0.0 if ans == float("inf") else ans
```

## 8. 边界情况与易错点

1. **点数不足 4**：$n < 4$ 时不可能构成矩形，循环里不会有任何候选通过，返回 0。
2. **共线点**：三点共线时点积不为 0（除非有重合点），不会被误判；但若 $A = C$，点积恒为 0，必须显式排除。
3. **退化"矩形"**：若 $A, B, C$ 中有重合，$D$ 可能也重合，面积算出来是 0；这类情形要在枚举时排除 $a \ne b$、$c \ne b$、$c \ne a$。
4. **浮点精度**：面积是 $\sqrt{d_1 d_2}$，$d_1 d_2$ 可达 $10^{19}$ 量级（实际约束下 $d \le 3.2\times10^9$，乘积 $\le 10^{19}$），必须用 `double`/`long double` 或 Python 的任意精度整数转 `math.sqrt`；用 `float` 会丢精度导致 $10^{-5}$ 误差超限。
5. **坐标编码冲突**：键用 `x * BASE + y` 时 `BASE` 必须大于 $y$ 的最大值（$4\times10^4$），否则不同的点可能编码相同。
6. **点积溢出**：$v_x, v_y$ 在 $[-4\times10^4, 4\times10^4]$ 内，乘积约 $1.6\times10^9$，两个相加约 $3.2\times10^9$，`int` 处于边界，建议用 `long long`。
7. **轴对齐矩形也是矩形**：示例 2 的答案就是轴对齐的单位正方形，算法同样能枚举到（点积为 0 时两条边分别平行于坐标轴）。
8. **无需去重或排序**：同一矩形被枚举多次不影响取最小值；也不要试图"按面积排序后提前退出"，因为最小面积的矩形可能在任何枚举位置被发现。
