# LeetCode 最大宽度坡 题解

## 1. 题目概述

- **标题 / 题号**：最大宽度坡（#962，medium）
- **链接**：https://leetcode.cn/problems/maximum-width-ramp/
- **来源**：LeetCode 第 116 场周赛 Q2
- **难度**：中等
- **标签**：栈、数组、双指针、单调栈

**题意**：给定整数数组 `A`。若存在下标对 $(i, j)$ 满足 $i < j$ 且 $A[i] \le A[j]$，则称它是一个**坡**，宽度为 $j - i$。求所有坡中的**最大宽度**；若不存在任何坡，返回 0。

**约束**：

- $2 \le A.length \le 50000$
- $0 \le A[i] \le 50000$

## 2. 示例

**示例 1**

```text
输入：[6,0,8,2,1,5]
输出：4
解释：最大宽度的坡是 (i, j) = (1, 5)：A[1] = 0 <= A[5] = 5，宽度 5 - 1 = 4。
     (0,2) 宽度 2、(0,5) 宽度 5 但 A[0]=6 > A[5]=5 不成立。
```

**示例 2**

```text
输入：[9,8,1,0,1,9,4,0,4,1]
输出：7
解释：最大宽度的坡是 (i, j) = (2, 9)：A[2] = 1 <= A[9] = 1，宽度 9 - 2 = 7。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有下标对，检查 $i < j$ 且 $A[i] \le A[j]$，取最大的 $j - i$：

- 时间 $O(n^2)$：$n = 50000$ 时约 $1.25\times10^9$ 对，必然超时；
- 空间 $O(1)$。

换一种暴力：对每个左端点 $i$，从右往左找第一个满足 $A[j] \ge A[i]$ 的 $j$。当数组递增时这一步就能找到最右端，但当数组整体递减时会退化成 $O(n^2)$。

### 3.2 核心观察：只保留"严格前缀最小值"作为左端点

![候选左端点：只有刷新前缀最小值的位置才值得当左端点](images/wc116_q2_prefix_min.svg)

**观察（左端点的淘汰规则）**：如果存在 $j < i$ 使 $A[j] \le A[i]$，那么以 $i$ 为左端点的坡**永远不如**以 $j$ 为左端点：

$$A[j] \le A[i] \le A[k] \implies (j, k) \text{ 也是坡，且 } k - j > k - i.$$

所以最优解的左端点只需要在"**严格前缀最小值**"的位置里找，即那些满足

$$A[i] < \min(A[0], A[1], \dots, A[i-1])$$

的下标 $i$。把这些下标从左到右压入一个栈，就得到一个**下标递增、数值严格递减**的单调栈。

![单调栈 + 从右向左扫描](images/wc116_q2_stack_scan.svg)

**右端点的扫描**：从右往左枚举 $j = n-1, n-2, \dots$，检查栈顶 $i$：

- 若 $A[i] \le A[j]$，说明 $(i, j)$ 是坡。又因为 $j$ 是从右往左**第一次**满足条件的位置，所以 $j$ 就是 $i$ 能配到的最右端点，$(i,j)$ 是"以 $i$ 为左端点"的最宽坡。记录 $j - i$，然后把 $i$ **弹出**（它已经贡献完最大值）；
- 若 $A[i] > A[j]$，说明 $j$ 太靠右、值又太小，配不上当前栈顶；继续把 $j$ 往左移（栈不动，因为更靠左的 $j$ 更不可能满足 $A[i] \le A[j]$……注意这里要继续用同一个栈顶比较，直到栈空或匹配）。

一旦栈被弹空，说明所有候选左端点都已找到它们的最右配对，可以提前结束。

> 💡 **一句话总结**：左边用单调栈筛掉"被前驱支配"的端点，右边从后往前扫，每个栈顶只需匹配一次就弹出，总代价 $O(n)$。

### 3.3 算法流程

```text
1. stack = []
2. for i = 0 .. n-1:                       // 建单调栈
       若 stack 为空 或 A[i] < A[stack.top()]:  stack.push(i)
3. ans = 0
4. for j = n-1 down to 0:                  // 从右往左扫
       while stack 非空 且 A[stack.top()] <= A[j]:
              ans = max(ans, j - stack.top())
              stack.pop()
       若 stack 为空:  break
5. return ans
```

### 3.4 示例演算

对示例 2 的 `A = [9,8,1,0,1,9,4,0,4,1]`：

**建栈**：

| i | A[i] | 栈顶值 | 是否入栈 | 栈内容（下标） |
|---|------|--------|----------|----------------|
| 0 | 9 | — | 是 | [0] |
| 1 | 8 | 9 | 是（8 < 9） | [0,1] |
| 2 | 1 | 8 | 是 | [0,1,2] |
| 3 | 0 | 1 | 是 | [0,1,2,3] |
| 4 | 1 | 0 | 否（1 ≥ 0） | [0,1,2,3] |
| 5 | 9 | 0 | 否 | [0,1,2,3] |
| 6 | 4 | 0 | 否 | [0,1,2,3] |
| 7 | 0 | 0 | 否（不小于） | [0,1,2,3] |
| 8 | 4 | 0 | 否 | [0,1,2,3] |
| 9 | 1 | 0 | 否 | [0,1,2,3] |

**从右扫描**：

| j | A[j] | 栈顶 | A[栈顶] ≤ A[j]？ | ans |
|---|------|------|------------------|-----|
| 9 | 1 | 3 | 0 ≤ 1 ✓ → ans = 9−3 = 6，弹出 3；新栈顶 2：1 ≤ 1 ✓ → ans = 9−2 = 7，弹出 2；新栈顶 1：8 ≤ 1 ✗ | 7 |
| 8 | 4 | 1 | 8 ≤ 4 ✗ | 7 |
| 7 | 0 | 1 | 8 ≤ 0 ✗ | 7 |

## 4. 算法细节

1. **栈中存下标而不是值**：既要比较数值，又要用下标算宽度。
2. **入栈条件是严格小于**：`A[i] < A[stack.top()]`。若写成 `<=`，相等元素也会入栈，虽然不影响正确性但会多做无用比较；用严格小于正好对应"严格前缀最小值"。
3. **右边用 `<=` 比较**：$A[i] \le A[j]$ 才是坡，等号必须成立。
4. **每个栈顶只匹配一次**：匹配成功后立刻 `pop`，因为对同一个 $i$，当前 $j$ 已经是它最右的合法右端点，更小的 $j$ 只会给出更小的宽度。
5. **匹配失败的 `j` 不跳过栈顶**：`while` 循环的语义是"只要栈顶能配就配并弹出"，配不上就退出 while、把 $j$ 左移一格再试同一个栈顶。
6. **提前结束**：栈空即所有候选左端点都处理完毕，后面更小的 $j$ 不可能再改进答案。
7. **答案初值 0**：题目要求不存在坡时返回 0，与初值一致。
8. **不要用"从右往左找最大值"的贪心**：右端点未必是后缀最大值，关键是"最靠右的位置"，两者的区别正是本题的坑。

## 5. 正确性证明

记 $S$ 为所有**严格前缀最小**的下标集合（$i \in S$ 当且仅当 $i = 0$ 或 $A[i] < \min_{t<i} A[t]$）。栈的内容就是 $S$ 按升序排列（见引理 2）。

**引理 1（左端点可限制在 $S$ 中）**：对任意坡 $(i, k)$，存在 $i' \in S$，$i' \le i$，使 $(i', k)$ 也是坡且 $k - i' \ge k - i$。

**证明**：令 $i'$ 为 $0..i$ 中使 $A$ 取最小值的**最左**下标。则 $A[i'] \le A[i] \le A[k]$，故 $(i', k)$ 是坡；又 $i' \le i$，故 $k - i' \ge k - i$。而 $i'$ 是前缀 $0..i$ 的最小值位置，必满足严格前缀最小条件（若存在 $t < i'$ 且 $A[t] \le A[i']$，则 $t$ 更小且值不大于，与 $i'$ 为最左最小值矛盾），故 $i' \in S$。∎

**引理 2（栈恰好是 $S$）**：算法第 2 步结束后，栈内自底向上依次是 $S$ 的元素，且下标递增、数值严格递减。

**证明**：对 $i$ 归纳。$i = 0$ 时 $0 \in S$ 入栈。设处理 $i$ 前栈内容为 $S \cap [0, i-1]$。若 $A[i]$ 小于当前栈顶值（即 $A[i] < \min_{t<i}A[t]$），则 $i \in S$，入栈后仍有序；否则 $A[i] \ge \min_{t<i} A[t]$，$i \notin S$，不入栈。两种情况都与 $S$ 的定义一致。∎

**引理 3（弹出时记录的宽度是最大宽度）**：设算法在扫描到 $j$ 时弹出栈顶 $i$，则 $j = \max\{j' : j' > i,\ A[j'] \ge A[i]\}$，且 $j - i$ 是以 $i$ 为左端点的最大坡宽。

**证明**：$j$ 从 $n-1$ 递减扫描，被弹出说明 $A[i] \le A[j]$；而所有 $j' > j$ 都已经被扫描过，且当时 $i$ 还在栈中未被弹出，说明 $A[j'] < A[i]$（否则会在那时候弹出）。因此不存在比 $j$ 更靠右且满足条件的右端点，$j$ 是使 $(i, j')$ 成坡的最大 $j'$。宽度 $j - i$ 自然最大。∎

**定理**：算法返回最大坡宽。

**证明**：

- **上界**：算法每次更新 `ans` 用的都是真实存在的坡（$i < j$ 且 $A[i] \le A[j]$），所以 `ans` 不超过真实最大值。
- **下界**：设最优坡为 $(i^*, j^*)$，由引理 1 不妨设 $i^* \in S$（否则换成 $S$ 中的 $i'$，宽度不减）。由引理 2，$i^*$ 在栈中。当右指针扫到 $j^*$ 或更靠右的某个位置时，$i^*$ 必然会因为满足 $A[i^*] \le A[j]$ 而被弹出（$j^*$ 本身就满足条件；若更早被弹出，记录的宽度更大），由引理 3 记录的宽度不小于 $j^* - i^*$，故 `ans` 不小于真实最大值。

两者合并得 `ans` 恰为最大坡宽。∎

## 6. 复杂度分析

- **时间**：$O(n)$。建栈一趟 $O(n)$，每个下标至多入栈一次、出栈一次；右指针至多左移 $n$ 次，`while` 循环的弹出总次数不超过入栈总次数，故整体 $O(n)$。
- **空间**：$O(n)$，栈最坏存下全部下标（数组严格递减时）。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <algorithm>

using namespace std;

class Solution {
public:
    int maxWidthRamp(vector<int>& nums) {
        int n = nums.size();
        vector<int> st;                        // 严格前缀最小值的下标，单调递减栈
        for (int i = 0; i < n; i++) {
            if (st.empty() || nums[i] < nums[st.back()]) st.push_back(i);
        }

        int ans = 0;
        for (int j = n - 1; j >= 0; j--) {
            while (!st.empty() && nums[st.back()] <= nums[j]) {
                ans = max(ans, j - st.back());  // 对栈顶而言 j 已是最右端点
                st.pop_back();
            }
            if (st.empty()) break;              // 所有候选左端点都处理完
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maxWidthRamp(self, nums: list[int]) -> int:
        n = len(nums)
        st = []                                # 严格前缀最小值的下标
        for i in range(n):
            if not st or nums[i] < nums[st[-1]]:
                st.append(i)

        ans = 0
        for j in range(n - 1, -1, -1):
            while st and nums[st[-1]] <= nums[j]:
                ans = max(ans, j - st[-1])     # 对栈顶而言 j 已是最右端点
                st.pop()
            if not st:
                break                          # 候选左端点已全部处理

        return ans
```

## 8. 边界情况与易错点

1. **全相等数组**：如 `[3,3,3]`，栈只存下标 0，从右扫到 j=2 时 `3 <= 3` 成立，答案 2；注意比较用 `<=` 才能取到。
2. **严格递减数组**：如 `[5,4,3,2,1]`，没有任何坡，所有 `A[j]` 都小于栈顶值，`ans` 保持 0，正确。
3. **严格递增数组**：栈只有下标 0，右扫到 j = n-1 时弹出，答案 n−1。
4. **答案在数组内部**：如 `[6,0,8,2,1,5]` 的答案是 (1,5)，不能只检查首尾。
5. **弹出后不能再参与匹配**：如果忘了 `pop`，同一个 $i$ 会被反复匹配，虽然答案不会变错但复杂度退化为 $O(n^2)$。
6. **入栈判据要严格小于**：用 `<=` 也能得到正确答案（相等元素入栈后匹配宽度不会更优），但会多存冗余下标，且削弱单调性。
7. **`j` 与 `i` 必须不同**：题目要求 $i < j$；本算法中 $j$ 从 $n-1$ 递减，弹出时必有 $j > i$（$i$ 是更早的下标，且弹出发生在 `A[i] <= A[j]` 时，若 $j \le i$ 则 $i$ 早已被处理），无需额外判断。
8. **提前 `break` 的正确性**：栈空说明所有候选左端点已各自取得最右端点，剩余更小的 $j$ 不可能产生更大宽度。
