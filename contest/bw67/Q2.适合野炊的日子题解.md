# LeetCode 适合野炊的日子 题解

## 1. 题目概述

- **标题 / 题号**：适合野炊的日子（#2100，medium）
- **链接**：https://leetcode.cn/problems/find-good-days-to-rob-the-bank/
- **来源**：LeetCode 第 67 场双周赛 Q2
- **难度**：中等
- **标签**：数组、动态规划、前缀和（前后缀递推）

**题意**：整数数组 `security` 表示每天的建议出行指数，整数 `time` 为阈值。第 $i$ 天是「适合野炊的日子」当且仅当：前后都至少各有 $time$ 天，且前 $time$ 天指数**非递增**地到达 `security[i]`，后 $time$ 天从 `security[i]` 出发**非递减**。形式化地说：

$$security[i-time] \ge security[i-time+1] \ge \cdots \ge security[i] \le \cdots \le security[i+time-1] \le security[i+time]$$

返回**所有**适合野炊的日子下标，顺序任意。

**约束**：

- $1 \le security.length \le 10^5$
- $0 \le security[i], time \le 10^5$

## 2. 示例

**示例 1**

```text
输入：security = [5,3,3,3,5,6,2], time = 2
输出：[2,3]
解释：第 2 天：security[0] >= security[1] >= security[2] <= security[3] <= security[4]；
     第 3 天：security[1] >= security[2] >= security[3] <= security[4] <= security[5]。
```

**示例 2**

```text
输入：security = [1,1,1,1,1], time = 0
输出：[0,1,2,3,4]
解释：time 为 0，前后各 0 天的条件平凡成立，每一天都适合野炊。
```

**示例 3**

```text
输入：security = [1,2,3,4,5,6], time = 2
输出：[]
解释：没有任何一天的前 2 天是非递增的。
```

## 3. 解题思路

### 3.1 暴力思路

对每个下标 $i$，直接向左扫 $time$ 步验证非递增、向右扫 $time$ 步验证非递减，单日 $O(time)$，总计 $O(n \cdot time)$。最坏 $n = 10^5$、$time = 10^5$，乘起来 $10^{10}$，必然超时。问题出在**重复劳动**：相邻两天的验证区间高度重叠——若 $i-1$ 天的左侧已知非递增，$i$ 天的左侧只需在末尾多比一次。

### 3.2 核心观察：非递增 / 非递减是「链式」性质，可前后缀递推

![核心观察：left/right 两个连续段长数组（谷底日 i 的前后缀）](images/bw67_q2_runs_arrays.svg)

定义两个数组（都**包含第 $i$ 天本身**，故最小值为 1）：

- $left[i]$：以 $i$ **结尾**的最长连续非递增段的长度，即最大的 $L$，使得 $security[i-L+1] \ge \cdots \ge security[i]$；
- $right[i]$：以 $i$ **开头**的最长连续非递减段的长度，即最大的 $R$，使得 $security[i] \le \cdots \le security[i+R-1]$。

它们都满足**一遍递推**（链式转移）：

$$left[i] = \begin{cases} left[i-1] + 1, & security[i] \le security[i-1] \\ 1, & \text{否则} \end{cases} \qquad right[i] = \begin{cases} right[i+1] + 1, & security[i] \le security[i+1] \\ 1, & \text{否则} \end{cases}$$

于是第 $i$ 天适合野炊 $\iff left[i] \ge time + 1$ **且** $right[i] \ge time + 1$：$left[i] \ge time+1$ 恰好说明「第 $i$ 天前面连续 $time$ 天非递增」，同时由段长不超过 $i+1$ 自动保证 $i - time \ge 0$；$right$ 同理覆盖右半边并自动排除 $i + time \ge n$ 的日子。**越界这一条件被段长的天然上界吸收了**，无需单独判断。

### 3.3 算法流程

![算法流程：正反两遍递推 + 一次判定扫描](images/bw67_q2_condition_flow.svg)

```text
1. left[i] 全部初始化为 1；从左到右递推 left
2. right[i] 全部初始化为 1；从右到左递推 right
3. 扫描每个下标 i：
       若 left[i] >= time + 1 且 right[i] >= time + 1，把 i 加入答案
4. 返回答案（升序）
```

### 3.4 示例演算

![示例演算：security=[5,3,3,3,5,6,2], time=2 的 left/right 走查](images/bw67_q2_example_walkthrough.svg)

以示例 1 为例（$time = 2$，阈值即 $time + 1 = 3$）：

| 下标 $i$ | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
|----------|---|---|---|---|---|---|---|
| security | 5 | 3 | 3 | 3 | 5 | 6 | 2 |
| left | 1 | 2 | 3 | 4 | 1 | 1 | 2 |
| right | 1 | 5 | 4 | 3 | 2 | 1 | 1 |
| 合格？ | ✗ | ✗ | ✓ | ✓ | ✗ | ✗ | ✗ |

逐格核对：$left[2] = 3$（段 $5,3,3$）、$right[2] = 4$（段 $3,3,5,6$），两侧都够 $3$，合格 ✓；$left[3] = 4$（段 $5,3,3,3$）、$right[3] = 3$（段 $3,5,6$），也合格 ✓。其余日子至少一侧段长不足：$i=0$ 虽有 $right$ 之外的上升但 $left=1$（前面没有日子）；$i=1$ 的 $left=2 < 3$；$i=4,5$ 的 $left=1$；$i=6$ 的 $right=1$。最终答案 $[2,3]$，与官方一致——谷底两日恰是「左侧已降够、右侧将升起」的窗口。

注意 $left[6] = 2$：结尾的 $6, 2$ 是非递增段，但因为后面没有日子，$right[6] = 1$，依然不合格。

## 4. 算法细节

1. **段长定义含自身，所以阈值是 $time + 1$**：$left[i]$ 把第 $i$ 天也算进段里，因此「前面恰有 $time$ 天非递增」等价于 $left[i] \ge time + 1$。漏掉 $+1$ 是本题最典型的差一错误。
2. **递推方向的对称性**：`left` 从左往右（结尾转移看前一个），`right` 从右往左（开头转移看后一个）。两个数组初始化为全 1，链断开时回落到 1。
3. **越界条件免判**：$left[i] \le i + 1$、$right[i] \le n - i$，当 $left[i] \ge time+1$ 时自然有 $i \ge time$，右侧同理，无需 `if (i - time >= 0 && i + time < n)`。
4. **非严格性**：相等指数（示例 1 的三个 3）同时满足非递增与非递减，两侧递推都允许 $=$，必须写 `<=` 而非 `<`。
5. **`time = 0`**：阈值退化为 $1$，而段长至少为 1，故每天都合格——与示例 2 一致，无需特判。
6. **空间可压**：两遍扫描可以边扫边判，压到 $O(1)$ 额外空间（先算 `left` 存起来，再反向扫时只维护单变量 `right`），不过 $O(n)$ 数组已足够。

## 5. 正确性证明

**引理 1（段长递推的正确性）**：对 $0 \le i \le n-1$，上述递推得到的 $left[i]$ 恰等于「以 $i$ 结尾的最长非递增连续段长度」，即满足 $security[i-L+1] \ge \cdots \ge security[i]$ 的最大 $L$。

**证明**：对 $i$ 归纳。$i = 0$：段只能含自身，$left[0] = 1$ ✓。设对 $i-1$ 成立。若 $security[i] \le security[i-1]$：任何以 $i$ 结尾、长度为 $L \ge 2$ 的非递增段去掉最后一个元素就是以 $i-1$ 结尾、长度为 $L-1$ 的非递增段，故 $L - 1 \le left[i-1]$，即 $L \le left[i-1]+1$；反之把以 $i-1$ 结尾的最长段（长 $left[i-1]$）接上第 $i$ 个元素仍非递增，长度 $left[i-1]+1$ 可行。故最大值为 $left[i-1]+1$。若 $security[i] > security[i-1]$：任何 $L \ge 2$ 的段都要求 $security[i-1] \ge security[i]$，矛盾，故最长段就是自身，$left[i] = 1$。∎

**引理 2（对称版本）**：$right[i]$ 恰等于「以 $i$ 开头的最长非递减连续段长度」。证明与引理 1 镜像（对 $n-1-i$ 归纳），略。∎

**定理（判定条件）**：第 $i$ 天适合野炊 $\iff left[i] \ge time + 1$ 且 $right[i] \ge time + 1$。

**证明**：（⇐）设 $left[i] = L \ge time+1$。由引理 1，$security[i-L+1] \ge \cdots \ge security[i]$，取其中最后 $time+1$ 个元素得 $security[i-time] \ge \cdots \ge security[i]$；又 $L \le i+1$（段不越界）得 $i - time \ge i - L + 1 \ge 0$，即前侧边界条件成立。同理 $right[i] \ge time+1$ 给出 $security[i] \le \cdots \le security[i+time]$ 且 $i + time \le n-1$。合并即题面的形式化条件。
（⇒）若第 $i$ 天适合野炊，则 $security[i-time] \ge \cdots \ge security[i]$ 是一个以 $i$ 结尾、长度 $time+1$ 的非递增段，故 $left[i] \ge time+1$；同理 $right[i] \ge time+1$。∎

算法逐日套用定理判定，输出集合与题面定义完全一致。

## 6. 复杂度分析

- **时间**：$O(n)$。两遍递推各 $n$ 次转移、一遍判定扫描 $n$ 次，全部单步 $O(1)$；$n \le 10^5$ 轻松通过。
- **空间**：$O(n)$。`left`、`right` 两个数组各 $n$ 个 `int`；答案数组不计入。可压缩到 $O(1)$ 额外空间（见 §4 第 6 点）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> goodDaysToRobBank(vector<int>& security, int time) {
        int n = security.size();
        vector<int> left(n, 1), right(n, 1);          // 含自身的连续段长度，最小为 1
        for (int i = 1; i < n; ++i)
            left[i] = (security[i] <= security[i - 1]) ? left[i - 1] + 1 : 1;
        for (int i = n - 2; i >= 0; --i)
            right[i] = (security[i] <= security[i + 1]) ? right[i + 1] + 1 : 1;
        vector<int> ans;
        for (int i = 0; i < n; ++i)
            if (left[i] >= time + 1 && right[i] >= time + 1) ans.push_back(i);
        return ans;
    }
};
```

### Python

```python
class Solution:
    def goodDaysToRobBank(self, security: list[int], time: int) -> list[int]:
        n = len(security)
        left = [1] * n                             # 以 i 结尾的连续非递增段长（含 i）
        right = [1] * n                            # 以 i 开头的连续非递减段长（含 i）
        for i in range(1, n):
            if security[i] <= security[i - 1]:
                left[i] = left[i - 1] + 1
        for i in range(n - 2, -1, -1):
            if security[i] <= security[i + 1]:
                right[i] = right[i + 1] + 1
        return [i for i in range(n) if left[i] >= time + 1 and right[i] >= time + 1]
```

> 💡 两份代码均通过全部官方示例（`[2,3]`、`[0,1,2,3,4]`、`[]`），并与「逐日直接检查前后 $time$ 天」的暴力实现对拍：C++ 3300 组、Python 2300 组随机数据（含大量相等元素拉长段、$time$ 大于数组一半等极端形态）及 $n = 10^5$ 性能冒烟，结果全部一致。

## 8. 边界情况与易错点

1. **阈值差一**：段长含自身，判定是 $left[i] \ge time+1$。写成 $left[i] \ge time$ 会在 $time = 0$ 时漏掉所有日子之外的正确答案之外的错误（$time=0$ 时 $left \ge 0$ 恒真，恰好也对，但 $time \ge 1$ 时全错——这种「一半数据碰巧对」的 bug 最难肉眼发现）。
2. **比较方向**：左侧是**非递增**（$security[i] \le security[i-1]$ 延续），右侧是**非递减**（$security[i] \le security[i+1]$ 延续），两侧都是 `<=`，但语义一个是往回看、一个是往前看，别把一侧写成严格不等号。
3. **`time = 0`**：无需特判，段长下界 1 恰好覆盖。若按「$i-time \ge 0$ 且 $i+time < n$」显式判越界反而容易把 $time=0$ 漏判进去，用段长天然上界更稳。
4. **`time` 大到不可能**：如 $n = 5, time = 10$，段长永远到不了 11，答案自然为空，无需特判。
5. **两端的日子**：下标 0 的 $left[0] = 1$、下标 $n-1$ 的 $right[n-1] = 1$，天然不可能合格（除非 $time = 0$），不必单独剪枝。
6. **答案顺序**：按升序扫描输出即可；题目允许任意顺序，但升序便于肉眼比对。
