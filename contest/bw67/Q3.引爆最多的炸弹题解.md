# LeetCode 引爆最多的炸弹 题解

## 1. 题目概述

- **标题 / 题号**：引爆最多的炸弹（#2101，medium）
- **链接**：https://leetcode.cn/problems/detonate-the-maximum-bombs/
- **来源**：LeetCode 第 67 场双周赛 Q3
- **难度**：中等
- **标签**：深度优先搜索、广度优先搜索、图、几何、数组、数学

**题意**：每个炸弹是一个圆：$bombs[i] = [x_i, y_i, r_i]$ 表示以 $(x_i, y_i)$ 为圆心、$r_i$ 为半径的爆炸范围。**引爆一个**炸弹后，所有落在其爆炸范围内的炸弹都会被引爆，并继续连锁引爆它们范围内的炸弹。返回只引爆一个炸弹时，**最多**能引爆的炸弹数目（含自己）。

**约束**：

- $1 \le bombs.length \le 100$
- $bombs[i].length == 3$
- $1 \le x_i, y_i, r_i \le 10^5$

## 2. 示例

**示例 1**

```text
输入：bombs = [[2,1,3],[6,1,4]]
输出：2
解释：引爆左边的炸弹不影响右边；引爆右边的炸弹会连锁引爆左边，最多引爆 2 个。
```

**示例 2**

```text
输入：bombs = [[1,1,5],[10,10,5]]
输出：1
解释：两个圆互不覆盖，引爆任意一个都只能引爆它自己。
```

**示例 3**

```text
输入：bombs = [[1,2,3],[2,3,1],[3,4,2],[4,5,3],[5,6,4]]
输出：5
解释：炸弹 0 直接引爆 1 和 2，炸弹 2 引爆 3，炸弹 3 引爆 4，连锁后全部引爆。
```

## 3. 解题思路

### 3.1 暴力思路

按题面直接**模拟连锁**：引爆炸弹 $s$ 后，反复扫描所有未引爆炸弹，凡是「位于某个已引爆炸弹的圆内」就标记为引爆，直到一轮扫描无新增。单轮扫描 $O(n^2)$，连锁最多传播 $n$ 轮，单起点 $O(n^3)$，全体起点 $O(n^4)$——$n \le 100$ 时约 $10^8$，勉强能过但完全不必要。它的低效在于：同一个「谁能引爆谁」的关系被反复重算。**把 pairwise 关系一次性算好建图**，连锁过程就变成标准的图可达性问题。

### 3.2 核心观察：连锁 = 有向图上的可达闭包

![核心观察：炸弹建有向图，i→j 当且仅当 j 在 i 的圆内（注意方向不对称）](images/bw67_q3_graph_model.svg)

炸弹为节点，$i \to j$ 连一条**有向边**当且仅当 $j$ 落在 $i$ 的爆炸范围内：

$$(x_j - x_i)^2 + (y_j - y_i)^2 \le r_i^2$$

三个必须想清楚的性质：

1. **有向**：覆盖关系依赖「谁的半径」，$i$ 够得着 $j$ 不代表 $j$ 够得着 $i$（示例 1 正是一来一往只有单向边的情形）。
2. **不传递**：$i \to j \to k$ 不意味着 $i \to k$——引爆会沿边**传播**，但边本身不折叠。
3. **连锁即路径**：引爆 $s$ 后被引爆的炸弹，恰是从 $s$ 出发沿有向边**可达**的所有节点（含 $s$ 自己）。

于是答案 = $\max_s |\text{从 } s \text{ 可达的点集}|$。$n \le 100$，建图 $O(n^2)$、每个起点做一次 BFS/DFS 即可，总复杂度上界 $O(n^3) = 10^6$，稳过。

### 3.3 算法流程

![算法流程：建图 → 逐点 DFS/BFS 统计可达数 → 取最大](images/bw67_q3_dfs_flow.svg)

```text
1. 建邻接表：对所有有序对 (i, j), i != j，
       若 (xj-xi)² + (yj-yi)² <= ri²，加边 i -> j
2. best = 1
3. 对每个起点 s：
       visited 清零，从 s 出发 DFS/BFS，数出可达节点数 cnt
       best = max(best, cnt)
4. 返回 best
```

### 3.4 示例演算

![示例演算：示例1的单向边与示例3的连锁路径](images/bw67_q3_example_walkthrough.svg)

**示例 1**（$bombs = [[2,1,3],[6,1,4]]$）：两弹圆心距 $4$。左弹 $r=3 < 4$，够不着右弹；右弹 $r = 4 \ge 4$，够得着。有向边只有 $1 \to 0$。从 $0$ 出发可达 $\{0\}$，计数 1；从 $1$ 出发可达 $\{1, 0\}$，计数 2。答案 $2$ ✓。

**示例 3**：邻接关系为 $0 \to 1$、$0 \to 2$、$2 \to 3$、$3 \to 4$（其余各对距离均超半径）。从 $0$ 出发：$0$ 引爆 $1, 2$，$2$ 引爆 $3$，$3$ 引爆 $4$，可达 $\{0,1,2,3,4\}$，计数 5；其他起点可达数均更小（如从 $4$ 出发只有 $\{4\}$）。答案 $5$ ✓。

## 4. 算法细节

1. **比较用距离平方**：条件 $dx^2 + dy^2 \le r^2$ 两边同乘自身，避免 `sqrt` 的浮点误差与性能开销。坐标、半径 $\le 10^5$，$dx^2 + dy^2 \le 2 \times 10^{10}$、$r^2 \le 10^{10}$，都超出 32 位 `int` 上限（约 $2.1 \times 10^9$），**必须用 64 位整数**。
2. **自环跳过**：$i = j$ 时距离为 0 必然满足条件，但引爆集合按定义包含自己，建图时跳过 $i = j$，可达计数再统一加上起点本身（或初始时把起点标记为已访问后从 1 起计数）。
3. **邻接表而非矩阵皆可**：$n \le 100$，邻接矩阵 $O(n^2)$ 内存 10000 字节级别，两者皆可；用表的好处是 DFS 时只遍历真实出边。
4. **每个起点独立搜索**：可达性不满足并查集所需的对称、传递性质，**不能**用连通分量替代。例如 $a \to b$ 而 $b$ 无法引爆 $a$ 时，从 $a$ 起爆算 2 个、从 $b$ 起爆只算 1 个。
5. **重复计算不存在**：不同起点的搜索互不共享 `visited`，每次都要重新清零。
6. **答案下界 1**：只引爆自己也算，`best` 初值为 1。

## 5. 正确性证明

**引理 1（引爆集合 = 可达集合）**：从 $s$ 出发引爆后，最终被引爆的炸弹集合恰为有向图中从 $s$ 可达的节点集合 $R(s)$（含 $s$）。

**证明**：按引爆的「轮次」归纳。第 0 轮引爆 $s$。设第 $t$ 轮引爆的集合为 $D_t$，第 $t+1$ 轮新引爆的是所有「被 $D_0 \cup \cdots \cup D_t$ 中某炸弹覆盖但尚未引爆」的炸弹，即存在 $u \in D_0 \cup \cdots \cup D_t$ 且有边 $u \to v$ 的那些 $v$。对 $t$ 归纳可证 $\bigcup_{\tau \le t} D_\tau = \{$从 $s$ 出发边数 $\le t$ 的可达点$\}$：$t = 0$ 时两边都是 $\{s\}$；若第 $t$ 轮结论成立，则第 $t+1$ 轮新引爆点恰是「存在长度 $\le t+1$ 的路径且此前不可达」的点（新引爆需要一条指向它的边来自已引爆点，即路径延长一步）。连锁终止于某个 $T \le n - 1$ 轮（每轮至少新增一个点，至多 $n$ 个点），此时可达集合不再扩大，等于 $\bigcup_{\tau \le T} D_\tau$。反之，任何从 $s$ 可达的点都将在有限轮内被引爆。∎

**引理 2（BFS/DFS 计算可达集）**：从 $s$ 出发的图搜索访问的点集恰为 $R(s)$。

**证明**：搜索只沿存在的边走，访问点都可达（对访问顺序归纳，每个被访问点都经一条访问过的前驱连边）；而任何可达点 $v$ 有最短路径 $s = v_0 \to v_1 \to \cdots \to v_k = v$，对 $k$ 归纳：$v_{k-1}$ 被访问后，其出边 $v_{k-1} \to v_k$ 会被检查，故 $v_k$ 也被访问。∎

**定理**：算法返回值 $= \max_s |R(s)|$，即题意所求。

**证明**：由引理 1，引爆 $s$ 的总数是 $|R(s)|$，题目即求 $\max_s |R(s)|$；由引理 2，算法对每个 $s$ 恰好计算出 $|R(s)|$，取最大即得。∎

## 6. 复杂度分析

- **时间**：$O(n^3)$ 最坏。建图枚举所有有序对 $O(n^2)$；每个起点搜索 $O(n + E)$，$E \le n(n-1)$，$n$ 个起点合计 $O(n \cdot (n + E)) = O(n^3)$。$n = 100$ 时上界约 $10^6$ 次基本操作，实际远小于此（边通常稀疏）。
- **空间**：$O(n^2)$。邻接表最坏 $n(n-1)$ 条边；`visited` 数组 $O(n)$。改用邻接矩阵同为 $O(n^2)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maximumDetonation(vector<vector<int>>& bombs) {
        int n = bombs.size();
        vector<vector<int>> g(n);                       // 有向邻接表：i -> j 表示 i 能直接引爆 j
        for (int i = 0; i < n; ++i) {
            long long xi = bombs[i][0], yi = bombs[i][1], ri = bombs[i][2];
            for (int j = 0; j < n; ++j) {
                if (j == i) continue;
                long long dx = bombs[j][0] - xi, dy = bombs[j][1] - yi;
                if (dx * dx + dy * dy <= ri * ri) g[i].push_back(j);
            }
        }
        int best = 1;
        vector<int> visited(n), stk;
        for (int s = 0; s < n; ++s) {                   // 从每个点出发做一次 DFS
            fill(visited.begin(), visited.end(), 0);
            stk.assign(1, s);
            visited[s] = 1;
            int cnt = 0;
            while (!stk.empty()) {
                int u = stk.back(); stk.pop_back();
                ++cnt;
                for (int v : g[u])
                    if (!visited[v]) { visited[v] = 1; stk.push_back(v); }
            }
            best = max(best, cnt);
        }
        return best;
    }
};
```

### Python

```python
class Solution:
    def maximumDetonation(self, bombs: list[list[int]]) -> int:
        n = len(bombs)
        g = [[] for _ in range(n)]                 # 有向边 i -> j：i 的圆覆盖 j
        for i, (xi, yi, ri) in enumerate(bombs):
            r2 = ri * ri
            for j, (xj, yj, _) in enumerate(bombs):
                if i != j and (xj - xi) ** 2 + (yj - yi) ** 2 <= r2:
                    g[i].append(j)
        best = 1
        for s in range(n):                         # 每个起点一次 DFS
            visited = [False] * n
            visited[s] = True
            stack = [s]
            cnt = 0
            while stack:
                u = stack.pop()
                cnt += 1
                for v in g[u]:
                    if not visited[v]:
                        visited[v] = True
                        stack.append(v)
            best = max(best, cnt)
        return best
```

> 💡 两份代码均通过全部官方示例（`2`、`1`、`5`），并与「直接模拟连锁反应」的独立暴力实现（每轮全表扫描、不建图）对拍：C++ 440 组（含 $n = 30$、坐标 $\le 50$ 的中规模）+ Python 230 组随机数据全部一致，另跑通 $n = 100$、坐标半径 $10^5$ 的性能冒烟。

## 8. 边界情况与易错点

1. **整数溢出（最高频 WA 原因）**：$dx^2 + dy^2$ 最大 $\approx 2 \times 10^{10}$，C++ 里 `int` 相乘直接溢出为负数，可能把「够不着」错判成「够得着」。一律先转 `long long` 再平方；Python 无此问题但注意别写成 `sqrt` 浮点比较。
2. **方向搞反**：边 $i \to j$ 的条件是 $j$ 在 $i$ 的圆内，半径取**发射方** $r_i$。写成 $r_j$ 会把图整体转置，答案可能出错（示例 1 会输出 1）。
3. **别用并查集**：覆盖关系既不对称也不传递，按无向连通分量统计会把「单向可达」错误合并。可达闭包必须逐点搜索（或 Floyd 传递闭包）。
4. **`visited` 复用忘清零**：多起点搜索共享一个 `visited` 而不清零，第二个起点直接返回 0 或 1。
5. **圆心重合 / 包含**：多个炸弹同圆心时距离为 0，互相覆盖（半径都 $\ge 1 > 0$），大量重边与双向边，代码天然处理，无需去重。
6. **$n = 1$**：只能引爆自己，答案是 1；搜索循环里的 `best` 初值 1 保证正确。
7. **等号**：条件是「在范围内」，恰好压线（距离等于半径，如示例 1 的 $4 = r$）也算覆盖，必须写 `<=`。
