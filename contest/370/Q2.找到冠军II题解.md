# LeetCode 找到冠军 II 题解

## 1. 题目概述

- **标题 / 题号**：找到冠军 II（#2924，medium）
- **链接**：https://leetcode.cn/problems/find-champion-ii/
- **来源**：LeetCode 第 370 场周赛 Q2
- **难度**：中等
- **标签**：图、拓扑排序

**题意**：一场比赛有 $n$ 支队伍（编号 $0$ 到 $n-1$），它们同时是**有向无环图（DAG）**上的节点。边集 `edges` 中 $u \to v$ 表示 $u$ 队比 $v$ 队**强**。若不存在强于 $a$ 队的队伍，则 $a$ 队是**冠军**。冠军**唯一**时返回其编号，否则返回 $-1$。与 Q1 的矩阵版不同：这里强弱关系**稀疏且可以缺失**——并非任意两队都分出了胜负，因此冠军可能不唯一。

**约束**：

- $1 \le n \le 100$，$m = \text{edges.length}$，$0 \le m \le \frac{n(n-1)}{2}$
- `edges[i] = [u_i, v_i]`，$0 \le u_i, v_i \le n-1$，$u_i \ne v_i$（无自环）
- 输入保证：$a$ 强于 $b$ 就不会 $b$ 强于 $a$（无双向边）；强弱关系**可传递**；整体构成 **DAG**（无环）

> 💡 一句话点破：冠军就是 DAG 上的**源点**——**入度为 0** 的节点。整道题只做一件事：数一数入度 0 的队伍有几个，恰好 1 个返回它，否则返回 $-1$；一趟扫边 + 一趟扫点，不建图、不搜索，是拓扑排序「只看第一层」的特例。

## 2. 示例

**示例 1**

```text
输入：n = 3, edges = [[0,1],[1,2]]
输出：0
解释：1 队比 0 队弱，2 队比 1 队弱，强弱链 0 > 1 > 2。没有队伍强于 0 队，冠军是 0 队。
```

**示例 2**

```text
输入：n = 4, edges = [[0,2],[1,3],[1,2]]
输出：-1
解释：2 队比 0、1 队弱，3 队比 1 队弱；但 0 队与 1 队之间没有任何强弱对比，
      两支队伍都「无人强于」，冠军不唯一，返回 -1。
```

**补充边界示例**

```text
输入：n = 1, edges = []
输出：0
解释：只有一支队伍，没有任何队伍强于它，冠军唯一，返回 0。
```

## 3. 解题思路

### 3.1 暴力思路：逐队判定「有没有人强于它」

按定义直译：对每支队伍 $a$，判定是否存在强于它的队伍。若把「强于」理解成含间接压制，就要建反图从 $a$ 反向 BFS/DFS 做可达性判定，时间 $O(n(n+m))$；也可以用 Floyd / bitset 求传递闭包，把每个点的「祖先集」全部算出来再判定。$n \le 100$、$m \le 4950$，两条路都能过，但要建邻接表、写搜索，代码量和出错面都偏大。

> ⚠️ 暴力法回答了一个不需要回答的问题：「**谁**强于 $a$、经了哪些路径」。本题只需要知道「**有没有人**强于 $a$」——而这件事，**一条入边就足以否决一个点**。

### 3.2 核心观察：冠军集合 = 入度 0 的集合

![冠军概念：源点即冠军，入度 0](images/champion_ii_indegree_concept.svg)

**观察 1（入度 $> 0$ ⇒ 出局）**：若 $\text{indeg}(a) > 0$，存在边 $u \to a$，即 $u$ **直接**强于 $a$，$a$ 无缘冠军——一次 $O(1)$ 判定，无需任何搜索。

**观察 2（入度 $= 0$ ⇒ 冠军候选）**：若 $\text{indeg}(a) = 0$，则**没有任何边指向 $a$**。反证：若有队伍 $b$ 经路径间接强于 $a$，这条路径的**最后一条边** $(x, a)$ 就直接落在 $a$ 上，与入度 0 矛盾。「没人直接强于我」自动升级为「没人（直接或间接）强于我」——入度这个局部量，编码了「无人压制」的全局性质。

**观察 3（候选集非空）**：DAG 中**必存在**至少一个入度 0 的节点。反证：若所有节点入度都 $> 0$，从任一节点沿入边不断回走，$n+1$ 步内由鸽巢原理必重访某节点，成**环**，与 DAG 矛盾。

三条观察合起来：

$$\text{冠军集合} = \{\, v : \text{indeg}(v) = 0 \,\},\qquad \text{唯一冠军} \iff \text{入度 0 的节点恰好 1 个}$$

> 💡 **与 Q1 的承接**：Q1 的矩阵保证**完全性**（任两队恰有一方更强），胜负是**全序**，冠军必唯一，所以打擂台 $O(n)$ 直达答案；Q2 的边集**可以缺失**，胜负退化成**偏序**，源点可以有多个，打擂台幸存者也说不清「是否还有并列冠军」——必须**计数**并判 $-1$。Q1 的「全 0 列」正是矩阵语言的「入度 0」，两题是同一件事的稠密/稀疏两种编码。

### 3.3 算法流程：一趟扫边 + 一趟扫点

![入度统计算法流程](images/champion_ii_count_flow.svg)

1. **初始化**：`indeg[0..n-1]` 全部置 0。
2. **一趟扫边**：遍历每条边 `edges[i] = [u, v]`，执行 `indeg[v] += 1`——只认终点，起点 $u$ 是谁无关紧要。
3. **一趟扫点**：扫描 `indeg[]`，收集所有值为 0 的下标。
4. **判定**：恰好 1 个候选 → 返回该下标（唯一冠军）；$\ge 2$ 个 → 返回 $-1$（冠军不唯一）。

流程里**没有建图这一步**：不需要邻接表、不需要 BFS/DFS/拓扑排序。Kahn 拓扑排序的初始队列正是入度 0 的节点集合（第一层），本题只问这一层的大小，后续的删边、分层全用不上。

![示例演算：入度表生长过程](images/champion_ii_walkthrough.svg)

| 处理 | 操作 | indeg |

| 初始 | 全部置 0 | $[0, 0, 0]$ |
| 边 $[0,1]$ | $\text{indeg}[1]{+}{=}1$ | $[0, 1, 0]$ |
| 边 $[1,2]$ | $\text{indeg}[2]{+}{=}1$ | $[0, 1, 1]$ |

入度 0 的只有队 $0$ → 恰一个候选 → **返回 0**

**示例 2**（$n = 4$，`edges = [[0,2],[1,3],[1,2]]`）：

| 处理 | 操作 | indeg |
|------|------|-------|
| 初始 | 全部置 0 | $[0, 0, 0, 0]$ |
| 边 $[0,2]$ | $\text{indeg}[2]{+}{=}1$ | $[0, 0, 1, 0]$ |
| 边 $[1,3]$ | $\text{indeg}[3]{+}{=}1$ | $[0, 0, 1, 1]$ |
| 边 $[1,2]$ | $\text{indeg}[2]{+}{=}1$ | $[0, 0, 2, 1]$ |

入度 0 的有队 $0$ 和队 $1$ → 两个候选 → **返回 $-1$**（两队之间无任何强弱关系，分不出冠军）

## 4. 算法细节

1. **只认终点**：边 $u \to v$ 中被指向的是 $v$，统计的是 `indeg[e[1]]`；`e[0]`（压制者）从头到尾没有出场。
2. **计数数组可退化为布尔数组**：判定只看「是否为 0」，从不关心被几条边指向，用 `beaten[v] = True` 同样正确；计数版语义直观、可扩展（如追问「被压制最少的非冠军队伍」时直接复用）。
3. **候选收集两种写法**：C++ 版「遇到第二个候选立即返回 $-1$」提前退出；Python 版列表推导一次收齐再判长度。$n \le 100$ 下无性能差异，选顺手的。
4. **两条「生成的输入满足」是烟雾弹**：无双向边与传递性保证，对入度法毫无用处——它们只影响暴力法（保证「间接强于」时必也存在直接边，让路径判定与直接边判定等价）；入度 0 的刻画对**任何** DAG 都成立，天然免疫。
5. **用到的唯一结构保证是 DAG**：它同时保证候选集非空（观察 3）与 $-1$ 的语义是「冠军不唯一」而非「没有冠军」。

## 5. 正确性证明

**引理 1（冠军的刻画）**：队伍 $v$ 是冠军 $\iff$ $\text{indeg}(v) = 0$。

**证明**：题面把「强于」定义为边的语义：存在边 $b \to v$ 即 $b$ 强于 $v$。于是「不存在强于 $v$ 的队伍」$\iff$「没有边指向 $v$」$\iff$ $\text{indeg}(v) = 0$。∎

**引理 2（含间接压制仍成立）**：即使把「强于」放宽为「存在有向路径」（间接强于），冠军集合仍是入度 0 的集合。

**证明**：$\text{indeg}(v) = 0$ 时，若 $b$ 经路径 $b \leadsto v$ 间接强于 $v$，取路径最后一条边 $(x, v)$，它是直接指向 $v$ 的边，得 $\text{indeg}(v) \ge 1$，矛盾；反之 $\text{indeg}(v) > 0$ 时存在直接指向者，当然存在强于者。故两种题意理解下引理 1 的刻画均成立。∎

**引理 3（源点存在）**：任何 $n$ 节点 DAG 至少有一个入度 0 的节点。

**证明**：反证。若所有节点入度均 $> 0$，从任一节点出发沿某条入边不断回走，得到 $n+1$ 个节点序列；由鸽巢原理必有两步落在同一节点，回走路径的该片段构成**环**，与 DAG 矛盾。∎

**定理**：算法返回唯一冠军；冠军不唯一时返回 $-1$。

**证明**：由引理 3，候选集 $S = \{\, v : \text{indeg}(v) = 0 \,\}$ 非空。

- $|S| = 1$，设 $S = \{s\}$：由引理 1，$s$ 无人强于，是冠军；其余任意 $v$ 有 $\text{indeg}(v) > 0$，存在直接指向者，非冠军。冠军存在且唯一，返回 $s$ 正确。
- $|S| \ge 2$，任取 $s \ne t \in S$：由引理 2（含间接读法），$s$ 与 $t$ 都满足「无人强于」，都是冠军，冠军不唯一，返回 $-1$ 正确。

两种情形算法行为均与要求一致。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n + m)$。一趟扫边做 $m$ 次自增，一趟扫点做 $n$ 次判零。每条未读的边都可能把当前唯一候选踢出局（答案随之改变），因此任何正确算法必须读完整个输入，$O(n+m)$ 与输入规模同阶，已是最优；相比暴力法 $O(n(n+m))$，提升来自把「可达性的全局问题」换成「入度的局部统计」。
- **空间复杂度**：$O(n)$。仅一个入度数组（可退化为布尔数组），不需要邻接表。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int findChampion(int n, vector<vector<int>>& edges) {
        vector<int> indeg(n, 0);
        for (const auto& e : edges)
            indeg[e[1]]++;
        int champ = -1;
        for (int i = 0; i < n; i++) {
            if (indeg[i] == 0) {
                if (champ != -1) return -1;
                champ = i;
            }
        }
        return champ;
    }
};
```

### Python

```python
class Solution:
    def findChampion(self, n: int, edges: List[List[int]]) -> int:
        indeg = [0] * n
        for _, v in edges:
            indeg[v] += 1
        champs = [i for i, d in enumerate(indeg) if d == 0]
        return champs[0] if len(champs) == 1 else -1
```

## 8. 边界情况与易错点

1. **方向别记反**：$u \to v$ 表示 $u$ 强于 $v$，被统计的是**终点** `e[1]`；误写 `indeg[e[0]]++` 会把「压制者」数进去，满盘皆反。
2. **$n = 1$，$m = 0$**：唯一的队就是冠军，返回 0，循环天然覆盖。
3. **$n \ge 2$ 且 $m = 0$**：所有队入度皆为 0，候选 $\ge 2$，返回 $-1$——没有任何比赛自然分不出冠军。
4. **$-1$ 的语义是「冠军不唯一」而非「没有冠军」**：DAG 保证候选非空（引理 3），恒有队伍满足冠军定义；「0 个候选」只在输入违规（有环）时出现，此时代码返回 $-1$ 恰好也是合理的兜底。
5. **重复边无害**：判定只判「$= 0$」，即使 $[u, v]$ 出现两次使 $\text{indeg}[v] = 2$ 也不影响结论（本题输入亦不会出现）。
6. **不要建图、不要拓扑排序**：邻接表、队列、分层删边全是冗余，多写多错；Kahn 的第一步就是本题的全部。
7. **别被「传递性」带偏**：那是给暴力可达性判定准备的光滑保证，入度法不需要；误以为要跑闭包/Floyd 会平白浪费比赛时间。
