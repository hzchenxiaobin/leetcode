# LeetCode 平衡子序列的最大和 题解

## 1. 题目概述

- **标题 / 题号**：平衡子序列的最大和（#2926，hard）
- **链接**：https://leetcode.cn/problems/maximum-balanced-subsequence-sum/
- **来源**：LeetCode 第 370 场周赛 Q4
- **难度**：困难
- **标签**：树状数组、线段树、动态规划、离散化、二分查找

**题意**：给定下标从 $0$ 开始的整数数组 `nums`。选出 $k$ 个下标 $i_0 < i_1 < \cdots < i_{k-1}$ 组成子序列，若对每个 $j \in [1, k-1]$ 都有 $\text{nums}[i_j] - \text{nums}[i_{j-1}] \ge i_j - i_{j-1}$，则称该子序列**平衡**（长度为 $1$ 的子序列自动平衡）。求平衡子序列的**最大元素和**。

**约束**：

- $1 \le \text{nums.length} \le 10^5$：$O(n^2)$ 的 $10^{10}$ 次运算必然超时，需要 $O(n \log n)$
- $-10^9 \le \text{nums}[i] \le 10^9$：**有负数**，不能无脑全选；元素和最高 $10^{14}$，**必须 64 位整数**

> 💡 一句话点破：条件移项后即 $\text{nums}[i_j] - i_j \ge \text{nums}[i_{j-1}] - i_{j-1}$——令 $b[i] = \text{nums}[i] - i$，**平衡子序列就是 $b$ 上的非递减子序列**，问题变成「LIS 最大权和」这一经典模型；DP 转移里的「$j < i$ 且 $b[j] \le b[i]$ 的前驱最大值」用值域树状数组维护，$O(n \log n)$ 解决。

## 2. 示例

**示例 1**

```text
输入：nums = [3,3,5,6]
输出：14
解释：选下标 0、2、3（子序列 [3,5,6]）：
      nums[2] − nums[0] = 2 ≥ 2 − 0 = 2 ✓
      nums[3] − nums[2] = 1 ≥ 3 − 2 = 1 ✓
      和 = 3 + 5 + 6 = 14。选下标 1、2、3 同样平衡，也是 14。
```

**示例 2**

```text
输入：nums = [5,-1,-3,8]
输出：13
解释：选下标 0、3（子序列 [5,8]）：nums[3] − nums[0] = 3 ≥ 3 − 0 ✓，和 = 13。
      选下标 1、2、3 不行：nums[2] − nums[1] = −2 < 2 − 1 = 1 ✗。
```

**补充边界示例（全负数）**

```text
输入：nums = [-2,-1]
输出：-1
解释：选 [-2,-1] 虽平衡但和为 −3；最优是单选 −1。
      答案可以是负数——绝不能把答案初始化成 0。
```

## 3. 解题思路

### 3.1 暴力思路：两条路都堵死

- **枚举子集**：每个下标「选 / 不选」，$2^n$ 种组合再逐一验证，$n = 10^5$ 下是天文数字。
- **朴素 DP**：按 §3.3 的转移 $f[i] = \text{nums}[i] + \max(0,\ \max_{j<i,\ b[j] \le b[i]} f[j])$，每个 $i$ 都要**线性扫**一遍所有 $j < i$、挑出 $b[j] \le b[i]$ 的部分求最大——$O(n^2) \approx 10^{10}$，同样超时。

瓶颈在于转移里的查询是「**下标有序 + 值域有序**」的双条件 max，这正是 **LIS 优化**的经典场景：把值域离散化后用树状数组 / 线段树维护**前缀最大值**，单次查询降到 $O(\log n)$。

### 3.2 核心观察：移项，把两个条件压进一个数组

![核心观察：移项变形](images/balanced_subseq_transform.svg)

**观察 1（条件可以移项）**：对相邻选中下标 $p < q$，

$$\text{nums}[q] - \text{nums}[p] \ge q - p \iff \text{nums}[q] - q \ge \text{nums}[p] - p$$

**观察 2（$b$ 非递减）**：令 $b[i] = \text{nums}[i] - i$，则

$$\text{子序列平衡} \iff b[i_0] \le b[i_1] \le \cdots \le b[i_{k-1}]$$

**观察 3（几何直觉）**：把下标 $i$ 看成时间，条件说的是「每走一步，值至少涨 $1$」；$b[i] = \text{nums}[i] - i$ 就是元素值**跑赢「每步 +1」基准线的领先量**——平衡子序列就是领先量一路不倒退的子序列。

三步之后问题定型：**在 $b$ 上选非递减子序列、最大化 $\sum \text{nums}[i]$**——把 LIS 的「数个数」换成「加权求和」，就是经典的 **LIS 最大权和**变体。

### 3.3 算法流程：值域树状数组维护前缀最大值

![树状数组模型：先查后插](images/balanced_subseq_bit_model.svg)

DP 定义（$f[i]$ = **以 $i$ 结尾**的最大平衡子序列和）：

$$f[i] = \text{nums}[i] + \max\Big(0,\ \max_{j < i,\ b[j] \le b[i]} f[j]\Big),\qquad \text{答案} = \max_i f[i]$$

**算法步骤**：

1. 求出 $b[i] = \text{nums}[i] - i$，**排序去重离散化**成 $m$ 个槽位（$b$ 值域宽约 $2 \times 10^9$，开不下值域数组）；
2. 按 $i = 0, 1, \dots, n-1$ 的顺序处理，槽位上维护一棵**前缀最大值**树状数组；
3. 对每个 $i$：`query(rank(b[i]))` 得到「$b[j] \le b[i]$ 且 $j < i$」的最大 $f[j]$；
4. $f[i] = \text{nums}[i] + \max(0, \text{查询值})$，随后 `update(rank(b[i]), f[i])` **单点取 max** 插回；
5. 答案取 $\max_i f[i]$。

**两个精妙处**：

- **先查后插**：处理 $i$ 时槽里只有 $j < i$ 的 $f[j]$，「下标有序」这个条件被处理顺序**免费**实现，无需显式判断；
- **$\max(0, \cdot)$ 截断**：子序列不要求连续，负前缀可以整体弃掉、从 $i$ 另起炉灶——这正是「单元素子序列恒合法」的代码化。

### 3.4 示例演算

![示例演算：nums=[3,3,5,6]](images/balanced_subseq_walkthrough.svg)

**示例 1**（nums = [3,3,5,6]，$b = [3,2,3,3]$，槽位：$b$ 值 $\{2,3\}$ → 槽 $0$、槽 $1$）：

| $i$ | nums[i] | $b[i]$ | 槽位 | query（$b \le b[i]$） | $f[i]$ |
|-----|---------|--------|------|----------------------|--------|
| 0 | 3 | 3 | 1 | $-\infty$（空） | 3 |
| 1 | 3 | 2 | 0 | $-\infty$（槽 1 的 3 不算，$3 > 2$） | 3 |
| 2 | 5 | 3 | 1 | $\max(3, 3) = 3$ | 8 |
| 3 | 6 | 3 | 1 | $\max(3, 8) = 8$ | **14** |

答案 $= 14$，前驱链 $0 \to 2 \to 3$ 对应子序列 $[3,5,6]$，和 $3+5+6 = 14$ ✓。

**示例 2** 验算（nums = [5,-1,-3,8]，$b = [5,-2,-5,5]$，槽位：$-5 \to 0$、$-2 \to 1$、$5 \to 2$）：

| $i$ | $b[i]$ | 槽位 | query | $f[i]$ |
|-----|--------|------|-------|--------|
| 0 | 5 | 2 | $-\infty$ | 5 |
| 1 | −2 | 1 | $-\infty$ | −1 |
| 2 | −5 | 0 | $-\infty$ | −3 |
| 3 | 5 | 2 | $\max(-3,-1,5) = 5$ | $8+5=13$ |

答案 $13$ ✓。注意 $f[1], f[2]$ 为负照样插入槽中——被后续查询时的 $\max(0,\cdot)$ 截断，无害。

## 4. 算法细节

1. **离散化**：$b[i] \in [-10^9 - 10^5 + 1,\ 10^9]$，直接开值域数组不可能；`sort + unique` 后用 `lower_bound` 定位。由于 $b[i]$ 本身必在值集中，`lower_bound` 恰好**精确命中**，不存在「插入位置」的歧义。
2. **树状数组存「前缀最大」而非求和**：`update(p, v)` 自 $x = p+1$ 起沿 $x \mapsto x + \mathrm{lowbit}(x)$ 上行、沿途对节点值取 max；`query(p)` 自 $x = p+1$ 起沿 $x \mapsto x - \mathrm{lowbit}(x)$ 下行、拼出槽位 $[0, p]$ 上的已插入最大值。**初始化为 $-\infty$**（C++ 用 `LLONG_MIN`，Python 用 `-inf`）。
3. **先查后插**：查询在插入之前完成，保证 $i$ 永远查不到自己；「$j < i$」全靠这一顺序隐式保证。
4. **负 $f$ 照插**：槽里存的是「以某个 $j$ 结尾的最优值」，为负只说明这个结尾暂时无利可图，插入后自然被 $\max(0, \cdot)$ 屏蔽，不需要特判跳过。
5. **等号方向**：条件是 $\ge$，即 $b$ **非严格**非递减——前缀查询用 $\le$（**含相等**），重复 $b$ 值共用同一个槽位。若误用严格版本（查询 $< b[i]$），示例 1 的 $f[3]$ 会漏掉同为 $b = 3$ 的前驱。
6. **数值类型**：$|f[i]| \le 10^5 \times 10^9 = 10^{14}$，C++ 全程 `long long`；`nums[i]` 与查询值相加前注意类型提升。

## 5. 正确性证明

**引理 1（平衡条件的等价变形）**：下标序列 $i_0 < i_1 < \cdots < i_{k-1}$（$k \ge 1$）平衡，当且仅当 $b[i_0] \le b[i_1] \le \cdots \le b[i_{k-1}]$，其中 $b[i] = \text{nums}[i] - i$。

**证明**：对每个相邻对 $(i_{j-1}, i_j)$，

$$\text{nums}[i_j] - \text{nums}[i_{j-1}] \ge i_j - i_{j-1} \iff \text{nums}[i_j] - i_j \ge \text{nums}[i_{j-1}] - i_{j-1} \iff b[i_j] \ge b[i_{j-1}]$$

（两边同减 $i_j$、同加 $i_{j-1}$，不等号方向不变）。对所有 $j \in [1, k-1]$ 逐条取交即得；$k = 1$ 时无相邻对，两侧均平凡成立。∎

**引理 2（DP 递推）**：设 $f[i]$ 为以 $i$ 结尾的平衡子序列的最大和，则

$$f[i] = \text{nums}[i] + \max\Big(0,\ \max_{j < i,\ b[j] \le b[i]} f[j]\Big)$$

（内层 $\max$ 在集合为空时视为 $-\infty$，从而外层 $\max(0, \cdot) = 0$），且答案 $= \max_{0 \le i < n} f[i]$。

**证明**：以 $i$ 结尾的平衡子序列分两类。**只含 $i$**：和为 $\text{nums}[i]$，恒合法。**长度 $\ge 2$**：设倒数第二个下标为 $j$（$j < i$），由引理 1，整个序列平衡 $\iff$ 去掉 $i$ 后的前缀平衡（非递减性对子序列封闭）**且** $b[j] \le b[i]$（唯一新增的相邻条件只有 $(j, i)$ 一条）。固定 $j$ 时该类序列的和 $= \text{sum}(\text{前缀}) + \text{nums}[i]$，与前缀的具体形态无关、只依赖其和，故前缀取达到 $f[j]$ 的最优者；对所有合法 $j$ 取最大即得该类最优值 $\text{nums}[i] + \max_j f[j]$。两类合并：

$$f[i] = \max\Big(\text{nums}[i],\ \text{nums}[i] + \max_{j<i,\ b[j] \le b[i]} f[j]\Big) = \text{nums}[i] + \max\Big(0,\ \max_{j<i,\ b[j] \le b[i]} f[j]\Big)$$

任何平衡子序列必以某个 $i$ 结尾，故答案为 $\max_i f[i]$。∎

**定理（算法正确性）**：按 $i$ 从小到大处理、先查后插的树状数组算法对每个 $i$ 正确算出 $f[i]$，进而答案正确。

**证明**：先证树状数组不变式：任意时刻 $\text{query}(p) = \max\{ v_s : \text{已执行过 } \text{update}(p_s, v_s) \text{ 且 } p_s \le p \}$。由 Fenwick 树定义，节点 $x$（1-indexed）恰管辖区间 $(x - \mathrm{lowbit}(x),\ x]$；`update(p, v)` 自 $x = p+1$ 起沿 $x \mapsto x + \mathrm{lowbit}(x)$ 上行，恰好经过所有「管辖范围含 $p+1$」的节点并把 $v$ 与其取 max；`query(p)` 自 $x = p+1$ 起沿 $x \mapsto x - \mathrm{lowbit}(x)$ 下行，依次经过的节点区间互不相交且并集恰为 $[1, p+1]$（即 0-indexed 槽位 $[0, p]$），故返回值为该前缀上所有已插入值的最大值。

再对 $i$ 归纳：处理 $i$ 之前，槽中恰好插有 $j < i$ 的全部 $f[j]$（各自位于槽位 $\mathrm{rank}(b[j])$，由归纳假设值正确）。离散化保序——对值集中任意 $x, y$，$\mathrm{rank}(x) \le \mathrm{rank}(y) \iff x \le y$——故

$$\text{query}(\mathrm{rank}(b[i])) = \max\{ f[j] : j < i,\ b[j] \le b[i] \}$$

（$b[i]$ 自身因先查后插尚未进入；$b[j] = b[i]$ 的其余 $j$ 也被 $\le$ 正确纳入）。代入引理 2 得 $f[i]$ 正确；随后 `update` 维持不变式，归纳完成。$\max_i f[i]$ 遍历所有结尾，由引理 2 即为所求答案。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \log n)$。离散化排序 $O(n \log n)$；主循环 $n$ 轮，每轮一次槽位二分、一次 `query`、一次 `update`，各 $O(\log n)$。$n = 10^5$ 时约 $10^5 \times 17 \approx 1.7 \times 10^6$ 次基本操作，轻松通过。
- **空间复杂度**：$O(n)$。$b$ 数组、离散化值集、树状数组各 $O(n)$（树状数组开 $m + 1$ 个槽，$m \le n$）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long maxBalancedSubsequenceSum(vector<int>& nums) {
        int n = nums.size();
        vector<int> b(n);
        for (int i = 0; i < n; i++) b[i] = nums[i] - i;

        // 离散化：b 值域约 2e9，开不下值域数组
        vector<int> val(b);
        sort(val.begin(), val.end());
        val.erase(unique(val.begin(), val.end()), val.end());
        int m = val.size();

        // 前缀最大值树状数组（存 max，不是求和！）
        vector<long long> tree(m + 1, LLONG_MIN);
        auto update = [&](int p, long long v) {
            for (int x = p + 1; x <= m; x += x & -x) tree[x] = max(tree[x], v);
        };
        auto query = [&](int p) -> long long {   // max{ 已插入 f : 槽位 <= p }
            long long res = LLONG_MIN;
            for (int x = p + 1; x > 0; x -= x & -x) res = max(res, tree[x]);
            return res;
        };

        long long ans = LLONG_MIN;
        for (int i = 0; i < n; i++) {
            int p = lower_bound(val.begin(), val.end(), b[i]) - val.begin();
            long long best = query(p);            // j < i 且 b[j] <= b[i] 的最大 f[j]
            long long f = (long long)nums[i] + max(0LL, best);
            update(p, f);                         // 先查后插
            ans = max(ans, f);
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maxBalancedSubsequenceSum(self, nums: List[int]) -> int:
        n = len(nums)
        b = [x - i for i, x in enumerate(nums)]

        val = sorted(set(b))                     # 离散化（自动去重保序）
        rank = {v: i for i, v in enumerate(val)}
        m = len(val)

        tree = [-inf] * (m + 1)                  # 前缀最大值树状数组
        def update(p, v):
            x = p + 1
            while x <= m:
                if v > tree[x]:
                    tree[x] = v
                x += x & -x
        def query(p):
            res = -inf
            x = p + 1
            while x > 0:
                if tree[x] > res:
                    res = tree[x]
                x -= x & -x
            return res

        ans = -inf
        for i in range(n):
            p = rank[b[i]]
            best = query(p)                      # j < i 且 b[j] <= b[i]
            f = nums[i] + max(best, 0)           # 负前缀弃掉，另起炉灶
            update(p, f)                         # 先查后插
            if f > ans:
                ans = f
        return ans
```

## 8. 边界情况与易错点

1. **答案可为负**：全负数组时答案是最大的单个元素（如 $[-2,-1] \to -1$）。答案变量初始化为 $-\infty$ 而非 $0$；「转移里的 $\max(0,\cdot)$」是允许弃掉负前驱，别误改成「答案层面跟 $0$ 取 max」。
2. **溢出**：$|f| \le 10^{14}$，C++ 全程 `long long`；`nums[i] + best` 在 Python 里天然大整数，C++ 里注意 `(long long)nums[i]` 的类型提升。
3. **树状数组语义**：维护的是**前缀最大**，`update` 是单点取 max、不是位置累加；初始化 $-\infty$。本题因外层 $\max(0,\cdot)$ 的存在，初始化成 $0$ 恰好不影响结果——但纯属巧合，换个模型（如求最大权和恰好可为负的变体）就翻车，按 $-\infty$ 写最稳。
4. **等号别丢**：条件是 $\ge$，允许 $b$ 相等，查询前缀必须**含**相等的 $b$（用 $\le$），重复 $b$ 共用槽位；写成严格小于会漏解。
5. **先查后插**：先 `query` 再 `update`，否则 $i$ 会匹配到自己；「$j < i$」全靠这一顺序隐式保证。
6. **离散化必须做**：$b$ 值域宽约 $2 \times 10^9$，直接开数组会 MLE/RE；`lower_bound` 定位时 $b[i]$ 必在值集中，不存在找不到的情形。
7. **别停在 $O(n^2)$**：$n = 10^5$ 时朴素 DP 是 $10^{10}$ 次运算；比赛时看到「$j < i$ 且值满足某偏序」形态的转移，应条件反射地想到值域树状数组 / 线段树。
