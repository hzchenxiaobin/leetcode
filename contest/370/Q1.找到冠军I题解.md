# LeetCode 找到冠军 I 题解

## 1. 题目概述

- **标题 / 题号**：找到冠军 I（#2923，easy）
- **链接**：https://leetcode.cn/problems/find-champion-i/
- **来源**：LeetCode 第 370 场周赛 Q1
- **难度**：简单
- **标签**：数组、矩阵

**题意**：一场比赛有 $n$ 支队伍，编号 $0$ 到 $n-1$。给定 $n \times n$ 的 0/1 矩阵 `grid`：当 $i \ne j$ 时，`grid[i][j] == 1` 表示 $i$ 队比 $j$ 队**强**，否则 $j$ 队比 $i$ 队强。若不存在强于 $a$ 队的队伍，则 $a$ 队是**冠军**。返回冠军队伍的编号。

**约束**：

- $n = \text{grid.length} = \text{grid}[i].\text{length}$，$2 \le n \le 100$
- `grid[i][j]` 取值为 0 或 1；对角线 `grid[i][i] == 0`
- $i \ne j$ 时 `grid[i][j] != grid[j][i]`——**任两队恰有一方更强（完全性）**
- 胜负关系**可传递**：$a$ 强于 $b$、$b$ 强于 $c$，则 $a$ 强于 $c$

> 💡 签到题的最短路径：从「冠军 = 没人打赢它」直接翻译成「**列全 0**」检查，$O(n^2)$ 秒杀；再注意到约束给的是**全序**，可升级为 $O(n)$ 打擂台。

## 2. 示例

**示例 1**

```text
输入：grid = [[0,1],[0,0]]
输出：0
解释：grid[0][1] == 1 表示 0 队比 1 队强，没有队伍强于 0 队，0 队是冠军。
```

**示例 2**

```text
输入：grid = [[0,0,1],[1,0,1],[0,0,0]]
输出：1
解释：grid[1][0] == 1 表示 1 队比 0 队强；grid[1][2] == 1 表示 1 队比 2 队强。
     没有队伍强于 1 队，1 队是冠军。
```

## 3. 解题思路

### 3.1 直观思路：按定义找「全 0 列」

把定义直译成矩阵语言：队伍 $a$ 是冠军 $\Leftrightarrow$ 不存在 $i$ 使 `grid[i][a] == 1` $\Leftrightarrow$ **第 $a$ 列除对角线外全 0**。

于是逐列扫描，找到全 0 的那一列即可；对称地，也可以找「除对角线外全 1 的那一行」（冠军直接击败所有人，行和为 $n-1$）。时间 $O(n^2)$，$n \le 100$ 时最多 $10^4$ 次读取，比赛时直接写就能过。

### 3.2 核心观察：胜负关系是全序，打擂台 $O(n)$

![冠军概念：全 0 列与全序保证](images/champion_i_zero_column.svg)

矩阵给了全部 $\binom{n}{2}$ 个两两比较结果，但「找最强者」本质上只需 $n - 1$ 次比较。约束里藏着两把钥匙：

- **完全性**：$i \ne j$ 时 `grid[i][j]` 与 `grid[j][i]` 恰有一个为 1，任两队必分胜负；
- **传递性**：题目明说「强于」关系可传递。

二者合起来说明「更强」是一个**严格全序**：$n$ 支队伍排成一条确定的强弱链，冠军就是链上的**最大元**且**唯一**。找最大元的经典姿势是**打擂台**：维护当前擂主 `champ`，挑战者 $j$ 依次上擂，一次 $O(1)$ 的矩阵查询定胜负。

### 3.3 算法流程

![打擂台算法流程](images/champion_i_scan_flow.svg)

1. **初始化**：`champ = 0`，0 号队率先登擂。
2. **遍历** $j$ 从 $1$ 到 $n-1$：若 `grid[champ][j] == 0`（即 $j$ 比 `champ` 强），则 `champ = j`；否则擂主不动。
3. **结束**：返回 `champ`。

全程只读 $n - 1$ 个矩阵格子，矩阵其余 $O(n^2)$ 个单元一眼不看。

### 3.4 示例演算

![示例演算：打擂台过程](images/champion_i_walkthrough.svg)

以 `grid = [[0,0,1],[1,0,1],[0,0,0]]` 为例：

| $j$ | 查询 | 含义 | 结果 | 擂主变化 |
|-----|------|------|------|----------|
| 1 | $\text{grid}[0][1] = 0$ | 1 队强于 0 队 | 挑战成功 | $0 \to 1$ |
| 2 | $\text{grid}[1][2] = 1$ | 1 队强于 2 队 | 守擂成功 | 保持 $1$ |

最终返回 $1$，与示例 2 一致。复核：冠军列全 0（`grid[0][1] = grid[2][1] = 0`），冠军行全 1（`grid[1][0] = grid[1][2] = 1`）。

## 4. 算法细节

1. **比较方向**：判定写法是 `grid[champ][j] == 0`——位置 $(\text{champ}, j)$ 上的 0 表示挑战者 $j$ 更强；由完全性，此时 `grid[j][champ]` 必为 1。若习惯写成 `grid[j][champ] == 1` 完全等价，只是判 0 与判 1 之别，别把方向记反即可。
2. **不会读对角线**：循环中 `champ < j` 恒成立（`champ` 只会被更晚出现的 $j$ 替换），因此查询的格子永远不在对角线上。
3. **数据结构**：无需任何额外结构，一个下标变量 `champ` 足矣。
4. **两种复杂度取舍**：$O(n^2)$ 列检查是「翻译定义」，最稳；$O(n)$ 打擂台利用了全序保证，是本题的优雅解。$n \le 100$ 时两者实际耗时都可忽略。

## 5. 正确性证明

**引理 1（冠军存在且唯一）**：「强于」是 $n$ 支队伍上的严格全序。

**证明**：非自反性由对角线为 0 保证；完全性由 `grid[i][j] != grid[j][i]`（0/1 取值）保证；传递性由题面明给。严格全序下，把队伍按强弱排序，链头（最强者）存在且唯一，它无人强于，是冠军；其余每支队伍都至少被链头压制，不可能是冠军。∎

**引理 2（循环不变量）**：处理完挑战者 $j$ 后，`champ` 是队伍 $0..j$ 中的最强者。

**证明**：对 $j$ 归纳。$j = 0$ 时只有 0 号队，显然。设处理完 $j$ 时结论成立，考察 $j+1$：

- 若 `grid[champ][j+1] == 1`：擂主强于 $j+1$，又强于 $0..j$ 中所有队伍，仍是 $0..j+1$ 中最强者；
- 若 `grid[champ][j+1] == 0`：$j+1$ 强于 `champ`，由传递性也强于 `champ` 所击败的所有人，故 $j+1$ 是 $0..j+1$ 中最强者，登擂合法。

两种情况不变量均保持。∎

**定理**：算法返回冠军。

**证明**：由引理 2，循环结束时 `champ` 强于其他所有 $n-1$ 支队伍，即不存在强于 `champ` 的队伍，按定义 `champ` 是冠军；由引理 1 冠军唯一，故返回值正确。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。一趟扫描 $n - 1$ 步，每步恰一次 $O(1)$ 矩阵查询；对比直观解法 $O(n^2)$ 快一个数量级。从 $n$ 个元素中确定最大元至少需要 $n - 1$ 次两两比较，打擂台恰好达到该下界。
- **空间复杂度**：$O(1)$。仅维护一个下标变量 `champ`。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int findChampion(vector<vector<int>>& grid) {
        int champ = 0;
        for (int j = 1; j < (int)grid.size(); j++) {
            if (grid[champ][j] == 0) champ = j;
        }
        return champ;
    }
};
```

### Python

```python
class Solution:
    def findChampion(self, grid: List[List[int]]) -> int:
        champ = 0
        for j in range(1, len(grid)):
            if grid[champ][j] == 0:
                champ = j
        return champ
```

## 8. 边界情况与易错点

1. **0/1 语义记反**：位置 $(\text{champ}, j)$ 上的 **0** 才表示挑战者 $j$ 更强；写反会把「守擂」当「易主」，返回弱者。
2. **传递性是 $O(n)$ 解法的命门**：若关系可能成环（如石头剪刀布），打擂台幸存者未必全胜，必须退回 $O(n^2)$「全 0 列」检查并处理无解情形——这正是本场 Q2（2924 边集版）要面对的情况。
3. **对角线**：`grid[i][i] == 0` 恒成立且循环中 `champ < j`，永远不会读到对角线，无需特判。
4. **最小规模 $n = 2$**：只有一次比较，打擂台天然覆盖。
5. **返回值是队伍编号**（0-based 下标），不是计数或行列位置。
