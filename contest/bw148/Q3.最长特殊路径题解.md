# LeetCode 最长特殊路径 题解

## 1. 题目概述

- **标题 / 题号**：最长特殊路径（#3425，hard）
- **链接**：https://leetcode.cn/problems/longest-special-path/
- **来源**：LeetCode 第 148 场双周赛 Q3
- **难度**：困难
- **标签**：树、深度优先搜索、数组、哈希表、前缀和

**题意**：给定一棵以 $0$ 为根的无向树，$n$ 个节点，边带正长度；每个节点 $i$ 有一个值 $\text{nums}[i]$。**特殊路径**指树中一条**从祖先往下到后代**且经过节点的值**互不相同**的路径（允许起点终点相同）。返回长度为 2 的数组：

- `result[0]`：最长特殊路径的**长度**（边权之和）；
- `result[1]`：所有最长特殊路径中的**最少节点数**。

**约束**：

- $2 \le n \le 5 \cdot 10^4$
- $1 \le \text{length}_i \le 10^3$，$0 \le \text{nums}[i] \le 5 \cdot 10^4$
- `edges` 保证是一棵合法的树

## 2. 示例

**示例 1**

```text
输入：edges = [[0,1,2],[1,2,3],[1,3,5],[1,4,4],[2,5,6]], nums = [2,1,2,1,3,1]
输出：[6,2]
解释：最长特殊路径是 2 → 5（长度 6，2 个节点）与 0 → 1 → 4（长度 2+4 = 6，3 个节点）。
      两条长度并列，取节点数最少的 2。
```

**示例 2**

```text
输入：edges = [[1,0,8]], nums = [2,2]
输出：[0,1]
解释：两个节点值相同，任何包含两条边的路径都不合法；单节点路径长度 0，
      节点数最少的合法路径是 1（节点 0 或节点 1）。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有 $(u, v)$ 祖孙对，沿路径检查"值是否互不相同"，再算长度与节点数。对每对 $(u,v)$ 走一遍路径是 $O(n)$，总 $O(n^2)$，$n = 5\cdot10^4$ 时是 $2.5 \cdot 10^9$，超时。

暴力枚举的浪费在于：对每个终点都从根重新扫一遍。而 DFS 时路径是**增量变化**的 —— 进入一个节点只多了一个值，离开时再撤销。

### 3.2 核心观察：把"值互不相同"翻译成"起点下界"

![特殊路径 = 根路径的一段后缀，且这段上的"值"互不相同](images/bw148_q3_root_path_conflict.svg)

从根到当前节点 $v$ 的路径是一条"链"（深度下标 $0, 1, \dots, d$）。任何以 $v$ 为终点的祖先-后代路径，都是这条链的**一段后缀** $[s, d]$。它合法 $\iff$ 这段上的值互不相同。

DFS 时维护 `last[x]` = 值 $x$ 在当前根路径上**最后一次出现**的深度下标。走到 $v$（值 $x$、深度 $d$）时：

$$\text{low} = \max\bigl(\text{low}_{\text{父}},\ \text{last}[x]\bigr), \qquad \text{合法起点} \ge \text{low} + 1$$

为什么：若值 $x$ 之前出现在下标 $p$，那么任何包含 $p$ 的后缀都会让 $x$ 出现两次，故起点必须 $> p$。父节点已经累积了所有历史冲突，取 $\max$ 即可。

路径长度用根前缀长度 $\text{pref}[v]$ 表示：起点在下标 $s$ 时长度为 $\text{pref}[v] - \text{pref}[\text{path}[s]]$。于是

$$\text{最长长度} = \text{pref}[v] - \min_{s \in [\text{low}+1,\ d]} \text{pref}[\text{path}[s]]$$

而"节点数最少"要求起点尽量**深**，所以在取到最小 $\text{pref}$ 的那些下标里要选**最右**的一个：节点数 $= d - s + 1$。

### 3.3 算法流程

![线段树建在"深度下标"上：区间最小根前缀长度 + 最右取到者](images/bw148_q3_segmin_argmin.svg)

```text
线段树建在深度下标 0..n−1 上，每个位置存 (pref, 下标)，支持：
  update(d, pref)        进入节点时把深度 d 的位置写入
  query(l, r) → (最小 pref, 该值的最右下标)

迭代 DFS（栈里放"进入/离开"两种事件）：
  进入 v（父 p、边权 w）：
      d = (p 存在 ? dep[p] + 1 : 0)，pref[v] = pref[p] + w
      low = (p 存在 ? low[p] : -1)；low = max(low, last[nums[v]])
      old[nums[v]] = last[nums[v]]；last[nums[v]] = d；low[v] = low
      update(d, pref[v])
      (minP, s) = query(low + 1, d)
      len = pref[v] − minP；cnt = d − s + 1
      用 (len, cnt) 更新全局答案（长度优先，长度同则节点数取小）
      压入"离开 v"事件，再压入所有子节点
  离开 v：last[nums[v]] = old[nums[v]]        # 恢复现场
```

### 3.4 示例演算

![示例 1 的 DFS 走查](images/bw148_q3_example_walkthrough.svg)

| 进入节点 | 深度 / pref | low | 查询区间 | 长度 | 节点数 | 全局最优 |
|----------|-------------|-----|----------|------|--------|----------|
| 0（值 2） | $d=0$, 0 | $-1$ | $[0,0]$ → 0 @0 | 0 | 1 | [0, 1] |
| 1（值 1） | $d=1$, 2 | $-1$ | $[0,1]$ → 0 @0 | 2 | 2 | [2, 2] |
| 2（值 2） | $d=2$, 5 | $0$ | $[1,2]$ → 2 @1 | 3 | 2 | [3, 2] |
| 5（值 1） | $d=3$, 11 | $1$ | $[2,3]$ → 5 @2 | **6** | **2** | [6, 2] |
| 3（值 1） | $d=2$, 7 | $1$ | $[2,2]$ → 7 @2 | 0 | 1 | [6, 2] |
| 4（值 3） | $d=2$, 6 | $-1$ | $[0,2]$ → 0 @0 | 6 | 3 | [6, 2] |

节点 5 处 low 变成 $1$（值 1 在深度 1 出现过），所以起点只能是 2 或 3；节点 4 走的是另一条分支，回溯后 `last[2]` 已恢复成 0，所以它仍能一路接回根，得到长度 6 但节点数 3 —— 长度并列，答案是节点数更少的 2。

## 4. 算法细节

1. **迭代 DFS**：$n$ 可达 $5\cdot10^4$，递归可能爆栈。栈里放 `(节点, 父节点, 阶段, 边权)`，阶段 0 = 进入、1 = 离开。
2. **恢复 `last`**：进入 $v$ 前把 `old[v] = last[nums[v]]` 存下来，离开时写回。不恢复会让兄弟分支看到错误的历史。
3. **线段树的两个量**：`(最小 pref, 该最小值的最右下标)`。合并时"左小取左、右小取右、相等取右下标"，即得全局最右。
4. **不需要清理线段树**：查询区间 $[\text{low}+1, d]$ 只覆盖当前根路径上的位置，而位置 $> d$ 的旧叶子永远不会被查到，所以回溯时无需擦除。
5. **并列裁决**：长度相同时比节点数。节点数 $= d - s + 1$，$s$ 越深节点越少，故取最右的 $s$。
6. **`pref` 与答案类型**：$\text{pref}$ 最大 $5\cdot10^4 \times 10^3 = 5\cdot10^7$，`int` 够用，但用 `long long` 更稳妥；返回数组的元素是 `int`。
7. **单节点路径**：长度 0、节点数 1，答案初值设为 $(0, 1)$ 即覆盖示例 2 的情形。

## 5. 正确性证明

**引理 1（后缀刻画）**：以 $v$ 为终点、起点为祖先 $u$ 的路径，恰是 DFS 从根到 $v$ 的链的一段后缀 $[s, d]$，其中 $s$ 是 $u$ 的深度下标、$d$ 是 $v$ 的深度下标。

**证明**：树上从祖先到后代的路径唯一，且必为根路径的一段连续后缀。∎

**引理 2（`low` 的语义）**：走到 $v$ 时，`low` $= L$ 当且仅当：后缀 $[s, d]$ 的值互不相同 $\iff s \ge L + 1$。

**证明**：对深度归纳。$d = 0$ 时链只有一个节点，$L = -1$，条件 $s \ge 0$ 恒成立且只有一个后缀，成立。设父节点处成立，值为 $L_p$。进入 $v$ 时新增值 $x = \text{nums}[v]$，设它上次出现在下标 $p$（`last[x]`，不存在则 $p = -1$）。后缀 $[s,d]$ 的值互不相同 $\iff$ 后缀 $[s, d-1]$ 互不相同（即 $s \ge L_p + 1$）**且** $x$ 不在 $[s, d-1]$ 中出现，后者等价于 $s > p$ 即 $s \ge p + 1$。两者合并即 $s \ge \max(L_p, p) + 1 = L + 1$。∎

**引理 3（区间最小值给出最优长度）**：以 $v$ 为终点、满足 $s \ge L+1$ 的所有后缀中，长度最大者为 $\text{pref}[v] - \min_{s \in [L+1, d]}\text{pref}[\text{path}[s]]$；在长度最大者中节点数最少者为 $d - s^* + 1$，其中 $s^*$ 是最小 $\text{pref}$ 的最右取到位置。

**证明**：长度 $= \text{pref}[v] - \text{pref}[\text{path}[s]]$，$\text{pref}[v]$ 固定，故最大化长度即最小化 $\text{pref}[\text{path}[s]]$，这正由区间最小值给出。节点数 $= d - s + 1$ 随 $s$ 单调递减，故在取到最小值的下标中取最大者使节点数最小。∎

**引理 4（`last` 的恢复保证分支无关）**：离开节点 $v$ 后，`last` 与进入 $v$ 之前完全一致。

**证明**：进入时把旧值存入 `old[v]`，离开时写回，且 $v$ 的子节点都在 $v$ 离开之前完成并各自恢复了自己的改动，归纳即得。∎

**定理**：算法返回的数组为 $[\text{最长特殊路径长度},\ \text{该长度下的最少节点数}]$。

**证明**：由引理 1，所有特殊路径都是某个以 $v$ 为终点的后缀；由引理 2、3，算法对每个 $v$ 都算出了以其为终点的最优（长度最大、并列时节点最少）候选；对 $v$ 取全局最优即得答案。引理 4 保证不同分支互不污染，故每个 $v$ 的计算都基于正确的 `low` 与 `pref`。由于任何路径都以某个 $v$ 为终点，答案不会更差；而算法给出的每个候选都对应真实合法路径，故不会更好。∎

## 6. 复杂度分析

- **时间**：每个节点进入一次、离开一次，各做一次线段树点更新与一次区间查询，均 $O(\log n)$；建树 $O(n)$。总计 $O(n \log n)$，$n = 5 \cdot 10^4$ 时约 $1.7 \times 10^6$ 次操作。
- **空间**：邻接表 $O(n)$、线段树四个数组 $O(n)$、`last` 大小 $O(\max \text{nums}) \le 5\cdot10^4$、DFS 显式栈 $O(n)$。总计 $O(n)$。

### C++

```cpp
class Solution {
    int sz;
    vector<long long> mn;   // 区间内 根前缀长度 的最小值
    vector<int> arg;        // 该最小值出现的最右位置（深度下标）

    void update(int pos, long long val) {
        int i = pos + sz;
        mn[i] = val;
        arg[i] = pos;
        for (i >>= 1; i >= 1; i >>= 1) {
            int l = 2 * i, r = 2 * i + 1;
            if (mn[l] < mn[r]) { mn[i] = mn[l]; arg[i] = arg[l]; }
            else if (mn[r] < mn[l]) { mn[i] = mn[r]; arg[i] = arg[r]; }
            else { mn[i] = mn[l]; arg[i] = max(arg[l], arg[r]); }   // 并列取最右
        }
    }

    // 返回 [l, r] 内最小的根前缀长度，以及取到该最小值的最右下标
    pair<long long, int> query(int l, int r) {
        long long lo = LLONG_MAX / 4;
        int idx = -1;
        l += sz; r += sz;
        auto take = [&](int i) {
            if (mn[i] < lo || (mn[i] == lo && arg[i] > idx)) { lo = mn[i]; idx = arg[i]; }
        };
        while (l <= r) {
            if (l & 1) { take(l); l++; }
            if (!(r & 1)) { take(r); r--; }
            l >>= 1; r >>= 1;
        }
        return {lo, idx};
    }

public:
    vector<int> longestSpecialPath(vector<vector<int>>& edges, vector<int>& nums) {
        int n = (int)nums.size();
        vector<vector<pair<int, int>>> adj(n);
        for (auto& e : edges) {
            adj[e[0]].push_back({e[1], e[2]});
            adj[e[1]].push_back({e[0], e[2]});
        }

        sz = 1;
        while (sz < n) sz <<= 1;
        mn.assign(2 * sz, LLONG_MAX / 4);
        arg.assign(2 * sz, -1);

        int maxV = 0;
        for (int v : nums) maxV = max(maxV, v);
        vector<int> last(maxV + 1, -1);      // 当前根路径上该值最后一次出现的深度下标

        vector<long long> pref(n, 0);        // 根到该节点的边权和
        vector<long long> lowv(n, -1);       // 该节点处"路径起点至少要多深"的下界
        vector<int> dep(n, 0), oldLast(n, -1);

        long long bestLen = 0;
        int bestCnt = 1;

        struct Ev { int v, p, phase, w; };
        vector<Ev> st;
        st.push_back({0, -1, 0, 0});
        while (!st.empty()) {
            Ev e = st.back();
            st.pop_back();
            int v = e.v, p = e.p;
            if (e.phase == 1) {                       // 回溯：恢复该值上一次出现的位置
                last[nums[v]] = oldLast[v];
                continue;
            }
            int d = (p == -1) ? 0 : dep[p] + 1;
            dep[v] = d;
            pref[v] = (p == -1) ? 0 : pref[p] + e.w;

            long long low = (p == -1) ? -1 : lowv[p];
            int val = nums[v];
            if (last[val] > low) low = last[val];      // 冲突位置：起点必须在它之后
            oldLast[v] = last[val];
            last[val] = d;
            lowv[v] = low;

            update(d, pref[v]);
            auto [minP, idx] = query((int)(low + 1), d);
            long long len = pref[v] - minP;
            int cnt = d - idx + 1;
            if (len > bestLen || (len == bestLen && cnt < bestCnt)) {
                bestLen = len;
                bestCnt = cnt;
            }

            st.push_back({v, p, 1, 0});
            for (auto& [to, w] : adj[v])
                if (to != p) st.push_back({to, v, 0, w});
        }
        return {(int)bestLen, bestCnt};
    }
};
```

### Python

```python
class Solution:
    def longestSpecialPath(self, edges: list, nums: list) -> list:
        n = len(nums)
        adj = [[] for _ in range(n)]
        for u, v, w in edges:
            adj[u].append((v, w))
            adj[v].append((u, w))

        sz = 1
        while sz < n:
            sz <<= 1
        INF = float('inf')
        mn = [INF] * (2 * sz)        # 深度区间内"根前缀长度"的最小值
        arg = [-1] * (2 * sz)        # 该最小值出现的最右深度下标

        def update(pos, val):
            i = pos + sz
            mn[i] = val
            arg[i] = pos
            i >>= 1
            while i:
                l = i << 1
                r = l | 1
                if mn[l] < mn[r]:
                    mn[i], arg[i] = mn[l], arg[l]
                elif mn[r] < mn[l]:
                    mn[i], arg[i] = mn[r], arg[r]
                else:                # 并列时取最右，保证节点数最少
                    mn[i] = mn[l]
                    arg[i] = arg[l] if arg[l] > arg[r] else arg[r]
                i >>= 1

        def query(l, r):
            lo = INF
            idx = -1
            l += sz
            r += sz
            while l <= r:
                if l & 1:
                    if mn[l] < lo or (mn[l] == lo and arg[l] > idx):
                        lo, idx = mn[l], arg[l]
                    l += 1
                if not (r & 1):
                    if mn[r] < lo or (mn[r] == lo and arg[r] > idx):
                        lo, idx = mn[r], arg[r]
                    r -= 1
                l >>= 1
                r >>= 1
            return lo, idx

        maxV = max(nums)
        last = [-1] * (maxV + 1)     # 当前根路径上该值最后出现的深度下标
        pref = [0] * n
        lowv = [-1] * n
        dep = [0] * n
        old = [-1] * n

        best_len, best_cnt = 0, 1
        # 迭代 DFS 栈：(节点, 父节点, 阶段, 边权)；阶段 0 进入，1 离开
        stack = [(0, -1, 0, 0)]
        while stack:
            v, p, phase, w = stack.pop()
            if phase == 1:
                last[nums[v]] = old[v]       # 回溯：恢复该值上一次出现的位置
                continue
            d = 0 if p < 0 else dep[p] + 1
            dep[v] = d
            pref[v] = 0 if p < 0 else pref[p] + w

            low = -1 if p < 0 else lowv[p]
            val = nums[v]
            if last[val] > low:
                low = last[val]
            old[v] = last[val]
            last[val] = d
            lowv[v] = low

            update(d, pref[v])
            minP, idx = query(low + 1, d)
            length = pref[v] - minP
            cnt = d - idx + 1
            if length > best_len or (length == best_len and cnt < best_cnt):
                best_len, best_cnt = length, cnt

            stack.append((v, p, 1, 0))
            for to, ww in adj[v]:
                if to != p:
                    stack.append((to, v, 0, ww))
        return [best_len, best_cnt]
```

## 8. 边界情况与易错点

1. **忘记回溯 `last`**：最典型的 WA。兄弟分支会继承别的分支的"最后一次出现"，导致 `low` 偏大、答案偏小。
2. **`low + 1 > d` 的情况**：不会出现 —— `low` 最大是父节点深度 $d-1$（同值只可能在更浅处），所以区间 $[\text{low}+1, d]$ 至少含 $d$ 本身（单节点路径，长度 0）。若写成 `low` 而不是 `low+1`，会把冲突节点自己算进去。
3. **并列时取最左下标**：长度正确但节点数偏大，`result[1]` 错。
4. **递归爆栈**：链状树深度 $5\cdot10^4$，Python 默认递归限制 1000，必须迭代或手动 `setrecursionlimit`（迭代更稳）。
5. **根节点**：`low = -1`、`pref = 0`、深度 0，答案初值 $(0,1)$ 覆盖单节点。
6. **值域下标**：`last` 需开到 $\max(\text{nums}) + 1$，不要写死 $10^5$（也可以，但按最大值开更省）。
7. **边的方向**：`edges` 里的 $u,v$ 不保证 $u$ 是父亲，必须建无向图后从 0 号节点 DFS。
8. **线段树的残留**：查询区间只覆盖当前链，无需回溯清理；但若你把查询区间写成 $[0, d]$，就会读到别的分支的残留值而错。
