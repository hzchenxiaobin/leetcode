# LeetCode 所有安放棋子方案的曼哈顿距离 题解

## 1. 题目概述

- **标题 / 题号**：所有安放棋子方案的曼哈顿距离（#3426，hard）
- **链接**：https://leetcode.cn/problems/manhattan-distances-of-all-arrangements-of-pieces/
- **来源**：LeetCode 第 148 场双周赛 Q4
- **难度**：困难
- **标签**：数学、组合数学

**题意**：给定 $m \times n$ 的棋盘（$mn \ge 2$）与 $k \ge 2$ 个**无差别**的棋子。**合法方案**指把 $k$ 个棋子放进格子、每格至多一个。对所有合法方案，求"每对棋子之间的曼哈顿距离之和"的总和，对 $10^9+7$ 取模。

**约束**：

- $1 \le m, n \le 10^5$，$2 \le mn \le 10^5$
- $2 \le k \le mn$

注意 $mn \le 10^5$ 意味着棋盘的总格子数不大，但 $m$ 或 $n$ 单独可以到 $10^5$ —— 提示我们**必须用公式**，不能真的建棋盘（$m \times n$ 的二维枚举在 $m = 10^5, n = 1$ 时只有 $10^5$ 个格子，但在 $m = n = 316$ 时也才 $10^5$，其实建棋盘是可行的；真正的关键是"枚举方案数"爆炸，$C(mn,k)$ 天文数字）。

## 2. 示例

**示例 1**

```text
输入：m = 2, n = 2, k = 2
输出：8
解释：2×2 棋盘放 2 个棋子，共 C(4,2) = 6 种方案：
      4 种是"相邻"的，距离为 1（合计 4）；2 种是"对角"的，距离为 2（合计 4）。
      答案 4 + 4 = 8。
```

**示例 2**

```text
输入：m = 1, n = 4, k = 3
输出：20
解释：一维 4 格放 3 子，共 4 种方案（空出不同的格子）：
      空 0 → 1+2+1 = 4；空 1 → 2+3+1 = 6；空 2 → 6；空 3 → 4，合计 20。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有合法方案（$C(mn, k)$ 种，指数级），对每个方案枚举 $\binom{k}{2}$ 对棋子算距离求和。方案数可以是 $\binom{10^5}{10^5/2}$ 级别，完全不可行。即便只枚举"格子对"再乘方案数，格子对也有 $O((mn)^2) = 10^{10}$ 个，同样不行。

必须把"求和"化成**闭式**。

### 3.2 核心观察：交换求和顺序

![换个角度数：不去枚举方案，而是枚举"一对棋子"](images/bw148_q4_count_pairs.svg)

先把"方案内的对"与"方案间的求和"交换顺序：

$$\text{答案} = \sum_{\text{方案}} \sum_{\{p,q\} \subseteq \text{方案}} \text{dist}(p,q) = \sum_{\{p,q\}} \text{dist}(p,q) \cdot \#\{\text{含有 } p,q \text{ 的方案}\}$$

对任意固定的格子对 $\{p, q\}$，"同时占用 $p, q$ 的方案数"只取决于 $k$ —— 从剩下 $mn-2$ 个格子中再选 $k-2$ 个：

$$\#\{\text{含 } p,q \text{ 的方案}\} = \binom{mn-2}{k-2}$$

它与 $p, q$ 的具体位置**无关**，因此可以整体提出来：

$$\text{答案} = \binom{mn-2}{k-2} \cdot \sum_{\{p,q\}} \text{dist}(p,q)$$

问题降维成："棋盘上所有格子对的曼哈顿距离之和"。

### 3.3 算法流程

![曼哈顿距离可以按行、列拆开算](images/bw148_q4_row_col_decompose.svg)

曼哈顿距离按维度可加：$\text{dist} = |r_1 - r_2| + |c_1 - c_2|$，而"行列"在求和时可以分离。固定**行距** $d$：

- 行号差为 $d$ 的行对共 $m - d$ 个（$(0,d), (1,d+1), \dots$）；
- 每个行对内部的列可以任取，贡献 $n \times n = n^2$ 对格子；
- 每对格子的行距离都是 $d$。

于是行方向总贡献为

$$n^2 \sum_{d=1}^{m-1} d\,(m - d) = n^2 \cdot S(m)$$

列方向对称：$m^2 \cdot S(n)$。于是

$$\sum_{\{p,q\}} \text{dist}(p,q) = n^2 S(m) + m^2 S(n), \qquad S(L) = \sum_{d=1}^{L-1} d(L-d) = \frac{L^3 - L}{6}$$

$S(L)$ 的推导：$\sum_{d=1}^{L-1} d(L-d) = L\sum d - \sum d^2 = L\cdot\frac{(L-1)L}{2} - \frac{(L-1)L(2L-1)}{6} = \frac{L^3-L}{6}$。

```text
1. total = m * n，预处理 fact[0..total] 与 invfact[0..total]
2. ways = C(total − 2, k − 2)
3. S(L) = (L³ − L) / 6  （模 1e9+7 下乘 6 的逆元）
4. pairs = n² · S(m) + m² · S(n)
5. 返回 ways × pairs mod (1e9+7)
```

### 3.4 示例演算

![两个示例的数字核对](images/bw148_q4_example_walkthrough.svg)

| 示例 | $\binom{mn-2}{k-2}$ | $S(m)$ | $S(n)$ | $\sum\text{dist}$ | 答案 |
|------|---------------------|--------|--------|-------------------|------|
| $m=n=2, k=2$ | $\binom{2}{0}=1$ | $S(2)=1$ | $S(2)=1$ | $4\cdot1 + 4\cdot1 = 8$ | $8$ |
| $m=1, n=4, k=3$ | $\binom{2}{1}=2$ | $S(1)=0$ | $S(4)=10$ | $16\cdot0 + 1\cdot10 = 10$ | $20$ |

第二个示例可以用枚举校验：一维 4 格放 3 子共 4 种方案，方案内距离和分别为 $4, 6, 6, 4$，总计 $20$ —— 与公式一致。

## 4. 算法细节

1. **组合数**：$mn \le 10^5$，预处理阶乘与阶乘逆元到 $mn$ 即可，$O(mn)$；$\binom{mn-2}{k-2}$ 用 `fact[a] * invfact[b] % MOD * invfact[a-b] % MOD`。
2. **$S(L)$ 的取模**：$L^3$ 在 $L = 10^5$ 时是 $10^{15}$，超出 32 位但仍在 64 位内；先取模再乘更安全，$6$ 的逆元是 $166666668$。
3. **$n^2 S(m)$ 的溢出**：$n \le 10^5$ 时 $n^2 = 10^{10}$，必须先用 `long long`/取模再相乘。
4. **不要真的构造棋盘**：本解法完全不需要遍历 $mn$ 个格子，只有 $O(mn)$ 的阶乘预处理。
5. **$k = 2$ 与 $k = mn$ 两个端点**：$k=2$ 时 $\binom{mn-2}{0} = 1$（每个格子对恰好对应一个方案）；$k = mn$ 时 $\binom{mn-2}{mn-2} = 1$（只有一个方案）。
6. **模数**：$10^9+7$ 是质数，$mn < 10^9+7$，所以阶乘不会出现 $0$，逆元一定存在。

## 5. 正确性证明

**引理 1（按格子对求和）**：$\text{答案} = \binom{mn-2}{k-2}\sum_{\{p,q\}} \text{dist}(p,q)$。

**证明**：把二重求和交换顺序：

$$\sum_{\text{方案}}\sum_{\{p,q\}\subseteq \text{方案}} \text{dist} = \sum_{\{p,q\}} \text{dist}(p,q)\sum_{\text{方案} \ni p,q} 1 .$$

对固定 $\{p,q\}$，含它的方案 = 从剩余 $mn - 2$ 个格子中选 $k-2$ 个（棋子无差别，方案即格子集合），故内层和为 $\binom{mn-2}{k-2}$，与 $\{p,q\}$ 无关，可提出求和号。∎

**引理 2（行方向求和）**：$\sum_{\{p,q\}} |r_p - r_q| = n^2 S(m)$。

**证明**：按行距 $d = |r_p - r_q| \in [1, m-1]$ 分组。行对 $(r_1, r_2)$ 满足 $|r_1 - r_2| = d$ 的个数为 $m - d$（$r_1$ 可取 $0..m-d-1$）。每对行配上任意两列（$n^2$ 种），每对格子的行距离都是 $d$。故总和 $= n^2 \sum_{d=1}^{m-1} d(m-d) = n^2 S(m)$。∎

**引理 3**：$S(L) = \sum_{d=1}^{L-1} d(L-d) = \dfrac{L^3-L}{6}$。

**证明**：$S(L) = L\sum_{d=1}^{L-1} d - \sum_{d=1}^{L-1} d^2 = L\cdot\frac{L(L-1)}{2} - \frac{(L-1)L(2L-1)}{6} = \frac{3L^2(L-1) - L(L-1)(2L-1)}{6} = \frac{L(L-1)(3L - (2L-1))}{6} = \frac{L(L-1)(L+1)}{6} = \frac{L^3-L}{6}$。∎

**引理 4（行列可加）**：$\sum_{\{p,q\}} \text{dist}(p,q) = n^2 S(m) + m^2 S(n)$。

**证明**：$\text{dist}(p,q) = |r_p-r_q| + |c_p-c_q|$，两个求和分别处理：行方向由引理 2 得 $n^2S(m)$；列方向对称地按列距分组，列对 $n-d$ 个、每对行列组合 $m^2$ 种，得 $m^2S(n)$。∎

**定理**：算法返回值等于所有合法方案中每对棋子曼哈顿距离之和的总和（模 $10^9+7$）。

**证明**：由引理 1 与引理 4，答案 $= \binom{mn-2}{k-2}\bigl(n^2S(m) + m^2S(n)\bigr)$；引理 3 给出 $S$ 的闭式。算法正是按此式计算（组合数与 $S$ 均在模 $10^9+7$ 下计算，$\frac{1}{6}$ 用逆元实现，因 $10^9+7$ 与 $6$ 互素故合法）。∎

## 6. 复杂度分析

- **时间**：阶乘与逆阶乘预处理 $O(mn)$；随后 $O(\log MOD)$ 次快速幂（求逆元）与 $O(1)$ 次四则运算。总计 $O(mn + \log MOD) = O(mn)$，$mn \le 10^5$。
- **空间**：两个长度 $mn+1$ 的数组，$O(mn)$。

## 7. 参考代码

### C++

```cpp
class Solution {
    static const int MOD = 1000000007;

    long long power(long long a, long long e) const {
        long long r = 1;
        a %= MOD;
        while (e > 0) {
            if (e & 1) r = r * a % MOD;
            a = a * a % MOD;
            e >>= 1;
        }
        return r;
    }

public:
    int distanceSum(int m, int n, int k) {
        int total = m * n;
        // 阶乘与阶乘逆元，用来算组合数 C(total-2, k-2)
        vector<long long> fact(total + 1), invf(total + 1);
        fact[0] = 1;
        for (int i = 1; i <= total; i++) fact[i] = fact[i - 1] * i % MOD;
        invf[total] = power(fact[total], MOD - 2);
        for (int i = total; i >= 1; i--) invf[i - 1] = invf[i] * i % MOD;
        auto C = [&](int a, int b) -> long long {
            if (b < 0 || b > a) return 0;
            return fact[a] * invf[b] % MOD * invf[a - b] % MOD;
        };

        // S(L) = sum_{d=1}^{L-1} d*(L-d) = (L^3 - L) / 6
        const long long inv6 = power(6, MOD - 2);
        auto S = [&](long long L) -> long long {
            long long t = (L % MOD) * (L % MOD) % MOD * (L % MOD) % MOD;   // L^3
            long long num = (t - L % MOD + MOD) % MOD;                    // L^3 - L
            return num * inv6 % MOD;
        };

        long long pairs = (1LL * n % MOD) * (n % MOD) % MOD * S(m) % MOD      // 行方向
                        + (1LL * m % MOD) * (m % MOD) % MOD * S(n) % MOD;      // 列方向
        pairs %= MOD;

        long long ways = C(total - 2, k - 2);   // 固定这一对格子后，其余棋子的放法
        return (int)(ways * pairs % MOD);
    }
};
```

### Python

```python
class Solution:
    def distanceSum(self, m: int, n: int, k: int) -> int:
        MOD = 10 ** 9 + 7
        total = m * n
        fact = [1] * (total + 1)
        for i in range(1, total + 1):
            fact[i] = fact[i - 1] * i % MOD
        invf = [1] * (total + 1)
        invf[total] = pow(fact[total], MOD - 2, MOD)
        for i in range(total, 0, -1):
            invf[i - 1] = invf[i] * i % MOD
        ways = fact[total - 2] * invf[k - 2] % MOD * invf[total - k] % MOD

        inv6 = pow(6, MOD - 2, MOD)
        def S(L):                      # sum_{d=1}^{L-1} d*(L-d) = (L^3-L)/6
            return (L * L % MOD * L % MOD - L) % MOD * inv6 % MOD

        pairs = (n * n % MOD * S(m) + m * m % MOD * S(n)) % MOD
        return ways * pairs % MOD
```

## 8. 边界情况与易错点

1. **忘记乘 $\binom{mn-2}{k-2}$**：只算"格子对距离和"会漏掉每种方案被重复计数的部分，答案偏小 $C$ 倍。
2. **$k = 2$**：$\binom{mn-2}{0} = 1$，此时答案就是"所有格子对距离和"。
3. **$k = mn$**：只有一个方案（放满），$\binom{mn-2}{mn-2} = 1$；此时答案就是整盘所有格子对距离和。
4. **$m = 1$ 或 $n = 1$**：$S(1) = 0$，对应方向贡献为 0（一维棋盘没有行差），不要写入负指数或越界。
5. **溢出**：$n^2$ 与 $L^3$ 都会超 32 位；`(t - L % MOD + MOD) % MOD` 里的 `+MOD` 不能省（$L^3 \bmod$ 可能小于 $L$）。
6. **模逆元**：$\frac{L^3-L}{6}$ 不能直接整除后在模下除，必须乘 $6^{-1}$；$1/6$ 的逆元是 $166666668$。
7. **数组大小**：阶乘表开到 $mn$（不是 $\max(m,n)$），因为组合数的上标是 $mn-2$。
8. **误导性的数据范围**：$m, n$ 各自可达 $10^5$ 但 $mn \le 10^5$，说明不能开 $m \times n$ 的二维数组（当 $m=10^5, n=1$ 时相当于 $10^5$ 行，二维数组会爆内存）—— 本解法完全不建棋盘。
