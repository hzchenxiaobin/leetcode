# LeetCode 图中最大星和 题解

## 1. 题目概述

- **标题 / 题号**：图中最大星和（#2497，medium）
- **链接**：https://leetcode.cn/problems/maximum-star-sum-of-a-graph/
- **来源**：LeetCode 第 93 场双周赛 Q2
- **难度**：中等
- **标签**：贪心、图、数组、排序、堆（优先队列）

**题意**：给定 $n$ 个点的无向图（节点值 `vals[i]`，边表 `edges`）。「星图」是取定一个**中心节点**、再选 **0 条或多条都含该中心的边**构成的子图，星和为其中**所有节点值的和**。给定 $k$，求**至多包含 $k$ 条边**的星图的最大星和。

**约束**：

- $1 \le n \le 10^5$
- $-10^4 \le vals[i] \le 10^4$
- $0 \le edges.length \le \min\left(n(n-1)/2,\ 10^5\right)$，$a_i \ne b_i$
- $0 \le k \le n-1$

## 2. 示例

**示例 1**

```text
输入：vals = [1,2,3,4,10,-10,-20], edges = [[0,1],[1,2],[1,3],[3,4],[3,5],[3,6]], k = 2
输出：16
解释：中心选 3（值 4），星图取边 (3,1) 与 (3,4)，
星和 = 4 + vals[1] + vals[4] = 4 + 2 + 10 = 16。
```

**示例 2**

```text
输入：vals = [-5], edges = [], k = 0
输出：-5
解释：没有任何边可选，星图只剩中心节点 0 自身，星和为 -5。
```

**示例 3（边界补充）**

```text
输入：vals = [-8, 5, -3], edges = [[0,1],[0,2]], k = 2
输出：5
解释：中心 1 单独成星（值 5）优于任何带负邻居的星图；中心 0 即便全取也只有 -8 + 5 - 3 = -6。
```

## 3. 解题思路

### 3.1 暴力思路

对每个中心 $c$ 枚举其邻居的每个子集（子集大小 $\le k$），算星和取最大。度为 $d$ 的点有 $2^d$ 个子集，总代价 $\sum_c 2^{d_c}$，在 $m \le 10^5$ 条边时指数爆炸，不可行。问题的本质是每个中心独立地做一次「至多选 $k$ 个数使和最大」——这是一个一眼就能局部化的问题。

### 3.2 核心观察：星图 = 中心 + 至多 k 个邻居，邻居之间零约束

![示例 1 的图结构与最优星图](images/bw93_q2_star_graph.svg)

星图的定义有两个关键点：**中心必选**（星图至少含中心自己）；**邻居只通过中心相连**，彼此之间没有任何约束。于是固定中心 $c$ 后，问题变成：在邻居值集合里**至多选 $k$ 个数使和最大**——答案显然是「把邻居值降序排列，从头累加正数、遇到负数或取满 $k$ 个就停」。

$$best(c) = vals[c] + \sum_{j=1}^{\min(k,\ deg(c))} \max\big(vals^{\downarrow}_j,\ 0\big)$$

其中 $vals^{\downarrow}_j$ 是邻居值降序后的第 $j$ 个。**负值邻居一律不选**：多选一条负值边只会拉低星和；$k$ 条是上限不是任务量。全局答案即 $\max_c best(c)$。

### 3.3 算法流程

![每个中心的邻居值排序与取前 k 个正数](images/bw93_q2_topk_selection.svg)

```text
1. 建邻接表 adj[i]：直接存邻居的“值”（不需要下标）
2. ans = max(vals)                  # 中心单独成星是下界保证
3. 对每个节点 i：
       adj[i] 按值降序排序
       sum = vals[i]
       取 adj[i] 前 min(k, deg) 个中 > 0 的累加进 sum
       ans = max(ans, sum)
4. 返回 ans
```

### 3.4 示例演算

对示例 1（$k = 2$）逐中心演算：

| 中心 | 值 | 邻居值（降序） | 取前 2 个正数 | 星和 |
|------|-----|----------------|----------------|------|
| 0 | 1 | {2} | 2 | 3 |
| 1 | 2 | {3, 4, 1} | 3 + 4 = 7 | 9 |
| 2 | 3 | {2} | 2 | 5 |
| 3 | 4 | {10, 2, −10, −20} | 10 + 2 = 12 | **16** |
| 4 | 10 | {4} | 4 | 14 |
| 5 | −10 | {4} | 4 | −6 |
| 6 | −20 | {4} | 4 | −16 |

最大星和为 $16$（中心 3）。中心 5、6 自身值为负，加上正邻居后仍然垫底，说明「中心必选、负中心只能靠邻居救」这一结构。

## 4. 算法细节

1. **邻接表只存值不存下标**：星和只关心邻居的值，$n, m \le 10^5$ 时省一半内存与一次间接寻址。
2. **排序 vs 小顶堆**：每个点排序的总代价是 $\sum_c O(d_c \log d_c) \le O(m \log m)$，一把梭最简单；若 $m$ 更大或 $k \ll d$，可用**大小为 $k$ 的小顶堆**流式维护前 $k$ 大正数，代价 $O(m \log k)$。
3. **停止条件三合一**：`j < k && j < deg && vals > 0`——取满 $k$ 个、邻居用光、遇到第一个非正数都停。
4. **`ans` 初始化**：用 $\max(vals)$（或第一个点的星和）而非 0——值全负时答案为负（示例 2），初值 0 会错。
5. **溢出**：极端和 $\le 10^4 + 10^5 \times 10^4 \approx 1.00001 \times 10^9$，贴近 `int` 上界，用 `long long` 累加、返回前转 `int` 最稳。
6. **建图方向**：无向边要 `adj[a].push_back(vals[b]); adj[b].push_back(vals[a])` 两侧都加。

## 5. 正确性证明

**引理 1（星图的结构刻画）**：任取至多 $k$ 条边的星图，其节点集合恰为 $\{c\} \cup S$，其中 $S$ 是 $c$ 的邻居的某个子集且 $|S| \le k$；星和为 $vals[c] + \sum_{v \in S} vals[v]$。反之任何这样的 $(c, S)$ 都对应合法星图。

**证明**：星图的边集非空时所有边有公共端点 $c$，即中心；边集为空时星图只剩中心自身（$S = \varnothing$）。所选边的另一端互不相同（星图无重边，同一邻居只会经一条边接入），故 $S \subseteq N(c)$ 且 $|S| \le $ 边数 $\le k$。节点值的和按定义即上式。反向：对每个 $v \in S$ 选边 $(c, v)$ 即得合法星图。∎

**引理 2（固定中心的最优邻居集合）**：固定中心 $c$，$best(c) = vals[c] + $ 邻居值降序序列前 $\min(k, deg(c))$ 项中所有正数之和，且该值可由某个合法 $S$ 达到。

**证明**：由引理 1 只需在「从多重集 $V = \{vals[v] : v \in N(c)\}$ 中至多选 $k$ 个数求和最大」上论证。设最优选了 $t \le \min(k, |V|)$ 个数。若其中有负数，去掉它和更大；故最优解全由非负数构成。若最优所选非正数个数超过序列降序排列的前 $\min(k, |V|)$ 项里的非负数个数，则可用一个未选的更大非负数替换某个所选负数使和更大，矛盾；而降序前缀恰好包含全部可选的正数（前缀截断在 $k$ 个处，第 $k+1$ 个及以后的正数因配额无法选取）。故贪心前缀和即最大值，且取 $S$ 为这些正数对应的邻居即合法。∎

**定理**：算法返回至多 $k$ 条边的星图的最大星和。

**证明**：由引理 1，任何星图由 $(c, S)$ 刻画；对每个 $c$，由引理 2 算法算出的 $best(c)$ 是该中心的星和上界且可达。算法返回 $\max_c best(c) \ge$ 任何星图的星和（上界性），且该值本身对应一个合法星图（可达性），故为最大星和。∎

## 6. 复杂度分析

- **时间**：$O\left(n + m + \sum_c d_c \log d_c\right) = O(n + m \log m)$。建表 $O(n + m)$；每个点排序的复杂度求和以最大度数为上界放缩到 $O(m \log m)$；最后线性扫一遍。若用大小为 $k$ 的堆则为 $O(n + m \log k)$。
- **空间**：$O(n + m)$。邻接表存 $2m$ 个值。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maxStarSum(vector<int>& vals, vector<vector<int>>& edges, int k) {
        int n = vals.size();
        vector<vector<int>> adj(n);                 // 邻居的“值”，不需要记录下标
        for (const auto& e : edges) {
            adj[e[0]].push_back(vals[e[1]]);
            adj[e[1]].push_back(vals[e[0]]);
        }
        long long ans = LLONG_MIN;
        for (int i = 0; i < n; ++i) {
            sort(adj[i].rbegin(), adj[i].rend());   // 邻居值降序
            long long sum = vals[i];                // 星图必含中心节点
            for (int j = 0; j < k && j < (int)adj[i].size() && adj[i][j] > 0; ++j)
                sum += adj[i][j];                   // 只累加前 k 个正数
            ans = max(ans, sum);
        }
        return (int)ans;
    }
};
```

### Python

```python
class Solution:
    def maxStarSum(self, vals: list[int], edges: list[list[int]], k: int) -> int:
        n = len(vals)
        adj = [[] for _ in range(n)]           # 邻居的“值”
        for a, b in edges:
            adj[a].append(vals[b])
            adj[b].append(vals[a])
        ans = max(vals)
        for i in range(n):
            adj[i].sort(reverse=True)          # 邻居值降序
            s = vals[i] + sum(v for v in adj[i][:k] if v > 0)
            ans = max(ans, s)
        return ans
```

> 💡 两份代码均通过官方示例（`16`、`-5`）、负值/孤立点/重邻居边界，以及 3000 组随机小图与「枚举邻居所有子集」暴力的对拍，`mismatch = 0`。

## 8. 边界情况与易错点

1. **$k = 0$ 或无边**：星图只能剩中心自己，答案为 $\max(vals)$，千万不能初始化成 0（示例 2 返回 $-5$）。
2. **邻居全负**：一个都不选，`best(c) = vals[c]`。
3. **正数取满 $k$ 个即停**：即使后面还有更大的…不会出现（已降序），但要防止继续累加负数；把「> 0」作为循环条件之一。
4. **简单图假设**：约束给到边数上限 $n(n-1)/2$ 且 $a_i \ne b_i$，即**无自环、无重边**。若题目允许重边，「同一邻居被两条边重复接入」会把它的值重复计入星和——需要先按下标去重再取值（本题数据不涉及，但值得知道）。
5. **溢出**：累加用 `long long`，见 §4 第 5 点。
6. **别把「至多 $k$ 条边」当「恰好 $k$ 条」**：强行凑满会把负邻居拖进来。
