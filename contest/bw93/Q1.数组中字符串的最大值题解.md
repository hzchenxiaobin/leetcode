# LeetCode 数组中字符串的最大值 题解

## 1. 题目概述

- **标题 / 题号**：数组中字符串的最大值（#2496，easy）
- **链接**：https://leetcode.cn/problems/maximum-value-of-a-string-in-an-array/
- **来源**：LeetCode 第 93 场双周赛 Q1
- **难度**：简单
- **标签**：数组、字符串

**题意**：定义字符串的「值」：若字符串**只包含数字**，值为它表示的十进制数；否则值为字符串的**长度**。给定一个由小写字母和数字组成的字符串数组 `strs`，返回其中最大的值。

**约束**：

- $1 \le strs.length \le 100$
- $1 \le strs[i].length \le 9$
- `strs[i]` 只包含小写英文字母和数字

## 2. 示例

**示例 1**

```text
输入：strs = ["alic3","bob","3","4","00000"]
输出：5
解释：
- "alic3" 包含字母，值为长度 5；
- "bob" 只含字母，值为长度 3；
- "3"、"4" 只含数字，值分别为 3、4；
- "00000" 只含数字，值为 0。
最大值为 5。
```

**示例 2**

```text
输入：strs = ["1","01","001","0001"]
输出：1
解释：所有串都是纯数字串且数值都是 1（前导零不改变数值），返回 1。
```

**示例 3（边界补充）**

```text
输入：strs = ["999999999"]
输出：999999999
解释：长度上限 9 的纯数字串，数值可达 999999999，仍在 int 范围内。
```

## 3. 解题思路

### 3.1 暴力思路

本题没有复杂度压力：最直接的做法就是**按定义逐串求值再取最大**。真正的难点不在算法，而在**判定的边界**——这也是签到题的价值所在：把「读清定义 → 无 bug 落地」的最短路径走稳。容易踩的坑有三个：前导零（`"00000"` 的值是 $0$ 不是 $5$）、混合串（`"alic3"` 含数字但仍按长度 $5$ 计）、以及用库函数时把 Unicode 数字误判为数字（本题字符集已限定，详见 §8）。

### 3.2 核心观察：值的分段定义 → 一次线性扫描

![值的分段定义与判定流程](images/bw93_q1_value_rule.svg)

「值」函数是**分段**的：先做一次「是否全为数字」的判定，再决定走「十进制数值」分支还是「长度」分支。判定本身只需检查每个字符是否落在 `'0'` 到 `'9'` 之间。于是整个问题就是一次线性扫描：

$$value(s) = \begin{cases} \text{stoi}(s) & s \text{ 全为数字} \\ |s| & \text{否则} \end{cases}$$

答案即 $\max_{s \in strs} value(s)$。

### 3.3 算法流程

```text
1. ans = 0
2. 对每个字符串 s：
       allDigit = true
       对每个字符 c：若 c < '0' 或 c > '9'，则 allDigit = false，跳出
       v = allDigit ? stoi(s) : s.size()
       ans = max(ans, v)
3. 返回 ans
```

### 3.4 示例演算

![示例 1 的逐串求值过程](images/bw93_q1_example_walkthrough.svg)

对示例 1 逐串套用规则：

| 字符串 | 全为数字？ | 求值分支 | 值 |
|--------|-----------|----------|-----|
| `"alic3"` | 否（含字母） | 长度 | 5 |
| `"bob"` | 否 | 长度 | 3 |
| `"3"` | 是 | 数值 | 3 |
| `"4"` | 是 | 数值 | 4 |
| `"00000"` | 是（前导零） | 数值 | 0 |

最大值为 $5$，来自 `"alic3"`。

## 4. 算法细节

1. **数字判定用字符范围比较**：`'0' <= c && c <= '9'`，不依赖 `isdigit`（后者接受当前 locale 下的其他数字字符，虽然本题无影响，但范围比较最稳）。
2. **数值转换**：C++ 用 `stoi`，前导零自动忽略；Python 用 `int(s)` 同理。长度最多 9，最大 $999999999 < 2^{31}-1$，`int` 安全。
3. **混合串含数字也按长度**：如 `"alic3"` 中有 `'3'`，但只要出现任意非数字字符就走长度分支。
4. **答案初值取 0**：值的最小可能为 0（`"0"`、`"00000"`），而长度分支至少为 1，故 0 是合法下界，不会误伤。
5. **无需排序/去重**：只求最大值，一次遍历维护 `ans` 即可。

## 5. 正确性证明

**引理 1（纯数字判定与数值计算）**：字符串 $s$ 只含数字，当且仅当每个字符 $c_i \in \{\text{'0'}, \dots, \text{'9'}\}$；此时其十进制数值为 $\sum_{i=0}^{L-1}\big(c_i - \text{'0'}\big) \cdot 10^{L-1-i}$，前导零贡献为 0，不影响数值。

**证明**：字符集限定为小写字母与数字，故「非字母」等价于「数字」，逐字符比较即可判定。数值公式即十进制定义；前导零对应的高位系数为 0，求和后自动消去。∎

**定理**：上述算法返回 $\max_{s \in strs} value(s)$。

**证明**：对每个 $s$，由引理 1，算法在「全数字」时计算出正确数值、否则计算出 $|s|$，即 $value(s)$ 被逐个正确求出。遍历中以 `ans` 维护「已处理字符串的最大值」这一不变量：初始为合法下界 0，每处理一个串做一次 `max` 更新，归纳可得处理完所有串后 `ans` 恰为全体最大值。∎

## 6. 复杂度分析

- **时间**：$O\left(\sum_{s \in strs} |s|\right)$。每个字符至多被检查一次，`stoi` 的代价与串长同阶；总串长 $\le 100 \times 9 = 900$。
- **空间**：$O(1)$。只用常数个变量（不计输入本身）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maximumValue(vector<string>& strs) {
        int ans = 0;
        for (const string& s : strs) {
            bool allDigit = true;
            for (char c : s)
                if (c < '0' || c > '9') { allDigit = false; break; }
            ans = max(ans, allDigit ? stoi(s) : (int)s.size());
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maximumValue(self, strs: list[str]) -> int:
        ans = 0
        for s in strs:
            if all('0' <= c <= '9' for c in s):      # 只含数字 → 数值
                ans = max(ans, int(s))
            else:                                    # 否则 → 长度
                ans = max(ans, len(s))
        return ans
```

> 💡 两份代码均通过官方示例（`5`、`1`）、长 9 的极值数字串边界，以及 5000 组随机串与 `try: int(s) except: len(s)` 暴力实现的对拍，`mismatch = 0`。

## 8. 边界情况与易错点

1. **前导零**：`"00000"` 的值是 $0$ 不是 $5$——先判定再选分支，不要先看长度。
2. **`"01"` 的值是 1**：`stoi` / `int` 会自动去掉前导零。
3. **混合串按长度**：`"alic3"` 中的数字不参与数值计算，值是长度 5。
4. **初值不要用负数**：值域非负且最小为 0，`ans = 0` 即可；用 `-1` 反而会在全 0 输入（如 `["0"]`）时多算。
5. **Python 的 `str.isdigit()` 陷阱**：对 Unicode 数字（如 `'٣'`、`'²'`）返回 `True`，其中部分无法被 `int()` 解析或解析出非十进制值。本题字符集限定小写字母与数字，不受影响；但若在其他题目复用此判定，建议用显式范围比较。
6. **溢出**：长度上限 9，数值上限 $999999999 < 2^{31}-1$，`int` 安全；若题目放宽长度，需换 `long long` 或按「长度与数值不可比」重新设计比较。
