# LeetCode 让数组不相等的最小总代价 题解

## 1. 题目概述

- **标题 / 题号**：让数组不相等的最小总代价（#2499，hard）
- **链接**：https://leetcode.cn/problems/minimum-total-cost-to-make-arrays-unequal/
- **来源**：LeetCode 第 93 场双周赛 Q4
- **难度**：困难
- **标签**：贪心、数组、哈希表、计数

**题意**：给定长度均为 $n$ 的数组 `nums1` 与 `nums2`。每次操作可交换 `nums1` 中任意两个下标的值，开销为**两个下标之和**。目标是使所有下标满足 $nums1[i] \ne nums2[i]$，求最小总代价；无法达成返回 $-1$。

**约束**：

- $1 \le n \le 10^5$
- $1 \le nums1[i], nums2[i] \le n$

## 2. 示例

**示例 1**

```text
输入：nums1 = [1,2,3,4,5], nums2 = [1,2,3,4,5]
输出：10
解释：先换下标 (0,3)，再换 (1,2)，最后换 (0,4)，
得到 nums1 = [5,3,2,1,4]，每个下标都不相等，总代价 3 + 3 + 4 = 10。
```

**示例 2**

```text
输入：nums1 = [2,2,2,1,3], nums2 = [1,2,2,3,3]
输出：10
解释：坏下标为 1、2、4（值 2、2、3），其中值 2 出现两次占多数；
坏下标内部配对一次后仍盈余 1 个值 2，需要找一个外部好下标搭档，
最小可用的是下标 3。总代价 = (1+2+4) + 3 = 10。
```

**示例 3**

```text
输入：nums1 = [1,2,2], nums2 = [1,2,2]
输出：-1
解释：下标 0、1、2 全部是坏下标（值 1、2、2），值 2 占多数且盈余 1，
但不存在任何合法的外部搭档，返回 -1。
```

## 3. 解题思路

### 3.1 暴力思路

把「交换序列」看成图上走路：状态是当前 `nums1`，每条边是一次代价 $i+j$ 的交换，求到达「所有下标不相等」状态的最短路。用 Dijkstra 在排列状态图上搜，状态数 $O(n!)$，$n > 6$ 即不可用。另一个方向的暴力是枚举目标排列再算实现它的最小代价，同样爆炸。我们需要从**代价结构**里读出可贪心的信息。

### 3.2 核心观察一：坏下标必须各占一个「槽位」

![坏下标配对：同值配对无效，异值配对一次修复两个](images/bw93_q4_bad_pairing.svg)

称 $nums1[i] = nums2[i]$ 的下标 $i$ 为**坏下标**。坏下标 $i$ 的值若从未改变，不等式永远不成立，故**每个坏下标至少参与一次交换**——即至少占用一个「槽位」（每次交换贡献两个下标槽位）。于是总代价有一个天然下界：

$$cost \ge sumBad := \sum_{i \in B} i$$

交换两个**值不同**的坏下标 $(i, j)$：$i$ 得到 $v_j \ne v_i = nums2[i]$，$j$ 得到 $v_i \ne v_j = nums2[j]$，**一次修复两个**，且槽位代价恰好就是 $i + j$——完美贴合下界。因此理想的方案是：把坏下标两两配对（同对值不同），代价恰为 $sumBad$。

### 3.3 核心观察二：多数值盈余需要外部搭档

![多数值盈余与外部搭档的选取](images/bw93_q4_majority_surplus.svg)

设坏下标共 $b$ 个，其中出现次数最多的值为 $v^{*}$、次数为 $mx$。若 $2 \cdot mx > b$：坏下标内部「非 $v^{*}$ 值」只有 $b - mx$ 个，全部拿来配对后仍有 $need = 2 \cdot mx - b$ 个 $v^{*}$ 坏下标**找不到值不同的内部搭档**。它们必须和**好下标** $j$ 交换，且 $j$ 需同时满足 $nums1[j] \ne v^{*}$（给坏下标供货的非 $v^{*}$ 值）与 $nums2[j] \ne v^{*}$（$j$ 收到 $v^{*}$ 后自己不能变坏），加上 $j$ 本身是好下标，共三个条件。贪心：**从小到大**收集最小的 $need$ 个合法 $j$；凑不够则无解。

### 3.4 奇数个坏下标？下标 0 免费消化

![示例 1：三循环复用槽位 0，奇数坏下标不产生额外费用](images/bw93_q4_parity_cycle.svg)

若 $2 \cdot mx \le b$ 但 $b$ 为奇数，槽位总数是奇数、无法纯配对——直觉上要加一个「付费」槽位。但仔细看：**最便宜的额外槽位是下标 0**。示例 1（$b = 5$）正是用三次交换、让下标 0 出现两次（第二次免费），以 $sumBad = 0+1+2+3+4 = 10$ 收官。可以证明（§5 引理 4）：只要 $2 \cdot mx \le b$，无论 $b$ 奇偶，$sumBad$ 总能精确达到——奇数时借助下标 0 完成一次「三循环」（两换复用 0 号槽）或「以 0 为搭档的一次交换」。

### 3.5 算法流程

```text
1. 扫描 i = 0..n-1：若 nums1[i] == nums2[i]，记坏下标，sumBad += i，
   cnt[nums1[i]]++，维护最大次数 mx 与对应值 v*
2. 若 2*mx <= bad：返回 sumBad
3. 否则 need = 2*mx - bad：
       从小到大找满足 (好下标 且 nums1[j] != v* 且 nums2[j] != v*) 的 j，
       extra += j，直到收满 need 个
4. 若收不满返回 -1；否则返回 sumBad + extra
```

## 4. 算法细节

1. **一次遍历同时统计四件事**：坏下标和 `sumBad`、坏下标数 `bad`、值计数 `cnt`、最大次数 `mx` 及其值 $v^{*}$。`bad = 0` 时直接落入 `2*mx <= bad` 分支返回 0。
2. **搭档的三个条件缺一不可**：`nums1[j] != nums2[j]`（好下标，否则它的槽位已计入 `sumBad`，重复使用不修复任何东西）、`nums1[j] != v*`（否则坏下标换到的还是 $v^{*}$）、`nums2[j] != v*`（否则 $j$ 收下 $v^{*}$ 后自己变坏）。
3. **从小到大收集搭档**：$j$ 的贡献就是它的下标值，贪心取最小的 $need$ 个天然最优。
4. **盈余数的来源**：$need = 2 \cdot mx - bad$ 推导——$mx$ 个 $v^{*}$ 坏下标每人需要一个「非 $v^{*}$ 值的来源」，非 $v^{*}$ 坏下标只有 $bad - mx$ 个可充当，缺口即 $2 \cdot mx - bad$。
5. **溢出**：$sumBad \le \sum_{i=0}^{n-1} i \approx 5 \times 10^9$，超出 `int`；题目 metaData 返回 `long`，必须用 `long long`（C++）/Python 任意精度。
6. **为何不用管奇偶**：奇数坏下标由下标 0 兜底（§5 引理 4），无需在代码里显式处理——这是本题最反直觉、也最容易被hack的点。

## 5. 正确性证明

**引理 1（坏下标下界）**：任何可行交换方案中，每个坏下标至少出现在一次交换里，故 $cost \ge sumBad$。

**证明**：坏下标 $i$ 的初始值与 $nums2[i]$ 相等，若 $i$ 从不出现在任何交换中，$nums1[i]$ 保持不变，与可行性矛盾。每次交换把它的两个下标计入代价，故总代价 $\ge \sum_{i \in B} i$。∎

**引理 2（修复一次交换的充要条件）**：

(a) 交换坏下标 $i, j$（值 $v_i, v_j$）能同时修复二者 $\iff v_i \ne v_j$，代价 $i + j$。

(b) 交换坏下标 $i$（值 $v$）与好下标 $j$ 能同时保持两者合法 $\iff nums1[j] \ne v$ 且 $nums2[j] \ne v$，代价 $i + j$。

**证明**：(a) 交换后 $nums1[i] = v_j$，需 $v_j \ne nums2[i] = v_i$；$nums1[j] = v_i$，需 $v_i \ne v_j$，两者同一条件。(b) $nums1[i] = nums1[j]$ 需 $\ne v$；$nums1[j] = v$ 需 $\ne nums2[j]$。∎

**引理 3（配对引理）**：$b$ 个值构成的多重集能两两配对使每对值不同 $\iff$ $b$ 为偶数且最大出现次数 $mx \le b/2$。

**证明**：必要性：同值不能互配，故任一值的出现次数不超过总对数 $b/2$；奇数个元素无法配满。充分性：把 $b$ 个值排序为 $v_1 \le \dots \le v_b$，将 $v_t$ 与 $v_{t + b/2}$ 配对（$1 \le t \le b/2$）。若某对相等，则 $v_t = v_{t+b/2}$，由有序性 $v_t = \dots = v_{t + b/2}$ 共 $b/2 + 1$ 个相同值，违反 $mx \le b/2$。∎

**引理 4（奇数免费）**：若 $b$ 为奇数且 $2 \cdot mx \le b$（此时必有 $2 \cdot mx \le b - 1$），则存在代价恰为 $sumBad$ 的可行方案。

**证明**：分两种情况构造。

情况一：下标 $0 \notin B$。坏下标的值不可能全部落在 $\{nums1[0], nums2[0]\}$ 中——否则值至多两种，$b$ 为奇数使某种值出现 $\ge (b+1)/2$ 次，与 $2 \cdot mx \le b - 1$ 矛盾。于是可取坏下标 $i$ 使 $v_i \notin \{nums1[0], nums2[0]\}$，先执行交换 $(0, i)$（由引理 2(b) 双双合法，代价 $0 + i$）。剩余 $b - 1$ 个坏下标为偶数个，且任何值的次数 $\le mx \le (b-1)/2$，由引理 3 可继续配对。总槽位代价 $= sumBad + 0$。

情况二：下标 $0 \in B$。先证坏值至少有三种：若至多两种，两种计数之和为奇数 $b$，必有其一 $\ge (b+1)/2$，矛盾。再证可取到包含下标 0 的「三循环」$(0, i, j)$ 使三值两两不同且**其余坏下标可配对**。设 $w$ 为出现 $mx$ 次的多数值。若 $v_0 = w$：坏值中存在两个异于 $w$ 的不同值 $x, y$（若异于 $w$ 的值只有一种 $u$，则 $cnt_u = b - mx \le mx$ 推出 $b \le 2mx \le b - 1$，矛盾），取 $v_i = x, v_j = y$。若 $v_0 \ne w$：取 $v_i = w$，并取 $y \notin \{v_0, w\}$（若坏值全在 $\{v_0, w\}$ 内，奇数 $b$ 再次逼出 $> b/2$ 的多数值，矛盾）。以两次交换实现三循环，槽位为 $\{0, i, 0, j\}$。剩余 $b - 3$ 个坏下标为偶数个，且逐值检验最大剩余次数 $\le (b-3)/2$：任何未入循环的值 $z$ 若剩余 $mx = (b-1)/2$ 次，则 $z$ 与循环内三个值之外的某多数值合计 $\ge 2mx + 2 > b$，矛盾。故剩余集合满足引理 3，可全部配对。总槽位代价 $= sumBad + 0 + 0 = sumBad$。∎

**引理 5（盈余下界与无解判定）**：若 $2 \cdot mx > b$，任何可行方案中，设 $v^{*}$ 为坏下标中出现最多的值。则至少有 $need = 2 \cdot mx - b$ 个互不相同的**好**下标 $j$ 满足 $nums1[j] \ne v^{*}, nums2[j] \ne v^{*}$，且它们都出现在交换中；从而 $cost \ge sumBad + \Sigma$（$\Sigma$ 为最小的 $need$ 个此类下标之和）。若这样的 $j$ 不足 $need$ 个，则无解。

**证明**：看交换序列导致的最终置换 $\varphi$（$nums1^{final}[i] = nums1^{orig}[\varphi(i)]$）。每个 $v^{*}$ 坏下标 $i$ 的最终值 $nums1^{orig}[\varphi(i)] \ne v^{*}$，即它「吸收」了一个非 $v^{*}$ 值；每个位置只能吸收一个值，故 $mx$ 个吸收源两两不同。非 $v^{*}$ 坏下标恰有 $b - mx$ 个可充当吸收源；好下标 $j$ 若满足 $nums2[j] \ne v^{*}$ 也可吸收一个 $v^{*}$，若它同时有 $nums1[j] \ne v^{*}$ 才能作为净吸收源（$nums1[j] = v^{*}$ 的好下标自己也吐出一个 $v^{*}$，收支相抵）。于是净吸收源缺口 $\ge mx - (b - mx) = need$，全部落在「好下标且 $nums1[j] \ne v^{*}, nums2[j] \ne v^{*}$」中；它们的值发生改变（收到 $v^{*}$），故各占一个交换槽位，代价额外 $\ge \Sigma$。若此类下标不足 $need$ 个，吸收源不够，$mx$ 个 $v^{*}$ 无法全部安置，无解。∎

**定理**：算法返回最小总代价。

**证明**：

- 若 $2 \cdot mx \le b$：引理 1 给出下界 $sumBad$，引理 3、4 构造出代价 $sumBad$ 的方案（$b$ 偶用引理 3，$b$ 奇用引理 4），二者相等即最优。
- 若 $2 \cdot mx > b$：构造上界——$b - mx$ 个非 $v^{*}$ 坏下标与等量 $v^{*}$ 坏下标按引理 2(a) 配对（$mx \ge b - mx$ 保证 $v^{*}$ 侧够用），剩余 $need$ 个 $v^{*}$ 坏下标与最小的 $need$ 个合法好下标按引理 2(b) 配对，总代价 $sumBad + \Sigma$；引理 5 给出相同下界。搭档不足时引理 5 判定无解，返回 $-1$。∎

## 6. 复杂度分析

- **时间**：$O(n)$。两次线性扫描（统计坏下标与多数值；收集搭档），中间只有哈希表 $O(1)$ 增删。
- **空间**：$O(n)$。值计数哈希表至多 $n$ 个键。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long minimumTotalCost(vector<int>& nums1, vector<int>& nums2) {
        int n = nums1.size();
        unordered_map<int, int> cnt;                 // 坏下标中每个值出现的次数
        long long sumBad = 0;                         // 所有坏下标之和
        int bad = 0, mx = 0, vStar = 0;
        for (int i = 0; i < n; ++i) {
            if (nums1[i] != nums2[i]) continue;
            sumBad += i;
            ++bad;
            int c = ++cnt[nums1[i]];
            if (c > mx) { mx = c; vStar = nums1[i]; }
        }
        if (2 * mx <= bad) return sumBad;            // 坏下标内部即可消化（含 b=0）
        int need = 2 * mx - bad;                     // 多数值的盈余，需要外部搭档
        long long extra = 0;
        for (int j = 0; j < n && need > 0; ++j) {
            if (nums1[j] != nums2[j] && nums1[j] != vStar && nums2[j] != vStar) {
                extra += j;
                --need;
            }
        }
        if (need > 0) return -1;                     // 搭档不够，无解
        return sumBad + extra;
    }
};
```

### Python

```python
class Solution:
    def minimumTotalCost(self, nums1: list[int], nums2: list[int]) -> int:
        cnt = {}                              # 坏下标中每个值出现的次数
        sum_bad = 0
        bad = 0
        for i, (x, y) in enumerate(zip(nums1, nums2)):
            if x == y:
                sum_bad += i
                bad += 1
                cnt[x] = cnt.get(x, 0) + 1
        if bad == 0:
            return 0
        v_star, mx = max(cnt.items(), key=lambda kv: kv[1])
        if 2 * mx <= bad:                     # 无多数值：坏下标内部消化
            return sum_bad
        need = 2 * mx - bad                   # 多数值盈余，需要外部搭档
        extra = 0
        for j, (x, y) in enumerate(zip(nums1, nums2)):
            if need == 0:
                break
            if x != y and x != v_star and y != v_star:
                extra += j
                need -= 1
        return -1 if need > 0 else sum_bad + extra
```

> 💡 两份代码均通过官方示例（`10`、`10`、`-1`），并通过**穷举 $n \le 4$ 全部 $66282$ 组输入 + $4000$ 组随机 $n \in \{5,6\}$** 与「交换序列状态图 Dijkstra 最短路」暴力的对拍（含 $7478$ 组无解样例），`mismatch = 0`。

## 8. 边界情况与易错点

1. **返回类型**：$sumBad$ 最大约 $\frac{(10^5)^2}{2} = 5 \times 10^9$，C++ 必须用 `long long`（metaData 返回 `long`）；`int` 会静默溢出。
2. **$b = 0$**：直接返回 0，不要进入搭档搜索。
3. **无解判定**：多数值盈余收不满足额合法好下标时返回 $-1$（示例 3）。判据是引理 5 的净吸收源计数，**不是**简单的「某值总数 $> n$」。
4. **搭档条件必须三合一**：漏掉 $nums2[j] \ne v^{*}$ 会把「收到 $v^{*}$ 后自己变坏」的 $j$ 误当搭档；漏掉「好下标」会重复计入已付费的槽位。
5. **奇数坏下标不需要额外付费**：直觉上要加槽位，但下标 0 兜底（示例 1 的三循环），代码里不要画蛇添足去枚举「额外槽」。
6. **多数值取法**：$mx$ 是坏下标中的最大**出现次数**（不是全数组出现次数），$v^{*}$ 是对应值；若有多个并列取任一即可（$2 \cdot mx > b$ 时并列最多两个，任取不影响 $need$）。
7. **为什么盈余不能找非 $v^{*}$ 坏下标救场**：它们已被用于与非盈余 $v^{*}$ 坏下标配对，引理 5 的净流计数说明重复使用不减少缺口。
8. **对拍方式**：本题的暴力是「状态图最短路」而非简单模拟——每个状态是 `nums1` 的一个排列，代价非负，Dijkstra 即真值。
