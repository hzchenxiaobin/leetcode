# LeetCode 青蛙过河 II 题解

## 1. 题目概述

- **标题 / 题号**：青蛙过河 II（#2498，medium）
- **链接**：https://leetcode.cn/problems/frog-jump-ii/
- **来源**：LeetCode 第 93 场双周赛 Q3
- **难度**：中等
- **标签**：贪心、数组、二分查找

**题意**：河中石头位置由严格递增数组 `stones` 给出。青蛙从第一块石头出发，跳到最后一块石头，再跳回第一块石头；**每块石头至多到达一次**（起点出发与终点折返不重复计）。一条路径的**代价**是其中**最大跳跃长度**，跳跃长度为两块石头的位置差 $|stones[i] - stones[j]|$。求最小代价。

**约束**：

- $2 \le stones.length \le 10^5$
- $0 \le stones[i] \le 10^9$，$stones[0] = 0$，严格递增

## 2. 示例

**示例 1**

```text
输入：stones = [0,2,5,6,7]
输出：5
解释：去程 0 → 5 → 7（跳 5、2），回程 7 → 6 → 2 → 0（跳 1、4、2），
最大跳跃长度为 5。可以证明不存在代价小于 5 的路径。
```

**示例 2**

```text
输入：stones = [0,3,9]
输出：9
解释：去程直接 0 → 9，回程 9 → 0，两次跳跃长度都是 9，代价 9。
```

**示例 3（边界补充）**

```text
输入：stones = [0, 1000000000]
输出：1000000000
解释：只有两块石头，往返都必须一跳到底，代价即两端距离。
```

## 3. 解题思路

### 3.1 暴力思路

把往返拆成「去程访问的石头序列」与「回程访问的石头序列」（除首尾外不交），枚举每个内部石头归属去程/回程/跳过，再枚举两个序列的全排列取最小最大跳。这是 $O(3^n \cdot n!)$ 级别的灾难。退一步的经典套路是**二分答案**：猜代价上限 $x$，检验「能否用 $\le x$ 的跳跃完成往返」——但可行性检验的贪心并不好写（去程的取舍会连锁影响回程）。本题真正的考点是一个结构性观察：最优解有一个**闭式公式**。

### 3.2 核心观察：答案 =「隔一个差」的最大值

![下界论证：区间穿越必然产生一记长跳](images/bw93_q3_interval_crossing.svg)

注意到行程是「从最左到最右、再回来」：对任意**内部石头** $i$（$1 \le i \le n-2$），位置区间 $(stones[i-1],\ stones[i+1])$ 内部**只有石头 $i$ 这一块**。青蛙的完整行程从 $stones[0] \le stones[i-1]$ 出发、必然到达 $stones[n-1] \ge stones[i+1]$、再回到 $stones[0]$——也就是说，它必须**从区间左侧穿越到右侧一次、再从右侧穿越回左侧一次**。石头 $i$ 至多落地一次，于是**至多有一次穿越能借道石头 $i$**，另一次穿越必须**一跳跨过整个区间**，长度至少 $stones[i+1] - stones[i-1]$。由此得到下界：

$$cost \ge \max_{1 \le i \le n-2} \big(stones[i+1] - stones[i-1]\big)$$

这个论证非常强：它**不要求路径单调**（允许来回蹦），也**不要求访问全部石头**（允许跳过），任何合法行程都逃不掉。

### 3.3 算法流程 / 构造上界

![奇偶交替分配构造：去程走偶数下标，回程走奇数下标](images/bw93_q3_alternating_partition.svg)

而下界可以由「**奇偶交替分配**」精确达到：去程只踩下标为偶数的石头，回程只踩下标为奇数的石头（首尾两块两条链都要用）。此时两条链上任何一跳都跨过**恰好一块被对方链占用的石头**，即形如 $stones[j] - stones[j-2]$：

```text
1. 若 n == 2，返回 stones[1] - stones[0]
2. ans = 0
3. 对 i = 1 .. n-2：ans = max(ans, stones[i+1] - stones[i-1])
4. 返回 ans
```

### 3.4 示例演算

![示例 1 的三处候选间隔差与最优路径](images/bw93_q3_example_walkthrough.svg)

对 `stones = [0,2,5,6,7]` 计算「隔一个差」：

| $i$ | $stones[i+1] - stones[i-1]$ | 值 |
|-----|------------------------------|-----|
| 1 | $stones[2] - stones[0] = 5 - 0$ | 5 |
| 2 | $stones[3] - stones[1] = 6 - 2$ | 4 |
| 3 | $stones[4] - stones[2] = 7 - 5$ | 2 |

最大值为 $5$。按构造取去程 $0 \to 5 \to 7$（下标 $0,2,4$，跳 $5,2$）、回程 $7 \to 6 \to 2 \to 0$（下标 $4,3,1,0$，跳 $1,4,2$），最大跳恰为 $5$，与下界吻合。

## 4. 算法细节

1. **公式本身就是算法**：一次线性扫描 $i \in [1, n-2]$ 取 $stones[i+1] - stones[i-1]$ 的最大值，$O(n)$。
2. **$n = 2$ 特判**：没有内部石头，循环体不执行；真实答案是 $stones[1] - stones[0]$（去、回各一跳到底）。
3. **不需要排序**：题目保证严格递增。
4. **为什么答案不是相邻差的最大值**：那是「单程从左到右」的问题；往返结构迫使每条链都要「跨过」对方链上的石头，多跨一块就多出相邻两段间隔。
5. **溢出**：$stones[i] \le 10^9$，差值 $\le 10^9 < 2^{31}-1$，`int` 足够；放 `long long` 更保险（Python 无此虑）。
6. **正确读题**：「每块石头至多到达一次」意味着内部石头在去/回两条链间**不交分配**；跳过某块石头是允许的，但下界证明表明跳过帮不上忙、构造表明不跳过就能达标。

## 5. 正确性证明

**引理 1（穿越下界）**：对任意内部石头 $i$（$1 \le i \le n-2$），任何合法行程的代价 $\ge stones[i+1] - stones[i-1]$。

**证明**：记 $a = stones[i-1]$，$b = stones[i+1]$，开放区间 $(a, b)$ 中只有石头 $m = stones[i]$。把行程（去程 + 回程拼接成的位置序列 $P_0 = stones[0], P_1, \dots, P_T = stones[0]$）中每个落点按位置分入三区：左区 $\le a$、中区 $= m$、右区 $\ge b$。行程起点 $stones[0] \le a$ 在左区，终点同在左区；而行程必经 $stones[n-1] \ge b$（右区），故位置序列从左区出发、至少进入右区一次、再回到左区——至少发生一次「左→右」与一次「右→左」的相邻区域跨越。中区只有石头 $m$ 一块，而每块石头至多到达一次，故序列中至多出现**一个**中区落点，至多「承载」一次借道穿越（左→中→右或右→中→左）。于是另一次跨越必是**直接**的相邻落点 $P_t, P_{t+1}$ 分属左、右两区：若 $P_t \le a < b \le P_{t+1}$，则跳跃长度 $P_{t+1} - P_t \ge b - a$；另一方向同理。故最大跳跃 $\ge b - a = stones[i+1] - stones[i-1]$。∎

**引理 2（交替构造达到下界）**：构造去程链 $A = \{$下标 $0, 2, 4, \dots\} \cup \{n-1\}$、回程链 $B = \{$下标 $n-1\} \cup \{$下标 $1, 3, 5, \dots\} \cup \{$下标 $0\}$，各自按位置顺序行进（回程从 $n-1$ 递减到 $0$），则两条链的最大跳跃均 $\le M := \max_{1 \le i \le n-2}(stones[i+1] - stones[i-1])$。

**证明**：$A$ 与 $B$ 除首尾外不交，故为合法行程（每块石头至多一次）。$A$ 中相邻落点下标差为 2（相邻偶数）或 1（末端衔接 $n-1$，此时 $n-1$ 为奇数），前者跳跃为 $stones[j] - stones[j-2]$，恰为 $i = j-1$ 处的候选值 $\le M$；后者为相邻差 $stones[n-1] - stones[n-2] \le stones[n-1] - stones[n-3] \le M$（$i = n-2$ 处候选）。起始衔接 $0 \to$ 第一个奇数同理，相邻差 $\le stones[2] - stones[0] \le M$。$B$ 完全对称。故该行程代价 $\le M$。∎

**定理**：当 $n \ge 3$，最小代价恰为 $M = \max_{1 \le i \le n-2}(stones[i+1] - stones[i-1])$；当 $n = 2$ 时为 $stones[1] - stones[0]$。

**证明**：由引理 1，任何行程代价 $\ge \max_i (stones[i+1] - stones[i-1]) = M$（下界）；由引理 2，存在代价 $\le M$ 的合法行程（上界可达）。两者夹逼得最小代价 $= M$。$n = 2$ 时行程只能是 $0 \to 1 \to 0$ 两次满跳，代价为 $stones[1] - stones[0]$。∎

## 6. 复杂度分析

- **时间**：$O(n)$。一次线性扫描；`stones` 已严格递增，无需任何排序或预处理。
- **空间**：$O(1)$。只滚动使用 $O(1)$ 变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maxJump(vector<int>& stones) {
        int n = stones.size();
        if (n == 2) return stones[1] - stones[0];   // 只有首尾两块石头
        int ans = 0;
        for (int i = 1; i + 1 < n; ++i)
            ans = max(ans, stones[i + 1] - stones[i - 1]);
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maxJump(self, stones: list[int]) -> int:
        n = len(stones)
        if n == 2:
            return stones[1] - stones[0]
        return max(stones[i + 1] - stones[i - 1] for i in range(1, n - 1))
```

> 💡 两份代码均通过官方示例（`5`、`9`）与 $n = 2$ 边界，并通过 **30000 组随机数据**（$n \le 7$、位置随机）与「枚举全部去/回程归属 × 全排列（含非单调顺序与跳过石头）」暴力的对拍，`mismatch = 0`。

## 8. 边界情况与易错点

1. **$n = 2$ 特判**：循环区间为空会返回 0，必须单独返回 $stones[1] - stones[0]$（示例 3）。
2. **不要写成相邻差**：$\max_i (stones[i+1] - stones[i])$ 是单程问题的答案，往返结构下会系统性偏小（示例 1 中它给 3，正确答案 5）。
3. **不需要「访问全部石头」的假设**：引理 1 的下界对允许跳过、允许非单调的任意行程成立；引理 2 的构造恰好全部访问且单调。
4. **首尾石头两条链共用**：起点（出发与最终返回）与终点（到达与折返出发）不算重复到达，构造里两条链都含它们。
5. **二分答案不是最短路**：若坚持二分 $x$ 再验证，验证逻辑远比本公式难写对——赛场上先找结构再动手。
6. **数据规模**：$n \le 10^5$、值 $\le 10^9$：`int` 存差值安全，Python 无溢出问题。
