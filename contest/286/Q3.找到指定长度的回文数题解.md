# LeetCode 找到指定长度的回文数 题解

## 1. 题目概述

- **标题 / 题号**：找到指定长度的回文数（#2217，medium）
- **链接**：https://leetcode.cn/problems/find-palindrome-with-fixed-length/
- **来源**：LeetCode 第 286 场周赛 Q3
- **难度**：中等
- **标签**：数学、构造、数组

**题意**：给定查询数组 `queries` 与正整数 `intLength`，对每个 `queries[i] = q` 返回**长度恰为 `intLength` 的正回文数**中**第 q 小**的那个（1-indexed）；不存在则返回 `-1`。回文数从前往后与从后往前读完全相同，且不允许前导零。

**约束**：

- $1 \le \text{queries.length} \le 5 \times 10^4$ —— 多查询，但每个查询只依赖 $(q, \text{intLength})$，彼此独立
- $1 \le \text{queries}[i] \le 10^9$ —— 排名可达 $10^9$，注定不能逐个枚举
- $1 \le \text{intLength} \le 15$ —— 回文最长 15 位（$\approx 10^{15}$），C++ 必须用 64 位整数承载

> 💡 **关键转译**：题目问的不是「判定回文」而是「按排名构造回文」。回文左右对称，**左半（前 $\lceil n/2 \rceil$ 位）一旦确定，整个回文就被唯一确定**——于是「第 $q$ 小的 $n$ 位回文」直接坍缩成「第 $q$ 小的 $h$ 位整数」，一次算术定位加一次镜像拼接，$O(1)$ 出答案。这是本场分胜负的关键题：看出双射的人一分钟写完，没看出的人在枚举里超时。

## 2. 示例

**示例 1**

```text
输入：queries = [1,2,3,4,5,90], intLength = 3
输出：[101,111,121,131,141,999]
解释：长度为 3 的最小回文数依次是
     101, 111, 121, 131, 141, 151, ..., 191, 202, ...
     第 90 个（也是最大的）是 999。
```

**示例 2**

```text
输入：queries = [2,4,6], intLength = 4
输出：[1111,1331,1551]
解释：长度为 4 的前 6 个回文数是
     1001, 1111, 1221, 1331, 1441, 1551。
```

**补充示例（单位长与无解）**

```text
输入：queries = [9, 10], intLength = 1
输出：[9, -1]
解释：长度为 1 的正回文数只有 1~9 共 9 个（0 不是正数），第 10 个不存在。
```

**补充示例（大长度下的无解常态）**

```text
输入：queries = [90000000, 90000001, 1000000000], intLength = 15
输出：[999999999999999, -1, -1]
解释：15 位回文由前 8 位决定，总共 9×10^7 = 90000000 个；
     排名达到上限时恰好取到 15 个 9，更大的排名一律 -1。
```

## 3. 解题思路

### 3.1 暴力思路

从 $10^{n-1}$（最小的 $n$ 位数）起逐个判定回文、数到第 $q$ 个再回答——约束直接判死刑：

1. $q$ 可达 $10^9$，而 $n = 15$ 时 $n$ 位数的总量是 $10^{14}$ 量级，逐个扫描不可行；
2. 即便「聪明地」只枚举回文（按左半生成），$10^9$ 的排名也要求生成 $10^9$ 个候选，时间与内存都爆炸；
3. $5 \times 10^4$ 个查询互相独立，重复枚举纯属浪费。

> ⚠️ 比赛时的分水岭恰恰在这里：意识到「第 $q$ 小」是**排名定位**问题而非**枚举筛选**问题，就能把 $O(10^{14})$ 的搜索压成 $O(1)$ 的构造。回文数有结构，按结构直接编号，无需逐个生成。

### 3.2 核心观察：左半决定一切，左半 ⇄ 回文是双射

![核心观察：左半与回文一一对应，镜像补出右半](images/2217_kth_palindrome_mirror_concept.svg)

设回文长度为 $n$，**左半长度**（奇数时含正中间那位）为：

$$h = \left\lceil \frac{n}{2} \right\rceil$$

- **偶数长度**（$n = 4, h = 2$）：回文 = 左半 + 左半整体翻转。左半 `12` → `12|21` = `1221`，镜像长度 $n - h = h = 2$；
- **奇数长度**（$n = 3, h = 2$）：中间位左右共用。左半 `12` → `1(2)1` = `121`，镜像只翻左半**去掉末位**后的部分，镜像长度 $n - h = h - 1 = 1$。

统一写法：回文串 = `s + reverse(s[:n-h])`，其中 `s` 是左半的十进制字符串——偶、奇两种情形一行兼容，**中点绝不重复拼接**。

**左半就是普通的 $h$ 位整数**（首位非零自动排除前导零）：

$$\text{左半} \in \left[10^{h-1},\ 10^{h} - 1\right], \qquad \text{总数} = 9 \times 10^{h-1}$$

而「左半 → 回文」这个映射是**双射且严格保序**（§5 引理 1、2）：左半越小，回文越小。于是两个世界里的「第 $q$ 小」是同一件事：

$$\text{第 } q \text{ 小的回文} = \text{镜像}\big(\underbrace{10^{h-1} + (q-1)}_{\text{第 } q \text{ 小的 } h \text{ 位整数}}\big)$$

$q > 9 \times 10^{h-1}$ 时排名第 $q$ 的左半不存在，回文也不存在，返回 `-1`。

### 3.3 算法流程

![算法流程：预处理一次，逐查询 O(1) 构造](images/2217_kth_palindrome_flow.svg)

1. 预处理（与查询值无关，只做一次）：$h = \lceil n/2 \rceil$，$\text{start} = 10^{h-1}$，$\text{total} = 9 \times 10^{h-1}$；
2. 对每个查询 $q$：
   - 若 $q > \text{total}$：`answer[i] = -1`；
   - 否则 $\text{half} = \text{start} + (q - 1)$（1-indexed 偏移），把 `half` 转成字符串 `s`，拼接 `s + reverse(s[:n-h])` 再转回 64 位整数；
3. 返回 `answer`。

### 3.4 示例演算

![示例演算：n=3 与 n=4 的排名定位](images/2217_kth_palindrome_walkthrough.svg)

以官方示例 1（$n = 3$）走查：$h = 2$，$\text{start} = 10$，$\text{total} = 90$，镜像长度 $n - h = 1$。

| $q$ | $\text{half}=10+(q-1)$ | 左半串 `s` | 镜像 `s[:1]` 翻转 | 回文 |
|----|----|----|----|----|
| 1 | 10 | `"10"` | `"1"` | `101` |
| 2 | 11 | `"11"` | `"1"` | `111` |
| 5 | 14 | `"14"` | `"1"` | `141` |
| 90 | 99 | `"99"` | `"9"` | `999` |
| 91 | — | $91 > 90 = \text{total}$，越界 | — | `-1` |

再验官方示例 2（$n = 4$）：$h = 2$，镜像长度 $n - h = 2$（整体翻转）：$q = 2 \to 11 \to$ `"11"`+`"11"` $= 1111$；$q = 4 \to 13 \to$ `"13"`+`"31"` $= 1331$；$q = 6 \to 15 \to$ `"15"`+`"51"` $= 1551$ ✓。

## 4. 算法细节

1. **为什么不用排序/二分**：左半集合 $[10^{h-1}, 10^h - 1]$ 本身就是一段连续整数，「第 $q$ 小」是纯算术：$\text{start} + (q - 1)$。排名 → 左半是连续区间上的**直接寻址**，$O(1)$。
2. **镜像长度的统一**：镜像取左半串的前 $n - h$ 位翻转。偶数 $n$：$n - h = h$（整体翻转）；奇数 $n$：$n - h = h - 1$（跳过中点，中点由左半末位兼任，不重复拼接）。这是奇数长度最经典的 WA 来源。
3. **无解判定与查询无关**：$\text{total} = 9 \times 10^{h-1}$ 只依赖 $n$，预处理一次循环外提。注意无解条件是 $q > 9 \times 10^{h-1}$，**不是** $q > 10^n$——长度为 $n$ 的回文数远少于 $n$ 位数。
4. **字符串版 vs 数值版**：字符串版 `s + s[:n-h][::-1]` 语义最直白，比赛首选；数值版 `half * 10^(n-h) + 翻转(half 的高 n-h 位)` 省掉字符串开销，但奇数长度要先丢掉 `half` 的末位（中点）再翻转，见 §7 对照实现。
5. **返回类型**：题目签名为 `vector<long long>`（Python 天然大整数无感）。$n = 15$ 的最大回文 $\approx 10^{15}$ 超 `int` 范围；C++ 里 `start`、`total`、`half`、`stoll` 全链路用 `long long`。
6. **查询彼此独立**：$5 \times 10^4$ 个查询共享同一组 $(h, \text{start}, \text{total})$，无状态、无顺序依赖，天然可并行。

## 5. 正确性证明

记 $P_n$ 为所有长度为 $n$、无前导零的正回文数（按数值升序）构成的序列，$h = \lceil n/2 \rceil$，$D_h = [10^{h-1}, 10^h - 1]$ 为所有 $h$ 位正整数。定义 $\varphi: D_h \to P_n$：把 $x$ 的十进制串 `s` 映射为串 `s + reverse(s[:n-h])` 对应的整数。

**引理 1（双射性）**：$\varphi$ 是 $D_h$ 到 $P_n$ 的双射。

**证明**：先证 $\varphi(x) \in P_n$。记 $t = \varphi(x)$ 的数字串为 $t_0 t_1 \cdots t_{n-1}$（长度 $h + (n-h) = n$）。按构造：$i < h$ 时 $t_i = s_i$；$i \ge h$ 时记 $j = n - 1 - i$，由 $i \ge h$ 得 $0 \le j \le n - h - 1 < n - h$，故 $t_i = s_j$；而 $j < h$ 又给出 $t_j = s_j$。于是对一切 $i \ge h$ 有 $t_i = t_{n-1-i}$（$i < h$ 时对称式自动成立），$t$ 是回文。又 $t_0 = s_0 \ne 0$（$x \ge 10^{h-1}$ 保证首位非零），故 $t \in P_n$。

再证单射：若 $x \ne x'$，设 $s, s'$ 首个不同的位置为 $i_0$（$i_0 < h$），则 $\varphi(x)$ 与 $\varphi(x')$ 在位置 $i_0$ 处的字符分别是 $s_{i_0}, s'_{i_0}$，仍不同，故 $\varphi(x) \ne \varphi(x')$。

最后证满射：任取 $p = p_0 p_1 \cdots p_{n-1} \in P_n$，回文性给出 $p_i = p_{n-1-i}$。取 $x = p_0 p_1 \cdots p_{h-1}$ 拼成的整数：$p_0 \ne 0$ 保证 $x \ge 10^{h-1}$，即 $x \in D_h$。对 $i \ge h$，$\varphi(x)$ 的第 $i$ 位为 $s_{n-1-i} = p_{n-1-i} = p_i$；对 $i < h$ 两者显然相同。故 $\varphi(x) = p$。∎

**引理 2（保序性）**：对 $x < x' \in D_h$，有 $\varphi(x) < \varphi(x')$。

**证明**：等长、无前导零的两个正整数，数值比较等价于数字串的字典序比较。$s, s'$ 是 $x, x'$ 的 $h$ 位串（都恰 $h$ 位、首位非零），故 $x < x'$ 即 $s < s'$ 字典序；设首个不同位置为 $i_0$，则 $s_{i_0} < s'_{i_0}$ 且 $i_0 < h$ 落在「左半」区间。$\varphi(x), \varphi(x')$ 都是 $n$ 位无前导零串，在 $i_0$ 之前逐位相同（都复制 $s / s'$ 的前 $i_0$ 位），在 $i_0$ 处分别为 $s_{i_0} < s'_{i_0}$，于是 $\varphi(x)$ 字典序更小，数值更小。∎

**推论（排名等价）**：$P_n$ 升序排列的第 $q$ 个元素恰为 $\varphi\big(D_h \text{ 升序的第 } q \text{ 个}\big)$，且 $|P_n| = |D_h| = 9 \times 10^{h-1}$。

**证明**：引理 1 说 $\varphi$ 是 $D_h \to P_n$ 的满射（大小相等）且单射，故为双射；引理 2 说 $\varphi$ 严格递增，于是它把 $D_h$ 的升序序列逐项映射为 $P_n$ 的升序序列——两个序列一一对应、排名对齐。∎

**定理（算法正确性）**：对 $1 \le q \le 9 \times 10^{h-1}$，第 $q$ 小的长度为 $n$ 的正回文数为 $\varphi(10^{h-1} + q - 1)$；对 $q > 9 \times 10^{h-1}$，这样的回文数不存在，应返回 `-1`。

**证明**：$D_h$ 是连续整数区间，其升序第 $q$ 个元素为 $10^{h-1} + (q-1)$。当 $1 \le q \le 9 \times 10^{h-1}$ 时该值落在 $D_h$ 内，由推论即得。当 $q > 9 \times 10^{h-1}$ 时，$|P_n| = 9 \times 10^{h-1} < q$，排名第 $q$ 的元素不存在；算法的无解判定与镜像构造恰好分别覆盖这两种情形。∎

> 💡 证明的骨架是标准的「**结构化编号**」论证：双射（引理 1）保证不重不漏，保序（引理 2）保证两个世界里的「第 $q$ 小」是同一件事。这两点一旦成立，剩下的只是对连续整数区间做一次偏移——「枚举」就退化成了「寻址」。

## 6. 复杂度分析

- **时间复杂度**：$O(m \cdot n)$，其中 $m = \text{len(queries)}$。预处理 $O(n)$（求 $10^{h-1}$ 逐位乘 $h-1 \le 7$ 次）；每个查询做一次算术定位 + 一次长度 $O(n)$ 的字符串镜像与整数转换。$n \le 15$ 是常数，整体即 $O(m)$，$m \le 5 \times 10^4$ 轻松通过。
- **空间复杂度**：$O(1)$ 额外空间（不计输出数组 $O(m)$）；构造用的临时字符串长度 $\le 15$，视为常数。

## 7. 参考代码

### C++（字符串镜像版）

```cpp
class Solution {
public:
    vector<long long> kthPalindrome(vector<int>& queries, int intLength) {
        int h = (intLength + 1) / 2;
        long long start = 1;
        for (int i = 1; i < h; ++i) start *= 10;      // 10^(h-1)
        long long total = 9 * start;                   // n 位回文的总数

        vector<long long> ans;
        ans.reserve(queries.size());
        for (int q : queries) {
            if (q > total) {                           // 排名越界：无解
                ans.push_back(-1);
                continue;
            }
            long long half = start + (q - 1);          // 第 q 小的左半（1-indexed）
            string s = to_string(half);
            string t = s.substr(0, intLength - h);     // 镜像长度 n-h：偶=整体，奇=去中点
            reverse(t.begin(), t.end());
            ans.push_back(stoll(s + t));               // 15 位回文必须 long long
        }
        return ans;
    }
};
```

### Python（字符串镜像版）

```python
class Solution:
    def kthPalindrome(self, queries: List[int], intLength: int) -> List[int]:
        h = (intLength + 1) // 2
        start = 10 ** (h - 1)
        total = 9 * start                      # 无解判定只依赖 intLength

        ans = []
        for q in queries:
            if q > total:
                ans.append(-1)
                continue
            s = str(start + (q - 1))           # 第 q 小的左半
            ans.append(int(s + s[:intLength - h][::-1]))
        return ans
```

### Python（数值版，无字符串）

```python
class Solution:
    def kthPalindrome(self, queries: List[int], intLength: int) -> List[int]:
        h = (intLength + 1) // 2
        start = 10 ** (h - 1)
        total = 9 * start
        mirror_len = intLength - h             # 偶 n: = h；奇 n: = h-1

        ans = []
        for q in queries:
            if q > total:
                ans.append(-1)
                continue
            half = start + (q - 1)
            x = half // 10 if intLength % 2 else half   # 奇数长度先丢中点
            tail = 0
            for _ in range(mirror_len):                 # 从低位到高位翻转 n-h 位
                tail = tail * 10 + x % 10
                x //= 10
            ans.append(half * 10 ** mirror_len + tail)
        return ans
```

> 💡 数值版的关键一步：奇数长度时 `half` 的**末位是中点**，先 `half // 10` 丢掉，再从低位到高位把 $n - h$ 位「翻」进 `tail`。字符串版 `s[:n-h][::-1]` 天然正确，比赛时优先用它。

## 8. 边界情况与易错点

1. **32 位溢出（C++ 头号坑）**：`intLength = 15` 的回文达 $999{,}999{,}999{,}999{,}999 \approx 10^{15}$，远超 `int`；必须全程 `long long`，转整数用 `stoll`（写 `stoi` 直接运行时错误）。`start + (q - 1)` 也要在 `long long` 上运算（`start` 为 `long long` 时表达式自动提升，安全）。
2. **奇数长度把中点也镜像**：$n = 3$、`half = 12` 时若翻转整个左半得 `"12"+"21" = 1221`——长度直接错成 4 位。统一记法：**镜像长度 $= n - h$**，中点（左半末位）只出现一次。
3. **无解条件写错**：正确条件是 $q > 9 \times 10^{h-1}$，不是 $q > 10^n$。`intLength = 15` 时 $10^{15}$ 个 15 位数里只有 $9 \times 10^7$ 个回文；`queries[i]` 上限 $10^9$ 意味着大长度下 `-1` 是常态输出，漏判会大量 WA。
4. **1-indexed 偏移**：`half = start + (q - 1)`。写成 `start + q` 整体右移一位（`q = 1` 答出 `111` 而非 `101`），且越界判定恰好拦不住这类错位，错得更隐蔽。
5. **`intLength = 1`**：$h = 1$，`start = 1`，`total = 9`，镜像长度 $0$（空串），答案就是 $q$ 本身（$1 \sim 9$）；注意 **0 不在集合内**（正回文数），`q = 10` 即无解。
6. **别排序、别预生成全量回文**：排名 → 左半是连续区间上的直接寻址，排序毫无必要；预生成回文表在 $10^9$ 排名下内存爆炸。两个「多余动作」都源于没看穿双射。
7. **`substr` 边界**：`s.substr(0, intLength - h)` 在 $n = 1$ 时取 0 位得空串，拼接退化为 `s` 本身——无需特判，但写数值版时对应的「丢中点再翻 0 位」循环一次也不执行，两边语义要对照清楚。

**延伸思考**：若把「第 $q$ 小」改成「$\le x$ 的 $n$ 位回文数有多少个」（计数方向），等价于对左半做一次区间计数，仍是 $O(1)$。若长度不固定（求全体正回文数中第 $k$ 小），需按长度 $n = 1, 2, 3, \dots$ 逐层累加 $9 \times 10^{\lceil n/2 \rceil - 1}$ 定位层数与层内排名——正是 400 题的分层手法与本题的层内定位的合体。再进一步，若回文条件松弛为「至多一位不同」之类，双射即失效，需回到数位 DP 计数——体会「双射」在这套论证中承担的角色。
