# LeetCode 找出两数组的不同 题解

## 1. 题目概述

- **标题 / 题号**：找出两数组的不同（#2215，easy）
- **链接**：https://leetcode.cn/problems/find-the-difference-of-two-arrays/
- **来源**：LeetCode 第 286 场周赛 Q1
- **难度**：简单
- **标签**：数组、哈希表

**题意**：给定两个下标从 0 开始的整数数组 `nums1` 与 `nums2`，返回长度为 2 的列表 `answer`：`answer[0]` 是 `nums1` 中所有**不出现**于 `nums2` 的**不同**整数；`answer[1]` 是 `nums2` 中所有**不出现**于 `nums1` 的**不同**整数。答案内元素顺序任意。

**约束**：

- $1 \le \text{nums1.length},\ \text{nums2.length} \le 1000$
- $-1000 \le \text{nums1}[i],\ \text{nums2}[i] \le 1000$ —— 值域宽度仅 $2001$，是「小值域可直接寻址」的隐藏信号（见 §4）

> 💡 作为签到题，本题的最短路径是：两个 `set()`，两次集合差 $S_1 \setminus S_2$ 与 $S_2 \setminus S_1$，Python 三行拿走。坑点全在细节：**去重**（「不同整数」）、**方向**（谁减谁别搞反）、**空列表合法**。

## 2. 示例

**示例 1**

```text
输入：nums1 = [1,2,3], nums2 = [2,4,6]
输出：[[1,3],[4,6]]
解释：2 是公共元素，两边都不要；1、3 只在 nums1 中，4、6 只在 nums2 中。
```

**示例 2（官方设的「去重」坑）**

```text
输入：nums1 = [1,2,3,3], nums2 = [1,1,2,2]
输出：[[3],[]]
解释：nums1 有两个 3，但「不同整数」只保留一个；nums2 的每个值都在 nums1 中出现过，
     answer[1] 是空列表——这是完全合法的输出，不要特判。
```

**补充示例（不相交 + 负数）**

```text
输入：nums1 = [-1000, 0, 7], nums2 = [7, 9]
输出：[[-1000,0],[9]]
解释：两集合仅交于 {7}；负数与 0 哈希一视同仁，若用桶需 +1000 偏移。
```

## 3. 解题思路

### 3.1 暴力思路

对 `nums1` 的每个元素 `x` 线性扫描 `nums2` 判存在性，不存在则收入 `answer[0]`——但还得再建一个 `seen` 集合判重，否则示例 2 的两个 3 会入答案两次；`answer[1]` 对称处理。总时间 $O(n \cdot m) \approx 10^6$，在 $n, m \le 1000$ 下能过，却有两处浪费：对**列表**重复做线性查找、手动维护去重表。签到题可以这么做，但没有理由不一步到位。

### 3.2 核心观察：答案就是两个集合差

![核心观察：集合差 S1−S2 与 S2−S1 的韦恩图](images/2215_find_diff_venn_concept.svg)

把两个数组各自 `set()` 集合化，**三件事一次解决**：

1. **去重**：集合天然不存重复元素，`set([1,2,3,3])` 直接得到 `{1,2,3}`——「不同整数」的要求被无感满足；
2. **$O(1)$ 存在性判定**：`x in set` 平均 $O(1)$，取代对列表的 $O(m)$ 扫描；
3. **库直接支持差运算**：`set1 - set2` 语义恰是「在 `set1` 中但不在 `set2` 中」，与 `answer[0]` 的定义逐字吻合。

于是答案是双向集合差：$answer[0] = S_1 \setminus S_2$，$answer[1] = S_2 \setminus S_1$。

### 3.3 算法流程

![算法流程：集合化后双向过滤](images/2215_find_diff_flow.svg)

1. `S1 = set(nums1)`，$O(n)$；`S2 = set(nums2)`，$O(m)$；
2. **第一趟**：遍历 `x ∈ S1`，若 `x ∉ S2` 则收入 `answer[0]`；
3. **第二趟**：遍历 `x ∈ S2`，若 `x ∉ S1` 则收入 `answer[1]`；
4. 返回 `[answer[0], answer[1]]`。两个集合**互为对方的过滤表**，无需再建其他结构。

### 3.4 示例演算

![示例演算：建集合去重 + 双向扫描表](images/2215_find_diff_walkthrough.svg)

以示例 2 演算：`S1 = {1,2,3}`（两个 3 合并）、`S2 = {1,2}`（1、2 各合并）。

| 运算 | 逐元素判定 | 结果 |
|------|------|------|
| `S1 − S2` | 1 在、2 在、3 不在 | `{3}` → `answer[0] = [3]` |
| `S2 − S1` | 1 在、2 在（全部跳过） | `{}` → `answer[1] = []` |

返回 `[[3], []]` ✓。

## 4. 算法细节

1. **建集合即去重**：不需要任何显式 `seen` 结构；遍历集合本身保证输出无重复。
2. **双向过滤的写法**：C++ 的 `unordered_set` 没有差运算符，遍历 `s1` 用 `s2.count(x)` 判定即可，效果与 `set1 - set2` 完全一致。
3. **别用 `std::set_difference`**：它要求输入是**有序范围**，配 `unordered_set` 属于接口误用；改用有序 `std::set` 则插入退化为 $O(\log n)$，得不偿失。
4. **值域信号（竞赛更稳的替代）**：$V = 2001$ 极小，可开两个 `bool in1[2001]`、`in2[2001]`，下标 `x + 1000` 直接寻址（**负数必须偏移**）。建表 $O(n + m)$，扫描 $O(V)$，无哈希最坏退化、常数更小。值域任意大时退回哈希集合。
5. **顺序无需处理**：题目允许任意顺序，集合迭代顺序即可；不要画蛇添足地 `sort()`。

## 5. 正确性证明

**引理 1（集合化等价）**：记 $S_1 = \text{set}(\text{nums1})$，则 $x \in S_1$ 当且仅当 $x$ 在 `nums1` 中至少出现一次；且 $S_1$ 中元素互异。

**证明**：`set` 的插入语义为「已存在则不插入、不存在则插入」，故逐元素插入后，$x \in S_1$ iff 插入过程中某次成功或已被存在判定命中，iff $x$ 出现于 `nums1`。互异性由集合定义直接给出。∎

**引理 2（差集刻画）**：`answer[0]` 的元素全体恰为 $S_1 \setminus S_2$；`answer[1]` 的元素全体恰为 $S_2 \setminus S_1$。

**证明**：双向包含。若 $x \in S_1 \setminus S_2$，由引理 1，$x$ 出现于 `nums1` 且不出现于 `nums2`，按题意 $x$ 应在 `answer[0]` 中。反之，若 $x$ 满足题意（出现于 `nums1`、不出现于 `nums2`），由引理 1 得 $x \in S_1$ 且 $x \notin S_2$，即 $x \in S_1 \setminus S_2$。`answer[1]` 同理对称。∎

**定理**：算法的输出满足题意——两个列表的元素集合正确、各自无重复、且当一侧无独有元素时输出空列表。

**证明**：算法遍历 $S_1$ 收集 $S_2$ 中不存在的元素，由引理 2 该收集结果恰为 `answer[0]` 的元素全体；`answer[1]` 同理。由引理 1 的互异性，遍历集合不会重复产出同一元素，满足「不同整数」。当 $S_1 \subseteq S_2$ 时第一趟无收入，输出空列表，与示例 2 的官方判定一致。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n + m)$。建两个集合 $O(n) + O(m)$；两趟过滤遍历 $|S_1| + |S_2| \le n + m$ 个元素，每次存在性判定平均 $O(1)$。桶版为 $O(n + m + 2001)$，严格线性且无哈希退化。
- **空间复杂度**：$O(n + m)$ 记号下两个哈希集合；由于 $|S_1|, |S_2| \le 2001$，实际占用以值域为上界。桶版为 $O(2001)$。

## 7. 参考代码

### C++（unordered_set 双向过滤）

```cpp
class Solution {
public:
    vector<vector<int>> findDifference(vector<int>& nums1, vector<int>& nums2) {
        unordered_set<int> s1(nums1.begin(), nums1.end());
        unordered_set<int> s2(nums2.begin(), nums2.end());

        vector<int> ans0, ans1;
        for (int x : s1)
            if (!s2.count(x)) ans0.push_back(x);
        for (int x : s2)
            if (!s1.count(x)) ans1.push_back(x);
        return {ans0, ans1};
    }
};
```

### Python（集合差运算符，三行签到）

```python
class Solution:
    def findDifference(self, nums1: List[int], nums2: List[int]) -> List[List[int]]:
        s1, s2 = set(nums1), set(nums2)
        return [list(s1 - s2), list(s2 - s1)]
```

### C++（值域桶，直接寻址变体）

```cpp
class Solution {
public:
    vector<vector<int>> findDifference(vector<int>& nums1, vector<int>& nums2) {
        array<bool, 2001> in1{}, in2{};
        for (int x : nums1) in1[x + 1000] = true;   // 负数 +1000 偏移
        for (int x : nums2) in2[x + 1000] = true;

        vector<vector<int>> ans(2);
        for (int v = 0; v <= 2000; ++v) {
            if (in1[v] && !in2[v]) ans[0].push_back(v - 1000);
            if (in2[v] && !in1[v]) ans[1].push_back(v - 1000);
        }
        return ans;
    }
};
```

> 💡 桶版顺带输出了**升序**结果（虽非必需），且无 `unordered_set` 的迭代顺序不确定性——在需要确定性输出的场合更稳。

## 8. 边界情况与易错点

1. **忘去重（本题最经典的 WA）**：`nums1 = [1,2,3,3]` 若逐元素收集且不判重，`answer[0]` 会输出两个 3。官方示例 2 专为验证这一点；集合化天然免疫。
2. **方向搞反**：`answer[0]` 是「`nums1` 有、`nums2` 没有」；写成交集 $S_1 \cap S_2$ 或把两个差集顺序对调都会 WA。
3. **空列表合法**：一侧是另一侧的子集时对应答案为 `[]`，不要特判或自作主张塞哨兵值。
4. **负数与 0**：哈希一视同仁；**桶版必须 `x + 1000` 偏移**，否则负下标直接 RE。
5. **顺序任意**：`unordered_set` 遍历顺序不稳定也合法；不要浪费比赛时间排序。
6. **别误用 `std::set_difference`**：它要求有序范围，与 `unordered_set` 组合是接口错误（编译期或逻辑期才会暴露）。
7. **无空输入**：两数组长度 $\ge 1$，无需空数组特判。
