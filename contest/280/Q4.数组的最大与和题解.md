# LeetCode 数组的最大与和 题解

## 1. 题目概述

- **标题 / 题号**：数组的最大与和（#2172，hard）
- **链接**：https://leetcode.cn/problems/maximum-and-sum-of-array/
- **来源**：LeetCode 第 280 场周赛 Q4
- **难度**：困难
- **标签**：位运算、动态规划、状态压缩、三进制

**题意**：给定长度为 $n$ 的整数数组 `nums` 和整数 `numSlots`（满足 $2 \cdot \text{numSlots} \ge n$）。有 `numSlots` 个篮子编号 $1$ 到 $\text{numSlots}$，把所有 $n$ 个数分到篮子中，**每个篮子至多放 2 个数**。一种分配方案的**与和**为每个数与它所在篮子编号的**按位与**之和：

$$\text{与和} = \sum_{\text{每个数 } x} \bigl(x \mathbin{\&} \text{所在篮子编号}\bigr)$$

返回所有合法分配方案中的**最大与和**。

**约束**：

- $1 \le \text{numSlots} \le 9$
- $1 \le n \le 2 \cdot \text{numSlots} \le 18$
- $1 \le \text{nums}[i] \le 15$

> 💡 **一句话定位**：数据范围嗅觉——`numSlots ≤ 9` 且每篮容量恰好为 2，意味着**全部篮子的占用情况**可以用一个很小的整数完整编码（每位取 $0/1/2$，共 $3^9 = 19683$ 个状态）。「少量容器 + 小容量 + 逐个分配」正是**分配型状压 DP** 的甜区。

> 💡 本题在本仓库另有[每日题解 2172](../../solution/2101-2200/2172_数组的最大与和.md)：主线同为「三进制状压 DP」。本篇按**周赛复盘视角**展开：给出引理-定理化的完整正确性链（顺序规范化 → 计数一致性 → 充分统计量 → 转移完备性）、以官方示例 1 的最优路径演算与示例 2 的「篮子富余」形态、贪心反例与哨兵初始化等赛场易错清单，以及容量推广与费用流建模两个变体，两篇互为印证。

## 2. 示例

**示例 1**

```text
输入：nums = [1,2,3,4,5,6], numSlots = 3
输出：9
解释：[1,4] 放入篮子 1，[2,6] 放入篮子 2，[3,5] 放入篮子 3。
  与和 = (1&1)+(4&1)+(2&2)+(6&2)+(3&3)+(5&3)
       =  1  +  0  +  2  +  2  +  3  +  1  = 9。
```

**示例 2**

```text
输入：nums = [1,3,10,4,7,1], numSlots = 9
输出：24
解释：[1,1] 放入篮子 1，[3]→篮 3，[4]→篮 4，[7]→篮 7，[10]→篮 9。
  与和 = 1+1+3+4+7+8 = 24。篮子 2、5、6、8 空着——n = 6 < 2×9，允许空篮。
```

```text
输出：4
解释：两个数都放进篮子 2：(6&2)+(7&2) = 2+2 = 4，
  优于分开放 (6&2)+(7&1) = 2+1 = 3——篮子容量 2 允许「挤」，别默认一对一。
```

## 3. 解题思路

### 3.1 暴力思路（以及贪心为什么不行）

最朴素的做法是 DFS 回溯：依次为每个数枚举一个「当前少于 2 个数」的篮子，枚举所有合法分配取最大。$n \le 18$、每数至多 $18$ 种选择，方案数是天文数字（即使按多重组合计也远超 $10^{10}$）。

> 💡 暴力法的浪费在于：**同一个「篮子占用情况」会被大量不同顺序、不同身份的放置路径重复到达**，却各自独立计算。把「占用情况」抽象成状态、合并重复子问题，正是状压 DP 的切入点。

另一个诱人的捷径是**贪心**：把数从大到小排，每个数挑当前「收益 $x \mathbin{\&} b$ 最大」的空位篮子。反例（对拍验证）：

```text
nums = [3,3,2], numSlots = 2
贪心：3→篮 2（得 2），3→篮 2（得 2），2 只能→篮 1（得 0），共 4；
最优：3→篮 1（得 1），3→篮 2（得 2），2→篮 2（得 2），共 5。
```

两个 $3$ 挤占篮 2 后，$2$ 的最佳搭档篮被占走——**「当前收益最大」不考虑容量挤兑的后续代价**，贪心失效，必须完整搜索（DP）。

### 3.2 核心观察：占用情况天然是一位三进制

![核心观察：每篮至多 2 个数 → 占用情况天然是一位三进制](images/wc280_q4_concept.svg)

**观察一（数据范围的信号）**：$\text{numSlots} \le 9$ 且每篮容量恰为 2，则每个篮子的占用数 $d_i \in \{0,1,2\}$，全体占用情况只有 $3^{9} = 19683$ 种——DP 可承受的状态空间。

**观察二（两种编码，三进制最经济）**：

| 编码方式 | 状态含义 | 状态数（$S=9$） | cnt 的算法 |
|----------|----------|-----------------|-----------|
| **三进制** | 一位 = 一个篮子的占用数（$0/1/2$），$s = \sum_i d_i \cdot 3^{i}$ | $3^{9} = 19\,683$ | 三进制数位和 |
| 二进制拆槽 | 每篮拆成 2 个槽，每槽 $0/1$，共 $2S$ 个二进制位 | $2^{18} = 262\,144$ | `popcount` |

三进制把状态压到拆槽版的 $1/13$，是本题的**最优编码**；二进制拆槽则是通用模板（可无脑迁移到 1655、1799 等题），赛场上两者皆可，下文以三进制为主线。

**观察三（状态是充分统计量）**：状态 $s$ 只记「每篮放了几个数」，**不记哪个数在哪个篮**，为什么够用？规定**按下标顺序逐个放置**（由引理 1 保证不失一般性），则到达 $s$ 的所有方案都已放完**同一批数**——前 $\text{cnt}(s)$ 个（$\text{cnt}(s) = s$ 的三进制数位和）。它们只在配对方式上不同，与和不同，只需保留最大值 $\text{dp}[s]$；而未来只依赖「还剩哪些空位（由 $s$ 决定）」与「接下来放哪些数（由 $\text{cnt}(s)$ 唯一确定）」——马尔可夫性成立。

### 3.3 算法流程：转移与拓扑序

![算法流程：预处理 → 升序枚举 → 数位和定待放数 → 松弛后继 → 终态取 max](images/wc280_q4_dp_flow.svg)

定义 $\text{dp}[s]$ = 以占用 $s$ 结束、已按序放完前 $\text{cnt}(s)$ 个数时的**最大与和**，$\text{dp}[0] = 0$，其余初始化为 $-1$（不可达哨兵）。设当前状态 $s$ 的 $\text{cnt}(s) < n$，下一个待放数 $x = \text{nums}[\text{cnt}(s)]$，枚举每个篮子 $i+1$（$i = 0 \dots S-1$）：

- 若 $d_i(s) = (s / 3^{i}) \bmod 3 < 2$（还有空位），把 $x$ 放入篮子 $i+1$：

$$\text{dp}\bigl[s + 3^{i}\bigr] = \max\Bigl(\text{dp}\bigl[s + 3^{i}\bigr],\ \text{dp}[s] + \bigl(x \mathbin{\&} (i+1)\bigr)\Bigr)$$

**拓扑序免费赠送**：$s' = s + 3^{i} > s$，按 $s$ **升序**单循环枚举，计算 $\text{dp}[s']$ 时其所有前驱都已就绪，无需记忆化或显式拓扑排序。

**终态**：所有数放完即 $\text{cnt}(s) = n$ 的状态（注意**不是**篮子全满），答案 $= \max_{\text{cnt}(s)=n} \text{dp}[s]$。

二进制拆槽版同理：$\text{dp}[\text{mask} \mid (1 \ll j)] = \max(\ldots,\ \text{dp}[\text{mask}] + (\text{nums}[\text{popcount}(\text{mask})] \mathbin{\&} (j/2+1)))$，枚举空槽 $j$。

### 3.4 示例演算

![示例演算：[1,2,3,4,5,6] 沿最优路径的状态演化](images/wc280_q4_example_walkthrough.svg)

以示例 1（`nums = [1,2,3,4,5,6]`，`numSlots = 3`）沿一条最优放置路径走一遍，$s = d_1 \cdot 3^{0} + d_2 \cdot 3^{1} + d_3 \cdot 3^{2}$：

| 步 | 放入 $x$ | 选篮 | 占用 $(d_1,d_2,d_3)$ | 状态 $s$ | 收益 $x\&i$ | 累计 $\text{dp}$ |
|----|---------|------|----------------------|---------|------------|------------------|
| 1 | 1 | 篮 1 | $(0,0,0) \to (1,0,0)$ | $0 \to 1$ | $1\&1=1$ | 1 |
| 2 | 2 | 篮 2 | $(1,0,0) \to (1,1,0)$ | $1 \to 4$ | $2\&2=2$ | 3 |
| 3 | 3 | 篮 3 | $(1,1,0) \to (1,1,1)$ | $4 \to 13$ | $3\&3=3$ | 6 |
| 4 | 4 | 篮 1 | $(1,1,1) \to (2,1,1)$ | $13 \to 14$ | $4\&1=0$ | 6 |
| 5 | 5 | 篮 3 | $(2,1,1) \to (2,1,2)$ | $14 \to 23$ | $5\&3=1$ | 7 |
| 6 | 6 | 篮 2 | $(2,1,2) \to (2,2,2)$ | $23 \to 26$ | $6\&2=2$ | **9** ✓ |

终态 $s = 26 = (2,2,2)_3$（三个篮子全满），$\text{dp}[26] = 9$。DP 在枚举所有状态时会比较到达同一占用的全部路径，确认 $9$ 就是最大与和。

> 💡 第 4 步把 $4$ 放进篮子 1 收益为 $4\&1=0$（$4 = 100_2$，编号 $1/2/3$ 即 $01/10/11_2$，按位与全零）——放哪个篮都一样，但**篮子容量必须被消耗**，这正是自拟示例 3「两个数挤一个篮」的镜像情形。对照示例 2：$n = 6 < 2 \times 9$，最优终态占用是 $(2,0,1,1,0,0,1,0,1)$，篮 2/5/6/8 全空——**终态判据是 $\text{cnt}(s) = n$，不是篮子全满**。

## 4. 算法细节

1. **状态编码**：$s = \sum_{i=0}^{S-1} d_i \cdot 3^{i}$（篮 $i+1$ 对应第 $i$ 位），预处理 $\text{pow3}[i] = 3^{i}$；总状态数 $\text{total} = 3^{S} \le 19683$。
2. **cnt 现算**：每个状态用 `while (t) { cnt += t % 3; t /= 3; }` 求**数位和**，$O(S)$；也可递推预处理 $\text{cnt3}[s] = \text{cnt3}[s/3] + s \bmod 3$ 省常数，总量级下无所谓。
3. **哨兵 $-1$**：与和恒 $\ge 0$，用 $-1$ 区分「不可达」与「真值为 0」；初始仅 $\text{dp}[0]=0$ 可达，其余靠转移点亮。
4. **转移取位**：判断空位用 $(s / \text{pow3}[i]) \% 3 < 2$——三进制**没有**位运算捷径，别顺手写移位或 `& 3`；收益是 $\text{nums}[\text{cnt}] \mathbin{\&} (i+1)$，**编号从 1 起**，枚举 $i$ 从 0 起，别忘 `+1`。
5. **二进制拆槽版**：槽 $j \in [0, 2S)$ 对应篮 $j/2+1$，`popcount(mask)` 即已放个数。同一篮的两个槽对同一数贡献相同，状态存在对称冗余但不影响正确性（max 覆盖）；可剪枝成「每篮只枚举第一个空槽」（交换论证：放第二空槽的方案可换到第一空槽，贡献不变），后继减半。
6. **无需排序/去重 nums**：状态只关心「已放个数」，固定按下标顺序放即可，任何预处理都不改变答案。
7. **值域审计**：每个数的贡献 $x \mathbin{\&} b \le b \le \text{numSlots} \le 9$，答案 $\le 18 \times 9 = 162$，`int` 绰绰有余——本题无溢出坑。

## 5. 正确性证明

**引理 1（顺序规范化）**：任意合法分配方案的与和，都能由某个「按下标顺序逐个放置」的过程实现，且与和不变。

**证明**：分配方案本质是一个映射 $f$：下标 $k \mapsto$ 篮子 $f(k)$，合法性即每个篮子的原像数 $\le 2$；与和 $\sum_k (\text{nums}[k] \mathbin{\&} f(k))$ 只依赖映射本身。考虑按下标 $k=0,1,\dots,n-1$ 顺序放置的过程：放完前 $k$ 个数后，任一篮子的占用数不超过其在完整映射下的原像数 $\le 2$，故每步均合法，该过程实现了同一映射，与和不变。∎

**引理 2（计数一致性）**：按下标顺序放置时，到达占用状态 $s$ 的任何方案都恰好放完前 $\text{cnt}(s) = \sum_i d_i(s)$ 个数。

**证明**：每次放置恰使一个数位 $+1$，故 $k$ 步后数位和为 $k$；占用状态 $s$ 唯一决定步数 $\text{cnt}(s)$，而按序放置的第 $k$ 步放的是 $\text{nums}[k-1]$，故到达 $s$ 的方案放过的数恰为前 $\text{cnt}(s)$ 个。∎

**引理 3（充分统计量）**：以占用 $s$ 结束的放置前缀，其后续全部可行转移仅由 $s$ 决定，与到达 $s$ 的路径无关。

**证明**：由引理 2，到达 $s$ 的方案都已放完同一批数（前 $\text{cnt}(s)$ 个），下一个待放数唯一为 $\text{nums}[\text{cnt}(s)]$；下一步（以及递归地，以后每步）可选篮子集合为 $\{i+1 : d_i < 2\}$，仅由当前占用决定。故求最大与和时，到达 $s$ 的众多方案只需保留最大值 $\text{dp}[s]$。∎

**引理 4（转移完备性）**：「前 $k+1$ 个数的合法放置前缀」集合 = 「以某占用 $s$ 结束的前 $k$ 个数的合法前缀」$+$ 一步合法放置 $\text{nums}[k]$。

**证明**：反向（$\Leftarrow$）显然：占用只增一位且目标篮有空位，拼接后仍合法。正向（$\Rightarrow$）：取任一前 $k+1$ 个数的前缀，其第 $k+1$ 步把 $\text{nums}[k]$ 放入某篮 $i+1$；删去这最后一步即得前 $k$ 个数的合法前缀（占用每维只减不增），且原占用下 $d_i \ge 1$，删除后 $d_i - 1 \le 1 < 2$，说明该步对此外前缀合法。∎

**定理**：以 $\text{dp}[0]=0$ 为初值、按升序枚举 $s$ 执行上述转移，则 $\displaystyle\max_{\text{cnt}(s)=n} \text{dp}[s]$ 等于最大与和。

**证明**：先证不变式：对每个可达状态 $s$，$\text{dp}[s]$ = 以占用 $s$ 结束、放完前 $\text{cnt}(s)$ 个数的放置前缀的最大与和。对 $s$ 沿升序归纳：$s=0$ 时空前缀和为 $0$ 成立。设对一切 $s' < s$ 成立。以 $s$ 结束的前 $\text{cnt}(s)$ 个数的前缀集合，由引理 4 等于 $\bigcup_{i:\,d_i(s)\ge 1}\{$以 $s - 3^{i}$ 结束的前缀再放 $\text{nums}[\text{cnt}(s)-1]$ 入篮 $i+1\}$；其中每个 $s - 3^{i} < s$，其 $\text{dp}$ 已由归纳假设就绪，且该并集上的最大值恰为 $\max_i\bigl(\text{dp}[s-3^{i}] + (\text{nums}[\text{cnt}(s)-1] \mathbin{\&} (i+1))\bigr)$——正是转移方程取的 $\max$，故不变式对 $s$ 成立。再由引理 1，任一分配方案的与和都出现在某个 $\text{cnt}(s)=n$ 的状态上（放 $n$ 步后数位和恰为 $n$）；反之每个 $\text{cnt}(s)=n$ 的 $\text{dp}[s]$ 都对应一个合法完整方案。二者取 $\max$ 相等。∎

> ⚠️ **拓扑序**：转移严格递增（$s' = s + 3^{i} > s$），升序单循环即天然拓扑序——这也是「不可达状态先出现」不可能发生的原因（前驱更小必先被处理）。

## 6. 复杂度分析

- **时间复杂度**：$O(3^{S} \cdot S)$，$S = \text{numSlots}$。枚举 $3^{S} \le 19683$ 个状态，每个状态数位求和 $O(S)$、枚举 $S$ 个篮子松弛，约 $19683 \times 18 \approx 3.5 \times 10^{5}$ 次基本操作。二进制拆槽版为 $O(2^{2S} \cdot 2S) \approx 4.7 \times 10^{6}$，约 13 倍（实测 Python3、$n=18, S=9$ 随机数据：三进制约 35ms，拆槽约 0.64s，均远低于时限）。
- **空间复杂度**：$O(3^{S})$（dp 数组 $\le 19683$ 个 `int`，不足 80KB）；拆槽版 $O(2^{2S}) = 262144$。

## 7. 参考代码

### C++（三进制主解：最优编码）

```cpp
class Solution {
  public:
    int maximumANDSum(vector<int>& nums, int numSlots) {
        int pow3[10];
        pow3[0] = 1;
        for (int i = 1; i <= numSlots; ++i) pow3[i] = pow3[i - 1] * 3;
        int total = pow3[numSlots];          // 3^numSlots 个状态
        vector<int> dp(total, -1);           // -1 = 不可达哨兵
        dp[0] = 0;
        int n = nums.size();
        int ans = 0;

        for (int s = 0; s < total; ++s) {
            if (dp[s] < 0) continue;         // 不可达状态跳过
            int cnt = 0, t = s;              // cnt = 三进制数位和 = 已放个数
            while (t) { cnt += t % 3; t /= 3; }
            if (cnt >= n) {                  // 数已放完 → 终态（篮子可空）
                ans = max(ans, dp[s]);
                continue;
            }
            int x = nums[cnt];               // 下一个待放的数
            for (int i = 0; i < numSlots; ++i) {
                if ((s / pow3[i]) % 3 < 2) { // 篮子 i+1 还有空位
                    int ns = s + pow3[i];
                    int val = dp[s] + (x & (i + 1));
                    if (val > dp[ns]) dp[ns] = val;
                }
            }
        }
        return ans;
    }
};
```

### Python（二进制拆槽版：赛场模板速度）

```python
class Solution:
    def maximumANDSum(self, nums: List[int], numSlots: int) -> int:
        slots = 2 * numSlots
        total = 1 << slots
        dp = [-1] * total                    # -1 = 不可达哨兵
        dp[0] = 0
        n = len(nums)
        ans = 0

        for mask in range(total):
            if dp[mask] < 0:
                continue
            cnt = bin(mask).count("1")       # popcount = 已放个数
            if cnt >= n:                     # 数已放完 → 终态（篮子可空）
                ans = max(ans, dp[mask])
                continue
            x = nums[cnt]
            for j in range(slots):           # 枚举空槽 j（篮 j//2 + 1）
                if not mask & (1 << j):
                    basket = j // 2 + 1
                    nm = mask | (1 << j)
                    val = dp[mask] + (x & basket)
                    if val > dp[nm]:
                        dp[nm] = val
        return ans
```

> 💡 两版都通过了官方示例（9、24）与 3000 组随机数据对拍（`numSlots ∈ [1,5]`、$n \le 2S$、$\text{nums}[i] \in [1,15]$，对照 DFS 暴力零失配）。C++ 版展示三进制最优编码，Python 版展示可直接套用的二进制拆槽模板——赛场上先写熟的那版拿分，复盘时再升级编码。

## 8. 边界情况与易错点

1. **终态判据是 $\text{cnt}(s) = n$，不是「篮子全满」**：示例 2 的 $n = 6 < 2 \times 9$，最优终态有 4 个空篮；若把答案写成 $\text{dp}[全满状态]$ 或在 $d_i$ 全 $= 2$ 时才统计，直接 WA。
2. **三进制取位没有位运算捷径**：必须 `(s / pow3[i]) % 3`；顺手写 `s >> i`、`s & 3` 全错。**`popcount(s)` 也不是数位和**——如 $s = 4$ 即 $(1,1)_3$（已放 2 个数），$\text{popcount}(4) = 1$。
3. **哨兵 $-1$ vs 全 $0$ 初始化**：有趣的是，本题 dp 全 $0$ 初始化也能 AC（对拍 3000 组验证）：增益非负使虚假路径只会偏小，且「数位和 $> n$」的虚假状态会被 $\text{cnt} \ge n$ 分支拦下、其 $0$ 值不污染答案。但这是**侥幸**——收益可能为负的状压题里全 $0$ 初始化直接错，$-1$ 哨兵才是稳健惯例。
4. **篮子编号从 1 开始**：收益是 $x \mathbin{\&} (i+1)$、拆槽版 $\text{basket} = j/2+1$；忘 `+1` 会把篮 1 当成编号 0（$x \& 0 = 0$），小样例看不出来、大样例全错。
5. **贪心陷阱**：见 3.1 反例 $[3,3,2]$——「大数优先挑当前收益最大篮」会被容量挤兑反噬，必须 DP。
6. **nums 不必排序**：状态只关心已放个数，固定按下标顺序放即可；排序、去重都不改变答案。
7. **篮子富余与「挤篮」**：$n < 2S$ 时允许空篮；反过来两个数挤同一个篮也可能最优（自拟示例 $[6,7]$），别预设一对一配对。
8. **溢出审计**：答案 $\le 18 \times 15 = 270$，`int` 足够——本题是少见的「困难题无溢出坑」，把注意力留给状态编码。

**延伸思考**：

- **容量为 $k$ 的推广**：改用 $k+1$ 进制（容量 3 → 四进制 $4^{9} \approx 2.6 \times 10^{5}$，仍可行）；容量或篮子数再增大导致进制状态爆炸时，转**最大费用最大流**：源点 → 每个数（容量 1）、数 $x$ → 篮 $i$（容量 1、费用 $x \mathbin{\&} i$）、篮 → 汇点（容量 2），跑满 $n$ 单位流的最大费用即答案——本题正是「状压 DP 与流量模型同构」的教科书案例。
- **位结构观察**：篮子编号 $\le 3$ 时（$01/10/11_2$）只有低 2 位参与与运算，$\text{nums}[i] > 3$ 的高位全是「死重量」；一般地每个数的贡献上界是其与 $\{1,\dots,S\}$ 中编号与出的最大值，可用于剪枝，但 $S \le 9$ 下无必要。
- **输出具体方案**：转移时记录 $\arg\max$ 前驱（状态 + 篮子编号），从最优终态回溯即得每个数落点，代价 $O(3^{S})$ 额外空间或就地反查。
