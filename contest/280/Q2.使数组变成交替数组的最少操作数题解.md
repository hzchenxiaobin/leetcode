# LeetCode 使数组变成交替数组的最少操作数 题解

## 1. 题目概述

- **标题 / 题号**：使数组变成交替数组的最少操作数（#2170，medium）
- **链接**：https://leetcode.cn/problems/minimum-operations-to-make-the-array-alternating/
- **来源**：LeetCode 第 280 场周赛 Q2
- **难度**：中等
- **标签**：贪心、数组、哈希表、计数

**题意**：给定下标从 $0$ 开始、长度为 $n$ 的正整数数组 `nums`。若同时满足 $\text{nums}[i-2] = \text{nums}[i]$（$2 \le i \le n-1$）与 $\text{nums}[i-1] \ne \text{nums}[i]$（$1 \le i \le n-1$），则称其为**交替数组**。一步操作可选任意下标 $i$，把 $\text{nums}[i]$ 改成**任意正整数**。求使数组变成交替数组的最少操作数。

**约束**：

- $1 \le \text{nums.length} \le 10^5$
- $1 \le \text{nums[i]} \le 10^5$

> 💡 **一句话定位**：奇偶分组计数 × 频次前二配对 × 哨兵补位——「两组各选一个众数、撞车则一方让位」的频率贪心。

> 💡 本题在本仓库另有[每日题解 2170](../../solution/2101-2200/2170_使数组变成交替数组的最少操作数.md)：主线同为「奇偶分组 + 频次前二配对」，附「为什么 Top 2 足够」的初等证明与面试问答。本篇按**周赛复盘视角**展开：给出引理-定理化的完整正确性链（结构刻画 → 代价分解 → 候选收缩）、免特判的**哨兵补位 + $2 \times 2$ 枚举**统一实现（连 $n = 1$ 都不用写特判）、利用值域 $10^5$ 的桶直址 C++ 版，以及赛场易错清单，两篇互为印证。

## 2. 示例

```text
输出：3
解释：
  转成 [3,1,3,1,3,1]：偶数位全 3、奇数位全 1，只需改下标 3（2→1）、4（4→3）、5（3→1）。
  可以证明操作数少于 3 无法成为交替数组。
```

```text
  转成 [1,2,1,2,1]：保留下标 0 的 1 与两个奇数位的 2，只改下标 2、4。
  注意不能转成 [2,2,2,2,2]：nums[0] == nums[1]，不满足相邻不等。
```

```text
输出：2

```

## 3. 解题思路

### 3.1 暴力思路

交替数组的形态是「偶数位全为某值 $a$、奇数位全为某值 $b$、$a \ne b$」。最朴素的做法是枚举目标对 $(a, b)$：值域 $V = 10^5$，共 $V^2 = 10^{10}$ 对；即便预先做好频次表让每对验证 $O(1)$，$10^{10}$ 也远超时限。若不预统计、每对现扫数组，更是 $O(V^2 \cdot n)$ 天文数字。

> 💡 暴力法浪费在「把 $10^5$ 个候选值一视同仁地枚举」上。代价函数 $\text{cost}(a, b)$ 对 $a$、$b$ 各自**可分**：固定 $b$ 时只与 $\text{cnt}_e(a)$ 有关，而 $\text{cnt}_e$ 的最大值只出现在**频次前几名**上——这正是候选收缩的空间。

### 3.2 核心观察：奇偶分组 + 最大保留

![核心观察：交替数组 ⟺ 偶数位全 x、奇数位全 y（x ≠ y），代价对两组可分](images/wc280_q2_concept.svg)

**观察一（结构刻画）**：把两条定义拆开读——$\text{nums}[i-2] = \text{nums}[i]$ 把**同奇偶下标串成等值链**（$0,2,4,\dots$ 一条链，$1,3,5,\dots$ 一条链）；$\text{nums}[i-1] \ne \text{nums}[i]$ 就是链与链**相邻处不等**。合起来：交替数组 ⟺ 存在 $x \ne y$，使所有偶数下标值为 $x$、所有奇数下标值为 $y$。整个目标由**两个数** $(x, y)$ 完全决定。

**观察二（代价分解）**：目标定为 $(x, y)$ 后，每个位置独立——偶数位 $i$ 不等 $x$ 就必须改一次、等于 $x$ 就免费；奇数位同理。于是

$$\text{cost}(x, y) = \big(n_1 - \text{cnt}_e(x)\big) + \big(n_2 - \text{cnt}_o(y)\big), \qquad x \ne y$$

其中 $n_1 = \lceil n/2 \rceil$、$n_2 = \lfloor n/2 \rfloor$，$\text{cnt}_e / \text{cnt}_o$ 为两组频次。**最少操作 = 最多保留**，问题变成在 $x \ne y$ 约束下最大化 $\text{cnt}_e(x) + \text{cnt}_o(y)$。

**观察三（前二配对）**：无约束时各组取众数即可；唯一的坑是两组**众数撞车**（$\text{top1}_e = \text{top1}_o$）——此时必须有一方让位到自己的次高频（或干脆整组换新值）。关键结论（引理 3 给出证明）：**每组只需保留频次前二两个候选**，撞车时比较两条「让位」路线取优。

### 3.3 算法流程：前二候选 + 哨兵补位 + 2×2 枚举

![算法流程：分组 → 计数 → 取前二补哨兵 → 2×2 枚举过滤 x=y](images/wc280_q2_algorithm_flow.svg)

**分类讨论版**（每日版主线）：

1. 两组 top1 值不同：直接配对，$\text{cost} = (n_1 - c_1) + (n_2 - d_1)$；
2. 两组 top1 值相同：取 $\min\big((n_1 - c_1) + (n_2 - d_2),\ (n_1 - c_2) + (n_2 - d_1)\big)$，其中次高频不存在时频次记 $0$。

**统一枚举版**（本篇实现，更抗坑）：每组候选固定为「频次前二，不足两个补**哨兵** $(\bot, 0)$」——哨兵表示「选一个本组没出现过的全新值，保留 0 个」：

1. 偶组候选 $\{(v_1, c_1), (v_2, c_2)\}$，奇组候选 $\{(u_1, d_1), (u_2, d_2)\}$，缺位补 $(\bot, 0)$；
2. 枚举全部 $2 \times 2$ 组合，**跳过 $x = y$**，取 $\min\big((n_1 - \text{cx}) + (n_2 - \text{cy})\big)$。

哨兵一举消掉三类特判：某组只有一种值（无 top2）、**奇组为空**（$n = 1$）、撞车后「整组换新值」的兜底选项。连 `if (n == 1) return 0;` 都不用写。

### 3.4 示例演算

![示例演算：[1,2,2,2,2] 的 top1 撞车与四组合代价表](images/wc280_q2_example_walkthrough.svg)

以示例 2（`nums = [1,2,2,2,2]`，$n_1 = 3$，$n_2 = 2$）走一遍统一枚举版：

| 步骤 | 内容 | 结果 |
|------|------|------|
| ① 分组 | 偶数位 $[1,2,2]$，奇数位 $[2,2]$ | $n_1 = 3,\ n_2 = 2$ |
| ② 频次 | 偶组 $\{2{:}2,\ 1{:}1\}$，奇组 $\{2{:}2\}$ | — |
| ③ 前二 | 偶组 $(2,2),(1,1)$；奇组 $(2,2)$，top2 缺 → 补哨兵 $(\bot, 0)$ | ⚠ 两组 top1 都是 2，撞车 |
| ④ 枚举 | $(2,2)$ 撞车跳过；$(2,\bot) \to 1+2=3$；$(1,2) \to 2+0=\mathbf{2}$；$(1,\bot) \to 2+2=4$ | 最小 2 |
| ⑤ 还原 | 偶组目标 $x=1$（改下标 2、4），奇组目标 $y=2$（全保留） | $[1,2,1,2,1]$，答案 2 ✓ |

注意 ④：若漏判撞车直接 $n - (c_1 + d_1) = 5 - 4 = 1$ 是本题**最经典 WA**；只想到「撞车就整组换新值」也得 3，还差「让位到次高频」这一步才到 2。

## 4. 算法细节

1. **分组**：$n_1 = \lceil n/2 \rceil = (n + 1) / 2$，$n_2 = \lfloor n/2 \rfloor = n / 2$。$n = 1$ 时奇组为空，交给哨兵。
2. **频次统计**：值域仅 $10^5$，C++ 用两个定长桶 `ce[v] / co[v]` 直址计数，无哈希最坏退化；Python 用 `Counter` 切片一步到位（`nums[::2]` / `nums[1::2]`）。
3. **一次扫描取前二**：遍历桶维护 $(v_1, c_1, v_2, c_2)$——`c > c1` 时整体下移一位，否则 `c > c2` 只换第二。等频次并列时任取，不影响正确性。
4. **哨兵设计**：C++ 用**值 0** 当哨兵——值域从 1 开始，0 永不与真实值撞；Python 用 `None`。哨兵频次为 0，语义是「整组换成没出现过的全新正整数，保留 0 个」（这样的值总存在，正整数无穷）。
5. **$(\bot, \bot)$ 组合恰好被过滤**：双哨兵（全改）代价 $n$，被 $(\text{top1}_e, \bot)$（代价 $\le n - 1$）支配，且 $\bot = \bot$ 触发 $x = y$ 跳过——**两个哨兵可以用同一个值**，这个组合丢了也不亏。
6. **枚举**：$2 \times 2$ 共 4 组合，过滤 $x = y$ 后取最小。无溢出风险，`int` 即可。

## 5. 正确性证明

**引理 1（结构刻画）**：`nums` 是交替数组 ⟺ 存在值 $x, y$（$n \ge 2$ 时要求 $x \ne y$），使每个偶数下标处值为 $x$、每个奇数下标处值为 $y$。

**证明**：（⇐）该形态下同链下标隔一相等、相邻异号下标处 $x \ne y$，两条定义逐条满足；$n = 1$ 时两条定义均无适用下标，空真。（⇒）对每个 $2 \le i \le n-1$，$\text{nums}[i-2] = \text{nums}[i]$ 把同奇偶下标连成一串相邻相等，沿链传递得**同奇偶下标全部相等**，分别记其值为 $x, y$；$n \ge 2$ 时取 $i = 1$ 得 $\text{nums}[0] \ne \text{nums}[1]$，即 $x \ne y$。∎

**引理 2（代价分解）**：目标形态 $(x, y)$（$x \ne y$）确定后，最少操作数恰为 $(n_1 - \text{cnt}_e(x)) + (n_2 - \text{cnt}_o(y))$，其中 $x$ 不在偶组出现时 $\text{cnt}_e(x) = 0$（奇组对称）。

**证明**：各位置独立：偶数位 $i$ 若 $\text{nums}[i] = x$ 无需操作，否则改一次恰好足够；操作一次只影响一个下标，故总操作数即「与目标不符的位置数」$= (n_1 - \text{cnt}_e(x)) + (n_2 - \text{cnt}_o(y))$，且下界（每个不符位置至少一次）与上界（每个不符位置恰一次）重合。∎

**引理 3（候选收缩）**：固定奇组目标 $y$，偶组的最优 $x$ 可在「偶组频次前二的值 ∪ 任一偶组未出现的值」中取到；固定 $x$ 时奇组对称。

**证明**：代价中偶组部分 $n_1 - \text{cnt}_e(x)$ 只依赖 $\text{cnt}_e(x)$，与 $y$ 无关，故只需在 $x \ne y$ 下最大化 $\text{cnt}_e(x)$。把偶组各值按频次降序排为 $v_1, v_2, \dots$（频次 $c_1 \ge c_2 \ge \cdots$）：

- 若 $v_1 \ne y$：$x = v_1$ 即无约束全局最大；
- 若 $v_1 = y$：$v_2 \ne v_1 = y$（若存在），是约束下的最大；若 $v_2$ 不存在（偶组仅一种值且恰为 $y$），则一切 $x \ne y$ 都不在偶组出现，$\text{cnt}_e(x) = 0$，取任一未出现的值即可。∎

**定理**：算法（每组取频次前二、不足补哨兵 $(\bot, 0)$，枚举 $2 \times 2$ 组合并跳过 $x = y$，取最小代价）返回最少操作数。

**证明**：每个被枚举的组合都可行：$x \ne y$ 且均为真实值时由引理 1、2 该代价可达成；含哨兵时表示选一个本组未出现的正整数（且避开另一组的值，正整数无穷故总存在），保留数为 0，代价同样可达成。反之任取最优解 $(x^*, y^*)$（$n = 1$ 时奇组为空，$(\text{top1}_e, \bot)$ 即被枚举且代价为最优，以下设 $n \ge 2$）：由引理 3 的对称形式，存在候选 $y' \in \{\text{top1}_o, \text{top2}_o, \bot\}$ 使 $y' \ne x^*$ 且 $\text{cnt}_o(y') \ge \text{cnt}_o(y^*)$，故 $\text{cost}(x^*, y') \le \text{cost}(x^*, y^*)$；再由引理 3，存在候选 $x' \in \{\text{top1}_e, \text{top2}_e, \bot\}$ 使 $x' \ne y'$ 且 $\text{cnt}_e(x') \ge \text{cnt}_e(x^*)$，故 $\text{cost}(x', y') \le \text{cost}(x^*, y^*) = \text{OPT}$。组合 $(x', y')$ 在枚举范围内且未被过滤，于是算法输出 $\le \text{OPT}$；结合可行性得恰为 $\text{OPT}$。∎

> ⚠️ 引理 3 是「前二就够」的形式化：第三高频在同组内频次必不超过 top2，在 top1 撞车的场合只会让保留数更小；而「全新值」的保留数必为 0，由哨兵兜底。

## 6. 复杂度分析

- **时间复杂度**：$O(n + V)$，$V = 10^5$。分组计数 $O(n)$；扫桶取前二 $O(V)$；枚举 $O(1)$。Python 版 `Counter.most_common(2)` 内部是最小堆维护前 2 大，$O(\text{出现值数} \log 2) = O(n)$。
- **空间复杂度**：桶版 $O(V)$（两个 $10^5$ 桶）；哈希版 $O(n)$（最坏两组各 $n/2$ 个不同值）。

> 💡 $n = 10^5$ 下线性扫描毫无压力；本题真正分出快慢的是**读题 30 秒内看破「交替 = 两个数决定」**的结构翻译。

## 7. 参考代码

### C++（值域桶 + 哨兵枚举，免特判）

```cpp
class Solution {
public:
    int minimumOperations(vector<int>& nums) {
        int n = nums.size();
        // 值域 1..1e5：两组各开一个桶直址计数
        vector<int> ce(100001, 0), co(100001, 0);
        for (int i = 0; i < n; ++i)
            (i % 2 == 0 ? ce : co)[nums[i]]++;

        // 一次扫描取频次前二 (v1,c1,v2,c2)；值 0 兼任“不存在”哨兵
        auto top2 = [](const vector<int>& f) {
            int v1 = 0, c1 = 0, v2 = 0, c2 = 0;
            for (int v = 1; v < (int)f.size(); ++v) {
                if (f[v] > c1) { v2 = v1; c2 = c1; v1 = v; c1 = f[v]; }
                else if (f[v] > c2) { v2 = v; c2 = f[v]; }
            }
            return array<int, 4>{v1, c1, v2, c2};
        };

        auto [ev1, ec1, ev2, ec2] = top2(ce);
        auto [ov1, oc1, ov2, oc2] = top2(co);
        int n1 = (n + 1) / 2, n2 = n / 2;

        int vs[2][2] = {{ev1, ev2}, {ov1, ov2}};
        int cs[2][2] = {{ec1, ec2}, {oc1, oc2}};
        int ans = n;                        // 上界：全改
        for (int i = 0; i < 2; ++i)
            for (int j = 0; j < 2; ++j)
                if (vs[0][i] != vs[1][j])   // x == y 跳过（含双哨兵组合，恰被支配）
                    ans = min(ans, (n1 - cs[0][i]) + (n2 - cs[1][j]));
        return ans;
    }
};
```

### Python（Counter + None 哨兵枚举）

```python
class Solution:
    def minimumOperations(self, nums: List[int]) -> int:
        n = len(nums)
        n1, n2 = (n + 1) // 2, n // 2

        def top2(cnt):
            cand = cnt.most_common(2)
            cand += [(None, 0)] * (2 - len(cand))   # 哨兵：值 None，频次 0
            return cand

        even, odd = Counter(nums[::2]), Counter(nums[1::2])

        ans = n                                      # 上界：全改
        for x, cx in top2(even):
            for y, cy in top2(odd):
                if x != y:                           # None == None 也在此被过滤
                    ans = min(ans, (n1 - cx) + (n2 - cy))
        return ans
```

> 💡 两版都**没有** `if (n == 1) return 0;`：$n = 1$ 时奇组为空，候选全为哨兵，$(\text{top1}_e, \bot)$ 组合自动给出代价 $0$。对比每日版的分类讨论实现（需要 $n = 1$ 特判），哨兵枚举用「多枚举几个被支配组合」换「零特判」，赛场上更不容易写挂。

## 8. 边界情况与易错点

1. **漏判 top1 撞车（最经典 WA）**：直接 `n - (c1 + d1)`。反例 $[1,2,2,2,2]$：算出 $5 - 4 = 1$，实际答案 2——两组众数都是 2 时 $(2, 2)$ 根本不可行。
2. **撞车后只想到「整组换新值」**：得 $(\text{top1}, \bot)$ 的代价 3（上例），漏掉「让位到次高频」的 $(\text{top2}, \text{top1}) = 2$。两条让位路线都要比。
3. **某组无 top2 / 组为空**：哨兵 $(\bot, 0)$ 补位。若不补而直接用默认值参与配对，会把「保留 0 个」错算成「保留垃圾值」。反例 $[5,5,5,5]$：两组都无 top2，正确答案 2（整组改掉一组）。
4. **$n = 1$**：天然已是交替数组，答案 0。哨兵版无需特判；若手写分类讨论版，记得补 `if (n == 1) return 0;`（每日版的写法）。
5. **哨兵值不得与真实值域重叠**：值域从 1 开始故用 0 / `None`；若某变体值域含 0，需换哨兵（如 $-1$ 或 `None`）。
6. **双哨兵组合 $(\bot, \bot)$ 被跳过不亏**：代价 $n$ 被 $(\text{top1}, \bot) \le n - 1$ 支配——两组哨兵可以共用同一个值。
7. **别把「操作改成任意正整数」想复杂**：目标值不必来自原数组，也不需要构造出目标数组——只数「保留多少」，全新值的保留数就是 0。
8. **取前二别写成全排序**：$O(\text{值数})$ 一次扫描足够；值域 $10^5$ 的桶让 C++ 免受 `unordered_map` 最坏退化之苦。
9. **无溢出**：$n$、频次、代价全部 $\le 10^5$，`int` 足够——与 510 场 Q2 那种 $10^{19}$ 级溢出题形成对照。

- [本站每日题解 3937 / 3944. 使数组变为模交替数组的最少操作次数 I / II](../../solution/3901-4000/3937_使数组变为模交替数组的最少操作次数I.md)：本题的「余数环」加强版——目标从具体值放松为 $\bmod k$ 余数、操作从「任意替换」换成 $\pm 1$，代价表与配对框架依旧。

**延伸思考**：

- **周期推广**：若交替模式从 $x, y$ 两值扩成周期 $p$ 的 $x_0, x_1, \dots, x_{p-1}$（相邻不等），则分成 $p$ 组、每组取前 $p$ 高频候选，枚举 $p^p$ 个组合过滤两两相等即可——候选收缩引理逐组照搬。
- **模 $k$ 版本**（即 3937/3944）：约束改为 $\text{nums}[i] \bmod k$ 呈交替余数，元素代价变成「余数环短弧距离」，配对枚举框架不变——可见「分组 + 前二/全枚举 + 排斥约束」是一整个家族。
- **要求输出构造后的数组**：记录取得最小代价的 $(x, y)$（含哨兵时任选一个不冲突的未用值），再扫一遍把不符位置改掉即可，$O(n)$ 追加。
- **值域升到 $10^9$**：桶不可行，换哈希表；取前二改用一次遍历维护 $(v_1, c_1, v_2, c_2)$，复杂度回到 $O(n)$。
