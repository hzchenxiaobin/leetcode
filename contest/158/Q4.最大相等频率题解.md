# LeetCode 最大相等频率 题解

## 1. 题目概述

- **标题 / 题号**：最大相等频率（#1224，hard）
- **链接**：https://leetcode.cn/problems/maximum-equal-frequency/
- **来源**：LeetCode 第 158 场周赛 Q4
- **难度**：困难
- **标签**：数组、哈希表

**题意**：给定正整数数组 `nums`，找出一个**最长前缀** `nums[0..i]`，使得从该前缀中**恰好删去一个元素**（删去的是某次出现，删完后该数值可能还剩余若干次）后，剩下的每个不同数值出现的次数**完全相同**。返回这个前缀的长度。特别地，若删去后前缀为空，则「每个数值都出现 0 次」也算相等。

也就是说，我们要找最大的 $L$，使得存在下标 $j < L$，把 `nums[j]` 从 `nums[0..L-1]` 中拿掉之后，剩余多重集的频率分布是「单值」的（所有出现的数值频率相同，空集视为满足）。

**约束**：

- $2 \le \text{nums.length} \le 10^5$
- $1 \le \text{nums}[i] \le 10^5$

## 2. 示例

**示例 1**

```text
输入：nums = [2,2,1,1,5,3,3,5]
输出：7
解释：长度 7 的前缀 [2,2,1,1,5,3,3]，删去 nums[4] = 5 后得到 [2,2,1,1,3,3]，
      2、1、3 都出现 2 次，满足要求。
      长度 8 即整个数组频率为 2:2, 1:2, 3:2, 5:2，删掉任何一个都会让某个数变成 1 次，
      与其余 2 次不等，因此答案不是 8。
```

**示例 2**

```text
输入：nums = [1,1,1,2,2,2,3,3,3,4,4,4,5]
输出：13
解释：整个数组就是答案：删去末尾的 5 之后，1、2、3、4 各出现 3 次。
```

**补充用例（边界）**

```text
输入：nums = [1,2]
输出：2
解释：每个数各出现 1 次；删掉任意一个，剩下 1 个数出现 1 次，仍满足「频率相同」。
```

## 3. 解题思路

### 3.1 暴力思路

对每个前缀长度 $L$（共 $n$ 种），枚举删去的下标 $j$（$L$ 种），再统计剩余元素的频率并比较（$O(L)$），总复杂度 $O(n^3)$。稍加优化：只在删除处增量更新频率，仍要 $O(n^2)$ 次「删一次、判一次」，而 $n = 10^5$ 时 $10^{10}$ 量级完全不可行。

**关键难点**：合法的前缀**不满足单调性**。示例 1 中长度为 $1,2,3$ 的前缀合法、长度为 $4$ 的不合法、长度 $5$ 的又合法，所以「二分答案」「长度越长越难满足」这类直觉在这里全部失效，只能**逐个前缀精确判定**，问题变成：能否在 $O(1)$ 时间内判断当前前缀是否合法。

### 3.2 核心观察：频率直方图只有三种合法形态

![三种合法频率形态](images/wc158_q4_three_shapes.svg)

扫描时维护三样东西：

- $\text{cnt}[x]$：数值 $x$ 在当前前缀中出现的次数；
- $\text{freqCnt}[f]$：出现次数**恰好为** $f$ 的不同数值个数（频率直方图）；
- $\text{maxF}$：当前前缀中的最大频率。

设前缀长度为 $L$。删去一个元素后所有频率相等，只可能是下面三种形态之一：

- **形态 ①（全是单例）**：$\text{maxF} = 1$，即所有数值各出现 1 次。删掉任意一个元素，剩下的数值仍然各 1 次（或删空，0 次），合法。
- **形态 ②（唯一单例）**：恰好有**一个**数值出现 1 次，其余数值**全部**出现 $\text{maxF}$ 次。此时把这个单例整个删掉（它只有一次出现）即可，剩余频率统一为 $\text{maxF}$。
- **形态 ③（唯一尖峰）**：恰好有**一个**数值出现 $\text{maxF}$ 次，其余数值**全部**出现 $\text{maxF}-1$ 次。此时从那个最高频数值上削去一次，它的频率降到 $\text{maxF}-1$，全体统一。

于是「当前前缀合法」等价于下列三条判定式**至少一条**成立（$L = i+1$ 为当前前缀长度）：

- 判定 ①：$\text{maxF} = 1$；
- 判定 ②：$\text{freqCnt}[1] = 1$ 且 $\text{freqCnt}[\text{maxF}] \cdot \text{maxF} + 1 = L$；
- 判定 ③：$\text{freqCnt}[\text{maxF}] = 1$ 且 $\text{freqCnt}[\text{maxF}-1] \cdot (\text{maxF}-1) + \text{maxF} = L$。

为什么只有这三种？删去的元素值记为 $v$，只有两种去向：

1. **$v$ 被删空**（$\text{cnt}[v] = 1$）：剩下的数值频率必须一致，于是 $v$ 就是那个唯一的单例，其余数值频率都等于删后的公共值，也就是 $\text{maxF}$ —— 形态 ②（若 $L = 1$ 或删后为空，归入 ①）。
2. **$v$ 仍有剩余**：删后 $v$ 的频率为 $c \ge 1$，全体公共频率就是 $c$，于是 $v$ 原来出现 $c+1 = \text{maxF}$ 次且它是**唯一**的最大频率，其余数值都是 $c = \text{maxF}-1$ 次 —— 形态 ③。

### 3.3 算法流程

![单遍扫描流程图](images/wc158_q4_scan_flow.svg)

从左到右扫描，**每读入一个元素就更新直方图并判定一次**，用 `ans` 记录所有合法前缀中的最大长度：

1. 读入 $x = \text{nums}[i]$。若 $\text{cnt}[x] = c > 0$，先令 $\text{freqCnt}[c] \mathrel{-}= 1$（它马上要离开频率 $c$ 这一档）。
2. $\text{cnt}[x] \mathrel{+}= 1$（变为 $c+1$），$\text{freqCnt}[c+1] \mathrel{+}= 1$，并 $\text{maxF} \leftarrow \max(\text{maxF}, c+1)$。
3. 令 $L = i+1$，套用上面的三条判定式；只要有一条成立，就更新 `ans = L`。
4. 扫描结束返回 `ans`。

由于每个元素只做常数次哈希表/数组操作，整个过程 $O(n)$。$\text{maxF}$ 在插入时**单调不减**（频率只会上升），所以不需要回退或重算。

### 3.4 示例演算

![示例 1 逐前缀走查](images/wc158_q4_walkthrough.svg)

对 `nums = [2,2,1,1,5,3,3,5]` 逐前缀判定，$\text{ans}$ 依次被更新为 $1,2,3,5,7$：

| $L$ | 频率分布 | $\text{maxF}$ | 命中 | 说明 |
|----|----------|---------------|------|------|
| 1 | 1 个值 $\times 1$ | 1 | ① | 删空，全体 0 次 |
| 2 | $2{:}2$ | 2 | ③ | 削成 $2{:}1$ |
| 3 | $2{:}2,\ 1{:}1$ | 2 | ②③ | 删单例 1，或削 2 |
| 4 | $2{:}2,\ 1{:}2$ | 2 | — | 生成等频，删哪个都破坏平衡 |
| 5 | $2{:}2,\ 1{:}2,\ 5{:}1$ | 2 | ② | 删单例 5 |
| 6 | 上面再加 $3{:}1$ | 2 | — | 两个单例，②③都不成立 |
| 7 | $2{:}2,\ 1{:}2,\ 5{:}1,\ 3{:}2$ | 2 | ② | 删单例 5 |
| 8 | 四个值各 2 次 | 2 | — | $\text{freqCnt}[2] = 4$，削不动 |

表格第 4 行正是「不单调」的证据：$L=4$ 不合法，而更长的 $L=5$ 合法，所以必须逐项检查而不是二分。

## 4. 算法细节

1. **两份计数表各司其职**：$\text{cnt}$ 回答「某个数值出现了几次」，$\text{freqCnt}$ 回答「出现 $f$ 次的值有几个」。所有判定都只依赖 $\text{freqCnt}$ 与 $\text{maxF}$，因此维护成本是 $O(1)$。
2. **更新顺序不能颠倒**：必须先把 $\text{freqCnt}[\text{cnt}[x]]$ 减 1（此时 $\text{cnt}[x]$ 是旧值），再把 $\text{cnt}[x]$ 加 1 并给 $\text{freqCnt}[\text{新值}]$ 加 1。若先加 $\text{cnt}[x]$，旧的档位就再也减不掉了。
3. **只在 $c > 0$ 时扣减**：$c = 0$ 表示这个数值第一次出现，它原本不在任何频率档里，此时扣 $\text{freqCnt}[0]$ 会让判定 ③ 出现幽灵计数。
4. **$\text{freqCnt}[0]$ 恒为 0**：因此 $\text{maxF} = 1$ 时代入 ③ 得 $\text{freqCnt}[0] \cdot 0 + 1 = L$，只有当 $L = 1$ 才成立，与 ① 一致，不需要单独特判下溢。
5. **选数组还是哈希表**：$\text{nums}[i] \le 10^5$，C++ 直接用 `vector<int>` 开 $10^5+2$ 的两份数组，比 `unordered_map` 快一个量级；Python 用 `defaultdict` 或 `dict`，注意 $\text{freqCnt}$ 的键最大是 $\text{maxF} \le n$。
6. **答案初值与更新**：`ans = 0`，每次合法就赋值为 $L$；由于 $L = 1$ 时 $\text{maxF} = 1$ 必然命中 ①，所以 $n \ge 1$ 时答案至少为 1，不需要额外兜底。
7. **为什么不必回看历史**：合法性检查只依赖**当前**的直方图，不依赖删的是哪个下标，所以「先记录所有可能被删的位置」这种做法是多余的，直接比较形态即可。

## 5. 正确性证明

约定：前缀 $P = \text{nums}[0..L-1]$，$\text{maxF}$、$\text{freqCnt}$ 都是 $P$ 上的统计量；称 $P$ 是**可删的**，若存在某个下标删去后剩余元素频率全等。

**引理 1（形态完备性）**：若 $P$ 可删，则 $P$ 的频率分布属于形态 ①②③ 之一。

**证明**：设删去的元素值为 $v$（$\text{cnt}[v] \ge 1$）。

- 若 $\text{cnt}[v] = 1$：删后 $v$ 消失。剩余数值频率全等于某个 $c$。若剩余为空，则 $L = 1$、$\text{maxF} = 1$，属 ①。否则 $c \ge 1$，$P$ 中除 $v$ 外的数值频率都是 $c$，而 $\text{cnt}[v] = 1 \le c$，故 $\text{maxF} = c$：当 $c = 1$ 时全体都是单例，属 ①；当 $c \ge 2$ 时 $v$ 是唯一的频率 1 数值，属 ②。
- 若 $\text{cnt}[v] \ge 2$：删后 $v$ 仍有 $\text{cnt}[v] - 1 \ge 1$ 次，全体公共频率为 $c = \text{cnt}[v]-1$，即 $\text{cnt}[v] = c+1$。其余数值频率都为 $c$，故 $\text{maxF} = c+1$、$\text{freqCnt}[c+1] = 1$，其余（$d-1$ 个，$d$ 为不同值个数）都为 $c = \text{maxF}-1$，属 ③。∎

**引理 2（判定充分）**：若三条判定式之一成立，则 $P$ 可删。

**证明**：分三种情况构造删除方案。

- ①：$\text{maxF} = 1$ 表示所有数值各出现 1 次，删去任意一个元素后剩余数值仍各 1 次，若删空则全体 0 次，频率相同。
- ②：条件 $\text{freqCnt}[\text{maxF}] \cdot \text{maxF} + 1 = L$ 说明除一个元素之外，其余所有元素恰好被 $\text{freqCnt}[\text{maxF}]$ 个数值均分、每个 $\text{maxF}$ 次；而 $\text{freqCnt}[1] = 1$ 保证那多出来的一个元素是某个数值的唯一一次出现。删掉它，剩余频率全为 $\text{maxF}$。
- ③：条件 $\text{freqCnt}[\text{maxF}-1] \cdot (\text{maxF}-1) + \text{maxF} = L$ 说明除一个出现 $\text{maxF}$ 次的数值外，其余数值都是 $\text{maxF}-1$ 次；而 $\text{freqCnt}[\text{maxF}] = 1$ 保证该数值唯一。从它上面删去一次，频率降为 $\text{maxF}-1$，全体一致。∎

**引理 3（判定精确）**：三条判定式成立的充要条件是 $P$ 可删。

**证明**：充分性即引理 2，必要性即引理 1 的两条分支分别对应 ② 与 ③（或 ① 的特例），故等价。∎

**定理**：算法返回的 `ans` 等于最长可删前缀的长度。

**证明**：扫描到 $i$ 时，$\text{cnt}$、$\text{freqCnt}$、$\text{maxF}$ 恰好是前缀 $\text{nums}[0..i]$ 的统计量（归纳：每次插入都正确地把它从旧频率档移到新频率档，$\text{maxF}$ 取历史最大且单调不减，故等于当前最大频率）。由引理 3，此时判定结果精确等价于「该前缀可删」；算法在所有可删前缀中取最大长度，正是题目要求的最长前缀长度。又 $L = 1$ 时可删，故对任意满足约束的输入答案都有定义。∎

## 6. 复杂度分析

- **时间**：$O(n)$。每个元素做常数次数组/哈希表读写（$\text{cnt}$ 与 $\text{freqCnt}$ 各一次减、一次加），三次判定都是 $O(1)$ 的四则运算；共 $n$ 轮。
- **空间**：$O(n + U)$。$\text{cnt}$ 与 $\text{freqCnt}$ 各开 $U = \max(\text{nums}) \le 10^5$ 与 $n$ 规模的槽位；若用哈希表则只存不同数值个数 $d \le n$ 与它们占用的频率档，$O(n)$。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <algorithm>

using namespace std;

class Solution {
public:
    int maxEqualFreq(vector<int>& nums) {
        const int MAXV = 100002;
        vector<int> cnt(MAXV, 0);       // cnt[x]：值 x 在当前前缀中的出现次数
        vector<int> freqCnt(MAXV, 0);   // freqCnt[f]：出现次数恰为 f 的不同值个数
        int ans = 0, maxFreq = 0;

        for (int i = 0; i < (int)nums.size(); i++) {
            int x = nums[i];
            if (cnt[x] > 0) freqCnt[cnt[x]]--;
            cnt[x]++;
            freqCnt[cnt[x]]++;
            maxFreq = max(maxFreq, cnt[x]);

            int len = i + 1;
            bool ok = false;
            if (maxFreq == 1) ok = true;                              // ① 全是单例
            if (freqCnt[1] == 1 && freqCnt[maxFreq] * maxFreq + 1 == len)
                ok = true;                                            // ② 删掉唯一单例
            if (freqCnt[maxFreq] == 1 &&
                freqCnt[maxFreq - 1] * (maxFreq - 1) + maxFreq == len)
                ok = true;                                            // ③ 削掉最高频一次
            if (ok) ans = len;
        }
        return ans;
    }
};
```

### Python

```python
from collections import defaultdict
from typing import List


class Solution:
    def maxEqualFreq(self, nums: List[int]) -> int:
        cnt = defaultdict(int)        # cnt[x]：值 x 在当前前缀中的出现次数
        freq_cnt = defaultdict(int)   # freq_cnt[f]：出现次数恰为 f 的不同值个数
        ans = 0
        max_freq = 0
        for i, x in enumerate(nums):
            if cnt[x] > 0:
                freq_cnt[cnt[x]] -= 1
            cnt[x] += 1
            freq_cnt[cnt[x]] += 1
            if cnt[x] > max_freq:
                max_freq = cnt[x]

            length = i + 1
            ok = False
            if max_freq == 1:                                   # ① 全是单例
                ok = True
            if freq_cnt[1] == 1 and freq_cnt[max_freq] * max_freq + 1 == length:
                ok = True                                       # ② 删掉唯一单例
            if freq_cnt[max_freq] == 1 and \
               freq_cnt[max_freq - 1] * (max_freq - 1) + max_freq == length:
                ok = True                                       # ③ 削掉最高频一次
            if ok:
                ans = length
        return ans
```

## 8. 边界情况与易错点

1. **删空合法**：$L = 1$ 时删掉唯一元素后前缀为空，全体 0 次也可视为相等。判定 ① 已覆盖，不要因为「剩余必须有元素」而漏掉。
2. **全部元素相同**：`[5,5,5]` 中 $\text{freqCnt}[3] = 1$、$\text{freqCnt}[2] = 0$，命中 ③：$0 \cdot 2 + 3 = 3 = L$。若把 ③ 写成「$\text{freqCnt}[\text{maxF}-1] \ge 1$」，这里就会被误判为不合法。
3. **两个单例**：`[1,1,2,3]`（$1{:}2,\ 2{:}1,\ 3{:}1$）不合法，因为删掉一个单例后另一个单例仍与其他值频率不同。判定 ② 中的 $\text{freqCnt}[1] = 1$ 就是拦截这种情况的。
4. **等频计时不可删**：`[1,1,1,2,2,2]` 中 $\text{freqCnt}[3] = 2$，删任何一次都会造成 $3$ 与 $2$ 并存；③ 要求 $\text{freqCnt}[\text{maxF}] = 1$ 正是为此。
5. **$\text{maxF} = 1$ 时下标越界**：③ 里访问 $\text{freqCnt}[\text{maxF}-1] = \text{freqCnt}[0]$，数组必须至少多留一个槽位；C++ 中把数组开到 `MAXV` 且 `maxFreq ≤ n < MAXV` 即可，Python 字典要保证不出现 `KeyError`（用 `defaultdict`）。
6. **更新顺序**：先扣旧档、再加新档，顺序写反会让 $\text{freqCnt}$ 全盘失真，且这种错误在短用例上常常「恰好」通过，务必按 §4 的顺序实现。
7. **不要二分**：合法性不单调（$L=4$ 不合法而 $L=5$ 合法），二分答案会直接漏解；必须维护「所有合法长度的最大值」。
