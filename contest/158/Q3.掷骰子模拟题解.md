# LeetCode 掷骰子模拟 题解

## 1. 题目概述

- **标题 / 题号**：掷骰子模拟（#1223，hard）
- **链接**：https://leetcode.cn/problems/dice-roll-simulation/
- **来源**：LeetCode 第 158 场周赛 Q3
- **难度**：困难
- **标签**：数组、动态规划

**题意**：有一个六面骰子模拟器，每次投掷产生 $1$ 到 $6$ 的随机整数。现在给出一道附加约束：点数 $i$ 不允许**连续**出现超过 `rollMax[i-1]` 次（`rollMax` 按点数 $1\ldots6$ 的顺序给出，即 `rollMax[0]` 对应点数 1）。求掷 $n$ 次能得到的**不同点数序列**的个数，答案对 $10^9+7$ 取模。

**约束**：

- $1 \le n \le 5000$
- `rollMax.length == 6`
- $1 \le \text{rollMax}[i] \le 15$（$i=0\ldots5$，即每个点数的连续上限）
- 两个序列只要有一位不同就算不同，按有序序列计数

## 2. 示例

**示例 1**

```text
输入：n = 2, rollMax = [1,1,2,2,2,3]
输出：34
解释：无约束时共 6 × 6 = 36 种；点数 1、2 最多连续 1 次，
      故 (1,1) 与 (2,2) 非法，36 − 2 = 34。
```

**示例 2**

```text
输入：n = 2, rollMax = [1,1,1,1,1,1]
输出：30
解释：6 个点数都最多连续出现 1 次，6 个「双同」序列全部非法，36 − 6 = 30。
```

**示例 3**

```text
输入：n = 3, rollMax = [1,1,1,2,2,3]
输出：181
解释：长度 3 的序列共 6³ = 216 种，去掉违反连续上限的那些，剩下 181 种。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的做法是枚举全部 $6^n$ 个序列，对每个序列扫一遍连续段、检查是否超过上限。单次检查 $O(n)$，总复杂度 $O(n\cdot 6^n)$：$n=2$ 时 72 次运算尚可，$n=5000$ 时 $6^{5000}$ 是天文数字，完全不可行。

退一步，想用「长度 + 末尾点数」做线性 DP：$dp[t][i]$ 表示长度 $t$、末尾点数为 $i$ 的合法序列数。转移时却卡住了——要不要禁止续掷 $i$，取决于**末尾已经连续出现了几个 i**，而 $dp[t][i]$ 把这个信息抹掉了。所以状态必须显式带上「末尾连续长度」。

### 3.2 核心观察：状态 = (末尾点数, 末尾连续长度)

![状态压缩：只需末尾点数与末尾连续长度](images/wc158_q3_state_model.svg)

**关键洞察**：本题的约束是**局部**的。一个序列违规，当且仅当某个点数的某段连续出现次数超过上限。判断「下一掷的点数 $r$ 能否接在当前前缀后面」时，唯一相关的历史信息只有两个：

1. 末尾点数的**取值** $i$：$r=i$ 与 $r\ne i$ 走出完全不同的两条转移；
2. 末尾**连续长度** $d$：只有 $r=i$ 且 $d=m_i$ 时才被禁止，其中 $m_i=\text{rollMax}[i-1]$ 是点数 $i$ 的连续上限。

于是任意合法前缀都能压缩成一个二元组 $(i,d)$。状态空间大小 $\sum_{i=1}^{6} m_i \le 6\times 15 = 90$，**与 $n$ 无关**。例如 `3 4 4`、`5 4 4`、`4 4` 三条历史在这里完全等价——末尾都是「连续 2 个 4」，即状态 $(4,2)$，下一步能接的东西一模一样。这正是无后效性成立的原因。

### 3.3 状态转移

![状态转移：续掷同一点数或换一个点数](images/wc158_q3_transition_flow.svg)

记 $m_i=\text{rollMax}[i-1]$，$dp[i][d]$ 为「长度为当前轮数、末尾恰好是连续 $d$ 个点数 $i$」的合法序列数，其中 $1\le d\le m_i$。长度 1 时每个点数各 1 种，即 $dp[i][1]=1$。

从 $(i,d)$ 出发只有两条出边：

- **续掷同一个点数**（要求 $d<m_i$）：$\;\text{ndp}[i][d+1]\mathrel{+}=dp[i][d]$；
- **换一个点数** $j\ne i$（共 5 种选择）：$\;\text{ndp}[j][1]\mathrel{+}=dp[i][d]$。

若直接逐状态枚举，每层要做 $90\times 5$ 次加法。用一个**批量技巧**可以把「换点数」的 5 条边合并成一次减法。令

$$S[i]=\sum_{d=1}^{m_i} dp[i][d],\qquad T=\sum_{i=1}^{6} S[i]$$

则

$$\text{ndp}[i][1] = T - S[i],\qquad \text{ndp}[i][d+1] = dp[i][d]\ \ (1\le d<m_i)$$

理由：在长度 $L$ 的所有合法序列后面再接一个点数 $i$，只有「末尾已经连续 $m_i$ 个 $i$」的那批会越界，其数量恰为 $S[i]$；扣掉后剩下的正是「末尾不是 $i$、接上 $i$ 后连续长度变成 1」的全部方案。每个 $S[i]$ 本身只是一次求和，因此每层仍然是 $O(6\times 15)$。

答案就是最后一层所有状态之和：$\text{ans}=\sum_i\sum_d dp[i][d]$（长度恰为 $n$）。

### 3.4 示例演算

![逐层演算：n = 3，rollMax = [1,1,1,2,2,3]](images/wc158_q3_walkthrough.svg)

以示例 3 的 `rollMax = [1,1,1,2,2,3]` 走一遍（每个格子是 $dp[i][d]$，$d$ 从 1 开始）：

| 已掷长度 | $i=1$ | $i=2$ | $i=3$ | $i=4$ | $i=5$ | $i=6$ | 合计 |
|----------|-------|-------|-------|-------|-------|-------|------|
| $L=1$ | 1 | 1 | 1 | 1 | 1 | 1 | 6 |
| $L=2$ | 5 | 5 | 5 | 5, 1 | 5, 1 | 5, 1 | 33 |
| $L=3$ | 28 | 28 | 28 | 27, 5 | 27, 5 | 27, 5, 1 | 181 |

逐层读数：$L=2$ 时 $T=6$、每个 $S[i]=1$，于是 $\text{ndp}[i][1]=6-1=5$；点数 4、5、6 的上限大于 1，还能从 $(i,1)$ 续出 $(i,2)$，值为 1。合计 $3\times5+3\times6=33$。$L=3$ 时 $T=33$，点数 1、2、3 的 $S=5$，得到 $28$；点数 4、5 的 $S=6$，得到 $27$ 并各自续出 $5$；点数 6 还能再续出 $1$。合计 $28\times3+(27+5)\times2+(27+5+1)=181$，与官方输出一致。

再验证示例 1：$n=2$、`rollMax = [1,1,2,2,2,3]`，$36$ 个双掷序列中只有 `(1,1)`、`(2,2)` 越界（点数 1、2 的上限都是 1），答案 $36-2=34$。

## 4. 算法细节

1. **下标对齐**：题面按点数 $1\ldots6$ 给 `rollMax`，故 $m_i=$ `rollMax[i-1]`。代码里统一用 0-based 的 `f = i - 1`，于是 $m_i$ 就是 `rollMax[f]`，文章的 $dp[i][d]$ 对应代码的 `dp[f][d]`；两种写法不要混用，这是本题最常见的 off-by-one。
2. **滚动数组**：转移只依赖上一层，用两个 $6\times 16$ 的数组交替即可，空间 $O(6\times 15)$；每轮把旧数组整体换出、新数组清零。
3. **初始层与 $n=1$**：$dp[i][1]=1$，主循环执行 $n-1$ 轮；$n=1$ 时循环不执行，直接对初始层求和得到 6，符合题意。
4. **批量转移的实现顺序**：先扫一遍 6 行算出 $S[i]$ 与 $T$，再用 `ndp[f][1] = T - S[f]` **赋值**（不是累加，因为 $(i,1)$ 只可能来自换点数），最后把 `dp[f][d]` 平移进 `ndp[f][d+1]`（$d<m_i$ 才平移）。
5. **剪枝即「不生成」**：$d$ 已到 $m_i$ 时根本不写 $d+1$ 那条边，非法状态从不入表，不需要「先生成再减掉」，也不会污染后续层。
6. **负数取模**：$T-S[i]$ 在模意义下可能为负，C++ 必须写 `(T - S[f] + MOD) % MOD`；Python 的 `%` 天然返回非负，可直接相减。
7. **数组列宽**：$d$ 最大为 $m_i\le 15$，第二维开到 16 即可；求和上界用 `rollMax[f]` 而不是写死 15。
8. **答案取最后一层**：中间层之和是「长度不超过 $n$」的计数，与题意不符，只对第 $n$ 层求和。

## 5. 正确性证明

**引理 1（无后效性）**：设 $P,P'$ 是两个长度为 $L$ 的合法前缀序列，末尾点数同为 $i$ 且末尾连续长度同为 $d$。则对任意后缀 $X\in[1,6]^{n-L}$，$P$ 接 $X$ 合法当且仅当 $P'$ 接 $X$ 合法。

**证明**：合法性只受「同一点数连续出现的次数不超过上限」约束。$P$ 与 $P'$ 的差异全部位于末尾那 $d$ 个 $i$ 之前；跨越拼接边界的任何连续段，其长度只由 $d$（以及与 $X$ 首元素的相等关系）决定，前缀内部各自已经合法。故两边的合法性条件逐位相同。∎

**引理 2（转移完备且不重不漏）**：第 $L$ 层的每个合法序列，恰好经过一条转移边被计入第 $L+1$ 层的唯一状态。

**证明**：设 $P$ 合法、下一掷为点数 $r$。若 $r=i$，由 $P$ 合法知 $d+1\le m_i$，转移把 $P$ 写入 $(i,d+1)$，且这条边只被「续掷」产生；若 $r\ne i$，则由 $(i,d)$ 的「换点数」边写入 $(r,1)$。两类边互斥，同一个新序列不会有第二条来源路径。批量公式中 $\text{ndp}[i][1]=T-S[i]$ 正是「末尾不是 $i$ 的序列全部接一个 $i$」，与逐边累加等价。∎

**引理 3（状态空间封闭）**：任何时刻都满足 $1\le d\le m_i$，$dp$ 中不会出现越界状态。

**证明**：初始化 $d=1\le m_i$。归纳地，续掷边仅在 $d<m_i$ 时产生 $d+1\le m_i$；换点数边产生 $d=1\ge 1$。故所有被写入的状态都在范围内。∎

**定理**：算法输出的值等于长度 $n$ 的合法序列数模 $10^9+7$。

**证明**：对长度归纳。$L=1$ 时 $dp[i][1]=1$，恰为 6 个长度为 1 的合法序列。设第 $L$ 层按状态精确计数了全部合法序列：由引理 2，第 $L+1$ 层每个状态的值等于「能一步到达它的合法前缀数」，不重不漏；由引理 3，不会产生非法状态。于是第 $L+1$ 层同样精确地对合法序列按状态分类计数。归纳成立后，第 $n$ 层按状态求和即长度 $n$ 的合法序列总数。全程对 $10^9+7$ 取模，保持同余关系，输出正确。∎

## 6. 复杂度分析

- **时间**：$O(n\cdot 6\cdot 15)$。每层计算 $S[i]$、$T$ 需要 $\sum_i m_i\le 90$ 次加法，平移 `ndp[f][d+1]` 同样至多 90 次加法，故每层 $O(90)$；$n\le 5000$ 时总量约 $4.5\times10^5$ 次运算，远低于时限。
- **空间**：$O(6\times 15)$。两个滚动的 $6\times 16$ 数组，共约 192 个 `int`，与 $n$ 无关。
- **对比**：暴力枚举要 $O(n\cdot 6^n)$；只记末尾点数、不记连续长度则会**丢失约束信息**，算出的结果偏大。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <array>
using namespace std;

class Solution {
public:
    int dieSimulator(int n, vector<int>& rollMax) {
        const int MOD = 1000000007;
        // dp[f][d]：长度为当前轮数、末尾恰好是连续 d 个点数 f+1 的方案数
        vector<array<int, 16>> dp(6);
        for (int f = 0; f < 6; ++f) dp[f][1] = 1;   // 只掷 1 次

        for (int len = 1; len < n; ++len) {
            vector<array<int, 16>> ndp(6);          // 全 0
            int total = 0;
            vector<int> sum(6, 0);
            for (int f = 0; f < 6; ++f) {
                for (int d = 1; d <= rollMax[f]; ++d)
                    sum[f] = (sum[f] + dp[f][d]) % MOD;
                total = (total + sum[f]) % MOD;
            }
            for (int f = 0; f < 6; ++f) {
                // 换点数：末尾段重置为 1，来自「末尾不是 f+1」的全部方案
                ndp[f][1] = (total - sum[f] + MOD) % MOD;
                // 续掷同一点数：末尾段长度 + 1，到顶则这条边不存在
                for (int d = 1; d < rollMax[f]; ++d)
                    ndp[f][d + 1] = dp[f][d];
            }
            dp.swap(ndp);
        }

        int ans = 0;
        for (int f = 0; f < 6; ++f)
            for (int d = 1; d <= rollMax[f]; ++d)
                ans = (ans + dp[f][d]) % MOD;
        return ans;
    }
};
```

### Python

```python
from typing import List


class Solution:
    def dieSimulator(self, n: int, rollMax: List[int]) -> int:
        MOD = 10 ** 9 + 7
        # dp[f][d]：长度为当前轮数、末尾恰好是连续 d 个点数 f + 1 的方案数
        dp = [[0] * 16 for _ in range(6)]
        for f in range(6):
            dp[f][1] = 1

        for _ in range(1, n):
            ndp = [[0] * 16 for _ in range(6)]
            sum_f = [0] * 6
            for f in range(6):
                sum_f[f] = sum(dp[f][1:rollMax[f] + 1]) % MOD
            total = sum(sum_f) % MOD
            for f in range(6):
                # 换点数：末尾段重置为 1
                ndp[f][1] = (total - sum_f[f]) % MOD
                # 续掷同一点数：末尾段长度 + 1
                for d in range(1, rollMax[f]):
                    ndp[f][d + 1] = dp[f][d]
            dp = ndp

        return sum(sum(dp[f][1:rollMax[f] + 1]) for f in range(6)) % MOD
```

## 8. 边界情况与易错点

1. **$n=1$**：主循环不执行，直接对初始层求和得 6；若把初始化写成「先置 0 再循环」，会错误返回 0。
2. **完全无约束**：`rollMax` 全为 15 且 $n\le 15$ 时答案就是 $6^n$，可用来快速自检取模是否写对（如 $n=3$ 应为 216）。
3. **上限全为 1**：相邻两掷必须不同，答案 $6\cdot 5^{n-1}$；$n=15$ 时为 621093498，并不会「很快变成 0」。若发现输出 0，说明续掷边或取模被写错。
4. **`ndp[f][1]` 用 `+=`**：$(i,1)$ 只可能来自「换点数」，写累加会在 $n>1$ 时重复计数（新数组未清零时还会叠加上一轮的残值）。
5. **模下负数**：`total - sum[f]` 在 C++ 里是负数取模，必须补 `+MOD`；Python 的 `%` 已保证非负。
6. **漏掉续掷剪枝**：$d=m_i$ 时若仍写 `ndp[f][d+1]`，就会把「连续 $m_i+1$ 次」的非法序列算进去，结果偏大。
7. **第二维开成 15**：$d$ 的取值可到 15，数组长度需为 16（下标 $0\ldots15$）；否则 `dp[f][15]` 越界。
8. **答案求和范围**：只对第 $n$ 层求和；把每层答案相加得到的是「长度不超过 $n$」的计数。

**延伸思考**：把「换点数」看成整体后，可以得到一个不需要 $d$ 维的容斥写法。设 $F_t^{(i)}$ 为长度 $t$、以点数 $i$ 结尾的合法序列数，$T_t=\sum_i F_t^{(i)}$，则

$$F_t^{(i)}=T_{t-1}-\left(T_{t-1-m_i}-F_{t-1-m_i}^{(i)}\right)$$

其中下标为 0 时约定 $T_0=1$、$F_0^{(i)}=0$，下标为负时括号取 0。它的含义是：接上 $i$ 会越界的，恰好是「末尾正好连续 $m_i$ 个 $i$」的那些序列，而它们等于「长度 $t-1-m_i$ 的任意合法序列」后接一整段 $i$。这样每层只需 $O(6)$，整体 $O(6n)$、空间 $O(n)$，并且天然支持「上限很大」的数据。若 $n$ 增大到 $10^{18}$，还可以把 90 个状态写成 $90\times90$ 的转移矩阵做快速幂，得到 $O(90^3\log n)$ 的解法。
