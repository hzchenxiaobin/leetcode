# LeetCode 最长快乐前缀 题解

## 1. 题目概述

- **标题 / 题号**：最长快乐前缀（#1392，hard）
- **链接**：https://leetcode.cn/problems/longest-happy-prefix/
- **来源**：LeetCode 第 181 场周赛 Q4
- **难度**：困难
- **标签**：字符串、KMP、前缀函数、字符串哈希、Z 函数（扩展 KMP）

**题意**：「快乐前缀」是原字符串 `s` 中既是**非空前缀**又是**后缀**、且**不等于 `s` 自身**的字符串。求 `s` 的最长快乐前缀；若不存在，返回空串 `""`。前后缀允许在原串中**重叠**。

**约束**：

- $1 \le n = \text{s.length} \le 10^5$
- `s` 只含有小写英文字母

> 💡 换个名字这题就不神秘了：既是真前缀又是后缀的串在字符串算法里叫做**边界（border）**，本题求的就是整个串的最长边界。而「每个前缀的最长边界长度」正是 KMP 的**前缀函数** $\pi$——所求即 $\pi[n-1]$，**定义即答案**。

## 2. 示例

**示例 1**

```text
输入：s = "level"
输出："l"
解释：除 s 自身外，前缀有 "l","le","lev","leve"，后缀有 "l","el","vel","evel"。
      同时出现在两侧的最长串是 "l"。
```

**示例 2**

```text
输入：s = "ababab"
输出："abab"
解释："abab" 既是前缀又是后缀，且前后缀允许在原串中重叠（中段 "ab" 被两侧共用）。
```

**示例 3**

```text
输入：s = "abc"
输出：""
解释：任何非空真前缀（"a","ab"）都不是后缀，答案为空串。
```

## 3. 解题思路

### 3.1 暴力思路

从长到短枚举长度 $L = n-1, n-2, \dots, 1$，逐个判断 $s[0:L]$ 是否等于 $s[n-L:n]$，取首个相等者：

```cpp
for (int L = n - 1; L >= 1; L--)
    if (s.substr(0, L) == s.substr(n - L, L)) return s.substr(0, L);
return "";
```

共 $O(n)$ 种长度、每次比较 $O(L)$，最坏 $O(n^2)$（全同串 `"aaaa…a"` 每次都比满）。$n = 10^5$ 时约 $10^{10}$ 次字符比较，必然超时。

> ⚠️ 瓶颈在于每次判等**从零开始**，完全没有复用「更短的前后缀相等」这条已验证的信息。

### 3.2 核心观察：π 数组的定义就是答案

![边界与 π 的定义](images/wc181_q4_border_concept.svg)

定义前缀函数（又称 failure function / LPS 数组）：

$$\pi[i] = \max\{\, k \mid 0 \le k \le i,\ s[0:k] = s[i+1-k:i+1] \,\}$$

即 $\pi[i]$ 是子串 $s[0..i]$ 的最长**边界**长度（$k \le i$ 保证是真前缀，天然排除子串自身）。取 $i = n-1$：$\pi[n-1]$ 就是整个串的最长快乐前缀长度，答案为 `s[0 : π[n-1]]`。问题从「枚举判等」变成「**如何 $O(n)$ 构造 $\pi$ 数组**」。

### 3.3 算法流程：π 的线性递推

![π 数组线性递推流程](images/wc181_q4_kmp_flow.svg)

递推只依赖两条性质（证明见 §5）：

1. **至多增长 1**：$\pi[i] \le \pi[i-1] + 1$——长度 $k$ 的边界去掉末位后，剩下长度 $k-1$ 的边界属于 $s[0..i-1]$；
2. **嵌套回退**：若 $s[i] \ne s[\pi[i-1]]$，下一个候选不是 $0$，而是 $\pi[\pi[i-1]-1]$——把「当前最长边界」换成**它自身的最长边界**，长度严格变小，逐层试探直到匹配或归零。

于是对每个 $i \in [1, n-1]$ 三步走：

1. **继承**：$j \leftarrow \pi[i-1]$；
2. **回退**：`while` $j > 0$ 且 $s[i] \ne s[j]$：$j \leftarrow \pi[j-1]$；
3. **扩展**：若 $s[i] = s[j]$ 则 $j \leftarrow j+1$；最后置 $\pi[i] = j$。

### 3.4 示例演算

![π 数组逐位递推演算](images/wc181_q4_pi_walkthrough.svg)

以 `s = "aabaab"` 为例（特意选了带一次回退的串）：$i=2$ 时 $j = \pi[1] = 1$，但 $s[2] = \texttt{b} \ne s[1] = \texttt{a}$，回退到 $j = \pi[0] = 0$ 后仍失配，故 $\pi[2] = 0$；其余各位顺利「继承 + 扩展」，最终 $\pi[5] = 3$，答案 `"aab"`。

对照两个题面示例：`"ababab"` 的 $\pi = [0,0,1,2,3,4]$，答案 `"abab"`（六位全程无回退）；`"level"` 的 $\pi = [0,0,0,0,1]$，答案 `"l"`。

### 3.5 备选做法：前缀哈希 / Z 函数

- **前缀哈希**：$O(n)$ 预处理多项式哈希后，每个长度 $L$ 的前后缀判等降为 $O(1)$，从大到小线性扫 $L$，取第一个相等者。
- **Z 函数（扩展 KMP）**：$z[i]$ 为 $s$ 与其后缀 $s[i:]$ 的最长公共前缀，则「长度 $L$ 的边界存在 $\iff z[n-L] \ge L$」，同样线性扫描。

> ⚠️ 两种做法都**只能线性扫、不能二分**：前后缀相等不具单调性。反例 `"abab"`：$L=2$ 可行（`"ab" = "ab"`），$L=1$ 反而不可行（`"a" ≠ "b"`）。

三者均为 $O(n)$，但 $\pi$ 递推是**确定性**算法——无哈希碰撞风险、与字符集大小无关、常数也小，以下以它为主。

## 4. 算法细节

1. **初值**：$\pi[0] = 0$（单字符没有非空真前缀）。
2. **继承步不可省**：$j$ 的初值取 $\pi[i-1]$ 而非 $0$，这是线性复杂度的关键——每一位都从「上一位置的最长边界」起跳，而非从头匹配。
3. **回退步访问 $\pi[j-1]$ 是安全的**：`while` 条件保证 $j \ge 1$ 时才读 $\pi[j-1]$；`j > 0` 与 `s[i] != s[j]` 的先后顺序（短路求值）防止越界。
4. **为什么必须存整个 $\pi$ 数组**：回退时 $j$ 可能跳到任意历史位置，需要随机访问 $\pi[j-1]$，故空间需 $O(n)$——这与 KMP 匹配时「模式串 $\pi$ 预处理后即可滚动匹配」的用法不同。
5. **只用末位**：本题最终只消费 $\pi[n-1]$，但中间所有位都必须先算出来，无法跳过。

## 5. 正确性证明

记 $B(t)$ 为子串 $t$ 的**边界长度集合**（含 $0$），$B(t)^+$ 为其中的正数部分。

**引理 1（边界链的嵌套刻画）**：设子串 $t$ 的最长边界长度 $b_1 > 0$，记 $p = t[0:b_1]$，则 $B(t)^+ = \{b_1\} \cup B(p)^+$。特别地，$t$ 的次长边界长度 $b_2 = \pi[b_1 - 1]$。

**证明**：先证「$k \in (0, b_1)$ 是 $t$ 的边界 $\Rightarrow$ $k$ 是 $p$ 的边界」。由 $k$ 是边界知 $t[0:k] = t[|t|-k:|t|]$；又 $t[0:b_1] = t[|t|-b_1:|t|]$，故 $t$ 的末 $k$ 个字符等于 $p$ 的末 $k$ 个字符，即 $t[|t|-k:|t|] = t[b_1-k:b_1]$。于是 $t[0:k] = t[b_1-k:b_1]$，$k$ 是 $p$ 的边界。再证反向：若 $t[0:k] = t[b_1-k:b_1]$（$k$ 是 $p$ 的边界），则 $t[b_1-k:b_1]$ 作为 $p$ 的末 $k$ 个字符、又作为 $t[0:b_1]$ 的末 $k$ 个字符，等于 $t$ 的末 $k$ 个字符 $t[|t|-k:|t|]$，故 $t[0:k] = t[|t|-k:|t|]$，$k$ 是 $t$ 的边界。两侧合起来即 $B(t)^+ \setminus \{b_1\} = B(p)^+$；而 $p$ 的最长边界长度按定义为 $\pi[b_1-1]$。∎

**引理 2（候选集刻画）**：$\pi[i] \ge 1$ 当且仅当存在 $k \in B(s[0..i-1])$ 使 $s[k] = s[i]$，且此时

$$\pi[i] = 1 + \max\{\, k \in B(s[0..i-1]) : s[k] = s[i] \,\}.$$

**证明**：若 $\pi[i] = m \ge 1$，则 $s[0:m] = s[i+1-m:i+1]$。去掉两串末字符得 $s[0:m-1] = s[i+1-m:i]$，即 $m-1 \in B(s[0..i-1])$；比较两串末字符得 $s[m-1] = s[i]$。反之，若 $k \in B(s[0..i-1])$ 且 $s[k] = s[i]$，即 $s[0:k] = s[i-k:i]$ 且末字符相同，在两侧各拼上 $s[i]$ 得 $s[0:k+1] = s[i-k:i+1]$，故 $k+1$ 是 $s[0..i]$ 的边界长度。两个方向合并即得最大值刻画。∎

**引理 3（递推正确性）**：设 $\pi[0..i-1]$ 均已正确算出，则 §3.3 的三步流程算出的 $\pi[i]$ 正确。

**证明**：流程中 $j$ 依次取值 $j_0 = \pi[i-1]$，$j_1 = \pi[j_0-1]$，$j_2 = \pi[j_1-1]$，…，$0$。对 $t = s[0..i-1]$ 反复应用引理 1，该序列恰为 $B(s[0..i-1])$ 的全部元素**从大到小**排列。由引理 2，$\pi[i] = 1 + $ 序列中第一个满足 $s[j] = s[i]$ 的 $j$（若存在）。流程的 `while` 恰在 $s[j] \ne s[i]$ 且 $j > 0$ 时前进到序列下一项，停在第一个满足 $s[j] = s[i]$ 的位置并执行 $j{+}{+}$，得 $j+1$；若一路失配到 $j = 0$ 仍有 $s[0] \ne s[i]$，则候选集为空，$\pi[i] = 0$。∎

**定理**：算法返回 `s` 的最长快乐前缀，总时间 $O(n)$。

**证明**：对 $i$ 归纳：$\pi[0] = 0$ 正确；由引理 3，若 $\pi[0..i-1]$ 正确则 $\pi[i]$ 正确。故整个 $\pi$ 数组正确。$\pi[n-1]$ 按定义是 $s$ 的最长边界长度，而「非空、真前缀、同时是后缀」恰为快乐前缀的定义，故 `s[0:π[n-1]]` 为所求（$\pi[n-1] = 0$ 时即空串）。复杂度：每轮 `if` 命中时 $j$ 至多 $+1$，全体轮次合计至多 $n-1$ 次增长；`while` 每迭代 $j$ 至少减 $1$（因 $\pi[j-1] \le j-1 < j$）且 $j$ 始终非负，故回退总次数 $\le$ 增长总次数 $\le n-1$。总比较次数 $O(n)$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。主循环 $n-1$ 轮；摊还上看，$j$ 的增长总额 $\le n-1$，每次 `while` 回退都消耗一次过去的增长，回退总额也 $\le n-1$，两者相加仍为线性。
- **空间复杂度**：$O(n)$，即 $\pi$ 数组。回退需要随机访问任意历史位置 $\pi[j-1]$，无法压缩；若只统计长度而不返回子串，输出本身也只需一个整数。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    string longestPrefix(string s) {
        int n = s.size();
        vector<int> pi(n, 0);
        for (int i = 1; i < n; i++) {
            int j = pi[i - 1];                // 继承
            while (j > 0 && s[i] != s[j])     // 回退
                j = pi[j - 1];
            if (s[i] == s[j])                 // 扩展
                j++;
            pi[i] = j;
        }
        return s.substr(0, pi[n - 1]);
    }
};
```

### Python

```python
class Solution:
    def longestPrefix(self, s: str) -> str:
        n = len(s)
        pi = [0] * n
        for i in range(1, n):
            j = pi[i - 1]                     # 继承
            while j > 0 and s[i] != s[j]:     # 回退
                j = pi[j - 1]
            if s[i] == s[j]:                  # 扩展
                j += 1
            pi[i] = j
        return s[: pi[-1]]
```

> 💡 两版骨架一致：逐位递推 $\pi$，失配时沿 $\pi$ 链逐层回退。Python 切片 `s[:pi[-1]]` 在 $\pi[-1] = 0$ 时自然返回空串；C++ `substr(0, 0)` 同理，均无需特判。

## 8. 边界情况与易错点

1. **$n = 1$**：单字符没有非空真前缀，答案必为 `""`；$\pi[0] = 0$ 自然覆盖。
2. **无快乐前缀**（如 `"abc"`）：$\pi[n-1] = 0$，返回空串，Python / C++ 的切片写法都天然正确。
3. **允许重叠**：`"ababab"` 的答案是 `"abab"`，长度可以超过 $n/2$；若下意识只查 $L \le n/2$ 会直接漏解。
4. **不能二分**：前后缀相等不单调（`"abab"`：$L=2$ 可行、$L=1$ 不可行），哈希 / Z 做法必须线性扫全部 $L$。
5. **`while` 的短路顺序**：`j > 0` 必须写在 `s[i] != s[j]` 之前——循环体内要读 `pi[j-1]`，$j = 0$ 时下标越界（C++ 中是未定义行为）。
6. **继承初值 `j = pi[i-1]` 不可写成 0**：写成 0 后「嵌套回退」被破坏，算出的不是最长边界——那是**答案错误**而不只是变慢。
7. **排除原串自身**：题目要求真前缀；$\pi$ 的定义保证 $\pi[n-1] \le n-1$，自动排除，无需手动特判。
8. **哈希做法的碰撞**：单模哈希理论上可被构造数据卡掉，双哈希更稳；$\pi$ 递推则完全确定。

**延伸思考**：

- 若要输出**所有**快乐前缀而非最长者？——沿 $\pi$ 链回溯：$\pi[n-1] \to \pi[\pi[n-1]-1] \to \pi[\pi[\pi[n-1]-1]-1] \to \dots$，链上每个正值都是一个快乐前缀（`"ababab"`：$4 \to 2 \to 0$，即 `"abab"` 与 `"ab"`）。
