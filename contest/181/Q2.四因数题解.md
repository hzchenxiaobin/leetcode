# LeetCode 四因数 题解

## 1. 题目概述

- **标题 / 题号**：四因数（#1390，medium）
- **链接**：https://leetcode.cn/problems/four-divisors/
- **来源**：LeetCode 第 181 场周赛 Q2
- **难度**：中等
- **标签**：数组、数学、筛法、质因数分解

**题意**：对 `nums` 中每个 $x$，若 $x$ 的因数个数**恰为 4**，就把 $x$ 的 4 个因数全部计入答案；否则忽略。返回所有被计入整数之和。重复元素**分别计算**（`[21,21]` 的答案是 $2 \times 32 = 64$）。

**约束**：
- $1 \le \text{nums.length} \le 10^4$
- $1 \le \text{nums}[i] \le 10^5$
- 返回值落在 32 位有符号整数内：实测单个数最大贡献 $150000$（$x = 99998$），乘以 $10^4$ 得 $1.5 \times 10^9$，已逼近 `INT_MAX`（见 §8）

> 💡 这题「数因数」只是外壳，真正的抓手是：**因数个数为 4 的整数只有两种质因数形态**。看出来以后，判断退化成常数次比较，连因数都不用列。

## 2. 示例

**示例 1**

```text
输入：nums = [21,4,7]
输出：32
解释：21 有 4 个因数：1, 3, 7, 21
      4 有 3 个因数：1, 2, 4
      7 有 2 个因数：1, 7
      答案仅为 21 的所有因数之和。
```

**示例 2**

```text
输入：nums = [21,21]
输出：64
解释：两个 21 各贡献 1+3+7+21 = 32，重复元素不能被去重。
```

**示例 3**

```text
输入：nums = [1,2,3,4,5]
输出：0
解释：1 有 1 个、2 和 3 各 2 个、4 有 3 个、5 有 2 个因数，都不满足。
```

## 3. 解题思路

### 3.1 暴力思路

对每个 $x$ 从 $1$ 试除到 $x$，能整除就把 $d$ 计入和并计数，最后看计数是否等于 4：

```cpp
int cnt = 0, s = 0;
for (int d = 1; d <= x; d++) if (x % d == 0) cnt++, s += d;
```

单个数 $O(x)$，全数组 $O(nM) = 10^4 \times 10^5 = 10^9$，超时。

注意到因数成对出现，只需枚举到 $\sqrt{x}$：每个 $d \mid x$ 连带得到 $x/d$，若 $d = x/d$（平方数）只计一次。计数超过 4 就立即放弃，复杂度 $O(n\sqrt{M}) \approx 3.2 \times 10^6$。这条路已经能过。

> ⚠️ 但它每次都要把「数一遍」重做，平方数去重与提前退出的边界也容易写错。下面换个从根上看问题的做法，连数都不用数。

### 3.2 核心观察：$\tau(x) = 4$ 只有两种形态

![四因数的两种质因数形态](images/wc181_q2_four_divisors_forms.svg)

设 $x = p_1^{e_1} p_2^{e_2} \cdots p_k^{e_k}$ 是标准分解，由乘法原理

$$\tau(x) = \prod_{i=1}^{k} (e_i + 1).$$

要让这个乘积等于 4，而 $4 = 4$、$4 = 2 \times 2$ 是**仅有的两种**乘法拆法：

1. 单质因子且 $e_1 = 3$：$x = p^3$，因数为 $1, p, p^2, p^3$，贡献 $1 + p + p^2 + p^3$；
2. 双质因子且 $e_1 = e_2 = 1$：$x = p \cdot q$（$p \ne q$），因数为 $1, p, q, pq$，贡献 $1 + p + q + pq = (1+p)(1+q)$。

反过来这两种形态的因数个数都恰为 4，所以判据是**充要**的。于是问题从「数因数」变成「**看指数向量长什么样**」。

顺手记住反面形态：$1 \to 1$、$p \to 2$、$p^2 \to 3$、$p^4 \to 5$、$p^2q \to 6$、$p^2q^2 \to 9$——都不是 4。

### 3.3 算法流程：一次埃氏筛 + 逐数分解

![SPF 筛与形态判断流程](images/wc181_q2_spf_flow.svg)

1. 取 $M = \max(\text{nums})$，筛到 $M$ 即可，不必固定筛到 $10^5$；
2. 埃氏筛出**最小质因子表**：初值 `spf[v] = v`，外层 $i$ 只枚举到 $\sqrt{M}$，内层从 $i^2$ 起按 $i$ 步进，并且**只在 `spf[j] == j` 时写入** $i$——每个合数因此只被自己的最小质因子标记一次；
3. 对每个 $x$：令 $t = x$，反复取 $p = \text{spf}[t]$ 并把 $t$ 中所有因子 $p$ 连除干净、记录指数 $e$，得到指数向量；
4. 按向量形状套公式：形态 $(3)$ 用 $1+p+p^2+p^3$；形态 $(1,1)$ 用 $(1+p)(1+q)$；其余跳过；
5. 累加后返回。

> 💡 筛是「一次性预处理」，分解是「按需求值」：$10^4$ 次询问全部落在 $O(\log x)$ 内，比每次重跑试除更稳，也更容易在赛后复用到别的题。

### 3.4 示例演算

![示例演算表](images/wc181_q2_walkthrough.svg)

以 `nums = [21,4,7]` 走一遍：

- $21 = 3 \cdot 7$，指数向量 $(1,1)$，贡献 $(1+3)(1+7) = 4 \times 8 = 32$；
- $4 = 2^2$，指数向量 $(2)$，$\tau = 3$，跳过；
- $7$ 是质数，指数向量 $(1)$，$\tau = 2$，跳过；

合计 $32$。`[21,21]` 中两个 21 各算一次，得 $64$。再看两个容易漏的正例：$8 = 2^3$ 贡献 $1+2+4+8 = 15$，$6 = 2 \cdot 3$ 贡献 $3 \times 4 = 12$——**$p^3$ 这一支最容易被忘记**。

### 3.5 备选做法

- **试除法**：对每个 $x$ 枚举 $d \le \sqrt{x}$ 成对计数，超过 4 即退出，$O(n\sqrt{M})$，空间 $O(1)$。
- **倍数筛**：令 `cnt[v]`、`sum[v]` 表示 $v$ 的因数个数与因数和，对每个 $d \in [1, M]$ 枚举其倍数 $m = d, 2d, \dots$ 执行 `cnt[m]++`、`sum[m] += d`，总 $O(M \log M) \approx 1.2 \times 10^6$，之后 $O(1)$ 查表。这是最短、最不容易写错的「纯筛法」路线。
- **Miller–Rabin + Pollard–Rho**：若 $nums[i]$ 放大到 $10^{18}$，筛法与试除都失效，但「形态判据」一个字都不用改，只把分解引擎换掉。

三条路在本题的数据范围内都能过；本节选 `spf`，是因为它同时练到「筛」与「分解」两个套路，代码也不长。

## 4. 算法细节

1. **`spf` 数组开 $M+1$，`spf[1]` 留 0**：分解循环以 `t > 1` 为界，天然不会踩到下标 1。
2. **每轮重新取 $p = \text{spf}[t]$**：剥离后 $t$ 变小，但 `spf` 表对区间内任意值都给出正确的最小质因子，不需要边分解边补筛。
3. **判形态直接比指数**：用「只有一个因子且指数为 3」「两个因子且指数均为 1」判断，不要先算 $\tau$ 再比 4——等价但多一步乘法，且写错乘法的概率更高。
4. **累加用 `long long`**：全数组上界 $1.5 \times 10^9$ 虽在 `int` 内，但余量不足三成；Python 天然大整数，无此问题。
5. **筛上界取 $M = \max(\text{nums})$**：小数据（如 `[1]`）时循环几乎不执行，比固定 $10^5$ 更省。
6. **可选剪枝**：$M < 6$ 时（最小可行数是 6）可直接返回 0，连筛都不必建。
7. **不要用 `set` 去重**：题目对重复元素各自计数，去重会直接把 `[21,21]` 算成 32；想省时间可以用 `memo` 缓存「数值 → 贡献」，语义不变。

## 5. 正确性证明

**引理 1（因数个数公式与 4 的形态刻画）**：若 $x = \prod_{i=1}^{k} p_i^{e_i}$ 是标准分解，则 $\tau(x) = \prod_i (e_i+1)$；且 $\tau(x) = 4$ 当且仅当 $x = p^3$ 或 $x = pq$（$p \ne q$ 为质数）。

**证明**：$x$ 的每个正因数唯一写成 $\prod_i p_i^{f_i}$，其中 $0 \le f_i \le e_i$，各 $f_i$ 独立选取，共 $\prod_i (e_i+1)$ 个。若该乘积等于 4，因每个因子 $\ge 2$，只能是「一个因子 4」（$k=1,\ e_1=3$）或「两个因子 2」（$k=2,\ e_1=e_2=1$）。反之 $p^3$ 给出 $4$ 个、$pq$ 给出 $2 \times 2 = 4$ 个因数。∎

**引理 2（因数和公式）**：$\sigma(p^3) = 1+p+p^2+p^3$，$\sigma(pq) = (1+p)(1+q)$。

**证明**：因数求和时各质因子的指数选择彼此独立，故 $\sigma(x) = \prod_i \left(1 + p_i + \dots + p_i^{e_i}\right)$。代入 $(e) = (3)$ 与 $(1,1)$ 即得两个式子。∎

**引理 3（`spf` 筛正确性）**：筛结束后对每个 $v \in [2, M]$，`spf[v]` 等于 $v$ 的最小质因子。

**证明**：先看标记规则。内层只在 $i$ 为质数时执行——$i$ 为质数时没有任何更小的质因子能标记它，故 `spf[i] == i` 成立；一旦某位置已被标记就拒绝覆盖，即**首次标记生效**。

任取合数 $v$，设其最小质因子为 $p$。$v/p$ 的质因子都 $\ge p$，故 $v/p \ge p$，即 $v \ge p^2$，于是 $p \le \sqrt{v} \le \sqrt{M}$，外层循环必枚举到 $i = p$；此时 $j$ 序列 $p^2, p^2+p, \dots$ 以步长 $p$ 覆盖 $v = p \cdot (v/p)$，故 $v$ 一定被标记。

再看写入值。任何标记 $v$ 的 $i$ 都是 $v$ 的质因子，而 $p$ 最小；外层 $i$ 递增，$p$ 最先到达，因此 $v$ 的首次标记必由 $p$ 完成，后续更大质因子的写入被 `spf[j] == j` 挡掉。质数不可能等于 $i \cdot k$（$i, k \ge 2$ 时必为合数），故永不被标记，保持初值 `spf[v] = v`。∎

**引理 4（分解完整）**：对任意 $x \ge 2$，§3.3 的剥离循环必终止于 $t = 1$，且输出的指数向量恰为 $x$ 的标准分解。

**证明**：循环不变量为 $x = t \cdot \prod_i p_i^{e_i}$（右侧为已记录部分）。每轮取 $p = \text{spf}[t]$ 并连除到不能整除，故记录的 $e$ 恰为 $p$ 在剩余 $t$ 中的指数；此后新 $t$ 的最小质因子严格大于 $p$，各个质因子按递增顺序各被处理恰好一次，无重复、无遗漏。又 $t$ 每轮至少折半，循环必然终止；终止时 $t = 1$，由不变式知分解完整。∎

**定理**：算法返回值等于题目所求之和，时间复杂度 $O(M \log \log M + n \log M)$。

**证明**：由引理 4，每个 $x$ 都得到正确的指数向量；由引理 1，「形态为 $(3)$ 或 $(1,1)$」与 $\tau(x) = 4$ 等价，故两个分支恰好筛出全部四因数数、不漏也不多；由引理 2，分支内累加的正是该数的全部因数之和。最后对 `nums` 逐元素累加，重复元素各被计一次，与题意一致。复杂度见 §6。∎

## 6. 复杂度分析

- **时间**：埃氏筛 $O(M \log \log M)$，$M \le 10^5$，写入量约 $3 \times 10^5$ 次；每个数的分解为 $O(\log x)$（不同质因子至多 $\log_2 x \approx 17$ 个，连除次数同量级），全数组 $O(n \log M)$。合计 $O(M \log \log M + n \log M)$，$10^4$ 个 $10^5$ 以内的数在毫秒级完成。
- **空间**：$O(M)$ 的 `spf` 表；指数向量长度不超过 $\log_2 x$，可视为 $O(1)$。若改用试除法，空间可降到 $O(1)$，代价是时间升到 $O(n\sqrt{M})$。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int sumFourDivisors(vector<int>& nums) {
        int M = 0;
        for (int x : nums) M = max(M, x);

        // 埃氏筛：spf[v] = v 的最小质因子
        vector<int> spf(M + 1, 0);
        for (int i = 2; i <= M; i++) spf[i] = i;
        for (int i = 2; (long long)i * i <= M; i++) {
            if (spf[i] != i) continue;              // i 是合数
            for (int j = i * i; j <= M; j += i)
                if (spf[j] == j) spf[j] = i;        // 首次被最小质因子标记
        }

        long long ans = 0;
        for (int x : nums) {
            vector<pair<int, int>> fac;             // (质因子, 指数)
            int t = x;
            while (t > 1) {
                int p = spf[t], e = 0;
                while (t % p == 0) { t /= p; e++; }
                fac.push_back({p, e});
            }
            if (fac.size() == 1 && fac[0].second == 3) {           // x = p^3
                long long p = fac[0].first;
                ans += 1 + p + p * p + p * p * p;
            } else if (fac.size() == 2 && fac[0].second == 1 && fac[1].second == 1) {
                long long p = fac[0].first, q = fac[1].first;      // x = p * q
                ans += (1 + p) * (1 + q);
            }
        }
        return (int)ans;
    }
};
```

### Python

```python
class Solution:
    def sumFourDivisors(self, nums: list[int]) -> int:
        M = max(nums)

        # 埃氏筛：spf[v] = v 的最小质因子
        spf = list(range(M + 1))
        i = 2
        while i * i <= M:
            if spf[i] == i:                        # i 是质数
                for j in range(i * i, M + 1, i):
                    if spf[j] == j:                # 只被最小质因子标记一次
                        spf[j] = i
            i += 1

        ans = 0
        for x in nums:
            t, fac = x, []
            while t > 1:
                p = spf[t]
                e = 0
                while t % p == 0:
                    t //= p
                    e += 1
                fac.append((p, e))
            if len(fac) == 1 and fac[0][1] == 3:                      # x = p^3
                p = fac[0][0]
                ans += 1 + p + p * p + p ** 3
            elif len(fac) == 2 and fac[0][1] == 1 and fac[1][1] == 1:  # x = p * q
                p, q = fac[0][0], fac[1][0]
                ans += (1 + p) * (1 + q)
        return ans
```

> 💡 两版骨架完全一致：筛一次 `spf`，再对每个数剥离质因子、按形态累加。$x = 1$ 时分解循环不进入，`fac` 为空，两个分支都不命中，自然贡献 0。

## 8. 边界情况与易错点

1. **$x = 1$**：$\tau(1) = 1$，分解为空、不命中任何分支。不要把它当成「0 个因数」而触发除零或死循环。
2. **重复元素不能去重**：`[21,21]` 的正确答案是 64。顺手加 `set` 去重就会错；用 `memo` 缓存「数值 → 贡献」则可以（语义不变，只是省时间）。
3. **漏掉 $p^3$ 这一支**：只记住 $p \cdot q$ 是最常见的错误，$8$、$27$、$29791 = 31^3$ 都会被漏算。
4. **把 $\tau = 3$ 当成 4**：$p^2$（如 4、9、49）只有 3 个因数，是最容易误判的形态；$p^4$ 则是 5 个。
5. **`int` 溢出风险**：单个数最大贡献 $150000$（$x = 99998 = 2 \cdot 49999$），$10^4$ 个这样的数合计 $1.5 \times 10^9$，距 `INT_MAX` $= 2147483647$ 只剩三成余量。本题恰好不溢出，但用 `long long` 累加是零成本保险。
6. **试除法备选时的平方数去重**：枚举 $d$ 到 $\sqrt{x}$ 时，若 $d = x/d$ 只能计一次，否则平方数的因数个数会被多算。
7. **`spf` 的初值与上界**：初值必须是 `spf[v] = v`（否则质数也被当作合数，分解死循环）；$M = 1$ 时数组长 2、循环不执行，同样安全。
8. **换数据范围就换引擎**：$M$ 固定筛 $10^5$ 能过，但若数据是稀疏的 $10^{12}$ 查询，筛法直接崩，需改用 Miller–Rabin + Pollard–Rho，而形态判据不变。

**延伸思考**：

- 若要求「因数个数恰为 $k$」？——把 $k$ 拆成若干 $\ge 2$ 的因子（第 $i$ 个因子 $f_i$ 对应指数 $e_i = f_i - 1$），每种拆法对应一族形态；$k$ 的乘法分拆数增长很快，但 $k \le 100$ 时枚举仍可行。
- 若要求「因数之和等于 $2x$」（完全数）？——形态判据失效，必须真的算 $\sigma(x)$，用乘积公式 $\prod_i (1 + p_i + \dots + p_i^{e_i})$ 而非逐个枚举因数。
- 若 `nums[i]` 放大到 $10^{12}$？——筛法失效，改为 Miller–Rabin 判素 + Pollard–Rho 分解，但「$\tau(x) = 4 \iff x = p^3$ 或 $x = pq$」一个字都不用改：这才是本题真正的知识点。
- 若要求返回**乘积**而非和？——$\sigma$ 换成连乘后溢出更快，通常需要取模；形态判断则完全不变。
