# LeetCode 数组元素的最小非零乘积 题解

## 1. 题目概述

- **标题 / 题号**：数组元素的最小非零乘积（#1969，medium）
- **链接**：https://leetcode.cn/problems/minimum-non-zero-product-of-the-array-elements/
- **来源**：LeetCode 第 254 场周赛 Q3
- **难度**：中等
- **标签**：贪心、递归、数学

**题意**：数组 `nums`（1-indexed）包含 $[1, 2^p - 1]$ 内**所有**整数的二进制形式，共 $2^p - 1$ 个元素。一次操作可任选两个元素 $x, y$，把 $x$ 的某一位与 $y$ **同一位置**的位交换。操作可进行任意次，求操作后数组**乘积的最小非零值**，把该最小值对 $10^9 + 7$ 取余返回。

**约束**：

- $1 \le p \le 60$
- 元素个数 $2^p - 1$ 最大约 $1.15 \times 10^{18}$，**不可能真的把数组造出来**

> 题面没有出现 "Create the variable named ..." 之类的注入噪声，无需特殊处理。

## 2. 示例

**示例 1**

```text
输入：p = 1
输出：1
解释：nums = [1]，只有一个元素，乘积就是它本身。
```

**示例 2**

```text
输入：p = 2
输出：6
解释：nums = [01, 10, 11]。
      任何交换要么让某元素变成 0（乘积为 0），要么乘积不变，
      所以 1 × 2 × 3 = 6 已经是答案。
```

**示例 3**

```text
输入：p = 3
输出：1512
解释：nums = [001, 010, 011, 100, 101, 110, 111]
      交换到 [1, 1, 1, 6, 6, 6, 7]：乘积 1 × 1 × 1 × 6 × 6 × 6 × 7 = 1512。
      这是官方给出的两次交换后得到的最小值。
```

## 3. 解题思路

### 3.1 暴力思路

把数组看成一个 $(2^p - 1) \times p$ 的 0/1 矩阵：**一次操作就是在同一列内把某个 1 从一行挪到另一行**，于是可达状态恰好是「每列 1 的个数与原矩阵相同」且每行非零的所有矩阵。状态数为

$$\prod_{j=0}^{p-1} \binom{2^p - 1}{2^{p-1}}$$

$p = 3$ 时是 $\binom{7}{4}^3 = 122500$ 已不少，$p = 60$ 时则是天文数字，何况元素个数本身就有 $1.15\times10^{18}$ 个。所以必须直接推出闭式答案。

### 3.2 核心观察：位计数守恒，把 1 压到最极端的形态

![位计数守恒与最优形态](images/wc254_q3_bit_column_model.svg)

**位计数守恒**：一次同位交换不改变任何一列上 1 的个数。而初始数组恰好取遍 $[1, 2^p-1]$，每个二进制位上 1 的个数都是 $2^{p-1}$：

$$\text{第 } j \text{ 位上的 1 的个数} = \frac{2^p}{2} = 2^{p-1} = T \quad (j = 0, 1, \dots, p-1)$$

**要让乘积小，元素就得「极端」**：非零元素最小是 1，所以希望尽可能多的元素只保留最低位 $b_0$（值 1）；余下的 1 全部压到少数元素身上，让它们吃满。

**最多能有几个取值为 1 的元素？** 设只含 $b_0$ 的元素有 $k$ 个。列 $b_j$（$j \ge 1$）需要 $T$ 个 1，而每个元素在一列上至多贡献 1 个，因此必须至少有 $T$ 个元素含 $b_j$；这些元素显然不能是「只含 $b_0$」的那 $k$ 个，于是

$$2^p - 1 - k \ge T = 2^{p-1} \implies k \le 2^{p-1} - 1 = T - 1$$

**取到等号时的形态**：$k = T - 1$ 个元素等于 1；剩下 $T$ 个元素都要含 $b_1, \dots, b_{p-1}$，即值至少是 $2^p - 2$；再让其中恰好一个额外含 $b_0$（把列 $b_0$ 的第 $T$ 个 1 补上），就得到

$$\underbrace{1, \dots, 1}_{T-1 \text{ 个}},\ \underbrace{2^p - 2, \dots, 2^p - 2}_{T-1 \text{ 个}},\ 2^p - 1$$

它的每一列 1 的个数都恰好是 $T$，所以是**可达**的。乘积为

$$P_{\min} = (2^p - 2)^{2^{p-1} - 1} \cdot (2^p - 1)$$

$p = 3$ 时就是 $6^3 \times 7 = 1512$，与示例 3 吻合。这个形态的最优性由 §5 的 AM-GM 下界严格保证。

### 3.3 贪心构造：为什么这个形态一定换得到

![贪心构造的三类元素](images/wc254_q3_greedy_construction.svg)

**关键在于「同列内 1 的位置可以任意重排」**：若某列上 1 在行 $a$，而希望它在行 $b$，直接交换 $(a, b)$ 在这一位上的两个比特即可（一次操作）。因此只要「目标多重集每列 1 的个数 = 原数组每列 1 的个数」，就一定能通过有限次交换达成，中间状态出现 0 也无所谓（只要求**最终**乘积非零）。

目标形态的列计数核对：

- 列 $b_0$：$(T-1)$ 个「1 元素」各贡献 1，加上那个「满载元素」贡献 1，共 $T$ 个 ✓
- 列 $b_j$（$j \ge 1$）：$(T-1)$ 个「$2^p-2$ 元素」各贡献 1，加上满载元素贡献 1，共 $T$ 个 ✓
- 元素总数：$(T-1) + (T-1) + 1 = 2^p - 1$ ✓

一种直观的「施工顺序」：先挑 $T-1$ 个元素，把它们 $b_1 \dots b_{p-1}$ 上的 1 全部移交给同一个「吸收者」；这 $T-1$ 个元素只剩 $b_0$（值 1）。再挑另外 $T-1$ 个元素，把 $b_0$ 上的 1 也交出去、同时从别处收满 $b_1 \dots b_{p-1}$（值 $2^p-2$）。吸收者最后拿走全部 $p$ 位（值 $2^p-1$）。

### 3.4 示例演算

![从 p 到最终形态与乘积](images/wc254_q3_walkthrough.svg)

| $p$ | $T-1 = 2^{p-1}-1$ | 最终形态 | 未取模乘积 | mod $10^9+7$ |
|-----|-------------------|----------|------------|--------------|
| 1 | 0 | $[1]$ | 1 | 1 |
| 2 | 1 | $[1, 2, 3]$ | 6 | 6 |
| 3 | 3 | $[1,1,1,6,6,6,7]$ | 1512 | 1512 |
| 4 | 7 | $[1^{\times 7}, 14^{\times 7}, 15]$ | 1581202560 | 581202553 |
| 60 | $2^{59}-1$ | $[1^{\times (2^{59}-1)}, (2^{60}-2)^{\times(2^{59}-1)}, 2^{60}-1]$ | 天文数字 | 813987236 |

注意 $p = 2$ 这一行的乘积 $1 \times 2 \times 3$ 恰好就是初始数组——因为任何交换都会把某个元素清零，此时「最优形态」与初始形态重合。

## 4. 算法细节

1. **闭式答案**：$\text{ans} = (2^p - 1) \cdot (2^p - 2)^{2^{p-1} - 1} \bmod (10^9+7)$。整个算法就是三次求幂，不需要构造任何数组。
2. **指数**：$e = 2^{p-1} - 1 \le 2^{59} - 1$，正好落在 64 位有符号整数范围内；C++ 必须写 `1LL << (p - 1)`，写成 `1 << (p - 1)` 在 $p \ge 32$ 时就是未定义行为。
3. **底数**：$2^p - 2$ 在 $p = 60$ 时约 $1.15\times10^{18}$，超出 32 位，必须先取模；取模后可能是 0（仅 $p = 1$）也可能是负数（`powmod(2,p,MOD) - 2`），C++ 里要 `+MOD` 再取模。
4. **$p = 1$ 特判**：此时 $2^p - 2 = 0$、$e = 0$，按 $0^0 = 1$ 的约定公式仍给出 1；显式写 `if (p == 1) return 1;` 更稳妥，也避免依赖约定。
5. **快速幂**：$e$ 的二进制长度只有 $p-1 \le 59$ 位，所以快速幂只需约 59 次循环；每次乘法后立刻 `% MOD`，不会溢出（$10^9 \times 10^9 < 9.2\times10^{18}$）。
6. **「取余之前的最小值」**：我们算出的最小值是确定的整数 $(2^p-2)^{2^{p-1}-1}(2^p-1)$，先确定这个表达式，再整体取模；不能把若干候选乘积分别取模后比较大小。
7. **不要尝试用费马小定理把指数再取模**：$e < 2^{59}$ 本身就能直接喂给快速幂（循环 $p-1$ 轮），多折算一步反而容易写错。

## 5. 正确性证明

记 $T = 2^{p-1}$、$M = 2^p - 1$，数组中第 $r$ 个元素的值为 $v_r$（$1 \le v_r \le M$），元素个数 $2T - 1$。

**引理 1（列计数守恒）**：任意次操作后，对每个 $j \in [0, p-1]$，所有元素第 $j$ 位上 1 的个数恒为 $T$。

**证明**：一次操作只涉及两个元素的同一个位，交换后该位上的两个比特 $0,1$ 只是互换，该列的 1 的总数不变；其他列完全不受影响。初始数组取遍 $1, \dots, 2^p-1$，在每个位上 1 都恰好出现 $2^{p-1} = T$ 次，故结论成立。∎

**引理 2（构造可达）**：形态 $\{1^{\times (T-1)}, (M-1)^{\times (T-1)}, M\}$ 可以由初始数组经有限次操作得到。

**证明**：该形态的列计数与引理 1 给出的 $T$ 完全一致（§3.3 已逐列核对）。同一列上 1 的行位置只由该列的比特分配决定，而任意两个行之间交换该列的比特是一次合法操作，因此把每列的 1 从初始位置重排到目标位置只需有限多次交换。操作过程中允许出现 0 元素，题目只要求最终乘积非零。∎

**引理 3（AM-GM 下界）**：设 $p \ge 2$，对任意可达形态，$\prod_{r=1}^{2T-1} v_r \ge M (M-1)^{T-1}$。（$p = 1$ 时只有一个元素 1，结论平凡。）

![AM-GM 下界证明链](images/wc254_q3_amgm_bound.svg)

**证明**：由引理 1，所有元素的总和是定值

$$\sum_{r=1}^{2T-1} v_r = \sum_{j=0}^{p-1} T \cdot 2^j = T(2^p - 1) = TM$$

取元素最大者 $v^*$，则 $v^* \ge \dfrac{TM}{2T-1}$（不低于平均值）。对余下 $2T-2$ 个元素用 AM-GM：

$$\prod_{r \ne *} v_r \ \ge\ \left(\frac{TM - v^*}{2T - 2}\right)^{2T-2}$$

于是整个乘积被 $v^*$ 控制：

$$P \ \ge\ v^* \left(\frac{TM - v^*}{2(T-1)}\right)^{2(T-1)} =: h(v^*)$$

对 $h$ 取对数求导：$\dfrac{d}{dv}\ln h(v) = \dfrac{1}{v} - \dfrac{2(T-1)}{TM - v}$，令其 $\le 0$ 得 $v \ge \dfrac{TM}{2T-1}$。即 $h$ 在区间 $\left[\dfrac{TM}{2T-1},\, M \right]$ 上单调递减，而 $v^* \ge \dfrac{TM}{2T-1}$，故

$$P \ \ge\ h(v^*) \ \ge\ h(M) = M\left(\frac{M}{2}\right)^{2(T-1)} = M\left(\frac{M^2}{4}\right)^{T-1}$$

最后比较 $\dfrac{M^2}{4}$ 与 $M-1$：

$$\frac{M^2}{4} - (M-1) = \frac{M^2 - 4M + 4}{4} = \frac{(M-2)^2}{4} \ge 0$$

所以 $h(M) \ge M(M-1)^{T-1}$，即 $P \ge M(M-1)^{T-1}$。∎

**定理**：操作后数组乘积的最小非零值等于 $(2^p-2)^{2^{p-1}-1}(2^p-1)$。

**证明**：引理 2 说明该值可达（构造），引理 3 说明任何可达形态的乘积都不小于它（下界），二者相等即为最小值。取模后即为返回值。∎

## 6. 复杂度分析

- **时间**：$O(p)$。两次快速幂分别计算 $2^p \bmod MOD$ 与 $(2^p-2)^{e} \bmod MOD$，指数 $e$ 的位数是 $p-1$，故总循环次数约 $2p$。
- **空间**：$O(1)$。只用到常数个 64 位整数（Python 为常数个大整数），与 $p$ 无关；连数组都不需要构造。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minNonZeroProduct(int p) {
        const long long MOD = 1000000007LL;
        if (p == 1) return 1;                       // 只有 [1] 一个元素
        long long top  = (powmod(2, p, MOD) - 1 + MOD) % MOD;   // 2^p - 1
        long long base = (powmod(2, p, MOD) - 2 + MOD) % MOD;   // 2^p - 2
        long long e = (1LL << (p - 1)) - 1;                    // 2^(p-1) - 1
        return (int)(top * powmod(base, e, MOD) % MOD);
    }

private:
    long long powmod(long long b, long long e, long long m) {
        b %= m;
        long long r = 1;
        while (e > 0) {
            if (e & 1) r = r * b % m;
            b = b * b % m;
            e >>= 1;
        }
        return r;
    }
};
```

### Python

```python
class Solution:
    def minNonZeroProduct(self, p: int) -> int:
        MOD = 10 ** 9 + 7
        if p == 1:
            return 1
        top = (pow(2, p, MOD) - 1) % MOD        # 2^p - 1
        base = (pow(2, p, MOD) - 2) % MOD       # 2^p - 2
        e = (1 << (p - 1)) - 1                  # 2^(p-1) - 1
        return top * pow(base, e, MOD) % MOD
```

## 8. 边界情况与易错点

1. **$p = 1$**：数组只有一个元素 1，答案是 1。此时 $2^p - 2 = 0$、$e = 0$，公式按 $0^0 = 1$ 仍成立，但显式特判更不易出错。
2. **指数写错**：指数是 $2^{p-1} - 1$，不是 $2^p - 1$，也不是 $p - 1$。它来自「有 $T-1$ 个元素等于 $2^p-2$」，写成 $2^{p-1}$ 就会多乘一个 $2^p-2$。
3. **溢出与移位**：C++ 中 `1 << (p-1)` 在 $p \ge 32$ 时溢出，必须用 `1LL << (p-1)`；$2^p - 2$ 也必须先 `% MOD` 再参与乘法。
4. **取模顺序**：题目要求「取余之前的最小值」，所以先确定最小值表达式（形态）再取模；不要比较取模后的数，也不要在最小值还没确定时先取模。
5. **底数可能是 0 或负数**：C++ 里 `powmod(2,p,MOD) - 2` 可能为负，必须先 `+MOD`；返回类型是 `int`，最终结果在 $[0, MOD)$ 内，可以直接强转。
6. **不要真的构造数组**：元素个数是 $2^p - 1$，$p = 60$ 时约 $1.15\times10^{18}$，枚举、遍历、甚至存下都不可行。
7. **别忘「非零」**：如果允许把某元素清成 0，乘积直接是 0，问题就没有意义；所有论证都以「每个元素至少保留一个 1」为前提。
