# LeetCode 你能穿过矩阵的最后一天 题解

## 1. 题目概述

- **标题 / 题号**：你能穿过矩阵的最后一天（#1970，hard）
- **链接**：https://leetcode.cn/problems/last-day-where-you-can-still-cross/
- **来源**：LeetCode 第 254 场周赛 Q4
- **难度**：困难
- **标签**：二分查找、广度优先搜索、并查集、矩阵、连通性

**题意**：给定 $row \times col$ 的网格，第 0 天**全部是陆地**；此后每一天都会把一块陆地淹没成水域——第 $i$ 天淹没 `cells[i-1]` 所指的格子（数组 0-indexed，坐标 1-indexed），每天恰淹一格、坐标互不重复。称某天「能过河」，如果该天淹没完成后，从**第一行**的任意陆地格出发、沿上下左右四方向只走陆地格，能到达**最后一行**的任意陆地格。求仍能过河的**最后一天**。

**约束**：

- $2 \le row, col \le 2 \times 10^4$
- $4 \le row \times col \le 2 \times 10^4$，即格子总数 $n = row \cdot col \le 2 \times 10^4$
- `cells.length == row * col`，坐标互不相同 → 恰好在第 $n$ 天全部淹完
- 矩阵形状可以**极不对称**（如 $2 \times 10^4 \times 2$ 的长条），不要假设长宽接近

> 💡 本题在本仓库另有[每日题解 1970](../../solution/1901-2000/1970_你能穿过矩阵的最后一天.md)：那边以「逆向并查集」为主线，配面试问答与同类练习表。本篇按周赛复盘视角，以赛场的决策链「暴力超时 → 单调性 → 二分保底 → 逆向并查集优化」为主线，重点补全引理-定理化的严格证明（第 1 天恒可通行的列绕行论证、二分不变式的归纳、并查集刻画的归纳证明）与二分的逐步演算。两篇互为印证。

## 3. 解题思路

### 3.1 暴力思路：逐天 BFS

从第 1 天到第 $n$ 天逐天模拟：每天淹掉 `cells[i]` 后，从顶行所有陆地格出发做一次 BFS / DFS，判断能否到底行，记录最后一次「能到」的天数。

- **正确性**：穷举每一天、每次做完整连通判定，显然正确。
- **复杂度**：共 $n = row \cdot col \le 2\times 10^4$ 天，每趟判定 $O(n)$，总计 $O(n^2) = 4 \times 10^8$，**会超时**。
- **浪费所在**：相邻两天的矩阵只差一个格子，却整图重算；而且绝大多数天结果与前几天相同，全部重判毫无必要。

### 3.2 核心观察一：通行性随天数单调 → 二分答案

被淹格子集合**只增不减**，陆地集合只减不增。于是「能过河」关于天数是一个**单调布尔函数**：先全真、后全假，分界点唯一。所求「最后一天」正是**最后一个真**——这是二分答案的教科书形态。

![通行性随天数单调递减与二分答案示意图](images/wc254_q4_monotone_binary_search.svg)

于是把问题拆成两半：

1. **单调性**保证可二分（引理 1、引理 2，见 §5）；
2. **判定** $\text{crossable}(d)$：淹没前 $d$ 格后，从顶行所有陆地格**多源 BFS**，能触到底行即为真，单次 $O(row \cdot col)$。

> 💡 **一句话总结**：天数越多水越多、路越难走——「能过河」先真后假，对天数二分 + 每轮一次 BFS，$O(row \cdot col \cdot \log(row \cdot col)) \approx 3 \times 10^5$，赛场上这是最先能写出来的**保底正解**。

### 3.3 核心观察二：时间倒流「退洪」+ 并查集，删点变加点

二分每轮仍要**重建整图**。能否一次性线性解决？障碍在于：正向上「每天淹一格」是从图里**删点**，可能把一个连通块拆成多块——而并查集只会 `union`（合并）、不会 `split`（拆分），正向维护无能为力。

那就把时间倒过来：从「全部被淹」的终态出发，**倒序把格子一块块补回成陆地**。这样每一步都是**加点**，恰好落在并查集的能力范围内——与 [803. 打砖块](https://leetcode.cn/problems/bricks-falling-when-hit/) 的逆向并查集完全同构。

再加一个经典配件：**虚拟源汇**。设两个虚拟节点 TOP、BOT，把「整行 ↔ 整行」的连通折叠成「点 ↔ 点」的同根判断：

- 恢复的格子若在**顶行**，`union` 进 TOP；
- 恢复的格子若在**底行**，`union` 进 BOT；
- 恢复的格子与**已恢复的**四邻互相 `union`。

倒序过程中陆地只增不减，顶底一旦连通就永远连通，所以**首次** $find(TOP) == find(BOT)$ 的时刻，对应的就是最晚还能过河的那一天（定理 2，见 §5）。

![时间倒流与并查集虚拟源汇模型示意图](images/wc254_q4_reverse_uf_model.svg)

> ⚠️ 注意倒序下标与天数的对应：倒序处理到数组下标 $i$（即恢复 `cells[i]`）后，被淹集合恰为 $\{cells[0..i-1]\}$——这正是**第 $i$ 天**结束的状态，此时首次连通则**答案就是 $i$**（不是 $i+1$）。

### 3.4 算法流程

**方法一（二分 + BFS）**

```text
1. 令 lo = 1（第 1 天恒可过河，引理 3），hi = n − 1（第 n 天全淹必不能过）
2. 循环直到 lo == hi：
   a. mid = (lo + hi + 1) / 2          ← 上取整，找「最后一个真」
   b. 淹没 cells[0..mid−1]，从顶行所有陆地格多源 BFS
   c. 触到底行 → lo = mid；否则 → hi = mid − 1
3. 返回 lo
```

**方法二（逆向并查集）**

```text
1. n = row·col；并查集开 n + 2 个节点；land[] 全 false；TOP = n，BOT = n + 1
2. for i = n−1 downto 0:
   a. (r, c) = cells[i] 坐标减 1；land[id] = true
   b. 对四邻 (nr, nc)：界内且已恢复 → union(id(r,c), id(nr,nc))
   c. r == 0 → union(id, TOP)；r == row−1 → union(id, BOT)
   d. 若 find(TOP) == find(BOT) → 返回 i
3. 理论上不可达（第 1 天恒可过河），兜底返回 0
```

### 3.5 示例演算

以**示例 3**（$3\times 3$，$n=9$）为例。先看两个关键天数的网格状态：

![示例三第三天与第四天的连通状态演算图](images/wc254_q4_example_walkthrough.svg)

**方法一：二分的完整轨迹**（$lo=1$，$hi=8$）：

| 轮次 | lo | hi | mid | 判定 | 动作 |
|------|----|----|-----|------|------|
| 初始 | 1 | 8 | — | — | — |
| 1 | 1 | 8 | 5 | $\text{crossable}(5) = \text{✗}$（顶行仅剩 $(1,3)$，走到 $(2,3)$ 即死路） | $hi = 4$ |
| 2 | 1 | 4 | 3 | $\text{crossable}(3) = \text{✓}$（$(1,3)\to(2,3)\to(2,2)\to(3,2)$） | $lo = 3$ |
| 3 | 3 | 4 | 4 | $\text{crossable}(4) = \text{✗}$（再淹 $(2,2)$，桥断） | $hi = 3$ |
| 结束 | 3 | 3 | — | — | 返回 **3** ✓ |

仅需 3 次判定，每次 $O(row \cdot col)$。

**方法二：逆向并查集的推进**：倒序先恢复 $(3,2),(3,1),(2,3),(1,3),(1,1)$——底簇 $\{(3,1),(3,2)\}$ 并入 BOT、顶簇 $\{(1,3),(2,3),(1,1)\}$ 并入 TOP，两簇始终分离；直到 $i=3$ 恢复 $(2,2)$，它的四邻中 $(2,3)$ 属顶簇、$(3,2)$ 属底簇，两次 `union` 把顶底**缝成一片**，$find(TOP)==find(BOT)$ 成立，返回 3。桥未必在顶 / 底行——$(2,2)$ 正是中行的「桥梁格」。

## 4. 算法细节

1. **一维编号与虚拟节点**：格子 $(r,c)$（0-indexed）编号 $id = r \cdot col + c \in [0, n)$；虚拟节点 $TOP = n$、$BOT = n+1$，并查集容量 $n + 2$。
2. **天数 ↔ 下标换算**：第 $d$ 天淹没 `cells[d-1]`；「第 $d$ 天状态」= 已淹 $\{cells[0..d-1]\}$。逆向循环处理完下标 $i$ 恰为第 $i$ 天状态，**返回的就是 $i$ 本身**，极易 off-by-one。
3. **二分「最后一个真」模板**：`mid` 必须**上取整** $(lo+hi+1)/2$，真则 `lo = mid`。若写成下取整且真分支 `lo = mid`，当 $hi = lo+1$ 时 $mid = lo$ 会死循环。
4. **判定用多源 BFS**：起点是顶行**所有**陆地格同时入队（第 1 天顶行可能已被淹掉一格）；矩阵原地标记已访问（走过即置水），免开 `visited`；出队时判 $r == row-1$ 提前返回真。
5. **并查集只与「已恢复」的邻居合并**：用 `land` 布尔数组标记，判「界内」不等于判「是陆地」，误合并水域会得出偏大的答案。
6. **顶 / 底行的强制合并**：恢复顶行格必 `union` TOP、底行格必 `union` BOT。由 $row \ge 2$ 知顶底两行不重合，TOP、BOT 各自独立；若变体允许 $row = 1$ 需另行特判。
7. **`find` 写法**：迭代 + 隔代压缩 `parent[x] = parent[parent[x]]`，Python 可规避递归栈风险；$n \le 2\times 10^4$ 规模下单用路径压缩已够，无需按秩合并。
8. **上界微优化（非必需）**：顶底路径每步行号至多变 1，至少含 $row$ 个格子，故能过河需要 $n - d \ge row$，即答案 $\le n - row$；二分的 $hi$ 可收紧到 $n - row$。

## 5. 正确性证明

记全集 $\Omega$ 为全部 $n$ 个格子，$F(d)$ 为第 $d$ 天结束后被淹的格子集合，$L(d) = \Omega \setminus F(d)$ 为陆地集合，$\text{crossable}(d)$ 表示第 $d$ 天能否过河。

**引理 1（淹没集单调扩张）**：$F(1) \subseteq F(2) \subseteq \cdots \subseteq F(n)$，相应地 $L(1) \supseteq L(2) \supseteq \cdots \supseteq L(n)$。

**证明**：$F(d+1) = F(d) \cup \{cells[d]\} \supseteq F(d)$；对补集，包含关系反向。∎

**引理 2（通行性单调不增）**：若 $\text{crossable}(d)$ 为真，则对一切 $1 \le d' \le d$，$\text{crossable}(d')$ 为真。

**证明**：第 $d$ 天的顶底路径是 $L(d)$ 中一串四相邻的格子。由引理 1，$L(d') \supseteq L(d)$，该路径的每个格子仍在 $L(d')$ 中，故仍是 $d'$ 天的合法路径。∎

**推论 1**：$\text{crossable}$ 序列呈「先全真、后全假」形态，答案 = 其中最后一个真的下标。

**引理 3（第 1 天恒可通行）**：对 $row, col \ge 2$，$\text{crossable}(1)$ 恒为真。

**证明**：第 1 天仅淹没 $cells[0] = (r_1, c_1)$。由 $col \ge 2$ 可取 $c' \ne c_1$，整列 $(1,c'), (2,c'), \dots, (row,c')$ 全是陆地，构成从顶行直通底行的四连通路径。∎

**注（答案上界）**：顶底路径每步行号至多变 1，至少含 $row$ 个格子（$row \ge 2$），故 $\text{crossable}(d)$ 为真要求 $|L(d)| = n - d \ge row$，即答案 $\le n - row$；特别地 $\text{crossable}(n)$ 恒假。

**定理 1（二分解法正确性）**：以 $lo = 1$、$hi = n-1$ 执行 §3.4 方法一的循环，返回值等于答案。

**证明**：循环维持不变式：$\text{crossable}(lo)$ 为真，且一切 $j > hi$ 有 $\text{crossable}(j)$ 为假。初始时前者由引理 3 保证，后者由上界注保证（$j > n-1$ 即 $j = n$）。每轮 $mid \in (lo, hi]$：若真，令 $lo = mid$，不变式两半保持；若假，由引理 2 的一切 $j \ge mid$ 均假，令 $hi = mid - 1$ 后不变式保持。又 $mid \ge lo + 1$ 保证区间严格缩小、不漏解，循环必终止于 $lo = hi$。此时 $\text{crossable}(lo)$ 真且更大下标全假，$lo$ 即最后一个真 = 答案。∎

**引理 4（并查集刻画）**：逆向过程中的任一时刻，设已恢复格子集 $S$，在 $S$ 上按四邻接关系连边得诱导图 $G[S]$。则 DSU 中两个普通节点同根，当且仅当它们在 $G[S]$ 中连通；TOP（BOT）与某格同根，当且仅当该格与某一顶行（底行）已恢复格在 $G[S]$ 中连通。

**证明**：对恢复次数归纳。恢复 0 次时 $S = \varnothing$，各节点自成一簇，平凡成立。设对 $S$ 成立，恢复 $v$ 后 $S' = S \cup \{v\}$：算法执行 `union(v, 每个已恢复四邻)`，由归纳假设这恰把 $v$ 并入所有与它相邻的连通块，得到 $G[S']$ 中 $v$ 所在的新连通块，其余块不变；若 $v$ 在顶行，额外 `union(v, TOP)` 恰把 TOP 并入 $v$ 所在块（$v$ 自身即顶行格），底行同理。归纳完成。∎

**定理 2（逆向并查集正确性）**：倒序循环中，处理完下标 $i$ 后**首次**出现 $find(TOP) == find(BOT)$，则答案为 $i$。

**证明**：恢复 $cells[i]$ 后，已淹集合为 $\{cells[0..i-1]\}$，恰为第 $i$ 天结束的状态。由引理 4，此刻 TOP 与 BOT 同根当且仅当当前陆地中存在顶行到底行的连通路径，即 $\text{crossable}(i)$ 为真。而循环按 $i$ 从大到小处理，此前每次检查（对应 $j > i$ 各天）均未连通，即 $\text{crossable}(j)$ 对一切 $j > i$ 为假。故 $i$ 是最后一个能过河的天数，即答案。又由引理 3，循环必在 $i \ge 1$ 时返回，不会落到兜底的 `return 0`。∎

## 6. 复杂度分析

- **方法一（二分 + BFS）**
  - 时间：$O(row \cdot col \cdot \log(row \cdot col))$。单次判定 = 建图 $O(d)$ + 多源 BFS $O(row \cdot col)$，均为 $O(n)$；二分轮数 $\lceil \log_2 n \rceil \le \lceil \log_2 2\times 10^4 \rceil = 15$，总计约 $3 \times 10^5$ 次基本操作。
  - 空间：$O(row \cdot col)$，判定用的网格矩阵。
- **方法二（逆向并查集）**
  - 时间：$O(row \cdot col \cdot \alpha(row \cdot col)) \approx O(n)$。$n$ 次恢复，每次至多 6 回 `union`（四邻 + 两个虚拟节点）与一次同根检查，均摊近常数。
  - 空间：$O(row \cdot col)$，`parent`（$n+2$）与 `land` 标记。
- **对比**：$n \le 2\times 10^4$ 时两者都远低于时限；二分胜在**思路直、编码快**，是赛场保底；并查集胜在**一遍线性、常数小**，是复盘后的最优解。

## 7. 参考代码

### C++（方法一：二分 + 多源 BFS）

```cpp
class Solution {
  public:
    int latestDayToCross(int row, int col, vector<vector<int>>& cells) {
        int lo = 1, hi = (int)cells.size() - 1;   // 引理3: 第1天恒真; 第n天全淹恒假
        while (lo < hi) {
            int mid = lo + (hi - lo + 1) / 2;     // 上取整: 找「最后一个真」
            if (canCross(row, col, cells, mid)) {
                lo = mid;
            } else {
                hi = mid - 1;
            }
        }
        return lo;
    }

  private:
    // 判定: 淹没前 day 格后, 能否从顶行走到底行
    bool canCross(int row, int col, vector<vector<int>>& cells, int day) {
        vector<vector<int>> g(row, vector<int>(col, 0));   // 0 = 陆地
        for (int i = 0; i < day; i++) {
            g[cells[i][0] - 1][cells[i][1] - 1] = 1;        // 坐标 1-indexed -> 0-indexed
        }
        queue<pair<int, int>> q;
        for (int c = 0; c < col; c++) {
            if (g[0][c] == 0) { g[0][c] = 1; q.push({0, c}); }  // 顶行多源起手, 原地标记
        }
        static const int dr[4] = {-1, 1, 0, 0};
        static const int dc[4] = {0, 0, -1, 1};
        while (!q.empty()) {
            auto [r, c] = q.front();
            q.pop();
            if (r == row - 1) return true;                  // 触到底行
            for (int k = 0; k < 4; k++) {
                int nr = r + dr[k], nc = c + dc[k];
                if (nr >= 0 && nr < row && nc >= 0 && nc < col && g[nr][nc] == 0) {
                    g[nr][nc] = 1;
                    q.push({nr, nc});
                }
            }
        }
        return false;
    }
};
```

### Python（方法二：逆向并查集）

```python
class Solution:
    def latestDayToCross(self, row: int, col: int, cells: List[List[int]]) -> int:
        n = row * col
        parent = list(range(n + 2))
        land = [False] * n
        TOP, BOT = n, n + 1

        def find(x: int) -> int:          # 迭代 + 隔代压缩, 防递归栈风险
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x

        def union(a: int, b: int) -> None:
            ra, rb = find(a), find(b)
            if ra != rb:
                parent[ra] = rb

        for i in range(n - 1, -1, -1):    # 时间倒流: 逐格恢复陆地
            r, c = cells[i][0] - 1, cells[i][1] - 1
            cur = r * col + c
            land[cur] = True
            for nr, nc in ((r - 1, c), (r + 1, c), (r, c - 1), (r, c + 1)):
                if 0 <= nr < row and 0 <= nc < col and land[nr * col + nc]:
                    union(cur, nr * col + nc)      # 只与已恢复的邻居合并
            if r == 0:
                union(cur, TOP)                    # 顶行格并入虚拟源
            if r == row - 1:
                union(cur, BOT)                    # 底行格并入虚拟汇
            if find(TOP) == find(BOT):
                return i                           # 恢复 cells[i] 后即第 i 天的状态
        return 0                                   # 引理3保证不会到达
```

## 8. 边界情况与易错点

1. **天数与下标错位（最常见 WA）**：`cells` 坐标 1-indexed（编码要减 1），数组本身 0-indexed，第 $d$ 天淹没 `cells[d-1]`；逆向并查集**返回下标 $i$ 本身**（恢复 `cells[i]` 后是第 $i$ 天状态），误写成 `i + 1` 会偏大一天。
2. **二分死循环**：求「最后一个真」必须 `mid` 上取整、真分支 `lo = mid`；两者配错任意一个都会死循环或漏解。
3. **二分下界必须落在恒真处**：$lo = 1$ 依赖引理 3（整列绕行），不要随手写 $lo = 0$（「第 0 天」不在问题域）；上界 $n-1$ 依赖全淹必假。
4. **多源 BFS 不能只从一个顶行格出发**：第 1 天起顶行就可能有格子被淹，起点必须是顶行**所有**现存陆地格。
5. **并查集误合并水域**：`union` 前必须检查邻居 `land == true`；「在界内」不等于「已恢复」。
6. **长条形矩阵**：$row = 2\times 10^4, col = 2$（或反之）都是合法输入，编号公式 $id = r \cdot col + c$、BFS 邻界判断对两种方向都成立，不要默认 $col$ 是小边。
7. **顶底同行的退化**：$row \ge 2$ 保证 TOP、BOT 挂接的两行不同，本题无需特判；变体若允许 $row = 1$ 则「顶行 = 底行」，虚拟源汇会直接退化，需另行处理。
8. **答案规模的 sanity check**：能过河至少要剩 $row$ 块陆地，故答案 $\le n - row$；小数据验证时可用它快速发现 off-by-one。
9. **Python 递归版 `find` 的栈风险**：路径压缩前长链可能触发递归上限，建议迭代 + 隔代压缩（参考代码即如此）。
