# LeetCode 作为子字符串出现在单词中的字符串数目 题解

## 1. 题目概述

- **标题 / 题号**：作为子字符串出现在单词中的字符串数目（#1967，easy）
- **链接**：https://leetcode.cn/problems/number-of-strings-that-appear-as-substrings-in-word/
- **来源**：LeetCode 第 254 场周赛 Q1
- **难度**：简单
- **标签**：数组、字符串

**题意**：给定字符串数组 $patterns$ 与字符串 $word$，统计 $patterns$ 中有多少个字符串是 $word$ 的**子字符串**（**连续**字符序列），返回命中的数目。

**约束**：

- $1 \le patterns.length \le 100$
- $1 \le patterns[i].length \le 100$
- $1 \le word.length \le 100$
- $patterns[i]$ 与 $word$ 仅由小写英文字母组成

> 💡 本题在本仓库另有[每日题解 1967](../../solution/1901-2000/1967_作为子字符串出现在单词中的字符串数目.md)：那边侧重审题四关键、库函数与手写朴素查找的三版代码对照、KMP / AC 自动机扩展与面试问答。本篇按周赛复盘视角，聚焦**签到题的最短路径**——从题面到 AC 代码只隔一次库函数调用，并补全「起点枚举完备性」的引理-定理证明与赛场易错点。

## 2. 示例

**示例 1**

```text
输入：patterns = ["a","abc","bc","d"], word = "abc"
输出：3
解释："a"、"abc"、"bc" 都是 "abc" 的子字符串，"d" 不是。
```

**示例 2**

```text
输入：patterns = ["a","b","c"], word = "aaaaabbbbb"
输出：2
解释："a"、"b" 命中，"c" 未命中。
```

**示例 3**

```text
输入：patterns = ["a","a","a"], word = "ab"
输出：3
解释：三个相同的 "a" 各自命中——按位置计数，不能去重。
```

## 3. 解题思路

### 3.1 朴素思路：逐 pattern 枚举起点

对每个 $p \in patterns$，枚举 $word$ 中所有可能的起点 $i \in [0,\ |word| - |p|]$，逐一比对 $word[i..i+|p|-1]$ 是否等于 $p$，命中任意起点即计数。总时间 $O\!\left(\sum_i |patterns[i]| \cdot |word|\right)$，最坏 $100 \times 100 \times 100 = 10^6$ 次字符比对，瞬时 AC——数据范围已经明示**暴力足够**。

> ⚠️ 赛场视角：这题的「坑」不在算法，而在**审题**（不去重、子串连续）与**语言细节**（C++ 无符号 `npos`）。把子串查找交给库函数，是从题面到 AC 的最短且最不易错的路径。

### 3.2 核心观察：判定相互独立 + 库函数子串查找

![核心观察：每个 pattern 独立判定并计数](images/wc254_q1_substring_concept.svg)

- **判定独立**：每个 $patterns[i]$ 是否为 $word$ 的子串是一个独立的 yes/no 问题，某个 pattern 命中与否不影响其他 pattern，因此无需任何预处理或数据结构，逐个判定即可。
- **库函数即答案**：子串查找是标准原语——C++ 的 `word.find(p) != string::npos`、Python 的 `p in word`，把「枚举起点 + 逐字符比对」封装成一次调用，代码更短、实现更稳。
- **不能去重**：示例 3 表明重复 pattern 各自计数（三个 "a" → 3），**禁止 set 去重**。

$$\text{ans} = \sum_{p \in patterns} \mathbb{1}[\,p \text{ 是 } word \text{ 的子串}\,]$$

> 💡 **为什么不预计算 word 的所有子串？** 预生成全部子串需 $O(|word|^2)$ 个串，而查询次数一点没少，纯属负优化。仅当 $|patterns| \gg |word|^2$ 时才有微弱收益。

### 3.3 算法流程

![算法流程：遍历 patterns 并对每个 pattern 做库函数子串判定](images/wc254_q1_algorithm_flow.svg)

「遍历 + 判定 + 累加」的线性流程：初始化 $count = 0$；遍历每个 $p \in patterns$，若 `p in word` 则 $count{+}{+}$；遍历结束返回 $count$。注意本题是**计数型**——必须看完所有 pattern 才能得出总数，与判定型「命中即 return」不同，**不能提前退出**。

### 3.4 示例演算

![示例演算：逐 pattern 对齐 word 并计数](images/wc254_q1_example_walkthrough.svg)

以示例 1 为例（$word = $ "abc"）：

| pattern | 匹配位置 | 命中? | count |
|---------|----------|-------|-------|
| "a" | $word[0:1]$ | ✓ | 1 |
| "abc" | $word[0:3]$（整串是自身的子串） | ✓ | 2 |
| "bc" | $word[1:3]$ | ✓ | 3 |
| "d" | — | ✗ | 3 |

最终返回 $3$。示例 3（三个 "a"，$word = $ "ab"）则验证「重复各自计数」：$count = 3$ 而非去重后的 $1$。

## 4. 算法细节

1. **判定入口**：C++ 用 `word.find(p)`，返回首次匹配下标（`size_t` 无符号），未命中返回 `string::npos`，判定式必须写 `!= string::npos`；Python 用 `p in word` 直接返回布尔值，`sum(...)` 可对布尔序列求和。
2. **无需特判 $|p| > |word|$**：起点区间 $[0, |word|-|p|]$ 为空，`find` / `in` 天然返回未命中。
3. **无需预计算子串集合**：见 §3.2 的 blockquote，属负优化。
4. **手写朴素版**（若面试官禁用库函数）：双层循环枚举起点 + 逐字符比对；Python 可用切片 `w[i:i+m] == p`（临时空间 $O(|p|)$）。

## 5. 正确性证明

**引理 1（判定等价）**：$p$ 是 $word$ 的子串 $\iff$ 存在起点 $i \in [0,\ |word| - |p|]$，使得 $word[i..i+|p|-1] = p$。

**证明**：（⇒）子串定义为连续字符序列，若 $p$ 作为子串出现，其首字符必落在 $word$ 的某个位置 $i$，连续性保证其后 $|p|-1$ 个字符依次对应，故 $word[i..i+|p|-1] = p$ 且 $i + |p| \le |word|$。（⇐）若存在这样的 $i$，则 $p$ 恰为 $word$ 从 $i$ 开始的连续 $|p|$ 个字符，即子串。∎

**引理 2（起点枚举完备）**：朴素法对单个 $p$ 枚举全部 $|word| - |p| + 1$ 个起点，命中当且仅当 $p$ 是 $word$ 的子串。

**证明**：由引理 1，$p$ 是子串当且仅当某个 $i \in [0, |word|-|p|]$ 处匹配；朴素法恰好逐一检查这些起点，无遗漏亦无越界（$|p| > |word|$ 时起点区间为空，天然返回未命中）。∎

**定理**：算法返回值等于 $|\{\, i : patterns[i] \text{ 是 } word \text{ 的子串} \,\}|$（按下标计，不去重）。

**证明**：循环体对每个下标 $i$ 恰好执行一次判定；由引理 1、2，`find` / `in` 的返回值与「$patterns[i]$ 是 $word$ 的子串」严格一致，命中则 $count$ 增加 1，否则不变。故最终 $count = \sum_{i} \mathbb{1}[patterns[i] \text{ 是 } word \text{ 的子串}]$，即所求。∎

## 6. 复杂度分析

- **时间复杂度**：$O\!\left(\sum_i |patterns[i]| \cdot |word|\right)$。每个 pattern 做一次子串查找，朴素查找单次 $O(|p| \cdot |word|)$，库实现渐近相同、常数更小。约束下最坏约 $10^6$ 次字符比对。
- **空间复杂度**：$O(1)$。仅一个计数器；若采用 Python 切片写法则临时占 $O(\max |p|)$，逐字符比对可消除。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int numOfStrings(vector<string>& patterns, string word) {
        int count = 0;
        for (const string& p : patterns) {
            if (word.find(p) != string::npos) ++count;
        }
        return count;
    }
};
```

### Python

```python
class Solution:
    def numOfStrings(self, patterns: List[str], word: str) -> int:
        return sum(p in word for p in patterns)
```

## 8. 边界情况与易错点

1. **不能用 set 去重**：示例 3 三个 "a" 各自计数返回 3。按**位置**计数而非按**不同值**计数，`len(set(...))` 类写法直接错。
2. **子串 ≠ 子序列**："ac" 是 "abc" 的子序列但**不是**子串（不连续）；若误写双指针判子序列会多计。`find` / `in` 天然保证连续。
3. **pattern 可等于 word 本身**："abc" 是 "abc" 的子串（$word[0:|word|]$），示例 1 已覆盖，不要额外排除。
4. **C++ 的 `npos` 陷阱**：`find` 返回无符号 `size_t`，判定必须写 `!= string::npos`；写 `> 0` 会漏掉位置 0 的命中，写 `>= 0` 恒真。
5. **$|p| > |word|$**：起点区间为空，库函数天然返回未命中，无需特判。
6. **计数型不提前退出**：必须遍历完所有 pattern；与判定型（如 1961 前缀判定命中即 return）区分。
