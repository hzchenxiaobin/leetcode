# LeetCode 构造元素不等于两侧相邻元素平均值的数组 题解

## 1. 题目概述

- **标题 / 题号**：构造元素不等于两侧相邻元素平均值的数组（#1968，medium）
- **链接**：https://leetcode.cn/problems/array-with-elements-not-equal-to-average-of-neighbors/
- **来源**：LeetCode 第 254 场周赛 Q2
- **难度**：中等
- **标签**：贪心、数组、排序

**题意**：给定一个下标从 0 开始、由**互不相同**的整数组成的数组 `nums`，要求重新排列其中的元素，使得重排后对于每个内部下标 $1 \le i \le n-2$，都有 $\frac{nums[i-1] + nums[i+1]}{2} \ne nums[i]$，即每个元素都不等于其两侧相邻元素的平均值。返回任意一个满足条件的重排结果。

**约束**：

- $3 \le nums.length \le 10^5$
- $0 \le nums[i] \le 10^5$
- `nums` 中的整数**互不相同**

> 💡 本题在本仓库另有[每日题解 1968](../../solution/1901-2000/1968_数组元素不等于邻居平均值.md)：那边侧重「审题三关键」（邻居之和为奇数时天然免疫）、三种实现写法对照（交错填充 / 原地交换 / 双指针）与面试问答。本篇按周赛复盘视角，抓住题面**「互不相同」这一保证**，给出引理-定理化的严格证明（两半严格分离 → 锯齿性 → 平均值夹逼），并补全快速选择 $O(n)$ 优化、special judge 判定等赛场细节。两篇互为印证。

## 3. 解题思路

### 3.1 朴素思路：枚举排列

最直接的想法是枚举 `nums` 的全排列，逐一检查是否合法。全排列共 $n!$ 个，$n$ 最大 $10^5$，完全不可行。即使随机打乱后检查，每次检查 $O(n)$，也缺乏收敛保证。必须找到**确定性构造**。

另一个朴素想法是"局部修补"：先原样放置，发现某个 $i$ 处 $\frac{nums[i-1]+nums[i+1]}{2} = nums[i]$ 就交换修补，但修补可能破坏其他位置，正确性难证。

### 3.2 核心观察：排序切半 + 奇偶交错（锯齿排列）

**关键观察**：平均值有一个基本性质——对两个数 $x, y$，有

$$\min(x, y) \le \frac{x+y}{2} \le \max(x, y)$$

即**平均值被夹在两个邻居之间**。因此，只要让每个中间元素的两侧邻居**同时严格大于它**（或**同时严格小于它**），平均值就必然与它不等。

如何一步到位构造出这种"两侧邻居同侧"的形态？利用**元素互不相同**这一条件：

1. 将 `nums` 升序排序，从中间切开：前一半 $A$（较小的 $\lceil n/2 \rceil$ 个）、后一半 $B$（较大的 $\lfloor n/2 \rfloor$ 个）。由互不相同性，$A$ 中任意元素严格小于 $B$ 中任意元素。
2. **交错填充**：偶数下标放 $A$ 的元素，奇数下标放 $B$ 的元素，即 $res[2k] = A[k]$，$res[2k+1] = B[k]$。

这样得到的排列呈「小-大-小-大-…」的**锯齿（波浪）形**：每个偶数位（小值）的两侧邻居都是 $B$ 中的大值；每个奇数位（大值）的两侧邻居都是 $A$ 中的小值。平均值被严格推向一侧，条件自动满足。

![排序切半与奇偶交错形成锯齿排列的概念图](images/wc254_q2_zigzag_concept.svg)

> 💡 **一句话总结**：排序后"小半"与"大半"奇偶交错，让每个位置的邻居都来自另一半，平均值便永远"够不着"自己。

### 3.3 算法流程

![排序加奇偶交错算法流程图](images/wc254_q2_algorithm_flow.svg)

```text
1. 对 nums 升序排序
2. 令 m = ⌈n/2⌉，A = nums[0..m-1]（较小一半），B = nums[m..n-1]（较大一半）
3. 交错填充结果数组 res：
   res[2k]   = A[k]   （偶数位放小值）
   res[2k+1] = B[k]   （奇数位放大值）
4. 返回 res（无需验证，构造本身保证合法）
```

### 3.4 示例演算

以 `nums = [6,2,0,9,7]` 为例：

1. 排序得 `[0,2,6,7,9]`，$n=5$，$m=3$，$A=[0,2,6]$，$B=[7,9]$
2. 交错填充：$res[0]=A[0]=0$，$res[1]=B[0]=7$，$res[2]=A[1]=2$，$res[3]=B[1]=9$，$res[4]=A[2]=6$
3. 得 $res = [0,7,2,9,6]$，验证：$i=1$：$(0+2)/2=1 \ne 7$；$i=2$：$(7+9)/2=8 \ne 2$；$i=3$：$(2+6)/2=4 \ne 9$，全部满足

## 4. 算法细节

1. **切分点取 $m = \lceil n/2 \rceil$（上取整）**：保证 $A$ 的个数 $\ge B$ 的个数。交错填充时偶数位恰好有 $\lceil n/2 \rceil$ 个、奇数位有 $\lfloor n/2 \rfloor$ 个，正好与 $A$、$B$ 的规模一一对应，$B$ 先耗尽也不会产生空位。
2. **下标映射**：$res[2k] = nums[k]$，$res[2k+1] = nums[m+k]$。合并成单循环：对下标 $i$，若 $i$ 为偶数取 $nums[i/2]$，若 $i$ 为奇数取 $nums[m + i/2]$（整数除法）。
3. **Python 切片写法**：`ans[::2] = s[:m]`、`ans[1::2] = s[m:]`，两个切片长度必须精确等于偶数位/奇数位个数（上取整保证了这一点）。
4. **两半内部无需再排**：证明只用到"$A$ 中任意元素 < $B$ 中任意元素"这一条，$A$、$B$ **内部顺序无关紧要**。因此用快速选择（`nth_element`）按第 $m$ 小划分数组，可把平均复杂度降到 $O(n)$。
5. **无需输出后验证**：构造的正确性由证明保证（见下节），返回前不必再花 $O(n)$ 检查。

## 5. 正确性证明

**引理 1（两半严格分离）**：设排序后 $A = nums[0..m-1]$，$B = nums[m..n-1]$，$m = \lceil n/2 \rceil$。则对任意 $a \in A$、$b \in B$，有 $a < b$。

**证明**：`nums` 元素互不相同且已升序排序，故 $a \le nums[m-1] < nums[m] \le b$。∎

**引理 2（锯齿性）**：按 $res[2k] = A[k]$、$res[2k+1] = B[k]$ 填充后，对每个内部下标 $i$（$1 \le i \le n-2$）：

- 若 $i$ 为偶数，则 $res[i] \in A$，而 $res[i-1], res[i+1] \in B$，由引理 1 得 $res[i-1] > res[i] < res[i+1]$（两侧邻居均严格更大）；
- 若 $i$ 为奇数，则 $res[i] \in B$，而 $res[i-1], res[i+1] \in A$，由引理 1 得 $res[i-1] < res[i] > res[i+1]$（两侧邻居均严格更小）。

**证明**：$i-1$ 与 $i+1$ 的奇偶性都和 $i$ 相反，故邻居与 $res[i]$ 来自不同的半；再由引理 1 的严格分离即得大小关系。∎

**定理**：上述构造得到的 `res` 满足：对每个内部下标 $i$（$1 \le i \le n-2$），$\frac{res[i-1] + res[i+1]}{2} \ne res[i]$。

**证明**：由平均值的基本性质 $\min(x,y) \le \frac{x+y}{2} \le \max(x,y)$：

- $i$ 为偶数：$res[i-1] > res[i]$ 且 $res[i+1] > res[i]$，故 $\frac{res[i-1]+res[i+1]}{2} \ge \min(res[i-1], res[i+1]) > res[i]$，平均值严格大于 $res[i]$；
- $i$ 为奇数：$res[i-1] < res[i]$ 且 $res[i+1] < res[i]$，故 $\frac{res[i-1]+res[i+1]}{2} \le \max(res[i-1], res[i+1]) < res[i]$，平均值严格小于 $res[i]$。

两种情况均严格不等，定理成立。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \log n)$。排序占 $O(n \log n)$，交错填充一轮线性扫描 $O(n)$。若用快速选择代替排序（见 §4 第 4 点），平均可降到 $O(n)$。
- **空间复杂度**：$O(n)$。结果数组 $O(n)$（排序若为原地实现仅占 $O(\log n)$ 栈空间，不计输出可视为 $O(1)$ 额外）。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    vector<int> rearrangeArray(vector<int>& nums) {
        sort(nums.begin(), nums.end());
        int n = nums.size();
        int m = (n + 1) / 2; // 前半 A 的规模（上取整）
        vector<int> res(n);
        for (int i = 0; i < n; i++) {
            if (i % 2 == 0) {
                res[i] = nums[i / 2];       // 偶数位 <- A
            } else {
                res[i] = nums[m + i / 2];   // 奇数位 <- B
            }
        }
        return res;
    }
};
```

### Python

```python
class Solution:
    def rearrangeArray(self, nums: List[int]) -> List[int]:
        s = sorted(nums)
        m = (len(s) + 1) // 2  # 前半 A 的规模（上取整）
        ans = [0] * len(s)
        ans[::2] = s[:m]       # 偶数位 <- A（小值）
        ans[1::2] = s[m:]      # 奇数位 <- B（大值）
        return ans
```

## 8. 边界情况与易错点

1. **$n$ 为奇数**：$B$ 比 $A$ 少一个元素，交错填充到末尾时奇数位先耗尽，最后一个位置（偶数下标 $n-1$）恰好放 $A$ 的最后一个元素。单循环写法 `nums[m + i/2]` 天然不会越界；切片写法则要求 `s[:m]` 与 `s[m:]` 长度分别等于偶/奇数位个数，$m$ 上取整保证了这一点。
2. **首尾元素无需检查**：它们只有一个邻居，题目条件只约束内部下标 $1 \le i \le n-2$，不要多虑。
3. **「互不相同」是关键前提**：若允许重复（如 `[1,1,1]`），无论怎么排都有 $\frac{1+1}{2} = 1$，问题可能无解；本题保证互不相同，才使得"简单切半交错"即可。有重复时需改用 LeetCode 324 的三分区技巧。
4. **判题是 special judge**：任意合法解都通过，不必与示例输出一致（示例 2 官方输出 `[9,7,6,2,0]`，本解法输出 `[0,7,2,9,6]` 同样正确）。
5. **平均值不会溢出**：$nums[i] \le 10^5$，两邻居之和至多 $2 \times 10^5$，`int` 足够；且本解法根本不需要计算平均值。
6. **切分点用上取整**：若误用 $m = \lfloor n/2 \rfloor$，奇数位个数（$\lfloor n/2 \rfloor$）会多于 $B$ 的规模（$\lceil n/2 \rceil - 1$，当 $n$ 为奇数时），切片赋值直接报长度错误。
