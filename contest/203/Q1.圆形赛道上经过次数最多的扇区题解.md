# LeetCode 圆形赛道上经过次数最多的扇区 题解

## 1. 题目概述

- **标题 / 题号**：圆形赛道上经过次数最多的扇区（#1560，easy）
- **链接**：https://leetcode.cn/problems/most-visited-sector-in-a-circular-track/
- **来源**：LeetCode 第 203 场周赛 Q1
- **难度**：简单
- **标签**：数组、模拟、数学

**题意**：圆形赛道由 $n$ 个扇区组成，编号 $1 \sim n$，只能沿编号递增方向前进（$n$ 之后绕回 $1$）。马拉松分 $m$ 个阶段，第 $i$ 个阶段从 `rounds[i-1]` 走到 `rounds[i]`，整场比赛从 `rounds[0]` 起跑。求经过次数最多的扇区集合，按编号升序返回。

**约束**：

- $2 \le n \le 100$
- $1 \le m \le 100$，$\mathrm{rounds.length} = m + 1$
- $1 \le \mathrm{rounds}[i] \le n$
- 相邻检查点不同：$\mathrm{rounds}[i] \ne \mathrm{rounds}[i+1]$

> 💡 签到题，数据规模 $n, m \le 100$ 怎么写都能过。但它藏着一个很漂亮的观察：**中间检查点全是烟雾弹，答案只由起点 `rounds[0]` 和终点 `rounds[m]` 决定**。赛时先写模拟保底，再花两分钟把 $O(1)$ 判定想清楚，是本题的最优节奏。

输出：[1,2]
解释：路径 1 → 2 → 3（阶段 1）→ 4 → 1（阶段 2）→ 2（阶段 3）。
      扇区 1、2 各经过 2 次，扇区 3、4 各 1 次。
```

输出：[2]
解释：路径 2 → 1 → 2 → … → 2，扇区 2 经过 5 次，扇区 1 经过 4 次。
```

```text
输入：n = 7, rounds = [1,3,5,7]
输出：[1,2,3,4,5,6,7]
解释：路径 1 → 2 → … → 7，每个扇区恰好经过 1 次，全部并列最多。
```

## 3. 解题思路

### 3.1 暴力思路：逐格模拟

开计数数组 `cnt[1..n]`，从 `cur = rounds[0]` 起跑先计一次，随后对每个目标 `rounds[i]` 反复执行 `cur = cur % n + 1; cnt[cur]++` 直到抵达目标，最后取 `cnt` 最大值对应的所有扇区。

每个阶段最多绕 $n-1$ 步，总步数 $T \le m \cdot n \le 10^4$，配合收尾的 $O(n)$ 扫描毫无压力。赛时用这版保底完全没问题；但既然是复盘，值得把背后的结构挖出来——本题存在 **$O(1)$ 判定 + $O(n)$ 输出** 的做法。

### 3.2 核心观察：中继检查点是烟雾弹

![核心观察：连续行走与整圈残弧分解](images/wc203_q1_circular_track_concept.svg)

三个层层递进的观察：

1. **行走是连续的**。第 $i$ 阶段的终点就是第 $i+1$ 阶段的起点，方向又始终是编号递增。把 $m$ 段拼起来，整场马拉松就是**一条从 $s = \mathrm{rounds}[0]$ 出发、共走 $T$ 步的连续环形行走**，中途在哪些检查点「换段」根本不改变经过的扇区序列。
2. **整圈贡献均匀**。把 $T$ 步分解为 $q = \lfloor T/n \rfloor$ 个整圈加一段长 $r = T \bmod n$ 的残弧：整圈部分让**每个**扇区计数各 $+q$，对「谁最多」的比较毫无影响。
3. **残弧决定差异**。残弧从 $s$ 出发走 $r$ 步，恰好扫到终点 $e = \mathrm{rounds}[m]$（因为 $d(e) = T \bmod n = r$）。于是：

$$\text{经过最多的扇区} = \text{从 } s \text{ 到 } e \text{ 的顺时针弧（含两端）}$$

### 3.3 算法流程

![算法流程：只看首尾两个检查点](images/wc203_q1_algorithm_flow.svg)

只读 `rounds` 的首尾两个元素：

```text
1. s = rounds[0]，e = rounds[m]
2. 若 s ≤ e：答案 = [s, s+1, …, e]（一段）
3. 若 s > e：答案 = [1, …, e] ∪ [s, …, n]（残弧跨过 1，拆两段）
4. 按升序拼接返回
```

$s = e$（走满整数圈）被第 2 步自然覆盖：$[s..s] = [s]$。

### 3.4 示例演算

![示例演算：整圈加残弧分解](images/wc203_q1_example_walkthrough.svg)

| 示例 | $n$ | $s$ | $e$ | $T$ 的分解与判定 | 答案 |
|------|-----|-----|-----|-----------------|------|
| 1 | 4 | 1 | 2 | $T=5$：1 圈 + 1 步，$s \le e$ | $[1,2]$ |
| 2 | 2 | 2 | 2 | $T=8$：4 圈 + 0 步，$s = e$ | $[2]$ |
| 3 | 7 | 1 | 7 | $T=6$：0 圈 + 6 步，$s < e$ | $[1,\dots,7]$ |

- 示例 1：残弧长 $1$，从 $1$ 扫到 $2$，只有扇区 1、2 拿到「残弧 +1」，答案 $[1,2]$；
- 示例 2：$r = 0$，没有残弧，只有起点拿到「起跑」那一次计数，答案 $[2]$；
- 示例 3：$r = n - 1$，残弧几乎绕满一圈，所有扇区并列最多。

## 4. 算法细节

1. **只用首尾**：`rounds[1..m-1]` 全程不参与计算，读入后即可丢弃。
2. **跨 1 拼接顺序**：$s > e$ 时先输出 $[1..e]$ 再输出 $[s..n]$，保证升序；由 $e \ge 1$、$s \le n$ 知两段都非空。
3. **计数公式**（证明见 §5）：扇区 $x$ 的经过次数为 $q + [\,d(x) \le r\,]$，其中 $d(x) = (x - s) \bmod n$ 是 $x$ 相对起点的顺时针距离，$q = \lfloor T/n \rfloor$，$r = T \bmod n$。最大值 $q + 1$ 恰被弧上扇区取到。
4. **模拟写法的环形前进**：`cur = cur % n + 1` 是 1-indexed 的标准写法；不要写成 `(cur + 1) % (n + 1)`，否则 `cur = n` 时会走到 $0$。
5. **输出天然有序**：答案按弧的顺序构造即为升序，无需排序。

## 5. 正确性证明

**引理 1（路径连续性）**：整场马拉松经过的扇区序列，与「从 $s = \mathrm{rounds}[0]$ 出发沿编号递增方向连续走 $T$ 步」的序列相同，其中

$$T = \sum_{i=1}^{m} \bigl(\mathrm{rounds}[i] - \mathrm{rounds}[i-1] + n\bigr) \bmod n.$$

**证明**：第 $i$ 阶段是从 $\mathrm{rounds}[i-1]$ 到 $\mathrm{rounds}[i]$ 的编号递增行走；由约束 $\mathrm{rounds}[i] \ne \mathrm{rounds}[i+1]$，每阶段步数 $\bigl(\mathrm{rounds}[i] - \mathrm{rounds}[i-1] + n\bigr) \bmod n \in [1, n-1]$。按时间顺序拼接各阶段：前一段的终点即后一段的起点，方向一致无折返，故拼接结果是一条从 $s$ 出发、总步数为 $T$ 的单一连续递增环形行走。∎

**引理 2（计数公式）**：设 $d(x) = (x - s) \bmod n \in \{0, 1, \dots, n-1\}$，$q = \lfloor T/n \rfloor$，$r = T \bmod n$，则扇区 $x$ 的经过次数

$$\mathrm{cnt}(x) = q + [\,d(x) \le r\,].$$

**证明**：连续行走的第 $k$ 步到达的扇区 $x_k$ 满足 $d(x_k) = k \bmod n$（$k = 0, 1, \dots, T$，其中 $x_0 = s$ 即起跑位置计入一次）。于是 $x$ 被经过当且仅当存在 $k \in [0, T]$ 使 $k \equiv d(x) \pmod n$。

- 若 $d(x) \le r$：则 $T - d(x) \in [qn, (q+1)n - 1]$，满足条件的 $k$ 为 $d(x),\ d(x)+n,\ \dots,\ d(x)+qn$，共 $q + 1$ 个；
- 若 $d(x) > r$：若还有 $d(x) > T$，则不存在这样的 $k$，计数为 $0$（此时 $T < n$ 即 $q = 0$，与公式一致）；否则 $d(x) \le T$ 且必有 $q \ge 1$（若 $q = 0$ 则 $r = T$，与 $d(x) \le T < d(x)$ 矛盾），此时 $T - d(x) \in [(q-1)n,\ qn - 1]$，满足条件的 $k$ 共 $q$ 个。∎

**引理 3（终点即残弧末端）**：终点 $e = \mathrm{rounds}[m]$ 的顺时针距离 $d(e) = r$。

**证明**：$e$ 是第 $T$ 步到达的扇区，由引理 2 证明中 $d(x_k) = k \bmod n$，取 $k = T$ 得 $d(e) = T \bmod n = r$。∎

**定理**：经过次数最多的扇区集合恰为 $\{x : d(x) \le r\}$，即从 $s$ 到 $e$ 的顺时针弧（含两端）。

**证明**：由引理 2，$\mathrm{cnt}(x) = q + [d(x) \le r]$：$d(x) \le r$ 时取 $q + 1$，否则取 $q$；又 $d(s) = 0 \le r$，最大值 $q + 1$ 必可达。故 argmax 集合 $= \{x : d(x) \le r\} \overset{\text{引理 3}}{=} \{x : d(x) \le d(e)\}$，即从 $s$ 顺时针走到 $e$ 的弧。展开为构造：$s \le e$ 时 $r = e - s$，弧为 $[s, s+1, \dots, e]$；$s > e$ 时 $r = e - s + n$，弧为 $[s, \dots, n] \cup [1, \dots, e]$。∎

## 6. 复杂度分析

- **时间复杂度**：判定 $O(1)$（只读首尾两个元素），构造答案 $O(n)$（答案长度至多 $n$），总体 $O(n)$。相比模拟的 $O(mn)$，在 $n$ 很大、输出很少时优势更明显。
- **空间复杂度**：$O(1)$（不计返回数组）；模拟法则需 $O(n)$ 的计数数组。

## 7. 参考代码

### 方法一：只看首尾，$O(n)$

#### C++

```cpp
class Solution {
public:
    vector<int> mostVisited(int n, vector<int>& rounds) {
        int s = rounds.front(), e = rounds.back();
        vector<int> ans;
        if (s <= e) {
            for (int x = s; x <= e; ++x) ans.push_back(x);
        } else {
            for (int x = 1; x <= e; ++x) ans.push_back(x);
            for (int x = s; x <= n; ++x) ans.push_back(x);
        }
        return ans;
    }
};
```

#### Python

```python
class Solution:
    def mostVisited(self, n: int, rounds: List[int]) -> List[int]:
        s, e = rounds[0], rounds[-1]
        if s <= e:
            return list(range(s, e + 1))
        return list(range(1, e + 1)) + list(range(s, n + 1))
```

### 方法二：逐格模拟，$O(mn)$（赛时保底）

```python
class Solution:
    def mostVisited(self, n: int, rounds: List[int]) -> List[int]:
        cnt = [0] * (n + 1)
        cur = rounds[0]
        cnt[cur] += 1
        for nxt in rounds[1:]:
            while cur != nxt:
                cur = cur % n + 1
                cnt[cur] += 1
        best = max(cnt[1:])
        return [x for x in range(1, n + 1) if cnt[x] == best]
```

## 8. 边界情况与易错点

1. **$s = e$ 时误输出全体扇区**：走满整数圈时只有起点多一次「起跑」计数，答案是 $[s]$ 而非全体；它被 `s <= e` 分支自然覆盖，无需特判，但方向想错就会 WA（示例 2 即此情形）。
2. **$s > e$ 的拼接顺序**：必须先 $[1..e]$ 后 $[s..n]$；先 $[s..n]$ 再 $[1..e]$ 会输出两段降序拼接，不满足「升序返回」。
3. **方向搞反**：赛道只能沿编号递增方向走，$3 \to 1$ 要经过 $3 \to 4 \to 1$（$n = 4$）；把它当成可双向或按最短路走都会错。
4. **模拟的环形回绕**：`cur % n + 1` 才是 1-indexed 的正确写法；`(cur + 1) % (n + 1)` 会让 `cur = n` 时走到 $0$ 越界。
5. **起点漏计数**：模拟法里起跑扇区要先计一次（序列的第 0 项）；漏掉的话 $s = e$ 整圈情形会错误地输出全体并列。
6. **别被中间检查点带偏**：任何用到 `rounds[1..m-1]` 的做法都在做无用功；把每个阶段当独立环形区间做「区间 +1」差分答案也对，但浪费了 telescoping 结构。
