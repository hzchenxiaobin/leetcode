# LeetCode 你可以获得的最大硬币数目 题解

## 1. 题目概述

- **标题 / 题号**：你可以获得的最大硬币数目（#1561，medium）
- **链接**：https://leetcode.cn/problems/maximum-number-of-coins-you-can-get/
- **来源**：LeetCode 第 203 场周赛 Q2
- **难度**：中等
- **标签**：贪心、排序、数组、博弈

**题意**：有 $3n$ 堆硬币（大小不一，数值可以重复），共进行 $n$ 轮。每轮由**你**任意选出 3 堆：Alice 拿走硬币数**最多**的一堆，**你**拿走**第二多**的一堆，Bob 拿走剩下的那一堆（最少）。所有堆分完后，求你能拿到的硬币总数最大是多少。

**约束**：

- $3 \le \mathrm{piles.length} \le 10^5$
- $\mathrm{piles.length} \bmod 3 = 0$
- $1 \le \mathrm{piles}[i] \le 10^4$

> 💡 本题在本仓库另有[每日题解 1561](../../solution/1501-1600/1561_你可以获得的最大硬币数.md)：以「Bob 沉没损失、两两配对」的直觉展开并附面试问答。本篇按**周赛复盘视角**重写：赛时节奏（Q2 是速度题，两分钟内定位模板）、把直觉升级为**计数上界证明**（你的第 $k$ 大 $\le$ 全体第 $2k$ 大，引理—定理结构），以及每日版没有的推广——**「名次决定取数位」**：$T$ 人按名次分堆时，第 $t$ 名恰拿走从大到小第 $t, 2t, \dots, nt$ 名。两篇互为印证。

## 2. 示例

**示例 1**

```text
输入：piles = [2,4,1,2,7,8]
输出：9
解释：n = 2，共 2 轮。
第 1 轮选 {2, 7, 8}：Alice 拿 8，你拿 7，Bob 拿 2。
第 2 轮选 {1, 2, 4}：Alice 拿 4，你拿 2，Bob 拿 1。
你的总数 = 7 + 2 = 9。
若错配为 (1,2,8)、(2,4,7)，你只能得 2 + 4 = 6，不是最优。
```

**示例 2**

```text
输入：piles = [2,4,5]
输出：4
解释：n = 1，仅 1 轮：Alice 拿 5，你拿 4，Bob 拿 2。
```

**示例 3**

```text
输入：piles = [9,8,7,6,5,1,2,3,4]
输出：18
解释：排序后 [1,2,3,4,5,6,7,8,9]，n = 3，你取索引 3, 5, 7 → 4 + 6 + 8 = 18。
```

## 3. 解题思路

### 3.1 暴力思路：枚举每轮的三元组

第 1 轮有 $\binom{3n}{3}$ 种选法，第 2 轮 $\binom{3n-3}{3}$ 种……总方案数是阶乘级爆炸。$3n = 9$ 时 $\binom{9}{3}\binom{6}{3} = 1680$ 尚可硬算，$3n = 10^5$ 完全不可行。暴力失败的根源是把「每轮选 3 堆」当成自由组合搜索，而没有利用规则的**刚性**——名次是别人定死的，你真正能决定的只有「谁和谁同组」。

### 3.2 核心观察：名次刚性，自由度只剩配对

![核心观察：排序后的三段分工](images/wc203_q2_role_partition_concept.svg)

三个层层递进的观察：

1. **Alice 的堆你永远抢不到**。你拿的每一堆，在它所在的轮里必有一个**不小于它**的堆同时被选出——那一堆归 Alice。这是规则刚性，与你怎么选组无关。
2. **Bob 的堆是纯损失**。Bob 拿走的硬币不进任何人的口袋，属于「沉没损失」。想让损失最小，就该让 Bob 拿走**最小的 $n$ 堆**。
3. **你与 Alice 瓜分顶部 $2n$ 堆**。剩下的顶部 $2n$ 堆每轮满足「Alice $\ge$ 你」，最优配法是从大到小**两两配对**（第 1 名配第 2 名、第 3 名配第 4 名……），Alice 拿每对较大者，你拿较小者。

结论：**你拿走的恰是从大到小第 $2, 4, 6, \dots, 2n$ 名**，升序排序后即索引 $n, n+2, \dots, 3n-2$：

$$\text{ans} = \sum_{k=0}^{n-1} \mathrm{piles}[n + 2k]$$

### 3.3 算法流程

![算法流程：排序后从索引 n 起隔位取数](images/wc203_q2_greedy_flow.svg)

```text
1. piles 升序排序
2. n = len(piles) // 3
3. i 从 n 出发、步长 2，一路累加 piles[i]，直到 i ≥ 3n 退出
4. 返回累加和
```

循环恰好执行 $n$ 次：$i$ 依次取 $n, n+2, \dots, 3n-2$（共 $n$ 项），最后再 $+2$ 得 $3n$ 越界退出——因为 $3n - 2 - n = 2n - 2$ 是偶数，$3n-2$ 正好是最后一个落在界内的同奇偶下标。

### 3.4 示例演算

![示例演算：最优分组与题面反例对照](images/wc203_q2_example_walkthrough.svg)

排序得 $[1,2,2,4,7,8]$，$n = 2$：

| 轮次 | 选出 3 堆 | Alice（最大） | 你（第二大） | Bob（最小） |
|------|-----------|----------|----------|----------|
| 1 | {2, 7, 8} | 8 | **7** | 2 |
| 2 | {1, 2, 4} | 4 | **2** | 1 |
| **合计** | — | 12 | **9** | 3 |

你的总数 $= \mathrm{piles}[2] + \mathrm{piles}[4] = 2 + 7 = 9$。对照题面给出的错误配对 $(1,2,8)$、$(2,4,7)$：你只能拿 $2+4=6$。**同一批堆，配对方式不同，收益差 3**——这正是本题唯一的考点。

示例 3：排序 $[1,2,3,4,5,6,7,8,9]$，$n=3$，取索引 $3,5,7$，得 $4+6+8=18$。

## 4. 算法细节

1. **上界公式是证明的核心**：你的第 $k$ 大 $\le$ 全体第 $2k$ 大（§5 引理 1）。这一条把「任意分组方案」压缩到一个纯序统计的界，无需讨论具体交换过程。
2. **循环次数恰为 $n$**：$n$ 与 $3n-2$ 同奇偶（差 $2n-2$ 为偶数），序列 $n, n+2, \dots, 3n-2$ 共 $n$ 项，不会多取也不会漏取。
3. **降序写法对照**：若降序排序为数组 $d[0..3n-1]$（$d[0]$ 最大），则取「前 $2n$ 名中的奇数下标」$d[1], d[3], \dots, d[2n-1]$，与升序写法完全等价；两种方向别混用。
4. **值可以重复**：题面「数目不同」是 "3n piles of coins of varying size" 的直译，示例 1 就有两个 `2`。同值堆按位置决出名次即可，不影响按下标取数的代码。
5. **无需显式构造轮次**：「每轮选哪 3 堆」的存在性由 §5 引理 2 的构造保证，代码只做定位求和，不要真去建三元组。

## 5. 正确性证明

记号：升序排序 $a_0 \le a_1 \le \dots \le a_{3n-1}$，从大到小第 $j$ 名记 $d_j = a_{3n-j}$。

**引理 1（计数上界）**：任意合法方案中，把你拿到的 $n$ 堆降序排列为 $y_1 \ge y_2 \ge \dots \ge y_n$，则对每个 $1 \le k \le n$ 都有 $y_k \le d_{2k}$。

**证明**：考察你拿走 $y_1, \dots, y_k$ 的那 $k$ 轮。每轮中 Alice 拿走该轮最大的一堆，故 Alice 该轮的堆 $\ge$ 你该轮的堆 $\ge y_k$。这 $k$ 个 Alice 的堆来自互不相同的轮次，是 $k$ 个互不相同的堆，且都不在你手里；连同 $y_1, \dots, y_k$ 本身，共有 $2k$ 个互不相同的堆，值全部 $\ge y_k$。于是全体从大到小至少有 $2k$ 个堆 $\ge y_k$，即第 $2k$ 名 $d_{2k} \ge y_k$。∎

**引理 2（贪心可达）**：如下分组合法，且你的收益恰为 $\sum_{k=1}^{n} d_{2k}$：第 $k$ 轮选出三元组 $\{d_{2k-1},\ d_{2k},\ d_{2n+k}\}$（$k = 1, \dots, n$）。

**证明**：先看覆盖：Alice 拿 $d_1, d_3, \dots, d_{2n-1}$，你拿 $d_2, d_4, \dots, d_{2n}$，Bob 拿 $d_{2n+1}, \dots, d_{3n}$，三组下标不重叠地覆盖 $1 \sim 3n$，$n$ 轮恰好分完。再验证名次：第 $k$ 轮内 $d_{2k-1} \ge d_{2k}$（相邻序号），且 $d_{2k} \ge d_{2n} \ge d_{2n+k}$（因 $2k \le 2n < 2n+k$），即 Alice 拿最大、你拿第二、Bob 拿最小，符合规则。你的收益即 $\sum_{k=1}^{n} d_{2k}$。∎

**定理**：你能获得的最大硬币数等于 $\sum_{k=1}^{n} d_{2k}$，升序即 $\sum_{k=0}^{n-1} a_{n+2k}$。

**证明**：由引理 1，任意方案的收益 $\sum_{k=1}^n y_k \le \sum_{k=1}^n d_{2k}$；由引理 2，贪心分组取到该上界。上界与可达性夹逼即得。∎

> 💡 「计数上界 + 构造取等」是分配类贪心的标准证明范式：不纠缠具体交换过程，直接用「名次陪跑」数出上界，再验证贪心恰好达到上界。比赛时想不清交换论证，不妨先数上界。

## 6. 复杂度分析

- **时间复杂度**：$O(n \log n)$。排序 $3n \le 10^5$ 个数主导，约 $3n \log (3n) \approx 1.7 \times 10^6$ 次比较；隔位求和仅 $O(n)$。对 Q2 来说这就是读题两分钟后应有的复杂度。
- **空间复杂度**：$O(\log n)$，为排序递归栈开销；`piles` 原地排序，无额外数组。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maxCoins(vector<int>& piles) {
        sort(piles.begin(), piles.end());
        int m = piles.size();
        int n = m / 3;
        int ans = 0;
        for (int i = n; i < m; i += 2) {
            ans += piles[i];
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maxCoins(self, piles: List[int]) -> int:
        piles.sort()
        return sum(piles[len(piles) // 3::2])
```

> 💡 切片 `[n::2]` 从索引 $n$ 起、步长 2 取到末尾，恰好 $n$ 个元素。两行代码，是 Q2 该有的手速。

## 8. 边界情况与易错点

1. **起点 + 步长写错**：升序必须「从 $n$ 起、步长 2」。写成 `[::2]`（从 0 起）就变成了 561 数组拆分的取法，方向反了；写成 `[n:]` 全加则把 Alice 的堆也算进你的收益。
2. **「数目不同」≠「互不相同」**：题面是 "piles of varying size" 的直译，示例 1 就有两个 `2`。值重复不影响——名次按位置决出，代码按下标取数天然正确。
3. **`n` 的整数除法**：Python 用 `//`（`/` 返回 float 不能当下标）；题目保证长度是 3 的倍数，无舍入歧义。
4. **总和是否溢出**：$n \le \lfloor 10^5 / 3 \rfloor$、单堆 $\le 10^4$，总和 $\le 3.4 \times 10^8$，`int` 装得下；若约束再放大一个数量级就应换 `long long`，赛时留个心眼。
5. **降序写法的边界**：降序排序时取 0 起的奇数下标 `piles[1], piles[3], …, piles[2n-1]`——上界是 $2n-1$ 不是 $3n-1$，取到后面就把 Bob 的堆算进来了。
6. **别去模拟轮次**：谁和谁一组只是证明中的存在性构造，代码里建三元组、开结构体纯属浪费时间。
