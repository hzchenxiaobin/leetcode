# LeetCode 石子游戏 V 题解

## 1. 题目概述

- **标题 / 题号**：石子游戏 V（#1563，hard）
- **链接**：https://leetcode.cn/problems/stone-game-v/
- **来源**：LeetCode 第 203 场周赛 Q4
- **难度**：困难
- **标签**：数组、动态规划、区间 DP、前缀和、博弈

**题意**：`stoneValue` 排成一行，每块石子有一个正整数值。游戏每一轮：

1. Alice 把**当前行**切成两个非空行（左行 / 右行）；
2. Bob 计算两行各自的总和，**丢弃总和较大的那一行**，Alice 的得分 = 剩下那行的总和（累加进总分）；
3. 若两行总和相等，Bob 让 Alice **自行决定**丢弃哪一行；
4. 下一轮从剩下的那行继续。

当只剩一块石子时游戏结束，Alice 初始分数为 0。返回 Alice 能获得的最大分数。

**约束**：

- $1 \le n = \mathrm{stoneValue.length} \le 500$
- $1 \le \mathrm{stoneValue}[i] \le 10^6$

> 💡 本题的题眼是想清楚「到底在跟谁博弈」：**Bob 不是对手**——他的行为完全由规则确定（平局时甚至把决定权交给 Alice），被丢弃那一行的分数直接消失、不进任何人口袋。所以这不是 877. 石子游戏那种零和博弈，而是**带最优子结构的单人最优化**，状态记「累计得分」而非「双方差值」。

## 2. 示例

**示例 1**

```text
输入：stoneValue = [6,2,3,4,5,5]
输出：18
解释：
第 1 轮：切 [6,2,3] | [4,5,5]，和 11 < 14，丢右行，得 11，剩 [6,2,3]
第 2 轮：切 [6] | [2,3]，和 6 > 5，丢左行，得 5，剩 [2,3]，累计 16
第 3 轮：切 [2] | [3]，和 2 < 3，丢右行，得 2，剩 [2]，累计 18
只剩一块石子，游戏结束。
```

**示例 2**

```text
输入：stoneValue = [7,7,7,7,7,7,7]
输出：28
解释：先切 [7,7,7] | [7,7,7,7]，保留和为 21 的左行；
再切 [7] | [7,7]，保留 [7]，得 7，累计 21 + 7 = 28。
```

**示例 3**

```text
输入：stoneValue = [4]
输出：0
解释：开局只剩一块石子，游戏立即结束，得分 0。
```

**示例 4（平局分支）**

```text
输入：stoneValue = [1,2,3]
输出：4
解释：切 [1,2] | [3]，两边和都是 3，平局，Alice 自选保留哪边：
保留左行 [1,2] → 得 3，再切 [1] | [2] 又得 1，总计 4；
保留右行 [3]   → 得 3，只剩一块直接结束，总计 3。
保留左边更优，答案 4 —— 平局时必须比较两边后续潜力取 max。
```

## 3. 解题思路

### 3.1 暴力思路：按规则直接递归

最朴素的写法是照着规则写递归：对当前行枚举每一个切分点 $k$，按左和与右和的大小关系确定保留哪边，得当轮分数后递归保留侧。问题在于**同一个区间会被反复求解**：长度为 $m$ 的区间要枚举 $m-1$ 个切分点、每个切分点又递归一个最长 $m-1$ 的区间，设 $T(m)$ 为求解代价，则 $T(m) \approx \sum_{k} T(\text{保留侧长度})$，最坏 $T(m) = \Theta(m \cdot T(m-1))$，呈阶乘级爆炸，$n = 500$ 完全不可行。

加上记忆化后状态只剩 $O(n^2)$ 个区间、每个区间 $O(n)$ 个转移，就是下面方法一的 $O(n^3)$ 区间 DP；本文再进一步给出把它压到 $O(n^2)$ 的单调分界优化（方法二）。

### 3.2 核心观察：规则确定 + 历史无关 → 区间 DP

![石子游戏 V 的一轮：切一刀、丢大留小、三种分支](images/wc203_q4_split_concept.svg)

三个层层递进的观察：

1. **规则是确定的，没有对抗**。Bob 每轮只做一件事：丢掉和较大的一边（平局时由 Alice 定）。整场游戏里**唯一的决策者就是 Alice**，决策内容是「在哪切」以及「平局留哪边」。因此不需要 877 那种「双方轮流、记差值」的博弈状态，直接记「从当前局面出发还能拿多少分」。
2. **历史无关**。无论当前行是怎么切出来的，只要行是 $[l, r]$，之后的可选策略与得分只由 $[l, r]$ 决定——规则只引用「当前行」，总分是各轮得分的线性累加。这就是最优子结构。
3. **每轮向更短的区间递归**。保留侧一定是当前行的真子区间，游戏状态可以完全用一个区间刻画。于是自然定义：

> $f(l, r)$ = 当前行为 $\mathrm{stoneValue}[l..r]$ 时，Alice 之后能获得的最大累计得分（代码里存为 $\mathrm{dp}[l][r]$）。

### 3.3 状态转移与算法流程

![区间 DP 模型：状态、三分支转移与按长度填表](images/wc203_q4_interval_dp_model.svg)

预处理前缀和 $\mathrm{pre}$，记 $S(l, k) = \mathrm{pre}[k+1] - \mathrm{pre}[l]$（子行 $[l,k]$ 的和）。枚举切分点 $k \in [l, r-1]$，按左右和的大小关系分三种情况：

$$
f(l,r)=\max_{l \le k < r}\begin{cases}
S(l,k) + f(l,k), & S(l,k) < S(k{+}1,r)\ \ \text{（丢右，留左）}\\[4pt]
S(k{+}1,r) + f(k{+}1,r), & S(l,k) > S(k{+}1,r)\ \ \text{（丢左，留右）}\\[4pt]
S(l,k) + \max\{f(l,k),\, f(k{+}1,r)\}, & S(l,k) = S(k{+}1,r)\ \ \text{（平局，Alice 选）}
\end{cases}
$$

- **边界**：$f(l, l) = 0$（只剩一块，游戏结束，无得分）。
- **答案**：$f(0, n-1)$。
- **填表顺序**：$f(l,r)$ 只依赖 $f(l,k)$ 与 $f(k{+}1,r)$，两个子区间长度都严格小于 $r-l+1$，按区间长度 $\mathrm{len} = 2, 3, \dots, n$ 逐层填充即可，无需递归。

**规模账本**：状态约 $n^2/2 \approx 1.25 \times 10^5$ 个，每状态枚举至多 $n-1$ 个切分点，总计 $O(n^3) \approx n^3/6 \approx 2 \times 10^7$ 步基本运算，C++ 轻松通过；纯 Python 实测约 4 秒，比较悬，追求稳妥可上方法二。

### 3.4 示例演算

![示例演算：[6,2,3,4,5,5] 的三轮最优切分](images/wc203_q4_example_walkthrough.svg)

以示例 1（`[6,2,3,4,5,5]`）走一遍最优路径：

| 轮次 | 当前行 | 切分 | 左和 | 右和 | 保留 | 本轮得分 | 累计 |
|------|--------|------|------|------|------|----------|------|
| 1 | `[6,2,3,4,5,5]` | `[6,2,3] \| [4,5,5]` | 11 | 14 | 左 `[6,2,3]` | 11 | 11 |
| 2 | `[6,2,3]` | `[6] \| [2,3]` | 6 | 5 | 右 `[2,3]` | 5 | 16 |
| 3 | `[2,3]` | `[2] \| [3]` | 2 | 3 | 左 `[2]` | 2 | **18** |

- 「保留和小的一边」是 Bob 强制的，Alice 的自由度只有**选切分点**（及平局时选保留边）；
- 行和 $25 \to 11 \to 5 \to 2$，每轮近似减半——这解释了为什么轮数只有 $O(\log n)$、总分有上界（见 §4 第 7 点与 §5 推论）。

### 3.5 进阶：单调分界 + 两个前缀最大值，$O(n^2)$

![O(n²) 优化：分界线单向移动，A/B 两区各维护一个只增不减的前缀最大值](images/wc203_q4_monotone_split.svg)

方法一的内层 $k$ 循环有大量浪费：**左右和的大小关系随 $k$ 单调变化**，绝大多数切分点根本不可能是最优解，却被逐个检查。利用这一点可以把每个状态的转移摊还到 $O(1)$。

对区间 $[l, r]$，定义 $D(k) = S(l,k) - S(k{+}1,r)$。切分点右移一步，左边多吞一块、右边吐出同一块石子：

$$D(k+1) - D(k) = 2 \cdot \mathrm{stoneValue}[k+1] > 0$$

所以 $D$ 关于 $k$ **严格递增**，于是：

- **A 区**（留左候选，$D(k) \le 0$ 即左和 $\le$ 右和）是一段**前缀** $[l, k_a]$；
- **B 区**（留右候选，$D(k) \ge 0$ 即左和 $\ge$ 右和）是一段**后缀** $[k_b, r-1]$；
- 两区相邻或恰好重叠于一个平局点（$D = 0$ 同属两区，取 max 天然覆盖平局分支），且至少一区非空。

把两区候选改写成「与自由变量无关的部分 + 公共项」：

- A 区候选 $= S(l,k) + \mathrm{dp}[l][k] = \big(\mathrm{pre}[k{+}1] + \mathrm{dp}[l][k]\big) - \mathrm{pre}[l]$；
- B 区候选 $= S(k{+}1,r) + \mathrm{dp}[k{+}1][r] = \big(\mathrm{dp}[k{+}1][r] - \mathrm{pre}[k{+}1]\big) + \mathrm{pre}[r{+}1]$。

再看两个方向的单调性：

1. **固定 $l$，让 $r$ 增大**：每个 $k$ 的右和变大、$D(k)$ 变小，A 区只会变宽——右端 $k_a$ **只增不减**。于是在内层循环里维护**一个**前缀最大值 $\mathrm{runA} = \max_{k \in A}\{\mathrm{pre}[k{+}1] + \mathrm{dp}[l][k]\}$，指针 $p$ 右移时顺手折入新元素即可，转移时取 $\mathrm{runA} - \mathrm{pre}[l]$。
2. **固定 $r$，让 $l$ 减小**：每个 $k$ 的左和变大、$D(k)$ 变大，B 区只会变宽——左端 $k_b$ **只减不增**。于是**每个右端点 $r$ 各存一份** $\mathrm{runB}[r] = \max_{k \in B}\{\mathrm{dp}[k{+}1][r] - \mathrm{pre}[k{+}1]\}$，指针 $q[r]$ 左移时折入新元素，转移时取 $\mathrm{runB}[r] + \mathrm{pre}[r{+}1]$。

最终 $f(l,r) = \max(\text{A 区候选最大值},\ \text{B 区候选最大值})$。两个指针各自全程单向移动，总步数 $O(n^2)$，每步 $O(1)$ 附加簿记——内层 $k$ 循环被彻底干掉。

## 4. 算法细节

1. **前缀和**：$\mathrm{pre}[0] = 0$，$\mathrm{pre}[i+1] = \mathrm{pre}[i] + \mathrm{stoneValue}[i]$；$S(l,k) = \mathrm{pre}[k{+}1] - \mathrm{pre}[l]$，$O(1)$ 取任意子行和。若不用前缀和，每个切分点现算两边和会再乘一个 $n$，退化到 $O(n^4)$。
2. **方法一填表顺序**：外层按区间长度 $\mathrm{len} = 2 \dots n$，中层 $l$，内层枚举 $k$；两个依赖区间长度都严格更短，上一层必已就绪。
3. **方法二循环次序**：外层 $l$ 从 $n-1$ **递减**、内层 $r$ 从 $l+1$ **递增**——算 $\mathrm{dp}[l][r]$ 时用到的 $\mathrm{dp}[k{+}1][r]$（$k+1 > l$）来自更早的外层轮次，$\mathrm{dp}[l][k]$（$k < r$）来自本轮更早的内层次数，均已算好。
4. **公共项必须抽到 max 外面**：runA 折入的是 $\mathrm{dp}[l][k] + \mathrm{pre}[k{+}1]$（$-\mathrm{pre}[l]$ 转移时再减），runB 折入的是 $\mathrm{dp}[k{+}1][r] - \mathrm{pre}[k{+}1]$（$+\mathrm{pre}[r{+}1]$ 转移时再加）。只有这样折入的量才与 $r$（或 $l$）无关，running max 才有意义。
5. **两个不等号都必须带等号**：A 区用 $\le$、B 区用 $\ge$，平局点同时属于两区，两族候选取 max 恰好实现「平局 → 两边取大」的分支（示例 4 的 $[1,2,3]$ 即考此点）。
6. **指针初始化与空窗口**：$p = l - 1$（A 区空）、$q[r] = r$（B 区空），runA、runB 初始化为 $-\infty$；两区可能一空一非空（引理 3 保证至少一区非空），所以 best 也要从 $-\infty$ 起步，最后必被有效候选覆盖。
7. **数据范围**：总分 $< 5 \times 10^8$（§5 推论），$\mathrm{pre} \le 5 \times 10^8$，但 runA 这类中间量可到约 $1.5 \times 10^9$——虽然仍在 `int` 边界内，建议统一 `long long`，$-\infty$ 哨兵取 `LLONG_MIN / 4` 防算术溢出。

## 5. 正确性证明

**引理 1（历史无关性）**：若某时刻当前行为 $[l, r]$，则此后可选的策略集合及各策略的总得分只依赖于 $[l, r]$，与到达该行的切分历史无关。

**证明**：游戏规则的每一步判定（怎么切、两边和多少、丢哪边）都只引用「当前行」的内容；Alice 总分为各轮得分的线性累加，其中每一项只由当轮切分与当时的行决定，不含任何跨轮耦合项。不同历史到达同一行时，后续过程彼此同构。∎

**引理 2（单轮贡献分解）**：设当前行为 $[l, r]$，Alice 本轮选切分点 $k$，则「本轮得分 + 之后最优得分」等于

- $S(l,k) + f(l,k)$，若 $S(l,k) < S(k{+}1,r)$；
- $S(k{+}1,r) + f(k{+}1,r)$，若 $S(l,k) > S(k{+}1,r)$；
- $S(l,k) + \max\{f(l,k), f(k{+}1,r)\}$，若 $S(l,k) = S(k{+}1,r)$。

且三个表达式中每个出现的 $f$ 值都对应一个**可行**策略的得分。

**证明**：前两种情况中 Bob 丢哪边是唯一确定的，Alice 得分为保留侧的和，之后在保留侧（严格更短的行）上继续；由引理 1，后续最优值即保留侧的 $f$。平局时规则允许 Alice 二选一，两种保留方案都可行，取较优者。可行性：每个表达式都对应「本轮切在 $k$（平局时保留相应一侧），之后在保留侧走最优」的具体策略。∎

**定理 1（区间 DP 正确性）**：按 §3.3 递推式计算出的 $\mathrm{dp}[l][r]$ 等于行 $[l, r]$ 上的真实最大得分。

**证明**：对区间长度 $m = r - l + 1$ 归纳。$m = 1$：游戏已结束，得分为 0，与边界一致。$m \ge 2$：任一策略的第一个动作是某个切分 $k$，由引理 2，其总得分等于对应表达式，其中 $f(l,k)$、$f(k{+}1,r)$ 均为严格更短区间上的值，由归纳假设等于真实最优。所有 $k$ 取 max 即全体策略的最优值，恰为递推式右端。∎

**推论 1（得分上界）**：任意局面下，从行 $[0, n-1]$ 出发的总得分 $< S(0, n-1) \le 5 \times 10^8$，且轮数不超过 $\lceil \log_2 S(0,n-1) \rceil + 1$。

**证明**：设第 $t$ 轮开始时行和为 $S_t$。保留侧是和不大的一边，故本轮得分（即保留侧和）满足 $S_{t+1} \le S_t / 2$，归纳得 $S_t \le S_1 / 2^{t-1}$。游戏在有限轮 $T$ 内结束，于是

$$\text{总得分} = \sum_{t=2}^{T+1} S_t \le \sum_{t=2}^{T+1} \frac{S_1}{2^{t-1}} < \sum_{t=2}^{\infty} \frac{S_1}{2^{t-1}} = S_1 \le 5 \times 10^8$$

（有限项几何级数严格小于无穷和）。又 $S_t$ 每轮至少减半，而石子值恒正、行和恒 $\ge 1$，故轮数不超过 $\lceil \log_2 S_1 \rceil + 1$。∎

**引理 3（分界结构）**：对固定区间 $[l, r]$：（i）$D(k) = S(l,k) - S(k{+}1,r)$ 关于 $k$ 在 $[l, r-1]$ 上严格递增，因此 A 区 $= \{k : D(k) \le 0\}$ 是前缀、B 区 $= \{k : D(k) \ge 0\}$ 是后缀，且至少一区非空；（ii）固定 $l$、$r$ 增大时，A 区右端 $k_a$ 单调不减；（iii）固定 $r$、$l$ 减小时，B 区左端 $k_b$ 单调不增。

**证明**：（i）$D(k{+}1) - D(k) = 2\,\mathrm{stoneValue}[k{+}1] > 0$，严格递增，故两个水平集分别为前缀与后缀。若 A 区为空则 $D(l) > 0$，由单调性所有 $D(k) > 0$，B 区为全体切分点；反之亦然，故至少一区非空。（ii）$r$ 每增大一格，对每个旧切分点 $k$，右行吞入石子 $\mathrm{stoneValue}[r{+}1] > 0$，$D(k)$ 严格变小，原 A 区内点仍满足 $D \le 0$，A 区只会右扩（新增最右切分点）。（iii）对称：$l$ 每减小一格，左行吞入让出的那块石子（$> 0$），$D(k)$ 严格变大，原 B 区内点仍满足 $D \ge 0$，B 区只会左扩。∎

**引理 4（窗口不变式）**：方法二在计算 $\mathrm{dp}[l][r]$ 前：（i）$\mathrm{runA}$ 恰为 $\max_{k \in A \cap [l, r-1]}\{\mathrm{pre}[k{+}1] + \mathrm{dp}[l][k]\}$（A 区空时为 $-\infty$）；（ii）$\mathrm{runB}[r]$ 恰为 $\max_{k \in B \cap [l, r-1]}\{\mathrm{dp}[k{+}1][r] - \mathrm{pre}[k{+}1]\}$（B 区空时为 $-\infty$）。

**证明**：（i）固定 $l$，对 $r$ 归纳。切分点 $k$ 在首次满足 $k \le r-1$ 且 $D(k) \le 0$ 的时刻被折入 runA；由引理 3(ii)，此后 $D(k) \le 0$ 恒成立，元素一旦折入永不过期。while 循环从当前 $p$ 起逐个检查 $p+1$：由 $D$ 严格递增，遇到首个不合格点即停，其后所有点都不合格，窗口恰为合格前缀。折入时 $\mathrm{dp}[l][k]$ 已就绪（$k < r$，本轮更早的内层次数；$k = l$ 时为边界 0）。（ii）固定 $r$，对 $l$（递减序）归纳，对称：$k$ 在首次满足 $k \ge l$ 且 $D(k) \ge 0$ 时被折入，由引理 3(iii) 永不过期；while 从 $q[r]$ 起向左检查，窗口恰为合格后缀。折入时 $\mathrm{dp}[k{+}1][r]$ 已就绪（$k + 1 > l$，来自更早的外层轮次；$k+1 = r$ 时为边界 0）。∎

**定理 2（方法二正确性）**：方法二算出的 $\mathrm{dp}[0][n-1]$ 等于 $f(0, n-1)$。

**证明**：对每个 $(l, r)$，两族候选的并集恰好覆盖全部切分点：严格小于 / 严格大于的点各属一族，平局点同属两族。由引理 2，每族候选都是可行策略值；由引理 4，各族内部的最大值计算准确，故 $\mathrm{dp}[l][r] = \max(\text{A 区 max},\ \text{B 区 max})$。对平局点 $k$，两族分别给出 $S + f(l,k)$ 与 $S + f(k{+}1,r)$（$S$ 为相等的左右和），其 max 恰为递推式的平局分支。因此方法二在每一步算出的值与 §3.3 递推式一致，由定理 1 的归纳即得结论。∎

## 6. 复杂度分析

- **方法一时间复杂度**：$O(n^3)$。状态 $O(n^2)$ 个（上三角），每状态枚举至多 $n-1$ 个切分点，前缀和保证求和 $O(1)$；总运算量约 $n^3/6 \approx 2 \times 10^7$，C++ 轻松通过，纯 Python 实测约 4 秒、存在超时风险。
- **方法二时间复杂度**：$O(n^2)$。固定 $l$ 时指针 $p$ 在所有 $r$ 上累计只右移 $O(n)$ 步；固定 $r$ 时指针 $q[r]$ 在所有 $l$ 上累计只左移 $O(n)$ 步；两族合计 $O(n^2)$，其余每状态 $O(1)$ 常数簿记。实测 $n = 500$ 时 Python 约 0.14 秒。
- **空间复杂度**：两法均为 $O(n^2)$（dp 表），另有 $O(n)$ 的前缀和；方法二增加 $O(n)$ 的指针与 runB 数组。

### 方法一：区间 DP，$O(n^3)$（赛时主解）

#### C++

```cpp
class Solution {
public:
    int stoneGameV(vector<int>& stoneValue) {
        int n = stoneValue.size();
        vector<int> pre(n + 1, 0);
        for (int i = 0; i < n; i++) pre[i + 1] = pre[i] + stoneValue[i];
        // dp[l][r] = f(l, r)：行 [l, r] 上的最大后续得分
        vector<vector<int>> dp(n, vector<int>(n, 0));
        for (int len = 2; len <= n; len++) {
            for (int l = 0; l + len - 1 < n; l++) {
                int r = l + len - 1;
                int best = 0;
                for (int k = l; k < r; k++) {
                    int leftSum  = pre[k + 1] - pre[l];
                    int rightSum = pre[r + 1] - pre[k + 1];
                    int cur;
                    if (leftSum < rightSum)      cur = leftSum  + dp[l][k];
                    else if (leftSum > rightSum) cur = rightSum + dp[k + 1][r];
                    else                         cur = leftSum  + max(dp[l][k], dp[k + 1][r]);
                    best = max(best, cur);
                }
                dp[l][r] = best;
            }
        }
        return dp[0][n - 1];
    }
};
```

```python
class Solution:
    def stoneGameV(self, stoneValue: List[int]) -> int:
        n = len(stoneValue)
        pre = [0] * (n + 1)
        for i, x in enumerate(stoneValue):
            pre[i + 1] = pre[i] + x

                    elif left_sum > right_sum:
                        cur = right_sum + dp[k + 1][r]
                    else:
                        cur = left_sum + max(dp[l][k], dp[k + 1][r])
                    if cur > best:
                        best = cur
                dp[l][r] = best
```

### 方法二：单调分界 + 前缀最大值，$O(n^2)$

#### C++

```cpp
class Solution {
public:
    int stoneGameV(vector<int>& stoneValue) {
        int n = stoneValue.size();
        if (n == 1) return 0;                 // 单块直接结束（不特判也能由边界覆盖）
        vector<long long> pre(n + 1, 0);
        for (int i = 0; i < n; i++) pre[i + 1] = pre[i] + stoneValue[i];
        const long long NEG = LLONG_MIN / 4;  // 安全的 -inf
        vector<vector<long long>> dp(n, vector<long long>(n, 0));
        vector<int> q(n);                     // B 区窗口左端（按右端点 r 各一份）
        vector<long long> runB(n, NEG);       // B 区候选的前缀最大值
        for (int r = 0; r < n; r++) q[r] = r; // 窗口 [r, r-1] 即空
        for (int l = n - 2; l >= 0; l--) {    // l 递减：dp[k+1][r] 已就绪
            int p = l - 1;                    // A 区窗口右端（固定 l 时全程共享）
            long long runA = NEG;
            for (int r = l + 1; r < n; r++) { // r 递增：dp[l][k] 已就绪
                // A 区扩张：新切分点 k = p+1，条件 左和 <= 右和
                while (p + 1 <= r - 1 && pre[p + 2] - pre[l] <= pre[r + 1] - pre[p + 2]) {
                    p++;
                    runA = max(runA, dp[l][p] + pre[p + 1]);
                }
                // B 区扩张：新切分点 k = q[r]-1，条件 左和 >= 右和
                while (q[r] > l && pre[q[r]] - pre[l] >= pre[r + 1] - pre[q[r]]) {
                    q[r]--;
                    runB[r] = max(runB[r], dp[q[r] + 1][r] - pre[q[r] + 1]);
                }
                long long best = NEG;
                if (p >= l)         best = max(best, runA - pre[l]);       // 左和 + dp[l][k]
                if (q[r] <= r - 1)  best = max(best, runB[r] + pre[r + 1]); // 右和 + dp[k+1][r]
                dp[l][r] = best;
            }
        }
        return (int)dp[0][n - 1];
    }
};
```

#### Python

```python
class Solution:
    def stoneGameV(self, stoneValue: List[int]) -> int:
        n = len(stoneValue)
        if n == 1:
            return 0
        pre = [0] * (n + 1)
        for i, x in enumerate(stoneValue):
            pre[i + 1] = pre[i] + x
        NEG = float('-inf')
        dp = [[0] * n for _ in range(n)]
        q = list(range(n))          # B 区窗口左端（按右端点 r 各一份）
        runB = [NEG] * n
        for l in range(n - 2, -1, -1):
            p = l - 1               # A 区窗口右端（固定 l 时全程共享）
            runA = NEG
            for r in range(l + 1, n):
                while p + 1 <= r - 1 and pre[p + 2] - pre[l] <= pre[r + 1] - pre[p + 2]:
                    p += 1
                    runA = max(runA, dp[l][p] + pre[p + 1])
                while q[r] > l and pre[q[r]] - pre[l] >= pre[r + 1] - pre[q[r]]:
                    q[r] -= 1
                    runB[r] = max(runB[r], dp[q[r] + 1][r] - pre[q[r] + 1])
                best = NEG
                if p >= l:
                    best = max(best, runA - pre[l])
                if q[r] <= r - 1:
                    best = max(best, runB[r] + pre[r + 1])
                dp[l][r] = best
        return dp[0][n - 1]
```

## 8. 边界情况与易错点

1. **$n = 1$ 返回 0**：方法一的长度循环从 2 开始，天然返回初值 0；方法二外层 $l$ 从 $n-2 = -1$ 起不进循环，同样返回 0（代码里的显式特判只是可读性）。
2. **平局分支必须取 max**：漏掉后示例 4（$[1,2,3]$）会输出 3 而非 4。方法二里对应「A 区用 $\le$、B 区用 $\ge$」，两个等号缺一个就会静默丢掉平局点。
3. **切分两侧都必须非空**：$k \in [l, r-1]$。方法二两个 while 里的 `p + 1 <= r - 1` 与 `q[r] > l` 正是这道护栏，删掉会把空行当合法切分。
4. **溢出**：总分与 $\mathrm{pre}$ 均 $< 5 \times 10^8$（推论 1），`int` 存得下；但 runA $= \mathrm{dp} + \mathrm{pre}$ 可达约 $1.5 \times 10^9$，且 $-\infty$ 哨兵参与运算，C++ 建议 `long long` 并用 `LLONG_MIN / 4`。
5. **方法二的循环方向**：外层 $l$ 必须递减（保证 $\mathrm{dp}[k{+}1][r]$ 就绪）、内层 $r$ 必须递增（保证 $\mathrm{dp}[l][k]$ 就绪），方向写反会在指针折入时读到未初始化的值。
6. **runB 按右端点开 $n$ 份，runA 只需一份**：A 区窗口随 $r$ 增长（同一 $l$ 内共享），B 区窗口随 $l$ 左移（不同 $r$ 各自独立），维度搞反指针就不单调了。
7. **Python 慎用方法一**：$O(n^3)$ 在 $n = 500$ 实测约 4 秒，超时边缘；记忆化递归还叠加栈与 `lru_cache` 开销，更慢。换方法二（约 0.14 秒）一步到位。
8. **别把 Bob 当对手**：状态记「累计得分」而非「差值」，转移里没有减号——这是与 877 / 1690 一族零和博弈题最本质的分野。
