# LeetCode 掉落的方块 题解

## 1. 题目概述

- **标题 / 题号**：掉落的方块（#699，hard）
- **链接**：https://leetcode.cn/problems/falling-squares/
- **来源**：LeetCode 第 54 场周赛 Q4
- **难度**：困难
- **标签**：线段树，数组，有序集合

**题意**：方块按给定顺序一块块从无穷高处沿 $y$ 轴负方向落下，`positions[i] = [left, side]` 表示第 $i$ 块的左边贴 $x = left$、边长为 $side$。方块下落直到**底边压到某块已落稳方块的顶边**或落到 $x$ 轴上；仅仅擦过另一块的左右侧边不算着陆。每落一块就记录当前所有方块堆叠的最高高度，返回这个高度序列。

**约束**：

- $1 \le \text{positions.length} \le 1000$
- $1 \le left_i \le 10^8$
- $1 \le sideLength_i \le 10^6$

坐标跨度 $10^8$ 意味着不能按 $x$ 开数组；边长上限 $10^6$ 与块数上限 $1000$ 相乘，最高堆叠可达 $10^9$，答案仍在 32 位整数内，但中间量用 64 位更稳。

## 2. 示例

**示例 1**

```text
输入：positions = [[1,2],[2,3],[6,1]]
输出：[2,5,5]
解释：第 1 块落地，最高 2；
      第 2 块压在第 1 块上（[2,3) 与 [1,3) 重叠），顶边到 2+3=5；
      第 3 块落在 [6,7) 的空地上，高 1，低于已有最高 5，故答案不变。
```

**示例 2**

```text
输入：positions = [[100,100],[200,100]]
输出：[100,100]
解释：第 2 块区间 [200,300) 与第 1 块的 [100,200) 只在 x=200 处相接，
      擦右侧边不算着陆，两块都直接落在地面上，最高高度始终是 100。
```

## 3. 解题思路

### 3.1 暴力思路

最朴素的想法是按 $x$ 建一个高度数组，每个方块扫一遍自己的宽度、取最大值、整段改写。但坐标上界是 $10^8 + 10^6$，数组开不出来，必须先压缩坐标。

次一等的做法是只维护「已落稳方块列表」 $(left, right, height)$：每落一块，线性扫描所有旧方块求重叠区间的最大高度，再把新区间追加进去。复杂度 $O(n^2)$，$n = 10^3$ 时约 $10^6$ 次比较，**恰好能通过本题的数据**。但它没有沉淀出可复用的结构：$n = 10^5$ 就崩，也没法回答「某个区间当前最高多少」这类中途查询。既然是复盘，我们直接做到 $O(n\log n)$。

### 3.2 核心观察：高度场是分段常值的阶梯

![高度场阶梯与区间取最大](images/wc54_q4_height_profile.svg)

把「已经落稳的所有方块的最高顶边」看成定义在 $x$ 轴上的函数 $H(x)$：它只会在方块端点处跳变，是**分段常值**的阶梯函数。

由此得到两条关键性质。

**落点公式**：新方块 $i$ 的投影是半开区间 $[l_i,\ l_i + s_i)$，它落定后的底边高度取投影区间内的最大高度，即

$$M_i = \max_{x \in [l_i,\ l_i + s_i)} H(x), \qquad h_i = M_i + s_i,$$

其中区间内没有方块时约定 $M_i = 0$（直接落到 $x$ 轴上），$h_i$ 是落定后的顶边高度。

**整段赋值**：方块落定后，投影区间内每一列的「最高顶边」都恰好变成 $h_i$，区间外一概不变。

第二条性质把「取最大再更新」变成了**区间赋值**：因为 $h_i = M_i + s_i \ge M_i$，而区间内任何旧值都不超过 $M_i$，所以「对区间取 $\max$ 后再写 $h_i$」与「直接把整段赋成 $h_i$」完全等价，懒标记因此只需要一种操作。

于是问题变成：在长度 $m = O(n)$ 的数组上，支持**区间查询最大值**、**区间整段赋值**、**全局最大值**——线段树的标准三件套。答案序列还要再取一次前缀最大：$ans_i = \max_{j \le i} h_j$，因为堆叠最高高度只增不减。

### 3.3 算法流程：坐标压缩 + 懒标记线段树

![坐标压缩与懒标记线段树流程](images/wc54_q4_lazy_segment_tree.svg)

1. **坐标压缩**：收集所有端点 $xs = \mathrm{sort}(\mathrm{unique}\{l_i,\ l_i + s_i\})$，相邻端点夹出 $m = |xs| - 1$ 个**基本区间** $[xs_j,\ xs_{j+1})$。由于每个基本区间内部不含任何方块边界，$H$ 在其上恒为常数，一个下标 $j$ 就能代表它。
2. **区间映射**：方块 $[l_i,\ l_i+s_i)$ 恰好覆盖基本区间 $[L_i,\ R_i - 1]$，其中 $L_i = \mathrm{idx}(l_i)$、$R_i = \mathrm{idx}(l_i + s_i)$。半开区间天然处理「擦边不算着陆」。
3. **线段树节点**：维护 $mx$（该段基本区间的最大高度）与 $tag$（懒赋值标记，$-1$ 表示无标记）。
4. **`query(L, R)`**：整段被覆盖则直接返回 $mx$；否则先 `push` 下传标记，再递归左右取 $\max$。
5. **落定**：$base = query(L_i, R_i-1)$，$h_i = base + s_i$，再 `assign(L_i, R_i-1, h_i)` 把整段写成 $h_i$。
6. **记录答案**：$best \leftarrow \max(best, h_i)$，`ans` 追加 $best$。

注意第 6 步**不必**回读树根：树根的最大值只会因新方块而增大，因此 $best$ 与树根同步，用 $h_i$ 更新即可（少一次遍历）。

### 3.4 示例演算

![示例 1 的逐步走查与最终高度场](images/wc54_q4_walkthrough.svg)

对 `positions = [[1,2],[2,3],[6,1]]`，端点集合是 $\{1,2,3,5,6,7\}$，基本区间为 $[1,2),[2,3),[3,5),[5,6),[6,7)$，共 $m = 5$ 段：

| $i$ | 投影区间 | 覆盖的基本区间 | 查询 $base$ | $h_i = base + s_i$ | 高度场 $H$ | $ans_i$ |
|-----|----------|----------------|-------------|--------------------|------------|---------|
| 1 | $[1,3)$ | $[1,2),[2,3)$ | 0 | $0+2=2$ | 前两段都是 $2$ | 2 |
| 2 | $[2,5)$ | $[2,3),[3,5)$ | 2（来自 $[2,3)$） | $2+3=5$ | 首段 $2$，中间两段 $5$ | 5 |
| 3 | $[6,7)$ | $[6,7)$ | 0 | $0+1=1$ | 末段 $1$，其余不变 | 5 |

第 3 块虽然落定，但它只到高度 $1$，历史最高仍是 $5$，所以 $ans_3 = 5$。最终高度场就是阶梯 $2,5,5,0,1$，答案序列 $2,5,5$ 单调不减。

## 4. 算法细节

1. **半开区间是硬性要求**：投影取 $[l,\ l+s)$，映射到基本区间是 $[\mathrm{idx}(l),\ \mathrm{idx}(l+s) - 1]$。若写成闭环区间，示例 2 中 $x = 200$ 处的擦边会被误判成着陆，答案变错。
2. **懒标记用 $-1$ 而非 $0$**：高度恒为正，$0$ 是合法初值，用 $0$ 表示「无标记」会让 `push` 把真实的 $0$ 当成空操作。C++ 里 `lazy` 初始化为 $-1$，Python 同理。
3. **查询与赋值都要先 `push`**：只要走到部分覆盖的节点，就必须把父节点的整体赋值下传，否则子节点读到的是过期值。赋值在整段覆盖时直接 `apply`（同时改 $mx$ 与 $tag$），不再往下走。
4. **回写父节点**：`assign` 递归结束后 `mx[o] = max(mx[2o], mx[2o+1])`；`query` 是只读操作，`push` 之后不必回写（父节点的 $mx$ 已等于两子最大值，下传不改变它）。
5. **树的大小**：$|xs| \le 2n$，$m \le 2n - 1$，开 $4m$ 个节点足够；$m = 1$ 时树退化成单叶子，`query/assign` 的区间都是 $[0,0]$，代码无需特判。
6. **高度用 64 位**：$h_i$ 最坏 $1000 \times 10^6 = 10^9$，32 位整数恰好装得下，但 C++ 中统一用 `long long` 计算、只在写答案时转 `int`，避免加法溢出踩坑。
7. **答案单调性**：$ans_i = \max(ans_{i-1}, h_i)$，不要直接写 $h_i$；也不要漏掉「本来就没有刷新最高高度」的轮次（示例 1 的第 3 块）。

## 5. 正确性证明

**引理 1（落点公式）**：设落第 $i$ 块前的高度场为 $H$，区间 $[l_i,\ l_i+s_i)$ 上的最大值为 $M_i$（区间内无方块则 $M_i = 0$），则第 $i$ 块落定后底边高度恰为 $M_i$，顶边高度 $h_i = M_i + s_i$。

**证明**：设 $x_0 \in [l_i,\ l_i+s_i)$ 使 $H(x_0) = M_i$。若底边高度 $y > M_i$，则对投影区间内任意 $x$ 都有 $y > M_i \ge H(x)$，方块底边高于所有已落方块的顶边，不会接触任何支撑面，继续下落。当底边降到 $y = M_i$ 时，$x_0$ 处恰好有一块已落稳方块（或地面，当 $M_i=0$）的顶边等于 $M_i$，方块在该点着陆并冻结，不会继续下移。故底边为 $M_i$，顶边为 $M_i + s_i$。∎

**引理 2（整段赋值）**：第 $i$ 块落定后，对任意 $x \in [l_i,\ l_i+s_i)$ 有 $H'(x) = h_i$，区间外 $H'(x) = H(x)$。

**证明**：由引理 1，方块占据 $y \in [M_i,\ h_i]$ 且覆盖整个投影区间，故区间内每一列的「最高顶边」至少是 $h_i$；又 $h_i = M_i + s_i > M_i \ge H(x)$，原高度都低于它，所以恰好等于 $h_i$。方块不覆盖区间外的点，那些列的顶边不变。∎

**引理 3（线段树不变量）**：任意时刻，每个节点 $o$ 的 $mx[o]$ 等于其管辖基本区间段上 $H$ 的最大值；若 $tag[o] \ne -1$，则该段内所有基本区间的高度都等于 $tag[o]$，且 $mx[o] = tag[o]$。

**证明**：对操作次数归纳。初始全 $0$，不变量成立。`query` 只读不写，`push` 把父亲的统一赋值写给两个儿子（此时儿子段内全为 $tag$，$mx$ 与 $tag$ 同步），父亲清空标记，不变量保持。`assign` 分两种情形：整段覆盖时直接令 $mx[o] = tag[o] = v$，由引理 2 该段全为 $v$，成立；部分覆盖时先 `push`，递归处理两个儿子后回写 $mx[o] = \max(mx[2o], mx[2o+1])$，由归纳假设两儿子正确，故父亲的最大值正确。∎

**定理**：算法输出的 $ans_i$ 等于第 $i$ 块落定后所有方块堆叠的最高高度。

**证明**：由引理 1、2，每块落定后真实高度场与算法维护的高度场一致；由引理 3，`query` 返回的 $base$ 正是投影区间内的真实最高高度，`assign` 之后树中数据仍与真实高度场一致。于是 $ans_i = \max_{j \le i} h_j$。而任一时刻的最高堆叠高度就是高度场 $H$ 在整条 $x$ 轴上的最大值 $\max_x H(x)$，它只在落定高度创纪录时被刷新，即 $\max_{j \le i} h_j$。故输出正确。∎

## 6. 复杂度分析

- **时间**：$O(n \log n)$。坐标压缩排序 $O(n \log n)$；每个方块一次区间查询加一次区间赋值，单次 $O(\log m) = O(\log n)$，共 $O(n \log n)$。
- **空间**：$O(n)$。端点数组至多 $2n$ 个；线段树 $4m \le 8n$ 个节点的 $mx$ 与 $tag$，外加答案数组。

## 7. 参考代码

### C++

```cpp
class Solution {
    vector<long long> mx, lazy;
    void apply(int o, long long v) { mx[o] = v; lazy[o] = v; }
    void push(int o) {
        if (lazy[o] != -1) {
            apply(o << 1, lazy[o]);
            apply(o << 1 | 1, lazy[o]);
            lazy[o] = -1;
        }
    }
    void assign(int o, int l, int r, int ql, int qr, long long v) {
        if (ql <= l && r <= qr) { apply(o, v); return; }
        push(o);
        int mid = (l + r) >> 1;
        if (ql <= mid) assign(o << 1, l, mid, ql, qr, v);
        if (qr > mid) assign(o << 1 | 1, mid + 1, r, ql, qr, v);
        mx[o] = max(mx[o << 1], mx[o << 1 | 1]);
    }
    long long query(int o, int l, int r, int ql, int qr) {
        if (ql <= l && r <= qr) return mx[o];
        push(o);
        int mid = (l + r) >> 1;
        long long res = 0;
        if (ql <= mid) res = query(o << 1, l, mid, ql, qr);
        if (qr > mid) res = max(res, query(o << 1 | 1, mid + 1, r, ql, qr));
        return res;
    }

public:
    vector<int> fallingSquares(vector<vector<int>>& positions) {
        vector<int> xs;
        for (auto& p : positions) {
            xs.push_back(p[0]);
            xs.push_back(p[0] + p[1]);
        }
        sort(xs.begin(), xs.end());
        xs.erase(unique(xs.begin(), xs.end()), xs.end());
        int m = (int)xs.size() - 1;
        mx.assign(4 * m, 0);
        lazy.assign(4 * m, -1);

        vector<int> ans;
        long long tallest = 0;
        for (auto& p : positions) {
            int ql = lower_bound(xs.begin(), xs.end(), p[0]) - xs.begin();
            int qr = lower_bound(xs.begin(), xs.end(), p[0] + p[1]) - xs.begin() - 1;
            long long h = query(1, 0, m - 1, ql, qr) + p[1];
            assign(1, 0, m - 1, ql, qr, h);
            tallest = max(tallest, h);
            ans.push_back((int)tallest);
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def fallingSquares(self, positions: list[list[int]]) -> list[int]:
        xs = sorted({x for left, side in positions for x in (left, left + side)})
        idx = {x: i for i, x in enumerate(xs)}
        m = len(xs) - 1                      # 基本区间个数
        mx = [0] * (4 * m)                   # 区间最大高度
        tag = [-1] * (4 * m)                 # 懒赋值标记，-1 表示无

        def push(o: int) -> None:
            v = tag[o]
            if v != -1:
                mx[o << 1] = mx[o << 1 | 1] = v
                tag[o << 1] = tag[o << 1 | 1] = v
                tag[o] = -1

        def assign(o: int, l: int, r: int, ql: int, qr: int, v: int) -> None:
            if ql <= l and r <= qr:
                mx[o] = tag[o] = v
                return
            push(o)
            mid = (l + r) >> 1
            if ql <= mid:
                assign(o << 1, l, mid, ql, qr, v)
            if qr > mid:
                assign(o << 1 | 1, mid + 1, r, ql, qr, v)
            mx[o] = max(mx[o << 1], mx[o << 1 | 1])

        def query(o: int, l: int, r: int, ql: int, qr: int) -> int:
            if ql <= l and r <= qr:
                return mx[o]
            push(o)
            mid = (l + r) >> 1
            res = 0
            if ql <= mid:
                res = query(o << 1, l, mid, ql, qr)
            if qr > mid:
                res = max(res, query(o << 1 | 1, mid + 1, r, ql, qr))
            return res

        ans, tallest = [], 0
        for left, side in positions:
            l = idx[left]
            r = idx[left + side] - 1          # 半开区间 → 基本区间下标
            height = query(1, 0, m - 1, l, r) + side
            assign(1, 0, m - 1, l, r, height)
            tallest = max(tallest, height)
            ans.append(tallest)
        return ans
```

## 8. 边界情况与易错点

1. **擦边误判**：`[[1,2],[3,2]]` 只在 $x=3$ 相接，第二块必须落到地面，答案 $[2,2]$。用半开区间并映射成 $[\mathrm{idx}(l),\ \mathrm{idx}(l+s)-1]$ 才对；若把右端点也纳入区间，会把 $x=3$ 这一「零宽接触」算成着陆。
2. **懒标记哨兵值**：高度可能是 $0$（初始）也可能是任意正数，标记的「无」只能用 $-1$（或用一个高度取不到的哨兵值）。用 $0$ 当空标记会把「整段被赋成 0」误判为无标记。
3. **漏掉「最高高度不变」的轮次**：$ans$ 是前缀最大值，不是每块的 $h_i$（示例 1 第 3 块 $h_3 = 1$，输出仍是 $5$）。
4. **完全包含 / 完全重合**：`[[1,10],[2,1]]` → $[10, 11]$；`[[1,2],[1,2],[1,2]]` → $[2,4,6]$。重合区间的 $\max$ 查询必须能正确返回前一块的顶边。
5. **单块与 $m=1$**：只有一块时端点两个、$m=1$，线段树单叶子；若代码按 $m \ge 2$ 写死递归区间会越界。
6. **溢出**：最坏 $1000$ 块、每块边长 $10^6$、位置全重合时高度达到 $10^9$，加法用 `long long`，避免中间量按 `int` 计算时溢出。
