# LeetCode 时钟指针的夹角 题解

## 1. 题目概述

- **标题 / 题号**：时钟指针的夹角（#1344，medium）
- **链接**：https://leetcode.cn/problems/angle-between-hands-of-a-clock/
- **来源**：LeetCode 第 19 场双周赛 Q3
- **难度**：中等
- **标签**：数学

**题意**：给定小时数 `hour`（$1 \sim 12$）与分钟数 `minutes`（$0 \sim 59$），求该时刻时钟上**时针与分针的较小夹角**（单位：度）。与标准答案误差在 $10^{-5}$ 内即算正确。

**约束**：

- $1 \le hour \le 12$
- $0 \le minutes \le 59$
- 答案误差容忍 $10^{-5}$

## 3. 解题思路

### 3.1 暴力思路

按分钟为最小刻度模拟指针转动会引入不必要的离散化误差；而「查表」需要 $12 \times 60 = 720$ 个时刻，虽然可行但完全没必要。这题的正解是把两根针的位置各自写成**关于时间的线性函数**，再在圆周上取两点夹角。

### 3.2 核心观察：两根针都是匀速转动的，位置 = 角速度 × 时间

![两针转速与劣角：min(θ,360°−θ)](images/bw19_q3_speed_formula.svg)

以 12 点方向为 $0°$、顺时针为正：

- **分针**每 60 分钟转一整圈 $360°$，角速度 $6°/\text{分}$，位置 $= 6m$；
- **时针**每 12 小时（720 分）转一整圈，角速度 $0.5°/\text{分}$，位置 $= 30(h \bmod 12) + 0.5m$。

注意时针位置由**两项**组成：整点对齐的部分 $30h$ 加上随分钟爬行的部分 $0.5m$——「分钟数也推着时针走」正是本题最常见的失分点（比如 12:30 的时针不在 12 点整，而是过了 $15°$）。

### 3.3 算法流程

![12:30钟面：时针15°、分针180°、夹角165°](images/bw19_q3_clock_1230.svg)

```text
1. minuteAngle = 6 × minutes
2. hourAngle   = 30 × (hour mod 12) + 0.5 × minutes
3. diff = |hourAngle − minuteAngle|
4. 返回 min(diff, 360 − diff)        # 取劣角（不超过 180°）
```

第 4 步不可省：两根针把圆周分成两段圆弧，题目要**较小角**。例如 9:00 算出差 $270°$，答案却是 $90°$。

### 3.4 示例演算

- **12:30**：时针 $= 30 \times 0 + 0.5 \times 30 = 15°$，分针 $= 180°$，差 $165°$，$\min(165, 195) = 165$ ✓；
- **3:15**：时针 $= 90 + 7.5 = 97.5°$，分针 $= 90°$，差 $7.5°$ ✓（分数角度来自 $0.5m$）；
- **12:00**：两针重合，差 $0°$ ✓。

## 4. 算法细节

1. **`hour mod 12`**：$hour = 12$ 必须先归零（$12$ 点整的时针角度是 $0°$ 而非 $360°$），否则 `30 * 12 = 360` 虽然数值上不破坏夹角（$360$ 与 $0$ 同余），但依赖巧合不如显式取模。
2. **浮点的精确性**：所有出现的量都是 $\frac{m}{2}$ 的形式（$0.5$ 的整倍数），而 $0.5 = 2^{-1}$ 可被 `double` **精确**表示，因此 `abs`、`min` 参与的计算没有任何舍入误差，输出只可能是 `x.0` 或 `x.5`。
3. **等价公式**：$\theta = |30h' - 5.5m|$（$h' = h \bmod 12$），把分针对时针的相对运动（$5.5°/\text{分}$）压进一个式子；两种写法对所有 $720$ 个时刻逐一验证等价。
4. **避免浮点的写法**：全程用「半度」为单位做整数运算：$M = 2m$（分针 $3M$ 半度），$H = 60h' + m$（时针半度数），$d = \min(|H - 3M|,\ 720 - |H - 3M|)$，返回 $d / 2.0$。本题没必要，但值得知道。
5. **追及视角（扩展）**：分针相对时针 $5.5°/\text{分}$，重合周期 $720/11 \approx 65.45$ 分钟，12 小时共重合 11 次——这是「时针分针一天重合几次」这类面试变体的钥匙。

## 5. 正确性证明

**引理 1（指针位置公式）**：在时刻 $(h, m)$（$0 \le m \le 59$），从 12 点方向顺时针量起，分针角度为 $6m$，时针角度为 $30(h \bmod 12) + 0.5m$。

**证明**：分针 60 分转 $360°$ 且匀速，故每分 $6°$，$m$ 分即在 $0$ 基础上转过 $6m$。时针 720 分转 $360°$，每分 $0.5°$；在 $h$ 点 $m$ 分，时针从最近走过的整点 $h$（位置 $30(h \bmod 12)$，因 12 点位置与 0 点重合）起又走了 $m$ 分，再加 $0.5m$。两针均随时间匀速连续转动，线性叠加即得。∎

**引理 2（圆周两点的夹角）**：设两针角度为 $\alpha, \beta \in [0, 360)$，令 $d = |\alpha - \beta|$，则两针的夹角（两条射线在平面上形成的四个角中的最小者）为 $\min(d, 360 - d) \in [0, 180]$。

**证明**：两射线把圆心处的平面分成两对对顶角，度数分别为 $d$ 与 $360 - d$（射线间的两段圆弧对应）。平面上两射线的夹角定义为不超过 $180°$ 的那个角。若 $d \le 180$，则 $360 - d \ge 180$，最小角为 $d$；若 $d > 180$，最小角为 $360 - d < 180$。两种情况统一为 $\min(d, 360 - d)$，其值域恰为 $[0, 180]$。∎

**定理**：算法返回值等于时刻 $(h, m)$ 时针与分针的较小夹角。

**证明**：由引理 1，第 1、2 步算出的正是两针（从 12 点方向起）的角度；第 3 步取其差的绝对值 $d \in [0, 360)$；由引理 2，$\min(d, 360 - d)$ 即所求夹角。浮点计算只涉及可精确表示的 $0.5$ 倍数与整数，无舍入，返回值精确。∎

## 6. 复杂度分析

- **时间**：$O(1)$——常数次算术运算与一次比较。
- **空间**：$O(1)$——三个标量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    double angleClock(int hour, int minutes) {
        double minuteAngle = minutes * 6.0;                       // 分针：6 度/分
        double hourAngle = (hour % 12) * 30.0 + minutes * 0.5;    // 时针：30 度/时 + 0.5 度/分
        double diff = fabs(hourAngle - minuteAngle);
        return min(diff, 360.0 - diff);                           // 取劣角
    }
};
```

### Python

```python
class Solution:
    def angleClock(self, hour: int, minutes: int) -> float:
        minute_angle = minutes * 6.0
        hour_angle = (hour % 12) * 30.0 + minutes * 0.5
        diff = abs(hour_angle - minute_angle)
        return min(diff, 360.0 - diff)
```

> 💡 两份代码均通过全部 5 个官方示例（`165`、`75`、`7.5`、`155`、`0`），并用等价公式 $\min(|30h' - 5.5m|, 360 - |30h' - 5.5m|)$ 对 $12 \times 60 = 720$ 个时刻逐一交叉验证，全部一致。

## 8. 边界情况与易错点

1. **$hour = 12$**：必须 `hour % 12` 归零处理，否则 12:00 会得到差 $360°$（好在 $\min$ 兜底仍输出 $0$，但 12:30 等时刻直接算错就没了兜底巧合）。
2. **忘记取劣角**：9:00 的裸差是 $270°$，必须 `min(diff, 360 - diff)` 得 $90°$；漏掉这一步约一半用例会错。
3. **忘记分钟推动时针**：3:15 若写成 $90°$（整点位置）会得 $0°$，正确是 $97.5°$、夹角 $7.5°$。
4. **浮点写法**：`0.5` 的倍数在 `double` 下精确，无需 epsilon；但若改成 `0.25°` 刻度（更细的钟）就要小心精度。整数「半度」方案见 §4。
5. **返回类型是 `double`**：C++ 别顺手写成 `int` 截断 $7.5$；Python 2/3 的 `/` 差异在本题用 `float` 字面量天然规避。
6. **夹角恰为 180°**（如 6:00）：$\min(180, 180) = 180$，两种取法一致，无需特判。
