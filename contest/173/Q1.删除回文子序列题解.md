# LeetCode 删除回文子序列 题解

## 1. 题目概述

- **标题 / 题号**：删除回文子序列（#1332，easy）
- **链接**：https://leetcode.cn/problems/remove-palindromic-subsequences/
- **来源**：LeetCode 第 173 场周赛 Q1
- **难度**：简单
- **标签**：双指针、字符串

**题意**：给定一个只由 `'a'` 和 `'b'` 组成的字符串 `s`。一次操作可以从中删除**任意一个回文子序列**（子序列不要求连续，但必须保持相对顺序）。求把 `s` 删成空串所需的**最少操作次数**。

**约束**：

- $1 \le \lvert s \rvert \le 1000$
- `s[i]` 只可能是 `'a'` 或 `'b'`

这题的全部难度都在「敢不敢下结论」：看到「删除回文子序列」很容易联想到最长回文子序列、区间 DP，但真正决定答案的只有一件事——**`s` 本身是不是回文**。

## 2. 示例

**示例 1**

```text
输入：s = "ababa"
输出：1
解释：s 本身就是回文，整串作为回文子序列一次删除即可。
```

**示例 2**

```text
输入：s = "abb"
输出：2
解释："a" + "bb" 一次删完：删回文子序列 "a" 得 "bb"，再删 "bb" 得 ""。
```

**示例 3**

```text
输入：s = "baabb"
输出：2
解释：删回文子序列 "baab"（下标 0,1,2,3）得 "b"，再删 "b" 得 ""。
      注意无法一次删完，因为 "baabb" 不是回文（s[1]='a' ≠ s[3]='b'）。
```

## 3. 解题思路

### 3.1 暴力思路

**做法 A：模拟贪心。** 每一步枚举所有回文子序列、挑最长的一条删掉，重复到串空。$s$ 的子序列共有 $2^n$ 个，$n = 1000$ 时枚举量是天文数字；而且「每步都删最长的回文子序列」这个贪心本身也需要证明，并不天然正确。

**做法 B：区间 DP。** 设 $f(l,r)$ 为删空 $s[l..r]$ 的最少次数，转移要枚举「第一次操作覆盖了哪些位置」，状态至少 $O(n^2)$ 个、转移 $O(n)$，总 $O(n^3)$，对 $n = 1000$ 仍然过不去。

**做法 C：最长回文子序列（LPS）。** 直觉是「LPS 覆盖整串才能 1 次删完」，于是算 $O(n^2)$ 的 LPS 判断 $s$ 是否回文。判断 $s$ 是否回文这件事本身只需 $O(n)$，把 LPS 拿来判回文是**用牛刀杀鸡**；而且 LPS 只回答「答案是不是 1」，剩下的情形它给不出更多信息。

三条路都在给题目加难度，而题目其实只要求一个 $O(n)$ 的判定。

### 3.2 核心观察：答案只可能是 1 或 2

![只有 a、b 两种字母，答案只能是 1 或 2](images/wc173_q1_answer_only_1_or_2.svg)

关键点在于**字母表只有两个字符**，于是：

- 把 `s` 中**所有** `'a'` 按原顺序取出来，得到一个全由 `'a'` 组成的子序列；所有字符相同的串显然回文，所以它是一条**回文子序列**。
- 同理，把所有 `'b'` 取出来，也是一条回文子序列。

也就是说，无论 `s` 长什么样：

1. 先删「全部 `'a'` 子序列」，剩下一串纯 `'b'`；
2. 再删「全部 `'b'` 子序列」，串就空了。

**两次操作永远够用**，于是答案的上界是 2。另一方面，非空串不可能用 0 次删空，答案下界是 1。所以答案只能落在 $\{1, 2\}$ 里，唯一要回答的问题是：能不能**一次**删完？

一次删完整串，等价于「整个 `s` 本身是一条回文子序列」，也就等价于 **`s` 是回文串**。至此答案被完全确定：

$$\text{answer} = \begin{cases} 1, & s \text{ 是回文} \\ 2, & s \text{ 不是回文} \end{cases}$$

### 3.3 算法流程

![双指针判回文并分派答案](images/wc173_q1_two_pointer_check.svg)

1. 令 $i = 0$、$j = n-1$。
2. 当 $i < j$ 时：若 $s[i] \ne s[j]$，立即返回 `2`；否则 $i$ 右移一位、$j$ 左移一位。
3. 循环正常结束（两指针相遇或交错），说明所有对称位置都相等，返回 `1`。

一句话概括：**双指针判回文，是回文返回 1，否则返回 2**。

### 3.4 示例演算

![三个官方示例的判定走查](images/wc173_q1_walkthrough.svg)

| $s$ | 双指针过程 | 是否回文 | 答案 |
|---------|------------|----------|------|
| `"ababa"` | `s[0]=s[4]`、`s[1]=s[3]`，最后 $i$ 与 $j$ 都停在 2 | 是 | 1 |
| `"abb"` | 首轮 `s[0]='a' ≠ s[2]='b'`，立即失配 | 否 | 2 |
| `"baabb"` | `s[0]=s[4]='b'` 相等；次轮 `s[1]='a' ≠ s[3]='b'` 失配 | 否 | 2 |

值得注意的是 `"baabb"`：它的最长回文子序列是 `"baab"`（长度 4 < 5），答案却是 2 而不是 3——因为 `"b"` 也自成一条回文子序列，`"a"` 组 + `"b"` 组两步就清空了。**答案与「最长回文子序列能否覆盖全串」无关，只与「$s$ 是否回文」有关。**

## 4. 算法细节

1. **前置条件要用足**：结论 $2$ 的上界完全依赖「字母表只有 `'a'`、`'b'`」。若允许 $k$ 种字母，上界会变成 $k$（每种字母各删一次），例如 `"abc"` 的答案是 3 而不是 2，此时本题的结论失效。
2. **下界是 1 而不是 0**：只要 $s$ 非空，就至少需要一次删除。别把 `n = 1` 的输入误判成 0 次。
3. **判定回文用双指针**：$O(n)$ 时间、$O(1)$ 额外空间，且**可以提前跳出**——平均只看一半甚至几个字符就能确认「不是回文」。
4. **不要构造反转串**：`s[::-1] == s`（Python）或 `string t(s.rbegin(), s.rend())`（C++）要额外 $O(n)$ 空间，虽然仍能过题，但双指针更省也更符合「两指针」标签。
5. **一旦失配就返回 2**：失配意味着 $s$ 不是回文，而 2 步必然够用（见 §5 引理 2），此后的比较全是无用功，可以直接 `return 2`。
6. **不要真的去模拟删除**：删除子序列后剩余字符会「挤到一起」，维护下标极易出错，而且模拟一步本身就要 $O(n)$ 的判定；既然答案只有两个取值，模拟纯属自找麻烦。
7. **参数是 `string s`（按值传递）**：C++ 的 `int removePalindromeSub(string s)` 会拷贝一份，$n \le 1000$ 无所谓；若改成 `const string& s` 也无影响，接口签名保持与 `metaData` 一致即可。

> 💡 本题属于「观察题」：**代码 5 行，思考 5 分钟，写错 5 分钟**。周赛 Q1 的典型形态——先想清楚答案的取值范围，再决定用什么算法。

## 5. 正确性证明

**引理 1（单字母子序列必为回文）**：若一个字符串只由同一种字符组成，则它是回文串。

**证明**：设该串为 $c^k$（$k \ge 0$）。对任意 $0 \le t < k$，有 $s[t] = c = s[k-1-t]$，即每个位置都与对称位置相等，按定义是回文。∎

**引理 2（答案不超过 2）**：对任意只含 `'a'`、`'b'` 的字符串 $s$，存在一种至多 2 步的删除方案把 $s$ 删空。

**证明**：令 $A$ 为 $s$ 中所有 `'a'` 按原顺序构成的子序列，$B$ 为所有 `'b'` 按原顺序构成的子序列。删除子序列不改变剩余字符的相对顺序，因此删掉 $A$ 之后，剩下的恰好是 $B$（顺序不变）。由引理 1，$A$ 与 $B$ 都是回文串，所以「先删 $A$、再删 $B$」是合法的两步操作；若 $A$ 或 $B$ 为空，实际只需 1 步。故答案 $\le 2$。∎

**引理 3（答案为 1 当且仅当 $s$ 回文）**：$\text{answer} = 1 \iff s$ 是回文串。

**证明**：

- ($\Leftarrow$) 若 $s$ 回文，则 $s$ 自身就是一条回文子序列（整串），一次删除即清空，故 $\text{answer} \le 1$；又 $s$ 非空故 $\text{answer} \ge 1$，所以 $\text{answer} = 1$。
- ($\Rightarrow$) 若 $\text{answer} = 1$，则存在一条等于整串的回文子序列被一次删掉，即 $s$ 本身是回文串。∎

**定理（算法正确）**：双指针算法返回的正是最小删除次数。

**证明**：分两种情形。

1. 双指针走完循环，说明对每个 $0 \le i < j < n$ 都有 $s[i] = s[j]$，即 $s$ 是回文，由引理 3 最小次数为 1，算法返回 1，正确。
2. 双指针在某处发现 $s[i] \ne s[j]$，说明 $s$ 不是回文，由引理 3 最小次数 $\ne 1$；又由引理 2 最小次数 $\le 2$，结合「非空串至少 1 次」，最小次数只能为 2，算法返回 2，正确。

两种情形覆盖所有输入，故算法输出等于最优值。∎

## 6. 复杂度分析

- **时间**：$O(n)$。双指针每轮把 $i$、$j$ 各向中间挪一格，最多执行 $\lfloor n/2 \rfloor$ 轮，每轮 $O(1)$ 比较；一旦失配提前返回，实际比较次数可能远小于 $\lfloor n/2 \rfloor$。字符串长度扫描一次即 $O(n)$，已是下界（至少要读入全部字符才能确认回文）。
- **空间**：$O(1)$。只用了两个下标变量，没有递归栈、没有辅助数组、也没有构造反转串。若把语言层面的函数传参拷贝计入，C++ 的 `string s` 值传递占 $O(n)$，但它不随算法逻辑增长，属于接口开销。

## 7. 参考代码

### C++

```cpp
#include <string>
using namespace std;

class Solution {
public:
    int removePalindromeSub(string s) {
        int i = 0, j = (int)s.size() - 1;
        while (i < j) {
            if (s[i] != s[j]) return 2;   // 失配：s 不是回文，答案必为 2
            ++i;
            --j;
        }
        return 1;                          // 全程对称：s 是回文，一次删完
    }
};
```

### Python

```python
class Solution:
    def removePalindromeSub(self, s: str) -> int:
        i, j = 0, len(s) - 1
        while i < j:
            if s[i] != s[j]:
                return 2        # 失配：s 不是回文，2 步必然够用
            i += 1
            j -= 1
        return 1                # 全程对称：整串一次删除

# 等价写法（更短，但会额外复制一份反转串，空间 O(n)）：
#   return 1 if s == s[::-1] else 2
```

## 8. 边界情况与易错点

1. **单字符串**：`s = "a"` → 回文 → 返回 `1`。不要因为「只有一种字母」就返回 0，删除次数的最小值是 1。
2. **全同字符**：`s = "aaaa…a"`（$n = 1000$）或全 `'b'`，答案都是 `1`，双指针会一路走到相遇。
3. **长度为 2 的两个不同字母**：`s = "ab"` 不是回文 → 返回 `2`，而不是某些人以为的 1（`"ab"` 无法一次删除）。
4. **答案溢出思考**：不要以为「交替串很长就要删很多次」——`"abab…ab"`（$n = 1000$）的答案仍是 `2`，与长度无关，这是本题最容易踩的思维陷阱。
5. **误用最长回文子序列**：`LPS(s) = n` 才能判 1，但即使 `LPS(s) < n` 答案也一定是 2（如 `"abb"` 的 LPS 是 `"bb"`）。算 $O(n^2)$ 的 LPS 属于白费力气。
6. **误以为要特判空串**：约束保证 $n \ge 1$，双指针自然处理 `n = 1`；若要扩展成支持空串，应在函数开头补 `if (s.empty()) return 0;`，否则会错误地返回 1。
7. **字符集假设**：结论依赖「只有 `'a'` 和 `'b'`」。若题目放宽字符集，必须改回 $O(n^2)$ 的思路，不能照搬两行结论。
