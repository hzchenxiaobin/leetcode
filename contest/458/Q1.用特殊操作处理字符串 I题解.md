# LeetCode 用特殊操作处理字符串 I 题解

## 1. 题目概述

- **标题 / 题号**：用特殊操作处理字符串 I（#3612，medium）
- **链接**：https://leetcode.cn/problems/process-string-with-special-operations-i/
- **来源**：LeetCode 第 458 场周赛 Q1
- **难度**：中等
- **标签**：字符串、模拟

**题意**：从左到右扫描字符串 `s`，维护结果串 `result`：遇到小写字母就追加到末尾；`'*'` 删除 `result` 的最后一个字符（若存在）；`'#'` 把当前 `result` 复制一份拼接到自身后面（长度加倍）；`'%'` 反转整个 `result`。扫描结束后返回最终的 `result`。

**约束**：

- `1 <= s.length <= 20`
- `s` 只包含小写英文字母和特殊字符 `*`、`#`、`%`

## 2. 示例

**示例 1**

```text
输入：s = "a#b%*"
输出："ba"
解释：
  i=0 'a' → 追加           result = "a"
  i=1 '#' → 复制加倍        result = "aa"
  i=2 'b' → 追加           result = "aab"
  i=3 '%' → 反转           result = "baa"
  i=4 '*' → 删除末尾        result = "ba"
```

**示例 2**

```text
输入：s = "z*#"
输出：""
解释：'z' 追加得 "z"；'*' 删除得 ""；'#' 对空串加倍仍是 ""。
```

## 3. 解题思路

### 3.1 暴力思路

按题意逐字符模拟，用一个可变字符串维护 `result`，四类字符各写一个分支。模拟本身就是本题的做法——**真正的关键不是想出巧妙算法，而是先确认模拟的代价可控**（`'#'` 会让长度指数增长）。

### 3.2 核心观察：长度上界 2^19，直接模拟可行

![四种操作如何改变 result](images/process_str_ops_concept.svg)

四种操作中只有 `'#'` 会放大长度（翻倍），字母 +1、`'*'` −1、`'%'` 不变。设 `s` 长度为 $n \le 20$，其中字母 $k$ 个、`'#'` 最多 $n-k$ 个，则任意时刻

$$|result| \le k \cdot 2^{\,n-k} \le 2^{19} = 524288$$

约 $5 \times 10^5$ 个字符，内存和时间都没有压力。**直接用 `string` / `str` 模拟即可，无需任何高级数据结构。**

> 💡 一句话：`|s| ≤ 20` 是本题的"免死金牌"——指数爆炸被限制在 2^19 以内。

### 3.3 算法流程

![单次扫描 + if/elif 四分支](images/process_str_ops_flow.svg)

一次遍历 `s`，对每个字符 `c` 走 if/elif 四分支：

```text
if   c 是小写字母: result 追加 c
elif c == '*':    result 非空则删除末尾
elif c == '#':    result += result
else (c == '%'):  反转 result
```

### 3.4 示例演算

![示例演算：a#b%* 逐步走查](images/process_str_ops_example.svg)

对 `s = "a#b%*"` 的逐步走查：

| i | s[i] | 操作 | result |
|---|------|------|--------|
| 0 | `a` | 追加 | `a` |
| 1 | `#` | 复制加倍 | `aa` |
| 2 | `b` | 追加 | `aab` |
| 3 | `%` | 反转 | `baa` |
| 4 | `*` | 删除末尾 | `ba` |

最终返回 `"ba"` ✓

## 4. 算法细节

1. **数据结构**：C++ 用 `std::string`（`push_back` / `pop_back` 均摊 $O(1)$）；Python 直接用 `str`（长度上界小，每次操作整体重建也可接受），或用 `list` 减少拷贝。
2. **`'#'` 的实现**：`result += result`，单次代价 $O(|result|)$。连续多个 `'#'` 的长度构成公比 2 的几何级数，总拷贝代价 $O(L)$（$L$ 为最终长度）。
3. **`'%'` 的实现**：C++ 原地 `reverse`；Python 切片 `result[::-1]` 生成新串。
4. **`'*'` 的实现**：必须**先判空再删**，空串时什么都不做（对应题面"如果存在"）。
5. **分支顺序**：先判字母（出现概率最高、$O(1)$），再判三个特殊字符；用 if/elif 链保证互斥。

## 5. 正确性证明

**引理 1（长度上界）**：处理过程中任意时刻 $|result| \le 2^{19}$。

**证明**：设已处理 $i$ 个字符，其中字母 $k$ 个、`'#'` $m$ 个（$k + m \le i \le 20$）。字母使长度至多 +1，`'#'` 使长度至多翻倍，`'*'` 使长度 −1，`'%'` 不变，故当前长度 $\le k \cdot 2^m \le k \cdot 2^{20-k}$。整数函数 $f(k) = k \cdot 2^{20-k}$ 在 $k=1,2$ 处取最大值 $2^{19}$。∎

**引理 2（分支与语义一致）**：四个分支分别正确实现"追加 / 删末尾（若非空）/ 加倍 / 反转"。

**证明**：逐条对照题面定义。`'*'` 分支在 `result` 为空时不执行删除，恰对应"如果存在"；空串加倍仍为空串、空串反转仍为空串，无需特判。∎

**定理**：模拟算法返回的字符串即题意要求的 `result`。

**证明**：对已处理字符数 $i$ 归纳。$i=0$ 时 `result` 为空串，与题意一致。设处理 $i$ 个字符后 `result` 与题意一致，则第 $i+1$ 个字符经引理 2 的对应分支更新后仍与题意一致。由归纳原理，处理完所有字符后的 `result` 即答案；由引理 1，过程不会内存爆炸。∎

## 6. 复杂度分析

- **时间复杂度**：$O(|s| \cdot L)$，其中 $L \le 2^{19}$ 为最终串长度。字母与 `'*'` 均摊 $O(1)$；`'#'` 的拷贝代价是几何级数求和，总计 $O(L)$；`'%'` 反转至多 $|s|$ 次、每次 $O(L)$。本题规模下总操作数 $\le 10^7$，轻松通过。
- **空间复杂度**：$O(L)$，即存储 `result` 本身。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    string processStr(string s) {
        string result;
        for (char c : s) {
            if (c >= 'a' && c <= 'z') {
                result.push_back(c);
            } else if (c == '*') {
                if (!result.empty()) {
                    result.pop_back();
                }
            } else if (c == '#') {
                result += result;
            } else {
                reverse(result.begin(), result.end());
            }
        }
        return result;
    }
};
```

### Python

```python
class Solution:
    def processStr(self, s: str) -> str:
        result = ""
        for c in s:
            if c not in "*#%":
                result += c
            elif c == "*":
                result = result[:-1]
            elif c == "#":
                result += result
            else:
                result = result[::-1]
        return result
```

> 💡 Python 中 `""[:-1]` 恰好返回 `""`，天然满足 `'*'` 对空串的安全语义。

## 8. 边界情况与易错点

1. **`'*'` 打在空串上**：必须判空。C++ 对空 `string` 调 `pop_back()` 是**未定义行为**；示例 2 的 `"z*#"` 就覆盖了这一情形。
2. **`'#'` 打在空串上**：空串加倍仍是空串，无需特判，但别误以为要跳过或返回特殊值。
3. **`'#'` 与 `'%'` 语义别混**：`#` 是复制拼接（长度 ×2），`%` 才是反转（长度不变），比赛中手速题最易写反。
4. **特殊字符不入串**：`result` 中永远只有小写字母，`*`、`#`、`%` 本身只是操作符。
5. **别过度设计**：`|s| ≤ 20` 保证 `|result| ≤ 2^19`，直接模拟即可；懒反转、双端队列等技巧是 Q3 的事。
6. **分支写全**：用 if/elif 链时确保 `%` 落入 `else` 前已排除其余三类字符，避免把未知字符当字母追加。
