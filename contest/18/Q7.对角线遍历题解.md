# LeetCode 对角线遍历 题解

## 1. 题目概述

- **标题 / 题号**：对角线遍历（#498，medium）
- **链接**：https://leetcode.cn/problems/diagonal-traverse/
- **来源**：LeetCode 第 18 场周赛 B 卷 Q7
- **难度**：中等
- **标签**：数组、矩阵、模拟

**题意**：给定 $m \times n$ 的矩阵 `mat`，从左上角 $(0,0)$ 出发，先沿**右上**方向走；撞到边界后按规则转向（撞上边则右移一格、撞右边则下移一格、撞下边则右移一格、撞左边则下移一格），接着沿**左下**方向走，如此往复，形成一个「之」字，要求按访问顺序返回全部 $m \cdot n$ 个元素。

**约束**：

- $1 \le m, n \le 10^4$，且 $1 \le m \cdot n \le 10^4$
- $-10^5 \le \text{mat}[i][j] \le 10^5$
- 元素可为负数且可重复，输出必须**恰好**包含 $m \cdot n$ 个数、每个格子恰好一次

## 2. 示例

**示例 1**

```text
输入：mat = [[1,2,3],[4,5,6],[7,8,9]]
输出：[1,2,4,7,5,3,6,8,9]
解释：1 →（撞上边右移）2 →（左下）4 →（撞左边下移）7 →（右上）5 → 3
      →（撞右边下移）6 →（左下）8 →（撞下边右移）9。
```

**示例 2**

```text
输入：mat = [[1,2],[3,4]]
输出：[1,2,3,4]
解释：(0,0)=1 向右上走已越界，于是右移到 (0,1)=2；
      再沿左下走到 (1,0)=3；撞下边界后右移到 (1,1)=4。
      三条对角线长度依次为 1、2、1。
```

**示例 3（补充，非方阵 2×4）**

```text
输入：mat = [[1,2,3,4],[5,6,7,8]]
输出：[1,2,5,6,3,4,7,8]
解释：五条对角线的长度依次为 1、2、2、2、1，与方阵时的 1、2、3、2、1 不同；
      说明「每条线长度不同、需要裁剪行号范围」是本题的主要坑点。
```

## 3. 解题思路

### 3.1 暴力思路

最朴素的做法是**照抄题意**：维护当前坐标 $(i,j)$ 和一个方向布尔量，每走一步就检查四个边界并转向，走满 $m \cdot n$ 步为止。它的时间复杂度是 $O(mn)$，本身并不慢，但分支条件在**角点**上极容易写错——右上角 $(0, n-1)$ 同时满足「撞上边」和「撞右边」，左下角同时满足「撞下边」和「撞左边」，条件顺序写反就会原地打转或越界。

另一种常见写法是「枚举 $d$，每条线都从 $(d,0)$ 或 $(0,d)$ 出发扫固定长度 $\max(m,n)$ 个格子、越界就跳过」，复杂度退化为 $O\big((m+n)\cdot\max(m,n)\big)$：当 $m=1, n=10^4$ 时约 $10^8$ 次判空，白白浪费一个数量级。

### 3.2 核心观察：反对角线编号 $d=i+j$，奇偶定方向

![反对角线编号与奇偶方向](images/wc18_q7_diagonal_index_model.svg)

**观察一：同一条反对角线上的格子，行列坐标之和相同。**

沿右上走一步是 $(i,j) \to (i-1, j+1)$，$i+j$ 不变；沿左下走一步是 $(i,j) \to (i+1, j-1)$，$i+j$ 依然不变。而撞墙时的转移是右移一格（$j$ 加 1）或下移一格（$i$ 加 1），两者都使 $i+j$ **恰好加 1**。于是整条路线等价于按 $d = 0, 1, 2, \dots, m+n-2$ 的顺序，依次处理所有满足 $i+j=d$ 的格子——把二维的「走」换成一维的「按编号取」。

**观察二：方向完全由 $d$ 的奇偶决定，不需要维护方向变量。**

从 $(0,0)$ 出发时 $d=0$ 且方向为右上；每次撞墙 $d$ 加 1 且方向翻转，所以 $d$ 为偶数时是右上方向（行号递减），$d$ 为奇数时是左下方向（行号递增）。方向与 $d$ 的奇偶一一对应，一个 `if` 就能决定遍历顺序。

**观察三：每条线的行号范围可以 $O(1)$ 算出来。**

对固定的 $d$，$j = d - i$ 必须落在 $[0, n-1]$ 内，故 $i \ge d-(n-1)$；同时 $i \in [0, m-1]$。合并得
$$\text{lo} = \max\big(0,\ d-(n-1)\big), \qquad \text{hi} = \min\big(m-1,\ d\big)$$
该线长度为 $\text{hi}-\text{lo}+1$，无需任何越界判断。

### 3.3 算法流程

![按对角线编号逐条输出的流程](images/wc18_q7_diagonal_flow.svg)

```text
ans ← 空数组
for d = 0 .. m+n-2:
    lo ← max(0, d − (n − 1))
    hi ← min(m − 1, d)
    if d 是偶数:                       # 行号 hi → lo，即从左下往右上
        for i = hi down to lo:
            ans.push(mat[i][d − i])
    else:                             # 行号 lo → hi，即从右上往左下
        for i = lo up to hi:
            ans.push(mat[i][d − i])
return ans
```

三个关键点：

1. **外层只到 $m+n-2$**：$d$ 的最大值是 $m-1 + n-1$，多跑一步会得到空的 $\text{lo} \gt \text{hi}$，虽不越界但属于无意义迭代。
2. **内层用 $j = d-i$ 现算**：只维护行号一个变量，列号由 $d$ 与 $i$ 唯一确定，少一个变量就少一处写错的机会。
3. **两个分支只差一个 `range` 方向**：偶数走 `hi → lo`（递减），奇数走 `lo → hi`（递增），这正是「之」字的实质。

### 3.4 示例演算

![示例 1 的走查：格内小字为输出序号](images/wc18_q7_walkthrough.svg)

以 `mat = [[1,2,3],[4,5,6],[7,8,9]]`（$m=n=3$）为例，$d$ 从 $0$ 走到 $4$：

| $d$ | 奇偶 | $[\text{lo},\text{hi}]$ | 行号顺序 | 本段输出 |
|-----|------|--------------------------|----------|----------|
| 0 | 偶 | $[0,0]$ | 0 | 1 |
| 1 | 奇 | $[0,1]$ | 0 → 1 | 2, 4 |
| 2 | 偶 | $[0,2]$ | 2 → 1 → 0 | 7, 5, 3 |
| 3 | 奇 | $[1,2]$ | 1 → 2 | 6, 8 |
| 4 | 偶 | $[2,2]$ | 2 | 9 |

按 $d$ 递增拼接即 `[1,2,4,7,5,3,6,8,9]`，与官方输出一致。注意 $d=2$ 这一段（7, 5, 3）正是「从下往上」的体现：真实遍历先走到左下角的 7，再沿对角线回到右上角的 3，与「行号递减」完全对应。

## 4. 算法细节

1. **行号范围的推导**：由 $j = d - i \in [0, n-1]$ 得到 $d-(n-1) \le i \le d$，再与 $[0, m-1]$ 取交。写成 $\text{lo} = \max(0,\, d-n+1)$、$\text{hi} = \min(m-1,\, d)$，注意 $d-(n-1)$ 的括号不能省，$d-n+1$ 与之等价但更易读。
2. **$d$ 的奇偶与方向**：$d$ 偶数 → 行号**递减**（左下到右上）；$d$ 奇数 → 行号**递增**（右上到左下）。写反是最常见的 WA，用示例 1 心算一次即可确认。
3. **不要用四分支模拟**：角点处两条边界同时成立，必须靠分支顺序兜住；而按对角线枚举天然没有这个问题，代码短且不会越界。
4. **退化形状无需特判**：$m=1$ 时 $d$ 只有 $0 \sim n-1$，每条线长度均为 1，公式自动成立并输出原序；$n=1$ 同理输出原序；$1 \times 1$ 直接返回单个元素。
5. **答案容器一次分配**：Python 用 `ans = []` 追加，C++ 用 `ans.reserve(m * n)` 预留，避免 $10^4$ 次扩容的均摊拷贝。
6. **列号只算一次**：内层循环体里用 `mat[i][d - i]`，把 `d - i` 的计算交给编译器；不要在外层重复算 $j$ 的起点再自增，那种写法在两个方向下容易写成同一个符号。
7. **全程只用 `int`**：元素绝对值 $\le 10^5$、答案长度 $\le 10^4$，`int` 足够；只有当题目改成「求对角线元素和」才需要考虑累加上界。
8. **答案长度即校验**：程序结束时可断言 `len(ans) == m * n`，能一次性抓住「$d$ 上界写错」和「`lo`/`hi` 裁剪漏项」两类 bug。

## 5. 正确性证明

**引理 1（对角线划分）**：每个格子 $(i,j)$ 唯一对应一个编号 $d=i+j$，且 $d \in [0, m+n-2]$；反过来，每个 $d$ 都至少有一个格子与之对应。

**证明**：$d=i+j$ 由 $(i,j)$ 唯一确定。由 $0 \le i \le m-1$、$0 \le j \le n-1$ 得 $0 \le d \le m+n-2$。对每个 $d$，取 $i = \min(m-1, d)$，则 $i \ge 0$，且 $j = d-i \ge d - d = 0$；又 $j = d - \min(m-1,d)$，若 $d \le m-1$ 则 $j=0 \le n-1$，若 $d \gt m-1$ 则 $j = d-m+1 \le (m+n-2)-m+1 = n-1$。故该 $i$ 落在合法范围内，$S_d$ 非空。∎

**引理 2（范围公式正确）**：对固定 $d$，集合 $\{(i,\, d-i) \mid \text{lo} \le i \le \text{hi}\}$ 恰好等于矩阵中所有满足 $i+j=d$ 的格子，且 $\text{lo} \le \text{hi}$。

**证明**：格子 $(i, d-i)$ 合法当且仅当 $0 \le i \le m-1$ 且 $0 \le d-i \le n-1$，后者等价于 $d-(n-1) \le i \le d$。两段区间的交集即 $[\max(0, d-n+1),\ \min(m-1,d)] = [\text{lo},\text{hi}]$，故集合相等。由引理 1 该集合非空，故 $\text{lo} \le \text{hi}$。∎

**引理 3（方向与奇偶一致）**：真实遍历中，第 $d$ 条对角线的内部顺序为：$d$ 偶数时行号递减，$d$ 奇数时行号递增。

**证明**：对 $d$ 归纳。$d=0$ 时 $S_0=\{(0,0)\}$，只有一个格子，平凡成立；此时遍历方向为右上。设第 $d$ 段的方向为右上（此时 $d$ 为偶数，行号递减）。走到该段终点后撞墙，转移只可能是右移或下移，两种转移都使 $d$ 加 1，且方向翻转为左下；在左下方向上 $i$ 每次加 1，故第 $d+1$ 段内部行号递增。反之若第 $d$ 段方向为左下（$d$ 为奇数、行号递增），同理撞墙后 $d$ 加 1 且方向翻转为右上，行号递减。归纳成立。∎

**定理**：算法返回的数组与题面要求的对角线遍历顺序完全一致。

**证明**：由引理 2，算法对每个 $d$ 恰好输出 $S_d$ 中每个格子一次，而由引理 1 这些 $S_d$ 构成矩阵的一个划分，故输出总长为 $\sum_d |S_d| = m \cdot n$，**不重不漏**。顺序方面：算法按 $d$ 递增拼接，而真实遍历中 $d$ 每次只在撞墙时加 1（见 3.2 观察一），因此段与段的先后一致；段内顺序由引理 3 保证与真实遍历一致。两者共同说明整个序列相同。∎

## 6. 复杂度分析

- **时间**：$O(m \cdot n)$。外层循环 $m+n-1$ 次，内层恰好执行该对角线的长度次数，没有一次多余的越界判断；总内层次数为 $\sum_{d} (\text{hi}-\text{lo}+1) = m \cdot n$。拼接与返回同阶。
- **空间**：若不计返回数组，额外空间为 $O(1)$——只用了 $d, \text{lo}, \text{hi}, i$ 四个整型变量；若计入返回数组，总空间 $O(m \cdot n)$，这是输出本身的下界。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    vector<int> findDiagonalOrder(vector<vector<int>>& mat) {
        int m = mat.size(), n = mat[0].size();
        vector<int> ans;
        ans.reserve(m * n);                     // 一次分配，避免扩容

        for (int d = 0; d < m + n - 1; ++d) {   // d = i + j 的取值
            int lo = max(0, d - (n - 1));       // 该对角线最小的行号
            int hi = min(m - 1, d);             // 该对角线最大的行号
            if (d % 2 == 0) {                   // 偶数号：行号从 hi 递减到 lo
                for (int i = hi; i >= lo; --i) ans.push_back(mat[i][d - i]);
            } else {                            // 奇数号：行号从 lo 递增到 hi
                for (int i = lo; i <= hi; ++i) ans.push_back(mat[i][d - i]);
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def findDiagonalOrder(self, mat: list[list[int]]) -> list[int]:
        m, n = len(mat), len(mat[0])
        ans: list[int] = []

        for d in range(m + n - 1):              # d = i + j 的取值
            lo = max(0, d - (n - 1))            # 该对角线最小的行号
            hi = min(m - 1, d)                  # 该对角线最大的行号
            if d % 2 == 0:                      # 偶数号：行号递减（左下 → 右上）
                for i in range(hi, lo - 1, -1):
                    ans.append(mat[i][d - i])
            else:                               # 奇数号：行号递增（右上 → 左下）
                for i in range(lo, hi + 1):
                    ans.append(mat[i][d - i])

        return ans
```

## 8. 边界情况与易错点

1. **$1 \times 1$**：`[[7]]` 返回 `[7]`。外层只跑 $d=0$，$\text{lo}=\text{hi}=0$，无需特判。
2. **单行 / 单列**：`[[1,2,3]]` 与 `[[1],[2],[3]]` 都应输出原序。此时每条对角线长度为 1，奇偶分支退化为同一种行为——如果实现里额外假设「偶数号长度至少 2」就会出错。
3. **角点转向**：右上角 $(0, n-1)$、左下角 $(m-1, 0)$ 同时满足两个边界条件，模拟写法必须先判「撞右/下墙」再判「撞上/左墙」，否则会原地停留或越界。按对角线枚举不存在此问题。
4. **$d$ 的上界**：必须写 $d \lt m+n-1$（即最大 $d = m+n-2$）。写成 $m+n$ 时只会多出一轮 $\text{lo} \gt \text{hi}$ 的空迭代、结果仍对，但**如果**实现里改成了「先取 `mat[lo][d-lo]` 再判断」，就会下标越界。
5. **非方阵裁剪**：$m=2, n=4$ 时 $d=3$ 的 $\text{lo} = \max(0, 3-3) = 0$、$\text{hi} = \min(1, 3) = 1$，长度 2。若把 $\text{lo}$ 写成 $d-n$ 而非 $d-(n-1)$，$d=4$ 时会一路取到 $i=0$、列号 $j=4$，**列越界**；这种错误在方阵上未必暴露，只在非方阵上崩。
6. **别用元素值做哨兵**：元素可以是 $-10^5$ 也可以是 $0$，任何「用 0 表示未访问」的技巧都不可靠；本题也不需要访问标记，每条线天然不重叠。
7. **输出长度自查**：最终数组长度必须等于 $m \cdot n$。若少了元素，通常是 `hi` 少加了 1 或 `range` 的终止边界写错（Python 的 `range(hi, lo-1, -1)` 与 `range(lo, hi+1)` 都容易漏 $\pm 1$）。
