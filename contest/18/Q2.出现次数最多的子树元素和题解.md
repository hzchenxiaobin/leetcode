# LeetCode 出现次数最多的子树元素和 题解

## 1. 题目概述

- **标题 / 题号**：出现次数最多的子树元素和（#508，medium）
- **链接**：https://leetcode.cn/problems/most-frequent-subtree-sum/
- **来源**：LeetCode 第 18 场周赛 A 卷 Q2
- **难度**：中等
- **标签**：树，深度优先搜索，哈希表，二叉树，树形 DP

**题意**：给出一棵二叉树的根结点 `root`。对每个结点 $u$ 定义它的**子树元素和** $\text{sub}(u)$ 为「以 $u$ 为根的子树中所有结点值之和（含 $u$ 自身）」。于是这棵树一共给出 $n$ 个值（$n$ 为结点个数，**可重复**）。请返回出现次数最多的那些值；若多个值的出现次数并列最高，则把它们**全部**返回，顺序不限。

**约束**：

- 结点数在 $[1, 10^4]$ 内
- $-10^5 \le \text{Node.val} \le 10^5$
- 返回值顺序任意，只比较集合

> 💡 一句话抓重点：**每个结点贡献一个和，答案是对这些和做「众数」查询**；难点不在统计，而在如何一次遍历把 $n$ 个和全部算出来。

## 2. 示例

**示例 1**

```text
输入：root = [5, 2, -3]
输出：[2, -3, 4]
解释：三个结点的子树元素和分别为
      结点 2  → 2
      结点 -3 → -3
      根结点 5 → 5 + 2 + (-3) = 4
      三者频次都是 1，并列最高，故全部返回（顺序不限）。
```

**示例 2**

```text
输入：root = [5, 2, -5]
输出：[2]
解释：结点 2 → 2，结点 -5 → -5，根结点 5 → 5 + 2 + (-5) = 2。
      值 2 出现 2 次，是唯一的最大频次，故只返回 [2]。
```

两个示例形状完全相同，只差右叶子的取值，答案却从「三值并列」变成「单值独大」——这说明必须真的把每个和都算出来并计数，任何「只看根 / 只看叶子」的偷懒都会被卡掉。

## 3. 解题思路

### 3.1 暴力思路

最直白的做法是：对每个结点 $u$，再从 $u$ 出发做一次遍历，把它子树里所有值加起来得到 $\text{sub}(u)$，用哈希表计数，最后取最大频次。

- 时间复杂度 $O(n^2)$：最坏是链状树，第 $i$ 个结点的子树大小为 $n-i+1$。
- $n = 10^4$ 时约 $5 \times 10^7$ 次加法，C++ 勉强能过，Python 基本超时；而且它做了大量重复计算——同一棵子树被它的每个祖先重复遍历了一遍。

问题出在「子树和被反复重算」，而不是「统计频次」这一步。

### 3.2 核心观察：子树和自底向上可加，一次后序 DFS 即可

![子树元素和的定义与频次统计](images/wc18_q2_subtree_sum_concept.svg)

关键恒等式：

$$\text{sub}(u) = u.\text{val} + \text{sub}(u.\text{left}) + \text{sub}(u.\text{right})$$

即**父结点的子树和只依赖两个孩子的子树和**，与更深的内部结构无关。这意味着只要先拿到孩子的值，父结点的值就是 $O(1)$ 的加法——恰好是**后序遍历**（左右子树先结算，再结算自己）的顺序，也就是最基础的树形 DP。

于是「一次 DFS」同时完成两件事：

1. 递归函数**返回**当前子树的元素和（供父结点使用）；
2. 在返回之前，把当前子树的元素和丢进**哈希表**计数。

整棵树遍历完，哈希表里就恰好有 $n$ 个条目（按值合并后至多 $n$ 个键），每个键的值就是该子树和出现的次数。再扫一遍哈希表取最大频次并收集所有并列者即可。

### 3.3 算法流程

![后序遍历流程](images/wc18_q2_postorder_flow.svg)

1. 建一个哈希表 `cnt`：键是子树和，值是出现次数。
2. 从根调用 `dfs(root)`：
   - `node` 为空 → 返回 $0$（空子树的元素和视为 $0$，这样加法天然正确）；
   - 递归得到 $L = \text{dfs}(\text{left})$、$R = \text{dfs}(\text{right})$；
   - $s \leftarrow \text{node.val} + L + R$；
   - `cnt[s] += 1`，并 `return s`。
3. 遍历结束后求 `best = max(cnt.values())`。
4. 收集所有满足 `cnt[v] == best` 的 $v$，返回。

### 3.4 示例演算

![两组官方示例的走查](images/wc18_q2_example_walkthrough.svg)

对 `root = [5, 2, -3]`，后序结算顺序是「左叶子 → 右叶子 → 根」：

| 结算次序 | 结点 | 子树元素和 $s$ | 计数表 `cnt` |
|---------|------|----------------|--------------|
| 1 | 2（左叶） | $2$ | $\{2:1\}$ |
| 2 | −3（右叶） | $-3$ | $\{2:1,\ -3:1\}$ |
| 3 | 5（根） | $5+2-3=4$ | $\{2:1,\ -3:1,\ 4:1\}$ |

`best = 1`，三个键都并列，返回 `[2, -3, 4]`。

对 `root = [5, 2, -5]`：

| 结算次序 | 结点 | 子树元素和 $s$ | 计数表 `cnt` |
|---------|------|----------------|--------------|
| 1 | 2（左叶） | $2$ | $\{2:1\}$ |
| 2 | −5（右叶） | $-5$ | $\{2:1,\ -5:1\}$ |
| 3 | 5（根） | $5+2-5=2$ | $\{2:2,\ -5:1\}$ |

`best = 2`，只有键 $2$ 达到，返回 `[2]`。注意根的和 $2$ 恰好撞上左叶的和 $2$，两者被**合并计数**——这正是哈希表按键合并的语义，也是本题唯一的「坑点」所在。

## 4. 算法细节

1. **递归的返回值定义要单一**：`dfs(u)` 只返回 $\text{sub}(u)$，绝不返回「当前最大频次」之类的复合信息。把「求值」与「统计」通过闭包/引用捕获的哈希表解耦，代码才不容易写乱。
2. **结算时机必须是后序**：`cnt[s] += 1` 要写在两次递归**之后**。若写成前序（先计数再递归），拿到的 `s` 是残缺的，示例 2 会算成根的和为 $5$ 而不是 $2$。
3. **空结点返回 0**：这是让加法恒等式成立的最小约定；不要返回 `nullptr`/哨兵值，否则父结点还要特判。
4. **计数器选型**：C++ 用 `unordered_map<long long,int>`（最坏 $n = 10^4$ 个键，无性能问题）；Python 用 `collections.Counter`，`cnt[s] += 1` 即可。
5. **两次扫描哈希表**：先 `best = max(cnt.values())`，再过滤 `cnt[v] == best`。也可以边插入边维护 `best`，但那样在「`best` 变大后需要清空旧答案」时容易写错，两次扫描更稳。
6. **求和类型**：$\sum |val| \le 10^4 \times 10^5 = 10^9$，`int`（上限 $2.147 \times 10^9$）**刚好**装得下，但余量极小；C++ 一律用 `long long` 累加再转回 `int`。
7. **Python 的递归深度**：链状树深度可达 $10^4$，默认上限 $1000$ 会直接 `RecursionError`。要么 `sys.setrecursionlimit(30000)`，要么用下面的**显式栈迭代后序**；参考代码选了后者，避免依赖解释器设置。
8. **不要用「和」的大小做任何剪枝或桶排序**：和可以是负数、可以重复、范围是 $[-10^9, 10^9]$，只能靠哈希。

## 5. 正确性证明

**引理 1（递归返回值正确）**：对任意结点 $u$，调用 `dfs(u)` 的返回值等于 $\text{sub}(u)$。

**证明**：对子树高度做结构归纳。$u$ 为空时返回 $0$，而空子树的元素和按约定为 $0$，成立。设 $u$ 非空且左右孩子的结论均成立，则递归得到 $L = \text{sub}(u.\text{left})$、$R = \text{sub}(u.\text{right})$，函数返回

$$u.\text{val} + L + R = u.\text{val} + \text{sub}(u.\text{left}) + \text{sub}(u.\text{right}) = \text{sub}(u)$$

其中最后一步是子树元素和的定义（子树结点集合 = 根 ∪ 左子树结点 ∪ 右子树结点，三者不交）。∎

**引理 2（计数表正确）**：DFS 结束后，对任意整数 $s$，有 $\text{cnt}[s] = \bigl|\{\,u : \text{sub}(u) = s\,\}\bigr|$。

**证明**：每个非空结点 $u$ 在 `dfs(u)` 中恰好执行一次 `cnt[sub(u)] += 1`：一次，是因为 `dfs` 对每个结点只被父结点调用一次（树中每个结点只有一个父结点，根没有）；执行时机在两次递归返回之后，故由引理 1，累加的正是 $\text{sub}(u)$。空结点不计数，与「子树和由 $n$ 个非空结点各贡献一个」一致，故计数表精确。∎

**引理 3（最大频次正确）**：`best = max(cnt.values())` 等于

$$M = \max_{s}\ \bigl|\{\,u : \text{sub}(u) = s\,\}\bigr|$$

**证明**：由引理 2，`cnt` 的值域就是所有出现过的频次集合，取最大值即得 $M$。∎

**定理**：算法返回的集合恰为 $\{\,s : \text{cnt}[s] = M\,\}$，即「所有出现次数最多的子树元素和」，不重不漏。

**证明**：收集步骤按 `cnt[v] == best` 逐键过滤，哈希表的键唯一，故结果**不含重复**；由引理 3 得 `best = M`，故每个满足频次 $M$ 的 $s$ 都被收进结果，**不漏**；反向地，任何被收进的 $v$ 都满足 `cnt[v] = M`，即其频次确为最大，**不多**。题目要求并列时全部返回、顺序不限，与实现一致。∎

## 6. 复杂度分析

- **时间**：$O(n)$。每个结点进入 `dfs` 一次、离开一次，结点内部只做常数次加法与一次哈希表插入（均摊 $O(1)$）；最后的 `max` 与过滤各扫一遍哈希表，表大小不超过 $n$。总计 $O(n)$。
- **空间**：$O(n)$。哈希表最多存 $n$ 个键值对；递归栈深度为树高 $h$，最坏 $h = n = 10^4$（链状树），最好 $h = \log n$（完全二叉树）。迭代版本用显式栈，同样是 $O(h)$ 但不受解释器递归上限约束。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <unordered_map>
#include <algorithm>
using namespace std;

// TreeNode 的定义由判题系统给出
class Solution {
public:
    vector<int> findFrequentTreeSum(TreeNode* root) {
        unordered_map<long long, int> cnt;
        dfs(root, cnt);

        int best = 0;
        for (auto &kv : cnt) best = max(best, kv.second);

        vector<int> ans;
        for (auto &kv : cnt)
            if (kv.second == best) ans.push_back((int)kv.first);
        sort(ans.begin(), ans.end());      // 题目不限顺序，这里排序便于对照
        return ans;
    }

private:
    // 返回以 node 为根的子树元素和；为空返回 0
    long long dfs(TreeNode* node, unordered_map<long long, int>& cnt) {
        if (node == nullptr) return 0;
        long long s = (long long)node->val + dfs(node->left, cnt) + dfs(node->right, cnt);
        cnt[s]++;                          // 后序：孩子结算完才记自己
        return s;
    }
};
```

### Python

```python
from typing import Optional, List
from collections import Counter


class Solution:
    def findFrequentTreeSum(self, root: Optional[TreeNode]) -> List[int]:
        if root is None:
            return []
        cnt = Counter()
        sub = {}                                   # 结点 -> 子树元素和
        # 显式栈模拟后序：先压 (node, False)，弹出后再压 (node, True)
        stack = [(root, False)]
        while stack:
            node, done = stack.pop()
            if done:
                s = node.val + sub.get(node.left, 0) + sub.get(node.right, 0)
                sub[node] = s
                cnt[s] += 1                        # 左右子树都已结算
            else:
                stack.append((node, True))
                if node.right:
                    stack.append((node.right, False))
                if node.left:
                    stack.append((node.left, False))

        best = max(cnt.values())
        return sorted(v for v, c in cnt.items() if c == best)
```

> 若偏好递归写法，Python 中记得 `sys.setrecursionlimit(30000)`（链状树深度 $10^4$，默认 $1000$ 会 `RecursionError`）；C++ 的递归栈由系统管理，本题深度 $10^4$ 无压力。

## 8. 边界情况与易错点

1. **只有一个结点**：`cnt` 中只有一个键，频次 $1$，返回 `[root.val]`。若手写「先设 `best = 1` 再逐个比较」的版本，务必保证这个唯一的键能被收进答案，别让初值把结果挡掉。
2. **空树**：题面保证结点数 $\ge 1$，但接口允许 `nullptr`；返回 `[]` 而不是崩溃，避免本地测试时的空指针。
3. **负值与非单调**：子树和可负、可零、可重复，**数值大小与频次无关**。示例 1 里最大和 $4$ 也只出现一次，任何「取最大和」的想法都是错的。
4. **并列必须全返回**：示例 1 返回 $3$ 个数。若用 `unordered_map` 边统计边记「当前最优值」，在频次被追平时忘记把旧答案一起保留，就会漏项。
5. **顺序问题**：题目说「不限顺序」，但输出必须**不含重复**。用 `set` 语义或排序后输出都行；参考代码排序只是为了让结果确定、便于本地 diff。
6. **Python 递归深度**：$10^4$ 的链会触发 `RecursionError`，这是本题在 Python 下最常见的 RE，务必用显式栈或调高上限。
7. **求和溢出**：$\sum|\text{val}| = 10^9$ 虽在 `int` 内，但一旦把约束看错（如把 $10^5$ 当成 $10^4$）就会溢出；统一用 `long long` 最省心。
8. **别在哈希表里边遍历边删除**：收集答案用单独的结果数组，避免迭代器失效。
