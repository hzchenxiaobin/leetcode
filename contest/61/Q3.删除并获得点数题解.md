# LeetCode 删除并获得点数 题解

## 1. 题目概述

- **标题 / 题号**：删除并获得点数（#740，medium）
- **链接**：https://leetcode.cn/problems/delete-and-earn/
- **来源**：LeetCode 第 61 场周赛 Q3
- **难度**：中等
- **标签**：数组、哈希表、动态规划

**题意**：给定整数数组 `nums`。每步操作选一个 `nums[i]` 删除，获得 `nums[i]` 分；随后**所有值等于** `nums[i] - 1` 与 `nums[i] + 1` 的元素被强制删除。可以操作任意多次，求能拿到的最大总点数。

注意被连带删除的是「值」而不是「下标」：与 `nums[i]` **相等**的其它副本不会被删，可以继续选，每选一次再得一次分。

**约束**：

- $1 \le \text{nums.length} \le 2 \times 10^4$
- $1 \le \text{nums}[i] \le 10^4$
- 答案上界：所有元素同值时取满，$2 \times 10^4 \times 10^4 = 2 \times 10^8$，在 32 位 `int` 范围内

## 2. 示例

**示例 1**

```text
输入：nums = [3,4,2]
输出：6
解释：删 4 得 4 分，3 被连带删除，nums = [2]；
      再删 2 得 2 分，nums = []。总分 6。
      （也可以先删 2 再删 4，同样 6 分）
```

**示例 2**

```text
输入：nums = [2,2,3,3,3,4]
输出：9
解释：删一个 3 得 3 分，所有的 2 和 4 被删除，nums = [3,3]；
      再删两次 3，各得 3 分。总分 9。
      注意同值的 3 一共三份，可以全部收下。
```

**补充示例**

```text
输入：nums = [1,2]
输出：2
解释：删 2 得 2 分并连带删掉 1；若删 1 只能得 1 分。故答案为 2。
```

## 3. 解题思路

### 3.1 暴力思路

把「剩余的不同值集合」当作状态做记忆化搜索：每步从集合里挑一个值 $v$，得分加 $v$，再从集合中删掉 $v-1, v+1$。不同值的个数 $k$ 最多 $10^4$，状态数是 $2^k$ 量级；即便只枚举「取哪些值」的子集，也要 $O(2^k)$，完全不可行。

真正的问题在于：搜索没有利用**数值之间的线性结构**——冲突只发生在相邻整数上。

### 3.2 核心观察：同值打包 → 打家劫舍

![按值分桶后等价于打家劫舍](images/wc61_q3_bucket_reduce.svg)

**观察 1（同值全取）**：一旦决定取用某个值 $v$，就没有理由只取其中一部分。每多取一个值为 $v$ 的元素净赚 $v$ 分，且不会额外禁掉任何值（$v \pm 1$ 早在第一次取 $v$ 时就被删干净了）。于是同值元素可以压成一份：

$$\text{points}[v] = v \times \text{cnt}[v]$$

**观察 2（相邻互斥）**：取了 $v$ 就再也不能碰 $v-1$ 与 $v+1$，而不相邻的值之间毫无干扰。把值域 $1..V$ 看成一排格子，每格放一份分数 $\text{points}[v]$，问题变成：

> 选出若干个**互不相邻**的格子，使分数之和最大。

这就是路径图上的**最大权独立集**，也正是「打家劫舍」的模型——原题只是给它换了层数组外壳。

### 3.3 状态转移

![状态转移：取与不取两路候选](images/wc61_q3_dp_transition.svg)

设 $f[v]$ 表示只考虑值 $1..v$ 这些桶时能拿到的最大分数，$f[0] = 0$、$f[-1] = 0$。对桶 $v$ 只有两种去向：

$$
f[v] = \max\bigl(f[v-1],\; f[v-2] + \text{points}[v]\bigr)
$$

- 不取 $v$：直接继承 $f[v-1]$；
- 取 $v$：$v-1$ 已被禁，只能接 $f[v-2]$，再加上整桶分数。

答案即 $f[V]$，$V = \max(\text{nums})$。实现上只需两个滚动变量 `prev2` 与 `prev1`（分别代表 $f[v-2]$ 与 $f[v-1]$），边扫边更新即可，无需真的开出 $f$ 数组。

### 3.4 示例演算

![示例演算走查表](images/wc61_q3_walkthrough.svg)

对 `nums = [2,2,3,3,3,4]`，先聚合：$\text{cnt}[2]=2,\ \text{cnt}[3]=3,\ \text{cnt}[4]=1$，对应 $\text{points} = [0, 0, 4, 9, 4]$（下标 $0..4$）。

| $v$ | $\text{cnt}[v]$ | $\text{points}[v]$ | $f[v]$ | 来源 |
|-----|-----------------|--------------------|--------|------|
| 0 | 0 | 0 | 0 | 初值 |
| 1 | 0 | 0 | 0 | 空桶，$f[1] = \max(0, 0+0)$ |
| 2 | 2 | 4 | 4 | $f[0] + 4$ |
| 3 | 3 | 9 | 9 | $f[1] + 9$（大于 $f[2]=4$） |
| 4 | 1 | 4 | 9 | $\max(f[3], f[2]+4) = \max(9, 8)$ |

最终 $f[4] = 9$：把三个 `3` 一次取光，比「取 4 再取 2」（$4+4=8$）更划算。再看 `nums = [3,4,2]`：$\text{points}[2..4] = [2,3,4]$，$f$ 依次为 $2, 3, 6$（$v=4$ 时 $f[2]+4 = 2+4 = 6$），答案 6。

## 4. 算法细节

1. **用值域桶代替排序/哈希表**：先求 $V = \max(\text{nums})$，开长度 $V+1$ 的 `points` 数组，`points[x] += x` 一次遍历完成聚合并天然排好序，省掉 $O(n \log n)$ 的排序。
2. **空桶无需特判**：`points[v] = 0` 时递推自动退化为 $f[v] = f[v-1]$，因为 $f$ 单调不减；不要写 `if (points[v] == 0) continue;` 之类的分支，容易漏掉状态更新。
3. **滚动变量更新顺序**：必须先算 `cur`，再 `prev2 = prev1; prev1 = cur;`；若先覆盖 `prev2` 会把 $f[v-1]$ 错当成 $f[v-2]$，答案偏大。
4. **下标从 0 还是从 1 起**：`points[0]` 恒为 0（约束保证 $\text{nums}[i] \ge 1$），所以循环从 $v=0$ 开始、`prev2 = prev1 = 0` 即可，无需为 $f[-2]$ 做特殊处理。
5. **类型选择**：本题答案上界 $2 \times 10^8$，`int` 足够；但若变体把 $\text{nums}[i]$ 上界放大到 $10^6$、$n$ 到 $10^5$，则需 `long long`，写代码时留个心。
6. **复杂度取决于值域而非 $n$**：$O(n + V)$ 中的 $V = \max(\text{nums}) \le 10^4$，与 $n$ 同阶；若值域远大于 $n$，应改用「排序 + 相邻值压缩」的 DP（见延伸思考）。
7. **不要在递推里比较「取 $v$ 是否划算」**：$v$ 本身分数高低不代表贪心可取，必须由 $f[v-1]$ 与 $f[v-2] + \text{points}[v]$ 的比较决定；例如 `[1, 100, 101]` 取 $100$ 与取 $101$ 才是互斥的，与 $1$ 无关。

## 5. 正确性证明

**引理 1（同值全取）**：存在最优方案，使得只要它取用了值 $v$ 的某个元素，就取走全部值为 $v$ 的元素。

**证明**：设最优方案 $S$ 取用了值 $v$。取值 $v$ 会连带删除所有 $v-1$ 与 $v+1$ 的元素，这一步造成的「禁取集合」与取了几份 $v$ 无关。于是在 $S$ 之后继续取剩余的值为 $v$ 的元素：每步净增 $v > 0$ 分，且不新禁任何值，方案仍然合法。若 $S$ 未取尽同值元素，反复操作即得更高分，与最优性矛盾。∎

**引理 2（等价性）**：任一合法操作序列的取用值集合 $A$ 满足「$A$ 中不存在相差 1 的两个值」，得分等于 $\sum_{v \in A} \text{points}[v]$；反之，任一满足该条件的集合 $A$ 都可由某个合法序列实现同样得分。

**证明**：

- （$\Rightarrow$）若 $u, v \in A$ 且 $u = v+1$：先取 $u$ 会把所有 $v$ 删掉，此后无法再取 $v$；先取 $v$ 同理。故 $A$ 中无相邻值。由引理 1 不妨设同值全取，得分即 $\sum_{v\in A} v \cdot \text{cnt}[v]$。
- （$\Leftarrow$）按任意顺序取 $A$ 中的值。取 $u \in A$ 时会删除所有 $u \pm 1$，而 $A$ 中不含 $u \pm 1$，故其它目标值不会被误删；值在 $A$ 中互不相同，同值副本可一次取尽。总得分 $\sum_{v \in A} \text{points}[v]$。∎

**引理 3（DP 正确）**：对每个 $v \ge 0$，$f[v]$ 等于值域 $1..v$ 上的最大权独立集权重。

**证明**：对 $v$ 归纳。$v = 0$ 时无桶可取，$f[0] = 0$ 正确。设 $v-1$ 及以下成立。任取 $1..v$ 上的最优独立集 $A$：若 $v \notin A$，则 $A \subseteq 1..v-1$，权重 $w(A) \le f[v-1]$；若 $v \in A$，则 $v-1 \notin A$，$A \setminus \{v\} \subseteq 1..v-2$，故 $w(A) \le \text{points}[v] + f[v-2]$。两种情形取最大即得 $f[v] \ge w(A)$。另一方面，$f[v-1]$ 与 $\text{points}[v] + f[v-2]$ 各自都对应一个合法独立集的权重，故两者最大值不会超过最优权重 $w(A)$，即 $f[v] \le w(A)$。合并得 $f[v] = w(A)$。∎

**定理**：算法返回值是题目要求的最大点数。

**证明**：由引理 2，原问题与「值域桶上取不相邻格子的最大权独立集」等价；由引理 3，$f[V]$ 正是该独立集的最大权重，而算法输出 $f[V]$。故输出即最大点数。∎

## 6. 复杂度分析

- **时间**：$O(n + V)$。求最大值并累加桶分数需 $O(n)$；对 $v = 0..V$ 做一次 $O(1)$ 递推需 $O(V)$。其中 $V = \max(\text{nums}) \le 10^4$，与 $n$ 同量级，整体线性。
- **空间**：$O(V)$，即 `points` 桶数组；若额外存 $f$ 数组则再 $O(V)$，用两个滚动变量可把 DP 部分压到 $O(1)$。不改变输入数组，也不做排序。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int deleteAndEarn(vector<int>& nums) {
        int V = 0;
        for (int x : nums) V = max(V, x);

        vector<int> points(V + 1, 0);          // points[v] = v * cnt[v]
        for (int x : nums) points[x] += x;     // 同值一次性打包

        int prev2 = 0, prev1 = 0;              // f[v-2], f[v-1]
        for (int v = 0; v <= V; ++v) {
            int cur = max(prev1, prev2 + points[v]);
            prev2 = prev1;
            prev1 = cur;
        }
        return prev1;                          // 即 f[V]
    }
};
```

### Python

```python
class Solution:
    def deleteAndEarn(self, nums: list[int]) -> int:
        V = max(nums)
        points = [0] * (V + 1)          # points[v] = v * cnt[v]
        for x in nums:
            points[x] += x              # 同值一次性打包

        prev2 = prev1 = 0               # f[v-2], f[v-1]
        for v in range(V + 1):
            prev2, prev1 = prev1, max(prev1, prev2 + points[v])
        return prev1                    # 即 f[V]
```

## 8. 边界情况与易错点

1. **只有一个元素**：`[x]` → `points[x] = x`，答案 `x`；`V = x`，桶数组长度 `x+1`，无越界风险。
2. **全部元素相同**：`[10000]*20000` → 答案 $2 \times 10^8$，约为 `int` 上限 $2.1 \times 10^9$ 的十分之一，仍安全；但换成更小整型（如 `short`）或值域更大时就会溢出。
3. **相邻值只有两个**：`[1,2]` → 只能取其一，答案 2。别误以为「取小的更安全」或「取大的更好」是通则——`[1,100]` 答案是 101（两个都能取）。
4. **值域跨度大**：`[1,3,5]` → 互不相邻，全取，答案 9；递推中 $f[2]$ 会继承 $f[1]$，空桶不影响结果。
5. **最大值为 1**：`V = 1`，桶数组仅两个元素，循环跑 $v=0,1$ 两轮；不要因 `points.size()` 小而提前返回。
6. **滚动变量写错顺序**：`prev2 = prev1; prev1 = ...` 若合并成一行乱序赋值，会重复使用 $f[v-1]$ 当 $f[v-2]$，答案偏大，是最常见的 WA 来源。
7. **空输入**：约束保证 `nums` 非空，`max(nums)` 不会抛异常；若在本地对拍要覆盖 `n = 1` 的用例。
