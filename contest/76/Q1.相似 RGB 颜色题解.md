# LeetCode 相似 RGB 颜色 题解

## 1. 题目概述

- **标题 / 题号**：相似 RGB 颜色（#800，easy）
- **链接**：https://leetcode.cn/problems/similar-rgb-color/
- **来源**：LeetCode 第 76 场周赛 Q1
- **难度**：简单
- **标签**：数学、字符串、枚举

**题意**：颜色用 7 位字符串 `"#RRGGBB"` 表示，`RR`、`GG`、`BB` 各是两位十六进制数，即三个通道取值 $0 \sim 255$。若三个通道的两位数字**各自相同**，颜色就能写成 4 位简写 `"#XYZ"`，其含义是把每位数字重复一次：`"#15c"` 就是 `"#1155cc"`。

两个颜色 `"#ABCDEF"` 与 `"#UVWXYZ"` 的相似度定义为

$$\text{similarity} = -(AB-UV)^2-(CD-WX)^2-(EF-YZ)^2$$

给定 `color`，返回一个**有简写形式**的 7 位颜色，使相似度最大；相似度并列时任何答案都接受。

**约束**：

- `color.length == 7`，`color[0] == '#'`
- `color[1]` 到 `color[6]` 均为十六进制数字（`0-9`、`a-f`），输入小写
- 输出必须为 7 个字符且全小写

> 💡 本题输入规模是常数，枚举 $16^3$ 种简写色也能过；但真正值得沉淀的是「**把最相似翻译成每通道取最近的 $17$ 的倍数**」这一步建模，它是可分离优化的最简范例。

## 2. 示例

**示例 1**

```text
输入：color = "#09f166"
输出："#11ee66"
解释：相似度 = -(0x09-0x11)^2 - (0xf1-0xee)^2 - (0x66-0x66)^2
             = -64 - 9 - 0 = -73，是所有简写色中最高的。
```

**示例 2**

```text
输入：color = "#4e3fe1"
输出："#5544dd"
解释：R: 0x4e=78  → 5×17=85  ("55")，差 7
      G: 0x3f=63  → 4×17=68  ("44")，差 5
      B: 0xe1=225 → 13×17=221("dd")，差 4
      相似度 = -(49+25+16) = -90。
```

**示例 3**（边界：余数恰好为 8）

```text
输入：color = "#080808"
输出："#000000"
解释：v=8，到 0 的距离是 8，到 17 的距离是 9，故三个通道都向下取 0。
```

## 3. 解题思路

### 3.1 暴力思路

可简写的颜色一共 $16^3=4096$ 种（每通道 $16$ 个候选 `00,11,…,ff`）。枚举全部候选，逐色计算三通道平方差之和取最小即可，复杂度 $O(16^3 \times 3)$。数据规模固定，这能通过，但它把三个通道当成一个整体联合搜索，掩盖了题目结构，也无法推广到候选集更大的变体。

> ⚠️ 暴力法的根源在于「不知道目标函数可以按通道拆开」。

### 3.2 核心观察：相似度可分离，每通道取最近的 17 的倍数

![三通道各自取最近的 17 的倍数](images/wc76_q1_channel_separable.svg)

**第一层：候选值长什么样。** 简写通道 `"dd"` 的数值是 $16d+d=17d$，所以「可简写」的通道值集合恰为

$$S=\{0,17,34,\dots,255\}=\{\,17d \mid 0\le d\le 15\,\}$$

**第二层：目标可分离。** 相似度是三项平方差的**和**的相反数，最大化它等价于最小化

$$F(d_R,d_G,d_B)=(v_R-17d_R)^2+(v_G-17d_G)^2+(v_B-17d_B)^2$$

三项各含一个独立变量、互不耦合；而约束 $d_{ch}\in\{0,\dots,15\}$ 同样是逐通道的。

**于是原问题降维成三个相同的一维问题**：给定 $v\in[0,255]$，在 $S$ 中找离 $v$ 最近者。由 $(v-17d)^2$ 关于 $|v-17d|$ 单调，等价于最小化绝对差，解为

$$d^*=\operatorname{round}\!\left(\frac{v}{17}\right)=\left\lfloor\frac{v+8}{17}\right\rfloor,\qquad \text{输出段}="dd"$$

> 💡 $+8$ 就是 $\lfloor 17/2\rfloor$：加半个步长再整除，是「最近邻取整」的标准整数写法。因为 $17$ 是奇数，$v/17$ 的小数部分不可能等于 $0.5$，所以不存在需要约定平局方向的点——最优解唯一，与题目「答案唯一」的承诺一致。

### 3.3 算法流程

![算法流程：切分、逐通道取整、拼接](images/wc76_q1_round_flow.svg)

1. 去掉首字符 `#`，把余下 6 位按两位切成 `RR`、`GG`、`BB`。
2. 对每一段：解析为整数 $v$，算 $d=\lfloor (v+8)/17\rfloor$。
3. 把 $d$ 写成一位小写十六进制数字，重复两次得到该通道的两位输出。
4. 拼回 `"#" + 段R + 段G + 段B`，长度 $3\times 2+1=7$。

**免除法变体**：设通道两位数字为 $a$（高位）、$b$（低位），则

$$v=16a+b=17a+(b-a)\ \Longrightarrow\ d=a+\operatorname{round}\!\left(\frac{b-a}{17}\right)$$

而 $b-a\in[-15,15]$，故只有三种情况：$b-a\ge 9$ 时 $d=a+1$；$b-a\le -9$ 时 $d=a-1$；否则 $d=a$。整个过程只做一次数字作差，不需要进制解析。

### 3.4 示例演算

![示例演算：逐通道定位最近的可简写值](images/wc76_q1_example_table.svg)

以 `color = "#09f166"` 走一遍：`"09"`$=9$，$9/17\approx0.53$，$d=1$，输出 `"11"`，距离 $8$；`"f1"`$=241$，$241/17\approx14.18$，$d=14$，输出 `"ee"`，距离 $3$；`"66"`$=102=17\times6$，$d=6$，输出 `"66"`，距离 $0$。三段平方差之和 $64+9+0=73$，相似度 $-73$，与官方解释一致。

再验边界 `"#080808"`：$v=8$，$r=8\le 8$，$d=\lfloor 16/17\rfloor=0$，输出 `"000000"`——距离 $8$ 小于到 $17$ 的 $9$，说明「余数为 8 时向下」这条边界必须算对；而 $r=9$ 时（如 `"#090909"`）距离变为 $9$ 对 $8$，应当向上得到 `"#111111"`。两个方向的分界点正好是 $9$。

## 4. 算法细节

1. **切分下标**：`color[1:3]`、`color[3:5]`、`color[5:7]`。最后一段必须切到 7，写成 `color[5:6]` 只会拿到 1 位数字。
2. **进制解析**：`int(seg,16)` 与 C++ 的 `stoi(seg,nullptr,16)` 都**大小写不敏感**，无需先转小写。
3. **取整写法**：统一用 `(v+8)//17`。不要依赖浮点 `round(v/17.0)`；Python 内置 `round` 是银行家舍入（五取偶），虽然本题不会命中 $0.5$，但换个除数就可能踩坑。
4. **格式化回十六进制**：`format(d,'x')*2` / `string(2, "0123456789abcdef"[d])`。务必走小写路径，`%X`、`format(d,'X')` 会输出大写而判错。
5. **范围自洽**：$v\le 255=17\times15$，故 $d^*\le 15$，恰好一位十六进制数字；无需 `min(d,15)` 之类的钳位，钳位反而会掩盖公式本身的正确性。
6. **位值法替代除法**：$d=a+[\,b-a\ge 9\,]-[\,b-a\le -9\,]$（布尔值直接参与算术），适合在只拿到字符、不想进制转换的场合使用，与第 3.3 节推导一致。
7. **不要联合枚举**：逐通道贪心得到的答案与 $4096$ 枚举完全一致（见引理 2），但前者是精确的解析解，常数更小、可直接证明。

## 5. 正确性证明

**引理 1（单通道最近点）**：设 $v\in[0,255]$，$d^*=\lfloor (v+8)/17\rfloor$，则 $d^*\in\{0,\dots,15\}$，且对一切 $d\in\{0,\dots,15\}$ 有 $|v-17d^*|\le |v-17d|$。

**证明**：写 $v=17q+r$，其中 $q=\lfloor v/17\rfloor$、$0\le r\le 16$。由 $v\le 255=17\cdot15$ 得 $0\le q\le 15$。

- 若 $r\le 8$，则 $v+8=17q+(r+8)$ 且 $r+8\le 16<17$，故 $d^*=q$，距离为 $r$。对任意 $d\ne q$：$d<q$ 时距离 $17(q-d)+r\ge 17-r\ge 9>r$；$d>q$ 时距离 $17(d-q)-r\ge 17-r\ge 9>r$。
- 若 $r\ge 9$，则 $v+8=17(q+1)+(r-9)$ 且 $0\le r-9\le 7$，故 $d^*=q+1$，距离 $17-r\le 8$。此时必有 $q\le 14$（否则 $v\ge 17\cdot15+9>255$），故 $d^*\le 15$。对任意 $d\ne q+1$：$d\le q$ 时距离 $\ge r\ge 9>17-r$；$d\ge q+2$ 时距离 $\ge 34-r\ge 18>17-r$。

两种情形都表明 $d^*$ 是最近点，且 $d^*\in[0,15]$。∎

**引理 2（可分离性）**：记 $g_{ch}(d)=(v_{ch}-17d)^2$，则

$$\min_{d_R,d_G,d_B\in[0,15]}\bigl(g_R(d_R)+g_G(d_G)+g_B(d_B)\bigr)=\sum_{ch\in\{R,G,B\}}\min_{d\in[0,15]}g_{ch}(d)$$

**证明**：$(\le)$ 取每个通道各自的最小点 $d_{ch}$，三元组 $(d_R,d_G,d_B)$ 落在允许集合内，故左端不超过右端。$(\ge)$ 对任意三元组，$g_R(d_R)\ge\min g_R$ 等三项分别成立，逐项相加即得左端不小于右端。两向夹逼得等号，且右端取到最小值的三元组就是各通道最优解的组合。∎

**引理 3（最优解唯一）**：每个通道的最近点唯一，因此全局最优简写色唯一。

**证明**：由引理 1 的证明，$r\le 8$ 与 $r\ge 9$ 两种情形中的距离都**严格**小于其他所有候选的距离（$r\le 8$ 时其他距离 $\ge 9>r$；$r\ge 9$ 时其他距离 $\ge 9>17-r$），故最近点唯一；三通道组合唯一。∎

**定理**：算法返回的颜色与 `color` 相似度最大，且是合法的简写色。

**证明**：令 $F$ 为三通道平方差之和。由引理 2，算法逐通道取到的 $(d_R,d_G,d_B)$ 使 $F$ 达到全局最小；相似度 $=-F$，故其相似度最大。输出每段均为 `"dd"` 形式，可写成 `"#XYZ"`；长度 $1+2\times3=7$，数字取自小写表，满足输出格式要求。由引理 3 该答案还是唯一最优。∎

## 6. 复杂度分析

- **时间**：$O(1)$。三个通道，每通道一次两位解析、一次整数加法与整除、一次单字符格式化，全部常数次操作。若按输入长度 $n=7$ 计则是 $O(n)$。
- **空间**：$O(1)$。只有常数个临时变量；输出字符串长度固定为 7。对比枚举法需要 $O(1)$ 空间但 $O(16^3)$ 次相似度计算，纯常数差距。

## 7. 参考代码

### C++

```cpp
#include <string>
using namespace std;

class Solution {
public:
    string similarRGB(string color) {
        auto nearest = [](const string& seg) {
            int v = stoi(seg, nullptr, 16);        // 两位十六进制 → 通道值
            int d = (v + 8) / 17;                  // 等价 round(v / 17)，+8 即 ⌊17/2⌋
            static const string digits = "0123456789abcdef";
            return string(2, digits[d]);           // 数字 d 重复两次，即 "dd"
        };
        return "#" + nearest(color.substr(1, 2))
                   + nearest(color.substr(3, 2))
                   + nearest(color.substr(5, 2));
    }
};
```

### Python

```python
class Solution:
    def similarRGB(self, color: str) -> str:
        def nearest(seg: str) -> str:
            v = int(seg, 16)          # 两位十六进制 → 通道值
            d = (v + 8) // 17         # 等价 round(v / 17)
            return format(d, 'x') * 2  # 数字 d 重复两次，即 "dd"
        return "#" + nearest(color[1:3]) + nearest(color[3:5]) + nearest(color[5:7])
```

## 8. 边界情况与易错点

1. **余数为 8 与 9 的分界**：`"#080808"` → `"#000000"`（$8<9$，向下），`"#090909"` → `"#111111"`（$9>8$，向上）。若把阈值写成 $\ge 8$ 或 $\ge 10$，这两组就会有一个错。
2. **大小写**：输入本题保证小写；即便上游给 `"#09F166"`，解析也不受影响，但输出必须**全部小写**，`%X` 会直接判错。
3. **末段切片**：`color[5:7]` 才是最后两位，写成 `color[5:6]` 会静默丢失一位数字，得到 6 字符输出。
4. **端点颜色**：`"#ffffff"` 中 $255=17\times15$，$d=15$ → `"ff"`，不会溢出到 `d=16`；`"#000000"` 中 $d=0$，同样合法，无需特判。
5. **不要返回 4 位简写**：题目要求输出 7 字符的完整颜色，简写只是约束条件而非输出形式。
6. **并列答案**：本题由引理 3 保证最优解唯一；题目虽声明「并列可接受」，但按相似度比较更稳妥，不要在代码里做字符串层面的投票或排序。
7. **不要用浮点**：`round(v/17.0)` 在大数或换底数时会引入误差，本题虽安全，整数写法更符合「精确取整」的语义。

**延伸思考**：若通道简写占 $k$ 位（重复 $k$ 次同一位数字 $d$），通道值为 $d\cdot\frac{16^k-1}{15}$，于是问题变成「取最近的 $\frac{16^k-1}{15}$ 的倍数」，$k=2$ 时正是 $17$。若相似度改成加权形式 $\sum w_{ch}\Delta_{ch}^2$ 或 $L_1$ 距离，可分离性依然成立，逐通道最近邻仍是精确解；但若约束换成「整个颜色必须取自给定的调色板」，通道间重新耦合，就退化为三维最近点搜索，只能枚举整个调色板了。
