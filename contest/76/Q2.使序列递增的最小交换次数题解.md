# LeetCode 使序列递增的最小交换次数 题解

## 1. 题目概述

- **标题 / 题号**：使序列递增的最小交换次数（#801，hard）
- **链接**：https://leetcode.cn/problems/minimum-swaps-to-make-sequences-increasing/
- **来源**：LeetCode 第 76 场周赛 Q2
- **难度**：困难
- **标签**：数组、动态规划、状态机 DP

**题意**：给定两个长度相同（共 $n$ 列）的整型数组 `nums1`、`nums2`。一次操作可选中某一列 $i$，把 `nums1[i]` 与 `nums2[i]` 互换。求最少的操作次数，使操作结束后 `nums1` 与 `nums2` **都严格递增**。题目保证输入一定有解。

**约束**：

- $2 \le n \le 10^5$
- `nums2.length == nums1.length`
- $0 \le \text{nums1}[i],\, \text{nums2}[i] \le 2 \times 10^5$
- 保证存在使两数组严格递增的交换方案

## 2. 示例

**示例 1**

```text
输入：nums1 = [1,3,5,4], nums2 = [1,2,3,7]
输出：1
解释：交换下标 3 的两个元素，得到 nums1 = [1,3,5,7]、nums2 = [1,2,3,4]，两者严格递增。
```

**示例 2**

```text
输入：nums1 = [0,3,5,8,9], nums2 = [2,1,4,6,9]
输出：1
解释：交换下标 0（交换下标 1 也可以）：
      nums1 = [2,3,5,8,9]，nums2 = [0,1,4,6,9]。
```

**示例 3（补充示例，用于说明局部贪心会失效）**

```text
输入：nums1 = [0,2,3], nums2 = [1,1,2]
输出：1
解释：交换下标 0 → nums1 = [1,2,3]，nums2 = [0,1,2]。
      而「遇到冲突就换当前列」的贪心会先换下标 1、再换下标 2，共 2 次。
```

## 3. 解题思路

### 3.1 暴力思路

最直观的做法是枚举**每一列换或不换**：得到 $2^n$ 个决策向量 $d \in \{0,1\}^n$，逐个检查两行是否严格递增，代价 $O(n 2^n)$。$n = 10^5$ 时连枚举的第一步都做不到。

贪心同样靠不住。尝试「从左往右扫，第 $i-1$、$i$ 两列冲突就交换第 $i$ 列」：这个策略只看**当前相邻的一对**，但交换第 $i$ 列会改变它与**下一列**的四个比较结果——局部修好、全局变差。示例 3 就是反例：贪心先换下标 1（当时确实合法），再为下标 2 补一次交换，共 2 次；最优解只换下标 0，用 1 次。

> 💡 症结是**后效性**：一次决策的影响会跨过一列，判断第 $i$ 列时必须同时知道第 $i-1$ 列换没换。

### 3.2 核心观察：逐列决策 + 相邻耦合 ⇒ 2 状态 DP

![一次交换只牵动一列](images/wc76_q2_column_state_model.svg)

关键结构：交换第 $i$ 列**只**改动 $(\text{nums1}[i], \text{nums2}[i])$ 这一对值，其余列纹丝不动。于是：

- 决策是一个 $n$ 位 0/1 向量 $d$，$d_i = 1$ 表示交换第 $i$ 列，总代价为 $\sum_{i} d_i$；
- 全部约束都是「同一行内相邻两数的大小关系」，只涉及第 $i-1$、$i$ 两列；
- 所以**前缀是否合法只取决于「第 $i-1$ 列的决策」以及前缀自身是否已递增**，与更早的决策无关。

这正是**无后效性**，可以把 $2^n$ 压成「逐列推进、每列两个状态」的自动机。定义：

$$K_i = \text{使前缀 } 0..i \text{ 严格递增、且第 } i \text{ 列不交换的最少次数}$$

$$S_i = \text{使前缀 } 0..i \text{ 严格递增、且第 } i \text{ 列交换的最少次数}$$

答案即 $\min\bigl(K_{n-1},\, S_{n-1}\bigr)$。

### 3.3 状态转移

![两条件四条边](images/wc76_q2_transition_rules.svg)

先用 $i-1$、$i$ 两列的四个值写下两个相邻判定：

$$A:\ \text{nums1}[i-1] < \text{nums1}[i]\ \wedge\ \text{nums2}[i-1] < \text{nums2}[i]$$

$$C:\ \text{nums1}[i-1] < \text{nums2}[i]\ \wedge\ \text{nums2}[i-1] < \text{nums1}[i]$$

几何意义：$A$ 是「两列决策**相同**（都不换或都换）」时的衔接条件，$C$ 是「两列决策**相反**」时的衔接条件（交换后两行恰好交叉接上）。条件不成立的那一项视为 $+\infty$，两条来源取最小：

$$K_i = \min\bigl\{\,K_{i-1}\ (A \text{ 成立}),\ \ S_{i-1}\ (C \text{ 成立})\,\bigr\}$$

$$S_i = \min\bigl\{\,S_{i-1} + 1\ (A \text{ 成立}),\ \ K_{i-1} + 1\ (C \text{ 成立})\,\bigr\}$$

注意 $A$ 与 $C$ **可以同时成立**（四个值交叉可比时），此时四条边全部可用，这正是取 $\min$ 的意义。初始 $K_0 = 0$（第 0 列不换）、$S_0 = 1$（第 0 列交换）。

### 3.4 示例演算

![示例 2 逐列演算](images/wc76_q2_walkthrough.svg)

对示例 2（$n = 5$）逐列推进：

| $i$ | $\text{nums1}[i]$ | $\text{nums2}[i]$ | $A$ | $C$ | $K_i$ | $S_i$ |
|-----|------|------|------|------|------|------|
| 0 | 0 | 2 | 初值 | 初值 | 0 | 1 |
| 1 | 3 | 1 | 否 | 是 | 1 | 1 |
| 2 | 5 | 4 | 是 | 是 | 1 | 2 |
| 3 | 8 | 6 | 是 | 是 | 1 | 2 |
| 4 | 9 | 9 | 是 | 是 | 1 | 2 |

- $i = 1$：$\text{nums2}[0]=2 < \text{nums2}[1]=1$ 不成立，$A$ 为假，只能走 $C$：$K_1 = S_0 = 1$，$S_1 = K_0 + 1 = 1$。
- $i \ge 2$：$A$、$C$ 同时成立，$K_i = \min(K_{i-1}, S_{i-1}) = 1$，$S_i = \min(S_{i-1}+1, K_{i-1}+1) = 2$。

最终 $\min(K_4, S_4) = 1$，与官方答案一致。

## 4. 算法细节

1. **滚动变量**：$K_i$、$S_i$ 只依赖上一轮的两个值，用两个变量滚动即可，空间 $O(1)$。
2. **初值**：第 0 列不交换 $K_0 = 0$，交换 $S_0 = 1$；漏掉 $S_0 = 1$ 会系统性少算一次交换。
3. **两条来源独立判定**：$A$、$C$ 要分别算，不能写成 `if ... else if ...`——两者可同时成立，须对两个候选取 `min`。
4. **更新顺序**：先把本轮结果存进临时变量 `nk / ns`，最后整体赋值给 `keep / swap`；否则会用本轮新值去推本轮新值，答案偏小。
5. **不可达状态**：用 $10^9$ 作为 $+\infty$（Python 可用 `float('inf')`）。答案最大 $n \le 10^5$，加 1 也不会溢出 `int`。
6. **严格递增一律用 `<`**：题面要求 $a_0 < a_1 < \cdots$，相等非法；写成 `<=` 在含重复值的数据上会直接 WA。
7. **无需还原决策**：题面只要次数；若要输出方案，在转移时记录每个状态的前驱即可（额外 $O(n)$ 空间）。
8. **不要按值域开数组**：状态只与下标有关，$2\times10^5$ 的值域没有任何用处。

## 5. 正确性证明

**引理 1（局部性）**：对任意 $i \ge 1$，第 $i$ 个位置上的两个约束 $\text{nums1}[i-1] < \text{nums1}[i]$ 与 $\text{nums2}[i-1] < \text{nums2}[i]$，只由决策 $d_{i-1}, d_i$（以及原始输入）决定，与 $d_0, \dots, d_{i-2}$ 无关。

**证明**：交换第 $j$ 列只改动第 $j$ 列的上下两个元素。因此第 $i-1$、$i$ 列的最终值只取决于 $d_{i-1}$、$d_i$ 与原始输入，两个约束自然也只依赖这两个决策。∎

**引理 2（可拼接 / 无后效性）**：设 $d_0,\dots,d_i$ 是使前 $i$ 列内部所有相邻约束成立、且第 $i$ 列决策为 $d_i$ 的方案，则 $d_0,\dots,d_{i-1}$ 也是前 $i-1$ 列的合法方案，总代价为前者代价减去 $d_i$；反之，任意前 $i-1$ 列合法方案与满足 $A$（当 $d_{i-1}=d_i$）或 $C$（当 $d_{i-1}\ne d_i$）的 $d_i$ 拼接后，仍是前 $i$ 列的合法方案，代价加上 $d_i$。

**证明**：由引理 1，前缀内部的约束只涉及相邻两列，截断最后一个决策不影响更早的约束，故截断后仍合法、代价恰好少 $d_i$。反向：拼接只新增第 $i$ 个位置的约束，而它恰由 $A$/$C$ 保证成立（两列决策相同时最终同行比较、相反时最终交叉比较），其余约束不受影响。∎

**引理 3（转移完备）**：设 $d_0,\dots,d_i$ 是前 $i$ 列合法方案、总代价 $c$。若 $d_i = 0$ 则 $c \ge K_i$；若 $d_i = 1$ 则 $c \ge S_i$。

**证明**：对 $i$ 归纳。$i = 0$ 时，$d_0=0$ 的代价为 $0 = K_0$、$d_0=1$ 的代价为 $1 = S_0$，成立。设结论对 $i-1$ 成立，考察前 $i$ 列。

若 $d_i = 0$：由引理 2，$d_0,\dots,d_{i-1}$ 是前 $i-1$ 列的合法方案，代价同样是 $c$（本列没换）。当 $d_{i-1}=0$ 时，两行都走「同行相接」，位置 $i$ 合法迫使 $A$ 成立，归纳假设给出 $c \ge K_{i-1}$，而转移在 $A$ 成立时给出 $K_i \le K_{i-1}$，故 $c \ge K_i$；当 $d_{i-1}=1$ 时，位置 $i$ 的合法条件变成「交叉相接」，迫使 $C$ 成立，归纳假设给出 $c \ge S_{i-1}$，转移在 $C$ 成立时给出 $K_i \le S_{i-1}$，同样得 $c \ge K_i$。

若 $d_i = 1$：前缀代价为 $c-1$，仍由引理 2 是前 $i-1$ 列的合法方案。当 $d_{i-1}=0$ 时位置 $i$ 迫使 $C$ 成立，归纳假设给出 $c - 1 \ge K_{i-1}$，而转移在 $C$ 成立时给出 $S_i \le K_{i-1} + 1$，故 $c \ge S_i$；当 $d_{i-1}=1$ 时迫使 $A$ 成立，归纳假设给出 $c - 1 \ge S_{i-1}$，转移在 $A$ 成立时给出 $S_i \le S_{i-1} + 1$，故 $c \ge S_i$。∎

**定理**：算法返回的 $\min(K_{n-1}, S_{n-1})$ 就是最少交换次数。

**证明**：

- **下界**：任一合法方案都是合法决策向量，其最后一列决策为 $0$ 或 $1$；由引理 3（取 $i = n-1$）其代价不小于 $K_{n-1}$ 或不小于 $S_{n-1}$，故不小于 $\min(K_{n-1}, S_{n-1})$。
- **可达**：由引理 2 的反向拼接，DP 中每条被选中的转移都能拼出一个真实的合法决策向量，且代价恰等于该路径累计值；因此最小值被某个真实方案达到。

两者夹逼即得最优性。∎

## 6. 复杂度分析

- **时间**：$O(n)$。单层循环，每列做 4 次整数比较与常数次 `min`，$n = 10^5$ 时约 $10^5$ 次迭代（实测 Python 约 0.06 秒）。
- **空间**：$O(1)$。只保留 $K$、$S$ 两个滚动变量，不复制数组、不开 DP 表；Python 版直接读入参数数组，无额外分配。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int minSwap(vector<int>& nums1, vector<int>& nums2) {
        const int INF = 1e9;
        int keep = 0, swp = 1;                 // 第 0 列不换 / 换
        for (int i = 1; i < (int)nums1.size(); ++i) {
            int nk = INF, ns = INF;
            if (nums1[i - 1] < nums1[i] && nums2[i - 1] < nums2[i]) {
                nk = min(nk, keep);            // 决策一致：两列都不换
                ns = min(ns, swp + 1);         // 决策一致：两列都换
            }
            if (nums1[i - 1] < nums2[i] && nums2[i - 1] < nums1[i]) {
                nk = min(nk, swp);             // 决策相反：本列不换
                ns = min(ns, keep + 1);        // 决策相反：本列交换
            }
            keep = nk;
            swp = ns;
        }
        return min(keep, swp);
    }
};
```

### Python

```python
class Solution:
    def minSwap(self, nums1: list[int], nums2: list[int]) -> int:
        INF = float('inf')
        keep, swap = 0, 1              # 第 0 列不换 / 换
        for i in range(1, len(nums1)):
            nk = ns = INF
            if nums1[i - 1] < nums1[i] and nums2[i - 1] < nums2[i]:
                nk = min(nk, keep)         # 决策一致，两列都不换
                ns = min(ns, swap + 1)     # 决策一致，两列都换
            if nums1[i - 1] < nums2[i] and nums2[i - 1] < nums1[i]:
                nk = min(nk, swap)         # 决策相反
                ns = min(ns, keep + 1)
            keep, swap = nk, ns
        return min(keep, swap)
```

## 8. 边界情况与易错点

1. **本来就严格递增**：结果为 0（如 `nums1=[1,2], nums2=[3,4]`）。$K_i$ 一路为 0，最终 `min` 取到 0；若忘写 $S_0=1$ 而写成 0，可能错报 1 或 0。
2. **$n = 2$ 最小规模**：只有一对相邻约束，$A$ 与 $C$ 至少一个成立；两个候选都要算，不能只走第一条分支。
3. **相等值的严格性**：示例 3 的 $\text{nums2}=[1,1,2]$ 中相等元素必须导致冲突，比较一律用 `<`。
4. **交换位置不连续**：示例 1 只换第 3 列，不要假设「必须从前往后连续换」或「换一次就够」。
5. **$A$、$C$ 同时成立**：必须取两条来源的 `min`，写成 `if / else if` 会在大量数据上给出偏大答案。
6. **滚动变量覆盖时机**：先写入临时变量再统一赋值，否则会用到本轮新值。
7. **不可达状态与溢出**：$+\infty$ 取 $10^9$，最多加 1，不会溢出 `int`；Python 用 `float('inf')` 与整数比较、相加都安全，只是最终答案必须靠题面的「有解」保证为有限值。
8. **无解输入**：题面保证有解，但若某列 $A$、$C$ 都不成立，`keep / swp` 会停在 $+\infty$；需要防御时可在返回前判断结果是否不小于 $10^9/2$，是则返回 `-1`。
