# LeetCode 哈希分割字符串 题解

## 1. 题目概述

- **标题 / 题号**：哈希分割字符串（#3271，medium）
- **链接**：https://leetcode.cn/problems/hash-divided-string/
- **来源**：LeetCode 第 138 场双周赛 Q2
- **难度**：中等
- **标签**：字符串、模拟

**题意**：给定长度为 $n$ 的字符串 `s` 和整数 $k$，且 $n$ 是 $k$ 的倍数。把 `s` 从前往后切成 $n/k$ 个长度为 $k$ 的子串，对每个子串：

1. 把每个字符换算成字母表下标（`'a'` → 0，`'b'` → 1，…，`'z'` → 25）；
2. 求这些下标之和；
3. 对 26 取余，得到 `hashedChar`；
4. 把 `hashedChar` 对应的字母拼到答案末尾。

返回长度为 $n/k$ 的结果字符串。

**约束**：

- $1 \le k \le 100$
- $k \le s.length \le 1000$
- $s.length$ 能被 $k$ 整除
- `s` 只含小写英文字母

## 2. 示例

**示例 1**

```text
输入：s = "abcd", k = 2
输出："bf"
解释：第 1 块 "ab"：0 + 1 = 1，1 % 26 = 1 → 'b'
     第 2 块 "cd"：2 + 3 = 5，5 % 26 = 5 → 'f'
```

**示例 2**

```text
输入：s = "mxz", k = 3
输出："i"
解释：唯一一块 "mxz"：12 + 23 + 25 = 60，60 % 26 = 8 → 'i'
```

## 3. 解题思路

### 3.1 暴力思路

按定义直接模拟：外层枚举块的起点 $i = 0, k, 2k, \dots$，内层累加 $s[i..i+k-1]$ 的哈希值，取模后映射成字母。

时间 $O(n)$（每块扫 $k$ 个字符，共 $n/k$ 块），$n \le 1000$，一次扫描就到了理论下界——每读入一个字符至少要看一次。所以本题没有"更快的渐近解法"，重点在于**把映射与取模的细节写对**。

### 3.2 核心观察：块内求和可以一遍扫完，取模只需在块尾做一次

![切块 + 块内求和取模](images/bw138_q2_chunk_hash.svg)

要点：

- **切块是等长的**：因为 $n$ 是 $k$ 的倍数，所以起点可以直接按 $k$ 步进，不必处理残块。
- **取模放最后**：块内先累加原始哈希值（最大 $25k \le 2500$，远小于溢出范围），块尾再 `% 26` 一次即可。由模运算性质，先取模再相加与最后取模结果相同，但最后取模只做一次除法。
- **双向映射**：字符 → 下标用 `c - 'a'`，下标 → 字符用 `char('a' + v)`，二者互为逆运算，保证 `hashedChar = 0` 时得到 `'a'`。

### 3.3 算法流程

```text
1. result = 空串
2. for i = 0, k, 2k, ... , n - k:
       sum = 0
       for j = i .. i + k - 1:
           sum += s[j] - 'a'
       result 追加 char('a' + sum % 26)
3. 返回 result
```

### 3.4 示例演算

![示例演算：mxz 的哈希过程](images/bw138_q2_walkthrough.svg)

以示例 2 的 `s = "mxz"`、`k = 3` 为例：

| 块 | 字符 | 字母表下标 | 求和 | 对 26 取余 | 结果字符 |
|----|------|-----------|------|-----------|---------|
| 1 | m, x, z | 12, 23, 25 | 60 | 8 | 'i' |

$60 = 2 \times 26 + 8$，余数 8 对应字母 `'i'`（`'a'` 往后数 8 位），答案为 `"i"`。

再看示例 1 的 `"abcd"`、`k = 2`：

| 块 | 字符 | 下标 | 求和 | 取余 | 结果字符 |
|----|------|------|------|------|---------|
| 1 | a, b | 0, 1 | 1 | 1 | 'b' |
| 2 | c, d | 2, 3 | 5 | 5 | 'f' |

拼接得到 `"bf"`。

## 4. 算法细节

1. **步进方式**：`for (int i = 0; i + k <= n; i += k)`，循环次数恰为 $n/k$，不会越界。
2. **字符减法**：C++ 中 `s[j] - 'a'` 得到 `int`；Python 中用 `ord(ch) - ord('a')`。
3. **下标转字符**：C++ 用 `(char)('a' + v)`，Python 用 `chr(ord('a') + v)`。
4. **取模次数**：只在块尾取模一次，块内累加不减；若在块内频繁取模也不影响正确性，只是多做除法。
5. **结果容量**：答案长度固定为 $n/k$，C++ 可 `reserve(n / k)` 减少扩容。

## 5. 正确性证明

**引理 1（切块完整性）**：当 $n$ 是 $k$ 的倍数时，起点序列 $0, k, 2k, \dots, n-k$ 恰好把 $s[0..n-1]$ 划分为 $n/k$ 个互不重叠、长度为 $k$ 的块，且完全覆盖 `s`。

**证明**：设 $n = qk$。起点为 $tk$（$t = 0, \dots, q-1$），第 $t$ 块覆盖下标 $[tk, tk+k-1]$，块长为 $k$；相邻块首尾相接（下一块从 $tk+k$ 开始），首块从 $0$ 开始，末块结束于 $(q-1)k + k - 1 = qk - 1 = n - 1$。故恰好划分整个字符串。∎

**引理 2（块内求和正确）**：内层循环结束时 `sum` 等于该块所有字符的字母表下标之和。

**证明**：内层从 $i$ 到 $i+k-1$ 逐字符累加 $s[j] - 'a'$，而按定义 `'a'` 的下标为 0、每后移一个字母下标加 1，故 $s[j] - 'a'$ 正是 $s[j]$ 的哈希值；累加即得块内哈希值之和。∎

**引理 3（映射往返）**：对任意 $v \in [0, 25]$，`char('a' + v)` 是字母表中下标为 $v$ 的字符。

**证明**：字母表按 `'a'` 到 `'z'` 连续编码，`'a' + v` 的下标恰为 $v$；$v \in [0,25]$ 保证它落在字母表范围内。∎

**定理**：算法返回的字符串与题目定义的哈希结果逐字符相同。

**证明**：由引理 1，算法对每个块恰好处理一次且不重不漏；由引理 2，每块的 `sum` 等于该块哈希值之和，`sum % 26` 即 `hashedChar`；由引理 3，追加的字符正是 `hashedChar` 对应的字母。于是输出串的第 $t$ 个字符与题目对第 $t$ 块的定义一致，逐位相同，故整体相同。∎

## 6. 复杂度分析

- **时间**：$O(n)$。每个字符恰好被读入并换算一次；块尾的取模与拼接共 $n/k$ 次，都是 $O(1)$。这是本题的下界（必须读完整个字符串）。
- **空间**：$O(n/k)$ 存放结果字符串（若不计输出则为 $O(1)$）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    string stringHash(string s, int k) {
        string res;
        for (int i = 0; i + k <= (int)s.size(); i += k) {
            int sum = 0;
            for (int j = i; j < i + k; j++) sum += s[j] - 'a';
            res.push_back(char('a' + sum % 26));
        }
        return res;
    }
};
```

### Python

```python
class Solution:
    def stringHash(self, s: str, k: int) -> str:
        res = []
        for i in range(0, len(s), k):
            total = 0
            for ch in s[i:i + k]:
                total += ord(ch) - ord('a')
            res.append(chr(ord('a') + total % 26))
        return ''.join(res)
```

## 8. 边界情况与易错点

1. **`k == 1`**：每块只有一个字符，结果就是原串逐字符映射（`hashedChar` 等于该字符下标，字母不变），输出与输入相同。
2. **`k == n`**：只有一块，输出长度为 1 的字符串。
3. **余数为 0**：对应字母 `'a'`，不要写成空字符或漏掉。
4. **忘记取模**：直接 `'a' + sum` 会越出字母表，得到怪字符甚至非字母。
5. **切块步进写成 `i++`**：会让块之间重叠，输出长度变成 $n$ 而不是 $n/k$。
6. **残块处理**：本题保证 $n$ 是 $k$ 的倍数，无需处理；若条件放宽，最后不足 $k$ 的块应忽略（按 LeetCode 同类题惯例）或单独处理，需读题确认。
7. **字符与编码**：C++ 的 `char` 参与算术会自动提升为 `int`，但把结果塞回 `string` 时要用 `(char)` 显式转换以免告警。
8. **Python 的切片拷贝**：`s[i:i+k]` 会新建字符串，$n \le 1000$ 无影响；若 $n$ 很大可改成下标遍历避免额外内存。
