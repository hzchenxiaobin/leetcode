# LeetCode 对 Bob 造成的最少伤害 题解

## 1. 题目概述

- **标题 / 题号**：对 Bob 造成的最少伤害（#3273，hard）
- **链接**：https://leetcode.cn/problems/minimum-amount-of-damage-dealt-to-bob/
- **来源**：LeetCode 第 138 场双周赛 Q4
- **难度**：困难
- **标签**：贪心、数组、排序

**题意**：Bob 有 $n$ 个敌人，第 $i$ 个敌人有健康值 `health[i]`，只要它还活着（`health[i] > 0`），每秒就对 Bob 造成 `damage[i]` 点伤害。

每一秒的流程是：**先**由所有活着的敌人对 Bob 造成伤害，**然后** Bob 选择一个活着的敌人攻击，使其健康值减少 `power`（健康值降到 $\le 0$ 即被消灭）。

求 Bob 消灭所有敌人之前**最少**受到的总伤害。

**约束**：

- $1 \le power \le 10^4$
- $1 \le n = damage.length = health.length \le 10^5$
- $1 \le damage[i], health[i] \le 10^4$

## 2. 示例

**示例 1**

```text
输入：power = 4, damage = [1,2,3,4], health = [4,5,6,8]
输出：39
解释：依次集火敌人 3、2、0、1。
     前 2 秒打敌人 3，每秒总伤害 1+2+3+4 = 10，共 20；
     接着 2 秒打敌人 2，每秒 6，共 12；
     接着 1 秒打敌人 0，每秒 3，共 3；
     最后 2 秒打敌人 1，每秒 2，共 4。
     合计 20 + 12 + 3 + 4 = 39。
```

**示例 2**

```text
输入：power = 1, damage = [1,1,1,1], health = [1,2,3,4]
输出：20
解释：每个敌人的击杀耗时分别为 1、2、3、4 秒，
     伤害 = 4×1 + 3×2 + 2×3 + 1×4 = 20。
```

**示例 3**

```text
输入：power = 8, damage = [40], health = [59]
输出：320
解释：只有一个敌人，需要 ceil(59/8) = 8 秒，伤害 = 40 × 8 = 320。
```

## 3. 解题思路

### 3.1 暴力思路

状态爆炸的角度：每秒都要决定打谁，策略空间是 $n^{M}$ 量级（$M$ 为总秒数，可达 $10^9$）。

即便只考虑"集中火力、按某个顺序逐个击破"这一族策略，也要在 $n!$ 个顺序里挑最优，$n$ 最大 $10^5$，不可能枚举。

需要证明两点：**（1）最优策略一定是"按固定顺序逐个集中火力"；（2）这个顺序可以由一个简单的排序键确定。**

### 3.2 核心观察：总伤害 = Σ 伤害 × 死亡时刻

![总伤害 = Σ d_i × T_i](images/bw138_q4_damage_formula.svg)

先算击杀一个敌人要几秒：每次攻击扣 `power`，所以

$$t_i = \left\lceil \frac{health[i]}{power} \right\rceil = \left\lfloor \frac{health[i] + power - 1}{power} \right\rfloor$$

若按顺序 $\pi(1), \pi(2), \dots, \pi(n)$ 逐个集火，则第 $k$ 个被消灭的敌人死于时刻

$$T_k = t_{\pi(1)} + t_{\pi(2)} + \dots + t_{\pi(k)}$$

它在自己活着的每一秒都造成 `damage` 点伤害，因此总伤害为

$$\text{total} = \sum_{k=1}^{n} damage[\pi(k)] \cdot T_k$$

于是问题变成：**给 $t_i$ 与 $damage_i$ 配对排序，使 $\sum d_i T_i$ 最小**，其中 $T_k$ 是前缀和。

### 3.3 算法流程：按 $d/t$ 降序排序

![相邻交换论证：d/t 大的先打](images/bw138_q4_swap_argument.svg)

考虑相邻的两个敌人 $i, j$，前面已耗时 $T$：

- $i$ 先：额外伤害 $= d_i(T + t_i) + d_j(T + t_i + t_j)$
- $j$ 先：额外伤害 $= d_j(T + t_j) + d_i(T + t_j + t_i)$

两者相减，$T$ 与公共项全部抵消：

$$\Delta = d_j t_i - d_i t_j$$

因此 "«$i$ 先" 不劣于 "$j$ 先" $\iff \Delta \le 0 \iff d_i t_j \ge d_j t_i \iff \dfrac{d_i}{t_i} \ge \dfrac{d_j}{t_j}$。

于是**按 $d_i / t_i$ 降序排序**即可：单位击杀耗时造成伤害越高的敌人，越应该先被解决。

```text
1. 对每个敌人算 t_i = ceil(health[i] / power)
2. 按 d_i / t_i 降序排序（用交叉相乘比较，避免浮点）
3. T = 0，total = 0
4. for 排序后的每个敌人 (d, t):
       T += t
       total += d * T
5. 返回 total
```

### 3.4 示例演算

![示例 1 演算：排序、累计时刻、分段伤害](images/bw138_q4_walkthrough.svg)

对示例 1：`power = 4`，`damage = [1,2,3,4]`，`health = [4,5,6,8]`。

击杀耗时：$t = [1, 2, 2, 2]$（$\lceil 4/4 \rceil = 1$，$\lceil 5/4 \rceil = 2$，$\lceil 6/4 \rceil = 2$，$\lceil 8/4 \rceil = 2$）。

| 敌人 | damage | health | t | d / t |
|------|--------|--------|---|-------|
| 0 | 1 | 4 | 1 | 1.0 |
| 1 | 2 | 5 | 2 | 1.0 |
| 2 | 3 | 6 | 2 | 1.5 |
| 3 | 4 | 8 | 2 | 2.0 |

按 $d/t$ 降序：敌人 3、2、0、1（敌人 0 与 1 的比值同为 1，先后互换结果相同）。

| 顺序 | 敌人 | 耗时 | 累计 T | 本段伤害 |
|------|------|------|--------|---------|
| 1 | 3（d=4） | 2 | 2 | 4 × 2 = 8 |
| 2 | 2（d=3） | 2 | 4 | 3 × 4 = 12 |
| 3 | 0（d=1） | 1 | 5 | 1 × 5 = 5 |
| 4 | 1（d=2） | 2 | 7 | 2 × 7 = 14 |

合计 $8 + 12 + 5 + 14 = 39$，与示例一致。

## 4. 算法细节

1. **向上取整**：`(health[i] + power - 1) / power`，C++ 中整数除法天然向下取整，加 `power - 1` 即得向上取整；Python 用 `//`。
2. **排序键用交叉相乘**：比较器写成 `a.d * b.t > b.d * a.t`，避免浮点误差（本题数值小，浮点也能过，但交叉相乘是稳妥写法）。注意比值相等的两个敌人是可交换的，比较器应返回 `false`（即视为等价）。
3. **重排不改变 $d_i$ 与 $t_i$ 的绑定**：把 $(d_i, t_i)$ 打包成结构体/元组一起排序，千万不要只对 $d$ 或只对 $t$ 排序。
4. **累计时刻**：$T$ 必须累加 $t$（击杀耗时），而不是累加"秒数增量"；每段伤害是 $d \times T$，不是 $d \times t$。
5. **64 位整数**：$n \le 10^5$、$t_i \le 10^4$ 时总秒数可达 $10^9$，而 $\sum d_i T_i$ 可达 $10^{18}$ 量级，必须用 `long long`（Python 自动大整数）。
6. **排序稳定性无关**：比值相等的敌人互换不改变总伤害（由交换论证的差值公式可验证 $\Delta = 0$）。

## 5. 正确性证明

先约定：一个"调度"指每一秒决定攻击哪个活着的敌人；$D_i$ 表示敌人 $i$ 被消灭的那一秒（死亡时刻）。

**引理 1（伤害分解）**：任何调度下，Bob 受到的总伤害等于 $\sum_i damage_i \cdot D_i$。

**证明**：敌人在自己活着的每一秒各造成一次 `damage_i`，活着的秒恰好是第 $1$ 秒到第 $D_i$ 秒（含被消灭的那一秒，因为题面规定每秒钟"敌人先造成伤害，Bob 再攻击"），共 $D_i$ 次。对每秒的场上伤害求和并按敌人归并即得。∎

**引理 2（死亡时刻的前缀下界）**：把任意调度下各敌人的死亡时刻升序排列为 $D_{(1)} \le D_{(2)} \le \dots \le D_{(n)}$，对应的敌人为 $\pi(1), \dots, \pi(n)$，则对每个 $k$ 有

$$D_{(k)} \ge \sum_{j=1}^{k} t_{\pi(j)}$$

**证明**：这 $k$ 个敌人在 $D_{(k)}$ 时刻之前（含该秒）都已被消灭，说明针对它们的攻击次数分别达到 $t_{\pi(j)}$，合计 $\sum_{j\le k} t_{\pi(j)}$ 次。每秒只能攻击一个敌人，且这些攻击都发生在第 $1$ 到第 $D_{(k)}$ 秒这 $D_{(k)}$ 个时刻里（各占一个不重复的秒），故 $D_{(k)} \ge \sum_{j \le k} t_{\pi(j)}$。∎

**引理 3（集中火力的顺序策略最优）**：对任意调度，按它的死亡顺序 $\pi$ 做"逐个集中火力"的调度，总伤害不超过原调度。

**证明**：由引理 1 与死亡顺序的定义，

$$\text{原调度总伤害} = \sum_{k} damage_{\pi(k)} \cdot D_{(k)} \ge \sum_{k} damage_{\pi(k)} \cdot \Big(\sum_{j \le k} t_{\pi(j)}\Big)$$

右端正是"按顺序 $\pi$ 逐个集火"时的总伤害（此时 $\pi(k)$ 的死亡时刻恰为前缀和 $\sum_{j\le k} t_{\pi(j)}$）。∎

**引理 4（相邻交换判据）**：在顺序 $\pi$ 中相邻的两个敌人 $i, j$（$i$ 在前），交换它们之后总伤害的变化量为 $d_j t_i - d_i t_j$；故 $d_i/t_i \ge d_j/t_j$ 时 $i$ 在前不劣。

**证明**：设交换前 $i$ 的死亡时刻为 $T + t_i$、$j$ 为 $T + t_i + t_j$；交换后 $j$ 为 $T + t_j$、$i$ 为 $T + t_j + t_i$。两段贡献之差

$$\big[d_i(T+t_i) + d_j(T+t_i+t_j)\big] - \big[d_j(T+t_j) + d_i(T+t_j+t_i)\big] = d_j t_i - d_i t_j$$

其余敌人的死亡时刻只与两者耗时之和有关，不受影响。于是 $i$ 在前不劣 $\iff d_j t_i \le d_i t_j \iff d_i/t_i \ge d_j/t_j$。∎

**定理**：按 $d_i / t_i$ 降序排列并逐个集火，所得总伤害是所有调度中的最小值。

**证明**：由引理 3，最优调度可以在"逐个集火的顺序调度"中取得，故只需在 $n!$ 个顺序里最小化 $\sum_k d_{\pi(k)} T_k$。若某个顺序中存在相邻逆序对（即 $i$ 在 $j$ 前但 $d_i/t_i < d_j/t_j$），由引理 4 交换后总伤害严格变小，说明最优顺序不存在逆序对，必为按 $d/t$ 降序（比值相等时任意）。因此降序顺序达到最小值。∎

## 6. 复杂度分析

- **时间**：$O(n \log n)$。计算 $t_i$ 为 $O(n)$；排序 $O(n \log n)$；累加答案为 $O(n)$。$n = 10^5$ 时排序约 $1.7 \times 10^6$ 次比较。
- **空间**：$O(n)$ 存放 $(d_i, t_i)$ 对（若允许就地修改输入则可用常量额外空间，但 C++ 中 `vector` 拷贝更安全）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long minDamage(int power, vector<int>& damage, vector<int>& health) {
        int n = (int)damage.size();
        vector<pair<long long, long long>> e;  // (damage, seconds)
        for (int i = 0; i < n; i++)
            e.push_back({damage[i], (health[i] + power - 1) / power});
        sort(e.begin(), e.end(), [](const pair<long long,long long>& A,
                                    const pair<long long,long long>& B) {
            return A.first * B.second > B.first * A.second;
        });
        long long total = 0, t = 0;
        for (auto& p : e) { t += p.second; total += p.first * t; }
        return total;
    }
};
```

### Python

```python
from functools import cmp_to_key


class Solution:
    def minDamage(self, power: int, damage: list[int], health: list[int]) -> int:
        enemies = [(d, (h + power - 1) // power) for d, h in zip(damage, health)]

        def cmp(a, b):
            # a 在 b 前当且仅当 d_a * t_b >= d_b * t_a
            left = a[0] * b[1]
            right = b[0] * a[1]
            return -1 if left > right else (1 if left < right else 0)

        enemies.sort(key=cmp_to_key(cmp))
        total = 0
        t = 0
        for d, cnt in enemies:
            t += cnt
            total += d * t
        return total
```

## 8. 边界情况与易错点

1. **整除时的向上取整**：`health[i]` 恰为 `power` 的整数倍时，`(h + p - 1) / p` 仍得到正确值（如 $8/4 = 2$），不要多加一秒。
2. **`int` 溢出**：$\sum d_i T_i$ 可达 $10^{18}$ 量级，C++ 的 `total` 与 `t` 都必须是 `long long`；比较器里的 `d * t` 也要用 64 位。
3. **排序键搞反**：$d/t$ **降序**（大的先打）。若按升序会得到最大伤害但依然"能算"，样例也许多半对不上，务必用示例 1 校验。
4. **只排 $d$ 或只排 $t$**：两者必须绑定成同一元素一起移动，否则 $d_i$ 与 $t_i$ 的对应关系被破坏。
5. **每段伤害用累计时刻**：第 $k$ 段的伤害是 $d \times T_k$（$T_k$ 为到第 $k$ 个敌人死亡为止的总耗时），不是 $d \times t_k$。
6. **比值为整数时的并列**：如示例 1 中敌人 0、1 的 $d/t = 1$，任意先后结果相同；比较器要正确处理"相等"（返回 `false` / `0`），否则 `sort` 可能行为未定义。
7. **$n = 1$**：直接 $d_1 \times t_1$，示例 3 即此类。
8. **别忽略"敌人先造成伤害"**：如果误以为"敌人死后当秒不再伤害"，答案会偏小（每个敌人少算一整段 $d_i$）。
