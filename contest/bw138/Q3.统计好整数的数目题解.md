# LeetCode 统计好整数的数目 题解

## 1. 题目概述

- **标题 / 题号**：统计好整数的数目（#3272，hard）
- **链接**：https://leetcode.cn/problems/find-the-count-of-good-integers/
- **来源**：LeetCode 第 138 场双周赛 Q3
- **难度**：困难
- **标签**：哈希表、数学、组合数学、枚举

**题意**：给定正整数 $n$ 和 $k$。

- 若整数 $x$ 既是**回文数**又能被 $k$ 整除，则称 $x$ 为 **$k$ 回文整数**；
- 若整数 $x$ 的**数位重新排列**后能得到某个 $k$ 回文整数，则称 $x$ 为**好整数**。

求 $n$ 位数中好整数的个数。注意：重排前后都**不能有前导 0**（例如 1010 不能重排成 101）。

**约束**：

- $1 \le n \le 10$
- $1 \le k \le 9$

## 2. 示例

**示例 1**

```text
输入：n = 3, k = 5
输出：27
解释：551 可以重排成 515（回文且被 5 整除）；
     525 本身就是 k 回文整数。这样的三位数共 27 个。
```

**示例 2**

```text
输入：n = 1, k = 4
输出：2
解释：一位数中既是回文又能被 4 整除的只有 4 和 8。
```

**示例 3**

```text
输入：n = 5, k = 6
输出：2468
```

## 3. 解题思路

### 3.1 暴力思路

直接枚举所有 $n$ 位数，对每个数判断"是否存在一个数位排列是 $k$ 回文整数"。仅枚举就是 $9 \times 10^{n-1}$ 个，$n = 10$ 时是 $9 \times 10^9$，不可行；每个数还要再枚举排列，更不可行。

换个方向：**枚举回文数**。$n$ 位回文数由前 $\lceil n/2 \rceil$ 位唯一确定，数量只有 $9 \times 10^{\lceil n/2 \rceil - 1}$：$n = 10$ 时是 $9 \times 10^4 = 90000$，完全可控。

### 3.2 核心观察：好整数由"数位多重集"决定

![枚举前一半构造回文](images/bw138_q3_palindrome_gen.svg)

关键转换：

- 好整数的定义只看**数位的多重集**：$x$ 能重排成某个 $k$ 回文整数 $p$，等价于 $x$ 与 $p$ 的数位多重集相同。
- 因此"存在 $n$ 位数 $x$ 是好整数"这一信息，可以压缩成"**某个 $k$ 回文整数的数位多重集**"。
- 把所有 $k$ 回文整数的多重集去重后收集成集合 $S$，则

$$\text{答案} = \sum_{\sigma \in S} \big(\text{多重集 } \sigma \text{ 能组成的、无前导零的 } n \text{ 位数个数}\big)$$

不同 $\sigma$ 对应的排列集合互不相交（数位多重集不同，数就不同），所以直接相加不会重复。

![按数位多重集去重](images/bw138_q3_signature_dedup.svg)

### 3.3 算法流程

```text
1. 预处理 0! .. 10!
2. half = ceil(n / 2)，seen = 空集合，ans = 0
3. for h = 10^(half-1) .. 10^half - 1:
       s = str(h)
       p = (n 为偶数) ? s + reverse(s) : s + reverse(s 去掉末位)
       若 int(p) % k != 0: 跳过
       key = sorted(p) 的字符串（即数位多重集的规范表示）
       若 key 已在 seen 中: 跳过；否则加入 seen
       用公式数出该多重集能组成的、无前导零的 n 位数个数，累加到 ans
4. 返回 ans
```

排列计数公式（$c_d$ 表示数字 $d$ 的出现次数）：

$$\text{ways} = \frac{n!}{\prod_{d=0}^{9} c_d!} - \begin{cases} \dfrac{(n-1)!}{\prod_{d=0}^{9} (c_d - [d=0])!}, & c_0 > 0 \\[2mm] 0, & c_0 = 0 \end{cases}$$

第一项是全部排列数，第二项是"首位为 0"的排列数（把 0 钉在首位后重排剩下的 $n-1$ 位）。

![排列计数：总数减去以 0 开头](images/bw138_q3_perm_count.svg)

### 3.4 示例演算

以 $n = 4$、$k = 2$ 为例，看一个回文如何"变成"一批好整数：

| 步骤 | 内容 |
|------|------|
| 枚举前半 | $h = 20$（$n = 4$ 时 half $= 2$，$h \in [10, 99]$） |
| 镜像拼回文 | $p = 20 + \text{reverse}(20) = 2002$ |
| 整除检查 | $2002 \bmod 2 = 0$ ✓，是 $k$ 回文整数 |
| 多重集签名 | 数位 $\{0,0,2,2\}$ → `"0022"` |
| 排列计数 | $4!/(2!\,2!) = 6$ 个排列；以 0 开头的有 $3!/(1!\,2!) = 3$ 个 → 合法 3 个 |
| 结果 | 这 3 个数是 2002、2020、2200，它们都能重排成 2002，故都是好整数 |

其中 `2020` 正是题面举的例子：它可以重排成回文 `2002`，所以是 $k = 2$ 下的好整数。

再看去重的必要性（换成 $k = 3$ 的例子）：$h = 21$ 给出 $2112$、$h = 12$ 给出 $1221$，两者数位和都是 $6$，都能被 3 整除，签名同为 `"1122"`。若不去重，`1122` 这一族排列（1122、1212、1221、2112、2121、2211 共 6 个）会被累加两次；去重后只统计一次，正是"去重 + 计数"的分工。

再验证示例 2（$n = 1$、$k = 4$）：$h$ 从 $1$ 到 $9$，回文就是 $h$ 本身，$h \bmod 4 = 0$ 的只有 $4, 8$，各自签名 `"4"`、`"8"`，排列数均为 $1!/1! = 1$，合计 $2$，与示例一致。

## 4. 算法细节

1. **回文构造**：$n$ 为偶数时 $p = s + \text{reverse}(s)$；$n$ 为奇数时中间位只出现一次，故 $p = s + \text{reverse}(s[0..\text{len}-2])$。
2. **前导零安全**：$h \ge 10^{\text{half}-1}$ 保证首位非 0，拼出的回文首位也非 0。
3. **数值范围**：$n \le 10$ 时回文最大 $< 10^{10}$，超出 `int`，C++ 用 `long long` 存 `stoll` 的结果。
4. **签名表示**：把数位排序后的字符串作为键（长度 $n$，字符只有数字），也可用长度为 10 的计数数组；前者实现更短，后者比较更快。
5. **阶乘预处理**：$0! \sim 10!$ 直接打表，计数时用整数连除，避免浮点误差。
6. **扣减条件**：只有当 $c_0 > 0$ 时才存在"首位为 0"的非法排列，需扣减；$c_0 = 0$ 时不要扣，否则会多减。
7. **枚举顺序无关**：先去重再计数，与先计数再去重等价，但前者把重复工作降到最低。

## 5. 正确性证明

记 $\text{ms}(x)$ 为整数 $x$ 的数位多重集，$\mathcal{P}$ 为全部 $n$ 位 $k$ 回文整数的集合，$S = \{\text{ms}(p) : p \in \mathcal{P}\}$。

**引理 1（回文枚举完备且不重）**：算法枚举的 $p$ 恰好是全体 $n$ 位回文数，且每个只出现一次。

**证明**：$n$ 位回文数 $p$ 由前 $\text{half} = \lceil n/2 \rceil$ 位唯一确定（后 $\lfloor n/2 \rfloor$ 位是前面对称位置镜像），而任何满足首位非 0 的 `half` 位串都能拼出一个 $n$ 位回文数。首位非 0 的 `half` 位串恰为区间 $[10^{\text{half}-1}, 10^{\text{half}} - 1]$ 内的整数，算法逐一枚举且不重复，故枚举集合与全体 $n$ 位回文数一一对应。∎

**引理 2（好整数的多重集刻画）**：$n$ 位数 $x$ 是好整数 $\iff \text{ms}(x) \in S$。

**证明**：
($\Rightarrow$) 若 $x$ 是好整数，存在 $x$ 的数位重排 $p$ 使得 $p$ 是 $k$ 回文整数；重排不改变数位多重集，故 $\text{ms}(x) = \text{ms}(p)$。又 $p$ 是 $n$ 位数（重排不允许前导 0），故 $p \in \mathcal{P}$，于是 $\text{ms}(x) \in S$。
($\Leftarrow$) 若 $\text{ms}(x) \in S$，则存在 $p \in \mathcal{P}$ 使 $\text{ms}(p) = \text{ms}(x)$，即 $x$ 的数位可以重排成 $p$。$p$ 本身无前导 0，故这次重排合法，$x$ 是好整数。∎

**引理 3（排列计数公式正确）**：设多重集 $\sigma$ 的计数为 $c_0, \dots, c_9$，$\sum c_d = n$。则 $\sigma$ 能组成的、首位非 0 的 $n$ 位数的个数为

$$\frac{n!}{\prod_d c_d!} - \frac{(n-1)!}{\prod_d (c_d - [d=0])!}\quad (c_0 > 0)$$

**证明**：$\sigma$ 的全部排列数为多项式系数 $n! / \prod_d c_d!$（经典多重集排列数）。其中首位为 0 的排列：固定首位放一个 0（当 $c_0 > 0$ 时可用），其余 $n-1$ 个位置由剩余多重集（0 的个数变为 $c_0 - 1$，其余不变）任意排列，数目为 $(n-1)! / \prod_d (c_d - [d=0])!$。两类排列互斥且并集为"首位为 0 或非 0"，故相减即得首位非 0 的个数。∎

**定理**：算法返回值等于 $n$ 位数中好整数的个数。

**证明**：对每个 $\sigma \in S$，记 $G_\sigma$ 为满足 $\text{ms}(x) = \sigma$ 的 $n$ 位好整数集合。由引理 2，全部好整数集合 $G = \bigcup_{\sigma \in S} G_\sigma$；又不同 $\sigma$ 给出不同的数位多重集，故这些集合两两不交。于是 $|G| = \sum_{\sigma \in S} |G_\sigma|$。而 $G_\sigma$ 恰是"用多重集 $\sigma$ 组成、首位非 0 的 $n$ 位数"，由引理 3 其大小正是算法累加的值。由引理 1，算法收集的 $S$ 恰为全部 $k$ 回文整数的多重集，且每个 $\sigma$ 只处理一次。三处合起来即得结论。∎

## 6. 复杂度分析

- **时间**：枚举量 $9 \times 10^{\text{half}-1} \le 9 \times 10^{4}$（$n \le 10$）。每个候选需要 $O(n)$ 构造回文、取模、排序求签名；对每个**不同**签名再做 $O(n + 10)$ 的计数。总时间 $O\big(n \cdot 9 \cdot 10^{\lceil n/2 \rceil - 1}\big)$，$n = 10$ 时约 $10^6$ 量级。
- **空间**：$O\big(9 \cdot 10^{\lceil n/2 \rceil - 1}\big)$ 存放签名集合（$n = 10$ 时最多 9 万个字符串），以及 $O(1)$ 的阶乘表。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long countGoodIntegers(int n, int k) {
        int half = (n + 1) / 2;
        long long lo = 1, hi = 1;
        for (int i = 0; i < half - 1; i++) lo *= 10;
        for (int i = 0; i < half; i++) hi *= 10;

        long long fact[11];
        fact[0] = 1;
        for (int i = 1; i <= 10; i++) fact[i] = fact[i - 1] * i;

        set<string> seen;
        long long ans = 0;
        for (long long h = lo; h < hi; h++) {
            string s = to_string(h);
            string r = (n % 2 == 0) ? s : s.substr(0, s.size() - 1);
            reverse(r.begin(), r.end());
            string p = s + r;
            if (stoll(p) % k != 0) continue;
            string key = p;
            sort(key.begin(), key.end());
            if (!seen.insert(key).second) continue;

            int cnt[10] = {0};
            for (char ch : key) cnt[ch - '0']++;
            long long ways = fact[n];
            for (int d = 0; d < 10; d++) ways /= fact[cnt[d]];
            if (cnt[0] > 0) {
                long long bad = fact[n - 1];
                for (int d = 0; d < 10; d++) bad /= fact[cnt[d] - (d == 0 ? 1 : 0)];
                ways -= bad;
            }
            ans += ways;
        }
        return ans;
    }
};
```

### Python

```python
from math import factorial


class Solution:
    def countGoodIntegers(self, n: int, k: int) -> int:
        half = (n + 1) // 2
        seen = set()
        ans = 0
        for h in range(10 ** (half - 1), 10 ** half):
            s = str(h)
            p = s + (s[::-1] if n % 2 == 0 else s[:-1][::-1])
            if int(p) % k:
                continue
            key = ''.join(sorted(p))
            if key in seen:
                continue
            seen.add(key)
            cnt = [0] * 10
            for ch in key:
                cnt[int(ch)] += 1
            ways = factorial(n)
            for c in cnt:
                ways //= factorial(c)
            if cnt[0]:
                bad = factorial(n - 1)
                for d in range(10):
                    bad //= factorial(cnt[d] - (1 if d == 0 else 0))
                ways -= bad
            ans += ways
        return ans
```

## 8. 边界情况与易错点

1. **前导零的双向约束**：回文枚举时首位非 0（$h$ 的起点必须是 $10^{\text{half}-1}$），排列计数时也要扣掉首位为 0 的情况，两处都不能漏。
2. **$n = 1$**：`half = 1`，枚举 $1 \sim 9$；每个签名只含一个数字，排列数为 1。
3. **奇数长度的中间位**：$n$ 为奇数时镜像要去掉末位（`s[:-1]`），否则拼出的长度是 $2\text{half}$ 而不是 $n$。
4. **`c_0 > 0` 才扣减**：没有 0 的多重集若也扣一次，会得到负数或错误偏小。
5. **`int` 溢出**：$n = 10$ 的回文可达 $9.9 \times 10^9$，C++ 必须用 `long long` + `stoll`；`int` 会溢出甚至抛异常。
6. **去重必须在计数前**：如果对每个回文都累加排列数，同一多重集会被重复加很多次（例如 `2112` 与 `1221` 的签名都是 `"1122"`，不去重就会把这 6 个数算两遍）。
7. **不要枚举所有 $n$ 位数**：$9 \times 10^{9}$ 个候选，必然超时；务必从"回文由前半决定"切入。
8. **阶乘用整数除法**：`ways /= fact[c]` 逐个除与一次除乘积等价（因为可整除），但顺序无关；不要用浮点 `math.pow`。
