# LeetCode 将每个元素替换为右侧最大元素 题解

## 1. 题目概述

- **标题 / 题号**：将每个元素替换为右侧最大元素（#1299，easy）
- **链接**：https://leetcode.cn/problems/replace-elements-with-greatest-element-on-right-side/
- **来源**：LeetCode 第 16 场双周赛 Q1
- **难度**：简单
- **标签**：数组

**题意**：给定数组 `arr`，把每个元素替换成它**右边**（严格右侧，不含自身）所有元素的最大值；最后一个元素右侧为空，替换为 $-1$。返回替换后的数组。

**约束**：

- $1 \le arr.length \le 10^4$
- $1 \le arr[i] \le 10^5$

## 2. 示例

**示例 1**

```text
输入：arr = [17,18,5,4,6,1]
输出：[18,6,6,6,1,-1]
解释：下标 0 右侧最大是 18；下标 1、2、3 的右侧最大都是 6；
     下标 4 右侧最大是 1；下标 5 右侧没有元素，填 -1。
```

**示例 2**

```text
输入：arr = [400]
输出：[-1]
解释：唯一元素右侧为空。
```

**补充示例**

```text
输入：arr = [1,1,1]
输出：[1,1,-1]
解释：重复值不影响「最大」；最后一个位置仍是 -1。
```

## 3. 解题思路

### 3.1 暴力思路

对每个下标 $i$ 扫一遍 $arr[i+1..n-1]$ 取最大值，两重循环 $O(n^2)$。$n = 10^4$ 时约 $5 \times 10^7$ 次比较，能过但毫无必要——右边的答案被左边反复重算。$O(n^2)$ 的本质问题是「从左往右问右侧信息」，方向反了。

### 3.2 核心观察：从右往左，一个后缀最大值就够了

![核心观察：从右往左扫描维护右侧最大](images/bw16_q1_suffix_scan.svg)

所求 $\mathrm{ans}[i] = \max(arr[i+1..n-1])$（空则 $-1$）是一个**后缀量**：相邻下标的后缀高度重叠——

$$\mathrm{ans}[i-1] = \max(arr[i],\ \mathrm{ans}[i])$$

从右往左扫，维护变量 $mx$ 表示「当前下标严格右侧的最大值」：到访 $i$ 时**先**写出 $\mathrm{ans}[i] = mx$，**再**执行 $mx \gets \max(mx, arr[i])$ 把自己并入。两个动作的先后顺序恰好实现了「严格右侧」的语义，全程只用 $O(1)$ 额外空间。

### 3.3 算法流程

```text
1. mx = -1（哨兵：右侧为空时的答案）
2. for i = n-1 down to 0:
3.     ans[i] = mx          # 此刻 mx 恰为 arr[i+1..n-1] 的最大值
4.     mx = max(mx, arr[i]) # 把 arr[i] 并入后缀
5. 返回 ans
```

### 3.4 示例演算

![示例演算：逐格走查 mx 的变化](images/bw16_q1_example_walkthrough.svg)

以 `arr = [17,18,5,4,6,1]` 走查：

| i | 进入时 mx | ans[i] | 离开时 mx |
|---|-----------|--------|-----------|
| 5 | $-1$ | $-1$ | $\max(-1,1)=1$ |
| 4 | $1$ | $1$ | $\max(1,6)=6$ |
| 3 | $6$ | $6$ | $6$ |
| 2 | $6$ | $6$ | $6$ |
| 1 | $6$ | $6$ | $\max(6,18)=18$ |
| 0 | $18$ | $18$ | 不再需要 |

注意 $i = 0$ 行：进入时 $mx$ 已被上一轮（$i = 1$）涨到 $18$，于是 $\mathrm{ans}[0] = 18$。整个过程中**每个位置写下的都是它严格右侧的最大值**——$i$ 的答案早在处理 $i+1$ 时就已备好，这正是「先写后更」的全部意义。

## 4. 算法细节

1. **哨兵 $-1$**：$arr[i] \ge 1$ 恒成立，用 $-1$ 初始化 $mx$ 既表示「右侧为空」，也不会与任何真实元素混淆；最后一个位置自动得到 $-1$。
2. **先写答案再更新**：顺序颠倒会把 $arr[i]$ 自己算进「右侧」，例如 $arr = [5]$ 时错误地输出 $[5]$ 而不是 $[-1]$。
3. **原地 vs 新数组**：若原地覆写 `arr[i] = mx`，必须先保存 `arr[i]` 的旧值再更新 $mx$（或直接按「先写后更」顺序即可，天然安全）。本题返回新数组更清晰。
4. **正向一遍 + 后缀数组也可**：`suf[i] = max(arr[i+1..])` 先逆序算好再正向抄写，$O(n)$ 时间 $O(n)$ 空间；单变量滚动版本把空间压到 $O(1)$（不计输出）。
5. **无溢出风险**：值域 $\le 10^5$，`int` 足够。

## 5. 正确性证明

**引理 1**：算法循环到下标 $i$（即处理完 $i+1..n-1$ 之后）时，变量 $mx = \max(\{-1\} \cup \{arr[j] : j > i\})$。

**证明**：对 $i$ 从 $n-1$ 到 $0$ 归纳。处理 $i = n-1$ 前，$mx$ 初值为 $-1$，而集合 $\{j > n-1\}$ 为空，等式成立。设处理完 $i+1$ 后等式对 $i+1$ 成立，即此刻 $mx = \max(\{-1\} \cup \{arr[j] : j > i+1\})$；处理 $i$ 时先写 $\mathrm{ans}[i] = mx$（值不变），随后执行 $mx \gets \max(mx, arr[i+1])$——注意此时并入的恰是 $arr[i+1]$（上一轮尚未并入自身）。由 $arr[i+1] \ge 1 > -1$ 且归纳假设，新值 $= \max(\{-1\} \cup \{arr[j] : j > i\})$。∎

**定理**：算法输出的数组满足 $\mathrm{ans}[i] = \max(arr[i+1..n-1])$（右侧为空时为 $-1$），即题目所求。

**证明**：由引理 1，写 $\mathrm{ans}[i]$ 的瞬间 $mx$ 恰为 $\max(\{-1\} \cup \{arr[j] : j > i\})$；由于 $arr[j] \ge 1 > -1$，当右侧非空时该值即 $\max(arr[i+1..n-1])$，右侧为空时集合只剩 $\{-1\}$，值为 $-1$。两种情形均与题意一致。∎

## 6. 复杂度分析

- **时间**：$O(n)$。一次逆序扫描，每个下标常数次比较与赋值；$n = 10^4$ 时瞬时完成。
- **空间**：$O(1)$ 额外空间（输出数组不计入）；若计入输出则 $O(n)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> replaceElements(vector<int>& arr) {
        int n = (int)arr.size();
        vector<int> ans(n);
        int mx = -1;                       // 右侧（严格 i+1..n-1）最大值，初始无元素
        for (int i = n - 1; i >= 0; --i) {
            ans[i] = mx;                   // 先写答案：此刻 mx 是 arr[i+1..n-1] 的最大
            mx = max(mx, arr[i]);          // 再把 arr[i] 并入后缀
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def replaceElements(self, arr: List[int]) -> List[int]:
        ans = [0] * len(arr)
        mx = -1
        for i in range(len(arr) - 1, -1, -1):
            ans[i] = mx
            mx = max(mx, arr[i])
        return ans
```

> 💡 两份代码均通过官方示例（`[18,6,6,6,1,-1]`、`[-1]`），并与 $O(n^2)$ 暴力对拍 2 万组（C++）/ 5 千组（Python）随机数据，`mismatch = 0`。

## 8. 边界情况与易错点

1. **单元素数组**：`arr = [400]` 直接输出 `[-1]`；不要在循环里特判最后一个位置——哨兵 $-1$ 已自动覆盖。
2. **「先写后更」不能颠倒**：颠倒后 $\mathrm{ans}[i]$ 会包含 $arr[i]$ 自己，单元素输入立刻暴露错误。
3. **全相同 / 单调数组**：`[1,1,1]` 输出 `[1,1,-1]`；`[1,2,3]` 输出 `[3,3,-1]`。后缀最大对重复值不敏感，无需去重。
4. **不要用 `ans[n-1] = -1` 硬编码后正向扫**：正向维护「右侧最大」需要额外数据结构（如单调栈或从右先扫一遍），单变量正向做不到。
5. **原地覆写的陷阱**：若把结果写回 `arr` 且在更新 $mx$ **之前**覆写，会把原值丢掉。按本节顺序（先写 `ans[i]`、后用 `arr[i]` 更新）则天然安全。
