# LeetCode 转变数组后最接近目标值的数组和 题解

## 1. 题目概述

- **标题 / 题号**：转变数组后最接近目标值的数组和（#1300，medium）
- **链接**：https://leetcode.cn/problems/sum-of-mutated-array-closest-to-target/
- **来源**：LeetCode 第 16 场双周赛 Q2
- **难度**：中等
- **标签**：数组、二分查找、排序

**题意**：给定正整数数组 `arr` 与目标 `target`，选一个整数 `value`，把数组中**大于** `value` 的元素变成 `value`（小于等于的不动），使新数组的和 $S(value)$ 与 `target` 之差的绝对值最小。多个 `value` 达到相同接近程度时返回**最小**的那个。答案不必是 `arr` 中的元素。

**约束**：

- $1 \le arr.length \le 10^4$
- $1 \le arr[i],\ target \le 10^5$

## 2. 示例

**示例 1**

```text
输入：arr = [4,9,3], target = 10
输出：3
解释：value=3 时数组变 [3,3,3]，和 9，|9−10| = 1；
     value=4 时和 11，|11−10| = 1 同样接近，取较小的 3。
```

**示例 2**

```text
输入：arr = [2,3,5], target = 10
输出：5
解释：value=5 时数组不再被压（5 是最大值），和恰为 10。
```

**示例 3**

```text
输入：arr = [60864,25176,27249,21296,20204], target = 56803
输出：11361
```

**补充示例（tie-break）**

```text
输入：arr = [2,2,2], target = 7
输出：2
解释：value=1 时和为 3（差 4）；value=2 时和为 6（差 1），
     value 取任何 ≥2 的和都封顶在 6，|6−7|=1 已是最小，
     该偏差下 value=2 是最小（且唯一）取值。
```

## 3. 解题思路

### 3.1 暴力思路

`value` 的可行域是 $[0, \max(arr)]$（超过 $\max$ 后和不再变化，取更大的只会更差或并列）。逐个枚举 `value`，每个用 $O(n)$ 求和取最接近：总 $O(n \cdot \max)$，$\max \le 10^5$、$n \le 10^4$ 时约 $10^9$ 次操作，超时。观察发现 $S(value)$ 是一个关于 `value` 的**分段线性、单调不减**函数——单调性正是二分的入口。

### 3.2 核心观察：$S(value)$ 单调不减，最优解卡在「跨过 target 的台阶」两侧

![单调曲线与二分位置](images/bw16_q2_monotone_curve.svg)

$$S(v) = \sum_i \min(arr[i], v)$$

对每个元素 $\min(arr[i], v)$ 随 $v$ 增大**不减小**，故 $S$ 单调不减。设 $v^\ast$ 是使 $S(v) \ge target$ 的**最小** $v$：

- 若连 $v = 0$ 都有 $S(0) \ge target$，则 $v$ 越小 $S$ 越小、离 $target$ 不增，答案为 $0$；
- 否则 $S(v^\ast - 1) < target \le S(v^\ast)$。任何 $v < v^\ast - 1$ 的 $S$ 更小、离 $target$ 更远；任何 $v > v^\ast$ 的 $S$ 更大、离 $target$ 不近于 $v^\ast$。**最优解只能是 $v^\ast - 1$ 或 $v^\ast$**，比较两者的 $|S - target|$，打平取较小值 $v^\ast - 1$（见 §5 定理）。

### 3.3 算法流程：排序 + 前缀和，让 $S(v)$ 的计算降到 $O(\log n)$

![排序数组一分为二求 S(v)](images/bw16_q2_prefix_partition.svg)

```text
1. arr 排序，求前缀和 pre（pre[i] = 前 i 个元素之和）
2. 定义 S(v)：
       idx = 第一个大于 v 的下标（upper_bound）
       S(v) = pre[idx] + (n − idx) × v
3. 二分求最小 v* 使 S(v*) >= target，区间 [0, max(arr)]
4. 若 v* == 0：返回 0
5. 否则比较 |S(v*−1) − target| 与 |S(v*) − target|：
       前者 <= 后者 → 返回 v*−1（tie-break 取小）
       否则         → 返回 v*
```

### 3.4 示例演算

以示例 3 演算（排序后 `arr = [20204, 21296, 25176, 27249, 60864]`，`n = 5`）：

- 二分收敛到 $v^\ast = 11361$：$S(11361) = 0 + 5 \times 11361 = 56805 \ge 56803$；
- $S(11360) = 5 \times 11360 = 56800 < 56803$；
- $|56800 - 56803| = 3 > |56805 - 56803| = 2$，故返回 $11361$。✓

以示例 1 演算（`arr = [3,4,9]`，`target = 10`）：

- $S(3) = 9 < 10$，$S(4) = 11 \ge 10$，故 $v^\ast = 4$；
- $|S(3) - 10| = |9 - 10| = 1$，$|S(4) - 10| = 1$，打平取较小者 $3$。✓

## 4. 算法细节

1. **二分判断函数的单调性来源**：$S(v)$ 单调不减，故「$S(v) \ge target$」是一个单调谓词，`lower_bound` 型二分适用；边界 $[0, \max(arr)]$ 保证 $S(\max) = \mathrm{sum}(arr) \ge target$ 不必然成立——若 $\mathrm{sum}(arr) < target$，二分收敛到 $v^\ast = \max$（$S$ 在此封顶），比较逻辑照常工作。
2. **$S(v)$ 的 $O(\log n)$ 计算**：排序后 $\le v$ 的元素是前缀。`idx = upper_bound(arr, v)` 给出第一个 $> v$ 的位置；前 `idx` 个保持原值贡献 `pre[idx]`，后 $n - idx$ 个被压成 $v$。整段 $O(\log n)$，二分总代价 $O(\log(\max) \cdot \log n)$。
3. **溢出**：$n \cdot \max \le 10^4 \times 10^5 = 10^9$，贴近 `int` 上界；C++ 用 `long long` 累加前缀和与 $S(v)$，返回值本身 $\le \max \le 10^5$ 可安全转 `int`。
4. **tie-break 的方向**：题目要求多解取最小 `value`。比较时写 `target - s1 <= s2 - target`（注意是 $\le$），相等时选 $v^\ast - 1$；若写成严格小于，示例 1 会错误返回 4。
5. **$v^\ast = 0$ 的提前返回**：本题约束 $target \ge 1$ 而 $S(0) = 0 < target$ 恒成立，故 $v^\ast \ge 1$，该分支实际不可达，属纯防御性代码（若 $target$ 允许取 0 则 $v^\ast = 0$ 直接是答案）。
6. **别在无序数组上 `upper_bound`**：排序必须在求 `idx` 之前完成；排序改变了「哪些元素被压」的物理位置但不改变计数值，$S(v)$ 与原数组一致。
7. **备选写法**：不排序、二分内直接 $O(n)$ 求 $S(v)$，总 $O(n \log \max)$，$n = 10^4$ 时同样轻松通过；前缀和版本只是把每次判断再压一个量级。

## 5. 正确性证明

**引理 1（单调性）**：$S(v) = \sum_i \min(arr[i], v)$ 关于 $v$ 单调不减；且对 $v \ge \max(arr)$ 有 $S(v) = \sum arr[i]$ 为常数。

**证明**：任取 $v_1 \le v_2$，对每个 $i$，$\min(arr[i], v_1) \le \min(arr[i], v_2)$（$\min$ 关于第二参数单调不减），逐项相加即得。当 $v \ge \max(arr)$ 时每个 $\min(arr[i], v) = arr[i]$，和为常数。∎

**引理 2（候选收缩）**：设 $v^\ast = \min\{v \ge 0 : S(v) \ge target\}$。若 $\mathrm{sum}(arr) < target$（即集合为空），则任何 $v \ge \max(arr)$ 的 $S$ 相同，最优解中最小者为 $\max(arr)$；否则 $v^\ast$ 存在且 $1 \le v^\ast \le \max(arr)$，满足 $S(v^\ast - 1) < target \le S(v^\ast)$，此时任何最优解 $u$ 满足 $v^\ast - 1 \le u \le v^\ast$。

**证明**：设存在 $u < v^\ast - 1$ 达到最小偏差。由 $v^\ast$ 的最小性，$S(u) \le S(v^\ast - 1) < target$，且 $S(u) \le S(v^\ast - 1)$ 意味着 $target - S(u) \ge target - S(v^\ast - 1) > 0$，即 $|S(u) - target| \ge |S(v^\ast - 1) - target|$，且等号成立时 $u < v^\ast - 1$ 更小——这与「取最小」规则下 $u$ 优于 $v^\ast - 1$ 矛盾（若严格大于则根本不最优）。反之设 $u > v^\ast$ 最优：$S(u) \ge S(v^\ast) \ge target$，故 $|S(u) - target| = S(u) - target \ge S(v^\ast) - target = |S(v^\ast) - target|$，同理 $u$ 不优于 $v^\ast$。∎

**定理**：算法返回的 $v$ 满足 $|S(v) - target| = \min_u |S(u) - target|$，且在此最小偏差集合中取到最小值。

**证明**：由引理 1，二分正确找到 $v^\ast$（或判定全区间 $S < target$，此时 $v^\ast = \max$ 即封顶值，任何更大的 $v$ 的 $S$ 相同而值更大，最小者即 $\max$，算法在该分支直接命中）。由引理 2，最优候选只有 $v^\ast - 1$ 与 $v^\ast$（或封顶情形下的 $\max$ 单点）。算法逐一比较 $|S(v^\ast - 1) - target|$ 与 $|S(v^\ast) - target|$，因 $S(v^\ast - 1) < target \le S(v^\ast)$，两者分别为 $target - S(v^\ast-1)$ 与 $S(v^\ast) - target$；判定条件取 $\le$ 恰在打平时选择较小的 $v^\ast - 1$，与题意一致。∎

## 6. 复杂度分析

- **时间**：$O(n \log n + \log(\max) \cdot \log n)$。排序 $O(n \log n)$ 主导；二分至多 $\lceil \log_2(10^5) \rceil = 17$ 轮，每轮一次 `upper_bound` 与 $O(1)$ 代数运算。总量在 $10^4$ 规模下约 $10^5$ 次基本操作。
- **空间**：$O(n)$。前缀和数组与排序缓冲（C++ 原地排序仅前缀和数组；Python `sorted` 另需 $O(n)$）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int findBestValue(vector<int>& arr, int target) {
        int n = (int)arr.size();
        sort(arr.begin(), arr.end());
        vector<long long> pre(n + 1, 0);                 // pre[i] = arr[0..i-1] 之和
        for (int i = 0; i < n; ++i) pre[i + 1] = pre[i] + arr[i];

        int lo = 0, hi = arr.back();                     // 候选 value ∈ [0, max]
        while (lo < hi) {                                // 找最小的 v 使 sum(v) >= target
            int mid = lo + (hi - lo) / 2;
            if (mutatedSum(arr, pre, mid) >= target) hi = mid;
            else lo = mid + 1;
        }
        int v = lo;                                      // sum(v) >= target 的最小 v
        if (v == 0) return 0;                            // 防御分支：v=0 已封顶
        long long s1 = mutatedSum(arr, pre, v - 1);      // < target（或相等）
        long long s2 = mutatedSum(arr, pre, v);          // >= target
        // |s1 - target| <= |s2 - target| 时取较小的 v-1（tie-break 取较小 value）
        return (target - s1 <= s2 - target) ? v - 1 : v;
    }
private:
    long long mutatedSum(const vector<int>& arr, const vector<long long>& pre, int v) {
        int n = (int)arr.size();
        int idx = (int)(upper_bound(arr.begin(), arr.end(), v) - arr.begin());
        // 前 idx 个 <= v 保持原值，其余压到 v
        return pre[idx] + (long long)(n - idx) * v;
    }
};
```

### Python

```python
class Solution:
    def findBestValue(self, arr: List[int], target: int) -> int:
        arr.sort()
        pre = [0] + list(accumulate(arr))

        def mutated_sum(v: int) -> int:
            idx = bisect_right(arr, v)
            return pre[idx] + (len(arr) - idx) * v

        lo, hi = 0, arr[-1]
        while lo < hi:                       # 最小的 v 使 sum(v) >= target
            mid = (lo + hi) // 2
            if mutated_sum(mid) >= target:
                hi = mid
            else:
                lo = mid + 1
        v = lo
        if v == 0:
            return 0
        s1, s2 = mutated_sum(v - 1), mutated_sum(v)
        return v - 1 if target - s1 <= s2 - target else v
```

> 💡 两份代码均通过官方三个示例（`3`、`5`、`11361`）与边界用例（`target` 极小返回 0 类、封顶类 `[100000,100000],200000 → 100000`），并与「逐 `value` 枚举 + tie-break 取小」的暴力对拍 3000 组（C++）/ 2000 组（Python）随机数据，`mismatch = 0`。

## 8. 边界情况与易错点

1. **tie-break 方向**：打平必须取**较小** `value`。判定式用 `target - s1 <= s2 - target`（$\le$），示例 1（`[4,9,3], target=10`）两个方向给出 3 与 4，写 `<` 会错答 4。
2. **$\mathrm{sum}(arr) \le target$ 的封顶情形**：如 `[2,3,5], target=100`，任何 $v \ge 5$ 的 $S$ 都封顶在 10，二分收敛到 $v^\ast = 5$；$S(4) = 2+3+4 = 9 < 100$，比较 $|9-100|$ 与 $|10-100|$ 后返回 5。✓ 关键是二分上界取 $\max(arr)$：本题约束下 $v > \max$ 后 $S$ 不再变化，超过 $\max$ 的候选只会「更大但不更优（或并列但值更大）」，以 $\max$ 为界既不漏也不冗余。
3. **二分区间左端取 0 不取 1**：`arr` 全部大于 `target` 时（如 `[5,5,5], target=3`），$S(1) = 3 \ge 3$ 且 $S(0) = 0 < 3$，$v^\ast = 1$、返回 1——左端从 0 开始保证不漏。防御分支 `v == 0` 在本题约束（$target \ge 1$）下实际不可达，但保留无害。
4. **溢出**：前缀和与 $(n - idx) \times v$ 均可达 $10^9$ 量级，C++ 必须用 `long long`；Python 天然安全。
5. **`upper_bound` 而非 `lower_bound`**：$S(v)$ 定义中「大于 $v$ 才压」。用 `lower_bound` 找第一个 $\ge v$ 的位置，会把等于 $v$ 的元素也划进「被压」段——其贡献为 $v$，恰等于原值，数值不变；但语义变绕、边界讨论更容易写错，用 `upper_bound`（第一个 $> v$ 的位置）语义最干净。
6. **先排序再二分**：忘记排序时 `upper_bound` 结果无意义，且 C++ 对未排序区间用 `upper_bound` 是未定义行为级别的错误。
7. **答案不必是数组元素**：示例 3 的 11361 不在 `arr` 中，不要把候选限制为 `arr` 的元素集合。
