# LeetCode 层数最深叶子节点的和 题解

## 1. 题目概述

- **标题 / 题号**：层数最深叶子节点的和（#1302，medium）
- **链接**：https://leetcode.cn/problems/deepest-leaves-sum/
- **来源**：LeetCode 第 16 场双周赛 Q3
- **难度**：中等
- **标签**：树、深度优先搜索、广度优先搜索、二叉树

**题意**：给定二叉树根节点 `root`，返回**层数最深**的叶子节点（最深层的**所有**节点，不只叶子意义上的「无孩子」节点——最深层节点必然无孩子）的值之和。层号从 0（根）开始计。

**约束**：

- 树中节点数目在范围 $[1, 10^4]$ 之间
- $1 \le Node.val \le 100$

## 2. 示例

**示例 1**

```text
输入：root = [1,2,3,4,5,null,6,7,null,null,null,null,8]
输出：15
解释：最深为第 3 层，节点是 7（4 的左孩子）与 8（6 的右孩子），7+8=15。
```

**示例 2**

```text
输入：root = [6,7,8,2,7,1,3,9,null,1,4,null,null,null,5]
输出：19
解释：最深层（第 3 层）节点为 9、1、4、5，和 19。
```

**补充示例**

```text
输入：root = [5]
输出：5
解释：单节点树，最深层即根自身。
```

## 3. 解题思路

### 3.1 暴力思路

两遍 DFS：第一遍求最大深度 $D$，第二遍把所有深度恰为 $D$ 的节点值累加。正确但需要两次完整遍历。也可以每个节点算「以我为根的子树深度」再判断，那是 $O(n^2)$ 的弯路。更优雅的做法是把「深度」信息揉进一次遍历的维护逻辑里。

### 3.2 核心观察：BFS 天然按层分组，「最后一组」就是答案

![BFS 逐层累计，队列里只有当前层](images/bw16_q3_bfs_layers.svg)

BFS 的队列在任何时刻只装着「当前层（可能混着刚入队的下一层）」。经典套路是**每轮先拍下 `sz = q.size()`**，这一轮只弹 `sz` 个——弹完时队列里恰好剩下下一层。于是「最深层的和」不需要知道最深是几层：**每进入新的一层就把累加器清零重算**，循环自然终止于最后一个非空层，累加器停在该层的和上。

### 3.3 算法流程

```text
1. q = [root]
2. while q 非空：
3.     sz = q.size()          # 先固定本层节点数
4.     sum = 0                # 新层清零
5.     重复 sz 次：
6.         cur = q 出队
7.         sum += cur.val
8.         cur 的非空孩子入队
9. 返回 sum                   # 最后一次累计的层即最深层
```

DFS 版本（一次遍历，维护 `maxDep` 与 `sum` 两个量）：

```text
dfs(node, dep)：
    若 dep > maxDep：maxDep = dep，sum = node.val     # 首访更深层：全部作废重来
    否则 dep == maxDep：sum += node.val               # 同层追加
    （dep < maxDep：什么都不做）
    递归左右子树（dep+1）
```

### 3.4 示例演算

![DFS 双量刷新规则](images/bw16_q3_example_walkthrough.svg)

以示例 1 的树（根 1，孩子 2、3；2 的孩子 4、5；3 的右孩子 6；4 的左孩子 7；6 的右孩子 8）走 DFS：

| 访问顺序（先左） | dep | maxDep 变化 | sum |
|------------------|-----|-------------|-----|
| 1 | 0 | $0 \to 0$（首访） | 1 |
| 2 | 1 | $1$（新纪录） | 2 |
| 4 | 2 | $2$（新纪录） | 4 |
| 7 | 3 | $3$（新纪录） | 7 |
| 5 | 2 | 不变，且 $<3$ | 7 |
| 3 | 1 | $<3$ | 7 |
| 6 | 2 | $<3$ | 7 |
| 8 | 3 | $=3$，追加 | $7+8=15$ |

答案 $15$。✓ 关键在最后一步：8 与 7 同深，走「追加」分支；而 5、6 虽是「某子树的叶子」，深度却只有 2，被旧层规则正确排除——「最深层」与「叶子」在无孩子意义上重合，但**判定标准是深度**而非「无孩子」。

## 4. 算法细节

1. **`sz = q.size()` 必须在循环体开头拍下**：入队操作会让 `q.size()` 实时增长，若在循环中间取长度，本轮会弹出下一层节点，层边界失守。
2. **累加器清零的位置**：`sum = 0` 放在「拍下 `sz` 之后、弹出之前」——每个新层开始时重置，绝不能放循环外只加不清（那样得到的是全树和）。
3. **DFS 的两分支顺序**：先判 `dep > maxDep`（重置），再判 `dep == maxDep`（追加）；用 `else if` 连接，新纪录那一轮不会误入追加分支（重置已把 `sum` 设为该值本身）。
4. **树为链时的深度**：$10^4$ 节点的链状树递归深度 $10^4$，DFS 需要确保栈容量（C++ 默认栈通常 8 MB，每帧几十字节，安全；Python 默认递归上限 1000，比赛环境若用 DFS 要 `sys.setrecursionlimit` 或直接选 BFS）。**BFS 无此顾虑**，是本题最稳的写法。
5. **数值范围**：$\le 10^4$ 个节点、值 $\le 100$，和 $\le 10^6$，`int` / `int` 均安全。
6. **`null` 孩子的表示**：题目层序数组中的 `null` 只是占位；建树后指针为 `nullptr`，判空即可，无需关心「稀疏层序」里 null 的分布。

## 5. 正确性证明

**引理 1（BFS 分层不变式）**：算法第 $k$ 轮（外层 `while` 第 $k$ 次迭代）开始时，队列恰好包含深度为 $k$ 的全部节点（按从左到右的相对顺序）。

**证明**：对 $k$ 归纳。$k = 0$ 时队列仅含根，深度 0 的节点全集成立。设第 $k$ 轮开始时成立；该轮弹出全部 $sz$ 个深度 $k$ 节点，每个弹出的节点把自己的非空孩子（深度 $k+1$）入队，除此之外无任何入队操作。二叉树中深度 $k+1$ 的节点恰是深度 $k$ 节点的孩子全体，故轮末队列恰含深度 $k+1$ 的全部节点。∎

**引理 2（终止与最深层）**：BFS 在第 $D$ 轮结束后队列为空，其中 $D$ 为树的最大深度；第 $D$ 轮累计的 `sum` 即深度 $D$ 全部节点值之和。

**证明**：由引理 1，第 $k$ 轮开始时队列 = 深度 $k$ 节点集；队列为空当且仅当该层无节点，即 $k > D$。故共执行 $D + 1$ 轮，第 $D$ 轮（最后一轮）开始时队列恰含最深层全部节点，本轮 `sum` 从 0 起逐个累加它们的值，轮末队列空（深度 $D$ 节点无孩子，否则与 $D$ 最大矛盾），循环终止，`sum` 保持为最深层之和。∎

**定理**：算法返回树中最深一层的节点值之和。

**证明**：由引理 2 直接得出；DFS 版本正确性同理：对任意节点 $v$，其值被计入最终 `sum` 当且仅当 $\mathrm{dep}(v) = D$（若 $\mathrm{dep}(v) = D$，则从「$D$ 首次被刷新」起所有同深访问走追加分支，包括 $v$；若 $\mathrm{dep}(v) < D$，则 $v$ 计入后被某个更深的首次访问整体作废，且此后不再有 $\mathrm{dep} = \mathrm{dep}(v)$ 的访问进入追加分支——即使有，也会被后续刷新再次作废）。∎

## 6. 复杂度分析

- **时间**：$O(n)$。BFS 每节点入队出队各一次；DFS 每节点访问一次。$n = 10^4$ 时毫秒级。
- **空间**：$O(n)$。BFS 队列最坏同层节点数（满二叉树底层约 $n/2$）；DFS 为递归栈深，最坏 $n$（链状树）。两者同级，BFS 的最坏空间出现在平衡树、DFS 出现在链状树，互补但上界相同。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int deepestLeavesSum(TreeNode* root) {
        // BFS 逐层处理：队列为空时，最后被累计的那一层即最深层
        long long sum = 0;
        queue<TreeNode*> q;
        q.push(root);
        while (!q.empty()) {
            int sz = (int)q.size();      // 当前层的节点数（先固定下来）
            sum = 0;                     // 新的一层：清零重新累计
            for (int i = 0; i < sz; ++i) {
                TreeNode* cur = q.front(); q.pop();
                sum += cur->val;
                if (cur->left) q.push(cur->left);
                if (cur->right) q.push(cur->right);
            }
        }
        return (int)sum;                // 循环结束后 sum 恰为最深层的和
    }
};
```

### Python

```python
class Solution:
    def deepestLeavesSum(self, root: Optional[TreeNode]) -> int:
        q = deque([root])
        total = 0
        while q:
            sz = len(q)              # 当前层的节点数
            total = 0                # 新的一层：清零重新累计
            for _ in range(sz):
                cur = q.popleft()
                total += cur.val
                if cur.left:
                    q.append(cur.left)
                if cur.right:
                    q.append(cur.right)
        return total                 # 最后一次累计的即最深层
```

> 💡 两份代码均通过官方示例（`15`、`19`）与单节点边界（`5`），并与「BFS 指针三元组 / DFS 记 (maxDep, sum)」的独立参考实现（C++ 3000 组 / Python 2000 组随机形状树，节点数 $\le 60$）对拍，`mismatch = 0`。

## 8. 边界情况与易错点

1. **「最深层」不是「所有叶子」**：中间层的叶子（如示例 1 中深度 2 的 5、6）不算——判定标准是**深度等于最大值**。用「无孩子则累加」会多算。
2. **累加器每层清零**：忘清零得到全树和；清零位置放在拍 `sz` 之前也行，但放在弹出循环内则每弹一个清一次，逻辑崩坏。
3. **`sz` 要先存**：C++ 中 `q.size()` 返回无符号类型且随入队增长，循环条件写 `i < q.size()` 是经典事故（一层永弹不完的错觉 / 越层弹出）。
4. **单节点树**：根即最深层，BFS 一轮返回 `root.val`，无需特判。
5. **Python 递归深度**：若选 DFS 写法，链状 $10^4$ 节点会撞默认递归上限（1000）；BFS 或调大 `sys.setrecursionlimit` 均可，本题推荐 BFS。
6. **层序数组里的 `null` 只是编码**：不要按数组下标 $i$ 的孩子 $2i+1, 2i+2$ 直接计算——稀疏表示（孩子为 `null` 也占位）与「满二叉树式」下标公式仅在**完全**按层序补位时才对齐；接口给的是指针树，跟随指针即可。
7. **和的范围**：$10^4 \times 100 = 10^6$，远小于 `int` 上界，无需 `long long`（保留是防御性习惯）。
