# LeetCode 另一棵树的子树 题解

## 1. 题目概述

- **标题 / 题号**：另一棵树的子树（#572，easy）
- **链接**：https://leetcode.cn/problems/subtree-of-another-tree/
- **来源**：LeetCode 第 31 场周赛 Q2
- **难度**：简单
- **标签**：树、深度优先搜索、二叉树、字符串匹配、哈希函数

**题意**：给定两棵二叉树 `root` 与 `subRoot`，问 `root` 中是否存在某个节点 $u$，使得「以 $u$ 为根的子树」与 `subRoot` **结构完全相同、对应位置的值逐一相同**。子树必须包含 $u$ 的**全部后代**，不能只取其中一部分；`root` 自身也算它自己的一棵子树，所以 `subRoot` 有可能与整棵 `root` 同构。

这是**结构 + 值**的双重判定：值相同但形状不同（少一个孩子、多一个孩子、左右孩子位置对调）都不算匹配。

**约束**：

- `root` 的节点数在 $[1, 2000]$ 之间
- `subRoot` 的节点数在 $[1, 1000]$ 之间
- $-10^4 \le$ 节点值 $\le 10^4$（包含负数与 $0$）

## 2. 示例

**示例 1**

```text
输入：root = [3,4,5,1,2], subRoot = [4,1,2]
输出：true
解释：root 的节点 4 及其两个孩子 1、2 构成的子树与 subRoot 完全相同。
```

**示例 2**

```text
输入：root = [3,4,5,1,2,null,null,null,null,0], subRoot = [4,1,2]
输出：false
解释：root 中节点 4 的右孩子是 2，但 2 还挂着一个左孩子 0；
      subRoot 里的 2 是叶子，结构不同，因此不匹配。
```

**补充示例（值重复）**

```text
输入：root = [1,1], subRoot = [1]
输出：true
解释：root 的两个节点都是叶子 1，任取其一都能与单节点树 subRoot 匹配。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的做法：把 `root` 的每个节点 $u$ 都当作候选根，再**递归地把「以 $u$ 为根的子树」与 `subRoot` 逐节点比对**。

这个朴素框架方向是对的，但有两个细节容易踩空：

1. **比对必须带结构**。只看「值是否出现过」或「中序遍历是否为子串」都会误判（反例见 §8 第 6 条）。
2. **候选根只有 $n$ 个**。子树由根节点唯一确定（$u$ 选定后，后代就被全部包含），因此枚举 $u$ 已覆盖所有子树，不必枚举「子树的子集」。

总代价 = 外层 $n$ 个候选根 × 单次比对 $O(m)$ = $O(nm)$，两个上界相乘是 $2\times 10^6$ 次节点访问，量级安全。真正的陷阱在于：若在比对里做切片或序列化字符串比较，常数会大得多，甚至退化到 $O(nm\log m)$。

### 3.2 核心观察：匹配 = 外层枚举 × 内层同构判定

![子树匹配的两层结构](images/wc31_q2_subtree_match_model.svg)

把问题拆成两层，递归定义就非常干净：

$$\text{isSubtree}(u, t) = \text{same}(u, t) \;\lor\; \text{isSubtree}(u.\text{left}, t) \;\lor\; \text{isSubtree}(u.\text{right}, t)$$

其中 $\text{same}(a,b)$ 是「同构判定」：两棵树（可为空）结构相同且对应位置的值相同。它本身也是一个极短的递归：

$$\text{same}(a,b) = \begin{cases}\text{true}, & a = b = \varnothing \\ \text{false}, & a,\ b\ \text{恰有一个为}\ \varnothing \\ \text{false}, & a.\text{val} \ne b.\text{val} \\ \text{same}(a.\text{left}, b.\text{left}) \land \text{same}(a.\text{right}, b.\text{right}), & \text{否则}\end{cases}$$

**为什么这样就够了**：「子树」由根唯一确定，所以外层遍历必须命中某个 $u$；而「与 `subRoot` 相同」正是同构判定。两个递归的乘积覆盖全部答案。

**剪枝效果**：$\text{same}$ 的第一层就比 $a.\text{val}$ 与 $b.\text{val}$，一旦不等立即返回 `false`，绝大多数候选根只花 $O(1)$。只有候选根的值恰好等于 `subRoot` 根的值时才会往下钻，因此实际运行远快于 $O(nm)$ 上界。

### 3.3 算法流程

![same 的递归流程与三个剪枝出口](images/wc31_q2_same_tree_prune.svg)

**$\text{same}(a,b)$**：

1. `a` 与 `b` 都为空 → 返回 `true`（空结构等于空结构）；
2. 只有一个为空 → 返回 `false`（一空一非空，结构不同）；
3. `a.val != b.val` → 返回 `false`；
4. 否则返回 $\text{same}(a.\text{left}, b.\text{left})$ 且 $\text{same}(a.\text{right}, b.\text{right})$。

**$\text{isSubtree}(u, t)$**：

1. `u` 为空 → 返回 `false`（走到空说明这条路径上已经没有候选根）；
2. $\text{same}(u,t)$ 为真 → 返回 `true`（命中，立即短路）；
3. 否则返回 $\text{isSubtree}(u.\text{left}, t)$ 或 $\text{isSubtree}(u.\text{right}, t)$。

第 3 步用**短路或**：左子树一旦命中，右子树根本不会被访问。

### 3.4 示例演算

![示例 1 的候选根走查](images/wc31_q2_example_walkthrough.svg)

以示例 1（`root = [3,4,5,1,2]`，`subRoot = [4,1,2]`）为例，外层按先序访问候选根：

| 候选根 | 根值比较 | `same()` 下钻过程 | 结论 |
|---|---|---|---|
| 3（root） | $3 \ne 4$ | 第一层即返回 `false` | 剪枝，转左孩子 |
| 4（3 的左孩子） | $4 = 4$ | 左：$1 = 1$ ✓；右：$2 = 2$ ✓；两侧同为叶子 | 命中，返回 `true` |
| 5（3 的右孩子） | $5 \ne 4$ | 已提前返回，不再访问 | — |

示例 2 只差一个节点：`root` 中节点 2 多了一个左孩子 0。$\text{same}(4,4)$ 走到右孩子时比较「2 带左孩子 0」与「2 是叶子」，在 `a` 非空而 `b` 为空处被判 `false`；随后回溯到 5 继续找，整棵树扫完返回 `false`。

## 4. 算法细节

1. **空判断必须成对**：`!a && !b` 才是相等；写成 `!a || !b` 会把「空 vs 非空」误判为相同，`[1]` 与 `[1,2]` 就会错答 `true`。
2. **两个递归用不同的短路运算符**：`same` 用 `&&`（左右都同构才算同构），`isSubtree` 用 `||`（任一候选命中即整体命中），短路让最坏情况很少被真正触发。
3. **接口签名固定为 `isSubtree(root, subRoot)`**，参数顺序不能反：外层遍历的必须是**大树** `root`，内层模式是**小树** `subRoot`。
4. **把同构判定抽成独立函数** `isSameTree`：它就是第 100 题「相同的树」，独立后证明可拆成两条引理，也便于复用到「对称二叉树」等题。
5. **判空只能用指针，不能用值**：节点值域 $-10^4 \sim 10^4$ 包含 $0$ 与负数，用 $0$ 当「空」的哨兵一定出错。
6. **不改树、不用额外容器**：全程只读，空间只有递归栈；若担心退化链的栈深度（$\le 2000$），可把外层换成显式栈，内层 `same` 仍递归。
7. **标签中的「字符串匹配 / 哈希函数」指向另一种解法**：按固定格式序列化两棵树（空节点也要编码），再判断 `subRoot` 的串是否为 `root` 串的子串，可做到 $O(n+m)$（KMP 或双哈希），但实现细节更脆（见 §8 第 6 条）。

## 5. 正确性证明

**引理 1（`same` 的精确性）**：对任意两棵二叉树 $a,b$，$\text{same}(a,b)$ 返回 `true` 当且仅当 $a$ 与 $b$ 同构（结构相同且对应节点值相同）。

**证明**：对 $a,b$ 的节点数之和 $S$ 归纳。

- $S = 0$：两者皆空，同构，返回 `true`，成立。
- $S > 0$ 且一空一非空：节点数不同，不可能同构，返回 `false`，成立。
- 两者都非空：若 $a.\text{val} \ne b.\text{val}$，根值不同故不同构，返回 `false`。若根值相同，则「$a$ 与 $b$ 同构」等价于「$a.\text{left}$ 与 $b.\text{left}$ 同构且 $a.\text{right}$ 与 $b.\text{right}$ 同构」——这是同构定义按根拆开的直接结果。两个子问题的节点数之和都严格小于 $S$，由归纳假设各自精确，故 `&&` 的结果精确。∎

**引理 2（候选根完备）**：`root` 的全部子树恰好是 $\{\text{以 } u \text{ 为根的子树} \mid u \in \text{root}\}$。

**证明**：任取一棵子树 $T$，按定义它包含某个节点 $u$ 及其全部后代，而 $u$ 与它的后代集合唯一确定了 $T$，故 $T$ 就是以 $u$ 为根的子树；反之，每个以 $u$ 为根的子树都满足子树定义。∎

**引理 3（`isSubtree` 的精确性）**：$\text{isSubtree}(u,t)$ 返回 `true` 当且仅当「以 $u$ 为根的子树」中存在与 $t$ 同构的子树。

**证明**：对 $u$ 的高度归纳。

- $u = \varnothing$：以空节点为根的子树不存在，返回 `false`，成立。
- $u \ne \varnothing$：以 $u$ 为根的子树中，与 $t$ 同构的候选分三类——$u$ 自身、落在左子树内、落在右子树内。由引理 1，第一类由 $\text{same}(u,t)$ 精确判定；第二、三类分别由归纳假设保证 $\text{isSubtree}(u.\text{left},t)$ 与 $\text{isSubtree}(u.\text{right},t)$ 精确判定。三者取或即得结论。∎

**定理**：$\text{isSubtree}(\text{root}, \text{subRoot})$ 返回 `true` 当且仅当 `root` 中存在与 `subRoot` 同构的子树。

**证明**：在引理 3 中取 $u = \text{root}$，得「以 `root` 为根的子树中存在与 `subRoot` 同构的子树」$\iff$ 返回 `true`；再由引理 2，`root` 的子树集合正是所有以某节点为根的子树，故该命题即题目所求。∎

## 6. 复杂度分析

- **时间**：最坏 $O(nm)$，$n$、$m$ 分别为 `root`、`subRoot` 的节点数。外层最多访问 $n$ 个候选根，每个候选在 $\text{same}$ 中最多比对 $m$ 个节点，相乘得到 $2000 \times 1000 = 2 \times 10^6$。
  - 最好 $O(m)$：`root` 的根就与 `subRoot` 同构，一次 $\text{same}$ 即返回。
  - 常见情形接近 $O(n)$：多数候选根的值在 $\text{same}$ 第一层就被淘汰，每个只花 $O(1)$。
- **空间**：$O(h_{\text{root}} + \min(h_{\text{root}}, h_{\text{sub}}))$ 的递归栈，$h$ 为树高；最坏（两条退化链）为 $O(n)$。除递归栈外无额外数组或哈希表。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    // 判断两棵树是否完全同构（结构与值都相同）
    bool isSameTree(TreeNode* a, TreeNode* b) {
        if (!a && !b) return true;              // 都空：结构相同
        if (!a || !b) return false;             // 一空一非空：结构不同
        if (a->val != b->val) return false;     // 值不同
        return isSameTree(a->left, b->left) && isSameTree(a->right, b->right);
    }

    bool isSubtree(TreeNode* root, TreeNode* subRoot) {
        if (!root) return false;                        // 走到空，没得匹配了
        if (isSameTree(root, subRoot)) return true;     // 命中，短路返回
        return isSubtree(root->left, subRoot) || isSubtree(root->right, subRoot);
    }
};
```

### Python

```python
from typing import Optional

class Solution:
    def isSubtree(self, root: Optional[TreeNode], subRoot: Optional[TreeNode]) -> bool:
        def same(a: Optional[TreeNode], b: Optional[TreeNode]) -> bool:
            if a is None and b is None:      # 都空：结构相同
                return True
            if a is None or b is None:       # 一空一非空：结构不同
                return False
            if a.val != b.val:               # 值不同
                return False
            return same(a.left, b.left) and same(a.right, b.right)

        if root is None:
            return False
        if same(root, subRoot):              # 先试以 root 为根的子树
            return True
        return self.isSubtree(root.left, subRoot) or self.isSubtree(root.right, subRoot)
```

## 8. 边界情况与易错点

1. **`subRoot` 只有一个节点**：任何值相等的节点都可能匹配，但 `same` 仍要走完整出口（对方的两个孩子都必须为空），不能简化成「搜到该值就返回 `true`」。
2. **`root` 比 `subRoot` 浅**：如 `[1]` 与 `[1,2]`，根值相同但结构不同，返回 `false`；由 `same` 在「一空一非空」处拦下。
3. **值重复**：`[1,1]` 与 `[1]` 返回 `true`；而 `[1,2]` 与 `[1,null,2]` 返回 `false`——左孩子 2 与右孩子 2 是不同结构，必须比较位置而不只是值。
4. **单边树**：`[1,2]`（2 为左孩子）与 `[2]` 返回 `true`；`[1,null,2]`（2 为右孩子）与 `[2]` 也返回 `true`；但 `[1,2]` 与 `[2,1]` 方向不同，返回 `false`。
5. **外层递归到空必须返回 `false`**，否则会解引用空指针；`root` 由约束保证非空，但不能因此省掉判空。
6. **不要用中序/前序子串代替结构判定**：`root = [1,2,3]` 的中序是 `[2,1,3]`，`subRoot = [1,null,3]` 的中序是 `[1,3]`，后者确为前者的子串，但 `[1,null,3]` 不是 `[1,2,3]` 的子树（正确答案 `false`）。若走序列化路线，必须**带空节点标记与分隔符**，并保证匹配段对齐节点边界。
7. **退化链的栈深度**：`root` 是一条 2000 节点的链时 `isSubtree` 递归 2000 层，在 C++/Python 默认栈限制下可接受；若规模放大到 $10^5$，必须改显式栈或序列化方案。
