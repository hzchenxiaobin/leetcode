# LeetCode 松鼠模拟 题解

## 1. 题目概述

- **标题 / 题号**：松鼠模拟（#573，medium）
- **链接**：https://leetcode.cn/problems/squirrel-simulation/
- **来源**：LeetCode 第 31 场周赛 Q3
- **难度**：中等
- **标签**：数组、数学

**题意**：矩形网格里有 1 棵树 $T$、1 只松鼠 $S$ 和 $k$ 颗坚果 $N_1,\dots,N_k$。松鼠每步只能走到上下左右相邻格，**一次最多携带 1 颗坚果**。它要让所有坚果最终都落在树所在的格子，求松鼠需要走的最少步数。位置写作 `[row, col]`，两格之间的距离就是曼哈顿距离 $d(p,q)=\lvert r_p-r_q\rvert+\lvert c_p-c_q\rvert$。

**约束**：

- $3 \le \text{height}\times\text{width} \le 10^4$，即格子总数不超过 $10^4$，坚果数 $k < 10^4$
- 所有给定位置**互不重叠**：树、松鼠、各坚果各占不同格子，不必处理「同格」
- 至少 1 颗坚果，恰好 1 棵树、1 只松鼠
- 坚果给出的顺序没有任何含义，只是一个集合
- 松鼠一次最多带 1 颗，不能一次搬两颗、也不能把坚果放在中途

## 2. 示例

**示例 1**

```text
输入：height = 5, width = 7, tree = [2,2], squirrel = [4,4], nuts = [[3,0],[2,5]]
输出：12
解释：先搬 (2,5)：松鼠走 3 步到坚果处，再走 3 步送到树；
      然后搬 (3,0)：树下 → 坚果 3 步、坚果 → 树下 3 步，合计 3+3+3+3 = 12。
```

**示例 2（官方测试用例 2）**

```text
输入：height = 1, width = 3, tree = [0,1], squirrel = [0,0], nuts = [[0,2]]
输出：3
解释：只有一颗坚果。松鼠 0→2 走 2 步，再带着坚果 2→1 走 1 步，共 3 步。
```

**示例 3（补充反例，非官方）**

```text
输入：height = 1, width = 12, tree = [0,0], squirrel = [0,5], nuts = [[0,4],[0,11]]
输出：25
解释：先搬 (0,11)：6 + 11 = 17 步，再为 (0,4) 往返 4 + 4 步，合计 25；
      若贪心先搬最近的 (0,4)，则是 1 + 4 + 2×11 = 27，反而更差。
```

## 3. 解题思路

### 3.1 暴力思路

三条朴素路线，一条比一条接近答案，但都不能直接用：

1. **枚举搬运顺序**：坚果的访问顺序有 $k!$ 种，对每种顺序累加「当前位置 → 坚果 → 树」的距离取最小。思路是对的，但 $k$ 最大接近 $10^4$，$k!$ 种顺序完全不可能枚举。
2. **在状态空间上 BFS**：状态取「松鼠位置 + 已送达坚果集合 + 手里拿的是哪颗」，在网格图上做 0-1 BFS，这能精确求解，也是暴力对拍时最可靠的「标准答案」。但状态数是 $O\bigl(hw\cdot 2^k\cdot k\bigr)$，对 $k \approx 10^4$ 是指数级爆炸。
3. **贪心选最近的坚果**：看起来自然，却**是错的**——示例 3 里最近的坚果（1 步）反而是更差的第一颗。

真正需要的是「只做一次线性扫描」的观察。

### 3.2 核心观察：树是中转站，只有第一颗坚果特殊

![往返模型：第一颗单程送达，其余都是树下往返](images/wc31_q3_hub_model.svg)

**关键事实**：松鼠一旦把某颗坚果送到树所在的格子，它**就在树下**了；而它下一颗坚果必须从树下出发。因此除了第一颗之外，每一颗坚果都对应一段固定的往返：

$$T \to N_i \to T,\qquad \text{长度} = 2\,d(N_i,T)$$

而第一颗坚果 $N_j$ 只需要支付「松鼠当前位置 → $N_j$」的单程 $d(S,N_j)$ 加上「$N_j$ → 树」的 $d(N_j,T)$。于是固定「第一颗选 $j$」时，总距离恰好是

$$d(S,N_j) + d(N_j,T) + \sum_{i\ne j} 2\,d(N_i,T) = 2\sum_{i=1}^{k} d(N_i,T) + \bigl(d(S,N_j) - d(N_j,T)\bigr)$$

前一项与选择无关，是**必须支付**的固定成本；后一项只取决于「第一颗挑谁」。所以

$$\text{answer} = 2\sum_{i=1}^{k} d(N_i,T) + \min_{j}\bigl(d(S,N_j) - d(N_j,T)\bigr)$$

注意这个 $\min$ 可以是负数：当第一颗坚果落在「松鼠与树的反方向」时，$d(S,N_j)$ 比 $d(N_j,T)$ 还小，等于替松鼠省了路，答案会**小于** $2\Sigma$。

**别按距离贪心**。选择依据是差值 $\delta_j = d(S,N_j)-d(N_j,T)$，而不是 $d(S,N_j)$ 本身：

![反例：最近的坚果不一定最优](images/wc31_q3_choose_first_nut.svg)

示例 3 中 $\delta_1 = 1-4 = -3$，$\delta_2 = 6-11 = -5$，走得更远的 (0,11) 反而省下 2 步——它离树更远，回程本来就长，先把它「顺路带走」收益更大。

### 3.3 算法流程

![算法流程：一次线性扫描](images/wc31_q3_algorithm_flow.svg)

1. 令 $total = 0$、$best = +\infty$。
2. 遍历每颗坚果 $N=(r,c)$：算出 $dT = d(N,T)$、$dS = d(S,N)$，令 $total \leftarrow total + 2\,dT$，并令 $best \leftarrow \min(best,\, dS - dT)$。
3. 返回 $total + best$。

整个过程没有决策、没有回溯，只要一次扫描。$O(k)$ 时间、$O(1)$ 额外空间。

### 3.4 示例演算

对示例 1（树 `(2,2)`、松鼠 `(4,4)`、坚果 `(3,0)` 与 `(2,5)`）：

![示例 1 的网格走查](images/wc31_q3_walkthrough.svg)

| 坚果 | $d(N,T)$ | $d(S,N)$ | $\delta = d(S,N)-d(N,T)$ |
|------|----------|----------|--------------------------|
| $N_1=(3,0)$ | $\lvert3-2\rvert+\lvert0-2\rvert=3$ | $\lvert4-3\rvert+\lvert4-0\rvert=5$ | $2$ |
| $N_2=(2,5)$ | $\lvert2-2\rvert+\lvert5-2\rvert=3$ | $\lvert4-2\rvert+\lvert4-5\rvert=3$ | $0$ |

所以 $2\Sigma = 2\times(3+3) = 12$，$\min\delta = 0$，答案 $12$。若误选 $N_1$ 当第一颗，得到 $12+2=14$，多走 2 步。

示例 2 只有一颗坚果：$2\Sigma = 2\times1 = 2$，$\delta = 2-1 = 1$，答案 $2+1=3$——单颗时公式自动退化为 $d(S,N)+d(N,T)$。

示例 3 中 $2\Sigma = 2\times(4+11) = 30$，$\min\delta = \min(-3,-5) = -5$，答案 $30-5=25$。

## 4. 算法细节

1. **`height` / `width` 不参与计算**：它们只用来描述网格范围。因为树、松鼠、坚果都在矩形内部，曼哈顿距离就是网格上的真实最短路（见引理 3），不需要判断越界，也不需要 BFS。
2. **一次循环同时做两件事**：`total` 累加 $2\,d(N,T)$、`best` 取 $\min(d(S,N)-d(N,T))$，两者互不影响，不要拆成两轮扫描。
3. **`best` 的初值**：用第一颗坚果的 $\delta$ 初始化，或初始化为 `INT_MAX`。**不要初始化成 0**——$\delta$ 可以为负，写 0 会把所有省路的情形吃掉。
4. **距离公式必须是曼哈顿距离**：`abs(r1-r2) + abs(c1-c2)`。写成欧氏距离、写成 `max(|dr|,|dc|)`（切比雪夫）都会错。
5. **不要排序、不要模拟路径**：坚果顺序无关，排序只会多花 $O(k\log k)$；逐格模拟一条路径则是 $O(hw\cdot k)$，毫无必要。
6. **数值范围**：$k<10^4$ 且 $d\le 10^4$，故 $2\Sigma \lesssim 2\times10^8$，`int` 足够；若把网格上限放宽到 $10^9$ 量级，就该改用 `long long`。
7. **接口顺序**按题面签名：`minDistance(height, width, tree, squirrel, nuts)`，`tree` 与 `squirrel` 是长度为 2 的数组，`nuts` 是二维数组。

## 5. 正确性证明

**引理 1（下界）**：固定「松鼠第一颗搬运的坚果是 $N_j$」，则任何合法搬运方案的总步数不少于

$$d(S,N_j) + 2\sum_{i=1}^{k} d(N_i,T) - d(N_j,T)$$

**证明**：把松鼠的整条轨迹按「是否带着坚果」切成若干段。设它依次搬运 $N_j = M_1, M_2, \dots, M_k$。

- 搬 $M_1$ 之前的那段空手路程，起点为 $S$、终点为 $N_j$，长度 $\ge d(S,N_j)$（曼哈顿距离是最短路长度）。
- 对每个 $i$，把 $M_i$ 从 $M_i$ 送到树的搬运段，长度 $\ge d(M_i,T)$。
- 对每个 $i \ge 2$，在送完 $M_{i-1}$ 之后、拿起 $M_i$ 之前的空手路程从树出发、到 $M_i$ 结束，长度 $\ge d(T,M_i)=d(M_i,T)$；末次送达之后若还有移动，长度 $\ge 0$。

三段相加：$d(S,N_j) + \sum_i d(M_i,T) + \sum_{i\ge2} d(M_i,T) = d(S,N_j) + 2\sum_i d(N_i,T) - d(N_j,T)$。∎

**引理 2（可达）**：对任意 $j$，存在方案恰好达到引理 1 的下界。

**证明**：松鼠沿最短路从 $S$ 走到 $N_j$（$d(S,N_j)$ 步），带上坚果沿最短路走到树（$d(N_j,T)$ 步）；随后对每个 $i\ne j$，依次「树下 → $N_i$ → 树下」各走最短路（$2\,d(N_i,T)$ 步）。每颗坚果都在抵达树下时被放下，搬运时手里最多一颗，完全合法；总步数正是下界。∎

**引理 3（曼哈顿距离可实现）**：若 $p,q$ 都在矩形 $[0,h-1]\times[0,w-1]$ 内，则存在长度恰为 $d(p,q)$ 且不越界的格路径。

**证明**：先沿行方向从 $r_p$ 走到 $r_q$，再沿列方向从 $c_p$ 走到 $c_q$（或反过来）。行走过程中行坐标始终介于 $r_p,r_q$ 之间、列坐标始终介于 $c_p,c_q$ 之间，两个区间都落在矩形内，故不越界；总步数 $\lvert r_p-r_q\rvert+\lvert c_p-c_q\rvert = d(p,q)$。∎

**定理**：算法返回 $2\Sigma + \min_j\bigl(d(S,N_j)-d(N_j,T)\bigr)$，等于最小总步数。

**证明**：任一合法方案都有唯一的第一颗坚果 $N_j$，由引理 1 其步数 $\ge 2\Sigma + d(S,N_j)-d(N_j,T) \ge 2\Sigma + \min_j(\cdot)$，故最小步数不小于算法返回值。另一方面，取使 $\delta$ 最小的 $j^\star$，由引理 2、3 构造的方案步数恰为 $2\Sigma + \delta_{j^\star}$，即可达。上下界相等，结论成立。∎

## 6. 复杂度分析

- **时间**：$O(k)$，其中 $k$ 是坚果数量。只需一次遍历，每颗坚果做 4 次减法、3 次加法、1 次取绝对值与 1 次取最小，全部 $O(1)$；不需要排序、建图或搜索。
- **空间**：$O(1)$。只维护 `total`、`best` 两个整数与循环变量，与输入规模无关（不计输入本身）。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <climits>
#include <cstdlib>
using namespace std;

class Solution {
public:
    int minDistance(int height, int width, vector<int>& tree,
                    vector<int>& squirrel, vector<vector<int>>& nuts) {
        (void)height; (void)width;   // 位置都在矩形内，曼哈顿距离即最短路
        int total = 0;               // 2 * sum(d(nut, tree))
        int best = INT_MAX;          // min(d(squirrel, nut) - d(nut, tree))
        for (const auto& nut : nuts) {
            int dTree = abs(nut[0] - tree[0]) + abs(nut[1] - tree[1]);
            int dSq = abs(nut[0] - squirrel[0]) + abs(nut[1] - squirrel[1]);
            total += 2 * dTree;      // 这颗坚果必付的往返
            best = min(best, dSq - dTree);
        }
        return total + best;
    }
};
```

### Python

```python
from typing import List

class Solution:
    def minDistance(self, height: int, width: int, tree: List[int],
                    squirrel: List[int], nuts: List[List[int]]) -> int:
        total = 0        # 2 * sum(d(nut, tree))
        best = None      # min(d(squirrel, nut) - d(nut, tree))
        for nr, nc in nuts:
            d_tree = abs(nr - tree[0]) + abs(nc - tree[1])
            d_sq = abs(nr - squirrel[0]) + abs(nc - squirrel[1])
            total += 2 * d_tree          # 这颗坚果必付的往返
            delta = d_sq - d_tree
            if best is None or delta < best:
                best = delta
        return total + best
```

## 8. 边界情况与易错点

1. **只有一颗坚果**：答案就是 $d(S,N)+d(N,T)$。公式给出 $2d + (d_S-d) = d_S + d$，自动正确，不需要特判。
2. **`best` 初始化为 0**：$\delta$ 可能为负（示例 3），写 0 会漏掉「顺路省路」的情形，答案偏大。用第一颗初始化或 `INT_MAX`。
3. **贪心选最近的坚果**：示例 3 已给出反例（27 vs 25）。必须比较 $\delta = d(S,N)-d(N,T)$，不是 $d(S,N)$。
4. **误用欧氏距离或切比雪夫距离**：松鼠只能上下左右走，只能用 $\lvert\Delta r\rvert+\lvert\Delta c\rvert$；`max(|dr|,|dc|)` 会系统性低估。
5. **以为需要 `height`/`width`**：它们是**冗余参数**，不要为了「用上」而写边界判断或 BFS。要接受参数，但不参与计算。
6. **行列顺序混淆**：题面 `tree = [2,2]` 这类坐标本身对称，行列互换不影响 $\lvert\Delta r\rvert+\lvert\Delta c\rvert$，但若你额外用 $h$、$w$ 做越界校验，就必须对齐行/列含义。
7. **把「第一颗」当成 `nuts[0]`**：坚果顺序无意义，最小 $\delta$ 可能出现在任意一颗上（示例 1 里就出现在第二颗），必须扫完全部坚果再取 $\min$，不能取第一个就收工。
8. **以为要模拟移动**：最坏情况下总步数可达 $10^8$ 量级，逐格模拟既慢又易写错；直接套公式。

**延伸思考**：

1. **网格有障碍**：把 $d$ 换成 BFS 求出的最短路距离即可，公式**一字不改**——证明只用到「距离对称」与「三角不等式」两条性质。这是本题结论最值得迁移的地方。
2. **一次能背 $c$ 颗**：问题立刻变成带容量约束的取货路径规划，$c=1$ 时才有多项式解；$c\ge 2$ 一般是 NP-hard（可归约到多旅行商/车辆路径问题）。
3. **树的位置也可选**：目标变成「选一个格子放树」，使 $2\Sigma + \min\delta$ 最小，就退化成曼哈顿 1-median，行列可分离地取中位数。
4. **允许多只松鼠协作**：若每只松鼠各自从自己的起点出发，问题变成把坚果分配给松鼠再各自套用本篇公式；当坚果数很大时需要贪心/DP 决定分配。
