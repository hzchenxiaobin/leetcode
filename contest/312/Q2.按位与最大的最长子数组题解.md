# LeetCode 按位与最大的最长子数组 题解

## 1. 题目概述

- **标题 / 题号**：按位与最大的最长子数组（#2419，medium）
- **链接**：https://leetcode.cn/problems/longest-subarray-with-maximum-bitwise-and/
- **来源**：LeetCode 第 312 场周赛 Q2
- **难度**：中等
- **标签**：位运算、脑筋急转弯、数组

**题意**：给定长度为 $n$ 的整数数组 `nums`。令 $k$ 为**任意非空子数组**执行**按位与（bitwise AND）**所能得到的最大值，返回按位与结果**等于 $k$** 的**最长**子数组的长度。子数组是数组中的连续元素序列。

**约束**：

- $1 \le n \le 10^5$
- $1 \le \text{nums}[i] \le 10^6$

## 2. 示例

**示例 1**

```text
输入：nums = [1,2,3,3,2,2]
输出：2
解释：子数组按位与运算的最大值是 3。
      能得到此结果的最长子数组是 [3,3]，故返回 2。
```

**示例 2**

```text
输入：nums = [1,2,3,4]
输出：1
解释：子数组按位与运算的最大值是 4。
      能得到此结果的最长子数组是 [4]，故返回 1。
```

**示例 3**（全数组同值）

```text
输入：nums = [5,5,5,5]
输出：4
解释：k = 5，整个数组就是合法子数组，长度 4。
```

**示例 4**（最大值反复出现但不连续）

```text
输入：nums = [3,1,3,3,1,3]
输出：2
解释：k = 3，最长连续段是中间的 [3,3]，长度 2。
```

## 3. 解题思路

### 3.1 暴力思路

枚举全部 $O(n^2)$ 个子数组，用「向右扩展一位就把新元素 AND 进累计值」的增量计算，每个子数组的 AND 均摊 $O(1)$，总时间 $O(n^2)$。$n = 10^5$ 时约 $10^{10}$ 次位运算，必然超时。瓶颈在于把按位与当**黑盒聚合函数**逐段求值，没有利用它的代数性质。

> 💡 赛场信号：$n \le 10^5$ 直接排除枚举子数组；位运算标签 + 「子数组极值」的组合，几乎总指向一条**代数性质**（单调性 / 只清位不减位），而不是滑窗、DP 或二分——那些才是本题的烟雾弹。

### 3.2 核心观察：AND 只清位不减位 ⟹ $k = \max(\text{nums})$，且整段须全等于 $k$

![核心观察：按位 AND 只清位不减位，最大子数组 AND = max(nums)，整段取等须全等于 k](images/2419_and_upper_bound_concept.svg)

三步推理，每步都是一条独立的小性质：

1. **上界性**：按位与逐位做逻辑与，结果的每一位要么保留、要么清零，故 $a \,\&\, b \le a$ 且 $a \,\&\, b \le b$。归纳地，任何非空子数组的 AND 不超过其中**每个**元素，更不超过 $\max(\text{nums})$。
2. **可达性**：长度为 $1$ 的子数组 $[\text{nums}[i]]$ 的 AND 就是 $\text{nums}[i]$ 本身，取 $\text{nums}[i] = \max(\text{nums})$ 即顶格取等。上界与可达夹逼，得 $k = \max(\text{nums})$。
3. **取等刻画**：长度 $> 1$ 的子数组要 AND $= k$，必须**每个元素都等于 $k$**——只要混进一个 $x < k$，整段 AND $\le x < k$，立刻出局；反过来全段都等于 $k$ 时，相同值按位与仍是自身（$k \,\&\, k = k$），整段 AND $= k$。

> 💡 **一句话总结**：子数组 AND $= k \iff$ 子数组中所有元素都 $= k$。于是「按位与最大的最长子数组」等价转化为「**等于 $\max(\text{nums})$ 的元素构成的最长连续段长度**」——一个标准的一维连续段计数题，转化后**全程无需计算任何按位与**。

### 3.3 算法流程：两趟线性扫描

![算法流程：先求 max 再数最长连续段，两趟 O(n) 扫描](images/2419_scan_max_streak_flow.svg)

1. **第一趟**求 `mx = max(nums)`，同时确定 $k$；
2. **第二趟**统计 `== mx` 的最长连续段：维护 `cur`（以当前元素结尾、全等于 `mx` 的连续段长度）与 `ans`（历史最长）；遇到 `nums[i] == mx` 则 `cur += 1` 并更新 `ans = max(ans, cur)`，否则 `cur = 0`。

关键**不变式**：处理完 `nums[i]` 后，`cur` 恰为以 $i$ 结尾、值全等于 `mx` 的最长连续段长度；`ans` 为所有已见连续段长度的最大值。$i$ 全程单调前进，总 $O(n)$。

### 3.4 示例演算

![示例演算：nums=[1,2,3,3,2,2]，mx=3，cur 与 ans 逐步演化得答案 2](images/2419_example_walkthrough.svg)

以示例 1 `nums = [1,2,3,3,2,2]` 演算，先求得 `mx = 3`：

| $i$ | `nums[i]` | `== mx?` | 动作 | `cur` | `ans` |
|-----|-----------|----------|------|-------|-------|
| 0 | 1 | 否 | `cur = 0` | 0 | 0 |
| 1 | 2 | 否 | `cur = 0` | 0 | 0 |
| 2 | 3 | 是 | `cur = 1`，`ans = 1` | 1 | 1 |
| 3 | 3 | 是 | `cur = 2`，`ans = 2` | 2 | **2** |
| 4 | 2 | 否 | `cur = 0` | 0 | 2 |
| 5 | 2 | 否 | `cur = 0` | 0 | 2 |

连续段在 $i = 4$ 处被 `2` 打断（任何含 `2` 的子数组 AND $\le 2 < 3$，不可能再取等），`ans` 不再增长。最长连续段为 $[3,3]$（下标 $2 \sim 3$），答案 $2$ ✓。示例 4 中 `3` 出现 4 次但被 `1` 反复打断，最长连续段仍是 $2$——**计数的是连续段，不是出现次数**。

## 4. 算法细节

1. **两趟 vs 单趟**：两趟写法（先求 `mx` 再统计）逻辑最直白，是赛场首选；单趟写法边求 max 边统计，遇到 `x > mx` 时旧最大值作废，须**同时**重置 `cur = 1` 与 `ans = 1`，坑见 §8。
2. **为何不需要任何 AND 运算**：由 §3.2 的取等刻画，「AND $= k$ 的子数组」全体恰为「全等于 $k$ 的连续段的子段」全体，按位与从问题中完全消失。这是「脑筋急转弯」类题的典型套路：用代数性质**消去**表面运算。
3. **连续段计数模板**：与 [485. 最大连续 1 的个数](https://leetcode.cn/problems/max-consecutive-ones/) 同构，把「值为 1」换成「值等于 `mx`」即可；`cur` 遇非 `mx` 元素直接清零，段被打断后新段从下一个 `mx` 重新起算。
4. **比较写法**：第一趟求 `mx` 可用库函数（C++ `*max_element`、Python `max`）；由于 $1 \le \text{nums}[i]$，单趟写法用 `mx = 0` 起步即可保证首个元素立即覆盖，无需特判。

## 5. 正确性证明

**引理 1**（上界性）：对任意非负整数 $a, b$，有 $a \,\&\, b \le a$ 且 $a \,\&\, b \le b$；进而对任意非空子数组 $S$，$\text{AND}(S) \le \min_{x \in S} x$。

**证明**：按二进制位考察。设 $r = a \,\&\, b$ 的第 $j$ 位为 $r_j$，则 $r_j = a_j \wedge b_j$。当 $r_j = 1$ 时必有 $a_j = b_j = 1$；当 $r_j = 0$ 时该位对数值贡献为 $0$。故 $r$ 的每个为 $1$ 的位在 $a$（同理 $b$）中均为 $1$，即 $r$ 的置位集合是 $a$、$b$ 置位集合的子集，逐位求和即得 $r \le a$ 且 $r \le b$。对 $|S| \ge 2$ 的子数组，将 $\text{AND}(S) = x_1 \,\&\, x_2 \,\&\, \cdots \,\&\, x_m$ 视为对 $x_1$ 逐次应用二元 AND，每步结果单调不增，归纳得 $\text{AND}(S) \le \min_{x \in S} x$；$|S| = 1$ 时取等。∎

**引理 2**（最大值可达）：$k = \max(\text{nums})$。

**证明**：一方面，由引理 1，任意非空子数组 $S$ 满足 $\text{AND}(S) \le \min_{x \in S} x \le \max(\text{nums})$，故 $k \le \max(\text{nums})$。另一方面，取 $i^*$ 使 $\text{nums}[i^*] = \max(\text{nums})$，单元素子数组 $S^* = [\text{nums}[i^*]]$ 的 AND 无可再与，恰为 $\text{nums}[i^*] = \max(\text{nums})$，故 $k \ge \max(\text{nums})$。两侧夹逼得 $k = \max(\text{nums})$。∎

**引理 3**（取等刻画）：非空子数组 $S$ 满足 $\text{AND}(S) = k$ 当且仅当 $S$ 中每个元素都等于 $k$（其中 $k = \max(\text{nums})$）。

**证明**：（$\Leftarrow$）若 $S$ 中所有元素均为 $k$，则归纳地每一步 AND 的操作数相同，结果保持 $k$，故 $\text{AND}(S) = k$。（$\Rightarrow$）反证：设存在 $x \in S$ 且 $x < k$，由引理 1 得 $\text{AND}(S) \le x < k$，与 $\text{AND}(S) = k$ 矛盾；又由引理 2 的上界 $\text{AND}(S) \le \max(\text{nums}) = k$，$S$ 中不存在 $> k$ 的元素，故所有元素只能等于 $k$。∎

**定理**：所求答案等于「数组中等于 $\max(\text{nums})$ 的元素构成的最长连续段长度」。

**证明**：由引理 3，合法子数组（AND $= k$）的全体恰为「元素全等于 $k$ 的连续子数组」全体。一个元素全等于 $k$ 的极大连续段内，任取连续子段仍全等于 $k$；反之任何全等于 $k$ 的子数组必完整落于某个极大连续段内。故最长合法子数组即最长极大连续段本身，其长度为所求。第二趟扫描维护的不变式（§3.3）保证 `ans` 在扫描结束时恰为该长度。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。第一趟求最大值 $n$ 次比较，第二趟统计最长连续段 $n$ 次比较与常数次赋值，合计 $2n$ 个 $O(1)$ 步骤；渐近上两趟与单趟（每日题解 §5 的合并写法）同为 $O(n)$，差别仅在常数。
- **空间复杂度**：$O(1)$。仅 `mx`、`cur`、`ans` 三个变量，不随 $n$ 增长。

## 7. 参考代码

### C++（两趟，推荐）

```cpp
class Solution {
public:
    int longestSubarray(vector<int>& nums) {
        int mx = *max_element(nums.begin(), nums.end());
        int ans = 0, cur = 0;
        for (int x : nums) {
            if (x == mx) {
                ++cur;
                ans = max(ans, cur);
            } else {
                cur = 0;
            }
        }
        return ans;
    }
};
```

### C++（单趟，边求 max 边统计）

```cpp
class Solution {
public:
    int longestSubarray(vector<int>& nums) {
        int mx = 0, cur = 0, ans = 0;
        for (int x : nums) {
            if (x > mx) {           // 新最大值出现，旧记录全部作废
                mx = x;
                cur = 1;
                ans = 1;
            } else if (x == mx) {   // 延续当前段
                ++cur;
                ans = max(ans, cur);
            } else {                // 段被打断
                cur = 0;
            }
        }
        return ans;
    }
};
```

### Python（两趟）

```python
class Solution:
    def longestSubarray(self, nums: List[int]) -> int:
        mx = max(nums)
        ans = cur = 0
        for x in nums:
            if x == mx:
                cur += 1
                ans = max(ans, cur)
            else:
                cur = 0
        return ans
```

### Python（itertools 单趟分组）

```python
class Solution:
    def longestSubarray(self, nums: List[int]) -> int:
        mx = max(nums)
        return max(len(list(g)) for _, g in groupby(nums, key=lambda x: x == mx) if _)
```

## 8. 边界情况与易错点

1. **别去真的算 AND**：等价转化后不需要任何位运算。写滑窗、前缀 AND、DP 都是把简单题做复杂，赛场上白白浪费时间。
2. **计数的是连续段，不是出现次数**：`[3,1,3,3,1,3]` 中 `3` 出现 4 次，但答案是最长连续段 $2$。把 `cur` 打断后不清零、或直接数 `== mx` 的元素个数，都是 WA。
3. **单趟写法的重置陷阱**：`x > mx` 分支必须**同时**重置 `cur = 1` 与 `ans = 1`——新最大值自身就是长度为 $1$ 的合法段。只重置 `cur` 忘了 `ans`，在严格递增数组（如 `[1,2,3,4]`）上会返回过时的旧 `ans`。两趟写法天然无此风险。
4. **全数组同值**：答案为 $n$，扫描流程天然覆盖，无需特判。
5. **最大值仅出现一次**：答案为 $1$（示例 2），`ans` 初值 `0` 会在首个 `== mx` 处被更新为 `1`，同样无需特判；注意答案**不可能为 $0$**（非空子数组总存在，$k$ 总可达）。
6. **$n = 1$**：`mx = nums[0]`，答案 $1$，两种写法均自动成立。
7. **初值依赖约束**：单趟写法 `mx = 0` 依赖 $1 \le \text{nums}[i]$；若题目放宽为允许 $0$，应改用 `mx = nums[0]` 起步或保持两趟写法，避免 `x > mx` 永不触发的边界。
