# LeetCode 范围内的数字计数 题解

## 1. 题目概述

- **标题 / 题号**：范围内的数字计数（#1067，hard）
- **链接**：https://leetcode.cn/problems/digit-count-in-range/
- **来源**：LeetCode 第 1 场双周赛 Q4
- **难度**：困难
- **标签**：数学、动态规划、数位 DP

**题意**：给定数字 $d$（$0 \le d \le 9$）与两个正整数 $low, high$（$low \le high$）。统计 $[low, high]$ 中**所有整数**的十进制写法里，数字 $d$ 出现的**总次数**（边界计入；同一个数中多处出现要计多次）。

**约束**：

- $0 \le d \le 9$
- $1 \le low \le high \le 2 \times 10^8$

## 2. 示例

**示例 1**

```text
输入：d = 1, low = 1, high = 13
输出：6
解释：1、10、11、12、13 中共出现 6 次 1；注意 11 里有两个 1。
```

**示例 2**

```text
输入：d = 3, low = 100, high = 250
输出：35
解释：103、113、123、130、131、…、238、239、243 中的全部数字 3，共 35 个。
```

**示例 3**（自造，验证 $d=0$ 的边界）

```text
输入：d = 0, low = 1, high = 100
输出：11
解释：10、20、…、90 各一个 0（共 9 个），100 里有两个 0，合计 11。
```

## 3. 解题思路

### 3.1 暴力思路

从 $low$ 枚举到 $high$、逐个数位统计：$2 \times 10^8$ 个数、每个最多 9 位，约 $1.6 \times 10^9$ 次操作，必然超时。区间计数问题的标准突破口是**前缀和（差分）**：

$$\text{答案} = f(high) - f(low - 1),\qquad f(n) := [1,\ n]\ \text{中 } d\ \text{的出现次数}$$

于是问题只剩一个：如何快速求 $f(n)$？答案是**数位 DP 的按位贡献形式**——把「每一位上可能出现的 $d$」分开数清楚，再求和。

### 3.2 核心观察：前缀作差 + 按位贡献

![观察一：区间计数转前缀作差](images/bw1_q4_prefix_difference_model.svg)

**观察一（差分）**：$[1, high] = [1, low-1] \uplus [low, high]$（不相交并）。约束 $low \ge 1$ 保证 $low - 1 \ge 0$；$f$ 的定义域是 $[1, n]$，故 $f(0) = 0$（数字 0 自身那一个 0 永远不被计入）。

![观察二：按位贡献与三段切分](images/bw1_q4_position_contribution.svg)

**观察二（按位贡献）**：一次「$d$ 的出现」总发生在某个具体数 $x$ 的某个具体位（位权 $w \in \{1, 10, 100, \cdots\}$）上，因此

$$f(n) = \sum_{w \le n} \#\{\,x \in [1, n] :\ x\ \text{在位权}\ w\ \text{处的数字为}\ d\,\}$$

各位互不重叠（每个「出现」唯一对应一个 $(x, w)$ 对）、又覆盖全部出现——**不重不漏**。$w > n$ 时该位在 $[1, n]$ 中根本不存在，求和只需 $O(\log_{10} n)$ 项。

对固定的 $w$，把 $n$ 按 $w$ 切成三段（$H = \lfloor n / 10w \rfloor$、$c = \lfloor n/w \rfloor \bmod 10$、$L = n \bmod w$），则第 $w$ 位等于 $d$ 的数形如 $x = a \cdot 10w + d \cdot w + b$，$a \ge 0$、$0 \le b < w$：

- **$d \ge 1$**（此时 $x \ge w \ge 1$，只需 $x \le n$）：
  - $a < H$：$H$ 种 $a$、$w$ 种 $b$，且 $x < H \cdot 10w \le n$ 恒成立 → $H \cdot w$ 个；
  - $a = H$：比较 $d \cdot w + b \le c \cdot w + L$：$d < c$ 时 $w$ 个；$d = c$ 时 $L + 1$ 个；$d > c$ 时 0 个。
  - 合并三情：$c > d \Rightarrow (H+1)w$；$c = d \Rightarrow Hw + L + 1$；$c < d \Rightarrow Hw$。
- **$d = 0$**（额外要求该位**真实存在**，即 $x \ge w$，等价于 $a \ge 1$，防前导零）：
  - $a \in [1, H-1]$：$(H-1) \cdot w$ 个；
  - $a = H$：$c \ge 1$ 时 $w$ 个；$c = 0$ 时 $L + 1$ 个。
  - 合并：$c > 0 \Rightarrow Hw$；$c = 0 \Rightarrow (H-1)w + L + 1$（循环内 $w \le n$ 且 $c = 0$ 时必有 $H \ge 1$，见 §5 引理 4，$(H-1)$ 不会为负）。

> ⚠️ $d=0$ 若照搬 $d \ge 1$ 的公式会引入大量**前导零**计数。反例 $n = 13$ 的十位：$H=0, c=1$，正确答案是 0（1..9 没有十位），照搬公式会数出 $(H+1)w = 10$。

### 3.3 算法流程

```text
countUpTo(d, n):                          # f(n) = [1, n] 中 d 的出现次数
    若 n <= 0: 返回 0
    ans = 0
    w = 1                                 # 位权：1, 10, 100, …（w <= n 才迭代）
    while w <= n:
        H = n / (w*10)                    # 高段
        c = (n / w) % 10                  # 当前位数字
        L = n % w                         # 低段
        若 d == 0:                        # 防前导零：要求该位真实存在
            c > 0 ? ans += H * w
            否则   ans += (H-1) * w + L + 1
        否则:
            c > d ? ans += (H+1) * w
            c == d ? ans += H * w + L + 1
            c < d ? ans += H * w
        w *= 10
    返回 ans

digitsCount(d, low, high) = countUpTo(d, high) - countUpTo(d, low - 1)
```

### 3.4 示例演算

![示例演算：d=3 的两张按位统计表](images/bw1_q4_example_walkthrough.svg)

对示例 2（$d = 3$，$[100, 250]$）：

| $w$ | $H$ | $c$ | $L$ | 判定 | 个数 |
|----|----|----|----|------|------|
| 1 | 25 | 0 | 0 | $c < d \Rightarrow H \cdot w$ | 25 |
| 10 | 2 | 5 | 0 | $c > d \Rightarrow (H+1) \cdot w$ | 30 |
| 100 | 0 | 2 | 50 | $c < d \Rightarrow H \cdot w$ | 0 |

$f(250) = 25 + 30 + 0 = 55$；同理 $f(99) = 10 + 10 = 20$；答案 $= 55 - 20 = 35$。

对示例 1（$d = 1$，$[1, 13]$）：$f(13)$ 的 $w=1$ 位 $c = 3 > 1$ 给 $(1+1) \times 1 = 2$（数 1 与 11），$w=10$ 位 $c = 1 = d$ 给 $0 \times 10 + 3 + 1 = 4$（数 10、11、12、13），$f(13) = 6$；$low - 1 = 0$，$f(0) = 0$，答案 6。

对自造示例 3（$d = 0$，$[1, 100]$）：$f(100)$ 中 $w=1$ 位 $c = 0$ 给 $(10-1) \times 1 + 0 + 1 = 10$（10、20、…、100），$w=10$ 位 $c = 0$ 给 $(1-1) \times 10 + 0 + 1 = 1$（只有 100 有十位且为 0），$w=100$ 位 $c = 1 > 0$ 给 $0$；合计 $f(100) = 11$ ✓。

## 4. 算法细节

1. **$(x, w)$ 二元组视角**：把「出现」拆成「(数, 位) 对」是按位计数正确性的根——同一位不会被数两次，任何出现也不会被漏掉。
2. **三段切分别记反**：$H = \lfloor n / 10w \rfloor$ 是高段（含当前位以上的全部），$c = \lfloor n/w \rfloor \bmod 10$ 是当前位数字，$L = n \bmod w$ 是低段。
3. **$d = 0$ 的存在性条件**：第 $w$ 位真实存在 $\iff x \ge w$；在 $x = a \cdot 10w + b$ 的写法下即 $a \ge 1$。这就是两个公式分支差一的来源。
4. **循环条件必须是 $w \le n$**：$c = 0$ 分支含 $(H-1)$，只在 $w \le n$ 时才保证 $H \ge 1$；若写成 `w <= n*10` 或 `while (w)`，$w > n$ 的位会出现 $H = 0$、负贡献。
5. **溢出**：$n \le 2 \times 10^8$ 时 $w$ 最大 $10^8$，$w \cdot 10 = 10^9$ 贴着 32 位 int 上限（$\approx 2.1 \times 10^9$）——C++ 实现里位权与乘积统一用 `long long` 最稳。
6. **另一种等价实现**：记忆化数位 DP（状态：位指针 + 是否贴上界 + 是否已经开始 + 当前计数）更通用；按位公式是它在「统计出现次数」场景下的闭合形式，更短更快。

## 5. 正确性证明

**引理 1（差分）**：设 $f(n)$ 为 $[1, n]$ 中 $d$ 的出现总次数（$n \ge 0$，$f(0) = 0$）。则 $[low, high]$（$1 \le low \le high$）中 $d$ 的出现次数为 $f(high) - f(low-1)$。

**证明**：$[1, high]$ 是不相交集合 $[1, low-1]$ 与 $[low, high]$ 的并。出现次数是「对 (数, 位置) 对的计数」，对不相交的数字集合严格可加，故 $f(high) = f(low-1) + \#\{\text{在 } [low, high] \text{ 中的出现}\}$。∎

**引理 2（按位分解）**：$f(n) = \sum_{w \in \{1, 10, 100, \cdots\},\, w \le n} C(w)$，其中 $C(w) = \#\{x \in [1, n] : x\ \text{在位权 } w\ \text{处的数字为 } d\}$。

**证明**：$x$ 的十进制写法中位权 $w$ 处存在数字当且仅当 $w \le x$。每次「出现」唯一对应有序对 $(x, w)$：数 $x$、其位权 $w$ 处那一位恰为 $d$；反之每个满足条件的 $(x, w)$ 对应一次出现。故 $f(n) = \#\{(x, w) : 1 \le x \le n,\ w \le x,\ x \text{ 的 } w \text{ 位} = d\}$。按 $w$ 分组求和，$w > n$ 的分组为空（$w \le x \le n$ 不可能），组大小即 $C(w)$。∎

**引理 3（$d \ge 1$ 的计数公式）**：写 $n = H \cdot (10w) + c \cdot w + L$，其中 $H \ge 0$、$c \in [0, 9]$、$0 \le L < w$。对 $d \in [1, 9]$：$C(w) = (H+1)w$ 若 $c > d$；$Hw + L + 1$ 若 $c = d$；$Hw$ 若 $c < d$。

**证明**：$x$ 的 $w$ 位为 $d$ $\iff$ $x = a \cdot 10w + d \cdot w + b$，$a \ge 0$、$0 \le b < w$。因 $d \ge 1$，$x \ge d \cdot w \ge w \ge 1$，故 $x \in [1, n] \iff x \le n$。逐类计数：
- $0 \le a \le H - 1$：$x \le (H-1) \cdot 10w + d \cdot w + (w-1) < H \cdot 10w \le n$，全部合法，共 $H \cdot w$ 个；
- $a = H$：$x \le n \iff d \cdot w + b \le c \cdot w + L$。若 $d < c$：$d \cdot w + b < (d+1) \cdot w \le c \cdot w \le c \cdot w + L$ 恒真，$w$ 个；若 $d = c$：$b \le L$，$L + 1$ 个；若 $d > c$：$d \cdot w + b \ge d \cdot w > c \cdot w + L$（因 $b \ge 0$、$d > c$），0 个。
合并即得三情。∎

**引理 4（$d = 0$ 的计数公式）**：对 $d = 0$：$C(w) = Hw$ 若 $c > 0$；$(H-1)w + L + 1$ 若 $c = 0$。且在 $w \le n$ 的前提下，$c = 0$ 蕴含 $H \ge 1$。

**证明**：$x$ 的 $w$ 位为 0 且该位**真实存在** $\iff$ $x = a \cdot 10w + b$，$a \ge 1$、$0 \le b < w$（$a = 0$ 时 $x = b < w$，没有 $w$ 位）。计数：
- $1 \le a \le H - 1$：$x < H \cdot 10w \le n$ 全部合法，$(H-1) \cdot w$ 个（$H \le 1$ 时为空集）；
- $a = H$：$x \le n \iff b \le c \cdot w + L$。$c \ge 1$ 时 $b < w \le c \cdot w$ 恒真，$w$ 个；$c = 0$ 时 $b \le L$，$L + 1$ 个。
合并：$c \ge 1 \Rightarrow (H-1)w + w = Hw$（$H = 0$ 时两段皆空，公式给 0，一致）；$c = 0 \Rightarrow (H-1)w + L + 1$。
蕴含关系：若 $H = 0$ 且 $w \le n$，则 $w \le n < 10w$，故 $\lfloor n/w \rfloor \in [1, 9]$，$c = \lfloor n/w \rfloor \bmod 10 = \lfloor n/w \rfloor \ge 1$。逆否即 $c = 0 \Rightarrow H \ge 1$，从而 $(H-1) \ge 0$，公式恒非负。∎

**定理**：算法返回 $[low, high]$ 中数字 $d$ 的出现总次数。

**证明**：`countUpTo(d, n)` 对每个满足 $w \le n$ 的位权累加引理 3 / 引理 4 给出的 $C(w)$；由引理 2，其总和恰为 $f(n)$（$n \le 0$ 时按定义返回 $f(0) = 0$）。再由引理 1，$f(high) - f(low-1)$ 即为所求。∎

## 6. 复杂度分析

- **时间**：`countUpTo` 只枚举 $w \le n$ 的位权，每位 $O(1)$，共 $O(\log_{10} n)$；调用两次，总时间 $O(\log high)$。$high = 2 \times 10^8$ 时只有 9 位、两次调用合计约 18 项计算。
- **空间**：$O(1)$，只使用常数个变量。

## 7. 参考代码

### C++

```cpp
class Solution {
    // f(n)：[1, n] 中数字 d 的出现次数（按位贡献求和），f(0) = 0
    long long countUpTo(int d, long long n) {
        if (n <= 0) return 0;
        long long ans = 0;
        for (long long w = 1; w <= n; w *= 10) {     // w = 1, 10, 100, ...（位权）
            long long high = n / (w * 10);           // 高位部分
            int cur = (int)(n / w) % 10;             // 当前位数字
            long long low = n % w;                   // 低位部分
            if (d == 0) {
                // 第 w 位为 0 且该位真实存在（高位 >= 1，防前导零）
                if (cur > 0) ans += high * w;
                else ans += (high - 1) * w + low + 1;  // 循环内 cur==0 必有 high>=1
            } else {
                if (cur > d) ans += (high + 1) * w;
                else if (cur == d) ans += high * w + low + 1;
                else ans += high * w;
            }
        }
        return ans;
    }

public:
    int digitsCount(int d, int low, int high) {
        return (int)(countUpTo(d, high) - countUpTo(d, low - 1));
    }
};
```

### Python

```python
class Solution:
    def countUpTo(self, d: int, n: int) -> int:
        """f(n)：[1, n] 中数字 d 的出现次数（按位贡献求和），f(0) = 0"""
        if n <= 0:
            return 0
        ans = 0
        w = 1                              # w = 1, 10, 100, ...（位权）
        while w <= n:
            high = n // (w * 10)           # 高位部分
            cur = (n // w) % 10            # 当前位数字
            low = n % w                    # 低位部分
            if d == 0:
                # 第 w 位为 0 且该位真实存在（高位 >= 1，防前导零）
                if cur > 0:
                    ans += high * w
                else:
                    ans += (high - 1) * w + low + 1  # 循环内 cur==0 必有 high>=1
            else:
                if cur > d:
                    ans += (high + 1) * w
                elif cur == d:
                    ans += high * w + low + 1
                else:
                    ans += high * w
            w *= 10
        return ans

    def digitsCount(self, d: int, low: int, high: int) -> int:
        return self.countUpTo(d, high) - self.countUpTo(d, low - 1)
```

## 8. 边界情况与易错点

1. **$d = 0$ 的前导零是最大坑**：数 $x$ 的第 $w$ 位存在 $\iff x \ge w$。反例 $n = 13$、$w = 10$：正确答案 0（1..9 没有十位），照搬 $d \ge 1$ 的公式会得到 $(H+1)w = 10$。
2. **$c = 0$ 分支的 $(H-1)$ 依赖循环条件**：$w \le n$ 保证 $c = 0 \Rightarrow H \ge 1$；循环写成 `while (w)` 或 `w <= n * 10` 会在 $w > n$ 时产生 $H = 0$ 的负贡献。
3. **$low = 1$**：$f(0) = 0$，别把数字 0 自身的一个 0 计进去（$f$ 的定义域是 $[1, n]$）。
4. **同一数多处出现计多次**：示例 1 的 11 含两个 1——$(x, w)$ 视角天然处理了这一点，勿在数级去重。
5. **比较方向**：$c > d$ 是 $(H+1) \cdot w$（高位可取遍 $[0, H]$），$c < d$ 是 $H \cdot w$，写反会大面积出错。
6. **溢出**：$w \cdot 10$ 最大 $10^9$，贴着 int 上限；C++ 用 `long long`（本篇代码即如此）。
7. **务必对拍**：在 $d = 0..9$、$n \le$ 数百的范围与 $O(n \cdot \text{位数})$ 暴力逐一对照（本篇代码已对 $n \le 400$ 穷举 + 大数随机窗口对拍通过）。
