# LeetCode 字符串的索引对 题解

## 1. 题目概述

- **标题 / 题号**：字符串的索引对（#1065，easy）
- **链接**：https://leetcode.cn/problems/index-pairs-of-a-string/
- **来源**：LeetCode 第 1 场双周赛 Q2
- **难度**：简单
- **标签**：字典树、字符串、排序

**题意**：给定文本串 `text` 与单词表 `words`（单词互异），找出**所有**下标对 $[i, j]$，使得闭区间子串 $text[i..j]$ 出现在 `words` 中。返回结果需按 $i$ 升序、$i$ 相同时按 $j$ 升序排列。子串匹配**可以重叠**。

**约束**：

- 所有字符串只含小写英文字母
- $1 \le text.length \le 100$
- $1 \le words.length \le 20$
- $1 \le words[i].length \le 50$

## 2. 示例

**示例 1**

```text
输入：text = "thestoryofleetcodeandme", words = ["story","fleet","leetcode"]
输出：[[3,7],[9,13],[10,17]]
解释：story 命中 [3,7]，fleet 命中 [9,13]，leetcode 命中 [10,17]。
```

**示例 2**

```text
输入：text = "ababa", words = ["aba","ab"]
输出：[[0,1],[0,2],[2,3],[2,4]]
解释：匹配可以重叠——"aba" 同时命中 [0,2] 与 [2,4]，两者都要输出。
```

## 3. 解题思路

### 3.1 暴力思路

两重循环枚举全部 $O(n^2)$ 个子串 $text[i..j]$，每个子串查一次哈希集合（构造子串与计算哈希需扫过其全部字符）。$n \le 100$ 时子串只有约 5000 个、总字符量约 $10^5$，完全能过；但它把大量「第一个字符就对不上」的子串也完整构造了一遍。更优的组织方式是把多个单词**合并成一棵 Trie**：一次下探同时判定所有单词的公共前缀。

### 3.2 核心观察：Trie 上的一次下探 = 同时测试所有单词

![多模式匹配：words 建 Trie，起点 i 沿树下探](images/bw1_q2_trie_scan_model.svg)

把 `words` 建成 **Trie（前缀树）**，并在每个单词结尾节点打 `isEnd` 标记。随后枚举起点 $i$，从根出发沿 $text[i], text[i+1], \cdots$ 逐字符下探：

- 每走到一个 `isEnd` 节点，说明 $text[i..j]$ 是单词，记录 $[i, j]$；
- 一旦当前节点没有 $text[j]$ 的子节点就**失配剪枝**：$text[i..j]$ 已不是任何单词的前缀，更长的 $text[i..j']$ 更不可能是（前缀的前缀仍是前缀）。

三大收益：

1. **共享前缀只走一遍**：`fleet` 与 `leetcode` 等单词从起点处就被 Trie 分流，不必各自独立比对；
2. **输出顺序免费**：外层 $i$ 升序、内层 $j$ 升序，记录序列天然就是题目要求的字典序，**无需排序**；
3. **剪枝限深**：每个起点至多走 $\min(\text{剩余长度},\ \text{Trie 深度})$ 步，深度 $\le \max |words[k]|$。

### 3.3 算法流程

![算法流程：建 Trie → 双层枚举，失配即剪枝](images/bw1_q2_algorithm_flow.svg)

```text
1. root ← 空 Trie
2. for w in words:                      # 建 Trie，结尾打 isEnd
       逐字符插入 w
3. ans ← 空列表
4. for i = 0 .. n-1:                    # 起点升序
       cur ← root
       for j = i .. n-1:                # 终点升序
           若 cur 无 text[j] 子节点: break      # 失配剪枝
           cur ← cur 的 text[j] 子节点
           若 cur.isEnd: ans 追加 [i, j]        # 记录后继续下探
5. 返回 ans                              # 天然有序
```

### 3.4 示例演算

![示例演算：thestoryofleetcodeandme 的三处命中](images/bw1_q2_example_walkthrough.svg)

对示例 1，`text = "thestoryofleetcodeandme"`（23 个字符）：

| 单词 | 命中区间 | 说明 |
|------|----------|------|
| story | [3,7] | $text[3..7]$ = "story" |
| fleet | [9,13] | $text[9..13]$ = "fleet" |
| leetcode | [10,17] | $text[10..17]$ = "leetcode"，与 fleet **共享 10–13 段** |

按 $(i, j)$ 字典序输出 `[[3,7],[9,13],[10,17]]`。示例 2 更能体现「重叠」：`"ababa"` 上 `"ab"` 命中 [0,1] 与 [2,3]，`"aba"` 命中 [0,2] 与 [2,4]，同一个 `a` 同时充当两次匹配的结尾与开头，四对缺一不可。

## 4. 算法细节

1. **Trie 节点**：C++ 用 26 叉指针数组 + `isEnd` 布尔；Python 用嵌套 `dict` + 哨兵键 `"$"`，省去 26 叉数组。
2. **失配剪枝的依据是前缀封闭性**：见 5. 引理 2——这正是 Trie 能剪枝而哈希集合不能的原因（哈希必须把子串造完整才能查）。
3. **记录后继续下探**：`isEnd` 标记与子节点并存（`"ab"` 是 `"aba"` 的前缀），命中短单词后必须继续走，否则漏掉更长的。
4. **顺序即正确性**：题目要求按 $(i, j)$ 排序，而两层循环的枚举顺序与之完全一致，省掉一次显式 `sort`。
5. **单词互异**是题目保证：同一结尾节点至多对应一个单词；即便重复插入，Trie 与结果也幂等。

## 5. 正确性证明

**引理 1（Trie 判定等价）**：从根沿 $text[i..j]$ 的字符依次下探能到达节点 $v$ $\iff$ $text[i..j]$ 是某个单词的前缀；且此时 $v.isEnd$ 为真 $\iff$ $text[i..j] \in words$。

**证明**：单词 $w$ 插入时，沿 $w$ 的每个字符建边，并在 $w$ 对应的终点节点打 `isEnd`。对 $j - i + 1$ 归纳：长度 0（根）时「空串是每个单词的前缀」成立；设长度 $k$ 的结论成立，则长度 $k+1$ 的串能下探 $\iff$ 长度 $k$ 的前缀能下探且下一字符对应的子边存在 $\iff$ 它是某单词长度 $k+1$ 的前缀。`isEnd` 恰在「该节点对应一个完整单词」时被打上标记，且互异单词的节点互不相同。∎

**引理 2（剪枝安全性）**：若在字符 $text[j]$ 处失配，则对一切 $j' \ge j$，$text[i..j']$ 不是任何单词的前缀。

**证明**：反设 $text[i..j']$ 是某单词 $w$ 的前缀且 $j' \ge j$。则 $text[i..j]$ 是 $text[i..j']$ 的前缀，因而也是 $w$ 的前缀，由引理 1，Trie 中应存在沿 $text[i..j]$ 的路径，与失配矛盾。∎

**定理（不重不漏 + 有序）**：算法输出恰为全部合法下标对，且按 $(i, j)$ 字典序排列。

**证明**：**不漏**：任取合法对 $(i, j)$，即 $text[i..j] \in words$。外层循环到 $i$ 时，对每个 $i \le j'' < j$，$text[i..j'']$ 是 $text[i..j]$（某单词）的前缀，由引理 2 的逆否命题，下探不会提前 `break`，故内层必然依次走到 $j$，并由引理 1 记录 $[i, j]$。**不重**：每对 $(i, j)$ 只在外层 $i$ 的内层 $j$ 处被检查一次，至多记录一次。**有序**：外层 $i$ 严格递增，同一 $i$ 内 $j$ 严格递增，记录序列按 $(i, j)$ 字典序。∎

## 6. 复杂度分析

- **时间**：建 Trie 为 $O(\sum_k |words[k]|) \le 20 \times 50 = 1000$；匹配阶段每个起点至多下探 $\min(n - i, D)$ 步（$D$ 为 Trie 深度 $\le 50$），总计 $O(n \cdot \max |w|) \le 100 \times 50 = 5000$。整体 $O\!\left(\sum_k |words[k]| + n \cdot \max_k |words[k]|\right)$。
- **空间**：Trie 至多 $\sum_k |words[k]| + 1$ 个节点；C++ 26 叉数组 $O(26 \sum |w|)$，Python 嵌套 dict $O(\sum |w|)$。输出不计。

## 7. 参考代码

### C++

```cpp
class Solution {
    struct Node {
        Node* next[26];
        bool isEnd;
        Node() : isEnd(false) {
            for (int i = 0; i < 26; i++) next[i] = nullptr;
        }
    };

public:
    vector<vector<int>> indexPairs(string text, vector<string>& words) {
        Node* root = new Node();
        for (const string& w : words) {              // 1. 所有单词插入 Trie
            Node* cur = root;
            for (char c : w) {
                int k = c - 'a';
                if (!cur->next[k]) cur->next[k] = new Node();
                cur = cur->next[k];
            }
            cur->isEnd = true;                       // 单词结尾打标记
        }
        int n = (int)text.size();
        vector<vector<int>> ans;
        for (int i = 0; i < n; i++) {                // 2. 枚举起点 i（升序）
            Node* cur = root;
            for (int j = i; j < n; j++) {            // 3. 沿 Trie 逐字符下探（j 升序）
                int k = text[j] - 'a';
                if (!cur->next[k]) break;            // 失配：无单词拥有该前缀，剪枝
                cur = cur->next[k];
                if (cur->isEnd) ans.push_back({i, j});
            }
        }
        return ans;                                  // 4. (i, j) 双重升序，天然有序
    }
};
```

### Python

```python
class Solution:
    def indexPairs(self, text: str, words: list[str]) -> list[list[int]]:
        root = {}                          # 用嵌套 dict 表示 Trie
        END = "$"                          # 结尾哨兵键
        for w in words:                    # 1. 所有单词插入 Trie
            node = root
            for c in w:
                node = node.setdefault(c, {})
            node[END] = True               # 单词结尾打标记
        n = len(text)
        ans = []
        for i in range(n):                 # 2. 枚举起点 i（升序）
            node = root
            for j in range(i, n):          # 3. 沿 Trie 逐字符下探（j 升序）
                c = text[j]
                if c not in node:
                    break                  # 失配：无单词拥有该前缀，剪枝
                node = node[c]
                if END in node:
                    ans.append([i, j])
        return ans                         # 4. (i, j) 双重升序，天然有序
```

## 8. 边界情况与易错点

1. **闭区间 $[i, j]$**：$j$ 是下标不是长度，$text[i..j]$ 的长度是 $j - i + 1$；把 `[i, j]` 写成 `[i, j-i]` 或 `[i, j+1)` 是最常见的笔误。
2. **匹配可重叠**（示例 2 的 `"aba"` 命中 [0,2] 与 [2,4]）：不能用「匹配完跳到 $j+1$ 再找下一个」的单模式思路，每个起点独立下探才不漏。
3. **单词互为前缀**（`"ab"` 与 `"aba"`）：命中 `isEnd` 后**不能停**，要继续向子节点下探。
4. **输出必须有序**：枚举顺序天然有序；若改用哈希集合收集再输出，必须显式排序。
5. **单字符单词**：$j = i$ 时 $text[i..i]$ 就可能是单词，内层循环起点是 $i$ 本身。
6. **空结果**：没有任何命中时返回空数组（不是 `null`）。
