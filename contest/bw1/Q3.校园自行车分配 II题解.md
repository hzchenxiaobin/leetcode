# LeetCode 校园自行车分配 II 题解

## 1. 题目概述

- **标题 / 题号**：校园自行车分配 II（#1066，medium）
- **链接**：https://leetcode.cn/problems/campus-bikes-ii/
- **来源**：LeetCode 第 1 场双周赛 Q3
- **难度**：中等
- **标签**：位运算、动态规划、位掩码、回溯

**题意**：校园二维网格上有 $N$ 个工人和 $M$ 辆自行车（$N \le M$），坐标给定。给每个工人分配一辆**专属**的车（每个工人恰好一辆、每辆车至多一个主人），最小化「每个工人与其所分配车的**曼哈顿距离」之和**。两点间的曼哈顿距离为 $|x_1 - x_2| + |y_1 - y_2|$。返回最小可能的总距离。

**约束**：

- $0 \le workers[i][0], workers[i][1], bikes[i][0], bikes[i][1] < 1000$
- 所有工人与车的位置互不相同
- $1 \le workers.length \le bikes.length \le 10$

## 2. 示例

**示例 1**

```text
输入：workers = [[0,0],[2,1]], bikes = [[1,2],[3,3]]
输出：6
解释：w0→b0、w1→b1，两段距离都是 3，总和 6；
     交叉分配是 6+2 = 8，更差。
```

**示例 2**

```text
输入：workers = [[0,0],[1,1],[2,0]], bikes = [[1,0],[2,2],[2,1]]
输出：4
解释：w0→b0（距离 1）后，b1、b2 分给 w1、w2：w1→b1 + w2→b2 = 2+1，
     或 w1→b2 + w2→b1 = 1+2，总距离都是 4。
```

**示例 3**（官方测试用例之三）

```text
输入：workers = [[0,0],[1,0],[2,0],[3,0],[4,0]], bikes = [[0,999],[1,999],[2,999],[3,999],[4,999]]
输出：4995
解释：5 个工人在 y=0 一排、5 辆车在 y=999 正对着排：正对配对各距 999，
     总和 5 × 999 = 4995；任何交叉配对都会多出水平偏移，只会更贵。
```

## 3. 解题思路

### 3.1 暴力思路

本质是给 $N$ 个工人从 $M$ 辆车中挑一个**排列**：方案数 $A(M, N) \le 10! \approx 3.6 \times 10^6$，每个方案还需 $O(N)$ 累加距离，约 $3.6 \times 10^7$ 次运算——C++ 勉强能过、纯 Python 相当危险，而且完全没利用**重叠子问题**：两个方案若前 $k$ 个工人的选择一致，后半段的最优性只取决于「还剩哪些车」。本题实为**二分图最小权匹配**，通用多项式解法是匈牙利算法 / 最小费用流；但 $N, M \le 10$ 的规模给了更轻量的选择——**状态压缩 DP**。

### 3.2 核心观察：代价与顺序无关 → mask 足以编码状态

![核心观察：把「哪些车已被占用」压进一个整数](images/bw1_q3_bitmask_dp_model.svg)

两个观察把状态压到一维：

1. **代价与分配次序无关**：一组配对的总代价 $\sum_i \operatorname{dist}(w_i, b_{\pi(i)})$ 是有限和，与决策顺序无关。于是 **WLOG**（不失一般性）可规定工人按 $0, 1, \cdots, N-1$ 的下标顺序依次取车。
2. **「哪些车已用」唯一确定进度**：按此规范顺序，若已有 $k$ 辆车被占用，被服务的必是 $w_0, \cdots, w_{k-1}$，下一个待分配的就是 $w_k$。也就是说，$M$ 位的 **bitmask**（第 $j$ 位 = 车 $j$ 是否被占用）**同时编码了「剩什么车」和「轮到谁」**，工人维度被 $\operatorname{popcount}$ 免费表示。

定义 $dp[mask]$：把 $mask$ 中被占用的 $\lvert mask \rvert$ 辆车分配给工人 $w_0..w_{\lvert mask \rvert - 1}$ 的最小总距离。

### 3.3 状态转移

![算法流程：按 mask 升序递推，逐状态松弛](images/bw1_q3_algorithm_flow.svg)

$$dp[\,mask \cup \{j\}\,] \leftarrow \min\Big(dp[mask \cup \{j\}],\ \ dp[mask] + \operatorname{dist}(w_{\lvert mask \rvert},\, b_j)\Big),\qquad j \notin mask$$

- 初始 $dp[0] = 0$（无人无车），其余为 $+\infty$；
- $\lvert mask \rvert = N$ 时不再转移（工人已分完）；
- **枚举顺序**：$mask$ 从 $0$ 到 $2^M - 1$ 升序。转移目标 $mask \,|\, (1 \ll j)$ 严格大于 $mask$（把一个 0 位变 1 必然增大数值），所以处理任何状态时其全部前驱已就绪，升序枚举天然是拓扑序；
- **答案**：$\min\big\{ dp[mask] : \operatorname{popcount}(mask) = N \big\}$。

> ⚠️ $N < M$ 时最优解**未必用完全部的车**，必须在所有恰含 $N$ 个 1 的状态里取 min；只返回 $dp[2^M - 1]$（车全用尽）是本题最经典的 WA 点。

### 3.4 示例演算

![示例演算：按 |mask| 分层看 dp 的松弛](images/bw1_q3_dp_walkthrough.svg)

对示例 2，先算距离矩阵（$w_0$ 到 $b_0, b_1, b_2$ 分别距 $1, 4, 3$；$w_1$ 距 $1, 2, 1$；$w_2$ 距 $1, 2, 1$），再按 $\lvert mask \rvert$ 分层递推：

| 层 $\lvert mask \rvert$ | 各状态 dp 值 |
|---|---|
| 0 | $dp[000] = 0$（无人无车） |
| 1 | $dp[001]=1$（w0→b0），$dp[010]=4$，$dp[100]=3$ |
| 2 | $dp[011]=3$（w0→b0 + w1→b1），$dp[101]=2$（w0→b0 + w1→b2），$dp[110]=5$ |
| 3 | $dp[111] = \min(3+1,\ 2+2,\ 5+1) = 4$ |

收敛出两条等价最优方案：$w0{\to}b0 + w1{\to}b1 + w2{\to}b2$（$1+2+1$）或 $w0{\to}b0 + w1{\to}b2 + w2{\to}b1$（$1+1+2$），总距离均为 $4$，与题面一致。图中的灰虚线是被更小值压掉的松弛，如 $dp[010] + 1 = 5 > 3$ 未能改善 $dp[011]$。

## 4. 算法细节

1. **转移方向**：从 $mask$ 出发，对每个空闲位 $j$ 松弛 $mask \,|\, (1 \ll j)$；判断空闲用 `mask >> j & 1 == 0`。
2. **popcount 即工人下标**：`i = popcount(mask)`；C++ 用 `__builtin_popcount`，Python 用 `bin(mask).count("1")`（3.10+ 可用 `int.bit_count`）。
3. **不可达状态**：初始化为 $\infty$，转移前跳过；$\lvert mask \rvert > N$ 的状态永远保持 $\infty$（转移在 $\lvert mask \rvert = N$ 处截止）。
4. **答案收集**：单开一个循环对 $\operatorname{popcount}(mask) = N$ 的状态取 min，天然兼容 $N = M$（此时满足条件的状态只有 $2^M - 1$ 一个）。
5. **数值范围**：单段距离 $\le 999 + 999 = 1998$，总代价 $\le 10 \times 1998 = 19980$，`int` 足够。
6. **等价写法**：显式二维 $dp[i][mask]$（$i$ 为工人下标）同样正确、更直观，只是多一维；$\operatorname{popcount}$ 技巧把这一维省掉了。

## 5. 正确性证明

**引理 1（顺序无关）**：分配方案（单射 $\pi: \{0..N-1\} \to \{0..M-1\}$）的代价 $\sum_{i=0}^{N-1} \operatorname{dist}(w_i, b_{\pi(i)})$ 与工人被服务的先后顺序无关。

**证明**：和式中每一项只依赖配对 $(i, \pi(i))$ 本身，有限和与求和顺序无关。∎

**引理 2（规范化）**：每个分配方案都可重放为「按工人下标 $0..N-1$ 依次取车」的决策序列，代价不变。

**证明**：把 $\pi$ 的取车动作按工人下标排序重放。$\pi$ 是单射，每辆车至多被取一次，重放序列中每一步所取的车都未被占用，故是合法序列；由引理 1 总代价不变。∎

**引理 3（状态充分性）**：规范化序列中，已占车集合 $mask$（大小 $k$）唯一确定：已服务的工人是 $w_0, \cdots, w_{k-1}$，下一个待分配的工人是 $w_k$。

**证明**：规范化序列第 $i$ 步（$i = 0, 1, 2, \cdots$）服务工人 $w_i$，前 $k$ 步恰服务 $w_0..w_{k-1}$ 并占用 $k$ 辆车；反之，大小为 $k$ 的 $mask$ 的任何规范化重放都由前 $k$ 步产生。于是「已用 $k$ 辆车」与「已服务前 $k$ 个工人」一一对应。∎

**定理 1（子结构归纳 / DP 最优性）**：对每个 $\lvert mask \rvert = k \le N$，$dp[mask]$ 等于「把 $mask$ 中的 $k$ 辆车恰好分配给 $w_0..w_{k-1}$」的最小总距离。

**证明**：对 $k$ 归纳。$k = 0$：$dp[0] = 0$ 即空方案，正确。设结论对 $k$ 成立，考虑 $\lvert mask \rvert = k + 1$ 的状态。任取「把 $mask$ 中 $k+1$ 辆车分给前 $k+1$ 个工人」的方案：工人 $w_k$ 分到某辆车 $j \in mask$，前 $k$ 个工人分到 $mask \setminus \{j\}$ 中的 $k$ 辆（$k$ 个工人单射入 $k$ 辆车即双射），故方案代价 = 前缀部分代价 $+\ \operatorname{dist}(w_k, b_j)\ \geq\ dp[mask \setminus \{j\}] + \operatorname{dist}(w_k, b_j)$（归纳假设）。对所有 $j$ 取下界，再用取到最小值的 $j^\ast$：由归纳假设存在前缀的最优方案，添上边 $(w_k, b_{j^\ast})$ 便构造出达到该值的可行方案。两个方向夹逼，得递推值恰为最优值。枚举顺序方面：$mask$ 的前驱 $mask \setminus \{j\}$ 数值更小、先被处理，递推次序合法。∎

**定理 2（算法正确）**：算法输出全局最小总距离。

**证明**：最优方案存在（方案数有限），设其占用车辆集合为 $T$（$\lvert T \rvert = N$）。由引理 2，它的代价等于某个「恰好使用 $T$ 中车辆」的规范化决策序列的代价，故由定理 1 有 $dp[T] \le$ 全局最优值。另一方面，每个 $dp[mask]$（$\lvert mask \rvert = N$）都对应一个把 $mask$ 中 $N$ 辆车分给全部工人的可行方案，故 $dp[mask] \geq$ 全局最优值。在 $\operatorname{popcount}(mask) = N$ 的状态上取 min，两侧夹逼即得答案 $=$ 全局最优。∎

## 6. 复杂度分析

- **时间**：状态数 $2^M \le 1024$，每状态至多 $M \le 10$ 次松弛，共 $O(M \cdot 2^M) \approx 10^4$；答案收集再 $O(2^M)$。相比暴力的 $O(N \cdot A(M, N)) \sim 3 \times 10^7$ 干净利落。
- **空间**：$O(2^M)$ 的 dp 数组，本题约 1024 个整数。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int assignBikes(vector<vector<int>>& workers, vector<vector<int>>& bikes) {
        int n = (int)workers.size(), m = (int)bikes.size();
        const int INF = 1e9;
        vector<int> dp(1 << m, INF);
        dp[0] = 0;                                   // 没人没车：代价 0
        for (int mask = 0; mask < (1 << m); mask++) {
            if (dp[mask] == INF) continue;           // 不可达状态（如 |mask| > n）
            int i = __builtin_popcount(mask);        // 已分配工人数 = 下一个工人下标
            if (i == n) continue;                    // 工人全部分配完毕
            for (int j = 0; j < m; j++) {
                if (mask >> j & 1) continue;         // 车 j 已被占用
                int cost = abs(workers[i][0] - bikes[j][0])
                         + abs(workers[i][1] - bikes[j][1]);
                int nmask = mask | (1 << j);
                dp[nmask] = min(dp[nmask], dp[mask] + cost);
            }
        }
        int ans = INF;
        for (int mask = 0; mask < (1 << m); mask++)  // 在所有「恰好 n 辆车」的状态取 min
            if (__builtin_popcount(mask) == n) ans = min(ans, dp[mask]);
        return ans;
    }
};
```

### Python

```python
class Solution:
    def assignBikes(self, workers: list[list[int]], bikes: list[list[int]]) -> int:
        n, m = len(workers), len(bikes)
        INF = float("inf")
        dp = [INF] * (1 << m)
        dp[0] = 0                         # 没人没车：代价 0
        for mask in range(1 << m):
            if dp[mask] == INF:            # 不可达状态（如 |mask| > n）
                continue
            i = bin(mask).count("1")       # 已分配工人数 = 下一个工人下标
            if i == n:                     # 工人全部分配完毕
                continue
            for j in range(m):
                if mask >> j & 1:          # 车 j 已被占用
                    continue
                cost = (abs(workers[i][0] - bikes[j][0])
                        + abs(workers[i][1] - bikes[j][1]))
                nm = mask | (1 << j)
                if dp[mask] + cost < dp[nm]:
                    dp[nm] = dp[mask] + cost
        return min(dp[mask] for mask in range(1 << m)
                   if bin(mask).count("1") == n)
```

## 8. 边界情况与易错点

1. **N < M 时别只取 $dp[2^M-1]$**：最优方案只占 $N$ 辆车，答案要在所有 $\operatorname{popcount}(mask) = N$ 的状态上取 min（本篇代码与流程图都单独收集答案）。
2. **跳过 $\infty$ 状态**：不检查 `dp[mask] == INF` 会把垃圾值松弛进后继状态。
3. **popcount 对应关系别写反**：是「已用 $k$ 辆车 ⇒ 已服务 $w_0..w_{k-1}$ ⇒ 下一个工人 $w_k$」。
4. **转移只能加位**：$j \notin mask$ 才能转移，`mask | (1<<j)` 不会覆盖已有位。
5. **升序枚举是拓扑序的前提**：依赖「加位必增大」这一数值事实；乱序实现需改记忆化搜索。
6. **N == M 是特例**：所有车都必须用上，答案退化为 $dp[2^M - 1]$，但统一写法无需特判。
7. **答案上界** $\le 10 \times 1998 = 19980$：`int` 安全；若坐标放宽到 $10^9$ 级别需换 `long long`。
