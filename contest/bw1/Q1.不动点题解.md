# LeetCode 不动点 题解

## 1. 题目概述

- **标题 / 题号**：不动点（#1064，easy）
- **链接**：https://leetcode.cn/problems/fixed-point/
- **来源**：LeetCode 第 1 场双周赛 Q1
- **难度**：简单
- **标签**：数组、二分查找

**题意**：给定一个由**互不相同**的整数组成、按**严格递增**排序的数组 `arr`，返回满足 $arr[i] = i$ 的**最小**下标 $i$；若不存在这样的下标，返回 $-1$。满足 $arr[i] = i$ 的位置称为**不动点**。

**约束**：

- $1 \le arr.length < 10^4$
- $-10^9 \le arr[i] \le 10^9$
- `arr` 中的整数严格递增且互不相同

## 2. 示例

**示例 1**

```text
输入：arr = [-10,-5,0,3,7]
输出：3
解释：arr[0] = -10，arr[1] = -5，arr[2] = 0，arr[3] = 3，
     下标 3 是最小的满足 arr[i] == i 的位置。
```

**示例 2**

```text
输入：arr = [0,2,5,8,17]
输出：0
解释：arr[0] = 0，下标 0 即为答案。
```

**示例 3**

```text
输入：arr = [-10,-5,3,4,7,9]
输出：-1
解释：不存在 arr[i] == i 的下标。
```

## 3. 解题思路

### 3.1 暴力思路

从左到右顺序扫描，遇到第一个 $arr[i] = i$ 就返回，$O(n)$ 时间、$O(1)$ 空间，在 $n < 10^4$ 的范围下轻松通过。但题面特意强调「严格递增**且互异**」，这强烈暗示存在 $O(\log n)$ 做法：把**值域上的有序**转化为**下标上的判定单调**，再二分。这正是这道理应沉淀的思维模板。

### 3.2 核心观察：f(i) = arr[i] − i 单调不减 → 二分左端点

![核心观察：f(i)=arr[i]−i 单调不减，不动点落在后缀里](images/bw1_q1_binary_search_model.svg)

定义 $f(i) = arr[i] - i$。因为元素互异且严格递增，相邻两个整数至少相差 1：$arr[i+1] \ge arr[i] + 1$，于是

$$f(i+1) = arr[i+1] - (i+1) \ge (arr[i] + 1) - (i+1) = arr[i] - i = f(i)$$

即 $f$ **单调不减**，而**不动点恰好是 $f(i) = 0$ 的位置**。于是 $\{i : f(i) \ge 0\}$ 是一段后缀，二分找它的**左端点** $i^\ast$：

- 若 $arr[i^\ast] = i^\ast$（即 $f(i^\ast) = 0$），则 $i^\ast$ 就是最小不动点；
- 若 $arr[i^\ast] > i^\ast$（即 $f(i^\ast) > 0$），则由单调性，其后 $f$ 只增不减，**全数组无不动点**，返回 $-1$。

> ⚠️ 「互异」是二分成立的前提：若只保证非降（允许重复），$f$ 不再单调。反例 `arr = [0,0,2]`：$f = [0,-1,0]$，$\{f \ge 0\}$ 不是后缀，二分会漏掉最小不动点 $i = 0$。

### 3.3 算法流程

![算法流程：二分找 f≥0 的最左位置，循环外做最终判等](images/bw1_q1_algorithm_flow.svg)

```text
1. lo = 0, hi = n - 1, pos = -1
2. while lo <= hi:
3.     mid = lo + (hi - lo) / 2
4.     若 arr[mid] - mid >= 0:     # f(mid) >= 0，后缀左端点在 mid 或其左侧
5.         pos = mid               # 记录候选，继续向左压缩
6.         hi = mid - 1
7.     否则:                       # f(mid) < 0，不动点只可能在 mid 右侧
8.         lo = mid + 1
9. 若 pos != -1 且 arr[pos] == pos: 返回 pos
10. 否则返回 -1
```

### 3.4 示例演算

![示例演算：三组官方示例的 f 值与二分落点](images/bw1_q1_example_walkthrough.svg)

| arr | $f = arr[i]-i$ | 最左 $f \ge 0$ 的位置 | 该处判定 | 输出 |
|-----|----------------|----------------------|----------|------|
| [-10,-5,0,3,7] | [-10,-6,-2,0,4] | 3 | $arr[3]=3$ ✓ | 3 |
| [0,2,5,8,17] | [0,1,3,5,13] | 0 | $arr[0]=0$ ✓ | 0 |
| [-10,-5,3,4,7,9] | [-10,-6,1,1,3,4] | 2 | $arr[2]=3 \ne 2$，且 $f(2)=1>0$ | -1 |

第三行是最容易翻车的情形：最左的 $f \ge 0$ 位置是 2，但 $f(2) = 1 > 0$，此后 $f$ 只增不减，全数组必然无解——这正是「二分后必须再做一次判等」的原因。

## 4. 算法细节

1. **二分模板**：标准「找满足条件的最左位置」模板——命中时不立即返回，而是记录 `pos` 并把 `hi` 压到 `mid - 1`，继续向左探索。
2. **判等放在二分之外**：二分只负责定位 $\{f \ge 0\}$ 的左端点；`arr[pos] == pos` 的最终判等在循环结束后做一次。
3. **为什么不能直接对 `arr[i]==i` 二分**：谓词 $arr[i] = i$ 本身不满足二分单调性，真正单调的是 $arr[i] - i \ge 0$ 这个判定（$f$ 单调 ⇒ 谓词呈 `假…假 真…真` 布局）。
4. **为什么不用 `lower_bound`**：目标是「最小的 $i$ 使 $arr[i] \ge i$」，阈值随下标变化，不是对固定值的查找，标准库接口套不上，手写二分最直接。
5. **数值范围**：$|arr[i] - i| \le 10^9 + 10^4$，`int` 足够；`mid = lo + (hi - lo) / 2` 是防溢出的好习惯（本题其实不会溢出）。

## 5. 正确性证明

**引理 1（单调性）**：若 `arr` 严格递增且元素互异，则 $f(i) = arr[i] - i$ 单调不减。

**证明**：对任意 $i$，由严格递增与整数性质得 $arr[i+1] \ge arr[i] + 1$（互异整数相邻至少差 1）。于是 $f(i+1) = arr[i+1] - (i+1) \ge arr[i] + 1 - i - 1 = f(i)$。∎

**引理 2（结构）**：记 $S_0 = \{i : f(i) = 0\}$（不动点集合），$S_+ = \{i : f(i) \ge 0\}$。则 $S_+$ 是一段后缀；若 $S_0 \ne \varnothing$，则 $\min S_0 = \min S_+$。

**证明**：由引理 1，$f$ 的取值呈「负……负 | 非负……非负」布局，故 $S_+$ 是后缀 $[i^\ast, n)$（或空集）。设 $S_0 \ne \varnothing$，取 $j = \min S_0$。由 $f(j) = 0 \ge 0$ 知 $j \in S_+$，故 $j \ge i^\ast$。若 $j > i^\ast$，则由单调性 $0 \le f(i^\ast) \le f(j) = 0$，得 $f(i^\ast) = 0$，即 $i^\ast \in S_0$，与 $j$ 的最小性矛盾（$i^\ast < j$）。故 $j = i^\ast$。∎

**定理**：算法返回 `arr` 的最小不动点；若不存在则返回 $-1$。

**证明**：二分循环维护不变量「若 $S_+ \ne \varnothing$，则 $\min S_+$ 始终落在 $[lo, hi] \cup \{pos\}$ 内」：初始 $[lo,hi] = [0, n-1]$ 成立；当 $f(mid) \ge 0$ 时 $mid \in S_+$ 且 $S_+$ 是后缀，故 $\min S_+ \le mid$，记录 `pos = mid` 并舍弃右侧安全；当 $f(mid) < 0$ 时 $mid \notin S_+$ 且 $S_+$ 是后缀，故 $\min S_+ > mid$，舍弃左侧安全。循环结束时 `pos` 即 $\min S_+$（若 $S_+ = \varnothing$ 则 `pos = -1`）。分三种情形：

- `pos = -1`：$S_+ = \varnothing \supseteq S_0$，无不动点，返回 $-1$ 正确；
- `pos ≠ -1` 且 $arr[pos] = pos$：由引理 2，`pos` $= \min S_0$，返回最小不动点；
- `pos ≠ -1` 且 $arr[pos] > pos$（即 $f(pos) > 0$）：对 $j \ge pos$ 有 $f(j) \ge f(pos) > 0$，对 $j < pos$ 有 $f(j) < 0$，两种情形均无 $f(j) = 0$，故 $S_0 = \varnothing$，返回 $-1$ 正确。∎

## 6. 复杂度分析

- **时间**：$O(\log n)$。二分每轮将区间折半，共 $O(\log n)$ 轮，每轮 $O(1)$ 判定。
- **空间**：$O(1)$。只使用常数个变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int fixedPoint(vector<int>& arr) {
        int lo = 0, hi = (int)arr.size() - 1, pos = -1;
        while (lo <= hi) {                    // 找最左侧的 i 使 arr[i] - i >= 0
            int mid = lo + (hi - lo) / 2;
            if (arr[mid] - mid >= 0) {        // f(mid) >= 0：mid 是候选，继续向左压缩
                pos = mid;
                hi = mid - 1;
            } else {                          // f(mid) < 0：不动点只可能出现在右侧
                lo = mid + 1;
            }
        }
        return (pos != -1 && arr[pos] == pos) ? pos : -1;
    }
};
```

### Python

```python
class Solution:
    def fixedPoint(self, arr: list[int]) -> int:
        lo, hi = 0, len(arr) - 1
        pos = -1
        while lo <= hi:                    # 找最左侧的 i 使 arr[i] - i >= 0
            mid = (lo + hi) // 2
            if arr[mid] - mid >= 0:        # f(mid) >= 0：mid 是候选，继续向左压缩
                pos = mid
                hi = mid - 1
            else:                          # f(mid) < 0：不动点只可能出现在右侧
                lo = mid + 1
        return pos if pos != -1 and arr[pos] == pos else -1
```

## 8. 边界情况与易错点

1. **「互异」是隐含的算法前提**：去掉它（只非降）后 $f$ 不再单调，二分失效（见 3.2 的 `arr = [0,0,2]` 反例），只能退回 $O(n)$ 扫描。
2. **别直接对 `arr[i]==i` 二分**：该谓词不单调；能二分的是 $arr[i] - i \ge 0$，二分结束后**必须再做一次判等**，否则例 3 这类「端点处 $f > 0$」的数据会输出错误下标。
3. **两类无解都要覆盖**：`pos = -1`（整个数组 $f < 0$）与 `arr[pos] > pos`（端点处 $f > 0$），最终都应返回 $-1$。
4. **负数与比较方向**：$arr[i]$ 可为负，$f(mid) < 0$ 时应向右收缩（`lo = mid + 1`），方向写反会死循环或漏解。
5. **单元素数组**：`[0]` 返回 0；`[5]`、`[-1]` 返回 -1，二分模板天然处理。
6. **要「最小」下标**：命中后继续向左压缩（`hi = mid - 1`），找到任何命中点直接返回会拿到非最小的不动点。
