# LeetCode 单词的压缩编码 题解

## 1. 题目概述

- **标题 / 题号**：单词的压缩编码（#820，medium）
- **链接**：https://leetcode.cn/problems/short-encoding-of-words/
- **来源**：LeetCode 第 81 场周赛 Q3
- **难度**：中等
- **标签**：字典树，数组，哈希表，字符串

**题意**：把单词数组 `words` 编码成一个助记字符串 `s`：`s` 以 `'#'` 结尾，并且对每个 `words[i]` 存在下标 `indices[i]`，使得 `s` 从 `indices[i]` 开始、到**下一个** `'#'`（不含）为止的子串恰好是 `words[i]`。返回最短的 `s` 的长度。

换句话说：`s` 是由若干个 `单词#` 段拼起来的，但一个单词的开头可以落在**某一段的内部**——只要它是那一段内容的**后缀**，就能免费复用，不必再单独占一段。目标是让「段的字符数 + 段数」最小。

**约束**：

- $1 \le \text{words.length} \le 2000$
- $1 \le \lvert \text{words}[i] \rvert \le 7$
- `words[i]` 仅由小写英文字母组成

## 2. 示例

**示例 1**

```text
输入：words = ["time", "me", "bell"]
输出：10
解释：s = "time#bell#"，indices = [0, 2, 5]
      words[0] = "time" → s[0..4)  = "time"
      words[1] = "me"   → s[2..4)  = "me"   复用 time 的尾段，不占新长度
      words[2] = "bell" → s[5..9)  = "bell"
      总长 = (4 + 1) + (4 + 1) = 10。
```

**示例 2**

```text
输入：words = ["t"]
输出：2
解释：s = "t#"，indices = [0]，总长 1 + 1 = 2。
```

**示例 3（补充，用于对比「前缀 ≠ 后缀」）**

```text
输入：words = ["abc", "bc", "c"]
输出：4
解释：s = "abc#"，indices = [0, 1, 2]，"bc"、"c" 都是 "abc" 的后缀，各贡献 0。
```

## 3. 解题思路

### 3.1 暴力思路

**第一层暴力：枚举 `s` 的构造。** 把所有单词按某种顺序排好，逐个决定「新开一段」还是「挂到已有段的尾部」，取总长最小者。排列数是 $n!$，$n = 2000$ 时完全不可行——而且我们并不知道「挂到哪一段」的判定该怎么做，暴力枚举也没有给出结构。

**第二层暴力：直接判后缀。** 换一个角度，答案只可能来自两种单词：能免费复用的、必须独占一段的。于是对每个单词 `w` 扫描所有其它单词 `v`，判断 `len(v) > len(w)` 且 `v` 以 `w` 结尾：

$$\text{ans} = \sum_{w \text{ 不被任何更长单词覆盖}} (\lvert w\rvert + 1)$$

复杂度 $O(n^2 L) \approx 2000^2 \times 7 = 2.8 \times 10^7$，本题**确实能过**。但它有两个坑：其一，重复单词必须先去重（同一单词不能既覆盖别人又被别人覆盖地重复计数）；其二，若把 $L \le 7$ 换成 $L \le 10^3$，$O(n^2L)$ 立刻退化。周赛正解要求一个与单词长度之和成正比的**结构性做法**。

### 3.2 核心观察：后缀覆盖，只有「根」付账

![后缀覆盖模型：只有根单词才独占一段](images/wc81_q3_suffix_cover_model.svg)

**观察一：后缀可免费复用。** 若 `A` 是 `B` 的真后缀，就把 `A` 的起点指向 `B` 在 `s` 中那一段的内部偏移处——`A` 完全嵌在 `B` 的尾段里，不占任何新长度。称「不是任何其它单词真后缀」的单词为**根（root）**，其余为**非根**。

**观察二：后缀关系有传递性。** 若 `A` 是 `B` 的真后缀、`B` 是 `C` 的真后缀，则 `A` 也是 `C` 的真后缀（同一段尾部对齐的嵌套）。于是从任一非根出发，沿「被谁覆盖」的链条长度严格递增，必然终止于某个根。**每个非根都是某个根的真后缀**，把它挂到该根那一段的尾部即可。

**结论**：只需让每个根各占一段 `根#`，非根全部搭便车，于是

$$\text{ans} = \sum_{w \in R} \bigl(\lvert w\rvert + 1\bigr), \qquad R = \{\text{根单词}\}$$

每个根要付「自己的字符数 + 1 个分隔符」。难点只剩一件事：**如何高效找出所有根**。

### 3.3 算法：逆序 Trie + 叶子求和

![逆序插入 Trie：后缀关系变前缀关系](images/wc81_q3_reverse_trie_build.svg)

**反转是关键词。** 后缀关系不好直接维护，但把单词反转后，`A` 是 `B` 的后缀 $\iff$ `rev(A)` 是 `rev(B)` 的前缀。于是把所有单词**逆序**插入一棵 Trie：

- 一条 root 到某节点的路径对应「某单词反转后的前缀」；
- 若 `rev(A)` 的终点节点**还有子节点**，说明有更长的 `rev(B)` 越过它继续往下 ⇒ `A` 是 `B` 的真后缀 ⇒ `A` 不是根；
- 若终点节点**没有子节点（叶子）**，说明没有任何单词以 `rev(A)` 为真前缀 ⇒ `A` 不被覆盖 ⇒ `A` 是根。

于是「找根」变成「找叶子」：答案等于所有叶子的 $(\text{depth} + 1)$ 之和，其中深度就是原单词长度。插入 `time`→`emit`、`me`→`em`、`bell`→`lleb` 时，`em` 的终点 `m` 会被 `emit` 继续延伸出子节点 `i`，因此 `m` 不是叶子，`me` 自动不计入；这条路径还顺带把**重复单词**合并掉了，无需额外去重。

![算法流程：建逆序 Trie，再数叶子](images/wc81_q3_algorithm_flow.svg)

1. 为每个 `w` 逆序遍历字符，沿 Trie 下行，缺边就新建节点；
2. 从 root 做一次 DFS，携带 `depth`；
3. 到达**叶子**（无子节点）时 `ans += depth + 1`，否则对每个子节点递归 `depth + 1`；
4. DFS 结束返回 `ans`。

全程**不需要真的拼出字符串 `s`**，只做计数。

### 3.4 示例演算

![示例演算：words = ["time", "me", "bell"]](images/wc81_q3_walkthrough.svg)

| 步骤 | 插入（逆序） | Trie 变化 | 累计答案 |
|------|--------------|-----------|----------|
| 1 | `time` → `emit` | 新建 `e-m-i-t`，`t` 成为叶子 | 5 |
| 2 | `me` → `em` | 只复用 `e`、`m`；`m` 被延伸出子节点 `i`，**不再**是叶子 | 5 |
| 3 | `bell` → `lleb` | root 下另建分支 `l-l-e-b`，`b` 成为叶子 | 5 + 5 = 10 |

叶子集合为 $\{t,\ b\}$（深度各为 4），故答案 $(4+1)+(4+1)=10$，与 `s = "time#bell#"` 的长度一致。注意第 2 步虽然插入了 `me`，却没有产生任何新叶子——这正是「非根付 0 元」的体现。

## 4. 算法细节

1. **逆序插入、正序理解**：遍历时从 `w.size()-1` 往 `0` 走，Trie 的路径就代表「反转后的前缀」。不要顺手写成正序，否则维护的是前缀关系，答案会全错（如 `["time","tim"]` 正序会把 `tim` 误判为可复用）。
2. **节点不需要 `is_end`**：本题只问「节点有没有子节点」，不问「是不是单词结尾」。叶子必然由某次插入的停点产生，所以叶子天然就是某些单词的终点（可能被多个重复单词共享）。
3. **深度即长度**：DFS 的 `depth` 从 0 起，每下探一层加 1；因为插入是逆序的，root 到该节点的边数恰好等于原单词长度，无需再存 `len`。
4. **重复单词自动去重**：同一单词走同一条路径、落在同一节点，DFS 每个节点只访问一次，故重复项不会重复计费。
5. **实现选型**：C++ 用 `vector<array<int,26>>` 节点池 + `-1` 空指针，避免指针与内存泄漏，单节点 104 字节；Python 用「`dict` 套 `dict`」，节点即子节点表，判空只需 `if not node`。
6. **空间上界**：节点总数 $\le 1 + \sum_i \lvert w_i\rvert \le 1 + 2000 \times 7 = 14001$，无论哪种表示都极小。
7. **等价的哈希集合写法**（更适合快速写）：`good = set(words)`，对每个 `w` 把它的所有真后缀 `w[1:], w[2:], ...` 从 `good` 中删掉，最后 `sum(len(w)+1 for w in good)`。复杂度 $O(nL^2)$，本题 $L\le 7$ 完全够用；Trie 版则在 $L$ 很大时仍然线性。

## 5. 正确性证明

**引理 1（后缀传递）**：若 `A` 是 `B` 的真后缀，`B` 是 `C` 的真后缀，则 `A` 是 `C` 的真后缀。

**证明**：设 $\lvert C\rvert = c$，`B` 是 `C` 的长度为 $b$ 的后缀，即 $C[c-b..c)=B$；`A` 是 `B` 的长度为 $a$ 的后缀，即 $B[b-a..b)=A$。代入得 $C[c-a..c)=A$，且 $a<b<c$，故 `A` 是 `C` 的真后缀。∎

**引理 2（每个非根都挂在某个根上）**：设 `R` 为根集合，则任一单词 $x\notin R$ 都存在 $r\in R$ 使 $x$ 是 $r$ 的真后缀。

**证明**：因 $x\notin R$，存在不同于它的单词 $y$ 使 $x$ 是 $y$ 的真后缀，此时 $\lvert y\rvert > \lvert x\rvert$。若 $y\in R$ 则已证；否则对 $y$ 重复同一论证，得到一个长度严格递增的单词序列。长度有上界 $\max_i\lvert w_i\rvert$，故序列有限，终止项必属于 `R`；再由引理 1 逐步传递，$x$ 是该终止项的真后缀。∎

**引理 3（叶子判定）**：在逆序 Trie 中，深度为 $d\ge 1$ 的节点 $u$ 是叶子 $\iff$ $u$ 对应的字符串 $w_u$ 是某个单词，且不是任何其它单词的真后缀。

**证明**：

- ($\Rightarrow$) 节点 $u$ 无子节点。$u$ 由某次插入创建，故 $w_u$ 必为某个单词。若存在单词 $w'$ 使 $w_u$ 是其真后缀，则 $\text{rev}(w_u)$ 是 $\text{rev}(w')$ 的真前缀，$\text{rev}(w')$ 的路径会经过 $u$ 后继续下行一个字符，与「无子节点」矛盾。
- ($\Leftarrow$) 若 $u$ 有子节点，则该子节点同样由某次插入创建，说明存在单词 $w'$ 使其反转串以 $\text{rev}(w_u)$ 加一个字符为前缀，即 $w_u$ 是 $w'$ 的真后缀，矛盾。∎

**引理 4（下界）**：任一合法编码的参考串 $s$ 都满足 $\lvert s\rvert \ge \sum_{w\in R}(\lvert w\rvert+1)$。

**证明**：按 `'#'` 把 $s$ 切成 $s=\text{seg}_1\#\text{seg}_2\#\cdots\#\text{seg}_k\#$，则 $\lvert s\rvert=\sum_j(\lvert \text{seg}_j\rvert+1)$。对每个 $w\in R$，其出现必须结束于某个 `'#'` 之前，故它整体落在某个 $\text{seg}_j$ 内，$\lvert \text{seg}_j\rvert\ge\lvert w\rvert$。不同的根不可能落在同一段：否则两者都是该段的后缀，短的那个就是长的那个的真后缀（长度相同则两词相同，与根互异矛盾），违背根的定义。于是根与段一一对应，其余段每段至少贡献分隔符的 $1$ 个字符，故
$$\lvert s\rvert=\sum_{j\in J}\bigl(\lvert \text{seg}_j\rvert+1\bigr)+\sum_{j\notin J}\bigl(\lvert \text{seg}_j\rvert+1\bigr)\ \ge\ \sum_{w\in R}\bigl(\lvert w\rvert+1\bigr)$$
其中 $J$ 为根所对应的段下标集合。∎

**定理**：把根按任意顺序拼成 $s=\text{concat}_{w\in R}(w\#)$ 是一个合法编码，且长度等于下界，因此算法返回的 $\sum_{w\in R}(\lvert w\rvert+1)$ 就是最短长度。

**证明**：合法性——每个根取自己那一段的起点；每个非根 $x$ 由引理 2 是某根 $r$ 的真后缀，把 $x$ 的起点取为 $r$ 段内偏移 $\lvert r\rvert-\lvert x\rvert$ 处，则从该处到 $r$ 段末尾的 `'#'` 恰好是 $x$，满足定义；$s$ 以 `'#'` 结尾，且 `indices` 每个单词一项（根指向自己段的起点，非根指向所属根段的内部偏移），长度与 `words` 相同。长度——$\lvert s\rvert=\sum_{w\in R}(\lvert w\rvert+1)$ 达到引理 4 的下界。又由引理 3，Trie 的叶子集合与根集合相同，DFS 累加每个叶子的 $\text{depth}+1$（深度即长度）恰好等于该和。综上算法输出即最优值。∎

## 6. 复杂度分析

- **时间**：$O\bigl(\sum_i \lvert w_i\rvert\bigr)$。插入阶段每个字符做一次 $O(1)$ 的子节点查/建；DFS 每个节点恰好进出一次，叶子判定对 C++ 是 26 次常数扫描（$26$ 为常数），故总代价与字符总量成正比。上限约 $1.4\times10^4$ 次操作。
- **空间**：$O\bigl(\sum_i \lvert w_i\rvert\bigr)$。Trie 节点数不超过 $1+\sum_i\lvert w_i\rvert \le 14001$；DFS 用显式栈，深度不超过 $\max_i\lvert w_i\rvert \le 7$（递归写法栈深同理）。不额外存储字符串 `s`。

## 7. 参考代码

### C++

```cpp
#include <array>
#include <string>
#include <utility>
#include <vector>
using namespace std;

class Solution {
public:
    int minimumLengthEncoding(vector<string>& words) {
        vector<array<int, 26>> trie(1);   // 节点池：nxt[c] = 子节点下标，-1 表示空
        trie[0].fill(-1);

        for (const string& w : words) {
            int cur = 0;
            for (int i = (int)w.size() - 1; i >= 0; --i) {   // 逆序插入
                int c = w[i] - 'a';
                if (trie[cur][c] == -1) {
                    trie.emplace_back();
                    trie.back().fill(-1);
                    trie[cur][c] = (int)trie.size() - 1;
                }
                cur = trie[cur][c];
            }
        }

        int ans = 0;
        vector<pair<int, int>> st{{0, 0}};   // {节点下标, 深度}
        while (!st.empty()) {
            auto [node, depth] = st.back();
            st.pop_back();
            bool leaf = true;
            for (int c = 0; c < 26; ++c) {
                if (trie[node][c] != -1) {
                    leaf = false;
                    st.push_back({trie[node][c], depth + 1});
                }
            }
            if (leaf) ans += depth + 1;      // 叶子 = 根单词，独占 len+1
        }
        return ans;
    }
};
```

### Python

```python
from typing import List


class Solution:
    def minimumLengthEncoding(self, words: List[str]) -> int:
        trie = {}                            # 节点就是它的子节点字典
        for w in words:
            cur = trie
            for ch in reversed(w):           # 逆序插入
                cur = cur.setdefault(ch, {})

        ans = 0
        stack = [(trie, 0)]                  # (节点, 深度)
        while stack:
            node, depth = stack.pop()
            if not node:                     # 叶子 ⇔ 不是任何其它单词的真后缀
                ans += depth + 1             # +1 给分隔符 '#'
            else:
                stack.extend((child, depth + 1) for child in node.values())
        return ans
```

## 8. 边界情况与易错点

1. **前缀当后缀**：`["time","tim"]` 的答案是 $5+4=9$（`tim` 不是 `time` 的后缀，两段都要占），而 `["time","me"]` 的答案是 $5$。判断方向必须是「后缀」，或者反转后判「前缀」。
2. **重复单词**：`["time","time"]` 答案是 $5$ 而不是 $10$。Trie 天然合并；若用集合写法，`set(words)` 也必须先去重，否则集合里两个 `"time"` 会重复计费。
3. **单个单词 / 长度为 1**：`["t"]` → $2$；`["a","b","c"]` → $6$。每个根都要额外付一个 `'#'`，别忘记 `+1`。
4. **自嵌套链**：`["aaaa"]` 型数据（`["aaaa","aaa","aa","a"]`）答案 $5$：只有最长者是根，`depth+1` 用的是**叶子深度**，不是单词个数。
5. **root 不参与计数**：DFS 从 `depth = 0` 的 root 出发，但 root 的 `depth+1 = 1` 只在 root 无子节点时才会被计入——而 `words` 非空且 $\lvert w\rvert\ge1$，root 必有子节点，所以无需特判；若把「root 也算叶子」写进代码就会多出 1。
6. **C++ 节点池扩容**：`trie.emplace_back()` 可能触发 `vector` 重新分配，因此**不要**在扩容前保存指向节点的引用/指针，全程用下标访问（先 `emplace_back` 再写下标，如上面的代码）。
7. **不要真的构造 `s`**：拼接字符串并逐段匹配也能过，但会引入 $O(n^2)$ 的隐式开销与大量内存，计数式写法才是稳的。
