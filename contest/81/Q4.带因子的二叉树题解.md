# LeetCode 带因子的二叉树 题解

## 1. 题目概述

- **标题 / 题号**：带因子的二叉树（#823，medium）
- **链接**：https://leetcode.cn/problems/binary-trees-with-factors/
- **来源**：LeetCode 第 81 场周赛 Q4
- **难度**：中等
- **标签**：数组、哈希表、动态规划、排序

**题意**：给定互不相同的整数数组 `arr`，每个元素都 $\ge 2$。用这些整数（每个值可用任意多次）构造二叉树，要求**每个非叶结点的值等于其左右两个子结点值之积**，结点值必须取自 `arr`。问满足条件的二叉树共有多少棵，答案对 $10^9+7$ 取模。左右子树的位置是**有序**的：`[10,2,5]` 与 `[10,5,2]` 算两棵不同的树，但两个子结点值相同时，交换左右不产生新的树。

**约束**：

- $1 \le \text{arr.length} \le 1000$
- $2 \le \text{arr}[i] \le 10^9$
- `arr` 中所有值**互不相同**
- 答案对 $10^9+7$ 取模

## 2. 示例

**示例 1**

```text
输入：arr = [2, 4]
输出：3
解释：合法的二叉树共 3 棵：[2]、[4]、[4, 2, 2]
```

**示例 2**

```text
输入：arr = [2, 4, 5, 10]
输出：7
解释：[2]、[4]、[5]、[10]、[4, 2, 2]、[10, 2, 5]、[10, 5, 2]
```

**示例 3（补充，用于后文演算）**

```text
输入：arr = [2, 3, 4, 6, 12]
输出：18
解释：dp[2..12] 依次为 1、1、2、3、11，求和得 18；
      以 12 为根的 11 棵树里，只有 1 棵是叶子 [12]，其余都由因子对拼出。
```

## 3. 解题思路

### 3.1 暴力思路

最直白的做法是**按树的形状枚举**：先选根值，再递归地选左右子树，最后检查乘积约束。每层都要在 $n$ 个值里挑两个，而路径长度可达 $\log_2 10^9 \approx 30$，搜索树是指数级展开；即使把子树按根值缓存，仍要配合回溯去重，代码复杂、常数极大。$n=1000$ 时完全不可行。

换个角度：一棵树 = **根 + 左子树 + 右子树**。同一棵子树会被无数个父结点反复用到，这正是**重叠子问题**；而根值只有 $n$ 种可能，天然适合以「根值」为状态做计数 DP。

### 3.2 核心观察：按根值分类 + 因子对分解

![根与因子对：左右子树有序](images/wc81_q4_factor_pair_model.svg)

三个关键观察：

1. **按根分类不重不漏**：每棵合法树的根值必是 `arr` 中某个 $x$（所有结点值都取自 `arr`）。于是总答案就是 $\sum_{x \in \text{arr}} \text{dp}[x]$，其中 $\text{dp}[x]$ 表示**以 $x$ 为根的合法树数**。
2. **子结点值必是 $x$ 的因子**：根 $x$ 非叶时，存在 $a \cdot b = x$ 且 $a, b \in \text{arr}$。由 $a, b \ge 2$ 得 $a, b < x$——**因子严格更小**。因此把 `arr` 升序排序后逐个计算，$\text{dp}[a]$、$\text{dp}[b]$ 一定已经算好，转移无后效性。
3. **分解唯一**：根值 $x$ 加上左右子树的形状，唯一确定一棵树；反过来，给定有序因子对 $(a,b)$，左右子树可独立任取，由乘法原理贡献 $\text{dp}[a] \times \text{dp}[b]$ 棵。把所有有序因子对求和，再补上「$x$ 单独作叶子」这一棵，就得到 $\text{dp}[x]$。

状态转移方程：

$$\text{dp}[x] = 1 + \sum_{\substack{a \cdot b = x \\ a,\,b \in \text{arr}}} \text{dp}[a] \cdot \text{dp}[b]$$

**为什么要区分 $a=b$**：子树位置有序，$a \ne b$ 时「左 $a$ 右 $b$」与「左 $b$ 右 $a$」是两棵树，各贡献 $\text{dp}[a]\text{dp}[b]$；$a = b$（即 $a = \sqrt{x}$）时两种写法画出同一棵树，只能算一份。所以可以只枚举较小的因子 $a \le \sqrt{x}$，命中的有序对按系数 $(1 + [\,a \ne x/a\,])$ 合并：

$$\text{dp}[x] = 1 + \sum_{a \le \sqrt{x}} [\,a \mid x\,] \cdot [\,x/a \in \text{arr}\,] \cdot \text{dp}[a] \cdot \text{dp}[x/a] \cdot \bigl(1 + [\,a \ne x/a\,]\bigr)$$

其中 $[\,\cdot\,]$ 是艾弗森括号：条件成立取 1，否则取 0。

### 3.3 算法流程与状态转移

![排序、哈希表、因子对累加](images/wc81_q4_dp_flow.svg)

1. 将 `arr` **升序排序**；
2. 用**哈希表** `dp` 记录「值 → 以它为根的树数」（值域到 $10^9$，不能用数组下标）；
3. 依次取 $x$，先令 `dp[x] = 1`，代表叶子树；
4. 内层枚举 $a \in \text{arr}$，只要 $a \cdot a \le x$ 就继续：
   - 若 $x \bmod a \ne 0$，跳过；
   - 令 $b = x / a$，若 $b$ 不在 `dp` 中（即 $b \notin \text{arr}$），跳过；
   - 否则 `dp[x] += dp[a] * dp[b] * (a == b ? 1 : 2)`，边加边取模；
5. `total += dp[x]`；全部处理完后返回 `total mod (10^9 + 7)`。

> 💡 **只需一个 `dp` 表，不必另建集合**：$b = x/a \le x/2 < x$，凡在 `arr` 中的 $b$ 都已按升序算过 `dp[b]`，因此 `b ∈ dp` 与 `b ∈ arr` 等价，省掉一次查集合。

### 3.4 示例演算

![dp 表填充过程](images/wc81_q4_walkthrough.svg)

以 `arr = [2, 3, 4, 6, 12]` 为例，排序后依次计算：

| 值 $x$ | 内层枚举 $a$ | 命中的有序因子对 | 新增贡献 | $\text{dp}[x]$ |
|---|---|---|---|---|
| 2 | 无 | — | 初值 1 | 1 |
| 3 | 无 | — | 初值 1 | 1 |
| 4 | 2 | $(2,2)$，系数 1 | $1 \times 1 = 1$ | 2 |
| 6 | 2 | $(2,3)$、$(3,2)$，系数 2 | $1 + 1 = 2$ | 3 |
| 12 | 2、3 | $(2,6)$、$(6,2)$、$(3,4)$、$(4,3)$ | $2 \cdot 1 \cdot 3 + 2 \cdot 1 \cdot 2 = 10$ | 11 |

答案 $= 1 + 1 + 2 + 3 + 11 = 18$。以 $x = 12$ 为例，这 11 棵树分别是：

- 叶子 `[12]`，1 棵；
- 左 $2$ 右 $6$：右子树可取 `[6]`、`[6,2,3]`、`[6,3,2]` 三种 → 3 棵；镜像「左 6 右 2」再来 3 棵；
- 左 $3$ 右 $4$：右子树可取 `[4]`、`[4,2,2]` 两种 → 2 棵；镜像再来 2 棵。

合计 $1 + 3 + 3 + 2 + 2 = 11$ ✓。可见「左右有序」正是系数 2 的来源，而 $4$ 的唯一因子对 $(2,2)$ 天然只算一份。

## 4. 算法细节

1. **排序是 DP 的前提**。$a,b \ge 2 \Rightarrow a,b < x$，升序处理保证转移时因子已就绪；不需要按层数或树高分层。
2. **哈希表而非数组**。$x$ 可达 $10^9$，只能用 `unordered_map<int, long long>` / `dict`；$n \le 1000$，表里最多 1000 个条目。
3. **$\sqrt{x}$ 枚举只做一半**。只枚举 $a \le \sqrt{x}$ 再用系数补对称，内层迭代约减半；与「枚举全部 $a < x$」等价（见引理 2 的推论）。
4. **`a * a` 必须按 64 位算**。$a$ 可达 $10^9$，`a * a` 在 `int` 里会溢出成负数，比较直接失效。C++ 写 `(long long)a * a > x`；Python 的大整数没有这个问题。
5. **乘法用 `long long`**。`dp` 值都 $< 10^9+7$，故 $\text{dp}[a]\text{dp}[b] < 1.1 \times 10^{18}$，再乘系数 2 仍 $< 2.2 \times 10^{18} < 9.2 \times 10^{18}$，64 位整数安全；用 `int` 必然溢出。
6. **取模时机**。每次加法后立刻 `% MOD`；`dp[x]` 与 `total` 都要取模，否则 $n$ 项累加会溢出。
7. **叶子初值为 1**。题面只约束「非叶结点」，叶子没有子结点，条件空真成立，所以每个值至少贡献 1 棵树。
8. **内层不需要判 $a$ 越界**。$a \cdot a \le x$ 且 $x \ge 2$ 保证 $a \le \sqrt{x} < x$，所以 `dp[a]` 一定存在，可以放心取用。

## 5. 正确性证明

**引理 1（沿路径值严格递减）**：任一合法树中，若 $y$ 是 $z$ 的子结点，则 $y < z$；因此树高不超过 $\lfloor \log_2(\max \text{arr}) \rfloor + 1 \le 30$。

**证明**：$z$ 为叶结点时没有子结点，命题空真。$z$ 非叶时存在兄弟 $y'$ 使 $z = y \cdot y'$，由 $y, y' \ge 2$ 得 $y \le z/2 < z$。沿任一从根到叶的路径，结点值是严格递减的正整数，长度不超过 $\log_2(\max\text{arr}) + 1$。∎

**引理 2（分解双射）**：设 $a, b \in \text{arr}$ 且 $a \cdot b = x$。以 $x$ 为根、左子值为 $a$、右子值为 $b$ 的非叶树，与「以 $a$ 为根的合法树 + 以 $b$ 为根的合法树」的有序对构成一一对应。

**证明**：给定这样一棵树，去掉根得到左右两棵子树，它们各自合法、根值分别为 $a$ 与 $b$；反之给定两棵合法树，接上根 $x$ 后，新根与原有非叶结点都满足乘积条件，仍是一棵合法树。两个方向互逆，故为双射，由乘法原理数量为 $\text{dp}[a]\cdot\text{dp}[b]$。∎

**推论（$\sqrt{x}$ 枚举的等价性）**：$\sum_{a\cdot b = x,\ a,b\in\text{arr}} \text{dp}[a]\text{dp}[b]$ 等于「只枚举 $a \le \sqrt{x}$ 并乘系数 $(1+[a \ne x/a])$」的求和。

**证明**：$a \ne b$ 时有序对 $(a,b)$ 与 $(b,a)$ 同时出现在求和中且贡献相同，合并为一项乘 2；$a = b$ 时只有一个有序对，系数为 1。两类恰好覆盖全部有序对，故相等。∎

**引理 3（转移正确）**：按升序处理时，算法算出的 `dp[x]` 等于以 $x$ 为根的合法树数。

**证明**：对排序后的下标做归纳。设所有小于 $x$ 的值都已算对。以 $x$ 为根的树按「是否为叶」分两类：叶子只有 1 棵，对应初值 1；非叶树的根带一对子值 $(a,b)$，由引理 2 数量为 $\text{dp}[a]\text{dp}[b]$，且不同的有序对 $(a,b)$ 给出不同的树（子值不同，或左右位置不同）。由引理 1 有 $a,b < x$，按升序它们已算好；由推论，枚举 $a \le \sqrt{x}$ 已覆盖全部有序对。故 `dp[x]` 累加结果恰为全部合法树数。∎

**定理**：算法返回值等于所有合法二叉树的数量（模 $10^9+7$）。

**证明**：任一合法树的根值 $x$ 必属于 `arr`，故全部树按根值划分为 $n$ 个互不相交的类，第 $x$ 类大小为 `dp[x]`（引理 3），求和即总数，不重不漏。引理 1 同时保证枚举过程必然终止。模运算在加、乘下保持同余，且中间乘积不溢出（§4.5），故取模后的结果与原值同余。∎

## 6. 复杂度分析

- **时间**：排序 $O(n \log n)$；外层 $n$ 个值，内层因 $a \cdot a \le x$ 截断，最坏仍为 $O(n)$ 次常数操作（哈希查找期望 $O(1)$），合计 $O(n^2)$。$n \le 1000$ 时约 $10^6$ 次迭代，远低于时限。
- **空间**：`dp` 哈希表存 $n$ 个键值对，$O(n)$；排序的栈空间 $O(\log n)$，整体 $O(n)$。
- **数值**：中间乘积上界 $2.2 \times 10^{18}$，落在 64 位有符号整数范围内，无需高精度。

## 7. 参考代码

### C++

```cpp
#include <algorithm>
#include <unordered_map>
#include <vector>
using namespace std;

class Solution {
public:
    int numFactoredBinaryTrees(vector<int>& arr) {
        const long long MOD = 1000000007LL;
        sort(arr.begin(), arr.end());          // 升序：因子一定更小
        unordered_map<int, long long> dp;      // 值 -> 以它为根的树数
        long long total = 0;

        for (int x : arr) {
            long long cur = 1;                 // 叶子树：x 单独一棵
            for (int a : arr) {
                if ((long long)a * a > x) break;   // 只枚举较小的因子，注意 64 位
                if (x % a) continue;               // a 不是 x 的因子
                auto it = dp.find(x / a);          // b = x / a 必须在 arr 中
                if (it == dp.end()) continue;
                long long add = dp[a] * it->second % MOD;
                if (a != x / a) add = add * 2 % MOD;  // 左右交换是另一棵树
                cur = (cur + add) % MOD;
            }
            dp[x] = cur;
            total = (total + cur) % MOD;       // 按根值分类累加
        }
        return (int)total;
    }
};
```

### Python

```python
class Solution:
    def numFactoredBinaryTrees(self, arr: list[int]) -> int:
        MOD = 10 ** 9 + 7
        arr = sorted(arr)                 # 升序：因子一定更小
        dp = {}                           # 值 -> 以它为根的树数
        total = 0

        for x in arr:
            cur = 1                       # 叶子树：x 单独一棵
            for a in arr:
                if a * a > x:             # 只枚举较小的因子
                    break
                if x % a:                 # a 不是 x 的因子
                    continue
                b = x // a
                if b not in dp:           # b 不在 arr 中（b < x，故只查已算过的）
                    continue
                add = dp[a] * dp[b] % MOD
                if a != b:
                    add = add * 2 % MOD   # 左右交换是另一棵树
                cur = (cur + add) % MOD
            dp[x] = cur
            total = (total + cur) % MOD   # 按根值分类累加

        return total
```

## 8. 边界情况与易错点

1. **$n = 1$**：`arr = [2]` 只有叶子一种，返回 1。初值 1 已经给出答案，注意别漏掉 `total` 的累加。
2. **全是大质数**：如 `[999999937, 999999929]`，不存在任何因子对，答案为 $n$。此时内层循环每次都在 $a \cdot a > x$ 处立刻退出，性能没有隐患。
3. **`int` 溢出**：$a$ 接近 $10^9$ 时 `a * a` 溢出成负数，`dp[a] * dp[b]` 也会溢出。前者比较时转 `long long`，后者用 `long long` 存 `dp`——这是本题最高频的 WA 原因。
4. **$a = b$ 不能乘 2**：$x = 4$ 只有 $(2,2)$ 一个有序对，若也乘 2，示例 1 会算成 4 而不是 3。
5. **两种写法不能混用**：若改成「枚举全部 $a < x$ 并累加 $\text{dp}[a]\text{dp}[x/a]$」，$(a,b)$ 与 $(b,a)$ 各被枚举一次，此时**不能再乘系数 2**，否则重复计数。
6. **`b` 不在 `arr` 中要跳过**：如 `arr = [2, 3, 10]` 计算 $x = 10$ 时，$a = 2$ 得不整除的 $b = 5$，必须 `continue`，`dp[10]` 最终为 1（只有叶子）。
7. **取模不要留到最后**：`total` 只在返回前取模会溢出（1000 个大数相加），必须每轮取模。
8. **重复值需先去重**：题面保证元素互不相同；若输入有重复，同一棵树会被不同来源重复计数，语义上应先对 `arr` 去重再计算。

**延伸思考**：

1. 若要求**输出所有树**而不是只计数，可把 `dp` 从整数改成「树列表」，对每个因子对做笛卡尔积，规模随答案指数增长，需要额外约束。
2. 若只统计**不同的树形状**（忽略结点值），问题退化为「给定 $n$ 个乘数、乘积固定的因子分解树」，需要按因子多重集去重。
3. 若 `arr` 值域较小而 $n$ 很大，可以先用筛法预处理每个值的所有因子对（$O(V\log V)$），把每个 $x$ 的内层从 $O(n)$ 降到「因子个数」，整体接近 $O(V \log V)$。
4. 若允许 `arr` 中存在重复值、并把「值相同的结点视为不可区分」，则需要先聚合多重集再做带重组合系数的 DP，是对本题计数模型的一个自然推广。
