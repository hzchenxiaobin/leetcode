# LeetCode 能被 3 整除的三元组最大和 题解

## 1. 题目概述

- **标题 / 题号**：能被 3 整除的三元组最大和（#3780，medium）
- **链接**：https://leetcode.cn/problems/maximum-sum-of-three-numbers-divisible-by-three/
- **来源**：LeetCode 第 172 场双周赛 Q2
- **难度**：中等
- **标签**：贪心、数组、排序、堆（优先队列）

**题意**：从数组 `nums` 中**恰好选三个**整数（不同下标，值可以相同），使它们的和能被 $3$ 整除，求最大的可能和；不存在则返回 $0$。

**约束**：

- $3 \le nums.length \le 10^5$
- $1 \le nums[i] \le 10^5$

## 2. 示例

**示例 1**

```text
输入：nums = [4,2,3,1]
输出：9
解释：和为 9 的三元组有 (4,2,3)=9、(2,3,1)=6，最大是 9。
```

**示例 2**

```text
输入：nums = [2,1,5]
输出：0
解释：只有一个三元组 2+1+5 = 8，8 % 3 = 2，不合法，答案 0。
```

**补充示例 3**

```text
输入：nums = [1,2,3,4,5,6]
输出：15
解释：取 4 + 5 + 6 = 15，15 % 3 == 0，是最大可行和（三个数分别为模 3 余 1、2、0）。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有 $\binom{n}{3}$ 个三元组，逐个判和能否被 3 整除，取最大：$O(n^3)$，$n = 10^5$ 时约 $1.7 \times 10^{14}$，完全不可行。

### 3.2 核心观察：只看「模 3 的余数组合」

![三元组和能被 3 整除 ⟺ 余数组合是四种模式之一](images/bw172_q2_mod_patterns.svg)

三元组的和 $\bmod 3$ 只由三个元素各自的余数决定。设 $r_i = nums[i] \bmod 3 \in \{0, 1, 2\}$，则

$$(a + b + c) \bmod 3 = (r_a + r_b + r_c) \bmod 3$$

枚举全部 $3^3 = 27$ 种余数组合，只有 4 种满足和为 $0 \pmod 3$：

| 模式 | 余数组合 | 和的模 |
|------|----------|--------|
| A | $(0,0,0)$ | $0$ |
| B | $(1,1,1)$ | $3 \equiv 0$ |
| C | $(2,2,2)$ | $6 \equiv 0$ |
| D | $(0,1,2)$ | $3 \equiv 0$ |

**没有第五种**——这是本题的第一个关键结论（证明见引理 1）。

于是按余数把 `nums` 分成三组，各自**降序排序**，每个模式都只需要取本组**最大的若干个**：

- 模式 A：取组 0 的前 3 大；
- 模式 B：取组 1 的前 3 大；
- 模式 C：取组 2 的前 3 大；
- 模式 D：取组 0、组 1、组 2 各自的第 1 大。

对每种可行模式求和，取最大，若都不可行则返回 0。

### 3.3 算法流程

![算法流程：按余数分组 → 降序 → 试四种模式取最大](images/bw172_q2_group_and_try.svg)

```text
1. 把 nums 按 x % 3 分到 g[0]、g[1]、g[2] 三组
2. 每组降序排序
3. ans = 0
4. for m in {0,1,2}:
       若 |g[m]| >= 3:  ans = max(ans, g[m][0] + g[m][1] + g[m][2])
5. 若三组都非空:  ans = max(ans, g[0][0] + g[1][0] + g[2][0])
6. 返回 ans
```

由于每个模式内部和一定被 3 整除（模式定义保证），无需再做取模检查；写 `if (s % 3 == 0)` 也不会错，只是多余。

### 3.4 示例演算

对示例 1 的 `nums = [4,2,3,1]`：

| 组 | 元素（降序） |
|----|--------------|
| 组 0（$x \bmod 3 = 0$） | `[3]` |
| 组 1 | `[4, 1]` |
| 组 2 | `[2]` |

逐模式尝试：

- 模式 A（0,0,0）：组 0 只有 1 个元素，不足 3 个，跳过；
- 模式 B（1,1,1）：组 1 只有 2 个，跳过；
- 模式 C（2,2,2）：组 2 只有 1 个，跳过；
- 模式 D（0,1,2）：三组都非空，和 $= 3 + 4 + 2 = 9$ ✓。

答案 9，与示例一致。

对补充示例 3 的 `nums = [1,2,3,4,5,6]`：组 0 = `[6,3]`，组 1 = `[4,1]`，组 2 = `[5,2]`。模式 A/B/C 都凑不出三个，模式 D 给出 $6 + 4 + 5 = 15$ ✓，与示例一致。

## 4. 算法细节

1. **只需每组前 3 大**：可以用「排序 + 取前 3」，也可以用一个长度 3 的小根堆（$O(n \log 3)$）。排序写法更短，$O(n \log n)$ 对 $10^5$ 完全够；堆写法在 $n$ 极大时更优。
2. **`x % 3` 的符号**：本题 $nums[i] \ge 1$，余数非负，无坑；若允许负数，C++ 的 `%` 会得到负余数，需要 `(x % 3 + 3) % 3`。
3. **模式 D 只取各组的最大值**：因为三个数来自不同组，互不冲突，所以取各组最大即可（引理 2）。
4. **模式 A/B/C 取同一组的前 3 大**：同组内可以任取不同下标的元素，取最大三个最优（引理 2）。
5. **重复值**：题目允许值相同但下标不同，所以「排序后取前 3 个」而不是「去重后取前 3 个」——去重会错。
6. **`ans` 初值 0**：题目规定无解返回 0，而 $nums[i] \ge 1$ 保证任何合法三元组的和 $\ge 3 > 0$，所以用 0 当哨兵是安全的。
7. **不必真的构造三元组**：只需返回和。
8. **堆的替代**：若用堆维护每组前 3 大，注意小根堆要「先 push 再 pop」，保证最终留下 3 个最大元素。

## 5. 正确性证明

**引理 1（四种余数模式）**：设 $r_1, r_2, r_3 \in \{0,1,2\}$，则 $r_1 + r_2 + r_3 \equiv 0 \pmod 3$ 当且仅当多重集 $\{r_1, r_2, r_3\}$ 是 $\{0,0,0\}$、$\{1,1,1\}$、$\{2,2,2\}$、$\{0,1,2\}$ 之一。

**证明**：三个余数之和的范围是 $[0, 6]$，能被 3 整除即和为 $0, 3, 6$。
- 和为 0：三个都是 0 → $\{0,0,0\}$；
- 和为 6：三个都是 2 → $\{2,2,2\}$；
- 和为 3：把 3 分成三个 $0..2$ 的整数之和，可能的分拆为 $3+0+0$（不允许，单数超 2）、$2+1+0$、$1+1+1$ → 即 $\{0,1,2\}$ 与 $\{1,1,1\}$。
四类穷尽，故充要。∎

**引理 2（各模式的最优取法）**：
（a）若模式为 $\{0,0,0\}$，则最优三元组是组 0 中最大的三个元素之和；
（b）$\{1,1,1\}$、$\{2,2,2\}$ 同理取对应组最大的三个；
（c）若模式为 $\{0,1,2\}$，则最优是组 0、组 1、组 2 各自最大值之和。

**证明**：（a）三个数都来自组 0 且下标互异，要使和最大，在组 0 中取最大的三个（排序后前三个）。若把其中任一个换成更小的元素，和不会增大。（b）同（a）。（c）三个数分别来自不同组，三个选择**互相独立**，故分别取各组最大值即为最优。∎

**定理**：算法返回值为满足条件的三元组的最大和；若不存在则返回 0。

**证明**：
（1）**算法输出合法**：算法只在模式可行（对应组元素足够）时计入候选，且由引理 1，四种模式的和都能被 3 整除，故每个候选都是一个合法三元组的和，输出 $\le$ 最优值。
（2）**最优值被覆盖**：设最优三元组 $T$ 的余数多重集为 $M$。由引理 1，$M$ 是四种模式之一。若 $M = \{0,0,0\}$，则组 0 至少含 3 个元素（$T$ 的三个元素都在组 0），算法会尝试该模式；由引理 2(a)，算法得到的和不小于 $T$ 的和。其余模式同理。
（3）**无解情形**：若不存在合法三元组，则四种模式都不可行（引理 1 说明合法三元组必属某模式），`ans` 保持 0，符合题意。
由（1）（2）（3），算法输出等于所求最大值。∎

## 6. 复杂度分析

- **时间**：$O(n \log n)$。分组 $O(n)$；三组分别排序，最坏 $O(n \log n)$；枚举 4 种模式 $O(1)$。若改用大小 3 的堆，可降到 $O(n)$（常数略大）。
- **空间**：$O(n)$ 存三个分组数组（或 $O(1)$ 额外空间，若用 3 个大小为 3 的堆）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maximumSum(vector<int>& nums) {
        vector<vector<int>> g(3);
        for (int x : nums) {
            g[x % 3].push_back(x);
        }
        for (auto& v : g) {
            sort(v.rbegin(), v.rend());
        }
        int ans = 0;
        for (int m = 0; m < 3; m++) {
            if ((int)g[m].size() >= 3) {
                ans = max(ans, g[m][0] + g[m][1] + g[m][2]);
            }
        }
        if (!g[0].empty() && !g[1].empty() && !g[2].empty()) {
            ans = max(ans, g[0][0] + g[1][0] + g[2][0]);
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maximumSum(self, nums: list[int]) -> int:
        g = [[], [], []]
        for x in nums:
            g[x % 3].append(x)
        for v in g:
            v.sort(reverse=True)

        ans = 0
        for m in range(3):
            if len(g[m]) >= 3:
                ans = max(ans, g[m][0] + g[m][1] + g[m][2])
        if g[0] and g[1] and g[2]:
            ans = max(ans, g[0][0] + g[1][0] + g[2][0])
        return ans
```

## 8. 边界情况与易错点

1. **余数组合想漏**：容易只想到 $(0,0,0)$ 和 $(1,1,1)$，漏掉 $(2,2,2)$ 与 $(0,1,2)$。示例 1 的答案恰来自 $(0,1,2)$。
2. **去重后再取前 3**：值相同但下标不同是允许的，去重会导致「取不够三个」而漏解。
3. **模式 D 误取同组**：$(0,1,2)$ 必须来自三个不同组，不能从同一组取两个。
4. **`ans` 初值取 $-1$ 或 `INT_MIN`**：题目要求无解返回 0，若用 `INT_MIN` 直接返回会得到负数；用 0 作初值最省事（$nums[i] \ge 1$ 保证合法和为正）。
5. **`n = 3`**：只有唯一三元组，若不满足四种模式则为 0。
6. **只有一组有元素**：如 `[3,6,9]`，模式 A 命中，答案 18；其他模式天然不可行。
7. **排序方向**：降序取前三个最大；写成升序会取到最小的三个，答案偏小。
8. **值域与溢出**：$nums[i] \le 10^5$，三个之和 $\le 3 \times 10^5$，`int` 足够。
