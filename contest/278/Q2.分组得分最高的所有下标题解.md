# LeetCode 分组得分最高的所有下标 题解

## 1. 题目概述

- **标题 / 题号**：分组得分最高的所有下标（#2155，medium）
- **链接**：https://leetcode.cn/problems/all-divisions-with-the-highest-score-of-a-binary-array/
- **来源**：LeetCode 第 278 场周赛 Q2
- **难度**：中等
- **标签**：数组、前缀和、一次遍历

**题意**：给定下标从 0 开始、长度为 $n$ 的二进制数组 `nums`。枚举切点 $i$（$0 \le i \le n$），把数组切成 `numsleft = nums[0..i-1]` 与 `numsright = nums[i..n-1]` 两段（均可为空）。切点 $i$ 的**分组得分** = `numsleft` 中 **0** 的个数 + `numsright` 中 **1** 的个数。返回得分**最高**的所有不同下标，顺序任意。

**约束**：

- $1 \le n \le 10^5$
- `nums[i]` 为 `0` 或 `1`

> 💡 切点共有 $n+1$ 个（$0 \sim n$，含两端的"空切"），这是本题第一个易漏的细节。

## 2. 示例

**示例 1**

```text
输入：nums = [0,0,1,0]
输出：[2,4]
解释：五个切点的得分依次为 1, 2, 3, 2, 3。
     i=2：left=[0,0], right=[1,0]     → 2 + 1 = 3
     i=4：left=[0,0,1,0], right=[]    → 3 + 0 = 3
     两个切点并列最高，[4,2] 同样正确。
```

**示例 2**

```text
输入：nums = [0,0,0]
输出：[3]
解释：得分依次 0, 1, 2, 3 —— 全 0 数组切得越靠右越好，右端点独占最高分。
```

**示例 3**

```text
输入：nums = [1,1]
输出：[0]
解释：得分依次 2, 1, 0 —— 全 1 数组切得越靠左越好，左端点独占最高分。
```

## 3. 解题思路

### 3.1 暴力思路

对每个切点 $i$（共 $n+1$ 个）分别扫描两侧：数 `numsleft` 中的 0、数 `numsright` 中的 1，总代价 $O(n^2)$。$n = 10^5$ 时约 $10^{10}$ 次数组访问，**超时**。

浪费显而易见：相邻切点 $i$ 与 $i+1$ 的两侧只差**一个元素** `nums[i]`（它从右侧跨过切线进入左侧），暴力却把几乎相同的区间重复扫了 $n+1$ 遍。突破口就是把这个"跨线元素"的效应单独算清。

### 3.2 核心观察：切点右移时只有一个元素跨线

![核心观察：切点得分=左侧0数+右侧1数，右移一格增量±1](images/2155_contest_split_concept.svg)

记 $z(i)$、$o(i)$ 为前 $i$ 个元素中 0、1 的个数，$T_1$ 为全数组 1 的总数。由于右侧恰是前缀之外的补集：

$$\text{score}(i) = z(i) + \bigl(T_1 - o(i)\bigr)$$

切点从 $i$ 右移到 $i+1$ 时，`nums[i]` 跨线：若是 0，左侧 0 数 +1；若是 1，右侧 1 数 −1。两种情况都只动**一个**计数器：

$$\text{score}(i+1) - \text{score}(i) = 1 - 2 \cdot \text{nums}[i] = \begin{cases}+1 & \text{nums}[i] = 0 \\ -1 & \text{nums}[i] = 1\end{cases}$$

于是 $n+1$ 个得分可以像**前缀和**一样从左到右一趟递推出来，每步 $O(1)$。

> 💡 **游走视角**：把 0 记作 $+1$、1 记作 $-1$，则 $\text{score}(i) = T_1 + W(i)$（$W$ 为该 ±1 序列的前 $i$ 项和）。得分序列是一条步长 ±1 的游走——遇 0 上坡、遇 1 下坡，**最高得分下标就是游走的峰值平台**。这一视角把本题归入「重赋值 + 前缀和极值定位」家族。

### 3.3 算法流程

![算法流程：一趟扫描，先算分后更新维护argmax](images/2155_contest_sweep_flow.svg)

1. **初始化**：`leftZeros = 0`，`rightOnes = sum(nums)`（即切点 0 的两侧现状），`best = -1`，`ans = []`；
2. **遍历** $i$ 从 $0$ 到 $n$（共 $n+1$ 个切点）：
   1. **算分**：`score = leftZeros + rightOnes`；
   2. **维护 argmax**：`score > best` 则重置 `best = score, ans = [i]`；`score == best` 则追加 `i`；
   3. **更新**（仅当 $i < n$）：`nums[i] == 0` 则 `leftZeros++`，否则 `rightOnes--`；
3. 返回 `ans`。

> ⚠️ **顺序铁律**：先算分、后更新。算分用的是"当前切点"的两侧归属，而 `nums[i]` 在切点 $i$ 处还属右侧、到 $i+1$ 才属左侧——若先更新再算分，相当于把切点整体错位一格（见 §8）。

### 3.4 示例演算

![示例演算：五个切点得分表与游走](images/2155_contest_walkthrough.svg)

以 `nums = [0,0,1,0]` 为例，`leftZeros` 初值 0、`rightOnes` 初值 1：

| i | numsleft | numsright | leftZeros | rightOnes | score | 更新（为下一格） |
|---|----------|-----------|-----------|-----------|-------|------------------|
| 0 | `[]` | `[0,0,1,0]` | 0 | 1 | 1 | 吃 0 → leftZeros＋1 |
| 1 | `[0]` | `[0,1,0]` | 1 | 1 | 2 | 吃 0 → leftZeros＋1 |
| 2 | `[0,0]` | `[1,0]` | 2 | 1 | **3 ★** | 吃 1 → rightOnes−1 |
| 3 | `[0,0,1]` | `[0]` | 2 | 0 | 2 | 吃 0 → leftZeros＋1 |
| 4 | `[0,0,1,0]` | `[]` | 3 | 0 | **3 ★** | —（i = n 收尾） |

得分序列 $1,2,3,2,3$：$i=2$ 与 $i=4$ 并列最高，答案 `[2, 4]`。注意并列的两条来路不同——$i=2$ 是"左侧 0 已达 2、右侧 1 尚在"的山峰，$i=4$ 是"左侧 0 吃满 3、右侧 1 已清空"的收尾，两条路径恰好凑出同一个 3。

## 4. 算法细节

1. **初始化即切点 0**：`leftZeros = 0`（左侧空）、`rightOnes = Σnums`（右侧为全数组）。两端"空切"天然被循环覆盖，无需特判。
2. **argmax 维护免哈希**：刷新时 `ans = [i]`（C++ 用 `clear()` + `push_back`），等值时追加。不需要"得分 → 下标列表"的哈希表，也不需要最后排序——$i$ 递增遍历，`ans` 天然升序。
3. **`best` 初值取 $-1$**：得分非负，$-1$ 保证首个切点必刷新；取 0 虽然本题也能过（可证 $\max \text{score} \ge \lceil n/2 \rceil \ge 1$），但那要额外论证，$-1$ 是不依赖任何推理的安全写法。
4. **更新的越界守卫**：`i = n` 时读 `nums[n]` 越界（C++ 中是未定义行为而非报错，更隐蔽），更新必须包在 `if (i < n)` 里。
5. **闭式与单变量写法**：由 $z(i) = i - o(i)$ 代入引理 1 得 $\text{score}(i) = i + T_1 - 2\,o(i)$，于是只需维护一个计数器 $o(i)$；或直接维护 `score` 本身：`score += 1 - 2 * nums[i]`。三种写法（双计数器 / 单计数器 / 单得分）完全等价，见 §7。
6. **前缀和数组版本**：预处理 `preZeros`、`preOnes` 后 $\text{score}(i) = \text{preZeros}[i] + (\text{preOnes}[n] - \text{preOnes}[i])$，时间同为 $O(n)$、空间 $O(n)$。滚动计数把它压缩到 $O(1)$，是更优实现。

## 5. 正确性证明

**引理 1**（得分公式）：对任意 $0 \le i \le n$，$\text{score}(i) = z(i) + T_1 - o(i)$。

**证明**：`numsleft = nums[0..i-1]` 中 0 的个数按定义为 $z(i)$。`numsright = nums[i..n-1]` 是全数组去掉前 $i$ 位后的剩余，其中 1 的个数 = 全数组 1 的总数 − 前 $i$ 位中 1 的个数 = $T_1 - o(i)$。二者相加即得。∎

**引理 2**（增量递推）：对 $0 \le i < n$，$\text{score}(i+1) = \text{score}(i) + 1 - 2 \cdot \text{nums}[i]$。

**证明**：$z(i+1) = z(i) + [\text{nums}[i] = 0]$，$o(i+1) = o(i) + [\text{nums}[i] = 1]$。由引理 1，

$$\text{score}(i+1) - \text{score}(i) = [\text{nums}[i] = 0] - [\text{nums}[i] = 1].$$

`nums[i]` 取 0 时右端为 $+1$，取 1 时为 $-1$，统一写成 $1 - 2 \cdot \text{nums}[i]$。∎

**引理 3**（循环不变量）：算法处理切点 $i$ **之前**，恒有 `leftZeros` $= z(i)$ 且 `rightOnes` $= T_1 - o(i)$。

**证明**：对 $i$ 归纳。$i = 0$：初始化给出 `leftZeros` $= 0 = z(0)$、`rightOnes` $= \Sigma\text{nums} = T_1 = T_1 - o(0)$。设处理 $i$ 前不变量成立。算法在处理完切点 $i$ 后执行更新：若 `nums[i] = 0`，则 `leftZeros` 增 1（对应 $z(i+1) = z(i) + 1$），`rightOnes` 不变（对应 $T_1 - o(i+1) = T_1 - o(i)$）；若 `nums[i] = 1`，则 `rightOnes` 减 1（对应 $T_1 - o(i+1) = T_1 - o(i) - 1$），`leftZeros` 不变。两种情况均给出处理 $i+1$ 前不变量成立。$i = n$ 时不再更新，循环结束。∎

**定理**：算法返回的 `ans` 恰为 $\{\, i : \text{score}(i) = \max_{0 \le j \le n} \text{score}(j) \,\}$，且按 $i$ 升序排列。

**证明**：由引理 3，循环体在切点 $i$ 处计算的 `score` 等于真实 $\text{score}(i)$，比较对象无误。`best` 只在遇到严格更大得分时被抬高且从不降低，故循环结束时 `best` $= \max_j \text{score}(j)$；重置/追加规则保证：出现严格更大得分时，此前收集的下标被清空且 `best` 同步抬升，此后凡得分等于 `best` 的下标必被追加、小于 `best` 的必被跳过。又 $i$ 严格递增地遍历 $0..n$，`ans` 升序。故 `ans` 恰为全部取到最大得分的下标。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。求 `rightOnes` 初值一次 $O(n)$；主循环 $n+1$ 次，每次算分、比较、更新均为 $O(1)$。
- **空间复杂度**：$O(1)$。仅 `leftZeros`、`rightOnes`、`best`、`i` 等标量（输出数组不计入）。前缀和数组版本空间 $O(n)$，时间不变。

## 7. 参考代码

### C++（滚动双计数器）

```cpp
class Solution {
public:
    vector<int> maxScoreIndices(vector<int>& nums) {
        int n = nums.size();
        int leftZeros = 0;
        int rightOnes = accumulate(nums.begin(), nums.end(), 0);
        int best = -1;
        vector<int> ans;

        for (int i = 0; i <= n; ++i) {
            int score = leftZeros + rightOnes;
            if (score > best) {
                best = score;
                ans.clear();
                ans.push_back(i);
            } else if (score == best) {
                ans.push_back(i);
            }
            if (i < n) {
                if (nums[i] == 0) ++leftZeros;
                else              --rightOnes;
            }
        }
        return ans;
    }
};
```

### C++（单变量游走：直接递推得分）

```cpp
class Solution {
public:
    vector<int> maxScoreIndices(vector<int>& nums) {
        int n = nums.size();
        int score = accumulate(nums.begin(), nums.end(), 0); // score(0) = T1
        int best = -1;
        vector<int> ans;

        for (int i = 0; i <= n; ++i) {
            if (score > best) {
                best = score;
                ans = {i};
            } else if (score == best) {
                ans.push_back(i);
            }
            if (i < n) score += 1 - 2 * nums[i]; // 引理 2：±1 游走
        }
        return ans;
    }
};
```

### Python（滚动双计数器）

```python
class Solution:
    def maxScoreIndices(self, nums: List[int]) -> List[int]:
        n = len(nums)
        left_zeros, right_ones = 0, sum(nums)
        best, ans = -1, []

        for i in range(n + 1):
            score = left_zeros + right_ones
            if score > best:
                best, ans = score, [i]
            elif score == best:
                ans.append(i)
            if i < n:
                if nums[i] == 0:
                    left_zeros += 1
                else:
                    right_ones -= 1
        return ans
```

### Python（前缀和闭式：只维护 o(i)）

```python
class Solution:
    def maxScoreIndices(self, nums: List[int]) -> List[int]:
        n, total_ones = len(nums), sum(nums)
        ones = 0                      # o(i)：前 i 个元素中 1 的个数
        best, ans = -1, []

        for i in range(n + 1):
            score = i - 2 * ones + total_ones   # z(i) = i - o(i)
            if score > best:
                best, ans = score, [i]
            elif score == best:
                ans.append(i)
            if i < n:
                ones += nums[i]
        return ans
```

## 8. 边界情况与易错点

1. **切点有 $n+1$ 个**：`range(n + 1)` / `i <= n`，务必包含两端空切。全 1 数组的答案恰是 $[0]$（左空切）、全 0 数组的答案恰是 $[n]$（右空切）——漏掉端点，这两个用例会直接挂。
2. **先算分、后更新**：顺序颠倒后，切点 $i$ 处算出的是 $\text{score}(i+1)$，整体错位一格；$i = n$ 处还会多更新一次。这是本题最典型的实现 bug。
3. **`i = n` 时越界**：更新读的是 `nums[i]`，必须 `i < n` 守卫；C++ 越界读是未定义行为而非报错，本地可能"恰好能跑"。
4. **`best` 初值**：取 $-1$ 而非 $0$。虽然本题 $\max \text{score} \ge \max(T_1, z(n)) \ge \lceil n/2 \rceil \ge 1$ 使 0 也能侥幸通过，但 $-1$ 无需该论证，任何非负得分的同类题都安全。
5. **并列最高别绕路**：`>best` 重置、`=best` 追加两个分支足矣；先建"得分 → 下标列表"哈希再取 `max` 是多此一举（多一次遍历 + $O(n)$ 空间）。
6. **`n = 1` 只有两个切点**：如 `nums=[0]` 得分 $0, 1$，答案 `[1]`；`nums=[1]` 得分 $1, 0$，答案 `[0]`。循环边界写对即天然正确。
7. **返回顺序任意**：题目允许任意顺序，算法天然升序，无需排序去重。
