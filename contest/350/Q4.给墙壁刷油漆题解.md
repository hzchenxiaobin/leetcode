# LeetCode 给墙壁刷油漆 题解

## 1. 题目概述

- **标题 / 题号**：给墙壁刷油漆（#2742，hard）
- **链接**：https://leetcode.cn/problems/painting-the-walls/
- **来源**：LeetCode 第 350 场周赛 Q4
- **难度**：困难
- **标签**：数组、动态规划、0-1 背包

**题意**：给定长度为 $n$ 的数组 `cost` 与 `time`，刷 $n$ 堵墙时可动用两名油漆匠：**付费工匠**刷第 $i$ 堵墙耗时 $\text{time}[i]$、开销 $\text{cost}[i]$；**免费工匠**刷任意一堵墙耗时 $1$、开销 $0$，但只能与付费工匠**同时**工作。每堵墙恰被刷一次，返回刷完全部 $n$ 堵墙的最小总开销。

**约束**：

- $1 \le n \le 500$
- $1 \le \text{cost}[i] \le 10^6$
- $1 \le \text{time}[i] \le 500$

> 💡 **数据范围信号**：$n \le 500$ 指向 $O(n^2)$ 动态规划。乍看 $\text{time}[i]$ 大到 $500$，但把 dp 的第二维**封顶到 $n$** 后内层循环也只有 $O(n)$，总复杂度 $O(n^2)$ 恰好压线通过。

## 2. 示例

**示例 1**

```text
输入：cost = [1,2,3,2], time = [1,2,3,2]
输出：3
解释：墙 0、1 交给付费工匠（共 3 单位时间），期间免费工匠刷掉墙 2、3。总开销 1 + 2 = 3。
```

**示例 2**

```text

输出：4
解释：墙 0、3 交给付费工匠（共 2 单位时间），期间免费工匠刷掉墙 1、2。总开销 2 + 2 = 4。
```

```text
解释：只付费刷墙 0：耗时 10，期间免费工匠足够刷掉墙 1、2。覆盖量 10 + 1 = 11 ≥ 3，总开销 3。
```

## 3. 解题思路

### 3.1 暴力思路：枚举付费集合

每堵墙要么付费刷、要么免费刷，直接枚举付费集合 $S \subseteq \{0,\dots,n-1\}$：付费工匠串行刷完 $S$ 的总工时 $T = \sum_{i \in S} \text{time}[i]$，免费工匠只能在这段时间里干活、每堵墙 1 单位，故可行需 $n - |S| \le T$；在所有可行 $S$ 中取 $\sum_{i \in S} \text{cost}[i]$ 最小者。复杂度 $O(2^n)$，$n = 500$ 完全不可行。

> 💡 暴力虽不可行，却把问题说穿了：**方案只由集合 $S$ 决定，与墙的先后顺序无关**——这正是后续 DP 建模的立足点。

### 3.2 核心观察：付费刷墙 i ⇒ 覆盖 time[i] + 1 堵

"两名工匠并行"是题面最大的迷惑项。换个视角：付费工匠刷墙 $i$ 的 $\text{time}[i]$ 个单位里，免费工匠每一单位都能**白嫖**一堵免费墙；再加上墙 $i$ 本身也被刷掉——

$$\text{付费刷墙 } i \;\Longleftrightarrow\; \text{花 } \text{cost}[i] \text{，一次性覆盖 } \text{time}[i] + 1 \text{ 堵墙}$$

![核心观察：付费工匠的工时就是免费工匠的白嫖窗口](images/paint_walls_cover_concept.svg)

于是"调度问题"坍缩成纯粹的**选集合**问题（可行性刻画的严格证明见第 5 节引理 1）：

$$\text{原问题} \;\Longleftrightarrow\; \min_{S} \sum_{i \in S} \text{cost}[i] \quad \text{s.t.} \quad \sum_{i \in S} \big(\text{time}[i] + 1\big) \;\ge\; n$$

这正是 **0-1 背包**：墙 $i$ 是重量 $w_i = \text{time}[i] + 1$、价值 $c_i = \text{cost}[i]$ 的物品，背包容量为 $n$，且是**至少装满**而非恰好装满——覆盖量允许过剩，免费工匠闲着不要钱。

![问题转化：两名油漆匠 → 至少装满型 0-1 背包](images/paint_walls_knapsack_model.svg)

### 3.3 算法流程：一维滚动 0-1 背包

定义 $\mathrm{dp}[j]$ = 已决策的墙中选出的付费子集满足 $\sum w_i \ge j$ 的最小总开销（$j$ 封顶到 $n$）。采用 0-1 背包一维滚动：对每堵墙 $i$ **倒序**枚举 $j = n \dots 1$：

$$\mathrm{dp}[j] \;=\; \min\Big(\mathrm{dp}[j],\;\; \mathrm{dp}\big[\max(0,\; j - w_i)\big] + \text{cost}[i]\Big)$$

```text
初始化：dp[0] = 0，dp[1..n] = +∞
for i = 0 .. n-1：                       # 每堵墙 = 一个物品
    w = time[i] + 1, c = cost[i]
    for j = n .. 1（倒序）：             # 0-1 背包防复用
        dp[j] = min(dp[j], dp[max(0, j - w)] + c)
答案：dp[n]
```

其中 $\max(0, \cdot)$ 是"至少装满"的**需求封顶**：当 $w_i \ge j$ 时，单独这堵墙就已覆盖需求 $j$，剩余需求归零（示例 3 正是这种"一堵墙搞定全部"的情形）。

### 3.4 示例演算

以示例 2 `cost = [2,3,4,2]`、`time = [1,1,1,1]` 为例：$n = 4$，四个物品 $(w, c)$ 依次为 $(2,2),(2,3),(2,4),(2,2)$：

![示例 2 演算：dp 数组的四轮演化](images/paint_walls_dp_walkthrough.svg)

- **物品 1**：$j=2$ 由 $\mathrm{dp}[0]+2=2$ 首次更新；$j=1$ 因 $w=2>j$ 走 $\max(0, 1-2)=0$ 同样得 2。
- **物品 2**：$j=4,3$ 由 $\mathrm{dp}[2]+3=\mathrm{dp}[1]+3=5$ 首次更新；$j=2,1$ 因候选 $3>2$ 保持。
- **物品 3**：$c=4$ 处处不更优，**整轮无更新**——一维 DP 的常态，不必惊慌。
- **物品 4**：$j=4,3$ 由 $\mathrm{dp}[2]+2=\mathrm{dp}[1]+2=4$ 压到 4 ⭐，对应付费刷墙 0 与墙 3（$2+2=4 \ge 4$，开销 $2+2=4$）。

## 4. 算法细节

1. **物品建模**：$w_i = \text{time}[i] + 1$ 中的"+1"来自墙 $i$ 自身，"$\text{time}[i]$"来自并行白嫖的免费墙额度。漏掉 +1 是最常见的建模错误。
2. **"至少"型封顶**：需求 $j$ 只开到 $n$；转移下标 $\max(0, j - w_i)$ 把过剩覆盖折算到 0。与"恰好装满"型背包对照：后者初始化同样仅 $\mathrm{dp}[0]=0$、其余 $+\infty$，但下标**不封顶**，$j$ 维要开到 $\sum w_i$。
3. **倒序枚举**：$j - w_i < j$，倒序保证读到的 $\mathrm{dp}[j - w_i]$ 是上一轮（未含墙 $i$）的值；正序则同一堵墙可能在一轮内被复用，退化成完全背包。
4. **$\mathrm{dp}[0]$ 恒为 0**：任何集合（含空集）都满足"覆盖 $\ge 0$"，因此 $j$ 只需枚举到 $1$，$j=0$ 永不更新也永不需要。
5. **INF 的取法**：C++ 中取 $10^9$ 即可——$\mathrm{dp}[\text{prev}] + \text{cost}[i] \le 10^9 + 10^6 < 2^{31} - 1$，`int` 相加不溢出；若拿 `INT_MAX` 当 INF，相加立刻爆 `int` 回绕成负数，`min` 取到错误值。稳妥写法是先判 `dp[prev] != INF` 再加。
6. **答案必有解**：$\text{time}[i] \ge 1 \Rightarrow w_i \ge 2$，全付费集合满足 $\sum w_i \ge 2n > n$ 必然可行，故 $\mathrm{dp}[n]$ 必为有限值，无需无解特判。
7. **（可选）剪枝**：处理第 $i$ 堵墙时，$j$ 实际只需枚举到 $\min\big(n, \sum_{k \le i} w_k\big)$——超出前缀总体积的需求本轮不可能首次满足。$n \le 500$ 时收益有限，可省。

## 5. 正确性证明

**引理 1（可行性刻画）**：设付费墙集合为 $S$，$T = \sum_{i \in S} \text{time}[i]$。刷完全部 $n$ 堵墙的调度存在 $\iff |S| + T \ge n$。

**证明**：
（⇒）付费工匠串行刷 $S$ 中的墙，不妨将其施工段首尾相接（不改变总时长），总工作时长恰为 $T$。免费工匠只能在付费工匠工作的同时工作，可工作总时长 $\le T$；免费墙共 $n - |S|$ 堵、每堵恰 1 单位时间，故 $n - |S| \le T$。

（⇐）将 $S$ 中的墙按任意顺序排成付费工匠的连续日程，施工区间 $[0, T]$。由 $n - |S| \le T$，可把 $n - |S|$ 堵免费墙依次安排在 $[0,\; n - |S|] \subseteq [0, T]$ 内（每堵 1 单位、互不重叠）。两名工匠全程互不冲突，$n$ 堵墙全部刷完。∎

**引理 2（单调性与封顶合法）**：任意轮次中 $\mathrm{dp}$ 关于 $j$ 单调不增；且"覆盖 $\ge j - w$"的最优值与"覆盖 $\ge \max(0,\, j - w)$"的最优值相等。

**证明**：单调性来自可行集的包含关系——$j \ge j'$ 时 $\{S : \sum_{i \in S} w_i \ge j\} \subseteq \{S : \sum_{i \in S} w_i \ge j'\}$，可行域变小，最小值只增不减。当 $j - w \le 0$ 时，"覆盖 $\ge j - w$"被包括空集在内的**一切**子集满足，与"覆盖 $\ge 0$"的可行域完全相同，故两者最优值相等，均为封顶后的 $\mathrm{dp}[0]$ 起算。∎

**引理 3（递推不变式）**：以 $\mathrm{dp}_k[j]$ 表示处理完前 $k$ 堵墙后的数组，则对一切 $0 \le j \le n$：

$$\mathrm{dp}_k[j] \;=\; \min\Big\{ \sum_{i \in S} \text{cost}[i] \;:\; S \subseteq \{0,\dots,k-1\},\;\; \sum_{i \in S} w_i \ge j \Big\}$$

（该最小值不存在时记 $+\infty$；$j = 0$ 时空集合法，故恒为 $0$。）

**证明**（对 $k$ 归纳）：$k = 0$ 时唯一子集为空集，仅 $j = 0$ 可满足，与初始化一致。

设结论对 $k$ 成立。对前 $k+1$ 堵墙与需求 $j$，最优子集按"墙 $k$ 是否入选"划分为互不相交的两类：

- **$k \notin S$**：$S$ 本身就是前 $k$ 堵墙的合法子集，反之 $\mathrm{dp}_k[j]$ 的最优子集也不含 $k$。由归纳假设，本类最优值 $= \mathrm{dp}_k[j]$。
- **$k \in S$**：记 $S = S' \cup \{k\}$，则 $S' \subseteq \{0,\dots,k-1\}$ 须满足 $\sum_{i \in S'} w_i \ge j - w_k$。由引理 2，该约束与 $\sum_{i \in S'} w_i \ge \max(0, j - w_k)$ 同解，故本类最优值 $= \mathrm{dp}_k[\max(0,\, j - w_k)] + \text{cost}[k]$。

两类之并恰为全部子集，故

$$\mathrm{dp}_{k+1}[j] \;=\; \min\Big(\mathrm{dp}_k[j],\;\; \mathrm{dp}_k\big[\max(0,\, j - w_k)\big] + \text{cost}[k]\Big)$$

一维滚动倒序枚举时，$\max(0, j - w_k) \le j$ 尚未被本轮更新，读到的正是 $\mathrm{dp}_k$ 的值，与上式一致。∎

**定理**：算法返回的 $\mathrm{dp}[n]$ 即刷完全部墙的最小总开销。

**证明**：由引理 1，合法付费集合恰为满足 $\sum_{i \in S} w_i \ge n$ 的全体 $S$；由引理 3（取 $k = n,\ j = n$），$\mathrm{dp}[n]$ 恰为其中的最小总开销。由第 4 节第 6 点，$\mathrm{dp}[n] < +\infty$，最优解总存在。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n^2)$。外层 $n$ 堵墙、内层 $j$ 至多 $n$ 个取值，$n = 500$ 时约 $2.5 \times 10^5$ 次转移，毫秒级。关键在于 $j$ 维封顶到 $n$ 而非 $\sum \text{time}[i]$（后者最大 $2.5 \times 10^5$）——这是"至少装满 + 需求封顶"写法的最大收益。
- **空间复杂度**：$O(n)$。一维滚动数组 $n + 1$ 个元素。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int paintWalls(vector<int>& cost, vector<int>& time) {
        int n = cost.size();
        const int INF = 1e9;
        vector<int> dp(n + 1, INF);
        dp[0] = 0;                                // 覆盖 >= 0：空集，开销 0
        for (int i = 0; i < n; ++i) {
            int w = time[i] + 1, c = cost[i];     // 物品：墙自身 + 白嫖额度
            for (int j = n; j >= 1; --j) {        // 倒序：0-1 背包防复用
                int prev = max(0, j - w);        // 至少装满：需求封顶
                if (dp[prev] < INF) dp[j] = min(dp[j], dp[prev] + c);
            }
        }
        return dp[n];
    }
};
```

### Python

```python
class Solution:
    def paintWalls(self, cost: List[int], time: List[int]) -> int:
        n = len(cost)
        dp = [0] + [float('inf')] * n
        for c, t in zip(cost, time):
            w = t + 1
            for j in range(n, 0, -1):
                dp[j] = min(dp[j], dp[max(0, j - w)] + c)
        return dp[n]
```

> 💡 另一等价视角是记忆化 DFS：维护"免费工匠的时长余额"，付费刷墙使余额 $+\text{time}[i]$、免费刷墙使余额 $-1$，处理完全部墙后要求余额非负（墙的顺序可任意重排，故中途允许欠账）。两种视角殊途同归，复杂度同为 $O(n^2)$。

## 8. 边界情况与易错点

1. **INF 溢出**：C++ 用 `INT_MAX` 当 INF 时 `INF + cost` 溢出回绕成负数，`min` 直接过掉正确答案。取 $10^9$（相加不超过 $1.001 \times 10^9 < 2^{31}-1$）或加前先判 `dp[prev] != INF`。
2. **忘了 $\max(0,\, j - w)$**：$j - w < 0$ 时下标为负——C++ 直接越界 UB，Python 负索引**静默读到数组尾部**，是最隐蔽的 WA 来源。
3. **正序枚举 $j$**：一维 0-1 背包正序会把本轮刚更新的值当上轮用，同一堵墙被重复"白嫖"，退化成完全背包、答案偏小。
4. **误建模成"恰好装满"**：覆盖量允许过剩（免费工匠可闲置），示例 3 里 $\sum w = 11 \ge 3$ 的方案合法；若强行"恰好 $n$"会漏掉所有过剩覆盖解。
5. **漏掉 $w_i$ 的 +1**：把重量写成 $\text{time}[i]$ 会漏算墙 $i$ 自身，示例 2 将错算成只覆盖 $1+1=2 < 4$ 需要更多付费墙。
6. **别按性价比贪心**：0-1 背包没有贪心最优性。反例 `cost = [5,3,3], time = [100,1,1]`：按 $\text{cost}/w$ 贪心先选墙 1、2（性价比高），花费 6；最优只选墙 0，花费 5。
7. **$n = 1$ 无需特判**：$w_0 \ge 2 > 1$，$\mathrm{dp}[1] = \text{cost}[0]$ 自动成立（单堵墙付费刷、免费工匠全程闲着就是最优）。
8. **答案上界**：最坏全付费 $\sum \text{cost} \le 500 \times 10^6 = 5 \times 10^8$，`int` 装得下但已过 $2^{31}$ 的两成，别再叠加其他量纲（如再乘 $n$）。
9. **两个视角别混着写**：本题既可"覆盖量"（正向背包）也可"免费余额"（记忆化 DFS）建模，状态含义完全不同，混用两套下标必错。
