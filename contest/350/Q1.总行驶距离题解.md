# LeetCode 总行驶距离 题解

## 1. 题目概述

- **标题 / 题号**：总行驶距离（#2739，easy）
- **链接**：https://leetcode.cn/problems/total-distance-traveled/
- **来源**：LeetCode 第 350 场周赛 Q1
- **难度**：简单
- **标签**：数学、模拟

**题意**：卡车有主、副两个油箱，初始燃料分别为 `mainTank` 与 `additionalTank` 升。每消耗 1 升燃料行驶 $10\ \mathrm{km}$；每当主油箱累计用掉 $5$ 升燃料时，若副油箱还有至少 $1$ 升，则立即从副油箱向主油箱注入 $1$ 升。求卡车能行驶的最大总距离。

**约束**：

- $1 \le \mathrm{mainTank}, \mathrm{additionalTank} \le 100$

> 💡 签到题两个读题点：① 注入是**离散事件**——只在累计耗油到达 $5, 10, 15, \dots$ 的整点瞬间发生，不是按比例连续兑换；② 触发时只看副油箱**是否非空**，与剩余多少无关。数据范围小到模拟随手过，但这类「消耗-补给」题的套路沉淀是：**数清轮数，一笔写出 $O(1)$ 公式**。

## 2. 示例

**示例 1**

```text
输入：mainTank = 5, additionalTank = 10
输出：60
解释：耗掉 5 升（50 km）后主油箱清零，但恰好凑满第 1 个里程碑，
      副油箱注入 1 升；再耗掉这 1 升（10 km）。
      总计 5 + 1 = 6 升 → 60 km。
```

**示例 2**

```text
输入：mainTank = 1, additionalTank = 2
输出：10
解释：主油箱不足 5 升，一个里程碑都到不了，副油箱全程没机会注入。
      总计消耗 1 升 → 10 km。
```

**示例 3**（自拟，覆盖「补回来的油再次触发转移」）

```text
输入：mainTank = 9, additionalTank = 2
输出：110
解释：第 1 轮耗 5 升（主 9→4），注入后回到 5 升（副 2→1）；
      第 2 轮再耗 5 升（主 5→0），注入后剩 1 升（副 1→0）；
      最后零头 1 升耗尽。总计 9 + 2 = 11 升 → 110 km。
      若 additionalTank = 1，则只有第 1 轮转移，答案为 100 km。
```

## 3. 解题思路

### 3.1 暴力思路：逐升模拟

最朴素的写法是**逐升消耗**：每烧 1 升加 $10\ \mathrm{km}$，用一个计数器记录「距上个里程碑又烧了几升」，凑满 $5$ 升就尝试注入。总步数不超过 $m + a \le 200$，轻松通过。

逐升模拟正确但琐碎；周赛里更快、更不容易写错的版本是**按 5 升一轮批量模拟**：只要主油箱 $\ge 5$ 升，就一轮烧掉 $5$ 升、里程加 $50\ \mathrm{km}$，随后若副油箱非空就补 $1$ 升。循环至多 $\lceil 100/4 \rceil = 25$ 轮。

```text
while main >= 5:
    main -= 5          # 一轮烧 5 升
    dist += 50
    if add >= 1:       # 里程碑判定在烧完 5 升之后
        add -= 1
        main += 1
dist += main * 10      # 零头直接折算里程
```

### 3.2 核心观察：一轮「净耗 4 升」，直接数轮数

![核心观察：每轮净耗4升与里程碑公式](images/total_distance_net4_cycle.svg)

把「烧 5 升 + 补 1 升」视作**一轮**，则每轮的净变化是：主油箱 $-4$ 升、副油箱 $-1$ 升、里程 $+50\ \mathrm{km}$。于是转移次数被两个条件同时卡住：

1. **副油箱总量**：至多转移 $a$ 次；
2. **里程碑个数**：第 $k$ 次转移发生在「原始主油恰好累计消耗 $4k+1$ 升」的瞬间（前 $k-1$ 次转移补回的 $k-1$ 升也都烧掉了），故需要 $4k+1 \le m$，即 $k \le \lfloor (m-1)/4 \rfloor$。

两者取最小即为实际转移次数

$$t = \min\!\left(a,\ \left\lfloor \frac{m-1}{4} \right\rfloor\right),$$

而过程结束时主油箱必然耗尽（零头 $\le 4$ 升不够凑下一个里程碑，只能烧掉），总耗油恰为 $m + t$ 升，因此

$$\text{答案} = 10 \times (m + t)\ \mathrm{km}.$$

### 3.3 算法流程

![双油箱机制与里程碑触发流程](images/total_distance_fuel_flow.svg)

**公式版**（$O(1)$）：

```text
1. t = min(additionalTank, (mainTank - 1) / 4)   # 整除
2. 返回 10 * (mainTank + t)
```

**模拟版**（$O(m)$）：见 3.1 的批量循环。两者对任意输入等价（见第 5 节证明）。

### 3.4 示例演算

![示例演算：m=9, a=2 的完整走查](images/total_distance_example_walkthrough.svg)

以 $m = 9,\ a = 2$ 为例（完整走查见上图）：两轮各净耗 $4$ 升后主油箱剩 $1$ 升零头，副油箱恰好用光，总耗油 $9 + 2 = 11$ 升，行驶 $110\ \mathrm{km}$。注意第 1 轮补回的 $1$ 升正是第 2 轮能凑满 $5$ 升的原因——「补回来的油还能再触发转移」是这类题最容易漏算的一环。

## 4. 算法细节

1. **公式推导的关键一步**：第 $k$ 个里程碑对应主油箱**累计**消耗 $5k$ 升，其中 $k-1$ 升来自之前的转移补给，所以**原始主油**被消耗 $5k - (k-1) = 4k+1$ 升。这就是上界 $\lfloor (m-1)/4 \rfloor$ 的来源。
2. **两个上界取 min**：副油箱再多也不能超额转移（$a=100,\ m=5$ 时 $t=1$ 而非 $100$）；主油箱再多、副油箱空了也不再补。
3. **模拟版的循环条件必须含等号**（`main >= 5`）：主油箱恰有 5 升时烧完后归零，但里程碑照样触发注入（示例 1 正是如此）。写成 `main > 5` 会在 $m=5$ 这类点白丢 10 km。
4. **转移判定在扣完 5 升之后**：先 `main -= 5` 再判断注入，顺序反了会凭空多算一轮。
5. **零头处理**：循环结束时主油箱剩余 $m - 4t \in [1, 4]$ 升，直接乘 10 计入里程，不再触发任何转移。

## 5. 正确性证明

**引理 1**：第 $k$ 次转移能够发生，当且仅当 $m \ge 4k+1$ 且 $a \ge k$。

**证明**：记主油箱累计消耗到达 $5k$ 升的时刻为第 $k$ 个里程碑。先证不变量：**若前 $k-1$ 次转移全部发生，则第 $k$ 个里程碑处原始主油恰被消耗 $4k+1$ 升**。对 $k$ 归纳：$k=1$ 时消耗的 $5$ 升全部来自原始主油，$4 \cdot 1 + 1 = 5$ 成立。设结论对 $k$ 成立且第 $k$ 次转移发生，则从该里程碑到下一个恰好再烧 $5$ 升，其中 $1$ 升来自第 $k$ 次转移的补给、$4$ 升来自原始主油，累计原始消耗 $4k+1+4 = 4(k+1)+1$，不变量延续。
   - **必要性**：若第 $k$ 次转移发生，则卡车到达过第 $k$ 个里程碑，原始主油被消耗 $4k+1$ 升，故 $m \ge 4k+1$；判定时前 $k-1$ 次转移已取走 $k-1$ 升且本次再取 $1$ 升，故 $a \ge k$。
   - **充分性**：设 $m \ge 4k+1,\ a \ge k$ 且前 $k-1$ 次转移已发生。第 $k-1$ 次转移结束后主油箱存量 $= m + (k-1) - 5(k-1) = m - 4(k-1) \ge 5$，足以烧到第 $k$ 个里程碑；此时副油箱剩余 $a - (k-1) \ge 1$，第 $k$ 次转移必然触发。∎

**定理**：卡车最大行驶距离为 $10 \times \bigl(m + \min(a, \lfloor (m-1)/4 \rfloor)\bigr)$ 千米。

**证明**：实际转移次数 $t$ 是满足引理 1 两条件的最大 $k$（各条件关于 $k$ 单调，前缀可行），即 $t = \min\!\bigl(a,\ \max\{k : 4k+1 \le m\}\bigr) = \min\bigl(a, \lfloor (m-1)/4 \rfloor\bigr)$。过程终止时主油箱必然耗尽：若因 $m < 4(t+1)+1$ 停止，主油箱剩余 $m - 4t \in [1, 4]$ 升作为零头被烧完且不再触发转移；若因副油箱耗尽停止，剩余的 $m - 4t$ 升同样全部烧完（后续里程碑即使到达也无油可补）。于是总耗油 $= m + t$ 升，每升行驶 $10\ \mathrm{km}$，总距离 $= 10(m+t)$。∎

## 6. 复杂度分析

- **时间复杂度**：公式版 $O(1)$，只有一次 `min` 与一次整除；模拟版 $O(m)$（每轮主油箱净减 $4$ 升，$m \le 100$ 时至多 $25$ 轮）。本题范围下两者都远低于限制。
- **空间复杂度**：$O(1)$，只用到常数个变量。

## 7. 参考代码

### C++（$O(1)$ 公式）

```cpp
class Solution {
public:
    int distanceTraveled(int mainTank, int additionalTank) {
        int t = min(additionalTank, (mainTank - 1) / 4);
        return 10 * (mainTank + t);
    }
};
```

### Python（按 5 升批量模拟）

```python
class Solution:
    def distanceTraveled(self, mainTank: int, additionalTank: int) -> int:
        dist = 0
        while mainTank >= 5:
            mainTank -= 5
            dist += 50
            if additionalTank >= 1:
                additionalTank -= 1
                mainTank += 1
        return dist + mainTank * 10
```

两种写法等价（第 5 节定理），比赛时按手速任选；面试或数据范围放大（如 $m \le 10^9$）时优先公式版。

## 8. 边界情况与易错点

1. **$m < 5$（含 $m = 1$）**：一个里程碑都到不了，答案就是 $10m$。公式中 $\lfloor (m-1)/4 \rfloor = 0$ 自动处理，无需特判。
2. **主油箱恰好烧到 0 也要注入**：$m = 5$ 时烧完 5 升主油箱归零，但里程碑已凑满，注入照常发生。模拟循环条件写 `main >= 5` 而非 `main > 5`，否则示例 1 会输出 50 而非 60。
3. **副油箱不能超额转移**：$t$ 被 $\min(a, \lfloor (m-1)/4 \rfloor)$ 双重截断，$a = 100,\ m = 5$ 时 $t = 1$。
4. **补回来的油还能再触发**：$m = 9,\ a = 2$ 两次转移都发生；数轮数时别把转移进来的油漏算进后续里程碑。
5. **别连续化理解**：「每 4 升换 1 升」的比例式兑换是错的——转移只发生在 $5$ 的倍数里程碑上，最后 $1 \sim 4$ 升零头不参与兑换。
6. **溢出**：最大答案 $10 \times (100 + 24) = 1240\ \mathrm{km}$，`int` 绰绰有余；若数据放大需改 `long long`，公式版依然 $O(1)$。
