# LeetCode 找出分区值 题解

## 1. 题目概述

- **标题 / 题号**：找出分区值（#2740，medium）
- **链接**：https://leetcode.cn/problems/find-the-value-of-the-partition/
- **来源**：LeetCode 第 350 场周赛 Q2
- **难度**：中等
- **标签**：数组、排序

**题意**：给定一个正整数数组 `nums`，把它划分成两个**非空**数组 `nums1` 和 `nums2`（每个元素恰好属于其中一个）。分区值定义为 $\left|\max(\mathrm{nums1}) - \min(\mathrm{nums2})\right|$，求所有划分方案能取得的最小分区值。

**约束**：

- $2 \le n \le 10^5$
- $1 \le \mathrm{nums}[i] \le 10^9$

> 💡 本题本质是「一维最近点对」的换装：分区值只由 $\max(\mathrm{nums1})$ 与 $\min(\mathrm{nums2})$ 这**一对元素**决定，而一对元素之差想要小，排序后必然**相邻**——答案就是排序后的**最小相邻差**。示例 2 官方给的是交错划分（`nums2 = [100, 1]`，$\min = 1$），这是烟雾弹：它取得的 $9$ 恰好等于最小相邻差，交错划分并不能突破这个下界。

## 2. 示例

**示例 1**

```text
输入：nums = [1,3,2,4]
输出：1
解释：取 nums1 = [1,2]，nums2 = [3,4]，分区值 = |2 - 3| = 1。
```

**示例 2**

```text
输入：nums = [100,1,10]
输出：9
解释：官方解释取 nums1 = [10]，nums2 = [100,1]，分区值 = |10 - 1| = 9。
```

**示例 3**（自拟，覆盖「重复元素 → 答案 0」）

```text
输入：nums = [5,5,3]
输出：0
解释：两个 5 分居两侧：nums1 = [5]，nums2 = [5,3]，分区值 = |5 - 5| = 0。
```

## 3. 解题思路

### 3.1 暴力思路：枚举划分

每个元素有 $2$ 种归属，共有 $2^n - 2$ 种非空划分，对每种划分求 $\max/\min$ 再取绝对值差。$n \le 10^5$ 时是天文数字，完全不可行。即使退一步只枚举「哪个元素当 $\max(\mathrm{nums1})$、哪个当 $\min(\mathrm{nums2})$」也有 $O(n^2)$ 对，仍然超时。

### 3.2 核心观察：排序 + 最小相邻差

![核心观察：排序后最小相邻差即为答案](images/partition_value_min_gap.svg)

分区值由两个**具体元素** $M = \max(\mathrm{nums1})$ 和 $m = \min(\mathrm{nums2})$ 决定。对任意一对元素，它们之差想要尽量小，在**排序后**必然表现为**相邻**：

1. **非相邻对之差 = 相邻差之和**：排序后位置 $p < q$ 的两个元素，$a[q] - a[p] = \sum_{k=p}^{q-1} \left(a[k+1] - a[k]\right)$。当 $q > p$ 时右边至少一项，每一项都不小于全局最小相邻差 $d$，故 $a[q] - a[p] \ge d$。
2. **相邻对可以取到 $d$**：设最小相邻差出现在位置 $i$（$a[i+1] - a[i] = d$），把排序数组在此处**切一刀**：$\mathrm{nums1} = \{a[0], \dots, a[i]\}$（前缀），$\mathrm{nums2} = \{a[i+1], \dots, a[n-1]\}$（后缀）。此时 $\max(\mathrm{nums1}) = a[i]$，$\min(\mathrm{nums2}) = a[i+1]$，分区值恰好为 $d$。

于是：**任何划分的分区值都被 $d$ 卡住下界，而前缀/后缀切分恰好取得 $d$**，答案就是排序后的最小相邻差。

> ⚠️ 示例 2 的官方划分 `nums1 = [10]`, `nums2 = [100, 1]` 是交错的（$\min(\mathrm{nums2}) = 1$ 排在 $\max(\mathrm{nums1}) = 10$ 前面），这**不违反**上面的观察：无论交错与否，$|M - m|$ 中值较小的那个元素在排序后总排在前面，两者之差仍 $\ge d$。

### 3.3 算法流程

![算法流程：排序 + 一次线性扫描](images/partition_value_flow.svg)

```text
1. 对 nums 升序排序，得 a[0..n-1]
2. 线性扫描：ans = min(a[i] - a[i-1])，i = 1..n-1
3. 返回 ans（即最小相邻差 d）
```

### 3.4 示例演算

以 `nums = [100,1,10]` 为例：排序得 $[1, 10, 100]$，相邻差为 $10-1=9$ 与 $100-10=90$，最小相邻差 $d = 9$。

- **前缀/后缀切分**：$\mathrm{nums1} = [1]$，$\mathrm{nums2} = [10, 100]$，分区值 $= |1 - 10| = 9$ ✓
- **官方交错划分**：$\mathrm{nums1} = [10]$，$\mathrm{nums2} = [100, 1]$，分区值 $= |10 - 1| = 9$ ✓

两种划分殊途同归——都取到了下界 $d = 9$。

## 4. 算法细节

1. **排序是唯一的重活**：排序后只需一次线性扫描维护最小相邻差，$O(n)$。
2. **为什么只看相邻对**：见 3.2 第 1 点——非相邻对之差是若干相邻差之和，不可能比最小相邻差更小。这也是「一维最近点对」的经典结论。
3. **切分方式不必真的构造**：题目只要返回分区值，不需要输出两个数组；前缀/后缀切分只是**可达性的证明手段**，代码里根本不用构造。
4. **重复元素自动处理**：两个相等元素排序后相邻，相邻差为 $0$，扫描自然返回 $0$（示例 3），无需特判。
5. **能否不排序**：求「任意两元素之差的最小值」基于比较的下界是 $\Omega(n \log n)$；值域高达 $10^9$，计数排序不划算，$O(n \log n)$ 的比较排序就是本题的最优路径。

## 5. 正确性证明

![正确性证明：下界与可达性夹逼](images/partition_value_proof.svg)

以下设排序后的数组为 $a[0] \le a[1] \le \dots \le a[n-1]$，相邻差 $g_k = a[k+1] - a[k] \ge 0$，$d = \min_{0 \le k \le n-2} g_k$。

**引理 1（任意对差的下界）**：对任意 $0 \le p < q \le n-1$，有 $a[q] - a[p] \ge d$。

**证明**：$a[q] - a[p] = \sum_{k=p}^{q-1} g_k$，共 $q - p \ge 1$ 项。由 $d$ 的定义每项 $g_k \ge d$，故和 $\ge d$。∎

**引理 2（任何划分的分区值 $\ge d$）**：对任意合法划分，设 $M = \max(\mathrm{nums1})$，$m = \min(\mathrm{nums2})$，则 $|M - m| \ge d$。

**证明**：$M$ 与 $m$ 是两个不同位置的元素（一个在 $\mathrm{nums1}$、一个在 $\mathrm{nums2}$）。

- 若 $M \ne m$：设它们在排序数组中的位置为 $p, q$，**值小者必然排在前面**（排序的单调性），于是 $|M - m| = a[\max(p,q)] - a[\min(p,q)] \ge d$（引理 1）。注意此论证不关心 $M > m$ 还是 $M < m$——交错划分与前后缀分离划分一视同仁。
- 若 $M = m = v$：分区值为 $0$；此时值为 $v$ 的元素至少出现两次（$M \in \mathrm{nums1}$、$m \in \mathrm{nums2}$ 是不同位置），排序后必有两个 $v$ 相邻，故 $d = 0$，$0 \ge d$ 成立。∎

**引理 3（$d$ 可达）**：设 $g_i = d$（$0 \le i \le n-2$），取 $\mathrm{nums1} = \{a[0], \dots, a[i]\}$，$\mathrm{nums2} = \{a[i+1], \dots, a[n-1]\}$，则该划分的分区值为 $d$。

**证明**：两个数组均非空（$i \ge 0$ 保证 $\mathrm{nums1}$ 非空，$i + 1 \le n - 1$ 保证 $\mathrm{nums2}$ 非空）。$\max(\mathrm{nums1}) = a[i]$，$\min(\mathrm{nums2}) = a[i+1]$，分区值 $= a[i+1] - a[i] = g_i = d$。∎

**定理**：最小分区值等于排序后的最小相邻差 $d$。

**证明**：引理 2 说明任何划分的分区值 $\ge d$（$d$ 是下界），引理 3 说明存在划分恰好取得 $d$（$d$ 可达），两者夹逼即答案 $= d$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \log n)$，排序主导；线性扫描最小相邻差为 $O(n)$。$n \le 10^5$ 下轻松通过。
- **空间复杂度**：除排序外仅 $O(1)$。排序自身的辅助空间视语言而定（C++ `std::sort` 为 $O(\log n)$ 递归栈，Python `list.sort()` 为 $O(n)$），本题不做原地要求。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int findValueOfPartition(vector<int>& nums) {
        sort(nums.begin(), nums.end());
        int ans = INT_MAX;
        for (int i = 1; i < (int)nums.size(); i++) {
            ans = min(ans, nums[i] - nums[i - 1]);
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def findValueOfPartition(self, nums: List[int]) -> int:
        nums.sort()
        return min(nums[i + 1] - nums[i] for i in range(len(nums) - 1))
```

两份代码都是「排序 + 一遍扫描」，比赛时按手速任选；`n >= 2` 保证生成器非空，`min` 不会抛异常。

## 8. 边界情况与易错点

1. **重复元素 → 答案 0**：两个相等元素让它们分居两侧即可（示例 3）。排序后它们必然相邻，最小相邻差自动为 $0$，**无需特判**。
2. **$n = 2$**：唯一划分是单元素对单元素，答案 $= |\mathrm{nums}[0] - \mathrm{nums}[1]|$，恰好就是排序后的唯一相邻差。循环至少执行一次，`ans` 初值 `INT_MAX` 必被覆盖。
3. **不需要 `abs`**：排序后 $a[i] - a[i-1] \ge 0$，直接作差即可；加上也无害，只是多余。
4. **溢出**：$1 \le \mathrm{nums}[i] \le 10^9$，相邻差 $\le 10^9 - 1 < 2^{31} - 1$，C++ `int` 不溢出；若值域放大到 $10^{18}$ 需换 `long long`。
5. **「两数组非空」的约束不用操心**：前缀/后缀切分天然满足（引理 3）；不要因此去枚举「前缀取多长」——线性扫描已经覆盖了全部 $n - 1$ 个切点。
6. **别把题想复杂**：本题不需要 DP、二分或回溯。示例 2 的交错划分容易诱导人去枚举划分结构，但引理 2 的下界对任意划分一视同仁，排序扫描即最优。
7. **想清楚「最小相邻差」而不是「最小任意差」**：直接双重循环求任意两数最小差是 $O(n^2)$（$10^{10}$ 次比较，超时）；排序把「任意对」缩减为「相邻对」正是本题唯一考点。
