# LeetCode 特别的排列 题解

## 1. 题目概述

- **标题 / 题号**：特别的排列（#2741，medium）
- **链接**：https://leetcode.cn/problems/special-permutations/
- **来源**：LeetCode 第 350 场周赛 Q3
- **难度**：中等
- **标签**：位运算、数组、动态规划、状态压缩

**题意**：给定含 $n$ 个**互不相同**正整数的数组 `nums`。若 `nums` 的某个排列满足：每个相邻对要么 $\text{nums}[i] \bmod \text{nums}[i+1] = 0$、要么 $\text{nums}[i+1] \bmod \text{nums}[i] = 0$（即相邻两数**互相整除**），则称其为**特别的排列**。统计特别排列的总数，对 $10^9 + 7$ 取余返回。

**约束**：

- $2 \le n \le \mathrm{nums.length} \le 14$
- $1 \le \mathrm{nums}[i] \le 10^9$
- 所有元素互不相同

> 💡 **数据范围信号**：$n \le 14$ 正落在状压 DP 的甜区——$2^{14} = 16384$ 个子集状态，配上 $O(n)$ 或 $O(n^2)$ 的转移总量在百万级。赛场上看到「排列计数 + $n \le 20$」应条件反射地写 $\mathrm{dp}[\mathrm{mask}][\dots]$。

## 2. 示例

**示例 1**

```text
输入：nums = [2,3,6]
输出：2
解释：[3,6,2] 和 [2,6,3] 是两个特别的排列。
```

**示例 2**

```text
输入：nums = [1,4,3]
输出：2
解释：[3,1,4] 和 [4,1,3] 是两个特别的排列（1 与任何数都互相整除）。
```

```text
输入：nums = [3,5]
输出：0
解释：[3,5] 与 [5,3] 的相邻对都不互相整除，无特别排列。
```

## 3. 解题思路

### 3.1 暴力思路：枚举全排列

最朴素的做法是回溯枚举所有 $n!$ 个排列，逐对检查相邻整除性，中途失败即剪枝。$n = 14$ 时 $14! \approx 8.7 \times 10^{10}$，即使整除剪枝很强（大部分分支早早夭折），最坏情形仍远超时限。

但暴力中藏着金矿：**大量搜索路径殊途同归**。例如先放 $3$ 再放 $6$、与先放 $6$ 再放 $3$，如果它们最终都到达「已用 $\{3,6\}$、末位为 $6$」的同一局面，那么**从这个局面往后能走出的排列数完全相同**——后续决策只认局面，不认来路。这正是记忆化 / DP 可以介入的标志。

### 3.2 核心观察：无后效性 → 状态必须是 (mask, last)

排列是**逐位构造**出来的。决定「下一个能放谁」的信息只有两样：

1. **哪些数已经用过**——用位掩码 $\mathrm{mask}$ 表示，$n \le 14$ 塞得进一个 `int`；
2. **前一个放的是什么**——记 $\mathrm{last}$（末位元素的**下标**），因为新元素 $j$ 合法当且仅当与 $\mathrm{nums}[\mathrm{last}]$ 互相整除。

![核心观察：同一个 mask、不同 last，可扩展性截然不同](images/special_perm_state_concept.svg)

单记 `mask` **不够**，本题有一个致命反例：`nums = [2,3,6]` 时，已用集合 $\{3,6\}$（`mask = 110`）可以由 $[3,6]$（末位 6）或 $[6,3]$（末位 3）两种填法到达：

- 末位是 $6$：还能接 $2$（$6 \bmod 2 = 0$）✓
- 末位是 $3$：接不了 $2$（$3 \bmod 2 \ne 0$ 且 $2 \bmod 3 \ne 0$）✗

集合相同、末位不同、前景不同——**末位必须显式进入状态**，否则既会算错（把不可扩展的状态当作可扩展），也会算漏。于是：

$$
\mathrm{dp}[\mathrm{mask}][\mathrm{last}] \;=\; \text{已用集合为 } \mathrm{mask} \text{、末位为 } \mathrm{nums}[\mathrm{last}] \text{ 的合法前缀数目}
$$

### 3.3 算法流程：刷表法递推

![算法流程：按 mask 升序的刷表递推](images/special_perm_transition_flow.svg)

采用**刷表法**（把当前状态的贡献推给后继状态），按 $\mathrm{mask}$ 从小到大枚举：

```text
初始化：dp[1<<i][i] = 1（单元素排列，无前驱约束）
for mask = 1 .. (1<<n)-1：              # 升序枚举
    for last = 0 .. n-1：                # 末位（需在 mask 中且状态可达）
        for j = 0 .. n-1：               # 候选下一个元素（需不在 mask 中）
            若 nums[last] 与 nums[j] 互相整除：
                dp[mask | 1<<j][j] += dp[mask][last]，随手取模
答案：sum(dp[(1<<n)-1][j]) mod (1e9+7)
```

转移方程：

$$
\mathrm{dp}\big[\mathrm{mask} \mid (1 \ll j)\big][\,j\,] \;\mathrel{+}= \mathrm{dp}[\mathrm{mask}][\mathrm{last}]
\qquad \text{当 } j \notin \mathrm{mask} \text{ 且 } \mathrm{nums}[\mathrm{last}] \perp \mathrm{nums}[j] \text{（整除相容）}
$$

### 3.4 示例演算

以 `nums = [2,3,6]`（下标 0/1/2）为例，`mask` 的低位对应下标 0：

![示例演算：nums=[2,3,6] 的三层 DP](images/special_perm_example_walkthrough.svg)

- **长度 1**：$\mathrm{dp}[001][0] = \mathrm{dp}[010][1] = \mathrm{dp}[100][2] = 1$，对应前缀 $[2]$、$[3]$、$[6]$。
- **长度 2**：$2$ 与 $3$ 互不整除、不可相邻；$6$ 分别与两者整除相容，故可达 $[2,6]$、$[6,2]$、$[3,6]$、$[6,3]$ 四个状态：$\mathrm{dp}[101][2] = \mathrm{dp}[101][0] = \mathrm{dp}[110][2] = \mathrm{dp}[110][1] = 1$。
- **长度 3**：只有**末位为 6** 的状态能收官——$[2,6]$ 接 $3$ 得 $[2,6,3]$（$\mathrm{dp}[111][1] = 1$），$[3,6]$ 接 $2$ 得 $[3,6,2]$（$\mathrm{dp}[111][0] = 1$）；末位为 $2$ 或 $3$ 的状态接不上剩余元素，$\mathrm{dp}[111][2] = 0$。
- **答案**：$1 + 1 + 0 = 2$ ⭐

> 💡 $6$ 是 $2$、$3$ 的公倍数，在两个特别排列里都充当「中转站」。末位是 $2$ 时接不上 $3$，末位是 $6$ 时却接得上——这张图正是 3.2 节「必须记 `last`」的实证。

## 4. 算法细节

1. **状态语义**：$\mathrm{dp}[\mathrm{mask}][\mathrm{last}]$ 计数的是**合法前缀**（不是后缀方案数）：所有「元素集合恰为 $\mathrm{mask}$、末元素恰为 $\mathrm{nums}[\mathrm{last}]$」的合法部分排列。终点状态 $\mathrm{full} = (1 \ll n) - 1$ 的合法前缀就是完整的特别排列。
2. **初始值**：首位没有前驱、无整除约束，故每个单元素前缀都是合法起点，$\mathrm{dp}[1 \ll i][i] = 1$。不设「$\mathrm{mask}=0$ 虚拟起点」——那还得特判「无末位」的整除判定，得不偿失。
3. **枚举顺序的正确性（天然拓扑序）**：转移目标 $\mathrm{mask}' = \mathrm{mask} \mid (1 \ll j)$ 因 $j \notin \mathrm{mask}$ 而严格大于 $\mathrm{mask}$（至少多一个二进制位），所以**按 $\mathrm{mask}$ 从小到大刷表，被更新者一定晚于更新者被枚举**，无需显式拓扑排序。
4. **转移判定 O(1)**：整除相容即 `nums[last] % nums[j] == 0 || nums[j] % nums[last] == 0`。两数都在 `int` 范围内（$\le 10^9 < 2^{31}-1$），取模不溢出；且元素**互不相同**保证两数相等的情况不会出现，无需去重（对比 996 平方数组，含重复元素时同值下标需去重）。
5. **取余时机**：每步累加后立即 `% MOD`。C++ 中用 `int` 存 dp 是安全的：两加数均 $< 10^9 + 7$，和 $< 2.1 \times 10^9 < 2^{31} - 1$。若想更稳妥可全程 `long long`。
6. **不可达状态剪枝**：`dp[mask][last] == 0` 直接跳过（含隐式处理了 `last ∉ mask` 的非法组合——此时不存在任何合法前缀，dp 值恒为 0）。显式再写一句 `mask >> last & 1` 检查则是语义上更清晰的写法，二者取其一即可。
7. **答案汇总**：末位不同的完整排列互斥，$\mathrm{ans} = \sum_j \mathrm{dp}[\mathrm{full}][j] \bmod (10^9+7)$。注意求和后**还要再取一次模**。

## 5. 正确性证明

**引理 1（无后效性）**：设 $p[0..n-1]$ 是 `nums` 的一个排列。对任意 $0 \le k \le n-1$，前缀 $p[0..k]$ 之后的所有合法性约束（哪些元素还能放、相邻对是否整除）仅取决于二元组 $\big(\{p[0], \dots, p[k]\},\; p[k]\big)$，与前缀内部元素的排列顺序无关。

**证明**：前缀自身的合法性在逐位填入时已判定完毕（新增 $p[k]$ 只引入一个新相邻对 $(p[k-1], p[k])$，不回头影响旧对）。未来填 $p[k+1]$ 的约束恰为两条：其一，$p[k+1]$ 未被用过——由已用集合决定；其二，$p[k]$ 与 $p[k+1]$ 互相整除——由末位值决定。除此之外不存在任何依赖来路的约束。∎

**引理 2（前缀计数的不重不漏）**：对每个 $\mathrm{mask} \ne 0$ 与 $\mathrm{last} \in \mathrm{mask}$，递推结束后 $\mathrm{dp}[\mathrm{mask}][\mathrm{last}]$ 等于「元素集合恰为 $\mathrm{mask}$、末元素为 $\mathrm{nums}[\mathrm{last}]$ 的合法前缀」的个数。

**证明**（对 $|\mathrm{mask}|$ 归纳）：

- **基础**（$|\mathrm{mask}| = 1$）：唯一前缀 $[\mathrm{nums}[\mathrm{last}]]$，初始化 $\mathrm{dp}[1 \ll \mathrm{last}][\mathrm{last}] = 1$，成立。
- **归纳步**：设 $|\mathrm{mask}| = k+1 \ge 2$，记 $S$ 为「集合 $\mathrm{mask}$、末位 $\mathrm{last}$」的合法前缀集合。任取 $Q \in S$，去掉末位 $j^\* = \mathrm{last}$ 得 $Q'$（集合 $\mathrm{mask}' = \mathrm{mask} \setminus \{\mathrm{last}\}$、末位 $\mathrm{last}'$），则 $Q'$ 是合法前缀（$Q$ 的前缀自然合法）且 $(\mathrm{last}', \mathrm{last})$ 整除相容。反之，把任何一个这样的 $Q'$ 接上 $\mathrm{nums}[\mathrm{last}]$ 都得到 $S$ 中的一个成员。于是 $S$ 按「倒数第二个元素」划分为互不相交的子集，且
  $$
  |S| \;=\; \sum_{\mathrm{last}'} \#\{\text{集合 } \mathrm{mask}' \text{、末位 } \mathrm{last}' \text{ 的合法前缀}\},
  $$
  其中求和遍历所有与 $\mathrm{last}$ 整除相容且 $\mathrm{last}' \in \mathrm{mask}'$ 的下标。由归纳假设，右端每一项等于 $\mathrm{dp}[\mathrm{mask}'][\mathrm{last}']$，而递推恰好枚举所有 $(\mathrm{mask}', \mathrm{last}', j)$ 组合并把 $\mathrm{dp}[\mathrm{mask}'][\mathrm{last}']$ 累加进 $\mathrm{dp}[\mathrm{mask}][\mathrm{last}]$（$j = \mathrm{last}$），配合引理 1 保证「同一 $(\mathrm{mask}, \mathrm{last})$ 的成员共享完全相同的后续转移」，计数不重不漏。∎

**定理**：$\displaystyle \sum_{j=0}^{n-1} \mathrm{dp}[\mathrm{full}][j] \equiv \text{特别排列总数} \pmod{10^9+7}$。

**证明**：集合为 $\mathrm{full}$ 的合法前缀恰为完整的特别排列；按末位 $j$ 分类，各类互斥且并起来覆盖全部特别排列。由引理 2，第 $j$ 类的大小恰为 $\mathrm{dp}[\mathrm{full}][j]$。故求和即总数；递推中每步取模保证结果为真值模 $10^9+7$ 的同余。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n^2 \cdot 2^n)$。状态总数 $n \cdot 2^n$，每个状态枚举 $n$ 个候选后继并做 $O(1)$ 整除判定。$n = 14$ 时约 $14^2 \times 2^{14} \approx 3.2 \times 10^6$ 次操作，毫秒级完成。
- **空间复杂度**：$O(n \cdot 2^n)$。`dp` 数组 $2^{14} \times 14$ 个 `int`，约 $900\,\mathrm{KB}$。整除相容关系可预计算成 $n \times n$ 的邻接矩阵（$O(n^2)$ 空间）以省去重复取模判定，属常数优化，非必需。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int specialPerm(vector<int>& nums) {
        const int MOD = 1e9 + 7;
        int n = nums.size();
        int full = (1 << n) - 1;
        vector<vector<int>> dp(1 << n, vector<int>(n, 0));
        for (int i = 0; i < n; i++) dp[1 << i][i] = 1;          // 单元素起点
        for (int mask = 1; mask <= full; mask++) {
            for (int last = 0; last < n; last++) {
                if (dp[mask][last] == 0 || !(mask >> last & 1)) continue;  // 不可达/末位不在集合
                for (int j = 0; j < n; j++) {
                    if (mask >> j & 1) continue;                  // 已用过
                    if (nums[last] % nums[j] == 0 || nums[j] % nums[last] == 0) {
                        int nm = mask | (1 << j);
                        dp[nm][j] = (dp[nm][j] + dp[mask][last]) % MOD;
                    }
                }
            }
        }
        int ans = 0;
        for (int j = 0; j < n; j++) ans = (ans + dp[full][j]) % MOD;
        return ans;
    }
};
```

### Python

```python
class Solution:
    def specialPerm(self, nums: List[int]) -> int:
        MOD = 10**9 + 7
        n = len(nums)
        full = (1 << n) - 1
        dp = [[0] * n for _ in range(1 << n)]
        for i in range(n):
            dp[1 << i][i] = 1
        for mask in range(1, 1 << n):
            for last in range(n):
                if dp[mask][last] == 0 or not (mask >> last & 1):
                    continue
                for j in range(n):
                    if mask >> j & 1:
                        continue
                    if nums[last] % nums[j] == 0 or nums[j] % nums[last] == 0:
                        nm = mask | (1 << j)
                        dp[nm][j] = (dp[nm][j] + dp[mask][last]) % MOD
        return sum(dp[full]) % MOD
```

两份代码均为刷表递推：`mask` 升序枚举保证被转移状态晚于转移者（见 4.3），`dp==0` 剪枝跳过绝大多数不可达状态，实测常数很小。

## 8. 边界情况与易错点

1. **答案可能为 0**：如 `nums = [3,5]`，任何排列的相邻对都不互相整除（示例 3）。DP 自然返回 0，**不要特判**、更不要误以为「至少存在一个特别排列」。
2. **漏掉一个方向的整除**：条件是「**要么** $a \bmod b = 0$ **要么** $b \bmod a = 0$」，两个方向是**或**关系。只判一个方向会把 $[2,6]$ 与 $[6,2]$ 的一侧判死。大数在前时是小数整除大数（$6 \bmod 2 = 0$），小数在前时是大数被小数整除——方向随排列变化，缺一不可。
3. **忘了 `last` 维**：只写 $\mathrm{dp}[\mathrm{mask}]$ 是本题最典型的错法（3.2 节的反例正是「同集合、末位不同、可扩展性不同」）。若约束锚定在**位置**上（如 526），一维 `mask` 够用；锚定在**相邻元素**上，必须加末位维。
4. **取模时机**：每步累加后立即 `% MOD`；最终求和后**再取一次**。C++ 用 `int` 存 dp 虽不溢出（两加数均 $< 10^9+7$，和 $< 2^{31}-1$），但已是贴边操作，改用 `long long` 更从容。
5. **`last` 不在 `mask` 中**：递推枚举 `last` 时需保证 `mask >> last & 1`。虽然 `dp[mask][last] == 0` 的剪枝已隐式滤掉这类非法组合（不存在这样的合法前缀），显式检查更直白、不依赖该性质。
6. **`n = 2` 最小规模**：两个排列 $[a,b]$、$[b,a]$ 合法与否取决于同一对整除关系，答案非 0 即 2；初始化与转移自动覆盖，循环边界（`full = 3`）无误。
7. **别把 `10^9 + 7` 写成 `10^9`**：MOD 少加 7 是低级但高频的 WA 来源；Python 直接写 `10**9 + 7` 更醒目。
8. **值域 $10^9$ 无碍**：整除判定两侧都是 $\le 10^9$ 的正整数，`int` 取模不溢出；真正要提防溢出的是**计数**（$14$ 个元素的排列数可达 $14!$ 量级），这正是取模存在的原因。
9. **元素互不相同是白送的简化**：若含重复元素（如 996 平方数组），同值下标之间可互换会造成重复计数，需要额外去重逻辑；本题题面直接排除了这一坑。
