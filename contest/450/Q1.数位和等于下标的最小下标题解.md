# LeetCode 数位和等于下标的最小下标 题解

## 1. 题目概述

- **标题 / 题号**：数位和等于下标的最小下标（#3550，easy）
- **链接**：https://leetcode.cn/problems/smallest-index-with-digit-sum-equal-to-index/
- **来源**：LeetCode 第 450 场周赛 Q1
- **难度**：简单
- **标签**：数组、数学

**题意**：给定整数数组 `nums`，返回最小的下标 `i`，使得 `nums[i]` 的**数位和**（十进制各位数字之和）恰好等于 `i`；若不存在这样的下标，返回 `-1`。

**约束**：

- `1 <= nums.length <= 100`
- `0 <= nums[i] <= 1000`

## 2. 示例

**示例 1**

```text
输入：nums = [1,3,2]
输出：2
解释：nums[2] = 2，数位和为 2，等于下标 i = 2，输出 2。
```

**示例 2**

```text
输入：nums = [1,10,11]
输出：1
解释：nums[1] = 10，数位和 1+0 = 1，等于下标 1；nums[2] = 11，数位和 2，等于下标 2。
     取最小下标，输出 1。
```

**示例 3**

```text
输入：nums = [1,2,3]
输出：-1
解释：所有下标均不满足，输出 -1。
```

## 3. 解题思路

### 3.1 直接思路

签到题。数据规模只有 $10^2$ 量级，从左到右枚举每个下标，算出 `nums[i]` 的数位和并与 `i` 比较即可，无需任何优化。

### 3.2 核心观察：数位和 + 顺序扫描取首个

![核心思路：数位和计算与从左到右扫描](images/wc450_q1_digit_sum_concept.svg)

- **数位和**：反复"取个位、去个位"，即 `s += x % 10; x /= 10`，直到 `x = 0`；也可转成字符串逐字符求和。
- **最小下标**：从 `i = 0` 开始**顺序**枚举，遇到第一个满足 $\text{digitSum}(nums[i]) = i$ 的下标立即返回，天然保证"最小"。

### 3.3 算法流程

1. 令 `i` 从 `0` 遍历到 `n − 1`；
2. 计算 `ds = digitSum(nums[i])`；
3. 若 `ds == i`，立即返回 `i`；
4. 循环结束仍未返回，说明无解，返回 `-1`。

## 4. 算法细节

1. **数位和的两种写法**：
   - 取模除十：`while (x) { s += x % 10; x /= 10; }`。注意 `x = 0` 时循环体不执行、`s = 0`，恰好正确；
   - 字符串：`sum(map(int, str(x)))`，Python 一行流。
2. **最小性**：下标按升序枚举、命中即返回，第一个命中的就是最小下标，无需额外维护最小值。
3. **可选剪枝**：`nums[i] <= 1000`，数位和最大为 `999 → 27`，因此 `i >= 28` 时必然无解，可直接跳出循环。本题 `n <= 100`，剪枝与否都能瞬间通过。

## 5. 正确性证明

**引理 1**：取模除十法对任意非负整数 `x` 正确计算其数位和。

**证明**：设 `x` 的十进制表示为 $d_k d_{k-1} \cdots d_1 d_0$。`x % 10` 得到当前最低位 $d_0$，`x / 10` 去掉 $d_0$，剩余 $\lfloor x/10 \rfloor$ 的十进制表示为 $d_k \cdots d_1$。由归纳法，循环恰好把每一位数字累加一次；`x = 0` 时数位和为 `0`，循环不执行、`s = 0`，同样正确。∎

**定理**：算法返回满足条件的最小下标；无解时返回 `-1`。

**证明**：下标按 `0, 1, …, n−1` 升序枚举。设满足条件的下标集合为 `S`。若 `S` 非空，取其最小值 `i*`，则对一切 `i < i*` 条件不成立、算法不会提前返回；枚举到 `i*` 时由引理 1 数位和计算正确，条件成立，算法返回 `i*`，即最小下标。若 `S` 为空，循环自然结束，返回 `-1`。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \cdot D)$，其中 $D$ 是 `nums[i]` 的最大十进制位数。本题 $D \le 4$（`nums[i] <= 1000`），总计约 $4n$ 次常数运算。
- **空间复杂度**：$O(1)$，仅使用常数个变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int smallestIndex(vector<int>& nums) {
        for (int i = 0; i < (int)nums.size(); i++) {
            int s = 0, x = nums[i];
            while (x > 0) {
                s += x % 10;
                x /= 10;
            }
            if (s == i) return i;
        }
        return -1;
    }
};
```

### Python

```python
class Solution:
    def smallestIndex(self, nums: List[int]) -> int:
        for i, x in enumerate(nums):
            if sum(map(int, str(x))) == i:
                return i
        return -1
```

## 8. 边界情况与易错点

1. **`nums[0] = 0`**：数位和为 `0`，等于下标 `0`，答案为 `0`。不要误判 `0` 的数位和，也不要漏判下标 `0`。
2. **下标从 0 开始比较**：题目中的 `i` 从 `0` 起，不是从 `1` 起。
3. **无解返回 `-1`**：如 `[1,2,3]`，三个下标都不匹配。
4. **`10` 的数位和是 `1`**：即 `1 + 0 = 1`，不是 `10` 本身；同理 `100 → 1`、`1000 → 1`。
5. **无溢出风险**：`n <= 100`、`nums[i] <= 1000`、数位和不超过 `27`，`int` 绰绰有余。
