# LeetCode 包含要求路径的最小带权子图 II 题解

## 1. 题目概述

- **标题 / 题号**：包含要求路径的最小带权子图 II（#3553，hard）
- **链接**：https://leetcode.cn/problems/minimum-weighted-subgraph-with-the-required-paths-ii/
- **来源**：LeetCode 第 450 场周赛 Q4
- **难度**：困难
- **标签**：树、最近公共祖先、倍增、深度优先搜索、动态规划、位运算

**题意**：给定一棵 $n$ 个节点的**无向带权树**，`edges[i] = [ui, vi, wi]` 表示 $u_i$、$v_i$ 之间有一条权为 $w_i$ 的边。再给 $q$ 组查询 `queries[j] = [src1, src2, dest]`。对每个查询，求一棵**总权重最小**的子树（原树中若干节点和边组成的**连通子集**），使得沿该子树的边能从 `src1` 和 `src2` 都到达 `dest`。返回所有查询的答案数组。

**约束**：

- $3 \le n \le 10^5$，$1 \le w_i \le 10^4$，`edges` 保证构成合法的树
- $1 \le q \le 10^5$
- 每组查询中 `src1`、`src2`、`dest` 互不相同

> 💡 **读题关键**：这是 2203「包含要求路径的最小带权子图」的**树版续作**。一般图上「含指定路径的最小连通子图」是 NP 难的斯坦纳树问题，三点版也得靠 3 次 Dijkstra 枚举汇合点；而树**连通无环、任意两点间路径唯一**，两条要求路径完全确定，最小子树就是它们的并——问题从「最短路搜索」坍缩成「树上距离 + LCA」的模板组合拳。

## 2. 示例

输出：[12,11]
解释：
answer[0]：子树取边 1-2、1-3、1-4（权 3+5+4），从 2 和 3 都能到达 4。
answer[1]：子树取边 0-1、1-2、2-5（权 2+3+6），从 0 和 2 都能到达 5。
```

输出：[15]
解释：子树就是整棵树，从 0 和 1 到 2 的路径总权重 8+7 = 15。
```

## 3. 解题思路

### 3.1 暴力思路

最直观的暴力：把树根在 $0$，预处理父指针；每次查询分别从 `src1`、`src2` 沿父链爬向 `dest`（途经 LCA 中转），把两边路径的边放进哈希集合去重后求和。单次查询 $O(\text{depth})$，链形树深度为 $n-1$，总量 $O(nq) = 10^{10}$，必然超时。

另一路暴力是把 2203 的做法整个搬过来：每个查询跑 3 次 Dijkstra（树退化为 BFS），再枚举汇合点 $v$ 最小化 $d(a,v)+d(b,v)+d(c,v)$。单次查询 $O(n)$ 起步，$q = 10^5$ 时同样是 $10^{10}$ 量级。

两个暴力共同的瓶颈：**每条查询都在完整重走路径**，而树结构下「路径的权重」本可以被 $O(\log n)$ 地直接「问」出来。

### 3.2 核心观察：三点斯坦纳树的闭式解

![核心观察：最小子树是以中位点 m 为中心的三岔树，三条两两路径把每条腿恰好数两遍](images/wc450_q4_steiner_concept.svg)

记 $a=\text{src1}$、$b=\text{src2}$、$c=\text{dest}$，三个观察层层递进：

**观察 1（答案 = 两条要求路径的并）**：树上任意两点间的简单路径**唯一**。任何满足「从 $a$、$b$ 都能到达 $c$」的连通子树，都必须包含路径 $P(a,c)$ 与 $P(b,c)$ 的**每一条边**（连通性强制包含）；反过来，这两条路径的并共享端点 $c$、本身连通，就是一棵合法子树。**下界与可行解重合**，答案即并集的总权重。

**观察 2（并是一棵以 $m$ 为中心的三岔树）**：两条路径的公共部分从某个点 $m$ 开始（$m$ 即三点的**中位点**，恰为三个两两 LCA 中**最深**的那个），于是并集形如从 $m$ 伸出的三条「腿」：

$$\text{answer} = d(a,m) + d(b,m) + d(c,m)$$

**观察 3（闭式解，$m$ 被消掉）**：三条两两路径分别是两条腿的拼接——$P(a,b) = \text{腿A} + \text{腿B}$，$P(b,c) = \text{腿B} + \text{腿C}$，$P(c,a) = \text{腿C} + \text{腿A}$。三者相加，**每条腿恰好被数 2 遍**：

$$d(a,b) + d(b,c) + d(c,a) = 2\big(d(a,m) + d(b,m) + d(c,m)\big)$$

$$\boxed{\ \text{answer} = \frac{d(a,b) + d(b,c) + d(c,a)}{2}\ }$$

闭式解连 $m$ 都不用显式去找——三条两两距离一加、除以 2，$m$ 的信息已经被消掉了。剩下的唯一子问题是**树上两点距离**：任选根（比如 $0$）做一次 BFS 得到根距离 $\text{dist}[\cdot]$，则

$$d(x,y) = \text{dist}[x] + \text{dist}[y] - 2 \cdot \text{dist}[\mathrm{lca}(x,y)]$$

LCA 用**倍增**（binary lifting）预处理 $O(n \log n)$、单次查询 $O(\log n)$——这正是官方标签里「位运算 / 动态规划」的出处：$up[k][v] = up[k-1][\,up[k-1][v]\,]$ 本质是以「跳 $2^k$ 步到达的祖先」为状态的 DP，跳跃量按二进制拆分。

> ⚠️ **常见误读**：一是照搬 2203 的「枚举汇合点 $v$ 最小化 $d(a,v)+d(b,v)+d(c,v)$」——树上这个最优点有闭式解（中位点 $m$），且本题 $q$ 高达 $10^5$，每查询跑 Dijkstra 是 $O(q \cdot n \log n)$，直接爆炸；二是担心除以 2 出现小数——三条两两路径中每条边被经过 **0 或 2 次**，距离和必为偶数，整除安全（证明见 §5 引理 2）。

### 3.3 算法流程：根距离 + 倍增 LCA

![算法骨架：一次 BFS 预处理 depth/dist，倍增表 up 支撑 O(log n) 的 LCA 在线查询](images/wc450_q4_lca_binary_lifting.svg)

1. 建邻接表，从根 $0$ 做**迭代 BFS**（链形树不爆栈），一次得到 `depth`（深度）、`dist`（根到点的边权和）、`up[0]`（父指针，根指向自己）；
2. 递推倍增表：$up[k][v] = up[k-1][\,up[k-1][v]\,]$，共 $\lceil \log_2 n \rceil$ 层，$O(n \log n)$；
3. 每个查询做 3 次 LCA（两阶段：先按二进制拆位**对齐深度**，再从高位到低位**同跳找分叉**），得 3 个两两距离，求和除以 2 即答案。

### 3.4 示例演算

![示例演算：同一棵树的两次查询，红色粗边为选中的子树，虚线双圈为中位点 m](images/wc450_q4_example_walkthrough.svg)

以示例 1 为例（根取 $0$），BFS 得 `depth = [0,1,2,2,2,3]`，`dist = [0,2,5,7,6,11]`：

| 查询 | 三次 LCA | 三次距离 $d(x,y) = \text{dist}[x]+\text{dist}[y]-2\,\text{dist}[\mathrm{lca}]$ | 答案 |
|------|----------|--------------------------------------------------------------------------------|------|
| `[2,3,4]` | $\mathrm{lca}(2,3)=1$，$\mathrm{lca}(3,4)=1$，$\mathrm{lca}(4,2)=1$ | $d(2,3)=8$，$d(3,4)=9$，$d(4,2)=7$ | $(8+9+7)/2 = \mathbf{12}$ |
| `[0,2,5]` | $\mathrm{lca}(0,2)=0$，$\mathrm{lca}(2,5)=2$，$\mathrm{lca}(0,5)=0$ | $d(0,2)=5$，$d(2,5)=6$，$d(0,5)=11$ | $(5+6+11)/2 = \mathbf{11}$ |

与期望输出 `[12,11]` 一致。第一个查询三点同挂在节点 1 下，$m=1$，三腿 $3+5+4=12$；第二个查询 $m=2$（三个两两 LCA 中最深者），三腿 $5+0+6=11$——`src2` 自己就是中位点、腿 B 为空，公式照样成立。

## 4. 算法细节

1. **迭代 BFS 防爆栈**：$n = 10^5$ 的链形树递归深度同量级，Python 默认上限 1000 必炸；用「遍历队列 + 边遍历边扩展」（`for u in order:`）的写法天然线性，同时产出 `depth`、`dist`、`up[0]`。
2. **根的父亲指向自己**（`up[0][0] = 0`）：倍增跳跃越过后停在根，全程不用判空；倍增表的归纳构造也由此封口。
3. **LOG 取法**：只需 $2^{LOG} \ge n$（C++ 用 `while ((1 << LOG) < n) ++LOG;`，Python 用 `(n-1).bit_length()`），保证能对齐最大深度差并完成第二阶段上跳。
4. **LCA 两阶段顺序**：先对齐深度（深度差二进制拆位、逐位 `x = up[k][x]`），再从高位到低位同跳；阶段二比较的是 $up[k][x] \ne up[k][y]$ **而非** $x \ne y$，否则会直接跳过 LCA 本身。
5. **64 位累加**：单次距离上限约 $(n-1) \times 10^4 \approx 10^9$，三项求和可达 $3 \times 10^9$，超出 `int32`；C++ 中间量用 `long long`。最终答案 $\le$ 全树总权 $< 2^{31}$，落回返回类型 `vector<int>` 安全区。
6. **整除性**：由引理 2，每条边在三条两两路径中被数 0 或 2 次，距离和必为偶数，`// 2` 无舍入误差，不要用浮点除法。
7. **无向边双向建**：邻接表两个方向都要加；`depth[v] == -1` 兼作访问标记，天然防止回头。

## 5. 正确性证明

**引理 1（答案 = 两条要求路径的并）**：设 $T'$ 为任意一棵满足「沿 $T'$ 的边可从 $a$ 到 $c$、从 $b$ 到 $c$」的子树（原树的连通子集），则 $P(a,c) \cup P(b,c) \subseteq T'$；且 $P(a,c) \cup P(b,c)$ 本身是一棵满足要求的子树。从而 $\text{answer} = w\big(P(a,c) \cup P(b,c)\big)$。

**证明**：$T'$ 是树（连通、无环），其中任意两点间的路径唯一；又 $T'$ 的边集是原树边集的子集，而原树中 $a$ 到 $c$ 的路径也唯一，故 $T'$ 中 $a$ 到 $c$ 的路径就是 $P(a,c)$，即 $P(a,c) \subseteq T'$。同理 $P(b,c) \subseteq T'$。反之，$P(a,c) \cup P(b,c)$ 是原树边/点的子集，两条路径各连通且共享点 $c$，故并集连通且无环（树的子图无环），是合法子树，且包含 $P(a,c)$、$P(b,c)$ 本身从而满足要求。下界与可行解重合。∎

**引理 2（边计数恒等式与整除性）**：对树中每条边 $e$，$e$ 对和式 $d(a,b) + d(b,c) + d(c,a)$ 的贡献为 0 或 2，且贡献为 2 当且仅当 $e \in P(a,c) \cup P(b,c)$。从而

$$d(a,b) + d(b,c) + d(c,a) = 2 \cdot w\big(P(a,c) \cup P(b,c)\big)$$

**证明**：删去 $e$，树分成两个连通份。对点 $x$，令 $\delta_e(x) \in \{0,1\}$ 标记 $x$ 所在的侧。树上 $e \in P(x,y) \iff \delta_e(x) \ne \delta_e(y)$。看三个比特 $\delta_e(a), \delta_e(b), \delta_e(c)$：

- 三者全同：三个点对全不跨越 $e$，和式贡献 $0$；且 $a$、$b$ 与 $c$ 同侧，$e \notin P(a,c) \cup P(b,c)$，贡献 $0 = 2 \times 0$；
- 不全同（必为 1-2 划分）：恰有 2 个点对跨越 $e$，和式贡献 $2$。按孤立点分三类，每种情况 $e$ 都恰落入并集一次：孤立点是 $a$ 时跨越对为 $(a,b)$、$(a,c)$，$e \in P(a,c)$；孤立点是 $b$ 时跨越对为 $(a,b)$、$(b,c)$，$e \in P(b,c)$；孤立点是 $c$ 时跨越对为 $(a,c)$、$(b,c)$，$e$ 同属两条路径，但在并集中只计一次。故贡献 $2 = 2 \times 1$。

逐边求和即得恒等式；同时每条边贡献为偶数说明和式必为偶数，除以 2 无余数。∎

**引理 3（距离公式）**：以任意点 $r$ 为根，$\text{dist}[x] = w(P(r,x))$，则 $d(x,y) = \text{dist}[x] + \text{dist}[y] - 2\,\text{dist}[\mathrm{lca}(x,y)]$。

**证明**：设 $z = \mathrm{lca}(x,y)$，则 $P(r,x) = P(r,z) + P(z,x)$、$P(r,y) = P(r,z) + P(z,y)$，且 $P(x,y) = P(x,z) + P(z,y)$（树上路径经 LCA 中转）。于是 $\text{dist}[x] + \text{dist}[y] - 2\,\text{dist}[z] = w(P(z,x)) + w(P(z,y)) = w(P(x,y)) = d(x,y)$。∎

**定理**：对每组查询 $(a,b,c)$，算法输出的 $\big(d(a,b)+d(b,c)+d(c,a)\big)/2$ 等于最小子树总权重，且为整数。

**证明**：由引理 1，最小子树总权重为 $w(P(a,c) \cup P(b,c))$；由引理 2，它恰等于 $\big(d(a,b)+d(b,c)+d(c,a)\big)/2$，且该值为整数。由引理 3 与倍增 LCA 的标准正确性（阶段一对齐深度后两点的最近公共祖先保持不变；阶段二结束时 $x,y$ 的父指针即 LCA），三次距离计算无误。∎

## 6. 复杂度分析

- **时间复杂度**：$O((n + q) \log n)$。预处理：迭代 BFS $O(n)$ + 倍增表 $O(n \log n)$；查询：每查询 3 次 LCA、各 $O(\log n)$，共 $3q \log n$。$n = q = 10^5$、$\log n \approx 17$ 时约 $6 \times 10^6$ 次跳跃级操作，比暴力的 $O(nq) = 10^{10}$ 快三个数量级。
- **空间复杂度**：$O(n \log n)$。倍增表 $\lceil \log_2 n \rceil \times n \approx 17 \times 10^5$ 个整数（C++ 约 7 MB），加上邻接表、`depth`、`dist` 各 $O(n)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> minimumWeight(vector<vector<int>>& edges, vector<vector<int>>& queries) {
        int n = edges.size() + 1;
        vector<vector<pair<int,int>>> adj(n);
        for (auto& e : edges) {
            adj[e[0]].push_back({e[1], e[2]});
            adj[e[1]].push_back({e[0], e[2]});
        }
        int LOG = 1;                       // 2^LOG >= n，覆盖最大深度差
        while ((1 << LOG) < n) ++LOG;

        vector<int> depth(n, -1);
        vector<long long> dist(n, 0);
        vector<vector<int>> up(LOG, vector<int>(n, 0));
        up[0][0] = 0;                      // 根的父亲指向自己，跳过头也不怕

        vector<int> order;                 // 迭代 BFS：链形树不爆栈
        order.reserve(n);
        order.push_back(0);
        depth[0] = 0;
        for (int i = 0; i < (int)order.size(); ++i) {
            int u = order[i];
            for (auto [v, w] : adj[u]) {
                if (depth[v] == -1) {
                    depth[v] = depth[u] + 1;
                    dist[v] = dist[u] + w;
                    up[0][v] = u;
                    order.push_back(v);
                }
            }
        }
        for (int k = 1; k < LOG; ++k)      // 倍增表：跳 2^k 步到的祖先
            for (int v = 0; v < n; ++v)
                up[k][v] = up[k - 1][up[k - 1][v]];

        auto lca = [&](int x, int y) {
            if (depth[x] < depth[y]) swap(x, y);
            int diff = depth[x] - depth[y];        // 阶段一：对齐深度
            for (int k = 0; diff; ++k, diff >>= 1)
                if (diff & 1) x = up[k][x];
            if (x == y) return x;
            for (int k = LOG - 1; k >= 0; --k)     // 阶段二：同跳找分叉
                if (up[k][x] != up[k][y]) {
                    x = up[k][x];
                    y = up[k][y];
                }
            return up[0][x];
        };
        auto d = [&](int x, int y) {
            return dist[x] + dist[y] - 2 * dist[lca(x, y)];
        };

        vector<int> ans;
        ans.reserve(queries.size());
        for (auto& qy : queries) {
            long long s = d(qy[0], qy[1]) + d(qy[1], qy[2]) + d(qy[2], qy[0]);
            ans.push_back((int)(s / 2));   // 每条边被数 0/2 次，必整除
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def minimumWeight(self, edges: List[List[int]], queries: List[List[int]]) -> List[int]:
        n = len(edges) + 1
        adj = [[] for _ in range(n)]
        for u, v, w in edges:
            adj[u].append((v, w))
            adj[v].append((u, w))

        LOG = max(1, (n - 1).bit_length())     # 2^LOG >= n
        depth = [-1] * n
        dist = [0] * n
        up = [[0] * n for _ in range(LOG)]

        order = [0]                            # 迭代 BFS：链形树不爆栈
        depth[0] = 0
        for u in order:                        # 列表边遍历边扩展
            for v, w in adj[u]:
                if depth[v] == -1:
                    depth[v] = depth[u] + 1
                    dist[v] = dist[u] + w
                    up[0][v] = u
                    order.append(v)
        for k in range(1, LOG):
            uk, upk = up[k], up[k - 1]
            for v in range(n):
                uk[v] = upk[upk[v]]

        def lca(x: int, y: int) -> int:
            if depth[x] < depth[y]:
                x, y = y, x
            diff = depth[x] - depth[y]         # 阶段一：对齐深度
            k = 0
            while diff:
                if diff & 1:
                    x = up[k][x]
                diff >>= 1
                k += 1
            if x == y:
                return x
            for k in range(LOG - 1, -1, -1):   # 阶段二：同跳找分叉
                if up[k][x] != up[k][y]:
                    x = up[k][x]
                    y = up[k][y]
            return up[0][x]

        def d(x: int, y: int) -> int:
            return dist[x] + dist[y] - 2 * dist[lca(x, y)]

        return [(d(a, b) + d(b, c) + d(c, a)) // 2 for a, b, c in queries]
```

> 💡 已用随机树 + 暴力对拍（每组查询用「父链收集路径边、集合并集求和」做参照）验证公式与两份实现一致，示例 1/2/3 亦全部吻合。

## 8. 边界情况与易错点

1. **中间量溢出**：三条两两距离之和上限约 $3 \times (n-1) \times 10^4 \approx 3 \times 10^9 > 2^{31}-1$，C++ 必须用 `long long` 累加；最终答案 $\le (n-1) \times 10^4 < 2^{31}$，可安全转回 `int`（返回类型是 `vector<int>`）。
2. **Python 递归爆栈**：$n = 10^5$ 的链形树递归深度同量级，默认上限 1000；预处理必须迭代（BFS 序遍历），不要写递归 DFS。
3. **根的父亲必须指向自己**：否则倍增表构建时 `up[0][0]` 未定义、LCA 跳跃越界；这个哨兵让「跳过头」自动停靠在根。
4. **LOG 上界**：$2^{LOG} \ge n$ 才能覆盖最大深度差 $n-1$；取小了阶段一会数组越界或死循环。
5. **阶段二的比较对象**：是 $up[k][x] \ne up[k][y]$ 而非 $x \ne y$——后者会把 LCA 本身也跳过去，返回错误的更深祖先。
6. **除法用整除**：`// 2`（由引理 2 保证偶数），用浮点除法会引入精度问题，用 `int(s)/2` 会先溢出再截断。
7. **中位点与端点重合**：三点互异不保证 $m$ 与三点都不同——$a$ 恰在 $P(b,c)$ 上时 $m = a$、腿 A 为空，答案退化为 $d(b,c)$（本文示例 3 / 原题示例 2 即此形态）。闭式公式自动兼容，**无需特判**。
8. **每查询恰好 3 次 LCA**：$d(a,b)$、$d(b,c)$、$d(c,a)$ 一个都不能少，也不要算成 $d(a,c)+d(b,c)$（那是把公共腿算两遍、非公共腿各一遍的错误混合）。
9. **建图双向加边**：无向树两个方向都要加入邻接表；`depth[v] == -1` 兼作访问标记即可防止走回头路。
