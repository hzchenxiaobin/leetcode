# LeetCode 数位和排序需要的最小交换次数 题解

## 1. 题目概述

- **标题 / 题号**：数位和排序需要的最小交换次数（#3551，medium）
- **链接**：https://leetcode.cn/problems/minimum-swaps-to-sort-by-digit-sum/
- **来源**：LeetCode 第 450 场周赛 Q2
- **难度**：中等
- **标签**：数组、哈希表、排序

**题意**：给定一个由**互不相同**的正整数组成的数组 `nums`，要求把它重排成「**数位和**升序、数位和相同时**数值**小者在前」的顺序。返回所需的最少交换次数，一次交换指交换数组中任意两个不同位置的值。

**约束**：

- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`
- `nums` 中元素互不相同

## 2. 示例

**示例 1**

```text
输入：nums = [37,100]
输出：1
解释：数位和 [10, 1]，目标顺序 [100, 37]，交换 37 与 100 一次即可。
```

**示例 2**

```text
输入：nums = [22,14,33,7]
输出：0
解释：数位和 [4,5,6,7] 严格递增，数组已经有序。
```

**示例 3**

```text
输入：nums = [18,43,34,16]
输出：2
解释：数位和 [9,7,7,7]，目标顺序 [16,34,43,18]；
     交换 18↔16、43↔34 各一次，共 2 次。
```

## 3. 解题思路

### 3.1 暴力思路

把「每一步交换哪两个位置」当作决策，对交换序列做 BFS，状态数是 $n!$ 量级，$n \le 10^5$ 完全不可行。另一个直觉是「选择排序模拟」：每一轮在无序段里找（数位和，数值）最小的元素换到段首。这样交换次数恰好就是答案（后面会看到这不是巧合），但每轮线性找最值是 $O(n^2)$，$n = 10^5$ 时约 $10^{10}$ 次操作同样超时。必须利用「交换」的结构性性质。

### 3.2 核心观察：置换环分解

![核心观察：排序键与置换的建立](images/wc450_q2_sort_key_permutation.svg)

第一步先把「目标顺序」精确化：元素互不相同 ⇒ 二元组 $(\text{digitSum}(x), x)$ 两两不同 ⇒ **目标排列唯一确定**（引理 1）。于是「把数组变成目标顺序」在数学上就是把一个**置换**变成恒等置换：

- 设 `pos[i]` 为当前位于下标 `i` 的元素在目标数组中的下标，则 `pos` 是 $\{0,1,\cdots,n-1\}$ 上的一个置换；
- 把 `pos` 画成「$i \to pos[i]$」的有向图，得到若干个互不相交的**置换环**。

![置换环分解：答案 = n − 环数](images/wc450_q2_cycle_decomposition.svg)

**关键结论**：最小交换次数 $= n - c$，其中 $c$ 是置换环的个数。

- 长度为 $1$ 的环（自环）表示元素已就位，不需要交换；
- 长度为 $k \ge 2$ 的环，用「锚点法」$k-1$ 次交换即可让环上全部元素归位；
- 而任意一次交换至多让环数增加 $1$（引理 2），恒等置换有 $n$ 个环，所以 $n - c$ 同时也是下界。

### 3.3 算法流程

1. 预计算 `ds[i] = digitSum(nums[i])`；
2. 对下标 $0..n-1$ 按二元组 $(ds[i],\ nums[i])$ 升序排序，得到 `order`：`order[k]` 表示「应放在位置 `k` 的元素」当前所在的下标；
3. 反转映射得置换：`pos[order[k]] = k`，即 `pos[i]` 为下标 `i` 处元素的目标位置；
4. 对 `pos` 做环分解：沿 `j = pos[j]` 跳环并标记 `visited`，每个环累加「环长 − 1」。

### 3.4 示例演算

![示例演算：两次交换完成归位](images/wc450_q2_swap_walkthrough.svg)

以示例 3 为例：`pos = [3,2,1,0]`，分解出环 $(0 \to 3 \to 0)$ 与 $(1 \to 2 \to 1)$，各需 $2-1=1$ 次交换，答案 $(2-1)+(2-1) = 2$，与逐步交换演算的结果一致。

## 4. 算法细节

1. **双关键字排序**：`(数位和, 数值)`。只按数位和排会丢掉平局规则——示例 3 中 `16/34/43` 数位和同为 7，必须靠数值分出先后。元素互不相同保证排序无并列，目标位置唯一。
2. **置换方向**：`order[k] = i` 表示位置 `k` 需要当前在下标 `i` 的元素；反转得 `pos[i] = k`。`order` 与 `pos` 互为逆置换，用哪个做环分解都对，但两者含义不能混用。
3. **环分解写法**：经典「沿环跳」——从任意未访问的 `i` 出发，沿 `j = pos[j]` 走一圈标记 `visited`、统计环长 `len`，累加 `len - 1`。这等价于「带记忆的选择排序」，只是把每轮找最值换成了 $O(1)$ 的查表。
4. **数位和预计算**：`nums[i] <= 10^9` 至多 10 位。先把 `ds` 整体算好再排序，避免在比较器里反复拆位（比较器内拆位是 $O(D \cdot n\log n)$，多数语言也能过，但预计算更稳）。
5. **答案规模**：最坏是单个 $n$ 元环，答案 $n - 1 \le 10^5 - 1$，`int` 即可。

## 5. 正确性证明

**引理 1（目标唯一）**：`nums` 元素互不相同，故二元组 $(\text{digitSum}(x), x)$ 两两不同，按其升序得到的目标排列唯一。

**证明**：任取 $x \ne y$。若数位和不同，第一关键字分出先后；若 $\text{digitSum}(x) = \text{digitSum}(y)$，则第二关键字 $x \ne y$ 必分出先后。故任意两元素的先后关系严格确定，目标排列唯一。∎

**引理 2（交换对环数的影响）**：交换数组中位置 $a, b$ 上的元素后，置换环数变化恰为 $\pm 1$：$a, b$ 同属一个环时环数 $+1$（环分裂），分属两个环时环数 $-1$（环合并）。

**证明**：交换仅改变这两个元素所在的下标，新置换满足 $pos'(a) = pos(b)$、$pos'(b) = pos(a)$，其余下标处不变。
- 若 $a, b$ 同属环 $a \to pos[a] \to \cdots \to b \to pos[b] \to \cdots \to a$，交换后从 $a$ 沿新边 $pos'(a) = pos[b]$ 走到的链段不再经过 $b$，原环分裂为两个环；
- 若 $a, b$ 分属两个环，交换后两段链首尾相接合并为一个环。
其余环不含位置 $a, b$，完全不受影响。∎

**引理 3（环内归位代价）**：长度为 $k$ 的环可以恰好用 $k - 1$ 次交换使环上所有元素归位（$k=1$ 时为 $0$ 次）。

**证明**（构造）：对 $k$ 归纳。$k = 1$ 是自环，已就位。$k \ge 2$ 时取环上任一位置 $a$ 作**锚点**：位置 $a$ 应接收的元素当前在环上 $a$ 的前驱位置 $b$（即 $pos[b] = a$）。交换 $a, b$：该元素落到目标位置 $a$（此后不再移动），剩余 $k-1$ 个元素仍构成一个环（由引理 2，交换同环两点使环分裂为「一个自环 + 一个 $k-1$ 元环」）。故 $f(k) = 1 + f(k-1) = k - 1$。∎

**定理**：将 `nums` 变为目标顺序的最少交换次数为 $n - c$，其中 $c$ 为置换环数。

**证明**：
- **下界**：目标状态是恒等置换，含 $n$ 个环；初始置换含 $c$ 个环。由引理 2，每次交换使环数至多增加 $1$，故至少需要 $n - c$ 次交换。
- **上界**：由引理 3，对每个长度为 $k_i$ 的环用 $k_i - 1$ 次交换归位，不同环互不干扰，总计 $\sum_i (k_i - 1) = n - c$ 次。
两者相等，故最小交换次数恰为 $n - c$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \log n + nD)$，其中 $D \le 10$ 为 `nums[i]` 的最大十进制位数。主导项是下标排序的 $O(n \log n)$；数位求和 $O(nD)$、建映射与环分解均为 $O(n)$。
- **空间复杂度**：$O(n)$，用于存储数位和数组、下标排序数组、目标位置数组与 `visited` 标记。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minSwaps(vector<int>& nums) {
        int n = nums.size();
        vector<int> ds(n);
        for (int i = 0; i < n; i++) {
            int s = 0;
            for (int x = nums[i]; x > 0; x /= 10) s += x % 10;
            ds[i] = s;
        }
        vector<int> order(n), pos(n);
        iota(order.begin(), order.end(), 0);
        sort(order.begin(), order.end(), [&](int i, int j) {
            if (ds[i] != ds[j]) return ds[i] < ds[j];
            return nums[i] < nums[j];
        });
        for (int k = 0; k < n; k++) pos[order[k]] = k;

        vector<bool> vis(n, false);
        int ans = 0;
        for (int i = 0; i < n; i++) {
            if (vis[i]) continue;
            int len = 0;
            for (int j = i; !vis[j]; j = pos[j]) {
                vis[j] = true;
                len++;
            }
            ans += len - 1;
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def minSwaps(self, nums: List[int]) -> int:
        n = len(nums)
        order = sorted(range(n), key=lambda i: (sum(map(int, str(nums[i]))), nums[i]))
        pos = [0] * n
        for k, i in enumerate(order):
            pos[i] = k

        ans = 0
        seen = [False] * n
        for i in range(n):
            if seen[i]:
                continue
            j, length = i, 0
            while not seen[j]:
                seen[j] = True
                j = pos[j]
                length += 1
            ans += length - 1
        return ans
```

## 8. 边界情况与易错点

1. **`n = 1`**：单元素即自环，答案 `0`。
2. **数组已有序**：`pos` 为恒等置换，`n` 个自环，答案 `0`（示例 2）。
3. **平局必须用数值 break**：只按数位和排序时，示例 3 的 `16/34/43` 顺序任意，会算错环结构；又如 `[1000000000, 1]` 两者数位和都是 `1`，目标顺序是 `[1, 1000000000]`，答案 `1` 而非 `0`。
4. **`order` 与 `pos` 别混用**：两者互为逆置换，环分解用哪个都行，但「用 `order` 的值当 `pos` 跳环」这类笔误会得到错误的环长。
5. **比较器里重复拆位**：$O(D \cdot n\log n)$ 的常数放大，Python 尤其容易 TLE，务必预计算 `ds`。
6. **答案上界**：单个大环时最多 $n - 1$ 次交换，`n <= 10^5` 无溢出。
7. **本题是「任意两位置交换」**：不是相邻交换（那应数逆序对），也不是环形数组上的旋转，别套错模板。
