# LeetCode 网格传送门旅游 题解

## 1. 题目概述

- **标题 / 题号**：网格传送门旅游（#3552，medium）
- **链接**：https://leetcode.cn/problems/grid-teleportation-traversal/
- **来源**：LeetCode 第 450 场周赛 Q3
- **难度**：中等
- **标签**：广度优先搜索、最短路、0-1 BFS、矩阵

**题意**：给定 $m \times n$ 字符网格，`.` 是空地、`#` 是障碍、大写字母是**传送门**。从 $(0,0)$ 走到 $(m-1,n-1)$，每步可上下左右移动一格（不可出界、不可进障碍）。当**踏入**一个传送门格子且该字母此前未使用过时，可**立即免费**传送到网格中**另一个**同字母格子；每个字母的传送门全程**至多使用一次**（传送不消耗移动次数）。求最少移动次数，不可达返回 $-1$。

**约束**：

- $1 \le m,\ n \le 10^3$，格子数最多 $10^6$
- `matrix[i][j]` 是 `#`、`.` 或大写字母
- `matrix[0][0]` 保证不是障碍物（起点可出发）

## 2. 示例

**示例 1**

```text
输入：matrix = ["A..", ".A.", "..."]
输出：2
解释：起点 (0,0) 本身是传送门 'A'，第一次移动前先免费传送到 (1,1)；
     再走 (1,1)→(1,2)→(2,2)，共 2 步。
```

**示例 2**

```text
输入：matrix = [".#...", ".#.#.", ".#.#.", "...#."]
输出：13
解释：没有传送门，退化为普通迷宫 BFS：沿左侧通道下到底部，
     横穿到第 2 列后向上绕过障碍区，再从顶行走到右下角，共 13 步。
```

**示例 3**

```text
输入：matrix = ["A.#", "..."]
输出：3
解释：字母 A 只出现一次，不存在"另一个同字母格子"，传送门失效；
     只能绕行障碍：(0,0)→(0,1)→(1,1)→(1,2)，共 3 步。
```

**示例 4**

```text
输入：matrix = [".#", "#."]
输出：-1
解释：起点右侧与下方都是障碍，终点不可达。
```

## 3. 解题思路

### 3.1 暴力思路

最朴素的建模是把「已用过哪些字母」放进 BFS 状态：状态为 (格子, 已用字母集合)。字母最多 26 个，状态空间 $m \cdot n \cdot 2^{26} \approx 6.7 \times 10^{13}$，直接爆炸。

另一个直觉是「同字母格子之间两两连 0 权边，再跑最短路」。这有两个坑：其一，普通 BFS 队列处理不了 0 权边（会破坏按层出队的单调性）；其二，若某字母出现 $k$ 次，两两连边是 $O(k^2)$ 条——极端情况 $10^6$ 个格子全是同一个字母时，边数达 $10^{12}$，建图本身就不可能。

要同时解决这三个问题，需要三件套：**0-1 BFS** 处理 0 权边、**虚拟节点缩点**把 $O(k^2)$ 条边压成 $O(k)$ 条、**短路论证**证明「至多一次」约束免费（最短路天然不会重复使用同一字母，从而无需记录字母集合）。

### 3.2 核心观察：虚拟节点缩点 + 约束免费

![核心观察：同字母格子用虚拟节点缩点](images/wc450_q3_hub_concept.svg)

**观察 1（缩点建模）**：为每个字母 $X$ 建一个**虚拟节点** $V_X$，把所有 $X$ 格子与 $V_X$ 之间连** 0 权双向边**；相邻可通行格子之间连 **1 权边**（步行）。于是一次传送「从 $X$ 格子 $a$ 到 $X$ 格子 $b$」等价于走 $a \to V_X \to b$ 两条 0 权边，而边数从 $O(k^2)$ 降为 $O(k)$，总边数 $O(mn)$。

![短路论证：重复传送可被整段跳过](images/wc450_q3_shortcut_proof.svg)

**观察 2（约束免费）**：「每个字母至多传送一次」**不需要放进状态**。关键是一个**短路论证**：若一条路径两次经过同一个虚拟节点 $V_X$（… → $a$ → $V_X$ → $b$ → 中间段 $\sigma$ → $c$ → $V_X$ → $d$ → …），则可以把中间段整段删掉，直接 $a \to V_X \to d$——传送免费、删掉的步行代价非负，新路径代价不增，且 $X$ 的使用次数还减了一。反复短路可得：**存在一条每个字母至多传送一次的最短路**，故在图上不加任何约束地求最短路，答案自动满足题目限制（严格证明见 §5）。

### 3.3 算法流程

1. 扫描网格，统计每个字母的格子列表 `portals[26]`（只需字母出现 $\ge 2$ 次的）；
2. 节点编号：格子 $(i,j) \to i \cdot n + j \in [0, mn)$，虚拟节点 $V_X \to mn + (X - 'A')$；
3. 从起点 $0$ 出发做 **0-1 BFS**（双端队列 deque）：
   - 弹出 $u$，读当前 $d = dist[u]$；
   - **传送边（权 0）**：若 $u$ 是字母 $X$ 格子且该字母出现 $\ge 2$ 次，松弛 $V_X$，改进则**插到队首**；若 $u$ 是虚拟节点，松弛其所有同字母格子，同样插队首；
   - **步行边（权 1）**：四方向相邻非障碍格子，改进则**压入队尾**；
4. 结束后 $dist[mn-1]$ 即答案，仍为 $\infty$ 则返回 $-1$。

> 💡 0-1 BFS 是边权只有 0/1 时 Dijkstra 的双端队列特例：0 权边插队首保证出队距离单调不减，每个节点只需"近乎一次"有效扩展，整体线性。等价写法是优先队列 Dijkstra，复杂度多个 $\log$ 因子。

### 3.4 示例演算

![示例演算：起点即传送门，先 0 步传送再 2 步走到终点](images/wc450_q3_example_walkthrough.svg)

以示例 1 为例：起点 $(0,0)$ 是 `'A'`，弹出时经 0 权边 $V_A$ 把 $(1,1)$ 的距离定为 $0$（传送免费、且发生在第一次移动之前）；随后从 $(1,1)$ 步行扩展出 $(1,2)$、$(2,1)$（距离 1），再由 $(1,2)$ 扩展出终点 $(2,2)$，距离 $2$。若不传送，$(0,0)$ 到 $(2,2)$ 的曼哈顿距离为 $4$，传送恰好省下 $2$ 步。

## 4. 算法细节

1. **虚拟节点编号**：格子占 $[0, mn)$，$V_X$ 占 $mn + (X - 'A')$，`dist` 数组开 $mn + 26$。弹出的 $u \ge mn$ 即虚拟节点，用 `portals[u - mn]` 展开出边。
2. **不显式建邻接表**：步行边在弹出格子时即时枚举四邻居，传送边由 `portals` 列表即时展开。$10^6$ 节点、$8 \times 10^6$ 条有向边的显式邻接表要几十 MB，隐式展开只需 `dist`（约 4 MB）+ `portals`。
3. **单字母不建传送边**：字母只出现一次时"另一个同字母格子"不存在，显式跳过（`portals[c].size() > 1`），既省事又避免虚拟节点把同一格子以相同距离反复塞回队首。
4. **松弛用弹出时的当前 `dist[u]`**：0-1 BFS 惰性删除写法（不额外记"是否入队"），弹出时无论该条目是否陈旧，用当前 `dist[u]` 做松弛永远合法；strict 比较保证同一距离不会重复入队，节点只会在距离被改进时重新入队。
5. **起点即传送门**：题目允许在第一次移动前传送（示例 1），模型里 `dist[0] = 0` 经 0 权边自然覆盖，无需特判。
6. **终点是传送门也无妨**：答案在"踏入终点"那一刻结算，踏入后才发生的传送（不会再移动）不影响 `dist[终点]`。
7. **答案上界**：$m + n - 2 \le 1998$，`int` 足够。

## 5. 正确性证明

**引理 1（图模型等价）**：记 $G$ 为「格子四相邻 1 权边 + $X$ 格子与 $V_X$ 间 0 权边」的图。则任意合法旅程对应 $G$ 中一条同代价的起点→终点路径，且其中每个虚拟节点至多经过一次；反之，$G$ 中任意「每个虚拟节点至多经过一次」的路径对应一条同代价的合法旅程。

**证明**：
- 旅程→路径：每次步行 $(u \to v)$ 映射为 1 权边；每次传送（踏入 $X$ 格 $a$ 传到 $X$ 格 $b$，$a \ne b$）映射为 $a \to V_X \to b$ 两条 0 权边。传送免费，代价相同；每字母至多传送一次，故每个 $V_X$ 至多经过一次。
- 路径→旅程：设路径经过的虚拟节点依次为 $V_{X_1}, \dots, V_{X_t}$（互不相同）。$V_{X_i}$ 在路径中的相邻两步必是「某 $X_i$ 格子 $\to V_{X_i} \to$ 某 $X_i$ 格子」：若进出的是**不同**格子，把这三点片段还原为一次传送；若是**同一**格子，该片段是权 0 的零环，直接删除。其余步行片段原样保留。替换后每个字母恰传送一次或零次，是合法旅程，代价相同。∎

**引理 2（短路引理）**：设 $P$ 是 $G$ 中起点→终点的路径，某虚拟节点 $V_X$ 被经过至少两次。取**相邻**的两次经过（两次之间不再经过 $V_X$），记为
$$\cdots \to a \to V_X \to b \to \sigma \to c \to V_X \to d \to \cdots$$
其中 $\sigma$ 是 $b$ 到 $c$ 的中间段。将其替换为 $\cdots \to a \to V_X \to d \to \cdots$ 得新路径 $P'$，则 $w(P') \le w(P)$，且 $P'$ 中每个虚拟节点的经过次数不超过 $P$ 中对应次数（$V_X$ 恰减一）。

**证明**：替换删去了中间段 $\sigma$ 与第二次经过 $V_X$ 的两条 0 权边，保留第一次经过。边权非负，故 $w(P') = w(P) - w(\sigma) - 0 \le w(P)$；$V_X$ 经过次数减一，$\sigma$ 内部经过的虚拟节点次数只减不增，其余不受影响。∎

**定理**：$G$ 中起点到终点的最短路权值等于合法旅程的最少移动次数。

**证明**：
- **≥ 方向**：由引理 1，任一合法旅程对应 $G$ 中一条同代价路径，故最少移动次数 $\ge$ 最短路权。
- **≤ 方向**：取一条最短路 $P^*$。若存在虚拟节点被经过 $\ge 2$ 次，由引理 2 可得代价不增、且「所有虚拟节点经过次数总和」严格递减的路径。该总和是非负整数，反复应用引理 2 必然终止于一条每个虚拟节点至多经过一次、权值不增的路径 $P'$。由引理 1，$P'$ 对应一条代价为 $w(P') \le w(P^*)$ 的合法旅程，故最短路权 $\le$ 最少移动次数。
两个方向夹逼相等。∎

**推论**：在 $G$ 上不加「每字母一次」约束、直接用 0-1 BFS 求最短路，所得即为答案。0-1 BFS 在非负 0/1 权图上求出最短路是标准结论（双端队列保证出队距离单调不减，与 Dijkstra 等价）。

## 6. 复杂度分析

- **时间复杂度**：$O(mn)$。节点数 $mn + 26$；每个格子至多做 4 次步行松弛，传送边星形共 $\sum_X |portals_X| \le mn$ 条，边规模 $O(mn)$；0-1 BFS 每条边至多被松弛常数次，整体线性。对比暴力 $(格子, 字母集合)$ 状态的指数级与两两连边的 $O(k^2)$ 建图，这是能通过 $10^6$ 格子的关键。
- **空间复杂度**：$O(mn)$。`dist` 数组 $mn + 26$、`portals` 列表合计至多 $mn$ 个下标、双端队列至多存 $O(mn)$ 个元素。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minMoves(vector<string>& matrix) {
        int m = matrix.size(), n = matrix[0].size();
        int total = m * n;
        vector<vector<int>> portals(26);
        for (int i = 0; i < m; i++)
            for (int j = 0; j < n; j++) {
                char c = matrix[i][j];
                if (c >= 'A' && c <= 'Z') portals[c - 'A'].push_back(i * n + j);
            }

        vector<int> dist(total + 26, INT_MAX);
        deque<int> dq;
        dist[0] = 0;
        dq.push_back(0);
        int dx[4] = {0, 0, 1, -1}, dy[4] = {1, -1, 0, 0};

        while (!dq.empty()) {
            int u = dq.front();
            dq.pop_front();
            int d = dist[u];
            if (u >= total) {
                for (int v : portals[u - total])
                    if (d < dist[v]) {
                        dist[v] = d;
                        dq.push_front(v);
                    }
                continue;
            }
            int x = u / n, y = u % n;
            char c = matrix[x][y];
            if (c >= 'A' && c <= 'Z' && portals[c - 'A'].size() > 1) {
                int hub = total + (c - 'A');
                if (d < dist[hub]) {
                    dist[hub] = d;
                    dq.push_front(hub);
                }
            }
            for (int k = 0; k < 4; k++) {
                int nx = x + dx[k], ny = y + dy[k];
                if (0 <= nx && nx < m && 0 <= ny && ny < n && matrix[nx][ny] != '#') {
                    int v = nx * n + ny;
                    if (d + 1 < dist[v]) {
                        dist[v] = d + 1;
                        dq.push_back(v);
                    }
                }
            }
        }
        return dist[total - 1] == INT_MAX ? -1 : dist[total - 1];
    }
};
```

### Python

```python
class Solution:
    def minMoves(self, matrix: List[str]) -> int:
        m, n = len(matrix), len(matrix[0])
        total = m * n
        portals = [[] for _ in range(26)]
        for i in range(m):
            for j in range(n):
                c = matrix[i][j]
                if c.isalpha():
                    portals[ord(c) - 65].append(i * n + j)

        INF = float('inf')
        dist = [INF] * (total + 26)
        dist[0] = 0
        dq = deque([0])
        while dq:
            u = dq.popleft()
            d = dist[u]
            if u >= total:
                for v in portals[u - total]:
                    if d < dist[v]:
                        dist[v] = d
                        dq.appendleft(v)
                continue
            x, y = divmod(u, n)
            c = matrix[x][y]
            if c.isalpha() and len(portals[ord(c) - 65]) > 1:
                hub = total + ord(c) - 65
                if d < dist[hub]:
                    dist[hub] = d
                    dq.appendleft(hub)
            for x2, y2 in ((x, y + 1), (x, y - 1), (x + 1, y), (x - 1, y)):
                if 0 <= x2 < m and 0 <= y2 < n and matrix[x2][y2] != '#':
                    v = x2 * n + y2
                    if d + 1 < dist[v]:
                        dist[v] = d + 1
                        dq.append(v)
        return -1 if dist[total - 1] == INF else dist[total - 1]
```

## 8. 边界情况与易错点

1. **$1 \times 1$ 网格**：起点即终点，答案 $0$；即使该格是传送门也无事可做。
2. **起点是传送门**：允许第一次移动前传送（示例 1），模型中 0 权边自动覆盖，不要特判"第一步不能传"。
3. **字母只出现一次**：传送无意义，务必跳过建边；若误建自环，虽不改变答案（strict 比较不通过），但会做无用功。
4. **切勿把字母集合塞进状态**：$2^{26}$ 状态必然 MLE/TLE；本题的考点恰是证明该约束可丢弃（§5 短路论证）。
5. **切勿两两连 0 权边**：$10^6$ 个同字母格子会得到 $10^{12}$ 条边，必须星形缩点。
6. **切勿用普通队列跑 0 权图**：0 权边会把"更近"的节点排到后面，普通 BFS 求出的距离可能偏大；必须双端队列（0 权插队首）或 Dijkstra。
7. **不可达**：障碍隔断时 `dist[终点]` 保持 $\infty$，返回 $-1$（示例 4）。
8. **惰性删除的写法**：弹出节点后用当前 `dist[u]` 松弛即可，无需"是否访问过"标记；但若改成「弹出即定型」的 Dijkstra 写法，要保证用堆/双端队列的距离单调性，不要混用两种模式的断言。
9. **性能**：$mn = 10^6$，C++ 轻松通过；Python 建议把 `matrix` 行引用、`dist` 等做成局部变量并使用 `deque`，避免逐格 `str` 切片的额外开销。
