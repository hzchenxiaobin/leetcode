# LeetCode 最常见的单词 题解

## 1. 题目概述

- **标题 / 题号**：最常见的单词（#819，easy）
- **链接**：https://leetcode.cn/problems/most-common-word/
- **来源**：LeetCode 第 80 场周赛 Q1
- **难度**：简单
- **标签**：数组、哈希表、字符串、计数

**题意**：给定段落 `paragraph` 与禁用词表 `banned`，把段落按「非字母字符」切成单词，忽略大小写统计词频，返回**出现次数最多的非禁用词**，并以小写形式返回。

**约束**：

- $1 \le \lvert \text{paragraph} \rvert \le 1000$
- `paragraph` 由英文字母、空格与 `!` `?` `'` `,` `;` `.` 六种标点组成
- $0 \le \lvert \text{banned} \rvert \le 100$，$1 \le \lvert \text{banned}[i] \rvert \le 10$，且 `banned[i]` 仅含小写字母
- 数据保证至少存在一个非禁用词，且答案唯一

> 💡 答案唯一意味着**不必处理并列**：只要用严格大于号更新最优，谁先达到最大次数谁就是答案，不需要字典序兜底。

## 2. 示例

**示例 1**

```text
输入：paragraph = "Bob hit a ball, the hit BALL flew far after it was hit.", banned = ["hit"]
输出："ball"
解释：归一化后 hit 出现 3 次、ball 出现 2 次，其余 8 个词各 1 次；
      hit 是禁用词，所以答案是 ball。
```

**示例 2**

```text
输入：paragraph = "a.", banned = []
输出："a"
解释：段落到最后一个字符是标点，词 “a” 仍要在 j 撞到字符串末尾时被取出。
```

**示例 3**（补充用例：禁用词被整段过滤 + 连续逗号）

```text
输入：paragraph = "a, a, a, a, b,b,b,c, c", banned = ["a"]
输出："b"
解释：a 出现 4 次但被禁用；b 出现 3 次、c 出现 2 次，故答案为 b。
```

## 3. 解题思路

### 3.1 暴力思路

先按分隔符把段落切成一列词，再对每个**不同的**词回扫整列词统计次数：设词数 $W$、禁用词数 $B$，复杂度 $O(W^2 + WB)$。最坏情形下每个字母自成一词，$W \le 1000$，本题数据量下勉强能过，但这是纯重复劳动，而且真正的坑不在复杂度而在**切词**。

常见的错误切法是 `paragraph.lower().split(' ')` 或按六个标点逐个 `replace` 再 `split`：前者会把 `"ball,"`、`"hit."` 连同标点一起当成词，后者要写六次替换、漏一个就 WA。周赛 Q1 的追求是**一次写对、边扫边算**，所以下面直接做单趟扫描 $O(N)$。

### 3.2 核心观察：把切词、归一、过滤合并成一次扫描

![单词 = 极大连续字母段，双指针夹出每个词](images/wc80_q1_scan_tokenize.svg)

**关键定义**：单词就是段落里的**极大连续字母段**。于是「切词」不需要任何 `split`，只要两个指针：

- $i$ 指向下一段字母的首字符（沿途跳过所有非字母字符）；
- $j$ 从 $i$ 出发右移，直到 `paragraph[j]` 不是字母为止。

此时区段 $[i, j)$ 就是一个完整的词，长度 $\lvert w \rvert = j - i$。注意 $j$ 停在**第一个非字母**上——`"ball,"` 的逗号天然被挡在词外，这正是「单词不含标点」的形式化表述。

在同一个区段上顺手做完另外两件事：

1. **归一**：边读边转小写，得到 `"BALL"` → `"ball"`；
2. **过滤**：`banned` 先转成集合，若小写形式在集合里就直接跳过，连哈希表都不写。

这样「切词、归一、过滤、计数」四步共享同一趟扫描，总代价 $O(\lvert \text{paragraph} \rvert)$。

### 3.3 算法流程

![单趟扫描 + 哈希表计数的五个步骤与循环回边](images/wc80_q1_algorithm_flow.svg)

1. `ban = set(banned)`，`cnt = {}`，`best = ""`，`bestCnt = 0`，`i = 0`。
2. 若 `i` 越界则跳到第 7 步；否则若 `paragraph[i]` 不是字母，`i += 1` 后重复本步。
3. `j = i`，在 `j` 未越界且 `paragraph[j]` 是字母时不断右移 `j`。
4. 取 $w = \text{lower}(\text{paragraph}[i..j))$，并令 `i = j`（下一次外层循环从分隔符处继续）。
5. 若 $w \in \text{ban}$，丢弃并回到第 2 步。
6. `cnt[w] += 1`；若 `cnt[w] > bestCnt`，则 `bestCnt = cnt[w]`、`best = w`；回到第 2 步。
7. 返回 `best`。

第 4 步的 `i = j` 是整个流程的**推进保证**：$j$ 严格大于 $i$，所以 $i$ 每次至少前进一格，循环必然终止。

### 3.4 示例演算

![示例 1 的归一化、过滤与词频条形图](images/wc80_q1_walkthrough.svg)

对 `paragraph = "Bob hit a ball, the hit BALL flew far after it was hit."`、`banned = ["hit"]`：

| 扫描到的区段 | 小写形式 | 是否在 `banned` | 动作 | 表内状态 |
|--------------|----------|-----------------|------|----------|
| `Bob` | `bob` | 否 | `cnt[bob]=1` | bob=1（best=bob） |
| `hit` | `hit` | **是** | 丢弃 | 不变 |
| `a` | `a` | 否 | `cnt[a]=1` | bob=1, a=1 |
| `ball,` → `ball` | `ball` | 否 | `cnt[ball]=1` | ball=1 |
| `the` | `the` | 否 | `cnt[the]=1` | 四个词并列 1 |
| `hit` | `hit` | **是** | 丢弃 | 不变 |
| `BALL` | `ball` | 否 | `cnt[ball]=2` | **ball=2 → best** |
| `flew` `far` `after` `it` `was` | 各自小写 | 否 | 各 `+1` | 均为 1 |
| `hit.` → `hit` | `hit` | **是** | 丢弃 | 不变 |

扫描结束后 `bestCnt = 2`、`best = "ball"`，返回 `"ball"`。整段共 13 个词、10 个互不相同的归一化形式；`hit` 的 3 次全部被 banned 过滤，剩下 9 个非禁用词中 8 个各 1 次、`ball` 2 次。

## 4. 算法细节

1. **分隔符判据用「是不是字母」，而不是「是不是空格」**。题面给的标点是封闭集合，但按字母判是最贴合定义、也最不容易漏的做法：`isalpha` 为真才进词，否则一律当分隔符。
2. **小写化必须发生在查 `banned` 之前**。`banned` 里全是小写，若先拿原词查表再小写，`"Hit"`、`"BALL"` 就会漏判成非禁用词。
3. **`i = j` 而不是 `i += 1`**。若内层结束后只让 $i$ 前进一步，同一个词的每个字符都要重新判断，复杂度退化成 $O(\lvert\text{paragraph}\rvert \cdot \lvert w \rvert)$。
4. **不要整段 `toLowerCase` 后再按下标回溯**。ASCII 下长度不变看似安全，但一旦混入非 ASCII 字符，大小写映射可能改变长度，原始下标就会错位；边读边转小写则没有这个问题，也省掉一份 $O(N)$ 的副本。
5. **`banned` 一定要转集合**。$B \le 100$、$W \le 1000$ 时线性查找也能过，但用 `unordered_set` / `set` 把每次判定压到期望 $O(1)$，代码只多一行。
6. **用严格大于号更新最优**。写成 `>=` 会让「后来居上的同频词」覆盖前面的答案；本题答案唯一所以两者结果相同，但 `>` 的语义更稳，也便于把代码推广到「返回第一个达到最大频次的词」。
7. **C++ 的 `isalpha` 必须传 `unsigned char`**。`isalpha(char)` 在字符为负（高位 ASCII / 非 ASCII 字节）时是未定义行为，写 `isalpha((unsigned char)c)` 更安全。
8. **累加与比较的顺序**：先 `cnt[w] += 1` 再比较 `cnt[w]`，不要拿累加前的旧值比较，否则每个词都会晚一步更新最优。

## 5. 正确性证明

**引理 1（切分不重不漏）**：算法枚举出的每个区段 $[i, j)$ 都是 `paragraph` 的一段极大连续字母段；反过来，`paragraph` 的每段极大连续字母段都被枚举恰好一次。

**证明**：进入内层时 `paragraph[i]` 是字母；内层 `j` 一直右移到 `j = n` 或 `paragraph[j]` 非字母才停，故 $[i, j)$ 内部全为字母、右邻（若存在）不是字母；左邻若存在则为 `paragraph[i-1]`，而 $i$ 是由外层逐个跳过非字母（或上一段的 $j$）得到的，故它也非字母。于是 $[i, j)$ 是极大字母段。

不重叠：下一次外层的起点是上一段的 $j$，而 $[i, j)$ 已被完全跳过。不遗漏：设某极大字母段起始于 $p$，在此之前的所有字符都是非字母，外层循环逐个跳过、直到 $i = p$ 才进入内层，内层随即吃掉整段并把 $i$ 推到它的右邻。∎

**引理 2（计数不变式）**：设扫描指针为 $i$，记 $P_i$ 为 $\text{paragraph}[0..i)$ 中**已完整扫过**的全部区段构成的多重集（同一词出现多次就算多个元素）。则对任意非禁用词 $w$，

$$\text{cnt}[w] = \#\{\,v \in P_i : v = w\,\}, \qquad \text{bestCnt} = \max_{w \notin \text{ban}} \text{cnt}[w]$$

且 `best` 是取到该最大值的某个非禁用词（`cnt` 中不存在的键视为 0）。

**证明**：对 $i$ 归纳。初始 $i = 0$、表为空、`bestCnt = 0`，成立。设当前成立，内层结束于区段 $[i, j)$：由引理 1 它是尚未计入的完整词，算法对它的处理只有两种——$w \in \text{ban}$ 时什么都不写，非禁用词时 `cnt[w]` 加一，恰好与右端集合的增长一致。随后若新的 `cnt[w]` 超过 `bestCnt` 就同时更新二者，故最大值与代表元仍保持正确。其余键不受影响，归纳成立。∎

**定理（算法正确）**：扫描结束时返回的 `best` 是 `paragraph` 中出现次数最多的非禁用词。

**证明**：扫描结束时 $P_N$ 覆盖全部极大字母段（引理 1），由引理 2，`cnt` 就是各非禁用词的真实词频，且 `bestCnt` 是其中的最大值、`best` 取到该值。题面保证至少存在一个非禁用词，故 `best` 不是空串；又保证答案唯一，故 `best` 就是唯一答案。∎

## 6. 复杂度分析

- **时间**：$O(N + B + W)$，其中 $N = \lvert\text{paragraph}\rvert$、$B = \sum \lvert\text{banned}[i]\rvert$、$W$ 为词数。外层指针 $i$ 单调右移共 $N$ 次，内层指针 $j$ 全程也只右移 $N$ 次，故字符判断共 $O(N)$；每个词做一次小写拼接（$O(\lvert w\rvert)$，已计入 $N$）、一次期望 $O(1)$ 的集合查询与哈希累加；读入 `banned` 建集合 $O(B)$。最坏 $N = 1000$、$B = 1000$，常数极小。
- **空间**：$O(D + B + L)$。`cnt` 存 $D$ 个不同非禁用词，禁用词集合占 $O(B)$，扫描时的单词缓冲区最长 $O(L)$（$L$ 为最长单词长度）。注意 $L \le N$，若改为先就地小写再截取，缓冲区同样只需 $O(L)$。

## 7. 参考代码

### C++

```cpp
#include <string>
#include <vector>
#include <unordered_set>
#include <unordered_map>
#include <cctype>
using namespace std;

class Solution {
public:
    string mostCommonWord(string paragraph, vector<string>& banned) {
        unordered_set<string> ban(banned.begin(), banned.end());
        unordered_map<string, int> cnt;          // 非禁用词 -> 出现次数
        const int n = (int)paragraph.size();
        string best;
        int bestCnt = 0;

        for (int i = 0; i < n; ) {
            if (!isalpha((unsigned char)paragraph[i])) { ++i; continue; }  // 跳过分隔符
            int j = i;
            string w;
            while (j < n && isalpha((unsigned char)paragraph[j])) {
                w.push_back((char)tolower((unsigned char)paragraph[j]));  // 边扫边小写
                ++j;
            }
            i = j;                              // 从词边界继续，绝不 i++
            if (ban.count(w)) continue;         // 禁用词直接丢弃
            int c = ++cnt[w];
            if (c > bestCnt) { bestCnt = c; best = w; }
        }
        return best;
    }
};
```

### Python

```python
class Solution:
    def mostCommonWord(self, paragraph: str, banned: list[str]) -> str:
        ban = set(banned)
        cnt = {}
        best, best_cnt = "", 0
        i, n = 0, len(paragraph)

        while i < n:
            if not paragraph[i].isalpha():      # 分隔符：跳过
                i += 1
                continue
            j = i
            buf = []
            while j < n and paragraph[j].isalpha():
                buf.append(paragraph[j].lower())  # 边扫边小写
                j += 1
            i = j                               # 从词边界继续，绝不 i += 1
            w = "".join(buf)
            if w in ban:                        # 禁用词：不计数
                continue
            cnt[w] = cnt.get(w, 0) + 1
            if cnt[w] > best_cnt:
                best_cnt, best = cnt[w], w
        return best
```

## 8. 边界情况与易错点

1. **段落末尾没有标点**。`"Bob"` 的内层循环会在 `j == n` 时结束，区段照样是 `[0, 3)`；把内层条件写成「`j < n and 非字母` 才停」或漏掉 `j < n` 都会越界或死循环。
2. **标点紧贴单词**。`"ball,"`、`"hit."`、`"it's"` 必须以字母边界切：前两例分别是 `ball` 与 `hit`，`"it's"` 会切成 `it` 和 `s` 两个词——这是按题意（标点即分隔）的**正确**行为，不要试图保留撇号。
3. **连续或重复标点**。`"b,b,b"`、`"a , b"` 中的逗号、空格连续出现时，外层只是连续 `i += 1`；内层至少读到一个字母才会产出词，因此不会产生空字符串键。
4. **大小写混排**。`"BALL"` 与 `"ball"` 必须合并为同一个键，`"Bob"` 必须以 `bob` 输出；小写化要同时用于查禁用词和写哈希表。
5. **禁用词全部命中**。若某词出现在 `banned`，就不能进入 `cnt`；否则像示例 1 的 `hit`（3 次）会盖过 `ball`（2 次）而返回错误答案。
6. **`best` 的初值**。题面保证至少有一个非禁用词，所以循环结束 `best` 一定被赋过值；若把代码推广到「可能全是禁用词」的场景，需自行决定是返回空串还是抛异常，别让 `bestCnt` 初值 0 与「词频至少 1」混淆。
7. **C++ 的字符分类函数**。`isalpha` / `tolower` 的参数必须是 `unsigned char` 提升后的值，直接传负值字符是未定义行为；同时 `cnt[w]` 的 `operator[]` 会在键不存在时插入 0，正好配合 `++cnt[w]`。
8. **Python 的字符串拼接**。循环里用 `w += ch` 在 CPython 上有优化，但 `list + join` 语义更清晰；若在别的实现上跑，前者可能退化成 $O(\lvert w\rvert^2)$。
