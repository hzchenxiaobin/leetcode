# LeetCode 模糊坐标 题解

## 1. 题目概述

- **标题 / 题号**：模糊坐标（#816，medium）
- **链接**：https://leetcode.cn/problems/ambiguous-coordinates/
- **来源**：LeetCode 第 80 场周赛 Q3
- **难度**：中等
- **标签**：字符串、枚举、回溯

**题意**：原本有若干形如 `"(1, 3)"`、`"(2, 0.5)"` 的二维坐标，把它们里面的逗号、小数点、空格全部删掉，得到只含括号与数字的字符串 `s`。现在要求由 `s` 反推**所有可能的原始坐标**。两个数字之间固定写成 `", "`（逗号后一个空格），答案顺序任意。

约束的实质是「**规范写法**」：不能有多余的零。既不允许前导零（`"00"`、`"001"`），也不允许小数部分以零结尾（`"1.0"`、`"0.10"`），还不允许小数点前没有数字（`".1"`）。换言之，每个数都用「表示同一数值所需的最少数字位数」来书写。

**约束**：

- $4 \le \lvert s \rvert \le 12$
- `s[0] == '('`、`s[s.size()-1] == ')'`，其余字符均为数字
- 括号内部只有数字，故数字串长度 $n = \lvert s \rvert - 2 \le 10$

> 💡 数据规模是本场最温和的一题：$n \le 10$，合法组合最多 $165$ 个，**枚举就是正解**。真正的难点是把「什么算合法」写准、写全。

## 2. 示例

**示例 1**

```text
输入：s = "(123)"
输出：["(1, 2.3)", "(1, 23)", "(1.2, 3)", "(12, 3)"]
解释：切点 i=1 得 (1, 23)、(1, 2.3)；i=2 得 (1.2, 3)、(12, 3)。
```

**示例 2**

```text
输入：s = "(0123)"
输出：["(0, 1.23)", "(0, 12.3)", "(0, 123)", "(0.1, 2.3)", "(0.1, 23)", "(0.12, 3)"]
解释：共 6 个。左段为 "01"、"012" 时整数形式非法，只能写成小数。
```

**示例 3**

```text
输入：s = "(00011)"
输出：["(0, 0.011)", "(0.001, 1)"]
解释：0.0、00、0001、00.01 都不被允许——它们都有多余的零。
```

## 3. 解题思路

### 3.1 暴力思路

最直白的暴力是「往字符串里插符号」：在数字串的 $n-1$ 个空隙里放逗号（$n-1$ 种），再在两个数各自的空隙里放至多一个小数点（各 $O(n)$ 种），拼出候选串后用判定函数检查是否为规范写法。候选数只有 $O(n^3) \le 900$，这套做法其实能过，但有两处别扭：位置枚举会造出大量「必然非法」的候选（点在首位之前、末位之后），判定函数又要重新解析 `".1"`、`"1."`、`"00.1"` 这些边界，容易与构造逻辑写得对不上。

更干净的做法是把「位置枚举」换成「**形态枚举**」：先定逗号（分组），再让每段各自列出所有合法写法。两种决策彼此独立，天然是两层循环加笛卡尔积。

### 3.2 核心观察：逗号定分组，小数点定形态

![两层枚举：逗号切点 × 小数点位置](images/wc80_q3_two_level_enum.svg)

把 $s$ 去掉首尾括号得到数字串 $t$，长度 $n$。

- **第一层（逗号）**：原坐标 `"(x, y)"` 里，$x$ 的数字序列一定是 $t$ 的某个前缀，$y$ 是剩下的后缀。前缀长度 $i$ 满足 $1 \le i \le n-1$（两侧都至少一个数字），取遍就枚举了所有分组。
- **第二层（小数点）**：分组固定后 $x$ 与 $y$ 的写法**互不影响**，每段只需回答：数字串 $w$ 能写成哪些规范形式？

于是问题被压成子过程 `forms(w)`：输入一段数字串，输出它所有合法的书写形式。

![一段数字串的两条合法规则](images/wc80_q3_valid_number_rules.svg)

设 $w$ 长度为 $L$，字符为 $w[0..L-1]$。合法形态只有两类：

**规则 A（不加小数点）**：整段就是整数，合法当且仅当

$$L = 1 \quad\text{或}\quad w[0] \ne \texttt{'0'}$$

即「单个数字」或「首位非零」——前者让数字 $0$ 有写法，后者禁掉前导零。

**规则 B（在第 $k$ 位后加小数点，$1 \le k \le L-1$）**：写成 $w[0..k-1] \,\textbf{.}\, w[k..L-1]$，合法当且仅当

$$\bigl(k = 1 \ \text{或}\ w[0] \ne \texttt{'0'}\bigr) \ \wedge\ w[L-1] \ne \texttt{'0'}$$

- 前半句管**整数部**：$k=1$ 时点前只有一位，即使这位是 `'0'` 也合法（这就是 `"0.1"`、`"0.011"` 的来源）；$k \ge 2$ 时点前有前导零，非法（`"00.1"`）。
- 后半句管**小数部末位**：若末位是 `'0'`，删掉它数值不变而位数更少，说明原写法有多余的零（`"1.0"`、`"0.10"`）。

$1 \le k \le L-1$ 同时保证了「点前至少一位、点后至少一位」，所以 `".1"` 与 `"1."` 根本不会进入枚举。

### 3.3 算法流程

![算法流程：切点循环 + 形态生成](images/wc80_q3_algorithm_flow.svg)

1. 去掉首尾括号，得到长度 $n = \lvert s \rvert - 2$ 的数字串 $t$；
2. 枚举切点 $i = 1 \ldots n-1$，令 `left = forms(t[:i])`、`right = forms(t[i:])`；
3. 若 `left` 或 `right` 为空，说明该切点一侧无论怎么写都不合法，`continue`；
4. 否则做笛卡尔积：对每个 $a \in \texttt{left}$、$b \in \texttt{right}$，把 `"(" + a + ", " + b + ")"` 加入答案；
5. 返回答案列表（顺序任意）。

其中 `forms(w)` 按规则 A、规则 B 逐条尝试即可，**不需要递归**——每段至多一个小数点，形态数是 $O(L)$，写成两段循环比回溯更直接。

### 3.4 示例演算

以 `s = "(0123)"` 为例，$t = \texttt{"0123"}$，$n = 4$，切点只有 $i = 1,2,3$：

![演算：s = "(0123)" 的三个切点](images/wc80_q3_walkthrough.svg)

| 切点 $i$ | 左段与形态 | 右段与形态 | 条数 |
|---|---|---|---|
| 1 | `"0"` → `{0}` | `"123"` → `{123, 1.23, 12.3}` | 3 |
| 2 | `"01"` → `{0.1}` | `"23"` → `{23, 2.3}` | 2 |
| 3 | `"012"` → `{0.12}` | `"3"` → `{3}` | 1 |

合计 $3+2+1 = 6$ 个，与官方输出一致。

两处值得单独核对：

- 左段 `"01"`：规则 A 被「首位 `'0'` 且 $L>1$」否掉；规则 B 的 $k=1$ 给出 `"0.1"`（末位 `'1'` 非零），$k=2$ 越界（$L-1=1$），故只剩 `"0.1"`。
- 左段 `"012"`：规则 A 同理否掉；规则 B 中 $k=1$ 得 `"0.12"`，$k=2$ 的整数部 `"01"` 有前导零被否，故只剩 `"0.12"`。

再看 `"(00011)"`：切点 $i=1$ 给出左 `{0}`、右 `"0011"` 的 `{0.011}`；$i=2,3$ 的左段 `"00"`、`"000"` 无任何合法形态（整数有前导零，小数末位又是零）；$i=4$ 左段 `"0001"` 只有 `"0.001"`、右段 `"1"`。结果恰好是官方那两个。

## 4. 算法细节

1. **切分下标要清楚**：`t = s.substr(1, s.size() - 2)`（C++ 的第二个参数是**长度**，不是结束下标）或 `t = s[1:-1]`（Python）。
2. **整数部合法性写成 `k == 1 || w[0] != '0'`**：$k=1$ 时点前只有一位，必合法，无需再判断这位是不是 `'0'`；漏掉这个豁免会丢掉全部 `"0.xxx"` 形态。尾零则看**整段末位** `w.back()`（小数部就是 `w[k:]`，其末位即 $w[L-1]$），不是看小数部首位。
3. **两种形态互不干扰**：规则 A、规则 B 各写一个 `if`，不要试图用「先判整数、不合法再试小数」的链式逻辑——`"0"` 同时满足规则 A，而 `"01"` 两条都不满足，两者不是互斥关系。
4. **不要用 `set` 去重**：切点与两侧形态唯一决定输出串（见引理 2），天然无重复；加 `set` 只是把 $O(A)$ 变成 $O(A \log A)$，还可能打乱「输出顺序任意」这一约定。
5. **不要借浮点数判合法**：$0.10$ 与 $0.1$ 数值相等，但只有后者合法；差别只在「小数点后写了几位」，一旦转成 `double` 就丢了。全程用字符串比较。

## 5. 正确性证明

记 $t$ 为 $s$ 去掉首尾括号后的数字串，$n = \lvert t \rvert$，`forms(w)` 为按 §3.2 两条规则生成的形态集合。

**引理 1（形态刻画）**：对任意长度 $L \ge 1$ 的数字串 $w$，在 $w$ 中插入至多一个小数点后得到的**规范写法**，恰好是 `forms(w)` 的全部元素。

**证明**：

（$\subseteq$）设 $R$ 是 $w$ 的一种规范写法。

- 若 $R$ 不含小数点，则 $R = w$。若 $L \ge 2$ 且 $w[0] = \texttt{'0'}$，则 $R$ 带前导零，删去它不改变数值却少一位，与「无多余零」矛盾。故 $L = 1$ 或 $w[0] \ne \texttt{'0'}$，$R$ 被规则 A 收录。
- 若 $R$ 含小数点，设它写在第 $k$ 位之后。点前、点后都必须非空，故 $1 \le k \le L-1$。若 $k \ge 2$ 且 $w[0] = \texttt{'0'}$，整数部有前导零，矛盾，故 $k = 1$ 或 $w[0] \ne \texttt{'0'}$。若 $w[L-1] = \texttt{'0'}$，删去小数部末位后数值不变而位数更少，又矛盾，故 $w[L-1] \ne \texttt{'0'}$。于是 $R$ 被规则 B 收录。

（$\supseteq$）规则 A 产出的 $w$：$L=1$ 或首位非零，既无前导零也无小数点，是规范写法。规则 B 产出的 $w[0..k-1] \textbf{.} w[k..L-1]$：整数部要么是一位数字、要么首位非零，均无前导零；小数部非空且末位非零，删掉任一位都会改变数值、去掉小数点则改变数量级，故不存在更短的等价写法（十进制规范写法唯一：两个不含多余零的写法若同值，则数字串逐位相同）。综上两者都规范。$\blacksquare$

**引理 2（一一对应）**：映射

$$(i,\,a,\,b)\ \longmapsto\ \texttt{"("} + a + \texttt{", "} + b + \texttt{")"}$$

在集合 $S = \{(i,a,b) \mid 1 \le i \le n-1,\ a \in \texttt{forms}(t[0..i-1]),\ b \in \texttt{forms}(t[i..n-1])\}$ 上是单射，且其像恰为本题的全部合法原坐标。

**证明**：

**像合法**：由引理 1，$a$、$b$ 都是规范写法。把输出串按 `", "` 切开得到 $a$、$b$，再删去各自的小数点，得到的数字串分别是 $t[0..i-1]$ 与 $t[i..n-1]$，按序拼接正好是 $t$。故删去逗号、小数点、空格、括号后恰好还原 $s$，它确实是可能的原始坐标。

**覆盖**：设某个合法原坐标为 `"(x, y)"`，删去三个符号后得到 $t$。设 $x$ 的写法含 $i$ 个数字、$y$ 含 $n-i$ 个，两侧都至少一位，故 $1 \le i \le n-1$；又删符号只是把数字按原序拼接，所以 $x$ 的数字串必是 $t[0..i-1]$、$y$ 的必是 $t[i..n-1]$。由引理 1，$x$、$y$ 的写法分别属于两侧的 `forms` 集合，于是该坐标被 $(i,a,b)$ 生成。

**单射**：给定输出串，按 `", "` 切开后 $a$、$b$ 唯一；从 $a$、$b$ 中删去小数点得到两段数字，其长度唯一确定 $i$。故 $S$ 中不同的三元组不可能给出相同字符串。$\blacksquare$

**定理**：算法返回的列表恰好包含全部合法原坐标，且每个只出现一次。

**证明**：算法在 $i = 1 \ldots n-1$ 上枚举、对每对 $(a,b) \in \texttt{left} \times \texttt{right}$ 输出拼接结果，正是引理 2 中映射的像（跳过空集不影响像）。由引理 2，该像等于全部合法原坐标，且映射单射，故无重复。$\blacksquare$

## 6. 复杂度分析

- **时间**：外层 $n-1$ 个切点；每个切点内生成两段形态，共 $O(n)$ 个形态，每个形态需要 $O(n)$ 的字符拷贝，故单个切点 $O(n^2)$，总计 $O(n^3)$。拼接答案时每个输出串长度 $O(n)$，设答案个数为 $A$，再计入 $O(A \cdot n)$。$n \le 10$ 时全部操作在 $10^4$ 量级，远低于时限。
- **空间**：除答案外只需暂存两段形态，$O(n^2)$；输出本身的存储为 $O(A \cdot n)$，其中 $A \le \sum_{i=1}^{n-1} i(n-i) = \dfrac{n^3-n}{6}$，$n = 10$ 时 $A \le 165$。
- **答案规模上界**：切点 $i$ 处左段至多 $i$ 种形态、右段至多 $n-i$ 种，故

$$A \le \sum_{i=1}^{n-1} i\,(n-i) = \frac{n^3-n}{6}$$

所有位都非零时取等（`"1111111111"` → 165 个）。末位是 `'0'` 的输入会少得多（`"1234567890"` 只有 45 个）：右侧所有小数形态都被尾零否掉。这也解释了为什么本题可以直接枚举而不必担心输出爆炸。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    vector<string> ambiguousCoordinates(string s) {
        string t = s.substr(1, s.size() - 2);   // 去掉首尾括号
        int n = (int)t.size();
        vector<string> ans;
        for (int i = 1; i < n; ++i) {
            vector<string> left = forms(t.substr(0, i));
            if (left.empty()) continue;
            vector<string> right = forms(t.substr(i));
            if (right.empty()) continue;
            for (const string &a : left)
                for (const string &b : right)
                    ans.push_back("(" + a + ", " + b + ")");
        }
        return ans;
    }
  private:
    // 一段数字串的全部规范写法（整数形式 + 小数形式）
    vector<string> forms(const string &w) {
        int m = (int)w.size();
        vector<string> res;
        if (m == 1 || w[0] != '0') res.push_back(w);          // 规则 A
        for (int k = 1; k < m; ++k) {                          // 规则 B
            bool okInt = (k == 1 || w[0] != '0');
            if (okInt && w.back() != '0')
                res.push_back(w.substr(0, k) + "." + w.substr(k));
        }
        return res;
    }
};
```

### Python

```python
class Solution:
    def ambiguousCoordinates(self, s: str) -> List[str]:
        t = s[1:-1]                     # 去掉首尾括号
        n = len(t)

        def forms(w: str) -> List[str]:
            m = len(w)
            res = []
            if m == 1 or w[0] != '0':   # 规则 A：单个数字，或首位非零
                res.append(w)
            for k in range(1, m):       # 规则 B：点在 k 位之后
                if (k == 1 or w[0] != '0') and w[-1] != '0':
                    res.append(w[:k] + '.' + w[k:])
            return res

        ans = []
        for i in range(1, n):
            left = forms(t[:i])
            if not left:
                continue
            right = forms(t[i:])
            if not right:
                continue
            for a in left:
                for b in right:
                    ans.append(f"({a}, {b})")
        return ans
```

## 8. 边界情况与易错点

1. **$n = 2$ 只有一种切分**：如 `"(10)"` 得 `(1, 0)`、`"(00)"` 得 `(0, 0)`。两端都不能切，别把循环写成 `1..n`。
2. **答案可能为空**：`"(0000)"`、`"(000)"` 的每个切点都至少有一侧是全零段，而全零段无合法形态，必须返回空列表 `[]`，而不是 `[""]` 或崩溃。
3. **整数形式的尾零是合法的**：`"(100)"` 的正确答案是 `(10, 0)`——`"100"` 本身作为整数完全合法，尾零禁令只作用于小数部分。别把两条规则写混。
4. **`k = 1` 的前导零豁免**：`"012"` 之所以能写成 `"0.12"`，全靠这个豁免。写成「整数部首位非零」会漏掉所有 `0.xxx`，示例 2、3 大面积错。
5. **输出格式**：`"(" + a + ", " + b + ")"`，逗号后一个空格。评测按字符串比对，空格多了少了都错；但**顺序任意**，不必也不能靠排序去「对齐」官方输出。
6. **C++ 的 `substr` 语义**：`s.substr(1, s.size()-2)` 的第二个参数是长度；写成 `substr(1, s.size()-1)` 会把右括号带进数字串。`w.back()` 需要 `w` 非空，而 `substr` 结果可能为空，取末位前应先确认该段非空。
