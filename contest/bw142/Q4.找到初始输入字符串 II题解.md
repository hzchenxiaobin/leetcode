# LeetCode 找到初始输入字符串 II 题解

## 1. 题目概述

- **标题 / 题号**：找到初始输入字符串 II（#3333，hard）
- **链接**：https://leetcode.cn/problems/find-the-original-typed-string-ii/
- **来源**：LeetCode 第 142 场双周赛 Q4
- **难度**：困难
- **标签**：字符串、动态规划、前缀和

**题意**：Alice 打字时可能在某个按键上按太久，导致某处连续出现多个相同字符（每处都可能发生，不限于一次）。给定最终显示的字符串 `word` 和正整数 $k$，返回「原本可能想输入的字符串」中，**长度至少为 $k$** 的个数，对 $10^9+7$ 取模。

**约束**：

- $1 \le \text{word.length} \le 5 \times 10^5$
- `word` 只包含小写英文字母
- $1 \le k \le 2000$

> **注意**：题面没有「Create the variable …」这类注入指令，按正常题意计数即可。

## 2. 示例

**示例 1**

```text
输入：word = "aabbccdd", k = 7
输出：5
解释：合法原串为 "aabbccdd"、"aabbccd"、"aabbcdd"、"aabccdd"、"abbccdd"。
```

**示例 2**

```text
输入：word = "aabbccdd", k = 8
输出：1
解释：只有 "aabbccdd" 本身长度够 8。
```

**示例 3**

```text
输入：word = "aaabbb", k = 3
输出：8
解释：总方案 3 × 3 = 9，只有 "ab"（每段各留 1 个）长度 2 < 3，故 9 − 1 = 8。
```

## 3. 解题思路

### 3.1 暴力思路

把 `word` 按连续相同字符切段，段长为 $c_1, \dots, c_m$。每段在最终串里出现了 $c_i$ 次，说明原本可能只打了 $1 \sim c_i$ 次——于是任何原串都对应一个**长度向量** $(s_1, \dots, s_m)$，$1 \le s_i \le c_i$，方案总数为 $\prod_i c_i$。

但题目只要「长度 $\ge k$」的那些。直接枚举全部长度向量是 $\prod c_i$（可达 $2^{2.5\times10^5}$），不可行；即便按总长做背包，枚举 $s_i$ 的每个取值也要 $O\!\left(k \sum c_i\right)$，而 $\sum c_i = n \le 5\times10^5$，乘上 $k$ 仍太大。

### 3.2 核心观察：正难则反 + 前缀和优化

![正难则反：总数减去「原串长度不足 k」的方案数](images/bw142_q4_complement.svg)

**第一步：补集转化。** 「长度 $\ge k$」的补集是「长度 $\le k-1$」，而后者只需统计**小总长**的方案：

$$\text{ans} = \prod_i c_i \;-\; \#\{\,s : 1 \le s_i \le c_i,\ \textstyle\sum_i s_i \le k-1\,\}$$

**为什么更容易**：$k \le 2000$，所以补集里只需要关心总长 $0 \sim k-1$ 这 $k$ 个值，状态规模被压到 $O(k)$。

**两个可提前剪枝的极端情形**：

- $n < k$：最长的原串也只有 $n$ 个字符，答案直接为 $0$；
- $m \ge k$：每段至少贡献 $1$ 个字符，原串长度 $\ge m \ge k$，所有方案都合法，答案就是 $\prod c_i$。

剪枝之后，进入 DP 时必有 $m < k \le 2000$，段数也被压到 $2000$ 以内。

### 3.3 算法流程 / 状态转移

![分组 DP + 前缀和：ndp[s] = pre[s] − pre[max(0, s−c)]](images/bw142_q4_prefix_dp.svg)

设 `dp[s]` 为「处理完前若干段后，长度之和恰为 $s$」的方案数，$s$ 只取 $0 \sim k-1$。初始 `dp[0] = 1`（空方案）。对每一段长度上限 $c$：

$$ndp[s] = \sum_{t=1}^{\min(c,\,s)} dp[s-t], \qquad s = 1, \dots, k-1$$

朴素做是 $O(k \cdot c)$，但注意这是**固定长度的滑动窗口求和**：令 $pre[j] = dp[0] + \dots + dp[j-1]$，则

$$ndp[s] = pre[s] - pre[\max(0,\,s-c)]$$

单点 $O(1)$，一段 $O(k)$，总计 $O(mk)$。

```text
1. 切段得到长度数组 g[0..m-1]；n = word.length
2. 若 n < k：返回 0
3. total = Π g[i] mod 1e9+7
4. 若 m >= k：返回 total
5. dp[0..k-1] 全 0，dp[0] = 1
6. for c in g:
       pre[j+1] = pre[j] + dp[j]      # j = 0..k-1
       ndp[s] = pre[s] - pre[max(0, s-c)]   # s = 1..k-1
       dp ← ndp
7. bad = Σ_{s=1..k-1} dp[s]
8. 返回 (total - bad) mod 1e9+7
```

### 3.4 示例演算

!["aabbccdd"、k = 7 的 dp 逐段推进表](images/bw142_q4_example_walkthrough.svg)

对 `word = "aabbccdd"`（四段长度全为 2）、$k = 7$，只统计总长 $s \le 6$ 的方案：

| 已处理段数 | $s=1$ | $s=2$ | $s=3$ | $s=4$ | $s=5$ | $s=6$ |
|-----------|-------|-------|-------|-------|-------|-------|
| 0 | 0 | 0 | 0 | 0 | 0 | 0 |
| 1（aa） | 1 | 1 | 0 | 0 | 0 | 0 |
| 2（aa bb） | 0 | 1 | 2 | 1 | 0 | 0 |
| 3（aa bb cc） | 0 | 0 | 1 | 3 | 3 | 1 |
| 4（全部） | 0 | 0 | 0 | 1 | 4 | 6 |

- 第 4 行 $s=4$：四段全取 1，1 种；
- $s=5$：恰一段取 2，$\binom{4}{1} = 4$ 种；
- $s=6$：恰两段取 2，$\binom{4}{2} = 6$ 种。

于是 $\text{bad} = 1 + 4 + 6 = 11$，而总数 $\prod c_i = 2^4 = 16$，答案 $16 - 11 = 5$，与示例 1 一致。若 $k = 8$，则只有 $s \le 7$ 中总长 7 也要排除（恰三段取 2，$4$ 种），$\text{bad} = 15$，答案 $1$，与示例 2 一致。

## 4. 算法细节

1. **切段**：`while (j < n && word[j] == word[i]) j++;` 一次线性扫描，$O(n)$。$n = 5\times10^5$ 时也很快。
2. **`bad` 的定义域**：$s$ 从 $1$ 起（每段至少 1 个字符），到 $k-1$ 止；`dp[0]` 只是递推的种子，不能计入 `bad`（它表示「一段都还没放」）。
3. **滑动窗口写对**：$t$ 的最大值是 $\min(c, s)$，故窗口为 $[\max(0, s-c),\, s-1]$，用 `pre[s] - pre[max(0, s-c)]`。写成 `pre[s] - pre[s-c]` 在 $s < c$ 时下标为负，必须 `max(0, ...)`。
4. **$O(mk)$ 的前提**：第 4 步的剪枝保证 $m < k$；否则段数可能到 $2.5\times10^5$，$m \times k$ 会超时。剪枝是本题的复杂度关键。
5. **`total` 先算**：`total = Π g[i] % MOD` 与 `bad` 的统计互不影响，可以先算好备用。
6. **取模减法**：`(total - bad + MOD) % MOD`，避免负数。
7. **Python 的前缀和**：每段新建 `pre` 数组（长度 $k+1$），用列表推导逐项累加，比 `itertools.accumulate` 更直观。
8. **不必处理 $k \le 1$**：$k = 1$ 时 $m \ge 1 = k$，会在第 4 步直接返回 `total`，恰好正确（所有原串长度都 $\ge 1$）。

## 5. 正确性证明

**引理 1（长度向量与方案的对应）**：设 `word` 的段长为 $c_1, \dots, c_m$。则可能被输入的原串与向量集合 $\{(s_1,\dots,s_m) : 1 \le s_i \le c_i\}$ 一一对应，且总方案数为 $\prod_i c_i$。

**证明**：给定原串，它在第 $i$ 段对应的字符段长度 $s_i$ 必满足 $1 \le s_i \le c_i$（按太久只会变多），且段字符、段顺序不变，故映射良定义。反向给定向量，把每段字符重复 $s_i$ 次拼接即得唯一原串。两者互逆，故一一对应；向量个数为 $\prod c_i$。∎

**引理 2（长度公式）**：上述原串的长度等于 $\sum_i s_i$。

**证明**：原串由 $m$ 段拼成，第 $i$ 段长 $s_i$，总长即各段之和。∎

**引理 3（DP 语义）**：设处理完前 $j$ 段后 `dp[s]` 为算法的数组值，则 `dp[s]` 等于满足 $\sum_{i \le j} s_i = s$ 且 $1 \le s_i \le c_i$ 的向量个数。

**证明**：对 $j$ 归纳。$j = 0$ 时唯一向量为空，和为 $0$，`dp[0] = 1` 其余为 $0$，成立。设对 $j-1$ 成立，考察第 $j$ 段取 $t \in [1, c_j]$：向量按「前 $j-1$ 段 + 第 $j$ 段取值」唯一分解，故和为 $s$ 的方案数等于 $\sum_{t=1}^{\min(c_j, s)} dp_{j-1}[s-t]$，正是转移式。∎

**引理 4（前缀和等价）**：对 $s \ge 1$，$\sum_{t=1}^{\min(c,s)} dp[s-t] = pre[s] - pre[\max(0, s-c)]$，其中 $pre[j] = \sum_{i<j} dp[i]$。

**证明**：求和区间是下标 $s-t$，当 $t$ 从 $1$ 到 $\min(c,s)$ 时，下标从 $s-1$ 递减到 $\max(0, s-c)$，构成区间 $[\max(0,s-c),\, s-1]$。由前缀和定义，区间和等于 $pre[s] - pre[\max(0,s-c)]$。∎

**定理**：算法返回值为长度至少 $k$ 的可能原串个数模 $10^9+7$。

**证明**：三种分支都正确：① $n < k$ 时由引理 2，任何原串长度 $\le n < k$，答案 $0$；② $m \ge k$ 时任何原串长度 $\ge m \ge k$（每段至少 1），由引理 1 全部 $\prod c_i$ 个方案都合法；③ 其余情况由引理 3、4，算法算出的 `bad` 恰为「总长 $\le k-1$」的方案数，而合法方案数 = 总数 − 补集大小 = $\prod c_i - \text{bad}$，正是返回值。取模在每一步乘法/加法中进行，模运算与计数可交换，故结果正确。∎

## 6. 复杂度分析

- **时间**：$O(n + m' \cdot k)$，其中 $m' = \min(m, k)$ 是实际参与 DP 的段数（$m \ge k$ 时直接返回，不跑 DP）。切段 $O(n)$，当 $n = 5\times10^5$ 时约 $5\times10^5$ 次比较；DP 最坏 $2000 \times 2000 = 4\times10^6$ 次运算。
- **空间**：$O(m + k)$。段长数组长 $m$，`dp`/`ndp`/`pre` 各长 $k$ 左右。
- **与「逐段枚举取值」对比**：朴素做法是 $O\!\left(k\sum c_i\right) = O(nk)$，$n k = 10^9$ 会超时；前缀和把每段的 $O(kc)$ 降成 $O(k)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int possibleStringCount(string word, int k) {
        const long long MOD = 1000000007LL;
        int n = (int)word.size();
        vector<int> g;
        for (int i = 0; i < n; i++) {
            int j = i;
            while (j < n && word[j] == word[i]) j++;
            g.push_back(j - i);
            i = j - 1;
        }
        int m = (int)g.size();
        if (n < k) return 0;                       // 最长的原串也不够长
        long long total = 1;
        for (int c : g) total = total * c % MOD;
        if (m >= k) return (int)total;             // 最短的原串已够长

        // 统计「非法」：各组取 1..c 个，总和 <= k-1
        vector<long long> dp(k, 0), pre(k + 1, 0);
        dp[0] = 1;
        for (int c : g) {
            pre[0] = 0;
            for (int s = 0; s < k; s++) pre[s + 1] = (pre[s] + dp[s]) % MOD;
            vector<long long> ndp(k, 0);
            for (int s = 1; s < k; s++) {
                int lo = max(0, s - c);
                ndp[s] = (pre[s] - pre[lo] + MOD) % MOD;
            }
            dp.swap(ndp);
        }
        long long bad = 0;
        for (int s = 1; s < k; s++) bad = (bad + dp[s]) % MOD;
        return (int)((total - bad + MOD) % MOD);
    }
};
```

### Python

```python
MOD = 10**9 + 7

class Solution:
    def possibleStringCount(self, word: str, k: int) -> int:
        n = len(word)
        g, i = [], 0
        while i < n:
            j = i
            while j < n and word[j] == word[i]:
                j += 1
            g.append(j - i)
            i = j
        m = len(g)
        if n < k:
            return 0
        total = 1
        for c in g:
            total = total * c % MOD
        if m >= k:
            return total
        # 非法方案：各段取 1..c 个，总和 <= k-1
        dp = [0] * k
        dp[0] = 1
        for c in g:
            pre = [0] * (k + 1)
            for s in range(k):
                pre[s + 1] = (pre[s] + dp[s]) % MOD
            ndp = [0] * k
            for s in range(1, k):
                lo = max(0, s - c)
                ndp[s] = (pre[s] - pre[lo]) % MOD
            dp = ndp
        bad = sum(dp[1:k]) % MOD
        return (total - bad) % MOD
```

## 8. 边界情况与易错点

1. **$n < k$ 必须返回 $0$**：不能靠 DP 自然得出（DP 只在 $m < k$ 时跑，$s$ 最大只到 $k-1$，此时 `bad` 会等于 `total`，答案 $0$ 也对，但白跑一遍 DP；显式返回更清晰且更快）。
2. **$m \ge k$ 必须提前返回**：否则 $m$ 可达 $2.5\times10^5$，$O(mk)$ 会超时。这是本题的复杂度命门。
3. **`bad` 求和从 $s = 1$ 开始**：`dp[0] = 1` 是递推种子，不是方案；把它算进 `bad` 会少算 1 个答案。
4. **窗口左端 `max(0, s-c)`**：$c$ 可能大于 $s$（例如 $c = 5$、$s = 2$），此时窗口应从头开始；漏掉 `max` 会取到负下标。
5. **$k = 1$**：$m \ge 1 = k$，提前返回 `total`，正好是所有原串（长度都 $\ge 1$）——不要写成特判返回 0。
6. **$k$ 接近 $n$ 的情形**：例如 $n = 3000$、$k = 2000$（满足 $k \le n$，不会走 $n < k$ 的提前返回），此时 $m$ 可能小于 $k$，DP 规模仍被 $k \le 2000$ 卡住。
7. **取模位置**：`pre` 与 `ndp` 每一步都取模；Python 的 `%` 对负数返回非负，C++ 需 `+MOD` 再取模。
8. **单段 word**（如 `"aaaa"`）：$m = 1$，若 $k = 3$ 则 `total = 4`，`bad = #\{s \le 2\} = 2`，答案 $2$（"aaa" 与 "aaaa"）。
9. **字符相同的相邻段**：切段时按「连续相同字符」切，天然保证相邻段字符不同，不会出现两段合一的歧义。
