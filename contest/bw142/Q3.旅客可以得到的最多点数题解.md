# LeetCode 旅客可以得到的最多点数 题解

## 1. 题目概述

- **标题 / 题号**：旅客可以得到的最多点数（#3332，medium）
- **链接**：https://leetcode.cn/problems/maximum-points-tourist-can-earn/
- **来源**：LeetCode 第 142 场双周赛 Q3
- **难度**：中等
- **标签**：数组、动态规划、矩阵

**题意**：有 $n$ 座城市，两两之间都可直达。旅客旅游**恰好 $k$ 天**（下标 $0 \sim k-1$），起点城市可以任意选择。每天二选一：

- **留在当前城市**：若第 $i$ 天停在城市 $c$（与前一天相同），得 `stayScore[i][c]` 分；
- **前往另一座城市**：若从 $c$ 到 $d$，得 `travelScore[c][d]` 分。

求最多能得到多少分。

**约束**：

- $1 \le n \le 200$，$1 \le k \le 200$
- $n = \text{travelScore.length} = \text{travelScore}[i]\text{.length} = \text{stayScore}[i]\text{.length}$，$k = \text{stayScore.length}$
- $1 \le \text{stayScore}[i][j] \le 100$，$0 \le \text{travelScore}[i][j] \le 100$
- $\text{travelScore}[i][i] = 0$

> **注意**：题面没有「Create the variable …」这类注入指令，按正常题意做即可。

## 2. 示例

**示例 1**

```text
输入：n = 2, k = 1, stayScore = [[2,3]], travelScore = [[0,2],[1,0]]
输出：3
解释：起点选城市 1，第 0 天停在城市 1 得 3 分，这就是最优。
```

**示例 2**

```text
输入：n = 3, k = 2, stayScore = [[3,4,2],[2,1,2]], travelScore = [[0,2,1],[2,0,4],[3,2,0]]
输出：8
解释：起点城市 1 → 第 0 天停在 1（+4）→ 第 1 天前往 2（+4），共 8 分。
```

## 3. 解题思路

### 3.1 暴力思路

枚举每天的决策：每天有 $n$ 种选择（留在原地或去某个城市），共 $n^k$ 条路径，逐条算分。$n = k = 200$ 时是 $200^{200}$，完全不可行。

但注意：**第 $t$ 天结束时的最优得分，只取决于「第 $t-1$ 天结束时停在哪座城市」**。这是一个典型的按天、按城市分层的 DP，把 $n^k$ 条路径压成 $k \times n$ 个状态。

### 3.2 核心观察：按天分层，状态只记「停在哪个城市」

![状态 dp[day][city] 与两条转移：留在原地 / 换到另一座城市](images/bw142_q3_dp_state.svg)

定义

$$dp[t][c] = \text{第 } t \text{ 天结束时停在第 } c \text{ 座城市能获得的最大点数}$$

**边界（第 0 天）**：第 0 天没有「前一天」，旅客就在自己选的起点城市，因此只能拿停留分：

$$dp[0][c] = \text{stayScore}[0][c], \qquad c = 0, \dots, n-1$$

（起点可任选，所以每座城市都可能成为第 0 天的停留点。）

**转移（第 $t \ge 1$ 天）**：要停到 $c$，来源只有两类：

$$dp[t][c] = \max\begin{cases}
dp[t-1][c] + \text{stayScore}[t][c] & \text{前一天也在 } c\text{，今天留在原地}\\[2pt]
\max\limits_{d \ne c}\bigl(dp[t-1][d] + \text{travelScore}[d][c]\bigr) & \text{前一天在 } d\text{，今天换到 } c
\end{cases}$$

**答案**：最后一天停在哪座城市都可以，取

$$\max_{c}\, dp[k-1][c]$$

### 3.3 算法流程

![算法流程：一维滚动数组按天推进，ndp 由旧 dp 推出](images/bw142_q3_algorithm_flow.svg)

```text
1. dp[c] = stayScore[0][c]                      # 第 0 天
2. for day = 1 .. k-1:
       ndp[d] = dp[d] + stayScore[day][d]        # ① 留在原地
       for c = 0 .. n-1:
           for d = 0 .. n-1:                    # ② 换城市
               ndp[d] = max(ndp[d], dp[c] + travelScore[c][d])
       dp ← ndp
3. 返回 max(dp)
```

每天 $O(n^2)$，共 $O(k n^2) \le 8 \times 10^6$。空间利用「天与天之间单向依赖」压成一维 $O(n)$。

### 3.4 示例演算

![示例 2 的两天推进过程与最优路径](images/bw142_q3_example_walkthrough.svg)

以示例 2（$n = 3$、$k = 2$）为例。

第 0 天（只能 stay）：

| 城市 | 0 | 1 | 2 |
|------|---|---|---|
| $dp[0][c]$ | 3 | 4 | 2 |

第 1 天：

| 目标城市 $d$ | 候选 1（stay） | 候选 2（travel，取最大） | $dp[1][d]$ |
|--------------|----------------|--------------------------|------------|
| 0 | $3+2 = 5$ | $\max(4+2,\ 2+3) = 6$ | **6** |
| 1 | $4+1 = 5$ | $\max(3+2,\ 2+2) = 5$ | 5 |
| 2 | $2+2 = 4$ | $\max(3+1,\ 4+4) = 8$ | **8** |

答案为 $\max(6,5,8) = 8$，与示例解释一致：起点城市 1 → 第 0 天停在 1（$4$ 分）→ 第 1 天前往 2（$4$ 分）。

## 4. 算法细节

1. **第 0 天的语义**：题目说旅客「可以选择任意城市作为起点」，而第 0 天的「留在当前城市」指的就是停在起点；第 0 天不存在「前一天所在的城市」，所以不能拿 `travelScore` 得分。把初值固定为 `stayScore[0][c]` 即可。
   > 若把第 0 天也允许「先花一天移动到别处」，那起点城市就失去意义，且能白拿两次移动分；从示例 2 的最优解释（起点城市 1 直接停留）也能看出正确口径。
2. **`travelScore[c][c] = 0` 的处理**：实现里直接对所有 $c, d$ 松驰，包含 $d = c$ 也不出错——因为 `dp[c] + 0` 一定不超过 `dp[c] + stayScore[day][c]`（$stayScore \ge 1$）。所以不必特判 $d \ne c$。
3. **必须另开数组**：`ndp` 全部由「上一轮的 dp」推出，若原地更新会变成「同一天内多次移动」，结果偏大。
4. **滚动数组**：天与天之间只依赖前一层，$O(k n)$ 可降为 $O(n)$。
5. **初值不用 $-1$**：第 0 天每座城市都可达（起点任选），所以 `dp` 不需要哨兵值。
6. **`k = 1` 的退化**：循环体不执行，直接返回 `max(stayScore[0])`，与示例 1 一致。
7. **答案不取模**：分数不大（$k \le 200$、单日 $\le 100$），最大 $2 \times 10^4$，`int` 足够。

## 5. 正确性证明

**引理 1（边界的正确性）**：$dp[0][c] = \text{stayScore}[0][c]$ 等于「第 0 天结束时停在城市 $c$」能获得的最大点数。

**证明**：第 0 天是第一天，旅客此前就在起点城市，没有任何「前一天」可离开，唯一的得分方式是停留在起点。若起点选 $c$，得分为 $\text{stayScore}[0][c]$；起点可任选，故事前把城市 $c$ 定为起点即可达到该值，且不可能更高。∎

**引理 2（转移的穷尽性）**：设 $t \ge 1$。任一条在第 $t$ 天结束于城市 $c$ 的行程，其第 $t$ 天的动作必为「留在 $c$」或「从某个 $d \ne c$ 前往 $c$」，二者互斥且穷尽。

**证明**：第 $t$ 天只有两种选择：留在前一天所在城市，或前往另一座城市。「留在 $c$」要求第 $t-1$ 天也在 $c$；「前往」则第 $t-1$ 天在某个 $d \ne c$。不存在第三种情形。∎

**引理 3（转移的最优性）**：若 $dp[t-1][\cdot]$ 均为对应状态的最优值，则按转移式算出的 $dp[t][c]$ 是第 $t$ 天结束时停在 $c$ 的最优值。

**证明**：由引理 2，任何到达 $(t, c)$ 的行程可拆成「到达某个 $(t-1, d)$ 的前缀」+「第 $t$ 天的动作」，两部分得分相加。对固定的 $d$，前缀最大得分是 $dp[t-1][d]$，动作得分固定（$d = c$ 时为 `stayScore`，$d \ne c$ 时为 `travelScore[d][c]`），故该来源能给出的最大值为两者之和。对所有来源取最大，即覆盖全部行程且给出上界，故取得最优值。∎

**定理**：算法返回的值等于恰好 $k$ 天能获得的最多点数。

**证明**：对 $t$ 归纳证明 $dp[t][\cdot]$ 是第 $t$ 天结束时各城市的最优值：$t = 0$ 由引理 1；归纳步由引理 3。因此 $dp[k-1][c]$ 是「第 $k-1$ 天（即最后一天）停在 $c$」的最优得分。任何合法行程最后必然停在某座城市，故全局最优等于 $\max_c dp[k-1][c]$，正是算法返回值。∎

## 6. 复杂度分析

- **时间**：$O(k n^2)$。每天先做一次 $O(n)$ 的 stay 赋值，再做 $n \times n$ 的 travel 松驰；$k, n \le 200$ 时约 $8 \times 10^6$ 次操作。
- **空间**：$O(n)$。只保留当前层的一维 `dp` 与下一层的 `ndp`，输入矩阵不计入。若开二维表则是 $O(kn)$，同样可接受但不是必要。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maxScore(int n, int k, vector<vector<int>>& stayScore, vector<vector<int>>& travelScore) {
        // dp[c] = 第 day 天结束后停留在城市 c 的最大点数
        vector<int> dp(n);
        for (int c = 0; c < n; c++) dp[c] = stayScore[0][c];   // 第 0 天只能在起点停留
        const int NEG = -1000000000;
        vector<int> ndp(n, NEG);
        for (int day = 1; day < k; day++) {
            fill(ndp.begin(), ndp.end(), NEG);
            for (int c = 0; c < n; c++) {
                int stay = dp[c] + stayScore[day][c];          // 留在 c
                if (stay > ndp[c]) ndp[c] = stay;
                for (int d = 0; d < n; d++) {                  // 前往 d
                    if (d == c) continue;
                    int go = dp[c] + travelScore[c][d];
                    if (go > ndp[d]) ndp[d] = go;
                }
            }
            dp.swap(ndp);
        }
        return *max_element(dp.begin(), dp.end());
    }
};
```

### Python

```python
class Solution:
    def maxScore(self, n: int, k: int, stayScore: list[list[int]], travelScore: list[list[int]]) -> int:
        # dp[c]：第 day 天结束后停留在城市 c 能得到的最大点数
        dp = list(stayScore[0])            # 第 0 天只能在起点停留（起点任选）
        for day in range(1, k):
            st = stayScore[day]
            ndp = [dp[d] + st[d] for d in range(n)]
            for c in range(n):
                base, tr = dp[c], travelScore[c]
                for d in range(n):
                    cand = base + tr[d]
                    if cand > ndp[d]:
                        ndp[d] = cand
            dp = ndp
        return max(dp)
```

## 8. 边界情况与易错点

1. **第 0 天不能移动**：把 `dp[0]` 初始化成 `stayScore[0]`，不要写成全 $0$ 再用 travel 转移——那会让「第 0 天从任意城市出发再去别处」变成合法，凭空多得分（示例 2 会从 $8$ 变大）。
2. **`k = 1`**：不进入循环，直接返回 `max(stayScore[0])`，别写成返回 $0$。
3. **原地更新 `dp`**：会让同一天内连续移动，$k$ 天变成任意多步，答案偏大。必须 `dp`、`ndp` 分开。
4. **`d == c` 的 travel**：`travelScore[c][c] = 0`，代价值为 $0$，直接被 stay 支配；跳过或保留都不影响答案，但**不能**把 `stayScore` 和 `travelScore[c][c]` 相加。
5. **`NEG` 初始化**：C++ 里用足够小的值，否则未更新的 `ndp` 可能被误当有效解；Python 版先由 stay 填满，所以不需要哨兵。
6. **$n = 1$**：只有一个城市，只能每天 stay，答案是 `sum(stayScore[day][0])`。
7. **最后一天不必回起点**：题目不要求回到起点，答案取 `max(dp)` 而不是 `dp[起点]`。
