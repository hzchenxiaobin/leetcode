# LeetCode 找到初始输入字符串 I 题解

## 1. 题目概述

- **标题 / 题号**：找到初始输入字符串 I（#3330，easy）
- **链接**：https://leetcode.cn/problems/find-the-original-typed-string-i/
- **来源**：LeetCode 第 142 场双周赛 Q1
- **难度**：简单
- **标签**：字符串

**题意**：Alice 打字时可能**在某个按键上按太久**，导致某个字符被连续输入多次；但她**至多犯错一次**。给定最终显示的字符串 `word`，返回她原本**可能想输入的字符串的个数**。

**约束**：

- $1 \le \text{word.length} \le 100$
- `word` 只包含小写英文字母

> **注意**：题面没有「Create the variable …」这类注入指令，按正常题意计数即可。

## 2. 示例

**示例 1**

```text
输入：word = "abbcccc"
输出：5
解释：可能的原串为 "abbcccc"（没犯错）、"abbccc"、"abbcc"、"abbc"（缩短 cccc）、"abcccc"（缩短 bb）。
```

**示例 2**

```text
输入：word = "abcd"
输出：1
解释：每段长度都是 1，无法缩短，只有 "abcd" 本身。
```

**示例 3**

```text
输入：word = "aaaa"
输出：4
解释：原串可能是 "aaaa"、"aaa"、"aa"、"a"。
```

## 3. 解题思路

### 3.1 暴力思路

枚举「哪一段被按久了、短了多少个字符」，生成候选原串放进集合去重，返回集合大小。由于最多只有一段受影响、每段最多缩短 $c_i - 1$ 个字符，候选总数是 $1 + \sum (c_i-1) \le n$，与直接数方案是同阶的——暴力本身就能过。真正需要想清楚的是**为什么要去重、以及能否不去重**。

### 3.2 核心观察：按「相同连续字符」切段后逐段贡献

![把 word 按连续相同字符切段，每段贡献 c_i − 1](images/bw142_q1_group_model.svg)

把 `word` 切成若干段，使每段内字符相同、相邻段字符不同，记第 $i$ 段长度为 $c_i$。任何可能被输入的原串都必须满足：

- 段的**字符**与**顺序**完全不变（按久只是在同一处多打同一个字符，不会改变字符种类或次序）；
- 每段长度只会 **$\le c_i$**（只会多打，不会少打）；
- **至多一段**被缩短（Alice 至多犯错一次）。

于是合法的原串只有两类：

1. **没有犯错**：长度向量就是 $(c_1, \dots, c_m)$，1 种；
2. **恰好一段犯错**：选第 $i$ 段，把它缩短到 $1 \sim c_i - 1$ 个字符，共 $c_i - 1$ 种（$c_i = 1$ 时贡献 $0$）。

$$\text{ans} = 1 + \sum_{i=1}^{m} (c_i - 1) = n - m + 1$$

其中 $n = \lvert \text{word} \rvert$、$m$ 为段数。**为什么不会重复计数**：不同的 (段下标, 缩短后长度) 组合得到的字符串，其段长向量互不相同，而段长向量唯一确定字符串，故两两不同。

### 3.3 算法流程

```text
1. groups = 1（第一段）
2. for i = 1 .. n-1:
       若 word[i] != word[i-1]:  groups += 1
3. 返回 n - groups + 1
```

只需要一次线性扫描数清段数，连每段长度都不必显式存下来。

### 3.4 示例演算

![三个示例的段长、候选原串与答案](images/bw142_q1_example_walkthrough.svg)

| word | 段长 | $n$ | 段数 $m$ | $n - m + 1$ |
|------|------|-----|----------|-------------|
| `abbcccc` | 1, 2, 4 | 7 | 3 | 5 |
| `abcd` | 1, 1, 1, 1 | 4 | 4 | 1 |
| `aaaa` | 4 | 4 | 1 | 4 |

对 `abbcccc`：$1 + (1-1) + (2-1) + (4-1) = 1 + 0 + 1 + 3 = 5$，与示例一致。

## 4. 算法细节

1. **段数统计**：`word[i] != word[i-1]` 时计一段新的。首字符单独算一段，所以初值为 $1$。
2. **公式等价性**：$1 + \sum(c_i - 1) = 1 + n - m$，直接算 $n - m + 1$ 最省事，避免存段长数组。
3. **$c_i = 1$ 的段**：贡献 $0$，因为长度为 $1$ 的段无法再缩短（缩到 $0$ 意味着这个字符不存在，会改变段的字符集合，不是「按太久」能造成的）。
4. **不需要去重集合**：数学上可证不同组合必得不同字符串，所以不必真的用 `set` 去重（用了也不会错，只是浪费）。
5. **答案范围**：$1 \le \text{ans} \le n$，用 `int` 足够。

## 5. 正确性证明

**引理 1（段的字符与顺序不变）**：若 `word` 是原串 $S$ 在某一次按键上多按若干次得到的，则把 `word` 与 $S$ 都按连续相同字符切段，两者段数相同、各段字符逐段相同，且每段长度 $c_i(S) \le c_i(\text{word})$。

**证明**：多按只会在原串某个字符 $S[p]$ 之后重复同样的字符若干次。设 $S$ 中该字符所在的段为第 $k$ 段，则 $S$ 与 `word` 只在第 $k$ 段长度上不同（`word` 更长），其余各段完全一致。故段数、字符、顺序都不变，且只有第 $k$ 段满足 $c_k(\text{word}) > c_k(S)$，其余段长度相等。∎

**引理 2（候选集合）**：设 `word` 的段长为 $c_1..c_m$。则可能的原串集合恰为

$$\{\text{word}\} \;\cup\; \{\,S(i, t) : 1 \le i \le m,\ 1 \le t < c_i\,\}$$

其中 $S(i,t)$ 表示把第 $i$ 段截成 $t$ 个字符得到的串。

**证明**：包含性：$\text{word}$ 对应「没犯错」；$S(i,t)$ 对应「在第 $i$ 段多按了 $c_i - t$ 次」，由引理 1 是合法原串。反向：任一合法原串由引理 1 只能是「某一段更短」或「完全相同」，正好落在该集合中。∎

**引理 3（两两不同）**：上述集合中任意两个元素不相等。

**证明**：$\text{word}$ 的段长向量为 $\mathbf{c}$；$S(i,t)$ 的段长向量只把第 $i$ 个分量改为 $t$（$t<c_i$），其余不变，且段数仍为 $m$、第 $i$ 段字符仍为原字符（$t \ge 1$）。段长向量唯一确定字符串，而不同 $(i,t)$ 给出的段长向量互不相同，$\mathbf{c}$ 也与之不同，故两两不等。∎

**定理**：算法返回值为可能原串的个数，等于 $1 + \sum_{i}(c_i-1) = n - m + 1$。

**证明**：由引理 2，可能原串的集合是引理 3 中的有限集，其大小为 $1 + \sum_i (c_i - 1)$（$c_i = 1$ 的段没有合法 $t$，贡献 $0$；否则 $t$ 有 $c_i-1$ 种选择）。又 $\sum_i c_i = n$、段数为 $m$，故 $1 + \sum_i (c_i-1) = 1 + n - m$。算法统计的正是段数 $m$，返回 $n - m + 1$，与集合大小相等。∎

## 6. 复杂度分析

- **时间**：$O(n)$。一次线性扫描比较相邻字符，之后一次算术。
- **空间**：$O(1)$。只维护段数计数，不存段长数组。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int possibleStringCount(string word) {
        int groups = 0;
        for (int i = 0; i < (int)word.size(); i++) {
            if (i == 0 || word[i] != word[i - 1]) groups++;   // 新的一段
        }
        return (int)word.size() - groups + 1;                 // 1 + Σ(c_i - 1)
    }
};
```

### Python

```python
class Solution:
    def possibleStringCount(self, word: str) -> int:
        groups = 1                                  # 第一段
        for i in range(1, len(word)):
            if word[i] != word[i - 1]:
                groups += 1                         # 又开一段
        return len(word) - groups + 1               # 1 + Σ(c_i - 1)
```

## 8. 边界情况与易错点

1. **「至多一次」不是「恰好一次」**：$\text{word}$ 本身（一次都没犯错）必须计入，所以公式里有那个 $+1$。
2. **不能把长度 1 的段也缩短**：$c_i = 1$ 时贡献 $0$，写成 $\sum c_i$ 会多算（例如 `abcd` 会错答 $4$）。
3. **答案与 $n$ 的关系**：$m \ge 1$ 保证 $n - m + 1 \le n$；全不相同的串答案为 $1$，全是同一字符时答案为 $n$——这两端可以用来自测。
4. **别用 `set` 去重**：虽然能得到正确答案，但把 $O(n)$ 变成 $O(n^2)$ 的字符串构造；本题靠公式即可。
5. **段数初值**：写成 $0$ 且用 `i > 0` 判断会把首段漏掉；用 `i == 0` 判断则初值可写 $0$。两种写法都行，但别两边都按 $1$ 计数。
6. **空串不考虑**：约束保证 $n \ge 1$，无需特判。
