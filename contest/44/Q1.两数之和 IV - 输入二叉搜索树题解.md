# LeetCode 两数之和 IV - 输入二叉搜索树 题解

## 1. 题目概述

- **标题 / 题号**：两数之和 IV - 输入二叉搜索树（#653，easy）
- **链接**：https://leetcode.cn/problems/two-sum-iv-input-is-a-bst/
- **来源**：LeetCode 第 44 场周赛 Q1
- **难度**：简单
- **标签**：树、深度优先搜索、广度优先搜索、二叉搜索树、哈希表、双指针、二叉树

**题意**：给定一棵二叉搜索树的根节点 `root` 和一个目标值 $k$，判断树中**是否存在两个不同的节点**，使它们的值之和等于 $k$。存在返回 `true`，否则返回 `false`。

两个关键词决定了边界的写法：**不同节点**（不能拿同一个节点配两次，故 $k = 2\cdot\text{val}$ 且树中只有一个 $\text{val}$ 时必须返回 `false`）、**保证是合法 BST**（这给了「中序有序」这条额外信息，也开出了双指针解法的口子）。

**约束**：

- 节点个数 $1 \le n \le 10^4$
- $-10^4 \le \text{Node.val} \le 10^4$
- 输入保证是一棵**有效**的二叉搜索树
- $-10^5 \le k \le 10^5$

## 2. 示例

**示例 1**

```text
输入: root = [5,3,6,2,4,null,7], k = 9
输出: true
解释: 存在节点 2 与节点 7（也可取 4 与 5），2 + 7 = 9。
```

**示例 2**

```text
输入: root = [5,3,6,2,4,null,7], k = 28
输出: false
解释: 树中最大两值之和为 6 + 7 = 13 < 28，故不存在符合条件的两个节点。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的做法是「把树摊平成数组，再两两枚举」：先 $O(n)$ 遍历拿到全部 $n$ 个值，然后对所有点对 $(i,j)$、$i<j$ 检查 $a_i + a_j = k$，时间 $O(n^2)$。$n = 10^4$ 时约 $5\times10^7$ 次比较，能过但完全浪费了信息。

另一个「BST 味」更浓的暴力是：对每个节点 $u$，在 BST 里二分查找 $k - u$，单次 $O(h)$，总共 $O(n\log n)$——但树退化成链时 $h = n$，又掉回 $O(n^2)$。

两种暴力的共同问题是：**每遇到一个新值，都要把「整棵树」重新问一遍「你见过我的补数吗」**。而这个问题本可以用一个集合 $O(1)$ 回答。

### 3.2 核心观察：补数 + 哈希表

![补数查询：9−val 是否已出现](images/wc44_q1_complement_hash_set.svg)

「两数之和」的通用套路在这里一字不改地成立：

$$a + b = k \iff b = k - a$$

所以配对问题可以拆成两步——**遍历时用一个集合记住「已经见过的值」**，当前值为 $v$ 时只问一句「$k - v$ 在集合里吗」。命中即找到答案，否则把 $v$ 放进集合继续走。

为什么在这题里连 BST 的有序性都不需要？因为哈希表的查询不依赖顺序，**任意遍历顺序（先序 / 中序 / 层序，DFS 或 BFS）都能得到正确答案**。BST 在这里只提供了「另一种更好的解法」（见 3.3），并不是哈希解法的前提。

> 💡 有一个必须写对的细节：**先查后插**。若先插入自己再查补数，遇到 $k = 2v$ 的单节点树（如 `root = [2], k = 4`）就会把同一个节点配对给自己，直接误判为 `true`。

### 3.3 算法流程与三种写法

![中序遍历有序 → 双指针夹逼](images/wc44_q1_inorder_two_pointers.svg)

**写法 A（补数哈希，推荐）**：

1. 建空哈希集合 $S$；
2. 用栈（或递归、队列）做一次遍历；
3. 弹出节点 $v$：若 $k - v \in S$ 立即返回 `true`；
4. 否则把 $v$ 插入 $S$，把左右非空儿子压栈；
5. 遍历结束仍未命中，返回 `false`。

**写法 B（中序 + 双指针）**：BST 的中序序列 $a_1 < a_2 < \dots < a_n$ 单调递增，于是问题变成经典的「有序数组中找和为 $k$ 的两数」：$L$ 指向最小、$R$ 指向最大，$a_L + a_R < k$ 就 $L{+}{+}$（和太小，只能换更大的左端），$> k$ 就 $R{-}{-}$，相等即命中，$L \ge R$ 时无解。

**写法 C（双栈迭代器，空间 $O(h)$）**：写法 B 若先把中序存成数组需要 $O(n)$ 空间。改成两个栈即可——栈 `lo` 沿左链压到最小元素，栈 `hi` 沿右链压到最大元素，每次取两栈顶比较；`lo` 弹栈后把它的右儿子的左链补齐，`hi` 弹栈后把它的左儿子的右链补齐。每次取下一个元素均摊 $O(1)$，整体 $O(n)$ 时间、$O(h)$ 空间：

```cpp
class Solution {
public:
    bool findTarget(TreeNode* root, int k) {
        stack<TreeNode*> lo, hi;
        pushLeft(root, lo);
        pushRight(root, hi);
        while (!lo.empty() && !hi.empty()) {
            int a = lo.top()->val, b = hi.top()->val;
            if (a >= b) return false;                     // 两端相遇，不会再有合法配对
            if (a + b == k) return true;
            if (a + b < k) { TreeNode* p = lo.top(); lo.pop(); pushLeft(p->right, lo); }
            else           { TreeNode* p = hi.top(); hi.pop(); pushRight(p->left, hi); }
        }
        return false;
    }
private:
    void pushLeft(TreeNode* r, stack<TreeNode*>& st)  { while (r) { st.push(r); r = r->left; } }
    void pushRight(TreeNode* r, stack<TreeNode*>& st) { while (r) { st.push(r); r = r->right; } }
};
```

三种写法的复杂度对比：A 为 $O(n)$ 时间 / $O(n)$ 空间；B 为 $O(n)$ 时间 / $O(n)$ 空间（存数组）；C 为 $O(n)$ 时间 / $O(h)$ 空间。$n \le 10^4$ 时三者都远在限制内，**A 最短、最不容易写错，是比赛首选**。

### 3.4 示例演算

![两个目标的演算对比](images/wc44_q1_walkthrough.svg)

**$k = 9$**（按先序访问）：$5 \to$ 查 $4 \notin S$，插入 5；$3 \to$ 查 $6 \notin S$，插入 3；$2 \to$ 查 $7 \notin S$，插入 2；$4 \to$ 查 $9-4 = 5 \in S$，命中，返回 `true`。只处理了 4 个节点。

**$k = 28$**（双指针）：中序得 $[2,3,4,5,6,7]$，$L{=}0,R{=}5$ 时 $2+7=9 < 28$，$L$ 一路右移，直到 $L{=}5$ 与 $R$ 相遇仍未命中，返回 `false`。哈希写法同样要扫完全部 6 个节点才能给出 `false`——**命中可以早退，未命中必须遍历完整棵树**。

## 4. 算法细节

1. **先查后插是硬要求**：检查顺序必须写成「`if (k - v in seen) return true; seen.add(v);`」。反过来写，`[2], k = 4` 这类数据必错。
2. **集合里存值而不是节点**：判断只用值，存 `int` 比存指针更省；BST 节点值互不相同，重复插入也只是覆盖同一个键。
3. **遍历方式自由，但递归深度要管**：C++ 递归深度 $n = 10^4$ 一般安全；Python 默认递归上限 1000，链状 BST 会 `RecursionError`，所以参考代码的 Python 版改用**显式栈迭代**，C++ 版保留递归以保持简洁。
4. **值域很小，哈希表可退化为数组**：$-10^4 \le \text{val} \le 10^4$，用 `bool seen[20001]` 或 `vector<char> seen(20001)` 做偏移映射（`val + 10000`），常数比 `unordered_set` 更小；代价是值与值域强绑定。
5. **双指针法的前提是「中序有序」**：题面保证输入是合法 BST，所以可以直接用双指针；若输入只是普通二叉树，必须先排序，总代价 $O(n\log n)$。
6. **$a \ge b$ 这一行不能省**（写法 C）：两栈顶相遇说明剩余候选集为空或只剩同一节点，必须立刻返回 `false`，否则会把同一个节点配给自己。
7. **`k` 与和都不会溢出**：$\lvert \text{val}\rvert \le 10^4$，两值之和落在 $[-2\times10^4, 2\times10^4]$，`k` 落在 $[-10^5,10^5]$，`int` 足够，无需 `long long`。

## 5. 正确性证明

**引理 1（遍历完整性）**：写法 A 的遍历（递归 DFS 或显式栈）恰好访问树中每个节点一次。

**证明**：树无环，每个节点只通过其父节点被压入一次；入栈时非空，弹出后其左右非空儿子各被压入一次。归纳可知所有从根可达的节点都被访问且只被访问一次。∎

**引理 2（不会自我配对）**：算法返回 `true` 时，命中的两个值来自两个不同的节点。

**证明**：访问 $v$ 时，先执行「$k - v \in S$」检查、后执行「插入 $v$」。由引理 1，此刻 $S$ 中只含**更早被访问过**的节点值，不含当前节点自身（每个节点仅在检查之后插入一次）。因此命中的 $k - v$ 必来自另一个节点。∎

**引理 3（有解必被找到）**：若存在两节点 $u, v$，$u \ne v$ 且 $u.\text{val} + v.\text{val} = k$，则算法返回 `true`。

**证明**：设二者中较晚被访问的是 $v$。访问 $v$ 时，$u$ 已被访问且已插入 $S$（引理 1），于是 $k - v.\text{val} = u.\text{val} \in S$，检查立即命中并返回 `true`。∎

**定理**：`findTarget(root, k)` 返回 `true` 当且仅当树中存在两个不同节点，其值之和为 $k$。

**证明**：充分性由引理 3；必要性由引理 2——返回 `true` 意味着存在两个不同节点 $a, b$ 满足 $k - a = b$，即 $a + b = k$；若遍历结束仍未返回，由引理 1 所有节点都已访问，不存在任何满足条件的节点对，返回 `false` 正确。∎

**引理 4（双指针的单调性）**：在递增数组 $a$ 上，若 $a_L + a_R < k$，则对任意 $j \le R$ 都有 $a_L + a_j \le a_L + a_R < k$，即 $a_L$ 与任何剩余元素都配不成 $k$，可以永久丢弃；对称地，$a_L + a_R > k$ 时 $a_R$ 可永久丢弃。

**证明**：由 $a$ 递增，$j \le R \Rightarrow a_j \le a_R$，故 $a_L + a_j \le a_L + a_R < k$。对称情形同理。∎

> 由引理 4，双指针每一步都安全地淘汰一个元素，$L$ 与 $R$ 相向而行至多 $n$ 步；淘汰过程中不会漏掉任何可能的配对，所以写法 B / C 在合法 BST 上同样正确。

## 6. 复杂度分析

- **时间**：$O(n)$。写法 A 每个节点做一次哈希查询 + 一次插入，均摊 $O(1)$；写法 B 中序遍历 $O(n)$ + 双指针至多 $n$ 步；写法 C 每个节点被压栈、弹栈各一次，均摊 $O(1)$。
- **空间**：写法 A 为 $O(n)$——哈希表最坏存 $n$ 个值，另加显式栈最坏 $O(n)$（链状树）；写法 B 为 $O(n)$（中序数组）；写法 C 为 $O(h)$，$h$ 为树高，最好 $O(\log n)$、最坏 $O(n)$。
- **常数**：写法 A 最快进入 $O(n)$，且提前命中时可能只处理很少的节点（示例 1 只访问 4 个）；写法 C 空间最优但常数最大。

## 7. 参考代码

### C++

```cpp
#include <unordered_set>
using namespace std;

class Solution {
public:
    bool findTarget(TreeNode* root, int k) {
        unordered_set<int> seen;                     // 已访问过的节点值
        return dfs(root, k, seen);
    }
private:
    bool dfs(TreeNode* node, int k, unordered_set<int>& seen) {
        if (!node) return false;                     // 空树/空儿子
        if (seen.count(k - node->val)) return true;  // 先查补数
        seen.insert(node->val);                      // 再插入自己，避免同节点配对
        return dfs(node->left, k, seen) || dfs(node->right, k, seen);
    }
};
```

### Python

```python
from typing import Optional

class Solution:
    def findTarget(self, root: Optional[TreeNode], k: int) -> bool:
        seen = set()                     # 已访问过的节点值
        stack = [root] if root else []   # 显式栈，规避链状树的递归深度限制
        while stack:
            node = stack.pop()
            if k - node.val in seen:     # 先查补数
                return True
            seen.add(node.val)           # 再插入自己，避免同节点配对
            if node.left:
                stack.append(node.left)
            if node.right:
                stack.append(node.right)
        return False
```

## 8. 边界情况与易错点

1. **$k = 2\cdot\text{val}$ 的单节点树**：`root = [2], k = 4` 必须返回 `false`。把「先查后插」写成「先插后查」就会错答 `true`，这是本题最高频的 WA。
2. **只有一个节点 / 空树**：$n = 1$ 时任何 $k$ 都返回 `false`（没有第二个节点）；虽然约束保证 $n \ge 1$，但迭代写法里仍用 `[root] if root else []` 防御空指针。
3. **Python 递归深度**：链状 BST 深度可达 $10^4$，默认上限 1000 直接 `RecursionError`，务必用显式栈（或 `sys.setrecursionlimit`）。
4. **含负数、跨越零**：`root = [0,-1,2], k = 1` 答案是 `true`（$-1 + 2$）。不要写任何「值非负」的隐含假设，数组映射时记得加偏移 $10^4$。
5. **`false` 必须扫完整棵树**：只有命中才允许提前返回；示例 2 要遍历全部 6 个节点才能确认无解。
6. **双指针法不能用于非 BST**：写法 B/C 依赖中序有序，若把同一段代码套到普通二叉树上会漏解；题面已保证输入合法，但迁移到别的题（如「两棵 BST 之和」）时要重新检查这个前提。
7. **递归写法中 `||` 的短路**：`dfs(left) || dfs(right)` 命中左子树后不再访问右子树，这是正确的「提前返回」，不是漏遍历——引理 3 只依赖「较晚访问者能看到较早访问者」，提前结束意味着已经找到答案。
