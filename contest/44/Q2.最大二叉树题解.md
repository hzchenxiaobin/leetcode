# LeetCode 最大二叉树 题解

## 1. 题目概述

- **标题 / 题号**：最大二叉树（#654，medium）
- **链接**：https://leetcode.cn/problems/maximum-binary-tree/
- **来源**：LeetCode 第 44 场周赛 Q2
- **难度**：中等
- **标签**：栈，树，数组，分治，二叉树，笛卡尔树，单调栈

**题意**：给定元素互不相同的整数数组 `nums`，按如下递归规则构造「最大二叉树」：取区间最大值作为根；最大值**左边的前缀**递归构造左子树，**右边的后缀**递归构造右子树；空区间对应空子树。返回构造出的根节点。

**约束**：

- $1 \le \text{nums.length} \le 1000$
- $0 \le \text{nums}[i] \le 1000$
- `nums` 中所有整数**互不相同**

> 💡 这正是**笛卡尔树（Cartesian Tree）**的标准定义：中序遍历为原数组、父节点值不小于子节点值的唯一二叉树。认清这一点，递归定义就变成了「结构性质」。

## 2. 示例

**示例 1**

```text
输入：nums = [3,2,1,6,0,5]
输出：[6,3,5,null,2,0,null,null,1]
解释：[3,2,1,6,0,5] 的最大值 6 为根；
      左侧 [3,2,1] 的最大值 3 为左子树根，右侧 [0,5] 的最大值 5 为右子树根；
      [3,2,1] 中 3 的右侧 [2,1] 以 2 为根，2 的右侧 [1] 以 1 为根；
      [0,5] 中 0 在 5 的左边，成为 5 的左孩子。
```

**示例 2**

```text
输入：nums = [3,2,1]
输出：[3,null,2,null,1]
解释：3 是最大值，作为根；右侧 [2,1] 以 2 为根，2 的右侧 [1] 以 1 为根，
      整棵树退化成一条向右的链。
```

## 3. 解题思路

### 3.1 暴力思路

直接照定义递归：每层线性扫描求当前区间最大值下标 $k$，再递归 $[l,k-1]$ 与 $[k+1,r]$。复杂度满足

$$T(n) = T(k) + T(n-1-k) + O(n)$$

数据随机时左右大致均分，为 $O(n\log n)$；但遇到**单调递增或递减**的数组，每次划分都极端不平衡，退化成 $O(n^2)$。$n = 1000$ 时约 $5\times10^5$ 次比较还能过，规模一旦放大到 $10^5$ 就必然超时。

用**线段树 / ST 表**预处理「区间最大值下标」，可把每层扫描降到 $O(1)$，总复杂度 $O(n\log n)$ 预处理 + $O(n)$ 建树，能过更大数据——但代码量和常数都上去了。能不能只扫一遍、连区间最大值都不查？

### 3.2 核心观察：笛卡尔树 = 单调栈维护的「最右链」

![最大值定根与左右分段递归](images/wc44_q2_max_tree_concept.svg)

先提炼两个结构性事实：

1. **中序不变**：递归顺序是「左子树 → 根 → 右子树」，正是中序遍历，所以答案树的中序序列就是 `nums` 本身。
2. **堆序成立**：根是所在区间的最大值，故父节点值 $\ge$ 子节点值。

反过来，同时满足「中序 = 原数组」与「父 $\ge$ 子」的二叉树是**唯一**的，所以题目要的就是 `nums` 的笛卡尔树。

关键洞察：**不必知道全局最大值就能增量构造**。从左到右依次插入节点时，只需要维护已建树从根出发沿着 `right` 指针的那条路径，称为**最右链**：

- 新元素 $v$ 只可能与最右链上的节点产生父子关系，绝不会进入某个节点**左**子树的深处——因为它的下标最大，任何「在它左边」的节点都可以成为它的祖先；
- 最右链上的值沿链**严格递减**（堆序在链上成立），所以 $v$ 会「吃掉」链尾所有比它小的节点，成为它们共同的新父节点；链上比它大的第一个节点则收它作右孩子。

于是用一个栈保存最右链（栈底 = 根，栈顶 = 当前最深的右端节点），每来一个 $v$ 就弹掉栈顶所有 $< v$ 的元素即可，总弹出次数不超过总压入次数。

### 3.3 算法流程

![单调栈增量构造的五个步骤](images/wc44_q2_mono_stack_flow.svg)

```text
栈 st 初始为空
for v in nums:
    node = new TreeNode(v)
    last = null                       # 最后一个被弹出的节点
    while st 非空 and st.top.val < v:
        last = st.pop()
    node.left = last                  # 被弹出的「最高」节点成为左子树根
    if st 非空:
        st.top.right = node           # v 接到新的最右链末端
    st.push(node)
return st[0]                          # 栈底即全局最大值 = 根
```

为什么 `node.left = last` 是对的：弹出顺序是从栈顶往下，被弹出的节点自栈顶到栈底值**递增**，因此**最后**弹出的 `last` 是其中值最大、下标最小的那个，它恰好是 $v$ 左邻区间的最大值，也就是 $v$ 左子树的根。`last` 原本的右子链仍然描述它右侧的区间，形状无需改动，整块挂过去即可。

### 3.4 示例演算

![逐元素入栈的演算表](images/wc44_q2_example_walkthrough.svg)

对 `nums = [3,2,1,6,0,5]`，六个时刻的栈（自底向顶）依次是 `[3]`、`[3,2]`、`[3,2,1]`、`[6]`、`[6,0]`、`[6,5]`。

**最关键的是 $i=3$**：$v=6$ 把 `1,2,3` 连续弹出，`last` 停在 3（带着右链 $2\to1$），整块挂成 6 的左子树，6 成为新根。随后 `0`、`5` 依次挂在 6 的右侧：`0` 先成 6 的右孩子，`5` 再把 `0` 弹出来当自己的左孩子。最终层序输出 `[6,3,5,null,2,0,null,null,1]`，与示例一致。

## 4. 算法细节

1. **`last` 每轮重置为空**：没有节点被弹出时 `node.left` 必须为空，忘记重置会把它错误地接到上一轮的元素上。
2. **用「最后」弹出的节点当左孩子**：弹出顺序由栈顶向栈底，值递增。取最后弹出者才能把整段区间（含 $2\to1$ 这样的右链）一次搬走；若误用**第一个**弹出者，示例中只有 `1` 会被挂成 6 的左孩子，`2`、`3` 会从树上脱落。
3. **栈中存节点指针而非下标**：挂接时直接 `st.top.right = node`，不必再按下标二次定位；下标方案还要额外维护数组，反而更绕。
4. **`right` 只在栈非空时挂接**：栈空说明 $v$ 大于当前全部元素，它成为整棵树的新根，此时没有任何节点的右指针需要修改。
5. **返回 `st[0]`（栈底）**：栈底始终是已处理前缀的最大值，也就是最终根。写成 `st.back()` 会返回最后插入的元素（示例中是 5），立刻 WA。
6. **比较用严格小于 `st.top.val < v`**：题面保证元素互不相同，因此 `<` 与 `≤` 在此等价；若将来允许重复值，还要先明确「最大值取最左还是最右」再决定方向。
7. **不需要哨兵值**：元素可以取到 0，而算法只做元素之间的相对比较，不依赖 0 或 -1 表示「空」。

## 5. 正确性证明

记处理完 `nums[0..i]` 后，栈自底向顶为 $s_0, s_1, \dots, s_m$，对应下标 $p_0 < p_1 < \dots < p_m$（约定 $p_{-1} = -1$）。

**引理 1（栈单调）**：任意时刻栈内节点值自底向顶严格递减，即 $s_0 > s_1 > \dots > s_m$。

**证明**：初始为空，成立。插入 $v$ 前弹掉所有 $< v$ 的栈顶，留下的栈顶（若存在）满足 $> v$（值互不相同），原有相邻元素的次序不变，压入 $v$ 后单调性保持。∎

**引理 2（栈 = 前缀的右起最大值）**：栈中元素恰为 `nums[0..i]` 的后缀最大值序列；并且对每个 $0 \le j < m$，$s_{j+1}$ 是区间 $(p_j, i]$ 的最大值，即栈就是当前已建树从根出发的最右链。

**证明**：对 $i$ 归纳。$i=0$ 时栈只有一个元素，显然成立。设插入 $v = \text{nums}[i+1]$，被弹出的是 $s_{j+1},\dots,s_m$（即 $s_j > v$，或全部弹出）。任取 $x \in (p_j, i]$：

- 若 $x$ 是 `nums[0..i]` 的后缀最大值，则 $x \in \{s_{j+1},\dots,s_m\}$，由弹出条件 $x < v$；
- 若 $x$ 不是后缀最大值，则它右侧存在更大的元素，反复迭代必落到某个后缀最大值 $y \in \{s_{j+1},\dots,s_m\}$ 且 $y > x$，于是同样 $x < v$。

故 $v$ 大于 $(p_j, i]$ 内的全部元素，新栈 $s_0,\dots,s_j,v$ 仍是右起最大值序列，且 $v$ 是 $(p_j, i+1]$ 的最大值。∎

**引理 3（挂接正确）**：`node.left = last` 把 `last` 及其既有子树整体挂到 $v$ 左侧后，得到的正是区间 $(p_j, i]$ 的最大二叉树。

**证明**：由引理 2，$last = s_{j+1}$ 是 $(p_j, i]$ 的最大值；由归纳假设当前树已是 `nums[0..i]` 的最大二叉树，右链节点 $s_{j+1}$ 的子树恰好覆盖下标区间 $(p_j, i]$，其内部形状已符合递归定义，整体挂接不改动内部结构。∎

**定理**：算法结束时栈底节点就是 `nums` 的最大二叉树的根，且整棵树与题面的递归构造一致。

**证明**：对元素个数归纳。$n=1$ 时直接返回该节点，成立。设前 $i$ 个元素构造正确，插入 $v$ 时，由引理 2 的论证 $v$ 大于 $(p_j, i]$ 的全部元素，故把 $v$ 作为区间 $(p_j, i+1]$ 的根符合「最大值做根」；左子树由引理 3 正确，右子树为空；再把 $s_j$ 的右指针指向 $v$，表示 $s_j$（区间 $(p_{j-1}, i]$ 的最大值，现右端扩展到 $i+1$）的右子树以 $v$ 为根，同样符合递归定义；若栈被弹空，则 $v$ 大于整个前缀，其左子树为旧的整棵树、成为新的根，也符合定义。归纳可得处理完全部元素后整棵树正确，栈底即根（引理 2 中 $s_0$ 是全体最大值）。∎

## 6. 复杂度分析

- **时间**：$O(n)$。外层循环 $n$ 次；每个节点最多入栈一次、出栈一次，`while` 的总迭代次数不超过 $n$，均摊到每次插入是 $O(1)$。
- **空间**：$O(n)$。栈最多同时保存 $n$ 个节点指针；输出树自身占 $O(n)$ 个节点，通常不计入辅助空间。相比递归分治版，省掉了 $O(h)$ 的系统调用栈。

## 7. 参考代码

### C++

```cpp
#include <vector>
using namespace std;

struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
};

class Solution {
public:
    TreeNode* constructMaximumBinaryTree(vector<int>& nums) {
        vector<TreeNode*> st;                 // 单调递减栈：当前树的最右链
        for (int v : nums) {
            TreeNode* node = new TreeNode(v);
            TreeNode* last = nullptr;         // 最后一个被弹出的节点
            while (!st.empty() && st.back()->val < v) {
                last = st.back();
                st.pop_back();
            }
            node->left = last;                // 被弹出的最高节点 = 左子树根
            if (!st.empty()) st.back()->right = node;
            st.push_back(node);
        }
        return st.front();                    // 栈底是全局最大值 = 根
    }
};
```

### Python

```python
class Solution:
    def constructMaximumBinaryTree(self, nums: 'List[int]') -> 'TreeNode':
        st = []                               # 单调递减栈：当前树的最右链
        for v in nums:
            node = TreeNode(v)
            last = None                       # 最后一个被弹出的节点
            while st and st[-1].val < v:
                last = st.pop()
            node.left = last                  # 被弹出的最高节点 = 左子树根
            if st:
                st[-1].right = node
            st.append(node)
        return st[0]                          # 栈底是全局最大值 = 根
```

## 8. 边界情况与易错点

1. **单元素**：`nums = [5]` 时循环不弹出、栈空也不挂右指针，返回 `st[0]`，得到单节点 `[5]`，无需特判。
2. **严格递增**（如 `[1,2,3,4]`）：每轮都把栈弹空，形成一条**向左**的链，层序为 `[4,3,null,2,null,1]`；此时 `last` 是旧根，绝不能漏掉 `node.left = last`。
3. **严格递减**（如 `[4,3,2,1]`）：从不弹出，形成一条**向右**的链，层序为 `[4,null,3,null,2,null,1]`；深度可达 $1000$，递归分治版在这种数据上时间退化为 $O(n^2)$，Python 还有递归深度风险，迭代单调栈没有这两个问题。
4. **返回根写成 `st.back()`**：返回最后插入的节点，示例中会得到 5 而不是 6，是最常见的 WA 来源。
5. **`while` 比较方向写反**：写成「栈顶 `>` v 才弹」会把大元素弹掉，树结构完全错乱；正确条件是**栈顶小于 $v$**。
6. **值域含 0**：元素可以为 0，不要把 0 当作「空指针」哨兵，判空统一用 `nullptr` / `None`。
7. **空数组**：题目保证 $n \ge 1$；若把接口扩展到空输入，应返回 `nullptr` / `None`，否则 `st[0]` 越界。
8. **内存管理**：C++ 用 `new` 建节点，LeetCode 判题器统一回收；本地压测大量用例时需自行释放，避免内存暴涨。
