# LeetCode 输出二叉树 题解

## 1. 题目概述

- **标题 / 题号**：输出二叉树（#655，medium）
- **链接**：https://leetcode.cn/problems/print-binary-tree/
- **来源**：LeetCode 第 44 场周赛 Q3
- **难度**：中等
- **标签**：树、深度优先搜索、广度优先搜索、二叉树

**题意**：给定二叉树根 `root`，把树画进一个 $m \times n$ 的字符串矩阵 `res`（行列下标从 0 开始）。设树高为 `height`（根到最深叶子的**边数**），则 $m = height + 1$、$n = 2^{height+1} - 1$；根放在顶行正中间一列，即第 $\frac{n-1}{2}$ 列；位于第 $r$ 行第 $c$ 列的结点，其左孩子放在第 $r+1$ 行第 $c - 2^{height-r-1}$ 列、右孩子放在第 $c + 2^{height-r-1}$ 列；所有未被占用的格子必须是空串 `""`。返回这个矩阵。

**约束**：

- 结点数在 $[1, 2^{10}]$ 内
- $-99 \le Node.val \le 99$
- 树的深度（结点层数）在 $[1, 10]$ 内，即 $0 \le height \le 9$，故 $n \le 2^{10}-1 = 1023$、$m \le 10$

## 2. 示例

**示例 1**

```text
输入：root = [1,2]
输出：[["", "1", ""],
      ["2", "", ""]]
解释：高度 height = 1 ⇒ m = 2、n = 3；根 1 在 res[0][1]，
      左孩子 2 在 res[1][1 - 2^0] = res[1][0]。
```

**示例 2**

```text
输入：root = [1,2,3,null,4]
输出：[["", "", "", "1", "", "", ""],
      ["", "2", "", "", "", "3", ""],
      ["", "", "4", "", "", "", ""]]
解释：高度 height = 2（1→2→4 两条边）⇒ m = 3、n = 7。
      根 1 在 res[0][3]；2、3 分别在 res[1][1]、res[1][5]；
      4 是 2 的**右**孩子，落在 res[2][1 + 2^0] = res[2][2]。
```

**示例 3（边界补充）**

```text
输入：root = [1,2,3]
输出：[["", "1", ""],
      ["2", "", "3"]]
解释：满两层，height = 1；两个孩子在 res[1][0] 与 res[1][2]。
```

## 3. 解题思路

### 3.1 暴力思路

最朴素的写法是**逐格回答**：对矩阵中每个格子 $(r, c)$，从根出发沿某条路径判断「谁会落在这一格」，单格代价 $O(h)$，总计 $O(m \cdot n \cdot h)$。本题 $m \cdot n \le 10 \cdot 1023$ 尚能过，但实现绕、容易写错，而且完全没有利用题目布局的规律。

另一种常见误区是**直接拿完全二叉树的堆式编号当列号**：树不满时，缺失的兄弟结点不占位，编号会整体左移，列号就全错（题目要求缺失结点**照样占据**布局位置）。所以关键在于：布局属于「**完美二叉树**」而不是「完全二叉树」。

### 3.2 核心观察：列号就是「补全后」的中序编号

![补成完美二叉树后，列号即中序编号](images/wc44_q3_perfect_inorder.svg)

把树补全成高度为 $h$ 的完美二叉树（缺失结点只占位、不写字），总格子数恰为 $n = 2^{h+1} - 1$。此时题面的偏移规则 $2^{h-r-1}$ **每往下一层就减半**：从根出发，第 $i$ 步横移 $\pm 2^{h-i}$，走的正是「区间对半切」。

于是有一个漂亮的等价刻画：

> **深度 $d$、层内从左到右第 $j$ 个结点（$j$ 从 0 起，只数真实存在的结点），其列号为**
> $$c = (2j+1)\cdot 2^{h-d} - 1$$

验证：$d = 0$ 时 $c = 2^h - 1 = (n-1)/2$，正是顶行正中；$d = h$ 时 $c = 2j$，叶子只能落在偶数列 $0,2,\dots,n-1$。换句话说，**列号 = 该结点在完美补全树中的中序次序**：根是第 $2^h$ 个，左子树整体排在它左边。

由此还可得到实现上最省事的形式：**用列区间 $[lo, hi]$ 表示「这一层这一段留给这棵子树」**，取中点落格，左右孩子分别继承 $[lo, c-1]$ 与 $[c+1, hi]$——这正是「由有序数组建平衡 BST」的同一套区间二分，天然免去所有幂运算。

### 3.3 算法流程：两遍 DFS

![算法流程：先求高定尺寸，再区间二分填表](images/wc44_q3_two_pass_dfs.svg)

```text
1. h = height(root)：空结点返回 -1，否则 1 + max(height(left), height(right))
2. m = h + 1，n = 2^(h+1) - 1，res 全部初始化为 ""
3. fill(root, r = 0, lo = 0, hi = n - 1)：
     node 为空 → 直接返回
     c = (lo + hi) / 2
     res[r][c] = str(node.val)
     fill(node.left,  r + 1, lo, c - 1)
     fill(node.right, r + 1, c + 1, hi)
4. 返回 res
```

**为什么区间二分与题面公式等价**：结点所在区间的长度恒为 $2^{h-r+1} - 1$（$r$ 为深度），中点到左端点距离为 $2^{h-r} - 1$，而左孩子区间的中点在 $c - 2^{h-r-1}$ 处——相差恰好是题面要求的偏移。归纳假设下两者逐层一致（详见 §5 引理 2）。

### 3.4 示例演算

![示例 2 的 3×7 矩阵逐格走查](images/wc44_q3_example_walkthrough.svg)

以 `root = [1,2,3,null,4]` 为例，先求高：最长链 $1 \to 2 \to 4$ 有 2 条边，故 $h = 2$，$m = 3$、$n = 7$。

| 结点 | 深度 $r$ | 层内序号 $j$ | 列号 $(2j+1)2^{h-r}-1$ | 题面公式验算 |
|------|----------|--------------|------------------------|--------------|
| 1 | 0 | 0 | $1 \times 4 - 1 = 3$ | $(n-1)/2 = 3$ ✅ |
| 2 | 1 | 0 | $1 \times 2 - 1 = 1$ | $3 - 2^{2-0-1} = 1$ ✅ |
| 3 | 1 | 1 | $3 \times 2 - 1 = 5$ | $3 + 2^{2-0-1} = 5$ ✅ |
| 4 | 2 | 1 | $3 \times 1 - 1 = 2$ | $1 + 2^{2-1-1} = 2$ ✅ |

注意第 4 行：$4$ 是 $2$ 的**右**孩子（层序 `[1,2,3,null,4]` 中它挂在 $2$ 的右槽），所以是「加」偏移落在第 2 列，而不是第 0 列——这正是官方输出第 3 行为 `["", "", "4", "", "", "", ""]` 的原因。其余 $21 - 4 = 17$ 个格子保持空串。

## 4. 算法细节

1. **高度定义必须是「空树 = −1」**：这样才能让单结点的树得到 $h = 0$、$m = 1$、$n = 1$，与题面 $n = 2^{h+1}-1$ 自洽。若把空树记为 0，则 $n$ 会翻倍、根的位置也随之偏移。
2. **$n$ 用位运算**：`n = (1 << (h + 1)) - 1`，别用 `pow(2, h+1) - 1` 的浮点结果再取整，避免精度与取整方向问题。
3. **填表用区间而不是幂**：`fill(node, r, lo, hi)` 只需一次整除取中点；直接写 $c \pm 2^{h-r-1}$ 时，叶子处 $r = h$ 会得到 $2^{-1}$——C++ 中 `1 << -1` 是未定义行为，Python 里 `1 << -1` 直接抛 `ValueError`，必须靠「先判孩子是否为空」兜住。
4. **初始化即空串**：`vector<vector<string>> res(m, vector<string>(n, ""))` / `[[""] * n for _ in range(m)]`，保证未被写到的格子天然满足「空单元格为 `""`」。
5. **递归只往下走真实结点**：DFS 访问次数恰为结点数 $N$，不会因为矩阵有 $m \cdot n$ 格而变成指数级。
6. **求高也可 BFS**：层序遍历记录层数 `levels`，则 $h = levels - 1$；两者等价，DFS 更短。
7. **值域 $-99 \sim 99$ 含负数**：用 `to_string` / `str` 转换，切勿手写 `char('0' + val)` 之类。
8. **规模核对**：$N \le 1024$、$h \le 9$ ⇒ $n \le 1023$、$m \le 10$，格子数 $\le 10\,230$，一切 `int` 足够，$2^{h+1} \le 1024$ 也不会有位移溢出。

## 5. 正确性证明

**引理 1（层内序号的孩子映射）**：按「层序 + 同层从左到右」给结点编号，若结点 $u$ 在深度 $d$ 的层内序号为 $j$，则其左孩子（若存在）在深度 $d+1$ 的层内序号为 $2j$，右孩子（若存在）为 $2j + 1$。

**证明**：深度 $d+1$ 的结点由深度 $d$ 的结点按顺序「先左后右」展开得到；第 $j$ 个结点之前恰有 $j$ 个结点，它们各自最多贡献 2 个孩子，故 $u$ 的左孩子之前至多有 $2j$ 个结点。又因只统计真实存在的结点，序号连续，故左孩子序号为 $2j$、右孩子为 $2j+1$。∎

**引理 2（列号闭式）**：设结点深度为 $d$、层内序号为 $j$，按题面规则从根 $res[0][(n-1)/2]$ 逐层递推得到的列号为
$$c(d, j) = (2j+1)\cdot 2^{h-d} - 1$$
且恒有 $0 \le c \le n - 1$。

**证明**：对 $d$ 归纳。$d = 0$：$c = 2^h - 1 = (n-1)/2$，与题面根位置一致。设深度 $d$ 时成立，则左孩子列号
$$c(d,j) - 2^{h-d-1} = \big[(2j+1)\cdot 2 - 1\big]\cdot 2^{h-d-1} - 1 = \big(2\cdot 2j + 1\big)\cdot 2^{h-(d+1)} - 1 = c(d+1, 2j),$$
右孩子列号
$$c(d,j) + 2^{h-d-1} = \big[(2j+1)\cdot 2 + 1\big]\cdot 2^{h-d-1} - 1 = \big(2(2j+1) + 1\big)\cdot 2^{h-(d+1)} - 1 = c(d+1, 2j+1),$$
与引理 1 的孩子序号对应，归纳成立。范围：$0 \le j \le 2^d - 1$ 时 $c \ge 2^{h-d} - 1 \ge 0$，且
$$c \le (2^{d+1}-1)\cdot 2^{h-d} - 1 = 2^{h+1} - 2^{h-d} - 1 \le 2^{h+1} - 2 < n. \qquad \blacksquare$$

**引理 3（区间二分与闭式一致）**：若结点 $u$ 对应的列区间 $[lo, hi]$ 满足 $hi - lo = 2^{h-d+1} - 2$ 且中点 $c = (lo+hi)/2 = c(d,j)$，则其左、右孩子区间 $[lo, c-1]$、$[c+1, hi]$ 的中点分别为 $c(d+1, 2j)$、$c(d+1, 2j+1)$。

**证明**：左孩子区间中点为 $\lfloor (lo + c - 1)/2 \rfloor$。由 $c = (lo+hi)/2$ 与对称性 $hi - c = c - lo = 2^{h-d}-1$，得 $lo = c - (2^{h-d}-1)$，故左中点 $= (2c - 2^{h-d})/2 = c - 2^{h-d-1}$，右中点 $= (2c + 2^{h-d})/2 = c + 2^{h-d-1}$，与引理 2 的递推完全相同。∎

**定理**：算法输出的 `res` 严格满足题面的全部布局规则。

**证明**：尺寸由 §3.3 第 2 步按 $h$ 设为 $(h+1) \times (2^{h+1}-1)$，符合「行数 $= height+1$、列数 $= 2^{height+1}-1$」；根的位置由 `fill` 首层中点 $c(0,0) = 2^h-1 = (n-1)/2$ 给出，符合「根在顶行正中」；每个非空结点 $u$ 的落格由引理 2、3 保证恰是题面递推公式给出的位置，符合「左孩子在 $c - 2^{h-r-1}$、右孩子在 $c + 2^{h-r-1}$」；`fill` 沿树的边递归、每个真实结点恰好被访问一次（树无环、每点唯一父），故每个结点写入自己的 `str(val)` 且不会被覆盖；同一深度内列号随 $j$ 严格递增、不同结点列号互异，故无冲突；未被访问的格子保持初始值 `""`，满足「任意空单元格为空字符串」。∎

## 6. 复杂度分析

- **时间**：求高 $O(N)$；填表 $O(m \cdot n)$（矩阵初始化 $m \cdot n$ 次空串赋值，DFS 本体 $O(N)$）。总体 $O(m \cdot n) = O(2^{h})$，与输出规模同阶，已是下界。$h \le 9$ 时约 $10^4$ 次操作。
- **空间**：输出矩阵本身 $O(m \cdot n)$ 个字符串；递归栈深度 $O(h) \le 10$；除此之外仅 $O(1)$ 辅助变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int height(TreeNode* root) {
        if (!root) return -1;                       // 空树高度 -1，单结点为 0
        return 1 + max(height(root->left), height(root->right));
    }

    vector<vector<string>> printTree(TreeNode* root) {
        int h = height(root);
        int m = h + 1;
        int n = (1 << (h + 1)) - 1;                 // 完美二叉树的格子数
        vector<vector<string>> res(m, vector<string>(n, ""));
        function<void(TreeNode*, int, int, int)> fill = [&](TreeNode* node, int r, int lo, int hi) {
            if (!node) return;                      // 只对真实结点落格
            int c = (lo + hi) / 2;                  // 区间中点 = 中序编号
            res[r][c] = to_string(node->val);
            fill(node->left, r + 1, lo, c - 1);
            fill(node->right, r + 1, c + 1, hi);
        };
        fill(root, 0, 0, n - 1);
        return res;
    }
};
```

### Python

```python
class Solution:
    def printTree(self, root: TreeNode | None) -> list[list[str]]:
        def height(node: TreeNode | None) -> int:
            if node is None:
                return -1
            return 1 + max(height(node.left), height(node.right))

        h = height(root)
        m, n = h + 1, (1 << (h + 1)) - 1
        res = [[""] * n for _ in range(m)]

        def fill(node: TreeNode | None, r: int, lo: int, hi: int) -> None:
            if node is None:
                return
            c = (lo + hi) // 2
            res[r][c] = str(node.val)
            fill(node.left, r + 1, lo, c - 1)
            fill(node.right, r + 1, c + 1, hi)

        fill(root, 0, 0, n - 1)
        return res
```

> 💡 两份代码在官方 2 组示例与 1 组边界用例（`[1,2,3]`）上输出完全一致；另用 **2000 组随机二叉树**（结点数 $\le 10$、值域 $[-99, 99]$）对拍：一组校验器**逐条核对题面规则**（尺寸、根位置、每对父子位置、其余格为空串），另一组用**闭式** $c = (2j+1)2^{h-d}-1$ 独立构造，三方 `mismatch = 0`。

## 8. 边界情况与易错点

1. **单结点树**：$h = 0$ ⇒ $m = 1$、$n = 1$、`res[0][0] = str(root.val)`。若把空树高度记成 0，会误算成 $2 \times 3$ 的矩阵。
2. **右孩子是「加」偏移**：示例 2 的 `4` 落在第 2 列而不是第 0 列，就是右孩子按 $c + 2^{h-r-1}$ 落格；只写减号会在所有「只有右孩子」的树上错位。
3. **叶子处不要算 $2^{h-r-1}$**：$r = h$ 时指数为 $-1$，C++ `1 << -1` 未定义行为、Python 直接抛异常。用区间二分，或先判 `node->left` 是否存在再递归。
4. **空串 vs 空格**：未占用格必须是 `""`（长度为 0），写 `" "` 会让判题与对比全部失败。
5. **树不满时仍要占位**：布局按完美二叉树的坐标走，缺失的兄弟结点不能被「压缩掉」，否则整层列号左移。
6. **高度与深度别混**：题面 `height` 是边数，结点层数 = `height + 1`；用 BFS 求高时是「层数 − 1」。
7. **不要用堆式下标**：完全二叉树编号在缺孩子时会裂开，本题要的是完美布局。
8. **负数与规模**：值可为 $-99$，转换函数要能处理负号；$n$ 最大 1023，`int` 足够但别把 $2^{h+1}$ 写成 `2 ^ (h + 1)` 的异或（C++ 中 `^` 是位异或，不是幂）。
