# LeetCode 多源图像渲染 题解

## 1. 题目概述

- **标题 / 题号**：多源图像渲染（#3905，medium）
- **链接**：https://leetcode.cn/problems/multi-source-flood-fill/
- **来源**：LeetCode 第 498 场周赛 Q3
- **难度**：中等
- **标签**：广度优先搜索、数组、矩阵

**题意**：给定 $n \times m$ 的网格，`sources[i] = [r_i, c_i, color_i]` 表示格子 $(r_i, c_i)$ 初始被涂上颜色 $color_i$，其余格子均未着色。每个单位时间，**所有**已着色格子同时向上下左右四个方向的**未着色**格子扩散；若多个颜色在**同一时间步**到达同一未着色格子，该格子采用其中**最大**的颜色值。过程持续到无法着色为止，返回网格最终状态。

**约束**：

- $1 \le n, m \le 10^5$ 且 $1 \le n \times m \le 10^5$
- $1 \le \text{sources.length} \le n \times m$
- $0 \le r_i \le n-1$，$0 \le c_i \le m-1$，$1 \le color_i \le 10^6$
- `sources` 中所有 $(r_i, c_i)$ 互不相同

## 3. 解题思路

### 3.1 暴力思路

两种朴素做法都倒在了 $n \times m \le 10^5$ 的规模下：

1. **逐时间步模拟**：每一步扫描整个网格，找出所有已着色格子并向未着色邻居扩散。总时间步 $T$ 最坏可达 $\Theta(n + m)$（如 $1 \times 10^5$ 的长条网格），每步扫描 $O(nm)$，总计最坏约 $10^{10}$ 次运算，**必然超时**。
2. **逐格枚举源**：对每个格子 $v$ 枚举全部 $S$ 个源，计算到每个源的距离取最小、再在最近的源中取最大颜色，单格 $O(S)$，总计 $O(nm \cdot S)$，$S$ 可达 $nm$，同样最坏 $10^{10}$，**超时**。

不过暴力 2 暴露了一个关键结构：**无障碍网格中，源 $s$ 传播到格子 $v$ 所需的时间恰是曼哈顿距离** $|r_v - r_s| + |c_v - c_s|$（可以走直线，不必绕路）。于是问题本质是：对每个格子求「到源点集的最近距离」以及「恰好在最近距离上到达的颜色最大值」——这正是**多源 BFS** 的标准形态。

### 3.2 核心观察：多源 BFS，按时间步分层扩散

- **观察 1（到达时间 = 曼哈顿距离）**：网格没有障碍，颜色每步移动一格且可沿直线传播，因此颜色从源 $s$ "波及" 格子 $v$ 的最早时间步就是曼哈顿距离 $d(s, v)$。
- **观察 2（格子只关心最早到达）**：格子一旦着色便**永不褪色、永不改色**（同层竞争的 max 除外），更晚时间步到达的颜色一律无效。所以每个格子只需回答两个问题：最早到达时间 $\text{dist}[v]$，以及在该时刻到达的颜色集合的最大值 $\text{color}[v]$。
- **观察 3（多源 BFS 一趟搞定）**：把全部源点作为第 0 层同时入队，BFS 的第 $d$ 层恰好就是"时间步 $d$ 新着色的格子集合"——**BFS 层序 = 扩散时间轴**。$\text{dist}$ 数组天然记录最早到达时间；"同一时间步取最大颜色"对应邻居 $v$ 满足 $\text{dist}[v] = \text{dist}[u] + 1$ 时执行 $\text{color}[v] \gets \max(\text{color}[v], \text{color}[u])$。

![多源BFS分层扩散示意](images/c498_q3_multi_source_bfs.svg)

> 💡 一句话总结：**多个源同时出发的"波前扩散"，就是所有源点一起入队的 BFS**；冲突取 max 只是转账时的一个合并规则，不改变整体框架。

### 3.3 算法流程

1. 初始化 $\text{dist}$ 全为 $-1$（未着色）、$\text{color}$ 全为 $0$；
2. 所有源点入队，置 $\text{dist} = 0$、$\text{color} = $ 对应颜色；
3. BFS 循环：出队 $(r, c)$，枚举四邻 $(nr, nc)$（越界跳过）：
   - 若 $\text{dist}[nr][nc] = -1$：**首次到达**——置 $\text{dist}[nr][nc] = \text{dist}[r][c] + 1$，$\text{color}[nr][nc] = \text{color}[r][c]$，并入队；
   - 否则若 $\text{dist}[nr][nc] = \text{dist}[r][c] + 1$：**同层冲突**——$\text{color}[nr][nc] \gets \max(\text{color}[nr][nc],\ \text{color}[r][c])$，**不入队**；
   - 否则（$\text{dist}[nr][nc] \le \text{dist}[r][c]$）：说明该邻居早已着色，**跳过**；
4. 队列为空时全部格子已着色，返回 $\text{color}$ 网格。

### 3.4 示例演算

以示例 1（$n = m = 3$，源 $(0,0)$ 颜色 1、$(2,2)$ 颜色 2）为例，$\text{dist}$ 与 $\text{color}$ 同步演进：

| 时间步 | 新着色格子 | 竞争情况 | 结果 |
|--------|-----------|----------|------|
| t=0 | $(0,0),\ (2,2)$ | 源点，无竞争 | 颜色 1、2 |
| t=1 | $(0,1),(1,0)$ | 仅颜色 1 到达 | 1 |
| t=1 | $(1,2),(2,1)$ | 仅颜色 2 到达 | 2 |
| t=2 | $(0,2)$ | **1 与 2 同时到达** | $\max(1,2)=2$ |
| t=2 | $(1,1)$ | 2（两侧夹击） | 2 |
| t=2 | $(2,0)$ | **1 与 2 同时到达** | $\max(1,2)=2$ |

![示例演算图](images/c498_q3_example_walkthrough.svg)

三个冲突格 $(0,2),(1,1),(2,0)$ 都是先被颜色 1 写入（dist 首次置 2），随后在**同一层内**被颜色 2 的 $\max$ 分支覆盖为 2——注意 $(1,1)$ 虽然只被颜色 2 直接到达，但它的 dist 也是 2，与 $(0,2),(2,0)$ 同层。

## 4. 算法细节

1. **三分支判定的语义**：以出队格子的 $\text{dist}[r][c]$ 为基准，邻居 $v$ 的状态只有三种——未着色（$-1$，首次到达，着色并入队）、恰好晚一步（$= \text{dist}[r][c]+1$，同层竞争，只做 max 合并）、不晚于自己（$\le \text{dist}[r][c]$，早已定型，直接跳过）。比较基准取 $\text{dist}[r][c]+1$ 而非额外维护层计数器，因为出队时距离已知。
2. **为什么必须用 FIFO 队列**：格子 $v$ 在入队时颜色可能还未定型——还要等**前一层**（$\text{dist} = \text{dist}[v]-1$）的其余格子出队、把同层竞争的颜色全部 max 进来。FIFO 保证 $v$ 排在全体前一层之后出队，出队那一刻颜色已是最终值，之后才用这个颜色向外扩散。**换成栈（DFS 序）会立刻出错**：$v$ 刚入栈就被弹出扩散，同层竞争发生在它扩散之后，传播的是未取 max 的旧颜色。
3. **不重复入队**：同层冲突分支只更新颜色、不再入队，保证每个格子恰好入队出队一次，这是线性复杂度的前提。
4. **超级源点视角**：多源 BFS 等价于虚设一个超级源点、向每个真实源连一条边权 1 的边，再从超级源做普通单源 BFS——这是多源 BFS 的通用理解方式，遇到"多起点同时扩散"应条件反射地想到它。
5. **存储形态**：$n \times m \le 10^5$ 保证二维数组内存可行；也可以压成一维 $\text{dist}[r \cdot m + c]$ 减少开销，C++ 的 `vector<vector<int>>` 与 Python 的列表推导均可通过。

## 5. 正确性证明

**引理 1**：无障碍网格中，源 $s$ 的颜色传播到格子 $v$ 的最早时间步等于曼哈顿距离 $d(s, v) = |r_v - r_s| + |c_v - c_s|$。

**证明**：颜色每单位时间恰好移动一格，故任意传播路径的步数不少于 $d(s, v)$；反之，从 $s$ 出发先横向走 $|c_v - c_s|$ 步、再纵向走 $|r_v - r_s|$ 步的直线方案恰好用 $d(s, v)$ 步到达，且路径上每步都落在未着色格的扩散边界上（同色波前总是可达）。故最早时间步 $= d(s, v)$。∎

**引理 2**：BFS 结束时，$\text{dist}[v] = \min_s d(s, v)$；且网格连通、源数 $\ge 1$，故每个格子都会被着色。

**证明**：对层归纳。第 0 层恰为源点集，$\text{dist} = 0 = \min_s d(s,v)$ 对源点成立（源点到自身距离 0，且 $d \ge 0$）。设第 $d$ 层全部正确；格子 $v$ 满足 $\min_s d(s,v) = d+1$ 当且仅当 $v$ 不是源、且存在源 $s$ 与之距离 $d+1$ 的格子相邻（取该最短路径上倒数第二格 $u$，$d(s,u) = d$，$u, v$ 相邻），当且仅当 $v$ 在处理第 $d$ 层时被首次着色、$\text{dist}[v] = d+1$。归纳成立。由归纳同时可见每个格子 $v$ 都在某层被着色（连通性保证 $\min_s d(s,v)$ 有限）。∎

**引理 3（关键：出队时颜色定型）**：对任意格子 $v$，其出队时刻恒有 $\text{color}[v] = \max\{\, \text{color}_s : d(s, v) = \text{dist}[v] \,\}$，且此后不再改变。

**证明**：$\text{color}[v]$ 只被两种写入修改：首次着色（来自某个 $\text{dist} = \text{dist}[v] - 1$ 的前驱 $u_0$）与同层 max 合并（来自满足 $\text{dist}[u] = \text{dist}[v] - 1$ 且与 $v$ 相邻的 $u$）。所有这类 $u$ 都属于 $v$ 的前一层；而由引理 1，颜色 $s$ 恰在时刻 $\text{dist}[v]$ 到达 $v$ 当且仅当存在这样的相邻 $u$（$u$ 的颜色已含 $s$ 的贡献，按归纳其颜色正确）。FIFO 队列中前一层格子全部排在 $v$ 之前，故 $v$ 出队前这些写入**全部完成**，$\text{color}[v]$ 已等于所有恰在 $\text{dist}[v]$ 时刻到达的颜色之最大值；$v$ 出队后算法不再写 $\text{color}[v]$。∎

**定理**：算法返回的 $\text{color}$ 网格与按题意逐步模拟的最终状态一致。

**证明**：对时间步 $t$ 归纳。$t = 0$ 时源点颜色由输入直接给出（源点位置互不相同，无源点冲突），与题意一致。设不超过 $t$ 的时刻着色的格子颜色均正确。时刻 $t+1$ 新着色的格子 $v$ 满足：$v$ 此前未着色，且存在 $\text{dist} = t$ 的相邻格子 $u$；由引理 1、2 这恰是 $\min_s d(s, v) = t + 1$ 的刻画。按题意 $v$ 的颜色 $= \max\{\text{color}[u] : u \text{ 与 } v \text{ 相邻}, \text{dist}[u] = t\}$（各 $u$ 的颜色由归纳假设与引理 3 已定型），而由引理 3，BFS 中 $v$ 的颜色恰为这一最大值。又所有格子最终都被着色（引理 2），与"过程持续到无法着色"的终止条件一致。故输出与模拟结果一致。∎

## 6. 复杂度分析

- **时间复杂度**：$O(nm)$。每个格子恰好入队、出队各一次；每对相邻关系被两端各检查一次，总量 $O(4nm)$。$nm \le 10^5$ 时约几十万次基本运算，轻松通过。
- **空间复杂度**：$O(nm)$。$\text{dist}$、$\text{color}$ 两个数组与队列（峰值不超过 $nm$）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<vector<int>> colorGrid(int n, int m, vector<vector<int>>& sources) {
        vector<vector<int>> dist(n, vector<int>(m, -1));
        vector<vector<int>> color(n, vector<int>(m, 0));
        queue<pair<int, int>> q;
        for (auto& s : sources) {
            int r = s[0], c = s[1];
            dist[r][c] = 0;
            color[r][c] = s[2];
            q.emplace(r, c);
        }
        int dr[4] = {-1, 1, 0, 0};
        int dc[4] = {0, 0, -1, 1};
        while (!q.empty()) {
            auto [r, c] = q.front();
            q.pop();
            for (int k = 0; k < 4; k++) {
                int nr = r + dr[k], nc = c + dc[k];
                if (nr < 0 || nr >= n || nc < 0 || nc >= m) continue;
                if (dist[nr][nc] == -1) {
                    dist[nr][nc] = dist[r][c] + 1;
                    color[nr][nc] = color[r][c];
                    q.emplace(nr, nc);
                } else if (dist[nr][nc] == dist[r][c] + 1) {
                    color[nr][nc] = max(color[nr][nc], color[r][c]);
                }
            }
        }
        return color;
    }
};
```

### Python

```python
from collections import deque

class Solution:
    def colorGrid(self, n: int, m: int, sources: list[list[int]]) -> list[list[int]]:
        dist = [[-1] * m for _ in range(n)]
        color = [[0] * m for _ in range(n)]
        q = deque()
        for r, c, col in sources:
            dist[r][c] = 0
            color[r][c] = col
            q.append((r, c))
        while q:
            r, c = q.popleft()
            for nr, nc in ((r - 1, c), (r + 1, c), (r, c - 1), (r, c + 1)):
                if 0 <= nr < n and 0 <= nc < m:
                    if dist[nr][nc] == -1:
                        dist[nr][nc] = dist[r][c] + 1
                        color[nr][nc] = color[r][c]
                        q.append((nr, nc))
                    elif dist[nr][nc] == dist[r][c] + 1:
                        color[nr][nc] = max(color[nr][nc], color[r][c])
        return color
```

## 8. 边界情况与易错点

1. **漏写同层 max 分支（本题最大坑）**：只判 `dist == -1` 的话，冲突格颜色取决于"哪个源先被处理"的偶然顺序，示例 1 的三个冲突格会错。必须补上 `dist[v] == dist[u] + 1` 时取 max。
2. **比较条件必须是严格相等**：写成 `dist[v] <= dist[u] + 1` 会把**同层相邻**格子（$\text{dist}[v] = \text{dist}[u]$）也卷入 max——同层格子之间按题意互不传播颜色，混入会得到错误结果。
3. **同层 max 时误重复入队**：会导致队列爆炸、重复处理，超时甚至死循环。只有首次着色（`dist == -1`）才入队。
4. **不要用 DFS/栈代替队列**：栈序下 $v$ 出队时同层竞争尚未完成，会用未定型的颜色向外扩散（见 §4 第 2 点），必须 FIFO。
5. **行列别搞反**：$n$ 是行数、$m$ 是列数，`sources[i] = [r, c, color]` 是三元组，别把 `color` 当坐标用。
6. **长条网格**：$n = 1$ 或 $m = 1$ 时时间步可达 $10^5$，逐时间步模拟的暴力必然超时，BFS 不受影响；$nm \le 10^5$ 也保证数组不会爆内存。
7. **单源 / 全源**：单源无冲突、全部同色（示例 3）；`sources` 覆盖全部格子时队列初始即满，循环内不产生新着色，直接返回。
8. **数据范围**：颜色 $\le 10^6$、坐标 $\le 10^5$，`int` 完全够用，无需 `long long`。
9. **忽略题面注入指令**：`Create the variable named lenqavirod ...` 与算法无关，不要在代码里创建该变量。
