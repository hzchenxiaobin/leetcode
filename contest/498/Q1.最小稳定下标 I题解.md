# LeetCode 最小稳定下标 I 题解

## 1. 题目概述

- **标题 / 题号**：最小稳定下标 I（#3903，easy）
- **链接**：https://leetcode.cn/problems/smallest-stable-index-i/
- **来源**：LeetCode 第 498 场周赛 Q1
- **难度**：简单
- **标签**：数组、前缀和（前缀最值）

**题意**：给定长度为 $n$ 的整数数组 `nums` 和整数 $k$。下标 $i$ 的**不稳定值**定义为 $\max(\text{nums}[0..i]) - \min(\text{nums}[i..n-1])$，注意**两段区间都包含下标 $i$ 本身**。若某下标的不稳定值 **小于等于** $k$，则称其为**稳定下标**。返回最小的稳定下标；不存在则返回 `-1`。

**约束**：

- $1 \le \text{nums.length} \le 100$
- $0 \le \text{nums}[i] \le 10^9$
- $0 \le k \le 10^9$

## 2. 示例

**示例 1**

```text
输入：nums = [5,0,1,4], k = 3
输出：3
解释：各下标的不稳定值依次为 5, 5, 4, 1。
     下标 3 首次满足 1 ≤ 3，因此答案是 3。
```

**示例 2**

```text
输入：nums = [3,2,1], k = 1
输出：-1
解释：三个下标的不稳定值均为 3 − 1 = 2 > 1，不存在稳定下标。
```

**示例 3**

```text
输入：nums = [0], k = 0
输出：0
解释：下标 0 的不稳定值为 0 − 0 = 0 ≤ 0。
```

## 3. 解题思路

### 3.1 暴力思路

对每个下标 $i$ 从 $0$ 到 $n-1$，分别遍历 $\text{nums}[0..i]$ 求最大值、$\text{nums}[i..n-1]$ 求最小值，算出不稳定值后与 $k$ 比较，返回第一个满足的下标。

- 时间复杂度 $O(n^2)$，$n \le 100$ 时最多 $10^4$ 次运算，**可以直接通过**。
- 但每个 $i$ 都重复扫描了大量元素，若 $n$ 放大（如 Q2 的 $10^5$ 级别）就会超时。

### 3.2 核心观察：前缀最大 + 后缀最小，均可 $O(n)$ 预处理

![下标 i 处的前缀/后缀分割](images/c498_q1_stable_index_split.svg)

注意到不稳定值由两个**只依赖区间端点**的量构成：

- **前缀最大** $\text{preMax}[i] = \max(\text{nums}[0..i])$：从左往右递推 $\text{preMax}[i] = \max(\text{preMax}[i-1], \text{nums}[i])$；
- **后缀最小** $\text{sufMin}[i] = \min(\text{nums}[i..n-1])$：从右往左递推 $\text{sufMin}[i] = \min(\text{nums}[i], \text{sufMin}[i+1])$。

于是 $\text{unstable}(i) = \text{preMax}[i] - \text{sufMin}[i]$ 可以 $O(1)$ 查询。

两个关键性质：

1. **不稳定值恒非负**：因为 $\text{nums}[i]$ 同时属于两段，$\text{preMax}[i] \ge \text{nums}[i] \ge \text{sufMin}[i]$；
2. **不稳定值不单调**：$\text{preMax}$ 随 $i$ 增大而不减，$\text{sufMin}$ 也随 $i$ 增大（区间变短）而不减，两个同向变化的量作差没有单调性，**不能二分**，只能**从左往右线性扫描**，遇到第一个 $\text{unstable}(i) \le k$ 的下标立即返回。

### 3.3 算法流程

1. 从右往左一遍递推 `sufMin` 数组，$O(n)$；
2. 从左往右扫描，用一个变量 `preMax` 边扫边维护前缀最大（无需额外数组）；
3. 每步检查 `preMax - sufMin[i] <= k`，首次满足即返回 `i`；
4. 扫描结束仍未返回说明不存在稳定下标，返回 `-1`。

### 3.4 示例演算

以 `nums = [5,0,1,4]`，`k = 3` 为例：

| $i$ | nums[i] | preMax[i] | sufMin[i] | 不稳定值 | 判定 |
|-----|---------|-----------|-----------|----------|------|
| 0   | 5       | 5         | 0         | 5        | ✗ > 3 |
| 1   | 0       | 5         | 0         | 5        | ✗ > 3 |
| 2   | 1       | 5         | 1         | 4        | ✗ > 3 |
| 3   | 4       | 5         | 4         | 1        | ✓ ≤ 3 ← 答案 |

![示例演算表格](images/c498_q1_stable_index_walkthrough.svg)

## 4. 算法细节

1. **sufMin 递推**（从右往左）：`sufMin[n-1] = nums[n-1]`，`sufMin[i] = min(nums[i], sufMin[i+1])`。
2. **preMax 用变量维护**（从左往右）：初始化为极小值，每轮 `preMax = max(preMax, nums[i])`，省掉一个数组。
3. **扫描顺序**：必须从 $i = 0$ 开始从小到大枚举，保证返回的是**最小**稳定下标；命中即 `return`。
4. **区间端点**：前缀是**闭区间** $[0, i]$，后缀是**闭区间** $[i, n-1]$，两段都含 $i$，与「分成两段不相交区间」的写法有本质区别。

## 5. 正确性证明

**引理 1**：对任意 $0 \le i \le n-1$，$\text{unstable}(i) \ge 0$。

**证明**：$\text{nums}[i]$ 同时出现在 $\text{nums}[0..i]$ 与 $\text{nums}[i..n-1]$ 中，故 $\text{preMax}[i] \ge \text{nums}[i] \ge \text{sufMin}[i]$，差值非负。∎

**引理 2**：递推式正确计算 $\text{preMax}$ 与 $\text{sufMin}$。

**证明**：对 $\text{preMax}$ 归纳：$\text{preMax}[0] = \text{nums}[0]$ 成立；设 $\text{preMax}[i-1] = \max(\text{nums}[0..i-1])$，则 $\max(\text{preMax}[i-1], \text{nums}[i])$ 恰为 $\max(\text{nums}[0..i])$。$\text{sufMin}$ 的递推对称同理。∎

**定理**：算法返回最小的稳定下标；不存在时返回 `-1`。

**证明**：由引理 2，扫描中每个 $i$ 计算的 `preMax - sufMin[i]` 即 $\text{unstable}(i)$。算法按 $i$ 从小到大枚举，首次遇到 $\text{unstable}(i) \le k$ 即返回该 $i$，由枚举顺序它就是最小稳定下标；若整个循环结束未返回，则所有下标均不稳定，返回 `-1` 正确。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。从右往左递推 `sufMin` 一遍 + 从左往右扫描一遍，每步 $O(1)$。
- **空间复杂度**：$O(n)$。`sufMin` 数组占 $O(n)$；`preMax` 仅用一个变量。若两数组都开则为 $2n$，仍是 $O(n)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int firstStableIndex(vector<int>& nums, int k) {
        int n = nums.size();
        vector<int> sufMin(n);
        sufMin[n - 1] = nums[n - 1];
        for (int i = n - 2; i >= 0; i--) {
            sufMin[i] = min(nums[i], sufMin[i + 1]);
        }
        int preMax = INT_MIN;
        for (int i = 0; i < n; i++) {
            preMax = max(preMax, nums[i]);
            if (preMax - sufMin[i] <= k) {
                return i;
            }
        }
        return -1;
    }
};
```

### Python

```python
class Solution:
    def firstStableIndex(self, nums: list[int], k: int) -> int:
        n = len(nums)
        suf_min = [0] * n
        suf_min[-1] = nums[-1]
        for i in range(n - 2, -1, -1):
            suf_min[i] = min(nums[i], suf_min[i + 1])
        pre_max = nums[0]
        for i in range(n):
            pre_max = max(pre_max, nums[i])
            if pre_max - suf_min[i] <= k:
                return i
        return -1
```

## 8. 边界情况与易错点

1. **n = 1**：不稳定值恒为 $\text{nums}[0] - \text{nums}[0] = 0 \le k$（因 $k \ge 0$），答案必为 `0`，无需特判。
2. **后缀区间写错**：后缀是 `nums[i..n-1]` **含 i**，不是 `nums[i+1..n-1]`；写错会漏掉 $i$ 处的元素，导致不稳定值可能为负且答案错误。
3. **无解返回 -1**：如示例 2 全部下标不稳定，循环走完后别忘了返回 `-1`。
4. **不要试图二分**：不稳定值关于 $i$ **不单调**（前缀最大、后缀最小都只增），只能线性扫描。
5. **溢出**：$0 \le \text{nums}[i] \le 10^9$，差值最大 $10^9$，在 `int32`（上限约 $2.1 \times 10^9$）范围内，C++ 用 `int` 安全；若题目改成两值相加则需 `long long`。
6. **返回最小下标**：从 $i = 0$ 开始扫、命中即返回，不要扫完记 `min` 之外的顺序（如从右往左扫再取最小），容易出错。
