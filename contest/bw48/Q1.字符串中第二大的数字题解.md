# LeetCode 字符串中第二大的数字 题解

## 1. 题目概述

- **标题 / 题号**：字符串中第二大的数字（#1796，easy）
- **链接**：https://leetcode.cn/problems/second-largest-digit-in-a-string/
- **来源**：LeetCode 第 48 场双周赛 Q1
- **难度**：简单
- **标签**：哈希表、字符串

**题意**：给定一个由小写字母和数字组成的混合字符串 $s$，返回 $s$ 中出现的**第二大的数字**（不同数字中的第二大）；若不存在（没有数字，或只有一种数字），返回 $-1$。

**约束**：

- $1 \le s.length \le 500$
- $s$ 只包含小写英文字母和（或）数字

## 2. 示例

**示例 1**

```text
输入：s = "dfa12321afd"
输出：2
解释：出现的数字集合为 {1, 2, 3}，第二大的数字是 2。
```

**示例 2**

```text
输入：s = "abc1111"
输出：-1
解释：出现的数字只有 {1}，没有第二大的数字。
```

## 3. 解题思路

### 3.1 暴力思路

先扫一遍字符串把出现过的数字收集进**集合**去重，再对集合排序取倒数第二个，时间 $O(n + d \log d)$（$d \le 10$ 是不同数字的个数），空间 $O(d)$。结果必然正确，但"集合 + 排序"对这道题是杀鸡用牛刀——数字只有 0 到 9 共 10 种候选，我们真正关心的只有两个标量：**最大值**与**第二大值**。

### 3.2 核心观察：一遍扫描维护 first / second 两个变量

![核心观察：只需维护最大与第二大两个变量](images/bw48_q1_two_max_scan.svg)

设 $first$ 为当前已见的最大数字、$second$ 为当前已见的第二大数字（**互不相同**意义上的第二大），初始均为 $-1$。逐字符扫描 $c$：

- 不是数字 → 跳过；
- 设 $d = c - $ `'0'`，若 $d > first$：旧的最大值降级为第二大，即 $second \gets first$，$first \gets d$；
- 若 $d = first$：重复数字，不更新（第二大要求**不同**数字）；
- 若 $second < d < first$：$second \gets d$。

扫描结束返回 $second$：初始值 $-1$ 天然表达"无第二大数字"，同时覆盖了"没有数字"与"只有一种数字"两类边界。

> 💡 另一种等价写法是开长度 10 的布尔桶标记出现过的数字，最后从 9 往下找第二个 `true`——对 $d \le 10$ 同样是 $O(n)$，但扫描版连桶都省了，且顺序处理更贴合"一遍流式"的直觉。

### 3.3 算法流程

```text
1. first = second = -1
2. 对每个字符 c：
3.   若 c 不是数字：continue
4.   d = c - '0'
5.   若 d > first：second ← first，first ← d
6.   否则若 d != first 且 d > second：second ← d
7. 返回 second
```

### 3.4 示例演算

![示例演算：dfa12321afd 的 first/second 变化](images/bw48_q1_walkthrough.svg)

对 `"dfa12321afd"`：遇到 `1` 时 $first=1$；遇到 `2` 时 $2 > 1$，旧值降级 $second=1$、$first=2$；遇到 `3` 时 $3 > 2$，$second=2$、$first=3$；随后的 `2`、`1` 分别命中"等于 first 之外的分支"——`2` 不大于 $second=2$ 不更新，`1` 同样不更新。最终 $(first, second) = (3, 2)$，返回 2。

## 4. 算法细节

1. **数字判定**：`isdigit(c)` 或直接 `'0' <= c && c <= '9'`；本题保证只有小写字母与数字，两者皆可。
2. **更新分支的完整性**：三分支按 $d$ 与 $first$、$second$ 的关系**互斥且完备**——大于 first（降级）、等于 first（跳过）、介于其间（只更新 second）、小于等于 second（跳过）。漏掉 "$d = first$ 跳过" 会把相同数字错当第二大。
3. **"第二大"的含义**：是**不同数字**中的第二大，不是"出现次数第二多"，也不是"第二个出现的数字"。`"11122"` 的答案是 1，不是 2。
4. **返回语义**：返回的是数字本身（0 到 9），而 $-1$ 作为哨兵不会与任何真实数字冲突——数字最小是 0，永远安全。
5. **复杂度无关紧要但仍要心里有数**：$n \le 500$，$O(n)$ / $O(1)$ 是标准答案。

## 5. 正确性证明

**引理 1（不变量）**：扫描任意前缀后，$first$ 是前缀中出现的最大数字，$second$ 是前缀中出现且不等于 $first$ 的最大数字；若不存在这样的数字，$second = -1$。

**证明**：对前缀长度归纳。空前缀时 $first = second = -1$，命题成立（无数字）。设处理完前缀 $P$ 时命题成立，考察下一字符 $c$：若 $c$ 非数字，状态不变，命题对 $P' = Pc$ 成立。若 $c$ 是数字 $d$，分四种情形：（i）$d > first$：$P'$ 中最大数字是 $d$；$P'$ 中不等于 $d$ 的数字全体与 $P$ 中全体数字相同，其中最大者是原 $first$，故 $second \gets first$、$first \gets d$ 正确。（ii）$d = first$：出现集合不变，状态保持正确。（iii）$second < d < first$：$P'$ 最大数字仍是 $first$；不等于 $first$ 的数字中新添了 $d$，且 $d$ 大于原 $second$，新第二大是 $d$，更新正确。（iv）$d \le second$（且 $d \ne first$）：$d$ 不超过现有第二大，状态不变仍正确。∎

**定理**：算法返回 $s$ 中第二大的不同数字，不存在时返回 $-1$。

**证明**：由引理 1，扫描结束时 $second$ 是整串中不等于最大数字的最大数字，即"第二大的不同数字"；若这样的数字不存在（无数字或仅一种数字），归纳过程中 $second$ 从未被赋为非负值，保持 $-1$。∎

## 6. 复杂度分析

- **时间**：$O(n)$。每个字符一次判定、至多一次更新。
- **空间**：$O(1)$。两个整型变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int secondHighest(string s) {
        int first = -1, second = -1;              // 最大、第二大的不同数字
        for (char c : s) {
            if (!isdigit((unsigned char)c)) continue;
            int d = c - '0';
            if (d > first) { second = first; first = d; }
            else if (d != first && d > second) second = d;
        }
        return second;
    }
};
```

### Python

```python
class Solution:
    def secondHighest(self, s: str) -> int:
        first, second = -1, -1
        for ch in s:
            if not ch.isdigit():
                continue
            d = int(ch)
            if d > first:
                first, second = d, first
            elif d != first and d > second:
                second = d
        return second
```

> 💡 两份代码均通过官方 2 组示例；另与「出现数字去重排序取次大」的独立实现随机对拍 3000 组（字符集含 0–9 与字母混合），`mismatch = 0`。

## 8. 边界情况与易错点

1. **无数字 / 单一数字**：`"abc"`、`"abc1111"` 都返回 $-1$。哨兵 $-1$ 与真实数字 0 不冲突，别把初始值设成 0（0 是合法答案，如 `"ck00"` 的第二大？——注意 `{"0"}` 只有一种数字仍返回 $-1$；而 `"a0b1"` 返回 0）。
2. **重复数字要忽略**：`d == first` 时必须跳过，否则 `"11"` 会被误判为有第二大数字 1。
3. **降级别写反**：`d > first` 时先 `second = first` 再 `first = d`，顺序颠倒会把 $d$ 覆盖进 second。
4. **`isdigit` 的参数**：C++ 中传 `char` 给 `isdigit` 在某些平台上对负值（如 `char` 为有符号且字符集扩展）是未定义行为，习惯上传 `(unsigned char)c` 最稳。
5. **第二大 ≠ 次频出现**：题目问的是**值**的排序，与出现次数无关。
6. **字符串里有 0**：0 是合法数字，"第二大"完全可能是 0，初始 $-1$ 的哨兵设计正是为此。
