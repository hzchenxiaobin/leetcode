# LeetCode 幸福值最大化的选择方案 题解

## 1. 题目概述

- **标题 / 题号**：幸福值最大化的选择方案（#3075，medium）
- **链接**：https://leetcode.cn/problems/maximize-happiness-of-selected-children/
- **来源**：LeetCode 第 388 场周赛 Q2
- **难度**：中等
- **标签**：贪心、数组、排序

**题意**：$n$ 个孩子站成一队，第 $i$ 个孩子的幸福值为 `happiness[i]`。组织 $k$ 轮筛选、每轮选中一个孩子（共选 $k$ 个）：**每一轮选中一个孩子时，所有尚未被选中的孩子幸福值减少 1**（只在为正时才减，不能变负）。返回被选中的 $k$ 个孩子幸福值之和的最大值。

**约束**：

- $1 \le n = \text{happiness.length} \le 2 \times 10^5$
- $1 \le \text{happiness}[i] \le 10^8$
- $1 \le k \le n$

> 💡 读题关键：从示例 1 可读出三条隐藏规则——① **被选中的当轮自己不扣**（3 全额入账）；② 扣减对**所有**未选中者一视同仁，与站位无关；③ 扣到 **0 封底**。于是「一个孩子贡献多少」只取决于两件事：初始值 $h$、以及它在入选前经历了多少轮。

## 2. 示例

**示例 1**

```text
输入：happiness = [1,2,3], k = 2
输出：4

解释：先选 3（贡献 3），剩余 [2,1] 各扣 1 → [1,0]；再选 1（贡献 1）。
总和 3 + 1 = 4。
```

**示例 2**

```text
输入：happiness = [1,1,1,1], k = 2
输出：1

解释：先选一个 1（贡献 1），剩余 [0,0,0]；再选 0（贡献 0）。总和 1。
```

**示例 3**

```text
输入：happiness = [2,3,4,5], k = 1
输出：5

解释：只选一轮，没有任何扣减发生，选最大值 5。
```

**示例 4**（自造，演示截断）

```text
输入：happiness = [2,3,4,5], k = 4
输出：9

解释：降序 [5,4,3,2]，贡献依次为 5, 3, 1, max(2−3,0)=0，总和 9。
若忘记 max(·,0) 截断，会算成 5+3+1−1 = 8（错误）。
```

## 3. 解题思路

### 3.1 暴力思路

两条朴素路线：

1. **枚举选谁 + 顺序**：本质是给 $k$ 个孩子分配互不相同的轮次，方案数为 $A(n,k) \ge \binom{n}{k}$，$n = 2\times 10^5$ 时天文数字，不可行；
2. **逐轮模拟**：每轮用最大堆取当前幸福值最大者，其余未选中者统一减 1——$O((n+k)\log n)$，能过但多余。由于扣减是**统一**的（0 处截断仍保持大小次序），「每轮取当前最大」恰好等价于「按初始值降序依次选前 $k$ 大」（§5 引理 2），模拟可以一步化简成公式。

### 3.2 核心观察：降序选，第 i 个入选者恰好被扣 i 点

![核心观察：降序后第i轮入选的孩子恰好已被扣i点](images/happiness_pick_order_concept.svg)

三步推理：

1. **贡献只看「值 × 轮次」**：初始值为 $h$ 的孩子若在第 $t$ 轮（从 0 计）被选中，它此前恰经历 $t$ 轮统一扣减（每轮 $\max(v-1,0)$），故贡献为 $\max(h - t,\, 0)$（§5 引理 1）。
2. **轮次 = 排位**：若按降序选，第 $i$ 个入选者前面恰有 $i$ 个人先走，故 $t = i$，公式一步到位：
   $$\text{ans} \;=\; \sum_{i=0}^{k-1} \max\!\big(h_{(i)} - i,\; 0\big), \qquad h_{(0)} \ge h_{(1)} \ge \dots$$
3. **为什么降序最优**：把「多挨 $d$ 轮扣减」看作一笔损失——值大的孩子损失至多 $d$，值小的孩子往往已被截断到 0、损失更少。所以**扣减名额应留给小值孩子，让大值孩子先离场**（交换论证见 §5 引理 2）。

> 💡 与同场 Q1「重新分装苹果」对照：Q1 是「降序取前 $k$ 个」，本题在它之上加了一层**位置惩罚**——第 $i$ 个入账要扣 $i$。沉淀模板：**「排序贪心 + 下标即代价」**。

### 3.3 算法流程

![算法流程：降序排序后逐轮累加贡献](images/happiness_selection_flow.svg)

```text
happiness ← 按幸福值降序排序
ans ← 0
for i ← 0 to k−1:
    ans ← ans + max(happiness[i] − i, 0)     # 第 i 轮选第 i 大，已被扣 i 点
return ans
```

排序后一趟累加，无需任何额外数据结构。

### 3.4 示例演算

![示例演算：逐轮模拟与公式核对](images/happiness_selection_walkthrough.svg)

- **示例 1**：降序 `[3,2,1]`，$k=2$：$\max(3-0,0) + \max(2-1,0) = 3 + 1 = \textbf{4}$，与逐轮模拟（选 3 → 剩 $[1,0]$ → 选 1）完全一致；
- **示例 2**：降序 `[1,1,1,1]`，$k=2$：$1 + \max(1-1,0) = 1 + 0 = \textbf{1}$——第二个入选者已被扣到 0，体现截断；
- **示例 4**：降序 `[5,4,3,2]`，$k=4$：$5 + 3 + 1 + 0 = \textbf{9}$，最后一项 $2-3=-1$ 被截断为 0。

## 4. 算法细节

1. **排序方向**：必须**降序**。C++ 用 `sort(happiness.rbegin(), happiness.rend())`，Python 用 `sort(reverse=True)`。
2. **下标即轮次**：`i` 从 0 计，第 `i` 个入选者被扣 `i` 点（不是 `i+1`），贡献 `max(happiness[i] - i, 0)`。
3. **溢出**：$\text{ans} \le \sum h \le 2\times10^5 \times 10^8 = 2\times10^{13}$，远超 `int32`（约 $2.1\times10^9$）；接口返回 `long long`，**中间累加器也必须是 `long long`**，这是本题最大的 WA 点。
4. **提前剪枝**：降序后一旦 `happiness[i] <= i`，由于 $h_{(j)} \le h_{(i)}$ 且 $j > i$，其后所有 $\max(h_{(j)}-j,0)$ 全为 0，可直接 `break`（正确性依赖降序单调性）。
5. **等价模拟视角**：最大堆逐轮「取最大 + 其余减 1」与本公式结果相同（统一扣减保序），但复杂度 $O((n+k)\log n)$ 劣于排序公式的 $O(n\log n + k)$——赛时若不确定公式，堆模拟是可靠的保底写法。

## 5. 正确性证明

**引理 1（贡献公式）**：任一方案中，初始值为 $h$、在第 $t$ 轮（从 0 计）被选中的孩子，对答案的贡献为 $\max(h-t,\,0)$。

**证明**：该孩子在第 $0 \sim t-1$ 轮均为「未选中」，每轮执行 $v \leftarrow \max(v-1, 0)$（为正才减、不减成负）。归纳即得第 $t$ 轮被选时的值为 $\max(h-t,\,0)$。∎

**引理 2（交换不变差）**：设 $g(x) = \max(x, 0)$。若 $h_a \ge h_b$ 而 $t_a > t_b$（值大的反而晚选），交换二者的轮次后总和不减，即
$$g(h_a - t_b) + g(h_b - t_a) \;\ge\; g(h_a - t_a) + g(h_b - t_b).$$

**证明**：令 $d = t_a - t_b > 0$，定义 $\Delta(c) = g(c - t_b) - g(c - t_a)$，即「值为 $c$ 的孩子多挨 $d$ 轮扣减的损失」。$g$ 分段线性、斜率从 0（负段）跳到 1（正段）单调不减，故长度为 $d$ 的滑动增量 $\Delta(c)$ 关于 $c$ 单调不减（$c$ 很大时两端都在正段，$\Delta = d$；$c$ 很小时两端都被截断，$\Delta = 0$；居中时 $\Delta \in (0, d)$）。由 $h_a \ge h_b$ 得 $\Delta(h_a) \ge \Delta(h_b)$，移项即得欲证不等式。∎

> 💡 直观读法：同样多挨 $d$ 刀，**大值孩子最多损失 $d$，小值孩子常已归零、损失更少**——所以应把「挨刀名额」挪给小值孩子，等价于让大值孩子先入选。

**引理 3（换人不减）**：若某方案选中了 $y$ 而漏掉 $x$，且 $h_x \ge h_y$，则把 $y$ 的轮次改配给 $x$（其余不动）总和不减。

**证明**：其余孩子贡献不变，变化量为 $g(h_x - t_y) - g(h_y - t_y)$；由 $h_x \ge h_y$ 及 $g$ 单调不减，其值 $\ge 0$。∎

**定理**：降序排序后 $\displaystyle\text{ans} = \sum_{i=0}^{k-1} \max\big(h_{(i)} - i,\, 0\big)$ 即为最大总和。

**证明**：任一方案等价于「选 $k$ 个孩子并给它们分配互不相同的轮次 $t \in \{0,1,\dots,k-1\}$」，其值由引理 1 完全刻画。取一个最优方案：反复应用引理 3，可将其换人成「降序前 $k$ 大」的集合且值不变差；再反复应用引理 2 调整次序，可设第 $i$ 大的孩子恰在第 $i$ 轮入选且值不变差。此时方案值恰为公式值，故 最优值 $\le$ 公式值；又该「降序依次选前 $k$ 大」是可行方案，故 公式值 $\le$ 最优值。两者相等。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \log n)$。
  - 降序排序是主导开销 $O(n \log n)$；
  - 累加至多 $k \le n$ 项，每项 $O(1)$。
- **空间复杂度**：$O(1)$ 额外空间（不计排序递归栈）。
  - 原地排序，只用 `ans` 与下标 `i` 两个标量，未用前缀和数组或堆。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    long long maximumHappinessSum(vector<int>& happiness, int k) {
        sort(happiness.rbegin(), happiness.rend());   // 降序：值大的先入选
        long long ans = 0;                            // 上界 2e13，必须 long long
        for (int i = 0; i < k; ++i) {
            if (happiness[i] <= i) break;             // 后续 max(h−i,0) 全为 0，提前收工
            ans += happiness[i] - i;                  // 第 i 轮选第 i 大，已被扣 i 点
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maximumHappinessSum(self, happiness: List[int], k: int) -> int:
        happiness.sort(reverse=True)                  # 降序：值大的先入选
        ans = 0
        for i, h in enumerate(happiness[:k]):
            if h <= i:                                # 后续贡献全为 0，提前收工
                break
            ans += h - i
        return ans
```

## 8. 边界情况与易错点

1. **C++ 溢出（本题第一大 WA 点）**：$k \le 2\times10^5$、$h \le 10^8$，答案上界 $2\times10^{13}$ 超 `int32`。接口返回类型已是 `long long`，但**中间累加若用 `int` 一样会炸**，累加器声明勿省。
2. **忘记 $\max(\cdot, 0)$ 截断**：示例 4 中 $2 - 3 = -1$ 应记 0；不截断会把答案算小（算出 8 而非 9）。
3. **排序方向写反**：升序选会让大值孩子多挨刀，如 `[1,2,3], k=2` 升序只得 $1 + 2 = 3$（正确 4）。
4. **误以为被选中当轮也扣**：示例 1 第 0 轮选 3 得 3 分而非 2 分——扣减只作用于「尚未被选中」的孩子。
5. **轮次从 0 还是从 1 计**：第 $i$ 轮（0 起）扣 $i$ 点；误写成扣 $i+1$ 点会把示例 1 算成 $2 + 0 = 2$。
6. **$k = n$ 全选也要排序**：全部入选时次序仍决定扣减的分配（示例 4 中降序 9、升序 8），别因「都要选」就跳过排序。
7. **提前 `break` 的合法性依赖降序**：只有排序后才能由 `happiness[i] <= i` 推出其后全为 0；若用堆模拟则无此剪枝。

**延伸思考**：

- **扣减推广为每轮 $d$ 点**：公式变为 $\sum_{i=0}^{k-1} \max(h_{(i)} - i \cdot d,\, 0)$，引理 2 中 $d$ 换成 $(t_a - t_b)\cdot d$，证明完全平行。
- **一般非降惩罚序列 $c_0 \le c_1 \le \cdots$**：第 $t$ 轮入选者被扣 $c_t$（如平方惩罚 $c_t = t^2$）。凸增量论证依然成立，最优解仍是「第 $i$ 大配第 $i$ 小的惩罚」——这正是排序不等式在凸函数代价下的推广形态。
- **「至多 $k$ 轮」变体**：若每轮可以选择不选（不选则不扣减），答案不变——第 $i$ 个入选者经历的扣减恰为它之前的入选次数 $i$，而多选一项贡献 $\max(h_{(i)}-i,0) \ge 0$ 不会更差，公式照旧。
