# LeetCode K 个不相交子数组的最大能量值 题解

## 1. 题目概述

- **标题 / 题号**：K 个不相交子数组的最大能量值（#3077，hard）
- **链接**：https://leetcode.cn/problems/maximum-strength-of-k-disjoint-subarrays/
- **来源**：LeetCode 第 388 场周赛 Q4
- **难度**：困难
- **标签**：数组、动态规划、状态机 DP、前缀和

**题意**：给定长度为 $n$ 的整数数组 `nums` 与一个正奇数 $k$。需要从数组中选出**恰好 $k$ 个互不相交的非空子数组**（不重叠，但允许相邻），将它们从左到右编号 $1 \sim k$，记第 $i$ 个子数组的元素和为 $\text{sum}[i]$，能量值定义为

$$\text{strength} = \text{sum}[1]\cdot k - \text{sum}[2]\cdot (k-1) + \text{sum}[3]\cdot (k-2) - \cdots + \text{sum}[k]\cdot 1 = \sum_{i=1}^{k} (-1)^{i+1}\cdot \text{sum}[i]\cdot (k-i+1)$$

求可以取得的最大能量值。选出的子数组**不需要**覆盖整个数组。

**约束**：

- $1 \le n \le 10^4$
- $-10^9 \le \text{nums}[i] \le 10^9$
- $1 \le k \le n$，且 $k$ 为奇数
- $1 \le n \cdot k \le 10^6$

> 💡 读题关键：三条信息决定解法形态——「**恰好** $k$ 个」要求 DP 精确计段数，不能少选；「**不相交**但**可相邻**」意味着允许两段紧挨着（示例 2 就是 5 个紧邻的单元素段）；「$n \cdot k \le 10^6$」是官方给的复杂度上限提示，暗示 $O(nk)$ 的解法就是预期目标。

## 2. 示例

**示例 1**

```text
输入：nums = [1,2,3,-1,2], k = 3
输出：22

解释：选 nums[0..2]、nums[3..3]、nums[4..4]，
能量值 = (1+2+3)×3 − (−1)×2 + 2×1 = 18 + 2 + 2 = 22。
```

**示例 2**

```text
输入：nums = [12,-2,-2,-2,-2], k = 5
输出：64

解释：n = k = 5，只能每个元素单独成段，
能量值 = 12×5 − (−2)×4 + (−2)×3 − (−2)×2 + (−2)×1 = 60 + 8 − 6 + 4 − 2 = 64。
```

**示例 3**

```text
输入：nums = [-1,-2,-3], k = 1
输出：-1

解释：全为负数也必须选满 1 段，最优是单选 −1（长度为 1 的段）。
```

## 3. 解题思路

### 3.1 暴力思路

一个方案由 $2k$ 个端点（每段的左右边界）决定，总方案数是组合数级别的，枚举不可行。顺着 DP 想，最自然的定义是：

$$dp[i][j] = \text{前 } i \text{ 个元素中已选出 } j \text{ 个完整子数组的最大能量值}$$

转移时需要枚举「最后一段」的区间 $[l, r]$（用前缀和 $O(1)$ 求段和再乘系数），整体 $O(n^2 k)$。代入上界 $n = 10^4$、$k = 100$（满足 $n \cdot k \le 10^6$ 的最坏组合）约为 $10^{10}$ 次运算，**超时**。

瓶颈在于：转移时把「一段」当成**整体**计算贡献，被迫枚举段边界。如果把「段和 × 系数」拆开摊到**每个元素**上，转移就可以逐元素 $O(1)$ 进行——这正是「最大子数组和」（Kadane）与「股票买卖 IV」一脉相承的套路。

### 3.2 核心观察：能量值可以摊到「元素 × 所属段系数」

第 $j$ 段的系数只与段序号 $j$ 有关：

$$\text{coef}(j) = (-1)^{j+1}\,(k-j+1)$$

- $k = 3$：系数依次为 $+3,\ -2,\ +1$；
- $k = 5$：系数依次为 $+5,\ -4,\ +3,\ -2,\ +1$（$k$ 为奇数 ⇒ 首段系数 $+k$、末段系数 $+1$，首尾皆为正）。

于是能量值可以逐元素改写：

$$\text{strength} = \sum_{\text{被选元素 } i} \text{nums}[i] \cdot \text{coef}\big(j(i)\big)$$

其中 $j(i)$ 是元素 $i$ 所属段的序号。

![核心观察：能量值摊到元素上](images/strength_coef_decompose.svg)

这个分解带来关键推论：**子数组从左往右逐个元素扩展时，每新增一个元素，只需 $O(1)$ 地累加 $\text{nums}[i] \times \text{coef}(j)$**，无需回头对整段求和——「枚举段边界」的内层循环被彻底消掉。

### 3.3 状态机 DP：f0[j] / f1[j]

在逐元素的视角下，任意时刻每个元素只有两种身份：**在某一段内**或**在段间空隙中**。据此设计两个状态（$i$ 维滚动掉之后）：

- $f_0[j]$：已处理的前缀中恰有 $j$ 个完整段，当前**处于段间空隙**（当前元素不选）；
- $f_1[j]$：第 $j$ 段进行中，且**恰好以当前处理的元素结尾**。

![状态机 DP 与转移](images/k_disjoint_dp_states.svg)

每来一个新元素 $x = \text{nums}[i]$，$j$ 从大到小更新：

$$f_0[j] \leftarrow \max\big(f_0[j],\; f_1[j]\big) \qquad \text{（跳过 } x\text{：上一元素在段内也没关系，段到此结束）}$$

$$f_1[j] \leftarrow \max\big(\underbrace{f_1[j]}_{\text{延伸}},\; \underbrace{f_0[j-1]}_{\text{隔隙新开}},\; \underbrace{f_1[j-1]}_{\text{紧贴新开}}\big) + x \cdot \text{coef}(j)$$

**初值**：$f_0[0] = 0$，其余全部 $-\infty$（恰好 $k$ 段的强约束靠它保证）。**答案**：$\max(f_0[k],\; f_1[k])$。

两个实现细节：

1. **$j$ 必须倒序枚举**：$f_1[j]$ 的转移要读 $j-1$ 层的**旧值**（本元素尚未对 $j-1$ 层生效），与 01 背包一维滚动同理。若正序枚举，会用刚被本元素更新过的 $f_1[j-1]$，等于允许一个元素同时开两段。
2. **同一 $j$ 内先更新 $f_0[j]$ 再更新 $f_1[j]$**：$f_0[j]$ 的转移需要读**旧的** $f_1[j]$（上一元素结尾的段），更新完 $f_1[j]$ 就覆盖了。

### 3.4 示例演算

![示例 1 的 DP 演算表](images/k_disjoint_dp_walkthrough.svg)

以示例 1（`nums = [1,2,3,-1,2]`，$k=3$）走查（每格为 $(f_0[j], f_1[j])$，"—" 为 $-\infty$）：

- $x=1$：新开第 1 段，$f_1[1] = 0 + 1\times 3 = 3$；
- $x=2$：延伸第 1 段 $f_1[1] = 3 + 6 = 9$；新开第 2 段 $f_1[2] = 3 + 2\times(-2) = -1$；
- $x=3$：第 1 段累计 $f_1[1] = 9 + 9 = 18$（此时第①段 $[1,2,3]$ 成型）；
- $x=-1$：紧贴新开第 2 段，$f_1[2] = 18 + (-1)\times(-2) = 20$；
- $x=2$：紧贴新开第 3 段，$f_1[3] = 20 + 2\times 1 = \mathbf{22}$。

答案 $= \max(f_0[3], f_1[3]) = \max(2, 22) = 22$，与官方一致。

## 4. 算法细节

1. **系数计算**：$\text{coef}(j) = (k-j+1) \times (j \text{ 为奇数} ? +1 : -1)$，循环内 $O(1)$ 求出，无需预处理数组。
2. **状态不变量**：$f_1[j]$ 仅在「第 $j$ 段恰以当前元素结尾」时有效；每步转移 $f_0[j] \leftarrow \max(f_0[j], f_1[j])$ 把历史最优吸收进 $f_0[j]$，使其始终代表「段可以结束在 $\le i$ 的任何位置」的前缀最大值——这正是暴力解法里「枚举段结束位置」的滚动等价物。
3. **更新顺序**：外层正序扫元素，内层 $j$ 从 $k$ 到 $1$ 倒序；同一 $j$ 先 $f_0$ 后 $f_1$（原因见 §3.3）。
4. **负无穷哨兵**：C++ 中取 `NEG = LLONG_MIN / 4` 而非 `LLONG_MIN`——后者参与 `+ x * coef` 会溢出回绕；配 `best != NEG` 守卫后，无效状态永不产生数值漂移。Python 用 `float('-inf')` 天然安全。
5. **紧贴新开不能漏**：$f_1[j-1] \to f_1[j]$ 允许第 $j$ 段紧接第 $j-1$ 段开始（不相交 = 不重叠，相邻合法），示例 2 的最优解正依赖这条转移。
6. **溢出估计**：$|\text{strength}| \le \sum_i |\text{nums}[i]| \cdot k \le 10^9 \cdot (n \cdot k) \le 10^{15}$，64 位整数安全；C++ 中 `x * coef` 前先把 `x` 转成 `long long`。

## 5. 正确性证明

**引理 1（贡献分解）**：设某合法方案的 $k$ 个子数组从左到右序号为 $1 \sim k$，被选元素 $i$ 属于第 $j(i)$ 段，则该方案的能量值等于 $\sum_{\text{被选 } i} \text{nums}[i]\cdot \text{coef}(j(i))$。

**证明**：由定义 $\text{sum}[j] = \sum_{i:\, j(i)=j} \text{nums}[i]$，代入能量值公式并交换求和顺序：

$$\sum_{j=1}^{k} \text{coef}(j) \sum_{i:\, j(i)=j} \text{nums}[i] = \sum_{\text{被选 } i} \text{nums}[i]\cdot \text{coef}(j(i)). \; \square$$

**引理 2（方案与路径一一对应）**：每个合法方案对应状态图中一条从初始状态（$f_0[0]$）出发、结束于 $f_0[k]$ 或 $f_1[k]$ 的转移路径，且路径上所有「新开/延伸」累计的增量之和恰为该方案的能量值；反之，每条这样的路径对应一个合法方案。

**证明**：**（方案 → 路径）** 从左到右逐元素决策：元素 $i$ 被选入第 $j(i)$ 段，则经过一次进入 $f_1[j(i)]$ 的转移（新开或延伸），增量 $\text{nums}[i]\cdot\text{coef}(j(i))$；元素 $i$ 未被选，则走 $f_0$ 的自环或 $f_1 \to f_0$ 的「结束」转移，增量为 $0$。由于各段互不重叠且按序排列，$j(i)$ 随 $i$ 不减且每段连续非空，状态序列合法；增量总和由引理 1 恰为能量值。**（路径 → 方案）** $f_1[j]$ 只能从 $f_1[j]$（延续当前段）、$f_0[j-1]$ 或 $f_1[j-1]$（新开一段）到达，因此同一段内元素下标连续非空、段序号 $j$ 每新开一段恰增 1，得到 $k$ 个从左到右互不重叠的非空子数组。$\square$

**引理 3（归纳不变量）**：处理完前 $i$ 个元素后，$f_0[j]$、$f_1[j]$ 分别是「前 $i$ 个元素中恰有 $j$ 个完整段且第 $i$ 个未选 / 第 $j$ 段恰以 $i$ 结尾」的所有方案能量值的最大值。

**证明**：对 $i$ 归纳。$i=0$ 时仅 $f_0[0]=0$ 有定义，成立。设 $i-1$ 时成立：以 $i$ 结尾的第 $j$ 段，其最后一个元素 $x$ 要么使该段自 $i-1$ **延伸**而来（前驱 $f_1[j]$），要么 $i$ 恰为段首（前驱 $f_0[j-1]$ 隔隙新开或 $f_1[j-1]$ 紧贴新开，两种前驱恰好覆盖「上一元素在段间」与「上一元素在第 $j-1$ 段末尾」的全部情形）；未选 $i$ 的方案前驱为 $f_0[j]$ 或 $f_1[j]$（段在更早处结束）。转移对全体前驱取 max，由归纳假设即得最优。倒序枚举 $j$ 与先 $f_0$ 后 $f_1$ 的顺序保证所有前驱均取自第 $i-1$ 层旧值，归纳论证无漏洞。$\square$

**定理**：算法返回恰好 $k$ 个不相交子数组能取得的最大能量值。

**证明**：由约束 $k \le n$，可行方案非空。由引理 2，每个方案对应一条路径且路径权即能量值；由引理 3，DP 在全体路径上取到最大权；答案取 $\max(f_0[k], f_1[k])$ 恰好枚举「第 $k$ 段结束于任意位置」与「恰以末元素结尾」两种完成形态，覆盖所有方案。$\blacksquare$

## 6. 复杂度分析

- **时间复杂度**：$O(nk)$。每个元素对每个 $j \in [1, k]$ 做 $O(1)$ 转移，由约束 $n \cdot k \le 10^6$，总量不超过 $10^6$。
- **空间复杂度**：$O(k)$。$i$ 维滚动掉，只保留两行长度 $k+1$ 的数组 $f_0, f_1$。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    long long maximumStrength(vector<int>& nums, int k) {
        const long long NEG = LLONG_MIN / 4;   // 安全的 -inf：参与 + x*coef 不溢出
        // f0[j]: 已有 j 个完整段，当前处于段间
        // f1[j]: 第 j 段进行中，恰以当前元素结尾
        vector<long long> f0(k + 1, NEG), f1(k + 1, NEG);
        f0[0] = 0;
        for (int x : nums) {
            for (int j = k; j >= 1; --j) {     // 倒序：读 j-1 层旧值
                long long coef = (long long)(k - j + 1) * ((j & 1) ? 1 : -1);
                f0[j] = max(f0[j], f1[j]);     // 跳过 x（先更新，读旧 f1[j]）
                long long best = max(f1[j], f0[j - 1]);   // 延伸 / 隔隙新开
                best = max(best, f1[j - 1]);              // 紧贴新开（相邻合法）
                if (best != NEG) f1[j] = best + (long long)x * coef;
            }
        }
        return max(f0[k], f1[k]);
    }
};
```

### Python

```python
class Solution:
    def maximumStrength(self, nums: List[int], k: int) -> int:
        NEG = float('-inf')
        # f0[j]: 已有 j 个完整段，当前处于段间
        # f1[j]: 第 j 段进行中，恰以当前元素结尾
        f0 = [0] + [NEG] * k
        f1 = [NEG] * (k + 1)
        for x in nums:
            for j in range(k, 0, -1):          # 倒序：读 j-1 层旧值
                coef = (k - j + 1) * (1 if j % 2 else -1)
                if f1[j] > f0[j]:
                    f0[j] = f1[j]              # 跳过 x（先更新，读旧 f1[j]）
                best = f1[j]                   # 延伸
                if f0[j - 1] > best:
                    best = f0[j - 1]           # 隔隙新开
                if f1[j - 1] > best:
                    best = f1[j - 1]           # 紧贴新开（相邻合法）
                if best != NEG:
                    f1[j] = best + x * coef
        return int(max(f0[k], f1[k]))
```

## 8. 边界情况与易错点

1. **恰好 $k$ 段，不能少选**：初始化除 $f_0[0]=0$ 外全为 $-\infty$，答案只从 $f_0[k]$ / $f_1[k]$ 取。若误把「所有 $j$ 的最大值」当答案（当成「至多 $k$ 段」），由于系数交替变号，结果会错。
2. **全负数组也必须选**（示例 3）：正因为初值是 $-\infty$ 而不是 $0$，被迫选满 $k$ 段的方案不会被丢弃。
3. **更新顺序错→错答**：正序枚举 $j$ 会读到本元素刚写入的 $f_1[j-1]$（相当于一个元素同时开两段）；同一 $j$ 内先更新 $f_1[j]$ 再更新 $f_0[j]$ 会把「段恰好结束于当前元素」重复延伸一步。
4. **漏掉「紧贴新开」转移**：$f_1[j-1] \to f_1[j]$ 必须保留，否则示例 2 这类首尾相接的最优解直接丢失。「不相交」只要求不重叠，**允许相邻**。
5. **哨兵溢出**：C++ 用 `LLONG_MIN` 作 $-\infty$ 再加负贡献会回绕成巨大正数；取 `LLONG_MIN / 4` 并配 `!= NEG` 守卫。`x * coef` 记得先转 `long long`（$10^9 \times 10^2$ 已超 int）。
6. **系数符号**：$\text{coef}(j) = (-1)^{j+1}(k-j+1)$，$j$ 从 1 起算；写成 $(-1)^j$ 会全局反号。
7. **$k$ 为奇数**：本题面限定，但上述解法**不依赖奇偶性**（对任意 $1 \le k \le n$ 都正确），无需特判。奇数只保证系数序列首（$+k$）尾（$+1$）为正。
8. **返回类型**：能量值可达 $10^{15}$ 量级，接口返回 `long long`，Python 天然无溢出。

**延伸思考**：

- **$k$ 为偶数时本 DP 还对吗？** 对——转移与奇偶无关，只是末段系数变为 $-1$，代码零修改。
- **前缀和视角与 $O(n\log n)$ 做法**：用前缀和 $P$ 改写 $\text{strength} = \sum_j \text{coef}(j)\,(P[r_j+1] - P[l_j])$，展开后等价于**在前缀和序列上选 $2k$ 个指标，按 $-k, +k, +(k-1), -(k-1), \ldots$ 的符号权做交错加减**。这类结构可以用反悔贪心（优先队列合并，类似「种树」的套路）优化到 $O(n \log n)$，远超周赛要求，感兴趣的读者可自行挑战。
- **变体「至多 $k$ 段」**：由于系数随段数 $j$ 变化（每个 $j$ 对应一整套系数），「多选一段」不再具有单调性，需对每个 $j' \le k$ 分别求恰好 $j'$ 段的答案再取 max，或寻找更精细的交换论证。
