# LeetCode 仅仅反转字母 题解

## 1. 题目概述

- **标题 / 题号**：仅仅反转字母（#917，easy）
- **链接**：https://leetcode.cn/problems/reverse-only-letters/
- **来源**：LeetCode 第 105 场周赛 Q1
- **难度**：简单
- **标签**：双指针、字符串

**题意**：给定字符串 `s`，把所有**英文字母**（小写或大写）的位置反转，**非英文字母保留在原有位置**，返回处理后的字符串。

**约束**：

- $1 \le s.length \le 100$
- `s` 仅由 ASCII 码在 $[33, 122]$ 之间的字符组成
- `s` 不含 `"` 与 `\`

## 2. 示例

**示例 1**

```text
输入：s = "ab-cd"
输出："dc-ba"
解释：字母序列 a,b,c,d 逆序为 d,c,b,a，依次填回四个字母位；连字符留在原位。
```

**示例 2**

```text
输入：s = "a-bC-dEf-ghIj"
输出："j-Ih-gfE-dCba"
解释：共 10 个字母、3 个连字符；连字符下标 1、4、7 不变。
```

**示例 3**

```text
输入：s = "Test1ng-Leet=code-Q!"
输出："Qedo1ct-eeLg=ntse-T!"
解释：大写字母也算字母；数字、=、-、! 全部不动。
```

**示例 4（自造，没有字母）**

```text
输入：s = "7_28]"
输出："7_28]"
解释：没有字母可反转，原样返回。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的做法是「抽取—反转—回填」：先把所有字母按顺序收集成一个列表，把它反转，再从左到右扫描原串，遇到字母位就依次填入反转后的字母。时间 $O(n)$、空间 $O(n)$，是正确的，但需要额外数组。

也可以做「两次遍历 + 栈」，本质上与上面的做法等价。

### 3.2 核心观察：双指针从两端向中间找字母交换

![双指针：跳过非字母，只交换字母](images/wc105_q1_two_pointer_concept.svg)

「字母整体反转」等价于：**第一个字母与最后一个字母交换，第二个与倒数第二个交换……** 而非字母不参与交换、也不能被移动。

于是用两个指针：

- $i$ 从左往右，**跳过**所有非字母；
- $j$ 从右往左，**跳过**所有非字母；
- 此时 $s[i]$ 与 $s[j]$ 都是字母，交换它们，然后 $i{+}{+}$、$j{-}{-}$；
- 直到 $i \ge j$ 停止。

由于指针只在字母处停留、交换也只发生在字母之间，非字母的位置天然保持不变，不需要额外空间。

### 3.3 算法流程

![算法流程：两个内层循环负责跳过非字母](images/wc105_q1_algorithm_flow.svg)

```text
1. i = 0, j = n - 1
2. while i < j:
3.     while i < j 且 s[i] 不是字母:  i++
4.     while i < j 且 s[j] 不是字母:  j--
5.     若 i < j:  swap(s[i], s[j]); i++; j--
6. 返回 s
```

第 5 行的 `if i < j` 不能省：内层两个 `while` 可能把指针推到相遇，此时中间只剩非字母或同一个字母，不该再交换。

### 3.4 示例演算

![示例：s = "a-bC-dEf-ghIj"](images/wc105_q1_walkthrough.svg)

以 `s = "ab-cd"` 为例：

| 轮次 | $i$ | $j$ | 中间串 | 操作 |
|------|-----|-----|--------|------|
| 初始 | 0 | 4 | `ab-cd` | — |
| 第 1 轮 | 0 | 4 | `ab-cd` | `a` 与 `d` 都是字母 → 交换，得 `db-ca` |
| 第 2 轮 | 1 | 3 | `db-ca` | `b` 是字母、`c` 是字母 → 交换，得 `dc-ba` |
| 结束 | 2 | 2 | `dc-ba` | $i \ge j$，停止 |

最终结果 `"dc-ba"`，连字符始终在第 2 位。

## 4. 算法细节

1. **字母判定**：C++ 用 `isalpha((unsigned char)s[i])`（务必转 `unsigned char`，否则遇到负值字符是未定义行为），Python 用 `s[i].isalpha()`。注意 Python 的 `isalpha()` 对 Unicode 字母也返回 `True`，本题输入限定 ASCII，所以安全；若担心可以用 `s[i].isascii() and s[i].isalpha()`。
2. **内层 `while` 的边界**：两个内层循环都要带 `i < j` 条件，否则指针可能越界。
3. **交换后的移动**：交换完成后必须同时推进两个指针，否则会死循环。
4. **字符串可修改性**：C++ 的 `string` 支持下标赋值；Python 字符串不可变，需要先转成 `list(s)`，最后 `"".join(...)`。
5. **只遍历一遍**：每个指针最多走 $n$ 步，总移动量 $O(n)$。

## 5. 正确性证明

**引理 1（跳跃不变式）**：每次进入第 2 行的循环体时，$[0, i)$ 与 $(j, n-1]$ 内的字符中，**所有字母都已在最终位置**，且这两个区间内非字母的位置与原串相同；中间 $[i, j]$ 尚未处理。

**证明**：初始 $i=0, j=n-1$ 时两个区间为空，成立。归纳地看一轮：

- 内层循环只移动指针、不改字符，所以「非字母位置不变」始终成立；
- 交换把 $s[i]$（字母）与 $s[j]$（字母）互换。由不变式，$s[i]$ 应当是「从右往左数第几个待填的字母位」，而 $s[j]$ 是「从左往右数第几个待填的字母位」，两者互换后，恰好各自填到了与原来相反的位置；
- 交换后 $i$ 右移、$j$ 左移，两个区间各扩大一格，且新纳入的字符都是正确字母。∎

**引理 2（非字母不动）**：整个过程中，任何非字母字符的**下标**都不改变。

**证明**：算法唯一的写操作是第 5 行的 `swap(s[i], s[j])`，而执行前已保证 $s[i]$ 与 $s[j]$ 都是字母（内层循环把非字母跳过了）。因此非字母从未被写入，位置自然不变。∎

**引理 3（字母顺序反转）**：设原串中字母依次为 $\ell_1, \ell_2, \dots, \ell_m$，则算法结束后，从左到右的第 $t$ 个字母位上填的是 $\ell_{m+1-t}$。

**证明**：由引理 1，第 $t$ 轮交换把最左侧待填的字母位与最右侧待填的字母位配对，即 $\ell_t$ 与 $\ell_{m+1-t}$ 互换。共进行 $\lfloor m/2 \rfloor$ 轮，覆盖所有字母位；中间若剩一个（$m$ 为奇数），它本来就位于正中间，无需移动。∎

**定理**：算法返回的字符串满足「非字母保持原位、字母位置反转」，且恰为原串的一个排列。

**证明**：由引理 2，非字母位置不变；由引理 3，字母按逆序填充；算法只做交换，故字符多重集不变。三条件合起来即为题面要求。∎

## 6. 复杂度分析

- **时间**：$O(n)$。$i$ 单调递增、$j$ 单调递减，合计最多移动 $2n$ 步；交换次数不超过 $n/2$，每次 $O(1)$。
- **空间**：$O(1)$（不含输入输出）。C++ 原地修改 `string`；Python 需要 $O(n)$ 的 `list` 副本，因为字符串不可变。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    string reverseOnlyLetters(string s) {
        int i = 0, j = (int)s.size() - 1;
        while (i < j) {
            while (i < j && !isalpha((unsigned char)s[i])) i++;
            while (i < j && !isalpha((unsigned char)s[j])) j--;
            if (i < j) {
                swap(s[i], s[j]);
                i++;
                j--;
            }
        }
        return s;
    }
};
```

### Python

```python
class Solution:
    def reverseOnlyLetters(self, s: str) -> str:
        chars = list(s)
        i, j = 0, len(chars) - 1
        while i < j:
            while i < j and not chars[i].isalpha():
                i += 1
            while i < j and not chars[j].isalpha():
                j -= 1
            if i < j:
                chars[i], chars[j] = chars[j], chars[i]
                i += 1
                j -= 1
        return "".join(chars)
```

## 8. 边界情况与易错点

1. **`isalpha` 的参数**：C++ 传入负的 `char` 是未定义行为，必须转 `unsigned char`；本题 ASCII 范围 $[33,122]$ 不会出现负值，但写成规范形式更稳。
2. **内层 `while` 缺少 `i < j`**：会导致指针越界（C++）或索引错误（Python）。
3. **交换后忘记推进指针**：`i`、`j` 不动会死循环。
4. **没有字母**：如 `"7_28]"`，两个内层循环直接把 $i$ 推到 $j$，不交换任何字符，原样返回。
5. **全部是字母**：退化为普通字符串反转，结果正确。
6. **大小写混合**：`isalpha` 同时接受大小写，不需要单独判断。
7. **Python 字符串不可变**：直接 `s[i] = ...` 会抛 `TypeError`，必须先转 `list`。
8. **非 ASCII 字符**：本题限定 ASCII；若输入含 Unicode 字母，`isalpha()` 会把它当字母处理，而 C++ 的 `isalpha` 在默认 locale 下不会——跨语言行为可能不一致。
