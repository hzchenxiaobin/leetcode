# LeetCode 环形子数组的最大和 题解

## 1. 题目概述

- **标题 / 题号**：环形子数组的最大和（#918，medium）
- **链接**：https://leetcode.cn/problems/maximum-sum-circular-subarray/
- **来源**：LeetCode 第 105 场周赛 Q2
- **难度**：中等
- **标签**：数组、分治、动态规划、队列、单调队列

**题意**：给定**环形**整数数组 `nums`（末尾与开头相连），求**非空**子数组的最大可能和。子数组在环上连续，且每个元素最多使用一次（长度不超过 $n$）。

**约束**：

- $1 \le n \le 3\times 10^4$
- $-3\times 10^4 \le nums[i] \le 3\times 10^4$

## 2. 示例

**示例 1**

```text
输入：nums = [1,-2,3,-2]
输出：3
解释：最大子数组就是 [3]。
```

**示例 2**

```text
输入：nums = [5,-3,5]
输出：10
解释：取环上的两个 5（跳过中间的 −3），和 10；它们在环上连续。
```

**示例 3**

```text
输入：nums = [3,-2,2,-3]
输出：3
解释：[3] 与 [3,-2,2] 都能得到 3。
```

**示例 4（自造，全负）**

```text
输入：nums = [-3,-2,-3]
输出：-2
解释：任何环形子数组都含负值，最大的是单个元素 −2。
```

## 3. 解题思路

### 3.1 暴力思路

枚举起点 $i$、长度 $len \in [1, n]$，用前缀和 $O(1)$ 求和，总复杂度 $O(n^2)$。$n = 3\times 10^4$ 时约 $4.5\times10^8$，超时。

瓶颈是「环形」带来的两倍枚举量。如果能把环「拉直」，就能用经典的线性做法（Kadane）解决。

### 3.2 核心观察：环形子数组只有两类

![环形数组只有两种情形](images/wc105_q2_two_cases_concept.svg)

设数组总和为 $total$。任何非空环形子数组必然属于以下两类之一：

1. **不绕回**：它就是 `nums` 的一个普通连续子数组，和不超过「最大子数组和」$best$；
2. **绕回**：形如 `nums[i..n-1] + nums[0..j]`（$0 \le j < i$）。它在环上连续，并且「剩下没被选中的部分」$nums[j+1..i-1]$ 是一段**非空**的普通连续子数组。于是

$$\text{绕回子数组的和} = total - \text{被排除段的元素和} \le total - worst,$$

其中 $worst$ 是**最小**非空连续子数组和。

所以候选答案只有两个：$best$ 与 $total - worst$，取较大者即可。

**唯一的坑：全负数组。** 当所有元素都是负数时，$worst$ 会等于「整个数组」（因为加上更多负数只会更小），此时补集为空，$total - worst = 0$ 对应**空子数组**，是非法的，直接取 $\max$ 会错答成 0。正确做法是：若 $best < 0$（说明全负），直接返回 $best$。

### 3.3 算法流程

![一趟扫描同时算四个量](images/wc105_q2_algorithm_flow.svg)

```text
1. curMax = curMin = 0，best = −∞，worst = +∞，total = 0
2. for x in nums:
3.     total += x
4.     curMax = max(x, curMax + x);  best  = max(best,  curMax)
5.     curMin = min(x, curMin + x);  worst = min(worst, curMin)
6. 若 best < 0: 返回 best
7. 返回 max(best, total − worst)
```

- `curMax = max(x, curMax + x)` 是 Kadane 的写法：要么从 $x$ 重新开始，要么接上前一段；
- $best$、$worst$ 分别跟踪「以当前位置结尾」的最大/最小子数组和的历史极值；
- 第 6 行的特判处理全负情形。

### 3.4 示例演算

![三个示例：四个量一算就出答案](images/wc105_q2_walkthrough.svg)

**示例 2：`nums = [5,-3,5]`**

| 步骤 | `x` | `curMax` | `best` | `curMin` | `worst` | `total` |
|------|-----|----------|--------|----------|---------|---------|
| 初始 | — | 0 | $-\infty$ | 0 | $+\infty$ | 0 |
| 1 | 5 | 5 | 5 | 5 | 5 | 5 |
| 2 | −3 | 2 | 5 | −3 | −3 | 2 |
| 3 | 5 | 7 | 7 | 2 | −3 | 7 |

$best = 7 \ge 0$，故答案 $\max(7,\ 7-(-3)) = \max(7, 10) = 10$。

**示例 4：`nums = [-3,-2,-3]`**

最终 $best = -2 < 0$，走特判分支，直接返回 $-2$；若不做特判会得到 $\max(-2,\ -8-(-8)) = 0$，错误。

## 4. 算法细节

1. **`curMax` / `curMin` 的重置语义**：`max(x, curMax + x)` 保证子数组至少含当前元素，天然处理「非空」约束。
2. **`best`、`worst` 的初值**：用 `INT_MIN` / `INT_MAX`（或 Python 的 `-inf` / `inf`），不要用 0，否则全负数组会得到错误的最大值。
3. **全负特判**：`best < 0` 即说明所有元素为负（若存在非负元素，$best \ge 0$）。也可以写成「若 `total == worst` 则返回 `best`」，但 `best < 0` 更直观。
4. **边遍历边更新**：四个量在同一趟里更新，空间 $O(1)$。
5. **环长上限 $n$**：题目限制子数组最多包含每个元素一次，因此不能取「绕两圈」的子数组；我们的分类只考虑长度 $\le n$，符合要求。
6. **`int` 范围**：$n \le 3\times10^4$、$|nums[i]| \le 3\times10^4$，总和最大 $9\times 10^8$，在 `int` 范围内（约 $2.1\times 10^9$），用 `int` 安全；保险起见可用 `long long`。

## 5. 正确性证明

记 $\mathcal{S}$ 为所有非空环形子数组的集合，$best = \max\{\text{sum}(A) : A \text{ 是普通非空连续子数组}\}$，$worst = \min\{\cdots\}$。

**引理 1（绕回段与其补集）**：若 $A \in \mathcal{S}$ 绕回且 $A$ 不是整个数组，则 $A$ 在数组中的补集 $B$ 是一段**非空**连续子数组，且 $\text{sum}(A) = total - \text{sum}(B)$。

**证明**：绕回意味着 $A = nums[i..n-1] \cup nums[0..j]$ 且 $j < i$。其补集是 $nums[j+1..i-1]$。若 $j + 1 = i$，则补集为空，此时 $A$ 覆盖了整个数组，与「不是整个数组」矛盾；故 $j + 1 \le i - 1$，补集非空。补集是一段连续子数组，且 $A$ 与 $B$ 无交、并集为全体下标，故 $\text{sum}(A) = total - \text{sum}(B)$。∎

**引理 1'（整段情形的处理）**：若 $A$ 是整个数组，则 $\text{sum}(A) = total \le best$。

**证明**：整个数组本身也是一个（普通）连续子数组，而 $best$ 是所有普通连续子数组和的最大值，故 $best \ge total = \text{sum}(A)$。∎

**引理 2（两类上界）**：对任意 $A \in \mathcal{S}$，若 $A$ 不绕回（含整段情形），则 $\text{sum}(A) \le best$；若 $A$ 绕回且不是整个数组，则 $\text{sum}(A) \le total - worst$。

**证明**：第一类由 $best$ 的定义直接得到（整段情形见引理 1'）。第二类由引理 1，$\text{sum}(A) = total - \text{sum}(B)$，而 $B$ 是非空连续子数组，$\text{sum}(B) \ge worst$，故 $\text{sum}(A) \le total - worst$。∎

**引理 3（当 $best \ge 0$ 时上界可达）**：存在 $A \in \mathcal{S}$ 使 $\text{sum}(A) = \max(best,\ total - worst)$。

**证明**：取到 $best$ 的普通子数组本身就是合法的环形子数组，故 $best$ 可达。若 $total - worst \ge best$，只需证明 $total - worst$ 也可达：取到 $worst$ 的最小子数组 $B$，若 $B$ 不是整个数组，则其补集 $A$ 是非空绕回子数组，$\text{sum}(A) = total - worst$ ✓；若 $B$ 是整个数组，则 $worst = total$，于是 $total - worst = 0 \le best$（因为 $best \ge 0$），此时 $\max(best, total - worst) = best$ 已经可达。∎

**引理 4（全负情形）**：若 $best < 0$（所有元素为负），则 $\max_{A \in \mathcal{S}}\text{sum}(A) = best$。

**证明**：任意 $A \in \mathcal{S}$ 非空且元素全负，故 $\text{sum}(A)$ 不超过其中任一单个元素，而单个元素是普通子数组，其最大值不超过 $best$。故 $\text{sum}(A) \le best$；又 $best$ 本身可达，故最大值为 $best$。∎

**定理**：算法返回值等于 $\max_{A \in \mathcal{S}} \text{sum}(A)$。

**证明**：若 $best < 0$，由引理 4 返回 $best$ 正确。若 $best \ge 0$：由引理 2，任何 $A$ 的和不超过 $\max(best, total-worst)$；由引理 3 该上界可达。故返回值为最大值。∎

## 6. 复杂度分析

- **时间**：$O(n)$。一趟扫描，每个元素做常数次比较与加法。
- **空间**：$O(1)$。只用了 `curMax`、`curMin`、`best`、`worst`、`total` 五个变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maxSubarraySumCircular(vector<int>& nums) {
        int curMax = 0, curMin = 0;
        int best = INT_MIN, worst = INT_MAX;
        int total = 0;
        for (int x : nums) {
            total += x;
            curMax = max(x, curMax + x);
            best = max(best, curMax);
            curMin = min(x, curMin + x);
            worst = min(worst, curMin);
        }
        if (best < 0) return best;              // 全负：不能取空子数组
        return max(best, total - worst);
    }
};
```

### Python

```python
class Solution:
    def maxSubarraySumCircular(self, nums: list[int]) -> int:
        cur_max = cur_min = 0
        best, worst = -10 ** 18, 10 ** 18
        total = 0
        for x in nums:
            total += x
            cur_max = max(x, cur_max + x)
            best = max(best, cur_max)
            cur_min = min(x, cur_min + x)
            worst = min(worst, cur_min)
        if best < 0:
            return best
        return max(best, total - worst)
```

## 8. 边界情况与易错点

1. **全负数组**：最经典的坑。示例 4 的正确答案是 $-2$，而 `max(best, total - worst)` 会算出 0。必须先判 `best < 0`。
2. **`best` / `worst` 初值用 0**：会让全负数组的 `best` 变成 0，与上一条叠加出错。用 $\pm\infty$（或 `INT_MIN` / `INT_MAX`）。
3. **`curMax` 与 `curMin` 混用**：它们是两条独立的 Kadane 链，不能共用一个变量。
4. **`n = 1`**：`best = nums[0]`；若 `nums[0] >= 0`，`total - worst = x - x = 0`，`max(x, 0) = x` ✓；若 $x < 0$ 走特判 ✓。
5. **空子数组**：题目要求非空，`total - worst` 在 `worst == total` 时对应空子数组，这正是需要特判的根源。
6. **绕两圈**：不允许。分类中只考虑长度 $\le n$ 的段，与题意一致。
7. **环形连续性**：绕回段的补集必须**非空**，不能允许「排除零个元素」。
