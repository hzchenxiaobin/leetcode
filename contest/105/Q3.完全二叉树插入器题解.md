# LeetCode 完全二叉树插入器 题解

## 1. 题目概述

- **标题 / 题号**：完全二叉树插入器（#919，medium）
- **链接**：https://leetcode.cn/problems/complete-binary-tree-inserter/
- **来源**：LeetCode 第 105 场周赛 Q3
- **难度**：中等
- **标签**：树、广度优先搜索、设计、二叉树

**题意**：设计 `CBTInserter` 类，维护一棵**完全二叉树**：

- 构造函数接收已有的完全二叉树根节点 `root`；
- `insert(val)` 插入一个值为 `val` 的新节点，**保持完全二叉树性质**，返回新节点的**父节点值**；
- `get_root()` 返回当前树的根节点。

**约束**：

- 初始节点数在 $[1, 1000]$
- $0 \le Node.val \le 5000$，$0 \le val \le 5000$
- 每个测试用例最多调用 `insert` 与 `get_root` 共 $10^4$ 次

## 2. 示例

```text
输入：
["CBTInserter", "insert", "insert", "get_root"]
[[[1, 2]], [3], [4], []]
输出：
[null, 1, 2, [1, 2, 3, 4]]

解释：
CBTInserter([1, 2]);      // 树：1 的左孩子是 2
insert(3);                // 返回 1，3 成为 1 的右孩子
insert(4);                // 返回 2，4 成为 2 的左孩子
get_root();               // 返回层序 [1, 2, 3, 4]
```

**补充示例（自造，初始只有根）**

```text
输入：
["CBTInserter", "insert", "get_root"]
[[[1]], [2], []]
输出：
[null, 1, [1, 2]]
```

## 3. 解题思路

### 3.1 暴力思路

每次 `insert` 都从根开始 BFS，找到「第一个缺孩子的节点」再挂上去。单次插入 $O(n)$，$10^4$ 次插入、$n$ 可达 $10^4$，最坏 $10^8$ 次访问。虽然不一定超时，但完全没必要——**插入位置是单调前进的**，找到一次之后下次只会更靠右。

另一个思路是「用数组模拟完全二叉树」，插入就是往数组尾部追加。这确实与完全二叉树的层序编号一致（见 §3.2），但题目给的是**节点指针**，`get_root` 需要返回树的根，所以仍要维护节点之间的指针关系。

### 3.2 核心观察：层序第一个「缺孩子」的节点就是插入位置

![完全二叉树的层序数组：父子关系 (i−1)//2](images/wc105_q3_complete_tree_concept.svg)

完全二叉树的层序编号有两个重要性质：

1. 编号从 0 开始，节点 $i$ 的左孩子是 $2i+1$、右孩子是 $2i+2$，父节点是 $\lfloor (i-1)/2 \rfloor$；
2. 节点**连续编号**，没有空洞。因此若当前有 $k$ 个节点（编号 $0 \sim k-1$），新节点必然落在编号 $k$ 上，其父节点编号是 $\lfloor (k-1)/2 \rfloor$。

而「第一个缺孩子的节点」正好也是 $\lfloor (k-1)/2 \rfloor$：编号小于它的节点都满足 $2i+2 \le k-1$（两个孩子都在），编号等于它的节点至少缺一个孩子（因为 $2i+2 \ge k$）。

于是算法非常简单：

- 构造时 BFS 一遍，把节点按层序存进数组 `nodes`；
- 维护 `head`，指向层序中第一个缺孩子的节点；
- 插入时：先 `while nodes[head] 有两个孩子 → head++`，然后把新节点挂到 `nodes[head]` 的左孩子（若空）或右孩子，新节点追加到 `nodes` 末尾，返回父节点值。

`head` 只增不减，全程推进次数不超过插入次数，均摊 $O(1)$。

### 3.3 算法流程

![维护一个「待补」指针](images/wc105_q3_algorithm_flow.svg)

```text
构造 CBTInserter(root):
1. BFS 层序遍历整棵树，按访问顺序存入 nodes
2. head = 0

insert(val):
3. while nodes[head] 的左右孩子都存在:  head++
4. parent = nodes[head]
5. 若 parent 无左孩子: parent.left = 新节点
6. 否则:               parent.right = 新节点
7. nodes 追加新节点
8. 返回 parent.val

get_root():
9. 返回 root
```

### 3.4 示例演算

![示例：root = [1,2]，依次插入 3、4](images/wc105_q3_walkthrough.svg)

初始树为 `[1,2]`（1 的左孩子是 2），`nodes = [1, 2]`、`head = 0`：

| 操作 | `head` | 父节点 | 挂到 | 返回 | 树（层序） |
|------|--------|--------|------|------|------------|
| 初始 | 0 | — | — | — | [1,2] |
| `insert(3)` | 0 | 1 | 右孩子 | 1 | [1,2,3] |
| `insert(4)` | 1 | 2 | 左孩子 | 2 | [1,2,3,4] |
| `get_root()` | — | — | — | 根 1 | [1,2,3,4] |

第二次插入时，节点 1 的两个孩子都齐了，`while` 循环把 `head` 推进到 1（节点 2），于是 4 挂到 2 的左孩子上。

## 4. 算法细节

1. **构造必须按层序 BFS**：`nodes` 的下标要与完全二叉树的层序编号一致，才能保证 `nodes[head]` 是「层序第一个缺孩子的节点」。用 DFS 前序存会破坏这个性质。
2. **`while` 而不是 `if`**：一次插入后，`head` 指向的节点可能已经补齐（右孩子刚被填上），下次插入要继续推进；也可能连续多个节点都齐了（例如批量插入后），所以必须用 `while` 一路推到真正缺孩子的位置。
3. **左孩子优先**：完全二叉树的填充顺序是「从左到右、逐层填满」，所以先补左孩子、再补右孩子。
4. **新节点要入队**：`nodes.push_back(node)` 让后续插入能找到它。
5. **`get_root` 返回原根**：插入不会改变根，直接返回保存的 `root` 指针。
6. **内存管理**：C++ 用 `new TreeNode(val)` 创建节点（LeetCode 环境自动回收），不要用局部变量取地址。
7. **构造复杂度**：BFS 访问每个节点一次，$O(n)$；插入均摊 $O(1)$。

## 5. 正确性证明

设完全二叉树的节点按层序编号为 $0, 1, \dots, k-1$（与 BFS 访问顺序一致），节点 $i$ 的左右孩子编号为 $2i+1$、$2i+2$。

**引理 1（层序编号的父子关系）**：对任意节点 $i < k$，其左孩子存在当且仅当 $2i+1 < k$，右孩子存在当且仅当 $2i+2 < k$；且 BFS 得到的 `nodes` 数组满足 `nodes[i]` 就是编号为 $i$ 的节点。

**证明**：完全二叉树的定义要求前 $k$ 个层序位置都被填满且不留空洞，故层序第 $j$ 个位置有节点当且仅当 $j < k$。BFS 按层、层内从左到右访问，恰好产生层序，因此 `nodes[i]` 就是编号 $i$ 的节点。再由完全二叉树的数组表示（$i$ 的左孩子是 $2i+1$）即得两个存在性判据。∎

**引理 2（插入位置唯一）**：若当前树有 $k$ 个节点，插入后仍要是完全二叉树，则新节点必须成为编号 $k$ 的节点，其父节点是编号 $p = \lfloor (k-1)/2 \rfloor$。

**证明**：完全二叉树的节点编号必须连续无空洞，已有 $0 \sim k-1$，新节点只能占据编号 $k$。由引理 1 的父子关系，编号 $k$ 的父节点是 $\lfloor (k-1)/2 \rfloor$（对 $k \ge 1$）。∎

**引理 3（`head` 与父节点一致）**：设当前有 $k$ 个节点，则「层序中第一个缺孩子的节点」编号为 $\lfloor (k-1)/2 \rfloor$，与引理 2 给出的父节点 $p$ 相同。

**证明**：节点 $i$ 有右孩子 $\iff 2i+2 \le k-1 \iff i \le (k-3)/2$。因此「至少缺一个孩子」等价于 $i > (k-3)/2$，即 $i \ge \lceil (k-2)/2 
ceil$。对整数 $k \ge 1$ 有 $\lceil (k-2)/2 
ceil = \lfloor (k-1)/2 
floor$，故第一个不完整的节点编号就是 $\lfloor (k-1)/2 \rfloor$。∎

**引理 4（`head` 指针的正确性）**：设插入前有 $k$ 个节点，则 `insert` 执行完 `while` 之后，`head` 指向编号 $\lfloor (k-1)/2 \rfloor$ 的节点，即层序中**第一个**缺孩子的节点。

**证明**：只需证明每次 `insert` 执行完 `while` 之后 `head` 恰为 $\lfloor (k-1)/2 \rfloor$（$k$ 为插入前的节点数）。

- 构造时 $k = 1$，$\lfloor (k-1)/2 \rfloor = 0$，而 `head` 初值正是 0，成立。
- 归纳假设上次插入后 `head` 不超过当时的 $\lfloor (k'-1)/2 \rfloor$，而该值随节点数单调不减，故本次插入前 `head \le \lfloor (k-1)/2 \rfloor`。
- 由引理 3，编号小于 $\lfloor (k-1)/2 \rfloor$ 的节点两个孩子都齐（`while` 会跳过），编号等于它的节点至少缺一个孩子（`while` 会停下）。`head` 从不超过该值的位置单调推进，故恰好停在该值上。

插入后节点数变为 $k+1$，`head` 可能指向已补齐的节点，但下一次插入的 `while` 会按同样的论证把它校正到新的 $\lfloor k/2 \rfloor$。∎

**引理 5（插入后仍是完全二叉树）**：按引理 2 的位置插入后，树是完全二叉树。

**证明**：插入后节点编号为 $0 \sim k$，连续无空洞；且新节点挂在 $\lfloor (k-1)/2 \rfloor$ 的左或右孩子位（先左后右），符合层序填充顺序。由完全二叉树的等价刻画（前 $k+1$ 个层序位置被填满、且每个非叶节点的孩子尽可能靠左），树仍完全。∎

**定理**：`insert` 返回的父节点值正确，且每次插入后树保持完全二叉树性质；`get_root` 返回当前根。

**证明**：由引理 4，`head` 指向的编号正是 $\lfloor (k-1)/2 \rfloor$，与引理 2 给出的父节点 $p$ 相同，故 `nodes[head]` 就是新节点的父节点，`insert` 返回 `nodes[head].val` 即父节点值，正确。由引理 5，插入后仍是完全二叉树。`get_root` 直接返回构造时保存的根指针，而插入不改变根，故正确。∎

## 6. 复杂度分析

- **构造**：时间 $O(n)$（BFS 每个节点一次），空间 $O(n)$（`nodes` 数组）。
- **`insert`**：均摊 $O(1)$。`while` 循环中 `head` 单调递增，整个生命周期内总推进次数不超过节点总数；单次最坏 $O(n)$（例如连续插入后一次性推进），但均摊到每次插入是 $O(1)$。追加与挂孩子是 $O(1)$。
- **`get_root`**：$O(1)$。
- **总体空间**：$O(n)$，其中 $n$ 为当前节点总数（最多为初始节点数 + 插入次数）。

## 7. 参考代码

### C++

```cpp
class CBTInserter {
public:
    CBTInserter(TreeNode* root) {
        this->root = root;
        queue<TreeNode*> q;
        q.push(root);
        while (!q.empty()) {
            TreeNode* node = q.front();
            q.pop();
            nodes.push_back(node);
            if (node->left) q.push(node->left);
            if (node->right) q.push(node->right);
        }
        head = 0;
    }

    int insert(int val) {
        TreeNode* node = new TreeNode(val);
        while (nodes[head]->left && nodes[head]->right) head++;
        TreeNode* parent = nodes[head];
        if (!parent->left) parent->left = node;
        else parent->right = node;
        nodes.push_back(node);
        return parent->val;
    }

    TreeNode* get_root() {
        return root;
    }

private:
    TreeNode* root;
    vector<TreeNode*> nodes;
    int head;
};
```

### Python

```python
from collections import deque
from typing import Optional


class CBTInserter:
    def __init__(self, root: Optional["TreeNode"]):
        self.root = root
        self.nodes = []
        q = deque([root])
        while q:
            node = q.popleft()
            self.nodes.append(node)
            if node.left:
                q.append(node.left)
            if node.right:
                q.append(node.right)
        self.head = 0

    def insert(self, val: int) -> int:
        node = TreeNode(val)
        while self.nodes[self.head].left and self.nodes[self.head].right:
            self.head += 1
        parent = self.nodes[self.head]
        if parent.left is None:
            parent.left = node
        else:
            parent.right = node
        self.nodes.append(node)
        return parent.val

    def get_root(self) -> Optional["TreeNode"]:
        return self.root
```

## 8. 边界情况与易错点

1. **`while` 写成 `if`**：一次插入后 `head` 可能已完整，下次插入若不继续推进，就会把节点挂到已有两个孩子的父节点上（覆盖原有孩子或产生非法结构）。
2. **构造用 DFS**：`nodes` 顺序不是层序，`head` 的语义就失效了。
3. **先右后左**：完全二叉树必须**先填左孩子**，顺序写反会破坏性质。
4. **忘记把新节点加入 `nodes`**：后续插入会找不到它，导致 `head` 推进后找不到正确位置甚至越界。
5. **初始只有根节点**：`nodes = [root]`，`head = 0`，第一次插入挂左孩子，返回根值，正确。
6. **C++ 节点生命周期**：必须 `new TreeNode(val)`，不能返回局部对象的地址。
7. **`get_root` 不能返回 `nodes[0]` 之外的东西**：`nodes[0]` 就是根，但直接保存 `root` 更清晰。
8. **返回的是父节点值而不是新节点值**：题目要求返回父节点值，容易顺手返回 `val`。
