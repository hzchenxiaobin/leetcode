# LeetCode 连接连续二进制数字 题解

## 1. 题目概述

- **标题 / 题号**：连接连续二进制数字（#1680，medium）
- **链接**：https://leetcode.cn/problems/concatenation-of-consecutive-binary-numbers/
- **来源**：LeetCode 第 218 场周赛 Q3
- **难度**：中等
- **标签**：位运算、数学、模拟

**题意**：给定整数 $n$，把 $1, 2, \dots, n$ 每个数的**二进制表示**依次首尾拼接成一个大二进制串，把该串视作二进制数，返回其十进制值对 $10^9 + 7$ 取余的结果。

**约束**：

- $1 \leq n \leq 10^5$

> 💡 赛时定位：本场分水岭在 Q4，这一题是纯「模拟 + 位运算」的工整题。唯一的坎是**能不能立刻把"拼接"翻译成数值操作** $\text{ans} \times 2^L + i$——写出这条转移式后，取模与溢出处理只是肌肉记忆。

## 3. 解题思路

### 3.1 暴力思路：把整串拼出来再求值

先估算规模：拼接串的总位数

$$B \;=\; \sum_{i=1}^{n} \big(\lfloor \log_2 i \rfloor + 1\big) \;\approx\; n \log_2 n$$

$n = 10^5$ 时 $B \approx 1.57 \times 10^6$ 位，展开成十进制约有 **47 万位数字**。

- **Python**：`''.join(bin(i)[2:] for i in ...)` 再 `int(s, 2)` 确实能过——2 的幂进制解析是线性的；
- **C++**：没有大数类型，只能手写大数：每拼一个 $i$ 都要把已有的全部位整体左移，累计约 $n \cdot B \approx 10^{11}$ 次位操作，完全不可行。

> 💡 转机藏在题面最后一句话：**答案只要求对 $10^9 + 7$ 取余后的值**。与其维护 150 万位的真值，不如全程只维护它在模 $M$ 下的**余数**——这正是正解的由来。

### 3.2 核心观察：拼接 = 左移腾位 + 加数

![核心观察：拼接 i 即左移腾出 L 个低位再放 i，数值上等价于 ans×2^L+i](images/wc218_q3_shift_append_concept.svg)

设当前已拼好的串数值为 $\text{ans}$，现在要拼接 $i$，其**二进制位数**为 $L$。在串尾追加 $L$ 位，等价于把已有内容整体左移 $L$ 位（数值上 $\times 2^L$），再把 $i$ 放进空出来的低 $L$ 位：

$$\text{ans} \;\leftarrow\; \text{ans} \times 2^{L} + i$$

拿示例 2 收尾的一步验证：$6 \times 2^2 + 3 = 27$，即 "110" 拼上 "11" 得 "11011" ✓。

这个观察带来两个直接副产品：

- **串不必真的存在**：转移式只对数值做运算，一步 $O(1)$；
- **取模与转移相容**：乘法、加法在模 $M$ 下封闭，每步随手 $\bmod M$，150 万位的串从头到尾无需物化。

### 3.3 算法流程：位数 L 只在 2 的幂处 +1

![位数台阶与算法流程：L 只在 i 为 2 的幂时加一，每轮 O(1) 维护余数](images/wc218_q3_bitlen_jump_flow.svg)

转移式里的 $L = \lfloor \log_2 i \rfloor + 1$ 怎么来？逐轮重算当然可行（见 §7 方法二），但有个更帅的**台阶不变式**：

$$L_i = \begin{cases} L_{i-1} + 1, & i \text{ 是 } 2 \text{ 的幂} \\ L_{i-1}, & \text{否则} \end{cases}$$

因为 $\lfloor \log_2 i \rfloor$ 只在 $i$ 跨过某个 $2^k$ 时才 $+1$。判 2 的幂一行位运算搞定：`(i & (i - 1)) == 0`——$2^k$ 的二进制只有单个 1，减 1 借位后恰好抹掉它。

> ⚠️ **C/C++ 优先级坑**：`&` 的优先级低于 `==`，必须写成 `(i & (i-1)) == 0`；少写括号的 `i & (i-1) == 0` 实际是 `i & ((i-1) == 0)`。

流程：初始化 `ans = 0, L = 0`；对每个 $i$ 先判幂决定是否 `L++`，再执行 `ans = ((ans << L) % MOD + i) % MOD`；循环结束返回 `ans`。

![示例演算：n=5 逐步走查转移式，示例 2 的 n=3 停在第三行 ans=27](images/wc218_q3_walkthrough.svg)

取自拟的 $n = 5$（示例 4）逐轮走查：

| i | bin(i) | L | ans × 2^L + i | 新 ans | 串表示 |
|---|--------|---|---------------|--------|--------|
| 1 | 1 | 1 ★ | 0×2 + 1 | 1 | 1 |
| 2 | 10 | 2 ★ | 1×4 + 2 | 6 | 110 |
| 3 | 11 | 2 | 6×4 + 3 | 27 | 11011 |
| 4 | 100 | 3 ★ | 27×8 + 4 | 220 | 11011100 |
| 5 | 101 | 3 | 220×8 + 5 | 1765 | 11011100101 |

★ 行即 $L$ 跳变行（$i = 1, 2, 4$ 是 2 的幂）。第 3 行恰好是示例 2 的终点：$\text{ans} = 27$ ✓；第 5 行后串为 "11011100101" = 1765，与逐位直接拼接的结果一致 ✓。

## 4. 算法细节

1. **取模次序**：`((ans << L) % MOD + i) % MOD`——移位后先取模压回 $< M$，加完 $i$（$\leq 10^5$）再取模归约。两个 `%` 各司其职：前者守住下一轮移位的溢出预算，后者维护不变式 $\text{ans} < M$。中间量其实一次取模也够（见 §8 第 3 条），双取模是更稳的写法。
2. **溢出预算（C++）**：$M < 2^{30}$，$n \leq 10^5$ 时 $L \leq 17$，故 `ans << L` 的值 $< 2^{30} \cdot 2^{17} = 2^{47} \approx 1.4 \times 10^{14}$——`long long` 安全区，`int` 必溢出。
3. **判 2 的幂**：`(i & (i - 1)) == 0`（优先级坑见 §3.3）；增量变量初值 `len = 0`，$i = 1 = 2^0$ 会在首轮自增为 1，正好接住边界。
4. **不维护增量也行**：C++ 用 `32 - __builtin_clz(i)`（或 C++20 的 `std::bit_width(i)`），Python 用 `i.bit_length()`，每轮 $O(1)$ 重算位数，见 §7 方法二。增量维护省一次函数调用，更重要的是把「台阶不变式」写进了代码。
5. **$i$ 不必取模**：$i \leq 10^5 \ll M$，直接加即可。

## 5. 正确性证明

**引理 1（拼接恒等式）**：设串 $s$ 的数值为 $A$，$i$ 的二进制串 $t$ 长 $L$ 位，则 $s \Vert t$（$s$ 后拼接 $t$）的数值为 $A \cdot 2^L + i$。

**证明**：按位记数法，在 $s$ 末尾追加 $L$ 位，就是把 $s$ 每一位的权重 $\times 2^L$；又 $i < 2^L$，$t$ 恰好落在空出的低 $L$ 位上，与 $s$ 的位不重叠、不产生跨段进位。∎

**引理 2（位数跳变）**：记 $L_i = \lfloor \log_2 i \rfloor + 1$。对 $i \geq 2$，$L_i = L_{i-1} + 1$ 当且仅当 $i$ 是 2 的幂；否则 $L_i = L_{i-1}$。

**证明**：$L_i > L_{i-1}$ 当且仅当 $\lfloor \log_2 i \rfloor > \lfloor \log_2 (i-1) \rfloor$，即存在整数 $k$ 使 $i - 1 < 2^k \leq i$；相邻整数之间这只能是 $i = 2^k$。∎

**引理 3（模同态）**：若 $x \equiv x' \pmod M$，则对任意 $y$ 有 $x \cdot 2^L + y \equiv x' \cdot 2^L + y \pmod M$。

**证明**：模 $M$ 的剩余类环对加法、乘法封闭（$\mathbb{Z} \to \mathbb{Z}/M\mathbb{Z}$ 是环同态）。∎

**定理**：循环结束后，$\text{ans} \equiv$ 串 "1"∥"10"∥…∥bin(n) 的数值 $\pmod M$，且 $0 \leq \text{ans} < M$。

**证明**：对 $i$ 归纳，不变式为「处理完 $i$ 轮后 $\text{ans}$ 与前缀串 "1"∥…∥bin(i) 的数值模 $M$ 同余，且 $\text{ans} < M$」。$i = 0$：空串值为 $0$，`ans = 0` 成立。设第 $i - 1$ 轮后成立，则第 $i$ 轮

$$\text{ans}' = (\text{ans} \times 2^{L_i} + i) \bmod M \;\equiv\; A_{i-1} \cdot 2^{L_i} + i \pmod M$$

其中 $A_{i-1}$ 是前缀串数值——由引理 1 该式恰为拼接 $i$ 后新串的数值；由引理 3 取模不破坏同余；由引理 2 代码中增量维护的 $L_i$ 就是 $i$ 的二进制位数。取模运算保证 $\text{ans}' < M$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$——每轮一次判幂、一次移位、一次加法、两次取模，全部 $O(1)$。
- **空间复杂度**：$O(1)$——只维护 `ans` 与 `L` 两个整数。
- **对比暴力**：朴素拼接需要 $O(B) = O(n \log n)$ 的串空间；C++ 手写大数更要做 $O(nB)$ 级别的位搬运。正解把"串"压成一个 $< 2^{30}$ 的整数。

> 💡 $n = 10^5$ 时 $O(n)$ 稳稳通过，本题比拼的是正确性与手速——方法一、方法二复杂度相同，赛时选顺手的写。

## 7. 参考代码

### 方法一：移位拼接 + 增量维护位数

### C++

```cpp
class Solution {
  public:
    int concatenatedBinary(int n) {
        const long long MOD = 1'000'000'007;
        long long ans = 0;
        int len = 0;                          // 当前二进制位数 L
        for (int i = 1; i <= n; i++) {
            if ((i & (i - 1)) == 0) len++;    // 跨过 2 的幂：台阶 +1
            ans = ((ans << len) % MOD + i) % MOD;
        }
        return (int)ans;
    }
};
```

### Python

```python
class Solution:
    def concatenatedBinary(self, n: int) -> int:
        MOD = 10**9 + 7
        ans, length = 0, 0
        for i in range(1, n + 1):
            if i & (i - 1) == 0:              # 跨过 2 的幂：台阶 +1
                length += 1
            ans = ((ans << length) + i) % MOD
        return ans
```

### 方法二：每轮直接求位数（不维护增量）

### C++

```cpp
class Solution {
  public:
    int concatenatedBinary(int n) {
        const long long MOD = 1'000'000'007;
        long long ans = 0;
        for (int i = 1; i <= n; i++) {
            int len = 32 - __builtin_clz(i);  // i ≥ 1 才能安全调用
            ans = ((ans << len) % MOD + i) % MOD;
        }
        return (int)ans;
    }
};
```

### Python

```python
class Solution:
    def concatenatedBinary(self, n: int) -> int:
        MOD = 10**9 + 7
        ans = 0
        for i in range(1, n + 1):
            ans = ((ans << i.bit_length()) + i) % MOD
        return ans
```

## 8. 边界情况与易错点

1. **`&` 与 `==` 的优先级**：`i & (i - 1) == 0` 实际解析为 `i & ((i-1) == 0)`，含义完全不同且不报编译错误，必须写成 `(i & (i - 1)) == 0`。
2. **移位溢出**：`ans << len` 最大约 $2^{47}$，C++ 必须 `long long`（用 `int` 存移位结果直接溢出）；Python 天然大整数无此忧。
3. **取模姿势**：`((ans << L) + i) % MOD` 一次取模也正确（本题中间量 $< 2^{47}$ 远低于 $2^{63}$）；但**完全不取模**必然出错——`ans` 按位串长度指数增长，几轮之后爆掉 `long long`，且模同余关系根本不成立。
4. **`len` 初值是 0 不是 1**：$i = 1 = 2^0$ 在首轮触发 `len++` 变为 1；若初值给 1，"1" 会被左移两位，答案错 4 倍。
5. **`__builtin_clz(0)` 是未定义行为**：方法二要求 $i \geq 1$，本题循环天然满足；把这行移植到数组/任意值场景时要当心 0。
6. **$n = 1$ 无需特判**：循环恰执行一次，返回 1。
7. **无进位是转移式成立的隐含前提**：$i < 2^L$ 恒成立（$i$ 的最高位恰是第 $L$ 位），低 $L$ 位与 `ans` 的位不重叠——加法等价于按位或。理解这一点，转移式可以无推导地"看出来"。
8. **Python 朴素法的边界**：`int(s, 2)` 不受 4300 位转换上限约束（2 的幂进制解析线性，实测 150 万位字符串可解析）；但 `str(大数)` 十进制输出会触发上限抛异常，想打印 47 万位的完整答案得 `sys.set_int_max_str_digits`——侧面印证"只返回余数"的题设才是正道。

**延伸思考**：

- **$n$ 大到 $10^{18}$ 怎么办**：$O(n)$ 失效，但按位数分块可加速——位数同为 $L$ 的整块 $[2^{L-1}, 2^L)$ 的拼接是「等差 × 等比」级数，有封闭式（配合快速幂与模逆元），整块 $O(\log)$ 求值，不足整块的残余单独扫，总复杂度 $O(\log^2 n)$。
- **反向问题**：给定完整拼接串（不给余数）能否恢复 $n$？串长随 $n$ 严格递增，二分 + 复用本题的余数转移即可定位。
- **进制推广**：改为拼接 $n$ 进制表示时转移式变为 $\text{ans} \cdot n^{d(i)} + i$（$d(i)$ 为 $i$ 的 $n$ 进制位数）；$n$ 为 2 的幂时恰好退化成移位形式——本题是这个家族里最工整的特例。
