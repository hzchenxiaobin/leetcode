# LeetCode K和数对的最大数目 题解

## 1. 题目概述

- **标题 / 题号**：K和数对的最大数目（#1679，medium）
- **链接**：https://leetcode.cn/problems/max-number-of-k-sum-pairs/
- **来源**：LeetCode 第 218 场周赛 Q2
- **难度**：中等
- **标签**：数组、哈希表、排序、双指针

**题意**：给定整数数组 `nums` 与整数 `k`。每一步操作从数组中选出**和为 `k` 的两个整数**并移出数组，返回最多能执行的**操作次数**。

**约束**：

- $1 \leq \text{nums.length} \leq 10^5$
- $1 \leq \text{nums}[i] \leq 10^9$
- $1 \leq k \leq 10^9$

> 💡 这是赛时几分钟级别的套路题——「两数之和」的**计数版**。比拼的是谁能最快意识到**配对只与「值」有关、与位置和顺序无关**，从而把"反复搜索-移除"降维成"一次频次统计"。

## 2. 示例

**示例 1**

```text
输入：nums = [1,2,3,4], k = 5
输出：2
解释：移出 1 和 4 后 nums = [2,3]；移出 2 和 3 后 nums = []。
共 2 次操作。
```

**示例 2**

```text
输入：nums = [3,1,3,4,3], k = 6
输出：1
解释：移出前两个 3 后 nums = [1,4,3]，剩下 1、4、3 中任意两数之和都不为 6。
共 1 次操作。
```

**示例 3**（自拟：自配对 + 落单）

```text
输入：nums = [5,5,5], k = 10
输出：1
解释：5 + 5 = 10 可移出一对，剩下的一个 5 落单。
奇数个 k/2 只能凑出 3 // 2 = 1 对。
```

## 3. 解题思路

### 3.1 暴力思路：每轮全量搜一对

模拟题面：每轮枚举所有 $(i, j)$，找到 $\text{nums}[i] + \text{nums}[j] = k$ 就移除这两个元素，找不到则停止。每轮搜索 $O(n^2)$，最多 $\lfloor n/2 \rfloor$ 轮，总时间 $O(n^3)$；即便每轮用哈希把找一对降到 $O(n)$，总计也是 $O(n^2)$。对 $n = 10^5$ 都不可行。

低效的根源：每一轮都在"从零开始找一对"，没有利用**全局信息**——一旦知道每个值出现了多少次，所有能配的对数可以直接**算**出来，根本不需要一轮轮地搜。

### 3.2 核心观察：配对按「值类」消耗，频次表一次算清

![核心观察：值 v 只与补数 k−v 相关，频次表直接算出配对总数](images/wc218_q2_freq_pairing_concept.svg)

**关键观察**：$a + b = k$ 等价于 $b = k - a$。值为 $v$ 的元素**只可能**与值为 $k - v$ 的元素配对——它属于唯一的**值类对** $\{v,\ k-v\}$，不同值类之间互不争抢。于是答案可以按值类独立结算：

$$
\text{ans} \;=\; \sum_{v \,<\, k-v} \min\big(\text{freq}[v],\ \text{freq}[k-v]\big) \;+\; \left\lfloor \frac{\text{freq}[k/2]}{2} \right\rfloor
$$

- **跨类配对** $\{v,\ k-v\}$（$v \neq k-v$）：两频次取较小者即为能凑出的对数，补数缺失则贡献 $0$；
- **自配对** $\{k/2,\ k/2\}$（$k$ 为偶数时存在）：自己和自己配，$\text{freq}[k/2] \mathbin{//} 2$ 对，多出的一个落单（示例 3）。

> ⚠️ **只枚举 $v < k-v$ 一侧**：$\{v,\ k-v\}$ 与 $\{k-v,\ v\}$ 是同一个值类对，两侧都算会重复计数。

### 3.3 算法流程：排序 + 双指针

![排序+双指针：和太小左移、太大右移、命中双移，每步丢弃都安全](images/wc218_q2_two_pointer_flow.svg)

排序后左右指针从两端向中间收拢，按 $\text{sum}$ 与 $k$ 的大小三分支移动：

1. $\text{sum} < k$：左端太小——它连当前**最大值**都配不够，窗口内无搭档，放心丢弃，`left++`；
2. $\text{sum} > k$：右端太大——它连当前**最小值**都配超，窗口内无搭档，放心丢弃，`right--`；
3. $\text{sum} = k$：记一对，`ans++`，两端同时收进，`left++` 且 `right--`。

循环直到 $\text{left} \geq \text{right}$。排序带来的单调性保证每个元素至多被"看"一次；且 `left < right` 天然保证配对取自**两个不同位置**——哈希法需要的 $v = k/2$ 自配对特判在这里自动消失。

### 3.4 示例演算

![示例演算：排序后 [1,3,3,3,4]，k=6，三种分支各走一遍](images/wc218_q2_walkthrough.svg)

以示例 2 为例，排序后 $\text{nums} = [1,3,3,3,4]$，$k = 6$：

| 步骤 | left | right | nums[left] | nums[right] | sum | 动作 | ans |
|------|------|-------|------------|-------------|-----|------|-----|
| 1 | 0 | 4 | 1 | 4 | 5 | $< k$ → left++ | 0 |
| 2 | 1 | 4 | 3 | 4 | 7 | $> k$ → right−− | 0 |
| 3 | 1 | 3 | 3 | 3 | 6 | $= k$ ✓ → ans++，双移 | 1 |
| 4 | 2 | 2 | — | — | — | left ≥ right，结束 | 1 |

三个分支恰好各走一遍：$1$ 太小被丢、$4$ 太大被丢、剩下三个 $3$ 中取走两个配成 $3+3=6$，最后一个 $3$ 落单。最终 $\text{ans} = 1$。

对照哈希法：$\text{freq} = \{1{:}1,\ 3{:}3,\ 4{:}1\}$，$\{1,5\}$ 与 $\{4,2\}$ 的补数缺失各贡献 $0$，$\{3,3\}$ 贡献 $3 \mathbin{//} 2 = 1$，结果一致。

## 4. 算法细节

1. **哈希法三分支**：遍历频次表的每个键 $v$，令 $\text{comp} = k - v$：
   - $\text{comp} < v$：跳过（该值类已由较小一侧统计过）；
   - $\text{comp} = v$：自配对，贡献 $\text{freq}[v] \mathbin{//} 2$；
   - $\text{comp} > v$：跨类配对，贡献 $\min(\text{freq}[v], \text{freq}[\text{comp}])$（$\text{comp}$ 不在表中则贡献 $0$）。

   $k$ 为奇数时不存在整数 $v$ 使 $2v = k$，自配对分支自动不触发，**无需特判 $k$ 的奇偶**。
2. **`operator[]` 的坑**：C++ 遍历 `unordered_map` 期间用 `freq[comp]` 查询，`comp` 缺失时会**插入 0**，可能触发 rehash 使当前迭代器失效。查存在性用 `find`/`count`。
3. **单趟"边查边减"变体**：遍历每个元素 `x`，若表中 `k-x` 计数为正就配对（计数减一、`ans++`），否则把 `x` 计入表中。任何一对 $(a, b)$ 中**后出现的总能查到先出现的**，一遍扫完与"先建表再统计"等价，且自配对、重复计数两个坑一并消失。
4. **双指针的 `sum`**：$\text{nums}[i] \leq 10^9$，两端相加最大 $2 \times 10^9$，勉强低于 $\text{INT32\_MAX} \approx 2.147 \times 10^9$——本题上界侥幸安全，赛时建议直接 `long long` 兜底（见 §8）。
5. **原地排序**：双指针法直接 `sort(nums)` 修改原数组即可，无需拷贝。

## 5. 正确性证明

**引理 1（配对视角）**：恰好能执行 $t$ 次操作 $\Leftrightarrow$ 多重集 $\{\text{nums}[i]\}$ 可以划分出 $t$ 个互不相交、每个和为 $k$ 的二元组。

**证明**：（⇐）取该划分，按任意顺序每组执行一次操作——组间互不相交保证每步取用时两个元素仍在数组中。（⇒）$t$ 次操作依次移走的二元组即构成这样一个划分。∎

**引理 2（值类上界）**：任何划分中，跨类组 $\{v,\ k-v\}$（$v \neq k-v$）的数目 $\leq \min(\text{freq}[v], \text{freq}[k-v])$；自配组 $\{k/2,\ k/2\}$ 的数目 $\leq \big\lfloor \text{freq}[k/2] / 2 \big\rfloor$。

**证明**：每个跨类组恰消耗一个值 $v$ 与一个值 $k-v$ 的元素，两个方向的频次分别给出两个上界；每个自配组消耗两个 $k/2$ 元素，故组数两倍不超过 $\text{freq}[k/2]$。∎

**引理 3（上界可达）**：对每个 $v < k-v$ 配 $\min(\text{freq}[v], \text{freq}[k-v])$ 组、对 $k/2$ 配 $\big\lfloor \text{freq}[k/2]/2 \big\rfloor$ 组，是一个合法划分。

**证明**：值 $v$（$v \neq k/2$）只出现在值类对 $\{v, k-v\}$ 中，$k/2$ 只出现在自配类中——各值类消耗的元素互不重叠，逐类取满引理 2 的上界均不超过各自频次。∎

**定理 1**：最大操作数 $= \sum_{v < k-v} \min(\text{freq}[v], \text{freq}[k-v]) + \big\lfloor \text{freq}[k/2]/2 \big\rfloor$（$k$ 为奇数时末项为 $0$）。

**证明**：由引理 1，答案即最大划分的组数；由引理 2 它不超过右式，由引理 3 右式可以取到。∎

**引理 4（丢弃安全性）**：排序后，若 $\text{nums}[L] + \text{nums}[R] < k$，则窗口 $[L, R]$ 内**任何**划分都不含 $L$；若 $> k$，则都不含 $R$。

**证明**：窗口内任一元素 $x \leq \text{nums}[R]$，故 $\text{nums}[L] + x \leq \text{nums}[L] + \text{nums}[R] < k$，即 $L$ 在窗口内无搭档，任何含 $L$ 的合法组都不存在，划分 $[L, R]$ 与划分 $[L+1, R]$ 一一对应。对称证 $> k$ 情形。∎

**引理 5（命中可配）**：若 $\text{nums}[L] + \text{nums}[R] = k$，则存在窗口 $[L, R]$ 的最优划分把 $L$ 与 $R$ 配成一组。

**证明**：任取一个最优划分 $P$，分类讨论：

- $L, R$ 同组，即得；
- $L$ 配 $y$ 且 $R$ 配 $z$：$y + z = (k - \text{nums}[L]) + (k - \text{nums}[R]) = 2k - k = k$，把两组换为 $\{L, R\}$ 与 $\{y, z\}$，组数不变且仍合法；
- $L$ 配 $y$ 而 $R$ 落单：此时 $y = k - \text{nums}[L] = \text{nums}[R]$（值相同），换成 $\{L, R\}$、让 $y$ 落单即可；$R$ 配 $z$ 而 $L$ 落单的情形对称；
- $L, R$ 均落单：补入 $\{L, R\}$ 使组数加一，与 $P$ 最优矛盾，不会发生。∎

**定理 2**：双指针算法返回最大操作数。

**证明**：记 $OPT(L, R)$ 为窗口 $[L, R]$ 能划出的最多组数。由引理 4，$\text{sum} < k$ 与 $\text{sum} > k$ 的分支分别有 $OPT(L, R) = OPT(L{+}1, R)$ 与 $OPT(L, R) = OPT(L, R{-}1)$；由引理 5，$\text{sum} = k$ 的分支有 $OPT(L, R) = 1 + OPT(L{+}1, R{-}1)$。算法每轮按此把 `ans` 与窗口同步归约，窗口长度 $< 2$ 时 $OPT = 0$，对窗口长度归纳即得算法输出 $OPT(0, n-1)$，由引理 1 即为答案。∎

## 6. 复杂度分析

- **时间复杂度**：
  - 哈希计数：$O(n)$——一次遍历建频次表 + 一次遍历键集合，均为线性（均摊）；
  - 排序+双指针：$O(n \log n)$——排序占主导，收拢扫描 $O(n)$。
- **空间复杂度**：
  - 哈希计数：$O(n)$——频次表至多 $n$ 个不同键；
  - 排序+双指针：C++ 内省排序栈深 $O(\log n)$；Python Timsort 需 $O(n)$ 辅助空间。

> 💡 $n = 10^5$ 时两种做法都远低于时限，赛时选写得最快的那个——双指针代码最短且无任何特判。

## 7. 参考代码

### 方法一：哈希表计数

### C++

```cpp
class Solution {
  public:
    int maxOperations(vector<int>& nums, int k) {
        unordered_map<int, int> freq;
        for (int x : nums) freq[x]++;

        int ans = 0;
        for (auto& [v, cnt] : freq) {
            int comp = k - v;
            if (comp < v) continue;            // 该值类已由较小一侧统计过
            if (comp == v) {
                ans += cnt / 2;                // 自配对：两两消化，多的落单
            } else if (freq.count(comp)) {
                ans += min(cnt, freq[comp]);    // 跨类配对：取两频次较小者
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maxOperations(self, nums: List[int], k: int) -> int:
        freq = Counter(nums)
        ans = 0
        for v, cnt in freq.items():
            comp = k - v
            if comp < v:
                continue                        # 该值类已由较小一侧统计过
            if comp == v:
                ans += cnt // 2                 # 自配对
            elif comp in freq:
                ans += min(cnt, freq[comp])     # 跨类配对
        return ans
```

### 方法二：排序 + 双指针

### C++

```cpp
class Solution {
  public:
    int maxOperations(vector<int>& nums, int k) {
        sort(nums.begin(), nums.end());
        int left = 0, right = (int)nums.size() - 1, ans = 0;
        while (left < right) {
            long long sum = (long long)nums[left] + nums[right];
            if (sum == k) {
                ans++;
                left++;
                right--;
            } else if (sum < k) {
                left++;
            } else {
                right--;
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maxOperations(self, nums: List[int], k: int) -> int:
        nums.sort()
        left, right = 0, len(nums) - 1
        ans = 0
        while left < right:
            s = nums[left] + nums[right]
            if s == k:
                ans += 1
                left += 1
                right -= 1
            elif s < k:
                left += 1
            else:
                right -= 1
        return ans
```

## 8. 边界情况与易错点

1. **`sum` 溢出**：$\text{nums}[i] \leq 10^9$，两端相加最大 $2 \times 10^9$，距 $\text{INT32\_MAX} \approx 2.147 \times 10^9$ 只差约 $1.5 \times 10^8$——本题上界侥幸安全，但同类题上界稍一放大就溢出，C++ 建议直接 `long long sum` 兜底。
2. **补数可能非正**：$v > k$ 时 $k - v \leq 0$，必然不在频次表中，贡献 $0$；哈希查不到就跳过，不会误配出"不存在的元素"。
3. **自配对是向下取整**：$\text{freq}[k/2] \mathbin{//} 2$ 而非向上取整——奇数个 $k/2$ 必落单一个（示例 3 的 $[5,5,5]$ 只有 $1$ 对）。
4. **跨类只算一次**：不加 `comp < v` 跳过，$\{3,4\}$ 会在 $v=3$ 与 $v=4$ 各算一遍，答案翻倍。
5. **遍历哈希表时勿用 `operator[]` 查询**：缺失键会被插入 $0$，可能触发 rehash 使迭代器失效（未定义行为），用 `find`/`count`。
6. **`k` 为奇数无自配类**：不存在整数 $v$ 满足 $2v = k$，`comp == v` 分支自动不触发，无需写奇偶特判。
7. **双指针结束条件**：`left < right`——窗口剩 $0$ 或 $1$ 个元素时自然退出；$n \geq 1$ 保证初始化 `right = n-1` 合法，无需特判单元素数组。
8. **两种方法对负数/零也成立**：双指针只依赖排序单调性，与元素正负无关；哈希法只需注意补数可能不在表中。本题约束 $\text{nums}[i] \geq 1$，无此顾虑。
