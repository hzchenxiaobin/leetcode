# LeetCode 统计出现过一次的公共字符串 题解

## 1. 题目概述

- **标题 / 题号**：统计出现过一次的公共字符串（#2085，easy）
- **链接**：https://leetcode.cn/problems/count-common-words-with-one-occurrence/
- **来源**：LeetCode 第 66 场双周赛 Q1
- **难度**：简单
- **标签**：数组、哈希表、字符串、计数

**题意**：给定两个字符串数组 `words1` 与 `words2`，统计满足**在两个数组中都恰好出现一次**的字符串数目，返回该数目。

**约束**：

- $1 \le words1.length, words2.length \le 1000$
- $1 \le words1[i].length, words2[j].length \le 30$
- 所有字符串只含小写英文字母

> 💡 "恰好出现一次"是**双条件**：在 words1 中出现 1 次**且**在 words2 中出现 1 次，两个条件缺一不可。

## 2. 示例

**示例 1**

```text
输入：words1 = ["leetcode","is","amazing","as","is"], words2 = ["amazing","leetcode","is"]
输出：2
解释："leetcode"、"amazing" 两边各出现一次，计入；"is" 在 words1 出现 2 次，不算。
```

**示例 2（无公共串）**

```text
输入：words1 = ["b","bb","bbb"], words2 = ["a","aa","aaa"]
输出：0
解释：没有字符串同时出现在两个数组中。
```

**示例 3（一侧重复）**

```text
输入：words1 = ["a","ab"], words2 = ["a","a","a","ab"]
输出：1
解释："a" 在 words2 出现 3 次，不算；只有 "ab" 两边各出现一次。
```

## 3. 解题思路

### 3.1 暴力思路

对 words1 中每个**去重后**的字符串 $w$，线性扫 words1、words2 各数一遍出现次数，双条件都为 1 则计数。最坏 $1000 \times 2000$ 次字符串比较，约 $2 \times 10^6$，能过但难看；两次哈希计数一遍扫完更利落。

### 3.2 核心观察：两张计数哈希表 + 双条件过滤

![双条件计数：两张哈希表](images/bw66_q1_counter_model.svg)

"恰好一次"的判定只依赖每个字符串在各数组中的**总出现次数**，与位置无关。于是：

1. 用哈希表 `c1`、`c2` 分别统计两数组中每个字符串的出现次数；
2. 遍历 `c1` 中计数为 1 的键，查 `c2` 中该键是否也恰为 1，是则答案 +1。

遍历 `c1`（而非两个数组的笛卡尔积）保证每个候选只被检查一次；`c2.get(w, 0) == 1` 同时涵盖"不存在"（0）与"出现多次"（≥2）两种失败情形。

### 3.3 算法流程

![算法流程：两遍计数与双条件过滤](images/bw66_q1_flow.svg)

```text
1. c1 = Counter(words1)，c2 = Counter(words2)
2. ans = 0
3. for (w, k) in c1:
       若 k == 1 且 c2[w] == 1：ans += 1
4. 返回 ans
```

### 3.4 示例演算

示例 1：`c1 = {leetcode:1, is:2, amazing:1, as:1}`，`c2 = {amazing:1, leetcode:1, is:1}`。遍历 `c1`：`leetcode`（1，且 c2 中 1）✓；`is`（c1 中 2）✗；`amazing`（1，且 c2 中 1）✓；`as`（c2 中不存在）✗。答案 2。

## 4. 算法细节

1. **计数表键是整串**：字符串最长 30，哈希一次的代价 $O(|w|)$，整体线性于输入总字符数。
2. **先过滤 k == 1 再查 c2**：`c1` 里多数键可能重复，先判本表可少查 `c2`；两者顺序无所谓正确性。
3. **`c2.get(w, 0)` 处理缺键**：等价于"出现 0 次 ≠ 1 次"，不要在查询前假设键存在。
4. **答案上界**：$\min(|\text{unique}(words1)|, |\text{unique}(words2)|)$，无需提前截断。
5. **遍历较小的表更快**（可选优化）：若 `len(c1) > len(c2)` 可交换两表再遍历，本题规模无所谓。

## 5. 正确性证明

**引理 1**：哈希计数后，$c1[w]$、$c2[w]$ 分别等于 $w$ 在两数组中的出现次数。

**证明**：每读入一个字符串对其键自增 1，总自增次数即出现次数。∎

**定理**：算法返回的恰是"在两数组中都恰好出现一次"的字符串数目。

**证明**：一个字符串 $w$ 满足双条件当且仅当 $c1[w] = 1 \wedge c2[w] = 1$（引理 1）。算法枚举 `c1` 的全部键——任何满足 $c1[w]=1$ 的 $w$ 必是 `c1` 的键——并精确检验这两个等式，既不漏（候选全枚举）也不重（哈希键唯一）。计数值即满足双条件的字符串个数。∎

## 6. 复杂度分析

- **时间**：$O(L_1 + L_2)$，其中 $L_1$、$L_2$ 是两数组的总字符数（每串哈希 $O(|w|)$）；遍历 `c1` 再花 $O(|\text{unique}(words1)|)$ 次哈希查询。
- **空间**：$O(L_1 + L_2)$，两张哈希表存全部不同字符串。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int countWords(vector<string>& words1, vector<string>& words2) {
        unordered_map<string, int> c1, c2;
        for (const auto& w : words1) ++c1[w];
        for (const auto& w : words2) ++c2[w];
        int ans = 0;
        for (const auto& [w, k] : c1)                 // 遍历较短的表更快，这里无所谓
            if (k == 1) {
                auto it = c2.find(w);
                if (it != c2.end() && it->second == 1) ++ans;
            }
        return ans;
    }
};
```

### Python

```python
from collections import Counter

class Solution:
    def countWords(self, words1: list[str], words2: list[str]) -> int:
        c1, c2 = Counter(words1), Counter(words2)
        return sum(1 for w, k in c1.items() if k == 1 and c2.get(w, 0) == 1)
```

> 💡 两份代码均通过官方 3 组示例（`2` / `0` / `1`）以及 C++ 5000 组、Python 2000 组随机数据（小词表强制制造重复）与独立 `map` 暴力的对拍，`mismatch = 0`。

## 8. 边界情况与易错点

1. **双条件的"且"**：只查 `c1[w] == 1` 不查 `c2` 会把单侧唯一的串算进来（示例 1 的 `"as"`）；只查 `c2` 同理漏掉 words1 侧重复。
2. **一侧出现 3 次以上**：`"a"` 在 words2 出现 3 次，必须排除——条件是**等于** 1，不是"出现过"。
3. **两数组无交集**：答案 0，`c2.find` 全部落空，注意判空迭代器再取 `second`。
4. **短串与重复串混合**：单字符串也是合法键，不要按长度过滤。
5. **遍历对象用 `c1` 而非 `words1`**：直接扫数组会把 `c1[w]==1` 的串重复检查多遍（虽然结果仍对，但无谓地慢）。
