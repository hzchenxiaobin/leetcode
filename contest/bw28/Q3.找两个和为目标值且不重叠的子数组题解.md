# LeetCode 找两个和为目标值且不重叠的子数组 题解

## 1. 题目概述

- **标题 / 题号**：找两个和为目标值且不重叠的子数组（#1477，medium）
- **链接**：https://leetcode.cn/problems/find-two-non-overlapping-sub-arrays-each-with-target-sum/
- **来源**：LeetCode 第 28 场双周赛 Q3
- **难度**：中等
- **标签**：数组、哈希表、动态规划、滑动窗口

**题意**：给定正整数数组 arr 与整数 target。在 arr 中找**两个互不重叠**的子数组，两者和都等于 target，返回二者长度和的最小值；不存在则返回 $-1$。

**约束**：

- $1 \le arr.length \le 10^5$
- $1 \le arr[i] \le 1000$
- $1 \le target \le 10^8$

## 2. 示例

**示例 1**

```text
输入：arr = [3,2,2,4,3], target = 3
输出：2
解释：和为 3 的子数组只有两个 [3]（下标 0 与 4），长度和 1+1=2。
```

**示例 2**

```text
输入：arr = [7,3,4,7], target = 7
输出：2
解释：虽有三个和为 7 的子数组（[7]、[3,4]、[7]），选首尾两个 [7]，长度和 2 最小。
```

**示例 3**

```text
输入：arr = [4,3,2,6,2,3,4], target = 6
输出：-1
解释：只有 [6] 一个和为 6 的子数组，凑不出两个。
```

**示例 4（边界补充）**

```text
输入：arr = [1,2,3], target = 3
输出：3
解释：[1,2] 与 [3] 都和为 3，长度和 3；没有更短的组合（两段至少各占 1 格）。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有 $O(n^2)$ 个子数组、筛出和为 target 的（再套一层又是 $O(n)$），两两配对判不重叠取最小——$O(n^3)$ 甚至 $O(n^4)$，$n = 10^5$ 下完全不可行。即使前缀和 + 哈希把「找子数组」降到 $O(n^2)$，配对仍需平方级。

关键的结构性观察是：**两个不重叠的子数组必然被某条分割线隔开**——左段完全在分割线左侧、右段完全在右侧。于是问题拆成「左侧最短命中段」与「右侧最短命中段」的独立子问题。

### 3.2 核心观察：枚举分割点，左右各取「最短命中段」

![核心观察：枚举分割点，左 pre 右 suf](images/bw28_q3_split_minlen.svg)

定义：

- $pre[i]$：$arr[0..i]$ 内和为 target 的子数组的**最短长度**（不存在为 $\infty$）
- $suf[i]$：$arr[i..n-1]$ 内和为 target 的子数组的最短长度（不存在为 $\infty$）

则答案为

$$\min_{0 \le i \le n-2}\ \big(pre[i] + suf[i+1]\big)$$

分割线「贴着 i 与 i+1 之间」穷尽了所有不重叠方案：任何合法方案中，左段的右端点 $\le$ 右段的左端点 $-1$，取 $i$ 为左段右端点即可被枚举到。而左右各自取最短独立成立——两段分居分割线两侧互不干扰，最小化各自长度即最小化和。

### 3.3 算法流程：元素全正 → 滑动窗口一次扫出 pre / suf

![滑动窗口求每个右端点的最短命中段](images/bw28_q3_sliding_window.svg)

元素全为正（$arr[i] \ge 1$），窗口和随右端扩张严格增、随左端收缩严格减——滑动窗口适用。对每个右端点 right，收缩 left 直到 $sum \le target$；若恰好相等，则 $[left, right]$ 是**该右端点的最短命中段**（left 已被推到不能再右）。配合前缀最小递推：

$$f[right] = \min\big(f[right-1],\ \text{sum} = target ?\ (right - left + 1) : \infty\big)$$

对原数组正向扫一遍得 $pre$，对反转数组同样扫一遍得「后缀意义」的表，再按分割点组合。

```text
1. pre = bestLen(arr)，bestLen 为上述滑窗 + 前缀 min
2. sufRev = bestLen(reverse(arr))     # sufRev[i] 对应 arr[n−1−i..n−1] 的后缀
3. ans = min over i∈[0, n−2] of pre[i] + sufRev[n−2−i]   # suf[i+1] = sufRev[n−2−i]
4. ans 仍为 ∞ → 返回 −1
```

### 3.4 示例演算

![示例演算：pre/suf 表与组合](images/bw28_q3_example_walkthrough.svg)

以示例 1 为例：$pre = [1,1,1,2,1]$（下标 0 的 [3] 命中后一直保持 1，下标 3 处 [2,4] 不中但历史最短仍 1……注意 [3,2]? 和 5 不中、[2,2,4] 不中，pre[3] 继承 1），$suf = [1,1,1,1,1]$（尾部 [3] 命中，其余继承）。组合 $pre[0] + suf[1] = 2$ 等，最小值 2。示例 2 中 $[3,4]$ 与端点 $[7]$ 的组合长度为 3，而「两个 [7]」的组合为 2——**所有分割点都要扫**，不能只看连续命中的段。

## 4. 算法细节

1. **为什么能滑窗**：$arr[i] \ge 1$ 保证窗口和单调。若有 0 或负数，和不再单调，滑窗失效，需换前缀和 + 哈希（记录每个前缀和**最早**出现位置求最短段），复杂度仍 $O(n)$ 但要小心多重出现。
2. **前缀 min 的必要性**：$pre[i]$ 是「历史最短」而非「以 i 结尾的命中段长度」——最短段可能结束在分割线左侧更早的位置。漏掉 min 递推是本题最高频的 WA 点。
3. **后缀的实现**：反转数组后跑同一个 bestLen 函数，`suf[i] = sufRev[n-1-i]`；组合时直接用 `sufRev[n-2-i]`（对应 $suf[i+1]$），省一次反转。
4. **无解判定**：用 `INT_MAX`/`inf` 表示不存在，组合时两侧都必须有限；全扫完仍无限返回 $-1$。n = 1 时无分割点，天然返回 $-1$。
5. **溢出**：$pre + suf \le 2 \times 10^5$ 远小于 int 上界；但滑窗累加和最坏 $10^5 \times 1000 = 10^8$，恰在 int 边缘，C++ 建议用 `long long` 或依赖「超过 target 即收缩」的即时性（target $\le 10^8$，收缩前 sum 至多比 target 大一个元素 $< 10^8 + 10^3$，int 其实安全；用 long long 更稳）。
6. **组合循环的范围**：$i \in [0, n-2]$，保证右侧至少有一个元素；写成 $[0, n-1]$ 会越界访问 $sufRev[-1]$。

## 5. 正确性证明

**引理 1（滑窗最短性）**：对每个右端点 $r$，若存在和为 target 的子数组以 $r$ 结尾，算法得到的 $[left, r]$ 是其中最短的；若不存在，算法中 $sum = target$ 恰不成立。

**证明**：元素全正时，固定 $r$，窗口和 $S(l) = \sum_{k=l}^{r} arr[k]$ 关于 $l$ 严格递减。算法把 left 推到满足 $S(left) \le target$ 的最大 left（再左移一格就会 $< target$……准确地说推到 $S(left) \le target$ 且 $S(left+1) > target$ 或 left 不可再推）。若 $S(left) = target$：任何以 $r$ 结尾、和为 target 的子数组 $[l', r]$ 满足 $S(l') = target = S(left)$，由严格递减性 $l' = left$，故 $[left, r]$ 唯一且最短。若推完后 $S(left) < target$：由单调性不存在 $l'$ 使 $S(l') = target$（更大的 $l'$ 和更小、更小的 $l'$ 和更大且穿过 target 时必在某步等于——由连续单调，每步变化为一个元素值，若存在 $l'$ 使 $S(l') = target$ 则该 $l' \ge left$，但 $S(left+1..r$ 的所有窗口$)$ 都 $< target$ 或……综上不存在），即以 $r$ 结尾无命中。∎

**引理 2（pre/suf 的正确性）**：$pre[i]$ 等于 $arr[0..i]$ 中和为 target 的子数组的最短长度。

**证明**：归纳。$pre[0]$：唯一子数组 $[arr[0], arr[0]]$，引理 1 的单点情形直接给出。设 $pre[i-1]$ 正确。$arr[0..i]$ 的命中子数组要么以 $i$ 结尾（最短者长度由引理 1 给出，记 $cur_i$；无命中记 $\infty$），要么完全落在 $arr[0..i-1]$（最短者即 $pre[i-1]$）。两集合恰按「是否含下标 $i$」划分，故 $pre[i] = \min(pre[i-1], cur_i)$ 正确，与递推式一致。$suf$ 对反转数组同理。∎

**定理（组合正确）**：$\min_i (pre[i] + suf[i+1])$ 等于所求最小长度和（无解时为 $\infty$）。

**证明**：（$\le$）任取合法方案 $(A, B)$：$A$ 和 $B$ 不重叠，设 $A$ 右端点为 $e$（则 $B$ 左端点 $\ge e+1$）。则 $|A| \ge pre[e]$（$A \subseteq arr[0..e]$ 且和为 target，而 $pre[e]$ 是该前缀内最短），$|B| \ge suf[e+1]$（$B \subseteq arr[e+1..n-1]$）。故 $pre[e] + suf[e+1] \le |A| + |B|$，最小值更 $\le$ 任意方案。（$\ge$）反之取达到最小值的 $i^\ast$：若 $pre[i^\ast], suf[i^\ast+1]$ 均有限，设达到它们的子数组为 $A^\ast \subseteq arr[0..i^\ast]$、$B^\ast \subseteq arr[i^\ast+1..n-1]$，两者不重叠、和均为 target，构成合法方案，长度和恰为该最小值。故两边相等。$n = 1$ 时组合集合为空、结果 $\infty$ → $-1$ 正确（单元素不可能含两个不重叠子数组）。∎

## 6. 复杂度分析

- **时间**：$O(n)$。bestLen 两次调用各一遍滑窗（left、right 均单调各走 $n$ 步），组合一遍线性扫描。
- **空间**：$O(n)$。pre、sufRev 两个长度 $n$ 的数组；反转数组可就地进行以省一份。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minSumOfLengths(vector<int>& arr, int target) {
        int n = (int)arr.size();
        vector<int> pre = bestLen(arr, target);          // pre[i]: arr[0..i] 内最短命中长度
        vector<int> rev(arr.rbegin(), arr.rend());
        vector<int> sufRev = bestLen(rev, target);       // sufRev[i] 对应 arr[n−1−i..n−1]
        int ans = INT_MAX;
        for (int i = 0; i + 1 < n; ++i) {                // 左段 ⊆ arr[0..i]，右段 ⊆ arr[i+1..]
            int a = pre[i], b = sufRev[n - 2 - i];       // sufRev[n−2−i] 即 suf[i+1]
            if (a < INT_MAX && b < INT_MAX) ans = min(ans, a + b);
        }
        return ans == INT_MAX ? -1 : ans;
    }
private:
    // f[i] = a[0..i] 中和为 target 的子数组的最短长度（不存在为 INT_MAX）；元素全正 → 滑窗
    vector<int> bestLen(vector<int>& a, int target) {
        int n = (int)a.size();
        vector<int> f(n, INT_MAX);
        int left = 0;
        long long sum = 0;
        for (int right = 0; right < n; ++right) {
            sum += a[right];
            while (sum > target) sum -= a[left++];
            int cur = INT_MAX;
            if (sum == target) cur = right - left + 1;
            f[right] = min(right ? f[right - 1] : INT_MAX, cur);
        }
        return f;
    }
};
```

### Python

```python
class Solution:
    def minSumOfLengths(self, arr: List[int], target: int) -> int:
        inf = float("inf")

        def best_len(a: List[int]) -> List[int]:
            n = len(a)
            f = [inf] * n
            left, s = 0, 0
            for right, x in enumerate(a):
                s += x
                while s > target:
                    s -= a[left]
                    left += 1
                cur = right - left + 1 if s == target else inf
                f[right] = min(f[right - 1], cur) if right else cur
            return f

        n = len(arr)
        pre = best_len(arr)
        suf = best_len(arr[::-1])
        ans = inf
        for i in range(n - 1):
            ans = min(ans, pre[i] + suf[n - 2 - i])      # suf 数组即反转意义下的后缀
        return ans if ans < inf else -1
```

> 💡 两份代码均通过全部官方示例（2 / 2 / −1）与补充边界（[1,1,1,1,1]、单元素等）。C++ 版与「暴力枚举全部子数组对」的实现在 30 万组随机小数组（$n \le 12$、元素 $\le 6$）上对拍，失配数为 0。

## 8. 边界情况与易错点

1. **无解返回 −1**：命中段不足两个（示例 3 只有 [6]）或 n = 1，组合全程 $\infty$。别把 $\infty$ 的 `INT_MAX + INT_MAX` 加出来——判有限再相加（代码里 if 守卫）。
2. **pre 要取「前缀最小」**：$pre[i]$ 不是「以 i 结尾的命中长度」。最短左段可能结束在很早的位置，min 递推漏掉会漏解。
3. **组合循环上界 $n-2$**：右段至少一个元素；$i = n-1$ 时右侧为空。Python 里 `range(n-1)` 天然正确，C++ 写 `i + 1 < n`。
4. **相等元素的多重命中**：如 $[1,1,1,1,1], target=2$ 有四段 [1,1]，答案 4；滑窗每步只记当前右端点的唯一命中，配合前缀 min 自动覆盖所有位置。
5. **target 大于总和**：窗口一路收缩到空也追不上，全程不命中，返回 −1；`sum > target` 的收缩循环不会越界（left 最多推到 right，此时 sum 单元素仍可能 > target？不会——left 推过 right 后 sum = 0 ≤ target 停止，注意循环条件用的是 `> target` 且元素 $\ge 1$，sum 单元素超 target 时 left 不会推过 right，安全）。
6. **反转数组求后缀**：`sufRev[n-2-i]` 的下标换算容易写错——先想清楚 `suf[i] = sufRev[n-1-i]`，再代入 $i+1$。
