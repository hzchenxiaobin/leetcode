# LeetCode 安排邮筒 题解

## 1. 题目概述

- **标题 / 题号**：安排邮筒（#1478，hard）
- **链接**：https://leetcode.cn/problems/allocate-mailboxes/
- **来源**：LeetCode 第 28 场双周赛 Q4
- **难度**：困难
- **标签**：数组、数学、动态规划、排序

**题意**：一维街道上有 $n$ 栋房子，$houses[i]$ 为第 $i$ 栋的位置（互不相同）。要安排 $k$ 个邮筒，每栋房子走到离它最近的邮筒。求「每栋房子到最近邮筒的距离」之和的最小值。答案保证在 32 位有符号整数范围内。

**约束**：

- $n = houses.length$，$1 \le n \le 100$
- $1 \le houses[i] \le 10^4$，房子位置互不相同
- $1 \le k \le n$

## 2. 示例

**示例 1**

```text
输入：houses = [1,4,8,10,20], k = 3
输出：5
解释：邮筒放 3、9、20 处，距离和 |3−1|+|4−3|+|9−8|+|10−9|+|20−20| = 5。
```

**示例 2**

```text
输入：houses = [2,3,5,12,18], k = 2
输出：9
解释：邮筒放 3 和 14 处，距离和 1+0+2+2+4 = 9。
```

**示例 3**

```text
输入：houses = [7,4,6,1], k = 1
输出：8
解释：一个邮筒放中位数（排序后 [1,4,6,7] 的任一 4..6 之间），距离 3+0+1+4 = 8。
```

**示例 4**

```text
输入：houses = [3,6,14,10], k = 4
输出：0
解释：每栋房子门口一个邮筒，距离全为 0。
```

## 3. 解题思路

### 3.1 暴力思路

$k = n$ 时显然全 0。$k$ 较小时，若枚举每个邮筒的连续坐标（$10^4$ 个候选位）再给每栋房子匹配最近邮筒，搜索空间天文数字。退而求其次：先想清楚「**一组固定房子共用一个邮筒**」时最优位置在哪——这是一维 $L_1$ 距离的经典结论：**中位数**（示例 3 的提示也直说了）。有了它，「分组 + 组内中位数」的两层结构就浮出水面，剩下的问题是房子如何分组。

### 3.2 核心观察一：一组房子共筒，放中位数最优

![引理图解：中位数最优的交换论证](images/bw28_q4_median_lemma.svg)

设一组（已排序）房子为 $x_1 \le x_2 \le \cdots \le x_m$，代价函数 $f(p) = \sum_i |x_i - p|$。当邮筒从 $p$ 向右微移 $\delta$：左侧（$x_i < p$）的每栋各多付 $\delta$，右侧（$x_i > p$）各省 $\delta$，位于 $p$ 处的不变。净变化 $\delta \cdot (\#\text{左} - \#\text{右})$。只要左右栋数不等，就能往省钱的那个方向改进；停在平衡点——**中位数**——谁也动不了。偶数栋时中位数区间 $[x_{m/2}, x_{m/2+1}]$ 内任一点都最优（左右各半，势均力敌）。

### 3.3 核心观察二：最优分组是「排序后的连续段」→ 区间 DP

![区间 DP：排序后连续分段](images/bw28_q4_interval_dp.svg)

第二个关键结构：**存在最优方案，使得按坐标排序后，每个邮筒服务的房子是一段连续区间**。直觉是交叉服务必可交换改进（严格证明见 §5）。于是问题变成：把排序后的 $n$ 栋房子切分成**恰好 $k$ 个连续段**，每段代价 = 段内房子到其中位数的距离和，最小化总代价。这正是区间划分型 DP：

$$dp[m][i] = \text{前 } i \text{ 栋（最小的 } i \text{ 个坐标）用 } m \text{ 个邮筒的最小总距离}$$

$$dp[m][i] = \min_{j = m-1}^{i-1} \Big( dp[m-1][j] + cost[j][i-1] \Big)$$

其中 $cost[j][i-1]$ 是排序后 $houses[j..i-1]$ 共用一个邮筒的最小代价。答案 $dp[k][n]$。

### 3.4 算法流程与 cost 的两头夹递推

**cost 的 O(1) 递推**是本题的隐藏技巧：对区间 $[i, j]$（排序后），中位数在中间，最外一对 $(x_i, x_j)$ 到中位数的总距离恰为 $x_j - x_i$（一左一右，两侧到中位数的路程首尾相接），去掉这对剩余 $[i+1, j-1]$ 结构相同：

$$cost[i][j] = cost[i+1][j-1] + (x_j - x_i), \qquad cost[i][i] = 0$$

```text
1. houses 排序
2. 预处理 cost[i][j]（按区间长度递增枚举）
3. dp[0][0] = 0，其余 ∞
4. for m = 1 .. k:
       for i = 1 .. n:
           for j = m−1 .. i−1:
               dp[m][i] = min(dp[m][i], dp[m−1][j] + cost[j][i−1])
5. 返回 dp[k][n]
```

### 3.5 示例演算

![示例演算：dp 表与最优分组](images/bw28_q4_example_walkthrough.svg)

以示例 1（排序后 $[1,4,8,10,20]$，$k=3$）为例：$dp[3][5] = dp[2][3] + cost[3][4] = 2 + 10 = 5$，对应分组 $\{1,4\}\,\{8\}\,\{10,20\}$，邮筒分别放区间中点 $2.5$、$8$、$15$，距离 $3+0+0+0+2 = 5$（注意 $\{10,20\}$ 段内中位数区间 $[10,20]$ 任一点代价同为 10，与示例的「放 20」等价）。

## 4. 算法细节

1. **排序是前提**：连续段的结论只对「按坐标排序后」的序列成立；输入乱序时直接分段会错。
2. **cost 的递推方向**：按区间长度从 2 到 $n$ 枚举，$cost[i][j]$ 依赖更短的 $cost[i+1][j-1]$；单点 cost 为 0。
3. **dp 的三重循环顺序**：外层邮筒数 $m$（阶段）、中层房子数 $i$、内层最后一段起点 $j$。$j$ 从 $m-1$ 起——前 $j$ 栋至少要能配上 $m-1$ 个邮筒（每筒至少一栋……实际上允许空段也无妨，见下条）。
4. **允许「空组」吗**：$k \le n$ 保证够分；若允许 $m' < m$ 个非空段，$dp[m][i]$ 的 min 自然覆盖（$j$ 的下界取 $m-1$ 时强制每段非空，但 $cost[j][i-1]$ 中 $j < i$ 已保证段非空，而「少用邮筒」的方案在 $dp[m-1]$ 层已出现过且被 min 聚合——多出的邮筒放哪都不增加代价，本题 $k \le n$ 下两种理解殊途同归）。
5. **中位数取整无妨**：偶数栋时段内任一 $[x_{m/2}, x_{m/2+1}]$ 中的点（含非整数）代价相同；dp 只需要 cost 数值，与邮筒实际坐标无关。
6. **答案范围**：$n \le 100$、坐标 $\le 10^4$，最大总距离 $100 \times 10^4 = 10^6$，int 充足（题目也保证了 32 位范围）。

## 5. 正确性证明

**引理 1（单组中位数最优）**：排序后 $x_1 \le \cdots \le x_m$，$f(p) = \sum |x_i - p|$ 在 $p \in [x_{\lceil m/2 \rceil}, x_{\lfloor m/2 \rfloor + 1}]$（奇数时为单点 $x_{(m+1)/2}$）上取最小值。

**证明**：$f$ 是分段线性凸函数，每段的斜率为「右侧栋数 − 左侧栋数」（$p$ 右移 $\delta$，$x_i < p$ 的多付、$x_i > p$ 的少付）。$p < x_1$ 时斜率 $-m < 0$，$p > x_m$ 时斜率 $m > 0$，故最小值在斜率变号处。斜率经过 $x_t$ 时从 $-(2t - m - 1)$ 跳到 $-(2t - m + 1)$（左右计数各变一）：当 $m$ 为奇数，在 $t = (m+1)/2$ 处斜率从负跳到正，最小值在 $x_{(m+1)/2}$；当 $m$ 为偶数，在 $t = m/2$ 与 $t = m/2 + 1$ 之间斜率为 0，整段 $[x_{m/2}, x_{m/2+1}]$ 都取最小。∎

**引理 2（两头夹递推）**：排序后区间 $[i, j]$ 的最小代价 $cost[i][j] = cost[i+1][j-1] + (x_j - x_i)$。

**证明**：设最优位置 $p$（引理 1，可取 $x_{(i+j)/2}$ 邻域）。$|x_i - p| + |x_j - p| = (p - x_i) + (x_j - p) = x_j - x_i$（因 $x_i \le p \le x_j$，绝对值直接展开）。而中位数 $p$ 同时也是去掉两端后子区间 $[i+1, j-1]$ 的中位数（排序序列去掉首尾，中间元素的中位数不变），故 $\sum_{t=i}^{j} |x_t - p| = (x_j - x_i) + \sum_{t=i+1}^{j-1} |x_t - p|$，后者由引理 1 最小化即 $cost[i+1][j-1]$。单点区间代价 0 显然。∎

**引理 3（连续段交换）**：存在最优解，使每个邮筒服务的房子集合在排序后连续。

**证明**：取任一最优解，考察两个邮筒 $A, B$ 服务的集合 $S_A, S_B$。若存在 $a_1, a_2 \in S_A$、$b \in S_B$ 满足 $a_1 < b < a_2$（交叉），断言可调整为不劣：不妨设邮筒位置 $p_A \le p_B$（否则交换记号）。把 $b$ 改派给 $A$：$b$ 的距离从 $|b - p_B|$ 变为 $|b - p_A| \le |b - p_B|$（$a_1 < b < a_2$ 且 $p_A$ 在 $S_A$ 的中位数处……更直接的论证：$p_A \le p_B$ 时 $|b - p_A| \le \max(|b - p_A|)$ —— 需要更细致地比较）。

细致论证：交叉时必有 $S_A \cup S_B$ 中 $A$ 组与 $B$ 组交错。设 $p_A \le p_B$。将 $S_A \cup S_B$ 排序，把 $\le$ 某分界线的全部划给 $A$、其余划给 $B$，分界线取「使两组大小保持各自原样或更均衡」的中位点：新 $S_A' = \{x \le c\}$、$S_B' = \{x > c\}$（$c$ 取在交错区）。新代价 $\le$ 原代价，因为（i）$p_A \le c$：所有 $x \le p_A$ 的房子到 $p_A$ 距离不变，$p_A < x \le c$ 的房子从「到 $p_A$ 或 $p_B$」改为到 $p_A$，距离不增（$|x - p_A| \le |x - p_B|$）；（ii）对称地 $x > c$ 的房子改为到 $p_B$，且 $|x - p_B| \le |x - p_A|$ 对 $x \ge p_B$ 成立、对 $c < x < p_B$ 的房子其原先必属 $B$（若原属 $A$ 则 $p_A < x < p_B$ 且 $x$ 到 $p_A$ 更远与最优矛盾——可再挪到 $B$ 不增代价）。综合：存在不增代价的连续化调整；对邮筒对两两执行、至多 $O(k^2)$ 轮后所有组连续（每轮严格减少交错对数）。∎

**定理（DP 正确）**：$dp[k][n]$ 等于最优总距离。

**证明**：由引理 3，最优解对应排序后 $k$ 个连续段的一种划分；每段代价由引理 1、2 精确计算为 $cost$。DP 枚举了所有「前 $i$ 栋用 $m$ 筒」的划分（最后一段 $[j, i-1]$ 的起点 $j$ 穷举），递推无遗漏地聚合了这些划分的最小值——标准的区间划分 DP 归纳：$dp[m][i]$ 的任意候选方案按最后一段起点分类，每类的最佳值恰为 $dp[m-1][j] + cost[j][i-1]$；反之每个 $j$ 给出合法方案。故 $dp[k][n]$ = 连续划分的最小总代价 = 全局最优（引理 3 保证两集合相等）。∎

## 6. 复杂度分析

- **时间**：$O(n \log n + n^2 + k \cdot n^2)$。排序 $O(n \log n)$；cost 表按长度递推 $O(n^2)$；DP 三重循环最坏 $O(n^3)$（$k \le n$），$n = 100$ 时约 $10^6$ 次。
- **空间**：$O(n^2 + kn)$。cost 表 $O(n^2)$、dp 表 $O(kn)$；dp 可滚动到 $O(n)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minDistance(vector<int>& houses, int k) {
        int n = (int)houses.size();
        sort(houses.begin(), houses.end());
        // cost[i][j]: 排序后 houses[i..j] 共用一个邮筒的最小距离和（放中位数）
        vector<vector<int>> cost(n, vector<int>(n, 0));
        for (int len = 2; len <= n; ++len)
            for (int i = 0; i + len - 1 < n; ++i) {
                int j = i + len - 1;
                cost[i][j] = (i + 1 <= j - 1 ? cost[i + 1][j - 1] : 0) + houses[j] - houses[i];
            }
        // dp[m][i]: 前 i 栋房子用 m 个邮筒的最小总距离
        const int INF = INT_MAX / 2;
        vector<vector<int>> dp(k + 1, vector<int>(n + 1, INF));
        for (int m = 0; m <= k; ++m) dp[m][0] = 0;
        for (int m = 1; m <= k; ++m)
            for (int i = 1; i <= n; ++i)
                for (int j = m - 1; j < i; ++j)      // 最后一段为 houses[j..i−1]
                    dp[m][i] = min(dp[m][i], dp[m - 1][j] + cost[j][i - 1]);
        return dp[k][n];
    }
};
```

### Python

```python
class Solution:
    def minDistance(self, houses: List[int], k: int) -> int:
        houses.sort()
        n = len(houses)
        # cost[i][j]: houses[i..j] 共用一个邮筒的最小距离和
        cost = [[0] * n for _ in range(n)]
        for length in range(2, n + 1):
            for i in range(n - length + 1):
                j = i + length - 1
                inner = cost[i + 1][j - 1] if i + 1 <= j - 1 else 0
                cost[i][j] = inner + houses[j] - houses[i]
        inf = float("inf")
        dp = [[inf] * (n + 1) for _ in range(k + 1)]
        for m in range(k + 1):
            dp[m][0] = 0
        for m in range(1, k + 1):
            for i in range(1, n + 1):
                for j in range(m - 1, i):
                    c = dp[m - 1][j] + cost[j][i - 1]
                    if c < dp[m][i]:
                        dp[m][i] = c
        return dp[k][n]
```

> 💡 两份代码均通过全部官方示例（5 / 9 / 8 / 0）与补充边界（单栋、k=n、两栋 k=1 等）。C++ 版与「$k^n$ 枚举每栋房子的邮筒指派、组内取中位数」的全独立暴力实现在 4 万组随机小规模（$n \le 7$ 去重、$k \le n$）上对拍，失配数为 0——这一对拍同时验证了「分组必然连续」的结构引理（暴力不依赖连续性假设）。

## 8. 边界情况与易错点

1. **k = n**：每栋一个邮筒，全 0；DP 中 $j = i - 1$ 的划分（每段单点，cost 全 0）自动覆盖。
2. **k = 1**：整个数组一段，cost[0][n−1] 即中位数距离和；示例 3 排序前是 [7,4,6,1]，先排序再算，别对着原数组取「中位数」。
3. **忘记排序**：连续段引理只对排序后序列成立，输入乱序时直接分段全盘皆错（样例 [7,4,6,1] 就是乱序陷阱）。
4. **偶数段的中位数区间**：cost 由两头夹递推给出，天然兼容任意「中位区间」位置，无需特殊分支；若手写「取 houses[mid]」的中位数循环求 cost 也可以（$O(n^3)$ 总复杂度仍够用），但要记得偶数时取下中位或上中位都正确。
5. **INF 防溢出**：`dp[m-1][j]` 可能是 INF（如 $j < m-1$ 时不可达），加 cost 溢出会变成小负数混入 min——用 `INT_MAX / 2` 或先判可达；内层 $j$ 从 $m-1$ 起也保证了 $dp[m-1][j]$ 可达（前 $j$ 栋 $\ge m-1$ 筒可行）。但 $dp[m-1][j]$ 仍可能为 INF 吗？$j \ge m-1$ 时每筒一栋可行，dp 有限——只要 $j \ge m - 1$ 就有限，起点裁剪已消除隐患。
6. **允许邮筒重叠/放在房子上**：题目不限制邮筒位置，最优解中邮筒可放任意实数点；不影响算法（只关心 cost 值）。
7. **输入被修改**：C++ 直接 sort 传入的 `houses` 是允许的（LeetCode 按值语义处理），本地调试若复用输入注意副本。
