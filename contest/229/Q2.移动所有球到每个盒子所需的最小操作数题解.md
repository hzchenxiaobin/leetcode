# LeetCode 移动所有球到每个盒子所需的最小操作数 题解

## 1. 题目概述

- **标题 / 题号**：移动所有球到每个盒子所需的最小操作数（#1769，medium）
- **链接**：https://leetcode.cn/problems/minimum-number-of-operations-to-move-all-balls-to-each-box/
- **来源**：LeetCode 第 229 场周赛 Q2
- **难度**：中等
- **标签**：数组、字符串、前缀和

**题意**：给定长度为 $n$ 的二进制字符串 `boxes`，`boxes[i] == '1'` 表示第 $i$ 个盒子里有一个球，`'0'` 表示空。一次操作可以把**一个球**移动到**相邻**盒子（$|i - j| = 1$）。返回数组 `answer`，其中 `answer[i]` 是把**所有球**集中到第 $i$ 个盒子的最少操作数（每个 `answer[i]` 都按球的初始状态独立计算，盒子可容纳多个球）。

**约束**：

- $1 \le n \le 2000$
- `boxes[i]` 为 `'0'` 或 `'1'`

> 💡 **关键结构**：单个球从 $j$ 移到 $i$ 至少要走 $|i - j|$ 步，且各球互不干扰，所以 $\text{answer}[i] = \sum_{\text{boxes}[j]=1} |i - j|$——纯粹的「一维点到多点距离和」。这正是 [1685. 有序数组中差绝对值之和](https://leetcode.cn/problems/sum-of-absolute-differences-in-a-sorted-array/) 的 01 串版本：位置天然有序，可按方向去掉绝对值做前缀累加。

## 2. 示例

**示例 1**

```text
输入：boxes = "110"
输出：[1,1,3]
解释：球在位置 0、1。
answer[0] = |0-0| + |1-0| = 1
answer[1] = |0-1| + |1-1| = 1
answer[2] = |0-2| + |1-2| = 3
```

**示例 2**

```text
输入：boxes = "001011"
输出：[11,8,5,4,3,4]
解释：球在位置 2、4、5。
answer[0] = 2+4+5 = 11，answer[4] = 2+0+1 = 3 为最小值。
```

## 3. 解题思路

### 3.1 暴力思路：逐目标求距离和

按定义，对每个目标 $i$ 独立扫一遍所有球，累加距离：

```text
for i in 0..n-1:
    answer[i] = 0
    for j in 0..n-1:
        if boxes[j] == '1': answer[i] += abs(i - j)
```

时间 $O(n^2)$，$n \le 2000$ 时约 $4 \times 10^6$ 次整数运算，**能过**。但作为周赛 Q2 的定位是套路题，期望用线性解法稳定拿下，且 $O(n^2)$ 在更大的 $n$ 下会直接超时。

> ⚠️ **症结**：每个 `answer[i]` 都从零开始独立累加，完全没利用相邻答案间的关系——目标从 $i$ 移到 $i+1$ 时，答案的变化量是一个可以 $O(1)$ 维护的常数。

### 3.2 核心观察：目标右移一格的差分（左 +1、右 −1）

![核心观察：目标右移一格，左球各 +1 步、右球各 −1 步](images/wc229_q2_shift_diff_concept.svg)

把目标盒子想成**磁铁**。当目标从 $i$ 右移到 $i+1$ 时，全体球按位置分成互不重叠的两区：

- **左区**（位置 $\le i$，共 $L$ 个球）：每个球被拉远一步，距离各 $+1$；
- **右区**（位置 $\ge i+1$，共 $R$ 个球）：每个球被拉近一步，距离各 $-1$。

于是相邻答案只差一个「左计数 − 右计数」：

$$
\text{answer}[i+1] - \text{answer}[i] = L - R, \qquad L + R = \text{total}
$$

两式联立，只需维护左区球数 $L$：

$$
\text{answer}[i+1] = \text{answer}[i] + 2L - \text{total}
$$

而 $L$ 的维护是 $O(1)$ 的：扫描指针每越过一个 `'1'`，$L$ 就加一。配合 $O(n)$ 算出的基例 `answer[0]`（所有球位置之和），即可单趟递推出全部答案。

> 💡 **可迁移判据**：「到多点距离和」类问题（1685 / 238 / 2602）的通用加速器都是**相邻差分**——目标每移动一步，距离发生变化的只是「跨过分界线的左右两组计数」，差分恒为「左计数 − 右计数」。看到 $\sum |i - j|$ 就条件反射找差分。

### 3.3 算法流程：基例 + 单趟递推

![算法流程：一趟预处理 total 与 answer[0]，再单趟递推](images/wc229_q2_recurrence_flow.svg)

1. **预处理**（一趟 $O(n)$）：统计 `total`（球总数）与 `answer[0]`（所有球位置之和，即 $\sum_j |0 - j|$）；`left` 初始化为 `[boxes[0]=='1']`，即 $i=1$ 时的左区球数；
2. **递推**：对 $i = 1, \ldots, n-1$：
   - `answer[i] = answer[i-1] + left - (total - left)`（`left` 即目标从 $i-1$ 右移到 $i$ 时的 $L$，亦即 `boxes[0..i-1]` 中的球数）；
   - 若 `boxes[i] == '1'`，`left += 1`（供下一轮使用）；
3. **终止**：返回 `answer`。

### 3.4 示例演算

以示例 2 `boxes = "001011"`（球在 2、4、5，`total = 3`）为例：

![示例演算：从 answer[0]=11 出发，5 步递推出全部答案](images/wc229_q2_walkthrough.svg)

| $i$ | boxes[i] | left（位置 $< i$ 的球数） | $\Delta = 2 \cdot \text{left} - \text{total}$ | answer[i] |
|-----|----------|------------|------|-----------|
| $0$ | 0 | 0（基例） | — | $2+4+5 = 11$ |
| $1$ | 0 | 0 | $-3$ | $8$ |
| $2$ | 1 | 0 | $-3$ | $5$ |
| $3$ | 0 | 1 | $-1$ | $4$ |
| $4$ | 1 | 1 | $-1$ | $3$ |
| $5$ | 1 | 2 | $+1$ | $4$ |

- 目标还在最左侧时右区球最多（3 个），每右移一步净赚 3 步（$\Delta = -3$）；
- 越过位置 2 的球后它转入左区，$\Delta$ 变为 $-1$；越过位置 4 的球后变为 $+1$——$\Delta$ 的变化点恰是各个球的位置；
- 最终 `[11, 8, 5, 4, 3, 4]` ✓，与示例输出一致。

## 4. 算法细节

1. **`answer[0]` 的计算**：所有球到位置 0 的距离恰为各自的位置值，故 `answer[0]` = 球位置之和，与 `total` 在同一趟统计即可。
2. **`left` 的语义与更新时机**：递推 `answer[i]` 时 `left` 必须是 `boxes[0..i-1]` 中的球数——**先用后加**，`boxes[i]` 的球要在本轮递推结束后才并入 `left`。若先加后用，位置 $i$ 的球被提前算进左区，`answer[i]` 偏大。
3. **增量的两种等价写法**：`left - (total - left)` 与 `2 * left - total` 完全等价；前者语义直白（左球数 − 右球数），后者少一次减法，按喜好选择。
4. **与两次扫描法等价**：另一常见写法分方向累计——左→右一趟维护 `leftOps[i]`（左侧球距离和），右→左一趟维护 `rightOps[i]`，相加即答案。它与本递推同源：`answer[i] - answer[i-1]` 恰等于「左球数 − 右球数」（§5 引理 2），只是把一个差分拆成两个前缀和分别落地。
5. **语言惯用法**：C++ 用 `vector<int> answer(n)` 定长后下标写入；Python 用 `answer = [0] * n`。注意 `boxes[i] == '1'` 是**字符**比较，Python 中写 `== 1` 恒为 `False`，是典型 WA 点。

## 5. 正确性证明

**引理 1（距离和刻画）**：$\text{answer}[i] = \sum_{j:\,\text{boxes}[j]='1'} |i - j|$。

**证明**：题面允许一个盒子容纳多个球，故各球的移动互相独立。单个球从 $j$ 到 $i$：每步移动到相邻盒子，位置每步变化恰 1，故至少需 $|i-j|$ 步；依次向目标方向移到相邻盒子即可用 $|i-j|$ 步完成。总最小操作数 = 各球最小步数之和。∎

**引理 2（相邻差分）**：对 $1 \le i \le n-1$，记 $L_i = \#\{j < i : \text{boxes}[j]='1'\}$（严格在 $i$ 左侧的球数），则

$$
\text{answer}[i] - \text{answer}[i-1] = L_i - (\text{total} - L_i) = 2L_i - \text{total}
$$

**证明**：对每个球 $j$ 考察 $|i-j| - |i-1-j|$。当 $j \le i-1$（即 $j < i$）时两个绝对值均可直接去符号，差为 $(i-j) - (i-1-j) = 1$；当 $j \ge i$ 时差为 $(j-i) - (j-i+1) = -1$。左区球共 $L_i$ 个各贡献 $+1$，其余球共 $\text{total} - L_i$ 个各贡献 $-1$，对引理 1 的和式逐项相加即得。∎

**定理**：单趟递推算法输出的数组等于 `answer`。

**证明**：对 $i$ 归纳。**基例**：预处理算出 $\text{answer}[0] = \sum \text{球位置} = \sum_j |0-j|$，与引理 1 一致。**归纳步**：设算法在第 $i$ 轮开始时 `left` 恰为 $L_i$——初始 `left = [boxes[0]=='1']` 即 $L_1$，且每轮末将 `boxes[i]` 并入，归纳地与 $L_{i+1}$ 的定义吻合。于是由引理 2 与归纳假设（`answer[i-1]` 正确），本轮赋值

$$
\text{answer}[i] = \text{answer}[i-1] + \text{left} - (\text{total} - \text{left})
$$

给出正确的 $\text{answer}[i]$。故所有位置正确，算法终止时输出即答案数组。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。一趟统计 `total` 与 `answer[0]`，一趟递推 $n-1$ 轮、每轮 $O(1)$；相比暴力 $O(n^2)$（$n = 2000$ 约 $4 \times 10^6$ 次运算）是数量级的提升，$n$ 再放大两个数量级也不慌。
- **空间复杂度**：$O(1)$ 辅助空间。全程只维护 `total`、`left`、位置和三个标量；输出数组不计入。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> minOperations(string boxes) {
        int n = boxes.size();
        vector<int> answer(n);

        int total = 0, posSum = 0;
        for (int i = 0; i < n; ++i) {
            if (boxes[i] == '1') {
                ++total;
                posSum += i;
            }
        }
        answer[0] = posSum;

        int left = boxes[0] == '1' ? 1 : 0;
        for (int i = 1; i < n; ++i) {
            answer[i] = answer[i - 1] + left - (total - left);
            left += boxes[i] == '1' ? 1 : 0;
        }
        return answer;
    }
};
```

### Python

```python
class Solution:
    def minOperations(self, boxes: str) -> List[int]:
        n = len(boxes)
        total = boxes.count('1')
        answer = [0] * n
        answer[0] = sum(i for i, c in enumerate(boxes) if c == '1')

        left = 1 if boxes[0] == '1' else 0
        for i in range(1, n):
            answer[i] = answer[i - 1] + left - (total - left)
            if boxes[i] == '1':
                left += 1
        return answer
```

## 8. 边界情况与易错点

1. **全 '0'（无球）**：`total = 0`、`answer[0] = 0`，递推恒为 0，输出全 0 数组——无需任何特判。
2. **全 '1'**：$\text{answer}[i] = \frac{i(i+1)}{2} + \frac{(n-1-i)(n-i)}{2}$，递推自然得出，可用小样例对拍验证。
3. **n = 1**：递推循环不执行，仅靠基例输出 `[0]`。
4. **`left` 先用后加**：见 §4 第 2 点。以 `"110"` 为例，$i=1$ 时正确的 `left = 1`，若先加后用则 `left = 2`，算出 `answer[1] = 3` 而非 `1`。
5. **漏算基例 `answer[0]`**：递推没有起点会整体输出全 0；`answer[0]` 必须单独用「球位置之和」算出。
6. **数值范围**：$n \le 2000$ 时答案上界约 $n^2/4 = 10^6$，`int` 足够；若 $n$ 放大到 $10^5$ 级别需 `long long`（Python 无虞）。
7. **字符比较**：`boxes` 是字符串，C++ / Python 都是与 `'1'` 比较；Python 中 `boxes[i] == 1` 恒为 `False`，导致输出全 0。
8. **不要真的「移动」球**：每个 `answer[i]` 按初始状态独立计算，全程只做计数，绝不能在递推过程中修改 `boxes`。
