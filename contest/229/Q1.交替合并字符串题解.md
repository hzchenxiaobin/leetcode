# LeetCode 交替合并字符串 题解

## 1. 题目概述

- **标题 / 题号**：交替合并字符串（#1768，easy）
- **链接**：https://leetcode.cn/problems/merge-strings-alternately/
- **来源**：LeetCode 第 229 场周赛 Q1
- **难度**：简单
- **标签**：双指针、字符串

**题意**：给定两个字符串 `word1` 和 `word2`，从 `word1` 开始**交替**取字符拼接：先取 `word1[0]`，再取 `word2[0]`，再取 `word1[1]`，再取 `word2[1]`……若某一串先取尽，则把另一串**剩余字符整体追加**到末尾。返回合并后的字符串。

**约束**：

- $1 \le \text{word1.length}, \text{word2.length} \le 100$
- `word1` 和 `word2` 均由小写英文字母组成

> 💡 **快速切入**：签到题，读题 30 秒定位为「归并式模拟」。关键结构是「按位轮取」——第 $k$ 轮固定先取 `word1[k]` 再取 `word2[k]`，**没有任何选择自由度**，比「合并两个有序链表」少了比较决策，因此可以更简单。

## 2. 示例

**示例 1**

```text
输入：word1 = "abc", word2 = "pqr"
输出："apbqcr"
解释：两串等长，严格交替：a p b q c r。
```

**示例 2**

```text
输入：word1 = "ab", word2 = "pqrs"
输出："apbqrs"
解释：交叠段 a p b q 之后 word1 取尽，word2 剩余 "rs" 直接追加。
```

**示例 3**

```text
输入：word1 = "abcd", word2 = "pq"
输出："apbqcd"
解释：交叠段 a p b q 之后 word2 取尽，word1 剩余 "cd" 直接追加。
```

## 3. 解题思路

### 3.1 暴力思路：双指针 + 两阶段

最直觉的写法是维护两个独立指针 $i, j$：第一阶段「两串都未取尽」时严格交替追加；第二阶段把未尽串的尾巴整体拼上。

```text
i, j = 0, 0
res = []
while i < n1 and j < n2:          # 交叠段
    res.append(word1[i]); i += 1
    res.append(word2[j]); j += 1
res.append(word1[i:])             # 尾段（其一必为空）
res.append(word2[j:])
return "".join(res)
```

时间 $O(n_1 + n_2)$、空间 $O(1)$（不计输出），$n \le 100$ 下轻松通过。作为签到题这已经能 AC，但写法上分了两阶段，且 $i, j$ 各自递增、相互独立。

> ⚠️ **症结（仅写法层面）**：交叠段里 $i, j$ 每轮各 +1，**永远同步前进**，故 $i = j$ 恒成立——维护两个永远相等的指针是冗余；「交叠段」与「尾段」本质都是「按位取字符」，被人为拆成两套逻辑。

### 3.2 核心观察：同步指针塌缩为单索引 k

![核心观察：同步双指针塌缩为单索引 k，两个 if 判界守卫统一两阶段](images/wc229_q1_single_index_concept.svg)

关键洞察：第 $k$ 轮要追加的字符就是 `word1[k]`（若存在）和 `word2[k]`（若存在）。既然 $i = j = k$ 恒成立，就**只保留一个索引 $k$**：遍历 $k = 0, 1, \ldots, \max(n_1, n_2) - 1$，每轮做两次**条件追加**：

$$
\text{if } k < n_1:\ \text{res} \mathrel{+}= \text{word1}[k]; \qquad \text{if } k < n_2:\ \text{res} \mathrel{+}= \text{word2}[k]
$$

- **交叠段**（$k < \min(n_1, n_2)$）：两个条件都成立，每轮追加 2 个字符；
- **剩余段**（$\min(n_1, n_2) \le k < \max(n_1, n_2)$）：仅长串的条件成立，每轮追加 1 个字符。

尾段处理被两个 `if` 的越界守卫自然吸收，**无需任何特判**。

> 💡 **可迁移判据**：当两个指针以相同速率推进时必然相等，可合并成一个——「同步归并」的通用判据。对照 [21. 合并两个有序链表](https://leetcode.cn/problems/merge-two-sorted-lists/)：那里两指针**不同速**（谁小谁先走），无法塌缩，必须保留双指针。本题的「严格交替」正是同速的保证。

### 3.3 算法流程

![算法流程：单索引 k 一轮循环，两个独立 if 判界追加](images/wc229_q1_flow.svg)

1. **初始化**：`res = []`，`k = 0`，记 $n_1, n_2$ 为两串长度；
2. **循环**：当 $k < \max(n_1, n_2)$：
   - 若 $k < n_1$，追加 `word1[k]`；
   - 若 $k < n_2$，追加 `word2[k]`；
   - `k += 1`；
3. **终止**：返回 `"".join(res)`。

每轮 $O(1)$，共 $\max(n_1, n_2)$ 轮。

### 3.4 示例演算

以示例 2 `word1 = "ab"`（$n_1 = 2$）、`word2 = "pqrs"`（$n_2 = 4$）为例：

![示例演算：word1 取尽后 word2 尾巴自动落位，全程一个循环](images/wc229_q1_walkthrough.svg)

| $k$ | `word1[k]` | `word2[k]` | 本轮追加 | `res` 累积 |
|-----|-----------|-----------|----------|------------|
| $0$ | `a` | `p` | `a, p` | `ap` |
| $1$ | `b` | `q` | `b, q` | `apbq` |
| $2$ | ∅ 越界 | `r` | `r` | `apbqr` |
| $3$ | ∅ 越界 | `s` | `s` | `apbqrs` |

- 交叠段 $k = 0, 1$：两个 `if` 都触发，每轮 +2 字符；
- 剩余段 $k = 2, 3$：`k < n1` 不成立，`word1` 的追加被守卫跳过，仅追加 `word2` 字符——走的是**同一段代码**，只是其中一个 `if` 不触发；
- 最终 `"apbqrs"` ✓

## 4. 算法细节

1. **循环上界取 $\max(n_1, n_2)$ 而非 $\min$**：保证长串的尾部字符也能进入循环，由各自的 `if` 守卫决定是否追加——这是「单循环统一两阶段」的关键。
2. **两个 `if` 相互独立、顺序固定**：先判 `k < n1` 追加 `word1[k]`，再判 `k < n2` 追加 `word2[k]`，顺序不可颠倒（题面要求「从 `word1` 开始」）。
3. **Python 惯用法**：用 `list.append` + 末尾 `"".join`，避免循环内 `str +=` 反复建串（$O(n^2)$ 风险，虽然 $n \le 100$ 无感，但是好习惯）。
4. **C++ 惯用法**：`res.reserve(n1 + n2)` 一次性预分配，避免 `push_back` 扩容拷贝。
5. **一行流**（Python）：`itertools.zip_longest(word1, word2, fillvalue="")` 用空串填补短串缺失位，与下标判界**语义同构**。

## 5. 正确性证明

**引理 1（结果刻画）**：设 $n_1 = |\text{word1}|$，$n_2 = |\text{word2}|$，$m = \min(n_1, n_2)$。题目要求的合并串唯一，且等于

$$
\prod_{k=0}^{m-1} \big(\text{word1}[k] \cdot \text{word2}[k]\big) \;+\; T
$$

其中 $T$ 为较长串自下标 $m$ 起的剩余后缀（较短串取尽时较长串的尾巴）。

**证明**：「交替添加」在两串均有剩余时，每轮固定先取 `word1` 的下一字符、再取 `word2` 的下一字符，无任何选择余地，故前 $2m$ 个字符按上述配对唯一确定。一串取尽后，另一串剩余字符按原顺序整体追加，恰为 $T$。∎

**引理 2（循环行为）**：单索引循环在第 $k$ 轮（$0 \le k < \max(n_1, n_2)$）中，当且仅当 $k < n_1$ 时先追加 $\text{word1}[k]$；当且仅当 $k < n_2$ 时再追加 $\text{word2}[k]$。

**证明**：循环体是两个顺序执行的带守卫追加，由 `if k < n1` / `if k < n2` 的布尔判定直接得出。∎

**定理**：算法返回的串等于题目要求的合并串。

**证明**：由引理 2，对每个 $k < m$ 两条件均成立，本轮追加 $\text{word1}[k]$、$\text{word2}[k]$，与引理 1 中第 $k$ 个配对块逐字符一致；对 $m \le k < \max(n_1, n_2)$，仅较长串的条件成立，本轮恰追加较长串下标 $k$ 的字符，即 $T$ 的第 $k - m + 1$ 个字符（按序对齐）。总追加字符数为 $2m + (\max(n_1, n_2) - m) = n_1 + n_2$，与两串长度和相等，无遗漏无重复。故输出与引理 1 刻画的串逐字符相同。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n_1 + n_2)$。循环 $\max(n_1, n_2)$ 轮，每轮至多追加 2 个字符，总追加数恰为 $n_1 + n_2$；拼串/连接为线性。
- **空间复杂度**：$O(1)$ 辅助空间（仅索引与常数变量；不计输出串，若计入则为 $O(n_1 + n_2)$）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    string mergeAlternately(string word1, string word2) {
        int n1 = word1.size(), n2 = word2.size();
        string res;
        res.reserve(n1 + n2);
        for (int k = 0; k < max(n1, n2); ++k) {
            if (k < n1) res.push_back(word1[k]);
            if (k < n2) res.push_back(word2[k]);
        }
        return res;
    }
};
```

### Python

```python
class Solution:
    def mergeAlternately(self, word1: str, word2: str) -> str:
        n1, n2 = len(word1), len(word2)
        res = []
        for k in range(max(n1, n2)):
            if k < n1:
                res.append(word1[k])
            if k < n2:
                res.append(word2[k])
        return "".join(res)
```

> ⚠️ **别用 `zip(word1, word2)`**：`zip` 在较短串处**截断**，会丢掉较长串的尾部，还须另写补尾代码，反而退化回 3.1 的两阶段写法。单循环请用 `range(max(n1, n2))` + 下标判界；若要一行流，用 `itertools.zip_longest(word1, word2, fillvalue="")`。

## 8. 边界情况与易错点

1. **两串等长**（示例 1）：循环每轮两个 `if` 都触发，无需单独处理——「尾段长度为 0」被守卫自然吸收。
2. **word1 更长 / word2 更长**（示例 3 / 示例 2）：两种方向对称，同一循环天然兼容，**不要**为「谁更长」写 if-else 分支。
3. **追加顺序不可颠倒**：必须先 `word1[k]` 后 `word2[k]`——题面明确「从 word1 开始」，顺序反了示例 1 就变成 `"paqbrc"`。
4. **Python `zip` 截断陷阱**：见上文警告，短串尾部会静默丢失，属于典型 WA 点。
5. **循环内字符串拼接**：Python 中 `res += ch` 逐次建串是 $O(n^2)$ 写法，用列表收集再 `join`；C++ 用 `reserve` 预分配后 `push_back`。
6. **下标越界**：剩余段中 `k ≥ n1`（或 `k ≥ n2`）时必须由 `if` 守卫拦下，直接取 `word1[k]` 会越界——守卫本身就是「尾段处理」。
7. **约束保证 $n \ge 1$**：无空串；即便允许空串，本写法也天然兼容（循环退化为整串拷贝另一串）。
