# LeetCode 由子序列构造的最长回文串的长度 题解

## 1. 题目概述

- **标题 / 题号**：由子序列构造的最长回文串的长度（#1771，hard）
- **链接**：https://leetcode.cn/problems/maximize-palindrome-length-from-subsequences/
- **来源**：LeetCode 第 229 场周赛 Q4
- **难度**：困难
- **标签**：字符串、动态规划

**题意**：给定两个小写字母串 `word1` 和 `word2`。分别从中各选一个**非空**子序列 $s_1$、$s_2$，按顺序拼接成 $s_1 + s_2$。问拼出的串是回文串时，长度的最大值是多少；若无法构造出回文串，返回 $0$。

**约束**：

- $1 \le |\text{word1}|, |\text{word2}| \le 1000$
- 两个串均只含小写英文字母

> 💡 **关键约束**：两串总长 $N \le 2000$，恰好容纳 $O(N^2) \approx 4 \times 10^6$ 状态的区间 DP。而题面中「**非空**」二字是全题最大的陷阱：若无此约束，问题就是「拼接串的最长回文子序列（LPS）」；正是它要求答案必须**跨越两段的分界**，也催生了本题与模板题 516 之间唯一但致命的改造。

## 2. 示例

**示例 1**

```text
输入：word1 = "cacb", word2 = "cbba"
输出：5
解释：从 word1 中选出 "ab"，从 word2 中选出 "cba"，拼接得到回文串 "abcba"。
```

**示例 2**

```text
输入：word1 = "ab", word2 = "ab"
输出：3
解释：从 word1 中选 "ab"、word2 中选 "a"，拼出回文串 "aba"。
```

**示例 3**

```text
输入：word1 = "aa", word2 = "bb"
输出：0
解释：两串无公共字符，任何拼接都不可能是回文串。
```

**示例 4（自造：直接求 LPS 的陷阱）**

```text
输入：word1 = "aba", word2 = "xyz"
输出：0
解释：s = "abaxyz" 的 LPS 是 "aba"（长 3），但它整段落在 word1 内、word2 的子序列为空，不合法；
      两段无公共字符，凑不出一对「分属两段且相等」的端点，故答案为 0。
```

## 3. 解题思路

### 3.1 暴力思路：枚举子序列组合

组合视角的暴力：`word1` 有 $2^{n}-1$ 个非空子序列、`word2` 有 $2^{m}-1$ 个，两两拼接共约 $2^{n+m}$ 种组合，每种判回文花 $O(N)$。$n = m = 1000$ 时组合数是 $2^{2000}$ 量级，彻底不可行。

更隐蔽的坑是想「分而治之」：先分别求出两段各自的最长回文子序列，再以某种方式拼起来。**这条路从根上就不成立**——回文的对称结构可以横跨分界，两侧互为镜像：

```text
word1 = "ab",  word2 = "ba"
LPS(word1) = 1,  LPS(word2) = 1  →  各自之和只有 2
但 "ab" + "ba" = "abba" 是长度 4 的合法回文！
```

分界两侧的字符通过「镜像关系」彼此耦合，任何只看单段内部的预处理都无法捕捉这种配对——必须把两段放进**同一个** DP 状态里整体考虑。

### 3.2 核心观察：拼接成一条串，「非空」=「跨越分界」

![核心观察：拼接成一条串，非空约束等价于回文跨越分界](images/wc229_q4_concat_concept.svg)

**第一步：消掉「两个子序列」。** 把两串首尾拼接成

$$s = \text{word1} + \text{word2},\qquad n = |\text{word1}|,\ N = |s|$$

任取 $s_1$（`word1` 的子序列）与 $s_2$（`word2` 的子序列），拼接 $s_1 + s_2$ 恰是 $s$ 的一个「前段子序列 + 后段子序列」；反过来，$s$ 的任何子序列按分界下标 $n$ 拆开也得到这样一对。于是：

> **「$s_1 + s_2$（允许为空）」=「$s$ 的子序列」**——两段各选子序列的组合，被一条串的子序列完美编码。

若没有非空约束，答案就是 $s$ 的**最长回文子序列** $\text{LPS}(s)$——经典区间 DP，$O(N^2)$ 直接可做。

**第二步：非空约束的代价。** 约束要求两段各至少贡献一个字符，即回文必须**跨越分界** $n$。于是「直接返回 $\text{dp}[0][N-1]$」成为本题最经典的 WA（见示例 4）：全局 LPS 可能整段落在一侧，此时它对应的 `word2` 子序列是空串，不合法；而合法的较短跨越回文又要另行寻找。

**第三步：跨越的结构刻画。** 设合法回文 $T = s_1 + s_2$（$s_1$、$s_2$ 非空）。把 $T$ 的字符映射回 $s$ 中被选中的位置：首字符必然落在前段某位置 $i < n$（它是 $s_1$ 的首字符），尾字符必然落在后段某位置 $j \ge n$（它是 $s_2$ 的尾字符）。而 $T$ 是回文，首尾字符相等，即 $s[i] = s[j]$：

$$\boxed{\ \text{ans} = \max_{s[i] = s[j],\ i < n \le j} \text{dp}[i][j]\ }$$

其中 $\text{dp}[i][j]$ 是 $s[i..j]$ 的 LPS 长度——由于 $s[i] = s[j]$，它可以取成**以 $s[i]$ 开头、$s[j]$ 结尾**（§5 引理 1），首尾两个字符恰好分别来自两段，非空约束自动满足；中间字符随意分属两段，不受任何约束。反过来（§5 引理 2），任何合法回文都形如「前段某字符 + 中间 + 后段某字符（值相等）」，长度不超过某个 $\text{dp}[i][j]$。

区间 DP 本来就要遍历所有 $(i, j)$，在 $s[i] = s[j]$ 且 $i < n \le j$ 时顺手打擂台即可——**零额外开销**。

### 3.3 算法流程：区间 DP + 端点对打擂台

![算法流程：区间 DP 转移，仅在相等分支且端点跨界时更新答案](images/wc229_q4_interval_dp_flow.svg)

**状态**：$\text{dp}[i][j]$ = $s[i..j]$ 的最长回文子序列长度（约定 $i > j$ 时为 $0$，$i = j$ 时为 $1$）。

**转移**（$i$ 从大到小、$j$ 从小到大枚举）：

- $s[i] = s[j]$：$\text{dp}[i][j] = \text{dp}[i+1][j-1] + 2$；此时若 $i < n \le j$，用 $\text{dp}[i][j]$ 更新 $\text{ans}$；
- $s[i] \ne s[j]$：$\text{dp}[i][j] = \max(\text{dp}[i+1][j],\ \text{dp}[i][j-1])$。

**答案**：$\text{ans}$（初始 $0$；若无任何满足条件的端点对则保持 $0$）。

**实现要点**：

1. **更新只在相等分支做**：$s[i] \ne s[j]$ 时的 $\text{dp}[i][j]$ 是「不强制端点」的 LPS，首尾未必落在两段，不能用来更新答案；
2. **$j = i+1$ 无需特判**：此时 $\text{dp}[i+1][j-1] = \text{dp}[i+1][i]$ 是下三角的初始 $0$，语义恰为「空区间的 LPS = 0」；
3. 相等分支中 $i < n \le j$ 时必有 $\text{dp}[i][j] \ge 2$：$s_1$ 至少含 $s[i]$、$s_2$ 至少含 $s[j]$，非空自动成立。

### 3.4 示例演算：示例 1 的端点对打擂台

![示例演算：cacb 与 cbba 拼接后各端点对的 dp 值与最优构造](images/wc229_q4_walkthrough.svg)

以示例 1 为例，$s ={}$ `cacb` $|{}$ `cbba`（$|$ 为分界，$n = 4$）。满足 $s[i] = s[j]$ 且 $i < n \le j$ 的端点对共 5 个：

| 端点对 $(i, j)$ | 字符 | $\text{dp}[i][j]$ | 强制端点构成的回文 |
|---|---|---|---|
| $(0, 4)$ | c = c | $3$ | `cac` |
| $(1, 7)$ | a = a | $\mathbf{5}$ | `abcba` |
| $(2, 4)$ | c = c | $3$ | `cbc` |
| $(3, 5)$ | b = b | $3$ | `bcb` |
| $(3, 6)$ | b = b | $3$ | `bcb` |

最优端点对 $(1, 7)$：$\text{dp}[1][7] = \text{dp}[2][6] + 2$，而 $\text{dp}[2][6] = 3$（`bcb`），拼上两端相等的 `a` 得 `abcba`。按分界拆开：`a`(1)、`b`(3) 来自 `word1`（子序列 `ab`），`c`(4)、`b`(5)、`a`(7) 来自 `word2`（子序列 `cba`），与示例解释完全一致。

> ⚠️ 顺带一提：本例 $\text{dp}[0][7] = \text{LPS}(s) = 5$ 恰好等于答案——全局 LPS 本身取到了跨越版本。但这只是巧合：dp 表并不记录构成信息，「LPS 是否可跨越」无从判断（见示例 4 的反例），所以「直接返回 $\text{dp}[0][N-1]$」不可靠，跨界打擂台才是普适做法。

## 4. 算法细节

1. **拼接与分界的表示**：分界用下标 $n$ 判定（条件 $i < n \le j$），**不要**在两串之间插入哨兵字符（如 `#`）——哨兵会切断跨段匹配，恰好杀掉所有合法解；而且 LPS 整段落在一侧的问题它同样无能为力。
2. **遍历顺序**：$i$ 从 $N-1$ 递减、$j$ 从 $i+1$ 递增，保证计算 $\text{dp}[i][j]$ 时 $\text{dp}[i+1][\cdot]$ 整行已算完、$\text{dp}[i][j-1]$ 已算完。等价写法是按区间长度 $j - i$ 从小到大枚举。
3. **初始化**：$\text{dp}[i][i] = 1$ 需单独赋值；若让 $j$ 从 $i$ 开始走相等分支，会访问 $\text{dp}[i+1][i-1]$ 越界。
4. **与模板题 516 的唯一实质差异**：就是相等分支里那句 `if (i < n && j >= n)` 打擂台——其余部分原封不动是 LPS 模板。
5. **空间**：$N \le 2000$，`int` 二维表 $2000 \times 2000 \times 4\text{B} \approx 16\text{MB}$，通常可接受；卡内存时可换 `short`（$\text{dp} \le N < 2^{15}$，8MB）或滚动成一维——$j$ 正序遍历时 `dp[j]` 恰好保存着上一行（$i+1$ 行）的值，用临时变量携带 $\text{dp}[i+1][j-1]$ 即可。
6. **Python 实现注意**：$4 \times 10^6$ 次内层循环必须用迭代数组；不要用 `lru_cache` 递归（常数大，且递归深度达 $N = 2000$ 会超默认上限）。

## 5. 正确性证明

**引理 1（端点引理）**：若 $s[i] = s[j]$（$i < j$），则 $\text{dp}[i][j] = \text{dp}[i+1][j-1] + 2$（$i+1 > j-1$ 时约定 $\text{dp} = 0$），且 $s[i..j]$ 存在一个**以位置 $i$、$j$ 为首尾**的最长回文子序列。

**证明**：一方面，取 $s[i+1..j-1]$ 的 LPS $P$（长 $\text{dp}[i+1][j-1]$），两端各拼上一个字符：$s[i]$ 与 $s[j]$ 值相等，且位置 $i$、$j$ 分别在 $P$ 所有选取位置的两侧，故得到 $s[i..j]$ 的回文子序列，长 $\text{dp}[i+1][j-1] + 2$，即 $\text{dp}[i][j] \ge \text{dp}[i+1][j-1] + 2$。另一方面，设 $P$ 为 $s[i..j]$ 的任一 LPS，选取位置 $p_1 < p_2 < \cdots < p_L$。由前一方向知 $\text{dp}[i][j] \ge 2$，故 $L \ge 2$。把 $P$ 的首尾选取位置换成 $i$、$j$：中间部分（选取位置 $p_2, \ldots, p_{L-1}$，全部落在 $[i+1, j-1]$ 内）是回文去掉首尾，仍为回文；两端 $s[i] = s[j]$ 相等，故

$$P' = s[i] + P[1..L-2] + s[j]$$

是与 $P$ 等长的回文子序列，且以 $i$、$j$ 为首尾。其去掉两端后是 $s[i+1..j-1]$ 的回文子序列，故 $L - 2 \le \text{dp}[i+1][j-1]$，即 $\text{dp}[i][j] \le \text{dp}[i+1][j-1] + 2$。两个方向合并，等号成立，且 $P'$ 即所需构造。∎

**引理 2（合法解的端点刻画）**：设 $T = s_1 + s_2$ 为合法构造（$s_1$、$s_2$ 均非空）且 $T$ 为回文，则存在 $i < n \le j$ 满足 $s[i] = s[j]$ 且 $|T| \le \text{dp}[i][j]$。

**证明**：固定 $T$ 到 $s$ 的一组选取位置（$s_1$ 的字符映到 $[0, n)$，$s_2$ 的映到 $[n, N)$，全体单调递增）。设首、尾字符分别映到位置 $i$、$j$。由 $s_1$、$s_2$ 非空知 $i < n \le j$。$T$ 是回文，首尾字符相等，故 $s[i] = s[j]$。$T$ 去掉首尾（若非空）是 $s[i+1..j-1]$ 的回文子序列，故 $|T| \le 2 + \text{dp}[i+1][j-1]$；再由引理 1（$s[i] = s[j]$）得 $|T| \le \text{dp}[i][j]$。∎

**定理**：算法返回值 $A = \max\{\text{dp}[i][j] : 0 \le i < n \le j < N,\ s[i] = s[j]\}$（集合为空时 $A = 0$）等于最优答案。

**证明**：

- **（$A \le$ 最优答案）**：对集合中任一 $(i, j)$，由引理 1 取以 $i$、$j$ 为首尾的 LPS $P$；其选取位置按是否 $< n$ 分成前后两部分：前部含 $i$，非空，是 `word1` 的子序列；后部含 $j$，非空，是 `word2` 的子序列；两部分拼接恰为 $P$（位置单调递增）。故 $P$ 是合法构造，最优答案 $\ge |P| = \text{dp}[i][j]$。对所有 $(i, j)$ 取最大即得 $A \le$ 最优答案（集合为空时 $A = 0 \le$ 最优答案平凡成立）。
- **（最优答案 $\le A$）**：若最优答案为 $0$，显然成立；否则存在合法回文 $T$，由引理 2 给出满足条件的 $(i, j)$ 且 $|T| \le \text{dp}[i][j] \le A$。

两个方向合并即证。∎

## 6. 复杂度分析

- **时间复杂度**：$O(N^2)$，其中 $N = n + m \le 2000$。共约 $\frac{N(N-1)}{2} \approx 2 \times 10^6$ 个状态（区间对），每个 $O(1)$ 转移，打擂台不增加渐进开销。
- **空间复杂度**：$O(N^2)$（`int` 表约 16MB）。可滚动优化到 $O(N)$（见 §4 第 5 点），但二维写法依赖清晰、不易错，本题数据范围下无需强求。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int longestPalindrome(string word1, string word2) {
        string s = word1 + word2;
        int n = word1.size(), N = s.size();
        vector<vector<int>> dp(N, vector<int>(N, 0));
        for (int i = 0; i < N; ++i) dp[i][i] = 1;
        int ans = 0;
        for (int i = N - 1; i >= 0; --i) {
            for (int j = i + 1; j < N; ++j) {
                if (s[i] == s[j]) {
                    dp[i][j] = dp[i + 1][j - 1] + 2;   // j = i+1 时取下三角的 0 = 空区间
                    if (i < n && j >= n)               // 端点分属两段 → 非空约束成立
                        ans = max(ans, dp[i][j]);
                } else {
                    dp[i][j] = max(dp[i + 1][j], dp[i][j - 1]);
                }
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def longestPalindrome(self, word1: str, word2: str) -> int:
        s = word1 + word2
        n, N = len(word1), len(s)
        dp = [[0] * N for _ in range(N)]   # 切勿 [[0]*N]*N（行引用共享）
        for i in range(N):
            dp[i][i] = 1
        ans = 0
        for i in range(N - 1, -1, -1):
            for j in range(i + 1, N):
                if s[i] == s[j]:
                    dp[i][j] = dp[i + 1][j - 1] + 2
                    if i < n <= j:         # 端点分属两段 → 非空约束成立
                        ans = max(ans, dp[i][j])
                else:
                    dp[i][j] = max(dp[i + 1][j], dp[i][j - 1])
        return ans
```

## 8. 边界情况与易错点

1. **直接返回 $\text{dp}[0][N-1]$（最经典 WA）**：全局 LPS 可能整段落在一侧（示例 4：`"aba"` + `"xyz"` 得 LPS 为 3 但答案 0），dp 表不记录构成信息，无法事后判断是否跨越——必须在转移中打擂台。
2. **在 $s[i] \ne s[j]$ 分支更新答案**：此时的 $\text{dp}[i][j]$ 不保证以 $i$、$j$ 为端点，可能算出构造不出来的偏大值。
3. **打擂台条件缺一半**：只判 $i < n$ 或只判 $j \ge n$ 都会混入单侧端点对；必须 $i < n$ **且** $j \ge n$ 同时成立。
4. **哨兵拼接陷阱**：在两串之间插入 `#` 等特殊字符想「标记分界」或「阻断单侧匹配」，反而切断所有合法的跨越回文（见 §4 第 1 点）。
5. **对角线初始化与 $j$ 起点**：$j$ 从 $i+1$ 开始；$\text{dp}[i][i] = 1$ 单独赋值，混进循环会访问 $\text{dp}[i+1][i-1]$ 越界。
6. **遍历顺序颠倒**：$i$ 必须逆序（或按区间长度枚举），否则会读到尚未计算的 $\text{dp}[i+1][\cdot]$。
7. **空区间初值**：下三角（$i > j$）应视为 $0$ 而非 $-\infty$——$j = i+1$ 时 $\text{dp}[i][j] = 2$ 是合法值，哨兵设错会漏掉长度 2 的答案。
8. **两串无公共字符**：答案 $0$（示例 3），算法自然给出——无端点对满足条件，`ans` 保持初值。
9. **Python 行引用共享**：`[[0]*N]*N` 会让所有行指向同一 list，写一格等于写一列；必须用推导式逐行创建。
