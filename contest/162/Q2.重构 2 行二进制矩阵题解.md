# LeetCode 重构 2 行二进制矩阵 题解

## 1. 题目概述

- **标题 / 题号**：重构 2 行二进制矩阵（#1253，medium）
- **链接**：https://leetcode.cn/problems/reconstruct-a-2-row-binary-matrix/
- **来源**：LeetCode 第 162 场周赛 Q2
- **难度**：中等
- **标签**：贪心，数组，矩阵

**题意**：给定两个行和 `upper`、`lower` 和一个长度 $n$ 的列和数组 `colsum`，构造一个 $2 \times n$ 的二进制矩阵（元素只能是 0 或 1），使得第 0 行元素之和为 `upper`、第 1 行元素之和为 `lower`、第 $i$ 列元素之和为 `colsum[i]`。若存在多个合法矩阵，返回任意一个即可；若不存在，返回空的二维数组。

**约束**：

- $1 \le n = \text{colsum.length} \le 10^5$
- $0 \le \text{upper}, \text{lower} \le n$
- $0 \le \text{colsum}[i] \le 2$

## 2. 示例

**示例 1**

```text
输入：upper = 2, lower = 1, colsum = [1,1,1]
输出：[[1,1,0],[0,0,1]]
解释：[[1,0,1],[0,1,0]] 和 [[0,1,1],[1,0,0]] 也是正确答案。
```

**示例 2**

```text
输入：upper = 2, lower = 3, colsum = [2,2,1,1]
输出：[]
解释：两列 colsum = 2 强制两行各写 2 个 1，上行额度 2 刚好被吃满（u = 0）、
      下行还剩 1 个（l = 1）；但后面还有 2 个单独的 1 要放，u + l = 1 ≠ cnt1 = 2，故无解。
```

**示例 3**

```text
输入：upper = 5, lower = 5, colsum = [2,1,2,0,1,0,1,2,0,1]
输出：[[1,1,1,0,1,0,0,1,0,0],[1,0,1,0,0,0,1,1,0,1]]
解释：3 列和为 2、4 列和为 1、3 列和为 0；两行各剩 2 个额度分给那 4 个单独的 1。
```

## 3. 解题思路

### 3.1 暴力思路

每一列的 `colsum[i]` 决定了这列的取值只有几种可能：为 0 时只能 $(0,0)$，为 2 时只能 $(1,1)$，为 1 时可以是 $(1,0)$ 或 $(0,1)$。于是最朴素的搜索是：枚举所有 `colsum[i] = 1` 的列把那个 1 放上行还是放下行，共 $2^{\text{cnt1}}$ 种方案，逐一检查行和。

$n$ 最大 $10^5$，`cnt1` 可以接近 $n$，$2^{\text{cnt1}}$ 是天文数字；即使是把问题看成 $2n$ 个 0/1 变量加 2 个行和约束、$n$ 个列和约束的整数规划，也没有高效的通用做法。必须利用**列和只有 0/1/2 三个取值**这一特殊结构。

### 3.2 核心观察：0 列与 2 列没有自由度

![列把每列的形态锁死，只有 colsum=1 可自由分配](images/wc162_q2_colsum_structure.svg)

把每一列单独拿出来看：

- `colsum[i] = 0`：两个元素都是 0，**没有选择**，也不消耗任何行和额度。
- `colsum[i] = 2`：两个元素都是 1，**没有选择**，但会同时消耗上、下两行各 1 个额度。
- `colsum[i] = 1`：恰好一个 1，这个 1 **可以**放上行，**也可以**放下行。

所以整道题的**自由度只有一个**：`cnt1` 个「单独的 1」怎么在上下两行之间分配。其余部分全被题面钉死。

设 `cnt2` 为列和为 2 的列数、`cnt1` 为列和为 1 的列数。两行被 2 列强制占用的 1 各有 `cnt2` 个，因此剩余可分配的额度是

$$u = \text{upper} - \text{cnt2}, \qquad l = \text{lower} - \text{cnt2}$$

而所有 1 的总数必须守恒：整个矩阵的 1 的个数既等于 `upper + lower`，也等于 $2\,\text{cnt2} + \text{cnt1}$，于是

$$\text{upper} + \text{lower} = 2\,\text{cnt2} + \text{cnt1} \iff u + l = \text{cnt1}$$

这就是**唯一的可行性判据**，再配上 $u \ge 0$、$l \ge 0$（即 `upper ≥ cnt2`、`lower ≥ cnt2`）。满足判据后，把 `cnt1` 个 1 中任意 $u$ 个丢给上行、剩下 $l$ 个丢给下行，就一定能构造成功——不需要搜索。

### 3.3 算法流程：统计 → 判据 → 贪心填写

![算法流程：统计、两条判据、贪心填写](images/wc162_q2_greedy_flow.svg)

具体做法分四步：

1. **一次遍历统计** `cnt2`、`cnt1`（`colsum[i] = 0` 的列不参与计算）。
2. **判据一**：若 `upper < cnt2` 或 `lower < cnt2`，返回 `[]`。
3. **判据二**：令 $u = \text{upper} - \text{cnt2}$、$l = \text{lower} - \text{cnt2}$，若 $u + l \ne \text{cnt1}$，返回 `[]`。
4. **贪心填写**：从左到右扫一遍，遇到 `colsum[i] = 2` 两行都写 1；遇到 0 两行都写 0；遇到 1 时「上行还有额度就写上行的，否则写下行的」。

第 4 步的「先灌满上行」是关键：它让 $u$ 单调递减到 0 之后不再回升，因此**只需要顺扫一遍、不需要回溯**，也不会出现「上行还剩额度但后面的 1 都填到了下行」这种浪费。由守恒式 $u + l = \text{cnt1}$，上行吃掉 $u$ 个 1 之后，剩下的 $\text{cnt1} - u = l$ 个 1 恰好填满下行，两行同时收满。

### 3.4 示例演算

![示例 3 逐列填写与额度消耗](images/wc162_q2_walkthrough.svg)

对示例 3：`upper = 5`、`lower = 5`、`colsum = [2,1,2,0,1,0,1,2,0,1]`。

- 统计得 `cnt2 = 3`（第 0、2、7 列），`cnt1 = 4`（第 1、4、6、9 列）。
- 判据：$u = 5 - 3 = 2$，$l = 5 - 3 = 2$，$u + l = 4 = \text{cnt1}$ ✓。
- 填写：第 0、2、7 列两行都写 1；第 3、5、8 列两行都写 0；第 1 列写上行（$u:2\to1$），第 4 列写上行（$u:1\to0$），此后第 6 列只能写下行（$l:2\to1$），第 9 列写下行（$l:1\to0$）。

最终第 0 行为 `[1,1,1,0,1,0,0,1,0,0]`、第 1 行为 `[1,0,1,0,0,0,1,1,0,1]`，行和均为 5，逐列和与原 `colsum` 完全一致，与官方输出相同。

## 4. 算法细节

1. **先判 capacity 再判守恒**：`upper ≥ cnt2`、`lower ≥ cnt2` 必须单独判，因为若 `upper < cnt2`，则 $u < 0$，此时即使 $u + l = \text{cnt1}$ 也可能成立（比如 `upper = 0, lower = 4, colsum = [2,2]`，$u=-2$、$l=2$、$u+l=0=\text{cnt1}$），但答案显然不存在。负数额度是这类「守恒式」题最常见的漏判。
2. **守恒式可以用总和写**：也可以直接判 $\sum_i \text{colsum}[i] = \text{upper} + \text{lower}$，两者等价；但写成 $u + l = \text{cnt1}$ 能直接给出剩余的分配量，更贴合构造过程。
3. **两种一次遍历的写法**：可以先统计再填写（两趟循环，$O(1)$ 额外空间），也可以在填写时边填边扣额度、最后检查 `upper == 0 && lower == 0`。后者更短，但「判据缺失」的错误更难发现，建议保留显式判据。
4. **填 1 的顺序无关**：把哪些 `colsum[i] = 1` 的列分给上行，对合法性没有影响，只要总数为 $u$ 即可。因此选「最左边 $u$ 个」这种最省事的策略即可，不需要排序或优先队列。
5. **矩阵初始化**：直接开 $2 \times n$ 的全 0 矩阵，`colsum = 0` 的列无需任何操作。C++ 写 `vector<vector<int>>(2, vector<int>(n, 0))`，外层 2 是行数、内层 $n$ 是列数，写反会得到 $n \times 2$ 的矩阵并导致越界；Python 必须写 `[[0] * n for _ in range(2)]`。
6. **不要真的去枚举**：很多人第一反应是 DFS 枚举每列的 0/1 分配，$n = 10^5$ 时必然超时；本题本质是**构造题**，只要判据对，构造是 $O(n)$ 的。

## 5. 正确性证明

**引理 1（0/2 列被迫）**：在任意合法矩阵中，若 `colsum[i] = 0`，则该列两行均为 0；若 `colsum[i] = 2`，则该列两行均为 1。

**证明**：一列只有两个元素且每个元素属于 $\{0,1\}$，列和为 0 只能是 $(0,0)$，列和为 2 只能是 $(1,1)$，取值唯一。∎

**引理 2（必要条件）**：若存在合法矩阵，则必有 `upper ≥ cnt2`、`lower ≥ cnt2`，且 $u + l = \text{cnt1}$。

**证明**：由引理 1，每个 `colsum = 2` 的列对上、下两行各贡献 1，共 `cnt2` 个，故第 0 行至少有 `cnt2` 个 1，即 `upper ≥ cnt2`；同理 `lower ≥ cnt2`。又整个矩阵的 1 的总数既等于 `upper + lower`，也等于 $2\,\text{cnt2} + \text{cnt1}$（按列统计），两式相减得 $\text{upper} + \text{lower} - 2\,\text{cnt2} = \text{cnt1}$，即 $u + l = \text{cnt1}$。∎

**引理 3（贪心填满）**：在引理 2 的条件成立时，按 3.3 的贪心策略填写，扫完全部列后必有 `upper` 与 `lower` 同时归零。

**证明**：贪心只对 `colsum[i] = 1` 的列做选择，且每次都是「上行有额度就用上行」。设共有 `cnt1` 个这样的列，其中前 $\min(u, \text{cnt1})$ 个被放进上行。由 $u \ge 0$ 与 $u + l = \text{cnt1}$ 得 $u \le \text{cnt1}$，故恰好有 $u$ 个 1 进入上行，上行剩余额度从 $u$ 减到 0；剩下 $\text{cnt1} - u = l$ 个 1 全部进入下行，下行剩余额度从 $l$ 减到 0。`colsum = 2` 的列由构造同时扣减两行额度各 1，与引理 1 一致，且这类列的数量恰为 `cnt2`，正好与初始扣减相抵。故扫完后两行额度均为 0。∎

**定理**：算法返回的矩阵合法；当且仅当存在合法矩阵时算法返回非空结果。

**证明**：合法性：由引理 3，两行 1 的个数分别为 `upper` 和 `lower`；每一列的取值按 `colsum[i]` 分别取 $(0,0)$、$(1,1)$、$(1,0)/(0,1)$，列和恒等于 `colsum[i]`，且元素只取 0/1，故矩阵合法。正确性（不漏解）：若存在合法矩阵，由引理 2 两条判据均通过，算法不会返回 `[]`；若某条判据不通过，由引理 2 的逆否命题知合法矩阵不存在，返回 `[]` 正确。∎

## 6. 复杂度分析

- **时间**：$O(n)$。统计 `cnt1`、`cnt2` 一趟 $O(n)$，判据 $O(1)$，填写再一趟 $O(n)$，每列只做常数次比较与赋值；总计线性。
- **空间**：$O(1)$ 额外空间（不计返回值）。若返回矩阵算作输出，则为 $O(n)$，这是题目要求的答案规模，不可避免。

## 7. 参考代码

### C++

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    vector<vector<int>> reconstructMatrix(int upper, int lower, vector<int>& colsum) {
        int n = colsum.size();
        int cnt2 = 0, cnt1 = 0;
        for (int c : colsum) {
            if (c == 2) cnt2++;
            else if (c == 1) cnt1++;
        }
        // 判据一：两行都必须承担 cnt2 个 1
        if (upper < cnt2 || lower < cnt2) return {};
        int u = upper - cnt2, l = lower - cnt2;
        // 判据二：剩余额度之和必须等于可自由分配的 1 的个数
        if (u + l != cnt1) return {};

        vector<vector<int>> res(2, vector<int>(n, 0));
        for (int i = 0; i < n; i++) {
            if (colsum[i] == 2) {
                res[0][i] = res[1][i] = 1;          // 两行都被迫为 1
            } else if (colsum[i] == 1) {
                if (u > 0) { res[0][i] = 1; u--; }  // 先灌满上行
                else       { res[1][i] = 1; l--; }  // 上行满了再给下行
            }
        }
        return res;
    }
};
```

### Python

```python
from typing import List


class Solution:
    def reconstructMatrix(self, upper: int, lower: int, colsum: List[int]) -> List[List[int]]:
        n = len(colsum)
        cnt2 = colsum.count(2)      # 两行都必须为 1 的列数
        cnt1 = colsum.count(1)      # 恰好一个 1、可自由分配的列数
        if upper < cnt2 or lower < cnt2:
            return []               # 判据一：被迫承担的 1 已超出行和
        u, l = upper - cnt2, lower - cnt2
        if u + l != cnt1:
            return []               # 判据二：可分配的 1 数与剩余额度不守恒

        res = [[0] * n for _ in range(2)]
        for i, c in enumerate(colsum):
            if c == 0:
                continue
            if c == 2:
                res[0][i] = res[1][i] = 1
            elif u > 0:             # 先填上行，上行满了再填下行
                res[0][i] = 1
                u -= 1
            else:
                res[1][i] = 1
                l -= 1
        return res
```

## 8. 边界情况与易错点

1. **`upper` 或 `lower` 小于 `cnt2`**：如 `upper = 0, lower = 4, colsum = [2,2]`，守恒式 $u+l = \text{cnt1}=0$ 竟然成立（$u = -2$），但无解。必须先判 `upper ≥ cnt2 && lower ≥ cnt2`，否则会返回带负额度的错误矩阵（或数组越界）。
2. **只判总和相等不够**：`upper = 0, lower = 3, colsum = [2,1]` 中 $\sum \text{colsum} = 3 = \text{upper} + \text{lower}$，但第 0 行必须含 1，矛盾。总和守恒只是必要条件，容量约束不能省。
3. **`n = 1` 的退化情形**：`colsum = [0]` 时 `upper = lower = 0` 才合法，返回 `[[0],[0]]`；`colsum = [2]` 时需要 `upper = lower = 1`；`colsum = [1]` 时需要 `upper + lower = 1`，此时 `u` 或 `l` 为 1，只会写一行。
4. **返回 `[]` 而不是 `[[],[]]`**：无解时 LeetCode 期望空二维数组 `[]`，C++ 中写 `return {};`，Python 中写 `return []`；不要返回 `nullptr` 对应的 `{{}}`。
5. **`cnt1 = 0` 且 `u = l = 0`**：例如 `upper = lower = 2, colsum = [2,0,2,0]`，两行额度刚好被 2 列吃满，此时不应再有任何 1 被分配；贪心循环里 `colsum[i]=1` 的分支一次都不会进入，结果正确。
6. **Python 的 `[[0] * n] * 2` 陷阱**：两个子列表是同一个对象的引用，`res[0][i] = 1` 会同时改掉 `res[1][i]`，导致列和变成 2。必须写 `[[0] * n for _ in range(2)]`。
7. **大 `n` 的 I/O 常数**：$n = 10^5$ 时两趟 `for` 完全够用；若在循环里用 `colsum.count(...)`（$O(n)$ 每次）而不是一次性统计，会退化到 $O(n^2)$。
