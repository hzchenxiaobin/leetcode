# LeetCode 统计封闭岛屿的数目 题解

## 1. 题目概述

- **标题 / 题号**：统计封闭岛屿的数目（#1254，medium）
- **链接**：https://leetcode.cn/problems/number-of-closed-islands/
- **来源**：LeetCode 第 162 场周赛 Q3
- **难度**：中等
- **标签**：深度优先搜索、广度优先搜索、并查集、数组、矩阵

**题意**：给定 $m \times n$ 的网格 `grid`，`0` 表示陆地、`1` 表示水域（注意与常见的 200 题相反）。岛屿是由 `0` 组成的四方向（上下左右）极大连通块；若一个岛屿的每一格都被 `1` 从四周**完全**包围，也就是它不接触网格边界，则称它为**封闭岛**。返回封闭岛的个数。

**约束**：

- $1 \le \text{grid.length}, \text{grid[0].length} \le 100$
- `0 <= grid[i][j] <= 1`

## 3. 解题思路

### 3.1 暴力思路

最朴素的想法是**逐格判断**：若某个 `0` 的上下左右都是 `1`，就认为它是一个封闭岛。这在示例 1 上就会把答案算成 1——那一圈 10 格的环形岛内部明明全是水，却被整体漏掉了。原因是「封闭」约束的是**整个连通块**，而不是单个格子。

正确的暴力做法是枚举连通块：对每个尚未访问的 `0`，用 DFS/BFS 收集它所在的整块，同时检查块内是否有格子落在第 0 行、第 $m-1$ 行、第 0 列或第 $n-1$ 列，没有就计数加一。这样每个格子只处理一次，时间是 $O(mn)$，但需要一个 $m \times n$ 的 `visited` 数组；若为了省空间不给标记，让每个 `0` 都重新扩展一遍，最坏（整张图连成一块）会退化成 $O\bigl((mn)^2\bigr)$，即 $10^8$ 量级，既慢又难写对。

### 3.2 核心观察：贴边与否决定一切

![封闭岛的判据：连通块里有没有格子落在网格边界上](images/wc162_q3_boundary_lemma.svg)

**判据**：一个 `0` 连通块 $C$ 是封闭岛，当且仅当 $C$ 中没有任何格子处在网格边界上。

- **若 $C$ 有格子贴边**：该格子朝外的那个方向已经越出网格，那里既不是 `0` 也不是 `1`，当然谈不上「被 `1` 包围」，所以 $C$ 不是封闭岛。
- **若 $C$ 没有格子贴边**：$C$ 是所有 `0` 的极大连通块，所以任何与 $C$ 相邻却不属于 $C$ 的格子都不可能是 `0`，只能是 `1`。从 $C$ 中任意一格往外走，要么仍走在 $C$ 里的 `0` 上，要么立刻被 `1` 挡住；而 $C$ 又不碰边界，这条「外圈」闭合在网格内部。于是 $C$ 被 `1` 完整包围，是封闭岛。

于是原问题可以改写成一句纯连通性的话：

$$\text{ans} = \#\{\, C : C \text{ 是 } 0 \text{ 的连通块，且 } C \cap \partial \Omega = \varnothing \,\}$$

其中 $\partial \Omega$ 表示网格四条边上的格子集合。**形状与「是不是一圈」完全无关**：环形、实心块、单格都一视同仁，示例 1 内部的环形岛与示例 3 的嵌套岛都只是在验证这一点。

### 3.3 算法流程：先淹边界，再数剩余

![两阶段扫描：从边界反向淹没，剩下的连通块就是答案](images/wc162_q3_two_phase_flow.svg)

既然「贴边的块」全部不作数，就不必为每块单独记录标记，而可以**反向消除**：

1. **阶段一（淹边界）**：遍历四条边上的每一个格子，凡是 `0`，就从它出发做一次 DFS/BFS，把能走到的 `0` 全部改成 `1`。这些正是「与边界连通」的块，它们一律不是封闭岛。用「改成 `1`」代替 `visited`，后续扫描不会再把它们当成陆地。
2. **阶段二（数剩余）**：从上到下、从左到右扫描整个网格，每遇到一个 `0`，就说明发现了一个新的封闭岛——`ans += 1`，然后同样用 DFS/BFS 把这一整块淹掉，保证同一块只被数一次。
3. 扫描结束，`ans` 即答案。

这样只做两遍线性扫描，既不需要 `visited` 数组，也不需要在 DFS 里额外携带「是否贴边」的标记，代码极短。等价的另一种写法是**并查集**：把所有相邻的 `0` 合并，同时给每个集合记一个「是否含边界格」的布尔量，最后统计不含边界格的集合个数，复杂度 $O(mn\,\alpha)$，但代码量明显更大。

### 3.4 示例演算

![示例 1 的两阶段走查](images/wc162_q3_walkthrough.svg)

以示例 1（$m = 5$，$n = 8$）为例：

| 连通块 | 位置 | 大小 | 是否贴边 | 是否封闭 |
|--------|------|------|----------|----------|
| ① 环形岛 | 第 1~3 行、第 1~4 列 | 10 格 | 否 | 是 |
| ② 单格岛 | (3, 6) | 1 格 | 否 | 是 |
| ③ 上段竖条 | (0, 7)、(1, 7)、(2, 7) | 3 格 | 是（第 7 列即最后一列） | 否 |
| ④ 单格 | (4, 7) | 1 格 | 是 | 否 |

阶段一从第 7 列的 `0` 出发，把 ③、④ 共 4 格淹成 `1`；阶段二先遇到 (1,1)，计数 1 并淹掉 ①（10 格），再遇到 (3,6)，计数 2 并淹掉 ②，此后全图无 `0`，输出 `2`。注意 ① 内部包着的水格 (2,2) 全程没有参与判断——判据只问「块里有没有贴边的格子」。

## 4. 算法细节

1. **原地淹没代替 `visited`**：入栈/入队时立刻把 `grid[nr][nc]` 置为 `1`，而不是出栈时才置。否则同一格可能被多个邻居重复压栈，最坏把栈撑到 $O(mn)$ 甚至反复膨胀。
2. **四条边的遍历**：第 0 行与第 $m-1$ 行整行扫一遍，第 0 列与第 $n-1$ 列整列扫一遍。四个角会被访问两次，但第二次它们已经是 `1`，不会重复开 DFS，无需特判。
3. **用显式栈而不是递归**：最坏情况下整张图是一个蛇形连通块，深度可达 $mn = 10^4$。Python 默认递归上限只有 1000，递归版会直接 `RecursionError`；C++ 的 $10^4$ 层在 8 MB 默认栈内一般安全，但把深度控制住并不吃亏。统一写成 `stack`/`deque` 迭代版本最稳。
4. **方向数组只取 4 个**：`(±1, 0)` 与 `(0, ±1)`。岛屿是四方向连通的，误写成八方向会把示例 2 的左右两块斜着连起来。
5. **`0` / `1` 的语义**：本题 `0` 是陆地、`1` 是水，恰好与 200 题相反。写代码时不要凭手感把「水」淹成「陆地」，否则会把答案算成水域连通块个数。
6. **计数与淹没必须绑定**：阶段二「发现 `0` → `ans += 1` → 立刻淹掉整块」是不可拆的原子操作；若先数完全图再淹，就会把同一块数很多次。
7. **不可变的输入**：LeetCode 允许修改 `grid` 参数（本题正是这样省掉 `visited` 的）。如果面试官要求保留原矩阵，请另开 `visited` 或先深拷贝一份。

## 5. 正确性证明

**引理 1（判据等价）**：`0` 连通块 $C$ 是封闭岛 $\iff$ $C$ 中不含网格边界上的格子。

**证明**：

- ($\Rightarrow$) 反证。设 $C$ 中有格子 $x$ 位于边界，则 $x$ 的某一侧直接越出网格，该侧不存在 `1`，「四周被 `1` 完全包围」不成立，$C$ 不是封闭岛，矛盾。
- ($\Leftarrow$) 设 $C$ 不含边界格。由 $C$ 是**极大**连通块可知：与 $C$ 中某格四方向相邻、却不属于 $C$ 的格子一定不是 `0`，只能是 `1`。于是从 $C$ 中任取一格出发，沿四个方向向外走，每一步遇到的要么仍是 $C$ 里的 `0`，要么是被 `1` 挡住；又因为 $C$ 中所有格子都不贴边，这条路不可能在碰到 `1` 之前走出网格。也就是 $C$ 被 `1` 完整封死，是封闭岛。∎

**引理 2（阶段一淹得不多不少）**：阶段一结束时，$C$ 被整块淹成 `1` $\iff$ $C$ 与边界连通（即 $C$ 含边界格）。

**证明**：

- ($\Leftarrow$) 若 $C$ 含边界格 $x$，阶段一会以 $x$ 为起点做 DFS，而 DFS 沿 `0` 邻接关系扩散，恰好遍历 $C$ 的全部格子，故 $C$ 被整块淹没。
- ($\Rightarrow$) 每次 DFS 都从某个边界 `0` 出发，且只在 `0` 邻接关系上扩散，所以被淹的格子必与该边界 `0` 属于同一连通块。∎

**引理 3（阶段二不重不漏）**：阶段二对每个「阶段一后仍为 `0` 的连通块」恰好计数一次，且对它不计数其它块。

**证明**：扫描按固定顺序进行，遇到某块的第一个 `0` 时计数并立刻淹掉整块，之后同一块再没有 `0` 可被遇到，故每块至多一次；又因为该块非空，其某一格必会被扫描到，故至少一次。计数时淹掉的只是该块（`0` 邻接扩散），不会波及别的块。∎

**定理**：算法返回的 `ans` 等于封闭岛的数量。

**证明**：由引理 1，封闭岛 $=$ 不含边界格的 `0` 连通块；由引理 2，阶段一后仍为 `0` 的块正是全部不含边界格的块；由引理 3，阶段二对这些块一一计数。三者合并即得结论。∎

## 6. 复杂度分析

- **时间**：$O(mn)$。阶段一从至多 $2m+2n-4$ 个边界格出发，但每次 DFS 只在尚未淹过的 `0` 上推进，每个格子被淹一次、入栈一次；阶段二的双重循环是 $O(mn)$，其中触发的 DFS 同样只处理新格子。两个阶段合计每个格子常数次访问。
- **空间**：$O(mn)$ 的辅助栈/队列（单块为蛇形时最坏全图入栈；实际远小于此），另加 $O(1)$ 的扫描变量。原地修改 `grid` 省掉了 $O(mn)$ 的 `visited` 数组；若改用递归实现，还需 $O(mn)$ 的调用栈空间，且受语言栈上限约束。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <utility>
using namespace std;

class Solution {
public:
    int closedIsland(vector<vector<int>>& grid) {
        int m = grid.size(), n = grid[0].size();
        const int dirs[4][2] = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};

        // 从 (sr, sc) 出发，把整块 0 淹成 1（原地标记，省去 visited）
        auto flood = [&](int sr, int sc) {
            grid[sr][sc] = 1;
            vector<pair<int, int>> st = {{sr, sc}};
            while (!st.empty()) {
                auto [r, c] = st.back();
                st.pop_back();
                for (auto& d : dirs) {
                    int nr = r + d[0], nc = c + d[1];
                    if (nr >= 0 && nr < m && nc >= 0 && nc < n && grid[nr][nc] == 0) {
                        grid[nr][nc] = 1;          // 入栈即标记，防止重复入栈
                        st.push_back({nr, nc});
                    }
                }
            }
        };

        // 阶段一：四条边上的 0 全部淹掉（它们与边界连通，不是封闭岛）
        for (int r = 0; r < m; r++)
            for (int c : {0, n - 1})
                if (grid[r][c] == 0) flood(r, c);
        for (int c = 0; c < n; c++)
            for (int r : {0, m - 1})
                if (grid[r][c] == 0) flood(r, c);

        // 阶段二：剩下的每个 0 连通块都是封闭岛
        int ans = 0;
        for (int r = 0; r < m; r++)
            for (int c = 0; c < n; c++)
                if (grid[r][c] == 0) { ans++; flood(r, c); }
        return ans;
    }
};
```

### Python

```python
from typing import List


class Solution:
    def closedIsland(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        dirs = ((1, 0), (-1, 0), (0, 1), (0, -1))

        def flood(sr: int, sc: int) -> None:
            grid[sr][sc] = 1                 # 入栈即标记，避免同一格重复入栈
            stack = [(sr, sc)]
            while stack:
                r, c = stack.pop()
                for dr, dc in dirs:
                    nr, nc = r + dr, c + dc
                    if 0 <= nr < m and 0 <= nc < n and grid[nr][nc] == 0:
                        grid[nr][nc] = 1
                        stack.append((nr, nc))

        # 阶段一：从四条边上的 0 出发，淹掉所有与边界连通的陆地
        for r in range(m):
            for c in (0, n - 1):
                if grid[r][c] == 0:
                    flood(r, c)
        for c in range(n):
            for r in (0, m - 1):
                if grid[r][c] == 0:
                    flood(r, c)

        # 阶段二：剩下的每个 0 连通块都是封闭岛
        ans = 0
        for r in range(m):
            for c in range(n):
                if grid[r][c] == 0:
                    ans += 1
                    flood(r, c)
        return ans
```

## 8. 边界情况与易错点

1. **单行或单列**：`1 <= m, n`，当 $m = 1$ 或 $n = 1$ 时每个格子都算边界格，任何 `0` 都会在阶段一被淹掉，答案必为 `0`。此时第 0 行与第 $m-1$ 行是同一行，边界循环会扫两遍——第二遍全是 `1`，不会出错。
2. **全 `0` 或全 `1`**：全 `0` 时整张图是一个贴边的大块，答案为 `0`；全 `1` 时没有任何陆地，答案同样是 `0`。两种情况都不需要特判，但要确认代码不会输出 $mn$ 或 $1$。
3. **单格网格**：`[[0]]` 与 `[[1]]` 的答案都是 `0`——唯一一格必然贴边，不可能封闭。写完代码先手测这两个用例最省事。
4. **把单格判据当成整题判据**：只检查 `grid[r][c]` 的四邻而不做连通块扩展，会在示例 1 的环形岛、示例 3 的嵌套环上双双翻车；封闭性属于连通块的属性。
5. **递归深度**：Python 默认递归上限 1000，$100 \times 100$ 的蛇形单块有 $10^4$ 层，递归版本必挂；要么改写成显式栈，要么 `sys.setrecursionlimit(10**6)`。C++ 在 $10^4$ 深度下通常安全，但递归深度是 $O(mn)$，数据范围一旦放大就会出问题，迭代写法不依赖语言栈。
6. **忘了「入栈即标记」**：若只在出栈时把格子置 `1`，同一格会被多个邻居重复压栈，队列规模可能指数级膨胀；更隐蔽的是把 `grid` 判断写在 `pop` 之后，容易漏掉起点自身的标记。
7. **嵌套岛屿**：示例 3 的内层岛被外层环岛包住，它依然不与网格边界连通，必须计入。任何「先扫外圈、再判内部」的直觉式剪枝都不成立，只有边界连通性才作数。

**延伸思考**：

1. 若要求的是**最大封闭岛**（面积最大者），阶段二把「`ans += 1`」换成「用块大小更新最大值」即可，一次遍历同时得到个数与最大面积。
