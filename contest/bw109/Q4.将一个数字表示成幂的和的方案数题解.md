# LeetCode 将一个数字表示成幂的和的方案数 题解

## 1. 题目概述

- **标题 / 题号**：将一个数字表示成幂的和的方案数（#2787，medium）
- **链接**：https://leetcode.cn/problems/ways-to-express-an-integer-as-sum-of-powers/
- **来源**：LeetCode 第 109 场双周赛 Q4
- **难度**：中等
- **标签**：动态规划

**题意**：给定正整数 $n$ 和 $x$，返回把 $n$ 表示成**互不相同**正整数的 $x$ 次幂之和的方案数：统计满足 $n = n_1^x + n_2^x + \dots + n_k^x$ 的互不相同整数集合 $\{n_1, \dots, n_k\}$ 的数目，答案对 $10^9 + 7$ 取模。

**约束**：

- $1 \le n \le 300$
- $1 \le x \le 5$

> ⚠️ **读题关键**："互不相同"约束在**底数**上——集合 $\{n_1,\dots,n_k\}$ 两两不同。因此 $1^x = 1$ 只能出现一次，这是 **0/1 背包**而非完全背包（用示例 2 验证：$n=4, x=1$ 的方案是 $\{4\}$ 与 $\{3,1\}$ 共 2 种，并不包含 $1+1+1+1$）。

## 2. 示例

**示例 1**

```text
输入：n = 10, x = 2
输出：1
解释：10 = 3² + 1²，是唯一方案。
```

**示例 2**

```text
输入：n = 4, x = 1
输出：2
解释：4 = 4¹；4 = 3¹ + 1¹。（1 只能用一次，故没有 1+1+1+1）
```

## 3. 解题思路

### 3.1 暴力思路

列出所有满足 $\mathrm{base}^x \le n$ 的底数（$x=1$ 时最多 300 个，$x=5$ 时只有 3 个：$1,2,3$），枚举这些"幂物品"的全部子集、累加体积并数出等于 $n$ 的个数：$2^{300}$ 组，天文数字；即便 $x=5$ 时 $2^3$ 可行，$x=1$ 也彻底不可行。换个角度——**子集计数恰好装满**是 0/1 背包计数的标准场景，DP 一步到位。

### 3.2 核心观察：物品是"底数的 $x$ 次幂"，每件至多选一次

![0/1 背包模型：物品为各底数的 x 次幂](images/bw109_q4_knapsack_model.svg)

把每个底数 $b$ 看作一件体积为 $b^x$ 的物品（$b = 1, 2, \dots$，直到 $b^x > n$ 为止），物品总数 $m = \lfloor n^{1/x} \rfloor \le 300$。**底数互不相同 ⇔ 每件物品至多选一次**；"和恰为 $n$" 即背包恰好装满容量 $n$。所求是方案数（不是最大值），因此 dp 存计数：

$$\mathrm{dp}[s] = \text{已考察物品中，体积和恰为 } s \text{ 的子集数}$$

### 3.3 状态转移：一维 dp + 容量倒序

![一维 dp 与倒序枚举的等价性](images/bw109_q4_dp_rolling.svg)

逐件加入物品。加入体积 $v = b^x$ 时：

$$\mathrm{dp}[s] \mathrel{+}= \mathrm{dp}[s - v] \quad (s \text{ 从 } n \text{ 倒序到 } v)$$

**倒序**保证 $\mathrm{dp}[s-v]$ 是"还没算入当前物品"的旧值——当前物品最多被选一次；若正序枚举，$\mathrm{dp}[s-v]$ 已混入本物品的贡献，物品可重复使用（完全背包），会把 $1^x + 1^x + \cdots$ 这类非法方案也计入。初始 $\mathrm{dp}[0] = 1$（空集），答案 $\mathrm{dp}[n]$（$n \ge 1$ 故空集不会误计）。

### 3.4 示例演算

![示例演算：n=10, x=2 的 dp 变化](images/bw109_q4_walkthrough.svg)

$n = 10$，$x = 2$，物品 $\{1, 4, 9\}$：

| 阶段 | dp 变化 |
|------|---------|
| 初始 | dp[0] = 1，其余 0 |
| 加入 $1$ | dp[1] = 1（$\{1\}$） |
| 加入 $4$（倒序） | dp[5] = 1（$\{1,4\}$），dp[4] = 1（$\{4\}$） |
| 加入 $9$（倒序） | dp[10] = dp[1] + dp[10] = 1（$\{1,9\}$），dp[13] 越界跳过 |

最终 dp[10] = 1 ✓。注意 $\{4\}+\{9\}$ 会得 13 超容量，$\{1,4\}+\{9\}$ 得 14 也不行——只有 $1 + 9$ 恰好等于 10。

## 4. 算法细节

1. **物品生成**：$v = b^x$ 逐个计算，$v > n$ 即停；$b \le 300$、$x \le 5$，$v$ 最大 $300^5 \approx 2.4 \times 10^{12}$，C++ 用 `long long` 存中间幂值再与 $n$ 比较（若先用 `int` 存会溢出；实际循环在 $v \le n$ 才继续，比较本身安全）。
2. **倒序枚举的下界**：内层 $s$ 从 $n$ 递减到 $v$——$s < v$ 时 $\mathrm{dp}[s-v]$ 无意义，直接不进循环。
3. **取模位置**：每次加法后立即取模（`(dp[s] + dp[s-v]) % MOD`），避免大数累积；C++ 用 `long long` 存 dp 即便取模前也不会溢出（两项各 $< 10^9+7$，和 $< 2^{31}$ 也够，但习惯上 64 位最稳）。
4. **为什么不用二维 dp**：$\mathrm{dp}[i][s]$ 展开是 $O(m \cdot n)$ 空间（$\le 300 \times 300$），一维滚动等价、更省；倒序枚举正是一维化 0/1 背包的标志写法。
5. **方案数而不是可行性**：如果题目改问"是否存在"，dp 存布尔即可；计数版对"恰好装满"同样自然——空集贡献 $\mathrm{dp}[0]=1$ 是唯一起点，所有方案都由它逐步加上物品转移而来，不会重不漏（见 §5）。

## 5. 正确性证明

**引理 1（无序集合 ↔ 有序选择）**：把互不相同底数的集合与"按底数升序的选取序列"一一对应；按底数从小到大逐件考察的背包过程等价于按此规范序做决策。

**证明**：集合元素天然可排序（互不相同），升序序列由集合唯一决定；反之序列（严格递增）唯一给出集合。背包按 $b = 1, 2, \dots$ 的顺序考察物品，每件"选/不选"恰好对应规范序中的决策位。∎

**引理 2（一维倒序等价于二维）**：设 $\mathrm{dp}_i[s]$ 为考察完前 $i$ 件物品、体积和恰为 $s$ 的子集数。按 $s$ 从 $n$ 倒序到 $v_i$ 执行 $\mathrm{dp}[s] \mathrel{+}= \mathrm{dp}[s - v_i]$ 后，数组内容恰为 $\mathrm{dp}_i[\cdot]$。

**证明**：对 $i$ 归纳。$i = 0$ 时数组仅 $\mathrm{dp}[0]=1$，即 $\mathrm{dp}_0$，成立。设某轮开始时数组恰为 $\mathrm{dp}_{i-1}[\cdot]$。倒序处理 $s = n, n-1, \dots, v_i$：处理某个 $s$ 时，$\mathrm{dp}[s - v_i]$ 尚未被本轮更新（因 $s - v_i < s$，倒序未到达），仍为 $\mathrm{dp}_{i-1}[s - v_i]$；而本轮后续要处理的下标都严格小于 $s$，不会再读 $\mathrm{dp}[s]$。于是每步执行的就是 $\mathrm{dp}_i[s] = \mathrm{dp}_{i-1}[s] + \mathrm{dp}_{i-1}[s - v_i]$（$s \ge v_i$；$s < v_i$ 处不进循环，$\mathrm{dp}_i[s] = \mathrm{dp}_{i-1}[s]$，与"选不下超容量物品"一致），这正是"含/不含第 $i$ 件物品"的划分计数。∎

**定理**：算法返回 $\mathrm{dp}[n]$ 恰为题目所求方案数模 $10^9+7$。

**证明**：由引理 1，方案集合与"每件物品选一次的选取决策"一一对应；由引理 2，$\mathrm{dp}_m[s]$ 累加的每条决策路径对应一个体积和为 $s$ 的互异底数集合，且不同决策路径对应不同集合（决策位即集合特征向量），不重不漏。$\mathrm{dp}_m[n]$ 即体积恰为 $n$ 的集合数。取模只改变表示不改变计数对应关系。∎

## 6. 复杂度分析

- **时间**：$O(m \cdot n)$，$m = \lfloor n^{1/x} \rfloor$。最坏 $x = 1$ 时 $m = n$，约 $300 \times 300 = 9 \times 10^4$ 次转移；$x$ 越大物品越少、越快。
- **空间**：$O(n)$，一维 dp 数组（另有 $O(1)$ 的幂值中间量）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int numberOfWays(int n, int x) {
        const long long MOD = 1'000'000'007;
        vector<long long> dp(n + 1, 0);           // dp[s]: 体积和恰为 s 的子集数
        dp[0] = 1;
        for (long long base = 1;; ++base) {
            long long v = 1;
            for (int k = 0; k < x; ++k) v *= base;    // v = base^x
            if (v > n) break;                     // 物品只有 base^x <= n
            for (int s = n; s >= v; --s)          // 0/1 背包：容量倒序
                dp[s] = (dp[s] + dp[s - v]) % MOD;
        }
        return (int)dp[n];
    }
};
```

### Python

```python
class Solution:
    def numberOfWays(self, n: int, x: int) -> int:
        MOD = 10 ** 9 + 7
        dp = [0] * (n + 1)                  # dp[s]: 体积和恰为 s 的子集数
        dp[0] = 1
        base = 1
        while True:
            v = base ** x
            if v > n:
                break
            for s in range(n, v - 1, -1):   # 0/1 背包：容量倒序
                dp[s] = (dp[s] + dp[s - v]) % MOD
            base += 1
        return dp[n]
```

> 💡 两份代码均通过全部官方示例（`1`、`2`）；另与"DFS 枚举全部幂物品子集计数"的独立暴力对拍：$x \in [1,5]$ 穷举（$x=1$ 时 $n \le 22$，$x \ge 2$ 时 $n \le 300$ 全量）加随机共 **2722 组**，`mismatch = 0`。

## 8. 边界情况与易错点

1. **0/1 还是完全背包**：这是本题最大陷阱。"互不相同"修饰**底数**，$1^x = 1$ 只能选一次。若按完全背包（正序）写，$n = 4, x = 1$ 会算出包含 $1+1+1+1$、$1+1+2$ 等的错答案（$>2$）。示例 2 就是官方埋的验证点。
2. **倒序边界**：内层循环到 $s = v$ 为止，`s - v` 最小为 0（空集转移），不要写成 `s > v`。
3. **幂值溢出**：$300^5 \approx 2.4 \times 10^{12}$ 超出 32 位；C++ 幂值变量用 `long long`（比较 `v > n` 发生在溢出前，循环必然终止：$x \ge 1$ 时 $v \ge \mathrm{base}$，$\mathrm{base} > n$ 时必有 $v > n$）。
4. **`dp[0] = 1` 的含义**：空集是"体积 0"的唯一方案；$n \ge 1$ 时它不会被计入答案，但它是所有非空方案的转移起点，漏掉则全盘为 0。
5. **取模**：加法计数随时可能超 $10^9+7$，每步取模；返回时 C++ 从 `long long` 收窄回 `int` 是安全的（已取模）。
6. **$x=1$ 的规模**：物品多达 300 件，但 $O(n^2) = 9 \times 10^4$ 转移毫无压力；不要误以为需要优化。
