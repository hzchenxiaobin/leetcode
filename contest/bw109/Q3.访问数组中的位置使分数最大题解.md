# LeetCode 访问数组中的位置使分数最大 题解

## 1. 题目概述

- **标题 / 题号**：访问数组中的位置使分数最大（#2786，medium）
- **链接**：https://leetcode.cn/problems/visit-array-positions-to-maximize-score/
- **来源**：LeetCode 第 109 场双周赛 Q3
- **难度**：中等
- **标签**：数组、动态规划

**题意**：给定下标从 0 开始的整数数组 `nums` 和正整数 $x$。你从位置 0 出发（初始得分 $\mathrm{nums}[0]$），可以反复从位置 $i$ 跳到**任意**位置 $j > i$；访问位置 $i$ 得到分数 $\mathrm{nums}[i]$；若一次移动 $\mathrm{nums}[i]$ 与 $\mathrm{nums}[j]$ 的**奇偶性不同**，额外失去 $x$ 分。返回能得到的最大总得分。

**约束**：

- $2 \le \mathrm{nums.length} \le 10^5$
- $1 \le \mathrm{nums}[i], x \le 10^6$

## 2. 示例

**示例 1**

```text
输入：nums = [2, 3, 6, 1, 9, 2], x = 5
输出：13
解释：按顺序访问 0 → 2 → 3 → 4，得分为 2 + 6 + 1 + 9 − 5 = 13
（6 与 1 奇偶不同，那一步扣 x = 5）。
```

**示例 2**

```text
输入：nums = [2, 4, 6, 8], x = 3
输出：20
解释：全数组奇偶相同，全部访问且无扣分：2 + 4 + 6 + 8 = 20。
```

## 3. 解题思路

### 3.1 暴力思路

访问路线是一条**下标递增的子序列**（起点必含 0），暴力即枚举所有子序列：$2^{n-1}$ 种（位置 0 必选，其余每个位置选或不选），对每条路线累加得分并按相邻奇偶变化扣 $x$，取最大。$n \le 25$ 左右尚可，$n = 10^5$ 时完全不可行。瓶颈在于"每个位置选/不选"看似独立，实际上得分只取决于**路线末尾的奇偶**——这个观察把指数压成线性。

### 3.2 核心观察：末尾奇偶两个状态就够了

![状态设计：以偶/奇结尾的两个状态与转移](images/bw109_q3_parity_states.svg)

定义 $\mathrm{best}[p]$（$p \in \{0, 1\}$）＝ 所有合法访问路线中，**末尾元素奇偶为 $p$** 的最大得分。为什么不需要更细的状态？因为决定"下一跳是否扣分"的只有**当前停在哪里这条路线最后一个数的奇偶**——历史路径的具体形状（跳过哪些位置）不影响未来。这正是**无后效性**：把"最后停在奇数/偶数"作为状态，转移只需 $O(1)$。

初始时只有起点：$\mathrm{best}[\mathrm{nums}[0] \bmod 2] = \mathrm{nums}[0]$，另一个状态记为 $-\infty$（"不存在"哨兵）。

### 3.3 状态转移：同奇偶免费续、换奇偶扣 $x$

![转移流程：一遍扫描的处理步骤](images/bw109_q3_transition_flow.svg)

处理到 $\mathrm{nums}[i]$（奇偶 $p$）时，它作为新末尾的得分来自两种前驱：

$$\mathrm{gain} = \mathrm{nums}[i] + \max\big(\mathrm{best}[p],\; \mathrm{best}[p \oplus 1] - x\big)$$

- 前驱末尾同为 $p$：直接续上，不扣分；
- 前驱末尾为 $p \oplus 1$：跨奇偶，先扣 $x$ 再加 $\mathrm{nums}[i]$。

随后松弛 $\mathrm{best}[p] = \max(\mathrm{best}[p], \mathrm{gain})$。两条来源与一次松弛，转移 $O(1)$；全程一遍扫描，最终答案 $\max(\mathrm{best}[0], \mathrm{best}[1])$（路线可以停在任何位置，不必到末尾）。

> ⚠️ 起点位置的奇偶可能两个状态都"可达"——第一跳换奇偶同样要扣 $x$，由 $-\infty$ 哨兵 + 上式自然处理：$\mathrm{best}[p \oplus 1]$ 初始为 $-\infty$，不会参与有效比较。

### 3.4 示例演算

![示例演算：best 两个状态的逐步取值](images/bw109_q3_walkthrough.svg)

$\mathrm{nums} = [2,3,6,1,9,2]$，$x = 5$：

| $i$ | $\mathrm{nums}[i]$ | $\mathrm{best}[0]$ | $\mathrm{best}[1]$ | 说明 |
|-----|-----|-----|-----|------|
| 0 | 2（偶） | 2 | $-\infty$ | 起点 |
| 1 | 3（奇） | 2 | 0 | $2-5+3=0$ |
| 2 | 6（偶） | 8 | 0 | $2+6$ |
| 3 | 1（奇） | 8 | 4 | $8-5+1$ |
| 4 | 9（奇） | 8 | 13 | $4+9$ |
| 5 | 2（偶） | 10 | 13 | $\max(8,\,13-5)+2$ |

答案 $\max(10, 13) = 13$ ✓。

## 4. 算法细节

1. **哨兵取值**：用 $\mathrm{NEG} = -10^{18}$（C++ `long long` / Python 整数）而非 `LLONG_MIN`，避免 $-x$ 再加值时的溢出与实现差异；有效得分下界 $-n \cdot x \ge -10^{11}$，与哨兵相差 7 个数量级，不会混淆。
2. **先读后写**：处理 $i$ 时读取的两个 $\mathrm{best}$ 都必须是"截至 $i-1$"的旧值；由于更新只落在 $\mathrm{best}[p]$ 上而读取包含 $\mathrm{best}[p]$ 自身（`max(f[p], f[p^1]-x)` 先算出再赋值），一次读改写天然时序正确，无需临时变量。
3. **答案在过程中取**：子序列可停在任意位置，但 $\mathrm{best}[p]$ 单调不减（$\mathrm{nums}[i] \ge 1$，每次更新只会更大），故扫描完取两状态的最大即为全程最优。
4. **每步都收益为正吗**：不是。同奇偶的 $\mathrm{nums}[i] \ge 1$ 白拿必赚；换奇偶要过 $-x$ 的门槛，$\mathrm{nums}[i] < x$ 时可能亏——这正是 DP 必要性所在，贪心"见就吃"会错（如 $[2,1,2]$，$x=5$：吃掉中间的 1 反而亏 4）。
5. **滚动数组即可**：状态只有两个 `long long`，无维度可滚。

## 5. 正确性证明

**引理 1（无后效性）**：设两条路线都以位置 $i$ 为末尾、得分分别为 $s_1 > s_2$。对任意后续跳转序列，从 $s_1$ 出发的最终得分不小于从 $s_2$ 出发的对应得分。

**证明**：后续每一步的增量（$\mathrm{nums}[j]$ 或 $-x$）只依赖**相邻两次停留位置元素的奇偶**，与更早历史无关。两条路线末尾相同，后续序列相同则每步增量逐项相同，最终差恒为 $s_1 - s_2 \ge 0$。∎

**引理 2（归纳不变量）**：扫描完前 $i+1$ 个位置后，$\mathrm{best}[p]$ 恰为"末尾落在 $\le i$ 且末元素奇偶为 $p$"的路线最大得分（不存在则仍为哨兵）。

**证明**：对 $i$ 归纳。$i=0$：只有路线 $\{0\}$，初值即其得分，成立。设对 $i-1$ 成立。考虑末尾为 $i$、奇偶 $p$ 的最优路线 $R$：其前驱路线 $R'$ 末尾 $j < i$（或 $R = \{0\}$，被初值覆盖）。$R$ 的得分 $= \mathrm{nums}[i] + (R'\text{ 的得分} + (\text{末尾奇偶不同则 } -x))$。由归纳假设 $R'$ 的得分 $\le \mathrm{best}[p]$（同偶时）或 $\le \mathrm{best}[p\oplus1]$（异偶时），故 $R$ 的得分 $\le \mathrm{gain}$，松弛后 $\mathrm{best}[p]$ 覆盖之；反之 $\mathrm{gain}$ 对应的两条前驱由归纳假设都存在可行路线，拼接 $\{i\}$ 得可行路线，故 $\mathrm{best}[p]$ 不虚高。末尾 $< i$ 的路线不参与更新，值保持。∎

**定理**：算法返回值为题意最优得分。

**证明**：最优路线必有末尾，末元素奇偶为 0 或 1，由引理 2 末轮扫描后其得分被 $\mathrm{best}$ 覆盖，返回的 max 不小于它；又 $\mathrm{best}$ 中每个值都对应一条可行路线（引理 2 的"不虚高"），返回值可行。两者夹逼即最优。∎

## 6. 复杂度分析

- **时间**：$O(n)$，每个位置常数次比较与加法。
- **空间**：$O(1)$，两个 `long long` 状态变量（哨兵与累加值都在 64 位安全范围内：得分上界 $n \cdot \max(\mathrm{nums}) \le 10^{11}$，扣分下界 $\ge -n \cdot x \ge -10^{11}$）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long maxScore(vector<int>& nums, int x) {
        const long long NEG = -1e18;              // “不存在”哨兵，远离溢出
        long long best[2] = {NEG, NEG};           // best[p]: 子序列最后一个数奇偶为 p 的最大得分
        best[nums[0] & 1] = nums[0];              // 起点必选
        for (int i = 1; i < (int)nums.size(); ++i) {
            int p = nums[i] & 1;
            long long gain = max(best[p], best[p ^ 1] - x);   // 同偶免罚 / 换偶扣 x
            best[p] = max(best[p], gain + nums[i]);
        }
        return max(best[0], best[1]);
    }
};
```

### Python

```python
class Solution:
    def maxScore(self, nums: list[int], x: int) -> int:
        NEG = -(1 << 60)                    # “不存在”哨兵
        best = [NEG, NEG]                   # best[p]: 子序列末尾奇偶为 p 的最大得分
        best[nums[0] & 1] = nums[0]         # 起点必选
        for v in nums[1:]:
            p = v & 1
            gain = max(best[p], best[p ^ 1] - x)   # 同偶免罚 / 换偶扣 x
            best[p] = max(best[p], gain + v)
        return max(best)
```

> 💡 两份代码均通过全部官方示例（`13`、`20`）；另与"枚举全部 $2^{n-1}$ 条子序列路线并直接算分"的独立暴力做了 3000 组随机对拍（$n \in [2,12]$、值域 $[1,20]$、$x \in [1,10]$），`mismatch = 0`；$n = 10^5$、值域 $10^6$ 的满规模实测约几十毫秒，得分达 $3.5 \times 10^{10}$，验证 64 位必要性。

## 8. 边界情况与易错点

1. **起点必须计入**：初始得分是 $\mathrm{nums}[0]$，不是 0；只初始化对应奇偶的那个状态，另一个保持哨兵。
2. **哨兵溢出**：若哨兵用 `LLONG_MIN`，`best[p^1] - x` 在 C++ 中是未定义行为（有符号溢出）。取 $-10^{18}$（Python 用 $-2^{60}$）距离 `long long` 下界尚有 7 个数量级余量。
3. **答案不必选到最后**：没有"必须访问所有位置"的约束，任意子序列都合法，末尾奇偶两个状态取 max 即可，不要在循环里提前返回。
4. **同奇偶不扣分是双向的**：奇→奇、偶→偶都免罚；扣分只看**相邻两次停留**的奇偶，跳过的位置无关（跳过 3 个奇数再落到奇数上，仍然是奇→奇）。
5. **`nums[i]` 全为正**：每一步同奇偶增量 $\ge 1$，这保证 `best` 单调、答案 $\ge \mathrm{nums}[0] \ge 1$；若有负数（本题无），"不选末尾"的最优性仍由 max 保持。
6. **int 溢出**：总得分上界 $10^{11}$，C++ 必须用 `long long`（返回类型即 `long`）；Python 无此虑。
