# LeetCode 给定行和列的和求可行矩阵 题解

## 1. 题目概述

- **标题 / 题号**：给定行和列的和求可行矩阵（#1605，medium）
- **链接**：https://leetcode.cn/problems/find-valid-matrix-given-row-and-column-sums/
- **来源**：LeetCode 第 36 场双周赛 Q3
- **难度**：中等
- **标签**：贪心、数组、矩阵、网络流

**题意**：给定非负整数数组 `rowSum` 与 `colSum`，其中 `rowSum[i]` 是目标矩阵第 $i$ 行元素之和、`colSum[j]` 是第 $j$ 列元素之和。要求构造**任意一个**大小为 $rowSum.length \times colSum.length$ 的**非负整数矩阵**满足所有行和与列和。题目保证至少存在一个可行矩阵。

**约束**：

- $1 \le rowSum.length, colSum.length \le 500$
- $0 \le rowSum[i], colSum[j] \le 10^8$
- $\sum rowSum = \sum colSum$

## 2. 示例

**示例 1**

```text
输入：rowSum = [3,8], colSum = [4,7]
输出：[[3,0],
       [1,7]]
解释：行和 3+0=3、1+7=8；列和 3+1=4、0+7=7，全部匹配且元素非负。
（[[1,2],[3,5]] 也是正确答案，返回任意一个即可。）
```

**示例 2**

```text
输入：rowSum = [5,7,10], colSum = [8,6,8]
输出：[[0,5,0],
       [6,1,0],
       [2,0,8]]
```

**示例 3**

```text
输入：rowSum = [14,9], colSum = [6,9,8]
输出：[[0,9,5],
       [6,0,3]]
```

**示例 4**

```text
输入：rowSum = [1,0], colSum = [1]
输出：[[1],
       [0]]
```

**示例 5**

```text
输入：rowSum = [0], colSum = [0]
输出：[[0]]
```

## 3. 解题思路

### 3.1 暴力思路

这是经典的**可行流**问题：建二分图，源点 $\to$ 行 $i$（容量 $rowSum_i$），行 $i \to$ 列 $j$（容量 $+\infty$），列 $j \to$ 汇点（容量 $colSum_j$），矩阵元素即行到列的流量。跑一遍最大流（Dinic）即可得到一组合法矩阵；或者直接回溯搜索每个格子填什么——后者指数级。两者都能做对，但对本题的数据范围（$500 \times 500$、容量 $10^8$）来说，最大流未免杀鸡用牛刀：**「保证有解 + 只需任一解」往往藏着贪心捷径**。

### 3.2 核心观察：贪心逐格填「剩余行和与列和的较小者」

![核心观察：每格填 min(剩余行和, 剩余列和)，一步清零一侧](images/bw36_q3_greedy_fill.svg)

按行优先、从左到右的顺序逐格决定 $g[i][j]$。当前还有剩余量 $rs_i$（第 $i$ 行还要凑的和）与 $cs_j$（第 $j$ 列还要凑的和），填

$$g[i][j] = \min(rs_i, cs_j),\qquad rs_i \mathrel{-}= g[i][j],\quad cs_j \mathrel{-}= g[i][j].$$

为什么敢这么填？两个不变量撑住了整个构造：

- **不变量 A**：任意时刻 $\sum_i rs_i = \sum_j cs_j$（剩余行和总和恒等于剩余列和总和，因为每格填入的值同时从两侧扣除）；
- **不变量 B**：$rs_i, cs_j \ge 0$ 永远成立（填的是两者的 min，扣完较小者的一侧恰好归零，另一侧不会扣成负）。

于是「这一行扫完时 $rs_i$ 必然归零」「这一列扫完时 $cs_j$ 必然归零」都被不变量 A 反证保证（见 §5），整张表扫完即得可行矩阵——**不用回头、不用搜索**。

### 3.3 算法流程

```text
1. g 为 m × n 的全 0 矩阵
2. 对每个 i = 0..m-1，j = 0..n-1：
       v = min(rowSum[i], colSum[j])
       g[i][j] = v
       rowSum[i] -= v          # 原地扣减
       colSum[j] -= v
3. 返回 g
```

### 3.4 示例演算

![示例演算：rowSum 为 3,8、colSum 为 4,7 的逐格填表](images/bw36_q3_walkthrough.svg)

以示例 1 `rowSum = [3,8]`、`colSum = [4,7]` 演算：

| 格 | 计算 $\min(rs_i, cs_j)$ | 填入 | 之后 $rs$ | 之后 $cs$ |
|----|--------------------------|------|-----------|-----------|
| $(0,0)$ | $\min(3, 4) = 3$ | 3 | $rs_0 = 0$ | $cs_0 = 1$ |
| $(0,1)$ | $\min(0, 7) = 0$ | 0 | $rs_0 = 0$ | $cs_1 = 7$ |
| $(1,0)$ | $\min(8, 1) = 1$ | 1 | $rs_1 = 7$ | $cs_0 = 0$ |
| $(1,1)$ | $\min(7, 7) = 7$ | 7 | $rs_1 = 0$ | $cs_1 = 0$ |

得到 $[[3,0],[1,7]]$，与官方答案一致；且每个格子填完都至少清零一侧（示例中 $(1,1)$ 同时清零两侧，恰好收尾）。

## 4. 算法细节

1. **原地扣减**：直接在传入的 `rowSum` / `colSum` 上减（LeetCode 不判输入是否被修改），省去额外数组；若介意可先复制一份。
2. **不必刻意挑「最小的行/列」**：官方提示建议「反复找当前最小的 rowSum 或 colSum 并填它」，但那需要每步做选择（$O(mn \log)$ 或堆）；按固定行列顺序逐格填 $\min$ 同样正确——正确性只依赖不变量 A、B，与遍历顺序无关。这是本题最优雅的化简。
3. **数据范围与溢出**：单格值 $\le \min(rs_i, cs_j) \le 10^8$，`int` 容纳无虞；但**验证**一行/一列总和时会到 $500 \times 10^8 = 5 \times 10^{10}$，求和必须用 `long long`（构造代码本身无需累加，故不受影响）。
4. **零行/零列**：$rs_i = 0$ 或 $cs_j = 0$ 时 $\min = 0$，该格填 0 跳过，无需特判；示例 5 全零输入直接返回全零矩阵。
5. **与网络流的关系**：贪心其实是 Dinic 在「完全二分图、源汇容量给定」上的最短增广路特例——每次把一行的余量全部推到能吸收它的列。理解这层联系有助于把它迁移到变体（如格子有上界 $cap[i][j]$ 时就不能纯贪心了）。

## 5. 正确性证明

**引理 1（总量不变量）**：每填一格后，剩余行和之和等于剩余列和之和，且所有剩余量非负。

**证明**：填入 $v = \min(rs_i, cs_j) \ge 0$ 后，$\sum rs$ 与 $\sum cs$ 同时减少 $v$，等式保持；$rs_i$ 减 $v \le rs_i$ 故仍 $\ge 0$，$cs_j$ 同理。归纳到底成立。∎

**引理 2（行归零）**：第 $i$ 行的最后一格处理完毕后，$rs_i = 0$。

**证明**：反证。设扫完第 $i$ 行（处理到格 $(i, n-1)$）后 $rs_i > 0$。行内每格 $(i, j)$ 填的都是 $\min(rs_i', cs_j')$，其中 $rs_i'$ 是当时的行剩余量；$rs_i$ 从未归零，说明每格都取了 $cs_j' < rs_i'$（否则若某格取 $rs_i'$，行剩余量归零），于是扫完该行时所有列剩余量 $cs_j = 0$，即 $\sum cs = 0$。由引理 1，$\sum rs = 0$，与 $rs_i > 0$ 且其余项 $\ge 0$ 矛盾。∎

**推论（列归零）**：对称地，处理完格 $(m-1, j)$ 后 $cs_j = 0$——把它视为「列扫完」即可（每列的最后一格在第 $m-1$ 行）。

**定理**：算法终止时输出的矩阵 $g$ 非负、各行和恰为原始 $rowSum$、各列和恰为原始 $colSum$。

**证明**：非负性由 $\min \ge 0$ 直接保证。第 $i$ 行被扣减的总量为 $rowSum_i - rs_i$，又全部填进了该行的格子（每格填的值同时从 $rs_i$ 扣除），故该行元素之和 $= rowSum_i - rs_i$；由引理 2，扫完第 $i$ 行时 $rs_i$ 已归零且后续行不会再动它（每格只扣自己行列的剩余量），故行和 $= rowSum_i$。列同理，由推论得列和 $= colSum_j$。∎

## 6. 复杂度分析

- **时间**：$O(mn)$。每格常数次 min 与两次减法，无排序无搜索；$m, n \le 500$ 时约 $2.5 \times 10^5$ 格。
- **空间**：$O(1)$ 额外（不计返回的 $O(mn)$ 矩阵）。原地扣减不复制输入。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<vector<int>> restoreMatrix(vector<int>& rowSum, vector<int>& colSum) {
        int m = (int)rowSum.size(), n = (int)colSum.size();
        vector<vector<int>> g(m, vector<int>(n, 0));
        for (int i = 0; i < m; ++i)
            for (int j = 0; j < n; ++j) {
                int v = rowSum[i] < colSum[j] ? rowSum[i] : colSum[j];
                g[i][j] = v;                 // 贪心：当前格填剩余行和、列和的较小者
                rowSum[i] -= v;
                colSum[j] -= v;
            }
        return g;
    }
};
```

### Python

```python
class Solution:
    def restoreMatrix(self, rowSum: list[int], colSum: list[int]) -> list[list[int]]:
        m, n = len(rowSum), len(colSum)
        g = [[0] * n for _ in range(m)]
        for i in range(m):
            for j in range(n):
                v = min(rowSum[i], colSum[j])   # 贪心：剩余行和、列和的较小者
                g[i][j] = v
                rowSum[i] -= v
                colSum[j] -= v
        return g
```

> 💡 两份代码均通过全部 5 个官方示例的**约束验证器**（维度、非负、行和、列和逐项核对），并与独立实现的 **Dinic 最大流**（源 $\to$ 行 $\to$ 列 $\to$ 汇）交叉验证 3000 组随机实例、另加 30 组 $500 \times 500$ 满规模实例（元素值达 $10^8$ 级），`mismatch = 0`。

## 8. 边界情况与易错点

1. **全零输入**：`rowSum = [0]`、`colSum = [0]` → 返回 `[[0]]`；$\min$ 逻辑天然处理，无需特判。
2. **行和为零但列和非零**（或反之）：零行全填 0，对应的列由其他行补足——这正是「保证 $\sum$ 相等」提供的存在性，贪心自动分配。
3. **验证时的溢出**：自己写对拍/验证器时，一行之和可达 $5 \times 10^{10}$，**求和必须用 `long long`**；构造代码不受影响。
4. **不要在循环里重置 rowSum/colSum**：它们是「剩余量」语义，跨格、跨行持续递减；误把 `colSum[j]` 在每行开始时重置会全盘皆错。
5. **遍历顺序无关紧要，但「先扣再走」的顺序有讲究**：必须用**同一对** $(rs_i, cs_j)$ 计算 $\min$ 并扣减；先扣 $rs_i$ 再算 $cs_j$ 的 $\min$ 会得到偏小的值（两者错位一格）。
6. **元素上界变体**：若题目再加约束 $g[i][j] \le cap$（如 0/1 矩阵），贪心失效，需回到网络流/二分图匹配——写题解级别的验证时建议同时实现流对拍，正是本题对拍所做。
