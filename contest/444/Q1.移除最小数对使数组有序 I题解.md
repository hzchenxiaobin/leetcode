# LeetCode 移除最小数对使数组有序 I 题解

## 1. 题目概述

- **标题 / 题号**：移除最小数对使数组有序 I（#3507，easy）
- **链接**：https://leetcode.cn/problems/minimum-pair-removal-to-sort-array-i/
- **来源**：LeetCode 第 444 场周赛 Q1
- **难度**：简单
- **标签**：数组、模拟

**题意**：给定数组 `nums`，可以执行以下操作任意多次：

- 选择**相邻**元素对中**和最小**的一对；若有多对的和并列最小，选择**最左边**的一对；
- 用它们的**和**替换这两个元素（两格并一格，数组长度减 1）。

返回使数组变为**非递减**（每个元素都大于或等于它前一个元素，如果存在的话）所需的**最小操作次数**。

**约束**：

- $1 \le \text{nums.length} \le 50$
- $-1000 \le \text{nums}[i] \le 1000$

> 💡 **读题关键**：题面问「最小操作次数」，第一反应像贪心 / DP，但操作规则是**完全强制**的——选哪一对由「和最小 + 平局取最左」唯一确定，没有任何决策分支。所谓「最小次数」就是这个确定性过程走到非递减时的自然步数，本题本质是**模拟题**（官方标签里的堆、双向链表等，对应的是本场 Q4 硬化版 3510 的加速器件，见「相关题目与扩展」）。

## 2. 示例

**示例 1**（官方）

```text
输入：nums = [5,2,3,1]
输出：2
解释：(3,1) 的和最小为 4，替换后 nums = [5,2,4]；(2,4) 的和为 6，替换后 nums = [5,6]，非递减。
```

**示例 2**（官方）

```text
输入：nums = [1,2,2]
输出：0
解释：数组已经非递减（2 = 2 合法），无需任何操作。
```

**示例 3**（自造：平局陷阱）

```text
输入：nums = [1,3,2,2]
输出：2
解释：对和为 4, 5, 4，(1,3) 与 (2,2) 并列最小，按规则取最左 (1,3) → [4,2,2]；
      再合并 (2,2) → [4,4] 非递减。若误取最右，[1,3,4] 一步有序，答案会错成 1。
```

**示例 4**（自造：负数）

```text
输入：nums = [2,2,-1]
输出：2
解释：(2,-1) 的代数和 1 全场最小，先合并 → [2,1]，仍逆序（2 > 1）；再合并 → [3]，非递减。
```

## 3. 解题思路

### 3.1 暴力思路

把题面逐字翻译成循环：每轮先 $O(n)$ 检查数组是否非递减；若否，再 $O(n)$ 扫出**和最小**的相邻对，把右格并入左格后删除，操作数加一。每轮长度减 1、长度为 1 的数组必然非递减，循环至多执行 $n-1$ 轮，总工作量 $O(n^2)$——$n \le 50$ 时不过几千次基本操作，一次通过。

也没有「更聪明」的空间可言：3.2 说明本题没有任何决策供你优化，模拟本身就是全部。

### 3.2 核心观察：没有决策，只有执行

![强制操作与平局规则](images/c444_q1_merge_concept.svg)

**操作是被规则强制规定的**：被合并的对由「相邻和最小 + 平局取最左」唯一确定，与任何策略无关。于是「最小操作次数」就是这条**唯一路径**到达非递减时的步数——**直接模拟即是答案，也是唯一解**，不需要 DP，也不需要贪心证明。两个实现细节决定对错：

- **平局必须取最左**：比较时用**严格小于**才更新（相等不换人），天然保留下标更早的对。这不是装饰性规则——示例 3 中它直接把答案从 1 改写为 2。
- **有序判定是非递减**：只有 $a > b$ 才算逆序，$a = b$ 合法；C++ 的 `std::is_sorted` 恰好就是这个语义，可直接用。

另外留意值域：合并是**累加**，最坏全部并入一个元素时 $|\text{sum}| \le 50 \times 1000 = 5 \times 10^4$，`int` 绰绰有余。

### 3.3 算法流程

![算法流程](images/c444_q1_algorithm_flow.svg)

| 步骤 | 动作 | 说明 |
|------|------|------|
| ① 判有序 | 逐对检查 $a \le b$ | 非递减即停，$a = b$ 合法 |
| ② 找最小对 | 扫一遍，严格 $<$ 才更新 | 并列时自动保留最左对 |
| ③ 合并 | `nums[best] += nums[best+1]`，删除右格 | 长度减 1，`ops++` |
| ④ 回到 ① | 重新判定 | 至多 $n-1$ 轮，必然停机 |

### 3.4 示例演算

![两轮演算与负数例子](images/c444_q1_example_walkthrough.svg)

用官方示例 `nums = [5,2,3,1]` 逐步走一遍：

| 轮次 | 数组 | 相邻对和 | 合并（和最小） | 操作后 | 有序？ |
|------|------|----------|----------------|--------|--------|
| 1 | `[5,2,3,1]` | 7, 5, **4** | $(3,1)$，和 4 | `[5,2,4]` | 否（$5>2$） |
| 2 | `[5,2,4]` | 7, **6** | $(2,4)$，和 6 | `[5,6]` | 是（$5\le6$） |

两轮后非递减，答案 **2**。负数例子 `[2,2,-1]` 见上图下半部分：「和最小」比的是**代数和**，不是绝对值、也不是「找最小元素」——$(2,-1)$ 的和 $1$ 最小，先被合并。

## 4. 算法细节

1. **有序检查**：`is_sorted` / `all(a <= b)` 逐对扫描，$O(n)$；非递减语义（相等合法）与题目定义一致，无需手写。
2. **找最小和对**：初始化 `best = 0`，从 $i = 1$ 起用**严格小于**比较 `nums[i] + nums[i+1] < nums[best] + nums[best+1]` 才更新——并列时保留更早下标，天然实现「平局取最左」。
3. **合并**：`nums[best] += nums[best+1]` 后 `erase` 右格，数组缩短 1。$O(n)$ 的搬移在 $n \le 50$ 下无关痛痒（$10^5$ 规模才需要链表，见本场 Q4）。
4. **计数与返回**：每合并一次 `ops++`；循环退出时 `ops` 即答案。函数签名 `vector<int>&` 非 const，原地修改即可。
5. **值域**：元素绝对值 $\le 1000$、至多 49 次累加，$|\text{sum}| \le 5\times10^4$，`int` 足够，无需 `long long`。

## 5. 正确性证明

**引理 1（确定性）**：在数组尚未非递减的每一轮，被合并的数对唯一确定。

**证明**：当前长度 $m \ge 2$ 时相邻对共有 $m - 1$ 个，其和的取值中必存在最小值；若最小和有多对并列，题面规定取最左边一对，故被选中的对仍唯一。替换方式（用和替换）亦无选择余地。∎

**引理 2（停机性）**：模拟至多执行 $n - 1$ 轮。

**证明**：每轮合并使长度减 1。长度为 1 时元素无前驱，「非递减」定义平凡成立，循环条件在合并前将其拦下。从 $n$ 出发归纳，至多 $n - 1$ 轮后长度归 1 且判定为有序。∎

**定理**：模拟返回的 `ops` 等于题目所求的最小操作次数。

**证明**：由引理 1，从初始数组出发的合法操作序列是唯一的；题目所求的「最小操作次数」即该唯一序列中数组**首次**变为非递减所需的步数 $t$。模拟逐轮执行这条唯一序列，并在每轮合并后重新判定有序；由引理 2 它在有限轮内终止，且终止条件（非递减）首次成立的轮数恰为 $t$，即 `ops`。∎

> 💡 之所以不需要任何贪心交换论证，根源在引理 1：「最小」二字是障眼法——过程没有分支，模拟即最优（也是唯一）。

## 6. 复杂度分析

- **时间复杂度**：$O(n^2)$。由引理 2 至多 $n-1$ 轮，每轮「有序判定 + 找最小对 + 合并搬移」各 $O(n)$；$n = 50$ 时约 $2.5\times10^3$ 次基本操作。
- **空间复杂度**：$O(1)$。原地修改输入数组，仅常数个额外变量（若不允许改输入，复制一份也只多 $O(n)$）。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int minimumPairRemoval(vector<int>& nums) {
        int ops = 0;
        while (!is_sorted(nums.begin(), nums.end())) {
            int best = 0;  // 和最小相邻对的左端点；严格 < 才更新 ⇒ 平局自动取最左
            for (int i = 1; i + 1 < (int)nums.size(); i++) {
                if (nums[i] + nums[i + 1] < nums[best] + nums[best + 1]) {
                    best = i;
                }
            }
            nums[best] += nums[best + 1];
            nums.erase(nums.begin() + best + 1);
            ops++;
        }
        return ops;
    }
};
```

### Python

```python
class Solution:
    def minimumPairRemoval(self, nums: List[int]) -> int:
        ops = 0
        while any(a > b for a, b in zip(nums, nums[1:])):
            i = min(range(len(nums) - 1), key=lambda k: nums[k] + nums[k + 1])
            nums[i] += nums[i + 1]
            del nums[i + 1]
            ops += 1
        return ops
```

> 💡 Python 的 `min(range(...), key=...)` 在并列最小时返回**最小下标**，与「平局取最左」天然一致；C++ 用严格小于更新同理。长度为 1 的数组在有序检查处即被拦下，不会进入找最小对的越界分支。

## 8. 边界情况与易错点

1. **平局取最左**：比较必须用严格小于才更新。`[1,3,2,2]` 取最左答案是 2、取最右错成 1——本题最典型的 WA 点。
2. **非递减 ≠ 递增**：$a = b$ 合法（示例 2 的 `[1,2,2]` 答案为 0），判定条件是 `a > b` 才算逆序，误写成 `a >= b` 会多合并。
3. **负数按代数和比较**：「和最小」不是「绝对值最小」也不是「最小元素」；`[2,2,-1]` 先合并 $(2,-1)$。
4. **长度 1 / 初始有序**：都返回 0；`is_sorted` / `any` 放在循环条件处天然拦截，无需特判。
5. **溢出评估**：本题 $|\text{sum}| \le 5\times10^4$，`int` 足够；但同题面的 Q4（$n \le 10^5$、$|a| \le 10^9$）必须换 `long long`，迁移代码时要重查值域。
6. **别预排序**：操作对象是**相邻**对且必须逐步合并，先排序再统计会完全改变题意。
