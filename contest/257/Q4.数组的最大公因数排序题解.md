# LeetCode 数组的最大公因数排序 题解

## 1. 题目概述

- **标题 / 题号**：数组的最大公因数排序（#1998，hard）
- **链接**：https://leetcode.cn/problems/gcd-sort-of-an-array/
- **来源**：LeetCode 第 257 场周赛 Q4
- **难度**：困难
- **标签**：并查集、数学、质因数分解、排序、数论

**题意**：给定整数数组 `nums`，可以执行**任意次**操作：若 $\gcd(\text{nums}[i], \text{nums}[j]) > 1$，则交换 `nums[i]` 与 `nums[j]`。判断能否通过这些交换把 `nums` 变成**非递减**顺序，能返回 `true`，否则返回 `false`。

**约束**：

- $1 \le n \le 3 \times 10^4$
- $2 \le \text{nums}[i] \le 10^5$

> 💡 本题在本仓库另有[每日题解 1998](../../solution/1901-2000/1998_数组的最大公因数排序.md)：那边侧重 SPF 筛的实现细节与面试问答。本篇按周赛复盘视角，聚焦**赛场思考路径**（如何从「任意次交换」一步跳到「连通分量」）与**完整正确性证明**（为什么同分量就能任意重排——用置换群语言严格化），两篇互为印证。

## 2. 示例

**示例 1**

```text
输入：nums = [7,21,3]
输出：true
解释：
- 交换 7 和 21（gcd = 7）→ [21, 7, 3]
- 交换 21 和 3（gcd = 3）→ [3, 7, 21]   已排序
```

**示例 2**

```text
输入：nums = [5,2,6,2]
输出：false
解释：5 与其他任何元素的 gcd 都为 1，5 无法移动，卡死在位置 0。
```

**示例 3**

```text
输入：nums = [10,5,9,3,15]
输出：true
解释：
- 交换 10 和 15（gcd = 5）→ [15, 5, 9, 3, 10]
- 交换 15 和 3 （gcd = 3）→ [3, 5, 9, 15, 10]
- 交换 10 和 15（gcd = 5）→ [3, 5, 9, 10, 15]   已排序
```

## 3. 解题思路

### 3.1 暴力思路：两两 gcd 建图

交换的合法性由**值**决定：$\gcd(\text{nums}[i], \text{nums}[j]) > 1$ 就能换。最直觉的建模是把每个元素看作节点、对所有数对算 $\gcd$，$>1$ 就连边，再用 DFS / 并查集求**连通分量**；最后把数组排序，逐位检查「原值」与「目标值」是否同分量。

正确性没有问题，但**求所有数对的 $\gcd$ 是 $O(n^2 \log V)$**：$n = 3 \times 10^4$ 时约 $4.5 \times 10^8$ 次 $\gcd$ 运算，必然超时。

核心矛盾：我们需要刻画「能互相交换」的**等价关系**（其实是它的传递闭包），但**不能枚举所有数对**。

### 3.2 核心观察：质因子是「公共枢纽」

![核心观察：质因子作公共枢纽](images/wc257_q4_prime_hub.svg)

关键事实：

$$\gcd(a, b) > 1 \iff a, b \text{ 至少共享一个质因子}$$

于是「能直接交换」=「共享质因子」。若引入**质因子作为中转节点**：对数组中每个数 $x$，分解出全部不同质因子 $p_1, \dots, p_k$，在并查集中执行 $\text{union}(x, p_i)$。这样：

- **共享同一质因子的所有值**自然落入同一集合；
- 即便 $a$、$c$ 不直接共享质因子，只要存在 $b$（或一串值）把它们串起来，也会被并查集合并——**传递闭包由并查集免费维护**；
- 每个数只和**自己的**质因子合并，每个数至多 $6$ 个不同质因子（$2 \cdot 3 \cdot 5 \cdot 7 \cdot 11 \cdot 13 = 30030 \le 10^5$），总边数 $O(n \cdot \omega) \ll O(n^2)$。

> ⚠️ **赛场辨识信号**：见到「可交换 / 可到达 / 划等价类」就往**连通分量**想；见到「$\gcd > 1$ / 相邻 / 有公共因子」就往**质因子（或最小单位）作中转节点**想。这两个信号叠加，并查集几乎是唯一解。同款套路见 [952. 按公因数计算最大组件大小](https://leetcode.cn/problems/largest-component-size-by-common-factor/)。

### 3.3 算法流程

![算法流程：筛 spf、值域并查集、排序、逐位验根](images/wc257_q4_algorithm_flow.svg)

五步走：

1. **筛 SPF**：埃氏筛变体预处理 $[2, M]$ 内每个数的最小质因子 `spf[x]`，$M = \max(\text{nums})$，使单次分解降为 $O(\log x)$。
2. **初始化并查集**：`parent[0..M]`，数值本身做下标（质因子 $p \le x \le M$ 也在范围内，值与质因子共用一套下标，无需映射）。
3. **分解 + 合并**：遍历 `nums`（可去重），对每个 $x$ 用 `spf` 逐个取出质因子，`union(x, p)` 并把 $p$ 一次性除尽。
4. **排序**：得到目标数组 `target`。
5. **逐位验根**：对每个 $i$，若 $\text{find}(\text{nums}[i]) \ne \text{find}(\text{target}[i])$ 返回 `false`；全部通过返回 `true`。

### 3.4 示例演算

![示例演算：分解、union、逐位验根](images/wc257_q4_example_walkthrough.svg)

以示例 3 `nums = [10, 5, 9, 3, 15]` 走查：

- **分解**：$10 = 2 \times 5$、$5 = 5$、$9 = 3^2$、$3 = 3$、$15 = 3 \times 5$；
- **合并**：`union(10,2)`、`union(10,5)` 得 $\{10,2,5\}$；`union(9,3)` 得 $\{9,3\}$；`union(15,3)` 把 15 并入 $\{9,3\}$，`union(15,5)` 再经 5 把两团桥接——**全部并入同一集合** $\{10,2,5,9,3,15\}$；
- **验根**：`target = [3,5,9,10,15]`，逐位 `find` 均相同 → 返回 `true`。

> 💡 注意位置 0 与 3：需要把 $10$ 与 $3$ 互换，但 $\gcd(10,3) = 1$ **不能直接换**——靠 $15$ 中转（$10 \xleftrightarrow{5} 15 \xleftrightarrow{3} 3$）完成链式交换。这正是「传递闭包」的直观体现，也是证明部分要严格化的核心。

## 4. 算法细节

1. **数值即下标**：$\text{nums}[i] \le 10^5$，`parent` 开 $M + 1$ 大小；任意 $x \le M$ 的质因子 $p \le x \le M$，值与质因子共用一套下标。若值域更大（如 $10^9$），需改为「对每个数试除分解 + 哈希并查集」。
2. **SPF 筛**：`spf[x]` 存 $x$ 的最小质因子，埃氏筛变体：从小到大枚举 $i$，若 `spf[i] == i` 说明 $i$ 是质数，把 $i$ 的倍数中尚未标记的 `spf` 设为 $i$。分解时 `p = spf[v]` 取出最小质因子，`while v % p == 0: v //= p` 一次性除尽——同一质因子只 `union` 一次（$9 = 3^2$ 只 `union(9,3)` 一次）。
3. **每个数至多 6 个不同质因子**：$\omega(x) \le 6$（$2 \cdot 3 \cdot 5 \cdot 7 \cdot 11 \cdot 13 = 30030 \le 10^5 < 510510$），故第 3 步总量 $\le 6n \approx 1.8 \times 10^5$ 次 `union`。
4. **去重加速**：重复值只分解一次（Python 遍历 `set(nums)`）；C++ 不去重也只是幂等 `union`，不影响正确性。
5. **逐位比较的是「值」**：并查集按数值建，`find(nums[i])` 查的是「数值 `nums[i]` 所属分量」。排序后位置 $i$ 应放的值是 `target[i]`，只要两值同根，就能经分量内链式交换把 `target[i]` 挪到位。重复元素自然通过（同值必同根）。
6. **SPF 与试除的选择**：不预处理 SPF、对每个 $x$ 试除到 $\sqrt{x}$ 也行（$O(n\sqrt{M}) \approx 10^7$，C++ 可过），但 Python 下约 $10^7$ 次取模会超时——先筛 SPF 更稳。

## 5. 正确性证明

**引理 1**（合法交换的封闭性）：任何一次合法交换所交换的两个值共享质因子，故属同一分量；因此**每个分量的值占据的下标集合在全部操作过程中保持不变**。

**证明**：设交换发生在下标 $i, j$，合法性给出 $\gcd(\text{nums}[i], \text{nums}[j]) > 1$，取公共质因子 $p$。算法中 `nums[i]` 与 `nums[j]` 都曾与 $p$ 合并，故同根、属同一分量。交换只互换同分量两值的下标，不影响任何分量占据的下标集合。∎

**引理 2**（两种连通等价）：算法构造的并查集分量 = 「值—质因子」二部图的连通分量 = **值-图**（顶点为值，两值相邻 $\iff \gcd > 1$）的连通分量。

**证明**：并查集只执行 $\text{union}(x, p)$，其连通性即二部图连通性。二部图中任何值到值的路径形如 $x - p_1 - z_1 - p_2 - \cdots - y$（交替经过质因子），其中相邻两个值共享中间质因子，压缩即得值-图路径 $x - z_1 - \cdots - y$；反之值-图的一条边 $(x, y)$ 对应二部图路径 $x - p - y$（$p$ 为任一公共质因子）。两图连通性相同，而并查集分量恰按二部图连通性合并。∎

**引理 3**（分量内任意置换可达）：设某分量的值-图连通，则该分量的值在其占据的下标集合上可达成**任意排列**。

**证明**：关键在于：**一次交换是否合法只取决于被交换的两个「值」**——$\gcd$ 是值的函数，与下标无关。于是「交换值 $u$ 与值 $w$」（只要 $\gcd(u,w) > 1$，即值-图中相邻）是一条**随时可执行**的原子操作，它作用在当前排列上恰好是值集合上的**对换** $(u\ w)$。重复值可视为带下标的可区分 token，不影响论证。

由引理 2，分量内值-图连通。经典结论：**连通图的边所对应的对换生成全集上的对称群**。证明该结论：只需证任意两顶点 $u, w$ 的对换 $(u\ w)$ 可被生成。取图中路径 $u = x_0, x_1, \dots, x_k = w$，反复使用「梭子」恒等式

$$(x_0\, x_1)(x_1\, x_2)(x_0\, x_1) = (x_0\, x_2),$$

可把路径首段逐步吞并：$(x_0\, x_2)$ 与 $(x_2\, x_3)$ 再梭一次得 $(x_0\, x_3)$，归纳得 $(x_0\, x_k) = (u\ w)$。全部对换生成对称群，故任意排列可达。∎

**定理**：`nums` 可经合法交换变为非递减 $\iff$ 对每个 $i$，`nums[i]` 与 `sorted(nums)[i]` 在并查集中同根。

**证明**：

（$\Longrightarrow$ 必要性）由引理 1，每个分量占据的下标集合不变。设 `target = sorted(nums)`。若存在 $i$ 使 `nums[i]` 属分量 $C$ 而 `target[i]` 属分量 $D \ne C$：因 `nums` 与 `target` 是同一多重集的排列，$C$ 的值在两数组中个数相同，$D$ 亦然；下标 $i$ 起初计入 $C$ 的位置集、终局计入 $D$ 的位置集，与两个位置集均不变矛盾。

（$\Longleftarrow$ 充分性）设所有位置同根。对任意分量 $C$：位置 $i$ 满足 $\text{nums}[i] \in C \iff \text{target}[i] \in C$（否则该位置两值不同根，与假设矛盾），故 $C$ 的初始位置集与终局位置集相同，且两集合上 $C$ 的值构成同一多重集。由引理 3，$C$ 的值可在这批位置上置换成 `target` 的排列；又由引理 1，一切合法交换本就发生在分量内部，各分量互不干扰。逐分量执行置换，合并即得整体非递减。∎

> 💡 **证明的灵魂**是引理 3 的第一句话：交换合法性只看「值」不看「位置」。这把动态的、依赖当前局面的一系列交换，抽象成值集合上一组**固定可用的对换**，问题瞬间变成纯群论——连通图的对换生成对称群。

## 6. 复杂度分析

- **时间复杂度**：$O(M \log \log M + n \log n)$，其中 $M = \max(\text{nums}) \le 10^5$：
  - 埃氏筛求 SPF：$O(M \log \log M)$；
  - 分解 + 合并：每个数至多 $6$ 个不同质因子，共 $O(n \cdot \omega) \le 6n$ 次 `union`，均摊（路径压缩 + 按需合并）近 $O(1)$；
  - 排序：$O(n \log n)$；
  - 逐位验根：$n$ 次 `find`，近线性。
  - 本题规模下总操作约 $3 \times 10^5$ 量级，毫秒级完成。
- **空间复杂度**：$O(M)$，即 `parent` 与 `spf` 两个长度 $M + 1$ 的数组。

## 7. 参考代码

### C++（SPF 筛 + 值域并查集）

```cpp
class Solution {
    vector<int> parent, spf;

    int find(int x) {
        return parent[x] == x ? x : parent[x] = find(parent[x]);
    }
    void unite(int a, int b) {
        a = find(a); b = find(b);
        if (a != b) parent[a] = b;
    }

public:
    bool gcdSort(vector<int>& nums) {
        int M = *max_element(nums.begin(), nums.end());
        // 埃氏筛求最小质因子
        spf.resize(M + 1);
        for (int i = 0; i <= M; ++i) spf[i] = i;
        for (int i = 2; (long long)i * i <= M; ++i)
            if (spf[i] == i)                          // i 是质数
                for (int j = i * i; j <= M; j += i)
                    if (spf[j] == j) spf[j] = i;
        // 值域并查集：数值即下标，质因子也在 [2, M] 内
        parent.resize(M + 1);
        for (int i = 0; i <= M; ++i) parent[i] = i;
        // 每个值与它的所有不同质因子合并（质因子作公共枢纽）
        for (int x : nums) {
            int v = x;
            while (v > 1) {
                int p = spf[v];
                unite(x, p);
                while (v % p == 0) v /= p;            // 一次性除尽
            }
        }
        // 排序后逐位验根
        vector<int> target(nums);
        sort(target.begin(), target.end());
        for (int i = 0; i < (int)nums.size(); ++i)
            if (find(nums[i]) != find(target[i])) return false;
        return true;
    }
};
```

### Python（SPF 筛 + 并查集 + 隔代压缩）

```python
class Solution:
    def gcdSort(self, nums: List[int]) -> bool:
        M = max(nums)
        # 埃氏筛求最小质因子
        spf = list(range(M + 1))
        for i in range(2, int(M ** 0.5) + 1):
            if spf[i] == i:                           # i 是质数
                for j in range(i * i, M + 1, i):
                    if spf[j] == j:
                        spf[j] = i
        # 值域并查集
        parent = list(range(M + 1))

        def find(x):
            while parent[x] != x:
                parent[x] = parent[parent[x]]         # 隔代压缩
                x = parent[x]
            return x

        # 每个值与它的所有不同质因子合并（去重，重复值只分解一次）
        for x in set(nums):
            v = x
            while v > 1:
                p = spf[v]
                rx, rp = find(x), find(p)
                if rx != rp:
                    parent[rx] = rp
                while v % p == 0:
                    v //= p
        # 排序后逐位验根
        target = sorted(nums)
        return all(find(a) == find(b) for a, b in zip(nums, target))
```

## 8. 边界情况与易错点

1. **$n = 1$ 直接可排**：单元素无需交换，逐位验根自然通过（同值同根），无需特判。
2. **质数值的质因子是自身**：如 $x = 7$，分解得 $p = 7$，`union(7, 7)` 幂等无害。示例 2 中孤立的 $5$ 正是因此独占一个分量，谁也换不动它。
3. **重复元素**：同值必同根，逐位验根自动通过；用 `set` 去重只是性能优化，不影响正确性。
4. **筛的循环边界**：外层条件用 `(long long)i * i <= M` 或 `i <= M / i` 防溢出（$i$ 最大约 $316$，`i * i` 用 `int` 恰不溢出，但换更大的 $M$ 就危险）；内层从 $i \cdot i$ 起步。
5. **必须与「排序后的目标」逐位比**：不是比较 multiset 是否同分量，而是每个位置的原值与目标值同根——不同位置可以有同分量的不同值互换。
6. **值域前提**：`parent` / `spf` 开 $M + 1$ 依赖 $\text{nums}[i] \le 10^5$；若值域 $10^9$，改为对每个数试除分解 $O(\sqrt{V})$ + 哈希表并查集（值与质因子都进哈希）。
7. **Python 性能**：直接对每个数试除到 $\sqrt{x}$ 约 $10^7$ 次取模，CPython 大概率超时；先筛 SPF（约 $10^5$ 次内层操作）再 $O(\log x)$ 分解，稳过。
8. **「局部可换」不等于「全局可排」**：判断必须落到**排序目标的逐位对应**上。反直觉的例子：$[6, 10, 15]$ 两两 $\gcd$ 分别为 $2, 3, 5$，人人有同伴、全连通，可任意重排；而 $[5, 2, 6, 2]$ 中 $5$ 虽有「同伴般」的邻居，却孤悬分量外——只看分量形状不够，必须逐位对准排序后的目标值。
