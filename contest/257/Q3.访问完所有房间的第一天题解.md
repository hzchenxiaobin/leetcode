# LeetCode 访问完所有房间的第一天 题解

## 1. 题目概述

- **标题 / 题号**：访问完所有房间的第一天（#1997，medium）
- **链接**：https://leetcode.cn/problems/first-day-where-you-have-been-in-all-the-rooms/
- **来源**：LeetCode 第 257 场周赛 Q3
- **难度**：中等
- **标签**：动态规划、前缀和、数学

**题意**：有 $n$ 个房间（编号 $0$ 到 $n-1$）和一个从 $0$ 开始递增的日期编号，每天恰好访问一个房间。第 $0$ 天访问 $0$ 号房间。给定数组 `nextVisit`，访问规则为：设当天访问房间 $i$——

- 若算上本次，房间 $i$ 被访问**奇数次** → 次日访问 `nextVisit[i]`（保证 $0 \le \text{nextVisit}[i] \le i$）；
- 若算上本次，房间 $i$ 被访问**偶数次** → 次日访问 $(i + 1) \bmod n$。

返回**所有房间都被至少访问过一次的第一天**的日期编号，对 $10^9 + 7$ 取余。

**约束**：

- $2 \le n \le 10^5$
- $0 \le \text{nextVisit}[i] \le i$

> 💡 本题在本仓库另有[每日题解 1997](../../solution/1901-2000/1997_访问完所有房间的第一天.md)：那边侧重审题信号与面试问答。本篇按周赛复盘视角，聚焦**赛场推理链**（「取模」信号如何倒逼 DP 状态设计）与**引理—定理式证明**（确定性 + 偶性不变量 + 轨迹重放），两篇互为印证。

## 2. 示例

**示例 1**

```text
输入：nextVisit = [0,0]
输出：2
解释：
  第 0 天访问房间 0（第 1 次，奇）→ 次日去 nextVisit[0] = 0
  第 1 天访问房间 0（第 2 次，偶）→ 次日去 (0 + 1) mod 2 = 1
  第 2 天访问房间 1 —— 第一次访问完所有房间的那天
```

**示例 2**

```text
输入：nextVisit = [0,0,2]
输出：6
解释：访问序列 [0,0,1,0,0,1,2,...]，第 6 天首次到访房间 2。
```

**示例 3**

```text
输入：nextVisit = [0,1,2,0]
输出：6
解释：访问序列 [0,0,1,1,2,2,3,...]，第 6 天首次到访房间 3。
```

## 3. 解题思路

### 3.1 暴力思路：逐日模拟

按规则一天一天模拟，维护每个房间的访问次数，直到所有房间都被访问过。忠实模拟必然正确，但**模拟步数恰好等于答案本身**。答案有多大？考察最坏情形 `nextVisit` 全为 $0$：每个房间 $i$ 首访后都要从房间 $0$ 一路重走回来，天数按 $2$ 的幂翻倍，真实答案是 $2^n - 2$——$n = 10^5$ 时约 $3$ 万位十进制数字。逐日模拟连边都摸不到。

> ⚠️ **「答案对 $10^9 + 7$ 取模」是本题最响的信号**：过程是**完全确定**的（没有任何选择），却要取模，说明天数大到必须用数学手段直接算出，而不是把过程走一遍。正确姿势是：**不模拟过程，给天数建立递推**。

### 3.2 核心观察：折返结构 + 轨迹重放

![核心观察：奇数次访问跳回 nextVisit[i]，折返腿原路重放后才能前进](images/wc257_q3_foldback_concept.svg)

三条观察环环相扣：

1. **`nextVisit[i] ≤ i`：永远不超前**。跳边只能往回（或原地），前进边只有 $i \to i+1$ 一条。于是房间 $1, 2, \dots$ 依次被首次到访，「访问完所有房间的第一天」就是**首访房间 $n-1$ 的那天**。
2. **偶数次才能前进**：每个房间必须「一来一回」被访问两次（先奇后偶）才放行，过程天然形成「推进—折返—再推进」的阶段结构。
3. **偶性不变量 + 确定性 ⇒ 轨迹重放**（本题为难的核心，也是能 DP 的根基）：首访房间 $i$ 时，房间 $0..i-1$ 各被访问了**偶数次**（引理见 §5）。首访 $i$（奇）后次日跳回 $j = \text{nextVisit}[i]$，此刻的奇偶状态与**当初首访 $j$ 时完全一致**；又因为明天去哪只由「当前位置 + 各房奇偶」决定，**折返腿会逐日重放过去「首访 $j$ 到首访 $i$」的那段轨迹**，耗时也就完全相同。

据此定义阶段耗时：

$$\text{dp}[i] = \text{首访 } i \text{ 到首访 } i+1 \text{ 之间经过的天数}$$

首访 $i$ 后的流程拆为三段：花 $1$ 天跳回 $j$；折返腿耗时 $\text{dp}[j] + \text{dp}[j+1] + \dots + \text{dp}[i-1]$ 天（$j = i$ 时区间为空）；再访 $i$（偶）后花 $1$ 天前进到 $i+1$。合计：

$$\text{dp}[i] = 2 + \sum_{k=\text{nextVisit}[i]}^{i-1} \text{dp}[k]$$

其中「$+2$」= 首访 $i$ 的次日 + 再访 $i$ 的次日。当 $\text{nextVisit}[i] = i$ 时区间和为空，公式自动给出 $\text{dp}[i] = 2$，无需特判——示例 3 正是每处 $\text{nextVisit}[i] = i$，答案 $2 \times 3 = 6$。

### 3.3 算法流程：前缀和 + 单趟线性递推

![算法流程：前缀和加速的线性 DP](images/wc257_q3_algorithm_flow.svg)

递推里出现了**区间和** $\sum_{k=j}^{i-1}\text{dp}[k]$，用前缀和 $\text{pre}[i] = \sum_{k=0}^{i-1}\text{dp}[k]$（$\text{pre}[0] = 0$）把每次转移降到 $O(1)$：

$$\text{dp}[i] = 2 + \text{pre}[i] - \text{pre}[\text{nextVisit}[i]]$$

$$\text{pre}[i+1] = \text{pre}[i] + \text{dp}[i]$$

**完整步骤**：

1. **初始化**：$\text{pre}[0] = 0$，$\text{MOD} = 10^9 + 7$。
2. **循环** $i = 0, 1, \dots, n-2$：
   - $j = \text{nextVisit}[i]$；
   - $\text{dp}[i] = \big(2 + \text{pre}[i] - \text{pre}[j] + \text{MOD}\big) \bmod \text{MOD}$（$+\text{MOD}$ 防取模后相减为负）；
   - $\text{pre}[i+1] = \big(\text{pre}[i] + \text{dp}[i]\big) \bmod \text{MOD}$。
3. **返回** $\text{pre}[n-1]$。

> ⚠️ **为什么答案是 $\text{pre}[n-1]$**：第 $0$ 天首访房间 $0$，经 $\text{dp}[0]$ 天首访房间 $1$……经 $\text{dp}[n-2]$ 天首访房间 $n-1$。总天数 $= \sum_{k=0}^{n-2}\text{dp}[k] = \text{pre}[n-1]$。房间 $n-1$ 是最后被首访的（观察 1），首访它即「全部到访」。**循环只需到 $n-2$**，$\text{dp}[n-1]$ 对应一个不存在的阶段。

### 3.4 示例演算

![示例演算：逐日序列与 DP 计算](images/wc257_q3_example_walkthrough.svg)

以 `nextVisit = [0, 0, 2]`（$n=3$）走查：

**逐日访问序列**：`[0, 0, 1, 0, 0, 1, 2]`（第 $0 \sim 6$ 天）。第 $2$ 天首访房间 $1$（奇）→ 第 $3$ 天跳回房间 $0$ → 第 $3$、$4$ 天**逐日重放**阶段 $0$ 的两天 → 第 $5$ 天再访房间 $1$（偶）→ 第 $6$ 天首访房间 $2$。

**DP 计算**：

| $i$ | $j=\text{nextVisit}[i]$ | $\text{dp}[i] = 2 + \text{pre}[i] - \text{pre}[j]$ | $\text{pre}[i+1]$ |
|-----|------------------------|---------------------------------------------------|-------------------|
| 0   | 0                      | $2 + 0 - 0 = 2$                                   | $2$               |
| 1   | 0                      | $2 + 2 - 0 = 4$                                   | $6$               |

**答案** $= \text{pre}[2] = 6$ ✓

> 💡 $\text{dp}[1] = 4$ 的直观含义：首访 $1$（第 $2$ 天）→ 跳回 $0$ → 重放 $\text{dp}[0] = 2$ 天回到房间 $1$（第 $5$ 天）→ 前进到房间 $2$（第 $6$ 天），$2 + 2 = 4$ 天。

## 4. 算法细节

1. **状态设计为「阶段耗时」而非「首访日期」**：若直接定义 $d[i]$ 为首访 $i$ 的日期，递推等价变形为 $d[i+1] = 2\,d[i] - d[j] + 2$，能用但不直观；定义 $\text{dp}[i]$ 后，「跳回重走」直接对应区间和 $\sum_{k=j}^{i-1}\text{dp}[k]$，语义与公式一眼对齐，且 $d[i]$ 就是前缀和 $\text{pre}[i]$，答案即 $\text{pre}[n-1]$。
2. **前缀和是唯一的优化点**：朴素递推每步求区间和是 $O(n)$、总计 $O(n^2)$（约 $10^{10}$，不可行）；前缀和把转移降到 $O(1)$，总体 $O(n)$。
3. **$j = i$ 无需特判**：$\text{nextVisit}[i] = i$ 时 $\text{pre}[i] - \text{pre}[j] = 0$，公式自动给出 $\text{dp}[i] = 2$（首访当天 + 次日再访后前进）。
4. **取模防负**：$\text{pre}[i]$ 与 $\text{pre}[j]$ 都是余数，相减可能为负——C++ 必须先 $+\text{MOD}$ 再取模；Python 的 `%` 恒非负，保留 $+\text{MOD}$ 只是与 C++ 写法对齐。
5. **循环上界 $n-2$**：房间 $n-1$ 首访即终点，「首访 $n$」的阶段不存在，$\text{dp}[n-1]$ 不用算。
6. **空间的下限**：$j$ 可取 $0..i$ 中任意值，$\text{pre}[j]$ 需要随机访问，前缀和数组必须整体保留——$O(n)$ 空间是这套递推的固有开销，无法滚动成 $O(1)$。

## 5. 正确性证明

**引理 1（首访有序与活动范围）**：首次到访按 $0, 1, \dots, n-1$ 的次序依次发生；且首访 $i$ 与首访 $i+1$ 之间，访问序列只经过房间 $0..i$。

**证明**：位置转移只有两种：奇数次时跳到 $\text{nextVisit}[i] \le i$（不增），偶数次时前进到 $i+1$（$i < n-1$ 时 $(i+1) \bmod n = i+1$；$i = n-1$ 时的环边从不生效——首访 $n-1$ 即终点）。于是进入房间 $k \ge 1$ 的唯一途径是 $k-1$ 的前进边。归纳：首访 $i$ 后，要首访新房间只能经 $i \to i+1$，这条边只在房间 $i$ 被访问偶数次后开放；期间所有跳边目标 $\le i$，故阶段内活动范围是 $0..i$。∎

**引理 2（确定性）**：给定当前房间位置与各房间访问次数的奇偶向量，其后的整个访问过程被唯一确定；每次访问恰使当前房间的计数奇偶翻转。

**证明**：规则是（位置， 奇偶向量）的函数：当前房间奇 → 跳 $\text{nextVisit}[\cdot]$，偶 → 前进；而访问使当前房间计数 $+1$（奇偶翻转）。对天数归纳即得。∎

**引理 3（偶性不变量与轨迹重放）**：对每个 $i \ge 0$，记 $j = \text{nextVisit}[i]$：

- (a) 首访 $i$ 时，房间 $0..i-1$ 各被访问**偶数次**（房间 $i$ 恰为第 $1$ 次）；
- (b) 若 $j < i$：从「跳回 $j$ 的那天」到「再访 $i$ 的那天」，访问序列与当初「首访 $j$」到「首访 $i$」的访问序列**逐日相同**，间隔同为 $\sum_{k=j}^{i-1}\text{dp}[k]$ 天，且结束时房间 $0..i-1$ 又全为偶数次；
- (c) 若 $j = i$：次日即再访 $i$，房间 $0..i-1$ 未被触碰，保持偶性。

**证明**：对 $i$ 强归纳。$i = 0$：(a) 空集平凡；$\text{nextVisit}[0] = 0 = i$，属 (c)：首访 $0$（奇）→ 次日再访 $0$（偶）→ 次日首访 $1$。成立。

设引理对一切 $k < i$ 成立，证 $i$：

(a)：首访 $i$ 发生在阶段 $i-1$ 的末尾（从 $i-1$ 前进一步），故房间 $i-1$ 计数为偶。对阶段 $i-1$ 用归纳假设：若 $\text{nextVisit}[i-1] < i-1$，由 (b) 其折返腿结束时房间 $0..i-2$ 全偶；若 $= i-1$，由 (c) 房间 $0..i-2$ 保持首访 $i-1$ 时的偶性。(a) 得证。

(b)：首访 $i$（第 $1$ 次，奇）后次日跳到 $j$。此刻奇偶向量：房间 $0..j-1$ 为偶（(a)，本阶段尚未触碰），房间 $j$ 刚被访问、由偶翻奇，房间 $j+1..i-1$ 为偶（(a)，各 $\ge 2$ 次）；当前位置 $j$。而当初首访 $j$ 那天（对 $j < i$ 用归纳假设 (a)）：房间 $0..j-1$ 偶、房间 $j$ 刚翻奇、房间 $j+1..i-1$ 为 $0$ 次——**也是偶**。两个时刻在房间 $0..i-1$ 上的奇偶向量完全一致，位置也同为 $j$。由引理 2，两个过程从各自该天起走出**逐日相同**的房间序列，直到其中一方首次到达房间 $i$（由引理 1，此前的序列只在 $0..i-1$ 内，两过程中房间 $i$ 计数的差异不影响任何决策）。当初那段恰在 $\text{d}[i] - \text{d}[j] = \sum_{k=j}^{i-1}\text{dp}[k]$ 天后首访 $i$（按 $\text{dp}$ 定义逐阶段拼接），故折返腿间隔同为该值；且结束时刻奇偶向量与当初首访 $i$ 时一致，即 $0..i-1$ 全偶。

(c)：$j = i$ 时次日访问的仍是房间 $i$（计数翻偶），房间 $0..i-1$ 全程未动。∎

**定理（递推与答案）**：$\text{dp}[i] = 2 + \sum_{k=\text{nextVisit}[i]}^{i-1}\text{dp}[k]$（空和为 $0$，统一覆盖 $j = i$），且答案 $= \sum_{k=0}^{n-2}\text{dp}[k] \bmod (10^9+7)$。

**证明**：首访 $i$ 当天为第 $\text{d}[i]$ 天。次日（$+1$ 天）跳到 $j$；由引理 3 (b)/(c)，再访 $i$ 在 $+\sum_{k=j}^{i-1}\text{dp}[k]$ 天后；再访使计数为偶，次日（再 $+1$ 天）首访 $i+1$。故 $\text{dp}[i] = \text{d}[i+1] - \text{d}[i] = 2 + \sum_{k=j}^{i-1}\text{dp}[k]$。由引理 1，首访次序为 $0, 1, \dots, n-1$ 且 $\text{d}[0] = 0$，故「访问完所有房间的第一天」$= \text{d}[n-1] = \sum_{k=0}^{n-2}\text{dp}[k]$。∎

> 💡 **证明的灵魂**是引理 2 + 引理 3 (b)：把「指数长的未来」压缩成「已算好的过去的重放」。确定性过程里，相同的奇偶状态必然走出相同的轨迹——这正是能跳过模拟、直接递推天数的全部依据。

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。单趟循环 $i = 0 \dots n-2$，每步一次查表（$\text{pre}[j]$）与常数次加减取模。对比暴力：模拟步数 $=$ 答案本身，最坏 $\Theta(2^n)$。
- **空间复杂度**：$O(n)$。`pre` 数组长度 $n$；由于 $\text{pre}[\text{nextVisit}[i]]$ 需随机访问，无法滚动优化。`nextVisit` 为输入不计。

## 7. 参考代码

### C++（前缀和优化 DP）

```cpp
class Solution {
  public:
    int firstDayBeenInAllRooms(vector<int>& nextVisit) {
        const int MOD = 1e9 + 7;
        int n = nextVisit.size();
        vector<long long> pre(n);                       // pre[i] = dp[0] + ... + dp[i-1]
        for (int i = 0; i + 1 < n; ++i) {               // 只需递推到 dp[n-2]
            long long dp = (2 + pre[i] - pre[nextVisit[i]] + MOD) % MOD;
            pre[i + 1] = (pre[i] + dp) % MOD;
        }
        return pre[n - 1];                              // 答案 = dp[0] + ... + dp[n-2]
    }
};
```

### Python

```python
class Solution:
    def firstDayBeenInAllRooms(self, nextVisit: List[int]) -> int:
        MOD = 10**9 + 7
        n = len(nextVisit)
        pre = [0] * n                                   # pre[i] = dp[0] + ... + dp[i-1]
        for i in range(n - 1):                         # 只需递推到 dp[n-2]
            j = nextVisit[i]
            dp = (2 + pre[i] - pre[j] + MOD) % MOD     # + MOD 防负（Python 可省，与 C++ 对齐）
            pre[i + 1] = (pre[i] + dp) % MOD
        return pre[n - 1] % MOD
```

> 💡 两个版本都已对拍验证：官方三示例（2 / 6 / 6）与 $n = 10^5$ 的全零最坏用例（$2^{100000} - 2 \bmod (10^9+7) = 607723518$）一致；此外 $n \le 7$ 的全部 $5912$ 组输入与暴力模拟逐一对拍通过。

## 8. 边界情况与易错点

1. **答案是 $\text{pre}[n-1]$，不是 $\text{dp}[n-1]$**：$\text{dp}[n-1]$ 描述「首访 $n-1 \to$ 首访 $n$」这个不存在的阶段；循环上界 $n-2$，别多算一步也别少算一步。
2. **取模后的负数**：$\text{pre}[i] - \text{pre}[j]$ 是两个余数相减，可能为负——C++ 忘写 $+\text{MOD}$ 会直接输出负数或 WA；Python 的 `%` 恒非负，天然免疫。
3. **$j = i$ 不用特判**：$\text{nextVisit}[i] = i$ 时公式自动给 $2$（示例 3 全是这种情形）；手写 `if` 分支反而容易漏掉「首访次日」与「再访次日」各占 $1$ 天。
4. **最小规模 $n = 2$**：循环恰好执行一次，$\text{dp}[0] = 2$ 即答案（示例 1）。
5. **别用「天数达到某阈值」做模拟终止条件**：天数最坏 $2^n - 2$，且题目只给取模后的答案——真实天数在模拟中照样会爆炸（大整数），取模后又丢失信息，此路不通。
6. **C++ 溢出审计**：各项 $< \text{MOD} < 2^{30}$，$2 + \text{pre}[i] - \text{pre}[j] + \text{MOD} < 2^{31}$ 名义上不溢 `int`，但用 `long long` 存 `pre` 与中间量更稳健；返回值必在 `int` 范围内。
7. **「偶数次」按单个房间计数，且「算上本次」**：判断发生在访问当天、以该房间的历史访问次数（含当天）为准——模拟暴力里最容易把奇偶判断放在移动之后再做，差一天全错。
8. **题面为 2021 年老题**：无「Create the variable…」类注入语句，按题意正常实现即可。

**延伸思考**：

- **若允许 $\text{nextVisit}[i] > i$**（跳到未访问房间）：首访次序不再单调、偶性不变量失效，本篇递推崩塌——这也解释了题面为何特意保证 $\text{nextVisit}[i] \le i$。
- **在线询问「首访房间 $x$ 在第几天」**：预处理 $\text{pre}$ 后每次 $O(1)$ 回答 $\text{pre}[x] \bmod p$；若要精确值需大整数（$n = 10^5$ 最坏约 $3$ 万位）。
- **「第 $k$ 天访问哪个房间」**：$k$ 天文级，但可利用各阶段长度 $\text{dp}[i]$ 从后往前二分定位到阶段，再在「折返腿 = 过去重放」的结构内递归定位——把指数长的过程折叠成 $O(n)$ 级查询。
- **规则推广为「访问次数是 $m$ 的倍数才前进」**：同样的重放论证逐字成立（把「奇偶」换成「模 $m$ 的余数」），首访 $i$ 后要经历 $m-1$ 次「跳回 + 重放」，递推变为 $\text{dp}[i] = (m-1)\big(1 + \sum_{k=j}^{i-1}\text{dp}[k]\big) + 1$；$m = 2$ 时恰退化为 $2 + \sum_{k=j}^{i-1}\text{dp}[k]$。
