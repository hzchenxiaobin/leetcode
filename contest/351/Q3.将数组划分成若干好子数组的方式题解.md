# LeetCode 将数组划分成若干好子数组的方式 题解

## 1. 题目概述

- **标题 / 题号**：将数组划分成若干好子数组的方式（#2750，medium）
- **链接**：https://leetcode.cn/problems/ways-to-split-array-into-good-subarrays/
- **来源**：LeetCode 第 351 场周赛 Q3
- **难度**：中等
- **标签**：数组、数学、动态规划

**题意**：给定二元数组 `nums`。若一个子数组**恰好**只含**一个**值为 $1$ 的元素，则称其为**好子数组**。统计把 `nums` 划分成若干好子数组的方案数，对 $10^9 + 7$ 取余后返回。划分即把数组切成若干连续非空段。

**约束**：

- $1 \le \text{nums.length} \le 10^5$
- $\text{nums[i]} \in \{0, 1\}$

> 💡 读题第一眼就该抓住的点：**划分 = 选一个切点集合**。$n-1$ 个间隙每个「切 / 不切」，看似 $2^{n-1}$ 种组合，但「每段恰含一个 1」这个约束极其刚性——它把切点的自由度压缩到**相邻两个 1 之间**，方案数不是指数级而是**各空隙宽度的乘积**。

## 2. 示例

**示例 1**

```text
输入：nums = [0,1,0,0,1]
输出：3
解释：[0,1] | [0,0,1]、[0,1,0] | [0,1]、[0,1,0,0] | [1]
```

**示例 2**

```text
输入：nums = [0,1,0]
输出：1
解释：只有一个 1，整段 [0,1,0] 本身就是好子数组，不切即唯一方案。
```

**示例 3（自补：无 1）**

```text
输入：nums = [0,0,0]
输出：0
解释：任何划分都至少含一个全 0 段（1 的个数为 0 ≠ 1），无合法方案。
```

**示例 4（自补：多空隙）**

```text
输入：nums = [1,0,1,0,1]
输出：4
解释：1 在下标 0、2、4，两个空隙各 2 选 1，共 2 × 2 = 4 种。
```

## 3. 解题思路

### 3.1 暴力思路：枚举切点子集

在 $n-1$ 个间隙里每个独立地「切 / 不切」，共 $2^{n-1}$ 种划分，每种再 $O(n)$ 检查每段是否恰含一个 `1`，总复杂度 $O(2^n \cdot n)$——$n = 10^5$ 时是天文数字。

更关键的是暴力的**浪费**：合法划分的结构完全由 `1` 的位置支配，与枚举到的具体切点组合无关。两个 `1` 之间必须切、没有 `1` 的区域禁止切——先把这两条结构性质提炼出来，方案数就能直接**算**出来。

### 3.2 核心观察：相邻 1 之间恰放一个切点

![核心观察：相邻1之间恰放一个切点](images/good_split_gaps_concept.svg)

设 `1` 的下标为 $p_1 < p_2 < \cdots < p_k$。一个划分等价于一个切点集合（在下标 $c$ 与 $c+1$ 之间切开）。**「每段恰含一个 1」逐字翻译成切点语言**：

1. **相邻 1 之间必须切**：若 $p_i$ 与 $p_{i+1}$ 之间无切点，二者落入同一段，该段含两个 `1`，非法；
2. **相邻 1 之间只能切一次**：若切两次，两个切点之间夹出一段不含任何 `1` 的全 0 段，非法；
3. **$p_1$ 之前、$p_k$ 之后禁止切**：否则首 / 尾出现全 0 段。首尾的 `0` 只能分别并入第一段、最后一段，**不产生任何选择**。

于是切点的自由度只剩：在每对相邻 `1` 之间**恰选一个切点**。切点可放在「紧跟 $p_i$ 之后」到「紧贴 $p_{i+1}$ 之前」的任意间隙，共 $p_{i+1} - p_i$ 个候选（= 中间 `0` 的个数 + 1）。**各空隙互相独立，乘法原理**直接给出：

$$\text{ans} = \prod_{i=1}^{k-1} \left( p_{i+1} - p_i \right) \bmod \left( 10^9 + 7 \right)$$

两个边界：$k = 0$（无 `1`）时无合法划分，返回 $0$；$k = 1$ 时空乘积为 $1$（整段即好子数组，不切即唯一方案）。

### 3.3 算法流程：一次扫描，遇 1 累乘下标差

![算法流程：一次扫描遇到1就累乘下标差](images/good_split_flow.svg)

不需要显式收集 `1` 的位置数组，一遍扫描即可——维护「上一个 `1` 的下标 `prev`」与累乘器 `ans`，遇到 `1` 时若之前见过 `1` 就把下标差乘进去：

```text
1. prev ← −1，ans ← 1
2. for i = 0 … n−1:
3.     若 nums[i] = 1:
4.         若 prev ≠ −1: ans ← ans × (i − prev) mod (10⁹+7)
5.         prev ← i
6. 返回 prev = −1 ? 0 : ans
```

相邻两次遇到的 `1` 恰好是 $p_i$ 与 $p_{i+1}$，乘进去的 $(i - \text{prev})$ 恰为空隙宽度——扫描过程就是乘积公式的在线版。

### 3.4 示例演算

![示例演算：扫描0,1,0,0,1与三个边界](images/good_split_walkthrough.svg)

以 $[0,1,0,0,1]$ 为例：$i=1$ 遇首个 `1`，仅记录 `prev = 1`；$i=4$ 再遇 `1`，`ans ← 1 × (4−1) = 3`；结束 `prev ≠ −1` 返回 $3$，与示例一致。再验证 $[1,0,1,0,1]$：$\text{ans} = (2-0) \times (4-2) = 4$，两个空隙各 2 选 1，乘法原理成立。

## 4. 算法细节

1. **状态极简**：只需 `prev`（上一个 `1` 的下标）与 `ans`（累乘器）两个变量，无需开 `1` 的位置数组。等价写法是先收集所有 `1` 的下标再逐对相乘，二者完全等价，扫描版少一次遍历。
2. **DP 视角与「塌缩」**：定义 $f[j]$ 为把前 $j$ 个元素完整划分成好子数组、且 $j$ 处是段边界的方案数（$f[0]=1$）。设新一段的唯一 `1` 位于 $q$、其前一个 `1` 位于 $P$，则上一段边界 $j$ 可取 $(P,\, q]$ 中任意整数——这个区间里没有 `1`，所有 $f[j]$ 全相等（都等于扫完上一个 `1` 后的累计值 $F$），求和塌缩成乘法：

$$f\text{ 的更新} \;=\; \sum_{j \in (P,\,q]} f[j] \;=\; (q - P) \times F$$

   这正是代码里 `ans = ans * (i - prev)` 的由来。**线性计数 DP 一旦「转移区间内 dp 值恒等」，就塌缩成乘法原理**——这也是判断该写 DP 还是找闭式的信号。
3. **取模时机**：每乘一次立即 `% (10^9+7)`。因子 $\le n-1 < 10^5 < 2^{17}$，`ans` $< 2^{30}$，C++ 中 `long long` 乘积 $< 2^{47}$ 绝对安全，`int` 相乘则会溢出。
4. **返回值兜底**：`prev == -1`（一个 `1` 都没见过）返回 `0`；`k = 1` 时不进任何乘法，返回初值 `1`，恰好就是空乘积的正确值，无需特判。

## 5. 正确性证明

**引理 1（切点刻画）**：设 `1` 的下标 $p_1 < \cdots < p_k$（$k \ge 1$）。切点集合 $C \subseteq \{0,\dots,n-2\}$（$c \in C$ 表示在下标 $c$ 与 $c+1$ 之间切开）对应合法划分，当且仅当：

- (a) 对每个 $1 \le i < k$：$|C \cap \{p_i,\, p_i+1,\, \dots,\, p_{i+1}-1\}| = 1$；
- (b) $C$ 中不含任何 $< p_1$ 或 $\ge p_k$ 的切点。

**证明**：（⇒）设划分合法，每段恰含一个 `1`。若违反 (b)，如存在切点 $c < p_1$，则 $c$ 与上一个切点（或数组开头）之间的一段全部位于 $p_1$ 之前、全为 `0`，非法；$c \ge p_k$ 时其后段同理全 0，非法。若 (a) 中区间内无切点，则 $p_i$ 与 $p_{i+1}$ 之间无切开，落入同一段，该段至少两个 `1`，非法；若区间内有 $c < c'$ 两个切点，则段 $[c+1,\, c']$ 夹在 $p_i$ 与 $p_{i+1}$ 之间（下标均落在 $(p_i, p_{i+1})$ 内），不含任何 `1` 且非空，非法。（⇐）满足 (a)(b) 时，设 $C = \{c_1 < \cdots < c_{k-1}\}$ 且 $c_i \in [p_i,\, p_{i+1}-1]$，则各段为 $[0, c_1],\, [c_1+1, c_2],\, \dots,\, [c_{k-1}+1,\, n-1]$：首段含 $p_1$ 且不含 $p_2$（$c_1 \le p_2 - 1$），恰一个 `1`；中间段 $[c_i+1, c_{i+1}]$ 恰含 $p_{i+1}$（$c_i \ge p_i$ 排除 $p_i$，$c_{i+1} \le p_{i+2}-1$ 排除 $p_{i+2}$）；末段恰含 $p_k$；各段均非空。故划分合法。∎

**引理 2（独立计数）**：$k \ge 1$ 时，合法切点集合与序列 $(c_1, \dots, c_{k-1})$（$c_i$ 独立取自 $\{p_i, \dots, p_{i+1}-1\}$，共 $p_{i+1} - p_i$ 种）一一对应。

**证明**：由引理 1，合法 $C$ 在每个区间 $\{p_i, \dots, p_{i+1}-1\}$ 中恰含一个元素，取出即为该序列；各区间互不相交，不同序列拼出的 $C$ 互不相同，反之任意选取拼出的 $C$ 由引理 1 的 (⇐) 方向合法。选取互相独立，由乘法原理，合法划分数为 $\prod_{i=1}^{k-1} (p_{i+1} - p_i)$。∎

**定理**：算法返回值正确——$k = 0$ 时返回 $0$，否则返回 $\prod_{i=1}^{k-1} (p_{i+1} - p_i) \bmod (10^9+7)$。

**证明**：$k = 0$ 时全程未遇 `1`，`prev == -1`，返回 $0$，与「无合法划分」一致。$k \ge 1$ 时，扫描中依序遇到的 `1` 即 $p_1, \dots, p_k$：首个 `1`（$p_1$）处 `prev = -1` 不触发乘法，此后每遇 $p_{i+1}$（$i \ge 1$）恰执行一次 `ans ← ans × (p_{i+1} − p_i)`，`prev` 依次更新为 $p_2, \dots, p_k$。故最终 `ans` = $\prod_{i=1}^{k-1} (p_{i+1} - p_i)$ 逐次对 $10^9+7$ 取模的结果（模乘法逐次合法）。由引理 2，该值即方案数。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$——单次遍历，遇 `1` 做 $O(1)$ 乘法与取模，遇 `0` 直接跳过；`1` 的个数不超过 $n$。
- **空间复杂度**：$O(1)$——只维护 `prev` 与 `ans` 两个变量，不随输入规模增长。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int numberOfGoodSubarraySplits(vector<int>& nums) {
        const int MOD = 1'000'000'007;
        long long ans = 1;
        int prev = -1;
        for (int i = 0; i < (int)nums.size(); i++) {
            if (nums[i] == 1) {
                if (prev != -1) {
                    ans = ans * (i - prev) % MOD;
                }
                prev = i;
            }
        }
        return prev == -1 ? 0 : (int)ans;
    }
};
```

### Python

```python
class Solution:
    def numberOfGoodSubarraySplits(self, nums: List[int]) -> int:
        MOD = 10**9 + 7
        ans = 1
        prev = -1
        for i, x in enumerate(nums):
            if x == 1:
                if prev != -1:
                    ans = ans * (i - prev) % MOD
                prev = i
        return 0 if prev == -1 else ans
```

## 8. 边界情况与易错点

1. **全 0 数组返回 0（头号坑）**：`[0,0,0]` 时「空乘积 = 1」的直觉是错的——乘积公式的前提是 $k \ge 1$。必须用 `prev == -1` 兜底返回 `0`，否则交上去直接 WA 在最小的一档用例上。
2. **恰一个 1 返回 1**：`[0,1,0]`、`[1]` 都不进任何乘法，靠初值 `ans = 1` 自然返回 1，初值别手滑写成 0。
3. **因子是下标差，不是 0 的个数**：因子为 $p_{i+1} - p_i$（中间 `0` 的个数 **加一**）。相邻两个 `1` 贴着（`[...,1,1,...]`）时因子为 1（只能贴着切），别写成 0；想成「中间 0 各自归左归右」时也别数漏「整块归属」。
4. **C++ 溢出**：`ans × (i − prev)` 最大约 $10^9 \times 10^5 = 10^{14}$，`int` 相乘必然溢出，`ans` 必须声明为 `long long` 且逐次取模。
5. **首尾的 0 无需处理**：$p_1$ 之前、$p_k$ 之后的 `0` 被迫并入首段 / 末段，不产生选择，扫描代码天然正确——不要画蛇添足地去乘它们。
6. **别误上 DP 数组**：DP 塌缩成乘积（见 §4），开 $f$ 数组纯属浪费空间；比赛时直接推公式更快更稳。
