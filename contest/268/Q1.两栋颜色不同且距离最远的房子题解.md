# LeetCode 两栋颜色不同且距离最远的房子 题解

## 1. 题目概述

- **标题 / 题号**：两栋颜色不同且距离最远的房子（#2078，easy）
- **链接**：https://leetcode.cn/problems/two-furthest-houses-with-different-colors/
- **来源**：LeetCode 第 268 场周赛 Q1
- **难度**：简单
- **标签**：贪心、数组

**题意**：街上有 $n$ 栋房子排成一列，`colors[i]` 表示第 $i$ 栋房子的颜色。返回两栋**颜色不同**的房子之间的**最大**距离，其中房子 $i$ 与 $j$ 的距离为 $\lvert i - j \rvert$。数据保证至少存在两栋颜色不同的房子。

**约束**：

- `n == colors.length`
- $2 \le n \le 100$
- $0 \le colors[i] \le 100$
- 生成的测试数据满足**至少**存在 2 栋颜色不同的房子

## 2. 示例

**示例 1**

```text
输入：colors = [1,1,1,6,1,1,1]
输出：3
解释：房子 0（颜色 1）与房子 3（颜色 6）颜色不同，距离 |0-3| = 3。
房子 3 与房子 6 同理也是一组最优答案。
```

**示例 2**

```text
输入：colors = [1,8,3,8,3]
输出：4
解释：房子 0（颜色 1）与房子 4（颜色 3）颜色不同，距离 |0-4| = 4。
```

**示例 3**

```text
输入：colors = [0,1]
输出：1
解释：房子 0 与房子 1 颜色不同，距离 1。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有下标对 $(i, j)$（$i < j$），当 $colors[i] \ne colors[j]$ 时用 $j - i$ 更新答案。时间复杂度 $O(n^2)$，本题 $n \le 100$，约 $10^4$ 次比较也能通过。但周赛签到题也应追求 $O(n)$ 的观察解，下面给出更优做法。

### 3.2 核心观察：最优对必含端点

![核心观察：最优对必含端点](images/furthest_houses_concept.svg)

**关键结论**：答案对应的两栋房子中，**必有一栋是最左端（0 号）或最右端（$n-1$ 号）的房子**。

因此只需计算两个候选：

- **候选一（配左端点）**：最大的 $j$ 使得 $colors[j] \ne colors[0]$，配对 $(0, j)$，距离为 $j$；
- **候选二（配右端点）**：最小的 $i$ 使得 $colors[i] \ne colors[n-1]$，配对 $(i, n-1)$，距离为 $n-1-i$。

答案即 $\max(j,\ n-1-i)$。直观理解：要让距离尽量大，就应该把其中一栋房子"推"到数组的两端去。

### 3.3 算法流程

一次遍历即可同时维护两个候选：对每个下标 $k$，

1. 若 $colors[k] \ne colors[0]$，用 $k$ 更新候选一；
2. 若 $colors[k] \ne colors[n-1]$，用 $n-1-k$ 更新候选二；
3. 最终返回两个候选的最大值。

遍历结束后，候选一自动取到"最大的 $j$"，候选二自动取到"最小的 $i$"（因为越小的 $i$ 对应越大的 $n-1-i$，取 max 后留下的一定是最左的异色房子）。

### 3.4 示例演算

![示例演算：一次遍历两个候选取max](images/furthest_houses_walkthrough.svg)

以 `colors = [1,1,1,6,1,1,1]` 为例：

| 步骤 | 检查 | 结果 |
|------|------|------|
| 候选一 | $colors[0]=1$，从右向左第一个 $\ne 1$ 的房子在 $j=3$（颜色 6） | $3$ |
| 候选二 | $colors[6]=1$，从左向右第一个 $\ne 1$ 的房子在 $i=3$（颜色 6） | $6-3=3$ |
| 答案 | $\max(3, 3)$ | $3$ ✓ |

以 `colors = [1,8,3,8,3]` 为例：

| 步骤 | 检查 | 结果 |
|------|------|------|
| 候选一 | $colors[0]=1$，从右向左第一个 $\ne 1$ 的房子在 $j=4$（颜色 3） | $4$ |
| 候选二 | $colors[4]=3$，从左向右第一个 $\ne 3$ 的房子在 $i=1$（颜色 8） | $4-1=3$ |
| 答案 | $\max(4, 3)$ | $4$ ✓ |

## 4. 算法细节

1. **双向扫描合并为单次遍历**：对每个下标 $k$ 同时与 $colors[0]$ 和 $colors[n-1]$ 比较是否异色，各自更新候选。
2. **候选一的正确取法**：配左端点时要找**最大**的 $j$——遍历中不断用更靠右的异色下标覆盖即可。
3. **候选二的正确取法**：配右端点时要找**最小**的 $i$——因为距离 $n-1-i$ 随 $i$ 减小而增大，取 max 后保留的恰是最左的异色下标。
4. **数据保证有解**：约束保证至少存在两栋异色房子，因此两个候选中至少一个会被更新，无需特判无解。

## 5. 正确性证明

**引理 1**：存在一对最优解 $(i, j)$（$i < j$，$colors[i] \ne colors[j]$，且 $j-i$ 最大），满足 $i = 0$ 或 $j = n-1$。

**证明**：反证。设某最优对 $(i, j)$ 满足 $i \ge 1$ 且 $j \le n-2$。由 $colors[i] \ne colors[j]$，对 $colors[0]$ 与 $colors[n-1]$ 分类：

- 若 $colors[j] \ne colors[0]$：则 $(0, j)$ 是合法异色对，距离 $j > j - i$，与 $(i,j)$ 的最优性矛盾；
- 否则 $colors[j] = colors[0]$，此时必有 $colors[i] \ne colors[0]$（否则 $colors[i] = colors[j]$）。再对 $colors[n-1]$ 分类：
  - 若 $colors[n-1] \ne colors[i]$：则 $(i, n-1)$ 是合法异色对，距离 $n-1-i > j-i$，矛盾；
  - 若 $colors[n-1] = colors[i]$：则 $colors[0] = colors[j] \ne colors[i] = colors[n-1]$，即 $(0, n-1)$ 是合法异色对，距离 $n-1 > j-i$，矛盾。

所有情形均矛盾，故最优对必含端点。∎

**定理**：算法返回两栋颜色不同房子之间的最大距离。

**证明**：算法输出 $= \max(\text{候选一}, \text{候选二})$。一方面，两个候选都是真实存在的异色对距离，故输出 $\le$ 最优值。另一方面，由引理 1，存在最优对含端点：

- 若形如 $(0, j^*)$：候选一取的是最大的 $j$ 使 $colors[j] \ne colors[0]$，故候选一 $\ge j^* - 0$；
- 若形如 $(i^*, n-1)$：候选二取的是最小的 $i$ 使 $colors[i] \ne colors[n-1]$，故候选二 $\ge n-1-i^*$。

两种情形下输出均 $\ge$ 最优值。结合两方面，输出 $=$ 最优值。∎

![反证法：不含端点的最优对总能被拉得更长](images/furthest_houses_proof.svg)

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。单次遍历数组，每个下标做两次颜色比较。
- **空间复杂度**：$O(1)$。只使用常数个变量（`ans`、`n`）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maxDistance(vector<int>& colors) {
        int n = colors.size();
        int ans = 0;
        for (int i = 0; i < n; ++i) {
            if (colors[i] != colors[0]) ans = max(ans, i);              // 配对 (0, i)
            if (colors[i] != colors[n - 1]) ans = max(ans, n - 1 - i);  // 配对 (i, n-1)
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maxDistance(self, colors: List[int]) -> int:
        n = len(colors)
        ans = 0
        for i, c in enumerate(colors):
            if c != colors[0]:
                ans = max(ans, i)            # 配对 (0, i)
            if c != colors[-1]:
                ans = max(ans, n - 1 - i)    # 配对 (i, n-1)
        return ans
```

## 8. 边界情况与易错点

1. **只扫一个方向会 WA**：例如 `colors = [1,2,2,2,1]`，只配左端点得到候选 $2$（房子 0 与房子 2），但正确答案是 $3$（房子 1 与房子 4，配右端点）。两个方向都必须检查。
2. **最小规模**：$n = 2$ 且两栋异色时，两个候选都算出 $1$，正确。
3. **端点自身异色**：若 $colors[0] \ne colors[n-1]$，答案直接是 $n-1$，算法的两个候选都会覆盖该情况。
4. **无解情况不存在**：题目数据保证至少两栋异色，无需处理 `ans == 0` 的返回约定；若题目不保证，需与出题方确认返回值。
5. **$O(n^2)$ 暴力也能过**：$n \le 100$ 时暴力约 $10^4$ 次比较，比赛时可作为保底；但端点观察的 $O(n)$ 解更值得沉淀。
