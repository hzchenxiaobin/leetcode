# LeetCode 统计字典序元音字符串的数目 题解

## 1. 题目概述

- **标题 / 题号**：统计字典序元音字符串的数目（#1641，medium）
- **链接**：https://leetcode.cn/problems/count-sorted-vowel-strings/
- **来源**：LeetCode 第 213 场周赛 Q2
- **难度**：中等
- **标签**：数学、动态规划、组合数学

**题意**：给定整数 $n$，返回长度为 $n$、仅由元音 `a`、`e`、`i`、`o`、`u` 组成、且**按字典序排列**（非降）的字符串个数。非降指：对所有有效的 $i$，`s[i]` 在字母表中的位置不晚于 `s[i+1]`——等价地，串必然形如 $a^{c_a} e^{c_e} i^{c_i} o^{c_o} u^{c_u}$（各段可为空）。

**约束**：

- $1 \le n \le 50$

> 💡 这是一道**披着字符串外衣的计数题**：非降条件把「字符串」压成了「多重集」——每种元音取几个，就**唯一确定**一个字符串。识破这一点，答案就是一个隔板法组合数 $\binom{n+4}{4}$；识不破，线性 DP 也只需一遍前缀和。两个解法在杨辉三角里胜利会师。




## 3. 解题思路

### 3.1 暴力思路：枚举全部 $5^n$ 个字符串

生成所有长度 $n$ 的元音字符串、逐个检查非降，复杂度 $O(5^n \cdot n)$——$n = 50$ 时约 $8.9 \times 10^{34}$ 个串，天文数字。即使在搜索里加「非降剪枝」，真正的问题也浮出水面：**合法串的生成过程只由「结尾字符」决定**，前面的历史毫无影响。把这一点显式化成状态，就是 DP。

### 3.2 核心观察：结尾字符定乾坤——线性 DP

![核心观察：新字符不小于结尾才能保持非降，转移构成下三角前缀和](images/1641_dp_transition_concept.svg)

1. **前缀封闭与尾接规则**：非降串去掉最后一个字符仍是非降串；反之，往非降串尾部追加一个**不小于当前结尾**的元音，得到的仍是非降串——新增的相邻对是唯一可能违规的位置。合法串「接下来能接什么」**只取决于结尾字符**，与更前面的内容无关，**无后效性**成立。
2. **状态设计**：$f(i, j)$ = 长度为 $i$、以第 $j$ 个元音结尾（$j = 0..4$ 对应 a, e, i, o, u）的非降串个数。边界 $f(1, j) = 1$。
3. **转移即前缀和**：结尾为 $j$ 的串，其倒数第二个字符可以是 $0..j$ 中任何元音，故

$$f(i, j) = \sum_{k=0}^{j} f(i-1, k), \qquad \text{ans}(n) = \sum_{j=0}^{4} f(n, j).$$

15 条转移边恰好构成一张**下三角**图：沿字符串从左到右，结尾字符的「档位」只增不减。

### 3.3 算法流程：一行数组的原地前缀和

```text
1. 初始化 f[0..4] = 1                （长度 1：每个元音各一个串）
2. 重复 n−1 轮（对应长度 2..n）：
       for j = 1 .. 4：              ← 必须从左到右
           f[j] += f[j−1]            （原地前缀和）
3. 返回 f[0] + f[1] + f[2] + f[3] + f[4]
```

**原地更新为何正确**：$j$ 升序推进时，更新 $f[j]$ 之前 $f[j-1]$ 已是新值（$= \sum_{k \le j-1} f_{\text{old}}(k)$），于是新 $f[j] = f_{\text{old}}(j) + \sum_{k < j} f_{\text{old}}(k) = \sum_{k \le j} f_{\text{old}}(k)$，恰为转移方程。

### 3.4 示例演算

![递推表逐行演进：行=长度、列=结尾元音，每行滚一遍前缀和](images/1641_dp_table_walkthrough.svg)

以 $n = 1 \dots 4$ 走查（行 = 长度 $i$，列 = 结尾元音，最右列 = 行和即答案）：

| $i$ ＼ 结尾 | a | e | i | o | u | ans |
|------------|---|---|---|---|---|-----|
| 1 | 1 | 1 | 1 | 1 | 1 | **5** |
| 2 | 1 | 2 | 3 | 4 | 5 | **15** |
| 3 | 1 | 3 | 6 | 10 | 15 | **35** |
| 4 | 1 | 4 | 10 | 20 | 35 | **70** |

$n = 2$ 时行和为 15，与示例 2 逐个列出的一致 ✓。表里还有两个白送的观察：

- **u 列 = 上一行答案**：$f(n, u) = \text{ans}(n-1)$——以 u 结尾意味着前面 $n-1$ 个字符任意非降都行。
- **斜着看是杨辉三角**：$f(i, j) = \binom{i+j-1}{j}$，暗示闭式就在眼前。

### 3.5 换视角：多重集 + 隔板法，一步到闭式

![组合视角：非降串一一对应五桶分球，隔板法得 C(n+4,4)](images/1641_stars_bars_bijection.svg)

非降 ⇒ 串必然形如 $a^{c_a} e^{c_e} i^{c_i} o^{c_o} u^{c_u}$，与计数向量 $(c_a, c_e, c_i, c_o, c_u)$（$c \ge 0$，$\sum c = n$）**一一对应**。于是答案 = 把 $n$ 个相同的球放进 5 个有序桶的方案数，隔板法一步写出：

$$\text{ans}(n) = \binom{n + 4}{4}.$$

验证：$n = 1:\ \binom{5}{4} = 5$ ✓；$n = 2:\ \binom{6}{4} = 15$ ✓；$n = 33:\ \binom{37}{4} = 66045$ ✓（示例 3）。

DP 与闭式由**曲棍球恒等式**（hockey stick）衔接：$\sum_{j=0}^{4} \binom{n-1+j}{j} = \binom{n+4}{4}$——两个解法在杨辉三角里殊途同归。

## 4. 算法细节

1. **状态与边界**：$f(1, j) = 1$；转移 $f(i, j) = \sum_{k \le j} f(i-1, k)$。滚动成一维数组后每轮只做 4 次加法。
2. **遍历方向**：原地前缀和必须 $j$ **升序**。若降序，$f[j] += f[j-1]$ 两侧都是旧值，算出的是「相邻两项之和」$f_{\text{old}}(j) + f_{\text{old}}(j-1)$，与转移方程完全不符。
3. **对称写法**：也可定义 $g(i, j)$ = 以第 $j$ 个元音**开头**的长度 $i$ 非降串数，则 $g(i, j) = \sum_{k \ge j} g(i-1, k)$，从右往左滚前缀和，答案相同（把串整体反过来即可互推）。
4. **组合数实现**：$\binom{n+4}{4} = \frac{(n+1)(n+2)(n+3)(n+4)}{24}$ 迭代计算：第 $t$ 步后恰为 $\binom{n+1+t}{t+1}$，**每步除法都整除**，无精度与余数问题。
5. **值域宽裕**：$n \le 50$ 时最大答案 $\binom{54}{4} = 316251$，32 位 `int` 轻松装下——计数题里少见的「不用担心溢出」。
6. **记忆化搜索**也可（状态 $(i, j)$ 仅 $50 \times 5$ 个），但递推版 4 次加法/轮，更短更快。

## 5. 正确性证明

**引理 1（前缀封闭与尾接规则）**：设 $s$ 是长度 $i-1$ 的非降元音串，结尾为第 $k$ 个元音。则：(a) $s$ 去掉末字符后仍非降；(b) $s$ 追加第 $j$ 个元音得到的新串非降 $\iff j \ge k$。

**证明**：非降条件逐对约束相邻字符。追加字符 $c$ 只引入一个新的相邻对（旧结尾, $c$），其余对不变，故新串非降当且仅当旧结尾 $\le c$，即 $j \ge k$；(a) 删除末字符只减少一个相邻对，剩余约束原样保留。∎

**引理 2（递推成立）**：$f(1, j) = 1$，且 $f(i, j) = \sum_{k=0}^{j} f(i-1, k)$。

**证明**：长度 $i$、以第 $j$ 个元音结尾的非降串 $t$，与二元组 $(t', j)$ 一一对应，其中 $t'$ 为 $t$ 去掉末字符所得的长度 $i-1$ 串（由引理 1(a) 非降），$j$ 为被追加的元音序号。由引理 1(b)，$t$ 非降 $\iff$ $t'$ 的结尾 $k \le j$。故按 $t'$ 的结尾分类，$f(i, j) = \sum_{k \le j} |\{t' : \text{结尾} = k\}| = \sum_{k \le j} f(i-1, k)$。边界：长度 1 的非降串恰为 5 个单字符。∎

**定理 1（DP 正确性）**：算法返回 $\text{ans}(n) = \sum_{j=0}^{4} f(n, j)$。

**证明**：长度 $n$ 的非降串按结尾字符分为 5 类，互不相交且覆盖全集，故答案为各类之和。对长度 $i$ 归纳：$i = 1$ 时初始化正确；设第 $i-1$ 轮后数组等于 $f(i-1, \cdot)$，原地更新中 $j$ 升序保证（见 §3.3）新 $f[j] = \sum_{k \le j} f_{\text{old}}(k)$，由引理 2 恰为 $f(i, j)$。循环执行 $n-1$ 轮后数组即 $f(n, \cdot)$，求和返回。∎

**定理 2（组合闭式）**：$\text{ans}(n) = \binom{n+4}{4}$。

**证明**：定义映射 $\varphi$：非降串 $t \mapsto$ 计数向量 $(c_a(t), \dots, c_u(t))$，显然 $\sum c = n$、$c \ge 0$。
- **单射**：非降串中同类字符连续成段、且五段按 a < e < i < o < u 固定顺序排列，故各字符个数唯一确定该串。
- **满射**：任给满足约束的 $(c_a, \dots, c_u)$，串 $a^{c_a} e^{c_e} i^{c_i} o^{c_o} u^{c_u}$ 长度为 $n$ 且非降。

故答案 = 方程 $c_a + c_e + c_i + c_o + c_u = n$ 的非负整数解个数；将 $n$ 个 ★ 与 4 块隔板排成一行，隔板切出的五段依次装入五个桶，共 $n + 4$ 个位置中选 4 个放隔板，即 $\binom{n+4}{4}$。∎

**推论（两解法一致）**：$f(n, j) = \binom{n-1+j}{j}$。

**证明**：对 $n$ 归纳：$n=1$ 时 $\binom{j}{j} = 1$ ✓；设 $n-1$ 成立，则由引理 2 与 Pascal 恒等式，$f(n, j) = \sum_{k \le j} \binom{n-2+k}{k} = \binom{n-1+j}{j}$。于是 $\text{ans}(n) = \sum_{j=0}^{4} \binom{n-1+j}{j} = \binom{n+4}{4}$（曲棍球恒等式），定理 1 与定理 2 给出同一数值。∎

## 6. 复杂度分析

- **时间复杂度**：DP 为 $O(5n) = O(n)$，每轮固定 4 次加法，$n \le 50$ 至多 196 次加法；组合闭式 $O(1)$（4 次乘除）。
- **空间复杂度**：$O(5) = O(1)$，一个长度 5 的滚动数组；组合闭式连数组都不需要。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int countVowelStrings(int n) {
        int f[5] = {1, 1, 1, 1, 1};            // 长度 1：以各元音结尾各 1 个
        for (int len = 2; len <= n; ++len)
            for (int j = 1; j < 5; ++j)        // 升序！原地前缀和
                f[j] += f[j - 1];
        return f[0] + f[1] + f[2] + f[3] + f[4];
    }
};
```

组合数学版（隔板法闭式，第 $t$ 步后恰为 $\binom{n+1+t}{t+1}$，每步整除）：

```cpp
class Solution {
public:
    int countVowelStrings(int n) {
        long long ans = 1;
        for (int t = 0; t < 4; ++t) ans = ans * (n + 1 + t) / (t + 1);
        return (int)ans;                       // C(n+4, 4)，n=50 时 316251
    }
};
```

### Python

```python
class Solution:
    def countVowelStrings(self, n: int) -> int:
        f = [1] * 5                            # 长度 1
        for _ in range(n - 1):
            for j in range(1, 5):              # 升序原地前缀和
                f[j] += f[j - 1]
        return sum(f)
```

```python
from math import comb

class Solution:
    def countVowelStrings(self, n: int) -> int:
        return comb(n + 4, 4)                  # 隔板法一步到位
```

## 8. 边界情况与易错点

1. **$n = 1$**：主循环不执行，直接返回 $1 \times 5 = 5$，与示例 1 一致，无需特判。
2. **前缀和方向反了 = 经典 WA**：`j` 必须升序。降序时 `f[j] += f[j-1]` 两边都是旧值，得到 $f_{\text{old}}(j) + f_{\text{old}}(j-1)$，逐轮错得离谱（$n=2$ 会返回 $1+2+2+2+2=9$ 而非 15）。
3. **别把非降当严格递增**：严格递增的长度 $n$ 串只有 $\binom{5}{n}$ 个（$n > 5$ 时为 0）；示例 2 里 `"aa"` 合法是最直白的提醒。
4. **字典序方向**：是「不晚于后一个字符」，a 最小、u 最大——别把 u 当开头字符；`"ea"` 非法正是方向反了的典型。
5. **组合数乘除顺序**：先乘后除时中间值会放大（本题 $\le 7.6 \times 10^6$，`long long` 毫无压力）；迭代版每步除法整除，不需要取模或分数处理。Python 直接 `math.comb`。
6. **答案量级**：$\binom{54}{4} = 316251$，`int` 足够——但写惯了计数题的话，顺手 `long long` 防手滑不亏。
7. **递归深搜不加记忆化**：纯 DFS 是 $O(5^n)$ 指数级；加记忆化后状态仅 $50 \times 5$，但既然递推 4 行写完，没必要上搜索。
