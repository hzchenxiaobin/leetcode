# LeetCode 构造相同颜色的正方形 题解

## 1. 题目概述

- **标题 / 题号**：构造相同颜色的正方形（#3127，easy）
- **链接**：https://leetcode.cn/problems/make-a-square-with-the-same-color/
- **来源**：LeetCode 第 129 场双周赛 Q1
- **难度**：简单
- **标签**：数组、枚举、矩阵

**题意**：给定一个 $3 \times 3$ 的字符矩阵 `grid`，每个格子是 `'B'`（黑）或 `'W'`（白）。你**最多可以改变一个格子的颜色**，问能否让矩阵中出现一个 $2 \times 2$ 的四格同色正方形。

**约束**：

- `grid.length == 3`，`grid[i].length == 3`
- `grid[i][j]` 只能是 `'B'` 或 `'W'`
- 允许**改 0 个**格子（即原本就有同色 $2 \times 2$ 也算成功）

> 💡 题面里混入了一段 `.grid-container { ... }` 的 CSS 残留，那是网页渲染样式，与算法无关，读题时直接跳过。

## 2. 示例

**示例 1**

```text
输入：grid = [["B","W","B"],["B","W","W"],["B","W","B"]]
输出：true
解释：把 grid[0][2] 的 B 改成 W，右下 2×2 块变成 W W / W W，成功。
```

**示例 2**

```text
输入：grid = [["B","W","B"],["W","B","W"],["B","W","B"]]
输出：false
解释：这是棋盘格，每个 2×2 块都恰好两黑两白，改一格凑不出四格同色。
```

**示例 3**

```text
输入：grid = [["B","W","B"],["B","W","W"],["B","W","W"]]
输出：true
解释：右下 2×2 块已经是 W W / W W，一格都不用改。
```

**示例 4（边界补充）**

```text
输入：grid = [["B","B","B"],["B","B","B"],["B","B","B"]]
输出：true
解释：本来四块全黑，改 0 格即可。
```

## 3. 解题思路

### 3.1 暴力思路

最直白的做法是「真的去改」：枚举不改 + 枚举 9 个格子各改一次，共 10 种局面，对每种局面扫描 4 个 $2 \times 2$ 块看是否四格同色。总操作量约 $10 \times 4 \times 4 = 160$ 次比较，跑得动，但代码分支多、还容易把「改回来」写错。

既然矩阵尺寸被钉死成 $3 \times 3$，真正值得推敲的是**判据**本身：一个块需要改几格才能变全同色？

### 3.2 核心观察：只看块内少数色的个数

![一次改动能救的只有这四种计数](images/bw129_q1_count_rule.svg)

把注意力放在**某一个** $2 \times 2$ 块上，块内一共 4 格，设黑色格数为 $c$，则白色格数为 $4 - c$。分类讨论：

| $c$ | 形态 | 需要改几格 | 可行 |
|-----|------|-----------|------|
| 4 | 全黑 | 0 | ✓ |
| 3 | 三黑一白 | 1（把白改黑） | ✓ |
| 2 | 两黑两白 | 2 | ✗ |
| 1 | 一黑三白 | 1（把黑改白） | ✓ |
| 0 | 全白 | 0 | ✓ |

于是判据非常短：**块内 $c \ne 2$ 即可行**。$c = 2$ 是唯一的坏形态，因为改一格只会让计数变成 $1$ 或 $3$，仍在「两色并存」的坑里。

由此，全局问题退化为：**4 个 $2 \times 2$ 块里，是否存在一块满足 $c \ne 2$**。

### 3.3 算法流程

```text
1. 枚举 2×2 块的左上角 (i, j)，其中 i, j ∈ {0, 1}，共 4 块
2. 对每块统计黑色格数 c
3. 若 c != 2：立即返回 true
4. 4 块都不满足：返回 false
```

注意「4 个块互相重叠」这一点完全不影响结论：题目只要求**存在**一个同色块，我们对着目标块改它自己的格子就行，其它块变成什么样都无所谓。

### 3.4 示例演算

![示例 1：4 个 2×2 块逐个查](images/bw129_q1_four_blocks.svg)

示例 1 的 `grid` 为

```text
B W B
B W W
B W B
```

四个块分别是：

| 块左上角 | 四格 | 黑格数 | 结论 |
|----------|------|--------|------|
| $(0,0)$ | B W / B W | 2 | ✗ |
| $(0,1)$ | W B / W W | 1 | ✓ |
| $(1,0)$ | B W / B W | 2 | ✗ |
| $(1,1)$ | W W / W B | 1 | ✓ |

第二块（和第四块）是 $3$ 白 $1$ 黑，把那个黑格改白即可，返回 `true`。

![示例 2：棋盘格四块全是 2:2](images/bw129_q1_checkerboard.svg)

示例 2 是棋盘格，四个块逐个看都是 $2:2$，全部判死，于是返回 `false`。即使改中间那格 $(1,1)$（它同时属于四个块），每个块也只是从 $2:2$ 变成 $3:1$ 或 $1:3$，仍然不是全同色。

## 4. 算法细节

1. **块数固定为 4**：左上角只有 $(0,0),(0,1),(1,0),(1,1)$ 四种，两层 `for` 循环上限都是 2，不会越界。
2. **只数一种颜色**：$c_B + c_W = 4$，数黑就够了，判据写成 $c_B \ne 2$。
3. **用 `!= 2` 而不是 `>= 3`**：前者一次性覆盖 $4:0$、$3:1$、$1:3$、$0:4$，后者会漏掉全白块。
4. **不需要真的改格子**：判据只依赖计数，不需要修改 `grid`，也就不存在「改回去」的问题。
5. **重叠块独立判定**：4 个块共享格子，但由于目标是「存在一块」，逐个独立判定不会重复计数、也不会互相干扰。
6. **返回值是 `bool`**：C++ 返回 `bool`，Python 返回 `True`/`False`，别写 `0/1` 混过去。
7. **常数复杂度**：$4 \times 4 = 16$ 次字符比较，是标准的签到题量级。

## 5. 正确性证明

**引理 1（单块判据）**：对任意一个 $2 \times 2$ 块，至多改动其中一格的颜色就能使其四格同色，当且仅当块内黑格数 $c \ne 2$。

**证明**：

- 充分性：若 $c = 4$ 或 $c = 0$，四格已经同色，改 0 格即可；若 $c = 3$，块内恰有一个白格，把它改成黑；若 $c = 1$，块内恰有一个黑格，把它改成白。三种情况改动数都不超过 1。
- 必要性：反设 $c = 2$。改动至多一格时，黑格数只能变成 $1$（改黑为白）、$3$（改白为黑）或保持 $2$（不改），永远不可能是 $0$ 或 $4$，即永远无法四格同色。∎

**引理 2（局部即全局）**：存在一种「至多改一格」的方案使矩阵含有一个 $2 \times 2$ 同色块，当且仅当存在某个 $2 \times 2$ 块满足引理 1 的条件。

**证明**：

- 充分性：设块 $Q$ 满足引理 1 的条件，按引理 1 的构造改动 $Q$ 内至多一格，矩阵其余 5 格保持不动，则 $Q$ 四格同色，改动总数不超过 1，方案合法。
- 必要性：设某个合法方案改动格子 $p$ 后使块 $Q$ 四格同色。若 $p \notin Q$，则 $Q$ 在改动前就已经四格同色，$c \in \{0, 4\}$，满足条件；若 $p \in Q$，则改动前 $Q$ 内只有 $p$ 这一格与其余三格颜色不同（否则改一格不可能让四格全部同色），故改动前 $Q$ 内的黑格数为 $1$ 或 $3$，同样满足条件。∎

**定理**：算法返回 `true` 当且仅当可以通过至多一次改色得到同色 $2 \times 2$ 正方形。

**证明**：算法枚举了全部 4 个 $2 \times 2$ 块（$3 \times 3$ 矩阵中 $2 \times 2$ 子块恰好这 4 个），并对每块精确计算黑格数、检查引理 1 的条件，只要有一块满足就返回 `true`。由引理 2，该条件与全局可行性等价，故返回值正确。∎

## 6. 复杂度分析

- **时间**：$O(1)$。固定枚举 4 个块，每块常数次字符比较（共 16 次），与输入规模无关。
- **空间**：$O(1)$。只用了循环变量与一个计数变量，未修改输入矩阵。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool canMakeSquare(vector<vector<char>>& grid) {
        for (int i = 0; i < 2; ++i) {
            for (int j = 0; j < 2; ++j) {
                int cntB = (grid[i][j] == 'B') + (grid[i][j + 1] == 'B')
                         + (grid[i + 1][j] == 'B') + (grid[i + 1][j + 1] == 'B');
                if (cntB != 2) return true;   // 3/4 个同色：改至多一格即可
            }
        }
        return false;
    }
};
```

### Python

```python
class Solution:
    def canMakeSquare(self, grid: list[list[str]]) -> bool:
        for i in range(2):
            for j in range(2):
                cells = [grid[i][j], grid[i][j + 1], grid[i + 1][j], grid[i + 1][j + 1]]
                b = cells.count('B')
                if b == 3 or b == 4 or b == 0 or b == 1:
                    return True
        return False
```

> 💡 两份代码通过官方三个示例（`true` / `false` / `true`）、全黑与全白边界，并与「枚举 10 种改法 + 逐块检查」的暴力实现在 2 万组随机 $3 \times 3$ 矩阵上对拍，`mismatch = 0`。

## 8. 边界情况与易错点

1. **本来就同色**：$c = 4$ 或 $c = 0$ 时必须返回 `true`，不能要求「必须改一格」。判据写成 `cntB >= 3` 就会漏掉全白块。
2. **$2:2$ 是唯一失败形态**：不要把「块内颜色种类数 $\le 1$」之外的条件再加进来，例如「两块同时满足」这种额外要求是错的。
3. **只查左上角一块会漏解**：示例 1 的可行块在 $(0,1)$ 与 $(1,1)$，只查 $(0,0)$ 会误判为 `false`。
4. **字符大小写**：比较的是大写 `'B'` / `'W'`，别写成 `'b'` / `'w'`。
5. **不要真的改矩阵**：若坚持模拟，务必记得改完再改回来，否则第二个分支会看到被污染的矩阵。
6. **固定尺寸不代表可以硬编码**：若把题目推广到 $n \times n$，块数变成 $(n-1)^2$，循环上界要改成 `i + 1 < n`；本题写成 `< 2` 是可以的，但心里要清楚它来自 $3 \times 3$。
7. **返回类型**：LeetCode 的返回类型是 `boolean`（C++ `bool`），return 语句别写成整型常量。
