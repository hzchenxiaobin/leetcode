# LeetCode 找出所有稳定的二进制数组 II 题解

## 1. 题目概述

- **标题 / 题号**：找出所有稳定的二进制数组 II（#3130，hard）
- **链接**：https://leetcode.cn/problems/find-all-possible-stable-binary-arrays-ii/
- **来源**：LeetCode 第 129 场双周赛 Q4
- **难度**：困难
- **标签**：动态规划、前缀和

**题意**：与 I 版完全相同——统计恰好含 `zero` 个 $0$、`one` 个 $1$、且不存在长度大于 `limit` 的同值连续段的二进制数组个数，对 $10^9+7$ 取模。唯一区别是数据范围放大到 $zero, one, limit \le 1000$。

**约束**：

- $1 \le zero, one, limit \le 1000$
- 状态数 $10^6$ 量级，答案必须取模

## 2. 示例

**示例 1**

```text
输入：zero = 1, one = 1, limit = 2
输出：2
解释：[1,0] 与 [0,1]，长度 2 不超过 limit。
```

**示例 2**

```text
输入：zero = 1, one = 2, limit = 1
输出：1
解释：只有 [1,0,1]；[1,1,0]、[0,1,1] 都含长度为 2 的全 1 段。
```

**示例 3**

```text
输入：zero = 3, one = 3, limit = 2
输出：14
解释：C(6,3) = 20 种排列里剔除 6 个含三段同值的排列。
```

**示例 4（边界补充）**

```text
输入：zero = 3, one = 3, limit = 1
输出：2
解释：limit = 1 只允许完全交替，即 010101 与 101010。
```

## 3. 解题思路

### 3.1 暴力思路

I 版的做法是 $dp_0[i][j]$、$dp_1[i][j]$ 两个状态，转移时枚举最后一段的长度 $k = 1 \sim \min(limit, i)$：

$$dp_0[i][j] = \sum_{k=1}^{\min(limit,\,i)} dp_1[i-k][j]$$

复杂度 $O(zero \cdot one \cdot limit)$。在 I 版里这是 $200^3 = 8 \times 10^6$，够用；到了 II 版，$1000^3 = 10^9$，C++ 也会超时，Python 更是没戏。

![同一个 DP，规模一放大就必须换优化方式](images/bw129_q4_scale.svg)

坏在「求和」这一步：它为每个状态都重新扫一遍长度不超过 $limit$ 的窗口，而相邻状态的窗口几乎完全重叠。这类「窗口内元素之和」的重复计算，标准解法就是**前缀和**。

### 3.2 核心观察：沿一个方向做前缀和，枚举立刻变减法

![沿 i 方向的前缀和与长度 limit 的窗口](images/bw129_q4_window_prefix.svg)

固定列 $j$ 看转移：$dp_0[i][j]$ 依赖的是 $dp_1[i-1][j], dp_1[i-2][j], \dots, dp_1[i-limit][j]$，即**同一列**上连续 $limit$ 个值。定义沿 $i$ 方向的前缀和

$$S_1[a][j] = \sum_{t=0}^{a} dp_1[t][j]$$

则窗口和可以写成两项之差：

$$dp_0[i][j] = S_1[i-1][j] - S_1[i-limit-1][j] \qquad (\text{下标为负时取 } 0)$$

同理，沿 $j$ 方向定义 $S_0[i][b] = \sum_{t=0}^{b} dp_0[i][t]$，则

$$dp_1[i][j] = S_0[i][j-1] - S_0[i][j-limit-1]$$

每个状态 $O(1)$，总复杂度降到 $O(zero \cdot one) = 10^6$，比 I 版在最大规模下快三个数量级。

### 3.3 算法流程

![填表顺序：i 从小到大，j 在行内从小到大](images/bw129_q4_scan_order.svg)

关键是要保证「用到的前缀和已经算好」。按 $i$ 递增、行内 $j$ 递增的顺序填表：

1. **$S_1$ 沿 $i$ 累加**：$S_1[i][j] = S_1[i-1][j] + dp_1[i][j]$。填第 $i$ 行时，$S_1[i-1][\cdot]$ 已经是最终值，可以直接取用。
2. **$S_0$ 在行内累加**：算到 $(i,j)$ 时，$S_0[i][0..j-1]$ 已经在本次行内循环里算好，只需一个一维数组。
3. **递推方向**：$dp_0[i][j]$ 只读第 $i-1$ 行及更早的 $S_1$（已知），$dp_1[i][j]$ 只读本行更小的 $j$ 的 $S_0$（已知），因此不存在循环依赖。

```text
1. 初始化 S1[0][j] = 1 (1 ≤ j ≤ min(limit, one))       // dp1[0][j] 的基态
2. for i = 1..zero:
       S0[0] = (i <= limit ? 1 : 0)                    // dp0[i][0] 的基态
       for j = 1..one:
           dp0[j] = S1[i-1][j] - (i-limit-1 >= 0 ? S1[i-limit-1][j] : 0)
           dp1[j] = S0[j-1]   - (j-limit-1 >= 0 ? S0[j-limit-1]   : 0)
           S0[j]  = S0[j-1] + dp0[j]
       for j = 1..one: S1[i][j] = S1[i-1][j] + dp1[j]
3. 返回 dp0[one] + dp1[one]（均为第 zero 行的值）
```

### 3.4 示例演算

以 $zero = 3,\ one = 3,\ limit = 2$ 为例，跑完两张表得到：

| $i \backslash j$ | 0 | 1 | 2 | 3 |
|------------------|---|---|---|---|
| $dp_0$ 行 $i=1$ | 1 | 1 | 1 | 0 |
| $dp_0$ 行 $i=2$ | 1 | 2 | 3 | 2 |
| $dp_0$ 行 $i=3$ | 0 | 2 | 5 | **7** |
| $dp_1$ 行 $i=1$ | 0 | 1 | 2 | 2 |
| $dp_1$ 行 $i=2$ | 0 | 1 | 3 | 5 |
| $dp_1$ 行 $i=3$ | 0 | 0 | 2 | **7** |

其中第 $i$ 行的第 $0$ 列是基态（$1$ 或 $0$），$j \ge 1$ 的格子由前缀和减法得到。答案 $7 + 7 = 14$，与 I 版的 $O(zero \cdot one \cdot limit)$ 实现完全一致。

抽查一格：$dp_0[3][3]$ 应当等于 $dp_1[2][3] + dp_1[1][3] = 5 + 2 = 7$（$limit = 2$，窗口长度 2），与表里一致；用前缀和写就是 $S_1[2][3] - S_1[0][3]$，其中 $S_1[2][3] = dp_1[0][3] + dp_1[1][3] + dp_1[2][3] = 0 + 2 + 5 = 7$，$S_1[0][3] = 0$，差值为 7 ✓。

## 4. 算法细节

1. **窗口长度是 $limit$ 而不是 $limit+1$**：$k$ 从 $1$ 取到 $limit$，对应下标从 $i-1$ 到 $i-limit$，共 $limit$ 项；减去的边界是 $S_1[i-limit-1]$。
2. **越界处理**：$i-limit-1 < 0$ 时该项按 $0$ 处理（前缀数组在负下标上没有定义），代码里用三元表达式挡住。
3. **基态进前缀数组**：$dp_1[0][j]$（$1 \le j \le limit$）必须写进 $S_1[0][j]$，否则「前缀为空、整串是一段 $1$」的方案全部丢失。这是本题最容易漏的一行。
4. **减法取模**：两项都取过模，差值可能为负，需要 `(x - y + MOD) % MOD`。
5. **$S_0$ 只需要一行**：$dp_1[i][j]$ 只依赖本行的 $S_0$，用完即可丢弃；$S_1$ 要么存全表（$1001 \times 1001$ 个 `int`，约 4 MB），要么用长度 $limit+2$ 的滚动窗口（本题没必要，全表更简单）。
6. **加法用 `long long`**：$S_1[i-1][j] + dp_1[i][j] < 2 \times 10^9$，`int` 会溢出，先转 `long long` 再取模。
7. **对称性**：交换 $zero$ 与 $one$ 答案不变，可作快速自检（例如 $(999, 1000)$ 与 $(1000, 999)$）。
8. **与 I 版的关系**：递推式完全一样，只是「枚举求和」换成「前缀和相减」，两版代码可以互相对拍。

## 5. 正确性证明

**引理 1（前缀和恒等式）**：设 $S_1[a][j] = \sum_{t=0}^{a} dp_1[t][j]$，则对 $i \ge 1$，

$$\sum_{k=1}^{\min(limit,\,i)} dp_1[i-k][j] = S_1[i-1][j] - S_1[i-limit-1][j]$$

其中 $S_1[a][j]$ 在 $a < 0$ 时取 $0$。

**证明**：求和项的下标集合为 $\{i - k : 1 \le k \le \min(limit, i)\}$。当 $i \ge limit$ 时它是 $\{i-limit, \dots, i-1\}$，共 $limit$ 个连续下标；当 $i < limit$ 时它是 $\{0, \dots, i-1\}$（因为 $k \le i$ 使下标非负），共 $i$ 个连续下标。两种情况下它都等于区间 $[\max(0, i-limit),\, i-1]$ 上的全部整数下标，而前缀和之差 $S_1[i-1][j] - S_1[i-limit-1][j]$ 恰好是该区间的和（$i < limit$ 时第二项按 $0$ 处理）。∎

**引理 2（填表顺序合法）**：按 $i$ 递增、行内 $j$ 递增的顺序，计算 $dp_0[i][j]$ 与 $dp_1[i][j]$ 所需的量都已知。

**证明**：$dp_0[i][j]$ 用到 $S_1[i-1][j]$ 与 $S_1[i-limit-1][j]$，两者都由行 $< i$ 的数据确定，而 $S_1[i-1][\cdot]$ 在上一轮外层循环末尾已算完；$dp_1[i][j]$ 用到 $S_0[i][j-1]$ 与 $S_0[i][j-limit-1]$，两者都是本行 $j$ 之前的位置，行内循环已按 $j$ 递增算好。故顺序合法。∎

**引理 3（基态正确）**：$dp_0[i][0] = 1$（$1 \le i \le limit$）与 $dp_1[0][j] = 1$（$1 \le j \le limit$），对应「整个数组只有一种值」的唯一方案。

**证明**：$dp_0[i][0]$ 表示用 $i$ 个 $0$、$0$ 个 $1$ 且末位为 $0$ 的稳定数组，只能是 $0^i$，它稳定当且仅当 $i \le limit$，方案唯一；$dp_1[0][j]$ 同理。∎

**定理**：算法输出等于稳定数组总数（模 $10^9+7$）。

**证明**：由引理 1，前缀和版转移与 I 版的枚举式转移逐项相等；由引理 3，基态相同；由引理 2，两版都能按同一顺序算出全部状态。于是对 $i + j$ 归纳可知两版每个状态值相同。I 版已被证明正确（其转移按「末段长度」唯一分解枚举，不重不漏），而末位二分又使 $dp_0[zero][one] + dp_1[zero][one]$ 覆盖全部稳定数组，故结论成立。∎

## 6. 复杂度分析

- **时间**：$O(zero \cdot one)$。状态 $(zero+1)(one+1) \approx 10^6$ 个，每个 $O(1)$ 转移加 $O(1)$ 前缀维护。C++ 数十毫秒，Python 约半秒。
- **空间**：$O(zero \cdot one)$（$S_1$ 全表，约 4 MB）加 $O(one)$ 的三个一维数组；若把 $S_1$ 改成滚动窗口，空间可降到 $O(one \cdot limit)$ 甚至 $O(one)$，本题不需要。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int numberOfStableArrays(int zero, int one, int limit) {
        const int MOD = 1000000007;
        if (zero == 0 || one == 0) return (zero + one <= limit) ? 1 : 0;
        // dp0[i][j] / dp1[i][j]：用 i 个 0、j 个 1，末位是 0 / 1 的方案数
        // S1[i][j] = sum_{a=0..i} dp1[a][j]：沿 i 方向的前缀和
        vector<vector<int>> S1(zero + 1, vector<int>(one + 1, 0));
        for (int j = 1; j <= one && j <= limit; ++j) S1[0][j] = 1;  // dp1[0][j] 的基态
        vector<int> dp0(one + 1, 0), dp1(one + 1, 0), S0(one + 1, 0);
        for (int i = 1; i <= zero; ++i) {
            fill(dp0.begin(), dp0.end(), 0);
            fill(dp1.begin(), dp1.end(), 0);
            S0[0] = (i <= limit) ? 1 : 0;                  // dp0[i][0] 的基态
            for (int j = 1; j <= one; ++j) {
                int hi0 = S1[i - 1][j];
                int lo0 = (i - limit - 1 >= 0) ? S1[i - limit - 1][j] : 0;
                dp0[j] = (hi0 - lo0 + MOD) % MOD;          // 末尾追加 1..limit 个 0
                int hi1 = S0[j - 1];
                int lo1 = (j - limit - 1 >= 0) ? S0[j - limit - 1] : 0;
                dp1[j] = (hi1 - lo1 + MOD) % MOD;          // 末尾追加 1..limit 个 1
                S0[j] = (int)((S0[j - 1] + (long long)dp0[j]) % MOD);
            }
            S1[i][0] = 0;
            for (int j = 1; j <= one; ++j)
                S1[i][j] = (int)((S1[i - 1][j] + (long long)dp1[j]) % MOD);
        }
        return (int)((dp0[one] + (long long)dp1[one]) % MOD);
    }
};
```

### Python

```python
class Solution:
    def numberOfStableArrays(self, zero: int, one: int, limit: int) -> int:
        MOD = 10 ** 9 + 7
        if zero == 0 or one == 0:
            return 1 if zero + one <= limit else 0
        # S1[i][j] = sum_{a=0..i} dp1[a][j]
        S1 = [[0] * (one + 1) for _ in range(zero + 1)]
        for j in range(1, min(one, limit) + 1):
            S1[0][j] = 1                     # dp1[0][j] 的基态
        dp0 = [0] * (one + 1)
        dp1 = [0] * (one + 1)
        for i in range(1, zero + 1):
            S0 = [0] * (one + 1)
            dp0 = [0] * (one + 1)
            dp1 = [0] * (one + 1)
            S0[0] = 1 if i <= limit else 0    # dp0[i][0] 的基态
            for j in range(1, one + 1):
                lo0 = S1[i - limit - 1][j] if i - limit - 1 >= 0 else 0
                dp0[j] = (S1[i - 1][j] - lo0) % MOD
                lo1 = S0[j - limit - 1] if j - limit - 1 >= 0 else 0
                dp1[j] = (S0[j - 1] - lo1) % MOD
                S0[j] = (S0[j - 1] + dp0[j]) % MOD
            S1[i][0] = 0
            for j in range(1, one + 1):
                S1[i][j] = (S1[i - 1][j] + dp1[j]) % MOD
        return (dp0[one] + dp1[one]) % MOD
```

> 💡 两份代码通过官方三个示例（`2` / `1` / `14`），与 I 版 $O(zero \cdot one \cdot limit)$ 实现在 400 组随机参数（$zero, one \le 30$，$limit \le 12$）上对拍，`mismatch = 0`；最大参数 $(1000,1000,1000)$ 输出 `72475738`、$(1000,1000,1)$ 输出 `2`、$(200,200,200)$ 输出 `587893473`，其中最后一项与 I 版完全一致。C++ 最大规模耗时 < 0.1 s，Python 约 0.5 s。

## 8. 边界情况与易错点

1. **$S_1[0][j]$ 的基态**：必须写入 $dp_1[0][j] = 1$（$1 \le j \le limit$），它代表「前缀为空」的合法情况；漏掉会让所有「整串以一段 $1$ 开头」的方案凭空消失，小数据对拍时表现为答案偏小。
2. **窗口边界的 $-1$**：$i - limit - 1$、$j - limit - 1$ 为负时按 $0$ 处理，不能直接取下标（Python 的负下标会**从尾部取值**，是隐蔽的错源，务必显式判断）。
3. **减法取模**：`(hi - lo) % MOD` 在 C++ 里会得到负数，必须 `+ MOD` 再取模；Python 的 `%` 天然返回非负，但两版写法要保持语义一致。
4. **加法溢出**：$S_1[i-1][j] + dp_1[i][j]$ 最大接近 $2 \times 10^9$，用 `int` 相加会溢出，先转 `long long`。
5. **$limit$ 很大时**：$limit \ge \max(zero, one)$ 时行为应与「答案是 $\binom{zero+one}{zero}$」一致；这是最强的正确性自检，例如 $(3,3,5) \to 20$。
6. **$limit = 1$**：所有 $dp$ 值退化为 $0/1$ 交替计数，答案只可能是 $0$、$1$ 或 $2$，可用作快速 sanity check。
7. **$zero$ 或 $one$ 为 $0$（约束外）**：单值数组，答案 $1$ 当且仅当长度 $\le limit$；代码里加了保护分支，避免空转移误返回 $0$。
8. **数组复用**：$dp_0$、$dp_1$、$S_0$ 每行都要清零，绝不能跨行残留——尤其 $dp_0$ 与 $dp_1$ 在循环内重新分配（Python）或 `fill`（C++），漏一行就会串味。
