# LeetCode 删列造序 题解

## 1. 题目概述

- **标题 / 题号**：删列造序（#944，easy）
- **链接**：https://leetcode.cn/problems/delete-columns-to-make-sorted/
- **来源**：LeetCode 第 111 场周赛 Q2
- **难度**：简单
- **标签**：数组、字符串

**题意**：给定 $n$ 个**等长**小写字母字符串，把它们按行排成一个 $n \times m$ 的网格。删除那些**不是按字典序非严格递增**的列，返回需要删除的列数。

即：第 $c$ 列是"好"的 $\iff$ 对所有 $1 \le r < n$ 有 $strs[r-1][c] \le strs[r][c]$。

**约束**：

- $1 \le n \le 100$
- $1 \le strs[i].length \le 1000$（所有串等长）
- 仅小写字母

## 2. 示例

**示例 1**

```text
输入：strs = ["cba","daf","ghi"]
输出：1
解释：网格为  c b a
                d a f
                g h i
     列 0: c<d<g ✓；列 1: b>a ✗；列 2: a<f<i ✓。只需删列 1。
```

**示例 2**

```text
输入：strs = ["a","b"]
输出：0
解释：只有一列 a<b，已非严格递增。
```

**示例 3**

```text
输入：strs = ["zyx","wvu","tsr"]
输出：3
解释：三列分别是 (z,w,t)、(y,v,s)、(x,u,r)，全部严格递减，三列都要删。
```

## 3. 解题思路

### 3.1 暴力思路

最直观的"暴力"是**按列提取字符串再排序对比**：

```text
for c in 0..m-1:
    col = strs[0][c] + strs[1][c] + ... + strs[n-1][c]
    若 sorted(col) != col:  ans++
```

正确，但每列排序是 $O(n \log n)$，总计 $O(mn\log n)$；而且为了比较还得把列拼成字符串，多花 $O(n)$ 空间。

更"暴力"的枚举思路是"枚举要删除的列的子集，检查剩下的列是否全部合法"——$2^m$ 种组合，$m$ 可达 $1000$，完全不可行。

### 3.2 核心观察：列与列互相独立

![按列检查：相邻两行必须非严格递增](images/wc111_q2_columns.svg)

**关键 insight**：删除一列**不会改变其它列的内容与顺序**。列的合法性只取决于该列自身 $n$ 个字符的上下顺序，与其它列无关。

因此问题**完全解耦**成 $m$ 个独立子问题：

$$\text{答案} = \sum_{c=0}^{m-1} \big[\, \exists r:\ strs[r-1][c] > strs[r][c] \,\big].$$

而判定一列是否非严格递增，只需**一次自上而下的相邻比较**，$O(n)$ 就能解决——不必排序。

### 3.3 算法流程

![minDeletionSize 流程：逐列扫一遍](images/wc111_q2_flow.svg)

```text
1. ans = 0
2. for c in 0..m-1:                    // 逐列
3.     for r in 1..n-1:               // 自上而下比较相邻两行
4.         若 strs[r][c] < strs[r-1][c]:
5.             ans += 1
6.             break                  // 该列已判定，跳到下一列
7. return ans
```

`break` 既保证每列只计一次，也提前结束该列扫描。

### 3.4 示例演算

对示例 1 的 `strs = ["cba","daf","ghi"]`：

| 列 | 自上而下 | 相邻比较 | 结论 |
|----|---------|---------|------|
| 0 | c, d, g | c<d ✓, d<g ✓ | 保留 |
| 1 | b, a, f | b>a ✗ | **删除**（`break`） |
| 2 | a, f, i | a<f ✓, f<i ✓ | 保留 |

答案为 1。注意列 1 只需看到第一对 `b > a` 就能判定，无需继续比较 `a < f`——这就是 `break` 的价值。

## 4. 算法细节

1. **列独立**：这是全部优化的基础。删除某列不会让其它列"变好"或"变差"，所以可以各判各的、互不影响。
2. **相邻比较即可**：非严格递增 $\iff$ 所有相邻对非降（传递性），因此 $n-1$ 次比较足够，无需两两比较的 $O(n^2)$。
3. **早停**：一旦发现下降立即 `break`，最坏仍是 $O(n)$，但常数更小。
4. **字符比较**：题目限定小写字母，直接比较 `char` 与字典序一致（ASCII 码递增），不需要 `tolower`。
5. **转置 vs 直接索引**：不必真的构造转置矩阵，用 `strs[r][c]` 直接按列访问即可（字符串在内存中连续，列访问的缓存局部性一般，但 $n,m$ 很小无影响）。
6. **Python 写法**：可用 `zip(*strs)` 得到各列的元组，`any(a > b for a, b in zip(col, col[1:]))` 判定，语义最清晰。
7. **计数而非构造**：题目只要"删除的列数"，不需要真的返回剩余字符串。

## 5. 正确性证明

**引理 1（列的合法性判据）**：第 $c$ 列非严格递增 $\iff$ 对所有 $1\le r<n$ 有 $strs[r-1][c] \le strs[r][c]$。

**证明**："$\Leftarrow$"：由相邻不等式的传递性，任意 $r_1<r_2$ 有 $strs[r_1][c] \le strs[r_2][c]$，即整列非降。"$\Rightarrow$"：非降列自然满足所有相邻对。∎

**引理 2（列独立）**：删除任意若干列不影响任何未被删除列的相对上下顺序与内容。

**证明**：删除操作是"整列移除"，被删除列的字符从每一行中同时消失；剩余列中每个字符所在的**行号**保持不变，因此任一剩余列内部的上下比较关系完全不变。所以一列删与不删，与其他列是否合法无关。∎

**定理**：算法返回的 `ans` 等于必须删除的列数，且该值是最小的。

**证明**：由引理 1，算法第 4 步的判定与"该列非法"等价；`break` 使每列至多计数一次，故 `ans` 恰为**非法列的总数**。又由引理 2，各列合法性互相独立，任何合法方案都必须删除所有非法列、且不需要删除任何合法列（删掉合法列只会让结果变差），故最小删除数正是非法列总数。∎

## 6. 复杂度分析

- **时间**：$O(nm)$。外层 $m$ 列，内层最多 $n-1$ 次比较，每列因 `break` 可能更少。$n,m \le 1000$ 时约 $10^6$ 次字符比较。
- **空间**：$O(1)$（不计输入）。不构造转置矩阵；Python 的 `zip(*strs)` 版本为 $O(nm)$ 的元组开销，若在意空间可改为下标访问。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minDeletionSize(vector<string>& strs) {
        int m = strs.size(), n = strs[0].size(), ans = 0;
        for (int c = 0; c < n; c++) {            // 逐列
            for (int r = 1; r < m; r++) {        // 自上而下相邻比较
                if (strs[r][c] < strs[r - 1][c]) { ans++; break; }
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def minDeletionSize(self, strs: list[str]) -> int:
        ans = 0
        for col in zip(*strs):                  # 逐列（转置后按列迭代）
            for up, down in zip(col, col[1:]):
                if up > down:                   # 出现下降 → 该列必须删除
                    ans += 1
                    break
        return ans
```

## 8. 边界情况与易错点

1. **相等不算下降**：题目要求"非严格递增"，`a <= b` 是合法的；写成严格比较会把含相等字符的列误删。
2. **单行网格**（$n=1$）：没有任何相邻对，任何列都合法，答案 0。
3. **单列网格**（$m=1$）：只需判定该列，答案 0 或 1。
4. **全逆序网格**：如示例 3，所有列都非法，答案等于列数 $m$。
5. **不要真的去"删除"再递归**：删除列不会影响其它列（引理 2），一旦写成"删一列后重新判定"就会退化成搜索。
6. **`break` 缺失**：漏掉 `break` 会把同一列的多个下降对重复计数，答案偏大。
7. **列索引越界**：$m$ 与 $n$ 容易写反；本题行数 $n$、列数 $m$ 与变量命名建议统一（代码里用 `m = strs.size()` 表示行数）。
8. **Python 的 `zip(*strs)`**：当 `strs` 为空列表时会得到空迭代器（题面保证 $n\ge1$）；若允许空输入需特判返回 0。
