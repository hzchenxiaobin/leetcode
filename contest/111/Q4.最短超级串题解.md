# LeetCode 最短超级串 题解

## 1. 题目概述

- **标题 / 题号**：最短超级串（#943，hard）
- **链接**：https://leetcode.cn/problems/find-the-shortest-superstring/
- **来源**：LeetCode 第 111 场周赛 Q4
- **难度**：困难
- **标签**：位运算、数组、字符串、动态规划、位掩码、哈密顿通路

**题意**：给定字符串数组 `words`，找一个**最短**字符串，使 `words` 中**每个**字符串都是它的**子串**。若有多解返回任意一个。

**约束**：

- $1 \le words.length \le 12$
- $1 \le words[i].length \le 20$
- `words[i]` 由小写字母组成且**互不相同**
- 题目**保证**没有任何词是另一个词的子串

## 2. 示例

**示例 1**

```text
输入：words = ["alex","loves","leetcode"]
输出："alexlovesleetcode"
解释：三词互不重叠，"leetcode" 含 "lee"，任何顺序拼接都不产生重叠（长度 5+5+8=18）。
```

**示例 2**

```text
输入：words = ["catg","ctaagt","gcta","ttca","atgcatc"]
输出："gctaagttcatgcatc"
解释：顺序 gcta → ctaagt → ttca → catg → atgcatc，
     重叠分别为 "cta"、"t"、"ca"、"atg"，总长 4+3+3+2+4 = 16。
```

**示例 3（补充，说明答案不唯一）**

```text
输入：words = ["alex","loves","leetcode"]
输出："leetcodelovesalex"
解释：长度同为 18，任何排列都合法，判题按"最短 + 包含全部词"校验。
```

## 3. 解题思路

### 3.1 暴力思路

枚举 `words` 的全部排列，按顺序贪心地用**最大重叠**拼接，取最短者。

排列数 $n!$，$n = 12$ 时 $12! \approx 4.79\times 10^{8}$，每次拼接还要 $O(nL)$，总计 $10^{10}$ 量级——不可行。

**贪心也不行**。一个反例（已用程序穷举验证）：

```text
words = ["baaa","abaa","bbba","aaaa"]
贪心（每次挑重叠最大的下一个词，起点也取最优）："abaaaabbba"，长度 10
最优（bbba → abaa → aaaa → baaa 的排列）：  "bbbabaaaa" ，长度 9
```

贪心在第一步就被"局部重叠最大"吸引了，导致后续无法咬合，最终多出 1 个字符。**这题的全局结构必须靠 DP 才能精确求解**。

### 3.2 核心观察：问题等价于「带权哈密顿路径」

![重叠矩阵 ov(i,j)：i 的后缀配 j 的前缀](images/wc111_q4_overlap.svg)

先定义两词之间的**最长可重叠长度**：

$$ov[i][j] = \max\{\,k : words[i]\text{ 的后 }k\text{ 个字符} = words[j]\text{ 的前 }k\text{ 个字符}\,\},$$

即 $words[i]$ 的**后缀**与 $words[j]$ 的**前缀**匹配的最大长度。把 $words[j]$ 接在 $words[i]$ 后面只需追加 $len_j - ov[i][j]$ 个字符。

**关键定理（本解法的立足点）**：在"没有任何词是另一个词的子串"的前提下，

$$\boxed{\;\min |S| \;=\; \min_{\text{排列 }p}\; \Big( len_{p_1} + \sum_{k=2}^{n}\big(len_{p_k} - ov[p_{k-1}][p_k]\big)\Big)\;}$$

即**任何一个最短超级串，都等于"按某个排列、相邻取最大重叠"依次拼接的结果**（证明见 §5 引理 1~4）。于是

- 把每个词看作一个节点；
- 从 $i$ 走到 $j$ 的边权定义为 $w(i,j) = len_j - ov[i][j]$；
- 答案 = **访问所有节点恰好一次的最短路径长度**，即**哈密顿路径**（不必回到起点）。

$n\le 12$ 正是"状压 DP 解哈密顿路径"的标准规模。

### 3.3 状态压缩 DP

![状压 DP：状态与转移](images/wc111_q4_bitmask_dp.svg)

**状态**：`dp[mask][last]` = 已访问集合为 `mask`、且最后一个词是 `last` 时，拼接出的字符串**最短长度**。

**边界**：`dp[1 << i][i] = len(words[i])`（只含一个词）。

**转移**（从 `last` 走向未访问的 `nxt`）：

$$dp[mask \mid 2^{nxt}][nxt] = \min\Big(dp[mask \mid 2^{nxt}][nxt],\; dp[mask][last] + len_{nxt} - ov[last][nxt]\Big).$$

**答案**：$\min_{last} dp[2^n-1][last]$。

**还原方案**：额外记录 `par[mask][last]`（让该状态取到最小值的前驱），从满集状态沿 `par` 反向走回单点状态，再翻转得到拼接顺序。

```text
1. 预处理 ov[i][j]（i ≠ j）
2. dp[*][*] = INF；dp[1<<i][i] = len(words[i])
3. for mask in 1..2^n-1:
       for last in mask:
           若 dp[mask][last] == INF: continue
           for nxt not in mask:
               val = dp[mask][last] + len[nxt] - ov[last][nxt]
               若 val < dp[mask|1<<nxt][nxt]: 更新 dp 与 par
4. 在 dp[full][*] 中取最小，沿 par 回溯出顺序 order
5. res = words[order[0]]；依次追加 words[order[k]].substr(ov[order[k-1]][order[k]])
```

### 3.4 示例演算

![从满 mask 回溯 par 还原顺序](images/wc111_q4_reconstruct.svg)

示例 2 的重叠矩阵（$i$ 的后缀配 $j$ 的前缀）：

| ov | catg | ctaagt | gcta | ttca | atgcatc |
|----|------|--------|------|------|---------|
| catg | — | 0 | 1 | 0 | **3** |
| ctaagt | 0 | — | 0 | 1 | 0 |
| gcta | 0 | **3** | — | 0 | 1 |
| ttca | 2 | 0 | 0 | — | 1 |
| atgcatc | 1 | 1 | 0 | 0 | — |

最优顺序 `gcta → ctaagt → ttca → catg → atgcatc`，代价

$$4 + (6-3) + (4-1) + (4-2) + (7-3) = 4 + 3 + 3 + 2 + 4 = 16,$$

拼接过程：`gcta` → 追加 `agt` → `gctaagt` → 追加 `tca` → `gctaagttca` → 追加 `tg` → `gctaagttcatg` → 追加 `gcatc` → `gctaagttcatgcatc`，长度 16，与题面一致。

## 4. 算法细节

1. **重叠预处理**：枚举 $k$ 从 $\min(len_i, len_j)$ 递减，第一个匹配即为最长重叠，$O(n^2L^2)$（$12^2\times20^2 = 5.8\times10^4$），无需 KMP。
2. **不预处理也能过**：由于题目保证无包含关系，$ov[i][j]$ 与 $ov[j][i]$ 不会同时达到 $\min(len_i,len_j)$，否则短者被长者包含。
3. **INF 的选取**：用 `1e9`（或 `INT_MAX/2`）避免加法溢出；Python 可直接用 `float('inf')`。
4. **转移顺序**：外层按 `mask` 递增即可——`mask | (1<<nxt) > mask`，天然满足拓扑序，无需按 popcount 分层。
5. **`last` 必须在 `mask` 内**：写成 `for last in 0..n-1` 也可以，只要 `dp[mask][last] == INF` 就跳过。
6. **回溯**：`par[mask][last]` 记录前驱；回溯时先 `mask ^= (1<<last)` 再赋 `last = par[...]`，注意顺序。
7. **拼接**：`res += words[b].substr(ov[a][b])`，直接用 `substr` 追加后缀部分，比逐字符拼接简洁。
8. **多解无影响**：DP 只保证长度最优；`min` 的取法、同长度时的先后都只影响具体答案，判题接受任意最优解。
9. **Python 常数**：$2^{12}\times12\times12 \approx 5.9\times10^5$ 次转移，纯 Python 也在 1 秒内。

## 5. 正确性证明

设 $S$ 是任一包含全部词的字符串，$len_i = \lvert words[i]\rvert$。

**引理 1（起始位置严格递增）**：在 $S$ 中为每个词选一次出现，记第 $i$ 个词的起始位置为 $s_i$、结束位置为 $e_i = s_i + len_i - 1$。由于没有任何词包含另一个词，这些出现可以选得使**所有 $s_i$ 互不相同**，且按 $s$ 排序后 $e$ 也**严格递增**。

**证明**：若两个出现满足 $s_a \le s_b$ 且 $e_a \ge e_b$，则 $words[b]$ 的该次出现完全落在 $words[a]$ 的区间内，即 $words[b]$ 是 $words[a]$ 的子串，与题设矛盾。故按 $s$ 排序后必然 $e$ 也递增；$s$ 相等则两个区间同起点、短者被长者包含，同样矛盾，故 $s$ 互不相同。∎

**引理 2（相邻重叠有上界）**：设按 $s$ 排序后相邻两个出现为 $A = words[p_{k-1}]$、$B = words[p_k]$，则它们的公共部分长度不超过 $ov[p_{k-1}][p_k]$。

**证明**：公共部分是 $A$ 的一个**后缀**，同时是 $B$ 的一个**前缀**（因为 $s_B > s_A$ 且 $e_B > e_A$，交集为 $[s_B, e_A]$，恰为 $A$ 的后缀、$B$ 的前缀）。其长度 $= e_A - s_B + 1$，而由定义 $ov$ 是"$A$ 的后缀 = $B$ 的前缀"的**最长**长度，故不超过 $ov$。∎

**引理 3（下界）**：对任意包含全部词的 $S$，存在一个排列 $p$ 使

$$\lvert S\rvert \;\ge\; len_{p_1} + \sum_{k=2}^{n}\big(len_{p_k} - ov[p_{k-1}][p_k]\big).$$

**证明**：按引理 1 把 $n$ 个出现按起始位置排序为 $p_1,\dots,p_n$，记相邻两次出现的重叠长度

$$\text{overlap}_k = e_{p_{k-1}} - s_{p_k} + 1 \qquad (2 \le k \le n),$$

若 $s_{p_k} > e_{p_{k-1}}$ 则它为负，表示两词之间还有间隙。由 $e_{p_{k-1}} = s_{p_{k-1}} + len_{p_{k-1}} - 1$ 得

$$s_{p_k} - s_{p_{k-1}} = len_{p_{k-1}} - \text{overlap}_k .$$

$S$ 至少要覆盖从 $s_{p_1}$ 到 $e_{p_n}$ 的全部位置，故

$$\lvert S\rvert \ge e_{p_n} - s_{p_1} + 1 = len_{p_n} + \sum_{k=2}^{n}\big(s_{p_k} - s_{p_{k-1}}\big) = \sum_{i=1}^{n} len_{p_i} - \sum_{k=2}^{n}\text{overlap}_k .$$

由引理 2，$\text{overlap}_k \le ov[p_{k-1}][p_k]$（负值时不等式更显然），于是

$$\lvert S\rvert \ge \sum_{i=1}^{n} len_{p_i} - \sum_{k=2}^{n} ov[p_{k-1}][p_k] = len_{p_1} + \sum_{k=2}^{n}\big(len_{p_k} - ov[p_{k-1}][p_k]\big). \qquad\blacksquare$$

**引理 4（上界可达）**：对任意排列 $p$，按下式构造的字符串 $S_p$ 是超级串，且

$$\lvert S_p\rvert = len_{p_1} + \sum_{k=2}^{n}\big(len_{p_k} - ov[p_{k-1}][p_k]\big).$$

**证明**：取 $S_p = words[p_1]$，依次把 $words[p_k]$ 的**后缀**（去掉与当前串末尾重叠的 $ov[p_{k-1}][p_k]$ 个字符）追加到末尾。由 $ov$ 的定义，追加后 $words[p_k]$ 完整出现，且之前追加的词仍然完整出现（追加只在末尾加字符，不改变已有内容）。长度即为上式。∎

**定理**：算法返回的字符串是最短超级串。

**证明**：

1. 由引理 4，对任意排列都能构造出长度等于代价的超级串，故**最优长度 $\le \min_p \text{cost}(p)$**；
2. 由引理 3，任意超级串长度都 $\ge$ 某个排列的代价 $\ge \min_p \text{cost}(p)$，故**最优长度 $\ge \min_p \text{cost}(p)$**；
3. 二者合并得最优长度 $= \min_p \text{cost}(p)$。

而 DP 求的正是"从任意起点出发、恰好访问每个节点一次"的最短路径代价——对每个 `mask`，`dp[mask][last]` 是该访问集合下以 `last` 结尾的**最小代价**（对 $|mask|$ 归纳：单点情形取边界，多点为所有合法前驱取 $\min$，转移完备且不遗漏）。因此 $\min_{last} dp[full][last] = \min_p \text{cost}(p)$。最后沿 `par` 回溯得到的排列，用引理 4 的方式拼接，长度恰为该最小值，故输出是最短超级串。∎

## 6. 复杂度分析

- **时间**：
  - 重叠预处理 $O(n^2 L^2)$，$n\le12, L\le20$；
  - DP 状态 $2^n \cdot n$，每个状态至多 $n$ 次转移，$O(2^n n^2) \approx 5.9\times10^5$；
  - 回溯与拼接 $O(nL)$。总时间为 $O(2^n n^2 + n^2L^2)$。
- **空间**：`dp` 与 `par` 均为 $2^n \times n$，即 $O(2^n n)$；另有 $O(n^2)$ 的重叠矩阵与 $O(nL)$ 的答案串。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    string shortestSuperstring(vector<string>& words) {
        int n = words.size();
        // 1. 预处理重叠长度 ov[i][j]
        vector<vector<int>> ov(n, vector<int>(n, 0));
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                if (i == j) continue;
                int lim = min(words[i].size(), words[j].size());
                for (int k = lim; k > 0; k--) {
                    if (words[i].compare(words[i].size() - k, k, words[j], 0, k) == 0) {
                        ov[i][j] = k;
                        break;
                    }
                }
            }
        }
        // 2. 状压 DP
        const int INF = 1000000000;
        int full = 1 << n;
        vector<vector<int>> dp(full, vector<int>(n, INF));
        vector<vector<int>> par(full, vector<int>(n, -1));
        for (int i = 0; i < n; i++) dp[1 << i][i] = words[i].size();
        for (int mask = 1; mask < full; mask++) {
            for (int last = 0; last < n; last++) {
                if (dp[mask][last] == INF) continue;
                for (int nxt = 0; nxt < n; nxt++) {
                    if (mask >> nxt & 1) continue;
                    int nm = mask | (1 << nxt);
                    int val = dp[mask][last] + (int)words[nxt].size() - ov[last][nxt];
                    if (val < dp[nm][nxt]) {
                        dp[nm][nxt] = val;
                        par[nm][nxt] = last;
                    }
                }
            }
        }
        // 3. 取最优终点并回溯顺序
        int best = INF, last = -1;
        for (int i = 0; i < n; i++) {
            if (dp[full - 1][i] < best) { best = dp[full - 1][i]; last = i; }
        }
        vector<int> order;
        int mask = full - 1;
        while (last != -1) {
            order.push_back(last);
            int p = par[mask][last];
            mask ^= (1 << last);
            last = p;
        }
        reverse(order.begin(), order.end());
        // 4. 按重叠拼接
        string res = words[order[0]];
        for (int i = 1; i < (int)order.size(); i++) {
            int a = order[i - 1], b = order[i];
            res += words[b].substr(ov[a][b]);
        }
        return res;
    }
};
```

### Python

```python
class Solution:
    def shortestSuperstring(self, words: list[str]) -> str:
        n = len(words)
        # 1. 预处理重叠长度：ov[i][j] = i 的后缀与 j 的前缀最长匹配长度
        ov = [[0] * n for _ in range(n)]
        for i in range(n):
            for j in range(n):
                if i == j:
                    continue
                for k in range(min(len(words[i]), len(words[j])), 0, -1):
                    if words[i][-k:] == words[j][:k]:
                        ov[i][j] = k
                        break

        # 2. 状压 DP：dp[mask][last] = 覆盖 mask 且以 last 结尾的最短长度
        INF = float('inf')
        dp = [[INF] * n for _ in range(1 << n)]
        par = [[-1] * n for _ in range(1 << n)]
        for i in range(n):
            dp[1 << i][i] = len(words[i])
        for mask in range(1 << n):
            for last in range(n):
                cur = dp[mask][last]
                if cur == INF:
                    continue
                for nxt in range(n):
                    if mask >> nxt & 1:
                        continue
                    nm = mask | (1 << nxt)
                    val = cur + len(words[nxt]) - ov[last][nxt]
                    if val < dp[nm][nxt]:
                        dp[nm][nxt] = val
                        par[nm][nxt] = last

        # 3. 回溯出拼接顺序
        full = (1 << n) - 1
        last = min(range(n), key=lambda i: dp[full][i])
        order, mask = [], full
        while last != -1:
            order.append(last)
            nxt = par[mask][last]
            mask ^= (1 << last)
            last = nxt
        order.reverse()

        # 4. 按重叠拼接
        res = words[order[0]]
        for a, b in zip(order, order[1:]):
            res += words[b][ov[a][b]:]
        return res
```

## 8. 边界情况与易错点

1. **`n = 1`**：DP 只有单点状态，`full = 1`，直接返回该词本身；不要因 `best` 初值而返回空串。
2. **无重叠**：`ov = 0` 时按长度相加，答案总长 $=\sum len_i$；示例 1 就是这种退化情形。
3. **重叠方向的单向性**：$ov[i][j]$ 与 $ov[j][i]$ 一般不同，DP 转移必须用 `ov[last][nxt]`，方向写反会得到更长的串（仍可能是合法超级串，但不是最短）。
4. **贪心不可用**：§3.1 的反例说明"每步取最大重叠"会陷入局部最优，必须用 DP 遍历全部 $2^n$ 个子集。
5. **`par` 回溯的更新顺序**：先记录 `p = par[mask][last]`，再改 `mask`，最后 `last = p`；顺序错会读到已失效的状态。
6. **`dp[full][*]` 全为 INF**：只可能在 $n=0$ 时发生（题面 $n\ge1$），可加防御。
7. **字符串拼接效率**：C++ 的 `res += words[b].substr(...)` 均摊 $O(L)$；Python 的 `res +=` 在少量拼接（$n\le12$）下无性能问题。
8. **题目保证的"无包含"**：若输入违反该保证（某词是另一词的子串），应先删去被包含的词再求解，否则重叠矩阵会出现 $ov = \min(len_i,len_j)$，DP 仍能跑但答案未必最优。
9. **多解**：判题只校验"长度最短 + 含全部词"，因此 `min` 的并列处理无需与样例一致。
