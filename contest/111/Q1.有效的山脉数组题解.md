# LeetCode 有效的山脉数组 题解

## 1. 题目概述

- **标题 / 题号**：有效的山脉数组（#941，easy）
- **链接**：https://leetcode.cn/problems/valid-mountain-array/
- **来源**：LeetCode 第 111 场周赛 Q1
- **难度**：简单
- **标签**：数组

**题意**：给定整数数组 `arr`，判断它是否为**山脉数组**。山脉数组满足：

1. `arr.length >= 3`；
2. 存在下标 $i$ 满足 $0 < i < n-1$，使得
$$arr[0] < arr[1] < \cdots < arr[i-1] < arr[i] > arr[i+1] > \cdots > arr[n-1].$$

即"**严格上升 → 唯一山顶 → 严格下降**"，山顶不能在两端，相邻元素不能相等。

**约束**：

- $1 \le arr.length \le 10^4$
- $0 \le arr[i] \le 10^4$

## 2. 示例

**示例 1**

```text
输入：arr = [2,1]
输出：false
解释：长度不足 3。
```

**示例 2**

```text
输入：arr = [3,5,5]
输出：false
解释：5 与 5 相等，不是严格上升/下降。
```

**示例 3**

```text
输入：arr = [0,3,2,1]
输出：true
解释：0 < 3 > 2 > 1，山顶在下标 1。
```

**示例 4（补充，只有上升段）**

```text
输入：arr = [0,1,2,3]
输出：false
解释：一直在上升，没有下降段，山顶落在末尾（i = n-1 不合法）。
```

## 3. 解题思路

### 3.1 暴力思路

枚举山顶下标 $i \in (0, n-1)$，对每个 $i$ 分别检查前缀严格递增、后缀严格递减：

```text
for i in 1..n-2:
    若 arr[0..i] 严格递增 且 arr[i..n-1] 严格递减: return true
return false
```

每个 $i$ 的检查是 $O(n)$，总复杂度 $O(n^2)$。$n \le 10^4$ 时约 $10^8$，勉强能过但不优雅；若用前缀布尔数组预处理可降到 $O(n)$，但需要 $O(n)$ 额外空间。

其实**根本不需要枚举山顶**：数组的"第一个下降位置"一旦出现就唯一确定了山顶，直接跑一遍就能确定。

### 3.2 核心观察：丘陵的"轮廓"唯一

![山脉数组：严格上升 → 唯一山顶 → 严格下降](images/wc111_q1_scan.svg)

设数组从左到右的相邻比较序列为 $c_j = [arr[j] < arr[j+1]]$，则山脉数组 $\iff$ 该布尔序列恰好是「若干个 $1$ 后接若干个 $0$」，且**两种都非空**。

于是扫描分两段：

1. **上坡段**：从 $j=0$ 起，只要 $arr[j] < arr[j+1]$ 就右移，停在第一个不满足的位置 $i$——这就是山顶候选；
2. **合法性检查**：$i = 0$ 说明根本没有上坡（例如 `[3,2,1]`）；$i = n-1$ 说明根本没有下坡（例如 `[0,1,2,3]`）。两种都直接 `false`；
3. **下坡段**：从 $i$ 继续右移，只要 $arr[j] > arr[j+1]$ 就前进，最后看是否走到 $n-1$。

任何"平局"（$arr[j] = arr[j+1]$）都会让两段同时停下，于是走不到终点，自然被判为 `false`——严格性检查免费获得。

### 3.3 算法流程

![四类输入对照：什么才算山脉](images/wc111_q1_cases.svg)

```text
1. 若 n < 3：return false
2. i = 0
3. while i+1 < n 且 arr[i] < arr[i+1]:  i++      // 上坡
4. 若 i == 0 或 i == n-1:  return false          // 没上坡 / 没下坡
5. while i+1 < n 且 arr[i] > arr[i+1]:  i++      // 下坡
6. return i == n-1
```

### 3.4 示例演算

以 `arr = [0,3,2,1]` 为例：

| 阶段 | 动作 | i | 说明 |
|------|------|---|------|
| 上坡 | $0 < 3$ | 0 → 1 | 继续 |
| 上坡 | $3 < 2$ 不成立 | 1 | 停在山顶 i=1 |
| 检查 | $i \ne 0$ 且 $i \ne n-1$ | 1 | 通过 |
| 下坡 | $3 > 2$ | 1 → 2 | 继续 |
| 下坡 | $2 > 1$ | 2 → 3 | 继续 |
| 下坡 | $i+1 = n$ 越界停止 | 3 | $i = n-1$ ✓ |

返回 `true`。若输入换成 `[3,5,5]`：上坡停在 $i=1$（$3<5$），下坡第一步 $5 > 5$ 不成立停在 $i=1 \ne n-1 = 2$，返回 `false`。

## 4. 算法细节

1. **先判长度**：$n < 3$ 时不可能同时有上坡与下坡，必须最先短路。
2. **两个端点检查**：`i == 0`（全程下降）与 `i == n-1`（全程上升）都必须否决，这是本题最常见的 WA 点。
3. **严格不等**：上坡用 `<`，下坡用 `>`；写成 `<=` / `>=` 会把 `[3,5,5]` 判成合法。
4. **单循环两段**：第二段从山顶继续右移，不需要两个独立的指针或前缀数组。
5. **收尾判定**：只需 `i == n-1`，不必再检查"下坡段非空"——因为 $i \ne n-1$ 时至少前进了一步，说明存在一次下降。
6. **越界**：循环条件先判 `i + 1 < n`，短路求值保证 `arr[i+1]` 不越界。
7. **Python 写法**：同样的两段 `while`，注意 `elif` 不可写成两个独立 `if`（否则平局会被误判）。

## 5. 正确性证明

**引理 1（上坡段最长性）**：设第一段循环结束时指针为 $i_0$，则 $arr[0..i_0]$ 严格递增，且 $i_0$ 是不满足 $arr[i] < arr[i+1]$ 的最小下标（或 $i_0 = n-1$）。

**证明**：循环每次在 $arr[i] < arr[i+1]$ 时把 $i$ 加一，等价于"依次验证 $arr[0]<arr[1],\ arr[1]<arr[2],\dots$"，遇到第一个不成立即停。故前缀内相邻比较全部成立、且第一个失败位置被精确定位。∎

**引理 2（合法性等价于两点）**：`arr` 是山脉数组 $\iff$ 存在 $i\in(0,n-1)$ 使 $arr[0..i]$ 严格递增、$arr[i..n-1]$ 严格递减。

**证明**：这正是题面定义逐字展开；注意两段在 $i$ 处共享元素且方向相反，不冲突。∎

**引理 3（下沉段判定）**：若 $0 < i_0 < n-1$，则算法从 $i_0$ 出发的第二段循环结束时 $i = n-1$ $\iff$ $arr[i_0..n-1]$ 严格递减。

**证明**：与引理 1 对称：循环逐步验证 $arr[i_0] > arr[i_0+1] > \cdots$，全部通过当且仅当一直前进到 $n-1$。∎

**定理**：算法返回 `true` 当且仅当 `arr` 是山脉数组。

**证明**：

- **必要性**（返回 true ⇒ 是山脉）：返回 true 说明 $n\ge3$、$0<i_0<n-1$（第 4 步未短路）且第二段走到 $n-1$。由引理 1、3，$arr[0..i_0]$ 严格递增、$arr[i_0..n-1]$ 严格递减，取 $i=i_0$ 即满足引理 2 的条件。
- **充分性**（是山脉 ⇒ 返回 true）：若存在合法的 $i^\*$，则 $arr[0..i^\*]$ 严格递增，由引理 1 的最长性有 $i_0 \ge i^\*$；又 $arr[i^\*+1] < arr[i^\*]$（$i^\* < n-1$），故上坡段必停在 $i_0 = i^\*$（不会越过，因为 $arr[i^\*] > arr[i^\*+1]$ 已使比较失败）。于是 $0<i_0<n-1$，再由引理 3，$arr[i_0..n-1]$ 严格递减使第二段走到 $n-1$，算法返回 true。∎

## 6. 复杂度分析

- **时间**：$O(n)$。两个 `while` 的指针只增不减，合计至多前进 $n-1$ 步，每步 $O(1)$。
- **空间**：$O(1)$，只用了两个下标变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool validMountainArray(vector<int>& arr) {
        int n = arr.size();
        if (n < 3) return false;
        int i = 0;
        while (i + 1 < n && arr[i] < arr[i + 1]) i++;   // 上坡
        if (i == 0 || i == n - 1) return false;          // 没有上坡 / 没有下坡
        while (i + 1 < n && arr[i] > arr[i + 1]) i++;   // 下坡
        return i == n - 1;
    }
};
```

### Python

```python
class Solution:
    def validMountainArray(self, arr: list[int]) -> bool:
        n = len(arr)
        if n < 3:
            return False
        i = 0
        while i + 1 < n and arr[i] < arr[i + 1]:   # 上坡
            i += 1
        if i == 0 or i == n - 1:                    # 没有上坡 / 没有下坡
            return False
        while i + 1 < n and arr[i] > arr[i + 1]:   # 下坡
            i += 1
        return i == n - 1
```

## 8. 边界情况与易错点

1. **长度不足 3**：`[2,1]`、`[1]`、`[]` 一律 `false`，先短路。
2. **全程单调**：`[0,1,2,3]`（$i=n-1$）与 `[3,2,1]`（$i=0$）都要否决，这是最高频的漏判。
3. **相邻相等**：`[3,5,5]`、`[0,2,2,1]` 必须 `false`，比较符不能写成 `<=`/`>=`。
4. **山顶位置**：山顶不能在端点，但可以是 $i=1$（如 `[0,1,0]`）或 $i=n-2$（如 `[0,2,1]`），不要额外加限制。
5. **只有一个元素重复出现多次**：`[5,5,5]` 平局，两段都不动，$i=0$ 直接 `false`。
6. **不要用 `arr[i] != arr[i+1]` 代替方向判断**：山顶之后的"再次上升"（峡谷）也是非法的，必须一路下降到底。
7. **Python 的 `while ... and ...` 短路**：条件顺序保证不越界；写成先访问 `arr[i+1]` 会 `IndexError`。
