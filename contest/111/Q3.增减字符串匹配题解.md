# LeetCode 增减字符串匹配 题解

## 1. 题目概述

- **标题 / 题号**：增减字符串匹配（#942，easy）
- **链接**：https://leetcode.cn/problems/di-string-match/
- **来源**：LeetCode 第 111 场周赛 Q3
- **难度**：简单
- **标签**：贪心、数组、双指针、字符串

**题意**：给定长度为 $n$ 的字符串 $s$，只含 `'I'`（increase）与 `'D'`（decrease）。要求构造一个 $0..n$（共 $n+1$ 个数）的**排列** $perm$，使

$$perm[i] < perm[i+1] \iff s[i] = \texttt{'I'},\qquad perm[i] > perm[i+1] \iff s[i] = \texttt{'D'}.$$

返回**任意**一个合法排列。

**约束**：

- $1 \le s.length \le 10^5$
- $s$ 只含 `'I'` 与 `'D'`

## 2. 示例

**示例 1**

```text
输入：s = "IDID"
输出：[0,4,1,3,2]
解释：0<4>1<3>2，与 I,D,I,D 完全对应。
```

**示例 2**

```text
输入：s = "III"
输出：[0,1,2,3]
解释：全递增，直接升序即可。
```

**示例 3**

```text
输入：s = "DDI"
输出：[3,2,0,1]
解释：3>2>0<1，与 D,D,I 对应。
```

## 3. 解题思路

### 3.1 暴力思路

枚举 $0..n$ 的全部 $(n+1)!$ 个排列，逐个校验：$n=9$ 时已是 $3.6\times 10^6$，$n = 10^5$ 时天文数字，**完全不可行**。

带剪枝的回溯（逐位填数、只保留满足方向的候选）单次搜索是 $O(n)$ 甚至更优，但需要回溯框架与"已用数字集合"，实现量大、常数高，且最坏情况仍有分支。比赛里没人会这么写。

### 3.2 核心观察：区间两端取数

![双指针：I 取最小剩余，D 取最大剩余](images/wc111_q3_pointer.svg)

关键观察非常干净：**当前要填的数，只需在"剩余可用数字"的两端取**。

维护剩余数字恰为连续区间 $[lo, hi]$（初始 $[0, n]$）：

- 若 $s[i] = \texttt{'I'}$，就取 **$lo$** 并令 $lo \gets lo+1$；
- 若 $s[i] = \texttt{'D'}$，就取 **$hi$** 并令 $hi \gets hi-1$。

**为什么这样一定对？** 直觉是"**把不确定性留到后面**"：

- 取 $lo$（当前最小值）后，后面任何剩余数都比它大，所以"下一项比它大"这个要求**无论后面怎么填都成立**——把 $perm[i] < perm[i+1]$ 一次性"锁死"为真；
- 同理取 $hi$（当前最大值）后，后面所有剩余数都比它小，$perm[i] > perm[i+1]$ 必然成立。

也就是说，每一步都用"极值"把当前这位的方向要求**做成必然**，并把剩余问题**原样保留**为同构的小区间问题，天然可归纳。填完 $n$ 个字符后 $lo = hi$，把最后一个数补上即可。

### 3.3 算法流程

![示例 "IDID" 的逐步填表](images/wc111_q3_walkthrough.svg)

```text
1. lo = 0, hi = n
2. ans = []
3. for ch in s:
       若 ch == 'I':  ans.push(lo); lo += 1
       否则:          ans.push(hi); hi -= 1
4. ans.push(lo)        // 此时 lo == hi
5. return ans
```

### 3.4 示例演算

对 $s = \texttt{"IDID"}$（$n=4$，剩余区间初始 $[0,4]$）：

| 步骤 | 字符 | 取数 | 更新后区间 |
|------|------|------|-----------|
| 1 | I | 取 lo = 0 | $[1,4]$ |
| 2 | D | 取 hi = 4 | $[1,3]$ |
| 3 | I | 取 lo = 1 | $[2,3]$ |
| 4 | D | 取 hi = 3 | $[2,2]$ |
| 收尾 | — | 补 lo = 2 | 空 |

得 `[0,4,1,3,2]`，与题面示例一致。校验：$0<4>1<3>2$，方向序列正是 `I,D,I,D`。

## 4. 算法细节

1. **区间不变式**：始终保证"剩余未使用的数字集合 = $\{lo, lo+1, \dots, hi\}$"，这是一个连续区间，长度等于"还未填的位数"。归纳法据此推进（见 §5）。
2. **取极值即"锁死方向"**：取 $lo$ 后，后面所有数都 $> lo$；取 $hi$ 后，后面所有数都 $< hi$。这是全解法的核心。
3. **最后一个数无需判断**：循环结束后 $lo = hi$，剩一个数，没有"下一位"需要比较，直接补上。
4. **数组大小**：答案长度固定 $n+1$，可以预分配（C++ `reserve`）避免扩容。
5. **不需要去重或校验**：构造保证是 $0..n$ 的排列（每个数恰好用一次），不必事后检查。
6. **其他合法解**：本题答案不唯一，例如 `"III"` 也可以是 `[0,2,3,1]`？——不行，必须递增，只有升序链；但 `"ID"` 的解有多个（`[0,2,1]`、`[1,2,0]`）。判题采用"任意合法解"校验，无需匹配样例。
7. **Python 写法**：`itertools`/`deque` 都不必要，两个整数变量即可，且天然 $O(1)$ 空间（除输出）。

## 5. 正确性证明

**引理 1（区间不变式）**：在第 $i$ 步开始前（已填 $i$ 位），剩余未使用的数字集合恰为 $[lo, hi]$，且 $hi - lo + 1 = n + 1 - i$。

**证明**：对 $i$ 归纳。$i=0$ 时剩余 $\{0,\dots,n\} = [0,n]$，成立。若第 $i$ 步取 $lo$，则新区间为 $[lo+1, hi]$，长度减一，且剩余集合正是原集合去掉 $lo$；取 $hi$ 同理。∎

**引理 2（方向必然成立）**：在第 $i$ 步（$i < n$）取数后，若 $s[i] = \texttt{'I'}$ 则 $ans[i] < ans[i+1]$ 必成立；若 $s[i]=\texttt{'D'}$ 则 $ans[i] > ans[i+1]$ 必成立。

**证明**：由引理 1，$ans[i+1]$ 将取自填完 $ans[i]$ 后的剩余区间。若 $s[i]=\texttt{'I'}$，$ans[i]=lo$，而剩余区间中每个数都 $\ge lo+1 > lo$，故 $ans[i] < ans[i+1]$。若 $s[i]=\texttt{'D'}$，$ans[i]=hi$，剩余区间中每个数都 $\le hi-1 < hi$，故 $ans[i] > ans[i+1]$。∎

**引理 3（排列性）**：输出的 $n+1$ 个数恰为 $0,1,\dots,n$ 的一次排列。

**证明**：每次取数都从剩余集合中取走一个元素，由引理 1 剩余集合始终是"尚未使用的数"；共取 $n$ 次加收尾 1 次，每个 $0..n$ 中的数恰好被取一次。故输出是排列。∎

**定理**：算法输出满足题目要求的任意合法排列。

**证明**：由引理 3 是合法排列；由引理 2，对每个 $0 \le i < n$，$s[i]$ 指定的方向关系在 $ans[i]$ 与 $ans[i+1]$ 之间必然成立；两个方向互斥且穷尽，故全部 $n$ 个约束都满足。∎

## 6. 复杂度分析

- **时间**：$O(n)$。每个字符一次判断 + 一次数组写入，$n \le 10^5$。
- **空间**：$O(n)$ 存输出数组（若不计输出则为 $O(1)$，只用了 `lo`/`hi` 两个整数）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> diStringMatch(string s) {
        int lo = 0, hi = s.size();
        vector<int> ans;
        ans.reserve(s.size() + 1);
        for (char ch : s) {
            if (ch == 'I') ans.push_back(lo++);   // 取最小值，后面必然更大
            else           ans.push_back(hi--);   // 取最大值，后面必然更小
        }
        ans.push_back(lo);                        // lo == hi，补最后一个
        return ans;
    }
};
```

### Python

```python
class Solution:
    def diStringMatch(self, s: str) -> list[int]:
        lo, hi = 0, len(s)
        ans = []
        for ch in s:
            if ch == 'I':
                ans.append(lo)      # 取当前最小值
                lo += 1
            else:
                ans.append(hi)      # 取当前最大值
                hi -= 1
        ans.append(lo)              # 此时 lo == hi
        return ans
```

## 8. 边界情况与易错点

1. **`'I'` 与 `'D'` 写反**：这是最高频错误。记住口诀"**I 抬小二，D 砍老大**"——`I` 取小的（`lo`），`D` 取大的（`hi`）。
2. **忘记收尾**：循环只处理 $n$ 个字符，最后必须再补一个数，否则长度是 $n$ 而非 $n+1$。
3. **收尾取哪个**：此时 $lo = hi$，取哪个都一样，不要额外判断。
4. **全 `I`**：得 `[0,1,...,n]`；**全 `D`**：得 `[n,n-1,...,0]`；两者都是合法解，可作自测。
5. **单字符**：$s = \texttt{"I"}$ 应返回长度 2 的排列（如 `[0,1]`）；不要特判成空数组。
6. **不要试图匹配样例输出**：答案不唯一，`"IDID"` 的 `[0,2,1,4,3]` 也算对。判题只看方向关系与排列性。
7. **输出规模**：$n=10^5$ 时结果有 $10^5+1$ 个整数，注意 `reserve` 或 Python 的 `append`（均摊 $O(1)$）。
8. **不要用 `sorted` 或搜索**：本题是纯构造题，任何排序/回溯都属于浪费。
