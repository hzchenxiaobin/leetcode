# LeetCode 或值至少为 K 的最短子数组 I 题解

## 1. 题目概述

- **标题 / 题号**：或值至少为 K 的最短子数组 I（#3095，easy）
- **链接**：https://leetcode.cn/problems/shortest-subarray-with-or-at-least-k-i/
- **来源**：LeetCode 第 127 场双周赛 Q1
- **难度**：简单
- **标签**：位运算，数组，滑动窗口

**题意**：给定非负整数数组 `nums` 与整数 $k$。若一个子数组内所有元素按位或（OR）的结果**至少**为 $k$，称它是「特别的」。求最短的**非空特别子数组**长度；不存在则返回 $-1$。

一句话版本：在所有满足 $\text{OR}(nums[l..r]) \ge k$ 的区间里，找长度最小的那个。

**约束**：

- $1 \le nums.length \le 50$
- $0 \le nums[i] \le 50$
- $0 \le k < 64$

> 💡 数据极小（$n \le 50$），本题考的不是优化而是「把暴力写干净」：如何用一次累或把 $O(n^3)$ 压到 $O(n^2)$，以及 $k = 0$ 这类边界。

## 2. 示例

**示例 1**

```text
输入：nums = [1,2,3]，k = 2
输出：1
解释：[3] 的或值为 3 ≥ 2；[2] 的或值 2 ≥ 2，长度同样是 1。
```

**示例 2**

```text
输入：nums = [2,1,8]，k = 10
输出：3
解释：单个元素最大只有 8 < 10；[2,1] 或值为 3；[1,8] 或值为 9；只有 [2,1,8] 的或值 11 ≥ 10。
```

**示例 3（$k = 0$ 的边界）**

```text
输入：nums = [1,2]，k = 0
输出：1
解释：任何非空子数组的或值都 ≥ 0，因此最短长度就是 1。
```

## 3. 解题思路

### 3.1 暴力思路

最直白的写法是三重循环：枚举左右端点 $l \le r$，再套一层循环求区间或，复杂度 $O(n^3)$。$n = 50$ 时约 $1.25 \times 10^5$ 次操作，其实已经能过，但没必要——把「求或」这一步做成**增量**即可降一维。

![固定起点向右延伸，或值单调不减](images/bw127_q1_subarray_scan.svg)

### 3.2 核心观察：或值随窗口变长只增不减

按位或有一个关键性质：**加进更多元素，只会把更多的位置 1**。位集合只会变大，因此或值的数值也只会变大（子集的位模式对应的整数必然不大于超集的位模式）。

于是固定左端点 $i$ 后，随着 $j$ 从 $i$ 向右移动，$\text{OR}(i..j)$ 单调不减。这带来两个直接好处：

1. **增量维护**：`cur |= nums[j]`，不用回头重算；
2. **提前退出**：一旦 `cur >= k`，再往右只会更大、更长，所以第一个命中的 $j$ 就是该起点的最优解，可以立刻 `break`。

### 3.3 算法流程

```text
1. ans = n + 1                      # 用 n+1 表示「无解」
2. for i = 0 .. n-1:
       cur = 0
       for j = i .. n-1:
           cur |= nums[j]           # 增量维护区间或
           if cur >= k:
               ans = min(ans, j - i + 1)
               break                # 或值只增，继续扩展没有意义
3. return ans == n + 1 ? -1 : ans
```

### 3.4 示例演算

![示例 1 逐起点累或的演算表](images/bw127_q1_walkthrough.svg)

以 `nums = [1,2,3]`、$k = 2$ 为例，三行分别是三个起点：

| 起点 $i$ | $j=0$ | $j=1$ | $j=2$ | 该行最短 |
|----------|-------|-------|-------|----------|
| 0 | 1 ✗ | 3 ✓ | — | 2 |
| 1 | — | 2 ✓ | — | 1 |
| 2 | — | — | 3 ✓ | 1 |

取三行最优值的 $\min$，答案 $= 1$。

## 4. 算法细节

1. **答案初值**：用 `n + 1`（任何合法长度都 $\le n$）作为「无解」哨兵，最后统一判断，避免在多处 `ans = -1` 与 `min` 混用出错。
2. **内层 `break` 的正确性**：由 §3.2 的单调性，$j$ 增大只会让 `cur` 不变或变大，因此一旦满足条件，更长的区间一定也满足，且长度更大——不可能更优。
3. **$k = 0$ 的处理**：任何非空子数组的或值都 $\ge 0 = k$，所以外层第一轮、内层第一次就会命中，返回 1。代码不需要特判，但写题解时必须点明，否则容易被「或值为 0 的数组」绕进去。
4. **或值上界**：$nums[i] \le 50 < 64 = 2^6$，所以任意或值都 $< 64$，与 $k < 64$ 的量级一致，`int` 完全够用，无溢出风险。
5. **不要用 `ans = INT_MAX` 再判断**：虽然也对，但结合「长度 $\le n$」，用 `n + 1` 语义更清晰。
6. **能更快的写法**：若 $n$ 很大（本题的加强版 #3097），内层会退化成 $O(n)$ 从而导致 $O(n^2)$ 超时，此时需要 §相关题目 中的「不同或值集合」技巧。本题保留暴力正是为了对照。

## 5. 正确性证明

**引理 1（或值的单调性）**：固定 $i$，对任意 $i \le j_1 \le j_2 \le n-1$，有 $\text{OR}(i..j_1)$ 的二进制位集合 $\subseteq \text{OR}(i..j_2)$ 的位集合，从而 $\text{OR}(i..j_1) \le \text{OR}(i..j_2)$。

**证明**：区间 $[i, j_2]$ 是 $[i, j_1]$ 的超集，按位或是逐位取「是否存在 1」的运算，元素变多只会让更多位从 0 变 1，不会让任何已为 1 的位回到 0。位集合包含关系成立。又因为对两个位模式 $A \subseteq B$，有 $A \;\&\; B = A$，且 $A \le A \mid B = B$（按无符号整数比较），故数值上也有 $\text{OR}(i..j_1) \le \text{OR}(i..j_2)$。∎

**引理 2（每个起点的最优解）**：固定 $i$，设 $j^*$ 是满足 $\text{OR}(i..j^*) \ge k$ 的最小下标，则所有以 $i$ 为左端点且或值 $\ge k$ 的区间中，$[i, j^*]$ 最短；若不存在这样的 $j$，则以 $i$ 为左端点无解。

**证明**：由 $j^*$ 的最小性，$j < j^*$ 时都不满足条件，故可行的右端点集合恰为 $\{j^*, j^*+1, \dots\}$，其中长度 $j - i + 1$ 随 $j$ 递增，最小值在 $j = j^*$ 处取得。∎

**定理**：算法返回 $nums$ 中最短特别非空子数组的长度；若不存在则返回 $-1$。

**证明**：外层循环枚举了全部可能的左端点 $i$。对每个 $i$，内层循环按 $j$ 递增的顺序检查，并由引理 1 在首次命中时终止——由引理 2，此时记录的长度恰是以 $i$ 为左端点的最短可行长度；若内层循环自然结束，则由引理 2 该起点无解。因此 `ans` 在循环结束时等于所有起点最优长度的最小值，即全局最短长度。哨兵 `n + 1` 只有在所有起点都无解时才保持原值，此时返回 $-1$ 正确。∎

## 6. 复杂度分析

- **时间**：$O(n^2)$。外层 $n$ 次，内层最坏 $n$ 次，每次 $O(1)$ 的按位或与比较；有了 `break`，实际常数更小（命中越早越快）。
- **空间**：$O(1)$。只用了 `cur`、`ans` 两个整型变量，未开额外数组。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minimumSubarrayLength(vector<int>& nums, int k) {
        int n = nums.size();
        int ans = n + 1;                       // n+1 表示无解
        for (int i = 0; i < n; ++i) {
            int cur = 0;
            for (int j = i; j < n; ++j) {
                cur |= nums[j];                // 增量维护区间或
                if (cur >= k) {                // 或值只增不减，第一个满足即最短
                    ans = min(ans, j - i + 1);
                    break;
                }
            }
        }
        return ans == n + 1 ? -1 : ans;
    }
};
```

### Python

```python
class Solution:
    def minimumSubarrayLength(self, nums: list[int], k: int) -> int:
        n = len(nums)
        ans = n + 1                            # n+1 表示无解
        for i in range(n):
            cur = 0
            for j in range(i, n):
                cur |= nums[j]                 # 增量维护区间或
                if cur >= k:                   # 或值只增不减，第一个满足即最短
                    ans = min(ans, j - i + 1)
                    break
        return -1 if ans == n + 1 else ans
```

> 💡 两份代码均通过官方三个示例（`1`、`3`、`1`），并与「三重循环重算区间或」的朴素实现对拍了 400 组随机数据（$n \le 50$，$0 \le k < 64$），结果完全一致。

## 8. 边界情况与易错点

1. **$k = 0$**：答案恒为 1（数组非空）。若把判定写成 `cur > k` 就会错。
2. **无解**：例如 `nums = [1,2]`、$k = 4$，所有或值都 $< 4$，必须返回 $-1$；用哨兵 `n + 1` 判断最稳。
3. **$n = 1$**：内层只跑一次，答案是 `nums[0] >= k ? 1 : -1`。
4. **元素为 0**：0 不贡献任何位，窗口里可以有任意多个 0 而不改变或值，不要误以为「0 会拖累或值」。
5. **`break` 之后不要再用该行的 `ans`**：一旦命中就跳出，后续更长的 $j$ 不再考察，这是正确的（引理 1），但若把 `break` 写成 `continue` 就会退化成纯暴力。
6. **或值范围**：$nums[i] \le 50$ 使或值 $< 64$，与 $k < 64$ 同量级；若把题目换成 $nums[i] \le 10^9$（即 #3097），`int` 仍然够用，但内层必须换成集合维护，否则超时。
