# LeetCode 求出所有子序列的能量和 题解

## 1. 题目概述

- **标题 / 题号**：求出所有子序列的能量和（#3098，hard）
- **链接**：https://leetcode.cn/problems/find-the-sum-of-subsequence-powers/
- **来源**：LeetCode 第 127 场双周赛 Q4
- **难度**：困难
- **标签**：数组，动态规划，排序

**题意**：给定长度为 $n$ 的整数数组 `nums` 和正整数 $k$。一个子序列的**能量**定义为子序列中**任意两个元素差值绝对值的最小值**，即

$$E(S) = \min_{x, y \in S,\ x \ne y} |x - y|$$

求所有长度恰为 $k$ 的子序列的能量之和，对 $10^9 + 7$ 取模。

> ⚠️ 注意能量是「最小差值」，不是「最大值减最小值」。示例 1 中 `[1,2,3]` 的能量是 $\min(1,2,1) = 1$，而不是 $3 - 1 = 2$。

**约束**：

- $2 \le n \le 50$
- $-10^8 \le nums[i] \le 10^8$
- $2 \le k \le n$

> 💡 $n \le 50$ 说明多项式做法可行，但 $O(2^n)$ 或 $O(\binom{n}{k})$ 不行：$\binom{50}{25} \approx 1.26 \times 10^{14}$。

## 2. 示例

**示例 1**

```text
输入：nums = [1,2,3,4]，k = 3
输出：4
解释：4 个长度 3 的子序列 [1,2,3]、[1,3,4]、[1,2,4]、[2,3,4] 的能量分别都是 1，合计 4。
```

**示例 2**

```text
输入：nums = [2,2]，k = 2
输出：0
解释：唯一的子序列是 [2,2]，能量 |2 − 2| = 0。
```

**示例 3**

```text
输入：nums = [4,3,-1]，k = 2
输出：10
解释：三个子序列的能量为 |4−3| = 1、|4−(−1)| = 5、|3−(−1)| = 4，合计 10。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有长度为 $k$ 的子序列，对每个子序列求两两差的最小值。子序列个数是 $\binom{n}{k}$，$n = 50$、$k = 25$ 时约 $1.26 \times 10^{14}$，完全不可行。注意到（按值）排序不会改变子序列的能量，所以可以先排序，把「任意两元素差的最小值」化简为「相邻元素差的最小值」。

### 3.2 核心观察：用阈值把「最小值」拆成计数

![阈值分解：能量等于阶梯函数的面积](images/bw127_q4_threshold_identity.svg)

对非负整数 $m$ 有恒等式

$$m = \sum_{d \ge 1} [\,m \ge d\,]$$

把它逐个子序列用上，再交换求和顺序：

$$\sum_{|S| = k} E(S) = \sum_{d \ge 1} \#\{\,|S| = k : E(S) \ge d\,\}$$

这一步把「求最小值的和」变成了「对每个阈值 $d$ 数个数」。而 $E(S) \ge d$ 是一个**纯局部条件**：排序后只要相邻元素差都 $\ge d$ 即可（等价于任意两元素差 $\ge d$）。于是问题化为：对每个 $d$，统计长度 $k$、相邻差均 $\ge d$ 的下标子序列个数。

$d$ 只需取遍所有「真实存在的差值」（最多 $\binom{n}{2} = 1225$ 个），因为 $\#\{E \ge d\}$ 只在差值处跳变。

### 3.3 算法流程：固定 $d$ 的链式 DP

![固定阈值的链式 DP，指针随 i 单调右移](images/bw127_q4_dp_chain.svg)

排序后记数组为 $a_0 \le a_1 \le \dots \le a_{n-1}$。固定阈值 $d$，令 $ways_c[i]$ 表示「长度 $c$、以 $i$ 结尾、且相邻差都 $\ge d$」的链数，则

$$ways_1[i] = 1, \qquad ways_c[i] = \sum_{p < i,\ a_i - a_p \ge d} ways_{c-1}[p]$$

由于 $a$ 已排序，满足 $a_i - a_p \ge d$ 的 $p$ 恰好是一段**前缀** $\{0, 1, \dots, q(i)\}$，且 $q(i)$ 随 $i$ 单调不减。用指针 $p$ 边走边累加前缀和，每层只需 $O(n)$。

$$\#\{E \ge d\} = \sum_{i} ways_k[i]$$

最后按 §3.2 的分解，把区间长度 $d_t - d_{t-1}$ 作为权重累加：

$$\text{answer} = \sum_{t} (d_t - d_{t-1}) \cdot \#\{E \ge d_t\}\pmod{10^9+7}$$

### 3.4 示例演算

![示例 1 的两种视角对账](images/bw127_q4_walkthrough.svg)

以 `nums = [1,2,3,4]`、$k = 3$ 为例，差值集合为 $\{1, 2, 3\}$：

| 阈值 $d$ | $\#\{E \ge d\}$ | 区间宽度 | 贡献 |
|----------|------------------|----------|------|
| 1 | 4（全部 3 元子集） | $1 - 0 = 1$ | 4 |
| 2 | 0（凑不出两两差 $\ge 2$ 的 3 个数） | $2 - 1 = 1$ | 0 |
| 3 | 0 | $3 - 2 = 1$ | 0 |

合计 $4 + 0 + 0 = 4$，与逐个枚举的 $1+1+1+1$ 一致。

## 4. 算法细节

1. **排序的合法性**：子序列是「按下标的子集」，能量只依赖被选元素的**多重集**，与它们的原始顺序无关；排序只是把「任意两元素差的最小值」变成「相邻元素差的最小值」，不改变任何子序列的能量。
2. **只枚举存在的差值**：`d` 取遍所有 $a_j - a_i\ (j > i)$ 去重后的结果。因为 $E(S)$ 只能等于 $0$ 或某个差值，所以 $\#\{E \ge d\}$ 在 $d$ 的两个相邻差值之间是常数。
3. **区间宽度为什么是 $d_t - d_{t-1}$**：整数 $d$ 落在 $(d_{t-1}, d_t]$ 内共有 $d_t - d_{t-1}$ 个取值，且这些 $d$ 上的计数都等于 $\#\{E \ge d_t\}$（$E$ 取不到中间值）。
4. **$d = 0$ 不参与**：差值集合里会出现 $0$（有重复元素时），但 $\sum_{d \ge 1}$ 从 1 开始，代码中要跳过 $d = 0$（也顺便避免了 $d = 0$ 时「$a_i - a_p \ge 0$ 恒成立」导致指针越过 $i$ 的越界问题）。
5. **取模顺序**：$\#\{E \ge d\}$ 可能很大（$\binom{50}{25} \approx 1.26 \times 10^{14}$），必须先取模再乘宽度，否则中间乘积可达 $1.26\times10^{14}\times 2\times10^{8} \approx 2.5\times10^{22}$，远超 64 位整数范围。
6. **指针单调性**：$q(i)$ 随 $i$ 不减，因此每层用一个指针累计即可，不必二分。
7. **状态压缩**：$ways_c$ 只依赖 $ways_{c-1}$，用两个长度 $n$ 的数组滚动，空间 $O(n)$。

## 5. 正确性证明

**引理 1（排序后能量等于最小相邻差）**：设排序后的子序列为 $b_0 \le b_1 \le \dots \le b_{k-1}$，则 $E(S) = \min_{0 \le t < k-1} (b_{t+1} - b_t)$。

**证明**：任意两元素差 $b_j - b_i$（$j > i$）可拆成相邻差之和 $\sum_{t=i}^{j-1}(b_{t+1}-b_t)$，故不小于其中的最小值，即任意两元素差 $\ge$ 最小相邻差；而相邻差本身就是某两元素的差，故最小值恰在相邻对上取到。∎

**引理 2（阈值分解）**：对任意子序列 $S$，$E(S) = \sum_{d \ge 1} [E(S) \ge d]$。

**证明**：$E(S)$ 是非负整数（元素为整数，差值绝对值也是整数），对非负整数 $m$，$\{1, \dots, m\}$ 中恰有 $m$ 个 $d$ 满足 $d \le m$，故右端 $= m = E(S)$。∎

**引理 3（DP 正确性）**：对每个 $c \in [1, k]$，DP 结束后 $ways_c[i]$ 恰等于「以下标 $i$ 结尾、长度 $c$、相邻差均 $\ge d$ 的下标子序列个数」。

**证明**：对 $c$ 归纳。$c = 1$ 时每个位置自成一链，恰 1 个，成立。设对 $c-1$ 成立，则长度 $c$ 且以 $i$ 结尾的链由「去掉 $i$ 后的长度 $c-1$ 链 + $i$」唯一确定，且合法的前驱恰为满足 $a_i - a_p \ge d$ 的 $p$（由于排序，这也保证了与链中更早元素的差都 $\ge d$：链上最大元素是 $a_p$）。故 $ways_c[i] = \sum_{p: a_i - a_p \ge d} ways_{c-1}[p]$，与转移式一致；指针实现遍历的正是这一段前缀，无遗漏无重复。∎

**引理 4（阶梯函数在区间上取常值）**：设所有**正**差值去重升序为 $d_1 < d_2 < \dots < d_m$，并约定 $d_0 = 0$。则对任意 $d \in (d_{t-1}, d_t]$，有 $\#\{E \ge d\} = \#\{E \ge d_t\}$。

**证明**：只需证对每个子序列，$[E \ge d] = [E \ge d_t]$。若 $E \ge d_t$ 则显然 $E \ge d$；反之设 $E \ge d > d_{t-1}$。由引理 1，$E$ 为 $0$ 或某个差值。若 $E = 0 \le d_{t-1} < d$，矛盾；若 $E$ 是差值且 $E < d_t$，则 $E \le d_{t-1}$（$d_{t-1}$ 与 $d_t$ 之间没有其它差值），同样矛盾。故 $E \ge d_t$。∎

**定理**：算法输出的和等于所有长度 $k$ 子序列能量之和对 $10^9+7$ 取模。

**证明**：由引理 1、2，
$$\sum_{|S|=k} E(S) = \sum_{|S|=k} \sum_{d \ge 1} [E(S) \ge d] = \sum_{d \ge 1} \#\{|S| = k : E(S) \ge d\}$$
由引理 4，把右端按区间 $(d_{t-1}, d_t]$ 分组，每组有 $d_t - d_{t-1}$ 个 $d$、计数同为 $\#\{E \ge d_t\}$，故等于 $\sum_t (d_t - d_{t-1}) \cdot \#\{E \ge d_t\}$。而每个 $\#\{E \ge d_t\}$ 由引理 3 的 DP 精确算出（$E \ge d$ 等价于相邻差均 $\ge d$，引理 1）。因此算法求和结果正确；模运算在加法与乘法下保持同余，取模后仍正确。∎

## 6. 复杂度分析

- **时间**：$O(m \cdot n \cdot k)$，其中 $m$ 为不同差值个数，$m \le \binom{n}{2} = 1225$。取 $n = k = 50$ 时约 $1225 \times 2500 \approx 3.1 \times 10^6$ 次加法。排序与去重为 $O(n^2 \log n)$，可忽略。
- **空间**：$O(n)$。DP 只用两个长度 $n$ 的数组滚动；差值表 $O(n^2)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int sumOfPowers(vector<int>& nums, int k) {
        const long long MOD = 1000000007LL;
        sort(nums.begin(), nums.end());
        int n = nums.size();
        vector<long long> diffs;                               // 全部候选阈值
        for (int i = 0; i < n; ++i)
            for (int j = i + 1; j < n; ++j)
                if (nums[j] > nums[i]) diffs.push_back((long long)nums[j] - nums[i]);
        sort(diffs.begin(), diffs.end());
        diffs.erase(unique(diffs.begin(), diffs.end()), diffs.end());
        long long ans = 0, prev = 0;                           // prev = 上一个阈值
        for (long long d : diffs) {
            long long cnt = countAtLeast(nums, k, d);           // 能量 ≥ d 的子序列数
            ans = (ans + ((d - prev) % MOD) * (cnt % MOD)) % MOD;
            prev = d;
        }
        return (int)ans;
    }

private:
    // 已排序数组 a 中，长度恰为 k 且相邻元素差都 ≥ d 的下标子序列个数
    long long countAtLeast(const vector<int>& a, int k, long long d) {
        const long long MOD = 1000000007LL;
        int n = a.size();
        vector<long long> ways(n, 1), nxt(n, 0);  // ways[i]：以 i 结尾的当前长度链数
        for (int c = 2; c <= k; ++c) {
            long long sum = 0;
            int p = 0;
            fill(nxt.begin(), nxt.end(), 0);
            for (int i = 0; i < n; ++i) {
                while (p < i && a[i] - a[p] >= d) {  // 所有能接在 i 前面的起点
                    sum = (sum + ways[p]) % MOD;
                    ++p;
                }
                nxt[i] = sum;
            }
            ways.swap(nxt);
        }
        long long total = 0;
        for (long long w : ways) total = (total + w) % MOD;
        return total;
    }
};
```

### Python

```python
class Solution:
    def sumOfPowers(self, nums: list[int], k: int) -> int:
        MOD = 10**9 + 7
        a = sorted(nums)
        n = len(a)
        diffs = sorted({a[j] - a[i] for i in range(n)
                        for j in range(i + 1, n) if a[j] > a[i]})
        ans = prev = 0
        for d in diffs:
            cnt = self.countAtLeast(a, k, d)          # 能量 ≥ d 的子序列数
            ans = (ans + (d - prev) * cnt) % MOD
            prev = d
        return ans

    def countAtLeast(self, a: list[int], k: int, d: int) -> int:
        MOD = 10**9 + 7
        n = len(a)
        ways = [1] * n                    # 长度 1：每个位置自成一链
        for _ in range(2, k + 1):
            nxt = [0] * n
            total = 0
            p = 0
            for i in range(n):
                while p < i and a[i] - a[p] >= d:
                    total = (total + ways[p]) % MOD
                    p += 1
                nxt[i] = total
            ways = nxt
        return sum(ways) % MOD
```

> 💡 两份代码均通过官方示例（`4`、`0`、`10`），并与「枚举所有 $\binom{n}{k}$ 子序列直接算能量」的暴力对拍了 370 组随机数据（$n \le 16$，含大量重复值、负数、$k = 2$ 与 $k = n$），结果完全一致。

## 8. 边界情况与易错点

1. **$k = 2$**：能量就是两数之差的绝对值，答案等于「所有数对差值之和」，可作为快速自检（示例 3）。
2. **全部元素相同**：所有差值都是 0，能量全为 0，答案 0；此时「正差值集合」为空，主循环一次都不执行，直接返回 0。代码里用 `if (nums[j] > nums[i])` 过滤掉了 0，DP 内层的 `p < i` 又保证了指针不越界，双保险。
3. **$k = n$**：只有一个子序列（全体），答案是全体元素的最小相邻差，DP 退化为一条链。
4. **负数**：排序后差值仍非负，无需特殊处理；但排序前不能想当然地按绝对值处理。
5. **溢出**：$\#\{E \ge d\}$ 最大约 $1.26 \times 10^{14}$，乘以宽度（最大 $2 \times 10^8$）会溢出 64 位，必须先取模再相乘。
6. **`d = 0` 的区间**：$d_0 = 0$ 只作为区间左端点使用，不参与求值；$\sum_{d \ge 1}$ 的第一段是 $(0, d_1]$，宽度为 $d_1$。
7. **答案可能为 0**：不要用 0 当「无解」的哨兵。
8. **排序后下标含义变了**：DP 统计的是排序后数组的下标子序列，与原始下标一一对应（排序是双射），计数不受影响。
