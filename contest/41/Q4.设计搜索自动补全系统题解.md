# LeetCode 设计搜索自动补全系统 题解

## 1. 题目概述

- **标题 / 题号**：设计搜索自动补全系统（#642，hard）
- **链接**：https://leetcode.cn/problems/design-search-autocomplete-system/
- **来源**：LeetCode 第 41 场周赛 Q4
- **难度**：困难
- **标签**：设计、字典树、字符串、数据流、排序、堆（优先队列）、深度优先搜索

**题意**：维护一张「历史句子 → 热度」表，热度是该句子被**完整输入**过的次数。之后用户逐字符输入新句子，每个字符 $c$ 都要即时补全：

- $c$ 为小写字母或空格：返回所有以当前已输入前缀为前缀的历史句子中，热度最高的 **3** 条；热度相同按 ASCII 字典序（小者在前）；不足 3 条就有几条给几条。
- $c$ 为 `#`：本句结束，把它计入历史（热度 +1，首次出现记为 1），返回空列表，并清空输入状态开始下一句。

**约束**：

- 历史句子条数 $N \le 100$，每个句子长度 $L \le 100$（历史句与本次输入的句子都算）
- 输入只含 `'a'`–`'z'`、空格、`#`；句子以字母开头、以 `#` 结尾，单词间恰好一个空格
- 返回条数可以少于 3

> 💡 `AutocompleteSystem` 会被多组测试复用，所有状态都放进成员并在构造函数初始化，别用静态变量。

## 2. 示例

**示例 1（官方示例）**

```text
输入：AutocompleteSystem(["i love you", "island", "iroman", "i love leetcode"], [5, 3, 2, 2])
input('i')  →  ["i love you", "island", "i love leetcode"]
input(' ')  →  ["i love you", "i love leetcode"]
input('a')  →  []
input('#')  →  []

解释：热度为 5、3、2、2。"iroman" 与 "i love leetcode" 并列 2，
      但 ' '(32) < 'r'(114)，所以 "i love leetcode" 排第三，"iroman" 被挤出；
      前缀 "i a" 无命中 → []；输入 '#' 后 "i a" 以热度 1 落库。
```

**示例 2（新句子落库后参与竞争）**

```text
输入：AutocompleteSystem(["ab", "abc"], [2, 1])
input('a')  →  ["ab", "abc"]
input('b')  →  ["ab", "abc"]
input(' ')  →  []
input('c')  →  []
input('#')  →  []                 # "ab c" 以热度 1 落库
input('a')  →  ["ab", "ab c", "abc"]
解释：前缀 "a" 下三条 ab(2)、"ab c"(1)、abc(1)；后者并列 1 且 ' '(32) < 'c'(99)。
```

## 3. 解题思路

### 3.1 暴力思路

每读一个字符就扫全部历史句子做前缀判断，命中后按 $(-\text{热度},\text{句子})$ 排序取前 3：单次 $O(NL + N\log N)$。$N,L \le 100$ 时约 $10^4$ 量级，能过题，但**每次都全表扫描 + 重排序**，历史无上限时直接退化。补全系统真正要的是「按前缀索引 + 增量维护」。

### 3.2 核心观察：前缀就是 Trie 上的一条路径

![Trie 每个节点缓存子树前 3 名](images/wc41_q4_trie_top3.svg)

把历史句子都插进 Trie，句尾标记热度。三条关键事实：

1. **子树 = 前缀集合**：以 $p$ 为前缀的所有句子，恰是 Trie 中 $p$ 对应节点 $u$ 的子树里被标记的句子。前缀判断退化成「顺字符走一步」。
2. **查询只要前 3**：任何一次查询最多返回 3 条，所以每个节点只需缓存自己子树的 **top 3**，长度 $\le 3$，读取 $O(1)$。
3. **插入只碰一条路径**：句子 $s$ 只出现在 $s$ 这条路径各节点的子树里，别的节点子树根本不含 $s$。热度变化时只需刷新路径上的 $O(L)$ 个节点。

排序键固定为 $(-\text{热度},\ \text{句子})$：热度降序、同热度 ASCII 升序。C++ 的 `std::string`、Python 的 `str` 比较本身就是码点序，字符集只含小写字母与空格，不会出现歧义。

### 3.3 算法流程

![input(c) 的两种走向](images/wc41_q4_input_flow.svg)

**构造**：逐句把热度累加进哈希表 `cnt`（同一句子重复给出要相加），再沿路径插入并刷新各节点 top3。

**`input(c)`**：

- `c == '#'`：`cnt[prefix] += 1`，沿 `prefix` 路径刷新 top3（路径不存在就新建）；清空 `prefix`、`cur` 回根；返回 `[]`。
- 否则：`prefix += c`，`cur` 走到子节点（不存在则 `cur = -1`）；返回 `cur` 处缓存列表，`cur = -1` 返回 `[]`。

**刷新节点**（`offer(node, c, s)`）：在长度 $\le 3$ 的列表里按句子删掉旧项，再按 $(-\text{热度},\text{句子})$ 插入 $(c,s)$，超过 3 条就砍掉末尾。列表恒 $\le 3$，故这一步 $O(1)$。

### 3.4 示例演算

![示例逐字符走查](images/wc41_q4_example_walkthrough.svg)

对示例 1 的历史数据 $\{\text{"i love you"}:5,\ \text{"island"}:3,\ \text{"iroman"}:2,\ \text{"i love leetcode"}:2\}$：

| 步 | 输入 | 当前前缀 | 该前缀下的历史句子（热度） | 返回 |
|----|------|----------|------------------------------|------|
| 1 | `'i'` | `"i"` | i love you 5、island 3、i love leetcode 2、iroman 2 | `["i love you","island","i love leetcode"]` |
| 2 | `' '` | `"i "` | i love you 5、i love leetcode 2 | `["i love you","i love leetcode"]` |
| 3 | `'a'` | `"i a"` | 无 | `[]` |
| 4 | `'#'` | — | 落库 `"i a"`，热度 1 | `[]` |

第 1 步是本题唯一的坑：5、3、2 直接排好，剩下两条并列 2 靠 `' ' < 'r'` 决出第 3 名；第 3 步 Trie 上 `'i' → ' ' → 'a'` 走不通，`cur` 变 $-1$，直到 `#` 前都返回空。

## 4. 算法细节

1. **字符映射与节点容量**：只需 27 个槽——`'a'`–`'z'` 映射 $0..25$，空格映射 26；`#` 是终止符，不进入句子文本。最多 $N\cdot L = 10^4$ 个节点，C++ 用定长 `int nxt[27]`（约 $1\text{MB}$）比 `unordered_map` 更快更省。
2. **比较函数**：插入位置按「比 $(c,s)$ 更优」判断，即 `cc > c || (cc == c && ss < s)`；列表 $\le 3$ 项，线性扫描即可。
3. **热度以全局表为准**：刷新传入的必须是 `cnt[s]` 的当前值；历史数据里同一句子可能重复，构造时用 `+=` 累加，不能覆盖。
4. **先删后插**：节点里可能已有同一句子的旧项。不删就会留下两条同句子，截断与输出都会出错。
5. **根节点也刷新**：完整句子的路径包含根，统一处理才能让「每个节点 = 子树 top3」对所有节点成立（查询时前缀非空，根缓存用不上，但代码更干净）。
6. **`cur = -1` 后仍要累积**：前缀走空不代表输入结束，`prefix` 继续拼接，`#` 时用整句落库（可能新建路径），再把 `cur` 复位到根。
7. **`#` 的空前缀保护**：连续 `##` 或首字符即 `#` 时 `prefix` 为空，不能把空串记入历史。

## 5. 正确性证明

**引理 1（子树刻画前缀）**：Trie 建好后，对任意节点 $u$（对应串 $p$），其子树中被标记的句子集合 $S(u)$ 恰为「以 $p$ 为前缀的历史句子」全体。

**证明**：插入句子 $s$ 时逐字符下降，只有 $s$ 的前 $|p|$ 个字符与 $p$ 完全相同时才会经过 $u$，故 $s$ 落在 $u$ 子树 $\iff$ $p$ 是 $s$ 的前缀。∎

**引理 2（`offer` 保持 top3 不变式）**：若节点 $u$ 的列表 $T_u$ 是 $S(u)$ 按 $(-\text{热度},\text{句子})$ 的前 $\min(3,|S(u)|)$ 名，则对 $s\in S(u)$ 以新热度执行 `offer` 后该性质仍成立。

**证明**：`offer` 先删掉 $s$ 的旧项再插入新项并截断到 3。

- 若 $|S(u)| \le 3$：列表原本含全部句子，删后插回便等于全集，截断不触发，成立。
- 若 $|S(u)| > 3$：删插后长度最多 4，设被砍掉的是 $x$。热度只增不减，第 3 名的门槛（第 3 大分值）单调不降；$x$ 被砍时分值已不高于门槛，此后若不因自身被 `offer` 而重新参选则分值不变，仍不高于门槛，因此 $x$ 在任何时刻都不应进入前 3。∎

**引理 3（路径刷新充分）**：句子 $s$ 热度变化时，只有 $s$ 路径上的节点满足 $s\in S(u)$，其余节点 top3 不变。

**证明**：由引理 1，$s\in S(u)$ $\iff$ $u$ 对应的串是 $s$ 的前缀，即 $u$ 在 $s$ 的路径上，故沿路径刷新恰好覆盖全部受影响节点。∎

**定理**：`input(c)` 返回的列表恰为题面要求的结果。

**证明**：普通字符时算法走到前缀 $p$ 的节点 $u$ 并返回 $T_u$。引理 1 给出 $S(u)$ 正是所有以 $p$ 为前缀的历史句子；引理 2、3 保证 $T_u$ 是它们正确的前 3 名；排序键与题意一致（3.2 节：字符串比较即 ASCII 序，字符集只有小写字母与空格）。若 $p$ 不在树中则 $S(u)=\varnothing$，返回空表正确。`#` 时按规则累加并刷新路径，返回空表符合题意。不变量在构造后与每次输入后都成立。∎

## 6. 复杂度分析

- **时间**：构造 $O(NL)$（每句沿路径走 $L$ 步，每步 $O(1)$）。普通字符 $O(1)$：走一步 + 输出至多 3 条；`#` 为 $O(L)$。总 $O\big((N+T)\cdot L\big)$，$T$ 为输入字符总数。
- **空间**：节点数 $O(NL)$，每节点 27 个后继 + 至多 3 条缓存；哈希表 $O(N)$。$N,L\le 100$ 时约 $10^4$ 节点、约 $1\text{MB}$。

## 7. 参考代码

### C++

```cpp
#include <algorithm>
#include <string>
#include <unordered_map>
#include <utility>
#include <vector>
using namespace std;

class AutocompleteSystem {
    struct Node {
        int nxt[27];                                // 'a'-'z' -> 0..25，空格 -> 26
        vector<pair<int, string>> top;              // 热度降序，同热度字典序升序
        Node() { fill(begin(nxt), end(nxt), -1); }
    };
    vector<Node> tr;
    unordered_map<string, int> cnt;                 // 句子 -> 当前热度
    string prefix;
    int cur;                                        // 前缀对应节点，-1 表示不存在
    static int id(char c) { return c == ' ' ? 26 : c - 'a'; }

    void offer(Node& nd, int c, const string& s) {
        for (auto it = nd.top.begin(); it != nd.top.end(); ++it)
            if (it->second == s) { nd.top.erase(it); break; }   // 摘掉旧热度
        auto pos = nd.top.begin();                  // 线性找第一个不比 (c, s) 更优的位置
        while (pos != nd.top.end() && (pos->first > c || (pos->first == c && pos->second < s))) ++pos;
        nd.top.insert(pos, {c, s});
        if (nd.top.size() > 3) nd.top.pop_back();               // 只留前 3
    }
    void insertWord(const string& s, int c) {
        int node = 0;
        offer(tr[node], c, s);
        for (char ch : s) {
            int d = id(ch);
            if (tr[node].nxt[d] == -1) { tr[node].nxt[d] = (int)tr.size(); tr.emplace_back(); }
            node = tr[node].nxt[d];
            offer(tr[node], c, s);
        }
    }

public:
    AutocompleteSystem(vector<string> sentences, vector<int> times) {
        tr.emplace_back();
        cur = 0;
        for (size_t i = 0; i < sentences.size(); ++i) {
            cnt[sentences[i]] += times[i];          // 同一句子出现多次要累加
            insertWord(sentences[i], cnt[sentences[i]]);
        }
    }
    vector<string> input(char c) {
        if (c == '#') {
            if (!prefix.empty()) { int now = ++cnt[prefix]; insertWord(prefix, now); }
            prefix.clear();
            cur = 0;
            return {};
        }
        prefix.push_back(c);
        if (cur != -1) cur = tr[cur].nxt[id(c)];
        vector<string> res;
        if (cur != -1) for (auto& p : tr[cur].top) res.push_back(p.second);
        return res;
    }
};
```

### Python

```python
class AutocompleteSystem:
    def __init__(self, sentences, times):
        self.ch = [dict()]      # ch[node]: 字符 -> 子节点
        self.top = [[]]         # top[node]: [(热度, 句子)]，有序，长度 <= 3
        self.cnt = {}
        self.cur = 0            # 当前前缀节点，-1 表示前缀不存在
        self.prefix = []
        for s, t in zip(sentences, times):
            self.cnt[s] = self.cnt.get(s, 0) + t        # 同一句子累加
            self._insert(s, self.cnt[s])

    def _offer(self, node, c, s):
        lst = self.top[node]
        for i, (_, ss) in enumerate(lst):
            if ss == s:                                 # 先摘掉旧热度
                lst.pop(i)
                break
        pos = len(lst)
        for i, (cc, ss) in enumerate(lst):              # 第一个不比 (c, s) 更优的位置
            if not (cc > c or (cc == c and ss < s)):
                pos = i
                break
        lst.insert(pos, (c, s))
        if len(lst) > 3:
            lst.pop()                                   # 只保留前 3 名

    def _insert(self, s, c):
        self._offer(0, c, s)
        node = 0
        for ch in s:
            if ch not in self.ch[node]:
                self.ch[node][ch] = len(self.ch)
                self.ch.append(dict())
                self.top.append([])
            node = self.ch[node][ch]
            self._offer(node, c, s)

    def input(self, c):
        if c == '#':
            if self.prefix:                             # 空句子不落库
                s = ''.join(self.prefix)
                self.cnt[s] = self.cnt.get(s, 0) + 1
                self._insert(s, self.cnt[s])
            self.prefix, self.cur = [], 0
            return []
        self.prefix.append(c)
        if self.cur != -1:
            self.cur = self.ch[self.cur].get(c, -1)
        if self.cur == -1:
            return []
        return [s for _, s in self.top[self.cur]]
```

## 8. 边界情况与易错点

1. **并列按 ASCII，不按长度也不按插入顺序**：`"i love leetcode"` 与 `"iroman"` 都是 2，前者第三字符是空格 32、后者是 `'r' 114`，前者在前。直接比较字符串即可。
2. **`#` 时前缀为空**：连续 `##` 或首字符即 `#`，不能把空串记入历史，否则会多出一条无意义的热度记录。
3. **历史数据重复**：`sentences` 可能有重复项，热度必须 `+=` 累加；若写成 `cnt[s] = times[i]` 覆盖会丢次数。
4. **`cur = -1` 后仍要累积字符**：前缀走空不代表输入结束，`prefix` 继续拼，`#` 时整句落库（可能新建路径），再把 `cur` 复位到根。
5. **先删旧项再插新项**：不删会留下同一句子的两条记录，截断后可能重复输出，第 3 名的判断也会错。
6. **返回条数可少于 3**：不足时直接返回现有长度，不要补 `""` 或 `None`；C++ 返回空 `vector<string>`。
7. **多测试用例复用**：`cnt`、`tr`、`prefix`、`cur` 全部做成成员并在构造函数初始化，任何 `static` 缓存都会跨用例残留导致 WA。
