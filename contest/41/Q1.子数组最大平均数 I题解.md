# LeetCode 子数组最大平均数 I 题解

## 1. 题目概述

- **标题 / 题号**：子数组最大平均数 I（#643，easy）
- **链接**：https://leetcode.cn/problems/maximum-average-subarray-i/
- **来源**：LeetCode 第 41 场周赛 Q1
- **难度**：简单
- **标签**：数组、滑动窗口

**题意**：给定长度为 $n$ 的整数数组 `nums` 与整数 $k$，在所有**长度恰好为 $k$** 的连续子数组中，找出平均数最大的那一个，返回该最大平均数（浮点数，误差小于 $10^{-5}$ 即判对）。

**约束**：

- $1 \le k \le n \le 10^5$
- $-10^4 \le \textit{nums}[i] \le 10^4$
- 返回值与标准答案误差小于 $10^{-5}$ 视为正确

## 2. 示例

**示例 1**

```text
输入：nums = [1,12,-5,-6,50,3], k = 4
输出：12.75
解释：长度为 4 的窗口共 3 个：
      [1,12,-5,-6]   → 2/4  = 0.5
      [12,-5,-6,50]  → 51/4 = 12.75
      [-5,-6,50,3]   → 42/4 = 10.5
      最大平均数是 12.75。
```

**示例 2**

```text
输入：nums = [5], k = 1
输出：5.00000
解释：n = k = 1，唯一的窗口就是全体元素，平均数即 5。
```

**补充示例（非官方，覆盖全负情形）**

```text
输入：nums = [-3,-1,-2,-5], k = 2
输出：-1.50000
解释：窗口和依次为 -4、-3、-7，最大和 -3，平均数 -3/2 = -1.5；
      注意答案不是 0 —— 最大和的初值不能取 0。
```

## 3. 解题思路

### 3.1 暴力思路

对每个起点 $i \in [0, n-k]$ 逐元素累加 $k$ 项得到窗口和，再除以 $k$ 取最大值：时间 $O(nk)$。当 $k = \Theta(n)$ 时是 $O(n^2) \approx 10^{10}$ 次加法，必然超时。

改用前缀和能把单窗口求和降到 $O(1)$，但需要 $O(n)$ 额外空间，且完全没有利用「相邻窗口高度重合」这一结构。签到题应当一步到位。

### 3.2 核心观察：定长窗口 → 增量滑动

![定长窗口滑动：只换两个端点](images/wc41_q1_sliding_window.svg)

相邻两个窗口的起点只差 1，因此它们**共享 $k-1$ 个元素**，两个窗口的和只相差两个端点：

$$S_{i+1} = \sum_{j=i+1}^{i+k} \textit{nums}[j] = S_i - \textit{nums}[i] + \textit{nums}[i+k]$$

也就是「**左端移出、右端加入**」，中间 $k-1$ 项原地不动，无需重算。由此得到两个关键简化：

- **比较目标可以换成和**：因为 $k > 0$ 固定，$\dfrac{S_i}{k} > \dfrac{S_j}{k} \iff S_i > S_j$。全程整数比较，最后才做一次除法——比「边算平均值边比较」少 $n$ 次浮点除法，也避免舍入误差在比较时翻转结论。
- **空间降到 $O(1)$**：只需维护当前窗口和 $S$ 与历史最大和 `maxSum`，不必存前缀和数组。

> 💡 一句话：**定长窗口是"传送带"而不是"伸缩尺"**——右端进一个、左端出一个，和随之 $O(1)$ 更新，答案在最大的那个 $S$ 上产生。

### 3.3 算法流程

![首窗求和 → 逐格滑动 → 取最大和](images/wc41_q1_algorithm_flow.svg)

```text
输入：nums（长度 n），k
1. S ← nums[0] + nums[1] + ⋯ + nums[k−1]     # 首窗，O(k)
2. maxSum ← S                                 # 初值必须是首窗和
3. 对 i = k, k+1, …, n−1：                     # i 是进入窗口的右端点
   a. S ← S + nums[i] − nums[i−k]              # 进一个、出一个
   b. maxSum ← max(maxSum, S)
4. 返回 maxSum / k                            # 只做一次浮点除法
```

循环共 $n-k$ 轮，每轮 $O(1)$；加上首窗 $O(k)$，总计 $O(n)$，只扫一遍数组。

### 3.4 示例演算

![示例 1 走查：三个窗口的和与平均值](images/wc41_q1_example_walkthrough.svg)

对 `nums = [1,12,-5,-6,50,3]`、$k = 4$：

| 起点 $i$ | 窗口 | 和 $S_i$ | 平均值 | 递推说明 |
|---|---|---|---|---|
| 0 | $[1,12,-5,-6]$ | 2 | 0.5 | 首窗直接累加 |
| 1 | $[12,-5,-6,50]$ | 51 | **12.75** | $S_1 = S_0 - 1 + 50 = 51$ |
| 2 | $[-5,-6,50,3]$ | 42 | 10.5 | $S_2 = S_1 - 12 + 3 = 42$ |

`maxSum` 最终停在 51，返回 $51 / 4 = 12.75$。注意每次滑动只做**一次加法与一次减法**，而不是重新加 4 个数。

## 4. 算法细节

1. **先单独算首窗**：`S = sum(nums[:k])` 一次 $O(k)$ 解决。若把首窗塞进循环、靠 `if i >= k: S -= nums[i-k]` 兜底，代码更绕且容易在 `i < k` 时越界，不如显式两段式。
2. **`maxSum` 初值必须取首窗和**：写成 `0` 在「全为负数」时会错误返回 0（如 `[-3,-1,-2,-5], k=2` 应为 -1.5）；写成 $-\infty$ 虽正确但没有必要，直接 `maxSum = S` 最干净。
3. **比较和、不比较平均数**：$k$ 是正常数，$S \mapsto S/k$ 严格单调递增，两者等价；省掉 $n$ 次除法，也不受浮点舍入影响。
4. **最后只除一次**：返回 `(double)maxSum / k`。C++ 中若写 `maxSum / k`（两侧皆整型）会被截断成整数除法，$51/4$ 变成 $12$。
5. **累加变量用 `long long`**：$n \le 10^5$、$|\textit{nums}[i]| \le 10^4$，窗口和绝对值的上界是 $10^9$，`int`（约 $2.1\times10^9$）勉强够用；但 `long long` 只多一行，可一劳永逸消除溢出顾虑。
6. **窗口右端点从 $k$ 开始**：`i` 表示新进入窗口的元素下标，`i - k` 恰是离开窗口的元素下标；`i < n` 保证 `nums[i]` 与 `nums[i-k]` 同时合法。
7. **无法提前结束**：后面的窗口可能更大，必须看完全部 $n-k+1$ 个窗口，不存在剪枝空间。

## 5. 正确性证明

**引理 1（窗口和递推）**：设 $S_i = \sum_{j=i}^{i+k-1} \textit{nums}[j]$，则对任意 $0 \le i < n-k$ 有
$$S_{i+1} = S_i - \textit{nums}[i] + \textit{nums}[i+k].$$

**证明**：由定义展开
$$S_{i+1} = \sum_{j=i+1}^{i+k} \textit{nums}[j] = \Bigl(\sum_{j=i}^{i+k-1} \textit{nums}[j]\Bigr) - \textit{nums}[i] + \textit{nums}[i+k] = S_i - \textit{nums}[i] + \textit{nums}[i+k].$$
其中第一个等号是窗口平移后下标的重新编号，第二个等号是把多出的右端点补上、把丢掉的左端点减去。∎

**引理 2（循环不变量）**：对 $k \le i \le n-1$，循环变量取 $i$ 时：进入循环体前有 $S = S_{i-k}$ 且 $\textit{maxSum} = \max_{0 \le j \le i-k} S_j$；执行完循环体后有 $S = S_{i-k+1}$ 且 $\textit{maxSum} = \max_{0 \le j \le i-k+1} S_j$。

**证明**：对 $i$ 归纳。$i = k$ 时，由步骤 1、2 的初始化得 $S = S_0 = S_{k-k}$、$\textit{maxSum} = S_0 = \max_{0 \le j \le 0} S_j$，进入条件成立。设 $i$ 时成立，则执行 `S ← S + nums[i] − nums[i−k]` 后由引理 1 得 $S' = S_{i-k} - \textit{nums}[i-k] + \textit{nums}[i] = S_{i-k+1}$；再执行 `maxSum ← max(maxSum, S')` 后
$$\textit{maxSum}' = \max\Bigl(\max_{0 \le j \le i-k} S_j,\ S_{i-k+1}\Bigr) = \max_{0 \le j \le i-k+1} S_j,$$
恰为下一轮 $i+1$ 的进入条件。∎

**引理 3（比较等价）**：对任意两个窗口和 $S_a, S_b$ 与 $k \ge 1$，有 $\dfrac{S_a}{k} \ge \dfrac{S_b}{k} \iff S_a \ge S_b$。

**证明**：两边同乘正常数 $k$，不等号方向不变。∎

**定理**：算法返回 $\max_{0 \le i \le n-k} \dfrac{S_i}{k}$，即所有长度为 $k$ 的连续子数组中的最大平均数。

**证明**：若 $k = n$，循环为空，初始化即得 $\textit{maxSum} = S_0 = \max_{0 \le j \le 0} S_j = \max_{0 \le j \le n-k} S_j$；若 $k < n$，最后一轮取 $i = n-1$，由引理 2 结束时同样有 $\textit{maxSum} = \max_{0 \le j \le n-k} S_j$。两种情形都恰好覆盖全部 $n-k+1$ 个长度为 $k$ 的窗口，不漏不重。由引理 3，最大化 $S_j/k$ 与最大化 $S_j$ 同解，故返回 $\textit{maxSum}/k$ 正是所求最大平均数。∎

## 6. 复杂度分析

- **时间**：$O(n)$。首窗累加 $O(k)$；滑动循环 $n-k$ 轮，每轮一次加法、一次减法、一次比较，均为 $O(1)$；末尾一次除法。合计 $O(k) + O(n-k) = O(n)$，$n = 10^5$ 时约 $2\times10^5$ 次基本运算。
- **空间**：$O(1)$。额外只使用 `S`、`maxSum`、循环下标三个标量，不复制数组、不建前缀和表，也不分配递归栈。

## 7. 参考代码

### C++

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    double findMaxAverage(vector<int>& nums, int k) {
        int n = (int)nums.size();
        long long s = 0;
        for (int i = 0; i < k; i++) s += nums[i];      // 首窗和
        long long best = s;                             // 初值 = 首窗和，不能用 0
        for (int i = k; i < n; i++) {
            s += (long long)nums[i] - nums[i - k];      // 进一个、出一个
            if (s > best) best = s;
        }
        return (double)best / k;                        // 只做一次浮点除法
    }
};
```

### Python

```python
class Solution:
    def findMaxAverage(self, nums: list[int], k: int) -> float:
        s = sum(nums[:k])                 # 首窗和
        best = s                          # 初值必须取首窗和
        for i in range(k, len(nums)):
            s += nums[i] - nums[i - k]    # 加入右端、移出左端
            if s > best:
                best = s
        return best / k                   # Python 3 的 / 是真除法
```

## 8. 边界情况与易错点

1. **`k = n`**：只有一个窗口，`range(k, n)` 为空，直接返回总和 $/n$，无需特判——两段式写法的额外好处。
2. **全为负数**：`[-3,-1,-2,-5], k=2` 应返回 $-1.5$。把 `best` 初始化成 `0`（或写成 `max(0, ...)` 之类"防护"）会返回 $0$，是本题最高频 WA。
3. **整数除法**：C++ 的 `best / k` 在两侧都是整型时截断（$51/4 = 12$），必须 `(double)best / k`；Python 3 的 `/` 自带真除法，`//` 才是截断。
4. **`k = 1`**：滑动退化为"逐元素取最大"，返回 `max(nums)`；代码路径不变，不要额外加分支。
5. **溢出**：窗口和上界 $10^9$，`int` 尚可容纳，但若数据范围再加一档就会溢出，故统一 `long long`（Python 无此问题）。
6. **精度**：不要维护 `double` 类型的"当前窗口平均值"并累积误差，也不要用平均值比较——两窗口仅差 1 时可能判反。只比较整数和，判题容差 $10^{-5}$ 足够。
7. **下标越界**：`nums[i-k]` 要求 $i \ge k$（循环起点），`nums[i]` 要求 $i \le n-1$（循环终点）；写成 `i <= n` 会越界，写成 `i = k-1` 会把首窗重复加减一次。
