# LeetCode 数组的最大因子分数 题解

## 1. 题目概述

- **标题 / 题号**：数组的最大因子分数（#3334，medium）
- **链接**：https://leetcode.cn/problems/find-the-maximum-factor-score-of-array/
- **来源**：LeetCode 第 421 场周赛 Q1
- **难度**：中等
- **标签**：数组、数学、数论、枚举、前缀后缀分解

**题意**：定义数组的**因子分数**为所有元素的 $\gcd$（最大公约数）与 $\mathrm{lcm}$（最小公倍数）的**乘积**。允许**最多移除一个**元素（也可以不移除），返回能得到的最大因子分数。单个数字的 $\gcd$ 和 $\mathrm{lcm}$ 都是它本身，空数组的因子分数为 0。

**约束**：

- $1 \le \text{nums.length} \le 100$
- $1 \le \text{nums[i]} \le 30$

## 2. 示例

**示例 1**

```text
输入：nums = [2,4,8,16]
输出：64
解释：移除 2 后，剩余元素 [4,8,16] 的 GCD 为 4、LCM 为 16，因子分数 = 4 × 16 = 64。
```

**示例 2**

```text
输入：nums = [1,2,3,4,5]
输出：60
解释：不移除任何元素，GCD = 1，LCM = 60，因子分数 = 1 × 60 = 60。
```

**示例 3**

```text
输入：nums = [3]
输出：9
解释：单个数的 GCD 与 LCM 都是其本身，3 × 3 = 9；移除唯一元素得空数组（分数 0）。
```

## 3. 解题思路

### 3.1 暴力思路：枚举全部 n+1 种方案

「**最多移除一个**」意味着可行动作只有 $n+1$ 种：不移除，或移除 $nums[i]$（$i = 0, \dots, n-1$）。对每种方案重新折叠一遍 GCD/LCM，取最大值即可：

```python
def score(a):                      # a 非空
    g = reduce(gcd, a)
    l = 1
    for x in a:
        l = l // gcd(l, x) * x
    return g * l

ans = score(nums)                  # 不移除
for i in range(len(nums)):         # 逐一尝试移除
    ans = max(ans, score(nums[:i] + nums[i+1:]))
```

单次求值 $O(n)$，总计 $O(n^2 \log C)$；$n \le 100$ 时只有约 $10^4$ 次基本运算，赛时两分钟写完直接提交，本题到此已经 AC。

### 3.2 核心观察：GCD 只升不降、LCM 只降不升

![移除一个元素时 GCD 与 LCM 的变化](images/factor_score_tradeoff.svg)

删除元素后（多重集变小）：

- **GCD 只会不变或变大**：$\gcd(S)$ 整除 $S$ 的每个元素，自然也整除子集 $T$ 的每个元素，而 $\gcd(T)$ 是整除 $T$ 中所有元素的最大正整数；
- **LCM 只会不变或变小**：$T$ 的每个元素都被 $\mathrm{lcm}(S)$ 整除，而 $\mathrm{lcm}(T)$ 是被 $T$ 中所有元素整除的最小正整数。

因此**移除是否划算，取决于 GCD 的增益能否覆盖 LCM 的损失**：

- 示例 1 移除 2：GCD 由 $2 \to 4$ 翻倍，LCM 保持 $16$ 不变 → 赚；
- 示例 2：GCD 已是 1（升无可升），移除任何元素只可能丢 LCM → 不移除最优。

> ⚠️ 不能凭直觉「只删最小 / 最大元素」：如 `[4,8,3]` 的最优解是删除**最大**的 3（剩 `[4,8]`，得分 $4 \times 8 = 32$），而删除最小的 4 只得 24。必须逐下标枚举。

### 3.3 优化：前缀 / 后缀分解（「删一个元素」通用模板）

![前缀后缀分解求删除一个元素后的 GCD 与 LCM](images/factor_score_prefix_suffix.svg)

$\gcd$ 与 $\mathrm{lcm}$ 都满足**结合律 + 交换律**，且存在**单位元**：$\gcd(0, x) = x$、$\mathrm{lcm}(1, x) = x$。于是「删掉下标 $i$ 后」的 GCD/LCM 可由两侧预计算结果 $O(1)$ 拼出：

$$\gcd(T_i) = \gcd\big(pg_i,\ sg_{i+1}\big), \qquad \mathrm{lcm}(T_i) = \mathrm{lcm}\big(pl_i,\ sl_{i+1}\big)$$

其中 $pg_i / pl_i$ 是**前缀**折叠值（前 $i$ 个元素，从左往右），$sg_i / sl_i$ 是**后缀**折叠值（从第 $i$ 个到末尾，从右往左）。当 $i = 0$ 或 $i = n-1$ 时一侧为空，靠单位元自动退化，**无需特判**——与 1186「删除一次得到子数组最大和」、509 场 Q2 的前后缀预处理同源，是「至多改动一个位置」类问题的通用套路。

### 3.4 示例演算

![示例 [2,4,8,16] 的五种方案演算表](images/factor_score_walkthrough.svg)

对 `nums = [2,4,8,16]` 枚举全部 5 种方案：

| 方案 | 剩余元素 | GCD | LCM | 得分 |
|------|----------|-----|-----|------|
| 不移除 | [2,4,8,16] | 2 | 16 | 32 |
| 移除 2 | [4,8,16] | **4** | 16 | **64** ✓ |
| 移除 4 | [2,8,16] | 2 | 16 | 32 |
| 移除 8 | [2,4,16] | 2 | 16 | 32 |
| 移除 16 | [2,4,8] | 2 | 8 | 16 |

答案 = 64。移除 16 是反面教材：GCD 不变、LCM 由 16 降到 8 → 得分减半。

## 4. 算法细节

1. **前缀数组**：$pg_0 = 0$、$pl_0 = 1$（单位元），递推 $pg_{i+1} = \gcd(pg_i, nums_i)$，$pl_{i+1} = pl_i / \gcd(pl_i, nums_i) \cdot nums_i$。
2. **后缀数组**：$sg_n = 0$、$sl_n = 1$，递推 $sg_i = \gcd(sg_{i+1}, nums_i)$，$sl_i = sl_{i+1} / \gcd(sl_{i+1}, nums_i) \cdot nums_i$。
3. **初始答案**：不移除的方案即 $pg_n \times pl_n$。$n = 1$ 时它就是 $nums_0^2$，移除唯一元素得空数组（0 分），自动被 max 淘汰。
4. **枚举合并**：对每个 $i$，候选得分 $= \gcd(pg_i,\ sg_{i+1}) \times \mathrm{lcm}(pl_i,\ sl_{i+1})$，取最大。
5. **值域分析**：$nums_i \le 30$，任何子集的 LCM 都整除 $\mathrm{lcm}(1..30) = 2\,329\,089\,562\,800 \approx 2.33 \times 10^{12}$，GCD $\le 30$，故得分 $\le 7 \times 10^{13}$——**超出 int32**（$\approx 2.1 \times 10^9$），C++ 必须用 `long long`；Python 天然大数无碍。
6. **防中间溢出**：lcm 合并写成 `a / gcd(a, b) * b` 而非 `a * b / gcd(a, b)`。前缀与后缀的 LCM 都可大到 $2.33 \times 10^{12}$，先乘后除的中间值会爆 `long long`；先除后乘的中间值恰好等于结果本身，安全。

## 5. 正确性证明

**引理 1（单调性）**：设非空多重集 $T$ 是 $S$ 删去若干元素后的子集，则 $\gcd(T) \ge \gcd(S)$ 且 $\mathrm{lcm}(T) \le \mathrm{lcm}(S)$。

**证明**：记 $g = \gcd(S)$。$g$ 整除 $S$ 中每个元素，故也整除 $T$ 中每个元素；而 $\gcd(T)$ 是整除 $T$ 中所有元素的**最大**正整数，于是 $g \mid \gcd(T)$，正整数下即 $g \le \gcd(T)$。记 $L = \mathrm{lcm}(S)$，$T$ 中每个元素都被 $L$ 整除；而 $\mathrm{lcm}(T)$ 是被 $T$ 中所有元素整除的**最小**正整数，于是 $\mathrm{lcm}(T) \mid L$，即 $\mathrm{lcm}(T) \le L$。∎

**引理 2（前缀后缀拼接）**：$\gcd$ 与 $\mathrm{lcm}$ 满足结合律与交换律，且 $\gcd(0, x) = x$、$\mathrm{lcm}(1, x) = x$。因此对多重集的不相交并 $A \uplus B$，有 $\gcd(A \uplus B) = \gcd(\mathrm{fold}(A), \mathrm{fold}(B))$，$\mathrm{lcm}$ 同理；$A$ 为空时由单位元退化成立。

**证明**：结合律 + 交换律说明任意二元折叠顺序结果一致，故整集折叠可拆为「先折叠 $A$、再折叠 $B$、最后合并两结果」；合并时单位元保证空集一侧不改变另一侧的折叠值。∎

**定理**：算法返回「至多移除一个元素」能得到的最大因子分数。

**证明**：可行方案集合 $= \{\text{不移除}\} \cup \{\text{移除 } nums_i : 0 \le i < n\}$，共 $n + 1$ 个。不移除的得分为 $pg_n \times pl_n$。移除 $nums_i$ 后剩余多重集为 $\{nums_0, \dots, nums_{i-1}\} \uplus \{nums_{i+1}, \dots, nums_{n-1}\}$，由引理 2，其 GCD/LCM 分别等于 $\gcd(pg_i, sg_{i+1})$、$\mathrm{lcm}(pl_i, sl_{i+1})$（$i = 0$ 或 $i = n-1$ 时一侧为空，由单位元退化成立）。算法对全部 $n + 1$ 个方案求值取 max，每个方案的值均计算正确，故最大值正确。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \log C)$，其中 $C = 30$ 为值域上界。两次线性递推 + 一次枚举合并，每次 gcd/lcm 为 $O(\log C)$。暴力版 $O(n^2 \log C)$ 在 $n \le 100$ 下同样通过。
- **空间复杂度**：$O(n)$，四个前缀/后缀数组。可以滚动压缩到 $O(1)$，但 $O(n)$ 写法更清晰、更不易出错。

## 7. 参考代码

### C++（前缀 / 后缀分解，O(n)）

```cpp
class Solution {
  public:
    long long maxFactorScore(vector<int>& nums) {
        int n = nums.size();
        // 前缀：pg[i]/pl[i] = nums[0..i-1] 的 GCD/LCM，单位元 0/1
        vector<long long> pg(n + 1, 0), pl(n + 1, 1);
        for (int i = 0; i < n; i++) {
            pg[i + 1] = gcd(pg[i], (long long)nums[i]);
            pl[i + 1] = pl[i] / gcd(pl[i], (long long)nums[i]) * nums[i];
        }
        // 后缀：sg[i]/sl[i] = nums[i..n-1] 的 GCD/LCM
        vector<long long> sg(n + 1, 0), sl(n + 1, 1);
        for (int i = n - 1; i >= 0; i--) {
            sg[i] = gcd(sg[i + 1], (long long)nums[i]);
            sl[i] = sl[i + 1] / gcd(sl[i + 1], (long long)nums[i]) * nums[i];
        }
        long long ans = pg[n] * pl[n]; // 不移除
        for (int i = 0; i < n; i++) {  // 移除 nums[i]
            long long g = gcd(pg[i], sg[i + 1]);
            long long l = pl[i] / gcd(pl[i], sl[i + 1]) * sl[i + 1];
            ans = max(ans, g * l);
        }
        return ans;
    }
};
```

### Python（同思路）

```python
from math import gcd

class Solution:
    def maxFactorScore(self, nums: List[int]) -> int:
        n = len(nums)

        pg, pl = [0] * (n + 1), [1] * (n + 1)
        for i, x in enumerate(nums):
            pg[i + 1] = gcd(pg[i], x)
            pl[i + 1] = pl[i] // gcd(pl[i], x) * x

        sg, sl = [0] * (n + 1), [1] * (n + 1)
        for i in range(n - 1, -1, -1):
            sg[i] = gcd(sg[i + 1], nums[i])
            sl[i] = sl[i + 1] // gcd(sl[i + 1], nums[i]) * nums[i]

        ans = pg[n] * pl[n]
        for i in range(n):
            g = gcd(pg[i], sg[i + 1])
            l = pl[i] // gcd(pl[i], sl[i + 1]) * sl[i + 1]
            ans = max(ans, g * l)
        return ans
```

## 8. 边界情况与易错点

1. **n = 1**：不移除得 $nums_0^2$；移除唯一元素得空数组（0 分）。以不移除作为初始答案即可，`[3]` → 9，无需特判。
2. **C++ 溢出**：最大得分约 $7 \times 10^{13} > 2^{31} - 1$，返回值与所有中间量都用 `long long`。
3. **lcm 先除后乘**：写成 `a / gcd(a, b) * b`，不要 `a * b / gcd(a, b)`——前缀、后缀 LCM 直接相乘可达 $10^{24}$ 量级，会爆 `long long`。
4. **单位元方向别写反**：GCD 的空集单位元是 **0**，LCM 的是 **1**。写反后（如 GCD 用 1）删首/删尾一侧的合并结果会整体错误，示例 1 就无法得到 64。
5. **别只删最小值**：`[4,8,3]` 的最优解是删除最大的 3。必须逐下标枚举全部 $n + 1$ 种方案。
6. **重复元素删除是无效操作**：某值出现 ≥ 2 次时删掉一个，剩余多重集不变、分数不变。可据此剪枝（只试删出现次数为 1 的值），本题 $n \le 100$ 无此必要。
7. **Python 版本**：`math.lcm` 需 Python 3.9+；低版本环境手写 `a // gcd(a, b) * b`。
