# LeetCode 网络信号最好的坐标 题解

## 1. 题目概述

- **标题 / 题号**：网络信号最好的坐标（#1620，medium）
- **链接**：https://leetcode.cn/problems/coordinate-with-maximum-network-quality/
- **来源**：LeetCode 第 37 场双周赛 Q2
- **难度**：中等
- **标签**：数组、枚举、数学

**题意**：信号塔数组 `towers`，`towers[i] = [x_i, y_i, q_i]` 表示塔的位置与信号强度参数；整数 `radius` 为塔的**到达半径**。对整数坐标 $(x,y)$，若第 $i$ 座塔到该点的欧几里得距离 $d \le radius$，则该塔在此处的信号为 $\left\lfloor \dfrac{q_i}{1+d} \right\rfloor$；坐标处的**信号强度**为所有可达塔的信号之和。求信号强度最大的**整数**坐标 $(c_x, c_y)$；若有并列，返回**字典序最小的非负坐标**。

**约束**：

- $1 \le towers.length \le 50$，$towers[i].length = 3$
- $0 \le x_i, y_i, q_i \le 50$
- $1 \le radius \le 50$

> ⚠️ 两个题意细节决定对错：一是**并列取字典序最小**（$x$ 优先，其次 $y$），且限定**非负**坐标；二是除法是**对实数 $\frac{q}{1+d}$ 向下取整**，不是整数除法。

## 2. 示例

**示例 1**

```text
输入：towers = [[1,2,5],[2,1,7],[3,1,9]], radius = 2
输出：[2,1]
解释：坐标 (2,1)：
  塔 (2,1,q=7)：d=0，⌊7/1⌋ = 7
  塔 (1,2,q=5)：d=√2，⌊5/(1+√2)⌋ = ⌊2.07⌋ = 2
  塔 (3,1,q=9)：d=1，⌊9/2⌋ = 4
  强度合计 7+2+4 = 13，为最大。
```

**示例 2**

```text
输入：towers = [[23,11,21]], radius = 9
输出：[23,11]
解释：只有一座塔，塔所在位置信号最强。
```

**示例 3**

```text
输入：towers = [[1,2,13],[2,1,7],[0,1,9]], radius = 2
输出：[1,2]
解释：坐标 (1,2) 的信号强度最大（13 + 3 + 2 = 18）。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的做法：既然要找「信号最强的整数坐标」，就把候选坐标**全部枚举**一遍。塔坐标都在 $[0,50]^2$ 内、$radius \le 50$，直觉上最优点一定在塔群附近，扫描 $[0,50]^2$ 的全部 $51 \times 51$ 个点、每个点对 $T \le 50$ 座塔累加信号，共 $51^2 \times 50 \approx 1.3 \times 10^5$ 次运算，完全可行。剩下的疑虑只有一个：**凭什么最优点（以及字典序最小的最优解）一定落在 $[0,50]^2$ 内？** 这一步必须给出证明（§5），否则扫描范围就是拍脑袋。

另一个方向的「暴力」是贡献法：对每座塔，把它的信号加到半径内所有整点上（哈希表累加），最后取最大值。复杂度 $O(T \cdot (2 \cdot radius + 1)^2)$，$radius = 50$ 时约 $5 \times 10^5$，同样可行，但代码略长且还要单独处理并列与字典序，不如直接扫格点干净。

### 3.2 核心观察：信号随距离单调不增 → 最优解在塔的包围盒内

![核心观察：信号随距离衰减与包围盒收缩](images/bw37_q2_signal_model.svg)

单座塔在点 $P$ 处的贡献 $\lfloor q/(1+d) \rfloor$ 是距离 $d$ 的**不增函数**：$d$ 变小，分母变小，值不减（向下取整保序）。把任意点 $P$ 「收缩」到所有塔的包围盒 $[0,50]^2$ 内（每个坐标分量独立地夹到 $[0,50]$），每座塔到该点的距离都**不会变大**——因为塔的每个坐标分量都在 $[0,50]$ 内，把 $P$ 的分量朝 $[0,50]$ 夹近只会减小（或不变）该分量上的差。于是收缩后的点强度**不小于**原点，最优值必然能在盒内取到；再结合题目「非负坐标」的限制，字典序最小的最优解也在盒内（§5 引理 2）。扫描 $[0,50]^2$ 就足够。

### 3.3 算法流程：按字典序扫描 + 严格大于更新

![算法流程：字典序扫描与严格大于更新](images/bw37_q2_scan_order.svg)

```text
1. best = -1, ans = (0,0)
2. for x = 0 .. 50:                 # x 升序
3.   for y = 0 .. 50:               # y 升序 → 扫描顺序即字典序
4.     q = 0
5.     for (tx, ty, tq) in towers:
6.       d2 = (tx-x)² + (ty-y)²
7.       if d2 <= radius²:           # 可达（用平方比较，避免开方误差）
8.         q += floor(tq / (1 + sqrt(d2)))
9.     if q > best:                  # 严格大于才更新 → 并列保留先扫到者 = 字典序小者
10.      best = q; ans = (x, y)
11. 返回 ans
```

关键在于第 9 行用**严格大于**：扫描顺序 $(0,0), (0,1), \dots, (0,50), (1,0), \dots$ 本身就是字典序，遇到并列（$q = best$）不更新，天然保留字典序最小的坐标，无需任何额外的 tie-break 代码。

## 4. 算法细节

1. **可达判定用平方**：$d \le radius$ 等价于 $d^2 \le radius^2$，两端都是整数，比较精确无浮点误差。$d^2 \le 5000$、$radius^2 \le 2500$，`int` 完全够用。
2. **取整的精度安全性**：$\lfloor q/(1+d) \rfloor$ 中 $d = \sqrt{d^2}$。若 $d^2$ 是完全平方数，`sqrt` 结果精确；否则 $q/(1+d)$ 是无理数，与整数的距离不会太近——由 $N(1+\sqrt{d^2}) = q$ 无整数解可推出 $|q/(1+d) - N| \ge \frac{1}{2N \cdot (q-N) + \cdots}$ 量级的下界（约 $10^{-4}$ 以上），而 `double` 的相对误差仅 $10^{-16}$，向下取整不会翻转。实测对拍中从未出现偏差（§7 验证说明）。
3. **严格大于更新**：并列时保留先扫描到的（字典序小）坐标。若写成 `>=`，会保留字典序**最大**的并列点，示例 3 这类多峰数据就会答错。
4. **负贡献不存在**：$q_i \ge 0$，信号全部非负，无需剪枝。$q_i = 0$ 的塔贡献恒为 0，但仍占据「可达」判定——对结果无影响。
5. **塔可以重叠**：多座塔在同一坐标是合法输入，累加即可，无需去重。
6. **扫描范围固定 $[0,50]^2$**：直接用约束中的坐标上界，不必计算实际包围盒（计算包围盒 $[\min x, \max x] \times [\min y, \max y]$ 也能过，但注意若所有塔挤在角落，仍需保证扫描含 $(0,0)$ 一带的并列候选——固定 $[0,50]^2$ 最省心，复杂度也不变）。

## 5. 正确性证明

**引理 1（单调性）**：固定塔 $(t_x, t_y, q)$，其贡献 $c(P) = \lfloor q/(1+d(P)) \rfloor$（不可达时为 0）关于点 $P$ 到塔的距离 $d(P)$ 不增。

**证明**：$d$ 减小时 $1+d$ 减小、$\frac{q}{1+d}$ 不减（$q \ge 0$）；向下取整保持序：$a \le b \Rightarrow \lfloor a \rfloor \le \lfloor b \rfloor$。不可达（$d > radius$）时贡献为 $0 \le$ 任何可达贡献，同样不增。∎

**引理 2（收缩不减）**：设 $B = [0,50]^2$ 为塔的包围盒（由约束 $0 \le x_i, y_i \le 50$）。对任意非负点 $P = (x, y)$，定义收缩 $P' = (\mathrm{clip}(x), \mathrm{clip}(y))$（各分量夹到 $[0,50]$），则每座塔到 $P'$ 的距离不超过到 $P$ 的距离，且 $P' \preceq_{lex} P$（$P'$ 字典序不大于 $P$，$P \notin B$ 时严格更小）。

**证明**：对塔坐标 $t \in [0,50]$ 与非负数 $x$：$|\mathrm{clip}(x) - t| \le |x - t|$。若 $x \le 50$ 则 $\mathrm{clip}(x) = x$ 不变；若 $x > 50$ 则 $\mathrm{clip}(x) = 50 \le x$，且 $t \le 50 \le x$，故 $|50 - t| = 50 - t \le x - t = |x-t|$。两个分量各自成立，由勾股不等式 $d(P') \le d(P)$，再由引理 1 每塔贡献不减，求和得 $\mathit{quality}(P') \ge \mathit{quality}(P)$。字典序：若 $x > 50$，则 $P'$ 的横坐标 $50 < x$，严格小；若 $x \le 50 < y$，则横坐标相同、纵坐标 $50 < y$，严格小。∎

**定理**：按字典序扫描 $[0,50]^2$ 中所有整数点、以严格大于更新所得的坐标，即「信号强度最大的字典序最小非负整数坐标」。

**证明**：设 $Q^*$ 为全体非负整数坐标中强度最大、字典序最小的点，强度最大值为 $M$。**存在性**：任取一个非负最优点 $P$（强度 $M$，存在因为强度非负且 $(0,0)$ 处有定义），其收缩 $P' \in B$ 强度 $\ge M$，而 $M$ 已是最大，故 $P'$ 强度 $= M$——最大值在盒内取到。**字典序最小性**：若 $Q^* \notin B$，取其收缩 $Q'$：强度 $= M$（同上）且 $Q' \prec_{lex} Q^*$，与 $Q^*$ 字典序最小矛盾，故 $Q^* \in B$。**算法返回 $Q^*$**：算法按字典序枚举 $B$ 内所有点，只有严格大于当前最优才更新，故最终保留的是 $B$ 内强度为 $M$ 的点中字典序最小者。盒外不存在强度 $M$ 且字典序小于它的非负点（否则其收缩更小，矛盾），故该点即 $Q^*$。∎

## 6. 复杂度分析

- **时间**：$O(51^2 \cdot T)$，其中 $T = towers.length \le 50$，约 $1.3 \times 10^5$ 次内层运算，常数极小。
- **空间**：$O(1)$ 额外空间（不计输入）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> bestCoordinate(vector<vector<int>>& towers, int radius) {
        int bx = 0, by = 0, best = -1;
        long long r2 = (long long)radius * radius;
        for (int x = 0; x <= 50; ++x) {
            for (int y = 0; y <= 50; ++y) {           // 扫描顺序 = 字典序
                int q = 0;
                for (const auto& t : towers) {
                    long long dx = t[0] - x, dy = t[1] - y;
                    long long d2 = dx * dx + dy * dy;
                    if (d2 <= r2)                      // 平方比较，避免开方误差
                        q += (int)(t[2] / (1.0 + sqrt((double)d2)));
                }
                if (q > best) { best = q; bx = x; by = y; }  // 严格大于 → 保留字典序小者
            }
        }
        return {bx, by};
    }
};
```

### Python

```python
class Solution:
    def bestCoordinate(self, towers: list[list[int]], radius: int) -> list[int]:
        best, bx, by = -1, 0, 0
        r2 = radius * radius
        for x in range(51):
            for y in range(51):                        # 扫描顺序 = 字典序
                q = 0
                for tx, ty, tq in towers:
                    d2 = (tx - x) ** 2 + (ty - y) ** 2
                    if d2 <= r2:                       # 平方比较，避免开方误差
                        q += int(tq / (1 + d2 ** 0.5))
                if q > best:                           # 严格大于 → 保留字典序小者
                    best, bx, by = q, x, y
        return [bx, by]
```

> 💡 两份代码均通过官方 3 个示例（`[2,1]`、`[23,11]`、`[1,2]`）；并与「精确整数二分求 $\lfloor q/(1+\sqrt{d^2}) \rfloor$、扫描 $[0,70]^2$ 更大范围」的题意模拟暴力对拍 300 组随机数据（含 $q=0$ 塔、塔重叠、大半径等极端情况），另做 200 组 C++/Python 互拍，全部一致，`mismatch = 0`。对拍中还专门验证了「$q=0$ 时全平面强度为 0、答案必须是 $(0,0)$ 而非任意负坐标」这一非负约束的坑。

## 8. 边界情况与易错点

1. **tie-break 是字典序最小，且限定非负**：$x$ 优先比较、其次 $y$；扫描顺序 + 严格大于更新一步到位。若写成 `>=` 或倒序扫描都会答错。
2. **$q_i = 0$ 的塔**：所有点强度至多 0（全平面强度都是 0），答案为 $(0,0)$——这恰好检验「非负坐标」约束：若允许负坐标，字典序最小会是 $(-\infty \cdots)$ 方向的点，题目因此显式限定非负。
3. **可达判定用 $d^2 \le radius^2$**：直接 `sqrt(d) <= radius` 在边界上可能因浮点误差翻转；平方比较全部是整数运算，精确。
4. **$\lfloor q/(1+d) \rfloor$ 别写成整数除法**：$q \bmod (1+d)$ 的除数是实数，C++ 中 `(int)(t[2] / (1.0 + sqrt(...)))` 是先浮点除再截断（操作数非负，截断即向下取整）。
5. **单塔时答案就是塔的位置**：看似显然，但它是「最优在盒内」的特例；不要因此误以为只需检查塔的位置——多塔叠加时最优点可能在塔外（甚至空白处）。
6. **不要只扫塔的包围盒附近**：比如塔都在 $x \ge 30$ 时，$(0,0)$ 仍可能是并列最优（强度 0 时），必须保证扫描覆盖全部 $[0,50]^2$ 或按引理 2 论证收缩。
7. **`best` 初值用 $-1$ 而非 $0$**：保证第一个点 $(0,0)$（哪怕强度 0）也会被记录，避免「全 0 强度时返回未初始化值」。
