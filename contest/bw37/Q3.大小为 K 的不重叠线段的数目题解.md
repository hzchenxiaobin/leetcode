# LeetCode 大小为 K 的不重叠线段的数目 题解

## 1. 题目概述

- **标题 / 题号**：大小为 K 的不重叠线段的数目（#1621，medium）
- **链接**：https://leetcode.cn/problems/number-of-sets-of-k-non-overlapping-line-segments/
- **来源**：LeetCode 第 37 场双周赛 Q3
- **难度**：中等
- **标签**：数学、动态规划、组合数学

**题意**：一维数轴上有 $n$ 个点，第 $i$ 个点位于 $x = i$（$i = 0 \dots n-1$）。要放置**恰好 $k$ 条线段**，要求每条线段两个端点都是整数坐标、至少覆盖**两个**点、且 $k$ 条线段互不重叠（但**端点可以重合**）。求方案数，对 $10^9+7$ 取余。

**约束**：

- $2 \le n \le 1000$
- $1 \le k \le n-1$

> ⚠️ 本题最大的语义坑是「不重叠」：相邻线段**共享端点是允许的**（如 $(0,2)$ 与 $(2,3)$），只禁止内部相交（如 $(0,3)$ 与 $(1,2)$）。这个语义直接决定计数公式，见 §3.2 与 §5。

## 3. 解题思路

### 3.1 暴力思路

线段总数有 $\binom{n}{2}$ 条（每条由端点对 $(l, r)$、$l < r$ 决定），从中选 $k$ 条的组合数是 $\binom{\binom{n}{2}}{k}$，$n = 1000$ 时天文数字，直接枚举子集不可行。改用逐段 DFS：从左到右依次决定每条线段 $(l_i, r_i)$，要求 $r_{i-1} \le l_i$。这个搜索的状态空间仍然巨大——但它的结构提示我们：**「从左到右、逐点决策」天然是一个线性 DP**，或者更进一步，是一段可以直接闭式化简的组合计数。

### 3.2 核心观察：平移双射 → 严格递增序列 → 一个组合数

![核心观察：平移双射与挡板法](images/bw37_q3_shift_bijection.svg)

把 $k$ 条线段按位置从左到右排序为 $l_1 \le r_1 \le l_2 \le r_2 \le \cdots \le l_k \le r_k$（不重叠保证可以如此全序排列，端点重合即取等号）。关键的一步**平移**：把第 $i$ 条线段整体右移 $i-1$，令

$$l'_i = l_i + (i-1), \qquad r'_i = r_i + (i-1).$$

- 段内：$l_i < r_i \Rightarrow l'_i < r'_i$ 不变；
- 段间：$r_i \le l_{i+1} \Rightarrow r_i + i - 1 < l_{i+1} + i - 1 + 1$，即 $r'_i < l'_{i+1}$，**共享端点被平移拆开**，相邻段之间至少空出一个位置；
- 值域：$l'_1 = l_1 \ge 0$，$r'_k = r_k + k - 1 \le n + k - 2$。

于是合法方案与「从 $[0, n+k-2]$ 这 $n+k-1$ 个数中选 $2k$ 个互不相同的数组成的严格递增序列 $l'_1 < r'_1 < l'_2 < r'_2 < \cdots < l'_k < r'_k$」**一一对应**，方案数为

$$\binom{n+k-1}{2k}.$$

用示例 1 验证：$\binom{4+2-1}{4} = \binom{5}{4} = 5$ ✓；示例 2：$\binom{3}{2} = 3$ ✓；示例 3：$\binom{36}{14} = 3796297200 \bmod (10^9+7) = 796297179$ ✓。

> 💡 等价的**挡板法**视角：一条线段覆盖 $a_i \ge 1$ 个单位长度（相邻点之间的间隔），线段之间及两端共有 $g_0, g_1, \dots, g_k \ge 0$ 个空位（$g_i$ 为可共端点时相邻两段间隔的点数，可以为 0），总长守恒 $g_0 + a_1 + g_1 + \cdots + a_k + g_k = n-1$。这是 $2k+1$ 个非负变元、和为 $n-1-k$ 的方程，解数 $\binom{(n-1-k)+(2k+1)-1}{(2k+1)-1} = \binom{n+k-1}{2k}$，与平移双射殊途同归。

### 3.3 状态机 DP：扫描每个点，三选一

![状态机 DP：开段 / 收段 / 空过](images/bw37_q3_dp_automaton.svg)

若不想推组合公式（或担心语义推错），一个稳妥的通用做法是按点扫描的计数 DP。定义 $dp[j][0/1]$：扫描到当前点 $x$ 时，已完成 $j$ 条线段，$0$ 表示当前没有「开口」的线段，$1$ 表示有一条已放左端点、尚未放右端点的线段。初始（点 $0$）：

$$dp[0][0] = 1 \quad (点 0 空过), \qquad dp[0][1] = 1 \quad (点 0 作为某线段左端点).$$

每前进到新点，有三种动作——**空过**、**开新段**（把当前点作为新线段左端点）、**收尾**（把当前点作为开口线段的右端点；收尾后还可以**立刻**在同一点开新段，这正是「端点可重合」的来源）：

$$\begin{aligned}
dp_{\text{新}}[j][0] &= dp[j][0] + dp[j-1][1] &&(\text{空过；或收尾且不接新段})\\
dp_{\text{新}}[j][1] &= dp[j][0] + dp[j][1] + dp[j-1][1] &&(\text{开新段；延续开段；或收尾后立刻开新段})
\end{aligned}$$

扫描完 $n-1$ 个点后，答案为 $dp[k][0]$（不允许留下未闭合的线段）。

> ⚠️ 若删去转移里的第三项「收尾后立刻开新段」，算出的就是「相邻线段不可共端点」的方案数，$n=4, k=2$ 时会错算成 3 而非 5——这一项正是两种语义的分水岭。

### 3.4 示例演算

![示例演算：n=5,k=3 的全部 7 种方案](images/bw37_q3_walkthrough.svg)

以 $n = 5, k = 3$ 为例，公式给 $\binom{5+3-1}{6} = \binom{7}{6} = 7$，逐一列出核对：

$$\begin{aligned}
&\{(0,1),(1,2),(2,3)\},\quad \{(0,1),(1,2),(2,4)\},\quad \{(0,1),(1,2),(3,4)\},\\
&\{(0,1),(1,3),(3,4)\},\quad \{(0,1),(2,3),(3,4)\},\quad \{(0,2),(2,3),(3,4)\},\\
&\{(1,2),(2,3),(3,4)\}.
\end{aligned}$$

7 个方案全部满足「相邻段可共端点」（如第一、二个方案里相邻段端点 $1,1$、$2,2$ 重合）。DP 与公式在 $n \le 10$ 的所有 $(n,k)$ 上逐点互拍一致（见 §7 验证说明）。

## 4. 算法细节

1. **两种实现任选其一**：
   - **DP 版**：$O(nk)$ 时间、$O(k)$ 空间（滚动掉点维度），稳、通用、不依赖组合洞察；
   - **公式版**：$\binom{n+k-1}{2k}$，预处理阶乘与阶乘逆元 $O(n+k)$，代码极短。
2. **阶乘逆元线性递推**：$inv\_fact[i-1] = inv\_fact[i] \cdot i \bmod p$，只需一次费马小定理求 $inv\_fact[N]$（$N \le n + k - 1 \le 1998$）。
3. **平移双射中「$+1$ 拆端点」的方向别搞反**：是第 $i$ 条段整体加 $i-1$，使「$r_i \le l_{i+1}$」变「$r'_i < l'_{i+1}$」；若平移量取错（如都加 $k-1$），段间约束不会被拆成严格序，映射不再双射。
4. **DP 的下标边界**：$dp[j-1][1]$ 在 $j = 0$ 时不存在，置 0；初始状态里 $dp[0][1] = 1$ 对应「在点 0 开段」，漏掉它 $(0, \cdot)$ 起点的方案会全部丢失。
5. **滚动数组更新顺序**：先算 $dp_{\text{新}}[j][0]$ 再算 $dp_{\text{新}}[j][1]$ 无妨，因为二者都只读**旧**层数组；务必复制到新数组再交换，不能原地自更新。
6. **取模时机**：每次加法后取模，乘法用 `long long` 中转（$p < 2^{30}$，三个 $p$ 量级的数相加不溢出 `long long`）。

## 5. 正确性证明

**引理 1（全序化）**：合法方案中 $k$ 条线段可唯一排成 $l_1 \le r_1 \le l_2 \le r_2 \le \cdots \le l_k \le r_k$，且 $l_i < r_i$。

**证明**：「不重叠」意味着任意两条线段 $[l,r]$、$[l',r']$ 要么 $r \le l'$、要么 $r' \le l$（否则存在点同属两线段内部之外——准确地说，若 $l < l'$ 且 $r > l'$，则线段 $[l,r]$ 覆盖 $l'+0.5$ 附近的单位区间与 $[l',r']$ 覆盖的区间相交，即内部相交，违反不重叠）。故两两可比较，构成全序，排序唯一。两条完全相同的线段会内部相交，故不重复出现，序严格确定。「至少覆盖两个点」即 $l_i < r_i$。∎

**引理 2（平移双射）**：映射 $\Phi: (l_i, r_i) \mapsto (l_i + i - 1,\ r_i + i - 1)$ 是「满足引理 1 的非降端点序列（值域 $[0, n-1]$）」到「严格递增序列 $x_1 < x_2 < \cdots < x_{2k}$（值域 $[0, n+k-2]$）」的双射。

**证明**：先证像合法。段内：$l_i < r_i \Rightarrow l_i + i - 1 < r_i + i - 1$。段间：$r_i \le l_{i+1} \Rightarrow r_i + i - 1 \le l_{i+1} + i - 1 < l_{i+1} + i$，即像中第 $2i$ 个数 $<$ 第 $2i+1$ 个数。值域上界：$r_k + k - 1 \le (n-1) + k - 1 = n + k - 2$；下界 $l_1 = l_1 + 0 \ge 0$。故像确实是 $[0, n+k-2]$ 上的严格递增 $2k$ 元组。

再证满射且逆映射回到原空间。给定严格递增 $x_1 < \cdots < x_{2k} \in [0, n+k-2]$，令 $l_i = x_{2i-1} - (i-1)$，$r_i = x_{2i} - (i-1)$。段内：$l_i < r_i$（由 $x_{2i-1} < x_{2i}$）。段间：$x_{2i} < x_{2i+1} \Rightarrow x_{2i} \le x_{2i+1} - 1 \Rightarrow r_i = x_{2i} - (i-1) \le x_{2i+1} - i = l_{i+1}$。值域：$l_1 = x_1 \ge 0$；$r_k = x_{2k} - (k-1) \le (n+k-2) - (k-1) = n-1$。且两个复合都恒等（平移量逐段相互抵消）。故 $\Phi$ 是双射。∎

**定理（公式）**：方案数 $= \binom{n+k-1}{2k}$。

**证明**：由引理 1，方案 ↔ 非降端点序列；由引理 2，非降端点序列 ↔ $[0, n+k-2]$ 内的 $2k$ 元严格递增序列，后者恰是从 $n+k-1$ 个数中选 $2k$ 个（再按序排列）的方法数 $\binom{n+k-1}{2k}$。∎

**定理（DP）**：状态机 DP 扫描 $n-1$ 步后 $dp[k][0]$ 即方案数。

**证明**：对扫描点数 $x$ 归纳：$dp[j][s]$ 等于「只用 $[0, x]$ 内的点、已完成 $j$ 段、处于状态 $s$ 的**前缀方案**数」。归纳基础 $x = 0$：两个初始状态各对应一种前缀。归纳步：任何 $[0, x+1]$ 上的前缀方案按其在点 $x+1$ 处的动作分类——空过 / 开新段 / 延续开段 / 收尾（不接或接新段）——五类动作互斥且穷尽，且删去点 $x+1$ 的动作后恰得一个 $[0, x]$ 上的合法前缀（收尾动作要求此前处于状态 1 且完成后段数增一），分类计数与三条转移一一对应。归纳成立。终态时「不留下开段」即 $s = 0$，且每段端点都落在 $[0, n-1]$、至少跨两个点（开段与收尾不在同一点发生，由转移结构保证：状态 1 只能由「开新段」进入、且在**下一个及以后**的点才能收尾），故 $dp[k][0]$ 精确计数全部合法方案。∎

## 6. 复杂度分析

- **时间**：DP 版 $O(nk)$（$n, k \le 1000$，至多 $10^6$ 次转移，每次常数）；公式版 $O(n + k)$ 预处理 + $O(1)$ 查询。
- **空间**：DP 版滚动后 $O(k)$；公式版 $O(n+k)$ 存阶乘表（也可不存逆元表、按需快速幂，$O(\log p)$ 每次查询）。

## 7. 参考代码

### C++（状态机 DP）

```cpp
class Solution {
public:
    int numberOfSets(int n, int k) {
        const long long MOD = 1000000007LL;
        // dp[j][0/1]：扫描到当前点，已完成 j 段；0=无开段，1=有一条已放左端点的开段
        vector<array<long long, 2>> cur(k + 1), nxt(k + 1);
        cur[0][0] = 1;              // 点 0 空过
        cur[0][1] = 1;              // 点 0 作为某线段左端点开段
        for (int i = 1; i <= n - 1; ++i) {
            for (int j = 0; j <= k; ++j) {
                long long closed = (j >= 1) ? cur[j - 1][1] : 0;       // 在当前点收尾，凑成第 j 段
                nxt[j][0] = (cur[j][0] + closed) % MOD;               // 空过 / 收尾后不接新段
                nxt[j][1] = (cur[j][0] + cur[j][1] + closed) % MOD;   // 开新段 / 延续 / 收尾后立刻开新段
            }
            swap(cur, nxt);
        }
        return (int)cur[k][0];
    }
};
```

### Python（闭式公式 $\binom{n+k-1}{2k}$）

```python
class Solution:
    def numberOfSets(self, n: int, k: int) -> int:
        MOD = 10 ** 9 + 7
        N, M = n + k - 1, 2 * k                      # 从 n+k-1 个数中选 2k 个
        fact = [1] * (N + 1)
        for i in range(1, N + 1):
            fact[i] = fact[i - 1] * i % MOD
        inv_fact = [1] * (N + 1)
        inv_fact[N] = pow(fact[N], MOD - 2, MOD)     # 费马小定理求逆元
        for i in range(N, 0, -1):
            inv_fact[i - 1] = inv_fact[i] * i % MOD
        return fact[N] * inv_fact[M] % MOD * inv_fact[N - M] % MOD
```

> 💡 两份代码均通过官方全部 5 个示例（`5`、`3`、`796297179`、`7`、`1`）。另外做了三重对拍：(1) $n \le 10$ 的所有 $(n, k)$ 上 DP、Python 公式类与「逐段 DFS 枚举」暴力三方一致；(2) 500 组随机 $(n \le 1000)$ DP 与公式一致；(3) 300 组随机 C++/Python 互拍，`mismatch = 0`。

## 8. 边界情况与易错点

1. **「至少覆盖两个点」= $l < r$**：不是 $l \le r$（单点线段非法），也不是「长度 $\ge 2$」。DP 中「开段后至少到下一个点才能收尾」由状态结构保证；公式中体现为 $l'_i < r'_i$ 的严格序。
2. **「端点可以重合」是计数公式的命门**：DP 漏掉「收尾后立刻开新段」转移、公式误用严格不重叠版本都会错。若端点**不可**重合（相邻段至少隔 1 个点），同法可推得方案数为 $\binom{n}{2k}$——例如 $n=4,k=2$ 时仅 $\{(0,1),(2,3)\}$ 一种 $=\binom{4}{4}$。
3. **$k = n-1$ 的极限**：$n$ 个点放 $n-1$ 条线段，每条恰好覆盖相邻两点、相邻段共端点，唯一方案「首尾相接」；公式 $\binom{n+n-2}{2n-2}$ 退化为 $\binom{2n-2}{2n-2} = 1$ ✓。
4. **溢出**：转移里三个 $10^9$ 量级的数相加仍在 `long long` 范围内，但相乘必须先取模；公式版 `fact` 累乘前每步 `% MOD`。
5. **DP 初始状态**：$dp[0][1] = 1$（点 0 可以直接开段）最易漏；漏掉后所有以 $l_1 = 0$ 开头的方案消失。
6. **答案取 $dp[k][0]$ 而非 $dp[k][0] + dp[k][1]$**：$s=1$ 表示仍有未闭合线段，不是完整方案。
7. **`k > n-1` 不会出现**（约束保证），但公式版写成防御性的 $M > N \Rightarrow 0$ 更稳。
