# LeetCode 最深叶节点的最近公共祖先 题解

## 1. 题目概述

- **标题 / 题号**：最深叶节点的最近公共祖先（#1123，medium）
- **链接**：https://leetcode.cn/problems/lowest-common-ancestor-of-deepest-leaves/
- **来源**：LeetCode 第 145 场周赛 Q2
- **难度**：中等
- **标签**：树、深度优先搜索、广度优先搜索、二叉树、最近公共祖先、树形 DP

**题意**：给定一棵二叉树的根 `root`，返回它的**所有最深叶节点的最近公共祖先**（返回节点本身，评测时按该节点子树的层序序列化比较）。其中叶节点指没有子节点的节点；根节点深度为 $0$，其子节点深度为 $d+1$。

**约束**：

- 节点数在 $[1, 1000]$ 之间
- $0 \le \text{Node.val} \le 1000$，且各节点值**互不相同**
- 深度基准：根节点深度为 $0$

> 💡 题意里的「最深」是**全局最深**；而递归过程中每个节点只关心自己子树内的最深叶子——两者的区分是本题的唯一门槛。

## 2. 示例

**示例 1**

```text
输入：root = [3,5,1,6,2,0,8,null,null,7,4]
输出：[2,7,4]
解释：最深叶子是 7 和 4（深度 3），它们的 LCA 是节点 2，故返回以 2 为根的子树。
      节点 6、0、8 也是叶子，但深度只有 2，不参与计算。
```

**示例 2**

```text
输入：root = [1]
输出：[1]
解释：根节点同时是唯一的叶子和最深节点，LCA 就是它自己。
```

**示例 3**

```text
输入：root = [0,1,3,null,2]
输出：[2]
解释：最深叶子只有 2（深度 2），单个节点的 LCA 是它自己。
```

## 3. 解题思路

### 3.1 暴力思路

最直白的做法分两趟：

1. 一次遍历求出每个节点的深度，收集所有最深叶子，得到一个集合 $S$；
2. 对集合 $S$ 求 LCA：从根往下走，若某个孩子节点的子树包含 $S$ 的全部节点就下沉，否则停在当前节点。

第 2 步需要额外维护「子树内最深叶子个数」，或者对每个叶子记录根路径、取所有路径的最长公共前缀，复杂度 $O(nh)$；若套用通用 LCA（倍增 / 父链哈希表）则是 $O(n\log n)$。$n \le 1000$ 时这些做法都能过，但都要多趟遍历、维护额外信息，边界也更容易写错。

### 3.2 核心观察：后序回传「高度 + 答案」

![示例 1 的树与答案节点](images/wc145_q2_example_tree.svg)

设 $u$ 子树内的**最深叶子**指深度（相对整棵树）最大的那些叶子。答案节点 $A$ 有一个关键性质：**它的左右两侧都含有全局最深叶子**。若只有一侧含有全局最深叶子，这些叶子就全在该侧的子树里，LCA 必然也落在那一侧、可以继续下沉，$A$ 就不是最低的了。

反过来也成立：如果一个节点左右两侧「最深叶子到它的距离」**相等**，那它的两侧都贡献了同样深的叶子，任何后代节点都只能覆盖其中一侧，于是这个节点本身就是该子树内最深叶子的 LCA。

于是对每个节点 $u$ 定义两个量，用一次后序遍历就能算出来：

- $h(u)$：$u$ 子树内最深叶子到 $u$ 的**距离**（叶子为 $0$，空子树为 $-1$）；
- $a(u)$：$u$ 子树内所有最深叶子的 **LCA**。

递推只有三种情况：

$$h(u) = 1 + \max\bigl(h(l),\, h(r)\bigr)$$

$$a(u) = \begin{cases} a(l), & h(l) > h(r) \\ a(r), & h(r) > h(l) \\ u, & h(l) = h(r) \end{cases}$$

第三种情况正是「同高 ⇒ 分叉点就是自己」；而叶子节点左右都是 $-1$，也自动落进这一支，不需要特判。

### 3.3 算法流程

![后序遍历的三选一返回规则](images/wc145_q2_postorder_dp.svg)

1. `dfs(null)` 返回 $(-1,\ \text{null})$，作为空子树的基准；
2. 先递归左、右子树，拿到 $(h_l, a_l)$ 与 $(h_r, a_r)$；
3. 按上面三种情况返回 $(1+\max(h_l,h_r),\ a)$；
4. 主函数只取 `dfs(root)` 的第二个分量，即答案节点。

整个过程**自底向上、每个节点只访问一次**，不需要额外哈希表，也不需要知道最深叶子具体是谁——只回传高度就足够做比较。

> 💡 如果不想写递归，可以用显式栈做后序遍历，或者先 BFS 求深度、再按深度从大到小合并父节点；本质都是同一份递推，只是遍历顺序不同。

### 3.4 示例演算

![示例 1 的后序演算表](images/wc145_q2_walkthrough.svg)

对示例 1 的树按「叶子 → 内部节点」的顺序回传，下表摘出关键节点（其余叶子 6、0、8 都是同一行的 $(0,\text{自己})$，完整走查见上图）：

| 节点 | 左 $(h_l,a_l)$ | 右 $(h_r,a_r)$ | 返回 $(h,a)$ | 判定 |
|------|----------------|----------------|--------------|------|
| 7、4 | $(-1,\cdot)$ | $(-1,\cdot)$ | $(0,\text{自己})$ | 叶子，落进同高分支 |
| 2 | $(0,7)$ | $(0,4)$ | $(1,2)$ | 同高，2 就是分叉点 |
| 5 | $(0,6)$ | $(1,2)$ | $(2,2)$ | 右更深，继承右子树答案 |
| 1 | $(0,0)$ | $(0,8)$ | $(1,1)$ | 同高，1 是自己子树内的答案 |
| 3 | $(2,2)$ | $(1,1)$ | $(3,2)$ | 左更深，继承左子树答案 |

最终 `dfs(3)` 返回 $(3, 2)$，输出以 2 为根的子树 `[2,7,4]`，与官方示例一致。注意节点 1 虽然也「同高」，但它的高度只有 $1$，在根处比较时被左侧的 $2$ 淘汰——**局部同高只决定局部答案，全局答案靠逐层比较得出**。

## 4. 算法细节

1. **空子树基准取 $-1$**：这样叶子的回传高度正好是 $0$，与「叶子到自身的距离为 $0$」一致，回传值可以直接读作距离。若把空子树记作 $0$，所有高度会整体 $+1$（叶子变成 $1$），左右比较本身仍然成立，但已与「高度 = 距离」的定义错位；一旦再顺手给叶子写一句 `h = 0` 的特判，单孩子节点就会出现「空子树 $0$ 与子节点 $0$ 相等」的假同高。
2. **返回值用二元组**：C++ 用 `pair<int, TreeNode*>`，Python 用元组 `(h, node)`；空子树返回 `(-1, nullptr)`。不要用全局变量保存「当前答案」，否则无法表达「子树内答案」这一层语义。
3. **同高分支返回 `u` 本身**，而不是继续把两侧答案往上合并——同高意味着两侧各有一批同样深的最深叶子，唯一的公共祖先是 `u`。
4. **比较高度，不要比较节点值**：题目保证值唯一，但值的大小与深度无关；所有判断都必须基于高度 $h$。
5. **递归深度**：$n \le 1000$，C++ 默认栈足够；Python 默认递归上限为 $1000$，链状树会踩线，应 `sys.setrecursionlimit(10000)` 或改写为迭代。
6. **返回值是节点引用**：$a(\text{root})$ 直接指向原树中的节点，不复制子树，因此额外空间只有递归栈。

## 5. 正确性证明

**引理 1（高度正确）**：对任意节点 $u$，`dfs(u)` 返回的 $h(u)$ 等于 $u$ 子树内最深叶子到 $u$ 的距离；空子树约定为 $-1$。

**证明**：对子树大小归纳。空子树与叶子节点显然成立（叶子：两个空孩子高度均为 $-1$，故 $h = 0$）。设 $u$ 的左右孩子为 $l, r$（可以为空），由归纳假设它们返回的高度正确。$u$ 子树内的最深叶子必然落在某个非空孩子子树中，且到 $u$ 的距离等于「到该孩子的距离 $+1$」，故 $h(u) = 1 + \max(h(l), h(r))$（空孩子贡献 $-1$），与递推一致。∎

**引理 2（答案正确）**：对任意节点 $u$，`dfs(u)` 返回的 $a(u)$ 是 $u$ 子树内所有最深叶子的最近公共祖先。

**证明**：对子树高度归纳，分三种情况。

- $h(l) > h(r)$：$u$ 子树内最深叶子全部位于左子树，且它们在左子树内也是「最深叶子」（相对深度同为 $h(l)$）。任何公共祖先必须位于左子树内，而由归纳假设 $a(l)$ 是左子树内这些叶子的最低公共祖先，它同时是 $u$ 子树内的最低公共祖先，故 $a(u) = a(l)$。
- $h(r) > h(l)$：与上一种对称，$a(u) = a(r)$。
- $h(l) = h(r)$：若两者均为 $-1$，则 $u$ 是叶子，$u$ 子树内唯一的最深叶子就是它自己，LCA 为 $u$，成立。否则 $h(l) = h(r) \ge 0$，两侧都含有 $u$ 子树内的最深叶子（距离同为 $h(l)+1$）。$u$ 的任何真后代都只属于左子树或只属于右子树，无法同时覆盖两侧的最深叶子，因此公共祖先只能是 $u$ 或 $u$ 的祖先；而 $u$ 自身即可覆盖全部，故最低公共祖先为 $u$，即 $a(u) = u$。∎

**定理**：算法返回的节点是整棵树中所有最深叶节点的最近公共祖先。

**证明**：全体最深叶子正是根节点子树内的最深叶子，由引理 1，$h(\text{root})$ 等于全局最大深度（根深度为 $0$，距离即深度差）；再由引理 2 取 $u = \text{root}$，`dfs(root)` 返回的 $a(\text{root})$ 即这些叶子的最低公共祖先。∎

## 6. 复杂度分析

- **时间**：$O(n)$。后序遍历中每个节点恰好被访问一次，每次只做两次比较、一次加法与一次 `pair` 构造，常数开销；没有额外的深度预计算或 LCA 预处理。
- **空间**：$O(h)$，$h$ 为树高，来自递归调用栈；最坏情形是链状树，$h = n \le 1000$，即 $O(n)$。除栈以外只用了 $O(1)$ 的临时变量，返回的是原树节点引用。

## 7. 参考代码

### C++

```cpp
class Solution {
    // 返回 (子树内最深叶子到 u 的距离, 该子树内最深叶子的 LCA)
    pair<int, TreeNode*> dfs(TreeNode* u) {
        if (!u) return {-1, nullptr};                 // 空子树基准：高度 -1
        auto L = dfs(u->left);
        auto R = dfs(u->right);
        if (L.first > R.first) return {L.first + 1, L.second};   // 左侧更深
        if (R.first > L.first) return {R.first + 1, R.second};   // 右侧更深
        return {L.first + 1, u};                      // 同高（含叶子）：u 是分叉点
    }

public:
    TreeNode* lcaDeepestLeaves(TreeNode* root) {
        return dfs(root).second;
    }
};
```

### Python

```python
import sys


class Solution:
    def lcaDeepestLeaves(self, root: Optional[TreeNode]) -> Optional[TreeNode]:
        sys.setrecursionlimit(10000)                  # 链状树深度可达 1000

        # 返回 (子树内最深叶子到 node 的距离, 该子树内最深叶子的 LCA)
        def dfs(node: Optional[TreeNode]):
            if node is None:
                return -1, None                       # 空子树基准：高度 -1
            lh, ln = dfs(node.left)
            rh, rn = dfs(node.right)
            if lh > rh:
                return lh + 1, ln                     # 左侧更深，答案在左边
            if rh > lh:
                return rh + 1, rn                     # 右侧更深，答案在右边
            return lh + 1, node                       # 同高（含叶子）：node 是分叉点

        return dfs(root)[1]
```

## 8. 边界情况与易错点

1. **只有根节点**：`[1]` → 两个空孩子高度都是 $-1$，返回 $(0, \text{root})$，答案就是根本身。
2. **链状树**：`[0,1,3,null,2]` 中每层都有一侧为空（$h = -1$），严格不等，答案一路继承到最深叶子 2，最终返回它自己。
3. **空子树基准与叶子高度混用**：若既把空子树记作 $0$、又给叶子特判 `h = 0`，那么「只有一个孩子且该孩子是叶子」的节点会被判成左右同高，错误地返回自己而不是那个叶子。两处必须用同一套约定（本文：空 $=-1$，叶子 $=0$）。
4. **把「最深叶子的值」当答案**：示例 1 返回的是节点 2 的**整棵子树** `[2,7,4]`，不是叶子 7 或 4，也不是值 `2` 单独一个节点。
5. **Python 递归上限**：默认 $1000$，深度接近上限的链会 `RecursionError`，务必提高上限或改迭代写法（此时可用显式栈模拟后序）。
6. **多叶子同深**：完全二叉树的所有叶子深度相同，此时根就是答案；这正是「同高一路向上返回 $u$」的自然结果，无需特判。

**延伸思考**：

1. **最浅叶子的 LCA**：把 $h$ 换成「最深」改为「最浅」不能直接照抄递推——最浅叶子可能只出现在一侧，需要额外记录该层是否已达标，属于「按层聚合」而非「取最大」。
2. **第 $k$ 深的叶子集合**：把返回的高度换成一个「深度频次数组」或者按深度分桶后再自底向上合并，可以把问题推广到任意深度层。
3. **带边权的版本**：把 $h$ 从「边数」改为「路径长度和」，递推结构不变，只是 $+1$ 变为 $+w(u, \text{child})$。
4. **多叉树 / 森林**：多叉树需要在所有孩子中找最大值并统计「取到最大值的个数」，个数 $\ge 2$ 时才是分叉点；森林则要先在各棵树上分别求，再对结果按深度取 LCA。
