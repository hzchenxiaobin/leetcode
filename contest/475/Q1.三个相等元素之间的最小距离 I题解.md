# LeetCode 三个相等元素之间的最小距离 I 题解

## 1. 题目概述

- **标题 / 题号**：三个相等元素之间的最小距离 I（#3740，easy）
- **链接**：https://leetcode.cn/problems/minimum-distance-between-three-equal-elements-i/
- **来源**：LeetCode 第 475 场周赛 Q1
- **难度**：简单
- **标签**：数组、哈希表、枚举、滑动窗口

**题意**：给定整数数组 `nums`。若 `nums[i] == nums[j] == nums[k]` 且 `i, j, k` 为 3 个**不同**下标，则称三元组 $(i, j, k)$ 为**有效三元组**，其**距离**定义为 $\lvert i - j \rvert + \lvert j - k \rvert + \lvert k - i \rvert$。返回有效三元组的**最小**距离；不存在则返回 `-1`。

**约束**：

- $1 \le n = \text{nums.length} \le 100$
- $1 \le \text{nums}[i] \le n$

> 💡 **审题关键**：① 三个下标只需**互不相同**且值相等，$(i,j,k)$ 的任意排列算出的距离相同——绝对值天然对称，不必纠结顺序；② $n \le 100$，官方 hint 直说可用暴力，但同场 Q2（#3741）把 $n$ 放大到 $10^5$，Q1 阶段就值得想清楚线性做法。

## 2. 示例

**示例 1**

```text
输入：nums = [1,2,1,1,3]
输出：6
解释：最小距离对应的有效三元组是 (0, 2, 3)。nums[0] == nums[2] == nums[3] == 1，
距离为 |0-2| + |2-3| + |3-0| = 2 + 1 + 3 = 6。
```

**示例 2**

```text
输入：nums = [1,1,2,3,2,1,2]
输出：8
解释：最小距离对应的有效三元组是 (2, 4, 6)。nums[2] == nums[4] == nums[6] == 2，
距离为 |2-4| + |4-6| + |6-2| = 2 + 2 + 4 = 8。
```

**示例 3**

```text
输入：nums = [1]
输出：-1
解释：不存在有效三元组，因此答案为 -1。
```

## 3. 解题思路

### 3.1 暴力思路

按 $i < j < k$ 枚举全部 $\binom{n}{3}$ 个下标三元组，三者值相等时用距离公式更新答案：

$n = 100$ 时三元组至多 $\binom{100}{3} \approx 1.6 \times 10^5$ 个，轻松通过。但把 $n$ 放大到 Q2 的 $10^5$，$O(n^3)$ 直接爆炸——比赛时若在 Q1 就写出线性做法，Q2 可以直接复制提交，这也是本题的复盘价值所在。

### 3.2 核心观察：距离 = 2 × (最大下标 − 最小下标)

![核心观察：三个成对距离之和等于两倍跨度](images/wc475_q1_distance_pairwise_sum.svg)

三个绝对值项 $\lvert i-j \rvert$、$\lvert j-k \rvert$、$\lvert k-i \rvert$ 恰好是三个下标**两两之间的全部成对距离**。设三个下标排序后为 $a < b < c$，则：

$$\lvert i-j \rvert + \lvert j-k \rvert + \lvert k-i \rvert = (b-a) + (c-b) + (c-a) = 2(c-a)$$

**中间下标 $b$ 一加一减正好抵消**——距离只由两端下标决定，与中间取哪个同值下标无关。

于是问题转化为：**对每个值，找三次出现的最小下标跨度 $c - a$，答案再乘 2**。

### 3.3 算法流程：按值分组 + 相邻三次出现

![算法流程：按值分组与相邻三次出现滑窗](images/wc475_q1_consecutive_occurrences.svg)

固定某个值 $v$，设其出现位置（升序）为 $p_1 < p_2 < \cdots < p_m$。任取其中三次出现 $p_a < p_b < p_c$（$a < b < c$ 为列表下标），由 $a \le c-2$ 得：

$$p_c - p_a \;\ge\; p_c - p_{c-2}$$

即把左端收紧到与 $p_c$ **相邻**的前两次出现，跨度只减不增——**最小跨度必然在某个相邻三次出现窗口 $(p_s, p_{s+1}, p_{s+2})$ 处取得**（中间的 $p_{s+1}$ 天然夹在两端之间，合法性自动满足）。

算法流程：

1. 一趟扫描，`pos[v]` 记录每个值的出现位置（按下标顺序追加，天然升序）。
2. 对每个值 $v$，枚举相邻三次出现窗口，用 $p_{s+2} - p_s$ 更新最小跨度 `best`。
3. 无候选（没有任何值出现至少 3 次）返回 `-1`，否则返回 $2 \times \text{best}$。

### 3.4 示例演算

![示例演算：按值分组求最小跨度](images/wc475_q1_example_walkthrough.svg)

以示例 2 `nums = [1,1,2,3,2,1,2]` 为例：

| 值 $v$ | 出现位置 pos[v] | 相邻三次出现 | 跨度 | 候选距离 |
|--------|----------------|--------------|------|----------|
| 1 | [0, 1, 5] | (0, 1, 5) | 5 | 10 |
| 2 | [2, 4, 6] | (2, 4, 6) | 4 | **8** |
| 3 | [3] | —（不足 3 次，跳过） | — | — |

最小跨度为 4，答案 $= 2 \times 4 = 8$，与示例一致。

## 4. 算法细节

1. **建表**：`pos[v]` 用哈希表（`defaultdict(list)`）；由于值域为 $1 \le \text{nums}[i] \le n$，也可用数组桶 `vector<vector<int>> pos(n + 1)`，避免哈希开销（对 Q2 的 $10^5$ 规模更稳）。
2. **天然升序**：按下标顺序追加，`pos[v]` 内部无需再排序。
3. **窗口枚举**：对每个长度为 $m$ 的位置列表，枚举 $s = 0, 1, \ldots, m-3$，跨度为 `pos[v][s+2] - pos[v][s]`。
4. **乘 2 收尾**：`best` 记录的是跨度 $c - a$，返回前别忘乘 2。
5. **流式变体**：也可以只维护每个值**最近两次**出现位置，扫描到第三次出现时结算 $i - \text{prev}_2$ 再滑窗——一趟完成，写法更短（见参考代码第二个 Python 版本），Q2 可直接沿用。

## 5. 正确性证明

**引理 1（距离化简）**：对任意三个不同下标，设排序后为 $a < b < c$，则 $\lvert i-j \rvert + \lvert j-k \rvert + \lvert k-i \rvert = 2(c-a)$。

**证明**：三个绝对值项与 $(i, j, k)$ 的具体排列无关（绝对值对称），且恰为三个下标两两之间的全部成对距离，即 $b-a$、$c-b$、$c-a$ 三个数。求和得 $(b-a) + (c-b) + (c-a) = 2(c-a)$。∎

**引理 2（相邻收紧）**：设值 $v$ 的出现位置升序为 $p_1 < p_2 < \cdots < p_m$，则任意三次出现 $(p_a, p_b, p_c)$（$a < b < c$）满足 $p_c - p_a \ge p_{c-2} - p_a \ge p_{c-2} - p_a$，特别地跨度不小于窗口 $(p_{c-2}, p_{c-1}, p_c)$ 的跨度 $p_c - p_{c-2}$。

**证明**：$a < b < c$ 为整数，故 $a \le c - 2$，从而 $p_a \le p_{c-2}$，$p_c - p_a \ge p_c - p_{c-2}$。∎

**定理**：算法返回有效三元组的最小距离；不存在有效三元组时返回 `-1`。

**证明**：由引理 1，最小化距离等价于最小化某个值三次出现的跨度 $c - a$。由引理 2，对任意同值三元组，存在右端点相同的**相邻三次出现**窗口，其跨度不更大；且窗口 $(p_s, p_{s+1}, p_{s+2})$ 本身是合法三元组（三个位置互不相同、值相等）。故全局最小跨度必在某个相邻窗口处取得，算法恰好枚举全部窗口并取最小，乘 2 即为答案。若所有值出现次数均不足 3，`best` 保持 $+\infty$，返回 `-1`。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。建表一趟 $O(n)$；所有值的位置列表总长度为 $n$，窗口枚举总数不超过 $n$。
- **空间复杂度**：$O(n)$。位置列表总计存储 $n$ 个下标（流式变体同样 $O(n)$，且每个值只存 2 个位置，常数更小）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minimumDistance(vector<int>& nums) {
        int n = nums.size();
        // 值域 1..n，用数组桶代替哈希表
        vector<vector<int>> pos(n + 1);
        for (int i = 0; i < n; ++i) {
            pos[nums[i]].push_back(i);
        }
        int best = INT_MAX;
        for (int v = 1; v <= n; ++v) {
            for (int s = 0; s + 2 < (int)pos[v].size(); ++s) {
                best = min(best, pos[v][s + 2] - pos[v][s]);
            }
        }
        return best == INT_MAX ? -1 : 2 * best;
    }
};
```

### Python

```python
class Solution:
    def minimumDistance(self, nums: List[int]) -> int:
        pos = defaultdict(list)
        for i, v in enumerate(nums):
            pos[v].append(i)
        best = inf
        for p in pos.values():
            for s in range(len(p) - 2):
                best = min(best, p[s + 2] - p[s])
        return -1 if best == inf else 2 * best
```

流式一趟写法（只保留每个值最近两次出现，Q2 可直接沿用）：

```python
class Solution:
    def minimumDistance(self, nums: List[int]) -> int:
        tail = defaultdict(list)  # v -> 最近两次出现位置
        best = inf
        for i, v in enumerate(nums):
            t = tail[v]
            if len(t) == 2:
                best = min(best, i - t[0])
                t[0], t[1] = t[1], i
            else:
                t.append(i)
        return -1 if best == inf else 2 * best
```

## 8. 边界情况与易错点

1. **无解情况**：所有值出现次数均小于 3（包括 $n < 3$）时返回 `-1`。`best` 初始化为 $+\infty$，窗口循环一次不执行，天然处理，**无需特判**。
2. **答案恒为偶数**：距离 $= 2(c-a)$，且三个不同整数下标必有 $c - a \ge 2$，故答案 $\ge 4$（如 `[1,1,1]` → 下标 (0,1,2)，距离 4）。提交后可用这两点自检。
3. **忘乘 2**：滑窗得到的是跨度 $c - a$，返回前必须乘 2。
4. **值域即桶大小**：$1 \le \text{nums}[i] \le n$，数组桶开 $n+1$ 即可；若用哈希表则无此限制。
5. **中间下标自动合法**：相邻三次出现天然满足 $a < b < c$，无需额外检查中间点位置。
6. **(i, j, k) 的顺序**：距离公式对任意排列对称，按无序三元组考虑即可，不必枚举 6 种排列。
