# LeetCode 检测相邻递增子数组 II 题解

## 1. 题目概述

- **标题 / 题号**：检测相邻递增子数组 II（#3350，medium）
- **链接**：https://leetcode.cn/problems/adjacent-increasing-subarrays-detection-ii/
- **来源**：LeetCode 第 423 场周赛 Q2
- **难度**：中等
- **标签**：数组、递增游程、二分答案、一次扫描

**题意**：给定长度为 $n$ 的整数数组 $\textit{nums}$，求**最大**的 $k$，使得存在两个**相邻**且长度均为 $k$ 的**严格递增**子数组：即存在下标 $a$，使 $\textit{nums}[a..a+k-1]$ 与 $\textit{nums}[a+k..a+2k-1]$（$b = a + k$）都严格递增。返回 $k$ 的最大可能值。

**约束**：

- $2 \le n = \textit{nums.length} \le 2 \times 10^5$
- $-10^9 \le \textit{nums}[i] \le 10^9$

> ⚠️ **读题关键（同 Q1）**：两段只需**各自**严格递增，接缝处**不要求** $\textit{nums}[a+k-1] < \textit{nums}[a+k]$，因此本题**不能**等价成"找长度 $2k$ 的递增段"。本题是同场 Q1（#3349 判定版）的加强版：$n$ 从 $100$ 放大到 $2 \times 10^5$，且从"给定 $k$ 判定"变为"求最大 $k$"。

## 2. 示例

**示例 1**

```text
输入：nums = [2,5,7,8,9,2,3,4,3,1]
输出：3
解释：a = 2 的 [7,8,9] 与 b = 5 的 [2,3,4] 各自严格递增，且 b = a + 3。
```

**示例 2**

```text
输入：nums = [1,2,3,4,4,4,4,5,6,7]
输出：2
解释：[1,2] 与 [3,4] 是一组相邻的长度 2 递增子数组；中间的 4,4,4 把递增段截短，k 无法更大。
```

**示例 3（自构造，单条长链）**

```text
输入：nums = [1,2,3,4,5,6]
输出：3
解释：整个数组是一条递增链，取前半 [1,2,3] 与后半 [4,5,6]，k = ⌊6/2⌋ = 3。
```

## 3. 解题思路

### 3.1 暴力与二分：从判定到最大值

**直接暴力**：枚举 $k$ 与起点 $a$ 逐段检查，最坏 $O(n^2)$——$n = 2 \times 10^5$ 时约 $4 \times 10^{10}$ 次比较，必然超时。

**二分答案**（本题标签 Binary Search 的来源）：注意 $k$ 的可行性**单调**——若 $(a, k)$ 合法，则两段各截去末尾一个元素后 $(a, k-1)$ 仍合法。于是可二分 $k \in [1, \lfloor n/2 \rfloor]$，每次用 Q1 的 $O(n)$ 判定（求出 $\text{inc}$ 游程后检查是否存在 $e$ 满足 $\text{inc}[e] \ge k$ 且 $\text{inc}[e-k] \ge k$），总复杂度 $O(n \log n)$，可以通过。

但二分的每次判定都要重扫一遍数组。其实**一次线性扫描就能直接算出最大 $k$**——只需换一个枚举对象：不枚举 $k$，枚举**接缝**。

### 3.2 核心观察：枚举接缝，双向游程取 min

![枚举接缝 j，两侧游程长度取 min](images/adjacent_inc_seam_concept.svg)

两个相邻子数组 $\textit{nums}[a..a+k-1]$ 与 $\textit{nums}[a+k..a+2k-1]$ 的分界是一个**接缝**：第一段右端点 $j = a+k-1$，第二段左端点 $j+1$。反过来，**固定接缝位置 $j$**，两段就被钉死在 $j$ 两侧：

- 第一段**以 $j$ 结尾**：沿用 Q1 的定义，$\text{inc}[j]$ 为以 $j$ 结尾的最长严格递增连续段长度，第一段最长能取 $\text{inc}[j]$；
- 第二段**从 $j+1$ 开始**：对称地定义 $\text{nxt}[i]$ 为从 $i$ 开始的最长严格递增连续段长度，第二段最长能取 $\text{nxt}[j+1]$。

于是接缝 $j$ 处的最大可行 $k$ 恰为：

$$k(j) = \min\big(\text{inc}[j],\ \text{nxt}[j+1]\big)$$

答案是所有接缝中的最大值：$\max_{0 \le j \le n-2} k(j)$。

这一视角的妙处是**无需分类讨论**——接缝无论落在一个长递增段的**内部**（两段同源，各取链的前后两半），还是落在两个相邻递增段的**边界**（左段取尾、右段取头），都被同一个公式覆盖：

![接缝的两种位置被同一公式统一覆盖](images/adjacent_inc_seam_cases.svg)

$\text{nxt}$ 与 $\text{inc}$ 完全对称，倒序一遍即可求出：

$$\text{nxt}[i] = \begin{cases} \text{nxt}[i+1] + 1, & \textit{nums}[i] < \textit{nums}[i+1] \\ 1, & \text{其他情况} \end{cases}$$

### 3.3 算法流程

1. 正向扫描求 $\text{inc}$（与 Q1 完全相同）；
2. 反向扫描求 $\text{nxt}$；
3. 枚举接缝 $j \in [0, n-2]$，答案取 $\max\big(\min(\text{inc}[j],\ \text{nxt}[j+1])\big)$。

三趟都是简单线性扫描，无嵌套循环。

### 3.4 示例演算

![示例 1 的 inc/nxt 演算与逐接缝取 min](images/adjacent_inc_seam_walkthrough.svg)

对示例 1，$\text{inc} = [1,2,3,4,5,1,2,3,1,1]$，$\text{nxt} = [5,4,3,2,1,3,2,1,1,1]$。逐接缝计算 $k(j) = \min(\text{inc}[j], \text{nxt}[j+1])$：$j = 4$ 处 $\min(5, 3) = 3$ 为全局最大，对应 $[7,8,9] \mid [2,3,4]$，返回 $3$。示例 2 中 $j = 1$ 与 $j = 7$ 处均得 $2$（$\text{inc}[1]=2$ 且 $\text{nxt}[2]=2$；$\text{inc}[7]=2$ 且 $\text{nxt}[8]=2$），故答案 $2$。

## 4. 算法细节

1. **两个游程数组的递推**：$\text{inc}$ 正向判 $\textit{nums}[i] > \textit{nums}[i-1]$，$\text{nxt}$ 反向判 $\textit{nums}[i] < \textit{nums}[i+1]$。方向相反、不等号同向（都要求严格递增），倒序递推边界是 $i$ 从 $n-2$ 到 $0$。
2. **接缝枚举范围**：$j \in [0, n-2]$（写成 `j + 1 < n` 防越界）。$j = n-1$ 右侧无元素，不构成接缝。由 $n \ge 2$，枚举范围非空。
3. **答案下界 1**：$\text{inc}[j] \ge 1$、$\text{nxt}[j+1] \ge 1$ 恒成立（单元素即长度 1 的递增段），故任何 $n \ge 2$ 的数组答案至少为 1，无需特判，也不会返回 0。
4. **$O(1)$ 空间变体**：不存游程数组，单趟扫描维护"上一段长 $\text{prev}$、当前段长 $\text{cur}$"，每步更新

$$\textit{ans} \gets \max\Big(\textit{ans},\ \Big\lfloor \frac{\text{cur}}{2} \Big\rfloor,\ \min(\text{prev},\ \text{cur})\Big)$$

   遇到 $\textit{nums}[i] \le \textit{nums}[i-1]$ 时结算 $\text{prev} \gets \text{cur},\ \text{cur} \gets 1$。$\lfloor \text{cur}/2 \rfloor$ 对应接缝在**段内**的情况（链长 $L$ 贡献 $\lfloor L/2 \rfloor$），$\min(\text{prev}, \text{cur})$ 对应接缝在**段边界**的情况（相邻段贡献 $\min(L_1, L_2)$），与 §3.2 的两种接缝位置一一对应。
5. **与二分解法的取舍**：二分 + 判定为 $O(n \log n)$，思路顺承 Q1；接缝枚举 $O(n)$ 且代码更短。比赛中两者都稳，建议把 $O(n)$ 写法沉淀为模板。

## 5. 正确性证明

**引理 1**（左游程刻画，即 Q1 引理 1）：区间 $\textit{nums}[l..r]$ 严格递增 $\iff \text{inc}[r] \ge r - l + 1$。

**证明**：见 Q1 题解（对 $r$ 归纳）。∎

**引理 2**（右游程刻画）：区间 $\textit{nums}[l..r]$ 严格递增 $\iff \text{nxt}[l] \ge r - l + 1$。

**证明**：将下标反转为 $\sigma(i) = n-1-i$，则 $\textit{nums}[l..r]$ 严格递增等价于反转数组的 $[\sigma(r)..\sigma(l)]$ 严格递增，且 $\text{nxt}[l]$ 恰为反转数组中以 $\sigma(l)$ 结尾的递增游程长度，由引理 1 即得。∎

**定理**：最大可行 $k = \max_{0 \le j \le n-2} \min(\text{inc}[j],\ \text{nxt}[j+1])$。

**证明**：
（$\ge$）取达到最大值的接缝 $j$，令 $k = \min(\text{inc}[j], \text{nxt}[j+1])$。由引理 1、2 知 $\text{inc}[j], \text{nxt}[j+1] \ge 1$，故 $k \ge 1$。取 $a = j - k + 1$：由 $k \le \text{inc}[j]$ 得 $a \ge j - \text{inc}[j] + 1 \ge 0$。第一段 $\textit{nums}[a..j]$ 长为 $k$，由引理 1 严格递增；第二段 $\textit{nums}[j+1..j+k]$ 长为 $k$，由 $k \le \text{nxt}[j+1]$ 及引理 2 严格递增，且 $j + k \le j + \text{nxt}[j+1] \le n-1$ 不越界。两段满足 $b = a + k = j + 1$，即 $(a, k)$ 是合法方案，故答案 $\ge k$。
（$\le$）设 $(a^*, k^*)$ 是任一合法方案，其接缝 $j = a^* + k^* - 1$ 满足 $j + 1 = a^* + k^* \le n - k^* \le n - 1$，故 $j$ 在枚举范围内。第一段 $\textit{nums}[a^*..j]$ 严格递增长 $k^*$，由引理 1 得 $\text{inc}[j] \ge k^*$；第二段 $\textit{nums}[j+1..j+k^*]$ 严格递增长 $k^*$，由引理 2 得 $\text{nxt}[j+1] \ge k^*$。故 $\max_j \min(\text{inc}[j], \text{nxt}[j+1]) \ge k^*$，即公式给出的值不小于任何可行解。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。正向求 $\text{inc}$、反向求 $\text{nxt}$、枚举接缝，三趟各一遍线性扫描，每步 $O(1)$。
- **空间复杂度**：$O(n)$，即两个游程数组；用 §4 的滚动写法可降到 $O(1)$。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int maxIncreasingSubarrays(vector<int>& nums) {
        int n = nums.size();
        vector<int> inc(n, 1), nxt(n, 1);
        for (int i = 1; i < n; i++) {
            if (nums[i] > nums[i - 1]) {
                inc[i] = inc[i - 1] + 1;
            }
        }
        for (int i = n - 2; i >= 0; i--) {
            if (nums[i] < nums[i + 1]) {
                nxt[i] = nxt[i + 1] + 1;
            }
        }
        // j 是第一段右端点（接缝），第二段从 j+1 开始
        int ans = 0;
        for (int j = 0; j + 1 < n; j++) {
            ans = max(ans, min(inc[j], nxt[j + 1]));
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maxIncreasingSubarrays(self, nums: List[int]) -> int:
        n = len(nums)
        inc = [1] * n
        for i in range(1, n):
            if nums[i] > nums[i - 1]:
                inc[i] = inc[i - 1] + 1
        nxt = [1] * n
        for i in range(n - 2, -1, -1):
            if nums[i] < nums[i + 1]:
                nxt[i] = nxt[i + 1] + 1
        # j 是第一段右端点（接缝），第二段从 j+1 开始
        return max(min(inc[j], nxt[j + 1]) for j in range(n - 1))
```

### O(1) 空间变体（C++）

```cpp
class Solution {
  public:
    int maxIncreasingSubarrays(vector<int>& nums) {
        int n = nums.size(), ans = 0, prev = 0, cur = 1;
        for (int i = 1; i < n; i++) {
            if (nums[i] > nums[i - 1]) {
                cur++;
            } else {
                prev = cur;
                cur = 1;
            }
            ans = max(ans, max(cur / 2, min(prev, cur)));
        }
        return ans;
    }
};
```

## 8. 边界情况与易错点

1. **接缝陷阱（同 Q1 最大坑）**：不要求接缝处递增。$\textit{nums} = [5,6,7,1,2,3]$ 的答案是 $3$ 而非 $1$；若误用"最长递增段 $\ge 2k$"判定会系统性偏小。
2. **"严格"递增**：相邻相等即断链，正向判 `>`、反向判 `<`，别写成 `>=` / `<=`。
3. **最小规模 $n = 2$**：如 $\textit{nums} = [5,5]$，两段各取单元素，答案为 $1$（长度 1 的子数组天然严格递增）；公式给出 $\min(\text{inc}[0], \text{nxt}[1]) = 1$，自动覆盖。
4. **单调递减 / 全相等数组**：所有游程长为 1，答案仍为 1，不会返回 0。
5. **全递增数组**：答案为 $\lfloor n/2 \rfloor$，在接缝居中处取到；注意 $n$ 为奇数时下取整（如 $n = 5$ 答案为 2）。
6. **下标方向别搞反**：$\text{inc}$ 用右端点、$\text{nxt}$ 用左端点，接缝枚举处是 $\min(\text{inc}[j], \text{nxt}[j+1])$——两个下标一个 $j$ 一个 $j+1$，方向相反，最易写错。
7. **二分写法**：若采用二分，判定直接复用 Q1 代码，范围 $[1, \lfloor n/2 \rfloor]$，依据是"若 $k$ 可行则 $k-1$ 必可行"的单调性。
8. **$O(1)$ 滚动写法**：断裂时先 $\text{prev} \gets \text{cur}$ 再置 $\text{cur} \gets 1$，且 $\min(\text{prev}, \text{cur})$ 要在**每一步**更新（段增长过程中接缝右侧可选长度在变大），只在断裂时更新会用已重置的 $\text{cur}$ 而漏解。

**延伸思考**：

- 推广到 **$m$ 段**相邻的长 $k$ 递增子数组（$m > 2$）：记 $L_i$ 为第 $i$ 个递增段长，答案变为 $\max\big(\max_i \lfloor L_i / m \rfloor,\ \min_{\text{连续 } m \text{ 段}} L\big)$，即"段内均分"或"跨相邻 $m$ 段取最短"取大，可用大小为 $m-1$ 的滑动窗口最小值做到 $O(n)$。
- 若两段**不必相邻**（任意两处各取一段）：答案由"最长段 $\lfloor L_1/2 \rfloor$"与"最长段与次长段之 $\min(L_1, L_2)$"取最大，一次扫描维护前二大段长即可。
