# LeetCode 移除十进制表示中的所有零 题解

## 1. 题目概述

- **标题 / 题号**：移除十进制表示中的所有零（#3726，easy）
- **链接**：https://leetcode.cn/problems/remove-zeros-in-decimal-representation/
- **来源**：LeetCode 第 473 场周赛 Q1
- **难度**：简单
- **标签**：数学、字符串、模拟

**题意**：给定正整数 $n$，把 $n$ 的十进制表示中所有的数字 $0$ 删除，返回剩余数字按原顺序组成的新整数。

**约束**：

- $1 \le n \le 10^{15}$

## 2. 示例

**示例 1**

```text
输入：n = 1020030
输出：123
解释：从 1020030 中移除所有的零后，得到 123。
```

**示例 2**

```text
输入：n = 1
输出：1
解释：1 的十进制表示中没有零，因此结果为 1。
```

**补充示例**

```text
输入：n = 1000000000000000（即 10^15）
输出：1
解释：最高位 1 后面跟 15 个零，全部删掉后只剩 1。
```

## 3. 解题思路

### 3.1 暴力思路

签到题，按题意直接模拟：把 $n$ 转成字符串，过滤掉所有 `'0'` 字符，再转回整数。这已经是最优做法（每个字符必须看一遍）。另一种等价写法是不碰字符串，纯数学地逐位累加。

### 3.2 核心观察：删零 = 保序过滤

![删零即保序过滤](images/remove_zeros_concept.svg)

两个关键观察：

1. **保序**：删除操作不改变剩余数字的相对顺序，"1020030" 删零后剩下的一定是 "123"，不存在其他排列。
2. **非空**：$n \ge 1$ 保证最高位数字非零，因此过滤后**至少保留一位数字**，结果必定是正整数——不需要处理"删成空串"或"结果为 0"的边界。

> 💡 这两条观察把问题化归为最朴素的"序列保序过滤"，也就是数组题里最常见的双指针/`filter` 模板的数字版。

### 3.3 两种实现

**字符串法**：`to_string(n)` → 跳过 `'0'` → `stoll`。

**数学法**：从高位到低位扫描，维护 `res`，遇到非零位 $d$ 就执行 `res = res × 10 + d`：

```text
res = 0
for d in n 的十进制表示（从高位到低位）:
    if d != 0:
        res = res * 10 + d
返回 res
```

> ⚠️ 若用 `n % 10; n /= 10` 从低位往高位取数，`res = res × 10 + d` 会得到**逆序**结果，还需再翻转一次；不如直接从字符串高位往低位扫省事。

### 3.4 示例演算

![示例演算：1020030 逐位累加](images/remove_zeros_example.svg)

$n = 1020030$，从高位到低位逐位累加：

| 当前位 $d$ | 操作 | res |
|-----------|------|-----|
| 1 | 保留：res = 0×10 + 1 | 1 |
| 0 | 跳过 | 1 |
| 2 | 保留：res = 1×10 + 2 | 12 |
| 0 | 跳过 | 12 |
| 0 | 跳过 | 12 |
| 3 | 保留：res = 12×10 + 3 | 123 |
| 0 | 跳过 | 123 |

最终 res = **123** ✓

## 4. 算法细节

1. **扫描顺序**：从高位到低位。字符串天然从高位开始；取模除法天然从低位开始，用后者需要二次翻转，不推荐。
2. **累加公式**：仅当 $d \ne 0$ 时执行 `res = res × 10 + d`，语义上等价于"把非零数字依次追加到结果末尾"。
3. **数据范围**：$n \le 10^{15} < 2^{63} - 1 \approx 9.2 \times 10^{18}$，C++ 用 `long long` 即可；结果与中间量都 $\le n$，无溢出风险。
4. **非空保证**：最高位 $\in [1, 9]$，故 `stoll` 的输入串非空，不会抛异常。

## 5. 正确性证明

**引理 1（唯一性）**：正整数 $n$ 的十进制表示唯一；对其做"删除所有 0"的保序过滤后，所得数字序列唯一。

**证明**：正整数十进制表示的唯一性是标准结论。过滤操作逐位判断"$d \ne 0$ 则保留"，输出序列由输入序列唯一确定。∎

**引理 2（非空性）**：过滤后至少保留一个数字，结果为正整数。

**证明**：$n \ge 1$，设其位数为 $k$，则最高位 $d_{k-1} \in \{1, \dots, 9\}$ 非零，必被保留，故结果非空且首位非零。∎

**定理**：上述算法返回 $n$ 删除所有零后的十进制表示所对应的整数。

**证明**：对已扫描的位数 $i$ 归纳：扫描完前 $i$ 位后，`res` 恰为前 $i$ 位中非零数字按原顺序拼接成的整数（空拼接约定为 0）。奠基 $i = 0$ 时 `res = 0` 成立。归纳步骤：设第 $i$ 位为 $d$。若 $d = 0$，非零数字序列不变，`res` 不变；若 $d \ne 0$，`res` 更新为 $\text{res} \times 10 + d$，恰为把 $d$ 追加到序列末尾后的整数值。扫描完全部 $k$ 位后，`res` 即"删零后"的数字序列对应的整数；由引理 1 该序列唯一，由引理 2 其为正整数，算法返回值合法且正确。∎

## 6. 复杂度分析

- **时间复杂度**：$O(d)$，其中 $d$ 为 $n$ 的位数，$d = \lfloor \log_{10} n \rfloor + 1 \le 16$，每个字符恰好处理一次。
- **空间复杂度**：字符串法 $O(d)$（存临时字符串）；纯数学法 $O(1)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long removeZeros(long long n) {
        long long res = 0;
        for (char c : to_string(n)) {
            if (c != '0') {
                res = res * 10 + (c - '0');
            }
        }
        return res;
    }
};
```

### Python

```python
class Solution:
    def removeZeros(self, n: int) -> int:
        return int(''.join(c for c in str(n) if c != '0'))
```

## 8. 边界情况与易错点

1. **无零**：$n = 1$ 或 $n = 12345$，结果即 $n$ 本身。
2. **只有最高位非零**：$n = 10^{15}$，结果为 1，验证"非空保证"。
3. **溢出**：$n \le 10^{15}$，C++ 必须用 `long long`（`int` 上限约 $2.1 \times 10^9$，直接溢出）；题目接口本身就是 `long long`。
4. **逆序陷阱**：用 `n % 10` 从低位取数直接 `res = res * 10 + d` 会得到反向数字（如 1020030 → 321），需二次翻转。
5. **无需特判空结果**：$n \ge 1$ 保证结果非空（见引理 2），不存在 `stoll("")` 或返回 0 的输入。
