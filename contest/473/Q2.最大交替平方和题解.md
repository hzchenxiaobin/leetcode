# LeetCode 最大交替平方和 题解

## 1. 题目概述

- **标题 / 题号**：最大交替平方和（#3727，medium）
- **链接**：https://leetcode.cn/problems/maximum-alternating-sum-of-squares/
- **来源**：LeetCode 第 473 场周赛 Q2
- **难度**：中等
- **标签**：贪心、数组、排序

**题意**：给定整数数组 `nums`，允许以任意顺序重排所有元素。定义重排后数组 `arr` 的**交替得分**为 $\text{score} = arr[0]^2 - arr[1]^2 + arr[2]^2 - arr[3]^2 + \cdots$（偶数下标取正号、奇数下标取负号）。求重排后能得到的**最大**交替得分。

**约束**：

- $1 \le \text{nums.length} \le 10^5$
- $-4 \times 10^4 \le \text{nums}[i] \le 4 \times 10^4$

## 2. 示例

**示例 1**

```text
输入：nums = [1, 2, 3]
输出：12
解释：重排为 [2, 1, 3]，score = 2² − 1² + 3² = 4 − 1 + 9 = 12。
```

**示例 2**

```text
输入：nums = [1, -1, 2, -2, 3, -3]
输出：16
解释：重排为 [-3, -1, -2, 1, 3, 2]，
score = (−3)² − (−1)² + (−2)² − 1² + 3² − 2² = 9 − 1 + 4 − 1 + 9 − 4 = 16。
```

**补充示例**

```text
输入：nums = [-3, -2]
输出：5
解释：重排为 [-3, -2]，score = 9 − 4 = 5。
若误按"数值大小"排序放成 [-2, -3]，只得 4 − 9 = −5 —— 负数场景必须按平方（绝对值）排序。
```

## 3. 解题思路

### 3.1 暴力思路

枚举全部 $n!$ 个排列、逐个 $O(n)$ 求得分，总代价 $O(n \cdot n!)$，只对 $n \lesssim 10$ 的玩具规模可行；$n$ 上限 $10^5$，必须找多项式算法。暴力的价值在于提示出关键结构：**得分由"元素落在奇/偶下标"决定，与同组内的顺序无关**（见 3.2 观察 2），这把"选排列"压缩成了"选划分"。

### 3.2 核心观察：符号只挂在"位置组"上

![位置符号模型](images/maxalt2_sign_model.svg)

三个观察把问题化简到只剩一步贪心：

1. **平方消灭符号**：每个元素都以 $x^2$ 出现在得分里，$(-3)^2 = 3^2 = 9$，元素本身的正负完全不影响贡献，**只有绝对值（平方）重要**。记 $b_i = x_i^2 \ge 0$，问题变成关于非负数组 $b$ 的纯组合问题。
2. **得分只依赖划分**：偶数下标 $0, 2, 4, \dots$ 共 $\lceil n/2 \rceil$ 个，奇数下标共 $\lfloor n/2 \rfloor$ 个。一旦确定哪些元素进偶数位（＋组）、哪些进奇数位（－组），**组内怎么摆得分都一样**；反之任何大小合法的划分都能摆出对应重排。
3. **化为选择问题**：最大化得分 $\iff$ 从 $n$ 个非负数中选 $p = \lceil n/2 \rceil$ 个进＋组，最大化（＋组和）$-$（－组和）。

> 💡 一句话结论：**排序，前 $\lceil n/2 \rceil$ 大的平方进正号位**。直觉是正号位多留给"大块头"、负号位塞给"小个子"；$n$ 为奇数时正号位恰好多一个（下标从 0 开始）。

### 3.3 算法流程：按平方降序，前 p 大进 ＋ 组

![算法流程](images/maxalt2_algorithm_flow.svg)

```text
p = ⌈n/2⌉
1. b[i] = nums[i]²            # 符号消失
2. 将 b 降序排序
3. ＋组 = b 的前 p 个；－组 = 其余 n−p 个
4. ans = (b[0] + … + b[p−1]) − (b[p] + … + b[n−1])
```

正确性由**交换论证**保证（完整证明见 §5）：若＋组中混进某个较小值 $b$，而更大的值 $a$ 留在－组，交换二者，得分变化 $2(a - b) \ge 0$，只会不变或更优。反复交换到无法改进时，＋组恰为平方最大的 $p$ 个。

### 3.4 示例演算

![示例演算](images/maxalt2_example_walkthrough.svg)

以示例 2 演算：$nums = [1, -1, 2, -2, 3, -3]$，$n = 6$，$p = \lceil 6/2 \rceil = 3$。

| 步骤 | 结果 |
|------|------|
| 平方 | $1, 1, 4, 4, 9, 9$ |
| 降序排序 | $9, 9, 4, 4, 1, 1$ |
| ＋组（前 3 个） | $9 + 9 + 4 = 22$ |
| －组（其余 3 个） | $4 + 1 + 1 = 6$ |
| 答案 | $22 - 6 = 16$ ✓ |

一种取得 16 的具体重排：$[3, 1, -3, -1, 2, -2]$，展开 $9 - 1 + 9 - 1 + 4 - 4 = 16$。

## 4. 算法细节

1. **排序键**：对 $x^2$（或 $|x|$）降序排序，**不要**对原值排序——负数会打乱次序（见补充示例）。
2. **组大小**：$p = \lceil n/2 \rceil = (n + 1) / 2$（整数除法向下取整自动实现）；$n$ 为奇数时＋组多 1 个，偶数时两组各半。
3. **无需构造排列**：题目只要得分，算两组和之差即可返回，不必真的摆出 `arr`。
4. **溢出**：$|x| \le 4 \times 10^4 \Rightarrow x^2 \le 1.6 \times 10^9$ 已超 32 位 `int`；总和上界 $10^5 \times 1.6 \times 10^9 = 1.6 \times 10^{14}$，C++ 的中间量与返回值都必须 `long long`，也不能在原 `int` 数组上原地平方。Python 原生大整数无此问题。
5. **可选优化**：只需"前 $p$ 大之和"与"其余之和"，用 `nth_element`（C++）或快速选择可做到平均 $O(n)$，免整趟排序。

## 5. 正确性证明

**引理 1（得分只依赖划分，且划分均可实现）**：设 $n$ 为数组长度。对任一重排 $arr$，记 $P$ 为落在偶数下标的元素集合、$M$ 为落在奇数下标的元素集合，则 $|P| = \lceil n/2 \rceil$、$|M| = \lfloor n/2 \rfloor$，且 $\text{score} = \sum_{x \in P} x^2 - \sum_{x \in M} x^2$。反之，对任意满足 $|P| = \lceil n/2 \rceil$、$|M| = \lfloor n/2 \rfloor$、$P \cup M = \text{nums}$ 且 $P \cap M = \varnothing$ 的划分，存在重排使其偶/奇下标元素集合恰为 $P / M$。

**证明**：偶数下标 $\{0, 2, \dots\}$ 在 $\{0, \dots, n-1\}$ 中恰有 $\lceil n/2 \rceil$ 个、奇数下标恰有 $\lfloor n/2 \rfloor$ 个，是计数事实。得分表达式中每一项只含该位置元素的平方与位置奇偶性，与同奇偶组内的相对顺序无关，故得分只由 $(P, M)$ 决定。反之，把 $P$ 中元素按任意顺序填入偶数下标、$M$ 中元素填入奇数下标，即得实现该划分的合法重排。∎

**引理 2（交换论证）**：设 $b_1 \ge b_2 \ge \cdots \ge b_n \ge 0$，$p = \lceil n/2 \rceil$。对大小为 $p$ 的下标集合 $S \subseteq \{1, \dots, n\}$，定义 $f(S) = \sum_{i \in S} b_i - \sum_{i \notin S} b_i$，则 $f$ 在 $S^\ast = \{1, 2, \dots, p\}$ 处取得最大值。

**证明**：$f(S) = 2\sum_{i \in S} b_i - \sum_{i=1}^{n} b_i$，第二项与 $S$ 无关，故最大化 $f$ 等价于最大化 $g(S) = \sum_{i \in S} b_i$。若存在 $i \in S$、$j \notin S$ 且 $i > j$（从而 $b_j \ge b_i$），令 $S' = S \setminus \{i\} \cup \{j\}$，则 $g(S') - g(S) = b_j - b_i \ge 0$。每次这样的交换严格减少"在 $S$ 内的下标大于在 $S$ 外的下标"的数对个数，故有限步后终止于不存在此类数对的状态；又 $|S| = p$ 固定，该状态只能是 $S^\ast = \{1, \dots, p\}$。因此对一切大小为 $p$ 的 $S$ 有 $g(S) \le g(S^\ast)$。∎

**定理**：将 `nums` 全体元素平方后降序排列为 $b_1 \ge \cdots \ge b_n$，则最大交替得分等于 $\sum_{i=1}^{p} b_i - \sum_{i=p+1}^{n} b_i$，其中 $p = \lceil n/2 \rceil$。

**证明**：由引理 1，最大化得分等价于在全体合法划分上最大化 $\sum_{x \in P} x^2 - \sum_{x \in M} x^2$（$|P| = p$）；将各元素平方取非增排列后，这正是引理 2 中的 $f(S)$。由引理 2，最优划分取平方最大的 $p$ 个元素进 $P$；再由引理 1 的可实现性，存在具体重排取到该值，且任何重排都不超过它。∎

> 💡 引理 2 是经典**排序不等式（重排不等式）**在"系数为 $\pm 1$"情形的特例：把元素平方与系数序列 $(\underbrace{+1,\dots,+1}_{p},\underbrace{-1,\dots,-1}_{n-p})$ 同序配对，乘积和（即得分）最大。

## 6. 复杂度分析

- **时间复杂度**：$O(n \log n)$，瓶颈是排序；划分与求和均为线性扫描。改用 `nth_element` / 快速选择可降到平均 $O(n)$。
- **空间复杂度**：$O(n)$，存平方数组（C++ 因 `int` 平方会溢出，需要 `long long` 数组，不能原地）；若按 $|x|$ 排序、只在求和时平方，C++ 可做到 $O(1)$ 额外空间（求和变量用 `long long`）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long maxAlternatingSum(vector<int>& nums) {
        int n = nums.size();
        vector<long long> b(n);
        for (int i = 0; i < n; i++) {
            b[i] = 1LL * nums[i] * nums[i];
        }
        sort(b.begin(), b.end(), greater<long long>());
        int p = (n + 1) / 2;
        long long pos = 0, neg = 0;
        for (int i = 0; i < p; i++) pos += b[i];
        for (int i = p; i < n; i++) neg += b[i];
        return pos - neg;
    }
};
```

### Python

```python
class Solution:
    def maxAlternatingSum(self, nums: List[int]) -> int:
        b = sorted((x * x for x in nums), reverse=True)
        p = (len(b) + 1) // 2
        return sum(b[:p]) - sum(b[p:])
```

## 8. 边界情况与易错点

1. **n = 1**：唯一元素必在 0 号位，答案即 $x^2$；公式中 $p = 1$、负号为空和 0，自然成立，无需特判。
2. **按原值排序**：负数场景会错（$[-3, -2]$ 按原值降序放成 $[-2, -3]$ 得 $-5$，正确为 $5$）。必须按平方或绝对值排序。
3. **溢出**：单个平方 $1.6 \times 10^9$ 超 `int`，总和上界 $1.6 \times 10^{14}$；C++ 的平方数组、累加变量、返回值都必须 `long long`，不要在原 `int` 数组上原地平方。
4. **p 的奇偶处理**：$p = \lceil n/2 \rceil$ 用 `(n + 1) / 2` 计算；$n$ 为奇数时＋组多一个元素（下标从 0 开始，首项必为正）。
5. **答案非负**：排序后前 $p$ 项和 $\ge$ 后 $n - p$ 项和（逐项比较 $b_i \ge b_{i+p}$），故答案恒 $\ge 0$；全相同元素时为 0（如 $[5, 5, 5, 5]$ 得 0），这不是异常。
6. **正负对称**：$x$ 与 $-x$ 平方相同，谁进＋组无所谓，无需去重或特判。
7. **无需构造排列**：题目只要最大得分，直接返回两组和之差即可。
