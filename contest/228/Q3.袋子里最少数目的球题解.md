# LeetCode 袋子里最少数目的球 题解

## 1. 题目概述

- **标题 / 题号**：袋子里最少数目的球（#1760，medium）
- **链接**：https://leetcode.cn/problems/minimum-limit-of-balls-in-a-bag/
- **来源**：LeetCode 第 228 场周赛 Q3
- **难度**：中等
- **标签**：数组、二分查找、二分答案

**题意**：给定整数数组 `nums`，`nums[i]` 表示第 $i$ 个袋子里球的数目。一次操作可以任选一个袋子，把袋里的球分成 **2 个新袋子**，每个袋子里都有**正整数**个球（如 5 个球可分成 1+4 或 2+3）。至多操作 `maxOperations` 次，最小化「单个袋子里球数目的**最大值**」，返回这个最小开销。

**约束**：

- $1 \le \text{nums.length} \le 10^5$
- $1 \le \text{maxOperations},\ \text{nums}[i] \le 10^9$

> 💡 **比赛快速切入（Q3 三分钟路线）**：① 「**最小化最大值**」+ 单个候选值能 $O(n)$ 验证 ⇒ 想**二分答案**；② 单袋 $n$ 个球压到每袋 $\le x$，恰需 $\lceil n/x \rceil - 1 = \lfloor (n-1)/x \rfloor$ 次操作；③ 总操作数 $\text{ops}(x) = \sum_i \lfloor (\text{nums}[i]-1)/x \rfloor$ 关于 $x$ **单调不增** ⇒ 在 $[1, \max(\text{nums})]$ 上二分找最小可行 $x$。全程盯紧 `long long`。

## 2. 示例

**示例 1**

```text
输入：nums = [9], maxOperations = 2
输出：3
解释：
- [9] -> [6,3]（第 1 次操作）
- [6,3] -> [3,3,3]（第 2 次操作）
最大值 3。若想压到 2，需把 9 拆成 5 份，要 4 次操作 > 2，不可行。
```

**示例 2**

```text
输入：nums = [2,4,8,2], maxOperations = 4
输出：2
解释：
- [2,4,8,2] -> [2,4,4,4,2]（拆 8）
- -> [2,2,2,4,4,2]（拆一个 4）
- -> [2,2,2,2,2,4,2]（再拆一个 4）
- -> [2,2,2,2,2,2,2,2]（拆最后一个 4）
共 4 次操作，最大值 2。
```

**示例 3**

```text
输入：nums = [7,17], maxOperations = 2
输出：7
解释：17 -> [14,3] -> [7,7,3]，2 次操作后全部 ≤ 7，7 球的袋子不动；
若目标为 6：17 需拆成 3 份（2 次）、7 需拆成 2 份（1 次），共 3 次 > 2，不可行。
```

## 3. 解题思路

### 3.1 暴力思路：模拟操作 + 贪心陷阱

最直觉的做法是**模拟每一次操作**：用优先队列维护当前最大袋子，每次取出「对半拆」。这条路有两个坑：

1. **复杂度爆炸**：总操作数最坏可达 $\sum_i (\text{nums}[i]-1) \approx 10^5 \times 10^9 = 10^{14}$ 次，逐次模拟完全不可行（$\text{maxOperations}$ 本身也可达 $10^9$）。
2. **贪心不最优（更致命）**：取 `nums = [9]`、`maxOperations = 2`。对半贪心：$9 \to 4+5 \to 2+3+4$，开销 $4$；而最优解 $9 \to 6+3 \to 3+3+3$，开销 $3$。**局部把最大袋折半无法预知后续配额**——怎么分袋子取决于目标值 $x$，而 $x$ 正是要求的量。

另一条朴素路是**逐值枚举答案** $x = 1, 2, \dots$，对每个 $x$ 检查「能否在预算内让所有袋子 $\le x$」。单次验证 $O(n)$ 没问题，但 $x$ 的范围是 $[1, \max(\text{nums})] \subseteq [1, 10^9]$，逐个试必然超时。

> ⚠️ 症结：我们把「怎么拆」当成了优化对象。正确的转身是：**先固定开销上限 $x$，问「可行与否」**——可行性恰是关于 $x$ 单调的，这正是二分答案的入场券。

### 3.2 核心观察：二分答案

![核心观察：单袋分拆公式 ⌊(n−1)/x⌋ 与 ops(x) 的单调性](images/wc228_q3_monotone_concept.svg)

**观察 1（单袋分拆公式）**：把一个装 $n$ 个球的袋子拆到每份 $\le x$，最少需要

$$\left\lceil \frac{n}{x} \right\rceil - 1 \;=\; \left\lfloor \frac{n-1}{x} \right\rfloor$$

次操作。两个关键视角：

- **计数视角**：每次操作把 1 个袋子变成 2 个，**袋子总数 +1**——拆成 $k$ 份恰用 $k-1$ 次，操作次数只由「最终份数」决定，与拆分顺序、比例无关。
- **鸽笼下界**：$k$ 份每份 $\le x$ 至多装 $kx$ 个球，故 $k \ge \lceil n/x \rceil$。
- **剥离构造**：只要剩余 $> x$ 就剥出一袋 $x$，余数（若非 0）单独一份，份数恰为 $\lceil n/x \rceil$，下界可以取到。

**观察 2（单调性 ⇒ 二段性）**：各袋子互相独立，总操作数为

$$\text{ops}(x) = \sum_{i} \left\lfloor \frac{\text{nums}[i]-1}{x} \right\rfloor$$

$x$ 增大时每一项只减不增，故 $\text{ops}(x)$ **单调不增**。于是可行集 $\{x : \text{ops}(x) \le \text{maxOperations}\}$ 是一个**上闭区间** $[x^*, +\infty)$：$x < x^*$ 时操作不够，$x \ge x^*$ 时可行。「求最小可行 $x$」就是在有序区间 $[1, \max(\text{nums})]$ 上二分定位 $x^*$。

> 💡 **识别信号**：题目求「**最小化最大值**」，且能 $O(n)$ 验证候选值合法性 ⇒ 二分答案。这与「在有序数组里二分下标」是另一类二分——**二分的是答案本身**。与 [1011. 在 D 天内送达包裹的能力](https://leetcode.cn/problems/capacity-to-ship-packages-within-d-days/) 是同一套模板，只是 `check()` 从「贪心装船」换成「逐袋求分拆次数求和」。
>
> ⚠️ **上下界**：下界取 $1$ 而非 $0$（每袋必须正整数个球）；上界取 $\max(\text{nums})$ 即可——不操作就已是可行解，取更松的上界只多几次无效二分。

### 3.3 算法流程：闭区间二分

![算法流程：闭区间二分 [lo, hi]，每轮 O(n) 验证 mid](images/wc228_q3_binary_search_flow.svg)

1. **初始化**：`lo = 1`，`hi = max(nums)`，`ans = hi`（不操作必可行）。
2. **循环** `lo <= hi`：取 `mid = lo + (hi - lo) / 2`。
3. **验证** `mid`：累加 `ops = Σ (nums[i] - 1) / mid`（整数除法），一旦超过 `maxOperations` 提前剪枝。
4. **判定**：若 `ops <= maxOperations`，`mid` 可行——**先记 `ans = mid` 再收缩右界** `hi = mid - 1`；否则 `lo = mid + 1` 放宽限制。
5. 区间为空时返回 `ans`。

> 💡 二分 $O(\log M)$ 轮（$M = \max(\text{nums}) \le 10^9$，约 30 轮），每轮验证 $O(n)$，总共约 $3 \times 10^6$ 次整数运算——比模拟路线的 $10^{14}$ 次操作小了七个数量级。

### 3.4 示例演算

![示例演算：nums = [2,4,8,2] 的三轮二分过程](images/wc228_q3_walkthrough.svg)

以 `nums = [2,4,8,2]`、`maxOperations = 4` 为例，$\max(\text{nums}) = 8$，答案区间 $[1, 8]$：

| 轮次 | $[\text{lo}, \text{hi}]$ | mid | $\text{ops}(\text{mid}) = \sum \lfloor (n_i-1)/\text{mid} \rfloor$ | 判定与动作 |
|------|--------------------------|-----|----------------------------------------------------------------|------------|
| 1 | $[1, 8]$ | 4 | $0+0+1+0 = 1 \le 4$ | ✓ ans=4, hi=3 |
| 2 | $[1, 3]$ | 2 | $0+1+3+0 = 4 \le 4$ | ✓ ans=2, hi=1 |
| 3 | $[1, 1]$ | 1 | $1+3+7+1 = 12 > 4$ | ✗ lo=2 |
| 结束 | lo > hi | — | — | 返回 ans=2 |

关键看第 2 轮 `mid=2`：袋子 `[2,4,8,2]` 分别需要 $0, 1, 3, 0$ 次操作（8 个球拆成 `[2,2,2,2]` 需 3 次），总计 $4 \le 4$ **压线可行**；而 `mid=1` 时需 $12 > 4$。故最小开销为 $2$，3 轮二分恰为 $\log_2 8$ 的理论值。

## 4. 算法细节

1. **上取整恒等式**：对正整数 $n, x$ 有 $\lceil n/x \rceil = \lfloor (n-1)/x \rfloor + 1$（证明见 §5 引理 2 的推论），因此 $\lceil n/x \rceil - 1$ 直接写成整数除法 `(n - 1) / x`，无需浮点或条件分支。
2. **袋间独立性**：操作只作用于单个袋子，各袋互不影响；操作次序也无关紧要——只需统计「每个初始袋子共被拆几次」。这是 $\text{ops}(x)$ 能写成逐袋求和的根基。
3. **溢出**：单项 $\lfloor (n_i-1)/x \rfloor$ 可达 $10^9 - 1$，$10^5$ 个袋子求和最坏 $\approx 10^{14}$，**超出 32 位 `int` 上界**。C++ 中 `ops` 必须 `long long`；配合「`ops > maxOperations` 立即返回 false」的剪枝，既防溢出又提速。
4. **二分模板**：闭区间 `[lo, hi]` + `ans` 记录：可行时 `ans = mid; hi = mid - 1`，不可行时 `lo = mid + 1`，不会死循环；`mid = lo + (hi - lo) / 2` 是防溢出的习惯写法（本题 `hi ≤ 10^9` 其实安全）。
5. **上界即初始答案**：`ans` 初始化为 `max(nums)`——它本身可行（`ops = 0`），即使二分循环一次都不执行也能正确返回。
6. **无需排序**：`check` 只遍历求和，与顺序无关；`max_element` 求上界即可。

## 5. 正确性证明

**引理 1（操作计数）**：一次操作使袋子总数 $+1$。把某个初始袋子（含其所有后代袋）拆成 $k$ 份，恰需 $k-1$ 次作用于它的操作。

**证明**：每次操作把一个袋子一分为二，袋子总数 $+1$；每个袋子恰有一个「初始袋子」祖先，故对某个初始袋子 $b$，一次操作是否增加 $b$ 的份数，取决于被拆的是否为 $b$ 的后代。设 $t$ 次操作作用于 $b$ 的后代，则 $b$ 的份数从 $1$ 变为 $t+1$（归纳：每拆一次份数 $+1$）。份数为 $k$ 当且仅当 $t = k-1$。∎

**引理 2（单袋最小操作数）**：对正整数 $n, x$（$x \ge 1$），使袋子最终每份都是 $\le x$ 的正整数的最少操作数为 $\lceil n/x \rceil - 1 = \lfloor (n-1)/x \rfloor$。

**证明**：**下界**：设最终 $k$ 份、每份 $\le x$，则 $n \le kx$，故 $k \ge n/x$；$k$ 为整数故 $k \ge \lceil n/x \rceil$，由引理 1 操作数 $= k - 1 \ge \lceil n/x \rceil - 1$。**上界**：取 $k_0 = \lceil n/x \rceil$，构造分法「尽量装满」：只要剩余 $> x$ 就剥出一袋 $x$。设剥出 $a = \lfloor n/x \rfloor$ 袋后余 $r = n - ax \in [1, x]$（若 $r = 0$ 则 $n = ax$ 恰 $a$ 份，且 $a = \lceil n/x \rceil$）；否则 $r$ 单独成第 $a+1$ 份，且 $a + 1 = \lfloor n/x \rfloor + 1 = \lceil n/x \rceil = k_0$。每份为正整数且 $\le x$。由引理 1 用 $k_0 - 1$ 次操作可实现。
**推论（恒等式）**：写 $n - 1 = qx + s$（$0 \le s < x$），则 $n = qx + (s+1)$ 且 $1 \le s + 1 \le x$，故 $\lceil n/x \rceil = q + 1 = \lfloor (n-1)/x \rfloor + 1$，移项即得。∎

**引理 3（可行性刻画）**：存在至多 `maxOperations` 次操作的方案使所有袋子球数 $\le x$ $\iff$ $\sum_i \lfloor (\text{nums}[i]-1)/x \rfloor \le \text{maxOperations}$。

**证明**：（⇐）对每个袋子独立执行引理 2 的剥离构造，最终每份 $\le x$，总操作数恰为该和式，不超过预算。（⇒）任一合法方案中，把操作按「所作用的初始袋子」分组：第 $i$ 个袋子被操作 $t_i$ 次、最终分成 $t_i + 1$ 份（引理 1）且每份 $\le x$，由引理 2 下界部分 $t_i \ge \lceil n_i/x \rceil - 1 = \lfloor (n_i - 1)/x \rfloor$。求和：$\text{maxOperations} \ge \sum t_i \ge \sum_i \lfloor (n_i-1)/x \rfloor$。∎

**引理 4（单调性）**：$x_1 < x_2 \Rightarrow \text{ops}(x_2) \le \text{ops}(x_1)$。

**证明**：对每个 $i$，$x_2 > x_1 > 0$ 时 $\lfloor (n_i - 1)/x_2 \rfloor \le \lfloor (n_i - 1)/x_1 \rfloor$（正数除法商随分母增大不增，下取整保序）；逐项求和保持。∎

**定理**：算法返回最小开销 $\min\{x \ge 1 : \text{ops}(x) \le \text{maxOperations}\}$。

**证明**：由引理 4，可行集 $F = \{x \in [1, +\infty) : \text{ops}(x) \le \text{maxOperations}\}$ 若非空必为上闭区间；又 $x = \max(\text{nums}) \in F$（$\text{ops} = 0$），故 $F$ 非空，记 $x^* = \min F$。由引理 3，开销 $\le x$ 可达 $\iff x \in F$，故最小开销即 $x^*$。二分不变量：**任意一轮开始时，$x^* \in [\text{lo}, \text{hi}]$ 或 $\text{ans} = x^*$**。初始时 $[\text{lo}, \text{hi}] = [1, \max] \ni x^*$ 成立。归纳：取 mid；若 mid $\in F$，则 mid $\ge x^*$——当 mid $= x^*$ 时执行 `ans = mid` 后 ans $= x^*$，当 mid $> x^*$ 时 $x^* \in [\text{lo}, \text{mid}-1]$ 为新区间；若 mid $\notin F$，由可行集是上闭区间知 mid $< x^*$，故 $x^* \in [\text{mid}+1, \text{hi}]$。不变量始终保持。终止时 lo > hi 区间为空，必有 $\text{ans} = x^*$；又 ans 的初值 $\max(\text{nums}) \in F$、每次赋值均赋可行值，故返回值 $\in F$ 且等于 $x^*$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \log M)$，$M = \max(\text{nums}) \le 10^9$。二分 $O(\log M) \approx 30$ 轮，每轮 `check` 遍历数组 $O(n)$；$n = 10^5$ 时总量约 $3 \times 10^6$，配合提前剪枝实际更快。
- **空间复杂度**：$O(1)$。仅 `lo/hi/mid/ans/ops` 等常数个变量，无需排序或额外数据结构。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int minimumSize(vector<int>& nums, int maxOperations) {
        int lo = 1;
        int hi = *max_element(nums.begin(), nums.end());
        int ans = hi;                     // 不操作必可行

        while (lo <= hi) {
            int mid = lo + (hi - lo) / 2;
            if (canAchieve(nums, mid, maxOperations)) {
                ans = mid;                // 可行，尝试更小的限制
                hi = mid - 1;
            } else {
                lo = mid + 1;             // 操作不够，放宽限制
            }
        }
        return ans;
    }

  private:
    // 验证：限制为 limit 时，所需操作数是否 <= maxOps
    bool canAchieve(const vector<int>& nums, int limit, int maxOps) {
        long long ops = 0;                // 总和可达 ~1e14，必须 long long
        for (int n : nums) {
            ops += (n - 1) / limit;       // ⌈n/limit⌉ - 1 = ⌊(n-1)/limit⌋
            if (ops > maxOps) return false;  // 提前剪枝
        }
        return true;
    }
};
```

### Python

```python
class Solution:
    def minimumSize(self, nums: List[int], maxOperations: int) -> int:
        lo, hi = 1, max(nums)
        ans = hi                          # 不操作必可行

        while lo <= hi:
            mid = (lo + hi) // 2
            if self._can_achieve(nums, mid, maxOperations):
                ans = mid                 # 可行，尝试更小的限制
                hi = mid - 1
            else:
                lo = mid + 1              # 操作不够，放宽限制
        return ans

    def _can_achieve(self, nums: List[int], limit: int, max_ops: int) -> bool:
        ops = 0
        for n in nums:
            ops += (n - 1) // limit       # ⌈n/limit⌉ - 1 = ⌊(n-1)/limit⌋
            if ops > max_ops:
                return False              # 提前剪枝
        return True
```

> ⚠️ **两个经典 WA 点**：① 溢出——C++ 中 `ops` 用 `int` 累加最坏 $10^{14}$ 直接爆；② 公式写反——是 $(n-1)/x$ 不是 $n/x$，反例 $n = 9, x = 3$：正确 $2$ 次，而 $9/3 = 3$ 错。

## 8. 边界情况与易错点

1. **溢出是头号 WA 点**：$\sum \lfloor (n_i-1)/x \rfloor$ 最坏 $\approx 10^{14} > 2^{31}-1$。C++ 必须 `long long`，或依赖「一超预算立即 break」的剪枝（两者都写最稳）。
2. **公式别写 $n/x$**：$n$ 整除 $x$ 时会多算一次。$n = 9, x = 3$：$(9-1)/3 = 2$ ✓，$9/3 = 3$ ✗。
3. **`lo` 从 1 开始而非 0**：每袋必须正整数个球，$x = 0$ 无意义且会导致除零。
4. **`maxOperations` 极大**：当 $\sum (\text{nums}[i]-1) \le \text{maxOperations}$ 时答案为 $1$（全部拆成每袋 1 球），二分自然覆盖，无需特判。
5. **全 1 数组**：`hi = 1`，首轮 `ops(1) = 0 ≤ maxOps`，返回 1，无坑。
6. **「至多」而非「恰好」**：操作不必用完。若误读成必须恰好用完，会在所有袋子都是 1 时陷入「1 无法拆成两个正整数」的死胡同。
7. **贪心对半拆不可行**：见 3.1 反例 `[9], 2`：贪心得 4，最优 3。比赛时若贪心写完 WA，应立刻转向二分答案而不是修补贪心。
8. **二分死循环**：闭区间模板必须 `hi = mid - 1` / `lo = mid + 1`（而非 `hi = mid`），保证区间每轮严格缩小。

**延伸思考**：

1. **「恰好用完」变体**：若要求**恰好**用满 `maxOperations` 次操作，可行性如何刻画？提示：把一袋 $a + b$（$a, b \ge 1$）拆成两袋不改变最大值的合法性，故多余操作总能「烧」在任意一个 $\ge 2$ 球的袋子上；结论：可行 $\iff \text{ops}(x) \le \text{maxOperations} \le \sum_i (\text{nums}[i] - 1)$，仍可二分。
2. **一次拆成至多 $k$ 份**：每次操作份数 $+(k-1)$ 而非 $+1$，单袋最少操作变为 $\left\lceil \dfrac{\lceil n/x \rceil - 1}{k - 1} \right\rceil$，逐袋求和后依然单调 ⇒ 二分骨架原封不动，只换公式。
3. **输出具体方案**：二分出 $x^*$ 后，对每个袋子执行引理 2 的剥离构造（依次剥出 $x^*$，余数收尾）即得一份具体拆法，额外 $O(\text{最终袋子数})$；体会「二分答案只定阈值、构造留到验证里」的分层思想。
