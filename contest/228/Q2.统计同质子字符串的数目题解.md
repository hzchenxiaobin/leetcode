# LeetCode 统计同质子字符串的数目 题解

## 1. 题目概述

- **标题 / 题号**：统计同质子字符串的数目（#1759，medium）
- **链接**：https://leetcode.cn/problems/count-number-of-homogenous-substrings/
- **来源**：LeetCode 第 228 场周赛 Q2
- **难度**：中等
- **标签**：字符串、数学、计数

**题意**：给定字符串 `s`，统计其中**同质子字符串**的数目。「同质」指子串内所有字符都相同；子串是**连续**字符序列。答案可能很大，只需返回对 $10^9 + 7$ 取模后的结果。

**约束**：

- $1 \le s.length \le 10^5$
- `s` 由小写英文字母组成

> 💡 **比赛快速切入（Q2 五分钟路线）**：① 同质 = 全同字符 ⇒ 子串**不能跨过字符变化的边界**，整串天然切成一段段「游程」；② 长 $k$ 的游程内，子串按右端点分类得 $1 + 2 + \dots + k = \frac{k(k+1)}{2}$ 个；③ 不必显式分段——维护「以当前位结尾的游程长度 `len`」，逐位 `ans += len` 一遍扫完。全程盯紧 `int` 溢出与取模。

## 2. 示例

**示例 1**

```text
输入：s = "abbcccaa"
输出：13
解释：同质子字符串如下所列：
"a"   出现 3 次    "b"   出现 2 次    "c"   出现 3 次
"aa"  出现 1 次    "bb"  出现 1 次    "cc"  出现 2 次
                                 "ccc" 出现 1 次
合计 3+1 + 2+1 + 3+2+1 = 13
```

**示例 2**

```text
输入：s = "xy"
输出：2
解释：两个游程长度均为 1，同质子串只有 "x" 与 "y"。
```

**示例 3**

```text
输入：s = "zzzzz"
输出：15
解释：单一游程 k = 5，长度 1 的 5 个、长度 2 的 4 个……贡献 5+4+3+2+1 = 15。
```

## 3. 解题思路

### 3.1 暴力思路：枚举全部子串逐个判定

两层循环枚举所有子串 $s[l..r]$，逐个检查内部字符是否全同。判定若朴素扫描是 $O(n)$，总计 $O(n^3)$；即便用「以 $l$ 为起点向右扩展、$s[r] \ne s[r-1]$ 立即停止」把判定摊成 $O(1)$，总体仍是 $O(n^2)$——$n = 10^5$ 时约 $5 \times 10^9$ 次操作，**超时**。症结：把每个子串当成独立个体去判定，完全没有利用「同质子串成簇聚在连续同字符段内」的结构。

### 3.2 核心观察：游程分解 + 按右端点等差计数

![核心观察：同质子串不能跨字符边界，长 k 的游程按右端点贡献 1+2+…+k = k(k+1)/2](images/wc228_q2_run_concept.svg)

**观察 1（不可跨越）**：同质子串的所有字符相同，因此它**绝不能跨过任何一条字符变化的边界**——一旦覆盖了 $s[j] \ne s[j+1]$ 的位置，就同时含两种字符，立刻非同质。于是可把 `s` 按「与前一位字符是否相同」切成若干**极长同字符段（游程，run）**，同质子串只在游程内部产生，**答案 = 各游程贡献之和**。

**观察 2（段内计数）**：考察长 $k$ 的游程（如 `"ccc"`，$k = 3$）。**以第 $i$ 位为右端点**的同质子串，左端点可取段内第 $1 \ldots i$ 个位置中的任意一个，恰有 $i$ 个。对 $i = 1 \ldots k$ 求和：

$$
1 + 2 + \dots + k = \frac{k(k+1)}{2}
$$

**合并**：设各游程长度为 $k_1, k_2, \dots, k_m$，则

$$
\text{ans} = \sum_{j=1}^{m} \frac{k_j (k_j + 1)}{2} \pmod{10^9 + 7}
$$

代入示例 1：$1 + 3 + 6 + 3 = 13$ ✓。

### 3.3 算法流程：增量扫描

![算法流程：维护 len 逐位累加，同字符接续 +1、换字符重置 1，每步取模](images/wc228_q2_incremental_flow.svg)

赛场上最稳的写法不显式切游程，而是**增量法**一遍扫完：维护 `len` = 以当前位结尾的同质子串个数（即当前游程已扫过的长度）。

1. **初始化**：`ans = 0`，`len = 0`。
2. **遍历**每个字符 `c = s[i]`：若 `i > 0` 且 `c == s[i-1]`，则 `len += 1`（接续游程）；否则 `len = 1`（换字符或首位，开启新游程）。
3. **累加**：`ans = (ans + len) % MOD`。
4. 扫描结束，返回 `ans`。

> 💡 **增量法与公式法为何等价？** 长 $k$ 的游程内 `len` 依次取 $1, 2, \dots, k$，逐位累加恰为 $\frac{k(k+1)}{2}$。「整段套公式」与「逐位加 `len`」只是求和顺序不同。增量法省去显式分段与段边界处理，代码更短、更不易错——把「段内求和」摊成「逐位增量」是常见的手感优化。

### 3.4 示例演算

![示例演算：abbcccaa 逐位追踪 len 与 ans，最终 ans = 13](images/wc228_q2_walkthrough.svg)

以 `s = "abbcccaa"`（$n = 8$）为例逐位追踪：

| $i$ | $s[i]$ | 与前一位 | `len` | `ans`（累加后） | 所属游程 |
|-----|--------|-----------|-------|----------------|---------|
| $0$ | `a` | —（起始） | 1 | 1 | `"a"`（k=1） |
| $1$ | `b` | 换 → 重置 | 1 | 2 | `"bb"`（k=2） |
| $2$ | `b` | 同 → +1 | 2 | 4 | |
| $3$ | `c` | 换 → 重置 | 1 | 5 | `"ccc"`（k=3） |
| $4$ | `c` | 同 → +1 | 2 | 7 | |
| $5$ | `c` | 同 → +1 | 3 | 10 | |
| $6$ | `a` | 换 → 重置 | 1 | 11 | `"aa"`（k=2） |
| $7$ | `a` | 同 → +1 | 2 | 13 | |

最终 `ans = 13` ✓。分游程核对：$1 + (1+2) + (1+2+3) + (1+2) = 1 + 3 + 6 + 3 = 13$，与公式法一致。

对照示例 3 `"zzzzz"`：`len` 走 $1,2,3,4,5$，累加 $1+2+3+4+5 = 15$ ✓。

## 4. 算法细节

1. **`len` 的双重语义**：既是「当前游程已扫长度」（实现视角），也是「以 $s[i]$ 结尾的同质子串个数」（计数视角，即 $f[i]$ = 以 $i$ 结尾的合法子串数）。后者把增量法升级为通用范式：按结尾位置定义计数、找递推、求和。
2. **首字符守护**：`i > 0` 才能比较 `s[i-1]`；也可用哨兵 `prev = '\0'`（小写字母之外的任意值）规避下标判断。
3. **取模与溢出**：$k$ 最大 $10^5$，单段贡献 $\frac{k(k+1)}{2} \approx 5 \times 10^9$，**已超 32 位 `int` 上界**（$\approx 2.1 \times 10^9$）。C++ 中 `ans` 必须用 `long long`；每步取模最稳（即使中途不取，总和 $\le \frac{n(n+1)}{2} \approx 5 \times 10^9$ 仍在 `long long` 安全范围内，最后取一次亦可，但每步取模是无脑安全的习惯）。Python 天然大整数，只在返回前取模即可。
4. **公式法对照写法**：也可显式数出游程长度再累加 $\frac{k(k+1)}{2}$——注意 `k * (k + 1)` 在 `int` 下溢出，必须先转 `long long` 再乘。
5. **无额外数据结构**：`len` 只依赖上一位置的值，滚动变量即可，$O(1)$ 空间；不需要 DP 数组或哈希表。

## 5. 正确性证明

**引理 1（游程刻画）**：子串 $s[l..r]$ 同质 $\iff$ $[l, r]$ 完整落在某个极长同字符段（游程）之内。

**证明**：（⇐）游程内字符全部相同，其任意子串自然同质。（⇒）反证：若 $[l, r]$ 未完整落在任一游程内，则存在边界位置 $j \in [l, r-1]$ 使 $s[j] \ne s[j+1]$，于是该子串同时含有 $s[j]$ 与 $s[j+1]$ 两种字符，非同质，矛盾。∎

**引理 2（段内计数）**：长 $k$ 的游程内，同质子串恰有 $\frac{k(k+1)}{2}$ 个。

**证明**：按**右端点**分类。以游程内第 $i$ 位（$1 \le i \le k$）为右端点时，左端点可取第 $1, \dots, i$ 个位置，得到长度 $1, \dots, i$ 的 $i$ 个互不相同且完全落在游程内的子串，由引理 1 的（⇐）方向知它们全部同质。每个子串由（左端点，右端点）二元组唯一决定，而右端点互不相同，故该分类**不重不漏**。总数 $= \sum_{i=1}^{k} i = \frac{k(k+1)}{2}$。∎

**定理**：$\text{ans} \equiv \sum_{j=1}^{m} \frac{k_j(k_j+1)}{2} \pmod{10^9+7}$，且增量法（维护 `len`、每步 `ans += len`）算得同一结果。

**证明**：由游程的极长性与互不重叠性，每个同质子串**完整落在唯一的游程内**，按所在游程分类是对全体同质子串的不重不漏划分；由引理 2，落在游程 $j$ 内的恰有 $\frac{k_j(k_j+1)}{2}$ 个，逐段求和即得公式。对增量法：在游程 $j$ 的第 $i$ 位处，归纳可证 `len` $= i$（第 1 位由「换字符或起始」分支置 1；归纳步由「同字符」分支加 1），故该游程对 `ans` 的累计增量 $= \sum_{i=1}^{k_j} i = \frac{k_j(k_j+1)}{2}$，与公式逐段相同；又取模保持同余，故两种写法返回值一致。∎

> 💡 **可迁移套路**：「**按右端点分类 + 不重不漏**」是子串计数的通用坐标系——本题的递推最简（同字符则 +1），进阶版如 [2262. 字符串的总引力](https://leetcode.cn/problems/total-appeal-of-a-string/)（转移要看字符上次出现位置）站在同一副骨架上。

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。单趟扫描，每个字符一次比较、一次加法、一次取模，均为 $O(1)$。
- **空间复杂度**：$O(1)$。仅 `ans`、`len` 两个滚动变量，不显式存储游程，也无 DP 数组。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int countHomogenous(string s) {
        const long long MOD = 1e9 + 7;
        long long ans = 0;
        int len = 0;
        for (int i = 0; i < (int)s.size(); ++i) {
            len = (i > 0 && s[i] == s[i - 1]) ? len + 1 : 1;
            ans = (ans + len) % MOD;
        }
        return (int)ans;
    }
};
```

### Python

```python
class Solution:
    def countHomogenous(self, s: str) -> int:
        MOD = 10 ** 9 + 7
        ans = 0
        run = 0
        for i, c in enumerate(s):
            run = run + 1 if i > 0 and c == s[i - 1] else 1
            ans = (ans + run) % MOD
        return ans
```

> ⚠️ **公式法别直接写 `int` 乘法**：`(long long)k * (k + 1) / 2` 才安全，`k * (k + 1)` 在 32 位下 $10^5 \times 10^5$ 直接溢出。增量法每步加的 `len ≤ 10^5`，只要 `ans` 是 `long long` 就无此坑——这也是比赛优先选增量写法的理由之一。

## 8. 边界情况与易错点

1. **溢出是头号 WA 点**：$n = 10^5$ 全同字符时单段贡献 $\approx 5 \times 10^9 > 2^{31} - 1$。C++ 中 `ans` 用 `int` 累加、或公式法 `k * (k + 1)` 用 `int` 相乘，都会溢出。
2. **换字符忘重置 / 重置成 0**：`len` 必须重置为 **1**（新游程第一位自身就是 1 个子串），置 0 会把每段开头全部漏计。
3. **首字符越界**：`i = 0` 时不存在 `s[i-1]`，`i > 0` 守护不可少；漏写时读 `s[-1]` 在 C++ 中是未定义行为。
4. **子串 ≠ 子序列**：同质要求**连续**。若误按子序列算，长 $k$ 段内是 $2^k$ 级别的计数，公式完全不同——读题时盯住「连续字符序列」。
5. **n = 1**：单字符即 1 个同质子串，算法自然给出 `len = 1, ans = 1`，无需特判。
6. **取模对象**：模的是**累加和**而非 `len`（`len ≤ 10^5` 远小于模数）；返回值保证已落在 $[0, 10^9+7)$ 内。
7. **公式法的整除**：$k(k+1)$ 必为偶数，`/ 2` 整除无损；但务必**先乘后除**且用 `long long`。

**延伸思考**：

1. **长度恰为 $L$ 的同质子串数**：长 $k$ 的游程贡献 $\max(0,\, k - L + 1)$——把「按长度求和」换成「按长度筛选」，依旧 $O(n)$，体会游程分解「换问法只改段内公式」的可迁移性。
2. **带权版本**（每个子串的权为其长度 $\ell$ 的平方）：游程内贡献 $\sum_{\ell=1}^{k} \ell^2 (k - \ell + 1)$，用 $\sum \ell^2$、$\sum \ell^3$ 的闭式可 $O(1)$ 求出，仍是「分段 + 段内公式」骨架。
3. **「几乎同质」变体**（允许至多一个位置字符不同）：类似 [424. 替换后的最长重复字符](https://leetcode.cn/problems/longest-repeating-character-replacement/) 的滑窗可求极大合法段，再按段套计数公式——分段思想从「严格游程」推广到「滑窗段」。
