# LeetCode 计算交替和 题解

## 1. 题目概述

- **标题 / 题号**：计算交替和（#3701，easy）
- **链接**：https://leetcode.cn/problems/compute-alternating-sum/
- **来源**：LeetCode 第 470 场周赛 Q1
- **难度**：简单
- **标签**：数组、模拟

**题意**：给定整数数组 `nums`，其**交替和**定义为：偶数下标位置的元素**相加**，再**减去**奇数下标位置的元素，即 $nums[0] - nums[1] + nums[2] - nums[3] + \cdots$。返回 `nums` 的交替和。

**约束**：

- `1 <= nums.length <= 100`
- `1 <= nums[i] <= 100`

## 2. 示例

**示例 1**

```text
输入：nums = [1,3,5,7]
输出：-4
解释：
  偶数下标元素：nums[0]=1, nums[2]=5
  奇数下标元素：nums[1]=3, nums[3]=7
  交替和 = 1 - 3 + 5 - 7 = -4
```

**示例 2**

```text
输入：nums = [100]
输出：100
解释：唯一的偶数下标元素是 nums[0]=100，没有奇数下标元素，
  交替和 = 100。
```

**示例 3**

```text
输入：nums = [5,1,5]
输出：9
解释：5 - 1 + 5 = 9。奇数长度时最后一个元素下标为偶数，取加号。
```

## 3. 解题思路

### 3.1 暴力思路

按定义从左到右扫描一遍：偶数下标累加、奇数下标累减。$n \le 100$，一次扫描 $O(n)$ 已是最优，签到题不需要任何优化。

### 3.2 核心观察：下标奇偶决定符号

![核心观察：下标奇偶决定符号](images/alt_sum_concept.svg)

交替和可以统一写成带符号求和：

$$\text{ans} = \sum_{i=0}^{n-1} sign(i) \cdot nums[i], \quad sign(i) = \begin{cases} +1, & i \text{ 为偶数} \\ -1, & i \text{ 为奇数} \end{cases}$$

- 符号只与**下标奇偶**有关，与元素值无关，用 `i % 2 == 0`（或位运算 `!(i & 1)`）判断。
- 不需要任何额外数据结构，一遍扫描、一个累加变量即可。

### 3.3 算法流程

```text
ans = 0
for i = 0 .. n-1:
    if i 是偶数: ans += nums[i]
    else:       ans -= nums[i]
返回 ans
```

等价写法是**符号翻转变量**：维护 `sign` 初值 $+1$，每步 `ans += sign * nums[i]` 后执行 `sign = -sign`，省去奇偶判断。

### 3.4 示例演算

对 `nums = [1,3,5,7]` 逐步累加：

| i | nums[i] | 符号 | 操作 | 累计 ans |
|---|---------|------|------|----------|
| 0 | 1 | $+$ | 0 + 1 | 1 |
| 1 | 3 | $-$ | 1 − 3 | −2 |
| 2 | 5 | $+$ | −2 + 5 | 3 |
| 3 | 7 | $-$ | 3 − 7 | −4 |

最终答案 $-4$，与示例 1 一致 ✓

![示例演算：逐步累加过程](images/alt_sum_walkthrough.svg)

## 4. 算法细节

1. **符号判断**：`i % 2 == 0` 取加号，否则取减号；位运算写法 `!(i & 1)` 等价且更快（本题无感知）。
2. **累加顺序无关**：加减满足交换律与结合律，任意顺序累加结果相同，但按下标从左到右最直观。
3. **Python 一行流**：`sum(x if i % 2 == 0 else -x for i, x in enumerate(nums))`，签到题可直接内联。
4. **结果范围**：$|ans| \le \sum nums[i] \le 100 \times 100 = 10^4$，`int` 完全够用。

## 5. 正确性证明

**引理 1**：$sign(i) = (-1)^{i}$，即 $i$ 为偶数时取 $+1$、奇数时取 $-1$，与题面定义的符号模式一致。

**证明**：$i=0$ 时 $(-1)^0 = +1$，对应首个元素取加号。每当下标增加 1，$(-1)^i$ 变号一次，故符号沿下标 $+,-,+,-,\cdots$ 交替，恰好是"偶数下标相加、奇数下标相减"。∎

**定理**：算法返回的 `ans` 等于 `nums` 的交替和。

**证明**：循环不变量为：处理完下标 $i$ 后，$ans = \sum_{j=0}^{i} sign(j) \cdot nums[j]$。归纳基础：循环前 $ans = 0 = \sum_{j=0}^{-1}$（空和）。归纳步骤：设处理完 $i-1$ 时不变量成立，则第 $i$ 轮按引理 1 以 $sign(i)$ 加减 $nums[i]$，不变量对 $i$ 仍成立。循环结束时 $i = n-1$，故 $ans = \sum_{j=0}^{n-1} sign(j) \cdot nums[j]$，即交替和。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。每个元素恰好访问一次，做一次加减。
- **空间复杂度**：$O(1)$。仅使用 `ans` 与下标变量。

> 💡 签到题的最短路径：读题 → 识别"下标奇偶定符号" → 一遍扫描累加 → 注意结果可为负。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int alternatingSum(vector<int>& nums) {
        int ans = 0;
        for (int i = 0; i < (int)nums.size(); i++) {
            if (i % 2 == 0) ans += nums[i];
            else ans -= nums[i];
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def alternatingSum(self, nums: list[int]) -> int:
        return sum(x if i % 2 == 0 else -x for i, x in enumerate(nums))
```

## 8. 边界情况与易错点

1. **单元素数组**（$n=1$）：只有 `nums[0]` 参与加法，无减项，答案即 `nums[0]`（示例 2）。
2. **奇数长度**：最后一个元素下标为偶数，符号为 $+$，别漏加（示例 3）。
3. **结果可为负**：如示例 1 输出 $-4$，不要误取绝对值或与 0 取 `max`。
4. **下标从 0 开始**：第一个元素是**加号**，若误把下标当 1 起算会整体反号。
5. **溢出**：本题 $|ans| \le 10^4$ 无风险；若数据范围放大到 $10^5 \times 10^9$ 量级，C++ 需改用 `long long`。
