# LeetCode 统计和为 N 的无零数对 题解

## 1. 题目概述

- **标题 / 题号**：统计和为 N 的无零数对（#3704，hard）
- **链接**：https://leetcode.cn/problems/count-no-zero-pairs-that-sum-to-n/
- **来源**：LeetCode 第 470 场周赛 Q4
- **难度**：困难
- **标签**：数学、动态规划、数位 DP

**题意**：**无零整数**指十进制表示中不含数字 $0$ 的**正整数**（如 $1 \sim 9$、$17$、$99$；而 $10$、$105$ 不是）。给定整数 $n$，统计满足 $a + b = n$ 且 $a$、$b$ 都是无零整数的数对 $(a, b)$ 的数量。注意 $(1,2)$ 与 $(2,1)$ 按**有序数对**分别计数。

**约束**：

- $2 \le n \le 10^{15}$

## 3. 解题思路

### 3.1 暴力思路

枚举 $a \in [1, n-1]$，逐位检查 $a$ 与 $n - a$ 是否都不含 $0$：时间 $O(n \log n)$，$n \le 10^{15}$ 时约 $10^{16}$ 次操作，不可行。

真正的难点在于**耦合**：单独统计「$[1, m]$ 内无零数的个数」是经典数位计数（每位 9 种选择），但 $a$ 合法不代表 $n - a$ 合法——$n - a$ 的每一位由减法**借位**决定，随 $a$ 的低位取值全局联动，两侧计数无法拆开相乘；朴素的容斥（总数 $-$ $a$ 含 0 $-$ $n-a$ 含 0）需要「两者都含 0」的交集项，同样绕不开这个耦合。

突破口是换个方向：**不先定 $a$ 再检查 $b$，而是把 $a + b = n$ 这个加法本身当成过程**——从个位到高位同步生成 $a$、$b$ 的每一位，减法的借位耦合就变成了加法的**进位链**，而进位只有 $0/1$ 两种取值，天然适合 DP。

### 3.2 核心观察：竖式加法逐列拆解

![核心观察：竖式加法逐列拆解](images/wc470_q4_column_addition.svg)

把 $n$ 的十进制位从低到高记为 $n_0, n_1, \dots, n_{L-1}$（$L \le 16$）。将 $a$、$b$ 高位**补零**到 $L$ 位后，有三个关键事实：

1. **加法逐列进行，进位 $\in \{0,1\}$**：第 $i$ 列满足 $d_a + d_b + c_i = n_i + 10 \cdot c_{i+1}$，其中 $d_a, d_b$ 是两数在该位的数字，$c_0 = 0$。由于 $d_a + d_b + c_i \le 9 + 9 + 1 = 19$，必有 $c_{i+1} \in \{0, 1\}$。
2. **无零结构 = 「先非零段、后零段」**：补零后 $a$ 的 $L$ 位形如「低若干位全在 $1 \sim 9$、其余位全为 $0$」——一旦某位填了 $0$，更高位只能恒填 $0$（这正是前导零）。例如 $b = 87$ 补成 $0\ 0\ 8\ 7$。
3. **$n$ 本身可以含 $0$**：「无零」约束只作用于 $a$、$b$，不作用于和（如 $2713 + 5287 = 8000$ 合法）。

于是「合法数对」与「逐列数字对序列 + 一条进位链」一一对应，可以沿列做数位 DP。

### 3.3 状态设计与转移

![状态设计：进位与阶段](images/wc470_q4_dp_state_machine.svg)

**状态**：处理完第 $0 \sim i-1$ 列后，记录三件事——

- $c \in \{0,1\}$：进入第 $i$ 列的进位；
- $s_a \in \{A, E\}$：$a$ 的**阶段**（$A$ = 活跃，还没填过 $0$；$E$ = 已结束，从某位起恒填 $0$）；$s_b$ 同理。

共 $2 \times 2 \times 2 = 8$ 个状态，初始 $dp[0][A][A] = 1$。

**转移**（处理第 $i$ 列，枚举数字对 $(d_a, d_b)$）：

- **合法数字域**：第 $0$ 位必须填 $1 \sim 9$（保证 $a, b \ge 1$）；第 $i \ge 1$ 位，活跃可填 $0 \sim 9$（填 $0$ 即转「已结束」），已结束只能填 $0$；
- **校验**：$(d_a + d_b + c) \bmod 10 = n_i$；
- **新进位**：$c' = \lfloor (d_a + d_b + c) / 10 \rfloor$；
- **新阶段**：$d > 0 \to A$，$d = 0 \to E$。

**终态**：处理完第 $L-1$ 列后，只对 $c = 0$ 的状态求和——末进位为 $1$ 意味着 $a + b = n + 10^L$，比 $n$ 整整多出一个最高位，必须丢弃。

由于枚举的 $(d_a, d_b)$ 区分了 $a$、$b$ 的角色，DP 天然统计**有序**数对，最后**不需要**乘 2 或除 2。

### 3.4 示例演算

![示例演算：n=205](images/wc470_q4_walkthrough.svg)

对 $n = 205$（$n_0 = 5,\ n_1 = 0,\ n_2 = 2$）逐列演算，状态写作 $(c, s_a, s_b)$：

| 阶段 | 状态计数 | 关键转移 |
|---|---|---|
| 初始 | $(0,A,A):1$ | — |
| 第 0 位 $n_0=5$ | $(0,A,A):4$，$(1,A,A):4$ | 数字对和 $\in \{5,15\}$：和 $5$（4 组）进位 $0$；和 $15$（4 组）进位 $1$ |
| 第 1 位 $n_1=0$ | $(0,E,E):4$，$(0,E,A):4$，$(0,A,E):4$，$(1,A,A):68$ | 和 $\equiv 0 \pmod{10}$：$(0,0)$ 双双封笔；和 $10$ 的 9 组双双继续；进位 $1$ 时和 $9$ 的 $(0,9)/(9,0)$ 单边封笔、其余 8 组继续 |
| 第 2 位 $n_2=2$ | $(0,E,A):72$，$(0,A,E):72$，$(1,A,A):544$ | 进位 $1$ 下和 $\in \{1,11\}$：和 $1$ 即 $(1,0)/(0,1)$，一边封笔（各 $+68$）；和 $11$ 的 8 组双双写满三位；原有 $(0,E,A)$、$(0,A,E)$ 各 $4$ 个穿过（$d_b=2$ / $d_a=2$） |
| 终态 | $\mathbf{144} = 72 + 72$ | 丢弃 $c=1$：如 $(686,519)$ 逐列看低位全对，但 $686+519=1205 \ne 205$ |

两个 $72$ 恰好左右对称：一个是「$a$ 已结束（一/两位数，$4+68$）$\times$ $b$ 写满三位」，另一个对称。这也与暴力按位数分解的结果吻合：$(1,3):4$、$(2,3):68$、$(3,2):68$、$(3,1):4$，总计 $144$。

## 4. 算法细节

1. **位数与方向**：把 $n$ 的十进制位**从低到高**存入数组（$n_0$ 为个位），DP 沿加法进位方向推进。$L \le 16$（$10^{15}$ 是 16 位数）。
2. **补零与「已结束」状态**：$a, b < n < 10^L$，都能用 $L$ 位表示。「已结束」= 高位补零段，此后每列只有 $d = 0$ 一种选择；「活跃」填 $0$ 的那一刻转入「已结束」。两数**不要求**恰有 $L$ 位——短数就是提前结束的路径，全部计入答案。
3. **个位强制非零**：第 $0$ 位 $d_a, d_b \in \{1,\dots,9\}$，一步同时保证 $a, b \ge 1$、排除「一上来就结束」的退化路径，无需任何特判。
4. **转移实现**：对每个状态枚举全部 $\le 100$ 组 $(d_a, d_b)$，做一次取模与整除。也可用「给定和 $s$ 的数对个数」公式 $O(1)$ 完成（$2 \le s \le 10$ 时 $s-1$ 组，$11 \le s \le 18$ 时 $19-s$ 组），但 $L \le 16$ 时两者都瞬间完成，枚举写法更不易错。
5. **终态收集**：答案 $= \sum_{s_a, s_b} dp[0][s_a][s_b]$，把进位非零的状态全部丢掉。
6. **有序性**：$(d_a, d_b)$ 与 $(d_b, d_a)$ 是两条不同转移，$(a,b)$、$(b,a)$ 自然分开计数，与示例 2 一致。

## 5. 正确性证明

**引理 1（补零表示）**：设 $L$ 为 $n$ 的位数。任意 $x \in [1, n)$ 有唯一的 $L$ 位十进制表示 $(x_0, \dots, x_{L-1})$（$x = \sum_i x_i 10^i$，高位允许为 $0$）；且 $x$ 是无零整数，当且仅当存在 $k \in [1, L]$ 使得 $x_0, \dots, x_{k-1} \in \{1,\dots,9\}$ 且 $x_k = \cdots = x_{L-1} = 0$。

**证明**：表示的存在性与唯一性即十进制展开。若 $x$ 无零且最高非零位为第 $t$ 位，则 $x_t \in \{1,\dots,9\}$、第 $t+1 \sim L-1$ 位全为 $0$，又 $x$ 的所有数位非零，故 $x_0, \dots, x_t \in \{1,\dots,9\}$，取 $k = t+1 \in [1, L]$。反之，若表示满足上述形态，则 $x$ 的实际数位恰为 $x_0, \dots, x_{k-1}$（前导零不计入表示），全在 $\{1,\dots,9\}$，且 $k \ge 1$ 保证 $x \ge 1$。∎

**引理 2（进位刻画）**：设 $(a_0, \dots, a_{L-1})$、$(b_0, \dots, b_{L-1})$ 为任意数字序列（每位 $0 \sim 9$）。令 $c_0 = 0$，$c_{i+1} = \lfloor (a_i + b_i + c_i)/10 \rfloor$，则归纳可得每个 $c_i \in \{0,1\}$，且

$$\sum_{i=0}^{L-1} (a_i + b_i)\, 10^i \;=\; \sum_{i=0}^{L-1} \bigl((a_i + b_i + c_i) \bmod 10\bigr) 10^i \;+\; c_L \cdot 10^L.$$

特别地，若逐位满足 $(a_i + b_i + c_i) \bmod 10 = n_i$（$n$ 的第 $i$ 位），则 $a + b = n + c_L \cdot 10^L$，从而 $a + b = n \iff c_L = 0$；且进位序列由数字序列唯一决定。

**证明**：每列有 $a_i + b_i + c_i = \bigl((a_i + b_i + c_i) \bmod 10\bigr) + 10\,c_{i+1}$。两边乘 $10^i$ 并对 $i$ 求和，两个进位求和项望远镜相消（$c_0 = 0$），即得等式。$c_i \in \{0,1\}$ 由 $a_i + b_i + c_i \le 9 + 9 + 1 = 19$ 归纳；$c_L = 1$ 时右边多出 $10^L$，与 $n < 10^L$ 不相符，故 $a + b = n$ 当且仅当 $c_L = 0$。唯一性：$c_0$ 固定，$c_{i+1}$ 被低位数据递归决定。∎

**定理**：算法返回值等于 $\#\{(a,b) : a, b \text{ 均为无零整数},\ a + b = n\}$（有序计数）。

**证明**：**（路径 → 数对）** 任取一条从初始状态到某个 $c = 0$ 终态的 DP 路径，它在每列选定数字对 $(d_a, d_b)$。第 $0$ 位强制 $1 \sim 9$，此后「活跃填非零、已结束恒填零」，由引理 1，两串数字分别唯一拼出无零整数 $a, b \in [1, n)$。转移逐列校验 $(d_a + d_b + c) \bmod 10 = n_i$ 且按 $c_{i+1} = \lfloor (d_a + d_b + c_i)/10 \rfloor$ 推进，与引理 2 的进位递推一致；终态 $c_L = 0$ 结合引理 2 给出 $a + b = n$。**（数对 → 路径）** 反之，任一合法数对按引理 1、2 展开为唯一的数字序列与进位序列，逐列对应一条合法 DP 路径（各状态的阶段取值与「是否已进入零段」一致）。两个方向的构造互逆，DP 对路径的计数不重不漏；又 $(d_a, d_b)$ 区分 $a$、$b$ 的角色，路径与有序数对一一对应。故返回值恰为所求。∎

## 6. 复杂度分析

- **时间复杂度**：$O(100 \cdot L) \approx O(L)$，$L \le 16$。每列至多 $8$ 个状态、每状态至多 $100$ 组数字对，总计 $\le 16 \times 8 \times 100 = 12800$ 次转移。
- **空间复杂度**：$O(1)$。滚动维护 $8$ 个状态计数，与位数无关。

> 💡 本题的通用套路：**遇到「两个数做运算、双方都带数位约束」的计数题，把运算过程（进位/借位）当作 DP 的骨架**，从低位向高位同步生成双方的数字。进位只有 $O(1)$ 种取值，状态数天然可控。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long countNoZeroPairs(long long n) {
        // n 的十进制位，从低位到高位
        int dig[20], L = 0;
        for (long long x = n; x > 0; x /= 10) dig[L++] = x % 10;

        // dp[进位][a 阶段][b 阶段]：1 = 活跃（尚未填过 0），0 = 已结束
        long long dp[2][2][2] = {};
        dp[0][1][1] = 1;

        for (int i = 0; i < L; ++i) {
            long long nd[2][2][2] = {};
            for (int c = 0; c < 2; ++c)
                for (int sa = 0; sa < 2; ++sa)
                    for (int sb = 0; sb < 2; ++sb) {
                        long long cnt = dp[c][sa][sb];
                        if (!cnt) continue;
                        for (int da = 0; da < 10; ++da) {
                            if (i == 0 && da == 0) continue;  // 个位必须非零
                            if (!sa && da > 0) continue;       // 已结束只能补 0
                            for (int db = 0; db < 10; ++db) {
                                if (i == 0 && db == 0) continue;
                                if (!sb && db > 0) continue;
                                int s = da + db + c;
                                if (s % 10 != dig[i]) continue;
                                nd[s / 10][da > 0][db > 0] += cnt;
                            }
                        }
                    }
            memcpy(dp, nd, sizeof dp);
        }
        // 终态：只保留进位为 0 的状态
        return dp[0][0][0] + dp[0][0][1] + dp[0][1][0] + dp[0][1][1];
    }
};
```

### Python

```python
class Solution:
    def countNoZeroPairs(self, n: int) -> int:
        # n 的十进制位，从低位到高位
        digs = []
        x = n
        while x:
            digs.append(x % 10)
            x //= 10

        # 状态 (进位, a 活跃?, b 活跃?) -> 方案数
        dp = {(0, True, True): 1}
        for i, ni in enumerate(digs):
            ndp = {}
            for (c, sa, sb), cnt in dp.items():
                for da in range(10):
                    if i == 0 and da == 0:      # 个位必须非零
                        continue
                    if not sa and da > 0:       # 已结束只能补 0
                        continue
                    for db in range(10):
                        if i == 0 and db == 0:
                            continue
                        if not sb and db > 0:
                            continue
                        s = da + db + c
                        if s % 10 == ni:
                            key = (s // 10, da > 0, db > 0)
                            ndp[key] = ndp.get(key, 0) + cnt
            dp = ndp
        # 终态：只保留进位为 0 的状态
        return sum(v for (c, _, _), v in dp.items() if c == 0)
```

## 8. 边界情况与易错点

1. **有序计数，最后不要除 2 / 乘 2**：DP 枚举的是有序数字对，$(a,b)$ 与 $(b,a)$ 天然分开。若改用「无序再翻倍」，$n$ 为偶数且 $n/2$ 无零时中间数对 $(n/2, n/2)$ 只能算一次，极易翻车。
2. **个位必须强制 $1 \sim 9$**：漏掉会把 $a = 0$ 的「数对」计入，也会违反「一旦填 0 更高位必须全 0」的结构约束。
3. **终态进位必须为 0**：$c_L = 1$ 的状态对应 $a + b = n + 10^L$，忘丢会多算（如 $n = 205$ 演算中被丢掉的 $544$）。
4. **阶段转移要写全**：「活跃」填 $0$ 转「已结束」；「已结束」再填非零 = 前导零后又出数字，非法；「已结束」恒填 $0$ 是自环。
5. **$n$ 本身可含 0**：不要看到 $n$ 有 0 就输出 0；只有 $a$、$b$ 受约束（$n = 8000$ 时 $2713 + 5287$ 合法）。
6. **数据范围**：$n \le 10^{15}$，接口已是 64 位整数；答案上界 $n - 1 < 10^{15}$ 同样安全（$n = 10^{15}$ 时答案为 $50{,}891{,}681{,}057{,}058$）。
7. **处理方向**：务必**从低位到高位**（进位向上传播）。从高位做起需要预知未来的进位，事倍功半。
