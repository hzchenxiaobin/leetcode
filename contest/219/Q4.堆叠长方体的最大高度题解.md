# LeetCode 堆叠长方体的最大高度 题解

## 1. 题目概述

- **标题 / 题号**：堆叠长方体的最大高度（#1691，hard）
- **链接**：https://leetcode.cn/problems/maximum-height-by-stacking-cuboids/
- **来源**：LeetCode 第 219 场周赛 Q4
- **难度**：困难
- **标签**：动态规划、排序、最长递增子序列变体、三维偏序

**题意**：给定 $n$ 个长方体，第 $i$ 个的尺寸为 $\text{cuboids}[i] = [width_i, length_i, height_i]$。从中选一个**子集**堆成塔：若（旋转后）满足 $width_i \le width_j$、$length_i \le length_j$、$height_i \le height_j$，三个维度**逐项**不超，块 $i$ 就可以放在块 $j$ 上方。每块可任意旋转（三个维度谁当长、宽、高随意指派）。返回塔的最大总高度（每块贡献其**当前朝向**的高度）。

**约束**：

- $1 \le n \le 100$
- $1 \le width_i, length_i, height_i \le 100$

> 💡 **关键信号**：$n \le 100$ 说明 $O(n^2)$ DP 绰绰有余；真正的障碍不是 DP，而是「可任意旋转」带来的 $6^n$ 朝向组合——先设法**把旋转自由度一次性消掉**，剩下就是一道熟悉的 LIS 求和变体（与 1626、354 同族）。

## 2. 示例

**示例 1**

```text
输入：cuboids = [[50,45,20],[95,37,53],[45,23,12]]
输出：190
解释：第 1 块放底部，53×37 一面朝下，高度 95；第 0 块放中间，45×20 朝下，高度 50；
      第 2 块放上面，23×12 朝下，高度 45。总高度 95 + 50 + 45 = 190。
```

**示例 2**

```text
输入：cuboids = [[38,25,45],[76,35,3]]
输出：76
解释：两块谁也放不到谁上面（任一旋转都无法三维全不超）。
      选第 1 块，35×3 朝下，高度 76。
```

**示例 3**

```text
输入：cuboids = [[7,11,17],[7,17,11],[11,7,17],[11,17,7],[17,7,11],[17,11,7]]
输出：102
解释：六个块是同一组尺寸 (7,11,17) 的全部旋转。按 11×7 朝下，高度都是 17，
      六块全叠：6 × 17 = 102。
```

> ⚠️ 示例 3 提示两点：① 完全相同的块**可以**互相堆叠（约束是 $\le$，含等号），无需去重，直接当独立块处理；② 输入本身可能就是「同一块的全部旋转」，内部排序后它们变成完全相同的三元组。

## 3. 解题思路

### 3.1 暴力思路：枚举朝向 + 枚举子集与顺序

每块有 $3! = 6$ 种朝向，$n$ 块共 $6^n$ 种朝向组合；对每种组合还要选子集（$2^n$）并决定堆叠顺序（子集内排列）。哪怕只枚举「谁在上谁在下」也有 $O(n!)$ 种。$n = 100$ 时任何指数级方案都不可行。

结论：必须证明**朝向根本不需要枚举**——存在一个不损失最优性的固定朝向。

### 3.2 核心观察：固定朝向——每块内部排序，最大维度当高

![核心观察：每块内部排序，最大维度立起来当高](images/wc219_q4_orientation_concept.svg)

**断言**：存在最优塔，其中每块都按 $w \le l \le h$ 定向——三元组升序排序，**最小维度当宽、中间当长、最大维度当高**。

直觉上是「双赢」：

- **高度只增不减**：任何朝向下，一块的高度都不会超过其最大维度；让最大维度竖直，单块贡献拉到上限；
- **底面只缩不涨**：底面换成最小的两个维度，上方块的放置条件只会更宽松。

但严谨性藏在一个隐蔽处：底面变了，会不会与**下方块**不再相容？这需要**排序保序引理**（§5 引理 1）：若某朝向下 $i$ 可放在 $j$ 上（三维逐项 $\le$），则各自内部排序后仍逐项 $\le$。于是把整座塔的**每块同时**重定向为排序朝向：塔不塌（相邻约束保持）、每块高度只增不减（变为最大维度）——总高度不降，最优性保住（§5 定理 1 完整证明）。

$6^n$ 种朝向组合，就此塌缩成每块唯一的 $1$ 种。

### 3.3 算法流程：整体排序 + 「以 i 为底」的 DP

![算法流程：内部排序 → 字典序排序 → 三维判定 DP](images/wc219_q4_dp_flow.svg)

消掉旋转后，问题变为：$n$ 个固定三元组 $(w_i \le l_i \le h_i)$，$i$ 可叠在 $j$ 上（$i$ 在上）当且仅当三维**逐项** $\le$。求「三维不降链」的最大权和——LIS 的三维求和版：

1. 每块内部升序排序；
2. 所有块按 $(w, l, h)$ **字典序**升序排序；
3. $dp[i] = h_i + \max\{\, dp[j] : j < i,\ \text{第 } j \text{ 块三维逐项} \le \text{第 } i \text{ 块} \,\}$，无前驱则 $dp[i] = h_i$（单独成堆）；
4. 答案 $= \max_i dp[i]$。

**为什么只看 $j < i$ 就够？** 塔自底向上三维单调不增 $\Rightarrow$ 底部块字典序最大、排序后位置最靠后 $\Rightarrow$ **任何合法塔都对应排序后序列的子序列**（自顶向下取；相同三元组的段内重排细节见 §5 引理 3）。于是「以 $i$ 为底的塔」完全由下标更小的块拼出，DP 无后效性。

### 3.4 示例演算

![示例演算：三步走查示例 1，dp 收敛到 190](images/wc219_q4_walkthrough.svg)

以示例 1 为例（完整走查见上图）：内部排序得 $[20,45,50], [37,53,95], [12,23,45]$；字典序排序后顺序为原下标 $2, 0, 1$；DP 递推 $dp = [45, 95, 190]$，答案 $190$。注意官方解释的堆法（底 $95$、中 $50$、顶 $45$）**恰好就是每块内部排序后的朝向**——最优解天然落在固定朝向的解空间里。

## 4. 算法细节

1. **内部排序**：`sort(c.begin(), c.end())`，每块常数 3 个元素；排序后 `c[0]=w ≤ c[1]=l ≤ c[2]=h`，高度即 `c[2]`。
2. **整体排序**：`vector<vector<int>>` 的默认比较就是字典序，等价于按 `(w, l, h)` 升序，保证 $j < i \Rightarrow w_j \le w_i$。
3. **DP 判定显式查三维**：$w$ 维其实已由字典序自动满足，可省；但显式写全三维是**防御式**写法——不依赖「排序键恰好覆盖判定维」这一隐含契约，日后改排序键也不致错，代价只有常数。
4. **`dp[i]` 初始化为 `h_i`**：单独成堆是合法起点，天然覆盖「无前驱」情形。
5. **答案取全局 `max` 而非 `dp[n-1]`**：字典序最大的块未必入塔（见 §8 易错点 5）。

## 5. 正确性证明

**引理 1（排序保序）**：设实数组 $\vec a = (a_1, a_2, a_3)$、$\vec b = (b_1, b_2, b_3)$。若存在配对（置换 $\pi, \sigma$）使 $a_{\pi(k)} \le b_{\sigma(k)}$（$k = 1,2,3$），则 $\mathrm{sort}(\vec a)_k \le \mathrm{sort}(\vec b)_k$（$k = 1,2,3$）。

**证明**：第 $k$ 小顺序统计量 $s_k(\vec x)$ 关于每个分量单调非降：固定其余分量，任一分量增大不可能使第 $k$ 小值减小。从 $\vec a$ 出发，把分量 $a_{\pi(k)}$ 逐一替换为 $b_{\sigma(k)}$，每次替换后 $s_k$ 不减；终态是 $\vec b$ 的一个排列 $\vec c$，$s_k(\vec c) = s_k(\vec b)$。故 $\mathrm{sort}(\vec a)_k = s_k(\vec a) \le s_k(\vec b) = \mathrm{sort}(\vec b)_k$。∎

**引理 2（重定向保持可行性）**：若在某朝向下块 $i$ 可放在块 $j$ 上（三维逐项 $\le$），则 $i, j$ 各自内部升序排序后仍逐项 $\le$。

**证明**：朝向下的「宽对宽、长对长、高对高」即引理 1 的配对前提，直接套用引理 1。∎

**定理 1（可固定朝向）**：存在最优塔，其中每块都按 $(w \le l \le h)$ 定向。

**证明**：取任意一座最优塔，将其中每块重定向为内部升序朝向。由引理 2，相邻两块的堆叠条件仍成立，塔仍合法；每块高度变为最大维度，只增不减，故总高度不小于原最优值，仍是最优塔。∎

**引理 3（塔 = 子序列）**：设所有块已内部升序并按 $(w,l,h)$ 字典序排列。任一合法塔可经**相同三元组段内重排**后，使塔中自底向上的块在序列中的位置严格递减。

**证明**：塔中相邻块三维逐项 $\le$。若相邻两块三元组不同，则上方块字典序严格更小，位置必然靠前。若塔中某极大连续段的三元组完全相同：这些块互相可堆叠（等号成立），与段外块的约束只依赖三元组，故可在段内按「位置大者居下」重排，合法性与塔高均不变。逐段处理后即得位置严格递减。∎

**定理 2（DP 正确性）**：设块已内部升序并按字典序排列，则 $\max_i dp[i]$ 等于最优塔高。

**证明**：对 $i$ 归纳证明：$dp[i]$ 等于「以第 $i$ 块为底」的塔的最大总高度。

- **上界（$\le$）**：设最优转移取自 $j^\*$。由归纳假设 $dp[j^\*]$ 对应一座以 $j^\*$ 为底的真塔，且 $j^\*$ 三维逐项 $\le i$，把 $i$ 垫在其下仍是合法塔，高度 $h_i + dp[j^\*] = dp[i]$；单独成堆（$dp[i] = h_i$）同理。故 $dp[i]$ 总能被某座以 $i$ 为底的真塔取到。
- **下界（$\ge$）**：设 $T$ 是以 $i$ 为底的最优塔，紧贴 $i$ 之上的块为 $j$。由引理 3 的重排（应用于 $T$），可设 $j$ 的位置 $< i$，且 $j$ 三维逐项 $\le i$，满足转移条件。$T$ 去掉底块 $i$ 后是以 $j$ 为底的合法塔，由归纳假设其高 $\le dp[j]$，故 $dp[i] \ge h_i + dp[j] \ge T$ 的高度。

两方向合并，$dp[i]$ 恰为以 $i$ 为底的最优值。任一座塔必有底块，在其位置处 $dp$ 值不小于塔高；反之每个 $dp[i]$ 都对应一座真塔。故 $\max_i dp[i]$ 等于最优塔高。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n^2)$。内部排序 $O(n)$（每块 3 个元素）、整体字典序排序 $O(n \log n)$、DP 双重循环 $O(n^2)$ 且每次转移判定 $O(3)$，DP 主导。$n \le 100$ 时约 $10^4$ 量级基本运算。
- **空间复杂度**：$O(n)$：`dp` 数组线性；排序原地（若不想修改输入，拷贝一份仍为 $O(n)$）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maxHeight(vector<vector<int>>& cuboids) {
        for (auto& c : cuboids)
            sort(c.begin(), c.end());          // 每块内部升序：最大维度当高
        sort(cuboids.begin(), cuboids.end());  // 整体按 (w, l, h) 字典序升序

        int n = cuboids.size();
        vector<int> dp(n);
        int ans = 0;
        for (int i = 0; i < n; ++i) {
            dp[i] = cuboids[i][2];             // 单独成堆
            for (int j = 0; j < i; ++j) {
                if (cuboids[j][0] <= cuboids[i][0] &&
                    cuboids[j][1] <= cuboids[i][1] &&
                    cuboids[j][2] <= cuboids[i][2]) {
                    dp[i] = max(dp[i], dp[j] + cuboids[i][2]);
                }
            }
            ans = max(ans, dp[i]);
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maxHeight(self, cuboids: List[List[int]]) -> int:
        for c in cuboids:
            c.sort()
        cuboids.sort()

        n = len(cuboids)
        dp = [0] * n
        ans = 0
        for i in range(n):
            dp[i] = cuboids[i][2]                      # 单独成堆
            for j in range(i):
                if (cuboids[j][0] <= cuboids[i][0]
                        and cuboids[j][1] <= cuboids[i][1]
                        and cuboids[j][2] <= cuboids[i][2]):
                    dp[i] = max(dp[i], dp[j] + cuboids[i][2])
            ans = max(ans, dp[i])
        return ans
```

## 8. 边界情况与易错点

1. **忘记内部排序（丢旋转自由度）**：按原始 $(w,l,h)$ 直接做字典序 + DP，示例 1 只会得到 $65$（最优塔里第 0、1 块的最大维度都躺平在底面里），远小于 $190$。内部排序是本题的第一生命线。
2. **外层只按高度排序**：等高不等维时会打乱「上方块在前」的次序。反例 `[[2,3,5],[1,2,5]]`（正确答案 $10$）：只按 $h$ 稳定排序后 $(2,3,5)$ 仍在 $(1,2,5)$ 前面，DP 漏掉「$(1,2,5)$ 叠 $(2,3,5)$」得 $5$。必须用**完整字典序**。
3. **以为「字典序小」就能叠**：字典序 $\prec$ 不蕴含三维逐项 $\le$。反例 $(1,9,9) \prec (2,2,2)$，但 $9 > 2$ 不可叠。判定必须显式查三个维度。
4. **相同尺寸块**：约束是 $\le$ 含等号，完全相同的块可互相堆叠——示例 3 六块全叠。无需去重，等号判定自动覆盖。
5. **答案不是 `dp[n-1]`**：字典序最大的块未必入塔。反例 `[[2,2,2],[1,1,100]]`：最优是单块 $100$，而 `dp[n-1] = 2`。必须取全局 `max`。
6. **$n = 1$**：答案是该块的最大维度；`dp[i]` 初始化为 $h_i$ 已自动覆盖，无需特判。
7. **贪心不可行**：「按高度降序、放得下就放」是常见错误直觉。反例 `[[2,2,10],[3,3,6],[3,3,6]]`：贪心先放 $(2,2,10)$，两块 $3 \times 3$ 底的放不上去，得 $10$；最优是两块 $(3,3,6)$ 相叠得 $12$。懂得「跳过局部最优块」正是 DP 的本职。
8. **溢出**：至多 $100$ 块、每块高 $\le 100$，总和 $\le 10^4$，`int` 绰绰有余。
