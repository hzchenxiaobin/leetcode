# LeetCode 石子游戏 VII 题解

## 1. 题目概述

- **标题 / 题号**：石子游戏 VII（#1690，medium）
- **链接**：https://leetcode.cn/problems/stone-game-vii/
- **来源**：LeetCode 第 219 场周赛 Q3
- **难度**：中等
- **标签**：动态规划、区间 DP、博弈、Minimax、前缀和

**题意**：$n$ 块石子排成一排，第 $i$ 块价值 $\text{stones}[i]$。爱丽丝与鲍勃轮流行动，**爱丽丝先手**；每回合移除**最左**或**最右**的那块石子，并获得与**移除后剩余石子值之和**相等的得分。石子取尽时游戏结束。鲍勃尽力**缩小**得分差值，爱丽丝尽力**扩大**得分差值。两人都发挥最佳水平，返回**爱丽丝得分 − 鲍勃得分**。

**约束**：

- $2 \le n \le 1000$
- $1 \le \text{stones}[i] \le 1000$

> ⚠️ 审题关键：得分不是「拿走的那块」，而是「**移除后剩余区间的和**」——每次得分随区间缩短而递减，与 [877. 石子游戏](https://leetcode.cn/problems/stone-game/)（拿走即得分）的关键差别。此外鲍勃「缩小差值」= 最大化自己的净分差，博弈对「差值」而言是**零和**的，这决定了后面只追踪一个差值维度的做法。

## 2. 示例

**示例 1**

```text
输入：stones = [5,3,1,4,2]
输出：6
解释：
- 爱丽丝移除 2，得分 5+3+1+4 = 13。爱丽丝=13，鲍勃=0，石子=[5,3,1,4]
- 鲍勃移除 5，得分 3+1+4 = 8。爱丽丝=13，鲍勃=8，石子=[3,1,4]
- 爱丽丝移除 3，得分 1+4 = 5。爱丽丝=18，鲍勃=8，石子=[1,4]
- 鲍勃移除 1，得分 4。爱丽丝=18，鲍勃=12，石子=[4]
- 爱丽丝移除 4，得分 0。爱丽丝=18，鲍勃=12，石子=[]
差值 18 − 12 = 6
```

## 3. 解题思路

### 3.1 暴力思路：极大极小博弈树

每回合先手有「移左」或「移右」两种选择，移除后剩余的一定是原数组的**一段连续区间**。直接展开博弈树：爱丽丝在偶数层取 $\max$、鲍勃在奇数层取 $\min$，复杂度 $O(2^n)$，$n = 1000$ 必爆。

但注意**同一区间会被反复到达**——无论前面怎么走，只要剩下区间 $[i..j]$，后续博弈与历史完全无关（得分只取决于「当前剩余区间」）。状态数只有 $O(n^2)$ 个，天然适合**区间 DP + 记忆化**。剩下的问题只是：状态里该存什么？

### 3.2 核心观察：净赚状态 + 零和

![核心观察：净赚状态与两种选择的分解](images/wc219_q3_net_gain_concept.svg)

**状态定义**：

> $\text{dp}[i][j]$ = 双方都最优时，**先手**在区间 $\text{stones}[i..j]$ 上能取得的最大「**先手总得分 − 后手总得分**」（净赚）。

为什么一个差值维度就够？因为博弈是零和的：鲍勃「最小化爱丽丝 − 鲍勃」等价于「最大化鲍勃 − 爱丽丝」，两人都在最大化自己的净赚；对手在子区间上的 $\text{dp}$ 已经是「他作为先手」视角的净赚，减掉即可，**不需要额外记录轮到谁**。

**转移**（先手两种第一手）：

- **移除左端 $\text{stones}[i]$**：本回合得分 $= \text{sum}(i+1, j)$（剩余区间之和，前缀和 $O(1)$）；剩余 $[i+1..j]$ 交对手先手，对手净赚 $\text{dp}[i+1][j]$，故先手净赚 $= \text{sum}(i+1,j) - \text{dp}[i+1][j]$；
- **移除右端 $\text{stones}[j]$**：本回合得分 $= \text{sum}(i, j-1)$；对手净赚 $\text{dp}[i][j-1]$，先手净赚 $= \text{sum}(i,j-1) - \text{dp}[i][j-1]$。

$$
\text{dp}[i][j] = \max\bigl(\ \text{sum}(i+1,j) - \text{dp}[i+1][j],\ \ \text{sum}(i,j-1) - \text{dp}[i][j-1]\ \bigr)
$$

**边界**：$\text{dp}[i][i] = 0$——只剩一块时移除后剩余为空，本回合得 $0$ 分。**答案**：$\text{dp}[0][n-1]$。

> 💡 **减号的含义**：先手本回合拿了 $\text{sum}$，随后**身份互换**——对手成为剩余区间的先手，拿到净赚 $\text{dp}[\text{sub}]$；从原先手视角这是对手的收益，要扣除。「对手让我后续拿得少」已被减法吸收，所以转移外层**恒为 $\max$**，无需按轮次交替 $\max/\min$。

### 3.3 算法流程：前缀和 + 按区间长度递推

![算法流程：前缀和与区间长度递推](images/wc219_q3_interval_dp_flow.svg)

$\text{dp}[i][j]$ 只依赖**正下方** $\text{dp}[i+1][j]$ 与**正左方** $\text{dp}[i][j-1]$，两者对应的区间都恰短 $1$。因此按**区间长度**从 $2$ 到 $n$ 递推即可保证依赖就绪；等价写法是外层 $i$ 从 $n-1$ 降到 $0$、内层 $j$ 从 $i+1$ 升到 $n-1$（后者天然支持一维滚动，见 §4）。区间和 $\text{sum}(l, r) = \text{prefix}[r+1] - \text{prefix}[l]$ 用前缀和 $O(1)$ 查询，避免总复杂度退化到 $O(n^3)$。

```text
prefix[0] ← 0;  prefix[k] ← prefix[k−1] + stones[k−1]
dp[i][i] ← 0                                    # 长度 1
for len in 2 … n:                                # 区间长度递增
    for i in 0 … n−len:
        j ← i + len − 1
        dp[i][j] ← max( sum(i+1, j) − dp[i+1][j],
                        sum(i, j−1) − dp[i][j−1] )
return dp[0][n−1]
```

## 4. 算法细节

1. **前缀和的差分**：$\text{prefix}[k] = \text{stones}[0] + \dots + \text{stones}[k-1]$，则 $\text{sum}(l, r) = \text{prefix}[r+1] - \text{prefix}[l]$。移除左端剩 $[i+1, j]$，得分 $\text{prefix}[j+1] - \text{prefix}[i+1]$；移除右端剩 $[i, j-1]$，得分 $\text{prefix}[j] - \text{prefix}[i]$——两组下标错开一位，写错一组就会样例 1 直接翻车。
2. **两种等价循环**：① 按 `len` 递增 + 左端点扫描（本文 C++ 版）；② 外层 `i` 从 $n-1$ 降到 $0$、内层 `j` 从 $i+1$ 升到 $n-1$（本文 Python 滚动版）。② 的正确性：计算 $(i, j)$ 时，$(i+1, j)$ 在上一轮 `i+1` 已算好，$(i, j-1)$ 在本轮早些时候已算好。
3. **一维滚动**：`dp[j]` 覆盖前存的是 $\text{dp}[i+1][j]$（上一轮的同一列），`dp[j-1]` 已被本轮更新为 $\text{dp}[i][j-1]$——一个数组同时当「下一行」和「本行左侧」用，空间 $O(n^2) \to O(n)$。
4. **记忆化搜索对照**：写成 `dfs(i, j)` 的自顶向下版与递推等价（先算后算互不干扰），但 $n = 1000$ 时 Python 递归深度近千，赛时用迭代递推更稳（见 §8）。
5. **值域**：$|\text{dp}| \le \sum \text{stones} \le 1000 \times 1000 = 10^6$，C++ `int`（上限约 $2.1 \times 10^9$）绰绰有余，无需 `long long`。
6. **答案恒正**：题面即断言「鲍勃总是输」，实测各种小输入答案均 $\ge 1$；但算法不依赖该结论，直接返回 $\text{dp}[0][n-1]$。

## 5. 正确性证明

以下把「从区间 $[i..j]$ 开始、当前行动者记为**先手**」的一局称为状态 $(i,j)$ 的对局；先手第一手移除左端时本回合得 $g_L = \text{sum}(i+1, j)$，移除右端时得 $g_R = \text{sum}(i, j-1)$。

**引理 1（差值记账恒等式）**：状态 $(i,j)$（$i < j$）的任一局中，若先手第一手移除左端、得 $g_L$，记 $\delta$ 为整局「先手总得分 − 后手总得分」，$\delta'$ 为后续子对局（区间 $[i+1..j]$，以原后手为新先手）中「新先手总得分 − 新后手总得分」，则 $\delta = g_L - \delta'$。移除右端时同理：$\delta = g_R - \delta''$，其中 $\delta''$ 对应区间 $[i..j-1]$ 的子对局差值。

**证明**：整局中原先手的总得分 $= g_L +$ 其在子对局中的得分，原后手的总得分 $=$ 其在子对局中的得分（第一手不是他走的）。于是

$$
\delta = g_L + (\text{原先手子局得分} - \text{原后手子局得分}) = g_L - (\text{原后手子局得分} - \text{原先手子局得分}) = g_L - \delta',
$$

末一等号成立是因为子对局中「新先手 = 原后手、新后手 = 原先手」，$\delta'$ 恰为括号内的量。此为逐局记账恒等式，**不依赖任何最优性假设，也不依赖总得分是否为定值**。∎

**引理 2（零和等价）**：鲍勃最小化「爱丽丝 − 鲍勃」$\iff$ 鲍勃最大化「鲍勃 − 爱丽丝」；故在每个状态上，双方都在最大化「当前行动者 − 对方」这一差值。

**证明**：「鲍勃 − 爱丽丝」$= -$（「爱丽丝 − 鲍勃」），最小化 $f$ 等价于最大化 $-f$。∎

**定理（净赚递推）**：记 $D(i,j)$ 为状态 $(i,j)$ 双方最优对局的差值，则 $D(i,i) = 0$，且对 $i < j$，

$$
D(i,j) = \max\bigl(\ g_L - D(i+1,j),\ \ g_R - D(i,j-1)\ \bigr), \qquad g_L = \text{sum}(i+1,j),\ g_R = \text{sum}(i,j-1).
$$

**证明**：对区间长度 $L = j - i + 1$ 归纳，且归纳命题加强为双策略形式：

- (a) 先手有策略使 $\delta \ge D(i,j)$；
- (b) 后手有策略使 $\delta \le D(i,j)$。

**基础** $L = 1$：先手移除唯一石子后剩空，得 $0$ 分，后手无石子可拿，$\delta = 0$；(a)(b) 平凡成立，且 $D(i,i) = 0$。

**归纳步**：设长度 $< L$ 的所有状态满足 (a)(b) 且 $D$ 由递推式给出。考察长度 $L \ge 2$ 的状态 $(i,j)$。记 $M = \max(g_L - D(i+1,j),\ g_R - D(i,j-1))$。

(a)：先手选择 $M$ 的取值分支，不妨设移除左端（$g_L - D(i+1,j) = M$，另一分支对称）。得 $g_L$ 后，先手成为子对局 $[i+1..j]$ 的**后手**，套用归纳 (b)：他有策略使 $\delta' \le D(i+1,j)$。由引理 1，$\delta = g_L - \delta' \ge g_L - D(i+1,j) = M$。

(b)：设先手第一手移除左端（另一分支对称），得 $g_L$ 后，后手成为子对局 $[i+1..j]$ 的**先手**，套用归纳 (a)：他有策略使 $\delta' \ge D(i+1,j)$。由引理 1，$\delta = g_L - \delta' \le g_L - D(i+1,j) \le M$。先手第一手移除右端时同上有 $\delta \le g_R - D(i,j-1) \le M$。

(a)(b) 合起来说明双方最优时 $\delta$ 恰被压在 $M$：先手能保证 $\ge M$、后手能保证 $\le M$，故 $D(i,j) = M$，即递推式成立。∎

**推论**：按 §3.3 的递推算出的 $\text{dp}[0][n-1]$ 等于 $D(0, n-1)$，即为所求差值。

**证明**：$\text{dp}$ 与 $D$ 满足同一边界与同一递推，按区间长度归纳得 $\text{dp} \equiv D$；$\text{dp}[0][n-1]$ 是爱丽丝在整段先手（游戏从她开始）的净赚，即「爱丽丝 − 鲍勃」。∎

> 💡 **总得分不是定值，为何还能递推**：877 中每回合得分之和恒为 $\sum \text{piles}$；本题每次得分是「当时的剩余和」，随移除顺序变化（如 $[5,3,1,4,2]$ 最优局总得分 $30$，换走法会变）。但引理 1 是**记账恒等式**，只逐局分解差值，从不使用「总分守恒」——差值的可分解性才是递推的根基。

## 6. 复杂度分析

- **时间复杂度**：$O(n^2)$。上三角约 $n^2/2$ 个状态，每个状态两个分支、每分支一次前缀和 $O(1)$ 查询；$n = 1000$ 时约 $5 \times 10^5$ 次转移，总量 $10^6$ 级，远在时限内。若不用前缀和、每次现算区间和，则退化为 $O(n^3) \approx 10^9$，会超时。
- **空间复杂度**：$O(n^2)$（二维表）+ $O(n)$ 前缀和；一维滚动可降到 $O(n)$（见 §4 第 3 点），$n = 1000$ 时约 $4\,\text{KB}$。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int stoneGameVII(vector<int>& stones) {
        int n = stones.size();
        // prefix[k] = stones[0..k-1] 之和
        vector<int> prefix(n + 1, 0);
        for (int i = 0; i < n; i++) prefix[i + 1] = prefix[i] + stones[i];

        // dp[i][j] = 先手在 stones[i..j] 上的最大净赚
        vector<vector<int>> dp(n, vector<int>(n, 0));  // 边界 dp[i][i] = 0
        for (int len = 2; len <= n; len++) {
            for (int i = 0; i + len - 1 < n; i++) {
                int j = i + len - 1;
                int gainL = prefix[j + 1] - prefix[i + 1];  // 移除左端，剩 [i+1, j]
                int gainR = prefix[j] - prefix[i];          // 移除右端，剩 [i, j-1]
                dp[i][j] = max(gainL - dp[i + 1][j], gainR - dp[i][j - 1]);
            }
        }
        return dp[0][n - 1];
    }
};
```

### Python

```python
class Solution:
    def stoneGameVII(self, stones: List[int]) -> int:
        n = len(stones)
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + stones[i]

        # 一维滚动：dp[j] 覆盖前存 dp[i+1][j]，dp[j-1] 已更新为 dp[i][j-1]
        dp = [0] * n                       # 边界 dp[i][i] = 0
        for i in range(n - 2, -1, -1):     # i 从 n-1 降到 0
            for j in range(i + 1, n):      # j 从 i+1 升到 n-1
                gain_l = prefix[j + 1] - prefix[i + 1]  # 移除左端，剩 [i+1, j]
                gain_r = prefix[j] - prefix[i]          # 移除右端，剩 [i, j-1]
                dp[j] = max(gain_l - dp[j], gain_r - dp[j - 1])
        return dp[n - 1]
```

## 8. 边界情况与易错点

1. **边界是 $\text{dp}[i][i] = 0$，不是 $\text{stones}[i]$**：只剩一块时移除后剩空、得 $0$ 分。877 的边界是「拿走的那堆」$\text{piles}[i]$，照抄必错。
2. **转移是「减」不是「加」**：净赚 $=$ 本回合得分 $-$ 对手子局净赚。写成 $\text{gain} + \text{dp}[\text{sub}]$ 等于把对手的收益算进自己，示例 1 立刻算出错误值。
3. **外层恒 $\max$，不要交替 $\max/\min$**：零和性已把「对手让我拿得少」吸收进减号。若坚持按轮次切换算子，状态必须加「轮到谁」维度；只定义 $\text{dp}[i][j]$ 却交替算子是错的。
4. **循环顺序**：依赖是「正下方 + 正左方」，必须按 `len` 递增，或 `i` 从 $n-1$ 降序、`j` 升序。若写成 `i` 升序的双重循环，$\text{dp}[i+1][j]$ 尚未计算，答案全错。
5. **前缀和 off-by-one**：$\text{sum}(l, r) = \text{prefix}[r+1] - \text{prefix}[l]$。移除左端是 $\text{prefix}[j+1] - \text{prefix}[i+1]$，移除右端是 $\text{prefix}[j] - \text{prefix}[i]$——两组下标错开一位，赛前用 $n = 2$ 手验一遍最稳。
6. **$n = 2$ 是天然的对拍样例**：答案必为 $\max(\text{stones}[0], \text{stones}[1])$（先移较小端，白拿较大端的值），可快速检验转移是否写对。
7. **Python 记忆化递归的栈深**：$n = 1000$ 时递归深度近千，接近默认栈限；赛时直接写迭代递推（或滚动版）。
8. **数值范围**：$|\text{dp}| \le \sum \text{stones} \le 10^6$，`int` 足够；但若把得分规则记错成「剩余和的平方」之类，$10^{12}$ 会悄悄溢出——先估值域再选类型。
