# LeetCode 比赛中的配对次数 题解

## 1. 题目概述

- **标题 / 题号**：比赛中的配对次数（#1688，easy）
- **链接**：https://leetcode.cn/problems/count-of-matches-in-tournament/
- **来源**：LeetCode 第 219 场周赛 Q1
- **难度**：简单
- **标签**：数学、模拟

**题意**：$n$ 支队伍进行单败淘汰赛。每一轮：若当前队伍数为偶数，则两两配对进行 $n/2$ 场比赛，$n/2$ 支队伍晋级；若为奇数，则随机轮空一支队伍直接晋级，其余配对进行 $(n-1)/2$ 场比赛，$(n-1)/2 + 1$ 支队伍晋级。求决出冠军时总共进行的配对（比赛）次数。

**约束**：

- $1 \le n \le 200$

> 💡 签到题的最短路径：逐轮模拟八行代码稳过；但更值得沉淀的是**总量守恒**观察——每场比赛恰好淘汰一支队伍，从 $n$ 支打到只剩冠军要淘汰 $n - 1$ 支，于是答案直接是 $n - 1$，一个减法收工。

## 2. 示例

**示例 1**

```text
输入：n = 7
输出：6
解释：第 1 轮 7 队打 3 场（1 队轮空）→ 4 队；第 2 轮 4 队打 2 场 → 2 队；
      第 3 轮 2 队打 1 场 → 决出冠军。总计 3 + 2 + 1 = 6 场。
```

**示例 2**

```text
输入：n = 14
输出：13
解释：14 → 7 场 → 7 队 → 3 场 → 4 队 → 2 场 → 2 队 → 1 场 → 1 队。
      总计 7 + 3 + 2 + 1 = 13 场。
```

**示例 3**（自拟，覆盖 $n$ 为 2 的幂）

```text
输入：n = 8
输出：7
解释：每轮队伍数都是偶数：8 → 4 → 2 → 1，场次 4 + 2 + 1 = 7 = 8 − 1。
```

**示例 4**（自拟，最小边界）

```text
输入：n = 1
输出：0
解释：唯一队伍直接夺冠，一场比赛都没打；公式 n − 1 = 0 自动成立。
```

## 3. 解题思路

### 3.1 暴力思路：逐轮模拟

按题面逐轮转写：只要队伍数大于 1，就累加本轮配对数，再把队伍数换成晋级数。每轮队伍数至少减半，$n \le 200$ 时至多 8 轮，模拟毫无压力，是赛时最稳的写法。

```text
while n > 1:
    ans += n / 2        # 本轮场次（整数除法，奇数时恰为 (n-1)/2）
    n   -= n / 2        # 晋级队伍数 = ⌈n/2⌉，轮空的那支自动保留
return ans
```

### 3.2 核心观察：每场比赛恰好淘汰一支队伍

![核心观察：一场比赛净减一支队伍，总量守恒](images/1688_elimination_concept.svg)

换一个视角数：不看「轮」，只看「**队伍数的减少量**」。

- 一场比赛：两支队伍进、一支队伍出，队伍数净减 $1$；
- 一次轮空：不产生比赛，队伍数不变。

要从 $n$ 支队伍变成唯一冠军，队伍数总共减少 $n - 1$，而每场比赛**恰好**贡献 $1$ 的减少量，所以总场次必然是

$$\text{总场次} = n - 1,$$

**与奇偶如何交错、谁轮空完全无关**。这就是守恒计数：盯住一个「每次操作的改变量固定」的量，直接把总操作次数写出来。

### 3.3 算法流程

![算法流程：逐轮模拟与 O(1) 公式殊途同归](images/1688_round_flow.svg)

**模拟版**（$O(\log n)$）：见 3.1 的循环——奇偶两种规则被统一成 $\lfloor n/2 \rfloor$ 与 $n - \lfloor n/2 \rfloor = \lceil n/2 \rceil$ 两个表达式，无需分支。

**公式版**（$O(1)$）：直接 `return n - 1`。两者对任意 $n$ 等价（第 5 节证明）。

### 3.4 示例演算

![示例演算：n = 7 的逐轮配对走查](images/1688_walkthrough.svg)

以 $n = 7$ 为例（完整括号图见上图）：第 1 轮奇数，$3$ 场淘汰 $3$ 支、$1$ 支轮空，$4$ 支晋级；第 2 轮 $2$ 场淘汰 $2$ 支；第 3 轮 $1$ 场淘汰最后 $1$ 支。累计淘汰 $3 + 2 + 1 = 6$ 支 $= 7 - 1$，与守恒公式一致。

## 4. 算法细节

1. **奇偶统一的状态转移**：本轮场次为 $\lfloor n/2 \rfloor$（偶数时 $n/2$，奇数时 $(n-1)/2$，整数除法天然覆盖两种情形）；晋级队伍数为 $n - \lfloor n/2 \rfloor = \lceil n/2 \rceil$（奇数时 $(n-1)/2 + 1$，即「胜者们 + 轮空队」）。一个表达式同时吃掉两种分支，**不需要写 if**。
2. **轮空队必须保留在下一轮**：奇数轮晋级数是 $(n-1)/2 + 1$，若误写为 $(n-1)/2$，$n = 7$ 会算出 $3 + 1 = 4 \ne 6$。
3. **望远镜求和（telescoping）结构**：模拟中第 $i$ 轮场次恰为 $n_i - n_{i+1}$（本轮淘汰数），逐轮求和即 $n_1 - n_{\text{final}} = n - 1$——这正是模拟版与公式版等价的代数原因。
4. **终止性**：$n > 1$ 时 $\lceil n/2 \rceil < n$ 严格成立（$n \ge 2 \Rightarrow \lceil n/2 \rceil \le (n+1)/2 < n$），队伍数是严格递减的正整数，循环至多 $\lceil \log_2 n \rceil$ 轮内落到 $1$。
5. **赛时取舍**：$n \le 200$ 时模拟与公式都对；数据范围放大到 $10^{18}$ 时只剩公式版可用，且它不会溢出任何主流整数类型。

## 5. 正确性证明

**引理 1**（每场恰淘汰一队）：一场比赛使参赛队伍数恰好减少 $1$；轮空使队伍数不变且不计入场次。

**证明**：一场比赛由两支队伍进行、决出一支晋级者，队伍计数由 $2$ 变为 $1$，净变化 $-1$；轮空队伍直接进入下一轮，既不产生比赛也不改变计数。∎

**引理 2**（模拟转移式）：逐轮模拟中，若某轮开始时队伍数为 $n$，则该轮场次为 $\lfloor n/2 \rfloor$，且轮后队伍数为 $n - \lfloor n/2 \rfloor$。

**证明**：$n$ 为偶数时，配对 $n/2 = \lfloor n/2 \rfloor$ 场、$n/2 = n - \lfloor n/2 \rfloor$ 支晋级，两式成立。$n$ 为奇数时，配对 $(n-1)/2 = \lfloor n/2 \rfloor$ 场，晋级 $(n-1)/2 + 1 = \lceil n/2 \rceil = n - \lfloor n/2 \rfloor$ 支（含轮空队）。∎

**定理**：对任意 $n \ge 1$，总比赛场次为 $n - 1$，且模拟版循环的返回值与之相等。

**证明**：先证模拟终止且终态队伍数为 $1$：$n = 1$ 时不进循环；$n > 1$ 时由引理 2，轮后队伍数 $\lceil n/2 \rceil < n$，正整数严格递减，必在至多 $\lceil \log_2 n \rceil$ 轮内到达 $1$。设各轮开始时队伍数依次为 $n = n_1, n_2, \dots, n_k = 1$，由引理 2，第 $i$ 轮场次为 $\lfloor n_i/2 \rfloor = n_i - n_{i+1}$，故

$$\sum_{i=1}^{k-1} \left\lfloor \frac{n_i}{2} \right\rfloor = \sum_{i=1}^{k-1} (n_i - n_{i+1}) = n_1 - n_k = n - 1,$$

即模拟返回 $n - 1$。再由引理 1 的守恒视角：整个赛程队伍数总减少 $n - 1$，每场比赛恰贡献 $1$、轮空贡献 $0$，故任何合法赛程的总场次均为 $n - 1$。∎

## 6. 复杂度分析

- **时间复杂度**：模拟版 $O(\log n)$——每轮队伍数至少减半，$n \le 200$ 时至多 $8$ 轮；公式版 $O(1)$，一次减法。
- **空间复杂度**：$O(1)$，只用到常数个变量。

## 7. 参考代码

### C++（逐轮模拟）

```cpp
class Solution {
public:
    int numberOfMatches(int n) {
        int ans = 0;
        while (n > 1) {
            ans += n / 2;
            n -= n / 2;
        }
        return ans;
    }
};
```

### Python（$O(1)$ 公式）

```python
class Solution:
    def numberOfMatches(self, n: int) -> int:
        return n - 1
```

两种写法对任意 $n$ 等价（第 5 节定理）；赛时按手速任选，范围放大（如 $n \le 10^{18}$）时只剩公式版。

## 8. 边界情况与易错点

1. **$n = 1$**：$0$ 场，唯一队伍直接夺冠。公式 $n - 1 = 0$ 与 `while (n > 1)` 均自动正确，无需特判。
2. **奇数轮丢轮空队**：晋级数是 $(n-1)/2 + 1 = \lceil n/2 \rceil$，误写成 $(n-1)/2$ 会在 $n = 7$ 时输出 $4$ 而非 $6$。
3. **答案与轮空选择无关**：题面说「随机」轮空，但守恒保证无论谁轮空、奇偶如何交错，总场次都是 $n - 1$——这正是 $O(1)$ 公式可靠的原因，读题时别被「随机」二字带偏。
4. **别把「场次」当成「轮数」**：轮数是 $\lceil \log_2 n \rceil$（$n = 7$ 时 $3$ 轮），场次是 $n - 1$（$6$ 场），两个量完全不同。
5. **溢出**：$n \le 200$，`int` 绰绰有余；范围放大时 $n - 1$ 也在 `long long` 范围内。
6. **整数除法**：C++/Java 的 `n / 2` 对正数即下取整；Python 要用 `//` 或 `>> 1`，写 `/` 会得到浮点数。
