# LeetCode 根到叶路径上的不足节点 题解

## 1. 题目概述

- **标题 / 题号**：根到叶路径上的不足节点（#1080，medium）
- **链接**：https://leetcode.cn/problems/insufficient-nodes-in-root-to-leaf-paths/
- **来源**：LeetCode 第 140 场周赛 Q3
- **难度**：中等
- **标签**：树, 深度优先搜索, 二叉树

**题意**：给定二叉树根 `root` 与整数 `limit`，一次性删除所有**不足节点**并返回新根。节点 `u` 不足，当且仅当原树中**经过** `u` 的每一条根-叶路径，其节点值之和都严格小于 `limit`。删除一个节点意味着它的整棵子树一起消失。

**约束**：

- 节点数 $1 \le n \le 5000$
- $-10^5 \le \text{Node.val} \le 10^5$
- $-10^9 \le limit \le 10^9$

## 2. 示例

**示例 1**

```text
输入：root = [1,2,3,4,-99,-99,7,8,9,-99,-99,12,13,-99,14], limit = 1
输出：[1,2,3,4,null,null,7,8,9,null,14]
解释：经过 −99 的四条路径和为 −195、−195、−83、−82，另一条经过 7 左侧 −99 的路径和为 −88，
      全部小于 1，这些 −99 节点连同其孩子 12、13 一起被删除（共 6 个节点）。
```

**示例 2**

```text
输入：root = [5,4,8,11,null,17,4,7,1,null,null,5,3], limit = 22
输出：[5,4,8,11,null,17,4,7,null,null,null,5]
解释：叶 1 的路径和 5+4+11+1 = 21 < 22，叶 3 的路径和 5+8+4+3 = 20 < 22，二者被删；
      11 只剩左孩子 7，节点 4 只剩左孩子 5（路径和 22 恰好等于 limit，仍算充足）。
```

**示例 3**

```text
输入：root = [1,2,-3,-5,null,4,null], limit = -1
输出：[1,null,-3,4]
解释：左侧路径和 1+2+(−5) = −2 < −1，于是 −5 与 2 都被删除；右侧 1+(−3)+4 = 2 ≥ −1 保留。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的做法：把原树所有根-叶路径枚举出来并记录各自的和；对每个节点 `u`，挑出所有经过 `u` 的路径，用其中最大的和与 `limit` 比较。枚举所有路径本身需要 $O(n)$ 空间，而逐个节点扫描路径集合是 $O(n^2)$ 时间（「一条长链 + 末端挂满叶子」的结构里，路径数与路径长度可同时达到 $O(n)$）。$n = 5000$ 时约 $2.5\times10^7$ 次操作，勉强能过，但还要额外处理「删完之后如何重建树」，实现又长又易错。

真正的浪费在于**同一条路径的和被反复计算**：经过 `u` 的最大路径和其实可以由孩子的结果 $O(1)$ 拼出来，这就是自底向上的 DFS。

### 3.2 核心观察：最大值判定 + 自底向上合并

![不足节点的判定：只看经过它的最大路径和](images/wc140_q3_insufficient_definition.svg)

把一条路径和拆成两段：

$$\text{sum}(root \to leaf) = pre(u) + \text{val}(u) + \text{down}(u \to leaf)$$

其中 $pre(u)$ 是根到 `u` 父亲（含）的路径和，在递归向下的过程中是**唯一确定**的。于是判据可以改写成：

> `u` 不足 $\iff$ 经过 `u` 的所有路径和中最大的那个 $< limit$

这正是我们需要的返回值：**经过 `u` 的根-叶路径和的最大值**。一旦它 $< limit$，`u` 就该被删，用 $-\infty$ 作为「此路不通」的哨兵向上汇报。每个节点只算一次，$O(n)$ 完成。

图 1 借用示例 2 的数据（`limit = 22`）展示这个视角：叶 1、3 的路径和 21、20 不足被删，节点 11 只剩 7、节点 4 只剩 5；而叶 5 的路径和恰好 22，等于 `limit` 仍算充足。

还有一个容易忽略的推论：**删除是向下封闭的**。若 `u` 不足，则 `u` 子树中任意节点 `v` 的所有根-叶路径都要经过 `u`，和只会更小，故 `v` 也不足。所以删掉 `u` 时整棵子树一起丢弃，结果依然是一棵合法二叉树，不需要额外修补。

### 3.3 算法流程

![一次后序 DFS 的三个分支](images/wc140_q3_dfs_flow.svg)

定义 `dfs(node, pre)` 返回「经过 `node` 的根-叶路径和的最大值」，$-\infty$ 表示该子树被删：

1. `node` 为空，返回 $-\infty$；
2. 令 $cur = pre + \text{val}(node)$；若 `node` 是叶子，返回 $cur \ge limit$ 时的 $cur$，否则返回 $-\infty$；
3. 否则递归 `l = dfs(left, cur)`、`r = dfs(right, cur)`；
4. 若 `l` 为 $-\infty$ 则 `node.left = None`；若 `r` 为 $-\infty$ 则 `node.right = None`；
5. 若 `l`、`r` 都是 $-\infty$，说明经过 `node` 的路径全部不足，返回 $-\infty$；否则返回 $\max(l, r)$。

根返回 $-\infty$ 时答案是 `null`，否则直接返回 `root`（孩子的指针已经就地改好）。

**为什么这满足「同时删除」**：删除次序不影响结论。$-\infty$ 自底向上传递，一个节点的去留只取决于它在**原树**中的最大路径和，与其它分支何时被删无关——第 5 步只把「所有路径都不足」这一事实向上汇报，正是同时性要求的语义。

### 3.4 示例演算

![示例 3 的逐节点走查](images/wc140_q3_example_walkthrough.svg)

**示例 3**（`limit = -1`）只有两条根-叶路径，和为 $-2$ 与 $2$，走查见上图：节点 2 与 $-5$ 的最大路径和均为 $-2 < -1$，被删；节点 $-3$、4 与根 1 的最大路径和为 $2 \ge -1$，保留，输出 `[1,null,-3,4]`。注意删掉 $-5$ 后节点 2 已无孩子，但它的「不足」在原树中就已成立，级联与判据并不冲突。

**示例 1**（`limit = 1`）的 8 条路径和依次是 $15, 16, -195, -195, -83, -82, -88, 25$：只有 $25$（$1\to3\to7\to14$）与 $15/16$（$1\to2\to4\to8/9$）达标。四条经过 $-99$ 的路径与经过 7 左侧 $-99$ 的那条路径（共 5 条）全灭，于是 4 个 $-99$ 节点连同 12、13 一起被删；节点 4 与 7 因各自孩子中仍有达标路径而保留，输出 `[1,2,3,4,null,null,7,8,9,null,14]`。

**示例 2**（`limit = 22`）的 5 条路径和是 $27, 21, 30, 22, 20$：$21$ 与 $20$ 对应的叶 1、3 被删，节点 11 只剩 7、节点 4 只剩 5，而路径和为 $22$ 的叶 5 恰好达标，输出 `[5,4,8,11,null,17,4,7,null,null,null,5]`。

## 4. 算法细节

1. **返回值语义要统一**：全程只返回「经过该节点的最大根-叶路径和」，叶子返回 $cur$ 或 $-\infty$，内部节点返回 $\max(l,r)$ 或 $-\infty$。不要在某一层换成「后缀和」再换算回去，叶子和单孩子节点上最容易因此算错。
2. **先递归、后判空**：第 3 步必须先把 `l`、`r` 存进局部变量，再去改 `node.left/right`。若先写 `node.left = None` 再调用 `dfs(node.left, ...)`，就会把「孩子原本不存在」与「孩子刚被删」混为一谈，漏掉整段递归。
3. **叶子用原始结构判定**：`node.left is None and node.right is None`。单孩子节点不算叶子；它的唯一孩子被删后，本节点在**第 5 步**自然消亡，而不是被重新当成叶子判一次。
4. **哨兵取值**：$-\infty$ 不参与加法。合法路径和范围是 $[-5\times10^8, 5\times10^8]$，C++ 用 `LLONG_MIN / 4`、Python 用 `float("-inf")` 都不会与真实值混淆；**切忌用 0 当哨兵**（本题路径和可正可负，0 是合法值）。
5. **严格小于**：不足要求「全都严格小于 `limit`」，所以达标判定写 `cur >= limit`；写成 `>` 会误删路径和恰好等于 `limit` 的节点（示例 2 的叶 5 就是这种边界）。
6. **递归深度**：$n$ 可达 5000，链状树深度 5000。C++ 默认栈够用；Python 默认递归上限 1000，递归实现要加 `sys.setrecursionlimit(20000)`，或改成显式栈的后序遍历。
7. **就地修改的合法性**：本题允许就地剪枝（`node.left = None`），因为被删节点之后不会再被访问；若要求不破坏输入树，就要返回 `(新子树, 最大值)` 二元组或先做深拷贝。

## 5. 正确性证明

设原树为 $T$，$pre(u)$ 为根到 $u$ 父亲的路径和。对节点 $u$，记 $S(u)$ 为「$T$ 中所有经过 $u$ 的根-叶路径的路径和」构成的集合。

**引理 1（返回值语义）**：对任意节点 `u`，`dfs(u, pre(u))` 的返回值为 $\max S(u)$（当 $\max S(u) \ge limit$），否则为 $-\infty$。

**证明**：对 `u` 的子树高度归纳。

- `u` 是叶子：$S(u)$ 中只有 $pre(u) + \text{val}(u) = cur$ 一个元素，按第 2 步返回 $cur$ 或 $-\infty$，成立。
- `u` 有孩子：设 $L$、$R$ 为左右子树（可能为空）。经过 `u` 的根-叶路径必然紧接着经过 `u` 的某个孩子，故 $S(u) = S(L) \cup S(R)$，空子树对应空集。于是 $\max S(u) = \max(\max S(L), \max S(R))$；由归纳假设 $l = \max S(L)$ 或 $-\infty$、$r = \max S(R)$ 或 $-\infty$，第 5 步的返回值恰为 $\max S(u)$；当 $l = r = -\infty$ 时 $S(u) = \emptyset$，返回 $-\infty$。∎

**引理 2（删除判据）**：`u` 不足 $\iff \max S(u) < limit$；且 `u` 不足时，其子树中所有节点都不足。

**证明**：由定义，`u` 不足 $\iff$ 每个 $s \in S(u)$ 都满足 $s < limit$ $\iff$ $\max S(u) < limit$（`u` 的子树至少含一片叶子，故 $S(u) \neq \emptyset$）。若 `u` 不足、`v` 为 `u` 的后代，则 $S(v) \subseteq S(u)$，故 $\max S(v) < limit$，`v` 也不足。∎

**定理**：算法返回的树恰为 $T$ 删去所有不足节点（连同其子树）后的树。

**证明**：由引理 1，算法返回值 $-\infty$ 与「该节点不足」等价（引理 2），而算法只在某孩子返回 $-\infty$ 时把对应边置空，因此保留下来的节点集合恰为 $G = \{u : \max S(u) \ge limit\}$。由引理 2 的向下封闭性，$G$ 对「祖先-后代」关系封闭：$u \in G$ 蕴含其所有祖先也在 $G$，故 $G$ 诱导的子树连通、以 `root` 为根；若 `root` 不足则 $G = \emptyset$，算法返回 `null`。两种情况都恰是题目要求的输出。∎

## 6. 复杂度分析

- **时间**：$O(n)$。每个节点恰好被 `dfs` 调用一次，函数体内只有常数次加法、比较与指针赋值，没有重复遍历。
- **空间**：$O(h)$，$h$ 为树高，开销全部来自递归栈；链状树最坏 $h = n = 5000$，平衡树为 $O(\log n)$。除递归栈外只用常数个变量，没有额外数组或哈希表。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    const long long NEG = LLONG_MIN / 4;   // 哨兵：该子树应被删除

    // 返回经过 node 的「根-叶」路径和最大值；pre 为根到 node 父节点的路径和
    long long dfs(TreeNode* node, long long pre, long long limit) {
        if (!node) return NEG;
        long long cur = pre + node->val;
        if (!node->left && !node->right)            // 叶子
            return cur >= limit ? cur : NEG;
        long long l = dfs(node->left, cur, limit);
        long long r = dfs(node->right, cur, limit);
        if (l == NEG) node->left = nullptr;         // 剪掉不足的左子树
        if (r == NEG) node->right = nullptr;        // 剪掉不足的右子树
        if (l == NEG && r == NEG) return NEG;       // 所有路径都不足 -> 本节点也删
        return max(l, r);
    }

    TreeNode* sufficientSubset(TreeNode* root, int limit) {
        return dfs(root, 0, (long long)limit) == NEG ? nullptr : root;
    }
};
```

### Python

```python
class Solution:
    def sufficientSubset(self, root: Optional[TreeNode], limit: int) -> Optional[TreeNode]:
        NEG = float("-inf")

        def dfs(node, pre):
            # 返回经过 node 的「根-叶」路径和最大值；-inf 表示整棵子树被删
            if node is None:
                return NEG
            cur = pre + node.val
            if node.left is None and node.right is None:    # 叶子
                return cur if cur >= limit else NEG
            l = dfs(node.left, cur)
            r = dfs(node.right, cur)
            if l == NEG:
                node.left = None                            # 剪掉不足的左子树
            if r == NEG:
                node.right = None                           # 剪掉不足的右子树
            if l == NEG and r == NEG:
                return NEG                                  # 所有路径都不足 -> 本节点也删
            return max(l, r)

        return root if dfs(root, 0) != NEG else None
```

> 💡 若评测环境的递归上限只有默认的 1000（Python），请在 `class Solution` 之前补 `import sys; sys.setrecursionlimit(20000)`；链状树深度 5000 时这不是可选项。

## 8. 边界情况与易错点

1. **单节点树**：`root = [5], limit = 6` → 返回 `[]`；`limit = 5` → 返回 `[5]`（相等即充足）。根被删时必须返回 `null`，不能把原 `root` 返回。
2. **limit 为负、节点全负**：示例 3 就是这种数据，任何「最大值初值取 0」的写法都会判错；哨兵必须是 $-\infty$，不能是 0 或某个「差不多够小」的常数——合法路径和最小可达 $-5\times10^8$，与哨兵之间必须留足余地。
3. **单孩子节点**：唯一的孩子被删后，该节点没有任何剩余路径，必须**自己也被删**（示例 3 的节点 2）。若把它当成新叶子重新判 `cur >= limit`，反而可能错误保留。
4. **不要多轮重判**：删除的向下封闭性保证一次后序足够；若删完对新树再判一遍，最多要重扫 $h$ 轮、复杂度升到 $O(nh)$，而且判据本身已蕴含级联，纯属多余。
5. **递归深度 5000**：Python 需调高递归上限；无法调高时改用显式栈模拟后序（先记录访问顺序，再逆序处理）。C++ 用 `long long` 累加 `pre + node->val`，避免换成更大参数后溢出。
6. **空孩子与哨兵不可混用**：`dfs(None)` 必须返回 $-\infty$，否则「唯一孩子被删」与「本来没有孩子」无法区分，级联删除会失效。
7. **返回值是指针**：LeetCode 期望返回 `TreeNode*` / `TreeNode | None`；就地剪枝后返回 `root` 本身，而不是 `root->left` 或新建的节点。
