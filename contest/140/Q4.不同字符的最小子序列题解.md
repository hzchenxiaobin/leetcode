# LeetCode 不同字符的最小子序列 题解

## 1. 题目概述

- **标题 / 题号**：不同字符的最小子序列（#1081，medium）
- **链接**：https://leetcode.cn/problems/smallest-subsequence-of-distinct-characters/
- **来源**：LeetCode 第 140 场周赛 Q4
- **难度**：中等
- **标签**：栈、单调栈、贪心、字符串、哈希表

**题意**：给定字符串 `s`，返回 `s` 的一个**子序列**，要求它包含 `s` 中出现的**所有不同字符**、每个字符**恰好出现一次**，并且在所有满足条件的子序列中**字典序最小**。子序列保留下标相对顺序，但不要求连续。

**约束**：

- $1 \le \lvert s \rvert \le 1000$
- `s` 仅由小写英文字母组成
- 本题与 [316. 去除重复字母](https://leetcode.cn/problems/remove-duplicate-letters/) 完全相同，只是换了叙述方式

## 2. 示例

**示例 1**

```text
输入：s = "bcabc"
输出："abc"
解释：不同字符为 a、b、c。候选子序列有 "bac"、"bca"、"abc" 等，
      "abc" 字典序最小。
```

**示例 2**

```text
输入：s = "cbacdcbc"
输出："acdb"
解释：不同字符为 a、b、c、d。a 是最小字符且出现在位置 2，其后仍能凑齐 b、c、d，
      于是让它当首字符；再在子问题里依次定出 c、d、b，得到 "acdb"。
```

## 3. 解题思路

### 3.1 暴力思路

可行解的形态很明确：**为每个不同字符挑一个出现位置**，再按下标升序把字符拼起来。设不同字符数为 $k$、字符 $c$ 出现 $\mathrm{cnt}(c)$ 次，则候选解共有

$$\prod_{c} \mathrm{cnt}(c)$$

个。最坏情况 $n = 1000$、26 个字符时，这个乘积是天文数字；即便用「枚举 $2^n$ 个子序列再筛选」也是 $O(n 2^n)$，立刻爆炸。枚举 $k$ 个字符的全排列（$k$ 可达 26）同样是 $26!$ 量级。

暴力的浪费在于：**它先把所有候选都造出来再比较字典序**。而字典序是从左到右逐位比较的——只要我们能证明「某一位该放什么」，就能一次性定下这一位，不必枚举。

### 3.2 核心观察：单调栈 + 「还有后援」判定

![贪心三规则：跳过、弹栈、压入](images/wc140_q4_greedy_rules.svg)

从左到右扫描，维护一个**候选栈**：栈中的字符就是「已确定的答案前缀」，其下标严格递增。

- **规则 1（跳过）**：若 $c$ 已在栈中，直接跳过。更靠前的那次 $c$ 已经保证字符 $c$ 被选中，再压一次只会重复。
- **规则 2（弹栈）**：若栈顶 $x > c$ 且 $x$ 在 $i$ 之后还会出现（$\text{last}[x] > i$），就弹出 $x$。理由是把 $x$ 挪到后面那次出现去取，字符一个不少；而 $c$ 因此提前到 $x$ 原来的位置，由于 $c < x$，答案在这一位上严格更小。
- **规则 3（压入）**：若栈顶 $x < c$，或 $x$ 之后不再出现（$\text{last}[x] < i$），则弹掉 $x$ 就永远补不回来，只能保留它并把 $c$ 压栈。

> 💡 **一句话**：单调栈保证「能小就小」，`last[]` 保证「敢删才删」。两个条件缺一不可——只比较大小会把必须保留的字符误删，只看 `last[]` 又退化成原顺序。

### 3.3 算法流程

![算法流程：预处理 last、跳过、弹栈、压入](images/wc140_q4_stack_flow.svg)

1. 预处理 $\text{last}[c]$：$c$ 在 `s` 中**最后一次**出现的下标，$O(n)$。
2. 从左到右枚举 $i$，令 $c = s[i]$；若 `inStack[c]` 为真，跳过（规则 1）。
3. `while` 循环：只要「栈非空」且「栈顶 $> c$」且「$\text{last}[$栈顶$] > i$」，就弹出栈顶并清除它的 `inStack` 标记（规则 2）。三个条件必须同时成立，缺一不可。
4. 把 $c$ 压栈，置 `inStack[c] = true`（规则 3）。
5. 扫描结束后，栈内字符按「底 → 顶」拼起来就是答案。

由于每个字符最多入栈一次、出栈一次，第 2~4 步的总代价是均摊 $O(1)$，整个过程 $O(n)$。

### 3.4 示例演算

![示例演算：s = "cbacdcbc" 的 8 步走查](images/wc140_q4_walkthrough.svg)

对 `s = "cbacdcbc"`，$\text{last}[c]=7,\ \text{last}[b]=6,\ \text{last}[a]=2,\ \text{last}[d]=4$：

| $i$ | $c$ | 动作 | 栈（底 → 顶） |
|-----|-----|------|----------------|
| 0 | c | 栈空，压入 | `c` |
| 1 | b | `c > b` 且 `last[c]=7 > 1` → 弹 c，压入 b | `b` |
| 2 | a | `b > a` 且 `last[b]=6 > 2` → 弹 b，压入 a | `a` |
| 3 | c | `a < c`，不弹，压入 | `a c` |
| 4 | d | `c < d`，不弹，压入 | `a c d` |
| 5 | c | 已在栈中 → 跳过 | `a c d` |
| 6 | b | `d > b` 但 `last[d]=4 < 6` → **不能弹**，压入 b | `a c d b` |
| 7 | c | 已在栈中 → 跳过 | `a c d b` |

最终返回 `"acdb"`。注意 $i=6$ 这一步：`d` 虽然比 `b` 大，但 `d` 在 $i=4$ 之后不再出现，弹掉就丢字符，所以「大」并不构成弹出理由。

## 4. 算法细节

1. **`last[]` 用一遍扫描填满**：初始化为 $-1$，从左到右覆盖写入，最后留下的就是最后出现位置。这一步不可省，它是「能否安全删除」的唯一依据。
2. **`inStack[]` 必须与栈同步**：弹栈时立刻置回 `false`。若忘记清除，该字符之后再也无法入栈，答案会缺字符；这是本题最高频的 bug。
3. **`while` 条件的顺序与语义**：`!st.empty()` 放最前（短路求值，避免访问空栈）；中间是 `st.back() > c`（大小关系）；最后是 `last[st.back()] > i`（后援判定）。后两个条件可以互换，但 `st.empty()` 必须最先判，否则空栈时 `st.back()` 是未定义行为。
4. **后援判定的含义是「后面还有」**：条件写作 `last[top] > i`。由于 $s[i] = c \ne \text{top}$，$\text{last}[\text{top}] = i$ 不可能发生，所以写成 `>=` 结果恰好相同；但语义上应写 `>`。真正不能省的是这个条件本身——只留「栈顶 $> c$」时，`"cba"` 会被弹成 `"a"`、`"cbacdcbc"` 会被弹成 `"abc"`，都缺字符。
5. **「跳过」必须放在 `while` 之前**：若 $c$ 已在栈中，先跑弹栈循环会把本该保留的栈顶弹掉。例如 `"abacb"` 处理 $i=2$ 的第二个 `a` 时，栈顶 `b` 满足 `b > a` 且 `last[b]=4 > 2`，会被误弹，`b` 只能推迟到末尾，答案从 `"abc"` 退化成 `"acb"`。
6. **用数组 / `string` 充当栈**：`vector<char>` 或直接 `string` 当栈，最后一次性 `return`；不要用「在字符串中间插入」的方式维护答案，那会引入 $O(n^2)$ 的搬移。
7. **等价写法：剩余计数**：把 `last[]` 换成「每个字符还剩几次」（每处理一个字符就减一），条件改写为 `remaining[top] > 0`，与 `last[top] > i` 完全等价；这种写法在「每个字符至少出现 $k$ 次」的进阶题（如 2030）中更容易推广。

## 5. 正确性证明

记 $D$ 为 `s` 的不同字符集合，$\text{last}[c]$ 为 $c$ 的最后出现位置，$M = \min_{c\in D}\text{last}[c]$，$g$ 为 $s[0..M]$ 中的最小字符，$p$ 为 $g$ 在 $s[0..M]$ 中的**最左**出现位置。

**引理 1（栈始终是合法候选）**：任意时刻，栈内字符互不相同，且按栈顺序对应 `s` 中一个严格递增的下标序列，故栈内容是 `s` 的子序列。

**证明**：入栈按 $i$ 递增进行，因此栈内下标天然递增；弹栈只删除元素，不改变其余元素的相对顺序。重复方面：字符 $c$ 在栈中时，后续出现的 $c$ 会被规则 1 跳过；$c$ 被弹出时立即清除标记，可再次入栈——因此栈内任何时刻不会同时存在两个相同字符。∎

**引理 2（不遗漏任何字符）**：算法结束时，栈中包含 $D$ 中的每个字符。

**证明**：取任意 $c \in D$，考察处理 $i = \text{last}[c]$ 的时刻。若此时 $c$ 已在栈中，则结论成立；否则 $c$ 被压入。此后若 $c$ 在某个时刻 $j$ 被弹出，弹出条件要求 $\text{last}[c] > j$；但 $j \ge \text{last}[c]$，矛盾。所以在 $\text{last}[c]$ 之后 $c$ 一直留在栈中，直到结束。∎

**引理 3（首字符引理）**：字典序最小的可行子序列，其首字符必为 $g$。

**证明**：
1. **任何可行解的首字符 $\ge g$**：可行解为每个 $c$ 选一个位置 $q(c)$。取 $c_0$ 满足 $\text{last}[c_0] = M$，则 $q(c_0) \le \text{last}[c_0] = M$，故最小选中位置不超过 $M$，首字符属于 $\{s[0..M]\}$，因而不小于 $g$。
2. **存在以 $g$ 开头的可行解**：在 $p$ 处选 $g$；对任意 $c \ne g$，有 $\text{last}[c] \ge M \ge p$，若 $\text{last}[c] = p$ 则 $s[p] = c \ne g$，矛盾，故 $\text{last}[c] > p$。于是其余字符都能在其最后出现处（都在 $p$ 之后）被选中，得到一个以 $g$ 为最前字符的可行解。∎

**引理 4（算法输出以 $g$ 开头，且 $g$ 不再出栈）**：

**证明**：
1. **处理到 $p$ 时栈被清空**：设 $t$ 是此刻栈中某个下标 $< p$ 的字符（若栈空则结论显然）。$t$ 出现在 $s[0..M]$ 内，且 $t \ne g$（$p$ 是 $g$ 的最左出现），故 $t > g$；又 $\text{last}[t] \ge M \ge p$，而 $\text{last}[t] = p$ 会推出 $t = g$，矛盾，故 $\text{last}[t] > p$。于是弹出条件对栈中每个元素都成立，栈被逐层弹空，$g$ 压入并成为栈底。
2. **$g$ 不会再被弹出**：若 $g$ 在某时刻 $j$ 被弹出，需要 $s[j] < g$ 且 $\text{last}[g] > j$。由 $g$ 是 $s[0..M]$ 的最小值，$s[j] < g$ 迫使 $j > M$。取 $w$ 满足 $\text{last}[w] = M$：若 $w = g$，则 $\text{last}[g] = M < j$，与 $\text{last}[g] > j$ 矛盾；若 $w \ne g$，则 $w$ 在 $M > p$ 处还有出现，它在 $p$ 之后入栈、位于 $g$ 之上，且此后不会被弹出（弹出需 $\text{last}[w] >$ 当前下标 $\ge M$，矛盾），于是 $g$ 之上始终有元素，$g$ 不可能成为栈顶。∎

**定理**：算法返回的字符串就是字典序最小的可行子序列。

**证明**：由引理 1、2，返回值是可行子序列（含全部不同字符、各一次、保持顺序）。由引理 4，它先输出 $g$；而引理 4 第一段还说明 $p$ 之后栈为空、每个 $c \ne g$ 都满足 $\text{last}[c] > p$，因此处理 $s[p+1..]$ 的过程与「在 $s[p+1..]$ 上、字符集 $D\setminus\{g\}$ 上运行本算法」逐步一致。对 $\lvert D \rvert$ 做强归纳（$\lvert D \rvert = 1$ 时唯一字符只出现一种选法）：每一层依据引理 3 都输出了该子问题可能的最小首字符，逐层累加即得字典序最小。∎

## 6. 复杂度分析

- **时间**：$O(n)$。预处理 `last[]` 为 $O(n)$；主循环遍历 $n$ 个位置，每个字符至多入栈一次、出栈一次，`while` 的总弹出次数不超过 $n$，故均摊 $O(n)$；最后拼接栈内容 $O(\lvert D \rvert) \le O(n)$。
- **空间**：$O(\lvert\Sigma\rvert) = O(1)$（不计输入与输出）。`last[]`、`inStack[]` 各 26 个槽，栈最多 26 个字符；即使 $n$ 增长，额外空间也不变。

## 7. 参考代码

### C++

```cpp
#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    string smallestSubsequence(string s) {
        int n = s.size();
        vector<int> last(26, -1);
        for (int i = 0; i < n; ++i) last[s[i] - 'a'] = i;   // 最后出现位置

        string st;                                          // 用 string 当栈
        vector<bool> inStack(26, false);
        for (int i = 0; i < n; ++i) {
            int c = s[i] - 'a';
            if (inStack[c]) continue;                       // 规则 1：已在栈中
            while (!st.empty() && st.back() - 'a' > c &&
                   last[st.back() - 'a'] > i) {             // 规则 2：栈顶更大且还有后援
                inStack[st.back() - 'a'] = false;           // 弹栈必须同步清标记
                st.pop_back();
            }
            st.push_back(s[i]);                             // 规则 3：压入
            inStack[c] = true;
        }
        return st;
    }
};
```

### Python

```python
class Solution:
    def smallestSubsequence(self, s: str) -> str:
        last = {c: i for i, c in enumerate(s)}      # 每个字符的最后出现位置
        stack = []                                  # 候选栈：答案前缀
        in_stack = set()                            # 与栈同步的标记
        for i, c in enumerate(s):
            if c in in_stack:                       # 规则 1：已选中过
                continue
            while stack and stack[-1] > c and last[stack[-1]] > i:
                in_stack.discard(stack.pop())       # 规则 2：弹出并清标记
            stack.append(c)                         # 规则 3：压入
            in_stack.add(c)
        return "".join(stack)
```

## 8. 边界情况与易错点

1. **全部字符相同**：`"aaaa"` → `"a"`。第一个 `a` 入栈，后面三次都命中「已在栈中」被跳过，`while` 永不触发。
2. **严格递增**：`"abc"` → `"abc"`。栈顶永远小于当前字符，一次都不弹，答案即原串。
3. **严格递减且无重复**：`"cba"` → `"cba"`。处理 $i=1$ 时栈顶 `c > b`，但 `last[c] = 0 < 1`，不满足后援条件，不能弹；$i=2$ 时同理——这正是 `last[]` 存在的意义。
4. **用首次出现代替最后出现**：把 `last[]` 换成 `first[]` 会严重出错。例如 `"babaaab"`，正确答案是 `"ab"`（下标 1 的 `a` 在下标 2 的 `b` 之前），而按 `first[]` 判断时 `first[b] = 0 < 1`，弹栈条件永不成立，只能得到 `"ba"`。`first[]` 表达不了「后面还有」，条件过于保守。
5. **忘记清除 `inStack`**：弹栈后不置 `false`，该字符之后无法再入栈（被规则 1 当成「已在栈中」跳过），结果缺字符。例如 `"babaaab"` 会得到 `"a"`——`b` 被弹出后再也进不来，而正确答案是 `"ab"`。
6. **把「跳过」写在 `while` 之后**：这不会造成重复字符（`while` 遇到 `top == c` 就停下），但会误弹栈顶，`"abacb"` 得到 `"acb"` 而不是 `"abc"`；「跳过」必须放在弹栈之前。
7. **字符集假设**：代码用 26 个槽（`s[i] - 'a'`），题目保证只含小写字母；若换字符集（大写、Unicode），需要改 `map`，否则数组越界。
8. **空串不会被输入**：约束 $n \ge 1$，但值得让代码对空串安全（`last` 为空、栈为空、返回 `""`），便于复用。
