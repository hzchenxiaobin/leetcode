# LeetCode 两个数字的最大乘积 题解

## 1. 题目概述

- **标题 / 题号**：两个数字的最大乘积（#3536，easy）
- **链接**：https://leetcode.cn/problems/maximum-product-of-two-digits/
- **来源**：LeetCode 第 448 场周赛 Q1
- **难度**：简单
- **标签**：数学、排序

**题意**：给定正整数 `n`，从 `n` 的十进制表示中**任选两个数位**（两个不同位置；同一数字出现多次时可以重复选用），返回它们乘积的**最大值**。

**约束**：

- `10 <= n <= 10^9`，即 `n` 至少 2 位、至多 10 位
- 数位取值 `0`~`9`，全部非负

## 2. 示例

**示例 1**

```text
输入：n = 31
输出：3
解释：数位为 [3, 1]，唯一的一对乘积为 3 × 1 = 3。
```

**示例 2**

```text
输入：n = 22
输出：4
解释：数位为 [2, 2]，数字 2 出现两次，可重复选用：2 × 2 = 4。
```

**示例 3**

```text
输入：n = 124
输出：8
解释：数位为 [1, 2, 4]，所有数位对乘积为 2、4、8，最大为 2 × 4 = 8。
```

**示例 4（下界）**

```text
输入：n = 10
输出：0
解释：数位为 [1, 0]，唯一乘积 1 × 0 = 0。
```

## 3. 解题思路

### 3.1 暴力思路

把 `n` 拆成数位数组，枚举全部 $\binom{d}{2}$ 个数位对（$d \le 10$，至多 45 对），取乘积最大值，时间 $O(d^2)$。本题数据下完全能过——签到题的价值不在复杂度，而在沉淀**从题面到代码的最短路径**：一趟扫描维护前二大。

### 3.2 核心观察：数位非负 → 最大 × 次大

![两个最大数位概念图](images/wc448_q1_two_largest_digits.svg)

设 `n` 的数位多重集降序排列为 $e_1 \ge e_2 \ge \dots \ge e_d$（$d \ge 2$）。

> 💡 **关键观察**：数位全部落在 $[0, 9]$，**非负**。非负数的乘积不存在「负负得正」的翻盘分支（对照 [628. 三个数的最大乘积](https://leetcode.cn/problems/maximum-product-of-three-numbers/)），所以**最大乘积一定是最大的两个数位之积** $e_1 \times e_2$。

注意是**多重集合意义下的前二大**：若最大数位只出现一次（如 `n = 19`），第二个因子必须取真实的次大数位 `1`，答案 `9 × 1 = 9` 而不是 `9 × 9 = 81`——这是本题唯一的思维陷阱。

### 3.3 算法流程：单趟扫描维护 (a, b)

![单趟扫描流程图](images/wc448_q1_scan_flow.svg)

用 `n % 10` 逐位取出、`n /= 10` 去掉个位，同时维护两个变量 $a \ge b$（已处理数位的最大与次大）：

1. 取出个位 $d = n \bmod 10$。
2. 若 $d \ge a$：旧最大退居次大，`b = a; a = d`。
3. 否则若 $d > b$：$d$ 顶替次大，`b = d`。
4. 否则两个变量都不动。
5. `n /= 10`，回到第 1 步，直到 `n = 0`。
6. 返回 `a * b`。

### 3.4 示例演算

![示例演算走查](images/wc448_q1_walkthrough.svg)

以 `n = 2943` 为例（从低位往高位取）：

| 步骤 | 取出 d | a（最大） | b（次大） | 剩余 n |
|------|--------|-----------|-----------|--------|
| 初始 | — | 0 | 0 | 2943 |
| ① | 3 | 3 | 0 | 294 |
| ② | 4 | 4 | 3 | 29 |
| ③ | 9 | 9 | 4 | 2 |
| ④ | 2 | 9（不变） | 4（不变） | 0 |

第④步 $d = 2$：$2 < 9$ 且 $2 < 4$，`a`、`b` 均不更新。最终答案 $a \times b = 9 \times 4 = 36$（数位 9 只出现一次，次大取 4）。

## 4. 算法细节

1. **数位拆解模板**：`d = n % 10` 取个位、`n /= 10` 去个位，从低位到高位处理，无需转字符串。
2. **前二大维护模板（top-2 pattern）**：三分支更新 `(a, b)`。分支内必须**先** `b = a` **再** `a = d`——顺序写反会把次大也覆盖成 `d`，旧最大值丢失。Python 用元组赋值 `a, b = d, a` 天然避免。
3. **初始化为 0 的安全性**：数位非负，初始状态可看成「已处理多重集 $\{0, 0\}$」，其前二大恰为 $(0, 0)$；只要真实数位至少 2 个（$n \ge 10$ 保证），并入两个 0 不会改变前二大。若推广到可能为负的元素，必须初始化为 $-\infty$。
4. **Python 捷径**：$d \le 10$，直接 `sorted(str(n))` 取末两位相乘，与单趟扫描无本质差别；单趟写法更能体现 top-2 模板的可迁移性。
5. **乘积上界**：$9 \times 9 = 81$，任何整型都安全。

## 5. 正确性证明

**引理 1（非负乘法的单调性）**：若 $0 \le x \le a$ 且 $0 \le y \le b$，则 $xy \le ab$。

**证明**：由 $y \ge 0$ 与 $x \le a$ 得 $xy \le ay$；由 $a \ge 0$ 与 $y \le b$ 得 $ay \le ab$。串联即得。∎

**引理 2（数位对的界）**：设数位降序为 $e_1 \ge e_2 \ge \dots \ge e_d$（$d \ge 2$）。任取两个**不同位置**的数位 $p, q$（不妨 $p \ge q$），则 $p \le e_1$ 且 $q \le e_2$。

**证明**：把这两个位置的数位放进降序序列，设分别排第 $s$、$t$ 名且 $s < t$。则 $p = e_s \le e_1$（$s \ge 1$）；又 $t \ge 2$，故 $q = e_t \le e_2$。∎

**定理**：数位对乘积的最大值等于 $e_1 \times e_2$。

**证明**：

-（上界）任取不同位置数位对 $p, q$（$p \ge q \ge 0$），由引理 2 有 $0 \le p \le e_1$、$0 \le q \le e_2$，再由引理 1 得 $pq \le e_1 e_2$。
-（可达）降序第 1、2 名对应两个**不同位置**，取这一对，乘积恰为 $e_1 e_2$。

两者结合，最大值 $= e_1 e_2$。∎

**引理 3（单趟维护的不变式）**：任意时刻，$(a, b)$ 恰为「已处理数位多重集 $\cup \{0, 0\}$」的前二大。

**证明**：对处理步数归纳。初始多重集为 $\{0, 0\}$，前二大为 $(0, 0)$，成立。设当前不变式成立，新到达数位 $d$：

- 若 $d \ge a$：$d$ 不小于一切已处理元素，成为新最大；旧最大 $a$（$\ge$ 旧次大 $b$）退居次大。新前二大为 $(d, a)$，与更新 `b = a; a = d` 一致。
- 若 $b < d < a$：最大仍为 $a$；$d$ 超过旧次大 $b$ 成为新次大。新前二大为 $(a, d)$，与更新 `b = d` 一致。
- 若 $d \le b$：$d$ 进不了前二大，$(a, b)$ 不变，跳过一致。∎

由引理 3 与 §4 第 3 点（并入 $\{0, 0\}$ 不改变「至少两个非负数位」的前二大），循环结束时 $a = e_1$、$b = e_2$；再由定理，返回值 $a \times b$ 即为答案。

## 6. 复杂度分析

- **时间复杂度**：$O(d)$，其中 $d$ 为数位个数（$n \le 10^9$ 时 $d \le 10$），即 $O(\log n)$。每个数位只做常数次比较与赋值。
- **空间复杂度**：$O(1)$。仅 `a`、`b`、`d` 三个变量，不转字符串、不开数组。（Python 的 `sorted(str(n))` 写法需 $O(d)$ 额外空间，本题规模下无所谓。）

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maxProduct(int n) {
        int a = 0, b = 0;  // a >= b：已处理数位的最大与次大
        while (n > 0) {
            int d = n % 10;
            if (d >= a) {
                b = a;     // 先保存旧最大，再覆盖
                a = d;
            } else if (d > b) {
                b = d;
            }
            n /= 10;
        }
        return a * b;
    }
};
```

### Python

```python
class Solution:
    def maxProduct(self, n: int) -> int:
        a = b = 0
        while n:
            d = n % 10
            if d >= a:
                a, b = d, a  # 元组赋值：同时更新，避免覆盖丢失
            elif d > b:
                b = d
            n //= 10
        return a * b
```

## 8. 边界情况与易错点

1. **最大数位只出现一次（本题唯一陷阱）**：不能拿最大值自乘。`n = 19` → `9 × 1 = 9`，不是 `81`；`n = 124` → `4 × 2 = 8`。这就是必须维护「次大」的原因。
2. **含 0 数位**：`n = 10` → `0`。数位非负保证「取前二大」直接最优，不存在负数，无需讨论「负负得正」。
3. **恰好两位数**：循环跑两次，`a × b` 即两数位之积，无需特判。
4. **更新顺序写反**：写成 `a = d; b = a;` 会把 `b` 也赋成 `d`。如 `n = 2943` 会一路算成 `a = b = 9`，错误返回 `81`（正确答案 `36`）。
5. **溢出**：最大乘积 $9 \times 9 = 81$，`int` 绰绰有余。
6. **初始化**：`a = b = 0` 的安全性依赖「数位非负 + 至少两位」；若元素可能为负（推广题），应初始化为 `-inf`，否则负数位会被 0 压制。
7. **`d >= a` 与 `d > a` 均正确**：$d = a$ 时落入第二分支 `b = d` 同样能把次大顶上去（如 `n = 55` → `25`）。保持 `>=` 与「前二大」的定义对齐，更不易错。

**延伸思考**：

- **带负数版**：若数位可正可负，两数最大乘积 $= \max(e_1 e_2,\ f_1 f_2)$（$f_1 \le f_2$ 为最小两个），需同时维护前二大与前二小。
- **k 个数位版**：非负情形仍是「取前 k 大」；带负数则需按选取负数的个数分类讨论（或 DP）。

- **统计版**：返回取得最大乘积的数位对数量——排序后按「最大值个数 × 次大值个数」分类计数。
