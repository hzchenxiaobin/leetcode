# LeetCode 填充特殊网格 题解

## 1. 题目概述

- **标题 / 题号**：填充特殊网格（#3537，medium）
- **链接**：https://leetcode.cn/problems/fill-a-special-grid/
- **来源**：LeetCode 第 448 场周赛 Q2
- **难度**：中等
- **标签**：数组、分治、矩阵

**题意**：给定非负整数 $N$，把 $0 \sim 2^{2N}-1$ 共 $4^N$ 个整数**每个恰好一次**填入 $2^N \times 2^N$ 的网格，使其成为**特殊**网格：

- 右上角象限中的所有数字都**小于**右下角象限中的所有数字；
- 右下角象限中的所有数字都**小于**左下角象限中的所有数字；
- 左下角象限中的所有数字都**小于**左上角象限中的所有数字；
- 每个象限自身也是一个特殊网格（任何 $1 \times 1$ 网格天然特殊）。

返回一个满足条件的网格。

**约束**：

- $0 \le N \le 10$：网格最大 $1024 \times 1024 \approx 1.05 \times 10^6$ 格；
- 数值上界 $4^{10} - 1 = 1{,}048{,}575 < 2^{31} - 1$，`int` 全程安全。

> 💡 **读题关键**：三条不等式串成一条链——**右上 < 右下 < 左下 < 左上**，最小的数住在右上角、最大的住在左上角；"每个象限也是特殊网格"说明结构**自相似**，天然指向递归。

## 2. 示例

**示例 1**

```text
输入：N = 0
输出：[[0]]
解释：唯一可以放置的数字是 0，网格中只有一个位置。
```

**示例 2**

```text
输入：N = 1
输出：[[3,0],[2,1]]
解释：四个象限分别放 0（右上）、1（右下）、2（左下）、3（左上），0 < 1 < 2 < 3。
```

**示例 3**

```text
输入：N = 2
输出：[[15,12,3,0],[14,13,2,1],[11,8,7,4],[10,9,6,5]]
解释：右上象限拿 0~3，右下拿 4~7，左下拿 8~11，左上拿 12~15；
      每个象限内部再按同样规则排布。
```

## 3. 解题思路

### 3.1 暴力思路：枚举排列验证

网格共 $4^N$ 个格子与 $4^N$ 个数，最朴素的做法是枚举全排列逐个验证四条约束：$N=1$ 时 $4! = 24$ 种尚可手算，$N=2$ 时 $16! \approx 2 \times 10^{13}$ 已经爆炸，$N = 10$ 更是天文数字。更关键的是，这种做法完全浪费了题面给的信号——**约束本身就是一份施工图**，不等式链已把每个数该落在哪个象限讲得明明白白，照着摆即可，不需要任何"试错—回退"。

### 3.2 核心观察：不等式链就是施工图（连续值块 + 分治）

![核心观察：象限按右上→右下→左下→左上顺序领取连续数值块](images/wc448_q2_quadrant_allocation.svg)

推理链条只有三步：

1. **不等式是全称的**：右上 < 右下 < 左下 < 左上是**逐元素**成立的大小关系（传递后：右上的每个数都小于象限外的每个数），不是只比较各象限的最大最小值。
2. **鸽笼推出连续块**：四个象限各占 $4^{N-1}$ 个数。右上的每个数都小于象限外的每个数，故右上**必然恰好**是最小的 $4^{N-1}$ 个数 $\{0, \dots, 4^{N-1}-1\}$；同理右下、左下、左上依次领取第 2、3、4 段连续块。
3. **自相似递归**：每段都是连续区间，而"特殊"的定义对值域平移不变——把右下的数整体减去 $4^{N-1}$，子问题与原问题完全同构，继续四分即可。

> 💡 **答案唯一**：上述推理在每一层都被不等式强制，没有任何选择空间——特殊网格是**唯一**的，示例输出就是标准答案。两个哨兵坐标可直接自检：右上角 $(0,\ 2^N-1)$ 恒为 $0$，左上角 $(0,\ 0)$ 恒为 $4^N - 1$。

于是整个算法浓缩成一段四行递归：把区间 $[start,\ start + 4^n)$ 切成四段，按**右上 → 右下 → 左下 → 左上**顺序依次发给四个象限，各自递归。

### 3.3 算法流程：递归函数 fill(r, c, n, start)

![算法流程：fill 递归按象限顺序分配数值块](images/wc448_q2_recursion_flow.svg)

递归函数设计为 `fill(r, c, n, start)`：用区间 $[start,\ start + 4^n)$ 填充左上角为 $(r, c)$、边长 $2^n$ 的子网格：

1. **递归出口**：$n = 0$ 时子网格是 $1 \times 1$，直接 `grid[r][c] = start`。
2. **算两个量**：`half = 2^(n-1)`（子象限边长）、`block = 4^(n-1)`（每象限数值块大小），均用移位计算。
3. **四次递归**（严格串行，前一块填满才进入下一块）：
   - 右上：`fill(r, c + half, n-1, start)`
   - 右下：`fill(r + half, c + half, n-1, start + block)`
   - 左下：`fill(r + half, c, n-1, start + 2*block)`
   - 左上：`fill(r, c, n-1, start + 3*block)`

区间终点不必传参——恒为 $start + 4^n$，由 $n$ 唯一确定，少一个参数就少一处越界隐患。四次调用按序执行，块与块之间天然**不重不漏**。

### 3.4 示例演算：N = 2

![示例演算：N=2 递归展开与拼接](images/wc448_q2_walkthrough.svg)

$N = 2$ 的递归展开（`block = 4`）：

| 层级 | 调用 | 分到的区间 | 填出的子网格 |
|------|------|-----------|--------------|
| 0 | `fill(0, 0, 2, 0)` | $[0, 16)$ | 整个 $4 \times 4$ |
| 1 | ① `fill(0, 2, 1, 0)` | $[0, 4)$ | 右上 = `[[3,0],[2,1]]` |
| 1 | ② `fill(2, 2, 1, 4)` | $[4, 8)$ | 右下 = `[[7,4],[6,5]]` |
| 1 | ③ `fill(2, 0, 1, 8)` | $[8, 12)$ | 左下 = `[[11,8],[10,9]]` |
| 1 | ④ `fill(0, 0, 1, 12)` | $[12, 16)$ | 左上 = `[[15,12],[14,13]]` |

四块拼起来正是示例 3 的输出。注意每个 $2 \times 2$ 象限内部的排布与 $N=1$ 的答案**一模一样**——自相似肉眼可见。

## 4. 算法细节

1. **参数设计**：`fill(r, c, n, start)`——子网格左上角 + 边长指数 + 值域起点。区间终点恒为 $start + 4^n$，由 $n$ 唯一确定，**无需传参**；传了反而多一处越界风险。
2. **移位代替幂运算**：`half = 1 << (n - 1)` 即 $2^{n-1}$；`block = 1 << (2 * (n - 1))` 即 $4^{n-1}$。$N \le 10$ 时移位完全安全。
3. **顺序与偏移一一对应**：右上偏移 $0$、右下 $+\,block$、左下 $+2 \cdot block$、左上 $+3 \cdot block$。写完先拿 $N=1$ 自检——输出必须是 `[[3,0],[2,1]]`，一秒发现顺序错误。
4. **串行递归保证不重不漏**：四个子调用按序执行，每段值域只交给一个象限，格子与数值一一对应，无需任何 visited 标记。
5. **逐格闭式（扩展）**：把 $(r, c)$ 各写成 $N$ 位二进制，第 $i$ 位（从高到低）记为 $r_i, c_i$，则每格的值有闭式

$$\text{val}(r, c) = \sum_{i=1}^{N} \text{digit}(r_i, c_i)\cdot 4^{\,N-i},\qquad \text{digit}(r_i, c_i) = 2\,(1 - c_i) + \big(1 \oplus r_i \oplus c_i\big)$$

   验证 $(r, c) = (1, 2), N = 2$：两位分别是 $(0,1) \to 0$、$(1,0) \to 2$，$\text{val} = 0 \times 4 + 2 = 2$ ✓。这正是 **Z 序曲线（Morton order）**的旋转版本——标准四叉树按"左上→右上→左下→右下"交错坐标比特，本题换成"右上→右下→左下→左上"。用比特交错技巧可做到每格 $O(1)$ 直出；但递归写法已经 $O(4^N)$ 触底（输出本身就有 $4^N$ 格），比赛时选最不容易写错的。

## 5. 正确性证明

**引理 1（连续值块划分）**：任意 $2^N \times 2^N$（$N \ge 1$）特殊网格中，记 $q = 4^{N-1}$，则右上象限恰含数值 $\{0, 1, \dots, q-1\}$，右下恰含 $\{q, \dots, 2q-1\}$，左下恰含 $\{2q, \dots, 3q-1\}$，左上恰含 $\{3q, \dots, 4q-1\}$。

**证明**：由三条不等式的传递性，右上的每个数小于右下、左下、左上中的每个数。设 $S$ 为右上象限的数值集合（$|S| = q$），$T$ 为其余三个象限的数值集合（$|T| = 3q$），则 $\max S < \min T$。把 $0 \sim 4^N - 1$ 排成升序，$S$ 的元素必须整体排在 $T$ 的元素之前，而 $|S| = q$，故 $S$ 恰为前 $q$ 个数 $\{0, \dots, q-1\}$。在剩余的 $3q$ 个数上，约束链"右下 < 左下 < 左上"同样成立，对其重复上述论证，即得右下、左下、左上依次领取第 2、3、4 段连续块。∎

**引理 2（值域平移不变性）**：设网格 $G$ 的值域为 $[0, 4^n)$，$G + k$ 表示每格加 $k$ 后的网格（值域 $[k,\ k+4^n)$）。则 $G$ 满足象限不等式与"每个象限也是特殊网格"，当且仅当 $G + k$ 满足同样两条性质。

**证明**：象限间的"全部小于"是逐元素比较，对全体元素加减同一常数不改变任何一次比较的结果；"每个象限也是特殊网格"是递归性质，展开后同样只涉及子象限之间的相对大小。故两条性质在平移下均保持。∎

**定理（构造正确性）**：算法输出的网格是特殊网格。

**证明**：对 $n$ 归纳。$n = 0$：单格网格是 $1 \times 1$，天然特殊。设结论对 $n-1$ 成立（$n \ge 1$），记 $q = 4^{n-1}$。算法把 $[start,\ start + 4^n)$ 切成四段连续块，按右上、右下、左下、左上的顺序递归填充。由归纳假设，四个子网格在各自值域 $[start + j \cdot q,\ start + (j+1) \cdot q)$（$j = 0, 1, 2, 3$）上都是特殊网格；由引理 2，它们填入象限后"每个象限也是特殊网格"这一条成立。又对 $j = 0, 1, 2$ 有：第 $j$ 段的最大值 $start + (j+1)q - 1$ **小于**第 $j+1$ 段的最小值 $start + (j+1)q$，且段落发放顺序与象限顺序一致（右上→右下→左下→左上），故三条象限不等式逐元素成立。所以输出是特殊网格。∎

**推论（唯一性）**：特殊网格唯一，且恰为算法的输出。

**证明**：由引理 1，每一层每个象限分到哪段值域被不等式**强制**，没有选择余地；对每段的内部递归应用同样论证，直到 $1 \times 1$ 无自由度。故任意特殊网格与算法输出逐格相同。∎

## 6. 复杂度分析

- **时间复杂度**：$O(4^N)$。递归树恰有 $4^N$ 个叶子（每格只写一次），内部节点 $1 + 4 + \dots + 4^{N-1} = \frac{4^N - 1}{3}$ 个，每个节点只做常数次运算；$N = 10$ 时约 $1.4 \times 10^6$ 次操作，瞬间完成。
- **空间复杂度**：$O(4^N)$，即输出矩阵本身；递归栈深 $N + 1 \le 11$ 层，为常数级（不计输出时空间 $O(N)$）。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    vector<vector<int>> specialGrid(int n) {
        int size = 1 << n;
        vector<vector<int>> grid(size, vector<int>(size));
        fill(grid, 0, 0, n, 0);
        return grid;
    }

  private:
    // 用 [start, start + 4^n) 填充左上角为 (r, c)、边长 2^n 的子网格
    void fill(vector<vector<int>> &grid, int r, int c, int n, int start) {
        if (n == 0) {
            grid[r][c] = start;   // 1×1 递归出口
            return;
        }
        int half = 1 << (n - 1);         // 子象限边长 2^(n-1)
        int block = 1 << (2 * (n - 1));  // 每象限数值块大小 4^(n-1)
        fill(grid, r,        c + half, n - 1, start);             // 右上：最小块
        fill(grid, r + half, c + half, n - 1, start + block);     // 右下
        fill(grid, r + half, c,        n - 1, start + 2 * block); // 左下
        fill(grid, r,        c,        n - 1, start + 3 * block); // 左上：最大块
    }
};
```

### Python

```python
class Solution:
    def specialGrid(self, n: int) -> List[List[int]]:
        size = 1 << n
        grid = [[0] * size for _ in range(size)]

        def fill(r: int, c: int, n: int, start: int) -> None:
            if n == 0:
                grid[r][c] = start          # 1×1 递归出口
                return
            half = 1 << (n - 1)             # 子象限边长
            block = 1 << (2 * (n - 1))      # 数值块大小 4^(n-1)
            fill(r,        c + half, n - 1, start)              # 右上
            fill(r + half, c + half, n - 1, start + block)      # 右下
            fill(r + half, c,        n - 1, start + 2 * block)  # 左下
            fill(r,        c,        n - 1, start + 3 * block)  # 左上

        fill(0, 0, n, 0)
        return grid
```

> 💡 两个语言细节：① `1 << (2 * (n - 1))` 就是 $4^{n-1}$，用移位避免调用 `pow`；② 四个递归调用的书写顺序与 `start` 偏移一一对应，写完拿 $N=1$ 一秒自检（`[[3,0],[2,1]]`）。

## 8. 边界情况与易错点

1. **$N = 0$**：边长 $2^0 = 1$，递归出口直接写 `grid[0][0] = 0`，返回 `[[0]]`，无需特判。
2. **象限顺序写反（最高频错误）**：肌肉记忆的 Z 序是"左上→右上→左下→右下"，本题的链是**右上→右下→左下→左上**（从右上角出发的逆时针绕行）。顺序错了连 $N=1$ 的输出都不对，务必用 `[[3,0],[2,1]]` 自检。
3. **偏移与象限错位**：右上偏移 $0$、右下 $+\,block$、左下 $+2 \cdot block$、左上 $+3 \cdot block$。若偏移对了但发错了象限，会得到"数值块进错房间"的网格，$N=2$ 时哨兵 `(0,3) = 0`、`(0,0) = 15` 会立刻暴露。
4. **行列偏移写反**：右半是 `c + half`、下半是 `r + half`。若把行列对调会得到转置网格——转置后不等式链变成"左上 < 左下 < 右下 < 右上"，不再满足题意。
5. **溢出**：$4^{10} - 1 = 1{,}048{,}575 < 2^{31} - 1$，最大偏移 $3 \cdot 4^9 = 786{,}432$ 同样安全，`int` 全程无忧。
6. **Python 开矩阵**：用 `[[0] * size for _ in range(size)]`，不要 `[[0] * size] * size`——后者所有行共享同一个列表对象，赋值会互相串改。
7. **递归深度**：$N + 1 \le 11$ 层，无栈溢出风险；若 $N$ 放宽到 26 以上才需要考虑 `long long` 与显式栈迭代化。
