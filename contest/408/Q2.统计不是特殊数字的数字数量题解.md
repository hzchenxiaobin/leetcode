# LeetCode 统计不是特殊数字的数字数量 题解

## 1. 题目概述

- **标题 / 题号**：统计不是特殊数字的数字数量（#3233，medium）
- **链接**：https://leetcode.cn/problems/find-the-count-of-numbers-which-are-not-special/
- **来源**：LeetCode 第 408 场周赛 Q2
- **难度**：中等
- **标签**：数学、数论、埃拉托斯特尼筛

**题意**：给定两个正整数 $l$ 和 $r$。定义 $x$ 的**真因数**为 $x$ 的所有正因数中**除去 $x$ 本身**的那些。若一个数**恰好有且仅有两个真因数**，则称其为**特殊数字**（例如 $4$ 的真因数是 $1, 2$，是特殊数字；$6$ 的真因数是 $1, 2, 3$，不是）。返回区间 $[l, r]$ 内**不是**特殊数字的数量。

**约束**：

- $1 \le l \le r \le 10^9$

> 💡 **审题关键**：任何 $x > 1$ 的真因数里永远有 $1$；$1$ 本身的真因数个数是 $0$。「恰好两个真因数」等价于「恰好**三个**因数」——多出来的第三个正是 $x$ 自己。题面真正在问：区间里有多少个数恰有三个因数，再拿总数一减。

## 2. 示例

**示例 1**

```text
输入：l = 5, r = 7
输出：3
解释：区间 [5, 7] 内不存在特殊数字（2² = 4 < 5，3² = 9 > 7）。
```

**示例 2**

```text
输入：l = 4, r = 16
输出：11
解释：区间 [4, 16] 内的特殊数字为 4 和 9。
```

**补充示例（覆盖 l = 1 边界）**

```text
输入：l = 1, r = 10
输出：8
解释：特殊数字为 4 = 2² 和 9 = 3²；1 的真因数是空集，10 − 2 = 8。
```

## 3. 解题思路

### 3.1 暴力思路：逐个试除数因数

对 $[l, r]$ 内每个 $x$，试除到 $\sqrt{x}$ 数出全部因数，判断真因数个数是否为 $2$。单个判定 $O(\sqrt{r}) \approx 3 \times 10^4$，但区间长度最长达 $10^9$，总量 $10^{13}$ 步起步，必然超时。

瓶颈在于**一个一个看**：区间很长，但「特殊数字」在整个值域里其实**极其稀疏**（见下图与 §3.2）——值得先刻画出它的形状，再反着数。

### 3.2 核心观察：恰好两个真因数 ⟺ 质数的平方

![核心观察：因数成对、奇数因数必是平方数、中间因数必须是质数](images/wc408_q2_prime_square_insight.svg)

三步推理：

- **第一步（因数成对）**：$d$ 是 $x$ 的因数当且仅当 $x/d$ 是因数，两者围绕 $\sqrt{x}$ 对称配对。非完全平方数的因数两两配对，**个数必为偶数**。
- **第二步（奇数 ⟹ 平方数）**：因数个数为奇数（本题要的 $3$ 是奇数）⟹ $x = m^2$，此时 $m$ 自己与自己配对，是「落单」的那个因数。
- **第三步（中间那个必须是质数）**：$x = m^2$ 的因数至少包含 $1, m, x$。若 $m = a \cdot b$（$1 < a \le b < m$）还可分解，则 $a$ 也是 $x$ 的因数且不属于 $\{1, m, x\}$，因数个数就超过 $3$。反过来 $m = p$ 为质数时，$p^2$ 的因数**恰好**是 $1, p, p^2$ 三个。

$$\text{特殊数字} \iff \text{真因数恰两个} \iff \text{因数恰三个} \iff x = p^2\ (p\ \text{为质数})$$

对账：$4 = 2^2$ 的真因数 $\{1, 2\}$ ✓；$9 = 3^2$ 的 $\{1, 3\}$ ✓；$6 = 2 \times 3$ 的 $\{1, 2, 3\}$ ✗（3 个）；$16 = 4^2$ 的 $\{1, 2, 4, 8\}$ ✗（$m = 4$ 是合数）；质数 $7$ 的真因数只有 $\{1\}$ ✗。

于是问题瞬间塌缩：

$$\text{答案} = (r - l + 1) - \#\{\, p \text{ 为质数} : l \le p^2 \le r \,\}$$

由 $p^2 \le r \le 10^9$ 得 $p \le \lfloor\sqrt{r}\rfloor \le 31622$——全值域内的特殊数字总共只有 $\pi(31622) = 3401$ 个，**只需在区区 3 万多的范围内筛质数**，一次埃氏筛就够了。

> 💡 **换个视角**：这是典型的「正向枚举 → 逆向刻画」——与其检验区间里每个候选，不如刻画出目标形状 $p^2$ 后反着数稀疏的特殊数。204 题计数质数是同一套筛法的母题。

### 3.3 算法流程：埃氏筛 + 计数

![算法流程：筛到 √r，数出平方落在区间内的质数](images/wc408_q2_sieve_flow.svg)

1. 求 $n = \lfloor\sqrt{r}\rfloor$：Python 用 `math.isqrt` 精确无误差；C++ 的 `sqrt` 是浮点，需上下各修正一步；
2. 对 $[2, n]$ 做埃氏筛：从 $i^2$ 起步划掉 $i$ 的倍数（$i^2$ 以下的倍数已被更小的质数划过）；
3. 每遇到一个质数 $p$，检查 $p^2 \ge l$：成立则 $p^2 \in [l, r]$（上界 $p \le n$ 已保证 $p^2 \le r$），特殊数计数 +1；
4. 返回 $(r - l + 1) - \text{special}$。

两个边界细节：

- **下界判定用 $p^2 \ge l$ 而不是先算 $\lceil\sqrt{l}\rceil$**：前者只需一次整数乘法比较，天然规避「开方取整方向写反」这类边界 bug（$l$ 自身是完全平方数时最容易错）；
- **$r < 4$ 时** $n < 2$，筛循环不执行，特殊数为 $0$，直接返回区间长度——代码无需特判，自然成立。

### 3.4 示例演算

![示例演算：l=4, r=16，只有 4 和 9 是特殊数字](images/wc408_q2_example_walkthrough.svg)

`l = 4, r = 16`：区间共 $16 - 4 + 1 = 13$ 个数，$n = \lfloor\sqrt{16}\rfloor = 4$，扫描 $2 \sim 4$：

| $i$ | 是否质数 | $i^2$ | 落在 $[4, 16]$？ | special |
|:---:|:---:|:---:|:---:|:---:|
| 2 | ✓ 质数 | 4 | ✓（$4 \ge 4$） | 1 |
| 3 | ✓ 质数 | 9 | ✓（$9 \le 16$） | 2 |
| 4 | ✗（$2$ 的倍数，被划掉） | — | — | 2 |

$$\text{答案} = 13 - 2 = \boxed{11}$$

区间视角：$4 = 2^2$、$9 = 3^2$ 是特殊数字；$16 = 4^2$ 因 $m = 4$ 是合数**不是**特殊数字；下一个 $5^2 = 25 > 16$ 已出界。**示例 1**（$l = 5, r = 7$）同理：$2^2 = 4 < 5$、$3^2 = 9 > 7$，特殊数为 $0$，答案 $3 - 0 = 3$。

## 4. 算法细节

1. **整数平方根**：判定 $p^2 \le r$ 的前提是精确的 $n = \lfloor\sqrt{r}\rfloor$。Python 的 `math.isqrt` 是纯整数实现，无浮点误差；C++ 的 `sqrt((double)r)` 在 $10^9$ 的完全平方边界可能抖动 $\pm 1$，标准修正是双向循环：`while ((n+1)*(n+1) <= r) ++n;` 与 `while (n*n > r) --n;`。
2. **筛表设计**：只开 `comp[0..n]`（约 $3.2 \times 10^4$ 个布尔位），不开到 $r$。标记从 $i^2$ 起步，使每个合数只被其**最小质因子**划掉，这是埃氏筛 $O(n \log\log n)$ 复杂度的来源。
3. **计数与筛同步**：外层循环遇到 `comp[i]` 为假即知 $i$ 是质数，顺手完成「划倍数 + 判断 $i^2 \ge l$ + 计数」，一趟扫完，不需要单独的质数列表。
4. **上下界的不对称处理**：上界 $p^2 \le r$ 由 $p \le n$ **隐式**保证（循环上界就是 $n$）；下界 $p^2 \ge l$ 用**显式乘法比较**。一侧隐式一侧显式，是这类「值域 − 筛」题的常见写法。
5. **乘法用 64 位**：C++ 中 `i * i` 与 `(n + 1)²` 的量级已达 $10^9$（$31623^2 = 1{,}000{,}014{,}129$），虽未越 `int` 上限，但用 `long long` 兜底可彻底规避极端边界的风险。

## 5. 正确性证明

**引理 1（因数个数的奇偶性）**：正整数 $x$ 的因数个数为奇数，当且仅当 $x$ 是完全平方数。

**证明**：映射 $d \mapsto x/d$ 是 $x$ 的因数集合上的一个对合（ involution）。$d$ 是不动点当且仅当 $d = x/d$，即 $d^2 = x$、$d = \sqrt{x}$。若 $x$ 不是完全平方数，对合无不动点，因数被两两配对，个数为偶数；若 $x = m^2$，则恰有一个不动点 $m$，其余因数两两配对，总个数为奇数。∎

**引理 2（特殊数字的刻画）**：$x$ 恰有 $2$ 个真因数 $\iff$ 存在质数 $p$ 使 $x = p^2$。

**证明**：

（$\Leftarrow$）设 $p$ 为质数，$x = p^2$。$p^2$ 的因数恰为 $1, p, p^2$：若 $d \mid p^2$ 且 $d \notin \{1, p, p^2\}$，则 $d$ 有质因子 $q$，$q \mid p^2$ 且 $q \ne p$ 不可能（$p^2$ 的质因子只有 $p$）。故真因数恰为 $\{1, p\}$，共 $2$ 个。

（$\Rightarrow$）设 $x$ 的真因数恰 $2$ 个。若 $x = 1$，真因数为空集，矛盾；故 $x > 1$，且 $1$ 总是真因数。于是 $x$ 的因数个数 $d(x) = 2 + 1 = 3$（补回 $x$ 自身），为奇数。由引理 1，$x = m^2$（$m \ge 2$）。若 $m$ 是合数，取 $m = a \cdot b$，$1 < a \le b < m$，则 $a \mid m \mid x$ 且 $a \notin \{1, m, x\}$，得 $d(x) \ge 4$，矛盾。故 $m$ 是质数。∎

**定理**：算法返回 $[l, r]$ 内非特殊数字的个数。

**证明**：$[l, r]$ 内每个数要么特殊要么不特殊，故所求 $= (r - l + 1) - S$，其中 $S$ 为特殊数字个数。由引理 2，映射 $p \mapsto p^2$ 是「$[2, n]$ 内质数中满足 $p^2 \ge l$ 者」到「$[l, r]$ 内特殊数字」的双射：单射因 $p^2 = p'^2 \Rightarrow p = p'$；满射因每个特殊数字 $x = p^2$（$p \le \sqrt{r} \le n$）都被计入。又 $p \le n = \lfloor\sqrt{r}\rfloor \iff p^2 \le r$ 对整数 $p$ 成立，故筛选条件精确对应 $l \le p^2 \le r$。埃氏筛正确标记 $[2, n]$ 内每个数的素性（每个合数 $c$ 被其最小质因子 $q \le \sqrt{c} \le \sqrt{n} \le n$ 划掉，且质数永不被划），因此 `special` 恰等于 $S$，返回值即非特殊数字个数。∎

## 6. 复杂度分析

- **时间复杂度**：$O(\sqrt{r} \log\log \sqrt{r})$。埃氏筛到 $\sqrt{r} \le 31622$；对每个质数再做一次 $O(1)$ 的乘法比较。对照暴力 $O((r-l+1)\sqrt{r}) \approx 10^{13}$：正解与区间长度 $r - l + 1$ **完全无关**，等于把 $10^9$ 的题做成了 $3 \times 10^4$ 的题。
- **空间复杂度**：$O(\sqrt{r})$。筛表约 $3.2 \times 10^4$ 个布尔位。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int nonSpecialCount(int l, int r) {
        int n = (int)sqrt((double)r);
        while ((long long)(n + 1) * (n + 1) <= r) ++n;   // 修正浮点误差：n = ⌊√r⌋
        while ((long long)n * n > r) --n;
        vector<bool> comp(n + 1, false);                 // comp[i]：i 是否为合数
        int special = 0;
        for (int i = 2; i <= n; ++i) {
            if (comp[i]) continue;                       // 合数跳过
            for (long long j = 1LL * i * i; j <= n; j += i)
                comp[j] = true;                          // 从 i² 起划掉 i 的倍数
            if (1LL * i * i >= l) ++special;             // p² ≥ l；p² ≤ r 由 i ≤ n 保证
        }
        return r - l + 1 - special;                      // 总数 − 特殊数
    }
};
```

### Python

```python
from math import isqrt

class Solution:
    def nonSpecialCount(self, l: int, r: int) -> int:
        n = isqrt(r)                          # 精确整数平方根，无浮点误差
        comp = [False] * (n + 1)              # comp[i]：i 是否为合数
        special = 0
        for i in range(2, n + 1):
            if comp[i]:
                continue                      # 合数跳过
            for j in range(i * i, n + 1, i):
                comp[j] = True                # 从 i² 起划掉 i 的倍数
            if i * i >= l:                    # p² ≥ l；p² ≤ r 由 i ≤ n 保证
                special += 1
        return (r - l + 1) - special          # 总数 − 特殊数
```

## 8. 边界情况与易错点

1. **$l = 1$**：$1$ 的真因数是空集（$0$ 个），不是特殊数字。算法中 $p \ge 2$ 保证 $p^2 \ge 4 > 1$，天然不会误判，无需特判。
2. **$r < 4$**（如 $l = 1, r = 3$）：$n < 2$，循环不执行，`special = 0`，直接返回区间长度 $3$，自然正确。
3. **C++ 浮点 `sqrt` 的抖动**：$r = 10^9$ 时 $n = 31622$（$31622^2 = 999{,}950{,}884 \le 10^9 < 31623^2 = 1{,}000{,}014{,}129$），完全平方边界处 `sqrt` 可能返回 $x.999\cdots$ 或 $y.000\cdots1$ 截断后偏 $1$，必须用两个 `while` 双向修正；Python 的 `math.isqrt` 无此坑。
4. **下界判断写 $p \cdot p \ge l$**，不要先算 $\lceil\sqrt{l}\rceil$ 再比较：$l$ 为完全平方数时 $\lceil\sqrt{l}\rceil = \lfloor\sqrt{l}\rfloor$，开闭区间与取整方向极易写错；一次整数乘法最稳。
5. **别把质数本身当成特殊数字**：质数只有 $1$ 个真因数 $\{1\}$，特殊的是 $p^2$。
6. **别把合数的平方当成特殊数字**：$16 = 4^2$ 的真因数是 $\{1, 2, 4, 8\}$ 共 $4$ 个——中间那个 $m$ 必须是质数。
7. **闭区间端点**：$l$、$r$ 自身也可能是特殊数字（如 $l = 4$ 或 $r = 9$），判定条件两端的等号（$p^2 \ge l$、$p^2 \le r$）都不能丢。
8. **乘法用 64 位兜底**：C++ 中 `i * i`、`(n + 1)²` 量级约 $10^9$，加 `1LL` 转换是好习惯（见 §4 第 5 点）。

**延伸思考**：

- **值域更大怎么办**：$r \le 10^{14}$ 时 $\sqrt{r} \le 10^7$，本地埃氏筛仍可行（约 10 MB 内存），本题代码一行不改；$r \le 10^{18}$ 时整表筛不动，改用**区间筛**（只筛 $[\lceil\sqrt{l}\rceil, \lfloor\sqrt{r}\rfloor]$ 这一段）或对平方候选逐个 **Miller–Rabin** 判素。
