# LeetCode 统计 1 显著的字符串的数量 题解

## 1. 题目概述

- **标题 / 题号**：统计 1 显著的字符串的数量（#3234，medium）
- **链接**：https://leetcode.cn/problems/count-the-number-of-substrings-with-dominant-ones/
- **来源**：LeetCode 第 408 场周赛 Q3
- **难度**：中等
- **标签**：字符串、枚举、前缀和

**题意**：给定二进制字符串 $s$。若一个子串中 **1 的个数 $k$** ≥ **0 的个数 $z$ 的平方 $z^2$**，则称该子串为 **1 显著** 的。统计并返回 $s$ 中 1 显著子串的数量。

**约束**：

- $1 \le n \le 4 \times 10^4$
- $s$ 仅包含字符 `'0'` 和 `'1'`

> 💡 **审题关键**：条件 $k \ge z^2$ 是**极不对称**的——0 的个数被 1 的个数的平方压制。子串里 1 最多 $4 \times 10^4$ 个，于是 $z \le \sqrt{k} \le \sqrt{n} \approx 200$：**0 是稀缺资源**。这决定了正解的枚举对象应该选「0 的个数」而不是「1 的个数」。

## 2. 示例

**示例 1**

```text
输入：s = "00011"
输出：5
解释：1 显著子串共 5 个："1"(s[3])、"1"(s[4])、"01"、"11"、"011"。
```

**示例 2**

```text
输入：s = "101101"
输出：16
解释：共 21 个子串，其中 5 个不是 1 显著（"0"、"0"、"0110"、"10110"、"01101"），21 − 5 = 16。
```

**补充示例（全 1 串）**

```text
输入：s = "1111"
输出：10
解释：0 的个数为 0，任何子串都满足 k ≥ 0² = 0，答案为 n(n+1)/2 = 10。
```

## 3. 解题思路

### 3.1 暴力思路：枚举全部子串

双重循环枚举 $(L, R)$，右端点右移时 $O(1)$ 增量维护 $k$ 与 $z$，逐个判定 $k \ge z^2$。总量 $O(n^2) \approx 1.6 \times 10^9$：C++ 勉强卡过、Python 必然超时，且没有沉淀任何观察。

**为什么滑动窗口也不行**：固定左端点 $L$，令 $f(R) = \text{ones}(L..R) - \text{zeros}(L..R)^2$。$R$ 右移遇到 `1` 时 $f$ 增加 $1$，遇到 `0` 时 $f$ 减少 $2z+1$——$f$ **先降后升完全可能**（例如 `"100000011111111"`，前面一堆 0 把 $f$ 打到负数，后面连续 1 又把它拉回非负）。判定条件对 $R$ 不单调，双指针 / 二分全部失效。

### 3.2 核心观察：0 的个数 ≤ √n ≈ 200

![核心观察：1 显著推出 0 的个数不超过根号 n，枚举对象从 1 的个数换成 0 的个数](images/wc408_q3_zeros_sqrt_insight.svg)

三步推理：

- **第一步（条件本身）**：$k \ge z^2$，两边开方得 $z \le \sqrt{k}$；
- **第二步（放缩）**：子串内 $k \le n \le 4 \times 10^4$，故 $z \le \sqrt{n} = 200$；
- **第三步（换枚举对象）**：与其对每个 $L$ 枚举「第 $k$ 个 1」（$k$ 最多 $4 \times 10^4$ 种，全 1 串直接退化成 $O(n^2)$），不如枚举「0 的个数 $z$」——只有 $200$ 种。

$$\text{1 显著} \iff k \ge z^2 \iff z \le \lfloor\sqrt{k}\rfloor \le \lfloor\sqrt{n}\rfloor = 200$$

> 💡 **一句话总结**：平方条件把「0 的个数」压缩成了 $O(\sqrt{n})$ 量级的小量，枚举它，每个左端点只需 $O(\sqrt{n})$ 而不是 $O(n)$。

### 3.3 算法流程：固定 L 枚举 z，两条约束夹出 R 区间

![固定 L 与 0 的个数 z，0 的个数约束与 1 的个数约束求交得到合法右端点区间](images/wc408_q3_window_counting.svg)

固定左端点 $L$ 后，子串由右端点 $R$ 唯一确定。把子串按 $z = \text{zeros}(L..R)$ 分组，对每个 $z$ 求合法 $R$ 的区间：

1. **预处理**：记录 `1` 的位置数组 `one`、`0` 的位置数组 `zero`，以及前缀计数 `cnt1[i]`（前 $i$ 个字符中 `1` 的个数）、`cnt0[i]`。于是「$L$ 起第 $t$ 个 `0`」= `zero[cnt0[L] + t − 1]`，「$L$ 起第 $t$ 个 `1`」= `one[cnt1[L] + t − 1]`，都是 $O(1)$ 查询；
2. **约束①（0 恰好 $z$ 个）**：$R \in [r_1, r_2]$，其中 $z = 0$ 时 $r_1 = L$，$z \ge 1$ 时 $r_1 = Z_z$（第 $z$ 个 `0`）；$r_2 = Z_{z+1} - 1$（第 $z+1$ 个 `0` 不存在则 $r_2 = n-1$）；
3. **约束②（1 至少 $z^2$ 个）**：$z \ge 1$ 时还需 $R \ge Q_{z^2}$（第 $z^2$ 个 `1` 的位置）；$z = 0$ 时 $k \ge 0$ 恒真，无此约束；
4. **求交计数**：该 $(L, z)$ 的贡献为

$$\max\bigl(0,\; r_2 - \max(r_1,\; Q_{z^2}) + 1\bigr)$$

5. **两个终止条件**（$z$ 递增时一旦触发即 `break`）：
   - 第 $z$ 个 `0` 不存在——后面的 $z$ 更不存在；
   - 第 $z^2$ 个 `1` 不存在（1 不足 $z^2$ 个）——$z$ 越大需要的 1 越多，更不存在。

| 1 | 1 | $[1, 3]$ | $Q_1 = 2$ | $[2, 3]$ | 2 |
| 2 | 0 | $[2, 3]$ | — | $[2, 3]$ | 2 |
| 2 | 1 | $[4, 5]$ | $Q_1 = 2$ | $[4, 5]$ | 2 |
| 3 | 0 | $[3, 3]$ | — | $[3, 3]$ | 1 |

各 $L$ 小计 $5 + 2 + 4 + 3 + 1 + 1 = \boxed{16}$。两个值得注意的行：

- $L = 0, z = 1$：$Q_1 = 0 < r_1 = 1$，此时 $\max$ 由窗口左端生效——约束②不设限，全部 $[1, 3]$ 有效（`10`、`101`、`1011` 都显著）；
- $L = 0, z = 2$：$Q_4 = 5$ 把区间左端从 $4$ 推到 $5$——$s[0..4] = $ `10110` 只有 $3$ 个 1，$3 < 2^2 = 4$，确实不显著。

## 4. 算法细节

1. **排名 → 位置的 $O(1)$ 查询**：`cnt0[L]` 是「$L$ **之前**」的 0 的个数，所以「$L$ 起第 $t$ 个 0」是 `zero[cnt0[L] + t − 1]`。这是「值 → 排名 → 位置」的经典三连，避免每次二分。
2. **两个 break 的单调性**：$z$ 递增时，需要的 0 个数与 $z^2$ 个 1 都单调递增，因此某个 $z$ 触发越界后，更大的 $z$ 必然也越界，`break` 而非 `continue` 既正确又保证复杂度。
3. **$z = 0$ 的特殊处理**：$r_1 = L$（不存在「第 0 个 0」），且无需 $Q$ 约束（$k \ge 0$ 恒真）。全 1 段的所有子串在 $z = 0$ 一趟内 $O(1)$ 计入——这正是全 1 串不会退化成 $O(n^2)$ 的原因。
4. **哨兵技巧**：第 $z+1$ 个 0 不存在时 $r_2 = n - 1$（窗口一直开到串尾），不需要额外哨兵元素。
5. **溢出评估**：$z \le 200$，$z^2 \le 4 \times 10^4$，下标 `cnt1[L] + z*z − 1` 最多约 $8 \times 10^4$，均在 `int` 范围；答案上界为全 1 串的 $n(n+1)/2 \approx 8.0 \times 10^8$，仍小于 $2^{31} - 1$，但建议累加器用 `long long` 兜底。

## 5. 正确性证明

**引理 1（0 个数窗口）**：固定 $L \in [0, n)$ 与整数 $z \ge 0$。记 $Z_t$ 为位置 $\ge L$ 的第 $t$ 个 `0`（$t \ge 1$，从 1 数起）。则

$$\{\, R : \mathrm{zeros}(s[L..R]) = z \,\} = [r_1, r_2]$$

其中 $z = 0$ 时 $r_1 = L$、$z \ge 1$ 时 $r_1 = Z_z$；$r_2 = Z_{z+1} - 1$，$Z_{z+1}$ 不存在时 $r_2 = n - 1$。区间可能为空。

**证明**：$\mathrm{zeros}(s[L..R]) = z$ 当且仅当第 $z$ 个 `0` 已被包含而第 $z+1$ 个尚未被包含，即 $Z_z \le R < Z_{z+1}$（约定 $Z_0$ 的约束 vacuous，即 $R \ge L$）。两端具象化即得 $[r_1, r_2]$；$Z_{z+1}$ 超出串长时上界为 $n - 1$。∎

**引理 2（1 个数下界）**：固定 $L$，记 $Q_t$ 为位置 $\ge L$ 的第 $t$ 个 `1`。则对任意 $t \ge 1$：

$$\mathrm{ones}(s[L..R]) \ge t \iff R \ge Q_t$$

（$Q_t$ 不存在时右端永假）。

**证明**：$R \mapsto \mathrm{ones}(s[L..R])$ 单调不减，每右移经过一个 `1` 恰好加一，故其值首次达到 $t$ 的位置恰为 $Q_t$。∎

**定理（计数正确性）**：算法返回值等于 1 显著子串个数，且

$$\text{答案} = \sum_{L=0}^{n-1} \sum_{z \ge 0} \max\bigl(0,\; r_2(L, z) - \max(r_1(L, z),\, Q_{z^2}) + 1\bigr)$$

（$z = 0$ 项不含 $Q$ 因子）。

**证明**：把子串按二元组 $(L, z)$ 分组，其中 $z = \mathrm{zeros}(s[L..R])$ 由 $(L, R)$ 唯一确定，分组不重不漏。子串 $s[L..R]$ 1 显著等价于「$\mathrm{zeros} = z$ 且 $\mathrm{ones} \ge z^2$」。由引理 1，满足前者的 $R$ 构成区间 $[r_1, r_2]$；由引理 2，满足后者（$z \ge 1$ 时）等价于 $R \ge Q_{z^2}$（$z = 0$ 时恒真）。二者之交为 $[\max(r_1, Q_{z^2}),\, r_2]$，其大小恰为求和项（交空时为 0，对应 $\max(0, \cdot)$）。所有组内的子串集合两两不交，且每个 1 显著子串必属于某一组（其 $z \le \sqrt{k} \le \sqrt{n}$ 有限），故求和恰为所求个数。∎

**推论（循环有界）**：对每个 $L$，内层循环至多执行 $\min\bigl(\mathrm{zeros}_{after}(L),\, \lfloor\sqrt{\mathrm{ones}_{after}(L)}\rfloor\bigr) + 1 \le \lfloor\sqrt{n}\rfloor + 1 = 201$ 次。

**证明**：两个 break 分别在 $z > \mathrm{zeros}_{after}(L)$ 与 $z^2 > \mathrm{ones}_{after}(L)$ 时触发，取先到者。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n\sqrt{n})$。预处理 $O(n)$；主循环每个 $L$ 至多 $201$ 个 $z$，每次 $O(1)$。$n = 4 \times 10^4$ 时约 $8 \times 10^6$ 次基本操作——实测最坏输入（`"10"` 交替串）Python 约 1.4 s、C++ 数十毫秒。对照暴力 $O(n^2) \approx 1.6 \times 10^9$：快了约 200 倍，倍数正是 $\sqrt{n}$。
- **空间复杂度**：$O(n)$。两个位置数组与两个前缀计数数组。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int numberOfSubstrings(string s) {
        int n = (int)s.size();
        vector<int> one, zero;                       // 1 / 0 的位置（按序）
        vector<int> cnt1(n + 1, 0), cnt0(n + 1, 0);  // 前 i 个字符中 1 / 0 的个数
        for (int i = 0; i < n; ++i) {
            cnt1[i + 1] = cnt1[i] + (s[i] == '1');
            cnt0[i + 1] = cnt0[i] + (s[i] == '0');
            (s[i] == '1' ? one : zero).push_back(i);
        }
        int m = (int)one.size(), w = (int)zero.size();
        long long ans = 0;
        for (int L = 0; L < n; ++L) {
            for (int z = 0;; ++z) {                  // z = 子串中 0 的个数
                int r1;
                if (z == 0) {
                    r1 = L;                          // 0 个 0：从 L 开始
                } else {
                    int jz = cnt0[L] + z - 1;        // L 起第 z 个 0
                    if (jz >= w) break;              // 0 不够了
                    r1 = zero[jz];
                }
                int jz1 = cnt0[L] + z;               // L 起第 z+1 个 0
                int r2 = (jz1 < w ? zero[jz1] - 1 : n - 1);
                int lo = r1;
                if (z >= 1) {
                    int jq = cnt1[L] + z * z - 1;    // L 起第 z² 个 1
                    if (jq >= m) break;              // 1 不足 z² 个
                    lo = max(lo, one[jq]);
                }
                if (r2 >= lo) ans += r2 - lo + 1;    // 两条约束求交
            }
        }
        return (int)ans;
    }
};
```

### Python

```python
class Solution:
    def numberOfSubstrings(self, s: str) -> int:
        n = len(s)
        one = [i for i, c in enumerate(s) if c == '1']    # 1 的位置（按序）
        zero = [i for i, c in enumerate(s) if c == '0']   # 0 的位置（按序）
        cnt1 = [0] * (n + 1)                              # 前 i 个字符中 1 的个数
        cnt0 = [0] * (n + 1)
        for i, c in enumerate(s):
            cnt1[i + 1] = cnt1[i] + (c == '1')
            cnt0[i + 1] = cnt0[i] + (c == '0')
        m, w = len(one), len(zero)
        ans = 0
        for L in range(n):
            z = 0                                         # z = 子串中 0 的个数
            while True:
                if z == 0:
                    r1 = L                                # 0 个 0：从 L 开始
                else:
                    jz = cnt0[L] + z - 1                  # L 起第 z 个 0
                    if jz >= w:
                        break                             # 0 不够了
                    r1 = zero[jz]
                jz1 = cnt0[L] + z                         # L 起第 z+1 个 0
                r2 = zero[jz1] - 1 if jz1 < w else n - 1
                lo = r1
                if z >= 1:
                    jq = cnt1[L] + z * z - 1              # L 起第 z² 个 1
                    if jq >= m:
                        break                             # 1 不足 z² 个
                    if one[jq] > lo:
                        lo = one[jq]
                if r2 >= lo:
                    ans += r2 - lo + 1                    # 两条约束求交
                z += 1
        return ans
```

## 8. 边界情况与易错点

1. **全 0 串**：答案为 $0$。每个 $L$ 的 $z = 0$ 窗口为空（$s[L] =$ `'0'` 时 $Z_1 = L$，窗口 $[L, L-1]$），$z = 1$ 时 $Q_1$ 不存在直接 `break`。
2. **全 1 串**：答案 $n(n+1)/2 \approx 8.0 \times 10^8$。全部由 $z = 0$ 一趟计入（窗口 $[L, n-1]$），$z = 1$ 立即 `break`——若错误地枚举「1 的个数」会退化成 $O(n^2)$。
3. **别用双指针/滑动窗口**：$\text{ones} - \text{zeros}^2$ 对右端点不单调（遇 `0` 减 $2z+1$、遇 `1` 加 $1$，可先降后升，见 §3.1 的例子），必须换成按 $z$ 分组数区间。
4. **$Q$ 的下标是 $z^2$ 不是 $z$**：约束②需要的是「第 $z^2$ 个 1」，平方写在 1 的个数上，写成第 $z$ 个 1 是典型手滑。
5. **`break` 不能写成 `continue`**：`jq >= m` 的含义是「1 不足 $z^2$ 个」，此时贡献为 0 且更大的 $z$ 更不满足——若改成 `continue` 跳过检查，会把不含 1 的窗口整段误计入（全 0 串直接出错），且复杂度也失去保证。
6. **$z = 0$ 的两处特判**：$r_1 = L$（没有「第 0 个 0」）；无 $Q$ 约束（$k \ge 0$ 恒真）。
7. **前缀计数的锚点**：`cnt0[L]` 统计的是 $L$ **之前**的 0，「$L$ 起第 $t$ 个 0」取 `zero[cnt0[L] + t - 1]`，不要把 $s[L]$ 自己漏掉或重复。
8. **答案上界**：$8.0 \times 10^8 < 2^{31} - 1$，`int` 恰好装得下，但接近上限，C++ 建议累加器用 `long long`。

**延伸思考**：

- **条件推广到 $p$ 次方**：若定义显著为 $k \ge z^p$，则 $z \le n^{1/p}$，总复杂度 $O(n \cdot n^{1/p})$——$p$ 越大 0 越稀缺、算法越快；$p = 1$ 时条件线性，$f(R) = \text{ones} - \text{zeros}$ 遇 `1` 加 1、遇 `0` 减 1，可证明合法 $R$ 区间性质更好，能否做到 $O(n)$？
- **反向条件**：统计「0 显著」（$z \ge k^2$）的子串数量——对称地把枚举对象换成「1 的个数」，$k \le \sqrt{n}$，同样是 $O(n\sqrt{n})$。
- **恰好条件**：若要求 $\text{ones} = z^2$（恰好相等），约束②从「$R \ge Q_{z^2}$」变成「$Q_{z^2} \le R < Q_{z^2+1}$」，仍是区间求交，框架原样可用。
