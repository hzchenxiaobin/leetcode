# LeetCode 判断矩形的两个角落是否可达 题解

## 1. 题目概述

- **标题 / 题号**：判断矩形的两个角落是否可达（#3235，hard）
- **链接**：https://leetcode.cn/problems/check-if-the-rectangle-corner-is-reachable/
- **来源**：LeetCode 第 408 场周赛 Q4
- **难度**：困难
- **标签**：并查集、计算几何、平面交叉对偶、数学

**题意**：给定矩形 $[0, xCorner] \times [0, yCorner]$（左下角 $S=(0,0)$，右上角 $E=(X,Y)$）和 $n$ 个圆 $circles[i]=(x_i, y_i, r_i)$。判断是否存在一条从 $S$ 到 $E$ 的连续路径，满足：**完全在矩形内部**、**只在起点和终点接触矩形边界**、且**不触碰（更不能进入）任何圆的内部与边界**。

**约束**：

- $3 \le xCorner, yCorner \le 10^9$
- $1 \le circles.length \le 1000$
- $1 \le x_i, y_i, r_i \le 10^9$（注意：**圆心坐标恒为正**，圆可以整个在矩形外）

> 💡 **审题关键**：路径是**连续曲线**而非网格行走，坐标高达 $10^9$ 无法直接搜索；但「路径存在性」是一个纯粹的**平面连通性**问题——它有一个经典的对偶判据：**路径被挡住 ⟺ 若干圆连成一堵「墙」，把矩形的左上边界弧与右下边界弧接通**。剩下的全部难点在于：这堵「墙」的连边条件必须严格限定在**矩形内部**发生，朴素做法在这里埋着本题最著名的坑。

```text
输出：true
解释：圆 (2,1,1) 只与下边、右边相切，没有与任何「上/左」边界相连，
      黑色曲线可以从 (0,0) 绕到 (3,4)。
```

**示例 2**

```text

```

**示例 3**

```text
输出：false
解释：圆 (1,2,1) 贴左边与上边（连到「左上弧」），圆 (2,1,1) 贴下边与右边
      （连到「右下弧」），两圆圆心距 √2 ≤ 2 且公共透镜在矩形内 → 连成一堵墙。
```


## 3. 解题思路

### 3.1 暴力思路：直接搜索路径

最直接的想法是在矩形内打网格做 BFS：把 $[0,X] \times [0,Y]$ 划分成格子，标记落在圆内（含边界）的格子为障碍，再从 $S$ 附近的格子泛洪到 $E$。两个致命问题：

- 坐标与半径高达 $10^9$，格子数不可承受；缩放成浮点网格又会**丢掉相切精度**——本题恰恰充满「恰好相切」的边界（路径不得触碰圆**边界**，圆与墙恰好相切即视为粘连）；
- 障碍是连续区域，任何有限分辨率都可能把一条真实存在的细缝判没（或把不存在的缝判有）。

所以必须彻底换视角：不去构造路径，而是去刻画「路径**不存在**」的等价条件。

### 3.2 核心观察：交叉对偶——「找路径」变成「判连通」

![交叉对偶：可达时圆是孤岛；不可达时圆连成一堵墙，把左上弧与右下弧接通](images/wc408_q4_barrier_duality.svg)

把 $S=(0,0)$、$E=(X,Y)$ 之外的矩形边界切成两段**墙**：

- $W_A$ = **左边 ∪ 上边**（从 $S$ 沿逆时针到 $E$ 的左上弧）；
- $W_B$ = **下边 ∪ 右边**（从 $S$ 沿顺时针到 $E$ 的右下弧）。

由**交叉引理**（若尔当曲线定理的推论，见 §5）：矩形内一条 $S \to E$ 的连续曲线，与一条 $W_A \to W_B$ 的连续曲线（障碍链）**必然相交**。而路径不得触碰任何圆与任何边界，于是：

$$\text{不可达} \iff \text{若干圆连成一堵墙，把 } W_A \text{ 与 } W_B \text{ 接通（外加 } S \text{ 或 } E \text{ 落在某个圆内）}$$

圆与圆「连成墙」的含义：相邻圆**相交或相切**（相切也算——路径连一个切点都不能碰，两圆外切时缝隙宽度为 $0$，钻不过去）；圆与墙「接通」的含义：圆**碰到那条边的线段**（同样含相切，理由相同）。

> 💡 **一句话总结**：把 $W_A$、$W_B$ 当成两个虚拟节点放进并查集，圆碰线段就与对应墙合并，圆与圆相交（**在矩形内**）就互相合并——最后看两个墙节点是否连通。连续几何问题就此离散化，$n \le 1000$ 允许 $O(n^2)$ 两两判交。

### 3.3 大坑预警：「两圆平面相交」≠「两圆在矩形内相连」

![朴素平面连边的两个反例：圆在矩形外相切成链，或透镜整个落在角外侧](images/wc408_q4_corner_trap.svg)

顺着上节很容易写出「错误率极高」的朴素版：**圆 $i$ 与圆 $j$ 只要平面相交（圆心距 $\le r_i + r_j$）就连边**。这是错的——圆可以**在矩形外面**手拉手：

**反例 ①（外切链）**：$X=Y=8$，$circles=[[4,10,2],[8,12,3],[12,8,3],[10,4,2]]$。四个圆全在矩形外：第一个与上边相切、最后一个与右边相切，中间在矩形外依次相交。朴素并查集得到 $W_A \sim c_1 \sim c_2 \sim c_3 \sim c_4 \sim W_B$，判「不可达」；实际上矩形**内部空无一圆**，对角线路径畅通无阻，正确答案是 `true`。

**反例 ②（透镜在角外）**：$X=Y=1000$，$circles=[[985,1100,101],[1100,985,101]]$。两个圆都**真实地**跨过边界浸入矩形（$u$ 跨上边向下浸入 $1$、$v$ 跨右边向左浸入 $1$），圆心距 $115\sqrt2 \approx 162.6 < r_1+r_2 = 202$，平面确实相交；但它们的**公共透镜（公共材料）整体落在角 $E=(1000,1000)$ 的外侧**——矩形内部两圆的材料互不相交（角 $E$ 附近留有约 $0.12$ 的缝隙）。朴素连边误判 `false`，正确答案是 `true`。

**修正**：圆-圆连边条件必须是——

$$D_i \cap D_j \cap [0,X] \times [0,Y] \neq \varnothing$$

即**两圆的公共部分（透镜）与闭矩形有公共点**。路径只在矩形内部活动，矩形外的相交材料对它是空气。反过来说，「贴墙」这一侧反而**不必**要求浸入：一个只在墙外相切的圆在矩形内部没有任何材料，即使并进 $W_A$，它也无法通过「透镜∩矩形」连到任何别的圆，不会制造假墙——判定压力全部集中在圆-圆边上。

### 3.4 算法流程

![并查集建模：两个墙节点与三类连边，以及 X=Y=10 的示例演算](images/wc408_q4_dsu_model.svg)

```text
canReachCorner(X, Y, circles):
    # 第 0 步：端点被圆包含（含相切）→ 路径无法起/终点
    for (x, y, r) in circles:
        if dist²((x,y), S) ≤ r² or dist²((x,y), E) ≤ r²: return false

    建立并查集，节点 0..n-1 为圆，节点 WA = 左+上墙，节点 WB = 下+右墙

    # 边①②：圆-墙。点到线段距离 ≤ r（clamp 技巧，含相切）
    for i in 0..n-1:
        if 圆 i 与左边段 {0}×[0,Y] 或 上边段 [0,X]×{Y} 相交: union(i, WA)
        if 圆 i 与下边段 [0,X]×{0} 或 右边段 {X}×[0,Y] 相交: union(i, WB)

    # 边③：圆-圆。透镜与闭矩形有公共点（三部曲，见 §4）
    for i < j:
        if lensIntersectBox(i, j, X, Y): union(i, j)

    return find(WA) != find(WB)   # 两墙连通 → 不可达
```

`lensIntersectBox(i, j)` 的三部曲：

1. 若 $dist^2(c_i, c_j) > (r_i + r_j)^2$：平面都不相交，返回否；
2. 若 $dist^2(c_i, c_j) \le (r_i - r_j)^2$：一圆包含另一圆，透镜就是小圆，退化为**小圆与矩形是否相交**（圆心 clamp 到矩形，距离 $\le r$ 即相交）；
3. 否则透镜是「双凸透镜」形区域：取 $\le 19$ 个**候选点**（矩形四角、两圆心向矩形/四边的投影、根轴与四边的交点、根轴垂足），逐一检验是否**同时在两圆内**——全是整数十字相乘，零浮点（正确性见 §5 引理 3）。

### 3.5 示例演算

以 $X=Y=10$，$circles=[[5,5,3],[8,2,3],[2,8,3]]$ 为例（见上图右半）：

| 圆 | 贴墙情况 | 并查集归属 |
|----|----------|-----------|
| $c_3=(2,8,3)$ | 跨左边（弦 $y\in[5.8,10]$）、跨上边（弦 $x\in[0,4.2]$） | $W_A$ |
| $c_1=(5,5,3)$ | 四边都不沾（到每边距离 $5 > 3$） | 独立 |
| $c_2=(8,2,3)$ | 跨下边（弦 $x\in[5.8,10]$）、跨右边（弦 $y\in[0,4.2]$） | $W_B$ |

圆-圆判交：$dist(c_3, c_1) = \sqrt{18} \approx 4.24 \le 6$，透镜中点 $(3.5, 6.5)$ 在矩形内 → 连边；$dist(c_1, c_2)$ 同理连边；$dist(c_2, c_3) = \sqrt{72} \approx 8.49 > 6$ → 不连。于是 $W_A - c_3 - c_1 - c_2 - W_B$ 全线连通，且 $S, E$ 均不在圆内 → 返回 `false`。这堵墙把 $S$ 封死在左下角的「口袋」里。官方示例 3 同理：$(1,2,1)$ 粘 $W_A$、$(2,1,1)$ 粘 $W_B$、透镜在矩形内 → `false`。

## 4. 算法细节

1. **端点判定用 $\le$**：题面禁止触碰圆的**边界**，所以 $dist^2(c, S) \le r^2$（而非 $<$）即判 `false`。同理，圆-圆相切（透镜退化为一个切点）、圆贴墙相切（弦退化为一个切点）**都算**粘连——缝隙宽度为 $0$，路径钻不过去。

2. **圆-墙判交 = 点到线段距离**：对轴对齐线段，把圆心坐标 clamp 到线段范围即得最近点，全程整数。注意是**线段**不是直线——圆碰到的若是边的**延长线**（例如圆心在 $y > Y$ 处碰到直线 $x=0$），并不粘墙。四条边分别判定：

   - 贴左边 $\iff x \le r \wedge y \le Y$，或 $x^2 + (y - Y)^2 \le r^2$（够到左上角）；
   - 贴下边、上边、右边完全对称（用 clamp 统一实现最省心）。

3. **透镜 ∩ 矩形的候选点法**：透镜 $= D_i \cap D_j$ 是凸集，且

   $$f(p) = \max\bigl(|p-c_i|^2 - r_i^2,\; |p-c_j|^2 - r_j^2\bigr)$$

   是凸函数，「透镜与矩形相交」$\iff f$ 在矩形上的最小值 $\le 0$。凸函数在矩形（紧凸集）上的最小值点只可能出现在：**矩形内部**（一阶条件推出是圆心或根轴垂足）、**某条边的内部**（归约为一维凸函数 → 端点 / 顶点 / 两函数交点，即根轴与边的交点）、或**矩形角点**。于是只需检验：

   - 4 个角点、2 个圆心的 clamp 点、8 个「圆心单坐标 clamp 到边」的投影点（共 14 个整数点）；
   - 根轴 $A\bar{x} + B\bar{y} = C$（其中 $A = 2(x_j - x_i)$，$B = 2(y_j - y_i)$，$C = |c_j|^2 - r_j^2 - |c_i|^2 + r_i^2$）与四条边的交点（至多 4 个有理数点）；
   - 根轴垂足（圆心到根轴的最近点，1 个有理数点）。

   有理数点不必显式求出坐标再开方：全部判定都可**十字相乘成整数比较**。例如底边交点 $\bigl(\tfrac{C}{A}, 0\bigr)$：

   $$\text{在两圆内} \iff (C - Ax_i)^2 + (Ay_i)^2 \le A^2 r_i^2 \;\wedge\; (C - Ax_j)^2 + (Ay_j)^2 \le A^2 r_j^2$$

   根轴垂足 $(x_i + \tfrac{N}{D}A,\; y_i + \tfrac{N}{D}B)$（$N = C - Ax_i - By_i$，$D = A^2 + B^2$）：$f(\text{垂足}) = \tfrac{N^2}{D} - r_i^2$，故在透镜内 $\iff N^2 \le D\, r_i^2$，在矩形内 $\iff 0 \le x_i D + NA \le XD$（$y$ 同理）。

4. **为什么候选点法是精确的**：所有比较都是整数等式/不等式的同解变形，相切、经过角点、根轴平行于边等退化情形被「$\le$ + 闭矩形」自然覆盖，全程无浮点、无 $\varepsilon$。

5. **溢出**：$dist^2$、$(r_i + r_j)^2$ 达 $8 \times 10^{18}$，候选点十字相乘最高约 $10^{37}$——C++ 必须用 `__int128`；Python 天然大整数无此虑。

## 5. 正确性证明

**引理 1（交叉引理）**：设 $K \subseteq [0,X] \times [0,Y]$ 是连通闭集，$K \cap W_A \neq \varnothing$，$K \cap W_B \neq \varnothing$，且 $S, E \notin K$。则在 $\mathrm{int}(R) \cup \{S, E\}$ 中不存在从 $S$ 到 $E$ 且避开 $K$ 的连续路径。

**证明**：反设路径 $\gamma$ 存在。取 $a \in K \cap W_A$、$b \in K \cap W_B$；$K$ 是有限个凸块（圆 ∩ 矩形、墙段）组成的连通并，故存在折线 $\beta \subseteq K$ 从 $a$ 到 $b$。将 $\gamma$ 与沿 $W_A$ 方向的边界弧（$E \to$ 上边 $\to$ 左边 $\to S$）拼成闭曲线 $C$，$\beta$ 与 $\gamma$ 不交，于是 $\beta$ 只能穿越 $C$ 的边界弧部分离开 $C$——但 $\beta$ 从 $W_A$ 侧的 $a$ 到 $W_B$ 侧的 $b$，而 $W_B$ 整段落在 $C$ 关于 $\gamma$ 的另一侧，$\beta$ 与 $\gamma$ 的奇偶交叉数必为奇数，与 $\beta \cap \gamma = \varnothing$ 矛盾。此即若尔当曲线定理的标准交叉数推论（对相切等退化情形，用 $\varepsilon$-微扰归约到一般位置）。∎

**引理 2（块链刻画）**：记 $P_i = D_i \cap [0,X] \times [0,Y]$（圆 $i$ 的「材料」）。则存在连通集 $K \subseteq \bigl(\bigcup_i P_i\bigr) \cup W_A \cup W_B$ 同时触及 $W_A$、$W_B$ $\iff$ 并查集中 $W_A$ 与 $W_B$ 连通。

**证明**：$P_i$（凸 ∩ 凸）与 $W_A$、$W_B$ 都是连通闭集，且只有有限个。有限个连通闭集的并是连通的，当且仅当它们能排成一条链使相邻两个相交（否则按相交关系分成两族，两族的并是不相交闭集，拆散连通性）。而「相邻相交」恰好逐条对应三类连边：$P_i \cap P_j = D_i \cap D_j \cap R \neq \varnothing$（边③）、$P_i \cap W_A \neq \varnothing \iff$ 圆 $i$ 碰左/上线段（边①）、$P_i \cap W_B$ 同理（边②）。∎

**引理 3（候选点刻画）**：$D_i \cap D_j \cap R \neq \varnothing$ $\iff$ §4 所列 $\le 19$ 个候选点中存在同时在两圆内（且在矩形内）的点。

**证明**：透镜与矩形相交 $\iff f(p) = \max(g_i, g_j)$（两凸二次函数之最大值，仍是凸函数）在矩形上取到 $\le 0$。设 $p^\ast$ 为最小值点：若 $p^\ast$ 在矩形内部，一阶条件 $0 \in \partial f(p^\ast)$ 给出 $p^\ast = c_i$、$p^\ast = c_j$（某圆支配且取驻点）或 $p^\ast$ 落在根轴上且属于两圆心连线段——而根轴垂直于 $c_i c_j$，它与线段 $c_i c_j$ 的交点恰是根轴垂足；若 $p^\ast$ 在某条边的相对内部，把 $f$ 限制到该边是一维凸函数，其最小值只能取在边端点（角点）、单侧函数的顶点（圆心向该边的投影）或两限制函数的交点（根轴与该边的交点）；若在角点则已列。全部情形穷尽于候选集。∎

**定理（对偶判定）**：算法返回 `false` $\iff$ 不存在可行路径。

**证明**：

（$\Leftarrow$ 充分性）若某圆含 $S$ 或 $E$，路径的起点/终点本身就非法，显然 `false`。否则若 $W_A \sim W_B$，由引理 2 取到连通障碍 $K$，且因第 0 步已排除 $S, E$ 落在圆内、墙不含 $S, E$，有 $S, E \notin K$；由引理 1，路径必与 $K$ 相交——与「避开一切圆与边界」矛盾。故 `false` 正确。

（$\Rightarrow$ 必要性）反设无路径、无圆含 $S/E$、且 $W_A \not\sim W_B$。对自由区域 $\bigl(\mathrm{int}(R) \cup \{S,E\}\bigr) \setminus \bigcup D_i$ 从 $S$ 所在分量 $C$ 泛洪。$E \notin C$，故 $C$ 的边界中必有一道由圆材料与墙段构成的「堤坝」隔开两侧；沿堤坝追迹（经典的涂色 / 六边形引理论证），得到一条从 $W_A$ 到 $W_B$、相邻块在矩形内相接的圆链——由引理 2 这正是并查集中的一条连边路径，与 $W_A \not\sim W_B$ 矛盾。∎

> ⚠️ **朴素做法的失败位置**：把引理 2 中的 $P_i \cap P_j \neq \varnothing$ 换成「$D_i \cap D_j \neq \varnothing$（平面相交）」即得朴素版。反例 ①② 说明平面相交推不出 $P_i \cap P_j \neq \varnothing$——两块材料可以在矩形外相接。透镜条件是必要且不可放宽的。

## 6. 复杂度分析

- **时间复杂度**：$O(n^2 \cdot C)$，其中每对圆的判交 $C$ 为常数（$\le 19$ 个候选点、每个 $O(1)$ 次整数乘法比较）。$n \le 1000$ 时约 $5 \times 10^5$ 对，实测 C++ 满规模 30ms 内。第 0 步与贴墙判定均为 $O(n)$。
- **空间复杂度**：$O(n)$——并查集数组，几何判定全部 $O(1)$ 局部变量，无任何建图/建网格开销。

```cpp
class Solution {
    using i64 = long long;
    using i128 = __int128_t;
    int n;
    vector<array<i64, 3>> cs; // {x, y, r}
    vector<int> fa;
    static i128 sq(i128 v) { return v * v; }
    int find(int a) { while (fa[a] != a) a = fa[a] = fa[fa[a]]; return a; }
    void unite(int a, int b) { fa[find(a)] = find(b); }
    static i64 cl(i64 v, i64 lo, i64 hi) { return v < lo ? lo : (v > hi ? hi : v); }

    // 点到（轴对齐）线段的距离平方
    static i128 dist2seg(i64 px, i64 py, i64 ax, i64 ay, i64 bx, i64 by) {
        i64 qx = cl(px, min(ax, bx), max(ax, bx));
        i64 qy = cl(py, min(ay, by), max(ay, by));
        return sq(px - qx) + sq(py - qy);
    }

    // 两圆的公共透镜是否与闭矩形 [0,X]x[0,Y] 有公共点
    bool lensHitsBox(int i, int j, i64 X, i64 Y) {
        i64 x1 = cs[i][0], y1 = cs[i][1], r1 = cs[i][2];
        i64 x2 = cs[j][0], y2 = cs[j][1], r2 = cs[j][2];
        i128 dx = x1 - x2, dy = y1 - y2;
        i128 d2 = dx * dx + dy * dy;
        if (d2 > sq((i128)r1 + r2)) return false;      // 平面内都不相交
        if (d2 <= sq((i128)r1 - r2)) {                  // 大圆含小圆：透镜 = 小圆
            i64 cx = r1 < r2 ? x1 : x2, cy = r1 < r2 ? y1 : y2, cr = min(r1, r2);
            return sq((i128)cl(cx, 0, X) - cx) + sq((i128)cl(cy, 0, Y) - cy) <= sq((i128)cr);
        }
        i128 A = 2 * (i128)(x2 - x1), B = 2 * (i128)(y2 - y1);
        i128 C = (sq(x2) + sq(y2) - sq(r2)) - (sq(x1) + sq(y1) - sq(r1)); // 根轴
        auto okPt = [&](i128 px, i128 py) {
            return sq(px - x1) + sq(py - y1) <= sq((i128)r1) &&
                   sq(px - x2) + sq(py - y2) <= sq((i128)r2);
        };
        // 整数候选：角点 / 圆心 clamp / 圆心向四边投影
        const i64 cxs[2] = {x1, x2}, cys[2] = {y1, y2};
        for (int k = 0; k < 2; k++) {
            if (okPt(cl(cxs[k], 0, X), cl(cys[k], 0, Y))) return true;
            if (okPt(cl(cxs[k], 0, X), 0) || okPt(cl(cxs[k], 0, X), Y)) return true;
            if (okPt(0, cl(cys[k], 0, Y)) || okPt(X, cl(cys[k], 0, Y))) return true;
        }
        if (okPt(0, 0) || okPt(X, 0) || okPt(0, Y) || okPt(X, Y)) return true;
        // 根轴与四边的交点（有理数点，十字相乘判定）
        auto between = [](i128 v, i128 lo, i128 hi) { return lo <= v && v <= hi; };
        if (A != 0) {                                    // px = C/A（下边）、(C-BY)/A（上边）
            i128 lo = min((i128)0, A * X), hi = max((i128)0, A * X);
            if (between(C, lo, hi) &&
                sq(C - A * x1) + sq(A * y1) <= sq(A) * r1 * r1 &&
                sq(C - A * x2) + sq(A * y2) <= sq(A) * r2 * r2) return true;
            i128 t = C - B * Y;
            if (between(t, lo, hi) &&
                sq(t - A * x1) + sq(A * (Y - y1)) <= sq(A) * r1 * r1 &&
                sq(t - A * x2) + sq(A * (Y - y2)) <= sq(A) * r2 * r2) return true;
        }
        if (B != 0) {                                    // py = C/B（左边）、(C-AX)/B（右边）
            i128 lo = min((i128)0, B * Y), hi = max((i128)0, B * Y);
            if (between(C, lo, hi) &&
                sq(B * x1) + sq(C - B * y1) <= sq(B) * r1 * r1 &&
                sq(B * x2) + sq(C - B * y2) <= sq(B) * r2 * r2) return true;
            i128 t = C - A * X;
            if (between(t, lo, hi) &&
                sq(B * (X - x1)) + sq(t - B * y1) <= sq(B) * r1 * r1 &&
                sq(B * (X - x2)) + sq(t - B * y2) <= sq(B) * r2 * r2) return true;
        }
        i128 D = A * A + B * B, N = C - A * x1 - B * y1; // 根轴垂足
        return between(x1 * D + N * A, (i128)0, (i128)X * D) &&
               between(y1 * D + N * B, (i128)0, (i128)Y * D) && sq(N) <= D * r1 * r1;
    }

public:
    bool canReachCorner(int X, int Y, vector<vector<int>>& circles) {
        n = circles.size();
        cs.resize(n);
        for (int i = 0; i < n; i++) {
            i64 x = circles[i][0], y = circles[i][1], r = circles[i][2];
            cs[i] = {x, y, r};
            if (sq(x) + sq(y) <= sq(r)) return false;             // S 在圆内/圆上
            if (sq(x - X) + sq(y - Y) <= sq(r)) return false;     // E 在圆内/圆上
        }
        fa.resize(n + 2);
        iota(fa.begin(), fa.end(), 0);
        const int WA = n, WB = n + 1;
        for (int i = 0; i < n; i++) {
            auto [x, y, r] = cs[i];
            if (dist2seg(x, y, 0, 0, 0, Y) <= sq(r) ||   // 左边 → W_A
                dist2seg(x, y, 0, Y, X, Y) <= sq(r))     // 上边 → W_A
                unite(i, WA);
            if (dist2seg(x, y, 0, 0, X, 0) <= sq(r) ||   // 下边 → W_B
                dist2seg(x, y, X, 0, X, Y) <= sq(r))     // 右边 → W_B
                unite(i, WB);
        }
        for (int i = 0; i < n; i++)
            for (int j = i + 1; j < n; j++)
                if (lensHitsBox(i, j, X, Y)) unite(i, j);
        return find(WA) != find(WB);
    }
};
```

### Python

```python
class Solution:
    def canReachCorner(self, X: int, Y: int, circles: List[List[int]]) -> bool:
        n = len(circles)
        for x, y, r in circles:                       # 端点被圆包含（含相切）
            if x * x + y * y <= r * r or (x - X) ** 2 + (y - Y) ** 2 <= r * r:
                return False

        fa = list(range(n + 2))                       # n 个圆 + WA + WB
        WA, WB = n, n + 1

        def find(a):
            while fa[a] != a:
                fa[a] = fa[fa[a]]
                a = fa[a]
            return a

        def union(a, b):
            fa[find(a)] = find(b)

        def cl(v, lo, hi):
            return lo if v < lo else (hi if v > hi else v)

        def hit_seg(px, py, ax, ay, bx, by, r):       # 点到线段距离 ≤ r
            qx = cl(px, min(ax, bx), max(ax, bx))
            qy = cl(py, min(ay, by), max(ay, by))
            return (px - qx) ** 2 + (py - qy) ** 2 <= r * r

        for i, (x, y, r) in enumerate(circles):
            if hit_seg(x, y, 0, 0, 0, Y, r) or hit_seg(x, y, 0, Y, X, Y, r):
                union(i, WA)
            if hit_seg(x, y, 0, 0, X, 0, r) or hit_seg(x, y, X, 0, X, Y, r):
                union(i, WB)

        def lens_hits_box(i, j):                      # 透镜 ∩ 矩形
            x1, y1, r1 = circles[i]
            x2, y2, r2 = circles[j]
            d2 = (x1 - x2) ** 2 + (y1 - y2) ** 2
            if d2 > (r1 + r2) ** 2:
                return False
            if d2 <= (r1 - r2) ** 2:                 # 大圆含小圆
                cx, cy, cr = (x1, y1, r1) if r1 < r2 else (x2, y2, r2)
                return (cl(cx, 0, X) - cx) ** 2 + (cl(cy, 0, Y) - cy) ** 2 <= cr * cr
            A = 2 * (x2 - x1)
            B = 2 * (y2 - y1)
            C = (x2 * x2 + y2 * y2 - r2 * r2) - (x1 * x1 + y1 * y1 - r1 * r1)

            def ok(px, py):
                return ((px - x1) ** 2 + (py - y1) ** 2 <= r1 * r1 and
                        (px - x2) ** 2 + (py - y2) ** 2 <= r2 * r2)

            for cx, cy in ((x1, y1), (x2, y2)):      # 整数候选
                if ok(cl(cx, 0, X), cl(cy, 0, Y)):
                    return True
                if ok(cl(cx, 0, X), 0) or ok(cl(cx, 0, X), Y):
                    return True
                if ok(0, cl(cy, 0, Y)) or ok(X, cl(cy, 0, Y)):
                    return True
            if ok(0, 0) or ok(X, 0) or ok(0, Y) or ok(X, Y):
                return True
            if A:                                     # 根轴与下边/上边交点
                hi = abs(A * X)
                if abs(C) <= hi and (C - A * x1) ** 2 + (A * y1) ** 2 <= A * A * r1 * r1 \
                        and (C - A * x2) ** 2 + (A * y2) ** 2 <= A * A * r2 * r2:
                    return True
                t = C - B * Y
                if abs(t) <= hi and (t - A * x1) ** 2 + (A * (Y - y1)) ** 2 <= A * A * r1 * r1 \
                        and (t - A * x2) ** 2 + (A * (Y - y2)) ** 2 <= A * A * r2 * r2:
                    return True
            if B:                                     # 根轴与左边/右边交点
                hi = abs(B * Y)
                if abs(C) <= hi and (B * x1) ** 2 + (C - B * y1) ** 2 <= B * B * r1 * r1 \
                        and (B * x2) ** 2 + (C - B * y2) ** 2 <= B * B * r2 * r2:
                    return True
                t = C - A * X
                if abs(t) <= hi and (B * (X - x1)) ** 2 + (t - B * y1) ** 2 <= B * B * r1 * r1 \
                        and (B * (X - x2)) ** 2 + (t - B * y2) ** 2 <= B * B * r2 * r2:
                    return True
            D = A * A + B * B                          # 根轴垂足
            N = C - A * x1 - B * y1
            return (0 <= x1 * D + N * A <= X * D and 0 <= y1 * D + N * B <= Y * D
                    and N * N <= D * r1 * r1)

        for i in range(n):
            for j in range(i + 1, n):
                if lens_hits_box(i, j):
                    union(i, j)
        return find(WA) != find(WB)
```

## 8. 边界情况与易错点

1. **朴素「平面相交」连边是本题最大的坑**（§3.3 两个反例）。判定网络上的既有讨论表明该写法在角外侧构造下必然出错；「透镜∩矩形」是正确且必要的形式。
2. **相切即粘连**：路径不得触碰圆的边界，所以**一切判定用 $\le$**——圆含 $S/E$、圆-圆外切、圆贴墙相切全都算「挡住」。写成 $<$ 会在一票相切用例上翻车。
3. **线段不是直线**：圆碰到边的延长线（圆心越过端点）不算贴墙，必须 clamp；否则会把矩形外的圆误粘到墙上。
4. **单圆封角**：一个圆同时贴「左/上」与「下/右」（例如 $X=Y=3$、圆 $(2,2,2)$ 同时碰左边与下边），单独就把答案变成 `false`——它切掉了包含 $S$ 或 $E$ 的角。
5. **圆完全在矩形外**：只要不碰四条线段（含相切），就与并查集无关；碰到的若是四个角的「对角延长线」区域，同样不粘。
6. **浮点不可用**：本题充满 $0$ 宽缝隙与恰好相切，`double` 的 epsilon 取多少都会漏判/误判；全程整数（C++ 配 `__int128`，乘积可达 $\sim 10^{37}$，恰好在其表示范围内）。
7. **圆心恒正（$x_i, y_i \ge 1$）是隐藏几何条件**：它保证了下边/左边只能被圆从「内侧」接近（不存在完全悬在 $y<0$ 或 $x<0$ 的圆），角 $S$ 外侧不可能出现反例 ① 型的假墙——假墙只可能出现在角 $E$ 外侧。理解这一点有助于自查连边逻辑。
