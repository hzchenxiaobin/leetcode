# LeetCode 跳跃游戏 III 题解

## 1. 题目概述

- **标题 / 题号**：跳跃游戏 III（#1306，medium）
- **链接**：https://leetcode.cn/problems/jump-game-iii/
- **来源**：LeetCode 第 169 场周赛 Q3
- **难度**：中等
- **标签**：深度优先搜索、广度优先搜索、数组

**题意**：给定长度为 $n$ 的非负整数数组 `arr` 与起点下标 `start`。站在下标 $i$ 时，下一步只能跳到 $i + \text{arr}[i]$ 或 $i - \text{arr}[i]$，且不许跳出数组。问是否存在一条合法的跳跃序列，最终落在某个 $\text{arr}[j] = 0$ 的下标 $j$ 上。

**约束**：

- $1 \le n \le 5 \times 10^4$
- $0 \le \text{arr}[i] < n$
- $0 \le \text{start} < n$

后两条合起来说明：单步落点的取值范围落在 $[-(n-1), 2n-2]$ 内，32 位整数足够表示；同时每个下标最多只能跳到数组的另一端，跳跃距离不会超过整个区间长度。注意 `arr` 完全可能全为非零值，此时答案必然是 `false`。

## 2. 示例

**示例 1**

```text
输入：arr = [4,2,3,0,3,1,2], start = 5
输出：true
解释：到达值为 0 的下标 3 有两条路线
      下标 5 -> 下标 4 -> 下标 1 -> 下标 3
      下标 5 -> 下标 6 -> 下标 4 -> 下标 1 -> 下标 3
```

**示例 2**

```text
输入：arr = [4,2,3,0,3,1,2], start = 0
输出：true
解释：一条可行路线：下标 0 -> 下标 4 -> 下标 1 -> 下标 3
```

**示例 3**

```text
输入：arr = [3,0,2,1,2], start = 2
输出：false
解释：无法到达值为 0 的下标 1 处。
```

## 3. 解题思路

### 3.1 暴力思路

最直白的做法是「把跳跃序列枚举出来」：从 `start` 出发做不做标记的回溯，每一步尝试两个落点，遇到 $\text{arr}[i] = 0$ 就返回。

这行不通，原因非常硬：

1. **可能永不终止**。`arr = [1,1]`、`start = 0` 时，序列 $0 \to 1 \to 0 \to 1 \to \dots$ 永远合法，回溯会在两个下标之间无限弹跳。
2. **即使加深度上限也会指数爆炸**。路径数随步数按 $2^k$ 增长，而「最短可行路径」最长可达 $n-1$（链状图）。

退一步的「次优解」是**分层展开可达集**：记 $S_0 = \{\text{start}\}$，$S_{k+1} = S_k \cup f(S_k)$，其中 $f(S)$ 是 $S$ 中所有下标的两条出边终点，一直展开到集合不再变化。它一定能停（最多 $n-1$ 轮），但每轮都要重扫一遍整个集合，最坏 $O(n^2)$，$n = 5\times10^4$ 时约 $2.5 \times 10^9$ 次操作，必然超时。

差距全在一点上：**已经算过的下标不需要再算第二遍**。

### 3.2 核心观察：跳跃关系是固定有向图，可达性只需染一次色

![下标是节点、i ± arr[i] 是两条出边的隐式有向图](images/wc169_q3_implicit_graph.svg)

把每个下标 $i$ 看成图的一个节点，从 $i$ 向 $i + \text{arr}[i]$ 与 $i - \text{arr}[i]$ 各连一条有向边（越界的那条不存在）。有两条关键性质：

- **出边与「怎么走到 $i$」无关**。它只由 $\text{arr}[i]$ 决定，所以整张图在搜索开始前就已经固定，每个节点出度不超过 2，边数不超过 $2n$。
- **问题变成纯粹的可达性**。任何一段合法跳跃序列，恰好对应图中的一条有向路径；反过来任意有向路径都是一段合法的跳跃序列。于是题目问的是：从 `start` 出发的有向路径能否碰到某个 $\text{arr}[j] = 0$ 的节点。

为什么「每个节点只处理一次」就够了？把可达集写成最小不动点：$R$ 是同时满足下面两条的**最小**下标集合——

$$\text{start} \in R, \qquad i \in R \;\Rightarrow\; f(i) \subseteq R$$

这个定义有两个性质：**单调**（$R$ 一旦加入元素就不会再被移除）与**幂等**（对同一个节点重复展开，得到的后继完全相同）。所以一个节点第一次被展开时，它能贡献的所有后继就已经进入了候选集；第二次、第三次经过它都不会带来任何新信息。路径搜索需要「回溯 + 撤销标记」是因为它在枚举**具体路径**；而可达性只问「在不在集合里」，标记永不撤销才是正确语义。

> 💡 由此还能立刻得出一个工程结论：BFS 和 DFS 在这道题上**完全等价**，复杂度相同，差别只在用队列还是用栈。选 BFS 只是因为它是迭代写法，没有递归深度风险。

### 3.3 算法流程

![BFS 流程：染色入队、弹出判零、队空即 false](images/wc169_q3_bfs_flow.svg)

1. **初始化**：`seen[start] = true`，把 `start` 入队（起点同时完成「染色」与「入队」）。
2. **取队首**：若队列为空，说明可达集已经穷尽却仍未命中 0，返回 `false`。
3. **判零**：弹出下标 $i$，若 $\text{arr}[i] = 0$ 立即返回 `true`。把判零放在**出队时**而不是入队时，可以省掉「起点本身就是 0」的特判。
4. **扩展**：对两个候选落点 $i + \text{arr}[i]$、$i - \text{arr}[i]$，先判越界，再看 `seen`，只有「未越界且未染色」的才置 `seen = true` 并入队。
5. **循环**直到队列为空或命中 0。

```text
seen[start] = true;  q = [start]
while q 非空:
    i = q.pop_front()
    if arr[i] == 0: return true
    for nxt in (i + arr[i], i - arr[i]):
        if 0 <= nxt < n and not seen[nxt]:
            seen[nxt] = true
            q.push_back(nxt)
return false
```

整个循环维护一条不变式：**队列中的下标两两不同，且每一个都已染色；每一个已染色的下标都从 `start` 可达**。第 5 节用它来证明正确性。

### 3.4 示例演算

![示例 1 的 BFS 逐步走查表](images/wc169_q3_walkthrough.svg)

以示例 1（`arr = [4,2,3,0,3,1,2]`，`start = 5`）为例，BFS 过程如下。注意下标 0、2 虽然存在，但从 5 出发根本走不到。

| 步 | 弹出 $i$ | $\text{arr}[i]$ | 后继 | 新入队 | 队列 |
|----|---------|----------------|------|--------|------|
| 1 | 5 | 1 | 6, 4 | 6, 4 | `[6, 4]` |
| 2 | 6 | 2 | 4（已染色） | — | `[4]` |
| 3 | 4 | 3 | 1 | 1 | `[1]` |
| 4 | 1 | 2 | 3 | 3 | `[3]` |
| 5 | 3 | **0** | —（命中） | — | `[]` |

第 5 步弹出下标 3，$\text{arr}[3] = 0$，返回 `true`，对应路径 $5 \to 6 \to 4 \to 1 \to 3$（另一条 $5 \to 4 \to 1 \to 3$ 同样成立，BFS 先走哪条取决于入队顺序，不影响结论）。

示例 3（`arr = [3,0,2,1,2]`，`start = 2`）走完则完全不同：从 2 出发（$\text{arr}[2] = 2$）到 0 与 4；0 到 3；4 回 2；3 到 4 与 2，全部已染色。队列耗尽，可达集只有 $\{0, 2, 3, 4\}$；而唯一的值 0 下标是 1，要落在 1 上必须存在某个可达下标 $i$ 使 $i \pm \text{arr}[i] = 1$，可达集里没有这样的 $i$（唯一指向 1 的只有 $\text{arr}[1] = 0$ 的自环），故返回 `false`——**能到达很多节点，却到不了目标**，这正是可达性判定的典型形态。

## 4. 算法细节

1. **判零放在出队时**：省掉 `arr[start] == 0` 的特判，而且值为 0 的节点有自环（$i \pm 0 = i$），出队即返回意味着它永远不会被展开，自环根本不会进入循环。
2. **染色放在入队时**：若改成出队才染色，同一节点可能被多个前驱重复入队，队列峰值会从 $n$ 涨到边数量级；入队即染色保证「每个下标至多入队一次」，队列长度恒 $\le n$。
3. **越界判定要写全**：$\text{arr}[i] \ge 0$ 意味着 $i + \text{arr}[i] \ge i$ 不会下溢，但 $i - \text{arr}[i]$ 可能为负。C++ 必须写 `nxt >= 0 && nxt < n`；Python 可以写链式比较 `0 <= nxt < n`。
4. **`seen` 的存储类型**：用 `vector<char>`（或 `vector<uint8_t>`）而不是 `vector<bool>`。后者是按位压缩的特化，读写都要经过代理对象，在这个热循环里有可测量的常数差距。
5. **队列容器**：C++ 用 `queue<int>` 或 `deque`；Python 必须用 `collections.deque`。用 `list.pop(0)` 每弹一次搬迁 $O(n)$ 个元素，整体退化到 $O(n^2)$，是本题最常见的 TLE 原因。
6. **原地标记（可选优化）**：把访问过的 `arr[i]` 改成 $-1$ 兼作 `visited`，额外空间降到 $O(1)$。代价是修改输入、破坏可复现性，面试与复盘场景更推荐显式的 `seen` 数组。
7. **顺手求最少步数**：若题目改成「最少跳几次」，把队列换成按层处理（记录当前层剩余个数），层号就是答案；本题只要可行性，不需要这层信息。
8. **DFS 正确但不推荐递归**：最坏递归深度可达 $n = 5\times10^4$（`arr` 全为 1 的链），Python 默认递归上限 1000 会直接 `RecursionError`，C++ 也可能爆栈。要写 DFS 就用显式栈。

## 5. 正确性证明

记 $a_i = \text{arr}[i]$，$f(i) = \{\, i + a_i,\ i - a_i \,\} \cap [0, n-1]$。

**引理 1（图模型等价）**：下标序列 $v_0, v_1, \ldots, v_k$ 是一段合法的跳跃序列，当且仅当 $v_0 = \text{start}$ 且对每个 $t < k$ 有 $v_{t+1} \in f(v_t)$。

**证明**：题面规定站在 $i$ 时只能跳到 $i + a_i$ 或 $i - a_i$，且不允许跳出数组，所以「合法的一步」与「$v_{t+1} \in f(v_t)$」是同一件事；对步数归纳即得整段序列的等价。∎

**引理 2（染色不变式）**：算法运行过程中恒有：(a) 队列中元素两两不同，且每个都已染色；(b) 每个满足 $\text{seen}[i] = \text{true}$ 的下标 $i$ 都从 `start` 可达。

**证明**：初始时队列只有 `start`，`seen[start] = true`，两条性质均成立。归纳地设入队前成立：每次入队发生在「$\text{seen}[\text{nxt}]$ 为 false」时，入队后立即置为 true，故同一下标不会被入队两次，(a) 保持且队列内无重复；同时 `nxt` 的入队是由某个已弹出（因而已染色、由 (b) 可达）的下标 $i$ 经 $f(i)$ 的一条边产生的，由引理 1 该 $i \to \text{nxt}$ 就是一步合法跳跃，故 `nxt` 也可达，(b) 保持。∎

**引理 3（穷尽性）**：若算法以 `false` 结束，则所有从 `start` 可达的下标都已染色。

**证明**：算法以 `false` 结束意味着队列为空。每次循环只出队一个元素，而入队仅在某个 `seen` 由 false 变为 true 时发生，每个下标至多被染色一次，故入队次数不超过 $n$，循环必然终止——这一点保证「队列为空」是可达集处理完毕的状态，而不是中途退出。

反证：设存在可达却未染色的下标，取一条从 `start` 到它的路径 $v_0 = \text{start}, v_1, \ldots, v_k$，令 $v_t$ 是路径上第一个未染色的点，则 $t \ge 1$ 且 $v_{t-1}$ 已染色。染色只在入队时发生（起点在初始化时即入队），故 $v_{t-1}$ 曾被入队；队列已空说明它必定已被出队。出队时算法会枚举 $f(v_{t-1})$，其中包含 $v_t$：若 $v_t$ 已染色，与「$v_t$ 是路径上第一个未染色点」矛盾；若未染色，算法会把 $v_t$ 染色并入队，同样矛盾。故不存在未染色的可达点。∎

**定理**：`canReach` 返回 `true` 当且仅当存在从 `start` 可达的下标 $j$ 满足 $a_j = 0$。

**证明**：

- 若返回 `true`：返回发生在一个下标 $i$ 出队且 $a_i = 0$ 时，由引理 2(b) 该 $i$ 从 `start` 可达，取 $j = i$ 即得。
- 若返回 `false`：由引理 3，所有可达点都已染色。染色只发生在入队时，故任一可达点都曾入队；队列最终为空，故它曾被出队。若某个可达点 $j$ 有 $a_j = 0$，它出队时必然已返回 `true`，矛盾。于是可达集中不含值为 0 的下标。∎

## 6. 复杂度分析

- **时间**：$O(n)$。每个下标至多入队一次、出队一次；每次出队只做常数次操作（一次判零、两次后继判定），总计不超过 $n$ 次出队与 $2n$ 次边检查，即 $O(n)$。$n = 5\times10^4$ 时是十几万次基本操作。
- **空间**：$O(n)$。`seen` 数组 $n$ 个字节；队列在任意时刻至多容纳所有未出队的已染色点，容量上界为 $n$。二者合计约 $2n$ 个机器字，对 $5\times10^4$ 的数据是数十 KB 量级。
- 递归 DFS 版本的空间还要加上调用栈：深度最坏为 $n$，这是它在本题上不划算的原因。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <queue>

class Solution {
public:
    bool canReach(std::vector<int>& arr, int start) {
        int n = (int)arr.size();
        std::vector<char> seen(n, 0);       // char 而非 vector<bool>，避免位压缩代理
        std::queue<int> q;

        seen[start] = 1;                     // 起点同时染色 + 入队
        q.push(start);

        while (!q.empty()) {
            int i = q.front();
            q.pop();
            if (arr[i] == 0) return true;    // 出队判零，省掉起点特判
            for (int nxt : {i + arr[i], i - arr[i]}) {
                if (nxt >= 0 && nxt < n && !seen[nxt]) {
                    seen[nxt] = 1;           // 入队即染色，保证至多入队一次
                    q.push(nxt);
                }
            }
        }
        return false;                        // 可达集穷尽，未遇到 0
    }
};
```

### Python

```python
from typing import List
from collections import deque


class Solution:
    def canReach(self, arr: List[int], start: int) -> bool:
        n = len(arr)
        seen = [False] * n
        seen[start] = True                   # 起点同时染色 + 入队
        q = deque([start])

        while q:
            i = q.popleft()
            if arr[i] == 0:                  # 出队判零，省掉起点特判
                return True
            for nxt in (i + arr[i], i - arr[i]):
                if 0 <= nxt < n and not seen[nxt]:
                    seen[nxt] = True         # 入队即染色，保证至多入队一次
                    q.append(nxt)

        return False                         # 可达集穷尽，未遇到 0
```

## 8. 边界情况与易错点

1. **`arr[start] == 0`**：起点本身就是目标，必须立即返回 `true`。把判零写在出队处，第一轮出队就命中，无需额外特判；若把判零写在「生成后继时」，就容易漏掉起点而 WA。
2. **$n = 1$**：约束 $0 \le \text{arr}[0] < 1$ 强制 $\text{arr}[0] = 0$，答案必然为 `true`。这也说明本题不存在「单元素无解」的输入。
3. **数组里没有 0**：如 `arr = [1,1,1,1]`，可达集为 $\{0,1,2,3\}$，没有一个值为 0，队列耗尽后返回 `false`。不要因为「可达集非空」就返回 `true`。
4. **两节点互相弹跳**：`arr = [1,1]` 从 0 出发，$0 \to 1 \to 0$ 形成 2-环。`seen` 让第二次到达的 0 直接跳过，否则队列会被无限灌满（这是不染色版本唯一能暴露问题的地方）。
5. **值为 0 的自环**：$i \pm 0 = i$，若先染色再枚举后继，会尝试把 $i$ 再次入队——被 `seen[i]` 拦住。但更干净的是出队即判零、根本不展开它。
6. **Python 用 `list` 当队列**：`q.pop(0)` 是 $O(n)$ 搬迁，$n = 5\times10^4$ 时退化为 $O(n^2)$，本地小样例完全测不出来，交上去就 TLE。
7. **C++ 的 `int` 与越界**：$i - \text{arr}[i]$ 最小约为 $-5\times10^4$，远在 `int` 范围内，不需要 `long long`；但**必须先用 `int` 判断越界再取下标**，对负值做 `arr[nxt]` 是未定义行为。
8. **函数末尾漏 `return false`**：C++ 中会变成未定义行为（常见结果是返回垃圾值），Python 中会返回 `None` 导致判题判错，务必保留末尾的 `return false`。

**延伸思考**：

1. **改问最少跳跃次数**：BFS 的层号就是答案，无需改结构；但若改问「所有方案数」，`seen` 剪枝就不再合法（不同路径必须分别计数），有环时还要先按强连通分量缩点，变成 DAG 上的路径计数。
2. **限制「只能向右跳」**：图退化成 DAG，可用一遍从左到右的布尔 DP：$g[i] = \bigvee_{j \in f^{-1}(i)} g[j]$，仍是 $O(n)$，但不再需要队列；这类「后继只朝一个方向」的结构通常还能用 bitset 再压一个常数。
3. **多组询问**：若要对大量不同的 `start` 回答同一个 `arr`，可以建**反向图**、从所有 $\text{arr}[j] = 0$ 的下标出发做一次多源 BFS，预处理出「哪些起点能到达某个 0」，此后每次询问 $O(1)$，总代价仍是 $O(n)$。
4. **要输出一条具体路径**：在染色时顺手记录 `parent[nxt] = i`，命中 0 后从目标回溯到 `start` 即可，额外空间仍是 $O(n)$，且不需要改动搜索框架。
