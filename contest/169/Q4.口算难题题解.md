# LeetCode 口算难题 题解

## 1. 题目概述

- **标题 / 题号**：口算难题（#1307，hard）
- **链接**：https://leetcode.cn/problems/verbal-arithmetic-puzzle/
- **来源**：LeetCode 第 169 场周赛 Q4
- **难度**：困难
- **标签**：数组、数学、字符串、回溯

**题意**：给定左部字符串数组 `words` 与右部字符串 `result`，判断是否存在一个「大写字母 → 数字」的**单射**，把每个字符串解码成**没有前导零**的十进制数，并使左侧数字之和恰好等于右侧数字。

**约束**：

- $2 \le \text{words.length} \le 5$
- $1 \le \lvert \text{words}[i]\rvert,\ \lvert \text{result}\rvert \le 7$
- `words[i]`、`result` 只含大写英文字母
- 表达式中不同字母的数量 $\le 10$（正好等于数字个数，这是「枚举排列仍可行」的关键前提）

## 2. 示例

**示例 1**

```text
输入：words = ["SEND","MORE"], result = "MONEY"
输出：true
解释：S→9, E→5, N→6, D→7, M→1, O→0, R→8, Y→2；9567 + 1085 = 10652
```

**示例 2**

```text
输入：words = ["SIX","SEVEN","SEVEN"], result = "TWENTY"
输出：true
解释：S→6, I→5, X→0, E→8, V→7, N→2, T→1, W→3, Y→4；650 + 68782 + 68782 = 138214
```

**示例 3**

```text
输入：words = ["LEET","CODE"], result = "POINT"
输出：false
解释：不存在任何映射满足等式；注意两个不同字母不能映射到同一个数字。
```

## 3. 解题思路

### 3.1 暴力思路

直接把 $k$ 个不同字母映射到 $k$ 个不同数字：从 $10$ 个数字里选 $k$ 个做全排列，共 $P(10,k)$ 种，最多 $10! = 3628800$ 种。每种映射都要把 $n+1$ 个字符串翻译成整数再求和，判定代价约 $nL \le 35$ 次字符访问，总代价约 $10! \times 35 \approx 1.3\times10^{8}$。C++ 勉强能跑，Python 必然超时；更糟的是**它把判定放在最后**，前几位早就矛盾的分支仍要一路枚举到底。

### 3.2 核心观察：竖式按列切开，列间只靠进位耦合

![竖式按列拆解与进位传递](images/wc169_q4_column_model.svg)

把 $n$ 个加数与 `result` 右对齐写成竖式，从**个位（最右列）**向高位逐列推进。设第 $c$ 列（$c=0$ 为个位）中，`words[i]` 若长度不足则视为不参与，参与的数字记为 $a_i^{(c)}$，来自右邻列的进位为 $\text{carry}_c$，则

$$S_c = \text{carry}_c + \sum_i a_i^{(c)}, \qquad \text{carry}_{c+1} = \left\lfloor \frac{S_c}{10} \right\rfloor, \qquad \text{digit}_c(\text{result}) = S_c \bmod 10$$

这个式子说明：**一列的合法性只依赖本列字母的取值与一个进位**。因此不需要等整张映射表填完，只要某一列的个位对不上 `result` 的对应字符（或该数字已被别的字母占用、或是前导零），整棵子树立刻剪掉。示例 3 的搜索只需 191 个节点就得出 false，而全排列要 $10!\cdot 35$ 次操作。

### 3.3 算法流程：按列回溯 + 三条原子操作

![按列回溯的搜索流程](images/wc169_q4_backtrack_flow.svg)

搜索状态是一个三元组 $(\text{col}, \text{wi}, \text{carry})$：当前在第 `col` 列、本列处理到第 `wi` 个词、当前进位为 `carry`。每次调用做三件事之一：

1. **列越界**：`col == L`（`L = len(result)`）时，只剩最高位进位没消化，返回 `carry == 0`。
2. **本列还有加数**：取 `words[wi]` 在该列的字符 `ch`（长度不够就跳到 `wi+1`）。已赋值则 `carry += digit[ch]`；未赋值则枚举 $0 \sim 9$，跳过已被占用的数字、跳过前导零字符的 $0$，赋值后递归、返回前撤销。
3. **本列加数处理完**：只剩 `result` 在该列的字符 `ch`。令 $t = \text{carry} \bmod 10$：已赋值则要求 `digit[ch] == t`；未赋值则把 `ch` 绑定为 $t$（同样检查占用与前导零）。通过后进入下一列 $(\text{col}+1, 0, \text{carry} \div 10)$。

三条剪枝贯穿其中：**长度剪枝**（任一 `words[i]` 比 `result` 长则必无解）、**前导零剪枝**（长度 $>1$ 的词与 `result` 的首字符不许取 $0$）、**列末余数剪枝**（$S_c \bmod 10$ 必须正好是 `result` 该列字符的值，否则本列已经错了）。

### 3.4 示例演算

![SEND + MORE = MONEY 的逐列走查](images/wc169_q4_walkthrough.svg)

对示例 1 最终找到的映射（S=9, E=5, N=6, D=7, M=1, O=0, R=8, Y=2）逐列验证：

| 列（从右往左） | 本列字母与数字 | $S_c$ | `result` 字符 | 新进位 |
|:---:|:---|:---:|:---:|:---:|
| 0（个位） | D=7 + E=5 | 12 | Y=2 | 1 |
| 1（十位） | N=6 + R=8 + 进位 1 | 15 | E=5 | 1 |
| 2（百位） | E=5 + O=0 + 进位 1 | 6 | N=6 | 0 |
| 3（千位） | S=9 + M=1 + 进位 0 | 10 | O=0 | 1 |
| 4（万位） | 只有进位 1（两加数都已到顶） | 1 | M=1 | 0 |

五列全部对齐、末列进位归零，映射合法。搜索树上这一组数字并非第一组被试的映射（DFS 从小数字开始试），只在 6117 个节点处命中；而示例 3 只推进到十位（col=1）就全部分支矛盾，共 191 个节点即返回 false。

## 4. 算法细节

1. **预处理字符集**：把出现的字母映射到 $0\sim25$ 的下标（或直接用 `dict` / `char` 下标），`digit[ch] = -1` 表示未赋值。不同字母数 $>10$ 时按鸽巢原理直接返回 false（本题约束保证 $\le 10$，作为防御性检查保留）。
2. **前导零集合 `lead`**：按题面「没有前导零」的字面含义，只有**长度 $>1$** 的字符串首字符才禁止取 $0$；单字符串解码出的就是一位数，取 $0$ 不算前导零。
3. **列内先加数、后结果**：`words` 全部处理完再校验 `result` 的该列字符，这样 `carry` 已累积成完整的 $S_c$，做一次取余即可，避免「边加边比」的重复判断；本列最多 $5$ 个加数，$S_c \le 9\times5+4=49$，故进位 $\le 4$，`int` 足够。
4. **已赋值字母复用**：同一字母会跨列反复出现（如示例 1 的 E），第一次出现时赋值，之后每次直接取 `digit[ch]` 累加，既不重复枚举也自然保证了「同一字母同一数字」。
5. **撤销现场**：赋值与 `used[t]` 必须成对恢复；`result` 字符的赋值也要撤销，否则回溯到更浅层时映射表被污染。Python 用 `dict.pop`，C++ 用 `-1` 覆盖。

## 5. 正确性证明

**引理 1（列恒等式）**：设字母到数字的映射为 $\pi$，按竖式规则把 `words` 与 `result` 右对齐，第 $c$ 列的加数数字为 $a_i^{(c)}$（该词长度不足时取 $0$），并定义 $\text{carry}_0 = 0$、$\text{carry}_{c+1} = \lfloor (\text{carry}_c + \sum_i a_i^{(c)})/10 \rfloor$，则对 $d_c = $ `result` 第 $c$ 位数字（$0 \le c < L$）有

$$\sum_i \text{val}(\text{words}[i]) = \text{val}(\text{result}) \iff \forall c:\ \bigl(\text{carry}_c + \sum_i a_i^{(c)}\bigr) \bmod 10 = d_c \ \text{且}\ \text{carry}_{L} = 0$$

**证明**：把两边都按 $\sum_c d_c 10^c$ 展开。逐列相加的标准竖式算法给出的正是 $\sum_i \text{val}(\text{words}[i]) = \sum_{c} \bigl((\text{carry}_c + \sum_i a_i^{(c)}) \bmod 10\bigr) 10^c + \text{carry}_L \cdot 10^{L}$，两边比较系数即得：低位各列余数必须依次等于 $d_c$，且最高位之后不能再有非零进位。∎

**引理 2（搜索树完备且只含合法前缀）**：DFS 的每个节点对应一个部分映射 $\pi$，且 $\pi$ 在所有已处理完的列上满足引理 1 的列条件；反过来，任取一个满足列条件的部分映射，它在搜索树上都有唯一对应节点。

**证明**：对已处理列数 $c$ 与列内进度 `wi` 做归纳。初始 $(\text{col}=0,\text{wi}=0,\text{carry}=0)$ 对应空映射，没有已处理列，条件空真。归纳步：处理 `words[wi]` 的字符时，分「已赋值（把该数字累加进 `carry`）」与「未赋值（枚举所有未被占用的数字）」两支，前者唯一、后者覆盖全部可能取值，故不重不漏；处理 `result` 字符时，`carry % 10` 是本列唯一可能的余数，若该字符未赋值则只能绑定这一个数字，已赋值则只接受相等的情形——恰好是列条件本身。每进入下一列时 `carry` 被更新为 $\lfloor S_c/10 \rfloor$，与引理 1 的递推一致。∎

**引理 3（三条剪枝不丢失解）**：(a) 若某 `words[i]` 长度大于 $\lvert \text{result}\rvert$，则方程必不可解；(b) 长度 $>1$ 的字符串首字符取 $0$ 必不合法；(c) 列末余数不匹配时该分支不可能补全为解。

**证明**：(a) 该加数 $\ge 10^{\lvert \text{result}\rvert-1+1} > \text{result}$，而其余加数非负，和严格大于右端。(b) 首位为 $0$ 的 $m$ 位数（$m>1$）按题目定义不是合法解码，与题面规则冲突。(c) 由引理 1，列条件对所有解都必须成立，某列余数已经不等，任何补全都无法满足。∎

**定理**：`isSolvable` 返回 true 当且仅当方程存在合法映射。

**证明**：($\Rightarrow$) 返回 true 时，搜索停在 `col == L` 且 `carry == 0` 的叶子。由引理 2，该叶子对应的完整映射在所有列上满足列条件，由引理 1 即得 $\sum_i \text{val}(\text{words}[i]) = \text{val}(\text{result})$；数字互异由 `used` 保证，前导零由 `lead` 保证，故是一个合法解。($\Leftarrow$) 若存在合法解 $\pi^{*}$，由引理 2 它对应搜索树上一条完整路径，由引理 3 该路径上没有任何剪枝条件被触发（合法解本身满足全部条件），于是 DFS 沿此路径一路深入，最终在 `col == L` 处看到 `carry == 0` 而返回 true。∎

## 6. 复杂度分析

- **时间**：最坏上界 $O\bigl(P(10,k)\cdot nL\bigr)$，即 $10! \times 35 \approx 1.3\times10^{8}$ 次基本操作，其中 $k \le 10$ 为不同字母数、$n \le 5$、$L \le 7$。实际因为每列结束就做余数校验，绝大多数分支在深度 $\le 2$ 时被剪掉：示例 1 仅 6117 个节点、示例 3 仅 191 个节点；对 $5\times 7$ 的随机数据，Python 实测 $<0.3$ s。
- **空间**：$O(k + n + L)$。`digit` 表 $O(26)$、`used` 数组 $O(10)$、`lead` 集合 $O(26)$；递归深度不超过 $n \cdot L \le 35$，每层只存几个整数，无需显式栈。

## 7. 参考代码

### C++

```cpp
#include <string>
#include <vector>
#include <functional>
using namespace std;

class Solution {
public:
    bool isSolvable(vector<string>& words, string result) {
        int L = result.size();
        for (auto& w : words) if ((int)w.size() > L) return false;   // 加数比结果还长
        bool seen[26] = {false}, lead[26] = {false};
        int cnt = 0;
        auto mark = [&](char c) {
            if (!seen[c - 'A']) { seen[c - 'A'] = true; ++cnt; }
        };
        for (char c : result) mark(c);
        for (auto& w : words) for (char c : w) mark(c);
        if (cnt > 10) return false;                                  // 鸽巢

        if (L > 1) lead[result[0] - 'A'] = true;                     // 单字符串允许取 0
        for (auto& w : words) if (w.size() > 1) lead[w[0] - 'A'] = true;
        int dig[26];
        fill(begin(dig), end(dig), -1);
        bool used[10] = {false};
        int n = words.size();
        // col: 当前列（0 为个位）; wi: 本列处理到第几个词; carry: 进位
        function<bool(int, int, int)> dfs = [&](int col, int wi, int carry) -> bool {
            if (col == L) return carry == 0;                         // 最高位进位必须归零
            if (wi == n) {                                           // 本列加数处理完，校验 result
                char ch = result[L - 1 - col];
                int t = carry % 10;
                int d = dig[ch - 'A'];
                if (d != -1) return d == t && dfs(col + 1, 0, carry / 10);
                if (used[t] || (t == 0 && lead[ch - 'A'])) return false;
                dig[ch - 'A'] = t; used[t] = true;
                bool ok = dfs(col + 1, 0, carry / 10);
                dig[ch - 'A'] = -1; used[t] = false;                 // 撤销
                return ok;
            }
            string& w = words[wi];
            if (col >= (int)w.size()) return dfs(col, wi + 1, carry); // 该词此列没有字母
            char ch = w[w.size() - 1 - col];
            int d = dig[ch - 'A'];
            if (d != -1) return dfs(col, wi + 1, carry + d);          // 已赋值，复用
            for (int t = 0; t < 10; ++t) {
                if (used[t] || (t == 0 && lead[ch - 'A'])) continue;
                dig[ch - 'A'] = t; used[t] = true;
                if (dfs(col, wi + 1, carry + t)) return true;
                dig[ch - 'A'] = -1; used[t] = false;
            }
            return false;
        };
        return dfs(0, 0, 0);
    }
};
```

### Python

```python
class Solution:
    def isSolvable(self, words: list[str], result: str) -> bool:
        L = len(result)
        if any(len(w) > L for w in words):          # 加数比结果还长，必无解
            return False
        letters = set(result) | set("".join(words))
        if len(letters) > 10:                       # 鸽巢：字母比数字多
            return False
        lead = set()
        if L > 1:                                   # 单字符串允许取 0
            lead.add(result[0])
        for w in words:
            if len(w) > 1:
                lead.add(w[0])
        digit: dict[str, int] = {}                  # 字母 -> 数字
        used = [False] * 10
        n = len(words)

        def dfs(col: int, wi: int, carry: int) -> bool:
            if col == L:                            # 最高位进位必须归零
                return carry == 0
            if wi == n:                             # 本列加数处理完，校验 result
                ch = result[L - 1 - col]
                t = carry % 10
                d = digit.get(ch, -1)
                if d != -1:
                    return d == t and dfs(col + 1, 0, carry // 10)
                if used[t] or (t == 0 and ch in lead):
                    return False
                digit[ch] = t
                used[t] = True
                ok = dfs(col + 1, 0, carry // 10)
                digit.pop(ch)
                used[t] = False                     # 撤销现场
                return ok
            w = words[wi]
            if col >= len(w):                       # 该词此列没有字母
                return dfs(col, wi + 1, carry)
            ch = w[len(w) - 1 - col]
            d = digit.get(ch, -1)
            if d != -1:
                return dfs(col, wi + 1, carry + d)  # 已赋值，复用
            for t in range(10):
                if used[t] or (t == 0 and ch in lead):
                    continue
                digit[ch] = t
                used[t] = True
                if dfs(col, wi + 1, carry + t):
                    return True
                digit.pop(ch)
                used[t] = False
            return False

        return dfs(0, 0, 0)
```

## 8. 边界情况与易错点

1. **单字母词能否取 $0$**：题面说「没有前导零」，$0$ 只有一位、并没有前导零，所以长度 $1$ 的串取 $0$ 合法（如 `words=["A","A"], result="A"` 应为 true）。若把首字符无条件禁止取 $0$，这类输入会被误判为 false——代码里用 `len > 1` 判断。
2. **加数比结果长**：如 `words=["AB"], result="A"`，和至少两位，直接返回 false，不必进搜索。
3. **最高位进位与 `result` 首字符**：进入 `col == L` 后必须要求 `carry == 0`，否则位数不够（例如把 102 写成 02）；同理 `result` 长度 $>1$ 时首字符禁止取 $0$，这条由 `lead` 集合在赋值时统一拦截。
4. **跨列复用同一字母**：示例 1 的 E 在第 0、1、2 列各出现一次，必须取同一个数字；实现上依赖「已赋值就复用」，不能每列重新枚举。
5. **缺列跳过**：`words` 各词长度不同（示例 2 中 `SIX` 只有 3 位），短词在高位列不参与，直接 `wi + 1`；若错误地把它当作「数字 0 的字母」就会多分配一个不存在的字母。
6. **撤销不彻底**：`result` 字符赋值后也必须恢复，且 `used[t]` 与 `digit[ch]` 要成对撤销，否则回溯到上层会残留占用导致漏解（典型症状：明明有解却返回 false）。
