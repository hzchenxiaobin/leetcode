# LeetCode 和为零的 N 个不同整数 题解

## 1. 题目概述

- **标题 / 题号**：和为零的 N 个不同整数（#1304，easy）
- **链接**：https://leetcode.cn/problems/find-n-unique-integers-sum-up-to-zero/
- **来源**：LeetCode 第 169 场周赛 Q1
- **难度**：简单
- **标签**：数组、数学、构造

**题意**：给定整数 $n$，返回**任意**一个长度恰为 $n$ 的整数数组，要求同时满足两条：数组内 $n$ 个数**两两互不相同**；$n$ 个数之和为 $0$。答案不唯一，返回任意一组即可。

**约束**：

- $1 \le n \le 1000$
- 返回值只校验「个数为 $n$、元素互异、和为 $0$」三件事，不校验具体数值

> 💡 签到题的第一判断力：题目说的是「返回任意一个」，所以这**不是搜索题而是构造题**，得分关键是「一眼看出一个永远成立的构造」，而不是枚举验证。

## 2. 示例

**示例 1**

```text
输入：n = 5
输出：[-7,-1,1,3,4]
解释：这些数组也是正确的 [-5,-1,1,2,3]，[-3,-1,2,-2,4]。
      （和均为 0，元素互不相同，长度均为 5）
```

**示例 2**

```text
输入：n = 3
输出：[-1,0,1]
```

**示例 3**

```text
输入：n = 1
输出：[0]
解释：只有一个元素时，它只能是 0。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的想法是「搜」：从某个值域 $[-M, M]$ 里挑 $n$ 个不同整数，用回溯枚举所有 $n$ 元组合，边搜边判断当前和是否为 $0$。

- 搜索空间为 $\binom{2M+1}{n}$ 量级，而 $M$ 题面根本没给（任何整数都合法）；
- 即使乐观地取 $M = n$，$n = 1000$ 时 $\binom{2001}{1000}$ 是天文数字，且很难剪枝——因为「和恰好为 0」这条约束几乎不影响前缀的可行性；
- 更本质的问题是：本题**答案一定存在**（见 §5），搜索是在为「存在性」付代价，而构造只需要 $O(n)$ 时间就能直接写出答案。

所以暴力只适合作为对拍工具（用 $n \le 12$ 的小数据验证构造的正确性），不是解法。

### 3.2 核心观察：相反数配对抵消

![相反数配对与奇偶补零](images/wc169_q1_symmetry_pairing.svg)

注意到一个平凡但极强的事实：

$$(-k) + (+k) = 0 \quad (k \ge 1)$$

一对相反数同时给出两个性质：**它们本身不同**（$-k \ne k$），**它们的和恰好为 0**。把这一点放大，就得到构造：

- **偶数** $n = 2m$：取 $m$ 对 $(-1,1), (-2,2), \ldots, (-m, m)$，共 $2m = n$ 个整数，和等于 $m$ 个 $0$；不同对之间绝对值不同，故两两互异。
- **奇数** $n = 2m+1$：同样取 $m$ 对，再补一个 $0$。$0$ 与所有 $\pm k$（$k \ge 1$）都不同，不破坏互异性；而 $0$ 是唯一「加进集合不改变总和」的整数，因此和仍为 $0$。

> 💡 $0$ 在这里承担的是「填满一个空位但不改变和」的角色。换成任何非零数 $x$，就必须再想办法把 $-x$ 配回来，反而把问题推回原状。

### 3.3 算法流程

![构造流程：配对循环 + 奇偶补零](images/wc169_q1_construct_flow.svg)

1. 置空数组 `res`，令 $i = 1$。
2. 当 $i \le \lfloor n/2 \rfloor$ 时循环：依次把 $-i$、$+i$ 加入 `res`，然后 $i$ 自增 $1$。
3. 循环结束后判断：若 $n$ 为奇数，把 $0$ 加入 `res`；若为偶数则跳过。
4. 返回 `res`。

关键在于**整数除法自动统一了奇偶**：$n=2m$ 与 $n=2m+1$ 的 $\lfloor n/2 \rfloor$ 都是 $m$，所以循环体里完全不需要分情况讨论，只在循环外判一次 `n % 2`。

写成伪代码只有三行：

```text
for i in 1 .. floor(n/2):  push(-i); push(i)
if n is odd:               push(0)
return res
```

### 3.4 示例演算

![n=5 与 n=6 的逐步构造表](images/wc169_q1_walkthrough.svg)

以 $n = 5$（奇）与 $n = 6$（偶）为例，逐轮跟踪 `res` 的变化：

| $n$ | 轮次 | 加入 | `res` 当前内容 |
|-----|------|------|----------------|
| 5 | $i=1$ | $-1, +1$ | $[-1, 1]$ |
| 5 | $i=2$ | $-2, +2$ | $[-1, 1, -2, 2]$ |
| 5 | 补零 | $0$ | $[-1, 1, -2, 2, 0]$ |
| 6 | $i=1$ | $-1, +1$ | $[-1, 1]$ |
| 6 | $i=2$ | $-2, +2$ | $[-1, 1, -2, 2]$ |
| 6 | $i=3$ | $-3, +3$ | $[-1, 1, -2, 2, -3, 3]$ |

$n=5$ 时元素个数 $4 + 1 = 5$，$\sum = (-1+1)+(-2+2)+0 = 0$ ✓
$n=6$ 时元素个数为 $6$，$\sum = 3 \times 0 = 0$ ✓
$n=1$ 时循环不执行、$n$ 为奇数补 $0$，得到 `[0]` ✓

## 4. 算法细节

1. **整数除法统一奇偶**：C++ 的 `n / 2`、Python 的 `n // 2` 在 $n \ge 1$ 时都等于 $\lfloor n/2 \rfloor$。Python 要写成 `//`，用 `/` 会得到浮点数（`range` 直接报错）。
2. **访问顺序无关**：先 push $-i$ 还是先 push $+i$ 都不影响合法性，题面不要求有序；本解按「负数在前」输出，读起来与数轴对称。
3. **值域天然很小**：配对法生成的最大绝对值是 $\lfloor n/2 \rfloor \le 500$，远在 32 位整数内，不会溢出。若改用「前缀 + 末位凑零」（放 $1 \sim n-1$，末位补 $-\frac{n(n-1)}{2}$），$n=1000$ 时末位约为 $-5\times10^5$，虽然仍在 `int` 范围内，但数值明显更「难看」。
4. **闭式写法（无循环分支）**：$a_i = 2i - n + 1\ (i = 0,1,\ldots,n-1)$ 是公差为 $2$ 的等差数列，首项 $1-n$、末项 $n-1$ 互为相反数，两端对称相加为 $0$，求和必为 $0$。$n=5$ 给出 $[-4,-2,0,2,4]$，$n=6$ 给出 $[-5,-3,-1,1,3,5]$，同样合法且天然有序，奇偶无需分支。代价是最大绝对值放大到 $n-1$。
5. **预分配容量**：C++ 用 `res.reserve(n)` 避免 `push_back` 多次扩容；Python 用 `list` 即可，`append` 摊还 $O(1)$。
6. **$n=1$ 不需要特判**：循环上界 $\lfloor 1/2 \rfloor = 0$，一次都不进；随后 `n % 2 == 1` 成立补 $0$，恰好输出 `[0]`。
7. **不要硬编码样例**：示例 1 的输出 `[-7,-1,1,3,4]` 只是 $n=5$ 的一个特例，写死会在 $n \ne 5$ 时立刻 WA。
8. **自测要看「性质」而非「期望串」**：因为答案不唯一，本地验证应检查 `len == n`、`len(set(res)) == n`、`sum(res) == 0` 三个条件，而不是与某个期望数组逐位比对。

## 5. 正确性证明

**引理 1（元素个数恰为 $n$）**：算法返回的数组长度为 $n$。

**证明**：循环执行 $\lfloor n/2 \rfloor$ 次，每次 push 两个元素，共 $2\lfloor n/2 \rfloor$ 个。若 $n$ 为偶数，$2\lfloor n/2 \rfloor = n$，且不补 $0$；若 $n$ 为奇数，$2\lfloor n/2 \rfloor = n-1$，补 $0$ 后为 $n$。两种情形长度都是 $n$。∎

**引理 2（元素两两互不相同）**：返回数组中任意两个元素不相等。

**证明**：每个配对元素都可唯一写成 $x = s \cdot k$，其中符号 $s \in \{+1, -1\}$、绝对值 $k \in \{1, \ldots, \lfloor n/2 \rfloor\}$。（1）同一对内部：取 $x = -k$、$y = +k$，因 $k \ge 1$ 有 $-k \ne k$。（2）不同对之间：若 $x = y$，则 $|x| = |y|$，即 $k_x = k_y$，于是 $x, y$ 属于同一组；而同组内两个数符号相反、不相等，矛盾，故不同对的元素必不相等。（3）$0$ 与其它元素：$0$ 只在 $n$ 为奇数时补入一个，而所有配对元素的 $|x| = k \ge 1$，故 $0$ 不等于任何已存在的数。综上，任意两个元素都不相等。∎

**引理 3（总和为 $0$）**：返回数组的元素和等于 $0$。

**证明**：循环内的元素可分成 $\lfloor n/2 \rfloor$ 组 $\{-i, +i\}$，每组和为 $0$，故循环结束时部分和为 $0$。若 $n$ 为奇数，再补 $0$，总和仍为 $0$；若 $n$ 为偶数，本就无需补。故总和恒为 $0$。∎

**定理**：对任意 $1 \le n \le 1000$，算法输出的数组都是本题的合法答案；且这样的数组一定存在。

**证明**：由引理 1、2、3，输出同时满足「长度为 $n$」「元素互异」「和为 $0$」三条要求，故是合法答案。又对任意 $n \ge 1$，循环在 $\lfloor n/2 \rfloor$ 轮后必然结束、随后只有一次取模判断，算法一定终止并返回，因此合法答案对每个 $n$ 都存在，本题不会出现无解输入。∎

## 6. 复杂度分析

- **时间**：$O(n)$。循环执行 $\lfloor n/2 \rfloor$ 次，每次两次 `push_back`/`append`，均为摊还 $O(1)$；总计写出 $n$ 个元素，常数因子约为 $2$ 次写操作/元素。闭式写法同样是 $O(n)$，但只有 $n$ 次写。
- **空间**：$O(n)$，即返回数组本身占用的 $n$ 个整数；除此之外只用到了循环变量 $i$，**额外空间 $O(1)$**。
- $n \le 1000$ 时实际运算是千级规模，任何常数优化都不必要，代码可读性优先。

## 7. 参考代码

### C++

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> sumZero(int n) {
        vector<int> res;
        res.reserve(n);                       // 预分配，避免多次扩容
        for (int i = 1; i <= n / 2; i++) {    // n/2 向下取整，奇偶统一
            res.push_back(-i);
            res.push_back(i);                 // 一组相反数，和恒为 0
        }
        if (n % 2 == 1) res.push_back(0);     // 奇数补 0，不破坏互异性
        return res;
    }
};

// 备选写法：闭式等差数列 a[i] = 2i - n + 1，公差 2，天然对称有序
class SolutionAlt {
public:
    vector<int> sumZero(int n) {
        vector<int> res(n);
        for (int i = 0; i < n; i++) res[i] = 2 * i - n + 1;
        return res;
    }
};
```

### Python

```python
from typing import List


class Solution:
    def sumZero(self, n: int) -> List[int]:
        res: List[int] = []
        for i in range(1, n // 2 + 1):      # n//2 向下取整，奇偶统一
            res.append(-i)
            res.append(i)                   # 一组相反数，和恒为 0
        if n % 2 == 1:
            res.append(0)                   # 奇数补 0，不破坏互异性
        return res


class SolutionAlt:
    """闭式写法：a[i] = 2i - n + 1，公差 2 的等差数列"""

    def sumZero(self, n: int) -> List[int]:
        return [2 * i - n + 1 for i in range(n)]
```

## 8. 边界情况与易错点

1. **$n = 1$**：只能返回 `[0]`。循环上界为 $0$ 不进循环，靠补零分支兜住；若把补零写成 `if n % 2 == 1 and n > 1` 这种「防御性」特判，反而会输出空数组。
2. **Python 的 `/` 与 `//`**：`n / 2` 得到 `2.5` 这类浮点数，`range(1, n / 2 + 1)` 会直接抛 `TypeError`；必须用 `n // 2`。
3. **把补零写成 `push(n % 2)`**：奇数时加入的是 $1$ 而不是 $0$，总和直接变成 $1$，并且这个 $1$ 与配对产生的 $+1$ 重复——一个笔误同时踩中「和不零」和「元素重复」两个错误，是本题最常见的 WA 形式。
4. **误把「和为零」当成「前缀和为零」**：本题只要求和为 $0$，不要求任意前缀和为 $0$。若误加前缀约束，会写出贪心调整导致元素重复。
5. **答案校验方式错**：本地对拍时不能和示例输出逐位比较（答案不唯一），要校验三性质；这也是 OJ 的 special judge 逻辑。
6. **返回值类型**：C++ 返回 `vector<int>`、Python 返回 `List[int]`，$n \le 1000$ 时数值最大 $500$（配对法），闭式法则到 $999$，都在 `int` 内，无需 `long long`。

**延伸思考**：

1. **值域最小化**：若要求答案中最大绝对值尽量小，最优值是 $\lfloor n/2 \rfloor$。理由：$n$ 个互不相同的整数若都落在 $[-k, k]$，该区间只有 $2k+1$ 个整数，需 $2k+1 \ge n$，即 $k \ge \lceil (n-1)/2 \rceil = \lfloor n/2 \rfloor$；配对法恰好达到这个下界，因此它不只是「一种」构造，而是值域意义下的**最优**构造。
2. **换成「乘积为零」**：多加一条「$n$ 个数乘积为 $0$」，等价于要求 $0$ 必须出现在答案里。此时 $n = 1$ 仍取 `[0]`；$n = 2$ 无解（只能是 $\{0, x\}$，和为 $0$ 逼出 $x = 0$，与互异矛盾）；$n \ge 3$ 仍有解，例如 $n = 4$ 取 $\{0, -3, 1, 2\}$。可见「多一条约束」往往先坏在小 $n$ 上。
3. **换成「绝对值互不相同」**：这一条与配对构造**正面冲突**——$+k$ 与 $-k$ 的绝对值相同，配对法会立刻违反约束，必须换一套构造（例如 $n = 4$ 的 $\{0, -1, -2, 3\}$：和为 $0$、绝对值 $0,1,2,3$ 互不相同）。这说明构造题的技巧高度依赖具体约束，不能指望一招通吃。
4. **一般化**：若要求 $n$ 个互不相同的整数和为 $s$（$s$ 为任意整数），可先构造和为 $0$ 的 $n-1$ 个元素，末位放 $s - \text{sum}$；只需验证末位不与已有元素重复，这正是本题「前缀 + 末位凑零」写法的推广。
