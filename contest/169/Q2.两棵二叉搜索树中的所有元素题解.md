# LeetCode 两棵二叉搜索树中的所有元素 题解

## 1. 题目概述

- **标题 / 题号**：两棵二叉搜索树中的所有元素（#1305，medium）
- **链接**：https://leetcode.cn/problems/all-elements-in-two-binary-search-trees/
- **来源**：LeetCode 第 169 场周赛 Q2
- **难度**：中等
- **标签**：树、深度优先搜索、二叉搜索树、二叉树、排序

**题意**：给定两棵二叉搜索树 `root1`、`root2`，把两棵树的**全部结点值**收集起来，返回一个**升序**排列的列表。注意是「所有元素」而不是「并集」：两棵树之间、甚至同一棵树内部的重复值都要**原样保留**，不做去重。

**约束**：

- 每棵树的结点数在 $[0, 5000]$ 内，两棵合计最多 $10^4$ 个结点
- $-10^5 \le \text{Node.val} \le 10^5$，值可为负数
- 输入以**层序数组**给出，`null` 表示空结点（不是先序/中序）
- 树形任意：可能是链状（高度 5000），也可能是完全平衡树
- 题目未限制同一棵树内不能有重复值，因此 BST 的「有序」应理解为**非降**

## 2. 示例

**示例 1**

```text
输入：root1 = [2,1,4]，root2 = [1,0,3]
输出：[0,1,1,2,3,4]
解释：root1 的中序为 [1,2,4]，root2 的中序为 [0,1,3]，
      二路归并后得到 [0,1,1,2,3,4]（值 1 出现两次，都保留）。
```

**示例 2**

```text
输入：root1 = [1,null,8]，root2 = [8,1]
输出：[1,1,8,8]
解释：root1 是 1 的右孩子为 8；root2 的根为 8、左孩子为 1。
      两棵树各自都含 1 和 8，输出保留全部 4 个元素。
```

**补充自测（空树，官方未给出）**

```text
输入：root1 = []，root2 = [3,1,4]
输出：[1,3,4]
解释：空树不贡献任何元素，答案就是另一棵树的中序序列。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的做法：随便用一种遍历（先序即可）把两棵树的结点值都塞进一个数组，然后 `sort` 一遍。

- 复杂度 $O(n \log n)$，其中 $n = n_1 + n_2 \le 10^4$；对本题数据量完全能过。
- 但它**完全没有用到「二叉搜索树」这个条件**——哪怕输入是两棵普通二叉树也一样跑。周赛里这样写可以拿分，可一旦面试官追问「能不能 $O(n)$」，就露馅了。

另一类「朴素」写法是每轮扫描两棵树找当前最小值（$O(n^2)$），或者反复删除最小结点；前者慢，后者破坏了输入，都不推荐。

> 💡 关键提醒：题目给的是 **BST**，BST 自带一个免费的「有序」结构，用好它就能把 $n \log n$ 降到 $n$。

### 3.2 核心观察：中序遍历天然有序，问题变成二路归并

![BST 中序有序 + 二路归并](images/wc169_q2_inorder_sorted_model.svg)

**观察 1（BST 的基本性质）**：对二叉搜索树做**中序遍历**（左 → 根 → 右），得到的序列一定**非降**。于是两棵树各自给出**一条有序流**：

$$
A = \text{inorder}(root_1),\qquad B = \text{inorder}(root_2)
$$

**观察 2**：问题于是退化成教科书级的「**合并两个有序数组**」——双指针各扫一遍，每次取较小的头部，$O(n_1 + n_2)$，且不需要额外排序。

这两个观察可以做成两档实现：

| 实现 | 时间 | 额外空间 | 特点 |
|------|------|----------|------|
| 两数组归并 | $O(n)$ | $O(n)$ 存两条序列 | 最好写，不容易错 |
| 双栈惰性归并 | $O(n)$ | $O(h_1 + h_2)$ | 不落盘整棵树，只保留「当前路径」 |

本题值域小、数据量小，两数组版足够；但**双栈版**才是把 BST 用到极致的形式，而且顺带解决了链状树递归爆栈的问题，下面按双栈版讲解。

### 3.3 算法流程：双栈惰性中序 + 边遍历边归并

![双栈惰性中序流程](images/wc169_q2_two_stack_flow.svg)

**核心子过程 `pushLeft(st, x)`**：从 `x` 出发一路向左，把 `x`、`x.left`、`x.left.left`…… 依次压栈，遇空停止。压完后**栈顶就是这棵子树里的最小结点**（最左结点），整条栈就是一条「左脊」。

**初始化**：`pushLeft(st1, root1)`、`pushLeft(st2, root2)`。

**主循环**（只要两栈任一非空）：

1. 若 `st2` 为空，或 `st1` 非空且 `st1.back().val <= st2.back().val`，则弹出 `st1` 栈顶；
2. 否则弹出 `st2` 栈顶；
3. 把弹出的值追加到 `ans`；
4. **立刻**对该结点的右孩子执行 `pushLeft`——因为中序的下一个结点就在右子树里（是其最左结点）；右孩子为空时这一步什么都不做，栈顶自动回退到祖先。

栈顶为什么能直接比较？因为两栈的栈顶各自都是「本树尚未输出的最小结点」（见 §5 引理 2），所以比较两个栈顶就等价于比较两条有序流的头部。

相等时（`top1 == top2`）取 `st1` 只是为了让输出**确定**，取哪个都不影响结果的正确性。

### 3.4 示例演算

![示例 1 的双栈走查表](images/wc169_q2_walkthrough.svg)

以 `root1 = [2,1,4]`、`root2 = [1,0,3]` 为例：

- 初始：`st1 = [2,1]`（`pushLeft(2)` 压入 2、1），`st2 = [1,0]`（压入 1、0）。
- ① `top2 = 0 < top1 = 1` → 弹出 0，右子树为空，`ans = [0]`；
- ② 两个栈顶都是 1，取 `st1` 的 1，右子树为空，`ans = [0,1]`；
- ③ 弹出 `st2` 的 1，其右孩子 3 压栈，`st2 = [3]`，`ans = [0,1,1]`；
- ④ `top1 = 2 < top2 = 3` → 弹出 2，其右孩子 4 压栈，`st1 = [4]`；
- ⑤ 弹出 3，`st2` 空；⑥ `st2` 为空则无条件弹 `st1` 的 4。
- 得到 `[0,1,1,2,3,4]`，与官方输出一致。

## 4. 算法细节

1. **`pushLeft` 用循环而非递归**：它只沿左孩子的链走，深度等于左脊长度；写成 `while (node) st.push_back(node), node = node->left;` 即可，天然不会爆栈。
2. **比较表达式的短路顺序**：C++ 写 `if (st2.empty() || (!st1.empty() && st1.back()->val <= st2.back()->val))`，Python 写 `if not st2 or (st1 and st1[-1].val <= st2[-1].val)`。必须保证「取 `st1` 栈顶」这一支里 `st1` 一定非空：当 `st1` 为空、`st2` 非空时，条件的第一项 `st2.empty()` 为假、第二项 `st1 and ...` 为假，正好走 `else` 取 `st2`。
3. **弹出后必须 `pushLeft(right)`**：这是双栈中序的唯一「推进点」。漏掉它，右子树的元素就永远进不了栈，答案会少元素（示例 1 会丢掉 3 和 4）。
4. **迭代优于递归**：结点数 5000 且树可能是一条链，中序递归深度可达 5000，Python 默认递归上限 1000 会直接 `RecursionError`，C++ 也要为此担心栈空间；迭代版把调用栈换成显式 `vector`，彻底免疫。
5. **空树无需特判**：`pushLeft(nullptr)` 不压任何东西，`while (st1 或 st2 非空)` 在双空时直接退出并返回 `[]`；两棵都空、只有一棵空都能自然覆盖。
6. **输出规模可控**：答案最多 $10^4$ 个元素，C++ 可以 `ans.reserve(10000)` 减少扩容；Python 直接 `append` 即可。
7. **想要更短代码时用两数组版**：`inorder(root1)`、`inorder(root2)` 各得一个列表，再用 `merge` 双指针合并；总复杂度同为 $O(n)$，只是多花 $O(n)$ 空间。若面试只要求正确、不追问空间，两数组版更省事。

## 5. 正确性证明

**引理 1（中序非降）**：对任意二叉搜索树，其中序遍历序列非降。

**证明**：对树高归纳。设根为 $r$，左子树所有结点值 $\le r$，右子树所有结点值 $\ge r$（BST 定义）。中序序列为「左子树中序 + $r$ + 右子树中序」；由归纳假设两段子树序列各自非降，且左段最大者 $\le r \le$ 右段最小者，拼接后非降。∎

**引理 2（栈顶即最小未输出）**：在每轮比较开始前，若 `st1` 非空，则 `st1` 栈顶是 `root1` 中所有**尚未输出**结点的值最小者；`st2` 同理。

**证明**：对出栈次数归纳，同时证明「栈内容是某个结点到其最左后代的一条左脊，且栈中结点自上而下按中序位置递增」。初始 `pushLeft(root1)` 显然满足，栈顶是最左结点即全树最小。设当前栈顶为 $u$，由归纳假设 $u$ 是未输出结点中的最小者，故弹出并输出 $u$ 是正确的中序下一步。弹出后：

- 若 $u$ 的右子树非空，中序后继是右子树的**最左结点**，`pushLeft(right(u))` 恰好把它压到栈顶；右子树所有结点都大于 $u$、小于栈中剩余的任何祖先，故新栈顶是新的最小未输出结点；
- 若右子树为空，中序后继是栈中紧邻 $u$ 下方的那个祖先（若存在）；$u$ 的整棵子树已全部输出，剩余结点全在该祖先及其上方，故它就是新的最小者。

两种情况都保持不变量，归纳成立。∎

**引理 3（二路归并正确）**：设 $A, B$ 非降，按「每次取两流当前头部较小者」输出序列 $C$，则 $C$ 是 $A \cup B$ 的非降排列。

**证明**：$C$ 的元素两两来自 $A$ 或 $B$，且每个元素在其流被推进时恰好输出一次，故 $C$ 与 $A \cup B$ 多重集相同。非降性：设当前头部为 $a_i, b_j$，取 $x = \min(a_i, b_j)$，则 $x$ 是全部剩余元素的最小值；剩余集合不断缩小，最小值单调不减，故 $C$ 非降。∎

**定理**：算法输出的 `ans` 恰为两棵树全部结点值的一个非降排列。

**证明**：由引理 2，`st1` 的弹出序列是 `root1` 的中序序列（每个结点入栈、出栈各一次，故恰好输出全部结点），`st2` 同理；由引理 1 这两条序列非降；由引理 3，主循环的输出是二者的正确归并。循环在两栈皆空时结束，而栈空当且仅当该树已无未输出结点，故两树元素全部输出，既不遗漏也不重复计数；所得序列非降且包含全部 $n_1 + n_2$ 个元素，即为所求排序结果。∎

## 6. 复杂度分析

- **时间**：$O(n_1 + n_2)$。每个结点被 `pushLeft` 压栈恰好一次、出栈恰好一次，每次栈操作与一次整数比较均为 $O(1)$；主循环共执行 $n_1 + n_2$ 轮，无嵌套扫描。
- **空间（额外）**：$O(h_1 + h_2)$，其中 $h$ 为树高，两个栈各存一条左脊。平衡树时 $h = O(\log n)$；链状树时 $h = n$，最坏 $O(n_1 + n_2)$。
- **空间（总计）**：$O(n_1 + n_2)$，其中主体是必须返回的答案数组，无法避免。
- **对比**：两数组归并版额外空间恒为 $O(n_1+n_2)$；暴力排序版时间 $O(n \log n)$。三者空间同阶，差距在时间常数与「是否利用 BST 结构」。

## 7. 参考代码

### C++

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> getAllElements(TreeNode* root1, TreeNode* root2) {
        vector<int> ans;
        vector<TreeNode*> st1, st2;

        // 把 x 及其所有左后代压栈：栈顶即该子树最小结点
        auto pushLeft = [](vector<TreeNode*>& st, TreeNode* x) {
            while (x) {
                st.push_back(x);
                x = x->left;
            }
        };

        pushLeft(st1, root1);
        pushLeft(st2, root2);

        while (!st1.empty() || !st2.empty()) {
            if (st2.empty() || (!st1.empty() && st1.back()->val <= st2.back()->val)) {
                TreeNode* cur = st1.back();
                st1.pop_back();
                ans.push_back(cur->val);
                pushLeft(st1, cur->right);   // 中序的下一步：右子树的最左结点
            } else {
                TreeNode* cur = st2.back();
                st2.pop_back();
                ans.push_back(cur->val);
                pushLeft(st2, cur->right);
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def getAllElements(self, root1, root2):
        ans = []
        st1, st2 = [], []

        def push_left(st, node):
            """把 node 及其所有左后代压栈，栈顶即该子树最小结点"""
            while node:
                st.append(node)
                node = node.left

        push_left(st1, root1)
        push_left(st2, root2)

        while st1 or st2:
            if not st2 or (st1 and st1[-1].val <= st2[-1].val):
                cur = st1.pop()
                ans.append(cur.val)
                push_left(st1, cur.right)
            else:
                cur = st2.pop()
                ans.append(cur.val)
                push_left(st2, cur.right)
        return ans
```

## 8. 边界情况与易错点

1. **两棵树都为空**：返回 `[]`。不要写 `return None`，题面要求返回列表。
2. **只有一棵树为空**：`pushLeft(nullptr)` 不入栈，主循环只在非空的那棵上跑，等价于输出它的中序序列，无需特判。
3. **重复值必须保留**：两棵树之间（示例 2 的 1 和 8）以及树内重复都不能去重；`<=` 与 `<` 只影响相等时从哪棵树取，结果都是合法答案。
4. **链状树导致递归爆栈**：5000 个结点的单链，递归中序在 Python 下必然 `RecursionError`（默认上限 1000）。本题的迭代写法是必需的，不是「可选的优化」。
5. **忘记 `pushLeft(cur.right)`**：这是最常见的实现错误，会导致右子树的元素整体丢失；用示例 1 自测时表现为答案少了 3、4。
6. **比较前未判空**：若直接写 `st1.back()->val <= st2.back()->val`，在某棵树输出完、栈变空时会访问空容器。务必将「`st2` 为空」这一短路条件放在最前。
7. **把输入当成先序**：`[1,null,8]` 表示 1 的右孩子是 8，而不是「先序 1、8」；建树/理解示例时容易看错，进而误判中序序列。
8. **结果顺序要求非降而非严格递增**：不要误加去重逻辑（如 `if not ans or ans[-1] != cur.val`），否则示例 2 会输出 `[1,8]`。
