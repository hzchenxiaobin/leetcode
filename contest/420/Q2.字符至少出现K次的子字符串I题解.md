# LeetCode 字符至少出现 K 次的子字符串 I 题解

## 1. 题目概述

- **标题 / 题号**：字符至少出现 K 次的子字符串 I（#3325，medium）
- **链接**：https://leetcode.cn/problems/count-substrings-with-k-frequency-characters-i/
- **来源**：LeetCode 第 420 场周赛 Q2
- **难度**：中等
- **标签**：滑动窗口、字符串、双指针、计数

**题意**：给定字符串 `s` 和整数 `k`，统计 `s` 的所有子字符串中，**至少有一个**字符出现次数**至少为** $k$ 的子字符串数目。子字符串是连续非空的字符序列。

**约束**：

- $1 \le s.length \le 3000$
- $1 \le k \le s.length$
- `s` 仅由小写英文字母组成

> 💡 **读题关键**：① 条件是「**存在**某字符频次 $\ge k$」的**至少型**条件——窗口越长越容易满足，这与常见的「至多型」模板方向相反，决定了计数姿势是「数左边」（见 §3.2）；② $n \le 3000$ 意味着 $O(n^2)$ 暴力也能过（周赛现场保底手段），但 $O(n)$ 滑窗代码更短，且是姊妹题 [3329. II 版](https://leetcode.cn/problems/count-substrings-with-k-frequency-characters-ii/)（Hard）的必备姿势；③ 答案上界 $\frac{n(n+1)}{2} \approx 4.5 \times 10^6$，`int` 足够。

## 2. 示例

**示例 1**

```text
输入：s = "abacb", k = 2
输出：4
解释：符合条件的子字符串：
     "aba"（'a' 出现 2 次）
     "abac"（'a' 出现 2 次）
     "abacb"（'a' 出现 2 次）
     "bacb"（'b' 出现 2 次）
```

**示例 2**

```text
输入：s = "abcde", k = 1
输出：15
解释：所有子字符串都有效——每个字符至少出现一次。
```

**边界用例（自造）**

```text
输入：s = "aaaa", k = 2
输出：6
解释：所有长度 >= 2 的子串中 'a' 都出现 >= 2 次，共 3 + 2 + 1 = 6 个。
```

## 3. 解题思路

### 3.1 暴力思路：枚举起点 + 增量频次 + 提前止损

枚举每个左端点，右端点逐步右移并**增量**维护 26 个频次：一旦窗口内出现频次达到 $k$ 的字符，由「扩窗封闭性」（§3.2），右端点继续右移的所有子串必然合法，直接累加 $n - right$ 并跳出内层循环。用「达标字符种数」做 $O(1)$ 判断，总体 $O(n^2)$——$n = 3000$ 约 $4.5 \times 10^6$ 次操作，本题可过。

问题在于**扫描的浪费**：同一段右部被每个起点反复扫描，全相同字符、$k = 2$ 时仍是 $\Theta(n^2)$；这只是吃了「数据范围放水」的侥幸，II 版数据范围放大后直接出局。

### 3.2 核心观察：至少型条件 → 固定右端点「数左边」

![核心观察：合法对扩窗封闭，固定右端点数左边](images/kfreq_substrings_concept.svg)

三条观察环环相扣：

**观察一：合法性对扩窗封闭。** 窗口变大，字符频次只增不减——若 $[i, j]$ 合法（某字符频次 $\ge k$），则它的任何超集 $[i', j'] \supseteq [i, j]$ 仍合法；等价地，**坏窗口（所有字符频次 $\le k-1$）对缩窗封闭**，子集只会更坏。

**观察二：固定右端点 $r$，合法起点是一段前缀。** 起点越小窗口越长，由观察一，若 $[l, r]$ 合法则一切 $l' \le l$ 也合法。于是以 $r$ 结尾的合法子串恰是 $l \in [0, L(r)]$；坏起点是后缀 $(L(r), r]$，其中 $[L(r)+1, r]$ 是**以 $r$ 结尾的最长坏窗口**。记其左边界为 $lo$，则以 $r$ 结尾的合法子串个数恰为 $lo$——「一个变量两个身份」。

**观察三：$lo$ 单调不降 → 双指针。** $r$ 右移后窗口只增不减，坏窗口若被破坏，只需从左端吐出字符即可恢复，$lo$ 全程只进不退——每个字符至多入窗、出窗各一次，总代价 $O(n)$。

> ⚠️ **方向对调**：经典计数滑窗（[713. 乘积小于 K 的子数组](https://leetcode.cn/problems/subarray-product-less-than-k/)）处理「**至多型**」条件——好窗口对**收缩**封闭，模板是外层 `right` + `shrink while bad` + `ans += right − left + 1`（数左边**短**串）；本题「**至少型**」恰好镜像——好窗口对**扩张**封闭，收缩循环要一直缩到窗口**重新变坏**，贡献是 `ans += lo`（数左边**长**串）。照抄至多型模板、把「恰好合法」的窗口长度当贡献，数出来的集合整个是错的。若嫌方向别扭，可取补集：总数 $\frac{n(n+1)}{2}$ 减去「每字符频次 $\le k-1$」的子串数，转化回至多型模板。

**O(1) 判定**：维护 `over` = 窗口内频次 $\ge k$ 的字符**种数**。入窗字符频次恰从 $k-1$ 变 $k$ 时 `over++`；出窗恰从 $k$ 降 $k-1$ 时 `over−−`。`over > 0` $\iff$ 窗口含达标字符，无需每步扫 26 个频次取最大值。

### 3.3 算法流程

![算法流程：外层枚举 r，入窗后收缩到最长坏窗口，ans += lo](images/kfreq_substrings_flow.svg)

外层 `r` 逐位右移；`s[r]` 入窗后，若 `over > 0`（窗口含达标字符、不再是坏窗口），从左端持续移出字符直至**重新变坏**——此时 `[lo, r]` 恰是以 $r$ 结尾的最长坏窗口，把 $lo$ 累进答案：

1. 初始化 `freq[26] = 0`、`over = 0`、`lo = 0`、`ans = 0`
2. 外层 `r` 从 $0$ 到 $n-1$：
   - `s[r]` 入窗（频次恰达 $k$ 则 `over++`）
   - 当 `over > 0`：移出 `s[lo]`（其频次恰从 $k$ 降则 `over−−`），`lo++`
   - `ans += lo`
3. 返回 `ans`

### 3.4 示例演算

![示例演算：s = "abacb", k = 2 的五轮滑窗与计数](images/kfreq_substrings_walkthrough.svg)

以 `s = "abacb"`、$k = 2$ 走一遍：

| $r$ | 入窗动作 | 收缩动作 | 最长坏窗口 $[lo, r]$ | 贡献 $lo$ | $ans$ |
|-----|----------|----------|----------------------|-----------|-------|
| 0（`a`） | a:1，over = 0 | 无需收缩 | $[0,0]$「a」 | 0 | 0 |
| 1（`b`） | b:1，over = 0 | 无需收缩 | $[0,1]$「ab」 | 0 | 0 |
| 2（`a`） | a:2 ⇒ over = 1 | 移出 s[0]「a」⇒ over = 0 | $[1,2]$「ba」 | 1 | 1 |
| 3（`c`） | c:1，over = 0 | 无需收缩 | $[1,3]$「bac」 | 1 | 2 |
| 4（`b`） | b:2 ⇒ over = 1 | 移出 s[1]「b」⇒ over = 0 | $[2,4]$「acb」 | 2 | 4 |

对照合法清单：$r=2$ 贡献 $l=0$ 的「aba」，$r=3$ 贡献 $l=0$ 的「abac」，$r=4$ 贡献 $l \in \{0,1\}$ 的「abacb」「bacb」——恰为示例 1 列出的 4 个子串。再验证示例 2（$k = 1$）：每个字符入窗即达标、随即把自己缩出窗外，每轮 $lo = r+1$，逐轮贡献 $1,2,3,4,5$，合计 $15$ ✓。

## 4. 算法细节

1. **窗口语义**：全程维护「以 $r$ 结尾的**最长坏窗口** $[lo, r]$」——所有字符频次 $\le k-1$。收缩循环条件 `over > 0` 在窗口重新变坏的瞬间自动停住，无需手动判断「加回一个字符是否合法」。
2. **over 的更新顺序**：入窗「先加后判」（`++freq[c] == k` 才 `over++`）；出窗「先判后减」（`freq[c] == k` 才 `over−−`，再 `−−freq[c]`）。顺序写反 `over` 会失真。
3. **贡献公式**：`ans += lo` 数的是起点 $\in [0, lo-1]$、终点为 $r$ 的子串——由观察二，这恰是以 $r$ 结尾的合法子串全集。窗口本身是**坏**窗口，与被计数的（**好**）子串错开一个位置，别误写成 `r − lo + 1`。
4. **收缩只需盯住 s[r]**：入窗前 $[lo, r-1]$ 是坏窗口（循环不变式），所有频次 $\le k-1$；入窗后唯一可能达到 $k$ 的字符只有 $s[r]$，因此收缩过程中 `over` 至多为 1，循环必然终止（最坏缩到空窗口）。
5. **字符集**：仅小写字母，`freq` 开 26；换成任意字符集则改用哈希表，`over` 维护方式不变，复杂度不变。

## 5. 正确性证明

**引理 1（封闭性）**：若 $[i, j]$ 合法，则任何 $[i', j'] \supseteq [i, j]$（$i' \le i \le j \le j'$）合法；若 $[i, j]$ 坏，则任何 $[i', j'] \subseteq [i, j]$ 坏。

**证明**：从 $[i, j]$ 扩为 $[i', j']$，每个字符频次不减；「合法 $\iff$ 存在字符频次 $\ge k$」，该字符在超集中频次只多不少。「坏 $\iff$ 所有字符频次 $\le k-1$」，子集中频次只少不多。∎

**引理 2（不变式）**：每轮收缩结束后，$[lo, r]$ 是以 $r$ 结尾的最长坏窗口——所有字符频次 $\le k-1$，且 $lo = 0$ 或 $[lo-1, r]$ 合法。

**证明**：对 $r$ 归纳。$r = 0$：$k \ge 2$ 时 $[0,0]$ 坏且 $lo = 0$；$k = 1$ 时收缩后 $lo = 1$（空窗坏），而 $[0,0]$ 中字符频次 $1 \ge 1$ 合法。
设第 $r-1$ 轮结束时 $[lo, r-1]$ 为最长坏窗口。加入 $s[r]$：其余字符频次不变仍 $\le k-1$，只有 $s[r]$ 可能达到 $k$。若未达标，$[lo, r]$ 坏，且 $[lo-1, r-1]$ 合法（归纳假设）$\subset [lo-1, r]$，由引理 1 知 $[lo-1, r]$ 合法。若达标（`over = 1`）触发收缩：每次移出一个字符，`over` 仅在「被移出字符频次恰为 $k$」时减一，而全过程中频次能达到 $k$ 的只有 $s[r]$，故循环恰在移出 $s[r]$ 的某次出现、其频次降至 $k-1$ 时终止，且最后移出的 $s[lo-1]$ 正是 $s[r]$ 的这次出现。于是 $[lo, r]$ 坏，而把 $s[lo-1]$ 加回后 $s[r]$ 频次回到 $k$，$[lo-1, r]$ 合法。∎

**定理**：算法返回值恰为合法子串总数。

**证明**：按右端点 $r$ 将所有子串分类，各类互斥，求和即得全部子串。对固定 $r$：由引理 2，$[lo, r]$ 坏 $\Rightarrow$ 由引理 1 其任何子集 $[l, r]$（$l \ge lo$）坏；又 $[lo-1, r]$ 合法 $\Rightarrow$ 由引理 1 一切 $[l, r]$（$l \le lo-1$，为其超集）合法。故以 $r$ 结尾的合法子串恰为 $l \in [0, lo-1]$ 共 $lo$ 个，与 `ans += lo` 一致。逐轮累加不重不漏，总和正确。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。$r$、$lo$ 各自单调前进，每个字符至多入窗、出窗各一次（摊还分析），每步频次与 `over` 的更新均为 $O(1)$。
- **空间复杂度**：$O(26) = O(1)$。频次数组大小固定，与 $n$ 无关。
- **暴力对照**：$O(n^2)$ 在 $n \le 3000$ 下约 $4.5 \times 10^6$ 次操作也能通过，是周赛现场的保底选项；II 版（#3329）放大 $n$ 后必须 $O(n)$。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int numberOfSubstrings(string s, int k) {
        int n = s.size();
        int freq[26] = {0};
        int over = 0, lo = 0;                       // over: 频次 >= k 的字符种数
        long long ans = 0;
        for (int r = 0; r < n; ++r) {
            if (++freq[s[r] - 'a'] == k) ++over;    // 入窗: 先加后判
            while (over > 0) {                      // 收缩到以 r 结尾的最长坏窗口
                if (freq[s[lo] - 'a'] == k) --over; // 出窗: 先判后减
                --freq[s[lo] - 'a'];
                ++lo;
            }
            ans += lo;                              // 起点在 [0, lo-1]、终点为 r 的子串全部合法
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def numberOfSubstrings(self, s: str, k: int) -> int:
        freq = [0] * 26
        over = lo = 0                  # over: 频次 >= k 的字符种数
        ans = 0
        for r, ch in enumerate(s):
            c = ord(ch) - 97
            freq[c] += 1
            if freq[c] == k:           # 入窗: 先加后判
                over += 1
            while over > 0:            # 收缩到以 r 结尾的最长坏窗口
                c2 = ord(s[lo]) - 97
                if freq[c2] == k:      # 出窗: 先判后减
                    over -= 1
                freq[c2] -= 1
                lo += 1
            ans += lo                  # 起点在 [0, lo-1]、终点为 r 的子串全部合法
        return ans
```

## 8. 边界情况与易错点

1. **别照抄「至多型」模板**：`ans += r − lo + 1` 数的是以 $r$ 结尾、起点 $\ge lo$ 的**更短**子串——对至少型条件恰恰**更不**合法，集合整个数错。正确贡献是 `ans += lo`（数**更长**的子串），或取补集转化回至多型。
2. **over 更新顺序**：入窗「先加后判」、出窗「先判后减」，写反会漏计或多计达标字符。
3. **k = 1**：所有非空子串合法，答案 $\frac{n(n+1)}{2}$；此时坏窗口恒为空（每轮 $lo = r+1$），逐轮贡献 $1, 2, \dots, n$，可作 sanity check（示例 2）。
4. **全同字符**：`s = "a…a"`、$k = 2$ 时合法子串即所有长度 $\ge 2$ 的子串，共 $\frac{(n-1)n}{2}$ 个。
5. **答案范围**：本题 $\le \frac{3000 \times 3001}{2} \approx 4.5 \times 10^6$，`int` 即可；II 版放大后必须 `long long`（Python 天然大整数无虞）。
6. **先收缩、后累加**：`ans += lo` 必须放在收缩循环之后——收缩未完成就累加，会把坏起点也数进去。
7. **收缩必然终止**：`over > 0` 时窗口内确有频次 $\ge k$ 的字符，最多把窗口缩空（$lo = r+1$，空窗 `over = 0`），不会死循环。
