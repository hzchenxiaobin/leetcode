# LeetCode 移除不同值重排数组 题解

## 1. 题目概述

- **标题 / 题号**：移除不同值重排数组（#4065，easy）
- **链接**：https://leetcode.cn/problems/rearrange-array-by-removing-distinct-values/
- **来源**：LeetCode 第 521 场周赛 Q1
- **难度**：简单
- **标签**：数组、哈希表、计数、排序、模拟

**题意**：给定整数数组 `nums`，初始 `ans` 为空。重复以下操作直到 `nums` 变空：找出当前 `nums` 中所有**不同**的值，把每个不同值**各移除一个**，并按**升序**依次追加到 `ans`。返回 `ans`。

**约束**：

- `1 <= nums.length <= 100`
- `1 <= nums[i] <= 100`

## 2. 示例

**示例 1**

```text
输入：nums = [3,1,3,2,1,3]
输出：[1,2,3,1,3,3]
解释：第 1 轮移除 1,2,3 各一个，剩余 [3,1,3]；
      第 2 轮移除 1,3 各一个，剩余 [3]；
      第 3 轮移除 3，nums 清空。
```

**示例 2**

```text
输入：nums = [7,7,4,4,4]
输出：[4,7,4,7,4]
解释：注意结果不是全局有序的——每轮内部升序，但下一轮的值可能比上一轮小。
```

**示例 3**

```text
输入：nums = [5,5,5]
输出：[5,5,5]
解释：每轮唯一的不同值都是 5，共执行 3 轮。
```

## 3. 解题思路

### 3.1 朴素思路：逐轮模拟

按题面直接模拟：每轮用哈希集合取出当前不同值，排序后拼进 `ans`，再把每个值的计数减一。最多 $10^2$ 轮、每轮 $O(n \log n)$，总量不过 $10^4$ 量级，对本题数据完全够用。但每轮都要重新收集集合、重新排序，"移除一个副本"的维护也写得琐碎——签到题值得找一条从题面到代码的更短路径。

### 3.2 核心观察：出现次数决定轮次——频率直方图逐层读出

设值 $v$ 的总出现次数为 $c_v$。每轮至多移走 $v$ 的一个副本，且只要 $v$ 还有副本就一定会被移走一个，因此：

> $v$ 在第 $r$ 轮仍存在 $\iff$ $c_v \ge r$；$v$ 恰好出现在第 $1, 2, \dots, c_v$ 轮。

于是**根本不需要真的反复移除**：第 $r$ 轮追加到 `ans` 的，就是所有满足 $c_v \ge r$ 的值升序排列。把每个值画成高度为 $c_v$ 的柱子，答案就是**从下往上逐层、每层从左到右读出直方图**：

![频率直方图逐层读出](images/wc521_q1_histogram_layers.svg)

以示例 1 为例：`cnt = {1:2, 2:1, 3:3}`，$M = 3$。第 1 层读出 `1,2,3`，第 2 层读出 `1,3`，第 3 层读出 `3`，拼接即 `[1,2,3,1,3,3]`。

### 3.3 算法流程

![计数与逐轮输出流程](images/wc521_q1_counting_flow.svg)

1. 扫一遍 `nums` 统计每个值的出现次数 `cnt[v]`（值域 $1 \sim 100$，直接开长度 101 的数组）
2. 求最大次数 $M = \max_v c_v$，这就是总轮数
3. 外层循环轮次 $r = 1 \dots M$，内层按值从小到大扫描：`cnt[v] >= r` 则把 `v` 追加进 `ans`
4. 循环自然结束，返回 `ans`

### 3.4 示例演算

![示例 1 逐轮演算](images/wc521_q1_example_walkthrough.svg)

计数视角与模拟视角逐轮对照：第 $r$ 轮的输出集合 $\{v : c_v \ge r\}$ 恰等于模拟中"当前仍存在的不同值"，两条路径每轮产出完全一致。

## 4. 算法细节

1. **计数表**：值域 $1 \le nums[i] \le 100$，C++ 用 `int cnt[101]` 最省事；Python 用 `Counter`。值从 1 开始，不必担心下标 0。
2. **轮数上界**：$M = \max_v c_v$，且 $n \ge 1$ 保证 $M \ge 1$，循环至少执行一轮。
3. **双重循环顺序**：外层轮次、内层值升序——顺序不能反，否则输出变成"按值分块"而非"按轮分层"。
4. **长度自校验**：值 $v$ 恰在 $r = 1 \dots c_v$ 共 $c_v$ 次被追加，输出总长 $\sum_v c_v = n$，天然与输入等长，无需额外检查。
5. **值域大时的等价实现**：对 `nums` 排序后给每个副本标记"同值内第几个"（层号），再按层号**稳定排序**一次成形，$O(n \log n)$——见延伸思考。

## 5. 正确性证明

**引理 1（轮次不变式）**：设值 $v$ 初始出现 $c_v \ge 1$ 次，则第 $r$ 轮开始时 $v$ 的剩余副本数为 $\max(c_v - r + 1,\ 0)$；特别地，$v$ 仍存在 $\iff r \le c_v$。

**证明**：对 $r$ 归纳。$r = 1$ 时副本数为 $c_v$，公式成立。设第 $r$ 轮开始时副本数为 $c_v - r + 1$。若 $r \le c_v$，则副本数 $\ge 1$，$v$ 是当前不同值之一，本轮恰被移除一个，剩余 $c_v - r = \max(c_v - (r{+}1) + 1,\ 0)$（因 $c_v - r \ge 0$）；若 $r > c_v$，副本数为 $0$，$v$ 不在当前不同值中，不被移除，仍为 $0$，与公式一致。归纳完成。∎

**引理 2（每轮输出）**：第 $r$ 轮追加到 `ans` 的是集合 $\{v : c_v \ge r\}$ 的升序排列。

**证明**：由引理 1，第 $r$ 轮开始时 `nums` 中的不同值集合恰为 $\{v : c_v \ge r\}$；操作定义将其中的每个值移除一个并按升序依次追加。∎

**定理**：模拟恰在第 $M = \max_v c_v$ 轮后终止，且计数算法的输出与模拟逐元素一致。

**证明**：由引理 1，第 $M$ 轮开始时存在 $c_v = M$ 的值 $v$ 仍有副本，模拟未终止；第 $M+1$ 轮开始时所有值满足 $c_v \le M < M + 1$，副本数全为 $0$，`nums` 为空，模拟恰执行 $M$ 轮。计数算法对 $r = 1 \dots M$ 依次输出 $\{v : c_v \ge r\}$ 的升序排列，由引理 2 与模拟每轮输出相同；又每个 $v$ 恰被输出 $c_v$ 次，总长 $\sum_v c_v = n$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n + D \cdot M)$，其中 $D \le 100$ 为不同值个数，$M \le n$ 为最大出现次数。计数一遍 $O(n)$，双重循环至多 $100 \times 100 = 10^4$ 次判断，本题规模下毫无压力；采用排序版本则为 $O(n \log n)$。
- **空间复杂度**：$O(D)$ 的计数表加 $O(n)$ 的输出数组（输出不计则为 $O(D)$）。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    vector<int> rearrangeArray(vector<int>& nums) {
        int cnt[101] = {0};
        for (int x : nums) cnt[x]++;
        int M = 0;
        for (int c : cnt) M = max(M, c);
        vector<int> ans;
        ans.reserve(nums.size());
        // 第 r 轮输出所有 cnt[v] >= r 的值（升序）
        for (int r = 1; r <= M; r++) {
            for (int v = 1; v <= 100; v++) {
                if (cnt[v] >= r) ans.push_back(v);
            }
        }
        return ans;
    }
};
```

### Python

```python
from collections import Counter


class Solution:
    def rearrangeArray(self, nums: list[int]) -> list[int]:
        cnt = Counter(nums)
        ans = []
        # 第 r 轮输出所有 cnt[v] >= r 的值（升序）
        for r in range(1, max(cnt.values()) + 1):
            ans.extend(v for v in sorted(cnt) if cnt[v] >= r)
        return ans
```

## 8. 边界情况与易错点

1. **每轮"各移除一个"，不是清空重复**：第 1 轮后重复值仍会残留副本（示例 1 的 `[3,1,3,2,1,3]` 一轮后剩 `[3,1,3]`），把"移除不同值"理解成"整体去重一遍"会直接丢数据。
2. **ans 不是全局有序的**：每轮内部升序，但轮与轮之间可以"回退"（示例 2 的 `[4,7,4,7,4]`）。**不能** `sort(nums)` 了事。
3. **全相同元素**：如 `[5,5,5]`，$M = 3$，每轮只输出一个 5，答案 `[5,5,5]`。
4. **全互不相同**：$M = 1$，一轮结束，答案恰为升序排序的 `nums`（如 `[2,1] → [1,2]`）。
5. **循环边界**：内层 $v$ 必须遍历到 $100$（值域含 $100$）；$n \ge 1$ 保证 $M \ge 1$，无需特判空轮。
6. **复杂度别误判**：双重循环是 $D \cdot M$ 而非 $n^2$，本题至多 $10^4$，不必为了"优化"改回逐轮模拟或引入堆/有序集合。

**延伸思考**：

- 若 $n$ 与值域增大（如 $n \le 10^5$），$D \cdot M$ 最坏可达 $\Theta(n^2)$（约一半值各出现一次、某个值占另一半时）。改用一次成形的 $O(n \log n)$ 做法：先按值排序，给每个副本标记"同值内第几个"作为层号，再按层号**稳定排序**——同层内保持值升序，恰好还原逐层读出的顺序。
- 若每轮要求**降序**追加，只需把内层扫描方向反过来；若要求输出每轮的分组而非拼接的一维数组，那就是 2610 本身。
