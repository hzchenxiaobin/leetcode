# LeetCode 移除不同值重排数组 题解

## 1. 题目概述

- **标题 / 题号**：移除不同值重排数组（#4065，easy）
- **链接**：https://leetcode.cn/problems/rearrange-array-by-removing-distinct-values/
- **来源**：LeetCode 第 521 场周赛 Q1
- **难度**：简单
- **标签**：数组、哈希表、计数、排序、模拟

**题意**：给定整数数组 `nums`，重复执行以下操作直到 `nums` 为空：找出当前 `nums` 中**所有不同的值**，把每个不同值**各移除一个**，并按**升序**依次追加到答案数组 `ans`。返回 `ans`。

**约束**：

- `1 <= nums.length <= 100`
- `1 <= nums[i] <= 100`

## 2. 示例

**示例 1**

```text
输入：nums = [3,1,3,2,1,3]
输出：[1,2,3,1,3,3]
解释：轮 1 取走 {1,2,3}，轮 2 取走 {1,3}，轮 3 取走 {3}，
      依次拼接得 [1,2,3] + [1,3] + [3] = [1,2,3,1,3,3]。
```

**示例 2**

```text
输入：nums = [7,7,4,4,4]
输出：[4,7,4,7,4]
解释：轮 1 取走 {4,7}，轮 2 取走 {4,7}，轮 3 取走 {4}，
      拼接得 [4,7] + [4,7] + [4]。
```

**示例 3（自定义：全部相同）**

```text
输入：nums = [5,5,5]
输出：[5,5,5]
解释：每轮只有一种不同值 5，各取走一个，三轮各追加 [5]。
```

## 3. 解题思路

### 3.1 直接模拟

最朴素的做法是严格照题面模拟：每轮统计当前剩余的不同值，排序后逐个追加到 `ans` 并把对应计数减一。设不同值个数为 $D$、最大出现次数为 $R$，共需 $R$ 轮，每轮 $O(D \log D)$ 排序，总量级 $O(R \cdot D \log D) \le 100 \times 100 \times 7 \approx 7 \times 10^4$，在 $n \le 100$ 下毫无压力，也能通过。

> 💡 但每轮重新"找不同值 + 排序"是重复劳动——每一轮取走的值集合只会**变小**（嵌套），相对顺序根本不变，这可以一次预处理掉。

### 3.2 核心观察：计数分层，按列读取

设初始时值 $v$ 出现 $cnt[v]$ 次，有两个关键事实：

1. **值 $v$ 恰好参与前 $cnt[v]$ 轮**：每轮只要 $v$ 还有剩余，它就是"不同值"之一、被取走恰好一个，所以 $cnt[v]$ 个拷贝恰好在第 $1, 2, \dots, cnt[v]$ 轮各被取走一个。
2. **轮内顺序恒定**：第 $r$ 轮取走的是 $\{\,v : cnt[v] \ge r\,\}$ 的**升序**排列——这永远是固定升序值表的子序列，直接对升序去重后的值表 `vals` 每轮从左到右扫一遍、跳过计数已归零的值即可。

把每个值的 $cnt[v]$ 个拷贝按行排开（行按值升序、左对齐），形成一张"柱状图"，则**第 $r$ 轮的输出恰好是第 $r$ 列自上而下**，`ans` 就是整张图**按列读取**的结果。

![核心观察：柱状图按列读取](images/wc521_q1_transpose_concept.svg)

这一观点把"逐轮操作数组"转化为"按列遍历计数矩阵"，与 [LeetCode 2610. 转换二维数组](https://leetcode.cn/problems/convert-an-array-into-a-2d-array-with-conditions/) 同构——那题要求每行元素互不相同，本题相当于再叠加"每行升序 + 逐行拼接"。

### 3.3 算法流程

![计数 + 逐轮扫描流程](images/wc521_q1_algorithm_flow.svg)

1. **桶计数**：值域仅 $1..100$，开长度 101 的桶数组统计 $cnt[v]$
2. **升序值表**：从小到大收集出现过的值得到 `vals`（桶序天然升序，无需再排序）
3. **逐轮扫描**：重复"从左到右扫一遍 `vals`，凡 $cnt[v] > 0$ 就把 $v$ 追加到 `ans` 并将 $cnt[v]$ 减一"，用 `changed` 标记本轮是否取走了元素
4. **终止**：某轮一个值都没取（所有计数归零），循环结束，返回 `ans`

### 3.4 示例演算

以示例 2 `nums = [7,7,4,4,4]` 为例，初始计数 $cnt[4]=3$、$cnt[7]=2$，升序值表 `vals = [4, 7]`：

![示例 2 逐轮演算](images/wc521_q1_example_walkthrough.svg)

三轮后所有计数归零，返回 $[4,7,4,7,4]$。注意每轮存活值集合是上一轮的**子集**（$\{4,7\} \to \{4,7\} \to \{4\}$），所以"固定顺序扫 `vals`"与"每轮重新排序"结果完全一致。

## 4. 算法细节

1. **桶计数替代哈希表**：$1 \le nums[i] \le 100$，用 `int cnt[101]` 即可；按 $1..100$ 顺序收集 `vals` 天然升序，省一次排序。值域更大时改用 `Counter` / `unordered_map` + `sort`
2. **轮内扫描而非重建集合**：每轮不重新建 set、不重新排序，直接复用同一个升序 `vals` 数组，靠 $cnt[v] > 0$ 过滤
3. **`changed` 标记终止**：一轮扫描结束若没有任何追加，说明所有计数为 0，退出；等价于固定循环 $\max_v cnt[v]$ 轮
4. **总输出长度恰为 $n$**：每个元素恰好被取走一次，`ans` 长度 $= n$，可 `reserve` 预分配
5. **无需真正删除**：题目只要求返回 `ans`，"从 nums 移除"用计数减一表达即可，不必动原数组

## 5. 正确性证明

**引理 1**：设初始计数为 $cnt[v]$，则第 $r$ 轮开始时 $v$ 的剩余数量为 $\max(cnt[v] - r + 1,\ 0)$；$v$ 恰在第 $1..cnt[v]$ 轮各被取走一个。

**证明**：对 $r$ 归纳。$r = 1$ 时剩余为 $cnt[v]$，成立。设第 $r$ 轮开始时剩余 $\max(cnt[v]-r+1, 0)$：若为正，则 $v$ 出现在当前数组中，属于本轮"所有不同的值"，被取走恰好一个，第 $r+1$ 轮开始时剩余 $\max(cnt[v]-r, 0)$；若为零，则 $v$ 不在数组中，不会被取走，且此时 $cnt[v] \le r - 1 < r$，剩余仍为 $\max(cnt[v]-r, 0) = 0$。归纳成立，且 $v$ 恰在剩余为正的第 $1..cnt[v]$ 轮各被取走一个。∎

**引理 2**：第 $r$ 轮追加到 `ans` 的一段恰为 $\{\,v : cnt[v] \ge r\,\}$ 的升序排列。

**证明**：由引理 1，第 $r$ 轮开始时 $v$ 有剩余 $\iff cnt[v] \ge r$，故本轮被取走的值集合即 $\{v : cnt[v] \ge r\}$；又题面规定按升序依次追加。∎

**定理**：算法（桶计数 + 逐轮扫描升序 `vals`、跳过计数为 0 的值）输出的数组与逐轮模拟的结果完全一致。

**证明**：算法第 $r$ 次扫描追加的值恰为 `vals` 中当前计数 $> 0$ 的值按升序排列。归纳假设前 $r-1$ 轮扫描后各值剩余计数 $= \max(cnt[v]-r+1, 0)$（$r=1$ 时显然成立，与引理 1 的模拟状态一致），则第 $r$ 次扫描时"当前计数 $> 0$" $\iff cnt[v] \ge r$，追加序列 $= \{v : cnt[v] \ge r\}$ 的升序排列，与引理 2 中第 $r$ 轮模拟的输出一致；扫描后计数变为 $\max(cnt[v]-r, 0)$，归纳保持。当所有计数为 0 时 `changed` 为假、算法终止；由引理 1 所有值在恰好 $\max_v cnt[v]$ 轮后取尽，故两序列逐段相等。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n + V + D \cdot R)$，其中 $V = 100$ 为值域（桶统计与收集开销），$D$ 为不同值个数，$R$ 为最大出现次数。扫描共 $R$ 轮、每轮过一遍 $D$ 个值；$D \cdot R \le 100 \times 100 = 10^4$，而追加总次数恰为 $n$，对 $n \le 100$ 绰绰有余。若用哈希表 + 排序实现则为 $O(n + D \log D + D \cdot R)$。
- **空间复杂度**：$O(V + n)$。桶数组 $O(V)$，输出数组 $O(n)$（不计输出则 $O(V)$）。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    vector<int> rearrangeArray(vector<int>& nums) {
        int cnt[101] = {0};
        for (int x : nums) cnt[x]++;
        vector<int> vals;                        // 值域从小到大收集，天然升序
        for (int v = 1; v <= 100; v++)
            if (cnt[v] > 0) vals.push_back(v);
        vector<int> ans;
        ans.reserve(nums.size());
        bool changed = true;
        while (changed) {                        // 每轮 = 从左到右扫一遍 vals
            changed = false;
            for (int v : vals) {
                if (cnt[v] > 0) {
                    ans.push_back(v);
                    cnt[v]--;
                    changed = true;
                }
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def rearrangeArray(self, nums: list[int]) -> list[int]:
        cnt = Counter(nums)
        vals = sorted(cnt)                       # 升序去重后的值表
        ans = []
        changed = True
        while changed:                           # 每轮 = 从左到右扫一遍 vals
            changed = False
            for v in vals:
                if cnt[v] > 0:
                    ans.append(v)
                    cnt[v] -= 1
                    changed = True
        return ans
```

「按列读取」观点的直接翻译——第 $r$ 列（轮）输出所有 $cnt[v] \ge r$ 的值：

```python
class Solution:
    def rearrangeArray(self, nums: list[int]) -> list[int]:
        cnt = Counter(nums)
        vals = sorted(cnt)
        return [v for r in range(1, max(cnt.values()) + 1)
                  for v in vals if cnt[v] >= r]
```

## 8. 边界情况与易错点

1. **全部相同**：`[7,7,7]` 每轮只取走一个 7，输出 `[7,7,7]`——不要误以为一轮取完。
2. **全部不同**：`[3,1,2]` 一轮取完，输出 `[1,2,3]`，等价于整体排序。
3. **单元素**：`[5] → [5]`。终止条件是"本轮无任何追加"，首轮取走后次轮空转退出，不要另外写基于 `nums` 长度的判断。
4. **不要用 set 去重后丢次数**：只保留不同值会漏掉重复拷贝，必须带计数。
5. **升序别忘**：每轮追加必须升序；桶序 / 预排序的 `vals` 保证了这一点。每轮对存活值重新排序也不会错，但属重复劳动。
6. **规模与溢出**：$n \le 100$、值域 $\le 100$，任何 $O(n^2)$ 内的做法都可通过，无需堆或有序集合；输出长度恰为 $n$，无溢出风险。
