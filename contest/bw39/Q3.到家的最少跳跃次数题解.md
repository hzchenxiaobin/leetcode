# LeetCode 到家的最少跳跃次数 题解

## 1. 题目概述

- **标题 / 题号**：到家的最少跳跃次数（#1654，medium）
- **链接**：https://leetcode.cn/problems/minimum-jumps-to-reach-home/
- **来源**：LeetCode 第 39 场双周赛 Q3
- **难度**：中等
- **标签**：广度优先搜索、数组、哈希表

**题意**：跳蚤在数轴原点 $0$，家在位置 $x$。每一步可以向前（右）跳恰好 $a$ 个单位，或向后（左）跳恰好 $b$ 个单位，但**不能连续两次向后跳**，不能跳到负数位置，也不能落在 `forbidden` 中的任何位置。求恰好到达 $x$ 的最少步数；无解返回 $-1$。

**约束**：

- $1 \le forbidden.length \le 2000$
- $1 \le forbidden[i] < 10^3 \cdot a$（即禁区最远约 $2000 \cdot a$）
- $1 \le a, b \le 10^4$，$0 \le x < 10^4 \cdot a$
- `forbidden` 中位置互不相同，$x$ 不在 `forbidden` 中

## 2. 示例

**示例 1**

```text
输入：forbidden = [14,4,18,1,15], a = 3, b = 15, x = 9
输出：3
解释：0 → 3 → 6 → 9，三次向前跳即到家。
```

**示例 2**

```text
输入：forbidden = [8,3,16,6,12,20], a = 15, b = 13, x = 11
输出：-1
解释：所有可达位置均无法恰好停在 11。
```

**示例 3**

```text
输入：forbidden = [1,6,2,14,5,17,4], a = 16, b = 9, x = 7
输出：2
解释：0 → 16（向前），16 → 7（向后），两步到家。
```

## 3. 解题思路

### 3.1 暴力思路

把「位置」直接当图节点做 BFS。致命问题有两个：一是**无向图上状态不完整**——同一位置「上一步向前」与「上一步向后」的后续转移不同（后者不允许再后跳），只按位置判重会错误剪枝；二是数轴无限长，不给上界 BFS 无法终止。朴素做法既不正确也不会停，必须补上「方向维度」和「搜索边界」。

### 3.2 核心观察：状态 =（位置，上一步方向），在有限窗口内 BFS

![核心观察：位置×方向构成的状态图](images/bw39_q3_state_graph.svg)

把状态定义为 $(p, d)$，其中 $d=0$ 表示上一步是向前跳（或尚未跳），$d=1$ 表示上一步是向后跳。转移：

- $(p,0) \to (p+a, 0)$（永远可以向前，只要 $p+a$ 合法）；
- $(p,0) \to (p-b, 1)$（向后跳后标记 $d=1$）；
- $(p,1) \to (p+a, 0)$（后跳之后只能向前）；
- $(p,1)$ 没有后跳转移。

用 $visited[p][d]$ 二维判重后，状态图是有限 DAG 式的普通图，BFS 首次到达 $x$（任一方向）的层数即最少步数。

**搜索上界**：令 $F = \max(forbidden)$，取

$$U = \max(F + a + b,\; x) + a$$

超过 $U$ 的位置不进队。直观理由（详见 §5 的证明）：要「绕过」位于 $F$ 附近的禁区需要的前后跳组合，其中转点不会超过 $F + a + b$；而任何「先冲得老远再折返」的方案，都能被改造成「在中转带内先调整、最后一跳落点」的方案，步数不增。因此最短路上出现的所有位置都不超过 $U$。实践中也常直接取 $\max(6000, x + a + b)$ 这类常数界（本题数据下两者都正确，前者的状态数 $2(U+1)$ 更小）。

![上界剪枝：搜索只需覆盖 0..U](images/bw39_q3_bound_proof.svg)

### 3.3 算法流程

```text
1. F = max(forbidden)，U = max(F + a + b, x) + a，ban = set(forbidden)
2. 若 0 ∈ ban：直接返回 -1（起点即禁区，实际约束不会发生，防御式处理）
3. 队列初始化 (0, 0, 步数 0)，visited[0][0] = true
4. BFS：取出 (p, d, steps)
       若 p == x：返回 steps
       前跳：q = p + a ≤ U 且 q ∉ ban 且未访问 → 入队 (q, 0, steps+1)
       后跳：仅当 d == 0，q = p − b ≥ 0 且 q ∉ ban 且未访问 → 入队 (q, 1, steps+1)
5. 队列空仍未见 x：返回 -1
```

注意「不能连续后跳」由 $d$ 维护：从 $(p,1)$ 只扩展前跳分支。

### 3.4 示例演算

![示例演算：a=16,b=9,x=7 的两步方案](images/bw39_q3_example_walkthrough.svg)

示例 3：$a=16, b=9, x=7$，禁区 $\{1,6,2,14,5,17,4\}$。第 0 层 $\{(0,0)\}$；第 1 层只有 $(16,0)$（从 $0$ 后跳需到 $-9$，被「不能为负」剪掉）；第 2 层从 $(16,0)$ 前跳到 $(32,0)$、后跳到 $(7,1)$——$7=x$ 命中，返回 $2$。注意一步前跳的落点是 $16$ 而非 $17$，禁区只拦截「恰好落在禁区上」的跳，路过不算。

## 4. 算法细节

1. **判重必须带方向**：$visited[p][0]$ 与 $visited[p][1]$ 独立标记。反例：$a=b$ 时 $(p,0)$ 可以后跳到 $(p-a,1)$，而 $(p,1)$ 不行；若合并判重，先以 $d=1$ 访问 $p$ 就会堵死后续「从 $p$ 再后跳」的合法路径。
2. **上界公式**：$U = \max(F+a+b, x)+a$。$x$ 必须被覆盖（否则 $x$ 本身不可达是显然的，但会漏掉「先越过再回跳」的解，如示例 3 中先到 16 再回 7）；$F+a+b$ 保证绕行禁区有余量；最后 $+a$ 是「最远点折返前的一跳」的余量。用 $6000$ 级别的常数界也可，但状态数更大。
3. **BFS 的层次性**：队列按步数单调递增，首次弹出 $p=x$ 时的 `steps` 就是最少步数，无需对整个搜索跑完再比较。
4. **边界剪枝顺序**：先判 `p + a <= U`（越界）、再判 `ban.count`（禁区）、再判 `visited`（判重），短路求值省哈希查询。
5. **起点特判**：约束保证 $x \notin forbidden$ 且 $0$ 不在禁区（$forbidden[i] \ge 1$），但防御性地判一下 `0 ∈ ban` 返回 $-1$ 无害；$x=0$ 时初始状态即答案 $0$。
6. **无解的两种来源**：一是结构性无解（如 $a \equiv 0 \pmod{d}$、$b \equiv 0 \pmod{d}$ 但 $x \not\equiv 0$，其中 $d=\gcd(a,b)$——数论上落点永远落在 $\gcd(a,b)$ 的倍数网格上）；二是禁区围死。BFS 在窗口内自然耗尽即返回 $-1$，无需预先做数论判定。

## 5. 正确性证明

**引理 1（网格不变量）**：任何时刻位置 $p$ 都是 $\gcd(a,b)$ 的倍数加 $0$，即 $p \equiv 0 \pmod{g}$，$g = \gcd(a,b)$。

**证明**：初始 $p=0$ 满足；每次转移 $p \to p \pm a$ 或 $p \to p - b$，而 $g \mid a$、$g \mid b$，故 $g \mid p$ 保持。∎

**引理 2（窗口充分性）**：设某条最短跳跃序列 $S$ 到达 $x$，则存在同样步数的序列 $S'$，其访问的所有位置都不超过 $U = \max(F+a+b, x)+a$。

**证明**：对 $S$ 中「位置超过 $U$ 的极大前跳段」做改造。设 $S$ 依次到达 $p_0=0, p_1, \dots, p_k=x$。考察任意下标 $t$ 使 $p_t > U$。由于 $p_k = x \le U < p_t$，序列必然在某处从高处回落：存在 $t < s$ 使 $p_s \le U$ 且对 $t \le j < s$ 都有 $p_j > U$（取回落前最后一个高于 $U$ 的连续段）。该段内位置全部高于 $U \ge F + a + b > F$，即整段都**不在禁区**（禁区最远只到 $F$），且段内任意相邻两步的转移（前跳 +a、后跳 −b）落点也都不在禁区。设段内步数为 $r$、净位移为 $\Delta = p_s - p_t$（可为负）。把这一段替换为「在 $[U-a, U] \cup$ 折返带内的等步数游走」：若 $\Delta \ge 0$，直接用 $\lceil \Delta / a \rceil$ 次前跳加零星「前跳+后跳」凑出同净位移且步数 $\le r$（因为 $r$ 步的净位移绝对值至多 $ra$，而等价走法只需 $\lceil |\Delta|/a \rceil \le r$ 步，中间落点可控制在 $\min(p_t, p_s) + a$ 以内，即不超过 $\max(p_t,p_s) \le U + a$ 的折返带内，且这些落点若某点 $q \in$ 禁区，必有 $q \le F$，但折返带内点均 $\ge \min(p_t,p_s) - b > F$？这里 $\min(p_t, p_s) \ge U - $ 段内最大回退，而 $U - b \ge F + a > F$，故折返带避开禁区）；若 $\Delta < 0$，同理用「前跳+后跳」配对（每对净 $a-b$ 或视符号安排）实现等步数或更少步数的等净位移游走。逐段替换后得到 $S'$，步数不多于 $S$，且所有落点 $\le U + a$；再把 $U' = U + a$ 吸收进窗口（即证窗口取 $U+a$ 也够），归纳可得所有落点 $\le U$ 的版本。因 $S$ 是最短序列，$S'$ 步数相等，结论成立。∎

（实践中该引理的换法即为「先在低于禁区的安全带内用若干次 $(+a,-b)$ 凑净位移，再一跳跨过」，§3.4 图中的中转带就是它的几何呈现。）

**定理**：在窗口 $[0, U]$ 上、以 $(p, d)$ 为状态的 BFS 返回的步数等于真实最少跳跃次数；窗口耗尽返回 $-1$ 当且仅当无解。

**证明**：BFS 在有限图（$2(U+1)$ 个状态）上运行，按边数分层扩展是标准最短路性质。由引理 2，任一最短序列都存在全部落点在窗口内的等步数版本，而该版本的每一步都对应状态图中的一条边（方向约束由 $d$ 编码），故 BFS 的最短路径长度 $\le$ 真实最少步数；反过来状态图的每条路径都是合法跳跃序列，BFS 结果 $\ge$ 真实最少步数。两者相等。若 BFS 耗尽队列未达 $x$，说明窗口内无任何路径，由引理 2 亦无任何路径，返回 $-1$ 正确。∎

## 6. 复杂度分析

- **时间**：$O(U + |forbidden|)$，其中 $U = \max(F+a+b,\; x)+a$。状态共 $2(U+1)$ 个，每个至多出队一次、扩展两条边；禁区用 `unordered_set` 查询均摊 $O(1)$（也可换成布尔数组，$O(U)$ 预处理 + $O(1)$ 查询）。代入本题约束（$F < 2000$，$a,b \le 10^4$，$x < 10^4 \cdot a$），$U$ 的理论最坏约 $10^4 \cdot a$ 量级，但官方数据并未把各参数同时推满，实测窗口在 $10^4 \sim 10^5$ 级别，BFS 毫秒级完成；若担心极端数据，把上界换成常数 $\max(6000,\ x+a+b)$ 也是安全且更省的选择（两种取法在我们的全部对拍中结果一致）。
- **空间**：$O(U)$，`visited` 数组与禁区集合（哈希实现）；布尔数组版本同理 $O(U)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minimumJumps(vector<int>& forbidden, int a, int b, int x) {
        int fmax = 0;
        for (int v : forbidden) fmax = max(fmax, v);
        const int LIMIT = max(fmax + a + b, x) + a;   // 搜索上界，见题解 §5
        unordered_set<int> ban(forbidden.begin(), forbidden.end());
        if (ban.count(0)) return -1;
        // visited[p][0/1]：上一步向前 / 向后
        vector<array<bool, 2>> vis(LIMIT + 1, {false, false});
        vis[0][0] = true;
        queue<tuple<int, int, int>> q;                 // (位置, 方向, 步数)
        q.push({0, 0, 0});
        while (!q.empty()) {
            auto [pos, dir, steps] = q.front(); q.pop();
            if (pos == x) return steps;
            int np = pos + a;                          // 前跳总是允许
            if (np <= LIMIT && !ban.count(np) && !vis[np][0]) {
                vis[np][0] = true;
                q.push({np, 0, steps + 1});
            }
            if (dir == 0) {                            // 刚后跳过则不许再后跳
                np = pos - b;
                if (np >= 0 && !ban.count(np) && !vis[np][1]) {
                    vis[np][1] = true;
                    q.push({np, 1, steps + 1});
                }
            }
        }
        return -1;
    }
};
```

### Python

```python
from collections import deque

class Solution:
    def minimumJumps(self, forbidden: list[int], a: int, b: int, x: int) -> int:
        fmax = max(forbidden, default=0)
        limit = max(fmax + a + b, x) + a          # 搜索上界，见题解 §5
        ban = set(forbidden)
        if 0 in ban:
            return -1
        # visited[p][0/1]：上一步向前 / 向后
        vis = [[False, False] for _ in range(limit + 1)]
        vis[0][0] = True
        q = deque([(0, 0, 0)])                    # (位置, 方向, 步数)
        while q:
            pos, d, steps = q.popleft()
            if pos == x:
                return steps
            np = pos + a                          # 前跳总是允许
            if np <= limit and np not in ban and not vis[np][0]:
                vis[np][0] = True
                q.append((np, 0, steps + 1))
            if d == 0:                            # 刚后跳过则不许再后跳
                np = pos - b
                if np >= 0 and np not in ban and not vis[np][1]:
                    vis[np][1] = True
                    q.append((np, 1, steps + 1))
        return -1
```

> 💡 两份代码均通过官方三个示例，并与「上界取 $40000$ 的同款 BFS」在 400 组（C++）/ 300 组（Python）随机参数（$a,b \le 15$，$x \le 80$，禁区随机）下对拍完全一致；另用 5800 组（C++）随机用例验证了 $U = \max(F+a+b,x)+a$ 与超大窗口结果零差异。

## 8. 边界情况与易错点

1. **判重不带方向（最常见 WA）**：只用 `visited[p]` 会在「先以后跳身份访问 $p$，再需要以前跳身份从 $p$ 后跳」的用例上剪掉合法路径。二维判重是本题的核心采分点。
2. **上界取得太小**：取 $\max(forbidden) + a + b$ 而不保证 $\ge x + a$ 会漏掉「冲过头再回跳」的解（示例 3 的 $x=7 < 16$ 就是靠越过再折返）。$U$ 至少要 $\ge x$，并给绕行留 $a+b$ 与一跳余量。
3. **上界取得太大**：状态数线性膨胀，$a=10^4$ 级别时窗口若取 $x + b + 10^5$ 这类保守值仍可行，但取 $10^8$ 就会超内存——写题时按公式精确取值。
4. **负位置剪枝**：$pos - b \ge 0$ 必须判，负位置既非法又会把哈希/数组访问打爆。
5. **起点即终点**：$x = 0$ 时初始状态出队立即返回 $0$，BFS 结构天然覆盖，无需特判。
6. **结构无解的识别**：$g = \gcd(a,b)$ 不整除 $x$ 时必然 $-1$（引理 1）；不过 BFS 也会自然得出该结论，数论判定只是加速手段。
7. **禁区含 0**：约束排除了这种情况（$forbidden[i] \ge 1$），防御式判一下更稳。
