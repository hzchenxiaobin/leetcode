# LeetCode 使字符串平衡的最少删除次数 题解

## 1. 题目概述

- **标题 / 题号**：使字符串平衡的最少删除次数（#1653，medium）
- **链接**：https://leetcode.cn/problems/minimum-deletions-to-make-string-balanced/
- **来源**：LeetCode 第 39 场双周赛 Q2
- **难度**：中等
- **标签**：字符串、动态规划、栈

**题意**：字符串 $s$ 只含 `'a'` 与 `'b'`。称 $s$ **平衡**，当且仅当不存在下标对 $(i,j)$，$i<j$，$s[i]=\texttt{b}$ 且 $s[j]=\texttt{a}$（即任何一个 `b` 后面都不能再出现 `a`）。可以删除任意字符，求使 $s$ 平衡的最少删除次数。

**约束**：

- $1 \le |s| \le 10^5$
- $s[i] \in \{\texttt{a}, \texttt{b}\}$

## 2. 示例

**示例 1**

```text
输入：s = "aababbab"
输出：2
解释：删除第 2、6 个字符（0 下标）得 "aaabbb"；
      或删除第 3、6 个字符得 "aabbbb"。两种方案都删 2 个。
```

**示例 2**

```text
输入：s = "bbaaaaabb"
输出：2
解释：唯一最优是删掉最前面的两个 b，剩下 "aaaaabb"。
```

**示例 3（边界补充）**

```text
输入：s = "a"
输出：0
解释：单个字符已经平衡（没有 b 在 a 前面的对）。
```

## 3. 解题思路

### 3.1 暴力思路

枚举要删除的字符子集（$2^n$ 种）并检查每个剩余串是否平衡——指数级，$n=10^5$ 下完全不可行。退一步的「正确暴力」是前缀计数：预处理 $preB[i]$（前 $i$ 个字符中 `b` 的个数）与 $sufA[i]$（下标 $i$ 之后 `a` 的个数），枚举分界点取 $\min_i preB[i] + sufA[i]$，$O(n)$ 时间、$O(n)$ 空间，其实已经能过。下面把它压到一遍扫描、$O(1)$ 空间。

### 3.2 核心观察：平衡串 ⟺ 存在分界点，左边全 a 右边全 b

![核心观察：分界点两侧各自清理](images/bw39_q2_split_model.svg)

**平衡串的结构**必然形如 `aaa...abbb...b`：若它平衡且含有 `b`，则最后一个 `b` 之后不能再有 `a`；若有 `a` 在某个 `b` 之前，则那个 `b` 与这个 `a` 构成违规对。所以平衡串 = 若干 `a` 拼若干 `b`（任一侧可为空）。

于是「保留尽量多的字符」等价于：**选定一个分界位置 $i$（$0 \le i \le n$），把前 $i$ 个位置里的 `b` 全删掉、后 $n-i$ 个位置里的 `a` 全删掉**，剩下的串一定形如 `a...ab...b`，平衡。代价为

$$cost(i) = (\text{前 } i \text{ 个字符中 b 的个数}) + (\text{第 } i+1 \dots n \text{ 个字符中 a 的个数})$$

答案即 $\min_{0 \le i \le n} cost(i)$。任何一种删除方案所得的平衡串都能这样描述（取「最后一个保留的 a 的位置」为分界），所以枚举分界点已覆盖全部最优解。

### 3.3 算法流程：一遍滚动

设 $cntB$ 为已扫过前缀中 `b` 的个数，$cntA$ 为尚未扫描后缀中 `a` 的个数（初始 $cntA = $ 全串 `a` 总数，对应分界点 $i=0$，即「把所有 a 删光」的代价上界）。从左到右扫描：

```text
1. cntA = count('a', s), cntB = 0, ans = cntA          # 分界 i=0：删光所有 a
2. 对每个字符 c = s[0..n-1]：
       若 c == 'a'：cntA -= 1   # 这个 a 现在位于分界左侧，不必删
       若 c == 'b'：cntB += 1   # 这个 b 位于分界左侧，必须删
       ans = min(ans, cntA + cntB)                      # 分界点滑到 i+1
3. 返回 ans
```

扫描到下标 $j$ 并处理完 $s[j]$ 后，$cntB = preB[j+1]$、$cntA = sufA[j+1]$，正好对应分界点 $i = j+1$ 的 $cost$；连同初始的 $i=0$，全部 $n+1$ 个分界点都被枚举。

### 3.4 示例演算

![示例演算：bbaaaaabb 的分界代价表](images/bw39_q2_prefix_suffix_walkthrough.svg)

对 $s = $ `bbaaaaabb`：初始 $cntA = 6$（六个 a），$ans = 6$。逐字符滚动后各分界点的 $cost$ 为 $4, 5, 6, 5, 4, 3, \mathbf{2}, 2, 2$——最小值 $2$ 出现在分界点 $6$（前 6 个字符是 `bbaaaa`，删 2 个 b；后 2 个是 `bb`，无 a 需删），与示例答案一致。

## 4. 算法细节

1. **两个计数器的语义要钉死**：$cntB$ 数的是「已扫过前缀」里的 b（分界左侧必须删的），$cntA$ 数的是「未扫过后缀」里的 a（分界右侧必须删的）。一个向前看、一个向后看，滚动时刚好一个 `+` 一个 `−`。
2. **初始值 $ans = cntA$ 不可省**：它对应「分界点在位置 0」的方案（删光所有 a，剩下全 b），扫描循环只覆盖 $i \ge 1$ 的分界点。
3. **相等元素无影响**：`a`/`b` 是仅有的字符，不需要任何比较逻辑，分支只有两个。
4. **为什么不用栈**：本题也有「栈模拟删除」的解法——遇到 `ba` 相邻对就同时弹掉并计数，但那本质上是同一个贪心的另一种表述；分界点 DP 更容易推广（见延伸思考）。
5. **数据类型**：计数上限 $10^5$，`int` 足够。

## 5. 正确性证明

**引理 1（平衡串的结构）**：只含 `a`、`b` 的字符串平衡，当且仅当它形如 $a^p b^q$（$p, q \ge 0$）。

**证明**：（⟸）$a^p b^q$ 中任何 `b` 的下标都大于任何 `a` 的下标，不存在 $i<j$ 且 $s[i]=\texttt{b}, s[j]=\texttt{a}$ 的对，故平衡。（⟹）反设平衡串中存在某个 `b` 在某个 `a` 之前，即有下标 $i<j$，$s[i]=\texttt{b}$，$s[j]=\texttt{a}$，这恰是题意禁止的对，矛盾。故所有 `a` 都在所有 `b` 之前，串形如 $a^p b^q$。∎

**引理 2（最优删除方案的分界表示）**：设 $D$ 为任一使 $s$ 平衡的删除方案，$T$ 为保留下的字符序列，则存在分界点 $i$，使 $D$ 删除的字符集 ⊆「前 $i$ 个中所有 b」∪「后 $n-i$ 个中所有 a」，且后者本身也是一个可行方案。

**证明**：$T$ 平衡，由引理 1 形如 $a^p b^q$。取 $i$ 为「$T$ 中最后一个 `a` 在原串中的下标」（$T$ 无 a 时取 $i=0$；$T = a^p$ 时取最后那个 a 的下标，下文论证同样成立）。由 $T$ 的结构：保留的 `a` 全部来自原串前 $i$ 个位置（下标 $\le i$），保留的 `b` 全部来自后 $n-i$ 个位置（下标 $> i$）——若某个保留下来的 `b` 下标 $\le i$，它的下标严格小于某个保留下来的 `a` 的下标（两者都 $\le i$ 且 `a` 的取法是「最后一个 a」，于是 $j_b < j_a$ 成立需要 $j_b \ne j_a$；若 $j_b < j_a$，则 $T$ 中 `b` 出现在 `a` 之前，与 $T = a^p b^q$ 矛盾），故不可能存在。

于是「删掉前 $i$ 个位置中的全部 `b` 与后 $n-i$ 个位置中的全部 `a`」这个方案 $D'$ 所得的串，恰由「前 $i$ 个位置的全部 `a`（$p' \ge p$ 个）拼后 $n-i$ 个位置的全部 `b`（$q' \ge q$ 个）」组成，形如 $a^{p'} b^{q'}$，由引理 1 平衡，故 $D'$ 可行。再比较删除数：$D$ 必须删掉前 $i$ 个位置中所有 `b`（前段论证了它们不可能被保留）、也必须删掉后 $n-i$ 个位置中所有 `a`（同理），即 $D$ 的删除集 $\supseteq$ $D'$ 的删除集，因此 $|D| \ge |D'| = preB(i) + sufA(i)$。∎

**定理**：$\min_{0 \le i \le n} \big(preB(i) + sufA(i)\big)$ 等于最少删除次数。

**证明**：一方面，对任意 $i$，「删前 $i$ 个中的全部 b 与后 $n-i$ 个中的全部 a」产生 $a^{p'}b^{q'}$ 形的平衡串（引理 1 的 ⟸ 方向），删除数 $preB(i)+sufA(i)$，故最优值 $\le$ 该最小值。另一方面，任一最优方案 $D^*$ 由引理 2 对应某个 $i$ 且 $|D^*| \ge preB(i)+sufA(i) \ge$ 该最小值。两个不等式夹逼即得。算法按 §3.3 的滚动逐一计算了全部 $n+1$ 个 $cost(i)$ 并取最小，返回值即该最小值。∎

## 6. 复杂度分析

- **时间**：$O(n)$。一次统计 `a` 总数 $O(n)$，一次扫描 $O(n)$，每字符 $O(1)$。
- **空间**：$O(1)$ 额外空间（只有三个整型计数器）；对比前缀/后缀数组版需要 $O(n)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minimumDeletions(string s) {
        int cntA = count(s.begin(), s.end(), 'a');   // 分界 i=0：删光所有 a 的代价
        int cntB = 0;
        int ans = cntA;
        for (char c : s) {
            if (c == 'a') --cntA;    // 该 a 进入分界左侧，不必删
            else         ++cntB;     // 该 b 位于分界左侧，必须删
            ans = min(ans, cntA + cntB);
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def minimumDeletions(self, s: str) -> int:
        cnt_a = s.count('a')          # 分界 i=0：删光所有 a 的代价
        cnt_b = 0
        ans = cnt_a
        for c in s:
            if c == 'a':
                cnt_a -= 1            # 该 a 进入分界左侧，不必删
            else:
                cnt_b += 1            # 该 b 位于分界左侧，必须删
            ans = min(ans, cnt_a + cnt_b)
        return ans
```

> 💡 两份代码均通过官方两个示例，并与「枚举全部 $2^n$ 子集检查平衡」的暴力在 2000 组（C++）/ 1500 组（Python）随机串（$n \le 12$）上对拍，`mismatch = 0`。

## 8. 边界情况与易错点

1. **全 a 或全 b**：`"aaaa"` 与 `"bbbb"` 都已平衡，答案 0。全 b 时 $cntA$ 初始为 0，滚动只会增大，$ans=0$ 正确；全 a 时 $ans$ 在扫到末尾时降为 0。
2. **单个字符**：`"a"`、`"b"` 答案均为 0，无需特判。
3. **忘记初始 $ans = cntA$**：它对应分界点 $i=0$ 的方案（删光所有 a）。循环只覆盖 $i \ge 1$ 的分界点。反例是 `"bba"`：各分界点的代价依次为 $1, 2, 3, 2$，最优 $1$ 只出现在分界 0（即 $cntA$）；若初始 $ans$ 设成 $+\infty$，循环内最小只能取到 $2$，返回错误值。务必初始化。
4. **滚动方向写反**：遇 `a` 应 $cntA{-}1$（右侧待删 a 变少）、遇 `b` 应 $cntB{+}1$；写成相反方向会得到「删光所有 b」这类单侧答案。
5. **$n$ 达 $10^5$**：任何 $O(n^2)$ 的朴素检查（如对每个前缀重新数一遍）在 C++ 里约 $10^{10}$ 次操作，必然超时；一遍扫描是安全线。
