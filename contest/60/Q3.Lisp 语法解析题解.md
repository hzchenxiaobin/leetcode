# LeetCode Lisp 语法解析 题解

## 1. 题目概述

- **标题 / 题号**：Lisp 语法解析（#736，hard）
- **链接**：https://leetcode.cn/problems/parse-lisp-expression/
- **来源**：LeetCode 第 60 场周赛 Q3
- **难度**：困难
- **标签**：栈、递归、哈希表、字符串

**题意**：给一个 Lisp 风格表达式串求整数值。表达式只有五种形态：整数字面量（可负、可为 0）、变量、`(add e1 e2)`、`(mult e1 e2)`、`(let v1 e1 v2 e2 ... vn en expr)`。求值按**括号嵌套划分作用域**，找变量先看最内层、再依次向外；`let` 体内的绑定按**顺序**生效，且只在该体内可见。

**约束**：

- $1 \le \lvert \text{expression} \rvert \le 2000$
- 无前导/尾随空格，相邻 token 之间恰好一个空格
- 答案与所有中间结果都在 32 位整数范围内
- 表达式保证合法，结果必为整数，不会出现未定义变量

## 2. 示例

**示例 1**
```text
输入：expression = "(let x 2 (mult x (let x 3 y 4 (add x y))))"
输出：14
解释：内层 (add x y) 的 x 先命中最内层 x = 3，故 3 + 4 = 7；
      回到外层 (mult x 7)，内层已退出，x 又是 2，故 2 * 7 = 14。
```

**示例 2**
```text
输入：expression = "(let x 3 x 2 x)"
输出：2
解释：绑定按顺序处理，x 先赋 3、再被 2 覆盖，末位 expr 求值为 2。
```

**示例 3**
```text
输入：expression = "(let x 1 y 2 x (add x y) (add x y))"
输出：5
解释：第一个 (add x y) = 3 并写回 x；第二个 (add x y) = 3 + 2 = 5。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的想法是**字符串替换**：反复找出最内层不含嵌套括号的片段，求值成字面量，再把变量名替换成数字，直到全串变成一个数。这条路能跑通，但有两处硬伤。其一，替换必须**按 token 对齐**：直接 `replace("x", "2")` 会误伤 `xyz`、`xx` 里的 `x`，要安全就得先切词，又绕回「括号配平」上。其二，**遮蔽语义要手工维护**：绑定只在 `let` 体内有效，出体后同名变量得恢复成外层旧值，替换模型里等于每次进出作用域都存一份 $O(n)$ 快照，总代价退化到 $O(n^2)$ 以上；**难点不在改写字符串，而在作用域的进出**——那就别改写，直接照语法结构求值。

### 3.2 核心观察：括号即作用域边界

![括号嵌套对应作用域链](images/wc60_q3_scope_chain.svg)

- 每个 `(` 开启一层新作用域；`add` / `mult` 不放绑定，`let` 才往里写变量。
- 变量查找**自内向外**：从栈顶扫到栈底，第一个命中的绑定就是答案。
- 作用域是**栈式**的：进入 `let` 体 push 一层，求出体的值后 pop，外层同名绑定立刻恢复可见——示例 1 的 `x` 先读到 3、出内层又读回 2。
- `let` 的绑定是**顺序**语义：第 $i$ 对 $(v_i, e_i)$ 的 $e_i$ 可引用 $v_1,\dots,v_{i-1}$，因此必须「求一个、写一个」。

于是算法只剩两件事：**按括号配平切 token**，**递归求值 + 作用域栈**。

### 3.3 算法流程

![eval 的三路分派](images/wc60_q3_eval_flow.svg)

1. **不以 `(` 开头**：首字符是 `-` 或数字 ⇒ `stoi` 得整数；否则是变量 ⇒ 沿作用域栈自内向外查，返回首个命中值。
2. **以 `(` 开头**：剥掉最外层括号，把内部切成 token——遇到 `(` 用配平计数（`(` 加一、`)` 减一、归零处收尾）整段截出；否则取到下一个空格前的原子（数字或变量名）。
3. 看 `token[0]`：`let` ⇒ push 空作用域，$i=1$ 起每轮先 `eval(tok[i+1])` 并把结果写入当前层的 `tok[i]`，$i \mathrel{+}= 2$，循环结束后 `tok[i]` 是末位 `expr`，求值、pop、返回；`add` / `mult` ⇒ 求两个子表达式再相加/相乘。

### 3.4 示例演算

![示例 1 的逐步演算](images/wc60_q3_example_trace.svg)

对示例 1 的 `(let x 2 (mult x (let x 3 y 4 (add x y))))`：

| 步骤 | 当前求值对象 | 作用域（内 → 外） | 结果 |
|------|--------------|-------------------|------|
| 1 | `(let x 2 ...)` | `{x=2}` | push |
| 2 | `(let x 3 y 4 (add x y))` | `{x=3, y=4}` 叠在 `{x=2}` 上 | push |
| 3 | `(add x y)` | 命中内层 `x=3`、`y=4` | 7 |
| 4 | `(mult x 7)` | 内层已 pop，命中外层 `x=2` | 14 |
| 5 | 整串结束 | 栈空 | 返回 14 |

示例 3 走的是顺序绑定：`x` 先算 `(add x y) = 3` 并写回，第二次 `(add x y)` 用新的 `x=3` 得 5——若改成「先全部求值再统一写入」的并行语义，答案会不同。

## 4. 算法细节

1. **切 token 必须配平**：`(add 1 (add 2 3))` 的内部是 `add 1 (add 2 3)`，按空格切会切碎子表达式；必须遇到 `(` 就往后数配平，到配平的 `)` 截断。
2. **原子判定有优先级**：先判 `expr[0] == '('`，再判 `'-'` 或 `isdigit`，最后才当变量名；顺序反了会把 `-12` 当变量。
3. **push/pop 配对**：进入 `let` 立刻压入新层（$e_i$ 求值时要能看到 $v_1,\dots,v_{i-1}$，它们就在这层），求出 body 后 pop；`add` / `mult` 不压栈。
4. **写入当前层**：`eval(tok[i+1])` 内部的递归会成对 push/pop，返回后 `scopes.back()` 仍是当前 `let` 这层，写入安全；为清晰可先取 `int idx = scopes.size() - 1`。
5. **同名覆盖直接写 map**：示例 2 的 `x 3 x 2` 就是覆盖语义，别用「禁止重复绑定」的 set。
6. **负数只作字面量**：题面保证 `-` 紧贴数字，不存在一元负号表达式，`stoi` / `int()` 直接吃掉；查找兜底的 0 不能当「未命中」哨兵，否则「值恰为 0」的变量会被误判。

## 5. 正确性证明

**引理 1（切分正确）**：剥掉复合表达式最外层括号后，`split` 的每个 token 恰好是体内一个完整原子或一段括号配平的子表达式。

**证明**：体内某位置若不是 `(`，它是原子开头，原子到下一个空格为止且不含空格与括号，截取正确。若是 `(`，合法表达式的括号必然配平，第一次计数归零处正是匹配的 `)`，故截出完整子表达式，其后紧跟空格或串尾。逐段推进覆盖整个体内串，无重叠无遗漏。∎

**引理 2（作用域链查找正确）**：栈 $S=(s_1,\dots,s_k)$（$s_k$ 最内层）下，变量 $v$ 的可见绑定是使 $v \in s_j$ 的最大下标 $j$；`lookup` 自 $k$ 递减扫描并返回首个命中，即返回该绑定。

**证明**：词法作用域定义即「最内层优先」，而栈序与括号嵌套深度一致（进 `let` push、退出 pop），下标越大越内层；自内向外首个命中恰是最大 $j$。题面保证合法表达式无未定义变量，故 $j$ 必存在。∎

**引理 3（顺序绑定）**：第 $i$ 轮求值 $e_i$ 时，当前层可见绑定恰为 $v_1,\dots,v_{i-1}$（外加各外层）。

**证明**：归纳。$i=1$ 时当前层为空；若第 $i$ 轮开始前当前层只有 $v_1,\dots,v_{i-1}$，该轮求值期间当前层不变（递归子调用 push/pop 成对，不动本层内容），写入 $v_i$ 后进入第 $i+1$ 轮，条件仍成立。∎

**定理**：`evaluate` 对任意合法表达式返回真实整数值。

**证明**：对结构归纳。叶子：数字由 `stoi` 直接正确；变量由引理 2 返回可见绑定，在合法整体求值下即其词法绑定，正确。`add` / `mult`：由归纳假设两子式求值正确，再做整数加/乘，正确。`let`：由引理 1，`tok[1..]` 恰是「变量名、$e_1$、变量名、$e_2$、…、末位 expr」；由归纳假设每次 `eval(tok[i+1])` 得真实值，由引理 3 求 $e_i$ 时的可见绑定与顺序语义一致；写入后末位 expr 的环境恰为该 `let` 的完整作用域，由归纳假设其值正确；最后 pop 恢复外层，故外层后续求值不受影响。∎

## 6. 复杂度分析

- **时间**：单次 `eval` 切分自己负责的子串需 $O(L)$，而其递归调用的各子式长度之和不超过 $L$，故 $T(L) = O(L) + \sum T(L_i)$。最坏（链式深嵌套）每个字符被每层祖先各扫一次，总代价 $O(n \cdot d) = O(n^2)$（$d$ 为嵌套深度且 $d = O(n)$）；$n \le 2000$ 时约 $4\times10^{6}$ 次字符比较，极轻松。
- **空间**：作用域栈内变量总数 $O(n)$，递归深度 $O(n)$（每个 `let` 至少 8 字符，实际不超过约 250 层），各层临时 token 列表合计 $O(n)$，故 $O(n)$。

## 7. 参考代码

### C++

```cpp
#include <string>
#include <vector>
#include <unordered_map>
using namespace std;

class Solution {
public:
    int evaluate(string expression) {
        vector<unordered_map<string, int>> scopes;   // 栈底最外层，栈顶最内层
        return eval(expression, scopes);
    }
private:
    int matchParen(const string& e, int i) {        // 与 e[i] 处 '(' 配对的 ')'
        int bal = 0;
        while (true) {
            if (e[i] == '(') ++bal;
            else if (e[i] == ')' && --bal == 0) return i;
            ++i;
        }
    }
    vector<string> split(const string& e) {         // 切成原子或整段子表达式
        vector<string> res;
        int n = (int)e.size();
        for (int i = 0; i < n; ) {
            if (e[i] == ' ') { ++i; continue; }
            int j = (e[i] == '(') ? matchParen(e, i) + 1 : i;
            while (e[i] != '(' && j < n && e[j] != ' ') ++j;
            res.push_back(e.substr(i, j - i));
            i = j;                                  // 原子后 j 指向空格，循环开头跳过
        }
        return res;
    }
    int lookup(const vector<unordered_map<string, int>>& scopes, const string& name) {
        for (int i = (int)scopes.size() - 1; i >= 0; --i) {
            auto it = scopes[i].find(name);
            if (it != scopes[i].end()) return it->second;   // 最内层优先
        }
        return 0;                                   // 合法输入下不会走到这里
    }
    int eval(const string& e, vector<unordered_map<string, int>>& scopes) {
        if (e[0] != '(') {                          // 叶子：整数或变量
            if (e[0] == '-' || isdigit((unsigned char)e[0])) return stoi(e);
            return lookup(scopes, e);
        }
        vector<string> tok = split(e.substr(1, e.size() - 2));
        if (tok[0] == "let") {
            scopes.emplace_back();                  // 进入 let：新作用域
            size_t i = 1;
            while (i + 1 < tok.size()) {            // 逐对 (vi, ei) 顺序求值
                int v = eval(tok[i + 1], scopes);
                scopes.back()[tok[i]] = v;          // 允许同名覆盖
                i += 2;
            }
            int res = eval(tok[i], scopes);         // 末位 expr 才是 let 的值
            scopes.pop_back();                      // 退出，恢复外层可见性
            return res;
        }
        if (tok[0] == "add") return eval(tok[1], scopes) + eval(tok[2], scopes);
        return eval(tok[1], scopes) * eval(tok[2], scopes);
    }
};
```

### Python

```python
class Solution:
    def evaluate(self, expression: str) -> int:
        def match(expr, i):                      # 与 expr[i] 处 '(' 配对的 ')'
            bal = 0
            while True:
                if expr[i] == '(':
                    bal += 1
                elif expr[i] == ')':
                    bal -= 1
                    if bal == 0:
                        return i
                i += 1

        def split(expr):                         # 切成原子或整段子表达式
            res, n, i = [], len(expr), 0
            while i < n:
                if expr[i] == ' ':
                    i += 1
                    continue
                if expr[i] == '(':
                    j = match(expr, i) + 1
                else:
                    j = i
                    while j < n and expr[j] != ' ':
                        j += 1
                res.append(expr[i:j])
                i = j                            # 原子后 j 指向空格，循环开头跳过
            return res

        def lookup(name):
            for sc in reversed(scopes):          # 自内向外，命中即停
                if name in sc: return sc[name]
            return 0                             # 合法输入下不会走到这里

        def ev(expr):
            if expr[0] != '(':                   # 叶子：整数或变量
                if expr[0] == '-' or expr[0].isdigit():
                    return int(expr)
                return lookup(expr)
            tok = split(expr[1:-1])
            if tok[0] == 'let':
                scopes.append({})                # 进入 let：新作用域
                i = 1
                while i + 1 < len(tok):          # 逐对 (vi, ei) 顺序求值
                    scopes[-1][tok[i]] = ev(tok[i + 1])
                    i += 2
                res = ev(tok[i])                 # 末位 expr 才是 let 的值
                scopes.pop()                     # 退出，恢复外层可见性
                return res
            if tok[0] == 'add':
                return ev(tok[1]) + ev(tok[2])
            return ev(tok[1]) * ev(tok[2])

        scopes = []
        return ev(expression)
```

## 8. 边界情况与易错点

1. **同一 let 重复绑定**：`(let x 3 x 2 x)` ⇒ 2，直接覆盖；做成「首次绑定生效」就会错。
2. **遮蔽与恢复**：`(let x 2 (mult x (let x 3 x)))` 内层返回 3、外层 `x` 仍是 2；用一张全局 map 而非栈必错。
3. **负数字面量**：`(mult -3 7)` ⇒ -21、`-12` ⇒ -12，判定时必须先看 `-`。
4. **切 token 配平**：`(add 1 (add 2 3))` 必须切成 `add`、`1`、`(add 2 3)` 三段，否则取参数越界。
5. **let 末位判定**：token 个数为奇数，循环条件 `i + 1 < len(tok)`，退出时 `tok[i]` 是 body；写成 `i < len(tok)` 会把 body 当绑定值。
6. **0 不是「查不到」的标记**：`(mult 0 5)` 的合法值就是 0；同理别把整张环境表按层复制，空间会退化到 $O(n^2)$。
