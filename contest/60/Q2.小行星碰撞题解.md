# LeetCode 小行星碰撞 题解

## 1. 题目概述

- **标题 / 题号**：小行星碰撞（#735，medium）
- **链接**：https://leetcode.cn/problems/asteroid-collision/
- **来源**：LeetCode 第 60 场周赛 Q2
- **难度**：中等
- **标签**：栈、数组、模拟

**题意**：数组 `asteroids` 从左到右给出每颗小行星，符号表示方向（正向右、负向左），绝对值表示体积，所有小行星速度相同。相遇时体积小的爆炸，体积相同则同归于尽，同向前进的永远追不上。求所有碰撞结束后的剩余序列（顺序不变）。

> 关键点：撞击只可能发生在「左侧一颗向右、右侧一颗向左」且中间没有别的行星阻隔的一对之间，序列长度在过程中只减不增。

**约束**：

- $2 \le |\text{asteroids}| \le 10^4$
- $-1000 \le \text{asteroids}[i] \le 1000$，且 $\text{asteroids}[i] \ne 0$
- 每颗小行星速度相同，方向只由符号决定

## 2. 示例

**示例 1**

```text
输入：asteroids = [5,10,-5]
输出：[5,10]
解释：10 与 -5 相撞，-5 体积更小爆炸，剩 [5,10]；5 与 10 同向，永不相撞。
```

**示例 2**

```text
输入：asteroids = [8,-8]
输出：[]
解释：两颗体积相同，同归于尽，结果为空数组。
```

**示例 3**

```text
输入：asteroids = [3,5,-6,2,-1,4]
输出：[-6,2,4]
解释：-6 连续撞碎 5 与 3 后继续向左；2 撞碎 -1 后继续向右；2 与 4 同向，永不相撞。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的做法是按物理时间模拟：给每颗行星一个坐标与速度，每轮求出「最早的一次碰撞时刻」，推进时间并消解那一对，直到没有任何相向而行的相邻对。思路正确，但每轮都要扫描全部相邻对找最早时刻，轮数为 $O(n)$，总复杂度 $O(n^2)$；$n = 10^4$ 时约 $10^8$ 次操作，Python 必然超时。

另一种「每轮把所有相撞的相邻对一起消掉」的写法同样要反复扫描整个数组，最坏也是 $O(n^2)$。浪费的根源是：**每次碰撞都把整个序列的稳定性重算了一遍**，而实际上只有新行星附近的状态真正变了。

### 3.2 核心观察：稳定前缀 + 只与栈顶比较

![稳定栈的形态：左段全向左、右段全向右](images/wc60_q2_stack_invariant.svg)

把已处理前缀的中间结果记作一个序列。稳定态的形状非常整齐：**左边一段全部向左，右边一段全部向右**（任一段可以为空）。段内方向相同追不上；交界处是「左负右正」，两者背向而行。所以稳定序列里根本不存在「左边向右、右边向左」这种相向的相邻对。

于是碰撞判据只剩一条：

$$\text{栈顶} > 0 \ \wedge\ a < 0$$

即「栈顶这颗向右，新来的这颗向左」。其余组合都不可能撞：新行星向右时它已在最右端、右侧无人；新行星向左而栈顶也向左时，栈内那颗在它左边、同样向左，永远追不上。

由此得到**稳定前缀 + 逐颗入栈**：从左到右处理每颗行星，把它与栈顶反复比较消解，直到它被撞碎或者不再与栈顶相向，再压入栈。旧的稳定前缀不会被破坏，一趟扫描即可。

### 3.3 算法流程

![栈解法流程：入栈前先与栈顶搏斗](images/wc60_q2_flow.svg)

1. 维护栈 `st`（初始为空），依次取出 `asteroids` 中的每颗行星 `a`。
2. 若 `a > 0`：栈内不可能有元素与它相向，直接 `push(a)`。
3. 若 `a < 0`：只要栈非空、栈顶 $> 0$（相向）且 `a` 还活着，就比较 $|a|$ 与 $|\text{栈顶}|$：
   - 栈顶更小：`pop` 掉栈顶，`a` 继续向左撞下一颗；
   - 两者相等：`pop` 掉栈顶，`a` 也随之爆炸，标记 `alive = false`；
   - 栈顶更大：`a` 爆炸，标记 `alive = false`。
4. `alive` 为真则把 `a` 压栈，否则丢弃，回到步骤 1 处理下一颗。
5. 扫描结束后 `st` 自底向上就是答案。

### 3.4 示例演算

以 `asteroids = [3,5,-6,2,-1,4]` 为例：

![演算表：逐颗行星与栈顶搏斗](images/wc60_q2_walkthrough.svg)

| 步骤 | $a$ | 与栈顶的搏斗 | 栈状态 |
| --- | --- | --- | --- |
| 0 | 3 | 正数，直接入栈 | [3] |
| 1 | 5 | 正数，直接入栈 | [3, 5] |
| 2 | −6 | 5、3 都比 6 小，连续 `pop` 两次，栈空后入栈 | [−6] |
| 3 | 2 | 正数，直接入栈 | [−6, 2] |
| 4 | −1 | 栈顶 2 更大，−1 爆炸 | [−6, 2] |
| 5 | 4 | 正数，直接入栈 | [−6, 2, 4] |

最终答案 $[-6, 2, 4]$。注意步骤 2：一颗 −6 连续吃掉两颗正数，说明「搏斗」必须写成循环，不能只判断一次。

## 4. 算法细节

1. **判据三条件缺一不可**：`a < 0 && !st.empty() && st.back() > 0`。`!st.empty()` 必须写在 `st.back()` 之前，靠短路求值避免空栈取栈顶。
2. **`alive` 标志区分两种结局**：`a` 被撞碎（退出循环且不入栈）与 `a` 撞碎别人后继续向左（留在循环里）。只用一个 `while` + 标志位，比嵌套 `if-else` 清晰得多。
3. **相等情形要单独成支**：`top == -a` 时双方都爆炸。若只写 `<` 与 `>` 两个分支，相等会落进「栈顶更大」分支，只销毁 `a`，漏掉栈顶。
4. **用 `vector`/`list` 当栈**：C++ 用 `push_back` / `back()` / `pop_back()`，Python 用 `append` / `[-1]` / `pop()`，都是均摊 $O(1)$；不要用 `std::stack`（无迭代器，最后还要倒出来）。
5. **比较用 `-a` 而不是 `abs(a)`**：已知 `a < 0`，`-a` 与 `abs(a)` 同值，省一次函数调用；C++ 里写成 `st.back() < -a` 即可。
6. **答案就是栈本身**：栈自底向上对应行星从左到右的位置顺序，不需要 `reverse` 或头插。
7. **避免 $O(n^2)$ 的写法**：不要用 `del st[0]`、`st[1:]` 这类从头部删除或整体切片重建的写法，也不要每轮重新扫描整个数组去判断是否已稳定；只操作栈顶才能保证均摊 $O(n)$。

## 5. 正确性证明

**引理 1（稳定不变式）**：每次外层循环结束时，栈 `st` 是稳定的，即不存在相邻的 $(\text{正}, \text{负})$ 对。

**证明**：初始空栈稳定。设处理 `a` 前栈稳定。

- 若 `a > 0`：新产生的相邻对是 $(\text{栈顶}, a)$，其右元素为正，不是 $(\text{正}, \text{负})$；其余相邻对未变，故稳定。
- 若 `a < 0`：循环每轮只弹出一个正栈顶，弹出后若新栈顶仍为正则继续被检查，因此循环终止时栈空或栈顶 $\le 0$。若 `a` 存活并压栈，新相邻对为 $(\text{非正}, \text{负})$，不是 $(\text{正}, \text{负})$，其余相邻对未变，稳定；若 `a` 爆炸，栈中剩下的是原稳定栈的一个前缀，其内部相邻对完全不变，稳定。

综上不变式成立。∎

**引理 2（碰撞对象唯一）**：处理 `a` 时，若发生碰撞，对手必是栈顶；且当且仅当 `a < 0` 且栈顶 $> 0$ 时才会碰撞。

**证明**：`a` 的位置在栈内所有元素右侧。碰撞要求两者相向：靠左的那颗向右，靠右的那颗向左。

- 若 `a > 0`：`a` 是靠右的一方却向右，与任何左侧元素都不构成相向，故不碰撞。
- 若 `a < 0`：能与之相向的栈内元素必须向右，即栈顶为正。`a` 向左移动，最先遇到的正是位置最靠右的栈内元素，也就是栈顶；栈内更靠左的元素被栈顶挡住，只有栈顶消失后才可能成为下一个对手——这恰好对应循环继续的条件。

∎

**引理 3（稳定序列内部不会再撞）**：若序列 $S$ 稳定，则在 $S$ 右侧追加一颗行星后，$S$ 内部元素之间不会再发生碰撞。

**证明**：设 $S$ 中相邻两颗速度为 $v_i, v_{i+1} \in \{+1, -1\}$，稳定性排除了 $v_i = +1, v_{i+1} = -1$，故间距 $p_{i+1} - p_i$ 的导数 $v_{i+1} - v_i \ge 0$，所有相邻间距单调不减，元素之间不会穿越，也就不会重合。又因为速度只在碰撞时改变，而 $S$ 内部不相撞，所以右侧新增的行星无法改变 $S$ 内元素的运动，$S$ 内部不再碰撞。∎

**定理**：算法输出的栈等于所有碰撞结束后的最终序列。

**证明**：对前缀长度 $i$ 归纳，设处理完前 $i$ 颗后栈等于该前缀的最终稳定序列 $F_i$。

- 基础：$i = 0$ 时栈为空，等于空前缀的最终序列。
- 归纳步：由归纳假设此时栈就是 $F_i$，且由引理 1 它稳定。由引理 3，追加第 $i+1$ 颗时 $F_i$ 内部不再碰撞，所有碰撞都发生在新增行星与 $F_i$ 的右端之间，并按位置从右向左依次发生——这正是 `while` 循环的消解顺序。由引理 2，循环终止条件（栈空或栈顶 $\le 0$）恰好是「新增行星向左行进时已无对手」。因此这一步的结果就是 $F_{i+1}$，且由引理 1 它稳定。

归纳至 $i = n$ 即得算法输出为最终序列。∎

## 6. 复杂度分析

- **时间**：$O(n)$。外层扫描 $n$ 颗行星；内层 `while` 每轮要么 `pop` 掉一颗已入栈的行星（此后它不再出现），要么让 `a` 爆炸并立即结束，因此每颗行星最多入栈一次、出栈一次，`while` 的总迭代次数不超过 $n$。
- **空间**：$O(n)$，栈最多存放 $n$ 颗行星（返回数组本身也是 $O(n)$）；除栈之外无需额外辅助空间，为 $O(1)$。

## 7. 参考代码

### C++

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> asteroidCollision(vector<int>& asteroids) {
        vector<int> st;                     // 稳定栈：栈内不会再有相向而行的一对
        for (int a : asteroids) {
            bool alive = true;
            // 仅当「栈顶向右(>0) 且 当前向左(<0)」才可能碰撞
            while (alive && a < 0 && !st.empty() && st.back() > 0) {
                if (st.back() < -a) {
                    st.pop_back();          // 栈顶被撞碎，a 继续向左
                } else if (st.back() == -a) {
                    st.pop_back();          // 同归于尽
                    alive = false;
                } else {
                    alive = false;          // a 被撞碎
                }
            }
            if (alive) st.push_back(a);
        }
        return st;
    }
};
```

### Python

```python
class Solution:
    def asteroidCollision(self, asteroids: list[int]) -> list[int]:
        st = []                      # 栈内始终保持稳定，不会再互相碰撞
        for a in asteroids:
            alive = True
            # 只有「栈顶向右 + 当前向左」才会碰撞，且当前行星可能连续撞掉多个
            while alive and a < 0 and st and st[-1] > 0:
                if st[-1] < -a:      # 栈顶更小，爆炸，继续用 a 向左撞
                    st.pop()
                elif st[-1] == -a:   # 同归于尽
                    st.pop()
                    alive = False
                else:                # 栈顶更大，a 爆炸
                    alive = False
            if alive:
                st.append(a)
        return st
```

## 8. 边界情况与易错点

1. **全同向 / 全为负**：`[1,2,3]` 与 `[-1,-2,-3]` 都原样返回。两颗都向左的行星不会相撞，不要把「相邻且同为负」误判成碰撞候选。
2. **体积相等**：`[8,-8]` → `[]`、`[5,-5,5,-5]` → `[]`。相等分支必须显式处理，否则会只销毁 `a` 而留下栈顶。
3. **一颗行星连续作战**：`[1,2,3,-9]` → `[-9]`、`[10,2,-5]` → `[10]`。必须用 `while`，写成 `if` 只能撞掉一颗。
4. **空栈取栈顶**：条件写成 `a < 0 && !st.empty() && st.back() > 0`；顺序写反会越界（C++ 是 UB，Python 抛 `IndexError`）。
5. **撞完后栈顶变负**：`[-2,1,-3]` → `[-2,-3]`。−3 撞掉 1 后栈顶变成 −2（同样向左），循环必须停止，不能继续比较。
6. **结果为空**：Python 返回 `[]`，C++ 返回空 `vector`（`return {};` 或直接返回栈），不要返回 `nullptr`。示例 2 就是这种情况。
7. **数值范围**：$|a| \le 1000$，`int` 比较不会溢出；但若要写成通用代码，`-a` 对 `INT_MIN` 会溢出，应写 `-(long long)a`。
