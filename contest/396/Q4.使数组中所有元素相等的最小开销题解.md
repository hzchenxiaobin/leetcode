# LeetCode 使数组中所有元素相等的最小开销 题解

## 1. 题目概述

- **标题 / 题号**：使数组中所有元素相等的最小开销（#3139，hard）
- **链接**：https://leetcode.cn/problems/minimum-cost-to-equalize-array/
- **来源**：LeetCode 第 396 场周赛 Q4
- **难度**：困难
- **标签**：贪心、数组、枚举、数学

**题意**：给定整数数组 `nums` 与两个操作定价 `cost1`、`cost2`，操作可执行任意次：

- **零售**：任选下标 $i$，令 $nums[i]$ 加 1，花费 $c_1$；
- **批发**：任选两个**不同**下标 $i \ne j$，令二者**同时**加 1，花费 $c_2$。

目标是让所有元素相等，返回最小总开销对 $10^9 + 7$ 取模的结果。

**约束**：

- $1 \le n = \mathrm{nums.length} \le 10^5$
- $1 \le nums[i] \le 10^6$
- $1 \le c_1, c_2 \le 10^6$

> 💡 读题三个信号：① 操作**只能加不能减**，终值 $T \ge mx$；② 批发必须落在**两个不同**元素上——这一行小字是全题的灵魂，它决定了批发「无法消化堆在单个元素上的缺口」；③ 取模只是输出格式，**最小化必须发生在取模之前**（模完大小关系就乱了）。

## 2. 示例

**示例 1**

```text
输入：nums = [4,1], cost1 = 5, cost2 = 2
输出：15
解释：缺口全在 nums[1] 上（g = [0,3]），批发让两个元素一起加、不改变差距，
      一次也用不了；只能零售 3 × 5 = 15。
```

**示例 2**

```text
输入：nums = [2,3,3,3,5], cost1 = 2, cost2 = 1
输出：6
解释：批发 4 次 + 零售 1 次：4 × 1 + 1 × 2 = 6。
```

**示例 3**

```text
输入：nums = [3,5,3], cost1 = 1, cost2 = 3
输出：4
解释：c₂ = 3 ≥ 2c₁ = 2，批发不如两次零售，全零售：(3×5 − 11) × 1 = 4。
```

**补充示例（抬升终值）**

```text
输入：nums = [1,5,5,5], cost1 = 100, cost2 = 1
输出：6
解释：T = 5 时缺口 [4,0,0,0] 全堆在一个元素上，S−d = 0，一次批发都做不了，
      只能全零售 400；抬到 T = 7，三个「已到站」元素被拉回来各捐 2 格缺口，
      独裁被稀释，6 次批发全部配对，只要 6。
```

## 3. 解题思路

### 3.1 暴力思路：枚举终值 + 优先队列模拟

终值 $T$ 固定后，每个元素的缺口 $g_i = T - nums[i]$ 就完全确定，问题变成「怎么用两种操作填掉这些缺口」。最直觉的暴力：枚举 $T$，用**大根堆**模拟——每次弹出缺口最大的两个元素做一次批发，只剩一个非零缺口时改零售。单轮模拟 $O((n + S)\log n)$，而 $S = nT - \Sigma$ 本身可达 $10^{11}$ 量级，乘上 $10^6$ 个候选 $T$，总量是天文数字；至于对数组状态做 BFS/DP，状态空间更是无穷无尽。

暴力的价值在于把问题**定型**：固定 $T$ 后这是一个纯组合问题——「批发最多能用几次、零头怎么算」。这个问题若能 $O(1)$ 回答，枚举的每一格就都变便宜了。

> ⚠️ 真正的坑不在模拟，而在**枚举范围**：$T = mx$ 未必最优（见补充示例），所以不能只算一个点就收工。

### 3.2 核心观察：固定 T 的闭式开销——批发次数的双瓶颈

![核心观察：固定 T 后批发次数 p = min(⌊S/2⌋, S−d)](images/equalize_cost_pairing_bound.svg)

记 $S = nT - \Sigma$ 为**总缺口**，$d = T - mn$ 为**最大缺口**（落在最小元素头上）。

**观察一（终值下界）**：只能加不能减，故 $T \ge mx$，且 $g_i \ge 0$。

**观察二（批发不划算就全零售）**：若 $c_2 \ge 2c_1$，任何一次批发都可替换成两次零售而不更贵（引理 8），于是全部零售、$T = mx$：

$$\text{ans} = (n \cdot mx - \Sigma) \cdot c_1$$

示例 3 走的就是这条路。

**观察三（配对双瓶颈）**：固定 $T$，设批发次数为 $p$：

- 每次批发消耗 **2 格**总缺口（两个不同元素各 +1）$\Rightarrow p \le \lfloor S/2 \rfloor$；
- 缺口最大的那个元素**没法和自己配对**：每次批发至少有 1 格落在「其余缺口」上 $\Rightarrow p \le S - d$。

关键是这两个上界**都能取到**（引理 2 的度序列构造），于是：

$$\boxed{\;p = \min\Big(\Big\lfloor \frac{S}{2} \Big\rfloor,\ S - d\Big),\qquad C(T) = p\,c_2 + (S - 2p)\,c_1\;}$$

其中 $S - 2p$ 是配不出去的零头，只能零售。直观贪心「每次挑缺口**最大的两个**元素配对」同样能达到 $p$。示例 1 恰是 $S - d = 0$ 的极端：独裁者一手遮天，一次批发都做不了。

### 3.3 抬升终值：C(T) 分段线性，最优只藏在 4 个候选点

![抬升终值：C(T) 分段线性，最优只藏在 4 个候选点](images/equalize_cost_piecewise_v.svg)

**观察四（抬升的稀释效应）**：$T$ 每抬 1 格，$S \mathrel{+}= n$、$d \mathrel{+}= 1$，于是 $S - d \mathrel{+}= n - 1$——已到站的元素被拉回来「捐」缺口，**其余缺口以每格 $n-1$ 的速度稀释独裁者**。当 $d$ 是瓶颈且 $c_2 \ll c_1$ 时，抬 $T$ 反而更省（补充示例：$400 \to 6$）。

把定义域 $[\,mx, +\infty)$ 按瓶颈归属切成两段（$n \ge 3$）：

- **d 瓶颈段**（$d \ge \lceil S/2 \rceil$，即 $(n-2)T \le \Sigma - 2mn$）：$p = S - d$，
  $$C(T) = (S-d)\,c_2 + (2d-S)\,c_1 \quad\text{是 } T \text{ 的线性函数，斜率 } \sigma = (n-1)c_2 - (n-2)c_1$$
- **⌊S/2⌋ 瓶颈段**（$d < \lceil S/2 \rceil$）：$p = \lfloor S/2 \rfloor$，
  $$C(T) = \lfloor S/2 \rfloor\,c_2 + (S \bmod 2)\,c_1 \quad\text{每抬 2 格 } +\,n c_2 \text{，按 } S \text{ 奇偶分类各自单调递增}$$

**赛时及格线**：两段各自的单调性保证最优落在 $[\,mx,\ 2mx - mn]$ 内（引理 6 证明切换点 $T^* \le 2mx - mn$），于是**全扫描**这个区间、每格 $O(1)$ 直算，$O(n + mx - mn)$ 稳过——这也是[每日题解](../../solution/3101-3200/3139_使数组中所有元素相等的最小开销.md)的主解法。

**本篇主解（打磨版）**：线性段的最优只在端点，递增段的最优只在开头——全局最优只需要查 **4 个候选点**：

$$T^* = \max\Big(mx,\ \Big\lceil \tfrac{\Sigma - 2mn}{n - 2} \Big\rceil\Big),\qquad \text{候选集} = \{\,mx,\ T^*-1,\ T^*,\ T^*+1\,\}$$

$T^*+1$ 的存在意义：$n$ 为奇数时 $S$ 的奇偶随 $T$ 交替，$S$ 为奇的格要花一个 $c_1$ 零头，多抬一格换一次奇偶可能反而省（当 $c_2 < c_1$ 时）。

![示例演算：例 2 的逐 T 表格与抬升反例](images/equalize_cost_walkthrough.svg)

**例 2**（$n = 5$，$\Sigma = 16$，$mn = 2$，$mx = 5$）：

| $T$ | $S = 5T-16$ | $d = T-2$ | $S-d$ | $\lfloor S/2 \rfloor$ | $p$ | 零售 $S-2p$ | $C(T)$ |
|-----|------------|-----------|-------|---------------------|-----|------------|--------|
| **5** | 9 | 3 | 6 | **4** | 4 | 1 | $4 \times 1 + 1 \times 2 = \mathbf{6}$ |
| 6 | 14 | 4 | 10 | **7** | 7 | 0 | 7 |
| 7 | 19 | 5 | 14 | **9** | 9 | 1 | 11 |
| 8 | 24 | 6 | 18 | **12** | 12 | 0 | 12 |

全程 $\lfloor S/2 \rfloor \le S - d$（总量瓶颈主导），越抬越贵，谷底就在 $T = mx$，答案 **6**。

**抬升反例**（$[1,5,5,5]$，$c_1 = 100$，$c_2 = 1$）：$T^* = \lceil (16-2)/2 \rceil = 7$，候选 $\{5, 6, 7, 8\}$。$T = 5$：$S = 4$，$d = 4$，$p = 0$，$C = 400$；$T = 7$：$S = 12$，$d = 6$，$S - d = 6 = \lfloor S/2 \rfloor$，$p = 6$ 全配对，$C = 6$——恰在切换点 $T^*$ 命中。

## 4. 算法细节

![算法流程：两个特判 + 切换点 + 四候选直算](images/equalize_cost_algorithm_flow.svg)

1. **预处理**：一次扫描收集 $n, mx, mn, \Sigma$ 四个标量，之后不再碰数组。
2. **特判一 $n \le 2$**：$T^*$ 公式分母 $n - 2$ 为零；且 $n = 2$ 时批发不改变差距（引理 7），直接返回 $(mx - mn) \cdot c_1 \bmod p$（$n = 1$ 自然为 0）。
3. **特判二 $c_2 \ge 2 c_1$**：全零售（引理 8），返回 $(n \cdot mx - \Sigma) \cdot c_1 \bmod p$。
4. **切换点**：$T^* = \max\big(mx,\ \lceil (\Sigma - 2mn)/(n-2) \rceil\big)$，注意**上取整**（见易错点 5）。
5. **候选评估**：对 $\{mx,\ T^*-1,\ T^*,\ T^*+1\}$ 中 $\ge mx$ 的每个 $T$，$O(1)$ 直算 $S, d, p, C$；全程用**完整数值**比较，只在返回前取一次模。
6. **数值范围**：$T \le 2mx - mn < 2 \times 10^6$，$S \le n \cdot 2mx \approx 2 \times 10^{11}$，$C$ 峰值约 $3 \times 10^{17}$——`long long` 全程安全，`int` 必炸；Python 大整数无虞。

## 5. 正确性证明

以下设 $n \ge 3$、$c_2 < 2c_1$（另两种情形见引理 7、8）。对 $T \ge mx$ 记 $g_i = T - nums[i]$，$S = \sum g_i = nT - \Sigma$，$d = \max g_i = T - mn$；最大缺口元素并列时任取其一，记为 $x$。

**引理 1（批发双上界）**：任何合法操作序列的批发次数 $p$ 满足 $p \le \lfloor S/2 \rfloor$ 且 $p \le S - d$。

**证明**：每次批发使两个不同元素各 +1，消耗 2 格总缺口，故 $2p \le S$。再设与 $x$ 同做批发共 $a$ 次：每次的另一端必须落在别的元素上，消耗 1 格「其余缺口」，故 $a \le S - d$；不与 $x$ 同做的批发共 $b = p - a$ 次，每次消耗 2 格其余缺口，$2b \le S - d - a$。于是
$$p = a + b \le a + \frac{S - d - a}{2} = \frac{a + S - d}{2} \le \frac{(S-d) + (S-d)}{2} = S - d. \;\blacksquare$$

**引理 2（可达性）**：$p = \min(\lfloor S/2 \rfloor,\ S - d)$ 次批发总能实现。

**证明**：把「元素 $i$ 参与批发的次数 $u_i \le g_i$」看作**不许自环的多重图度数**，由度序列理论，$u$ 可实现 $\iff$ $\sum u$ 为偶数且 $\max u \le \sum u - \max u$（构造上每次连当前度数最大的两点即可）。

- 若 $2d \le S$：取 $u_i = g_i$。$\sum u = S$，最大度 $d \le S - d$ 满足条件；$S$ 为奇数时任取一个正 $u_i$ 减 1（由 $2d \le S$ 与 $S$ 奇得 $2d \le S - 1$，条件仍成立）。得 $\lfloor S/2 \rfloor$ 条边。
- 若 $2d > S$：把 $u_x$ 压到 $S - d$，其余全取。$\sum u = 2(S - d)$ 为偶数，最大度 $S - d \le$ 其余度之和 $S - d$，满足。得 $S - d$ 条边。

每条边就是一次批发（落在两个不同元素上），剩余 $S - 2p$ 格缺口逐格零售。∎

**引理 3（固定 $T$ 的最优开销）**：$C(T) = p\,c_2 + (S - 2p)\,c_1$，$p = \min(\lfloor S/2 \rfloor, S - d)$。

**证明**：设批发 $k$ 次，由引理 1、2 可行域恰为 $k \in [0, p]$（不足 $p$ 的方案去掉若干批发、改两次零售即可）。总开销
$$f(k) = k\,c_2 + (S - 2k)\,c_1 = S\,c_1 + k\,(c_2 - 2c_1)$$
是 $k$ 的线性函数；$c_2 < 2c_1$ 时斜率为负，$k = p$ 最优。∎

**引理 4（d 瓶颈段线性 + 区间右端）**：记 $R_d = \{T \ge mx : d \ge \lceil S/2 \rceil\}$。在 $R_d$ 上 $C(T) = \big[(n-1)T - (\Sigma - mn)\big]c_2 + \big[\Sigma - 2mn - (n-2)T\big]c_1$ 是 $T$ 的线性函数（斜率 $\sigma = (n-1)c_2 - (n-2)c_1$）；且 $R_d = [\,mx, \tau\,]$（可能为空），右端 $\tau \in \{T^*-1,\ T^*\}$。

**证明**：代入 $S = nT - \Sigma$、$d = T - mn$ 展开即得线性。区域条件 $d \ge \lceil S/2 \rceil \iff 2d - S \ge S \bmod 2 \iff \Sigma - 2mn - (n-2)T \ge (S(T) \bmod 2)$。当 $(n-2)T \le \Sigma - 2mn - 1$ 时左边 $\ge 1$ 恒成立，当 $(n-2)T \ge \Sigma - 2mn + 1$ 时恒不成立，故 $R_d$ 是区间且右端只能取 $T_0 := \lfloor (\Sigma - 2mn)/(n-2) \rfloor$ 或 $T_0 - 1$（$T_0$ 本身是否属于 $R_d$ 取决于整除性与 $S(T_0)$ 的奇偶）。按整除性分情况：$\Sigma - 2mn$ 不被 $n - 2$ 整除时 $T^* = T_0 + 1$ 且 $T_0 \in R_d$，$\tau = T_0 = T^* - 1$；整除时 $T^* = T_0$，$\tau = T_0$ 或 $T_0 - 1$。两种情况都有 $\tau \in \{T^*-1, T^*\}$。∎

**引理 5（⌊S/2⌋ 瓶颈段单调 + 首点覆盖）**：记 $R_s = [\,mx, +\infty) \setminus R_d = [\,\rho, +\infty)$，则 $\rho \in \{mx,\ T^*,\ T^*+1\}$；在 $R_s$ 上 $C(T) = \lfloor S/2 \rfloor c_2 + (S \bmod 2) c_1$，且 $R_s$ 上的最小值只在 $\rho$ 或 $\rho + 1$ 处取得；$\rho + 1$ 不在候选集的唯一情形（$\rho = T^* + 1$）下 $C(\rho + 1) = C(T^*) + n c_2 > C(T^*)$。

**证明**：$R_s$ 上 $d < \lceil S/2 \rceil$ 推出 $S - d > \lfloor S/2 \rfloor$，故 $p = \lfloor S/2 \rfloor$。$T$ 每抬 2 格 $S$ 增 $2n$，$\lfloor S/2 \rfloor$ 增 $n$，同奇偶类内 $C$ 严格递增 $+n c_2$；$n$ 偶时 $S \equiv -\Sigma \pmod 2$ 奇偶恒定（单类），$n$ 奇时两类交替——两类各自的最小值都在该类于 $R_s$ 的首个点取得，即 $\rho$ 与 $\rho + 1$。$\rho = \max(mx, \tau + 1)$，由引理 4 的 $\tau \in \{T^*-1, T^*\}$ 得 $\rho \in \{mx, T^*, T^*+1\}$。唯一漏洞是 $\rho + 1 = T^* + 2$，仅在 $\tau = T^*$ 且 $T^* = T_0$（整除、$S(T_0)$ 为偶）时发生：此时 $2d(T^*) = S(T^*)$ 为偶，$S(\rho+1) = S(T^*+2)$ 与之同奇偶，逐项展开得 $C(\rho + 1) = \lfloor S(T^*)/2 \rfloor c_2 + n c_2 = C(T^*) + n c_2 > C(T^*)$。∎

**引理 6（切换点上界）**：$T^* \le 2mx - mn$。故全扫描 $[\,mx,\ 2mx - mn]$ 必然覆盖全局最优。

**证明**：$\Sigma \le (n-1)mx + mn$，于是
$$(n-2)(2mx - mn) - (\Sigma - 2mn) \ge (n-2)(2mx - mn) - (n-1)mx - mn + 2mn = (n-3)(mx - mn) \ge 0,$$
得 $\lceil (\Sigma - 2mn)/(n-2) \rceil \le 2mx - mn$；又 $mx \le 2mx - mn$。∎

**引理 7（$n = 2$ 的刚性）**：$n = 2$ 时最小开销为 $(mx - mn) \cdot c_1$。

**证明**：设对 $a = mn$ 零售 $s_a$ 次、对 $b = mx$ 零售 $s_b$ 次、批发 $k$ 次。终值相等 $\iff a + s_a + k = b + s_b + k \iff s_a - s_b = b - a$。开销 $= (s_a + s_b)c_1 + k c_2 \ge s_a c_1 \ge (b - a)c_1$，在 $s_b = k = 0$（即 $T = b$）时取等。∎

**引理 8（批发劣于两次零售）**：$c_2 \ge 2c_1$ 时存在不含批发的最优方案，且 $T = mx$。

**证明**：把任一方案中每次批发替换为对 $i, j$ 各一次零售，终值不变、开销变化 $2c_1 - c_2 \le 0$。故全零售最优，其开销 $(nT - \Sigma)c_1$ 关于 $T \ge mx$ 严格递增，$T = mx$。∎

**定理**：算法返回全局最小开销（取模前）。

**证明**：$n \le 2$、$c_2 \ge 2c_1$ 分别由引理 7、8 给出。下设 $n \ge 3$、$c_2 < 2c_1$：固定 $T$ 的最优开销由引理 3 给出；定义域 $[\,mx, +\infty) = R_d \cup R_s$，$R_d$ 上 $C$ 线性（引理 4），最小值在端点 $mx$ 或 $\tau \in \{T^*-1, T^*\}$ 取得；$R_s$ 上最小值在 $\rho \in \{mx, T^*, T^*+1\}$ 或 $\rho + 1$ 取得，而后者要么在候选集内、要么被 $T^*$ 支配（引理 5）。故全局最优在候选集 $\{mx, T^*-1, T^*, T^*+1\}$ 中取得。比较全部发生在取模之前，返回的非负值即真最小值 mod $10^9+7$。∎

> 💡 分段边界的整除/奇偶论证（引理 4、5 的分情况）最易疏漏，本篇用数十万组随机数据（Python + C++ 双实现）将候选点解与「全扫描 $[mx, 2mx-mn]$」逐一对拍验证一致，含 $n$ 奇偶、整除边界、$c_2 < c_1$ 等所有敏感组合。

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。一次线性扫描取 $n, mx, mn, \Sigma$；之后至多 4 个候选点、每点三条公式 $O(1)$ 直算（数值不超过 $\sim 3 \times 10^{17}$，64 位整数乘加即常数时间）。
- **空间复杂度**：$O(1)$ 额外空间，只维护标量。
- **与及格线的差距**：全扫描版 $O(n + mx - mn)$ 依赖**值域**（$mx - mn$ 可达 $10^6$），赛时同样能过；候选点版把分段单调性用干净，量级降到只依赖 $n$——属于「同样能过、更彻底」的打磨，也顺手回答了「到底要枚举到多高」。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int minCostToEqualizeArray(vector<int>& nums, int cost1, int cost2) {
        const long long MOD = 1'000'000'007;
        const long long n = nums.size();
        const long long mx = *max_element(nums.begin(), nums.end());
        const long long mn = *min_element(nums.begin(), nums.end());
        const long long total = accumulate(nums.begin(), nums.end(), 0LL);
        const long long c1 = cost1, c2 = cost2;

        if (n <= 2)                                    // n=2：批发不改变差距（引理 7）
            return (mx - mn) * c1 % MOD;
        if (c2 >= 2 * c1)                              // 批发不划算，全零售（引理 8）
            return (n * mx - total) * c1 % MOD;

        auto C = [&](long long T) {                    // 终值 T 的精确开销
            long long S = n * T - total;               // 总缺口
            long long d = T - mn;                      // 最大缺口
            long long p = min(S / 2, S - d);           // 批发次数：双瓶颈（引理 3）
            return p * c2 + (S - 2 * p) * c1;
        };

        long long num = total - 2 * mn, den = n - 2;
        long long Tstar = max(mx, (num + den - 1) / den);   // 切换点，上取整
        long long ans = LLONG_MAX;
        for (long long T : {mx, Tstar - 1, Tstar, Tstar + 1})
            if (T >= mx)                               // 越界候选跳过
                ans = min(ans, C(T));
        return ans % MOD;                              // 先比较，后取模！
    }
};
```

### Python

```python
class Solution:
    def minCostToEqualizeArray(self, nums: List[int], cost1: int, cost2: int) -> int:
        MOD = 10 ** 9 + 7
        n = len(nums)
        mx, mn, total = max(nums), min(nums), sum(nums)

        if n <= 2:                                     # n=2：批发不改变差距（引理 7）
            return (mx - mn) * cost1 % MOD
        if cost2 >= 2 * cost1:                         # 批发不划算，全零售（引理 8）
            return (n * mx - total) * cost1 % MOD

        def C(T):                                      # 终值 T 的精确开销
            S = n * T - total                          # 总缺口
            d = T - mn                                 # 最大缺口
            p = min(S // 2, S - d)                     # 批发次数：双瓶颈（引理 3）
            return p * cost2 + (S - 2 * p) * cost1

        Tstar = max(mx, (total - 2 * mn + n - 3) // (n - 2))   # 切换点，上取整
        cands = {mx} | {t for t in (Tstar - 1, Tstar, Tstar + 1) if t >= mx}
        return min(C(T) for T in cands) % MOD          # 先比较，后取模！
```

> 💡 想写**及格线版**只需把候选循环换成 `for T in range(mx, 2 * mx - mn + 1):`（C++ 同理），其余一行不动——两版对拍也是赛后排错的好习惯。

## 8. 边界情况与易错点

1. **$n = 1$ / 全等数组**：$S = 0$，公式自然给 0；$n = 1$ 被 `n <= 2` 分支覆盖为 $(mx - mn)c_1 = 0$，无需单独特判。
2. **$n = 2$ 忘特判**：$T^*$ 公式除零；且容易误以为「$c_2$ 便宜就猛配对」——批发根本不改变两元素差距（引理 7），示例 1 就是这个陷阱的具象化。
3. **先取模再比 min**：$C_1 = 10^9 + 6$ 与 $C_2 = 10^9 + 8$ 模后变成 $10^9 + 6$ 与 $1$，大小关系彻底失真。必须用完整数值比较（C++ `long long` 峰值约 $3 \times 10^{17}$ 安全；Python 大整数天然无虞），返回前取一次模。
4. **中途乘法溢出**：$S$ 可达 $2 \times 10^{11}$，与 $c_1 \le 10^6$ 相乘约 $2 \times 10^{17}$，超 32 位整型 4 个数量级——这题专为「忘了 `long long`」设计。
5. **$T^*$ 必须上取整**：下取整会把候选窗口整体左移一格。反例 `nums = [8,2,6,6,8]`，$c_1 = 4$，$c_2 = 1$：$\Sigma - 2mn = 26$ 不被 $n - 2 = 3$ 整除，真实最优在 $T = 10 = \lceil 26/3 \rceil + 1 = T^* + 1$（$C = 10$）；用下取整得到候选 $\{7, 8, 9\}$，算出 11，错。
6. **候选钳制**：$T^* - 1 < mx$ 时要跳过（$T^* = mx$ 时候选实际只有 $\{mx, mx+1\}$）；漏掉钳制会在 $T < mx$ 上算出无意义的负 $d$。
7. **$c_2 = 2c_1$ 边界**：两种策略等价（引理 8 的替换不改变开销），走哪个分支答案相同，不必纠结。
8. **奇数零头**：$S$ 为奇时必有 1 个 $c_1$ 零头；$n$ 为奇数时 $S$ 奇偶随 $T$ 交替，$T^* + 1$ 正是留给「换一次奇偶省下零头」的候选（$c_2 < c_1$ 时可能反超）——这也是候选集取 4 个点而非 3 个的原因。
