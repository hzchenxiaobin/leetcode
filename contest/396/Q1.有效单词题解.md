# LeetCode 有效单词 题解

## 1. 题目概述

- **标题 / 题号**：有效单词（#3136，easy）
- **链接**：https://leetcode.cn/problems/valid-word/
- **来源**：LeetCode 第 396 场周赛 Q1
- **难度**：简单
- **标签**：字符串

**题意**：给定字符串 `word`，判断它是否为**有效单词**。有效单词需**同时**满足四个条件：

1. 长度**至少为 3**；
2. 只由数字 `0-9` 和英文**大小写字母**组成；
3. 至少包含一个**元音字母**（`a/e/i/o/u` 及其大写形式）；
4. 至少包含一个**辅音字母**（元音之外的字母）。

满足返回 `true`，否则返回 `false`。

**约束**：

- $1 \le \mathrm{word.length} \le 20$
- `word` 由英文大小写字母、数字、`'@'`、`'#'`、`'$'` 组成

> 💡 签到题的关键信号：四个条件全是「全称 / 存在」型判断，且是 **AND 关系、一票否决**。读题时抓住两处坑即可秒杀——① 元音/辅音的主语都是**字母**，数字两者都不算；② `'@' '#' '$'` 一旦出现直接出局。$n \le 20$ 怎么写都能过，比拼的是**从题面到代码的最短路径**。

## 2. 示例

**示例 1**

```text
输入：word = "234Adas"
输出：true
解释：长度 7 ≥ 3；全部字符均为字母/数字；'A'、'a' 是元音；'d'、's' 是辅音。四条全过。
```

**示例 2**

```text
输入：word = "b3"
输出：false
解释：长度 2 < 3，且不含元音——两条都不满足。
```

**示例 3**

```text
输入：word = "a3$e"
输出：false
解释：包含 '$'（非法字符，一票否决），且不含辅音。
```

**补充示例**

```text
输入：word = "aei"
输出：false
解释：长度、字符集合法，元音也有，但全是元音、没有辅音。

输入：word = "123"
输出：false
解释：数字既不算元音也不算辅音，两个存在性条件都无法满足。
```

三个官方示例恰好对应三种典型「死法」：长度不足 / 非法字符 / 缺类别，赛场上建议顺手在脑内过一遍这三类再提交。

## 3. 解题思路

### 3.1 暴力思路

最直接的写法是**四个条件各扫一遍**：

```python
if len(word) < 3: return False                                    # 条件 ①
if not all(c.isalnum() for c in word): return False               # 条件 ②
if not any(c in "aeiouAEIOU" for c in word): return False         # 条件 ③
if not any(c.isalpha() and c not in "aeiouAEIOU"
           for c in word): return False                           # 条件 ④
return True
```

正确性没有问题，最多扫四遍、元音表查两遍，$n \le 20$ 下毫无压力。但四趟扫描做的事高度重复——每个字符的「身份判定」（是不是字母？是不是元音？）本质是**同一次分类**，完全可以折叠成**一趟**。赛场上这两种写法的提交速度差不了几秒，但单趟版本更能体现对条件的结构化理解。

### 3.2 核心观察：字符四分类，单趟双标记

![核心概念：四个条件折叠为一趟扫描的三个标记](images/valid_word_conditions_concept.svg)

把四个条件按「检查时机」重新归类，信息只有三类：

1. **长度**是 $O(1)$ 的前置检查——入口处比一次大小即可，不值得进循环；
2. **合法性**是全称判断——见到第一个非法字符（`'@' '#' '$'`）即可**短路**返回 `false`；
3. **元音/辅音存在性**是两个存在判断——两个布尔 `hasVowel` / `hasConsonant`，**见过即置位、永不复位**。

于是每个字符恰好落入**四个桶**之一：

| 字符类别 | 处理 |
|----------|------|
| 数字 `0-9` | 合法，但**既非元音也非辅音**，两旗不动 |
| 元音字母（含大写） | `hasVowel = true` |
| 其他字母 | `hasConsonant = true` |
| `'@' '#' '$'` | 非法，立即 `return false` |

扫描结束后 `return hasVowel && hasConsonant`，与长度检查一起，四条件一次性判定完毕。

### 3.3 算法流程

![算法流程：长度前置、逐字符分类、收尾查两旗](images/valid_word_flow.svg)

1. **入口**：`len(word) < 3` → `false`；
2. **循环**：对每个字符 `c`——
   - `c` 是数字 → 跳过（合法，不置旗）；
   - `c` 不是字母（只能是 `@#$`）→ 立即 `return false`；
   - `c` 属于 `aeiouAEIOU` → `hasVowel = true`；
   - 否则 → `hasConsonant = true`；
3. **收尾**：`return hasVowel && hasConsonant`。

### 3.4 示例演算

![示例演算：234Adas 与 a3$e 的单趟走查](images/valid_word_walkthrough.svg)

以 `word = "234Adas"` 为例逐字符走查：

| $c$ | 分类 | hasVowel | hasConsonant |
|-----|------|----------|--------------|
| 2 | 数字 | ✗ | ✗ |
| 3 | 数字 | ✗ | ✗ |
| 4 | 数字 | ✗ | ✗ |
| A | 元音 | **✓** | ✗ |
| d | 辅音 | ✓ | **✓** |
| a | 元音 | ✓ | ✓ |
| s | 辅音 | ✓ | ✓ |

两旗皆立，四条件全过 → `true`。✓

再看 `word = "a3$e"`：`'a'` 置起 `hasVowel`，`'3'` 跳过，`'$'` 触发非法字符短路 → `false`。值得注意的是，**即使把 `'$'` 换成合法字符**，剩下的也只有元音（`a`、`e`）和数字，`hasConsonant` 永远不置位，结果仍是 `false`——示例 3 是「双重死法」。

## 4. 算法细节

1. **检查顺序**：长度放最前，$O(1)$ 挡掉最短的一类输入；非法字符中途短路，省掉剩余扫描。逻辑上 AND 可交换，工程上讲究「**便宜的先判、能短路的先判**」。
2. **元音集合**：用 10 字符的字面量 `"aeiouAEIOU"` 一次 `in` / `strchr` 判定；也可统一转小写后只查 `"aeiou"`。追求极致可用位技巧 `0x208222 >> (c & 31) & 1` 一条移位判元音（详见文末每日题解）。
3. **C++ 细节**：`isalpha` / `isdigit` / `isalnum` 的入参必须能表示为 `unsigned char`（`char` 可能带符号，传负值是未定义行为），本题字符集保证 ASCII，但习惯性 cast 一层最稳。
4. **Python 细节**：`str.isalnum()` 会对 Unicode 字母/数字（如 `'é'`、`'②'`）也返回 `True`，本题靠输入约束兜底；无约束场景应显式写区间比较。
5. **正则一行流**（sanity check 用）：`^(?=.*[aeiouAEIOU])(?=.*[b-df-hj-np-tv-zB-DF-HJ-NP-TV-Z])[0-9a-zA-Z]{3,}$`——两个 lookahead 分别保证元音、辅音存在，字符类管长度与合法集。注意不能用 `\w`，它包含下划线。

## 5. 正确性证明

**引理 1**（分类完备且互斥）：`word` 中的每个字符，恰为「数字 / 元音字母 / 辅音字母 / 非法字符」四类之一。

**证明**：由约束，`word` 仅含字母、数字、`'@' '#' '$'`。数字与字母不相交；字母按是否属于 $\{a,e,i,o,u,A,E,I,O,U\}$ 划分为元音与辅音，划分完备且互斥；`'@' '#' '$'` 不属于前三类，归入非法。故四类构成对字符集的一个划分。∎

**引理 2**（标记与短路的正确性）：扫描能完整到达串尾，当且仅当 `word` 不含非法字符；且到达串尾时，`hasVowel` 为真当且仅当 `word` 含元音，`hasConsonant` 同理。

**证明**：由引理 1，每字符恰进入一个分支。非法字符所在分支直接 `return false`，故算法能扫到串尾 ⇔ 无人走非法分支 ⇔ 无非法字符。对标记：置位只发生在对应分支中，故标记为真的前提是该类字符存在（必要性）；反之若存在元音字符 $c$，扫描经过 $c$ 时必进元音分支（引理 1 保证不会再进别的分支），`hasVowel` 被置位，且此后无任何路径将其复位（充分性）。`hasConsonant` 对称成立。∎

**定理**：算法返回 `true`，当且仅当 `word` 是有效单词。

**证明**：

- （充分性）设 `word` 满足四条件。长度条件使入口检查通过；无非法字符使扫描完整到达串尾（引理 2）；存在元音与辅音使 `hasVowel`、`hasConsonant` 均为真（引理 2），收尾返回 `true`。
- （必要性）设算法返回 `true`。返回点在收尾，故入口长度检查已通过（条件 ①）；扫描完整结束，由引理 2 无非法字符（条件 ②）；且 `hasVowel ∧ hasConsonant`，由引理 2 存在元音与辅音（条件 ③ ④）。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$，其中 $n = |\mathrm{word}| \le 20$。长度检查 $O(1)$；单趟扫描中每字符做 $O(1)$ 分类（元音判定查 10 字符常量表）。
- **空间复杂度**：$O(1)$。全部状态就是两个布尔标记，元音表为常量。
- **短路收益**：含非法字符时提前出局，最坏（全合法）仍需扫到串尾才收尾判定，故最坏时间不变，只是常数更优。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    bool isValid(string word) {
        if (word.size() < 3) return false;
        bool hasVowel = false, hasCons = false;
        for (char ch : word) {
            unsigned char c = ch;
            if (!isalnum(c)) return false;
            if (isalpha(c)) {
                if (strchr("aeiouAEIOU", c)) hasVowel = true;
                else                        hasCons  = true;
            }
        }
        return hasVowel && hasCons;
    }
};
```

### Python

```python
class Solution:
    def isValid(self, word: str) -> bool:
        if len(word) < 3:
            return False
        has_vowel = has_cons = False
        for c in word:
            if not c.isalnum():
                return False
            if c.isalpha():
                if c in "aeiouAEIOU":
                    has_vowel = True
                else:
                    has_cons = True
        return has_vowel and has_cons
```

## 8. 边界情况与易错点

1. **忘记大写元音**：元音集必须含 `AEIOU`。自测 `"Ab9"` 应为 `true`（`A` 元音、`b` 辅音），只查小写会误判。
2. **把数字当辅音**：元音/辅音的定义主语都是**字母**，数字合法存在但不参与两分类。误当辅音则 `"123"` 会被误判为有效——这是本题最阴的坑。
3. **把 `'y'` 当元音**：本题 `y` 是辅音。`"a9y"` 应为 `true`（`a` 元音、`y` 辅音），若把 `y` 当元音会误判为 `false`（元音齐全、无辅音）。
4. **非法字符短路 vs 扫完再判**：两者正确性等价，短路只是更快；别在短路分支里顺手 `continue`——那是 `return false`，写反逻辑会挂全对拍。
5. **长度检查放最前**：`n < 3` 直接 `false`。约束保证 $n \ge 1$，无空串，但仍建议先判长度再进循环，省一次无谓扫描。
6. **C 库函数的未定义行为**：`isalnum` 等直接传可能为负的 `char` 是 UB，cast 成 `unsigned char` 是肌肉记忆。
7. **正则误用 `\w`**：`\w` 含下划线，字符集白名单应显式写 `[0-9a-zA-Z]`（本题输入不含下划线，属「侥幸正确」的隐患写法）。
8. **三类必挂用例**：全元音 `"aei"`、全辅音 `"bcd"`、全数字 `"123"` 都是 `false`——两个存在性条件缺一不可。
