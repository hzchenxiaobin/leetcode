# LeetCode 找出第 K 个字符 I 题解

## 1. 题目概述

- **标题 / 题号**：找出第 K 个字符 I（#3304，easy）
- **链接**：https://leetcode.cn/problems/find-the-k-th-character-in-string-game-i/
- **来源**：LeetCode 第 417 场周赛 Q1
- **难度**：简单
- **标签**：位运算、递归、数学、模拟

**题意**：初始 `word = "a"`。Bob 要求 Alice 执行以下操作**无限次**：将 `word` 中每个字符替换为英文字母表中的**下一个**字符（`z` 的下一个绕回 `a`），把生成的新串**追加**到 `word` 末尾。例如 `"zb"` 生成 `"zbac"`。当 `word` 中至少存在 $k$ 个字符时，返回第 $k$ 个字符。

**约束**：

- $1 \le k \le 500$

> 💡 **赛事视角**：签到题。$k \le 500$ 意味着串长最多到 $2^9 = 512$，照题意模拟 9 轮就能过，是比赛现场最稳的拿分路径。但本场 **Q4（3307）正是同一游戏的升级版**——$k$ 高达 $10^{14}$、操作分「原样复制 / 加一」两种——Q1 的「倍增 + popcount」观察正是 Q4 的钥匙，赛后值得把一行闭式沉淀下来。

## 2. 示例

**示例 1**

```text
输入：k = 5
输出："b"
解释：word 依次变为 "a" → "ab" → "abbc" → "abbcbccd"，
     第 5 个字符是 'b'。
```

**示例 2**

```text
输入：k = 10
输出："c"
解释：还需再执行一次操作得到长度 16 的串，其第 10 个字符是 'c'。
```

**补充示例（边界）**

```text
输入：k = 1
输出："a"
解释：无需任何操作，第 1 个字符就是初始的 'a'。
```

## 3. 解题思路

### 3.1 暴力思路：照题意模拟 9 轮

每次操作把与当前串**等长**的新串追加到末尾，长度**精确翻倍**：$1 \to 2 \to 4 \to \cdots$，$t$ 轮后长度为 $2^t$。$k \le 500$ 只需模拟 $\lceil \log_2 500 \rceil = 9$ 轮（$2^9 = 512$），最终串长不超过 512，$O(k)$ 时间与空间轻松通过，现场写这个最不容易出错：

```python
class Solution:
    def kthCharacter(self, k: int) -> str:
        w = 'a'
        while len(w) < k:
            w += ''.join(chr((ord(c) - 97 + 1) % 26 + 97) for c in w)
        return w[k - 1]
```

但模拟把「不需要的信息」全造了出来：我们只关心**一个**位置，却构造了整串。把 $k$ 放大到 $10^{14}$（正是本场 Q4 的数据范围），构造法当场爆内存——需要**只定位、不构造**。

### 3.2 核心观察：倍增结构 + popcount 闭式

![倍增结构：后半段 = 前半段整体 +1 后追加](images/c417_q1_doubling_concept.svg)

记 $S_t$ 为 $t$ 次操作后的串，则结构完全**自相似**：

$$S_0 = \text{"a"}, \qquad |S_t| = 2^t, \qquad S_{t+1} = S_t \cdot \mathrm{inc}(S_t)$$

其中 $\mathrm{inc}$ 表示「每个字符 +1」。也就是说 $S_{t+1}$ 的**后半段**就是**前半段**逐字符 +1 的镜像（见上图逐层展开）。

**关键引理**：按 0-indexed 记位置 $i$，则

$$S_t[i] = \text{'a'} + \operatorname{popcount}(i)$$

**直观读法**：把 $i$ 的二进制从高位到低位读一遍——每遇到一个 `1`，就表示「在对应那一层，这个位置落在了后半段」，而后半段的字符 = 前半段对应位置 +1，所以**每个为 1 的二进制位恰好贡献一次 +1**。于是答案一步写出（$k$ 是 1-indexed，先减一）：

$$\text{ans} = \text{chr}\big(\text{'a'} + \operatorname{popcount}(k-1)\big)$$

### 3.3 算法流程：逆向下落

![算法流程：逆向下落 = popcount 的手工展开](images/c417_q1_algorithm_flow.svg)

不想现场背闭式也没关系，**逆向下落**可以当场推出来：从「能覆盖 $k$ 的最小串长」那层开始，每层问一句「当前位置在前半还是后半」——在后半就记一次 +1 并把位置减去半长；在前半就原样下落。落到基准位置 1 时，累计的 +1 次数就是位移。把「第 $t$ 层落后半段」翻译成二进制语言，正是「$k-1$ 的第 $t$ 位为 1」——这个循环就是 $\operatorname{popcount}$ 的手工展开，也是没有内置位计数函数时的通用写法。

### 3.4 示例演算：k = 10

![示例演算：k=10 的逐层下落与二进制对照](images/c417_q1_example_walkthrough.svg)

取 $t = 4$（$2^4 = 16 \ge 10$），从串长 16 的层开始下落：

| 串长 | 位置 $k$ | 判定 | 动作 |
|------|---------|------|------|
| 16 | 10 | $10 > 8$，落**后半段** | $k \to 2$，记 **+1** |
| 8 | 2 | $2 \le 4$，前半段 | 原样下落 |
| 4 | 2 | $2 \le 2$，前半段（压线） | 原样下落 |
| 2 | 2 | $2 > 1$，落**后半段** | $k \to 1$，记 **+1** |
| 1 | 1 | 基准 | $\text{'a'}$ |

累计位移 $+2$，答案 $\text{'a'} + 2 = \text{'c'}$ ✓。对照闭式：$k - 1 = 9 = 1001_2$，两个 1 恰好对应两次「落后半段」，$\operatorname{popcount}(9) = 2 \Rightarrow \text{'c'}$，两条路线完全吻合。再验示例 1：$k = 5$，$k - 1 = 4 = 100_2$，一个 1 $\Rightarrow \text{'b'}$ ✓。

## 4. 算法细节

1. **轮数**：长度每次精确翻倍，覆盖 $k$ 只需 $t = \lceil \log_2 k \rceil \le 9$ 轮；模拟法因此只需 $O(k)$。
2. **下标转换**：引理按 0-indexed 对齐（第 0 位是 'a'），题目问 1-indexed 的第 $k$ 位，必须用 $j = k - 1$。
3. **位计数实现**：C++ 用 `__builtin_popcount(j)`，Python 用 `bin(j).count('1')`（3.10+ 可写 `j.bit_count()`）；没有内置时用 `j & 1` 取末位、`j >>= 1` 砍末位的循环手工数位，即逆向下落的代码形态。
4. **取模判断**：$k \le 500 \Rightarrow k - 1 \le 499 < 2^9 \Rightarrow \operatorname{popcount} \le 8 < 26$，位移绝不会绕过 'z'，**无需 `% 26`**。这一步「先看数据范围再定要不要取模」不能省——Q4 的位移可达 100，必须取模。

## 5. 正确性证明

**引理 1**：$t$ 次操作后 $|S_t| = 2^t$，且 $S_{t+1} = S_t \cdot \mathrm{inc}(S_t)$，即 $S_{t+1}$ 的第 $2^t + r$ 位（$0 \le r < 2^t$）等于 $\mathrm{inc}(S_t[r])$。

**证明**：操作生成的新串与当前串等长（逐字符 +1）并追加到末尾，长度 $2^t \to 2^{t+1}$；新串的第 $r$ 位由 $S_t[r]$ 加一而来，落在 $S_{t+1}$ 的第 $2^t + r$ 位。∎

**引理 2**：对一切 $t \ge 0$ 与 $0 \le i < 2^t$，有 $S_t[i] = \text{'a'} + \operatorname{popcount}(i)$。

**证明**（对 $t$ 归纳）：

- **基础**：$S_0[0] = \text{'a'} = \text{'a'} + \operatorname{popcount}(0)$ ✓
- **步骤**：设对 $S_t$ 成立，看 $S_{t+1}$（长度 $2^{t+1}$）：
  - 若 $i < 2^t$（前半段）：$S_{t+1}[i] = S_t[i] = \text{'a'} + \operatorname{popcount}(i)$ ✓
  - 若 $i = 2^t + r \ge 2^t$（后半段）：由引理 1，$S_{t+1}[i] = \mathrm{inc}(S_t[r]) = \text{'a'} + \operatorname{popcount}(r) + 1$；又 $r < 2^t$ 保证 $i$ 的第 $t$ 个二进制位是 1、其余低位恰为 $r$，故 $\operatorname{popcount}(i) = 1 + \operatorname{popcount}(r)$，两式吻合 ✓ ∎

**定理**：返回 $\text{chr}(\text{'a'} + \operatorname{popcount}(k-1))$ 是 `word` 的第 $k$ 个字符。

**证明**：取 $t$ 使 $2^t \ge k$，第 $k$ 个字符即 $S_t[k-1]$（1-indexed 转 0-indexed）。由引理 2，$S_t[k-1] = \text{'a'} + \operatorname{popcount}(k-1)$。又 $k - 1 \le 499 < 2^9 \Rightarrow \operatorname{popcount}(k-1) \le 8 < 26$，加法不会越过 'z'，无需环绕处理。∎

## 6. 复杂度分析

- **时间复杂度**：$O(\log k)$——只需数 $k-1$ 的二进制位数，$k \le 500$ 时至多 9 次循环；对照的模拟法为 $O(k)$（构造长度 $\le 512$ 的串），同样轻松通过。
- **空间复杂度**：$O(1)$——闭式只占常数空间；模拟法需 $O(k)$ 存整串。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    // 写法一：popcount 闭式，O(log k) / O(1)
    char kthCharacter(int k) {
        return 'a' + __builtin_popcount(k - 1);
    }
};
```

```cpp
class Solution {
  public:
    // 写法二：逆向下落（popcount 的手工展开，无内置函数语言通吃）
    char kthCharacter(int k) {
        int shift = 0;
        for (int j = k - 1; j > 0; j >>= 1)  // 每圈剥掉一个二进制位
            shift += j & 1;                   // 末位是 1 = 该层落后半段，记 +1
        return 'a' + shift;
    }
};
```

### Python

```python
class Solution:
    def kthCharacter(self, k: int) -> str:
        # 闭式：第 k 个字符 = 'a' + popcount(k-1)
        return chr(ord('a') + bin(k - 1).count('1'))
```

```python
class Solution:
    def kthCharacter(self, k: int) -> str:
        # 逆向下落：现场可推导的版本
        shift, j = 0, k - 1
        while j:
            shift += j & 1    # 末位是 1 ⇒ 该层落入后半段，+1
            j >>= 1           # 砍掉末位，下落一层
        return chr(ord('a') + shift)
```

## 8. 边界情况与易错点

1. **1-indexed 陷阱**：闭式依赖 $k - 1$ 而非 $k$。忘减一会把「恰好是 2 的幂」的位置算错：$k = 4$ 的正确答案是 'c'（`"abbc"` 第 4 位，$\operatorname{popcount}(3) = 2$），而 $\operatorname{popcount}(4) = 1$ 会错误地给出 'b'。
2. **k = 1**：$j = 0$，$\operatorname{popcount}(0) = 0$，直接返回 'a'；下落循环从 `j > 0` 起判，天然覆盖。
3. **环绕 z → a**：本题位移 $\le 8$，绝无触发；不要顺手写 `% 26` 就当万能——Q4 的位移可达 100，必须取模。「先问数据范围、再定要不要取模」是位运算题基本功。
4. **模拟循环条件**：`while len(w) < k` 而非 `<=`——长度恰好等于 $k$ 时已可返回（多算一轮不影响正确性，但没必要）。
5. **下落起点**：逆向下落要取满足 $2^t \ge k$ 的层；从更大的层开始也正确（多出的高位 0 不贡献），从更小的层开始则位置越界。
