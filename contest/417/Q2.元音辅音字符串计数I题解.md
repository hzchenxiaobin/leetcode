# LeetCode 元音辅音字符串计数 I 题解

## 1. 题目概述

- **标题 / 题号**：元音辅音字符串计数 I（#3305，medium）
- **链接**：https://leetcode.cn/problems/count-of-substrings-containing-every-vowel-and-k-consonants-i/
- **来源**：LeetCode 第 417 场周赛 Q2
- **难度**：中等
- **标签**：哈希表、字符串、滑动窗口

**题意**：给定小写字符串 `word` 和非负整数 $k$，统计同时满足以下两个条件的**子串**（连续）个数：

1. 五种元音 `a` / `e` / `i` / `o` / `u` 各**至少**出现一次；
2. **恰好**包含 $k$ 个辅音字母。

**约束**：

- $5 \le |\text{word}| \le 250$
- `word` 仅由小写英文字母组成
- $0 \le k \le |\text{word}| - 5$

> 💡 **赛事视角**：本场 Q2 与 **Q3（3306）是同一道题**，仅把 $n$ 从 $250$ 放大到 $2 \times 10^5$——典型的「一鱼两吃」布局。Q2 的数据范围故意放 $O(n^2)$ 暴力通过，但比赛现场值得直接写 $O(n)$ 的「**至少**差分滑窗」：写完 Q2 改个返回类型就能交 Q3，两题共用一份代码。

## 2. 示例

```text
输出：0
解释：整个字符串都不含 'u'，不存在五种元音齐全的子串。
```

**示例 2**

```text

输出：1
解释：唯一满足条件的是 word[0..4] = "aeiou"（元音齐 + 0 个辅音）。
```

**示例 3**

```text
输出：3
解释：word[0..5] = "ieaouq"、word[6..11] = "qieaou"、word[7..12] = "ieaouq"。
```

```text
      [1..5] = "eiouq" 缺 'a'，[5..5] = "q" 元音不齐。
```

## 3. 解题思路

### 3.1 暴力思路：枚举所有子串

固定左端点 $l$ 向右延伸 $r$，增量维护「已出现的元音集合」与「辅音个数」，每一步 $O(1)$ 判断，总计 $O(n^2)$：

```python
class Solution:
    def countOfSubstrings(self, word: str, k: int) -> int:
        ans = 0
        for l in range(len(word)):
            seen, cons = set(), 0
            for r in range(l, len(word)):
                if word[r] in "aeiou":
                    seen.add(word[r])
                else:
                    cons += 1
                if len(seen) == 5 and cons == k:
                    ans += 1
        return ans
```

$n \le 250$ 时子串至多 $\tfrac{250 \times 251}{2} = 31375$ 个，轻松通过 Q2。但 Q3 把 $n$ 放大到 $2 \times 10^5$，$O(n^2) \approx 2 \times 10^{10}$ 当场超时——**必须把「判断每个子串」优化成「按右端点批量计数」**。

### 3.2 核心观察：「恰好」不能滑窗，容斥成「至少」

![核心观察：恰好 k = 至少 k − 至少 k+1，且至少方向可滑窗](images/c417_q2_at_least_k_concept.svg)

滑动窗口计数的命门在于：**以 $r$ 结尾的合法左端点必须是一段连续区间**（通常是前缀），才能用「贡献个数」代替逐个枚举。本题直接对「恰好 $k$」滑窗会翻车——两个条件的单调方向**相反**：

- 左端点 $l$ 右移（窗口变小）：辅音变少 ✓（更易满足「恰好」），但可能丢掉唯一的某个元音 ✗（破坏「元音齐」）。

看片段 `"aeciou"`（$k = 1$，固定 $r$ 指向 `u`）：$[2,5] = $ `"ciou"` 合法，但左端点再右移到 $[3,5] = $ `"iou"` 既缺 `a` 又缺 `e`——**合法左端点集既不是前缀也不是后缀**，滑窗无从下手。

**破局**：把「恰好」拆成两个「至少」的差。定义

$$g(m) = \big|\{\,\text{子串} : 5 \text{ 种元音齐} \wedge \text{辅音数} \ge m\,\}\big|$$

则按辅音个数分类做容斥（$N_c$ 为「元音齐且辅音恰 $c$ 个」的子串数，$g(k) = \sum_{c \ge k} N_c$）：

$$\boxed{\;\text{answer} = g(k) - g(k+1) = N_k\;}$$

关键是「至少」版本里**两个条件同向**：窗口越大，元音计数只增不减、辅音个数也只增不减，**都更容易满足**。于是固定 $r$ 时合法左端点构成前缀 $\{0, 1, \dots, l_{\max}(r)\}$，贡献就是 $l_{\max}(r) + 1$ 个——滑窗复活。

### 3.3 算法流程：对每个 r 贪心收缩出 l_max

![算法流程：对每个右端点 r 贪心收缩出 l_max](images/c417_q2_sliding_window_flow.svg)

计算 $g(m)$ 的滑窗（$l$ 只前进不回退，因 $l_{\max}(r)$ 随 $r$ 单调不减）：

1. 右端 $r$ 右移一格，纳入 `word[r]`（元音 → 对应计数 +1，辅音 → `cons` +1）；
2. **当**窗口 $[l, r]$ 满足「5 元音齐 且 `cons` ≥ $m$」时：移出 `word[l]`，$l{+}{+}$，回到 2（贪心把 $l$ 推到最大的合法位置）；
3. 收缩结束后累加 $\text{ans} \mathrel{+}= l$——此时 $l - 1 = l_{\max}(r)$，恰好有 $l$ 个合法左端点；
4. 主答案 $= g(k) - g(k+1)$，整个过程只调两次 `atLeast`。

注意第 3 步累加的是**左端点个数** $l$，而不是子串长度——这是「计数型滑窗」的标准贡献写法：以 $r$ 结尾、左端点任取 $\{0, \dots, l_{\max}(r)\}$ 的 $l_{\max}(r)+1$ 个子串**全部**合法。

### 3.4 示例演算：word = "ieaouqqieaouqq"，k = 1

![示例演算：g(1) 与 g(2) 的逐 r 走查与差分](images/c417_q2_example_walkthrough.svg)

辅音（`q`）出现在下标 $5, 6, 12, 13$。对每个右端点 $r$ 走查两个滑窗的贡献与差分：

| 右端 $r$ | 5 | 6 | 7 | 8 | 9 | 10 | 11 | 12 | 13 |
|---------|---|---|---|---|---|----|----|----|----|
| $g(1)$ 贡献 | 1 | 1 | 2 | 3 | 4 | 5 | 7 | 8 | 8 |
| $g(2)$ 贡献 | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
| **差（恰好 1）** | **1** | 0 | 0 | 0 | 0 | 0 | **1** | **1** | 0 |

（$r < 5$ 时窗口装不下 5 种元音，两行贡献均为 0，表中略去。）

$g(1) = 39$，$g(2) = 36$，答案 $= 39 - 36 = 3$ ✓。差分非零恰在 $r = 5, 11, 12$，正对应三个答案子串 `[0,5]`、`[6,11]`、`[7,12]`——**月牙差集被逐右端点精确切出**。

## 4. 算法细节

1. **为何选「至少」而非「至多」**：「至多 $k$」差分同样可行，但两个条件反向——辅音约束给出合法左端点的**下界**（指针驱动），元音约束给出**上界**（五个元音在 $\le r$ 处最后出现位置的最小值，即 `lastAll` 阈值），贡献为中段区间长度，需要「指针 + 阈值」双机制（站内 3306 题解走的正是这条路线）；「至少 $m$」两条件同向，合法左端点是纯前缀，单指针贪心收缩即可，代码更短、更不易错。
2. **贡献写法**：每轮收缩结束后 `ans += left`。`left` 的语义是「第一个不合法的左端点」，因此合法左端点恰有 `left` 个（$\{0, \dots, \text{left}-1\}$）。累加必须放在 `while` **外**——它统计的是以当前 $r$ 结尾的子串总数，不是收缩次数。
3. **双指针不回退**：$l_{\max}(r)$ 随 $r$ 单调不减，故 $l$ 全程只前进，每个字符至多进出窗口各一次，$g(m)$ 为线性。
4. **元音计数**：Python 用字典（计数归零即 `del`，保证 `len(cnt) == 5` 判断准确）；C++ 用长度 5 的数组、以 `cnt[i] > 0` 判断齐缺，天然规避「零计数残留」。辅音个数单独一个计数器。
5. **两次调用**：`atLeast(k) - atLeast(k + 1)`，代码零特判；也可升级为一次遍历同时维护两个左指针（三指针），但两次调用更短更不易错。
6. **返回类型**：Q2 上界 $31375$ 用 `int` 足够，但内部统一用 `long long`——直接搬去 Q3（$n \le 2 \times 10^5$，子串数可达 $2 \times 10^{10}$）只改函数返回类型即可。

## 5. 正确性证明

记 $P_m(l, r)$ 为「$[l, r]$ 内 5 种元音各至少一个且辅音数 $\ge m$」。

**引理 1（扩张单调性）**：若 $P_m(l, r)$ 成立，则对任意 $l' \le l$、$r' \ge r$，$P_m(l', r')$ 也成立。

**证明**：$[l', r'] \supseteq [l, r]$，五种元音的计数与辅音计数均只增不减，两个条件保持成立。∎

**引理 2（前缀性）**：固定 $r$，满足 $P_m(l, r)$ 的左端点集合要么为空，要么是前缀 $\{0, 1, \dots, L_r\}$。

**证明**：由引理 1（取 $r' = r$），若 $l$ 合法则一切更小的 $l' $ 合法，故集合形如 $\{0, \dots, L_r\}$。∎

**引理 3（$L_r$ 单调不减）**：$L_{r+1} \ge L_r$（两集合均非空时）。

**证明**：$[L_r, r]$ 合法，由引理 1（右扩张）$[L_r, r+1]$ 合法，故 $L_{r+1} \ge L_r$。这正是双指针 $l$ 只前进不回退的依据。∎

**引理 4（差分容斥）**：$\text{answer} = g(k) - g(k+1)$。

**证明**：设 $N_c$ 为「元音齐且辅音恰 $c$ 个」的子串数，则 $g(m) = \sum_{c \ge m} N_c$，于是 $g(k) - g(k+1) = \sum_{c \ge k} N_c - \sum_{c \ge k+1} N_c = N_k$，即辅音恰好 $k$ 个且元音齐的子串数。∎

**定理**：滑窗 `atLeast(m)` 返回值 $= g(m)$，从而算法返回正确答案。

**证明**：对 $r$ 归纳证明不变式：**第 $r$ 轮的 `while` 结束后，`left` 恰等于「以 $r$ 结尾的合法子串个数」**（即 $L_r + 1$；无合法左端点时为 $0$，此时 `left` 也恰为 $0$，贡献仍正确）。

- **基础**：`left = 0` 起步，$r = 0$ 时窗口单字符，元音必不齐，`while` 不执行，`ans += 0` ✓。
- **步骤**：设第 $r-1$ 轮结束后不变式成立。
  - 若本轮 `while` 执行了 $t \ge 1$ 次：每次执行的前提是当前 $[\text{left}, r]$ 合法；结束后 $[\text{left}, r]$ 不合法且 $[\text{left}-1, r]$ 合法（最后一次执行前的状态）。由引理 2，合法集是前缀且其最大元 $L_r = \text{left} - 1$，贡献 `left` $= L_r + 1$ ✓。
  - 若本轮一次未执行：$[\text{left}, r]$ 不合法。若 `left` $= 0$，即 $[0, r]$ 不合法，由引理 2 合法集为空，贡献 $0$ ✓。若 `left` $> 0$，归纳假设给出 $L_{r-1} = \text{left} - 1$，即 $[\text{left}-1, r-1]$ 合法，由引理 1 右扩张得 $[\text{left}-1, r]$ 合法；又 $[\text{left}, r]$ 不合法，由引理 2 得 $L_r = \text{left} - 1$，贡献 `left` $= L_r + 1$ ✓。
  
  （`while` 条件在窗口收空时必不成立——空窗 5 种元音计数全零——故 `left` 不会越过 $r + 1$，移出操作始终安全。）

对 $r$ 求和得 `atLeast(m)` $= \sum_r (L_r + 1) = g(m)$；再由引理 4，算法返回 $N_k$，即所求答案。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。`atLeast` 中 $r$ 主循环 $n$ 步，`while` 的收缩总量不超过 $n$（$l$ 只前进），每个字符至多进出窗口各一次；共调用两次（$m = k$ 与 $m = k+1$），总计仍是线性。对照暴力 $O(n^2)$：$n = 250$ 两者都过，$n = 2 \times 10^5$（Q3）只有线性法能过。
- **空间复杂度**：$O(1)$。5 个元音计数 + 1 个辅音计数 + 若干指针，与 $n$ 无关（Python 字典至多 5 个键）。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int countOfSubstrings(string word, int k) {
        // g(m)：5 元音齐 且 辅音 >= m 的子串数；答案 = g(k) - g(k+1)
        auto atLeast = [&](int m) -> long long {
            auto vid = [](char c) -> int {
                switch (c) {
                    case 'a': return 0;
                    case 'e': return 1;
                    case 'i': return 2;
                    case 'o': return 3;
                    case 'u': return 4;
                    default:  return -1;   // 辅音
                }
            };
            long long ans = 0;
            int left = 0, cons = 0;
            int cnt[5] = {0};             // a e i o u 的出现次数
            for (char c : word) {
                int id = vid(c);
                if (id >= 0) cnt[id]++;
                else cons++;
                while (cnt[0] && cnt[1] && cnt[2] && cnt[3] && cnt[4] && cons >= m) {
                    int out = vid(word[left]);
                    if (out >= 0) cnt[out]--;
                    else cons--;
                    left++;
                }
                ans += left;              // left-1 = l_max，恰有 left 个合法左端点
            }
            return ans;
        };
        return (int)(atLeast(k) - atLeast(k + 1));
    }
};
```

```cpp
class Solution {
  public:
    // 对照：O(n^2) 枚举 + 位掩码判元音齐，Q2 可过、Q3 超时
    int countOfSubstrings(string word, int k) {
        int n = word.size(), ans = 0;
        auto isVowel = [](char c) {
            return c == 'a' || c == 'e' || c == 'i' || c == 'o' || c == 'u';
        };
        auto vid = [&](char c) {
            return (int)string("aeiou").find(c);   // 0..4
        };
        for (int l = 0; l < n; l++) {
            int seen = 0, cons = 0;                // seen: 元音位掩码
            for (int r = l; r < n; r++) {
                if (isVowel(word[r])) seen |= 1 << vid(word[r]);
                else cons++;
                if (seen == 31 && cons == k) ans++;   // 31 = 0b11111
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def countOfSubstrings(self, word: str, k: int) -> int:
        def at_least(m: int) -> int:
            # 「5 元音齐 且 辅音 >= m」的子串数
            ans = left = cons = 0
            cnt = {}
            for c in word:
                if c in "aeiou":
                    cnt[c] = cnt.get(c, 0) + 1
                else:
                    cons += 1
                while len(cnt) == 5 and cons >= m:
                    out = word[left]
                    if out in "aeiou":
                        cnt[out] -= 1
                        if cnt[out] == 0:
                            del cnt[out]   # 归零即删，len(cnt)==5 才准
                    else:
                        cons -= 1
                    left += 1
                ans += left                # left-1 = l_max，恰有 left 个合法左端点
            return ans

        return at_least(k) - at_least(k + 1)
```

## 8. 边界情况与易错点

1. **「恰好」直接滑窗（最常见翻车点）**：两条件单调方向相反，合法左端点不连续，必须先容斥成「至少」或「至多」之差。且单指针前缀模板只适用于「至少」版；「至多」版需「指针 + `lastAll` 阈值」双机制——别把「乘积小于 K」那套模板原样搬过来。
2. **$k = 0$**：$g(0)$ 的辅音条件恒真（$\text{cons} \ge 0$），退化成「元音齐的子串数」，代码统一处理、无需特判。
3. **贡献是 `ans += left` 不是 `ans += r - left + 1`**：统计的是合法**左端点个数**；且累加必须放在 `while` 外，每轮 $r$ 只加一次。
4. **Python 计数归零要 `del`**：否则 `len(cnt) == 5` 会把已经丢光的元音误判为仍在；C++ 数组版以 `cnt[i] > 0` 参与判断，天然规避。
5. **`while` 不会越界**：窗口收空时元音计数全零、条件必假，`left` 最多推进到 $r + 1$，移出操作安全；不需要额外写 `left <= r` 保护。
6. **溢出**：Q2 的 `int` 足够（上界 31375）；搬去 Q3（$n \le 2 \times 10^5$）时子串数可达 $2 \times 10^{10}$，内部必须 `long long`（本解已内置）。
7. **答案为 0 的情形**：缺某个元音（示例 1）、或 $k$ 大于全串辅音总数时，两个 $g$ 相减自然得 0，同样无需特判。
