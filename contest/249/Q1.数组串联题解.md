# LeetCode 数组串联 题解

## 1. 题目概述

- **标题 / 题号**：数组串联（#1929，easy）
- **链接**：https://leetcode.cn/problems/concatenation-of-array/
- **来源**：LeetCode 第 249 场周赛 Q1
- **难度**：简单
- **标签**：数组、模拟

**题意**：给定长度为 $n$ 的整数数组 `nums`，构造长度为 $2n$ 的答案数组 `ans`（下标从 $0$ 开始），对所有 $0 \le i < n$ 满足：

$$\text{ans}[i] = \text{nums}[i], \qquad \text{ans}[i + n] = \text{nums}[i]$$

即 `ans` 恰由两个 `nums` 首尾**串联**而成。返回 `ans`。

**约束**：

- $n = \text{nums.length}$
- $1 \le n \le 1000$
- $1 \le \text{nums}[i] \le 1000$

> 💡 本题在本仓库另有[每日题解 1929](../../solution/1901-2000/1929_数组串联.md)：侧重「索引映射 $\text{ans}[j] = \text{nums}[j \bmod n]$ → 环形数组」的视角推广与面试问答。本篇按周赛复盘视角，聚焦**签到题从题面到 AC 的最短路径**——两条规则共享同一个循环变量、一趟循环每轮两个赋值，并补齐引理-定理化的正确性证明与赛场易错清单，两篇互为印证。

## 2. 示例

**示例 1**

```text
输入：nums = [1,2,1]
输出：[1,2,1,1,2,1]
解释：ans = [nums[0],nums[1],nums[2],nums[0],nums[1],nums[2]]
     即两个 [1,2,1] 首尾相接。
```

**示例 2**

```text
输入：nums = [1,3,2,1]
输出：[1,3,2,1,1,3,2,1]
解释：n = 4，前 4 格照抄 nums，后 4 格再抄一遍 nums。
```

**示例 3**（边界 $n = 1$）

```text
输入：nums = [7]
输出：[7,7]
解释：唯一一轮 i = 0 同时填 ans[0] 与 ans[1]，无需特判。
```

## 3. 解题思路

### 3.1 暴力思路

最朴素的做法：新建长度 $2n$ 的数组，**两趟**拷贝——第一趟把 `nums` 抄进 `ans[0..n-1]`，第二趟再抄进 `ans[n..2n-1]`。时间 $O(n)$、额外空间 $O(1)$（输出不计），复杂度上已经最优。签到题的分差不在复杂度，而在**从题面到代码的最短路径**与**一遍写对**：两条规则 $ans[i]=nums[i]$ 与 $ans[i+n]=nums[i]$ 的**右端完全相同**，左端下标 $i$ 与 $i+n$ 又由**同一个 $i$** 决定——两趟完全可以并成一趟。

### 3.2 核心观察：两条规则共享同一个循环变量

![核心观察：同一个 i 驱动两个落点](images/wc249_q1_two_writes_concept.svg)

**观察一（一轮填两格）**。对每个 $0 \le i \le n-1$，用同一个 $i$ 同时执行两个赋值：$ans[i] \leftarrow nums[i]$、$ans[i+n] \leftarrow nums[i]$。单趟循环、每轮两个赋值，前后两半**同时**填满。这是本题从题面到代码的最短路径——循环体与题目给的两条规则**逐字对应**，写完即可提交。

**观察二（两条规则可合并为一条索引映射）**。令 $j$ 遍历 $0 \sim 2n-1$，两条规则统一为 $ans[j] = nums[j \bmod n]$（$j < n$ 时 $j \bmod n = j$；$j \ge n$ 时 $j \bmod n = j - n$）。这是「环形数组走两圈」的通用视角，展开见[每日题解](../../solution/1901-2000/1929_数组串联.md)。

**观察三（两半恒等，可自检）**。由构造，$ans[i] = ans[i+n]$ 对一切 $i$ 成立——后半是前半的**逐元素拷贝**。这是与实现无关的必然性质，可当**自检断言**：交前扫一眼（或调试期 `assert`）即可排除「后半填错来源」类笔误。

> 💡 **一句话总结**：一趟循环，每个 $i$ 同时写 $ans[i]$ 与 $ans[i+n]$，值都取 $nums[i]$；两半必然相同，可用 $ans[i] = ans[i+n]$ 自检。

### 3.3 算法流程

![算法流程图](images/wc249_q1_algorithm_flow.svg)

1. 读入 $n$，新建长度 $2n$ 的数组 $ans$（预先开好，不逐个 `push_back`）。
2. 循环变量 $i$ 从 $0$ 到 $n-1$，每轮执行两个赋值：$ans[i] = nums[i]$、$ans[i+n] = nums[i]$。
3. $n$ 轮结束后 $2n$ 个格子全部填满，返回 $ans$。

### 3.4 示例演算

![示例演算走查](images/wc249_q1_walkthrough.svg)

以 $nums = [1,2,1]$（$n = 3$）为例：

| 轮次 $i$ | $ans[i] = nums[i]$ | $ans[i+n] = nums[i]$ | $ans$ 当前状态 |
|---------|--------------------|----------------------|----------------|
| $i=0$ | $ans[0] = 1$ | $ans[3] = 1$ | `[1, _, _, 1, _, _]` |
| $i=1$ | $ans[1] = 2$ | $ans[4] = 2$ | `[1, 2, _, 1, 2, _]` |
| $i=2$ | $ans[2] = 1$ | $ans[5] = 1$ | `[1, 2, 1, 1, 2, 1]` ✓ |

边界 $n = 1$：唯一一轮 $i=0$ 填 $ans[0] = ans[1] = nums[0]$，得 `[7,7]`——统一映射天然覆盖，**零特判**。

## 4. 算法细节

1. **预先开好 $2n$ 再按下标写入**：C++ 用 `vector<int> ans(2 * n)`，Python 用 `[0] * (2 * n)`。比逐个 `push_back` / `append` 更直白，也免去容量增长讨论；开成 $n$ 会直接越界。
2. **循环体与题面逐字对应**：两个赋值语句就是题目的两条规则，提交前肉眼比对一遍即可，这是签到题最稳的写法——不需要任何「聪明」。
3. **索引映射变体**：单趟 $j$ 从 $0$ 到 $2n-1$，`ans[j] = nums[j % n]`，两规则合一（见 §5 引理 3）。多 $2n$ 次取模，$n \le 1000$ 下开销可忽略；价值在**视角**——$j \bmod n$ 是环形数组问题的通用钥匙（503 / 918 都建立其上）。
4. **Python 一行流**：`return nums + nums`——列表 `+` 的语义即「串联」，底层由 C 实现，最快也最 Pythonic。显式循环版仅用于向索引映射视角过渡。
5. **C++ 原地变体**：`nums.insert(nums.end(), nums.begin(), nums.end()); return nums;`——把自身接到末尾。注意这**修改了入参**，周赛无碍（LeetCode 不复用入参），工程代码里慎用。

## 5. 正确性证明

**引理 1（覆盖性）**：当 $i$ 取遍 $0, 1, \dots, n-1$ 时，算法写入的位置集合为 $\{0,\dots,n-1\} \cup \{n,\dots,2n-1\} = \{0,\dots,2n-1\}$，每个位置**恰好被写一次**。

**证明**：左半写入位置 $i$ 取遍 $[0, n-1]$ 内全部整数，右半写入位置 $i+n$ 取遍 $[n, 2n-1]$ 内全部整数；两区间不相交且并集为 $[0, 2n-1]$，故 $2n$ 个位置无重复、无遗漏地各被赋值一次。∎

**引理 2（取值正确）**：算法执行后，对一切 $0 \le i \le n-1$ 有 $ans[i] = nums[i]$ 且 $ans[i+n] = nums[i]$。

**证明**：循环体只有两个赋值语句，即这两个等式本身；由引理 1，每个位置只被写一次，不存在后续覆盖，故终态保持等式成立。∎

**引理 3（索引映射写法等价）**：单趟循环 $j$ 从 $0$ 到 $2n-1$、每轮执行 $ans[j] = nums[j \bmod n]$，输出与主算法一致。

**证明**：对 $0 \le j < n$：$j \bmod n = j$，故 $ans[j] = nums[j]$，即引理 2 第一式（令 $i = j$）。对 $n \le j < 2n$：$j \bmod n = j - n$，故 $ans[j] = nums[j-n]$，即第二式（令 $i = j - n \in [0, n-1]$）。两种写法对每个下标写入的值逐一相同。∎

**定理**：算法返回的 $ans$ 恰为题目所定义的唯一数组。

**证明**：题目对 $ans$ 每个下标处的取值都有明确定义（$ans[i]=nums[i]$、$ans[i+n]=nums[i]$），故所求数组唯一。由引理 1，算法对全部 $2n$ 个位置各赋值恰一次；由引理 2，每次赋的值与题目定义逐下标一致。因此返回值与所求数组逐下标相等。∎

**推论（两半恒等）**：返回的 $ans$ 满足 $ans[i] = ans[i+n]$ 对一切 $0 \le i \le n-1$ 成立。

**证明**：由定理，$ans[i] = nums[i]$ 且 $ans[i+n] = nums[i]$，两者相等。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。单趟循环 $n$ 轮，每轮两个 $O(1)$ 赋值，共 $2n$ 次写入；$n \le 1000$ 远在时限内。索引映射版多 $2n$ 次取模，同阶。
- **空间复杂度**：$O(1)$ **额外空间**（输出数组按惯例不计入）。输出本身占 $O(n)$——题目要求返回 $2n$ 数组，不可避免，也是本题的空间下界。

## 7. 参考代码

### C++（主写法：单趟两个赋值）

```cpp
class Solution {
public:
    vector<int> getConcatenation(vector<int>& nums) {
        int n = nums.size();
        vector<int> ans(2 * n);
        for (int i = 0; i < n; i++) {
            ans[i] = nums[i];        // 规则一：前半照抄
            ans[i + n] = nums[i];    // 规则二：后半再抄
        }
        return ans;
    }
};
```

### C++（索引映射，两规则合一）

```cpp
class Solution {
public:
    vector<int> getConcatenation(vector<int>& nums) {
        int n = nums.size();
        vector<int> ans(2 * n);
        for (int j = 0; j < 2 * n; j++) {
            ans[j] = nums[j % n];    // 统一为 j mod n
        }
        return ans;
    }
};
```

### Python（主写法）

```python
class Solution:
    def getConcatenation(self, nums: list[int]) -> list[int]:
        n = len(nums)
        ans = [0] * (2 * n)
        for i in range(n):
            ans[i] = nums[i]
            ans[i + n] = nums[i]
        return ans
```

### Python（一行流）

```python
class Solution:
    def getConcatenation(self, nums: list[int]) -> list[int]:
        return nums + nums
```

> 💡 **写法对照**：主写法与题目两条规则逐字对应，签到首选；索引映射版用 $j \bmod n$ 统一两段，是环形数组视角的入门形态（详见[每日题解](../../solution/1901-2000/1929_数组串联.md)）；Python `nums + nums` 最快最 Pythonic。三版时间同为 $O(n)$。

## 8. 边界情况与易错点

1. **`ans` 长度忘开 $2n$**：预开 `vector<int> ans(2 * n)` / `[0] * (2 * n)`；开成 $n$ 则 $ans[i+n]$ 立刻越界。若改用 `push_back` / `append` 追加则无此问题，但要追加**两轮**。
2. **循环条件写成 `i <= n`**：会读 $nums[n]$（越界）并写 $ans[2n]$（越界）。边界是 $i < n$——每轮写两格，$n$ 轮恰好 $2n$ 格。
3. **把后半写成 `ans[i] = nums[i + n]`**：读越界且方向全错——规则是「**位置**加 $n$」，**来源永远是 $nums[i]$**，两个赋值的右端完全相同。
4. **误解「串联」为交错或原地扩展**：题意是构造**新数组**、前半照抄、后半再抄；不是把元素交错排列，也不要求原地修改 `nums`。
5. **$n = 1$ 边界**：唯一一轮 $i=0$ 填 $ans[0] = ans[1] = nums[0]$，统一映射天然覆盖，**无需特判**。
6. **溢出**：$n \le 1000$、元素 $\le 1000$，下标与值都在 `int` 范围内，无需考虑。
7. **自检**：正确实现必满足 $ans[i] = ans[i+n]$；交前扫一眼后半是否为前半原样拷贝，可秒排除方向类笔误。
