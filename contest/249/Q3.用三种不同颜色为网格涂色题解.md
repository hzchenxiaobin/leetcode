# LeetCode 用三种不同颜色为网格涂色 题解

## 1. 题目概述

- **标题 / 题号**：用三种不同颜色为网格涂色（#1931，hard）
- **链接**：https://leetcode.cn/problems/painting-a-grid-with-three-different-colors/
- **来源**：LeetCode 第 249 场周赛 Q3
- **难度**：困难
- **标签**：动态规划、状态压缩、图着色、矩阵快速幂

**题意**：给定两个整数 $m$ 和 $n$，构造一个 $m \times n$ 的网格，用**红（R）、绿（G）、蓝（B）**三种颜色为每个格子涂色（所有格子都必须涂）。要求**不存在两个相邻（共享一条边）的格子颜色相同**。返回合法涂色方案数，对 $10^9 + 7$ 取余。

**约束**：

- $1 \le m \le 5$
- $1 \le n \le 1000$

> 💡 本题在本仓库另有[每日题解 1931](../../solution/1901-2000/1931_用三种不同颜色为网格涂色.md)：侧重矩阵快速幂扩展与面试问答视角。本篇按周赛复盘视角，聚焦「按列状态压缩」这条最短 AC 路径的引理-定理化证明、兼容图的度数结构观察（正则性何时失效）与赛场易错清单，两篇互为印证。

## 3. 解题思路

### 3.1 暴力思路

最朴素的做法：枚举所有 $3^{m \times n}$ 种涂色方案，逐个检查相邻格子是否同色。当 $m = 5, n = 1000$ 时方案数达 $3^{5000}$，物理上不可枚举。即使写成逐格回溯（每格只试与已涂邻居不同的颜色），最坏情形的搜索树仍然是指数级——必须把**约束的局部性**利用起来。

> ⚠️ 两条可利用的结构：① 约束只发生在**相邻**格子之间，天然按行/列分界；② 两个维度极不对称——$m \le 5$ 而 $n$ 可达 $1000$。

### 3.2 核心观察：按列状态压缩——「小维度当状态，大维度当阶段」

![按列分解：小维度压成状态，大维度当阶段](images/wc249_q3_column_state_concept.svg)

把网格**按列拆开**，每一列是一个长度为 $m$ 的颜色序列。两类约束恰好被拆成两半：

1. **列内约束（纵向）**：同一列相邻两行不同色——在**生成状态时**预先满足。合法列的个数很好数：第 0 行任选 3 色，其后每行只需与上一行不同（2 种），共
   $$S = 3 \times 2^{m-1} \le 48 \quad (m \le 5)$$
2. **列间约束（横向）**：相邻两列在**每一行**上都不同色——称两列**兼容**，交给 **DP 转移**处理。

于是整个问题变成：在「合法列状态 × 兼容关系」构成的**转移图**上，数出长度为 $n$ 的走路条数—— DP 一轮转移一列，共 $n - 1$ 轮。

> 💡 **一句话总结**：一列 $\le 48$ 种合法状态，相邻列兼容 $\iff$ 逐行不同；沿 $n$ 个列做阶段、以列状态为 DP 状态，$O(n \cdot S^2)$ 稳过。反过来按行分解，行状态数 $3 \times 2^{n-1}$ 在 $n = 1000$ 时约 $10^{301}$，直接爆炸——**状态压缩的通用原则：把小维度压进状态，沿大维度做阶段**。

### 3.3 算法流程

![算法流程：枚举、建图、逐列 DP、求和](images/wc249_q3_algorithm_flow.svg)

1. **DFS 枚举合法列**：逐行选色、与上一行不同，收集全部 $S = 3 \times 2^{m-1}$ 个列状态。
2. **建兼容邻接表**：两两检查 $O(S^2)$ 对状态，逐行比较颜色，全不同则连边，得 $\mathrm{adj}[i]$。
3. **逐列 DP（滚动数组）**：初始 $\text{dp}[s] = 1$（第 0 列）；每轮
   $$\text{new\_dp}[s] = \sum_{t \in \mathrm{adj}[s]} \text{dp}[t] \pmod{10^9+7}$$
   共 $n - 1$ 轮，只需保留上一列。
4. **求和返回**：$\text{ans} = \sum_s \text{dp}[s] \bmod (10^9+7)$。

### 3.4 示例演算

![示例演算：m=2 兼容图与 m=5 逐列计数](images/wc249_q3_example_walkthrough.svg)

**$m = 2$（6 个状态）**：合法列为 RG、RB、GR、GB、BR、BG。兼容图是一个**三角柱**：外三角 $\{RG, GB, BR\}$ 两两兼容、内三角 $\{GR, RB, BG\}$ 两两兼容、再配三条「对位」边——每个状态恰有 **3 个邻居**（3-正则）。于是 dp 每轮整体翻三倍：

| 列 | 各点 dp 值 | 列和 |
|----|-----------|------|
| 0 | 全 1 | 6 |
| 1 | 全 3 | 18 |
| 2 | 全 9 | 54 |

即 $m=2$ 时 $f(n) = 6 \cdot 3^{n-1}$。

**$m = 5, n = 5$（48 个状态）**：逐列的 dp 列和为

$$48 \to 486 \to 5118 \to 54450 \to 580986$$

与示例 3 一致。注意此时各状态的**邻居数并不相等**（6 ~ 13 个），dp 向量不再均匀，没有简单的闭式——这正是必须老老实实做转移的原因（见 §8 易错点 3）。

## 4. 算法细节

1. **状态生成（DFS）**：从上往下逐行填色，传参 `prev` 记录上一行颜色，根调用 `prev = -1` 表示第 0 行不限色。颜色用 $0/1/2$ 整数表示，比较直接判等。
2. **兼容判定与邻接表**：$\mathrm{compatible}(a, b) \iff \forall r,\ a[r] \ne b[r]$，双循环 $O(S^2 m) \approx 1.2 \times 10^4$。兼容关系对称；同一状态与自身永不兼容（每行自己等于自己），无需特判自环。把邻居存成邻接表（而非布尔矩阵），DP 时只扫真实边。
3. **滚动数组**：`dp` 与 `nxt` 交替，空间从 $O(nS)$ 压到 $O(S)$。
4. **取模节奏**：C++ 中每轮对每个状态求和后立即取模——单轮求和至多 48 项、每项 $< 10^9 + 7$，和 $< 5 \times 10^{10}$，`long long` 绰绰有余；但**若不逐轮取模**，数值会指数膨胀，若干轮后溢出。Python 无溢出，但逐轮取模能避免大整数运算拖慢速度。
5. **$n = 1$ 特判可省**：循环 `for col in [1, n)` 自然跳过，答案即 $S = 3 \times 2^{m-1}$（$m=1$ 得 3、$m=5$ 得 48，与示例 1 吻合）。

**注记（兼容边数恰为 $3^m$）**：$m$ 行时兼容无序对恰有 $E = 3^m$ 个（$m = 5$ 时 243），故 $\sum_s \deg(s) = 2E$，DP 一轮的实际加法次数是 $2 \cdot 3^m \le 486$。证明骨架：把兼容对 $\{a, b\}$ 映到「**第三色列**」$s$（$s_r$ 为异于 $a_r, b_r$ 的那个颜色），对 $m$ 归纳可证每个**任意**的 $s \in \{R,G,B\}^m$ 恰好对应一个兼容无序对——$m = 1$ 时显然；从 $m$ 推 $m+1$ 时，新行可用色是异于 $s_{m}$ 的两色，其中恰好一个是 $a_m$ 或 $b_m$ 的禁区，分配方式唯一。

## 5. 正确性证明

**引理 1（分解双射）**：设全体合法网格涂色为 $\mathcal{G}$，令 $\mathcal{S}$ 为所有满足以下条件的列序列 $(c_0, \dots, c_{n-1})$：每个 $c_j$ 列内合法（相邻行不同色），且相邻列 $c_j, c_{j+1}$ 兼容（每行颜色都不同）。映射「涂色 $\mapsto$ 按列切分」是 $\mathcal{G} \to \mathcal{S}$ 的双射。

**证明**：网格中每对相邻格子要么纵向（同列相邻行）要么横向（相邻列同一行）。涂色合法 $\iff$ 所有纵向对不同色且所有横向对不同色 $\iff$ 每列内部合法且相邻列兼容。故该映射把 $\mathcal{G}$ 恰好映满 $\mathcal{S}$；又网格由各列唯一拼成，切分与拼合互逆，是双射。∎

**引理 2（合法列计数）**：列内合法的列恰有 $S = 3 \times 2^{m-1}$ 个。

**证明**：自上而下逐行选色：第 0 行任意 3 色；第 $r \ge 1$ 行只需异于第 $r-1$ 行，恰 2 种。由乘法原理得 $3 \times 2^{m-1}$。∎

**引理 3（转移方程）**：设 $f_j(s)$ 为「前 $j+1$ 列且第 $j$ 列状态为 $s$」的合法涂色数。则 $f_0(s) = 1$，且对 $j \ge 1$：
$$f_j(s) = \sum_{t \sim s} f_{j-1}(t)$$
其中 $t \sim s$ 表示 $t$ 与 $s$ 兼容。

**证明**：对 $j$ 归纳。$j = 0$：单列涂色与其状态一一对应，每个状态恰 1 种。$j \ge 1$：由引理 1，此类涂色由「前 $j$ 列的涂色」与「第 $j$ 列取 $s$」拼成，且前 $j$ 列的末列 $t$ 必与 $s$ 兼容；反之任意「末列为 $t \sim s$ 的前 $j$ 列涂色」都能唯一拼上 $s$。按末列状态 $t$ 分类，各类互不相交且穷尽（末列由涂色唯一确定），求和式成立。∎

**定理**：算法返回值为合法涂色总数对 $10^9 + 7$ 取模的结果。

**证明**：由引理 3 与归纳法，第 $j$ 轮转移后 `dp` 与 $f_j$ 逐项相等（每步取模不改变计数，因加法对取模保持同态：$(a + b) \bmod p = ((a \bmod p) + (b \bmod p)) \bmod p$）。最终 $\sum_s f_{n-1}(s) = |\mathcal{G}|$ 由引理 1 给出（对末列状态求和即对全体涂色按末列分类）。∎

## 6. 复杂度分析

- **时间复杂度**：$O\big(S^2 (m + n)\big)$，其中 $S = 3 \times 2^{m-1} \le 48$。
  - 枚举合法列：$O(S \cdot m)$，可忽略。
  - 建兼容邻接表：$O(S^2 \cdot m) \approx 1.2 \times 10^4$。
  - DP：$n - 1$ 轮，每轮扫全部邻接边，即 $\sum_s \deg(s) = 2 \cdot 3^m \le 486$ 次加法，共 $\approx 4.9 \times 10^5$；以宽松上界 $n \cdot S^2 \approx 2.3 \times 10^6$ 计也远低于时限。
- **空间复杂度**：$O(S + E) = O(3^m)$（邻接表 $\le 48 + 243$ 个整数），滚动数组 $O(S)$，与 $n$ 无关。

## 7. 参考代码

### C++

```cpp
class Solution {
    static constexpr long long MOD = 1e9 + 7;

    void genColumns(int m, int pos, int prev, vector<int>& cur,
                    vector<vector<int>>& cols) {
        if (pos == m) { cols.push_back(cur); return; }
        for (int c = 0; c < 3; ++c) {
            if (c == prev) continue;          // 与上一行不同色
            cur.push_back(c);
            genColumns(m, pos + 1, c, cur, cols);
            cur.pop_back();
        }
    }

public:
    int colorTheGrid(int m, int n) {
        vector<vector<int>> cols;
        vector<int> cur;
        genColumns(m, 0, -1, cur, cols);
        int S = cols.size();                  // S = 3 * 2^(m-1) <= 48

        vector<vector<int>> adj(S);           // 兼容邻居表
        for (int i = 0; i < S; ++i)
            for (int j = 0; j < S; ++j) {
                bool ok = true;
                for (int r = 0; r < m && ok; ++r)
                    ok = cols[i][r] != cols[j][r];
                if (ok) adj[i].push_back(j);
            }

        vector<long long> dp(S, 1);           // 第 0 列：每个状态 1 种
        for (int col = 1; col < n; ++col) {
            vector<long long> ndp(S);
            for (int j = 0; j < S; ++j) {
                long long s = 0;
                for (int i : adj[j]) s += dp[i];
                ndp[j] = s % MOD;             // 每轮取模，防膨胀
            }
            dp = move(ndp);
        }
        long long ans = 0;
        for (long long x : dp) ans += x;
        return ans % MOD;
    }
};
```

### Python

```python
class Solution:
    def colorTheGrid(self, m: int, n: int) -> int:
        MOD = 10**9 + 7

        cols, cur = [], []
        def gen(pos, prev):                   # DFS 枚举合法列
            if pos == m:
                cols.append(tuple(cur)); return
            for c in range(3):
                if c != prev:
                    cur.append(c); gen(pos + 1, c); cur.pop()
        gen(0, -1)

        S = len(cols)                         # 3 * 2^(m-1) <= 48
        adj = [[j for j in range(S)
                if all(cols[i][r] != cols[j][r] for r in range(m))]
               for i in range(S)]

        dp = [1] * S                          # 第 0 列
        for _ in range(n - 1):
            dp = [sum(dp[i] for i in adj[j]) % MOD for j in range(S)]
        return sum(dp) % MOD
```

> 💡 两版逻辑逐行对应：DFS 状态生成 → $O(S^2 m)$ 建图 → 滚动 DP。Python 的邻接表用双重推导式一步建好；C++ 里 `s % MOD` 放在内层求和之后，避免每条边取模一次的小开销。

## 8. 边界情况与易错点

1. **方向别搞反**：状态必须是「长度 $m$ 的**列**」——因为 $m \le 5$、$n$ 可达 1000。接口 `colorTheGrid(m, n)` 中 $m$ 是行数（状态长度）、$n$ 是列数（DP 轮数）；若误把行当状态，状态数 $3 \times 2^{n-1}$ 直接爆炸。
2. **$n = 1$**：无转移，答案即 $S = 3 \times 2^{m-1}$（示例 1：$m=1$ 得 3）。循环写法天然覆盖，无需特判。
3. **正则图陷阱（本题最阴的坑）**：$m \le 2$ 时兼容图正则（每点 $2 / 3$ 个邻居），答案有闭式 $3 \cdot 2^{n-1}$、$6 \cdot 3^{n-1}$；但 $m \ge 3$ 度数不齐（$m = 3$：首尾同色型 ABA 有 5 个邻居、三色全异型 ABC 只有 4 个），**不能**想当然套 $S \cdot d^{\,n-1}$，必须老老实实逐列转移。
4. **溢出与取模**：C++ 用 `long long`；单轮求和 $\le 48 \times (10^9+6) < 5 \times 10^{10}$ 安全，但**必须逐轮取模**，否则数值逐轮放大，若干轮后溢出。Python 不会溢出，但不取模会让大整数运算越来越慢。
5. **兼容判定写全 $m$ 行**：漏一行即错；同一状态与自身必不兼容（每行自身相等），自环天然不存在，无需特判。
6. **列内约束别在 DP 里重复判**：纵向合法性在 DFS 生成状态时已经保证，DP 转移只查横向兼容——两边约束混在一起判既冗余又易错。
7. **对拍建议**：用 $m \le 2$ 的闭式与「逐格回溯暴力」在 $m \le 3, n \le 4$ 的小网格上对拍，再放大数据测 $m = 5, n = 1000$ 的耗时。

**延伸思考**：

- **$n$ 巨大（$10^9 \sim 10^{18}$）怎么办？** 把转移写成 $S \times S$ 的 0/1 矩阵 $T$（$S = 48$），则 $\text{ans} = \mathbf{1}^\top T^{\,n-1} \mathbf{1}$，矩阵快速幂 $O(S^3 \log n)$——每次矩阵乘 $48^3 \approx 1.1 \times 10^5$ 次乘法，$n = 10^{18}$ 也只需约 60 次。完整实现见每日版 1931。

- **为什么 $E = 3^m$ 如此整齐？** 见 §4 注记的「第三色列」归纳——兼容无序对与**无任何约束**的三进制列一一对应。这个巧合只属于 3 色；$k \ge 4$ 时无此好事。
