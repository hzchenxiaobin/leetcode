# LeetCode 长度为 3 的不同回文子序列 题解

## 1. 题目概述

- **标题 / 题号**：长度为 3 的不同回文子序列（#1930，medium）
- **链接**：https://leetcode.cn/problems/unique-length-3-palindromic-subsequences/
- **来源**：LeetCode 第 249 场周赛 Q2
- **难度**：中等
- **标签**：位运算、哈希表、字符串、前缀和

**题意**：给定仅含小写英文字母的字符串 `s`，统计其中**长度恰为 3** 的**不同回文子序列**的个数。同一个回文子序列即便能由多组不同下标构成，也只计数一次。**子序列**允许跳过字符、只要求保持相对顺序；**回文**要求正读反读相同。

**约束**：

- $3 \le \text{s.length} \le 10^5$
- `s` 仅由小写英文字母组成（字符集大小 $|\Sigma| = 26$）

> 💡 本题在本仓库另有[每日题解 1930](../../solution/1901-2000/1930_长度为3的不同回文子序列.md)：侧重「枚举降维」的思维链展开与面试问答。本篇按周赛复盘视角，聚焦「**两端夹中间**」这条最短路径的引理-定理化证明、中间区间统计的三种实现对照与赛场易错清单，两篇互为印证。

## 2. 示例

**示例 1**

```text
输入：s = "aabca"
输出：3
解释：长度为 3 的 3 个回文子序列分别是：
- "aba" ("a a b c a" 的子序列)
- "aaa" ("aa bc a" 的子序列)
- "aca" ("a ab ca" 的子序列)
```

**示例 2**

```text
输入：s = "adc"
输出：0
解释："adc" 不存在长度为 3 的回文子序列——任何字符都只出现一次，凑不出相同的首尾。
```

**示例 3**

```text
输入：s = "bbcbaba"
输出：4
解释：长度为 3 的 4 个回文子序列分别是：
- "bbb" ("bb c b aba" 的子序列)
- "bcb" ("b b cb aba" 的子序列)
- "bab" ("b bcb ab a" 的子序列)
- "aba" ("bbcb aba" 的子序列)
```

## 3. 解题思路

### 3.1 暴力思路

最朴素的做法：枚举所有下标三元组 $i < j < k$，判定 $s[i] = s[k]$（长度为 3 的回文当且仅当首尾相同），把拼出的字符串 $s[i]s[j]s[k]$ 丢进哈希集合去重，最后返回集合大小。

- **正确性**：穷举一切可能，显然正确。
- **效率**：三元组数量 $O(n^3)$，$n \le 10^5$ 时约 $10^{15}$ 量级，完全不可行；哈希字符串的开销更是雪上加霜。

> ⚠️ 必须利用两条性质降维：① 长度**固定为 3**——回文结构只有 $xyx$ 一种；② 只数**不同**子序列——按「字符对」而非「下标三元组」计数，天然去重。

### 3.2 核心观察：$xyx$ 结构 + 首末出现夹出「最宽中间窗口」

![核心观察：xyx 结构与首末出现夹出的最宽中间窗口](images/wc249_q2_span_concept.svg)

**观察一（结构）**：长度为 3 的回文必形如 $xyx$——首尾同为某个字符 $x$，中间字符 $y$ 任意（**允许 $y = x$**，如 `"aaa"`）。于是「不同回文子序列」$\Leftrightarrow$「不同有序对 $(x, y)$」，总数至多 $26 \times 26 = 676$ 个。

**观察二（两端夹中间）**：对固定的外层字符 $x$，所有能充当两端的下标对 $(i, k)$（$s[i] = s[k] = x$，$i < k$）中，**取 $x$ 的最左出现 $\text{first}[x]$ 与最右出现 $\text{last}[x]$ 这一对即可**——它夹出的中间窗口 $(\text{first}[x], \text{last}[x])$ 是**最宽**的，任何合法中间字符 $y$ 必然落在这个开区间里。于是

$$xyx \text{ 是 } s \text{ 的子序列} \iff y \text{ 在开区间 } (\text{first}[x],\ \text{last}[x]) \text{ 内出现}$$

**观察三（计数公式）**：把观察一、二合起来，答案就是一个双层求和——外层枚举 26 个外层字符 $x$，内层统计其开区间内**出现过多少种不同字符**：

$$\text{ans} = \sum_{x = \text{'a'}}^{\text{'z'}} \Big|\{\, y : y \text{ 出现在 } (\text{first}[x],\ \text{last}[x]) \text{ 内}\}\Big|$$

按 $(x, y)$ 对计数，相同回文只被算一次，**去重免费完成**，不再需要任何哈希集合。

> 💡 **一句话总结**：长度 3 回文 $= xyx$；两端取 $x$ 的首末出现，中间窗口里每有一种新字符就多一个回文；答案 $= \sum_x |\text{窗口内不同字符}| \le 676$。

### 3.3 算法流程

![算法流程图](images/wc249_q2_algorithm_flow.svg)

1. **预处理**：一趟扫描 $s$，记录每个字符 $c$ 的最左出现 $\text{first}[c]$ 与最右出现 $\text{last}[c]$（`first` 只在首次遇到时写入，`last` 每次覆盖）。
2. **外层循环**：$c$ 从 `'a'` 到 `'z'`：
   - 若 $c$ 未出现（$\text{first}[c] = -1$）或只出现一次（$\text{first}[c] = \text{last}[c]$），中间窗口为空，**跳过**；
   - 否则扫描开区间 $(\text{first}[c], \text{last}[c])$ 内的每个字符，标进一个 26 位的出现集合 `mask`（位掩码）。
3. **累加**：`ans += popcount(mask)`——集合里有几个不同字符，就贡献几个回文。
4. 外层循环结束，返回 `ans`。

### 3.4 示例演算

![示例演算：bbcbaba](images/wc249_q2_example_walkthrough.svg)

以 $s = {}$"bbcbaba"（下标 $0 \sim 6$）为例，逐个外层字符走查：

| 外层 $x$ | first | last | 中间开区间内容 | 不同字符集 | 生成回文 | 计数 |
|---------|-------|------|---------------|-----------|---------|------|
| `'a'` | $4$ | $6$ | $s[5..5] =$ "b" | $\{b\}$ | "aba" | $1$ |
| `'b'` | $0$ | $5$ | $s[1..4] =$ "bcba" | $\{a,b,c\}$ | "bbb","bcb","bab" | $3$ |
| `'c'` | $2$ | $2$ | 空（只出现一次） | $\varnothing$ | — | $0$ |

合计 $1 + 3 + 0 = 4$，与示例 3 一致。注意 `'b'` 行中间串 "bcba" 里 `'b'` 出现两次，但**不同字符集**只记一次——这正是「按 $(x,y)$ 对去重」的体现。

## 4. 算法细节

1. **first/last 预处理**：一趟 $O(n)$。`first[c]` 初始化为 $-1$ 表示未出现，只在 `first[c] == -1` 时写入；`last[c]` 无条件覆盖，扫完自然停在最后一次出现。
2. **中间集合统计——三种写法**（复杂度见 §6，均可通过）：
   - **写法 A（主写法，扫区间 + 位掩码）**：对每个有效 $c$ 直接遍历 $(\text{first}[c], \text{last}[c])$，用 `mask |= 1 << (s[i]-'a')` 收集，最后 `__builtin_popcount(mask)` 计数。26 个区间总长 $\le 26n$，额外空间仅 $O(26)$。
   - **写法 B（前缀和）**：预处理 `pre[i][d]` = 前 $i$ 个字符中 $d$ 的出现次数，则「$d$ 是否在 $(l, r)$ 内出现」由 `pre[r][d] - pre[l+1][d] > 0` $O(1)$ 判定，26×26 对字符共 676 次查询。空间 $O(26n)$。
   - **写法 C（出现位置列表 + 二分）**：为每个字符存出现位置数组，查询「$d$ 是否在 $(l, r)$ 内出现」= 在 $d$ 的位置数组上二分找到第一个 $> l$ 的位置，看它是否 $< r$。空间 $O(n)$，查询 $O(26^2 \log n)$。
3. **位掩码妙用**：`mask` 是 26 位整数，一位一个字符；`popcount` 直接给出「不同字符数」。字符集扩到 52/62 时换 64 位整数或 `bitset`。
4. **去重逻辑藏在结构里**：外层 $x$ 只数一次首末窗口，内层 $y$ 按集合去重——同一对 $(x, y)$ 无论窗口里出现多少次，只贡献 $1$。**不需要**把 "aba" 这类字符串塞进哈希集合。
5. **答案上界**：$26 \times 26 = 676$，`int` 绰绰有余，无溢出风险。

## 5. 正确性证明

**引理 1（结构引理）**：$s$ 的任何长度为 3 的回文子序列都形如 $xyx$（首字符与第三字符相同，中间字符任意）。

**证明**：设该子序列为 $t_1 t_2 t_3$。回文要求 $t_1 = t_3$，此即 $xyx$ 结构；对 $t_2$ 无任何约束。∎

**引理 2（最宽窗口判定）**：对字符 $x, y$，"$xyx$" 是 $s$ 的子序列 $\iff$ $y$ 在开区间 $(\text{first}[x],\ \text{last}[x])$ 内至少出现一次。约定 $x$ 出现少于两次时开区间为空、判定为假。

**证明**：
（$\Rightarrow$）设下标 $i < j < k$ 满足 $s[i] = s[k] = x$、$s[j] = y$。由定义 $\text{first}[x] \le i$ 且 $k \le \text{last}[x]$，于是 $\text{first}[x] \le i < j < k \le \text{last}[x]$，得 $\text{first}[x] < j < \text{last}[x]$，即 $y$ 在开区间内出现。
（$\Leftarrow$）设 $j$ 满足 $\text{first}[x] < j < \text{last}[x]$ 且 $s[j] = y$，取三元组 $(\text{first}[x],\ j,\ \text{last}[x])$，三个下标严格递增且字符依次为 $x, y, x$。∎

**引理 3（双射去重）**：映射 $(x, y) \mapsto$ "$xyx$" 是「有序字符对」到「长度为 3 的回文串」的双射；从而**不同有序对 $(x,y)$ 与 $s$ 中不同长度 3 回文子序列一一对应**（后者还需 $xyx$ 是 $s$ 的子序列）。

**证明**：由引理 1，每个长度 3 回文串都等于某个 "$xyx$"，故该映射满射到目标集合；又 "$xyx$" 的首字符唯一确定 $x$、第二字符唯一确定 $y$，不同的有序对给出不同的串，故单射。∎

**定理**：算法返回值恰等于 $s$ 中不同长度 3 回文子序列的个数。

**证明**：由引理 3，答案 $= \left|\{(x, y) : xyx \text{ 是 } s \text{ 的子序列}\}\right|$。由引理 2，该集合等于 $\{(x,y) : y \text{ 在 } (\text{first}[x], \text{last}[x]) \text{ 内出现}\}$，其大小为 $\sum_x |\text{开区间内不同字符}|$。算法的 `mask` 恰收集开区间（循环变量从 $\text{first}[c]+1$ 到 $\text{last}[c]-1$）内出现过的字符，`popcount` 恰为不同字符数，逐项相加与右端一致。∎

## 6. 复杂度分析

- **时间复杂度**：写法 A 为 $O(n + 26n) = O(26n)$——预处理一趟 $O(n)$，外层至多 26 个区间、每个区间长度 $\le n$，总扫描 $\le 2.6 \times 10^6$（$n = 10^5$），远在时限内。写法 B 为预处理 $O(26n)$ + 查询 $O(26^2)$；写法 C 为 $O(n + 26^2 \log n)$。三者同以 $|\Sigma|$ 为次要因子。
- **空间复杂度**：写法 A 仅 $O(26)$（`first`/`last`/`mask`），是最省的；写法 B 需 $O(26n)$ 前缀和表；写法 C 需 $O(n)$ 位置列表。输出只有一个整数。

## 7. 参考代码

### C++（主写法：扫区间 + 位掩码）

```cpp
class Solution {
public:
    int countPalindromicSubsequence(string s) {
        int n = s.size();
        int first[26], last[26];
        fill(first, first + 26, -1);
        for (int i = 0; i < n; i++) {
            int c = s[i] - 'a';
            if (first[c] == -1) first[c] = i;   // 只在首次遇到时写入
            last[c] = i;                        // 无条件覆盖，停在最后出现
        }
        int ans = 0;
        for (int c = 0; c < 26; c++) {
            if (first[c] == -1 || first[c] >= last[c]) continue;  // 窗口为空，跳过
            int mask = 0;
            for (int i = first[c] + 1; i < last[c]; i++)          // 开区间 (first, last)
                mask |= 1 << (s[i] - 'a');
            ans += __builtin_popcount(mask);      // 窗口内不同字符数
        }
        return ans;
    }
};
```

### C++（前缀和版）

```cpp
class Solution {
public:
    int countPalindromicSubsequence(string s) {
        int n = s.size();
        vector<array<int, 26>> pre(n + 1);
        pre[0].fill(0);
        for (int i = 0; i < n; i++) {
            pre[i + 1] = pre[i];
            pre[i + 1][s[i] - 'a']++;
        }
        vector<int> first(26, -1), last(26, -1);
        for (int i = 0; i < n; i++) {
            int c = s[i] - 'a';
            if (first[c] == -1) first[c] = i;
            last[c] = i;
        }
        int ans = 0;
        for (int c = 0; c < 26; c++) {
            if (first[c] == -1 || first[c] >= last[c]) continue;
            for (int d = 0; d < 26; d++)          // d 在 (first, last) 内出现？
                ans += pre[last[c]][d] - pre[first[c] + 1][d] > 0;
        }
        return ans;
    }
};
```

### Python（主写法：find / rfind + 切片集合）

```python
class Solution:
    def countPalindromicSubsequence(self, s: str) -> int:
        ans = 0
        for c in set(s):                 # 只遍历出现过的字符
            l, r = s.find(c), s.rfind(c)  # C 实现，首末出现
            if l < r:                     # 未出现/只出现一次都被此式挡掉
                ans += len(set(s[l + 1:r]))  # 开区间 (l, r) 内的不同字符
        return ans
```

> 💡 **写法对照**：C++ 主写法空间最省（$O(26)$）、思路最直白，赛场首选；前缀和版把「扫区间」换成 676 次 $O(1)$ 查询，适合顺手写过前缀和表的选手；Python 版借 `find`/`rfind`/切片的 C 级速度，四行即 AC。三者时间同阶，均 $O(26n)$ 上下。

## 8. 边界情况与易错点

1. **中间字符可以等于两端**：`"aaa"` 是合法回文，$y$ 允许 $= x$。若在统计时误加 `s[i] != c` 的过滤，会漏掉 $xxx$ 型。
2. **开区间，不是闭区间**：中间窗口是 $(\text{first}[x], \text{last}[x])$，**不含端点**——端点本身就是两端的 $x$。若误用闭区间，`"aba"` 会被算出中间含 `a`，虚增不存在的 `"aaa"`（`"aba"` 里 `a` 只在端点出现）。C++ 循环边界 `i = first+1; i < last`，Python 切片 `s[l+1:r]`，都是开区间。
3. **只出现一次或未出现的字符**：$\text{first}[c] = \text{last}[c]$（或 $= -1$）时窗口为空，必须跳过；条件写成 `first[c] < last[c]` 一式挡掉两种情况。
4. **去重方向**：题目按「字符串内容」去重，不按下标三元组。不要对三元组计数（会数重），也不必真把 `"aba"` 塞进哈希集合——按 $(x, y)$ 对计数天然去重。
5. **别把子序列当子串**：中间字符只需出现在窗口内**任意位置**，不要求与两端相邻。
6. **最小规模 $n = 3$**：`"adc"` $\to 0$（首尾凑不齐），`"aaa"` $\to 1$（窗口恰含一个 `a`）。
7. **答案上界 676**：`int` 足够；同时提醒「至多 676 个」意味着枚举 $(x,y)$ 对逐个验证的暴力也能过（每个对验证 $O(n)$ 或 $O(\log n)$），这是写法 C 的另一动机。
