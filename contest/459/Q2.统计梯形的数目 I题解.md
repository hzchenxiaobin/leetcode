# LeetCode 统计梯形的数目 I 题解

## 1. 题目概述

- **标题 / 题号**：统计梯形的数目 I（#3623，medium）
- **链接**：https://leetcode.cn/problems/count-number-of-trapezoids-i/
- **来源**：LeetCode 第 459 场周赛 Q2
- **难度**：中等
- **标签**：几何、数组、哈希表、数学、组合计数

**题意**：给定平面上 $n$ 个两两不同的点，统计从中**任选 4 个点**恰好构成**水平梯形**的方案数。水平梯形定义为**凸四边形**，且**至少一对边平行于 $x$ 轴**。答案对 $10^9 + 7$ 取模。

**约束**：

- $4 \le points.length \le 10^5$
- $-10^8 \le x_i, y_i \le 10^8$
- 所有点两两不同

## 2. 示例

**示例 1**

```text
输入：points = [[1,0],[2,0],[3,0],[2,2],[3,2]]
输出：3
解释：y=0 上有 3 个点、y=2 上有 2 个点，
      底边 3 种取法 × 顶边 1 种取法 = 3 个水平梯形
```

**示例 2**

```text
输入：points = [[0,0],[1,0],[0,1],[2,1]]
输出：1
解释：y=0 与 y=1 各有 2 个点，1 × 1 = 1
```

**补充示例 3**（无法构成任何梯形）

```text
输入：points = [[0,0],[1,0],[2,0],[3,0]]
输出：0
解释：4 点全部共线（只有一条水平线），退化，不构成四边形
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有 $\binom{n}{4} \approx 4 \times 10^{18}$（$n = 10^5$）个四点组合，逐个判凸性、判水平平行边——天文数字，不可行。即使只枚举「两条水平边」：先按 $y$ 分组，再对每对组枚举点对，也是 $O(n^2)$ 起步。必须把「选点」这一步用组合数一次性算掉。

### 3.2 核心观察：水平边只能水平来 —— 按 y 分组，两条不同水平线各取 2 点

![按y分组的2+2结构](images/wc459_q2_horizontal_lines_concept.svg)

一对水平边分别躺在两条水平线 $y = a$ 与 $y = b$ 上，且 $a \ne b$（若 $a = b$ 则 4 点共线，退化不是四边形）。每条水平边需要 2 个端点，因此**一个水平梯形对应的 4 个点必然是「2 点在 $y=a$、2 点在 $y=b$」的 2 + 2 结构**。

三个关键结论：

1. **凸性是白送的**：可以证明 2 + 2 结构必为凸四边形，且两条水平段恰为它的一对对边（§5 引理 1）——**完全不需要**叉积、凸包或面积判定。
2. **3 + 1 结构天然枚举不到**：3 点共线 + 1 点时凸包退化为三角形，而它根本不在「每线取 2 点」的枚举范围内。
3. 于是每条水平线的「供给能力」只取决于该线上的点数 $c$：$m = \binom{c}{2}$（点数不足 2 的线贡献为 0）。

### 3.3 算法流程：线对配对用平方和公式

![平方和配对公式](images/wc459_q2_pairing_formula.svg)

设所有水平线为 $v_1, v_2, \dots, v_k$（$k \le n$ 为不同 $y$ 值个数），$m_i = \binom{c_{v_i}}{2}$，则

$$\text{答案} = \sum_{1 \le i < j \le k} m_i \, m_j$$

逐对求和是 $O(k^2)$，$k$ 最坏 $10^5$ 时约 $10^{10}$ 次乘法会超时。用恒等式一步到位：

$$\sum_{i<j} m_i m_j = \frac{\Bigl(\sum_i m_i\Bigr)^2 - \sum_i m_i^2}{2}$$

**流程**：

1. 哈希表按 $y$ 统计每条水平线上的点数 $c_v$。
2. 对每个 $c_v \ge 2$，计算 $m_v = \frac{c_v (c_v - 1)}{2} \bmod p$，累加 $S = \sum m_v$ 与 $Q = \sum m_v^2$（均取模）。
3. 返回 $(S^2 - Q) \cdot \mathit{inv2} \bmod p$，其中 $\mathit{inv2} = \frac{p+1}{2} = 500000004$ 是 $2$ 在模 $p$ 意义下的逆元。

### 3.4 示例演算

![示例1三种梯形演算](images/wc459_q2_example_walkthrough.svg)

**示例 1**：$y=0$ 上 3 点 $\Rightarrow m_1 = \binom{3}{2} = 3$；$y=2$ 上 2 点 $\Rightarrow m_2 = \binom{2}{2} = 1$。$S = 4$，$Q = 9 + 1 = 10$，$\frac{16 - 10}{2} = 3$ ✓。三个梯形中 ② 恰是矩形——「至少一对水平边」，矩形当然计入。

**示例 2**：两条线各 2 点，$m_1 = m_2 = 1$，$S = 2$，$Q = 2$，$\frac{4-2}{2} = 1$ ✓。

**补充示例 3**：只有一个非零 $m$，$\frac{S^2 - Q}{2} = \frac{m^2 - m^2}{2} = 0$，公式自动给出 0 ✓。

## 4. 算法细节

1. **哈希分组**：`unordered_map<int, int>`（C++）或 `Counter`（Python），key 为 $y$ 坐标，一趟统计 $c_v$。
2. **$m$ 必须用 64 位**：$c \le 10^5$ 时 $\frac{c(c-1)}{2} \approx 5 \times 10^9$，超出 32 位 `int`。
3. **先取模再平方（头号陷阱）**：$S \le \binom{10^5}{2} \approx 5 \times 10^9$，若不取模直接算 $S^2 \approx 2.5 \times 10^{19}$，**超出 $2^{64} \approx 1.8 \times 10^{19}$，连 `unsigned long long` 都会溢出**。务必 $S \bmod p$ 之后再平方（模后 $S^2 < p^2 \approx 10^{18}$，`long long` 安全）。
4. **除以 2 的两种安全做法**：① 乘逆元 $\mathit{inv2} = \frac{p+1}{2} = 500000004$；② 干脆不除——扫描时维护「已处理线的 $m$ 之和」`pre`，每来一条新线就 `ans += m × pre`，天然规避除法。**不能**对模后的 $(S^2 - Q)$ 直接 `/2` 或 `>>1`（模后奇偶性已破坏）。
5. **$c_v < 2$ 的线**：$m = 0$，跳过与否不影响正确性，跳过可省两次乘法。

## 5. 正确性证明

**引理 1（2 + 2 必为凸四边形且水平段是对边）**：设 $A_1 = (x_1, a)$、$A_2 = (x_2, a)$（$x_1 \ne x_2$）在直线 $y = a$ 上，$B_1 = (x_3, b)$、$B_2 = (x_4, b)$（$x_3 \ne x_4$）在 $y = b$ 上，且 $a \ne b$。则这 4 个点均为凸包顶点，且 $A_1A_2$、$B_1B_2$ 是凸包的两条互相平行的水平边。

**证明**：先证无三点共线：任意非水平直线与每条水平线至多交于一点，故它至多包含 4 点中的 2 个；水平方向每线上恰 2 点，也不存在三点共线。再证 4 点均为凸包顶点：不妨设某点 $P$（在 $y=a$ 上）不是顶点，则 $P$ 落在其余三点（$y=a$ 上一点 $Q$，$y=b$ 上两点 $R, S$）构成的三角形内或边上；但边 $QR$、$QS$ 与直线 $y=a$ 仅交于 $Q$，边 $RS$ 整条位于 $y=b$ 上，故该三角形与 $y=a$ 的交恰为 $\{Q\}$，而 $P \ne Q$，矛盾；$y=b$ 上的点同理。最后证 $A_1A_2$ 是凸包边：不妨 $a < b$，则直线 $y = a$ 是支撑线（全部点在闭半平面 $y \ge a$ 内，且 $A_1, A_2$ 在线上），由凸性线段 $A_1A_2$ 含于凸包，而支撑线上的凸包点必在边界上，故 $A_1A_2$ 整段落在边界上，是一条边；同理 $y = b$（此时为上方支撑线）给出 $B_1B_2$ 是边。两边均水平，故平行。∎

**引理 2（双射）**：「从 points 中选 4 点构成水平梯形」的方案集合，与 $\{(\text{线 } y=a \text{ 上选 2 点},\ \text{线 } y=b \text{ 上选 2 点}) : a \ne b\}$ 存在一一对应。

**证明**：（→）水平梯形的一对水平边各由 2 个顶点组成，分别位于两条水平线上，且两线不同（若同线则 4 点共线，与「凸四边形」矛盾），故每个水平梯形给出唯一的 2 + 2 选取。（←）由引理 1，每个 2 + 2 选取给出凸四边形，且两条水平段是它的一对平行边，即水平梯形。两个方向构造的映射互逆（对应的 4 点集合相同），且任一 4 点集的 2 + 2 分解唯一（每条水平线上恰含其中 2 个点），不重不漏。∎

**定理**：答案 $= \sum_{i<j} m_i m_j = \dfrac{\bigl(\sum_i m_i\bigr)^2 - \sum_i m_i^2}{2} \pmod p$，其中 $m_i = \binom{c_{v_i}}{2}$。

**证明**：由引理 2，方案数等于对每对不同的水平线 $(v_i, v_j)$，「$v_i$ 上选 2 点」与「$v_j$ 上选 2 点」的方案数之积的总和，即 $\sum_{i<j} \binom{c_{v_i}}{2}\binom{c_{v_j}}{2} = \sum_{i<j} m_i m_j$。展开 $\bigl(\sum_i m_i\bigr)^2 = \sum_i m_i^2 + 2\sum_{i<j} m_i m_j$，移项即得恒等式。取模正确性：所有乘加均在 $\mathbb{Z}_p$ 上进行，除以 $2$ 即乘 $2$ 的逆元 $\frac{p+1}{2}$（$p$ 为奇素数，$2$ 可逆）。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。哈希分组一趟 $O(n)$；对 $k$ 条线求 $S$、$Q$ 一趟 $O(k) \le O(n)$。
- **空间复杂度**：$O(k)$。哈希表至多存 $n$ 个不同的 $y$ 值。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int countTrapezoids(vector<vector<int>>& points) {
        const long long MOD = 1'000'000'007;
        unordered_map<int, int> cnt;
        for (auto& p : points) cnt[p[1]]++;

        long long s = 0, q = 0;                 // S = Σm，Q = Σm²（均取模）
        for (auto& [y, c] : cnt) {
            if (c < 2) continue;
            long long m = (long long)c * (c - 1) / 2 % MOD;
            s = (s + m) % MOD;
            q = (q + m * m) % MOD;
        }
        long long inv2 = (MOD + 1) / 2;         // 2 的逆元 = 500000004
        return (s * s % MOD - q + MOD) % MOD * inv2 % MOD;
    }
};
```

### Python

```python
class Solution:
    def countTrapezoids(self, points: List[List[int]]) -> int:
        MOD = 1_000_000_007
        cnt = Counter(y for _, y in points)

        s = q = 0                               # S = Σm，Q = Σm²（均取模）
        for c in cnt.values():
            if c >= 2:
                m = c * (c - 1) // 2 % MOD
                s = (s + m) % MOD
                q = (q + m * m) % MOD
        inv2 = (MOD + 1) // 2                   # 2 的逆元 = 500000004
        return (s * s - q) % MOD * inv2 % MOD
```

## 8. 边界情况与易错点

1. **溢出（头号坑）**：$S$ 未取模可达 $\binom{10^5}{2} \approx 5 \times 10^9$，$S^2 \approx 2.5 \times 10^{19} > 2^{64} \approx 1.8 \times 10^{19}$，`unsigned long long` 也会溢出——**必须先 `% MOD` 再平方**；单线 $m = \frac{c(c-1)}{2} \approx 5 \times 10^9$ 同样超 32 位。
2. **模意义下不能 `/2`**：取模后的 $(S^2 - Q)$ 未必是偶数，要用逆元 $500000004$，或改用「前缀 $m$ 之和边扫边乘」的写法。
3. **全部点共线**：只有一条水平线有 $\ge 2$ 个点时答案为 0，公式自动覆盖（$(S^2 - Q)/2 = 0$），无需特判。
4. **不要画蛇添足判凸性**：2 + 2 结构天然凸（引理 1），写叉积/凸包纯属浪费时间；3 + 1 退化结构也天然枚举不到。
5. **矩形合法**：「至少一对水平边」包含矩形/正方形（示例 1 的 ② 就是矩形），无需排除两对平行边的情形——这与本场 Q4（任意方向平行）需要处理的方向重复问题不同。
6. **点两两不同**：题目已保证，无需按 $(x, y)$ 去重；坐标含负数，哈希 key 直接用 $y$ 即可。
