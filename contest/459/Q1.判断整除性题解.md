# LeetCode 判断整除性 题解

## 1. 题目概述

- **标题 / 题号**：判断整除性（#3622，easy）
- **链接**：https://leetcode.cn/problems/check-divisibility-by-digit-sum-and-product/
- **来源**：LeetCode 第 459 场周赛 Q1
- **难度**：简单
- **标签**：数学

**题意**：给定正整数 $n$，计算 $n$ 的**数字和** $S$（各位数字之和）与**数字积** $P$（各位数字之积），判断 $n$ 能否被 $S+P$ 整除。能则返回 `true`，否则返回 `false`。

**约束**：

- $1 \le n \le 10^6$
- 至多 7 个数位，全部由十进制数字构成

## 2. 示例

**示例 1**

```text
输入：n = 99
输出：true
解释：数字和 S = 9 + 9 = 18，数字积 P = 9 × 9 = 81，
      S + P = 18 + 81 = 99，99 % 99 == 0。
```

**示例 2**

```text
输入：n = 23
输出：false
解释：S = 2 + 3 = 5，P = 2 × 3 = 6，S + P = 11，
      23 % 11 = 1 ≠ 0。
```

**补充示例 3（含 0 数位，关键边界）**

```text
输入：n = 10
输出：true
解释：S = 1 + 0 = 1，P = 1 × 0 = 0，S + P = 1，
      10 % 1 == 0。数字 0 使数字积归零，照常计算即可。
```

**补充示例 4（最小输入）**

```text
输入：n = 1
输出：false
解释：S = 1，P = 1，S + P = 2 > 1，余数为 1。
```

## 3. 解题思路

### 3.1 暴力思路

签到题，按定义模拟即是正解：逐位取出 $n$ 的每个数字，累加得 $S$、累乘得 $P$，最后判 $n \bmod (S+P)$ 是否为 0。一遍扫描 $O(D)$（$D$ 为位数）已是最优，无需任何优化。

### 3.2 核心观察：逐位分解 + 一遍累加累乘

![数字和与数字积概念图](images/wc459_q1_digit_sum_product_concept.svg)

三个关键点：

1. **数字积初始值为 1**（乘法单位元），不是 0——这是本题最经典的写错点。
2. **数字 0 正常参与乘积**：含 0 数位时 $P = 0$，$S+P = S$ 退化为只判数字和，无需任何特判。
3. **无除零风险**：$n \ge 1$ 至少含一个非零数位，故 $S \ge 1$，$S + P \ge 1$，取模恒合法。

### 3.3 算法流程

1. 置 `s = 0`，`p = 1`。
2. 取副本 `x = n`，循环：`d = x % 10` 取末位；`s += d`；`p *= d`；`x /= 10`，直到 `x == 0`。
3. 返回 `n % (s + p) == 0`——注意**必须用原始 $n$** 取模，分解过程会销毁副本 `x`。

### 3.4 示例演算

| $n$ | 数字和 $S$ | 数字积 $P$ | $S+P$ | $n \bmod (S+P)$ | 答案 |
|-----|-----------|-----------|-------|-----------------|------|
| 99  | 9+9 = 18  | 9×9 = 81  | 99    | 0               | true |
| 23  | 2+3 = 5   | 2×3 = 6   | 11    | 1               | false |
| 10  | 1+0 = 1   | 1×0 = 0   | 1     | 0               | true |
| 1   | 1         | 1         | 2     | 1               | false |

## 4. 算法细节

1. **逐位分解**：用 `x % 10` 取末位、`x /= 10` 去末位，比转字符串更直接，也无额外分配开销。
2. **累乘初值 1**：`p` 初始化为 1；若误初始化为 0，则 $P$ 恒为 0，全部用例判成 $n \bmod S$。
3. **保留原值**：分解用副本 `x` 遍历，最后的整除判断用原始 `n`。
4. **值域核算**：$n \le 10^6$ 至多 7 位；不含 0 时 $P \le 9^6 = 531441$，$S \le 63$，`S+P` 最大约 $5.3 \times 10^5$，32 位 `int` 足够，无需 `long long`。

## 5. 正确性证明

**引理 1**：对任意正整数 $n$，其数字和 $S \ge 1$，因此 $S + P \ge 1$，取模运算合法。

**证明**：$n \ge 1$ 的最高位必为 $1 \sim 9$，至少贡献一个非零数字，故 $S \ge 1$。∎

**引理 2**（循环不变量）：设 $x$ 的当前值为十进制表示去掉末 $k$ 位后剩余的高位部分，则已累计的 `s`、`p` 恰为这 $k$ 位数字之和与之积。

**证明**：归纳。$k=0$ 时 `s=0, p=1` 为空和/空积，成立。每轮 `d = x % 10` 正确取出当前末位，`s += d`、`p *= d` 将该位并入累计值，随后 `x /= 10` 使 $k$ 增 1，不变量保持。循环终止时 $k = D$（总位数），`s`、`p` 即全体数字之和与之积。∎

**定理**：算法返回 `true` 当且仅当 $(S+P) \mid n$。

**证明**：由引理 2，`s + p` 即题面定义的 $S+P$；由引理 1 分母非零。最后一步判断 $n \bmod (S+P) = 0$ 与整除定义一致。∎

## 6. 复杂度分析

- **时间复杂度**：$O(D)$，$D$ 为 $n$ 的位数（$D \le 7$），即 $O(\log n)$。每个数位处理一次。
- **空间复杂度**：$O(1)$。只使用常数个变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool checkDivisibility(int n) {
        int s = 0, p = 1;
        for (int x = n; x > 0; x /= 10) {
            int d = x % 10;
            s += d;
            p *= d;
        }
        return n % (s + p) == 0;
    }
};
```

### Python

```python
class Solution:
    def checkDivisibility(self, n: int) -> bool:
        s, p = 0, 1
        x = n
        while x > 0:
            d = x % 10
            s += d
            p *= d
            x //= 10
        return n % (s + p) == 0
```

## 8. 边界情况与易错点

1. **累乘初值写成 0**：`p` 必须初始化为 1，否则 $P$ 恒为 0，整除判断退化为 $n \bmod S$。
2. **含 0 数位**：如 $n = 10$，$P = 0$、$S+P = 1$，任何数模 1 都为 0，恒返回 `true` 一类的值；不需特判，但演算时要意识到积会归零。
3. **销毁原值**：判整除必须用原始 $n$，分解循环务必用副本；直接 `while (n)` 会把 $n$ 改成 0 导致错误的 `n % (s+p)`。
4. **一位数恒为 false**：$n \in [1,9]$ 时 $S = P = n$，$S+P = 2n > n$，余数为 $n \ne 0$——可作对拍时的小结论。
5. **溢出**：$P \le 9^6 = 531441$，$S+P < 2^{31}$，`int` 安全；C++ 中若把 $n$ 声明为 `long long` 也无妨，但非必需。
6. **除零担忧多余**：$n \ge 1$ 保证 $S+P \ge 1$，无需防御性判断。
