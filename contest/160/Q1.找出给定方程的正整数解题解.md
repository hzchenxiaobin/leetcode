# LeetCode 找出给定方程的正整数解 题解

## 1. 题目概述

- **标题 / 题号**：找出给定方程的正整数解（#1237，medium）
- **链接**：https://leetcode.cn/problems/find-positive-integer-solution-for-a-given-equation/
- **来源**：LeetCode 第 160 场周赛 Q1
- **难度**：中等
- **标签**：数学、双指针、二分查找、交互

**题意**：给一个黑盒函数 `customfunction.f(x, y)` 和目标值 $z$，函数的具体公式未知，只知道它对两个参数都**严格递增**：$f(x,y) < f(x+1,y)$、$f(x,y) < f(x,y+1)$。要求返回**全部**满足 $f(x,y)=z$ 的正整数对 $(x,y)$，顺序任意。公式看不见，只能靠反复调用 $f$ 探测；判题器会在 9 种隐藏实现中挑一个来评判。

**约束**：

- `function_id` 共 9 种取值（判题器的 9 个隐藏实现），$1 \le z \le 100$
- 保证所有解落在 $1 \le x, y \le 1000$
- 保证 $1 \le x, y \le 1000$ 时 $f(x,y)$ 始终在 32 位有符号整数范围内
- 对两个参数都严格单调递增，因此固定一个参数时，另一个参数最多对应一个解

## 2. 示例

**示例 1**

```text
输入：function_id = 1, z = 5
输出：[[1,4],[2,3],[3,2],[4,1]]
解释：function_id = 1 对应 f(x, y) = x + y。
      f(1,4) = f(2,3) = f(3,2) = f(4,1) = 5；
      x = 5 时 y 必须取 0，已不是正整数。
```

**示例 2**

```text
输入：function_id = 2, z = 5
输出：[[1,5],[5,1]]
解释：function_id = 2 对应 f(x, y) = x · y。
      z = 5 是质数，只有 1×5 与 5×1 两种正整数分解。
```

**示例 3（补充：同一判题器的另一种实现）**

```text
输入：function_id = 5, z = 25
输出：[[3,4],[4,3]]
解释：function_id = 5 对应 f(x, y) = x² + y²，3² + 4² = 4² + 3² = 25。
      (0,5)、(5,0) 不是正整数对，不计入答案。
```

## 3. 解题思路

### 3.1 暴力思路

最直白：两重循环枚举 $1 \le x, y \le 1000$，每个格子调一次 $f$，等于 $z$ 就收集，共 $10^6$ 次调用。逻辑没错，但浪费严重：

- 交互题每次调用都要过一层判题器代理，常数远大于普通函数调用，$10^6$ 次在 Python 下很容易 TLE；
- 完全没用上单调性——固定 $x$ 后一旦某个 $y$ 让 $f(x,y) > z$，更大的 $y$ 只会更大，后面的判断全是白做；
- 若把 $z$ 的量级放大（函数不变），$O(1000^2)$ 的写法立刻失效。

### 3.2 核心观察：解集是一条严格下降的阶梯

![单调矩阵里的解集是一条阶梯](images/wc160_q1_monotone_staircase.svg)

**观察 1（每行至多一个解）**：固定 $x$ 时 $f(x,\cdot)$ 严格递增，所以 $f(x,y)=z$ 在 $y$ 上至多一个解。

**观察 2（解的 $y$ 随 $x$ 增大而严格减小）**：若 $f(x_1,y_1)=f(x_2,y_2)=z$ 且 $x_1<x_2$，则必有 $y_1>y_2$（反证见引理 2）。

把所有解画在坐标系里，它们恰好落在一条**从左上到右下的阶梯**上：$x$ 越大，配对的 $y$ 越小。站在当前点 $(x,y)$、记 $v=f(x,y)$，三种情况各自能一次性排除一整行或一整列：

| $v$ 与 $z$ | 可以排除的候选 | 指针动作 |
|------------|----------------|----------|
| $v < z$ | 固定 $x$、所有 $y' \le y$ 的格子 | `x++` |
| $v > z$ | 固定 $y$、所有 $x' \ge x$ 的格子 | `y--` |
| $v = z$ | 该行剩余部分（$< z$）与该列剩余部分（$> z$） | 记录后 `x++`、`y--` |

**起点取 $(1,z)$**：判题器的 9 种实现都满足 $f(x,y) \ge \max(x,y)$（逐条代入即可验证），因此 $f(x,y)=z$ 蕴含 $x \le z$、$y \le z$，从 $(1,z)$ 出发既不会漏解，也不用从 $1000$ 一路退下来。

> 💡 单调性把「$10^6$ 个格子逐一检查」压成「沿阶梯走 $2z$ 步、每步一次调用」。

### 3.3 算法流程

![双指针阶梯搜索流程](images/wc160_q1_two_pointer_flow.svg)

```text
ans ← []
x ← 1, y ← z
while x ≤ z and y ≥ 1:
    v ← f(x, y)
    if v == z:  ans 加入 (x, y); x ← x + 1; y ← y - 1
    elif v < z: x ← x + 1
    else:       y ← y - 1
return ans
```

**不变量**：每轮开始时，所有尚未被记录的解 $(x^*,y^*)$ 都满足 $x^* \ge x$ 且 $y^* \le y$。初始 $(1,z)$ 成立，三种转移各自保持它（见 §5 引理 4）。

**终止性**：每轮要么 $x$ 加一、要么 $y$ 减一，故循环不超过 $z+z=2z$ 轮，即最多 $2z$ 次调用。

### 3.4 示例演算

取 $f(x,y)=x \cdot y$、$z=8$，解为 $(1,8),(2,4),(4,2),(8,1)$，阶梯形状最明显。

![f(x,y)=x·y, z=8 的走查](images/wc160_q1_walkthrough.svg)

| 步 | 当前 $(x,y)$ | $f(x,y)$ | 比较 | 动作 |
|----|--------------|----------|------|------|
| 1 | $(1,8)$ | 8 | $= z$ | 记录 $(1,8)$，`x++`、`y--` |
| 2 | $(2,7)$ | 14 | $> z$ | `y--` |
| 3 | $(2,6)$ | 12 | $> z$ | `y--` |
| 4 | $(2,5)$ | 10 | $> z$ | `y--` |
| 5 | $(2,4)$ | 8 | $= z$ | 记录 $(2,4)$，`x++`、`y--` |
| 6 | $(3,3)$ | 9 | $> z$ | `y--` |
| 7 | $(3,2)$ | 6 | $< z$ | `x++` |
| 8 | $(4,2)$ | 8 | $= z$ | 记录 $(4,2)$，`x++`、`y--` |
| 9 | $(5,1)$ | 5 | $< z$ | `x++` |
| 10 | $(6,1)$ | 6 | $< z$ | `x++` |
| 11 | $(7,1)$ | 7 | $< z$ | `x++` |

共 12 次调用拿到 4 组解；同等规模下暴力枚举要 $8 \times 8 = 64$ 次调用。$z=100$ 时差距是 $2\times 10^2$ 对 $10^4$。

## 4. 算法细节

1. **初值取 $y=z$ 而不是 $y=1000$**。这依赖 9 种实现都满足 $f(x,y) \ge \max(x,y)$，故解必有 $x,y \le z$；比从 $1000$ 退下来少走几百步。若只依赖题面给出的单调性（不看具体实现），可用二分在 $[1,1000]$ 上找「最大的 $y$ 使 $f(1,y) \le z$」作为初值，代价 $O(\log 1000)$ 次额外调用，同样正确。
2. **循环条件两侧都要判**（`x <= z && y >= 1`）。$x$ 只增、$y$ 只减，任何一侧越界都说明候选集已空；只判一侧会在另一侧越界后继续空转，甚至探测到非正整数的格子。
3. **命中时两个指针一起动**。$v=z$ 时该行剩余位置都 $< z$、该列剩余位置都 $> z$，行、列可同时排除；若只 `x++` 也正确（下一步必然 $>z$ 再 `y--`），但不变量的保持会变得不对称，证明要多绕一步。
4. **每轮只调用一次 $f$**。总调用次数 $\le 2z \le 200$，这是本题最省的交互量级；不要在循环里额外调用 $f$ 做「预检查」或「回退验证」。
5. **答案无需去重**。路径上 $x$ 单调不减、$y$ 单调不增，且每步必动其中一个变量，所以同一格子不会访问两次；又由每行至多一解，答案规模 $\le z$。
6. **不要猜测公式**。签名只给 `customfunction` 对象，拿不到 `function_id`；写「$f=x+y$ 特判」既不被接口允许，也违背题意。
7. **只做比较、不做算术**。$v$ 只参与 `==`、`<`、`>`，不参与加减乘除，天然没有溢出风险（$f$ 本身由判题器保证落在 32 位内）。

## 5. 正确性证明

**引理 1（行内至多一解）**：对任意固定的 $x$，满足 $f(x,y)=z$ 的正整数 $y$ 至多一个。

**证明**：若 $y_1<y_2$ 都满足，由 $y$ 方向严格递增得 $f(x,y_1)<f(x,y_2)$，二者不可能同时等于 $z$。∎

**引理 2（阶梯单调）**：若 $(x_1,y_1)$、$(x_2,y_2)$ 都是解且 $x_1<x_2$，则 $y_1>y_2$。

**证明**：反设 $y_1 \le y_2$。由 $x$ 方向严格递增，$f(x_1,y_1)<f(x_2,y_1)$；由 $y$ 方向严格递增及 $y_1 \le y_2$，$f(x_2,y_1) \le f(x_2,y_2)$。两式相连得 $f(x_1,y_1)<f(x_2,y_2)$，与二者都等于 $z$ 矛盾。∎

**引理 3（局部排除）**：在当前点 $(x,y)$ 处：

- 若 $f(x,y)<z$，则对所有 $1 \le y' \le y$ 有 $f(x,y')<z$；
- 若 $f(x,y)>z$，则对所有 $x' \ge x$ 有 $f(x',y)>z$；
- 若 $f(x,y)=z$，则对所有 $y'<y$ 有 $f(x,y')<z$，对所有 $x'>x$ 有 $f(x',y)>z$。

**证明**：三条都直接来自单调性：$y' \le y \Rightarrow f(x,y') \le f(x,y)$，且严格递增保证 $y'<y$ 时严格小；$x' \ge x \Rightarrow f(x',y) \ge f(x,y)$；代入 $f(x,y)=z$ 即得第三组不等号。∎

**引理 4（不变量）**：每轮循环开始时，所有解要么已被记录，要么满足 $x^* \ge x$ 且 $y^* \le y$。

**证明**：对轮数归纳。初始 $x=1$、$y=z$：任何解都有 $x^* \ge 1$；又 9 种实现满足 $f(x,y) \ge y$，故 $y^* \le f(x^*,y^*)=z$，不变量成立。

设本轮开始时不变量成立。

- 若 $f(x,y)<z$：由引理 3，固定 $x$ 的整行在 $y' \le y$ 处无解；于是未记录的解都满足 $x^* \ge x+1$、$y^* \le y$，$(x+1,y)$ 保持不变量。
- 若 $f(x,y)>z$：由引理 3，固定 $y$ 的整列在 $x' \ge x$ 处无解；未记录的解满足 $x^* \ge x$、$y^* \le y-1$，$(x,y-1)$ 保持不变量。
- 若 $f(x,y)=z$：记录 $(x,y)$。由引理 3，该行在 $y'<y$ 处都 $< z$、该列在 $x'>x$ 处都 $> z$；又由不变量，$y'>y$ 与 $x'<x$ 处没有未记录的解，故剩余解满足 $x^* \ge x+1$、$y^* \le y-1$，$(x+1,y-1)$ 保持不变量。∎

**定理**：循环结束时 `ans` 恰好是全部解。

**证明**：一方面，每个被记录的 $(x,y)$ 在记录前刚比较过，满足 $f(x,y)=z$，且由引理 1 不会重复记录，故 `ans` 中没有假解。另一方面，循环只因 $x>z$ 或 $y<1$ 结束；由引理 4 及「解满足 $1 \le x^*,y^* \le z$」，若仍有未记录的解，则须同时满足 $x^* \ge x>z$ 与 $x^* \le z$（矛盾），或 $y^* \le y<1$ 与 $y^* \ge 1$（矛盾）。故不遗漏。∎

## 6. 复杂度分析

- **时间**：$O(z)$ 次 $f$ 调用。循环最多 $2z$ 轮，每轮一次调用、常数次比较与指针移动；$z \le 100$ 时不超过 200 次调用。收集答案额外 $O(|\text{ans}|) \le O(z)$。
- **空间**：除答案外 $O(1)$（两个指针 + 一个临时值）；答案本身 $O(|\text{ans}|) \le O(z)$。
- **对照**：暴力 $O(1000^2)$ 次调用；逐行二分 $O(z \log z)$ 次调用；双指针 $O(z)$ 次调用，且完全不依赖函数的具体形状。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<vector<int>> findSolution(CustomFunction& customfunction, int z) {
        vector<vector<int>> ans;
        int x = 1, y = z;                  // 解必满足 x, y <= z
        while (x <= z && y >= 1) {
            int v = customfunction.f(x, y);
            if (v == z) {
                ans.push_back({x, y});
                ++x;                       // 该行剩余位置都小于 z
                --y;                       // 该列剩余位置都大于 z
            } else if (v < z) {
                ++x;                       // 固定 x 的一整行排除
            } else {
                --y;                       // 固定 y 的一整列排除
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def findSolution(self, customfunction: 'CustomFunction', z: int) -> List[List[int]]:
        ans = []
        x, y = 1, z                    # 解必满足 x, y <= z
        while x <= z and y >= 1:
            v = customfunction.f(x, y)
            if v == z:
                ans.append([x, y])
                x += 1                 # 该行剩余位置都小于 z
                y -= 1                 # 该列剩余位置都大于 z
            elif v < z:
                x += 1                 # 固定 x 的一整行排除
            else:
                y -= 1                 # 固定 y 的一整列排除
        return ans
```

## 8. 边界情况与易错点

1. **无解**：$f(x,y)=x^2+y^2$、$z=3$ 时只有 $(1,1)$ 使 $f=2$，走几步排除后返回 `[]`。中途没找到不代表后面没有，不能提前 `break`。
2. **起点本身就是解**：$f=x \cdot y$、$z=25$ 时第一步就是 $(1,25)$；必须先比较再移动，若先 `y--` 会漏掉 $y=z$ 这一列。
3. **$z=1$**：只有 $f(1,1)=1$ 的实现（$x \cdot y$）有解 $(1,1)$，其余返回空；循环里的 `y >= 1` 保证不会探测 $y=0$。
4. **指针越界**：命中后 $x$ 可能变成 $z+1$、$y$ 可能变成 $0$，必须靠 `while` 条件兜住；写成死循环再内部判断，容易漏掉出口。
5. **不要自己实现 `CustomFunction`**：接口由判题器注入，自己再定义一遍会造成重定义（C++ 编译错误）或覆盖判题器实现。
6. **不要依赖 `function_id`**：函数签名里只有 `customfunction` 对象；用编号特判既拿不到编号，也绕过了题意。
7. **返回类型**：C++ 是 `vector<vector<int>>`，`ans.push_back({x, y})` 依赖 C++11 列表初始化；Python 返回 `List[List[int]]`，别返回元组列表。
8. **别用集合去重答案**：每个 $x$ 至多一解、路径不重复走同一格，天然无重复；加 `std::set` 只会增加常数并破坏「按 $x$ 递增」的顺序。
