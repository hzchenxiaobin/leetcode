# LeetCode 循环码排列 题解

## 1. 题目概述

- **标题 / 题号**：循环码排列（#1238，medium）
- **链接**：https://leetcode.cn/problems/circular-permutation-in-binary-representation/
- **来源**：LeetCode 第 160 场周赛 Q2
- **难度**：中等
- **标签**：位运算、数学、回溯

**题意**：给定 $n$ 与 $start$，构造 $0, 1, \dots, 2^n-1$ 的一个排列 $p$（每个数**恰好出现一次**），满足三条：$p[0] = start$；相邻两项 $p[i], p[i+1]$ 的二进制只有一位不同；首尾 $p[2^n-1]$ 与 $p[0]$ 也只有一位不同。

换一种说法：把 $0 \sim 2^n-1$ 看成 $n$ 维超立方体的 $2^n$ 个顶点，两个数相邻当且仅当二进制只差一位。题目要的就是一条**从 $start$ 出发、把所有顶点恰好走一遍、最后回到起点**的哈密顿回路。

**约束**：

- $1 \le n \le 16$，即顶点数 $2^n \le 65536$
- $0 \le start < 2^n$
- 答案不唯一：**任意**合法排列都判对（Special Judge），不要试图与示例输出逐位比对

## 2. 示例

**示例 1**

```text
输入：n = 2, start = 3
输出：[3,2,0,1]
解释：二进制为 (11,10,00,01)：
      11→10 差 bit0，10→00 差 bit1，00→01 差 bit0，01→11（首尾）差 bit1。
      另一个合法答案是 [3,1,0,2]。
```

**示例 2**

```text
输入：n = 3, start = 2
输出：[2,6,7,5,4,0,1,3]
解释：二进制为 (010,110,111,101,100,000,001,011)，每对相邻（含首尾）恰好一位不同。
      官方答案是把标准格雷码旋转到 2 开头；本解输出
      [2,3,1,0,4,5,7,6]（二进制 010,011,001,000,100,101,111,110），同样合法。
```

## 3. 解题思路

### 3.1 暴力思路

最朴素的做法是**回溯搜索**：从 $start$ 出发，每次尝试翻转某一位走到未访问的邻居，走满 $2^n$ 个顶点后检查能否回到起点。单次推进的分支是 $n$ 个，最坏情况是指数级回溯（本质上是在超立方体上找哈密顿回路，一般图上是 NP 完全问题）；即使某个访问顺序侥幸一次走通，也没有可证明的时间界，不能当作可靠解法。

另一类「暴力」是先生成答案再检查：枚举 $2^n$ 个数的全排列是 $(2^n)!$ 级别，毫无意义。

关键问题是：**我们需要的不是搜索，而是一个已知的构造**。而 $n$ 维超立方体的哈密顿回路恰好有教科书级的构造——格雷码。

### 3.2 核心观察：二进制反射格雷码就是一条回路

![格雷码在立方体上构成哈密顿回路](images/wc160_q2_gray_cycle.svg)

定义**二进制反射格雷码**

$$g(i) = i \oplus (i \gg 1), \qquad i = 0, 1, \dots, 2^n-1$$

其中 $\oplus$ 是异或、$\gg$ 是右移。它有两个关键性质：

1. **相邻性**：$g(i) \oplus g(i+1)$ 恒为 $2^k$（单个 1），所以 $g(i)$ 与 $g(i+1)$ 只差一位；
2. **首尾性**：$g(0) = 0$，$g(2^n-1) = 2^{n-1}$，两者只差最高位。

于是 $g(0), g(1), \dots, g(2^n-1)$ 已经是一条**首尾闭合**的环，只是它固定以 $0$ 开头，不满足 $p[0] = start$。

**怎么把起点搬到 $start$？** 注意三条要求全部是「两个数的二进制差几位」这种**相对**条件，它们只依赖于 Hamming 距离：

$$\text{Hamming}(u \oplus s,\ v \oplus s) = \text{Hamming}(u, v)$$

也就是说，对序列里**每个元素同时异或 $start$**，是一个保距离的变换（超立方体的自同构）：环还是环，只是每个顶点都被重新贴了标签，原来的起点 $0$ 变成了 $start$。而 $g(i)$ 取遍全部 $2^n$ 个值，异或后依然取遍全部值，排列性也不受影响。

于是答案只有一行：

$$p[i] = \bigl(i \oplus (i \gg 1)\bigr) \oplus start$$

> 💡 官方提示给了「先造格雷码、再旋转到 $start$ 开头」的路线；异或平移是同一思路的更强版本——**不需要查找 $start$ 在格雷码中的位置**，一次位运算就完成「平移起点」。

### 3.3 算法流程

![算法流程与两个性质的推导](images/wc160_q2_algorithm_flow.svg)

1. 计算顶点数 $total = 2^n$；
2. 对 $i$ 从 $0$ 到 $total-1$：先算格雷码 $g = i \oplus (i \gg 1)$；
3. 再异或起点：$p[i] = g \oplus start$，直接写入答案数组；
4. 返回 $p$。

全过程**一次线性扫描**，没有搜索、没有回溯、没有去重，也不需要任何判定；合法性由 §5 的引理保证。

### 3.4 示例演算

取 $n = 3$、$start = 2$：

![n=3, start=2 的逐项演算](images/wc160_q2_walkthrough.svg)

| $i$ | $i \gg 1$ | $g(i) = i \oplus (i \gg 1)$ | $p[i] = g \oplus 2$ | 二进制 |
|-----|-----------|-----------------------------|---------------------|--------|
| 0 | 0 | 0 | 2 | 010 |
| 1 | 0 | 1 | 3 | 011 |
| 2 | 1 | 3 | 1 | 001 |
| 3 | 1 | 2 | 0 | 000 |
| 4 | 2 | 6 | 4 | 100 |
| 5 | 2 | 7 | 5 | 101 |
| 6 | 3 | 5 | 7 | 111 |
| 7 | 3 | 4 | 6 | 110 |

相邻两行的差值（异或）依次是 $1, 2, 1, 4, 1, 2, 1$，全是**单个 1**；首尾 $110 \oplus 010 = 100 = 4$，同样是单个 1，环闭合。答案 $p = [2,3,1,0,4,5,7,6]$，是 $[0,2^3)$ 的一个排列且 $p[0]=2$，三条要求全部满足。

## 4. 算法细节

1. **括号不要省**：写成 `i ^ (i >> 1)`。C++ 中 `>>` 的优先级高于 `^`，`i ^ i >> 1` 恰好也解析成同一式子，但依赖优先级会让人误读；Python 的 `^` 与 `>>` 同样如此，统一加括号最稳。
2. **整数范围**：$n \le 16$ 时 $2^{16} = 65536$，`1 << n` 与所有中间值都在 `int` 内，不需要 `long long`；但写 `1 << n` 时要确认 `n` 不是负数（约束已保证 $n \ge 1$）。
3. **不要真的去「旋转」**：旋转法要先定位 $start$ 在格雷码里的下标——线性扫描是 $O(2^n)$，用逆格雷码 $i = g \oplus (g \gg 1) \oplus (g \gg 2) \oplus \cdots$ 是 $O(n)$；而异或平移是 $O(1)$，且输出仍然是合法回路。
4. **两种答案形状不同**：旋转法得到的是「遍历顺序不变、起点后移」，异或法得到的是「顶点重贴标签」。两者都合法（如示例 2 官方输出 $[2,6,7,5,4,0,1,3]$，本解输出 $[2,3,1,0,4,5,7,6]$），因此**绝不要**为了对齐示例而加特判。
5. **输出数组预分配**：C++ 用 `vector<int> ans(1 << n)` 再按下标赋值，避免 `push_back` 反复扩容；Python 直接列表推导即可。
6. **不需要 `set` / `sort` / 去重**：$i \mapsto i \oplus (i \gg 1)$ 是双射（引理 2），异或又是双射，$p$ 天然是 $0 \sim 2^n-1$ 的一个排列，多做一步排序只会把 $O(2^n)$ 变成 $O(2^n \log 2^n)$。
7. **首元素自然正确**：$g(0) = 0 \oplus 0 = 0$，所以 $p[0] = 0 \oplus start = start$，不需要额外交换首元素。

## 5. 正确性证明

**引理 1（相邻只差一位）**：设 $i < 2^n - 1$，且 $i$ 的二进制末尾恰有 $k$ 个连续的 1，则 $g(i) \oplus g(i+1) = 2^k$。

**证明**：$i$ 的末尾形如 $\cdots 0\underbrace{1\cdots1}_{k}$，因此 $i \oplus (i+1) = 2^{k+1}-1$（低 $k+1$ 位全部取反、更高位不变）。又因为异或与右移可交换，$(i \gg 1) \oplus ((i+1) \gg 1) = (i \oplus (i+1)) \gg 1 = 2^k - 1$。于是

$$g(i) \oplus g(i+1) = \bigl(i \oplus (i \gg 1)\bigr) \oplus \bigl((i+1) \oplus ((i+1) \gg 1)\bigr) = (2^{k+1}-1) \oplus (2^k-1) = 2^k$$

即异或结果是单个 1，两项只差第 $k$ 位。∎

**引理 2（$g$ 是双射）**：$g(i) = i \oplus (i \gg 1)$ 是 $\{0,\dots,2^n-1\}$ 到自身的双射。

**证明**：$g$ 是 $\mathbb{F}_2^n$ 上的线性映射，其矩阵 $M = I + S$（$S$ 为右移矩阵）是主对角线全 1 的三角矩阵，故 $\det M = 1$，映射可逆。显式逆变换为逐级前缀异或：

$$i = g \oplus (g \gg 1) \oplus (g \gg 2) \oplus \cdots \oplus (g \gg (n-1))$$

所以 $g$ 是双射，$g(0), \dots, g(2^n-1)$ 恰好取遍全部 $2^n$ 个值。∎

**引理 3（首尾只差一位）**：$g(0) = 0$，$g(2^n-1) = 2^{n-1}$，二者异或为 $2^{n-1}$，只差最高位。

**证明**：$2^n-1$ 的二进制是全 1，$(2^n-1) \gg 1 = 2^{n-1}-1$（低 $n-1$ 位全 1），两者异或得 $2^{n-1}$。∎

**引理 4（异或保距离）**：对任意 $u, v, s$，$\text{Hamming}(u \oplus s,\ v \oplus s) = \text{Hamming}(u, v)$。

**证明**：第 $j$ 位上 $(u \oplus s)$ 与 $(v \oplus s)$ 是否相同，取决于 $u_j = v_j$ 是否成立，与 $s_j$ 无关；故所有位上「是否不同」的判定结果全部不变，计数自然相等。∎

**定理**：令 $p[i] = g(i) \oplus start$（$0 \le i < 2^n$），则 $p$ 是 $0,\dots,2^n-1$ 的排列，且 $p[0] = start$、$p[i]$ 与 $p[i+1]$ 只差一位、$p[2^n-1]$ 与 $p[0]$ 只差一位。

**证明**：排列性由引理 2 与「$x \mapsto x \oplus start$ 是双射」得到；$p[0] = g(0) \oplus start = start$ 由引理 3 前半段得到；相邻性与首尾性分别是引理 1、引理 3 的不等式，再经引理 4 在两边同时异或 $start$ 后保持为「差一位」。三条要求全部满足。∎

## 6. 复杂度分析

- **时间**：$O(2^n)$。对每个 $i$ 只做一次右移、两次异或，$O(1)$ 次位运算，共 $2^n$ 次迭代；$n \le 16$ 时不超过 $65536$ 次迭代，实际运行在毫秒级。
- **空间**：$O(2^n)$，且全部是**输出本身**占用的空间；除答案数组外只用到循环变量与临时变量，额外空间 $O(1)$（不计返回值）。

## 7. 参考代码

### C++

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> circularPermutation(int n, int start) {
        int total = 1 << n;
        vector<int> ans(total);
        for (int i = 0; i < total; i++) {
            int g = i ^ (i >> 1);        // 二进制反射格雷码
            ans[i] = g ^ start;          // 整体异或，把起点搬到 start
        }
        return ans;
    }
};
```

### Python

```python
from typing import List


class Solution:
    def circularPermutation(self, n: int, start: int) -> List[int]:
        total = 1 << n
        # g(i) = i ^ (i >> 1) 是反射格雷码；再整体异或 start 相当于平移起点
        return [(i ^ (i >> 1)) ^ start for i in range(total)]
```

## 8. 边界情况与易错点

1. **$n = 1$**：只有 $\{0,1\}$ 两个顶点，$g = [0,1]$。此时 $p[0]$ 与 $p[1]$ 这一对边**既是相邻边又是首尾边**，两个元素互为取反（差一位），三条要求同时成立：$start=0$ 得 $[0,1]$，$start=1$ 得 $[1,0]$。不要给 $n=1$ 加特判。
2. **$start = 0$**：此时答案就是标准格雷码 $[0,1,3,2,6,7,5,4,\dots]$，可以拿来做「无异或」的对照测试。
3. **$start = 2^n-1$**：整体异或全 1 等于把每个数按位取反，回路依然合法；$n=2, start=3$ 时恰得示例 1 的 `[3,2,0,1]`。
4. **特殊判题，别硬比输出**：示例 2 的官方输出与本解不同但同样正确。若在本地测试里写 `assert ans == [2,6,7,5,4,0,1,3]`，会把正确代码误判为错。
5. **数组长度必须恰好 $2^n$**：`range(total)` / `i < total` 恰好 $total$ 个值，写成 `<= total` 会多算一项，写成 `range(total - 1)` 会漏掉最后一项，两者都会破坏排列性。
6. **位运算括号**：`i ^ (i >> 1)` 两侧都加括号，避免把 `i ^ i >> 1`、`(i ^ i) >> 1` 这类笔误带进代码。
7. **不要用 `set` 去重后转列表**：那会打乱顺序，直接毁掉相邻性；答案天然无重复（引理 2）。
