# LeetCode 移动机器人 题解

## 1. 题目概述

- **标题 / 题号**：移动机器人（#2731，medium）
- **链接**：https://leetcode.cn/problems/movement-of-robots/
- **来源**：LeetCode 第 106 场双周赛 Q3
- **难度**：中等
- **标签**：脑筋急转弯、数组、前缀和、排序

**题意**：数轴上 $n$ 个机器人，初始位置 `nums[i]`，方向由字符串 `s` 给出（`'L'` 向左、`'R'` 向右），均以每秒 1 单位的速度匀速运动。两个机器人在同一时刻占据同一位置即**相撞**，撞后立即掉头（不耗时）。指令执行 $d$ 秒后，求所有机器人两两之间的距离之和，对 $10^9 + 7$ 取余。机器人**无差别**：$(i, j)$ 与 $(j, i)$ 视为同一对。

**约束**：

- $2 \le nums.length \le 10^5$
- $-2 \times 10^9 \le nums[i] \le 2 \times 10^9$，且 `nums[i]` 互不相同
- $0 \le d \le 10^9$
- `nums.length == s.length`，`s` 只含 `'L'`/`'R'`

## 2. 示例

**示例 1**

```text
输入：nums = [-2,0,2], s = "RLL", d = 3
输出：8
解释：碰撞轨迹为 [-1,-1,1] → [-2,0,0] → [-3,-1,1]，两两距离 2 + 4 + 2 = 8。
```

**示例 2**

```text
输入：nums = [1,0], s = "RL", d = 2
输出：5
解释：两机器人相背而行，3 秒后位于 3 与 −2，距离 5。
```

**示例 3（边界补充）**

```text
输入：nums = [0, 1], s = "RL", d = 2
输出：3
解释：相向而行：0.5 秒后在 0.5 处相撞掉头（幻影世界里直接穿过），
      2 秒后分别位于 −1 与 2，距离 3。碰撞发生在非整数时刻！
```

## 3. 解题思路

### 3.1 暴力思路

逐秒（甚至逐事件）模拟碰撞过程：每秒按方向移动、检测同点机器人、集体掉头，$d$ 秒后统计两两距离。单看时间复杂度是 $O(d \cdot n)$——$d$ 高达 $10^9$，纯按秒模拟直接爆炸；按碰撞事件离散化模拟（相邻相向对相撞）事件数也是 $O(nd)$ 级别。必须找到碰撞的"不变量"，绕开过程看终态。

### 3.2 核心观察：相撞掉头 ≡ 互相穿过（只交换标签）

![核心观察：碰撞反弹的世界与穿过世界的位置多重集逐刻相同](images/bw106_q3_pass_through.svg)

**穿过等价**：设想机器人是"幻影"，相撞时不掉头而直接穿过对方。断言：**任意时刻，真实世界（撞后掉头）的位置多重集与幻影世界（直接穿过）完全相同**。

道理在于机器人**无差别**：两个机器人相撞掉头的净效果，等价于"两个机器人互换身份后各自继续前进"。站在旁观者角度，"A 在左掉头回来、B 在右掉头回来"与"A 穿过去变成右边的那个、B 穿过去变成左边的那个"，占据的位置集合一模一样——我们只统计位置的距离和，不在乎谁是谁。于是终态位置可以**逐个独立计算**：

$$pos_i = nums[i] + \begin{cases} +d & s_i = \texttt{'R'} \\ -d & s_i = \texttt{'L'} \end{cases}$$

完全不用管谁撞了谁、撞了几次。

### 3.3 排序 + 前缀和：两两距离和的线性计算

![排序后每个点的贡献：a_i × (2i − n + 1)](images/bw106_q3_prefix_sum.svg)

把终态位置排序为 $a_0 \le a_1 \le \cdots \le a_{n-1}$，答案为 $\sum_{i<j}(a_j - a_i)$。固定 $a_i$：它是 $i$ 个对里的"较小端"（减别人 $i$ 次），又是 $n-1-i$ 个对里的"较大端"（被减 $n-1-i$ 次），故

$$\sum_{i<j}(a_j - a_i) = \sum_{i=0}^{n-1} a_i \cdot \big(i - (n-1-i)\big) = \sum_{i=0}^{n-1} a_i\,(2i - n + 1)$$

实现上用前缀和更顺手：遍历排序后的 $a_i$，维护 `prefix` $= a_0 + \cdots + a_{i-1}$（取模后），则 $a_i$ 对答案的贡献是 $a_i \cdot i - \text{prefix}$。全程取模防溢出。

### 3.4 示例演算

![示例演算：[-2,0,2] RLL d=3 的幻影终态与距离配对](images/bw106_q3_walkthrough.svg)

以示例 1 演算（`nums = [-2,0,2]`，`s = "RLL"`，`d = 3`）：

1. 幻影终态：$-2+3=1$、$0-3=-3$、$2-3=-1$ → 多重集 $\{-3, -1, 1\}$（与真实碰撞世界的 $[-3,-1,1]$ 完全一致）；
2. 排序后配对：$(-1)-(-3)=2$、$1-(-1)=2$、$1-(-3)=4$；
3. 总和 $2+2+4=8$ ✓。系数公式验算：$(-3)(-2) + (-1)(0) + 1(2) = 6+0+2 = 8$ ✓。

## 4. 算法细节

1. **"穿过"不需要真的换标签**：位置多重集相同即可——题目标的就是由位置决定的两两距离和，与身份无关。千万别去模拟"哪两个机器人相撞"，那会把问题复杂化回模拟。
2. **相撞可能发生在非整数时刻**：如示例 3 的 0.5 秒处。穿过模型天然兼容——幻影位置 $x \pm t$ 对任意实数 $t$ 都成立，不需要离散事件。
3. **取模纪律（C++）**：位置可达 $\pm 3 \times 10^9$（$|nums[i]| \le 2 \times 10^9$、$d \le 10^9$），必须 `long long` 存储；两两距离和理论峰值 $\sim 10^{19}$ 超过 `long long` 上界，**必须边累加边取模**。每个位置先归一化到 $[0, MOD)$（负数取模在 C++ 里得到负余数，`((x % MOD) + MOD) % MOD` 修正）。
4. **前缀和版贡献式**：`ans = (ans + x * i % MOD - prefix + MOD) % MOD`，其中 `x` 是归一化后的位置、`prefix` 是此前位置之和（模意义下）。`x * i` 最大约 $10^9 \times 10^5 = 10^{14}$，`long long` 安全。
5. **Python 无溢出**但也要取模（答案要求）；`x % MOD` 在 Python 里天然非负，写法更省心。
6. **`d = 0`**：终态即初始位置，公式自动成立，无需特判。

## 5. 正确性证明

**引理 1（穿过等价）**：把相撞规则改为"穿过"，则任意时刻 $t$，幻影世界的位置多重集与真实世界（撞后掉头）的位置多重集相同。

**证明**：机器人速度大小恒为 1，相撞是唯一改变方向的事件，且碰撞**只发生在相邻两机器人之间**（速度相同者永不相撞、相同速度者间距不变）。对碰撞事件数归纳：无碰撞时两世界显然相同。设前 $k$ 次碰撞后多重集相同，考察第 $k+1$ 次碰撞：相邻机器人 $A$（左，向右）与 $B$（右，向左）在时刻 $t_0$ 相遇于点 $q$。真实世界：$A$ 掉头向左、$B$ 掉头向右；幻影世界：$A$ 继续向右、$B$ 继续向左——两世界此后各自不再有新事件，直到下一个事件。对 $t > t_0$：真实世界里"从 $q$ 出发向左的速度 1 质点"与"从 $q$ 出发向右的速度 1 质点"占据 $q \mp (t - t_0)$；幻影世界里 $A$ 走到 $q + (t - t_0)$、$B$ 走到 $q - (t - t_0)$。**两种世界在 $t$ 时刻都恰有质点位于 $q - (t-t_0)$ 与 $q + (t - t_0)$**（真实世界是掉头后的 $A, B$，幻影世界是穿过去的 $B, A$），多重集一致；两质点之外的部分由归纳假设一致，且这两个质点在碰撞前后均不与第三方在下一事件前相撞（相撞由位置与方向决定，而两世界在相同位置有相同速度方向的质点——真实 $A$ 掉头后位于幻影 $B$ 的位置、方向也与幻影 $B$ 相同，故后续事件序列在多重集意义下同构）。归纳完成。∎

**引理 2（距离和的系数公式）**：对升序数组 $a_0 \le \cdots \le a_{n-1}$，$\displaystyle\sum_{i<j}(a_j - a_i) = \sum_{i=0}^{n-1} a_i \,(2i - n + 1)$。

**证明**：每个 $a_j$ 在含 $j$ 的对中作为较大端出现 $j$ 次（与 $a_0, \dots, a_{j-1}$ 配对），贡献 $+j \cdot a_j$；作为较小端出现 $n - 1 - j$ 次，贡献 $-(n-1-j) \cdot a_j$。合计系数 $j - (n-1-j) = 2j - n + 1$。遍历求和即得。∎

**定理**：算法返回值等于 $d$ 秒后真实世界的两两距离和（模 $10^9+7$）。

**证明**：终态位置多重集由引理 1 等于幻影位置 $\{nums[i] \pm d\}$ 的多重集；两两距离和只依赖该多重集。排序后由引理 2，答案等于 $\sum a_i (2i - n+1)$；代码实现为等价的前缀和形式（逐项 $a_i \cdot i - \text{prefix}_i$ 累加，$\text{prefix}_i = \sum_{k<i} a_k$，与系数式逐项展开一致）。全部运算在模 $10^9+7$ 下进行，同余保持。∎

## 6. 复杂度分析

- **时间**：$O(n \log n)$——排序主导；求和部分单趟 $O(n)$，每步常数次乘加与取模。$n = 10^5$ 毫秒级。
- **空间**：$O(n)$ 存终态位置数组（也可原地修改 `nums` 后排序，省到 $O(1)$ 额外——C++ 排序原地，Python `sorted` 需 $O(n)$）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int sumDistance(vector<int>& nums, string s, int d) {
        const long long MOD = 1e9 + 7;
        int n = nums.size();
        vector<long long> pos(n);
        for (int i = 0; i < n; ++i)
            pos[i] = (long long)nums[i] + (s[i] == 'R' ? d : -d);  // 穿过模型
        sort(pos.begin(), pos.end());
        long long ans = 0, prefix = 0;             // prefix = 已出现的最终位置之和 (mod)
        for (int i = 0; i < n; ++i) {
            long long x = ((pos[i] % MOD) + MOD) % MOD;    // 位置可能为负
            ans = (ans + x * i % MOD - prefix + MOD) % MOD;
            prefix = (prefix + x) % MOD;
        }
        return (int)ans;
    }
};
```

### Python

```python
class Solution:
    def sumDistance(self, nums: List[int], s: str, d: int) -> int:
        MOD = 10 ** 9 + 7
        pos = sorted(x + d if c == 'R' else x - d for x, c in zip(nums, s))  # 穿过模型
        ans = prefix = 0                    # prefix = 已出现的最终位置之和 (mod)
        for i, x in enumerate(pos):
            ans = (ans + x % MOD * i - prefix) % MOD
            prefix = (prefix + x) % MOD
        return ans
```

> 💡 两份代码均通过官方示例（`8`、`5`）与"相向贴脸半秒撞""$d=0$"等边界，并与**独立的连续时间碰撞事件模拟器**（整数化坐标 + 逐事件反弹）对拍 3410 组随机数据（$n \le 9$、$d \le 10$，含连环撞、跨零点），另有 40 组大规模用例（$n = 10^5$、$|x| \le 2 \times 10^9$、$d \le 10^9$）C++/Python 一致性校验，`mismatch = 0`。

## 8. 边界情况与易错点

1. **碰撞发生在非整数时刻**：题面例子（相距 1 相向）已经暗示 0.5 秒撞——只要还想"逐秒模拟"就注定错过，穿过模型是唯一正解。
2. **负数取模（C++）**：`pos[i] % MOD` 为负，直接参与累加会得到负答案；必须 `((x % MOD) + MOD) % MOD`。Python 的 `%` 天然非负。
3. **溢出**：距离和峰值可达 $\binom{10^5}{2} \times 6 \times 10^9 \approx 3 \times 10^{19}$，超 `long long` 上界（约 $9.2 \times 10^{18}$）；**逐项取模**（每步 `% MOD`）是硬要求，绝不能先求和再取模。`x * i` 一项约 $10^{14}$，安全。
4. **`nums[i]` 是 `int` 但 $|nums[i]| \le 2 \times 10^9$ 超 `int` 范围？**——不会：$2 \times 10^9 < 2^{31} \approx 2.147 \times 10^9$，恰在 `int` 内；但 $nums[i] \pm d$ 就超了，必须 `long long` 接住。
5. **机器人两两位置可以相同吗**：初始互不相同保证撞前不重合；穿过模型里终态可以有相同位置（如 $[0, 2]$、`"RL"`、$d=1$ → 都在 1），距离 0 正常计入，无需去重。
6. **别忘题目要"无序对"**：$\sum_{i<j}$ 就是每对一次；若实现成 $\sum_{i \ne j}$ 记得除以 2（模意义下乘逆元），前缀和写法天然避免这个坑。
7. **`d` 用 `int` 读**：$d \le 10^9$ 在 `int` 内；但测试 main 里读取时注意 `nums[i]` 负号解析（负数 token）。
