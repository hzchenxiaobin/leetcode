# LeetCode 判断一个数是否迷人 题解

## 1. 题目概述

- **标题 / 题号**：判断一个数是否迷人（#2729，easy）
- **链接**：https://leetcode.cn/problems/check-if-the-number-is-fascinating/
- **来源**：LeetCode 第 106 场双周赛 Q1
- **难度**：简单
- **标签**：哈希表、数学

**题意**：给定三位数 $n$（$100 \le n \le 999$）。把 $n$、$2n$、$3n$ 三个数**首尾拼接**成一个整数（例如 $192 \| 384 \| 576 \to 192384576$）。若拼接结果**恰好包含数字 $1$ 到 $9$ 各一次、且不含任何 $0$**，则称 $n$ 是**迷人的**。判断 $n$ 是否迷人。

**约束**：

- $100 \le n \le 999$

## 2. 示例

**示例 1**

```text
输入：n = 192
输出：true
解释：192 ‖ 384 ‖ 576 = 192384576，恰好是 1~9 各出现一次、无 0。
```

**示例 2**

```text
输入：n = 100
输出：false
解释：100 ‖ 200 ‖ 300 = 100200300，含 0 且有重复数字。
```

**示例 3（边界补充）**

```text
输入：n = 333
输出：false
解释：333 ‖ 666 ‖ 999 = 333666999，长度虽为 9，但 3/6/9 各出现三次，其余数字缺席。
```

## 3. 解题思路

### 3.1 暴力思路

模拟题面：把三个数转字符串拼起来，逐字符统计每个数字出现次数，最后检查"1~9 各一次、0 出现零次"。这就是正解本身，没有更优的必要——总共 900 个候选 $n$，事实上整个值域的迷人数只有 $192, 219, 273, 327$ 四个（见 §3.4）。

### 3.2 核心观察：拼接串合法 ⟺ 长度为 9 且排序后等于 "123456789"

![核心观察：拼接 192|384|576 后逐位查表，1~9 各一次](images/bw106_q1_concat_check.svg)

合法条件可以压缩成一个等价判定：拼接串 $t$ 合法 $\iff$ $\text{len}(t) = 9$ 且 $\text{sorted}(t) = $ `"123456789"`。

- **长度为 9 不可省略**：$n \ge 100$ 时 $n$、$2n$ 各占 3 位，但 $3n$ 最多可达 $3 \times 999 = 2997$（4 位），拼接可能是 $3+3+4 = 10$ 位（$n \ge 334$ 时必然如此）。位数一错，"各一次"必然不成立。
- **长度为 9 时**：9 个字符排序后恰好是 `123456789`，当且仅当多重集 $\{t$ 的字符$\} = \{1, \dots, 9\}$——既保证每个数字恰一次（无重复），又保证没有 0（0 不在目标串里）。一步比对同时完成"无 0、无重复、全覆盖"三项检查。

### 3.3 算法流程

![算法流程：拼接 → 长度检查 → 排序比对](images/bw106_q1_flow.svg)

```text
1. t = str(n) + str(2n) + str(3n)
2. 若 len(t) != 9：返回 false
3. 把 t 的字符排序
4. 返回 排序结果 == "123456789"
```

### 3.4 示例演算

![示例演算：192 通过、100 失败](images/bw106_q1_walkthrough.svg)

| $n$ | 拼接 | 长度 | 排序后 | 结论 |
|-----|------|------|--------|------|
| 192 | 192384576 | 9 | 123456789 ✓ | true |
| 100 | 100200300 | 9 | 000000123 ✗ | false |
| 334 | 3346681002 | 10 | —（位数错） | false |
| 333 | 333666999 | 9 | 333666999（无 1、2 等，重复超标）✗ | false |

顺带一提，把 $100 \sim 999$ 全跑一遍，迷人的只有 $192, 219, 273, 327$（分别对应 $192{\times}1{,}2{,}3 = 192/384/576$、$219 \to 438/657$、$273 \to 546/819$、$327 \to 654/981$）——这也解释了为何约束把 $n$ 卡在三位数。

## 4. 算法细节

1. **用字符串而非数值拼接**：若用算术拼接 $n \times 10^7 + 2n \times 10^4 + 3n$，$3n$ 为 4 位时会错位（应该乘 $10^4$ 还是 $10^3$ 取决于位数），字符串拼接天然规避进位讨论。
2. **排序比对的正确性**：两串排序后相等 ⟺ 两串互为字符重排（anagram）；`"123456789"` 自身无重复字符，故"重排到它"恰好等价于"1~9 各一次"。
3. **等价写法**：也可用 `seen[10]` 计数数组逐字符标记，遇 0 或重复即返回 false，最后查 $seen[1..9]$ 全为 1；两种写法等价，排序版更短。
4. **`2 * n`、`3 * n` 的类型**：C++ 中 `3 * n` 最大 2997，`int` 无压力；Python 无溢出问题。
5. **值域提醒**：$n \le 333$ 时 $3n \le 999$ 仍为三位数，拼接恰 9 位；$n \ge 334$ 时拼接必为 10 位，可提前 false——但排序前的长度检查已覆盖，无需分支。

## 5. 正确性证明

**引理 1（重排等价）**：两个等长字符串 $u, v$ 满足 $\text{sorted}(u) = \text{sorted}(v)$，当且仅当 $v$ 中每个字符的出现次数与 $u$ 中相同。

**证明**：排序后相等即逐位置相同；对每个字符 $c$，排序将 $u$ 中全部 $c$ 连续排列，其在排序结果中的区段长度即出现次数，两串排序结果逐位相同故各区段一致，次数相同。反之次数相同则排序结果显然相同。∎

**定理**：算法返回 true 当且仅当拼接串 $t$ 恰含数字 $1$ 到 $9$ 各一次且不含 $0$。

**证明**：设 $t$ 合法。$t$ 由 9 个数字字符组成（各出现一次），故 $\text{len}(t) = 9$；把 $t$ 的字符按字典序重排，9 个互不相同的非零数字的升序排列恰为 `"123456789"`，由引理 1（反向）$\text{sorted}(t) = $ `"123456789"`。反之设 $\text{len}(t) = 9$ 且 $\text{sorted}(t) = $ `"123456789"`：由引理 1，$t$ 中每个字符出现次数与目标串一致，即 $1 \sim 9$ 各一次、$0$ 零次，且总长 $9$ 与之相容。两方向合并即得。∎

## 6. 复杂度分析

- **时间**：$O(1)$——拼接至多 11 个字符，排序常数开销；或按值域说法 $O(\log n)$。
- **空间**：$O(1)$，一个不超过 11 字节的临时串。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool isFascinating(int n) {
        string t = to_string(n) + to_string(2 * n) + to_string(3 * n);
        if (t.size() != 9) return false;          // 拼接可能超过 9 位
        sort(t.begin(), t.end());
        return t == "123456789";
    }
};
```

### Python

```python
class Solution:
    def isFascinating(self, n: int) -> bool:
        t = f"{n}{2 * n}{3 * n}"
        return len(t) == 9 and sorted(t) == list("123456789")
```

> 💡 两份代码均通过官方示例（`true`、`false`），并对 $100 \sim 999$ 全量 900 个值与"逐字符 seen 数组"独立判定法三方互查（C++/Python/独立实现完全一致），迷人数集合恰为 $\{192, 219, 273, 327\}$，与数学常识锚点吻合，`mismatch = 0`。

## 8. 边界情况与易错点

1. **漏掉长度检查是最大陷阱**：$n \ge 334$ 时拼接是 10 位，如果只查"1~9 各一次、无 0"而忘了长度，10 位串必然有重复（鸽笼），排序比对会**碰巧**返回 false——真正会错的是"计数只查到前 9 个字符"之类的实现。稳妥起见显式判 `len(t) == 9`。
2. **`sorted` 与字符串比较的配合**：Python 中 `sorted(t)` 是字符列表，要与 `list("123456789")` 比较；与字符串 `"123456789"` 直接比较恒为 false（类型不同）。C++ 版对 `string` 排序后与字符串字面量比较即可。
3. **别用数值拼接**：$n \times 10^6 + 2n \times 10^3 + 3n$ 在 $3n$ 为四位数时把 4 位数挤错位，得出 $192 \times 10^6 + 384 \times 10^3 + 576$ 之类看似对、实则对 4 位 $3n$ 全错的式子。
4. **"恰好各一次"不是"都出现"**：`333666999` 九位、无 0，但 3 出现三次——计数语义必须精确到"各一次"，排序比对天然满足。
5. **约束就是三位数**：不需要防御 $n < 100$ 或 $n > 999$ 的输入。
