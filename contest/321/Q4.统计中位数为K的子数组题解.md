# LeetCode 统计中位数为K的子数组 题解

## 1. 题目概述

- **标题 / 题号**：统计中位数为K的子数组（#2488，hard）
- **链接**：https://leetcode.cn/problems/count-subarrays-with-median-k/
- **来源**：LeetCode 第 321 场周赛 Q4
- **难度**：困难
- **标签**：数组、哈希表、前缀和

**题意**：给定长度为 $n$ 的数组 `nums`，它是 $1$ 到 $n$ 的**互不相同**整数的一个排列，再给定正整数 $k$。统计 `nums` 中**中位数等于 $k$** 的非空连续子数组的数目。中位数定义：子数组按**递增**排序后位于中间的元素；长度为偶数时取**中间靠左**的那个（即 0 下标处的 $\lfloor (L-1)/2 \rfloor$ 位）。

**约束**：

- $1 \le n \le 10^5$
- $1 \le \text{nums}[i],\ k \le n$
- `nums` 中整数互不相同

> 💡 读题抓三个信号：①「$1$ 到 $n$ 的排列、互不相同」——任意元素与 $k$ 的关系只有 $>k$、$<k$、$=k$ 三种，天然适合 $\pm1/0$ 变换；②「中位数」是**序统计量**——排序后的位置只由「比 $k$ 小 / 大的**个数**」决定，与具体数值无关，判定可以压成一个计数差；③ 偶数长度取**靠左**中位——本题最大的坑，它直接决定目标集合是 $\{0,1\}$ 还是 $\{-1,0\}$，动手写代码前必须先在纸上推清楚。

## 2. 示例

**示例 1**

```text
输入：nums = [3,2,1,4,5], k = 4
输出：3
解释：中位数等于 4 的子数组有：[4]、[4,5] 和 [1,4,5]。
      注意 [1,4] 的中位数是 1（偶长取靠左），[3,2,1,4,5] 的中位数是 1，都不算。
```

**示例 2**

```text
输入：nums = [2,3,1], k = 3
输出：1
解释：[3] 是唯一中位数等于 3 的子数组；[2,3] 中位数是 2，[3,1] 中位数是 1。
```

**补充示例 3**

```text
输入：nums = [2,1,3,5,4], k = 3
输出：5
解释：[3]、[3,5]、[1,3,5]、[1,3,5,4]（偶长 4，排序 [1,3,4,5]，靠左中位是 3）、
      [2,1,3,5,4] 共 5 个。偶、奇长度同时命中，适合自测。
```

## 3. 解题思路

### 3.1 暴力思路：枚举子数组 + 排序，$O(n^2 \log n)$ 超时

最朴素的做法：枚举全部 $O(n^2)$ 个子数组 $[l, r]$，各自排序后取下标 $\lfloor (L-1)/2 \rfloor$ 判断是否为 $k$，总复杂度 $O(n^3 \log n)$；即使固定 $l$ 向右扩 $r$、增量维护「比 $k$ 小 / 大的个数」把每个子数组的判定压到 $O(1)$，也仍是 $O(n^2)$。$n = 10^5$ 时 $O(n^2) = 10^{10}$，必然超时。

暴力暴露的关键事实是：**中位数是否等于 $k$，只取决于子数组内比 $k$ 小的个数 $a$ 与比 $k$ 大的个数 $b$ 的相对关系**，与这些元素的具体取值无关。既然判定只依赖两个计数，就有希望把它压成一个可增量、可哈希的量。

### 3.2 核心观察：中位数 $=k$ ⟺ 变换和 $\in \{0,1\}$

![核心观察：奇数长度 d=0，偶数长度（靠左中位）d=1](images/wc321_q4_median_condition.svg)

**观察一（必须包含 $k$）**：中位数是子数组排序后的**某个元素本身**，而值互不相同，所以中位数 $=k$ 强制 $k$ 出现在子数组里。于是先定位 $k$ 的下标 $p$，所有候选子数组都被 $p$ 切成三段：**左段 $[l, p-1]$（可为空）+ $k$ + 右段 $[p+1, r]$（可为空）**，问题变成左右两段的**组合计数**。

**观察二（判定只看计数差）**：设子数组长 $L$，比 $k$ 小的有 $a$ 个、大的有 $b$ 个，则 $L = a+b+1$。排序后 $k$ 恰好落在下标 $a$（前面有 $a$ 个更小的），而中位数在下标 $\lfloor (L-1)/2 \rfloor$，故

$$
a = \Big\lfloor \frac{L-1}{2} \Big\rfloor = \Big\lfloor \frac{a+b}{2} \Big\rfloor
$$

分奇偶解出（$m$ 为非负整数）：

| $L$（含 $k$） | $a+b = L-1$ | 要求 $a$ | 解得 $b$ | $d = b - a$ |
|------|------|------|------|------|
| 奇 $2m+1$ | $2m$ | $a = m$ | $b = m$ | $0$ |
| 偶 $2m$ | $2m-1$ | $a = m-1$ | $b = m$ | $1$ |

> ⚠️ 偶数长度取**靠左**中位，所以是「大数多一个」即 $d=+1$；若取靠右中位则反转为 $\{-1, 0\}$。这里的符号方向是本题最经典的 WA 点。

**观察三（把 $d$ 写成子数组和）**：做变换

$$
\text{val}(x) = \begin{cases} +1, & x > k \\ \phantom{+}0, & x = k \\ -1, & x < k \end{cases}
$$

则含 $k$ 的子数组变换和 $= b \cdot (+1) + a \cdot (-1) + 0 = b - a = d$。合并三个观察：

$$
\boxed{\ \text{中位数} = k \iff \text{子数组含 } k \text{ 且变换和 } d \in \{0,\ 1\}\ }
$$

### 3.3 算法流程：锚点切两段，左建哈希、右枚举查表

![算法流程：以 pos 为锚，左段平衡入哈希，右段平衡查表配对](images/wc321_q4_hash_count.svg)

子数组被 $p$ 切成独立两段后，$d = \text{bal}_L + \text{bal}_R$，其中 $\text{bal}_L$、$\text{bal}_R$ 分别是左、右段的变换和（$k$ 贡献 $0$，不进任何一边）。条件 $d \in \{0,1\}$ 即

$$
\text{bal}_L \in \{-\text{bal}_R,\ 1 - \text{bal}_R\}
$$

于是标准的前缀和 + 哈希配对登场：

1. **定位**：$p \leftarrow$ `nums.index(k)`；
2. **左扫建表**：`cnt[0] = 1`（空左段），$i$ 从 $p-1$ 向左到 $0$，每步 $\text{bal} \mathrel{+}= \text{val}(i)$，`cnt[bal]++`；
3. **右扫查表**：$\text{rb} = 0$（空右段），$j$ 从 $p$ 向右到 $n-1$；$j > p$ 时 $\text{rb} \mathrel{+}= \text{val}(j)$，然后
   $$\text{ans} \mathrel{+}= \text{cnt}[-\text{rb}] + \text{cnt}[1 - \text{rb}]$$
4. 返回 `ans`。

每一对（左段, 右段）唯一确定一个子数组，左段建表、右段查询，每组组合恰好被统计一次，不重不漏。

### 3.4 示例演算

![示例演算：左表 4 项，右扫 2 步，共 3 个子数组](images/wc321_q4_walkthrough.svg)

以示例 1 `nums = [3,2,1,4,5], k = 4` 演算：$p = 3$，变换数组为 $[-1, -1, -1, 0, +1]$。

**左扫建表**（从 $p-1 = 2$ 向左）：

| 左段 | 元素 | $\text{bal}_L$ | `cnt` |
|------|------|------|------|
| 空（$l = p$） | — | $0$ | $\{0:1\}$ |
| $[2]$ | $1 \to -1$ | $-1$ | $\{0:1,\ -1:1\}$ |
| $[1,2]$ | $2 \to -1$ | $-2$ | $\{0:1,\ -1:1,\ -2:1\}$ |
| $[0,1,2]$ | $3 \to -1$ | $-3$ | $\{0:1,\ -1:1,\ -2:1,\ -3:1\}$ |

**右扫查表**（从 $p = 3$ 向右）：

| 右段 | $\text{bal}_R$ | 查 $\{-\text{bal}_R,\ 1-\text{bal}_R\}$ | 贡献 | 命中子数组 |
|------|------|------|------|------|
| 空（$r = p$） | $0$ | $\{0, 1\} \to 1 + 0$ | $1$ | $[4]$ |
| $[5]$ | $+1$ | $\{-1, 0\} \to 1 + 1$ | $2$ | $[1,4,5]$、$[4,5]$ |

合计 $1 + 2 = 3$，与示例一致。**补充示例 3** 可同理走查出 $5$ 个，建议作为自测用例。

## 4. 算法细节

1. **返回类型是 `long long`**：含 $p$ 的子数组至多 $(p+1)(n-p) \le \left\lceil \frac{n+1}{2} \right\rceil^2 \approx 2.5 \times 10^9$ 个，超过 `int32` 上界，C++ 必须用 `long long`（本题函数签名就是 `long long`），Python 天然无碍。
2. **`cnt[0] = 1` 的含义是空左段**：对应所有左端点 $l = p$ 的子数组（包括 $[k]$ 自身）。漏掉这一项会系统性少算一整类答案。
3. **右侧循环从 $j = p$ 开始且该步不更新 $\text{rb}$**：$j = p$ 对应空右段、$\text{bal}_R = 0$；也可以统一写成「先查询、后累加」的形式，语义相同。
4. **键域是 $[-n, n]$**：左段和的绝对值不超过段长，可用长度 $2n+1$ 的数组加偏移 $n$ 替代 `unordered_map`，消除哈希常数，比赛中是更稳的写法。
5. **与前缀和标准写法等价**：令 $P$ 为变换数组的空前缀和，条件即 $l \le p \le r$ 且 $P[r+1] - P[l] \in \{0,1\}$；把 $l \in [0, p]$ 的 $P[l]$ 建表、枚举 $r \ge p$ 查 $P[r+1]$ 与 $P[r+1]-1$，与锚点分解完全等价——锚点视角只是把「跨 $p$ 配对」看得更清楚。
6. **为什么不能滑动窗口**：变换和可负、随窗口扩张不单调，窗口没有单调收缩的依据；「值域小 + 求配对个数」正是哈希计数的招牌场景（对照 560 题）。

## 5. 正确性证明

**引理 1（包含性）**：中位数等于 $k$ 的子数组必包含下标 $p$（$k$ 的位置）。

**证明**：中位数是子数组排序后位于下标 $\lfloor (L-1)/2 \rfloor$ 处的**元素本身**。若该元素值为 $k$，则 $k$ 属于子数组；又 `nums` 元素互不相同，$k$ 在全数组中仅出现于 $p$，故子数组包含 $p$。∎

**引理 2（平衡条件）**：设含 $p$ 的子数组中比 $k$ 小、大的元素个数分别为 $a, b$，则其中位数等于 $k$ 当且仅当 $b - a \in \{0, 1\}$。

**证明**：子数组长 $L = a + b + 1$。排序后，前 $a$ 个均小于 $k$、接着是 $k$（下标 $a$）、后 $b$ 个均大于 $k$，故中位数等于 $k$ 等价于 $a = \lfloor (L-1)/2 \rfloor = \lfloor (a+b)/2 \rfloor$。

（⇒）由 $a \le \frac{a+b}{2} < a + 1$ 得 $2a \le a + b < 2a + 2$，即 $a \le b \le a+1$，故 $b - a \in \{0, 1\}$。

（⇐）若 $b = a$：$L = 2a+1$ 为奇，$\lfloor (L-1)/2 \rfloor = a$ 成立；若 $b = a + 1$：$L = 2a+2$ 为偶，$\lfloor (L-1)/2 \rfloor = \lfloor (2a+1)/2 \rfloor = a$ 成立。两种情况中位数均为 $k$。∎

**引理 3（和刻画）**：含 $p$ 的子数组在 $\pm1/0$ 变换下的和恰为 $b - a$。

**证明**：子数组由 $a$ 个 $-1$、$b$ 个 $+1$ 和一个 $0$（$k$ 自身）组成，求和即 $b - a$。∎

**引理 4（计数不重不漏）**：左段集合 $\{[l, p-1] : 0 \le l \le p\}$（含空段）与右段集合 $\{[p+1, r] : p \le r \le n-1\}$（含空段）的笛卡尔积，与「包含 $p$ 的子数组」一一对应；且每对的变换和 $d = \text{bal}_L + \text{bal}_R$。

**证明**：包含 $p$ 的子数组 $[l, r]$（$l \le p \le r$）由二元组 $(l, r)$ 唯一刻画，其左段 $[l, p-1]$（$l = p$ 时为空）与右段 $[p+1, r]$（$r = p$ 时为空）由 $l, r$ 唯一确定，反之任一（左段, 右段）组合拼上 $k$ 即得唯一的 $[l, r]$。变换和按段可加，$k$ 贡献 $0$，故 $d = \text{bal}_L + \text{bal}_R$。∎

**定理（算法正确性）**：算法返回中位数等于 $k$ 的子数组个数。

**证明**：由引理 1，只需统计含 $p$ 的子数组。由引理 4，对其做（左段, 右段）组合分解，每组恰对应一个子数组且 $d = \text{bal}_L + \text{bal}_R$。算法中 `cnt` 恰好记录所有左段的 $\text{bal}_L$ 频次（含空段 $0$，因为初始化 `cnt[0]=1`）；右扫枚举每个右段（含空段，$j = p$ 时 $\text{rb} = 0$），累加满足 $\text{bal}_L \in \{-\text{rb}, 1-\text{rb}\}$ 的左段个数，即 $d \in \{0, 1\}$ 的组合数。由引理 2 与引理 3，这些组合恰是中位数等于 $k$ 的子数组，且每组被统计一次。∎

> 💡 **一句话**：中位数 $=k$ 的判定被压缩成「含 $k$ 且 $\pm1/0$ 变换和 $\in \{0,1\}$」，锚点把子数组切成独立左右两段后，就是一道「两段和配对」的前缀和哈希计数题。

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。定位 $p$ 一趟 $O(n)$；左扫建表一趟，每步 $O(1)$；右扫查表一趟，每步 $O(1)$（偏移数组版是真 $O(1)$，`unordered_map` 版均摊 $O(1)$）。
- **空间复杂度**：$O(n)$。`cnt` 至多存 $p + 1 \le n$ 个不同的平衡值；偏移数组版固定开 $2n+1$。
- **对照**：暴力排序 $O(n^3 \log n)$；增量计数暴力 $O(n^2) = 10^{10}$，均不可行；本题 $n = 10^5$ 期望线性解。

## 7. 参考代码

### C++（偏移数组版：$O(n)$ 时间，无哈希常数，推荐）

```cpp
class Solution {
public:
    long long countSubarrays(vector<int>& nums, int k) {
        int n = nums.size();
        int pos = find(nums.begin(), nums.end(), k) - nums.begin();

        vector<int> cnt(2 * n + 1, 0);        // 键域 [-n, n]，偏移 n
        ++cnt[n];                             // 空左段：bal_L = 0
        int bal = 0;
        for (int i = pos - 1; i >= 0; --i) {  // 左扫建表
            bal += nums[i] > k ? 1 : -1;
            ++cnt[bal + n];
        }

        long long ans = 0;
        int rb = 0;
        for (int j = pos; j < n; ++j) {       // 右扫查表
            if (j > pos) rb += nums[j] > k ? 1 : -1;
            ans += cnt[n - rb] + cnt[n + 1 - rb];  // bal_L ∈ {-rb, 1-rb}
        }
        return ans;
    }
};
```

### C++（unordered_map 版）

```cpp
class Solution {
public:
    long long countSubarrays(vector<int>& nums, int k) {
        int n = nums.size();
        int pos = find(nums.begin(), nums.end(), k) - nums.begin();

        unordered_map<int, int> cnt;
        cnt.reserve(2 * n);
        cnt[0] = 1;                           // 空左段
        int bal = 0;
        for (int i = pos - 1; i >= 0; --i) {
            bal += nums[i] > k ? 1 : -1;
            ++cnt[bal];
        }

        long long ans = 0;
        int rb = 0;
        for (int j = pos; j < n; ++j) {
            if (j > pos) rb += nums[j] > k ? 1 : -1;
            ans += (long long)cnt[-rb] + cnt[1 - rb];  // 不存在的键取 0
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def countSubarrays(self, nums: List[int], k: int) -> int:
        pos = nums.index(k)
        cnt = Counter({0: 1})                 # 空左段：bal_L = 0
        bal = 0
        for i in range(pos - 1, -1, -1):      # 左扫建表
            bal += 1 if nums[i] > k else -1
            cnt[bal] += 1

        ans = 0
        rb = 0
        for j in range(pos, len(nums)):       # 右扫查表
            if j > pos:
                rb += 1 if nums[j] > k else -1
            ans += cnt[-rb] + cnt[1 - rb]     # bal_L ∈ {-rb, 1-rb}
        return ans
```

## 8. 边界情况与易错点

1. **偶数长度取靠左中位 ⇒ 目标集合是 $\{0, 1\}$**：粗心写成只判 $d = 0$ 会漏掉所有合法的偶长度子数组（如补充示例 3 的 $[1,3,5,4]$）；把方向记反成 $\{-1, 0\}$ 则对应「靠右中位」的平行题，同样 WA。建议比赛时用长度 2、4 的小数组手推一遍再写。
2. **答案溢出 `int`**：上限约 $2.5 \times 10^9$，C++ 用 `long long` 累加；`unordered_map` 版里 `cnt[-rb] + cnt[1-rb]` 相加也要先转 `long long` 再加进 `ans`。
3. **空左段 `cnt[0] = 1` 别漏**：它对应 $l = p$ 的整类子数组，漏掉则示例 2 这种 $k$ 在中间的 case 都会少算。
4. **$j = pos$ 时右侧平衡是 $0$**：$k$ 自身贡献 $0$，不进右段和；若把 $k$ 也累加进 $\pm1$ 就全错了。
5. **枚举范围必须是 $l \le p \le r$**：左右两段各自独立于 $p$ 的两侧，哈希表里只放左段、查询只发生在右段，不要把全数组的前缀和混进来跨 $p$ 乱配。
6. **变换符号方向**：$>k$ 记 $+1$、$<k$ 记 $-1$（「大」为正）；写反会让答案变成对称错的另一组数。
7. **`unordered_map` 的 `operator[]` 会插入不存在的键**：本题值为 $0$ 无害，但介意内存峰值可换 `find` 或偏移数组版。
8. **单元素子数组 $[k]$**：左空右空，$d = 0$ 合法，算法天然计入，无需特判。
