# LeetCode 将数组分成三个子数组的方案数 题解

## 1. 题目概述

- **标题 / 题号**：将数组分成三个子数组的方案数（#1712，medium）
- **链接**：https://leetcode.cn/problems/ways-to-split-array-into-three-subarrays/
- **来源**：LeetCode 第 222 场周赛 Q3
- **难度**：中等
- **标签**：数组、前缀和、二分查找、双指针

**题意**：称一种分割方案是**好的**，当它满足：数组被从左至右分成三个**非空**连续子数组 `left`、`mid`、`right`，且 `left` 的元素和 $\le$ `mid` 的元素和、`mid` 的元素和 $\le$ `right` 的元素和。给定一个**非负**整数数组 `nums`，返回好的分割方案总数，结果对 $10^9 + 7$ 取余。

**约束**：

- $3 \le \text{nums.length} \le 10^5$
- $0 \le \text{nums[i]} \le 10^4$

> 💡 读题关键：**元素非负** ⇒ 前缀和**单调不减**。这是把两个「和的不等式」压缩成前缀和数组上「一段连续下标」、再用二分/双指针一减计数的根基——若允许负数，整套结构崩塌（§5 引理 1 正是围绕它展开，延伸思考给出负数版做法）。

## 2. 示例

**示例 1**

```text
输入：nums = [1,1,1]
输出：1
解释：唯一的好分割是 [1] [1] [1]，三段和 1 ≤ 1 ≤ 1。
```

**示例 2**

```text
输入：nums = [1,2,2,2,5,0]
输出：3
解释：3 种好分割：
  [1]   [2]   [2,2,5,0]    和 1 ≤ 2 ≤ 9
  [1]   [2,2] [2,5,0]      和 1 ≤ 4 ≤ 7
  [1,2] [2,2] [5,0]        和 3 ≤ 4 ≤ 5
```

**示例 3**

```text
输入：nums = [3,2,1]
输出：0
解释：n = 3 只有唯一切法 [3] [2] [1]，三段和 3、2、1 不满足 3 ≤ 2。
```

## 3. 解题思路

### 3.1 暴力思路：枚举两个切点

用 $(i, j)$ 表示切点：`left = nums[0..i-1]`、`mid = nums[i..j-1]`、`right = nums[j..n-1]`。三段非空等价于 $1 \le i < j \le n-1$。暴力枚举全部 $(i, j)$，用前缀和 $O(1)$ 取三段和判断，时间 $O(n^2)$；切点对共 $\binom{n-1}{2} \approx 5 \times 10^9$ 个（$n = 10^5$），**超时**。

但暴力暴露了关键结构：对**固定的 $i$**，合法的 $j$ 不是散点，而是**扎堆成一段连续区间**——这正是优化入口。

### 3.2 核心观察：固定 i，合法 j 是前缀和上的连续区间

![核心观察：两个不等式转化为前缀和数组上的连续合法区间](images/wc222_q3_prefix_bounds_concept.svg)

记 $P[0] = 0$、$P[k] = \text{nums}[0] + \cdots + \text{nums}[k-1]$（长度 $n+1$），则：

$$\text{leftSum} = P[i],\quad \text{midSum} = P[j] - P[i],\quad \text{rightSum} = P[n] - P[j]$$

把两个不等式代入，$j$ 的合法性**只取决于 $P[j]$ 落在哪个值域**：

| 不等式 | 代入前缀和 | 等价形式 |
|--------|-----------|---------|
| leftSum $\le$ midSum | $P[i] \le P[j] - P[i]$ | $P[j] \ge 2\,P[i]$（下界） |
| midSum $\le$ rightSum | $P[j] - P[i] \le P[n] - P[j]$ | $2\,P[j] \le P[n] + P[i]$，即 $P[j] \le \lfloor (P[n]+P[i])/2 \rfloor$（上界） |

> 💡 由于 `nums` 非负，$P$ **单调不减**：满足下界的 $j$ 构成一个**后缀**，满足上界的 $j$ 构成一个**前缀**，交集是**连续区间** $[\text{lo}, \text{hi})$。本行方案数一减即得 $\text{hi} - \text{lo}$，完全不必逐个 $j$ 判断。

其中 $\text{lo}$ 是 $[i+1, n)$ 中首个 $P[j] \ge 2P[i]$ 的下标，$\text{hi}$ 是 $[\text{lo}, n)$ 中首个 $2P[j] > P[n] + P[i]$ 的下标（注意 $\text{hi}$ 是**首个不合法**位置，区间右端点开区间）。

### 3.3 算法流程：每行定界，二分或双指针

![算法流程：枚举 i，定出合法区间 [lo, hi) 后累加 hi−lo](images/wc222_q3_algorithm_flow.svg)

定位 lo 与 hi 有两种等价写法：

1. **二分**（$O(n \log n)$，赛时最稳）：`lo` 用 `lower_bound(P, i+1, n, 2*P[i])`，`hi` 用 `upper_bound(P, lo, n, (total+P[i])/2)`；
2. **双指针**（$O(n)$，复盘优化）：$i$ 递增时 $2P[i]$ 与 $(P[n]+P[i])/2$ **同步变大**，故 lo、hi 都**只右移不回退**，可跨轮复用，总移动量 $2n$。

### 3.4 示例演算

![示例演算：[1,2,2,2,5,0] 四轮定界共得 3](images/wc222_q3_walkthrough.svg)

以示例 2 走查，$P = [0,1,3,5,7,12,12]$、total $= 12$：

| $i$ | leftSum | 下界 $2P[i]$ | 上界 $\lfloor(12+P[i])/2\rfloor$ | lo | hi | 合法 $j$ | 贡献 |
|-----|---------|--------------|----------------------------------|-----|-----|----------|------|
| 1 | 1 | 2 | 6 | 2 | 4 | $[2,3]$ | 2 |
| 2 | 3 | 6 | 7 | 4 | 5 | $[4,4]$ | 1 |
| 3 | 5 | 10 | 8 | 5 | 5 | $\varnothing$ | 0 |
| 4 | 7 | 14 | 9 | 6 | 6 | $\varnothing$ | 0 |

合计 $2 + 1 + 0 + 0 = 3$ ✓——注意 $i = 3$ 行「下界 10 > 上界 8」是区间为空的自然形态（lo = hi），无需特判。

**示例 1 / 3 快验**：

- `[1,1,1]`：$P = [0,1,2,3]$。$i=1$：下界 $2$、上界 $2$，$P[2] = 2$ 恰好取等 → 合法 $j = [2,2]$，答案 $1$ ✓。
- `[3,2,1]`：$P = [0,3,5,6]$。$i=1$：下界 $6$，唯一候选 $j=2$ 处 $P[2] = 5 < 6$ → lo 推到 $n$，答案 $0$ ✓。

## 4. 算法细节

1. **下标约定**：$P$ 长 $n+1$；$(i, j)$ 表示「left 含前 $i$ 个元素、left+mid 含前 $j$ 个元素」。三段非空 $\Leftrightarrow$ $1 \le i < j \le n-1$，二分/指针的搜索范围 $[i+1, n)$ 一次性编码了全部边界。
2. **上界的整数化**：$2P[j] \le P[n] + P[i]$ 中所有量都是整数，等价于 $P[j] \le \lfloor (P[n]+P[i])/2 \rfloor$。C++/Python 对非负整数的除法自动向下取整，直接写 `(total + P[i]) / 2` 即可。
3. **二分版**（先保证正确）：
   - `lo = lower_bound(P, i+1, n, 2*P[i])`：首个满足下界者；
   - `hi = upper_bound(P, lo, n, (total+P[i])/2)`：首个越过上界者；
   - 贡献 $\max(0, \text{hi} - \text{lo})$（hi ≥ lo 恒成立，取正即可）。两次二分都只在合法活动范围 $[i+1, n)$ 内搜，天然不会把 mid / right 切空。
4. **双指针版**（$O(n)$ 优化）：lo、hi 初始化为 1、随 $i$ 跨轮复用；每轮先 `lo = max(lo, i+1)`、`hi = max(hi, lo)` 回拨，再分别推进到各自阈值。两句 `max` 是跨轮复用不出错的保险（§8.5）。
5. **取模**：单行贡献至多 $n - 2 < 10^5$，累计最坏 $\binom{n-1}{2} \approx 5 \times 10^9 > 2^{31}$，C++ 在累加处对 $10^9 + 7$ 取模即可（加法封闭，逐行取模与最后取模同余）。

## 5. 正确性证明

**引理 1（区间性）**：设 `nums` 非负、$P$ 为其前缀和，则 $P$ 单调不减；且对任意固定 $i$，集合 $S_i = \{\, j : i < j < n,\ P[j] \ge 2P[i],\ 2P[j] \le P[n] + P[i] \,\}$ 是连续区间 $[\text{lo}_i, \text{hi}_i)$。

**证明**：非负 ⇒ $P[k+1] = P[k] + \text{nums}[k] \ge P[k]$，故 $P$ 单调不减。若 $j$ 满足下界且 $j < j'$，则 $P[j'] \ge P[j] \ge 2P[i]$，满足下界者构成**后缀**；若 $j$ 满足上界且 $j' < j$，则 $2P[j'] \le 2P[j] \le P[n]+P[i]$，满足上界者构成**前缀**。后缀与前缀的交集是连续区间，取 lo 为后缀起点（限制在 $[i+1, n)$ 内）、hi 为前缀终点之后的首位即得。∎

**引理 2（指针单调性）**：若 $i < i'$，则 $\text{lo}_i \le \text{lo}_{i'}$ 且 $\text{hi}_i \le \text{hi}_{i'}$。

**证明**：$P$ 单调不减 ⇒ $2P[i'] \ge 2P[i]$ 且 $\lfloor(P[n]+P[i'])/2\rfloor \ge \lfloor(P[n]+P[i])/2\rfloor$，即两个阈值同时升高。「首个满足下界者」与「首个越过上界者」在阈值升高时都只可能右移（否则新位置左侧仍留有满足旧阈值者，与「首个」矛盾）。∎

**定理（计数正确性）**：算法输出 = 好分割数 $\bmod\ (10^9+7)$。

**证明**：切点对 $(i, j)$（$1 \le i < j \le n-1$）与三段非空的划分**一一对应**（划分决定切点，切点决定划分），故

$$\text{好分割数} \;=\; \sum_{i=1}^{n-2} \left| S_i \right| \;=\; \sum_{i=1}^{n-2} \left( \text{hi}_i - \text{lo}_i \right).$$

由引理 1，二分版中 `lower_bound` 恰定位 $\text{lo}_i$、`upper_bound` 恰定位 $\text{hi}_i$，逐行累加即得；由引理 2，双指针版跨轮复用与每轮独立计算结果一致，且总移动量 $\le 2n$。两种写法都逐行取模，由取模对加法的封闭性，与对总数取模同余。∎

> 💡 证明重心全在引理 1 的「非负 ⇒ 单调 ⇒ 区间」三段论。一旦题面允许负数，$S_i$ 不再是区间，计数就得换武器（见延伸思考）。

## 6. 复杂度分析

- **时间复杂度**：
  - 二分版 $O(n \log n)$：外层 $n - 2$ 轮，每轮两次二分各 $O(\log n)$；$n = 10^5$ 时约 $2 \times 10^5 \times 17 \approx 3.4 \times 10^6$ 次比较，轻松通过；
  - 双指针版 $O(n)$：lo、hi 全程各最多推进 $n$ 步，均摊每轮 $O(1)$，加上预处理前缀和的 $O(n)$。
- **空间复杂度**：$O(n)$，前缀和数组 $P$ 长 $n + 1$。（原地累加可降到 $O(1)$ 额外空间，但会丢失原数组，不推荐。）

## 7. 参考代码

### C++（二分定界，$O(n \log n)$）

```cpp
class Solution {
  public:
    int waysToSplit(vector<int>& nums) {
        const long long MOD = 1e9 + 7;
        int n = nums.size();
        vector<long long> P(n + 1, 0);
        for (int i = 0; i < n; i++) P[i + 1] = P[i] + nums[i];
        long long total = P[n];

        long long ans = 0;
        for (int i = 1; i < n - 1; i++) {
            // lo：[i+1, n) 中首个 P[j] >= 2*P[i]（下界）
            auto lo = lower_bound(P.begin() + i + 1, P.begin() + n, 2 * P[i]);
            // hi：[lo, n) 中首个 P[j] > (total + P[i]) / 2（越过上界）
            auto hi = upper_bound(lo, P.begin() + n, (total + P[i]) / 2);
            ans = (ans + (hi - lo)) % MOD;   // 合法 j ∈ [lo, hi)
        }
        return (int)ans;
    }
};
```

### Python（双指针，$O(n)$）

```python
class Solution:
    def waysToSplit(self, nums: List[int]) -> int:
        MOD = 10 ** 9 + 7
        n = len(nums)
        P = [0] * (n + 1)
        for k in range(n):
            P[k + 1] = P[k] + nums[k]
        total = P[n]

        ans = 0
        lo = hi = 1
        for i in range(1, n - 1):          # left、right 各至少 1 个元素
            if lo < i + 1:                 # mid 非空：j >= i+1
                lo = i + 1
            while lo < n and P[lo] < 2 * P[i]:
                lo += 1                    # 推到首个满足下界
            if hi < lo:                    # 上界起点不能落后于下界
                hi = lo
            while hi < n and 2 * P[hi] <= total + P[i]:
                hi += 1                    # 推到首个越过上界
            ans = (ans + hi - lo) % MOD    # 合法 j ∈ [lo, hi)
        return ans
```

> ⚠️ 两版可以互换语言实现：二分版每轮独立、不易写错，是赛时的稳妥选择；双指针版快一个 $\log$，但依赖跨轮复用的回拨细节。本题 $n \le 10^5$，两版都在时限内。

## 8. 边界情况与易错点

1. **贡献是 hi − lo，不是 hi − lo + 1（头号坑）**：hi 定义为**首个不合法**位置（半开区间右端点）。若把 hi 当成「末个合法位置」再 +1，每个非空行都会多算一个，示例 2 会算出 4 而不是 3。
2. **C++ 必须 `long long`**：$P[k]$ 最大 $10^5 \times 10^4 = 10^9$，`2 * P[i]` 与 `total + P[i]` 都可达 $2 \times 10^9$，超出 `int` 上界 $2{,}147{,}483{,}647$——用 `int` 存前缀和直接溢出。Python 大整数无此问题。
3. **三段非空的下标边界**：$i$ 取 $1 \dots n-2$，$j$ 取 $i+1 \dots n-1$。二分版把范围写成 $[i+1, n)$ 一次编码；手写双指针时漏掉 `lo = max(lo, i+1)` 会把 mid 切空。
4. **上界除法取整**：`(total + P[i]) / 2` 必须向下取整——C++/Python 对非负整数自动如此；若换浮点 `/2.0` 参与比较，既有精度隐患又改变了「整数不等式」的语义。
5. **双指针的 max 回拨**：lo、hi 跨轮复用，当本轮 $i$ 追过指针位置时必须拉回（`lo = max(lo, i+1)`、`hi = max(hi, lo)`），否则用上一轮的旧位置错算区间——双指针版最隐蔽的 WA 点。
6. **全零数组（对拍利器）**：`nums` 全 0 时任何切法都合法，答案 $= \binom{n-1}{2} = \frac{(n-1)(n-2)}{2} \bmod (10^9+7)$（$n = 10^5$ 时约 $5 \times 10^9$，正好检验取模）。
7. **n = 3 最小规模**：只有唯一切法 $(i=1, j=2)$，用 `[1,1,1]`（处处取等）与 `[3,2,1]`（不合法）双方向卡边界。

**延伸思考**：

- **允许负数怎么办**：$P$ 失去单调性后「合法 j 是区间」不再成立。可把条件改写成关于**值**的二维约束：对每个 $j$ 统计满足 $2P[i] \le P[j]$ 且 $P[i] \ge 2P[j] - P[n]$ 的 $i < j$——本质是二维偏序计数，用排序 + 树状数组做到 $O(n \log n)$。单调性只是把「数据结构」简化成了「两个指针」。
- **推广到 k 段**：段数变多后「逐段定界」不再平凡，需 DP：$f(t, i)$ = 前 $i$ 个元素分成合法 $t$ 段的方案数，转移又是一个定界计数（对 $f(t-1, \cdot)$ 的前缀和二分），总复杂度 $O(kn \log n)$。
- **复盘定位**：本题是「**计数型定界**」模板题——见到「切分/配对 + 不等式约束 + 求个数」，先把约束**搬到一个单调数组上**，再用二分/双指针把每行答案压成两个端点相减。赛中先写二分保正确，复盘再升级双指针抢常数。
