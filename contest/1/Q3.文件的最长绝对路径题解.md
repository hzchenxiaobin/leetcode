# LeetCode 文件的最长绝对路径 题解

## 1. 题目概述

- **标题 / 题号**：文件的最长绝对路径（#388，medium）
- **链接**：https://leetcode.cn/problems/longest-absolute-file-path/
- **来源**：LeetCode 第 1 场周赛（Warm-Up Contest） Q3
- **难度**：中等
- **标签**：栈、深度优先搜索、字符串

**题意**：输入 `input` 用 `\n` 把文件系统按「先序遍历」摊平成文本，行首 `\t` 的个数表示该条目的深度（根目录深度为 0）。目录名只含字母、数字、空格；文件名形如 `name.extension`。绝对路径是把从根到该条目的各级名字用 `/` 连接起来的字符串（不含前导 `/`），其**长度**就是字符数。求所有**文件**中最长绝对路径的长度；一个文件都没有则返回 `0`。

**约束**：

- $1 \le \lvert \text{input} \rvert \le 10^4$
- `input` 只含大小写英文字母、`\n`、`\t`、`.`、空格、数字
- 每个目录名由字母、数字、空格组成；每个文件名形如 `name.extension`
- 输入保证合法：深度逐行最多增加 1，文件行下面不会再有更深缩进的行

> 💡 关键点：答案只关心**长度**，不关心路径长什么样。这一点决定了整道题的写法。

## 2. 示例

**示例 1**

```text
输入：input = "dir\n\tsubdir1\n\tsubdir2\n\t\tfile.ext"
输出：20
解释：唯一的文件路径是 "dir/subdir2/file.ext"，长度为 3 + 1 + 7 + 1 + 8 = 20。
```

**示例 2**

```text
输入：input = "dir\n\tsubdir1\n\t\tfile1.ext\n\t\tsubsubdir1\n\tsubdir2\n\t\tsubsubdir2\n\t\t\tfile2.ext"
输出：32
解释：两个文件
      "dir/subdir1/file1.ext"            长度 3+1+7+1+9  = 21
      "dir/subdir2/subsubdir2/file2.ext" 长度 3+1+7+1+10+1+9 = 32
      取较大者 32。
```

**示例 3**

```text
输入：input = "a"
输出：0
解释："a" 是目录，整个文件系统里没有任何文件，返回 0。
```

## 3. 解题思路

### 3.1 暴力思路

最直观的做法是「先把文本还原成树，再对每个文件 DFS 累加长度」：用栈建树需要先确定每行的父亲，而父亲就是「前面最近一个深度小 1 的**目录**行」；建完树再对每个文件节点自底向上累加，总代价 $O(n \cdot d)$（$d$ 为最大深度）。

更朴素的字符串写法还要在每一级祖先上截取子串：对每个文件行向上逐级回溯，每次在 `input` 里再扫一遍找上一级，单行 $O(d)$ 次回溯、每次 $O(n)$ 扫描，最坏 $O(n^2 d)$；即使直接用 `substr` 拼路径，长度累加也只到 $O(n \cdot d)$ 的时间、$O(n \cdot d)$ 的空间。

这些写法在 $n \le 10^4$ 时能过，但都在做**多余的活**：题目只问「最长路径有多长」，而长度可以一边扫描一边累加，根本不需要把路径拼出来，也不需要显式建树。

### 3.2 核心观察：行首制表符数就是深度，深度就是栈的下标

![深度与栈：stack[d] 记录深度 d 目录的绝对路径长度](images/wc1_q3_depth_stack_concept.svg)

三条观察把整道题压成一次线性扫描：

1. **深度可由文本直接读出**：行首 `\t` 的个数就是深度 $d$。格式保证「某条目的父亲 = 它之前最近一个深度为 $d-1$ 的条目」，所以**不需要建树**，按行顺序处理时，深度 $d-1$ 的「最近条目」正好是还没被更深层覆盖掉的那个。
2. **长度可加**：绝对路径长度 $= \sum_{k=0}^{d} \lvert \text{name}_k \rvert + d$，最后一项 $d$ 是分隔符 `/` 的个数。所以只要知道父亲的路径长度，就能 $O(1)$ 得到自己的。
3. **深度天然是栈下标**：维护 `stack[d]` = 深度 $d$ 目录的绝对路径长度。读到深度 $d$ 的行时，把栈弹到长度 $d$，栈顶就是父亲的路径长度。

> 💡 第 1 条是最容易被忽略的：正因为「最近一个浅一层」就是父亲，栈顶弹出后才恰好回到父目录，不会串到别的分支。

### 3.3 算法流程与状态转移

![算法流程：计数、弹栈、算长度、更新答案或入栈](images/wc1_q3_algorithm_flow.svg)

```text
ans = 0, stack = []
for line in input.split('\n'):
    d    = 行首 '\t' 的个数
    name = line[d:]
    while len(stack) > d:  stack.pop()        # 回到父目录
    base = stack[-1] + 1 if stack else 0      # 父路径长度 + 一个 '/'
    cur  = base + len(name)                   # 本条目绝对路径长度
    if '.' in name:  ans = max(ans, cur)      # 文件：只更新答案
    else:            stack.append(cur)        # 目录：作为后续行的潜在父目录
return ans
```

用式子写出来，状态转移就是

$$\text{stack}[d] \;=\; \bigl(\text{stack}[d-1] + 1\bigr) + \lvert \text{name} \rvert,\qquad d \ge 1$$

其中 $d = 0$ 时把「父目录的路径长度」视作 $0$（根目录前面没有东西）。文件行不入栈，只更新

$$\text{ans} \;\leftarrow\; \max\bigl(\text{ans},\; \text{stack}[d-1] + 1 + \lvert \text{name} \rvert\bigr)$$

而不入栈——文件是叶子，不可能成为任何行的父亲。

### 3.4 示例演算

![示例 2 的逐步走查表](images/wc1_q3_walkthrough.svg)

对示例 2 逐行走一遍（`base` 是父目录长度 $+1$）：

| 行 | $d$ | base | cur | 动作 | ans |
|---|---|---|---|---|---|
| `dir` | 0 | 0 | 3 | 目录，`stack=[3]` | 0 |
| `subdir1` | 1 | 4 | 11 | 目录，`stack=[3,11]` | 0 |
| `file1.ext` | 2 | 12 | 21 | 文件，更新答案 | 21 |
| `subsubdir1` | 2 | 12 | 22 | 目录，`stack=[3,11,22]` | 21 |
| `subdir2` | 1 | 4 | 11 | 弹到 $d=1$，`stack=[3,11]` | 21 |
| `subsubdir2` | 2 | 12 | 22 | 目录，`stack=[3,11,22]` | 21 |
| `file2.ext` | 3 | 23 | 32 | 文件，更新答案 | 32 |

第 5 行是关键一步：`subdir2` 的深度从 2 回退到 1，必须把 `subsubdir1` 弹出。若整段漏掉弹栈，`subdir2` 就会把 `subsubdir1` 当父亲（$22+1+7=30$），最终算出 $51$ 而不是 $32$。

再看另外两组样例：示例 1 只有 `file.ext` 一个文件，`cur = (3+1+7)+1+8 = 20`；若三行都在根目录（`"file1.txt\nfile2.txt\nlongfile.txt"`），每行的 `base` 都是 0，答案为最长的 `longfile.txt` 即 12。

## 4. 算法细节

1. **切行方式**：Python 直接 `input.split('\n')`；C++ 用下标扫描 `'\n'`，避免 `stringstream` 的额外拷贝。每行只访问一次，切行总代价 $O(n)$。
2. **数制表符**：`d = len(line) - len(line.lstrip('\t'))` 一行搞定；C++ 手写 `while (i < end && input[i] == '\t')`。制表符只可能出现在行首，不必担心中间混入。
3. **弹栈条件**：`while len(stack) > d`，等价于 `stack = stack[:d]`，但原地 `pop` 不重新分配内存；每个目录最多出栈一次，弹栈总代价摊还 $O(1)$。
4. **`base` 的公式**：`base = stack[-1] + 1 if stack else 0`。注意 $d = 0$ 时栈**必然**已被弹空，所以用「栈是否为空」判断根目录与用 $d=0$ 判断等价；写成 `stack[d-1]` 会在 $d=0$ 时越界（Python 的 $-1$ 索引甚至静默取到错误值）。
5. **文件判定**：题面保证目录名只含字母/数字/空格，文件名必含 `.`，所以 `'.' in name` 是安全的判别。不要用 `name.endswith(".ext")`，扩展名长度不限；也不要判断「是否以字母开头」，因为文件名本身也可能含空格。
6. **长度用字符数**：`len(name)` 在本题纯 ASCII 场景下就是字符数与字节数，Python 的码点长度也不会出错；空格名（如 `"a b"`）长度 3，千万不要 `trim`。
7. **不构造子串**：`line[d:]` 只是为了让代码短；追求常数可以把名字长度直接算成 `len(line) - d`，全程零切片、零字符串拼接。
8. **答案初值**：`ans = 0`，因为「没有文件」时答案就是 0，无需特判返回。

## 5. 正确性证明

固定一份合法的输入。称某行若含 `.` 为**文件行**，否则为**目录行**；记第 $i$ 行的深度为 $d_i$，名字为 $N_i$，第 $i$ 行在深度 $k$ 的**祖先**（$k \le d_i$）为它上面最近的一个深度 $k$ 的目录行。

**格式事实**：对任意 $i$ 与 $k < d_i$，第 $i$ 行深度 $k$ 的祖先，就是第 $i$ 行之前最近出现的深度 $k$ 的目录行。这是输入格式（先序遍历 + 行首制表符）本身给出的结论。

**引理 1（栈不变量）**：处理第 $i$ 行之前，(a) 栈长恰为 $d_i$；(b) $\text{stack}[k]$ 等于「第 $i$ 行之前最近出现的深度 $k$ 的目录」的绝对路径长度。

**证明**：对 $i$ 归纳。$i = 1$ 时 $d_1 = 0$、栈空，两项均空真成立。设处理完第 $i$ 行后不变量对第 $i+1$ 行成立。分两种情形：

- 第 $i$ 行是目录：入栈后栈长为 $d_i + 1$，且新栈顶 $\text{stack}[d_i] = \text{cur}$ 恰为本目录的路径长度（见引理 2），其余项不变。若 $d_{i+1} = d_i + 1$，则新行父亲就是它，条件 (a)(b) 成立；若 $d_{i+1} \le d_i$，弹栈把它及更深的项全部去掉，栈长变为 $d_{i+1}$，留下的是各深度最近出现的目录，条件仍成立。
- 第 $i$ 行是文件：不压栈，栈长保持 $d_i$，项均未变。注意文件行下面不可能有更深缩进的行，故 $d_{i+1} \le d_i$，弹栈后同样满足。

由引理 2，入栈的 `cur` 就是该目录的真实路径长度，归纳步成立。∎

**引理 2（`cur` 就是绝对路径长度）**：设第 $i$ 行深度为 $d$，处理它时栈长为 $d$ 且栈中存的是其祖先的路径长度，则 `cur = base + len(name)` 等于第 $i$ 行条目的绝对路径长度。

**证明**：绝对路径由 $d+1$ 个名字与 $d$ 个 `/` 连接而成，故长度为 $\sum_{k=0}^{d}\lvert N_{a_k}\rvert + d$，其中 $a_k$ 是深度 $k$ 的祖先。由引理 1，$\text{stack}[d-1] + 1 = \bigl(\sum_{k=0}^{d-1}\lvert N_{a_k}\rvert + (d-1)\bigr) + 1 = \sum_{k=0}^{d-1}\lvert N_{a_k}\rvert + d$，加上 $\lvert \text{name}\rvert = \lvert N_{a_d}\rvert$ 即得。$d = 0$ 时 base 取 0，`cur = len(name)` 正是根目录条目的长度。∎

**引理 3（文件行被完整枚举）**：算法对每个文件行恰好计算一次 `cur`，且该值等于其绝对路径长度。

**证明**：外层循环按序处理每一行，文件行的 `cur` 由引理 2 给出；文件行不入栈不影响后续任何行的 `cur`（引理 1 中已论证）。∎

**定理**：算法返回的值等于所有文件绝对路径长度的最大值（无文件时为 0）。

**证明**：由引理 3，每个文件的真实路径长度都作为某个 `cur` 出现过，故 $\text{ans} \ge$ 最大值；又 `ans` 只由文件行的 `cur` 更新、且只做 `max`，故 $\text{ans} \le$ 最大值。两者相等；无文件时 `ans` 保持初值 0。∎

## 6. 复杂度分析

- **时间**：$O(n)$，$n = \lvert \text{input} \rvert$。切行与数制表符共访问每个字符常数次；每个目录行至多入栈、出栈各一次，栈操作总额 $O(\text{行数}) \le O(n)$；文件行只做一次加法与比较。
- **空间**：$O(h)$，$h$ 为最大深度（栈中元素个数），最坏 $h = O(n)$（例如每层只有一个目录的链）。除此之外只用常数个整型变量；若把输入本身算作占用，则总空间 $O(n)$。

## 7. 参考代码

### C++
```cpp
#include <string>
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int lengthLongestPath(string input) {
        int ans = 0, n = (int)input.size();
        vector<int> len;              // len[d] = 深度 d 的目录的绝对路径长度（不含分隔符）
        int start = 0;
        while (start < n) {
            int end = start;
            while (end < n && input[end] != '\n') end++;   // 本行区间 [start, end)
            int depth = 0, i = start;
            while (i < end && input[i] == '\t') { depth++; i++; }
            int nameLen = end - i;
            while ((int)len.size() > depth) len.pop_back();  // 弹回父目录
            int base = len.empty() ? 0 : len.back() + 1;     // 多一个 '/'
            int cur = base + nameLen;
            bool isFile = false;
            for (int k = i; k < end; k++)
                if (input[k] == '.') { isFile = true; break; }
            if (isFile) ans = max(ans, cur);                 // 文件：只更新答案
            else len.push_back(cur);                         // 目录：入栈
            start = end + 1;
        }
        return ans;
    }
};
```

### Python
```python
class Solution:
    def lengthLongestPath(self, input: str) -> int:
        ans = 0
        stack = []                     # stack[d] = 深度 d 的目录的绝对路径长度（不含结尾 '/'）
        for line in input.split('\n'):
            depth = len(line) - len(line.lstrip('\t'))
            name = line[depth:]
            while len(stack) > depth:  # 弹回父目录
                stack.pop()
            base = stack[-1] + 1 if stack else 0    # 父路径长度 + 一个 '/'
            cur = base + len(name)
            if '.' in name:            # 文件名必含 '.'，目录名必不含
                ans = max(ans, cur)    # 文件：只更新答案
            else:
                stack.append(cur)      # 目录：作为后续行的潜在父目录
        return ans
```

## 8. 边界情况与易错点

1. **没有任何文件**：`input = "a"` 时所有行都是目录，`ans` 始终为初值 0，直接返回 0，不要返回 `-1`。
2. **根目录下的文件**：`"file1.txt\nfile2.txt\nlongfile.txt"` 中每行深度都是 0，`base` 恒为 0，答案 12；这类输入没有任何 `/`，长度公式的 $d$ 项为 0，正好覆盖。
3. **深度回退**：`subdir1 → subdir2` 需要把深度 2 的条目弹出；漏掉 `while` 弹栈会把上一棵子树的目录当作父亲，示例 2 的答案会从 32 变成 51。
4. **弹一次不等于弹到 `d`**：把 `while` 写成 `if`（只弹一层）时，深度一次跨越多层就会错位。如 `"dir\n\ta\n\t\tb\nc.txt"` 从深度 2 直接回到 0，正确答案是 5，只弹一次会算出 11。必须用 `while` 弹到栈长等于 `d`。
5. **`stack[d-1]` 越界**：$d = 0$ 时栈必为空，必须写成 `stack ? stack.back() + 1 : 0`；Python 里 `stack[-1]` 在空栈会抛异常，而 `stack[d-1]` 在 $d=0$ 时会静默取到栈底——两种写法都会出错。
6. **文件识别不能靠扩展名**：用 `'.' in name`（目录名按题面保证不含 `.`）；若改用 `endswith(".txt")` 之类的判断会漏掉其它扩展名。
7. **名字里的空格**：`"a b"` 长度是 3，空格计入路径长度；不要对 `name` 做 `strip`，只能去掉行首的 `\t`。
8. **末行处理**：C++ 扫描时 `end` 可能等于 `n`，此时 `start = end + 1` 会让循环结束，不会越界；Python 的 `split` 天然处理末行，但输入不会以 `\n` 结尾，也不要人为补 `\n`。
9. **深度跳跃（非法输入）**：若某行深度比上一个目录深度大 2 及以上（题面保证不出现），`stack` 长度不足 `d`，`base` 会取错；工程实现中可加 `depth = min(depth, len(stack))` 之类的防御，但本题无需。
