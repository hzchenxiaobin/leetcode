# LeetCode 至少是其他数字两倍的最大数 题解

## 1. 题目概述

- **标题 / 题号**：至少是其他数字两倍的最大数（#747，easy）
- **链接**：https://leetcode.cn/problems/largest-number-at-least-twice-of-others/
- **来源**：LeetCode 第 64 场周赛 Q1
- **难度**：简单
- **标签**：数组、排序

**题意**：数组 `nums` 中的最大值 $m$ **唯一**。判断 $m$ 是否**至少是其余每个元素的两倍**：若对任意 $\text{nums}[i] \ne m$ 都有 $m \ge 2 \cdot \text{nums}[i]$，返回 $m$ 的下标；否则返回 `-1`。

**约束**：

- $2 \le \text{nums.length} \le 50$
- $0 \le \text{nums}[i] \le 100$
- 最大元素唯一（因此下标也唯一，不需要处理并列最大）

## 2. 示例

**示例 1**

```text
输入：nums = [3,6,1,0]
输出：1
解释：6 是最大整数（下标 1）。其余元素 3、1、0 都满足 6 ≥ 2*x，
      其中 6 ≥ 2*3 = 6 恰好取等，故返回 1。
```

**示例 2**

```text
输入：nums = [1,2,3,4]
输出：-1
解释：4 是最大值，但 4 < 2*3 = 6，不满足「至少两倍」，返回 -1。
```

**示例 3（补充，考察取等与 0 值）**

```text
输入：nums = [0,1]
输出：1
解释：1 ≥ 2*0 = 0 成立（0 也是「其他数字」），返回 1。
```

## 3. 解题思路

### 3.1 暴力思路

对每个下标 $i$，扫描整个数组检查是否所有 $j \ne i$ 都满足 $\text{nums}[i] \ge 2\cdot\text{nums}[j]$，成立就返回 $i$。正确但需要 $O(n^2)$ 次比较（$n \le 50$ 时完全够用），属于「签到题也能过」的写法；问题在于没有说出这道题真正的观察点。

稍好一点：排序后取末元素 $m$ 与次末元素 $s$，判断 $m \ge 2s$，复杂度 $O(n \log n)$。但排序后下标就丢了，必须额外记录「原下标」或再扫一遍找回 $m$ 的位置——反而更啰嗦。

### 3.2 核心观察：只需和「第二大」比一次

![核心观察：只需比较第二大](images/wc64_q1_second_max_insight.svg)

设 $m$ 是唯一最大值，$s = \max\{\text{nums}[i] \mid \text{nums}[i] < m\}$ 是**第二大**（严格小于 $m$ 的元素里的最大值）。关键引理：

$$m \ge 2\cdot\text{nums}[i]\ \ (\forall\, \text{nums}[i] \ne m) \iff m \ge 2s$$

- 「$\Leftarrow$」：任何其他元素 $x \le s$，故 $2x \le 2s \le m$；
- 「$\Rightarrow$」：$s$ 本身就是一个「其他元素」，直接代入即可。

也就是说，**逐个检查所有元素是多余的**：第二大是「其余元素」里最大的那个，只要它能过，其余的自然都能过；只要它过不了，答案就是 `-1`。于是问题从「$O(n)$ 次比较」压缩成「$O(1)$ 次比较」。

### 3.3 算法流程：一次遍历同时求 $m$ 与 $s$

![一次遍历维护最大值与第二大](images/wc64_q1_one_pass_flow.svg)

维护三个变量：`maxVal`（当前前缀最大值）、`maxIdx`（它的下标）、`second`（当前前缀中**除最大值之外**的最大值）。遍历每个 $x = \text{nums}[i]$：

1. **$x > \text{maxVal}$（刷新最大值）**：旧的 `maxVal` 从「最大」退位成「其余元素里的最大」，所以先执行 `second = maxVal`，再执行 `maxVal = x`、`maxIdx = i`。
2. **否则（$x \le \text{maxVal}$）**：新元素只能去争「第二大」，若 $x > \text{second}$ 就执行 `second = x`。

遍历结束后做唯一一次判定：`maxVal >= 2 * second` 为真则返回 `maxIdx`，否则返回 `-1`。

初值取 `-1` 就够了：题面保证 $\text{nums}[i] \ge 0$，所以 `-1` 相当于 $-\infty$，而 $2 \cdot (-1) = -2$ 不会让判定误通过。

### 3.4 示例演算

![走查表：nums = [3,6,1,0]](images/wc64_q1_trace_table.svg)

| 步骤 | $x$ | $x > \text{maxVal}$ | `second` | `maxVal` | `maxIdx` |
|------|-----|---------------------|----------|----------|----------|
| 初始 | — | — | −1 | −1 | −1 |
| $i=0$ | 3 | 是 | −1 | 3 | 0 |
| $i=1$ | 6 | 是 | 3 | 6 | 1 |
| $i=2$ | 1 | 否（$1 < 6$） | 3 | 6 | 1 |
| $i=3$ | 0 | 否（$0 < 6$） | 3 | 6 | 1 |

判定 $6 \ge 2 \times 3 = 6$ 成立 → 返回 `1`。对照 `[1,2,3,4]`：最终 `maxVal = 4`、`second = 3`，$4 < 6$ → 返回 `-1`。

## 4. 算法细节

1. **只用第二大做判定**，不要写「$\forall j$」的双重循环；这是本题从 $O(n^2)$ 走到 $O(n)$ 的唯一一步。
2. **更新顺序不能反**：必须 `second = maxVal; maxVal = x;`。若先写 `maxVal = x`，旧的峰值被覆盖，`second` 会被赋成新的最大值本身，判定退化为 $m \ge 2m$；示例 1 会因此错答 `-1`。
3. **两个分支必须互斥（`else if`）**：若把第二个判断写成独立的 `if (x > second)`，在刷新最大值的那一轮 `second` 刚被置为旧最大值，而 $x$ 又大于它，`second` 就会被覆盖成 $x$，于是 `second` 恒等于当前最大值，判定退化成 $m \ge 2m$；凡是答案不为 `-1` 的用例都会错，例如 `[0,1]`、`[3,6,1,0]` 都返回 `-1`。
4. **判定用 `>=` 而不是 `>`**：题面是「至少两倍」，$m = 2s$ 是合法边界（示例 1 的 $6 = 2\times3$ 就是取等）。
5. **比较式写成 `2 * second <= maxVal`**：本题 $2s \le 200$，`int` 绝对安全；迁移到值域 $10^9$ 的版本时应改用 `long long` 或 `maxVal / 2 >= second`，避免 $2s$ 溢出。
6. **记录下标而非事后查找**：遍历时顺手存 `maxIdx`，避免再扫一遍 `index(max)`；也避免「值相同取哪个下标」的歧义。
7. **`-1` 初值是依赖数据范围的技巧**：一旦允许负数，`-1` 可能大于真实元素，必须改用 `INT_MIN` / `None`。写进注释，便于迁移。
8. **不需要排序**：标签里虽有 Sorting，但排序是 $O(n\log n)$ 且丢失下标；本解 $O(n)$ 更优，排序只在「需要前 $k$ 大」时才必要。

## 5. 正确性证明

**引理 1（第二大充分）**：设 $m = \max(\text{nums})$ 唯一，$s$ 为其余元素的最大值，则

$$\bigl(\forall i,\ \text{nums}[i] \ne m \Rightarrow m \ge 2\,\text{nums}[i]\bigr) \iff m \ge 2s .$$

**证明**：

（$\Leftarrow$）任取其他元素 $x$，由 $s$ 是其余元素的最大值有 $x \le s$，于是 $2x \le 2s \le m$。

（$\Rightarrow$）$s$ 取在某个不等于 $m$ 的元素上，属于「其他元素」，条件直接给出 $m \ge 2s$。∎

**引理 2（遍历不变量）**：处理完前 $k$ 个元素后，`maxVal` 等于前缀最大值 $M_k$，`maxIdx` 是它的下标，`second` 等于前缀中除 $M_k$ 之外元素的最大值 $S_k$。

**证明**：对 $k$ 归纳。$k=1$ 时第一个元素必然满足 $x > -1$，于是 `maxVal = nums[0]`、`second = -1`；空集的「其余元素最大值」按 $-\infty$ 处理，而元素非负，`-1` 正是安全的 $-\infty$，故成立。

归纳步：读入 $x = \text{nums}[k]$。

- 若 $x > M_{k-1}$：新前缀最大为 $x$，「其余元素」恰为旧前缀全体，其最大值就是 $M_{k-1}$，代码先执行 `second = maxVal` 再令 `maxVal = x`、`maxIdx = k`，正确。
- 若 $x \le M_{k-1}$：新前缀最大仍是 $M_{k-1}$，「其余元素」为「旧其余元素 $\cup \{x\}$」，其最大值为 $\max(S_{k-1}, x)$，而代码仅在 $x > S_{k-1}$ 时令 `second = x`，正是该式。∎

**定理**：算法返回值正确——条件成立时返回唯一最大值的下标，否则返回 `-1`。

**证明**：遍历结束（$k=n$）时由引理 2 得 `maxVal = m`、`second = s`、`maxIdx` 为 $m$ 的下标。若 `maxVal >= 2 * second`，即 $m \ge 2s$，由引理 1 知 $m$ 至少是其余每个元素的两倍，返回 `maxIdx` 符合题意；若不成立，则 $m < 2s$ 且 $s$ 对应某个「其他元素」，故至少存在一个元素使条件被破坏，返回 `-1` 同样符合题意。最大值唯一保证返回的下标唯一，不会被并列最大值干扰。∎

## 6. 复杂度分析

- **时间**：$O(n)$。一次遍历，每个元素 $O(1)$ 次比较与赋值；遍历结束后 $O(1)$ 次判定。没有排序，也没有二次扫描。
- **空间**：$O(1)$。只用 `maxVal`、`maxIdx`、`second` 三个整型变量，与 $n$ 无关（不复制数组、不建哈希表）。

## 7. 参考代码

### C++

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    int dominantIndex(vector<int>& nums) {
        int maxVal = -1, maxIdx = -1, second = -1;   // nums[i] >= 0，-1 当 -∞
        for (int i = 0; i < (int)nums.size(); ++i) {
            int x = nums[i];
            if (x > maxVal) {
                second = maxVal;      // 旧的 maxVal 退位为「第二大」
                maxVal = x;
                maxIdx = i;
            } else if (x > second) {  // 否则只能争「第二大」
                second = x;
            }
        }
        return maxVal >= 2 * second ? maxIdx : -1;
    }
};
```

### Python

```python
class Solution:
    def dominantIndex(self, nums: list[int]) -> int:
        max_val, max_idx, second = -1, -1, -1
        for i, x in enumerate(nums):
            if x > max_val:
                second = max_val          # 旧的 max_val 退位为「第二大」
                max_val, max_idx = x, i
            elif x > second:              # 否则只能争「第二大」
                second = x
        return max_idx if max_val >= 2 * second else -1
```

## 8. 边界情况与易错点

1. **取等临界**：`[3,6,1,0]` 中 $6 = 2 \times 3$ 属于「至少两倍」，必须用 `>=`；写成 `>` 会让示例 1 返回 `-1`。
2. **最大值在首位 / 末位**：`[6,3,1,0]` 返回 `0`，`[1,2,6]` 返回 `2`；`maxIdx` 随 `maxVal` 同步更新，不要事后用「值相等取第一个下标」去查。
3. **第二大等于 0**：`[0,1]`、`[5,0,1]` 中 $2s = 0$，`maxVal >= 0` 恒成立，返回最大值下标。注意 `second` 的初值 `-1` 与「真实的第二大 0」是两回事，不能拿 `second == -1` 当「没有第二大」来特判。
4. **只有两个元素**：$n \ge 2$，`[1,2]` → `1`，`[2,3]` → `-1`；由于最大值唯一，其余元素非空，遍历结束时 `second` 一定取到某个真实元素的值，不会停留在 `-1`（最大值排第一时由第二个元素补上）。
5. **`else if` 写成两个独立 `if`**：在刷新最大值的那一轮，`second` 已被置为旧最大值，而 $x$ 比它更大，第二个独立的 `if` 会把 `second` 覆盖成 $x$；此后 `second` 恒等于当前最大值，判定退化为 $m \ge 2m$，凡是答案不为 `-1` 的用例都会错（`[0,1]` 会返回 `-1`）。这是本题最高频的 WA。
6. **初值 `-1` 依赖非负约束**：迁移到含负数的版本时必须改用 `INT_MIN` / `float('-inf')`，否则 `[-2,-1]` 这类输入会返回非法的下标 `-1`。
7. **忘记唯一性前提**：题面保证最大值唯一，故「最大值出现两次」不会出现；若放开该前提，`[0,0]` 的答案应为 `-1`（两个最大值互相都不满足两倍），需要额外统计最大值出现次数。
