# LeetCode 可见点的最大数目 题解

## 1. 题目概述

- **标题 / 题号**：可见点的最大数目（#1610，hard）
- **链接**：https://leetcode.cn/problems/maximum-number-of-visible-points/
- **来源**：LeetCode 第 209 场周赛 Q3
- **难度**：困难
- **标签**：几何、数组、数学、排序、滑动窗口

**题意**：你站在平面上固定位置 `location`，初始面向正东，不能移动但可以自转。视野是张角为 `angle` 的扇形（中心方向可随自转任意调整，视野范围 $[d - angle/2,\ d + angle/2]$）。给定点数组 `points`，点之间互不遮挡，与 `location` 重合的点无论怎么转都可见。求一次观测中最多能看到多少个点。

**约束**：

- $1 \le points.length \le 10^5$
- $points[i].length == 2$，$location.length == 2$
- $0 \le angle \le 360$
- $0 \le pos_x, pos_y, x_i, y_i \le 10^5$

> 💡 本题是标准的**极角排序 + 环形滑动窗口**模板题：距离无关紧要，每个点只剩「方向」一个自由度；把方向量化成极角后，「找最优视野」变成「单位圆上找一条定长圆弧覆盖最多极角」——排序破环后一趟双指针即可。$n = 10^5$ 恰好卡掉 $O(n^2)$，指明必须 $O(n \log n)$。

```text
      在同一条射线上（极角都是 45°），仍各自可见，互不遮挡。
```

```text
      加上与 location 重合的点 [1,1]（恒可见），共 4 个。
```

## 3. 解题思路

### 3.1 朴素思路

「枚举所有自转角 $d$ 再逐一检查」不可行：$d$ 是连续变量，无法枚举。退一步，最优视野总可以**对齐到某个点**（见 §5 引理 3），于是只需检查 $O(n)$ 个候选方向，每个方向线性数一遍落入侵野的点——$O(n^2) \approx 10^{10}$，在 $n = 10^5$ 下超时。瓶颈在于「检查一个方向」本身就要 $O(n)$；要想提速，必须让「所有方向的答案」能被一次性地批量维护——这就是滑动窗口的切入点。

### 3.2 核心观察：极角 + 定长圆弧覆盖

![核心概念：极角与可旋转的视野扇形](images/wc209_q3_polar_vision.svg)

三个关键观察把几何问题压缩成序列问题：

1. **距离无关**：可见性只取决于点相对 `location` 的**方向**，与远近无关（点不遮挡）。每个点因此坍缩成一个**极角** $\theta_i = \operatorname{atan2}(y_i - pos_y,\ x_i - pos_x)$（正东为 $0°$，逆时针为正，归一化到 $[0°, 360°)$）。
2. **可见 ⟺ 落入一段弧**：自转 $d$ 后视野是 $[d - \alpha/2,\ d + \alpha/2]$（$\alpha$ 为 `angle`），在极角圆上恰是一条**长度为 $\alpha$ 的弧**；$d$ 自由 ⟺ 弧的位置自由。最大化可见点数 = **在周长 360 的圆上找一条长 $\alpha$ 的弧，覆盖最多极角**。
3. **重合点恒可见**：与 `location` 重合的点方向未定义（$\operatorname{atan2}(0,0)$ 无意义），必须剔除后单独计数，最后统一加上。

> ⚠️ 观察里的「弧」在圆上**可跨过 $0°$**（例如同时盖住 $350°$ 与 $5°$），这是本题最隐蔽的坑——把弧摊平成线段时会漏掉跨 $0°$ 的最优解。

### 3.3 算法流程：排序破环 + 双副本滑动窗口

![破环为链：排序加双副本后的滑动窗口](images/wc209_q3_circular_window.svg)

```text
① 剔除与 location 重合的点，计数 cnt
② 其余点求极角 θ = atan2(dy, dx) 归一到 [0°, 360°)
③ 特判 angle = 360 → 直接返回 n + cnt（视野覆盖全平面）
④ 极角升序排序，再拼接一份整体 +360° 的副本（破环为链）
⑤ 双指针滑窗：对每个右端 i，左端 j 右移直到 θ[i] − θ[j] ≤ angle + ε
   窗口大小 i − j + 1 取最大
⑥ 返回 max(窗口) + cnt
```

**为什么双副本能破环**：排序后 $\theta_1 \le \cdots \le \theta_n < 360$，拼接得 $\theta_1 \le \cdots \le \theta_n \le \theta_1 + 360 \le \cdots \le \theta_n + 360$。任何一条不跨 $0°$ 的弧对应第一份中的窗口；跨 $0°$ 的弧（右端在第二份）因副本存在同样被完整枚举——一条弧最多覆盖 $n$ 个点，绝不会同时用到两份中的「同一点」，因此计数不重不漏（$\alpha = 360$ 的退化情形除外，见特判）。

### 3.4 示例演算

![示例演算：示例1与示例3的滑动窗口走查](images/wc209_q3_walkthrough.svg)

**示例 1** `points = [[2,1],[2,2],[3,3]]`，`angle = 90`：极角 $[0°, 45°, 45°]$，双副本 $[0, 45, 45, 360, 405, 405]$。窗口右端滑到第三项时 $\theta_i - \theta_j = 45 \le 90$，窗口 $\{0, 45, 45\}$ 覆盖 3 个点；答案 $3 + 0 = 3$。

**示例 3** `points = [[1,0],[2,1]]`，`angle = 13`：极角 $[270°, 0°]$，排序后 $[0, 270]$，双副本 $[0, 270, 360, 630]$。任意相邻两项之差最小为 $90 > 13$，每个窗口只能装下 1 个点；答案 $1 + 0 = 1$——这正是「极角差不够，一个也多看不见」的最小反例。

## 4. 算法细节

1. **重合点必须先剔除**：$\operatorname{atan2}(0, 0)$ 依实现返回 $0°$，若不剔除会把重合点误当成「正东方向的点」——它确实恒可见，但放极角里参与窗口竞争是错的（例如 `angle = 0`、视野朝西时应可见它，极角 0° 却不落入窗口）。
2. **极角归一化**：`atan2` 返回 $[-180°, 180°]$，模 $360°$ 归一到 $[0°, 360°)$；也可直接用 $[-180°, 180°]$ 排序后拼副本，两种写法等价。
3. **`angle = 360` 特判**：视野覆盖整个平面，所有点可见；若走双副本滑窗，窗口 $[\theta, \theta + 360]$ 会把同一点的两个副本同时计入，**多算近一倍**。
4. **容差 $\varepsilon$**：视野边界是**闭区间**（边界上的点可见，示例 1 中 $[3,3]$ 在边界仍可见），且 `atan2` + 度数转换引入 $10^{-13}$ 量级误差，故滑窗条件写成 $\theta_i - \theta_j > \alpha + 10^{-8}$ 才收缩。$\varepsilon$ 取 $10^{-9} \sim 10^{-8}$ 均可，过大（如 $10^{-4}$）可能在极角极密的构造数据下误收边界外的点。
5. **滑窗实现**：`i` 从 0 扫到 $2n-1$，`j` 单调不降，均摊 $O(n)$；也可对每个左端点在副本上二分 `upper_bound(θ_j + α + ε)`，同为 $O(n \log n)$ 但常数更大。
6. **答案组装**：`ans = max(window) + cnt`，`max(window)` 初始为 0（全部点与 `location` 重合时窗口数为 0）。

## 5. 正确性证明

**引理 1（可见性刻画）**：非重合点 $p$ 在自转 $d$ 后可见，当且仅当 $\theta(p) \in [d - \alpha/2,\ d + \alpha/2] \pmod{360°}$。

**证明**：$p$ 可见当且仅当「$p$、`location`、正东方向」的夹角落在视野内，而这个夹角正是 $\theta(p)$（$\operatorname{atan2}$ 的定义）；自转 $d$ 等价于把视野平移到以 $d$ 为中心。模 $360°$ 处理角度绕圆一周的同余。∎

**引理 2（弧覆盖等价）**：最大化可见的非重合点数，等价于在周长 360 的圆上找一条长度为 $\alpha$ 的弧，使落入弧内（含端点）的极角最多。

**证明**：由引理 1，固定 $d$ 的可见集恰为弧 $[d - \alpha/2, d + \alpha/2]$ 内的极角集；反之任取一条长 $\alpha$ 的弧，令 $d$ 为其中点，该弧即为此 $d$ 的视野。二者一一对应，最优值相等。∎

**引理 3（端点对齐）**：存在一条最优弧，其**左端点**与某个极角重合（$\alpha < 360$ 时）。

**证明**：取一条最优弧。若左端点未对齐任何极角，将其**向右**平移 $\delta$，其中 $\delta$ 小于左端点与右侧最近极角的距离，则覆盖集不变（仍在弧内的点未变，新移入区域为空）。重复平移，直到左端点碰上某个极角；此时覆盖集仍是最优的。∎

**定理（主算法正确性）**：双副本排序滑窗求出的最大窗口，加上重合点数 `cnt`，恰为答案。

**证明**：

- **可达性（不高于最优）**：滑窗枚举的每个窗口 $[\theta_j, \theta_i]$ 满足 $\theta_i - \theta_j \le \alpha$，对应一条合法弧，其覆盖的点数为窗口大小（两份副本互不重复计入同一点：窗口长度 $< 360$，而同一点两副本相差恰为 $360$），故每个枚举值 $\le \mathrm{OPT}$。
- **完备性（不低于最优）**：由引理 3，存在最优弧左端对齐某极角 $\theta_j$、右端 $\le \theta_j + \alpha$。设其覆盖的最右极角为 $\theta_i$（若弧跨 $0°$，取第二份副本中的对应值），则 $\theta_j, \theta_i$ 均出现在双副本序列中且 $\theta_i - \theta_j \le \alpha$——滑窗右端到达该 $\theta_i$ 时窗口左端至多为 $\theta_j$，窗口大小 $\ge$ 该最优覆盖数。
- 二者合并得窗口最大值 $= \mathrm{OPT}$，再加恒可见的重合点数 `cnt`。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \log n)$。求极角与双指针滑窗均为 $O(n)$，排序主导；$n = 10^5$ 下约 $1.7 \times 10^6$ 次比较，轻松通过。
- **空间复杂度**：$O(n)$。极角双副本数组占 $2n$ 个 `double`（约 1.6 MB），可接受。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int visiblePoints(vector<vector<int>>& points, int angle, vector<int>& location) {
        int cnt = 0;                       // 与 location 重合的点，恒可见
        vector<double> angs;
        for (auto& p : points) {
            int dx = p[0] - location[0], dy = p[1] - location[1];
            if (dx == 0 && dy == 0) ++cnt; // atan2(0,0) 无意义，单独计数
            else angs.push_back(fmod(atan2(dy, dx) * 180.0 / M_PI + 360.0, 360.0));
        }
        int n = angs.size();
        if (angle >= 360) return n + cnt;  // 视野覆盖全平面（避免双副本重复计数）
        sort(angs.begin(), angs.end());
        for (int i = 0; i < n; ++i) angs.push_back(angs[i] + 360.0);  // 破环为链
        const double EPS = 1e-8;           // 闭区间边界 + 浮点容差
        int ans = 0;
        for (int i = 0, j = 0; i < 2 * n; ++i) {
            while (angs[i] - angs[j] > angle + EPS) ++j;
            ans = max(ans, i - j + 1);
        }
        return ans + cnt;
    }
};
```

### Python

```python
class Solution:
    def visiblePoints(self, points: List[List[int]], angle: int, location: List[int]) -> int:
        cnt, angs = 0, []
        for x, y in points:
            dx, dy = x - location[0], y - location[1]
            if dx == 0 and dy == 0:
                cnt += 1                    # 重合点恒可见，不参与窗口
            else:
                angs.append(math.degrees(math.atan2(dy, dx)) % 360)
        n = len(angs)
        if angle >= 360:
            return n + cnt                  # 全平面可见
        angs.sort()
        angs += [a + 360 for a in angs]     # 双副本破环
        ans, j = 0, 0
        for i, a in enumerate(angs):
            while a - angs[j] > angle + 1e-8:
                j += 1
            ans = max(ans, i - j + 1)
        return ans + cnt
```

## 8. 边界情况与易错点

1. **重合点未剔除**：$\operatorname{atan2}(0, 0)$ 返回 0，重合点混进极角数组后，在 `angle = 0` 且视野不对准正东时会**丢答案**——重合点本应无条件可见。
2. **`angle = 360` 未特判**：双副本滑窗中窗口 $[\theta, \theta + 360]$ 把同一点的两个副本同时计入，答案翻倍报错；此时视野即全平面，直接返回 $n + cnt$。
3. **闭区间边界用错不等号**：视野边界上的点**可见**（示例 1 的 $[3,3]$ 在 $d + \alpha/2$ 边界上）。滑窗收缩条件必须是 $\theta_i - \theta_j > \alpha + \varepsilon$（严格大于），写成 $\ge$ 会把恰在边界上的点挤出窗口。
4. **浮点容差缺失**：`atan2` 结果乘 $180/\pi$ 引入误差，两极角「数学上相等」时浮点差可能为 $10^{-13}$，无 $\varepsilon$ 会把同方向点误判出窗。
5. **忘记 `+360` 副本**：只排序不破环，跨 $0°$ 的最优窗口（如极角 $350°$ 与 $5°$、`angle = 20`）会漏掉，答案偏小。
6. **`angle = 0` 退化**：视野是一条射线，同射线上**所有点**可见（含不同距离），靠 $\varepsilon$ 保证极角差为 0 的点计入窗口。
7. **窗口初值为 0**：全部点与 `location` 重合时极角数组为空，滑窗部分贡献 0，答案 = `cnt`。
8. **度数与弧度混用**：`atan2` 返回弧度，`angle` 是度数，忘记 `* 180 / π` 转换是最高频的 WA 原因。
