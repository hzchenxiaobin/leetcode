# LeetCode 使整数变为 0 的最少操作次数 题解

## 1. 题目概述

- **标题 / 题号**：使整数变为 0 的最少操作次数（#1611，hard）
- **链接**：https://leetcode.cn/problems/minimum-one-bit-operations-to-make-integers-zero/
- **来源**：LeetCode 第 209 场周赛 Q4
- **难度**：困难
- **标签**：位运算、递归、记忆化搜索、数学、动态规划

**题意**：给定整数 `n`，每次可以执行以下两种操作之一，目标是把 `n` 变成 `0`，求**最少操作次数**：

- **操作 1**：翻转二进制表示的第 $0$ 位（最低位），任何时候可用。
- **操作 2**：翻转第 $i$ 位（$i \ge 1$），前提是第 $i-1$ 位为 $1$ 且第 $i-2 \sim 0$ 位**全为 $0$**——即低 $i$ 位恰好呈 $10\cdots0_2$ 的模式。

**约束**：

- $0 \le n \le 10^9$（不足 30 位）

> 💡 这道题是**九连环**（Baguenaudier）的位运算化身：九连环「要拆第 $k$ 环，必须第 $k-1$ 环在架上且更低的环全在架下」，正是操作 2 的前提。而九连环最优解的状态序列恰好按 **Gray 码**推进——这暗示答案与 Gray 码的逆变换有关。

## 2. 示例

**示例 1**

```text
输入：n = 3
输出：2
解释：3 = "11"
"11" -> "01"   操作 2 翻 bit 1（前提 bit 0 = 1 满足）
"01" -> "00"   操作 1 翻 bit 0
```

**示例 2**

```text
输入：n = 6
输出：4
解释：6 = "110"
"110" -> "010"  操作 2 翻 bit 2（前提 bit 1=1、bit 0=0 满足）
"010" -> "011"  操作 1 翻 bit 0
"011" -> "001"  操作 2 翻 bit 1（前提 bit 0 = 1 满足）
"001" -> "000"  操作 1 翻 bit 0
```

**示例 3（补充：孤立最高位最「贵」）**

```text
输入：n = 4
输出：7
解释：4 = "100"
"100" -> "101" -> "111" -> "110" -> "010" -> "011" -> "001" -> "000"
依次为：操作1、操作2(翻bit1)、操作1、操作2(翻bit2)、操作1、操作2(翻bit1)、操作1
单点 n = 2^k 的答案是 2^(k+1) − 1。
```

## 3. 解题思路

### 3.1 暴力思路：BFS

把每个整数看成图中的一个节点、每种合法操作看成一条边，从 `n` 出发 BFS 找到 `0` 的最短路。但 $n$ 高达 $10^9 < 2^{30}$，状态数 $10^9$ 量级存不下也跑不完；更糟的是答案本身可达 $2^{30} - 1$（如 $n = 2^{29}$），路径长得离谱。显式搜索必死，必须挖掘操作自身的结构。

### 3.2 核心观察：状态图是一条链

![状态图不是网而是一条链](images/wc209_q4_state_path.svg)

三个观察层层递进：

1. **操作可逆，图是无向的**：两种操作都只翻转某一位且自逆；操作 2 的前提只看被翻位**以下**的位，而这些位在操作前后不变，故前提对操作前后同真同假。于是每条边双向可走。
2. **每个状态至多 2 种操作**：操作 1 恒可用；操作 2 在位 $i$ 可用的前提是「低 $i$ 位 $= 100\cdots0_2$」，这一前提对不同的 $i$ **互斥**。精确地说：设非零状态 $s$ 的最低置位位为 $\ell$，则 $s$ **恰好**可用操作 2 翻位 $\ell+1$（低 $\ell+1$ 位正是 $10\cdots0_2$），再无第二个操作 2。所以每个非零状态恰有 2 种操作，$0$ 只有操作 1 一种。
3. **Gray 码给出一条现成的链**：反射 Gray 码 $\mathrm{gray}(i) = i \oplus (i \gg 1)$ 相邻两项恰好只差一位，且可以证明（§5 引理 3）$\mathrm{gray}(i) \to \mathrm{gray}(i+1)$ **永远是合法操作**。于是
   $$0 = \mathrm{gray}(0) - \mathrm{gray}(1) - \mathrm{gray}(2) - \cdots$$
   构成一条经过**每个非负整数恰好一次**的无限链。

关键一步（§5 定理）：这条链在 $\mathrm{gray}(i)$（$i \ge 1$）处用掉了它前后两条边，而这两条边恰好就是这个状态仅有的 2 种操作——**再无剩余的边**。所以整个状态图就是这条 Gray 链本身，链上没有捷径，从 `n` 走到 `0` 的最短路就是沿链走的边数：`n` 在链上的位置下标 $i$（$0$ 的位置是 $0$）。

> 💡 一句话总结：**答案 = n 在 Gray 链上的位置**，即 $n$ 的逆 Gray 码 $\mathrm{gray}^{-1}(n)$。

### 3.3 算法流程：逆 Gray 码 / 镜像递归

![Gray 定位表与闭式解码](images/wc209_q4_gray_table.svg)

**方法一（闭式解码，推荐）**：逆 Gray 码有逐位异或的闭式

$$f(n) = n \oplus (n \gg 1) \oplus (n \gg 2) \oplus \cdots$$

实现为一个 $O(\log n)$ 的小循环：不断把 `n` 右移一位并异或累加。

**方法二（镜像递归）**：设 $n \ge 1$ 的最高位为 $k$、$r = n - 2^k$，则

$$f(n) = 2^{k+1} - 1 - f(r)$$

直觉来自反射 Gray 码的「反射」：最高位为 $1$ 的状态全在链的后半段，而后半段与前半段**镜像对称**。$n$ 到链首 $0$ 的距离等于总长 $2^{k+1} - 1$ 减去它到「剥掉最高位后的对应位置」的距离，后者正是 $f(r)$。

### 3.4 示例演算

![示例演算 n=6 沿链四步归零](images/wc209_q4_walkthrough.svg)

以 $n = 6 = 110_2$ 为例，三种口径互相印证：

- **闭式解码**：$6 \oplus 3 \oplus 1 = 110_2 \oplus 011_2 \oplus 001_2 = 100_2 = 4$。
- **镜像递归**：$k=2,\ r=2$：$f(6) = 2^3 - 1 - f(2)$；$f(2) = 2^2 - 1 - f(0) = 3$；故 $f(6) = 7 - 3 = 4$。
- **实际序列**：$110 \to 010 \to 011 \to 001 \to 000$，4 步，与示例 2 完全一致。

| 步骤 | 操作 | 前提核对 | 状态变化 |
|------|------|----------|----------|
| 1 | 操作 2 翻 bit 2 | bit 1=1、bit 0=0 ✓ | `110` → `010` |
| 2 | 操作 1 翻 bit 0 | 恒可用 | `010` → `011` |
| 3 | 操作 2 翻 bit 1 | bit 0=1 ✓ | `011` → `001` |
| 4 | 操作 1 翻 bit 0 | 恒可用 | `001` → `000` |

## 4. 算法细节

1. **闭式解码的实现**：

```text
ans = 0
while n > 0:
    ans ^= n      # 把 n >> j 累加进答案
    n >>= 1
return ans
```

循环恰好执行 $n$ 的位数次，最终 $f(n) = \bigoplus_{j \ge 0}(n \gg j)$。等价的递归一行：$f(n) = n \oplus f(n \gg 1)$，基准 $f(0) = 0$。

2. **镜像递归的实现**：$k$ 取最高位下标（`bit_length() - 1`），剥掉最高位用 `n ^ (1 << k)`，返回 $(1 \ll (k+1)) - 1 - f(n \oplus 2^k)$。每层位数严格减一，至多 30 层。

3. **两种写法等价**：镜像递归反复展开后与逐位异或完全一致（§5 推论给出代数证明）。闭式版连递归栈都省了，是首选。

4. **为什么不需要记忆化**：标签中的「记忆化搜索」对应自顶向下的写法，但本递归每个子问题位数严格减小且**没有分支**，是一条 30 层的线性调用链——既无重复子问题，也谈不上 DP；迭代写法最优。

5. **答案规模**：$n \le 10^9 < 2^{30}$，答案 $< 2^{30} < 2^{31} - 1$，32 位 `int` 安全。

## 5. 正确性证明

**引理 1（操作可逆）**：若状态 $u$ 可经一次操作变为 $v$，则 $v$ 可经同一操作变回 $u$；状态图是无向图。

**证明**：操作只翻第 $i$ 位，$v = u \oplus 2^i$。操作 1 无前提；操作 2 的前提只涉及第 $0 \sim i-1$ 位，这些位在操作前后不变，故前提对 $u, v$ 同真同假。∎

**引理 2（每个状态的可用操作数）**：任何状态恒可用操作 1；非零状态 $s$（设最低置位位为 $\ell$）恰好可用**一个**操作 2——翻位 $\ell+1$；状态 $0$ 没有任何操作 2 可用。

**证明**：操作 2 在位 $i$ 可用 $\iff$ 低 $i$ 位 $= 100\cdots0_2$。**至多一个**：若对 $i > j \ge 1$ 同时可用，前者要求 bit $j-1 = 0$（因 $j - 1 \le i - 2$），后者要求 bit $j-1 = 1$，矛盾。**存在性**：$s \ne 0$ 时取 $\ell$ 为最低置位位，则低 $\ell+1$ 位恰为 $10\cdots0_2$，翻位 $\ell+1$ 的操作 2 可用；$s = 0$ 时所有前提（要求 bit $i-1 = 1$）均不成立。∎

**引理 3（Gray 转移合法）**：对任意 $i \ge 0$，设 $t$ 为 $i$ 的最低 $0$ 位（即 $i$ 的低 $t$ 位全为 $1$、bit $t$ 为 $0$），则 $\mathrm{gray}(i) \oplus \mathrm{gray}(i+1) = 2^t$，且这是一次合法操作：$t = 0$ 时是操作 1，$t \ge 1$ 时是操作 2 且前提恰好满足。

**证明**：$i \to i+1$ 的进位止于 $t$，即只有 bit $0 \sim t$ 发生变化。按 $\mathrm{gray}(x)$ 的第 $j$ 位 $= x_j \oplus x_{j+1}$ 逐段核对：$j \le t-2$ 时前后均为 $1 \oplus 1 = 0$；$j = t-1$ 时前后均为 $1 \oplus 0 = 0 \oplus 1 = 1$；$j = t$ 时由 $0 \oplus i_{t+1}$ 变为 $1 \oplus i_{t+1}$，发生**翻转**；$j \ge t+1$ 不变。故只翻第 $t$ 位。当 $t \ge 1$ 时，翻位前 $\mathrm{gray}(i)$ 的低 $t$ 位恰为 $10\cdots0_2$（由前两段的取值），正是操作 2 翻位 $t$ 的前提。∎

**引理 4（逆变换闭式）**：记 $h(x) = \bigoplus_{j \ge 0}(x \gg j)$（有限项），则 $h = \mathrm{gray}^{-1}$，即 $\mathrm{gray}(h(x)) = x$ 且 $h(\mathrm{gray}(i)) = i$。

**证明**：$h(x) \oplus (h(x) \gg 1) = \bigoplus_{j \ge 0}(x \gg j) \oplus \bigoplus_{j \ge 0}(x \gg (j+1))$，右端每个 $x \gg k\ (k \ge 1)$ 出现两次相互抵消，只剩 $x$，故 $\mathrm{gray}(h(x)) = x$。又 $\mathrm{gray}(a) = \mathrm{gray}(b) \iff \mathrm{gray}(a \oplus b) = 0$，而 $\mathrm{gray}(y) = y \oplus (y \gg 1)$ 与 $y$ 最高位相同，故 $\mathrm{gray}(y) = 0 \iff y = 0$，从而 $\mathrm{gray}$ 单射、$h$ 是其逆。∎

**定理（状态图 = Gray 链）**：全体非负整数按题面操作构成的状态图恰为无限路径 $0 = \mathrm{gray}(0) - \mathrm{gray}(1) - \mathrm{gray}(2) - \cdots$，从而 $f(n) = \mathrm{gray}^{-1}(n) = \bigoplus_{j \ge 0}(n \gg j)$。

**证明**：

- **路径含于图**：由引理 3，相邻 Gray 状态间可经一次合法操作互达，再由引理 1 该边双向可走。由引理 4，$\mathrm{gray}$ 是 $\mathbb{N}$ 上的双射，故该路径经过每个非负整数恰好一次。
- **再无其他边**：任取 $i \ge 1$，路径在 $\mathrm{gray}(i)$ 处的两条边分别翻 $\mathrm{gray}(i-1) \oplus \mathrm{gray}(i)$ 与 $\mathrm{gray}(i) \oplus \mathrm{gray}(i+1)$ 所在的位。这两位不同（否则 $\mathrm{gray}(i-1) = \mathrm{gray}(i+1)$，与 $\mathrm{gray}$ 单射矛盾），故是两条**互异**的合法操作边；而由引理 2，非零状态总共只有这 2 种操作，恰好被路径用尽。$0$ 处唯一的操作 1 也正是路径的第一条边。于是图中每条边都在路径上，图 = 路径。
- **结论**：链上 $0$ 是端点（位置 $0$），从 $n = \mathrm{gray}(i)$ 沿链走到 $0$ 恰需 $i$ 步且别无他路，故 $f(n) = i = \mathrm{gray}^{-1}(n) = \bigoplus_{j \ge 0}(n \gg j)$。∎

**推论（镜像递归）**：设 $n \ge 1$ 的最高位为 $k$、$r = n - 2^k$，则 $f(n) = 2^{k+1} - 1 - f(r)$。

**证明**：$f(n) = \bigoplus_{j \ge 0}\big((2^k + r) \gg j\big)$。$j = 0$ 项为 $2^k + r$；$1 \le j \le k$ 的项为 $2^{k-j} + (r \gg j)$（$r < 2^k$，$2^k + r$ 的位互不重叠）；$j > k$ 的项为 $0$。于是

$$f(n) = 2^k \oplus r \oplus \Big(\bigoplus_{j=1}^{k} 2^{k-j}\Big) \oplus \bigoplus_{j \ge 1}(r \gg j) = 2^k \oplus (2^k - 1) \oplus \big(f(r) \oplus r\big) \oplus r = (2^{k+1} - 1) \oplus f(r).$$

由 $0 \le f(r) < 2^k$ 知 $f(r)$ 的二进制位包含于掩码 $2^{k+1}-1$ 之中，异或退化为减法：$f(n) = 2^{k+1} - 1 - f(r)$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(\log n)$。闭式解码的循环执行 `n` 的位数次（$\le 30$）；镜像递归每层位数减一，同至多 30 层。
- **空间复杂度**：闭式解码 $O(1)$，仅常数变量；镜像递归 $O(\log n)$ 递归栈。

## 7. 参考代码

### 方法一：闭式解码（逆 Gray 码，推荐）

### C++

```cpp
class Solution {
public:
    int minimumOneBitOperations(int n) {
        int ans = 0;
        while (n) {
            ans ^= n;   // 累加 n >> j
            n >>= 1;
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def minimumOneBitOperations(self, n: int) -> int:
        ans = 0
        while n:
            ans ^= n    # 累加 n >> j
            n >>= 1
        return ans
```

### 方法二：镜像递归

### C++

```cpp
class Solution {
public:
    int minimumOneBitOperations(int n) {
        if (n == 0) return 0;
        int k = 31 - __builtin_clz(n);   // 最高置位位（n=0 时 UB，必须先特判）
        return (1 << (k + 1)) - 1 - minimumOneBitOperations(n ^ (1 << k));
    }
};
```

### Python

```python
class Solution:
    def minimumOneBitOperations(self, n: int) -> int:
        if n == 0:
            return 0
        k = n.bit_length() - 1           # 最高置位位
        return (1 << (k + 1)) - 1 - self.minimumOneBitOperations(n ^ (1 << k))
```

## 8. 边界情况与易错点

1. **`n = 0`**：答案为 0。闭式解码的循环自然跳过；镜像递归必须先特判，否则 C++ 的 `__builtin_clz(0)` 是未定义行为。
2. **编码 / 解码方向搞反**：$x \oplus (x \gg 1)$ 是 Gray **编码**（位置 → 状态），本题要的是**解码**（状态 → 位置），必须逐位异或累加。直接返回 `n ^ (n >> 1)` 是错的——$n=3$ 时碰巧得 $3 \oplus 1 = 2 = f(3)$（纯属巧合），$n=6$ 时露馅：$6 \oplus 3 = 5 \ne 4$。
3. **操作 2 前提理解错**：前提是低 $i$ 位**恰好等于** $2^{i-1}$（形如 $10\cdots0_2$），不是「低位里有 1」，也不是「bit $i-1 = 1$ 就够」。
4. **截断位数的误区**：把状态图截成「$m$ 位框」会漏掉一条边——状态 $2^{m-1}$ 满足前提还能翻 bit $m$ 跳出框外。严格论证应在全体非负整数的无穷图上进行（§5 定理）；框外的路只会在更高的位置上绕远，不会成为捷径。
5. **BFS 的诱惑**：状态数 $10^9$、路径长可达 $10^9$ 量级，任何显式搜索（含双向 BFS）都超时超内存。
6. **答案上界**：$n < 2^{30} \Rightarrow f(n) < 2^{30}$，`int` 不溢出；若 $n$ 放宽到 $10^{18}$，C++ 需换 `long long`，且移位写 `1LL << (k + 1)` 防溢出。
