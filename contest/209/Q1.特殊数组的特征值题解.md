# LeetCode 特殊数组的特征值 题解

## 1. 题目概述

- **标题 / 题号**：特殊数组的特征值（#1608，easy）
- **链接**：https://leetcode.cn/problems/special-array-with-x-elements-greater-than-or-equal-x/
- **来源**：LeetCode 第 209 场周赛 Q1
- **难度**：简单
- **标签**：数组、排序、二分查找

**题意**：给定非负整数数组 `nums`。若存在数 `x` 使得 `nums` 中**恰好有 `x` 个元素** `>= x`，则称 `nums` 为**特殊数组**，`x` 为其**特征值**（`x` 不必属于数组）。是特殊数组则返回特征值，否则返回 `-1`。题目保证特征值若存在则唯一。

**约束**：

- $1 \le n = nums.length \le 100$
- $0 \le nums[i] \le 1000$

> 💡 签到题的关键信号：`x` 是「**个数**」而非「数值」——候选 $x \in [1, n]$ 只有 $n$ 个，与值域 $1000$ 无关。把「找 `x`」几何化为「计数曲线 $f(x)$ 与对角线 $y = x$ 求交点」，单调性立刻给出**唯一性**与**二分**两条路；比赛时最稳的落地写法是**排序后一趟分界扫描**。

## 2. 示例

**示例 1**

```text
输入：nums = [3,5]
输出：2
解释：恰好有 2 个元素（3 和 5）大于或等于 2。注意 x = 2 并不在数组中。
```

**示例 2**

```text
输入：nums = [0,0]
输出：-1
解释：x = 0 时应有 0 个元素 >= 0，但两个 0 都 >= 0；
     x = 1、x = 2 时又没有任何元素 >= x，均不成立。
```

**示例 3**

```text
输入：nums = [0,4,3,0,4]
输出：3
解释：恰好有 3 个元素（4、3、4）大于或等于 3。
```

**示例 4**

```text
输入：nums = [3,6,7,7,0]
输出：-1
解释：任何 x 都无法使「>= x 的元素个数」恰好等于 x。
```

## 3. 解题思路

### 3.1 朴素思路

枚举候选 `x`，对每个 `x` 线性扫描一遍数组，数出有多少元素 `>= x`，恰好等于 `x` 就返回。复杂度 $O(n^2)$；$n \le 100$ 时至多 $10^4$ 次比较，**直接就能过**——签到题先把这条最短路径走通。

枚举范围是唯一的「剪裁点」：

- **上界是 `n` 而非 `max(nums)`**：`x` 是「`>= x` 的元素个数」，个数至多 `n`；$x > n$ 时恒有 $f(x) \le n < x$，不可能命中。
- **下界是 1**：元素全非负，$f(0) = n \ge 1 \ne 0$，`x = 0` 永远无解（严格化见 §5 引理 1）。

要避开的想偏方向：**只拿数组元素当候选**——`x` 不必在数组中（示例 1 的 `x = 2` 不在 `[3,5]` 里），必须把 $[1, n]$ 的整数全部纳入枚举。

### 3.2 核心观察：计数曲线与对角线至多一个交点

![核心概念：计数曲线 f(x) 与对角线 y=x 的交点](images/wc209_q1_counting_concept.svg)

定义计数函数 $f(x) = \left|\{\, i : nums_i \ge x \,\}\right|$，则「找特征值」就是解方程 $f(x) = x$，几何上即**阶梯曲线 $f$ 与对角线 $y = x$ 的交点**。

- **单调性**：$x$ 变大时满足 $nums_i \ge x$ 的元素只减不增，$f(x)$ **单调不增**；而 $x$ 严格递增，于是 $g(x) = f(x) - x$ **严格递减**（每步至少减 1）。
- **唯一性**：严格递减的函数至多一次取到 $0$，故特征值至多一个——这正是题目「可以证明特征值唯一」的内容（§5 引理 2）。
- **可二分**：$g$ 严格递减，比较 $g(mid)$ 与 $0$ 即可把解的存在范围折半：$g(mid) > 0$ 则解只可能在 $(mid, n]$，$g(mid) < 0$ 则只在 $[1, mid)$。

### 3.3 算法流程：排序 + 一趟分界扫描

![算法流程：排序后枚举分界下标 i](images/wc209_q1_boundary_scan_flow.svg)

把数组**升序排序**后，「`>= x` 的元素」必是数组的一段**后缀**。若特征值 `x` 存在，后缀长度恰为 `x`，分界下标 $i = n - x$。反过来枚举每个下标 `i` 充当分界点：

1. 候选 $x = n - i$（分界右侧的元素个数）；
2. 命中条件：`nums[i] >= x`（后缀 $x$ 个元素全部 $\ge x$）**且**（`i == 0` 或 `nums[i-1] < x`，前缀全部 $< x$，保证不多不少）；
3. 命中即返回 `x`；`i` 扫完 `0..n-1` 仍未命中则返回 `-1`。

### 3.4 示例演算

![示例演算：两个例子对照 g(x) 是否取到 0](images/wc209_q1_walkthrough.svg)

**示例 3** `nums = [0,4,3,0,4]`，排序后 `[0,0,3,4,4]`，$n = 5$：

| $i$ | 候选 $x = n - i$ | `nums[i] >= x`？ | `i == 0` 或 `nums[i-1] < x`？ | 判定 |
|---|---|---|---|---|
| 0 | 5 | $0 \ge 5$ ✗ | —— | 跳过 |
| 1 | 4 | $0 \ge 4$ ✗ | —— | 跳过 |
| 2 | 3 | $3 \ge 3$ ✓ | $nums[1] = 0 < 3$ ✓ | **返回 3** |

**示例 4** `nums = [3,6,7,7,0]`，排序后 `[0,3,6,7,7]`：每个下标都被否决——最接近的是 $i = 2$（候选 $x = 3$）：$nums[2] = 6 \ge 3$ ✓，但 $nums[1] = 3$ **不满足** $< 3$，实际有 4 个元素 $\ge 3 \ne 3$。此时 $g(x) = 3, 2, 1, -1, -2$，从 $+1$ 直接跳到 $-1$、跳过了 $0$，返回 `-1`。

## 4. 算法细节

1. **排序暴露后缀结构**：升序排序后，所有阈值判定都变成「后缀长度」问题，这是「排序 + 计数」家族的通用起手式。
2. **枚举 `i` 与枚举 `x` 一一对应**：$x = n - i$（$i \in [0, n-1]$ ⟺ $x \in [1, n]$），扫下标即扫候选，一个不漏。
3. **判定条件的两侧分工**：右侧 `nums[i] >= x` 保证「至少 $x$ 个」，左侧 `nums[i-1] < x`（严格）保证「至多 $x$ 个」，合起来才是「恰好」。
4. **与二分计数版等价**：$\text{cnt}(x) = n - \text{lower\_bound}(x)$，对每个 $x \in [1, n]$ 二分找首个 $\ge x$ 的位置再比对（每日题解采用的主写法，见文末链接）。
5. **找到即返回**：由唯一性（引理 2），命中后无需继续扫描。
6. **不排序也能二分**：直接在 $[1, n]$ 上二分 $g(x)$，每次 $O(n)$ 计数，总体同为 $O(n \log n)$——排序的价值是把每次「计数」也降到了 $O(\log n)$ 以下。

## 5. 正确性证明

**引理 1（候选范围）**：若 `x` 满足「恰好 `x` 个元素 `>= x`」，则 $1 \le x \le n$。

**证明**：满足条件的元素是 $n$ 个元素的子集，故 $x \le n$。若 $x = 0$，则要求没有任何元素 $\ge 0$；但 $nums_i \ge 0$ 对全部 $i$ 成立，即 $n \ge 1$ 个元素全部 $\ge 0$，$f(0) = n \ne 0$，矛盾。∎

**引理 2（唯一性）**：$g(x) = f(x) - x$ 在整数上严格递减，故方程 $f(x) = x$ 至多一解。

**证明**：设 $x_1 < x_2$。阈值升高只会剔除候选元素，故 $f(x_1) \ge f(x_2)$，于是

$$g(x_1) = f(x_1) - x_1 \ge f(x_2) - x_1 > f(x_2) - x_2 = g(x_2).$$

严格递减的函数至多一次取到 $0$。∎

**定理（主算法正确性）**：排序分界扫描当且仅当特征值存在时返回它，否则返回 `-1`。

**证明**：

- **充分性**：设算法在 `i` 处返回 `x = n - i`。排序后 `nums[i] >= x` 保证下标 $i..n-1$ 共 $n - i = x$ 个元素 $\ge x$；`nums[i-1] < x`（或 `i = 0`）与升序性保证下标 $0..i-1$ 全部 $< x$。故恰好 $x$ 个元素 $\ge x$，`x` 是特征值。
- **必要性**：设特征值 $x$ 存在，取 $i = n - x \in [0, n-1]$（引理 1）。「恰好 $x$ 个元素 $\ge x$」意味着排序数组中 $\ge x$ 的元素恰为后缀 $i..n-1$：后缀首元素 $nums[i] \ge x$；且若 $i > 0$，则 $nums[i-1] < x$（否则 $\ge x$ 的元素多于 $x$ 个）。算法扫描到 `i` 时条件成立、返回 $x$。由引理 2 特征值唯一，返回值即正确答案。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \log n)$，排序主导；分界扫描本身 $O(n)$。朴素枚举 $O(n^2)$、二分 $g(x)$ 同为 $O(n \log n)$，在 $n \le 100$ 下全部可过。
- **空间复杂度**：$O(1)$。扫描只用下标与常数个变量（不计排序自身辅助空间：C++ 内省排序栈深 $O(\log n)$，Python Timsort 需 $O(n)$）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int specialArray(vector<int>& nums) {
        sort(nums.begin(), nums.end());
        int n = nums.size();
        for (int i = 0; i < n; ++i) {
            int x = n - i;   // 分界右侧元素个数 = 候选特征值
            if (nums[i] >= x && (i == 0 || nums[i - 1] < x)) {
                return x;    // 唯一性保证：命中即答案
            }
        }
        return -1;
    }
};
```

### Python

```python
class Solution:
    def specialArray(self, nums: List[int]) -> int:
        nums.sort()
        n = len(nums)
        for i in range(n):
            x = n - i
            if nums[i] >= x and (i == 0 or nums[i - 1] < x):
                return x
        return -1
```

> 💡 比赛求稳也可直接写朴素版：`next((x for x in range(1, n + 1) if sum(v >= x for v in nums) == x), -1)`——$O(n^2)$ 在 $n \le 100$ 下同样 AC，「写得快、写得对」优先。

## 8. 边界情况与易错点

1. **`x = 0` 永远无解**：元素非负 $\Rightarrow f(0) = n \ge 1$。枚举从 1 起即可；若从 0 起也只是白算一次，但**不能把 0 当合法答案返回**。
2. **枚举上界是 `n` 而非 `max(nums)`**：`x` 是个数不是数值，$x > n$ 时 $f(x) \le n < x$ 恒不成立，枚举到 1000 是纯浪费。
3. **左侧条件必须严格 `<`**：`[0,3,6,7,7]` 在 `i = 2`（候选 `x = 3`）时 `nums[1] = 3` 恰好**等于**候选值，实际有 4 个元素 `>= 3`；误写成 `nums[i-1] <= x` 会错误返回 3。
4. **全零数组**：`[0,0]` 的 $f(1) = f(2) = 0$，返回 `-1`——最典型的「个数追不上阈值」。
5. **单元素数组**：`[0]` → `-1`；`[5]` → `1`（1 个元素 $\ge 1$）。
6. **特征值不必在数组中**：`[3,5]` 的答案 `2` 不在数组里——不要只在元素值里搜索候选。
7. **命中即返回**：唯一性（引理 2）保证无多解，扫描到第一个满足的分界点就是答案。
