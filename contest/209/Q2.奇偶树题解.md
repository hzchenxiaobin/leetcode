# LeetCode 奇偶树 题解

## 1. 题目概述

- **标题 / 题号**：奇偶树（#1609，medium）
- **链接**：https://leetcode.cn/problems/even-odd-tree/
- **来源**：LeetCode 第 209 场周赛 Q2
- **难度**：中等
- **标签**：树、二叉树、广度优先搜索（BFS）

**题意**：给定一棵二叉树的根节点 `root`，判断它是否是**奇偶树**。层号从 `0` 开始（根为第 `0` 层），需同时满足两条按层陈述的规则：

- **偶数下标层**：所有节点值为**奇数**，且从左到右**严格递增**；
- **奇数下标层**：所有节点值为**偶数**，且从左到右**严格递减**。

是奇偶树返回 `true`，否则返回 `false`。

**约束**：

- $1 \le \text{树中节点数} \le 10^5$
- $1 \le Node.val \le 10^5$

> 💡 Q2 套路题的信号：所有条件都**按层陈述、层内从左到右检查**——这正是 BFS 层序遍历的天然产出。两个检查（奇偶性、严格单调）都能在同一趟「逐层从左到右」的扫描里**流式**完成：奇偶判定可合并为一句 `v % 2 != level % 2`（值与层号奇偶相反），单调性每层只需一个滚动变量 `prev` + **域外哨兵**（偶层 `0`、奇层 `10^6`），连「每层第一个元素」的特判都省了。

## 3. 解题思路

### 3.1 朴素思路：先收集每层，再回头校验

DFS（或 BFS）把每层的值按从左到右存进 `levels[d]`，遍历结束后逐层校验：所有值奇偶正确，且相邻对严格有序（也有人写成 `row == sorted(set(row))` 之类的整层比较）。时间 $O(n)$，但有两个问题：

1. **空间翻倍**：除了遍历自身的栈/队列，还要 $O(n)$ 存全部层，之后才能校验——「验证」被推迟到了遍历之后；
2. **递归爆栈风险**：$n = 10^5$ 且树退化成链时，DFS 递归深度 $10^5$——Python 默认递归上限 1000 直接 `RecursionError`，C++ 默认栈也偏紧。

改进方向：把「验证」**折叠进遍历**。每层校验只需要记住「本层上一个值」，而这正是 BFS 按层处理的天然副产品——`for (i = 0; i < sz; ++i)` 圈出一整层，层内出队顺序就是从左到右。

### 3.2 核心观察：三条「合并同类项」

![核心概念：奇偶性看层号，单调方向看层号的奇偶](images/wc209_q2_level_rules.svg)

1. **条件逐层独立**：两条规则都不跨层——任何一层违规即可立刻判 `false`，任何两层之间没有需要「联合」检查的东西（与 Q3 的环形窗口、Q4 的位运算状态机不同，本题没有全局耦合）。
2. **奇偶判定合一**：偶层配奇数、奇层配偶数——合法当且仅当**值与层号奇偶相反**：

   $$v \bmod 2 \ne level \bmod 2$$

   一条式子覆盖两种层，不用写 if 分支。
3. **严格单调只需相邻比较 + 域外哨兵**：严格递增 $\iff$ 每个值大于前一个（严格序的传递性，见 §5 引理 2）。于是每层只维护 `prev`，初值取**值域外**的哨兵——偶层 `prev = 0`（值 $\ge 1$）、奇层 `prev = 10^6`（值 $\le 10^5$），首节点自动通过，「本层第一个元素」的特判就此消失。

### 3.3 算法流程：BFS + 逐层哨兵扫描

![算法流程：BFS 逐层快照 + prev 哨兵滚动检查](images/wc209_q2_bfs_flow.svg)

```text
① q ← [root]，level = 0
② 每轮开始：若 q 为空 → 所有层通过，返回 true
③ sz = |q|（快照本层节点数）
④ prev = (level 为偶 ? 0 : 10⁶) ← 哨兵
⑤ 循环 sz 次：node 出队，v = node.val
     · 奇偶检查：v % 2 == level % 2 → 返回 false
     · 单调检查：偶层 v ≤ prev 或 奇层 v ≥ prev → 返回 false
     · prev = v；node 的左、右孩子依次入队（先左后右）
⑥ level += 1，回到 ②
```

要点在第 ③ 步：**先快照 `sz` 再循环**。循环中会向队列压入孩子、长度一直在变，只有快照能把「本层」和「下一层」隔开；第 ⑤ 步的先左后右入队，保证了下一层在队列里依然从左到右（§5 引理 3）。

### 3.4 示例演算

![示例演算：示例 1 通过 / 示例 2、3 失败](images/wc209_q2_walkthrough.svg)

**示例 1** `root = [1,10,4,3,null,7,9,12,8,6,null,null,2]`：

| 层 | 值序列（左→右） | 奇偶检查 | 单调检查（prev 演进） | 结果 |
|---|---|---|---|---|
| 0 | `[1]` | $1 \bmod 2 \ne 0$ ✓ | 单元素层，平凡 ✓ | 通过 |
| 1 | `[10, 4]` | 均为偶 ✓ | $10^6 \to 10 \to 4$，严格递减 ✓ | 通过 |
| 2 | `[3, 7, 9]` | 均为奇 ✓ | $0 \to 3 \to 7 \to 9$，严格递增 ✓ | 通过 |
| 3 | `[12, 8, 6, 2]` | 均为偶 ✓ | $10^6 \to 12 \to 8 \to 6 \to 2$，严格递减 ✓ | 通过 |

四层全部通过，队列清空，返回 `true`。

**示例 2** `[5,4,2,3,3,7]`：第 1 层 `[4,2]` 通过（$10^6 \to 4 \to 2$）；第 2 层 `[3,3,7]`：`prev` 演进到 $0 \to 3$ 后，第二个 $3$ 满足 $3 \le prev = 3$——**相等触发违规**，返回 `false`。

**示例 3** `[5,9,1,3,5,7]`：第 0 层 `[5]` 通过；第 1 层第一个值 $9$：$9 \bmod 2 = 1 = level \bmod 2$，奇偶性不符，**立即**返回 `false`（后面的 `1` 与单调性检查都不必看）。

## 4. 算法细节

1. **快照层宽**：进入每层先记 `sz = q.size()`，内层循环恰好处理一整层；边 `while (!q.empty())` 边当同层处理，会把孩子混进本层，层号与奇偶全部错位。
2. **奇偶判定合并**：合法 $\iff$ `v % 2 != level % 2`；代码里写「`v % 2 == level % 2` 则 `false`」，一个表达式覆盖两种层。
3. **哨兵取值域外**：偶层 `prev = 0`（比最小值 1 小），奇层 `prev = 10^6`（比最大值 $10^5$ 大）——本质是 $-\infty / +\infty$ 的整数近似，首节点免检且不产生虚假约束。
4. **严格比较**：判死条件是「偶层 $v \le prev$」「奇层 $v \ge prev$」，放行必须严格 `<` / `>`——相等即违规。
5. **先左后右入队**：这是同层左到右顺序的前提（§5 引理 3）；反着入队会让层内顺序变成从右到左，单调方向整体颠倒。
6. **失败即返回**：任一检查失败立即 `return false`，后续层无需再看（条件逐层独立，见 §5 引理 1）。
7. **DFS 变体**：前序 DFS 用数组 `last[d]` 记每层最近访问的值也能流式校验（前序遍历同层访问序同样从左到右，引理 3 的推论），额外空间降到 $O(h)$；但链状树递归深度 $10^5$，Python 必须调大递归上限或改显式栈——比赛求稳选 BFS。

## 5. 正确性证明

**引理 1（条件逐层独立）**：二叉树是奇偶树，当且仅当它的每一层（各自按左到右读取）分别满足「偶层：全奇 + 严格递增 / 奇层：全偶 + 严格递减」。

**证明**：定义中的每条约束都只引用**同一层**的节点，不存在跨层约束；全体约束的合取等于各层约束的合取。因此任一层违规即可判 `false`，全部层通过即可判 `true`，逐层独立检查与原定义等价。∎

**引理 2（相邻比较等价）**：序列 $a_1, \dots, a_k$ 严格递增 $\iff$ 对所有相邻对 $a_i < a_{i+1}$（递减同理）。

**证明**：若整层严格递增，相邻对显然满足。反之若所有相邻对严格不等，由「$<$」的传递性，任意 $i < j$ 有 $a_i < a_{i+1} < \cdots < a_j$，故整层严格递增。∎

**引理 3（BFS 层序性）**：孩子按「先左后右」入队的 BFS 中，出队序列的每一层都按**从左到右**排列，且层与层不交错。

**证明**：称同层节点 $u \prec v$，若 $u$ 在 $v$ 左侧（等价刻画：在 $u, v$ 的最近公共祖先处，$u$ 位于左子树、$v$ 位于右子树）。关键事实：$u \prec v \Rightarrow$ $u$ 的任何孩子 $\prec$ $v$ 的任何孩子（孩子仍落在 LCA 的对应子树内，左右相对位置不变）。

  维护不变式：**任一时刻队列由「至多两层」的节点组成，第 $d$ 层在前、第 $d+1$ 层在后，各自按左到右排列**。初始队列只含根，成立。出队队首不破坏顺序；出队第 $d$ 层节点 $u$ 时其孩子追加到队尾，而队尾已有的第 $d+1$ 层节点都是**先于 $u$ 出队**的节点的孩子，由关键事实它们都 $\prec$ $u$ 的孩子，故第 $d+1$ 层的入队保持左到右序。第 $d$ 层处理完毕时，队列恰为完整的第 $d+1$ 层，归纳成立。∎

**引理 4（哨兵安全）**：值域为 $[1, 10^5]$ 时，偶层哨兵 $0$ 与奇层哨兵 $10^6$ 使每层首节点的单调检查恒通过，且不引入额外约束。

**证明**：首节点 $v$ 满足 $v \ge 1 > 0$（偶层）或 $v \le 10^5 < 10^6$（奇层），单调检查必过。哨兵不是任何节点的值，奇偶检查只作用于出队节点，哨兵不参与，故不产生虚假判定。∎

**定理（主算法正确性）**：BFS 逐层哨兵扫描返回 `true`，当且仅当输入是奇偶树。

**证明**：

- **（返回 `true` $\Rightarrow$ 奇偶树）** 设算法通过。由引理 3，第 $d$ 层的检查序列即该层从左到右的真实值序列。每个值通过了 $v \bmod 2 \ne d \bmod 2$，由引理 1 即「偶层全奇、奇层全偶」；首节点由引理 4 通过，其余由相邻检查通过，再由引理 2 得整层严格单调（方向由层号奇偶决定）。所有层满足定义，故是奇偶树。
- **（奇偶树 $\Rightarrow$ 返回 `true`）** 设输入是奇偶树。则每层每个值奇偶合法（奇偶检查不触发）、相邻对严格有序（单调检查不触发，首节点由引理 4 通过），算法不会中途返回 `false`；树有限，队列最终为空，返回 `true`。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。每个节点恰好入队、出队各一次，每次出队做 $O(1)$ 的两次检查与孩子入队；$n = 10^5$ 下毫秒级完成，远低于周赛时限。
- **空间复杂度**：$O(n)$。队列峰值 = 最宽一层的节点数，满/完全二叉树最底层约 $\lceil n/2 \rceil$，链状退化时 $O(1)$；BFS 无递归栈，不随树高增长（对比 DFS：递归栈最坏 $O(n)$）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool isEvenOddTree(TreeNode* root) {
        queue<TreeNode*> q;
        q.push(root);
        int level = 0;
        while (!q.empty()) {
            int sz = q.size();                            // 快照本层宽度
            int prev = level % 2 == 0 ? 0 : 1000001;      // 哨兵：偶层递增 / 奇层递减
            while (sz--) {
                TreeNode* node = q.front(); q.pop();
                int v = node->val;
                if (v % 2 == level % 2) return false;     // 值与层号奇偶必须相反
                if (level % 2 == 0 ? v <= prev : v >= prev)
                    return false;                         // 严格单调：相等即违规
                prev = v;
                if (node->left)  q.push(node->left);      // 先左后右，保序
                if (node->right) q.push(node->right);
            }
            ++level;
        }
        return true;
    }
};
```

### Python

```python
class Solution:
    def isEvenOddTree(self, root: Optional[TreeNode]) -> bool:
        q, level = deque([root]), 0
        while q:
            prev = 0 if level % 2 == 0 else 10 ** 6       # 哨兵：偶层求递增，奇层求递减
            for _ in range(len(q)):                       # 快照本层宽度
                node = q.popleft()
                v = node.val
                if v % 2 == level % 2:                    # 值与层号奇偶必须相反
                    return False
                ok = v > prev if level % 2 == 0 else v < prev
                if not ok:                                # 严格单调：相等即违规
                    return False
                prev = v
                if node.left:
                    q.append(node.left)                   # 先左后右，保序
                if node.right:
                    q.append(node.right)
            level += 1
        return True
```

> 💡 也有写法用 `INT_MIN / INT_MAX`（或 `float("-inf") / inf`）当哨兵，语义相同——「域外值」即可。DFS 版（前序 + `last[d]` 数组、或先收集层列表再校验）同样 $O(n)$，但链状树递归深度 $10^5$，Python 默认上限 1000 必爆，需 `sys.setrecursionlimit` 或改显式栈；每日题解收录了 BFS / DFS 两版对比，见文末链接。

## 8. 边界情况与易错点

1. **层号从 0 开始**：`level` 初始化为 0。从 1 开始数会把整套奇偶与方向**同时弄反**——`[1]`（应 `true`）会被误判为 `false`。
2. **根节点为偶数**：第 0 层要求奇数，`[2]` 直接 `false`；单节点 `[1]` 为 `true`（单元素层的严格单调平凡成立）。
3. **相等即违规**：示例 2 的 `3, 3` 是「严格」二字最阴的测试点——比较运算符带等号（`v <= prev` 写成放行条件、或判死条件漏掉等号）必错。
4. **哨兵落在值域内**：偶层哨兵取 1 时，首节点恰为 1 会被误杀（$1 \le 1$）；奇层哨兵取 $10^5$ 同理。必须取域外值（0 与 $10^6$、或 $\pm\infty$），或干脆「首节点免单调检查」。
5. **忘记快照 `sz`**：直接 `while q` 逐个出队，孩子入队后又被当作本层处理，层号错位、检查全乱。
6. **入队顺序反了**：先右后左会让同层顺序变成从右到左，非回文层直接误判（引理 3 的前提被破坏）。
7. **递归爆栈**：$n \le 10^5$ 且链状树时 DFS 深度 $10^5$——Python 默认上限 1000 抛 `RecursionError`，C++ 也可能爆栈；BFS 无此患，这也是它作为主解的理由。
8. **奇偶条件取反**：合法是「$v \bmod 2 \ne level \bmod 2$」（偶层要奇、奇层要偶），写成「相等」当合法恰好把条件弄反。
