# LeetCode 找出缺失和重复的数字 题解

## 1. 题目概述

- **标题 / 题号**：找出缺失和重复的数字（#2965，easy）
- **链接**：https://leetcode.cn/problems/find-missing-and-repeated-values/
- **来源**：LeetCode 第 376 场周赛 Q1
- **难度**：简单
- **标签**：数组、哈希表、数学、矩阵

**题意**：一个 $n \times n$ 的矩阵装着 $[1, n^2]$ 内的整数——本应每个数**恰好出现一次**，但有一个数字 $a$ **混进来两次**、一个数字 $b$ **弄丢了**。找出这对「一多一少」，返回 `[a, b]`（$a$ 在前、$b$ 在后）。

**约束**：

- $2 \le n = grid.length = grid[i].length \le 50$，即格子数与值域上界 $m = n^2 \le 2500$
- $1 \le grid[i][j] \le n^2$
- 值域内**恰好一个** $x$ 与矩阵中的两个成员相等（即 $a$ 出现两次）
- 值域内**恰好一个** $x$ 与矩阵中的任何成员都不相等（即 $b$ 缺失）
- 其余每个 $x$ 恰好对应矩阵中的一对 $(i, j)$（出现一次）

> 💡 读题抓三个信号：① 题目只问「哪个值多了、哪个值少了」，**不问它们在矩阵的哪里**——位置信息完全无用，$n \times n$ 矩阵在脑内先**摊平**成 $n^2$ 个数；② 值域是**连续已知**的 $[1, n^2]$ 且上界极小 ⇒ 计数数组（桶）比哈希表更贴；③ 「一个 $\times 2$、一个 $\times 0$」是仅有的两个异常指纹。这是 [645. 错误的集合](https://leetcode.cn/problems/set-mismatch/) 家族的**二维包装版**。

## 2. 示例

```text
输入：grid = [[1,3],[2,2]]
输出：[2,4]
解释：数字 2 重复（两个 2 挤在同一行），数字 4 缺失，所以答案是 [2,4]。
```

**示例 2**

```text
输入：grid = [[9,1,7],[8,9,2],[3,4,6]]
输出：[9,5]
解释：数字 9 重复，数字 5 缺失，所以答案是 [9,5]。
```

**示例 3（自造，验证 $b$ 可以是最小值）**

```text
输入：grid = [[4,2],[2,3]]
输出：[2,1]
解释：数字 2 重复，数字 1 缺失 —— b 可能排在 a 前面，值域必须扫完。
```

## 3. 解题思路

### 3.1 暴力思路

两档朴素做法：

1. **逐值普查 $O(n^4)$**：对每个候选 $v \in [1, m]$ 扫整个矩阵数出现次数——数为 2 的是 $a$，数为 0 的是 $b$。$n = 50$ 时约 $2500 \times 2500 = 6.25 \times 10^6$ 次比较，本题规模下也能过，但矩阵被反复扫了 2500 遍，纯浪费。
2. **排序 $O(n^2 \log n^2)$**：摊平排序后，相邻相等的是 $a$，相邻差为 2 的缺口跳过的是 $b$。为此付一次排序也绕远了。

正解回到本质：「找重复 / 找缺失」只关心**每个值出现了几次**——一遍扫矩阵计数即可，$O(n^2)$；数据结构上再用**值域桶**替代泛型哈希表。

### 3.2 核心观察：摊平 + 值域桶计数

![快速切入：二维是包装，摊平开桶是本分](images/wc376_q1_flatten_concept.svg)

- **观察 1（位置无用，先摊平）**：题目不问 $a$、$b$ 在矩阵的哪里，双层 for 循环把 $n^2$ 个格子读一遍即可，不需要任何坐标技巧。
- **观察 2（值域即下标）**：值全部落在连续的 $[1, m]$（$m = n^2 \le 2500$），开一个长度 $m+1$ 的计数数组 `cnt`，`cnt[v]` 就是值 $v$ 的出现次数——**数组下标当键**，$O(1)$ 访问、零哈希开销。
- **观察 3（两个指纹）**：入桶后，`cnt[v] == 2` 唯一指向 $a$，`cnt[v] == 0` 唯一指向 $b$。第二遍**按序**扫 $v \in [1, m]$，缺失者作为「空桶」天然暴露——这是无序哈希表给不了的便利。

$$\boxed{\ a = \{\, v \mid cnt[v] = 2 \,\},\qquad b = \{\, v \mid cnt[v] = 0 \,\},\qquad v \in [1,\, n^2]\ }$$

### 3.3 算法流程

![算法流程：入桶一遍，查桶一遍](images/wc376_q1_algorithm_flow.svg)

1. **初始化**：长度 $m + 1$（$m = n^2$）的计数数组 `cnt` 全 0；
2. **第一遍 · 入桶**：双层循环摊平矩阵，每读一个值 `v = grid[i][j]` 就 `cnt[v]++`；
3. **第二遍 · 查桶**：$v$ 从 1 到 $m$ 按序逐桶检查——`cnt[v] == 2` 记 `a = v`，`cnt[v] == 0` 记 `b = v`；
4. **收尾**：值域扫完时两问必有答案，返回 `[a, b]`。

### 3.4 示例演算

![示例演算：入桶一遍，查桶一遍](images/wc376_q1_example_walkthrough.svg)

以示例 2（`grid = [[9,1,7],[8,9,2],[3,4,6]]`，$n = 3$，值域 $1..9$）为例，第一遍入桶后：

| $v$ | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 | 9 |
|-----|---|---|---|---|---|---|---|---|---|
| $cnt[v]$ | 1 | 1 | 1 | 1 | **0** | 1 | 1 | 1 | **2** |

第二遍按序查桶：扫到 $v = 5$ 发现空桶 ⇒ $b = 5$；扫到 $v = 9$ 发现两颗球 ⇒ $a = 9$。返回 `[9, 5]` ✓。

示例 1（`[[1,3],[2,2]]`，值域 $1..4$）：`cnt = [1, 2, 1, 0]` ⇒ $a = 2$、$b = 4$，返回 `[2, 4]` ✓。

## 4. 算法细节

1. **桶长开 $m+1$**：下标 $1..m$ 需要 $m+1$ 格，`cnt[0]` 恒空置。开成 $m$ 格会让 `cnt[m]` 越界——恰好 $a = m$ 或 $b = m$ 时当场崩。
2. **两遍扫描缺一不可**：第一遍入桶必须**全部读完**才能下结论（`cnt[v]` 的终值才是出现次数）；第二遍**必须扫完整个值域**——$b$ 可能比 $a$ 小（自造示例 3 中 $b = 1 < a = 2$），找到 $a$ 就 `return` 会答半题。优化写法是 `a`、`b` 都非默认值才 `break`。
3. **摊平方式**：C++ 范围 for 逐行 `for (auto& row : grid) for (int v : row)`；Python 双层 for 或 `collections.Counter` 皆可，显式循环最稳。
4. **备选：数学法 $O(1)$ 空间**。设 $m = n^2$，实际和 $S$、实际平方和 $S_2$ 与期望值的差异全部来自 $a$、$b$：

$$d_1 = S - \frac{m(m+1)}{2} = a - b, \qquad d_2 = \frac{S_2 - \frac{m(m+1)(2m+1)}{6}}{d_1} = \frac{a^2 - b^2}{a - b} = a + b$$

$$a = \frac{d_1 + d_2}{2}, \qquad b = \frac{d_2 - d_1}{2}$$

   $a \ne b$ 保证 $d_1 \ne 0$，除法安全。竞赛视角：计数法代码量最小、最不易错，Q1 首选；数学法留给「不许额外空间」的追问（C++ 记得 `long long`，见第 8 节）。

## 5. 正确性证明

**引理 1（计数指纹）**：入桶结束后，`cnt` 数组满足：恰有一个 $v \in [1, m]$ 使 $cnt[v] = 2$（即 $a$），恰有一个 $v \in [1, m]$ 使 $cnt[v] = 0$（即 $b$），其余均为 1，且 $a \ne b$。

**证明**：题面保证值域内恰有一个 $x$ 与矩阵的**两个**成员相等（出现两次）、恰有一个 $x$ 与**任何**成员都不相等（出现零次）、其余每个 $x$ 恰对应**一对** $(i, j)$（出现一次）。`cnt[v]` 按定义统计值 $v$ 的出现次数，故三种取值结构如上。又 $a$ 至少出现一次而 $b$ 出现零次，二者不可能相等。∎

**引理 2（判定等价）**：第二遍按序扫描中，`cnt[v] == 2` 成立当且仅当 $v = a$；`cnt[v] == 0` 成立当且仅当 $v = b$。

**证明**：由引理 1，`cnt` 中取值 2 的下标唯一（$a$）、取值 0 的下标唯一（$b$），判定条件与身份一一对应。∎

**定理**：算法返回的数组恰为 `[a, b]`。

**证明**：第二遍扫描覆盖 $v \in [1, m]$ 全体，由引理 2，`a` 被赋值恰一次且为重复数字，`b` 被赋值恰一次且为缺失数字；`else if` 保证两个判定互不干扰（`cnt[v]` 不可能同时为 0 和 2）。扫描结束时按 `[a, b]` 顺序组装返回，即所求。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n^2)$。第一遍入桶读 $n^2$ 个格子各一次 $O(1)$ 计数，第二遍查桶扫 $m = n^2$ 个值各一次 $O(1)$ 判定。$n^2$ 个格子每个都可能是重复者，$\Omega(n^2)$ 是读取下界——两遍扫描已贴着下界走。
- **空间复杂度**：$O(n^2)$。计数数组长 $m + 1 = n^2 + 1$ 格（不计输出数组）；若改用第 4 节数学法可降至 $O(1)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> findMissingAndRepeatedValues(vector<vector<int>>& grid) {
        int n = grid.size(), m = n * n;
        vector<int> cnt(m + 1, 0);
        for (auto& row : grid)
            for (int v : row) cnt[v]++;
        int a = -1, b = -1;
        for (int v = 1; v <= m; v++) {
            if (cnt[v] == 2) a = v;
            else if (cnt[v] == 0) b = v;
        }
        return {a, b};
    }
};
```

### Python

```python
class Solution:
    def findMissingAndRepeatedValues(self, grid: List[List[int]]) -> List[int]:
        m = len(grid) ** 2
        cnt = [0] * (m + 1)
        for row in grid:
            for v in row:
                cnt[v] += 1
        a = b = 0
        for v in range(1, m + 1):
            if cnt[v] == 2:
                a = v
            elif cnt[v] == 0:
                b = v
        return [a, b]
```

## 8. 边界情况与易错点

1. **桶开 $m+1$ 而非 $m$**：下标 $1..m$ 需要 $m+1$ 格；开短一格时 `cnt[m]` 越界，恰好 $a = n^2$ 或 $b = n^2$ 的用例会崩（本题 $m \le 2500$，UB 可能「侥幸」不崩，更隐蔽）。
2. **找到 $a$ 不能提前返回**：$b$ 在值域中的位置可能在 $a$ 之前（自造示例 3 中 $b=1 < a=2$），必须扫完值域，或 `a`、`b` 都已赋值才 `break`。
3. **返回顺序固定 `[a, b]`**：重复在前、缺失在后。别把第 415 场 Q1「顺序任意」的肌肉记忆带过来——本题判题按位置校验。
4. **$m = n \times n$，别笔误成 $2n$**；重复的两个 $a$ 可以挤在同一行（示例 1 的 `[2,2]`），双层循环天然覆盖，无需特判。
5. **数学法的溢出坑**：$m = 2500$ 时期望平方和 $\frac{m(m+1)(2m+1)}{6} \approx 5.2 \times 10^9$，超出 32 位 `int` 上限（约 $2.1 \times 10^9$），C++ 累加平方和与中间量必须 `long long`；Python 原生大整数无此虑。
6. **最小规模 $n = 2$**：4 个格子、值域 $1..4$，算法自然覆盖，无需特判。
