# LeetCode 使数组成为等数数组的最小代价 题解

## 1. 题目概述

- **标题 / 题号**：使数组成为等数数组的最小代价（#2967，medium）
- **链接**：https://leetcode.cn/problems/minimum-cost-to-make-array-equalindromic/
- **来源**：LeetCode 第 376 场周赛 Q3
- **难度**：中等
- **标签**：贪心、数组、数学、排序、二分

**题意**：给定整数数组 `nums`。每次操作可任选一个下标 $i$，把 `nums[i]` **加 1 或减 1**。要求把**所有**元素都变成**同一个正回文整数**，返回所需的最少操作次数。

**约束**：

- $1 \le n \le 10^5$
- $1 \le nums[i] \le 10^9$

> 💡 读题抓三个信号：① 操作是 $\pm 1$ 且双向，把 $a_i$ 挪到目标 $t$ 的代价就是 $|a_i - t|$——[LC 462](https://leetcode.cn/problems/minimum-moves-to-equal-array-elements-ii/)「归拢到中位数」的标准模型；② 目标多了一条**回文**限制，中位数本身未必可用，要在回文数集合里挑；③ 回文数在值域里**极其稀疏**（$2\times 10^9$ 内只有约 $1.2\times 10^5$ 个）——「挑」可以直接升级为「全枚举」。本场 Q4（#2968）正是同一套「排序 + 前缀和 + 中位数」的姊妹题。

## 2. 示例

**示例 1**

```text
输入：nums = [1,2,3,4,5]
输出：6
解释：中位数 3 恰好是回文，全部归拢到 3：
      代价 = 2 + 1 + 0 + 1 + 2 = 6。
```

**示例 2**

```text
输入：nums = [10,12,13,14,15]
输出：11
解释：中位数 13 不是回文；左侧最近回文 11 的代价 = 1+1+2+3+4 = 11，
      右侧最近回文 22 的代价 = 12+10+9+8+7 = 46，取 11。
```

**示例 3**

```text
输入：nums = [22,33,22,33,22]
输出：22
解释：排序后 [22,22,22,33,33]，中位数 22 是回文，
      代价 = 两个 33 各挪 11 步 = 22。
```

**示例 4（自造，目标越过 max）**

```text
输入：nums = [1000000000]
输出：1
解释：10^9 不是回文，最近回文是 999999999 与 1000000001，各差 1。
      —— 说明候选回文必须枚举到 2×10^9，不能止步于 max(nums)。
```

**示例 5（自造，全部相同）**

```text
输入：nums = [1000000000, 1000000000]
输出：2
解释：全体一致但值非回文，仍要整体挪到 999999999 或 1000000001，代价 2。
```

## 3. 解题思路

### 3.1 暴力思路

最直观的暴力是**枚举目标值**：把 $t$ 从 $1$ 扫到某个上界，每个 $t$ 用 $O(n)$ 累加 $\sum |a_i - t|$，取最小。

- 上界取 $2 \times 10^9$（为什么是这个见第 5 节）：$2 \times 10^9 \times 10^5 = 2 \times 10^{14}$，直接爆炸；
- 先排序 + 前缀和，把单点代价压到 $O(\log n)$：仍有 $2 \times 10^9 \times 17 \approx 6 \times 10^{10}$，不可行；
- 退一步只枚举 $t \in nums$ 的值也不行——目标**必须是回文**，数组里可能一个回文都没有（示例 4）。

暴力的困境全在「值域太大」。突破口：目标不必是任意整数——**只需是回文数**，而回文数由前半段数字完全决定，个数只有 $O(\sqrt{U})$ 量级。两个爆炸维度（值域、逐点算代价）分别被「枚举回文」和「前缀和 + 二分」化解。

### 3.2 核心观察：代价函数是凸的，候选目标只需是回文

![核心观察：代价函数是凸的，最优回文紧贴中位数](images/wc376_q3_convex_median_concept.svg)

三个观察层层递进：

- **观察 1（凸性）**：$f(t) = \sum_i |a_i - t|$ 是关于 $t$ 的分段线性**凸函数**（每个 $|a_i - t|$ 凸，和非负组合保持凸）。不带回文约束时，最小值在**中位数** $m$ 处取到——这就是 [LC 462](https://leetcode.cn/problems/minimum-moves-to-equal-array-elements-ii/)。
- **观察 2（单峰 ⇒ 候选稀疏）**：凸函数单峰：$f$ 在 $(-\infty, m]$ 上**不增**、在 $[m, +\infty)$ 上**不减**。于是最优回文目标只可能是 $p^-$（$\le m$ 的最大回文）或 $p^+$（$\ge m$ 的最小回文）——离中位数更远的回文代价只会更大。
- **观察 3（回文极稀疏）**：$d$ 位回文由前 $\lceil d/2 \rceil$ 位唯一决定，恰有 $9 \times 10^{\lceil d/2 \rceil - 1}$ 个；值域 $[1, 2\times 10^9]$ 内总共只有 $119{,}998 \approx 1.2 \times 10^5$ 个。全枚举 + 单点 $O(\log n)$ 代价，总运算量约 $2 \times 10^6$。

$$\boxed{\ \text{答案}\ =\ \min_{\substack{p\ \text{是回文}\\ 1 \le p \le 2\times 10^9}}\ \sum_i \big|a_i - p\big|\ }$$

实现上直接全枚举取最小，最稳最快写；「只算 $p^-, p^+$ 两个候选」的精化由第 5 节定理保证，文末延伸再谈。

### 3.3 算法流程：镜像生成回文 + 排序前缀和 + 二分算代价

![算法流程：回文由前半镜像生成，数量级 O(√U)](images/wc376_q3_palindrome_mirror_concept.svg)

1. **排序 + 前缀和**：$pre[i] = $ 前 $i$ 个元素之和，$i = 0..n$；
2. **生成 $[1, 2\times 10^9]$ 内全部回文**：枚举位数 $d = 1..10$ 与前半 `half`，镜像拼接——偶数位拼 `reverse(half)`，奇数位拼「`half` 去掉末位再翻转」。同位数内回文随 `half` 严格递增，超过上界即 `break`；
3. **对每个回文 $p$ 算代价**：二分 $i = \mathrm{lower\_bound}(a, p)$，用 $pre$ 两段 $O(1)$ 拼出 $\sum |a_i - p|$（细节见第 4 节）；
4. 取所有代价的最小值。

### 3.4 示例演算

![示例演算：中位数 13 非回文，左右最近回文 11 与 22 之争](images/wc376_q3_example_walkthrough.svg)

以示例 2 走一遍（排序后 $a = [10,12,13,14,15]$，$pre = [0,10,22,35,49,64]$，中位数 $m = 13$）：

| 目标 $p$ | 代价 $f(p)$ | 备注 |
|---------|-------------|------|
| 8 | $2+4+5+6+7 = 24$ | 左侧远端 |
| 9 | $1+3+4+5+6 = 19$ | 仍偏左 |
| **11** | $1+1+2+3+4 = \mathbf{11}$ | $p^-$，最优 |
| 22 | $12+10+9+8+7 = 46$ | $p^+$，太远 |

最终答案 $11$，对应方案「全部变成 11」。中位数右侧的下一个回文隔了整整 $9$ 个数（14→22），左侧只隔 $2$ 个（13→11）——**回文分布不均匀，左右两侧的最近回文都必须查**。

## 4. 算法细节

**回文生成**。位数 $d$ 的前半长 $h = \lceil d/2 \rceil$，`half` 取遍 $[10^{h-1}, 10^h)$（首位非零）：

- $d$ 偶：`pal = half ‖ reverse(half)`，如 `123 → 123321`；
- $d$ 奇：`pal = half ‖ reverse(half 去掉末位)`，如 `123 → 12321`；$d = 1$ 时后半为空串，`1..9` 自然生成（目标必须是**正**回文，不含 $0$，但 $1$ 永远在候选里，无需特判）。

**上界 $2\times 10^9$ 的来历**。最优目标被「中位数 $m \le 10^9$ 两侧的最近回文」支配（第 5 节定理），而大于 $10^9$ 的最小回文是 $1000000001 \le 2\times 10^9$，所以枚举到 $2\times 10^9$ 必然罩住最优解。实际枚举到 $1.1\times 10^9$ 就够，取 $2\times 10^9$ 图个整。

**代价的 $O(\log n)$ 计算**。排序后二分 $i = \mathrm{lower\_bound}(a, x)$，把数组切成「全 $< x$」的左段 $[0, i)$ 与「全 $\ge x$」的右段 $[i, n)$：

![代价的 O(log n) 计算：二分定位 + 前缀和](images/wc376_q3_prefix_cost_split.svg)

$$\text{cost}_L = x \cdot i - pre[i] \qquad \text{cost}_R = (pre[n] - pre[i]) - x \cdot (n - i)$$

$$\text{cost}(x) = \text{cost}_L + \text{cost}_R$$

等于 $x$ 的元素落在右段贡献恰好为 $0$，用 `lower_bound` / `upper_bound` 结果相同。回文列表本身有序，也可用双指针代替逐个二分（微优化，没有必要）。

**量级**。单项 $x \cdot n$ 最大约 $2\times 10^9 \times 10^5 = 2\times 10^{14}$——C++ 全程 `long long`（函数签名返回值本身就是 `long long`），Python 天然大整数无忧。

## 5. 正确性证明

**引理 1（凸性）**：$f(t) = \sum_{i=1}^{n} |a_i - t|$ 是凸函数。

**证明**：对每个 $i$ 与 $\lambda \in [0, 1]$，由三角不等式
$$\big|a_i - (\lambda s + (1-\lambda)t)\big| = \big|\lambda(a_i - s) + (1-\lambda)(a_i - t)\big| \le \lambda|a_i - s| + (1-\lambda)|a_i - t|,$$
故每个 $t \mapsto |a_i - t|$ 凸；凸函数的非负和仍凸。∎

**引理 2（单峰性）**：设排序后 $m = a\!\left[\lfloor (n-1)/2 \rfloor\right]$（中位数，偶数长取偏左）。则 $f$ 在 $(-\infty, m]$ 上不增、在 $[m, +\infty)$ 上不减；且 $f(m)$ 是 $f$ 在实数上的最小值。

**证明**：考察 $t$ 从小到大移动。在不含任何 $a_i$ 的开区间上 $f$ 是线性的，斜率为 $L - R$，其中 $L = \#\{a_i < t\}$，$R = \#\{a_i > t\}$。$t$ 增大时 $L$ 不减、$R$ 不增，斜率单调不减（顺带再证了引理 1）。记 $k = \lfloor (n-1)/2 \rfloor$：

- 当 $t < m$：$L \le \#\{a_i < m\} \le k$，而 $R \ge \#\{a_i \ge m\} \ge n - k$。$n = 2j$ 时 $L \le j-1 < j+1 \le R$；$n = 2j+1$ 时 $L \le j < j+1 \le R$。斜率恒负，$f$ 在 $(-\infty, m]$ 上严格递减；
- 当 $t > m$：$L \ge \#\{a_i \le m\} \ge k+1 \ge n/2 \ge \#\{a_i > m\} \ge R$。斜率非负，$f$ 在 $[m, +\infty)$ 上不减（偶数长时两个中位元素之间斜率为 $0$，正好是平底）。

两段合起来，谷底在 $m$（以及偶数长时的整个中位区间）处。∎

**定理（枚举正确性）**：设 $\mathcal{P}_2 = \{p : p \text{ 为回文},\ 1 \le p \le 2\times 10^9\}$，则 $\min_{p \in \mathcal{P}_2} f(p)$ 即答案。

**证明**：一方面，$\mathcal{P}_2$ 中每个 $p$ 都对应一个合法方案（把每个元素逐步挪到 $p$），故枚举最小值 $\ge$ 真实最优 $\text{ans}^*$。另一方面，设最优目标为回文 $p^*$：

- 若 $p^* \le m$：取 $p^- = $ $\le m$ 的最大回文（存在：$1$ 是回文且 $1 \le m$）。由引理 2 与 $p^- \ge p^*$（同在 $m$ 左侧，$p^-$ 更靠右）得 $f(p^-) \le f(p^*)$，而 $p^- \le m \le 10^9$，故 $p^- \in \mathcal{P}_2$；
- 若 $p^* > m$：取 $p^+ = $ $\ge m$ 的最小回文（存在：$1000000001$ 是回文且 $> 10^9 \ge m$，且 $p^+ \le 1000000001 \le 2\times 10^9$）。由引理 2 与 $p^+ \le p^*$ 得 $f(p^+) \le f(p^*)$，故 $p^+ \in \mathcal{P}_2$。

两种情况都给出 $\mathcal{P}_2$ 中一个代价不劣于 $p^*$ 的候选，于是 $\min_{\mathcal{P}_2} f \le \text{ans}^*$。两向合围，等号成立。∎

**推论（两候选）**：$\text{ans} = \min\big(f(p^-),\, f(p^+)\big)$——证明已含于定理。∎

**代价公式正确性**：排序后 $\mathrm{lower\_bound}$ 恰把数组按「$< x$ / $\ge x$」切成两段，左段和为 $pre[i]$、右段和为 $pre[n] - pre[i]$，逐元素求 $|a_i - x|$ 的和即两段「目标和减实际和」之和。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \log n + P \log n)$，其中 $P = 119{,}998 \approx 1.2\times 10^5$ 是 $[1, 2\times 10^9]$ 内回文个数
  - 排序 $O(n \log n)$；
  - 前缀和 $O(n)$；
  - 回文生成 $O(P)$（字符串拼接常数开销）；
  - 逐回文二分定位 + $O(1)$ 拼代价：$O(P \log n) \approx 2\times 10^6$。
  - $n = 10^5$ 时排序约 $1.7\times 10^6$ 次比较，与枚举部分同量级，整体轻松通过（实测 Python 约 0.2s）。
- **空间复杂度**：$O(n + P)$
  - 前缀和 $O(n)$；回文列表 $O(P)$（若边生成边评价可省去列表，但存下来写法更清晰、也便于「两候选」变体复用）。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    long long minimumCost(vector<int>& nums) {
        int n = nums.size();
        sort(nums.begin(), nums.end());

        vector<long long> pre(n + 1);
        for (int i = 0; i < n; ++i)
            pre[i + 1] = pre[i] + nums[i];

        auto cost = [&](long long x) {
            int i = lower_bound(nums.begin(), nums.end(), x) - nums.begin();
            return x * i - pre[i] + (pre[n] - pre[i]) - x * (n - i);
        };

        long long ans = LLONG_MAX;
        for (int d = 1; d <= 10; ++d) {           // 回文位数
            int h = (d + 1) / 2;                   // 前半长度
            long long lo = 1;
            for (int i = 1; i < h; ++i) lo *= 10;
            for (long long half = lo; half < lo * 10; ++half) {
                string s = to_string(half), t = s;
                if (d % 2 == 0) reverse(t.begin(), t.end());
                else { t.pop_back(); reverse(t.begin(), t.end()); }
                long long p = stoll(s + t);
                if (p > 2000000000LL) break;       // 同位数随 half 递增，可 break
                ans = min(ans, cost(p));
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def minimumCost(self, nums: List[int]) -> int:
        nums.sort()
        n = len(nums)
        pre = [0] * (n + 1)
        for i, x in enumerate(nums):
            pre[i + 1] = pre[i] + x

        def cost(x: int) -> int:
            i = bisect_left(nums, x)
            return x * i - pre[i] + (pre[n] - pre[i]) - x * (n - i)

        ans = inf
        for d in range(1, 11):                     # 回文位数
            h = (d + 1) // 2                       # 前半长度
            for half in range(10 ** (h - 1), 10 ** h):
                s = str(half)
                if d % 2 == 0:
                    p = int(s + s[::-1])
                else:
                    p = int(s + s[-2::-1])         # 去掉末位再翻转；d=1 时为空串
                if p > 2 * 10 ** 9:
                    break
                ans = min(ans, cost(p))
        return ans
```

## 8. 边界情况与易错点

1. **回文枚举上界（本题主坑）**：只枚举到 $\max(nums)$ 或 $10^9$ 会 WA——`nums = [10^9]` 的答案是 $1$（目标 $999999999$ 或 $1000000001$，后者越过 $\max$）。必须罩住中位数右侧的最近回文，枚举到 $2\times 10^9$ 最稳。
2. **整数溢出**：代价最大约 $(2\times 10^9 - 1) \times 10^5 = 2\times 10^{14}$，`x * i`、前缀和全部超 `int`；C++ 全程 `long long`，返回值签名本身就是 `long long`，拿 `int` 接会当场溢出。
3. **$d = 1$ 的回文**：奇数位「去掉末位再翻转」对单字符得到空串，`1..9` 自然生成；手写生成器时别把一位数漏掉或错写成 $0$（目标是**正**回文，$1$ 永远是候选，无需特判空集）。
4. **中位数是回文 ≠ 答案为 0**：示例 3 中位数 $22$ 是回文，但代价是其余元素到 $22$ 的距离和 $22$。看到中位数回文就直接输出 $0$ 是典型 WA 点。
5. **`lower_bound` / `upper_bound` 均可**：等于 $x$ 的元素在左段贡献 $x - x = 0$、在右段贡献 $0$，两边公式都对，不必纠结。
6. **生成顺序与 `break`**：同位数内回文随 `half` 严格递增，超上界可 `break`；跨位数天然有序（$999999999 < 1000000001$），外层循环 $d = 1..10$ 不会乱序。
7. **$n = 1$ / 全部相同**：全枚举自动覆盖（到最近回文的距离 / 整体平移距离），无需特判。
8. **别先入为主套 Q4 的滑窗**：本题没有「预算 $k$」、目标是全体一致，滑窗无用武之地；真正同构的是「排序 + 前缀和 + 中位数」那一半。

**延伸思考**：

- **两候选写法**：由推论，生成回文表后只需 `bisect` 出 $p^-, p^+$ 各算一次代价；更进一步用 [LC 564](https://leetcode.cn/problems/find-the-closest-palindrome/) 的「镜像 + 进位边界」技术直接构造中位数附近的最近回文，连 $O(P)$ 的回文表都不用建，整体 $O(n \log n)$——适合当作枚举写法的交叉验证。
- **目标换成其它稀疏集合**（质数、$2$ 的幂、斐波那契数……）：框架不变——凸代价函数 + 稀疏候选集全枚举（或只查离最优点最近的几个），这是「带约束的归拢问题」的通用套路。
- **若代价改成平方** $|a_i - t|^2$：仍是凸函数，无约束最优解从「中位数」变为「均值」，候选变为均值附近的回文，枚举框架照搬。
- **若允许每个元素各自变成任意回文**：问题退化成「每个元素独立找最近回文」，与本题「统一目标」完全两回事——赛场上认清这一点能避免往错误方向套模型。
