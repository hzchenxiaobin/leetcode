# LeetCode 划分数组并满足最大差限制 题解

## 1. 题目概述

- **标题 / 题号**：划分数组并满足最大差限制（#2966，medium）
- **链接**：https://leetcode.cn/problems/divide-array-into-arrays-with-max-difference/
- **来源**：LeetCode 第 376 场周赛 Q2
- **难度**：中等
- **标签**：贪心、数组、排序

**题意**：给一个长度为 $n$（$3$ 的倍数）的整数数组 `nums` 和正整数 $k$，把它切成 $n/3$ 个**长度恰为 3** 的子数组，要求每个子数组内**任意两个**元素的差都 $\le k$。返回任意一种合法切法；若切不出来，返回空数组。

**约束**：

- $1 \le n \le 10^5$，且 $n$ 是 $3$ 的倍数
- $1 \le nums[i] \le 10^5$
- $1 \le k \le 10^5$

> 💡 读题抓三个信号：① 「任意两个元素的差 $\le k$」看着要对每组的 $\binom{3}{2}=3$ 对元素逐一检查，其实是烟雾弹——它**等价于组内极差 $\max-\min \le k$**，一次比较顶三次；② 「返回任意一个」意味着**构造与判定可以合一**：与其在解空间里搜索，不如直接造一个「要么是解、要么证明无解」的候选；③ 每组**恰好 3 个**、$n$ 又是 3 的倍数 ⇒ 排序后按步长 3 切，天然对齐、永不越界。这是「排序贪心分组」家族的标准形态，Q2 套路题的典型面孔。

## 2. 示例

**示例 1**

```text
输入：nums = [1,3,4,8,7,9,3,5,1], k = 2
输出：[[1,1,3],[3,4,5],[7,8,9]]
解释：每个数组中任何两个元素之间的差都小于或等于 2。
```

**示例 2**

```text
输入：nums = [2,4,2,2,5,2], k = 2
输出：[]
解释：四个 2 无论怎么分，都会有一组同时装下 2 和 5，而 5 − 2 = 3 > k，
     仅有的两种划分方式 [[2,2,2],[2,4,5]] 与 [[2,2,4],[2,2,5]] 全部失败。
```

**示例 3**

```text
输入：nums = [4,2,9,8,2,12,7,12,10,5,8,5,5,7,9,2,5,11], k = 14
输出：[[2,2,2],[4,5,5],[5,5,7],[7,8,8],[9,9,10],[11,12,12]]
解释：k 很宽裕，顺序分组逐组通过。
```

**示例 4（自造，最小规模 $n=3$）**

```text
输入：nums = [1,5,9], k = 3
输出：[]
解释：唯一的分组就是整组 [1,5,9]，极差 8 > 3——n = 3 也要走完同一套判定。
```

## 3. 解题思路

### 3.1 暴力思路

最朴素的做法是**枚举划分方案**：从 $n$ 个数里挑 3 个当第一组，再从剩下 $n-3$ 个里挑 3 个当第二组……方案总数为

$$\frac{n!}{(3!)^{n/3}\,(n/3)!}$$

$n = 10^5$ 时这是 $10^5$ 阶乘级别的天文数字；即便写成 DFS + 回溯（每次给当前未归组的全局最小元素配两个搭档），最坏情形下的分支仍然指数级爆炸。暴力的困境在于：**乱序数组里「谁和谁差得远」完全不可见**，只能靠穷举去撞。

突破口藏在题面的两个细节里：约束「差 $\le k$」是**区间型相容关系**（值相近者天然相容），而题目只要求**任意一个**解——排序一把，相容结构就会在数轴上显形。

### 3.2 核心观察：排序 + 顺序三分组

![核心观察：排序后连续三个一组，只查首尾差](images/wc376_q2_sort_group_concept.svg)

三个观察层层递进：

- **观察 1（极差等价）**：组内任意两元素的差 $\le k$ $\iff$ 组内极差 $\max-\min \le k$。任一对元素的差都不超过极差，而极差本身恰是某一对元素的差——**一次比较顶三次**。
- **观察 2（顺序三分）**：数组排成非降序 $a_0 \le a_1 \le \cdots \le a_{n-1}$ 后，每 **3 个连续**元素绑成一组。组内最小值恰是 $a_i$、最大值恰是 $a_{i+2}$，组是否合法只看一处：$a_{i+2} - a_i \le k$。
- **观察 3（失败即无解）**：这是贪心正确性的命门——若某组 $a_{3j+2} - a_{3j} > k$，则**任何**划分方案都不可能合法，「返回空数组」不是启发式的猜测，而是定理（第 5 节给出计数证明）。直觉上：把最小的数和尽量小的数绑在一起，是**不浪费差预算**的装法；顺序分组若都装不下，别的装法只会更浪费。

$$\boxed{\ \text{存在合法划分}\ \iff\ \text{排序后顺序三分组逐组通过}\ a_{3j+2}-a_{3j} \le k\ }$$

> 💡 一句话：**顺序三分组要么直接是答案，要么证明答案不存在**——它同时解决了「构造」与「判定」两件事，这是排序贪心题最舒服的形态。

### 3.3 算法流程

![算法流程：排序后步长 3 扫描，一票否决](images/wc376_q2_algorithm_flow.svg)

1. **排序**：将 `nums` 原地排成非降序；
2. **逐组扫描**：$i$ 从 $0$ 起、步长 $3$——若 `nums[i+2] - nums[i] > k`，**立即**返回空数组；
3. **收录**：否则把 `[nums[i], nums[i+1], nums[i+2]]` 加入答案；
4. **收尾**：$i$ 扫到 $n$ 说明全部组通过，返回答案。

> ⚠️ 两个高频手误：① 去比较 `nums[i+1] - nums[i]`（相邻差）——相邻差小推不出极差小，反例见第 8 节；② 某组失败后还继续扫描——失败即无解（观察 3），必须当场返回空。

### 3.4 示例演算

![示例演算：一次成功与一次无解](images/wc376_q2_example_walkthrough.svg)

**示例 1**（`nums = [1,3,4,8,7,9,3,5,1]`，$k=2$）：排序后 `[1,1,3,3,4,5,7,8,9]`，切成三组：

| 组 | 元素 | 首尾差 | 判定 |
|----|------|--------|------|
| 0 | `[1,1,3]` | $3-1=2 \le 2$ | ✓ |
| 1 | `[3,4,5]` | $5-3=2 \le 2$ | ✓ |
| 2 | `[7,8,9]` | $9-7=2 \le 2$ | ✓ |

返回 `[[1,1,3],[3,4,5],[7,8,9]]` ✓。

**示例 2**（`nums = [2,4,2,2,5,2]`，$k=2$）：排序后 `[2,2,2,2,4,5]`：

| 组 | 元素 | 首尾差 | 判定 |
|----|------|--------|------|
| 0 | `[2,2,2]` | $2-2=0 \le 2$ | ✓ |
| 1 | `[2,4,5]` | $5-2=3 > 2$ | ✗ |

第二组失败 ⇒ 返回 `[]` ✓。这正是四个 2 的困境：它们必须摊进两个组，剩下的大数 $4, 5$ 无论塞给哪个组，都与该组里的 2 拉开 $3 > k$ 的差——顺序分组第一时间把这暴露了出来。

## 4. 算法细节

1. **极差判定压比较**：组内合法 $\iff$ `nums[i+2] - nums[i] <= k`（引理 1 的工程面）。每组一次比较、$n/3$ 组共 $n/3$ 次，扫描成本贴着读写下界。
2. **失败即返回是「判定」不是「剪枝」**：依据是第 5 节定理的逆否方向——顺序分组失败 ⟹ 全局无解。所以循环里 `return {}` 放心写，不存在「换个分法也许能行」的侥幸。
3. **原地排序 + 步长循环**：`sort(nums)` 原地打乱输入（题目不依赖原顺序），`for (i = 0; i < n; i += 3)` 步长对齐 $3 \mid n$，`i+1`、`i+2` 永不越界；C++ 预先 `reserve(n/3)` 免去 vector 反复扩容。
4. **无需任何回溯或多方案枚举**：排序之后候选划分**唯一**（顺序三分组是唯一的贪心候选），解空间从组合级塌缩成单个方案——这是「构造与判定合一」的全部含义。
5. **数据结构极简**：不需要哈希表、堆或并查集，一次排序承担全部结构信息；值域虽已知（$1 \le nums[i] \le 10^5$）可换计数排序 $O(n+V)$，但 $n$ 与 $V$ 同量级，收益趋近于零，比赛写比较排序最稳。

## 5. 正确性证明

![无解证明：低高元素计数出矛盾](images/wc376_q2_counting_proof.svg)

设排序后 $a_0 \le a_1 \le \cdots \le a_{n-1}$，$n = 3m$（共 $m$ 组）。

**引理 1（极差判定）**：三元组 $\{x, y, z\}$ 满足「任意两元素差 $\le k$」 $\iff$ $\max\{x,y,z\} - \min\{x,y,z\} \le k$。

**证明**：（⇒）$\max$ 与 $\min$ 本身就是组内两个元素，其差 $\le k$；（⇐）任两元素之差均不超过 $\max - \min \le k$。∎

**引理 2（低高不相容）**：若 $a_{3i+2} - a_{3i} > k$，则任何**值 $\le a_{3i}$** 的元素与任何**值 $\ge a_{3i+2}$** 的元素不能同组。

**证明**：二者之差 $\ge a_{3i+2} - a_{3i} > k$，违反组约束。∎

**引理 3（组数下界）**：设存在合法划分 $P$。称值 $\le a_{3i}$ 的元素为**低元素**、值 $\ge a_{3i+2}$ 的元素为**高元素**，则：

（a）$P$ 中含低元素的组数 $\ge i+1$；（b）$P$ 中含高元素的组数 $\ge m-i$；（c）这两类组互不相交。

**证明**：（a）由排序，下标 $\le 3i$ 的元素 $a_0, \ldots, a_{3i}$ 全部是低元素，共 $3i+1$ 个；每组至多容纳 3 个低元素，故含低元素的组数 $\ge \left\lceil \frac{3i+1}{3} \right\rceil = i+1$。（b）同理，下标 $\ge 3i+2$ 的元素全部是高元素，共 $n - (3i+2) = 3m - 3i - 2 = 3(m-i-1)+1$ 个，故含高元素的组数 $\ge \left\lceil \frac{3(m-i-1)+1}{3} \right\rceil = m-i$。（c）由引理 2，一个组不能同时含低元素与高元素。∎

**定理（判定等价）**：存在合法划分 $\iff$ 排序后顺序三分组逐组满足 $a_{3j+2} - a_{3j} \le k$。

**证明**：（⇐）顺序分组中每组的最小、最大元素恰为首尾 $a_{3j}, a_{3j+2}$，极差 $= a_{3j+2} - a_{3j} \le k$，由引理 1 每组合法，顺序分组即合法划分。（⇒）证逆否命题。设存在 $i$ 使 $a_{3i+2} - a_{3i} > k$ 且合法划分 $P$ 存在。$P$ 恰有 $m$ 个组，由引理 3，其中含低元素的组 $\ge i+1$ 个、含高元素的组 $\ge m-i$ 个且两类不交，故

$$m \;\ge\; (i+1) + (m-i) \;=\; m+1,$$

矛盾。∎

**推论**：算法（排序 → 顺序分组 → 逐组检查）在全部通过时返回合法划分，在任一组失败时正确报告无解。

> 💡 证明的核心是**鸽笼计数**：失效组 $a_{3i+2} - a_{3i} > k$ 像一道「断层」，把数轴切成低、高两半，两半元素互相不能同组；而低元素多到必须占 $i+1$ 个组、高元素多到必须占 $m-i$ 个组，加起来比总组数 $m$ 还多一组——装不下，无解。

## 6. 复杂度分析

- **时间复杂度**：$O(n \log n)$。排序主导 $O(n \log n)$；分组扫描 $O(n)$——共 $n/3$ 组、每组一次比较。$n \le 10^5$ 时排序约 $1.7 \times 10^6$ 次比较，毫秒级。
- **空间复杂度**：$O(\log n)$，为 C++ `std::sort`（introsort）的递归栈开销（Python timsort 另需 $O(n)$ 辅助缓冲）；输出数组 $O(n)$ 按惯例不计入。原地复用排序后的 `nums`，无任何额外结构。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<vector<int>> divideArray(vector<int>& nums, int k) {
        sort(nums.begin(), nums.end());
        int n = nums.size();
        vector<vector<int>> ans;
        ans.reserve(n / 3);
        for (int i = 0; i < n; i += 3) {
            if (nums[i + 2] - nums[i] > k) return {};
            ans.push_back({nums[i], nums[i + 1], nums[i + 2]});
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def divideArray(self, nums: List[int], k: int) -> List[List[int]]:
        nums.sort()
        ans = []
        for i in range(0, len(nums), 3):
            if nums[i + 2] - nums[i] > k:
                return []
            ans.append([nums[i], nums[i + 1], nums[i + 2]])
        return ans
```

## 8. 边界情况与易错点

1. **失败条件是 `> k` 不是 `>= k`**：题面说「小于**或等于** $k$」合法——首尾差恰好等于 $k$ 的组是**压线合法**（示例 1 三组全部 $2 = k$）。写成 `>=` 会把压线组误杀。
2. **查首尾差，不是相邻差**：`nums[i+1] - nums[i]` 达标推不出极差达标。反例：$k=1$、组 $[1,2,3]$——相邻差 $1,1$ 均 $\le k$，极差却是 $2 > k$。极差要**跨两个格子**看 `nums[i+2] - nums[i]`。
3. **失败立即返回空**：任一组失败即无解（定理），不要继续扫完凑答案，更不要尝试「重试别的分组」——顺序分组之外没有别的候选。
4. **步长必须是 3**：循环写成 `i++` 会把交错分组当成顺序分组，既漏判又数组越界；$3 \mid n$ 保证步长 3 恰好切完。
5. **最小规模 $n=3$**：单组也要走完整判定（自造示例 4）；全相等数组极差恒 0，天然全通过。
6. **无溢出风险**：$nums[i], k \le 10^5$，首尾差至多 $10^5 - 1$，`int` 绰绰有余——与 Q1 的数学法必须 `long long` 形成对照，这题不用换类型。
7. **空答案的表示**：C++ 返回 `{}`（空的 `vector<vector<int>>`），Python 返回 `[]`；不要返回 `[[]]` 或含空组的结构。
8. **顺序无要求**：组间顺序、组内顺序均任意（题目「多个答案返回任意一个」），判题只验证合法性，无需排序输出、无需去重。
