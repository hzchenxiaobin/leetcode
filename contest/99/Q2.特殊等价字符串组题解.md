# LeetCode 特殊等价字符串组 题解

## 1. 题目概述

- **标题 / 题号**：特殊等价字符串组（#893，medium）
- **链接**：https://leetcode.cn/problems/groups-of-special-equivalent-strings/
- **来源**：LeetCode 第 99 场周赛 Q2
- **难度**：中等
- **标签**：数组、哈希表、字符串、排序

**题意**：允许的操作是：交换某个字符串中**任意两个偶数下标**的字符，或**任意两个奇数下标**的字符。若两个字符串能经过任意多次操作变得相同，则称它们**特殊等价**。给定长度相同的字符串数组 `words`，返回其中特殊等价类的个数（每个类中的字符串涵盖该类下所有可达字符串）。

**约束**：

- $1 \le \text{words.length} \le 1000$
- $1 \le \text{words}[i]\text{.length} \le 20$，所有字符串等长
- 只含小写英文字母

## 2. 示例

**示例 1**

```text
输入：words = ["abcd","cdab","cbad","xyzz","zzxy","zzyx"]
输出：3
解释：三组分别是 ["abcd","cdab","cbad"]、["xyzz","zzxy"]、["zzyx"]。
      注意 "zzxy" 与 "zzyx" 并不特殊等价。
```

**示例 2**

```text
输入：words = ["abc","acb","bac","bca","cab","cba"]
输出：3
解释：三组 ["abc","cba"]、["acb","bca"]、["bac","cab"]：
      偶数位(0,2)与奇数位(1)各自的多重集相同者才同组。
```

## 3. 解题思路

### 3.1 暴力思路

从每个字符串出发做 BFS/DFS：每次枚举所有「同奇偶性的字符对」交换，把新串入队，直到闭包不再扩大，闭包大小即该等价类的可达集；再对未访问的字符串继续。单次闭包规模可达 $(L/2)! \cdot (L/2)!$ 级别（$L = 20$ 时约 $10! \cdot 10! \approx 1.3\times10^{13}$），完全不可行。

### 3.2 核心观察：交换只在同奇偶性下标内进行 ⇒ 两个多重集是全部不变量

![奇偶位置分组与签名](images/wc99_q2_parity_concept.svg)

关键点：一次交换的两个下标**奇偶性相同**，所以：

1. 偶数下标上的字符**永远留在偶数下标**，奇数下标同理；
2. 同奇偶性内部可以任意置换（相邻交换即可生成对称群），因此这些字符的**排列顺序**完全不重要，只有**多重集**重要。

于是每个字符串都可以压成一个签名：

$$\text{signature}(w) = \big(\text{sort}(w[0::2]),\ \text{sort}(w[1::2])\big)$$

两个字符串特殊等价 $\iff$ 签名相同。答案就是不同签名的个数。

### 3.3 算法流程

![算法流程：签名 + 哈希去重](images/wc99_q2_signature_flow.svg)

```text
kinds = 空集合
for w in words:
    even = sorted(w 的偶数位字符)
    odd  = sorted(w 的奇数位字符)
    kinds.insert(even + "|" + odd)
return |kinds|
```

`"|"` 分隔符保证不会把 `("ab","c")` 与 `("a","bc")` 混淆（若直接拼接会撞车）。

### 3.4 示例演算

![示例演算：三组](images/wc99_q2_walkthrough.svg)

对示例 1 逐个算签名：

| 单词 | 偶数位 | 排序 | 奇数位 | 排序 | 签名 |
|------|--------|------|--------|------|------|
| abcd | ac | ac | bd | bd | `ac\|bd` |
| cdab | ca | ac | db | bd | `ac\|bd` |
| cbad | ca | ac | bd | bd | `ac\|bd` |
| xyzz | xz | xz | yz | yz | `xz\|yz` |
| zzxy | zx | xz | zy | yz | `xz\|yz` |
| zzyx | zy | yz | zx | xz | `yz\|xz` |

前三个签名相同 → 一组；`xyzz`、`zzxy` 一组；`zzyx` 的签名是 `yz|xz`，与前两者都不同 → 单独一组。共 3 组，与题意一致。

## 4. 算法细节

1. **分隔符不能省**：`even + odd` 直接相连时，长度相同也可能产生歧义（例如 `("ab","c")` 与 `("a","bc")` 都得到 `"abc"`）。虽然本题所有单词等长、两段长度由奇偶位置固定，仍建议保留分隔符，稳健且不增加成本。
2. **只需排序，不需要真去交换**：同奇偶性的字符可以任意置换，排序后的字符串就是该多重集的规范代表元。
3. **哈希集合去重**：`unordered_set<string>` / `set` 都可以；用 `set` 能顺便得到有序签名，但没必要。
4. **复杂度**：每个单词取奇偶两段 $O(L)$，两段排序 $O(L \log L)$，插入哈希 $O(L)$；总 $O(N L \log L)$。
5. **长度都是偶数还是奇数**：`w[0::2]` 与 `w[1::2]` 自动适配，无需特判；奇数长度时偶数位比奇数位多一个，签名仍然唯一。
6. **等价关系三性质**：自反、对称、传递都成立（签名相同是等价关系），所以「分组」与「去重」是同一件事。

## 5. 正确性证明

记 $E(w)$、$O(w)$ 分别为 $w$ 的偶数位、奇数位字符组成的**多重集**。

**引理 1（不变量）**：任何允许的操作都不改变 $E(w)$ 与 $O(w)$。

**证明**：操作交换两个偶数下标的字符，只是把 $E(w)$ 中两个元素互换位置，多重集不变；交换两个奇数下标同理。操作前后 $E$、$O$ 都不变，故任意多次操作后仍不变。∎

**引理 2（可达性）**：若 $E(w) = E(w')$ 且 $O(w) = O(w')$，且 $|w| = |w'|$，则 $w$ 可经允许的操作变成 $w'$。

**证明**：把 $w$ 的偶数位视为一个序列 $a_0, a_2, \dots$，其多重集与 $w'$ 的偶数位序列 $a'_0, a'_2, \dots$ 相同。多重集相同意味着存在一个双射把 $a$ 的每个位置映到 $a'$ 的对应位置；而任意置换都可以分解为若干次**对换**，每次对换正是「交换两个偶数下标字符」这一允许操作。因此可以先用允许操作把偶数位逐个归位。奇数位同理（操作独立、互不干扰）。归位后 $w$ 与 $w'$ 完全相同。∎

**引理 3（签名相同 ⇔ 等价）**：$w$ 与 $w'$ 特殊等价 $\iff$ $(E(w), O(w)) = (E(w'), O(w'))$。

**证明**：必要性由引理 1；充分性由引理 2（多重集相同即签名相同，因为签名就是两段多重集排序后的字符串表示）。∎

**定理**：算法返回的 `kinds` 大小等于 `words` 中特殊等价类的个数。

**证明**：由引理 3，签名相同是特殊等价的充要条件，因此签名把 `words` 精确划分成等价类，每个类恰有一个签名。算法对每个单词计算签名并放入集合，集合元素个数就是不同签名数，也就是等价类数。∎

## 6. 复杂度分析

- **时间**：$O(N \cdot L \log L)$，其中 $N \le 1000$、$L \le 20$。拆分 $O(L)$，两次排序各 $O(L\log L)$，字符串拼接与哈希 $O(L)$。
- **空间**：$O(N \cdot L)$ 存储签名集合；排序临时空间 $O(L)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int numSpecialEquivGroups(vector<string>& words) {
        unordered_set<string> kinds;
        for (const string& w : words) {
            string even, odd;
            for (int i = 0; i < (int)w.size(); i++) {
                (i % 2 == 0 ? even : odd).push_back(w[i]);
            }
            sort(even.begin(), even.end());   // 偶数位字符可任意重排
            sort(odd.begin(), odd.end());     // 奇数位字符可任意重排
            kinds.insert(even + "|" + odd);   // 规范化签名
        }
        return (int)kinds.size();
    }
};
```

### Python

```python
class Solution:
    def numSpecialEquivGroups(self, words: List[str]) -> int:
        def signature(w: str) -> tuple:
            even = sorted(w[0::2])      # 偶数位字符可任意重排
            odd = sorted(w[1::2])       # 奇数位字符可任意重排
            return ("".join(even), "".join(odd))

        return len({signature(w) for w in words})
```

## 8. 边界情况与易错点

1. **签名的顺序敏感**：`("xz","yz")` 与 `("yz","xz")` 是不同签名（如 `zzxy` 与 `zzyx`），不能把两段再拼成一个字符串排序，否则会误判为同组。
2. **不要把所有字符一起排序**：那样会忽略奇偶位置约束，示例 1 的 6 个词会被判成 2 组左右。
3. **长度 1**：`w[1::2]` 为空串，签名退化为 `(唯一字符, "")`，仍然正确。
4. **重复单词**：完全相同的单词签名必然相同，集合自动去重，不需要额外处理。
5. **分隔符**：直接用 `even + odd` 拼接在本题（等长、切分位置固定）不会错，但加上分隔符更安全，也给判题之外的重用留了余地。
6. **字符集**：只含小写字母时也可以把签名压成 26 个计数拼接，但排序写法更短且通用。
7. **不要真的做 BFS 展开**：可达状态是指数级的，必须用「多重集不变量」直接判定。
