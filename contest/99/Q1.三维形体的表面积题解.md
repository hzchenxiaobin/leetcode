# LeetCode 三维形体的表面积 题解

## 1. 题目概述

- **标题 / 题号**：三维形体的表面积（#892，easy）
- **链接**：https://leetcode.cn/problems/surface-area-of-3d-shapes/
- **来源**：LeetCode 第 99 场周赛 Q1
- **难度**：简单
- **标签**：几何、数组、数学、矩阵

**题意**：有一个 $n \times n$ 的网格，`grid[i][j]` 表示在格子 $(i,j)$ 上竖直叠放的 $1\times1\times1$ 立方体个数。相邻（上下左右）立方体会**粘在一起**，求最终所有形体的**总表面积**，注意**底面也要计入**。

**约束**：

- $n = \text{grid.length} = \text{grid}[i]\text{.length}$，$1 \le n \le 50$
- $0 \le \text{grid}[i][j] \le 50$

> 💡 表面积只与「暴露在空气中的面」有关：两个立方体贴合的那一面互相抵消，不再计入。

## 2. 示例

**示例 1**

```text
输入：grid = [[1,2],[3,4]]
输出：34
解释：四根柱子高度 1、2、3、4，逐格算贡献为 4 + 7 + 10 + 13 = 34。
```

**示例 2**

```text
输入：grid = [[1,1,1],[1,0,1],[1,1,1]]
输出：32
解释：中间是空的"环"，8 根高度 1 的柱子；每根贡献 2 + 4 个侧面 = 6，但相邻处各抵消 1 面，
      总表面积为 8 × 4（顶底）+ 外围 16 面 + 内圈 8 面 = 32。
```

**示例 3**

```text
输入：grid = [[2,2,2],[2,1,2],[2,2,2]]
输出：46
```

## 3. 解题思路

### 3.1 暴力思路

把每个立方体当成独立个体：总共 $n^2 \cdot h$ 个（最多 $2500 \times 50 = 1.25 \times 10^5$），对每个立方体数它 6 个方向上有多少面没被邻居挡住。这种做法正确且能过（$1.25\times10^5 \times 6$），但需要显式维护三维占用信息；如果高度范围变大就不可行。

### 3.2 核心观察：表面积 = 顶底 + 相邻高度差 + 边界高度

![顶底面 + 侧面高度差](images/wc99_q1_faces_concept.svg)

按「每根柱子」拆解贡献：

1. **顶面 + 底面**：只要 `grid[i][j] > 0`，就贡献 $2$ 个水平面（最顶上 1 个 + 最底下 1 个）。
2. **侧面**：一根柱子向某个方向看，若邻居高度为 $h'$，则被挡住的部分是 $\min(h, h')$ 个面，**露出来**的是 $h - \min(h,h') = \max(0, h - h')$ 个面。边界之外视为 $h' = 0$，公式同样成立。

于是

$$\text{表面积} = \sum_{(i,j):\,h>0} 2 \;+\; \sum_{(i,j)} \sum_{\text{四方向}} \max(0,\, h_{ij} - h_{\text{邻居}})$$

这就是一次 $O(n^2)$ 的双重循环，每个格子看 4 个邻居，常数极小。

### 3.3 算法流程

![算法流程](images/wc99_q1_delta_flow.svg)

```text
ans = 0
for i in 0 .. n-1:
    for j in 0 .. n-1:
        h = grid[i][j]
        if h == 0: continue
        ans += 2                                  # 顶 + 底
        for 四个方向 (x, y):
            nh = 边界外 ? 0 : grid[x][y]
            ans += max(0, h - nh)                 # 只数露出来的侧面
return ans
```

### 3.4 示例演算

![示例演算：2×2 网格的四格贡献](images/wc99_q1_walkthrough.svg)

对 `grid = [[1,2],[3,4]]` 逐格计算：

| 格子 | $h$ | 顶+底 | 四方向露出的侧面 | 合计 |
|------|-----|-------|------------------|------|
| (0,0) | 1 | 2 | 左 1、右 0、上 1、下 0 → 2 | 4 |
| (0,1) | 2 | 2 | 左 1、右 2、上 2、下 0 → 5 | 7 |
| (1,0) | 3 | 2 | 左 3、右 0、上 2、下 3 → 8 | 10 |
| (1,1) | 4 | 2 | 左 1、右 4、上 2、下 4 → 11 | 13 |

总和 $4+7+10+13 = 34$，与题面一致。

## 4. 算法细节

1. **为什么只加 `max(0, h - nh)` 而不用加两次**：每根柱子只对自己那一侧负责，相邻两柱之间的粘贴面在两边各被扣掉 $\min(h,h')$，恰好等于两侧各减去被挡住的部分，不会重复也不会遗漏。
2. **边界处理**：把数组外的邻居高度视为 0，就不需要为四个方向各写一段特判，`max(0, h - 0) = h` 正好是完整的侧面。
3. **`h == 0` 直接跳过**：高度 0 的格子没有顶底面；它的侧面贡献是 0（`max(0, 0 - nh) = 0`），跳过只是省几次比较。
4. **方向数组**：`dx = {-1,1,0,0}`、`dy = {0,0,-1,1}`，循环展开或写成 4 个 `max` 都可以。
5. **答案范围**：单格最大贡献 $2 + 4 \times 50 = 202$，$2500$ 格最多约 $5 \times 10^5$，`int` 足够。
6. **等价写法**：用「相邻两柱贡献 $|h_i - h_j|$ + 边界高度」也能得到同一答案，但逐格写 `max(0, h - h')` 更不容易在边界上出错。

## 5. 正确性证明

**引理 1（顶底贡献）**：每根非空柱子对表面积的顶面与底面贡献恰为 $2$。

**证明**：高度为 $h \ge 1$ 的柱子最顶上一个立方体的上表面暴露在空气中，最底下一个立方体的下表面也暴露（题目要求底面计入）。中间的立方体上下面都与同类立方体贴合，不计。故恰为 2。∎

**引理 2（相邻侧面的抵消）**：高度 $h$ 与 $h'$ 的两根相邻柱子，在贴合方向上，各自暴露的侧面数分别为 $\max(0, h-h')$ 与 $\max(0, h'-h)$，两者之和为 $|h-h'|$，等于这一段「没有被粘住」的竖直面积。

**证明**：两柱在高度 $[0, \min(h,h'))$ 范围内完全贴合，这些面上的立方体侧面互相抵消；在高度 $[\min(h,h'), \max(h,h'))$ 范围内只有较高的柱子有立方体，其侧面暴露。较高者暴露的面数就是 $\max(0, h - h')$，较低者在该方向全部被贴住，暴露数为 0，两者之和即高度差。∎

**定理**：算法输出的 `ans` 等于所有形体的总表面积。

**证明**：把总表面积按「面」的来源分类：每个单位面要么是某个立方体的上/下表面，要么是某个立方体的侧表面。

- 上/下表面：只有每根柱子的最顶和最底暴露，由引理 1 恰好计入 $2[h>0]$。
- 侧表面：每个立方体的 4 个侧向中，朝向网格外的直接暴露（此时 `nh = 0`，`max(0,h-0)=h` 恰好数出整根柱子的外侧高度）；朝向相邻柱子的部分，由引理 2 恰好数出未被粘贴的高度。

算法对每个格子、每个方向各统计一次，覆盖全部立方体的全部 6 个面且不重不漏；粘贴面因 `h - nh <= 0` 被计 0，正是不应计入的部分。∎

## 6. 复杂度分析

- **时间**：$O(n^2)$。每个格子常数次比较，$n \le 50$ 时约 $2.5\times 10^3$ 次循环体。
- **空间**：$O(1)$ 额外空间（只用到几个方向常量）；输入矩阵本身 $O(n^2)$ 不计入。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int surfaceArea(vector<vector<int>>& grid) {
        int n = (int)grid.size(), ans = 0;
        int dx[4] = {-1, 1, 0, 0}, dy[4] = {0, 0, -1, 1};
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                int h = grid[i][j];
                if (h == 0) continue;               // 没有方块，不贡献面积
                ans += 2;                           // 顶面 + 底面
                for (int d = 0; d < 4; d++) {
                    int x = i + dx[d], y = j + dy[d];
                    int nh = (x >= 0 && x < n && y >= 0 && y < n) ? grid[x][y] : 0;
                    if (h > nh) ans += h - nh;      // 只数"露出来"的那部分侧面
                }
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def surfaceArea(self, grid: List[List[int]]) -> int:
        n = len(grid)
        ans = 0
        for i in range(n):
            for j in range(n):
                h = grid[i][j]
                if h == 0:
                    continue                        # 没有方块，不贡献面积
                ans += 2                            # 顶面 + 底面
                for x, y in ((i - 1, j), (i + 1, j), (i, j - 1), (i, j + 1)):
                    nh = grid[x][y] if 0 <= x < n and 0 <= y < n else 0
                    if h > nh:
                        ans += h - nh               # 只数"露出来"的那部分侧面
        return ans
```

## 8. 边界情况与易错点

1. **全 0 网格**：如 `[[0]]`，答案应为 0；`h == 0` 时不能加顶底。
2. **边界不能漏**：边界柱子的外侧整面都暴露，把外部邻居当成 0 才正确；若只对内层邻居计算，会漏掉整圈侧面。
3. **不要重复计算粘贴面**：若对每根柱子的四个方向都加上「邻居高度」，就会把粘贴面重复计入，得到偏大的答案。
4. **底面必须算**：题目明确要求底面计入，只算顶面会少 $n^2_{\text{非空}}$ 个面。
5. **`max(0, ...)` 不能省**：邻居更高时 `h - nh` 为负，直接累加会让答案变小。
6. **`int` 溢出**：本题远小于 `int` 上限；但若把高度上限改成 $10^9$、$n$ 很大，需改用 `long long`。
7. **方向数组越界**：四个方向的下标检查要同时判断 `x` 与 `y`，只判一个会在角上越界。
