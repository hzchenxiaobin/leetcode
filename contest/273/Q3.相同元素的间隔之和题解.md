# LeetCode 相同元素的间隔之和 题解

## 1. 题目概述

- **标题 / 题号**：相同元素的间隔之和（#2121，medium）
- **链接**：https://leetcode.cn/problems/intervals-between-identical-elements/
- **来源**：LeetCode 第 273 场周赛 Q3
- **难度**：中等
- **标签**：数组、哈希表、前缀和

**题意**：给定下标从 $0$ 开始、长度为 $n$ 的整数数组 `arr`。两个元素的**间隔**定义为其下标之差的绝对值 $|i - j|$。返回等长数组 `intervals`，其中 $intervals[i]$ 是 $arr[i]$ 到**所有同值元素**的间隔之和（到自身的间隔为 $0$，并入求和不影响结果，见 §8 第 5 条）。

**约束**：

- $1 \le n \le 10^5$
- $1 \le arr[i] \le 10^5$

> 💡 本题与 [2615. 等值距离和](https://leetcode.cn/problems/sum-of-distances/) **完全同题**——后者是第 340 场周赛 Q2，站内 `contest/340/Q2` 已有题解，本站的每日版题解见 `../solution/2101-2200/2121_相同元素的间隔之和.md`，可对照阅读。本题是分场胜负的关键题：$n$ 达 $10^5$ 直接判死两两枚举的 $O(n^2)$，突破口在于**按值分组后组内下标天然升序**——绝对值可以按「当前点左侧 / 右侧」安全脱去，再用**前缀和**把每个位置的距离和降到 $O(1)$，整体 $O(n)$。

## 2. 示例

**示例 1**

```text
输入：arr = [2,1,3,1,2,3,3]
输出：[4,2,7,2,4,4,5]
解释：
- 下标 0：另一个 2 在下标 4，|0−4| = 4
- 下标 1：另一个 1 在下标 3，|1−3| = 2
- 下标 2：另两个 3 在下标 5、6，|2−5| + |2−6| = 7
- 下标 3：另一个 1 在下标 1，|3−1| = 2
- 下标 4：另一个 2 在下标 0，|4−0| = 4
- 下标 5：另两个 3 在下标 2、6，|5−2| + |5−6| = 4
- 下标 6：另两个 3 在下标 2、5，|6−2| + |6−5| = 5
```

**示例 2**

```text
输入：arr = [10,5,10,10]
输出：[5,0,3,4]
解释：
- 下标 0：另两个 10 在下标 2、3，|0−2| + |0−3| = 5
- 下标 1：值 5 只出现一次，间隔和为 0
- 下标 2：另两个 10 在下标 0、3，|2−0| + |2−3| = 3
- 下标 3：另两个 10 在下标 0、2，|3−0| + |3−2| = 4
```

> 💡 示例 2 是最小的完整样本：一个 $m = 3$ 的组把公式的三个位置全部走一遍，一个 $m = 1$ 的单元素组恰好验证「自动为 $0$」，§3.4 用它做全程演算。

## 3. 解题思路

### 3.1 暴力思路：按值分组 + 组内两两枚举

与题意一一对应的朴素做法：用哈希表按值收集下标，对每个下标组 $g$ 内的每个 $p_i$，再扫一遍整组累加 $|p_i - p_j|$。

一次组内扫描 $O(m)$，整组 $O(m^2)$，所有组合计 $O\!\left(\sum_v m_v^2\right)$——最坏情况（全部元素同值）退化为 $O(n^2)$，$n = 10^5$ 时约 $10^{10}$ 次运算，**必然超时**。

> ⚠️ 暴力的问题在于对每个 $p_i$ 都重新「裸算」一整组距离，完全没有复用组内已有序的结构。突破口是观察：组内下标**升序**时，$p_i$ 左侧的 $p_j$ 都满足 $p_j < p_i$，右侧同理——绝对值可以直接按左右**去括号**，去完括号的距离和就能用**前缀和** $O(1)$ 算出。

### 3.2 核心观察：组内升序 → 拆左右去绝对值 → 前缀和闭式

![核心观察：按值分组、以 p_i 为界拆左右去绝对值](images/wc273_q3_group_prefix_concept.svg)

**观察一（分组互不相干，组内天然升序）**：间隔只定义在同值元素之间，因此整个问题按值分组后**各组完全独立**，可以逐组求解、各自回填。又因为遍历 `arr` 时下标 $i$ 从 $0$ 递增到 $n-1$，`pos[v].append(i)` 顺序收集得到的下标组**天然严格升序**，连排序都省了——这是本题最「白送」的一步，但它是后面一切去绝对值操作的前提。

**观察二（以 $p_i$ 为界拆左右）**：设某值对应下标组 $g = [p_0, p_1, \dots, p_{m-1}]$，对组内第 $i$ 个位置求

$$f(i) = \sum_{j=0}^{m-1} |p_i - p_j|$$

由升序性，$j < i$ 时 $|p_i - p_j| = p_i - p_j$（共 $i$ 项），$j > i$ 时 $|p_i - p_j| = p_j - p_i$（共 $m-1-i$ 项；$j = i$ 自身贡献 $0$）。于是

- **左侧** $= i \cdot p_i - \sum_{j<i} p_j = i \cdot p_i - \text{prefix}[i]$，其中 $\text{prefix}[i]$ 为**前 $i$ 项之和**；
- **右侧** $= \left(\text{total} - \text{prefix}[i] - p_i\right) - (m-1-i) \cdot p_i$，其中 $\text{total} = \sum_j p_j$ 为组内下标总和，括号里正是右侧下标之和。

**观察三（闭式合并）**：左右相加，$p_i$ 的系数为 $i - 1 - (m-1-i) = 2i - m$，得到一行公式

$$\boxed{f(i) = (2i - m) \cdot p_i + \text{total} - 2 \cdot \text{prefix}[i]}$$

> 💡 **系数 $2i - m$ 的直觉**：它正是「左侧点数 $i$ − 右侧点数 $m - i$」。位置越靠左，左边点越少、右边点越多，$p_i$ 的负系数让向右的距离贡献占优；越靠右则反过来。前缀和把「左侧下标和」「右侧下标和」都压成 $O(1)$ 查询——这正是把每位置 $O(m)$ 降到 $O(1)$、整组 $O(m^2)$ 降到 $O(m)$ 的关键。

### 3.3 算法流程：分组 → 逐组滚动前缀和 → 闭式回填

![算法流程：分组 → 逐组滚动前缀和 → 闭式回填](images/wc273_q3_algorithm_flow.svg)

结合三个观察，算法是「一次遍历建组 + 双重循环逐组回填」：

1. **建组**：遍历 $i = 0, \dots, n-1$，`pos[arr[i]].append(i)`，得到若干升序下标组；
2. **逐组**：对每个组 $g$（长度 $m$）先算 $\text{total} = \sum_k g[k]$，置 $\text{prefix} \leftarrow 0$；
3. **逐位置**：对 $i = 0, \dots, m-1$，套闭式 $\text{ans}[g[i]] \leftarrow (2i-m) \cdot g[i] + \text{total} - 2 \cdot \text{prefix}$，**然后**才 $\text{prefix} \mathrel{+}= g[i]$（先算后加，保证公式里用的是前 $i$ 项之和）；
4. 所有组处理完，返回 `ans`。

「先套公式再累加」是唯一需要小心的时序：公式中的 $\text{prefix}[i]$ **不含 $g[i]$ 自身**，写反顺序会得到 $f(i) - 2g[i]$（负数是响亮的警报，见 §8 第 3 条）。

### 3.4 示例演算

![示例演算：arr = [10,5,10,10] 的两组回填](images/wc273_q3_example_walkthrough.svg)

以示例 2（`arr = [10,5,10,10]`）全程走查。分组得两个组：值 $10 \to g = [0,2,3]$（$m=3$，$\text{total}=5$），值 $5 \to g = [1]$（$m=1$）。

**值 10 组**（$\text{prefix}$ 依次为 $0, 0, 2$，注意 $\text{prefix}[1] = g[0] = 0$）：

| $i$ | $g[i]$ | $\text{prefix}$ | $(2i-m) \cdot g[i]$ | $\text{total} - 2 \cdot \text{prefix}$ | 回填 |
|-----|--------|-----------------|---------------------|----------------------------------------|------|
| 0 | 0 | 0 | $(0-3) \cdot 0 = 0$ | $5 - 0 = 5$ | $\text{ans}[0] = 0 + 5 = 5$ |
| 1 | 2 | 0 | $(2-3) \cdot 2 = -2$ | $5 - 0 = 5$ | $\text{ans}[2] = -2 + 5 = 3$ |
| 2 | 3 | 2 | $(4-3) \cdot 3 = 3$ | $5 - 4 = 1$ | $\text{ans}[3] = 3 + 1 = 4$ |

**值 5 组**（$m = 1$）：$(0-1) \cdot 1 + 1 - 0 = 0 \Rightarrow \text{ans}[1] = 0$，单元素组公式自动归零，无需特判。

两组回填合并得 `intervals = [5, 0, 3, 4]`，与示例一致。对照可见：组内三个位置各花 $O(1)$，而暴力要各扫一遍整组——差距全部来自前缀和对「左侧下标和 / 右侧下标和」的 $O(1)$ 化。

## 4. 算法细节

1. **分组容器的选择**：$1 \le arr[i] \le 10^5$ 恰好允许开值域数组 `vector<vector<int>> pos(100001)`（注意开到 $10^5 + 1$，值可以取到 $10^5$），最坏 $O(1)$ 定位、无哈希开销；用 `unordered_map<int, vector<int>>` 平均 $O(1)$ 也完全够用。**对照记忆**：2615 的值域是 $10^9$，值域数组不可行，只能哈希——「值域小用桶、值域大用哈希」要按数据范围临场判断，别把本题的桶当成套路必然。
2. **滚动前缀**：不需要显式前缀和数组，一个 `prefix` 标量随循环滚动即可；关键时序是**先套公式、再累加**（§3.3 第 3 步），使公式中的 `prefix` 恒等于前 $i$ 项之和。
3. **溢出审计（C++）**：全同值 $n = 10^5$ 时，$intervals[0] = \sum_{j=1}^{n-1} j \approx 5 \times 10^9$，$\text{total} \approx 5 \times 10^9$，中间乘积 $(2i-m) \cdot p_i$ 可达 $10^{10}$——三者全部超过 `int` 上限（约 $2.1 \times 10^9$），必须 `long long`，且 $2i$ 要写成 `2LL * i` 先行提升（实测峰值 $4\,999\,950\,000$，见 §7 代码注释）。本题 C++ 接口返回 `vector<long long>` 本身就是提示。Python 整数无此问题。
4. **回填用原下标**：`ans[g[i]]` 里的 `g[i]` 是**原数组下标**，`i` 只是组内序号，两者只在「恰好从 0 连续」时碰巧相等（见 §8 第 2 条）。
5. **相邻差分变体（备用推导）**：闭式相邻作差，$f(i) - f(i-1) = (2i - m)(p_i - p_{i-1})$，即把「拆左右」理解为「每右移一格，左侧 $i$ 个点各远 $d$、右侧 $m-i$ 个点各近 $d$」。于是 $f(0) = \text{total} - m \cdot p_0$，$f(i) = f(i-1) + (2i-m)(p_i - p_{i-1})$——连 `prefix` 都省了，是现场推导卡壳时的兜底写法，也是 1685 一族「有序数组差绝对值之和」的统一视角。
6. **单元素组免特判**：$m = 1$ 时代入公式得 $(0-1) \cdot p_0 + \text{total} - 0 = 0$（$\text{total} = p_0$），自动正确；追求常数可加 `if (m == 1) continue;` 整组跳过。

## 5. 正确性证明

设某值对应下标组 $g = [p_0, \dots, p_{m-1}]$，由 §3.2 观察一知 $p_0 < p_1 < \dots < p_{m-1}$（下标互异且按序收集）。记 $f(i) = \sum_{j=0}^{m-1} |p_i - p_j|$，$\text{total} = \sum_{j=0}^{m-1} p_j$，$\text{prefix}[i] = \sum_{j=0}^{i-1} p_j$（$\text{prefix}[0] = 0$）。

**引理 1（拆左右）**：对任意 $0 \le i < m$，

$$f(i) = \sum_{j<i} (p_i - p_j) \; + \; \sum_{j>i} (p_j - p_i)$$

**证明**：$j < i$ 时由严格升序有 $p_j < p_i$，故 $|p_i - p_j| = p_i - p_j$；$j > i$ 时 $p_j > p_i$，故 $|p_i - p_j| = p_j - p_i$；$j = i$ 项为 $|p_i - p_i| = 0$，舍弃不影响求和。三项合计即证。∎

**引理 2（闭式公式）**：$f(i) = (2i - m) \cdot p_i + \text{total} - 2 \cdot \text{prefix}[i]$。

**证明**：由引理 1 展开。左侧共 $i$ 项：$\sum_{j<i}(p_i - p_j) = i \cdot p_i - \text{prefix}[i]$。右侧共 $m - 1 - i$ 项：$\sum_{j>i}(p_j - p_i) = (\text{total} - \text{prefix}[i] - p_i) - (m-1-i) \cdot p_i$（右侧下标之和恰为 $\text{total}$ 减去前 $i$ 项与自身）。相加：

$$i \cdot p_i + (m - 1 - i) \cdot p_i - p_i - 2\,\text{prefix}[i] + \text{total} = (2i - m) \cdot p_i + \text{total} - 2\,\text{prefix}[i] \; \blacksquare$$

**定理（算法正确性）**：按 §3.3 流程得到的 `ans` 满足 $ans[k] = \sum_{j:\, arr[j] = arr[k]} |k - j|$ 对一切 $0 \le k < n$ 成立。

**证明**：按值分组把全部下标划分成若干互不相交的组，同值当且仅当同组；于是目标和可按组分解，每组只须对组内下标求 $f$。对组 $g$ 的第 $i$ 个位置：循环不变式为「第 $i$ 轮套公式时 `prefix` 等于 $\text{prefix}[i]$、`total` 等于 $\text{total}$」，初始 $i = 0$ 时 `prefix` 为 $0 = \text{prefix}[0]$ 成立，每轮**先套公式再累加**保持不变式，故回填值恰为引理 2 的 $f(i)$。又组内 $p_i$ 互异，每个下标恰好被其所在组回填一次，无重复无遗漏。$m = 1$ 时引理 2 给 $(0-1) \cdot p_0 + p_0 = 0$，单元素组自动正确。∎

> 💡 证明的骨架是「**分组分解 + 组内闭式 + 回填双射**」三段式：分组分解是这类「按值/按类统计」题通用的合法性框架，值得与 §8 第 2 条的回填错误对照记忆——公式对了但回填下标错了，证明里「每个下标恰好被回填一次」这半句就不成立。

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。建组遍历一次 $O(n)$；每组内 `total` 一趟 $O(m)$、逐位置回填 $O(m)$，而 $\sum_v m_v = n$，合计仍为 $O(n)$（值域数组定位 $O(1)$ 最坏；`unordered_map` 平均 $O(1)$）。对比暴力 $O\!\left(\sum_v m_v^2\right)$ 最坏 $10^{10}$，提速来自前缀和把每位置 $O(m)$ 的距离和压成 $O(1)$。
- **空间复杂度**：$O(n)$。分组存下标共 $n$ 个，输出数组 $n$ 个（若不计输出，额外空间为存放下标组的 $O(n)$，可用值域数组省去哈希表开销但不改变量级）。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    vector<long long> getDistances(vector<int>& arr) {
        int n = arr.size();
        unordered_map<int, vector<int>> pos;
        pos.reserve(n);
        for (int i = 0; i < n; i++) pos[arr[i]].push_back(i);   // 天然升序

        vector<long long> ans(n);
        for (auto& [v, g] : pos) {
            int m = g.size();
            long long total = 0;
            for (int p : g) total += p;
            long long prefix = 0;                               // 滚动：前 i 项之和
            for (int i = 0; i < m; i++) {
                long long p = g[i];
                // 峰值答案 4999950000 ≈ 5e9，全 long long 防溢出
                ans[g[i]] = p * (2LL * i - m) + total - 2 * prefix;
                prefix += p;                                    // 先套公式再累加
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def getDistances(self, arr: List[int]) -> List[int]:
        pos = defaultdict(list)
        for i, v in enumerate(arr):
            pos[v].append(i)          # 天然升序

        ans = [0] * len(arr)
        for g in pos.values():
            m, total = len(g), sum(g)
            prefix = 0                 # 滚动：前 i 项之和
            for i, p in enumerate(g):
                ans[p] = p * (2 * i - m) + total - 2 * prefix
                prefix += p            # 先套公式再累加
        return ans
```

## 8. 边界情况与易错点

1. **32 位溢出（最高频 RE/WA）**：全同值 $n = 10^5$ 时峰值答案 $4\,999\,950\,000$、`total` 同量级、中间乘积可达 $10^{10}$，全部超过 `int`；C++ 须全程 `long long`，且 `2LL * i` 先行提升——若乘法两侧都是 `int`（如写成 `g[i] * (2*i-m)`），`int × int` 在赋给 `long long` 之前就已截断。Python 整数任意精度，免疫此坑。
2. **回填下标写错**：`ans[g[i]]` 用的是**原数组下标**，不是组内序号 `i`。示例 2 上写 `ans[i]` 会得到形如 $[5,3,4,0]$ 的结果（哈希序不同则 $[0,3,4,0]$），样例即可拦住；但若组恰好「从 0 连续」（如 $g=[0,1,2]$），写错也能蒙混过关，最险。
3. **先累加再套公式**：顺序写反相当于用了 $\text{prefix}[i] + p_i$，结果等于 $f(i) - 2g[i]$——答案是偏小甚至为**负**的数，负数是响亮的警报，见到即可定位此错。
4. **别画蛇添足排序**：组内天然升序，再 `sort` 白付 $O(m \log m)$；更不要对「值」排序——组间处理顺序与答案无关。
5. **「到自身」与单元素组**：$|i - i| = 0$，$j = i$ 含不含都不影响和；$m = 1$ 的组公式自动给 $0$——两处都不需要 `if` 特判，写了反而不美。
6. **「间隔」是下标差，不是值的差**：$|i - j|$ 针对位置，与 $arr[i]$、$arr[j]$ 的数值无关（同值只是「谁参与求和」的准入条件）。误按值差计算会在示例 1 的 $intervals[2] = 7$ 处现形（值差全为 $0$）。
7. **值域数组开到 $100001$**：$arr[i]$ 可取到 $10^5$，开 $10^5$ 会越界一格；这是「值域桶」类写法的固定陷阱位。
8. **$n = 1$**：唯一的元素自成一组，公式给 $0$，输出 `[0]`，无需处理。

**延伸思考**：若把距离和换成**距离平方和** $\sum (p_i - p_j)^2$，拆左右后还需额外维护 $\sum p_j^2$ 的二阶前缀，套路不变、阶数升高；若要求**在线**支持插入元素并随时查询某点的距离和，可对下标离散化后用两个树状数组（分别维护个数与前缀和）做到单次 $O(\log n)$；而 §4 第 5 条的相邻差分视角 $f(i) - f(i-1) = (2i-m)(p_i - p_{i-1})$ 提示：位置每右移一格，答案的增量只与「左右点数之差」和「步长」有关——这与 1685、2602 一族问题共享同一条「一维距离场」的性质链。
