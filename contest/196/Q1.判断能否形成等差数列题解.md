# LeetCode 判断能否形成等差数列 题解

## 1. 题目概述

- **标题 / 题号**：判断能否形成等差数列（#1502，easy）
- **链接**：https://leetcode.cn/problems/can-make-arithmetic-progression-from-sequence/
- **来源**：LeetCode 第 196 场周赛 Q1
- **难度**：简单
- **标签**：数组、排序

**题意**：给定数字数组 `arr`。若一个数列中任意相邻两项的差总等于同一常数，则称为**等差数列**。判断 `arr` 能否**重新排列**成等差数列：能则返回 `true`，否则返回 `false`。

**约束**：

- `2 <= arr.length <= 1000`
- `-10^6 <= arr[i] <= 10^6`

> 💡 签到题的最短路径就藏在题面里：「**可以重新排列**」= 元素顺序无关 = **排序**。排序之后，「是否存在某种排列」坍缩为「这一个序列是否等差」，一遍验证即可出解。

## 2. 示例

**示例 1**

```text
输入：arr = [3,5,1]
输出：true
解释：重新排序得到 [1,3,5]（或 [5,3,1]），相邻差恒为 2（或 −2），是等差数列。
```

**示例 2**

```text
输入：arr = [1,2,4]
输出：false
解释：无论如何重排，相邻差都无法恒定：排序后 [1,2,4] 的相邻差为 1、2。
```

**示例 3**

```text
输入：arr = [7,7,7]
输出：true
解释：公差为 0 的常数列也是等差数列——排序后相邻差全为 0。
```

## 3. 解题思路

### 3.1 暴力思路

最朴素的做法是枚举全部 $n!$ 种排列、逐个检查是否等差，复杂度 $O(n! \cdot n)$，$n = 1000$ 时是天文数字。它失败的根源在于把「重排」当成了**搜索空间**——而等差数列的元素集合是确定的 $\{a,\ a+d,\ \dots,\ a+(n-1)d\}$，根本不需要搜索任何排列：排序一步就能把排列自由度全部消掉。

### 3.2 核心观察：排序消掉「重排」自由度

![排序消掉重排自由度](images/1502_sort_verify_concept.svg)

关键 insight 分两步：

- **顺序无关 ⇒ 排序**：题目允许任意重排，等价于只关心元素的多重集合。排序把这个多重集变成唯一确定的非降序列 $c$，于是「存在一种重排成等差」等价于「$c$ 本身是等差数列」（严格论证见 §5 引理 2）。
- **等差判定只需一个基准差**：$c$ 是等差数列，当且仅当全部 $n-1$ 个相邻差都等于 $d = arr[1] - arr[0]$。排序保证 $d \ge 0$，连负公差的讨论都省了。

### 3.3 算法流程：排序 + 逐对验证

![排序与逐对验证流程](images/1502_sort_verify_flow.svg)

```text
1. arr.sort()                       # 排序，消掉重排自由度
2. d = arr[1] - arr[0]              # n >= 2 保证安全；排序后 d >= 0
3. for i in 2 .. n-1:
       if arr[i] - arr[i-1] != d:   # 首个不匹配
           return false             # 提前失败
4. return true                       # 全部相邻差都等于 d
```

### 3.4 示例演算

![三个代表情形演算](images/1502_walkthrough_check.svg)

三个代表情形走查（详见插图）：

- **情形 A** `arr = [3,5,1]`：排序得 $[1,3,5]$，$d = 2$，相邻差 $2, 2$ 全相等 → `true`。
- **情形 B** `arr = [1,2,4]`：排序不变，$d = 1$，相邻差 $1, 2$，在 $i = 2$ 处 $2 \ne 1$ → 提前返回 `false`：

| $i$ | $arr[i] - arr[i-1]$ | 与 $d = 1$ 比较 |
|---|---|---|
| 2 | $4 - 2 = 2$ | $2 \ne 1$，失败 ✗ |

- **情形 C** `arr = [7,7,7]`：$d = 0$，相邻差全为 0 → `true`，公差为零无需特判。

## 4. 算法细节

1. **排序是唯一的关键动作**：把存在性/构造性问题转成验证性问题，这是「可重排」类题面的标准切入（同款套路见「相关题目与扩展」）。
2. **$d$ 取排序后前两项之差**：排序后非降，$d \ge 0$ 恒成立，全程不出现负公差；$d$ 本身就是第一个相邻差，无需任何额外推导。
3. **提前失败**：验证循环中一遇到 $\ne d$ 的差立即 `return false`，最坏 $n-1$ 次比较，随机数据往往几步就出结果。
4. **`arr[1]` 安全**：约束保证 $n \ge 2$，取 `arr[1] - arr[0]` 不越界；$n = 2$ 时循环从 $i = 2$ 起不执行，天然返回 `true`——任意两个数必成等差数列。
5. **无溢出风险**：$|arr[i]| \le 10^6$，相邻差绝对值 $\le 2 \times 10^6$，`int` 足够。
6. **Python 可一行收尾**：`all(arr[i] - arr[i-1] == d for i in range(2, len(arr)))`，短路特性天然支持提前失败。

## 5. 正确性证明

**引理 1（排序唯一性）**：任一含 $n$ 个实数的多重集，其非降排列唯一。

**证明**：设 $c_1 \le c_2 \le \dots \le c_n$ 与 $c'_1 \le c'_2 \le \dots \le c'_n$ 是同一多重集的两个非降排列。$c_1$ 与 $c'_1$ 都是该多重集的最小值，故 $c_1 = c'_1$；各去掉一个最小值后剩余多重集仍相同，依归纳得 $c_k = c'_k$ 对一切 $k$ 成立。∎

**引理 2（重排判定等价）**：`arr` 可重排成等差数列 $\iff$ `arr` 排序后得到的序列 $c$ 本身是等差数列。

**证明**：（⇐）$c$ 就是 `arr` 的一种重排，$c$ 等差即结论成立。（⇒）设 `arr` 的某个重排 $b_1, \dots, b_n$ 是公差为 $d$ 的等差数列。若 $d = 0$：全部元素相等，$c$ 是常数列，公差 0 等差。若 $d > 0$：$b$ 严格递增，从而 $b$ 本身就是 `arr` 的一种非降排列，由引理 1 得 $c = b$，是等差数列。若 $d < 0$：$b$ 严格递减，其反序 $\tilde{b}$ 是公差 $-d > 0$ 的等差数列且严格递增，故 $\tilde{b}$ 是非降排列，由引理 1 得 $c = \tilde{b}$；反序只把公差变号、不破坏等差性，故 $c$ 是等差数列。∎

**定理**：令 $c$ 为 `arr` 排序后的序列（下标从 0 记），算法返回 `true` $\iff$ `arr` 可重排成等差数列。

**证明**：算法返回 `true` $\iff$ 循环全部通过 $\iff$ 对所有 $i \ge 2$ 有 $c_i - c_{i-1} = d$，其中 $d = c_1 - c_0$。若该条件成立，则 $c$ 的 $n-1$ 个相邻差全部等于 $d$，按定义 $c$ 是公差 $d$ 的等差数列；反之若 $c$ 等差，其相邻差全等于同一公差，自然全等于 $d = c_1 - c_0$，循环必全部通过。故「返回 `true`」$\iff$「$c$ 等差」$\iff$（由引理 2）「`arr` 可重排成等差数列」。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \log n)$。排序主导 $O(n \log n)$，逐对验证 $O(n)$；$n \le 1000$，签到题无需追求更优。
- **空间复杂度**：$O(\log n)$，即 C++ `std::sort`（内省排序）的递归栈；Python `list.sort` 为 Timsort，最坏 $O(n)$。验证循环本身只用 $O(1)$ 额外变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool canMakeArithmeticProgression(vector<int>& arr) {
        sort(arr.begin(), arr.end());
        int d = arr[1] - arr[0];               // n >= 2 保证安全，排序后 d >= 0
        for (int i = 2; i < (int)arr.size(); ++i) {
            if (arr[i] - arr[i - 1] != d) {    // 首个不匹配立即失败
                return false;
            }
        }
        return true;
    }
};
```

### Python

```python
class Solution:
    def canMakeArithmeticProgression(self, arr: List[int]) -> bool:
        arr.sort()
        d = arr[1] - arr[0]                    # n >= 2 保证安全，排序后 d >= 0
        return all(arr[i] - arr[i - 1] == d for i in range(2, len(arr)))
```

`all()` 自带短路：遇到第一个不等于 $d$ 的差立刻返回 `False`，与手写循环等价。

## 8. 边界情况与易错点

1. **不排序直接判原数组**：`[3,5,1]` 原序相邻差为 $2, -4$，会误判 `false`。「重排成等差」必须先排序，把顺序自由度一次用到位。
2. **先取 $d$ 后排序**：顺序颠倒会把 $d$ 取成原数组前两项之差（可能为负、也可能恰好误导判断），必须 `sort` 之后再取。
3. **$n = 2$ 恒真**：只有一个相邻差，天然「恒定」。循环从 $i = 2$ 开始自然处理，不要写成从 $i = 1$ 开始（那是拿 $d$ 与自身比较，永远白比一次）。
4. **公差 $d = 0$**：全相等数组（如 `[7,7,7]`）是公差为 0 的等差数列，排序后相邻差全 0，算法自然通过，**无需特判**；也别反过来误以为「有重复元素就返回 `false`」。
5. **有重复但不全等**：如 `[1,1,2]` 排序后相邻差 $0, 1$，$0 \ne d$ 正确返回 `false`——非零公差的等差数列不允许重复元素，逐对验证天然覆盖。
6. **负数与负公差**：值域含 $-10^6$，排序后 $d \ge 0$，全程不涉及负公差；不要在原数组上对符号做任何假设。
7. **溢出**：$|arr[i]| \le 10^6$，相邻差 $|d| \le 2 \times 10^6$，`int` 安全，无需 `long long`。
8. **Python `arr.sort()` 修改入参**：LeetCode 判题允许；介意副作用时改用 `sorted(arr)`。

**延伸思考**：能否做到 $O(n)$ 时间？可以——一次遍历取 `min/max`，若 $(max - min)$ 不能被 $n-1$ 整除直接 `false`；否则 $d = (max - min) / (n - 1)$：$d = 0$ 时全相等返回 `true`；$d > 0$ 时把元素全部入哈希集合，检查 $min + i \cdot d$（$i = 0, \dots, n-1$）这 $n$ 个互异期望值是否全部在集合中——是则原数组恰为该等差集合（用 $O(n)$ 空间换掉排序）。更值得沉淀的是通用套路：**题面出现「重新排列 / 任意顺序」字眼，第一反应就是排序**，把存在性问题坍缩为验证性问题。
