# LeetCode 所有蚂蚁掉下来前的最后一刻 题解

## 1. 题目概述

- **标题 / 题号**：所有蚂蚁掉下来前的最后一刻（#1503，medium）
- **链接**：https://leetcode.cn/problems/last-moment-before-all-ants-fall-out-of-a-plank/
- **来源**：LeetCode 第 196 场周赛 Q2
- **难度**：中等
- **标签**：脑筋急转弯、数组、模拟

**题意**：一块长为 $n$ 个单位的木板上有若干蚂蚁，每只以**每秒 1 单位**的速度移动，部分向左、部分向右。两只**不同方向**的蚂蚁在某点相遇时，**同时改变方向**继续移动（转向不耗时）。蚂蚁到达木板任一端时立即掉落。给定 `n`、`left`（向左蚂蚁在 $t=0$ 的位置）、`right`（向右蚂蚁在 $t=0$ 的位置），返回**最后一只蚂蚁掉落的时刻**。

**约束**：

- $1 \le n \le 10^4$
- $0 \le \text{left.length} \le n + 1$，$0 \le \text{right.length} \le n + 1$
- $0 \le \text{left}[i], \text{right}[i] \le n$，两数组内所有值唯一且互不重叠
- $1 \le \text{left.length} + \text{right.length} \le n + 1$

> 💡 表面是一道「带碰撞的模拟」，实际是一道**脑筋急转弯**：题眼是「蚂蚁**不可区分** + 只问最后一只」。相撞掉头在观察者眼里与互相穿过完全一样，于是碰撞可以被整体消去，答案坍缩为两个最值。

## 2. 示例

**示例 1**

输出：4
解释：A@0→、B@1→、C@3←、D@4←。虽然中间发生了一连串碰撞掉头，
但最后一只蚂蚁在 t = 4 时才从木板掉落。
```

**示例 2**

输出：7
解释：全部向右，无碰撞。最左的蚂蚁（位置 0）要直走 7 秒才到右端。
```

**示例 3**

```text
输入：n = 7, left = [0,1,2,3,4,5,6,7], right = []
输出：7
解释：全部向左，无碰撞。最右的蚂蚁（位置 7）要直走 7 秒才到左端。
```

## 3. 解题思路

### 3.1 暴力思路

朴素做法是**逐秒（甚至逐事件）模拟**：每步把所有蚂蚁推进一个单位，检测「同点异向」的蚂蚁对让它们反向，直到板空。三个致命问题：

1. **碰撞发生在半整数时刻**：相向蚂蚁间距为奇数时（如 B@1→ 与 C@2←），相遇在 $t = 0.5$、位置 $1.5$。按整秒步进会直接漏掉这次碰撞，必须改为「事件驱动」模拟——精确求出下一对相向蚂蚁的相遇时刻，跳到该时刻处理。
2. **事件数量可达 $O(m^2)$**：每对相向蚂蚁都可能相遇一次，$m \le n + 1 = 10^4 + 1$ 时最坏 $5 \times 10^7$ 量级的碰撞事件，逐一处理必然超时。
3. **实现极易写错**：同一时刻多处碰撞、掉落与碰撞同时发生的边界都需要小心处理。

结论：模拟路线「可行但又慢又脆」，正解必须把**碰撞**从问题里整体消掉。

### 3.2 核心观察：相撞反弹 ⟺ 互相穿过

![核心观察：相撞反弹等价于互相穿过](images/wc196_q2_pass_through_equivalence.svg)

关键 insight：**蚂蚁是同质不可区分的**。两只蚂蚁相撞后双双掉头，A 走上了 B 原本要走的路，B 走上了 A 原本要走的路——从外部观察者的视角看，这与「两只蚂蚁互不干扰地穿过对方」**完全无法区分**。

于是把规则替换为**穿过模型**：所有蚂蚁无视碰撞、沿初始方向直行：

- 向左的蚂蚁在位置 $p$：直走 $p$ 秒从**左端**掉落，用时 $p$；
- 向右的蚂蚁在位置 $p$：直走 $n - p$ 秒从**右端**掉落，用时 $n - p$。

答案即全体掉落时刻的最大值：

$$\text{ans} = \max\Big(\max_{p \in \text{left}} p,\;\; n - \min_{p \in \text{right}} p\Big)$$

> ⚠️ 等价性成立的前提是「只问**最后一只**何时掉落」。单只蚂蚁的命运在两个模型里并不相同——相撞瞬间发生的是**身份交换**（见 3.4 的表格：真实模型里 A 在 $t=3$ 掉落，穿过模型里 A 要到 $t=4$）。但「掉落时刻的**多重集合**」两模型处处相同，这个不变量支撑起整个解法，严格论证见 §5。

### 3.3 算法流程

![算法流程：穿过模型下取最大掉落时间](images/wc196_q2_algorithm_flow.svg)

```text
1. ans ← 0
2. for p in left:  ans ← max(ans, p)         # 向左：直走 p 秒落左端，最晚的是 max(left)
3. for p in right: ans ← max(ans, n − p)     # 向右：直走 n−p 秒落右端，最晚的是 n − min(right)
4. return ans                                 # 全局最晚掉落时刻
```

两个方向的「最晚者」一目了然：向左的蚂蚁离左端越远掉得越晚（取 `max(left)`）；向右的蚂蚁离右端越远掉得越晚，即**位置越靠左**越晚（取 `min(right)` 再用 $n$ 减）。

### 3.4 示例演算

![示例演算：两个模型的位置-时间图](images/wc196_q2_walkthrough.svg)

以示例 1 `n=4, left=[4,3], right=[0,1]`（A@0→、B@1→、C@3←、D@4←）完整走查，把两个模型画成**位置-时间图**（横轴位置、纵轴时间向上）：

- **左图（真实模型）**：折线是碰撞掉头。碰撞事件按时间依次为 $(t{=}1, x{=}2)$ B×C、$(t{=}1.5, x{=}1.5)$ A×B、$(t{=}1.5, x{=}2.5)$ C×D、$(t{=}2, x{=}2)$ B×C（B 和 C 竟然碰了两次！）。
- **右图（穿过模型）**：直线互不干扰。四条直线的交点恰好也是 $(1,2)$、$(1.5,1.5)$、$(1.5,2.5)$、$(2,2)$——**与左图的碰撞事件在时刻、地点上一一对应**（严格证明见 §5 引理 1）。

两模型下各蚂蚁的掉落时刻对照（注意**身份确实换了**）：

| 蚂蚁 | 起点 | 方向 | 穿过模型掉落 | 真实模型掉落 |
|---|---|---|---|---|
| A | 0 | → | $t=4$（右端） | $t=3$（左端） |
| B | 1 | → | $t=3$（右端） | $t=4$（左端） |
| C | 3 | ← | $t=3$（左端） | $t=4$（右端） |
| D | 4 | ← | $t=4$（左端） | $t=3$（右端） |

单只蚂蚁的掉落时刻与端点全都变了，但掉落时刻的**多重集合**两模型都是 $\{3, 3, 4, 4\}$，故：

$$\text{ans} = \max\big(\max(4, 3),\; 4 - \min(0, 1)\big) = \max(4, 4) = 4 \checkmark$$

## 4. 算法细节

1. **公式只依赖两个最值**：向左蚂蚁掉落用时恰为其位置 $p$，最晚者为 $\max(\text{left})$；向右蚂蚁掉落用时为 $n - p$，最晚者为 $n - \min(\text{right})$。**不需要排序**，一遍扫描取最值即可。
2. **空数组的吸收**：`left` 为空时左侧无蚂蚁，对应项取 $0$；`right` 为空时同理。所有 $p \in [0, n]$，两项均非负，与 $0$ 取 `max` 不影响结果——C++ 里累加器初始为 $0$ 天然吸收空数组；Python 用 `max(left, default=0)` 与 `min(right, default=n)`（$n - n = 0$）。
3. **碰撞的半整数时刻被整体绕开**：穿过模型里根本不存在「碰撞」这一概念，无需事件驱动、无需判断相遇奇偶性。
4. **数据规模无害**：$n \le 10^4$，答案 $\le n$，`int` 无溢出风险。
5. **识别题目类型**：题面出现「相遇换向 / 碰撞反弹」+ 只问**聚合量**（最后时刻、总距离、计数）时，第一反应就是找**不可区分 ⇒ 穿过等价**这类不变量，而不是打开模拟器。

## 5. 正确性证明

设真实模型为 $R$（相撞双双掉头），穿过模型为 $P$（互不干扰直行），蚂蚁总数 $m = \text{left.length} + \text{right.length} \ge 1$。称某时刻的**有向占据集合**为当时木板上所有蚂蚁「(位置, 方向)」构成的多重集合。

**引理 1（事件对应）**：$P$ 中同向蚂蚁永不相遇；异向蚂蚁至多相遇一次。且 $R$ 中的碰撞事件与 $P$ 中的相遇事件在（时刻, 地点）上**一一对应**。

**证明**：$P$ 中每只蚂蚁的位置是 $t$ 的斜率 $\pm 1$ 线性函数，在位置-时间图上是直线：斜率相同（同向）的两条直线平行，永不相遇；斜率相反的两条直线至多交于一点。故 $P$ 的相遇事件有限（至多 $\binom{m}{2}$ 个）。对 $R$ 按事件归纳：初始时刻 $t=0$，$R$ 与 $P$ 的有向占据集合相同（输入给定）。设两模型的前 $k$ 个事件（时刻, 地点）逐一对应，且第 $k$ 个事件后两模型的有向占据集合相同。在下一个事件前，两模型中所有蚂蚁都无碰撞直行，有向占据集合按相同方式演化，故下一个「相遇/碰撞」在两模型中同时发生于同一（时刻, 地点）。在该时刻，$P$ 中两只蚂蚁交错而过、各自保持速度；$R$ 中两只蚂蚁交换速度向量——两种情形产生**完全相同的**事件后有向占据集合（只是蚂蚁标签的归属不同，而占据集合不看标签）。归纳成立。∎

**引理 2（占据集合不变）**：任意时刻 $t \ge 0$，$R$ 与 $P$ 中「仍在木板上的蚂蚁位置构成的多重集合」相同。

**证明**：由引理 1，两模型的有向占据集合作为时间的函数处处相同。蚂蚁掉落当且仅当其位置到达端点 $0$（向左）或 $n$（向右）并离开，这一事件由有向占据集合的演化唯一决定，故两模型的掉落事件在（时刻, 位置）上逐一对应。任意时刻仍在板上的位置多重集合 = 初始位置多重集合删去已掉落者，两模型相同。∎

**引理 3（掉落时刻集合相同）**：$R$ 与 $P$ 的掉落时刻多重集合相同。

**证明**：掉落时刻多重集合由引理 2 中的占据集合演化唯一决定：$t$ 属于该集合 $\iff$ 恰有一只蚂蚁在时刻 $t$ 到达端点并离开。占据集合处处相同，故掉落时刻多重集合相同。∎

**定理**：最后一只蚂蚁的掉落时刻为 $\max\Big(\max_{p \in \text{left}} p,\; n - \min_{p \in \text{right}} p\Big)$（约定空集对应项取 $0$）。

**证明**：题目所求即 $R$ 中掉落时刻的最大值。由引理 3，其等于 $P$ 中掉落时刻的最大值。$P$ 中每只蚂蚁匀速直行：$p \in \text{left}$ 者于 $t = p$ 从左端掉落，$p \in \text{right}$ 者于 $t = n - p$ 从右端掉落。全体掉落时刻构成多重集合 $\{p : p \in \text{left}\} \cup \{n - p : p \in \text{right}\}$，其中前者最大值为 $\max(\text{left})$，后者最大值为 $n - \min(\text{right})$（$n - p$ 关于 $p$ 递减）。两侧取最大即得。空集时该侧无蚂蚁、对应项不存在，以 $0$ 代入不影响结果，因为另一侧各项均 $\ge 0$ 且 $m \ge 1$ 保证另一侧非空或两侧皆空时答案为 $0$ 与约束相容。∎

## 6. 复杂度分析

- **时间复杂度**：$O(L + R)$，其中 $L$、$R$ 为两数组长度。分别扫一遍取最值即可；由 $L + R \le n + 1$ 也可写成 $O(n)$。这已是理论下界——每个位置至少要读一次。
- **空间复杂度**：$O(1)$，只用常数个累加器，不排序、不建事件表、不模拟。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int getLastMoment(int n, vector<int>& left, vector<int>& right) {
        int ans = 0;
        for (int p : left)  ans = max(ans, p);      // 向左：直走 p 秒落左端
        for (int p : right) ans = max(ans, n - p);  // 向右：直走 n-p 秒落右端
        return ans;                                // 碰撞全部无视，取全局最晚
    }
};
```

### Python

```python
class Solution:
    def getLastMoment(self, n: int, left: List[int], right: List[int]) -> int:
        return max(max(left, default=0),            # 最右的向左蚂蚁
                   n - min(right, default=n))        # 最左的向右蚂蚁
```

`default` 参数同时解决了空数组问题：`right` 为空时 $n - n = 0$，与「该侧无蚂蚁」语义一致。

## 8. 边界情况与易错点

1. **方向搞反（最常见 WA）**：向右蚂蚁中最晚掉落的是**位置最小**的那只（$n - p$ 随 $p$ 减小而增大），写成 `max(right)` 就错了；对称地，向左蚂蚁取 `max(left)` 而非 `min(left)`。
2. **空数组**：Python 的 `max([])` / `min([])` 直接抛 `ValueError`，必须用 `default=` 或先判空；C++ 累加器从 $0$ 起步天然安全（示例 2 / 3 就是两个单侧为空的用例）。
3. **蚂蚁初始就在端点且朝外**：位置 $0$ 向左、位置 $n$ 向右，$t = 0$ 立即掉落（用时 $0$）；位置 $0$ 向右、位置 $n$ 向左则用时 $n$。公式全部自然覆盖，无需特判。
4. **碰撞在半整数时刻**：间距为奇数的相向蚂蚁在 $x.5$ 处相遇（见 §3.4 的 $(1.5, 1.5)$、$(1.5, 2.5)$），逐秒模拟党的大坑；穿过模型里这个问题不存在。答案本身一定是整数（掉落只发生在端点，起点与速度均为整数）。
5. **误答「指定蚂蚁何时掉落」**：若题目改成问「编号为 A 的蚂蚁何时掉落」，穿过模型不能直接套——单只蚂蚁的掉落时刻在两模型中确实不同（见 §3.4 表格），需沿碰撞点显式追踪身份交换。
6. **蚂蚁速度不同则等价性破产**：穿过等价依赖「碰撞后双方速度大小不变、只换方向」。若引入快慢蚂蚁，碰撞后速度如何分配没有自然答案，整套转化失效。
7. **不必要的排序**：把 `left`、`right` 排序再取端点是多余的 $O(n \log n)$；一遍 `max`/`min` 即可。
8. **约束解读**：$L + R \le n + 1$ 意味着位置不会拥挤到极端之外，且 $m \ge 1$ 保证至少一只蚂蚁、答案有意义；所有值唯一且两数组不相交，故初始无重叠、无同点异向的瞬时奇观。
