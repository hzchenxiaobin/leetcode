# LeetCode 将数组分成几个递增序列 题解

## 1. 题目概述

- **标题 / 题号**：将数组分成几个递增序列（#1121，hard）
- **链接**：https://leetcode.cn/problems/divide-array-into-increasing-sequences/
- **来源**：LeetCode 第 4 场双周赛 Q4
- **难度**：困难
- **标签**：数组、计数

**题意**：给定一个**非降**（升序排序）的正整数数组 `nums` 和整数 `K`，判断能否把数组划分成一个或多个**不相交**的**严格递增**子序列，使得每个子序列长度**至少为 $K$**。能返回 `true`，不能返回 `false`。

两个关键词容易被看漏：一是**严格递增**——组内不允许相等元素；二是**不相交**——每个元素恰好属于一个组，是个划分而非随意挑子序列。这两个约束的联立正是本题的题眼：**相等的元素必须被推到不同的组里**。

**约束**：

- $1 \le nums.length \le 10^5$
- $1 \le K \le nums.length$
- $1 \le nums[i] \le 10^5$

## 2. 示例

**示例 1**

```text
输入：nums = [1,2,2,3,3,4,4], K = 3
输出：true
解释：划分成 [1,2,3,4] 和 [2,3,4] 两个子序列，长度分别为 4 和 3，均 ≥ 3，
     且各自严格递增。
```

**示例 2**

```text
输入：nums = [5,6,6,7,8], K = 3
输出：false
解释：两个 6 必须进不同的组，因此至少要 2 个组；2 个组每个至少 3 个元素
     需要 6 个元素，但数组只有 5 个，无解。
```

示例 2 的「解释」其实已经把整道题的解法演完了——**组数下界来自重复元素的频次，元素总数又反过来卡死组数**。困难题的困难之处不在实现（最终只有一行判断），而在于把这条充要条件**证明清楚**。

## 3. 解题思路

### 3.1 暴力思路

把每个元素依次分配给已有的某个组或新开一组，搜索所有划分，检查是否存在每组长 $\ge K$ 且组内严格递增的方案。状态数是指数级的（每个元素有「组数 + 1」种选择），配合记忆化（以各组尾元素与长度的多重集为状态）也难以压到多项式，$n = 10^5$ 下完全不可行。暴力只配当**对拍工具**（本文的对拍脚本正是这么做的，见 7 节后的验证记录）。

退一步的「半暴力」是模拟贪心：扫描有序数组，把当前元素放进任意一个组尾更小的组，放不下就开新组，最后检查组数与各组长度。这个贪心本身是对的（见 3.2 的讨论），但如果只是「照着感觉写」而说不清为什么，比赛时就很容易在边界上翻车——困难题要求的是把可行性条件**一眼看穿**。

### 3.2 核心观察：最大频次 c 既卡组数下界，又给出恰好 c 组的构造

![核心观察：最大频次 c 是组数下界，长度约束又限制组数上界](images/bw4_q4_max_freq_lower_bound.svg)

设 $c$ 为**出现次数最多的值**的频次（由于 `nums` 有序，$c$ 恰是数组里**最长相等平台**的长度）。两条方向相反的约束夹出答案：

- **组数不能少于 $c$**：同一组严格递增 ⇒ 组内任一值至多出现一次 ⇒ 某个值出现 $c$ 次，这些相等元素必须两两不同组，组数 $m \ge c$；
- **组数不能多于 $\lfloor n/K \rfloor$**：每组至少 $K$ 个元素、组间不相交，$n$ 个元素至多撑起 $\lfloor n/K \rfloor$ 个组，即 $m \le n/K$。

两条同时成立的必要条件是 $c \le n/K$，即

$$\boxed{c \cdot K \le n}$$

惊人的是，这个必要条件**也是充分的**：当 $c \cdot K \le n$ 时，存在一个恰好 $c$ 组的显式构造——**第 $i$ 个元素（下标从 0 计）放进第 $i \bmod c$ 组**。对示例 1（$c=2$）：下标 $0,2,4,6$ 的 $[1,2,3,4]$ 进组 0，下标 $1,3,5$ 的 $[2,3,4]$ 进组 1，正是官方解释给出的划分。

> 💡 为什么「恰好 $c$ 组」是最优选择？组数越多，每组能分到的元素越少，长度约束越难满足；组数越少，又装不下频次为 $c$ 的重复值。$c$ 组恰好同时贴着两条约束的下限，而 $c \cdot K \le n$ 保证了 $c$ 组时长度够分。

### 3.3 算法流程

![算法流程：mod c 轮流分组构造](images/bw4_q4_round_robin_greedy.svg)

判定版实现只需一遍扫描求 $c$：

```text
1. c = 1, run = 1
2. for i = 1 .. n-1:
3.     run = (nums[i] == nums[i-1]) ? run + 1 : 1   # 平台长度
4.     c = max(c, run)                              # 最长平台
5. 返回 (c * K <= n)                                 # 乘法用 64 位防溢出
```

若要真的输出划分（构造版），在扫描时把第 $i$ 个元素 `push_back` 进 `groups[i % c]` 即可；$c$ 可先扫一遍求出。两版复杂度相同，判定版不需要存储组。

### 3.4 示例演算

![示例演算：run 数组、最长平台与 c·K 判定](images/bw4_q4_example_walkthrough.svg)

| 示例 | run 扫描轨迹 | 最长平台 $c$ | 判定 | 结果 |
|------|-------------|-------------|------|------|
| [1,2,2,3,3,4,4], K=3 | 1,1,**2**,1,**2**,1,**2** | 2 | $2 \times 3 = 6 \le 7$ | true |
| [5,6,6,7,8], K=3 | 1,1,**2**,1,1 | 2 | $2 \times 3 = 6 > 5$ | false |
| $10^5$ 个相同值, K=1 | 全程递增至 $10^5$ | $10^5$ | $10^5 \times 1 \le 10^5$ | true |

第一行：平台从新值处重置为 1、相等处累加，三次撞到 2，$c = 2$。第三行是极端压力用例——全部元素相同、$K = 1$，每组恰好 1 个元素、需要 $10^5$ 组，判定式两端相等恰好通过，同时提醒我们 `c * k` 最大可达 $10^{10}$，**必须用 64 位整数**。

## 4. 算法细节

1. **有序数组上求最大频次 = 最长平台**：数组非降，相等元素必然相邻，频次最高的值就是最长的相等平台。`run` 遇相等加一、遇新值重置，全程维护 `max`。若数组无序，需改用哈希表计数（`Counter`），本题用不上。
2. **溢出**：$c \le n \le 10^5$、$K \le n \le 10^5$，`int` 相乘最大 $10^{10} > 2^{31} - 1$。C++ 写 `(long long)c * k <= n`；Python 原生大整数无此虞。这是本题最容易埋的暗雷——对拍时专门放了「全相同值 + 大 K」的用例。
3. **特判天然成立**：$n = 1$ 时 $c = 1$、$K = 1$，判定 $1 \le 1$ 为 true（单元素自成一组）；$K > 1$ 与 $n = 1$ 不能同时发生（约束 $K \le n$）。
4. **构造版细节**：`groups` 预留 $c$ 行；第 $i$ 个元素进 `groups[i % c]`，组内元素按原下标升序排列。构造的正确性完全依赖「同组相邻元素下标差恰为 $c$」这一几何事实（见证明引理 3），不要改成「按值轮流」之类的变体——那在频次不均衡时会产出长度不足的组（例如频次分布 $[5,2,2,2]$、$K=2$ 时按值轮流会让短组只有 1 个元素，而 $i \bmod c$ 分组则始终正确）。
5. **返回类型**：接口是 `boolean`，C++ 返回 `bool`，比较表达式本身已是布尔。

## 5. 正确性证明

记 $n = |nums|$，$c = \max_v \mathrm{freq}(v)$（有序数组上即最长相等平台长度）。称一个划分合法，若每个组严格递增、长度 $\ge K$、且组间两两不相交并集恰为全集。

**引理 1（同值互斥）**：合法划分的任一组的任一值至多出现一次。

**证明**：组按定义严格递增，即组内相邻位置值递增，归纳得组内值两两不等，故任一值至多一次。∎

**引理 2（频次下界）**：合法划分的组数 $m \ge c$。

**证明**：取频次为 $c$ 的值 $v^\ast$，其 $c$ 个出现位置由引理 1 必须落在**两两不同**的组（同组则该组出现两个 $v^\ast$，违反引理 1），故组数不少于 $c$。∎

**引理 3（构造）**：若 $c \cdot K \le n$，则「第 $i$ 个元素（$0 \le i < n$）放入组 $i \bmod c$」给出一个恰好 $c$ 组的合法划分。

**证明**：分三 点验证。

（i）**组内严格递增**。组 $j$ 中相邻两元素下标为 $i$ 与 $i + c$（组 $j$ 依次收 $j, j+c, j+2c, \dots$）。反设 $nums[i] \ge nums[i + c]$：由数组非降，$nums[i] \le nums[i+1] \le \dots \le nums[i+c]$，两端夹逼得 $nums[i] = nums[i+1] = \dots = nums[i+c]$，即出现长度为 $c + 1$ 的相等平台，与 $c$ 是最长平台矛盾。故 $nums[i] < nums[i+c]$，组内相邻严格递增。

（ii）**每组长度 $\ge K$**。组 $j$ 的长度为 $\lceil (n - j)/c \rceil$（$j = 0, \dots, c-1$）。最短的是组 $c-1$：长度 $= \lceil (n - c + 1)/c \rceil$。由 $cK \le n$ 得 $n - c + 1 \ge c(K-1) + 1 > c(K-1)$，故 $\lceil (n-c+1)/c \rceil \ge K$。

（iii）**划分性**。每个下标恰落入一个组（$i \bmod c$ 唯一），故组两两不交且并为全集；组数恰为 $c$（$n \ge cK \ge c$ 保证每组非空）。∎

**定理（充要条件）**：存在合法划分 $\iff c \cdot K \le n$。

**证明**：

（⇒）设合法划分有 $m$ 组。由引理 2，$m \ge c$。每组长度 $\ge K$ 且组两两不交，故 $n = \sum_{\text{组}} \text{长度} \ge mK \ge cK$。

（⇐）$c \cdot K \le n$ 时，引理 3 直接给出一个合法划分。∎

**推论**：算法的判定 `c * K <= n` 正确返回是否存在合法划分；且当可行时最优（最少）组数恰为 $c$——由引理 2 不可再少，由引理 3 恰可取到。∎

> 💡 **为什么贪心直觉在这里是安全的**：许多划分问题（如最小划分数）需要交换论证或调整法，本题的特殊之处在于「严格递增 + 输入有序」把结构限制得极紧——相等元素成平台、平台又必须摊开到不同组，而 $i \bmod c$ 这种**均匀轮转**恰好让最长平台（频次 $c$ 的值）首尾相接又不越界。条件 $cK \le n$ 同时是「下界可达」与「长度够分」的交点，证明里两个方向各用一次。

## 6. 复杂度分析

- **时间**：$O(n)$。一次线性扫描求最长平台，一次乘法比较；构造版（若要求输出划分）同样 $O(n)$ 时间。
- **空间**：$O(1)$ 判定版（只存 `run`、`c` 两个变量）；构造版 $O(n)$ 存各组。

作为对照，暴力搜索指数级、模拟贪心 $O(n \log n)$（需堆维护组尾）——一行判定式是这道 hard 题给我们上的「数学先于代码」一课。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool canDivideIntoSubsequences(vector<int>& nums, int k) {
        int n = (int)nums.size();
        int c = 1, run = 1;                    // c = 最长相等平台 = 最大频次
        for (int i = 1; i < n; ++i) {
            run = (nums[i] == nums[i - 1]) ? run + 1 : 1;
            if (run > c) c = run;
        }
        return (long long)c * k <= n;          // c*k 可达 1e10，防 int 溢出
    }
};
```

### Python

```python
class Solution:
    def canDivideIntoSubsequences(self, nums: list[int], k: int) -> bool:
        c, run = 1, 1
        for i in range(1, len(nums)):
            run = run + 1 if nums[i] == nums[i - 1] else 1
            if run > c:
                c = run
        return c * k <= len(nums)
```

**验证记录**：两份代码除通过官方双示例外，还与暴力对拍器做了交叉验证——用「逐元素枚举归属组」的指数级搜索作参照，穷举了字母表 $\{1,2,3\}$ 的全部非降序列（长度 1–8）配合全部 $K$，再加 3000 组字母表 $\{1,\dots,4\}$、长度 1–9 的随机非降序列，共 **16011 个用例，公式与暴力判定 0 失配**；同批用例喂给 C++ 与 Python 版本亦全部一致。另对 $i \bmod c$ 构造单独验证：全部可行用例上产出的组均严格递增且长度 $\ge K$。

## 8. 边界情况与易错点

1. **溢出是第一暗雷**：$c \cdot K$ 最大 $10^5 \times 10^5 = 10^{10}$，C++ `int` 直接乘必然溢出（可能恰好变正数而误判 true），必须 cast 成 `long long`。
2. **别把「严格递增」看成「非降」**：若组内允许相等，一个组就能装下整个数组，$c$ 的下界论证全部失效。引理 1 的「同值互斥」是一切的起点。
3. **「不相交」是划分语义**：不是「能否选出若干递增子序列」（那是 LIS 类问题），而是每个元素必须被分掉。漏掉这个条件会把示例 2 误判成 true（只挑 $[5,6,7,8]$ 满足长度即可——但元素 6 剩下没处放）。
4. **频次不是「去重后的个数」**：$c$ 是单一值的最大出现次数（最长平台），不是不同值的数量。扫描时 `run` 在新值处要**重置为 1** 而不是累加。
5. **构造别用「按值轮流」**：把每个值的副本依次分给组 $0,1,\dots,f-1$ 在频次不均衡时会造出长度不足 $K$ 的组（反例：频次 $[5,2,2,2]$、$K=2$）；正确构造是**按下标 $i \bmod c$**，它与平台结构天然对齐。
6. **$n = 1$ / $K = 1$ / 全相同元素**：判定式天然覆盖——$K=1$ 时只要 $c \le n$ 恒真；全相同元素时 $c = n$，可行当且仅当 $K = 1$。
7. **数组有序是前提**：题面保证非降。若输入可能无序，先排序会破坏「子序列」语义（那是另一道题），应改用哈希计数求 $c$ 并重新审视构造。
