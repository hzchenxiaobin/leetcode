# LeetCode 删去字符串中的元音 题解

## 1. 题目概述

- **标题 / 题号**：删去字符串中的元音（#1119，easy）
- **链接**：https://leetcode.cn/problems/remove-vowels-from-a-string/
- **来源**：LeetCode 第 4 场双周赛 Q2
- **难度**：简单
- **标签**：字符串

**题意**：给定一个仅由**小写英文字母**组成的字符串 `s`，删去其中所有的元音字母 `a`、`e`、`i`、`o`、`u`，返回删除后的新字符串。本质是一道**字符串过滤**题：保序挑出所有非元音字符，拼成答案。

**约束**：

- `s` 仅由小写英文字母组成
- $1 \le |s| \le 1000$

约束里「仅小写」这句话很关键：它排除了大写元音、空格、数字等一切干扰，判定函数只需针对 5 个字符做精确匹配。

## 2. 示例

**示例 1**

```text
输入：s = "leetcodeisacommunityforcoders"
输出："ltcdscmmntyfrcdrs"
解释：逐个删去 e, e, o, e, i, a, o, u, i, o, o, e 共 12 个元音，
     其余 17 个辅音按原顺序保留。
```

**示例 2**

```text
输入：s = "aeiou"
输出：""
解释：整个字符串都是元音，全部删光，得到空串。
```

**边界自查（非官方示例）**

```text
输入：s = "xyz"
输出："xyz"
解释：没有任何元音，原样返回。
```

## 3. 解题思路

### 3.1 暴力思路

最直观的写法是原地删除：遍历 `s`，遇到元音就调用 `erase` / `remove`。C++ 里对 `string` 反复 `erase` 是 $O(n)$ 单次、$O(n^2)$ 总体的操作（每次删除都要搬移后缀），在 $|s| \le 1000$ 下也能过，但属于典型的「能过但不应学」。正确姿势是**一遍构造**：开一个空结果串 `t`，从左到右扫 `s`，非元音就追加到 `t` 尾部——每个字符只被搬运一次。

### 3.2 核心观察：一遍过滤，判定 O(1)

![核心观察：逐字符过元音闸门，非元音追加、元音丢弃](images/bw4_q2_filter_scan_model.svg)

把过程想象成一道**闸门**：字符逐个排队经过，闸门里存着元音集合 $V = \{a, e, i, o, u\}$。每个字符 $c$ 只有两种命运：

- $c \in V$：**丢弃**，继续处理下一个；
- $c \notin V$：**追加**到结果串 `t` 的尾部。

判定 $c \in V$ 是 $O(1)$ 的——$V$ 只有 5 个元素，可以用 5 个 `!=` 连写、一个 `set`/`frozenset`，甚至一个 26 位的**位掩码**（`mask = 0b100000100000100010001`，判断 `mask >> (c-'a') & 1`）。任何一种实现都只与字母表大小相关，与 $n$ 无关。

由于我们**从左到右**扫描、只在「非元音」分支追加，`t` 中相邻两个字符在 `s` 中的下标必然严格递增——输出的相对顺序自动与输入一致，无需任何额外操作。换句话说，**答案就是 `s` 的一个子序列**（保留相对顺序、删去若干字符），过滤模型天然保证这一点。

### 3.3 算法流程

```text
1. V = {a, e, i, o, u}；t = 空串
2. for c in s:
3.     if c ∉ V:      # 5 次比较或一次 set 查询
4.         t += c     # 追加到尾部
5.     # c ∈ V 时什么都不做，等于丢弃
6. 返回 t
```

Python 里这条流程可以压缩成一行生成器表达式：`''.join(c for c in s if c not in "aeiou")`——语义即解法。C++ 端一个循环加 `push_back` 即可，`t.reserve(s.size())` 可省去扩容开销（本题规模下无关痛痒）。

### 3.4 示例演算

![示例演算：29 个字符逐一过闸，12 个元音被删，17 个辅音保序拼接](images/bw4_q2_example_walkthrough.svg)

以示例 1 的前几个字符走一遍闸门：

| 字符 | ∈ V ? | 动作 | t 当前值 |
|------|-------|------|---------|
| l | 否 | 追加 | "l" |
| e | 是 | 丢弃 | "l" |
| e | 是 | 丢弃 | "l" |
| t | 否 | 追加 | "lt" |
| c | 否 | 追加 | "ltc" |
| o | 是 | 丢弃 | "ltc" |
| d | 否 | 追加 | "ltcd" |

扫完 29 个字符后 `t = "ltcdscmmntyfrcdrs"`：元音恰好 12 个（e, e, o, e, i, a, o, u, i, o, o, e），辅音 17 个，$29 - 12 = 17$ 与输出长度吻合。示例 2 中 5 个字符全部命中「丢弃」分支，`t` 保持空串；边界自查里 3 个字符全部命中「追加」分支，`t` 与 `s` 相同。

## 4. 算法细节

1. **元音集合的表示**：优先级从高到低——`set("aeiou")`（Python，可读性最好）、5 个 `!=` 连写（C++，零开销）、位掩码（通用，扩展到大写字母时 `mask |= 1 << (tolower(c)-'a')` 即可）。本题任选， readability first。
2. **结果的构造方式**：C++ 用 `t += c`（均摊 $O(1)$）；Python 用 `''.join(...)` 而不是 `t += c`——虽然 CPython 对 `str +=` 有原地扩容优化，`join` 仍是语义最清晰、复杂度最稳的写法。
3. **不要原地 `erase`**：C++ `string::erase` 单次 $O(n)$，最坏总 $O(n^2)$；若一定要原地，用 `std::remove_if` + `erase` 的 **erase–remove 惯用法**一次搬移完成，但「新建结果串」在这类题目里永远是最简单的选择。
4. **顺序保证的来源**：见 3.2 末段——单向扫描 + 单调追加 ⇒ 子序列性质自动成立，不需要显式记录下标。
5. **字符集假设**：题面保证仅小写字母，因此判定可以只对 5 个小写元音做精确比较；若题目变形为含大写，判定改为 `tolower(c) ∈ V`，其余代码一行不动。

## 5. 正确性证明

**引理 1（输出是子序列）**：算法输出 `t` 中第 $j$ 个字符在 `s` 中的下标严格大于第 $j-1$ 个字符的下标。

**证明**：字符按 $s$ 的下标从左到右依次进入判定，且只有「非元音」分支会追加。设 $t_{j-1}$ 来自下标 $i_{j-1}$，$t_j$ 来自下标 $i_j$。追加 $t_j$ 发生在追加 $t_{j-1}$ 之后，而扫描单调向右，故 $i_j > i_{j-1}$。∎

**引理 2（无元音残留）**：`t` 中不含任何元音字符。

**证明**：追加的唯一入口是非元音分支（$c \notin V$），元音字符永不进入 `t`。∎

**定理**：`t` 恰为「从 `s` 中删去全部元音、其余字符保持相对顺序」得到的结果，即题目所求。

**证明**：`s` 的每个字符要么是元音（被丢弃，引理 2 保证不出现在 `t`）要么不是（恰好被追加一次），故 `t` 由 `s` 的全部非元音字符组成；由引理 1，这些字符的相对顺序与 `s` 中一致。这与「删除所有元音」的结果定义完全吻合，且两条引理合起来说明该结果唯一。∎

## 6. 复杂度分析

- **时间**：$O(n)$，其中 $n = |s|$。每个字符恰好判定一次，每次判定 $O(1)$（与 5 个元音的比较次数有关，与 $n$ 无关）。
- **空间**：$O(n)$。结果串 `t` 至多存 $n$ 个字符（不计输出则 $O(1)$ 辅助空间；Python 的 `join` 会先经生成器消费一遍，仍为线性）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    string removeVowels(string s) {
        string t;
        t.reserve(s.size());            // 可选：省去扩容
        for (char c : s) {
            if (c != 'a' && c != 'e' && c != 'i' && c != 'o' && c != 'u') {
                t += c;                 // 非元音：保序追加
            }
            // 元音：什么都不做，即丢弃
        }
        return t;
    }
};
```

### Python

```python
class Solution:
    def removeVowels(self, s: str) -> str:
        vowels = set("aeiou")
        return "".join(c for c in s if c not in vowels)
```

两个版本都跑了官方双示例外加「全辅音」边界（`"xyz"` → `"xyz"`），输出与题面一致。

## 8. 边界情况与易错点

1. **全元音**：`"aeiou"` → 空串。返回空串是合法结果，不要因为「答案非空」的惯性加任何特殊处理。
2. **全辅音**：`"xyz"` → 原样返回。此时代码走的全是追加分支，是检验「元音判定写反了没有」的好用例。
3. **单个字符**：`"a"` → `""`，`"b"` → `"b"`，天然覆盖。
4. **别在循环里 `erase`**：C++ 边扫边 `erase` 既容易迭代器失效，又是 $O(n^2)$；要原地就 erase–remove 惯用法，更好的选择是新建结果串。
5. **元音只有 5 个小写**：`y` 在英语里有时算半元音，但本题**不算**；也不要顺手把大写 `A/E/I/O/U` 加进集合——题面说只有小写。
6. **顺序**：题目要求删去元音、保持其余字符相对顺序（输出是输入的子序列）。若手滑用了 `set(s) - set("aeiou")` 再拼接，顺序就被破坏了。
