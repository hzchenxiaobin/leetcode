# LeetCode 灯泡开关 Ⅱ 题解

## 1. 题目概述

- **标题 / 题号**：灯泡开关 Ⅱ（#672，medium）
- **链接**：https://leetcode.cn/problems/bulb-switcher-ii/
- **来源**：LeetCode 第 48 场周赛 Q4
- **难度**：中等
- **标签**：位运算、深度优先搜索、广度优先搜索、数学

**题意**：$n$ 盏灯初始全亮，编号 $1 \sim n$。四个开关分别翻转「全部灯」「偶数编号灯」「奇数编号灯」「$j = 3k+1$ 的灯」。必须**恰好**按压 `presses` 次，每次任选一个开关，问所有按压结束后一共有多少种**不同的亮灭状态**。

**约束**：

- $1 \le n \le 1000$
- $0 \le presses \le 1000$

> 💡 题面干净、没有附加变量之类的噪声句子。本题是纯计数题：既不需要模拟每一次按压，也不关心「按了几次」，只关心「哪些终态可达」。

## 2. 示例

**示例 1**

```text
输入：n = 1, presses = 1
输出：2
解释：按开关 1 → [关]；按开关 2 → [开]（开关 2 对灯 1 无效）。
```

**示例 2**

```text
输入：n = 2, presses = 1
输出：3
解释：开关 1 → [关, 关]；开关 2 → [开, 关]；开关 3 → [关, 开]。
      注意按开关 4 与按开关 3 结果相同（都只翻灯 1），所以只有 3 种。
```

**示例 3**

```text
输入：n = 3, presses = 1
输出：4
解释：开关 1 → [关, 关, 关]；开关 2 → [开, 关, 开]；
      开关 3 → [关, 开, 关]；开关 4 → [关, 开, 开]。
```

## 3. 解题思路

### 3.1 暴力思路

按题意直接模拟：从全亮出发，枚举长度为 `presses` 的按压序列，用集合收集终态。序列数是 $4^{presses}$，最坏 $4^{1000}$，不可行。

换一条路：在「状态」上做 BFS，每层用 4 个开关转移。但状态数本身是 $2^{n} \le 2^{1000}$，同样爆炸。所以必须先在**数学层面**把问题压小，而不是换搜索方式。

### 3.2 核心观察：4 个开关只有 3 个自由度

![4 个开关在 6 类灯泡上的翻转表](images/wc48_q4_button_patterns.svg)

**第一层压缩：顺序无关 + 两次抵消。** 开关之间互不干扰，先按谁后按谁结果一样；同一个开关按两次等于没按。于是任何按压序列都等价于「被按了**奇数次**的开关集合」$S \subseteq \{1,2,3,4\}$，一共只有 $2^4 = 16$ 种。

**第二层压缩：作用周期为 6。** 每个开关的判定条件只用编号的奇偶性与 $i \bmod 3$，两者都以 6 为周期，所以只需看前 6 盏灯（$n$ 更小时看前 $n$ 盏）：

| 灯泡编号（按 6 取模） | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| 奇偶 | 奇 | 偶 | 奇 | 偶 | 奇 | 偶 |
| $i \bmod 3$ | 1 | 2 | 0 | 1 | 2 | 0 |
| 开关 1（全部） | 1 | 1 | 1 | 1 | 1 | 1 |
| 开关 2（偶数） | 0 | 1 | 0 | 1 | 0 | 1 |
| 开关 3（奇数） | 1 | 0 | 1 | 0 | 1 | 0 |
| 开关 4（$3k+1$） | 1 | 0 | 0 | 1 | 0 | 0 |

表中立刻看出 $b_1 = b_2 \oplus b_3$（偶数灯 ⊕ 奇数灯 = 全部灯），**开关 1 是冗余的**。把 4 个奇偶位重组成 3 个有效比特：

$$\alpha = b_1 \oplus b_2,\qquad \beta = b_2 \oplus b_3,\qquad \gamma = b_4$$

![压缩成 α、β、γ 三个有效比特](images/wc48_q4_effective_bits.svg)

其中 $b_k \in \{0,1\}$ 表示开关 $k$ 被按了奇数次。于是第 $i$ 盏灯被翻转的奇偶性可以统一写成

$$\text{flip}(i) = \alpha \oplus \beta \cdot [\,i \text{ 为奇数}\,] \oplus \gamma \cdot [\,i \equiv 1 \pmod 3\,]$$

三种模式（全翻、只翻奇数、只翻 $3k+1$）线性无关，所以终态最多只有 $2^3 = 8$ 种。$n$ 很大时状态数也不再增长，这就是本题的全部秘密。

### 3.3 算法流程

![恰好 presses 次的可行性筛选与去重](images/wc48_q4_reachability_flow.svg)

「恰好 `presses` 次」这个条件同样只需奇偶化。若 $S$ 是最终按了奇数次的开关集合，把多出来的次数用「同一开关再按两次」补齐即可，于是

$$S \text{ 可实现} \iff |S| \le presses \ \text{ 且 }\ |S| \equiv presses \pmod 2$$

算法只有四步：

1. 枚举 `mask` $\in [0, 16)$，第 $k$ 位表示开关 $k+1$ 是否被按了奇数次；
2. 用上面两条判据过滤（`popcount` 与奇偶比较）；
3. 对可行 `mask`，算出前 $m = \min(n, 6)$ 盏灯的翻转位，压成一个整数位掩码；
4. 位掩码塞进集合，最后返回集合大小。

候选取多只有 16 个，内层最多 6 盏灯，常数极小；而且「去重」是集合天然完成的，不需要额外推导。

### 3.4 示例演算

![n = 3、presses = 2 的 7 个可行子集](images/wc48_q4_example_walkthrough.svg)

以 $n = 3$、$presses = 2$ 为例：可行集合是空集与 6 个二元子集，共 7 个。逐个算 $\alpha,\beta,\gamma$ 再套公式：

| 按下集合 $S$ | $(\alpha,\beta,\gamma)$ | 翻转位 | 灯 1..3 |
|---|---|---|---|
| $\varnothing$ | $(0,0,0)$ | 000 | 开 开 开 |
| $\{1,2\}$ | $(0,1,0)$ | 101 | 关 开 关 |
| $\{1,3\}$ | $(1,1,0)$ | 010 | 开 关 开 |
| $\{2,3\}$ | $(1,0,0)$ | 111 | 关 关 关 |
| $\{1,4\}$ | $(1,0,1)$ | 011 | 开 关 关 |
| $\{2,4\}$ | $(1,1,1)$ | 110 | 关 关 开 |
| $\{3,4\}$ | $(0,1,1)$ | 001 | 开 开 关 |

7 个状态两两不同，答案是 7。对比之下 $n \ge 3$ 一共才 8 种状态，缺的那个是「关 开 开」，即 $(\alpha,\beta,\gamma) = (0,0,1)$：它的两个原像（$b_1$ 取 0 或 1）大小为 $1$ 和 $4$，都不是「$\le 2$ 且为偶数」，所以两次按压到不了它。

## 4. 算法细节

1. **状态编码**：用整数第 $i$ 位表示第 $i+1$ 盏灯被翻转了奇数次（即灭）。因为初始全亮，「翻转奇数次」与「灭」等价，不需要额外存初值。
2. **为什么取 $m = \min(n, 6)$**：开关作用以 6 为周期，编号相差 6 的两盏灯永远同步变化；$n < 6$ 时自然只算 $n$ 盏。这一步把 $n \le 1000$ 的规模压成常数。
3. **可行性判据**：`popcount(mask) <= presses` 且 `(presses - popcount(mask)) % 2 == 0`。`presses = 0` 时只有 `mask = 0` 通过，自动得到 1 种，不需要单独特判。
4. **为什么枚举 16 个掩码而不是 8 个 $(\alpha,\beta,\gamma)$**：可达性定义在 $(b_1,b_2,b_3,b_4)$ 上，而映射到 $(\alpha,\beta,\gamma)$ 是**2 对 1**，且两个原像的大小往往一奇一偶地错开（例如 $(0,0,1)$ 的两个原像 $\{4\}$ 与 $\{1,2,3,4\}$ 大小为 $1$、$4$）。若直接在 3 维空间里枚举，就丢掉了「哪个原像的大小满足 `presses` 约束」这条信息，会把不可达状态算成可达。16 次枚举的成本完全可以接受。
5. **去重容器**：只有 16 个候选，`std::set<int>` 或 Python `set` 都足够；位掩码本身是整数，哈希常数极小。
6. **等价的闭式解**：把 16 次枚举的结果提前算好，$n = 1$、$n = 2$、$n \ge 3$ 三类各只需记住几个常数，见下方速查表。比赛时直接返回常数也能过，但枚举法写起来更短、也不容易背错。
7. **语言细节**：C++ 用 `__builtin_popcount`；Python 用 `bin(mask).count("1")` 或 `mask.bit_count()`（3.8 以下没有后者，用前者更稳）。

**闭式解速查表**（行是 $n$，列是 $presses$，与枚举法结果完全一致）：

| $n$ ＼ $presses$ | $0$ | $1$ | $2$ | $\ge 3$ |
|---|---|---|---|---|
| $1$ | 1 | 2 | 2 | 2 |
| $2$ | 1 | 3 | 4 | 4 |
| $\ge 3$ | 1 | 4 | 7 | 8 |

## 5. 正确性证明

**引理 1（按压序列 → 奇偶向量）**：任意按压序列的效果只取决于每个开关被按次数的奇偶性；反之，给定奇偶向量 $b \in \{0,1\}^4$，它可由**恰好** `presses` 次按压实现 $\iff$ $|b|_1 \le presses$ 且 $|b|_1 \equiv presses \pmod 2$。

**证明**：开关之间互不影响（各个灯的翻转量是各开关贡献之和），故可交换；同一开关按两次贡献为 0，故只剩奇偶。设 $S$ 为奇数次集合，$|S| \le presses$，且 $presses - |S|$ 必为偶数（每多一次按压只能成对增加）。反过来，先按 $S$ 中每个开关各一次，再把剩下的 $presses - |S|$ 次按「同一开关按两次」成对消耗，即可实现同一奇偶向量。∎

**引理 2（周期 6）**：对所有掩码，编号 $i$ 与 $i+6$ 的灯翻转奇偶性恒相同，故前 $\min(n,6)$ 盏灯的状态决定整个状态。

**证明**：四个开关的判定条件分别是「恒真」「$i$ 偶」「$i$ 奇」「$i \equiv 1 \pmod 3$」，它们都只依赖 $i \bmod 2$ 与 $i \bmod 3$，而 $i \mapsto (i \bmod 2, i \bmod 3)$ 恰好以 6 为周期。∎

**引理 3（自由度只有 3、且 $n \ge 3$ 时无碰撞）**：映射 $(b_1,b_2,b_3,b_4) \mapsto (\alpha,\beta,\gamma)$ 是满射且每个像恰有两个原像；当 $n \ge 3$ 时，

$$(\text{灯}1,\text{灯}2,\text{灯}3) = (\alpha \oplus \beta \oplus \gamma,\ \alpha,\ \alpha \oplus \beta)$$

是 $(\alpha,\beta,\gamma)$ 的双射，故 $n \ge 3$ 时至多 8 种状态。

**证明**：给定 $(\alpha,\beta,\gamma)$，取 $b_1$ 任意，令 $b_2 = \alpha \oplus b_1$、$b_3 = \beta \oplus b_2$、$b_4 = \gamma$，即得一个原像；$b_1$ 只有两个取值，故恰好两个原像。又由引理 2 的公式，灯 1（奇，$1 \bmod 3$）翻 $\alpha \oplus \beta \oplus \gamma$，灯 2（偶，$2 \bmod 3$）翻 $\alpha$，灯 3（奇，$0 \bmod 3$）翻 $\alpha \oplus \beta$；反过来由 $\alpha$、$\beta = \alpha \oplus \text{灯}3$、$\gamma = \text{灯}1 \oplus \text{灯}3$ 可唯一还原，故为双射。∎

**引理 4（小 $n$ 的上界）**：$n = 1$ 时至多 2 种状态，$n = 2$ 时至多 4 种。

**证明**：$n = 1$ 只有一盏灯，状态只有亮/灭两种。$n = 2$ 时状态为 $(\alpha \oplus \beta \oplus \gamma,\ \alpha)$，由 $(\alpha,\beta,\gamma)$ 的 8 种取值只可能落在这 4 个二元组上。∎

**定理**：算法返回值等于题目要求的「不同可能状态数」。

**证明**：由引理 1，算法枚举并保留的 `mask` 集合恰是所有可由恰好 `presses` 次按压实现的奇偶向量，不多不少。由引理 2，用前 $\min(n,6)$ 盏灯的位掩码编码不会把不同终态合并、也不会把相同终态拆开（相差 6 的灯同步变化，位掩码相同 $\iff$ 每盏灯翻转奇偶性相同 $\iff$ 终态相同）。故集合元素与可达终态一一对应，返回集合大小即为答案。∎

## 6. 复杂度分析

- **时间**：$O(2^4 \cdot \min(n,6)) = O(1)$。外层 16 个掩码，内层最多 6 盏灯、每盏灯 4 次判定，总计不超过约 $400$ 次基本运算，与 $n$、`presses` 的具体大小无关。
- **空间**：$O(2^4) = O(1)$。集合最多存 16 个整数，没有额外数组；递归/队列都不需要。

## 7. 参考代码

### C++

```cpp
#include <algorithm>
#include <set>

class Solution {
public:
    int flipLights(int n, int presses) {
        int m = std::min(n, 6);          // 开关作用以 6 为周期，只看前 m 盏灯
        std::set<int> states;
        for (int mask = 0; mask < 16; ++mask) {
            int cnt = __builtin_popcount(mask);   // 被按了奇数次的开关个数
            if (cnt > presses || ((presses - cnt) & 1)) continue;  // 剩余次数必须成对
            int cur = 0;
            for (int i = 0; i < m; ++i) {
                int bulb = i + 1;
                int flips = (mask & 1)
                          + ((mask >> 1) & 1) * (bulb % 2 == 0)
                          + ((mask >> 2) & 1) * (bulb % 2 == 1)
                          + ((mask >> 3) & 1) * (bulb % 3 == 1);
                if (flips & 1) cur |= (1 << i);
            }
            states.insert(cur);
        }
        return (int)states.size();
    }
};
```

### Python

```python
class Solution:
    def flipLights(self, n: int, presses: int) -> int:
        m = min(n, 6)                       # 作用周期为 6
        states = set()
        for mask in range(16):
            cnt = bin(mask).count("1")
            if cnt > presses or (presses - cnt) & 1:
                continue                    # 恰好 presses 次：多出的次数只能成对补
            cur = 0
            for i in range(m):
                bulb = i + 1
                flips = (mask & 1) \
                      + ((mask >> 1) & 1) * (bulb % 2 == 0) \
                      + ((mask >> 2) & 1) * (bulb % 2 == 1) \
                      + ((mask >> 3) & 1) * (bulb % 3 == 1)
                if flips & 1:
                    cur |= 1 << i
            states.add(cur)
        return len(states)
```

## 8. 边界情况与易错点

1. **`presses = 0`**：一次都不能按，只有「全亮」一种状态。枚举法里只有 `mask = 0` 通过筛选，自动得到 1，无需特判。
2. **`n = 1`**：开关 2 对灯 1 完全无效（1 不是偶数），开关 1、3、4 的效果则完全相同（都翻这唯一一盏灯）。所以 `presses >= 1` 时答案是 2 而不是 4。
3. **`n = 2` 且 `presses = 1` 是 3 不是 4**：开关 3 与开关 4 在灯 1、2 上的作用相同（都只翻灯 1），两者撞成同一个状态。很多人在这里直接套「$n \ge 3$ 的 4」而错。
4. **「恰好」不是「至多」**：必须做奇偶过滤。只写 `cnt <= presses` 会退化成「至多 presses 次」：$n \ge 3$ 时 `presses = 1` 会得到 5（多算全亮），`presses = 2` 会得到 8（多算 $(0,0,1)$），正确答案却是 4 和 7。
5. **不要按 `presses` 循环**：`presses` 可达 1000，但同一开关按两次即抵消，任何终态至多 2 次按压就能构造，多余次数只会成对浪费。
6. **不要枚举 $2^n$ 个状态或 $2^n$ 位掩码**：$n \le 1000$ 时位掩码根本存不下，必须先用周期 6 压缩。
7. **状态位含义别搞反**：这里 1 表示「被翻转奇数次」（灭），与初始全亮相符；若改成直接存亮/灭也可以，只要全局一致，不影响计数。
