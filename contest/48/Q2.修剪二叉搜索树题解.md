# LeetCode 修剪二叉搜索树 题解

## 1. 题目概述

- **标题 / 题号**：修剪二叉搜索树（#669，medium）
- **链接**：https://leetcode.cn/problems/trim-a-binary-search-tree/
- **来源**：LeetCode 第 48 场周赛 Q2
- **难度**：中等
- **标签**：树、深度优先搜索、二叉搜索树、二叉树

**题意**：给定一棵二叉搜索树与边界 $[low, high]$，删掉所有值不在区间内的节点，使得剩下的节点值全部落在 $[low, high]$。修剪**不改变保留下来的元素的相对结构**——任何原本的祖先-后代关系必须保持，因此不能重新排序、不能重建平衡。题目保证答案唯一，返回修剪后 BST 的新根（根可能换人）。

**约束**：

- 节点数在 $[1, 10^4]$ 内
- $0 \le Node.val \le 10^4$，且所有节点的值**互不相同**
- 输入保证是一棵有效的二叉搜索树
- $0 \le low \le high \le 10^4$

> 💡 关键约束是「值唯一 + 输入是有效 BST」。前者免去等值判定，后者让「整棵子树都越界」成为可证明的事实，而不是猜想。

## 2. 示例

**示例 1**

```text
输入：root = [1,0,2], low = 1, high = 2
输出：[1,null,2]
解释：0 < low 被剪掉；1、2 都在区间内，1 仍是根，2 仍是它的右孩子。
```

**示例 2**

```text
输入：root = [3,0,4,null,2,null,null,1], low = 1, high = 3
输出：[3,2,null,1]
解释：0 < 1 且 4 > 3 被剪掉；2 上移成为 3 的左孩子，
      1 保持为 2 的左孩子（相对结构不变）。注意结果是 3←2←1 的链，
      而不是把保留值 1、2、3 升序重插得到的 1→2→3。
```

**示例 3（边界补充）**

```text
输入：root = [1], low = 2, high = 3
输出：[]
解释：唯一的节点也越界，修剪后是空树。
```

## 3. 解题思路

### 3.1 暴力思路

最直观的两条路都走不通：

1. **中序遍历收集区间内的值，再按升序重建 BST**。它确实能得到一棵「值集合正确」的 BST，但**形状是错的**：示例 2 保留值 $\{1,2,3\}$，升序重建得到 $1 \to 2 \to 3$ 的右斜链，而正确答案是 $3 \leftarrow 2 \leftarrow 1$ 的左斜链。题目要求保留相对结构，重排直接违反。
2. **逐个删除越界节点**（BST 的 Hibbard 删除 + 旋转调整）。为了维持相对结构，必须在删除时反复搬运子树，实现复杂且极易写错；$k$ 个越界节点最坏 $O(kh)$，而 $k$ 可接近 $n$。

真正的浪费在于：普通做法「先找出越界节点、再逐个摘除」，而 BST 的有序性其实允许**一次判定就丢弃一整棵子树**。

### 3.2 核心观察：越界即整枝可弃

![BST 有序性带来的整枝剪除](images/wc48_q2_core_observation.svg)

设当前节点为 $u$，区间为 $[low, high]$：

- 若 $u.val < low$：由 BST 性质，$u$ 的**整棵左子树**的值都小于 $u.val$，于是全部 $< low$。这棵左子树连同 $u$ 自身可以整体丢弃，答案只可能来自右子树，直接返回 $\text{trim}(u.right)$。
- 若 $u.val > high$：对称地，$u$ 的**整棵右子树**的值都大于 $u.val > high$，返回 $\text{trim}(u.left)$。
- 若 $low \le u.val \le high$：$u$ 保留，只需递归修剪左右子树并接回。

注意这里不只是「少递归一半」的性能优化：**越界节点绝不能被返回**，否则它会被父节点当作合法根接回树里。所以两条越界分支直接 `return` 递归结果，一步「跳过」当前层，让更深的合法节点向上顶替它的位置——这正是根会改变的原因。

### 3.3 算法流程 / 状态转移

![递归修剪的三分支流程](images/wc48_q2_algorithm_flow.svg)

记 $\text{trim}(u)$ 为「修剪 $u$ 子树后的子树根」，则有

$$
\text{trim}(u)=
\begin{cases}
\varnothing, & u=\varnothing\\[2pt]
\text{trim}(u.right), & u.val < low\\[2pt]
\text{trim}(u.left), & u.val > high\\[2pt]
u,\quad u.left\leftarrow\text{trim}(u.left),\ u.right\leftarrow\text{trim}(u.right), & low\le u.val\le high
\end{cases}
$$

流程只有三步：

1. 空树返回 $\varnothing$；
2. 越界就朝「仍在区间内」的那一侧**单链下潜**，返回值直接向上传递；
3. 合法就原地修剪左右子树并返回自己。

> 💡 三个分支的判定顺序无关紧要，但「越界分支返回递归结果」与「合法分支返回自己」必须严格区分。把两者写混（例如越界时返回 `root`）是本题第一大错源。

### 3.4 示例演算

![示例 2 的原树与修剪结果对照](images/wc48_q2_example_walkthrough.svg)

以示例 2（`low = 1, high = 3`）为例，按 DFS 的调用顺序走查：

| 调用 | $u.val$ | 判定 | 返回 |
| --- | --- | --- | --- |
| $\text{trim}(3)$ | 3 | $1\le 3\le 3$，保留 | 左右各递归后返回节点 3 |
| $\text{trim}(0)$ | 0 | $0 < low$ | 返回 $\text{trim}(2)$ |
| $\text{trim}(2)$ | 2 | $1\le 2\le 3$，保留 | 左右各递归后返回节点 2 |
| $\text{trim}(1)$ | 1 | $1\le 1\le 3$，保留 | 孩子皆空，返回节点 1 |
| $\text{trim}(4)$ | 4 | $4 > high$ | 返回 $\text{trim}(\varnothing)=\varnothing$ |

于是 $2.left=1$、$2.right=\varnothing$，$3.left=2$、$3.right=\varnothing$，层序输出 `[3,2,null,1]`，与官方答案一致。整棵树只进入 5 个节点，被丢弃的子树（如 0 的左子树、4 的右子树）一次都没访问。

## 4. 算法细节

1. **返回值的语义**：`dfs(u)` 返回「$u$ 子树修剪后的根」，可能是 $u$ 自己，也可能是 $u$ 的某个后代，甚至 $\varnothing$。父层必须写成 `root.left = dfs(root.left)` 并**接住**返回值，用 `dfs(...)` 当过程调用（不接返回值）会丢掉上移的后代。
2. **越界时只走单侧**：$u.val < low$ 时左子树全废，无需也不应再调 `dfs(root.left)`；$u.val > high$ 时同理。两侧都调用虽不改变答案（被废的一侧必返回 $\varnothing$），但会白白遍历整棵废子树，最坏退化到 $O(n)$ 的无效访问。
3. **原地修改即可**：LeetCode 不要求深拷贝，直接复用原节点指针、改 `left/right`；被剪掉的子树不再被任何指针引用，交给垃圾回收/程序结束处理即可，无需手动释放。
4. **根会换人**：示例 2 中根仍是 3，但若 3 越界、其左子树的某个后代合法，答案的根就会是那个后代。所以入口必须 `return dfs(root)`，绝不能 `return root`。
5. **递归深度**：$10^4$ 个节点的左/右斜链会让递归深度达到 $10^4$。C++ 默认栈（8 MB）每帧仅数十字节，安全；Python 默认 `recursionlimit = 1000` 会直接 `RecursionError`，需 `sys.setrecursionlimit(20000)`。
6. **迭代写法（替代方案）**：先用 `while root and root.val < low: root = root.right` / `while root and root.val > high: root = root.left` 找到新根，再对左右链分别做 `while cur.left and cur.left.val < low: cur.left = cur.left.right` 与对称的右侧循环。时间同为 $O(n)$，空间 $O(1)$，适合对栈深度敏感的语言；但代码分支多、易错，面试/周赛优先写递归。
7. **不要碰中序重建**：任何「收集值后重建」的方案都会改变相对结构（见 3.1 的反例），这是本题唯一的硬约束。

## 5. 正确性证明

**引理 1（越界侧的整枝越界）**：若节点 $u$ 满足 $u.val < low$，则 $u$ 的左子树中所有节点值都 $< low$；若 $u.val > high$，则 $u$ 的右子树中所有节点值都 $> high$。

**证明**：由 BST 性质，$u$ 左子树的每个节点 $v$ 都满足 $v.val < u.val$，而 $u.val < low$，由传递性 $v.val < low$。右子树情形对称，取 $v.val > u.val > high$。∎

**引理 2（递归返回的结构正确）**：对任意节点 $u$，$\text{trim}(u)$ 返回的树的节点集合恰为「$u$ 子树中值落在 $[low,high]$ 的节点」，且其中每个节点 $v$ 的父节点正是它在原树中**最近的、值也在区间内的祖先**（新区间的根无父）。

**证明**：对 $u$ 子树的节点数归纳。空树时为空集，成立。

- 若 $u.val < low$：由引理 1，$u$ 及其左子树全部越界、不贡献任何节点，且 $u$ 自身不成父节点，故全部保留节点都在右子树中。由归纳假设，$\text{trim}(u.right)$ 已按「最近保留祖先」挂接好；又因为 $u$ 被删去，右子树内节点的原树祖先链去掉 $u$ 后相对关系不变，所以最近保留祖先的判定与在原树中一致。
- 若 $u.val > high$：与上一条对称。
- 若 $low\le u.val\le high$：$u$ 保留，且是自身子树内除自己外所有保留节点的最近保留祖先。由归纳假设，$\text{trim}(u.left)$、$\text{trim}(u.right)$ 分别返回左右侧按规则挂接的树；把它们的根接到 $u.left$、$u.right$，则每个保留节点的父节点即其最近保留祖先，左右归属也由值的大小关系保持。∎

**定理**：`trimBST(root, low, high)` 返回的树满足：(a) 所有节点值都在 $[low,high]$；(b) 保留节点的祖先-后代关系与原树一致；(c) 该结果是唯一的，且等于按「最近保留祖先」规则挂接得到的树。

**证明**：(a)(b) 直接由引理 2 得到（取 $u=root$）：节点集合正是区间内的节点，父子关系是原树的最近保留祖先关系，故原树的祖先-后代关系被保持。(c) 唯一性：设 $T'$ 是任一合法答案。对 $T'$ 中任一保留节点 $v$，其父节点 $p$ 必是原树中 $v$ 的某个祖先（否则相对结构改变）；若 $p$ 不是「最近」的保留祖先，则存在原树祖先 $q$ 位于 $p$ 与 $v$ 之间且 $q$ 也为保留节点，$q$ 在 $T'$ 中必须仍是 $v$ 的祖先（相对结构不变），这与 $p$ 是 $v$ 的父节点矛盾。故父节点被唯一确定；又 BST 中 $v$ 挂左还是挂右由 $v.val < p.val$ 唯一确定，树的根即无父的那个节点。于是 $T'$ 与引理 2 给出的树完全相同，答案唯一。∎

## 6. 复杂度分析

- **时间**：$O(n)$。`dfs` 每被调用一次对应一个互不相同的原树节点，且调用后只朝一个方向（合法时两个方向）继续，每个节点至多进入一次；越界分支的子调用属于「沿单链下潜」，同样不重复访问。因此总调用次数 $\le n$，每次常数工作。
- **空间**：$O(h)$，$h$ 为树高，来自递归栈。平衡树 $O(\log n)$，最坏退化成链时 $O(n)=10^4$ 层；除栈外只用了若干指针，额外空间 $O(1)$（不计输出）。

## 7. 参考代码

### C++

```cpp
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    TreeNode* trimBST(TreeNode* root, int low, int high) {
        if (!root) return nullptr;                       // 空树无需修剪
        if (root->val < low)                             // 根与整棵左子树都太小
            return trimBST(root->right, low, high);      // 让右子树的修剪结果顶上来
        if (root->val > high)                            // 根与整棵右子树都太大
            return trimBST(root->left, low, high);       // 让左子树的修剪结果顶上来
        root->left  = trimBST(root->left, low, high);    // 根合法：左右分别修剪后接回
        root->right = trimBST(root->right, low, high);
        return root;
    }
};
```

### Python

```python
import sys
from typing import Optional


class TreeNode:                       # 题目已提供该定义
    def __init__(self, val=0, left=None, right=None):
        self.val, self.left, self.right = val, left, right


class Solution:
    def trimBST(self, root: Optional[TreeNode], low: int, high: int) -> Optional[TreeNode]:
        sys.setrecursionlimit(20000)   # 最坏是 10^4 深的斜链，默认 1000 会爆栈

        def dfs(node: Optional[TreeNode]) -> Optional[TreeNode]:
            if node is None:
                return None
            if node.val < low:                  # 根与整棵左子树都太小
                return dfs(node.right)          # 整体丢弃，右子树的修剪结果顶上来
            if node.val > high:                 # 根与整棵右子树都太大
                return dfs(node.left)           # 整体丢弃，左子树的修剪结果顶上来
            node.left = dfs(node.left)          # 根合法：递归修剪左右子树并接回
            node.right = dfs(node.right)
            return node

        return dfs(root)
```

## 8. 边界情况与易错点

1. **全部节点越界**：如 `root = [1], low = 2, high = 3`，答案为空树 `[]`。递归会一路返回空（`dfs(None)` / `trimBST(nullptr, ...)`），最终得到 `None` / `nullptr`；调用方不能把空指针再当树用。
2. **`low == high`**：只保留值等于该值的节点。由于值唯一，答案至多是单个节点（示例 `[2,1,3], low=high=2` 结果为 `[2]`），此时左右子树全部越界，正好验证「单侧剪枝」。
3. **根被剪掉**：入口必须 `return dfs(root)`。写成 `dfs(root); return root;` 会返回一棵仍含越界节点的树（甚至原树），是最常见的一类 WA。
4. **越界分支返回递归结果**：`if (root->val < low) return trimBST(root->right, ...);` 而不是「把 `root->right` 赋给 `root` 再返回 `root`」——后者会把 $u$ 自己留在树里。
5. **Python 递归深度**：$10^4$ 个节点的链在默认 `recursionlimit = 1000` 下必然 `RecursionError`，必须提高上限（或改用 §4 第 6 条的迭代写法）。C++ 每帧只存少量指针与两个整数，1 万层远低于默认 8 MB 的栈空间，可以放心递归。
6. **必须接住返回值**：示例 2 里 `3.left` 原本指向 0，修剪后要重新指向 `dfs(0)` 的返回值 2。若只写 `dfs(root.left);` 而不赋值，`3.left` 仍指着被剪掉的 0，树里就残留了越界节点（值 1 也会因此不可达）。
7. **不要输出成「中序序列」**：本题返回的是树，判题按层序（含 `null` 占位）比较；示例 2 的正确答案 `[3,2,null,1]` 与中序 `[1,2,3]` 完全不同。
