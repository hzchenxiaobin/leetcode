# LeetCode 二叉树中第二小的节点 题解

## 1. 题目概述

- **标题 / 题号**：二叉树中第二小的节点（#671，easy）
- **链接**：https://leetcode.cn/problems/second-minimum-node-in-a-binary-tree/
- **来源**：LeetCode 第 48 场周赛 Q1
- **难度**：简单
- **标签**：树、深度优先搜索、二叉树

**题意**：给定一棵**特殊的二叉树**——每个节点要么有 2 个孩子、要么是叶子，且每个内部节点都满足 $\text{root.val} = \min(\text{left.val}, \text{right.val})$（父节点的值等于两个孩子中较小的那个）。返回全树节点值中**严格第二小**的值，也就是把出现过的值去重升序排列后的第 2 个；若全树只有一种取值（第二小不存在），返回 `-1`。

**约束**：

- 节点数 $n \in [1, 25]$
- $1 \le \text{Node.val} \le 2^{31} - 1$
- 每个内部节点满足 $\text{root.val} = \min(\text{left.val}, \text{right.val})$

> 💡 **审题关键**：① 「第二小」是**不同值**的第二小，不是"遍历到的第 2 个节点值"；② 题面这条性质直接推出**根值就是全局最小值**，于是第二小 = 「严格大于根值的最小值」；③ $n$ 只有 25，怎么写都能过，但剪枝写法（只展开同值节点）对任意规模都成立，是这道签到题真正的收益点。

## 2. 示例

**示例 1**

```text
输入：root = [2,2,5,null,null,5,7]
输出：5
解释：节点值共 5 个，集合为 {2, 2, 5, 5, 7}，去重升序是 2 < 5 < 7，
      所以第二小的值是 5。
```

**示例 2**

```text
输入：root = [2,2,2]
输出：-1
解释：三个节点的值全是 2，只有一种取值，不存在第二小的值。
```

**补充示例（自构造，用于对照剪枝效果）**

```text
输入：root = [1,1,3,1,1,3,4]
输出：3
解释：值集合 {1,1,3,1,1,3,4}，去重升序 1 < 3 < 4，第二小是 3；
      注意 3 出现在两个节点上，但它只算"一个值"。
```

## 3. 解题思路

### 3.1 暴力思路

最朴素的两条路：

- **收集 + 排序**：DFS 把所有节点值塞进数组，排序后取第二个不同值。时间 $O(n \log n)$，空间 $O(n)$。
- **两遍 DFS**：第一遍求全局最小值 $\text{minVal}$，第二遍求严格大于 $\text{minVal}$ 的最小值。时间 $O(n)$，空间 $O(h)$。

两条都正确，但都把树当成「普通二叉树」，题面白送的结构性质一点没用上。$n \le 25$ 时当然能过，可换个规模就得重想——所以先把这个性质榨干。

### 3.2 核心观察：根值就是全局最小值

![核心观察：根值是全局最小，答案只能是 minVal 节点的孩子](images/wc48_q1_min_at_root_concept.svg)

**观察一（根值最小）**：对任意节点 $u$，它子树内所有值都 $\ge u.\text{val}$。因为 $u.\text{val} = \min(l.\text{val}, r.\text{val}) \le l.\text{val}$，而按归纳 $l$ 子树内每个值又 $\ge l.\text{val}$。取 $u$ 为根即得：**根值就是全局最小值**，记为 $\text{minVal}$，不必再求一遍（严格证明见 §5 引理 1）。

**观察二（答案的刻画）**：把所有出现过的不同值升序排成 $v_0 < v_1 < \cdots$，由观察一 $v_0 = \text{minVal}$，而「第二小」按定义就是 $v_1$：

$$v_1 = \min\{v : v > \text{minVal}\}$$

问题于是变成「在树中找严格大于根值的最小值」。若该集合为空（全树同值），输出 `-1`。

**观察三（候选只在同值节点的孩子上）**：设答案 $M$ 取在节点 $u$ 上。从 $u$ 往上走，找**最近的**值为 $\text{minVal}$ 的祖先 $p$（根一定是这样的祖先，且 $p \ne u$）。$p$ 到 $u$ 路径上 $p$ 的孩子 $c$ 满足 $\text{minVal} < c.\text{val} \le M$（下界由"最近"给出，上界由观察一给出，因为 $u$ 在 $c$ 的子树里），而 $M$ 是严格大于 $\text{minVal}$ 的最小值，只能 $c.\text{val} = M$。**结论：答案必定是某个 $\text{minVal}$ 节点的直接孩子**——所以只有值为 $\text{minVal}$ 的节点需要往下展开。

**观察四（遇到更大的值即剪枝）**：由观察一，若 $u.\text{val} > \text{minVal}$，则该子树内所有值都 $\ge u.\text{val}$，最优候选就是 $u.\text{val}$ 本身；结算完这棵子树可以整棵扔掉。

> 💡 **一句话**：根值定死为最小值 ⇒ 问题化为"找严格大于根值的最小值"；又因"子树最小值在根" ⇒ 只需展开同值节点，其余子树一刀剪掉。

### 3.3 算法流程

![算法流程：先序遍历 + 上界剪枝](images/wc48_q1_pruned_dfs_flow.svg)

1. 令 $\text{minVal} = \text{root.val}$，$ans = +\infty$；
2. 调用 `dfs(u)`：
   - $u$ 为空，或 $u.\text{val} \ge ans$ → 直接返回（当前最优已不比它差，整棵子树不可能更优）；
   - $u.\text{val} > \text{minVal}$ → $ans \leftarrow \min(ans, u.\text{val})$，**立即返回**（子树最小值就是它，不会再冒出更小的候选）；
   - 否则 $u.\text{val} = \text{minVal}$，递归 $u$ 的左右孩子；
3. 收尾：$ans$ 仍是 $+\infty$ 说明不存在更大的值，返回 `-1`，否则返回 $ans$。

### 3.4 示例演算

![示例演算：root = [2,2,5,null,null,5,7] 的访问顺序与走查表](images/wc48_q1_example_walkthrough.svg)

以 `root = [2,2,5,null,null,5,7]` 为例，$\text{minVal} = 2$、$ans = +\infty$：

| 步 | 访问节点 | 判断 | 动作 | $ans$ |
|----|----------|------|------|-------|
| ① | 2（根） | $= \text{minVal}$ | 继续递归两个孩子 | $+\infty$ |
| ② | 2（左孩子，叶子） | $= \text{minVal}$ | 没有孩子，直接返回 | $+\infty$ |
| ③ | 5（右孩子） | $> \text{minVal}$ | $ans \leftarrow 5$，剪掉子树 $\{5, 7\}$ | $5$ |

最终 $ans = 5$ → 输出 **5** ✓。整棵树只访问了 3 个节点，`5`、`7` 这两个孙子节点从未进入递归。

再看 `root = [2,2,2]`：三个节点全等于 $\text{minVal}$，全程走「$= \text{minVal}$」分支，$ans$ 一直是 $+\infty$ → 输出 **-1** ✓。

## 4. 算法细节

1. **无穷大必须严格大于值域上界**：节点值可达 $2^{31}-1 = 2147483647$。若把 $+\infty$ 写成 `INT_MAX`，一旦答案恰好是 `INT_MAX`，入口的 $u.\text{val} \ge ans$ 会在 $ans$ 被更新前就把它剪掉，错误地返回 `-1`。C++ 用 `LLONG_MAX`（或 `1LL << 31`），Python 用 `1 << 62`。
2. **两个比较分工不同，不能合并**：入口的 $u.\text{val} \ge ans$ 是"上界剪枝"（不比当前最优更好就走人）；$u.\text{val} > \text{minVal}$ 是"是否结算"。前者用 $\ge$，后者用 $>$，语义分别是"已无必要"和"严格更大"。
3. **minVal 直接取根值**：由引理 1 省掉一遍求最小值的 DFS；递归里统一与这个常量比较，无需向下传参，也无需维护「当前最小值」。
4. **只按同值下探**：递归条件实际是 $u.\text{val} = \text{minVal}$（树中不可能有更小的值，写成 $\le$ 也等价），语义上取 $=$ 更清晰。
5. **递归 vs 显式栈**：$n \le 25$ 时递归深度最多十来层，安全；若换成一棵可能退化成链的一般树，用显式栈（后进先出，与递归同序）更稳。
6. **结算后立即 `return`**：入口已保证 $u.\text{val} < ans$，所以直接写 `ans = u.val` 与 `ans = min(ans, u.val)` 等价；若改成"更新后仍递归孩子"，正确性还在（孩子会被 $u.\text{val} \ge ans$ 剪掉），但白白多一层调用，违背剪枝初衷。
7. **Python 闭包要用 `nonlocal`**：内层 `dfs` 修改外层 `ans` 必须声明 `nonlocal ans`，否则会把它当成新的局部变量（`UnboundLocalError`）；也可把 `ans` 放进单元素列表或 `self.ans`。

## 5. 正确性证明

**引理 1（子树最小值在根）**：对任意节点 $u$，$u$ 的子树内所有节点的值都 $\ge u.\text{val}$。

**证明**：对子树高度归纳。$u$ 为叶子时只有自己，成立。$u$ 有孩子 $l, r$ 时，题设给出 $u.\text{val} = \min(l.\text{val}, r.\text{val})$，故 $u.\text{val} \le l.\text{val}$、$u.\text{val} \le r.\text{val}$；由归纳假设 $l$ 子树内的值都 $\ge l.\text{val} \ge u.\text{val}$，$r$ 子树同理，故整个子树内的值都 $\ge u.\text{val}$。∎

**引理 2（答案的刻画）**：记 $\text{minVal} = \text{root.val}$。若存在值 $> \text{minVal}$，则答案是 $\min\{v : v > \text{minVal}\}$；否则答案是 `-1`。

**证明**：由引理 1 取 $u = \text{root}$，$\text{minVal}$ 是全局最小值。设不同值升序为 $v_0 < v_1 < \cdots$，则 $v_0 = \text{minVal}$，「第二小」按定义为 $v_1$，即集合 $\{v : v > \text{minVal}\}$ 的最小元；集合为空时不存在第二小值，返回 `-1`。∎

**引理 3（剪枝合法）**：若 $u.\text{val} > \text{minVal}$，则子树 $u$ 中的最优候选恰为 $u.\text{val}$。

**证明**：由引理 1，子树 $u$ 内任意节点值 $\ge u.\text{val}$，故该子树对集合 $\{v : v > \text{minVal}\}$ 的贡献只能来自 $\ge u.\text{val}$ 的值，其中最小者正是 $u.\text{val}$（$u$ 自己就在子树内）。因此写入 $u.\text{val}$ 之后，子树内不可能再有更优候选，整棵剪掉不影响答案。∎

**引理 4（完备性）**：若答案 $M$ 存在，算法必定访问到某个值为 $M$ 的节点。

**证明**：取值为 $M$ 的节点 $u$，令 $p$ 为从 $u$ 向根方向**最近的**值为 $\text{minVal}$ 的祖先（根是候选故存在；又 $M > \text{minVal}$ 故 $p \ne u$）。设 $c$ 是 $p$ 在该路径上的孩子。由引理 1，$c.\text{val} \le u.\text{val} = M$；由 $	ext{minVal}$ 的全局最小性 $c.	ext{val} \ge \text{minVal}$，由 $p$ 的"最近性" $c.\text{val} \ne 	ext{minVal}$，故 $c.	ext{val} > 	ext{minVal}$；于是 $\text{minVal} < c.\text{val} \le M$，而 $M$ 是严格大于 $\text{minVal}$ 的最小值，只能 $c.\text{val} = M$。算法在 $p$ 处因 $p.\text{val} = \text{minVal}$ 递归到 $c$，并在 $c$ 处因 $c.\text{val} > \text{minVal}$ 结算，不会漏。∎

**定理**：算法返回值等于题目要求的第二小值；第二小值不存在时返回 `-1`。

**证明**：由引理 3，算法写入 $ans$ 的每个值都是所在子树的最优候选且 $> \text{minVal}$；由引理 4，答案一旦存在必被某次结算写入，故 $ans$ 的终值要么是 $\min\{v : v > \text{minVal}\}$，要么保持 $+\infty$。再由引理 2 得到题面要求的输出；$+\infty$ 用严格大于值域上界的数表示，不会与任何合法答案混淆。∎

## 6. 复杂度分析

- **时间**：最坏 $O(n)$。递归只对值为 $\text{minVal}$ 的节点继续下探，其余节点被访问一次即返回；精确地说，被访问的节点集合包含于「值为 $\text{minVal}$ 的节点」$\cup$「它们的直接孩子」，故实际是 $O(m)$，$m$ 为这两类节点的个数，$m \le n$。示例中 $m = 3$，子树 $\{5, 7\}$ 一次都没进。
- **空间**：$O(h)$，$h$ 为递归深度，只压栈同值链上的节点；最坏（全树同值）为 $O(n)$，本题 $n \le 25$ 时可忽略。
- **对比**：收集全部值再排序为 $O(n \log n)$ 时间 / $O(n)$ 空间；在最小值节点稀疏的大树上，剪枝版与它们的差距可达一个数量级。

## 7. 参考代码

### C++

```cpp
#include <climits>

struct TreeNode {
    int val;
    TreeNode *left;
    TreeNode *right;
    TreeNode() : val(0), left(nullptr), right(nullptr) {}
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
    TreeNode(int x, TreeNode *l, TreeNode *r) : val(x), left(l), right(r) {}
};

class Solution {
public:
    int findSecondMinimumValue(TreeNode *root) {
        long long ans = LLONG_MAX;             // 必须严格大于 2^31-1，不能用 INT_MAX
        dfs(root, root->val, ans);
        return ans == LLONG_MAX ? -1 : (int)ans;
    }

private:
    void dfs(TreeNode *u, int minVal, long long &ans) {
        if (!u || u->val >= ans) return;       // 上界剪枝：不比当前最优更好
        if (u->val > minVal) {                 // 子树最小值就是 u->val，结算后剪枝
            ans = u->val;
            return;
        }
        dfs(u->left, minVal, ans);             // u->val == minVal，继续下探
        dfs(u->right, minVal, ans);
    }
};
```

### Python

```python
from typing import Optional


class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right


class Solution:
    def findSecondMinimumValue(self, root: Optional[TreeNode]) -> int:
        INF = 1 << 62                 # 严格大于 2^31-1
        min_val = root.val            # 根值即全局最小值
        ans = INF

        def dfs(u: Optional[TreeNode]) -> None:
            nonlocal ans
            if u is None or u.val >= ans:     # 上界剪枝
                return
            if u.val > min_val:               # 子树最小就是它，结算后剪枝
                ans = u.val
                return
            dfs(u.left)                       # u.val == min_val，继续下探
            dfs(u.right)

        dfs(root)
        return -1 if ans == INF else ans
```

> 💡 也可以写成显式栈：把 `root` 压栈，弹栈时套用同样的两条判断，遇到同值节点就压入其两个孩子——与上面递归版本完全等价，且不用担心递归深度。

## 8. 边界情况与易错点

1. **单节点树**：`root = [1]`，没有第二小值，返回 `-1`；根是叶子，DFS 一次即结束。
2. **全树同值**：`[2,2,2]` 或任意全为 $c$ 的树 → $ans$ 保持 $+\infty$ → 返回 `-1`；判据就是 `ans == INF`。
3. **`INT_MAX` 陷阱（最隐蔽）**：值域上界是 $2^{31}-1$，若 $+\infty$ 用 `INT_MAX`，数据 `[1,1,2147483647,1,1]` 会被误判成 `-1`。参见 §4 第 1 条。
4. **答案可能在更深的层**：别以为第二小就是"根的右孩子"。`[1,1,1,2,3,2,9]` 中根的右孩子仍是 1，答案 2 在孙子层——所以值为 $\text{minVal}$ 的节点必须继续下探。
5. **`ans` 千万别初始化成 `-1` / `0`**：值都是正数，那样入口的 $u.\text{val} \ge ans$ 恒成立，整棵树被剪光，直接返回 `-1`。
6. **重复值只算一个**：`[2,2,5,null,null,5,7]` 里有两个 5，但答案是 5 而不是 7；判断必须用「严格大于 $\text{minVal}$」，不能按"第二个不同的访问值"来数。
7. **Python 作用域**：内层函数修改 `ans` 忘了 `nonlocal` 会抛 `UnboundLocalError`；C++ 则要把 `ans` 用引用传入，按值传递会丢掉更新。
