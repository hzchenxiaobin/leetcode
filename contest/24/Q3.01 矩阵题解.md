# LeetCode 01 矩阵 题解

## 1. 题目概述

- **标题 / 题号**：01 矩阵（#542，medium）
- **链接**：https://leetcode.cn/problems/01-matrix/
- **来源**：LeetCode 第 24 场周赛 Q3
- **难度**：中等
- **标签**：广度优先搜索、数组、动态规划、矩阵

**题意**：给定一个只含 `0`、`1` 的 $m \times n$ 矩阵 `mat`，返回同样大小的矩阵 `dist`，其中 `dist[i][j]` 是 `mat[i][j]` 到**最近的 0** 的**步数**（上下左右相邻算一步）。若该格本身就是 `0`，距离为 `0`。等价说法：以所有 `0` 为源，求每个格子的最短路长度。

**约束**：

- $1 \le m, n \le 10^4$
- $1 \le m \times n \le 10^4$
- `mat[i][j]` 是 `0` 或 `1`
- `mat` 中至少有一个 `0`（保证答案存在，不会出现无解）

> 💡 **关键规模**：格子总数最多 $10^4$，但行、列**各自**可达 $10^4$（另一维退化成 1）。所以复杂度只应以 $m \times n$ 为单位衡量，任何「逐格再扫全图」的平方级做法都要掂量一下。

## 2. 示例

**示例 1**

```text
输入：mat = [[0,0,0],[0,1,0],[0,0,0]]
输出：[[0,0,0],[0,1,0],[0,0,0]]
解释：唯一的 1 被 0 四面包围，距离为 1。
```

**示例 2**

```text
输入：mat = [[0,0,0],[0,1,0],[1,1,1]]
输出：[[0,0,0],[0,1,0],[1,2,1]]
解释：(2,1) 上下左右的 0 都不直接相邻：
      (2,0) 与 (2,2) 距离为 1，故 (2,1) 的距离为 2。
```

**示例 3（自造，一维退化）**

```text
输入：mat = [[0,1,1,1]]
输出：[[0,1,2,3]]
解释：m = 1 时只能沿横向走，距离就是下标差。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的写法：对每个格子单独做一次 BFS，直到碰到 `0` 为止。

- 单次 BFS 最坏访问全部 $m n$ 个格子；
- 一共 $m n$ 个格子 → 总时间 $O\bigl((mn)^2\bigr)$；
- 当 $m n = 10^4$ 时约 $10^8$ 次队列操作，C++ 勉强、Python 必然超时。

另一种「看起来聪明」的暴力：因为网格里**没有障碍**（`1` 只是待求值的格子，不是墙），两点间距离就是曼哈顿距离，于是可以直接枚举所有 `0` 取 $\min\bigl(\lvert i-a\rvert + \lvert j-b\rvert\bigr)$。但 0 的个数可达 $m n$，总时间仍是 $O\bigl((mn)^2\bigr)$。它可以作为对拍用的独立暴力，却不能当正解。

### 3.2 核心观察：多源 BFS

![多源 BFS 核心观察](images/wc24_q3_multisource_bfs.svg)

真正的浪费在于：**每格各跑一次 BFS，等于把同一片 0 反复搜索了 $m n$ 遍**。而题目要的是「到最近 0 的距离」，所有 `0` 的地位完全对等——它们都是距离为 $0$ 的起点。

于是把问题改写成**单源最短路**：虚构一个超级源点 $S$，向每个 `mat[i][j] == 0` 的格子连一条权为 $0$ 的边。则

$$dist[i][j] = \operatorname{shortest}(S \to (i,j))$$

在无权（边权全为 1）的网格图上，这个最短路就是 **BFS 层数**。实现上不需要真的建超级源点，只要**一开始把所有 0 全部压进队列**（`dist = 0`），再从它们同时向外扩散即可——这就是**多源 BFS**。

它带来的两个直接好处：

1. **每个格子只被访问一次**。第一次被写入的距离就是最近的 0 给的距离，之后再也不会被更新（后写入的只会更大）。
2. **天然分层**。队列按层推进，第 $k$ 层恰好是距离 $k$ 的全部格子，答案就是「入队时被写下的那个数」。

> ⚠️ 与「对每个 0 各做一次 BFS 再取 min」的区别：后者是 $O\bigl((mn)^2\bigr)$，前者把 $m n$ 次搜索合并成 1 次，是 $O(mn)$。

### 3.3 算法流程

![多源 BFS 流程](images/wc24_q3_bfs_flow.svg)

1. 建 `dist` 矩阵，初值全为 $-1$（表示「未访问」）。
2. 扫描一遍矩阵，把所有 `mat[i][j] == 0` 的格子 `dist` 置 $0$ 并入队。
3. 循环：队首出队 $(x,y)$，枚举四邻 $(nx,ny)$：
   - 若越界，跳过；
   - 若 `dist[nx][ny] != -1`（已访问），跳过；
   - 否则 `dist[nx][ny] = dist[x][y] + 1`，并入队。
4. 队列为空时返回 `dist`。

用一行伪代码概括转移：

$$dist[nx][ny] = \min\bigl(dist[nx][ny],\ dist[x][y] + 1\bigr) \quad\text{（仅当未访问时写入，等价于取一次 min）}$$

因为「未访问」的初值是 $-\infty$ 语义上的无穷大，第一次写入就完成了这次 `min`。

### 3.4 示例演算

![示例 2 逐层演算](images/wc24_q3_walkthrough.svg)

对示例 2 的 `mat = [[0,0,0],[0,1,0],[1,1,1]]`：

| 阶段 | 队列内容（dist） | 新写入的格子 |
|------|------------------|--------------|
| ① 初始 | 5 个 0（dist = 0） | `(0,0)(0,1)(0,2)(1,0)(1,2)` 全为 0 |
| ② 第 1 层 | 出队 5 个 0，入队 3 个 1 | `(1,1) (2,0) (2,2)` 写入 1 |
| ③ 第 2 层 | 出队 3 个 1，入队 1 个 2 | `(2,1)` 写入 2，队列清空 |

最终 `[[0,0,0],[0,1,0],[1,2,1]]`，与官方输出一致。注意 `(2,1)` 是在第 2 层才被写到的——它在第 1 层出队时还没有任何邻居被访问，只能等邻居 `(2,0)`、`(1,1)`、`(2,2)` 出队后再被赋值。

## 4. 算法细节

1. **`dist` 兼作访问标记**。初值 $-1$ 表示未访问，BFS 时用 `dist[nx][ny] == -1` 判重，不必额外开 `visited`。**不要用 0 判重**——源点本身就是 0，会被误判成「已访问而值不对」。
2. **一次性全部入队**。初始扫描必须把所有 0 都压进队列后再开始扩散，不能只入队第一个 0 就跑 BFS（那样得到的是「到该 0 的距离」）。
3. **不需要显式分层**。本题只要距离值，`dist[nx][ny] = dist[x][y] + 1` 即可；只有当题目问「第几层」时（如腐烂的橘子求轮数）才需要用 `for (int k = q.size(); k--; )` 逐层处理。
4. **坐标压缩**。用 `id = x * n + y` 存 `int` 队列，比 `pair<int,int>` 更省内存、更快；$m n \le 10^4$ 时差别不大，但这是周赛里值得养成的写法。
5. **不要修改输入**。`mat` 是按引用传入的，若想原地把 `mat` 当 `dist` 用（把 1 改成 -1），调用者的数组会被破坏；LeetCode 判题虽不检查，但这是坏习惯。
6. **四邻写法**。用 `dx[4] = {1,-1,0,0}`、`dy[4] = {0,0,1,-1}` 循环展开，配合 `nx < 0 || nx >= m` 的短路判断，比四段 if 更不容易写错。
7. **等价解法：两趟 DP**。先按「上、左」松弛一遍，再按「下、右」松弛一遍，也能得到正确答案：

   $$dist[i][j] = \begin{cases} 0, & mat[i][j]=0 \\ \min(dist[i-1][j],\ dist[i][j-1],\ dist[i+1][j],\ dist[i][j+1]) + 1, & \text{否则} \end{cases}$$

   两趟扫描各 $O(mn)$，且无需队列。缺点是初值必须用一个足够大的数（如 $10^9$），不能取 `INT_MAX` 后 `+1`（有符号溢出是未定义行为）。
8. **队列容量**。每个格子最多入队一次，队列峰值不超过 $m n$，`std::queue` 自动扩容即可；手写数组队列时开 $m n + 1$ 就够。

## 5. 正确性证明

记 $d(i,j)$ 为格子 $(i,j)$ 到最近 `0` 的真实最短步数，$D(i,j)$ 为算法写入的 `dist` 值。

**引理 1（写入值对应一条真实路径）**：若算法给 $(i,j)$ 写入 $D(i,j) = k$，则存在一条长度恰为 $k$、从某 `0` 出发到达 $(i,j)$ 的路径，从而 $d(i,j) \le k$。

**证明**：对 $k$ 归纳。$k = 0$ 时该格子本身是 `0`，路径长 $0$ 成立。$k > 0$ 时它是由某个已出队的格子 $(x,y)$ 扩展而来，$(x,y)$ 与 $(i,j)$ 相邻且 $D(x,y) = k-1$；由归纳假设存在长度 $k-1$ 的路径到达 $(x,y)$，再走一步即得长度 $k$ 的路径到达 $(i,j)$。∎

**引理 2（出队序按距离不减）**：算法过程中队列里的 `dist` 值单调不减，因此出队序列的 `dist` 非降。

**证明**：初始时所有元素 `dist = 0`。归纳假设当前队列 `dist` 非降。每次取出队首 $v$（其值是该队列的最小值 $k$），并把若干 `dist = k+1` 的元素压到队尾；由于队尾原有元素的值 $\ge k$，新队列仍非降。∎

**引理 3（上界）**：对任意格子 $v$，若它被访问，则 $D(v) \le d(v)$。

**证明**：对 $d(v)$ 归纳。$d(v) = 0$ 即 $v$ 是 `0`，算法初始就写入 $D(v)=0$。设 $d(v) = t > 0$，取最短路径上 $v$ 的前驱 $u$，有 $d(u) = t-1$，由归纳假设 $D(u) \le t-1$。由于 $u$ 最终**一定**会出队（它已入队，队列按 FIFO 排空），出队时检查邻居 $v$：若 $v$ 尚未访问，则写入 $D(v) = D(u)+1 \le t$；若 $v$ 已访问，则它当初写入的值至多也是 $t$（由同样的论证），且值写入后不再改变。两种情形都有 $D(v) \le t = d(v)$。∎

**引理 4（所有格子都会被访问）**：BFS 结束时每个格子的 `dist` 都不是 $-1$。

**证明**：网格在四邻接意义下连通（所有格子可通行，`1` 不是障碍），且至少有一个 `0` 作为源点。标准 BFS 会访问源点所在连通块的全部顶点，故全部 $m n$ 个格子都被访问。∎

**定理**：算法返回的 `dist` 满足 $D(i,j) = d(i,j)$，即答案正确。

**证明**：由引理 4 每个格子都有 $D$ 值；由引理 1 得 $d(i,j) \le D(i,j)$，由引理 3 得 $D(i,j) \le d(i,j)$，故相等。∎

## 6. 复杂度分析

- **时间**：$O(m n)$。初始化扫描 $O(m n)$；每个格子至多入队、出队各一次，每次出队检查 4 个邻居，总计 $O(m n)$ 次邻居检查。队列操作均为 $O(1)$。
- **空间**：$O(m n)$。答案矩阵 $m n$ 个整数；队列峰值不超过 $m n$ 个元素（用坐标压缩时每个元素 4 字节）。没有额外的 `visited` 矩阵（复用 `dist` 的 $-1$）。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <queue>
using namespace std;

class Solution {
public:
    vector<vector<int>> updateMatrix(vector<vector<int>>& mat) {
        int m = mat.size(), n = mat[0].size();
        vector<vector<int>> dist(m, vector<int>(n, -1));   // -1 表示未访问
        queue<pair<int, int>> q;

        // 多源初始化：所有 0 同时作为源点
        for (int i = 0; i < m; ++i)
            for (int j = 0; j < n; ++j)
                if (mat[i][j] == 0) {
                    dist[i][j] = 0;
                    q.push({i, j});
                }

        const int dx[4] = {1, -1, 0, 0};
        const int dy[4] = {0, 0, 1, -1};

        while (!q.empty()) {
            auto [x, y] = q.front();
            q.pop();
            for (int d = 0; d < 4; ++d) {
                int nx = x + dx[d], ny = y + dy[d];
                if (nx < 0 || nx >= m || ny < 0 || ny >= n) continue;  // 越界
                if (dist[nx][ny] != -1) continue;                      // 已访问
                dist[nx][ny] = dist[x][y] + 1;
                q.push({nx, ny});
            }
        }
        return dist;
    }
};
```

### Python

```python
from collections import deque


class Solution:
    def updateMatrix(self, mat: list[list[int]]) -> list[list[int]]:
        m, n = len(mat), len(mat[0])
        dist = [[-1] * n for _ in range(m)]      # -1 表示未访问
        q = deque()

        # 多源初始化：所有 0 同时入队
        for i in range(m):
            for j in range(n):
                if mat[i][j] == 0:
                    dist[i][j] = 0
                    q.append((i, j))

        dirs = ((1, 0), (-1, 0), (0, 1), (0, -1))
        while q:
            x, y = q.popleft()
            for dx, dy in dirs:
                nx, ny = x + dx, y + dy
                if 0 <= nx < m and 0 <= ny < n and dist[nx][ny] == -1:
                    dist[nx][ny] = dist[x][y] + 1
                    q.append((nx, ny))

        return dist
```

## 8. 边界情况与易错点

1. **没有 1**：`mat` 全为 0 → 答案全 0。算法里不会有任何扩展，直接返回全 0 的 `dist`，无需特判。
2. **只有一个 0、其余全 1**：答案退化为曼哈顿距离。这是检验「多源」是否写对的最简用例（如果漏了部分源点就会偏大）。
3. **一维退化**：$m = 1$ 或 $n = 1$。此时 `nx >= m`、`ny >= n` 的边界判断必须成对出现，少写一个就会越界读取。
4. **误用 0 做访问标记**：若 `dist` 初值为 0（而不是 -1）再用 `dist == 0` 判重，源点会被当成「已访问」而跳过扩散，答案全错。必须用 $-1$ 或 `INF` 作为未访问标记。
5. **只入队第一个 0**：这是最容易犯的逻辑错误——那求的是「到某个特定 0 的距离」，不是「到最近的 0」。
6. **两趟 DP 的溢出**：若改用 DP 写法，初值用 $10^9$ 而不是 `INT_MAX`；`INT_MAX + 1` 是有符号溢出（未定义行为），在开启优化的编译器上会静默出错。
7. **Python 的递归/队列**：用 `deque` 而非 `list.pop(0)`；`list.pop(0)` 是 $O(n)$，在 $10^4$ 个格子上会把 $O(mn)$ 拖成 $O((mn)^2)$。
8. **题目输入规模陷阱**：$m, n$ 各自可达 $10^4$，但乘积不超过 $10^4$，所以**不能**开 `int dist[10000][10000]` 的静态数组，必须用 `vector` 动态分配。

**延伸思考**：

1. 若 `1` 变成**不可通行的墙**，本题的多源 BFS 只要在扩展时跳过障碍即可，复杂度仍是 $O(mn)$；但「曼哈顿距离」这个暴力就失效了，对拍必须换成逐格 BFS。
2. 若每走一步的**代价不同**（例如进入某些格子的花费是 $0$ 或 $1$），则要用 **0-1 BFS**（双端队列）或 Dijkstra，多源初始化方式不变。
3. 若要求「每个格子到最近 $k$ 个 0 的距离之和」，可以在 BFS 时让每个格子最多被写入 $k$ 次（用计数代替 `visited`），复杂度 $O(k m n)$。
