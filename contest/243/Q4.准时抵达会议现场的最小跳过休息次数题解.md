# LeetCode 准时抵达会议现场的最小跳过休息次数 题解

## 1. 题目概述

- **标题 / 题号**：准时抵达会议现场的最小跳过休息次数（#1883，hard）
- **链接**：https://leetcode.cn/problems/minimum-skips-to-arrive-at-meeting-on-time/
- **来源**：LeetCode 第 243 场周赛 Q4
- **难度**：困难
- **标签**：动态规划、数学、数组

**题意**：要按顺序走完 $n$ 条道路，第 $i$ 条长 $\text{dist}[i]$ 千米，速度恒为 $\text{speed}$ 千米/小时。走完第 $i$ 条路（$i < n-1$）后必须**休息**，等待到**下一个整数小时**才能走下一条路；可以选择**跳过**某些休息（跳过 = 不等待，立即出发）。走完最后一条路即到达会议现场。给定可用时间 $\text{hoursBefore}$，求**最少跳过几次休息**能准时到达；无法准时则返回 $-1$。

**约束**：

- $1 \le n = \text{dist.length} \le 1000$
- $1 \le \text{dist}[i] \le 10^5$
- $1 \le \text{speed} \le 10^6$
- $1 \le \text{hoursBefore} \le 10^7$

> 💡 本题在本仓库另有[每日题解 1883](../../solution/1801-1900/1883_准时抵达会议现场的最少跳过数.md)，两篇为姊妹篇：每日版侧重「用距离替代时间」的浮点规避技巧、与 1870「二分 vs DP」的对照和面试问答。本篇按周赛复盘视角展开：**休息取整的级联效应**、**贪心选位的反例**、**引理-定理链证明**（单调性 / 时间支配性 / 无后效性），并按比赛版原始接口（$\text{hoursBefore}$ 为整数）给出更干净的整数化写法。

## 2. 示例

**示例 1**

```text
输入：dist = [1,3,2], speed = 4, hoursBefore = 2
输出：1

解释：
不跳过：0.25h 走完路0，等到 1h 出发；1.75h 走完路1，等到 2h 出发；2.5h 到达 —— 迟到。
跳过第 1 次休息：路0 + 路1 连续行驶，恰在 1.0h（整点）走完路1，
  路1 后的休息等待自动为 0；1.0h 出发走路2，1.5h 到达 ≤ 2h。
```

**示例 2**

```text
输入：dist = [7,3,5,5], speed = 2, hoursBefore = 10
输出：2

解释：
不跳过任何休息共需 (7/2 + 1/2) + (3/2 + 1/2) + (5/2 + 1/2) + (5/2) = 11.5h。
跳过第 1、3 次休息：3.5 + 1.5 = 5.0h 恰为整点（中间等待为 0），
  再 2.5 + 2.5 = 5.0h，总时间恰好 10h，赶上会议。
```

**示例 3**

```text
输入：dist = [7,3,5,5], speed = 1, hoursBefore = 10
输出：-1

解释：speed = 1 时每段路的耗时都是整数，所有休息的等待都为 0，
  跳不跳结果都一样：总时间恒为 7 + 3 + 5 + 5 = 20h > 10h，无解。
```

## 3. 解题思路

### 3.1 暴力思路

每个休息点有「跳 / 不跳」两种选择，共 $n-1$ 个休息点 → $2^{n-1}$ 种组合。$n \le 1000$ 时这是天文数字；即使单种组合只需 $O(n)$ 模拟，组合爆炸也直接判死暴力。

退一步想一个**简化版**：如果只允许跳 1 次，能做吗？能——枚举跳第 $k$ 个休息，$O(n)$ 模拟一遍，取最优，共 $O(n^2)$。这提示：**「跳过次数」作为一维状态是可枚举的**，这正是 DP 的雏形。

> ⚠️ 另一个隐蔽的坑：直接用浮点数累加 $\text{dist}[i] / \text{speed}$、逐段 `ceil`，在「总和恰为整数」「恰好压线」的边界用例上会因浮点误差判错（详见 §8）。

### 3.2 核心观察：休息 = 向上取整，且跳过会「级联」

把「走完第 $i$ 条路的时刻」记为 $t_i$（小时），规则翻译成一行公式：

$$t_i = \lceil t_{i-1} \rceil + \frac{\text{dist}[i]}{\text{speed}} \;\;(\text{休息版})， \qquad t_i = t_{i-1} + \frac{\text{dist}[i]}{\text{speed}} \;\;(\text{跳过版})$$

即：**休息就是一次向上取整**（取整到下一个整点），**跳过就是不做这次取整**。

![核心观察：休息=向上取整，跳过可级联](images/minskips_rest_rounding.svg)

观察示例 1 的两条时间线，有一个容易漏掉的现象——**级联**：跳过第 1 次休息后，路0 + 路1 连续行驶恰好在 **1.0h 整点**结束，于是路1 后面那次休息的等待**自动变成 0**——一次跳过「顺带」消掉了两次等待。跳过位置选得好，收益会滚动放大。

两个后续证明中要用的结构性质：

> 💡 **性质 1（跳过永不吃亏）**：对任意时刻 $t \ge 0$ 有 $t \le \lceil t \rceil$，所以**单看一步**，跳过后的到达时刻不会更晚。

> 💡 **性质 2（贪心选位不可行）**：性质 1 只保证「跳过不亏」，**不保证「跳哪儿都一样」**。各次取整互相耦合，一次跳过可能让后面的到达恰好落在整点（收益级联），也可能白跳（见 3.3 反例）。

### 3.3 为什么不能贪心：一个反例

构造 $\text{dist} = [5,2,3,1]$，$\text{speed} = 5$，$\text{hoursBefore} = 3$：

![贪心反例：跳过位置选错等于白跳](images/minskips_greedy_counter.svg)

- **方案 A（跳第 1 次休息）**：路0 恰好 1.0h 走完，本来就是整点、等待为 0，这次跳过**被白白浪费**；后面 1.4h→2h、2.6h→3h 两处等待一分没省，总时间 **3.2h > 3h，迟到**。
- **方案 B（跳第 2 次休息）**：路1 + 路2 连续行驶恰在 **2.0h 整点**结束，既省掉了 0.6h 的等待，又让下一处休息等待自动为 0（级联），总时间 **2.2h ≤ 3h，准时**。

同样跳 1 次，一个 3.2h 一个 2.2h。**「能跳就跳」「跳最早的」都没有安全保证——跳过位置是全局组合问题**，这正是本题必须 DP 的原因。

### 3.4 状态设计与转移

把「已走路数」和「已跳次数」都放进状态：

$$f[i][j] = \text{已走完第 } 0 \sim i \text{ 条路、至多跳过 } j \text{ 次休息时，最早的到达时刻（单位：小时} \times \text{speed）}$$

> ⚠️ **为什么乘 $\text{speed}$**：$f$ 的递推每一步都要做 $\lceil f / \text{speed} \rceil \times \text{speed}$，若 $f$ 以「小时」为单位就是小数；**把单位换成 $\text{speed} \times$ 小时（正好是千米）后**，走一条路恰好增加整数 $\text{dist}[i]$，「整点」恰好是 $\text{speed}$ 的倍数——全程变成**纯整数运算**，零精度误差。

两条转移对应第 $i$ 条路出发前的那次休息（$j = 0$ 时无跳过分支）：

$$f[i][j] = \min\Big(\underbrace{\big\lceil f[i-1][j] / \text{speed} \big\rceil \times \text{speed} + \text{dist}[i]}_{\text{休息：等整点再出发}}， \;\; \underbrace{f[i-1][j-1] + \text{dist}[i]}_{\text{跳过：立即出发，} j \to j+1}\Big)$$

边界 $f[0][j] = \text{dist}[0]$（首条路前没有休息可跳）；答案为**最小的** $j$ 使 $f[n-1][j] \le \text{hoursBefore} \times \text{speed}$。

![状态设计与两条转移](images/minskips_dp_transition.svg)

### 3.5 示例演算

以示例 2（$\text{dist} = [7,3,5,5]$，$\text{speed} = 2$，$\text{limit} = 10 \times 2 = 20$ 千米）为例填表：

![示例演算：DP 表与答案提取](images/minskips_dp_table.svg)

- $i=1$：$f[1][0] = \lceil 7/2 \rceil \times 2 + 3 = 11$；$f[1][1] = \min(11,\, 7+3) = 10$（跳过休息 0 更优）；
- $i=3$：$f[3][1] = \min(\lceil 15/2 \rceil \times 2 + 5,\; 17 + 5) = \min(21, 22) = 21$，**就差 1 千米**；
  $f[3][2] = \min(\lceil 15/2 \rceil \times 2 + 5,\; 15 + 5) = \min(21, 20) = 20 \le 20$ ✓；
- 逐 $j$ 检查：$j=0$：$23$ ✗，$j=1$：$21$ ✗，$j=2$：$20$ ✓ → **答案 2**。

回溯最优方案：$f[3][2] \leftarrow$ 跳过休息 2（$f[2][1] + 5$）$\leftarrow f[2][1] \leftarrow$ 休息（$f[1][1]$ 取整后 $+5$）$\leftarrow f[1][1] \leftarrow$ 跳过休息 0（$7+3$）——即跳过第 1、3 次休息（1 编号），与官方解释一致，总时间恰为 $20 / 2 = 10$ 小时。

## 4. 算法细节

1. **单位统一为「千米」**：$f$ 存的是 $\text{speed} \times$ 小时。上取整用整数公式 $\lceil a/b \rceil = \lfloor (a+b-1)/b \rfloor$，代码写作 `(f + speed - 1) / speed * speed`。
2. **「至多 $j$ 次」语义**：$f[0][j] = \text{dist}[0]$ 对**所有** $j$ 成立（0 次跳过也满足「至多 $j$」），该语义下所有格子天然有限，**无需 INF 哨兵**，比「恰好 $j$ 次」的写法干净。
3. **$j$ 的范围**：只有 $n-1$ 个休息，$j$ 循环 $0 \sim n-1$ 即可。
4. **滚动数组 + 倒序**：$f[i][j]$ 只依赖上一行的 $f[i-1][j]$ 与 $f[i-1][j-1]$；压成一维后，内层 $j$ **必须从大到小**遍历（0-1 背包同款），保证「跳过」分支读 $f[j-1]$ 时拿到的仍是上一行旧值。
5. **答案判定**：$\text{limit} = \text{hoursBefore} \times \text{speed}$ 最大 $10^7 \times 10^6 = 10^{13}$，C++ 必须 `long long`。
6. **无解**：所有 $j$ 均超限则返回 $-1$。全跳（$j = n-1$）时 $f = \sum \text{dist}$，它超时则必然无解，无需特判。

## 5. 正确性证明

**引理 1（跳过单步不减）**：对任意 $t \ge 0$、整数 $s \ge 1$，有 $t \le \lceil t/s \rceil \cdot s$。

**证明**：由 $\lceil t/s \rceil \ge t/s$，两边同乘 $s > 0$ 即得。∎

**推论 1（单调性）**：$f[i][j+1] \le f[i][j]$ 对一切 $i, j$ 成立；且「可行 $j$」构成一段后缀，答案 = 第一个满足 $f[n-1][j] \le \text{limit}$ 的 $j$。

**证明**：「至多 $j+1$ 次」的方案集合包含「至多 $j$ 次」的方案集合，取最小值只会不变或变小，得单调性。记 $S = \{\, j : f[n-1][j] \le \text{limit} \,\}$：一方面 $j \in S$ 当且仅当存在跳过次数 $\le j$ 的准时方案；另一方面最小跳过次数恰为 $\min S$——任一准时方案的跳过次数 $k$ 都满足 $k \in S$，而 $j \in S$ 又说明存在跳过次数 $\le j$ 的方案。由单调性 $S$ 是一段后缀，$\min S$ 即第一个满足不等式的 $j$。∎

**引理 2（时间支配性）**：设两条历史都走完了前 $i+1$ 条路、至多 $j$ 次跳过，到达时刻（千米）满足 $t_1 \le t_2$。则对**任意**相同的后续决策序列，从 $t_1$ 出发的最终时刻 $\le$ 从 $t_2$ 出发的。

**证明**：对剩余路数归纳。单步转移 $g_{\text{休}}(t) = \lceil t/s \rceil \cdot s + d$ 与 $g_{\text{跳}}(t) = t + d$ 都是 $t$ 的单调不减函数（上取整与加法均单调）。归纳步：$t_1 \le t_2 \Rightarrow t_1' \le t_2'$，且两侧剩余跳数同步变化（休息不变、跳过同减 1），套归纳假设即得。∎

**引理 3（无后效性）**：走完前 $i+1$ 条路后，后续的最优决策只依赖（当前时刻，剩余可跳次数），与「具体跳过了哪几次」无关。

**证明**：后续过程中一切取值只经由 $g_{\text{休}}, g_{\text{跳}}$ 作用于当前时刻；除「时刻」与「剩余跳数」外，跳过历史不再进入任何后续计算，状态信息充分。∎

**定理**：上述 DP 返回最小跳过次数；无解时返回 $-1$。

**证明**：
①（可达性刻画）对 $i$ 归纳：$f[i][j]$ 是「至多 $j$ 次跳过走完前 $i+1$ 条路」全部方案中到达时刻的最小值。$i=0$ 时唯一方案给出 $f[0][j] = \text{dist}[0]$；归纳步中第 $i$ 条路出发前只有「休息 / 跳过」两种决策，转移两支恰好枚举二者，且由引理 2，同一决策支下仅保留最小时刻不损失最优性。
②（答案正确）由 ①，$f[n-1][j] \le \text{limit}$ 当且仅当存在至多 $j$ 次跳过的准时方案；由推论 1，第一个满足的 $j$ 即最小跳过次数。
③（无解正确）跳过次数超过 $n-1$ 无意义（只有 $n-1$ 个休息），故所有 $j \le n-1$ 均不满足时不存任何准时方案，返回 $-1$ 正确。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n^2)$
  - 外层遍历 $n-1$ 条路，内层遍历 $O(n)$ 个跳过数，共约 $10^6$ 次整数运算（$n \le 1000$），轻松通过。
- **空间复杂度**：$O(n)$
  - 一维滚动数组；若存满整张表则为 $O(n^2)$，非必需。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int minSkips(vector<int>& dist, int speed, int hoursBefore) {
        int n = dist.size();
        long long limit = 1LL * hoursBefore * speed;   // 最多 10^13，必须 long long

        // f[j]：走完前 i+1 条路、至多跳过 j 次休息的最早到达时刻（单位：小时 × speed）
        vector<long long> f(n, dist[0]);               // 边界：首条路前没有休息可跳

        for (int i = 1; i < n; ++i) {
            for (int j = n - 1; j >= 0; --j) {         // 倒序：保证 f[j-1] 还是上一行旧值
                long long best = (f[j] + speed - 1) / speed * speed + dist[i];  // 休息：等整点
                if (j >= 1)
                    best = min(best, f[j - 1] + dist[i]);                        // 跳过：立即出发
                f[j] = best;
            }
        }

        for (int j = 0; j < n; ++j)
            if (f[j] <= limit)
                return j;
        return -1;
    }
};
```

### Python

```python
class Solution:
    def minSkips(self, dist: List[int], speed: int, hoursBefore: int) -> int:
        n = len(dist)
        limit = hoursBefore * speed

        # f[j]：走完前 i+1 条路、至多跳过 j 次休息的最早到达时刻（单位：小时 × speed）
        f = [dist[0]] * n
        for i in range(1, n):
            d = dist[i]
            for j in range(n - 1, -1, -1):             # 倒序：f[j-1] 读到的是上一行旧值
                best = (f[j] + speed - 1) // speed * speed + d      # 休息：等整点
                if j >= 1:
                    best = min(best, f[j - 1] + d)                   # 跳过：立即出发
                f[j] = best

        for j, t in enumerate(f):
            if t <= limit:
                return j
        return -1
```

## 8. 边界情况与易错点

1. **浮点精度（最大坑）**
   - 用 `double` 累加时间、逐段 `ceil`，当「总时间恰为整数」「恰好压线」时浮点和可能略偏离真值，被 `ceil` 错误地多抬 1 小时或漏抬，导致答案错误甚至误判 $-1$。
   - **所有量 ×speed 化为整数**后此坑消失；比赛版 $\text{hoursBefore}$ 本身就是整数，连放大变换都不需要。
2. **整数溢出**
   - $\text{hoursBefore} \times \text{speed}$ 可达 $10^{13}$，C++ 必须 `long long`。
   - $f$ 会累积等待（每次休息至多多等 $\text{speed}-1$ 千米），量级约 $\sum\text{dist} + n \cdot \text{speed} \approx 10^9$，已贴近 `int` 上限，统一用 `long long` 最稳。
3. **滚动数组方向**
   - 一维滚动时 $j$ 必须从大到小，否则「跳过」分支读到本行新值（0-1 背包同款错误）。
4. **末段无休息**
   - 状态定义在「到达第 $i$ 条路的终点」，天然不含末段后的取整；不要对最后一条路再做取整。
5. **整点到达的休息**
   - 到达时刻恰为整点时等待为 0，跳过它纯属浪费（见 §3.3 方案 A）——这也是「能跳就跳」贪心失败的根源。
6. **$n = 1$**
   - 没有休息；答案为 $\text{dist}[0] \le \text{hoursBefore} \times \text{speed}$ 时的 $0$，否则 $-1$。
7. **$\text{speed} = 1$**
   - 任何时刻都是整点，全部等待为 0，退化为 $\sum\text{dist}$ 与 limit 的直接比较（示例 3）。
8. **「至多 $j$」vs「恰好 $j$」**
   - 「恰好 $j$」的写法需要 INF 哨兵并处理 $j \le i$ 的分支；「至多 $j$」语义初始化整列同值、实现更简，且由推论 1 答案等价。
