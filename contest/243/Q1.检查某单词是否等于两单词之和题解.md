# LeetCode 检查某单词是否等于两单词之和 题解

## 1. 题目概述

- **标题 / 题号**：检查某单词是否等于两单词之和（#1880，easy）
- **链接**：https://leetcode.cn/problems/check-if-word-equals-summation-of-two-words/
- **来源**：LeetCode 第 243 场周赛 Q1
- **难度**：简单
- **标签**：字符串、数学

**题意**：字母的**字母值**取决于其在字母表中的位置（从 0 开始计数），即 `'a' -> 0`、`'b' -> 1`、…、`'j' -> 9`。把单词中每个字母的字母值按顺序**连接**再转成整数，即为该单词的**数值**。给定三个单词 `firstWord`、`secondWord`、`targetWord`，判断前两者的数值之和是否等于第三者的数值。

**约束**：

- `1 <= firstWord.length, secondWord.length, targetWord.length <= 8`
- 三个单词仅由 `'a'` 到 `'j'`（含）的小写字母组成

## 2. 示例

**示例 1**

```text
输入：firstWord = "acb", secondWord = "cba", targetWord = "cdb"
输出：true
解释：
firstWord 的数值为 "acb" -> "021" -> 21
secondWord 的数值为 "cba" -> "210" -> 210
targetWord 的数值为 "cdb" -> "231" -> 231
由于 21 + 210 == 231，返回 true
```

**示例 2**

```text
输入：firstWord = "aaa", secondWord = "a", targetWord = "aab"
输出：false
解释：0 + 0 != 1（"aab" -> "001" -> 1）
```

**示例 3**

```text
输入：firstWord = "aaa", secondWord = "a", targetWord = "aaaa"
输出：true
解释：0 + 0 == 0（"aaaa" -> "0000" -> 0）
```

## 3. 解题思路

### 3.1 暴力思路

按题意模拟：把每个单词转成字母值串（如 `"acb"` → `"021"`），再用 `stoi` / `int()` 转整数，最后比较 `v1 + v2 == v3`。这本身就是最优做法，复杂度由输入长度决定。

> 💡 注意：若直接用 `stoi("021")` 这类带前导零的字符串，C++ 中 `std::stoi` 默认按十进制解析没问题，但 C 风格 `atoi`/`strtol` 遇到 `"0..."` 也安全；真正要小心的是**不要**误用八进制语义或手动 `pow(10, k)` 时搞错幂次。

### 3.2 核心观察：逐位累乘求值（Horner 法）

![单词求值：字母值连接转整数](images/word_summation_concept.svg)

数值本质是一个**十进制数**，第 $i$ 位字母 `c` 贡献 `(c - 'a') * 10^(L-1-i)`。因此求值无需真正拼字符串，一遍扫描即可：

$$\text{value}(s) = \sum_{i=0}^{L-1} (s_i - \text{'a'}) \times 10^{\,L-1-i}$$

等价地用**秦九韶（Horner）**形式从左往右递推：`value = value * 10 + (c - 'a')`。前导零（`'a'` 开头）天然被消化掉。

### 3.3 算法流程

1. 写辅助函数 `val(s)`：初始 `v = 0`，遍历每个字符 `c`，更新 `v = v * 10 + (c - 'a')`，返回 `v`。
2. 计算 `v1 = val(firstWord)`、`v2 = val(secondWord)`、`v3 = val(targetWord)`。
3. 返回 `v1 + v2 == v3`。

### 3.4 示例演算

`firstWord = "acb"`, `secondWord = "cba"`, `targetWord = "cdb"`：

| 单词 | 逐位字母值 | 连接结果 | 数值 |
|------|-----------|---------|------|
| "acb" | 0, 2, 1 | "021" | 21 |
| "cba" | 2, 1, 0 | "210" | 210 |
| "cdb" | 2, 3, 1 | "231" | 231 |

`21 + 210 == 231` → 返回 `true` ✓

![示例演算：21 + 210 == 231](images/word_summation_example.svg)

## 4. 算法细节

1. **求值方式**：Horner 递推 `v = v * 10 + (c - 'a')`，从左到右一遍完成，避免拼串和二次转换。
2. **数据范围**：长度 ≤ 8、每位 ≤ 9，最大数值不超过 $10^8 - 1$，`int`（上界约 $2.1 \times 10^9$）足以容纳 `v1 + v2`（< $2 \times 10^8$），无溢出风险。
3. **字母表限制**：题面保证只出现 `'a'`~`'j'`（字母值 0~9），恰好当数字用；若字母超过 `'j'` 则"连接"语义不成立，本题无需处理。
4. **返回值**：直接返回布尔表达式 `v1 + v2 == v3`，无需分支。

## 5. 正确性证明

**引理 1**：对长度为 $L$ 的单词 $s$，Horner 递推 $v_0 = 0$，$v_{i+1} = 10 v_i + (s_i - \text{'a'})$ 结束时 $v_L = \sum_{i=0}^{L-1} (s_i - \text{'a'}) \times 10^{L-1-i}$。

**证明**：对 $i$ 归纳。展开递推 $L$ 步，第 $i$ 个字符的字母值恰好被乘以 $10^{L-1-i}$ 次 10（其后每步乘 10，共 $L-1-i$ 步），且加法可交换合并。∎

**定理**：`val(firstWord) + val(secondWord) == val(targetWord)` 当且仅当两单词数值之和等于目标单词数值。

**证明**：由引理 1，`val` 精确计算题意定义的"字母值顺序连接所成整数"。数值均为非负整数，加法与比较即题意要求的判定，算法输出与定义一致。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n_1 + n_2 + n_3)$，$n_i$ 为三个单词的长度（≤ 8），每个字符常数次运算；本题规模下即 $O(1)$。
- **空间复杂度**：$O(1)$，只用常数个整数变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool isSumEqual(string firstWord, string secondWord, string targetWord) {
        auto val = [](const string& s) {
            int v = 0;
            for (char c : s) v = v * 10 + (c - 'a');
            return v;
        };
        return val(firstWord) + val(secondWord) == val(targetWord);
    }
};
```

### Python

```python
class Solution:
    def isSumEqual(self, firstWord: str, secondWord: str, targetWord: str) -> bool:
        def val(s: str) -> int:
            v = 0
            for c in s:
                v = v * 10 + (ord(c) - ord('a'))
            return v
        return val(firstWord) + val(secondWord) == val(targetWord)
```

## 8. 边界情况与易错点

1. **前导零**：`"aaa"` → `"000"` → 0。用 Horner 递推天然正确；若拼串后转整数，注意 `int("000") == 0` 也没问题，但不要自己写"去前导零"逻辑引入错误。
2. **最短输入**：长度为 1 的单词（如 `"a"`）数值就是单个字母值，递推同样适用。
3. **溢出**：三个数值均 < $10^8$，`v1 + v2 < 2 \times 10^8$，`int` 足够；不必开 `long long`，开了也不错。
4. **字符减法**：`(c - 'a')` 依赖题面保证字母 ∈ `['a','j']`，若不放心可加 `assert`，周赛中一般直接信任约束以节省时间。
5. **别被"连接"骗了**：是**按顺序连接成字符串再转整数**，不是把字母值**相加**——`"acb"` 是 21 而不是 0+2+1=3，读题时划出这个关键词。
