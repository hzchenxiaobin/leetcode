# LeetCode 移除 9 题解

## 1. 题目概述

- **标题 / 题号**：移除 9（#660，hard）
- **链接**：https://leetcode.cn/problems/remove-9/
- **来源**：LeetCode 第 45 场周赛 Q4
- **难度**：困难
- **标签**：数学

**题意**：从正整数序列 $1,2,3,\dots$ 中把所有**十进制表示里含数字 9** 的整数删掉（$9,19,29,90,199,\dots$ 全部消失），剩下的数按原顺序组成新序列
$$1,2,3,4,5,6,7,8,10,11,12,\dots,18,20,\dots$$
其中 $1$ 是新序列的第 $1$ 个数。给定正整数 $n$，返回新序列的第 $n$ 个数。

换一种说法：**求第 $n$ 个十进制表示不含数字 9 的正整数**。

**约束**：

- $1 \le n \le 9 \times 10^8$（题面 Hint：$n$ 不超过 $9\times10^8$）
- 函数签名为 `int newInteger(int n)`，返回值类型是 **32 位有符号整数**（这一点在 §8 会引出一个小陷阱）

规模 $10^8$ 级别说明了取舍：任何以「枚举候选数」为主体的做法都不可行，必须找到 $O(\log n)$ 的映射或 $O(\log^2 n)$ 的计数 + 二分。

## 2. 示例

**示例 1**

```text
输入：n = 9
输出：10
解释：新序列前 10 项为 1,2,3,4,5,6,7,8,10,11；
      9 因为含数字 9 被删掉，所以第 9 项是 10。
```

**示例 2**

```text
输入：n = 10
输出：11
解释：紧接在 10 之后的第 10 项是 11。
```

**补充示例（非官方，用于 §3.4 走查）**

```text
输入：n = 100
输出：121
解释：121 的十进制表示不含 9，且 [1, 121] 内不含 9 的正整数恰好 100 个，
      所以 121 正是第 100 个。
```

## 3. 解题思路

### 3.1 暴力思路

逐个自然数检查它是否含字符 `'9'`，计数器数到 $n$ 就返回：

```text
cnt = 0
for x = 1, 2, 3, ...:
    if '9' not in str(x): cnt += 1
    if cnt == n: return x
```

新序列的密度约为 $1$，第 $n$ 项与 $n$ 同量级，所以循环要跑 $O(\text{ans})$ 次（$\text{ans}$ 为答案，约为 $n$ 的常数倍）、每次再做 $O(\log \text{ans})$ 的字符串检查，总复杂度 $O(\text{ans}\log \text{ans})$。当 $n = 9\times10^8$ 时答案已达 $2.28\times10^9$，循环次数是十亿级，**必然超时**。

一个「更聪明的暴力」是数位计数 + 二分：定义 $C(x)$ 为 $[1,x]$ 中不含 9 的整数个数（数位 DP，$O(\log x)$），$C$ 单调不减，于是二分最小的 $x$ 满足 $C(x) = n$。复杂度 $O(\log^2 n)$，可行，但对本题这种有精确映射的题属于绕路——先看下面的观察。

### 3.2 核心观察：九进制重标号

![九进制重标号：第 n 个数就是 n 的九进制写法](images/wc45_q4_base9_bijection.svg)

**「十进制表示中不含 9」等价于「每一位只能从 $0\sim8$ 里取」**。而「每位有 9 种取值的进位制」就是**九进制**。于是定义映射

$$f(n) = \text{把 } n \text{ 的九进制数字串，原封不动地当作十进制数读出来的值}$$

例如 $n = 100 = (121)_9$，则 $f(100) = 121$；$n = 9 = (10)_9$，则 $f(9) = 10$。

为什么 $f(n)$ 就是答案？三句话：

1. **落点合法**：$f(n)$ 的每一位数字都来自九进制数字 $0\sim8$，所以它的十进制表示**永远不含 9**；
2. **严格保序**：$f$ 把「$n$ 的大小比较」翻译成「数字串的按位比较」——位数多者一定更大，位数相同则从最高位开始逐位比较（严格证明见 §5 引理 2）；
3. **不漏不重**：任一不含 9 的正整数 $x$，把它的十进制数字串（每位 $0\sim8$）按九进制解读，就得到唯一的原像 $n$。

三点合起来说明：$f$ 是「正整数」到「不含 9 的正整数」之间的**保序双射**。保序双射把第 $n$ 小的元素映到第 $n$ 小的元素，所以第 $n$ 项就是 $f(n)$。

> 💡 一句话记忆：**删掉一个数字，等于把进位基数减一**。删 9 → 九进制；若同时删掉 9 和 7，基数就变成 8（八进制）。

### 3.3 算法流程

![算法流程：反复除 9 取余，把余数按十进制权位拼回去](images/wc45_q4_algorithm_flow.svg)

$n$ 的九进制**最低位**是 $n \bmod 9$，它对应答案的**个位**；次低位对应十位，依此类推。所以不需要真的拼出字符串再解析，只要边除边累加：

```text
ans = 0, place = 1
while n > 0:
    ans  += (n % 9) * place     # 九进制最低位 → 十进制当前位
    n     = n // 9              # 剥掉这一位
    place = place * 10          # 权位左移
return ans
```

「低位在前」的累加方式天然右对齐，和手写进制转换时的「倒序拼接」等价，却省掉了反转。

### 3.4 示例演算

![n = 100 的三轮取模演算](images/wc45_q4_example_walkthrough.svg)

以 $n = 100$ 为例，$100 = 1\times81 + 2\times9 + 1$，九进制为 $121$：

| 轮次 | 进入本轮的 $n$ | $d = n \bmod 9$ | `place` | `ans` |
|------|----------------|-----------------|---------|-------|
| 第 1 轮 | 100 | 1 | 1 | 1 |
| 第 2 轮 | 11 | 2 | 10 | 21 |
| 第 3 轮 | 1 | 1 | 100 | 121 |
| 结束 | 0 | — | — | **121** |

再对照 $n = 9$：$9 = (10)_9$，第一轮 $d=0$ 落到个位、第二轮 $d=1$ 落到十位，得到 $10$——正好对应序列里 $1\sim8$ 之后跳过 9 直接到 10。

## 4. 算法细节

1. **取模与整除的顺序**：必须先取 $n \bmod 9$ 再 `n //= 9`，顺序写反会丢掉最低位；C++ 中 `n % 9` 与 `n / 9` 都是整除语义，与 Python 的 `//` 对正数一致。
2. **权位必须用 64 位**：`place` 依次取 $1,10,10^2,\dots,10^9$，循环最后还会再乘一次 10 得到 $10^{10}$；即使 `ans` 没溢出，`int place` 也会在 $10^{10}$ 处发生有符号溢出（UB），因此 `place` 与 `ans` 都用 `long long`。
3. **乘法提升到 64 位**：C++ 写 `ans += 1LL * (n % 9) * place;`，避免 `int * long long` 之前就先在 `int` 里算乘积；单个 $d \times place \le 8\times10^9$，`long long` 绰绰有余。
4. **循环轮数**：$n$ 的九进制位数是 $\lfloor \log_9 n \rfloor + 1$。因为 $9^9 = 3.87\times10^8 \le 9\times10^8 < 9^{10}$，最大 $n$ 需要 **10 轮**，每轮常数次算术运算。
5. **不要先转成字符串**：`to_string` + 逐位拼接会引入 $O(\log n)$ 的额外空间与字符处理开销；Python 里虽然有 `int(str(n), 9)` 这种写法，但它依赖「九进制串恰好由 0~8 组成」的隐式前提，可读性反而不如手写循环。
6. **返回值类型按题面接口**：`metaData` 指定返回 `integer`，所以 C++ 用 `int newInteger(int n)`，函数内部用 `long long` 计算、返回时转回 `int`（溢出讨论见 §8 第 4 条）。

## 5. 正确性证明

**引理 1（落点合法）**：对任意 $n \ge 1$，$f(n)$ 的十进制表示不含数字 9。

**证明**：$f(n)$ 的定义是「把 $n$ 的九进制数字串按十进制读出」，因此 $f(n)$ 的每一位十进制数字就等于 $n$ 的对应九进制位，取值必定属于 $\{0,1,\dots,8\}$，不可能出现 9。∎

**引理 2（严格单调）**：若 $n_1 < n_2$，则 $f(n_1) < f(n_2)$。

**证明**：设 $n_2$ 的九进制位数为 $k$（$k \ge 1$），$n_1$ 的位数为 $j$。

- **位数不同**（$j < k$）：$n_2 \ge 9^{k-1}$，故 $f(n_2)$ 是一个 $k$ 位十进制数且首位非零，$f(n_2) \ge 10^{k-1}$；而 $f(n_1)$ 至多 $j$ 位，$f(n_1) \le 10^{j} - 1 < 10^{j} \le 10^{k-1}$。于是 $f(n_1) < f(n_2)$。
- **位数相同**（$j = k$）：设最高不同位是从左数第 $t$ 位（$1 \le t \le k$），其前 $t-1$ 位完全相同，且第 $t$ 位上 $d_1 < d_2$。于是
  $$f(n_1) \le \text{前缀}\cdot 10^{k-t+1} + (d_2-1)\cdot 10^{k-t} + (10^{k-t}-1) < \text{前缀}\cdot 10^{k-t+1} + d_2 \cdot 10^{k-t} \le f(n_2)$$
  即 $f(n_1) < f(n_2)$。∎

**引理 3（双射）**：$f$ 是正整数集到「十进制表示不含 9 的正整数集」的双射。

**证明**：

- **像集不越界**：由引理 1，$f(n)$ 不含 9；又 $n\ge1$ 时 $f(n) \ge 1$，故像落在目标集合内。
- **满射**：任取不含 9 的正整数 $x$，它的十进制数字串每位属于 $0\sim8$ 且首位非零，把它按九进制解读得到的正整数记为 $n$，按定义 $f(n) = x$。
- **单射**：每个正整数 $n$ 的九进制表示唯一，因此不同 $n$ 的数字串（去掉前导零后）不同，读出的十进制值也不同。∎

**定理**：$f(n)$ 就是新序列的第 $n$ 项。

**证明**：由引理 1、引理 3，$f$ 是在「正整数」与「不含 9 的正整数」两个全序集之间的双射；由引理 2，$f$ 严格递增，即**保序双射**。保序双射把第 $n$ 小的元素映为第 $n$ 小的元素，故 $f(n)$ 恰是不含 9 的正整数中第 $n$ 小的那个，也就是新序列的第 $n$ 项。∎

## 6. 复杂度分析

- **时间**：$O(\log_9 n)$。循环每轮对 $n$ 做一次除以 9 的整除，轮数等于 $n$ 的九进制位数，最大 $10$ 轮（$n \le 9\times10^8$），每轮只有取模、乘加、乘 10 三组常数运算。
- **空间**：$O(1)$。只用了 `ans`、`place` 两个累加器，没有数组、字符串或递归栈。

对比 §3.1 的数位计数 + 二分（$O(\log^2 n)$）与暴力枚举（$O(\text{ans}\log \text{ans})$），这个映射解法在时间与常数上都最优。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int newInteger(int n) {
        long long ans = 0;      // 答案累加器，用 64 位防止中间量溢出
        long long place = 1;    // 当前十进制权位：1, 10, 100, ...
        while (n > 0) {
            ans += 1LL * (n % 9) * place;   // 九进制最低位落到当前十进制位
            n /= 9;                          // 剥掉最低位
            place *= 10;                     // 权位左移
        }
        return (int)ans;        // 接口要求 int（取值边界见题解 §8）
    }
};
```

### Python

```python
class Solution:
    def newInteger(self, n: int) -> int:
        ans, place = 0, 1
        while n > 0:
            ans += (n % 9) * place   # 九进制最低位 → 十进制当前位
            n //= 9                  # 剥掉最低位
            place *= 10              # 权位左移
        return ans                   # Python 整数无溢出，无需转换
```

## 8. 边界情况与易错点

1. **$n \le 8$**：答案是 $n$ 本身（$1\sim8$ 的十进制表示都不含 9），循环一轮就结束，`place` 一直是 1，无需特判。
2. **$n = 9$**：第一个「跳号」发生在这里，答案是 $10$ 而不是 $9$。若写成「$n$ 减去 9 的个数」之类的偏移公式，就会在这里错位。
3. **`place` 的溢出**：`place` 最大到 $10^9$，循环末尾还会再乘一次 10 得到 $10^{10}$，超过 `int` 上限（$2.1\times10^9$）。即使答案本身没超，`int place` 在最后一轮也已经溢出（有符号溢出是 UB）。**必须用 `long long`（或每次循环后判断 `n == 0` 再更新 `place`）**。
4. **返回值超出 `int`**：$n = 841031062$ 时答案恰为 $2147483647$；$n \ge 841031063$ 起答案就超过 $2^{31}-1$，例如 $n = 9\times10^8$ 时答案为 $2281451810$。题面 Hint 给的 $n$ 上限会让 `int` 接口本身无法表达答案，这是题目接口的边界瑕疵；实现里用 `long long` 累加可保证「只要答案能装进 `int`，结果就一定正确」。
5. **别把「移除 9」理解成「删掉 9 这个字符」**：题目是把**整个整数**移除，`199` 是整体消失，而不是变成 `11`。一旦按「字符替换」去想，就会得到完全错误的序列。
6. **不要用暴力对拍全量**：答案可达 $2.28\times10^9$，暴力枚举无法跑到上界；验证大 $n$ 时应改用独立的**数位计数**函数校验 $C(f(n)) = n$，并检查 $f(n)$ 的十进制表示确实不含 9。

**延伸思考**：

1. **删掉别的数字**：若删掉的是数字 $d$，只要 $d \ne 0$，剩余可选数字仍是 9 个，答案依旧是「$n$ 的九进制读成十进制」；若同时删掉两个数字，基数变成 8，就换成八进制。一般地，删掉 $k$ 个数字后基数就是 $10-k$——前提是被删的数字里不含 0，否则还要处理前导零。
2. **反向问题**：给定一个不含 9 的 $x$，问它是新序列的第几个？答案就是数位计数 $C(x)$，$O(\log x)$，正是本文对拍时用来验证大 $n$ 的那个函数；它也是「任意删除规则」下唯一通用的做法（配合二分即可求正向答案）。
3. **$n$ 极大时**（超过 $10^{18}$）：九进制位数超过 19，需要用字符串存 `ans`，或直接用大整数；此时映射思路不变，只是「读成十进制」这一步要自己做进位拼接。
4. **0-indexed 变体**：若定义「$0$ 是第 $0$ 个数」，则答案仍是 $f(n+1)$；但若要求序列从 $0$ 开始且 $0$ 计入，则 $n=0$ 应返回 $0$，需要单独处理，否则会把 $0$ 的九进制 $0$ 与空串混淆。
