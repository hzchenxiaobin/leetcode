# LeetCode 在矩阵上写出字母 Y 所需的最少操作次数 题解

## 1. 题目概述

- **标题 / 题号**：在矩阵上写出字母 Y 所需的最少操作次数（#3071，medium）
- **链接**：https://leetcode.cn/problems/minimum-operations-to-write-the-letter-y-on-a-grid/
- **来源**：LeetCode 第 387 场周赛 Q3
- **难度**：中等
- **标签**：数组、矩阵、计数、枚举

**题意**：给定 $n \times n$（$n$ 为奇数）的矩阵 `grid`，元素取值 $\{0, 1, 2\}$。字母 Y 的笔画由三条线段构成：左上角到中心的对角线、右上角到中心的对角线、中心到底部的垂直线。每次操作可将任意一格改成 $0$、$1$ 或 $2$。要求最终矩阵满足：Y 内所有格子同值 $a$，Y 外所有格子同值 $b$，且 $a \ne b$。求最少操作次数。

**约束**：

- $3 \le n \le 49$，$n$ 为奇数（规模极小，$O(n^2)$ 乃至 $O(6n^2)$ 都能过——本题拼的是**正确性**而非复杂度）
- $0 \le \text{grid}[i][j] \le 2$（值域只有 3 个值，这是「枚举目标值对」可行的根基）
- $n = \text{grid.length} = \text{grid}[i].\text{length}$

> 💡 读题抓两点：一是**整个矩阵都要归位**——不是只把 Y 的笔画涂出来，$n^2$ 个格子每个都必须是「Y 内」「Y 外」两色之一；二是**两色必须不同**——$a \ne b$ 这个硬约束把两个区域的选择**耦合**起来，是本题唯一的坑（贪心翻车点）。

## 2. 示例

**示例 1**

```text
输入：grid = [[1,2,2],[1,1,0],[0,1,0]]
输出：3

解释：最优目标 (a, b) = (1, 0)：Y 内全 1、Y 外全 0。
  Y 内 4 格中 3 格已是 1，只改 (0,2)；
  Y 外 5 格中 3 格已是 0，只改 (0,1)、(1,0)。共 3 次操作。
```

**示例 2**

```text
输入：grid = [[0,1,0,1,0],[2,1,0,1,2],[2,2,2,0,1],[2,2,2,2,2],[2,1,2,2,2]]
输出：12

解释：最优目标 (a, b) = (0, 2)：Y 内全 0、Y 外全 2。
  注意 cntY = [2,2,3] 的众数是 2，但最优却让 Y 内取 0——
  因为 Y 外 cntN = [3,4,11] 的众数 2 更值钱，Y 必须让位（贪心陷阱，见 §3.2）。
```

**示例 3**（自造，覆盖「初始已是 Y、答案为 0」）

```text
输入：grid = [[1,0,1],[0,1,0],[0,1,0]]
输出：0

解释：Y 内 4 格 (0,0)、(0,2)、(1,1)、(2,1) 全为 1，
  Y 外 5 格全为 0，1 ≠ 0，已经是合法的 Y，无需任何操作。
```

## 3. 解题思路

### 3.1 暴力思路

最先浮现的念头是**逐格局部贪心**——每格看「改成什么最省」。这个方向没有意义：单格的取舍依赖于全局的目标值 $(a, b)$，而 $(a,b)$ 恰恰是待定的；局部视角根本无法决策。

退一步的正确暴力：**枚举最终形态**。合法的最终形态完全由一对目标值 $(a, b)$ 决定（$a$ = Y 内的值，$b$ = Y 外的值，$a \ne b$），值域 $\{0,1,2\}$ 使合法组合只有 $3 \times 2 = 6$ 对。对每对 $(a,b)$ **重扫整个矩阵**，数出「Y 内不等于 $a$ 的格子数 + Y 外不等于 $b$ 的格子数」，取最小。时间 $O(6n^2) \approx 1.4 \times 10^4$（$n \le 49$），轻松通过。

比赛写到这一步就能 AC。但它有明显的不优雅之处：每个格子「属不属于 Y」的几何判断被重复做了 6 遍，且 6 次扫描把同一个格子的值反复数——**所有重复劳动都源于没有先把「计数」沉淀下来**。更重要的是，6 次扫描给了 6 次写错几何判定的机会（中心重复计数、对角线端点边界），见 §8。

### 3.2 核心观察：静态几何划分 + 代价解耦 + 枚举 6 对目标值

![核心观察：Y 区域是与数值无关的静态几何，由三条线容斥计数](images/letter_y_geometry.svg)

**观察 1：Y 区域只由 $n$ 决定，与 `grid` 数值无关。** 设 $m = \lfloor n/2 \rfloor$（中心下标），三条线的坐标规律为：

| 线段 | 坐标规律 | 格子数 |
|------|----------|--------|
| 左对角线 | $(i, i)$，$0 \le i \le m$ | $m+1$ |
| 右对角线 | $(i, n-1-i)$，$0 \le i \le m$ | $m+1$ |
| 垂直线 | $(i, m)$，$m \le i \le n-1$ | $n-m$ |

三条线只在中心 $(m, m)$ 汇合（$i < m$ 时两条对角线的格子两两不同，$i > m$ 后对角线已结束），中心被计 3 次、实际算 1 次。容斥：

$$|Y| = (m+1) + (m+1) + (n - m) - 2 = n + m$$

于是「是否在 Y 内」是**静态几何判定**，每格只需做一次；两张计数表 `cntY[3]`、`cntN[3]` 一次遍历即可建好。

**观察 2：固定 $(a,b)$ 后，代价完全解耦为两张表的查询。** 每个格子恰属 Y、非 Y 之一；当前值为 $v$、目标值为 $t$ 的格子，若 $v = t$ 需 0 次操作，若 $v \ne t$ 恰需 1 次（一次操作可改成任意值）。改动互不干扰，代价直接相加：

$$\text{cost}(a,b) = \underbrace{\big(|Y| - \text{cntY}[a]\big)}_{Y\ \text{内改成}\ a} + \underbrace{\big(|N| - \text{cntN}[b]\big)}_{Y\ \text{外改成}\ b}$$

其中 $|N| = n^2 - n - m$ 为非 Y 格数。

![枚举 6 对目标值：3×3 组合表与贪心耦合陷阱](images/letter_y_pair_table.svg)

**观察 3：只剩 6 对组合，枚举即可——但不能贪心。** 直觉上「Y 内取 cntY 的众数、Y 外取 cntN 的众数」很诱人，但 $a \ne b$ 的约束把两个选择**耦合**了：示例 2 中 $\text{cntY} = [2,2,3]$、$\text{cntN} = [3,4,11]$，贪心取 $a = 2$（Y 的众数）后 $b$ 只能退而取 1，代价 $4 + 14 = 18$；而最优解让 Y 让位取 $a = 0$、$b = 2$ 吃下大计数，代价 $5 + 7 = 12$。**值域只有 3，整体枚举全部 6 对是最不易错的写法。**

> ⚠️ 唯一的非法组合是 $a = b$（如 $(1,1)$），它是「两侧都取众数」时最想选、却恰恰被硬约束禁止的一格——枚举时必须显式跳过。

### 3.3 算法流程

```text
1. m ← n/2；cntY[0..2] ← 0，cntN[0..2] ← 0
2. 一次遍历所有格子 (r, c)：
     inY ⟺ (r ≤ m 且 (c = r 或 c = n−1−r)) 或 (r ≥ m 且 c = m)
     inY 为真 → cntY[grid[r][c]] += 1
     否则     → cntN[grid[r][c]] += 1
3. yTot ← n + m；nTot ← n² − yTot        # 也可用 sum(cntY) 对拍自检
4. 枚举 (a, b) ∈ {0,1,2}²，跳过 a = b：
     ans ← min(ans, (yTot − cntY[a]) + (nTot − cntN[b]))
5. 返回 ans
```

> ⚠️ 几何判定注意 $r = m$ 这一行：此时 $c = r$ 与 $c = n-1-r$ 都指向中心列（$n$ 为奇数时 $m = n-1-m$），加上垂线条件 $c = m$，中心格被三个条件同时命中——用「或」连接的布尔判定**天然去重**，不会重复计数。

### 3.4 示例演算

![示例 1 演算：计数表与 6 对目标值的代价](images/letter_y_example_walkthrough.svg)

以示例 1 `grid = [[1,2,2],[1,1,0],[0,1,0]]`（$n=3$、$m=1$）走查。Y 的 4 格：$(0,0)=1$、$(0,2)=2$、$(1,1)=1$、$(2,1)=1$；非 Y 的 5 格：$(0,1)=2$、$(1,0)=1$、$(1,2)=0$、$(2,0)=0$、$(2,2)=0$。

**计数表**：$\text{cntY} = [0, 3, 1]$，$\text{cntN} = [3, 1, 1]$，$|Y| = 4$，$|N| = 5$。

**枚举 6 对 $(a,b)$**：

| $(a,b)$ | Y 内代价 $4-\text{cntY}[a]$ | Y 外代价 $5-\text{cntN}[b]$ | 总代价 |
|---------|------|------|------|
| $(0,1)$ | $4-0=4$ | $5-1=4$ | 8 |
| $(0,2)$ | $4$ | $5-1=4$ | 8 |
| $(1,0)$ | $4-3=1$ | $5-3=2$ | **3** ★ |
| $(1,2)$ | $1$ | $5-1=4$ | 5 |
| $(2,0)$ | $4-1=3$ | $5-3=2$ | 5 |
| $(2,1)$ | $3$ | $5-1=4$ | 7 |

最小值 $\text{ans} = 3$（$a=1, b=0$，与示例一致：Y 内只改 $(0,2)$ 一格，Y 外只改 $(0,1)$、$(1,0)$ 两格）。

**示例 2 快速复核**（$n=5$、$m=2$）：$\text{cntY} = [2,2,3]$，$\text{cntN} = [3,4,11]$，$|Y|=7$、$|N|=18$。6 对代价为 $19, 12, 20, 12, 19, 18$，其中 $(0,2)$ 与 $(1,2)$ 并列最优 $12$——与官方解释「Y 内全 0、Y 外全 2」吻合；同时 $(2,1)$ 的代价 18 正是贪心会踩中的坑。

## 4. 算法细节

1. **几何判定的三种等价写法**：
   - 布尔公式（本文采用）：`(r <= m && (c == r || c == n-1-r)) || (r >= m && c == m)`，一行搞定，中心由「或」天然去重；
   - 标记法：先把 `vis[r][c] = true` 打在三条线上再统一数，直观但多一个 $O(n^2)$ 数组；
   - 公式法：直接按三条线的坐标枚举 Y 格（外层 `i` 从 0 到 m 收两条对角线，再从 m 到 n−1 收垂线），**注意中心只收一次**。
2. **一次遍历建表代替 6 次全扫**：几何判定每格只做一次，6 对组合退化为 $O(1)$ 查表。值域为 3 时优势只是常数级（$1/6$），但值域扩大后就是 $O(n^2 + K^2)$ 对 $O(K n^2)$ 的本质差距（见「相关题目与扩展」）。
3. **总数的两种来源**：$|Y| = n + m$ 用闭式公式，或者干脆 `yTot = sum(cntY)`——后者不可能错，前者适合做对拍自检（两者必须相等）。
4. **枚举顺序无关**：6 对组合独立，任意顺序取 min 结果相同；`a != b` 的跳过写在双层循环里最自然。
5. **贪心的正确补救**（如果不想枚举）：固定 $b$ 后，$a$ 的最优选择是 cntY 中**最大且 $a \ne b$** 的值——预处理 cntY 的最大值与次大值（各带下标）即可 $O(1)$ 应对每个 $b$。值域只有 3 时纯属多此一举，直接枚举 6 对最省心。

## 5. 正确性证明

**引理 1（Y 区域的静态性与大小）**：Y 区域只由 $n$ 决定，且 $|Y| = n + m$，其中 $m = (n-1)/2$。

**证明**：由题意，$Y = \{(i,i) : 0 \le i \le m\} \cup \{(i, n-1-i) : 0 \le i \le m\} \cup \{(i, m) : m \le i \le n-1\}$，其中每条线的坐标规律都可由「端点 + 线型」直接写出，与 `grid` 的数值无关。对相交情况：当 $0 \le i < m$ 时 $i \ne n-1-i$（因 $2i < n-1$），两条对角线的格子两两不同；$i = m$ 时两者同为 $(m, m)$；垂线与两条对角线也仅共享 $(m, m)$。故三线仅在中心一处相交，由容斥：$|Y| = (m+1) + (m+1) + (n-m) - 2 = 3m + 1 = n + m$。∎

**引理 2（合法最终形态的刻画）**：矩阵写成 Y，当且仅当存在 $(a, b)$（$a, b \in \{0,1,2\}$，$a \ne b$）使得 Y 内每格值为 $a$ 且 Y 外每格值为 $b$；这样的形态恰有 $3 \times 2 = 6$ 种。

**证明**：题目的三条判定条件（Y 内全相等、Y 外全相等、两值不同）恰好逐条对应「Y 内每格值为某个 $a$」「Y 外每格值为某个 $b$」「$a \ne b$」。$a$ 有 3 种取法、$b$ 须异于 $a$ 有 2 种取法，共 6 种互不相同的合法形态。∎

**引理 3（代价分解）**：固定目标 $(a, b)$，达到该最终形态的最少操作数为

$$\text{cost}(a,b) = \big(|Y| - \text{cntY}[a]\big) + \big(|N| - \text{cntN}[b]\big).$$

**证明**：一次操作只改变一个格子。对格子 $g$，设其当前值为 $v$、该形态下的目标值为 $t$（$t$ 由 $g$ 所在区域与 $(a,b)$ 唯一决定）：若 $v = t$，无需任何触及 $g$ 的操作；若 $v \ne t$，则任何达成该形态的操作序列中至少有一次操作触及 $g$（否则 $g$ 的值不变），而一次操作（改成 $t$）已足够。各格所需操作互不冲突（一次操作只影响一格），故最少总数 $=$ 目标值不匹配的格子数 $=$ Y 内 $v \ne a$ 的格子数 $+$ Y 外 $v \ne b$ 的格子数 $= (|Y| - \text{cntY}[a]) + (|N| - \text{cntN}[b])$。∎

**定理（算法最优性）**：算法返回写出 Y 的最少操作次数。

**证明**：设 OPT 为最少操作次数。任取一个达成合法 Y 的最优操作序列，其结束状态是某个合法最终形态，由引理 2 该形态由某对 $(a^*, b^*)$（$a^* \ne b^*$）唯一决定；由引理 3，该序列长度 $\ge \text{cost}(a^*, b^*) \ge \min_{a \ne b} \text{cost}(a, b)$，故 $\text{OPT} \ge \min_{a \ne b} \text{cost}(a,b)$。反之，取达到最小值的一对 $(a', b')$，按引理 3 的构造逐格把不匹配格子改成目标值，恰用 $\text{cost}(a', b')$ 次操作得到合法 Y，故 $\text{OPT} \le \min_{a \ne b} \text{cost}(a,b)$。算法遍历全部 6 对取最小（由引理 1，计数表在单次遍历中正确建立；由引理 3 的公式计算每对代价），返回值 $= \min_{a \ne b} \text{cost}(a,b) = \text{OPT}$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n^2)$。一次遍历建两张计数表是唯一的大头；之后枚举 6 对组合、每对 $O(1)$ 查表，值域为常数 3。相比暴力的 $O(6n^2)$ 渐近同阶、常数 $1/6$，且几何判定每格只执行一次，更不易写错。
- **空间复杂度**：$O(1)$。仅 6 个计数器（`cntY[3]` + `cntN[3]`）与常数个标量，与 $n$ 无关；若采用 `vis` 标记法判定 Y 区域则为 $O(n^2)$。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int minimumOperationsToWriteY(vector<vector<int>>& grid) {
        int n = grid.size(), m = n / 2;
        int cntY[3] = {0}, cntN[3] = {0};
        for (int r = 0; r < n; ++r) {
            for (int c = 0; c < n; ++c) {
                // 三条线：左对角 (r=c, r≤m)、右对角 (c=n−1−r, r≤m)、垂线 (c=m, r≥m)
                // 中心 (m,m) 被三个条件同时命中，or 连接天然去重
                bool inY = (r <= m && (c == r || c == n - 1 - r)) ||
                           (r >= m && c == m);
                if (inY) ++cntY[grid[r][c]];
                else     ++cntN[grid[r][c]];
            }
        }
        int yTot = n + m, nTot = n * n - yTot;   // |Y| = n+m，可用 sum(cntY) 对拍
        int ans = INT_MAX;
        for (int a = 0; a < 3; ++a)
            for (int b = 0; b < 3; ++b)
                if (a != b)                       // a ≠ b 是硬约束
                    ans = min(ans, yTot - cntY[a] + nTot - cntN[b]);
        return ans;
    }
};
```

### Python

```python
class Solution:
    def minimumOperationsToWriteY(self, grid: List[List[int]]) -> int:
        n, m = len(grid), len(grid) // 2
        cnt_y, cnt_n = [0] * 3, [0] * 3
        for r in range(n):
            for c in range(n):
                in_y = (r <= m and c in (r, n - 1 - r)) or (r >= m and c == m)
                if in_y:
                    cnt_y[grid[r][c]] += 1
                else:
                    cnt_n[grid[r][c]] += 1
        y_tot, n_tot = n + m, n * n - n - m
        return min(y_tot - cnt_y[a] + n_tot - cnt_n[b]
                   for a in range(3) for b in range(3) if a != b)
```

## 8. 边界情况与易错点

1. **中心格重复计数**：中心 $(m, m)$ 同时属于三条线。若分别对三条线累加再求和，中心被数 3 次，$|Y|$ 虚增 2，计数表全盘出错。用布尔「或」判定或 `vis` 标记去重。
2. **对角线的「上半」边界**：对角线只到中心为止（$r \le m$），垂线从中心开始（$r \ge m$），**两边都含中心**。写成 $r < m$ / $r > m$ 会把中心整个漏掉；写成 $r \le n$ 之类则把对角线延伸到下半区，Y 区域面目全非。
3. **$a \ne b$ 是硬约束**：枚举必须跳过 $a = b$；贪心「两侧各取众数」在这撞车（示例 2：贪心 18，最优 12）。这是本题最常见的 WA 来源。
4. **答案可以为 0**：初始矩阵可能已经是合法的 Y（自造示例 3），不要下意识给答案 +1 或特判。
5. **非 Y 区域也要全部同值**：读题只看「涂出 Y」会漏掉「$n^2$ 个格子每个都要归入两色之一」，代价公式里 $|N|$ 项整个丢掉。
6. **计数数组开大小 3**：值是 $0 \sim 2$，下标最大为 2，`cnt[2]` 会越界。
7. **$|Y| = n + m$ 可对拍自检**：遍历统计的 `sum(cntY)` 必须等于 $n + m$（$n=3 \to 4$、$n=5 \to 7$、$n=49 \to 73$），赛时花 10 秒断言一次，几何判定错误无所遁形。
8. **$n$ 为奇数是隐含地基**：奇数保证 $m = n-1-m$、中心唯一，三条线才有公共端点；偶数时题目本身失去定义（也是约束强调奇数的原因）。

**延伸思考**：

- **值域推广到 $K$**：枚举 $(a,b)$ 变为 $O(K^2)$，总时间 $O(n^2 + K^2)$；$K$ 很大时不必枚举——固定 $b$，$a$ 取 cntY 中最大且 $a \ne b$ 者，预处理最大与次大（带下标）即可 $O(1)$ 应对，总时间 $O(n^2 + K)$。
- **去掉 $a \ne b$ 约束**：两区域彻底解耦，各自取众数即可，连枚举都省了——本题的考点恰在这个不等约束引入的**耦合**上。
- **操作改成「每次 +1（模 3）」**：每格代价不再是 0/1，而是「当前值 → 目标值」的循环距离，需按差值分桶累加，但「枚举 $(a,b)$ + 计数」骨架依然成立。
- **同场对照**：第 387 场整体是基础套路场——Q1（#3069）模拟分配、Q2（#3070）前缀和剪枝、Q4（#3072）把 Q1 的「尾元素比较」升级为树状数组计数。本题居中，考「几何划分 + 小值域枚举」，是 Q3 位典型的分胜负手速题：思路十分钟，全对要小心 §8 的八个坑。
