# LeetCode 优惠券校验器 题解

## 1. 题目概述

- **标题 / 题号**：优惠券校验器（#3606，easy）
- **链接**：https://leetcode.cn/problems/coupon-code-validator/
- **来源**：LeetCode 第 457 场周赛 Q1
- **难度**：简单
- **标签**：数组、哈希表、字符串、排序

**题意**：给定 $n$ 张优惠券的三个属性数组 `code`、`businessLine`、`isActive`。一张优惠券**有效**当且仅当同时满足：

1. `code[i]` 非空，且仅由字母（`a-z`、`A-Z`）、数字（`0-9`）和下划线（`_`）组成；
2. `businessLine[i]` 是 `electronics`、`grocery`、`pharmacy`、`restaurant` 之一；
3. `isActive[i]` 为 `true`。

返回所有有效优惠券的 `code`，**先**按类别固定顺序 `electronics → grocery → pharmacy → restaurant` 排列，**再**在类别内按 `code` 字典序升序排列。

**约束**：

- `n == code.length == businessLine.length == isActive.length`
- `1 <= n <= 100`
- `0 <= code[i].length, businessLine[i].length <= 100`
- `code[i]` 与 `businessLine[i]` 由可打印 ASCII 字符组成
- `isActive[i]` 为 `true` 或 `false`

## 2. 示例

**示例 1**

```text
输入：code = ["SAVE20","","PHARMA5","SAVE@20"],
     businessLine = ["restaurant","grocery","pharmacy","restaurant"],
     isActive = [true,true,true,true]
输出：["PHARMA5","SAVE20"]
解释：第 1、3 张有效；第 2 张 code 为空；第 4 张含 '@'。
     PHARMA5 属 pharmacy(rank 2)，SAVE20 属 restaurant(rank 3)，故 PHARMA5 在前。
```

**示例 2**

```text
输入：code = ["GROCERY15","ELECTRONICS_50","DISCOUNT10"],
     businessLine = ["grocery","electronics","invalid"],
     isActive = [false,true,true]
输出：["ELECTRONICS_50"]
解释：第 1 张未激活；第 2 张有效（下划线合法）；第 3 张类别 "invalid" 不合法。
```

**示例 3（自拟，覆盖类别内排序与大小写）**

```text
输入：code = ["b1","A2","a3","x_9","b 1"],
     businessLine = ["grocery","grocery","electronics","pharmacy","restaurant"],
     isActive = [true,true,true,true,true]
输出：["a3","A2","b1","x_9"]
解释：electronics 桶 [a3]；grocery 桶内 "A2" < "b1"（'A'=65 < 'b'=98）；
     "b 1" 含空格非法；restaurant 桶为空不输出。
```

## 3. 解题思路

### 3.1 暴力思路

签到题，朴素做法即正解：**逐张校验 + 收集 + 排序**。$n \le 100$、串长 $\le 100$，怎么做都在 $10^6$ 量级内，不存在超时问题。唯一要防的是**校验漏条件**与**排序键写错**。

### 3.2 核心观察：三条件独立过滤 + 二元排序键

![三重过滤概念图](images/coupon_validator_filter_concept.svg)

- **过滤**：三个条件相互独立，逐条短路判断即可，任一不满足直接跳过。
- **排序键**：题目要求的顺序不是按类别**字典序**（否则 `electronics < grocery < pharmacy < restaurant` 恰好也是字典序，容易蒙混过关），而是**固定类别序**。稳妥做法是用哈希表把四个类别映射成 `rank = 0..3`，排序键取二元组 `(rank, code)`——rank 不同按 rank 升序，rank 相同按 `code` 字典序升序，恰好是语言内置对 pair / tuple 的默认比较。

> 💡 恰好本题四类别的字典序与题目给定顺序一致，但**不要依赖这个巧合**：直接 `(businessLine, code)` 排序能过，可一旦出题人调整类别顺序（如 `restaurant` 排第一）就会翻车。显式 rank 是可迁移的写法。

### 3.3 算法流程

1. 建哈希表 `rank = {"electronics":0, "grocery":1, "pharmacy":2, "restaurant":3}`。
2. 遍历 `i = 0..n-1`：
   - `isActive[i] == false` → 跳过；
   - `businessLine[i]` 不在 `rank` 中 → 跳过；
   - `code[i]` 为空，或存在字符 $\notin$ `[a-zA-Z0-9_]` → 跳过；
   - 否则把 `(rank[businessLine[i]], code[i])` 加入待排序列表。
3. 对列表整体排序（元组默认比较）。
4. 依序取出 `code` 返回。

### 3.4 示例演算

以示例 1 走查四张优惠券的判定与排序：

| i | code | businessLine | isActive | 判定 |
|---|------|--------------|----------|------|
| 0 | SAVE20 | restaurant | true | ✓ 有效（rank 3） |
| 1 | "" | grocery | true | ✗ code 为空 |
| 2 | PHARMA5 | pharmacy | true | ✓ 有效（rank 2） |
| 3 | SAVE@20 | restaurant | true | ✗ 含 '@' |

有效项为 `(3, "SAVE20")`、`(2, "PHARMA5")`，排序后 `(2, "PHARMA5")` 在前，输出 `["PHARMA5","SAVE20"]` ✓

## 4. 算法细节

1. **字符集校验**：先判空，再逐字符检查是否属于 `[a-zA-Z0-9_]`。
   - C++ 可用 `isalnum((unsigned char)c) || c == '_'`，注意 `isalnum` 的参数必须转成 `unsigned char`（传入负值是未定义行为）。
   - Python 的 `str.isalnum()` 与正则 `\w` 都是 **Unicode 感知** 的（`"中文".isalnum()` 为 `True`），本题约束可打印 ASCII 不会踩坑，但用显式范围比较更稳。
2. **类别映射**：用 `unordered_map<string,int>` / `dict` 做 O(1) 查询，同时天然完成"类别不合法"的判断——查不到即无效。
3. **排序键**：直接存 `pair<int,string>` / 元组 `(rank, code)`，`sort` / `list.sort` 的默认字典序比较就是题目要的顺序，无需自定义比较器。
4. **短路顺序**：先查 `isActive`（O(1)）再查类别（哈希 O(1)）最后扫字符串（O(L)），把贵的检查放后面。

## 5. 正确性证明

**引理 1**：`validCode(s)` 返回真，当且仅当 `s` 非空且每个字符 $\in$ `{a-z, A-Z, 0-9, _}`。

**证明**：`validCode` 先检查 `s` 非空，再对所有字符逐一判断是否落在四个合法区间之一；由穷举定义，任何不满足题设的串（空串，或含任一非法字符）都会在对应检查处返回假。∎

**引理 2**：二元组序 `(rank, code)` 与题目要求的排序规则等价：对两张有效优惠券 A、B，A 应排在 B 前当且仅当 `(rank_A, code_A) < (rank_B, code_B)`。

**证明**：题目规则为"先按类别固定顺序，类别内按 code 字典序"。分两种情形：
- 类别不同：四个类别与 rank 0..3 一一对应且 rank 严格递增，故"A 类别在前 ⇔ rank_A < rank_B"，此时元组比较由第一分量分出胜负，与规则一致；
- 类别相同：rank_A = rank_B，元组比较退化为 `code_A < code_B` 的字典序比较，与规则一致。∎

**定理**：算法输出恰为全部有效优惠券的 `code`，且按题目要求顺序排列。

**证明**：由算法流程，只有同时通过三个独立条件检查的优惠券才进入待排序列表，故输出的每个元素都有效（完备性由遍历全部 $i$ 保证——每个有效项都会被收集）。再由引理 1、2，过滤条件与题目定义逐条等价、排序序与题目要求等价，故输出集合正确且顺序正确。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \cdot L + n L \log n)$，其中 $L$ 为最大串长。过滤阶段每个优惠券做一次 O(L) 的字符扫描；排序阶段 O(n log n) 次比较，每次字符串比较最坏 O(L)。本题 $n \le 100$、$L \le 100$，总量级不超过 $10^6$。
- **空间复杂度**：$O(n)$，用于存储有效优惠券的二元组（不计返回值）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<string> validateCoupons(vector<string>& code, vector<string>& businessLine, vector<bool>& isActive) {
        unordered_map<string, int> rank{
            {"electronics", 0}, {"grocery", 1}, {"pharmacy", 2}, {"restaurant", 3}};

        auto validCode = [](const string& s) {
            if (s.empty()) return false;
            for (char c : s) {
                if (!(isalnum((unsigned char) c) || c == '_')) return false;
            }
            return true;
        };

        vector<pair<int, string>> items;
        int n = code.size();
        for (int i = 0; i < n; i++) {
            if (!isActive[i]) continue;
            auto it = rank.find(businessLine[i]);
            if (it == rank.end()) continue;
            if (!validCode(code[i])) continue;
            items.emplace_back(it->second, code[i]);
        }
        sort(items.begin(), items.end());

        vector<string> ans;
        ans.reserve(items.size());
        for (auto& [r, c] : items) ans.push_back(move(c));
        return ans;
    }
};
```

### Python

```python
class Solution:
    def validateCoupons(self, code: List[str], businessLine: List[str], isActive: List[bool]) -> List[str]:
        rank = {"electronics": 0, "grocery": 1, "pharmacy": 2, "restaurant": 3}

        def valid(s: str) -> bool:
            if not s:
                return False
            for c in s:
                if not ('0' <= c <= '9' or 'a' <= c <= 'z'
                        or 'A' <= c <= 'Z' or c == '_'):
                    return False
            return True

        items = [
            (rank[b], c)
            for c, b, a in zip(code, businessLine, isActive)
            if a and b in rank and valid(c)
        ]
        items.sort()
        return [c for _, c in items]
```

## 8. 边界情况与易错点

1. **空串判定**：`code[i]` 可能为空（长度下界是 0），必须显式判 `not s`。Python 里 `all(...)` 作用在空可迭代对象上返回 `True`，若不先判空，空串会被误判为合法。
2. **Unicode 陷阱**：Python 的 `isalnum()` / `\w` 会放行全角字符、中文字母；C++ 的 `isalnum` 遇到负值 `char`（UTF-8 多字节截断）是 UB。本题约束可打印 ASCII 不会实际触发，但显式范围检查是无坑写法。
3. **排序键层次**：类别优先、字典序次之。不要只按 `code` 排序，也不要想当然按 `businessLine` 字符串排序——本题恰好字典序与给定序一致纯属巧合。
4. **大小写敏感**：字典序区分大小写，`'A'(65) < '_'(95) < 'a'(98)`，直接用语言默认字符串比较即可，无需任何归一化。
5. **下划线是合法字符**：`ELECTRONICS_50` 有效；空格、`@`、`-`、`#` 等其他可打印 ASCII 均非法。
6. **三条件缺一不可**：`isActive == false` 时即使 code 与类别完全合法也无输出。
