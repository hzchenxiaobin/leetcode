# LeetCode 删点成林 题解

## 1. 题目概述

- **标题 / 题号**：删点成林（#1110，medium）
- **链接**：https://leetcode.cn/problems/delete-nodes-and-return-forest/
- **来源**：LeetCode 第 144 场周赛 Q3
- **难度**：中等
- **标签**：树，深度优先搜索，二叉树，数组，哈希表

**题意**：给定一棵节点值**互不相同**的二叉树 `root`，以及待删值集合 `to_delete`。把值出现在 `to_delete` 中的节点删掉，剩下的节点构成森林，返回森林中每棵树的根，顺序任意。

「删掉一个点」的准确含义是：**只删这个节点本身**，它和父亲、和两个孩子的边一起被切断，但孩子继续存在——若孩子也没被删，它就成为一棵新树的根。所以最终森林 = 原树去掉这些点后被切成的若干连通块。

**约束**：

- 节点数最多 $1000$
- 每个节点的值在 $1 \sim 1000$ 之间且互不相同
- `to_delete.length` $\le 1000$，其中各值互不相同、范围 $1 \sim 1000$
- 返回值顺序任意，判题使用 special judge

> 💡 值域只有 $1000$，可以开一个 `bool` 数组做「是否被删」的 $O(1)$ 判定，比 `unordered_set` 更省常数。

## 2. 示例

**示例 1**

```text
输入：root = [1,2,3,4,5,6,7], to_delete = [3,5]
输出：[[1,2,null,4],[6],[7]]
解释：删掉 3 和 5 后——3 的两个孩子 6、7 失去父亲，各自成为新树的根；
      5 是叶子，删掉后 2 的右孩子变为 null；
      1 仍是根，2 仍是它的左孩子，4 仍是 2 的左孩子。
```

**示例 2**

```text
输入：root = [1,2,4,null,3], to_delete = [3]
输出：[[1,2,4]]
解释：3 是 2 的右孩子且为叶子，删掉后只剩一棵树，根为 1。
```

**补充示例 3**（删根）

```text
输入：root = [1,2,3], to_delete = [1]
输出：[[2],[3]]
解释：根被删，两个子树各自独立成树；答案中不含 1。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的做法是：先遍历一次建好父指针，然后对 `to_delete` 中每个值找到对应节点，把父亲指向它的指针置空，再把它的两个（未被删的）孩子加入答案。每次查找 $O(n)$，共 $O(nk)$，在 $n, k \le 1000$ 时约 $10^6$ 次操作，勉强能过。

但这条路上有两个坑：

1. **删除顺序**：必须自底向上删。若先删父亲、后删孩子，孩子的父指针已经指向一个「已消失」的节点，需要额外维护；
2. **重复判定**：一个节点的父亲可能也在 `to_delete` 里，此时它只能被登记一次，也不能指望「父亲的父亲」来接管它。

可见真正的问题不是「怎么删」，而是「**怎么判断谁是新树的根**」。

### 3.2 核心观察：只需一个 isRoot 布尔量

![核心观察：删点只切断被删节点与孩子的边](images/wc144_q3_postorder_insight.svg)

记 $D$ 为 `to_delete` 的值集合。节点 $v$ 是森林中某棵树的根，当且仅当

$$v \notin D \quad \land \quad \bigl(\mathrm{parent}(v) = \text{null} \ \lor \ \mathrm{parent}(v) \in D\bigr)$$

也就是「**自己活着，且父亲不存在或已被删**」。

这条判据只依赖**父节点的状态**，与更深层的结构完全无关。于是可以：

- **向下传**一个布尔量 `isRoot`：子节点被调用时，父节点直接告诉它「你是不是候选根」；
- **向上返回**修剪后的子树：`dfs` 返回 `node` 表示「我还在」，返回 `null` 表示「我这棵子树断了」。

两者的配合点就在**被删节点**上：它自己消失，但它的两个孩子各自成为新子树的根，因此要对两个孩子**分别递归并把 `isRoot` 传 `true`**，然后自己返回 `null`。而保留的节点只要把两个孩子的返回值接回自己的 `left` / `right`，就顺带完成了「断链」。

### 3.3 算法流程

![一次 DFS：向下传 isRoot，向上返回子树根](images/wc144_q3_dfs_flow.svg)

```text
dfs(node, isRoot):
    if node == null: return null
    if node.val in D:                    # 自己被删
        dfs(node.left,  true)            # 左右孩子各自成为新树的根
        dfs(node.right, true)
        return null                      # 自己从父节点的视野里消失
    if isRoot: forest.push(node)         # 自己活着、父亲不在或被删 → 登记
    node.left  = dfs(node.left,  false)  # 修剪左子树并接回
    node.right = dfs(node.right, false)  # 修剪右子树并接回
    return node
```

主函数只调用 `dfs(root, true)`：根的父不存在，按定义它天然是「候选根」，若自身未被删就会登记进答案。

> 💡 登记放在递归前或递归后都可以——`forest` 里存的是指针，子树后来被修剪不影响指针有效性；放在递归前可以让输出顺序与官方示例一致。

### 3.4 示例演算

![示例 1 的 7 次调用走查](images/wc144_q3_walkthrough.svg)

对 `root = [1,2,3,4,5,6,7]`、`to_delete = [3,5]`，按代码实际的递归顺序走一遍：

| 次序 | 调用 | 被删? | 关键动作 | res |
|------|------|-------|----------|-----|
| 1 | `dfs(1,true)` | 否 | isRoot 真 ⇒ 登记 1 | `[1]` |
| 2 | `dfs(2,false)` | 否 | 不登记，继续剪左子树 | `[1]` |
| 3 | `dfs(4,false)` | 否 | 叶子，原样返回 4 | `[1]` |
| 4 | `dfs(5,false)` | 是 | 无孩子，返回 null ⇒ `2.right` 置空 | `[1]` |
| 5 | `dfs(3,true)` | 是 | 对 6、7 递归时 `isRoot = true` | `[1]` |
| 6 | `dfs(6,true)` | 否 | 父亲 3 已删 ⇒ 登记 6 | `[1,6]` |
| 7 | `dfs(7,true)` | 否 | 同样登记为根，DFS 结束 | `[1,6,7]` |

最终 `res = [1,6,7]`，序列化为 `[[1,2,null,4],[6],[7]]`，与官方输出一致。

注意 **4 始终没有被登记**：它父亲 2 没被删，4 只是被「接回」到 2 的左孩子位置；5 是 2 的右孩子，被删后该指针被写成 `null`。

## 4. 算法细节

1. **`isRoot` 只有三种传值场景**：根节点传 `true`；被删节点的两个孩子传 `true`；保留节点的两个孩子传 `false`。没有第四条路径，这是后面证明登记条件精确的关键。
2. **被删节点必须递归两个孩子**：不能直接 `return null` 了事，否则孩子若没被删，整棵子树会从答案中消失（示例 1 会漏掉 6、7）。
3. **用返回值接指针**：`node.left = dfs(node.left, false)` 一行同时完成「递归」和「断链」，父节点不需要再判断孩子是否被删。
4. **值域小就用数组**：$1 \le \text{val} \le 1000$，开 `bool deleted[1001]`（Python 用 `set`）即可，判定 $O(1)$ 且常数极小。
5. **不要改动被删节点的孩子指针**：它已经不在结果里，改它无意义；若把它的孩子「挂到祖父上」，语义就变成了另一种题目。
6. **递归深度**：树高最大 $1000$，C++ 默认栈够用；Python 默认递归上限是 $1000$，链状树会踩线，需要 `sys.setrecursionlimit(10000)`。
7. **输出顺序不做假设**：`forest` 的顺序由 DFS 决定，题目允许任意顺序；本地对拍时要把每棵树序列化后排序再比较。
8. **原地修改即可**：只重接指针，不新建节点、不复制值，答案中的每棵树共享原树节点，空间更省。

## 5. 正确性证明

**引理 1（`dfs` 的返回值语义）**：对任意节点 $v$ 与任意 `isRoot` 取值，调用 `dfs(v, isRoot)` 返回时有：

- (a) 若 $v \in D$，则返回 `null`；
- (b) 若 $v \notin D$，则返回 $v$，且以 $v$ 为根的这棵树恰好包含原树中 $v$ 子树里所有「从 $v$ 出发的路径上不含被删节点」的节点，父子关系不变。

**证明**：对 $v$ 的子树高度归纳。

- **基础**：$v$ 为叶子。若 $v \in D$，走删除分支，两个孩子的调用都返回 `null`，随即返回 `null`，(a) 成立；若 $v \notin D$，两个孩子的返回值都是 `null`，于是 $v$ 的左右指针保持为空、$v$ 被返回，(b) 成立（集合只含 $v$ 自身）。
- **归纳**：设 $v$ 的左右孩子都满足 (a)(b)。
  - 若 $v \in D$：先对两个孩子分别调用 `dfs(·, true)`，由归纳假设它们各自满足 (b)，即各自变成一棵合法的新树；随后返回 `null`，(a) 成立。此时 (b) 的前提不成立，无需验证。
  - 若 $v \notin D$：由归纳假设 (a)，孩子的返回值非空当且仅当孩子未被删；由 (b)，返回的恰是孩子子树里「路径上不含被删节点」的那些节点。把它们接回 $v$ 的左右指针后，$v$ 的树 $= \{v\} \cup$ 左孩子保留集 $\cup$ 右孩子保留集，恰是 (b) 所描述的集合，父子关系也与原子树一致。最后返回 $v$。∎

**引理 2（登记条件精确）**：节点 $v$ 被 `forest.push` 当且仅当 $v$ 是森林中某棵剩余树的根。

**证明**：

- ($\Leftarrow$) 设 $v$ 是根，则 $v \notin D$，且 $\mathrm{parent}(v)$ 为空或 $\in D$。代码中 `isRoot` 只有三种来源：主函数对根传 `true`、删除分支对孩子传 `true`、保留节点对孩子传 `false`。$v$ 是根意味着「父不存在」（对应第一种）或「父被删」（对应第二种），故调用 `dfs(v, ·)` 时 `isRoot` 必为 `true`；又 $v \notin D$，于是被 push。
- ($\Rightarrow$) 若 $v$ 被 push，则调用时 `isRoot = true` 且 $v \notin D$。`isRoot = true` 只可能来自「对根的首次调用」或「父节点被删的删除分支」，两种情况下 $\mathrm{parent}(v)$ 都为空或在 $D$ 中，故 $v$ 是根。
- 树中每个节点只有一个父亲，`dfs` 对每个节点恰好调用一次，因此不会重复登记。∎

**定理**：算法返回的 `forest` 恰为题面所求森林——剩余森林中每棵树的根各出现一次。

**证明**：由引理 1(b)，任何存活节点 $u$ 都出现在某次 `dfs` 返回的树中，且被修改后的指针关系保证它只归属一棵树（沿父链上溯，遇到的第一个「父为空或父被删」的存活节点唯一）。由引理 2，被 push 的节点正是全部这样的根，且不重不漏。故 `forest` 中每个元素是一棵互不相交的剩余树的根，它们的并集覆盖全部存活节点，正是所求森林。∎

## 6. 复杂度分析

- **时间**：$O(n + k)$。构建删除标记 $O(k)$；DFS 中每个节点恰好进入一次，节点内只做常数次判断与指针赋值，合计 $O(n)$。
- **空间**：$O(n + k)$。递归栈深度等于树高 $O(h) \le O(n)$；删除标记数组 $O(1000)$；答案数组最多存 $O(n)$ 个指针。全程原地重接指针，没有新建节点。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <functional>
using namespace std;

class Solution {
public:
    vector<TreeNode*> delNodes(TreeNode* root, vector<int>& to_delete) {
        bool deleted[1001] = {false};          // 值域 1..1000，数组比哈希表更快
        for (int v : to_delete) deleted[v] = true;
        vector<TreeNode*> forest;

        function<TreeNode*(TreeNode*, bool)> dfs = [&](TreeNode* node, bool isRoot) -> TreeNode* {
            if (!node) return nullptr;
            if (deleted[node->val]) {          // 自己被删：孩子各自成为新根
                dfs(node->left, true);
                dfs(node->right, true);
                return nullptr;
            }
            if (isRoot) forest.push_back(node); // 活着且父亲不在/被删 → 登记为根
            node->left = dfs(node->left, false);  // 修剪子树并把结果接回
            node->right = dfs(node->right, false);
            return node;
        };

        dfs(root, true);                        // 根的父不存在，按定义是候选根
        return forest;
    }
};
```

### Python

```python
import sys
from typing import List, Optional


class Solution:
    def delNodes(self, root: Optional[TreeNode], to_delete: List[int]) -> List[TreeNode]:
        sys.setrecursionlimit(10000)        # 链状树深度可达 1000
        deleted = set(to_delete)
        forest: List[TreeNode] = []

        def dfs(node: Optional[TreeNode], is_root: bool) -> Optional[TreeNode]:
            if node is None:
                return None
            if node.val in deleted:         # 自己被删：孩子各自成为新根
                dfs(node.left, True)
                dfs(node.right, True)
                return None
            if is_root:                     # 活着且父亲不在/被删 → 登记为根
                forest.append(node)
            node.left = dfs(node.left, False)    # 修剪子树并把结果接回
            node.right = dfs(node.right, False)
            return node

        dfs(root, True)                     # 根的父不存在，按定义是候选根
        return forest
```

## 8. 边界情况与易错点

1. **根被删**：`root` 不进答案，它的两个子树各自成根（补充示例 3）。代码里 `dfs(root, true)` 走删除分支，天然正确。
2. **全部删除**：返回空列表，注意 Python 返回 `[]` 而不是 `None`，C++ 返回空 `vector`。
3. **`to_delete` 含树上不存在的值**：标记数组多置一个 `true`，对结果无任何影响。
4. **单节点树**：被删 → `[]`；未被删 → `[root]`。
5. **链状树删中间节点**：只断一条边，断成两段（上段以原根为根、下段以被删节点的孩子为根），不要把下段接到祖父上。
6. **漏递归被删节点的孩子**：示例 1 会漏掉 6、7，答案少两棵树——这是本题最常见的错误。
7. **Python 递归深度**：$n = 1000$ 的链，递归深度正好 $1000$，默认上限容易触发 `RecursionError`，务必调高。
8. **用列表做成员判断**：`v in to_delete` 每次 $O(k)$，总 $O(nk)$ 虽能过但没必要，先转 `set` / `bool` 数组。
9. **对拍顺序**：DFS 输出顺序与官方示例不一定相同，本地比较前先对每棵树做层序序列化并排序。

**延伸思考**：

1. 若「删除」指**删掉整棵子树**（孩子一起没），删除分支直接 `return null` 即可，不必再递归孩子，答案只剩「被删节点之上的部分」。
2. 若要求返回每棵剩余树的**节点数或高度**，可让 `dfs` 额外带回统计量，或在后续对每棵树做一次遍历。
3. 若允许**删边而不删点**（把树切成若干连通块），判据就从「父是否被删」变成「这条边是否被切断」，其余框架不变。
4. 若要求按**原树的层序**输出各棵树的根，可在 DFS 后按节点深度排序；若要求按根值升序，直接排序 `forest` 即可，不影响正确性。
