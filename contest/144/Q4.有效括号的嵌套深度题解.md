# LeetCode 有效括号的嵌套深度 题解

## 1. 题目概述

- **标题 / 题号**：有效括号的嵌套深度（#1111，medium）
- **链接**：https://leetcode.cn/problems/maximum-nesting-depth-of-two-valid-parentheses-strings/
- **来源**：LeetCode 第 144 场周赛 Q4
- **难度**：中等
- **标签**：栈，字符串，括号序列

**题意**：`seq` 是一个**有效括号字符串**（VPS）。把每个下标涂成 0 或 1：标 0 的字符按原顺序拼成子序列 $A$，标 1 的拼成 $B$（子序列不要求连续）。要求 $A$、$B$ 都是有效括号字符串（允许为空串），并使

$$\max\bigl(\text{depth}(A),\ \text{depth}(B)\bigr)$$

**最小**。返回任意一组最优涂色方案。

**约束**：

- $2 \le |seq| \le 10^4$，因此 $|seq|$ 一定是偶数
- `seq` 保证是 VPS，不需要额外校验合法性
- 返回值长度必须为 $|seq|$，元素只能取 0 或 1
- 答案**不唯一**，任意合法最优解都会被接受

> 💡 **一句话直觉**：把 $A$、$B$ 看成两条「车道」，一个括号对占一层；让 $A$ 只收奇数层的括号对、$B$ 只收偶数层的括号对，深度就被硬生生砍成一半。

## 2. 示例

**示例 1**

```text
输入：seq = "(()())"
输出：[0,1,1,1,1,0]
解释：A = seq[0] + seq[5] = "()"，B = seq[1..4] = "()()"；
      depth(A) = depth(B) = 1，故 max = 1。
```

**示例 2**

```text
输入：seq = "()(())()"
输出：[0,0,0,1,1,0,1,1]
解释：该输出对应 A = "()()"、B = "()()"，max(depth) = 1。
      答案不唯一：[1,1,1,0,0,1,1,1] 同样正确（A = "()()()"，B = "()"），深度仍为 1。
```

**补充示例（非官方，用来说明「子序列可以不连续」）**

```text
输入：seq = "(((())))"          // 4 对括号，整串深度 d = 4
输出：[0,1,0,1,1,0,1,0]          // 本文算法的结果
解释：A = seq[0,2,5,7] = "(())"，B = seq[1,3,4,6] = "(())"；
      两者深度都是 2 = ⌈4/2⌉，已经达到最优。
```

## 3. 解题思路

### 3.1 暴力思路

枚举全部 $2^{n}$ 种涂色，对每种涂色拼出 $A$、$B$，校验它们是否为 VPS 并计算深度，取最优：单次校验 $O(n)$，总计 $O(n \cdot 2^{n})$。$n = 10^4$ 时完全不可行。

换个方向做「搜索」也不行：状态需要同时记录扫描位置、$A$ 的当前栈深、$B$ 的当前栈深以及各自是否可能非法，转移还要保证括号配对合法，状态数 $O(n^3)$ 起步，且实现极其容易写错。

> 暴力的浪费在于：它把「怎么分」当成自由选择去枚举，而实际上最优分法有一个**闭式结构**，根本不需要搜索。

### 3.2 核心观察：按括号对的层数奇偶染色

![按括号对的层数奇偶分组](images/wc144_q4_level_parity_model.svg)

先给每个括号定义**层数** $\ell$：最外层的括号对层数为 1，往里进一层加 1；**同一对括号的两个括号层数相同**。扫描时，$\ell$ 恰好就是「当前栈深」——左括号的层数是它压栈后的深度，右括号的层数是它弹栈前的深度。

于是有一个非常自然的染色方案：

- **奇数层的括号全部给 $A$（标 0）**，**偶数层的括号全部给 $B$（标 1）**。

这个方案有三个立刻能看见的好处：

1. **$A$、$B$ 一定合法**：同一对括号层数相同，所以一对括号要么整对进 $A$、要么整对进 $B$，两个子序列都是由**完整的括号对**按原顺序拼起来的，必然都是 VPS。
2. **深度被砍半**：$A$ 里所有括号对的层数落在 $\{1,3,5,\dots\}$，$B$ 里落在 $\{2,4,6,\dots\}$。$A$ 中一条长 $k$ 的嵌套链层数严格递增且同奇偶，至少是 $1,3,\dots,2k-1$，而层数不超过整串深度 $d$，故 $2k-1 \le d$，即 $k \le \lceil d/2 \rceil$；同理 $B$ 的深度不超过 $\lfloor d/2 \rfloor$。因此

$$\max\bigl(\text{depth}(A), \text{depth}(B)\bigr) \le \left\lceil \frac{d}{2} \right\rceil$$

3. **这个上界就是最优**：取一条最深的嵌套链，它含 $d$ 对两两嵌套的括号。把 $d$ 对分给 $A$、$B$ 两组，由鸽巢原理，必有一组拿到至少 $\lceil d/2 \rceil$ 对；而这些对在子序列中**仍然保持嵌套关系**（包含关系不会因为删掉别的字符而改变），所以该组的深度至少是 $\lceil d/2 \rceil$。

上下界一夹，答案就是 $\lceil d/2 \rceil$，奇数层/偶数层的分法正好达到它。

> 💡 换个角度记：这相当于把括号序列「按层数分层」，第 1 层和第 2 层合成一对车道、第 3 层与第 4 层合成一对车道……任意相邻两层交替分配给 $A$、$B$ 即可。

### 3.3 算法流程

![算法流程：一次扫描边走边染色](images/wc144_q4_algorithm_flow.svg)

1. 令 `level = 0`，`ans` 为空数组，`i` 从 0 扫描到 $n-1$；
2. 若 `seq[i] == '('`，先 `level += 1`（此时 `level` 就是该左括号的层数）；
3. 无论字符是左括号还是右括号，都用**当前** `level` 的奇偶决定归属：`level` 为奇写 0（归 $A$），为偶写 1（归 $B$）；
4. 若 `seq[i] == ')'`，再 `level -= 1`（此时 `level` 在自减前正是该右括号的层数）；
5. 扫描结束后返回 `ans`。

**更新顺序是本题唯一的坑**：左括号必须「先自增再染色」，右括号必须「先染色再自减」。写成统一地「先染色再自增/自减」或「先自增/自减再染色」，都会让某一侧的层数偏 1，导致同一对括号被拆到两组——$A$、$B$ 立刻不再合法。

### 3.4 示例演算

![示例 1 逐步演算表](images/wc144_q4_walkthrough.svg)

对 `seq = "(()())"`（$d = 2$）：

| $i$ | `seq[i]` | 染色时 `level` | `ans[i]` | 结束后 `level` | 分组 |
|-----|----------|----------------|----------|----------------|------|
| 0 | `(` | 1 | 0 | 1 | A |
| 1 | `(` | 2 | 1 | 2 | B |
| 2 | `)` | 2 | 1 | 1 | B |
| 3 | `(` | 2 | 1 | 2 | B |
| 4 | `)` | 2 | 1 | 1 | B |
| 5 | `)` | 1 | 0 | 0 | A |

得到 `[0,1,1,1,1,0]`，$A = $ `"()"`、$B = $ `"()()"`，两者深度都是 1，与官方示例完全一致。

示例 2 `seq = "()(())()"`（$d = 2$）用同样规则得到 `[0,0,0,1,1,0,0,0]`，对应 $A = $ `"()()()"`、$B = $ `"()"`，深度都是 1。它与官方给出的 `[0,0,0,1,1,0,1,1]` 逐位不同，但 $A$、$B$ 都合法、$\max$ 都是最优值 1，因此同样被接受。**这正是本题「答案不唯一」的体现，不要为了对上某个固定答案去调参。**

## 4. 算法细节

1. **`level` 的含义**：它是「当前尚未匹配的左括号个数」，也就是下一个左括号即将进入的层号。用 `int` 即可，$|seq| \le 10^4$ 时最大只有 5000，不会溢出。
2. **层号从 1 开始**：左括号先自增，所以第一个左括号的层号是 1；序列中任何字符染色时的 `level` 都 $\ge 1$，不会出现 `level = 0` 的字符。若写成「先取奇偶再自增」，第一个左括号会拿到 0（偶数）而被判给 $B$，两组仍合法但配对关系会错位到右括号侧，容易连带出错。
3. **0 与 1 可以互换**：把 `ans` 整体取反（`1 - ans[i]`）得到的仍然是合法最优解，因为 $A$、$B$ 的角色完全对称。本题不要求输出字典序最小或与官方一致。
4. **不需要显式栈**：`level` 本身就是栈深，省掉 `stack` 容器与 `push/pop` 的开销，也让代码只有五行。用真实栈虽然也能写出正确解（弹栈时按栈深奇偶染色），但常数更大、可读性更差。
5. **返回整数数组而不是字符串**：C++ 返回 `vector<int>`，Python 返回 `List[int]`；不要返回 `"011110"` 这样的字符串，也不要返回字符 `'0'`/`'1'`。
6. **预分配与追加**：C++ 用 `vector<int> ans(n)` 按 `ans[i] = ...` 覆写，避免 `push_back` 的反复扩容；Python 用 `ans.append(...)` 即可，$10^4$ 规模下开销可忽略。
7. **输入保证合法，不必做括号合法性校验**：题面已声明 `seq` 是 VPS，额外校验只会拖慢代码；只有在本地对拍时，才值得写一个 `is_vps` 辅助函数。

## 5. 正确性证明

设整串 $seq$ 的深度为 $d$。对下标 $i$，记 $b_i$ 为扫描完前 $i$ 个字符后的前缀和（左括号记 $+1$、右括号记 $-1$）。算法中染色时的 `level` 记作 $\ell_i$：若 $seq[i] = $ `'('`，则 $\ell_i = b_{i+1}$；若 $seq[i] = $ `')'`，则 $\ell_i = b_i$。

**引理 1（同一对括号层数相同）**：设 $seq[i] = $ `'('` 与 $seq[j] = $ `')'` 是一对匹配的括号，则 $\ell_i = \ell_j$。

**证明**：匹配意味着 $seq[i+1..j-1]$ 自己是一个 VPS，于是 $b_j = b_{i+1}$（中间那段括号的前缀和为 0，首尾抵消）。按定义 $\ell_i = b_{i+1}$、$\ell_j = b_j$，故 $\ell_i = \ell_j$。∎

**引理 2（输出合法）**：按「奇数层归 $A$、偶数层归 $B$」染色后，$A$ 与 $B$ 都是有效括号字符串。

**证明**：由引理 1，每一对匹配括号的两个字符层数相同，因而被染成同一个值，即每对括号整体进入 $A$ 或整体进入 $B$。子序列保持原相对顺序，故 $A$ 是若干完整括号对按原顺序拼接的结果：它的任一前缀中右括号数不超过左括号数（否则原串对应前缀也会失配），且总数相等，故 $A$ 是 VPS。对 $B$ 同理。∎

**引理 3（深度上界）**：$\text{depth}(A) \le \lceil d/2 \rceil$ 且 $\text{depth}(B) \le \lfloor d/2 \rfloor$。

**证明**：设 $A$ 中有一条 $k$ 对括号的嵌套链 $p_1 \supset p_2 \supset \dots \supset p_k$（$p_1$ 最外层）。嵌套意味着层号严格递增：$\ell(p_1) < \ell(p_2) < \dots < \ell(p_k)$。$A$ 中所有括号对的层号都是奇数，故 $\ell(p_t) \ge 2t - 1$。又层号不超过整串深度 $d$，于是 $2k - 1 \le \ell(p_k) \le d$，得 $k \le \lceil d/2 \rceil$。对 $B$ 同理：层号都是偶数且最小为 2，得 $\ell(p_t) \ge 2t$，于是 $2k \le d$，即 $k \le \lfloor d/2 \rfloor$。∎

**引理 4（下界）**：对任意满足条件的划分，都有 $\max(\text{depth}(A), \text{depth}(B)) \ge \lceil d/2 \rceil$。

**证明**：整串深度为 $d$，故存在一条含 $d$ 对括号的嵌套链 $q_1 \supset q_2 \supset \dots \supset q_d$。把它按染色分到两组，由鸽巢原理，至少一组含有其中 $\lceil d/2 \rceil$ 对。设这些对为 $q_{i_1}, \dots, q_{i_m}$（$m \ge \lceil d/2 \rceil$，下标递增）。由于 $q_{i_1} \supset \dots \supset q_{i_m}$ 且它们都保留在该组的子序列中，包含关系在子序列里依然成立，于是该组至少有一条 $m$ 层的嵌套链，深度 $\ge m \ge \lceil d/2 \rceil$。∎

**定理**：算法返回的染色方案使 $\max(\text{depth}(A), \text{depth}(B))$ 取得最小值 $\lceil d/2 \rceil$。

**证明**：由引理 2，输出合法；由引理 3，其目标值为 $\max(\lceil d/2 \rceil, \lfloor d/2 \rfloor) = \lceil d/2 \rceil$；由引理 4，任何合法划分的目标值都不小于 $\lceil d/2 \rceil$。故该方案最优，最优值即 $\lceil d/2 \rceil$。∎

## 6. 复杂度分析

- **时间**：$O(n)$。只扫描一遍字符串，每个字符做一次奇偶判断、常数次加法与一次写入；没有排序、没有栈操作、没有回溯。
- **空间**：$O(1)$ 的额外空间（只有 `level` 一个整型变量与循环下标）；返回数组 `ans` 占 $O(n)$，属于输出，不计入额外空间。递归与显式栈都不需要。

## 7. 参考代码

### C++

```cpp
#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> maxDepthAfterSplit(string seq) {
        int n = seq.size();
        vector<int> ans(n, 0);
        int level = 0;                       // 当前栈深 = 下一个左括号的层号
        for (int i = 0; i < n; ++i) {
            if (seq[i] == '(') ++level;      // 左括号的层数 = 自增后的 level
            ans[i] = (level & 1) ? 0 : 1;    // 奇数层归 A(0)，偶数层归 B(1)
            if (seq[i] == ')') --level;      // 右括号的层数 = 自减前的 level
        }
        return ans;
    }
};
```

### Python

```python
from typing import List


class Solution:
    def maxDepthAfterSplit(self, seq: str) -> List[int]:
        ans = []
        level = 0                      # 当前栈深
        for ch in seq:
            if ch == '(':
                level += 1             # 左括号所在括号对的层数 = 加一之后的 level
            ans.append(0 if level & 1 else 1)   # 奇数层 -> A(0)，偶数层 -> B(1)
            if ch == ')':
                level -= 1             # 右括号所在括号对的层数 = 减一之前的 level
        return ans
```

## 8. 边界情况与易错点

1. **最短输入 `seq = "()"`**：$d = 1$，答案 `[0,0]`，$A = $ `"()"`、$B = $ `""`，$\max(1,0) = 1 = \lceil 1/2 \rceil$。空子序列是合法的 VPS，不要把「$B$ 为空」当成错误。
2. **整个串只有一个平坦层（如 `"()()()"`）**：所有字符 `level` 都是 1，答案全 0，$A$ 拿走全部、$B$ 为空，深度仍为 1，正确。此时不要因为「$B$ 空了」试图把后半段挪给 $B$——那会破坏最优性证明里用到的结构，虽然可能仍合法但没必要。
3. **深嵌套（如 5000 层）**：`level` 单调升到 5000，答案会是 `0,1,0,1,...` 交替；只要奇偶取自正确的时机，成对性就不会被破坏。注意 `level` 用 `int` 足矣，不必担心溢出。
4. **`level` 的更新时间点写反**：这是最常见的 WA 来源。左括号「先加后染色」、右括号「先染色后减」，两者都不满足时会输出一个「两组都不合法」的答案（例如把某个右括号单独丢进只有左括号的那组）。
5. **返回类型**：必须是长度为 $n$ 的整数数组；返回 `'0'`/`'1'` 字符数组、或返回 `"011110"` 字符串都会判错。
6. **误以为要和官方输出逐位一致**：本题是 special judge，官方示例 2 的标准输出与本文结果就不同，两者都被接受。本地测试应该写「合法性 + 最优值」校验，而不是字符串比对。
7. **`seq[i] == ')'` 时先减再染色**：这样右括号会拿到「比自己真实层数小 1」的层号，同一对括号就被拆到两组，$A$ 或 $B$ 出现悬空的右括号，直接非法。写代码时务必让 `if (seq[i] == ')') --level;` 落在染色语句之后。
