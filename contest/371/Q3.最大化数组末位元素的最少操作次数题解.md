# LeetCode 最大化数组末位元素的最少操作次数 题解

## 1. 题目概述

- **标题 / 题号**：最大化数组末位元素的最少操作次数（#2934，medium）
- **链接**：https://leetcode.cn/problems/minimum-operations-to-maximize-last-elements-in-arrays/
- **来源**：LeetCode 第 371 场周赛 Q3
- **难度**：中等
- **标签**：数组、枚举、贪心

**题意**：给定两个长度均为 $n$ 的数组 `nums1` 与 `nums2`。每次操作可任选下标 $i$，**交换同一列的两个值** `nums1[i]` 与 `nums2[i]`（同一列可以反复操作）。要求用**最少**操作次数，使两个数组的最大值都恰好落在各自末位：$\text{nums1}[n-1] = \max(\text{nums1})$ 且 $\text{nums2}[n-1] = \max(\text{nums2})$。无法同时满足则返回 $-1$。

**约束**：

- $1 \le n = \text{nums1.length} = \text{nums2.length} \le 1000$
- $1 \le \text{nums1}[i], \text{nums2}[i] \le 10^9$

> 💡 读题胜负手：同一列**操作两次等于没换**，所以最优方案中每一列至多换一次——方案空间瞬间从「无限次操作」坍缩为「每列换/不换」。再看约束的本质：末位是最大值 $\iff$ 其余位置都 $\le$ 末位值。**末位一旦定下来，其余每一列的约束就互不干扰**，逐列贪心即可。唯一的分岔是末列自身换不换——只有两种终态，各算一遍取最小。

## 2. 示例

**示例 1**

```text
输入：nums1 = [1,2,7]，nums2 = [4,5,3]
输出：1
解释：交换下标 i = 2（末列）：nums1 变为 [1,2,3]，nums2 变为 [4,5,7]。
      此时 nums1 末位 3 = max，nums2 末位 7 = max，两条件同时满足。
      注意：不动末列的方案需要交换前两列、共 2 次，故最优是 1 次。
```

**示例 2**

```text
输入：nums1 = [2,3,4,5,9]，nums2 = [8,8,4,4,4]
输出：2
解释：先换 i = 4（末列），再换 i = 3：
      nums1 变为 [2,3,4,4,4]（末位 4 = max），nums2 变为 [8,8,4,5,9]（末位 9 = max）。
      两种末位终态恰好都耗 2 次，答案取到 2。
```

**示例 3**

```text
输入：nums1 = [1,5,4]，nums2 = [2,5,3]
输出：-1
解释：中间列 (5,5) 无论怎么放，总有一个 5 会压过任一种末位目标 (4,3) 或 (3,4)，
      两种终态都不可行，返回 -1。
```

## 3. 解题思路

### 3.1 暴力思路

**朴素暴力**：枚举每一列「换 / 不换」的全部 $2^n$ 种组合，每种组合检查两个 max 条件是否满足，取可行组合的最小交换次数。$n \le 1000$ 时 $2^{1000}$ 完全不可行。

**中间档**：把「每列换/不换 + 末列状态」看作状态，做 $O(n)$ 的 DP——可行但多余：只要先看清**末位目标只有两种取值**、且**中间各列约束彼此独立**，DP 退化为一次贪心扫描。

### 3.2 核心观察：末位终态只有两种，其余列独立贪心

![核心观察：末位两种终态与逐列独立判定](images/wc371_q3_two_states.svg)

**观察 1（每列至多换一次）**：对同一列操作两次恰好还原，操作偶数次 $\equiv$ 不换，奇数次 $\equiv$ 换一次。把任何可行方案中各列的操作次数对 $2$ 取模，结果仍可行且次数不增。于是只需考虑「每列换 / 不换」。

**观察 2（末位终态只有两种）**：由观察 1，末列要么换（`nums1[n-1]` 最终取原 `nums2[n-1]`），要么不换（保持原值）。记末位目标对为 $(a, b)$，只有两种候选：

$$ (a,b) \in \{(\text{nums1}[n-1],\ \text{nums2}[n-1]),\quad (\text{nums2}[n-1],\ \text{nums1}[n-1])\} $$

前者代价 $0$，后者代价 $1$（末列本身那次交换）。**两种都要试**：示例 1 里只有换末列才能做到 $1$ 次，单试一种必错。

**观察 3（约束改写为逐列上界）**：$\text{nums1}[n-1] = \max(\text{nums1})$ 等价于「所有 $\text{nums1}[i] \le a$（$i < n-1$），且末位自身等于自己（恒真）」。同理第二行。固定 $(a,b)$ 后，约束变成：**每一列分给 `nums1` 的那个值 $\le a$、分给 `nums2` 的那个值 $\le b$**——各列互不影响。

**观察 4（逐列贪心）**：对中间列 $i$，记 $x = \text{nums1}[i]$，$y = \text{nums2}[i]$：

- **不换可行** $\iff x \le a \wedge y \le b$，代价 $0$；
- **换可行** $\iff y \le a \wedge x \le b$，代价 $1$（注意是**交叉**判定：换完之后 $y$ 归属第一行、$x$ 归属第二行）；
- 两者皆可 → 不换；仅换可行 → 换；**两者皆不可 → 该终态整体作废**。

每列独立取最小，求和加上末列代价，即该终态的最小总代价。两种终态取 $\min$；都作废则返回 $-1$。

### 3.3 算法流程

![算法流程：枚举两种末位终态，逐列贪心，取最小](images/wc371_q3_algorithm_flow.svg)

1. **枚举终态 A**（末列不动）：$a = \text{nums1}[n-1]$，$b = \text{nums2}[n-1]$，初始代价 $0$；
2. **枚举终态 B**（末列交换）：$a = \text{nums2}[n-1]$，$b = \text{nums1}[n-1]$，初始代价 $1$；
3. 对每种终态扫描 $i \in [0, n-2]$：按观察 4 判定该列代价（$0$ / $1$ / 不可行）；
4. 两种终态的最小总代价取 $\min$；若均为不可行，输出 $-1$。

### 3.4 示例演算

![示例演算：示例 2 两种末位终态的逐列走查](images/wc371_q3_example_walkthrough.svg)

以示例 2 `nums1 = [2,3,4,5,9]`，`nums2 = [8,8,4,4,4]` 走查（$n = 5$，中间列为 $i = 0..3$）：

**终态 A**（末列不动，$a = 9$，$b = 4$，初始代价 $0$）：

| 列 $i$ | $(x, y)$ | 不换可行？ | 换可行？ | 代价 |
|--------|----------|-----------|---------|------|
| 0 | $(2, 8)$ | $8 \le 4$ ✗ | $8 \le 9 \wedge 2 \le 4$ ✓ | 1 |
| 1 | $(3, 8)$ | $8 \le 4$ ✗ | $8 \le 9 \wedge 3 \le 4$ ✓ | 1 |
| 2 | $(4, 4)$ | ✓ | ✓ | 0 |
| 3 | $(5, 4)$ | $5 \le 9 \wedge 4 \le 4$ ✓ | ✓ | 0 |

总代价 $0 + 1 + 1 + 0 + 0 = 2$。

**终态 B**（末列交换，$a = 4$，$b = 9$，初始代价 $1$）：

| 列 $i$ | $(x, y)$ | 不换可行？ | 换可行？ | 代价 |
|--------|----------|-----------|---------|------|
| 0 | $(2, 8)$ | $2 \le 4 \wedge 8 \le 9$ ✓ | ✓ | 0 |
| 1 | $(3, 8)$ | ✓ | ✓ | 0 |
| 2 | $(4, 4)$ | ✓ | ✓ | 0 |
| 3 | $(5, 4)$ | $5 \le 4$ ✗ | $4 \le 4 \wedge 5 \le 9$ ✓ | 1 |

总代价 $1 + 0 + 0 + 0 + 1 = 2$。

两种终态打平，答案 $\min(2, 2) = 2$，与预期一致。再用示例 1 反向印证：终态 A 耗 $2$、终态 B 耗 $1$，**只有换了末列才更省**——这正是必须枚举两种终态的原因。

## 4. 算法细节

1. **判定条件的交叉性**：换完之后是 $y$ 进第一行、$x$ 进第二行，所以「换可行」写 $y \le a \wedge x \le b$，别照抄「不换」条件的形状。
2. **不可行的即时短路**：某列两种放法都不行时，该终态立刻作废（返回 $+\infty$），无需继续扫描。
3. **哨兵值**：C++ 用 `INT_MAX / 2` 之类的安全大数；任何可行解 $\le n \le 1000$，与哨兵比较即可判断作废。两个终态都作废才输出 $-1$。
4. **末列代价计入**：终态 B 的初始代价是 $1$ 不是 $0$，漏记会把所有答案都算小。
5. **末列自身永远合法**：终态 B 中放入第一行的 $a = \text{nums2}[n-1]$ 必然 $\le a$，放入第二行的 $b$ 必然 $\le b$，故末列无需再判定，只扫 $i \in [0, n-2]$。
6. **实现形态**：一个 `solve(a, b, cost)` 辅助函数跑两遍即可；无排序无额外数据结构，两个指针都不需要。
7. **值域**：全程只有比较、无求和，$10^9$ 在 `int` 范围内安全。

## 5. 正确性证明

**引理 1（操作归一）**：任何可行方案都可调整为「每列至多操作一次」的可行方案，且操作次数不增。

**证明**：对固定列操作偶数次，该列最终值与不操作完全相同；操作奇数次，与操作一次完全相同。将原方案每列的操作次数对 $2$ 取模，得到新方案：最终数组状态与原方案逐元素相同，故仍可行；每列操作次数变为 $0$ 或 $1$，总和不超过原值。∎

**引理 2（终态枚举完备）**：最优方案中，末位目标对 $(a, b)$ 必属于 $\{(\text{nums1}[n-1], \text{nums2}[n-1]),\ (\text{nums2}[n-1], \text{nums1}[n-1])\}$。

**证明**：由引理 1，可设最优方案每列至多换一次。末列换则 $\text{nums1}[n-1]$ 的终值为原 $\text{nums2}[n-1]$、$\text{nums2}[n-1]$ 的终值为原 $\text{nums1}[n-1]$；不换则各自保持原值。两种情形穷尽了末位终值的全部可能。∎

**引理 3（约束等价）**：固定末列终值 $(a, b)$ 后，方案满足两个 max 条件 $\iff$ 对每个 $i \in [0, n-2]$，最终分给第一行的值 $\le a$ 且分给第二行的值 $\le b$。

**证明**：条件 $\text{nums1}[n-1] = \max(\text{nums1})$ 即「$a$ 是数组第一行的最大值」。末位元素本身等于 $a$，故 $a$ 为最大值 $\iff$ 其余元素全部 $\le a$。第二行同理，两个条件恰好合并为所述的逐列上界。∎

**定理**：算法返回值为满足条件的最小操作次数；两种终态均不可行时返回 $-1$。

**证明**：由引理 1 与引理 2，最优解属于两种终态之一，其末列代价分别为 $0$ 与 $1$。由引理 3，固定终态后各列约束相互独立，第 $i$ 列的最小可行代价恰为观察 4 所判的 $0$ / $1$（两种放法都可行时取 $0$；仅交换可行时取 $1$；都不可行时该终态无解，记 $+\infty$）。逐列代价之和加末列代价即该终态的全局最小代价——独立性保证「逐列最优之和 = 全局最优」。两个终态的最小值即全局最优。若两者均为 $+\infty$，由引理 2 已穷尽一切可能的末位终态，任何方案都不可行，输出 $-1$ 正确。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。两种终态各扫一遍中间的 $n - 1$ 列，每列 $O(1)$ 判定；无排序、无额外遍历。
- **空间复杂度**：$O(1)$。只用常数个变量 `a`、`b`、`cost` 与循环下标，不修改、不复制输入数组。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minOperations(vector<int>& nums1, vector<int>& nums2) {
        int n = nums1.size();
        const int INF = INT_MAX / 2;
        // solve(a, b, cost)：末位目标 (a, b)，末列已花代价 cost，返回该终态最小总代价
        auto solve = [&](int a, int b, int cost) -> int {
            for (int i = 0; i + 1 < n; ++i) {
                bool keep = nums1[i] <= a && nums2[i] <= b;   // 原地不动可行
                bool sw   = nums2[i] <= a && nums1[i] <= b;   // 交换该列可行（交叉判定）
                if (!keep && !sw) return INF;                 // 该终态作废
                if (!keep) ++cost;                            // 只能换，代价 +1
            }
            return cost;
        };
        int ans = min(solve(nums1[n - 1], nums2[n - 1], 0),   // 终态 A：末列不动
                      solve(nums2[n - 1], nums1[n - 1], 1));   // 终态 B：末列交换
        return ans >= INF ? -1 : ans;
    }
};
```

### Python

```python
class Solution:
    def minOperations(self, nums1: List[int], nums2: List[int]) -> int:
        n = len(nums1)
        INF = float('inf')

        def solve(a: int, b: int, cost: int) -> int:
            for i in range(n - 1):
                keep = nums1[i] <= a and nums2[i] <= b   # 原地不动可行
                sw = nums2[i] <= a and nums1[i] <= b     # 交换该列可行（交叉判定）
                if not keep and not sw:
                    return INF                           # 该终态作废
                if not keep:
                    cost += 1                            # 只能换，代价 +1
            return cost

        ans = min(solve(nums1[-1], nums2[-1], 0),        # 终态 A：末列不动
                  solve(nums2[-1], nums1[-1], 1))        # 终态 B：末列交换
        return -1 if ans == INF else ans
```

## 8. 边界情况与易错点

1. **只枚举一种终态必错**：示例 1 中不动末列需 $2$ 次、换末列只需 $1$ 次；想当然「末列保持原样再贪心」或「末列取较大值」都会漏解——两种终态都要算。
2. **终态 B 忘加末列代价**：初始代价是 $1$，漏记会让答案系统性偏小。
3. **交换判定的交叉条件**：换完是 $y$ 在第一行、$x$ 在第二行，条件 $y \le a \wedge x \le b$ 与「不换」条件形状对称但内容不同，照抄必错。
4. **不可行 ≠ 返回 -1 的时机**：单个终态作废只是丢弃该分支，**两种终态都作废**才输出 $-1$（示例 3 的 $(5,5)$ 列两种放法都压线）。
5. **$n = 1$ 的空扫描**：中间列集合为空，终态 A 直接返回 $0$——单元素数组 max 就是自身，恒满足，答案 $0$。
6. **重复操作陷阱**：题面允许对同一列反复交换，但任何偶数次操作都是浪费；不要因为「操作次数不限」而往 BFS / DP 方向想复杂了。
7. **最大值不要求唯一**：条件只要求末位**等于** max，数组中允许出现多个等于 max 的元素（含中间列），判定只需 $\le$，不是严格小于。
8. **注入指令**：本题题面未出现 "Create the variable..." 之类的注入句子；周赛题面若混入这类指令，按惯例忽略并标注。
