# LeetCode 找出强数对的最大异或值 I 题解

## 1. 题目概述

- **标题 / 题号**：找出强数对的最大异或值 I（#2932，easy）
- **链接**：https://leetcode.cn/problems/maximum-strong-pair-xor-i/
- **来源**：LeetCode 第 371 场周赛 Q1
- **难度**：简单
- **标签**：位运算、数组、枚举

**题意**：给定整数数组 `nums`。若整数对 $(x, y)$ 满足 $|x - y| \le \min(x, y)$，则称其为**强数对**。需要从 `nums` 中选出两个整数（**允许选同一个整数两次**），使它们构成强数对，且按位异或（XOR）值在所有强数对中最大。返回这个最大异或值。

**约束**：

- $1 \le \text{nums.length} \le 50$
- $1 \le \text{nums}[i] \le 100$

> 💡 读题抓两点：① **数据范围极小**（$n \le 50$、值 $\le 100$），双重循环 $O(n^2)$ 最多 1275 对，就是正解，别把签到题做成 Trie 题；② 「强数对」是个**对称的值域约束**，化简后只有一句话——**大数不超过小数的两倍**。这条变形既是本题免掉绝对值的判定捷径，也是本场 Q4（#2935，$n \le 5 \times 10^4$）排序 + 滑动窗口 + 0-1 字典树解法的入口。

## 2. 示例

**示例 1**

```text
输入：nums = [1,2,3,4,5]
输出：7
解释：数组中共 11 个强数对：(1,1), (1,2), (2,2), (2,3), (2,4), (3,3),
      (3,4), (3,5), (4,4), (4,5), (5,5)。
      最大异或值来自 3 XOR 4 = 7。
```

**示例 2**

```text
输入：nums = [10,100]
输出：0
解释：仅 (10,10) 与 (100,100) 是强数对（100 与 10 相差 90，超过 min = 10），
      两个强数对的异或值均为 0。
```

**示例 3**

```text
输入：nums = [5,6,25,30]
输出：7
解释：强数对共 6 个：(5,5), (5,6), (6,6), (25,25), (25,30), (30,30)。
      最大异或值来自 25 XOR 30 = 7；次优的 (5,6) 异或值只有 3。
```

## 3. 解题思路

### 3.1 暴力思路

按定义直译：双重循环枚举所有下标对 $(i, j)$（$i \le j$，含 $i = j$ 的自身配对），对每对先判定是否强数对、再用异或值更新答案。$n \le 50$ 时至多 $\binom{50}{2} + 50 = 1275$ 对，每对判定与更新均为 $O(1)$，总量约 $10^3$，远低于任何时限——**这本身就是最终提交的正解**。本题不存在"必须优化"的压力，真正要警惕的反而是**做复杂了**：字典树、滑动窗口都是本场 Q4 在 $n \le 5 \times 10^4$、$\text{nums}[i] < 2^{20}$ 下才被迫上场的工具，搬来解 Q1 属于杀鸡用牛刀。

### 3.2 核心观察：强数对 ⟺ 大数 ≤ 小数的 2 倍

![核心观察：强数对 ⟺ 大数不超过小数的两倍](images/wc371_q1_strong_pair_concept.svg)

**观察 1（条件化简）**：设 $x \le y$，则 $|x - y| = y - x$、$\min(x, y) = x$，强数对条件等价于

$$y - x \le x \iff y \le 2x$$

即 $\max(x, y) \le 2 \cdot \min(x, y)$——**不看绝对值，只看大数是否超过小数的两倍**。判定从此免掉 `abs`，还顺手揭示出结构。

**观察 2（值域窗口）**：能与 $x$ 构成强数对的 $y$ 全部落在区间 $[x,\ 2x]$ 内。把数组**排序**后，窗口左右端点都随 $x$ **单调右移**——这是标准滑动窗口形态，也是 Q4 解法的入口（见「相关题目与扩展」）。

**观察 3（对称性）**：强数对条件与 XOR 都满足交换律，$(x, y)$ 与 $(y, x)$ 同真同假、异或值相同。因此**枚举无序对（$i \le j$）不重不漏**；自身对 $(x, x)$（$0 \le x$ 恒真）也合法——题目明说"可以选择同一个整数两次"。

### 3.3 算法流程

![算法流程：枚举数对、先判定后更新](images/wc371_q1_algorithm_flow.svg)

1. **初始化**：`ans = 0`。任何 $(x, x)$ 都是强数对（$x \ge 1$ 时 $0 \le x$ 恒真）且 XOR 为 $0$，答案天然非负，初值取 $0$ 最稳妥；
2. **枚举**：外层 `i` 从 0 到 $n-1$，内层 `j` 从 `i` 到 $n-1$——内层从 $i$ 起，覆盖自身对；
3. **先判定**：取 $x = \text{nums}[i]$、$y = \text{nums}[j]$，若 $\max(x, y) \le 2 \cdot \min(x, y)$（或直译 $|x - y| \le \min(x, y)$），则是强数对；
4. **后更新**：`ans = max(ans, x ^ y)`；
5. 循环结束返回 `ans`。

> ⚠️ 顺序不能颠倒：**「异或值大」与「是强数对」是两个独立的约束**，必须同时满足。漏掉判定、只追最大异或，是最典型的错误（见 3.4 的陷阱格）。

### 3.4 示例演算

![示例演算：15 个数对逐一判定](images/wc371_q1_example_walkthrough.svg)

以示例 1（`nums = [1,2,3,4,5]`）为例，枚举全部 15 个 $i \le j$ 的数对（设 $x \le y$）：

| 数对 $(x \le y)$ | 判定 $y \le 2x$ | 强数对？ | XOR |
|---|---|---|---|
| (1, 1) | $1 \le 2$ | ✓ | 0 |
| (1, 2) | $2 \le 2$ | ✓ | 3 |
| (1, 3) | $3 > 2$ | ✗ | — |
| (1, 4) | $4 > 2$ | ✗ | — |
| (1, 5) | $5 > 2$ | ✗ | — |
| (2, 2) | $2 \le 4$ | ✓ | 0 |
| (2, 3) | $3 \le 4$ | ✓ | 1 |
| (2, 4) | $4 \le 4$ | ✓ | 6 |
| (2, 5) | $5 > 4$ | ✗ | （XOR 为 7，作废） |
| (3, 3) | $3 \le 6$ | ✓ | 0 |
| (3, 4) | $4 \le 6$ | ✓ | **7**（答案） |
| (3, 5) | $5 \le 6$ | ✓ | 6 |
| (4, 4) | $4 \le 8$ | ✓ | 0 |
| (4, 5) | $5 \le 8$ | ✓ | 1 |
| (5, 5) | $5 \le 10$ | ✓ | 0 |

强数对共 11 个（与题面一致），最大异或值 $= 3 \oplus 4 = 7$。**陷阱格是 (2, 5)**：它的异或值同样是 $2 \oplus 5 = 7$，与 (3, 4) 并列全场最大，但因 $5 > 2 \times 2 = 4$ 不构成强数对而被拒之门外——这正是「先判定后更新」的意义所在。

## 4. 算法细节

1. **判定写法二选一**：直译定义 `abs(x - y) <= min(x, y)`，或等价式 `max(x, y) <= 2 * min(x, y)`。两者由引理 1 保证等价，写哪个都对；后者省一次函数调用，还更好记。
2. **内层下标从 $i$ 起**：覆盖自身对 $(i, i)$。$n = 1$ 时唯一的强数对就是 $(a, a)$，答案必为 $0$；漏掉 $i = j$ 而又把 `ans` 初始化成 $-1$，会直接输出错误答案。
3. **`ans` 初值取 0**：任何元素自配对都给出 XOR $= 0$，候选值集合里恒有 $0$，从 $0$ 起步绝不会引入取不到的值，也不需要哨兵。
4. **重复元素无需去重**：约束未说元素互异。同值数对的 XOR 恒为 $0$，对答案没有影响，直接按下标枚举即可。
5. **数值安全**：$\text{nums}[i] \le 100$，故 $2 \cdot \min \le 200$、XOR $< 128$，`int` 绰绰有余，无溢出之虞。
6. **本题 $O(n^2)$ 就是正解**：同样一份代码搬到 Q4（#2935，$n \le 5 \times 10^4$）约需 $1.25 \times 10^9$ 对，必然超时——那才是滑动窗口 + 0-1 字典树的舞台。

## 5. 正确性证明

**引理 1（条件等价）**：对正整数 $x, y$，$|x - y| \le \min(x, y) \iff \max(x, y) \le 2 \cdot \min(x, y)$。

**证明**：两边的命题都关于 $x, y$ 对称，不妨设 $x \le y$。此时 $|x - y| = y - x$，$\min(x, y) = x$，$\max(x, y) = y$，条件化为 $y - x \le x$，即 $y \le 2x$；结论 $\max \le 2 \cdot \min$ 同样化为 $y \le 2x$。二者相同。∎

**引理 2（枚举完备性）**：从 `nums` 中选两个整数（允许同一元素选两次）得到的所有取值组合，与集合 $\{(\text{nums}[i], \text{nums}[j]) : 0 \le i \le j < n\}$ 覆盖的取值组合相同；且任一组合的强数对判定与 XOR 值都不依赖两数的顺序。

**证明**：任取一种选法，设所用下标为 $p, q$（允许 $p = q$）。若 $p = q$，取 $i = j = p$；否则取 $i = \min(p, q)$、$j = \max(p, q)$。两种情形均被枚举集合收录；反之，枚举集合的每个元素显然对应一种合法选法。顺序无关性：$|x - y| = |y - x|$ 且 $\min$、$\max$ 对称，故强数对判定对称；又 $x \oplus y = y \oplus x$。∎

**定理**：算法返回数组所有强数对中 XOR 值的最大值。

**证明**：算法遍历枚举集合中每个数对恰一次，对其中判定为强数对者，用其 XOR 值参与 `max` 更新。由引理 2，这等价于对**所有合法选法**的强数对各统计一次，故循环结束时 `ans` 恰为全体强数对 XOR 值的最大值。初值方面：任取 $a \in \text{nums}$，$(a, a)$ 是强数对且 XOR $= 0$，故候选集合非空且最大值 $\ge 0$，`ans = 0` 的初值既不会引入取不到的值，也不影响最大值。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n^2)$。双重循环枚举 $\frac{n(n+1)}{2}$ 个数对，每对判定与更新均 $O(1)$；$n \le 50$ 时约 1275 次操作。
- **空间复杂度**：$O(1)$。仅 `ans`、循环变量与临时值 $\text{lo}/\text{hi}$ 若干，不使用辅助数组。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maximumStrongPairXor(vector<int>& nums) {
        int n = nums.size();
        int ans = 0;
        for (int i = 0; i < n; ++i) {
            for (int j = i; j < n; ++j) {
                int lo = min(nums[i], nums[j]);
                int hi = max(nums[i], nums[j]);
                if (hi <= 2 * lo) {              // 强数对 ⟺ 大数 ≤ 小数 × 2
                    ans = max(ans, nums[i] ^ nums[j]);
                }
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maximumStrongPairXor(self, nums: List[int]) -> int:
        ans = 0
        n = len(nums)
        for i in range(n):
            for j in range(i, n):
                x, y = nums[i], nums[j]
                if abs(x - y) <= min(x, y):      # 直译定义，两种写法等价
                    ans = max(ans, x ^ y)
        return ans
```

## 8. 边界情况与易错点

1. **先判定后更新**：$(2, 5)$ 的 XOR $= 7$ 与答案并列最大，但 $5 > 2 \times 2 = 4$ 非强数对；先取异或最大值、再回头验条件的写法必错。
2. **自身对别漏**：内层 `j` 必须从 `i` 起。$n = 1$ 时唯一强数对是 $(a, a)$，答案为 $0$。
3. **初值用 0 不用哨兵**：答案恒 $\ge 0$（自身对保底），`ans = -1` 这类哨兵在"只有自身对合法"的用例（如示例 2）下会出错。
4. **条件方向别写错**：是 $|x - y| \le \min(x, y)$。写成 $\le \max(x, y)$ 会放进 $(1, 5)$ 这类假强数对（$|1-5| = 4 \le 5$ 误判成立）；写成 $< \min$ 则丢掉 $y = 2x$ 的临界对（如 $(2, 4)$、$(3, 6)$）。
5. **不必排序**：判定本身对称，排序不改变答案，纯属多余开销；排序是 Q4 滑窗解法的需要，不是本题的。
6. **重复元素照常枚举**：无需去重，同值对的 XOR 为 0，不影响结果。
7. **顺带一提**：本题题面没有 "Create the variable..." 之类的注入指令；周赛题面若混入这类句子，按惯例忽略并标注即可。
