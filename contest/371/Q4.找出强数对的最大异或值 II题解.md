# LeetCode 找出强数对的最大异或值 II 题解

## 1. 题目概述

- **标题 / 题号**：找出强数对的最大异或值 II（#2935，hard）
- **链接**：https://leetcode.cn/problems/maximum-strong-pair-xor-ii/
- **来源**：LeetCode 第 371 场周赛 Q4
- **难度**：困难
- **标签**：位运算、字典树、滑动窗口、排序、双指针

**题意**：给定整数数组 `nums`。若整数对 $(x, y)$ 满足 $|x - y| \le \min(x, y)$，则称其为**强数对**。需要从 `nums` 中选出两个整数（**允许选同一个整数两次**），使其构成强数对且按位异或值最大，返回这个最大异或值。

**约束**：

- $1 \le \text{nums.length} \le 5 \times 10^4$
- $1 \le \text{nums}[i] \le 2^{20} - 1$

> 💡 与本场 Q1（#2932）同题面，但数据全面放大：$n$ 从 $50$ 涨到 $5 \times 10^4$、值域从 $100$ 涨到 $2^{20}$。$O(n^2)$ 的 $1.25 \times 10^9$ 对枚举必然超时，必须把两件武器拼起来——「强数对判定」的排序 + 滑动窗口结构，与「动态集合最大异或查询」的可删除 0-1 字典树。Q1 的暴力在这里是**错误起点**，但也埋好了伏笔：化简后的判定式 $y \le 2x$ 正是滑窗解法的入口。

## 2. 示例

**示例 1**

```text
输入：nums = [1,2,3,4,5]
输出：7
解释：数组中共 11 个强数对：(1,1), (1,2), (2,2), (2,3), (2,4), (3,3),
      (3,4), (3,5), (4,4), (4,5), (5,5)。
      最大异或值来自 3 XOR 4 = 7。
```

**示例 2**

```text
输入：nums = [10,100]
输出：0
解释：仅 (10,10) 与 (100,100) 是强数对（100 与 10 相差 90，远超 min = 10），
      两个强数对的异或值均为 0。
```

**示例 3**

```text
输入：nums = [500,520,2500,3000]
输出：1020
解释：强数对共 6 个：(500,500), (500,520), (520,520), (2500,2500),
      (2500,3000), (3000,3000)。
      最大异或值来自 500 XOR 520 = 1020；另一个异或值非零的数对是
      (2500, 3000)，其异或值为 2500 XOR 3000 = 636。
```

> ⚠️ 题面示例 3 的解释中「数对 (5, 6)」是官方笔误，应为 (2500, 3000)；计算本身无误（$2500 \oplus 3000 = 636 < 1020$）。

**示例 4（补充，卡「不开窗口」的写法）**

```text
输入：nums = [2,5]
输出：0
解释：5 > 2 × 2 = 4，(2,5) 不是强数对；仅剩自身对 (2,2), (5,5)，异或值均为 0。
      注意全局最大异或恰是 2 ⊕ 5 = 7 —— 忽略强数对约束的解法会错误地返回 7。
```

## 3. 解题思路

### 3.1 暴力思路

按定义直译：双重循环枚举所有下标对 $(i, j)$（$i \le j$），先判定 $2 \cdot \min \ge \max$ 是否成立，再用异或值更新答案——正是 Q1 的正解。但本题 $n \le 5 \times 10^4$，至多 $\frac{n(n+1)}{2} \approx 1.25 \times 10^9$ 对，每对虽是 $O(1)$ 判定，总量仍然不可接受。

另一个更隐蔽的「半成品」思路：想到 [421. 数组中两个数的最大异或值](https://leetcode.cn/problems/maximum-xor-of-two-numbers-in-an-array/)，把**全部**元素插入 0-1 Trie，再对每个元素查询最大异或。这**不是慢，是错**——全局最大异或对未必是强数对。示例 4 就是一行卡死：Trie 会自信地返回 $2 \oplus 5 = 7$，而正确答案是 $0$。合法性约束必须参与算法结构，不能事后补救。

### 3.2 核心观察：排序 + 滑动窗口 + 可删除 0-1 Trie

![核心观察：排序后合法伙伴构成后缀窗口](images/wc371_q4_window_concept.svg)

**观察 1（条件化简，承接 Q1）**：设 $x \le y$，则 $|x - y| = y - x$、$\min(x, y) = x$，强数对条件等价于

$$y - x \le x \iff y \le 2x$$

排序后，带绝对值、带 $\min$ 的双变量条件塌缩成**一次乘法比较**。

**观察 2（合法伙伴是后缀 → 双指针滑窗）**：排序后固定右端点 $j$（较大者 $y = \text{nums}[j]$），合法伙伴 $k$ 需满足 $2 \cdot \text{nums}[k] \ge \text{nums}[j]$ 且 $k \le j$。由升序性，满足者的下标构成 $[0, j]$ 的一段**后缀** $[\ell(j), j]$（$\ell(j)$ 存在：$k = j$ 自身必满足）。且 $\text{nums}[j]$ 随 $j$ 非降，条件只会变严，故 $\ell(j)$ **单调不减**——窗口左右端点都只向右移动，每个元素至多**进窗一次、出窗一次**。这是 $O(n)$ 次集合增删的滑动窗口，而非 $O(n^2)$ 次两两配对。

**观察 3（动态集合的最大异或 → 带计数删除的 0-1 Trie）**：剩下的问题是「一个不断插入 / 删除元素的集合 $S$ 中，查询 $\max_{s \in S}\ y \oplus s$」。0-1 字典树天生干这个，但 421 那种「全量插入、只查不删」不够用——本题左端元素要**出窗**。标准做法是给每个节点挂**计数** `cnt`：

- 插入 $x$：沿 20 位路径走，每个经过节点 `cnt += 1`；
- 删除 $x$：同一条路径，`cnt -= 1`（**惰性删除**，节点不回收）；
- 查询时只把 `cnt > 0` 的儿子视为「存在」。

![0-1 Trie 逐位贪心查询示意](images/wc371_q4_trie_query.svg)

> 💡 为什么惰性删除不炸空间？每个元素至多被插入一次、删除一次，路径长度固定 20，所以节点总数上界始终是 $20n + 1$，与删除次数无关——删除只减计数，从不新建节点。`cnt = 0` 的子树成了「幽灵子树」，查询时绕开即可。

### 3.3 算法流程

![算法流程：排序、双指针滑窗、Trie 增删与查询](images/wc371_q4_algorithm_flow.svg)

1. **排序** `nums`（升序），初始化空 Trie、`ans = 0`、左指针 `i = 0`；
2. **枚举右端** $j$ 从 $0$ 到 $n - 1$，记 $y = \text{nums}[j]$：
   - **先插入**：`insert(nums[j], +1)`——窗口含 $y$ 自身，保证后续查询时 Trie 非空；
   - **再收缩**：只要 $2 \cdot \text{nums}[i] < y$，执行 `insert(nums[i], −1)` 并 `i++`；
   - **后查询**：`ans = max(ans, query(y))`，Trie 中现存 $[\ell(j), j]$ 窗口元素。
3. 循环结束，返回 `ans`。

> ⚠️ 收缩条件是**严格小于**：$y = 2x$ 时 $y - x = x = \min$，是合法强对（如 $(2,4)$、$(3,6)$），必须留在窗口内。

### 3.4 示例演算

![示例演算：逐步展示窗口与 Trie 变化](images/wc371_q4_example_walkthrough.svg)

以示例 1（`nums = [1,2,3,4,5]`，已排序）为例，`Trie 内容` 列给出**查询时刻**的窗口元素：

| $j$ | $\text{nums}[j]$ | 插入 / 收缩动作 | Trie 内容 | $\text{query}(\text{nums}[j])$ | ans |
|---|---|---|---|---|---|
| 0 | 1 | 插入 1 | $\{1\}$ | $1 \oplus 1 = 0$ | 0 |
| 1 | 2 | 插入 2（$2 \cdot 1 = 2 \ge 2$） | $\{1, 2\}$ | $2 \oplus 1 = 3$ | 3 |
| 2 | 3 | 插入 3；$2 \cdot 1 = 2 < 3$ → 删 1 | $\{2, 3\}$ | $3 \oplus 2 = 1$ | 3 |
| 3 | 4 | 插入 4（$2 \cdot 2 = 4 \ge 4$） | $\{2, 3, 4\}$ | $4 \oplus 3 = 7$ | **7** |
| 4 | 5 | 插入 5；$2 \cdot 2 = 4 < 5$ → 删 2 | $\{3, 4, 5\}$ | $5 \oplus 3 = 6$ | 7 |

最终返回 $7 = 3 \oplus 4$，与示例 1 一致。两个值得咀嚼的细节：

- **答案在 $j = 3$ 产生**：查询时刻窗口为 $\{2, 3, 4\}$，其中任意元素都与 4 构成强数对（窗口内两两皆强，见算法细节第 5 点），Trie 贪心挑出 $4 \oplus 3 = 7$；
- **$j = 4$ 时 2 必须出窗**：若忘了删除，`query(5)` 会拿到 $5 \oplus 2 = 7$——来自非法对 $(2, 5)$，而且**恰好与正解同值**，本例完全掩盖这个 bug，必须靠示例 4 这类用例才能暴露。

## 4. 算法细节

1. **位宽 $B = 20$**：$\text{nums}[i] \le 2^{20} - 1$，最高有效位是第 19 位，Trie 从第 19 位建到第 0 位。值域升到 $2^{31}$ 时只需把常量换成 31，逻辑零改动。
2. **Trie 三操作**：插入 / 删除共用一条 20 步路径，删除即「计数减回去」；查询从高位到低位，**优先走与 $y$ 当前位相反的儿子**，该儿子存在且 `cnt > 0` 才走，并把答案该位置 1，否则走同位儿子。
3. **每轮「先插入 → 再收缩 → 后查询」**：查询时 Trie 至少含 $y$ 自身（自身对异或为 0，恰是答案下界），全程无需判空。另一种等价顺序是「先收缩 → 查询 → 插入」（Trie 不含 $y$，需处理空 Trie），两种顺序都正确——共同点是**每个无序对恰在其右端点被统计一次**，见正确性证明。
4. **收缩用严格不等号**：`2 * nums[i] < nums[j]` 才删除，$y = 2x$ 的临界强对保留。左指针最多推进到 $j$（$2 \cdot \text{nums}[j] \ge \text{nums}[j]$ 恒真），不会越界。
5. **窗口是「强数对团」**：收缩完成后窗口 $[i, j]$ 内任意两元素 $k \le k'$ 都满足 $\text{nums}[k'] \le \text{nums}[j] \le 2 \cdot \text{nums}[i] \le 2 \cdot \text{nums}[k]$，两两互为强数对。因此查询 `query(nums[j])` 面对的候选全部合法，无需逐个验证；只查右端点也不会漏——每个无序对在其右端点那一轮必被考察。
6. **实现安全**：$2 \cdot \text{nums}[i] \le 2^{22} - 2$，`int` 无溢出；C++ 预分配 $20n + 1$ 个节点避免反复扩容；重复元素照常插入（计数累加），无需去重。

## 5. 正确性证明

**引理 1（强数对的排序刻画）**：`nums` 升序时，对任意 $k \le j$：$(\text{nums}[k], \text{nums}[j])$ 是强数对 $\iff \text{nums}[j] \le 2 \cdot \text{nums}[k]$。

**证明**：记 $x = \text{nums}[k] \le y = \text{nums}[j]$。此时 $|x - y| = y - x$、$\min(x, y) = x$，强数对条件化为 $y - x \le x$，即 $y \le 2x$。∎

**引理 2（后缀性与单调性）**：对每个 $j$，令 $\ell(j) = \min\{\,k \le j : 2 \cdot \text{nums}[k] \ge \text{nums}[j]\,\}$（存在，因 $k = j$ 满足）。则 $k \in [\ell(j), j] \iff (k, j)$ 是强数对下标对；且 $\ell(j)$ 关于 $j$ 单调不减。

**证明**：升序使 $2 \cdot \text{nums}[k]$ 关于 $k$ 非降，满足条件的 $k$ 构成 $[0, j]$ 的后缀，起点即 $\ell(j)$；结合引理 1 得前半部分。当 $j$ 增大时 $\text{nums}[j]$ 非降，$2 \cdot \text{nums}[k] \ge \text{nums}[j+1]$ 蕴含 $2 \cdot \text{nums}[k] \ge \text{nums}[j]$，故满足集缩小为子后缀，$\ell(j+1) \ge \ell(j)$。∎

**引理 3（双指针维护窗口）**：第 $j$ 轮查询时，Trie 中的多重集恰为 $\{\text{nums}[k] : \ell(j) \le k \le j\}$。

**证明**：对 $j$ 归纳。$j = 0$：插入后 Trie 为 $\{\text{nums}[0]\}$，且 $\ell(0) = 0$（$2 \cdot \text{nums}[0] \ge \text{nums}[0]$），成立。设第 $j - 1$ 轮末 Trie 为 $[\ell(j-1),\, j-1]$。第 $j$ 轮先插入 $\text{nums}[j]$，变为 $[\ell(j-1),\, j]$；随后 while 循环的继续条件 $2 \cdot \text{nums}[i] < \text{nums}[j]$ 由引理 2 等价于 $i < \ell(j)$，循环恰删除 $[\ell(j-1), \ell(j) - 1]$（由 $\ell(j) \ge \ell(j-1)$，该区间不误删窗口元素），止于 $i = \ell(j)$，Trie 变为 $[\ell(j), j]$。∎

**引理 4（Trie 贪心查询）**：设多重集 $S \ne \varnothing$ 已按上述计数方式插入 Trie，$y$ 为查询值。逐位贪心（在 `cnt > 0` 的儿子中优先取与 $y$ 当前位相反者）返回 $\max_{s \in S} y \oplus s$。

**证明**：按位归纳维护不变式：处理完第 $k$ 位后，当前子树恰为 $S_k = \{s \in S : (y \oplus s) \text{ 的第 } 19 \sim k \text{ 位与 res 一致}\}$，且 $S_k \ne \varnothing$。初始 $S_{20} = S \ne \varnothing$。归纳步看第 $k$ 位：若贪心走向相反位儿子，则该儿子 `cnt > 0`，$S_{k-1} = \{s \in S_k : \text{第 } k \text{ 位异或为 } 1\} \ne \varnothing$；若走向同位儿子，说明相反位儿子 `cnt` 为 0（不存在或为幽灵），即 $S_k$ 中所有 $s$ 的第 $k$ 位都与 $y$ 相同，$S_{k-1} = S_k \ne \varnothing$。子树的 `cnt` 按构造等于其中现存元素的个数（插入 +1、删除 −1 的路径计数守恒），故「`cnt > 0`」与「子树非空」精确一致。归纳终止时 $S_{-1} \ne \varnothing$，取 $s \in S_{-1}$，则 $y \oplus s$ 与 res 全 20 位一致，即 res 可取得。再证最大性：对任意 $s \in S$，设 $b$ 为 $y \oplus s$ 与 res 的最高差异位。若该位 res 为 0 而 $y \oplus s$ 为 1，则 $s \in S_{b+1}$ 且第 $b$ 位异或为 1，贪心在该位必然走向相反位儿子（其 `cnt > 0`，至少含 $s$），res 该位应为 1，矛盾。故不存在 $y \oplus s > \text{res}$，结合 $2^b > \sum_{t < b} 2^t$ 的逐位比较即 res 为最大值。∎

**定理**：算法返回数组所有强数对中异或值的最大值。

**证明**：**不漏**：任取强数对，设其两元素下标 $k \le j$（值 $\text{nums}[k] \le \text{nums}[j]$）。由引理 1，$\text{nums}[j] \le 2 \cdot \text{nums}[k]$，即 $k \ge \ell(j)$。由引理 3，第 $j$ 轮查询时 $\text{nums}[k]$ 在 Trie 中，由引理 4，`query(nums[j])` 返回值 $\ge \text{nums}[k] \oplus \text{nums}[j]$，故该对的异或值被 `ans` 覆盖。**不重、不假**：第 $j$ 轮查询仅与 Trie 中元素（即 $[\ell(j), j]$ 窗口元素，引理 3）配对，它们与 $\text{nums}[j]$ 均构成强数对（引理 1），故 `ans` 的每次更新只取自真实强数对的异或值。自身对 $(j, j)$ 异或为 0，是合法强对，与 `ans` 初值 0 一致，不影响最大值。综上 `ans` 恰为全体强数对异或值的最大值。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \log n + 20n)$
  - 排序 $O(n \log n)$；
  - 主循环中 $j$ 前进 $n$ 步、$i$ 总共前进不超过 $n$ 步，故插入、删除、查询各发生至多 $n$ 次，每次沿 20 位路径走 $O(20)$；
  - 合计约 $5 \times 10^4 \times 3 \times 20 = 3 \times 10^6$ 次节点访问，远低于时限。
- **空间复杂度**：$O(20n)$
  - Trie 节点数上界 $20n + 1 \approx 1.05 \times 10^6$（$n$ 次插入 $\times$ 路径长 20；惰性删除不新建节点），每节点两个儿子指针加一个计数。

## 7. 参考代码

### C++

```cpp
// 排序 + 双指针滑窗 + 可删除 0-1 Trie，O(n log n + 20n) / O(20n)
class Solution {
public:
    int maximumStrongPairXor(vector<int>& nums) {
        sort(nums.begin(), nums.end());
        int n = nums.size();

        int m = 20 * n + 1;                       // 节点数上界：n 次插入 × 20 位
        vector<array<int, 2>> ch(m, {-1, -1});    // ch[u] = 两个儿子编号
        vector<int> cnt(m, 0);                    // 惰性删除：经过 u 的元素计数
        int tot = 1;                              // 0 号为根，下一个可用编号为 1

        auto insert = [&](int x, int d) {         // d = +1 插入 / -1 删除
            int u = 0;
            for (int k = 19; k >= 0; --k) {
                int b = (x >> k) & 1;
                if (ch[u][b] < 0) ch[u][b] = tot++;
                u = ch[u][b];
                cnt[u] += d;
            }
        };
        auto query = [&](int x) {                 // x 与集合内元素的最大异或
            int u = 0, res = 0;
            for (int k = 19; k >= 0; --k) {
                int b = (x >> k) & 1;
                int v = ch[u][b ^ 1];             // 优先走与 x 相反的位
                if (v >= 0 && cnt[v] > 0) {
                    res |= 1 << k;
                    u = v;
                } else {
                    u = ch[u][b];                 // 只能走同位（该位贡献 0）
                }
            }
            return res;
        };

        int ans = 0;
        for (int i = 0, j = 0; j < n; ++j) {
            insert(nums[j], +1);                  // 先插入：查询时 Trie 必含自身
            while (2 * nums[i] < nums[j]) {       // 严格小于：y = 2x 的临界强对保留
                insert(nums[i], -1);
                ++i;
            }
            ans = max(ans, query(nums[j]));
        }
        return ans;
    }
};
```

### Python

```python
# 排序 + 双指针滑窗 + 可删除 0-1 Trie，O(n log n + 20n) / O(20n)
class Solution:
    def maximumStrongPairXor(self, nums: List[int]) -> int:
        nums.sort()
        n = len(nums)

        ch = [[-1, -1]]                          # 0 号为根，-1 表示儿子不存在
        cnt = [0]

        def insert(x: int, d: int) -> None:      # d = +1 插入 / -1 删除
            u = 0
            for k in range(19, -1, -1):
                b = (x >> k) & 1
                if ch[u][b] < 0:
                    ch[u][b] = len(ch)
                    ch.append([-1, -1])
                    cnt.append(0)
                u = ch[u][b]
                cnt[u] += d

        def query(x: int) -> int:                # x 与集合内元素的最大异或
            u, res = 0, 0
            for k in range(19, -1, -1):
                b = (x >> k) & 1
                v = ch[u][b ^ 1]                 # 优先走与 x 相反的位
                if v >= 0 and cnt[v] > 0:
                    res |= 1 << k
                    u = v
                else:
                    u = ch[u][b]
            return res

        ans = i = 0
        for j in range(n):
            insert(nums[j], 1)                   # 先插入：查询时 Trie 必含自身
            while 2 * nums[i] < nums[j]:         # 严格小于：y = 2x 的临界强对保留
                insert(nums[i], -1)
                i += 1
            ans = max(ans, query(nums[j]))
        return ans
```

## 8. 边界情况与易错点

1. **只建 Trie 不开窗口必错**：全局最大异或对可能是非法对。示例 4 的 `nums = [2,5]` 直接卡死这种写法（返回 7，正确为 0）；而示例 1 恰好掩盖此 bug（$5 \oplus 2 = 7$ 与正解同值），**自测必须补一个窗口外异或更大的用例**。
2. **收缩条件必须严格小于**：`2 * nums[i] < nums[j]` 才删除。$y = 2x$ 时 $y - x = x = \min$ 取等，是合法强对；写成 `<=` 会丢掉 $(2,4)$、$(3,6)$ 这类临界对。
3. **删除必须检查 `cnt > 0` 而非「儿子是否存在」**：被删除元素的路径节点仍在（儿子指针非空），但 `cnt = 0` 的子树已空。不查计数会走进幽灵子树，把出窗元素当候选。
4. **查询永不判空的秘密是「先插入」**：右端 $y$ 先入 Trie 再收缩再查询，自身对（异或 0，天然合法）保证集合非空，同时给出答案下界。若改用「先查询后插入」的顺序，第 $0$ 轮面对空 Trie 需要特判。
5. **每个无序对恰统计一次**：只以右端点为查询对象、Trie 只装 $[\ell(j), j]$。若把窗口当「团」对每个元素都查询一遍，答案不变但白做 $O(n)$ 倍功。
6. **数值与规模**：$2 \cdot \text{nums}[i] \le 2^{22} - 2$ 无溢出；$n = 1$ 时唯一强数对是 $(a, a)$，返回 0；重复元素照常插入（计数累加），无需去重。
7. **Python 常数**：$20n \approx 10^6$ 次节点操作，嵌套函数 + 列表实现即可通过；追求极速可把 `ch` 拆成两个平行列表并在主循环内联三操作。

**延伸思考**：① **按位分桶贪心**（官方 hints 的另一条路）：从高位到低位确定答案，每轮把元素按 $\text{num} \gg k$ 前缀分组哈希，对前缀 $a$ 与 $a \oplus t$ 两组用双指针判定「是否存在跨组强数对」（$x \le y \le 2x \iff x \in [\lceil y/2 \rceil,\ 2y]$，区间随 $y$ 右移），每组每轮至多访问两次，总复杂度 $O(20n)$ 且完全不用 Trie；② **按最高位分桶**：同桶（值域 $[2^k, 2^{k+1})$）内任意两数自动构成强数对（$y < 2^{k+1} = 2 \cdot 2^k \le 2x$），桶内退化为 421，只有跨相邻桶才需真正判定；③ 若把约束换成 $|x - y| \le k$（定值），仍是排序 + 双指针 + 可删除 Trie，代码几乎不变，只是收缩条件从「倍数」换成「差值」；④ 若改求强数对的**最小**异或值，Trie 查询改为优先走相同位即可，窗口逻辑原样保留。
