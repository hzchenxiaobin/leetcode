# LeetCode 构造最小位运算数组 II 题解

## 1. 题目概述

- **标题 / 题号**：构造最小位运算数组 II（#3315，medium）
- **链接**：https://leetcode.cn/problems/construct-the-minimum-bitwise-array-ii/
- **来源**：LeetCode 第 141 场双周赛 Q2
- **难度**：中等
- **标签**：位运算、数组

**题意**：给定长度为 $n$ 的**质数**数组 `nums`（本题 $nums[i]$ 可达 $10^9$），构造等长数组 `ans`，使每个下标 $i$ 满足

$$\text{ans}[i] \;\text{OR}\; (\text{ans}[i] + 1) = \text{nums}[i]$$

且在此前提下 `ans[i]` 取**最小值**；若不存在则 `ans[i] = -1`。

**约束**：

- $1 \le \text{nums.length} \le 100$
- $2 \le \text{nums}[i] \le 10^9$
- `nums[i]` 是**质数**

> **注意**：题面没有附加无关的变量注入指令。与 Q1 相比，唯一的差别是值域从 $1000$ 放大到 $10^9$，因此 Q1 的「逐个枚举 $x$」不再可行。

## 2. 示例

**示例 1**

```text
输入：nums = [2,3,5,7]
输出：[-1,1,4,3]
解释：
  ans[0] = -1：不存在 x 使 x | (x+1) = 2；
  ans[1] = 1 ：1 | 2  = 3；
  ans[2] = 4 ：4 | 5  = 5；
  ans[3] = 3 ：3 | 4  = 7。
```

**示例 2**

```text
输入：nums = [11,13,31]
输出：[9,12,15]
解释：
  9  | 10 = 11；
  12 | 13 = 13；
  15 | 16 = 31。
```

**示例 3（大值自测，仍在 $10^9$ 约束内）**

```text
输入：nums = [999999937]
输出：[999999936]
解释：999999938 = 2 × 499999969，故 T = 1，ans = 999999937 - 2^0 = 999999936；
      验证 999999936 | 999999937 = 999999937（x 为偶数时 x | (x+1) = x+1）。
```

## 3. 解题思路

### 3.1 暴力思路

沿用 Q1 的做法：对每个 `nums[i]`，从 $x = 0$ 开始逐个检验 $(x \;\text{OR}\; (x+1)) == \text{nums}[i]$，命中即最小解。

复杂度 $O(n \cdot V)$，其中 $V = \text{nums}[i]$。Q1 里 $V \le 1000$ 没问题，但本题 $V$ 可达 $10^9$，$n = 100$ 时最坏 $10^{11}$ 次位运算，**必然超时**。必须利用二进制结构直接算出答案。

### 3.2 核心观察：末尾连续 1 的个数决定一切

![末尾连续 1：x+1 只改动低位那一段，或运算把它补回来](images/bw141_q2_trailing_ones.svg)

设 $x$ 的二进制末尾有**连续 $t$ 个 $1$**（即 bit $0 \sim t-1$ 为 $1$、bit $t$ 为 $0$；$x$ 为偶数时 $t = 0$）：

$$x + 1 \;\text{把低 } t \text{ 位清零、把第 } t \text{ 位置 } 1\text{，高位不变}$$

再与 $x$ 做或运算，低 $t$ 位又被补回 $1$，于是得到一个干净恒等式：

$$x \;\text{OR}\; (x+1) = x + 2^t$$

例如 $x = 43 = 101011_2$，$t = 2$，则 $43 \;\text{OR}\; 44 = 47 = 43 + 2^2$。

**反过来推**：要求 $x \;\text{OR}\; (x+1) = N$，就等价于

$$N = x + 2^t,\qquad x \text{ 末尾恰有 } t \text{ 个 } 1$$

这又蕴含 $N$ 的低 $t+1$ 位**全为 $1$**。记 $N$ 末尾连续 $1$ 的个数为 $T$，则必须 $t + 1 \le T$，即 $t \le T - 1$。

![反向推：t 只有 T 个候选，取最大的 t 得到最小的 x](images/bw141_q2_lowbit_formula.svg)

- $N$ 为偶数时 $T = 0$，没有任何合法 $t$，答案为 $-1$（再次印证「结果必为奇数」）。
- $N$ 为奇数时 $t \in \{0, 1, \dots, T-1\}$，每个 $t$ 给出候选 $x = N - 2^t$。**$t$ 越大 $x$ 越小**，故取 $t = T - 1$：

$$\boxed{\;\text{ans} = N - 2^{T-1} = N - \frac{\text{lowbit}(N+1)}{2}\;}$$

因为 $N+1$ 恰好把末尾 $T$ 个 $1$ 变成 $T$ 个 $0$、第 $T$ 位置 $1$，所以 $\text{lowbit}(N+1) = 2^T$，一次 `n & -n` 就求得 $2^T$。

### 3.3 算法流程

```text
1. 对每个 N = nums[i]：
     若 N 是偶数：ans[i] = -1，继续
     记 low = (N+1) & -(N+1)        # 等于 2^T，T 为 N 末尾连续 1 的个数
     ans[i] = N - low / 2           # 即 N - 2^(T-1)
2. 返回 ans
```

整题 $O(n)$，每个元素常数次位运算。

### 3.4 示例演算

![示例演算表：N、二进制、T、lowbit(N+1) 与 ans 一一对应](images/bw141_q2_example_walkthrough.svg)

| $N$ | 二进制 | $T$ | $\text{lowbit}(N+1)$ | ans |
|-----|--------|-----|----------------------|-----|
| 2 | $10_2$ | 0 | 3（非 2 的幂） | $-1$ |
| 3 | $11_2$ | 2 | 4 | $3-2 = 1$ |
| 5 | $101_2$ | 1 | 2 | $5-1 = 4$ |
| 7 | $111_2$ | 3 | 8 | $7-4 = 3$ |
| 11 | $1011_2$ | 2 | 4 | $11-2 = 9$ |
| 13 | $1101_2$ | 1 | 2 | $13-1 = 12$ |
| 31 | $11111_2$ | 5 | 32 | $31-16 = 15$ |

注意 $N = 11$ 时末尾只有 $2$ 个 $1$，$t = 2$ 越界（$7 \;\text{OR}\; 8 = 15 \ne 11$），因此只能取 $t = 1$，答案 $9$。$N = 5$ 时 $T = 1$，只能取 $t = 0$，答案是偶数 $4$——**答案本身不要求是奇数**，只有等式左边的结果要求是奇数。

## 4. 算法细节

1. **lowbit 写法**：`low = (N + 1) & -(N + 1)`。$N \le 10^9$ 时 $N+1$ 不溢出 `int`，但用 `long long` 更稳妥，避免对边界值做心算。
2. **减半而不是移位**：$2^{T-1} = \text{low} / 2$，直接整除即可；$T \ge 1$ 保证 `low` 至少为 $2$。
3. **偶数的处理**：把 `T = 0` 视作「无候选」，与 `N % 2 == 0` 完全等价。写 `if (N % 2 == 0) → -1` 即可，不必真的去数 $T$。
4. **不需要求 $T$**：整个算法只用到 $\text{lowbit}(N+1)$，省掉逐位扫描，把本来 $O(\log N)$ 的统计也省成 $O(1)$。
5. **`INT_MIN` 陷阱**：若有人把 lowbit 写成 `n & -n` 而 `n = INT_MIN`，取负会溢出；本题 $N \ge 2$，且我们用 $N+1$ 并转 `long long`，无此风险。
6. **答案范围**：$0 \le \text{ans} \le N-1$，非负，用 `int` 或 `long long` 都行。

## 5. 正确性证明

**引理 1（尾段公式）**：设 $x$ 二进制末尾恰有 $t$ 个连续的 $1$，则 $x \;\text{OR}\; (x+1) = x + 2^t$。

**证明**：$x$ 的低 $t$ 位全为 $1$、第 $t$ 位为 $0$。加 $1$ 时低 $t$ 位逐位进位变 $0$、第 $t$ 位由 $0$ 变 $1$，更高位不产生进位、保持不变，故 $x+1$ 与 $x$ 只在第 $t$ 位不同（$x$ 为 $0$、$x+1$ 为 $1$），低 $t$ 位被清零。再做或运算，低 $t$ 位从 $x$ 取回 $1$，第 $t$ 位取 $1$，高位不变，结果恰为 $x$ 把第 $t$ 位置 $1$，即 $x + 2^t$。∎

**引理 2（解的形式）**：若 $x \;\text{OR}\; (x+1) = N$ 且 $x$ 末尾有 $t$ 个 $1$，则 $N = x + 2^t$，且 $N$ 的低 $t+1$ 位全为 $1$。特别地，$x = N - 2^t$。

**证明**：前半由引理 1 直接得到。由 $x$ 低 $t$ 位为 $1$、第 $t$ 位为 $0$，$x + 2^t$ 的低 $t$ 位仍为 $1$（不进位），第 $t$ 位变 $1$，所以 $N$ 的低 $t+1$ 位全为 $1$。∎

**引理 3（$t$ 的取值集合）**：设 $N$ 末尾连续 $1$ 的个数为 $T$（$N$ 偶数时 $T = 0$）。则 $N$ 有解当且仅当 $N$ 为奇数，且此时全部解恰为

$$\{\,N - 2^t \;:\; 0 \le t \le T-1\,\}$$

**证明**：由引理 2，任何解的 $t$ 必满足「$N$ 低 $t+1$ 位全 $1$」，即 $t + 1 \le T$，所以 $t \le T-1$，解必在集合内。反之对任意 $t \le T-1$ 取 $x = N - 2^t$：由于 $N$ 的第 $t$ 位为 $1$、低 $t$ 位为 $1$，减去 $2^t$ 时第 $t$ 位变 $0$、低位保持 $1$，故 $x$ 末尾恰有 $t$ 个 $1$（第 $t$ 位为 $0$），由引理 1 得 $x \;\text{OR}\; (x+1) = x + 2^t = N$，是合法解。集合内外都验证完毕。∎

**引理 4（最小性）**：$x = N - 2^t$ 关于 $t$ 单调递减，故集合中的最小值在 $t = T-1$ 处取得，等于 $N - 2^{T-1}$。

**证明**：$2^t$ 关于 $t$ 严格递增，故 $N - 2^t$ 严格递减。∎

**定理**：算法的返回值等于满足等式的最小非负整数；$N$ 为偶数时返回 $-1$。

**证明**：$N$ 为偶数时 $T = 0$，由引理 3 无解，算法返回 $-1$，符合题面要求。$N$ 为奇数时由引理 3 解集非空且恰为 $\{N-2^t\}$，由引理 4 最小解是 $N - 2^{T-1}$；而 $\text{lowbit}(N+1) = 2^T$（$N+1$ 低 $T$ 位为 $0$、第 $T$ 位为 $1$），所以 `N - low/2` 正是 $N - 2^{T-1}$，两者一致。∎

## 6. 复杂度分析

- **时间**：$O(n)$。每个元素只需一次加法、一次 `& -x`、一次整除与一次减法，位运算按机器字长 $O(1)$。
- **空间**：$O(1)$ 额外空间（不计长度为 $n$ 的输出数组）。
- **对比 Q1**：从 $O(n \cdot V)$（$V \le 10^9$，不可接受）降到 $O(n)$，代价只是要先想清楚末尾连续 $1$ 的结构。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> minBitwiseArray(vector<int>& nums) {
        vector<int> ans;
        ans.reserve(nums.size());
        for (int n : nums) {
            if (n % 2 == 0) {                       // 偶数的结果必为奇数，无解
                ans.push_back(-1);
                continue;
            }
            long long low = (long long)(n + 1) & -(long long)(n + 1);  // = 2^T
            ans.push_back((int)(n - low / 2));      // = n - 2^(T-1)
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def minBitwiseArray(self, nums: list[int]) -> list[int]:
        ans = []
        for n in nums:
            if n % 2 == 0:                  # 偶数必然无解
                ans.append(-1)
            else:
                low = (n + 1) & -(n + 1)    # = 2^T，T 为 n 末尾连续 1 的个数
                ans.append(n - low // 2)    # = n - 2^(T-1)
        return ans
```

## 8. 边界情况与易错点

1. **把 $T$ 用成 $T+1$**：`ans = N - lowbit(N+1)` 是错的，正确是 `N - lowbit(N+1)/2`。用 $N = 3$ 自测：正确 $1$，写错得 $-1$。
2. **`N = 3` 这类「全 1」值**：$T$ 等于二进制长度，$t = T-1$ 时 $x = 1$；若误取 $t = T$，$x = -1$，直接越界。
3. **忘了偶数的 $-1$**：$N = 2$ 时 $\text{lowbit}(3) = 3$，$3/2 = 1$（整除），会得到 $2 - 1 = 1$，但 $1 \;\text{OR}\; 2 = 3 \ne 2$，答案错误。必须显式判偶。
4. **`low / 2` 与 `low >> 1` 等价性**：两者都可以，但别写成 `(low - 1) / 2`。
5. **`n + 1` 溢出**：$n = 10^9$ 时 $n+1$ 仍在 `int` 范围内（$< 2^{31}-1$），但若把值域理解成 $2 \times 10^9$ 就会翻车；用 `long long` 零成本，建议照抄。
6. **不要用循环数 $T$**：虽能过，但把 $O(1)$ 变成 $O(\log N)$；本题数据规模下无所谓，但既然 lowbit 一行就够，就没必要。
7. **答案非负**：$N$ 为奇数时有 $2^{T-1} \le N$，所以 `ans ≥ 0`；这里不需要额外判负。
