# LeetCode 安排活动的方案数 题解

## 1. 题目概述

- **标题 / 题号**：安排活动的方案数（#3317，hard）
- **链接**：https://leetcode.cn/problems/find-the-number-of-possible-ways-for-an-event/
- **来源**：LeetCode 第 141 场双周赛 Q4
- **难度**：困难
- **标签**：数学、动态规划、组合数学

**题意**：共有 $n$ 位表演者、$x$ 个节目。每位表演者被安排到 $x$ 个节目中的恰好一个（允许某些节目**空着**）。安排完成后，评委会给**每一个有表演者的节目**打一个 $[1, y]$ 之间的整数分，空节目不打分。若两个活动满足下面任一条件，就视为**不同**的活动：

- 存在某位表演者被安排到了不同的节目；
- 存在某个节目的分数不同。

求不同活动的总数，对 $10^9+7$ 取模。

**约束**：

- $1 \le n, x, y \le 1000$

> **注意**：题面没有「Create the variable …」这类注入指令，按正常题意计数即可。

## 2. 示例

**示例 1**

```text
输入：n = 1, x = 2, y = 3
输出：6
解释：表演者可选节目 1 或 2（2 种），唯一非空节目可打 1/2/3 分（3 种）→ 2 × 3 = 6。
```

**示例 2**

```text
输入：n = 5, x = 2, y = 1
输出：32
解释：分数只能是 1，方案数退化为安排数 2^5 = 32。
```

**示例 3**

```text
输入：n = 3, x = 3, y = 4
输出：684
解释：非空节目数 j = 1/2/3 分别贡献 12 / 288 / 384，合计 684。
```

## 3. 解题思路

### 3.1 暴力思路

最直白的办法是枚举每位表演者去哪个节目，共有 $x^n$ 种安排；对每种安排，设非空节目数为 $j$，则打分方式有 $y^j$ 种。总答案即

$$\sum_{\text{安排}} y^{\#\text{非空节目}}$$

复杂度 $O(x^n \cdot n)$，$n, x$ 到 $1000$ 时完全不可行（$1000^{1000}$）。但这条式子给出了正确的**计数口径**：分数只与「有几个节目非空」有关，与具体是哪些节目无关。抓住这一点就能把「枚举安排」换成「按非空节目数分类」。

### 3.2 核心观察：按非空节目数 $j$ 分类

![按非空节目数 j 分三层：挑选节目、满射安排、独立打分](images/bw141_q4_counting_model.svg)

一个活动由三部分信息完全确定：哪些节目非空、每位表演者去哪个节目、每个非空节目的分数。设非空节目数为 $j$（$1 \le j \le \min(n, x)$，因为 $j$ 个非空节目至少需要 $j$ 位表演者，节目数也不超过 $x$）。这三层选择互相独立：

1. **挑出非空的节目**：从 $x$ 个节目里选 $j$ 个，共 $\binom{x}{j}$ 种；
2. **把 $n$ 位表演者满射到这 $j$ 个节目**：每个节目至少 1 人，共 $j! \cdot S(n, j)$ 种，其中 $S(n, j)$ 是第二类斯特林数（把 $n$ 个有区别的人分成 $j$ 个**无区别**的非空组）；
3. **给这 $j$ 个节目打分**：每个独立取 $[1, y]$，共 $y^j$ 种。

于是

$$\text{答案} = \sum_{j=1}^{\min(n, x)} \binom{x}{j} \cdot j! \cdot S(n, j) \cdot y^j \pmod{10^9+7}$$

**为什么按 $j$ 分类不重不漏**：$j$ 是活动的内在属性（非空节目的个数），任何一个活动都恰有一个 $j$，且三层选择（节目集合、人员分配、分数）合起来唯一确定活动，反之亦然。所以对 $j$ 求和既不重复也不遗漏。

### 3.3 算法流程 / 状态转移

![第二类斯特林数的递推与「组有编号」的换算](images/bw141_q4_stirling_dp.svg)

第二类斯特林数用经典递推在 $O(n \cdot \min(n,x))$ 内求出：

$$S(i, j) = S(i-1, j-1) + j \cdot S(i-1, j), \qquad S(0,0)=1,\ S(i,0)=0\ (i \ge 1)$$

含义：考虑第 $i$ 个元素，要么**自成一组**（前 $i-1$ 个元素分成 $j-1$ 组），要么**并入已有的 $j$ 组之一**（$j$ 种选择）。

整体流程：

```text
1. 预处理阶乘 fact[0..max(n,x)] 与逆元阶乘 inv_fact[]（模 1e9+7）
2. 用滚动数组求第二类斯特林数 S[j]（j = 0..min(n,x)）：
       S[0] = 1
       for i = 1 .. n:
           for j = min(i, k) 递减到 1:  S[j] = (S[j-1] + j * S[j]) % MOD
           S[0] = 0
3. ans = 0；枚举 j = 1 .. min(n, x)：
       C = fact[x] * inv_fact[j] * inv_fact[x-j] % MOD
       项 = C * (S[j] * fact[j] % MOD) % MOD * y^j % MOD
       ans = (ans + 项) % MOD
4. 返回 ans
```

计算 $\binom{x}{j}$ 时需要模意义下的除法，因此先求 $1010$ 以内的阶乘与逆元阶乘（用费马小定理 + 快速幂）。

### 3.4 示例演算

![示例 3 的逐项演算表：j = 1、2、3 三项贡献 12 + 288 + 384](images/bw141_q4_example_walkthrough.svg)

以 $n = 3,\ x = 3,\ y = 4$ 为例：

| $j$ | $\binom{3}{j}$ | $S(3,j)$ | $j!$ | $y^j = 4^j$ | 本项贡献 |
|-----|----------------|----------|------|-------------|----------|
| 1 | 3 | 1 | 1 | 4 | $3 \times 1 \times 1 \times 4 = 12$ |
| 2 | 3 | 3 | 2 | 16 | $3 \times 3 \times 2 \times 16 = 288$ |
| 3 | 1 | 1 | 6 | 64 | $1 \times 1 \times 6 \times 64 = 384$ |
| 合计 | | | | | $684$ |

与示例 3 的 $684$ 一致。$j = 2$ 一栏可以这样读：挑 2 个节目（3 种），3 人分成 2 个非空组（$S(3,2)=3$），给两组编号（$2!=2$），再各自打 $1\sim4$ 分（$4^2=16$），共 $3 \times 3 \times 2 \times 16 = 288$ 种。

## 4. 算法细节

1. **$j$ 的上界**：$j \le \min(n, x)$。$j > n$ 时无法满射（人手不足），$j > x$ 时节目不够。
2. **滚动求斯特林数**：`for (int j = min(i,k); j >= 1; j--)` 必须**倒序**，这样 `S[j-1]` 仍是第 $i-1$ 层的值；正序会把本层的新值当成上一层用。
3. **`S[0]` 的处理**：初值 `S[0] = 1` 对应 $S(0,0)$；每轮结束后置 `S[0] = 0`，因为 $i \ge 1$ 时 $S(i,0) = 0$。
4. **组合数计算**：$\binom{x}{j} = \dfrac{x!}{j!\,(x-j)!}$，用逆元阶乘避免每次快速幂；上限取 $\max(n, x) \le 1000$。
5. **满射数**：$j! \cdot S(n,j)$ 中 $S(n,j)$ 的「组无区别」，乘上 $j!$ 恰好把 $j$ 个组排列成具体节目，与 $\binom{x}{j}$ 选出的节目一一对应。
6. **$y^j$ 递推**：枚举 $j$ 时同步累乘 `ypow = ypow * y % MOD`，省掉每轮快速幂。
7. **取模**：所有乘法前用 `long long`，每一步都 `% MOD`；减法只在必要处出现（本题没有减法）。

## 5. 正确性证明

**引理 1（安排数与满射数）**：把 $n$ 位（互不相同的）表演者安排到指定的 $j$ 个（互不相同的）节目、且每个节目至少 1 人的方案数等于 $j! \cdot S(n,j)$。

**证明**：先把 $j$ 个节目标签抹掉，此时「$n$ 人分成 $j$ 个非空组」的方案数正是 $S(n,j)$。再把 $j$ 个标签重新贴回去，有 $j!$ 种贴法；由于节目标签互不相同且分组非空，不同贴法给出不同的安排，且每个安排恰好对应一个「无标签分组 + 一种贴法」的组合（把同节目的表演者聚成一组）。故方案数为 $j! \cdot S(n,j)$。∎

**引理 2（斯特林递推）**：$S(i,j) = S(i-1,j-1) + j\,S(i-1,j)$。

**证明**：按第 $i$ 个元素所在的组分类。若它**独占一组**，则前 $i-1$ 个元素须分成 $j-1$ 个非空组，贡献 $S(i-1,j-1)$；若它**并入已有组**，则前 $i-1$ 个元素已分成 $j$ 个非空组，且它可选其中任意一组，贡献 $j \cdot S(i-1,j)$。两类互斥且穷尽，相加即得。∎

**引理 3（分类不重不漏）**：设 $j$ 为活动的非空节目数，则三元组（非空节目集合 $A$、把 $n$ 人分配到 $A$ 且满射的映射 $f$、给 $A$ 中每个节目定的分数 $g$）与活动一一对应。

**证明**：正方向：由活动直接读出 $A$（有人的节目）、$f$（每人所在节目）、$g$（每个非空节目的分数）。反方向：给定 $(A,f,g)$ 并令 $A$ 之外的节目为空，即还原出唯一的活动。两方向互逆，故为双射。∎

**定理**：算法返回的值等于不同活动的总数对 $10^9+7$ 取模。

**证明**：由引理 3，活动按其非空节目数 $j$ 被划分为互不相交的类。对固定的 $j$，由引理 1，选择 $A$ 有 $\binom{x}{j}$ 种、在 $A$ 上满射分配有 $j!\,S(n,j)$ 种、分数有 $y^j$ 种，三层独立，故该类大小为 $\binom{x}{j} \cdot j! \cdot S(n,j) \cdot y^j$。对所有 $j$ 求和即总方案数。引理 2 保证程序算出的 $S(n,j)$ 与定义一致（数学归纳：初值 $S(0,0)=1$ 正确，每层按递推更新），快速幂与逆元阶乘保证 $\binom{x}{j}$、$y^j$ 在模意义下正确。因此输出恰为所求。∎

## 6. 复杂度分析

- **时间**：$O\big(n \cdot \min(n,x)\big)$ 求斯特林数，加上 $O(\max(n,x))$ 预处理阶乘与逆元、$O(\min(n,x))$ 求和。$n, x \le 1000$ 时最坏约 $10^6$ 次乘法，极快。
- **空间**：$O(\max(n,x) + \min(n,x))$。阶乘、逆元阶乘数组各长 $\max(n,x)+1$，斯特林数滚动数组长 $\min(n,x)+1$。
- **对比暴力**：从 $O(x^n)$ 降到 $O(n \min(n,x))$，靠的是「按非空节目数分类」这一步组合抽象。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int numberOfWays(int n, int x, int y) {
        const long long MOD = 1000000007LL;
        int lim = max(n, x);
        vector<long long> fact(lim + 1, 1), inv_fact(lim + 1, 1);
        for (int i = 1; i <= lim; i++) fact[i] = fact[i - 1] * i % MOD;
        auto power = [&](long long a, long long e) {
            long long r = 1 % MOD;
            a %= MOD;
            while (e > 0) {
                if (e & 1) r = r * a % MOD;
                a = a * a % MOD;
                e >>= 1;
            }
            return r;
        };
        inv_fact[lim] = power(fact[lim], MOD - 2);
        for (int i = lim; i >= 1; i--) inv_fact[i - 1] = inv_fact[i] * i % MOD;

        int k = min(n, x);
        // 第二类斯特林数 S(i, j)：把 i 个表演者划分成 j 个非空组
        vector<long long> S(k + 1, 0);
        S[0] = 1;
        for (int i = 1; i <= n; i++) {
            for (int j = min(i, k); j >= 1; j--) {      // 必须倒序
                S[j] = (S[j - 1] + (long long)j * S[j]) % MOD;
            }
            S[0] = 0;
        }

        long long ans = 0, ypow = 1;
        for (int j = 1; j <= k; j++) {
            ypow = ypow * y % MOD;
            long long choose = fact[x] * inv_fact[j] % MOD * inv_fact[x - j] % MOD;
            long long onto = S[j] * fact[j] % MOD;      // j! * S(n, j)
            ans = (ans + choose * onto % MOD * ypow) % MOD;
        }
        return (int)ans;
    }
};
```

### Python

```python
MOD = 10**9 + 7

class Solution:
    def numberOfWays(self, n: int, x: int, y: int) -> int:
        lim = max(n, x)
        fact = [1] * (lim + 1)
        for i in range(1, lim + 1):
            fact[i] = fact[i - 1] * i % MOD
        inv_fact = [1] * (lim + 1)
        inv_fact[lim] = pow(fact[lim], MOD - 2, MOD)
        for i in range(lim, 0, -1):
            inv_fact[i - 1] = inv_fact[i] * i % MOD

        k = min(n, x)
        # 第二类斯特林数 S(i, j)：i 个表演者划分成 j 个非空组
        S = [0] * (k + 1)
        S[0] = 1
        for i in range(1, n + 1):
            for j in range(min(i, k), 0, -1):       # 必须倒序
                S[j] = (S[j - 1] + j * S[j]) % MOD
            S[0] = 0

        ans = 0
        ypow = 1
        for j in range(1, k + 1):
            ypow = ypow * y % MOD
            choose = fact[x] * inv_fact[j] % MOD * inv_fact[x - j] % MOD
            onto = S[j] * fact[j] % MOD             # j! * S(n, j)
            ans = (ans + choose * onto % MOD * ypow) % MOD
        return ans
```

## 8. 边界情况与易错点

1. **$n = 1$**：只有一个非空节目（$j = 1$），答案为 $x \cdot y$，示例 1 即 $2 \times 3 = 6$。检查 $j$ 从 1 起，别把 $j = 0$ 算进去（那会多算「没人」的伪方案）。
2. **$y = 1$**：所有 $y^j = 1$，答案退化为 $x^n$（示例 2 的 $2^5 = 32$），可作为自测。
3. **$x > n$**：非空节目数受人数限制，$j$ 上界必须是 $\min(n, x)$，否则 $\binom{x}{j}$ 会把「人数不够满射」的项算进来（此时 $S(n,j)=0$，虽不出错但要多循环）。
4. **斯特林递推必须倒序**：正序更新会把本层的 $S[j-1]$ 当成上层的值，结果偏大。用 $n=3$ 自测：正确 $S(3,2)=3$。
5. **`S[0]` 每轮清零**：忘记清零会让 $S(0)$ 一直保留 $1$，进而污染 $j=1$ 的项。
6. **组合数用逆元**：不要用浮点除法或 `math.comb` 直接取模（后者在 $n = 1000$ 时数值巨大但 Python 大整数其实可行；C++ 必须用逆元）。Python 版也可以写 `comb(x, j) % MOD`，但统一用阶乘更一致。
7. **取模溢出**：C++ 里 `choose * onto % MOD * ypow` 中前两项已取模，乘积不超过 $10^{18}$，`long long` 安全；不要写成连续的三个 `long long` 连乘后再取模。
8. **空节目的处理**：题目规定空节目不打分。上面的分类中 $A$ 是全部非空节目的集合，$A$ 之外自动为空且无分数，不会漏也不会多。
