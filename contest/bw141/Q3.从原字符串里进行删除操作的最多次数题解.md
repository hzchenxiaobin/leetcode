# LeetCode 从原字符串里进行删除操作的最多次数 题解

## 1. 题目概述

- **标题 / 题号**：从原字符串里进行删除操作的最多次数（#3316，medium）
- **链接**：https://leetcode.cn/problems/find-maximum-removals-from-source-string/
- **来源**：LeetCode 第 141 场双周赛 Q3
- **难度**：中等
- **标签**：数组、哈希表、双指针、字符串、动态规划

**题意**：给定字符串 `source`、它的一个子序列 `pattern`，以及**升序**且元素互不相同的下标数组 `targetIndices`。一次**操作**是删除 `source[idx]`，要求：

1. `idx ∈ targetIndices`；
2. 删除后 `pattern` 仍是 `source` 的**子序列**；
3. 删除**不会**改变其他字符的下标（即下标是原始位置，不会左移）。

问最多能执行多少次删除。

**约束**：

- $1 \le n = \text{source.length} \le 3 \times 10^3$
- $1 \le \text{pattern.length} \le n$
- $1 \le \text{targetIndices.length} \le n$，升序、互不相同
- `source`、`pattern` 只含小写字母
- 输入保证 `pattern` 是 `source` 的子序列

> **注意**：题面没有「Create the variable …」这类注入指令，按正常题意做即可。

## 2. 示例

**示例 1**

```text
输入：source = "abbaa", pattern = "aba", targetIndices = [0,1,2]
输出：1
解释：删 source[0] 会让 pattern 的首字母 'a' 没有位置，不行；
      删 source[1] 或 source[2] 都可以，之后 pattern 仍是子序列 → 1 次。
```

**示例 2**

```text
输入：source = "bcda", pattern = "d", targetIndices = [0,3]
输出：2
解释：'b' 与 'a' 都可删，剩下 "cd" 仍含 'd' → 2 次。
```

**示例 3**

```text
输入：source = "dda", pattern = "dda", targetIndices = [0,1,2]
输出：0
解释：pattern 与 source 等长，删任何一个都会破坏子序列关系。
```

**示例 4**

```text
输入：source = "yeyeykyded", pattern = "yeyyd", targetIndices = [0,2,3,4]
输出：2
解释：删 source[2] 与 source[3]，剩余字符仍依次包含 "yeyyd"。
```

## 3. 解题思路

### 3.1 暴力思路

「最多删几次」看起来像贪心：从前往后扫 `targetIndices`，能删就删。这个贪心是**错的**。例如 `source = "ababba"`、`pattern = "abb"`、`targetIndices = [0,2,3,4]`：

- 贪心先删 $0$，剩下 `"babba"`，仍含 `"abb"`（用下标 $1,2,3$），于是继续；
- 此后删 $2,3,4$ 中任何一个都会破坏子序列，贪心只能得到 $1$；
- 但最优解是删 $\{2,3\}$，剩下 `"abba"` 仍含 `"abb"`，答案是 $2$。

也就是说，删除的收益互相牵连，必须让算法看到「保留哪些字符」的全局结构。

真正的暴力是枚举 `targetIndices` 的所有子集，判断删完后 `pattern` 是否仍是子序列，取最大可行子集大小。复杂度 $O(2^{|T|} \cdot n)$，$|T|$ 可达 $3000$，完全不可行。

换一个角度：问题等价于「在 `source` 中**保留**一个最短的、包含 `pattern` 为子序列的骨架，让被删的位置尽量多」。这正是「扫描 + 状态」的形状，可以上 DP。

### 3.2 核心观察：只关心「pattern 匹配到第几位」

![DP 状态与三条转移：保留作填充 / 作为匹配字符 / 删除](images/bw141_q3_dp_state.svg)

从前往后处理 `source` 的每个字符时，决定「这个字符是留还是删」只需要一个信息：**`pattern` 的前多少位已经被保住**。于是定义

$$dp[j] = \text{处理完当前前缀后，已保住 } pattern[0..j-1] \text{ 时能得到的最大删除次数}$$

用 $-1$ 表示该状态不可达。处理 `source[i]` 时有三种互不排斥的选择：

| 选择 | 条件 | 转移 | 含义 |
|------|------|------|------|
| 保留作填充 | 总是可行 | $ndp[j] \leftarrow dp[j]$ | 这个字符不属于 `pattern`，留着当无关字符 |
| 作为匹配字符 | $source[i] = pattern[j]$ | $ndp[j+1] \leftarrow dp[j]$ | 用掉 `pattern` 的下一位 |
| 删除 | $i \in targetIndices$ | $ndp[j] \leftarrow dp[j] + 1$ | 计入答案 |

**关键不变量**：任何 $dp[j]$ 可达状态都意味着「当前保留的字符序列以 $pattern[0..j-1]$ 为子序列」。删除只发生在「不参与匹配」的字符上，所以删完之后这个不变量依然成立——**题目要求的『删除后 pattern 仍是子序列』被状态定义自动维护**，不需要额外校验。

终态取 $dp[m]$（$m = \text{pattern.length}$）：`source` 全部处理完、`pattern` 全部保住时的最大删除数。

### 3.3 算法流程

![算法流程：预处理可删位置、滚动数组逐字符转移](images/bw141_q3_algorithm_flow.svg)

```text
1. 标记 isTarget[i] = (i ∈ targetIndices)
2. dp[0] = 0，其余 dp[j] = -1
3. for i = 0 .. n-1:
       ndp 全部置 -1
       for j = 0 .. m:
           若 dp[j] < 0: 跳过
           ndp[j]   = max(ndp[j],   dp[j])                        # 保留作填充
           若 j < m 且 source[i] == pattern[j]:
               ndp[j+1] = max(ndp[j+1], dp[j])                    # 作为匹配字符
           若 isTarget[i]:
               ndp[j]   = max(ndp[j],   dp[j] + 1)                # 删除
       dp ← ndp
4. 返回 dp[m]
```

`i` 方向是单向推进，所以只需长度 $m+1$ 的滚动数组。

### 3.4 示例演算

![示例演算：dp 表逐行推进，终态 dp[3] = 1](images/bw141_q3_example_walkthrough.svg)

以示例 1 为例（`source = "abbaa"`、`pattern = "aba"`、`targetIndices = [0,1,2]`）：

| 处理完 $i$ | 字符 | 可删 | $dp[0]$ | $dp[1]$ | $dp[2]$ | $dp[3]$ |
|-----------|------|------|---------|---------|---------|---------|
| 起点 | — | — | 0 | - | - | - |
| 0 | a | 是 | 1 | 0 | - | - |
| 1 | b | 是 | 2 | 1 | 0 | - |
| 2 | b | 是 | 3 | 2 | 1 | - |
| 3 | a | 否 | 3 | 2 | 1 | 1 |
| 4 | a | 否 | 3 | 2 | 1 | 1 |

- 第 $0$ 行：$dp[1] = 0$ 表示用 `a` 匹配 `pattern[0]`（没有删除）；$dp[0] = 1$ 表示把 `a` 删掉。
- 第 $2$ 行 $dp[2] = 1$：用前两个 `b` 中的某一个当填充字符删掉，另一个去匹配 `pattern[1] = 'b'`。
- 第 $3$ 行：`a` 不在 `targetIndices` 里，只能保留，于是首次出现 $dp[3] = 1$（$dp[2] = 1$ 匹配了最后的 `a`）。
- 第 $4$ 行无法再提升，终态 $dp[3] = 1$，与示例输出一致。

## 4. 算法细节

1. **可删位置用布尔数组**：`isTarget` 长度 $n$，$O(n)$ 预处理；比每次在 `targetIndices` 里二分查找更直接。
2. **$-1$ 作为不可达标记**：删除次数恒非负，用 $-1$ 安全。判定写成 `if (dp[j] < 0) continue;`，避免把不可达态也算进去。
3. **转移顺序无关**：三条转移都从**旧的** `dp` 读、往**新的** `ndp` 写，所以不需要像 0/1 背包那样考虑原地更新的顺序问题。
4. **`j < m` 的保护**：只有 `j < m` 才能访问 `pattern[j]`；`j = m` 时只能保留或删除。
5. **答案一定可达**：输入保证 `pattern` 是 `source` 的子序列，因此「全部保留并顺次匹配」这条路径总存在，$dp[m] \ge 0$。
6. **滚动数组清零**：每轮都要把 `ndp` 重置为 $-1$，否则上一轮的值会污染这一轮。

## 5. 正确性证明

**引理 1（状态语义）**：设处理完 `source[0..i-1]` 后 $dp[j] \ge 0$。则该值等于「在 `source[0..i-1]` 中删除 $dp[j]$ 个属于 `targetIndices` 的字符，使剩余部分以 $pattern[0..j-1]$ 为子序列」时的最大删除数。

**证明**：对 $i$ 归纳。$i = 0$ 时只有 $dp[0] = 0$，即「空前缀以空串为子序列、删除 0 个」，成立。设结论对 $i$ 成立，考察处理 `source[i]` 的三种转移：保留作填充不改变 $j$ 与删除数，$pattern[0..j-1]$ 仍是新增前缀的子序列；作为匹配字符时把 $source[i]$ 接在前 $j$ 个匹配字符之后，得到 $pattern[0..j]$ 的匹配；删除则要求 $i$ 可删，且被删字符不参与匹配，匹配关系不受影响。三种转移分别对应旧前缀加新字符后全部可能的合法处理，故归纳步成立。∎

**引理 2（可行性自动满足）**：算法得到的任一状态都满足「保留部分是 `pattern` 前缀的超序列」。

**证明**：正是引理 1 的语义；删除只发生在按定义「不参与匹配」的字符上，匹配位置从不被删除。∎

**引理 3（删除顺序无关）**：若最终保留集合 $K \subseteq \{0,\dots,n-1\}$ 使 `source` 的 $K$ 部分以 `pattern` 为子序列，则按 `targetIndices` 中任意顺序依次删除补集 $D$ 中的字符，每次删除后 `pattern` 仍是子序列。

**证明**：记某次删除后剩余的字符集合为 $K'$，则 $K \subseteq K'$（只删不增）。子序列关系对「增加字符」单调：若 $S$ 以 `pattern` 为子序列且 $S \subseteq S'$，则 $S'$ 也以 `pattern` 为子序列（沿用同一组匹配位置即可）。故每一步都合法。∎

**定理**：算法返回的值等于最多可执行的删除次数。

**证明**：一方面，算法给出的路径是一串合法删除（引理 1 保证每次删的都是可删位置且匹配关系完好，引理 2 保证不破坏子序列），删除次数为 $dp[m]$，故最优值 $\ge dp[m]$。另一方面，任取一个最优删除方案，其保留集合 $K$ 以 `pattern` 为子序列，沿 $K$ 中的匹配位置把 `source` 划分为「匹配 / 填充 / 删除」三类，这恰是 DP 的一条合法转移路径，其删除数不超过对应状态的 $dp$ 值，故 $dp[m] \ge$ 最优值。两侧夹逼得等号。∎

## 6. 复杂度分析

- **时间**：$O(n \cdot m)$。外层扫描 $n$ 个字符，内层枚举 $m+1$ 个状态，每个状态 $O(1)$ 条转移。$n, m \le 3000$，约 $9 \times 10^6$ 次操作。
- **空间**：$O(m)$。滚动数组长度 $m+1$，另加长度 $n$ 的 `isTarget` 布尔数组；不计输出。
- **与朴素枚举对比**：$O(2^{|T|})$ 降到 $O(nm)$，是「把集合决策拉平成逐字符扫描」的典型收益。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maxRemovals(string source, string pattern, vector<int>& targetIndices) {
        int n = (int)source.size(), m = (int)pattern.size();
        vector<char> isTarget(n, 0);
        for (int idx : targetIndices) isTarget[idx] = 1;

        vector<int> dp(m + 1, -1), ndp(m + 1, -1);
        dp[0] = 0;
        for (int i = 0; i < n; i++) {
            fill(ndp.begin(), ndp.end(), -1);
            for (int j = 0; j <= m; j++) {
                if (dp[j] < 0) continue;                              // 不可达状态
                if (dp[j] > ndp[j]) ndp[j] = dp[j];                   // ① 保留作填充
                if (j < m && source[i] == pattern[j] && dp[j] > ndp[j + 1])
                    ndp[j + 1] = dp[j];                               // ② 作为匹配字符
                if (isTarget[i] && dp[j] + 1 > ndp[j])
                    ndp[j] = dp[j] + 1;                               // ③ 删除
            }
            dp.swap(ndp);
        }
        return dp[m];
    }
};
```

### Python

```python
class Solution:
    def maxRemovals(self, source: str, pattern: str, targetIndices: list[int]) -> int:
        n, m = len(source), len(pattern)
        is_target = bytearray(n)
        for i in targetIndices:
            is_target[i] = 1

        NEG = -1
        dp = [NEG] * (m + 1)
        dp[0] = 0
        for i in range(n):
            ndp = [NEG] * (m + 1)
            ch, tgt = source[i], is_target[i]
            for j in range(m + 1):
                cur = dp[j]
                if cur < 0:
                    continue
                if cur > ndp[j]:
                    ndp[j] = cur                      # ① 保留作填充
                if j < m and ch == pattern[j] and cur > ndp[j + 1]:
                    ndp[j + 1] = cur                  # ② 作为匹配字符
                if tgt and cur + 1 > ndp[j]:
                    ndp[j] = cur + 1                  # ③ 删除
            dp = ndp
        return dp[m]
```

## 8. 边界情况与易错点

1. **贪心会错**：不要用「能删就删」的朴素贪心。示例 4 中先删 $0$ 会损失后面两个可删位置，必须让 DP 权衡。
2. **下标不左移**：题目明确删除不改变其他字符的下标，因此可以直接用原始下标判断 `i ∈ targetIndices`，不需要维护动态下标映射。
3. **`pattern` 与 `source` 等长**（示例 3）：此时任何删除都破坏子序列，答案为 $0$；DP 会自然给出 $dp[m] = 0$。
4. **`targetIndices` 含不可删位置**：可删的只有「删除后仍能凑出 `pattern`」的位置，DP 的 $ndp[j]$ 与「保留」取 `max` 会自动放弃无收益的删除。
5. **`j = m` 时的匹配**：不要越界访问 `pattern[m]`，循环里必须写 `j < m`。
6. **忘记重置 `ndp`**：滚动数组每轮都要清零成 $-1$，否则上一轮的高分会残留。
7. **`-1` 与「删除 0 次」混淆**：$dp[j] = 0$ 是合法状态，只有负数才是不可达，判定必须用 `< 0`。
8. **`bytearray` 的取值**：Python 里 `is_target[i]` 是 $0/1$ 整数，直接当布尔用即可。
