# LeetCode 收集树中金币 题解

## 1. 题目概述

- **标题 / 题号**：收集树中金币（#2603，hard）
- **链接**：https://leetcode.cn/problems/collect-coins-in-a-tree/
- **来源**：LeetCode 第 338 场周赛 Q4
- **难度**：困难
- **标签**：树、拓扑排序（剥叶）、图、广度优先搜索

**题意**：给定一棵 $n$ 个节点的**无向无根树**（节点编号 $0$ 到 $n-1$，`edges` 长度 $n-1$）和长度为 $n$ 的数组 `coins`，`coins[i] = 1` 表示节点 $i$ 处有一个金币。从**任意节点**出发，可以重复执行两种操作：

- **收集**：收集距离当前节点 $\le 2$ 的所有金币（不花边数，自动生效）；
- **移动**：移动到相邻节点，每经过一条边，答案 +1。

要求**收集所有金币并回到出发节点**，返回最少经过的边数（同一条边多次经过，每次都计数）。

**约束**：

- `n == coins.length`
- `1 <= n <= 3 * 10^4`
- `0 <= coins[i] <= 1`
- `edges.length == n - 1`，`edges` 表示一棵合法的树

## 2. 示例

```text
输出：2
解释：树是链 0-1-2-3-4-5，金币在两端。从节点 2 出发即可收 0 的金币（距离 2），
      走到 3 即可收 5 的金币（距离 2），再走回 2，共 2 条边。
```

## 3. 解题思路

### 3.1 暴力思路

「回到出发节点」的闭合游走可以用状态 `(当前节点, 已收集金币集合)` 做 BFS：站在某节点时，距离 $\le 2$ 的金币**自动**落入集合（收集不花钱、不可撤销，所以集合由踏足历史唯一决定），转移只有"移到相邻节点"。从每个出发节点各跑一遍、直到集合取满且回到起点，状态数 $O(n \cdot 2^n)$，$n \le 3 \times 10^4$ 直接爆炸。

瓶颈在于把「走法」当搜索对象。换个视角：**收集是自动的，移动才花钱**——真正决定答案的只有「哪些节点被踏足过」。设闭合游走的踏足集为 $S$：

- $S$ 必须在树上**导出连通子图**（相邻移动），且**每个金币到 $S$ 中某点距离 $\le 2$**（否则收不到）；
- 在树上踏遍 $S$ 并回到起点，每条被使用的边**至少走两次**（进入子树必须原路退出），按深度优先的「一去一回」恰好两次，故最优代价 $= 2 \times |E(S)| = 2(|S|-1)$。

于是问题改写为：**求最小的连通踏足集 $S$，使每个金币距 $S$ 不超过 2**。$S$ 的最优结构可以由三个观察完全刻画。

### 3.2 核心观察：两次剥叶

![两次剥叶：删无币枝 → 剥带币叶外两层 → 剩余核心每边走两次](images/wc338_q4_prune_concept.svg)

**观察 1（无币枝整枝剪掉）**：一个**不带金币的叶子**，走到它再原路返回纯亏 2 条边；更一般地，任何**不含金币的悬挂子树**整体都不必进入——它内部没有目标，而站在挂接点上能覆盖它原本能覆盖的所有金币（§5 引理 1 的交换论证）。于是**阶段①：反复删无币叶（级联）**，删到剩余树的叶子全部带币为止。

**观察 2（收集半径 2 ⇒ 外两层免走）**：删完无币叶后，叶子全都带币。站在某点能收距离 $\le 2$ 的金币，所以**带币叶子的最后两层不必亲自踏足**——站到它的「祖父」处即可收到。于是**阶段②：不再看金币，把叶子快照式地剥掉恰好两层**（第 1 层 = 当前的带币叶，第 2 层 = 删掉它们后新暴露的叶）。

**观察 3（核心每边恰走两次）**：两次剥叶后剩下的「核心」，其每条边**任何方案都必须跨过**（§5 引理 2 给出下界），而踏遍一棵树回到起点，每条边恰好一去一回。故

$$\text{答案} = 2 \times \text{核心边数}$$

> 💡 一句话：**能不走的边都不走，剩下的边都走两遍**。两个剥离参数各司其职——「无币」决定**要不要**剪（级联，剪到不能剪），「距离 2」决定**剪多深**（恰好两层，不级联）。

### 3.3 算法流程

![算法流程：阶段①级联剥无币叶，阶段②快照剥两层，度数和即答案](images/wc338_q4_algorithm_flow.svg)

1. **建图**：邻接表 + 度数组 `deg`（无向边两端各 +1）。
2. **阶段①（级联删无币叶）**：把所有「度 $=1$ 且无币」的节点入队；每弹出一个就标记删除、给存活邻居 `deg−1`，邻居若因此变成新的无币叶则继续入队——拓扑排序式剥到队空。
3. **阶段②（快照剥两层，不级联）**：重复 2 次：**先快照**当前所有「存活且度 $=1$」的叶子，**再统一删除**并给存活邻居 `deg−1`；本轮新暴露的叶子留给下一轮。
4. **统计**：答案 $=$ 存活节点的度数之和——每条存活边在两端各计 1 次度，故度数和恰为 $2 \times$ 剩余边数。

### 3.4 示例演算

![示例 2 演算：三阶段剥叶后只剩 0-2 一条边，答案 2](images/wc338_q4_example_walkthrough.svg)

以**示例 2**（金币在 3、4、7）为例：

- **阶段①**：叶子有 3、4（带币）、6（无币）、7（带币）。删 6；删后 5 的度 $3 \to 2$，不再是叶。此时所有叶子都带币，停止。
- **阶段② 第 1 轮**：快照删除叶子 3、4、7。剩边 1-0、0-2、2-5，新叶为 1、5。
- **阶段② 第 2 轮**：快照删除新叶 1、5。只剩 **0—2** 一条边。
- **答案**：剩余边数 $=1$，$2 \times 1 = 2$ ✓

示例 1（链 0-1-2-3-4-5，两端带币）：阶段① 无可删；第 1 轮删 0、5，第 2 轮删 1、4，剩 2—3 一条边，答案 $2$ ✓。示例 3（星形全币）：第 1 轮删 4 个叶子后中心变孤立点（度 0），第 2 轮无叶可删，剩余边数 $0$，答案 $0$ ✓。

## 4. 算法细节

1. **两阶段的删除判据不同**：阶段①是「无币**且**度 $=1$」且要**级联**（删出新无币叶就继续删）；阶段②只看度 $=1$，**不级联、恰好两轮**——每轮先快照再删，防止「删一个、暴露一个、当轮继续删」把两层并成一层。这是本题最大的 WA 来源。
2. **删除即减度**：不真正维护剩余图，只用 `deg` 数组 + `deleted` 标记模拟；删除 $u$ 时遍历 `g[u]` 给存活邻居 `deg−1`。存活节点的 `deg` 始终等于它在剩余树中的真实度数。
3. **答案用度数和统计**：$\sum_{\text{存活 } v} \deg[v] = 2 \times \text{存活边数}$，求和后**直接就是答案**，天然规避「剩余 0/1 个节点时 $(|S|-1)$ 为 0 或负」的特判。
4. **队列无重复**：节点只在「度数**首次**降为 1 且无币」时入队一次（度数单调不增，条件至多成立一次），无需额外的入队标记。
5. **阶段②的孤立点**：某轮删完若只剩一个度 $=0$ 的点（如示例 3 的中心），它不会再被删（判据是度 $=1$），也无需删——它不计入任何边，答案自动为 $0$。

## 5. 正确性证明

记 $T$ 为原树，$T_1$ 为**反复删无币叶后**的树，$T_2$ 为对 $T_1$ **再快照剥两层叶后**的存活节点集（「核心」）。称节点集 $S$ **可行**，若 $S$ 非空、在树上导出连通子图、且每个金币到 $S$ 中某点距离 $\le 2$。不妨设至少存在一个金币（否则答案显然为 0，算法给出的剩余边数也为 0）。

**引理 0（建模）**：最少代价 $= \min\{2(|S|-1) : S \text{ 可行}\}$。

**证明**：任取合法闭合游走，其踏足集可行（相邻步保证导出连通；金币覆盖由收集规则保证），且踏足边构成踏足集的连通生成子图；树上闭合游走每穿过一条边就切换一次该边两侧，回到起点必须切回来，故每条踏足边经过偶数次且 $\ge 2$，代价 $\ge 2(|S|-1)$。反之，对可行 $S$，沿其生成树做深度优先的往返游走，代价恰为 $2(|S|-1)$ 且合法。两边夹逼。∎

**引理 1（无币枝剪除）**：设 $B$ 是 $T$ 中不含金币的极大连通子树，与树其余部分只通过节点 $r \notin B$ 相连。则任何可行 $S$ 对应的 $S' = (S \setminus B) \cup \{r\}$ 仍可行，且 $|E(S')| \le |E(S)|$。

**证明**：若 $S \cap B = \varnothing$ 则取 $S' = S$。否则**覆盖**：任取金币 $c$ 与 $x \in S \cap B$ 使 $\text{dist}(c,x) \le 2$。$B$ 无金币故 $c \notin B$，而 $x$ 到 $c$ 的路径必经唯一挂接点 $r$，于是 $\text{dist}(c,r) = \text{dist}(c,x) - \text{dist}(x,r) \le 2 - 1 = 1$，即 $r$ 一个点就能覆盖 $B$ 内所有点的收集能力。**连通**：若 $S \subseteq B$，则 $S' = \{r\}$；若 $S$ 有 $B$ 外的点，任取 $s \in S \setminus B$ 与 $x \in S \cap B$，树上路径 $s \to x$ 必经 $r$，由 $S$ 导出连通知 $r \in S$；再任取 $s', t' \in S'$，路径 $s' \to t'$（含于 $S$）若进入 $B$ 则必须经 $r$ 进、经 $r$ 出，与树路径不重复节点矛盾，故该路径避开 $B$、含于 $S'$。又 $S' \subseteq S \cup \{r\}$，边数不增。∎

**推论 1**：存在最优解的踏足集 $\subseteq V(T_1)$；且「反复删无币叶」的终态唯一，恰为**所有金币的最小连通子树（Steiner 树）**，其叶子全部带币。

**证明要点**：归纳维护「当前树 $\supseteq$ Steiner 树」。归纳步：设要删的是当前无币叶 $u$，若 $u \in$ Steiner 树，则由不变量，$u$ 的 Steiner 邻居都是当前邻居——若 $u$ 是 Steiner 内点（$\ge 2$ 个 Steiner 邻居）它就不是当前叶，矛盾；若 $u$ 是 Steiner 叶子则必带币（否则去掉它仍是包含全部金币的更小连通子树，与最小性矛盾），与 $u$ 无币矛盾。故被删点 $\notin$ Steiner 树，不变量保持。反向，若当前树真包含 Steiner 树之外的点，取其中距 Steiner 树最远者 $y$：$y$ 无币（金币都在 Steiner 树内），其当前邻居中距 Steiner 更远者不存在（与最远矛盾），故 $y$ 恰有一个更近的邻居、是当前无币叶，仍可删。于是过程恰终止于 Steiner 树。∎

**引理 2（必经边，下界）**：对任何可行 $S \subseteq V(T_1)$，都有 $E(T_2) \subseteq E(S)$（$S$ 在 $T_1$ 上导出子图的边集）。

**证明**：分三步。

(i) **核心边的刻画**：边 $e = (u,v) \in E(T_2)$ $\iff$ 删掉 $e$ 后 $u$ 侧与 $v$ 侧**各有一个到 $e$ 距离 $\ge 2$ 的节点**。这是因为：$e$ 存活 $\iff$ $u, v$ 都存活两轮 $\iff$ $u, v$ 各有至少 2 个「第 1 轮存活」的邻居——后一个等价号：$u$ 不被第 1 轮删即 $u$ 非 $T_1$ 的叶；$u$ 不被第 2 轮删即第 1 轮后度数 $\ne 1$，而 $v$ 就是它的一个第 1 轮存活邻居（度 $\ge 1$），故等价于第 1 轮存活邻居数 $\ge 2$——再由「$w$ 第 1 轮存活 $\iff w$ 非 $T_1$ 的叶 $\iff w$ 在 $u$ 同侧另有邻居」互译成两侧距离 $\ge 2$ 的节点。

(ii) **两侧各有一个"远处带币叶"**：设删 $e$ 后两侧 $A \ni u$、$B \ni v$。由 (i)，$B$ 中存在到 $v$ 距离 $\ge 2$ 的节点；取 $B$ 中距 $v$ 最远的 $y$，则 $y$ 的所有邻居都更近（否则存在更远节点，与最远矛盾），故 $y$ 恰有一个邻居，是 $T_1$ 的叶子，**带币**（推论 1）。而 $A$ 中任一点 $a$ 满足 $\text{dist}(a, y) = \text{dist}(a,u) + 1 + \text{dist}(v,y) \ge 3 > 2$，即**站在 $A$ 侧收不到 $y$ 的币**。对称地，$A$ 侧也有一个 $B$ 侧收不到的带币叶。

(iii) **合并**：可行 $S$ 必须与 $A$、$B$ 同时相交（否则 (ii) 中那个币无人覆盖）；$S$ 导出连通，其中必有路径从 $A$ 侧跨到 $B$ 侧，而树上横跨两侧的边只有 $e$，故 $e \in E(S)$。∎

**引理 3（可达性，上界）**：$2|E(T_2)|$ 总能取到。

**证明**：若 $T_2 \ne \varnothing$：对任意金币 $c$ 分类——$c \in T_2$ 则距离 0；$c$ 被第 1 轮删（即 $T_1$ 的带币叶 $L$）：其父 $p(L)$ 不可能在第 1 轮被删（否则 $p(L)$ 也是 $T_1$ 的叶，$T_1$ 退化为单边、$T_2 = \varnothing$，与前提矛盾），故 $p(L)$ 若存活则距离 1；若 $p(L)$ 恰在第 2 轮被删，则它恰有一个第 1 轮存活的邻居 $q$，$q$ 存活时距离为 2，$q$ 也被第 2 轮删时 $p(L)$-$q$ 是第 1 轮后的孤立边（两端的第 1 轮存活邻居互为彼此），从而 $T_1$ 只剩这条边加两端悬挂的叶子，$T_2 = \varnothing$，与前提矛盾；$c$ 被第 2 轮删（$T_1$ 内点）：同理其唯一第 1 轮存活邻居要么在 $T_2$ 中（距离 1），要么导出孤立边、$T_2 = \varnothing$ 矛盾。故每个金币距 $T_2$ 不超过 2，从 $T_2$ 任一节点出发沿核心的边做深度优先往返即合法，代价 $2|E(T_2)|$。若 $T_2 = \varnothing$：第 1 轮后的剩余要么为空（$T_1$ 是单边），要么全由度为 1 的点组成，由 $T_1$ 连通知它是**一条孤立边** $\{p,q\}$（两个存活分支之间的路径必经已删叶子作中间点，而叶子不能做路径中间点），即 $T_1$ 是「双星」：$p$、$q$ 相连、各自挂若干带币叶。站在 $p$（或 $q$）：己侧叶子距离 1，对侧叶子距离 2，原地不动即合法，代价 $0 = 2|E(T_2)|$。∎

**定理**：最少经过的边数 $= 2 \times |E(T_2)|$。

**证明**：下界——任取合法游走，设其踏足集为 $S_W$。由引理 1，把 $S_W$ 中落入无币枝的节点逐个换成挂接点后得到的 $S'$ 是 $\subseteq V(T_1)$ 的可行集，且 $|E(S')| \le |E(S_W)|$；由引理 0，游走代价 $\ge 2|E(S_W)| \ge 2|E(S')|$；由引理 2，$|E(S')| \ge |E(T_2)|$，故代价 $\ge 2|E(T_2)|$。上界——引理 3 直接给出代价为 $2|E(T_2)|$ 的合法游走。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。建图 $O(n)$；阶段①每个节点至多入队删除一次、每条边至多被两端各扫常数次；阶段②两轮各做一次度数数组的线性扫描；统计求和一次线性扫描。
- **空间复杂度**：$O(n)$。邻接表、度数组、删除标记与队列均为线性；不计输入的 `edges`。

$n \le 3 \times 10^4$ 下远低于时限，本题也几乎不存在卡常空间。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int collectTheCoins(vector<int>& coins, vector<vector<int>>& edges) {
        int n = coins.size();
        vector<vector<int>> g(n);
        vector<int> deg(n);
        for (auto& e : edges) {
            g[e[0]].push_back(e[1]);
            g[e[1]].push_back(e[0]);
            deg[e[0]]++;
            deg[e[1]]++;
        }
        vector<char> deleted(n, 0);

        // 阶段①：级联删无币叶（拓扑剥到叶子全带币）
        queue<int> q;
        for (int i = 0; i < n; i++)
            if (deg[i] == 1 && coins[i] == 0) q.push(i);
        while (!q.empty()) {
            int u = q.front(); q.pop();
            deleted[u] = 1;
            for (int v : g[u]) {
                if (deleted[v]) continue;
                if (--deg[v] == 1 && coins[v] == 0) q.push(v);
            }
        }

        // 阶段②：快照剥两层叶（收集半径 2）
        for (int round = 0; round < 2; round++) {
            vector<int> leaf;
            for (int i = 0; i < n; i++)
                if (!deleted[i] && deg[i] == 1) leaf.push_back(i);
            for (int u : leaf) {
                deleted[u] = 1;
                for (int v : g[u])
                    if (!deleted[v]) deg[v]--;
            }
        }

        // 答案 = 存活节点的度数之和 = 2 × 剩余边数
        int ans = 0;
        for (int i = 0; i < n; i++)
            if (!deleted[i]) ans += deg[i];
        return ans;
    }
};
```

### Python

```python
from collections import deque
from typing import List

class Solution:
    def collectTheCoins(self, coins: List[int], edges: List[List[int]]) -> int:
        n = len(coins)
        g = [[] for _ in range(n)]
        deg = [0] * n
        for a, b in edges:
            g[a].append(b)
            g[b].append(a)
            deg[a] += 1
            deg[b] += 1
        deleted = [False] * n

        # 阶段①：级联删无币叶
        q = deque(i for i in range(n) if deg[i] == 1 and coins[i] == 0)
        while q:
            u = q.popleft()
            deleted[u] = True
            for v in g[u]:
                if deleted[v]:
                    continue
                deg[v] -= 1
                if deg[v] == 1 and coins[v] == 0:
                    q.append(v)

        # 阶段②：快照剥两层叶
        for _ in range(2):
            leaf = [i for i in range(n) if not deleted[i] and deg[i] == 1]
            for u in leaf:
                deleted[u] = True
                for v in g[u]:
                    if not deleted[v]:
                        deg[v] -= 1

        # 答案 = 存活节点度数之和 = 2 × 剩余边数
        return sum(deg[i] for i in range(n) if not deleted[i])
```

## 8. 边界情况与易错点

1. **快照删除（头号坑）**：阶段②每轮必须**先收集当前全部叶子、再统一删除**。若删一个就立刻把新暴露的叶并入本轮，两层并成一层，等价于多剥了一层，答案偏小。
2. **两阶段判据别混用**：阶段①「无币 + 级联到不能删」；阶段②「只看度数、恰好两轮、不级联」。把②误写成级联会一路删空，把①误写成不级联则删不干净无币枝。
3. **答案为 0 的一大类**：$n = 1$、无金币、金币距某个站点均 $\le 2$（星形、短链、双星等）。用度数和统计天然得 0；若改用 $(\text{剩余点数}-1) \times 2$，必须 `max(0, ...)` 防负数。
4. **第 1 轮后的孤立点**：星形树第 1 轮删完叶子后中心度数为 0，不再满足「度 $=1$」的删除判据——留着它无害（贡献 0 条边），无需特判。
5. **队列中节点度数可能已降为 0**：无币叶成对死亡时（如整棵树无金币），后弹出者的度已是 0，标记删除依然正确——它已无存活边。
6. **无向图建图**：邻接表与度数都要**双向**添加；漏加一端会让剥叶过程整体错乱。
7. **"回到出发节点"别漏**：核心每条边走两次正源于此。若题目改为**不必返回**，答案变为 $2 \times \text{核心边数} - \text{核心的直径}$（最后一段不必走回来）。
8. **数值范围**：答案上界 $2(n-1) \approx 6 \times 10^4$，`int` 足够；Python 无溢出问题。
