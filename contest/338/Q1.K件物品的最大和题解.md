# LeetCode K 件物品的最大和 题解

## 1. 题目概述

- **标题 / 题号**：K 件物品的最大和（#2600，easy）
- **链接**：https://leetcode.cn/problems/k-items-with-the-maximum-sum/
- **来源**：LeetCode 第 338 场周赛 Q1
- **难度**：简单
- **标签**：贪心、数学

**题意**：袋子里每件物品标着 `1`、`0` 或 `-1`，三种物品的件数分别为 `numOnes`、`numZeros`、`numNegOnes`。现要**恰好**选出 `k` 件物品，返回所有可行方案中物品上数字之和的最大值。

**约束**：

- `0 <= numOnes, numZeros, numNegOnes <= 50`
- `0 <= k <= numOnes + numZeros + numNegOnes`

## 2. 示例

**示例 1**

```text
输入：numOnes = 3, numZeros = 2, numNegOnes = 0, k = 2
输出：2
解释：物品为 {1, 1, 1, 0, 0}，选 2 件标 1 的物品，数字之和为 2。
```

**示例 2**

```text
输入：numOnes = 3, numZeros = 2, numNegOnes = 0, k = 4
输出：3
解释：选 3 件标 1 的物品 + 1 件标 0 的物品，数字之和为 3。
```

**示例 3（自拟，覆盖被迫拿负数）**

```text
输入：numOnes = 2, numZeros = 1, numNegOnes = 3, k = 5
输出：0
解释：物品为 {1, 1, 0, -1, -1, -1}，恰好选 5 件：两个 1（+2）、一个 0（+0）、
     两个 -1（−2），和为 0，即最大值。
```

## 3. 解题思路

### 3.1 暴力思路

把所有物品展开成数组，降序排序后取前 $k$ 个求和，时间 $O(n \log n)$（$n = \text{numOnes} + \text{numZeros} + \text{numNegOnes} \le 150$）。数据范围下必然能过，但三种物品的**件数是直接给出的计数**，逐件展开与排序都在做无用功——签到题的正确姿势是直接由计数算出答案。

### 3.2 核心观察：按价值降序贪心选取

![贪心选取与累积和](images/k_items_max_sum_greedy.svg)

**关键观察**：每件物品对总和的贡献只有三种：$+1$、$0$、$-1$。要让 $k$ 件物品之和最大，等价于：

- **优先拿 1**：每件使和 $+1$；
- 1 不够时**拿 0 补数**：和不变，但"白嫖"了件数；
- 只有当 $k$ 超过 $\text{numOnes} + \text{numZeros}$ 时，才**被迫拿 −1**：每件使和 $-1$。

把物品按价值降序排成一排、从左往右拿 $t$ 件时的累积和 $f(t)$ 呈"先升 → 平台 → 下降"的上凸形状：上升段对应拿 1，平台段对应 1 拿完、0 补数，下降段对应被迫拿 −1。

> 💡 本质是"从多重集合中选恰好 $k$ 个数使和最大"的**贪心模板**：值只有三类且值本身给定计数，贪心可以 $O(1)$ 完成而无需排序。

### 3.3 三种情况与统一公式

![k 的三种情况与统一公式](images/k_items_max_sum_cases.svg)

按 $k$ 与 $\text{numOnes}$、$\text{numOnes} + \text{numZeros}$ 的相对位置分三类：

| 情况 | $k$ 的位置 | 选法 | 答案 |
|------|-----------|------|------|
| ① | $k \le \text{numOnes}$ | 全选 1 | $k$ |
| ② | $\text{numOnes} < k \le \text{numOnes} + \text{numZeros}$ | 1 全拿 + 0 补齐 | $\text{numOnes}$ |
| ③ | $k > \text{numOnes} + \text{numZeros}$ | 1、0 全拿 + 被迫选 −1 | $2\,\text{numOnes} + \text{numZeros} - k$ |

三种情况可合并为一个**统一公式**：

$$\text{答案} = \min(k,\ \text{numOnes}) - \max(0,\ k - \text{numOnes} - \text{numZeros})$$

前一项是"最多能拿多少个 1"（贡献 $+1$），后一项是"被迫拿多少个 −1"（贡献 $-1$），0 不影响答案、只影响件数。

### 3.4 示例演算

以 $\text{numOnes}=3,\ \text{numZeros}=2,\ \text{numNegOnes}=2$ 为例，排序后物品为 $[1,1,1,0,0,-1,-1]$，累积和：

| $t$（已拿件数） | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|------|---|---|---|---|---|---|---|
| $f(t)$ | 1 | 2 | 3 | 3 | 3 | 2 | 1 |

- $k=2$：情况①，和 $= 2$；
- $k=4$：情况②，和 $= 3$（3 个 1 + 1 个 0）；
- $k=6$：情况③，和 $= 3 - 1 = 2$，即 $2 \times 3 + 2 - 6 = 2$ ✓。

## 4. 算法细节

1. **能拿多少个 1**：$\text{ones} = \min(k, \text{numOnes})$，受"只拿 $k$ 件"与"1 只有 numOnes 件"双重限制。
2. **拿多少个 0**：$\text{zeros} = \min(k - \text{ones}, \text{numZeros})$，对答案无贡献，但决定是否被迫拿 −1。
3. **被迫拿多少个 −1**：$\text{negs} = k - \text{ones} - \text{zeros} = \max(0,\ k - \text{numOnes} - \text{numZeros})$。
4. **答案**：$\text{ones} - \text{negs}$。三类件数直接给出，无需构造数组、无需排序，一次算术完成。

## 5. 正确性证明

**引理 1**：任何恰好选 $k$ 件的方案中，所拿 1 的件数 $a \le \min(k, \text{numOnes})$；所拿 −1 的件数 $c \ge \max(0,\ k - \text{numOnes} - \text{numZeros})$。

**证明**：$a$ 同时受"总共只拿 $k$ 件"与"1 只有 $\text{numOnes}$ 件"限制，故 $a \le \min(k, \text{numOnes})$。设拿 0 的件数为 $b$，则 $a + b + c = k$，且 $a \le \text{numOnes}$、$b \le \text{numZeros}$，故 $c = k - a - b \ge k - \text{numOnes} - \text{numZeros}$；又 $c \ge 0$，两不等式取并即得 $c \ge \max(0,\ k - \text{numOnes} - \text{numZeros})$。∎

**定理**：恰好选 $k$ 件时数字之和的最大值为 $\min(k, \text{numOnes}) - \max(0,\ k - \text{numOnes} - \text{numZeros})$。

**证明**：任一方案之和 $= a - c$，由引理 1，$a - c \le \min(k, \text{numOnes}) - \max(0,\ k - \text{numOnes} - \text{numZeros})$，此为上界。再证可达：取 $a = \min(k, \text{numOnes})$，$c = \max(0,\ k - \text{numOnes} - \text{numZeros})$，$b = k - a - c$。分情况验证 $b \ge 0$：若 $k \le \text{numOnes}$，则 $b = 0$；若 $k > \text{numOnes}$，则 $b = \min(k - \text{numOnes}, \text{numZeros}) \ge 0$。且 $(a, b, c)$ 均不超过各类库存，是合法方案，其和恰等于上界。∎

## 6. 复杂度分析

- **时间复杂度**：$O(1)$，只做常数次 $\min / \max$ 运算。
- **空间复杂度**：$O(1)$，仅使用常数个变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int kItemsWithMaximumSum(int numOnes, int numZeros, int numNegOnes, int k) {
        int ones = min(k, numOnes);
        int negs = max(0, k - numOnes - numZeros);
        return ones - negs;
    }
};
```

### Python

```python
class Solution:
    def kItemsWithMaximumSum(self, numOnes: int, numZeros: int,
                             numNegOnes: int, k: int) -> int:
        return min(k, numOnes) - max(0, k - numOnes - numZeros)
```

## 8. 边界情况与易错点

1. **"恰好选 k 件" vs "至多选 k 件"**：本题是**恰好**，$k$ 超过非负物品件数时必须拿 −1；若题面改为"至多"，则永远不拿 −1，答案退化为 $\min(k, \text{numOnes})$。审题时务必区分。
2. **漏掉 $\max(0, \cdot)$ 截断**：直接写 $\text{numOnes} - (k - \text{numOnes} - \text{numZeros})$，当 $k \le \text{numOnes} + \text{numZeros}$ 时会算出偏小的值，是本题最常见错误。
3. **$k = 0$**：答案为 0，公式自然覆盖，无需特判。
4. **全负袋**（$\text{numOnes} = \text{numZeros} = 0$）：答案为 $-k$，别习惯性返回 0。
5. **numNegOnes 是干扰信息**：只要 $k \le$ 总件数（题目保证），被迫拿的 −1 件数只由 $k - \text{numOnes} - \text{numZeros}$ 决定，`numNegOnes` 是否足够在约束下自动满足，公式无需引用它。
