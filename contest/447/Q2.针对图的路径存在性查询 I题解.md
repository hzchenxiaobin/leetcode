# LeetCode 针对图的路径存在性查询 I 题解

## 1. 题目概述

- **标题 / 题号**：针对图的路径存在性查询 I（#3532，medium）
- **链接**：https://leetcode.cn/problems/path-existence-queries-in-a-graph-i/
- **来源**：LeetCode 第 447 场周赛 Q2
- **难度**：中等
- **标签**：并查集、图、数组

**题意**：$n$ 个节点编号 $0 \sim n-1$，非递减数组 $nums$ 给每个节点一个权值。若 $|nums[i] - nums[j]| \le maxDiff$，则节点 $i$ 与 $j$ 之间存在一条**无向边**。给定 $queries$，对每个 $queries[i] = [u_i, v_i]$ 判断两节点之间是否存在路径，返回布尔数组。

**约束**：

- $1 \le n = nums.length \le 10^5$
- $0 \le nums[i] \le 10^5$，$nums$ 按**非递减**顺序排序
- $0 \le maxDiff \le 10^5$
- $1 \le queries.length \le 10^5$，$0 \le u_i, v_i < n$

> 💡 **审题关键**：其一，$nums$ **非递减**是题面送的礼物——对 $i < j$，绝对差 $|nums[i] - nums[j]| = nums[j] - nums[i]$，成边条件退化为单调量的比较；其二，图是**隐式**给出的，满足条件的点对最多 $\binom{n}{2} \approx 5 \times 10^9$ 对，**绝不能显式建图**；其三，$n$ 与 $q$ 同为 $10^5$，必须**离线预处理连通性、每查 $O(1)$**；其四，$u = v$ 恒为 true（到自身的平凡路径），预处理后自然覆盖，无需特判。

## 2. 示例

**示例 1**

```text
输入：n = 2, nums = [1, 3], maxDiff = 1, queries = [[0,0],[0,1]]
输出：[true, false]
解释：查询 [0,0]：节点 0 到自己有显然路径。
      查询 [0,1]：|nums[0] - nums[1]| = 2 > maxDiff，无边也不连通。
```

**示例 2**

```text
输入：n = 4, nums = [2, 5, 6, 8], maxDiff = 2, queries = [[0,1],[0,2],[1,3],[2,3]]
输出：[false, false, true, true]
解释：节点 0 与 1 差 3 > 2，被断口隔开；节点 1、2、3 相邻差 1、2 均 ≤ 2，
      连成一条链，两两互通。
```

## 3. 解题思路

本题表面是图论（查询、路径、连通），本质是**有序数组的分段**：连通分量与「断口」一一对应。

### 3.1 暴力思路：建图搜索

最朴素的两条路都不通：

```text
做法 A：显式建图
    枚举所有点对 (i, j)，判 |nums[i] - nums[j]| <= maxDiff 后连边
    O(n^2) = 10^10 次判断、最多 5×10^9 条边 —— 时间、内存双双爆炸

做法 B：不建图，每次查询从 u 出发 BFS/DFS
    每弹出节点 i，都要扫一遍全数组找邻居（值差 <= maxDiff 的点）
    单次查询 O(n^2)，q 次查询 O(q·n^2) ≈ 10^15 —— 更不可行
```

做法 B 有一个更聪明的版本：由 $nums$ 有序，节点 $i$ 的邻居是**连续的下标区间**（值都落在 $[nums[i] - maxDiff,\ nums[i] + maxDiff]$ 内），可用**二分**找到区间端点，单次查询降到 $O(n \log n)$——这正是官方标签 Binary Search 的来源。但总计仍是 $O(qn \log n) \approx 1.7 \times 10^{11}$，照样超时。

> ⚠️ 暴力的浪费在于：每次查询都从零开始搜索，而连通性是**全局静态**的——$10^5$ 个节点只属于少数几个连通分量，把分量编号一次算好，每次查询只需查表比对。

### 3.2 核心观察：断口切分连通分量

![核心观察：有序数组上断口切分连通分量，段内相邻边连成链，跨断口无边](images/wc447_q2_gap_segment_concept.svg)

称位置 $k$（$0 \le k < n-1$）为**断口**，若相邻差 $nums[k+1] - nums[k] > maxDiff$。三条观察给出全部结构：

| 观察 | 内容 | 带来的做法 |
|------|------|-----------|
| **绝对差单调化** | $i < j$ 时 $|nums[i] - nums[j]| = nums[j] - nums[i]$，两点在数组上相距越远差只会越大 | 只需考察**相邻**两个元素的差，其余点对的信息冗余 |
| **断口两侧完全隔离** | 跨断口的任意点对差 $\ge$ 断口差 $> maxDiff$（跨度只会放大） | 断口是不可逾越的墙，连通分量恰被其切分 |
| **段内链式连通** | 无断口的连续段内，相邻差都 $\le maxDiff$，相邻边连成一条链 | 段内任意两点互通，无需搜索 |
| **长边是冗余捷径** | 非相邻点对之间的直接边（若存在）不提供新的连通性 | 连通性由相邻边完全决定，判定连通只需这条链 |

结论：**连通分量 = 断口切出的连续段**。节点 $u$、$v$ 连通 $\iff$ 它们落在同一段。预处理一个段号数组 $group$，每查 $O(1)$。

### 3.3 算法流程：一遍染色 + O(1) 查询

![算法流程：group[0]=0，逐位看相邻差定段号，查询比对 group[u] 与 group[v]](images/wc447_q2_algorithm_flow.svg)

| 步骤 | 操作 | 说明 |
|------|------|------|
| ① 染色 | $group[0] = 0$；$i = 1 \cdots n-1$ 时 $group[i] = group[i-1] + [\,nums[i] - nums[i-1] > maxDiff\,]$ | 段号 = 左侧断口数，一趟线性扫描 |
| ② 查询 | $answer[i] = (\,group[u_i] == group[v_i]\,)$ | 每查 $O(1)$，$u = v$ 时段号必相同 |

> 💡 **等价的并查集写法**（官方标签 Union Find 的来源）：扫描时对每个相邻对 $(i, i+1)$，若 $nums[i+1] - nums[i] \le maxDiff$ 则 $\mathrm{union}(i, i+1)$；查询判 $\mathrm{find}(u) == \mathrm{find}(v)$。由于合并只发生在相邻编号之间，配路径压缩即可。两者答案一致（都由 §5 定理保证），染色法一个数组、零函数调用，常数更小也更不易写错。

### 3.4 示例演算

![示例 2 演算：相邻差定断口与段号，再逐查询比对段号](images/wc447_q2_example_walkthrough.svg)

以示例 2 走一遍。**染色**：$group[0] = 0$；$i=1$ 时差 $3 > 2$，断口，$group[1] = 1$；$i=2$ 时差 $1 \le 2$，$group[2] = 1$；$i=3$ 时差 $2 \le 2$，$group[3] = 1$。得 $group = [0, 1, 1, 1]$，即段 0 $= \{0\}$、段 1 $= \{1, 2, 3\}$。

**查询**：$[0,1]$：$0 \ne 1$ → false；$[0,2]$：$0 \ne 1$ → false；$[1,3]$：$1 = 1$ → true；$[2,3]$：$1 = 1$ → true。输出 $[\text{false}, \text{false}, \text{true}, \text{true}]$，与示例一致。示例 1 同理：$group = [0, 1]$，查询 $[0,0]$ 同段号 true、$[0,1]$ 异段号 false。

## 4. 算法细节

1. **断口判定的等号方向**：成边条件是 $\le maxDiff$，断口条件是**严格大于**——等号留在「有边」一侧。由 $maxDiff \ge 0$，相等元素（差为 0）永不产生断口。
2. **为什么只看相邻边就够**：由 §5 定理，段内相邻链已保证两两互通，非相邻的长边只是「捷径」，不改变连通性。这等价于「判定连通只需任何一棵生成树」，而有序性直接把这棵生成树递到了手上——就是相邻链。
3. **染色法 vs 并查集**：两者复杂度同阶（$O(n + q)$ vs $O((n+q)\,\alpha)$）。并查集的优势是**支持增量合并**（动态加点场景），静态查询场景染色法更简单直接。本题完全不需要 DSU 的能力，选染色。
4. **关于标签 Hash Table / Binary Search**：若 $nums$ 未排序，需先排序再用哈希表把值映回原下标（连通性与编号顺序无关）；二分视角（邻居是连续区间、二分定位断口）在静态查询下退化为线性扫描。这两个标签的真正主战场是姊妹篇 **Q4（#3534）**：查询改为「最少跳数」时，每一步都要二分找最远可达位置。
5. **返回类型**：C++ 返回 `vector<bool>`（按位压缩，注意别误写 `vector<int>`）。

## 5. 正确性证明

**引理 1（跨度放大）**：设 $i \le k < k+1 \le j$，则 $nums[j] - nums[i] \ge nums[k+1] - nums[k]$。

**证明**：由非递减性 $nums[i] \le nums[k]$、$nums[k+1] \le nums[j]$。拆和
$$nums[j] - nums[i] = \underbrace{(nums[j] - nums[k+1])}_{\ge 0} + (nums[k+1] - nums[k]) + \underbrace{(nums[k] - nums[i])}_{\ge 0} \ge nums[k+1] - nums[k].$$ ∎

**引理 2（断口隔离）**：若 $k$ 是断口（$nums[k+1] - nums[k] > maxDiff$），则不存在任何一条边连接左部的 $i \le k$ 与右部的 $j \ge k+1$。

**证明**：设 $i \le k < k+1 \le j$，则 $i < j$，由有序性 $|nums[i] - nums[j]| = nums[j] - nums[i] \ge nums[k+1] - nums[k] > maxDiff$，不满足成边条件。∎

**推论**：断口 $k$ 把节点集切成 $L = \{0, \cdots, k\}$ 与 $R = \{k+1, \cdots, n-1\}$，由引理 2 无边跨越 $\Rightarrow$ $L$ 中任意节点与 $R$ 中任意节点**不连通**。

**定理（连通判定）**：对任意 $u \le v$：$u$ 与 $v$ 连通 $\iff$ 区间 $[u, v]$ 内没有断口 $\iff$ $group[u] = group[v]$。

**证明**：

- （$\Leftarrow$）若 $[u, v]$ 内无断口，则对每个相邻对 $(k, k+1)$（$u \le k < v$）都有 $nums[k+1] - nums[k] \le maxDiff$，即边 $\{k, k+1\}$ 存在，于是 $u \to u+1 \to \cdots \to v$ 是一条路径，连通。
- （$\Rightarrow$）若存在断口 $k$（$u \le k < k+1 \le v$），则 $u \in L$、$v \in R$，由推论不连通。

再证段号刻画：$group$ 的递推定义恰为「当前位置左侧的断口个数」，而 $[u, v]$ 内无断口 $\iff$ $u$、$v$ 左侧断口数相同 $\iff$ $group[u] = group[v]$（$u = v$ 时平凡成立）。∎

由定理，染色法输出的每个查询答案均正确。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n + q)$。染色一趟线性扫描 $O(n)$；每个查询仅一次数组下标比较 $O(1)$，共 $O(q)$。
- **空间复杂度**：$O(n)$，即段号数组 $group$（不计返回的答案数组）。
- **对照**：显式建图 $O(n^2)$ 不可行；二分邻居 + BFS 为 $O(qn \log n) \approx 1.7 \times 10^{11}$，超时；并查集 $O((n+q)\alpha)$ 与染色同数量级但常数略大。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<bool> pathExistenceQueries(int n, vector<int>& nums, int maxDiff,
                                      vector<vector<int>>& queries) {
        vector<int> group(n);
        group[0] = 0;
        for (int i = 1; i < n; i++) {           // ① 染色：断口数即段号
            group[i] = group[i - 1] + (nums[i] - nums[i - 1] > maxDiff);
        }

        vector<bool> ans;
        ans.reserve(queries.size());
        for (auto& q : queries) {                // ② 比对段号
            ans.push_back(group[q[0]] == group[q[1]]);
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def pathExistenceQueries(self, n: int, nums: List[int], maxDiff: int,
                             queries: List[List[int]]) -> List[bool]:
        group = [0] * n
        for i in range(1, n):                    # ① 染色：断口数即段号
            group[i] = group[i - 1] + (nums[i] - nums[i - 1] > maxDiff)
        return [group[u] == group[v] for u, v in queries]   # ② 比对段号
```

## 8. 边界情况与易错点

1. **$u = v$ 的查询**：同一节点段号必相同 → true，染色法零特判自然覆盖（示例 1 的 $[0,0]$）。
2. **断口判定别写错等号**：断口条件是差**严格大于** $maxDiff$；写成 $\ge$ 会把「差恰好等于 $maxDiff$」的点对误判为断开（示例 2 的 $6, 8$ 差 2 恰好相等，应当连通）。
3. **$maxDiff = 0$**：段 = 极长的相等值段；相等元素差为 0，永不断段。
4. **别显式建图**：边数可达 $\binom{n}{2} \approx 5 \times 10^9$，内存时间双爆炸——这是本题埋给「惯性思维」的最大坑。
5. **$nums$ 已有序**：题面保证非递减，不要画蛇添足再排序（虽不致错但浪费 $O(n \log n)$）。
6. **溢出**：无。值域 $\le 10^5$，相邻差 $\le 10^5$，段号 $\le n$，`int` 均绰绰有余。
7. **姊妹篇预警**：Q4（#3534）把查询改成「最少跳数」，仅染色不够——同一段内一步可跳到**值差 $\le maxDiff$ 的最远点**，需二分 + 倍增优化，但**分段这一步地基完全相同**。

**延伸思考**：

- **乱序版**：若 $nums$ 未排序，先排序、用哈希表记录原下标，再按本题染色（连通性与编号顺序无关），查询仍 $O(1)$。
- **动态加点版**：用平衡树按值维护相邻间隙，新点只与值相邻的两个点尝试合并，并查集增量 $\mathrm{union}$ 即可。
- **$maxDiff$ 随查询变化（离线版）**：把所有间隙从小到大排序、查询按 $maxDiff$ 排序，Kruskal 式逐步合并（本质是问「最小生成树上 $\max$ 边权 $\le$ 阈值」的连通性），$O((n + q)\alpha)$ 离线回答。
- **在线版（$maxDiff$ 动态）**：连通性退化为「$u$、$v$ 之间最大相邻间隙 $\le maxDiff$」，即区间最大值查询，可用稀疏表 / 线段树 $O(1)$ 或 $O(\log n)$ 回答——染色是它在「间隙全 $\le$ 阈值」时的特例。
