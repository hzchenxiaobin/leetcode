# LeetCode 针对图的路径存在性查询 II 题解

## 1. 题目概述

- **标题 / 题号**：针对图的路径存在性查询 II（#3534，hard）
- **链接**：https://leetcode.cn/problems/path-existence-queries-in-a-graph-ii/
- **来源**：LeetCode 第 447 场周赛 Q4
- **难度**：困难
- **标签**：排序、双指针、贪心、倍增、图、动态规划

**题意**：$n$ 个节点编号 $0 \sim n-1$，数组 $nums$ 给每个节点一个权值（**本题中乱序**）。若 $|nums[i] - nums[j]| \le maxDiff$，则节点 $i$ 与 $j$ 之间存在一条**无向无权边**。对每个查询 $queries[i] = [u_i, v_i]$，求 $u_i$ 与 $v_i$ 之间的**最短距离**（路径上的边数）；两节点之间不存在路径则输出 $-1$。返回答案数组。

**约束**：

- $1 \le n = nums.length \le 10^5$
- $0 \le nums[i] \le 10^5$
- $0 \le maxDiff \le 10^5$
- $1 \le queries.length \le 10^5$，$queries[i] = [u_i, v_i]$，$0 \le u_i, v_i < n$

> 💡 **审题关键**：其一，这是本场 Q2 的困难升级版，两处关键变化——$nums$ 从「非递减」变成**乱序**，答案从「是否存在」变成「**最短距离**」；其二，图是隐式的（满足条件的点对最多 $\binom{n}{2} \approx 5 \times 10^9$ 对），**绝不能显式建图**；其三，$n$ 与 $q$ 同为 $10^5$，必须**离线预处理、每查 $O(\log n)$**；其四，$u = v$ 时距离为 $0$，需要特判；其五，也是本题最大的陷阱——**「答案 $= \lceil$ 值差 $/ maxDiff \rceil$」的直觉公式是错的**，每一跳都必须落在真实存在的值上（见 3.2 观察 4）。

## 3. 解题思路

一句话概括：**排序后图结构回到 Q2 的有序世界，「是否可达」由断口切分量 $O(1)$ 判定；同分量内的最短距离等于「贪心跳跃」次数，用倍增把每次查询压到 $O(\log n)$**。

### 3.1 暴力思路：每次查询 BFS

隐式图不能显式建。退一步，不建图、每次查询从 $u$ 出发 BFS：即使利用「邻居是连续区间、二分定位」的优化，单次 BFS 也要访问 $O(n)$ 个节点、每次定位 $O(\log n)$，总计 $O(qn \log n) \approx 1.7 \times 10^{11}$——必然超时。

> ⚠️ 浪费的根源：图是**静态**的，$10^5$ 次查询在反复搜索同一个图；而「隐式 + 值有序」其实已把整张图压缩成「数轴上的区间跳跃」，最短距离存在结构性刻画，根本不需要逐点搜索。

### 3.2 核心观察：排序 + 断口切分量 + 贪心跳跃

![核心观察：排序后断口切分量，跨段 = −1，段内贪心跳跃求最短距离](images/wc447_q4_sorted_component_concept.svg)

**观察 1（排序不变性）**：成边条件只与两个节点的**值**有关，与下标无关。把节点按 $nums$ 值升序重排，得到有序值序列 $v_0 \le v_1 \le \cdots \le v_{n-1}$，所有点对的连通性与距离**完全不变**——乱序只是表象，排序后一切回到 Q2 的有序世界。与 Q2 相比只需多做一件事：记录 $pos[\,]$ 把原下标映射回排序位（查询给的是原下标）。

**观察 2（断口切分连通分量）**：与 Q2 完全一致。排序后相邻差 $v_{k+1} - v_k > maxDiff$ 的位置是**断口**——断口两侧任意点对的值差只会更大，无任何边；无断口的连续段内，相邻位置两两有边、连成一条链。于是**连通分量 = 断口切出的段**：跨段查询直接 $-1$，$u = v$ 直接 $0$，同段才需要继续算距离。

**观察 3（段内最短距离 = 贪心跳跃次数）**：同段内从排序位 $p$ 到 $q$（$p < q$）怎么走最快？站在位置 $k$，能一步到达的排序位恰是值落在 $[\,v_k - maxDiff,\ v_k + maxDiff\,]$ 内的整段连续区间。定义**最远可达**

$$r(k) = \max\{\, j : v_j \le v_k + maxDiff \,\},$$

**每一步都跳到 $r$（窗口内最远的点）就是最优策略**，且最短距离 $= \min\{\, t : r^{(t)}(p) \ge q \,\}$（$r^{(t)}$ 表示 $r$ 迭代 $t$ 次）：先跳 $t-1$ 个「落点」，第 $t$ 跳直达 $q$。正确性证明见 §5——直觉是 $r$ 关于位置**单调不减**（起点越靠右，窗口右端点也越靠右），「跳得远」严格支配「跳得近」，不可能吃亏。

![贪心跳跃：每步跳到值窗口内最远的点，r 单调保证支配性；值差公式陷阱](images/wc447_q4_greedy_jump.svg)

**观察 4（值差公式是陷阱）**：能不能不算跳跃、直接输出 $\lceil (v_q - v_p) / maxDiff \rceil$？**不能**。反例：值 $[0, 5, 20]$、$maxDiff = 10$：$0 \leftrightarrow 5$ 有边，$5$ 与 $20$ 差 $15 > 10$ 是断口，$20$ 是孤立分量，真答案是 $-1$；值差公式却给出 $\lceil 20/10 \rceil = 2$。**跳跃必须落在真实存在的值上**，「落脚点存在性」正是本题 Hard 评级的核心考点——这也是「每步跳到最远可达」必须逐点迭代、而不能套闭式公式的原因。

### 3.3 算法流程：预处理 + 倍增查询

![倍增表与查询下降：up[t][k] 表示从 k 连跳 2^t 步，查询从高位往低位试跳](images/wc447_q4_binary_lifting.svg)

| 步骤 | 操作 | 说明 |
|------|------|------|
| ① 排序 | 按 $nums$ 值升序得 $order$、有序值 $vals$、原下标落点 $pos$ | 值相同时顺序任意，见 §8 |
| ② 断口染色 | $vals_k - vals_{k-1} > maxDiff$ 处分量号 $+1$ | 一遍递推，$O(n)$ |
| ③ 最远可达 | 双指针求 $r[k]$ = 值 $\le vals_k + maxDiff$ 的最右排序位 | 阈值随 $k$ 单调右移，$j$ 只进不退，$O(n)$ |
| ④ 倍增表 | $up[0] = r$；$up[t][k] = up[t-1][\,up[t-1][k]\,]$ | $t = 0 \sim 16$，$2^{17} > 10^5$，建表 $O(n \log n)$ |
| ⑤ 查询下降 | $u = v \to 0$；分量不同 $\to -1$；$p < q$ 后从 $t = 16$ 往低位试：$up[t][cur] < q$ 才跳 | 累计步数 $s$，答案 $s + 1$ |

整体框架一句话：**「是否可达」交给断口染色 $O(1)$ 判定，「走几步」交给贪心跳跃 + 倍增 $O(\log n)$ 计数**。

### 3.4 示例演算

![示例 2 演算：排序、断口、far 数组与四个查询的逐个处理](images/wc447_q4_example_walkthrough.svg)

以示例 2（$nums = [5,3,1,9,10]$，$maxDiff = 2$）走一遍。

排序后 $vals = [1, 3, 5 \mid 9, 10]$，$5 \to 9$ 差 $4 > 2$ 是断口：分量 $0$ = 排序位 $\{0,1,2\}$（原下标 $2,1,0$），分量 $1$ = 排序位 $\{3,4\}$（原下标 $3,4$）。$pos = [2,1,0,3,4]$（节点 0 的值 5 落在排序位 2）。双指针得 $r = [1, 2, 2, 4, 4]$（例如 $r[0] = 1$：值 $\le 1 + 2 = 3$ 的最右位置是排序位 1）。

- **查询 $[0,1]$**：节点 0 → 排序位 2，节点 1 → 排序位 1，交换成 $(p, q) = (1, 2)$；$r[1] = 2 \ge 2$，一步直达，$s = 0$，答案 $1$。
- **查询 $[0,2]$**：节点 0 → 排序位 2，节点 2 → 排序位 0，交换成 $(p, q) = (0, 2)$；倍增下降：$r[0] = 1 < 2$ 跳到位置 1（$s = 1$），此后 $r[1] = 2 \ge 2$ 直达，答案 $2$。对应路径：值 $1 \to 3 \to 5$，即节点 $2 \to 1 \to 0$，两条边 ✓。
- **查询 $[2,3]$**：节点 2 在分量 0、节点 3 在分量 1，跨断口，答案 $-1$。
- **查询 $[4,3]$**：节点 4 → 排序位 4，节点 3 → 排序位 3，交换成 $(p, q) = (3, 4)$；$r[3] = 4 \ge 4$ 直达，答案 $1$。

输出 $[1, 2, -1, 1]$，与期望一致。

## 4. 算法细节

1. **排序的值相同怎么办**：值相同的节点可任意排定先后——它们彼此必有边（差 $0 \le maxDiff$），且值相同 ⟹ $r$ 完全一样，从哪个出发的跳跃行为都相同，不影响任何答案。
2. **$r[k] \ge k$ 恒成立**：自身值 $v_k \le v_k + maxDiff$ 永远在窗口内。若 $r[k] = k$，说明右边一个都够不着（撞断口或到数组尽头）。同分量内目标在右侧时，$r$ 链每步至少前进一个位置（$p_t + 1$ 与 $p_t$ 同段、相邻差 $\le maxDiff$），故链**严格递增**、必然越过 $q$，倍增下降不会卡死。
3. **双指针的细节**：$vals_k$ 随 $k$ 递增 ⟹ 阈值 $vals_k + maxDiff$ 单调右移 ⟹ $j$ 只前进不回退。但撞断口后 $j$ 会「落后」于 $k$，因此每轮先做 $j \gets \max(j,\ k)$ 再推进。
4. **倍增表是「函数迭代的稀疏表」**：$up[t][k] = r^{\circ 2^t}(k)$，建表方式与 1483「第 $K$ 个祖先」的 jump pointer 完全同款。查询「最少跳几次能越过 $q$」=「求最大的 $s$ 使 $r^{\circ s}(p) < q$」，从高位到低位贪心累计——这是**计数型倍增**的标准姿势（先凑步数、末位直达）。
5. **答案要 $+1$**：下降结束时 $cur$ 是最后一个仍 $< q$ 的落点，而 $q \le r(cur)$ 说明 $q$ 就在 $cur$ 的值窗口内——最后一跳直达 $q$，故答案 $= s + 1$，不是 $s$。
6. **$LOG = 17$ 的由来**：$r$ 链每跳至少前进一个排序位，故 $s < n \le 10^5 < 2^{17}$，17 层必然够；再多只是浪费内存。

## 5. 正确性证明

设排序后值序列 $v_0 \le \cdots \le v_{n-1}$，$D = maxDiff$，$r$ 与断口、分段同上文。

**引理 1（断口是不可逾越的墙；段内链式连通）**：

（i）若 $v_{k+1} - v_k > D$，则对任意 $i \le k < j$，节点 $i, j$ 之间无边；
（ii）无断口的段内任意两点沿相邻边构成的链连通。

**证明**：（i）反设有边 $v_j - v_i \le D$。由 $j \ge k+1$、$i \le k$ 及有序性，$v_j - v_i \ge v_{k+1} - v_k > D$，矛盾。（ii）段内相邻差 $\le D$，相邻排序位两两有边，链上任意两点沿链可达。∎

**推论 1**：连通分量恰为断口切出的段；跨分量查询答案为 $-1$。且 $r$ 不跨墙：若 $k, k+1$ 之间是断口，则 $k$ 所在段内任意 $i \le k$ 有 $r(i) \le k$——否则 $r(i) \ge k+1$ 将给出 $v_{k+1} \le v_{r(i)} \le v_i + D \le v_k + D$，与断口定义矛盾。∎

**引理 2（$r$ 单调不减）**：$i \le j \Rightarrow r(i) \le r(j)$。

**证明**：$v_i \le v_j \Rightarrow v_i + D \le v_j + D$，故 $\{\, m : v_m \le v_i + D \,\} \subseteq \{\, m : v_m \le v_j + D \,\}$，取最大值即得。∎

**定理（贪心跳跃给出最短距离）**：设 $p < q$ 同段，定义贪心链 $p_0 = p$，$p_{t+1} = r(p_t)$，记 $t^{*} = \min\{\, t : p_t \ge q \,\}$。则节点 $p$、$q$ 之间的最短距离恰为 $t^{*}$。

**证明**：

**（a）$t^{*}$ 条边可达**：先看链的形态。当 $p_t < q$ 时，$p_t + 1 \le q$ 与 $p_t$ 同段，相邻差 $\le D$，故 $p_{t+1} = r(p_t) \ge p_t + 1$——链在越过 $q$ 之前**严格递增**；由推论 1，链不跨墙，始终留在 $p, q$ 所在的段内，故 $t^{*}$ 存在且 $p_0 < p_1 < \cdots < p_{t^{*}-1} < q$。链上相邻两跳满足 $v_{p_{t+1}} - v_{p_t} \le D$，有边；末端 $p_{t^{*}-1} < q \le p_{t^{*}} = r(p_{t^{*}-1})$ 给出 $v_q - v_{p_{t^{*}-1}} \le v_{p_{t^{*}}} - v_{p_{t^{*}-1}} \le D$，也有边。于是 $p \to p_1 \to \cdots \to p_{t^{*}-1} \to q$ 是一条 $t^{*}$ 条边、节点两两不同的路径。

**（b）少于 $t^{*}$ 条边不可达**：设 $R_j$ 为**任意** $j$ 条边的路径（允许来回折返、绕路）从 $p$ 出发所能到达的最大排序位。断言 $R_j \le p_j$，对 $j$ 归纳：$R_0 = p = p_0$；设 $R_j \le p_j$，任取 $j+1$ 条边的路径 $a_0 = p, a_1, \cdots, a_{j+1}$，有 $a_j \le R_j \le p_j$，而边 $(a_j, a_{j+1})$ 给出 $v_{a_{j+1}} \le v_{a_j} + D \le v_{p_j} + D$，故 $a_{j+1} \le r(p_j) = p_{j+1}$。若存在 $k < t^{*}$ 条边的路径到达 $q$，则 $q \le R_k \le p_k$，与 $p_k < q$（$t^{*}$ 的最小性）矛盾。

（a）（b）合并，最短距离 $= t^{*}$。∎

**推论 2（倍增查询的正确性）**：下降过程从高位到低位累计出**最大的** $s$ 使 $r^{\circ s}(p) < q$，从而 $r^{\circ (s+1)}(p) \ge q$，即 $s + 1 = t^{*}$，返回值恰为最短距离。∎

## 6. 复杂度分析

- **时间复杂度**：$O((n + q) \log n)$。排序 $O(n \log n)$；断口染色与双指针各 $O(n)$（$j$ 只前进，摊还至多 $n$ 步）；倍增建表 $O(n \log n)$（17 层每层 $n$）；每次查询 $O(\log n)$（至多 17 次表访问）。
- **空间复杂度**：$O(n \log n)$。倍增表 $17 \times 10^5$ 个 `int` 约 6.8 MB，其余 $order/vals/pos/comp/r$ 各 $O(n)$。
- **对照**：逐查询 BFS 为 $O(qn \log n) \approx 1.7 \times 10^{11}$，不可行；Q2 的断口染色只解决「可达性」，本题的全部增量在于「段内距离 = 贪心链长度」这一刻画 + 倍增计数。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> pathExistenceQueries(int n, vector<int>& nums, int maxDiff,
                                     vector<vector<int>>& queries) {
        vector<int> order(n);
        iota(order.begin(), order.end(), 0);
        sort(order.begin(), order.end(), [&](int a, int b) {
            return nums[a] < nums[b];
        });

        vector<int> vals(n), pos(n);                      // ① 排序 + 原下标映射
        for (int k = 0; k < n; k++) {
            vals[k] = nums[order[k]];
            pos[order[k]] = k;
        }

        vector<int> comp(n);                               // ② 断口染色：分量 = 段
        for (int k = 1; k < n; k++)
            comp[k] = comp[k - 1] + (vals[k] - vals[k - 1] > maxDiff);

        vector<int> far(n);                               // ③ 双指针求最远可达 r[k]
        for (int k = 0, j = 0; k < n; k++) {
            j = max(j, k);                                 //   撞断口后 j 会落后，先拉回
            while (j + 1 < n && vals[j + 1] - vals[k] <= maxDiff) j++;
            far[k] = j;
        }

        const int LOG = 17;                                // 2^17 > 1e5，s < n 必然够
        vector<vector<int>> up(LOG, vector<int>(n));       // ④ 倍增表：r 迭代 2^t 次
        up[0] = far;
        for (int t = 1; t < LOG; t++)
            for (int k = 0; k < n; k++)
                up[t][k] = up[t - 1][up[t - 1][k]];

        vector<int> ans;
        ans.reserve(queries.size());
        for (auto& qr : queries) {                         // ⑤ 查询下降
            int u = qr[0], v = qr[1];
            if (u == v) { ans.push_back(0); continue; }
            int p = pos[u], q = pos[v];
            if (comp[p] != comp[q]) { ans.push_back(-1); continue; }
            if (p > q) swap(p, q);
            int s = 0;                                     //   最大 s 使 r^s(p) < q
            for (int t = LOG - 1; t >= 0; t--)
                if (up[t][p] < q) { p = up[t][p]; s |= 1 << t; }
            ans.push_back(s + 1);                           //   最后一跳直达 q
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def pathExistenceQueries(self, n: int, nums: List[int], maxDiff: int,
                             queries: List[List[int]]) -> List[int]:
        order = sorted(range(n), key=lambda i: nums[i])   # ① 排序 + 原下标映射
        vals = [nums[i] for i in order]
        pos = [0] * n
        for k, i in enumerate(order):
            pos[i] = k

        comp = [0] * n                                     # ② 断口染色：分量 = 段
        for k in range(1, n):
            comp[k] = comp[k - 1] + (vals[k] - vals[k - 1] > maxDiff)

        far = [0] * n                                      # ③ 双指针求最远可达 r[k]
        j = 0
        for k in range(n):
            j = max(j, k)                                  #   撞断口后 j 会落后，先拉回
            while j + 1 < n and vals[j + 1] - vals[k] <= maxDiff:
                j += 1
            far[k] = j

        LOG = max(1, n.bit_length())                       # ④ 倍增表：r 迭代 2^t 次
        up = [far]
        for _ in range(1, LOG):
            prev = up[-1]
            up.append([prev[x] for x in prev])

        ans = []
        for u, v in queries:                               # ⑤ 查询下降
            if u == v:
                ans.append(0)
                continue
            p, q = pos[u], pos[v]
            if comp[p] != comp[q]:
                ans.append(-1)
                continue
            if p > q:
                p, q = q, p
            s = 0                                          #   最大 s 使 r^s(p) < q
            for t in range(LOG - 1, -1, -1):
                if up[t][p] < q:
                    p = up[t][p]
                    s |= 1 << t
            ans.append(s + 1)                              #   最后一跳直达 q
        return ans
```

## 8. 边界情况与易错点

1. **$u = v$ 必须特判为 $0$**：两个排序位相同时，倍增下降全程不跳，$s = 0$，若忘特判会输出错误的 $s + 1 = 1$（示例 3 的查询 $[0,0]$ 就是干这个的）。
2. **答案要 $+1$**：$s$ 是「跳到 $q$ 跟前」的步数，最后一跳直达 $q$——这是本题与「树上距离 / 祖先计数」类倍增最常错的一处。
3. **$p > q$ 要交换**：距离对称，但贪心链的方向是「从左往右」，下降算法要求 $p < q$。
4. **双指针遇断口先 $j \gets \max(j, k)$**：撞墙后 $j$ 落后于 $k$，不拉回会算出 $r[k] < k$ 的错值，且此后一路全错。
5. **乱序是本题新坑**：与 Q2 不同，不能在原数组上直接做断口/双指针，必须先排序并维护 $pos$ 映射——查询的 $u, v$ 是**原下标**。
6. **值差公式是 WA 之源**：答案 $\ne \lceil$ 值差 $/ D \rceil$（观察 4 的 $[0,5,20]$ 反例），任何不检查「落脚点存在性」的闭式捷径都会挂。
7. **倍增层树要够**：$LOG = 17$（$2^{17} = 131072 > 10^5$）；$r$ 链每跳至少前进一位保证 $s < n$，不会溢出层数。Python 里 `n.bit_length()` 在 $n = 1$ 时为 1，注意 `LOG ≥ 1`。
8. **$maxDiff = 0$ 的退化**：分量 = 同值组，组内任意两点距离 1、自身 0；算法自然覆盖（$r$ 窗口恰好覆盖整组），无需特判。
9. **溢出无忧**：$vals_k + maxDiff \le 2 \times 10^5$，`int` 足够，无需 `long long`。

**延伸思考**：

- **为什么不能每个分量一次多源 BFS 拿到全部距离？** 多源 BFS 维护的是「到最近源的距离」，得不到两两距离；分量内点对距离矩阵 $O(n^2)$ 存不下——「距离 = 贪心链长度」的结构化刻画才是把查询做到 $O(\log n)$ 的关键。
- **若边权不再是 $1$ 而是值差 $|v_i - v_j|$？** 同段内沿排序链走，相邻差逐段求和恰为 $v_q - v_p$（裂项相消），且任何路径代价 $\ge$ 值差（三角不等式），故答案直接退化为同分量时的 $|nums_u - nums_v|$——边权变「难」反而闭式可解，与本题形成有趣对照。
- **若 $nums$ 支持在线单点修改？** 排序位、断口、$r$ 都是数轴上的局部量，可用平衡树维护有序序列 + 分块重建倍增表做到近似 $O(\log^2 n)$ 修改，是很好的进阶练习。
