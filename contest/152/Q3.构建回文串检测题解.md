# LeetCode 构建回文串检测 题解

## 1. 题目概述

- **标题 / 题号**：构建回文串检测（#1177，medium）
- **链接**：https://leetcode.cn/problems/can-make-palindrome-from-substring/
- **来源**：LeetCode 第 152 场周赛 Q3
- **难度**：中等
- **标签**：位运算，数组，哈希表，字符串，前缀和

**题意**：给定字符串 $s$（长度 $n$）和若干次查询 $queries[i] = [left, right, k]$。对第 $i$ 次查询，你可以把子串 $s[left..right]$ **任意重排**，再从重排结果中挑**至多** $k$ 个字符，每个字符**独立地**替换成任意小写字母，然后判断能否得到回文串。返回逐条查询的布尔结果。每次查询互不影响，$s$ 本身不会被修改。

**约束**：

- $1 \le \lvert s \rvert,\ \lvert queries \rvert \le 10^5$
- $0 \le left \le right < \lvert s \rvert$，即子串非空
- $0 \le k \le \lvert s \rvert$
- $s$ 仅含小写英文字母

查询数可达 $10^5$，因此单次查询的复杂度必须是 $O(1)$ 或 $O(\log n)$，且 $O(26)$ 的常数也只有很小的余量。

## 2. 示例

**示例 1**

```text
输入：s = "abcda", queries = [[3,3,0],[1,2,0],[0,3,1],[0,3,2],[0,4,1]]
输出：[true,false,false,true,true]
解释：
queries[0]：子串 "d"，本身就是回文 → true
queries[1]：子串 "bc"，两个不同的字母各 1 次，k=0 无法处理 → false
queries[2]：子串 "abcd"，四个字母全为奇数，只改 1 个不够 → false
queries[3]：子串 "abcd"，改 2 个得到 "abba" → true
queries[4]：子串 "abcda"，改 1 个得到 "abdba" → true
```

**示例 2**

```text
输入：s = "lyb", queries = [[0,1,0],[2,2,1]]
输出：[false,true]
解释：
queries[0]：子串 "ly"，两个奇数计数，k=0 → false
queries[1]：子串 "b"，单字符回文，k=1 也用不上 → true
```

## 3. 解题思路

### 3.1 暴力思路

最直白的做法是照着题面模拟：对每条查询取子串，枚举「替换哪些位置、替换成什么字母」，再检查结果能否排成回文。这条路是组合爆炸的：光是选 $t \le k$ 个位置就有 $\binom{len}{t}$ 种，每个位置还有 $26$ 种选法，复杂度达到 $\binom{len}{k} \cdot 26^{k}$ 的量级，完全不可行。

退一步，若只按「统计频次 → 数奇数个数」的正确逻辑写，单条查询仍需扫一遍子串，$O(len)$。总计 $O(n \cdot q) = 10^{10}$，必然超时。**瓶颈不在判定逻辑，而在「反复统计同一段区间内各字母的奇偶性」**，这正是前缀和要解决的问题。

### 3.2 核心观察：只看计数奇偶，一次替换消掉一对奇数

![回文判定与一次替换的效果](images/wc152_q3_odd_parity.svg)

**重排是免费的，所以顺序无关。** 一个多重集能排成回文，当且仅当其中**至多一个字母出现奇数次**：成对的字母左右各放一个，那个落单的（若有）放在正中。记子串中出现奇数次的字母个数为 $odd$，则问题目标就是让 $odd \le 1$。

**替换是「消对」的操作。** 把某个 $x$ 改成 $y$，只有两个字母的计数奇偶会变：$x$ 的计数减一、$y$ 的计数加一。于是：

- $x$、$y$ 原本都是奇数次 → 两者都变成偶数，$odd$ **减少 2**；
- $x$、$y$ 原本都是偶数次 → 两者都变奇数，$odd$ 增加 2（我们不会这么做）；
- 一奇一偶 → $odd$ 不变（白费一次替换）。

所以一次替换最多把 $odd$ 降低 $2$，而只要 $odd \ge 2$ 就一定能找到两个奇数次字母，取其一改成另一个，恰好降低 $2$。于是最少替换次数为

$$\text{need} = \left\lfloor \frac{odd}{2} \right\rfloor$$

判定条件因此化为一行：$need \le k$，等价地 $odd \le 2k+1$。

> 💡 关键归约：**「能否重排 + 至多 $k$ 次单字符替换」这种看似要搜索的问题，被压缩成「数一数有多少个字母出现奇数次」**。

### 3.3 算法流程：26 位奇偶掩码 + 前缀异或

![前缀异或掩码与区间差分](images/wc152_q3_prefix_xor_flow.svg)

剩下的问题是「如何 $O(1)$ 求出区间内每个字母计数的奇偶」。奇偶只有两种状态，天然适合用**位掩码**：

- 用整数第 $c$ 位（$0 \le c < 26$）表示字母 `'a'+c` 在当前集合中出现次数的奇偶；
- **合并两个集合 = 按位异或**（奇偶相加取模 2，恰好是异或）；
- **区间差分 = 异或**（同一段前缀被异或两次自动抵消）。

定义 $pre[0] = 0$，

$$pre[i+1] = pre[i] \oplus \bigl(1 \ll (s[i] - \text{'a'})\bigr)$$

那么查询 $[left, right]$ 的区间掩码与答案就是

$$mask = pre[right+1] \oplus pre[left], \qquad answer = \bigl[\operatorname{popcount}(mask) \le 2k+1\bigr]$$

预处理 $O(n)$，之后每条查询一次异或 + 一次数位计数，$O(1)$。

### 3.4 示例演算

![s = "abcda" 的前缀掩码与五次查询](images/wc152_q3_walkthrough.svg)

以 `s = "abcda"`（$n = 5$）为例，逐字符累异或得到前缀掩码（十进制）：

| $i$ | 0 | 1 | 2 | 3 | 4 | 5 |
|-----|---|---|---|---|---|---|
| 读入的字符 | — | `a` | `b` | `c` | `d` | `a` |
| $pre[i]$ | 0 | 1 | 3 | 7 | 15 | 14 |

注意 $pre[5] = 15 \oplus 1 = 14$：末尾的 `a` 让 bit0 归零，说明整串里 `a` 出现了偶数次。

| 查询 | 区间掩码 | $odd$ | $\lfloor odd/2 \rfloor$ | $k$ | 答案 |
|------|----------|-------|--------------------------|-----|------|
| $[3,3], 0$ | $pre[4] \oplus pre[3] = 15 \oplus 7 = 8$ | 1 | 0 | 0 | true |
| $[1,2], 0$ | $pre[3] \oplus pre[1] = 7 \oplus 1 = 6$ | 2 | 1 | 0 | false |
| $[0,3], 1$ | $pre[4] \oplus pre[0] = 15$ | 4 | 2 | 1 | false |
| $[0,3], 2$ | $pre[4] \oplus pre[0] = 15$ | 4 | 2 | 2 | true |
| $[0,4], 1$ | $pre[5] \oplus pre[0] = 14$ | 3 | 1 | 1 | true |

输出 `[true,false,false,true,true]`，与官方示例一致。可以看到 $[0,3]$ 与 $[0,4]$ 只差末尾一个 `a`，掩码从 $15$ 变成 $14$，$odd$ 从 4 降到 3，判定随之翻转。

## 4. 算法细节

1. **掩码宽度**：只需 26 位，`int` 足够（最高位是 $1 \ll 25$，远小于 $2^{31}-1$），不必用 `long long`。
2. **下标对齐**：$pre$ 的下标是「前缀长度」，查询 $[left, right]$ 用 $pre[right+1] \oplus pre[left]$。写成 $pre[right] \oplus pre[left-1]$ 也等价，但 $left = 0$ 时会访问下标 $-1$，所以统一用长度形式最安全。
3. **popcount 的写法**：C++ 用 `__builtin_popcount(mask)`（掩码只有 26 位，转不转 `unsigned` 都正确）；Python 用 `bin(mask).count("1")`（各版本通用），3.10+ 可换成更快的 `int.bit_count()`。
4. **判定式的等价形式**：$\lfloor odd/2 \rfloor \le k$ 与 $odd \le 2k+1$ 完全等价（因为左侧是整数除法），任选一种即可；不要写成 $odd/2 \le k$ 的浮点比较。
5. **不要判长度奇偶**：$odd$ 与子串长度必然同奇偶（长度 = 各计数之和，其奇偶等于奇数计数的个数奇偶），所以「长度为偶数要求 $odd=0$、长度为奇数要求 $odd=1$」这条规则已被 $\lfloor odd/2 \rfloor$ 自动吸收，额外特判反而容易写错。
6. **前缀表的构造**：一次遍历即可，`pre` 大小取 $n+1$，下标从 0 开始且 $pre[0] = 0$。
7. **答案容器**：C++ 返回 `vector<bool>`，用 `reserve(queries.size())` 预留；Python 直接 append 到列表。
8. **输入规模意识**：$10^5$ 条查询下，即使每条只做 $O(26)$ 的循环也够用，但位运算版本把常数压到一次异或，是最干净的写法。

## 5. 正确性证明

**引理 1（回文的充要条件）**：一个字符多重集能重排成回文，当且仅当其中出现奇数次的字母至多一个。

**证明**：设回文长度为 $L$。若 $L$ 为偶数，回文关于中心对称，每个字母的出现次数必为偶数；若 $L$ 为奇数，除正中间那一个字符外，其余字符也成对出现，故恰有一个字母出现奇数次。必要性得证。充分性：把所有字母按「成对」摆放，先放左半部分再把左半部分镜像到右边，若有落单字符就把它放在正中。∎

**引理 2（单次替换的效果）**：把子串中某个 $x$ 改成 $y$（$x \ne y$），$odd$ 的变化量只可能是 $0$ 或 $\pm 2$；且当 $odd \ge 2$ 时，存在一次替换使 $odd$ 恰好减少 $2$。

**证明**：只有 $x$、$y$ 的计数发生变化（各 $\mp 1$），其他字母不变。$x$、$y$ 各自奇偶翻转，于是二者的奇数标记要么同时由 $0$ 变 $1$（$odd + 2$），要么同时由 $1$ 变 $0$（$odd - 2$），要么一增一减（$odd$ 不变）。当 $odd \ge 2$ 时，取两个出现奇数次的字母 $u \ne v$ 各一个，把其中一个 $u$ 改成 $v$：$u$ 的计数减一后为偶数，$v$ 的计数加一后为偶数，二者都退出奇数集合，$odd$ 减少 $2$。∎

**引理 3（最少替换次数）**：使子串能重排成回文所需的最少替换次数恰为 $\lfloor odd/2 \rfloor$。

**证明**：替换不改变长度，故 $odd$ 的奇偶性全程不变，目标 $odd' \le 1$ 结合奇偶性只能是 $odd' = odd \bmod 2$。

*下界*：每次替换最多使 $odd$ 减 $2$，$t$ 次后 $odd' \ge odd - 2t$；要求 $odd' \le 1$，即 $t \ge (odd-1)/2$，故 $t \ge \left\lceil (odd-1)/2 \right\rceil$。而 $\left\lceil (odd-1)/2 \right\rceil = \lfloor odd/2 \rfloor$：$odd$ 为奇数时两者都等于 $(odd-1)/2$，$odd$ 为偶数时 $\lceil (odd-1)/2 \rceil = odd/2 = \lfloor odd/2 \rfloor$。

*上界*：由引理 2，只要当前 $odd \ge 2$ 就能把 $odd$ 降 $2$；连续执行 $\lfloor odd/2 \rfloor$ 次后 $odd$ 变成 $odd \bmod 2 \in \{0, 1\}$，由引理 1 可排成回文。∎

**引理 4（掩码刻画奇偶）**：$mask = pre[right+1] \oplus pre[left]$ 的第 $c$ 位为 $1$，当且仅当字母 $c$ 在 $s[left..right]$ 中出现奇数次。

**证明**：设 $\text{cnt}(i, c)$ 为前缀 $s[0..i-1]$ 中字母 $c$ 的个数，则 $pre[i]$ 的第 $c$ 位是 $\text{cnt}(i,c) \bmod 2$。区间计数满足 $\text{cnt}(right+1,c) = \text{cnt}(left,c) + \text{cnt}(left..right, c)$，两边取模 2 得两个 0/1 值相加再取模，而这正是异或。故第 $c$ 位等于 $\text{cnt}(left..right, c) \bmod 2$。∎

**定理**：算法对每条查询返回 true，当且仅当该子串能在至多 $k$ 次替换后重排成回文。

**证明**：由引理 4，$\operatorname{popcount}(mask) = odd$ 正是子串中奇数计数字母的个数。由引理 3，最少替换次数为 $\lfloor odd/2 \rfloor$，因此「$k$ 次以内可以」等价于 $\lfloor odd/2 \rfloor \le k$，算法返回的正是该条件；由引理 1，达到该条件时回文确实可构造。∎

## 6. 复杂度分析

- **时间**：$O(n + q)$。建前缀表遍历一次字符串，每条查询做一次异或与一次 popcount；popcount 只涉及 26 位，视为常数（最多 26 次按位统计）。总时间线性。
- **空间**：$O(n)$。仅一个长度 $n+1$ 的整型前缀数组（外加 $O(q)$ 的输出数组）。掩码把 26 个计数压进一个整数，比「26 个前缀数组」的 $O(26n)$ 省一个数量级。

## 7. 参考代码

### C++

```cpp
#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    vector<bool> canMakePaliQueries(string s, vector<vector<int>>& queries) {
        int n = s.size();
        vector<int> pre(n + 1, 0);              // pre[i]：s[0..i-1] 的奇偶掩码
        for (int i = 0; i < n; ++i)
            pre[i + 1] = pre[i] ^ (1 << (s[i] - 'a'));

        vector<bool> ans;
        ans.reserve(queries.size());
        for (const auto& q : queries) {
            int mask = pre[q[1] + 1] ^ pre[q[0]];      // 区间内各字母计数的奇偶
            int odd = __builtin_popcount((unsigned)mask);
            ans.push_back(odd / 2 <= q[2]);            // 等价于 odd <= 2k+1
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def canMakePaliQueries(self, s: str, queries: list[list[int]]) -> list[bool]:
        n = len(s)
        pre = [0] * (n + 1)
        for i, ch in enumerate(s):
            pre[i + 1] = pre[i] ^ (1 << (ord(ch) - ord('a')))

        ans = []
        for left, right, k in queries:
            odd = bin(pre[right + 1] ^ pre[left]).count("1")  # 3.10+ 可换 int.bit_count()
            ans.append(odd // 2 <= k)
        return ans
```

## 8. 边界情况与易错点

1. **单字符子串**：`left == right` 时 $odd = 1$，$\lfloor 1/2 \rfloor = 0$，$k=0$ 也返回 true，符合「单字符本身就是回文」。
2. **$k$ 很大**：$k$ 可以取到 $n$，此时恒为 true；公式无需上界裁剪，也不会越界。
3. **$left = 0$**：务必用 $pre[right+1] \oplus pre[left]$ 的写法，若用 $pre[right] \oplus pre[left-1]$ 必须特判 $left=0$，否则数组下标 $-1$ 直接越界（C++ 是未定义行为，未必当场崩溃）。
4. **把「奇数计数个数」和「不同字母个数」混淆**：`"aaab"` 的不同字母数是 2，而 $odd = 2$（`a` 出现 3 次、`b` 出现 1 次）；`"aabb"` 的不同字母数也是 2，但 $odd = 0$。判据只认奇偶。
5. **长度奇偶不必单独判**：长度为偶数的子串 $odd$ 必为偶数，判定式会自动处理：$odd = 0$ 时恒真，$odd \ge 2$ 时要求 $k \ge 1$；再写一遍「偶数长度要求 $odd = 0$」只是重复劳动，容易和公式冲突。
6. **浮点除法**：$odd/2$ 在 Python 里得到 float，虽然不影响比较结果但语义不清；C++ 里若写成 $odd/2.0 \le k$ 也多余，整数除法即可。
7. **答案顺序**：`ans` 必须与 `queries` 一一对应，按输入顺序 push，不要因为预处理或排序打乱。
8. **`bit_count` 的版本**：`bin(mask).count("1")` 在任何版本都能跑；`int.bit_count()` 需要 3.10+（LeetCode 已满足，本地老解释器会报 `AttributeError`）。
