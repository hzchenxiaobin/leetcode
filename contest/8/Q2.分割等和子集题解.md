# LeetCode 分割等和子集 题解

## 1. 题目概述

- **标题 / 题号**：分割等和子集（#416，medium）
- **链接**：https://leetcode.cn/problems/partition-equal-subset-sum/
- **来源**：LeetCode 第 8 场周赛 Q2
- **难度**：中等
- **标签**：数组、动态规划、背包问题、0-1 背包

**题意**：给定一个只含**正整数**的非空数组 `nums`，判断能否把它划分成两个子集，使两个子集的元素和相等。这里的「划分」要求每个下标恰好属于其中一侧，同一个元素不能同时进入两边，也不能被拆开。

**约束**：

- $1 \le \text{nums.length} \le 200$
- $1 \le \text{nums}[i] \le 100$

由此总和 $S \le 2 \times 10^4$，半和 $\text{target} = S/2 \le 10^4$。这个「和的上界只有一万」的事实，是整道题从指数级暴搜走向伪多项式 DP 的关键。

## 2. 示例

**示例 1**

```text
输入：nums = [1,5,11,5]
输出：true
解释：可以分成 [1,5,5] 与 [11]，两边和都是 11。
```

**示例 2**

```text
输入：nums = [1,2,3,5]
输出：false
解释：总和 11 是奇数，两半和不可能相等，无论怎么分都不行。
```

**示例 3（补充边界）**

```text
输入：nums = [2,2,2]
输出：false
解释：总和 6，半和 3；但所有元素都是 2，凑不出 3，故无法平分。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的做法是枚举每个元素放进 A 还是 B，共 $2^n$ 种；$n = 200$ 时完全不可行。加排序、前缀和剪枝也只能缓解最坏情况，仍是指数级。

另一种「看起来聪明」的暴力是枚举所有子集和是否等于 $\text{target}$，本质一样是指数枚举。

> 💡 子集和问题是 NPC，**不存在多项式算法**；能过的只有以「和」为容量的**伪多项式** DP，复杂度 $O(n \cdot \text{target})$。

### 3.2 核心观察：转成 0-1 背包

![等和划分等价于凑出 S/2 的子集](images/wc8_q2_reduce_to_knapsack.svg)

两个观察把「划分」问题压成一个「凑和」问题：

1. **总和必须是偶数**。若两部分和相等，则 $S$ 等于两份相同整数之和，必为偶数；$S$ 为奇数时可以立刻返回 `false`。
2. **只需管一侧**。令 $\text{target} = S/2$，若存在子集 $A$ 的元素和恰为 $\text{target}$，那么它的补集 $B$ 的和为 $S - \text{target} = \text{target}$，两者天然构成合法划分；反之任何合法划分里，任取一侧的和都等于 $\text{target}$。于是

$$ \text{存在等和划分} \iff \text{存在子集元素和恰为 } \tfrac{S}{2} $$

而「每个元素最多选一次、问能否恰好装满容量 $\text{target}$」正是**0-1 背包的可行性问题**。

两个免费的剪枝：任一元素 $> \text{target}$ 时直接 `false`（它放哪一侧，那一侧的和都会超过 $\text{target}$）。

### 3.3 算法流程 / 状态转移

![dp 数组逆序更新：0-1 背包的一维写法](images/wc8_q2_dp_transition.svg)

定义 $dp[j]$（$0 \le j \le \text{target}$）为布尔值：用**已处理的前缀元素**能否恰好凑出和 $j$。

- 初始化：$dp[0] = \text{true}$（空集和为 0），其余为 `false`。
- 对每个元素 $x$，**逆序**枚举容量：

$$ dp[j] \leftarrow dp[j] \lor dp[j-x], \qquad j = \text{target}, \text{target}-1, \dots, x $$

- 每轮结束若 $dp[\text{target}]$ 已为真，提前返回 `true`；全部元素处理完仍为假则返回 `false`。

**为什么必须逆序**：写 $dp[j]$ 时读到的 $dp[j-x]$ 必须还是「上一轮」的旧值。由于 $j$ 从大到小枚举，位置 $j-x < j$ 尚未被本轮写过，所以读到的一定是旧值；若正序枚举，$dp[j-x]$ 可能刚被同一个 $x$ 更新，等价于让 $x$ 被重复选取，问题就退化成「完全背包」。

**为什么一维就够**：第 $i$ 轮只依赖第 $i-1$ 轮的数组，且状态只从 `false` 变成 `true`（单调），所以不需要滚动备份。

**位运算优化**：把整个 $dp$ 看成一个二进制整数 $bits$，第 $j$ 位表示 $dp[j]$，则一轮转移就是

$$ bits \leftarrow bits \ \lor\ (bits \ll x) $$

左移相当于「把所有可达和整体加上 $x$」，再与旧状态取或即可，答案取自第 $\text{target}$ 位。单轮代价从 $O(\text{target})$ 降到 $O(\text{target}/64)$（按机器字长并行），Python 的大整数天然支持这种写法。

### 3.4 示例演算

![数组 1 5 11 5 的 dp 表走查](images/wc8_q2_walkthrough.svg)

以 `nums = [1,5,11,5]` 为例，$S = 22$、$\text{target} = 11$：

| 轮次 | 处理元素 | 可达和集合 |
|------|----------|------------|
| 初始 | — | $\{0\}$ |
| 1 | 1 | $\{0,1\}$ |
| 2 | 5 | $\{0,1,5,6\}$ |
| 3 | 11 | $\{0,1,5,6,11,12,16,17\}$ |

第 3 轮出现了 11，即 $dp[11]$ 为真，返回 `true`；对应子集 $[11]$，补集 $[1,5,5]$ 的和同样是 11。

换成示例 2 的 `[1,2,3,5]`：$S = 11$ 为奇数，开头就返回 `false`，一轮 DP 都不用跑。

## 4. 算法细节

1. **先求总和并判奇偶**：一次 $O(n)$ 的求和同时得到 $S$ 与 $\text{target}$，奇数直接 `false`，不要等 DP 跑完。
2. **超界剪枝**：`max(nums) > target` 时直接 `false`；与奇偶判断配合，能挡掉大量非法输入。写在循环里（`if (x > target) return false`）同样正确，只是要扫到该元素才触发。
3. **逆序循环的下界是 $x$**：`for (int j = target; j >= x; --j)`，写成 `j >= 0` 会让 `j - x` 变成负下标；Python 的负下标不报错而是静默取到数组末尾，会制造极难发现的假 `true`。
4. **数组不必每轮清空或复制**：状态单调（只从 `false` 变 `true`），逆序又保证不会读到本轮的值，因此就地更新即可。
5. **提前返回**：每轮结束检查 $dp[\text{target}]$，为真立即 `return true`；示例 1 在第 3 轮就能结束。
6. **容器选型**：C++ 用 `vector<char>` 而不是 `vector<bool>`（后者是位压缩代理，读写都有额外开销）；`target ≤ 10000` 时数组只有 10 KB。
7. **位运算版**：C++ 可直接用 `bitset<10001>`，Python 用整数，两者都只需三行；注意 C++ 的 `bitset` 长度固定，查询下标必须 $\le 10000$，而 $\text{target} = S/2 \le 10^4$ 恒成立。
8. **求和不会溢出**：$S \le 200 \times 100 = 2\times10^4$，`int` / Python `int` 都安全，不需要 `long long`。

## 5. 正确性证明

**引理 1（奇偶性）**：若 $S$ 为奇数，则不存在等和划分。

**证明**：设划分为 $A, B$ 且 $\sum A = \sum B = t$，则 $S = \sum A + \sum B = 2t$ 为偶数，与 $S$ 为奇数矛盾。∎

**引理 2（超界元素）**：若存在元素 $x > \text{target} = S/2$，则不存在等和划分。

**证明**：$x$ 必属于 $A$ 或 $B$ 中的一侧，而两侧的和都恰为 $\text{target}$，故 $x \le \text{target}$，与 $x > \text{target}$ 矛盾。∎

**引理 3（DP 不变式）**：处理完前 $i$ 个元素后，$dp[j] = \text{true}$ 当且仅当存在 $\{\text{nums}[0], \dots, \text{nums}[i-1]\}$ 的子集，其元素和恰为 $j$。

**证明**：对 $i$ 归纳。$i = 0$ 时只有空集，和为 0，与 $dp[0] = \text{true}$、其余 `false` 一致。

设 $dp_{i-1}$ 满足结论，本轮处理 $x = \text{nums}[i-1]$，从 $j = \text{target}$ 递减到 $x$ 执行 $dp[j] \leftarrow dp[j] \lor dp[j-x]$。由于 $j$ 递减，此前被写过的位置都 $> j$，故 $j - x < j$ 处的值仍是 $dp_{i-1}[j-x]$（若 $j-x < x$ 则它根本不在本轮循环范围内，同样保持旧值）。于是本轮结束时

$$ dp_i[j] = dp_{i-1}[j] \ \lor\ \bigl(j \ge x \land dp_{i-1}[j-x]\bigr) $$

与标准二维转移一致。

- 若 $dp_i[j]$ 为真且由 $dp_{i-1}[j]$ 提供，由归纳假设存在不含 $x$ 的子集和为 $j$；
- 若由 $dp_{i-1}[j-x]$ 提供，取对应的子集并上 $x$，和恰为 $j$；
- 反向，任取前 $i$ 个元素的子集 $T$：若 $x \notin T$，由 $dp_{i-1}[j]$ 覆盖；若 $x \in T$，则 $T \setminus \{x\}$ 是前 $i-1$ 个元素的子集且和为 $j-x$，由归纳 $dp_{i-1}[j-x]$ 为真，本轮更新后 $dp_i[j]$ 为真。

故不变式成立。∎

**定理**：算法返回 `true` 当且仅当 `nums` 存在等和划分。

**证明**：

- ($\Leftarrow$) 若存在划分 $A, B$，则 $\sum A = \text{target}$。由引理 3，跑完全部元素后 $dp[\text{target}]$ 为真；而状态单调，它一旦为真就不会变回 `false`，所以无论是提前返回还是末尾返回，都返回 `true`。
- ($\Rightarrow$) 若算法返回 `true`，则某时刻 $dp[\text{target}]$ 为真，由引理 3 存在子集 $A$ 元素和为 $\text{target}$；其补集 $B$ 的和为 $S - \text{target} = \text{target}$，且 $A, B$ 覆盖所有下标，构成合法等和划分。

另外两个提前返回的分支：$S$ 为奇数时由引理 1 确实无解；存在超界元素时由引理 2 确实无解，都不会漏掉可行解。∎

## 6. 复杂度分析

- **时间**：$O(n \cdot \text{target}) = O(n \cdot S)$。求和 $O(n)$；DP 共 $n$ 轮，每轮最多 $\text{target}$ 次 $O(1)$ 转移，上限 $200 \times 10^4 = 2\times10^6$ 次操作。位运算版为 $O(n \cdot \text{target} / w)$，$w$ 为机器字长。
- **空间**：$O(\text{target})$，即 $O(S)$。一维数组长度 $\text{target}+1 \le 10001$；不需要二维表，因为每轮只依赖上一轮。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <bitset>
using namespace std;

class Solution {
public:
    bool canPartition(vector<int>& nums) {
        int total = 0;
        for (int x : nums) total += x;
        if (total & 1) return false;              // 和为奇数，无法平分
        int target = total / 2;
        vector<char> dp(target + 1, 0);
        dp[0] = 1;                                // 空集和为 0
        for (int x : nums) {
            if (x > target) return false;         // 超界元素，哪一侧都放不下
            for (int j = target; j >= x; --j)     // 逆序：每个元素最多用一次
                if (dp[j - x]) dp[j] = 1;
            if (dp[target]) return true;          // 已能凑出 target，提前结束
        }
        return dp[target];
    }

    // 位运算版：bits 的第 j 位表示 dp[j]，一轮转移就是 bits |= bits << x
    bool canPartitionBitset(vector<int>& nums) {
        int total = 0;
        for (int x : nums) total += x;
        if (total & 1) return false;
        bitset<10001> bits;
        bits[0] = 1;
        for (int x : nums) bits |= bits << x;
        return bits[total / 2];
    }
};
```

### Python

```python
from typing import List


class Solution:
    def canPartition(self, nums: List[int]) -> bool:
        total = sum(nums)
        if total & 1:                 # 和为奇数，两半不可能相等
            return False
        target = total // 2
        if max(nums) > target:        # 最大元素超过半和，放不进任何一侧
            return False

        dp = [False] * (target + 1)
        dp[0] = True                  # 空集凑出 0
        for x in nums:
            for j in range(target, x - 1, -1):   # 必须逆序，保证 x 只用一次
                if dp[j - x]:
                    dp[j] = True
            if dp[target]:            # 提前返回
                return True
        return dp[target]

    # 位运算版：大整数当 bitset，bits 的第 j 位表示 dp[j]
    def canPartitionBitset(self, nums: List[int]) -> bool:
        total = sum(nums)
        if total & 1:
            return False
        bits = 1
        for x in nums:
            bits |= bits << x
        return (bits >> (total // 2)) & 1 == 1
```

## 8. 边界情况与易错点

1. **和为奇数**：`[1,2,3,5]` 返回 `false`。这一步必须放在 DP 之前，否则会白跑一遍且最终结果仍错。
2. **单个元素超过半和**：`[100]` 的半和是 50，元素 100 放不进任何一侧，返回 `false`；靠 `max(nums) > target` 剪枝直接兜住，也顺带处理了 `n = 1` 的情况。
3. **元素全相等但个数为奇数**：`[2,2,2]` 的总和 6 是偶数，但半和 3 凑不出，返回 `false`。「和为偶数」只是必要条件，不能当充分条件用。
4. **逆序写成正序**：`nums = [2,3,3]`、$\text{target} = 4$ 时，正序会让同一个 2 被用两次从而误判为 `true`（正确答案是 `false`）。这是本题最经典的 WA。
5. **循环下界写成 0**：`j >= 0` 时 `dp[j-x]` 会取负下标；Python 会静默回绕到数组末尾，产生假 `true` 且极难排查，应写 `range(target, x - 1, -1)`。
6. **提前返回与末尾返回不一致**：若循环里 `return True`、末尾却漏了 `return dp[target]`，无解时会返回 `None`，被判为错误答案，务必两处都写。
7. **位运算版的位数**：C++ 的 `bitset` 长度必须是编译期常量，所以取题目上限 `bitset<10001>`，可用下标是 $0 \sim 10000$；而 $\text{target} = S/2 \le 10^4$ 恒成立，刚好够用。写成 `bitset<10000>` 会在 $S = 20000$、$\text{target} = 10000$ 时越界。
8. **`dp[0]` 的初值**：不能因为 `nums[i] >= 1` 就省掉 `dp[0] = true`，它是整个转移链的起点，少了它所有状态都是 `false`。
