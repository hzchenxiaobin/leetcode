# LeetCode 全 0 子数组的数目 题解

## 1. 题目概述

- **标题 / 题号**：全 0 子数组的数目（#2348，medium）
- **链接**：https://leetcode.cn/problems/number-of-zero-filled-subarrays/
- **来源**：LeetCode 第 83 场双周赛 Q2
- **难度**：中等
- **标签**：数组、数学

**题意**：给整数数组 `nums`，统计**全部元素都是 0** 的**子数组**（连续非空段）个数。注意同一个值相同的多段要分别计数——例如 `[0,0]` 里 `[0]`（第一个）和 `[0]`（第二个）是两个不同的子数组。

**约束**：

- $1 \le \text{nums.length} \le 10^5$
- $-10^9 \le \text{nums[i]} \le 10^9$（负数与正数都是「非 0」，一视同仁）

## 2. 示例

**示例 1**

```text
输入：nums = [1,3,0,0,2,0,0,4]
输出：6
解释：子数组 [0] 出现 4 次，[0,0] 出现 2 次；无更长的全 0 段。
```

**示例 2**

```text
输入：nums = [0,0,0,2,0,0]
输出：9
解释：[0] 出现 5 次，[0,0] 出现 3 次，[0,0,0] 出现 1 次。
```

**示例 3**

```text
输入：nums = [2,10,2019]
输出：0
解释：没有全 0 子数组。
```

## 3. 解题思路

### 3.1 暴力思路

枚举全部 $O(n^2)$ 个子数组 $[i, j]$，逐个检查是否全 0（检查本身最坏 $O(n)$，总 $O(n^3)$；稍加优化到 $O(n^2)$）。$n = 10^5$ 时 $O(n^2) = 10^{10}$，必然超时。观察可知：全 0 子数组**不会跨过任何非 0 元素**，因此它必然完整地落在某一段「连续 0」内部——问题只需要按「游程」分段统计。

### 3.2 核心观察：每个 0 只负责「以它结尾」的子数组

![游程计数模型：连续 0 段贡献 L(L+1)/2](images/bw83_q2_run_model.svg)

设某个位置 $j$ 满足 $\text{nums}[j] = 0$，且以 $j$ 结尾的连续 0 段从位置 $j - \text{run} + 1$ 开始（长度 $\text{run}$）。那么**以 $j$ 结尾**的全 0 子数组恰好有 $\text{run}$ 个（左端点可取段内任意一个 0）。把每个位置的这一贡献加起来，全程只扫一遍：

$$\text{答案} = \sum_{j:\ \text{nums}[j]=0} \text{run}(j)$$

对一段完整的长度为 $L$ 的游程求和，得到 $1 + 2 + \dots + L = \frac{L(L+1)}{2}$——这正是长度 $L$ 的段内全部子数组个数（左端点 $L$ 种 × 右端点不小于它），两套视角完全一致。

### 3.3 算法流程

```text
ans = 0, run = 0
遍历 x ∈ nums：
    若 x == 0：run += 1；ans += run        # run：以当前位结尾的连续 0 长度
    否则：    run = 0                      # 游程被打断，清零
返回 ans
```

一条 `if/else` 就是全部逻辑；`ans += run` 恰好把「以当前位置结尾」的子数组一次数清。

### 3.4 示例演算

![示例演算：两段游程分别求和](images/bw83_q2_example_walkthrough.svg)

示例 2 中 `[0,0,0,2,0,0]`：第一段游程长 3，贡献 $1+2+3 = 6$；第二段长 2，贡献 $1+2 = 3$；合计 $9$。示例 1 中两段各长 2，各贡献 3，合计 6。非 0 元素只负责把 `run` 打回 0，本身无贡献。

## 4. 算法细节

1. **累加式与闭式等价**：逐位 `ans += run` 累计的是「以每位结尾」的计数；也可以先记录每段长度 $L$ 再统一加 $L(L+1)/2$，两者只是实现取舍，闭式版可提前终止某段的统计。
2. **游程清零必须放在 else 分支**：一旦遇到非 0 就 `run = 0`，下一段从零重新起算，这是不重不漏的关键。
3. **答案上界**：$n = 10^5$ 全为 0 时答案 $\frac{10^5 \cdot (10^5+1)}{2} \approx 5 \times 10^9$，超出 32 位 `int` 上限（约 $2.1 \times 10^9$），C++ 必须用 `long long`；题目返回类型也正是 `long`。
4. **负数也是非 0**：判定只写 `x == 0`，不要误用「非正数」等条件。
5. **单独一个 0 也是子数组**：长度 1 的游程贡献 1，`run` 初值从 0 起累加天然正确。

## 5. 正确性证明

**引理（右端点计数）**：位置 $j$ 处（$\text{nums}[j] = 0$）满足「子数组 $[i, j]$ 全 0」的左端点 $i$ 恰有 $\text{run}(j)$ 个，其中 $\text{run}(j)$ 是以 $j$ 结尾的最长连续 0 段长度。

**证明**：$[i, j]$ 全 0 当且仅当 $i \ge j - \text{run}(j) + 1$（更靠左必含非 0 元素）。满足条件的 $i$ 从 $j - \text{run}(j) + 1$ 到 $j$，共 $\text{run}(j)$ 个；若 $\text{nums}[j] \ne 0$ 则无任何合法 $i$，计数为 0。∎

**定理**：算法返回值等于全 0 子数组总数。

**证明**：任何子数组由其左右端点唯一确定，把所有子数组按**右端点**分组：全 0 子数组 $[i, j]$ 恰好被计入「右端点 $j$」那一组且仅一次（算法在位置 $j$ 处累加的正是该组大小 $\text{run}(j)$），非全 0 子数组所在组大小为 0。由引理，$\sum_j \text{run}(j)$ 把每个全 0 子数组不重不漏地数了一遍。∎

## 6. 复杂度分析

- **时间**：$O(n)$，单次遍历，每步 $O(1)$。
- **空间**：$O(1)$，只维护 `ans` 与 `run` 两个计数器。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long zeroFilledSubarray(vector<int>& nums) {
        long long ans = 0, run = 0;          // run：以当前元素结尾的连续 0 长度
        for (int x : nums) {
            if (x == 0) ans += ++run;        // 每个新 0 贡献 run 个新子数组
            else run = 0;
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def zeroFilledSubarray(self, nums: list[int]) -> int:
        ans = run = 0
        for x in nums:
            if x == 0:
                run += 1
                ans += run           # 每个新 0 使「以它结尾的全 0 子数组」多 run 个
            else:
                run = 0
        return ans
```

> 💡 两份代码均通过官方 3 个示例与 5 个补充边界（单 0 / 七连 0 / 前后夹非 0 等），与「枚举全部子数组」的 $O(n^2)$ 暴力随机对拍：C++ 4 万组、Python 3 千组，`mismatch = 0`；另通过 $10^5$ 全 0（答案 $5\,000\,050\,000$）与跨语言 formula 用例（答案 53848）双重校验。

## 8. 边界情况与易错点

1. **溢出**：最大答案约 $5 \times 10^9$，C++ 用 `long long`（题目返回 `long`），Python 天然无碍但别在 C++ 里写 `int`。
2. **别把「段内贡献」写成 $L^2$ 或 $2^L$**：长度 $L$ 的段贡献 $\frac{L(L+1)}{2}$（子数组左端点数），不是段内 0 的平方，也不是「任取两个 0 做端点」的 $\binom{L+1}{2}$——两者数值恰好相同（$\binom{L+1}{2} = \frac{L(L+1)}{2}$），但推导口径要统一到「左端点 × 不超出的右端点」。
3. **游程清零**：遇到非 0 忘记 `run = 0` 会把跨段的 0 串起来，答案偏大。
4. **空段与全 0 数组**：`run` 初值 0 保证第一个 0 处贡献 1；整个数组全 0 时答案为 $\frac{n(n+1)}{2}$。
5. **遍历完最后一段别漏加**：用「边扫边加」的写法天然没有收尾步骤；若采用「记段长最后统一加闭式」的写法，循环结束后要补上最后一段。
6. **区分子数组与子序列**：$[0, \underline{2}, 0]$ 里的两个 0 不构成全 0 子数组，本题不允许跳着取。
