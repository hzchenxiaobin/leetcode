# LeetCode 减小数组使其满足条件的最小 K 值 题解

## 1. 题目概述

- **标题 / 题号**：减小数组使其满足条件的最小 K 值（#3824，medium）
- **链接**：https://leetcode.cn/problems/minimum-k-to-reduce-array-within-limit/
- **来源**：LeetCode 第 175 场双周赛 Q2
- **难度**：中等
- **标签**：数组、二分查找

**题意**：给定正整数数组 `nums`。对正整数 $k$ 定义 $\text{nonPositive}(nums, k)$ 为"让所有元素都变成**非正数**所需的最少操作次数"，一次操作是选一个下标把 $nums[i]$ 减去 $k$。求满足

$$\text{nonPositive}(nums, k) \le k^2$$

的**最小** $k$。

**约束**：

- $1 \le nums.length \le 10^5$
- $1 \le nums[i] \le 10^5$

> ⚠️ $k$ **没有上界**！$k$ 可以超过 $\max nums$——当数组全为 1 时，$k$ 只会被 $k^2 \ge n$ 这一侧限制。

## 2. 示例

**示例 1**

```text
输入：nums = [3,7,5]
输出：3
解释：k=3 时，操作次数 = ⌈3/3⌉ + ⌈7/3⌉ + ⌈5/3⌉ = 1 + 3 + 2 = 6 ≤ 9 = 3²。
      k=2 时次数 = 2+4+3 = 9 > 4，不达标；k=1 时 = 15 > 1。
```

**示例 2**

```text
输入：nums = [1]
输出：1
解释：k=1 时次数 = 1 ≤ 1，最小值就是 1。
```

## 3. 解题思路

### 3.1 暴力思路

从小到大枚举 $k = 1, 2, 3, \dots$，对每个 $k$ 花 $O(n)$ 算总次数，第一个满足就返回。正确但太慢：最坏答案可达 $\max(nums) \approx 10^5$，总复杂度 $O(n \cdot \max nums) = 10^{10}$。

不过"答案单调"这一性质提示了二分：**判定函数只有两种结果，且一旦为真就一直为真**。

### 3.2 核心观察：判定关于 $k$ 单调

![判定单调：总次数随 k 递减，而 k² 递增，越过交点后永远成立](images/bw175_q2_monotone.svg)

对单个元素，$\lceil nums[i] / k \rceil$ 关于 $k$ **单调不增**（分母变大，商变小）；求和保持单调不增：

$$f(k) = \sum_i \left\lceil \frac{nums[i]}{k} \right\rceil \quad\text{单调不增}$$

而 $k^2$ 严格递增，于是

$$g(k) = f(k) - k^2 \quad\text{严格递减}$$

因此"$g(k) \le 0$"的 $k$ 构成一个**后缀** $[k^*, +\infty)$，可以二分最小满足者。

**上界怎么取**：取 $k_0 = \max\big(\max nums,\ \lceil\sqrt{n}\rceil\big)$。因为 $k \ge \max nums$ 时每个 $\lceil nums[i]/k \rceil = 1$，故 $f(k_0) = n$；又 $k_0 \ge \lceil\sqrt n\rceil$ 保证 $k_0^2 \ge n \ge f(k_0)$，所以 $k_0$ 一定可行。答案必然 $\le k_0 \le 10^5$。

### 3.3 算法流程

```text
1. lo = 1，hi = max(max(nums), ceil(sqrt(n)))
2. while lo < hi:
       mid = (lo + hi) / 2
       若 f(mid) <= mid²（用 64 位）：hi = mid
       否则：lo = mid + 1
3. 返回 lo
```

### 3.4 示例演算

![示例演算：nums = [3,7,5] 在 k = 1..5 上的判定](images/bw175_q2_walkthrough.svg)

| $k$ | $\lceil 3/k\rceil$ | $\lceil 7/k\rceil$ | $\lceil 5/k\rceil$ | $f(k)$ | $k^2$ | 满足？ |
|-----|------|------|------|--------|-------|--------|
| 1 | 3 | 7 | 5 | 15 | 1 | ✗ |
| 2 | 2 | 4 | 3 | 9 | 4 | ✗ |
| 3 | 1 | 3 | 2 | **6** | 9 | ✓ |
| 4 | 1 | 2 | 2 | 5 | 16 | ✓ |
| 5 | 1 | 2 | 1 | 4 | 25 | ✓ |

$n = 3$，上界 $k_0 = \max(7, \lceil\sqrt 3\rceil) = 7$。二分在 $[1,7]$ 中落到 $k=3$。

## 4. 算法细节

1. **上界取 $\max(\max nums, \lceil\sqrt n\rceil)$**：只取 $\max nums$ 会错——全 1 数组的答案可能是 $\lceil\sqrt n\rceil > 1$。
2. **$\lceil a / b\rceil$ 用整数写法**：`(a + b - 1) / b`，避免浮点；Python 用 `(a + b - 1) // b` 或 `-(-a // b)`。
3. **64 位比较**：$k^2$ 最大 $10^{10}$，`int` 会溢出，C++ 用 `long long`（或把 $k$ 转成 `long long` 再乘）。
4. **二分边界**：`while (lo < hi)` + `hi = mid` 的写法保证返回最小可行值，不要写成 `lo = mid`（会死循环）。
5. **`f(k)` 提前剪枝**（可选）：累加过程中若已超过 $k^2$ 可直接返回 false，最坏情况仍是 $O(n)$。
6. **$f$ 单调的严格性**：$f$ 只是不增，但 $k^2$ 严格增，所以 $g$ 严格减，二分判定不会"平"。

## 5. 正确性证明

**引理 1（单点操作次数）**：把 $nums[i]$ 减到非正所需的最少操作次数是 $\lceil nums[i]/k \rceil$。

**证明**：$t$ 次操作后剩余 $nums[i] - tk$，需 $nums[i] - tk \le 0$，即 $t \ge nums[i]/k$；取最小整数 $t = \lceil nums[i]/k\rceil$。各元素互不影响，故总次数为求和。∎

**引理 2（判定单调）**：若 $f(k_1) \le k_1^2$ 且 $k_2 > k_1$，则 $f(k_2) \le k_2^2$。

**证明**：$f$ 不增故 $f(k_2) \le f(k_1) \le k_1^2 < k_2^2$。∎

**引理 3（上界可行）**：$k_0 = \max(\max nums, \lceil\sqrt n\rceil)$ 满足 $f(k_0) \le k_0^2$。

**证明**：$k_0 \ge \max nums$ ⇒ 每个 $\lceil nums[i]/k_0\rceil \le 1$ ⇒ $f(k_0) \le n$。又 $k_0 \ge \lceil\sqrt n\rceil$ ⇒ $k_0^2 \ge n \ge f(k_0)$。∎

**定理**：算法返回的 $lo$ 是满足条件的最小正整数 $k$。

**证明**：由引理 3，可行解集合非空且被 $[1, k_0]$ 覆盖。由引理 2，可行解集合是后缀，二分不变量"$hi$ 可行、$lo$ 左侧全不可行"在每步保持；循环结束时 $lo = hi$ 恰为最小可行值。∎

## 6. 复杂度分析

- **时间**：$O(n \log M)$，$M = \max(\max nums, \lceil\sqrt n\rceil) \le 10^5$，即约 $17 \times 10^5$ 次基本运算。
- **空间**：$O(1)$ 除输入外无额外空间。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minimumK(vector<int>& nums) {
        int n = nums.size();
        int mx = *max_element(nums.begin(), nums.end());
        // 上界：k >= mx 时每项只需 1 次操作，总次数 n <= k^2；再保证 k >= sqrt(n)
        int hi = max(mx, (int)sqrt((double)n) + 1);
        auto ok = [&](long long k) {
            long long cnt = 0;
            for (int v : nums) cnt += (v + k - 1) / k;
            return cnt <= k * k;
        };
        int lo = 1;
        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            if (ok(mid)) hi = mid;
            else lo = mid + 1;
        }
        return lo;
    }
};
```

### Python

```python
class Solution:
    def minimumK(self, nums: list[int]) -> int:
        n = len(nums)
        mx = max(nums)
        lo, hi = 1, max(mx, int(n ** 0.5) + 1)

        def ok(k: int) -> bool:
            cnt = 0
            for v in nums:
                cnt += (v + k - 1) // k
            return cnt <= k * k

        while lo < hi:
            mid = (lo + hi) // 2
            if ok(mid):
                hi = mid
            else:
                lo = mid + 1
        return lo
```

## 8. 边界情况与易错点

1. **$k$ 的上界别只取 $\max nums$**：`nums = [1,1,...,1]`（$n$ 很大）时，$k = 1$ 不满足，答案可能是 $\lceil\sqrt n\rceil$，超出 $\max nums$。
2. **`k*k` 溢出**：$k$ 最大 $10^5$，$k^2 = 10^{10}$ 超过 `int`；C++ 必须用 `long long`（或 `1LL * k * k`）。
3. **`ceil` 的整数写法**：`v / k` 是下取整，必须 `(v + k - 1) / k`；Python 里 `(v + k - 1) // k`。
4. **二分的收敛**：`hi = mid` 与 `lo = mid + 1` 配对，`mid` 用 `lo + (hi - lo) / 2` 防溢出。
5. **`nums` 只有一个元素且为 1**：答案 1（$1 \le 1$）。
6. **判定必须在 $k$ 侧取 64 位**：把 `mid`（`int`）直接平方会先溢出再比较，是典型隐性 bug。
7. **`sqrt` 的浮点误差**：`(int)sqrt(n) + 1` 取的是安全上界（略大不影响二分），不要用 `floor` 精确值去当答案。
