# LeetCode 反转一个字符串里的字母后反转特殊字符 题解

## 1. 题目概述

- **标题 / 题号**：反转一个字符串里的字母后反转特殊字符（#3823，easy）
- **链接**：https://leetcode.cn/problems/reverse-letters-then-special-characters-in-a-string/
- **来源**：LeetCode 第 175 场双周赛 Q1
- **难度**：简单
- **标签**：双指针、字符串、模拟

**题意**：给定由小写字母与特殊字符组成的字符串 $s$，**按顺序**做两件事：

1. 把串中所有**小写字母**拼成的子序列整体反转，放回原来字母占据的位置；
2. 把串中所有**特殊字符**拼成的子序列整体反转，放回原来特殊字符占据的位置。

返回最后得到的字符串。特殊字符仅来自集合 `"!@#$%^&*()"`。

**约束**：

- $1 \le s.length \le 100$
- $s$ 只含小写字母与 `"!@#$%^&*()"`

## 2. 示例

**示例 1**

```text
输入：s = ")ebc#da@f("
输出："(fad@cb#e)"
解释：字母序列 [e,b,c,d,a,f] 反转为 [f,a,d,c,b,e]，串先变 ")fad#cb@e("；
      特殊字符序列 [),#, @,( ] 反转为 [(,@,#,)]，最终 "(fad@cb#e)"。
```

**示例 2**

```text
输入：s = "z"
输出："z"
解释：只有一个字母、没有特殊字符，两步都不改变内容。
```

**示例 3**

```text
输入：s = "!@#$%^&*()"
输出：")(*&^%$#@!"
解释：没有字母，第二步等价于整体反转。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的三步：先把字母按出现顺序抽出来、反转；再把特殊字符抽出来、反转；最后按原串每一位"是字母就取反转后字母序列的下一个、否则取反转后特殊字符序列的下一个"填回去。时间复杂度 $O(n)$，这就是标准解。容易写错的地方是**两次反转的先后**：如果先反转特殊字符再反转字母，结果会不同吗？不会——两类位置互不相交，两次反转作用在不相交的字符集合上，可交换。但按题意顺序书写更不容易出错。

### 3.2 核心观察：两个独立的"位置槽"集合

![两类位置各自反转：字母槽与特殊字符槽互不干扰](images/bw175_q1_two_slots.svg)

把所有下标分成两个集合：

$$P_{\text{letter}} = \{i \mid s[i]\ \text{是小写字母}\}, \qquad P_{\text{other}} = \{i \mid s[i]\ \text{是特殊字符}\}$$

两步操作各自只在自己那个**有序位置集合**上做"首尾配对交换"，互不影响。因此也可以直接**双指针**同步做：左指针跳过不属于当前集合的位置，右指针同理，然后交换。两个集合各扫一遍，或一遍双指针处理两种字符，复杂度都是 $O(n)$。

### 3.3 算法流程

![算法流程：抽位置 → 反转字母 → 反转特殊字符](images/bw175_q1_algorithm_flow.svg)

```text
1. 收集 letterPos = 所有小写字母下标（升序）、otherPos = 其它下标（升序）
2. 对 letterPos 做首尾配对交换
3. 对 otherPos 做首尾配对交换
4. 返回结果串
```

### 3.4 示例演算

![示例演算：s = ")ebc#da@f(" 的两步反转](images/bw175_q1_walkthrough.svg)

| 步 | 字符序列 | 结果串 |
|----|----------|--------|
| 初始 | 字母 `[e,b,c,d,a,f]`，特殊 `[),#, @,(]` | `)ebc#da@f(` |
| 反转字母 | 字母变 `[f,a,d,c,b,e]` | `)fad#cb@e(` |
| 反转特殊 | 特殊变 `[(,@,#,)]` | `(fad@cb#e)` |

注意第一步之后字符 0（原 `)`）与字符 9（原 `(`）都还没动，它们是特殊字符，留给第二步。

## 4. 算法细节

1. **判定函数**：C++ 用 `s[i] >= 'a' && s[i] <= 'z'`（比 `isalpha` 更明确，也不会受 locale 影响）；Python 用 `'a' <= ch <= 'z'`。
2. **两次反转可交换**：两类下标集合不交，反转只重排各自集合内的字符，因此顺序无关；但题面写了顺序，按顺序实现即可。
3. **不要"先整体反转再原地挑"**：那会把另一类字符也带上，得到错误结果。
4. **原地修改**：C++ 可直接在 `string` 上 `swap`，$O(1)$ 额外空间；Python 先转 `list` 再 `"".join`。
5. **下标集合天然升序**：从左到右扫描得到的就是升序位置，无需排序。
6. **集合可能为空**：`otherPos` 为空时第 3 步什么都不做。

## 5. 正确性证明

**引理 1（位置集合划分）**：两个位置集合 $P_{\text{letter}}$ 与 $P_{\text{other}}$ 构成 $[0, n)$ 的一个划分。

**证明**：每个字符要么是小写字母，要么是特殊字符（题面限定字符集），故每个下标恰属于一个集合。∎

**引理 2（反转 = 首尾配对交换）**：对长度为 $m$ 的下标序列 $p_0 < p_1 < \cdots < p_{m-1}$，把 $s[p_0..p_{m-1}]$ 上的字符依序反转，等价于对所有 $k < m/2$ 交换 `s[p[k]]` 与 `s[p[m-1-k]]`。

**证明**：反转后位置 $p_k$ 处应是原位置 $p_{m-1-k}$ 的字符，交换一次即达成；每对只交换一次，中间元素（$m$ 为奇数时）保持不变，与反转的定义一致。∎

**引理 3（两步互不干扰）**：第二步反转特殊字符不会改变任何字母位置上的字符，第一步同理。

**证明**：第二步只交换 $P_{\text{other}}$ 内部的下标对，不触碰 $P_{\text{letter}}$ 中的位置；由引理 1 两个集合不交。∎

**定理**：算法输出等于按题意依次反转字母、反转特殊字符后的字符串。

**证明**：由引理 2，第 2、3 步分别精确实现了两次反转；由引理 3，两次反转互不破坏对方的结果，故最终串与题意要求的串逐位相同。∎

## 6. 复杂度分析

- **时间**：$O(n)$。收集两组位置一遍扫描，两次首尾配对合计不超过 $n/2 \times 2$ 次交换。
- **空间**：$O(n)$ 存两组位置（也可用双指针做到 $O(1)$ 额外空间，但常数更大）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    string reverseByType(string s) {
        vector<int> letterPos, otherPos;
        for (int i = 0; i < (int)s.size(); i++) {
            if (s[i] >= 'a' && s[i] <= 'z') letterPos.push_back(i);
            else otherPos.push_back(i);
        }
        for (int a = 0, b = (int)letterPos.size() - 1; a < b; a++, b--)
            swap(s[letterPos[a]], s[letterPos[b]]);
        for (int a = 0, b = (int)otherPos.size() - 1; a < b; a++, b--)
            swap(s[otherPos[a]], s[otherPos[b]]);
        return s;
    }
};
```

### Python

```python
class Solution:
    def reverseByType(self, s: str) -> str:
        a = list(s)
        letters = [i for i, ch in enumerate(a) if 'a' <= ch <= 'z']
        others = [i for i, ch in enumerate(a) if not ('a' <= ch <= 'z')]
        for pos in (letters, others):
            for i in range(len(pos) // 2):
                x, y = pos[i], pos[-1 - i]
                a[x], a[y] = a[y], a[x]
        return "".join(a)
```

## 8. 边界情况与易错点

1. **全是字母 / 全是特殊字符**：另一组为空，对应那一步空转（示例 3 是"全是特殊字符"）。
2. **只有一个字符**：`len(pos) // 2 == 0`，循环不执行。
3. **别把数字当特殊字符**：题面限定字符集只有小写字母与 `"!@#$%^&*()"`，但用 `isalnum` 之类的判定容易误判，建议显式区间比较。
4. **两次反转的顺序无关但不等于合并**：不能把"字母 + 特殊字符"一起反转。
5. **字符集含 `(` 与 `)`**：示例里的括号都是特殊字符，不要误认成"分组符号"。
6. **反转的配对边界**：`a < b` 而非 `a <= b`，否则中间字符会被换两次（对奇长度序列等价，但会多一次无用交换）。
