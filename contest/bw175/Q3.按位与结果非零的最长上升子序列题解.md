# LeetCode 按位与结果非零的最长上升子序列 题解

## 1. 题目概述

- **标题 / 题号**：按位与结果非零的最长上升子序列（#3825，medium）
- **链接**：https://leetcode.cn/problems/longest-strictly-increasing-subsequence-with-non-zero-bitwise-and/
- **来源**：LeetCode 第 175 场双周赛 Q3
- **难度**：中等
- **标签**：位运算、数组、动态规划

**题意**：求 `nums` 的一个**严格递增**子序列（保持相对顺序、非空），使其所有元素的**按位与**结果**非零**，返回最大长度；不存在则返回 0。

**约束**：

- $1 \le nums.length \le 10^5$
- $0 \le nums[i] \le 10^9$（即 $nums[i] < 2^{30}$）

## 2. 示例

**示例 1**

```text
输入：nums = [5,4,7]
输出：2
解释：[5,7] 严格递增，5 AND 7 = 5 ≠ 0；最长递增子序列 [4,7] 的与为 4，也合法，
      但长度同为 2。
```

**示例 2**

```text
输入：nums = [2,3,6]
输出：3
解释：[2,3,6] 严格递增，2 AND 3 AND 6 = 2 ≠ 0。
```

**示例 3**

```text
输入：nums = [0,1]
输出：1
解释：[0,1] 的与为 0；只能取单元素 [1]，其与为 1 ≠ 0。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有子序列（$2^n$），检验严格递增与按位与非零，复杂度指数级。即使改成 $O(n^2)$ 的 DP（$dp[i]$ = 以 $i$ 结尾的最长合法子序列），状态里也缺少"当前与值"这一维——与值有 $2^{30}$ 种可能，根本无法入状态。

### 3.2 核心观察：与结果非零 ⟺ 存在某一位被所有元素共享

![按位与非零等价于存在一位 b，所有元素在第 b 位都是 1](images/bw175_q3_bit_shared.svg)

**关键等价**：对任意非空集合 $S$，

$$\bigwedge_{x \in S} x \ne 0 \iff \exists\, b \in [0, 30),\ \forall x \in S,\ \text{bit}_b(x) = 1$$

证明是直白的：按位与的第 $b$ 位为 1，当且仅当所有元素的第 $b$ 位都为 1；与值非零就是"某一位为 1"。

于是问题被拆成**独立的 30 个子问题**：对每个二进制位 $b$，

1. 过滤出所有 `nums[i]` 第 $b$ 位为 1 的元素（保持原顺序）；
2. 在这个子序列上求**最长严格递增子序列（LIS）**的长度；

答案取 30 个结果的最大值。因为过滤后的子序列里所有元素共享第 $b$ 位，它们的按位与必然在第 $b$ 位上为 1，非零条件自动满足。

### 3.3 算法流程

![算法流程：对每个 bit 过滤 + 求 LIS](images/bw175_q3_algorithm_flow.svg)

```text
1. ans = 0
2. for b = 0 .. 29:
       tails = 空数组（LIS 的 patience 结构）
       for x in nums:
           若 x 的第 b 位为 0：跳过
           pos = lower_bound(tails, x)      # 严格递增用 lower_bound
           若 pos == len(tails): tails 追加 x
           否则：tails[pos] = x
       ans = max(ans, len(tails))
3. 返回 ans
```

**LIS 用 patience sorting（贪心 + 二分）**：`tails[k]` 表示"长度为 $k+1$ 的递增子序列的最小结尾值"，它关于 $k$ 单调递增，故可二分。严格递增必须用 `lower_bound`（等于时替换），非严格递增才用 `upper_bound`，这是本题最容易写错的细节。

### 3.4 示例演算

![示例演算：nums = [5,4,7] 在 b = 0 与 b = 2 上的两次 LIS](images/bw175_q3_walkthrough.svg)

以示例 1 的 `nums = [5,4,7]`（二进制 `101`、`100`、`111`）为例：

| $b$ | 过滤后 | 过程（`tails`） | LIS 长度 |
|-----|--------|------------------|----------|
| 0 | `[5, 7]` | `[5]` → `[5,7]` | 2 |
| 1 | `[]` | — | 0 |
| 2 | `[5, 4, 7]` | `[5]` → `[4]` → `[4,7]` | 2 |

取最大得 2，与示例一致。注意 $b=2$ 时虽然原序列不是递增的，LIS 依然能选出 `[4,7]` 或 `[5,7]`，长度 2。

## 4. 算法细节

1. **位数取 30**：$nums[i] \le 10^9 < 2^{30}$，扫 $b \in [0, 30)$ 即可；写成 31 也无害，只是多一次空转。
2. **严格递增用 `lower_bound`**：`bisect_left` / `lower_bound`；若用 `upper_bound` 会把相等元素也算进长度，得到"非严格递增"的答案。
3. **过滤不复制原数组**：直接在 `nums` 上判断位、按需喂给 LIS 结构，空间 $O(n)$ 级别的一次 `tails`。
4. **0 的处理**：`0` 没有任何位为 1，永远不会进入任何过滤序列；若全 0，答案 0。
5. **`tails` 每轮清空**：30 轮之间互不影响，注意不要在循环外复用未清空的容器。
6. **Python 用 `bisect_left`**，C++ 用 `lower_bound`；两者都是 $O(\log n)$。

## 5. 正确性证明

**引理 1（位共享判据）**：非空序列 $S$ 的按位与非零 $\iff$ 存在位 $b$ 使 $S$ 中所有元素第 $b$ 位均为 1。

**证明**：按位与的定义是逐位相与。若所有元素第 $b$ 位为 1，则结果的第 $b$ 位为 1，故非零；反之若结果非零，取结果的任一为 1 的位 $b$，则该位在结果中为 1 意味着每个元素该位都是 1。∎

**引理 2（子问题等价）**：设 $A_b$ 为 `nums` 中第 $b$ 位为 1 的元素构成的原序子序列，$L_b$ 为 $A_b$ 的最长严格递增子序列长度。则答案是 $\max_b L_b$。

**证明**：任取合法子序列 $S$（严格递增、与非零）。由引理 1 存在位 $b$ 使 $S$ 中元素第 $b$ 位全为 1，故 $S \subseteq A_b$ 且保持原序，于是 $|S| \le L_b \le \max_b L_b$。反向，取达到 $L_b$ 的递增子序列，它所有元素第 $b$ 位为 1，由引理 1 其与非零，故长度 $L_b$ 可达。两个方向给出等号。∎

**引理 3（patience 正确）**：上述 LIS 算法返回序列的最长严格递增子序列长度。

**证明**：经典结论。`tails` 关于下标单调递增；对每个元素 $x$，`lower_bound` 找到第一个 $\ge x$ 的位置 $p$，用 $x$ 替换它（或追加）。不变式："`tails[k]` 是当前已扫描前缀中长度为 $k+1$ 的严格递增子序列的最小可能结尾"。替换不会破坏不变式且使结尾更小（更有利于后续接续），追加当且仅当找到了更长的递增子序列。故扫描结束时 `len(tails)` 即 LIS 长度。∎

**定理**：算法返回按位与非零的最长严格递增子序列长度。

**证明**：由引理 2、3，第 $b$ 轮得到的 `len(tails)` 就是 $L_b$，取最大即答案。∎

## 6. 复杂度分析

- **时间**：$O(30 \cdot n \log n)$。每轮遍历 $n$ 个元素、每次二分 $O(\log n)$；$30 \times 10^5 \times 17 \approx 5 \times 10^7$ 次比较，可接受。
- **空间**：$O(n)$，仅 `tails` 数组（最坏长度 $n$），不保存过滤后的副本。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int longestSubsequence(vector<int>& nums) {
        int ans = 0;
        for (int b = 0; b < 30; b++) {
            vector<int> tails;          // 第 b 位为 1 的子序列上的 LIS 尾巴
            for (int v : nums) {
                if (((v >> b) & 1) == 0) continue;
                auto it = lower_bound(tails.begin(), tails.end(), v);
                if (it == tails.end()) tails.push_back(v);
                else *it = v;
            }
            ans = max(ans, (int)tails.size());
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def longestSubsequence(self, nums: list[int]) -> int:
        import bisect

        ans = 0
        for b in range(30):
            tails = []
            for v in nums:
                if not (v >> b) & 1:
                    continue
                i = bisect.bisect_left(tails, v)
                if i == len(tails):
                    tails.append(v)
                else:
                    tails[i] = v
            ans = max(ans, len(tails))
        return ans
```

## 8. 边界情况与易错点

1. **严格递增用 `lower_bound`**：用 `upper_bound` 会把重复值串起来，答案偏大。
2. **全 0 数组**：任何子序列的与都是 0，答案 0（没有非空合法子序列）。
3. **单元素**：长度为 1 的子序列其与就是元素本身，只要非零即合法；答案至少为 1（存在非零元素时）。
4. **位数上限**：$10^9 < 2^{30}$，扫到 30 足够；若扫到 31 也不出错，别扫到 20（会漏掉高位）。
5. **`tails` 复用**：每轮必须新建/清空，否则上一轮的尾巴会污染下一轮长度。
6. **过滤不改变相对顺序**：这是"子序列"的定义要求，直接顺序遍历天然满足，不要先排序。
7. **答案可能为 0**：当所有元素都是 0 时返回 0，不要初始化 `ans = 1`。
