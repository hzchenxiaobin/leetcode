# LeetCode 最小分割分数 题解

## 1. 题目概述

- **标题 / 题号**：最小分割分数（#3826，hard）
- **链接**：https://leetcode.cn/problems/minimum-partition-score/
- **来源**：LeetCode 第 175 场双周赛 Q4
- **难度**：困难
- **标签**：队列、数组、二分查找、分治、动态规划、前缀和、单调队列

**题意**：把数组 `nums` 分成**恰好 $k$ 个连续非空子数组**，一个子数组的**值**为

$$value(S) = \frac{S(S+1)}{2}, \qquad S = \text{子数组元素和}$$

一个分割方案的**分数**是各子数组值之和，求所有合法分割中的**最小分数**。

**约束**：

- $1 \le nums.length \le 1000$
- $1 \le nums[i] \le 10^4$
- $1 \le k \le nums.length$

> ⚠️ 分数可达 $5 \times 10^{13}$ 量级（全部元素一段时），C++ 必须用 `long long`。

## 2. 示例

**示例 1**

```text
输入：nums = [5,1,2,1], k = 2
输出：25
解释：[5] 的值 = 5·6/2 = 15，[1,2,1] 的和为 4、值 = 4·5/2 = 10，合计 25。
```

**示例 2**

```text
输入：nums = [1,2,3,4], k = 1
输出：55
解释：只能一段，和为 10，值 = 10·11/2 = 55。
```

**示例 3**

```text
输入：nums = [1,1,1], k = 3
输出：3
解释：唯一分法 [1]|[1]|[1]，每段值 1，合计 3。
```

## 3. 解题思路

### 3.1 暴力思路

设 $dp[t][i]$ 为"前 $i$ 个元素分成 $t$ 段的最小分数"，枚举最后一段的起点 $j$：

$$dp[t][i] = \min_{t-1 \le j < i} \Big( dp[t-1][j] + w(j, i) \Big), \qquad w(j,i) = \frac{S(S+1)}{2},\ S = pre[i] - pre[j]$$

复杂度 $O(k n^2)$，$n = k = 1000$ 时是 $10^9$，太慢。但注意 $w$ 只依赖区间和，且是**凸函数**——这类"分割型 DP + 凸代价"几乎总能套上**决策单调性**优化。

### 3.2 核心观察：代价满足四边形不等式，最优分割点单调

![分割型 DP：把最后一段的起点作为决策 j](images/bw175_q4_dp_model.svg)

记 $w(j,i) = f(pre[i]-pre[j])$，其中 $f(x) = x(x+1)/2$ 是**凸函数**。对 $a \le b \le c \le d$，令 $x_1 = pre[b]-pre[a]$、$x_2 = pre[c]-pre[b]$、$x_3 = pre[d]-pre[c]$（均 $\ge 0$），则四边形不等式

$$w(a,c) + w(b,d) \le w(b,c) + w(a,d)$$

等价于 $f(x_1+x_2) + f(x_2+x_3) \le f(x_2) + f(x_1+x_2+x_3)$。由 $f$ 的凸性，$f(x+z)-f(x)$ 关于 $x$ 单调不减，取 $x = x_1+x_2$、$z = x_3$ 与 $x = x_2$ 比较即得（见 §5 引理 2）。

由此可得**决策单调性**：记 $opt[t][i]$ 为 $dp[t][i]$ 的最优决策 $j$（取最小的那个），则

$$opt[t][i] \le opt[t][i+1]$$

于是每一层的 $n$ 个 DP 值可以用**分治优化**求出：`solve(l, r, optl, optr)` 先算 $mid = \lfloor (l+r)/2 \rfloor$，在 $[optl, \min(optr, mid-1)]$ 中暴力找最优 $j$，再分别递归左右两半（左半的决策上界收紧到 $opt(mid)$，右半的下界放宽到 $opt(mid)$）。

### 3.3 算法流程

![分治优化：每层 O(n log n) 求出整行 DP](images/bw175_q4_dnc_opt.svg)

```text
1. pre[i] = nums[0] + ... + nums[i-1]
2. prev[0] = 0，prev[1..n] = ∞
3. for t = 1 .. k:
       cur[0..n] = ∞
       用栈模拟分治：(t, n, t-1, n-1)
       每次取区间中点 mid，在 optl..min(optr, mid-1) 内找最优 j 算出 cur[mid]，
       并把 (l, mid-1, optl, best) 与 (mid+1, r, best, optr) 入栈
       prev = cur
4. 返回 prev[n]
```

**可行域**：$dp[t][i]$ 只在 $i \ge t$ 时有意义（每段至少 1 个元素），因此第 $t$ 层只需算 $i \in [t, n]$，决策 $j \in [t-1, i-1]$。

### 3.4 示例演算

![示例演算：nums = [5,1,2,1]、k = 2 的 DP 表](images/bw175_q4_walkthrough.svg)

`nums = [5,1,2,1]`，$pre = [0,5,6,8,9]$，$k=2$：

| $t$ \ $i$ | 0 | 1 | 2 | 3 | 4 |
|-----------|---|---|---|---|---|
| 0 | 0 | ∞ | ∞ | ∞ | ∞ |
| 1 | ∞ | 15 | 21 | 36 | 45 |
| 2 | ∞ | ∞ | 21 | 24 | **25** |

以 $dp[2][4]$ 为例，候选：

- $j=1$：$dp[1][1] + w(1,4) = 15 + \frac{4\cdot5}{2} = 25$；
- $j=2$：$dp[1][2] + w(2,4) = 21 + \frac{3\cdot4}{2} = 27$；
- $j=3$：$dp[1][3] + w(3,4) = 36 + \frac{1\cdot2}{2} = 37$。

取最小 25，对应分割 `[5] | [1,2,1]`，与示例一致。注意 $dp[2][4]$ 的最优决策是 1，而 $dp[2][3]$ 的最优决策是 1 或 2——决策随 $i$ 增大只右移，正是分治优化成立的前提。

## 4. 算法细节

1. **前缀和**：$pre$ 用 `long long`，区间和 $S = pre[i]-pre[j]$，$w = S(S+1)/2$ 也必须在 64 位下算（$S \le 10^7$，$S^2 \approx 10^{14}$）。
2. **分治的边界**：每次递归都要把决策区间裁到 $[optl, \min(optr, mid-1)]$，并且左子树上界为 `best`、右子树下界为 `best`。
3. **含 `INF` 的剪枝**：`prev[j] >= INF` 时跳过（$j < t-1$ 不可达）。
4. **`best` 初值**：先置 `INF`、`best = optl`，保证即使全部不可达也不会传下越界的 `optl`。
5. **迭代代替递归**：$n = 1000$ 时递归深度只有 $O(\log n)$，递归也可以；为统一风格这里用显式栈。
6. **`k = n` 时答案 = `sum(nums)`**：每段只有一个元素，$w = nums[i](nums[i]+1)/2$ 之和；算法自然给出同样结果，不必特判。
7. **`k = 1` 时答案** $= pre[n](pre[n]+1)/2$，同样是算法的退化情形。
8. **复杂度**：每层分治的候选枚举总量为 $O(n \log n)$，总 $O(k n \log n)$，$1000 \times 1000 \times 10 \approx 10^7$。

## 5. 正确性证明

**引理 1（DP 转移完备）**：$dp[t][i] = \min_{t-1 \le j < i}\big(dp[t-1][j] + w(j,i)\big)$ 对 $i \ge t \ge 1$ 成立（$dp[0][0]=0$，其余为 $\infty$）。

**证明**：任一 $t$ 段划分的最后一段必是 $[j, i)$（$j$ 唯一），去掉它得到前 $j$ 个元素的 $t-1$ 段划分，代价相加；反之任取 $j$ 与合法的 $t-1$ 段划分，补上 $[j,i)$ 得到合法 $t$ 段划分。双射即得。∎

**引理 2（四边形不等式）**：对 $a \le b \le c \le d$ 有 $w(a,c) + w(b,d) \le w(b,c) + w(a,d)$。

**证明**：记 $f(x) = x(x+1)/2$，$f$ 凸且 $f(x+z)-f(x)$ 关于 $x$ 单调不减（$f'$ 单调增，$f(x+z)-f(x) = \int_x^{x+z} f'(t)\,dt$）。令 $x_1 = pre[b]-pre[a]$、$x_2 = pre[c]-pre[b]$、$x_3 = pre[d]-pre[c]$，则原式等价于

$$f(x_1+x_2) + f(x_2+x_3) \le f(x_2) + f(x_1+x_2+x_3)$$

移项即 $f(x_1+x_2+x_3) - f(x_1+x_2) \ge f(x_2+x_3) - f(x_2)$，左边是 $\varphi(x_1+x_2)$、右边是 $\varphi(x_2)$（$\varphi(x) = f(x+x_3)-f(x)$ 单调不减），而 $x_1 + x_2 \ge x_2$，故成立。∎

**引理 3（决策单调）**：存在最优决策的选取使 $opt[t][i]$ 关于 $i$ 单调不降（取最小的最优 $j$）。

**证明**：设 $i < i'$，$a = opt[t][i]$，$b = opt[t][i']$，且反设 $a > b$。由最优性：

$$dp[t-1][a] + w(a,i) \le dp[t-1][b] + w(b,i), \qquad dp[t-1][b] + w(b,i') \le dp[t-1][a] + w(a,i')$$

两式相加得 $w(a,i) + w(b,i') \le w(b,i) + w(a,i')$。而由引理 2（取 $b \le a \le i \le i'$）有 $w(b,i) + w(a,i') \le w(a,i) + w(b,i')$。两式只能同时取等号，说明 $b$ 在 $i$ 处也最优，故"最小最优决策"应 $\le b < a$，与 $a$ 是最小者矛盾。∎

**引理 4（分治优化正确）**：若决策单调，则 `solve(l, r, optl, optr)`（保证 $opt[i] \in [optl, optr]$）能正确算出 $cur[l..r]$。

**证明**：对区间长度归纳。$mid$ 处的最优决策必在 $[optl, \min(optr, mid-1)]$ 内被枚举到（下界由 $j < mid$ 保证），故 $cur[mid]$ 正确，且 `best = opt[mid]`。对 $i < mid$，由引理 3 有 $opt[i] \le opt[mid] = best$，故左递归的区间 $[optl, best]$ 覆盖其最优决策；对 $i > mid$ 有 $opt[i] \ge best$，右递归同理。∎

**定理**：算法返回 $k$ 段划分的最小分数。

**证明**：对 $t$ 归纳。$t=0$ 只有 $dp[0][0]=0$ 正确。设第 $t-1$ 层全部正确，由引理 1、4，第 $t$ 层每个 $cur[i]$ 都取到了正确的最小值，故归纳成立；$t=k$ 时 $cur[n]$ 即答案。∎

## 6. 复杂度分析

- **时间**：$O(k\,n\log n)$。每层分治把决策枚举总量控制在 $O(n \log n)$（每层递归的候选区间总长 $O(n)$），共 $k$ 层。
- **空间**：$O(n)$。两个 DP 数组、前缀和、分治栈（深度 $O(\log n)$）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long minPartitionScore(vector<int>& nums, int k) {
        int n = nums.size();
        vector<long long> pre(n + 1, 0);
        for (int i = 0; i < n; i++) pre[i + 1] = pre[i] + nums[i];
        const long long INF = (long long)4e18;
        vector<long long> prev(n + 1, INF), cur(n + 1, INF);
        prev[0] = 0;
        for (int t = 1; t <= k; t++) {
            fill(cur.begin(), cur.end(), INF);
            // 决策单调：opt(i) 随 i 单调不降，用分治优化求出整层
            vector<tuple<int, int, int, int>> st;
            st.push_back({t, n, t - 1, n - 1});
            while (!st.empty()) {
                auto [l, r, optl, optr] = st.back();
                st.pop_back();
                if (l > r) continue;
                int mid = (l + r) / 2;
                int lim = min(optr, mid - 1);
                long long bestVal = INF;
                int best = optl;
                for (int j = optl; j <= lim; j++) {
                    if (prev[j] >= INF) continue;
                    long long s = pre[mid] - pre[j];
                    long long v = prev[j] + s * (s + 1) / 2;
                    if (v < bestVal) { bestVal = v; best = j; }
                }
                cur[mid] = bestVal;
                st.push_back({l, mid - 1, optl, best});
                st.push_back({mid + 1, r, best, optr});
            }
            swap(prev, cur);
        }
        return prev[n];
    }
};
```

### Python

```python
class Solution:
    def minPartitionScore(self, nums: list[int], k: int) -> int:
        n = len(nums)
        pre = [0] * (n + 1)
        for i, v in enumerate(nums):
            pre[i + 1] = pre[i] + v
        INF = 4 * 10 ** 18
        prev = [INF] * (n + 1)
        prev[0] = 0
        for t in range(1, k + 1):
            cur = [INF] * (n + 1)
            stack = [(t, n, t - 1, n - 1)]
            while stack:
                l, r, optl, optr = stack.pop()
                if l > r:
                    continue
                mid = (l + r) // 2
                lim = min(optr, mid - 1)
                best_val, best = INF, optl
                pm = pre[mid]
                for j in range(optl, lim + 1):
                    pj = prev[j]
                    if pj >= INF:
                        continue
                    s = pm - pre[j]
                    v = pj + s * (s + 1) // 2
                    if v < best_val:
                        best_val, best = v, j
                cur[mid] = best_val
                stack.append((l, mid - 1, optl, best))
                stack.append((mid + 1, r, best, optr))
            prev = cur
        return prev[n]
```

## 8. 边界情况与易错点

1. **溢出**：$w$ 可达 $5\times 10^{13}$，C++ 全程 `long long`；用 `int` 会在 $n$ 稍大时立刻出错。
2. **$k = 1$**：第一层直接给出整段值，注意 $dp[1][n]$ 的候选只有 $j=0$。
3. **$k = n$**：只能每段一个元素，答案 $= \sum nums[i](nums[i]+1)/2$。
4. **可行域 $i \ge t$**：$dp[t][i]$ 在 $i < t$ 时无意义，分治的初始区间必须是 $[t, n]$，否则会把 $\infty$ 当最优传下去。
5. **决策区间裁剪**：`lim = min(optr, mid-1)` 必须带上 `mid-1`，否则会枚举出"空段"。
6. **空段**：$j = mid$ 表示最后一段为空，非法，务必排除。
7. **`best` 的兜底**：若全部候选都是 `INF`，`best` 保持 `optl`，避免把非法值传给子递归。
8. **`nums[i] \ge 1`**：本题保证正数，前缀和严格递增；若允许负数或 0，代价不再凸，决策单调性会失效。
