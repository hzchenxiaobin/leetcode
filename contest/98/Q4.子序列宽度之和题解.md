# LeetCode 子序列宽度之和 题解

## 1. 题目概述

- **标题 / 题号**：子序列宽度之和（#891，hard）
- **链接**：https://leetcode.cn/problems/sum-of-subsequence-widths/
- **来源**：LeetCode 第 98 场周赛 Q4
- **难度**：困难
- **标签**：数组、数学、排序

**题意**：一个序列的**宽度**定义为「最大值 − 最小值」。给定数组 `nums`，求**所有非空子序列**的宽度之和，结果对 $10^9+7$ 取模。

**约束**：

- $1 \le n \le 10^5$
- $1 \le \text{nums}[i] \le 10^5$

## 2. 示例

**示例 1**

```text
输入：nums = [2,1,3]
输出：6
解释：7 个子序列及其宽度
     [1]→0，[2]→0，[3]→0，[2,1]→1，[2,3]→1，[1,3]→2，[2,1,3]→2
     总和 0+0+0+1+1+2+2 = 6。
```

**示例 2**

```text
输入：nums = [2]
输出：0
解释：只有一个子序列 [2]，宽度 0。
```

**示例 3（自造，说明重复值）**

```text
输入：nums = [5,5,5]
输出：0
解释：所有子序列的最大值、最小值都是 5，宽度恒为 0。
```

## 3. 解题思路

### 3.1 暴力思路

非空子序列共有 $2^n - 1$ 个，逐个枚举、求最大值与最小值、累加宽度。复杂度 $O(2^n \cdot n)$；$n = 10^5$ 时完全不可行（甚至 $n = 30$ 就已经很慢）。

枚举这条路走不通，必须把「对所有子序列求和」转化为「对每个元素的贡献求和」——这是组合计数类问题的标准套路。

### 3.2 核心观察：按元素算贡献

![排序后按元素计贡献](images/wc98_q4_contribution.svg)

**第一步：排序不改变答案。** 宽度只取决于子序列的**最大值与最小值**，与元素的相对顺序无关。而「所有子序列」这个集合在排序前后是一一对应的（子序列是选下标，排序后仍选同样多个元素）。所以可以先把 `nums` 升序排序，记排序后为 $a_0 \le a_1 \le \dots \le a_{n-1}$。

**第二步：把宽度拆成两部分。** 对任意子序列 $S$，

$$\text{width}(S) = \max(S) - \min(S)$$

于是

$$\sum_{S \ne \emptyset} \text{width}(S) = \underbrace{\sum_{S} \max(S)}_{\text{所有子序列最大值之和}} - \underbrace{\sum_{S} \min(S)}_{\text{所有子序列最小值之和}}$$

**第三步：数每个元素当了多少次最大值 / 最小值。** 排序后：

- $a_i$ 作为**最大值**：子序列必须包含 $a_i$，且其余元素只能从比它小的 $i$ 个元素里选（$a_0 \dots a_{i-1}$），每一个都可以选或不选，共 $2^i$ 种；
- $a_i$ 作为**最小值**：子序列必须包含 $a_i$，其余元素只能从比它大的 $n-1-i$ 个元素里选，共 $2^{n-1-i}$ 种。

因此

$$\text{答案} = \sum_{i=0}^{n-1} a_i \cdot \left(2^i - 2^{\,n-1-i}\right)$$

括号里的系数 $c_i = 2^i - 2^{n-1-i}$ 可以理解为「$a_i$ 在总和中被加了 $2^i$ 次、被减了 $2^{n-1-i}$ 次」。

![n = 5 的系数表](images/wc98_q4_coef_table.svg)

系数的符号很有意思：$i < \frac{n-1}{2}$ 时为负，$i = \frac{n-1}{2}$（$n$ 为奇数）时为 0，之后为正。这正对应「小元素更容易当最小值、大元素更容易当最大值」。

### 3.3 算法流程

```text
1. nums 升序排序
2. 预处理 pow2[0..n]：pow2[0] = 1，pow2[i] = pow2[i-1] * 2 % MOD
3. ans = 0
4. for i = 0 .. n-1:
5.     c = (pow2[i] - pow2[n-1-i]) mod MOD        # 负数先加 MOD
6.     ans = (ans + a[i] * c) mod MOD
7. 返回 ans
```

### 3.4 示例演算

![示例 2,1,3 的 7 个子序列](images/wc98_q4_example_enum.svg)

`nums = [2,1,3]` 排序后 $a = [1,2,3]$，$n = 3$。

| $i$ | $a_i$ | $2^i$ | $2^{n-1-i}$ | $c_i$ | 贡献 $a_i c_i$ |
|-----|-------|-------|-------------|-------|----------------|
| 0 | 1 | 1 | 4 | −3 | −3 |
| 1 | 2 | 2 | 2 | 0 | 0 |
| 2 | 3 | 4 | 1 | 3 | 9 |

答案 $= -3 + 0 + 9 = 6$，与枚举结果一致。

逐个核对含义：$a_0 = 1$ 当了 $2^0 = 1$ 次最大值（子序列 `[1]`）、$2^2 = 4$ 次最小值（`[1]`、`[2,1]`、`[1,3]`、`[2,1,3]`），净贡献 $1 - 4 = -3$；$a_2 = 3$ 当了 4 次最大值、1 次最小值，净贡献 $12 - 3 = 9$；$a_1 = 2$ 两者次数相同，抵消为 0。

## 4. 算法细节

1. **取模与负数**：C++ 中 `(pow2[i] - pow2[n-1-i]) % MOD` 可能为负，必须先 `+ MOD` 再取模；Python 的 `%` 天然返回非负，直接写即可。
2. **`pow2` 预计算**：$n \le 10^5$，预处理 $O(n)$ 次乘法，避免在循环里调用 `pow(2, i)`（$O(\log i)$）导致总复杂度多一个 log。
3. **乘积用 64 位**：$a_i \le 10^5$、$c_i < 2^{31}$，乘积可达 $10^{14}$，`int` 会溢出；C++ 用 `long long`，Python 无需担心。
4. **排序一次即可**：排序后所有下标关系固定，不需要额外的数据结构。
5. **重复元素**：排序后相等元素相邻，公式依然正确——见下方引理 2 的「最大下标」论证：每个子序列的最大值只会被记在「下标最大的那个最大值元素」上，恰好一次。
6. **最终再取模**：累加过程中每步取模即可（`ans = (ans + ...) % MOD`），Python 允许负数中间值，最后 `% MOD` 归正。

## 5. 正确性证明

**引理 1（排序不改变答案）**：设 $a$ 是 `nums` 升序排序后的数组，则两者的「所有非空子序列宽度之和」相等。

**证明**：排序是下标集合上的一个双射（把原下标按值重排）。对任一非空下标集合 $I$，它在原数组中对应的子序列宽度为 $\max_{i \in I} \text{nums}[i] - \min_{i \in I} \text{nums}[i]$，而在排序后数组中同样的下标集合对应的宽度为 $\max_{i\in I} a_i - \min_{i \in I} a_i$。因为 $a$ 是 `nums` 的重排，二者的最大值与最小值作为**数值**相同，故宽度相同。对所有 $I$ 求和即得结论。∎

**引理 2（贡献计数）**：在升序数组 $a$ 中，对每个 $i$，$a_i$ 作为「子序列最大值」出现的次数恰好是 $2^i$；作为「子序列最小值」出现的次数恰好是 $2^{n-1-i}$。

**证明**：设子序列非空。

- 若子序列的最大值等于 $a_i$，则必须包含下标 $i$，且不能包含任何 $j > i$（否则 $a_j \ge a_i$ 且下标更大，最大值应记在 $j$ 上）。因此可选元素只有 $a_0 \dots a_{i-1}$，每个可独立选或不选，方案数 $2^i$。注意这里用「最大值记在下标最大的那个元素上」来避免重复计数：当存在相等的值时，一个子序列仍只被记一次（记在它最大的下标上）。
- 对称地，最小值记在「下标最小的那个元素」上，此时可选元素只有 $a_{i+1} \dots a_{n-1}$，方案数 $2^{n-1-i}$。

∎

**定理**：$\displaystyle\sum_{S \ne \emptyset} \text{width}(S) = \sum_{i=0}^{n-1} a_i \left(2^i - 2^{n-1-i}\right)$。

**证明**：

$$\sum_{S} \text{width}(S) = \sum_{S} \left(\max(S) - \min(S)\right) = \sum_{S}\max(S) - \sum_{S}\min(S)$$

第一项按「最大值等于 $a_i$ 的子序列」分组：由引理 2，第 $i$ 组恰有 $2^i$ 个子序列、每个贡献 $a_i$，故 $\sum_S \max(S) = \sum_i a_i 2^i$。第二项同理为 $\sum_i a_i 2^{n-1-i}$。相减即得。再由引理 1，排序后求和与原数组相同。∎

## 6. 复杂度分析

- **时间**：$O(n \log n)$。排序是瓶颈；预处理 `pow2` 与累加各 $O(n)$。$n = 10^5$ 时约 $1.7 \times 10^6$ 次比较。
- **空间**：$O(n)$。`pow2` 数组 $O(n)$；若原地排序，除输入外只需 $O(n)$ 的辅助（Python 的 `sort()` 额外 $O(n)$）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int sumSubseqWidths(vector<int>& nums) {
        const long long MOD = 1000000007LL;
        sort(nums.begin(), nums.end());
        int n = nums.size();
        vector<long long> pow2(n + 1, 1);
        for (int i = 1; i <= n; i++) pow2[i] = pow2[i - 1] * 2 % MOD;
        long long ans = 0;
        for (int i = 0; i < n; i++) {
            long long coef = (pow2[i] - pow2[n - 1 - i] + MOD) % MOD;
            ans = (ans + nums[i] * coef) % MOD;
        }
        return (int)ans;
    }
};
```

### Python

```python
class Solution:
    def sumSubseqWidths(self, nums: list[int]) -> int:
        MOD = 10 ** 9 + 7
        nums.sort()
        n = len(nums)
        pow2 = [1] * (n + 1)
        for i in range(1, n + 1):
            pow2[i] = pow2[i - 1] * 2 % MOD
        ans = 0
        for i, v in enumerate(nums):
            ans = (ans + v * (pow2[i] - pow2[n - 1 - i])) % MOD
        return ans % MOD
```

## 8. 边界情况与易错点

1. **负数取模**：C++ 的 `%` 会保留负号，`pow2[i] - pow2[n-1-i]` 为负时直接取模得到负数，累加后答案错误。必须 `+ MOD` 再取模。
2. **整数溢出**：`nums[i] * coef` 是 `int * long long` 会提升为 `long long`，但要确保 `coef` 与 `nums[i]` 至少有一个是 64 位（代码里 `coef` 声明为 `long long` 即可）。
3. **$n = 1$**：系数 $2^0 - 2^0 = 0$，答案 0，与「只有一个子序列、宽度为 0」一致。
4. **全相同元素**：每个 $c_i$ 的正负贡献恰好抵消（对称位置 $2^i$ 与 $2^{n-1-i}$ 互换），最终答案为 0；不要因为中间出现负数就以为算错。
5. **重复元素不重不漏**：必须用「最大值记在最大下标、最小值记在最小下标」的约定来理解 $2^i$ / $2^{n-1-i}$，否则会误以为相等元素被重复计数。
6. **不要对每个子序列单独取模**：本题只对最终和取模，中间保持数学上的整数（Python 天然支持大整数；C++ 每步取模即可，因为取模对加法与乘法同余）。
7. **`pow2` 长度**：需要 $n+1$ 项（下标到 $n$），写成 `vector<long long> pow2(n + 1, 1)` 别忘了初值 1。
