# LeetCode 公平的糖果交换 题解

## 1. 题目概述

- **标题 / 题号**：公平的糖果交换（#888，easy）
- **链接**：https://leetcode.cn/problems/fair-candy-swap/
- **来源**：LeetCode 第 98 场周赛 Q1
- **难度**：简单
- **标签**：数组、哈希表、二分查找、排序

**题意**：爱丽丝有若干盒糖果 `aliceSizes`，鲍勃有若干盒 `bobSizes`。两人各拿出**一盒**交换，使交换后两人的糖果**总数相等**。返回 `[x, y]`（爱丽丝拿出的那盒数量、鲍勃拿出的那盒数量），多解返回任意一组。题目保证至少存在一组解。

设 $S_A = \sum \text{aliceSizes}$、$S_B = \sum \text{bobSizes}$，交换 $x$、$y$ 后要求

$$S_A - x + y = S_B - y + x$$

**约束**：

- $1 \le |\text{aliceSizes}|, |\text{bobSizes}| \le 10^4$
- $1 \le \text{aliceSizes}[i], \text{bobSizes}[j] \le 10^5$
- 两人的糖果总数**不同**（$S_A \ne S_B$）
- 保证至少存在一组有效答案

## 2. 示例

**示例 1**

```text
输入：aliceSizes = [1,1], bobSizes = [2,2]
输出：[1,2]
解释：S_A = 2，S_B = 4。交换 1 与 2 后：2 − 1 + 2 = 3，4 − 2 + 1 = 3，相等。
```

**示例 2**

```text
输入：aliceSizes = [1,2], bobSizes = [2,3]
输出：[1,2]
解释：S_A = 3，S_B = 5，交换后 3 − 1 + 2 = 4 = 5 − 2 + 1。
     [2,3] 也是一组合法解（交换后同样是 4），返回任意一组即可。
```

**示例 3**

```text
输入：aliceSizes = [2], bobSizes = [1,3]
输出：[2,3]
解释：S_A = 2，S_B = 4，交换后 2 − 2 + 3 = 3 = 4 − 3 + 2。
```

**示例 4**

```text
输入：aliceSizes = [1,2,5], bobSizes = [2,4]
输出：[5,4]
解释：S_A = 8，S_B = 6。x = 1 需要 y = 0（不存在），x = 2 需要 y = 1（不存在），
     只有 x = 5 对应 y = 4。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有 $(x, y)$ 组合（$x \in \text{aliceSizes}$，$y \in \text{bobSizes}$），检查交换后总和是否相等，第一组满足的就返回。复杂度 $O(|A| \cdot |B|)$，最坏 $10^8$ 次比较——在 Python 里必然超时，C++ 也很勉强。

关键在于：**给定 $x$，$y$ 其实已经被方程唯一确定**，根本不需要枚举 $y$。

### 3.2 核心观察：一个方程解出 y

![交换后总和相等 ⇔ 一个一次方程](images/wc98_q1_equation.svg)

把交换条件展开：

$$S_A - x + y = S_B - y + x \iff 2(x - y) = S_A - S_B \iff y = x - \frac{S_A - S_B}{2}$$

记 $\text{diff} = (S_A - S_B)/2$，则 **$y = x - \text{diff}$**。

于是算法变成：把 `bobSizes` 放进**哈希集合**，然后遍历 `aliceSizes` 中的每个 $x$，算出 $y = x - \text{diff}$，查它是否在集合里。命中即答案。

- 每个 $x$ 只做一次 $O(1)$ 查询，总时间 $O(|A| + |B|)$；
- 题目保证有解，所以循环一定能命中，不需要处理「找不到」的返回值（代码里仍留一个空返回兜底）。

![哈希集合里的一次性命中扫描](images/wc98_q1_scan_hit.svg)

### 3.3 算法流程

```text
1. sumA = sum(aliceSizes)，sumB = sum(bobSizes)
2. setB = 把 bobSizes 转成哈希集合
3. for x in aliceSizes:
4.     y2 = 2x − sumA + sumB          # 即 2y
5.     若 y2 是偶数 且 y2/2 ∈ setB:  返回 [x, y2/2]
6. （理论上不会走到这里）返回空
```

第 4 行用 `2x − sumA + sumB` 而不是 `x − (sumA − sumB)/2`，是为了**避免负数整除**：C++ 里 `-3 / 2 == -1`（向零取整），Python 里 `-3 // 2 == -2`（向下取整），两种语言的差异极易埋雷。先算 $2y$、判定奇偶后再整除，两种语言行为一致。

### 3.4 示例演算

**示例 1**：$S_A = 2$，$S_B = 4$。

| 步骤 | 值 |
|------|-----|
| `2x − sumA + sumB`，$x = 1$ | $2 - 2 + 4 = 4$，偶数，$y = 2$ |
| $2 \in \{2\}$？ | 是 → 返回 `[1, 2]` |

验证：爱丽丝变成 $2 - 1 + 2 = 3$，鲍勃变成 $4 - 2 + 1 = 3$。✓

**示例 4**：$S_A = 8$，$S_B = 6$。

| $x$ | $2x - 8 + 6$ | 偶数？ | $y$ | $y \in \{2,4\}$？ |
|-----|--------------|--------|-----|-------------------|
| 1 | 0 | 是 | 0 | 否（0 不是任何一盒） |
| 2 | 2 | 是 | 1 | 否 |
| 5 | 8 | 是 | 4 | **是 → 返回 [5, 4]** |

## 4. 算法细节

1. **哈希集合而非哈希表**：只需要「是否存在」，用 `unordered_set<int>` / `set` 即可，查询 $O(1)$。
2. **求和的类型**：$|A|, |B| \le 10^4$、每盒 $\le 10^5$，总和最大 $10^9$，`int` 尚可容纳，但 `2 * x` 与后续加减建议用 `long long`（C++），Python 无此问题。
3. **避免浮点**：不要写成 `diff = (sumA - sumB) / 2` 后再比较，整数除法在不同语言里对负数的行为不同；用「先算 $2y$、再判奇偶」的方式最稳。
4. **多解**：题目允许多解，因此不需要保证返回「字典序最小」之类的额外性质。示例 2 的 `[1,2]` 与 `[2,3]` 都合法。
5. **答案一定存在**：题面保证，所以循环体内一旦命中即可返回；末尾的空返回只是防御性代码。
6. **不排序也能过**：排序 + 双指针/二分同样可行（$O((|A|+|B|)\log)$），但哈希集合更直接。

## 5. 正确性证明

**引理 1（等价方程）**：对任意 $x \in A$、$y \in B$，交换后两人总数相等当且仅当 $2(x - y) = S_A - S_B$，即 $2y = 2x - S_A + S_B$。

**证明**：交换后爱丽丝为 $S_A - x + y$、鲍勃为 $S_B - y + x$。两者相等

$$S_A - x + y = S_B - y + x \iff S_A - S_B = 2x - 2y \iff 2y = 2x - (S_A - S_B)$$

两边同乘 2 后移项即得。∎

**引理 2（判定正确）**：对固定的 $x$，若 $2y = 2x - S_A + S_B$ 且 $y \in B$，则算法返回的 $[x, y]$ 是合法答案。

**证明**：$y$ 由方程唯一确定且确实属于 $B$（集合查询命中），由引理 1 交换后总数相等，故合法。∎

**定理**：若存在合法答案，算法一定能找到一组并返回；返回的一定合法。

**证明**：

- 返回值的合法性由引理 2 直接得到。
- 设存在合法答案 $(x^*, y^*)$，其中 $x^* \in A$、$y^* \in B$。由引理 1，$2y^* = 2x^* - S_A + S_B$，即 $2y^*$ 是偶数且 $y^* = (2x^* - S_A + S_B)/2 \in B$。算法遍历 $A$ 时必然经过 $x^*$，此时 `y2` 恰为 $2y^*$（偶数）且其一半 $y^*$ 在集合中，条件成立并返回。故不会漏解。

∎

> 注：若输入不满足「有解」的保证，$S_A - S_B$ 可能为奇数，此时任何 $x$ 都无法得到整数 $y$，算法会走完循环返回空——`y2 % 2 == 0` 的判断正是为此兜底。

## 6. 复杂度分析

- **时间**：$O(|A| + |B|)$。求两个和 $O(|A| + |B|)$；建哈希集合 $O(|B|)$（均摊）；遍历 $A$ 做至多 $|A|$ 次 $O(1)$ 查询。最坏 $10^4 + 10^4$ 次操作。
- **空间**：$O(|B|)$，哈希集合存储鲍勃的所有盒数（去重后不超过 $|B|$）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> fairCandySwap(vector<int>& aliceSizes, vector<int>& bobSizes) {
        long long sumA = 0, sumB = 0;
        for (int v : aliceSizes) sumA += v;
        for (int v : bobSizes) sumB += v;
        unordered_set<int> setB(bobSizes.begin(), bobSizes.end());
        for (int x : aliceSizes) {
            long long y2 = 2LL * x - sumA + sumB;
            if (y2 % 2 == 0 && setB.count((int)(y2 / 2))) {
                return {x, (int)(y2 / 2)};
            }
        }
        return {};
    }
};
```

### Python

```python
class Solution:
    def fairCandySwap(self, aliceSizes: list[int], bobSizes: list[int]) -> list[int]:
        sum_a, sum_b = sum(aliceSizes), sum(bobSizes)
        set_b = set(bobSizes)
        for x in aliceSizes:                     # x 是爱丽丝拿去交换的那盒
            y2 = 2 * x - sum_a + sum_b           # 2y = 2x - sumA + sumB
            if y2 % 2 == 0 and y2 // 2 in set_b:
                return [x, y2 // 2]
        return []
```

## 8. 边界情况与易错点

1. **负数整除的语义差异**：Python 的 `//` 向下取整、C++ 的 `/` 向零取整。若先算 `diff = (sumA - sumB) // 2` 再 `y = x - diff`，两个语言在 `sumA < sumB` 时会给出不同结果。用「$2y$ + 判奇偶」的写法可以彻底规避。
2. **$y$ 可能为 0 或负数**：集合里只有正数盒数，因此这些情况会被自动排除；不要额外加 `y > 0` 之外的特殊判断（除非数组包含 0）。
3. **返回值顺序**：`answer[0]` 必须来自爱丽丝、`answer[1]` 必须来自鲍勃。写反了在数值相等时（如 `[1,1]` 对 `[1,1]`）可能看起来也对，但一般会 WA。
4. **不要假设唯一解**：示例 2 有两组解；对拍时若直接和示例输出比对，需要通过「交换后总和相等」来校验而不是逐位比较。
5. **总和相同的情况**：题面保证 $S_A \ne S_B$，但若两者相等，交换任意两盒相同数量也能满足，算法仍会返回一组合法解（`y2 = 2x`）。
6. **`return {}` 的兜底**：Python 返回 `[]`、C++ 返回空 vector，都不是合法答案，仅用于让函数在异常输入下有返回值；正常测试数据不会触发。
