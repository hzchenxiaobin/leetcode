# LeetCode 从前序与后序遍历序列构造二叉树 题解

## 1. 题目概述

- **标题 / 题号**：从前序与后序遍历序列构造二叉树（#889，medium）
- **链接**：https://leetcode.cn/problems/construct-binary-tree-from-preorder-and-postorder-traversal/
- **来源**：LeetCode 第 98 场周赛 Q3
- **难度**：中等
- **标签**：树、数组、哈希表、分治、二叉树

**题意**：给定同一棵二叉树的**前序遍历** `preorder` 与**后序遍历** `postorder`（节点值互不相同），还原这棵二叉树。若存在多个答案，返回其中**任意一个**。

**约束**：

- $1 \le \text{preorder.length} \le 30$
- $1 \le \text{preorder}[i] \le n$，`preorder` 中所有值互不相同
- `postorder.length == preorder.length`，`postorder` 中所有值互不相同
- 保证两个序列是同一棵二叉树的前序/后序遍历

## 2. 示例

**示例 1**

```text
输入：preorder = [1,2,4,5,3,6,7], postorder = [4,5,2,6,7,3,1]
输出：[1,2,3,4,5,6,7]
解释：根 1，左子树 {2,4,5}，右子树 {3,6,7}；层序即 [1,2,3,4,5,6,7]。
```

**示例 2**

```text
输入：preorder = [1], postorder = [1]
输出：[1]
解释：只有一个节点，直接返回。
```

**示例 3（自造，说明「多解」）**

```text
输入：preorder = [1,2], postorder = [2,1]
输出：[1,2,null] 或 [1,null,2] 均可
解释：根 1 只有一个孩子 2，前序/后序都无法区分它是左孩子还是右孩子——
     这正是本题允许返回任意解的原因。
```

## 3. 解题思路

### 3.1 暴力思路

暴力做法是「枚举分界点」：前序的第二个元素可能是根的左孩子，也可能是（当左子树为空时）右孩子；于是递归地尝试每一种可能的子树划分，把所有能对上的树都构造出来。划分方式的数量是卡特兰数量级，递归里还要反复扫描数组定位根，复杂度可达 $O(n \cdot \text{Catalan}(n))$，对 $n = 30$ 完全不可行。

而且这条路没有必要——题目只要**任意一个**解，不需要枚举全部解。

### 3.2 核心观察：前序第二个元素 + 后序下标 ⇒ 左子树大小

![前序/后序的切分：左子树大小由后序决定](images/wc98_q3_split.svg)

两个事实定乾坤：

1. **根是谁**：`preorder` 的第一个元素与 `postorder` 的最后一个元素都是根，二者必相等。
2. **左子树的根是谁**：当子树节点数 $\ge 2$ 时，`preorder` 的第二个元素 `pre[preL+1]` 一定是「根的第一个非空孩子」子树的根。由于前序是「根 → 左 → 右」，若左子树非空，它就是左子树的根；若左子树为空，它就是右子树的根。

找到了左子树的根 `leftRoot`，再在 `postorder` 里查它的下标 `pos[leftRoot]`。后序是「左 → 右 → 根」，左子树的所有节点都排在根的左边，且以 `leftRoot` 结尾，于是

$$\text{leftSize} = \text{pos}[\text{leftRoot}] - \text{postL} + 1$$

- 若左子树非空：`leftSize` 恰好是左子树的节点数；
- 若左子树为空（只有右孩子）：`pos[leftRoot]` 会落在整个区间的末尾，算出的 `leftSize` 等于「除根以外的全部节点数」，于是这段被当作左子树、右子树为空——构造出的树与原树不同，但**前序/后序完全一致**，仍是合法答案。

这正是本题「可以返回任意解」的用武之地。

![递归时只需传三个下标](images/wc98_q3_ranges.svg)

### 3.3 算法流程

```text
1. 建立哈希表 pos：值 → 在 postorder 中的下标
2. build(preL, preR, postL):
3.     若 preL > preR: 返回 None
4.     root = 新节点(preorder[preL])
5.     若 preL == preR: 返回 root
6.     leftRoot = preorder[preL + 1]
7.     leftSize = pos[leftRoot] - postL + 1
8.     root.left  = build(preL + 1, preL + leftSize, postL)
9.     root.right = build(preL + leftSize + 1, preR, postL + leftSize)
10.    返回 root
11. 返回 build(0, n - 1, 0)
```

注意：只传 `preL`、`preR`、`postL` 三个下标就够了——后序区间的右端点可以由「节点数 = preR − preL + 1」推出，不必额外传参。

### 3.4 示例演算

![示例 1 重建出的树](images/wc98_q3_rebuilt.svg)

`preorder = [1,2,4,5,3,6,7]`，`postorder = [4,5,2,6,7,3,1]`。

| 步骤 | 内容 | 值 |
|------|------|-----|
| 1 | 根 | `pre[0] = 1`（即 `post[6] = 1` ✓） |
| 2 | 左子树的根 | `pre[1] = 2` |
| 3 | `2` 在后序中的下标 | 2 |
| 4 | 左子树大小 | $2 - 0 + 1 = 3$ |
| 5 | 左子树区间 | 前序 `[1..3] = [2,4,5]`，后序 `[0..2] = [4,5,2]` |
| 6 | 右子树区间 | 前序 `[4..6] = [3,6,7]`，后序 `[3..5] = [6,7,3]` |
| 7 | 递归 | 左：根 2，左 4，右 5；右：根 3，左 6，右 7 |

最终得到 `1` 的左孩子 `2`（`4`、`5`）、右孩子 `3`（`6`、`7`），层序为 `[1,2,3,4,5,6,7]`。

## 4. 算法细节

1. **`pos` 哈希表**：值 → 后序下标，避免每次递归线性查找，把定位降到 $O(1)$。值域是 $[1, n]$，也可以用数组直接映射。
2. **三个下标而非六个**：后序区间右端点恒为 `postL + (preR - preL)`，少传参数不容易错。
3. **`preL == preR` 提前返回**：叶子节点没有「第二个元素」，若继续访问 `pre[preL+1]` 会越界。
4. **递归深度**：最坏是链状树，深度 $n \le 30$，远低于语言栈限制；$n$ 放大到 $10^5$ 时应改为显式栈或迭代。
5. **不必校验 `post[postL + len - 1] == root`**：题面保证输入合法；若想更稳健，可以加一次断言帮助调试。
6. **允许非唯一**：只有单孩子的节点会产生歧义，本算法统一把这种情况解释成「左孩子」，因此每个输入都能产出一棵合法树。

## 5. 正确性证明

设 $\text{pre}[l..r]$ 与 $\text{post}[p..p+len-1]$（$len = r - l + 1$）分别是某棵子树的前序与后序。

**引理 1（根的位置）**：该子树的根是 $\text{pre}[l]$，也是 $\text{post}[p+len-1]$，且两者相等。

**证明**：前序遍历第一个访问的就是根；后序遍历最后访问的也是根。二者都是同一棵子树的根，故相等。∎

**引理 2（左块划分）**：当 $len \ge 2$ 时，令 $u = \text{pre}[l+1]$、$k = \text{pos}[u] - p + 1$。则 $\text{pre}[l+1..l+k]$ 与 $\text{post}[p..p+k-1]$ 恰是同一棵子树的两种遍历，$\text{pre}[l+k+1..r]$ 与 $\text{post}[p+k..p+len-2]$ 恰是另一棵子树的两种遍历（可能为空）。

**证明**：根的孩子中，**最左边的非空子树**在前序中紧随根之后，即其根为 $\text{pre}[l+1] = u$；在后序中，这棵子树的所有节点也排在最前面（因为后序先左、再右、最后根，且左侧没有别的子树）。设该子树有 $k$ 个节点，则它的后序区间是 $\text{post}[p..p+k-1]$，并以该子树的根结尾，即 $\text{pos}[u] = p + k - 1$，故 $k = \text{pos}[u] - p + 1$。它的前序区间是 $\text{pre}[l+1..l+k]$（前序遍历中一棵子树占据连续的一段，长度为 $k$）。剩余节点构成根的另一个孩子（若存在），在前序与后序中都紧随其后，长度均为 $len - 1 - k$。∎

**定理**：`build(preL, preR, postL)` 返回的树，其前序遍历恰为 `preorder[preL..preR]`、后序遍历恰为 `postorder[postL..postL+len-1]`。

**证明**：对 $len$ 归纳。

**基础**：$len = 1$ 时返回单节点树，前序、后序都是该节点，成立。

**归纳**：设 $len \ge 2$。由引理 1，根取 $\text{pre}[preL]$ 正确。由引理 2，第 8、9 行的两个递归调用作用在两段合法的「前序 + 后序」子区间上，长度分别为 $k$ 与 $len-1-k$，都严格小于 $len$，故由归纳假设，返回的两棵子树 $T_L, T_R$ 的前序/后序分别等于对应区间。把它们组装成 $T = \text{root}(T_L, T_R)$：

$$\text{preorder}(T) = [\text{root}] + \text{preorder}(T_L) + \text{preorder}(T_R) = \text{pre}[preL..preR]$$

$$\text{postorder}(T) = \text{postorder}(T_L) + \text{postorder}(T_R) + [\text{root}] = \text{post}[postL..postL+len-1]$$

两者都成立，归纳完成。∎

**推论**：算法返回的树一定是合法答案（其前序/后序与输入一致），即使原树在单孩子节点处的左右归属不同。

## 6. 复杂度分析

- **时间**：$O(n)$。建 `pos` 表 $O(n)$；`build` 的每个节点被创建一次，每次递归只做常数次哈希查询与下标运算，总调用 $O(n)$ 次。
- **空间**：$O(n)$。`pos` 哈希表 $O(n)$，递归栈深度 $O(h) \le O(n)$，返回的树本身 $O(n)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    TreeNode* constructFromPrePost(vector<int>& preorder, vector<int>& postorder) {
        unordered_map<int, int> pos;
        for (int i = 0; i < (int)postorder.size(); i++) pos[postorder[i]] = i;
        int n = preorder.size();
        function<TreeNode*(int, int, int)> build = [&](int preL, int preR, int postL) -> TreeNode* {
            if (preL > preR) return nullptr;
            TreeNode* root = new TreeNode(preorder[preL]);
            if (preL == preR) return root;
            int leftRoot = preorder[preL + 1];
            int leftSize = pos[leftRoot] - postL + 1;
            root->left = build(preL + 1, preL + leftSize, postL);
            root->right = build(preL + leftSize + 1, preR, postL + leftSize);
            return root;
        };
        return build(0, n - 1, 0);
    }
};
```

### Python

```python
# TreeNode 由平台提供，定义为：val / left / right
class Solution:
    def constructFromPrePost(self, preorder: list[int], postorder: list[int]) -> "TreeNode":
        pos = {v: i for i, v in enumerate(postorder)}

        def build(pre_l: int, pre_r: int, post_l: int) -> "TreeNode":
            if pre_l > pre_r:
                return None
            root = TreeNode(preorder[pre_l])
            if pre_l == pre_r:                 # 只有一个节点
                return root
            left_root = preorder[pre_l + 1]     # 左子树的根
            left_size = pos[left_root] - post_l + 1
            root.left = build(pre_l + 1, pre_l + left_size, post_l)
            root.right = build(pre_l + left_size + 1, pre_r, post_l + left_size)
            return root

        return build(0, len(preorder) - 1, 0)
```

## 8. 边界情况与易错点

1. **单节点子树**：`preL == preR` 时必须提前返回，否则 `preorder[preL + 1]` 越界（C++ 是 UB、Python 抛 `IndexError`）。
2. **左子树为空**：此时 `pre[preL+1]` 是右子树的根，算出的 `leftSize` 会让整段剩余节点都归到「左子树」，右子树为空。这是合法答案，不要试图「纠正」它。
3. **后序区间右端点**：不要另外维护 `postR`，用 `postL + (preR - preL)` 推出即可；两处下标不同步是最常见的错解来源。
4. **用值当哈希键**：题面保证值互不相同，因此 `pos[值] = 后序下标` 是安全的；若值可能重复，必须改用其他定位方式（本题不适用）。
5. **`function` 递归的捕获**：C++ 用 `std::function` 写递归 lambda 时要按引用捕获 `pos`、`preorder`、`postorder`，否则每次递归拷贝会变慢甚至出错。
6. **返回 `nullptr`**：递归边界返回空指针，父节点接上即可；`new TreeNode(...)` 的内存由判题系统管理，不必手动释放。
7. **不要用中序**：本题只有前序 + 后序，无法像「前序 + 中序」那样唯一确定结构，因此不可能构造出唯一解——理解这一点才能接受「任意解」。
