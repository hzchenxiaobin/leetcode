# LeetCode 查找两棵二叉搜索树之和 题解

## 1. 题目概述

- **标题 / 题号**：查找两棵二叉搜索树之和（#1214，medium）
- **链接**：https://leetcode.cn/problems/two-sum-bsts/
- **来源**：LeetCode 第 10 场双周赛 Q2
- **难度**：中等
- **标签**：树、二叉搜索树、深度优先搜索、双指针

**题意**：给定两棵**二叉搜索树** `root1` 和 `root2` 与整数 `target`。若存在一棵树中的某节点与另一棵树中的某节点，其**值之和等于** `target`，返回 `true`；否则返回 `false`。

**约束**：

- 每棵树至多 5000 个节点
- $-10^9 \le target, node.val \le 10^9$

## 2. 示例

**示例 1**

```text
输入：root1 = [2,1,4], root2 = [1,0,3], target = 5
输出：true
解释：root1 中的 2 与 root2 中的 3 之和为 5。
```

**示例 2**

```text
输入：root1 = [0,-10,10], root2 = [5,1,7,0,2], target = 18
输出：false
```

**示例 3（补充）**

```text
输入：root1 = [1], root2 = [1], target = 2
输出：true
解释：1 + 1 = 2。
```

## 3. 解题思路

### 3.1 暴力思路

把两棵树的节点值全部收集出来，问题退化为「两个无序数组中找和为 target 的数对」：

- 双重循环 $O(n_1 n_2) = 5000 \times 5000 = 2.5 \times 10^7$ 次，勉强能过但丑陋；
- 哈希集合：一棵树的值入集合，遍历另一棵树查 `target - v`，$O(n_1 + n_2)$ 平均，但最坏哈希退化、且无视了 BST 的结构性质；
- 对 tree1 的每个值在 tree2 做 **BST 查找**：$O(n_1 \cdot h_2)$，树平衡时 $O(n_1 \log n_2)$，退化成链时仍是 $O(n_1 n_2)$。

### 3.2 核心观察：中序遍历把两棵 BST 变成两条有序带 → 首尾双指针

![核心观察：中序收集 + 首尾双指针](images/bw10_q2_bst_two_pointer_model.svg)

BST 的招牌性质：**中序遍历严格（非降）递增**。于是：

1. 对两棵树各做一次中序遍历，得到升序数组 $a$（长度 $n_1$）与 $b$（长度 $n_2$）；
2. 问题变为「两个**有序**数组中找和为 target 的数对」——这正是 [167. 两数之和 II](https://leetcode.cn/problems/two-sum-ii-input-array-is-sorted/) 的场景：**一个指针从头、一个从尾**：
   - $a[i] + b[j] < target$：和太小，$i$ 右移（$b[j]$ 已经是 $b$ 中当前可选的最大者，$a[i]$ 无可救药，排除）；
   - $a[i] + b[j] > target$：和太大，$j$ 左移；
   - 相等即命中。

整个过程 $O(n_1 + n_2)$ **严格线性**（无哈希、无退化），且一旦命中立刻返回。相比哈希法，它把「有序」这一题面赠送的性质真正用满。

### 3.3 算法流程

![算法流程：中序收集后首尾夹逼](images/bw10_q2_algorithm_flow.svg)

```text
1. 中序遍历 root1 得升序数组 a；中序遍历 root2 得升序数组 b
2. i = 0（a 的头部），j = len(b) - 1（b 的尾部）
3. 当 i < len(a) 且 j >= 0：
   3.1 s = a[i] + b[j]
   3.2 若 s == target：返回 true
   3.3 若 s < target：i++      # 和太小 → 换更大的 a
   3.4 若 s > target：j--      # 和太大 → 换更小的 b
4. 返回 false
```

### 3.4 示例演算

![示例演算：示例 1 的双指针夹逼过程](images/bw10_q2_example_walkthrough.svg)

示例 1：`root1 = [2,1,4]` 中序为 $a = [1,2,4]$；`root2 = [1,0,3]` 中序为 $b = [0,1,3]$；target = 5。

| 步骤 | $(i, j)$ | $a[i]$ | $b[j]$ | 和 | 判定 |
|---|---|---|---|---|---|
| 1 | (0, 2) | 1 | 3 | 4 | 4 < 5 → i++ |
| 2 | (1, 2) | 2 | 3 | 5 | **命中，返回 true** |

示例 2：`root1 = [0,-10,10]` 中序为 $a = [-10, 0, 10]$；`root2 = [5,1,7,0,2]` 中序为 $b = [0, 1, 2, 5, 7]$；target = 18。

| 步骤 | $(i, j)$ | $a[i]$ | $b[j]$ | 和 | 判定 |
|---|---|---|---|---|---|
| 1 | (0, 4) | -10 | 7 | -3 | -3 < 18 → i++ |
| 2 | (1, 4) | 0 | 7 | 7 | 7 < 18 → i++ |
| 3 | (2, 4) | 10 | 7 | 17 | 17 < 18 → i++ |
| 4 | (3, 4) | i 越界 | — | — | **返回 false** |

最大可能的和 $10 + 7 = 17$ 都够不到 18，指针把 $a$ 耗尽后自然退出。

## 4. 算法细节

1. **中序遍历的写法**：递归最简洁（每棵树至多 5000 节点，递归深度最坏 5000，在默认栈深下安全）；若担心链状退化，可用显式栈的迭代中序。
2. **双指针的「排除」方向**：和太小只能动**头**指针（尾指针已取到当前最大可选值），和太大只能动**尾**指针，方向搞反会漏解。
3. **溢出**：$|node.val| \le 10^9$，和的绝对值至多 $2 \times 10^9 < 2^{31} - 1$，`int` 恰好够用；但余量极小，工程上建议用 `long long`/Python 任意精度保险。
4. **空树**：虽然约束通常保证非空，代码对空树天然安全——中序得空数组，双指针循环一次不进，返回 false。
5. **进阶：O(h) 空间的双栈迭代**：不必真正展开两条有序数组，可以同时维护「root1 的下一个最小」（升序迭代器栈）与「root2 的下一个最大」（降序迭代器栈），按双指针逻辑同步推进——空间降到 $O(h_1 + h_2)$，且能提前终止。本题数据规模下两种写法都绰绰有余，展开数组版更好写好证。
6. **与单树版（653）的区别**：[653. 两数之和 IV](https://leetcode.cn/problems/two-sum-iv-input-is-a-bst/) 只有一棵树，可用「哈希集合 + 遍历」或「中序 + 双指针同数组首尾」；本题是两棵树各取一个节点，双指针天然跨数组，反而更直接。

## 5. 正确性证明

**引理 1（中序有序）**：BST 的中序遍历序列非降（若节点值互异则严格递增）。

**证明**：对子树归纳：中序 = 左子树序列 + 根 + 右子树序列；由 BST 性质左子树全部 $\le$ 根 $\le$ 右子树全部，归纳假设两侧各自非降，拼接后整体非降。∎

**引理 2（双指针不漏）**：设 $a, b$ 非降。双指针过程中，每当 $a[i] + b[j] < target$ 时，数对 $(i, j')$（$j' \le j$）都不满足和为 target，故 $i$ 可安全排除；每当 $a[i] + b[j] > target$ 时，数对 $(i', j)$（$i' \ge i$）都不满足，$j$ 可安全排除。

**证明**：$a[i] + b[j] < target$ 时，对任意 $j' \le j$ 有 $b[j'] \le b[j]$（非降），故 $a[i] + b[j'] \le a[i] + b[j] < target$，$(i, j')$ 全体失败。对称地，$a[i] + b[j] > target$ 时对任意 $i' \ge i$ 有 $a[i'] \ge a[i]$，$a[i'] + b[j] \ge a[i] + b[j] > target$，$(i', j)$ 全体失败。∎

**定理**：算法返回 true 当且仅当存在 $u \in tree1, v \in tree2$ 使 $u.val + v.val = target$。

**证明**：由引理 1，$a, b$ 是两树节点值的非降序列，问题等价于有序数组的两数之和。**充分性**：算法返回 true 时显然找到了相等和的数对。**必要性（不漏）**：对指针推进次数归纳，维护不变量「一切尚未被排除的数对 $(i', j')$（$i' \ge i$ 且 $j' \le j$）仍在搜索范围内」：初始成立；每次推进由引理 2 只排除已判失败的数对。循环终止（某指针越界）时，未被排除的数对集合为空——若 $i$ 越界，则一切 $i' \ge i$ 无效；若 $j$ 越界，一切 $j' \le j$ 无效——即所有数对都被显式判定过，返回 false 正确。∎

## 6. 复杂度分析

- **时间**：$O(n_1 + n_2)$。两次中序遍历线性，双指针每步至少移动一格、总共至多 $n_1 + n_2$ 步。相比 BST 查找法的 $O(n_1 h_2)$，最坏情形（链状树）从 $O(n_1 n_2)$ 降到线性。
- **空间**：$O(n_1 + n_2)$，存储两条中序序列（递归栈深度另计 $O(h_1 + h_2)$）。若改用双栈迭代器可降到 $O(h_1 + h_2)$，代价是实现复杂度上升。

## 7. 参考代码

### C++

```cpp
class Solution {
    void inorder(TreeNode* root, vector<int>& out) {
        if (!root) return;
        inorder(root->left, out);
        out.push_back(root->val);
        inorder(root->right, out);
    }
public:
    bool twoSumBSTs(TreeNode* root1, TreeNode* root2, int target) {
        vector<int> a, b;
        inorder(root1, a);                   // BST 中序遍历 → 递增序列
        inorder(root2, b);
        int i = 0, j = (int)b.size() - 1;    // 首尾双指针
        while (i < (int)a.size() && j >= 0) {
            int sum = a[i] + b[j];
            if (sum == target) return true;
            if (sum < target) ++i;           // 和太小 → 左指针右移
            else --j;                        // 和太大 → 右指针左移
        }
        return false;
    }
};
```

### Python

```python
class Solution:
    def twoSumBSTs(self, root1: 'TreeNode', root2: 'TreeNode',
                   target: int) -> bool:
        def inorder(root, out):
            if not root:
                return
            inorder(root.left, out)
            out.append(root.val)
            inorder(root.right, out)

        a, b = [], []
        inorder(root1, a)                   # BST 中序遍历 → 递增序列
        inorder(root2, b)
        i, j = 0, len(b) - 1                # 首尾双指针
        while i < len(a) and j >= 0:
            s = a[i] + b[j]
            if s == target:
                return True
            if s < target:
                i += 1                      # 和太小 → 左指针右移
            else:
                j -= 1                      # 和太大 → 右指针左移
        return False
```

## 8. 边界情况与易错点

1. **空树**：任一棵树为空则无数对，返回 false；中序遍历与双指针循环都天然处理，无需特判。
2. **指针方向别写反**：和小时动**头**、和大时动**尾**，写反会在错过解后永不再回头，产生漏判。
3. **溢出余量**：两值之和可达 $\pm 2 \times 10^9$，恰好还在 32 位带符号整数内，但只差 5%——C++ 选手若不放心可改用 `long long` 存和。
4. **重复值**：BST 若含重复（取决于具体题面约定），中序非降而非严格递增，双指针的存在性判定不受影响（引理 2 只用到非降）。
5. **target 与值同号极端**：如 target = $-2 \times 10^9$，两指针可能一步就同时耗尽一边数组，注意循环条件是「且」——任一越界即终止。
6. **别忘了这是 premium 题目变体常见的「各取一个」语义**：不是「同一棵树内取两个」也不是「两树取任意多个」——双指针恰好对应「各取一个」，语义对齐后再动手。
