# LeetCode 验证回文串 III 题解

## 1. 题目概述

- **标题 / 题号**：验证回文串 III（#1216，hard）
- **链接**：https://leetcode.cn/problems/valid-palindrome-iii/
- **来源**：LeetCode 第 10 场双周赛 Q4
- **难度**：困难
- **标签**：字符串、动态规划

**题意**：给定字符串 `s` 与整数 `k`，判断 `s` 是否为 **K-回文串**：能否通过**删除至多 $k$ 个字符**，使剩余部分成为回文串。可以删，返回 `true`；否则 `false`。

**约束**：

- $1 \le s.length \le 1000$
- `s` 只包含小写英文字母
- $1 \le k \le s.length$

## 2. 示例

**示例 1**

```text
输入：s = "abcdeca", k = 2
输出：true
解释：删除 'b' 和 'e'，剩余 "acca"... 实际保留 "acdca"（删除 b、e），
     得到长度 5 的回文子序列 "acdca"，删除数 2 <= 2。
```

**示例 2**

```text
输入：s = "abbababa", k = 1
输出：true
解释：删除一个 'b'（下标 1），剩余 "abababa"，是回文。
```

**示例 3（补充）**

```text
输入：s = "abc", k = 1
输出：false
解释：最长回文子序列长度为 1，至少要删 2 个字符，2 > 1。
```

## 3. 解题思路

### 3.1 暴力思路

「删除至多 $k$ 个」最直接的量化方法是枚举删除集合（$2^n$ 个）或对「删除数」做带记忆化的递归：定义 $minDel(i, j)$ 为把 $s[i..j]$ 变成回文的最少删除数，

$$minDel(i,j) = \begin{cases} 0 & i \ge j \\ minDel(i+1, j-1) & s_i = s_j \\ 1 + \min\big(minDel(i+1,j),\ minDel(i,j-1)\big) & s_i \ne s_j \end{cases}$$

不带记忆化是指数级；带记忆化其实就是区间 DP 本身。另一条直白的思路是按题面直接三维 DP：$f(i, j, k')$ 表示 $s[i..j]$ 删至多 $k'$ 个能否回文——正确但状态是 $O(n^2 k)$，$n = k = 1000$ 时高达 $10^9$，爆炸。观察发现 $k$ 这一维是**冗余的**：把「预算」从状态里拿出来、只保留「最少删除数」这个标量，三维立刻塌缩成二维。

### 3.2 核心观察：最少删除数 = n − 最长回文子序列

![核心观察：删除 ↔ 保留的对称，问题化归为最长回文子序列](images/bw10_q4_interval_dp_model.svg)

删除与保留是同一枚硬币的两面：「删除若干字符得到回文」等价于「**保留**一个回文**子序列**」。于是：

$$\text{把 } s \text{ 变成回文的最少删除数} = n - \mathrm{LPS}(s),$$

其中 $\mathrm{LPS}(s)$ 是 $s$ 的**最长回文子序列**长度。答案判定一行：

$$n - \mathrm{LPS}(s) \le k .$$

而 LPS 是教科书级区间 DP（[516. 最长回文子序列](https://leetcode.cn/problems/longest-palindromic-subsequence/)）：

$$dp[i][j] = \begin{cases} 1 & i = j \\ dp[i+1][j-1] + 2 & s_i = s_j \\ \max(dp[i+1][j],\ dp[i][j-1]) & s_i \ne s_j \end{cases}$$

首尾相等时「首尾配对」必然不劣（可以严格证明），首尾不等时至少一头要被删掉——两头递推覆盖所有情况。

> 💡 与本题常被混淆的 [680. 验证回文串 II](https://leetcode.cn/problems/valid-palindrome-ii/)：那里 $k = 1$，双指针贪心（首尾不等时尝试跳过任意一头）就够；$k$ 变大后贪心失效（局部跳过可能不是全局最优），必须上区间 DP。「$k = 1$ 贪心、$k$ 通用 DP」正是这对题目的分水岭。

### 3.3 算法流程

![算法流程：按区间长度递推 LPS，最后做删除数判定](images/bw10_q4_algorithm_flow.svg)

```text
1. n = len(s)，开 n×n 的 dp 表，dp[i][i] = 1
2. 按 len = 2..n 枚举区间长度，对每个 i（j = i+len-1）：
   2.1 若 s[i] == s[j]：dp[i][j] = dp[i+1][j-1] + 2（len=2 时直接为 2）
   2.2 否则：dp[i][j] = max(dp[i+1][j], dp[i][j-1])
3. 返回 (n - dp[0][n-1]) <= k
```

### 3.4 示例演算

![示例演算："abcdeca" 的 LPS 区间 DP 表](images/bw10_q4_example_walkthrough.svg)

对示例 1 的 $s = $ `abcdeca`（下标 0..6），只列上三角（$j \ge i$），行标 $i$、列标 $j$：

| $i \backslash j$ | 0(a) | 1(b) | 2(c) | 3(d) | 4(e) | 5(c) | 6(a) |
|---|---|---|---|---|---|---|---|
| **0** | 1 | 1 | 1 | 1 | 1 | 3 | **5** |
| **1** |  | 1 | 1 | 1 | 1 | 3 | 3 |
| **2** |  |  | 1 | 1 | 1 | 3 | 3 |
| **3** |  |  |  | 1 | 1 | 1 | 1 |
| **4** |  |  |  |  | 1 | 1 | 1 |
| **5** |  |  |  |  |  | 1 | 1 |
| **6** |  |  |  |  |  |  | 1 |

几个关键格子：

- $dp[2][5] = 3$：子串 `cdec` 首尾都是 `c`，配对后中间 `de` 的 LPS 为 1，得 $1 + 2 = 3$；
- $dp[1][5] = 3$：子串 `bcdec` 首尾 `b`、`c` 不等，取 $\max(dp[2][5], dp[1][4]) = \max(3, 1) = 3$；
- $dp[0][6] = 5$：首尾 `a`、`a` 相等，$dp[1][5] + 2 = 5$，对应回文子序列 `acdca`（下标 0,2,3,5,6）。

最终 $n - dp[0][n-1] = 7 - 5 = 2 \le k = 2$，返回 `true` ✓。示例 2 中 $\mathrm{LPS}(\text{abbababa}) = 7$（如 `abababa`），$8 - 7 = 1 \le 1$，同样 `true`。

## 4. 算法细节

1. **DP 顺序**：按区间长度从小到大。$dp[i][j]$ 依赖长度小 1 或小 2 的区间，`len` 外层循环保证依赖先算好；也可按 $i$ 从大到小、$j$ 从小到大的双循环。
2. **`len = 2` 且首尾相等的特判**：此时 $dp[i+1][j-1]$ 是「空区间」（$i+1 > j-1$），按 0 处理得 2；用条件 `i + 1 <= j - 1 ? dp[i+1][j-1] + 2 : 2` 规避越界。
3. **状态压缩**：$n \le 1000$ 时整表 $10^6$ 个 int 约 4 MB，可以不压；若要压到 $O(n)$，按行倒序滚动即可（依赖只有左、下、左下三个格子，滚动时左下角需要临时保存）。
4. **答案判定的方向**：是「最少删除数 $\le k$」而不是「恰好 $k$」——删除是「至多」语义；又 $n - \mathrm{LPS} \le k$ 与 $\mathrm{LPS} \ge n - k$ 等价，两种写法都对。
5. **LPS 与 LCS 的等价**：$\mathrm{LPS}(s) = \mathrm{LCS}(s, \mathrm{reverse}(s))$，于是本题也可套 LCS 模板；两者状态同阶，凭手感选用。
6. **三维 DP 的教训**：直接带 $k$ 维（$f[i][j][k']$）在 $n = 1000$ 时是 $10^9$ 状态——「把判定维度压成标量比较」是这类「预算型」问题通用的降维手法。

## 5. 正确性证明

**引理 1（删除-保留刻画）**：$s$ 可通过删至多 $k$ 个字符变为回文 $\iff$ $s$ 存在长度 $\ge n - k$ 的回文子序列。

**证明**：（⇒）删除 $t \le k$ 个字符后剩下长 $n - t \ge n - k$ 的串 $s'$ 是回文，而 $s'$ 保留字符的下标序列在 $s$ 中单调增，故 $s'$ 是 $s$ 的子序列。（⇐）取该回文子序列，删掉 $s$ 中其余 $n - |P| \le k$ 个字符即得回文。∎

**引理 2（LPS 递推）**：设 $dp[i][j]$ 为子串 $s[i..j]$ 的最长回文子序列长度。若 $i < j$：

- $s_i = s_j$ 时 $dp[i][j] = dp[i+1][j-1] + 2$（约定空区间为 0）；
- $s_i \ne s_j$ 时 $dp[i][j] = \max(dp[i+1][j],\ dp[i][j-1])$。

**证明**：先证一个辅助事实：**区间去掉任一端的字符，LPS 至多减 1**。以去掉右端为例（左端对称——把串翻转后同理）：设 $P$ 是 $s[u..v]$ 的 LPS：若 $P$ 不含 $s_v$，则 $P$ 整体是 $s[u..v-1]$ 的回文子序列，$|P| \le dp[u][v-1]$；若 $P$ 含 $s_v$（必然作为 $P$ 的末字符），去掉该末字符后剩余部分是 $s[u..v-1]$ 的回文子序列，$|P| \le dp[u][v-1] + 1$。两种情形都有 $dp[u][v] \le dp[u][v-1] + 1$。

**相等情形**：记 $P$ 为 $s[i..j]$ 的一个 LPS，先证 $dp[i][j] \le dp[i+1][j-1] + 2$，分三种情形：

- $P$ 同时含 $s_i$ 与 $s_j$：由于子序列中 $s_i$ 只能是首字符、$s_j$ 只能是末字符，$P = s_i + P' + s_j$ 且 $P'$ 是 $s[i+1..j-1]$ 的回文子序列，$|P| \le dp[i+1][j-1] + 2$；
- $P$ 不含 $s_i$：$P$ 是 $s[i+1..j]$ 的子序列，再由辅助事实 $dp[i+1][j] \le dp[i+1][j-1] + 1 < dp[i+1][j-1] + 2$，得 $|P| \le dp[i+1][j-1] + 2$；
- $P$ 不含 $s_j$：对称地 $|P| \le dp[i][j-1] \le dp[i+1][j-1] + 1$（对 $s[i..j-1]$ 与 $s[i+1..j-1]$ 用辅助事实，去掉端点 $s_i$）。

反向不等式：在 $s[i+1..j-1]$ 的某个 LPS 首尾各接上 $s_i, s_j$（二者相等），得到 $s[i..j]$ 的回文子序列，长度 $dp[i+1][j-1] + 2$，故 $dp[i][j] \ge dp[i+1][j-1] + 2$。∎

**不等情形**：$P$ 不能同时以 $s_i$ 开、以 $s_j$ 结（否则首尾字符相等，与 $s_i \ne s_j$ 矛盾），故 $P$ 缺 $s_i$（是 $s[i+1..j]$ 的子序列，$|P| \le dp[i+1][j]$）或缺 $s_j$（$|P| \le dp[i][j-1]$）二者必居其一，得 $dp[i][j] \le \max(dp[i+1][j],\ dp[i][j-1])$；反向不等式由「子区间的子序列也是本区间的子序列」直接得到。∎

**定理**：算法返回 `true` 当且仅当 $s$ 是 K-回文串。

**证明**：引理 2 对区间长度做归纳（基例 $i = j$ 时 $dp = 1$、空区间为 0），可知 $dp[0][n-1] = \mathrm{LPS}(s)$。结合引理 1：$s$ 可删至多 $k$ 个变回文 $\iff \mathrm{LPS}(s) \ge n - k \iff n - dp[0][n-1] \le k$，即判定式。∎

## 6. 复杂度分析

- **时间**：$O(n^2)$。区间 DP 共 $\binom{n+1}{2} \approx 5 \times 10^5$ 个状态、每状态 $O(1)$ 转移；$n = 1000$ 时 C++ 毫秒级、Python 约 0.1 秒。
- **空间**：$O(n^2)$（约 4 MB）；滚动数组可压至 $O(n)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool isValidPalindrome(string s, int k) {
        int n = (int)s.size();
        vector<vector<int>> dp(n, vector<int>(n, 0));
        for (int i = 0; i < n; ++i) dp[i][i] = 1;             // 单字符
        for (int len = 2; len <= n; ++len)
            for (int i = 0; i + len - 1 < n; ++i) {
                int j = i + len - 1;
                if (s[i] == s[j])
                    dp[i][j] = (i + 1 <= j - 1) ? dp[i + 1][j - 1] + 2 : 2;
                else
                    dp[i][j] = max(dp[i + 1][j], dp[i][j - 1]);
            }
        return n - dp[0][n - 1] <= k;                         // 最少删除字符数
    }
};
```

### Python

```python
class Solution:
    def isValidPalindrome(self, s: str, k: int) -> bool:
        n = len(s)
        dp = [[0] * n for _ in range(n)]
        for i in range(n):
            dp[i][i] = 1                       # 单字符
        for length in range(2, n + 1):
            for i in range(n - length + 1):
                j = i + length - 1
                if s[i] == s[j]:
                    dp[i][j] = dp[i + 1][j - 1] + 2 if i + 1 <= j - 1 else 2
                else:
                    dp[i][j] = max(dp[i + 1][j], dp[i][j - 1])
        return n - dp[0][n - 1] <= k           # 最少删除字符数
```

## 8. 边界情况与易错点

1. **`len = 2` 且首尾相等**：必须给 2 而不是读越界的 $dp[i+1][j-1]$，特判（或把空区间约定为 0 并保证不越界读）。
2. **`k \ge n` 时恒真**：$n - \mathrm{LPS} \le n - 1 < k$（LPS 至少为 1），代码无需特判但值得知道；约束里 $k \ge 1$，$n = 1$ 的单字符也恒真。
3. **「至多」而非「恰好」**：判 $\le k$；若误写成 $n - dp == k$ 会在「删除更少也行」的数据上误判 false。
4. **DP 循环方向**：`len` 必须从小到大；若直接双层 `i, j` 循环且方向写错，会读到尚未计算的「更长区间」值。
5. **别和「子串」混淆**：要求的是回文**子序列**（[5. 最长回文子串](https://leetcode.cn/problems/longest-palindromic-substring/) 的中心扩展/MANACHER 解法在这里完全不适用）。
6. **贪心的陷阱**：$k = 1$ 时「双指针遇不等跳一头」的贪心正确（680 题），但 $k \ge 2$ 时跳过头的选择会相互影响——必须用 DP 覆盖所有跳法。
7. **对拍建议**：小串（$n \le 11$）可用「枚举全部子序列取最长回文」的暴力核对 DP；本文以 2500 组随机小串对拍通过。
