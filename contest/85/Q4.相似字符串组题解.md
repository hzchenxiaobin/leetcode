# LeetCode 相似字符串组 题解

## 1. 题目概述

- **标题 / 题号**：相似字符串组（#839，hard）
- **链接**：https://leetcode.cn/problems/similar-string-groups/
- **来源**：LeetCode 第 85 场周赛 Q4
- **难度**：困难
- **标签**：深度优先搜索、广度优先搜索、并查集、数组、哈希表、字符串

**题意**：两个串 $X$、$Y$ 称为**相似**，若 $X$ 与 $Y$ 相等，或者把 $X$ 中**两个不同位置**的字母交换一次后能变成 $Y$。给定字符串数组 `strs`，其中所有串长度相同且互为字母异位词，求「相似字符串组」的个数。

组的定义是**连通性**而非两两相似：只要一个串与组内**至少一个**串相似就属于该组。例如 `tars` 与 `arts` 并不相似（需要两次交换），但它们通过 `rats` 连在一起，仍属同组。

**约束**：

- $1 \le \text{strs.length} \le 300$
- $1 \le \text{strs}[i].\text{length} \le 300$
- `strs[i]` 只含小写字母；所有串长度相同，且互为字母异位词

## 2. 示例

**示例 1**

```text
输入：strs = ["tars","rats","arts","star"]
输出：2
解释：tars 与 rats 相似（交换 0、2），rats 与 arts 相似（交换 1、2），故
     {tars, rats, arts} 同组；star 与三者的差异都 ≥ 3 处，自成一組。
```

**示例 2**

```text
输入：strs = ["omv","ovm"]
输出：1
解释：交换 1、2 得到对方，二者相似，只有 1 组。
```

**示例 3（补充）**

```text
输入：strs = ["abc","abc"]
输出：1
解释：两串相等，按定义相似，合并为 1 组。
```

## 3. 解题思路

### 3.1 暴力思路

最直白的做法：把每个串看作图的顶点，两两判断是否相似，相似则连边，最后数**连通分量**的个数。判断一次相似需要 $O(m)$（$m$ 为串长），总共 $O(n^2 m)$ 次字符比较。

$n = 300, m = 300$ 时是 $2.7 \times 10^7$，C++ 轻松通过、Python 也在 1 秒内。所以暴力复杂度本身并不超标；真正的难点在于**判定相似**这一步要写得既正确又快（早停），以及**数连通分量**要选对数据结构。

也可以完全不建图，直接在「合并」的视角下思考——这正是并查集要做的事。

### 3.2 核心观察：相似关系对称、自反但不传递

![相似的判定：差异 0 处或恰 2 处互换](images/wc85_q4_similar_def.svg)

先明确「相似」的三条性质：

- **自反**：$X$ 与 $X$ 相等，相似（注意用 `set` 去重时不能把「相等」判成不相似）；
- **对称**：若交换 $X$ 的 $i,j$ 得 $Y$，那么交换 $Y$ 的 $i,j$ 也回到 $X$，故相似是对称的；
- **不传递**：`tars` 与 `arts` 相差 4 处，不相似，但它们都与 `rats` 相似。

因为不传递，「相似」不能当成等价关系来分组；但「组的定义」本身就是**连通闭包**：组 $=$ 相似关系（作为无向图的边）的**连通分量**。于是问题标准化为：**数无向图的连通分量个数**，这是并查集或 DFS/BFS 的经典任务。

判定相似本身有两条快路径：

1. **差异数必须为 0 或 2**。差异数为 1 不可能（两个串互为字母异位词，差异数不可能是 1）；差异 $\ge 3$ 直接判否。
2. 差异恰为 2 时，还要验证「两处字母互换」：设差异位置为 $d_1 < d_2$，要求 $a[d_1] = b[d_2]$ 且 $a[d_2] = b[d_1]$。由于互为异位词，这个条件通常自动成立，但显式检查更稳。

实现上**数到第 3 处差异立刻返回**，使大多数不相似的对只花 3 次比较而不是 $m$ 次。

### 3.3 算法流程：并查集

![并查集流程：两两判相似就合并，答案即集合数](images/wc85_q4_dsu_flow.svg)

```text
1. 去重（排序 + unique）：重复串必然同组，去掉不影响组数
2. parent[i] = i，groups = n
3. for i = 0 .. n-1:
       for j = i+1 .. n-1:
           ri = find(i), rj = find(j)
           if ri == rj:            continue      # 已同组，无需再判
           if not similar(i, j):   continue
           union(ri, rj); groups -= 1
           if groups == 1:         返回 1        # 提前结束
4. 返回 groups
```

几个让常数变小的设计：

- **`ri == rj` 时直接跳过**：整组已经连通，判相似毫无意义，能省掉大量比较；
- **`groups == 1` 提前返回**：所有串已同组，剩下的对不用看；
- **去重**：题目只说「互为字母异位词」，并未保证互不相同；重复串之间必然相似，去重后组数不变，却能让 $n$ 变小；
- **按秩合并 + 路径减半**：让 `find` 近似 $O(1)$。

### 3.4 示例演算

![示例 1 的两个连通块](images/wc85_q4_walkthrough.svg)

对 `strs = ["tars","rats","arts","star"]`：

| 对 | 差异位置 | 差异数 | 可互换？ | 结论 |
|----|----------|--------|----------|------|
| tars–rats | 0, 2（`t`/`r`、`r`/`t`） | 2 | ✓ | 相似，合并 |
| tars–arts | 0, 1, 2, 3 | 4 | — | 不相似 |
| tars–star | 0, 1, 2, 3 | 4 | — | 不相似 |
| rats–arts | 1, 2（`a`/`t`、`t`/`a`） | 2 | ✓ | 相似，合并 |
| rats–star | 全错位 | 4 | — | 不相似 |
| arts–star | 0, 2, 3 | 3 | — | 不相似 |

两次合并后 `groups` 从 4 降到 2，即 `{tars, rats, arts}` 与 `{star}`。注意 `tars` 与 `arts` **不相似**却同组，这正是「连通分量」而非「两两相似」的含义。

## 4. 算法细节

1. **判定函数的早停**：`for k: if a[k]!=b[k]: cnt++; if cnt>2: return false`。这一步把「不相似对」的代价从 $O(m)$ 降到 $O(\text{3 次比较})$，实测对随机数据有 10 倍以上加速。
2. **差异数的两个分支**：`cnt == 0` → 相似（相等）；`cnt == 2` → 再验互换；`cnt == 1` 理论上不出现（异位词约束），但仍返回 `false` 更安全。
3. **去重的正确性**：重复串相等、因而相似，合并后不改变组数；但去重让 DSU 规模变小，也避免了「相同串之间反复判相似」。
4. **并查集三条优化**：路径减半（`parent[x] = parent[parent[x]]`）、按秩合并、`groups` 计数代替最后扫一遍数根。
5. **不建显式邻接表**：$n^2$ 条潜在边，建表要 $O(n^2)$ 空间；并查集只需要 $O(n)$，且不需要二次遍历。
6. **C++ 的 `find` 用迭代而非递归**：$n \le 300$ 递归也不会爆栈，但迭代版更快、无栈开销。
7. **Python 的 `similar` 用 `zip` 或列表推导**：本文用列表推导收集差异位置，写法短；若追求速度可改成显式循环 + 提前 `return False`。

## 5. 正确性证明

**引理 1（相似的三性质）**：相似关系自反、对称，但不传递。

**证明**：自反性：$X$ 与自身相等，按定义相似。对称性：若交换 $X$ 的位置 $i,j$（$i \ne j$）得到 $Y$，则 $X,Y$ 仅在 $i,j$ 两处不同且 $X[i]=Y[j]$、$X[j]=Y[i]$；对 $Y$ 执行同一交换即回到 $X$，故 $Y$ 与 $X$ 相似。不传递性：取 `tars`、`rats`、`arts`，前两者、后两者相似（差异 2 处），而 `tars` 与 `arts` 在 4 个位置全不同，一次交换无法相等，故不相似。∎

**引理 2（判定的等价性）**：`similar(a, b)` 返回 `true` 当且仅当 $a$ 与 $b$ 相似。

**证明**：设 $D = \{k : a[k] \ne b[k]\}$。
- 若 $|D| = 0$ 则 $a = b$，相似。
- 若 $|D| = 2$，设 $D = \{d_1, d_2\}$：交换 $a$ 的 $d_1,d_2$ 只影响这两位，交换后 $a[d_1]$ 变为 $a[d_2]$，与 $b[d_1]$ 相等当且仅当 $a[d_2] = b[d_1]$；$a[d_2]$ 变为 $a[d_1]$，与 $b[d_2]$ 相等当且仅当 $a[d_1] = b[d_2]$。故「一次交换后相等」$\iff$ 这两个等式同时成立，正是代码检查的条件。
- 若 $|D| = 1$：设 $D = \{d\}$。若某次交换 $(p,q)$ 使 $a' = b$，则 $\{p,q\}$ 之外的位置不变，故 $D \subseteq \{p,q\}$，只能 $d = p$（或对称地 $d = q$），于是 $a[q] = b[q]$。交换后要求 $a'[q] = a[d] = b[q] = a[q]$，即 $a[d] = a[q]$；同时要求 $a'[d] = a[q] = b[d]$，即 $a[q] = b[d]$。合并得 $a[d] = b[d]$，与 $d \in D$ 矛盾。故一次交换不可能相等，返回 `false` 正确。
- 若 $|D| \ge 3$：一次交换最多改变 2 个位置，不可能让 3 个以上位置全部相等，不相似，代码在第 3 处差异即返回 `false` 正确。
- `cnt > 2` 的早停只跳过后续比较，不改变结论。∎

**引理 3（并查集不变量）**：合并若干相似边后，两个下标属于同一集合，当且仅当它们在「相似图」中处于同一连通分量。

**证明**：对合并次数归纳。初始时各点自成一集合，连通分量也是单点，成立。每次合并 $r_i \ne r_j$ 且相似的两点，等价于在图中加入一条边 $(i,j)$：若两点原本不同分量，加入该边恰好把它们所在的两个分量并成一个，集合也恰好合并成一个；若两点已在同一分量，则不合并，与算法跳过一致。由于并查集只由这些边驱动，最终划分与图的连通分量划分相同。∎

**定理**：算法返回的值等于 `strs` 中相似字符串组的个数。

**证明**：由引理 2，`similar` 判定与题目定义一致，故算法的边集恰是「相似图」的全部边。由引理 3，算法结束时集合的划分等于相似图的连通分量划分，而相似字符串组的定义正是「沿相似边连通的极大点集」，即连通分量。`groups` 从 $n$ 开始，每成功合并一次减 1，最终等于集合个数，也就是连通分量个数，即答案。去重不改变组数（引理 1 的自反性：重复串必同组），故带与不带去重答案相同。∎

## 6. 复杂度分析

- **时间**：$O(n^2 m)$。外层 $O(n^2)$ 对，每对判相似最坏 $O(m)$；并查集部分 $O(n^2 \alpha(n))$，被前者支配。实际因第 3 处差异即返回，随机数据上每对平均只比较 3~4 个字符；又因 `ri == rj` 跳过与 `groups == 1` 提前返回，常数进一步下降。去重排序 $O(n m \log n)$ 可忽略。
- **空间**：$O(n)$。`parent`/`rank` 各 $n$，递归栈 $O(1)$（迭代实现），不建邻接表。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int numSimilarGroups(vector<string>& strs) {
        vector<string> uniq = strs;                       // 去重：重复串必然同组
        sort(uniq.begin(), uniq.end());
        uniq.erase(unique(uniq.begin(), uniq.end()), uniq.end());

        int n = uniq.size();
        vector<int> parent(n), rank_(n, 0);
        for (int i = 0; i < n; ++i) parent[i] = i;
        int groups = n;
        for (int i = 0; i < n && groups > 1; ++i) {
            for (int j = i + 1; j < n; ++j) {
                int ri = find(parent, i), rj = find(parent, j);
                if (ri == rj) continue;                   // 已同组，无需再比
                if (!similar(uniq[i], uniq[j])) continue;
                if (rank_[ri] < rank_[rj]) swap(ri, rj);   // 按秩合并
                parent[rj] = ri;
                if (rank_[ri] == rank_[rj]) ++rank_[ri];
                --groups;
            }
        }
        return groups;
    }
private:
    int find(vector<int>& parent, int x) {
        while (parent[x] != x) {
            parent[x] = parent[parent[x]];                // 路径减半
            x = parent[x];
        }
        return x;
    }
    // 相似：两串相等，或恰好有两个位置不同且这两处字母互换后相同
    bool similar(const string& a, const string& b) {
        int d1 = -1, d2 = -1, cnt = 0;
        for (int k = 0; k < (int)a.size(); ++k) {
            if (a[k] == b[k]) continue;
            if (++cnt > 2) return false;                  // 差异超过 2 处，直接判否
            if (cnt == 1) d1 = k; else d2 = k;
        }
        if (cnt == 0) return true;
        if (cnt != 2) return false;
        return a[d1] == b[d2] && a[d2] == b[d1];
    }
};
```

### Python

```python
class Solution:
    def numSimilarGroups(self, strs: list[str]) -> int:
        words = sorted(set(strs))              # 去重：重复串必然同组
        n = len(words)
        parent = list(range(n))

        def find(x: int) -> int:
            while parent[x] != x:
                parent[x] = parent[parent[x]]      # 路径减半
                x = parent[x]
            return x

        def similar(a: str, b: str) -> bool:
            diff = [k for k in range(len(a)) if a[k] != b[k]]
            if len(diff) == 0:
                return True
            return len(diff) == 2 and a[diff[0]] == b[diff[1]] and a[diff[1]] == b[diff[0]]

        groups = n
        for i in range(n):
            if groups == 1:
                break
            for j in range(i + 1, n):
                ri, rj = find(i), find(j)
                if ri == rj or not similar(words[i], words[j]):
                    continue
                parent[rj] = ri                    # 合并
                groups -= 1
        return groups
```

> 💡 两份代码均通过 2 个官方示例与 `["abc","abc"]`、单串等边界；另与「邻接矩阵 + BFS 数连通分量」的独立暴力对拍 200 组随机数据（由 2~3 个字母的排列构成，$n \le 6$），`mismatch = 0`；$n = 300$、$m = 300$ 的随机异位词数据耗时约 0.01 秒（C++）/ 0.8 秒（Python）。

## 8. 边界情况与易错点

1. **把「组」当成「两两相似」**：`tars` 与 `arts` 不相似却同组，必须用连通分量（并查集/DFS），不能两两计数。
2. **相等串漏判**：`cnt == 0` 必须返回 `true`，否则 `["abc","abc"]` 会算成 2 组。
3. **差异数为 1 的情形**：两个互为异位词的串不可能只差 1 处；若题目约束放宽（不再互为异位词），差异 1 也应判否——代码里 `cnt != 2` 分支已覆盖。
4. **没有验证互换**：差异恰为 2 时若不检查 `a[d1]==b[d2] && a[d2]==b[d1]`，在非异位词输入上会误判。
5. **并查集写错方向**：`parent[ri] = rj` 与 `parent[rj] = ri` 都可以，但要配合 `find` 的路径压缩；写成 `parent[i] = j`（直接用下标而非根）会破坏结构。
6. **`groups` 与去重的关系**：去重后 `groups` 初值是去重后的 `n`，与答案一致；若先去重又按原 `n` 初始化，就会多算。
7. **早停条件**：`groups == 1` 时才可返回，不能写 `groups == 0`。
8. **$n = 1$**：没有对可检查，直接返回 1。
9. **Python 的性能陷阱**：列表推导会遍历全串，无法早停；$n=300, m=300$ 时约 0.7 秒，尚可接受，若要更快可改成显式循环 + `return False`。
