# LeetCode 矩形重叠 题解

## 1. 题目概述

- **标题 / 题号**：矩形重叠（#836，easy）
- **链接**：https://leetcode.cn/problems/rectangle-overlap/
- **来源**：LeetCode 第 85 场周赛 Q1
- **难度**：简单
- **标签**：几何、数学

**题意**：矩形用列表 `[x1, y1, x2, y2]` 表示，`(x1, y1)` 是**左下角**、`(x2, y2)` 是**右上角**，四条边分别平行于坐标轴。两个矩形「重叠」当且仅当它们的**交集面积严格大于 0**——只在边或角上接触**不算**重叠。给定 `rec1`、`rec2`，判断是否重叠。

**约束**：

- `rec1.length == rec2.length == 4`
- $-10^9 \le \text{rec}_i[j] \le 10^9$
- `rec1` 与 `rec2` 都是面积不为零的**有效矩形**，即 $x_1 < x_2$ 且 $y_1 < y_2$

## 2. 示例

**示例 1**

```text
输入：rec1 = [0,0,2,2], rec2 = [1,1,3,3]
输出：true
解释：交集是以 (1,1)、(2,1)、(1,2)、(2,2) 为顶点的 1×1 正方形，面积 1 > 0。
```

**示例 2**

```text
输入：rec1 = [0,0,1,1], rec2 = [1,0,2,1]
输出：false
解释：两矩形共用 x = 1 这条竖直边，但公共内部区域为空，交集面积为 0。
```

**示例 3**

```text
输入：rec1 = [0,0,1,1], rec2 = [2,2,3,3]
输出：false
解释：两矩形完全分离，没有任何公共点。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的做法是「找一个同时在两个矩形内部的点」：把矩形内部的半格点全枚举一遍。但坐标跨度可达 $2 \times 10^9$，格点数量是天文数字，完全不可行。

另一条暴力路线是取两个矩形的 8 条边，两两求交得到 16 个交点与重叠线段，再逐个判断是否落在对方矩形内部——可行但分支极多，纯属把一个 $O(1)$ 的问题做成 30 行的几何题。

真正的突破口是：**二维的相交问题可以拆成两个一维的区间相交问题。**

### 3.2 核心观察：投影到两轴，各自做区间交

![矩形重叠等价于两个坐标轴上的投影区间同时相交](images/wc85_q1_projection.svg)

设矩形 $R$ 在 x 轴上的投影是闭区间 $[x_1, x_2]$，在 y 轴上是 $[y_1, y_2]$。两个矩形的**交集**（作为点集）恰好是

$$(\text{x 投影之交}) \times (\text{y 投影之交})$$

也就是一个（可能退化为空集的）轴对齐矩形。于是

$$\text{overlap} \iff \max(x_1^{(1)}, x_1^{(2)}) < \min(x_2^{(1)}, x_2^{(2)}) \ \wedge\ \max(y_1^{(1)}, y_1^{(2)}) < \min(y_2^{(1)}, y_2^{(2)})$$

这里**严格不等号**是全部考点所在：

- 写成 $\le$ 会把「共边」（示例 2）误判为重叠；
- 写错成 $x_1^{(1)} < x_2^{(1)}$ 这类「自己和自己比」则完全丢掉了另一个矩形。

等价的展开写法是四个不等式同时成立：

$$x_1^{(1)} < x_2^{(2)},\quad x_1^{(2)} < x_2^{(1)},\quad y_1^{(1)} < y_2^{(2)},\quad y_1^{(2)} < y_2^{(1)}$$

但 `max/min` 版本只有两个比较式，阅读与书写都更不容易出错，推荐直接使用。

### 3.3 算法流程

![共边、交叉两种情形的判定对比](images/wc85_q1_conditions.svg)

```text
1. l = max(rec1[0], rec2[0])        # 交集左边界
2. r = min(rec1[2], rec2[2])        # 交集右边界
3. b = max(rec1[1], rec2[1])        # 交集下边界
4. t = min(rec1[3], rec2[3])        # 交集上边界
5. 返回 l < r 且 b < t
```

整个算法只有 4 次取最值和 2 次比较，没有任何循环。

### 3.4 示例演算

![三个示例的区间计算过程](images/wc85_q1_walkthrough.svg)

| 示例 | rec1 | rec2 | x 交集 | y 交集 | 结论 |
|------|------|------|--------|--------|------|
| 1 | [0,0,2,2] | [1,1,3,3] | $(1,2)$，长 1 | $(1,2)$，长 1 | 面积 1 → `true` |
| 2 | [0,0,1,1] | [1,0,2,1] | $(1,1)$，长 0 | $(0,1)$，长 1 | 面积 0 → `false` |
| 3 | [0,0,1,1] | [2,2,3,3] | $(2,1)$，空 | $(2,1)$，空 | 面积 0 → `false` |

注意示例 3 里 $l = 2 > r = 1$，交集的左右端点「交叉」了，说明该方向根本没有交集；`l < r` 一个条件同时覆盖了「共边」与「分离」两类失败。

## 4. 算法细节

1. **用 `max/min` 而不是四条不等式**：四条式子里最容易把 `x1` 与 `x2` 的下标写反；`max/min` 的语义是「交集的左右边界」，写错时会立刻在示例 2/3 上暴露。
2. **严格不等号**：题目明确「只在角或边接触不构成重叠」，因此必须 `<`；改成 `<=` 会在「共边」用例上返回 `true`。
3. **不需要分类讨论**：包含、部分重叠、分离、点在矩形内等情形被同一个公式统一处理——包含时 $\max/\min$ 化简成小矩形自身的边界，交集就是小矩形。
4. **无溢出风险**：全程只做整数比较，不做加减乘，$-10^9 \sim 10^9$ 的坐标不涉及溢出；若后续要算面积才需换成 `long long`。
5. **退化矩形**：题目保证面积为正，公式不依赖这个假设；即便出现面积为 0 的输入，`l < r` 也不会成立，返回 `false`，行为一致。
6. **参数是数组而非结构体**：下标含义为 `[x1, y1, x2, y2]`，C++ 传 `vector<int>&`，Python 直接传 `list[int]`。

## 5. 正确性证明

**引理 1（一维区间交）**：设 $[a_1,a_2]$、$[b_1,b_2]$ 为非空闭区间（$a_1<a_2$，$b_1<b_2$）。它们的**内部**交集非空当且仅当 $\max(a_1,b_1) < \min(a_2,b_2)$，且此时内部交集恰为开区间 $(\max(a_1,b_1), \min(a_2,b_2))$。

**证明**：记 $l = \max(a_1,b_1)$，$r = \min(a_2,b_2)$。若 $l < r$，取 $m = (l+r)/2$，则 $l < m < r$；由 $a_1 \le l$、$b_1 \le l$ 得 $a_1 < m$、$b_1 < m$，由 $r \le a_2$、$r \le b_2$ 得 $m < a_2$、$m < b_2$，故 $m$ 同时落在两区间内部，交集内部非空。反之若 $m$ 同时落在两区间内部，则 $a_1 < m < a_2$ 且 $b_1 < m < b_2$，于是 $l = \max(a_1,b_1) < m < \min(a_2,b_2) = r$，即 $l < r$。而内部交集的端点恰为 $l$ 与 $r$（小于 $r$ 的内部点必 $< a_2$ 且 $< b_2$，大于 $l$ 的内部点必 $> a_1$ 且 $> b_1$），故表达式成立。∎

**引理 2（交集分解）**：矩形 $R_1, R_2$ 的交集内部等于「x 方向内部交集」与「y 方向内部交集」的笛卡尔积。

**证明**：点 $(x,y)$ 位于矩形 $R_k$ 的内部，当且仅当 $x$ 位于 $R_k$ 的 x 投影内部**且** $y$ 位于其 y 投影内部（轴对齐矩形的内部就是两个开区间的乘积）。因此 $(x,y)$ 同时位于两个矩形内部 $\iff$ $x$ 同时属于两个 x 投影内部且 $y$ 同时属于两个 y 投影内部，正是两方向内部交集的乘积。∎

**定理**：算法返回 `true` 当且仅当两矩形交集面积大于 0。

**证明**：交集是轴对齐（可能退化为空集的）矩形，其面积为两个方向交集长度的乘积，两个因子都非负，故面积 $> 0$ $\iff$ 两个方向的内部交集都非空。由引理 2，两方向内部交集恰为引理 1 描述的开区间；由引理 1，它们非空 $\iff l<r$ 且 $b<t$。算法返回的正是这两个条件，故结论成立。∎

## 6. 复杂度分析

- **时间**：$O(1)$。4 次 `max/min` 与 2 次比较，与坐标大小无关。
- **空间**：$O(1)$。只用了 4 个临时变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool isRectangleOverlap(vector<int>& rec1, vector<int>& rec2) {
        // 两个矩形的交：x 方向区间 (max(x1), min(x2)) 与 y 方向同构
        int l = max(rec1[0], rec2[0]);
        int r = min(rec1[2], rec2[2]);
        int b = max(rec1[1], rec2[1]);
        int t = min(rec1[3], rec2[3]);
        return l < r && b < t;   // 严格不等：面积必须为正
    }
};
```

### Python

```python
class Solution:
    def isRectangleOverlap(self, rec1: list[int], rec2: list[int]) -> bool:
        # 交集的 x 区间为 (max(x1), min(x2))，y 区间同理
        left = max(rec1[0], rec2[0])
        right = min(rec1[2], rec2[2])
        bottom = max(rec1[1], rec2[1])
        top = min(rec1[3], rec2[3])
        return left < right and bottom < top   # 严格不等：面积必须为正
```

> 💡 两份代码均通过 3 个官方示例；另以「半格点采样」作为独立暴力，在 $[-4,4]$ 范围内的随机矩形对上对拍 400 组，`mismatch = 0`。

## 8. 边界情况与易错点

1. **共边被判成重叠**：最典型 WA。示例 2 中 $x$ 交集长度恰为 0，必须用 `<` 而不是 `<=`。
2. **坐标写反**：`[x1,y1,x2,y2]` 不是 `[x1,x2,y1,y2]`，`rec[1]` 是 y 不是 x。
3. **只判一半**：只比较 x 方向（或只比较 y 方向）会把「上下错开但左右重叠」的两矩形判成重叠。
4. **一个矩形完全包含另一个**：此时 $\max/\min$ 自动化简为小矩形的边界，无需特判；若特判写错反而容易漏。
5. **大坐标**：$-10^9 \sim 10^9$ 只是比较，不会溢出；但如果顺手去算面积（`(r-l)*(t-b)`）就要用 `long long`，否则 $2 \times 10^9$ 量级的乘积溢出。
6. **返回类型**：C++ 返回 `bool`，Python 返回 `True`/`False`，不要返回整数 0/1（Python 里 `bool` 是 `int` 子类，但语义上应给布尔值）。
7. **点在边上**：若内部只交出一条线段或一个点（例如 `[0,0,1,1]` 与 `[0,0,1,1]` 的角接触变体），面积仍为 0，按题意不算重叠，公式自然给出 `false`。
