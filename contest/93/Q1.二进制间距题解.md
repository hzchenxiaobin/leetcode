# LeetCode 二进制间距 题解

## 1. 题目概述

- **标题 / 题号**：二进制间距（#868，easy）
- **链接**：https://leetcode.cn/problems/binary-gap/
- **来源**：LeetCode 第 93 场周赛 Q1
- **难度**：简单
- **标签**：位运算

**题意**：给定正整数 $n$，考察 $n$ 的二进制表示中所有为 $1$ 的位。若两个 $1$ 之间只隔着 $0$（即它们在二进制串中相邻出现），则称这两个 $1$ **相邻**，它们的**距离**就是两个二进制位的下标之差的绝对值。要求返回所有相邻 $1$ 对中距离的最大值；如果 $n$ 的二进制里不足两个 $1$，返回 $0$。

换句话说：把 $n$ 的二进制中所有 $1$ 的位置从小到大排成序列 $p_1 < p_2 < \cdots < p_m$，求

$$\max_{1 \le i < m} \left( p_{i+1} - p_i \right)$$

当 $m < 2$ 时答案为 $0$。

**约束**：

- $1 \le n \le 10^9$
- $n$ 的二进制长度不超过 $30$ 位

## 2. 示例

**示例 1**

```text
输入：n = 22
输出：2
解释：22 的二进制是 "10110"，三个 1 位于下标 4、2、1（从低位起数）。
     相邻对的距离分别为 2 和 1，取最大值得 2。
```

**示例 2**

```text
输入：n = 8
输出：0
解释：8 的二进制是 "1000"，只有一个 1，不存在相邻的两个 1，返回 0。
```

**示例 3**

```text
输入：n = 5
输出：2
解释：5 的二进制是 "101"，两个 1 位于下标 2 和 0，距离为 2。
```

## 3. 解题思路

### 3.1 暴力思路

最直白的做法是先把 $n$ 的二进制每一位拆进一个数组 `bits`（长度 $b \le 30$），再双重循环枚举所有 $1$ 与 $1$ 的下标对：

```text
for i in 0 .. b-1:
    for j in i+1 .. b-1:
        if bits[i] == 1 and bits[j] == 1 and 中间没有别的 1:
            ans = max(ans, j - i)
```

「中间没有别的 1」这一条件让写法变得啰嗦，而且复杂度是 $O(b^2)$。虽然 $b \le 30$ 完全能过，但这道签到题值得写出**一遍扫描**的干净版本：只要按顺序记录「上一个遇到的 1 在哪」，当前 1 与它之间的距离就是一对相邻 1 的距离。

### 3.2 核心观察：只记上一个 1 的位置

![扫描流程：维护上一个 1 的位置，遇到新 1 就算距离](images/wc93_q1_scan_flow.svg)

把一个整数从**最低位**往高位看，第 $i$ 位就是 $n$ 右移 $i$ 位后的最低位，即 `(n >> i) & 1`。设当前扫描到下标 $i$：

- 若第 $i$ 位是 $0$：它对「相邻 1 的距离」没有任何贡献，直接跳过。
- 若第 $i$ 位是 $1$：设上一个 1 的下标为 `last`，那么 `i - last` 恰好是**这一对相邻 1 的距离**——因为 `last` 是 $i$ 之前最近的 1，中间不可能还有别的 1。

于是只需要两个变量：`last`（上一个 1 的下标，初值 $-1$ 表示还没有）和 `ans`（当前最大距离，初值 $0$）。整个算法一遍扫完 $b$ 位，$O(b)$ 时间、$O(1)$ 空间。

### 3.3 算法流程

```text
1. last = -1，ans = 0，i = 0
2. 当 n > 0 时循环：
   2.1 若 n & 1 == 1：
       a) 若 last >= 0：ans = max(ans, i - last)
       b) last = i
   2.2 n >>= 1，i += 1
3. 返回 ans
```

注意循环条件写成 `n > 0`，而不是扫固定的 30 位：这样天然在最高位的 1 之后停止，少做无用功，也顺便保证了「末尾的一串 0 不会制造垃圾距离」。

### 3.4 示例演算

以 `n = 22`（二进制 `10110`）为例，逐步跟踪：

| 轮次 $i$ | `n & 1` | `last`（更新前） | `i - last` | `ans` | 说明 |
|---------|---------|-----------------|-----------|-------|------|
| 0 | 0 | −1 | — | 0 | 最低位是 0，跳过 |
| 1 | 1 | −1 | — | 0 | 第一个 1，只记 `last = 1` |
| 2 | 1 | 1 | 1 | 1 | 与上一个 1 距离 1 |
| 3 | 0 | 2 | — | 1 | 跳过 |
| 4 | 1 | 2 | 2 | 2 | 与上一个 1 距离 2，刷新答案 |

循环在 `n` 变为 $0$ 时结束，返回 `ans = 2`，与示例一致。

## 4. 算法细节

1. **用移位代替字符串**：`to_string` 或 `bitset` 都需要额外空间，而且高低位顺序容易搞反；`n & 1` 配合 `n >>= 1` 直接从低位往上走，下标天然与「位置」一致。
2. **哨兵 `last = -1`**：第一个 1 没有「上一个 1」，用 `last >= 0` 判断即可避免凭空产生一次距离计算。若把 `ans` 初值设成 $0$，那么即使漏判也不会污染最大值，但代码语义会含混。
3. **`ans` 初值取 0**：题目规定「不存在两个相邻的 1 时返回 0」，正好与「至少两个 1 才有正距离」自洽，无需特判。
4. **距离是下标差而非位数**：`"1001"` 的两个 1 相距 $3$（下标 $3$ 与 $0$），不是 $2$。示例 1 中 $22$ 的距离 $2$ 也是下标 $4-2$ 得来。
5. **不修改原值的写法**：也可以 `for (int i = 0; (n >> i) > 0; i++)`，但 `n >>= 1` 更省一次移位运算，且边界条件更直观。

## 5. 正确性证明

**引理 1（`last` 的语义）**：在第 $i$ 轮循环开始时（若 `last >= 0`），`last` 等于 $i$ 之前**最近的**那个为 $1$ 的位下标。

**证明**：对 $i$ 归纳。$i = 0$ 时 `last = -1`，命题空真。设第 $i$ 轮开始时命题成立：若第 $i$ 位为 $0$，`last` 不变，而 $i$ 不是 1，故「$i+1$ 之前最近的 1」与「$i$ 之前最近的 1」相同，命题对 $i+1$ 成立；若第 $i$ 位为 $1$，代码把 `last` 置为 $i$，而 $i$ 正是 $i+1$ 之前最近（也最靠右）的 1，命题对 $i+1$ 成立。∎

**引理 2（每对相邻 1 恰好被计算一次）**：设 $n$ 的二进制中 1 的下标依次为 $p_1 < p_2 < \cdots < p_m$。扫描过程中，当 $i = p_{k}$（$k \ge 2$）时恰好执行一次 `ans = max(ans, p_k - p_{k-1})`，且不存在其它被计算的距离。

**证明**：由引理 1，在 $i = p_k$ 这一轮，`last` 等于 $p_{k-1}$（$i$ 之前最近的 1），故计算的差值就是 $p_k - p_{k-1}$。而 `ans` 的更新只发生在「当前位为 1 且 `last >= 0`」时，即只在 $k \ge 2$ 的 $p_k$ 处发生，故计算的差值集合恰为 $\{p_{k} - p_{k-1}\}_{k=2}^{m}$，既无遗漏也无重复。∎

**定理**：算法返回 $\max_{1 \le i < m}(p_{i+1}-p_i)$，当 $m<2$ 时返回 $0$。

**证明**：由引理 2，`ans` 是所有相邻 1 距离的最大值。当 $m < 2$ 时不存在相邻对，`ans` 保持初值 $0$，正是题目要求。∎

## 6. 复杂度分析

- **时间**：$O(\log n)$。循环执行 $b = \lfloor \log_2 n \rfloor + 1 \le 30$ 次，每次 $O(1)$ 位运算。
- **空间**：$O(1)$。只用到 `last`、`ans`、`i` 三个整型变量，与 $n$ 的大小无关。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int binaryGap(int n) {
        int last = -1, ans = 0;
        for (int i = 0; n > 0; i++, n >>= 1) {
            if (n & 1) {
                if (last >= 0) ans = max(ans, i - last);
                last = i;
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def binaryGap(self, n: int) -> int:
        last = -1
        ans = 0
        i = 0
        while n:
            if n & 1:
                if last >= 0:
                    ans = max(ans, i - last)
                last = i
            n >>= 1
            i += 1
        return ans
```

## 8. 边界情况与易错点

1. **只有一个 1**：如 $n = 8$（`1000`）、$n = 1$（`1`），此时 `last` 从未被「第二次」使用，`ans` 保持 $0$，符合题意。
2. **全是 1**：如 $n = 7$（`111`），所有距离都是 $1$，答案为 $1$，不要误答 $0$。
3. **高低位顺序**：距离是**下标差**，与从哪一端数无关，但 `i` 必须与 `last` 用同一套下标体系；混用「从高位数」和「从低位数」会得到相反的错误答案。
4. **`n >>= 1` 与 `i += 1` 的配对**：漏掉 `i += 1` 会让所有距离算成 $0$；把 `i += 1` 放在判断之前会整体错位一位。
5. **不要扫固定 32 位**：$n \le 10^9$，扫 32 位虽不错但会多做循环；扫 31 位以上还好，扫成 $b-1$ 位则可能漏掉最高位。
6. **`ans` 初值**：取 $0$ 而非 $-1$，否则「只有一个 1」的用例会返回 $-1$。
