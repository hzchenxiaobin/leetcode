# LeetCode 子序列最大 XOR 值 题解

## 1. 题目概述

- **标题 / 题号**：子序列最大 XOR 值（#3681，hard）
- **链接**：https://leetcode.cn/problems/maximum-xor-of-subsequences/
- **来源**：LeetCode 第 165 场双周赛 Q4
- **难度**：困难
- **标签**：位运算、贪心、数组、数学（线性基）

**题意**：给定非负整数数组 `nums`，选出**两个子序列**（都可以为空，**允许共用同一个下标**），设

- $X$ = 第一个子序列所有元素的按位异或，
- $Y$ = 第二个子序列所有元素的按位异或，

求 $X \oplus Y$ 的**最大值**。空子序列的异或定义为 0，子序列保持原数组顺序，但异或结果与顺序无关。

**约束**：

- $2 \le nums.length \le 10^5$
- $0 \le nums[i] \le 10^9$

## 2. 示例

**示例 1**

```text
输入：nums = [1,2,3]
输出：3
解释：取第一个子序列 [2]（X = 2）、第二个子序列 [2,3]（Y = 1），X ⊕ Y = 3。
     下标 1 被两个子序列共用，这是允许的。
```

**示例 2**

```text
输入：nums = [5,2]
输出：7
解释：X = 5，Y = 2，5 ⊕ 2 = 7。这也是全部元素异或的上界。
```

**示例 3（补充例子）**

```text
输入：nums = [7,7]
输出：7
解释：两个 7 相同，取第一个子序列 [7]（X = 7）、第二个为空（Y = 0），得 7。
     注意不能通过「两个子序列各取一个 7」拿到 7 ⊕ 7 = 0，那不是最大。
```

## 3. 解题思路

### 3.1 暴力思路

两个子序列各自独立选择，每个下标有 4 种状态（不进 / 只进第一个 / 只进第二个 / 两边都进），共 $4^n$ 种组合；枚举后计算 $X \oplus Y$ 取最大。$n = 10^5$ 时完全不可行。即使退一步只考虑「每个下标最多用一个」（$3^n$），依然是指数级。

### 3.2 核心观察：重复使用会被异或自己抵消

![每个下标的使用次数只关心奇偶：两次等于一次都不用](images/bw165_q4_parity_observe.svg)

把「第一个子序列用了下标 $i$」记为 $a_i \in \{0,1\}$，「第二个子序列用了 $i$」记为 $b_i \in \{0,1\}$。则

$$X \oplus Y = \bigoplus_{i:\,a_i=1} nums[i] \;\oplus\; \bigoplus_{i:\,b_i=1} nums[i] \;=\; \bigoplus_{i:\,a_i \oplus b_i = 1} nums[i] .$$

因为 $nums[i] \oplus nums[i] = 0$，所以「两边都用」与「两边都不用」对结果的贡献完全相同：**每个下标最终只取决于 $a_i \oplus b_i$，即它被使用的总次数的奇偶性**。

于是问题变成：对每个下标自由决定「用奇数次还是偶数次」，求 $\bigoplus_{i \in S} nums[i]$ 的最大值，其中 $S \subseteq \{1,\dots,n\}$ 可任选。

**反过来也成立**：任取一个下标集合 $S$，令第一个子序列恰为 $S$、第二个为空，就得到 $X \oplus Y = \bigoplus_{i\in S} nums[i]$。因此

$$\left\{\, X \oplus Y \,\right\} = \left\{\, \bigoplus_{i \in S} nums[i] \;:\; S \subseteq [n] \,\right\},$$

即**所有子集的异或**（也叫 $nums$ 的张成空间，含空集异或 0）。本题就是「求数组所有子集异或的最大值」，与「两个子序列」这个外壳无关。

### 3.3 算法流程：线性基（XOR basis）贪心求最大

![线性基插入与贪心取最大值](images/bw165_q4_linear_basis.svg)

$10^9 < 2^{30}$，所以只需 $30$ 位（第 $0 \sim 29$ 位；代码里统一开到第 30 位更稳）。维护一组「主元互不相同的基向量」：

1. **插入**：对每个 $x = nums[i]$，从高位到低位扫，若 $x$ 的第 $b$ 位为 1：
   - 若 `basis[b]` 为空，把 $x$ 放进 `basis[b]`，插入结束；
   - 否则 $x \leftarrow x \oplus basis[b]$（消掉这一位），继续看更低位。
2. **取最大**：从高位到低位贪心，若 `ans ^ basis[b] > ans` 就异或上去。由于 `basis[b]` 的最高位是 $b$，高位一旦能变大就绝不会被低位翻盘，故贪心正确。

线性基的本质是：对所有子集异或构成的集合做**高斯消元**，得到一个「最高位互不相同」的等价生成组，之后逐位贪心就等价于在二进制下逐位取最大。

### 3.4 示例演算

![示例 1 的子集异或全集与线性基](images/bw165_q4_example_walkthrough.svg)

**示例 1**：`nums = [1,2,3]`。3 = 1 ⊕ 2，所以三个数的张成空间是 $\{0,1,2,3\}$，最大 3。

| 子集 $S$ | $\bigoplus_{i\in S} nums[i]$ |
|----------|------------------------------|
| $\varnothing$ | 0 |
| {1} | 1 |
| {2} | 2 |
| {3} | 3 |
| {1,2} | 3 |
| {1,3} | 2 |
| {2,3} | 1 |
| {1,2,3} | 0 |

最大值 3，与题面一致。

**示例 2**：`nums = [5,2]`（二进制 `101`、`010`）。插入 5 后 `basis[2] = 101`；插入 2，第 2 位为 0，第 1 位为 1，`basis[1] = 010`。取最大：`ans = 0`，第 2 位 `basis[2] = 101` 使 `ans` 变 5；第 1 位 `5 ⊕ 2 = 7 > 5`，取 7。答案 7 ✓。

## 4. 算法细节

1. **位数上限**：$nums[i] \le 10^9 < 2^{30}$，最高位是第 29 位，开到第 30 位（数组长 31）绰绰有余；若值域放大到 $10^{18}$ 就要开到 60 位并改用 `long long`。
2. **插入时不做归一化也能取最大**：只要保证 `basis[b]` 的最高位恰为 $b$（消元时从高位往低位做就能保证），贪心取最大时用 `ans ^ basis[b] > ans` 判断即可。
3. **重复元素**：相同的数插第二次会被完全消成 0，直接丢弃，天然去重。
4. **零元素**：`nums[i] = 0` 插入时 $x=0$，不进任何基位，正确（0 对张成空间无贡献）。
5. **空集**：答案允许为 0（例如全 0 数组），此时 `ans` 保持 0，正确；题面说两个子序列可以为空，也印证了 0 是合法取值。
6. **异或用 `int` 足够**：$10^9 < 2^{30}$，异或不会溢出 32 位有符号正数范围。

## 5. 正确性证明

**引理 1（奇偶归约）**：对任意两个子序列，设 $S = \{i : a_i \oplus b_i = 1\}$，则 $X \oplus Y = \bigoplus_{i \in S} nums[i]$。

**证明**：$X \oplus Y = \left(\bigoplus_{a_i=1} nums[i]\right) \oplus \left(\bigoplus_{b_i=1} nums[i]\right)$。异或满足交换律、结合律，把同一个下标的两项合并：$a_i=b_i=1$ 时贡献 $nums[i]\oplus nums[i] = 0$；$a_i=b_i=0$ 时无贡献；$a_i \ne b_i$ 时贡献一次 $nums[i]$。故结果为 $S$ 中元素异或。∎

**引理 2（可达性）**：任一子集 $S$ 的异或值都可作为某对子序列的 $X \oplus Y$。

**证明**：取第一个子序列为 $S$ 中下标按原序排列、第二个为空，则 $Y = 0$（空子序列异或为 0），$X \oplus Y = \bigoplus_{i\in S} nums[i]$。∎

**引理 3（线性基张成不变）**：插入过程结束后，$\text{span}\{basis[b] \ne 0\}$ 等于 $\text{span}\{nums[i]\}$。

**证明**：插入时执行的 $x \leftarrow x \oplus basis[b]$ 与「把 $x$ 存入空位」都只做向量空间中的可逆替换（$x$ 与 $x\oplus basis[b]$ 张成同一空间），故每一步都保持张成空间不变；被丢弃的元素是 0，不影响张成。∎

**引理 4（贪心取最大）**：设 `basis[b]` 的最高位恰为 $b$，则从高到低执行「能变大就异或」得到的 `ans` 是张成空间中最大的数。

**证明**：按位归纳。设当前已处理完第 $k+1 \sim 30$ 位，`ans` 在这些位上的取值是张成空间中所有元素在这些位上的**字典序最大前缀**。考察第 $k$ 位时，`ans` 的第 $k$ 位为 0 且存在某个 `basis[b]`（$b \le k$）其第 $k$ 位为 1 时，异或后第 $k$ 位变 1 且更高位不变，严格优于不变；若 `ans` 第 $k$ 位已为 1，则任何异或都会把它变 0（因为能影响第 $k$ 位的基向量最高位就是 $k$），故不动。于是每一层都取到该层能达到的最大前缀，最终 `ans` 是张成空间中二进制字典序最大的元素，即数值最大。∎

**定理**：算法输出等于所有合法子序列对的 $X \oplus Y$ 最大值。

**证明**：由引理 1、2，所有可能的 $X\oplus Y$ 集合恰为 $\text{span}\{nums\}$（含 0）。由引理 3，线性基张成同一空间；由引理 4，贪心取到该空间中的最大值。故输出即所求最大值。∎

## 6. 复杂度分析

- **时间**：$O(n \log V)$，其中 $V = \max nums < 2^{30}$，即 $O(30n)$。每个元素插入时最多扫 30 位，取最大再扫 30 位，$n = 10^5$ 时约 $3 \times 10^6$ 次位运算。
- **空间**：$O(\log V)$，只有 31 个基向量；不需要存额外数组。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maxXorSubsequences(vector<int>& nums) {
        int basis[31] = {0};
        for (int v : nums) {
            int x = v;
            for (int b = 30; b >= 0; b--) {
                if (((x >> b) & 1) == 0) continue;
                if (basis[b] == 0) {
                    basis[b] = x;
                    break;
                }
                x ^= basis[b];
            }
        }
        int ans = 0;
        for (int b = 30; b >= 0; b--) {
            if ((ans ^ basis[b]) > ans) ans ^= basis[b];
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maxXorSubsequences(self, nums: list[int]) -> int:
        basis = [0] * 31
        for v in nums:
            x = v
            for b in range(30, -1, -1):
                if (x >> b) & 1 == 0:
                    continue
                if basis[b] == 0:
                    basis[b] = x
                    break
                x ^= basis[b]
        ans = 0
        for b in range(30, -1, -1):
            if (ans ^ basis[b]) > ans:
                ans ^= basis[b]
        return ans
```

## 8. 边界情况与易错点

1. **「两个子序列」是干扰项**：因为允许重叠，等价于每个下标可以选奇数次或偶数次，最终就是「选一个子集」。若题目改成**不允许重叠**，答案会变成「两个不交子集的异或之和」的变体，做法完全不同。
2. **空子序列合法**：答案可以为 0（如 `nums = [0,0]`），不要特判成「必须有元素」而返回别的值。
3. **位数要够**：$10^9$ 需要第 29 位，若只开到第 19 位（$2^{20}$）会丢掉高位导致答案偏小。取 30 位（不含第 30 位）足够，代码多留一位也无害。
4. **插入循环里 `break` 的位置**：存入空位后必须立刻 `break`，否则会继续用旧的 $x$ 去消低位，破坏基的结构。
5. **不能用 `ans = max(ans, ans ^ basis[b])` 的写法偷懒而不判「是否能变大」**：其实 `max` 与「大于才取」等价，但要注意不能写成 `ans |= basis[b]`（那只对「已消成下三角」的基成立）。
6. **值域为 0**：全 0 数组时基为空，答案 0，正确。
