# LeetCode 统计圆内格点数目 题解

## 1. 题目概述

- **标题 / 题号**：统计圆内格点数目（#2249，medium）
- **链接**：https://leetcode.cn/problems/count-lattice-points-inside-a-circle/
- **来源**：LeetCode 第 290 场周赛 Q2
- **难度**：中等
- **标签**：几何、数组、哈希表、数学、枚举

**题意**：给定二维整数数组 `circles`，其中 `circles[i] = [xi, yi, ri]` 表示网格上圆心为 $(x_i, y_i)$、半径为 $r_i$ 的圆。返回出现在**至少一个**圆内的**格点**（整数坐标点）数目。注意：**圆周上的点也算圆内**。

**约束**：

- $1 \le \mathrm{circles.length} \le 200$
- $\mathrm{circles}[i].\mathrm{length} = 3$
- $1 \le x_i, y_i \le 100$
- $1 \le r_i \le \min(x_i, y_i)$

> 💡 两条约束撑起全部做法：**坐标、半径 $\le 100$** 把候选格点封顶在 $201 \times 201$ 的网格里（观察 A）；**$r_i \le \min(x_i, y_i)$** 保证每个圆完整贴在第一象限内，矩阵下标不会为负。几何计数题的第一件事永远是**算值域**。

## 2. 示例

**示例 1**

```text
输入：circles = [[2,2,1]]
输出：5
解释：圆内格点为 (1,2)、(2,1)、(2,2)、(2,3)、(3,2)；
      像 (1,1)、(1,3) 这样的点不在圆内。
```

**示例 2**

```text
输入：circles = [[2,2,2],[3,4,1]]
输出：16
解释：共 16 个格点被至少一个圆覆盖，其中 (3,3)、(2,4) 被两圆同时覆盖，只计一次。
```

**边界示例（圆贴住坐标轴）**

```text
输入：circles = [[1,1,1]]
输出：5
解释：格点 (1,0)、(0,1)、(1,1)、(2,1)、(1,2) 在圆内——出现了坐标为 0 的点。
```

**规模上限示例（单圆最大）**

```text
输入：circles = [[100,100,100]]
输出：31417
解释：半径 100 的圆内恰有 31417 个格点（高斯圆问题 N(100)）。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的组合是「**点 × 圆**」双重枚举：把 $[0,200]^2$ 里每个格点拿出来，逐个圆判定 $(p_x - x_i)^2 + (p_y - y_i)^2 \le r_i^2$，命中即计数并 `break`。总判定次数至多 $201 \times 201 \times 200 \approx 8.1 \times 10^6$，C++ 轻松通过，Python 偏慢但一般也能过。另一条等价路线是反过来「**圆 × 外接框**」：对每个圆枚举外接正方形 $[x_i - r_i, x_i + r_i] \times [y_i - r_i, y_i + r_i]$ 内的点，塞进哈希集合去重，规模同数量级（标签里的 Hash Table 就是这条路线）。

本题数据规模「良心」，暴力就能收工——比赛时求稳直接写完是合理策略。但两个版本浪费都明显：前者对远离所有圆的点也要扫完 200 个圆；后者对外接框四角大量「框内但圆外」的点做了无效判定。更快的钥匙藏在圆的几何形状里。

### 3.2 核心观察一：值域封顶 + 整数判定

![核心观察：值域封顶与整数判定](images/2249_lattice_bounds_concept.svg)

**观察 A（候选空间封顶）**：由 $r_i \le \min(x_i, y_i)$ 知圆最左端 $x_i - r_i \ge 0$、最下端 $y_i - r_i \ge 0$——每个圆都被「按」在第一象限内，至多贴住坐标轴；又 $x_i + r_i \le 100 + 100 = 200$。于是**所有可能被覆盖的格点都落在 $[0,200]^2$ 内**，候选仅 $201 \times 201 = 40401$ 个。哈希集合可以换成 $201 \times 201$ 的布尔矩阵，去重退化为幂等的置位操作。

**观察 B（整数平方判定）**：格点 $P$ 在圆内（含周界）$\iff (p_x - x_i)^2 + (p_y - y_i)^2 \le r_i^2$。三项都是不超过 $4 \times 10^4$ 的整数，`int` 全程无溢出、无浮点误差。题目明确「圆周上的点也算」，所以是 $\le$ 而非 $<$。

### 3.3 核心观察二：圆的每一行是连续区间

![行跨度：固定 py 后 px 是一段连续区间](images/2249_lattice_row_span.svg)

**观察 C（行连续性）**：固定纵坐标 $p_y$，记 $dy = p_y - y_i$（$|dy| \le r_i$），圆内条件化为 $(p_x - x_i)^2 \le r_i^2 - dy^2$，即

$$p_x \in \left[\, x_i - \left\lfloor\sqrt{r_i^2 - dy^2}\right\rfloor,\ \ x_i + \left\lfloor\sqrt{r_i^2 - dy^2}\right\rfloor \,\right]$$

——**圆与每条水平线的交是一段连续区间**，宽度由勾股定理直接算出。于是「逐点判定」升级为「逐行打区间」：每个圆只做 $O(r)$ 次开方，每行把一整段区间标记进布尔矩阵。若进一步用**差分数组**打标记（区间左端 $+1$、右端 $+1$ 处 $-1$，最后逐行前缀和），每行只需 $O(1)$，标记成本从每圆 $O(r^2)$ 降到 $O(r)$。

### 3.4 算法流程

```text
1. cover ← 201×201 布尔矩阵，全 False
2. 对每个圆 (x, y, r)：
       对每行 dy ∈ [−r, r]：
           dx = ⌊√(r² − dy²)⌋          （Python: math.isqrt，整数精确）
           把 cover[y+dy][x−dx .. x+dx] 整段置 True
3. 答案 = cover 中 True 的个数
```

### 3.5 示例演算

![示例演算：圆 (2,2,2) 与 (3,4,1)，答案 16](images/2249_lattice_walkthrough.svg)

对示例 2 逐行走查（区间含义：该行被覆盖的 $p_x$ 范围）：

| $p_y$ | 圆 A $(2,2,2)$ | 圆 B $(3,4,1)$ | 该行覆盖点数 |
|-------|----------------|----------------|--------------|
| 0 | $[2,2]$ | — | 1 |
| 1 | $[1,3]$ | — | 3 |
| 2 | $[0,4]$ | — | 5 |
| 3 | $[1,3]$ | $[3,3]$ | 3（$(3,3)$ 两圆重叠，只计一次） |
| 4 | $[2,2]$ | $[2,4]$ | 3（$(2,4)$ 重叠） |
| 5 | — | $[3,3]$ | 1 |

合计 $1+3+5+3+3+1 = 16$。再用容斥核对：$|A| = 13$，$|B| = 5$，$A \cap B = \{(3,3),(2,4)\}$ 共 2 个，$13 + 5 - 2 = 16$ ✓。布尔矩阵的幂等置位自动完成了这次去重，无需显式容斥。

## 4. 算法细节

1. **矩阵大小 $201 \times 201$**：坐标取值范围 $[0,200]$ 两侧均闭；开成 $200 \times 200$ 会在 $p_x = 200$ 或 $p_y = 0$ 处越界（见 §2 两个边界示例）。
2. **开方必须精确**：Python 用 `math.isqrt`（纯整数、零误差）。C++ 的 `std::sqrt` 是浮点，对完全平方数也可能得到 $x.999\cdots$，截断后差 1——必须「向下、向上各校正一次」（见 §7 代码），这是本题主坑。
3. **行内整段标记**：Python 用切片赋值 `row[l:r+1] = [True] * (r-l+1)`，一次 C 级拷贝；C++ 循环置位即可。重复置位幂等，同心圆、重复圆无需特判。
4. **下标非负的保障**：$x - dx \ge x - r \ge 0$、$y - r \ge 0$ 都由 $r \le \min(x, y)$ 保证。**若约束放开**（允许 $r > \min(x,y)$ 或负坐标），必须先平移坐标系再开矩阵。
5. **差分优化版**：把整段置位换成 `diff[y+dy][x−dx] += 1; diff[y+dy][x+dx+1] -= 1`，最后逐行前缀和数出「前缀和 $> 0$」的位置。差分不止能判是否覆盖，还能数覆盖层数。

## 5. 正确性证明

**引理 1（判定等价）**：格点 $P = (p_x, p_y)$ 被圆 $(x, y, r)$ 覆盖（含周界）$\iff (p_x - x)^2 + (p_y - y)^2 \le r^2$。

**证明**：$P$ 到圆心的欧氏距离 $d(P) = \sqrt{(p_x - x)^2 + (p_y - y)^2}$。「在圆内含周界」即 $d(P) \le r$；两边均为非负数，平方保序，得 $(p_x - x)^2 + (p_y - y)^2 \le r^2$。∎

**引理 2（值域封顶）**：被任一圆覆盖的格点都落在 $[0,200]^2$ 内。

**证明**：设 $P$ 被 $(x, y, r)$ 覆盖，由引理 1 得 $|p_x - x| \le r$ 且 $|p_y - y| \le r$。又 $1 \le x, y \le 100$、$r \le \min(x, y)$、$r \le 100$，故 $p_x \ge x - r \ge 0$，$p_x \le x + r \le 200$；$p_y$ 同理。∎

**引理 3（行跨度）**：对 $|dy| \le r$ 的整数 $dy$ 及整数 $p_x$：格点 $(p_x, y + dy)$ 被覆盖 $\iff |p_x - x| \le \lfloor\sqrt{r^2 - dy^2}\rfloor$。

**证明**：由引理 1，覆盖 $\iff (p_x - x)^2 \le r^2 - dy^2$。记 $N = r^2 - dy^2 \ge 0$；整数 $k$ 满足 $k^2 \le N \iff k \le \lfloor\sqrt{N}\rfloor$（$\lfloor\sqrt{N}\rfloor$ 是平方不超过 $N$ 的最大整数）。取 $k = |p_x - x|$ 即得。$|dy| > r$ 时 $N < 0$ 无解，对应「该行无覆盖」，算法也不枚举这些行。∎

**定理**：算法返回值恰为被至少一个圆覆盖的格点数目。

**证明**：算法置位的集合 $S = \bigcup_i \bigcup_{dy=-r_i}^{r_i} \{\, (p_x,\, y_i + dy) : |p_x - x_i| \le \lfloor\sqrt{r_i^2 - dy^2}\rfloor \,\}$。由引理 3，第 $i$ 个圆贡献的集合恰为该圆覆盖的格点集；由引理 2，这些点全部落在矩阵下标范围内——既不越界，也无遗漏（矩阵外的格点不可能被任何圆覆盖）。布尔置位幂等，最终 `True` 的个数即 $\bigcup_i \{\text{圆 } i \text{ 覆盖的格点}\}$ 的基数，正是「出现在至少一个圆内」的格点数。∎

## 6. 复杂度分析

- **时间复杂度**：$O\left(\sum_i r_i^2 + 201^2\right)$。每圆 $O(r)$ 行，每行一次开方（数值 $\le 10^4$，$O(1)$）加 $O(r)$ 长度的置位，单圆 $O(r^2)$；最坏 200 个 $r = 100$ 的圆约 $6.3 \times 10^6$ 次置位，最后清点矩阵 $201^2 \approx 4 \times 10^4$。相比「点 × 圆」固定 $8.1 \times 10^6$ 次三参数判定，常数更小且不依赖 `break` 运气；差分版（§7 备选）把标记降到 $O(\sum_i r_i)$，总量约 $10^5$ 量级，再快近两个数量级。
- **空间复杂度**：$O(201^2)$，即布尔矩阵（差分数组同阶）。哈希集合写法最坏要存 40401 个坐标对，矩阵法更省也更缓存友好。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int countLatticePoints(vector<vector<int>>& circles) {
        vector<vector<char>> cover(201, vector<char>(201, 0));
        for (auto& c : circles) {
            int x = c[0], y = c[1], r = c[2];
            for (int dy = -r; dy <= r; ++dy) {
                int dx = isqrt(r * r - dy * dy);
                int row = y + dy;
                for (int px = x - dx; px <= x + dx; ++px) {
                    cover[row][px] = 1;
                }
            }
        }
        int ans = 0;
        for (auto& row : cover) {
            for (char v : row) ans += v;
        }
        return ans;
    }

private:
    static int isqrt(int n) {
        int r = (int)sqrt((double)n);
        while (r * r > n) --r;
        while ((r + 1) * (r + 1) <= n) ++r;
        return r;
    }
};
```

### Python

```python
from math import isqrt

class Solution:
    def countLatticePoints(self, circles: List[List[int]]) -> int:
        cover = [[False] * 201 for _ in range(201)]
        for x, y, r in circles:
            for dy in range(-r, r + 1):
                dx = isqrt(r * r - dy * dy)
                row = cover[y + dy]
                row[x - dx:x + dx + 1] = [True] * (2 * dx + 1)
        return sum(map(sum, cover))
```

### 备选：差分标记版（C++）

```cpp
class Solution {
public:
    int countLatticePoints(vector<vector<int>>& circles) {
        int diff[201][202] = {};
        for (auto& c : circles) {
            int x = c[0], y = c[1], r = c[2];
            for (int dy = -r; dy <= r; ++dy) {
                int dx = isqrt(r * r - dy * dy);
                int row = y + dy;
                ++diff[row][x - dx];
                --diff[row][x + dx + 1];
            }
        }
        int ans = 0;
        for (int y = 0; y <= 200; ++y) {
            int cur = 0;
            for (int x = 0; x <= 200; ++x) {
                cur += diff[y][x];
                if (cur > 0) ++ans;
            }
        }
        return ans;
    }

private:
    static int isqrt(int n) {
        int r = (int)sqrt((double)n);
        while (r * r > n) --r;
        while ((r + 1) * (r + 1) <= n) ++r;
        return r;
    }
};
```

最朴素的「点 × 圆」双循环（§3.1）代码最短，本题也能通过，比赛时限紧张时是合理选择；上文按行区间的版本在同样简短的代码量下换来了更小的常数与更清晰的几何结构。

## 8. 边界情况与易错点

1. **圆周上的点必须算**：判定用 $\le$ 不是 $<$。示例 1 的 $(1,2)$ 就是周界点：$(1-2)^2 + (2-2)^2 = 1 = r^2$，写成 $<$ 会直接漏掉。
2. **浮点 `sqrt` 差 1（最大坑）**：`sqrt(10000)` 可能返回 `99.999...`，`(int)` 截断成 99，跨度凭空少 1。Python 一律 `math.isqrt`；C++ 必须双向校正。完全平方数情形最容易踩。
3. **矩阵开 $201 \times 201$ 而非 $200 \times 200$**：下标取值 $0 \sim 200$ 共 201 个。`[[1,1,1]]` 用到下标 0，`[[100,100,100]]` 用到下标 200。
4. **下标为负的风险**：$r \le \min(x, y)$ 保证了 $x - dx \ge 0$。换到没有这条约束的变体时，直接开矩阵会越界——先整体平移坐标再算。
5. **重复 / 同心圆**：多圆覆盖同一格点只计一次。本题是**计数去重**，不是简单加总；若误写成「每圆各自计数再相加」，同心圆数据立刻翻倍报错。布尔置位（或集合）天然幂等。
6. **$dy = \pm r$ 的行**：此时 $dx = 0$，区间退化为单点，循环仍要执行，别当空区间跳过（圆的上下顶点也是答案的一部分）。
7. **答案上界**：$201^2 = 40401$，`int` 绰绰有余；但若坐标上界放大到 $10^4$ 以上，矩阵法的时间和内存都会爆，需回到哈希或扫描线（见延伸思考）。
