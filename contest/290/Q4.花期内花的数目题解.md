# LeetCode 花期内花的数目 题解

## 1. 题目概述

- **标题 / 题号**：花期内花的数目（#2251，hard）
- **链接**：https://leetcode.cn/problems/number-of-flowers-in-full-bloom/
- **来源**：LeetCode 第 290 场周赛 Q4
- **难度**：困难
- **标签**：数组、哈希表、二分查找、有序集合、前缀和、排序

**题意**：给定二维整数数组 `flowers`，`flowers[i] = [start_i, end_i]` 表示第 $i$ 朵花的**花期**是闭区间 $[\text{start}_i, \text{end}_i]$（**两端都包含**）。再给定整数数组 `people`，`people[i]` 是第 $i$ 个人来看花的时间。返回数组 `answer`，其中 `answer[i]` 为第 $i$ 个人到达时**正在盛开的花的数目**。

**约束**：

- $1 \le \mathrm{flowers.length} \le 5 \times 10^4$
- $\mathrm{flowers}[i].\mathrm{length} = 2$
- $1 \le \text{start}_i \le \text{end}_i \le 10^9$
- $1 \le \mathrm{people.length} \le 5 \times 10^4$
- $1 \le \mathrm{people}[i] \le 10^9$

> 💡 本题在本仓库另有[每日题解 2251](../../solution/2201-2300/2251_花期内花的数目.md)：以「排序 + 两次二分」为主线，附面试问答。本篇按**周赛复盘视角**展开，主线换成**事件差分 + 离散化前缀和（扫描线）**——与同场 Q2（圆内格点的行差分）、Q3（矩形包含点的桶计数）一脉相承，把「覆盖计数」统一成**事件流**视角，并补齐引理-定理化的严格证明与赛场易错清单，两篇互为印证。这是 290 场的收官题：Q2/Q3 把覆盖计数铺到二维平面，Q4 收回一维时间轴，正是差分思想最纯粹的形态。

## 2. 示例

**示例 1**

```text
输入：flowers = [[1,6],[3,7],[9,12],[4,13]], people = [2,3,7,11]
输出：[1,2,2,2]

解释：
t=2  ：仅花0 [1,6] 在开                              → 1
t=3  ：花0 [1,6] 与花1 [3,7]（当天开就算开）          → 2
t=7  ：花1 [3,7]（end 当天仍盛开！）与花3 [4,13]      → 2
t=11 ：花2 [9,12] 与花3 [4,13]（花0、花1 均已谢）     → 2
```

**示例 2**

```text
输入：flowers = [[1,10],[3,3]], people = [3,3,2]
输出：[2,2,1]

解释：
t=3：花0 [1,10] 与花1 [3,3] 都在开（花1 的花期只有一天，两端都算） → 2
t=2：仅花0（花1 尚未开）                                          → 1
```

**边界示例（端点语义自查）**

```text
输入：flowers = [[5,8]], people = [4,5,8,9]
输出：[0,1,1,0]

解释：start 当天已开（t=5 → 1）；end 当天仍开（t=8 → 1）；
      end+1 才算谢（t=9 → 0）；早于 start 全为 0（t=4 → 0）。
```

## 3. 解题思路

### 3.1 暴力思路

对每个 `people[i] = t` 遍历所有花，统计满足 $\text{start}_j \le t \le \text{end}_j$ 的花数。判定总次数 $n \times m = (5 \times 10^4)^2 = 2.5 \times 10^9$，必然超时——每朵花的开谢信息被每个人重复扫描，完全没有利用时间轴的结构。

另一条死路同样值得一看：想开一个**值域差分数组** `diff[1..10^9]`，在 `start` 处 `+1`、`end+1` 处 `−1`，前缀和后 $O(1)$ 回答任意时刻——但 $10^9$ 的值域直接 MLE。两条死路共同指向同一出口：**时间不能逐格枚举，只能压缩成「事件」**。

### 3.2 核心观察：闭区间花期 → 事件流 → 阶梯函数

![花期时间轴与事件化](images/2251_flowers_timeline.svg)

**观察 A（谢花发生在 end + 1）**：花期是**闭区间**，`end` 当天花仍盛开，所以「花少了一朵」这个变化最早发生在 $\text{end} + 1$ 时刻。把每朵花拆成两个事件：

$$\text{start}_i \ \text{时刻} + 1 \ (\text{开花}), \qquad \text{end}_i + 1 \ \text{时刻} - 1 \ (\text{谢花})$$

**观察 B（盛开数是阶梯函数）**：盛开数 $\mathrm{bloom}(t)$ 只在事件时刻跳变，两个相邻事件之间恒定。人问的只是「你站在哪级台阶上」。

**观察 C（差分恒等式）**：把两条观察合起来，任意时刻的盛开数可以拆成**两个前缀计数之差**：

$$\mathrm{bloom}(t) \;=\; \underbrace{\#\{i : \text{start}_i \le t\}}_{\text{已开始（含当天开）}} \;-\; \underbrace{\#\{i : \text{end}_i < t\}}_{\text{已结束（严格小于！）}}$$

> ⚠️ 「已开始」用 $\le$（含等号），「已结束」用 $<$（严格小于）——两端点的**包含性相反**，这是本题全部易错点的根源，也是后文两次二分方向相反的原因。

### 3.3 解法一（主推）：事件差分 + 离散化前缀和

![事件扫描与阶梯曲线](images/2251_flowers_event_sweep.svg)

把值域差分「离散化」到只有事件坐标上，死路即变通途：

```text
1. 差分登记：哈希表 diff，对每朵花 diff[start] += 1，diff[end + 1] -= 1
2. 坐标压缩：xs ← diff 的键排序去重（事件点，至多 2m 个）
3. 建台阶：height[k] ← 前 k+1 个事件坐标上差分的累加和（阶梯高度）
4. 逐人二分：对 t，k = bisect_right(xs, t) − 1（≤ t 的最后一个事件下标）
            答案 = k ≥ 0 ? height[k] : 0
```

$10^9$ 的值域被「只保留事件坐标」压缩到 $O(m)$ 个，前缀和一次性把整条阶梯建好，每个人只需**一次二分**定位自己脚下的台阶。

### 3.4 解法二（最短写法）：排序 + 两次二分

![两次二分的方向](images/2251_flowers_two_bisect.svg)

观察 C 的恒等式还可以「不建表、当场算」：把所有 `start`、所有 `end` 分别升序排序成 `starts`、`ends`，对每个 $t$：

- $a = \mathrm{bisect\_right}(\mathrm{starts},\ t) = \#\{\text{start} \le t\}$（`bisect_right` 停在**首个** $> t$ 处，等于 $t$ 的都被数进来）；
- $b = \mathrm{bisect\_left}(\mathrm{ends},\ t) = \#\{\text{end} < t\}$（`bisect_left` 停在**首个** $\ge t$ 处，等于 $t$ 的被排除）；
- $\mathrm{answer} = a - b$。

两个解法是同一恒等式的两种落地：解法一**先建阶梯、每次 1 次二分**；解法二**不建表、每次 2 次二分**。复杂度同阶，解法二代码最短（Python 三行），解法一的「事件流」视角则更能迁移到带权、动态的变体（见延伸思考）。

### 3.5 示例演算

![示例演算](images/2251_flowers_walkthrough.svg)

对示例 1（`starts = [1,3,4,9]`，`ends = [6,7,12,13]`）逐人核对：

| 人 $t$ | starts 中 $\le t$ | $a$ | ends 中 $< t$ | $b$ | $\mathrm{ans}=a-b$ | 谁在开 |
|--------|------------------|-----|---------------|-----|--------------------|--------|
| 2 | $\{1\}$ | 1 | $\{\}$ | 0 | **1** | 花0 |
| 3 | $\{1,3\}$ | 2 | $\{\}$ | 0 | **2** | 花0、花1 |
| 7 | $\{1,3,4\}$ | 3 | $\{6\}$ | 1 | **2** | 花1、花3 |
| 11 | $\{1,3,4,9\}$ | 4 | $\{6,7\}$ | 2 | **2** | 花2、花3 |

事件视角同步核对：$xs = [1,3,4,7,8,9,13,14]$，台阶高度 $\mathrm{prefix} = [1,2,3,2,1,2,1,0]$，则 $t=2,3,7,11$ 分别落在下标 $k=0,1,3,5$ 的台阶上，读数 $1,2,2,2$，与二分视角完全一致 ✓。

**$t = 7$ 的关键解析**：`ends` 中 $< 7$ 的只有 $6$——$7$ 本身是花1 的 `end`，**当天仍盛开不算已谢**；`starts` 中 $\le 7$ 的有 $1,3,4$，故 $\mathrm{ans} = 3 - 1 = 2$。若误把「已结束」写成 $\le$，花1 被漏掉，答案错成 1。

## 4. 算法细节

1. **差分登记用哈希表 / `map` 自动合并同刻事件**：多朵花同日开、同日谢是常态，`diff[s] += 1` 天然把同坐标的差分加总，避免 `xs` 里出现重复坐标。
2. **`−1` 必须落在 `end + 1`**：这是闭区间语义在事件化时的直接体现。写成 `end` 会让 `end` 当天的台阶提前降一级（边界示例的 $t=8$ 由 1 错成 0）。
3. **二分定位的越界分支**：`bisect_right(xs, t) − 1` 可能为 $-1$（人来得比所有事件都早），此时答案为 0，不能取 `height[-1]`（Python 会静默取到末尾，错得非常隐蔽；C++ 是未定义行为）。
4. **两次二分的 API 对照**：C++ `upper_bound` ↔ Python `bisect_right`（停在首个 $> t$）；C++ `lower_bound` ↔ Python `bisect_left`（停在首个 $\ge t$）。`starts` 侧用前者数 $\le t$，`ends` 侧用后者数 $< t$。
5. **离线双指针版（免二分）**：把 `people` 连同原下标排序，事件 $(x, \Delta)$ 也排序，单趟扫描：指针推进时把**所有坐标 $\le t$ 的事件**累加进计数器再读数。同刻的 $+1$ 与 $−1$ 先后无所谓（加减可交换），「先消费再读数」保证引理 4 的台阶语义。
6. **答案保序**：离线版处理顺序是按时间的，必须把结果写回原下标 `ans[i]`；两个在线二分版天然保序，无此负担。
7. **重复值无需去重**：`bisect` 系列在重复元素上仍准确定位计数边界；事件版靠哈希合并，二分版根本不涉及去重。
8. **在线替代方案**：若查询必须流式回答，可用 `SortedList` / 离散化树状数组 / 动态开点线段树支持「单点 ±1、前缀和查询」，但对本题的离线设定纯属大炮打蚊子。

## 5. 正确性证明

**引理 1（三态划分）**：对任意查询时刻 $t$，每朵花 $i$ 恰处于以下三种状态之一：未开（$t < \text{start}_i$）、盛开（$\text{start}_i \le t \le \text{end}_i$）、已谢（$t > \text{end}_i$）。

**证明**：由约束 $\text{start}_i \le \text{end}_i$，时间轴被分成 $[1, \text{start}_i)$、$[\text{start}_i, \text{end}_i]$、$(\text{end}_i, +\infty)$ 三段，两两不交且并集覆盖所有可能时刻，$t$ 必落且仅落其中一段，三态互斥且穷尽。∎

**引理 2（前缀计数分解）**：$\mathrm{bloom}(t) = \#\{i : \text{start}_i \le t\} - \#\{i : \text{end}_i < t\}$。

**证明**：先证 $\{i : \text{start}_i \le t\}$ 是「盛开」与「已谢」的不交并。一方面，$\text{start}_i \le t$ 时：若 $\text{end}_i \ge t$ 则 $t$ 落入 $[\text{start}_i, \text{end}_i]$，盛开；若 $\text{end}_i < t$ 则已谢；二者由引理 1 互斥且必居其一。另一方面，盛开蕴含 $\text{start}_i \le t$，已谢蕴含 $\text{start}_i \le \text{end}_i < t$，两态都落在该集合中。故 $\#\{\text{start} \le t\} = \#\text{盛开} + \#\text{已谢}$。再证 $\{i : \text{end}_i < t\}$ 恰为「已谢」：$\text{end}_i < t$ 即 $t > \text{end}_i$，已谢；反之已谢显然满足 $\text{end}_i < t$。两式相减，$\#\text{已谢}$ 抵消，得 $\mathrm{bloom}(t)$。∎

**引理 3（二分计数恒等式）**：对长度为 $m$ 的非降序列 $A$，$\mathrm{bisect\_right}(A, t) = \#\{a \in A : a \le t\}$，$\mathrm{bisect\_left}(A, t) = \#\{a \in A : a < t\}$。

**证明**：`bisect_right(A, t)` 返回首个满足 $A[k] > t$ 的下标 $k$。由非降性，所有 $\le t$ 的元素必连成前缀 $A[0..k-1]$（若 $A[j] \le t$ 且 $j' < j$，则 $A[j'] \le A[j] \le t$），且 $A[k..m-1]$ 全部 $> t$，故 $k$ 恰为 $\le t$ 的元素个数。`bisect_left` 同理：返回首个 $\ge t$ 的下标，其左侧恰为全部 $< t$ 的元素。∎

**引理 4（阶梯不变性）**：设事件坐标集 $x_1 < x_2 < \cdots < x_K$ 为 $\{\text{start}_i\} \cup \{\text{end}_i + 1\}$ 去重排序的结果，$\Delta(x) = \#\{\text{start}_i = x\} - \#\{\text{end}_i + 1 = x\}$，$S_k = \sum_{j \le k} \Delta(x_j)$，约定 $S_0 = 0$。则对任意满足 $x_k \le t < x_{k+1}$ 的 $t$（$k = 0$ 时指 $t < x_1$），$\mathrm{bloom}(t) = S_k$。

**证明**：先证 $S_k = \mathrm{bloom}(x_k)$。每个 $\text{start}_i$ 都是事件坐标，故 $\#\{\text{start} \le x_k\} = \sum_{j \le k} \#\{\text{start} = x_j\}$；同理 $\sum_{j \le k} \#\{\text{end} + 1 = x_j\} = \#\{\text{end} + 1 \le x_k\} = \#\{\text{end} < x_k\}$（整数坐标下 $\text{end} + 1 \le x_k \iff \text{end} \le x_k - 1 \iff \text{end} < x_k$）。于是 $S_k = \#\{\text{start} \le x_k\} - \#\{\text{end} < x_k\} = \mathrm{bloom}(x_k)$（引理 2）。再证 $[x_k, x_{k+1})$ 上 $\mathrm{bloom}$ 恒定：若 $\text{start}_i \in (x_k, t]$，则该 $\text{start}_i$ 是落在开区间 $(x_k, x_{k+1})$ 内的事件坐标，与 $x_k, x_{k+1}$ 相邻矛盾，故 $\#\{\text{start} \le t\} = \#\{\text{start} \le x_k\}$；若 $\text{end}_i \in [x_k, t)$，由整数性 $\text{end}_i + 1 \in (x_k, x_{k+1})$（因 $t \le x_{k+1} - 1$），同样是相邻区间内的事件坐标，矛盾，故 $\#\{\text{end} < t\} = \#\{\text{end} < x_k\}$。两计数都不变，由引理 2 得 $\mathrm{bloom}(t) = \mathrm{bloom}(x_k) = S_k$。∎

**定理**：解法一（事件差分 + 前缀和 + 二分定位）、解法二（排序 + 两次二分）与离线双指针版，对每个 $t = \mathrm{people}[i]$ 都返回 $\mathrm{bloom}(t)$。

**证明**：解法二：由引理 3，两次二分分别算出 $\#\{\text{start} \le t\}$ 与 $\#\{\text{end} < t\}$，相减由引理 2 即 $\mathrm{bloom}(t)$。解法一：`bisect_right(xs, t) − 1` 定位到 $k = \max\{j : x_j \le t\}$（$t < x_1$ 时 $k = 0$，返回约定值 $S_0 = 0$，即还没有任何花开），此时 $x_k \le t < x_{k+1}$，由引理 4 返回 $S_k = \mathrm{bloom}(t)$。离线双指针版：按 $t$ 升序处理查询，计数器在消费完所有坐标 $\le t$ 的事件后恰为 $S_k$（增量累加与求和次序无关），与解法一返回相同值。∎

## 6. 复杂度分析

- **时间复杂度**：$O((n + m) \log m)$，其中 $m$ 为花数、$n$ 为人数。
  - 事件版：$2m$ 个差分登记 $O(m)$，坐标排序 $O(m \log m)$，前缀和 $O(m)$，每人一次二分共 $O(n \log m)$。
  - 两次二分版：两个数组排序 $O(m \log m)$，每人两次二分共 $O(2n \log m)$。
  - 量级估计：$m = n = 5 \times 10^4$ 时约 $10^5 \times \log_2(5 \times 10^4) \approx 1.7 \times 10^6$ 次比较，毫秒级；对比暴力的 $2.5 \times 10^9$ 次判定，快了三个数量级。
- **空间复杂度**：$O(m)$——事件版存差分表、坐标与台阶高度；二分版存 `starts`、`ends` 两个数组（均不计输出）。
- **离线双指针版**：时间 $O((n + m)\log(n+m) + n + m)$（排序主导），单查询摊还 $O(1)$，查询量极大时占优。

## 7. 参考代码

### C++（事件差分 + 离散化前缀和，主推）

```cpp
class Solution {
  public:
    vector<int> fullBloomFlowers(vector<vector<int>>& flowers, vector<int>& people) {
        map<int, int> diff;                 // 坐标 -> 差分（自动合并同刻事件）
        for (auto& f : flowers) {
            diff[f[0]]++;                   // start 时刻开花
            diff[f[1] + 1]--;               // end+1 时刻才谢（闭区间）
        }
        vector<int> xs, height;             // 事件坐标 与 台阶高度（前缀和）
        int cur = 0;
        for (auto& [x, d] : diff) {
            xs.push_back(x);
            cur += d;
            height.push_back(cur);
        }
        vector<int> ans;
        ans.reserve(people.size());
        for (int t : people) {
            int k = upper_bound(xs.begin(), xs.end(), t) - xs.begin() - 1;
            ans.push_back(k >= 0 ? height[k] : 0);   // 比所有事件都早 -> 0
        }
        return ans;
    }
};
```

### Python（事件差分 + 离散化前缀和，主推）

```python
from bisect import bisect_right
from collections import Counter

class Solution:
    def fullBloomFlowers(self, flowers: List[List[int]], people: List[int]) -> List[int]:
        diff = Counter()
        for s, e in flowers:
            diff[s] += 1        # start 时刻开花
            diff[e + 1] -= 1    # end+1 时刻才谢（闭区间）

        xs = sorted(diff)
        height = []
        cur = 0
        for x in xs:
            cur += diff[x]
            height.append(cur)

        ans = []
        for t in people:
            k = bisect_right(xs, t) - 1
            ans.append(height[k] if k >= 0 else 0)
        return ans
```

### 备选一：排序 + 两次二分（最短写法）

```python
from bisect import bisect_left, bisect_right

class Solution:
    def fullBloomFlowers(self, flowers: List[List[int]], people: List[int]) -> List[int]:
        starts = sorted(s for s, _ in flowers)
        ends = sorted(e for _, e in flowers)
        return [bisect_right(starts, t) - bisect_left(ends, t) for t in people]
```

```cpp
class Solution {
  public:
    vector<int> fullBloomFlowers(vector<vector<int>>& flowers, vector<int>& people) {
        vector<int> starts, ends;
        for (auto& f : flowers) {
            starts.push_back(f[0]);
            ends.push_back(f[1]);
        }
        sort(starts.begin(), starts.end());
        sort(ends.begin(), ends.end());

        vector<int> ans;
        ans.reserve(people.size());
        for (int t : people) {
            int a = upper_bound(starts.begin(), starts.end(), t) - starts.begin();
            int b = lower_bound(ends.begin(), ends.end(), t) - ends.begin();
            ans.push_back(a - b);
        }
        return ans;
    }
};
```

### 备选二：离线双指针（免二分，单查询摊还 O(1)）

```python
class Solution:
    def fullBloomFlowers(self, flowers: List[List[int]], people: List[int]) -> List[int]:
        events = []
        for s, e in flowers:
            events.append((s, 1))
            events.append((e + 1, -1))
        events.sort()

        order = sorted(range(len(people)), key=lambda i: people[i])
        ans = [0] * len(people)
        cur = k = 0
        for i in order:
            t = people[i]
            while k < len(events) and events[k][0] <= t:   # 同刻事件全部入账再读数
                cur += events[k][1]
                k += 1
            ans[i] = cur
        return ans
```

## 8. 边界情况与易错点

1. **「已结束」必须严格小于（本场最大坑）**：花期含 `end`，`end = t` 当天仍盛开。`ends` 侧必须用 `lower_bound` / `bisect_left`；事件版 `−1` 必须落在 `end + 1`。误用 `upper_bound` / `bisect_right`：示例 1 的 $t=7$ 会把 $[3,7]$ 误判已谢，答案 $2 \to 1$；边界示例的 $t=8$ 由 $1 \to 0$。
2. **「已开始」必须含等于**：`start = t` 当天已开，`starts` 侧必须用 `upper_bound` / `bisect_right`。误用 `lower_bound`：示例 1 的 $t=3$ 会漏掉 $[3,7]$，答案 $2 \to 1$。
3. **两次二分方向相反的根源**：两端点的包含性相反（$\text{start} \le t$ 含等号、$\text{end} < t$ 严格），背公式容易记混，回到引理 2 的推导就忘不了。
4. **二分定位越界**：事件版 `bisect_right(xs, t) − 1 = −1`（人早于所有事件）要返回 0。Python 的 `height[-1]` 会静默取末尾而不报错，是最隐蔽的 WA 来源之一；C++ 直接未定义行为。
5. **值域 $10^9$**：任何按值域开数组的做法（差分数组、前缀和数组）都会 MLE，必须排序 / 离散化。C++ 中 $\text{end} + 1 \le 10^9 + 1 < 2^{31} - 1$，本题只做加减不会溢出，但混入乘法就要警惕。
6. **同刻事件的处理顺序**：离线双指针版只要保证「坐标 $\le t$ 的事件全部入账后再读数」，同刻 $+1$ 与 $−1$ 的先后不影响结果（加减可交换）；事件排序时 $(x, -1)$ 自然排在 $(x, 1)$ 前，无需特判。
7. **people 的顺序还原**：离线版按时间排序处理，答案必须写回原下标；两个在线二分版天然保序。
8. **重复值无需去重**：多花同日开 / 谢是常态，`bisect` 在重复元素上仍准确；事件版靠哈希表合并同刻差分。
9. **全零答案**：所有人时刻都早于所有花期时答案全 0，事件版的 $k = 0$ 分支与二分版的 $a = b = 0$ 都天然覆盖（引理 4 的边界情形），无需特判。
