# LeetCode 维持亮度的最小总能量 题解

## 1. 题目概述

- **标题 / 题号**：维持亮度的最小总能量（#3951，medium）
- **链接**：https://leetcode.cn/problems/minimum-energy-to-maintain-brightness/
- **来源**：LeetCode 第 184 场双周赛 Q2
- **难度**：中等
- **标签**：数组、排序、贪心

**题意**：$n$ 个灯泡排成一排（下标 $0 \sim n-1$）。开启的灯泡会照亮**自身及左右相邻位置**（若存在），一个位置的照明度最多计 1 次。

给定 `brightness` 与若干**闭时间区间** `intervals[i] = [start, end]`：

- 若某单位时间被至少一个区间覆盖，则该时间内「总照明度」必须**至少**为 `brightness`；
- 未被任何区间覆盖的时间，所有灯泡可以关闭。

每个时间单位内开启一个灯泡消耗 1 单位能量。求所需**最小总能量**。

**约束**：

- $1 \le n \le 10^6$
- $1 \le brightness \le n$
- $1 \le intervals.length \le 10^5$，$0 \le start_i \le end_i \le 10^9$

## 2. 示例

**示例 1**

```text
输入：n = 5, brightness = 5, intervals = [[6,12]]
输出：14
解释：开位置 1 与 4 的灯泡 → 0 1 0 0 1，5 个位置全被照亮。
     有效时长 12 − 6 + 1 = 7，能量 = 2 × 7 = 14。
```

**示例 2**

```text
输入：n = 2, brightness = 1, intervals = [[0,0],[2,2]]
输出：2
解释：两段各长 1，每段开 1 个灯泡 → (1 + 1) × 1 = 2。
```

**示例 3**

```text
输入：n = 4, brightness = 2, intervals = [[1,3],[2,4]]
输出：4
解释：两区间合并为 [1,4]，长度 4；只需 1 个灯泡即可照亮 2 个位置 → 4 × 1 = 4。
```

## 3. 解题思路

### 3.1 暴力思路

按时间逐格模拟：对每个被覆盖的时间单位，求「照亮至少 `brightness` 个位置所需的最少灯泡数」，再乘上时间单位的个数。时间端点可达 $10^9$，逐格枚举必超时（$10^9$ 次）；灯泡的摆放也不该逐个枚举（$2^n$ 种）。所以两件事都要**用公式替代**：

1. 每单位时间的最少灯泡数——只与 $brightness$ 与 $n$ 有关；
2. 有效时间总长——区间的并集长度，用排序 + 合并求出。

### 3.2 核心观察：一个灯泡最多照 3 格，且时间与灯泡数无关

![一个灯泡最多照亮 3 个位置](images/bw184_q2_bulbs.svg)

**（1）每单位时间的最少灯泡数 = $\lceil brightness / 3 \rceil$。**

- **下界**：一个灯泡最多照亮 3 个位置（自己 + 左右邻居），$m$ 个灯泡最多照亮 $3m$ 个位置，故要照亮 $b$ 个位置必须 $3m \ge b$，即 $m \ge \lceil b/3 \rceil$。
- **可达**：记 $m = \lceil b/3 \rceil$。若 $3m \le n$，把灯泡放在 $1, 4, 7, \dots, 3m-2$，覆盖区域是连续的 $[0, 3m-1]$，恰好 $3m \ge b$ 个位置；若 $3m > n$，则 $m > n/3$，推出 $m \ge \lceil n/3 \rceil$，而「用 $\lceil n/3 \rceil$ 个灯泡照亮整排」的结论可以这样归纳证明：$n \ge 3$ 时在最左端放一个灯泡（照亮 $0,1,2$），剩下的长度 $n-3$ 的尾部需要 $\lceil (n-3)/3 \rceil$ 个，而 $1 + \lceil (n-3)/3 \rceil = \lceil n/3 \rceil$；$n \le 3$ 时 1 个灯泡足够。于是整排 $n \ge b$ 个位置全亮。

**（2）时间可以任意重排，所以「每单位时间最优配置」可以反复使用。** 题面允许每个时间单位独立开关灯泡，且照度只与位置有关、与时间无关；因此最优策略就是每个「被覆盖的时间单位」都用同一个最少灯泡数的配置（同一个摆放）。总能量 = 最少灯泡数 × 被覆盖的时间单位总数。

**（3）被覆盖的时间单位总数 = 区间并集长度。** 区间是闭的整数时间区间，长度 $= end - start + 1$，用「按起点排序 + 合并相交区间」求得。

![有效时间 = 区间的并集长度](images/bw184_q2_intervals.svg)

### 3.3 算法流程

```text
1. bulbs = (brightness + 2) / 3                 // 向上取整的整数写法
2. 对 intervals 按起点排序
3. total = 0，cur = 第一个区间
   for 每个后继区间 [s, e]:
       若 s <= cur.end：cur.end = max(cur.end, e)      // 相交则合并
       否则：total += cur.end - cur.start + 1；cur = [s, e]
   total += cur.end - cur.start + 1
4. 返回 bulbs * total
```

### 3.4 示例演算

| 示例 | `brightness` | 最少灯泡数 | 有效时长 | 能量 |
|------|---------------|------------|----------|------|
| 1 | 5 | $\lceil 5/3 \rceil = 2$ | $12-6+1 = 7$ | $2 \times 7 = 14$ |
| 2 | 1 | $\lceil 1/3 \rceil = 1$ | $1 + 1 = 2$ | $1 \times 2 = 2$ |
| 3 | 2 | $\lceil 2/3 \rceil = 1$ | $[1,3] \cup [2,4] = [1,4]$ → 4 | $1 \times 4 = 4$ |

三个示例分别覆盖了「灯泡数 > 1」「多段不相交」「区间相交合并」三种情况。

## 4. 算法细节

1. **向上取整**：`(brightness + 2) / 3` 是整数版的 $\lceil b/3 \rceil$，避免浮点误差。
2. **排序**：按 `start` 升序（`start` 相同则按 `end`，本题不敏感）。
3. **合并判据**：`s <= cur.end` 即两段有公共时间单位；若 `s == cur.end + 1`（首尾相接但不相交），合并与否不影响总长度，两种写法都对，本文采用「相交才合并」，语义更贴切。
4. **长度累加**：`end - start + 1`（闭区间），不要写成 `end - start`。
5. **溢出**：$n \le 10^6$、区间端点 $\le 10^9$、最多 $10^5$ 段，总时长的上界约 $10^{14}$，必须用 64 位整数；Python 天然支持大整数。
6. **`n` 的作用**：只用于确定「一排有 $n$ 个位置」，进而确定每单位时间的最少灯泡数；摆放细节不需要真的构造。

## 5. 正确性证明

**引理 1（每单位时间的灯泡下界）**：任一单位时间内，若照明度至少为 $b$，则开启的灯泡数 $m \ge \lceil b/3 \rceil$。

**证明**：位置 $p$ 的灯泡只照亮 $p-1, p, p+1$ 三个位置，故 $m$ 个灯泡的照明度不超过 $3m$。要求照明度 $\ge b$，即 $3m \ge b$，$m \ge \lceil b/3 \rceil$。∎

**引理 2（下界可达）**：设 $m = \lceil b/3 \rceil$，则存在一种摆放使照明度 $\ge b$。

**证明**：分两种情形。

- $3m \le n$：把灯泡放在 $1, 4, \dots, 3m-2$。第 $k$ 个灯泡（$k = 0..m-1$）照亮 $[3k, 3k+2]$，这些区间两两不重叠且并集为 $[0, 3m-1]$，共 $3m \ge b$ 个位置。
- $3m > n$：此时 $m > n/3$，故 $m \ge \lceil n/3 \rceil$。下面证明「$\lceil n/3 \rceil$ 个灯泡可照亮整排 $n$ 个位置」：对 $n$ 归纳。$n \le 3$ 时 1 个灯泡放在中间位置即可照亮全部；$n \ge 4$ 时在最左端（位置 1）放一个灯泡照亮 $0,1,2$，剩余尾部 $[3, n-1]$ 长度为 $n-3$，由归纳假设用 $\lceil (n-3)/3 \rceil$ 个灯泡即可照亮，总数 $1 + \lceil (n-3)/3 \rceil = \lceil n/3 \rceil$。于是整排 $n \ge b$ 个位置全亮，照明度 $n \ge b$。

∎

**引理 3（时间与灯泡可分离）**：最小总能量 = 每单位时间最少灯泡数 × 被覆盖的时间单位总数。

**证明**：任一合法方案在每个被覆盖的时间单位里都必须开启 $\ge \lceil b/3 \rceil$ 个灯泡（引理 1），未被覆盖的时间可全关（不耗能），故总能量 $\ge \lceil b/3 \rceil \times T$，其中 $T$ 为被覆盖的时间单位总数。另一方面，对每个被覆盖的时间单位都采用引理 2 的同一摆放、其余时间全关，即可用恰好 $\lceil b/3 \rceil \times T$ 的能量满足要求。两向夹逼即得。∎

**引理 4（并集长度）**：按起点排序并合并相交区间后，各合并段的长度之和等于区间并集所含的整数时间单位个数。

**证明**：排序后，相交的区间必然形成「传递重叠」的簇：若 $[s_1,e_1]$ 与 $[s_2,e_2]$ 相交且 $s_1 \le s_2$，则 $s_2 \le e_1$。合并时把当前簇的右端不断扩展到 $\max(e_i)$，得到簇的并集区间 $[s_{\min}, e_{\max}]$，长度即簇内单位数。不同簇之间不相交，故总长度可加。∎

**定理**：算法返回最小总能量。

**证明**：算法先按引理 2 取 $m = \lceil b/3 \rceil$，再按引理 4 得到被覆盖时间单位总数，最后相乘。由引理 3，该乘积恰为最小总能量。∎

## 6. 复杂度分析

- **时间**：$O(k \log k)$，$k = intervals.length$。排序 $O(k \log k)$，合并扫描 $O(k)$；与 $n$、端点的数值大小无关。
- **空间**：$O(1)$ 额外空间（原地排序，只存当前合并段与累计值）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long minEnergy(int n, int brightness, vector<vector<int>>& intervals) {
        sort(intervals.begin(), intervals.end());
        long long total = 0;
        long long curL = intervals[0][0], curR = intervals[0][1];
        for (size_t i = 1; i < intervals.size(); i++) {
            long long s = intervals[i][0], e = intervals[i][1];
            if (s <= curR) {
                if (e > curR) curR = e;
            } else {
                total += curR - curL + 1;
                curL = s;
                curR = e;
            }
        }
        total += curR - curL + 1;
        long long bulbs = (brightness + 2) / 3;
        return bulbs * total;
    }
};
```

### Python

```python
class Solution:
    def minEnergy(self, n: int, brightness: int, intervals: list[list[int]]) -> int:
        intervals = sorted(intervals)
        total = 0
        cur_l, cur_r = intervals[0]
        for s, e in intervals[1:]:
            if s <= cur_r:
                cur_r = max(cur_r, e)
            else:
                total += cur_r - cur_l + 1
                cur_l, cur_r = s, e
        total += cur_r - cur_l + 1
        bulbs = (brightness + 2) // 3
        return bulbs * total
```

## 8. 边界情况与易错点

1. **`brightness = n`（满亮度）**：需要照亮整排，答案仍是 $\lceil n/3 \rceil \times T$；示例 1 就是 $n = 5$、$b = 5$，2 个灯泡。
2. **区间首尾相接但不重叠**（如 `[0,1]` 与 `[2,3]`）：交集为空，应算作两段各 2 个单位、总长 4；合并与否不影响长度，但若用「`s <= curR + 1` 才合并」的写法要注意长度仍正确。
3. **区间完全包含**（如 `[1,5]` 与 `[2,3]`）：合并时右端取 `max`，不能直接赋成后一段的右端。
4. **长度公式**：闭区间要 `+1`，漏掉会系统性少算。
5. **64 位**：$10^5$ 段、每段端点可达 $10^9$，总能量可达 $10^{14}$ 量级，`int` 溢出。
6. **`ceil(b/3)` 的写法**：`(b + 2) / 3`；不要用 `b / 3 + 1`（$b$ 为 3 的倍数时会多 1）。
7. **不要按时间模拟**：`start`、`end` 可到 $10^9$，逐格循环必然超时。
