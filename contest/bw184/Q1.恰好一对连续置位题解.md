# LeetCode 恰好一对连续置位 题解

## 1. 题目概述

- **标题 / 题号**：恰好一对连续置位（#3950，easy）
- **链接**：https://leetcode.cn/problems/exactly-one-consecutive-set-bits-pair/
- **来源**：LeetCode 第 184 场双周赛 Q1
- **难度**：简单
- **标签**：位运算

**题意**：给定整数 $n$。若其二进制表示中**恰好**只包含**一对**相邻的置位（「置位」= 二进制中的 `1`），返回 `true`，否则返回 `false`。

「一对相邻置位」指下标 $(i, i+1)$ 的两个位**同时**为 1；它数的是**位置对**的个数，不是「连续 1 的段数」。

**约束**：

- $0 \le n \le 10^5$

## 2. 示例

**示例 1**

```text
输入：n = 6
输出：true
解释：6 = 110(2)，位 1 与位 0 同时为 1，恰好一对相邻置位。
```

**示例 2**

```text
输入：n = 5
输出：false
解释：5 = 101(2)，两个 1 不相邻，一对也没有。
```

**补充示例**

```text
n = 7  → 111(2)：位(0,1) 与位(1,2) 都是相邻置位对，共 2 对 → false
n = 3  → 11(2)：恰好 1 对 → true
n = 0  → 0：没有任何置位 → false
```

## 3. 解题思路

### 3.1 暴力思路

把 $n$ 的二进制写出来（或用 `n >> i & 1` 逐位取），统计有多少个 $i$ 满足「第 $i$ 位与第 $i+1$ 位都为 1」。位数只有 $\lfloor \log_2 n \rfloor + 1 \le 17$，$O(\log n)$ 的逐位比较完全够用。这已经是最优复杂度，但可以写得更短。

### 3.2 核心观察：`n & (n >> 1)` 一次收集所有相邻对

![恰好一对连续置位：用 n & (n >> 1) 收集所有相邻对](images/bw184_q1_bits.svg)

把 $n$ 右移一位后与原数按位与，得到

$$t = n \ \& \ (n \gg 1)$$

$t$ 的第 $i$ 位为 1 $\iff$ $n$ 的第 $i$ 位与第 $i+1$ 位同时为 1。于是：

- **相邻置位对的个数** $= \operatorname{popcount}(t)$；
- 要求「恰好一对」$\iff \operatorname{popcount}(t) = 1$；
- 「恰好一个 1」的位运算判据：$t \ne 0$ 且 $t \ \& \ (t-1) = 0$（后者把最低位的 1 消掉，若结果为 0 说明只有一个 1）。

两步都是 $O(1)$ 的机器指令，无需循环。

### 3.3 算法流程

```text
1. t = (unsigned)n & ((unsigned)n >> 1)
2. 返回 t != 0 且 (t & (t-1)) == 0
```

### 3.4 示例演算

![示例演算：数一数有几处「11」](images/bw184_q1_walkthrough.svg)

| $n$ | 二进制 | $t = n \ \& \ (n \gg 1)$ | `popcount(t)` | 结论 |
|-----|--------|---------------------------|----------------|------|
| 6 | `110` | `110 & 011 = 010` | 1 | `true` |
| 5 | `101` | `101 & 010 = 000` | 0 | `false` |
| 7 | `111` | `111 & 011 = 011` | 2 | `false` |
| 3 | `11` | `11 & 01 = 01` | 1 | `true` |
| 0 | `0` | `0` | 0 | `false` |

注意 $n = 7$ 是最典型的反例：连续三个 1 会产生**两对**（重叠在中间那个 1 上），所以「连续 1 的长度为 2」与「恰好一对」不是一回事。

## 4. 算法细节

1. **无符号化**：`n` 非负且 $\le 10^5$，但为了移位语义安全，先转 `unsigned`（Python 无此问题）。
2. **`t & (t-1)` 的含义**：清掉最低位的 1。结果非零说明还有别的 1，即 `popcount(t) >= 2`。
3. **必须先判 `t != 0`**：$t = 0$ 时 `t & (t-1)` 也是 0，若不判 `t != 0` 会把「没有相邻对」误判成 `true`。
4. **不需要知道对的个数**：只要「至少一个」且「不超过一个」，用「是否为 2 的幂」是最省事的写法。若题目改成「恰好 $c$ 对」，直接 `__builtin_popcount(t) == c`。
5. **Python 的 `n >> 1` 与 `&`**：Python 整数无溢出问题，直接写即可。

## 5. 正确性证明

**引理 1（$t$ 的位语义）**：对任意 $i \ge 0$，$t = n \ \& \ (n \gg 1)$ 的第 $i$ 位为 1 当且仅当 $n$ 的第 $i$ 位与第 $i+1$ 位都为 1。

**证明**：$(n \gg 1)$ 的第 $i$ 位就是 $n$ 的第 $i+1$ 位；按位与要求两者同时为 1。∎

**引理 2（幂次判据）**：$t \ne 0$ 且 $t \ \& \ (t-1) = 0$ 当且仅当 $\operatorname{popcount}(t) = 1$。

**证明**：$t-1$ 把 $t$ 最低位的 1 变成 0、把它右边的 0 全变成 1，其余位不变，因此 $t \ \& \ (t-1)$ 恰为「去掉最低位 1」的结果。若 $\operatorname{popcount}(t) = 1$，去掉后为 0；若 $\operatorname{popcount}(t) \ge 2$，去掉一个 1 后仍非零。再结合 $t \ne 0$（即 $\operatorname{popcount} \ge 1$），结论成立。∎

**定理**：算法返回 `true` 当且仅当 $n$ 的二进制表示中恰好有一对相邻置位。

**证明**：由引理 1，相邻置位对的个数等于 $\operatorname{popcount}(t)$；由引理 2，算法的返回条件等价于 $\operatorname{popcount}(t) = 1$。两者结合即得结论。∎

## 6. 复杂度分析

- **时间**：$O(1)$（常数次位运算，与 $n$ 的大小无关，机器字长内一次完成）。
- **空间**：$O(1)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool consecutiveSetBits(int n) {
        unsigned int u = (unsigned int)n;
        unsigned int t = u & (u >> 1);
        return t != 0 && (t & (t - 1)) == 0;
    }
};
```

### Python

```python
class Solution:
    def consecutiveSetBits(self, n: int) -> bool:
        t = n & (n >> 1)
        return t != 0 and (t & (t - 1)) == 0
```

## 8. 边界情况与易错点

1. **$n = 0$**：没有置位，`t = 0`，必须返回 `false`。漏掉 `t != 0` 判断会返回 `true`。
2. **连续三个及以上的 1**：$n = 7 = 111$ 有 2 对，答案是 `false`；把它误当成「连续 1 的段长为 2」就会答错。
3. **`popcount` 与「1 的个数」的区别**：$n = 6$ 与 $n = 3$ 的置位个数都是 2、相邻对都是 1；但 $n = 9 = 1001$ 的置位个数是 2、相邻对是 0，答案 `false`。
4. **移位符号问题**：`int` 右移在高位是符号位，对非负数无影响；写成 `unsigned` 可彻底避免疑问。
5. **`t & (t-1)` 的前置条件**：只在 $t \ne 0$ 时才有「消掉最低位 1」的意义，先判非零再判幂。
6. **不要循环统计**：虽然循环也对，但本题的数据范围小、位运算更贴合「位运算」标签，也更快。
