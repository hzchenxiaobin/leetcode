# LeetCode 选择不同 X 值三元组使 Y 值之和最大 题解

## 1. 题目概述

- **标题 / 题号**：选择不同 X 值三元组使 Y 值之和最大（#3572，medium）
- **链接**：https://leetcode.cn/problems/maximize-ysum-by-picking-a-triplet-of-distinct-xvalues/
- **来源**：LeetCode 第 158 场双周赛 Q1
- **难度**：中等
- **标签**：贪心、数组、哈希表、排序、堆（优先队列）

**题意**：给定两个长度均为 $n$ 的整数数组 $x$ 与 $y$。选择三个**互不相同**的下标 $i, j, k$，要求 $x_i, x_j, x_k$ **两两不同**（即三个 $x$ 值互不相等），在满足条件的前提下最大化 $y_i + y_j + y_k$。若不存在这样的三元组，返回 $-1$。

**约束**：

- $3 \le n \le 10^5$
- $1 \le x_i, y_i \le 10^6$

> 💡 约束里的 $y_i \ge 1$ 很关键：所有 $y$ 都是正数，所以「选满三个」永远比「少选」好，问题变成纯贪心，不需要考虑负数带来的取舍。

## 2. 示例

**示例 1**

```text
输入：x = [1,2,1,3,2], y = [5,3,4,6,2]
输出：14
解释：选下标 0（x=1, y=5）、1（x=2, y=3）、3（x=3, y=6），5+3+6 = 14。
```

**示例 2**

```text
输入：x = [1,2,1,2], y = [4,5,6,7]
输出：-1
解释：x 只有 1 和 2 两个不同值，凑不出三个互不相同的 x。
```

**示例 3（自造）**

```text
输入：x = [1,1,2,2,3,3], y = [100,1,90,2,80,3]
输出：270
解释：每个 x 取自己的最大 y：1→100, 2→90, 3→80，和为 270。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有 $\binom{n}{3} = O(n^3)$ 个下标三元组，检查三个 $x$ 是否互不相同，取最大 $y$ 之和。$n = 10^5$ 时约 $1.7\times 10^{14}$ 次枚举，完全不可行。即使只枚举「不同 $x$ 值的三元组」，$D^3$ 在 $D = 10^5$ 时同样是 $10^{15}$ 级别。

### 3.2 核心观察：同一个 $x$ 只留最大的 $y$

![同一个 x 只保留最大的 y，再取前三名](images/bw158_q1_dedupe_max.svg)

- 三元组要求三个 $x$ **两两不同**，因此每个 $x$ 值在下标意义上只能贡献**一个**元素。
- 对固定的 $x$，如果有多组 $(x, y)$，显然只有**最大的**那个 $y$ 有意义：任何用到次大 $y$ 的方案，把它换成同 $x$ 的最大 $y$ 仍然满足「$x$ 两两不同」，且和变大（或不变）。
- 于是问题被压缩成：从「每个不同 $x$ 的最大 $y$」这个集合里，挑出**最大的 3 个**求和；若不同 $x$ 的个数 $< 3$，返回 $-1$。

### 3.3 算法流程

![算法流程：map 取每组最大 -> 判个数 -> 取前三](images/bw158_q1_flow.svg)

```text
1. best = 空哈希表（x 值 -> 最大 y）
2. for i = 0 .. n-1:  best[x[i]] = max(best[x[i]], y[i])
3. 若 |best| < 3: 返回 -1
4. 把 best 的 value 降序排序，返回前 3 项之和
```

也可以用大小为 3 的小根堆代替排序，把第 4 步降到 $O(D\log 3)$——但 $D \le 10^5$ 时排序已经足够快。

### 3.4 示例演算

![两个示例分别命中「有解」与「无解」](images/bw158_q1_example_walk.svg)

| 示例 | 输入 | 每组最大值 | 答案 |
|------|------|-----------|------|
| 1 | $x=[1,2,1,3,2]$，$y=[5,3,4,6,2]$ | $1\to5$，$2\to3$（$y=2$ 被丢弃），$3\to6$ | $5+3+6=14$ |
| 2 | $x=[1,2,1,2]$，$y=[4,5,6,7]$ | $1\to6$，$2\to7$ | $-1$（只有 2 个不同 $x$） |

示例 1 中 $x=2$ 出现了两次（$y=3$ 与 $y=2$），保留 $3$；$x=1$ 出现两次（$y=5$ 与 $y=4$），保留 $5$。

## 4. 算法细节

1. **哈希表还是排序**：哈希表一遍扫描 $O(n)$，最直接；也可以把 $(x, y)$ 按 $x$ 排序后每段取最大 $y$，$O(n\log n)$。前者更优。
2. **只保留最大值**：更新时写 `best[x] = max(best[x], y)`，不要覆盖成「最后一次出现的 $y$」。
3. **判无解**：`|best| < 3` 时直接返回 $-1$；注意 $n \ge 3$ 不代表一定有解（示例 2）。
4. **取前三大**：降序排序后取前 3，或维护大小为 3 的小根堆，堆顶即第 3 大。
5. **数值范围**：$y_i \le 10^6$，三个之和 $\le 3\times 10^6$，`int` 足够；返回类型是 `int`。
6. **重复 $x$ 的「丢弃」不影响合法性**：被丢弃的只是同 $x$ 的较小 $y$，而三元组本就要求 $x$ 互不相同，所以丢弃不会损失可行解。

## 5. 正确性证明

**引理 1（同 $x$ 只留最大 $y$）**：设 $S$ 为所有下标集合，对每个 $x$ 值令 $M(x) = \max\{y_i : x_i = x\}$，并取一个达到该最大值的下标 $p(x)$。则对任意合法三元组 $(i,j,k)$，$(p(x_i), p(x_j), p(x_k))$ 也是合法三元组，且 $y$ 之和不小于原来的。

**证明**：三个 $x$ 值两两不同，所以 $p(x_i), p(x_j), p(x_k)$ 是三个 $x$ 值互不相同的下标，仍是合法三元组。由 $M$ 的定义，$y_{p(x_i)} = M(x_i) \ge y_i$，其余两个同理，故和不变小。∎

**引理 2（取最大的三个）**：设不同 $x$ 值对应的 $M$ 值集合为 $\{m_1 \ge m_2 \ge \dots \ge m_D\}$，$D \ge 3$。则最大和为 $m_1 + m_2 + m_3$。

**证明**：任意合法三元组对应三个不同 $x$，其和不超过这三个 $x$ 各自 $M$ 值之和，而后者不超过 $M$ 值中最大的三个之和。取 $m_1, m_2, m_3$ 对应的三个 $x$ 即可达到该上界，故上界可取。∎

**定理**：算法返回值等于题目要求的最大和（无解时返回 $-1$）。

**证明**：由引理 1，最优解可以在「每个 $x$ 只取最大 $y$」的集合里找到；若 $D < 3$，任何三元组都无法满足「三个 $x$ 两两不同」，返回 $-1$ 正确；若 $D \ge 3$，由引理 2，排序后前 3 项之和即为答案。∎

## 6. 复杂度分析

- **时间**：$O(n + D\log D) \le O(n\log n)$。建表一遍扫描 $O(n)$（哈希表均摊 $O(1)$ 每次），排序 $D$ 个值 $O(D\log D)$，$D \le n$。
- **空间**：$O(D) \le O(n)$，存放每个不同 $x$ 的最大 $y$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maxSumDistinctTriplet(vector<int>& x, vector<int>& y) {
        unordered_map<int, int> best;   // x 值 -> 该 x 下的最大 y
        for (int i = 0; i < (int)x.size(); i++) {
            auto it = best.find(x[i]);
            if (it == best.end()) best[x[i]] = y[i];
            else it->second = max(it->second, y[i]);
        }
        if (best.size() < 3) return -1;  // 不同 x 不足 3 个
        vector<int> v;
        v.reserve(best.size());
        for (auto& kv : best) v.push_back(kv.second);
        sort(v.begin(), v.end(), greater<int>());
        return v[0] + v[1] + v[2];
    }
};
```

### Python

```python
class Solution:
    def maxSumDistinctTriplet(self, x: list[int], y: list[int]) -> int:
        best = {}                    # x 值 -> 该 x 下的最大 y
        for xi, yi in zip(x, y):
            if xi not in best or yi > best[xi]:
                best[xi] = yi
        if len(best) < 3:            # 不同 x 不足 3 个
            return -1
        top = sorted(best.values(), reverse=True)[:3]
        return sum(top)
```

## 8. 边界情况与易错点

1. **$n \ge 3$ 但不同 $x$ 只有 2 个**：返回 $-1$（示例 2），不能返回 0 或最大的两个之和。
2. **覆盖而非取最大**：`best[x] = y` 会把之前的更大值冲掉，必须 `max`。
3. **排序方向**：要最大的三个，降序取前 3；升序取前 3 会得到最小值。
4. **同 $x$ 的次大 $y$ 不能重复使用**：三元组要求 $x$ 两两不同，同一个 $x$ 只能贡献一个下标。
5. **$y$ 全为正**：所以「选满 3 个」永远不亏；若题目允许负数，则需要重新考虑「是否少选」，本题不需要。
6. **下标互不相同**：三个不同 $x$ 必然对应三个不同下标，无需额外判重。
