# LeetCode 买卖股票的最佳时机 V 题解

## 1. 题目概述

- **标题 / 题号**：买卖股票的最佳时机 V（#3573，medium）
- **链接**：https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-v/
- **来源**：LeetCode 第 158 场双周赛 Q2
- **难度**：中等
- **标签**：数组、动态规划

**题意**：给定每日股价 `prices` 与最多可做的交易笔数 $k$。每笔交易是以下两种之一：

1. **普通交易**：第 $i$ 天买入、第 $j$ 天（$i < j$）卖出，利润 $p_j - p_i$；
2. **做空交易**：第 $i$ 天卖出、第 $j$ 天（$i < j$）买回，利润 $p_i - p_j$。

要求上一笔交易**完全结束**才能开始下一笔，且同一天不能既买又卖。求最多 $k$ 笔交易的**最大总利润**。

**约束**：

- $2 \le n \le 1000$
- $1 \le p_i \le 10^9$
- $1 \le k \le n/2$

> 💡 两种交易的利润都可以写成 $|p_j - p_i|$ ——「方向」只是符号，这是本题化简的起点。

## 2. 示例

**示例 1**

```text
输入：prices = [1,7,9,8,2], k = 2
输出：14
解释：普通交易第 0 天买、第 2 天卖：9-1 = 8；做空交易第 3 天卖、第 4 天买回：8-2 = 6；合计 14。
```

**示例 2**

```text
输入：prices = [12,16,19,19,8,1,19,13,9], k = 3
输出：36
解释：[0,2] 赚 7；[3,4] 做空赚 11；[5,6] 赚 18；合计 7+11+18 = 36。
```

**示例 3（自造）**

```text
输入：prices = [5,1], k = 1
输出：4
解释：做空：第 0 天卖 5，第 1 天买回 1，赚 4。
```

## 3. 解题思路

### 3.1 暴力思路

枚举每笔交易的起止日：设 $f[j][i]$ 表示「前 $i$ 天（下标 $0..i-1$）内最多做 $j$ 笔交易」的最大利润，则

$$f[j][i] = \max\Big(f[j][i-1],\ \max_{s < i-1}\big(f[j-1][s] + |p_{i-1} - p_s|\big)\Big)$$

状态数 $O(kn)$，每个状态枚举起点 $O(n)$，总 $O(kn^2)$。$n = 1000$、$k = 500$ 时是 $5\times 10^8$，Python 直接超时，C++ 也偏慢。注意到「$\max_{s}$ 这一层」可以从左往右滚动维护。

### 3.2 核心观察：两种交易都是「区间上的价格差绝对值」

![两种交易统一成同一条公式](images/bw158_q2_interval_model.svg)

- 普通交易利润 $p_j - p_i$，做空利润 $p_i - p_j$，合起来就是 $|p_j - p_i|$。所以一笔交易 $=$ 选一段区间 $[i, j]$（$i < j$），收益为这段区间端点价格之差的绝对值。
- 「上一笔结束才能开始下一笔」「同一天不能既买又卖」$\Rightarrow$ 各笔交易对应的区间**互不重叠且不共享端点**，即「上一笔的右端点 $<$ 下一笔的左端点」。
- 于是问题变成：**从 $n$ 天里选至多 $k$ 个不相交区间，使 $\sum |p_{\text{右}} - p_{\text{左}}|$ 最大**。

再看转移中的内层最大值：

$$|p_i - p_s| = \max\big(p_i - p_s,\ p_s - p_i\big)$$

于是

$$\max_{s<i}\Big(\text{prev}(s) + |p_i - p_s|\Big) = \max\Big(-p_i + \underbrace{\max_s(\text{prev}(s) + p_s)}_{\text{bestA}},\ \ p_i + \underbrace{\max_s(\text{prev}(s) - p_s)}_{\text{bestB}}\Big)$$

其中 $\text{prev}(s)$ 是「在前 $s-1$ 天、用 $j-1$ 笔交易能取得的最大利润」（$s = 0$ 时为 $0$）。只要在 $i$ 递增时**滚动维护 `bestA` 与 `bestB`**，内层枚举就消失了。

### 3.3 算法流程

![O(kn) 的 DP：把枚举起点换成两个滚动最大值](images/bw158_q2_dp_transition.svg)

```text
prev[] = 0                       # 0 笔交易时，任意前缀利润都是 0
for j = 1 .. k:
    cur[0] = 0；bestA = bestB = -inf
    for i = 0 .. n-1:
        cand = -inf
        if i >= 1:
            cand = max(-p[i] + bestA, p[i] + bestB)     # 以 i 为结束日的第 j 笔
        cur[i] = max(cur[i-1] (i>=1 时), cand)          # 也可以不用这第 j 笔
        before = (i == 0 ? 0 : prev[i-1])               # 上一笔必须在 i 之前结束
        bestA = max(bestA, before + p[i])               # 把 i 登记为「下一笔的开始日」
        bestB = max(bestB, before - p[i])
    prev = cur
返回 prev[n-1]
```

**注意顺序**：计算第 $i$ 天的 `cand` 时，`bestA/bestB` 里只能包含 $s < i$ 的开始日，所以「先把 $i$ 作为结束日算完，再把 $i$ 登记为开始日」。

### 3.4 示例演算

![示例 1 与示例 2 的交易拆解](images/bw158_q2_example_walk.svg)

| 示例 | 交易 1 | 交易 2 | 交易 3 | 合计 |
|------|--------|--------|--------|------|
| 1: $[1,7,9,8,2]$，$k=2$ | $[0,2]$：$9-1=8$ | $[3,4]$：$8-2=6$ | — | $14$ |
| 2: $[12,16,19,\dots]$，$k=3$ | $[0,2]$：$19-12=7$ | $[3,4]$：$19-8=11$ | $[5,6]$：$19-1=18$ | $36$ |

对示例 1 逐层看：$j=1$ 时 `prev` 变为 $[0,6,8,8,8]$（一笔交易最多赚 8）；$j=2$ 时在 $i=4$ 处由 `bestA`（来自 $s=3$，值 $8+8=16$）给出 $16-2 = 14$，与答案一致。

## 4. 算法细节

1. **状态定义**：`prev[i]` 是「下标 $0..i$ 内、至多 $j-1$ 笔」的答案；`prev` 天然单调不减（多一天不可能更差），因此 `prev[i-1]` 就是「前 $i$ 天」的最优值。
2. **两个滚动量**：`bestA = max(prev(s) + p_s)`、`bestB = max(prev(s) - p_s)`，两者都是「以 $s$ 为起点」的信息，与 $i$ 无关，故可 $O(1)$ 更新。
3. **更新顺序**：`cand` 必须在把 $i$ 登记为起点**之前**计算，否则会出现「同一天买卖」的非法交易。
4. **「至多」而非「恰好」**：`cur[i] = max(cur[i-1], cand)`，保证少用一笔也行；示例 1 的最优解只用了 2 笔中的 2 笔，但很多用例最优解笔数 $< k$。
5. **负值哨兵**：`bestA/bestB` 初始化为一个极小值（C++ 用 `LLONG_MIN/4`，Python 用 `-(10**18)`），避免 $i=0$ 时用到非法起点。
6. **数值范围**：单笔利润最大 $10^9$，$k \le 500$，总和最大 $5\times 10^{11}$，必须用 `long long`。
7. **空间**：只需两行 `prev`、`cur`，滚动数组 $O(n)$；不需要 $k \times n$ 的二维表。

## 5. 正确性证明

**引理 1（收益归约）**：任意一笔合法交易（普通或做空）的利润等于其起止日价格之差的绝对值；反之，任意一对 $i < j$ 都对应恰好一种合法交易（$p_j > p_i$ 时做多，否则做空），收益为 $|p_j - p_i|$。

**证明**：普通交易利润 $p_j - p_i$，做空利润 $p_i - p_j$，二者分别是 $p_j - p_i$ 的正部与负部绝对值，合起来覆盖 $|p_j - p_i|$ 的全部情形。∎

**引理 2（区间模型等价）**：最多 $k$ 笔交易的最大总利润，等于「选至多 $k$ 个右端点严格小于下一个左端点的不相交区间 $[s, e]$，最大化 $\sum |p_e - p_s|$」。

**证明**：由引理 1，每笔交易 $\leftrightarrow$ 一个区间且收益相同；「上一笔结束才能开始下一笔」+「同一天不能既买又卖」$\iff$ 相邻区间满足 $e_{\text{前}} < s_{\text{后}}$。两个方向的对应关系都是一一的。∎

**引理 3（转移等价）**：算法中的 `cand`（在 $i$ 处）等于 $\max_{s<i}\big(\text{prev}(s) + |p_i - p_s|\big)$。

**证明**：$\text{prev}(s) = $ 前 $s-1$ 天用 $j-1$ 笔的最优值，正是「第 $j$ 笔以 $s$ 为起点」的合法前缀值。而

$$\text{prev}(s) + |p_i - p_s| = \max\big(\text{prev}(s) + p_i - p_s,\ \text{prev}(s) - p_i + p_s\big) = \max\big(p_i + (\text{prev}(s) - p_s),\ -p_i + (\text{prev}(s) + p_s)\big)$$

对 $s$ 取 $\max$ 时，$p_i$ 与 $-p_i$ 与 $s$ 无关可提到外层，内层正是 `bestA`、`bestB` 的定义。由于 `bestA/bestB` 在计算 `cand` 之前只吸收了 $s < i$ 的项，故恰为 $\max_{s<i}$。∎

**定理**：算法返回值为题目要求的最大总利润。

**证明**：对 $j$ 归纳。$j = 0$ 时 `prev` 全 0，正确（不做交易利润 0）。设 `prev` 是 $j-1$ 笔的最优值表。对每个 $i$，`cur[i] = max(cur[i-1], cand)`：第一项表示第 $j$ 笔不用（退化为 $j-1$ 笔的最优），第二项由引理 3 表示「以 $i$ 为结束日的第 $j$ 笔」的最优。两者取最大即为「前 $i$ 天内至多 $j$ 笔」的最优值，故归纳成立。最终 `prev[n-1]` 即答案。∎

## 6. 复杂度分析

- **时间**：$O(kn)$。外层 $k$ 笔，内层 $n$ 天，每天 $O(1)$ 次取最大值。$k \le n/2 = 500$、$n \le 1000$，共约 $5\times 10^5$ 次操作。
- **空间**：$O(n)$。两行滚动数组 `prev`、`cur`，外加若干标量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long maximumProfit(vector<int>& prices, int k) {
        int n = (int)prices.size();
        // prev[i] = 前 i+1 天（0..i）内最多 j-1 笔交易的最大利润
        vector<long long> prev(n, 0), cur(n, 0);
        for (int j = 1; j <= k; j++) {
            long long bestA = LLONG_MIN / 4;  // max(prevProfit(s) + p[s])
            long long bestB = LLONG_MIN / 4;  // max(prevProfit(s) - p[s])
            cur[0] = 0;
            for (int i = 0; i < n; i++) {
                long long cand = LLONG_MIN / 4;
                if (i >= 1) {
                    // 以 i 为结束日：|p[i] - p[s]| = max(-p[i] + (prev+p[s]), p[i] + (prev-p[s]))
                    cand = max(cand, -1LL * prices[i] + bestA);
                    cand = max(cand, 1LL * prices[i] + bestB);
                }
                cur[i] = max(i >= 1 ? cur[i - 1] : 0LL, cand);
                // 把 i 登记为「下一笔交易的开始日」候选
                long long before = (i == 0) ? 0 : prev[i - 1];
                bestA = max(bestA, before + prices[i]);
                bestB = max(bestB, before - prices[i]);
            }
            prev.swap(cur);
        }
        return prev[n - 1];
    }
};
```

### Python

```python
class Solution:
    def maximumProfit(self, prices: list[int], k: int) -> int:
        n = len(prices)
        NEG = -(10 ** 18)
        # prev[i] = 前 i+1 天（0..i）内最多 j-1 笔交易的最大利润
        prev = [0] * n
        for _ in range(k):
            cur = [0] * n
            bestA = NEG      # max(prevProfit(s) + p[s])
            bestB = NEG      # max(prevProfit(s) - p[s])
            for i in range(n):
                cand = NEG
                if i >= 1:
                    # 以 i 为结束日：|p[i]-p[s]| = max(-p[i] + (prev+p[s]), p[i] + (prev-p[s]))
                    cand = max(-prices[i] + bestA, prices[i] + bestB)
                cur[i] = max(cur[i - 1] if i >= 1 else 0, cand)
                # 把 i 登记为「下一笔交易的开始日」候选
                before = 0 if i == 0 else prev[i - 1]
                bestA = max(bestA, before + prices[i])
                bestB = max(bestB, before - prices[i])
            prev = cur
        return prev[n - 1]
```

## 8. 边界情况与易错点

1. **同一天买卖**：`cand` 必须用「只含 $s < i$」的 `bestA/bestB` 计算，再把 $i$ 登记为起点；顺序颠倒会造出 $s = i$ 的零长度交易。
2. **`bestB` 的符号**：`bestB = max(prev(s) - p_s)`，对应 $+p_i$；写反会算出 $p_i + p_s$ 这种量纲错误的表达式。
3. **「至多」$k$ 笔**：`cur[i] = max(cur[i-1], cand)` 少一个都不行；示例 1 的 $k=2$ 但最优只用 2 笔，而很多用例最优笔数 $< k$。
4. **$i = 0$ 不能做交易**：一笔交易需要 $i < j$，所以 $i=0$ 时 `cand` 必须保持负无穷。
5. **哨兵值**：`LLONG_MIN/4` 而不是 `LLONG_MIN`，避免 `-p_i + bestA` 时下溢。
6. **`long long` 溢出**：$k\times 10^9$ 可达 $5\times 10^{11}$，`int` 会溢出。
7. **$k$ 可以很大**：约束保证 $k \le n/2$，即使不保证，$O(kn)$ 也只要把 $k$ 截到 $n/2$ 即可（每笔至少占 2 天）。
8. **价格相等**：$p_i = p_j$ 时收益 0，不影响正确性，但会参与 `max`，无需特判。
