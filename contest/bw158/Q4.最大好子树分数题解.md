# LeetCode 最大好子树分数 题解

## 1. 题目概述

- **标题 / 题号**：最大好子树分数（#3575，hard）
- **链接**：https://leetcode.cn/problems/maximum-good-subtree-score/
- **来源**：LeetCode 第 158 场双周赛 Q4
- **难度**：困难
- **标签**：位运算、树、深度优先搜索、数组、动态规划、位掩码

**题意**：给定一棵以节点 $0$ 为根的 $n$ 个节点的树（父数组 `par`）。每个节点 $i$ 有权值 `vals[i]`。

若从某个节点的**子树**中选出一部分节点，使它们的十进制表示里**每个数字 $0\sim 9$ 最多出现一次**（跨所有被选数字统计），则称这个子集是**好**的，其**分数**为被选节点权值之和。

令 `maxScore[u]` 表示以 $u$ 为根的子树内好子集的最大分数，求 $\sum_u \text{maxScore}[u] \bmod (10^9+7)$。

**约束**：

- $1 \le n \le 500$
- $1 \le \text{vals}[i] \le 10^9$（数位最多 10 位）
- `par[0] == -1`，$0 \le \text{par}[i] < n$，且 `par` 表示一棵合法的树

> 💡 关键信息：`vals[i] <= 1e9` 意味着一个数最多 10 位数字，而数字种类恰好是 $0\sim9$ 十种 —— 这强烈暗示用 **10 位掩码**表示「已用了哪些数字」。

输出：8
解释：节点 0 的子树 {0,1}：选 {2,3} 是好子集，分数 5；节点 1 的子树 {1}：分数 3。
     maxScore = [5,3]，总和 8。
```

```

输入：vals = [34,1,2], par = [-1,0,1]
输出：42
解释：maxScore = [37,3,2]，总和 42（34、1、2 的数位 3,4,1,2 互不重复）。
```

```

## 3. 解题思路

### 3.1 暴力思路

对每个节点 $u$，其子树大小记为 $s_u$，好子集有 $2^{s_u}$ 个候选，逐个检验数位冲突（$O(10)$ 每元素）。最坏情况（一条链）$\sum_u 2^{s_u} \approx 2^n$，$n = 500$ 时完全不可能。即便用「只有数位合法的节点才能入选」剪枝，链状数据仍是灾难。

### 3.2 核心观察：把「数位不重复」压成 10 位掩码

![数位掩码：好子集等价于掩码两两不交](images/bw158_q4_mask_model.svg)

- 每个数 $v$ 对应一个掩码 $m_v$：第 $d$ 位为 $1$ 表示数字 $d$ 出现过。若 $v$ 自身有重复数字（如 $22$、$100$），则 $m_v$ 非法，该节点**永远不能入选**（但可以作为「空集」的一部分，不影响合并）。
- 一个子集是好的 $\iff$ 其所有元素的掩码**两两不交** $\iff$ 掩码的按位与为 $0$ 逐步成立。
- 掩码只有 $2^{10} = 1024$ 种，于是可以对每个节点维护一个长度 1024 的 DP 数组：

$$f_u[\text{mask}] = \text{子树 } u \text{ 内、数位集合恰为 mask 的好子集的最大分数}$$

### 3.3 算法流程

![树上 DP：每个掩码一个最大分数，孩子间用子集卷积合并](images/bw158_q4_merge.svg)

```text
1. 建孩子表；迭代 DFS 得到「孩子先于父亲」的处理顺序
2. 每个节点算出掩码 mask[u]（有重复数位则标记非法）
3. 逆序处理每个节点 u：
      f[0] = 0；若 mask[u] 合法则 f[mask[u]] = vals[u]
      for 每个孩子 v:
          用 max-plus 子集卷积合并：g[m] = max over sub ⊆ m of (f[sub] + f_v[m ^ sub])
          f = g
      maxScore[u] = max over m of f[m]
4. 把所有 maxScore[u] 累加取模
```

**合并为什么是子集卷积**：$f[\text{sub}]$ 描述「已合并部分用掉的数位集合恰为 sub」，孩子的 $f_v[m \oplus \text{sub}]$ 描述「孩子用的数位集合恰为 $m \oplus \text{sub}$」，两者不交（因为 $m \oplus \text{sub}$ 与 $\text{sub}$ 是 $m$ 的互补子集），合并后总掩码恰为 $m$。对 $m$ 的所有子掩码枚举一遍，总计 $\sum_m 2^{\text{popcount}(m)} = 3^{10} \approx 5.9\times 10^4$ 次转移。

### 3.4 示例演算

![示例 1 的 DP 过程](images/bw158_q4_example_walk.svg)

`vals = [2,3]`、`par = [-1,0]`：

| 节点 | 子树 | $f_u$ 的非零项 | $\max$ |
|------|------|----------------|--------|
| 1（叶子，值 3） | $\{3\}$ | $f[0]=0$，$f[\{3\}]=3$ | 3 |
| 0（根，值 2） | $\{2,3\}$ | $f[0]=0$，$f[\{2\}]=2$，$f[\{3\}]=3$，$f[\{2,3\}]=5$ | 5 |

总和 $5 + 3 = 8$，与示例 1 一致。示例 4 中 `vals[1] = 22` 的掩码含两个 $2$，节点 1 自身非法，只能以空集身份参与合并，所以根的 `maxScore` 是 $3 + 5 = 8$。

## 4. 算法细节

1. **掩码合法性**：逐位取数位，若某位已出现则标记非法（`ok = false`）；`vals[i] >= 1` 保证至少一位。
2. **非法节点的处理**：不要把它从树里删掉——它的子树仍然要算 `maxScore`，只是它自己不能入选（$f$ 中没有 $f[\text{mask}_u]$ 这一项）。
3. **空集是合法状态**：$f[0] = 0$，保证「什么都不选」永远是候选，也保证合并时两边都可以取空。
4. **处理顺序**：用「先序序列的逆序」即可保证孩子先于父亲（先序中父在子前），无需真递归。
5. **子集枚举技巧**：`for (int sub = m;; sub = (sub-1)&m) { ... if (sub == 0) break; }` 是标准的降序枚举子掩码写法，注意 `sub = 0` 后要立即跳出，否则 `(0-1)&m = m` 会死循环。
6. **不可达状态**：用 $-1$ 表示「该掩码无法凑出」，转移时要求两边都 $\ge 0$；也可以直接把 $f$ 初始化为 $-1$ 并在取最大值时忽略。
7. **结果二是「恰好」**：$f[m]$ 的语义是**恰好**用了集合 $m$，不是「$m$ 的子集」。若改成「至多」，子集卷积的形式会变，容易被误用。
8. **取模**：$f$ 的值可达 $500\times 10^9 = 5\times10^{11}$，用 `long long` 存储**不取模**（取模会破坏大小比较！），只在累加 $\sum_u \text{maxScore}[u]$ 时取模。

## 5. 正确性证明

**引理 1（好子集的掩码刻画）**：一个节点子集是好子集 $\iff$ 其中每个节点的掩码合法，且所有掩码按位与两两为 $0$（等价地，它们的并集掩码的 popcount 等于各掩码 popcount 之和）。

**证明**：好子集要求每个数字在所有被选数字的十进制表示中出现至多一次。若某节点自身含重复数字，它单独就违反条件，故必须掩码合法。若两个节点掩码有交集，则存在数字 $d$ 同时出现在两个数的表示中，出现两次，违反条件；反之若所有掩码两两不交，则每个数字最多被一个节点贡献一次，条件成立。∎

**引理 2（合并转移的完备性）**：设 $u$ 的孩子为 $v_1,\dots,v_k$。用 $f^{(t)}[m]$ 表示「合并前 $t$ 个孩子后，子树部分用掉的数位集合恰为 $m$ 的最大分数」，则初值 $f^{(0)}$ 只含 $\{0 \to 0,\ \text{mask}_u \to \text{vals}[u]\}$，且

$$f^{(t)}[m] = \max_{\text{sub} \subseteq m}\Big(f^{(t-1)}[\text{sub}] + f_{v_t}[m \oplus \text{sub}]\Big)$$

**证明**：一个「用掉数位集合恰为 $m$」的方案，可按「是否使用孩子 $v_t$ 子树中的节点」拆成两部分：前 $t-1$ 个孩子与节点 $u$ 贡献的集合 $\text{sub}$，以及第 $t$ 个孩子贡献的集合 $m \oplus \text{sub}$。由引理 1，两部分都必须内部合法且互相不交，而 $\text{sub}$ 与 $m\oplus\text{sub}$ 互补于 $m$，天然不交。枚举所有 $\text{sub} \subseteq m$ 覆盖全部拆法，故转移完备；反向每个合法拆法都对应一个合法方案，故不重复计算非法解。∎

**引理 3（子集枚举代价）**：对 $m \in [0, 2^{10})$ 枚举全部子掩码的总次数为 $3^{10}$。

**证明**：每个二进制位在「属于 $m$ 且属于子掩码」「属于 $m$ 但不属于子掩码」「不属于 $m$」三种状态中恰选一种，各位独立，故总数为 $3^{10}$。∎

**定理**：算法输出等于 $\sum_u \text{maxScore}[u] \bmod (10^9+7)$。

**证明**：对树高归纳。叶子处 $f$ 恰为「空集」与「只选自己」两个状态，$\max f$ 即该叶子的最大好子集分数。设所有孩子已算对，由引理 2 合并后 $f_u[m]$ 恰为「子树 $u$ 内用掉数位集合 $m$ 的最大分数」（完备性 + 最优性由 max 保证），于是 $\max_m f_u[m] = \text{maxScore}[u]$；所有节点相加即得题目要求。取模在最后一步做，与题目要求一致。∎

## 6. 复杂度分析

- **时间**：$O(n\cdot 3^{10} + n\cdot 10)$。每个节点与每个孩子的合并做 $3^{10}\approx 5.9\times 10^4$ 次转移，边数 $n-1$，总计约 $3\times 10^7$ 次运算；建掩码、求 $\max$ 各 $O(1024n)$。
- **空间**：$O(n\cdot 2^{10})$。每个节点一个长度 1024 的 `long long` 数组，$500\times 1024\times 8 \approx 4$ MB；另有孩子表、掩码、顺序数组 $O(n)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int goodSubtreeSum(vector<int>& vals, vector<int>& par) {
        const int MOD = 1000000007;
        const int M = 1 << 10;              // 10 个数位 -> 10 位掩码
        int n = (int)vals.size();

        vector<vector<int>> ch(n);
        int root = 0;
        for (int i = 0; i < n; i++) {
            if (par[i] == -1) root = i;
            else ch[par[i]].push_back(i);
        }

        // 每个节点的数位掩码；数位有重复则记为 -1（该节点不能入选好子集）
        vector<int> mask(n, -1);
        for (int i = 0; i < n; i++) {
            int m = 0, x = vals[i];
            bool ok = true;
            while (x > 0) {
                int d = x % 10;
                if ((m >> d) & 1) { ok = false; break; }
                m |= 1 << d;
                x /= 10;
            }
            mask[i] = ok ? m : -1;
        }

        // 迭代式 DFS 求先序，逆序即为「孩子先于父亲」的处理顺序
        vector<int> order;
        order.reserve(n);
        vector<int> stk{root};
        while (!stk.empty()) {
            int u = stk.back();
            stk.pop_back();
            order.push_back(u);
            for (int v : ch[u]) stk.push_back(v);
        }

        vector<vector<long long>> f(n);
        long long total = 0;
        for (int idx = n - 1; idx >= 0; idx--) {
            int u = order[idx];
            vector<long long>& cur = f[u];
            cur.assign(M, -1);
            cur[0] = 0;                              // 空子集
            if (mask[u] >= 0) cur[mask[u]] = max(cur[mask[u]], (long long)vals[u]);
            for (int v : ch[u]) {
                vector<long long>& fv = f[v];
                vector<long long> g(M, -1);
                for (int m = 0; m < M; m++) {
                    long long best = -1;
                    for (int sub = m;; sub = (sub - 1) & m) {
                        long long a = cur[sub], b = fv[m ^ sub];
                        if (a >= 0 && b >= 0 && a + b > best) best = a + b;
                        if (sub == 0) break;
                    }
                    g[m] = best;
                }
                cur.swap(g);
            }
            long long bestHere = 0;
            for (int m = 0; m < M; m++) bestHere = max(bestHere, cur[m]);
            total = (total + bestHere) % MOD;
        }
        return (int)total;
    }
};
```

### Python

```python
class Solution:
    def goodSubtreeSum(self, vals: list[int], par: list[int]) -> int:
        MOD = 10 ** 9 + 7
        n = len(vals)

        ch = [[] for _ in range(n)]
        root = 0
        for i, p in enumerate(par):
            if p == -1:
                root = i
            else:
                ch[p].append(i)

        # 每个节点的数位掩码；数位有重复则记为 -1（不能入选好子集）
        mask = [-1] * n
        for i, v in enumerate(vals):
            m, ok, x = 0, True, v
            while x > 0:
                d = x % 10
                if (m >> d) & 1:
                    ok = False
                    break
                m |= 1 << d
                x //= 10
            mask[i] = m if ok else -1

        # 迭代式 DFS 求先序，逆序即为「孩子先于父亲」的处理顺序
        order, stk = [], [root]
        while stk:
            u = stk.pop()
            order.append(u)
            stk.extend(ch[u])

        dp = [None] * n                 # dp[u]: {数位掩码: 子树内该掩码下的最大分数}
        total = 0
        for u in reversed(order):
            cur = {0: 0}                # 空子集
            if mask[u] >= 0:
                cur[mask[u]] = max(cur.get(mask[u], 0), vals[u])
            for v in ch[u]:
                child = dp[v]
                nxt = dict(cur)         # 不选孩子 v 的任何节点
                for m1, s1 in cur.items():
                    for m2, s2 in child.items():
                        if m1 & m2 == 0:            # 两个数位集合不相交才能合并
                            m = m1 | m2
                            if s1 + s2 > nxt.get(m, -1):
                                nxt[m] = s1 + s2
                cur = nxt
                dp[v] = None
            dp[u] = cur
            total = (total + max(cur.values())) % MOD
        return total
```

## 8. 边界情况与易错点

1. **自身含重复数位的节点**（如 $22$、$100$）：不能入选，但仍要参与子树合并（作为父节点的后代，其子树的其他节点可以被选）。
2. **子集枚举的死循环**：`sub = (sub - 1) & m` 在 `sub == 0` 后会回到 `m`，必须显式 `break`。
3. **$\max$ 前先取模**：DP 值不能中途取模，否则大小关系被破坏（$5\times10^{11}$ 完全放得下 `long long`）。
4. **$f$ 的语义是「恰好」**：用 $-1$ 表示不可达，转移时两边都必须可达；若误用「至多」语义会重复计数。
5. **链状树**：必须用迭代（或提高递归上限），$n = 500$ 的链递归深度 500，Python 默认上限 1000 刚好够但很险。
6. **空树 / 单节点**：$n = 1$ 时答案就是 `vals[0]`（若其数位合法），否则为 $0$；代码中 `cur[0] = 0` 保证至少返回 0。
7. **根不一定是 0 号节点**：虽然题目保证 `par[0] == -1`，代码里仍从 `par` 里找 `-1` 更稳。
8. **$k$ 个孩子合并顺序**：与顺序无关（子集卷积满足交换律），但建议先用孩子数少的方向合并以减少中间态数量（本实现未做此优化，$n \le 500$ 无需）。
