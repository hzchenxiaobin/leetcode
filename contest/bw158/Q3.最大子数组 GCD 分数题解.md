# LeetCode 最大子数组 GCD 分数 题解

## 1. 题目概述

- **标题 / 题号**：最大子数组 GCD 分数（#3574，hard）
- **链接**：https://leetcode.cn/problems/maximize-subarray-gcd-score/
- **来源**：LeetCode 第 158 场双周赛 Q3
- **难度**：困难
- **标签**：数组、数学、枚举、数论

**题意**：给定正整数数组 `nums` 与整数 $k$。你**最多**可以做 $k$ 次操作，每次把数组中的**一个**元素翻倍，且每个元素**最多**只能翻倍一次。操作后，选一个**连续子数组**，其**分数** $=$ 子数组所有元素的 GCD $\times$ 子数组长度。求最大分数。

**约束**：

- $1 \le n \le 1500$
- $1 \le \text{nums}[i] \le 10^9$
- $1 \le k \le n$

> 💡 「最多 $k$ 次、每个元素最多一次」意味着：翻倍会让元素变大，但 GCD 由**所有**元素共同决定，所以盲目翻倍最大元素往往毫无意义。

## 2. 示例

**示例 1**

```text
输入：nums = [2,4], k = 1
输出：8
解释：把 nums[0] 翻倍成 4，数组变 [4,4]；子数组 [4,4] 的 GCD = 4、长度 2，分数 8。
```

**示例 2**

```text
输入：nums = [3,5,7], k = 2
输出：14
解释：把 7 翻倍成 14；子数组 [14] 的 GCD = 14、长度 1，分数 14。
```

**示例 3**

```text
输入：nums = [5,5,5], k = 1
输出：15
解释：翻倍任何一个 5 都会让 GCD 变成 5（其余两个仍是 5），分数不变；取整段 [5,5,5]：GCD 5 × 长度 3 = 15。
```

## 3. 解题思路

### 3.1 暴力思路

对每个子数组（$O(n^2)$ 个），尝试「翻倍其中的哪些元素」——每个元素翻或不翻，$O(2^{len})$ 种，总复杂度爆炸。即便限制为「最多翻 $k$ 个」，也是 $O(n^2 \cdot \binom{len}{k})$，彻底不可行。

### 3.2 核心观察：GCD 拆成「奇数部分 × $2$ 的幂」

![GCD = 奇数部分 × 2 的幂，翻倍只能抬起 2 的指数](images/bw158_q3_v2_model.svg)

把每个元素写成

$$\text{nums}[i] = \text{odd}_i \times 2^{v_2(i)}$$

其中 $\text{odd}_i$ 是奇数部分，$v_2(i)$ 是 $2$ 的指数（即 `ctz`）。翻倍只让 $v_2$ 加一，**奇数部分完全不变**。因此对任意子数组 $S$：

$$\gcd(S) = \gcd(\text{odd}_{i})\times 2^{\min_{i \in S} v_2(i)}$$

注意到 $\gcd(\text{odd}_i)$ 与翻倍无关（翻倍不改变任何奇数部分），所以**翻倍至多只能把整个 GCD 乘以 2**，绝不可能乘 4 或更多。

那么「乘 2」什么时候能做到？设子数组内 $v_2$ 的最小值为 $m$，达到该最小值的元素个数为 $c$。只有把这些元素**全部**翻倍，最小值才会抬到 $m+1$；少翻一个，最小值仍是 $m$，GCD 不变。所以：

$$\text{score}(S) = G \times \begin{cases} 2, & c \le k \\ 1, & c > k\end{cases} \times |S|$$

其中 $G = \gcd(S)$。**不需要考虑 $m+2$**：每个元素最多翻倍一次，翻倍后的 $v_2$ 最多是 $m+1$。

### 3.3 算法流程

![枚举左端点向右扩展，O(n²) 扫完所有子数组](images/bw158_q3_scan.svg)

```text
best = 0
for i = 0 .. n-1:                     # 枚举左端点
    G = 0；minV2 = +inf；cntMin = 0
    for j = i .. n-1:                 # 向右扩展右端点
        v2 = ctz(nums[j])
        G = gcd(G, nums[j])
        若 v2 < minV2:  minV2 = v2；cntMin = 1
        否则若 v2 == minV2:  cntMin += 1
        factor = (cntMin <= k ? 2 : 1)
        best = max(best, G * factor * (j - i + 1))
返回 best
```

**为什么可以增量维护**：子数组扩张时，$\gcd$ 只会变小或不变（$\gcd(G, x)$ 整除 $G$）；$v_2$ 的最小值同理，可以在 $O(1)$ 内更新「最小值 + 出现次数」。

### 3.4 示例演算

![三个示例分别验证翻倍成功、单元素最优、翻倍无用](images/bw158_q3_example_walk.svg)

| 输入 | 子数组 | $G$ | $\min v_2$ / $c$ | 能否翻倍 | 分数 |
|------|--------|-----|------------------|---------|------|
| $[2,4]$，$k=1$ | $[2,4]$ | 2 | $1$ / $1$ | 能（$1 \le 1$） | $2\times2\times2 = 8$ |
| $[3,5,7]$，$k=2$ | $[7]$ | 7 | $0$ / $1$ | 能（$1 \le 2$） | $7\times2\times1 = 14$ |
| $[5,5,5]$，$k=1$ | $[5,5,5]$ | 5 | $0$ / $3$ | 不能（$3 > 1$） | $5\times1\times3 = 15$ |

第一行：$2 = 1\times 2^1$，$4 = 1\times 2^2$，最小值出现在 $2$ 上，把它翻倍成 $4$ 后两个元素都是 $4$，GCD 从 $2$ 变 $4$。第三行：三个元素都带 $2^0$，抬 GCD 需要同时翻三处，$k=1$ 不够。

## 4. 算法细节

1. **求 $v_2$**：C++ 用 `__builtin_ctz(x)`，Python 用 `(x & -x).bit_length() - 1`。输入保证 $x \ge 1$，不会遇到 `ctz(0)` 的未定义行为。
2. **元素个数 $c$ 的维护**：当新的 $v_2$ 严格小于当前最小值时，**重置** `cntMin = 1`；等于时累加。这是「维护最小值及其频次」的标准写法。
3. **$G$ 的增量维护**：`G = gcd(G, nums[j])`，$G$ 随 $j$ 单调不增，且不同取值只有 $O(\log V)$ 种（本题不需要用这个性质，但可以据此优化到 $O(n\log V)$）。
4. **翻倍上限只到 $m+1$**：不要写「$c \le 2k$ 时乘 4」之类的推广——每个元素只能翻一次，$m+2$ 永远做不到（除非子数组里所有元素的 $v_2$ 都 $\ge m+1$，那就与 $m$ 是最小值矛盾）。
5. **单调性技巧（可选优化）**：对固定的 $i$，`G` 只在 $O(\log V)$ 个位置变化，可以把 $j$ 按 `G` 分组跳跃，把复杂度降到 $O(n\log V\log V)$；但 $n \le 1500$ 时 $O(n^2)$ 的 $1.1\times 10^6$ 次迭代已经非常快。
6. **数值范围**：$G$ 最大 $10^9$，翻倍后 $2\times10^9$，乘以长度 $1500$ 得 $3\times10^{12}$，必须用 `long long`。
7. **长度 1 的子数组**：$c = 1 \le k$（因为 $k \ge 1$），所以单元素分数为 $2\times$ 该元素——示例 2 就是这样取到 14 的。

## 5. 正确性证明

**引理 1（GCD 的 $2$ 部分可分离）**：对任意子数组 $S$，$\gcd_{i\in S}\text{nums}[i] = D \cdot 2^{m}$，其中 $D = \gcd_{i \in S}\text{odd}_i$ 为奇数，$m = \min_{i\in S} v_2(i)$。

**证明**：每个 $\text{nums}[i] = \text{odd}_i \cdot 2^{v_2(i)}$，奇数部分与 $2$ 的幂互质。GCD 的每个素因子指数取各元素的最小值：对素因子 $2$，最小值是 $\min_i v_2(i) = m$；对其他素因子 $p$，指数是 $\min_i v_p(\text{odd}_i)$，即 $D$ 的 $p$ 指数。故 GCD 等于 $D \cdot 2^m$。∎

**引理 2（翻倍的效果）**：设对集合 $T \subseteq S$ 中的元素各翻倍一次（$|T| \le k$）。则翻倍后子数组的 GCD 为 $D\cdot 2^{m'}$，其中 $m' = \min_{i \in S}\big(v_2(i) + [i \in T]\big)$；特别地 $m' \le m+1$，且 $m' = m+1$ 当且仅当「所有 $v_2(i) = m$ 的元素都在 $T$ 中」。

**证明**：翻倍不改变奇数部分，由引理 1 的同样论证，GCD 为 $D \cdot 2^{m'}$。对每个 $i$，$v_2(i) + [i\in T] \le v_2(i) + 1$，故 $m' \le m+1$。若存在某个 $v_2(i) = m$ 的元素不在 $T$ 中，则该元素贡献 $m$，于是 $m' \le m$；反之若所有最小值元素都翻倍，则它们的 $v_2$ 都变成 $m+1$，其余元素原本 $\ge m+1$，故 $m' = m+1$。∎

**引理 3（最优分数的闭合式）**：对子数组 $S$，在最多 $k$ 次翻倍下可达到的最大 GCD 为 $G\cdot 2^{[c \le k]}$（其中 $c$ 为 $v_2$ 等于 $m$ 的元素个数），因此最大分数为 $G\cdot(2^{[c\le k]})\cdot |S|$。

**证明**：由引理 2，可实现的最大 $m'$ 为 $m+1$（当且仅当 $c \le |T| \le k$）或 $m$。而 $D$ 恒不变，故最大 GCD 如式。分数 $=$ GCD $\times$ 长度，长度固定，故最大分数取最大 GCD 时取得。∎

**定理**：算法输出为所有可能（操作后）子数组分数的最大值。

**证明**：算法枚举了全部 $O(n^2)$ 个子数组（引理：两重循环的 $(i,j)$ 与子数组一一对应），对每个子数组由引理 3 直接算出它在最优翻倍下的分数，并取全局最大。因此输出等于所求最大值。∎

## 6. 复杂度分析

- **时间**：$O(n^2\log V)$。外层 $i$ 共 $n$ 轮，内层 $j$ 平均 $n/2$，每步一次 `gcd`，单次 $O(\log V)$（$V \le 10^9$）。$n = 1500$ 时约 $1.1\times 10^6$ 次 gcd 调用 ≈ 数千万次基本运算。若利用「$G$ 只有 $O(\log V)$ 种取值」跳跃枚举，可优化到 $O(n\log^2 V)$。
- **空间**：$O(1)$。只用了若干标量（$G$、`minV2`、`cntMin`、`best`），没有额外数组。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long maxGCDScore(vector<int>& nums, int k) {
        int n = (int)nums.size();
        long long best = 0;
        for (int i = 0; i < n; i++) {
            long long g = 0;               // 当前子数组的 GCD
            int minV2 = INT_MAX, cntMin = 0;  // 子数组内 2 的指数最小值及其出现次数
            for (int j = i; j < n; j++) {
                int v2 = __builtin_ctz((unsigned)nums[j]);
                g = std::gcd(g, (long long)nums[j]);
                if (v2 < minV2) {
                    minV2 = v2;
                    cntMin = 1;
                } else if (v2 == minV2) {
                    cntMin++;
                }
                // 把「2 的指数最小」的那些元素全部翻倍，GCD 恰好翻一倍
                long long factor = (cntMin <= k) ? 2 : 1;
                long long score = g * factor * (long long)(j - i + 1);
                if (score > best) best = score;
            }
        }
        return best;
    }
};
```

### Python

```python
from math import gcd


class Solution:
    def maxGCDScore(self, nums: list[int], k: int) -> int:
        n = len(nums)
        best = 0
        for i in range(n):
            g = 0                                  # 当前子数组的 GCD
            min_v2 = None                          # 子数组内 2 的指数最小值
            cnt_min = 0                            # 达到该最小值的元素个数
            for j in range(i, n):
                v = nums[j]
                v2 = (v & -v).bit_length() - 1     # 等价于 v2(v)
                g = gcd(g, v)
                if min_v2 is None or v2 < min_v2:
                    min_v2 = v2
                    cnt_min = 1
                elif v2 == min_v2:
                    cnt_min += 1
                # 把「2 的指数最小」的那些元素全部翻倍，GCD 恰好翻一倍
                factor = 2 if cnt_min <= k else 1
                best = max(best, g * factor * (j - i + 1))
        return best
```

## 8. 边界情况与易错点

1. **以为能翻出 $4G$**：每个元素只能翻倍一次，$2$ 的指数最多抬 $1$，GCD 最多变 $2G$（引理 2）。
2. **只翻「部分」最小值元素**：必须把 $c$ 个最小值元素**全部**翻倍，少一个都不行；所以判定条件是对「个数 $c$」，不是对「元素」。
3. **$c$ 与 $k$ 的比较**：$c \le k$ 才乘 2；$k \ge 1$ 保证长度 1 的子数组总能翻倍（示例 2）。
4. **$\gcd$ 的初值**：内层用 $g = 0$ 起步（$\gcd(0,x)=x$），不要写 $g = 1$ 或 $g = \text{nums}[i]$（后者在切换左端点时容易忘重置）。
5. **$v_2$ 的求法**：C++ `__builtin_ctz` 对 $0$ 未定义，本题 $\text{nums}[i] \ge 1$ 安全；Python 用 `(x & -x).bit_length() - 1`。
6. **`int` 溢出**：$2\times 10^9 \times 1500 = 3\times10^{12}$，必须 `long long`；Python 无此问题。
7. **最小值频次的重置**：新的 $v_2$ 更小时必须把 `cntMin` **重置为 1**，而不是加一。
8. **空子数组**：题目要求非空，两重循环保证长度 $\ge 1$。
