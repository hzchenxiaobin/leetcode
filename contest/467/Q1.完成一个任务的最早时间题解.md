# LeetCode 完成一个任务的最早时间 题解

## 1. 题目概述

- **标题 / 题号**：完成一个任务的最早时间（#3683，easy）
- **链接**：https://leetcode.cn/problems/earliest-time-to-finish-one-task/
- **来源**：LeetCode 第 467 场周赛 Q1
- **难度**：简单
- **标签**：数组、枚举

**题意**：给定二维整数数组 `tasks`，其中 `tasks[i] = [si, ti]` 表示第 `i` 个任务从时刻 `si` 开始、需要 `ti` 个时间单位才能完成。返回**至少完成一个任务**的最早时刻。

**约束**：

- `1 <= tasks.length <= 100`
- `tasks[i].length == 2`
- `1 <= si, ti <= 100`

## 2. 示例

**示例 1**

```text
输入：tasks = [[1,6],[2,3]]
输出：5
解释：任务 1 在 1 + 6 = 7 完成，任务 2 在 2 + 3 = 5 完成，最早为 5。
```

**示例 2**

```text
输入：tasks = [[100,100],[100,100],[100,100]]
输出：200
解释：三个任务都在 100 + 100 = 200 完成。
```

**示例 3（单任务）**

```text
输入：tasks = [[5,1]]
输出：6
解释：只有一个任务，答案即 5 + 1 = 6。
```

## 3. 解题思路

### 3.1 暴力思路

签到题。数据范围极小（`n <= 100`），逐个算出每个任务的完成时刻再取最小即可，不存在更朴素也更不需要更高级的做法（无需排序、无需堆）。

### 3.2 核心观察：任务相互独立，完成时刻取最小

![核心观察：完成时刻 = s + t，取最小](images/earliest_finish_concept.svg)

任务之间**相互独立**：第 `i` 个任务从 `si` 开始、持续 `ti`，完成时刻就是 $s_i + t_i$，与其他任务无关。而"至少完成一个任务的最早时间"就是所有任务完成时刻的**最小值**：

$$\text{ans} = \min_{0 \le i < n} \, (s_i + t_i)$$

一次线性扫描即可。

### 3.3 算法流程

1. 初始化 `ans = +∞`；
2. 遍历每个 `tasks[i] = [si, ti]`，计算完成时刻 $f_i = s_i + t_i$；
3. 更新 `ans = min(ans, fi)`；
4. 遍历结束，返回 `ans`。

### 3.4 示例演算

`tasks = [[1,6],[2,3]]`：

| 任务 | 开始 $s_i$ | 时长 $t_i$ | 完成时刻 $s_i + t_i$ |
|------|-----------|-----------|---------------------|
| 任务 1 | 1 | 6 | 7 |
| 任务 2 | 2 | 3 | **5** ← 最小 |

`ans = min(7, 5) = 5` ✓

![示例演算：逐任务计算完成时刻并取最小](images/earliest_finish_example.svg)

## 4. 算法细节

1. **独立计算**：每个任务的完成时刻只取决于自身的 `si` 与 `ti`，题目不涉及任务间调度、抢占或资源冲突，直接算即可。
2. **取最小**：维护变量 `ans`（初始为 `INT_MAX`），遍历中不断取 `min`；Python 可用生成器一行 `min(s + t for s, t in tasks)`。
3. **数值范围**：$s_i + t_i \le 200$，`int` 完全够用，无溢出风险。

## 5. 正确性证明

**引理 1**：第 `i` 个任务的完成时刻为 $f_i = s_i + t_i$。

**证明**：任务从时刻 $s_i$ 开始，连续执行 $t_i$ 个时间单位，故在时刻 $s_i + t_i$ 完成。∎

**定理**：至少完成一个任务的最早时刻为 $\min_i (s_i + t_i)$。

**证明**："时刻 `T` 时至少有一个任务完成" 等价于 "$\exists i,\ f_i \le T$"。若 $T < \min_i f_i$，则所有 $f_i > T$，该条件不成立；取 $T = \min_i f_i$ 时，取到最小值的任务恰好完成，条件成立。故使条件成立的最早时刻即 $\min_i (s_i + t_i)$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。单次遍历，每个任务 `O(1)` 计算 `si + ti` 并更新最小值。
- **空间复杂度**：$O(1)$。仅使用常数个额外变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int earliestTime(vector<vector<int>>& tasks) {
        int ans = INT_MAX;
        for (auto& t : tasks) {
            ans = min(ans, t[0] + t[1]);
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def earliestTime(self, tasks: List[List[int]]) -> int:
        return min(s + t for s, t in tasks)
```

## 8. 边界情况与易错点

1. **单任务**：`n = 1` 时答案就是 `s0 + t0`。
2. **完成时刻全部相同**：如示例 2，多个任务同时完成，`min` 不受影响。
3. **别想复杂了**：看到"任务""时间"容易往排序、贪心、调度方向想；本题任务互不干扰，签到题果断直接算。
4. **min 初值**：手写循环取 `min` 时初值用 `INT_MAX`（或直接用第一个元素），不要用 `0`。
