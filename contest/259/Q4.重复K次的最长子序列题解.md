# LeetCode 重复 K 次的最长子序列 题解

## 1. 题目概述

- **标题 / 题号**：重复 K 次的最长子序列（#2014，hard）
- **链接**：https://leetcode.cn/problems/longest-subsequence-repeated-k-times/
- **来源**：LeetCode 第 259 场周赛 Q4
- **难度**：困难
- **标签**：广度优先搜索、贪心、双指针、字符串、计数、枚举

**题意**：给定长度为 $n$ 的字符串 $s$ 和整数 $k$。若把字符串 $\text{seq}$ 串联 $k$ 次（记作 $\text{seq} * k$）后是 $s$ 的**子序列**，则称 $\text{seq}$ 是 $s$ 中一个**重复 $k$ 次的子序列**。求所有重复 $k$ 次的子序列中**最长**的那个；若存在并列，返回其中**字典序最大**的；若不存在，返回空串。

**约束**：

- $2 \le k \le 2000$
- $2 \le n < \min(2001,\ k \cdot 8)$
- $s$ 由小写英文字母组成

> 💡 本题的钥匙藏在约束 $n < \min(2001,\ 8k)$ 里：它同时锁死了**答案长度 $\le 7$**、**候选字母表 $\le 7$ 个字符**、**合法序列总数 $\le 13700$**。一个看似指数级的枚举问题，实际被数据范围关进了一个极小的"盒子"——从空串出发**按层 BFS** 暴力枚举即可通过。

## 2. 示例

**示例 1**

```text
输入：s = "letsleetcode", k = 2
输出："let"

解释：存在两个长度为 3 的重复 2 次的子序列："let" 和 "ete"。
      "let" 是其中字典序最大的一个。
```

**示例 2**

```text
输入：s = "bb", k = 2
输出："b"

解释："bb" 是 "b" 串联 2 次得到的，是 s 的子序列。
```

**示例 3**

```text
输入：s = "ab", k = 2
输出：""

解释：没有任何字符出现至少 2 次，不存在重复 2 次的子序列，返回空字符串。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的想法是枚举 $s$ 的所有子序列——$2^n$ 个，$n$ 可达 2000，直接爆炸。

退一步：利用"每个出现在答案里的字符频次必须 $\ge k$"（见 3.2），只需在**候选字母表**（$\le 7$ 个字符）上枚举所有长度 $\le 7$ 的字符串，共 $\sum_{i=0}^{7} 7^i \approx 9.6 \times 10^5$ 个，再逐个用 $O(n)$ 判定 $\text{seq} * k \subseteq s$，总计约 $2 \times 10^9$ 次字符比较。这在 C++ 里已经很勉强，Python 必然超时。

浪费的根源在于：**非法前缀被反复枚举**。例如 `"el"` 不合法，那么 `"elt"`、`"ele"`、`"ell"`…… 全部不必再试，但无剪枝的枚举会一次次从零判定它们。

### 3.2 核心观察：数据范围把问题关进"小盒子"

![容量过滤与三个上界](images/wc259_q4_capacity_concept.svg)

**观察 1（容量）**：若 $\text{seq} * k \subseteq s$，则 $\text{seq}$ 中字符 $c$ 每出现一次，$\text{seq} * k$ 中就出现 $k$ 次，而 $s$ 中 $c$ 至多有 $\text{freq}[c]$ 个，因此

$$\text{seq 中字符 } c \text{ 的出现次数} \le \left\lfloor \frac{\text{freq}[c]}{k} \right\rfloor$$

即每个候选字符自带一个**容量**；频次 $< k$ 的字符根本不可能出现在答案中。

**观察 2（长度与字母表上界）**：由 $\lvert\text{seq}\rvert \cdot k = \lvert \text{seq} * k \rvert \le n < 8k$ 得 $\lvert\text{seq}\rvert \le 7$；由每个候选字符频次 $\ge k$ 得候选字符数 $\le \lfloor n/k \rfloor \le 7$。

**观察 3（前缀封闭性）**：若 $\text{seq}$ 合法，则去掉 $\text{seq}$ **最后一个字符**得到的前缀也合法（证明见 §5）。因此所有合法序列恰好构成一棵**以空串为根的树**——每个合法序列都由某个合法前缀追加一个字符得到。

> 💡 三个观察合起来：树的深度 $\le 7$、每层分叉 $\le 7$、且**树上的节点（合法序列）总数 $\le 13700$**（证明见 §5 推论）。BFS 这棵树，每扩展一个孩子做一次 $O(n)$ 贪心判定，总代价立刻可控。

### 3.3 算法流程：按层 BFS + 贪心判定

![BFS 按层枚举流程](images/wc259_q4_bfs_flow.svg)

1. 统计频次，过滤出候选字符（$\text{freq}[c] \ge k$），**降序**排列。
2. 令第 0 层为 $\{ \, "" \, \}$。
3. 对当前层每个序列 $\text{seq}$ 与每个候选字符 $c$，用**贪心双指针**判定 $(\text{seq} + c) * k$ 是否为 $s$ 的子序列；合法者进入下一层。
4. 若某层扩展不出任何新序列，停止；**最后一个非空层**就是全体最长合法序列。
5. 同层序列等长，取 `max`（字典序最大）即为答案；初始层 $\{""\}$ 保证空答案时返回空串。

### 3.4 示例演算：s = "letsleetcode", k = 2

![示例演算：贪心判定与逐层结果](images/wc259_q4_greedy_walkthrough.svg)

频次：$l{:}2,\ e{:}4,\ t{:}2,\ s{:}1,\ c{:}1,\ o{:}1,\ d{:}1$，门槛 $k=2$，故候选字符为 $\{e, l, t\}$，容量分别为 $e{:}2,\ l{:}1,\ t{:}1$。

```text
第 0 层：""
第 1 层：t, l, e                       （3 个）
第 2 层：te, lt, le, et, ee            （5 个；el、tl、ll 等被判定否决）
第 3 层：let, ete                       （2 个；lee、eel、tet 等被判定否决）
第 4 层：∅                              （全部扩展失败）
```

最后一个非空层为 $\{\text{let},\ \text{ete}\}$，取字典序最大者 $\text{let}$，与官方答案一致。

## 4. 算法细节

1. **频次过滤**：用哈希表统计 $\text{freq}[c]$，仅保留 $\text{freq}[c] \ge k$ 的字符作为候选。这一步把 26 个字母压缩到 $\le 7$ 个。

2. **贪心判定 $\text{ok}(\text{seq})$**：判定 $\text{seq} * k \subseteq s$ 用双指针——指针 $j$ 扫过 $\text{seq} * k$ 的第 $j$ 个字符（即 $\text{seq}[j \bmod \lvert\text{seq}\rvert]$，**无需显式构造重复串**），指针扫 $s$，字符相等则 $j$ 前进。$j$ 单调前进，单次判定 $O(n)$。Python 中可用 `s.find(c, pos)` 把内层扫描交给 C 实现。

3. **逐层扩展**：`nxt` 收集本层所有合法扩展；`nxt` 为空即停，此时 `cur` 恰为**全体最长合法序列**。

4. **字典序最大**：同层序列等长，`max(cur)` 即字典序最大者。候选字符降序排列只是让生成顺序直观，正确性由 `max` 兜底。

5. **剪枝的本质**：非法前缀的孩子根本不会入队，等价于把整棵子树剪掉——这就是 BFS 树枚举远优于无剪枝全枚举的原因（合法节点 $\le 13700$ vs 全枚举 $9.6 \times 10^5$，且前者每次判定还被"父序列已验证"的信息摊薄）。

## 5. 正确性证明

**引理 1（贪心匹配）**：双指针从左到右扫描 $s$，每遇到与模式第 $j$ 个字符相同的位置就让 $j$ 前进，则最终 $j$ 走完整个模式，当且仅当模式是 $s$ 的子序列。

**证明**：若贪心走完整个模式，匹配到的位置序列就是一个合法嵌入，充分性显然。必要性：设存在某个嵌入 $p_0 < p_1 < \cdots$，对 $j$ 归纳证明贪心位置 $g_j \le p_j$：$g_0$ 是 $s$ 中第一个等于模式首字符的位置，故 $g_0 \le p_0$；若 $g_j \le p_j$，则 $p_{j+1}$ 是 $g_j$ 之后与模式第 $j+1$ 个字符相等的位置，而 $g_{j+1}$ 取的是**最早**的这样的位置，故 $g_{j+1} \le p_{j+1}$。因此贪心永不落后于任何嵌入，嵌入存在则贪心必能走完。∎

**引理 2（容量引理）**：若 $\text{seq} * k \subseteq s$，则 $\text{seq}$ 中每个字符 $c$ 的出现次数 $u_c \le \lfloor \text{freq}[c] / k \rfloor$。

**证明**：$\text{seq} * k$ 中 $c$ 出现 $k \cdot u_c$ 次；它是 $s$ 的子序列，故 $k \cdot u_c \le \text{freq}[c]$。∎

**推论**：答案长度 $\le 7$；候选字母表 $\le 7$；合法序列总数 $\le \sum_{i=0}^{7} P(7, i) = 13700$。

**证明**：长度：$\lvert\text{seq}\rvert \cdot k \le n < 8k$。字母表：每个候选字符频次 $\ge k$，故个数 $\le \lfloor n/k \rfloor \le 7$。计数：给合法 $\text{seq}$ 中同一字符的各次出现按出现顺序打上互异标签（第 1 个 $a$、第 2 个 $a$……），由引理 2 标签总数 $= \lvert\text{seq}\rvert \le 7$；打标签后的串是互异符号、长度 $\le 7$ 的排列，总数不超过 $\sum_{i=0}^{7} P(7,i) = 1 + 7 + 42 + 210 + 840 + 2520 + 5040 + 5040 = 13700$；不同 $\text{seq}$ 对应的标签排列互不相交，且每个 $\text{seq}$ 至少对应一个标签排列，故合法序列数 $\le 13700$。∎

**引理 3（前缀封闭）**：若 $\text{seq}$ 合法，则删去 $\text{seq}$ 末字符得到的前缀 $\text{seq}'$ 也合法。

**证明**：$\text{seq}' * k$ 可由 $\text{seq} * k$ 在每个副本中删去末字符得到，故 $\text{seq}' * k \subseteq \text{seq} * k$；又 $\text{seq} * k \subseteq s$，子序列关系具有传递性，得 $\text{seq}' * k \subseteq s$。∎

**定理**：上述 BFS 返回 $s$ 中重复 $k$ 次的最长子序列中字典序最大者。

**证明**：由引理 3，任何长度 $L+1$ 的合法序列删去末字符后是长度 $L$ 的合法序列，因此必被 BFS 第 $L$ 层的某个节点扩展出来——**不漏**；每个合法序列由唯一前缀逐步扩展得到——**不重**。故 BFS 的最深非空层恰为全体最长合法序列，它们等长，取 `max` 即字典序最大者，正是题目所求。∎

## 6. 复杂度分析

- **时间复杂度**：$O(V \cdot \Sigma \cdot n)$，其中 $V$ 为合法序列总数（$\le 13700$，推论），$\Sigma \le 7$ 为候选字符数，$n \le 2000$。
  - 最坏上界约 $13700 \times 7 \times 2000 \approx 1.9 \times 10^8$（C++ 可稳定通过）。
  - 实际远小于上界：合法序列还须满足**顺序约束**（引理 1 的贪心判定大量否决），实测每层节点通常只有几十到几百个，毫秒级完成。
  - Python 版用 `s.find` 把每次判定的内层扫描交给 C 实现，常数极小。
- **空间复杂度**：$O(V \cdot L)$ 存各层序列，$L \le 7$，即至多约 $10^5$ 个字符。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    string longestSubsequenceRepeatedK(string s, int k) {
        int n = s.size();
        int cnt[26] = {0};
        for (char c : s) cnt[c - 'a']++;

        // 候选字符：频次 >= k，按降序排列
        string cand;
        for (int c = 25; c >= 0; --c)
            if (cnt[c] >= k) cand.push_back('a' + c);

        // 贪心判定：seq 重复 k 次是否为 s 的子序列
        auto ok = [&](const string& seq) {
            int m = seq.size(), need = m * k;   // need <= 7 * 2000，int 足够
            int j = 0;
            for (int i = 0; i < n && j < need; ++i)
                if (s[i] == seq[j % m]) ++j;
            return j == need;
        };

        vector<string> cur{""};
        while (true) {
            vector<string> nxt;
            for (const string& seq : cur)
                for (char c : cand) {
                    string t = seq + c;
                    if (ok(t)) nxt.push_back(move(t));
                }
            if (nxt.empty()) break;             // 无法再变长：cur 即最长层
            cur = move(nxt);
        }
        return *max_element(cur.begin(), cur.end());
    }
};
```

### Python

```python
from collections import Counter


class Solution:
    def longestSubsequenceRepeatedK(self, s: str, k: int) -> str:
        freq = Counter(s)
        # 候选字符：频次 >= k，降序排列
        cand = sorted((c for c, v in freq.items() if v >= k), reverse=True)

        def ok(seq: str) -> bool:
            # 贪心匹配 seq * k：pos 单调前进，总扫描 O(n)
            pos = 0
            for _ in range(k):
                for c in seq:
                    pos = s.find(c, pos)
                    if pos < 0:
                        return False
                    pos += 1
            return True

        cur = [""]                # 第 0 层：空串
        while True:
            nxt = []
            for seq in cur:
                for c in cand:
                    t = seq + c
                    if ok(t):
                        nxt.append(t)
            if not nxt:           # 无法再变长：cur 即最长层
                break
            cur = nxt
        return max(cur)           # 同层等长，max 即字典序最大
```

## 8. 边界情况与易错点

1. **答案为空串**：没有任何字符频次 $\ge k$（如示例 3 `"ab"`, $k=2$）时，BFS 第一层就扩展为空，`max([""])` 返回 `""`。初始层放 `""` 而不是空列表，正是为了统一处理这一边界。
2. **必须保留整层，不能只维护"当前最优"单个序列**：字典序大的前缀未必能继续扩展。例如示例演算中第 2 层字典序最大者是 `"te"`，但它扩展不出任何长度 3 的合法序列；反而是 `"le"` 能扩展出答案 `"let"`。**局部最优 ≠ 可扩展**。
3. **判定不要显式构造 $\text{seq} * k$ 字符串**：用 $j \bmod \lvert\text{seq}\rvert$ 索引或 `s.find` 跳位即可，避免每次 $O(\lvert\text{seq}\rvert \cdot k)$ 的构造开销（虽然上界也只有 $14000$，但何必多此一举）。
4. **C++ 溢出检查**：$\text{need} = \lvert\text{seq}\rvert \cdot k \le 7 \times 2000 = 14000$，`int` 足够；一般地 $\lvert\text{seq}\rvert \cdot k \le n < 8k$ 由数据范围保证。
5. **候选字符降序排列不是正确性依赖**：它只影响生成顺序；若误以为"每层取第一个生成的就是字典序最大"，在"降序 + 逐层取首个"的组合下恰好也对，但一旦改成升序就错了。正确做法是同层取 `max`。
6. **别忘了一切的前提是 $n < 8k$**：答案长度 $\le 7$、候选字母表 $\le 7$、合法序列 $\le 13700$ 全部由此而来。若数据范围放开（见延伸思考），本题的 BFS 套路立即失效。
