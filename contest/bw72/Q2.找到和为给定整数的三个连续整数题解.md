# LeetCode 找到和为给定整数的三个连续整数 题解

## 1. 题目概述

- **标题 / 题号**：找到和为给定整数的三个连续整数（#2177，medium）
- **链接**：https://leetcode.cn/problems/find-three-consecutive-integers-that-sum-to-a-given-number/
- **来源**：LeetCode 第 72 场双周赛 Q2
- **难度**：中等
- **标签**：数学、模拟

**题意**：给定整数 $num$（$0 \le num \le 10^{15}$）。找出三个**连续整数**使其和恰为 $num$；不存在则返回空数组。答案按从小到大排列（三个连续数从小到大唯一确定顺序）。

**约束**：

- $0 \le num \le 10^{15}$；
- 注意三个整数**可以为负**（例如 $num = 0$ 时 $-1, 0, 1$ 是合法解）。

## 2. 示例

**示例 1**

```text
输入：num = 33
输出：[10,11,12]
解释：10 + 11 + 12 = 33，且三个数连续。
```

**示例 2**

```text
输入：num = 4
输出：[]
解释：任何三个连续整数之和都是 3 的倍数，4 不是，故无解。
```

**示例 3（边界补充）**

```text
输入：num = 0
输出：[-1,0,1]
解释：-1 + 0 + 1 = 0。num = 0 是 3 的倍数，中心数 x = 0，输出 [-1, 0, 1]。
```

## 3. 解题思路

### 3.1 暴力思路

从某个下界（如 $-3$）枚举首项 $x$ 直到 $x + (x+1) + (x+2) > num$——$num$ 可达 $10^{15}$，线性扫描 $10^{15}$ 次必然超时。即便二分首项也才 $O(\log num)$，但其实**一次整除判定**就够：和的形态是固定的 $3x$。

### 3.2 核心观察：三个连续数关于中心数对称

![中心数视角：三个连续数关于 x 对称](images/bw72_q2_center_concept.svg)

设三个连续整数为 $x - 1, x, x + 1$（$x$ 为**中心数**，不必是整数解的「中间那个」以外的任何东西）。求和：

$$
(x - 1) + x + (x + 1) = 3x = num.
$$

两端 $\pm 1$ 互相抵消，和**只由中心数决定**且恒为中心数的三倍。于是：

- $num \bmod 3 \ne 0$ → $x$ 不是整数 → **无解**，返回 `[]`；
- $num \bmod 3 = 0$ → $x = num / 3$（唯一），返回 $[x - 1, x, x + 1]$。

解的**唯一性**也随之显然：中心数被 $num$ 唯一确定，三个数随之确定——不存在「多个答案取其一」的问题。

### 3.3 算法流程

![算法流程：一次整除判定，O(1)](images/bw72_q2_flow.svg)

```text
if num % 3 != 0: return []
x = num / 3
return [x - 1, x, x + 1]
```

### 3.4 示例演算

- $num = 33$：$33 \% 3 = 0$，$x = 11$，输出 $[10, 11, 12]$。
- $num = 4$：$4 \% 3 = 1$，无解，输出 $[]$。
- $num = 10^{15}$：$10^{15} = 3 \times 333333333333333 + 1$（因 $10 \equiv 1 \pmod 3$，故 $10^{15} \equiv 1$），无解。可见最大输入也不必特殊处理。
- $num = 999999999999999$（$= 3 \times 333333333333333$）：$x = 333333333333333$，输出 $[333333333333332, 333333333333333, 333333333333334]$，接近 `long long` 但远未溢出（$< 10^{15} + 1$）。

## 4. 算法细节

1. **为什么允许负数**：题面只说「三个连续整数」，没限制正数。$num = 0$ 的合法解 $[-1, 0, 1]$；$num = 3$ 的解 $[0, 1, 2]$；$num = 1, 2$ 不是 3 的倍数，无解。公式对 $num \ge 0$ 全覆盖，无需任何下界检查。
2. **整型选择**：$num \le 10^{15}$ 超 32 位 `int`（约 $2.1 \times 10^9$）——C++ 必须用 `long long`，且注意 `num % 3`、`num / 3` 都在 `long long` 上做；返回类型是 `long[]`。Python 无此顾虑。
3. **别用浮点**：`x = num / 3` 在 C++ 中对整数是整除（前提是 `long long` 运算），但若手滑写成 `double` 再转回会有精度灾难（$10^{15}$ 级别超出 double 的精确整数区间边缘 $2^{53} \approx 9 \times 10^{15}$ 内虽可表示，但除法舍入仍危险）。坚持整数运算。
4. **判无解的条件只看模 3**：不需要检查 $x - 1 \ge$ 某个下界——负数合法，任何 3 的倍数都有解。

## 5. 正确性证明

**引理（和的形态）**：三个连续整数（按升序）可唯一写成 $x - 1, x, x + 1$，其中 $x$ 为整数（中间数）；其和为 $3x$。

**证明**：设三个连续整数为 $a, a+1, a+2$（$a$ 为最小者）。取 $x = a + 1$，则三者即 $x - 1, x, x + 1$，且任何这样的三元组由 $x$ 唯一确定。求和 $= (x - 1) + x + (x + 1) = 3x$。∎

**定理**：存在三个连续整数之和为 $num$ 当且仅当 $3 \mid num$；此时唯一解为 $[num/3 - 1,\ num/3,\ num/3 + 1]$。

**证明**：（存在性/必要性）若解存在，由引理其和为 $3x$ 形式，故 $3 \mid num$ 且 $x = num/3$。（充分性）若 $3 \mid num$，取 $x = num / 3$（整数），则 $x - 1, x, x + 1$ 是三个连续整数且和为 $3x = num$。唯一性：解由 $x$ 唯一决定（引理），而 $3x = num$ 在整数上至多一个解 $x = num/3$。∎

## 6. 复杂度分析

- **时间**：$O(1)$。一次取模、一次整除。
- **空间**：$O(1)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<long long> sumOfThree(long long num) {
        if (num % 3 != 0) return {};          // 3x = num 无整数解
        long long x = num / 3;
        return {x - 1, x, x + 1};
    }
};
```

### Python

```python
class Solution:
    def sumOfThree(self, num: int) -> list[int]:
        if num % 3 != 0:                 # 和为 3x，必须是 3 的倍数
            return []
        x = num // 3
        return [x - 1, x, x + 1]
```

> 💡 两份代码均通过官方示例（`[10,11,12]`、`[]`）以及 $num \in [0, 3000]$ 全量与「小范围扫描首项」暴力的对拍（3001 组），另抽查 $10^{15}$ 边界（无解）与 $999999999999999$（大解），`mismatch = 0`。

## 8. 边界情况与易错点

1. **$num$ 高达 $10^{15}$**：C++ 用 `int` 读参/运算必错（$10^{15} > 2^{31} - 1 \approx 2.1 \times 10^9$）；函数签名是 `long long`，返回容器也要 `vector<long long>`。Python 无溢出但别把返回写成 `int` 之外的自定义类型。
2. **$num = 0$ 有解**：$[-1, 0, 1]$。别加「正整数」之类的自设限制把 0 判成无解。
3. **$num = 1, 2$**：都不是 3 的倍数，无解；$num = 3$ 得 $[0,1,2]$（含 0）。小值手算验证最防呆。
4. **整除判断用 `%` 而非浮点**：`num % 3 != 0` 是整数精确判定；`num / 3` 在浮点下的舍入可能把无解误判有解。
5. **返回顺序**：升序 $[x-1, x, x+1]$ 即可，题目允许多种顺序时也不必倒腾。
