# LeetCode 统计数组中相等且可以被整除的数对 题解

## 1. 题目概述

- **标题 / 题号**：统计数组中相等且可以被整除的数对（#2176，easy）
- **链接**：https://leetcode.cn/problems/count-equal-and-divisible-pairs-in-an-array/
- **来源**：LeetCode 第 72 场双周赛 Q1
- **难度**：简单
- **标签**：数组、枚举

**题意**：给定长度为 $n$ 的整数数组 $nums$ 与整数 $k$，统计满足以下全部条件的下标对 $(i, j)$ 的个数：

1. $0 \le i < j < n$；
2. $nums[i] = nums[j]$；
3. $(i \times j) \bmod k = 0$。

**约束**：

- $1 \le n \le 100$；
- $1 \le nums[i], k \le 100$。

## 2. 示例

**示例 1**

```text
输入：nums = [3,1,2,2,2,1,3], k = 2
输出：4
解释：(0,6) 值 3，0×6=0 整除；(2,3)、(2,4)、(3,4) 值 2，乘积 6/8/12 均为偶数。
```

**示例 2**

```text
输入：nums = [1,2,3,4], k = 1
输出：0
解释：无重复值，数对条件 nums[i]==nums[j] 先不成立。
```

**示例 3（边界补充）**

```text
输入：nums = [5,5,5], k = 100
输出：2
解释：三对候选中，(0,1) 与 (0,2) 的下标乘积都是 0，能被 100 整除，均计入；
      只有 (1,2) 的乘积 2 不被 100 整除而被排除。
```

> ⚠️ 示例 3 印证了本题最常见的坑：$i = 0$ 时 $i \times j = 0$，**0 能被任何正整数整除**，含下标 0 的同值对全部直接通过整除测试。

## 3. 解题思路

### 3.1 暴力思路（即正解）

$n \le 100$，全部下标对只有 $\binom{100}{2} = 4950$ 个，双重循环逐对判定两个条件即可，$O(n^2)$ 约 5000 次操作，毫无压力。这题的价值在于**条件顺序与边界细节**，而不是算法优化。

### 3.2 核心观察：两个条件的判定顺序

![双重循环判定：i 与 j 逐对检查](images/bw72_q1_pair_scan.svg)

条件拆成独立的两项：

- **值相等**：$nums[i] == nums[j]$，数组比较，$O(1)$；
- **乘积整除**：$(i \times j) \% k == 0$。乘积最大 $99 \times 98 < 10^4$，`int` 无溢出风险。

先判哪个都行（短路求值下先判便宜的更好，但此处都是常数操作）。值得强调的是 $i = 0$ 的特例：乘积恒为 0，整除条件**自动成立**。

### 3.3 算法流程

```text
ans = 0
for i in [0, n-2]:
    for j in [i+1, n-1]:
        if nums[i] == nums[j] and (i*j) % k == 0:
            ans += 1
return ans
```

### 3.4 示例演算

![命中对速查：示例 1 的 4 对命中与排除对](images/bw72_q1_example_walkthrough.svg)

以示例 1（$nums = [3,1,2,2,2,1,3]$，$k = 2$）全部同值候选：

| 数对 | 值 | $i \times j$ | 判定 |
|------|-----|------|------|
| (0, 6) | 3 | 0 | $0 \% 2 = 0$ ✓ |
| (2, 3) | 2 | 6 | $6 \% 2 = 0$ ✓ |
| (2, 4) | 2 | 8 | $8 \% 2 = 0$ ✓ |
| (3, 4) | 2 | 12 | $12 \% 2 = 0$ ✓ |
| (1, 5) | 1 | 5 | $5 \% 2 = 1$ ✗ |

共 4 对，与官方输出一致。

## 4. 算法细节

1. **循环边界**：外层 $i$ 到 $n-2$、内层 $j$ 从 $i+1$ 起，保证 $i < j$ 不重不漏；写成两个都从 0 起再 `if i >= j: continue` 也对但多余。
2. **短路顺序**：`nums[i]==nums[j] && (i*j)%k==0` 把值判断放前面——多数测试里重复值稀疏，先筛掉大部分对。
3. **0 的整除性**：`(0 * j) % k == 0` 在数学上成立（$0 = 0 \times k$），C++/Python 取余结果也都是 0，无需特判。
4. **乘积不溢出**：$i, j < 100$，乘积 $< 10^4$；即便 $n$ 放大到 $10^5$ 也就是 $10^{10}$ 需要 `long long`，本题规模完全不用。
5. **复杂度下界直觉**：若 $n$ 放大到 $10^5$ 且 $k$ 任意，可用「按值分组 + 组内按 $i \bmod d$（$d \mid k$）分桶」做到近似 $O(n \sqrt{k})$ 或 $O(n \tau(k))$，但那是完全不同的题了。

## 5. 正确性证明

**引理（枚举完备且不重）**：双重循环 $(i, j)$ 恰好遍历集合 $\{(i, j) : 0 \le i < j < n\}$ 每个元素一次。

**证明**：外层 $i$ 取遍 $[0, n-2]$，内层 $j$ 取遍 $[i+1, n-1]$；对任意满足 $0 \le i < j < n$ 的对，$i \le n - 2$ 且 $j \ge i + 1$，恰在外层第 $i$ 轮、内层第 $j - i - 1$ 次被访问一次；不同 $(i, j)$ 访问时机互异，故不重不漏。∎

**定理**：算法返回值等于满足题意的数对个数。

**证明**：数对是「好对」当且仅当三条件同时成立；算法对每个被遍历的对检查 $nums[i] = nums[j]$（条件 2）与 $i \times j \equiv 0 \pmod k$（条件 3），条件 1（$i < j < n$）由循环边界保证。由引理，所有对被恰好检查一次，计数器每命中一个好对加 1，故返回值即好对总数。∎

## 6. 复杂度分析

- **时间**：$O(n^2)$。$n \le 100$ 时约 5000 对，每对 $O(1)$ 判定。
- **空间**：$O(1)$。只用常数个计数变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int countPairs(vector<int>& nums, int k) {
        int n = nums.size(), ans = 0;
        for (int i = 0; i < n; ++i)
            for (int j = i + 1; j < n; ++j)
                if (nums[i] == nums[j] && (long long)i * j % k == 0) ++ans;
        return ans;
    }
};
```

### Python

```python
class Solution:
    def countPairs(self, nums: list[int], k: int) -> int:
        n = len(nums)
        ans = 0
        for i in range(n):
            for j in range(i + 1, n):
                if nums[i] == nums[j] and i * j % k == 0:
                    ans += 1
        return ans
```

> 💡 两份代码均通过官方示例（`4`、`0`）以及 800 组随机与「按值分组再组内数对计数」独立实现的交叉对拍，`mismatch = 0`。

## 8. 边界情况与易错点

1. **$i = 0$ 时乘积为 0**：0 对任何 $k$ 整除，别把「乘积为 0」当不整除处理（也无需特判，取余自然为 0）。
2. **$k = 1$**：任何整数都能被 1 整除，答案退化为「相同值对」个数；示例 2 输出 0 只是因为无重复值。
3. **全部元素相同**：$\binom{n}{2}$ 对里按乘积整除筛选，不要直接返回 $\binom{n}{2}$。
4. **溢出习惯**：本题乘积很小，但 C++ 写 `(long long)i * j` 是好习惯——若 $n$ 增大，`int` 乘法可能溢出为负导致 `% k` 结果异常。
5. **别把「值相等」错写成「下标相等」**：题面里相等的判断对象是 $nums[i]$ 与 $nums[j]$，整除的对象是下标乘积 $i \times j$，两处对象不同，读题要慢。
