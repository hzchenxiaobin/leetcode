# LeetCode 统计数组中好三元组数目 题解

## 1. 题目概述

- **标题 / 题号**：统计数组中好三元组数目（#2179，hard）
- **链接**：https://leetcode.cn/problems/count-good-triplets-in-an-array/
- **来源**：LeetCode 第 72 场双周赛 Q4
- **难度**：困难
- **标签**：树状数组、线段树、分治、三维偏序

**题意**：给定两个长度为 $n$ 的排列 $nums1$、$nums2$（元素为 $0 \sim n-1$）。三元组 $(x, y, z)$（三个**互不相同**的值）是「好三元组」当且仅当：$x, y, z$ 在 $nums1$ 中的出现顺序与在 $nums2$ 中的出现顺序**完全一致**，即

$$
pos1_x < pos1_y < pos1_z \quad\text{且}\quad pos2_x < pos2_y < pos2_z.
$$

求好三元组的总数目。

**约束**：

- $3 \le n \le 10^5$；
- $nums1$、$nums2$ 均为 $[0, n-1]$ 的排列；
- 答案最大可达 $\binom{n}{3} \approx 1.7 \times 10^{14}$，必须用 64 位整数。

## 2. 示例

**示例 1**

```text
输入：nums1 = [2,0,1,3], nums2 = [0,1,2,3]
输出：1
解释：nums1 中递增的三元组共 4 个：(2,0,1)、(2,0,3)、(2,1,3)、(0,1,3)；
      其中只有 (0,1,3) 在 nums2 中也按 0→1→3 的顺序出现。
```

**示例 2**

```text
输入：nums1 = [4,0,1,3,2], nums2 = [4,1,0,2,3]
输出：4
解释：4 个好三元组：(4,0,3)、(4,0,2)、(4,1,3)、(4,1,2)。
```

**示例 3（边界补充）**

```text
输入：nums1 = [0,1,2], nums2 = [0,1,2]
输出：1
解释：两数组完全相同，唯一三元组 (0,1,2) 在两边都递增，答案 C(3,3)=1。
```

## 3. 解题思路

### 3.1 暴力思路

按定义枚举：在 $nums1$ 中取位置 $p < q < r$ 得到值三元组，检查它们在 $nums2$ 中的位置是否递增——$O(n^3)$。$n = 100$ 时 $10^5$ 尚可，$n = 10^5$ 时约 $1.7 \times 10^{14}$ 次，完全不可行。即便优化到「枚举前两个 + 哈希查第三个的合法性」也是 $O(n^2)$ 量级，仍然爆炸。需要把「两个数组中的顺序同时一致」这一条件**换一个坐标系**来表达。

### 3.2 核心观察：重映射成单数组上的「递增三元组」

![重映射：nums1 映到 nums2 坐标系](images/bw72_q4_remap_model.svg)

令 $pos2[v]$ 为值 $v$ 在 $nums2$ 中的位置。把 $nums1$ 的每个值换成它在 $nums2$ 中的位置，得到序列

$$
a[i] = pos2[nums1[i]], \quad i = 0, 1, \dots, n-1.
$$

于是发生**视角转换**：

- 「$x, y, z$ 在 $nums1$ 中按此顺序出现」⇔ 以 $nums1$ 的下标为**时间轴**，$x$ 先于 $y$ 先于 $z$ 被访问；
- 「在 $nums2$ 中也按此顺序出现」⇔ $pos2_x < pos2_y < pos2_z$，即 $a$ 下标递增处**值也递增**。

**好三元组 ⇔ 序列 $a$ 中的严格递增三元组** $a[p] < a[q] < a[r]$（$p < q < r$）。两个数组的一致顺序问题坍缩成单个数组上的三维偏序（下标一维 + 值一维 + 「同时有序」一维），而 $a$ 本身就是 $[0, n-1]$ 的一个排列（双射复合仍是双射）。

### 3.3 算法流程：固定中间元素 + 树状数组两趟扫描

![树状数组双向扫描：固定中间元素统计](images/bw72_q4_bit_sweep.svg)

递增三元组天然以**中间元素** $a[q]$ 为枢纽分解：

$$
\#\{\text{递增三元组}\} = \sum_{q=0}^{n-1} \underbrace{\#\{p < q : a[p] < a[q]\}}_{left[q]} \times \underbrace{\#\{r > q : a[r] > a[q]\}}_{right[q]}.
$$

左端选谁、右端选谁**相互独立**，乘法原理直接相乘。$left$、$right$ 都是经典的「在线排名查询」，用**树状数组**（BIT）维护：

```text
1. 预处理 pos2[v]，构造 a[i] = pos2[nums1[i]]
2. 左→右扫 a：处理 a[q] 前，BIT 中存的是 a[0..q−1] 全体
   left[q] = query(a[q] − 1)          # 已插入值中 ≤ a[q]−1 的个数
   update(a[q])
3. 清空 BIT，右→左扫 a：处理 a[q] 前，BIT 中存的是 a[q+1..n−1] 全体
   right[q] = (n − 1 − q) − query(a[q])   # 已插入总数 − ≤a[q] 的个数
   update(a[q])
4. 答案 = Σ left[q] × right[q]
```

第 3 步的恒等式：右侧共插入 $n - 1 - q$ 个**互不相同**的值，其中大于 $a[q]$ 的个数 = 总数 − 小于等于 $a[q]$ 的个数（$a[q]$ 自身尚未插入，不存在等于的情况）。

### 3.4 示例演算

![示例演算：a=[2,0,1,3] 的 left/right 表](images/bw72_q4_example_walkthrough.svg)

**示例 1**（$nums1 = [2,0,1,3]$，$nums2 = [0,1,2,3]$）：$pos2 = [0,1,2,3]$，故 $a = [2, 0, 1, 3]$。

| $q$ | $a[q]$ | $left[q]$（左侧更小） | $right[q]$（右侧更大） | 乘积 |
|-----|--------|----------------------|----------------------|------|
| 0 | 2 | 0（左侧空） | $3 - 2 = 1$ | 0 |
| 1 | 0 | 0（没有数 $< 0$） | $2 - 0 = 2$ | 0 |
| 2 | 1 | 1（只有 0） | $1 - 0 = 1$ | 1 |
| 3 | 3 | 3（0、1、2 全部） | 0（右侧空） | 0 |

答案 $= 0 + 0 + 1 + 0 = 1$ ✓。

**示例 2**（$nums1 = [4,0,1,3,2]$，$nums2 = [4,1,0,2,3]$）：$pos2 = [2, 1, 3, 4, 0]$，故 $a = [0, 2, 1, 4, 3]$。逐位计算：$left = [0, 1, 1, 3, 3]$，$right = [4, 2, 2, 0, 0]$，乘积和 $= 0 + 2 + 2 + 0 + 0 = 4$ ✓。

## 4. 算法细节

1. **重映射的方向**：把 $nums1$ 映到 $nums2$ 的坐标系（$a = pos2 \circ nums1$）。反方向（$pos1 \circ nums2$）同样可行——对称地统计该序列的递增三元组即可，两种写法答案相同（好三元组的定义对称）。
2. **BIT 下标约定**：值域 $[0, n-1]$，BIT 内部 1 起——`update(i)` 与 `query(i)` 前先 `++i`；`query(a[q] - 1)` 当 $a[q] = 0$ 时变 `query(-1)`，需在函数内处理（`i <= 0` 直接返回 0）。
3. **两趟共享一个 BIT 数组**：第二趟前 `fill(bit.begin(), bit.end(), 0)` 清零即可，无需重新分配。
4. **答案类型**：$\binom{10^5}{3} \approx 1.666 \times 10^{14}$，超 32 位；C++ 用 `long long`（乘法 `left[j] * greaterRight` 两侧至少一侧是 `long long`，本实现中 `greaterRight` 已声明为 `long long`）。Python 无虑。
5. **left 用 `long long` 存储**：单看 $left[q] \le n$ 用 `int` 够，但乘积必须 64 位，统一 `long long` 最省心。
6. **等价替代实现**：右→左那趟也可以换成「先右→左算 $right$，再左→右算 $left$ 顺便累加」，顺序无讲究；用 `std::pb_ds` 的有序集（`order_of_key`）或归并排序分治（CDQ）都能过，复杂度同为 $O(n \log n)$，BIT 代码最短。
7. **为什么不用线段树**：本题只需要「单点 +1、前缀求和」，BIT 恰好够用且常数更小；线段树是杀鸡用牛刀，但结构上完全等价。

## 5. 正确性证明

**引理 1（重映射等价性）**：三元组 $(x, y, z)$（三个互异的值）是好三元组，当且仅当存在 $p < q < r$ 使 $nums1[p] = x,\ nums1[q] = y,\ nums1[r] = z$ 且 $a[p] < a[q] < a[r]$。

**证明**：因 $nums1$ 是排列，值 $x, y, z$ 在 $nums1$ 中的位置唯一，分别记 $p, q, r$；$pos1_x < pos1_y < pos1_z$ 即 $p < q < r$。又 $a[p] = pos2[x]$ 等，故 $pos2_x < pos2_y < pos2_z \iff a[p] < a[q] < a[r]$。两个条件合起来即引理所述。∎

**引理 2（中间元素分解）**：序列 $a$ 中严格递增三元组的个数等于 $\sum_q left[q] \times right[q]$。

**证明**：任一递增三元组由其中间位置 $q$ 唯一确定（$p < q < r$ 且 $a[p] < a[q] < a[r]$）；反之，任取 $p \in \{p < q : a[p] < a[q]\}$ 与 $r \in \{r > q : a[r] > a[q]\}$，$a[p] < a[q] < a[r]$ 与 $p < q < r$ 同时成立，构成一个递增三元组，且不同的 $(p, q, r)$ 对应不同三元组。固定 $q$ 时左端与右端的选择相互独立，由乘法原理恰有 $left[q] \times right[q]$ 个。对 $q$ 求和，每个三元组恰被其自身的 $q$ 计一次，无重无漏。∎

**引理 3（BIT 计数正确）**：左→右扫描中，处理 $a[q]$ 之前 BIT 恰包含集合 $\{a[0], \dots, a[q-1]\}$ 各一次，且 $query(t)$ 返回其中值 $\le t$ 的元素个数。

**证明**：BIT 是「单点加 1、前缀和」结构，对值域 $[0, n-1]$ 建立；归纳：初始为空集合；每次处理完 $a[q]$ 执行 `update(a[q])` 即把值 $a[q]$ 的计数加 1，故处理 $a[q']$（$q' > q$）前 BIT 恰含 $\{a[0..q'-1]\}$（$a$ 是排列，值互异故各一次）。$query(t)$ 返回下标 $[0, t]$ 的计数和即值 $\le t$ 的元素个数。右→左对称。∎

**定理**：算法返回值等于好三元组总数。

**证明**：由引理 3，$left[q] = query(a[q]-1)$ 恰为 $\#\{p < q : a[p] < a[q]\}$（值 $\le a[q]-1$ 即 $< a[q]$）；右趟中 BIT 含 $\{a[q+1..n-1]\}$，已插入总数为 $n-1-q$，$query(a[q])$ 为其中 $\le a[q]$ 的个数，而 $a[q]$ 自身不在集合中（互异排列），故差值恰为 $\#\{r > q : a[r] > a[q]\} = right[q]$。代入引理 2 的分解式，累加即递增三元组总数；再由引理 1，该数目即好三元组总数。∎

## 6. 复杂度分析

- **时间**：$O(n \log n)$。重映射 $O(n)$；两趟扫描各 $n$ 次 BIT 操作，每次 $O(\log n)$；求和 $O(n)$。
- **空间**：$O(n)$。$pos2$、$a$、$left$ 数组各 $O(n)$，BIT 数组 $O(n)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long goodTriplets(vector<int>& nums1, vector<int>& nums2) {
        int n = nums1.size();
        vector<int> pos2(n), a(n);
        for (int i = 0; i < n; ++i) pos2[nums2[i]] = i;
        for (int i = 0; i < n; ++i) a[i] = pos2[nums1[i]];   // 把 nums1 映成 nums2 的位置序列

        vector<int> bit(n + 1, 0);
        auto update = [&](int i) { for (++i; i <= n; i += i & (-i)) ++bit[i]; };
        auto query = [&](int i) {              // 已插入值中，值 <= i 的个数
            int s = 0;
            for (++i; i > 0; i -= i & (-i)) s += bit[i];
            return s;
        };

        vector<long long> left(n);
        for (int j = 0; j < n; ++j) {          // 左起：a[j] 左侧比它小的个数
            left[j] = query(a[j] - 1);
            update(a[j]);
        }
        fill(bit.begin(), bit.end(), 0);
        long long ans = 0;
        for (int j = n - 1; j >= 0; --j) {     // 右起：a[j] 右侧比它大的个数
            long long greaterRight = (long long)(n - 1 - j) - query(a[j]);
            ans += left[j] * greaterRight;
            update(a[j]);
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def goodTriplets(self, nums1: list[int], nums2: list[int]) -> int:
        n = len(nums1)
        pos2 = [0] * n
        for i, v in enumerate(nums2):
            pos2[v] = i
        a = [pos2[v] for v in nums1]     # nums1 映成 nums2 中的位置序列

        bit = [0] * (n + 1)

        def update(i):
            i += 1
            while i <= n:
                bit[i] += 1
                i += i & (-i)

        def query(i):                    # 已插入的值中，<= i 的个数
            i += 1
            s = 0
            while i > 0:
                s += bit[i]
                i -= i & (-i)
            return s

        left = [0] * n
        for j in range(n):               # a[j] 左侧比它小的个数
            left[j] = query(a[j] - 1)
            update(a[j])

        bit = [0] * (n + 1)
        ans = 0
        for j in range(n - 1, -1, -1):   # a[j] 右侧比它大的个数
            greater_right = (n - 1 - j) - query(a[j])
            ans += left[j] * greater_right
            update(a[j])
        return ans
```

> 💡 两份代码均通过官方示例（`1`、`4`）、310 组随机排列（$n \le 300$）与 $O(n^3)$ 定义暴力的对拍，`mismatch = 0`；$n = 10^5$ 随机排列 C++ 0.21s / Python 0.45s，两者输出一致（含 $2.7 \times 10^{13}$ 量级的大答案）。

## 8. 边界情况与易错点

1. **答案溢出**：$\binom{10^5}{3} \approx 1.7 \times 10^{14}$ 远超 `int`；C++ 返回类型 `long long`，且**乘法** `left[j] * greaterRight` 必须至少一侧 64 位（两侧都 `int` 会先溢出再赋值）。这是本题最热门的 WA 点。
2. **$a[q] = 0$ 时的查询**：`query(-1)` 应返回 0；BIT 内部 `++i` 后为 0，循环体不执行，自然返回 0——但若把 `query(a[j] - 1)` 写成 `query(a[j]) - 1` 之类的「技巧」就会错（会把等于自身的值也算进去）。
3. **两趟之间必须清空 BIT**：第二趟复用数组前 `fill` 清零，否则左趟的计数会污染右趟。
4. **$n = 3$ 最小规模**：答案 0 或 1，用来快速自检；两数组完全相同（$a = [0..n-1]$）时答案 $\binom{n}{3}$，完全相反（$a = [n-1..0]$）时答案 0，可作极值校验。
5. **重映射数组构造**：$a[i] = pos2[nums1[i]]$，别写成 $pos2[i]$ 或 $pos1[nums2[i]]$ 方向搞混——方向错误通常不报错而是输出一个「似是而非」的数，务必用小样例对拍。
6. **乘法原理的独立性前提**：$left[q]$ 与 $right[q]$ 统计的是**不同侧**的元素，集合不相交（一侧下标 $< q$、另一侧 $> q$），才能直接相乘；若把中间元素自身计入会重复。
7. **long 累加**：Python 中 `ans` 无类型顾虑；C++ 中 `ans += left[j] * greaterRight` 若 `greaterRight` 是 `int` 表达式（如 `(n - 1 - j) - query(a[j])`），务必先转 `long long`。

**延伸思考**：本题是**三维偏序**（3D dominance counting）的降维特例：元素有三个坐标 $(pos1, pos2, value)$，好三元组要求三个坐标同时严格有序。一般的 3D 偏序用 **CDQ 分治**（按第一维排序、分治处理、BIT 统计跨区间贡献）做到 $O(n \log^2 n)$；本题因「值即排名、两个位置轴都是双射」而能一步重映射坍缩成二维，再用「固定中间 + 两侧独立」降到 $O(n \log n)$。更进一步的变体：统计好**四元组**（两个数组中顺序一致的四个值）无法再用中间元素乘法分解，需要 CDQ 或对 $\binom{pair}$ 做第二层偏序；若把「严格一致」放宽为「允许一个数组中相等」，重映射后要处理相等值的并列计数，BIT 查询需改成半开区间——这些变体共同勾勒出「偏序计数」从一维到高维的完整谱系。
