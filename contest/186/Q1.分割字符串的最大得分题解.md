# LeetCode 分割字符串的最大得分 题解

## 1. 题目概述

- **标题 / 题号**：分割字符串的最大得分（#1422，easy）
- **链接**：https://leetcode.cn/problems/maximum-score-after-splitting-a-string/
- **来源**：LeetCode 第 186 场周赛 Q1
- **难度**：简单
- **标签**：字符串、前缀和、计数

**题意**：给定一个仅由 `'0'` 和 `'1'` 组成的字符串 `s`，在某个位置把它切成**两个非空**子字符串（左子串 + 右子串）。定义**得分 = 左子串中 `'0'` 的个数 + 右子串中 `'1'` 的个数**。返回所有合法切法中的最大得分。

**约束**：

- `2 <= s.length <= 500`
- `s` 仅由字符 `'0'` 和 `'1'` 组成

## 2. 示例

**示例 1**

```text
输入：s = "011101"
输出：5
解释：左 "0" + 右 "11101"，得分 = 1 + 4 = 5（5 个分割点中的最大值）
```

**示例 2**

```text
输入：s = "00111"
输出：5
解释：左 "00" + 右 "111"，得分 = 2 + 3 = 5
```

**示例 3**

```text
输入：s = "1111"
输出：3
解释：左 "1" + 右 "111"，得分 = 0 + 3 = 3
```

## 3. 解题思路

### 3.1 暴力思路

枚举 $n-1$ 个分割点，对每个分割点分别向左数 `'0'`、向右数 `'1'`，取最大值。单次统计 $O(n)$，总计 $O(n^2)$。本题 $n \le 500$，$O(n^2)$ 约 $2.5 \times 10^5$ 次操作也能通过，但重复数了太多遍——每次移动分割点只有一个字符换了边，却把两边的计数全部重算，白板场景下应给出**线性做法**。

### 3.2 核心观察：分割点只移动一格，得分只变化 ±1

![核心观察：得分 = 左半 0 数 + 右半 1 数](images/1422_split_score_concept.svg)

设分割点为 $i$（左子串为 $s[0..i-1]$，右子串为 $s[i..n-1]$），得分记为 $f(i)$。比较**相邻两个分割点** $i$ 与 $i+1$：唯一的变化是字符 $s[i]$ 从右侧搬到了左侧。

- 若 $s[i] = \texttt{'0'}$：左边 `'0'` 的个数多 1，右边 `'1'` 的个数不变（`'0'` 本来就不贡献右边）→ $f(i+1) = f(i) + 1$
- 若 $s[i] = \texttt{'1'}$：左边 `'0'` 的个数不变，右边 `'1'` 的个数少 1 → $f(i+1) = f(i) - 1$

> 💡 一句话总结：得分序列 $f(1), f(2), \dots, f(n-1)$ 是一条**每步 ±1 的折线**，完全由初始值 $f(1)$ 和逐个搬家的字符决定，因此只需 $O(1)$ 地递推，不必重算任何计数。

### 3.3 算法流程：一次遍历增量维护

![算法流程：s[i] 搬家与得分的 ±1 更新](images/1422_one_pass_flow.svg)

1. **初始化**：令分割点为 1（左 = `s[0]`，右 = `s[1..n-1]`），计算 $f(1) = [s[0] = \texttt{'0'}] + \text{ones}(s[1..n-1])$，其中 $[\cdot]$ 为指示函数。令 `ans = f(1)`。
2. **递推**：字符下标 $i$ 从 1 到 $n-2$，每轮把 $s[i]$ 搬到左侧：`s[i]=='0'` 则 `score += 1`，否则 `score -= 1`，并更新 `ans = max(ans, score)`。此时 `score` 恰为分割点 $i+1$ 的得分。
3. **返回** `ans`，覆盖了全部 $n-1$ 个合法分割点。

等价写法（前缀统计视角）：预处理全串 `'1'` 的总数 $\text{total}$，从左到右扫，维护前缀 `'0'` 数 $z_i$ 与前缀 `'1'` 数 $o_i$，则 $f(i) = z_i + (\text{total} - o_i)$。两种写法只是增量法的不同表述。

### 3.4 示例演算

![示例演算：011101 的 5 个分割点与增量序列](images/1422_walkthrough_011101.svg)

以 `s = "011101"` 为例：初始 $f(1) = 1 + 4 = 5$；随后搬家的字符依次为 `'1','1','1','0'`，得分依次 $-1,-1,-1,+1$，序列为 $5,4,3,2,3$，最大值 $5$。

## 4. 算法细节

1. **初始值计算**：$f(1) = [s[0]=\texttt{'0'}] + \text{ones}(s[1..n-1])$。可以先数全串 `'1'` 的总数再减去 $[s[0]=\texttt{'1'}]$，也可以直接一次扫描：`score` 从 $[s[0]=\texttt{'0'}]$ 起步，先遍历 `s[1..]` 累加 `'1'`。
2. **循环边界**：递推循环的字符下标是 $i \in [1, n-2]$，对应分割点 $[2, n-1]$；加上初始分割点 1，恰好覆盖全部 $n-1$ 个合法分割点。**下标 $n-1$ 的字符永远留在右侧**（否则右子串为空）。
3. **数据结构选择**：只需 `score`、`ans` 两个整型变量，无需前缀和数组。
4. **数据范围**：$n \le 500$，得分上界 $n-1 \le 499$，`int` 完全够用。

## 5. 正确性证明

**引理 1（增量公式）**：对 $1 \le i \le n-2$，有

$$f(i+1) - f(i) = \begin{cases} +1, & s[i] = \texttt{'0'} \\ -1, & s[i] = \texttt{'1'} \end{cases}$$

**证明**：$f(i+1)$ 与 $f(i)$ 的左子串相差恰好一个字符 $s[i]$（前者多包含它），右子串相差也恰好是 $s[i]$（后者多包含它）。若 $s[i] = \texttt{'0'}$：左半 `'0'` 数加 1，而右半 `'1'` 数在两种分割下均不含这个 `'0'` 的贡献，不变，故差为 $+1$。若 $s[i] = \texttt{'1'}$：左半 `'0'` 数不变（`'1'` 不贡献左边），右半 `'1'` 数少 1（该字符移出了右半），故差为 $-1$。∎

**引理 2（初始值）**：$f(1) = [s[0]=\texttt{'0'}] + \text{ones}(s[1..n-1])$。

**证明**：分割点 1 的左子串恰为 $s[0]$，其中 `'0'` 的个数为 $[s[0]=\texttt{'0'}]$；右子串为 $s[1..n-1]$，其中 `'1'` 的个数即 $\text{ones}(s[1..n-1])$。由得分定义二者相加。∎

**定理**：算法返回的 `ans` 等于 $\max_{1 \le i \le n-1} f(i)$。

**证明**：归纳可证递推过程中每一步的 `score` 等于当前分割点的得分：初始时刻由引理 2 成立；由引理 1，每搬一个字符后的更新恰好等于下一个分割点的得分。循环依次访问分割点 $1, 2, \dots, n-1$，即整个可行域，而 `ans` 每步与当前 `score` 取 max，故 `ans` 为所有分割点得分的最大值。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。初始化扫描一遍（统计初始得分），递推再扫描一遍（每步 $O(1)$ 更新），总计两次线性扫描。
- **空间复杂度**：$O(1)$。仅使用 `score`、`ans` 等常数个变量，不建前缀和数组。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maxScore(string s) {
        int n = s.size();
        int score = (s[0] == '0');
        for (int i = 1; i < n; i++) {
            score += (s[i] == '1');   // 初始分割点 1：右侧 1 的个数
        }
        int ans = score;
        for (int i = 1; i <= n - 2; i++) {   // 把 s[i] 搬到左侧，分割点变为 i+1
            score += (s[i] == '0') ? 1 : -1;
            ans = max(ans, score);
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maxScore(self, s: str) -> int:
        n = len(s)
        score = (s[0] == '0') + sum(c == '1' for c in s[1:])
        ans = score
        for i in range(1, n - 1):
            score += 1 if s[i] == '0' else -1
            ans = max(ans, score)
        return ans
```

## 8. 边界情况与易错点

1. **两侧必须非空**：合法分割点为 $i \in [1, n-1]$（左 = $s[0..i-1]$）。若误把 $s[n-1]$ 也搬到左侧（分割点 $n$，右子串为空），会得到非法答案——例如 `s = "00000"` 会错算成 5（正确答案为 4）。
2. **n = 2**：只有 1 个分割点，递推循环不执行，直接返回初始值。如 `"00"` → 1，`"10"` → 0。
3. **全 '1' 串**：左半永远贡献 0，最优是让右半尽量长，取分割点 1，答案 $n-1$（如 `"1111"` → 3）。
4. **全 '0' 串**：右半永远贡献 0，最优是让左半尽量长，取分割点 $n-1$，答案 $n-1$（如 `"0000"` → 3）。
5. **初始值的重复计数**：`s[0]` 属于左侧，统计右半 `'1'` 数时不要把它算进去（用 $[s[0]=\texttt{'1'}]$ 修正总数，或直接从下标 1 开始累加）。
6. **增量符号别写反**：搬家的是 `'0'` → `+1`（左边多一个 0），搬家的是 `'1'` → `-1`（右边少一个 1）。
