# LeetCode 带限制的子序列和 题解

## 1. 题目概述

- **标题 / 题号**：带限制的子序列和（#1425，hard）
- **链接**：https://leetcode.cn/problems/constrained-subsequence-sum/
- **来源**：LeetCode 第 186 场周赛 Q4
- **难度**：困难
- **标签**：动态规划、单调队列、滑动窗口、堆（优先队列）

**题意**：给定整数数组 `nums` 和整数 `k`，返回**非空**子序列元素和的最大值。约束：子序列中每两个**相邻**的元素 `nums[i]` 与 `nums[j]` 满足 $i < j$ 且 $j - i \le k$——等价的说法：从数组中按原顺序"跳取"若干元素，**每次跳跃的步长不超过 $k$**，最大化取到的元素之和。

**约束**：

- $1 \le k \le n \le 10^5$
- $-10^4 \le \text{nums}[i] \le 10^4$

> 💡 约束 $j - i \le k$ 把"任意子序列"收紧为"步长受限的子序列"。两个极端都好做：$k \ge n$ 时任意子序列合法（退化为"选所有正数"）；$k = 1$ 时步长不超过 1 强制**连续**（退化为最大子数组和）。一般情形才是本题的考点。

## 2. 示例

**示例 1**

```text
输入：nums = [10,2,-10,5,20], k = 2
输出：37
解释：子序列 [10, 2, 5, 20]：下标 0→1→3→4，
      相邻间距 1、2、1，均 ≤ 2。
```

**示例 2**

```text
输入：nums = [-1,-2,-3], k = 1
输出：-1
解释：子序列必须非空，全负时最优是"只取最大元素"——
      负数接得越多和越小，答案可以为负。
```

**示例 3**

```text
输入：nums = [10,-2,-10,-5,20], k = 2
输出：23
解释：子序列 [10, -2, -5, 20]：跳过 -10（下标 2），
      0→1→3→4 的间距 1、2、1 均合法，和 23 > 连续全取的 13。
```

**示例 4（补充：k = 1 强制连续）**

```text
输入：nums = [1,-2,3,-1,2], k = 1
输出：4
解释：步长 ≤ 1 ⇒ 子序列必须连续，即 53. 最大子数组和：
      最优段 [3, -1, 2] = 4。
```

## 3. 解题思路

### 3.1 暴力思路：状态设计对了，窗口扫描太慢

**状态定义**：$dp[i]$ = **以 `nums[i]` 结尾**（必须选它）的合法子序列的最大和。

为什么状态要带"结尾"信息？约束 $j - i \le k$ 作用于子序列**相邻两个元素**的下标差——只有知道"最后一个选的是谁"，才知道下一步能接在哪。若定义成"前 $i$ 个元素的最大和"，结尾位置被丢掉，转移无从下手。

**转移**：以 `nums[i]` 结尾的子序列，前一个元素要么不存在（单开一段），要么是某个 `nums[j]`，$j \in [i-k, i-1]$：

$$dp[i] = \text{nums}[i] + \max\Bigl(0,\ \max_{i-k \le j \le i-1} dp[j]\Bigr)$$

- 外层 $\max(0, \cdot)$：窗口内最优前驱为负时接上去是拖累，不如从 `nums[i]` 单开一段；
- $i = 0$ 时窗口为空，$dp[0] = \text{nums}[0]$；
- 子序列可结束在任意位置，答案 $= \max_i dp[i]$。

**暴力实现**：对每个 $i$ 线性扫描窗口 $[i-k, i-1]$ 取最大，总时间 $O(nk)$。$n, k$ 均可达 $10^5$，最坏 $10^{10}$ 次运算，**超时**。

> ⚠️ 瓶颈在"对每个 $i$ 重新求一遍窗口内 $\max dp[j]$"。相邻两个窗口 $[i-k, i-1]$ 与 $[i+1-k, i]$ 只差一进一出，高度重叠却完全没复用——这是 [239. 滑动窗口最大值](https://leetcode.cn/problems/sliding-window-maximum/) 暴力解的翻版，解法也同源：**单调队列**。

### 3.2 核心观察：Kadane 的窗口化 + 单调队列

![核心观察：dp[i] 依赖窗口 [i−k, i−1] 内 dp 的最大值，k=1 时退化为 Kadane](images/wc186_q4_dp_window_concept.svg)

两个观察把本题钉死：

**观察一：$k = 1$ 时本题就是 Kadane**。步长 $\le 1$ 强制连续，转移退化为 $dp[i] = \text{nums}[i] + \max(0, dp[i-1])$——正是 53. 最大子数组和。本题是 Kadane 的**窗口化推广**：把"续接前一位"推广为"续接窗口内最优前驱"。$\max(0, \cdot)$ 继承自 Kadane，含义是"前驱全负时另起一段"。

**观察二：转移只依赖窗口内 $dp$ 的最大值**。这与 239 完全同构，只把维护对象从 `nums` 换成 `dp`：双端队列存**下标**，使对应 $dp$ 值从队头到队尾**单调递减**，队头永远是当前窗口 $[i-k, i-1]$ 内 $dp$ 最大的下标，$O(1)$ 取用。两个维护动作：

1. **过期出队（队头）**：队头下标 $< i - k$，已滑出窗口。队列中下标单调递增 ⇒ 过期者必然堆在队头，且一旦滑出**永不复活**（$i$ 越走越大，窗口左端只进不退）。
2. **入队弹尾（队尾）**：新算出的 $dp[i]$ 入队前，弹掉所有 $dp[\cdot] \le dp[i]$ 的队尾——它们"**更小且更早过期**"：只要 $i$ 还在窗口里，这些旧值永远轮不上当最大，丢弃无损。

### 3.3 算法流程：单调队列四步走

![算法流程：过期出队 → 查询计算 dp[i] → 入队弹尾 → 更新答案](images/wc186_q4_monotonic_queue_flow.svg)

对每个 $i$（从 $0$ 到 $n-1$）依次执行：

1. **过期出队**：`while 队非空 且 队头 < i − k：pop_front()`；
2. **查询并计算**：`best = 队空 ? 0 : dp[队头]`，`dp[i] = nums[i] + max(0, best)`；
3. **入队弹尾**：`while 队非空 且 dp[队尾] ≤ dp[i]：pop_back()`，然后 `push_back(i)`；
4. **更新答案**：`ans = max(ans, dp[i])`。

> ⚠️ **顺序不能反**：先过期再查询——查询时队头必须是**合法窗口内**的最大；`dp[i]` 算完才能入队——提前入队会让自己给自己当前驱（$j = i$ 非法）。与 239 / 1499 的"先过期、再查询、后弹尾"一脉相承。

### 3.4 示例演算

![示例演算：nums=[10,−2,−10,−5,20]，k=2，5 步遍历的队列变化与 dp 填充](images/wc186_q4_example_walkthrough.svg)

以示例 3 `nums = [10, -2, -10, -5, 20]`、$k = 2$ 为例：

| $i$ | nums[i] | 队列（下标:dp，入队后） | 动作 | dp[i] | ans |
|-----|---------|------------------------|------|-------|-----|
| 0 | 10 | `[0:10]` | 窗口空，best=0；dp[0]=10；入队 0 | 10 | 10 |
| 1 | −2 | `[0:10, 1:8]` | best=dp[0]=10；dp[1]=−2+10=8；10>8 不弹尾 | 8 | 10 |
| 2 | −10 | `[0:10, 1:8, 2:0]` | 队头 0 ≥ 2−2=0 **不过期**（距离恰为 k=2 仍合法）；best=10；dp[2]=0 | 0 | 10 |
| 3 | −5 | `[1:8, 3:3]` | 队头 0 < 3−2=1 → **过期弹出 0**；best=dp[1]=8；dp[3]=−5+8=3；弹尾 2:0 ≤ 3 | 3 | 10 |
| 4 | 20 | `[4:23]` | 队头 1 < 4−2=2 → **过期弹出 1**；best=dp[3]=3；dp[4]=20+3=23；弹尾 3:3 ≤ 23 | 23 | **23** |

三处关键：

- **$i=2$（边界）**：下标 0 距 $i=2$ 恰为 $k=2$，`0 < 2−2` 不成立，**不过期**——$j - i \le k$ 含等号，距离恰为 $k$ 的前驱仍可用；
- **$i=3$（双端齐动）**：下标 0 距离 3 超限，从**队头**过期弹出；同时 `2:0` 因 $dp[2]=0 \le dp[3]=3$ 从**队尾**弹出——两端各司其职，互不干扰；
- **$i=4$（窗口最大即可）**：best = dp[3] = 3 虽然平庸，但它是窗口 $[2,3]$ 内的最大——$20 + 3 = 23$ 恰好跳过了 `-10`（若接 $dp[2]=0$ 只得 20）。

最终 $dp = [10, 8, 0, 3, 23]$，答案 $\max(dp) = 23$，子序列 `[10, -2, -5, 20]`（下标 0→1→3→4）。

> 💡 **一句话总结**：1425 的本质是"**DP 转移依赖滑动窗口内 $dp$ 的最大值**"——把 Kadane 的"续接前一位"推广为"续接窗口 $[i-k, i-1]$ 内最优前驱"，再用单调队列把窗口 max 查询从 $O(k)$ 压到均摊 $O(1)$，整体 $O(n)$。形如 $f(i) = g(i) + \max_{j \in \text{窗口}} f(j)$ 的转移都可套用这套提速范式。

## 4. 算法细节

1. **状态必须携带结尾信息**：$dp[i]$ 定义为"以 `nums[i]` 结尾"，转移才干干净净地依赖一个窗口。"前 $i$ 个的最大和"无法表达相邻间距约束。
2. **$\max(0, \cdot)$ 是"单开一段"的选项**：窗口空（$i=0$）时 best 取 0，$dp[0] = \text{nums}[0]$ 自然成立，无需特判；窗口内前驱全负（示例 2）时同样取 0，不硬接负前驱。
3. **队列存下标，不存值**：过期判断要看下标（$< i-k$），维护单调要看 $dp$ 值，二者都要用。也可在队列里存 `(下标, dp值)` 二元组，省掉整个 `dp` 数组，空间降到 $O(k)$。
4. **过期条件用严格小于**：`队头 < i − k`。窗口是 $[i-k, i-1]$，下标 $i-k$ 距 $i$ 恰为 $k$ 仍合法（演算 $i=2$ 步）；对比 239 的窗口 $[i-k+1, i]$（含当前元素），过期条件是 `队头 ≤ i − k`——两题窗口定义差 1，条件差一个等号。
5. **弹尾条件用 `≤`**：$dp$ 相同的旧下标先过期，留着无意义，只留最新的；用 `<` 也正确但队列更长。
6. **答案是 $\max_i dp[i]$ 而非 $dp[n-1]$**：子序列可从任意位置开始、任意位置结束。对照 [1696. 跳跃游戏 VI](https://leetcode.cn/problems/jump-game-vi/)——起点 0、终点 $n-1$ 固定的"路径版"，那里没有 $\max(0, \cdot)$（没有另起一段的退路）、答案取 $dp[n-1]$。本题若照搬 1696 的返回 $dp[n-1]$，在全负数组上会答错。

## 5. 正确性证明

**引理 1（转移式正确）**：设 $\mathcal{S}_i$ 为全部以 `nums[i]` 结尾的合法子序列，则 $\max_{S \in \mathcal{S}_i} \mathrm{sum}(S) = \text{nums}[i] + \max\bigl(0,\ \max_{i-k \le j \le i-1} dp[j]\bigr)$。

**证明**：对 $S \in \mathcal{S}_i$ 按长度分类。$|S| = 1$：$\mathrm{sum}(S) = \text{nums}[i]$。$|S| \ge 2$：去掉末尾 `nums[i]` 得 $S'$，以某个 `nums[j]` 结尾；$S$ 合法当且仅当 $S'$ 合法**且**新出现的相邻对 $(j, i)$ 满足 $i - j \le k$，即 $j \in [i-k, i-1]$。于是

$$\max_{S \in \mathcal{S}_i} \mathrm{sum}(S) = \max\Bigl(\text{nums}[i],\ \text{nums}[i] + \max_{i-k \le j \le i-1} \bigl(\max_{S' \in \mathcal{S}_j} \mathrm{sum}(S')\bigr)\Bigr)$$

右端即 $\text{nums}[i] + \max\bigl(0,\ \max_{i-k \le j \le i-1} dp[j]\bigr)$（按 $i$ 从小到大归纳，$dp[j]$ 在计算 $dp[i]$ 前已得定义值）。∎

**引理 2（答案形式）**：合法子序列和的最大值 $= \max_{0 \le i < n} dp[i]$。

**证明**：任一非空合法子序列结束于某个 $i$，其和 $\le dp[i] \le \max_i dp[i]$；反向，每个 $dp[i]$ 都被某个合法子序列取到（对引理 1 的分类构造归纳）。两向夹逼。∎

**引理 3（过期不复活）**：若处理 $i$ 时下标 $b < i - k$，则对一切 $i' \ge i$，$b < i' - k$。

**证明**：$i' - k \ge i - k > b$。故从队头弹出的下标对当前与未来一切窗口都非法，丢弃无损。∎

**引理 4（弹尾有见证）**：设下标 $b$ 在处理 $t$ 时被弹尾（$b < t$，$dp[b] \le dp[t]$）。对任意后续查询 $i > t$：若 $b$ 在窗口内（$b \ge i - k$），则 $t$ 也在窗口内且 $dp[t] \ge dp[b]$。

**证明**：由 $t > b \ge i - k$ 得 $t > i - k$，又 $t < i$（弹尾发生在处理 $t$ 时，查询在其后），故 $t \in [i-k, i-1]$，且 $dp[t] \ge dp[b]$——丢弃 $b$ 后窗口内仍有不劣的见证。若 $t$ 日后也被弹尾，则被 $dp$ 更大、下标更大的新见证替代；对弹尾时刻归纳，见证链有限且链尾始终留在队列中。∎

**引理 5（查询不变式）**：第 2 步查询时，队列内元素全在窗口 $[i-k, i-1]$ 内，且窗口内每个下标的 $dp$ 值都不超过 $dp[\text{队头}]$。

**证明**：第 1 步刚弹出所有下标 $< i-k$ 的队头，队列中下标从队头到队尾递增（入队顺序保证），故剩余者均 $\ge i-k$，又均 $< i$（$dp[i]$ 尚未入队）——全在窗口内。窗口内不在队列中的下标：若曾被过期弹出，由引理 3 它对当前 $i$ 也非法，与"在窗口内"矛盾；否则曾被弹尾，由引理 4 存在仍在队列中的见证，其 $dp$ 不小于它。而队列内 $dp$ 从队头到队尾递减（弹尾保证），队头是队列内最大者。∎

**定理**：算法返回 $\max_i dp[i]$，即所求合法子序列和的最大值。

**证明**：由引理 5，第 2 步的 best 恰为 $\max\bigl(0,\ \max_{j \in [i-k, i-1]} dp[j]\bigr)$，与引理 1 的转移式一致；归纳得算法算出的每个 $dp[i]$ 等于定义值，ans 累计 $\max_i dp[i]$，由引理 2 即最优值。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。每个下标恰好入队 1 次、出队至多 1 次（过期或弹尾），两个 `while` 的总弹出次数 $\le n$，外层 $n$ 轮均摊 $O(1)$。$n = 10^5$ 时约 $2 \times 10^5$ 次队列操作，毫秒级完成。
- **空间复杂度**：$O(n)$（`dp` 数组）。若队列改存 `(下标, dp)` 二元组可省去 `dp` 数组，降至 $O(k)$（队列至多存 $k$ 个下标）。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int constrainedSubsetSum(vector<int>& nums, int k) {
        int n = nums.size();
        deque<int> dq;  // 存下标，对应 dp 值从队头到队尾递减
        vector<int> dp(n);
        int ans = INT_MIN;
        for (int i = 0; i < n; ++i) {
            // ① 过期出队：滑出窗口 [i-k, i-1] 的下标永不复活
            while (!dq.empty() && dq.front() < i - k) dq.pop_front();
            // ② 查询窗口内 dp 最大值；max(0,·) = 不接前驱、单开一段
            int best = dq.empty() ? 0 : dp[dq.front()];
            dp[i] = nums[i] + max(0, best);
            // ③ 入队弹尾：dp 更小且更早过期的下标永不可能成为窗口最大
            while (!dq.empty() && dp[dq.back()] <= dp[i]) dq.pop_back();
            dq.push_back(i);
            // ④ 子序列可结束在任意位置，答案是 max(dp) 而非 dp[n-1]
            ans = max(ans, dp[i]);
        }
        return ans;
    }
};
```

### Python

```python
from collections import deque

class Solution:
    def constrainedSubsetSum(self, nums: List[int], k: int) -> int:
        n = len(nums)
        dq = deque()  # 存下标，对应 dp 值从队头到队尾递减
        dp = [0] * n
        ans = float('-inf')
        for i in range(n):
            # ① 过期出队
            while dq and dq[0] < i - k:
                dq.popleft()
            # ② 查询窗口内 dp 最大值，计算 dp[i]
            best = 0 if not dq else dp[dq[0]]
            dp[i] = nums[i] + max(0, best)
            # ③ 入队弹尾
            while dq and dp[dq[-1]] <= dp[i]:
                dq.pop()
            dq.append(i)
            # ④ 更新答案
            ans = max(ans, dp[i])
        return ans
```

## 8. 边界情况与易错点

1. **全负数组（示例 2）**：最优是最大的单个数。$\max(0, \cdot)$ 兜底"单开一段"，不会硬接负前驱；`ans` 必须初始化为 `INT_MIN` / `float('-inf')`——答案可为负，初始化为 0 会错。
2. **过期条件是 `队头 < i − k` 而非 `≤`**：距离恰为 $k$（下标 $i-k$）的前驱**合法**（演算 $i=2$ 步：`0 ≥ 2−2` 不过期）。也不要照抄 239 的 `≤ i − k`——两题窗口定义差 1。
3. **四步顺序固定**：过期 → 查询 → 入队 → 记答案。`dp[i]` 提前入队会自己接自己（$j = i$ 非法）；查询放在过期前，会用上已滑出窗口的队头。
4. **弹尾用 `≤` 而非 `<`**：同值只留最新（更晚过期），队列更紧凑；`<` 也能过但队列偏长。
5. **$k \ge n$**：窗口覆盖全部历史，过期永不触发，队列退化为"全局单调栈"，算法依然正确；$k = 1$ 强制连续，退化为 53. 最大子数组和——两个极端都可用作对拍校验。
6. **溢出**：$|dp[i]| \le n \times 10^4 = 10^9 < 2^{31} - 1 \approx 2.1 \times 10^9$，`int` 刚好安全；若元素范围放大到 $10^5$（总量 $10^{10}$）必须换 `long long`。Python 无此虑。
7. **`n = 1`**：窗口恒空，`best = 0`，答案即 `nums[0]`（可为负），代码无需特判。
8. **别把答案写成 `dp[n-1]`**：那是 1696"路径版"的答案形式；本题子序列可任意结束，全负数组上 `dp[n-1]` 会漏掉更优的中间单元素。

- [LeetCode 1499. 满足不等式的最大值](https://leetcode.cn/problems/max-value-of-equation/)（第 195 场周赛 Q4）：同属单调队列优化最值查询，窗口按 $x$ 值滑动而非下标。
- [LeetCode 862. 和至少为 K 的最短子数组](https://leetcode.cn/problems/shortest-subarray-with-sum-at-least-k/)：前缀和 + 单调队列的另一种用法（维护凸性而非直接最值）。

**延伸思考**：

- 赛时不熟单调队列，可用**大顶堆 + 懒惰删除**：堆存 $(dp[j], j)$，每次查询前弹出下标 $< i-k$ 的堆顶，$O(n \log n)$，$n = 10^5$ 稳过。堆不利用"窗口连续滑动"的性质，常数更大，但当合法前驱集合**不连续**（如"下标属于给定集合"）时只能用堆/平衡树。
- 若改成**恰好选 $m$ 个**元素求最大和，需加一维状态 $dp[i][c]$（以 $i$ 结尾、选了 $c$ 个），每层一个单调队列，$O(nm)$。
- 若允许**空子序列**，答案与 $\max\bigl(0,\ \max_i dp[i]\bigr)$ 取 max 即可，主流程不变。
