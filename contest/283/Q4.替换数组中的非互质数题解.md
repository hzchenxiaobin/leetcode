# LeetCode 替换数组中的非互质数 题解

## 1. 题目概述

- **标题 / 题号**：替换数组中的非互质数（#2197，hard）
- **链接**：https://leetcode.cn/problems/replace-non-coprime-numbers-in-array/
- **来源**：LeetCode 第 283 场周赛 Q4
- **难度**：困难
- **标签**：栈、数组、数学、数论、最大公约数、最小公倍数

**题意**：给定整数数组 `nums`，反复执行以下操作直到无法继续：任选一对**相邻**的**非互质**数（$\gcd(x, y) > 1$），删除二者并替换为它们的**最小公倍数** $\text{lcm}(x, y)$。返回最终的数组。题目保证：无论以何种顺序替换，最终结果都相同；且最终数组中的值 $\le 10^8$。

**约束**：

- $1 \le \text{nums.length} \le 10^5$
- $1 \le \text{nums[i]} \le 10^5$
- 最终数组中的值 $\le 10^8$

> ⚠️ 本题在本仓库另有[每日题解 2197](../../solution/2101-2200/2197_替换数组中的非互质数.md)，两篇互为印证：本篇是周赛复盘视角，给出「顺序无关性」的**完整严格证明**（局部合流 + Newman 引理）与赛场易错点清单；每日版侧重面试问答与「为什么用栈」的直觉展开。

> 💡 **题眼**：把每次合并看成对数组的一条**重写规则**——长度减一、新值携带两数的全部质因子。「合并只增不减非互质机会」（引理 1）保证了**任意顺序殊途同归**（定理 1），于是可以放心地选最顺手的顺序：单趟扫描 + 栈的贪心左合并，`while` 循环就地处理**级联合并**，每个元素均摊只做一次 gcd。

## 2. 示例

**示例 1**

```text
输入：nums = [6,4,3,2,7,6,2]
输出：[12,7,6]

解释：
- (6, 4) 非互质，lcm(6,4)=12 → [12,3,2,7,6,2]
- (12, 3) 非互质，lcm(12,3)=12 → [12,2,7,6,2]
- (12, 2) 非互质，lcm(12,2)=12 → [12,7,6,2]
- (6, 2) 非互质，lcm(6,2)=6 → [12,7,6]
不存在相邻非互质对，过程终止。
```

**示例 2**（1 是天然分隔符；相等的数也非互质）

```text
输入：nums = [2,2,1,1,3,3,3]
输出：[2,1,1,3]

解释：gcd(1, x) = 1 恒成立，1 永不参与合并也永不被合并；
      两个 2 合并为 lcm(2,2)=2，三个 3 合并为 3。
```

**示例 3**（级联跨过多个栈顶，自构造）

```text
输入：nums = [2,3,6]
输出：[6]

解释：6 先与相邻的 3 合并：lcm(3,6)=6；
      新值 6 又与 2 非互质（gcd(2,6)=2），继续合并 lcm(2,6)=6，
      最终只剩一个 6。一个元素在一次 while 里连续吞噬两个邻居。
```

## 3. 解题思路

### 3.1 暴力思路：反复扫描

每轮从左到右扫一遍数组，遇到第一对相邻非互质数就合并，然后**从头重扫**，直到某一整轮没有合并发生。最坏情况（如 $[2,2,\ldots,2]$，每轮只把长度缩短 1）需要 $O(n)$ 轮 × 每轮 $O(n)$ 次检查 = $O(n^2)$，$n = 10^5$ 时约 $10^{10}$ 次基本操作，必然超时。

> ⚠️ 暴力法的核心痛点：合并出的新值可能与**左侧已扫过**的元素非互质（级联效应），被迫回头重扫。若能在单趟扫描中就地处理级联，每个元素就只需进出一次。

### 3.2 核心观察：栈 + 贪心左合并

两条关键观察支撑优化：

1. **顺序无关**（题目保证，§5 给出严格证明）：任意替换顺序收敛到同一终态。因此可以选最方便的顺序——**从左到右、能合则合（贪心向左合并）**。
2. **级联可以就地处理**：用栈保存「已无相邻非互质对的稳定前缀」。新元素 `x` 到来时，只要与栈顶非互质就弹出栈顶并把 `x` 更新为 $\text{lcm}$；`while` 循环让 `x` 逐层吞噬非互质栈顶，直到栈空或遇到互质边界，再压入 `x`。

![核心观察：新元素逐层吞噬非互质栈顶](images/wc283_q4_stack_merge_concept.svg)

> 💡 为什么级联必须「继续向左」？由**质因子吸收性**（引理 1）：$\text{lcm}(a,b)$ 携带 $a$、$b$ 的全部质因子，合并后的新值与左侧元素的非互质机会**只增不减**——原有的互质边界不受影响（压栈时已锁定），而新值带入的新质因子可能激活更深的非互质关系，必须继续检查。

### 3.3 算法流程

1. 初始化空栈；
2. 依次取每个元素 `x`：**while** 栈非空且 $g = \gcd(\text{栈顶}, x) > 1$：$x \leftarrow \text{栈顶} / g \times x$（即 lcm），弹出栈顶；
3. 压入 `x`；
4. 所有元素处理完毕，栈自底向上即答案。

![算法流程：单趟扫描与 while 级联回环](images/wc283_q4_algorithm_flow.svg)

## 4. 算法细节

1. **栈的不变式**：任一时刻（某个 `x` 处理完后）栈内相邻元素两两互质。初始空栈成立；`x` 压入前 `while` 已保证 $\gcd(\text{新栈顶}, x) = 1$（或栈空），更深的相邻对从未被动过。
2. **LCM 的计算**：$\text{lcm}(a, b) = a / \gcd(a, b) \times b$，**先除后乘**（见第 3 点与 §8）。
3. **值的上界**：栈中每个值都是它所在「合并段」最终 LCM 的**因子**——同一段内逐次合并构成整除链 $L_1 \mid L_2 \mid \cdots \mid L_{\text{终}}$，故任何中间值都 $\le$ 最终值 $\le 10^8$，用 `int` 存值本身不溢出；但表达式 `a * b / g` 的**中间乘积**可达 $10^{16}$，C++ 中必须先除后乘或全程 `long long`。
4. **均摊计数**：每个元素至多入栈一次、出栈一次，`while` 的总轮数（跨整个运行）$\le 2n$（每次弹出配一次检查 + 每次压入前一次失败检查），每轮恰好一次 gcd。
5. **1 无需特判**：$\gcd(1, x) = 1$ 恒成立，1 永不参与合并，是天然的分隔符。

## 5. 正确性证明

题目承诺「任意顺序替换结果相同」，本节给出严格证明——它是贪心栈解法的合法性基石。把一次合并视为数组上的一条**重写规则**，记 $A \to B$ 为数组 $A$ 一步合并得到 $B$，$A \to^* B$ 为多步（含零步）到达；称无法继续操作的数组为**终态**。

### 5.1 局部合流

![局部合流：重叠合并对殊途同归](images/wc283_q4_confluence_diamond.svg)

**引理 1（gcd–lcm 分配律 / 质因子吸收）**：对任意正整数 $a, b, c$，

$$\gcd\big(c,\ \text{lcm}(a, b)\big) = \text{lcm}\big(\gcd(c, a),\ \gcd(c, b)\big)$$

**证明**：对每个质数 $p$，设其在 $a, b, c$ 中的指数为 $\alpha, \beta, \gamma$（可为 0）。等式两边 $p$ 的指数分别为 $\min(\gamma, \max(\alpha, \beta))$ 与 $\max(\min(\gamma, \alpha), \min(\gamma, \beta))$，这是整数上熟知的 min–max 分配恒等式，故两边每个质因子的指数都相等。∎

**推论 1**：$\gcd(c, \text{lcm}(a,b)) = 1 \iff \gcd(c,a) = 1$ 且 $\gcd(c,b) = 1$。即与合并结果互质当且仅当与两个原料都互质——合并「只增不减」非互质机会。

**引理 2（重叠对收敛）**：设数组片段 $(\ldots, a, b, c, \ldots)$ 满足 $\gcd(a,b) > 1$ 且 $\gcd(b,c) > 1$，则先合并 $(a,b)$ 或先合并 $(b,c)$，最终都到达同一数组（该片段成为 $\text{lcm}(a,b,c)$）。

**证明**：设 $L_1 = \text{lcm}(a,b)$。取质数 $p \mid \gcd(b,c)$，则 $p \mid b \Rightarrow p \mid L_1$ 且 $p \mid c$，故 $\gcd(L_1, c) > 1$，$L_1$ 与 $c$ 可继续合并为 $\text{lcm}(L_1, c) = \text{lcm}(a,b,c)$（lcm 的结合律）。对称地，先合并 $(b,c)$ 得 $L_2 = \text{lcm}(b,c)$，由 $\gcd(a,b) > 1$ 得 $\gcd(a, L_2) > 1$，继续合并同样得到 $\text{lcm}(a,b,c)$。两条路线中片段外的元素均未被动过，故两个新数组逐字相同。∎

**引理 3（不相交对可交换）**：若两个可选合并对不共享元素（位置间隔 $\ge 2$），则任意先后执行得到的数组逐字相同。

**证明**：两次操作修改互不相交的位置，互不影响对方的存在性与结果。∎

**引理 4（终止性）**：任何操作序列必然终止，且步数 $\le n - 1$。

**证明**：每次合并使数组长度恰好减一，而长度始终 $\ge 1$。∎

### 5.2 全局合流：终态唯一

**定理 1（顺序无关性 / Newman 引理）**：从同一初始数组出发，任意操作序列都终止，且**终态唯一**。

**证明**：终止性即引理 4。对 $h(A) = $ 从 $A$ 出发的最长操作序列长度（由终止性有限）作强归纳，证明全局合流性：若 $A \to^* B$ 且 $A \to^* C$，则存在 $D$ 使 $B \to^* D$ 且 $C \to^* D$。

- 若 $A$ 为终态：则 $B = C = A$，取 $D = A$。
- 否则设第一步分别走到 $A_1 \to^* B$ 与 $A_2 \to^* C$（$h(A_1), h(A_2) < h(A)$）：
  - 若 $A_1 = A_2$：对 $A_1$ 用归纳假设即得 $D$。
  - 若 $A_1 \ne A_2$：由引理 2、3（局部合流），存在 $E$ 使 $A_1 \to^* E$ 且 $A_2 \to^* E$。对 $A_1$ 用归纳假设，存在 $F$ 使 $B \to^* F$ 且 $E \to^* F$；对 $A_2$ 同理存在 $G$ 使 $C \to^* G$ 且 $E \to^* G$。因 $E$ 从 $A_1$ 可达，$h(E) \le h(A_1) < h(A)$，可对 $E$ 用归纳假设：存在 $D$ 使 $F \to^* D$ 且 $G \to^* D$。串联得 $B \to^* F \to^* D$，$C \to^* G \to^* D$。∎

最后，若 $B$、$C$ 都是终态，上式迫使 $B = D = C$（终态无出边），故终态唯一。∎

**定理 2（栈算法正确性）**：栈算法输出 `nums` 的唯一终态。

**证明**：

1. **合法性**：栈自底向上保存当前中间数组的稳定前缀，`while` 内每次合并对应「中间数组最后两个相邻元素」的一次题目操作，故整个执行是一条合法操作序列，输出 $S$ 是 `nums` 可达的状态。
2. **终态性**：由 §4 第 1 条的不变式，输出数组相邻元素两两互质，不存在可选合并对，确为终态。
3. 由定理 1 终态唯一，$S$ 即答案。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \log V)$，其中 $V \le 10^8$。每个元素至多入栈、出栈各一次，`while` 总轮数 $\le 2n$，每轮一次欧几里得 gcd 计算 $O(\log V)$。
- **空间复杂度**：$O(n)$。栈最深 $n$ 个元素（输入全互质时），输出直接复用栈内容。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    vector<int> replaceNonCoprimes(vector<int>& nums) {
        vector<long long> st;
        for (int x : nums) {
            long long v = x;
            while (!st.empty()) {
                long long g = std::gcd(st.back(), v);
                if (g == 1) break;            // 互质边界，级联停止
                v = st.back() / g * v;        // lcm = 栈顶 / gcd * v（先除后乘）
                st.pop_back();
            }
            st.push_back(v);
        }
        return vector<int>(st.begin(), st.end());
    }
};
```

### Python

```python
from math import gcd
from typing import List

class Solution:
    def replaceNonCoprimes(self, nums: List[int]) -> List[int]:
        st = []
        for x in nums:
            while st:
                g = gcd(st[-1], x)
                if g == 1:                    # 互质边界，级联停止
                    break
                x = st.pop() // g * x         # lcm = 栈顶 // gcd * x（先除后乘）
            st.append(x)
        return st
```

> 💡 C++ 用 `long long` 栈是防御性写法：值本身 $\le 10^8$ 不会溢出 `int`，但「先除后乘」之外的写法（`a * b / g`）中间乘积可达 $10^{16}$。Python 无溢出问题，`// g * x` 保持与 C++ 一致的计算顺序。

## 8. 边界情况与易错点

1. **`while` 写成 `if`**：级联合并被漏掉。`[2,3,6]` 用 `if` 处理 $x=6$：只与 3 合并一次得到栈 `[2,6]`，漏掉 $\gcd(2,6)=2$ 的继续合并，错出 `[2,6]`（正确 `[6]`）。
2. **LCM 先乘后除**：`栈顶 * x / g` 的中间乘积可达 $10^{16}$，32 位 `int` 必溢出；必须 `栈顶 / g * x`（每个中间量 $\le 10^8$）或全程 `long long`。注意题目只保证**最终**值 $\le 10^8$，不要拿它当中间值的挡箭牌。
3. **`nums[i] = 1` 是分隔符**：$\gcd(1, \cdot) = 1$，1 永不参与合并（推论 1），无需特判，但演算时别把 1 卷进任何一段。
4. **相等的相邻元素**：$x > 1$ 时 $\gcd(x, x) = x > 1$，必须合并且 lcm 不变（$[3,3] \to [3]$），别误判「相同就不动」。
5. **返回顺序**：栈自底向上就是答案从左到右，正序输出即可，**不要 reverse**。
6. **`n = 1`**：无任何相邻对，直接返回原数组。
7. **别止步于「题目保证了顺序无关」**：赛中可以放心贪心；但只有引理 1–4 的证明链才能告诉你这保证**为什么**成立，从而迁移到未给保证的变体（例如合并规则换成减法时顺序无关性即失效）。
