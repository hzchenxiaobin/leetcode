# LeetCode Excel 表中某个范围内的单元格 题解

## 1. 题目概述

- **标题 / 题号**：Excel 表中某个范围内的单元格（#2194，easy）
- **链接**：https://leetcode.cn/problems/cells-in-a-range-on-an-excel-sheet/
- **来源**：LeetCode 第 283 场周赛 Q1
- **难度**：简单
- **标签**：字符串、枚举、模拟

**题意**：Excel 单元格 $(r, c)$ 记作 `"<col><row>"`：列号 `col` 是一个大写字母（第 1 列 `A`、第 2 列 `B`……），行号 `row` 是一位整数。给定形如 `"<col1><row1>:<col2><row2>"` 的字符串 `s`（保证 $r_1 \leq r_2$ 且 $c_1 \leq c_2$），返回所有满足 $r_1 \leq r \leq r_2$、$c_1 \leq c \leq c_2$ 的单元格，以 `"<col><row>"` 字符串列表输出，且按**非递减**顺序排列——先按列排，再按行排。

**约束**：

- `s.length == 5`：两个端点各占 2 个字符，中间 1 个 `':'`
- `'A' <= s[0] <= s[3] <= 'Z'`：列号是单个大写字母，且 $c_1 \leq c_2$
- `'1' <= s[1] <= s[4] <= '9'`：行号是一位数字，且 $r_1 \leq r_2$
- `s` 仅由大写字母、数字和 `':'` 组成

> 💡 **签到题信号**：`s` 长度恒为 5，四个参数的下标**完全定死**——`s[0]/s[1]` 是左上角，`s[3]/s[4]` 是右下角，`s[2]` 恒为 `':'`。整题就是「在字母 × 数字的矩形区域里，按列优先枚举所有格子」。

## 2. 示例

**示例 1**

```text
输入：s = "K1:L2"
输出：["K1","K2","L1","L2"]
解释：列 K..L 与行 1..2 的笛卡尔积，共 2×2=4 个单元格。
```

**示例 2**

```text
输入：s = "A1:F1"
输出：["A1","B1","C1","D1","E1","F1"]
解释：行恒为 1，列从 A 扫到 F，共 6 个单元格。
```

**示例 3（单格退化）**

```text
输入：s = "A1:A1"
输出：["A1"]
解释：行、列范围长度均为 1，只输出单个单元格。
```

## 3. 解题思路

### 3.1 暴力思路：枚举全表再过滤排序

最无脑的做法：把 `A1` 到 `Z9` 全部 $26 \times 9 = 234$ 个单元格都生成一遍，过滤出落在矩形内的，再按「先列后行」排序输出。正确但完全多余——**排序是没有必要的**：只要枚举顺序本身选对了，结果天然有序；过滤也是没有必要的：直接从 $c_1$ 枚举到 $c_2$、从 $r_1$ 枚举到 $r_2$，根本不会碰到界外格子。

### 3.2 核心观察：双重循环天然有序

![解析与双重循环范围](images/excel_range_parse_concept.svg)

**关键观察**：外层循环枚举**列** `c1..c2`，内层循环枚举**行** `r1..r2`，每步把 `col + row` 拼成字符串追加到答案：

- 列在外层**单调不减**、行在内层**单调不减**，产生的序列恰好就是题目要求的「先按列排，再按行排」的非递减序
- 枚举的正是 $[c_1, c_2] \times [r_1, r_2]$ 的**笛卡尔积**，不重不漏，无需过滤、无需排序

换句话说，**循环结构本身就是排序结构**——「按序输出二维区域」类签到题的共同套路：让枚举顺序与目标顺序一致，省掉排序。

### 3.3 算法流程

![算法流程：外层列、内层行](images/excel_range_traverse_flow.svg)

1. **解析**：直接按下标取 `s[0]`、`s[1]`、`s[3]`、`s[4]` 四个字符，无需切分字符串
2. **外层**：`col` 从 `s[0]` 枚举到 `s[3]`（字符可直接比较、自增）
3. **内层**：`row` 从 `s[1]` 枚举到 `s[4]`
4. **拼接**：把每个 `(col, row)` 拼成长度 2 的字符串追加进答案

### 3.4 示例演算

![示例演算：K1:L2 的列优先枚举](images/excel_range_walkthrough.svg)

以 `s = "K1:L2"` 为例：`c1='K'`、`r1='1'`、`c2='L'`、`r2='2'`。

| 步骤 | col | row | 追加 | ans |
|------|-----|-----|------|-----|
| ① | K | 1 | "K1" | ["K1"] |
| ② | K | 2 | "K2" | ["K1","K2"] |
| ③ | L | 1 | "L1" | ["K1","K2","L1"] |
| ④ | L | 2 | "L2" | ["K1","K2","L1","L2"] |

列 K 扫完行 1..2 后**换列并回到首行**，正好体现外层列、内层行的嵌套关系。

## 4. 算法细节

1. **下标解析**：`s.length == 5` 且格式固定，`s[2]` 恒为 `':'`，直接按下标取数即可，不必 `split`
2. **字符即数值**：大写字母与数字字符的编码都是连续的，`'A'..'Z'`、`'1'..'9'` 可以直接用 `<=` 比较、用 `++` 自增，**全程无需转整数**
3. **顺序不能反**：必须**外层列、内层行**；若外层行、内层列，得到的是行优先序（`"K1","L1","K2","L2"`），不符合题目要求
4. **字符串拼接**：C++ 用 `push_back({col, row})`（花括号初始化列表直接构造 2 字符的 `string`）或 `string(1, col) + row`；Python 用 `chr(col) + str(row)` 直接拼接

## 5. 正确性证明

**引理 1（有序性）**：外层列 `c` 从 $c_1$ 递增到 $c_2$、内层行 `r` 从 $r_1$ 递增到 $r_2$ 的双重循环，其输出序列按二元组 `(col, row)` 的字典序非递减。

**证明**：任取输出中第 $i$ 个与第 $j$ 个元素（$i < j$）。若二者在同一次外层迭代中产生，则列相同，且第 $i$ 个的行先于第 $j$ 个产生，行分量满足 $r_i \leq r_j$；若在不同外层迭代中产生，则第 $i$ 个所在列满足 $c_i < c_j$。两种情况均有 $(c_i, r_i)$ 字典序不大于 $(c_j, r_j)$，即序列非递减。∎

**定理（完备性与不重复）**：输出恰好包含所有满足 $c_1 \leq c \leq c_2$、$r_1 \leq r \leq r_2$ 的单元格，且每个只出现一次。

**证明**：双重循环遍历的是笛卡尔积 $[c_1, c_2] \times [r_1, r_2]$：对每个二元组 $(c, r)$，「外层取定 $c$、内层取定 $r$」的组合方式唯一，故恰好访问一次，共 $(c_2 - c_1 + 1)(r_2 - r_1 + 1)$ 个，与目标集合一一对应。结合引理 1，输出即题目要求的完整有序列表。∎

## 6. 复杂度分析

- **时间复杂度**：$O\big((c_2 - c_1 + 1)(r_2 - r_1 + 1)\big) \leq 26 \times 9 = 234$，即 $O(1)$。每个单元格恰好生成一次，没有任何冗余。
- **空间复杂度**：$O(1)$（不计输出本身）。输出至多 234 个长度为 2 的字符串。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<string> cellsInRange(string s) {
        vector<string> ans;
        for (char col = s[0]; col <= s[3]; ++col)
            for (char row = s[1]; row <= s[4]; ++row)
                ans.push_back({col, row});
        return ans;
    }
};
```

### Python

```python
class Solution:
    def cellsInRange(self, s: str) -> List[str]:
        return [chr(col) + str(row)
                for col in range(ord(s[0]), ord(s[3]) + 1)
                for row in range(int(s[1]), int(s[4]) + 1)]
```

## 8. 边界情况与易错点

1. **单格区间** `"A1:A1"`：两个循环都只执行一次，输出 `["A1"]`，无需特判
2. **循环顺序写反**：外层行、内层列会得到行优先序，WA；必须外层列、内层行
3. **行号转换基准**：若把行字符转整数，用 `s[i] - '1'`（0 起始）或 `int(s[i])`，别和 `'0'` 的基准错位——本题直接在字符域循环，可以完全绕开这一步
4. **无需处理反向区间**：题目保证 $r_1 \leq r_2$、$c_1 \leq c_2$；若变体不保证，需先用 `min/max` 归一化
5. **输出格式**：是字符串列表（`"K1"`）而不是坐标对，且列在前、行在后，拼接时别写反
