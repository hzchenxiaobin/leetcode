# LeetCode 最长乘积等价子数组 题解

## 1. 题目概述

- **标题 / 题号**：最长乘积等价子数组（#3411，easy）
- **链接**：https://leetcode.cn/problems/maximum-subarray-with-equal-products/
- **来源**：LeetCode 第 431 场周赛 Q1
- **难度**：简单
- **标签**：数组、数学、数论、枚举、滑动窗口

**题意**：给定正整数数组 `nums`。若子数组 `arr` 满足 `prod(arr) == lcm(arr) * gcd(arr)`（所有元素乘积 = 最小公倍数 × 最大公约数），则称其为**乘积等价子数组**。返回 `nums` 中最长乘积等价**子数组**（连续）的长度。

**约束**：

- `2 <= nums.length <= 100`
- `1 <= nums[i] <= 10`

> 💡 签到题但藏着漂亮的数论结构：**任意两个数都满足 $ab = \gcd(a,b)\cdot\mathrm{lcm}(a,b)$**，所以长度为 2 的子数组**全部**有效；而长度 $\ge 3$ 时等价条件恰好退化为**两两互素**。问题由此变成「最长无重复**素数**滑窗」——LC 3 的翻版。

## 2. 示例

**示例 1**

```text
输入：nums = [1,2,1,2,1,1,1]
输出：5
解释：最长的是 [1,2,1,1,1]：prod = 2，gcd = 1，lcm = 2，2 = 1×2 ✓。
     整个数组不行：两个 2 共享素数 2。
```

**示例 2**

```text
输入：nums = [2,3,4,5,6]
输出：3
解释：最长的是 [3,4,5]（两两互素）。注意 [2,3,4] 不行：
     prod = 24，gcd = 1，lcm = 12，24 ≠ 12（2 与 4 共享素数 2）。
```

**示例 3**

```text
输入：nums = [1,2,3,1,4,5,1]
输出：5
解释：[2,3,1,4,5] 中 2 与 4 不互素；最长窗口是 [3,1,4,5,1]。
```

## 3. 解题思路

### 3.1 暴力思路

枚举全部 $O(n^2)$ 个子数组，对每个子数组 $O(n)$ 地滚动维护 `prod / gcd / lcm`，直接验证定义，总计 $O(n^3)$。$n \le 100$ 时约 $10^6$ 次运算，时间上完全够用（Python 大整数可直接算）。

但有两个问题：

- **C++ 溢出**：`prod` 最大 $10^{100}$，远超 `long long`（约 $9.2\times10^{18}$），直接硬乘必炸。
- **没有沉淀**：完全没用上 $nums[i] \le 10$ 这一关键条件，也没提炼出结构。

### 3.2 核心观察：素因子指数视角

![素因子指数视角](images/equal_products_concept.svg)

把 `prod == lcm * gcd` **逐素数**拆开比较。设子数组长度为 $n$，素数 $p$ 在各元素中的指数为 $e_1, \dots, e_n \ge 0$（0 表示该元素不被 $p$ 整除），则三个量在 $p$ 上的指数分别为：

- `prod`：$\sum_i e_i$（求和）
- `lcm`：$\max_i e_i$（取最大）
- `gcd`：$\min_i e_i$（取最小）

于是 `prod == lcm * gcd` $\iff$ 对**每个**素数 $p$ 都有 $\sum_i e_i = \max_i e_i + \min_i e_i$。设 $k$ 为正指数的个数（即被 $p$ 整除的元素个数），分类讨论：

| 情形 | 等式是否成立 | 原因 |
|------|--------------|------|
| $k = 0$ | 成立 | $0 = 0 + 0$ |
| $k = 1$，$n \ge 2$ | 成立 | $\sum = \max$，$\min = 0$ |
| $k = 1$，$n = 1$ | 仅 $x = 1$ 成立 | $x = x \cdot x \iff x = 1$ |
| $k \ge 2$，$n = 2$ | **恒成立** | $e_1 + e_2 = \max + \min$（二元恒等式） |
| $k \ge 2$，$n \ge 3$ | **不成立** | 扣掉一个 $\max$、一个 $\min$ 后仍有正指数剩下，$\sum > \max + \min$ |

把所有素数的结论合并，得到本题主定理：

- **任何长度为 2 的子数组都乘积等价**（经典恒等式 $ab = \gcd(a,b)\cdot\mathrm{lcm}(a,b)$），故答案 $\ge 2$；
- **长度 $\ge 3$ 的子数组乘积等价 $\iff$ 元素两两互素**（每个素数至多除尽一个元素）；
- 长度 1 仅 `[1]` 有效，被下界 2 覆盖，无需特判。

$$\text{答案} = \max(2,\ \text{最长两两互素子数组的长度})$$

再用上 $nums[i] \le 10$：涉及的全部素数只有 $\{2, 3, 5, 7\}$。「两两互素」等价于「窗口内每种素数至多被一个元素占用」——把 LC 3 无重复字符最长子串里的**字符**换成**素数**，一模一样的滑动窗口。

> ⚠️ 反例直觉：`[2, 3, 4]` 看起来「只多了一个 4」，但 2 与 4 共享素数 2，`prod = 24` 而 `lcm × gcd = 12`，直接失效。共享**同一个素数**才是致命的，与数值大小无关。

### 3.3 算法流程：素数占用滑窗

![素数占用滑动窗口流程](images/equal_products_sliding_window.svg)

把每个元素映射为 4 位素数掩码 `mask(x)`（第 $k$ 位 = 是否被第 $k$ 个素数整除，如 `mask(6) = 0101₂`，`mask(1) = 0000₂`），窗口维护已占用素数集合 `win`（窗口内所有掩码的按位或）：

1. 初始化 `ans = 2`（长度 2 恒有效），`left = 0`，`win = 0`。
2. 枚举右端 `right`，计算 `mx = mask(nums[right])`。
3. **冲突判定**：`win & mx != 0` 说明新元素与窗口共享素数 → 循环移出 `nums[left]`（`win &= ~mask(nums[left])`，`left++`），直到无共享。
4. `win |= mx`，更新 `ans = max(ans, right - left + 1)`。

**窗口不变量**：任意时刻 `[left, right]` 内元素两两互素。由于「两两互素」是遗传性质（子区间仍两两互素），双指针收缩不漏解。

### 3.4 示例演算

![示例 1 滑窗演算](images/equal_products_example_walkthrough.svg)

以示例 1 `nums = [1,2,1,2,1,1,1]` 为例（1 的素数集为 $\varnothing$，2 的素数集为 $\{2\}$）：

| r | x | 冲突？ | 窗口（下标） | 内容 | 长度 |
|---|---|--------|--------------|------|------|
| 0 | 1 | — | [0, 0] | [1] | 1 |
| 1 | 2 | 否（win = ∅） | [0, 1] | [1,2] | 2 |
| 2 | 1 | 否 | [0, 2] | [1,2,1] | 3 |
| 3 | 2 | 素数 2 已占用 | [2, 3] | [1,2] | 2 |
| 4 | 1 | 否 | [2, 4] | [1,2,1] | 3 |
| 5 | 1 | 否 | [2, 5] | [1,2,1,1] | 4 |
| 6 | 1 | 否 | [2, 6] | [1,2,1,1,1] | 5 |

最终窗口 `[1,2,1,1,1]`：$\mathrm{prod} = 2$、$\gcd = 1$、$\mathrm{lcm} = 2$，$2 = 1 \times 2$ ✓，答案 **5**。

## 4. 算法细节

1. **掩码设计**：`nums[i] ≤ 10` → 素数固定为 `{2, 3, 5, 7}`，`mask(x)` 用 4 次取余求得，$O(1)$。复合数占多位：$6 = 2\times3$、$10 = 2\times5$。
2. **窗口状态 `win`**：窗口内所有元素掩码的按位或。两两互素 $\iff$ `win` 的每个 1 位只由一个元素贡献。
3. **冲突判定**：`win & mx != 0` 即新元素与窗口共享素数。注意判定的是**素数集合相交**，不是数值相等。
4. **收缩循环是 `while` 不是 `if`**：一个新元素（如 6）可能与窗口中的多个素数同时冲突，需要连续移出多个左端元素。
5. **`mask(1) = 0`**：1 没有素因子，永不引发冲突；收缩时移出 1 不改变 `win`，但 `left` 必须照常前进。
6. **答案下界**：初始化 `ans = 2`。约束 $n \ge 2$ 保证长度 2 的子数组总存在，而引理 1 保证它必然有效。

## 5. 正确性证明

**引理 1（二元恒等式）**：对任意正整数 $a, b$，$ab = \gcd(a,b) \cdot \mathrm{lcm}(a,b)$。

**证明**：对任意素数 $p$，设 $p$ 在 $a, b$ 中的指数为 $e_1 \le e_2$。等式左边 $p$ 的指数为 $e_1 + e_2$；右边 $\gcd$ 取 $\min = e_1$，$\mathrm{lcm}$ 取 $\max = e_2$，指数同样为 $e_1 + e_2$。每个素数上指数都相等，故两数相等。∎

**引理 2（长度 $\ge 3$ 的刻画）**：长度 $n \ge 3$ 的子数组乘积等价 $\iff$ 其元素两两互素。

**证明**：如 §3.2 所述，乘积等价 $\iff$ 对每个素数 $p$，指数满足 $\sum_i e_i = \max_i e_i + \min_i e_i$。将该等式改写为

$$\sum_i e_i - \max_i e_i - \min_i e_i = 0,$$

左边恰是「扣除一个取最大值的元素、一个取最小值的元素之后，剩余 $n-2$ 个元素的指数之和」，恒非负。

（$\Leftarrow$）两两互素时，每个素数 $p$ 至多除尽一个元素：$k = 0$ 时 $0 = 0$；$k = 1$ 时 $\sum = \max$ 且 $\min = 0$（$n \ge 2$）。等式对所有素数成立。∎

（$\Rightarrow$）反证：设 $a_i, a_j$（$i \ne j$）共享素数 $p$，即 $p$ 的正指数个数 $k \ge 2$。将指数升序排列为 $e_{(1)} \le \cdots \le e_{(n)}$。

- 若 $\min > 0$（所有元素都被 $p$ 整除）：扣除 $e_{(1)}$ 与 $e_{(n)}$ 后，剩余 $n - 2 \ge 1$ 个指数均 $\ge e_{(1)} > 0$，左边 $> 0$；
- 若 $\min = 0$：$k \ge 2$ 个正指数在升序排列中占据最靠右的位置，最大者是 $e_{(n)}$；另一个正指数位于排序位置 $\le n - 1$，又因 $e_{(1)} = 0$ 它的位置 $\ge 2$，故必然落在剩余项 $e_{(2)}, \dots, e_{(n-1)}$ 中（$n \ge 3$ 保证非空），左边 $> 0$。

两种情况都与等式矛盾，故两两互素。∎

**引理 3（滑窗不变量）**：每轮循环结束时，`[left, right]` 两两互素，且 `left` 是使 `[left, right]` 两两互素的最小左端点。

**证明**：归纳。初始空窗口成立。设加入 `nums[right]` 前不变量对 `[left, right-1]` 成立。收缩循环仅在 `win & mx != 0` 时执行，且每步从 `win` 中精确移除 `nums[left]` 的素数贡献；循环终止时 `win & mx == 0`，即新元素与窗口内所有元素无共享素数，加上新元素后窗口仍两两互素。又因两两互素是遗传性质（更大的 `left` 只会去掉元素），若存在更小的可行左端点，它对应的窗口是当前窗口的超集且两两互素，则当前 `win` 中不应含有与新元素冲突的素数——与循环已终止矛盾，故 `left` 最小。∎

**定理**：算法返回 `max(2, L)`，其中 `L` 为最长两两互素子数组长度，即所求答案。

**证明**：由引理 1，长度 2 的子数组恒乘积等价，且约束 $n \ge 2$，故答案 $\ge 2$。长度 1 仅 `[1]` 有效，不优于 2。长度 $\ge 3$ 的乘积等价子数组由引理 2 恰为两两互素子数组。故答案 $= \max(2, L)$。由引理 3，滑窗对每个 `right` 求得以其为右端点的最长两两互素窗口，遍历所有右端点即得 $L$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$（均摊）。`left` 全程只前进不后退，每个元素至多进出窗口各一次；`mask` 为 $O(4)$ 常数。
- **空间复杂度**：$O(1)$。仅 `win / mx / left / ans` 等常数个变量（4 位掩码）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maxLength(vector<int>& nums) {
        auto mask = [](int x) {
            int m = 0, p[4] = {2, 3, 5, 7};
            for (int k = 0; k < 4; k++)
                if (x % p[k] == 0) m |= 1 << k;
            return m;
        };
        int ans = 2, left = 0, win = 0;
        for (int right = 0; right < (int)nums.size(); right++) {
            int mx = mask(nums[right]);
            while (win & mx) win &= ~mask(nums[left++]);
            win |= mx;
            ans = max(ans, right - left + 1);
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maxLength(self, nums: List[int]) -> int:
        def mask(x: int) -> int:
            m = 0
            for k, p in enumerate((2, 3, 5, 7)):
                if x % p == 0:
                    m |= 1 << k
            return m

        ans, left, win = 2, 0, 0
        for right, x in enumerate(nums):
            mx = mask(x)
            while win & mx:
                win &= ~mask(nums[left])
                left += 1
            win |= mx
            ans = max(ans, right - left + 1)
        return ans
```

## 8. 边界情况与易错点

1. **忘记答案下界 2**：最典型的错误。如 `nums = [6, 6]` 全数组两两不互素，若只跑滑窗会输出 1；但由引理 1，`[6, 6]` 有 $\mathrm{prod} = 36 = 6 \times 6 = \gcd \times \mathrm{lcm}$，正确答案是 2。初始化 `ans = 2` 即可。
2. **C++ 直接维护乘积溢出**：$10^{100}$ 级别，`long long` / `unsigned long long` 都装不下，必须走互素判定而非乘积比较。
3. **长度 1 的误区**：`[2]` 不等价（$2 \ne 2\times2$），`[1]` 等价；均被下界 2 覆盖，无需分支处理。
4. **收缩用 `if` 而非 `while`**：新元素可能同时冲突窗口内多个素数（例如窗口含 2 和 3，新来一个 6）。
5. **`mask(1) = 0` 的收缩**：移出 1 时 `win` 不变，但 `left` 仍需前进，不要在收缩循环里跳过 1。
6. **冲突判定按位与**：`win & mx` 检查的是共享素数；两元素数值不同（如 2 与 4）同样冲突。
