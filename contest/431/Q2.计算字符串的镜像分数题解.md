# LeetCode 计算字符串的镜像分数 题解

## 1. 题目概述

- **标题 / 题号**：计算字符串的镜像分数（#3412，medium）
- **链接**：https://leetcode.cn/problems/find-mirror-score-of-a-string/
- **来源**：LeetCode 第 431 场周赛 Q2
- **难度**：中等
- **标签**：栈、哈希表、字符串、模拟

**题意**：字母 $c$ 的**镜像** $\mathrm{mirror}(c)$ 定义为反转字母表后对应位置上的字母（'a'↔'z'、'y'↔'b'）。初始时 $s$ 的所有下标未标记、分数为 0。从左到右遍历 $s$：对每个下标 $i$，寻找**距离最近**（即最大）的未标记下标 $j < i$ 且 $s[j] = \mathrm{mirror}(s[i])$；若存在则标记 $i$ 和 $j$，总分加上 $i - j$；否则跳过（$i$ 保持未标记）。返回最终总分。

**约束**：

- $1 \le s.length \le 10^5$
- $s$ 仅由小写英文字母组成

> 💡 读题关键：过程是**确定性**的——「距离最近的 $j$」若存在则唯一，没有任何决策自由度。所以这不是贪心/DP 选择题，而是纯**模拟题**；唯一考点是把「回跳扫描找最近的未标记匹配」优化到均摊 $O(1)$。

## 2. 示例

**示例 1**

```text
输入：s = "aczzx"
输出：5
解释：i=2 的 'z' 找到 j=0 的 'a'，得 2−0 = 2；
     i=4 的 'x' 找到 j=1 的 'c'，得 4−1 = 3。总分 5。
```

**示例 2**

```text
输入：s = "abcdef"
输出：0
解释：任何字母的镜像都不在串中出现，一次配对也没有。
```

**示例 3**

```text
输入：s = "yabz"
输出：4
解释：i=2 的 'b' 找 'y'：最近的未标记 'y' 是 j=0（中间的 a1 未标记但字母不对），得 2；
     i=3 的 'z' 找 'a'：j=1，得 2。总分 4。
     注意：配对中间可以隔着其他未标记字母——这正是「单栈括号匹配」的死穴（见 §3.3）。
```

## 3. 解题思路

### 3.1 暴力思路

对每个下标 $i$，从 $i-1$ 向 $0$ 回扫，跳过已标记以及字母不等于 $\mathrm{mirror}(s[i])$ 的下标，遇到的第一个合法者即为 $j$。最坏情况（例如 $s$ 全是 'a'，永远等不到 'z'）每个 $i$ 都要扫完整个前缀，总耗时 $\Theta(n^2) \approx 10^{10}$（$n = 10^5$），必然超时。

瓶颈在于：**重复地跳过「已标记」和「字母不对」的下标**。前者一旦标记就是死信息，后者与当前字母无关——两者都可以交给数据结构吸收。

### 3.2 核心观察：13 对固定镜像 + 按字母分栈

![镜像配对概念](images/mirror_pairs_alphabet.svg)

两个结构性观察：

1. **镜像是固定配对**：$\mathrm{mirror}(c)$ 的下标是 $25 - \mathrm{idx}(c)$，它是**对合**（$\mathrm{mirror}(\mathrm{mirror}(c)) = c$），且 $97 + 122 = 219$ 是奇数，没有字母是自己的镜像。于是 26 个字母被划分成 **13 个互不相交的配对**，匹配只会发生在同一对内部，与其他 24 个字母完全无关。
2. **「最近的未标记 $j$」= 某个栈的栈顶**：从左到右遍历时，把每个被跳过的下标压入**它自己字母的栈**；发生配对时 $j$ 从栈中弹出（即标记）。由于压入顺序与遍历顺序一致，每个栈内部下标自底向上**严格递增**，于是栈顶就是该字母**最大的未标记下标**，恰好是题目要的「距离 $i$ 最近」。

两者结合，得到均摊 $O(1)$ 的逐字符模拟：为 26 个字母各建一个栈。

### 3.3 算法流程

![26栈算法模型](images/mirror_score_stack_model.svg)

1. 建立 26 个栈 `st[0..25]`，`st[c]` 存放字母 $c$ 的未标记下标。
2. 遍历 $i = 0 \dots n-1$：设 $c = s[i] - \text{'a'}$，$m = 25 - c$（镜像字母的下标）。
3. 若 `st[m]` 非空：弹出栈顶 $j$，`ans += i - j`（$i$ 与 $j$ 同时标记，均不入栈）。
4. 否则：把 $i$ 压入 `st[c]`，等待未来某个 $\mathrm{mirror}(c)$ 字母来配对。

**为什么不能套「单栈括号匹配」**：不少选手的第一反应是 LC 20 那样的单栈——压入跳过的字符、栈顶能配对则弹出。但单栈只能看见「**最近的未标记下标**（不分字母）」，而题目要「**字母恰好是镜像**的最近下标」，中间允许隔着别的未标记字母：

![单栈反例](images/mirror_single_stack_counterexample.svg)

反例 $s = \texttt{"yabz"}$：正确答案是 4（`y₀↔b₂`、`a₁↔z₃`），而单栈在 $i=2$ 时栈顶是 `a1` 不是 `'y'`，只能把 `b2` 也压栈——`y0` 从此被「挡住」，最终得分 0。

> ⚠️ 单栈的一个**正确**变体是「从栈顶向下找到第一个可配对字母并**从中间删除**」（每个字母的相对顺序不变，效果等价于 26 个栈），但单次操作最坏 $O(n)$，总复杂度退化为 $O(n^2)$。26 个栈正是这个想法「按字母分桶」后的优化。

### 3.4 示例演算

![示例演算](images/mirror_score_walkthrough.svg)

以示例 1 `s = "aczzx"` 为例（下表只列出每步涉及的栈）：

| i | s[i] | 查看 mirror 栈 | 动作 | 得分 | 累计 |
|---|------|---------------|------|------|------|
| 0 | a | st['z'] = 空 | 0 压入 st['a'] | — | 0 |
| 1 | c | st['x'] = 空 | 1 压入 st['c'] | — | 0 |
| 2 | z | st['a'] = [0] | 弹出 0，标记 0 与 2 | +2 | 2 |
| 3 | z | st['a'] = 空 | 3 压入 st['z'] | — | 2 |
| 4 | x | st['c'] = [1] | 弹出 1，标记 1 与 4 | +3 | 5 |

总分 $= (2-0) + (4-1) = 5$ ✓。未被配对的下标（如 3 号 'z'）留在栈里，不贡献分数。

## 4. 算法细节

1. **镜像公式**：字符层面 $\mathrm{mirror}(c) = \mathrm{chr}(\text{'a'} + \text{'z'} - c)$；下标层面 $m = 25 - (c - \text{'a'})$。推荐用后者，直接当数组下标访问。
2. **数据结构**：`vector<vector<int>> st(26)`（C++）或 26 个列表（Python）；等价地可用哈希表「字母 → 栈」，这就是标签里 Hash Table 的含义。
3. **方向别搞反**：跳过时压入的是 `st[c]`（**自己**字母的栈）；匹配查询的是 `st[m]`（**镜像**字母的栈）；匹配成功后 $i$ **不**入任何栈。
4. **均摊分析**：每个下标至多被压入一次、弹出一次，单字符处理均摊 $O(1)$，总计 $O(n + 26)$。
5. **得分规模**：最坏约 $n^2/4 = 2.5 \times 10^9$（构造：前一半全 'a'、后一半全 'z'，每个 'z' 与越来越远的 'a' 配对），超过 `int32` 上限 $2\,147\,483\,647$。C++ 必须用 `long long`（本题接口返回类型就是 `long long`）；Python 天然大整数无碍。

## 5. 正确性证明

**引理 1（对合与配对分解）**：对任意字母 $c$，$\mathrm{mirror}(\mathrm{mirror}(c)) = c$；不存在 $c$ 使 $\mathrm{mirror}(c) = c$；26 个字母恰好划分成 13 对 $\{c, \mathrm{mirror}(c)\}$。

**证明**：写下标形式 $\mathrm{mirror}(x) = 25 - x$（$x \in [0, 25]$）。复合得 $25 - (25 - x) = x$。自镜像要求 $x = 25 - x$ 即 $2x = 25$，无整数解（对应 $\text{'a'} + \text{'z'} = 219$ 为奇数）。于是映射 $x \mapsto 25 - x$ 是无不动点的对合，其轨道恰为 13 个二元配对，互斥且覆盖全部 26 个字母。∎

**引理 2（栈不变量）**：处理完下标 $i$ 后，对每个字母 $c$，`st[c]` 中恰为所有满足 $j \le i$、$s[j] = c$ 且 $j$ 未标记的下标，且自底向上严格递增。

**证明**：对 $i$ 归纳。$i = -1$ 时全部为空栈，成立。设处理 $i$ 前结论对 $i-1$ 成立，考察处理 $s[i] = c$ 的两种情形：

- **匹配**（`st[m]` 非空，$m = 25 - c$）：弹出 $j$ 并标记 $i, j$。$i$ 从未进入任何栈；$j$ 恰从 `st[m]` 移出；其余栈未动。仍开着的栈依旧对应各自的未标记集合，递增性不变。
- **跳过**（`st[m]` 空）：$i$ 未标记，压入 `st[c]` 栈顶。由归纳假设 `st[c]` 原栈顶（若存在）$< i$，压入后仍递增；其余栈不动。

两种情形下不变量均保持。∎

**引理 3（栈顶即最近）**：处理 $s[i] = c$ 的时刻，存在未标记的 $j < i$ 且 $s[j] = \mathrm{mirror}(c)$，当且仅当 `st[m]` 非空（$m = 25 - c$）；且非空时栈顶是所有这样的 $j$ 中的最大者，即离 $i$ 最近的一个。

**证明**：由引理 2（应用于 $i-1$），`st[m]` 恰为集合 $\{\, j \le i-1 :\ s[j] = \mathrm{mirror}(c),\ j \text{ 未标记} \,\}$ 且自底向上递增。栈非空当且仅当集合非空；递增序列的最大元素即栈顶。∎

**定理**：算法的输出等于题目定义的总分。

**证明**：题目规定的过程对每个 $i$ 是确定的：若存在最近的未标记镜像下标则配对、标记并累加 $i - j$，否则跳过。由引理 3，算法每一步查询到的栈顶 $j$ 与题目要求的「最近的未标记 $j$」完全一致；由引理 2，「标记」恰好对应「弹出后永不再出现」，算法维护的未标记集合与题目过程同步。对 $i$ 归纳：每一步的配对对象、标记集合、累加分值均与题目过程相同，故总分相等。∎

> 💡 由于「选最近的 $j$」是题目**规定**的规则而非可选策略，无需（也不应）讨论「选最近是否最优」之类的交换论证——这是模拟题，不是贪心题。

## 6. 复杂度分析

- **时间复杂度**：$O(n + 26)$。每个下标至多一次入栈、至多一次出栈；每字符的判定与累加均为 $O(1)$。
- **空间复杂度**：$O(n)$。最坏时所有下标都未配对（如任何镜像对都不齐全的串），26 个栈共存放至多 $n$ 个下标；栈本身 $O(26)$ 个。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long calculateScore(string s) {
        vector<vector<int>> st(26);
        long long ans = 0;
        for (int i = 0; i < (int)s.size(); i++) {
            int c = s[i] - 'a', m = 25 - c;
            if (!st[m].empty()) {
                ans += i - st[m].back();
                st[m].pop_back();
            } else {
                st[c].push_back(i);
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def calculateScore(self, s: str) -> int:
        st = [[] for _ in range(26)]
        ans = 0
        for i, ch in enumerate(s):
            c = ord(ch) - ord('a')
            m = 25 - c
            if st[m]:
                ans += i - st[m].pop()
            else:
                st[c].append(i)
        return ans
```

## 8. 边界情况与易错点

1. **总分溢出 int32**：最坏 $\approx n^2/4 = 2.5 \times 10^9$（前半全 'a'、后半全 'z' 的构造）。C++ 必须用 `long long`，本题接口返回类型本身就是 `long long`。
2. **套单栈括号匹配**：最典型的错解。反例 `"yabz"` 正确答案 4，单栈得 0——配对中间隔着其他未标记字母时，栈顶不是需要的字母。
3. **镜像公式差一**：混用 `25 - c`（字符直减）与 `'z' - c + 'a'`。自测用例：'a'↔'z'、'm'↔'n'、'y'↔'b'。
4. **压栈方向搞反**：跳过时压入 `st[c]`（自己），不是 `st[m]`；匹配成功后 $i$ 不入栈。
5. **「距离最近」的含义**：是 $j$ 最大（离 $i$ 最近），不是最早出现的 $j$。栈顶天然满足，无需额外比较。
6. **极端串**：全同字母、无任何完整镜像对、$n = 1$，均输出 0，算法自然处理，无需特判。
