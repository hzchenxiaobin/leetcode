# LeetCode 使数组所有元素变成 1 的最少操作次数 题解

## 1. 题目概述

- **标题 / 题号**：使数组所有元素变成 1 的最少操作次数（#2654，medium）
- **链接**：https://leetcode.cn/problems/minimum-number-of-operations-to-make-all-array-elements-equal-to-1/
- **来源**：LeetCode 第 342 场周赛 Q4
- **难度**：中等
- **标签**：数组、数学、最大公约数、数论、欧几里得算法

**题意**：给定下标从 0 开始、长度为 $n$ 的正整数数组 `nums`，可以执行任意次操作：选择下标 $i$（$0 \le i < n-1$），把 `nums[i]` 与 `nums[i+1]` **二者之一**替换成它们的最大公约数 $\gcd(\text{nums}[i],\ \text{nums}[i{+}1])$。求让**所有**元素都等于 $1$ 的最少操作次数；若无法做到返回 $-1$。

**约束**：

- $2 \le n \le 50$
- $1 \le \text{nums}[i] \le 10^6$

> 💡 周赛压轴题却只标「中等」：难不在实现，而在**想到分类 + 证明公式**。另外 $n \le 50$ 小得反常——这是「结论题」的典型信号：正解是一个 $O(n^2)$ 级别的枚举 + 公式，而不是模拟或搜索。

## 2. 示例

**示例 1**

```text
输入：nums = [2,6,3,4]
输出：4
解释：i=2：nums[2] ← gcd(3,4)=1 → [2,6,1,4]
      i=1：nums[1] ← gcd(6,1)=1 → [2,1,1,4]
      i=0：nums[0] ← gcd(2,1)=1 → [1,1,1,4]
      i=2：nums[3] ← gcd(1,4)=1 → [1,1,1,1]
```

**示例 2**

```text
输入：nums = [2,10,6,14]
输出：-1
解释：全是偶数，任何时刻任何值都被公因子 2 整除，永远变不出 1。
```

**示例 3（初始已有 1，直接短路）**

```text
输入：nums = [2,1,3,7]
输出：3
解释：n=4，已有 k=1 个 1 → 答案 = n−k = 3：
      gcd(2,1)=1、gcd(3,7)=1、gcd(1,7)=1，恰好三次「传染」。
```

## 3. 解题思路

### 3.1 暴力思路

最朴素的做法是把**数组状态**当搜索节点做 BFS：每个状态有 $2(n-1)$ 个后继（每个 $i$ 有替换左 / 右两种选择），由于 $\gcd \le \min$，值只减不增，搜索有限。但状态数是各位置取值的笛卡尔积，$n=50$、值域 $10^6$ 时是天文数字。比赛现场更致命的是心态：这种「操作次数最小化」问题一旦开始硬搜，基本就与 AK 无缘了——**先想清楚一次操作到底改变了什么，公式自然浮出水面**。

> 💡 本文用上述 BFS 在 $n \le 6$、小值域的全部随机数据上验证过下述公式，完全一致——暴力不是用来提交的，是用来给公式兜底的。

### 3.2 核心观察：支撑区间 + 两阶段公式

![支撑区间不变量：一次操作 = 相邻两个区间求 gcd 后合并](images/wc342_q4_interval_merge_invariant.svg)

**观察 1（支撑区间不变量）**：任何时刻，每个位置上的值都等于原数组中**某段包含该位置的连续区间**的 gcd。操作的本质是：把两个相邻的「支撑区间」合并成它们的并（仍是连续区间），值取并集的 gcd。于是

$$\text{某位置出现 } 1 \iff \text{存在一段 gcd 为 1 的连续子数组被浓缩到该位置}$$

**观察 2（有 1 就赢了）**：若已有 $k \ge 1$ 个 1，则答案就是 $n - k$。因为 $\gcd(1, x) = 1$，一次操作就能把 1「传染」给相邻元素；而每次操作只替换一个位置，1 的个数每步至多加一（引理 1），所以 $n-k$ 次不多不少。

**观察 3（无 1 时先造第一个 1）**：设 $L$ = gcd 恰为 $1$ 的**最短**连续子数组的长度。把这段从左到右「滚动求 gcd」只需 $L-1$ 次操作就能在段右端得到一个 1；之后再用 $n-1$ 次把 1 传染到全数组。合计

$$\text{答案} = (L-1) + (n-1) = n + L - 2$$

**观察 4（无解判定）**：若整个数组的 gcd $> 1$，则公因子 $d$ 整除每个原始值，从而整除此后任何位置的任何值，永远出不来 1，返回 $-1$。反之整体 gcd $=1$ 时整个数组本身就是一段合法窗口，$L$ 必然存在。

### 3.3 算法流程

![三种情况的决策流程与公式](images/wc342_q4_case_flow.svg)

```text
1. 统计 1 的个数 k：若 k ≥ 1，返回 n − k          （观察 2）
2. 求整个数组的 gcd：若 > 1，返回 −1               （观察 4）
3. 枚举最短 gcd=1 连续子数组，记长度 L             （观察 1、3）
4. 返回 (L − 1) + (n − 1)
```

### 3.4 示例演算

![示例 1 走查：造第一个 1，再把 1 传染到全数组](images/wc342_q4_walkthrough.svg)

以示例 1（`nums = [2,6,3,4]`）走查：无 1；整体 gcd = 1 可解；枚举发现窗口 $[3,4]$ 的 $\gcd = 1$ 且最短，$L=2$。

| 阶段 | 操作 | 数组变化 | 累计次数 |
|------|------|----------|----------|
| 一：造第一个 1 | $i{=}2$：`nums[2]` ← $\gcd(3,4)=1$ | $[2,6,\mathbf{1},4]$ | $L-1 = 1$ |
| 二：传染 | $i{=}1$：`nums[1]` ← $\gcd(6,1)=1$ | $[2,\mathbf{1},1,4]$ | 2 |
| 二：传染 | $i{=}0$：`nums[0]` ← $\gcd(2,1)=1$ | $[\mathbf{1},1,1,4]$ | 3 |
| 二：传染 | $i{=}2$：`nums[3]` ← $\gcd(1,4)=1$ | $[1,1,1,\mathbf{1}]$ | $n-1 = 3 \Rightarrow$ 共 4 |

## 4. 算法细节

1. **求最短窗口**：枚举左端点 $i$，$g$ 从 $0$ 起向右滚动 $g \leftarrow \gcd(g,\ \text{nums}[j])$，一旦 $g = 1$ 记录长度 $j - i + 1$ 并 `break`。正确性：固定左端点时区间 gcd 随右端点扩大**单调不增**，首次为 1 的位置就是该左端点的最短窗口，再扩只会更长。
2. **三个判定的顺序**：$k \ge 1$ 的短路**必须**在求 $L$ 之前（否则会算错，见 §8 第 1 条）；整体 gcd 的无解判定放在求 $L$ 之前可以少做一次无效枚举。
3. **造第一个 1 选哪段窗口无所谓位置**：阶段二的代价恒为 $n-1$——1 在链上可双向传染，无论第一个 1 诞生在哪，剩余 $n-1$ 个非 1 元素每个恰好花一次操作。因此只需最小化 $L-1$，选**最短**窗口即可。
4. **滚动造 1 的构造**：对窗口 $a_p, \ldots, a_{p+L-1}$，第 $s$ 次操作把 `nums[p+s]` 替换为「区间 $[p,\ p+s]$ 的 gcd」（归纳易证），$L-1$ 次后右端即为整段 gcd $= 1$。
5. **gcd 实现**：C++ 用 `__gcd` / `std::gcd`，Python 用 `math.gcd`，欧几里得算法单次 $O(\log V)$，$V = 10^6$。

## 5. 正确性证明

**引理 1（1 的个数单调不减，每步至多 +1）**：任何操作后，数组中 1 的个数不减少，且每次至多增加 1。

**证明**：操作只替换一个位置，故个数变化只能是 $-1, 0, +1$ 中取值。逐一检查：若被替换的旧值是 1，新值 $= \gcd(1, x) = 1$，个数不变；若旧值非 1，则替换后 1 的个数要么不变、要么恰好 $+1$（新值为 1）。故个数变化 $\in \{0, +1\}$。∎

**引理 2（支撑区间不变量）**：任何时刻，每个位置 $q$ 上的值等于原数组某段**包含 $q$** 的连续区间的 gcd。

**证明**：对操作次数归纳。初始时取单点区间 $[q, q]$。设位置 $i$、$i{+}1$ 的支撑区间分别为 $[a, b] \ni i$ 与 $[c, d] \ni i{+}1$。一次操作后新值 $= \gcd(\gcd_{[a,b]},\ \gcd_{[c,d]}) = $ 并集上的 gcd，而两段区间的并是连续区间：若 $b < c$，则由 $i \le b < c \le i{+}1$ 迫使 $b = i,\ c = i{+}1$，并集 $[a, d]$ 仍连续无缺口；否则两段本身搭接。且并集包含被替换的位置（$i$ 或 $i{+}1$）。∎

**引理 3（造出第一个 1 至少需要 $L-1$ 次操作）**：若初始没有 1，$L$ 为 gcd 为 1 的最短子数组长度，则第一个 1 出现前至少发生了 $L-1$ 次操作。

**证明**：设第 $t$ 次操作产生了第一个 1。追溯它的「家谱」：节点是各时刻的值（叶子是初始值，内部节点是操作的产物），第 $t$ 次操作的产物（根）由两个输入值合并而来，递归展开所有祖先，得到一个有向无环图（同一个值被多次使用时只是出度 $>1$，不重复计数）。

- **叶子数 $\ell \ge L$**：由引理 2，根的支撑区间 $[\alpha, \beta]$ 是连续区间且其原始 gcd $= 1$，故 $\beta - \alpha + 1 \ge L$；而根的支撑区间恰为所有叶子位置的并，叶子互不相同（每个位置至多贡献一个初始值），故 $\ell \ge \beta-\alpha+1 \ge L$。
- **内部节点数 $I \ge \ell - 1$**：每个内部节点对应一次操作，恰有 **2 条输入边**，故输入边共 $2I$ 条；除根外的 $\ell + I - 1$ 个节点都是某个操作的输入（家谱的定义），各贡献至少 1 条输出边。于是 $2I \ge \ell + I - 1$，即 $I \ge \ell - 1$。

这些操作互不相同且全部发生在前 $t$ 次之内，故 $t \ge I \ge \ell - 1 \ge L - 1$。∎

![引理 3 的家谱 DAG 计数](images/wc342_q4_lineage_dag.svg)

> 💡 引理 3 的计数骨架——「每次操作恰吃进两个值、合并成一个值，故 $k$ 个东西并成 1 个至少 $k-1$ 次合并」——是各类合并 / 归并 / 哈夫曼下界证明的通用武器，值得单独收藏。

**定理（答案公式）**：

1. 若数组中有 $k \ge 1$ 个 1，最少操作数 $= n - k$；
2. 否则若整个数组的 gcd $> 1$，无解，返回 $-1$；
3. 否则设 $L$ 为 gcd 为 1 的最短连续子数组长度，最少操作数 $= (L-1) + (n-1)$。

**证明**：

（2）一切值始终是若干原始值的 gcd（引理 2 的支撑区间），被公因子 $d > 1$ 整除，永远非 1，无解；反之整体 gcd $=1$ 时 $L$ 存在，转入（3）。

（1）**下界**：引理 1 保证每步 1 的个数至多 $+1$，从 $k$ 涨到 $n$ 至少需要 $n-k$ 步。**上界**：只要还有非 1 元素，1 的集合与非 1 的集合在这条链上必有相邻处 $(q, q{+}1)$，对其操作一次恰好多一个 1，共 $n-k$ 步。

（3）**下界**：设第 $t$ 次操作产生第一个 1，由引理 3 得 $t \ge L-1$；此刻全数组恰好有 1 个 1，由引理 1，其后还需至少 $n-1$ 步；总计 $\ge (L-1)+(n-1)$。**上界**：按 §4 第 4 条的滚动 gcd 构造花 $L-1$ 步造出第一个 1，再按（1）的传染构造花 $n-1$ 步。两界相等。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n^2 \log V)$，其中 $V = \max \text{nums}[i] \le 10^6$。三步判定 $O(n \log V)$；双重循环枚举最短窗口至多 $\binom{51}{2} \approx 1250$ 对 $(i, j)$，每对一次欧几里得 gcd。$n = 50$ 时约一两千次 gcd，瞬间完成。
- **空间复杂度**：$O(1)$，只用了常数个变量。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int minOperations(vector<int>& nums) {
        int n = nums.size();
        int k = count(nums.begin(), nums.end(), 1);
        if (k > 0) return n - k;                  // 观察 2：1 的传染

        int g = 0;
        for (int x : nums) g = __gcd(g, x);
        if (g > 1) return -1;                     // 观察 4：公因子永存

        int L = n;                                // 观察 1：整体 gcd=1 保证存在
        for (int i = 0; i < n; ++i) {
            int cur = 0;
            for (int j = i; j < n; ++j) {
                cur = __gcd(cur, nums[j]);        // 固定 i，向右滚动
                if (cur == 1) {
                    L = min(L, j - i + 1);        // 首次为 1 即该左端最短
                    break;
                }
            }
        }
        return (L - 1) + (n - 1);                 // 两阶段公式
    }
};
```

### Python

```python
from math import gcd

class Solution:
    def minOperations(self, nums: List[int]) -> int:
        n = len(nums)
        k = nums.count(1)
        if k:
            return n - k                          # 观察 2：1 的传染

        g = 0
        for x in nums:
            g = gcd(g, x)
        if g > 1:
            return -1                             # 观察 4：公因子永存

        L = n                                     # 观察 1：整体 gcd=1 保证存在
        for i in range(n):
            cur = 0
            for j in range(i, n):
                cur = gcd(cur, nums[j])           # 固定 i，向右滚动
                if cur == 1:
                    L = min(L, j - i + 1)         # 首次为 1 即该左端最短
                    break
        return (L - 1) + (n - 1)                  # 两阶段公式
```

## 8. 边界情况与易错点

1. **忘记 $k \ge 1$ 短路**：`[5, 1, 5]` 的正确答案是 $n-k = 2$；若直接走 $L$ 路线，含 1 的相邻对 gcd 立即为 1，得 $L=2$、错算成 $(2-1)+(3-1)=3$。含 1 的问题必须走「传染」公式。
2. **忘记无解判定**：`[2,10,6,14]` 求最短窗口时循环一无所获，$L$ 保持初值 $n=4$，会错算成 $6$；必须先判整体 gcd $> 1$ 返回 $-1$。
3. **内层 `break` 不能省**：固定左端点后 gcd 单调不变差，首个 $1$ 即最短；不 `break` 虽然答案也对（取 `min`），但白扫且容易顺手写成覆盖 $L$。
4. **全 1 数组**：$k = n$ 时 $n - k = 0$，天然被第一步覆盖，无需特判。
5. **答案量级**：最坏 $L = n$（如 $[6,10,15]$ 扩到 $n$ 个两两不互素、整体互素的数），答案 $2n-2 \le 98$，`int` 毫无溢出风险；Python 无此忧。
6. **读题**：是「替换二者**之一**」，不是「都替换」——对计数推导无影响（gcd 对称），但别在模拟口径上出错。
7. **造第一个 1 的窗口位置**：与答案无关（阶段二代价恒 $n-1$），不必纠结选靠左还是靠右的等长窗口。
