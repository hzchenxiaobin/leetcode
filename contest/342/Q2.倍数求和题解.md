# LeetCode 倍数求和 题解

## 1. 题目概述

- **标题 / 题号**：倍数求和（#2652，easy）
- **链接**：https://leetcode.cn/problems/sum-multiples/
- **来源**：LeetCode 第 342 场周赛 Q2
- **难度**：简单
- **标签**：数学、数论、容斥原理

**题意**：给定正整数 $n$，计算 $[1, n]$ 内**能被 3、5 或 7 整除**的所有整数之和，返回这个和。

**约束**：

- $1 \le n \le 10^3$

> 💡 题面里的「3、5、7」是**或**关系：只要被其中任意一个整除就算数。像 15 这样同时被 3 和 5 整除的数**只算一次**——这条隐含约定正是本题从「签到」升级为「容斥入门」的全部戏码。

## 2. 示例

**示例 1**

```text
输入：n = 7
输出：21
解释：[1, 7] 内满足条件的数是 3、5、6、7（6 被 3 整除，7 被 7 整除），和为 21。
```

**示例 2**

```text
输入：n = 10
输出：40
解释：[1, 10] 内满足条件的数是 3、5、6、7、9、10，和为 40。
```

**示例 3（重叠情形，自测用）**

```text
输入：n = 20
输出：119
解释：满足条件的数是 3, 5, 6, 7, 9, 10, 12, 14, 15, 18, 20。
      其中 15 同时被 3 和 5 整除，只计一次。总和为 119。
```

## 3. 解题思路

### 3.1 暴力思路：一遍扫描

从 $1$ 到 $n$ 逐个检查 `i % 3 == 0 or i % 5 == 0 or i % 7 == 0`，满足就累加。时间 $O(n)$，$n \le 10^3$ 时 1000 次循环瞬间完成——**比赛现场这就是保底解**，先交上去锁定分数。

缺点是把 $n$ 放大到 $10^9$（本题套路的常见变体，见「相关题目与扩展」）就不可接受。周赛现场的正确节奏是：**暴力保底，再升级 $O(1)$**。

### 3.2 核心观察：容斥原理 + 等差数列闭合公式

![韦恩图：三个倍数集合的并集与容斥公式](images/sum_multiples_venn_concept.svg)

记 $S(k)$ 为 $[1,n]$ 内**被 $k$ 整除的数之和**。目标答案是三个倍数集合之并的元素和：

- 直接 $S(3) + S(5) + S(7)$：像 15（被 3、5 同时整除）被算了**两次**，21、35、105 同理；
- 用**容斥原理**修正重复：

$$\text{ans} = S(3) + S(5) + S(7) - S(15) - S(21) - S(35) + S(105)$$

为什么交集恰好是 $S(15)$、$S(21)$、$S(35)$、$S(105)$？因为「同时被 $a$、$b$ 整除」$\iff$「被 $\mathrm{lcm}(a,b)$ 整除」，而 3、5、7 两两**互质**，$\mathrm{lcm}$ 就是乘积（引理 2，证明见 §5）。

而每个 $S(k)$ 根本不用循环——「$k$ 的倍数」是一串**等差数列**，有闭合公式（引理 1）：

![等差数列闭合公式：S(k) = k·m(m+1)/2 的首尾配对推导](images/sum_multiples_series_formula.svg)

$$S(k) = k + 2k + \cdots + mk = k \cdot \frac{m(m+1)}{2}, \qquad m = \left\lfloor \frac{n}{k} \right\rfloor$$

七个 $S(k)$，每个一次整除加几次乘除，总共七次整数运算，与 $n$ 无关——$O(1)$。

### 3.3 算法流程

```text
1. 定义 S(k)：m = ⌊n/k⌋，返回 k · m(m+1)/2
2. 返回 S(3) + S(5) + S(7) − S(15) − S(21) − S(35) + S(105)
```

### 3.4 示例演算

![示例演算：n = 10 的七项容斥表](images/sum_multiples_walkthrough.svg)

| 符号 | $k$ | $m=\lfloor 10/k \rfloor$ | $\le 10$ 的 $k$ 的倍数 | $S(k)$ |
|------|-----|--------------------------|------------------------|--------|
| $+$ | 3 | 3 | 3, 6, 9 | 18 |
| $+$ | 5 | 2 | 5, 10 | 15 |
| $+$ | 7 | 1 | 7 | 7 |
| $-$ | 15 | 0 | — | 0 |
| $-$ | 21 | 0 | — | 0 |
| $-$ | 35 | 0 | — | 0 |
| $+$ | 105 | 0 | — | 0 |

$$\text{ans} = 18 + 15 + 7 - 0 - 0 - 0 + 0 = 40 \;\checkmark$$

$n = 10 < 15$，四个交集项全为 0——**小 $n$ 没有重叠，容斥退化为直接相加**。再看自测的 $n = 20$（重叠出现）：$S(3)=63$、$S(5)=50$、$S(7)=21$、$S(15)=15$，其余为 0，$\text{ans} = 63+50+21-15 = 119\;\checkmark$——此时 15 被「多算一次再减一次」，净贡献恰为一次。

## 4. 算法细节

1. **$S(k)$ 的实现**：一次整除 $m = \lfloor n/k \rfloor$ + 一次 $k \cdot m(m+1)/2$。$m$ 与 $m+1$ 必有一个偶数，故 $m(m+1)/2$ 是精确整数，地板除不丢精度。
2. **七项符号**：单集合（奇数重交集）取 $+$，两两交（偶数重）取 $-$，三重交取 $+$——「多退少补」，直到每个数恰好被算一次。
3. **交集的 $k$ 用 lcm**：本题 3、5、7 两两互质，$\mathrm{lcm}$ = 乘积，可直接写常数 15、21、35、105；若除数不互质（如 4、6），交集必须用 $\mathrm{lcm}(4,6)=12$ 而非 24。
4. **数据类型**：$n \le 10^3$ 时最大中间量 $3 \times 333 \times 334 \approx 3.3 \times 10^5$，C++ `int` 无溢出风险；Python 必须用 `//` 地板除，`/` 会返回浮点。

## 5. 正确性证明

**引理 1（倍数和闭合公式）**：$S(k) = k \cdot \dfrac{m(m+1)}{2}$，其中 $m = \left\lfloor n/k \right\rfloor$。

**证明**：$[1,n]$ 内 $k$ 的倍数恰为 $k, 2k, \ldots, mk$：由 $m = \lfloor n/k \rfloor$ 得 $mk \le n$（都 $\le n$）且 $(m+1)k > n$（无遗漏更多），故不重不漏。于是 $S(k) = k(1 + 2 + \cdots + m)$。把 $1 + \cdots + m$ 正序、倒序各写一遍逐列相加，每列之和均为 $m+1$，共 $m$ 列，得 $2(1+\cdots+m) = m(m+1)$，即 $1+\cdots+m = \frac{m(m+1)}{2}$。∎

**引理 2（交集的 lcm 刻画）**：$x$ 同时被 $a$、$b$ 整除 $\iff$ $x$ 被 $\mathrm{lcm}(a,b)$ 整除；$a$、$b$ 互质时 $\mathrm{lcm}(a,b) = ab$。

**证明**：「$a \mid x$ 且 $b \mid x$」即「$x$ 是 $a,b$ 的公倍数」。设 $L = \mathrm{lcm}(a,b)$，对任意公倍数 $x$ 写 $x = qL + r$（$0 \le r < L$）：由 $a \mid L, a \mid x$ 得 $a \mid r$，同理 $b \mid r$，故 $r$ 是公倍数且 $r < L$，由 $L$ 最小性只能 $r = 0$，即 $L \mid x$；反之显然。故公倍数集合 = $\mathrm{lcm}$ 的倍数集合。互质时由 $\mathrm{lcm}(a,b) \cdot \gcd(a,b) = ab$ 且 $\gcd = 1$ 得 $\mathrm{lcm} = ab$。∎

**定理（容斥求和公式）**：$\text{ans} = S(3)+S(5)+S(7)-S(15)-S(21)-S(35)+S(105)$。

**证明**：对任意 $x \in [1,n]$，考察等式右端含 $x$ 的项的代数和 $c(x)$（「净计次数」）。按 $x$ 被 3、5、7 整除的个数 $t$ 分类（由引理 2，交集项是否含 $x$ 完全由整除性决定）：

- $t = 0$：任何项都不含 $x$，$c(x) = 0$，而 $x$ 不该被计入 ✓
- $t = 1$（设仅 $3 \mid x$）：仅 $S(3)$ 含 $x$，交集项均要求第二个除数整除 $x$ 而不满足，$c(x) = 1$ ✓
- $t = 2$（设 $3,5 \mid x$，$7 \nmid x$）：$S(3), S(5)$ 各计一次（$+2$）；$S(15)$ 含 $x$（$-1$）；$S(21), S(35), S(105)$ 都要求 $7 \mid x$，不含；$c(x) = 2 - 1 = 1$ ✓
- $t = 3$（即 $105 \mid x$）：三个单集项 $+3$；三个两两项 $S(15), S(21), S(35)$ 各 $-1$ 共 $-3$；$S(105)$ $+1$；$c(x) = 3 - 3 + 1 = 1$ ✓

每种情况下 $c(x)$ 都恰等于「$x$ 是否该被计入」（0 或 1），故右端 $= \sum_{x \text{ 该计入}} x = \text{ans}$。∎

> 💡 证明的关键结构是**逐元素核账**：容斥公式对每个元素单独算清净计次数，不依赖元素间任何关系——这是容斥类正确性证明的通用套路，计数题如此，求和题亦如此。

## 6. 复杂度分析

- **时间复杂度**：$O(1)$。七个 $S(k)$，每个一次整除加常数次乘除。暴力法则为 $O(n)$——$n \le 10^3$ 时两者实测无差别，$n \to 10^9$ 时暴力不可行而容斥不变。
- **空间复杂度**：$O(1)$。仅常数个整型变量。

## 7. 参考代码

### 方法一：一遍扫描（$O(n)$，比赛保底）

### C++

```cpp
class Solution {
  public:
    int sumOfMultiples(int n) {
        int ans = 0;
        for (int i = 1; i <= n; ++i) {
            if (i % 3 == 0 || i % 5 == 0 || i % 7 == 0) {
                ans += i;
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def sumOfMultiples(self, n: int) -> int:
        return sum(
            i for i in range(1, n + 1)
            if i % 3 == 0 or i % 5 == 0 or i % 7 == 0
        )
```

### 方法二：容斥 + 等差数列（$O(1)$，进阶）

### C++

```cpp
class Solution {
  public:
    int sumOfMultiples(int n) {
        // S(k) = [1,n] 内 k 的倍数之和 = k * m*(m+1)/2，m = n/k
        auto S = [n](int k) {
            int m = n / k;
            return k * m * (m + 1) / 2;
        };
        // 容斥：3,5,7 两两互质，交集即被 lcm(=乘积) 整除
        return S(3) + S(5) + S(7) - S(15) - S(21) - S(35) + S(105);
    }
};
```

### Python

```python
class Solution:
    def sumOfMultiples(self, n: int) -> int:
        def s(k: int) -> int:        # S(k) = k 的倍数之和
            m = n // k
            return k * m * (m + 1) // 2
        # 容斥：3,5,7 两两互质，交集即被 lcm(=乘积) 整除
        return s(3) + s(5) + s(7) - s(15) - s(21) - s(35) + s(105)
```

## 8. 边界情况与易错点

1. **「或」写成「且」**：判定条件是 `||`（Python `or`）。误写 `&&` 后只有 105 的倍数满足，$n < 105$ 时直接返回 0，三个示例全 WA——这是本题最高频的翻车点。
2. **Python 除法用 `//`**：`m * (m + 1) / 2` 返回 `float`，轻则输出类型错误，重则隐式转换埋雷；`//` 才是整数。$m(m+1)$ 必为偶数，地板除无损。
3. **交集写乘积的前提是互质**：3、5、7 两两互质故 $15, 21, 35, 105$ 直接成立；换成 4、6 这类不互质除数，交集是 $\mathrm{lcm}(4,6)=12$ 的倍数而非 24。
4. **$n$ 小于最小交集基数**：$n < 15$ 时 $S(15), S(21), S(35), S(105)$ 全为 0（$m=0$），容斥退化为直接相加。建议用 $n=1$（答案 0）、$n=3$（答案 3）做边界自测。
5. **C++ 溢出评估**：$n \le 10^3$ 时最大中间量约 $3.3 \times 10^5$，`int` 安全；若沿用此法到 $n \le 10^9$ 的变体，中间量最大约 $3 \times 10^8$ 仍安全，但稳妥起见 `long long` 一步到位。
6. **先交暴力再优化**：$n \le 10^3$ 保证暴力必过，比赛现场别在「想 $O(1)$」上耗时间——节奏是先锁定分数，回头再沉淀套路。
