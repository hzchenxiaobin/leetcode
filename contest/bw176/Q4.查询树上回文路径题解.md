# LeetCode 查询树上回文路径 题解

## 1. 题目概述

- **标题 / 题号**：查询树上回文路径（#3841，hard）
- **链接**：https://leetcode.cn/problems/palindromic-path-queries-in-a-tree/
- **来源**：LeetCode 第 176 场双周赛 Q4
- **难度**：困难
- **标签**：位运算、树、深度优先搜索、树状数组、线段树、数组、字符串、分治

**题意**：给定 $n$ 个节点的无向树，节点 $i$ 上有小写字母 `s[i]`。处理 $q$ 条查询：

- `"update u c"`：把节点 $u$ 的字母改成 $c$；
- `"query u v"`：判断 $u$ 到 $v$ 的**唯一路径**（含两端点）上的字符串能否**重排成回文串**。

按顺序返回所有 `query` 的布尔结果。

**约束**：

- $1 \le n \le 5 \times 10^4$，$s$ 由小写字母组成，`edges` 构成合法树
- $1 \le queries.length \le 5 \times 10^4$

## 2. 示例

**示例 1**

```text
输入：n = 3, edges = [[0,1],[1,2]], s = "aac",
     queries = ["query 0 2","update 1 b","query 0 2"]
输出：[true,false]
解释：路径 0-1-2 得 "aac"，可排成 "aca"（仅 'c' 出现奇数次）；
      更新节点 1 为 'b' 后路径为 "abc"，三个奇数字符，无法构成回文。
```

**示例 2**

```text
输入：n = 4, edges = [[0,1],[0,2],[0,3]], s = "abca",
     queries = ["query 1 2","update 0 b","query 2 3","update 3 a","query 1 3"]
输出：[false,false,true]
解释：第三条查询时路径 1-0-3 的字符为 "bba"，可排成 "bab"。
```

## 3. 解题思路

### 3.1 暴力思路

对每条 `query` 用 BFS 找出 $u \to v$ 的路径，统计各字符出现次数，再判断"奇数频次的字符数 $\le 1$"。单次 $O(n)$，总 $O(qn) = 2.5 \times 10^9$，超时。瓶颈在于"路径信息"每次都重算，而 `update` 会破坏任何静态预处理。

需要一种**点更新 + 路径查询**的数据结构：路径用 LCA 拆成两段，点更新用"子树区间增量 + 树状数组"来维护。

### 3.2 核心观察：回文 ⟺ 至多一个字符出现奇数次

![回文判定：把字符频次的奇偶性压成 26 位掩码，看 popcount](images/bw176_q4_mask_concept.svg)

**引理**：长度为 $L$ 的字符串能重排成回文，当且仅当其中**出现奇数次的字符个数** $\le 1$。

理由是回文串关于中心对称：除中心（$L$ 为奇数时）外，每个字符都必须成对出现。因此只需维护**每个字符出现次数的奇偶性**——一个 26 位掩码。奇数次的字符个数 = 掩码的 popcount，条件即 $\text{popcount} \le 1$。

而"路径上字符计数的奇偶性"正好可以用**按位异或**维护：每个节点贡献 $2^{c}$（$c$ 为字符编号），路径掩码 = 路径上所有贡献的异或。异或天然是"模 2 加法"。

### 3.3 算法流程

![路径掩码 = 根到 u 的异或 ⊕ 根到 v 的异或 ⊕ lca 的字符](images/bw176_q4_path_formula.svg)

**第一步：根路径掩码与 LCA**。以 0 为根，令 $W[u]$ 为根到 $u$（含两端）所有字符掩码的异或。则

$$\text{mask}(u \to v) = W[u] \oplus W[v] \oplus \text{mask}[\text{lca}(u,v)]$$

因为 $W[u] \oplus W[v]$ 把"根到 lca"这段算了两次而抵消，需要补回 lca 节点本身。LCA 用**倍增**（$O(\log n)$）。

**第二步：点更新转化为子树区间异或**。当节点 $x$ 的字符由旧掩码 $m$ 变为新掩码 $m'$ 时，取 $\delta = m \oplus m'$。由 $W$ 的定义，$W[u]$ 包含 `mask[x]` 当且仅当 $x$ 是 $u$ 的祖先（$u$ 在 $x$ 的子树中），故

$$W'[u] = \begin{cases} W[u] \oplus \delta, & u \in \text{subtree}(x) \\ W[u], & \text{否则} \end{cases}$$

**第三步：欧拉序 + 树状数组**。对树做 DFS，每个子树对应欧拉序上一段**连续区间** $[\text{tin}[x], \text{tout}[x])$。于是"子树整体异或 $\delta$"变成"区间异或更新"，"查询 $W[u]$ 的当前值"变成"单点查询"：

- 树状数组（异或版）支持：**区间更新 + 单点查询** $O(\log n)$；
- 具体做法：区间更新 $[l, r)$ 转成两次前缀差分更新 `add(l+1, δ)`、`add(r+1, δ)`，单点查询取前缀异或。

```text
1. 迭代 DFS 求 tin / tout / dep / par / up[0]，以及初始 W0
2. 倍增表 up[j][v]；LCA(u,v) 用深度对齐 + 同时上跳
3. mask[] 记录每个节点当前字符掩码
4. 处理查询：
   update u c:
       δ = mask[u] ^ (1 << (c-'a'))
       若 δ ≠ 0：BIT 区间异或 [tin[u], tout[u]) 加 δ；mask[u] 更新
   query u v:
       w = LCA(u,v)
       cur = W0[u] ^ queryBIT(tin[u]) ^ W0[v] ^ queryBIT(tin[v]) ^ mask[w]
       答案 = (popcount(cur) <= 1)
```

### 3.4 示例演算

![示例演算：示例 1 中 update 前后路径掩码的变化](images/bw176_q4_walkthrough.svg)

示例 1：树为 $0-1-2$，`s = "aac"`，初始 $W[0] = \text{bit}(a)$、$W[1] = a \oplus a = 0$、$W[2] = a \oplus a \oplus c = c$。

| 操作 | 说明 | 结果 |
|------|------|------|
| `query 0 2` | lca=0，掩码 $= W[0] \oplus W[2] \oplus a = a \oplus c \oplus a = c$ | popcount 1 → `true` |
| `update 1 b` | 节点 1 由 `a` 变 `b`，$\delta = a \oplus b$；子树 $\{1,2\}$ 的 $W$ 全部异或 $\delta$ | $W[1] \to b$，$W[2] \to a \oplus b \oplus c$ |
| `query 0 2` | 掩码 $= a \oplus (a\oplus b\oplus c) \oplus a = a \oplus b \oplus c$ | popcount 3 → `false` |

结果与示例一致。注意 `update` 影响整棵子树（示例里节点 2 的 $W$ 也被改了），这正是"区间更新"的来源。

## 4. 算法细节

1. **迭代 DFS 防爆栈**：$n = 5\times10^4$ 的链在 Python 里递归必崩；用显式栈，`it[u]` 记录当前处理到哪个邻居。
2. **`tin/tout` 的语义**：`tin[u]` 在首次访问时分配，`tout[u]` 在子树处理完时记录为"当前计数器"，区间是**左闭右开** $[\text{tin}, \text{tout})$。
3. **树状数组的 1-based 下标**：`tin` 从 0 开始，BIT 内部统一 `+1`；区间更新 `[l, r)` 对应 `add(l+1, δ)` 与 `add(r+1, δ)`，注意 `r+1` 可能等于 `n+1`，BIT 数组开到 `n+2`。
4. **`W0` 与增量分离**：不真正修改 $W$，而是保存初始 $W_0$，查询时现算 `W0[u] ^ 前缀异或`，省去区间遍历。
5. **倍增表维度**：`LOG = ceil(log2(n)) + 1`，$n = 5\times10^4$ 时 `LOG = 17`。
6. **δ = 0 时跳过**：新旧字符相同则什么都不做，避免无意义更新。
7. **popcount**：C++ 用 `__builtin_popcount`，Python 用 `bin(x).count('1')`。
8. **查询 $u = v$**：LCA 就是自身，掩码 = 该节点字符，popcount = 1 → `true`（单字符是回文）。

## 5. 正确性证明

**引理 1（回文判据）**：字符串 $T$ 可重排成回文 $\iff$ $T$ 中出现奇数次的字符至多 1 个。

**证明**：若可重排，则回文串中每个字符除中心外都成对出现，故至多一个字符（中心）出现奇数次，而重排不改变各字符的计数奇偶性。反之，若至多一个字符出现奇数次，把所有成对字符分别放在首尾两侧、奇数次的字符（若有）放在中心，即构造出回文。∎

**引理 2（掩码即奇偶向量）**：路径掩码 $\text{cur}$ 的第 $c$ 位等于字符 $c$ 在路径上出现次数的奇偶性。

**证明**：每个节点对掩码贡献 $2^{c}$，异或即对每一位做模 2 加法；位 $c$ 上的结果就是"字符 $c$ 出现次数 mod 2"。∎

**引理 3（路径掩码公式）**：$\text{mask}(u\to v) = W[u] \oplus W[v] \oplus \text{mask}[\text{lca}(u,v)]$。

**证明**：设 $l = \text{lca}(u,v)$。$W[u] \oplus W[v]$ 中，"根到 $l$"的每个节点出现两次而异或为 0；$l$ 到 $u$ 与 $l$ 到 $v$ 的分支（不含 $l$）各出现一次，正好是路径去重后的部分；因此再异或上 `mask[l]` 即得整条路径。∎

**引理 4（子树区间更新正确）**：节点 $x$ 的字符改变 $\delta$ 后，$W'[u] = W[u] \oplus \delta$ 当且仅当 $u$ 在 $x$ 的子树中。

**证明**：$W[u]$ 是所有祖先（含自己）的掩码异或。只有包含 `mask[x]` 的那些 $W[u]$ 会变化，而 `mask[x]` 出现在 $W[u]$ 中当且仅当 $x$ 是 $u$ 的祖先，即 $u \in \text{subtree}(x)$。∎

**引理 5（BIT 语义）**：区间异或更新 + 点查询的树状数组实现，使任意时刻点 $i$ 的查询值等于"覆盖 $i$ 的所有更新 δ 的异或"；而欧拉序上子树恰为连续区间，故查询 `tin[u]` 得到 $W[u]$ 的总增量。

**证明**：前缀差分的两次 `add` 使区间 $[l,r)$ 内每个位置多异或一次 $\delta$、区间外异或两次（即 0）；点查询取前缀异或即累加所有覆盖该点的更新。子树区间连续性由 DFS 序的构造保证。∎

**定理**：对每条 `query`，算法给出的布尔值等于"该路径字符串可重排成回文"。

**证明**：由引理 3、4、5，查询时算出的 `cur` 就是当前路径的掩码；由引理 1、2，`popcount(cur) <= 1` 与"可重排成回文"等价。`update` 只改变被更新节点的掩码与 BIT，不破坏 $W_0$ 的正确性（增量分离）。∎

## 6. 复杂度分析

- **时间**：预处理 $O(n\log n)$（DFS + 倍增表）；每次 `update` 为两次 BIT 更新 $O(\log n)$；每次 `query` 为一次 LCA $O(\log n)$ 加两次 BIT 查询 $O(\log n)$。总计 $O\big((n+q)\log n\big)$。
- **空间**：$O(n\log n)$ 存倍增表（$17 \times 5\times10^4$），其余 $O(n)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<bool> palindromePath(int n, vector<vector<int>>& edges, string s, vector<string>& queries) {
        vector<vector<int>> adj(n);
        for (auto& e : edges) {
            adj[e[0]].push_back(e[1]);
            adj[e[1]].push_back(e[0]);
        }
        int LOG = 1;
        while ((1 << LOG) <= n) LOG++;

        vector<int> tin(n), tout(n), dep(n, 0), par(n, 0), W0(n, 0);
        vector<vector<int>> up(LOG, vector<int>(n, 0));
        vector<int> it(n, 0), st;
        st.push_back(0);
        par[0] = 0;
        up[0][0] = 0;
        W0[0] = 1 << (s[0] - 'a');
        int timer = 0;
        while (!st.empty()) {
            int u = st.back();
            if (it[u] == 0) tin[u] = timer++;
            if (it[u] < (int)adj[u].size()) {
                int v = adj[u][it[u]++];
                if (v == par[u]) continue;
                par[v] = u;
                dep[v] = dep[u] + 1;
                up[0][v] = u;
                W0[v] = W0[u] ^ (1 << (s[v] - 'a'));
                st.push_back(v);
            } else {
                tout[u] = timer;
                st.pop_back();
            }
        }
        for (int j = 1; j < LOG; j++)
            for (int v = 0; v < n; v++) up[j][v] = up[j - 1][up[j - 1][v]];

        // 树状数组（异或版）：支持「子树范围异或」+「单点查询」
        vector<int> bit(n + 2, 0);
        auto add = [&](int i, int val) {           // i 为 1-based
            for (; i <= n; i += i & -i) bit[i] ^= val;
        };
        auto pref = [&](int i) {
            int r = 0;
            for (; i > 0; i -= i & -i) r ^= bit[i];
            return r;
        };
        vector<int> mask(n);
        for (int i = 0; i < n; i++) mask[i] = 1 << (s[i] - 'a');

        auto lca = [&](int u, int v) {
            if (dep[u] < dep[v]) swap(u, v);
            int d = dep[u] - dep[v];
            for (int j = 0; j < LOG; j++)
                if ((d >> j) & 1) u = up[j][u];
            if (u == v) return u;
            for (int j = LOG - 1; j >= 0; j--)
                if (up[j][u] != up[j][v]) { u = up[j][u]; v = up[j][v]; }
            return up[0][u];
        };

        vector<bool> ans;
        for (auto& q : queries) {
            if (q[0] == 'u') {
                int u;
                char ch;
                sscanf(q.c_str(), "update %d %c", &u, &ch);
                int nm = 1 << (ch - 'a');
                int delta = mask[u] ^ nm;
                if (delta) {
                    add(tin[u] + 1, delta);
                    add(tout[u] + 1, delta);
                    mask[u] = nm;
                }
            } else {
                int u, v;
                sscanf(q.c_str(), "query %d %d", &u, &v);
                int w = lca(u, v);
                int x = W0[u] ^ pref(tin[u] + 1) ^ W0[v] ^ pref(tin[v] + 1) ^ mask[w];
                ans.push_back(__builtin_popcount((unsigned)x) <= 1);
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def palindromePath(self, n: int, edges: list[list[int]], s: str, queries: list[str]) -> list[bool]:
        adj = [[] for _ in range(n)]
        for a, b in edges:
            adj[a].append(b)
            adj[b].append(a)
        LOG = 1
        while (1 << LOG) <= n:
            LOG += 1

        tin, tout, dep = [0] * n, [0] * n, [0] * n
        par = [0] * n
        W0 = [0] * n
        up = [[0] * n for _ in range(LOG)]
        it = [0] * n
        st = [0]
        W0[0] = 1 << (ord(s[0]) - 97)
        timer = 0
        while st:
            u = st[-1]
            if it[u] == 0:
                tin[u] = timer
                timer += 1
            if it[u] < len(adj[u]):
                v = adj[u][it[u]]
                it[u] += 1
                if v == par[u]:
                    continue
                par[v] = u
                dep[v] = dep[u] + 1
                up[0][v] = u
                W0[v] = W0[u] ^ (1 << (ord(s[v]) - 97))
                st.append(v)
            else:
                tout[u] = timer
                st.pop()
        for j in range(1, LOG):
            prev, curj = up[j - 1], up[j]
            for v in range(n):
                curj[v] = prev[prev[v]]

        bit = [0] * (n + 2)

        def add(i, val):
            while i <= n:
                bit[i] ^= val
                i += i & -i

        def pref(i):
            r = 0
            while i > 0:
                r ^= bit[i]
                i -= i & -i
            return r

        def lca(u, v):
            if dep[u] < dep[v]:
                u, v = v, u
            d = dep[u] - dep[v]
            j = 0
            while d:
                if d & 1:
                    u = up[j][u]
                d >>= 1
                j += 1
            if u == v:
                return u
            for j in range(LOG - 1, -1, -1):
                if up[j][u] != up[j][v]:
                    u, v = up[j][u], up[j][v]
            return up[0][u]

        mask = [1 << (ord(c) - 97) for c in s]
        ans = []
        for q in queries:
            parts = q.split()
            if parts[0] == "update":
                u = int(parts[1])
                nm = 1 << (ord(parts[2]) - 97)
                delta = mask[u] ^ nm
                if delta:
                    add(tin[u] + 1, delta)
                    add(tout[u] + 1, delta)
                    mask[u] = nm
            else:
                u, v = int(parts[1]), int(parts[2])
                w = lca(u, v)
                x = W0[u] ^ pref(tin[u] + 1) ^ W0[v] ^ pref(tin[v] + 1) ^ mask[w]
                ans.append(bin(x).count("1") <= 1)
        return ans
```

## 8. 边界情况与易错点

1. **`u = v`**：路径只含一个字符，popcount = 1，答案 `true`。
2. **`update` 改回原字符**：$\delta = 0$，可以跳过；若仍更新，异或两次也会抵消，但会浪费常数。
3. **子树区间的右端点**：`tout` 是**开区间**，BIT 更新要写 `add(tout[u] + 1, delta)`；写成 `add(tout[u], delta)` 会把右边界外的第一个节点也算进去。
4. **BIT 大小**：`tout[u] + 1` 最大等于 $n + 1$，数组要开到 $n+2$，循环上界用 `i <= n` 时 `n+1` 的更新会"越界丢失"——本题用 `n+2` 的数组并让 `i <= n` 判断，若 `tout[u]+1 == n+1` 则该次 `add` 直接不生效，正好等价于"没有右侧元素"，是正确的；但若数组开成 `n+1` 则会产生下标越界。
5. **Python 递归**：必须用迭代 DFS，否则 $5\times10^4$ 的链会触发 `RecursionError`。
6. **`LOG` 的上界**：$n = 1$ 时 `LOG = 1`，倍增表只有一层，LCA 退化正确（`u = v = 0`）。
7. **掩码位宽**：26 位足够，`int` 容纳得下（$< 2^{26}$），不要用 32 位以上逻辑混淆。
8. **LCA 的深度对齐**：先跳到同深度再同时上跳，漏掉对齐或对齐方向反了都会算错。
