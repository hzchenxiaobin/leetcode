# LeetCode 打家劫舍 V 题解

## 1. 题目概述

- **标题 / 题号**：打家劫舍 V（#3840，medium）
- **链接**：https://leetcode.cn/problems/house-robber-v/
- **来源**：LeetCode 第 176 场双周赛 Q3
- **难度**：中等
- **标签**：数组、动态规划

**题意**：沿街有 $n$ 间房屋，第 $i$ 间有金额 `nums[i]`、颜色 `colors[i]`。若两间**相邻**房屋颜色**相同**，则不能同时偷窃它们；**不相邻**的房屋之间没有任何限制（不论颜色）。求能偷到的最大金额。

**约束**：

- $1 \le n \le 10^5$
- $1 \le nums[i], colors[i] \le 10^5$

> 💡 这是打家劫舍系列里限制最弱的一版：**只有"相邻且同色"才互斥**，隔着一间就完全自由。

## 2. 示例

**示例 1**

```text
输入：nums = [1,4,3,5], colors = [1,1,2,2]
输出：9
解释：偷 1 号（4）与 3 号（5）。1、2 号同色相邻不能同偷；2、3 号也同色相邻。
```

**示例 2**

```text
输入：nums = [3,1,2,4], colors = [2,3,2,2]
输出：8
解释：偷 0、1、3 号：0 与 1 颜色不同可相邻；1 与 3 不相邻，无限制。
```

**示例 3**

```text
输入：nums = [10,1,3,9], colors = [1,1,1,2]
输出：22
解释：偷 0、2、3 号：0 与 2 不相邻，2 与 3 颜色不同。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有子集（$2^n$），检验"不存在相邻同色对被同时选中"，复杂度指数级。经典打家劫舍的 DP 只需一维，但本题的合法性依赖**颜色相等**，容易误以为要加"上一个偷的颜色"这一维——实际上不必，因为限制只看**相邻下标**。

### 3.2 核心观察：只需讨论"是否偷第 i 间"以及"是否偷第 i−1 间"

![按第 i 间是否偷窃分类，只需比较三种转移](images/bw176_q3_dp_classification.svg)

设 $dp[i]$ 为"只考虑前 $i+1$ 间房屋（下标 $0..i$）能偷到的最大金额"。对第 $i$ 间：

1. **不偷 $i$**：问题退化为 $dp[i-1]$；
2. **偷 $i$，且不偷 $i-1$**：其余选择都在前 $i-1$ 间（下标 $0..i-2$）内，值为 $nums[i] + dp[i-2]$；
3. **偷 $i$，且也偷 $i-1$**：只允许 $colors[i] \ne colors[i-1]$，值为 $nums[i] + dp[i-1]$。

于是

$$dp[i] = \max\Big(dp[i-1],\ nums[i] + dp[i-2],\ [colors[i] \ne colors[i-1]] \cdot \big(nums[i] + dp[i-1]\big)\Big)$$

其中 $dp[-1] = 0$、$dp[0] = nums[0]$。

**为什么不需要"上一个偷的颜色"**：条件 3 只检查 $i-1$ 与 $i$ 的颜色，而 $i-1$ 是否被偷已经由"用 $dp[i-1]$ 还是 $dp[i-2]$"隐式区分了。$dp[i-1]$ 的最优方案要么不含 $i-1$（那么方案本身对 $i$ 无约束），要么含 $i-1$（颜色不同才允许），两种情况都被 $colors[i] \ne colors[i-1]$ 这一分支覆盖。

### 3.3 算法流程

```text
1. dp[0] = nums[0]
2. for i = 1 .. n-1:
       best = dp[i-1]                                   # 不偷 i
       best = max(best, nums[i] + (i >= 2 ? dp[i-2] : 0))   # 偷 i，隔一间
       若 colors[i] != colors[i-1]:
           best = max(best, nums[i] + dp[i-1])          # 偷 i，且偷 i-1
       dp[i] = best
3. 返回 dp[n-1]
```

### 3.4 示例演算

![示例演算：nums = [1,4,3,5]、colors = [1,1,2,2] 的 DP 表](images/bw176_q3_walkthrough.svg)

以示例 1 为例：

| $i$ | $nums[i]$ | $colors[i]$ | 与前一间同色？ | $dp[i-1]$ | $nums[i]+dp[i-2]$ | $nums[i]+dp[i-1]$ | $dp[i]$ |
|-----|-----------|-------------|----------------|-----------|-------------------|-------------------|---------|
| 0 | 1 | 1 | — | — | — | — | 1 |
| 1 | 4 | 1 | 是 | 1 | 4+0=4 | 不允许 | 4 |
| 2 | 3 | 2 | 否 | 4 | 3+1=4 | 3+4=7 | 7 |
| 3 | 5 | 2 | 是 | 7 | 5+4=9 | 不允许 | 9 |

答案 9，对应偷 1 号与 3 号。注意 $i=2$ 时"偷 2 且偷 1"给出 7（合法，颜色 1≠2）；$i=3$ 时因与 2 同色，只能靠"隔一间"转移拿到 9。

## 4. 算法细节

1. **状态一维**：$dp[i]$ 只依赖 $dp[i-1]$、$dp[i-2]$，可以用两个变量滚动，空间降到 $O(1)$（下文代码保留数组，便于对照）。
2. **64 位**：$n = 10^5$、$nums[i] \le 10^5$，最大金额可达 $10^{10}$，C++ 必须 `long long`。
3. **转移顺序**：先算"不偷"，再算"隔一间"，最后条件性地算"相邻偷"；三者取 max。
4. **$i = 1$ 的 $dp[i-2]$**：用 0 代替（偷 1 号时，前面的选择集合为空）。
5. **颜色比较**：直接用 `colors[i] != colors[i-1]`，不要比较 `nums`。
6. **相邻但异色**：允许同时偷，这是与经典打家劫舍唯一的区别（经典版本永远禁止相邻）。

## 5. 正确性证明

**引理 1（转移下界）**：$dp[i] \ge \max\big(dp[i-1],\ nums[i]+dp[i-2],\ [c_i \ne c_{i-1}](nums[i]+dp[i-1])\big)$。

**证明**：三种取值都由合法方案达到：① 取 $dp[i-1]$ 的最优方案（不含 $i$）；② 取 $dp[i-2]$ 的最优方案并加上 $i$（$i$ 与 $i-1$ 都不在方案中，与更前面的房屋不相邻，合法）；③ 当 $c_i \ne c_{i-1}$ 时，取 $dp[i-1]$ 的最优方案并加上 $i$：该方案若含 $i-1$ 则因颜色不同而合法，若不含 $i-1$ 则更显然合法。∎

**引理 2（转移上界）**：任一合法方案的价值不超过上式右端。

**证明**：设 $S$ 是前 $i+1$ 间的合法方案。若 $i \notin S$，则 $value(S) \le dp[i-1]$。若 $i \in S$：当 $i-1 \notin S$ 时，$S \setminus \{i\}$ 是前 $i-1$ 间的合法方案，故 $value(S) \le nums[i] + dp[i-2]$；当 $i-1 \in S$ 时，由合法性必有 $c_i \ne c_{i-1}$，且 $S \setminus \{i\}$ 是前 $i$ 间的合法方案，故 $value(S) \le nums[i] + dp[i-1]$。∎

**定理**：$dp[i]$ 等于前 $i+1$ 间房屋能偷到的最大金额，故 $dp[n-1]$ 为答案。

**证明**：对 $i$ 归纳。$i=0$ 时只有偷/不偷，$dp[0]=nums[0]$ 正确。设 $dp[i-1]$、$dp[i-2]$ 正确，由引理 1、2 得 $dp[i]$ 的上下界相同，等于真实最优值。∎

## 6. 复杂度分析

- **时间**：$O(n)$。每个位置常数次比较与加法。
- **空间**：$O(n)$（保留 `dp` 数组）；用滚动变量可优化到 $O(1)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long rob(vector<int>& nums, vector<int>& colors) {
        int n = nums.size();
        vector<long long> dp(n, 0);
        dp[0] = nums[0];
        for (int i = 1; i < n; i++) {
            long long best = dp[i - 1];                                  // 不偷第 i 间
            best = max(best, (long long)nums[i] + (i >= 2 ? dp[i - 2] : 0));  // 隔一间偷
            if (colors[i] != colors[i - 1])                              // 相邻但颜色不同
                best = max(best, (long long)nums[i] + dp[i - 1]);
            dp[i] = best;
        }
        return dp[n - 1];
    }
};
```

### Python

```python
class Solution:
    def rob(self, nums: list[int], colors: list[int]) -> int:
        n = len(nums)
        dp = [0] * n
        dp[0] = nums[0]
        for i in range(1, n):
            best = dp[i - 1]
            best = max(best, nums[i] + (dp[i - 2] if i >= 2 else 0))
            if colors[i] != colors[i - 1]:
                best = max(best, nums[i] + dp[i - 1])
            dp[i] = best
        return dp[-1]
```

## 8. 边界情况与易错点

1. **$n = 1$**：只有一间，答案为 `nums[0]`，注意不要返回 0。
2. **全部同色**：退化为经典打家劫舍（不能偷相邻），答案由 $dp[i] = \max(dp[i-1], nums[i]+dp[i-2])$ 给出。
3. **全部异色**：可以全部偷，答案为 `sum(nums)`——此时 `nums[i] + dp[i-1]` 每步都被选中。
4. **溢出**：$n$ 与 $nums[i]$ 都到 $10^5$，答案可达 $10^{10}$，`int` 会溢出。
5. **误加"上一个偷的颜色"维度**：本题限制只看相邻下标，多一维既慢又容易写错。
6. **$i-2$ 越界**：$i=1$ 时用 0 代替 $dp[-1]$，Python 里 `dp[-1]` 会取到末尾元素，是隐蔽 bug，务必显式判断。
7. **相邻异色必须允许**：漏掉这一分支，示例 2 会得到 7 而不是 8。
