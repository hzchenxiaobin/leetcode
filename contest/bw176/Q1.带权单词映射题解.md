# LeetCode 带权单词映射 题解

## 1. 题目概述

- **标题 / 题号**：带权单词映射（#3838，easy）
- **链接**：https://leetcode.cn/problems/weighted-word-mapping/
- **来源**：LeetCode 第 176 场双周赛 Q1
- **难度**：简单
- **标签**：数组、字符串、模拟

**题意**：给定字符串数组 `words` 与长度 26 的权重数组 `weights`（`weights[i]` 是第 $i$ 个小写字母的权重）。单词的**权重**是它所有字符权重之和。对每个单词，把权重对 26 取模，再按**字母倒序**映射成一个小写字母（$0 \to$ `'z'`，$1 \to$ `'y'`，…，$25 \to$ `'a'`）。返回所有映射字符按顺序拼接的字符串。

**约束**：

- $1 \le words.length \le 100$
- $1 \le words[i].length \le 10$
- $weights.length = 26$，$1 \le weights[i] \le 100$

## 2. 示例

**示例 1**

```text
输入：words = ["abcd","def","xyz"]，
     weights = [5,3,12,14,1,2,3,2,10,6,6,9,7,8,7,10,8,9,6,9,9,8,3,7,7,2]
输出："rij"
解释：abcd → 5+3+12+14 = 34，34 % 26 = 8 → 'r'；
      def → 14+1+2 = 17 → 'i'；xyz → 7+7+2 = 16 → 'j'。
```

**示例 2**

```text
输入：words = ["a","b","c"]，weights 全为 1
输出："yyy"
解释：每个权重都是 1，1 % 26 = 1 → 'y'。
```

**示例 3**

```text
输入：words = ["abcd"]，weights = [7,5,3,4,3,5,4,9,4,2,2,7,10,2,5,10,6,1,2,2,4,1,3,4,4,5]
输出："g"
解释：7+5+3+4 = 19，19 % 26 = 19 → 'z' 往前数 19 位 = 'g'。
```

## 3. 解题思路

### 3.1 暴力思路

对每个单词扫一遍字符累加权重，取模后映射成字符——这已经是 $O(\sum |words[i]|)$ 的最优复杂度。本题没有算法难点，考察的是**字母与下标的换算**和**倒序映射**两个细节。

### 3.2 核心观察：倒序映射就是 `'z' - v`

![映射关系：权重和 mod 26 从字母表尾往前数](images/bw176_q1_reverse_map.svg)

权重和 $S$ 取模得 $v = S \bmod 26 \in [0, 25]$，倒序映射为

$$\text{char}(v) = \text{'z'} - v$$

等价写法：`chr(ord('z') - v)`，或先算 `'a' + (25 - v)`。两种写法都要保证下标映射 `weights[ch - 'a']` 的方向正确——**正序下标、倒序取字符**，这是最容易反的一步。

### 3.3 算法流程

```text
1. ans = ""
2. for w in words:
       S = Σ weights[ch - 'a']     （对 w 中每个字符）
       v = S mod 26
       ans += 'z' - v
3. 返回 ans
```

### 3.4 示例演算

![示例演算：三个单词的权重和与映射字符](images/bw176_q1_walkthrough.svg)

以示例 1 为例：

| 单词 | 字符权重 | 权重和 $S$ | $S \bmod 26$ | 映射字符 |
|------|----------|------------|---------------|----------|
| `abcd` | 5+3+12+14 | 34 | 8 | `r` |
| `def` | 14+1+2 | 17 | 17 | `i` |
| `xyz` | 7+7+2 | 16 | 16 | `j` |

拼接得 `"rij"`。验证 `r`：`'z' - 8 = 'r'` ✓。

## 4. 算法细节

1. **字符转下标**：`ch - 'a'`（C++）或 `ord(ch) - 97`（Python），不要写成 `ch` 的 ASCII 值。
2. **倒序映射**：目标字符是 `'z' - v`；若用 `'a' + (25 - v)` 也可，二者数值相同。
3. **累加用整型**：单字符权重 $\le 100$、长度 $\le 10$，和 $\le 1000$，`int` 足够；养成用 `long long` 的习惯也无害。
4. **取模时机**：可以对每个字符边加边模，也可以最后统一模；结果一致（模运算与加法同态）。
5. **拼接**：C++ 用 `ans.push_back(char)` 或 `ans += char`，注意 `+=` 数字会追加编码值，必须 `+= (char)`。
6. **单词非空**：长度 $\ge 1$，不会出现空串映射。

## 5. 正确性证明

**引理 1（权重计算正确）**：对每个单词 $w$，累加 `weights[w[j] - 'a']` 得到的 $S$ 恰为其定义的权重。

**证明**：权重定义即"所有字符权重之和"，按下标遍历逐项累加，无遗漏无重复。∎

**引理 2（映射正确）**：对 $v \in [0,25]$，字符 `'z' - v` 正是题意中"$v \to$ 从 z 倒序数第 $v$ 个字母"的结果。

**证明**：ASCII 中 `'z'` 为 122、`'a'` 为 97，且小写字母连续。$v=0$ 得 `'z'`；$v=25$ 得 `'a'$；$v$ 每增 1，字符编码减 1，正好在字母表上后退一位，符合"0→z, 1→y, …, 25→a"的定义。∎

**定理**：算法输出的字符串逐位等于题目要求的映射结果。

**证明**：由引理 1、2，第 $i$ 个单词映射出的字符正确；按 `words` 顺序拼接，位置与顺序均与题意一致，故整体正确。∎

## 6. 复杂度分析

- **时间**：$O(L)$，$L = \sum |words[i]| \le 1000$，每个字符 $O(1)$。
- **空间**：$O(|words|)$ 存结果字符串。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    string mapWordWeights(vector<string>& words, vector<int>& weights) {
        string ans;
        for (auto& w : words) {
            long long sum = 0;
            for (char c : w) sum += weights[c - 'a'];
            ans.push_back((char)('z' - (int)(sum % 26)));
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def mapWordWeights(self, words: list[str], weights: list[int]) -> str:
        ans = []
        for w in words:
            total = sum(weights[ord(c) - ord('a')] for c in w)
            ans.append(chr(ord('z') - total % 26))
        return "".join(ans)
```

## 8. 边界情况与易错点

1. **映射方向反了**：写成 `'a' + v` 会得到镜像结果（示例 1 会变成 `"ihg"` 之外的错误值）。
2. **`S` 已超过 26**：必须先取模再映射，否则会算出字母表之外的字符。
3. **C++ `+=` 的坑**：`ans += 'z' - v` 中的 `'z' - v` 是 `int`，会按数字追加为字符编码，需强制转 `char`。
4. **`weights` 的下标**：是 `ch - 'a'` 而不是 `ch`（后者会越界）。
5. **取模为 0**：映射为 `'z'`，不是空字符、也不是 `'a'`。
6. **单词长度 1**：直接取单字符权重，逻辑无特殊分支。
