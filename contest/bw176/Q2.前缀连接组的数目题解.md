# LeetCode 前缀连接组的数目 题解

## 1. 题目概述

- **标题 / 题号**：前缀连接组的数目（#3839，medium）
- **链接**：https://leetcode.cn/problems/number-of-prefix-connected-groups/
- **来源**：LeetCode 第 176 场双周赛 Q2
- **难度**：中等
- **标签**：数组、哈希表、字符串、计数

**题意**：给定字符串数组 `words` 与整数 $k$。若两个**不同下标**的单词满足 $a[0..k-1] = b[0..k-1]$（前 $k$ 个字符完全相同），称它们**前缀连接**。**连接组**是一组单词，其中**每一对**都前缀连接。返回"单词数 $\ge 2$"的连接组的数目。

注意：

- 长度 $< k$ 的单词无法参与任何组，直接忽略；
- 完全相同的字符串视为**不同**单词（按下标区分）。

**约束**：

- $1 \le words.length \le 5000$
- $1 \le words[i].length \le 100$
- $1 \le k \le 100$

## 2. 示例

**示例 1**

```text
输入：words = ["apple","apply","banana","bandit"], k = 2
输出：2
解释：前缀 "ap"：apple、apply；前缀 "ba"：banana、bandit。
```

**示例 2**

```text
输入：words = ["car","cat","cartoon"], k = 3
输出：1
解释："car" 与 "cartoon" 共享 3 位前缀；"cat" 独占，被排除。
```

**示例 3**

```text
输入：words = ["bat","dog","dog","doggy","bat"], k = 3
输出：2
解释：前缀 "bat" 有 2 个（两个 "bat" 是不同单词）；前缀 "dog" 有 3 个。
```

## 3. 解题思路

### 3.1 暴力思路

两两比较前 $k$ 个字符、再用并查集或图连通性连边，复杂度 $O(n^2 k)$：$n = 5000$ 时为 $2.5 \times 10^7 \times k$，偏大且完全没必要——"前缀相等"是一个**等价关系**，不需要两两比较。

### 3.2 核心观察：前缀相等是等价关系，组 = 等价类

![按前缀分桶：同一个桶里的任意两个单词都前缀连接](images/bw176_q2_prefix_buckets.svg)

设 $\text{pre}(w) = w[0..k-1]$（仅对 $|w| \ge k$ 定义）。则

$$a \text{ 与 } b \text{ 前缀连接} \iff \text{pre}(a) = \text{pre}(b)$$

这个关系满足自反性、对称性、**传递性**（字符串相等可以传递）。因此：

- 所有前缀相同的单词天然构成一个**完全图**，即一个合法的连接组；
- 不同的前缀之间不可能有任何边，故**极大连接组就是等价类**；
- 题目要求的"包含至少两个单词的连接组数目"就是"出现次数 $\ge 2$ 的不同前缀个数"。

于是只需一次分桶计数：`Counter(prefix)`，统计计数 $\ge 2$ 的桶数。

### 3.3 算法流程

![算法流程：过滤短词 → 取前缀 → 计数](images/bw176_q2_algorithm_flow.svg)

```text
1. cnt = 空哈希表
2. for w in words:
       若 len(w) < k: 跳过
       cnt[w[0..k-1]] += 1
3. 返回 { v : cnt[v] >= 2 } 的个数
```

### 3.4 示例演算

![示例演算：示例 3 的三个桶](images/bw176_q2_walkthrough.svg)

示例 3（`k = 3`）：

| 单词 | 下标 | 长度 $\ge 3$？ | 前缀 | 桶计数 |
|------|------|----------------|------|--------|
| `bat` | 0 | ✓ | `bat` | 1 |
| `dog` | 1 | ✓ | `dog` | 1 |
| `dog` | 2 | ✓ | `dog` | 2 |
| `doggy` | 3 | ✓ | `dog` | 3 |
| `bat` | 4 | ✓ | `bat` | 2 |

前缀 `bat` 与 `dog` 的计数都不小于 2，故答案为 2。示例 2 中 `cat` 的桶计数为 1，被排除；`car`/`cartoon` 的桶计数为 2，贡献 1。

## 4. 算法细节

1. **长度过滤**：`len(w) < k` 的单词**没有**长度 $k$ 的前缀，不能取 `w[:k]`（Python 会静默返回更短的串，导致误分组）。
2. **前缀长度恰为 $k$**：`len(w) == k` 时前缀就是它本身，可以参与分组。
3. **重复字符串按下标区分**：用计数而不是集合去重，同一个字符串出现两次就是 2 个成员。
4. **哈希键的选择**：Python 用 `str` 切片直接做键；C++ 用 `w.substr(0, k)`。$k \le 100$、$n \le 5000$，总哈希代价 $O(nk)$ 可接受。
5. **不必构造组**：只数"桶大小 $\ge 2$ 的桶个数"，不保存成员列表，空间 $O(n)$。
6. **`k = 1`**：按首字母分组，退化为"首字母计数"。

## 5. 正确性证明

**引理 1（等价关系）**：在长度 $\ge k$ 的单词集合上，关系"前 $k$ 个字符相同"是等价关系。

**证明**：自反：$w[0..k-1] = w[0..k-1]$；对称：等式可交换；传递：若 $a[0..k-1] = b[0..k-1]$ 且 $b[0..k-1] = c[0..k-1]$，则字符串相等具传递性，得 $a[0..k-1] = c[0..k-1]$。∎

**引理 2（组 = 等价类）**：一个单词集合是连接组，当且仅当它包含在某个等价类中；极大连接组恰为等价类。

**证明**：若集合 $G$ 中每对都前缀连接，则由引理 1 的传递性所有成员共享同一前缀，即 $G$ 含于一个等价类。反之，同一等价类中任意两词前缀相同，故前缀连接，整个等价类构成合法连接组。结合"含于"关系，极大者正是等价类。∎

**引理 3（计数正确）**：哈希表 `cnt` 中前缀 $p$ 的计数等于前缀为 $p$ 的单词个数。

**证明**：算法对每个长度 $\ge k$ 的单词恰好取其前缀并让对应计数加 1，长度 $<k$ 的单词被跳过且本就不可能属于任何组（它连 $k$ 位前缀都没有）。∎

**定理**：算法返回"成员数 $\ge 2$ 的极大连接组"的个数。

**证明**：由引理 2，极大连接组与等价类一一对应、与不同前缀一一对应；由引理 3，桶计数就是该等价类的成员数。因此"计数 $\ge 2$ 的桶个数"正是所求组数。题目按极大组计数（每个前缀只贡献 1），不存在把同一等价类的子集重复计入的问题。∎

## 6. 复杂度分析

- **时间**：$O(nk)$。每个单词取前缀 $O(k)$ 并做一次哈希插入（均摊 $O(k)$，因为哈希需要读取整个前缀）。
- **空间**：$O(nk)$ 最坏（所有前缀互不相同），即 $5000 \times 100$ 字符量级。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int prefixConnected(vector<string>& words, int k) {
        unordered_map<string, int> cnt;
        for (auto& w : words) {
            if ((int)w.size() < k) continue;
            cnt[w.substr(0, k)]++;
        }
        int ans = 0;
        for (auto& p : cnt) if (p.second >= 2) ans++;
        return ans;
    }
};
```

### Python

```python
class Solution:
    def prefixConnected(self, words: list[str], k: int) -> int:
        from collections import Counter
        cnt = Counter(w[:k] for w in words if len(w) >= k)
        return sum(1 for v in cnt.values() if v >= 2)
```

## 8. 边界情况与易错点

1. **短词过滤**：`len(w) < k` 必须跳过；Python 的 `w[:k]` 不会报错，会把短词和"前缀恰好是它本身"的长词混在一起，导致多数组。
2. **重复字符串是不同单词**：用计数而不是 `set`，否则示例 3 会少算。
3. **`k` 大于所有单词长度**：答案为 0。
4. **`k == 1`**：按首字母分组，逻辑不变。
5. **组必须"每一对"都连接**：不要误以为是"存在一条连接路径"（那样会退化成图连通分量，但本题因传递性两者其实等价——不过前提是只看前缀相等关系）。
6. **返回值是组数而非单词数**：示例 3 答案是 2 而不是 5。
