# LeetCode 将二叉搜索树变平衡 题解

## 1. 题目概述

- **标题 / 题号**：将二叉搜索树变平衡（#1382，medium）
- **链接**：https://leetcode.cn/problems/balance-a-binary-search-tree/
- **来源**：LeetCode 第 180 场周赛 Q3
- **难度**：中等
- **标签**：贪心、树、深度优先搜索、二叉搜索树、分治、二叉树

**题意**：给一棵二叉搜索树的根 `root`，返回一棵「平衡后」的二叉搜索树：节点值与原树完全相同（同一组值，不多不少），且每个节点的左右子树高度差不超过 1。合法答案不唯一，返回任意一种即可。

**约束**：

- 树中节点数目 $1 \le n \le 10^4$
- $1 \le \text{Node.val} \le 10^5$

> 💡 读题先抓「协议」：「返回任意一种」+「只要求值集合相同」——这两句话合起来等于宣布**原树的形状信息可以整包丢弃**。周赛里看到这种自由度，几乎就是「拍平重建」的免费通行证，完全没必要在原树上小心翼翼地旋转。

## 2. 示例

**示例 1**（右链 → 平衡）

```text
输入：root = [1,null,2,null,3,null,4]
输出：[2,1,3,null,null,null,4]
解释：这不是唯一的正确答案，[3,1,4,null,2,null,null] 也是一个可行的构造方案。
```

**示例 2**（已经平衡）

```text
输入：root = [2,1,3]
输出：[2,1,3]
解释：原树已满足平衡定义，原样返回即可。
```

**示例 3**（自拟：单节点下界）

```text
输入：root = [5]
输出：[5]
解释：n = 1 时既无左子树也无右子树，天然平衡，无需任何特判。
```

**示例 4**（自拟：左链，与示例 1 对称）

```text
输入：root = [4,3,null,2,null,1,null]
输出：[2,1,3,null,null,null,4]
解释：左链 4←3←2←1 与右链同病同治——中序展开后 nums 都是 [1,2,3,4]，重建结果自然相同。
```

## 3. 解题思路

### 3.1 暴力思路：AVL 式旋转

最直觉的做法是套用 AVL 的自平衡机制：要么把原树节点逐个拆下、重新插入一棵空 AVL 树；要么反复定位失衡节点做 LL/RR/LR/RL 旋转，直到全树平衡。两者都**正确**，但都不适合周赛 Q3 的节奏：

- **代码量大**：单旋、双旋、平衡因子维护，任何一处手滑就是 WA；
- **终止性难写**：「反复旋转直到平衡」需要额外论证不会死循环；
- **大材小用**：逐个插入是 $O(n \log n)$，且是为「**动态**插入」设计的；本题节点一次性全部给定，是**静态**数据，完全可以整树推倒重建，一步到位。

> ⚠️ 「静态数据用重建、动态数据用旋转」——识别问题类型本身就砍掉一半代码量。

### 3.2 核心观察：中序拍平 + 分治重建

![核心观察：中序遍历是形状与值集之间的桥梁，拍平成升序数组后取中点分治重建出平衡 BST](images/wc180_q3_flatten_rebuild_concept.svg)

两个观察把问题拆成两步热身题：

- **观察 1（形状可丢）**：BST 的中序遍历恒为**升序序列**。因此值集合相同的任意两棵 BST，中序遍历结果完全一致——原树退化成链还是完美平衡，对「值的信息」毫无影响。中序展开后，形状信息被有意识地清零，只剩一条唯一的升序数组。
- **观察 2（重建必平衡）**：对升序数组 $[lo, hi]$，**取中点为根**、左右区间递归建树。一方面左区间全部元素小于中点、右区间全部大于中点，BST 性质自动保持；另一方面左右区间长度差至多 1，天然产出「近似完美」的平衡树。

于是本题 = **LC 94（中序遍历）+ LC 108（有序数组转 BST）**，两步都是模板，串起来就是正解：

### 3.3 算法流程

![算法流程：中序展开得到升序数组，再分治建树：空区间返回 null，否则取下标中点建根、左右递归](images/wc180_q3_build_flow.svg)

1. **中序展开**：递归（左 → 根 → 右）遍历原树，把节点值收进 `nums`，得升序数组；
2. **分治建树** `build(lo, hi)`：
   - 若 $lo > hi$：空区间，返回 `null`；
   - 否则取 $mid = \lfloor (lo + hi) / 2 \rfloor$，`nums[mid]` 建为新根，左孩子 = `build(lo, mid-1)`，右孩子 = `build(mid+1, hi)`，返回该根；
3. **入口**：`build(0, n-1)` 即为答案。

### 3.4 示例演算

![示例演算：右链的调用栈展开、重建树与各节点子树高度和平衡因子验证](images/wc180_q3_walkthrough.svg)

以示例 1 为例，中序展开得 $nums = [1,2,3,4]$，分治调用栈自顶向下展开：

| 调用 | 区间 | $mid$ | 新根 |
|------|------|-------|------|
| `build(0, 3)` | `[1,2,3,4]` | 1 | **2** |
| `build(0, 0)` | `[1]` | 0 | **1** |
| `build(2, 3)` | `[3,4]` | 2 | **3** |
| `build(3, 3)` | `[4]` | 3 | **4** |

重建结果：根 2，左孩子 1，右孩子 3，3 的右孩子 4，层序恰为 `[2,1,3,null,null,null,4]`。逐节点验收平衡性：根 2 左右子树高度 $1, 2$，差 $1$；节点 3 左右高度 $0, 1$，差 $1$；叶节点差 $0$——处处 $\le 1$，且中序仍为 $1,2,3,4$。

## 4. 算法细节

1. **中序遍历的写法**：递归最短；链状树递归深度最坏 $10^4$，C++ 无压力，**Python 默认递归上限 1000 会爆栈**——要么 `sys.setrecursionlimit(10**5)`，要么改显式栈迭代（LC 94 模板）。
2. **中点是「下标中点」不是「值中点」**：$mid = (lo + hi) / 2$ 对下标取半。误写成 $(nums[lo] + nums[hi]) / 2$ 在值稀疏时会取到不存在的值，直接崩。
3. **左中点与右中点都对**：$\lfloor (lo+hi)/2 \rfloor$（左中点）与 $\lceil (lo+hi)/2 \rceil$（右中点）都正确——正确性证明（§5 引理 3）只用到「左右区间长度差 $\le 1$」这一条，两种取法都满足。甚至可以随机抖动。
4. **溢出防呆**：本题 $lo + hi \le 2 \times 10^4$，`int` 毫无风险；但与二分一致，写成 $lo + (hi - lo) / 2$ 是可移植的好习惯。
5. **新建节点 vs 复用原节点**：`new TreeNode(nums[mid])` 最直观；也可以中序遍历时把原节点指针存进数组、建树时直接改接指针，省掉新分配——本题反正已有 $O(n)$ 数组，新建即可，不为省这点内存冒险。
6. **两段递归深度要分开看**：中序遍历最坏深度 $O(n)$（链），建树深度 $O(\log n)$（区间逐层折半，$n = 10^4$ 时约 14 层）。栈空间大头在前者。

## 5. 正确性证明

记高度按**节点数**计（单节点高度 1，空树高度 0）；按边数计时长差相同，不影响结论。

**引理 1（中序升序）**：任意 BST 的中序遍历序列严格递增。

**证明**：对子树规模归纳。空树与单节点平凡。设根为 $r$，左、右子树的所有节点值分别严格小于、大于 $r$ 的值。归纳假设左、右子树的中序各自内部严格递增，而「左子树全体 $< r <$ 右子树全体」，拼接（左中序）$+\ r\ +$（右中序）整体严格递增。∎

**引理 2（重建保持 BST）**：对升序数组 $nums[lo..hi]$，`build(lo, hi)` 返回一棵 BST，且其中序恰为 $nums[lo..hi]$。

**证明**：对区间长度归纳。空区间返回空树，平凡。否则 $mid$ 把数组切成 $nums[lo..mid\!-\!1] < nums[mid] < nums[mid\!+\!1..hi]$（升序保证）。归纳假设左右递归结果分别是相应子区间的 BST 且中序一致；于是**左子树所有值 $<$ 根 $<$ 右子树所有值**（BST 的全局条件成立），且整树中序 = 左中序 $+$ 根 $+$ 右中序 $= nums[lo..hi]$。∎

**引理 3（重建平衡且最矮）**：记 $H(n)$ 为 `build` 在长度 $n$ 的区间上建出的子树高度，则 $H(n) = \lceil \log_2 (n+1) \rceil$；从而每个节点的左右子树高度差 $\le 1$，且重建树是 $n$ 节点 BST 中最矮的。

**证明**：对 $n$ 强归纳。$n = 0$ 时 $H(0) = 0 = \lceil \log_2 1 \rceil$。$n \ge 1$ 时左右区间长度为 $l = \lfloor (n-1)/2 \rfloor$ 与 $r = \lceil (n-1)/2 \rceil$，满足 $l \le r \le l + 1$。由归纳假设与 $\lceil \log_2 \rceil$ 的单调性，$\max(H(l), H(r)) = H(r)$。记整数 $x = n + 1 \ge 2$、$m = \lceil \log_2 x \rceil$，则 $2^{m-1} < x \le 2^{m}$，两边除以 2 并取整得 $2^{m-2} < \lceil x/2 \rceil \le 2^{m-1}$，故 $\lceil \log_2 \lceil x/2 \rceil \rceil = m - 1$。代入 $r + 1 = \lceil (n-1)/2 \rceil + 1 = \lceil (n+1)/2 \rceil = \lceil x/2 \rceil$：

$$H(n) = 1 + H(r) = 1 + (m - 1) = m = \lceil \log_2 (n+1) \rceil$$

**平衡性**：任一节点的左右子树对应长度 $l, r$（$r \le l + 1$）的区间，由已证闭式与 $r + 1 \le l + 2 \le 2(l+1)$（$l \ge 0$）：

$$H(r) = \lceil \log_2 (r+1) \rceil \le \lceil \log_2 2(l+1) \rceil = H(l) + 1$$

又 $l \le r$ 故 $H(l) \le H(r)$，于是高度差 $\le 1$。**最矮性**：$n$ 节点二叉树高度 $h$ 需满足 $n \le 2^h - 1$，即 $h \ge \lceil \log_2 (n+1) \rceil = H(n)$，重建树取到理论下界。∎

**定理**：算法返回的树 $T'$ 与原树 $T$ 值集合相同，且 $T'$ 是平衡 BST。

**证明**：中序遍历把 $T$ 的每个节点值恰收集一次，故 `nums` 的多重集等于 $T$ 的值多重集；引理 2 保证 $T'$ 是 BST 且中序恰为 `nums`，故值多重集一致；引理 3 保证 $T'$ 平衡。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。中序遍历每个节点进出各一次；`build` 的调用与「新建节点 + 空区间」一一对应，共 $2n + 1$ 次调用、每次均摊 $O(1)$。对照暴力 AVL 逐个插入的 $O(n \log n)$，重建法读一遍、建一遍，已是信息论下界（至少要读完每个节点）。
- **空间复杂度**：$O(n)$。`nums` 数组占大头；递归栈方面中序最坏 $O(n)$（链）、建树 $O(\log n)$。若复用原节点（§4 第 5 点），可省去新节点分配，但数组仍在，渐进不变。
- **工程取舍**：比赛时「新建节点」写起来最快最稳；面试被追问 $O(1)$ 辅助空间时才亮出 DSW 原地算法（见延伸思考）。

## 7. 参考代码

### C++

```cpp
class Solution {
    vector<int> nums;

    void inorder(TreeNode* cur) {
        if (!cur) return;
        inorder(cur->left);
        nums.push_back(cur->val);          // 左 → 根 → 右：升序收集
        inorder(cur->right);
    }

    TreeNode* build(int lo, int hi) {
        if (lo > hi) return nullptr;       // 空区间 → 空子树
        int mid = lo + (hi - lo) / 2;      // 下标中点（防溢出习惯写法）
        TreeNode* node = new TreeNode(nums[mid]);
        node->left = build(lo, mid - 1);
        node->right = build(mid + 1, hi);
        return node;
    }

public:
    TreeNode* balanceBST(TreeNode* root) {
        nums.clear();
        inorder(root);
        return build(0, (int)nums.size() - 1);
    }
};
```

### Python

```python
class Solution:
    def balanceBST(self, root: Optional[TreeNode]) -> Optional[TreeNode]:
        nums = []

        def inorder(node):
            if node:
                inorder(node.left)
                nums.append(node.val)
                inorder(node.right)
        inorder(root)

        def build(lo, hi):
            if lo > hi:
                return None
            mid = (lo + hi) // 2
            node = TreeNode(nums[mid])
            node.left = build(lo, mid - 1)
            node.right = build(mid + 1, hi)
            return node
        return build(0, len(nums) - 1)
```

> ⚠️ Python 版在 $n = 10^4$ 的链状树上递归深度过万，超出默认上限 1000——提交前 `sys.setrecursionlimit(200000)`，或把 `inorder` 改成显式栈迭代版（LC 94 模板）。

## 8. 边界情况与易错点

1. **单节点（$n = 1$）**：`build(0, 0)` 直接建根返回，无需特判；真正兜底的是 `lo > hi` 分支——叶子两侧的空区间全靠它接住，漏写必 RE。
2. **约束保证 $n \ge 1$，`root` 不会为空**；但代码让 `inorder` / `build` 天然容忍 `null`，无需画蛇添足的判空。
3. **左链、右链、任意畸形树统一处理**：中序展开后形状信息清零，这是重建法对「输入长什么样」完全鲁棒的根源——不存在按形状分类讨论的分支。
4. **下标中点 ≠ 值中点**：$mid$ 必须取 $(lo + hi)/2$；误用 $(nums[lo] + nums[hi])/2$ 在值稀疏时取到不存在的值。另一个常见笔误：`build(lo, mid)`（忘减 1）导致区间不缩、死循环爆栈。
5. **漏接递归返回值**：`node->left = build(...)` 的赋值漏掉 = 整棵子树丢失，输出层序缺节点。
6. **平衡是「每个节点」的性质**，不是只看根的左右高度差；自检最稳的姿势是拿 LC 110 的 `isBalanced` 对输出跑一遍，再对输出中序排序比对值集合——判题器本质上就这么验收「任意合法答案」。
7. **高度按节点数还是边数计，判定结果不变**（两种口径作差同值），不必纠结。

**延伸思考**：若被追问 $O(1)$ 辅助空间——**DSW（Day–Stout–Warren）算法**先把全树右旋成一条「藤」（vine），再按最大完美平衡树的规模 $2^{\lfloor \log_2 (n+1) \rfloor} - 1$ 逐轮左旋压缩，时间 $O(n)$、空间 $O(1)$，是纯指针操作的原地版（每日版题解 §5 有完整推演）；若给的不是 BST 而是普通二叉树，则必须先花 $O(n \log n)$ 排序再重建——本题的 BST 性质替你省掉了这次排序，这正是「中序遍历即有序」的价值所在。
