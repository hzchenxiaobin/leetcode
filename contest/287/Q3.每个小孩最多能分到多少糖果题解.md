# LeetCode 每个小孩最多能分到多少糖果 题解

## 1. 题目概述

- **标题 / 题号**：每个小孩最多能分到多少糖果（#2226，medium）
- **链接**：https://leetcode.cn/problems/maximum-candies-allocated-to-k-children/
- **来源**：LeetCode 第 287 场周赛 Q3
- **难度**：中等
- **标签**：数组、二分查找

**题意**：给定下标从 0 开始的整数数组 `candies`，`candies[i]` 表示第 $i$ 堆糖果的数量。每堆都可以**拆分成任意数量的子堆**，但拆开后**无法再合并**。要把糖果分给 $k$ 个小孩：每个小孩分到**相同数量**的糖果，且**至多拿走一堆**（子堆），允许部分糖果不被分配。求每个小孩能拿走的**最大**糖果数目。

**约束**：

- $1 \le \text{candies.length} \le 10^5$
- $1 \le \text{candies}[i] \le 10^7$
- $1 \le k \le 10^{12}$

> 💡 本题在本仓库另有[每日题解 2226](../../solution/2201-2300/2226_每个小孩最多能分到多少糖果.md)：主线同为「二分答案 + $O(n)$ 验证」，并统一了「最大可行 / 最小可行」二分模板与面试问答。本篇按**周赛复盘视角**展开，补齐可行性的双向刻画证明、二段性推导与赛时易错点（`long long` 溢出、答案为 0 的哨兵语义、整除方向）。

## 2. 示例

**示例 1**

```text
输入：candies = [5,8,6], k = 3
输出：5
解释：把 8 分成 5 和 3，把 6 分成 5 和 1，得到五堆 5、5、3、5、1；
      挑 3 堆大小为 5 的分给 3 个小孩。可以证明无法让每人超过 5 颗。
```

**示例 2**

```text
输入：candies = [2,5], k = 11
输出：0
解释：总共只有 7 颗糖果，11 个小孩每人 1 颗都凑不齐，答案为 0。
```

**补充示例 3（k = 1）**

```text
输入：candies = [5,8,6], k = 1
输出：8
解释：把最大的整堆直接给唯一的小孩，无需拆分。
```

**补充示例 4（总数恰好等于 k）**

```text
输入：candies = [3,3], k = 6
输出：1
解释：f(1) = 3 + 3 = 6 ≥ 6 刚好可行，但 f(2) = 1 + 1 = 2 < 6，每人只能分到 1 颗。
```

## 3. 解题思路

### 3.1 暴力思路

逐个尝试每份数 $m = 1, 2, \dots, \max(\text{candies})$：对每个 $m$ 检查能否分给 $k$ 个小孩，取最大的可行 $m$。单个 $m$ 的验证是 $O(n)$，整体 $O(n \cdot \max(\text{candies}))$，最坏 $10^5 \times 10^7 = 10^{12}$ 次操作，必然超时。

瓶颈在于**候选空间被线性扫描**：可行性关于 $m$ 是「一好俱好」的——某个 $m$ 可行则一切更小的 $m$ 都可行，某个 $m$ 不可行则一切更大的 $m$ 都不可行。这种单调结构没有被利用。

### 3.2 核心观察：份数 $f(m)$ 单调递减 → 二分答案

![核心观察：份数 f(m) 随每份数 m 单调递减，存在分界点 m*](images/wc287_q3_binary_search_model.svg)

把视角从「怎么切」换到「每份多大」：

- 一堆大小为 $c$ 的糖果切成每份 $m$ 颗，最多切出 $\lfloor c/m \rfloor$ 个**完整**子堆，余下 $c \bmod m$ 颗不足一份，只能丢弃；
- 定义**总份数** $f(m) = \sum_i \lfloor \text{candies}[i] / m \rfloor$，它就是「每份 $m$ 颗时最多能同时喂饱的小孩数」；
- 除数越大商越小：$m_1 \le m_2 \Rightarrow \lfloor c/m_1 \rfloor \ge \lfloor c/m_2 \rfloor$，逐项求和得 $f$ **单调不增**。

于是可行（$f(m) \ge k$）与不可行（$f(m) < k$）之间存在**分界点** $m^*$：

```text
m ≤ m*  →  f(m) ≥ k   每份小、份数多，够分（可行）
m > m*  →  f(m) < k   每份大、份数少，不够分（不可行）
```

「左侧全可行、右侧全不可行」正是二分查找所需的**二段性**：在 $[1, \max(\text{candies})]$ 上二分 $m$，每次 $O(n)$ 验证，求**最大的可行 $m$**。

> 💡 **识别信号**：求「最大的满足某条件的值」，且该条件关于候选值**单调**、单次验证便宜 → 二分答案。
>
> ⚠️ **上界取 $\max(\text{candies})$ 即可**：$m > \max(\text{candies})$ 时每堆 $\lfloor c/m \rfloor = 0$，$f(m) = 0 < k$（$k \ge 1$），必然不可行，无需更大的上界。

### 3.3 算法流程

![二分答案流程：可行记 ans 并右缩，不可行左缩](images/wc287_q3_binary_search_flow.svg)

关键在于**收缩方向**：本题求最大可行值，判定可行时**先记 `ans = mid` 再把左界右移**（`lo = mid + 1`），继续试探更大的 $m$；不可行则把右界左移（`hi = mid - 1`）。这与「求最小可行值」的二分（如 875 爱吃香蕉的珂珂）收缩方向正好相反。

### 3.4 示例演算

![示例演算：candies=[5,8,6], k=3 的二分过程](images/wc287_q3_walkthrough.svg)

以示例 1（`hi = max = 8`）走一遍：

- **第 1 轮** `[1,8]`，`mid=4`，$f(4) = 1+2+1 = 4 \ge 3$ ✓ → 可行，记 `ans=4`，`lo=5`；
- **第 2 轮** `[5,8]`，`mid=6`，$f(6) = 0+1+1 = 2 < 3$ ✗ → 不够分，`hi=5`；
- **第 3 轮** `[5,5]`，`mid=5`，$f(5) = 1+1+1 = 3 \ge 3$ ✓ → 可行，记 `ans=5`，`lo=6`；
- `lo=6 > hi=5`，区间空，循环结束，返回 `ans=5`。

示例 2 中 $f(1) = 7 < 11$，连 $m = 1$ 都不可行，二分全程走「不可行」分支，`ans` 保持初值 `0`，自然返回 `0`。

## 4. 算法细节

1. **验证函数**：`check(m)` 只需一趟求和 $\text{cnt} = \sum \text{candies}[i] / m$。整数除法天然向下取整，正是「完整子堆数」的语义，无需取整改写。
2. **二分区间**：`lo = 1`（$m = 0$ 无意义且会除零），`hi = max(candies)`（更大的 $m$ 每堆切不出一份，必然不可行）。
3. **哨兵初值 `ans = 0`**：若 $\sum \text{candies}[i] < k$，则 $f(1) < k$，全程无可行值，`ans` 不会被更新，直接返回 0——**无需单独特判**「总数不够」的情形。
4. **收缩与记录**：可行分支必须 `ans = mid` 后再 `lo = mid + 1`，保证 `ans` 始终是「已见过的最大可行 mid」；不可行分支 `hi = mid - 1` 由单调性保证不丢失可行值。
5. **溢出防护**：$k$ 与 $m = 1$ 时的 `cnt` 都可达 $10^{12}$，C++ 中 `k`（形参）与 `cnt` 必须用 `long long`；二分变量本身不超过 $10^7$，但统一 `long long` 最省心。返回值 $\le 10^7$，转 `int` 安全。

## 5. 正确性证明

**引理 1（可行性刻画）**：对 $m \ge 1$，「存在一种分法使 $k$ 个小孩各得 $m$ 颗」当且仅当 $f(m) = \sum_i \lfloor \text{candies}[i]/m \rfloor \ge k$。

**证明**：
（充分）从第 $i$ 堆切出 $\lfloor \text{candies}[i]/m \rfloor$ 个大小恰为 $m$ 的子堆，全局共得 $f(m)$ 个大小为 $m$ 的堆。$f(m) \ge k$ 时任取其中 $k$ 个分给 $k$ 个小孩：每人整拿一堆、恰好 $m$ 颗，符合「至多一堆」的限制，剩余堆与零头不分配即可。
（必要）设某种合法分法让 $k$ 个小孩各得 $m$ 颗。每个小孩恰好拿走一个（子）堆，故每人对应一个**大小至少为 $m$** 的子堆，且不同小孩对应的子堆来自原始堆的互不重叠部分。考察任一原始堆 $c$：若它服务了 $t$ 个小孩，则需从这堆中划出 $t$ 个互不重叠、大小各 $\ge m$ 的部分，故 $tm \le c$，即 $t \le \lfloor c/m \rfloor$。对所有堆求和，被服务的小孩数 $\le f(m)$；又必须服务全部 $k$ 人，故 $k \le f(m)$。∎

**引理 2（单调性与二段性）**：$f$ 单调不增；因此可行值集合（若非空）恰为 $\{1, 2, \dots, m^*\}$，其中 $m^* = \max\{\, m \ge 1 : f(m) \ge k \,\}$，且 $m \le m^*$ 时 $f(m) \ge k$、$m > m^*$ 时 $f(m) < k$。

**证明**：设 $m_1 \le m_2$。对每个 $c > 0$，除数增大商只减不增，即 $\lfloor c/m_1 \rfloor \ge \lfloor c/m_2 \rfloor$，逐项求和得 $f(m_1) \ge f(m_2)$。若可行值集合非空，取 $m^*$ 为其最大元；对任意 $m \le m^*$，$f(m) \ge f(m^*) \ge k$，可行；对任意 $m > m^*$，由 $m^*$ 的最大性 $f(m) < k$，不可行。∎

**定理**：算法返回 $\max\{\, m \ge 1 : f(m) \ge k \,\}$（集合为空时返回 0），即每个小孩可拿走的最大糖果数目。

**证明**：先证循环不变量：每轮迭代开始时，(a) `ans` 等于已发现候选中的最大可行值（初值 0 表示「尚未发现」），(b) 一切大于 `ans` 的可行值（若存在）都落在 $[\text{lo}, \text{hi}]$ 内。归纳：首轮 $[1, \max]$ 覆盖全部候选，成立。设某轮成立，考察 `mid`：

- 若 `cnt ≥ k`：由引理 1，`mid` 可行，`ans ← mid` 后 (a) 仍成立；`lo ← mid + 1` 只排除 `mid` 及更小的值，而大于 `ans` 的可行值必然 $>$ mid，仍在新区间内，(b) 成立。
- 若 `cnt < k`：由引理 2，一切 $m \ge \text{mid}$ 均不可行，`hi ← mid − 1` 不丢失任何可行值，(a)(b) 均保持。

循环每步区间长度至少减半，必然终止；结束时区间为空，由 (b) 不存在大于 `ans` 的可行值，`ans` 即全局最大可行值；若全程无可行值，`ans` 保持初值 0。结合引理 1，该值恰是题意所求的最大糖果数。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \log M)$，其中 $M = \max(\text{candies}) \le 10^7$。二分共 $O(\log M) \approx 24$ 轮，每轮一趟 $O(n)$ 求和验证，总计约 $2.4 \times 10^6$ 次整除，轻松通过。
- **空间复杂度**：$O(1)$，只用 `lo/hi/mid/cnt/ans` 常数个变量，不计输入数组。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int maximumCandies(vector<int>& candies, long long k) {
        long long lo = 1, hi = *max_element(candies.begin(), candies.end());
        long long ans = 0;                        // 哨兵：全程无可行值时返回 0
        while (lo <= hi) {
            long long mid = lo + (hi - lo) / 2;
            long long cnt = 0;                    // m=1 时可达 10^12，必须 long long
            for (int c : candies) cnt += c / mid; // 整除 = 完整份数，余料丢弃
            if (cnt >= k) {
                ans = mid;      // 可行：先记答案，再往右找更大
                lo = mid + 1;
            } else {
                hi = mid - 1;   // 不够分：每份太大，往左缩
            }
        }
        return (int)ans;
    }
};
```

### Python

```python
class Solution:
    def maximumCandies(self, candies: List[int], k: int) -> int:
        lo, hi, ans = 1, max(candies), 0
        while lo <= hi:
            mid = (lo + hi) // 2
            if sum(c // mid for c in candies) >= k:  # 能分给的小孩数
                ans = mid       # 可行：先记答案，再往右找更大
                lo = mid + 1
            else:
                hi = mid - 1    # 不够分：每份太大，往左缩
        return ans
```

## 8. 边界情况与易错点

1. **`long long` 溢出（最常见 WA）**：$k \le 10^{12}$，且 $m = 1$ 时 $\text{cnt} = \sum \text{candies}[i] \le 10^5 \times 10^7 = 10^{12}$，双双超出 32 位 `int`（约 $2.1 \times 10^9$）。C++ 中 `cnt` 必须声明为 `long long`，与已是 `long long` 的形参 `k` 比较；Python 整数无上限，无此问题。
2. **答案为 0 是合法输出**：$\sum \text{candies}[i] < k$ 时每人分不到 1 颗（示例 2）。用 `ans = 0` 哨兵让二分自然覆盖；千万别为「提速」把 `lo` 初值设成 0——$m = 0$ 会除零。
3. **上界别开大**：`hi = max(candies)` 足够；随手取 $10^7$ 甚至更大虽不至于错，但多跑几次必然不可行的迭代。
4. **整除方向**：`c / mid` 向下取整正是「完整份数」，零头丢弃；不要顺手改成向上取整——那是 875 珂珂「吃不满一小时也要一小时」的语义，本题零头直接扔掉。
5. **收缩方向写反**：求最大可行时若写成「可行则 `hi = mid − 1`」，会收敛到最小可行值甚至把 `ans` 记错。口诀——**答案在可行侧的更远处**：求最大就往右缩，求最小就往左缩。
6. **`k = 1` 的快速校验**：答案应恰为 $\max(\text{candies})$（整堆给唯一的小孩），可作对拍时的边界用例。
7. **别把「每人相同数量」误解为「每堆必须分完」**：允许剩余糖果不分配，验证函数只数完整份数，与剩余多少无关；同理不必贪心地「尽量少浪费」——浪费不影响可行性。

**延伸思考**：

- **变体 1（禁止拆堆）**：若每堆只能整堆给出或弃掉，`check` 变为「大小 $\ge m$ 的堆数 $\ge k$」，即 $g(m) = \#\{\, i : \text{candies}[i] \ge m \,\}$，$g$ 依然单调不增，仍可 $O(n \log M)$ 二分。
