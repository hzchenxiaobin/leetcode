# LeetCode 最长的美好子字符串 题解

## 1. 题目概述

- **标题 / 题号**：最长的美好子字符串（#1763，easy）
- **链接**：https://leetcode.cn/problems/longest-nice-substring/
- **来源**：LeetCode 第 46 场双周赛 Q1
- **难度**：简单
- **标签**：位运算、哈希表、字符串、分治、滑动窗口

**题意**：若字符串 $s$ 中**每种**出现过的字母，其大写与小写形式**同时**出现（如 `"abABB"` 中 `a/A`、`b/B` 齐全），则称 $s$ 是**美好字符串**。给定 $s$，返回其**最长**的美好**子字符串**；有多个答案时返回**最早出现**的；不存在则返回空串。

**约束**：

- $1 \le s.length \le 100$
- $s$ 只包含大写和小写英文字母

## 2. 示例

**示例 1**

```text
输入：s = "YazaAay"
输出："aAa"
解释：子串中仅含字母 a，其大小写形式同时出现。
```

**示例 2**

```text
输入：s = "Bb"
输出："Bb"
解释："Bb" 是美好字符串，整个字符串也是原串的子串。
```

**示例 3**

```text
输入：s = "c"
输出：""
解释：没有美好子字符串。
```

**示例 4**

```text
输入：s = "dDzeE"
输出："dD"
解释："dD" 与 "eE" 都是最长答案，返回出现更早的 "dD"。
```

## 3. 解题思路

### 3.1 暴力思路

枚举全部 $O(n^2)$ 个子串，对每个子串用哈希集合判定「出现的每个字母是否大小写齐全」——每次判定 $O(|\text{子串}|)$，总计 $O(n^3)$。$n \le 100$ 时约 $10^6$ 次字符操作，完全可过。$O(n^3)$ 是安全垫底，签到题的正确升级路线是：**能不能把判定从 $O(len)$ 降到 $O(1)$，并且让相邻子串共享判定状态？**

### 3.2 核心观察：大小写各压成一个 26 位掩码，相等 ⇔ 美好

![两个 26 位掩码：lower == upper 即美好](images/bw46_q1_bitmask_concept.svg)

把子串里出现的**小写字母集合**压成整数 `lower`（第 $k$ 位为 $1$ 表示字母 $k$ 出现过）、**大写字母集合**压成 `upper`。美好字符串的条件「每种出现的字母大小写同时出现」等价于：

$$lower = upper$$

（两侧都按「字母本身」对齐：`lower` 的 `a` 位与 `upper` 的 `A` 位对应同一字母。）判定从「遍历集合」变成**一次整数比较**。

于是固定左端点 $i$、右端点 $j$ 向右推进时，两个掩码只做**或等一位**的增量更新——每个子串的判定摊还 $O(1)$，总复杂度 $O(n^2)$。

### 3.3 算法流程

```text
best = 0, pos = -1
for i in 0..n-1:                    # 枚举左端点（升序保证"最早"）
    lower = upper = 0
    for j in i..n-1:                # 右端点向右扩
        c = s[j]
        若 c 是小写: lower  |= 1 << (c - 'a')
        否则:        upper |= 1 << (c - 'A')
        若 lower == upper 且 j - i + 1 > best:   # 严格更长才更新
            best = j - i + 1, pos = i
返回 s[pos : pos + best]（pos = -1 时返回空串）
```

「最早出现」由两层循环顺序 + **严格大于**才更新共同保证：同一长度的所有出现中，左端点最小者最先被遍历到，之后同长度的候选不再覆盖它。

### 3.4 示例演算

![示例 "YazaAay" 的枚举演算](images/bw46_q1_walkthrough.svg)

以 `s = "YazaAay"` 走查关键前缀（从 $i = 0$ 扩展）：`Y`（upper={Y}）、`Ya`（差 `a`）、`Yaz`（差 `a/z`）、`Yaza`、`YazaA`、`YazaAa`（lower={a}, upper={Y,A}，不等）、`YazaAay`（仍不等）。从 $i = 1$ 起：`a`、`aA`（lower={a}, upper={A}，不等）、`aAa`（lower={a}, upper={A}，**相等**！长度 3）——记录 `(best=3, pos=1)`。此后任何起点的更长美好子串都不存在，返回 `s[1..3] = "aAa"`，与示例一致。

## 4. 算法细节

1. **掩码位对齐**：`lower` 的第 $k$ 位与 `upper` 的第 $k$ 位必须指**同一个字母**（`'a'+k` 与 `'A'+k`），这样 `lower == upper` 才是「每个字母要么两侧都有、要么两侧都没有」。若不放心，也可用单掩码 + 方向计数，但两掩码比较最省。
2. **判空的自动性**：长度 $\ge 1$ 的子串至少含一个字母，`lower`、`upper` 不可能同时为 $0$；而 `lower == upper` 且非零意味着至少一个字母大小写齐全。空串不在枚举范围内，天然不参与。
3. **「最早」的实现**：只在 `j - i + 1 > best`（严格大于）时更新。若写成 `>=`，同长度的后来者会覆盖，破坏「最早出现」。
4. **复杂度台阶**：$O(n^3)$ 哈希判定 → $O(n^2)$ 位掩码 →（进阶）$O(26 \cdot n)$ 或 $O(n \log n)$ 分治。$n \le 100$ 下 $O(n^2)$ 就是最佳性价比。
5. **为什么分治可行**（替代思路）：任取一个「只有单侧形式出现的字母」$c$，美好子串必然完全落在 $c$ 的某个间隙里——以 $c$ 为分割点递归。没有这种字母时整串即美好。每层至少消耗一个字母，总 $O(n \cdot 26)$。

## 5. 正确性证明

**引理 1（掩码判定）**：子串 $t$ 美好 $\iff$ `lower(t) == upper(t)`。

**证明**：设 $L$ 为 $t$ 中出现的小写字母集合（按字母本体），$U$ 为 $t$ 中出现的大写字母对应的字母集合。`lower` 的第 $k$ 位为 $1 \iff$ 字母 $k \in L$；`upper` 的第 $k$ 位为 $1 \iff$ 字母 $k \in U$。两个整数相等 $\iff$ 每一位都相等 $\iff \forall k: (k \in L \Leftrightarrow k \in U)$ $\iff L = U$。而「每种出现的字母大小写同时出现」即：对任意字母 $k$，$k$ 以某种形式出现 $\Rightarrow k \in L$ 且 $k \in U$；这等价于 $L = U$（若 $k \in L$ 但 $k \notin U$，即小写出现而大写缺席，违反美好；两侧集合相等则互相蕴含）。∎

**引理 2（增量维护）**：固定左端点 $i$，从 $j-1$ 推进到 $j$ 时，`lower/upper` 按 $s[j]$ 的大小写置位后，恰为子串 $s[i..j]$ 的两个掩码。

**证明**：掩码只依赖「集合中出现过哪些字母」，与顺序无关；$s[i..j]$ 的集合是 $s[i..j-1]$ 的集合并上 $\{s[j]\}$，或等一位即可完成并集。∎

**定理（算法正确性）**：算法返回 $s$ 的最长美好子串中最早出现者。

**证明**：**枚举完备性**：任意子串 $s[i..j]$（$i \le j$）都会被 $(i, j)$ 这层循环精确考察一次，且由引理 1、2，其时的 `lower == upper` 判定恰为该子串的美好性，不漏不重。**最优性**：设最长美好子串长度为 $L^*$，任何被记录的候选都是真实美好子串（值域合法性），故 $best \le L^*$；而长度 $L^*$ 的某个出现在 $(i^*, j^*)$ 被考察时必触发更新（此时 $j - i + 1 = L^* \ge best$，若为严格大于则更新，若等于说明已被同长更早者占据），故终止时 $best = L^*$。**最早性**：归纳考察更新序列——每次更新要么提高 $best$（记录当时的 $(i, j)$），要么不发生。对固定长度 $L$，最早出现的 $(i_L, j_L)$ 在 $(i, j)$ 字典序（先 $i$ 后 $j$）遍历中先于一切同长度出现；而更新条件是严格更长，故当 $best$ 首次达到 $L$ 时记录的正是 $(i_L, j_L)$，之后同长度不再覆盖。终止时 $best = L^*$，记录的即最早的 $L^*$ 长度美好子串。∎

## 6. 复杂度分析

- **时间**：$O(n^2)$。两层循环各 $O(n)$，循环体内是位或与整数比较的 $O(1)$ 操作；$n \le 100$ 时约 $10^4$ 次基本操作。
- **空间**：$O(1)$。两个 26 位整数与常数个下标；不随 $n$ 增长（输出切片不算额外空间）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    string longestNiceSubstring(string s) {
        int n = (int)s.size(), best = 0, pos = -1;
        for (int i = 0; i < n; ++i) {
            int lower = 0, upper = 0;               // 子串 s[i..j] 的两类字母掩码
            for (int j = i; j < n; ++j) {
                char c = s[j];
                if (c >= 'a' && c <= 'z') lower |= 1 << (c - 'a');
                else                      upper |= 1 << (c - 'A');
                if (lower == upper && j - i + 1 > best) {
                    best = j - i + 1;
                    pos = i;
                }
            }
        }
        return pos < 0 ? "" : s.substr(pos, best);
    }
};
```

### Python

```python
class Solution:
    def longestNiceSubstring(self, s: str) -> str:
        n = len(s)
        best, pos = 0, -1
        for i in range(n):
            lower = upper = 0
            for j in range(i, n):
                c = s[j]
                if 'a' <= c <= 'z':
                    lower |= 1 << (ord(c) - 97)
                else:
                    upper |= 1 << (ord(c) - 65)
                if lower == upper and j - i + 1 > best:
                    best, pos = j - i + 1, i
        return "" if pos < 0 else s[pos:pos + best]
```

> 💡 两份代码均通过官方 4 组示例（含 `dDzeE` 的并列取早），并与「集合判定 + 长度降序枚举」的独立暴力实现随机对拍 150 组（大小写混合、单侧字母密集），结果全部一致。

## 8. 边界情况与易错点

1. **无解返回空串**：全小写 / 全大写 / 单字符（示例 3）都没有美好子串，`pos = -1` 分支必须显式处理。
2. **并列取早**：示例 4 的 `"dD"` 与 `"eE"` 同长，必须返回前者——更新条件写 `>` 而非 `>=` 是命门。
3. **掩码位别错位**：小写用 `c - 'a'`、大写用 `c - 'A'`，两者都归一到「第几个字母」；若大写也用 `c - 'a'` 会得到负数偏移，位移行为未定义（C++）或直接错位（Python）。
4. **非字母字符**：本题约束只有英文字母，代码用 `c >= 'a'` 二分大小写即可；若放开字符集，先判 `isalpha` 再分流，否则数字/符号会污染 `upper` 掩码。
5. **空子串不是候选**：不要把 `lower == upper == 0`（长度 0）当作美好——本题枚举范围 $j \ge i$ 已天然排除，改写循环时别把空串放进来。
6. **$n = 1$ 与 $n = 2$**：单字符必无解；两个字符要么同字母异大小写（有解），否则无解。
