# LeetCode 互质树 题解

## 1. 题目概述

- **标题 / 题号**：互质树（#1766，hard）
- **链接**：https://leetcode.cn/problems/tree-of-coprimes/
- **来源**：LeetCode 第 46 场双周赛 Q4
- **难度**：困难
- **标签**：树、深度优先搜索、数组、数学、数论

**题意**：给定 $n$ 个节点的树（无环连通无向图），节点编号 $0 \sim n-1$，根为 $0$，每个节点有值 $nums[i]$（$1 \le nums[i] \le 50$），边由 `edges` 给出。节点 $i$ 的祖先 = 从 $i$ 到根路径上的节点（不含 $i$ 自己）。返回 `ans[i]`：离节点 $i$ **最近**（深度最大）的祖先 $a$，且 $nums[a]$ 与 $nums[i]$ **互质**（$\gcd = 1$）；不存在则 $-1$。

**约束**：

- `nums.length == n`
- $1 \le nums[i] \le 50$
- $1 \le n \le 10^5$
- `edges.length == n - 1`，`edges[j].length == 2`
- $0 \le u_j, v_j < n$，$u_j \ne v_j$

## 2. 示例

**示例 1**

```text
输入：nums = [2,3,3,2], edges = [[0,1],[1,2],[1,3]]
输出：[-1,0,0,1]
解释：节点 0 无祖先；节点 1 的唯一祖先 0（gcd(3,2)=1）；
     节点 2 的祖先 1（gcd(3,3)=3，不行）、0（gcd(3,2)=1，取更近的祖先前先跳过 1）；
     节点 3 的祖先 1（gcd(2,3)=1，最近，取 1）。
```

**示例 2**

```text
输入：nums = [5,6,10,2,3,6,15], edges = [[0,1],[0,2],[1,3],[1,4],[2,5],[2,6]]
输出：[-1,0,-1,0,0,0,-1]
```

## 3. 解题思路

### 3.1 暴力思路

对每个节点 $u$，沿父链一路向上，逐个祖先检查 $\gcd(nums[u], nums[a]) = 1$，取第一个满足的。树退化成链时祖先链长 $O(n)$，总计 $O(n^2) \approx 10^{10}$ 次 gcd——超时。瓶颈在「对每个节点枚举它的全部祖先」；突破口藏在一个不起眼的约束里：**$nums[i] \le 50$**。

### 3.2 核心观察：枚举「值」而不是枚举「祖先」——50 条祖先栈

![DFS 路径上按值维护祖先栈，查询时枚举互质的值取最深的栈顶](images/bw46_q4_ancestor_stacks.svg)

DFS 自根向下时，「节点 $u$ 的祖先集合」恰好是**当前 DFS 路径**（不含 $u$）。按值分桶：对每个值 $v \in [1, 50]$ 维护一条**祖先链栈** `st[v]`——当前路径上所有值为 $v$ 的节点按深度递增存放，**栈顶即该值在路径上的最近祖先**。

回答 $u$ 的询问时，不去枚举祖先，而是**枚举值**：候选互质祖先的值 $v$ 必与 $x = nums[u]$ 互质，这样的 $v$ 至多 50 个（预计算 `cop[x]` 列表）；对每个 $v \in cop[x]$ 看 `st[v]` 的栈顶（若非空），所有栈顶里**深度最大**的就是最近互质祖先：

$$ans[u] = \arg\max_{v:\ \gcd(v, x)=1,\ st[v] \ne \emptyset} depth\big(\text{top}(st[v])\big)$$

每次询问 $O(50)$ 次栈顶比较，DFS 进入 / 离开时对 `st[nums[u]]` 压栈 / 弹栈各一次，总复杂度 $O(50n)$。

> 💡 为什么「最近的互质祖先」可以按值分别取栈顶再合并：每个节点恰有一个值、只属于一条栈；深度最大的候选就是路径上离 $u$ 最近的候选——**不同值的栈顶之间互不并列**（同深度 ⇔ 同节点 ⇔ 同值），不会出现平局歧义。

### 3.3 状态设计与进出栈时机

![查询流程：先查后压、离开弹栈](images/bw46_q4_query_flow.svg)

DFS 的进出时机是正确性的关键：

```text
预计算 cop[x] = [v : gcd(x, v) == 1]（x, v ∈ 1..50）

DFS(u)：
    x = nums[u]
    # (A) 先回答询问——此刻 st 里只有 u 的真祖先
    ans[u] = st[v] 的栈顶中深度最大者（v ∈ cop[x]，栈空跳过），无则 -1
    # (B) 再把 u 自己入栈
    st[x].push((depth[u], u))
    for v in adj[u] 且 v ≠ parent:  DFS(v)
    # (C) 离开 u：恢复现场
    st[x].pop()
```

- **先查后压**（A 在 B 前）：保证 $u$ 不是自己的祖先——若先压再查，值为 $1$ 的节点会因 $\gcd(1, 1) = 1$ 把自己当「祖先」。
- **离开弹栈**（C）：回溯后路径恢复为「$u$ 的父辈路径」，后续兄弟子树的询问不受污染。
- **递归深度**：链状树深度达 $10^5$，C++ 默认栈空间紧张、Python 必爆递归上限，用**显式栈迭代 DFS**（进入时压 `st`、邻居扫完时弹）。

### 3.4 示例演算

![示例 2 的树与栈快照演算](images/bw46_q4_walkthrough.svg)

示例 2：`nums = [5,6,10,2,3,6,15]`。以节点 $4$（值 $3$）为例，DFS 进入 $4$ 时路径为 $0(5) \to 1(6) \to 4(3)$：

| $v \in cop[3]$ | $st[v]$ 栈顶 | 深度 |
|-----------------|--------------|------|
| $1$ | 空 | — |
| $2$ | 节点 $3$？否——**不在路径上**，$st[2]$ 空 | — |
| $4$ | 空 | — |
| $5$ | 节点 $0$ | $0$ |
| $7, 8, \dots$ | 空 | — |

$st[5]$ 栈顶是节点 $0$（深度 $0$），其余全空 $\Rightarrow ans[4] = 0$ ✓。节点 $6$（值 $15$）：$cop[15]$ 含 $\{1,2,4,7,\dots\}$，路径 $0(5) \to 2(10) \to 6$，$st[5]$ 栈顶节点 $0$ 但 $\gcd(15,5)=5 \ne 1$——$5 \notin cop[15]$ 不枚举它；$st[2]$、$st[4]$ 等全空 $\Rightarrow ans[6] = -1$ ✓（对照官方输出）。

## 4. 算法细节

1. **互质表预计算**：$50 \times 50$ 双重循环 + 欧几里得 `gcd`，或埃氏筛式预处理；每次询问只遍历 `cop[nums[u]]`（至多 50 个值），不再现场算 gcd。
2. **栈存什么**：`st[v]` 的元素存 `(depth, node)` 二元组——比较深度取最近，节点号用于回填 `ans`。同值节点在路径上深度严格递增，栈天然有序。
3. **迭代 DFS 的三态控制**：每个栈帧保存「节点 / 下一个待试邻居下标 / 父节点」。首次弹出帧（下标为 0）时做「查 + 压」，邻居耗尽时做「弹 `st` + 出栈」——等价于递归版的进入 / 离开。
4. **根的处理**：根 $0$ 进入时各栈全空，`ans[0] = -1` 自动成立；根也照常压栈供子孙查询。
5. **值的特殊性**：$\gcd(1, x) = 1$ 对一切 $x$ 成立，故路径上任何值为 $1$ 的祖先都是候选；反过来值为 $1$ 的节点会与值为 $1$ 的子孙「互质」——这是「先查后压」必须严格的又一佐证。
6. **邻接表**：双向加边；DFS 用 `parent` 数组或传入父节点防止走回头路（树无环，二者等价）。

## 5. 正确性证明

**引理 1（栈的内容 = 路径上该值的祖先）**：DFS 首次进入节点 $u$、执行询问的瞬间，`st[v]` 恰包含「根到 $u$ 路径上所有值为 $v$ 的节点」，且自底向上按深度递增排列（栈顶最深）。

**证明**：对 DFS 的进入 / 离开配对归纳：路径从根出发，每进入节点 $w$ 压入 $st[nums[w]]$，每离开 $w$ 弹出同一栈——「进入即压、离开即弹」保证任意时刻栈内元素恰为**当前路径**上该值的节点（不在路径上的节点必已离开，其元素已弹出）。进入 $u$ 时当前路径 = 根到 $u$ 的祖先链。压入顺序沿路径由浅入深，故栈内深度递增，栈顶最深。∎

**引理 2（询问的覆盖与正确选取）**：设 $x = nums[u]$。$u$ 的互质祖先集合 $S = \{a \in anc(u) : \gcd(nums[a], x) = 1\}$ 非空时，其最近者（深度最大者）$a^* = \arg\max_{a \in S} depth(a)$ 必被算法找到。

**证明**：按值分解 $S = \bigcup_{v \in cop[x]} S_v$，$S_v$ 为路径上值为 $v$ 的互质祖先（$v$ 与 $x$ 互质时 $S_v$ 全体元素都互质）。由引理 1，$S_v$ 中深度最大者恰为 $st[v]$ 栈顶（若 $S_v$ 非空）；算法遍历所有 $v \in cop[x]$，对非空栈取栈顶深度，取最大即 $\max_{a \in S} depth(a)$。深度最大者唯一（$u$ 的祖先在每个深度上至多一个节点），故选取无歧义，返回的正是 $a^*$。$S = \emptyset$ 时所有相关栈皆空，得 $-1$。∎

**引理 3（迭代 DFS 的等价性）**：显式栈实现按「首次弹出帧 = 进入、邻居耗尽 = 离开」的节奏，`st` 数组在每个询问时刻的内容与递归版完全一致。

**证明**：迭代版栈中从底到顶的帧恰为当前路径（未离开的节点），首次弹出帧时执行压栈，其后代全部处理完毕（帧回到栈顶且下标耗尽）时执行弹栈——与递归版调用 / 返回的时序逐事件对应，`st` 的状态序列一致。∎

**定理（算法正确性）**：算法返回的 `ans` 满足题目定义：`ans[i]` 为与 `nums[i]` 互质的最近祖先，不存在时为 $-1$。

**证明**：由引理 3，迭代实现忠实复现递归 DFS 的栈维护；由引理 1，每个询问时刻各栈内容正确；由引理 2，每个询问的返回值为该节点互质祖先中深度最大者或 $-1$，与「离 $i$ 最近的互质祖先」（唯一）定义一致。 DFS 访问每个节点恰一次并即时回答询问，故全部 $n$ 个询问均正确。∎

## 6. 复杂度分析

- **时间**：$O(50 \times 50 + 50n + n)$ ≈ $O(50n)$。互质表预计算 $O(50^2)$（欧几里得 gcd 约 $O(\log)$，总量 $O(50^2 \log 50)$ 可忽略）；DFS 每个节点一次压栈、一次弹栈、一次 $O(|cop[nums[u]]|) \le O(50)$ 的询问。$n = 10^5$ 时约 $5 \times 10^6$ 次操作。
- **空间**：$O(n + 50)$。邻接表 $O(n)$；`st` 总元素数任意时刻 $\le$ 当前路径长 $\le n$，且各值合计至多 $n$ 个；显式 DFS 栈深 $\le n$；`parent / depth / ans` 各 $O(n)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> getCoprimes(vector<int>& nums, vector<vector<int>>& edges) {
        int n = (int)nums.size();
        vector<vector<int>> adj(n);
        for (const vector<int>& e : edges) {
            adj[e[0]].push_back(e[1]);
            adj[e[1]].push_back(e[0]);
        }
        vector<vector<int>> cop(51);                    // cop[v]：与 v 互质的值列表
        for (int a = 1; a <= 50; ++a)
            for (int b = 1; b <= 50; ++b)
                if (gcd(a, b) == 1) cop[a].push_back(b);
        vector<int> ans(n, -1);
        vector<vector<pair<int,int>>> st(51);           // st[v]：路径上值为 v 的祖先栈
        vector<int> parent(n, -1), depth(n, 0), pos(n, 0), stk(n);
        int top = 0;
        stk[top++] = 0;                                 // 迭代 DFS，根 0 入栈
        while (top > 0) {
            int u = stk[top - 1];
            if (pos[u] == 0) {                          // 首次进入 u：先查再入栈
                int best = -1, bestDepth = -1;
                for (int v : cop[nums[u]])
                    if (!st[v].empty() && st[v].back().first > bestDepth) {
                        bestDepth = st[v].back().first;
                        best = st[v].back().second;
                    }
                ans[u] = best;
                st[nums[u]].push_back({depth[u], u});
            }
            if (pos[u] < (int)adj[u].size()) {
                int w = adj[u][pos[u]++];
                if (w == parent[u]) continue;           // 不走回头路
                parent[w] = u;
                depth[w] = depth[u] + 1;
                stk[top++] = w;
            } else {                                    // 离开 u：出栈
                st[nums[u]].pop_back();
                --top;
            }
        }
        return ans;
    }
};
```

### Python

```python
from math import gcd


class Solution:
    def getCoprimes(self, nums: list[int], edges: list[list[int]]) -> list[int]:
        n = len(nums)
        adj = [[] for _ in range(n)]
        for u, v in edges:
            adj[u].append(v)
            adj[v].append(u)
        cop = [[] for _ in range(51)]          # cop[v]：与 v 互质的值列表
        for a in range(1, 51):
            for b in range(1, 51):
                if gcd(a, b) == 1:
                    cop[a].append(b)
        ans = [-1] * n
        st = [[] for _ in range(51)]           # st[v]：路径上值为 v 的祖先栈
        depth = [0] * n
        stack = [[0, 0, -1]]                   # (节点, 下一个邻居下标, 父节点)
        while stack:
            u, i, p = stack[-1]
            if i == 0:                        # 首次进入 u：先查再入栈
                bd, best = -1, -1
                for v in cop[nums[u]]:
                    if st[v] and st[v][-1][0] > bd:
                        bd, best = st[v][-1]
                ans[u] = best
                st[nums[u]].append((depth[u], u))
            if i < len(adj[u]):
                stack[-1][1] += 1
                w = adj[u][i]
                if w != p:
                    depth[w] = depth[u] + 1
                    stack.append([w, 0, u])
            else:                             # 离开 u：出栈
                st[nums[u]].pop()
                stack.pop()
        return ans
```

> 💡 两份代码均通过官方 2 组示例，并与「BFS 建父指针 + 每节点沿父链上溯」的独立暴力实现随机对拍 150 组（含链状树、互质值密集、单值树），且在 $n = 10^5$ 的链状树上实测无爆栈，结果全部一致。

## 8. 边界情况与易错点

1. **先查后压**：把「压栈」放在「询问」之前，值为 $1$ 的节点会把**自己**当成互质祖先（$\gcd(1,1)=1$）。树根也会被自己污染（根无祖先，答案应为 $-1$）。
2. **离开时弹栈**：漏掉回溯弹出会让兄弟子树把别人的祖先误认为自己的（祖先必须是「到根路径」上的，不是「到某公共祖先」上的）。
3. **递归爆栈**：$n = 10^5$ 的链树递归深度 $10^5$，C++ 默认栈 8MB 勉强、Python 直接 `RecursionError`。迭代 DFS 是刚需；若坚持递归，Python 需 `setrecursionlimit` 且仍可能栈溢出。
4. **「最近」按深度，不是按值**：多条栈都非空时必须比深度取最大，不能随便取第一个非空的 `cop` 值。
5. **值 1 的特殊性**：$1$ 与所有数互质——路径上有值为 $1$ 的节点时它必是候选；同时注意 $\gcd(x, x) = x$，同值祖先在 $x > 1$ 时**不互质**、在 $x = 1$ 时**互质**，别在 `cop[x]` 里漏掉 $x=1$ 的情形（双重循环自然处理，手写互质表容易漏）。
6. **邻接表双向加边**：只加单向边会在迭代 DFS 里漏访问整个子树。
7. **边表长度 $n - 1$**：`edges` 可为空（$n = 1$，单节点树），代码不应假设至少一条边——答案 `[-1]`。
