# LeetCode 统计每个顶点的度 题解

## 1. 题目概述

- **标题 / 题号**：统计每个顶点的度（#3898，easy）
- **链接**：https://leetcode.cn/problems/find-the-degree-of-each-vertex/
- **来源**：LeetCode 第 497 场周赛 Q1
- **难度**：简单
- **标签**：图、数组、矩阵

**题意**：给定 $n \times n$ 的 0-1 矩阵 `matrix`，作为 $n$ 个顶点（编号 $0$ 到 $n-1$）的无向图**邻接矩阵**：`matrix[i][j] = 1` 表示 $i$、$j$ 之间有边。顶点的**度**（degree）是与它相连的边数。返回长度为 $n$ 的数组 `ans`，`ans[i]` 为顶点 $i$ 的度。

**约束**：

- `1 <= n == matrix.length == matrix[i].length <= 100`
- `matrix[i][i] == 0`（无自环）
- `matrix[i][j]` 仅为 `0` 或 `1`（无重边，简单图）
- `matrix[i][j] == matrix[j][i]`（无向，矩阵对称）

## 2. 示例

**示例 1**

```text
输入：matrix = [[0,1,1],[1,0,1],[1,1,0]]
输出：[2,2,2]
解释：三个顶点构成三角形，每个顶点都与其余两个顶点相连，度均为 2。
```

**示例 2**

```text
输入：matrix = [[0,1,0],[1,0,0],[0,0,0]]
输出：[1,1,0]
解释：只有顶点 0 与顶点 1 之间有一条边；顶点 2 是孤立点，度为 0。
```

**示例 3**

```text
输入：matrix = [[0]]
输出：[0]
解释：图中只有一个顶点且没有任何边，度为 0。
```

## 3. 解题思路

### 3.1 朴素思路：按定义逐点数邻居

按度的定义，对每个顶点 $i$ 枚举所有 $j$，若 `matrix[i][j] == 1` 则邻居计数加一——这就是 $O(n^2)$ 的双重循环。注意**输入本身就有 $n^2$ 个数**，任何算法至少要把矩阵读完，即下界就是 $O(n^2)$。所以这个"暴力"已经是**最优解**，签到题的目标是把从题面到代码的路径压到最短：一眼看出「度 = 行和」，然后直接写。

### 3.2 核心观察：度 = 行和

$$\deg(i) = \sum_{j=0}^{n-1} \text{matrix}[i][j]$$

即**顶点 $i$ 的度就是第 $i$ 行中 `1` 的个数**。这个等式由题目的三个保证共同支撑：

- **无自环**（`matrix[i][i] == 0`）：对角线项贡献为 $0$，不会把顶点自己数进去；
- **无重边**（0-1 矩阵）：每个邻居 $j$ 恰好贡献 $1$，不会重复计数；
- **对称性**（`matrix[i][j] == matrix[j][i]`）：行和等于列和，取哪个都对。

![核心观察：度等于行和](images/wc497_q1_row_sum_concept.svg)

### 3.3 算法流程

![逐行求和流程图](images/wc497_q1_algorithm_flow.svg)

1. 初始化答案数组 `ans`，遍历行号 $i$ 从 $0$ 到 $n-1$
2. 对第 $i$ 行求和（数其中 `1` 的个数），写入 `ans[i]`
3. 遍历结束后返回 `ans`

### 3.4 示例演算

以示例 2 为例，逐行数 `1`：

![示例 2 逐行求和演算](images/wc497_q1_example_walkthrough.svg)

第 0 行有一个 `1`（邻居是 1），第 1 行有一个 `1`（邻居是 0），第 2 行全 `0`（孤立点），得 `ans = [1, 1, 0]`，与图上直接数边的结果一致。

## 4. 算法细节

1. **一行一算**：外层循环行号，内层对该行求和；Python 直接 `sum(row)`，C++ 可用 `std::accumulate` 或手写内层循环
2. **行和 vs 列和**：由对称性两者相等，取行和缓存更友好（顺序访问内存）
3. **对角线无需特判**：题目保证 `matrix[i][i] == 0`，直接加也不会错
4. **自检技巧**：由握手定理 $\sum_i \deg(i) = 2|E|$，答案数组的总和应等于矩阵中 `1` 的总个数（每个 `1` 恰被行和统计一次），且必为偶数
5. **返回顺序**：按顶点编号 $0..n-1$ 依次填入，天然满足题目要求的顺序

## 5. 正确性证明

**引理 1**：对任意 $j \ne i$，`matrix[i][j] = 1` 当且仅当无向图中存在边 $\{i, j\}$。

**证明**：这是邻接矩阵的定义。0-1 取值进一步说明任一顶点对之间至多一条边（简单图）。∎

**引理 2**：集合 $\{j : j \ne i,\ \text{matrix}[i][j] = 1\}$ 与"和顶点 $i$ 关联的边"的集合之间存在双射。

**证明**：定义映射 $j \mapsto \{i, j\}$。由引理 1，每个满足条件的 $j$ 都对应一条真实存在的边；反过来，任何与 $i$ 关联的边必形如 $\{i, j\}$ 且 $j \ne i$（无自环保证不存在 $\{i,i\}$），其对应的 $j$ 满足 `matrix[i][j] = 1`。无重边保证不同的 $j$ 映射到不同的边，故该映射是双射。∎

**定理**：$\text{ans}[i] = \sum_{j=0}^{n-1} \text{matrix}[i][j]$ 等于顶点 $i$ 的度。

**证明**：和式遍历所有 $j$。对角线项 `matrix[i][i] = 0` 贡献为 $0$，故和式恰好等于集合 $\{j \ne i : \text{matrix}[i][j] = 1\}$ 的大小。由引理 2，该大小等于与 $i$ 关联的边数，即度的定义。∎

**推论（握手定理）**：$\sum_{i=0}^{n-1} \text{ans}[i]$ 等于矩阵中 `1` 的总个数 $= 2|E|$，必为偶数——可作为调试时的快速校验。

## 6. 复杂度分析

- **时间复杂度**：$O(n^2)$。$n \le 100$，至多 $10^4$ 次加法。输入规模即为 $n^2$，任何算法都需读完整个矩阵，因此这已是渐进最优。
- **空间复杂度**：$O(1)$。除返回的答案数组外仅用常数个变量。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    vector<int> findDegrees(vector<vector<int>>& matrix) {
        int n = matrix.size();
        vector<int> ans(n, 0);
        // 顶点 i 的度 = 第 i 行 1 的个数（行和）
        for (int i = 0; i < n; i++) {
            int deg = 0;
            for (int j = 0; j < n; j++) {
                deg += matrix[i][j];
            }
            ans[i] = deg;
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def findDegrees(self, matrix: list[list[int]]) -> list[int]:
        # deg(i) = 第 i 行 1 的个数，逐行求和即可
        return [sum(row) for row in matrix]
```

## 8. 边界情况与易错点

1. **单点图**：`n = 1` 时 `matrix = [[0]]`，行和自然为 $0$，返回 `[0]`，无需特判。
2. **孤立点**：某行全 `0` ⇒ 度为 $0$（示例 2 的顶点 2），行和自动处理。
3. **不要把"矩阵中 1 的总数除以 2"当答案**：那是边数 $|E|$，不是每个点的度。每个点的度必须逐行单独统计。
4. **不要"行和 + 列和"再忘除 2**：对称矩阵行和已经是度；若误把行、列加起来得到的是 $2\deg(i)$，忘记除以 2 会整体翻倍（虽然本题写了除以 2 也能对，但纯属多余）。
5. **对角线与自环**：本题保证 `matrix[i][i] == 0`。若换成一般输入，需跳过 $j = i$；且按图论惯例自环使度增加 $2$ 而非 $1$，不能简单套行和。
6. **有向图混淆**：邻接矩阵不对称时，行和是**出度**、列和是**入度**。本题是无向图才允许只看行和。
7. **完全图**：所有度均为 $n-1$，行和恰好为 $n-1$，可作对拍样例。

**延伸思考**：

- 若输入改为**边列表**（`edges`，长度 $m$），度统计只需对每条边两端各加一，时间 $O(m) \ll O(n^2)$——稀疏图下应避免邻接矩阵表示（空间 $O(n^2)$ 不可承受）。
- **度序列与可图化**：握手定理 $\sum \deg = 2|E|$ 给出度序列合法的必要条件；Havel-Hakimi 算法可进一步判定一个度序列能否对应一个简单无向图。
- **加权图 / 多重图**：邻接矩阵存权值（或重边条数）时，"度"可推广为非零项计数或边权之和，行遍历的框架不变。
