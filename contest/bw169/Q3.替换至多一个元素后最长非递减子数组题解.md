# LeetCode 替换至多一个元素后最长非递减子数组 题解

## 1. 题目概述

- **标题 / 题号**：替换至多一个元素后最长非递减子数组（#3738，medium）
- **链接**：https://leetcode.cn/problems/longest-non-decreasing-subarray-after-replacing-at-most-one-element/
- **来源**：LeetCode 第 169 场双周赛 Q3
- **难度**：中等
- **标签**：数组、动态规划

**题意**：给定整数数组 `nums`，允许把**至多一个**元素改成**任意**整数（也可以不改）。问修改后能得到的**最长非递减子数组**长度。注意替换的是整个数组里的一个位置，最长子数组只是「受益者」，被替换的元素不一定要落在答案子数组里。

**约束**：

- $1 \le nums.length \le 10^5$
- $-10^9 \le nums[i] \le 10^9$

## 2. 示例

**示例 1**

```text
输入：nums = [1,2,3,1,2]
输出：4
解释：把 nums[3] = 1 换成 3，得到 [1,2,3,3,2]，最长非递减子数组 [1,2,3,3] 长度为 4。
```

**示例 2**

```text
输入：nums = [2,2,2,2,2]
输出：5
解释：原数组本身就非递减，整段长度 5 即为答案。
```

## 3. 解题思路

### 3.1 暴力思路

枚举「替换位置 $k$」与「替换后的值 $v$」，再扫一遍求最长非递减段：$O(n^2 \cdot V)$ 甚至无穷（$v$ 可取任意整数）。即便只考虑「替换 $k$ 后必须以 $k$ 为中心」的候选段，也要 $O(n^2)$ 枚举左右端点并逐段检查，$n = 10^5$ 时完全不可行。

关键是把「检查某段是否只差一个元素」这件事变成常数时间，这需要**前缀 / 后缀最长非递减段**的预处理。

### 3.2 核心观察：前缀 + 后缀，中间只缝一个洞

![前缀 pre 与后缀 suf：以每个位置结尾 / 开头的最长非递减段](images/bw169_q3_prefix_suffix.svg)

定义两个 DP 数组：

- $pre[i]$：以 $i$ **结尾**的最长非递减子数组长度。
- $suf[i]$：以 $i$ **开头**的最长非递减子数组长度。

转移极其直接：

$$pre[i] = \begin{cases} pre[i-1] + 1, & i > 0 \text{ 且 } nums[i-1] \le nums[i] \\ 1, & \text{否则} \end{cases}$$

$$suf[i] = \begin{cases} suf[i+1] + 1, & i < n-1 \text{ 且 } nums[i] \le nums[i+1] \\ 1, & \text{否则} \end{cases}$$

不修改任何元素时的答案是 $\max_i pre[i]$，它已经被 $pre[n-1] \le pre[n-1]$ 这类边界覆盖，只需在下面的枚举里顺带取到。

若我们决定把位置 $i$ 换成某个值、并让答案子数组**穿过** $i$，则子数组形如 $[\,a \ldots i-1,\ i,\ i+1 \ldots b\,]$，其中：

- $[a \ldots i-1]$ 必须非递减（贡献 $pre[i-1]$ 个元素，$i = 0$ 时贡献 $0$）；
- $[i+1 \ldots b]$ 必须非递减（贡献 $suf[i+1]$ 个元素，$i = n-1$ 时贡献 $0$）；
- 中间那个 $i$ 被替换，只要存在一个值 $v$ 同时满足 $nums[i-1] \le v \le nums[i+1]$，缝合就成功。

最后一条等价于 $i$ 是边界或 $nums[i-1] \le nums[i+1]$——**与 $nums[i]$ 原来的值完全无关**，这是本题最漂亮的一点：被替换的元素是一个可任意取值的「自由变量」，它不会成为障碍。

### 3.3 算法流程

![缝合三情形：能同时接上前后缀，则只能二选一](images/bw169_q3_merge_condition.svg)

对每个 $i \in [0, n-1]$ 计算四种候选，取最大：

| 情形 | 条件 | 候选长度 |
|------|------|----------|
| 只保留前缀 + 替换位 | $i > 0$ | $pre[i-1] + 1$ |
| 只保留后缀 + 替换位 | $i < n-1$ | $1 + suf[i+1]$ |
| 前后缀同时缝上 | $i>0,\ i<n-1,\ nums[i-1] \le nums[i+1]$ | $pre[i-1] + 1 + suf[i+1]$ |
| 完全不替换 | 任意 | $\max_i pre[i]$ |

```text
1. 正序求 pre[]，倒序求 suf[]
2. ans = max(pre)
3. for i = 0 .. n-1:
       left  = (i > 0)      ? pre[i-1] : 0
       best  = left + 1
       若 i + 1 < n:
           若 i > 0 且 nums[i-1] <= nums[i+1]:  best = max(best, left + 1 + suf[i+1])
           否则:                               best = max(best, 1 + suf[i+1])
       ans = max(ans, best)
4. 返回 ans
```

「只保留前缀 + 替换位」与「只保留后缀 + 替换位」两个候选，正好被上面的 `else` 分支和一个 `best` 初值覆盖；同时注意 `ans = max(pre)` 与 `i` 走到 $n-1$ 时的 `left+1 = pre[n-2]+1 \ge pre[n-1]` 并不重复但都安全。

### 3.4 示例演算

![示例演算：pre / suf 与每处缝合的候选长度](images/bw169_q3_example_walkthrough.svg)

对示例 1 的 `nums = [1,2,3,1,2]`：

| i | nums[i] | pre[i] | suf[i] |
|---|---------|--------|--------|
| 0 | 1 | 1 | 3 |
| 1 | 2 | 2 | 2 |
| 2 | 3 | 3 | 1 |
| 3 | 1 | 1 | 2 |
| 4 | 2 | 2 | 1 |

逐点枚举缝合（$i$ 为被替换位置）：

| i | left = pre[i-1] | 可缝后缀 suf[i+1] | nums[i-1] ≤ nums[i+1] | 候选 |
|---|-----------------|-------------------|------------------------|------|
| 0 | 0 | suf[1]=2 | —（i=0，无左邻） | 3（1+2） |
| 1 | 1 | suf[2]=1 | 1 ≤ 3 ✓ | 1+1+1 = 3 |
| 2 | 2 | suf[3]=2 | 2 ≤ 1 ✗ | max(3, 1+2) = 3 |
| 3 | pre[2]=3 | suf[4]=1 | 3 ≤ 2 ✗ | max(4, 1+1) = 4 |
| 4 | pre[3]=1 | —（i=n-1） | — | 2 |

最大值为 4，对应「把 $i=3$ 的 1 换成 3，接上左边 `[1,2,3]`」，与示例一致。示例 2 全相等时 $pre = [1,2,3,4,5]$，$i=4$ 取 $pre[3]+1 = 5$。

## 4. 算法细节

1. **两次线性 DP**：`pre` 正序、`suf` 倒序，都是一次遍历、$O(1)$ 转移，注意比较用 `<=`（非递减允许相等）。
2. **缝合条件只看两个邻居**：`nums[i-1] <= nums[i+1]`，与被替换的原值无关；写成 `nums[i-1] <= nums[i] && nums[i] <= nums[i+1]` 是错的（原值可能是障碍，但我们本来就要替换它）。
3. **边界统一处理**：把 `i = 0` 的 `pre[-1]` 和 `i = n-1` 的 `suf[n]` 当成 $0$，可以免去大量 if。
4. **不替换也要算**：`ans` 初值取 $\max_i pre[i]$（等价于 `pre` 数组的最大值，或直接在循环中随 `best = left+1` 覆盖）。示例 2 靠这一条拿到 5。
5. **`n <= 2` 无需特判**：循环自然给出 $n$（把唯一的空隙换掉，或者两个都不动）。手写特判反而容易漏掉 `n = 1`。
6. **值域 $10^9$、可负**：只做大小比较，不涉及任何加减，`int` 足够，无需 `long long`。

## 5. 正确性证明

**引理 1（DP 正确性）**：$pre[i]$ 等于以 $i$ 结尾的最长非递减子数组长度；$suf[i]$ 等于以 $i$ 开头的最长非递减子数组长度。

**证明**：只证 $pre$（$suf$ 对称）。以 $i$ 结尾的非递减子数组，去掉末元素后是以 $i-1$ 结尾的子数组，且必须满足 $nums[i-1] \le nums[i]$；反之任何以 $i-1$ 结尾的非递减子数组在末尾接上 $nums[i]$（当 $nums[i-1] \le nums[i]$）仍非递减。故 $pre[i] = pre[i-1]+1$（当转移条件成立，取最长者最优）；条件不成立时长度只能是 1。∎

**引理 2（缝合可行性）**：设子数组为 $nums[a..b]$、被替换位置 $i \in [a,b]$（其余位置不变）。若 $[a \ldots i-1]$ 与 $[i+1 \ldots b]$ 都非递减，且（$i = a$ 或 $i = b$ 或 $nums[i-1] \le nums[i+1]$），则存在一个替换值使整个 $nums[a..b]$ 非递减。

**证明**：$i = a$ 时取 $v = nums[i+1]$（或 $i = a = b$ 时任意值），只需保证 $v \le nums[i+1]$，右段内部已非递减，成立。$i = b$ 对称，取 $v = nums[i-1]$。$i$ 在内部时，取 $v = nums[i-1]$（或 $nums[i+1]$，二者满足 $nums[i-1] \le nums[i+1]$，取哪个都落在区间内），则 $nums[i-1] \le v \le nums[i+1]$，拼接处的两个不等式都成立，左右段内部非递减，故整体非递减。∎

**引理 3（任意可行解都被枚举到）**：设替换位置 $k$ 后得到的非递减子数组为 $nums[a..b]$（长度 $L = b-a+1$）。若 $k \notin [a,b]$，则原数组中 $nums[a..b]$ 已非递减，$L \le pre[b] \le \max_i pre[i]$，被「不替换」情形覆盖；若 $k \in [a,b]$，则 $[a..k-1]$、$[k+1..b]$ 在替换后仍保持原值且非递减，故 $L \le pre[k-1] + 1 + suf[k+1]$（越界项取 0），且 $k$ 在内部时由引理 2 的必要性得 $nums[k-1] \le nums[k+1]$，正是算法在 $i=k$ 处计算的那个候选。

**证明**：替换只改一个位置，$[a..k-1]$、$[k+1..b]$ 中的元素值不变，且它们作为非递减子数组的子段仍非递减，故 $k-1-a+1 \le pre[k-1]$、$b-(k+1)+1 \le suf[k+1]$，相加再加 1 得 $L \le pre[k-1]+1+suf[k+1]$。若 $a < k < b$，则替换后必有 $nums[k-1] \le v \le nums[k+1]$，故 $nums[k-1] \le nums[k+1]$。∎

**定理**：算法返回值为「至多替换一个元素后」最长非递减子数组的长度。

**证明**：
（1）**答案不超过算法输出**：任取一个可行的替换方案与其最长非递减子数组 $nums[a..b]$（替换位置 $k$）。若 $k \notin [a,b]$，由引理 3 知 $L \le \max pre$，被覆盖；若 $k \in [a,b]$，由引理 3 知 $L \le pre[k-1]+1+suf[k+1]$ 且中间情形满足 $nums[k-1]\le nums[k+1]$，而算法在 $i=k$ 处的候选恰为 $pre[k-1]+1+suf[k+1]$，故 $L \le ans$。
（2）**算法输出可达到**：对任一 $i$，候选 $pre[i-1]+1+suf[i+1]$（在满足 $nums[i-1]\le nums[i+1]$ 时）由引理 2 可实际缝合成一个非递减子数组，长度正是该候选；不满足缝合条件时，候选 $pre[i-1]+1$ 与 $1+suf[i+1]$ 分别对应「把 $i$ 换成 $nums[i-1]$」与「换成 $nums[i+1]$」，同样由引理 2 的边界情形可达到；$\max pre$ 不需替换即可达到。故 `ans` 是某个真实可达方案的长度。
结合（1）（2），算法输出等于最优值。∎

## 6. 复杂度分析

- **时间**：$O(n)$。求 `pre`、`suf` 各一趟 $O(n)$，枚举缝合点一趟 $O(n)$，每处 $O(1)$ 常数次比较。$n = 10^5$ 时约 $3 \times 10^5$ 次运算。
- **空间**：$O(n)$。两个长度 $n$ 的 `int` 数组 `pre`、`suf`；若把 `pre` 复用为最终答案数组可省一半。递归栈 $O(1)$（纯迭代）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int longestSubarray(vector<int>& nums) {
        int n = (int)nums.size();
        vector<int> pre(n, 1), suf(n, 1);
        for (int i = 1; i < n; i++) {
            if (nums[i - 1] <= nums[i]) pre[i] = pre[i - 1] + 1;
        }
        for (int i = n - 2; i >= 0; i--) {
            if (nums[i] <= nums[i + 1]) suf[i] = suf[i + 1] + 1;
        }
        int ans = 1;
        for (int i = 0; i < n; i++) {
            int left = (i > 0) ? pre[i - 1] : 0;
            int best = left + 1;
            if (i + 1 < n) {
                if (i > 0 && nums[i - 1] <= nums[i + 1]) {
                    best = max(best, left + 1 + suf[i + 1]);
                } else {
                    best = max(best, 1 + suf[i + 1]);
                }
            }
            ans = max(ans, best);
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def longestSubarray(self, nums: list[int]) -> int:
        n = len(nums)
        pre = [1] * n
        suf = [1] * n
        for i in range(1, n):
            if nums[i - 1] <= nums[i]:
                pre[i] = pre[i - 1] + 1
        for i in range(n - 2, -1, -1):
            if nums[i] <= nums[i + 1]:
                suf[i] = suf[i + 1] + 1
        ans = 1
        for i in range(n):
            left = pre[i - 1] if i > 0 else 0
            best = left + 1
            if i + 1 < n:
                if i > 0 and nums[i - 1] <= nums[i + 1]:
                    best = max(best, left + 1 + suf[i + 1])
                else:
                    best = max(best, 1 + suf[i + 1])
            ans = max(ans, best)
        return ans
```

## 8. 边界情况与易错点

1. **缝合条件写错**：必须用 `nums[i-1] <= nums[i+1]`，不能带 `nums[i]`。写成 `nums[i-1] <= nums[i] <= nums[i+1]` 会漏掉大量答案（示例 1 的 $i=3$ 恰好原值 $1$ 不满足）。
2. **漏掉「不替换」**：`ans` 必须以 $\max pre$ 或 `best = left+1` 打底，否则全非递减的输入（示例 2）会少 1。
3. **两端候选漏写**：$i = 0$ 时只能接后缀（`1 + suf[1]`），$i = n-1$ 时只能接前缀（`pre[n-2] + 1`）。若统一写成 `pre[i-1] + 1 + suf[i+1]` 会数组越界。
4. **把 `<=` 写成 `<`**：非递减允许相等，`nums[i-1] == nums[i]` 时必须能接上，否则 `[2,2,2,2,2]` 会得到 2 而不是 5。
5. **误以为「替换元素必须落在答案子数组内」**：题目只要求全数组至多替换一个位置，若最优子数组本身已非递减，完全可以不替换或被替换点在子数组外——这就是 `ans = max(pre)` 那条分支的来源。
6. **`n = 1`**：返回 1。若写了 `pre[i-1]` 之类的越界访问而未做 `i > 0` 判断，会直接 RE。
7. **下标类型**：`n` 可达 $10^5$，`int` 足够，但循环里别把 `i+1 < n` 写成 `i < n-1` 之外的变形导致 `suf[n]` 越界。
