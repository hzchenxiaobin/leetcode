# LeetCode 统计主要元素子数组数目 II 题解

## 1. 题目概述

- **标题 / 题号**：统计主要元素子数组数目 II（#3739，hard）
- **链接**：https://leetcode.cn/problems/count-subarrays-with-majority-element-ii/
- **来源**：LeetCode 第 169 场双周赛 Q4
- **难度**：困难
- **标签**：线段树、数组、哈希表、分治、前缀和、归并排序

**题意**：与同场 Q2 完全一致——统计 `target` 为**主要元素**（出现次数严格大于子数组长度一半）的非空连续子数组个数，只是数据范围从 $n \le 1000$ 放大到 $n \le 10^5$，$O(n^2)$ 不再可行。

**约束**：

- $1 \le nums.length \le 10^5$
- $1 \le nums[i] \le 10^9$
- $1 \le target \le 10^9$

## 2. 示例

**示例 1**

```text
输入：nums = [1,2,2,3], target = 2
输出：5
解释：[2]（下标 1）、[2]（下标 2）、[2,2]、[1,2,2]、[2,2,3]。
```

**示例 2**

```text
输入：nums = [1,1,1,1], target = 1
输出：10
解释：全部 10 个子数组的主要元素都是 1，答案 10。
```

**示例 3**

```text
输入：nums = [1,2,3], target = 4
输出：0
解释：4 未出现，答案 0。
```

## 3. 解题思路

### 3.1 暴力思路

枚举 $l, r$ 并增量维护 `cnt`，$O(n^2)$。$n = 10^5$ 时约 $5 \times 10^9$ 次操作，必然超时；而且答案本身最大可达 $\frac{n(n+1)}{2} \approx 5 \times 10^9$，连累加变量都必须换成 64 位。**答案规模超大本身就是信号**：需要的是「批量计数」而不是「逐个判断」。

### 3.2 核心观察：+1/−1 变换 ⇒ 顺序对计数

![目标值记 +1、其余记 −1，主要元素问题变成前缀和的顺序对计数](images/bw169_q4_plus_minus_prefix.svg)

定义权重数组与它的前缀和：

$$w_i = \begin{cases} +1, & nums[i] = target \\ -1, & nums[i] \ne target \end{cases}, \qquad P_0 = 0,\quad P_k = \sum_{i=0}^{k-1} w_i$$

对子数组 $nums[l..r]$（即下标区间 $(l-1,\ r]$，对应前缀下标 $i = l$、$j = r+1$）：

$$P_j - P_i = \sum_{k=l}^{r} w_k = \text{cnt} - (\text{len} - \text{cnt}) = 2\,\text{cnt} - \text{len}$$

于是

$$target \text{ 是主要元素} \iff 2\text{cnt} > \text{len} \iff P_j > P_i$$

**问题变成**：在长度 $n+1$ 的前缀和序列 $P_0, P_1, \ldots, P_n$ 中，数有多少对 $i < j$ 满足 $P_i < P_j$。这正是「顺序对计数」（逆序对计数的镜像）。

### 3.3 算法流程

![从左到右扫前缀和，用树状数组回答「之前有多少个更小的值」](images/bw169_q4_count_order_pairs.svg)

$P$ 的取值范围是 $[-n, n]$ 且只取整数，但为了方便统一，直接做**离散化**（其实本题值域只有 $2n+1$ 个可能值，也可以开偏移数组，离散化更通用）：

1. 计算 $P_0 \ldots P_n$；
2. 把 $P$ 的全部取值排序去重，得到 $vals$，$P_k$ 的排名 $rank_k \in [1, |vals|]$；
3. 从左到右扫 $j = 0 \ldots n$：
   - 查询树状数组中「值严格小于 $P_j$」的已有元素个数，累加到 `ans`；
   - 把 $P_j$ 插入树状数组。
4. 返回 `ans`。

```text
1. P[0] = 0；for k = 1..n:  P[k] = P[k-1] + (nums[k-1]==target ? 1 : -1)
2. vals = 排序去重后的 P；rank[k] = lower_bound(vals, P[k]) + 1
3. BIT 清空；ans = 0
4. for j = 0..n:
       ans += BIT.query(rank[j] - 1)      // 严格小于
       BIT.add(rank[j], 1)
5. 返回 ans
```

「严格小于」由 `query(rank[j] - 1)` 保证：`query(x)` 返回排名 $\le x$ 的元素个数，减 1 就排除了等于自身的那些。

### 3.4 示例演算

![示例演算：前缀和序列与逐位插入树状数组的过程](images/bw169_q4_walkthrough.svg)

对示例 1 的 `nums = [1,2,2,3]`、`target = 2`：

| k | nums[k−1] | w | P[k] |
|---|-----------|---|------|
| 0 | — | — | 0 |
| 1 | 1 | −1 | −1 |
| 2 | 2 | +1 | 0 |
| 3 | 2 | +1 | 1 |
| 4 | 3 | −1 | 0 |

逐个插入并统计「之前有多少个值严格更小」：

| j | P[j] | 之前集合 | 更小者个数 | 累计 ans |
|---|------|----------|------------|----------|
| 0 | 0 | {} | 0 | 0 |
| 1 | −1 | {0} | 0 | 0 |
| 2 | 0 | {0, −1} | 1（−1） | 1 |
| 3 | 1 | {0, −1, 0} | 3 | 4 |
| 4 | 0 | {0, −1, 0, 1} | 1（−1） | 5 |

答案 5，与示例一致。注意 $j = 3$ 时 $P_i$ 有三个都小于 $1$，对应子数组 $(0,3] = [2,2,3]$、$(1,3] = [1,2,2,3]$ 不合法（那个是 4 对 4 平局）… 更准确地说，$j=3$ 对应的三个合法区间是 $(i,3]$，$i \in \{0,1,2\}$ 中 $P_i < 1$ 的全部：$i=0$ 即 $[1,2,2]$、$i=1$ 即 $[2,2]$、$i=2$ 即 $[2]$ 中的 `[2]`（下标 2）——正与另三个合法子数组对应。

## 4. 算法细节

1. **下标对齐**：前缀和数组长度是 $n+1$，子数组 $nums[l..r]$ 对应 $P$ 的下标对 $(i, j) = (l,\ r+1)$，$i < j$ 恒成立。**千万不要**写成 $(l, r)$，那会把区间长度算错一位。
2. **离散化**：`sort` + `unique` + `lower_bound`，$O(n \log n)$；排名从 1 开始，便于树状数组的 1-based 下标。
3. **严格小于**：`query(rank-1)`。若写成 `query(rank)` 就把 $P_i = P_j$（平局，即 $\text{len} = 2\text{cnt}$）也算进去，答案偏大——这是本题最隐蔽的 WA 点，示例 1 里 $P$ 有多个 0，会立刻暴露。
4. **答案用 64 位**：$n = 10^5$ 时最多 $5 \times 10^9$ 对，`int` 溢出，C++ 用 `long long`，Python 天然大整数。
5. **`target` 不存在可提前返回 0**：此时所有权重为 $-1$，$P$ 严格递减，任何 $i<j$ 都有 $P_i > P_j$，答案恰好是 0，逻辑上自动正确；提前判掉可少一次排序。
6. **树状数组 vs 归并排序**：两者都是 $O(n \log n)$。树状数组常数小、代码短；归并排序（CDQ）不需要离散化，但要注意用 `long long` 计数。标签里的「线段树 / 分治 / 归并排序」都是指这一类做法。
7. **值域替代方案**：因为 $P_k \in [-n, n]$，可以不加离散化，直接开 $2n+2$ 的数组并把下标偏移 $n$。这样是 $O(n)$ 空间 + $O(n \log n)$ 时间，常数更小；离散化写法更通用，推荐作为模板。

## 5. 正确性证明

**引理 1（区间和等价）**：对任意 $0 \le i < j \le n$，设 $l = i$、$r = j-1$，则 $P_j - P_i = 2 \cdot \text{cnt}(l,r) - (r-l+1)$。

**证明**：$P_j - P_i = \sum_{k=i}^{j-1} w_k$。其中等于 $target$ 的位置贡献 $+1$，共 $\text{cnt}$ 个；其余 $(\text{len} - \text{cnt})$ 个贡献 $-1$。故和为 $\text{cnt} - (\text{len} - \text{cnt}) = 2\text{cnt} - \text{len}$，而 $\text{len} = j - i = r - l + 1$。∎

**引理 2（判定等价）**：`target` 是子数组 $nums[l..r]$ 的主要元素 $\iff P_{r+1} > P_l$。

**证明**：由引理 1，$P_{r+1} - P_l = 2\text{cnt} - \text{len}$，故 $P_{r+1} > P_l \iff 2\text{cnt} > \text{len} \iff \text{cnt} > \text{len}/2$，正是主要元素的定义。∎

**引理 3（树状数组查询正确）**：扫描到第 $j$ 个前缀值时，`query(rank[j] - 1)` 恰好等于集合 $\{P_0, \ldots, P_{j-1}\}$ 中满足 $P_i < P_j$ 的元素个数。

**证明**：算法此前恰好对 $i = 0, \ldots, j-1$ 各执行了一次 `add(rank[i], 1)`，故树状数组存的是这 $j$ 个值按排名计数的多重集。`query(x)` 的定义是排名 $\le x$ 的元素个数之和，取 $x = rank[j]-1$ 即统计排名严格小于 $rank[j]$ 的元素。由于 $rank$ 是单调的（$P_a < P_b \iff rank_a < rank_b$，相等则排名相等），「排名更小」与「值更小」等价，故查询结果正是 $\#\{i < j : P_i < P_j\}$。∎

**定理**：算法返回值为 `nums` 中以 `target` 为主要元素的子数组个数。

**证明**：
（1）**单射**：每个非空子数组 $nums[l..r]$ 唯一对应一对前缀下标 $(l, r+1)$，且 $l < r+1$；不同子数组对应不同下标对。由引理 2，该子数组合法 $\iff P_l < P_{r+1}$。
（2）**计数**：算法对每个 $j \in [0, n]$ 恰好把「以 $j$ 为右端前缀下标、满足 $P_i < P_j$ 的 $i < j$ 的个数」加入 `ans`（引理 3）。把所有 $j$ 的这些个数相加，恰是满足 $i < j$ 且 $P_i < P_j$ 的下标对总数，即合法子数组总数。
（3）**不重不漏**：每个下标对 $(i,j)$ 只在 $j$ 这一轮被统计一次；每个子数组恰好对应一个下标对。故 `ans` 精确等于所求。∎

## 6. 复杂度分析

- **时间**：$O(n \log n)$。计算前缀和 $O(n)$；排序去重 $O(n \log n)$；离散化查排名 $n+1$ 次二分 $O(n \log n)$；树状数组 $n+1$ 次查询 + $n+1$ 次插入，每次 $O(\log n)$。合计 $O(n \log n)$，$n = 10^5$ 时约 $2 \times 10^6$ 次基本操作。
- **空间**：$O(n)$。`pref`、`vals`、`rank`、`bit` 各 $O(n)$；无递归。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long countMajoritySubarrays(vector<int>& nums, int target) {
        int n = (int)nums.size();
        vector<long long> pref(n + 1, 0);
        for (int i = 0; i < n; i++) {
            pref[i + 1] = pref[i] + (nums[i] == target ? 1 : -1);
        }
        vector<long long> vals = pref;
        sort(vals.begin(), vals.end());
        vals.erase(unique(vals.begin(), vals.end()), vals.end());
        int m = (int)vals.size();
        vector<int> bit(m + 1, 0);

        auto add = [&](int idx) {
            for (; idx <= m; idx += idx & -idx) bit[idx] += 1;
        };
        auto query = [&](int idx) {
            int s = 0;
            for (; idx > 0; idx -= idx & -idx) s += bit[idx];
            return s;
        };

        long long ans = 0;
        for (int j = 0; j <= n; j++) {
            int rank = (int)(lower_bound(vals.begin(), vals.end(), pref[j]) - vals.begin()) + 1;
            ans += query(rank - 1);
            add(rank);
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def countMajoritySubarrays(self, nums: list[int], target: int) -> int:
        n = len(nums)
        pref = [0] * (n + 1)
        for i, x in enumerate(nums):
            pref[i + 1] = pref[i] + (1 if x == target else -1)

        vals = sorted(set(pref))
        rank = {v: i + 1 for i, v in enumerate(vals)}
        m = len(vals)
        bit = [0] * (m + 1)

        def add(idx: int) -> None:
            while idx <= m:
                bit[idx] += 1
                idx += idx & -idx

        def query(idx: int) -> int:
            s = 0
            while idx > 0:
                s += bit[idx]
                idx -= idx & -idx
            return s

        ans = 0
        for v in pref:
            r = rank[v]
            ans += query(r - 1)
            add(r)
        return ans
```

## 8. 边界情况与易错点

1. **平局必须排除**：`query(rank-1)` 而非 `query(rank)`。`2cnt == len` 不是主要元素，示例 1 的 `[1,2,2,3]` 正是平局。
2. **前缀下标错位**：子数组 $[l, r]$ 对应 $(l, r+1)$。写成 $(l, r)$ 等价于把区间长度少算一位，全错。
3. **答案溢出**：$n = 10^5$ 时最大 $5 \times 10^9$，超过 `int`。C++ 的 `ans` 必须是 `long long`，返回类型也必须是 `long long`（题目 metaData 已给出 `long`）。
4. **`target` 不出现**：答案 0，逻辑自动成立；提前 `return 0` 可省时。
5. **$n = 1$**：$P = [0, \pm 1]$。$nums[0] = target$ 时 $P = [0,1]$，只有一对 $(0,1)$ 满足 $0 < 1$，答案 1；否则 $P = [0,-1]$，答案 0。代码无需特判。
6. **离散化排名从 1 开始**：树状数组下标 1-based，`lower_bound` 结果要 `+1`；忘记 `+1` 时 `query(0)` 恒为 0，答案会小得离谱。
7. **`bit` 的类型**：每个位置计数不超过 $n$，`int` 够；但若改成「带权」版本（如统计带权对数）需要 `long long`。
8. **重复值不影响正确性**：离散化把相等的 $P$ 映射到同一排名，`query(rank-1)` 天然把它们排除，无需额外判重。
