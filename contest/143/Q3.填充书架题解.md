# LeetCode 填充书架 题解

## 1. 题目概述

- **标题 / 题号**：填充书架（#1105，medium）
- **链接**：https://leetcode.cn/problems/filling-bookcase-shelves/
- **来源**：LeetCode 第 143 场周赛 Q3
- **难度**：中等
- **标签**：数组，动态规划

**题意**：有 $n$ 本书，$\text{books}[i] = [\text{thickness}_i, \text{height}_i]$ 是第 $i$ 本书的厚度与高度。必须**按数组原顺序**把书摆进总宽度为 `shelfWidth` 的书架：先挑若干本放在当前层（这些书的厚度之和不超过 `shelfWidth`），再新建一层放后面的书，如此重复直到放完。每一层的层高等于该层中最高的那本书，书架总高度为各层层高之和，求可能的最小总高度。

换一种更贴近算法语言的转述：把数组切成若干**连续段**，第 $k$ 段对应第 $k$ 层，要求每段内厚度之和 $\le \text{shelfWidth}$，段的代价是该段内高度的最大值，最小化所有段代价之和。

**约束**：

- $1 \le \text{books.length} \le 1000$
- $1 \le \text{thickness}_i \le \text{shelfWidth} \le 1000$
- $1 \le \text{height}_i \le 1000$

> 💡 由 `thickness_i <= shelfWidth` 可知「每本书单独占一层」始终合法，因此答案一定存在；同时内层循环的枚举长度被厚度和天然限制住，这是后文复杂度收紧的关键。

## 2. 示例

**示例 1**

```text
输入：books = [[1,1],[2,3],[2,3],[1,1],[1,1],[1,1],[1,2]], shelfWidth = 4
输出：6
解释：三层高度和为 1 + 3 + 2 = 6。
      第 1 层：0 号书              厚度 1 ≤ 4，层高 1
      第 2 层：1、2 号书           厚度 2+2 = 4，层高 3
      第 3 层：3、4、5、6 号书      厚度 1+1+1+1 = 4，层高 2
      注意 1 号书不必放在第 1 层——那样第 1 层会变成 [0,1] 两本、层高 3。
```

**示例 2**

```text
输入：books = [[1,3],[2,4],[3,2]], shelfWidth = 6
输出：4
解释：三本书厚度和 1+2+3 = 6 恰好等于书架宽度，全部放在同一层，
      层高 = max(3,4,2) = 4。
```

**补充示例 3**（用于说明贪心不可行）

```text
输入：books = [[1,1],[2,3],[2,3]], shelfWidth = 4
输出：4
解释：最优是 [0] 与 [1,2] 两层，层高 1 + 3 = 4。
      若贪心地「能塞就塞」，第 1 层会放 [0,1]（厚度 3 ≤ 4），
      2 号书只能单独成层，得到 3 + 3 = 6，比最优差 2。
```

## 3. 解题思路

### 3.1 暴力思路

所有摆放方案等价于在相邻书之间选择「是否换层」，即从 $n-1$ 个空隙中任选若干切开，方案数 $2^{n-1}$。对每种方案检查每层厚度和（$O(n)$）并累加层高，总时间 $O(n \cdot 2^{n})$，$n = 1000$ 时完全不可行。

更常见的错误是**贪心**：每层尽量塞满。补充示例 3 就是反例——贪心把 0、1 号书塞进第 1 层（厚度 3 ≤ 4），层高被高度为 3 的 1 号书抬到 3，于是 2 号书（厚 2、高 3）只能另起一层，总高 3 + 3 = 6；而最优解是第 1 层只放 0 号书。过程。可见「当前层是否还能塞下」不足以决定最优解，必须**全局权衡**。

### 3.2 核心观察：最后一层是一段后缀

![核心观察：最后一层是 books[j..i-1]](images/wc143_q3_shelf_dp_model.svg)

因为摆放顺序与数组顺序一致，任何一层的书在原数组中都对应一个**连续区间**。设 $dp[i]$ 表示**前 $i$ 本书**（$\text{books}[0..i-1]$）摆放完毕的最小总高度，$dp[0] = 0$。

盯住最优方案里的**最后一层**：它一定是 $\text{books}[j..i-1]$ 这样一段后缀，其中起点 $j$ 满足

$$\sum_{k=j}^{i-1} \text{thickness}_k \le \text{shelfWidth}$$

而它前面 $[0, j-1]$ 的摆法是一个独立的子问题，最优值正是 $dp[j]$。于是

$$dp[i] = \min_{0 \le j < i,\ \sum_{k=j}^{i-1} t_k \le W} \Bigl( dp[j] + \max_{j \le k \le i-1} h_k \Bigr)$$

**为什么这样就够**：切点 $j$ 一旦确定，前缀的层高之和与最后一层的层高**互不干扰**（不同层之间没有共享的约束），所以前缀取最优不会损失最后一层的可行性；反之若前缀不取最优，整体只会更差。

**枚举方向上的小技巧**：对固定的 $i$ 让 $j$ 从 $i-1$ 递减到 $0$，被并入最后一层的书依次是 $i-1, i-2, \dots$，厚度和 `w` 与层高 `h` 都可以**增量**维护；一旦 `w > shelfWidth` 立刻 `break`——再往左加书厚度只会更大，不可能重新合法。

### 3.3 算法流程

![一维 DP 的执行流程](images/wc143_q3_algorithm_flow.svg)

```text
1. dp[0] = 0，dp[1..n] = +INF
2. for i = 1 .. n:
       w = 0, h = 0                       # 当前最后一层的厚度和、层高
       for j = i-1 down to 0:
           w += thickness[j]
           if w > shelfWidth: break       # 再往左只会更宽，直接停
           h = max(h, height[j])
           dp[i] = min(dp[i], dp[j] + h)
3. 返回 dp[n]
```

外层每进入一个新的 $i$ 都要重置 `w = h = 0`；内层从右往左「长」出这一层，每加一本书就刷新一次候选答案。

## 4. 算法细节

1. **状态语义**：$dp[i]$ 对应**前 $i$ 本**（下标 $0 \sim i-1$），不是「第 $i$ 本」；$dp[0]=0$ 是哨兵，代表空书架。
2. **最后一层必是后缀**：因为顺序固定，最后一层一定是 $\text{books}[j..i-1]$ 这一段；不能从中间「抽」一本书出来，也不能交换书序。
3. **`w` 与 `h` 增量维护**：内层每步只并入一本新书，`w += t[j]`、`h = max(h, h[j])`，避免对每个 $j$ 重新扫区间，把单次转移从 $O(n)$ 降到 $O(1)$。
4. **`break` 用 `>` 而不是 `>=`**：厚度和恰好等于 `shelfWidth` 是合法的，只有严格超过才必须停。
5. **初值必须足够大**：`dp` 用 `+INF` 初始化，`dp[0] = 0`。若全零初始化，`min` 会把所有状态压成 0。
6. **数值范围**：答案上界是「每本书单独成层」时的 $\sum h_i \le 1000 \times 1000 = 10^6$，`int` 足够，无需 64 位；但 `INF` 取 $10^9$ 时也不要让 `INF + h` 溢出（用 `1e9` 安全，$10^9 + 1000$ 远小于 `INT_MAX`）。
7. **内层循环的真实上界**：每本书厚度至少 1，故内层至多执行 $\min(i, \text{shelfWidth})$ 次。这给出比 $O(n^2)$ 更紧的 $O(n \cdot \min(n, W))$。
8. **需要方案时加一个 `pre[i]`**：记录让 $dp[i]$ 取到最小值的 $j$，最后从 $n$ 反向回溯即可还原每一层的起止下标。

## 5. 正确性证明

**引理 1（摆法与连续切分一一对应）**：任意合法摆法都等价于把 `books` 切成若干连续段，段内厚度和 $\le W$，且总高度等于各段「段内最大高度」之和。

**证明**：按题意，同一层的书在数组中相邻（顺序固定、逐层连续取书），所以每一层对应一个连续段；反过来任意一个满足厚度约束的连续切分，都可以按顺序逐段放到各层上，是一个合法摆法。层高定义为层内最大高度，故总高度即各段最大值之和。∎

**引理 2（最优子结构）**：设某最优摆法的最后一层是 $\text{books}[j..i-1]$，则前 $j$ 本书的摆法必定是 $dp[j]$ 所对应的最优摆法。

**证明**：反证。若前 $j$ 本书存在总高度更小的合法摆法，把它与「最后一层 $\text{books}[j..i-1]$」拼起来，仍是一个合法摆法（前缀的层数、层内厚度约束都不变，且最后一层本身仍合法），而总高度更小，与最优性矛盾。∎

**引理 3（转移既完备又可达）**：固定 $i$，并假设对每个 $j < i$，$dp[j]$ 已等于前 $j$ 本书的最小总高度。记
$$S_i = \Bigl\{ dp[j] + \max_{j \le k < i} h_k \ \Big|\ 0 \le j < i,\ \sum_{k=j}^{i-1} t_k \le W \Bigr\}$$
则 $S_i$ 中每个值都可被某个合法摆法取到，且每个合法摆法的总高度都不小于 $S_i$ 中的某个值（即 $\min S_i$ 恰为前 $i$ 本书的最小总高度）。

**证明**：**可达性**：对任一满足厚度约束的 $j$，由归纳假设存在前 $j$ 本书的合法摆法高度为 $dp[j]$；由引理 1 再拼上最后一层 $\text{books}[j..i-1]$（该层厚度和 $\le W$），得到一个合法摆法，其高度恰为 $S_i$ 中对应的值。**完备性**：取任一合法摆法，设其最后一层起点为 $j$，由引理 1 知 $j$ 必满足厚度约束，故 $j$ 对应的候选值属于 $S_i$；该摆法总高度 =（前 $j$ 本的高度）$+ \max_{j \le k < i} h_k \ge dp[j] + \max_{j \le k < i} h_k$（这里用到归纳假设：$dp[j]$ 是前缀最小值）。∎

**定理**：对所有 $i$，算法结束时 $dp[i]$ 等于前 $i$ 本书的最小总高度，故返回 $dp[n]$ 正确。

**证明**：对 $i$ 归纳。$i=0$ 时 $dp[0]=0$ 正确（空书架高度为 0）。设 $i' < i$ 均已正确，则引理 3 的前提成立：算法对 $dp[i]$ 取的是 $\min S_i$，而 $S_i$ 中每个值都可实现（是某个合法摆法的高度），故 $dp[i] \ge$ 最优值；另一方面每个合法摆法的高度都不小于 $S_i$ 中某个值，故最优值 $\ge \min S_i = dp[i]$。两者夹逼得 $dp[i] =$ 最优值。∎

## 6. 复杂度分析

- **时间**：外层 $n$ 次，内层受厚度和限制，至多 $\min(i, W)$ 次（$W = \text{shelfWidth}$），每次 $O(1)$ 的加、取最大、取最小。总计 $O\bigl(n \cdot \min(n, W)\bigr)$，上界 $O(nW) \le 10^6$ 次转移，实测毫秒级。
- **空间**：一维 $dp$ 数组，$O(n)$；若额外记录 `pre` 输出方案，仍是 $O(n)$。递归暴力解会占用 $O(n)$ 栈但时间爆炸，不可取。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int minHeightShelves(vector<vector<int>>& books, int shelfWidth) {
        int n = books.size();
        const int INF = 1e9;
        vector<int> dp(n + 1, INF);          // dp[i]：前 i 本书的最小总高度
        dp[0] = 0;
        for (int i = 1; i <= n; i++) {
            int w = 0, h = 0;                // 当前最后一层的厚度和、层高
            for (int j = i - 1; j >= 0; j--) {
                w += books[j][0];
                if (w > shelfWidth) break;   // 再往左只会更宽
                h = max(h, books[j][1]);
                dp[i] = min(dp[i], dp[j] + h);
            }
        }
        return dp[n];
    }
};
```

### Python

```python
class Solution:
    def minHeightShelves(self, books: list[list[int]], shelfWidth: int) -> int:
        n = len(books)
        INF = float('inf')
        dp = [INF] * (n + 1)          # dp[i]：前 i 本书的最小总高度
        dp[0] = 0
        for i in range(1, n + 1):
            w = 0                     # 最后一层的厚度和
            h = 0                     # 最后一层的层高
            for j in range(i - 1, -1, -1):
                w += books[j][0]
                if w > shelfWidth:    # 再往左只会更宽，立即停止
                    break
                h = max(h, books[j][1])
                if dp[j] + h < dp[i]:
                    dp[i] = dp[j] + h
        return dp[n]
```

## 8. 边界情况与易错点

1. **`break` 条件写成 `>=`**：厚度和恰好等于 `shelfWidth` 是合法的，误写 `>=` 会漏掉「刚好填满一层」的最优解（示例 1 的第 3 层厚度正好是 4）。
2. **忘了重置 `w`、`h`**：它们是「当前这一层」的累积量，必须在外层每轮开头清零，否则会跨层累加，直接超限。
3. **`dp` 初值写成 0**：所有 `min` 都会取到 0，答案变成 0。必须用足够大的 `INF`（如 `1e9`）且只把 `dp[0]` 置 0。
4. **`j` 的下界**：必须能枚举到 $j=0$，即「所有书都放在同一层」这一情形；循环条件写成 `j > 0` 会漏掉它（示例 2 正是这种情形）。
5. **只按高度排序再贪心**：题目强制**保持原顺序**，任何排序都会破坏层内连续性与题意的对应关系，答案无意义。
6. **把它当贪心做**：如补充示例 3，「能塞就塞」会得到 6 而非最优的 4；每层塞满并不是最优策略。
7. **$n=1$**：内层只执行一次（$j=0$），返回该书高度；上面的代码无需特判。
8. **单本书厚度等于 `shelfWidth`**：内层第 1 步 `w == W` 不触发 `break`，还能继续并入下一本时才会超限，逻辑正确；若把比较写成 `w >= W` 就会在第一步误停并漏掉 $j=i-1$ 这一合法候选。
