# LeetCode 二叉树寻路 题解

## 1. 题目概述

- **标题 / 题号**：二叉树寻路（#1104，medium）
- **链接**：https://leetcode.cn/problems/path-in-zigzag-labelled-binary-tree/
- **来源**：LeetCode 第 143 场周赛 Q2
- **难度**：中等
- **标签**：树、数学、二叉树

**题意**：一棵无限大的完全二叉树，每层节点按「之」字形编号——奇数层从左到右、偶数层从右到左。第 $h$ 层恰好占用标号区间 $[2^{h-1},\,2^h-1]$。给定某个节点的标号 `label`，返回**从根到该节点**路径上所有节点的标号（自顶向下）。

**约束**：

- $1 \le \text{label} \le 10^6$
- 树无限深，但 `label` 所在层号 $h = \lfloor \log_2 \text{label} \rfloor + 1 \le 20$，路径长度至多 20
- 答案唯一：树中每个非根节点只有一个父节点

> 💡 本题的题面没有出现任何额外的「变量注入」指令，正常按题意实现 `pathInZigZagTree(int label)` 即可。

## 2. 示例

**示例 1**

```text
输入：label = 14
输出：[1, 3, 4, 14]
解释：14 位于第 4 层（区间 [8, 15]），该层从右到左编号；
      自顶向下的路径是 1 → 3 → 4 → 14。
```

**示例 2**

```text
输入：label = 26
输出：[1, 2, 6, 10, 26]
解释：26 位于第 5 层（区间 [16, 31]），该层从左到右编号；
      自顶向下的路径是 1 → 2 → 6 → 10 → 26。
```

## 3. 解题思路

### 3.1 暴力思路

最直观的做法是**逐层建表**：第 $h$ 层生成 $[2^{h-1}, 2^h-1]$ 这段整数，若 $h$ 为偶数就整体反转，得到该层「从左到右」的标号序列；记下 `label` 在本层的下标 $i$，则父节点下标为 $\lfloor i/2 \rfloor$，一层一层往回走即可。

这个做法是**正确**的，但需要把 $h$ 层的 $2^{h-1}$ 个标号全部存下来，时间与空间都是 $O(\text{label})$——对 $10^6$ 虽然勉强能跑，却完全没有利用编号的数学结构。事实上我们只需要「当前标号 → 父节点标号」这一个映射，把它写成 $O(1)$ 的公式，整条路径就能在 $O(\log \text{label})$ 内算出来。

> ⚠️ 另一个常见错误是直接套用普通完全二叉树的父节点公式 $\lfloor x/2 \rfloor$：对 `label = 14`，$\lfloor 14/2 \rfloor = 7$，但 7 在第 3 层的**最右端**，而 14 的父节点是 4。公式必须先把「之字形」的翻转抵消掉。

### 3.2 核心观察：镜像一次再除以 2

![之字形编号：奇数层从左到右，偶数层从右到左](images/wc143_q2_zigzag_numbering.svg)

先在**正常层序**（每层都从左到右）里看：节点 $x$ 的父节点恒为 $\lfloor x/2 \rfloor$，所在层号是 $\lfloor \log_2 x \rfloor + 1$。之字形只在一个地方偏离了正常层序——**偶数层的编号方向被翻转了**。

于是对第 $h$ 层的标号 $x$ 定义**镜像**：

$$\text{mirror}(x,h) = 3 \times 2^{h-1} - 1 - x$$

它把区间 $[2^{h-1}, 2^h-1]$ 关于自身中心对折，因此是**对合**（mirror 两次回到原值）。它的语义也非常干净：**$\text{mirror}(x,h)$ 就是「同一行内同一个位置、但在相反方向编号」时该位置上的标号**——

- $h$ 为奇数时该行从左到右，镜像后得到从右到左的标号；
- $h$ 为偶数时该行从右到左，镜像后得到从左到右（即正常层序）的标号。

关键性质是：**相邻两层的编号方向必然相反**。所以对 $x$ 做一次镜像，「方向类型」就与父节点所在层的方向类型对齐了，再执行标准的 $\lfloor \cdot/2 \rfloor$ 就得到父节点：

$$\text{parent}(x) = \left\lfloor \frac{\text{mirror}(x,h)}{2} \right\rfloor = \left\lfloor \frac{3 \times 2^{h-1} - 1 - x}{2} \right\rfloor = 2^{h-1} + 2^{h-2} - 1 - \left\lfloor \frac{x}{2} \right\rfloor$$

（最后一步用到了 $3 \times 2^{h-1}-1-x$ 与 $x$ 奇偶性相反这一点，见 §5 引理 1。）注意等式右端**只剩一次除 2**，比先算 mirror 更短，也更不容易写错。

### 3.3 算法流程

![算法流程：自底向上求父节点，每轮 O(1)](images/wc143_q2_parent_derivation.svg)

1. 求 `label` 的层号 $h$：$h$ 是 `label` 的二进制位数，即最小的满足 $2^{h} > \text{label}$ 的正整数。
2. 把当前标号 $x$ 追加进答案数组（此时是**自底向上**的顺序）。
3. 若 $h = 1$，说明已经到根，跳出循环。
4. 否则令 $x \leftarrow 2^{h-1} + 2^{h-2} - 1 - \lfloor x/2 \rfloor$，$h \leftarrow h-1$，回到第 2 步。
5. 反转答案数组，得到自顶向下的路径。

整个循环最多执行 $h \le 20$ 次，每次只有一次移位、一次除法、两次加减，是严格的 $O(\log \text{label})$。

### 3.4 示例演算

![示例演算：每轮套一次闭式，最后反转路径](images/wc143_q2_walkthrough.svg)

以 `label = 26`（$h = 5$）为例：

| 轮次 | 当前 $x$ | $h$ | $2^{h-1}+2^{h-2}-1-\lfloor x/2 \rfloor$ | 结果 |
|------|----------|-----|------------------------------------------|------|
| 1 | 26 | 5 | $16 + 8 - 1 - 13$ | 10 |
| 2 | 10 | 4 | $8 + 4 - 1 - 5$ | 6 |
| 3 | 6 | 3 | $4 + 2 - 1 - 3$ | 2 |
| 4 | 2 | 2 | $2 + 1 - 1 - 1$ | 1 |
| 5 | 1 | 1 | 已到根，停止 | — |

收集顺序是 $26, 10, 6, 2, 1$，反转后得到 $[1, 2, 6, 10, 26]$，与官方输出一致。

`label = 14`（$h = 4$）同理：$14 \to 4 \to 3 \to 1$，反转后为 $[1, 3, 4, 14]$。注意 14 的父节点是 4，而 $\lfloor 14/2 \rfloor = 7$——偶数层的翻转会让父节点偏离「除以 2」，偏移量随 $x$ 在同一行内的位置变化（例如 `label = 8` 的父节点是 7，反而比 $\lfloor 8/2 \rfloor = 4$ 大）。

## 4. 算法细节

1. **层号不要用浮点算**：`int(log2(x)) + 1` 在 $x$ 为 2 的幂时可能因为 `log2(8) = 2.9999...` 而少算一层。C++ 用 `while ((1 << h) <= label) ++h;`（或 `32 - __builtin_clz(label)`），Python 直接用 `label.bit_length()`。
2. **幂次用移位**：$2^{h-1}$ 写成 `1 << (h - 1)`；$h = 2$ 时 $2^{h-2} = 2^0 = 1$，移位 `1 << 0` 合法，不需要额外特判。
3. **闭式与「先镜像再除 2」等价**：闭式可以用取整恒等式从 mirror 版直接化简得到（引理 1），把「先翻转、再除以 2」两步取整合成一次，既少一次运算，也避免写错括号。
4. **自底向上收集再反转**：用 `push_back` + `reverse`（Python 的 `list.reverse()`）是 $O(h)$；若用头插 `insert(begin(), x)` 则是 $O(h^2)$，本题 $h \le 20$ 不会超时，但没有必要。
5. **不要递归求父节点**：递归深度只有 20，安全，但要额外处理「反转」这一步，反而比迭代 + `reverse` 更绕；迭代写法一眼能看出循环不变量。
6. **数据范围**：$\text{label} \le 10^6 \Rightarrow h \le 20$，闭式中的 $3 \times 2^{h-1} \le 3 \times 2^{19} \approx 1.57 \times 10^6$，`int` 绰绰有余；若上限放大到 $10^{18}$ 就必须换 `long long`。
7. **区间自检**：算出的父节点必须落在 $[2^{h-2}, 2^{h-1}-1]$ 内（正好是上一层的标号区间），这是调试时最快的断言。

## 5. 正确性证明

先约定：把第 $h$ 层从左到右的位置编号为 $0,1,\dots,2^{h-1}-1$，称为**行内位置** $\text{pos}$。奇数层标号随位置递增，偶数层标号随位置递减。

**引理 1（镜像的对合性与取整恒等式）**：设 $h \ge 2$，$x \in [2^{h-1}, 2^h-1]$，则 $\text{mirror}(x,h) = 3 \times 2^{h-1}-1-x$ 仍落在同一区间，且 $\text{mirror}(\text{mirror}(x,h),h) = x$；此外对任意整数 $x$ 有

$$\left\lfloor \frac{3 \times 2^{h-1}-1-x}{2} \right\rfloor = 3 \times 2^{h-2} - 1 - \left\lfloor \frac{x}{2} \right\rfloor$$

**证明**：区间端点之和为 $2^{h-1} + (2^h-1) = 3 \times 2^{h-1}-1$，故 $\text{mirror}$ 是区间到自身的中心对称映射，对合性两式代入即得。至于取整恒等式：写 $x = 2q + r$（$r \in \{0,1\}$）。因 $3 \times 2^{h-1}$ 为偶数，$3 \times 2^{h-1}-1-x$ 与 $x$ 奇偶性相反。当 $r = 0$ 时该式为奇数，$\lfloor \cdot/2 \rfloor = 3 \times 2^{h-2}-1-q$；当 $r = 1$ 时该式为偶数，$\lfloor \cdot/2 \rfloor = 3 \times 2^{h-2}-1-q$。两种情形都等于 $3 \times 2^{h-2}-1-\lfloor x/2 \rfloor$。∎

**引理 2（镜像 = 同位置的相反方向标号）**：第 $h$ 层位置 $\text{pos}$ 上的标号为 $x$，则同一位置在**相反编号方向**下的标号恰为 $\text{mirror}(x,h)$。

**证明**：一个方向的标号是 $2^{h-1}+\text{pos}$，相反方向是 $2^h-1-\text{pos}$，两者之和为 $3 \times 2^{h-1}-1$。当 $h$ 为奇数时 $x = 2^{h-1}+\text{pos}$，代入得 $\text{mirror}(x,h) = 2^h-1-\text{pos}$；当 $h$ 为偶数时 $x = 2^h-1-\text{pos}$，代入得 $\text{mirror}(x,h) = 2^{h-1}+\text{pos}$。两种情况都正好是相反方向的标号。∎

**引理 3（父节点公式）**：设 $x$ 位于第 $h \ge 2$ 层的行内位置 $\text{pos}$，则 $x$ 的父节点标号

$$P = 2^{h-1} + 2^{h-2} - 1 - \left\lfloor \frac{x}{2} \right\rfloor$$

恰为第 $h-1$ 层行内位置 $q = \lfloor \text{pos}/2 \rfloor$ 上的标号，即父节点的正确标号。

**证明**：分两种情形，注意 $h$ 与 $h-1$ 的编号方向相反。

- $h$ 为偶数：第 $h$ 层从右到左，$\text{pos} = 2^h-1-x$；第 $h-1$ 层从左到右，故父节点标号为 $2^{h-2}+q$，其中 $q = \lfloor (2^h-1-x)/2 \rfloor$。若 $x = 2t$，则 $q = 2^{h-1}-1-t$，$P = 2^{h-2}+2^{h-1}-1-t = 3 \times 2^{h-2}-1-t$；若 $x = 2t+1$，则 $q = 2^{h-1}-t-1$，$P = 3 \times 2^{h-2}-t-1$。两种情形都与引理 1 给出的闭式一致。
- $h$ 为奇数：第 $h$ 层从左到右，$\text{pos} = x-2^{h-1}$；第 $h-1$ 层从右到左，故父节点标号为 $2^{h-1}-1-q$，其中 $q = \lfloor (x-2^{h-1})/2 \rfloor$。若 $x = 2t$，则 $q = t-2^{h-2}$，$P = 3 \times 2^{h-2}-1-t$；若 $x = 2t+1$，则 $q = t-2^{h-2}$，$P = 3 \times 2^{h-2}-1-t$。同样与闭式一致。

最后确认值域：闭式在 $x = 2^{h-1}$ 时取 $3 \times 2^{h-2}-1-2^{h-2} = 2^{h-1}-1$，在 $x = 2^h-1$ 时取 $3 \times 2^{h-2}-1-(2^{h-1}-1) = 2^{h-2}$，而 $P$ 关于 $x$ 单调不增，故 $P \in [2^{h-2}, 2^{h-1}-1]$，确实落在第 $h-1$ 层。∎

**定理**：算法返回的数组是根节点到 `label` 的唯一路径（自顶向下）。

**证明**：由引理 3，循环每轮把当前节点替换成它在树中真正的父节点，且层号严格减 1；又第 1 层只有标号 1 一个节点，故循环必然在 $h = 1$ 时终止且当前节点为根。把「每次得到的节点」自底向上收集后反转，得到的序列正是从根出发、每步走到下一层子节点、最终到达 `label` 的节点序列。树中每个节点到根的路径唯一，所以该序列就是题目所求路径。∎

## 6. 复杂度分析

- **时间**：$O(\log \text{label})$。每轮一次移位、一次整数除法、两次加减，共 $h = \lfloor \log_2 \text{label} \rfloor + 1$ 轮；$\text{label} \le 10^6$ 时最多 20 轮。
- **空间**：$O(\log \text{label})$，仅为答案数组本身（最多 20 个整数）；除输出外额外空间 $O(1)$。
- 对比 §3.1 的逐层建表：时间与空间都是 $O(\text{label})$，本题里约 $10^6$ 的规模，常数与内存都远大于公式法。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    vector<int> pathInZigZagTree(int label) {
        int h = 1;                          // 层号，根为第 1 层
        while ((1 << h) <= label) ++h;      // label <= 1e6 ⇒ h <= 20

        vector<int> path;                   // 自底向上收集
        int x = label;
        while (true) {
            path.push_back(x);
            if (h == 1) break;              // 已到根，停止
            // 父节点 = 2^(h-1) + 2^(h-2) - 1 - floor(x/2)
            x = (1 << (h - 1)) + (1 << (h - 2)) - 1 - x / 2;
            --h;
        }
        reverse(path.begin(), path.end());
        return path;
    }
};
```

### Python

```python
class Solution:
    def pathInZigZagTree(self, label: int) -> list[int]:
        h = label.bit_length()          # 层号：最小的满足 2^h > label 的正整数
        path = []
        x = label
        while True:
            path.append(x)              # 自底向上收集
            if h == 1:                  # 已到根
                break
            # 镜像回「正常层序」再除 2，等价闭式
            x = (1 << (h - 1)) + (1 << (h - 2)) - 1 - x // 2
            h -= 1
        path.reverse()                  # 翻成自顶向下
        return path
```

## 8. 边界情况与易错点

1. **`label = 1`**：`h = 1`，循环第一轮就 `break`，返回 `[1]`。注意不要在 $h = 1$ 时去取 $2^{h-2}$（会移位负数，属于未定义行为）。
2. **`label = 2 / 3`（$h = 2$）**：闭式里 $2^{h-2} = 2^0 = 1$，公式退化为 $2 + 1 - 1 - \lfloor x/2 \rfloor = 1$，正好是根；写代码时不要为「$h-2 = 0$」加多余特判。
3. **把 $\lfloor x/2 \rfloor$ 直接当父节点**：`14` 的 $\lfloor 14/2 \rfloor = 7$，而真正父节点是 `4`，这是本题最常见的 WA 原因；两层方向不同时必须先镜像。
4. **浮点求层号**：`log2` 在 $x$ 恰为 2 的幂时可能返回略小的值（如 `log2(8) = 2.9999999`），下取整后层号少 1，导致整条路径错位；请用位长或循环移位。
5. **输出顺序**：迭代是自底向上的，必须 `reverse` 一次；若先把根当成末尾忘了反转，得到的会是 `[14, 4, 3, 1]`。
6. **整数除法的方向**：$x$ 恒为正，`x / 2` 与 `x // 2` 都是下取整，不需要也不应该写成 `(x - 1) / 2`；C++ 里若误用浮点除法会引入精度问题。
7. **中间量溢出**：本题 $3 \times 2^{h-1}$ 不超过 $1.6 \times 10^6$，`int` 安全；但若把数据范围改大（例如 $10^{18}$），需要改用 `long long` 并注意 `1 << (h - 1)` 的移位宽度。
