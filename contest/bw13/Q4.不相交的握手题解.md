# LeetCode 不相交的握手 题解

## 1. 题目概述

- **标题 / 题号**：不相交的握手（#1259，hard）
- **链接**：https://leetcode.cn/problems/handshakes-that-dont-cross/
- **来源**：LeetCode 第 13 场双周赛 Q4
- **难度**：困难
- **标签**：数学、动态规划

**题意**：偶数个人 `num_people` 围成一圈，每人恰与另一人握手一次，共 `num_people / 2` 次握手。求**没有任何两条握手线交叉**的方案数，对 $10^9 + 7$ 取模。

**约束**：

- $2 \le num\_people \le 1000$
- `num_people` 为偶数

## 2. 示例

**示例 1**

```text
输入：num_people = 2
输出：1
解释：唯一方案 [(1,2)]。
```

**示例 2**

```text
输入：num_people = 4
输出：2
解释：两种方案：[(1,2),(3,4)] 与 [(2,3),(4,1)]。
```

**示例 3**

```text
输入：num_people = 6
输出：5
```

**示例 4**

```text
输入：num_people = 8
输出：14
```

## 3. 解题思路

### 3.1 暴力思路

枚举 $n$ 个人的全部完美匹配（$(n-1)!! = (n-1) \times (n-3) \times \dots \times 1$ 种），对每个匹配逐对检查是否存在「端点交错」的两条握手线（相交判定：对 $(a,b)$ 与 $(c,d)$，$a<c<b<d$ 或 $c<a<d<b$ 即交叉）。$n = 8$ 时 $(7)!! = 105$ 种尚可，$n = 20$ 已是 $6.5 \times 10^8$，$n = 1000$ 完全不可行。暴力只配当对拍工具（本篇题解正是拿它验证到 $n = 12$，见 §7）。正确的切入点是**固定 1 号的握手对象**，让结构自己分治。

### 3.2 核心观察：1 号的握手线把圆切成两个独立子圈

![核心观察：握手线切分圆弧成独立子问题](images/bw13_q4_split_model.svg)

把人按顺时针编号 $1, 2, \dots, 2k$。**考察 1 号与谁握手**——这是全题的破局点：

1. **对象必为偶数编号**：设 1 号与 $j$ 号握手。握手线 $(1, j)$ 把圆上其余人切成两段弧：弧 A 含 $2, \dots, j-1$（共 $j - 2$ 人），弧 B 含 $j+1, \dots, 2k$（共 $2k - j$ 人）。**弧内的人只能与同弧的人握手**——若弧 A 中有人 $x$ 与弧 B 中有人 $y$ 握手，弦 $(x, y)$ 必然横穿弦 $(1, j)$（圆上四点交错），与「不相交」矛盾。于是两段弧的人数都必须是**偶数**：$j - 2$ 偶 ⇒ $j$ 偶。
2. **两弧独立递归**：弧 A 内部的不相交握手是**同构的小规模子问题**（线性排列上的不相交匹配），弧 B 亦然，二者互不影响，方案数相乘。
3. **卷积递推浮现**：设 $f(i)$ 为 $2i$ 个人的不相交握手方案数。枚举 1 号握第 $2(j{+}1)$ 人（$j = 0, \dots, i-1$）：左侧剩 $2j$ 人（$f(j)$ 种），右侧剩 $2(i - 1 - j)$ 人（$f(i-1-j)$ 种）。求和：

$$f(i) = \sum_{j=0}^{i-1} f(j) \cdot f(i-1-j), \qquad f(0) = 1$$

这正是**卡特兰数**的卷积定义：$f(i) = C_i$（$C_0 = 1, C_1 = 1, C_2 = 2, C_3 = 5, C_4 = 14, \dots$），与示例 $2 \to 1$、$4 \to 2$、$6 \to 5$、$8 \to 14$ 逐一吻合。

### 3.3 算法流程

![算法流程：折半后卷积DP取模](images/bw13_q4_algorithm_flow.svg)

```text
1. k = num_people / 2
2. f[0] = 1                                  # 空圈：1 种
3. for i = 1 to k:
       for j = 0 to i-1:                     # 1 号握第 2(j+1) 个人
           f[i] = (f[i] + f[j] * f[i-1-j]) mod 1e9+7
4. 返回 f[k]
```

### 3.4 示例演算

![示例演算：4人两种方案与6人五种的分类计数](images/bw13_q4_example_walkthrough.svg)

**$num\_people = 4$（$k = 2$）**：$f(2) = f(0)f(1) + f(1)f(0) = 1 + 1 = 2$，对应 $(1,2)(3,4)$（1 握 2，右侧剩 2 人）与 $(4,1)(2,3)$（1 握 4，左侧剩 2 人）两种 ✓。

**$num\_people = 6$（$k = 3$）**：按 1 号的对象分三类——

| 1 号握 | 左侧人数 | 右侧人数 | 方案数 |
|--------|----------|----------|--------|
| 2 | 0 | 4 | $f(0) \cdot f(2) = 2$ |
| 4 | 2 | 2 | $f(1) \cdot f(1) = 1$ |
| 6 | 4 | 0 | $f(2) \cdot f(0) = 2$ |

合计 $2 + 1 + 2 = 5$ ✓（与卡特兰数 $C_3 = 5$ 一致）。

## 4. 算法细节

1. **折半下标**：状态按「对数」计，$f(i)$ 对应 $2i$ 人，循环上界 $k = num\_people / 2 \le 500$，双重循环 $O(k^2) \le 2.5 \times 10^5$ 次。
2. **取模纪律**：每一步乘加后立即 `% MOD`。C++ 中用 `long long` 累乘（$< 10^9$ 的两数相乘 $< 10^{18}$，而 `long long` 上界 $9.2 \times 10^{18}$，安全）再取模；Python 大整数无溢出但仍取模防爆规模。
3. **$f(0) = 1$ 的语义**：空弧（0 人）恰有一种方案——什么都不做。它是卷积边界正确性的基石，漏设或设 0 都会全盘皆错。
4. **闭式公式备选**：$C_k = \binom{2k}{k} / (k+1)$，预处理阶乘 + 费马小逆元可 $O(k + \log p)$ 求单点；本题 $k \le 500$，卷积 DP 更直观且顺带产出所有前缀值，是首选。对拍时闭式公式恰好充当第三个独立参考。
5. **递推方向**：外层 $i$ 从小到大保证计算 $f(i)$ 时所有 $f(j), f(i-1-j)$（下标 $< i$）已就绪；内层 $j$ 顺序无关（加法交换）。
6. **为什么不需要显式建圆**：切分论证（§5 引理 2）说明圆上问题等价于「线段区间上的不相交匹配」，后者天然是区间结构；固定 1 号（区间最左端点）配对后剩余两段是**独立子区间**，无需几何计算。

## 5. 正确性证明

**引理 1（交错即相交）**：圆上四点按顺时针序 $a < b < c < d$，则弦 $(a,c)$ 与 $(b,d)$ 在圆内部相交，且这是弦相交的唯一形态（端点交错）。

**证明**：圆是凸闭曲线，弦是两端点间的线段，均在圆盘内部。由 Jordan 曲线定理，弦 $(a, c)$ 把圆盘分成两个区域，弧 $\widehat{ab} \cup$ 弦、具体地：沿圆周从 $a$ 顺时针到 $c$ 的弧与弦 $(a,c)$ 围成一区域 $R$，$b$ 在该弧上故 $b \in \partial R$，而 $d$ 在补弧上、$d \notin \bar R$。线段 $(b, d)$ 连接 $R$ 边界内点 $b$ 与 $R$ 外点 $d$，必穿越 $\partial R$；$\partial R$ 由弧 $\widehat{ac}$ 与弦 $(a,c)$ 组成，线段除端点外不触圆周（凸性：弦在开圆盘内部），故必穿越弦 $(a, c)$，即相交。反之，若两弦端点不交错（如 $(a,b)$ 与 $(c,d)$，同侧分离），两条线段分别含于两个不相交的弦切区域（由弦 $(a,b)$ 分割，$c, d$ 同在其一侧，线段 $(c,d)$ 整体在该侧；线段 $(a,b)$ 在弦上），不相交。∎

**引理 2（切分与独立性）**：设不相交握手方案中 1 号与 $j$ 号握手（$2 \le j \le 2k$）。则 $j$ 为偶数，且其余 $2k - 2$ 人的握手**不跨**弧 $A = (2, \dots, j-1)$ 与弧 $B = (j+1, \dots, 2k)$；反之，弧 $A$ 内任一不相交（线性意义下）方案与弧 $B$ 内任一方案拼接上 $(1, j)$ 得到圆上的合法方案。

**证明**：圆周顺序为 $1, 2, \dots, j, \dots, 2k$。若 $x \in A$ 与 $y \in B$ 握手，四点顺时针序为 $1, x, j, y$（或 $y, 1, x, j$ 等循环等价形态），端点 $x, y$ 与 $1, j$ 交错，由引理 1 弦 $(x,y)$ 与弦 $(1,j)$ 相交，矛盾。故弧 $A$、$B$ 各自内部配对，$|A| = j - 2$ 与 $|B| = 2k - j$ 均须为偶数，即 $j$ 偶。弧内匹配无相交（子弧上的弦即圆上的弦，线性序与圆周序在弧内一致，引理 1 的交错判定照用）。反向拼接：$(1,j)$ 与两弧内部的弦，任何两条弦或同弧（弧内已保证不相交）或分属两弧（由引理 1 的非交错形态分离），或一为 $(1,j)$ 本身（弧内弦端点同侧，非交错），全部不相交，是合法方案。∎

**定理**：$f(k)$（$2k$ 人不相交握手方案数）满足 $f(0) = 1$ 与 $f(i) = \sum_{j=0}^{i-1} f(j) f(i-1-j)$，即 $f(k) = C_k$（第 $k$ 个卡特兰数）。

**证明**：由引理 2，按 1 号的握手对象 $j' = 2, 4, \dots, 2k$（记 $j' = 2(j+1)$，$j = 0..k-1$）把方案**不重不漏**地分类：不同 $j'$ 的方案中 1 号的搭档不同必不相同（不重）；任一方案都有唯一的 1 号搭档（不漏）。固定 $j' = 2(j+1)$ 时，左侧弧 $A$ 有 $2j$ 人、右侧弧 $B$ 有 $2(k - 1 - j)$ 人，由引理 2 方案数 $f(j) \cdot f(k - 1 - j)$（两侧独立相乘）。求和即递推式，与卡特兰数满足同一初值与同一卷积，故 $f(k) = C_k$。∎

**推论（模运算正确性）**：DP 中每步取模，加法与乘法对模同余封闭（$(a + b) \bmod p$、$(a \cdot b) \bmod p$ 保持同余类），故算法输出 $C_k \bmod (10^9 + 7)$。∎

## 6. 复杂度分析

- **时间**：$O(k^2)$，$k = num\_people / 2 \le 500$，至多约 $1.25 \times 10^5$ 次乘加取模。
- **空间**：$O(k)$。一维 DP 数组（卷积需要全部前缀值，不能滚动掉——$f(i)$ 依赖所有 $f(0..i-1)$）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int numberOfWays(int numPeople) {
        const long long MOD = 1000000007LL;
        int k = numPeople / 2;                      // 折半：f[k] = 2k 个人的方案数
        vector<long long> f(k + 1);
        f[0] = 1;                                   // 空圈：1 种
        for (int i = 1; i <= k; ++i)
            for (int j = 0; j < i; ++j)             // 1 号握第 2(j+1) 个人
                f[i] = (f[i] + f[j] * f[i - 1 - j]) % MOD;
        return (int)f[k];
    }
};
```

### Python

```python
class Solution:
    def numberOfWays(self, numPeople: int) -> int:
        MOD = 10 ** 9 + 7
        k = numPeople // 2                   # f[i] = 2i 个人的方案数
        f = [0] * (k + 1)
        f[0] = 1                             # 空圈：1 种
        for i in range(1, k + 1):
            for j in range(i):               # 1 号握第 2(j+1) 个人
                f[i] = (f[i] + f[j] * f[i - 1 - j]) % MOD
        return f[k]
```

> 💡 两份代码均通过题面四个示例（$1, 2, 5, 14$），并在 $n \in \{2,4,6,8,10,12\}$ 与**枚举全部完美匹配再逐对查相交**的暴力对拍一致；$k \in [7, 250]$（C++）/ $[7, 100]$（Python）与**区间记忆化 DP** 及**闭式 $\binom{2k}{k}/(k+1) \bmod p$** 双参考对拍一致；上界 $num\_people = 1000$ 输出 $591137401$，与闭式公式吻合，`mismatch = 0`。

## 8. 边界情况与易错点

1. **$f(0) = 1$ 而非 0**：空集恰有一种「空方案」。卡特兰数全家福的边界哨兵，设错则全链崩塌（$f(1) = 0$ 起步，后面全 0）。
2. **下标折半易错**：状态数组按下标 $i$ 表示 $2i$ 人，枚举「1 号握第 $2(j+1)$ 人」时左弧 $2j$ 人、右弧 $2(i-1-j)$ 人，两个下标是 $j$ 与 $i-1-j$（**和为 $i-1$**，因为 1 号与搭档两人已被用掉）。写成 $i - j$ 会把 1 号搭档两人重复计入。
3. **取模时机**：C++ 必须 `long long` 中间量（两模数相乘逼近 $10^{18}$，`int` 直接溢出为未定义行为）；「最后统一取一次模」在 $k = 500$ 时累加值早爆 `long long`，必须逐步取。
4. **别把「不相交」弱化为「不共端点」**：完美匹配已保证每人只握一次；判定难点在弦的**交错相交**（引理 1），暴力对拍时交叉条件 `a1 < a2 < b1 < b2 || a2 < a1 < b2 < b1` 要写全两种交错形态。
5. **圆排列 vs 固定编号**：人已编号围圈、位置固定，方案按「谁与谁握手」的配对集合计数，与旋转无关（本题不是统计循环同构类）；不要自作主张除以 $2k$。
6. **$num\_people = 2$ 最小输入**：$f(1) = f(0) \cdot f(0) = 1$，直接命中。
7. **闭式公式的除法**：$C_k = \binom{2k}{k}/(k+1)$ 在模 $p$ 下要用**乘逆元**（$p$ 为质数，费马小定理 $x^{p-2}$），不能直接 `/ (k+1) % MOD`——模运算对除法不封闭。
