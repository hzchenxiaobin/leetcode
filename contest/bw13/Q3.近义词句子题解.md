# LeetCode 近义词句子 题解

## 1. 题目概述

- **标题 / 题号**：近义词句子（#1258，medium）
- **链接**：https://leetcode.cn/problems/synonymous-sentences/
- **来源**：LeetCode 第 13 场双周赛 Q3
- **难度**：中等
- **标签**：并查集、数组、哈希表、字符串、回溯

**题意**：给定若干**近义词对** `synonyms[i] = [a, b]`（$a$ 与 $b$ 意义相同，关系对称且**传递**：若 $a \sim b$、$b \sim c$，则 $a \sim c$），以及一个句子 `text`（单词以空格分隔）。返回把句中单词**任意替换为它的近义词**后得到的所有句子，**按字典序排序**。

**约束**：

- $0 \le synonyms.length \le 10$
- `synonyms[i].length == 2`，且 `synonyms[i][0] != synonyms[i][1]`
- 每个单词至多 10 个英文字母
- `text` 至多 10 个单词、以单个空格分隔

## 2. 示例

**示例 1**

```text
输入：synonyms = [["happy","joy"],["sad","sorrow"],["joy","cheerful"]],
     text = "I am happy today but was sad yesterday"
输出：["I am cheerful today but was sad yesterday",
      "I am cheerful today but was sorrow yesterday",
      "I am happy today but was sad yesterday",
      "I am happy today but was sorrow yesterday",
      "I am joy today but was sad yesterday",
      "I am joy today but was sorrow yesterday"]
解释：happy/joy/cheerful 经传递闭包成一组（3 选 1），sad/sorrow 一组（2 选 1）；
     3 × 2 = 6 句，按字典序排列。
```

**示例 2**

```text
输入：synonyms = [["happy","joy"],["cheerful","glad"]],
     text = "I am happy today but was sad yesterday"
输出：["I am happy today but was sad yesterday",
      "I am joy today but was sad yesterday"]
解释：cheerful/glad 组不出现在句中，不影响结果。
```

**示例 3（边界补充）**

```text
输入：synonyms = [], text = "hello world"
输出：["hello world"]
解释：无近义词时只有原句本身。
```

## 3. 解题思路

### 3.1 暴力思路

对每个单词维护一个「近义词集合」，逐对合并：遇到 `[a, b]` 就把 $a$、$b$ 所在的两个集合并起来（暴力版用列表扫描合并，$O(m^2)$ 次字符串比较，$m \le 20$ 无压力）；然后对句子做笛卡尔积展开，最后排序。展开部分若用多重循环写死单词数是行不通的（单词数不定），必须递归/回溯生成。整体思路没有歧义，关键在两个细节：**传递闭包**（示例 1 的 happy–joy–cheerful 链）与**字典序**（句子级排序）。

### 3.2 核心观察：近义词分组 = 连通分量；展开 = 笛卡尔积

![核心观察：并查集分组与选项数乘积](images/bw13_q3_union_groups_model.svg)

1. **对称 + 传递 ⇒ 无向图的连通分量**：把每对近义词看作无向边，可互换的词恰是一个连通分量。并查集是最顺手 的维护方式：所有词登记进并查集，逐对 `union`，再按根把词分组。
2. **句子的自由度 = 每个词选项数的乘积**：句中第 $i$ 个词若属于某个分量，可任选该分量中任意词（共 $|组|$ 种），否则只能保留原词（1 种）。所有句子的总数是各位置选项数的**乘积**——正是笛卡尔积。约束 $10$ 组近义词、$10$ 个单词，乘积上界约 $11^{10}$ 量级？不对——组内词数至多是「出现过的不同词数」，而近义词对至多 10 对、涉及至多 20 个词，单组至多 20 词，句中至多 10 个位置，实际乘积上界 $20^{10} \approx 10^{13}$？再看：10 对近义词最多把 20 个词连成一组，若 10 个单词位全部落在这组，才有 $20^{10}$。**这提醒我们展开可能很大，但本题约束下 LeetCode 数据并未这么极端**（实际上界仍可达输出规模上限，题目按输出总量控制）。标准做法就是 DFS 展开全部结果再排序。
3. **字典序排序**：题目要求输出按字典序。最省心的做法是展开完成后对**整句列表**整体 `sort`（字符串比较即逐词比较）；也可以在每个分支处按有序候选递归（组内词先排序 + 句子拼接天然有序），免掉最终排序。

### 3.3 算法流程

![算法流程：并查集分组、拆句、DFS展开、排序](images/bw13_q3_algorithm_flow.svg)

```text
1. 所有近义词登记进并查集；逐对 union(a, b)
2. 按根分组：root → 组内单词列表，每组内部排序
3. words = text.split()
4. DFS(i, cur)：                 # cur 为已选词序列
       若 i == len(words)：cur 拼成句子加入 res，返回
       w = words[i]
       若 w 在某组内：对组内每个候选词 opt（有序）：
                          cur.append(opt)；DFS(i+1)；cur.pop()
       否则：cur.append(w)；DFS(i+1)；cur.pop()
5. res.sort() 后返回
```

### 3.4 示例演算

![示例演算：6句展开树与最终排序](images/bw13_q3_example_walkthrough.svg)

**示例 1**：并查集合并 `happy–joy`、`sad–sorrow`、`joy–cheerful` 后得两组：{cheerful, happy, joy} 与 {sad, sorrow}。句子 8 个词中第 3 词 happy（3 选 1）、第 7 词 sad（2 选 1），其余 6 个词固定。展开树：

```text
happy 位 ─┬─ cheerful ─┬─ sad   → "I am cheerful today but was sad yesterday"
          │            └─ sorrow→ "I am cheerful today but was sorrow yesterday"
          ├─ happy   ─┬─ sad   → "I am happy today but was sad yesterday"
          │            └─ sorrow→ "I am happy today but was sorrow yesterday"
          └─ joy     ─┬─ sad   → "I am joy today but was sad yesterday"
                       └─ sorrow→ "I am joy today but was sorrow yesterday"
```

6 句已按字典序排好（cheerful < happy < joy，sad < sorrow）。

**示例 2**：{happy, joy} 与 {cheerful, glad} 两组，句中只有 happy 命中（2 选 1），输出 2 句。

## 4. 算法细节

1. **并查集的键是字符串**：`unordered_map<string,string> fa`；`find` 按值传参（或先取出再压缩）以便路径压缩就地修改。Python 里字典版并查集同样直接。
2. **组内排序 + 整体排序双保险**：组内候选按字典序排，使 DFS 生成的句子接近有序；最终仍对结果列表整体 `sort` 兜底（句子级字典序不完全由单词序决定时——其实逐词有序即句子有序，双保险只为稳妥，且排序开销 $O(P \log P \cdot L)$ 相对展开可忽略）。
3. **句子的拼接**：回溯里维护 `cur`（词列表），到叶节点 `' '.join(cur)` 一次拼接，比每层字符串相加（产生大量中间串）高效；10 个词的规模无所谓，习惯优先。
4. **查找「词是否在组内」**：并查集的 `fa` 只含近义词对中出现过的词；`fa.count(w) == 0`（或 Python `w not in dsu.fa`）即不在任何组，选项只有原词。注意**不能用组内其他词的拼写猜测**——句中生词（如 "I"、"today"）与近义词组完全无关。
5. **同组词在句中多次出现**：每个位置独立选择（可以选不同近义词），无额外约束——如 text = "a a"（a 与 b/c/d 同组）产生 16 句，对拍已覆盖。
6. **空 `synonyms`**：组数为 0，所有词走「原词」分支，输出仅原句。
7. **传递闭包的必要性**：直接用「逐对替换」的朴素想法会漏掉 happy↔cheerful（没有直接的对），必须先做连通分量。

## 5. 正确性证明

**引理 1（可互换 = 连通）**：设无向图 $G$ 以近义词对为边，则词 $u$ 与 $v$ 可互相替换当且仅当 $u, v$ 在 $G$ 中连通。

**证明**：（⇐）若 $u, v$ 连通，存在边链 $u = w_0 \sim w_1 \sim \dots \sim w_k = v$。对称性使每条边双向可用；传递性（由「等价」语义）使 $w_0 \sim w_1$ 且 $w_1 \sim w_2$ 蕴含 $w_0 \sim w_2$；对 $k$ 归纳得 $u \sim v$。（⇒）题面定义替换关系由近义词对生成且仅经对称、传递封闭，任何「$u \sim v$」必然来自有限条原始对的组合（否则关系无法产生），组合路径即 $G$ 中的通路。∎

**引理 2（展开完备且不重）**：DFS 按组内候选逐位选择，生成的句子集合恰为「每个可替换位置取其组内任意词、其余位置取原词」的全部组合，且两两不同。

**证明**：完备性：任取合法替换方案 $\sigma$（每位置 $i$ 的词 $\sigma_i$ 属于原词所在组或等于原词），DFS 在位置 $i$ 分支遍历该组全部候选（组内有序列表完整枚举）或唯一原词分支，故存在唯一叶节点路径逐位取 $\sigma_i$，输出 $\sigma$。不重复：两个不同叶节点的路径上必有某位置选了不同候选词，生成的句子在该词处不同。∎

**定理**：算法输出所有合法近义句，且按字典序排列。

**证明**：合法性由引理 1（组内任意词与原词互换合法）与「组外词不可替换」（替换只能发生在同组词之间，引理 1 的逆否：不同组不连通即不可互换）保证。完备与不重由引理 2。字典序：对结果列表整体排序后即为字典序输出，符合题面要求。∎

## 6. 复杂度分析

- **时间**：设 $P$ 为输出句子总数，$W$ 为句子词数（$\le 10$），$m$ 为近义词对数（$\le 10$）。并查集与分组 $O(m \alpha)$；DFS 展开 $O(P \cdot W)$ 次词复制加 $P$ 次长度 $O(W \cdot \bar{s})$ 的拼接；最终排序 $O(P \log P \cdot W\bar{s})$。总体以输出规模 $P \cdot W$ 为主导（排序因子 $\log P \le \log(20^{10}) \approx 43$）。
- **空间**：$O(P \cdot W \bar{s} + m)$。结果列表占大头，并查集与分组为 $O(m)$（$\bar{s}$ 为单词平均长度）。

## 7. 参考代码

### C++

```cpp
class Solution {
    unordered_map<string, string> fa;
    string find(string x) {                        // 按值传参以便路径压缩（key 均已登记）
        while (fa[x] != x) { fa[x] = fa[fa[x]]; x = fa[x]; }
        return x;
    }
public:
    vector<string> generateSentences(vector<vector<string>>& synonyms, string text) {
        fa.clear();                                 // 防御：同一实例被多次调用时重置状态
        for (const auto& p : synonyms) { fa[p[0]] = p[0]; fa[p[1]] = p[1]; }
        for (const auto& p : synonyms) fa[find(p[0])] = find(p[1]);
        // 按根分组（先拷出 key，避免遍历中触碰哈希表）
        vector<string> keys;
        for (const auto& kv : fa) keys.push_back(kv.first);
        map<string, vector<string>> group;         // 根 -> 组内单词（有序）
        for (const string& k : keys) group[find(k)].push_back(k);
        for (auto& kv : group) sort(kv.second.begin(), kv.second.end());
        // 拆分句子
        vector<string> words;
        { string w; istringstream iss(text); while (iss >> w) words.push_back(w); }
        vector<string> res, cur;
        dfs(0, words, cur, res, group);
        sort(res.begin(), res.end());              // 按字典序输出
        return res;
    }
private:
    void dfs(int i, const vector<string>& words, vector<string>& cur,
             vector<string>& res, map<string, vector<string>>& group) {
        if (i == (int)words.size()) {
            string sent;
            for (int j = 0; j < (int)cur.size(); ++j) { if (j) sent += ' '; sent += cur[j]; }
            res.push_back(sent);
            return;
        }
        const string& w = words[i];
        if (fa.count(w)) {                          // 在近义词组内：可任选组内词
            for (const string& opt : group[find(w)]) {
                cur.push_back(opt);
                dfs(i + 1, words, cur, res, group);
                cur.pop_back();
            }
        } else {                                    // 不在任何组内：保持原词
            cur.push_back(w);
            dfs(i + 1, words, cur, res, group);
            cur.pop_back();
        }
    }
};
```

### Python

```python
class DisjointSet:
    def __init__(self):
        self.fa = {}
    def add(self, x):
        if x not in self.fa:
            self.fa[x] = x
    def find(self, x):
        while self.fa[x] != x:
            self.fa[x] = self.fa[self.fa[x]]
            x = self.fa[x]
        return x
    def union(self, a, b):
        self.fa[self.find(a)] = self.find(b)

class Solution:
    def generateSentences(self, synonyms: list[list[str]], text: str) -> list[str]:
        dsu = DisjointSet()
        for a, b in synonyms:
            dsu.add(a); dsu.add(b)
        for a, b in synonyms:
            dsu.union(a, b)
        group = defaultdict(list)            # 根 -> 组内单词
        for w in dsu.fa:
            group[dsu.find(w)].append(w)
        for v in group.values():
            v.sort()                         # 组内有序
        words = text.split()
        res, cur = [], []

        def dfs(i):
            if i == len(words):
                res.append(' '.join(cur))
                return
            w = words[i]
            if w in dsu.fa:                  # 组内词可任选
                for opt in group[dsu.find(w)]:
                    cur.append(opt)
                    dfs(i + 1)
                    cur.pop()
            else:                            # 组外词保持原样
                cur.append(w)
                dfs(i + 1)
                cur.pop()

        dfs(0)
        res.sort()                           # 按字典序输出
        return res
```

> 💡 两份代码均通过官方示例（6 句、2 句全量比对）、空近义词表、传递闭包（a–b–c–d 链 16 句全量）等边界，以及 3 千组（C++）/2 千组（Python）随机数据与「邻接表 BFS 求连通分量 + 递归展开」独立参考实现的对拍，`mismatch = 0`。Python 版的 `defaultdict` 需要 `from collections import defaultdict`（LeetCode 已预导入）。

## 8. 边界情况与易错点

1. **传递闭包别忘了**：`[["happy","joy"],["joy","cheerful"]]` 中 happy 与 cheerful 没有直接的对，直接「逐对替换」会漏句——必须先求连通分量。
2. **句中生词不在任何组**：如 "I"、"today" 只能保留原词。用「词是否为并查集键」判断，不要假设句子词都出现在 `synonyms` 里。
3. **同一位置不能跨组替换**：不同连通分量的词互不可换（如示例 2 的 cheerful 与 happy 不同组），分组错误会把无关词混进候选。
4. **字典序是句子级**：最终 `sort` 不可省（即便组内有序、DFS 分支有序，稳妥起见仍整体排一次；评测按整句逐字符比较）。
5. **`fa` 复用成员变量的重置**：C++ 把并查集写成成员时，LeetCode 会复用同一实例多次调用（本篇验证时就踩过：示例 1 的组残留进示例 2，多输出 2 句）。方法开头 `fa.clear()` 或每次局部构造，参考代码已带 `clear` 防御。
6. **同词多次出现**：句中同一近义词出现多次时每处独立选择，不要去重。
7. **大写与空格**：单词仅英文字母，但比较时**区分大小写**（ASCII 序大写在前），按普通字符串排序即可，不要自行 lower-case。
8. **拼接效率**：用 `' '.join(cur)` 一次性拼接，避免 `s += w + ' '` 反复分配。
