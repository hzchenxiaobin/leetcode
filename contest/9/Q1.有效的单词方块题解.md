# LeetCode 有效的单词方块 题解

## 1. 题目概述

- **标题 / 题号**：有效的单词方块（#422，easy）
- **链接**：https://leetcode.cn/problems/valid-word-square/
- **来源**：LeetCode 第 9 场周赛 Q1
- **难度**：简单
- **标签**：数组、矩阵

**题意**：给定一个单词序列 `words`，若对每个 $k \in [0, \max(\text{行数}, \text{列数}))$，第 $k$ 行与第 $k$ 列读出的字符串**完全相同**，则它构成一个「有效的单词方块」，返回 `true`，否则返回 `false`。其中第 $k$ 行就是 `words[k]`；第 $k$ 列由所有「长度超过 $k$」的单词的第 $k$ 个字符按行号顺序拼接而成。行与列**允许不等长**，整体也不一定是方阵（见示例 2）。

**约束**：

- $1 \le \text{words.length} \le 500$
- $1 \le \text{words[i].length} \le 500$
- `words[i]` 仅含小写英文字母 `a`–`z`

> 💡 $k$ 的上界是 $\max(\text{行数},\text{列数})$，这暗示**列可能比行多**：只要有一个单词比单词个数还长，它多出来的那几位就必然与"不存在的行"冲突，这种情况必须判负。

## 2. 示例

**示例 1**

```text
输入：words = ["abcd","bnrt","crmy","dtye"]
输出：true
解释：第 0~3 行依次是 "abcd"、"bnrt"、"crmy"、"dtye"；
      第 0~3 列也依次读出 "abcd"、"bnrt"、"crmy"、"dtye"，四对全部相同。
```

**示例 2**

```text
输入：words = ["abcd","bnrt","crm","dt"]
输出：true
解释：后两行只有 3、2 个字母，但第 2 列读出 "crm"、第 3 列读出 "dt"，
      与第 2、3 行完全一致——参差不齐的“下三角缺失”同样可以构成单词方块。
```

**示例 3**

```text
输入：words = ["ball","area","read","lady"]
输出：false
解释：第 2 行是 "read"，第 2 列却是 "lead"（第 0 行第 2 个字母是 'l'，不是 'r'）。
```

## 3. 解题思路

### 3.1 暴力思路

最直白的有两种写法：

1. **补齐成方阵再比较**：令 $S = \max(n, L)$，把参差网格补成 $S \times S$，缺失格填一个**不属于 `a`–`z`** 的哨兵字符，然后逐格比较 $P[i][j]$ 与 $P[j][i]$。这是对的，但要 $O(S^2)$ 时间与空间（最坏 $500 \times 500$），而且哨兵必须选 `a`–`z` 以外的字符：图省事拿某个字母去补，缺失格就会和真实字符判成"相等"，把非法结果判成合法。
2. **显式造列再比较**：对每个 $k$ 把第 $k$ 列的字符拼成 $C_k$，再与 `words[k]` 比较。时间 $O(nL)$，额外空间 $O(nL)$，还得为「第 $k$ 行不存在」补空串、对齐下标。

两种写法都能在 $2.5\times 10^5$ 的规模内跑完，但都在**先造出一个完整矩阵/列串**之后才比较。可本题的判定其实**不需要任何额外空间**（见 3.2）。

### 3.2 核心观察：行 = 列 ⟺ 网格等于自己的转置

![单词方块等价于网格与自身转置一致](images/wc9_q1_transpose_grid.svg)

把 `words` 看成一个**参差网格**：第 $i$ 行是 `words[i]`，格子 $(i,j)$（$j < \lvert words[i] \rvert$）里存 `words[i][j]`。于是：

- 「第 $k$ 列」就是网格第 $k$ 列自上而下读出的字符串；
- 「第 $k$ 行 = 第 $k$ 列」对所有 $k$ 成立，等价于说：**网格等于它自己的转置**。

换成转置的语言，判据变得极简：对**每个存在的格子** $(i,j)$，镜像格子 $(j,i)$ 必须**也存在，且字符相同**。破坏方式只有三种：

1. **行比"行数"还长**：$j \ge n$，第 $j$ 列根本不存在；
2. **列比行短**：$i \ge \lvert words[j] \rvert$，镜像格子空缺；
3. **字符不等**：$words[i][j] \ne words[j][i]$。

> 💡 「格子缺失」不等于「字符为空」：它压根没有格子，也就谈不上"与镜像相等"。所以直接用越界判负，比补哨兵更安全、更省空间——注意两个**同时**缺失的格子本来就对称，不该判负（示例 2 的 $(2,3)$ 与 $(3,2)$ 正是如此）。

### 3.3 算法流程

![三个失败条件，任一成立即判负](images/wc9_q1_check_flow.svg)

```text
for i in 0 .. n-1:
    for j in 0 .. len(words[i])-1:
        if j >= n                     : return false   # 第 j 列不存在
        if i >= len(words[j])         : return false   # 镜像格缺失
        if words[i][j] != words[j][i] : return false   # 镜像字符不等
return true
```

三个条件可以合并成一行 `if`。**只遍历存在的格子**，参差部分的空位天然被跳过，既不补齐也不占额外空间。

### 3.4 示例演算

![示例 3 演算：第 2 行与第 2 列在首字符分叉](images/wc9_q1_example3_walkthrough.svg)

以示例 3 `["ball","area","read","lady"]`（$n=4$，每行恰好 4 个字母）按行优先顺序走一遍：

| 顺序 | 格子 $(i,j)$ | `words[i][j]` | 镜像 `words[j][i]` | 结论 |
|------|--------------|---------------|--------------------|------|
| 1 | $(0,0)$ | `b` | `b` | 通过 |
| 2 | $(0,1)$ | `a` | `a` | 通过 |
| 3 | $(0,2)$ | `l` | `l` | 通过 |
| 4 | $(0,3)$ | `l` | `l` | 通过 |
| 5 | $(1,0)$ | `a` | `a` | 通过 |
| 6 | $(1,1)$ | `r` | `r` | 通过 |
| 7 | $(1,2)$ | `e` | `e` | 通过 |
| 8 | $(1,3)$ | `a` | `a` | 通过 |
| 9 | $(2,0)$ | `r` | `l` | **不等 → 返回 false** |

第 9 步正好对上「第 2 行 `read` vs 第 2 列 `lead`」：两者在首字符就分叉，后面无需再比。再看不那么规整的示例 2（$n=4$）：

| 行 | 该行要检查的格子 | 镜像位置 | 结论 |
|----|------------------|----------|------|
| 0（`abcd`） | $(0,0)$–$(0,3)$ | $(0,0)$–$(3,0)$，四行都非空 | 全部通过 |
| 1（`bnrt`） | $(1,0)$–$(1,3)$ | $(0,1)$–$(3,1)$，四行长度都 $\ge 2$ | 全部通过 |
| 2（`crm`） | $(2,0)$–$(2,2)$ | $(0,2),(1,2),(2,2)$，均存在且相等 | 全部通过 |
| 3（`dt`） | $(3,0)$–$(3,1)$ | $(0,3),(1,3)$，均存在且相等 | 全部通过 |

第 2、3 行分别只有 3、2 个字符，故 $(2,3)$、$(3,2)$、$(3,3)$ 根本不存在，循环不会访问——这正是「参差也合法」的实现来源。

## 4. 算法细节

1. **外层边界**：外层取 $n = \lvert words \rvert$（行数），内层取 $\lvert words[i] \rvert$（该行字符数）；不要写成固定 $n$，更不要写成"最长单词长度"（会越界）。
2. **三个失败条件缺一不可**：漏掉 $j \ge n$ 会把「行比行数长」判成合法；漏掉 $i \ge \lvert words[j] \rvert$ 会漏掉「列比行短」；漏掉字符比较当然更不行。
3. **不能只扫上三角（$i \le j$）**：「列比行短」的失败点可能落在下三角，形如 `["ab","ba","c"]` 的第 $(2,0)$ 个格子；它的镜像 $(0,2)$ 根本不存在，没有别的格子能替你发现问题。
4. **不要用负索引兜底**：Python 里 `words[j][-1]` 不报错而是悄悄取到行末字符，把越界检查写丢了就会得到看似合理的错误答案。先判长度，再取字符。
5. **C++ 无符号陷阱**：`words[i].size()` 是 `size_t`；若直接写 `i < words[j].size()` 而 `i` 是 `int`，负值会被悄悄转成极大的无符号数。先把长度取成 `int`、比较两边都是 `int` 最稳。
6. **可提前退出**：三个条件任一成立立即 `return false`；无需把整个网格扫完。
7. **常数级剪枝**：必有 $\lvert words[0] \rvert = n$（第 0 列恰好有 $n$ 个字符，必须与第 0 行等长），否则可直接判 `false`；但它只是剪枝，**不能**当作唯一判据。

## 5. 正确性证明

记号：$n = \lvert words \rvert$，$R_i = words[i]$；第 $k$ 列 $C_k$ 为所有满足 $k < \lvert words[r] \rvert$ 的行 $r$ 的 `words[r][k]` 按 $r$ 递增拼接成的字符串，不存在的行记为 $R_k = \varnothing$（空串）。题意即：对所有 $0 \le k < \max\left(n,\ \max_i \lvert words[i] \rvert\right)$ 有 $R_k = C_k$。

**引理 1（转置判据 ⟹ 定义）**：若对每个 $i < n$ 与每个 $j < \lvert R_i \rvert$ 都有 $j < n$、$i < \lvert words[j] \rvert$ 且 $words[i][j] = words[j][i]$，则 `words` 是有效的单词方块。

**证明**：先证所有行长度 $\le n$：反设某行 $\lvert words[i] \rvert = L > n$，则格子 $(i, n)$ 存在（$n < L$），判据却要求 $n < n$，矛盾。于是 $k \ge n$ 时 $C_k$ 与 $R_k$ 都是空串，$R_k = C_k$ 成立。再固定 $i < n$，对任意满足 $i < \lvert words[r] \rvert$ 的行 $r$，格子 $(r,i)$ 存在，判据给出 $r < \lvert R_i \rvert$，故 $\lvert C_i \rvert = \#\{r : i < \lvert words[r] \rvert\} \le \lvert R_i \rvert$；另一方面对每个 $j < \lvert R_i \rvert$，判据给出 $i < \lvert words[j] \rvert$，即行 $j$ 属于该集合，故 $\lvert C_i \rvert \ge \lvert R_i \rvert$。两者合并得 $\lvert C_i \rvert = \lvert R_i \rvert$，且集合恰为 $\{0,1,\dots,\lvert R_i \rvert - 1\}$，于是对每个 $j$ 都有 $C_i[j] = words[j][i] = words[i][j] = R_i[j]$，即 $R_i = C_i$。∎

**引理 2（定义 ⟹ 转置判据）**：若 `words` 是有效的单词方块，则对每个 $i < n$、$j < \lvert R_i \rvert$ 都有 $j < n$、$i < \lvert words[j] \rvert$ 且 $words[i][j] = words[j][i]$。

**证明**：设定义成立，记 $\ell_i = \lvert words[i] \rvert$。

1. $\ell_i \le n$：若某 $\ell_i > n$，则第 $n$ 列非空、第 $n$ 行却是空串；此时 $n < \max(n, \max_r \ell_r)$，定义要求 $R_n = C_n$，矛盾。
2. 由 $R_i = C_i$ 得 $\ell_i = \lvert C_i \rvert = \#\{r : \ell_r > i\}$。于是 $\ell_i = \#\{r : \ell_r > i\} \ge \#\{r : \ell_r > i+1\} = \ell_{i+1}$，即 $\ell_0 \ge \ell_1 \ge \cdots \ge \ell_{n-1}$ 单调不增。
3. 序列非增时，"大于 $i$ 的行"必为前缀：$\{r : \ell_r > i\} = \{0,1,\dots,\ell_i - 1\}$。
4. 取 $i < n$、$j < \ell_i$：由第 3 条得 $j < n$ 且 $\ell_j > i$，即 $i < \lvert words[j] \rvert$；又 $C_i$ 的第 $j$ 个字符正是第 $j$ 行提供的 $words[j][i]$，故 $words[i][j] = R_i[j] = C_i[j] = words[j][i]$。∎

**定理**：算法返回 `true` 当且仅当 `words` 构成有效的单词方块。

**证明**：算法返回 `false` 当且仅当某次检查中三个条件之一成立，即存在 $i < n$、$j < \lvert R_i \rvert$，使 $j \ge n$ 或 $i \ge \lvert words[j] \rvert$ 或 $words[i][j] \ne words[j][i]$——这正是引理 2 结论的否定（前两条意味着镜像格不存在，"字符相同"无从谈起）。由引理 1 与引理 2，转置判据与题目定义等价，故算法返回 `true` 当且仅当序列有效。∎

## 6. 复杂度分析

- **时间**：$O(m)$，其中 $m = \sum_i \lvert words[i] \rvert \le 500 \times 500 = 2.5 \times 10^5$。每个存在的格子恰好访问一次，每次 $O(1)$。
- **空间**：$O(1)$。只用两层循环下标，不构造列字符串、不复制网格。
- 对照 3.1：补齐方阵要 $O(S^2)$ 空间（$S$ 最大 500），显式造列要 $O(m)$ 空间，两者都比这里的 $O(1)$ 多。

## 7. 参考代码

### C++

```cpp
#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    bool validWordSquare(vector<string>& words) {
        int n = (int)words.size();
        for (int i = 0; i < n; i++) {
            int m = (int)words[i].size();
            for (int j = 0; j < m; j++) {
                if (j >= n) return false;                      // 第 j 列不存在
                if (i >= (int)words[j].size()) return false;    // 镜像格缺失
                if (words[i][j] != words[j][i]) return false;   // 镜像字符不等
            }
        }
        return true;
    }
};
```

### Python

```python
from typing import List

class Solution:
    def validWordSquare(self, words: List[str]) -> bool:
        n = len(words)
        for i in range(n):
            row = words[i]
            for j in range(len(row)):
                # j 必须落在一行上；第 j 行必须有第 i 个字符；字符必须镜像相等
                if j >= n or i >= len(words[j]) or row[j] != words[j][i]:
                    return False
        return True
```

> 💡 两份代码均通过全部 3 组官方示例，并与独立实现（显式构造每一列再与对应行比较）做了 500 组随机对拍（其中 136 组合法），`mismatch = 0`；另外验证了 `["a"]`、`["abc","b"]`、`["ab","ba","c"]`、`["a","a"]` 等 8 组边界。

## 8. 边界情况与易错点

1. **单单词**：`["a"]` → `true`（第 0 行、第 0 列都是 `"a"`）；`["ab"]` → `false`（第 0 列只有 1 个字符，第 0 行有 2 个）。
2. **参差但合法**：`["abcd","bnrt","crm","dt"]` → `true`。别因为后几行短、看起来"缺了一角"就提前判负。
3. **行比行数长**：`["abc","b"]` → `false`，在格子 $(0,2)$ 处触发 $j \ge n$（$n=2$ 却有一行长度为 3，第 2 列不存在）。
4. **列比行短**：`["ab","ba","c"]` → `false`（第 0 列是 `"abc"`，第 0 行只有 `"ab"`），在格子 $(2,0)$ 处触发 $i \ge \lvert words[0] \rvert$。
5. **两行相同不代表合法**：`["a","a"]` → `false`，因为第 0 列是 `"aa"` 而第 0 行只有 `"a"`；很容易被"两行一模一样"的表象骗到。
6. **空串（约束外）**：约束保证长度 $\ge 1$，但代码对空串依然正确——长度为 0 的行不产生任何检查，该列是否为空由别的行的镜像检查兜住。
7. **$k$ 的上界**：题意写的是 $\max(\text{行数},\text{列数})$，但实际只需比较 $k < n$ 的行列对——若某行比 $n$ 还长，它在第 $n$ 列上就会与"不存在的第 $n$ 行"冲突，正好被 $j \ge n$ 的检查兜住。
