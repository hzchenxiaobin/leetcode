# LeetCode 从英文中重建数字 题解

## 1. 题目概述

- **标题 / 题号**：从英文中重建数字（#423）
- **链接**：https://leetcode.cn/problems/reconstruct-original-digits-from-english/
- **来源**：LeetCode 第 9 场周赛 Q2
- **难度**：中等
- **标签**：哈希表、数学、字符串

**题意**：给定字符串 `s`，它是若干个英文数字单词（`zero` ~ `nine`）**字母打乱后拼接**起来的结果。要求还原出原始的数字集合，并按**升序**输出对应的数字串（同一数字出现几次，输出里就出现几次）。

**约束**：

- $1 \le \lvert s \rvert \le 10^5$
- `s[i]` 只可能是 `e g f i h o n s r u t w v x z` 这 15 个字母之一
- `s` 保证**合法**：一定可以由某些英文数字单词拼出

> 💡 单词边界完全丢失，本题本质是「给定字母多重集，反解各个数字单词的线性组合」。

## 2. 示例

**示例 1**

```text
输入：s = "owoztneoer"
输出："012"
解释：可拆成 "zero" + "one" + "two"，字母 z/e/r/o、o/n/e、t/w/o 打乱后恰好拼出 s；
      数字 0、1、2 各一个，升序输出 "012"。
```

**示例 2**

```text
输入：s = "fviefuro"
输出："45"
解释：可拆成 "four" + "five"，对应数字 4、5，升序输出 "45"。
```

**示例 3**（补充自测，非官方；覆盖重复数字）

```text
输入：s = "tthreehree"   （即 "three" + "three"）
输出："33"
解释：同一数字可以出现多次，答案为升序的重复数字串。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的做法是枚举：设数字 $d$ 出现 $c_d$ 次，搜索所有满足字母多重集与 `s` 一致的 $(c_0,\dots,c_9)$，搜索空间是

$$\prod_{d=0}^{9}\left(c_d+1\right)$$

当 $\lvert s\rvert = 10^5$ 时单个 $c_d$ 可达 3 万，枚举量是天文数字，完全不可行。

另一个常见误区是「按长度 3/4/5 切分 `s`，再逐段查表」：字母已经被彻底打乱，单词边界不复存在，切分没有任何依据。DFS 逐字母找单词、字符串哈希去凑也同样退化——因为 `e`、`o`、`n` 等字母被多个单词共享，分支会指数爆炸。

### 3.2 核心观察：专属字母 + 逐层减法

![专属字母与减法链](images/wc9_q2_unique_letter_chain.svg)

十个英文数字单词里，有 5 个各自含有一个**只属于自己**的字母（下文称「专属字母」）：

| 数字 | 单词 | 专属字母 | 结论 |
| --- | --- | --- | --- |
| 0 | zero | z | $c_0 = \text{cnt}[z]$ |
| 2 | two | w | $c_2 = \text{cnt}[w]$ |
| 4 | four | u | $c_4 = \text{cnt}[u]$ |
| 6 | six | x | $c_6 = \text{cnt}[x]$ |
| 8 | eight | g | $c_8 = \text{cnt}[g]$ |

这些字母在其余 9 个单词中都不出现，因此它在 `s` 里的出现次数**恰好**就是该数字的出现次数：读一次频次表即可确定，无需任何搜索。

剩下的 1、3、5、7、9 没有专属字母，但各自都能找到一个「近似专属」的关键字母，其归属集合很小：

| 待求 | 关键字母 | 该字母出现的单词 | 反推公式 |
| --- | --- | --- | --- |
| $c_1$ | o | zero, one, two, four | $c_1 = \text{cnt}[o] - c_0 - c_2 - c_4$ |
| $c_3$ | h | three, eight | $c_3 = \text{cnt}[h] - c_8$ |
| $c_5$ | f | four, five | $c_5 = \text{cnt}[f] - c_4$ |
| $c_7$ | s | six, seven | $c_7 = \text{cnt}[s] - c_6$ |
| $c_9$ | i | five, six, eight, nine | $c_9 = \text{cnt}[i] - c_5 - c_6 - c_8$ |

关键点：**每个公式右端的量都已在之前算出**——$c_0,c_2,c_4,c_6,c_8$ 来自第一层，而 $c_9$ 所需的 $c_5$ 也先于它得到。于是整件事不是需要联立求解的方程组，而是一条**单向减法链**，一遍扫完即可。

> 💡 为什么不用 `e`？`e` 出现在 zero、one、three、five、seven、eight、nine 共 7 个单词中，用它判定要预先知道 7 个量，等于没有简化。找「专属 / 近专属字母」是这类多重集反解题的通用套路。

### 3.3 算法流程

![算法流程](images/wc9_q2_count_flow.svg)

1. **建频次表**：扫一遍 `s`，用长度 26 的数组 `cnt` 统计每个字母出现次数。
2. **第一层（专属字母）**：$c_0=\text{cnt}[z]$、$c_2=\text{cnt}[w]$、$c_4=\text{cnt}[u]$、$c_6=\text{cnt}[x]$、$c_8=\text{cnt}[g]$。
3. **第二层（减法）**：按 $c_1 \to c_3 \to c_5 \to c_7 \to c_9$ 的顺序套公式；注意 $c_9$ 依赖 $c_5$，所以 $c_5$ 必须先算。
4. **输出**：从 $d=0$ 到 $9$，把字符 `'0'+d` 重复 $c_d$ 次拼进答案串，天然升序。

### 3.4 示例演算

![示例演算](images/wc9_q2_example_walkthrough.svg)

以 `s = "owoztneoer"`（共 11 个字母）为例，相关字母频次为 z=1、w=1、o=3，u=x=g=h=f=s=i=0：

| 步骤 | 计算式 | 结果 |
| --- | --- | --- |
| 专属量 | $c_0=z=1$，$c_2=w=1$，$c_4=u=0$，$c_6=x=0$，$c_8=g=0$ | 0、2 各一个 |
| $c_1$ | $3-c_0-c_2-c_4 = 3-1-1-0$ | $1$ |
| $c_3$ | $h - c_8 = 0-0$ | $0$ |
| $c_5$ | $f - c_4 = 0-0$ | $0$ |
| $c_7$ | $s - c_6 = 0-0$ | $0$ |
| $c_9$ | $i - c_5 - c_6 - c_8 = 0-0-0-0$ | $0$ |
| 拼接 | $c_0,c_1,c_2$ 各 1，其余 0 | `"012"` |

再用 `s = "fviefuro"` 交叉验证：f=2、u=1、i=1、o=1，于是 $c_4=1$、$c_5=2-1=1$、$c_1=1-0-0-1=0$、$c_9=1-1-0-0=0$，输出 `"45"`，与官方示例一致。

## 4. 算法细节

1. **频次表用定长数组**：`cnt` 开 26 个桶（C++ `vector<int> cnt(26)`，Python `[0]*26`），`cnt[ch - 'a']++`；不要用 `unordered_map`，定长数组在常数、内存和缓存友好度上都更优。
2. **必须分两层写**：先算 $c_0,c_2,c_4,c_6,c_8$，再算减法量。若把 $c_9$ 提到 $c_5$ 之前，读到的 $c_5$ 还是 0，结果直接错。
3. **公式的记忆方式**：对每个待求数字，取它的「关键字母」，把该字母的**所有宿主单词**的计数减掉。例如 `i` 的宿主是 five、six、eight、nine，减掉前三个就得到 nine。
4. **拼接答案**：C++ 用 `res.append(c[d], char('0' + d))`；Python 用 `''.join(str(d) * c[d] for d in range(10))`，避免循环内反复 `+=` 造成的额外拷贝。
5. **升序不需要排序**：按 $d=0\to9$ 拼接天然有序；若先按「拆出的顺序」收集再排序，会额外付出 $O(k\log k)$（$k \le \lvert s\rvert/3$）。
6. **合法性可以信任**：题目保证 `s` 由合法数字串打乱而来，减法结果必定非负，无需校验。若想防御非法输入，则每次减法后判断是否小于 0。
7. **无需再做总量校验**：每个字母都被它所属的公式恰好「用掉」一次，长度与非负性由输入保证，因此不必再扫一遍验证答案。

## 5. 正确性证明

**引理 1（专属字母）**：对 $d \in \{0,2,4,6,8\}$，存在字母 $k_d$ 只出现在 $d$ 的单词中，故 $\text{cnt}[k_d] = c_d$。

**证明**：枚举十个单词的字母构成即可验证：`z` 只在 zero，`w` 只在 two，`u` 只在 four，`x` 只在 six，`g` 只在 eight。`s` 中每个 $k_d$ 都来自数字 $d$ 的某次出现、每次贡献恰好一个，且没有其他来源，故出现次数等于 $c_d$。∎

**引理 2（减法等式）**：五个减法公式的右端都等于对应数字的出现次数；且右端变量在代入时均已确定。

**证明**：按字母归属列出等式：`o` 属于 {zero, one, two, four}，故 $\text{cnt}[o] = c_0+c_1+c_2+c_4$，移项得 $c_1 = \text{cnt}[o]-c_0-c_2-c_4$；同理 `h` 属于 {three, eight}、`f` 属于 {four, five}、`s` 属于 {six, seven}、`i` 属于 {five, six, eight, nine}，逐一移项即得另外四式。再看依赖：$c_1$ 只用 $c_0,c_2,c_4$，$c_3$ 只用 $c_8$，$c_5$ 只用 $c_4$，$c_7$ 只用 $c_6$，$c_9$ 用 $c_5,c_6,c_8$ —— 这些右端量全部先于对应公式算出（其中 $c_0,c_2,c_4,c_6,c_8$ 由引理 1 直接得到）。∎

**引理 3（结果合法）**：按 $c_0,\dots,c_9$ 拼出的字符串长度等于 $\lvert s\rvert$，字母多重集与 `s` 完全一致。

**证明**：记 $m_d(a)$ 为字母 $a$ 在单词 $d$ 中出现的次数。由引理 1、2，对每个字母 $a$ 都有 $\text{cnt}[a] = \sum_{d=0}^{9} c_d \cdot m_d(a)$（右端的 $c_d$ 已被全部确定）。对 $a$ 求和得

$$\lvert s\rvert = \sum_{a} \text{cnt}[a] = \sum_{d=0}^{9} c_d \sum_{a} m_d(a) = \sum_{d=0}^{9} c_d \cdot \text{len}(d)$$

即拼接串长度等于 $\lvert s\rvert$；又因每个字母 $a$ 的个数等式单独成立，拼接串的字母多重集与 `s` 完全一致。∎

**定理**：算法返回的就是题目要求的唯一答案（升序数字串）。

**证明**：由引理 1、2，算法算出的每个 $c_d$ 都是输入中数字 $d$ 的真实出现次数；由引理 3，按这些次数拼出的串与输入字母多重集一致，是合法还原。

唯一性：若 $c'$ 是另一组合法次数，它也必须满足同样的字母频次等式。由专属字母等式（引理 1）直接得 $c'_0=c_0$、$c'_2=c_2$、$c'_4=c_4$、$c'_6=c_6$、$c'_8=c_8$；再由引理 2 的五个等式依次得 $c'_1=c_1$、$c'_3=c_3$、$c'_5=c_5$、$c'_7=c_7$、$c'_9=c_9$，故 $c'=c$，解唯一。

最后按 $d=0\to9$ 拼接，输出即升序数字串，与题目要求一致。∎

## 6. 复杂度分析

- **时间**：$O(\lvert s\rvert)$。扫描 `s` 建频次表 $O(\lvert s\rvert)$；10 次常数级加减 $O(1)$；拼接答案 $O(k)$，其中 $k \le \lvert s\rvert/3$。整体线性，$10^5$ 规模下只需毫秒级。
- **空间**：$O(1)$ 额外空间（不计返回串）。频次数组 26 个整数 + 答案计数 10 个整数，与输入规模无关；若把返回串计入，则为 $O(k) \le O(\lvert s\rvert)$。

## 7. 参考代码

### C++

```cpp
#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    string originalDigits(string s) {
        vector<int> cnt(26, 0);
        for (char ch : s) cnt[ch - 'a']++;

        vector<int> c(10, 0);
        // 第一层：专属字母
        c[0] = cnt['z' - 'a'];
        c[2] = cnt['w' - 'a'];
        c[4] = cnt['u' - 'a'];
        c[6] = cnt['x' - 'a'];
        c[8] = cnt['g' - 'a'];
        // 第二层：用「总数 - 已确定」反推
        c[1] = cnt['o' - 'a'] - c[0] - c[2] - c[4];
        c[3] = cnt['h' - 'a'] - c[8];
        c[5] = cnt['f' - 'a'] - c[4];
        c[7] = cnt['s' - 'a'] - c[6];
        c[9] = cnt['i' - 'a'] - c[5] - c[6] - c[8];

        string res;
        res.reserve(s.size());
        for (int d = 0; d < 10; d++) res.append(c[d], char('0' + d));
        return res;
    }
};
```

### Python

```python
class Solution:
    def originalDigits(self, s: str) -> str:
        cnt = [0] * 26
        for ch in s:
            cnt[ord(ch) - 97] += 1

        c = [0] * 10
        # 第一层：专属字母 z / w / u / x / g
        c[0] = cnt[ord('z') - 97]
        c[2] = cnt[ord('w') - 97]
        c[4] = cnt[ord('u') - 97]
        c[6] = cnt[ord('x') - 97]
        c[8] = cnt[ord('g') - 97]
        # 第二层：减法（顺序不能乱，c9 依赖 c5）
        c[1] = cnt[ord('o') - 97] - c[0] - c[2] - c[4]
        c[3] = cnt[ord('h') - 97] - c[8]
        c[5] = cnt[ord('f') - 97] - c[4]
        c[7] = cnt[ord('s') - 97] - c[6]
        c[9] = cnt[ord('i') - 97] - c[5] - c[6] - c[8]

        return ''.join(str(d) * c[d] for d in range(10))
```

## 8. 边界情况与易错点

1. **只有一个数字**：`"zero"` → `"0"`，`"nine"` → `"9"`。此时绝大多数 $c_d$ 为 0，公式不需要任何特判。
2. **同一数字重复出现**：如 `"ninenine"` → `"99"`。此时 `cnt[i]=2`，$c_9 = 2 - 0 - 0 - 0 = 2$，公式对重复次数同样成立。
3. **`i` 的减法最易漏项**：`i` 同时属于 five、six、eight、nine，漏减任意一项都会让 $c_9$ 偏大；`o` 同理必须减掉 zero、two、four 三个。
4. **不要拿 `e` 当判定字母**：`e` 出现在 7 个单词中，用它需要联立求解，无法单遍完成，容易写出死循环或需要回溯的代码。
5. **C++ 字符下标**：统一写 `cnt[ch - 'a']`，不要写 `cnt[ch]`（可读性差且依赖字符集）；本题输入仅含 15 个小写字母，不存在越界。
6. **Python 的字符下标**：`str` 不能相减，必须写 `cnt[ord(ch) - 97]`，不能照抄 C++ 的 `ch - 'a'`；结果用 `join` 而不是循环 `+=`。
7. **答案长度上界**：最短单词 `zero`/`two`/`six` 长度为 3，故 $k \le \lfloor \lvert s\rvert/3 \rfloor$，开数组或估计输出规模时按此上界。
