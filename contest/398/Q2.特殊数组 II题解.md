# LeetCode 特殊数组 II 题解

## 1. 题目概述

- **标题 / 题号**：特殊数组 II（#3152，medium）
- **链接**：https://leetcode.cn/problems/special-array-ii/
- **来源**：LeetCode 第 398 场周赛 Q2
- **难度**：中等
- **标签**：数组、前缀和、二分查找

**题意**：如果数组的**每一对相邻元素**都是两个**奇偶性不同**的数字，则称该数组为**特殊数组**。给定整数数组 `nums` 与查询矩阵 `queries`（$queries[i] = [from_i, to_i]$），对每个查询判断**子数组** $nums[from_i..to_i]$ 是不是特殊数组，返回布尔数组 `answer`。

**约束**：

- $1 \le n = nums.length \le 10^5$
- $1 \le nums[i] \le 10^5$
- $1 \le queries.length \le 10^5$
- $queries[i].length = 2$，$0 \le from_i \le to_i \le n - 1$

> 💡 **读题关键**：本场 Q1（3151 特殊数组 I）问「**整个**数组特殊吗」，一趟线性扫描即可；Q2 把它放大成「**q 个任意区间**各自特殊吗」。$n, q$ 同阶 $10^5$，任何「每次查询重扫一遍区间」的做法都会被总量卡死——判定信息必须**预处理**成每个查询 $O(1)$ 就能读取的结构。这是「单次判定 → 区间批量查询」最经典的一次升级，也是前缀和模板的教科书入口。

## 2. 示例

**示例 1**

```text
输入：nums = [3,4,1,2,6], queries = [[0,4]]
输出：[false]
解释：子数组为 [3,4,1,2,6]。2 和 6 都是偶数（存在同奇偶的相邻对），不是特殊数组。
```

**示例 2**

```text
输入：nums = [4,3,1,6], queries = [[0,2],[2,3]]
输出：[false,true]
解释：子数组 [4,3,1] 中 3 和 1 都是奇数 → false；
      子数组 [1,6] 唯一的相邻对 (1,6) 奇偶互异 → true。
```

**示例 3（自造，覆盖单元素查询）**

```text
输入：nums = [2,4], queries = [[0,1],[0,0]]
输出：[false,true]
解释：[2,4] 两元素同为偶数 → false；[2] 只有一个元素、没有相邻对 → true（空真）。
```

## 3. 解题思路

### 3.1 暴力思路：逐查询扫描区间

把 Q1 的判定直接套到每个查询上：对 $[l, r]$ 从 $l+1$ 扫到 $r$，逐对检查 $nums_{i-1}$ 与 $nums_i$ 奇偶是否互异，遇到同奇偶立即判 `false`。单查询最坏 $O(n)$，总计：

$$O(n \cdot q) = 10^5 \times 10^5 = 10^{10}$$

必然超时。问题不在判定本身，而在于**静态信息被反复重算**——`nums` 全程不变，某个间隙是否违规是一次就能算完的**静态事实**，第 $10^5$ 个查询却还在重查第 1 个间隙。

### 3.2 核心观察：违规对 0/1 化 + 前缀和，查询变两数相减

![核心概念：违规间隙 0/1 化后做前缀和，区间查询变两数相减](images/wc398_q2_prefix_sum_model.svg)

分三步：

**第一步：判定的原子单位只有 $n-1$ 个间隙。**「特殊」的全部信息只藏在相邻对的间隙里。把每个间隙的二值事实编码成**违规位**：

$$d_i = \begin{cases} 1, & nums_i \text{ 与 } nums_{i-1} \text{ 同奇偶（违规）} \\ 0, & \text{否则（合法）} \end{cases} \qquad (i = 1, \ldots, n-1)$$

**第二步：子数组特殊 ⟺ 区间内违规位全 0。**子数组 $[l, r]$ 恰好包含间隙 $d_{l+1}, \ldots, d_r$（$l$ **左侧**的间隙与它无关），于是：

$$[l, r] \text{ 特殊} \iff \sum_{k=l+1}^{r} d_k = 0$$

**第三步：区间求和 → 前缀和两点相减。**令 $pre_i = \sum_{k=1}^{i} d_k$（$pre_0 = 0$），即**前 $i$ 个间隙中的违规总数**，则上述条件一刀截断：

$$[l, r] \text{ 特殊} \iff pre_r - pre_l = 0$$

每个查询只剩**两次下标访问 + 一次比较**。两个天然的边界红利：

- $l = r$（单元素查询）：和式为空，差为 0，自动 `true`——「没有相邻对 ⟹ 空真」被前缀和免费送出，无需特判；
- 违规位挂在**间隙** $i$ 上而非元素 $i$ 头上，$pre_r - pre_l$ 恰好只截取 $(l, r]$ 内的间隙，端点边界自动正确。

### 3.3 算法流程

![算法流程：一趟 O(n) 预处理 + 逐查询 O(1) 判定](images/wc398_q2_algorithm_flow.svg)

两阶段：

1. **预处理**（一趟）：$pre_0 = 0$；对 $i = 1 \ldots n-1$ 依次计算 $pre_i = pre_{i-1} + d_i$，其中 $d_i = 1$ 当且仅当 $(nums_i \oplus nums_{i-1}) \,\&\, 1 = 0$（异或末位为 0 ⟺ 同奇偶）；
2. **逐查询**：取出 $[l, r]$，$answer_i = (pre_r = pre_l)$，直到 $q$ 个查询全部处理完。

### 3.4 示例演算

![示例演算：pre 两数相减，答案立即出炉](images/wc398_q2_example_walkthrough.svg)

以示例 2 `nums = [4,3,1,6]` 演算：间隙违规位 $d_1 = 0$（4 偶 3 奇）、$d_2 = 1$（3 奇 1 奇）、$d_3 = 0$（1 奇 6 偶），故 $pre = [0, 0, 1, 1]$：

| 查询 | 计算式 | 违规间隙是否落入 $(l, r]$ | 结果 |
|------|--------|--------------------------|------|
| `[0,2]` | $pre_2 - pre_0 = 1 - 0 = 1$ | $d_2$（3 与 1 同奇）落入 | **false** |
| `[2,3]` | $pre_3 - pre_2 = 1 - 1 = 0$ | 无 | **true** |

**「+1 跳变」的位置就是违规间隙**：$pre$ 从某个位置起抬升 1 并保持——查询区间只要**跨过一次跳变**，两端差值即非 0，立即 `false`；区间完全落在同一段平稳段内则差为 0，`true`。

## 4. 算法细节

1. **违规位的挂点**：$d_i$ 记在**间隙** $i$（元素 $i-1$ 与 $i$ 之间）上，$i \in [1, n-1]$。若误记在元素头上（如「$i$ 与前一个同奇偶」记在 $i$），做差 $pre_r - pre_l$ 的语义会偏移一位，$l$ 处的违规被错误计入或排除，边界特判就没完没了——挂点选对，边界自动正确。
2. **前缀和定义**：$pre_0 = 0$，$pre_i$ 表示**前 $i$ 个间隙**（间隙 $1 \ldots i$）中的违规总数。查询 $[l, r]$ 对应的判定区间是 $[l+1, r]$，恰好由 $pre_r - pre_l$ 截出——两端都不含 $l$ 左侧的信息。
3. **奇偶判定**：$(a \oplus b) \,\&\, 1$——异或末位为 0 ⟺ 同奇偶，为 1 ⟺ 互异；等价写法 `a % 2 == b % 2`。
4. **C++ 运算符优先级**：`==` 的优先级**高于** `&` 与 `^`，`(a ^ b) & 1 == 0` 会被解析成 `(a ^ b) & (1 == 0)` 即 `(a ^ b) & 0`——恒为 0，不报错但判定全错。必须写全括号 `((a ^ b) & 1) == 0`。Python 恰好相反（`&` 高于 `==`），同一行表达式在两种语言里语义不同，移植时务必核对。
5. **返回类型**：题目要布尔数组，C++ 用 `vector<bool>`、Python 用 `List[bool]`，直接 push/append 比较结果即可。

## 5. 正确性证明

**引理 1**：子数组 $[l, r]$ 中的相邻对构成的集合恰为 $\big\{(i-1,\ i) : l+1 \le i \le r\big\}$。

**证明**：下标对 $(i-1, i)$ 的两个元素同时落入 $[l, r]$ 当且仅当 $l \le i-1$ 且 $i \le r$，即 $l+1 \le i \le r$。∎

**引理 2**：$[l, r]$ 是特殊数组 $\iff \sum_{k=l+1}^{r} d_k = 0$。

**证明**：由定义，数组特殊 ⟺ 每一对相邻元素奇偶互异。由引理 1，$[l, r]$ 的相邻对与间隙 $d_{l+1}, \ldots, d_r$ 一一对应，且 $d_k = 1 \iff$ 对应相邻对同奇偶（违规）。故「所有相邻对合法」⟺「$d_{l+1}, \ldots, d_r$ 全为 0」⟺ 它们的和为 0。当 $l = r$ 时和式为空、值为 0，与「单元素数组没有相邻对、空真为特殊」一致。∎

**定理**：算法对每个查询 $[l, r]$ 返回 `true` 当且仅当 $[l, r]$ 是特殊数组。

**证明**：由 $pre$ 的定义，$pre_r - pre_l = \sum_{k=1}^{r} d_k - \sum_{k=1}^{l} d_k = \sum_{k=l+1}^{r} d_k$（telescoping，对任意 0/1 序列精确成立）。算法返回 $pre_r = pre_l \iff pre_r - pre_l = 0 \iff \sum_{k=l+1}^{r} d_k = 0$，再由引理 2 即得结论。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n + q)$。预处理一趟扫 $n-1$ 个间隙，每个一次异或 + 按位与 + 加法；$q$ 个查询各 $O(1)$（两次下标访问 + 一次比较）。对比暴力 $O(nq) = 10^{10}$，快 5 个数量级。
- **空间复杂度**：$O(n)$，即 `pre` 数组；不计输出 `answer`（$O(q)$）。若改用等价的「段起点」数组（见延伸思考）同为 $O(n)$。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    vector<bool> isArraySpecial(vector<int>& nums, vector<vector<int>>& queries) {
        int n = nums.size();
        vector<int> pre(n, 0);   // pre[i]：前 i 个间隙中的违规对数，pre[0] = 0
        for (int i = 1; i < n; i++) {
            // 括号必须带全：C++ 中 == 优先级高于 & 和 ^
            pre[i] = pre[i - 1] + (((nums[i] ^ nums[i - 1]) & 1) == 0);
        }

        vector<bool> ans;
        ans.reserve(queries.size());
        for (const auto& q : queries) {
            ans.push_back(pre[q[1]] == pre[q[0]]);   // 区间违规数为 0 ⟺ 特殊
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def isArraySpecial(self, nums: List[int], queries: List[List[int]]) -> List[bool]:
        pre = [0] * len(nums)
        for i in range(1, len(nums)):
            # Python 中 & 优先级高于 ==，此行无需再套括号
            pre[i] = pre[i - 1] + ((nums[i] ^ nums[i - 1]) & 1 == 0)
        return [pre[r] == pre[l] for l, r in queries]
```

> 💡 Python 中 `bool` 是 `int` 的子类，`pre[i-1] + True` 合法，省去显式转换。提交前用示例 2 自测：输出应为 `[false, true]`——若得 `[true, false]`，多半是违规位条件写反（`== 0` 写成 `!= 0`）。

## 8. 边界情况与易错点

1. **单元素查询 $from = to$**：无相邻对，空真 → `true`。前缀和自动覆盖（$pre_r - pre_l = 0$），**无需特判**；若手写逐对扫描，循环从 $l+1$ 开始时天然不执行，也安全。
2. **$n = 1$**：没有间隙，`pre` 只有 `pre[0] = 0`，查询只能是 `[0,0]`，恒 `true`。预处理循环一次都不进，代码无需修改。
3. **违规位挂点**：记在**间隙** $i$（$1 \le i \le n-1$）上，不是元素上。挂错位置会使 $pre_r - pre_l$ 偏移一位，是最隐蔽的 WA 来源（示例 2 正好能测出：`[2,3]` 会误判）。
4. **C++ 优先级陷阱**：`==` 高于 `&` / `^`，`(a ^ b) & 1 == 0` 恒等于 `(a^b) & 0 = 0`——**编译不报错但判定全错**（永远不记违规，所有查询都返回 `true`）。全套括号 `(((a ^ b) & 1) == 0)` 是唯一安全写法；Python 优先级相反，同一表达式直接可用。
5. **循环边界**：预处理从 $i = 1$ 开始、到 $i \le n - 1$ 结束；写成 `i < n - 1` 会漏掉最后一个间隙，恰使 `[l, n-1]` 类查询误判。
6. **返回值类型**：题目要布尔数组，不要返回 0/1 整数列表；C++ 记得 `reserve` 避免反复扩容。

**延伸思考**：

- **段起点视角**：把数组切成极长特殊段，记录 $start_i$ = 「$i$ 所在段的最左下标」（$nums_i$ 与 $nums_{i-1}$ 同奇偶则 $start_i = i$，否则延续 $start_{i-1}$），则 $[l, r]$ 特殊 $\iff start_r \le l$。与前缀和法是同一信息的两种编码（$start_r \le l \iff pre_r = pre_l$），复杂度同为 $O(n + q)$。
- **二分视角**（对应标签 Binary Search）：把违规间隙下标收进有序数组 `bad`，每次查询二分找第一个 $\ge l+1$ 的元素、看它是否 $\le r$，单查询 $O(\log n)$，违规稀疏时更省内存。
- **动态修改**：若允许点更新 `nums[i] = v`，受影响的只有间隙 $i$ 与 $i+1$——改用树状数组维护违规位，点更新与查询均 $O(\log n)$，即 3187 的做法。
