# LeetCode 所有数对中数位差之和 题解

## 1. 题目概述

- **标题 / 题号**：所有数对中数位差之和（#3153，medium）
- **链接**：https://leetcode.cn/problems/sum-of-digit-differences-of-all-pairs/
- **来源**：LeetCode 第 398 场周赛 Q3
- **难度**：中等
- **标签**：数组、哈希表、数学、计数

**题意**：给定一个只含**正整数**的数组 `nums`，保证所有整数的**数位长度相同**。两个整数的**数位差**定义为二者**相同位置**上**不同数字**的数目。求 `nums` 中**所有数对** $(i, j)$（$i < j$）的数位差之和。

**约束**：

- $2 \le n = nums.length \le 10^5$
- $1 \le nums[i] < 10^9$（至多 9 个数位）
- `nums` 中所有整数数位长度相同

> 💡 **读题关键**：「所有数位长度相同」是本题的命门——它意味着把所有数竖着排开后**数位天然按列对齐**，数位差可以**按位独立计算**。而「所有数对」加上 $n$ 高达 $10^5$，意味着 $O(n^2)$ 的逐对枚举不可行，必须把「**数对层面**的计数」降维成「**数字层面**的计数」。

## 2. 示例

**示例 1**

```text
输入：nums = [13, 23, 12]
输出：4
解释：
- 13 和 23 的数位差为 1（十位 1≠2，个位 3=3）
- 13 和 12 的数位差为 1（十位 1=1，个位 3≠2）
- 23 和 12 的数位差为 2（十位 2≠1，个位 3≠2）
总和 = 1 + 1 + 2 = 4
```

**示例 2**

```text
输入：nums = [10, 10, 10, 10]
输出：0
解释：所有数完全相同，任何数对在每个数位上数字都相同，数位差恒为 0。
```

**示例 3（自造，覆盖一位数与重复数字）**

```text
输入：nums = [22, 23, 33]
输出：4
解释：逐对计算：(22,23)=1，(22,33)=2，(23,33)=1，合计 4。
      按列看：十位一列 [2,2,3] 贡献 2，个位一列 [2,3,3] 贡献 2。
```

## 3. 解题思路

### 3.1 暴力思路：双重循环逐对比较

枚举所有 $O(n^2)$ 个数对，每个数对再逐位比较（至多 9 位）：

$$O(n^2 \cdot d) \approx (10^5)^2 \times 9 = 9 \times 10^{10}$$

必然超时。与 Q2 不同的是，这里连「枚举数对」本身就扛不住——事实「数对 $(i,j)$ 在位 $p$ 上不同」的总量是 $O(n^2 \cdot d)$ 级的，逐对处理的任何写法都注定超时。突破口只能是**不再逐对枚举**，把这些事实**按位分桶聚拢**后批量统计。

### 3.2 核心观察：按位分解 + 逐列桶计数

![核心概念：按数位分解，每列独立做桶计数](images/wc398_q3_digit_decompose.svg)

**第一步：数位差是按位可加的。** 记 $d_p(x)$ 为 $x$ 的第 $p$ 位数字，每个数对的数位差是**逐位指示器之和**：

$$\mathrm{diff}(i, j) = \sum_{p=0}^{m-1} \big[\, d_p(nums_i) \neq d_p(nums_j) \,\big]$$

把「先枚举数对、再遍历数位」的**双重求和交换次序**，总和变成「先固定数位，再数有多少数对在这一位上不同」：

$$\text{ans} = \sum_{p=0}^{m-1} \underbrace{\#\{\, (i,j) : i < j,\ d_p(nums_i) \neq d_p(nums_j) \,\}}_{\text{第 } p \text{ 列的贡献 } N_p}$$

**第二步：每一列只有 10 种数字，桶计数即可。** 固定数位 $p$ 后，我们不再关心数对，只关心**每个数字出现了几次**。设 $cnt_p[c]$ 为第 $p$ 位等于 $c$ 的数的个数（$c \in \{0, 1, \ldots, 9\}$），两数在该位不同当且仅当它们落在**不同的桶**里，于是：

$$N_p = \sum_{c_1 < c_2} cnt_p[c_1] \cdot cnt_p[c_2] = \binom{n}{2} - \sum_{c=0}^{9} \binom{cnt_p[c]}{2}$$

后一等式是「正难则反」的读法：总数对 $\binom{n}{2}$ 减去落在**同一个桶**里的相同数对。至此，$O(n^2)$ 级的数对计数降维成每列 $O(10)$ 个桶的**数字计数**。

**第三步：增量式「现结」——新数到达时当场结算。** 上式还能写成单趟扫描：处理第 $i$ 个数（0 编号）时，之前已有 $i$ 个数；设它的第 $p$ 位为 $c$，其中 $cnt_p[c]$ 个与它**相同**，那么 $i - cnt_p[c]$ 个与它**不同**——这恰好是「该新数参与的数对在第 $p$ 列上的贡献总数」：

$$\text{ans} \mathrel{+}= \sum_{p} \big( i - cnt_p[c] \big), \qquad \text{随后每位执行 } cnt_p[c] \mathrel{+}= 1$$

这一步把公式变成**一趟循环 + 查桶减法**：每个数对恰好在「后到者」到达的时刻被结算一次，之前到过的、数字不同的前辈个个计数。

### 3.3 算法流程

![算法流程：一趟扫描，新数到达时逐位现结](images/wc398_q3_algorithm_flow.svg)

1. 初始化 `ans = 0`，桶数组 `cnt[p][c]` 全 0（$p \in [0, 9)$，$c \in [0, 10)$）；
2. 依次处理 $nums_0, nums_1, \ldots, nums_{n-1}$：令 $x = nums_i$，$p = 0$；
3. 内层循环取位：只要 $x > 0$，取 $c = x \bmod 10$，执行 `ans += i − cnt[p][c]`，随后 `cnt[p][c]++`，再 `x /= 10`、`p++`；
4. 所有数处理完，`ans` 即答案。

> 💡 题目保证所有数**数位长度相同**且 $nums_i \ge 1$，因此 `while (x > 0)` 对每个数执行的次数一致，各数之间不会错位（见 §8 第 4 点）。

### 3.4 示例演算

![示例演算：三个数逐位现结的全过程](images/wc398_q3_example_walkthrough.svg)

以 `nums = [13, 23, 12]` 演算（$p = 0$ 为个位，由 `x % 10` 最先取出）：

| i | 到达的数 | 位 p | 数字 c | 结算 i − cnt[p][c] | ans |
|---|---------|------|--------|-------------------|-----|
| 0 | 13 | 0（个位） | 3 | 0 − 0 = 0 | 0 |
| 0 | 13 | 1（十位） | 1 | 0 − 0 = 0 | 0 |
| 1 | 23 | 0（个位） | 3 | 1 − 1 = 0（与 13 个位相同） | 0 |
| 1 | 23 | 1（十位） | 2 | 1 − 0 = 1（与 13 十位不同） | 1 |
| 2 | 12 | 0（个位） | 2 | 2 − 0 = 2（与 3、3 均不同） | 3 |
| 2 | 12 | 1（十位） | 1 | 2 − 1 = 1（与 2 不同、与 1 相同） | 4 |

三处非零结算合计 $1 + 2 + 1 = 4$，与逐对验证 $(13,23)=1$、$(13,12)=1$、$(23,12)=2$ 完全一致。

## 4. 算法细节

1. **取位顺序**：用 `x % 10` 从**最低位**开始取，$p$ 从 0 递增。各列互相独立，取位顺序不影响正确性，只要全程一致。
2. **桶的规模**：$nums_i < 10^9$ 至多 9 位，桶数组开 `cnt[9][10]`（90 个计数器）即可；防御性开 10 行也无妨。
3. **读桶与自增的先后**：必须**先读后增**——`ans += i - cnt[p][d]` 用的是累加前的值；若先自增再读，等于把「自己」也扣进同桶，每步恰好多减 1，整体偏差 $n \cdot m$。
4. **单趟 vs 两阶段**：本文采用单趟「现结」写法；等价的两阶段写法是先统计每列 $cnt$，再对每列计算 $\binom{n}{2} - \sum_c \binom{cnt_p[c]}{2}$，二者只差一个求和顺序（见 §5 引理 3）。
5. **溢出（本题最大的坑）**：$n = 10^5$ 时 $\binom{n}{2} \approx 5 \times 10^9$，答案上界约 $9\binom{n}{2} \approx 4.5 \times 10^{11}$，**远超 32 位 int**。C++ 累加器必须 `long long`；中途表达式 `i - cnt[p][d]` 本身不超过 $10^5$，用 int 无妨。

## 5. 正确性证明

**引理 1（按位分解）**：$\displaystyle\sum_{i<j} \mathrm{diff}(i,j) = \sum_{p=0}^{m-1} N_p$，其中 $N_p = \#\{(i,j) : i < j,\ d_p(nums_i) \neq d_p(nums_j)\}$。

**证明**：由数位差的定义，$\mathrm{diff}(i,j) = \sum_{p} [\, d_p(nums_i) \neq d_p(nums_j) \,]$——每一位比较一次，不同记 1。于是

$$\sum_{i<j} \mathrm{diff}(i,j) = \sum_{i<j} \sum_{p} [\, d_p(i) \neq d_p(j) \,] = \sum_{p} \sum_{i<j} [\, d_p(i) \neq d_p(j) \,] = \sum_{p} N_p$$

中间一步是有限项**求和次序交换**，恒合法。∎

**引理 2（桶计数公式）**：$N_p = \sum_{c_1 < c_2} cnt_p[c_1] \cdot cnt_p[c_2] = \binom{n}{2} - \sum_{c=0}^{9} \binom{cnt_p[c]}{2}$。

**证明**：把第 $p$ 位按数字分成 10 个桶 $B_0, \ldots, B_9$。无序数对 $\{i,j\}$ 在第 $p$ 位不同当且仅当二者分属不同桶。将「互异有序对」按桶对分解：先选有序的两只桶 $(c_1, c_2)$（$c_1 \neq c_2$）共 $cnt_p[c_1] \cdot cnt_p[c_2]$ 个有序对，除以 2 去序得 $N_p = \sum_{c_1 < c_2} cnt_p[c_1] \, cnt_p[c_2]$。另一方面，全体 $\binom{n}{2}$ 个无序对按「同桶 / 异桶」划分为不交两部分：同桶数对即在某桶 $B_c$ 内任取两个，共 $\binom{cnt_p[c]}{2}$，对 $c$ 求和；异桶部分恰为 $N_p$，两式相减即得后者。∎

**引理 3（增量结算 = 桶计数公式）**：单趟扫描中，第 $i$ 个数到达时在位 $p$ 上累加的 $i - cnt_p[c]$（$cnt_p[c]$ 取**累加前**的值，$c = d_p(nums_i)$）沿全程求和，恰等于 $N_p$。

**证明**：对每个无序数对 $\{i, j\}$（$i < j$）单独考察第 $p$ 位：当 $j$ 到达时，之前的数恰有 $j$ 个，按「第 $p$ 位是否等于 $c = d_p(nums_j)$」划分为「同」「异」两部分，其中同者 $cnt_p[c]$ 个、异者 $j - cnt_p[c]$ 个。$i$ 落在异部当且仅当 $d_p(nums_i) \neq d_p(nums_j)$，此时该数对恰在此刻被加 1；落在同部则加 0。故每个在位 $p$ 上不同的无序数对**恰被计一次**，相同的**恰计零次**，总和即 $N_p$。∎

**定理**：算法返回的 `ans` 等于所有数对的数位差之和。

**证明**：算法把每步的 $i - cnt_p[c]$ 累加进 `ans`。由引理 3，这些增量按位 $p$ 分组求和后恰为各列贡献 $N_p$；再由引理 1，$\sum_p N_p$ 即所求总和。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \cdot m)$，其中 $m \le 9$ 为数位长度（$nums_i < 10^9$）。外层 $n$ 个数，内层至多 9 位，每步只有一次取余、一次查桶、一次减法、一次自增；$n = 10^5$ 时约 $9 \times 10^5$ 次基本操作，对比暴力 $9 \times 10^{10}$ 快 5 个数量级。
- **空间复杂度**：$O(10m) = O(1)$ 额外空间（90 个计数器），不计输入数组。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    long long sumDigitDifferences(vector<int>& nums) {
        long long ans = 0;
        int n = nums.size();
        vector<array<int, 10>> cnt(9);      // cnt[p][d]：已处理数中第 p 位为 d 的个数
        for (int i = 0; i < n; i++) {
            int x = nums[i];
            for (int p = 0; x > 0; p++) {
                int d = x % 10;
                ans += i - cnt[p][d];        // 之前的 i 个数中，第 p 位与 d 不同的个数
                cnt[p][d]++;
                x /= 10;
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def sumDigitDifferences(self, nums: List[int]) -> int:
        n = len(nums)
        cnt = [[0] * 10 for _ in range(9)]   # cnt[p][d]：已处理数中第 p 位为 d 的个数
        ans = 0
        for i, x in enumerate(nums):
            p = 0
            while x:
                d = x % 10
                ans += i - cnt[p][d]         # 之前的数中，第 p 位与 d 不同的个数
                cnt[p][d] += 1
                x //= 10
                p += 1
        return ans
```

> 💡 Python 无溢出问题；C++ 的 `ans` 必须是 `long long`（答案上界约 $4.5 \times 10^{11}$）。提交前用示例 1 自测应得 4；若得 3 或 5，先查 `ans += ...` 与 `cnt[p][d]++` 是否写反了顺序。

## 8. 边界情况与易错点

1. **答案溢出 int32**：$n = 10^5$、9 位全互异时答案可达 $9\binom{n}{2} \approx 4.5 \times 10^{11}$；即使「只差个位」的构造（一半 `...9`、一半 `...8`）也有跨组数对 $5 \times 10^4 \times 5 \times 10^4 = 2.5 \times 10^9 > 2^{31} - 1$（每对恰差 1 个数位）。C++ 累加器必须 `long long`。
2. **桶下标与位数**：$nums_i < 10^9$ 保证至多 9 位，`cnt` 开 9 行足够；取位循环 `while (x > 0)` 依赖「正整数」前提——若数组可能出现 0，该循环一次都不执行导致位错位（本题不会发生，但变体题要警觉）。
3. **先读后增**：`ans += i - cnt[p][d]` 必须在 `cnt[p][d]++` 之前执行，否则每步把自己多扣一次，整体少 $n \cdot m$。
4. **同长度前提**：不同长度的数（如 7 与 100）无法按列对齐；若放宽此条件，需按最长位数对齐、短数前导补零后再逐位统计。
5. **两阶段写法的中间量溢出**：若用批量公式，$cnt_p[c] \cdot (cnt_p[c] - 1)$ 在 $cnt = 10^5$ 时约 $10^{10}$，中间乘积同样要 64 位。
6. **最小规模与全重复**：$n = 2$、全相同数组（示例 2）均由通用逻辑自然覆盖，无需特判。
