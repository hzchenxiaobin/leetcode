# LeetCode 到达第 K 级台阶的方案数 题解

## 1. 题目概述

- **标题 / 题号**：到达第 K 级台阶的方案数（#3154，hard）
- **链接**：https://leetcode.cn/problems/find-number-of-ways-to-reach-the-k-th-stair/
- **来源**：LeetCode 第 398 场周赛 Q4
- **难度**：困难
- **标签**：数学、组合数学、动态规划、记忆化搜索、位运算

**题意**：台阶无限长，最低一层编号为 $0$。Alice 从台阶 $1$ 出发，整数 `jump` 初值为 $0$。位于台阶 $i$ 时她可以执行两种操作：

- **操作①（向下）**：走到台阶 $i-1$，但该操作**不能连续使用**，且在台阶 $0$ 上不能使用；
- **操作②（向上）**：跳到台阶 $i + 2^{jump}$，然后 `jump` 加一。

求到达台阶 $k$ 的**总方案数**。**一条方案** = 一条**以「位于台阶 $k$」结尾**的有限操作序列；到达 $k$ 后离开再回来，对应一条更长的序列，算**另一条**方案。

**约束**：

- $0 \le k \le 10^9$

> 💡 **读题关键**：$k$ 高达 $10^9$，「位置」本身做不了 DP 状态。但操作② 的跳距是 $2^{jump}$ **指数增长**——向上跳约 30 次就跨过 $10^9$ 级，任何一条落在 $k$ 的方案**操作总数都极少**。突破口是「数操作次数」而不是「数位置」。另注意 $2^{31}$ 恰好是 32 位 int 的溢出线，位运算要小心。

## 2. 示例

**示例 1**

```text
输入：k = 0
输出：2
解释（D = 操作①向下，U = 操作②向上）：
- 方案 1：D              —— 1 → 0
- 方案 2：D U D          —— 1 → 0 → 1 → 0
```

**示例 2**

```text
输入：k = 1
输出：4
解释：
- 方案 1：（空序列）      —— 起点就在 1
- 方案 2：D U            —— 1 → 0 → 1
- 方案 3：U D            —— 1 → 2 → 1
- 方案 4：D U D U D      —— 1 → 0 → 1 → 0 → 2 → 1
```

**示例 3（自造，验证口径与公式）**

```text

解释：

    D U U D    —— 1→0→1→3→2   （D 放空档0、空档2）
    U D U D    —— 1→2→1→3→2   （D 放空档1、空档2）
```

## 3. 解题思路

### 3.1 暴力思路：DFS 搜索操作序列

状态是三元组（当前位置 `stair`、当前跳力 `jump`、上一步是否向下 `lastDown`）。DFS 每步分叉「向下 / 向上」，**进入状态时若 `stair == k` 先计 1**——「停在 $k$ 收工」是一条方案，但序列还能继续延伸，延伸后以 $k$ 结尾的每个后继又是新方案。

朴素搜索有两个致命问题：

1. **位置无上界**：一直向上跳，`stair` 能冲破 $2^{30}$，搜索树**无限伸展**，连终止都无法保证；
2. **状态反复重算**：不同前缀汇聚到同一 $(stair, jump, lastDown)$，重复展开。

救活它的剪枝是「**位置一旦超过 $k+1$ 就永远回不到 $k$**」（§5 引理 4）：向上分支只保留 `stair + 2^jump ≤ k+1` 的。剪枝后可达位置形如 $2^j - m$（$m \le j+1$），每个 $j \le 30$ 至多 $j+2$ 个位置，总计 $O(\log^2 k)$ 个状态，配记忆化即可通过（代码见 §7 备选写法）。

但状态空间小成这样，恰恰说明**位置高度结构化**——不如把结构挖到底，直接**闭式计数**。

### 3.2 核心观察：终点 $= 2^x - y$，方案数 $= \binom{x+1}{y}$

![核心概念：终点位置由 (x, y) 决定，「不连续向下」变槽位组合数](images/wc398_q4_slot_model.svg)

**第一步：向上的总升高只由「向上次数」决定。** 操作② 的跳距是 $2^{jump}$，而 `jump` 从 0 起、每用一次加一——所以**第 $j$ 次使用操作②（$j$ 从 0 数起）恰跳 $2^j$ 级**，与向下操作怎么穿插毫无关系。设一条方案共 $x$ 次向上、$y$ 次向下，总升高为

$$2^0 + 2^1 + \cdots + 2^{x-1} = 2^x - 1$$

从台阶 1 出发，**终点位置**为 $1 + (2^x - 1) - y = 2^x - y$。一条方案的全部信息被压缩成两个整数 $(x, y)$，$10^9$ 的位置值域坍缩成 $x \le 30$ 的小枚举——这是全题的题眼。

**第二步：「不能连续向下」⟹ 槽位模型。** 把 $x$ 个向上排成一列，向下只能插进空档：首档（第 1 次向上之前）+ 每次向上之后各一档，共 $x+1$ 个空档；「不能连续」⟹ 每档**至多放 1 个**向下。固定 $(x, y)$ 的方案数就是从 $x+1$ 个空档中选 $y$ 个的组合数：

$$\binom{x+1}{y}$$

**第三步：台阶 0 的限制自动满足。** 第 $i$ 次向上后再执行向下时，此前至多配对出 $i$ 次向下（§5 引理 2 的配对论证），此刻位置 $\ge 2^i - i \ge 1$——向下永远踩在 $\ge 1$ 的位置上，永远不会掉到 $-1$。$\binom{x+1}{y}$ 种插法**一个不废**，无需额外剔除非法方案。

**第四步：解出 $y$ 并求和。** 令 $2^x - y = k$ 得 $y = 2^x - k$，答案是

$$\text{ans} = \sum_{x \ge 0} \binom{x+1}{\,2^x - k\,}$$

只有满足 $0 \le 2^x - k \le x+1$ 的 $x$ 贡献非零项：$y \ge 0$ 要求 $2^x \ge k$（跳得上界），$y \le x+1$ 要求 $2^x \le k + x + 1$（空档装得下）。由 $k \le 10^9 < 2^{30}$ 可得 $x \le 29$（§5 定理），**枚举 $x = 0 \sim 31$ 绰绰有余**。

> ⚠️ **方案口径**：「一条方案」= 一条**以位于 $k$ 结尾**的有限序列，中途路过 $k$ 只是中间态；「停在 $k$ → 离开 → 回到 $k$」对应一条**更长**的序列，被更大的 $x$ 枚举到。$(x, y)$ 分解枚举了所有长度的序列，与题意严丝合缝。

### 3.3 算法流程

![算法流程：枚举 x、解出 y、组合数累加](images/wc398_q4_algorithm_flow.svg)

1. 初始化 `ans = 0`；
2. 枚举向上次数 $x = 0, 1, \ldots, 31$；
3. 解出向下次数 $y = 2^x - k$（用 64 位计算 `(1LL << x) - k`）；
4. 若 $0 \le y \le x+1$：`ans += C(x+1, y)`；否则该项为 0，跳过；
5. 枚举结束，返回 `ans`。

> 💡 组合数 $\binom{x+1}{y}$ 中 $x+1 \le 32$，用「边乘边除」的滚动公式 `c = c * (n-i) / (i+1)` 即可——每步中间值恰是 $\binom{n}{i+1}$，整除必然成立，无需预处理阶乘表。

### 3.4 示例演算

![示例演算：k=1 的四条方案按 (x, y) 分解](images/wc398_q4_example_walkthrough.svg)

以 $k = 1$ 为例，把 4 条方案按 $(x, y)$ 分解：

| $x$（向上次数） | $y = 2^x - k$ | 空档数 $x+1$ | 贡献 | 对应方案 |
|------|------|------|------|------|
| 0 | 0 | 1 | $\binom{1}{0} = 1$ | 空序列（原地即达） |
| 1 | 1 | 2 | $\binom{2}{1} = 2$ | D 放空₀（D,U）；D 放空₁（U,D） |
| 2 | 3 | 3 | $\binom{3}{3} = 1$ | D,U,D,U,D（空档全放） |
| 3 | $7 > 4$ | — | 0 | $y$ 超出空档数，枚举终止 |

合计 $1 + 2 + 1 = 4$ ✓。顺手验证 $k = 0$：$x=0$ 时 $y=1$，$\binom{1}{1}=1$；$x=1$ 时 $y=2$，$\binom{2}{2}=1$；合计 $2$ ✓。$k = 2$：$x=1$ 贡献 $\binom{2}{0}=1$（纯向上 $1 \to 2$），$x=2$ 贡献 $\binom{3}{2}=3$，合计 $4$ ✓（见 §2 示例 3）。

## 4. 算法细节

1. **枚举上界**：非零项要求 $2^x \le k + x + 1$。$k \le 10^9$ 时 $x = 30$ 已必败（$2^{30} = 1073741824 > 10^9 + 31$），实际有效 $x \le 29$；代码枚举到 31 留保险余量。
2. **64 位防溢出**：`(1LL << x)` 必须用 `long long`——`1 << 31` 在 32 位 int 下是**负数**，会直接骗过 `y < 0` 的判断，这是本题最容易写错的一行；Python 无此虑。
3. **组合数计算**：$n = x+1 \le 32$，滚动公式 `c = c * (n-i) / (i+1)` 从 $i = 0$ 乘到 $y-1$，每步中间值恰为 $\binom{n}{i+1}$，整除必然成立；Python 直接 `math.comb`。
4. **两类无效项都要跳过**：$y < 0$（$2^x < k$，跳不上来）与 $y > x+1$（向下配额超出空档数）。后者不是可选项——Python 的 `math.comb(n, r)` 在 $r > n$ 时**直接抛异常**，漏判即 RE。
5. **记忆化备选写法**（比赛时不依赖组合灵光的保底解）：状态 $(stair, jump, lastDown)$，进入状态先 `res = (stair == k)`，再按两种操作延伸；向上分支剪枝条件 `stair + (1 << jump) <= k+1`（§5 引理 4）。剪枝不只是省时间，更是**终止性保障**——没有它，位置可以无限向上跳，DFS 根本停不下来。

## 5. 正确性证明

**引理 1（位置闭式）**：恰含 $x$ 次向上、$y$ 次向下的操作序列，执行完毕时所在台阶为 $2^x - y$。

**证明**：操作② 的跳距是执行那一刻的 $2^{jump}$，而 `jump` 的值恰等于此前已执行的向上次数，故第 $j$ 次向上（$j$ 从 0 数）使位置增加 $2^j$。总升高 $\sum_{j=0}^{x-1} 2^j = 2^x - 1$；起点为 1，向下共降 $y$ 级，终点 $= 1 + (2^x - 1) - y = 2^x - y$。∎

**引理 2（合法 ⟺ 不相邻）**：一条由 $U$（向上）与 $D$（向下）组成的序列是**合法**操作序列（每次 $D$ 不连续使用、不在台阶 0 使用，从而全程位置 $\ge 0$）当且仅当 **$D$ 互不相邻**。

**证明**：（⇒）合法序列按定义满足 $D$ 互不相邻。（⇐）设 $D$ 互不相邻，对序列长度归纳证明全程合法，关键是证**每次执行 $D$ 时当前位置 $\ge 1$**。考察其中任一次 $D$，设其前缀含 $i$ 个 $U$、$m$ 个 $D$。若前缀为空，则此刻位置 $= 1$；否则前缀不能以 $D$ 结尾（否则与本次 $D$ 相邻），故以 $U$ 结尾。这样的前缀里，每个 $D$ 的**下一个符号必是 $U$**（不能是 $D$，也不能是序列尽头），把「$D$ → 紧随其后的 $U$」配对，一个 $U$ 至多紧随一个 $D$，故配对是单射，$m \le i$。由引理 1 的同款计算，执行该 $D$ 前的位置 $= 2^i - m \ge 2^i - i \ge 1$（$i \ge 1$ 时 $2^i \ge i+1$；$i = 0$ 时前缀必为空）。于是每次 $D$ 合法且落到 $\ge 0$ 处，归纳完成。∎

**引理 3（类内计数）**：固定 $(x, y)$ 且 $0 \le y \le x+1$，恰含 $x$ 个 $U$、$y$ 个 $D$ 的合法序列数为 $\binom{x+1}{y}$；$y > x+1$ 时为 $0$。

**证明**：把 $x$ 个 $U$ 排成一列。「$D$ 互不相邻」⟺ 从 $x+1$ 个空档（首档 + 每个 $U$ 之后各一档）中选出 $y$ 个、每档恰放一个 $D$：空档选择与序列**一一对应**，共 $\binom{x+1}{y}$ 种。$y > x+1$ 时由鸽笼原理必有相邻 $D$，方案数为 $0$。由引理 2，这些序列全部合法，且合法序列全部被数到。∎

**引理 4（越界剪枝，记忆化写法用）**：若当前位置 $s \ge k+2$，则无论后续如何操作都**永远回不到** $k$。

**证明**：设已执行 $i$ 次向上（故 `jump` $= i$），反设某条后续序列（$j$ 次向上、$m$ 次向下）能回到 $k$。后续序列中 $D$ 互不相邻，$m$ 个 $D$ 塞进 $j$ 个 $U$ 的 $j+1$ 个空档，故 $m \le j+1$；后续向上共升高 $\sum_{t=0}^{j-1} 2^{i+t} = 2^i(2^j - 1)$。于是

$$k = s + 2^i(2^j - 1) - m \ge (k+2) + 2^i(2^j - 1) - (j+1) \implies 2^i(2^j - 1) \le j - 1$$

$j = 0$ 时左为 $0 \le -1$，矛盾；$j \ge 1$ 时 $2^i(2^j - 1) \ge 2^j - 1 \ge j > j - 1$，亦矛盾。∎

**定理（主结论）**：$\displaystyle\text{ans} = \sum_{x \ge 0,\ 0 \le 2^x - k \le x+1} \binom{x+1}{2^x - k}$，且 $k \le 10^9$ 时求和只需 $x \le 29$。

**证明**：方案集 = 所有以「位于 $k$」结尾的合法序列，按 $(x, y)$ 二元组划分：由引理 1，落在 $k$ 要求 $y = 2^x - k$ **唯一确定**，划分不重不漏；类内计数由引理 3 为 $\binom{x+1}{y}$（$y \notin [0, x+1]$ 时为空类，贡献 0）。上界：非空类要求 $2^x = k + y \le k + x + 1$；而对 $x \ge 30$，$2^x - x \ge 2^{30} - 30 > 10^9 + 1 \ge k + 1$（$2^x - x$ 关于 $x$ 递增），即 $2^x > k + x + 1$ 恒不成立，故 $x \le 29$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(\log^2 k)$——枚举 $x$ 至多 32 个，每个组合数边乘边除至多 $O(x) \le 30$ 步；$k = 10^9$ 时约 $10^3$ 次基本操作，与 $k$ 的大小无关。
- **空间复杂度**：$O(1)$，只用常数个变量，无任何预处理表。
- **答案规模**：单项最大值出现在 $k = 2^{29} - 15$，为 $\binom{30}{15} \approx 1.55 \times 10^8$；且 $x \ge 3$ 的非零项至多 1 个（两个有效的大 $x$ 会迫使 2 的幂间距 $\le$ 常数，矛盾），总和远小于 $2^{31}$——`int` 返回值可容纳，C++ 内部用 `long long` 累加更稳。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int waysToReachStair(int k) {
        long long ans = 0;
        for (int x = 0; x <= 31; x++) {          // 有效 x ≤ 29，枚举到 31 保险
            long long y = (1LL << x) - k;        // 必须 1LL：1<<31 在 int 下是负数
            if (y < 0 || y > x + 1) continue;    // 跳不上来 / 空档不够，贡献 0
            ans += comb(x + 1, y);               // 从 x+1 个空档选 y 个放「向下」
        }
        return ans;
    }
  private:
    long long comb(long long n, long long r) {   // n ≤ 32，边乘边除
        long long c = 1;
        for (long long i = 0; i < r; i++)
            c = c * (n - i) / (i + 1);           // 每步恰为 C(n, i+1)，整除必然成立
        return c;
    }
};
```

### Python

```python
class Solution:
    def waysToReachStair(self, k: int) -> int:
        from math import comb
        return sum(
            comb(x + 1, (1 << x) - k)            # y = 2^x − k
            for x in range(32)                   # 有效 x ≤ 29，取 32 保险
            if 0 <= (1 << x) - k <= x + 1        # 不满足则该项为 0，生成器自动跳过
        )
```

> 💡 生成器里的 `if` 不成立时该项直接跳过（贡献 0），无须额外分支；Python 无溢出问题。提交前用 $k = 0$、$k = 1$ 自测应分别得 2、4。

### 记忆化写法（备选）

```python
from functools import cache

class Solution:
    def waysToReachStair(self, k: int) -> int:
        @cache
        def dfs(stair: int, jump: int, last_down: bool) -> int:
            res = stair == k                     # 就此停在 k 是一种方案
            if not last_down and stair > 0:      # 操作①：不能连续、不在台阶 0
                res += dfs(stair - 1, jump, True)
            if stair + (1 << jump) <= k + 1:     # 操作②：超过 k+1 永远回不来（引理 4）
                res += dfs(stair + (1 << jump), jump + 1, False)
            return res
        return dfs(1, 0, False)
```

两个写法复杂度同阶：记忆化好想好写、是比赛时的保底；组合解一步到位、$O(1)$ 空间。实测两组代码在 $k = 0 \sim 10^9$ 的随机与边界样本上逐点一致。

## 8. 边界情况与易错点

1. **`(1LL << x)` 溢出**：$x = 31$ 时 `1 << 31` 在 32 位 int 下为负值（且是 UB），`y < 0` 的判断会被骗过——必须用 `long long` 字面量 `1LL`。
2. **空序列也算方案**：$k = 1$ 时起点即终点，贡献 $\binom{1}{0} = 1$；记忆化写法里体现为「进入状态先计 `stair == k` 再延伸」，若只在操作之后判断会漏掉它。
3. **「以 $k$ 结尾」的口径**：DFS 遇到 `stair == k` 不能停搜——「停」与「停了再回来」是不同方案；组合写法天然覆盖（不同的 $x$ 各自计数），无需特判。
4. **超过一半的 $k$ 答案为 0**：可达位置只能落在 $\bigcup_x [2^x - x - 1,\ 2^x]$ 内，故 $k \in (2^{29},\ 10^9]$ 时无解、答案为 0——这不是 bug 而是题目性质（可用 $k = 10^9$ 自测，应得 0）。
5. **`math.comb` 的 `r > n` 异常**：Python 下漏掉 `y > x + 1` 的守卫会在小 $k$（如 $k=0$、$x=2$ 时 $y=4 > 3$）直接抛 `ValueError`；C++ 自写 `comb` 也要靠显式判断拦截，别依赖循环里 `n - i = 0` 的巧合。
6. **边乘边除的顺序**：`c = c * (n-i) / (i+1)` 每步结果恰为整数 $\binom{n}{i+1}$（归纳：$c$ 始终是组合数，$(n-i)$ 乘上后能被 $(i+1)$ 整除）；改成先除后乘会破坏整除性引入误差。
7. **记忆化剪枝写错方向**：条件是 `stair + (1 << jump) <= k + 1`（跳完落点不超过 $k+1$ 才允许跳）。漏写或写成 `stair <= k+1` 会让位置无限上冲，**递归不终止**而非仅仅超时——剪枝在本题是终止性条件。

- [LeetCode 231. 2 的幂](https://leetcode.cn/problems/power-of-two/)（[站内题解](../../solution/0201-0300/231_2的幂.md)）：本题 $2^x$ 枚举与跳距指数增长背后的位运算基础。

**延伸思考**：

- **去掉「不能连续向下」**：槽位模型立刻退化——每个空档可堆任意多个 $D$，计数从普通组合 $\binom{x+1}{y}$ 变成隔板法的可重组合 $\binom{x+y}{y}$。「不能连续」这条约束的价值，正是把可重组合压成普通组合。
- **改问「恰好 $t$ 步到达」**：增加约束 $x + y = t$，与 $2^x - y = k$ 联立得 $2^x + x = t + k$；左端关于 $x$ 严格递增，至多一个解，对 $x \in [0, 31]$ 枚举校验，命中后答案是单个 $\binom{x+1}{y}$。
- **升级为「所有方案的位置总和」**：把「计数」换成「对每条方案求终点/途经位置之和」——需在槽位模型上对「$D$ 放在第几个空档」做加权贡献分析，属于带权组合计数的进阶练习。
