# LeetCode 特殊数组 I 题解

## 1. 题目概述

- **标题 / 题号**：特殊数组 I（#3151，easy）
- **链接**：https://leetcode.cn/problems/special-array-i/
- **来源**：LeetCode 第 398 场周赛 Q1
- **难度**：简单
- **标签**：数组、位运算

**题意**：如果数组的**每一对相邻元素**的奇偶性都**互不相同**（一对中必须一个是偶数、另一个是奇数），则称该数组为**特殊数组**。给定整数数组 `nums`，判断它是否为特殊数组，是则返回 `true`，否则返回 `false`。

**约束**：

- $1 \le n = nums.length \le 100$
- $1 \le nums[i] \le 100$

> 💡 签到题的关键信号：判定条件是**局部的**——「每一对相邻元素」意味着全部信息只藏在 $n-1$ 个**间隙**里，一趟线性扫描天然够用。本题的任务是把判定原子单位（间隙）与判定算子（末位异或）一次找对；下一题 Q2（3152 特殊数组 II）就把这个判定放大成 $q$ 个任意区间的批量查询，逼你把间隙信息预处理成前缀和。

## 2. 示例

**示例 1**

```text
输入：nums = [1]
输出：true
解释：只有一个元素，不存在相邻对，条件空真成立。
```

**示例 2**

```text
输入：nums = [2,1,4]
输出：true
解释：只有两对相邻元素：(2,1) 和 (1,4)，均一奇一偶、互不相同。
```

**示例 3**

```text
输入：nums = [4,3,1,6]
输出：false
解释：nums[1] = 3 与 nums[2] = 1 同为奇数，违规 → false。
```

## 3. 解题思路

### 3.1 朴素思路

枚举所有相邻对 $(nums_{i-1}, nums_i)$，逐对检查奇偶是否互异，遇到同奇偶立即返回 `false`；全部通过返回 `true`。一趟 $O(n)$ 扫描——由于每个相邻对至少要看一眼，$O(n)$ 已是复杂度下界，**本题的考点不在优化，而在把判定写对写短**。真正要避开的是两个「想偏」方向：按数值统计奇偶个数（位置信息丢失，`[2,4,1,3]` 奇偶各半却 `false`），以及双重循环枚举全部数对 $(i,j)$（定义只约束相邻对，纯负优化）。

### 3.2 核心观察：判定原子单位是 $n-1$ 个间隙，末位异或一刀判定

![核心概念：奇偶沿数组交替，末位异或一刀判定](images/wc398_q1_parity_alternation_model.svg)

**关键性质 1（奇偶 = 二进制末位）**：奇偶性恰由二进制**末位**决定，$nums_i \bmod 2 = nums_i \,\&\, 1$。于是「两数奇偶互异」有一个免除除法的等价刻画：

$$(a \oplus b) \,\&\, 1 = 1 \iff a \text{ 与 } b \text{ 奇偶互异}$$

异或的末位就是两数末位之异或——一奇一偶时为 1，同奇同偶时为 0。**一次异或 + 一次按位与**完成一次判定。

**关键性质 2（首元素定调）**：把每个元素压成奇偶 bit $p_i = nums_i \,\&\, 1$，「相邻互异」即 $p$ 沿下标**严格交替**，归纳一步即得全局等价式：

$$\text{特殊} \iff p_i \equiv p_0 + i \pmod{2}, \quad \forall\, 0 \le i \le n-1$$

首个元素是奇数则整条奇偶序列必为 $1,0,1,0,\ldots$，是偶数则为 $0,1,0,1,\ldots$——**整条序列只有两个自由度（起点选奇或选偶），每个位置的「应有奇偶」无需看邻居即可 $O(1)$ 算出**。

### 3.3 算法流程

1. 对 $i = 1 \ldots n-1$ 逐一检查间隙：若 $(nums_i \oplus nums_{i-1}) \,\&\, 1 = 0$（同奇偶，违规），**立即**返回 `false`；
2. $n - 1$ 个间隙全部通过，返回 `true`；
3. $n = 1$ 时循环体一次不执行，自然落到第 2 步返回 `true`（空真），无需特判。

### 3.4 示例演算

![示例走查：三个官方示例的逐间隙判定](images/wc398_q1_example_walkthrough.svg)

以示例 3 `nums = [4,3,1,6]` 走查（下标从 0 起）：

| 间隙 $i$ | 相邻对 | 计算 $(a \oplus b) \,\&\, 1$ | 含义 | 结果 |
|---|---|---|---|---|
| 1 | $(4, 3)$ | $7 \,\&\, 1 = 1$ | 偶→奇，互异 | ✓ 继续 |
| 2 | $(3, 1)$ | $2 \,\&\, 1 = 0$ | 奇→奇，同奇偶 | ✗ **返回 false** |
| 3 | $(1, 6)$ | ——（提前返回，未检查） | | |

撞到间隙 2 的违规对后即刻短路返回，间隙 3 根本不看。示例 2 `[2,1,4]` 的两个间隙均为 1 → `true`；示例 1 `[1]` 无间隙 → 空真 `true`。✓

## 4. 算法细节

1. **判定原子单位是间隙，不是元素**：「每一对相邻元素」的全部信息只落在 $n-1$ 个间隙 $i \in [1, n-1]$ 上，循环恰从 $i = 1$ 扫到 $i \le n-1$，与间隙集合一一对应。把挂点选在间隙上，边界自动正确——Q2 做前缀和时违规位 $d_i$ 也挂在同一位置，直接复用。
2. **末位异或代替取模**：`(a ^ b) & 1` 比 `a % 2 == b % 2` 更快，且对**负数更稳**——C++ 中 `-1 % 2 == -1`，而补码下 `-1 & 1 == 1` 恒正确。本题 $nums_i \ge 1$ 用取模同样对，位运算是习惯加分项。
3. **运算符优先级，C++ 与 Python 相反**：C++ 中 `==` 优先级**高于** `&` 与 `^`，判定式必须写全括号 `(((a ^ b) & 1) == 0)`；Python 中 `&` 高于 `==`，同一行表达式可直接用。
4. **两种等价写法**：逐对检查（比较相邻两元素）与「首元素定调」（比较 $nums_i \bmod 2$ 与 $(nums_0 + i) \bmod 2$）完全等价；前者更短、无需记住起点奇偶，推荐。
5. **提前返回 / 短路求值**：布尔判定题结论一旦确定即可返回，最好 $O(1)$（首间隙即违规），最坏仍 $O(n)$；Python 的 `all()` 生成器天然短路。

## 5. 正确性证明

**引理 1**：对任意整数 $a, b$：$(a \oplus b) \,\&\, 1 = 1 \iff a, b$ 奇偶互异。

**证明**：整数的奇偶性由二进制末位唯一决定（奇 $\iff$ 末位为 1）。异或的第 $k$ 位等于两数第 $k$ 位之异或；取 $k = 0$，$(a \oplus b)$ 的末位为 1 $\iff$ $a, b$ 的末位不同 $\iff$ 一奇一偶。∎

**引理 2**（空真）：$n = 1$ 时 `nums` 是特殊数组。

**证明**：特殊数组的定义是「每一对相邻元素都满足奇偶互异」这一全称命题。$n = 1$ 时相邻对集合为空，全称命题无假见证，恒成立。∎

**定理**：算法返回 `true` 当且仅当 `nums` 是特殊数组。

**证明**：`nums` 的相邻对集合恰为 $\{(i-1,\ i) : 1 \le i \le n-1\}$，与循环检查的间隙一一对应。（⇐）若算法返回 `true`，则循环中每一步检查都未触发返回，即对每个间隙 $(a \oplus b) \,\&\, 1 \ne 0$，由引理 1 每个相邻对奇偶互异；$n = 1$ 时循环体不执行、直接返回 `true`，由引理 2 同样成立。故 `nums` 特殊。（⇒）若 `nums` 特殊而算法返回了 `false`，则存在某个间隙使 $(a \oplus b) \,\&\, 1 = 0$，由引理 1 该相邻对同奇偶，与特殊矛盾。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。至多检查 $n-1$ 个间隙，每个间隙一次异或 + 一次按位与 + 一次比较；首个违规对提前返回，最好 $O(1)$。由 $n \le 100$，总量不超过 99 次判定。
- **空间复杂度**：$O(1)$。仅下标与常数个临时变量，不建奇偶数组。注：Python `zip(nums, nums[1:])` 的切片占 $O(n)$，可换 `itertools.pairwise` 消除。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    bool isArraySpecial(vector<int>& nums) {
        for (int i = 1; i < (int)nums.size(); ++i) {
            // 括号必须带全：C++ 中 == 优先级高于 & 和 ^
            if (((nums[i] ^ nums[i - 1]) & 1) == 0) {
                return false;   // 撞到首个同奇偶对，短路返回
            }
        }
        return true;            // n = 1 时循环不执行，空真直接返回 true
    }
};
```

### Python

```python
class Solution:
    def isArraySpecial(self, nums: List[int]) -> bool:
        # n = 1 时无对可配，all() 对空序列返回 True —— 恰是空真语义
        return all((a ^ b) & 1 for a, b in zip(nums, nums[1:]))
```

> 💡 Python 中 `&` 优先级高于 `==`，`(a ^ b) & 1` 无需再套括号即可直接作为真值使用。Python 3.10+ 可用 `itertools.pairwise(nums)` 替代 `zip(nums, nums[1:])`，省掉 $O(n)$ 切片拷贝。

## 8. 边界情况与易错点

1. **$n = 1$**：无相邻对，空真 → `true`。循环从 $i = 1$ 起不执行 / `all()` 空序列返回 `True`，两种写法都自动覆盖，**无需特判**。
2. **循环边界**：$i$ 从 $1$ 到 $n - 1$（共 $n-1$ 个间隙）。误写 `i < n - 1` 会漏掉最后一个间隙——`[1,2,4]` 只查 $(1,2)$ 即误判 `true`（正确为 `false`）。另注意 C++ 中 `nums.size()` 是无符号类型，防御性写法是先转 `int`。
3. **C++ 优先级陷阱**：`==` 高于 `&` / `^`，`(nums[i] ^ nums[i-1]) & 1 == 0` 被解析为 `(nums[i] ^ nums[i-1]) & (1 == 0)` 即与 0 相与——**恒为 0、条件永假，所有输入都返回 `true`**，编译不报错但判定全错。全套括号 `(((nums[i] ^ nums[i-1]) & 1) == 0)` 是唯一安全写法；Python 优先级相反，同一表达式可直接用。
4. **条件方向别写反**：`(a ^ b) & 1 == 1` 才是「互异」（合法），`== 0` 是「同奇偶」（违规）。提交前用示例 3 自测：`[4,3,1,6]` 应为 `false`。
5. **同奇偶数组**：全奇（`[1,1,1]`）或全偶（`[2,4,6]`）从第一个间隙起就违规，属于最快的 `false` 路径，可作为对拍用例。
6. **从 Q1 到 Q2 的迁移**：若把本判定函数原样复用到 $q$ 个区间查询上，每次查询仍要整段重扫、总量 $O(nq)$——这正是 Q2 改用 0/1 前缀和的动机；单次判定越早短路，批量复用时越要警惕重复扫描。
