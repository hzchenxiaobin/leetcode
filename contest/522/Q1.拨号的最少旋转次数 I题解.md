# LeetCode 拨号的最少旋转次数 I 题解

## 1. 题目概述

- **标题 / 题号**：拨号的最少旋转次数 I（#4070，easy）
- **链接**：https://leetcode.cn/problems/minimum-rotations-to-dial-a-number-i/
- **来源**：LeetCode 第 522 场周赛 Q1
- **难度**：简单
- **标签**：贪心、数学、模拟

**题意**：0~9 十个数字按顺序排成一圈组成**环形拨号盘**（0 与 9 相邻），指针初始指向 0。给定长度为 10 的数字串 `s`，需按顺序拨出其中每个数字：每次旋转把指针移动到**相邻**数字（方向任选），指针已指向目标数字则无需旋转。求拨完全部数字的**最少总旋转次数**。

**约束**：

- `s.length == 10`
- `s` 仅由数字 `'0'` ~ `'9'` 组成

## 2. 示例

**示例 1**

```text
输入：s = "0192837465"
输出：25
解释：逐段旋转次数为 0,1,2,3,4,5,4,3,2,1。
      其中 1→9、9→2、2→8 三段都走"跨过 0/9"的短方向，
      例如 1→9 经 0 只需 2 步，而非绕远 8 步。
```

**示例 2**

```text
输入：s = "1200210200"
输出：12
解释：第一步 0→1 就要 1 次旋转（指针初始在 0）；
      中间的 "00"、"结尾 0" 段距离为 0，不旋转。
```

**示例 3**

```text
输入：s = "0000000000"
输出：0
解释：指针始终指向 0，全程无需旋转（下界情况）。
```

## 3. 解题思路

### 3.1 朴素思路

数据极小（10 个字符、每段距离 ≤ 5），怎么做都能过：可以对每对相邻数字在环上向两个方向各"走一格"模拟直到抵达；甚至从每个状态做 BFS 也绰绰有余。但签到题的价值在于找到**从题面到代码的最短路径**——"每次旋转移动到相邻数字"正是环上距离的定义，一步就能写出公式，无需任何搜索。

### 3.2 核心观察：环形距离公式 + 各段独立

**观察 1（环形距离）**：设指针在 $a$、目标为 $b$，记 $d = |a - b|$。沿环顺时针需 $p = (b - a) \bmod 10$ 步，逆时针需 $q = (a - b) \bmod 10$ 步，且 $a \ne b$ 时 $p + q = 10$——**两个方向的步数恰好互补**。而任何中途折返的走法都可删去折返、不会更差，所以最优走法必是纯顺时针或纯逆时针，最少步数为：

$$\delta(a, b) = \min(d,\ 10 - d)$$

**观察 2（各段独立 → 贪心成立）**：拨出一个数字后，指针**必然停在该数字上**——怎么走的完全不影响后续状态。因此总费用被切成 10 个互不干扰的段：$0 \to s_0,\ s_0 \to s_1,\ \dots,\ s_8 \to s_9$，每段各取最小值即可，局部最优自动组合成全局最优。

![环形拨号盘与双向距离](images/wc522_q1_ring_distance.svg)

> 💡 一句话：**每段取 $\min(d, 10-d)$，再加起来**。本题唯一的"考点"就是别忘了 0 和 9 相邻。

### 3.3 算法流程

![一遍扫描流程](images/wc522_q1_algorithm_flow.svg)

1. 初始化 `prev = 0`（指针初始指向 0），`ans = 0`
2. 依次取每个字符 `c`：
   - 计算 $d = |c - prev|$
   - `ans += min(d, 10 - d)`，再令 `prev = c`
3. 扫描结束，返回 `ans`

## 4. 算法细节

1. **公式推导**：从 $a$ 到 $b$，顺时针需 $(b-a) \bmod 10$ 步、逆时针需 $(a-b) \bmod 10$ 步，两者之和为 10（$a \ne b$ 时），故 $\delta(a,b) = \min(d, 10-d)$，其中 $d = |a-b|$。
2. **初值 `prev = 0`**：第一段是 $0 \to s_0$，不能漏。示例 2 的 $s_0 = 1$，第一步就要 1 次旋转；若 $s_0 = 0$ 则该段为 0（示例 1）。
3. **字符转数字**：C++ 用 `c - '0'`；Python 用 `int(c)`。
4. **单变量滚动**：只需 `prev` 一个变量记录上一位置，不必开数组、不必存下标。

## 5. 正确性证明

**引理 1（环形距离）**：指针从 $a$ 旋转到 $b$ 的最少次数为 $\delta(a,b) = \min(|a-b|,\ 10 - |a-b|)$。

**证明**：把旋转序列看成环 $\mathbb{Z}_{10}$ 上的游走，设顺时针净步数（顺时针次数减逆时针次数）为 $t$，则抵达 $b$ 当且仅当 $a + t \equiv b \pmod{10}$。总步数 $\ge$ 顺时针次数 $+$ 逆时针次数 $\ge |t|$。取 $t \equiv (b - a) \pmod{10}$ 且 $|t|$ 最小的方案：$t = p := (b-a) \bmod 10$（纯顺时针）或 $t = -q$、$q := (a-b) \bmod 10$（纯逆时针），步数分别为 $p$ 与 $q$；当 $a \ne b$ 时 $p, q \ge 1$ 且 $p + q = 10$。故最少步数为 $\min(p, q) = \min(d, 10 - d)$，其中 $d = |a - b|$。∎

**引理 2（独立分解）**：无论采用何种旋转方式，拨出 $s_i$ 后指针停在 $s_i$；全过程的总旋转次数等于 10 个段（$0 \to s_0$ 与 $s_{i-1} \to s_i$，$1 \le i \le 9$）的次数之和，且各段方案互相独立。

**证明**：对 $i$ 归纳：指针初始位置为 0（确定）；拨 $s_i$ 的过程按题面以"指针指向 $s_i$"结束，与之前如何旋转无关。于是序列被各位切成 10 个先后执行的段，相邻两段仅通过"下一段起点 = 上一段终点"耦合，而该终点恒为 $s_i$，与段内路径无关，故各段内部可自由选择方案，总次数为各段之和。∎

**定理**：贪心算法（每段取环形距离 $\delta$）返回最少总旋转次数。

**证明**：由引理 2，总次数 $= \sum_{i=0}^{9} \text{cost}_i$ 且各段独立、可各自取到最小值；由引理 1，第 $i$ 段的最小值即 $\delta$。贪心对每段恰好取 $\delta$，各段同时取到最小，总和最小。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$，其中 $n = 10$。每个字符 $O(1)$ 计算距离并累加，共扫描一遍。
- **空间复杂度**：$O(1)$。仅维护 `prev` 与 `ans` 两个变量。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int minRotations(string s) {
        int ans = 0, prev = 0;
        for (char c : s) {
            int cur = c - '0';
            int d = abs(cur - prev);
            ans += min(d, 10 - d);
            prev = cur;
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def minRotations(self, s: str) -> int:
        ans = prev = 0
        for c in s:
            cur = int(c)
            d = abs(cur - prev)
            ans += min(d, 10 - d)
            prev = cur
        return ans
```

## 8. 边界情况与易错点

1. **忘记环形**：只用 $|a - b|$ 会在"跨 0/9"处算错——1→9 是 **2** 步而非 8 步。这是本题唯一的考点。
2. **忘记初始指针在 0**：第一段 $0 \to s_0$ 也要计费；只有 $s_0 = 0$ 时才免。
3. **对径 $d = 5$**：两个方向等长，取 5 即可，无需特判（示例 1 的 8→3）。
4. **连续相同字符**：距离为 0，不旋转（示例 2 的 "00"）。
5. **结果范围自检**：每段至多 5、共 10 段，答案 $\le 50$（如 `"0505050505"` 全程对径取到上界 50）；全 `'0'` 时为下界 0。`int` 足够，无溢出风险。

**延伸思考**：

- 若盘面换成 $k$ 个符号（如 26 个英文字母），公式推广为 $\min(d, k - d)$；若每步可转 1 至 $m$ 格，单段代价变为 $\lceil \delta / m \rceil$，骨架不变。
- Q2 的后缀反转打破了"各段独立"——反转改变相邻配对的**顺序**但不改变配对集合。预处理每段距离的后缀和，即可对每个 $k$ 只重算衔接段，总复杂度 $O(n)$，详见 Q2 题解。
