# LeetCode 最少翻转次数得到反转二进制字符串 题解

## 1. 题目概述

- **标题 / 题号**：最少翻转次数得到反转二进制字符串（#3750，easy）
- **链接**：https://leetcode.cn/problems/minimum-number-of-flips-to-reverse-binary-string/
- **来源**：LeetCode 第 170 场双周赛 Q1
- **难度**：简单
- **标签**：位运算、数学、双指针、字符串

**题意**：给定正整数 $n$，令 $s$ 为 $n$ 的二进制表示（无前导零）。每次操作可翻转 $s$ 的**任意一位**（$0 \to 1$ 或 $1 \to 0$）。问最少多少次翻转，能让 $s$ 变成**它原始形式的反转串**。

关键理解：目标是「**原串的**反转」，是一个**固定的目标串** $rev = reverse(s)$，而不是「翻转后自身回文」。所以答案就是 $s$ 与 $rev$ 的**汉明距离**。

**约束**：

- $1 \le n \le 10^9$（二进制长度 $\le 30$）

## 2. 示例

**示例 1**

```text
输入：n = 7
输出：0
解释：7 = "111"，反转仍是 "111"，已经相同，无需翻转。
```

**示例 2**

```text
输入：n = 10
输出：4
解释：10 = "1010"，反转 = "0101"。每一位都不同，需要翻转 4 位。
```

**补充示例 3**

```text
输入：n = 2
输出：2
解释：2 = "10"，反转 = "01"，两位都不同，翻转 2 次。
```

## 3. 解题思路

### 3.1 暴力思路

枚举「翻转哪些位」的所有子集，逐个检查是否等于 $rev$，取最小翻转数：$O(2^{30})$，不可行。稍好一点：按位比较两个串，凡是不同的位就必须翻——这一位**必须翻**，且没有其他方式能改变它，所以「不同位的个数」既是下界也是可达方案。

### 3.2 核心观察：答案是汉明距离，且必然成对出现

![逐位比较 s 与 reverse(s)：不同的位置成对出现](images/bw170_q1_mirror_pairs.svg)

设 $s = s_0 s_1 \cdots s_{L-1}$，$rev = s_{L-1} \cdots s_1 s_0$。位置 $i$ 上两者不同当且仅当 $s_i \ne s_{L-1-i}$。于是：

- **成对性**：位置 $i$ 不同 $\iff$ 位置 $L-1-i$ 也不同（两者是同一个对称条件），所以不同位总数必为**偶数**。
- **答案**：$ans = \#\{i : s_i \ne s_{L-1-i}\}$，即汉明距离 $\text{dist}(s, rev)$。

用双指针从两端向中间扫，每遇到一对不同的对称位就 $+2$，扫完即得答案，无需构造 $rev$。

### 3.3 算法流程

![算法流程：取二进制、双指针向中间夹](images/bw170_q1_algorithm_flow.svg)

```text
1. s = n 的二进制串（无前导零）
2. ans = 0；i = 0；j = L - 1
3. while i < j:
       若 s[i] != s[j]:  ans += 2
       i++；j--
4. 返回 ans
```

### 3.4 示例演算

对 $n = 10$，$s = \texttt{"1010"}$：

| 对称对 $(i, j)$ | $s_i$ | $s_j$ | 是否不同 | ans |
|-----------------|-------|-------|----------|-----|
| (0, 3) | 1 | 0 | 是 | 2 |
| (1, 2) | 0 | 1 | 是 | 4 |

$i \ge j$ 时结束，答案 4，与示例一致。

对 $n = 7$，$s = \texttt{"111"}$：只有一对 $(0,2)$，$1 = 1$，答案 0。中间位（当 $L$ 为奇数时）自己和自己比，永远相同，不计入。

## 4. 算法细节

1. **取二进制**：C++ 用「不断取 $n \bmod 2$ 再反转」，或用 `bitset`；Python 直接 `bin(n)[2:]`，注意去掉 `0b` 前缀且 $n \ge 1$ 保证没有前导零。
2. **双指针而非构造反转串**：`s[i]` 与 `s[L-1-i]` 直接比较，省掉一次 `reverse` 拷贝（虽然本题长度很小，写法更贴合「对称」语义）。
3. **每次 $+2$**：也可以逐个位置数（每对贡献 $2$），两种写法等价；用 $+2$ 更直观地体现「成对」。
4. **不翻转中间位**：$L$ 为奇数时中间位 $i = j$，对称位置是自己，无论取值都相同，循环条件 `i < j` 天然排除。
5. **$n \ge 1$**：由约束保证，不必处理 $n = 0$（若允许 $0$，二进制为 `"0"`，答案也是 0）。

## 5. 正确性证明

**引理 1（不同位的成对性）**：对任意 $i$，$s_i \ne s_{L-1-i} \iff s_{L-1-i} \ne s_i$。故不同位的集合在映射 $i \mapsto L-1-i$ 下封闭，其大小必为偶数。

**证明**：不等号是对称的，且 $(L-1)-(L-1-i) = i$，映射是对合（自逆）。若 $i \ne L-1-i$，则两个不同位置成对出现；若 $i = L-1-i$，则该位与自身相等，不可能「不同」。故不同位集合是若干个二元组之并，大小为偶数。∎

**引理 2（下界）**：任何把 $s$ 变成 $rev$ 的方案至少需要 $\text{dist}(s, rev)$ 次翻转。

**证明**：一次翻转只改变**一个**位置的值。若原串与目标串在 $d$ 个位置上不同，则这 $d$ 个位置中每一个都必须被翻转奇数次（至少一次），故总翻转次数 $\ge d$。∎

**引理 3（可达性）**：恰好翻转所有 $s_i \ne rev_i$ 的位置一次，即可使 $s$ 变成 $rev$。

**证明**：对不同的位置翻一次，其值从 $s_i$ 变成 $\lnot s_i = rev_i$；对相同的位置不翻，保持 $s_i = rev_i$。逐位相等故整串相等，翻转次数恰为 $d$。∎

**定理**：算法返回值为最少翻转次数。

**证明**：由引理 3，存在 $d$ 次翻转的可行方案；由引理 2，任何方案至少 $d$ 次，故最小值为 $d$。而算法双指针枚举的正是全部对称对 $(i, L-1-i)$，每对若不同计 2、否则计 0，恰好覆盖 $d$ 个不同位（引理 1 保证成对），故 `ans` $= d$。∎

## 6. 复杂度分析

- **时间**：$O(\log n)$。二进制长度 $L = \lfloor \log_2 n \rfloor + 1 \le 30$，双指针扫 $L/2$ 对，每次 $O(1)$。
- **空间**：$O(\log n)$，用于存放二进制串（$\le 30$ 个字符）；双指针本身 $O(1)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minimumFlips(int n) {
        string s;
        while (n > 0) {
            s.push_back(char('0' + n % 2));
            n /= 2;
        }
        reverse(s.begin(), s.end());
        int ans = 0;
        int i = 0, j = (int)s.size() - 1;
        while (i < j) {
            if (s[i] != s[j]) ans += 2;
            i++;
            j--;
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def minimumFlips(self, n: int) -> int:
        s = bin(n)[2:]
        return sum(1 for a, b in zip(s, s[::-1]) if a != b)
```

## 8. 边界情况与易错点

1. **误读成「变成回文串」**：那答案是「不同对称位的**对数**」（$\text{dist}/2$），与本题差一倍。示例 2 的 $n = 10$ 是最佳鉴别用例：回文版本答案是 2，本题答案是 4。
2. **前导零**：`bin(n)[2:]` 已经去掉 `0b`，且 $n \ge 1$ 无前导零。若用固定 32 位补零表示，会把前导零也算进对称比较，答案完全错误。
3. **$n = 1$**：`"1"`，$i = j$，循环不进，返回 0。
4. **答案必为偶数**：如果算出奇数，说明实现把中间位重复计了，是明显的 bug 信号。
5. **`char('0' + n % 2)`**：C++ 里 `s += '0' + n % 2` 若写错成字符串拼接会得到奇怪结果，注意 `push_back` 配 `char`。
6. **`int` 足够**：$n \le 10^9 < 2^{30}$，答案 $\le 30$，无溢出风险。
