# LeetCode 字典序最小和为目标值且绝对值是排列的数组 题解

## 1. 题目概述

- **标题 / 题号**：字典序最小和为目标值且绝对值是排列的数组（#3752，medium）
- **链接**：https://leetcode.cn/problems/lexicographically-smallest-negated-permutation-that-sums-to-target/
- **来源**：LeetCode 第 170 场双周赛 Q3
- **难度**：中等
- **标签**：贪心、数组、数学、双指针、排序

**题意**：给定正整数 $n$ 与整数 $target$。要求返回一个长度 $n$ 的数组 $a$，满足：

1. $\sum_i a_i = target$；
2. $\lvert a_i \rvert$ 恰好构成 $1 \ldots n$ 的一个**排列**（即每个绝对值的出现次数都是 1）。

在全部可行数组中，返回**字典序最小**者；不存在则返回空数组。

**约束**：

- $1 \le n \le 10^5$
- $-10^{10} \le target \le 10^{10}$

> ⚠️ 注意 $target$ 的绝对值可达 $10^{10}$，远超 `int`，必须用 64 位（C++ `long long`）；而 $n$ 的和 $\frac{n(n+1)}{2} \approx 5 \times 10^9$ 同样需要 64 位。

## 2. 示例

**示例 1**

```text
输入：n = 3, target = 0
输出：[-3,1,2]
解释：和为 0 的合法数组共 12 个，字典序最小的是 [-3,1,2]
     （首位 -3 已是最小的可能元素）。
```

**示例 2**

```text
输入：n = 1, target = 10000000000
输出：[]
解释：只有 1 个元素，和只能是 1 或 -1，不可能达到 10^10。
```

**补充示例 3**

```text
输入：n = 4, target = 10
输出：[1,2,3,4]
解释：全部取正数和为 10 = S，无需任何负号。
```

## 3. 解题思路

### 3.1 暴力思路

枚举 $2^n$ 种符号组合，再对每种组合枚举 $n!$ 种排列，取字典序最小者——$n = 10^5$ 时完全不可行。即使只枚举符号组合也是 $2^{10^5}$。

问题的结构其实很清晰：**总和只由符号决定，与排列顺序无关**；因此可以分两步走——先定符号集合，再定顺序。

### 3.2 核心观察：翻一个符号等价于减去 $2x$

![先全取正号得 S，再把若干个数取负，每次让总和减 2x](images/bw170_q3_total_and_flip.svg)

从「全正」出发：$1 + 2 + \cdots + n = S = \frac{n(n+1)}{2}$。若把 $x$ 从 $+x$ 改成 $-x$，总和减少 $2x$。设最终取负的集合为 $N \subseteq \{1,\ldots,n\}$，则

$$target = S - 2\sum_{x \in N} x \quad \Longleftrightarrow \quad \sum_{x \in N} x = \frac{S - target}{2} = D$$

于是可行性判定只需三步：

- $target > S$ 或 $target < -S$：无论怎么取符号都达不到，返回空；
- $S - target$ 为**奇数**：左边是 $2$ 的倍数，不可能，返回空；
- 否则 $D = \frac{S - target}{2} \in [0, S]$，问题化为「从 $1 \ldots n$ 中选一个子集使其和为 $D$」。

**关键事实**：对 $1 \ldots n$ 的连续整数集合，任何 $0 \le D \le S$ 都**一定**能用子集凑出（不会出现「Coin Problem」式的无解），所以上述三条就是完整的可行性判定。

### 3.3 算法流程：从大到小贪心选负号

![贪心：从 n 往 1 扫，能取就取](images/bw170_q3_greedy.svg)

```text
1. S = n*(n+1)/2
2. 若 target < -S 或 target > S 或 (S - target) 为奇数：返回 {}
3. D = (S - target) / 2；neg[1..n] = false
4. for x = n down to 1:
       若 x <= D:  neg[x] = true；D -= x
5. 构造答案：
       先按 x 从 n 到 1，把 neg[x] 为真的 -x 依次加入；
       再按 x 从 1 到 n，把 neg[x] 为假的 +x 依次加入
6. 返回答案
```

第 5 步的顺序正是「**升序排好整个带符号的多重集**」：负数从 $-n$ 到 $-1$ 升序，正数从 $1$ 到 $n$ 升序。

为什么从大到小贪心？两个理由：

- **能凑出**：从 $n$ 递减尝试，`x <= D` 就取，可以证明结束时 $D$ 必然恰好归零（见引理 2）。这与「找零用大面额优先」同理，但因为面额是 $1,2,\ldots,n$ 连续，必然精确命中。
- **字典序最小**：为了让答案数组的首位尽可能小，我们希望**被取负的最大值尽可能大**——即优先把大的数变成负数。逐位贪心（先最大化最大负元素，再最大化次大负元素……）恰好就是字典序最小。

### 3.4 示例演算

![排列顺序：所有负数升序在前，所有正数升序在后](images/bw170_q3_lex_order.svg)

对 $n = 3$、$target = 0$：$S = 6$，$D = (6-0)/2 = 3$。

| 步骤 | x | x ≤ D ? | 动作 | D |
|------|---|---------|------|---|
| 1 | 3 | 3 ≤ 3 ✓ | neg[3] = true | 0 |
| 2 | 2 | 2 ≤ 0 ✗ | 跳过 | 0 |
| 3 | 1 | 1 ≤ 0 ✗ | 跳过 | 0 |

负号集合 $N = \{3\}$。构造：负数段 $[-3]$，正数段 $[1, 2]$，答案 $[-3, 1, 2]$，与示例一致。

再验证一个「需要多个负号」的例子：$n = 5$、$target = -3$。$S = 15$，$D = (15-(-3))/2 = 9$。

| x | x ≤ D ? | 动作 | D |
|---|---------|------|---|
| 5 | 5 ≤ 9 ✓ | neg[5] | 4 |
| 4 | 4 ≤ 4 ✓ | neg[4] | 0 |
| 3,2,1 | ✗ | 跳过 | 0 |

答案 $[-5, -4, 1, 2, 3]$，和 $= -5-4+1+2+3 = -3$ ✓。

## 4. 算法细节

1. **先判上界再算 $D$**：如果直接算 $S - target$，当 $target = -10^{10}$ 时中间值可达 $1.5 \times 10^{10}$，仍在 `long long` 范围内（$9.2 \times 10^{18}$），安全；但先判 $|target| \le S$ 更直观。
2. **奇偶判定**：$S - target$ 为奇数则无解。注意 $target$ 可能为负，C++ 中负数取模为负，用 `((S - target) % 2 != 0)` 判断（不要写 `== 1`）。
3. **`neg` 用 `vector<char>`**：$n \le 10^5$，布尔数组即可；`vector<bool>` 也行但位压缩，`char` 更快更直观。
4. **构造顺序**：先负后正，各自升序。若写成「按原顺序 $1 \ldots n$ 输出」（负数也在原位），字典序会变大（例如 $n=3$ 会输出 $[1, 2, -3]$，字典序大于 $[-3,1,2]$）。
5. **答案长度必须恰为 $n$**：每个绝对值用一次，不要漏掉 $x$ 或重复。
6. **$D = 0$ 的边界**：全正，输出 $[1, 2, \ldots, n]$。
7. **$D = S$（$target = -S$）**：全部取负，输出 $[-n, \ldots, -1]$。

## 5. 正确性证明

**引理 1（和的刻画）**：若取负集合为 $N$，则数组和为 $S - 2\sum_{x\in N} x$。

**证明**：全正时为 $S$。把 $x$ 从 $+x$ 改为 $-x$，总和变化量为 $(-x) - (+x) = -2x$。各元素符号独立，故总变化量为 $-2\sum_{x \in N}x$。∎

**引理 2（贪心的精确命中）**：设 $S(k) = \frac{k(k+1)}{2}$。若 $0 \le D \le S(k)$，执行「对 $x = k, k-1, \ldots, 1$，若 $x \le D$ 则取 $x$ 并令 $D \leftarrow D - x$」，则结束时 $D = 0$。

**证明**：对 $k$ 归纳，并维护不变式 $0 \le D \le S(k)$。

- $k = 0$：$0 \le D \le 0$，故 $D = 0$，直接成立。
- 设对 $k-1$ 成立。当前处理 $x = k$：
  - 若 $D \le S(k-1) = \frac{(k-1)k}{2}$：因为 $k > S(k-1)$（对 $k \ge 2$；$k=1$ 时 $S(0)=0 < 1$ 同样成立），故 $D < k$，条件 $k \le D$ 不成立，跳过 $x=k$。此时 $D$ 不变且仍满足 $0 \le D \le S(k-1)$，由归纳假设，后续（$k-1$ 到 1）能归零。
  - 若 $D > S(k-1)$：则 $D \ge S(k-1)+1 > \frac{(k-1)k}{2}$。需要 $k \le D$，即 $D \ge k$。由于 $D$ 是整数且 $D > \frac{k(k-1)}{2}$，对 $k \ge 2$ 有 $\frac{k(k-1)}{2} \ge k-1$，故 $D \ge k$（$k=1$ 时 $D > S(0)=0$ 即 $D \ge 1 = k$，也成立）。于是贪心取 $k$，新 $D' = D - k \le S(k) - k = \frac{k(k-1)}{2} = S(k-1)$，且 $D' \ge 0$，不变式恢复，由归纳假设后续归零。
- 两种情形都保证最终 $D = 0$。∎

**引理 3（定符号后升序最优）**：给定带符号多重集，其字典序最小的排列是升序排列。

**证明**：设某排列存在相邻（或任意）$i < j$ 且 $a_i > a_j$。交换这两个位置：交换后前 $i-1$ 位不变，第 $i$ 位从 $a_i$ 变为 $a_j < a_i$，故新排列字典序更小。因此字典序最小者不含任何逆序对，即升序排列。∎

**引理 4（贪心给出字典序最小）**：设贪心得到的取负集合为 $N^\ast$，其元素按降序记为 $g_1 > g_2 > \cdots > g_p$。则对任何可行集合 $N$（和同为 $D$），其降序序列 $e_1 > \cdots > e_q$ 满足：在两者第一个不相同的位置 $t$ 上，$g_t > e_t$。

**证明**：对贪心的步数归纳。第一步：贪心取 $g_1 = \min(n, D)$（因为从 $n$ 往下扫，第一个满足 $x \le D$ 的即 $\min(n, D)$）。任何可行集合的元素都不超过 $\min(n, D)$：元素 $\le n$ 显然，且若有元素 $> D$，其余元素为正，和超过 $D$，矛盾。故 $e_1 \le \min(n,D) = g_1$，若 $e_1 \ne g_1$ 则 $g_1 > e_1$，第一步即分出胜负。若 $e_1 = g_1$，则两边都取走 $g_1$，剩余问题变成「从 $1 \ldots g_1 - 1$ 中选子集和为 $D - g_1$」，由引理 2 的论证，该剩余和不超过 $S(g_1 - 1)$，归纳假设给出第二个位置的分出胜负关系。∎

**定理**：若存在可行数组，算法返回的是字典序最小者；否则返回空数组。

**证明**：
（1）**可行性判定完备**：$target \notin [-S, S]$ 时由引理 1，$\sum_{x \in N} x \ge 0$ 使和 $\le S$，且 $\ge -S$，故无解。$S - target$ 为奇数时，$2\sum x$ 必为偶数，故 $S - target$ 必为偶数，矛盾，无解。其余情形由引理 2，贪心给出和恰为 $D$ 的集合，引理 1 保证最终和等于 $target$，构造出的数组长度 $n$、绝对值恰为排列，故有解。
（2）**字典序最小**：任一可行数组由「取负集合 $N$ + 排列」决定。由引理 3，给定 $N$ 时升序排列最小；于是只需比较不同 $N$ 的升序数组。设 $N^\ast$ 为贪心集合、$N$ 为任一其他可行集合。由引理 4，在第一个不同位置 $t$ 上 $g_t > e_t$，从而升序数组中第 $t$ 位为 $-g_t < -e_t$；若 $N$ 的降序序列是 $N^\ast$ 的真前缀则两者和不同（矛盾），故 $N^\ast$ 不会被「更短却前缀相同」的情形击败。因此 $N^\ast$ 对应的升序数组字典序最小。
综合（1）（2），算法正确。∎

## 6. 复杂度分析

- **时间**：$O(n)$。计算 $S$ 与可行性判定 $O(1)$；贪心扫 $n$ 到 $1$ 一趟 $O(n)$；构造答案两趟 $O(n)$。总 $O(n)$，$n = 10^5$ 时约 $3 \times 10^5$ 次操作。
- **空间**：$O(n)$，`neg` 数组与输出数组各 $O(n)$；无排序、无递归。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> lexSmallestNegatedPerm(int n, long long target) {
        long long S = (long long)n * (n + 1) / 2;
        if (target < -S || target > S) return {};
        long long diff = S - target;
        if (diff % 2 != 0) return {};
        long long D = diff / 2;

        vector<char> neg(n + 1, 0);
        for (int x = n; x >= 1; x--) {
            if (x <= D) {
                neg[x] = 1;
                D -= x;
            }
        }

        vector<int> res;
        res.reserve(n);
        for (int x = n; x >= 1; x--) {
            if (neg[x]) res.push_back(-x);
        }
        for (int x = 1; x <= n; x++) {
            if (!neg[x]) res.push_back(x);
        }
        return res;
    }
};
```

### Python

```python
class Solution:
    def lexSmallestNegatedPerm(self, n: int, target: int) -> list[int]:
        S = n * (n + 1) // 2
        if target < -S or target > S:
            return []
        diff = S - target
        if diff % 2 != 0:
            return []
        D = diff // 2

        neg = [False] * (n + 1)
        for x in range(n, 0, -1):
            if x <= D:
                neg[x] = True
                D -= x

        res = [-x for x in range(n, 0, -1) if neg[x]]
        res += [x for x in range(1, n + 1) if not neg[x]]
        return res
```

## 8. 边界情况与易错点

1. **`target` 用 `int`**：$target$ 可达 $\pm 10^{10}$，C++ 必须 `long long`；Python 无此问题。函数签名 metaData 已给出 `long`。
2. **奇偶判定写错**：`diff % 2 == 1` 在 `diff` 为负时不成立（C++ 负数取模为负），要用 `!= 0`。注意此处 `diff = S - target ≥ 0`（已先判 $target \le S$），但仍建议用 `!= 0` 的习惯写法。
3. **`n * (n + 1) / 2` 溢出**：C++ 中若写成 `n * (n + 1) / 2`（`int` 运算），$n = 10^5$ 时 $10^5 \times 100001 = 10^{10}$ 直接溢出。必须先把 $n$ 转成 `long long`。
4. **返回空数组 vs 返回 `[0]`**：无解时返回 `{}` / `[]`（长度 0），不要返回含 0 的数组（`0` 不是 $1..n$ 的元素，绝对值为 0 也不合法）。
5. **构造顺序搞反**：必须「负数升序在前，正数升序在后」。若按 `1..n` 原序输出（负数留在原位），$n=3, target=0$ 会得到 $[1,2,-3]$，字典序比 $[-3,1,2]$ 大。
6. **$D = 0$**：不取任何负号，输出 $[1, 2, \ldots, n]$，注意此时第二个构造循环会输出全部 $n$ 个元素。
7. **$n = 1$**：$S = 1$，$target \in \{-1, 1\}$ 分别得 $[-1]$、$[1]$；其余一律空。注意 $target = 0$ 时 $diff = 1$ 为奇数，正确返回空。
8. **不要对结果排序后再输出负数绝对值**：只要保证「负数段降幅 + 正数段升幅」，等价于整体升序；直接对最终数组 `sort` 一遍也能得到同样结果，但多一次 $O(n \log n)$，没必要。
