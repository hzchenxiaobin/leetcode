# LeetCode 范围内总波动值 I 题解

## 1. 题目概述

- **标题 / 题号**：范围内总波动值 I（#3751，medium）
- **链接**：https://leetcode.cn/problems/total-waviness-of-numbers-in-range-i/
- **来源**：LeetCode 第 170 场双周赛 Q2
- **难度**：中等
- **标签**：数学、动态规划、枚举

**题意**：数字的**波动值**定义为它十进制表示中「峰」与「谷」的总数：

- 某数位**严格大于**它左右两个相邻数位 → 该位是**峰**；
- 某数位**严格小于**它左右两个相邻数位 → 该位是**谷**；
- 首位与末位**不可能**是峰或谷；
- 少于 3 位的数字波动值为 0。

给定闭区间 $[num1, num2]$，返回区间内所有数字的波动值之和。

**约束**：

- $1 \le num1 \le num2 \le 10^5$

## 2. 示例

**示例 1**

```text
输入：num1 = 120, num2 = 130
输出：3
解释：120（中间位 2 是峰）、121（2 是峰）、130（3 是峰）各贡献 1，其余为 0。
```

**示例 2**

```text
输入：num1 = 198, num2 = 202
输出：3
解释：198（9 是峰）、201（0 是谷）、202（0 是谷）各贡献 1。
```

**示例 3**

```text
输入：num1 = 4848, num2 = 4848
输出：2
解释：4848 的第二位 8 是峰、第三位 4 是谷，波动值 2。
```

## 3. 解题思路

### 3.1 暴力思路

区间长度最大 $10^5$，每个数最多 6 位。逐个数字、逐个数位检查「峰 / 谷」，单个数 $O(\text{位数})$，总计约 $6 \times 10^5$ 次比较——**这已经是本题的正解**。I 版的设计意图就是让你写对「枚举 + 逐位判定」，把精力留给理解「峰谷」的定义细节。

### 3.2 核心观察：只有「内部数位」参与判定

![峰与谷：只有非首非尾的内部数位才可能贡献](images/bw170_q2_peak_valley.svg)

设数字的十进制串为 $d_0 d_1 \cdots d_{L-1}$。对每个**内部**下标 $i \in [1, L-2]$：

$$w_i = \begin{cases} 1, & (d_i > d_{i-1} \text{ 且 } d_i > d_{i+1}) \ \text{或}\ (d_i < d_{i-1} \text{ 且 } d_i < d_{i+1}) \\ 0, & \text{否则} \end{cases}$$

数字的波动值 $W = \sum_{i=1}^{L-2} w_i$。三个易错点：

1. **首尾不算**：$d_0$ 没有左邻、$d_{L-1}$ 没有右邻，绝不能拿「缺省值 0」去比较（否则 $d_0 > 0$ 会被误判为峰）。
2. **严格不等**：$d_i = d_{i-1}$ 或 $d_i = d_{i+1}$ 都不算峰也不算谷（`4848` 的 4 与两侧都不等，才算谷）。
3. **少于三位为 0**：$L \le 2$ 时内部下标集合为空，求和自然为 0，无需特判。

### 3.3 算法流程

![算法流程：枚举区间内每个数，逐位判峰谷](images/bw170_q2_algorithm_flow.svg)

```text
1. ans = 0
2. for x = num1 .. num2:
       s = 十进制串(x)
       for i = 1 .. len(s)-2:
           左 = s[i-1]；中 = s[i]；右 = s[i+1]
           若 (中 > 左 且 中 > 右) 或 (中 < 左 且 中 < 右):  ans += 1
3. 返回 ans
```

### 3.4 示例演算

![示例演算：区间 198..202 的逐数判定](images/bw170_q2_example_walkthrough.svg)

对示例 2 的 $[198, 202]$：

| 数字 | 内部位 | 判定 | 波动值 |
|------|--------|------|--------|
| 198 | 9（邻居 1, 8） | $9 > 1$ 且 $9 > 8$ → 峰 | 1 |
| 199 | 9（邻居 1, 9） | $9 > 1$ 但 $9 \ngtr 9$；$9 \ngtr 9$ | 0 |
| 200 | 0（邻居 2, 0） | $0 < 2$ 但 $0 \ngtr 0$；不满足严格小 | 0 |
| 201 | 0（邻居 2, 1） | $0 < 2$ 且 $0 < 1$ → 谷 | 1 |
| 202 | 0（邻居 2, 2） | $0 < 2$ 且 $0 < 2$ → 谷 | 1 |

合计 3，与示例一致。注意 199 与 200 这两个「相邻相等」的反例，正是严格不等号的作用所在。

## 4. 算法细节

1. **转成字符串**：逐位比较用字符串最直观（`s[i-1]` 等），C++ 也可用整数取模，但字符串写法不易错。
2. **字符比较合法**：`'0'..'9'` 的 ASCII 码连续递增，`s[i] > s[i-1]` 与数值比较等价，无需 `- '0'`。
3. **循环边界**：`i` 从 1 到 $L-2$（含），即 `i + 1 < L`；写成 `i < L - 1` 即可。
4. **不要用「缺省比较值」**：有些实现会补 `s[-1] = 0`、`s[L] = 0` 然后统一判峰，这会把「数字 < 10 的数首位」误判——正确做法是直接限定内部下标。
5. **区间长度**：$num2 - num1 + 1 \le 10^5$，逐个数处理完全够；答案上界约 $10^5 \times 4$，`int` 足够。
6. **可写成辅助函数**：把「单数波动值」抽成 `waviness(x)`，主函数只负责枚举累加，代码更清晰，也便于 II 版复用。

## 5. 正确性证明

**引理 1（内部位命题）**：对 $L \ge 3$ 的数字，只有下标 $1 \le i \le L-2$ 的数位可能成为峰或谷。

**证明**：峰 / 谷的定义都要求「与左右两个相邻数位比较」。$i = 0$ 没有左邻，$i = L-1$ 没有右邻，二者不满足定义前提，故不可能。∎

**引理 2（$w_i$ 刻画）**：对内部位 $i$，$w_i = 1$ 当且仅当 $d_i$ 同时严格大于两个邻居或同时严格小于两个邻居。

**证明**：这是峰 / 谷定义的直接转写：峰即 $d_i > d_{i-1} \wedge d_i > d_{i+1}$，谷即 $d_i < d_{i-1} \wedge d_i < d_{i+1}$；二者互斥（不可能既大于又小于同一位），故 $w_i \in \{0,1\}$。∎

**引理 3（$L \le 2$ 时为 0）**：若数字少于 3 位，则波动值为 0。

**证明**：$L \le 2$ 时区间 $[1, L-2]$ 为空，引理 2 的求和为空和 $0$，与定义一致。∎

**定理**：算法输出等于 $\sum_{x=num1}^{num2} W(x)$。

**证明**：外层循环恰好枚举区间内每个整数一次（步长 1、闭区间），由引理 2，内层循环对每个数恰好累加其全部峰与谷的个数，即 $W(x)$；由引理 3，短数字自动贡献 0。故总累加值等于所求之和。∎

## 6. 复杂度分析

- **时间**：$O\big((num2 - num1 + 1) \cdot D\big)$，$D \le 6$ 为最大位数。最坏 $10^5 \times 6 = 6 \times 10^5$ 次比较，瞬时完成。数字串的构造也只需 $O(D)$。
- **空间**：$O(D)$，每个数字临时生成长度 $\le 6$ 的字符串；无额外数组（若 C++ 用 `to_string`，每次小字符串分配也在常数范围内）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int totalWaviness(int num1, int num2) {
        int ans = 0;
        for (int x = num1; x <= num2; x++) {
            string s = to_string(x);
            int len = (int)s.size();
            for (int i = 1; i + 1 < len; i++) {
                if ((s[i] > s[i - 1] && s[i] > s[i + 1]) ||
                    (s[i] < s[i - 1] && s[i] < s[i + 1])) {
                    ans++;
                }
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def totalWaviness(self, num1: int, num2: int) -> int:
        ans = 0
        for x in range(num1, num2 + 1):
            s = str(x)
            for i in range(1, len(s) - 1):
                a, b, c = s[i - 1], s[i], s[i + 1]
                if (b > a and b > c) or (b < a and b < c):
                    ans += 1
        return ans
```

## 8. 边界情况与易错点

1. **首尾参与判定**：把首位当峰（例如 `120` 的 1 与「假想的 0」比较判为峰）会多算。必须严格限定 $1 \le i \le L-2$。
2. **相等被算作峰谷**：用 `>=` / `<=` 而非 `>` / `<`。示例 2 的 199（9 与 9）、200（0 与 0）就是对应用例。
3. **两位及以下**：$L \le 2$ 时 `range(1, L-1)` 为空，Python 天然为 0；C++ 的 `i + 1 < len` 同样不进循环。若写成 `i < len - 1` 要小心 `len = 1` 时 `len - 1 = 0` 与有符号无符号混用。
4. **区间端点**：闭区间，`for x in range(num1, num2 + 1)`；漏掉 `num2` 是常见笔误。
5. **把峰谷判成「局部极值段」**：如 `1212` 中间两位都算（2 是峰、1 是谷），每个内部位独立判定，不要「去重」或「合并相邻」。
6. **前导零**：本题输入是十进制正整数，`to_string` 不会产生前导零，无需担心；但若迁移到「定长补零」的 DP，必须显式跳过前导零（见 II 版）。
