# LeetCode 二叉树中所有距离为 K 的结点 题解

## 1. 题目概述

- **标题 / 题号**：二叉树中所有距离为 K 的结点（#863，medium）
- **链接**：https://leetcode.cn/problems/all-nodes-distance-k-in-binary-tree/
- **来源**：LeetCode 第 91 场周赛 Q2
- **难度**：中等
- **标签**：树、深度优先搜索、广度优先搜索、哈希表、二叉树

**题意**：给定一棵二叉树 `root`、一个目标结点（题面以**结点的值** `target` 给出）和整数 $k$，返回所有与 `target` 距离恰好为 $k$ 的结点的值，顺序任意。

这里的「距离」是树上两点间唯一路径上的边数。关键难点在于：**距离为 $k$ 的结点既可能在 `target` 的子树里，也可能在它的祖先方向上**。

**约束**：

- 结点数在 $[1, 500]$ 范围内
- $0 \le \text{Node.val} \le 500$，且**所有结点的值互不相同**（因此用值就能唯一定位 `target`）
- `target` 保证是树上的结点
- $0 \le k \le 1000$

## 2. 示例

**示例 1**

```text
输入：root = [3,5,1,6,2,0,8,null,null,7,4], target = 5, k = 2
输出：[7,4,1]
解释：以 5 为起点，距离 1 的结点是 3、6、2；
     距离 2 的结点是 1（经 3）、7（经 2）、4（经 2）。
```

**示例 2**

```text
输入：root = [1], target = 1, k = 3
输出：[]
解释：整棵树只有 1 个结点，不存在距离为 3 的结点。
```

**示例 3（补充）**

```text
输入：root = [0,1,2,3,4], target = 1, k = 1
输出：[0,3,4]
解释：1 的父结点 0、左孩子 3、右孩子 4，三者距离都是 1。
     这个例子专门说明「向上」也需要计入。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的想法是「从 `target` 出发向下 DFS，走了 $k$ 层就收集」。但它只能覆盖**子树方向**：在示例 3 中，从 1 往下走 1 层只得到 3 和 4，漏掉了父结点 0；在示例 1 中，从 5 向上再折向右边才能拿到 1。

补上方向的办法是枚举每一对结点：对每个候选点 $v$ 求它与 `target` 的距离，用「求最近公共祖先 + 深度差」的公式 $dist(u,v) = dep(u) + dep(v) - 2\,dep(lca)$，单次 $O(\log n)$，总共 $O(n \log n)$ 也能过（$n \le 500$）。但对一般二叉树求 LCA 需要倍增或 Tarjan，实现成本远高于本题应有的难度。

真正的问题是：**树是有向的（只有指向孩子的边），而「距离」是无向概念**。补上反向边，问题立刻退化成一个标准的最短路。

### 3.2 核心观察：补父指针，把树变成无向图

![给每个结点补一条指向父结点的指针，树就变成无向图](images/wc91_q2_parent_edges.svg)

一次 DFS 就能顺手完成两件事：

1. 用哈希表记录 `parent[child] = node`，把「父亲 → 孩子」的单向边**补成双向**；
2. 顺便找到值等于 `target` 的那个结点，作为 BFS 的起点。

改造后得到一个有 $n$ 个结点、$2(n-1)$ 条边的无向图（就是原树的无向版本）。在这个图上，「与 `target` 距离为 $k$」就是「从 `target` 出发的 BFS 第 $k$ 层」。

> 💡 **一句话总结**：树的距离问题先问「是否需要向上走」。需要，就先补父指针把树当图用。

### 3.3 算法流程

![算法流程：一次建图 + 一次 BFS](images/wc91_q2_algorithm_flow.svg)

```text
1. parent = {root: null}，栈 stack = [root]，start = null
2. while stack 非空：
       取栈顶 node
       若 node.val == target：start = node
       对 node 的左右孩子 ch（存在时）：
           parent[ch] = node；ch 入栈
3. visited = {start}，队列 q = [start]，dist = 0
4. while q 非空：
       记录当前层大小 sz
       重复 sz 次：出队 cur
           若 dist == k：把 cur.val 收入答案，不再扩展
           否则把 cur 的左孩子、右孩子、parent[cur]（存在且未访问）入队
       若 dist == k：结束
       dist += 1
5. 返回答案
```

### 3.4 示例演算

![从 target 出发逐层扩散：第 k 层就是答案](images/wc91_q2_bfs_layers.svg)

对示例 1 的树，从 5 出发：

| 层数 | 本层结点 | 说明 |
|------|----------|------|
| dist = 0 | 5 | 起点（已访问） |
| dist = 1 | 3, 6, 2 | 3 来自 parent，6 与 2 来自左右孩子 |
| dist = 2 | 1, 7, 4 | 1 由 3 向下得到，7、4 由 2 向下得到 |

$k = 2$，因此收集第 2 层，答案为 $\{1, 7, 4\}$，与示例输出一致。注意 6 的左右孩子都为空、3 的另一侧是 1，正是「父指针」让 3 这一支能继续向外扩展。

## 4. 算法细节

1. **建图方式**：C++ 用 `unordered_map<TreeNode*, TreeNode*>`，Python 用 `dict`，键是结点对象本身（按引用/身份哈希），不要用 `val` 作键——虽然本题值互不相同，但用对象更通用。
2. **起点定位**：题面给的是**值**，所以在建图 DFS 里比对 `node.val == target`。值互不相同保证了唯一性。
3. **访问标记**：无向图必须带 `visited`，否则会立刻沿「孩子 → 父 → 孩子」来回震荡。
4. **层序控制**：用「记录当前队列长度、整层处理」的写法，层内出队时判断 `dist == k`；也可以把 `(node, dist)` 一起入队，代码更短但常数略大。
5. **剪枝**：一旦 `dist == k` 收集完本层就立刻结束，不再把第 $k+1$ 层入队。
6. **不用递归的建图**：结点数上限 500，递归不会爆栈，但显式栈更稳。

## 5. 正确性证明

记原树为 $T$，构造的无向图为 $G$：$G$ 的顶点集与 $T$ 相同，边集为 $T$ 的全部父子边（视为无向）。

**引理 1（边集一致）**：对任意两个不同结点 $u, v$，$(u,v)$ 是 $G$ 中的边当且仅当 $T$ 中 $u$ 是 $v$ 的父结点或 $v$ 是 $u$ 的父结点。

**证明**：算法对每条父子边 `node → child` 都写入了 `parent[child] = node`，BFS 扩展时同时沿「孩子」和「父」两个方向走，等价于把这条边当作双向边；反之 $G$ 中没有加入任何非父子边。∎

**引理 2（树中唯一路径）**：$T$ 中任意两结点间恰有一条简单路径，其边数即两点距离；在 $G$ 中沿父子边行走的任意简单路径与 $T$ 中的路径一一对应。

**证明**：树是无环连通图，任取 $u, v$，从 $u$ 出发沿边向上走到 $lca(u,v)$ 再向下走到 $v$ 得到一条路径；若存在两条不同简单路径则并起来构成环，与无环矛盾，故唯一。$G$ 只把同一条边看成双向，不增加新的连通方式，所以 $G$ 中的简单路径集合与 $T$ 中相同（只是方向可逆）。∎

**引理 3（BFS 层次 = 最短距离）**：设 $G$ 中所有边权为 1，从起点 $s$ 做 BFS，则结点 $v$ 在 BFS 中首次被访问时的层号等于 $dist_G(s, v)$。

**证明**：对层号归纳。第 0 层只有 $s$，$dist = 0$。设第 $d$ 层恰好是所有距离为 $d$ 的结点，则第 $d+1$ 层的结点恰为「与第 $d$ 层相邻且未被访问」者：一方面它们与 $s$ 的距离不超过 $d+1$；另一方面若某结点距离为 $d+1$，其最短路径上的前驱距离为 $d$，已在第 $d$ 层，故它必被第 $d$ 层扩展到时距离恰为 $d+1$（若更早被访问则距离更小，矛盾）。∎

**定理**：算法输出的集合恰为 $\{v \in T : dist_T(\text{target}, v) = k\}$。

**证明**：由引理 1、2，$G$ 中的最短距离与原树距离相同；由引理 3，BFS 第 $k$ 层的结点正是距离 `target` 恰为 $k$ 的结点；算法恰好收集第 $k$ 层并在此后停止，故输出的集合与所求集合相等，且每个结点只被收入一次（`visited` 保证）。∎

## 6. 复杂度分析

- **时间**：$O(n)$。建图 DFS 每个结点进出栈一次，每条父子边处理一次，共 $O(n)$；BFS 中每个结点至多入队一次，每个结点扩展至多 3 条边（左孩子、右孩子、父结点），共 $O(n)$。
- **空间**：$O(n)$。`parent` 哈希表存 $n-1$ 条记录，`visited` 与 BFS 队列各 $O(n)$，递归/显式栈 $O(n)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> distanceK(TreeNode* root, int target, int k) {
        unordered_map<TreeNode*, TreeNode*> parent;
        parent[root] = nullptr;
        TreeNode* start = nullptr;
        stack<TreeNode*> st;
        st.push(root);
        while (!st.empty()) {
            TreeNode* node = st.top();
            st.pop();
            if (node->val == target) start = node;
            if (node->left) {
                parent[node->left] = node;
                st.push(node->left);
            }
            if (node->right) {
                parent[node->right] = node;
                st.push(node->right);
            }
        }

        vector<int> ans;
        unordered_set<TreeNode*> visited;
        queue<TreeNode*> q;
        q.push(start);
        visited.insert(start);
        int dist = 0;
        while (!q.empty()) {
            int sz = (int)q.size();
            for (int i = 0; i < sz; i++) {
                TreeNode* cur = q.front();
                q.pop();
                if (dist == k) {
                    ans.push_back(cur->val);
                    continue;
                }
                TreeNode* cand[3] = {cur->left, cur->right, parent[cur]};
                for (TreeNode* nxt : cand) {
                    if (nxt && !visited.count(nxt)) {
                        visited.insert(nxt);
                        q.push(nxt);
                    }
                }
            }
            if (dist == k) break;
            dist++;
        }
        return ans;
    }
};
```

### Python

```python
from collections import deque

class Solution:
    def distanceK(self, root: TreeNode, target: int, k: int) -> list[int]:
        parent = {root: None}
        start = None
        stack = [root]
        while stack:
            node = stack.pop()
            if node.val == target:
                start = node
            for child in (node.left, node.right):
                if child is not None:
                    parent[child] = node
                    stack.append(child)

        ans = []
        visited = {start}
        q = deque([start])
        dist = 0
        while q:
            for _ in range(len(q)):
                cur = q.popleft()
                if dist == k:
                    ans.append(cur.val)
                    continue
                for nxt in (cur.left, cur.right, parent[cur]):
                    if nxt is not None and nxt not in visited:
                        visited.add(nxt)
                        q.append(nxt)
            if dist == k:
                break
            dist += 1
        return ans
```

## 8. 边界情况与易错点

1. **$k = 0$**：答案就是 `[target]` 本身，代码里「先判 `dist == k` 再扩展」的写法天然正确；若写成「先扩展再判断」会多收集一层。
2. **$k$ 大于偏心距**：队列在某层就空了，返回空数组（示例 2），不要返回 `[-1]` 之类的哨兵。
3. **只向下搜索**：最常见的错误，示例 3 会立刻暴露——必须沿父指针向上。
4. **忘记 `visited`**：无向图上会父子来回震荡，队列爆炸或死循环。
5. **用 `val` 做 `visited` 的键**：本题值互不相同所以能过，但写法脆弱；用结点指针更稳妥。
6. **单结点树**：`root` 既是根也是 `target`，建图时 `parent[root] = null`，扩展时对空指针要判空。
7. **答案顺序**：题面允许任意顺序，判题器通常按集合比较；若本地对拍，请先排序再比较。
