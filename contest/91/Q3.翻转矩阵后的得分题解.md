# LeetCode 翻转矩阵后的得分 题解

## 1. 题目概述

- **标题 / 题号**：翻转矩阵后的得分（#861，medium）
- **链接**：https://leetcode.cn/problems/score-after-flipping-matrix/
- **来源**：LeetCode 第 91 场周赛 Q3
- **难度**：中等
- **标签**：贪心、位运算、数组、矩阵

**题意**：给定 $m \times n$ 的 0/1 矩阵 `grid`。一次**移动**可以选任意一行或任意一列，把该行/列的所有元素取反（0 变 1、1 变 0）。做任意多次移动后，把每一行看成一个二进制数，矩阵的**得分**是这些数之和。求可能的最大得分。

关键词是「任意多次」：行/列翻转都是自逆操作，所以只需关心**每行、每列各自翻了奇数次还是偶数次**，与先后顺序无关。

**约束**：

- $1 \le m, n \le 20$
- $grid[i][j] \in \{0, 1\}$

## 2. 示例

**示例 1**

```text
输入：grid = [[0,0,1,1],[1,0,1,0],[1,1,0,0]]
输出：39
解释：把第 0 行翻成 [1,1,0,0]，再把第 2、3 列各翻一次，得到
     [1,1,1,1] = 15
     [1,0,0,1] = 9
     [1,1,1,1] = 15
     总分 15 + 9 + 15 = 39。
```

**示例 2**

```text
输入：grid = [[0]]
输出：1
解释：只有一个元素，翻转该行即可得到 1。
```

**示例 3（补充）**

```text
输入：grid = [[0,1],[1,0]]
输出：6
解释：翻转第 0 行得 [[1,0],[1,0]]，再翻转第 1 列得 [[1,1],[1,1]]，
     总分 3 + 3 = 6。这说明「行翻转之外还要考虑列翻转」。
```

## 3. 解题思路

### 3.1 暴力思路

$m, n \le 20$，每行每列都可以选择翻或不翻，方案数 $2^{m+n}$，最大 $2^{40}$，不可枚举。若只枚举行翻转（$2^m \le 10^6$）再对每列贪心，其实已经接近正解；但对每一行都枚举仍嫌浪费，而且对 $m = 20$ 时 $2^{20} \times 20$ 虽然勉强能过，却完全没有必要。

### 3.2 核心观察：把总分按「列」拆分

![把行得分拆成每一列的贡献：权重是 2 的幂](images/wc91_q3_bit_weight.svg)

得分其实是各行二进制数之和。交换求和顺序，**按列**来看：

$$\text{score} = \sum_{j=0}^{n-1} c_j \cdot 2^{\,n-1-j}$$

其中 $c_j$ 是第 $j$ 列中 1 的个数。于是每一列的贡献只取决于「这一列有多少个 1」，而**列翻转只能把 $c_j$ 变成 $m - c_j$**，动不了别的列。

由此得到两条结论：

1. **首列（$j = 0$）的权重 $2^{n-1}$ 比后面所有列加起来还大**：$\sum_{j=1}^{n-1} 2^{n-1-j} = 2^{n-1} - 1$。所以只要某行的首位是 0，翻转整行一定使总分增加（至少 $+1$），且这是最优解的必要条件。
2. 首列固定为全 1 之后，剩下每一列都独立地取 $\max(c_j, m - c_j)$：1 多的方向就是最终方向，直接按需翻转该列。

### 3.3 算法流程

![示例走查：先按行把首列翻成全 1，再按列把 1 多的方向留下](images/wc91_q3_example_flip.svg)

```text
1. 对每一行 i：
       若 grid[i][0] == 0：整行取反（首列变 1，得分必然变大）
2. score = 0
3. 对每一列 j：
       ones = 该列 1 的个数
       score += max(ones, m - ones) * (1 << (n - 1 - j))
4. 返回 score
```

第一步之后首列全为 1，第二步对每列取「翻转或不翻转中更好的那个」。两步合起来只做了 $O(mn)$ 的工作。

### 3.4 示例演算

对示例 1 的矩阵：

| 阶段 | 第 0 行 | 第 1 行 | 第 2 行 |
|------|---------|---------|---------|
| 原始 | 0 0 1 1 | 1 0 1 0 | 1 1 0 0 |
| 第 0 行翻成首列 1 | 1 1 0 0 | 1 0 1 0 | 1 1 0 0 |
| 各列 1 的个数 | 3 | 2 | 1 → 翻成 2 | 0 → 翻成 3 |
| 列翻转后 | 1 1 1 1 | 1 0 0 1 | 1 1 1 1 |

最终得分为 $15 + 9 + 15 = 39$。注意第 1 列有 2 个 1、只有 1 个 0，不翻转；第 2、3 列反之，各翻一次。首列有 3 个 1（$= m$），已经最大，绝不翻转。

## 4. 算法细节

1. **翻转的实现**：直接原地异或 `grid[i][j] ^= 1`，或者只在计算时判断该行「是否被翻过」——本题 $m, n \le 20$，原地改最省事。
2. **权重计算**：第 $j$ 列权重是 $2^{\,n-1-j}$，用 `1 << (n - 1 - j)`；$n \le 20$ 不会溢出 `int`（最大约 $2^{20}$，得分上界 $20 \times 2^{19}$，仍在 `int` 内）。
3. **第一步只看首列**：只需判断 `grid[i][0]`，因为行翻转的收益完全由首列支配；不要试图「对每行比较翻转前后的得分再决定」，那样既慢又容易写错交互影响。
4. **第二步逐列统计**：`ones` 与 `m - ones` 取较大者，等价于「这一列翻或不翻取优」。
5. **两步的顺序不可换**：若先做列翻转再翻行，那么行翻转会破坏已经调好的列分布；正确顺序是「先定行（首列全 1）→ 再定价列」。
6. **只翻转首列为 0 的行**：首列为 1 的行若翻转，会立刻损失 $2^{n-1}$ 分，后面所有列最多补回 $2^{n-1}-1$，必然亏。

## 5. 正确性证明

先说明一个建模前提。

**引理 1（移动可交换）**：任意移动序列的最终效果只由「哪些行被翻了奇数次」和「哪些列被翻了奇数次」决定，与顺序无关。

**证明**：每次行翻转是对该行所有元素异或 1，每次列翻转是对该列所有元素异或 1。对单元格 $(i, j)$ 的最终值等于初值异或「第 $i$ 行翻转次数的奇偶」异或「第 $j$ 列翻转次数的奇偶」。异或满足交换律与结合律，故只与各行、各列的奇偶性有关。∎

**引理 2（最优解首列必全 1）**：设 $A$ 是任一通过合法移动得到的矩阵，若存在某行 $i$ 满足 $A[i][0] = 0$，则对 $A$ 再做一次行翻转可使得分严格增大。

**证明**：翻转第 $i$ 行只改变该行的数值。设翻转前该行值按位为 $b_0 b_1 \cdots b_{n-1}$，$b_0 = 0$，其贡献为 $\sum_{j\ge1} b_j 2^{n-1-j}$；翻转后首位置 1、其余位取反，贡献为 $2^{n-1} + \sum_{j\ge1} (1-b_j) 2^{n-1-j}$。差值

$$\Delta = 2^{n-1} + \sum_{j\ge 1}(1 - 2b_j)\,2^{n-1-j} \ge 2^{n-1} - \sum_{j\ge 1} 2^{n-1-j} = 2^{n-1} - (2^{n-1} - 1) = 1 > 0$$

故得分严格增大，$A$ 不可能是最优。∎

**引理 3（列贡献可分离）**：固定各行翻转方案后，总得分为各列贡献之和，且列 $j$ 的贡献为 $c_j \cdot 2^{n-1-j}$（不翻）或 $(m - c_j)\cdot 2^{n-1-j}$（翻），其中 $c_j$ 是该列 1 的个数；对一列的操作不影响其他列的 $c_{j'}$。

**证明**：由引理 1，最终得分是矩阵中所有 1 按其列权重的加权和，按列汇总即得第一式。列翻转只把本列的 0/1 互换，故本列 1 的个数变为 $m - c_j$，而其他列逐元素不变。∎

**定理**：算法返回的得分是可达的最大得分。

**证明**：设最优矩阵为 $A^\*$，由引理 2 可设其首列全 1（否则可继续增大，与最优矛盾），且这只需翻转首列为 0 的行，正是算法的第一步。对第二步，由引理 3，在行翻转固定后各列独立，算法取 $\max(c_j, m - c_j) \cdot 2^{n-1-j}$ 是该列在两种选择下的最大值，因而对任意列选择方案 $A^\*$ 都有

$$\text{score}(A^\*) \le \sum_j \max(c_j, m - c_j)\, 2^{n-1-j} = \text{score}(\text{算法})$$

另一方面算法对应的操作序列合法（先翻行为 0 的行，再按需翻列，首列本身 $c_0 = m$ 已最优不翻），所以该上界可达，算法结果即最大值。∎

## 6. 复杂度分析

- **时间**：$O(mn)$。行翻转扫描 $m$ 行、每行 $n$ 个元素，$O(mn)$；逐列统计 $n$ 列、每列 $m$ 个元素，$O(mn)$。合计 $O(mn)$。
- **空间**：$O(1)$ 额外空间（原地修改输入矩阵，不做额外拷贝）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int matrixScore(vector<vector<int>>& grid) {
        int m = grid.size(), n = grid[0].size();
        for (int i = 0; i < m; i++) {
            if (grid[i][0] == 0) {
                for (int j = 0; j < n; j++) grid[i][j] ^= 1;
            }
        }
        int score = 0;
        for (int j = 0; j < n; j++) {
            int ones = 0;
            for (int i = 0; i < m; i++) ones += grid[i][j];
            score += max(ones, m - ones) * (1 << (n - 1 - j));
        }
        return score;
    }
};
```

### Python

```python
class Solution:
    def matrixScore(self, grid: list[list[int]]) -> int:
        m, n = len(grid), len(grid[0])
        for i in range(m):
            if grid[i][0] == 0:
                for j in range(n):
                    grid[i][j] ^= 1
        score = 0
        for j in range(n):
            ones = sum(grid[i][j] for i in range(m))
            score += max(ones, m - ones) * (1 << (n - 1 - j))
        return score
```

## 8. 边界情况与易错点

1. **单元素矩阵**：`[[0]]` 翻转后为 `[[1]]`，答案 1（示例 2），权重公式 `1 << (n-1-j)` 在 $n=1$ 时取 $2^0 = 1$，正确。
2. **单行矩阵**：$m = 1$ 时「翻转该列」等价于把这一位改 1，`max(ones, m - ones)` 恒为 1，答案恰为 $2^n - 1$。
3. **单列矩阵**：$n = 1$ 时首列就是所有权重，先把首列全变 1，答案恒为 $m$。
4. **权重不要写反**：第 $j$ 列对应 $2^{n-1-j}$（左边是高位），写 `1 << j` 会把结果算成镜像。
5. **忘记先翻行**：只做列翻转时示例 1 得 33 而不是 39，是最常见的失分点。
6. **首列也去比 `max`**：首列翻转后 1 的个数是 $m - m = 0$，若误取 `max` 没问题，但若先翻转首列则直接崩；正确做法是首列永远不翻。
7. **整数溢出**：$m, n \le 20$ 时最大得分约 $20 \times 2^{19} \approx 1.05\times 10^7$，`int` 足够；若 $n$ 更大则需 `long long`。
