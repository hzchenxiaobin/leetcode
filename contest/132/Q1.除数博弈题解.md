# LeetCode 除数博弈 题解

## 1. 题目概述

- **标题 / 题号**：除数博弈（#1025，easy）
- **链接**：https://leetcode.cn/problems/divisor-game/
- **来源**：LeetCode 第 132 场周赛 Q1
- **难度**：简单
- **标签**：数学、动态规划、博弈论、脑筋急转弯

**题意**：黑板上有一个数字 $n$，Alice 先手，两人轮流操作。轮到某人时，他必须：

1. 选一个整数 $x$，满足 $0 < x < n$ 且 $n \bmod x = 0$；
2. 把黑板上的数替换为 $n - x$。

无法操作的人输。两人都采取最优策略，返回 Alice 是否必胜。

**约束**：

- $1 \le n \le 1000$

> 💡 这是一道典型的**无偏博弈（impartial game）**：局面只由当前数字决定，必胜/必败可以按 $n$ 从小到大递推。

## 2. 示例

**示例 1**

```text
输入：n = 2
输出：true
解释：Alice 只能选 x = 1（唯一的真因子），把 2 变成 1；
      Bob 面对 1，找不到 0 < x < 1 的因子，无法操作，输。
```

**示例 2**

```text
输入：n = 3
输出：false
解释：Alice 只能选 x = 1，把 3 变成 2；Bob 选 x = 1，把 2 变成 1；
      Alice 面对 1 无法操作，输。
```

**示例 3（自造）**

```text
输入：n = 4
输出：true
解释：Alice 选 x = 1，把 4 变成 3（奇数）；之后 Bob 只能把奇数变成偶数，
      Alice 再把偶数变成奇数……最终 Bob 面对 1，Alice 胜。
```

## 3. 解题思路

### 3.1 暴力思路

把每个数字当作一个局面，做记忆化搜索：

$$win(n) = \exists\, x \mid n,\ 0 < x < n:\ \lnot win(n - x)$$

$n \le 1000$ 时，对每个 $n$ 枚举因子是 $O(\sqrt n)$，总复杂度 $O(n\sqrt n)$，完全能过。但它把一个有封闭形式的问题做成了搜索，既慢又不必要。

### 3.2 核心观察：奇偶性决定胜负

![奇偶转移：奇数只能交出偶数，偶数总能交出奇数](images/wc132_q1_parity_concept.svg)

两条关于因子的基本事实：

- 设 $x \mid n$ 且 $x < n$，则 $x$ 与 $n$ **奇偶性相同当且仅当** $n$ 是偶数时 $x$ 可以取偶——更关键的是：**若 $n$ 是奇数，则 $n$ 的所有因子 $x$ 都是奇数**（若 $x$ 是偶数且 $x \mid n$，则 $n$ 也是偶数，矛盾）。
- 因此：
  - **$n$ 是奇数**：$n - x$ 必为**偶数**（奇 − 奇 = 偶）。也就是说，面对奇数的人只能把偶数交给对手。
  - **$n$ 是偶数**：取 $x = 1$（$1$ 一定是因子），$n - 1$ 是**奇数**。也就是说，面对偶数的人可以把奇数交给对手。

于是局面在奇偶之间交替：

| 当前 $n$ | 可交出的局面 | 结论 |
|---|---|---|
| 奇数 $> 1$ | 只能交给对手偶数 | 必败 |
| 偶数 | 可以交给对手奇数 | 必胜 |
| $n = 1$ | 无法操作 | 必败 |

用归纳法把它变成定理（见 §5）：**偶数必胜，奇数必败**。所以答案就是 `n % 2 == 0`。

> 💡 直观解释：每局只要 $n > 1$ 就能操作（$x = 1$ 总是合法），而每次操作都会把 $n$ 严格变小；奇数局面的「控制权」被夺走——持有偶数的人每次都把「只能交偶数」的奇数留给对手，最终把 1 留给对手。

### 3.3 算法流程

![算法流程：一行判定](images/wc132_q1_algorithm_flow.svg)

```text
1. 若 n 是偶数: 返回 true
2. 否则:        返回 false
```

### 3.4 示例演算

![示例演算：n = 4 的四步走完](images/wc132_q1_walkthrough.svg)

$n = 4$（偶）：

| 步 | 轮到 | 黑板 | 选择 | 交出的数 |
|---|---|---|---|---|
| 1 | Alice | 4 | $x = 1$ | 3（奇） |
| 2 | Bob | 3 | $x = 1$ | 2（偶） |

## 4. 算法细节

1. **只需判奇偶**：`return n % 2 == 0`，时间 $O(1)$、空间 $O(1)$。
2. **$n = 1$ 的特判被自动覆盖**：1 是奇数，返回 false，正是「先手无法操作」。
3. **奇数的因子必为奇数**：这是整个结论的支点，务必在证明里写清楚（若 $x$ 为偶数且 $x \mid n$，则 $n$ 为偶数）。
4. **$x = 1$ 永远合法**（当 $n > 1$）：所以「能否操作」只取决于 $n$ 是否等于 1，而不是因子结构。
5. **不要用 DP 也能 AC，但要能说清为什么**：面试/题解里如果只写 `n % 2 == 0` 而不给证明，会被认为「猜出来的」。

## 5. 正确性证明

**引理 1（奇数的因子皆奇）**：若 $n$ 为奇数、$x \mid n$，则 $x$ 为奇数。

**证明**：反证，若 $x$ 为偶数，设 $x = 2k$、$n = xm = 2km$，则 $n$ 为偶数，与 $n$ 为奇数矛盾。∎

**引理 2（可操作性）**：$n > 1$ 时存在合法选择 $x$（取 $x = 1$）；$n = 1$ 时不存在。

**证明**：$n > 1$ 时 $0 < 1 < n$ 且 $n \bmod 1 = 0$，故 $x = 1$ 合法。$n = 1$ 时要求 $0 < x < 1$，无整数解。∎

**定理**：对任意 $n \ge 1$，若 $n$ 为偶数则先手必胜，若 $n$ 为奇数则先手必败。

**证明**：对 $n$ 作强归纳。

- $n = 1$：由引理 2，先手无法操作，必败，与「奇数必败」一致。
- 设结论对所有 $< n$ 的数成立，考察 $n$：
  - **$n$ 为偶数**：先手取 $x = 1$（合法，引理 2），局面变为 $n - 1$，是奇数且 $< n$。由归纳假设，$n-1$ 是必败局面，故先手有制胜着法，必胜。
  - **$n$ 为奇数**：任一合法 $x$ 由引理 1 都是奇数，故 $n - x$ 是偶数且 $1 \le n - x < n$。由归纳假设，所有可达局面（偶数）都是必胜局面，即无论先手怎么走，对手都必胜，故先手必败。

由强归纳，结论对所有 $n \ge 1$ 成立。∎

## 6. 复杂度分析

- **时间**：$O(1)$，一次取模。
- **空间**：$O(1)$。
- **对比**：记忆化搜索为 $O(n\sqrt n)$（$n \le 1000$ 约 $3 \times 10^4$ 次枚举），虽然也能过，但结论型解法更优。

```cpp
    }
```


## 8. 边界情况与易错点

1. **$n = 1$**：返回 false（先手无法操作），`n % 2 == 0` 恰好给出 false，无需特判。
2. **$n = 2$**：唯一选择 $x = 1$，返回 true。
3. **$x$ 不能等于 $n$**：题目要求 $x < n$，所以 $n$ 本身不能选；否则先手可以把 $n$ 直接变成 0 秒杀。
4. **误以为「偶数因子个数多就赢」**：胜负只与奇偶有关，与因子个数无关。
5. **用 DP 时忘记 `win[1] = false`**：递推基准错会导致整体翻转。
6. **$n$ 很大时不要搜索**：$n$ 若放大到 $10^9$，搜索必然超时，而奇偶结论仍是 $O(1)$。
