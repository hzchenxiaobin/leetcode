# LeetCode 节点与其祖先之间的最大差值 题解

## 1. 题目概述

- **标题 / 题号**：节点与其祖先之间的最大差值（#1026，medium）
- **链接**：https://leetcode.cn/problems/maximum-difference-between-node-and-ancestor/
- **来源**：LeetCode 第 132 场周赛 Q2
- **难度**：中等
- **标签**：树、深度优先搜索、二叉树

**题意**：给定二叉树的根 `root`，在**不同**节点 $A, B$ 中（$A$ 是 $B$ 的祖先），求 $V = |A.val - B.val|$ 的最大值。

「祖先」的定义：$A$ 是 $B$ 的祖先，当且仅当 $A$ 在根到 $B$ 的路径上且 $A \ne B$。

**约束**：

- 节点数在 $[2, 5000]$ 范围内
- $0 \le Node.val \le 10^5$

> 💡 键的观察：对固定节点 $B$，要让 $|A.val - B.val|$ 最大，$A$ 只需在**根到 $B$ 路径上的最小值**与**最大值**之间选——不用枚举所有祖先。

## 2. 示例

**示例 1**

```text
输入：root = [8,3,10,1,6,null,14,null,null,4,7,13]
输出：7
解释：|8 - 1| = 7 是最大值（8 在根到 1 的路径上）；
      其他如 |8-3| = 5、|3-7| = 4、|10-13| = 3 都更小。
```

**示例 2**

```text
输入：root = [1,null,2,null,0,3]
输出：3
解释：树是一条「只有左孩子」的链 1 → 2 → 0，节点 3 是 0 的左孩子；
      路径上的最大差值是 |0 - 3| = 3。
```

**示例 3（自造）**

```text
输入：root = [5,5]
输出：0
解释：两个节点值相同，任何祖先对差值都是 0。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的做法：对每个节点 $B$，沿父指针向上走到根，收集所有祖先的值，求 $|A.val - B.val|$ 的最大值。

- 单次向上走是 $O(h)$，总计 $O(nh)$，链状树退化为 $O(n^2) = 2.5 \times 10^7$；
- 而且需要先构建父指针（或者对每个节点重新 DFS 定位路径），实现也麻烦。

换一个方向：DFS 时把「当前路径」整个记住（用一个数组），回溯时维护。这样每个节点都要重新遍历路径数组，同样是 $O(nh)$。

### 3.2 核心观察：|差值| 只需路径上的 min 与 max

![对固定 B，最优祖先必是路径最小或最大值](images/wc132_q2_path_minmax.svg)

对固定节点 $B$ 和它祖先集合 $S$：

$$\max_{A \in S} |A.val - B.val| = \max\Bigl( \max_{A \in S} A.val - B.val,\; B.val - \min_{A \in S} A.val \Bigr)$$

也就是说，只需要知道路径上的**最大值** $M$ 与**最小值** $m$：

$$\text{候选}(B) = \max\bigl(M - B.val,\; B.val - m\bigr)$$

（若 $m = M = B.val$ 则为 0，也无妨。）

而 $M, m$ 在 DFS 时**按路径增量维护**：进入孩子时 $M' = \max(M, val)$、$m' = \min(m, val)$，回溯时父节点仍保有自己的 $M, m$。由于是按值传递，兄弟分支互不干扰。

> 💡 这就是「路径状态随 DFS 下行」的又一实例：把「祖先集合」压缩成「路径上的 (min, max)」，状态只有两个整数。

### 3.3 算法流程

![算法流程：携带 (min, max) 下行，逐节点更新答案](images/wc132_q2_dfs_flow.svg)

```text
1. ans = 0
2. dfs(u, mn, mx):
       若 u 为空: 返回
       ans = max(ans, mx - u.val, u.val - mn)     # 用「进入 u 之前」的路径极值
       mn2 = min(mn, u.val)
       mx2 = max(mx, u.val)
       dfs(u.left,  mn2, mx2)
       dfs(u.right, mn2, mx2)
3. dfs(root, root.val, root.val)，返回 ans
```

两个细节：

- 初始时 $mn = mx = root.val$（路径只有根）；
- 先算答案再更新 $mn, mx$ 更自然（保证 $A \ne B$），但即使包含自身也无妨——自己与自己差 0，不会影响最大值。

### 3.4 示例演算

![示例演算：沿路径维护 min / max](images/wc132_q2_walkthrough.svg)

对示例 1 的树：

| 节点（路径） | 路径极值（进入前） $m, M$ | 候选 $M-v,\ v-m$ | 当前答案 |
|---|---|---|---|
| 8（根） | 8, 8 | 0, 0 | 0 |
| 3（8→3） | 8, 8 | 5, −5 | 5 |
| 1（8→3→1） | 3, 8 | 7, −2 | **7** |
| 6（8→3→6） | 3, 8 | 2, 3 | 7 |
| 4（8→3→6→4） | 3, 8 | 4, 1 | 7 |
| 7（8→3→6→7） | 3, 8 | 1, 4 | 7 |
| 10（8→10） | 8, 8 | −2, 2 | 7 |

| 13（8→10→14→13） | 8, 14 | 1, 5 | 7 |

最终答案 7，由 $|8 - 1|$ 取得 ✓。

## 4. 算法细节

1. **先结算再更新**：进入节点时用「父路径的 $m, M$」计算候选，天然满足 $A \ne B$；若先更新再算，会把自己的值算进祖先集合（结果不变，因为自差为 0，但语义上不严谨）。
2. **初始值**：$mn = mx = root.val$，根节点候选为 0。
3. **按值传递**：C++ 递归参数 `int mn, int mx` 按值传递，回溯自动恢复；Python 同理。
4. **答案用引用/成员**：C++ `int& ans`；Python `nonlocal` 或类成员。
5. **数值范围**：$val \le 10^5$，差最大 $10^5$，`int` 足够。若值域达 $10^{18}$ 需 `long long`。
6. **不建父指针**：只需一次自顶向下的 DFS，无需额外预处理，空间只有递归栈。
7. **迭代写法**：栈里存 `(node, mn, mx)` 三元组，效果等价，能规避极深树（$n = 5000$ 链）的栈风险。

## 5. 正确性证明

记 $P(u)$ 为根到 $u$ 的路径（含 $u$），$Anc(u) = P(u) \setminus \{u\}$ 为 $u$ 的祖先集合。

**引理 1（祖先 = 路径前缀）**：节点 $X$ 是 $B$ 的祖先 $\iff$ $X \in Anc(B)$。

**证明**：由定义，$X$ 是 $B$ 的祖先当且仅当 $X$ 在根到 $B$ 的路径上且 $X \ne B$，正是 $P(B)$ 去掉 $B$ 自身。∎

**引理 2（固定 $B$ 的最优祖先）**：设祖先值集合为 $S = \{v.val : v \in Anc(B)\}$，则

$$\max_{a \in S} |a - B.val| = \max\bigl(\max S - B.val,\; B.val - \min S\bigr) \ge 0$$

**证明**：$|a - b| = \max(a - b,\ b - a)$。对 $a \in S$ 取最大：$\max_a (a - b) = \max S - b$（由最大元素达到），$\max_a (b - a) = b - \min S$（由最小元素达到），两者取大即得。取 $a = \max S$ 时该值非负，故整体 $\ge 0$。∎

**引理 3（DFS 不变量）**：设调用 `dfs(u, mn, mx)`。

- 若 $u$ 是根：$mn = mx = root.val$；
- 否则 $mn = \min\{v.val : v \in Anc(u)\}$，$mx = \max\{v.val : v \in Anc(u)\}$。

**证明**：对树做归纳。根调用传入 $(root.val, root.val)$，符合第一条。设对 $u$ 成立，则两个孩子 $v$ 收到的参数为

$$mn_v = \min(mn_u,\ u.val), \qquad mx_v = \max(mx_u,\ u.val)$$

而 $Anc(v) = Anc(u) \cup \{u\}$（$u$ 是 $v$ 的父节点，路径上 $v$ 之前恰是 $u$ 与 $u$ 的祖先），故 $mn_v$、$mx_v$ 恰为 $Anc(v)$ 上值的最小/最大值，符合第二条。（$u$ 为根时 $Anc(v) = \{root\}$，同样成立。）∎

**定理**：算法返回值为所有「祖先-后代」对的 $|A.val - B.val|$ 最大值。

**证明**：DFS 访问每个节点一次。
- 对非根节点 $u$：由引理 3，进入时 $mn, mx$ 恰为 $Anc(u)$ 上的极值，算法计算 $\max(mx - u.val,\ u.val - mn)$，由引理 2 等于 $\max_{X \in Anc(u)} |X.val - u.val|$，即 $u$ 作为后代时的最优值。
- 对根节点：候选为 $\max(root.val - root.val, root.val - root.val) = 0$，而根没有祖先，不产生任何合法对，贡献 0 正确（且其它候选值都 $\ge 0$，不会抬高答案）。

答案取所有节点候选的最大值，即所有合法对的最大差值；题面保证 $n \ge 2$，故至少存在一个非根节点，答案即为所求。∎

## 6. 复杂度分析

- **时间**：$O(n)$，每个节点访问一次，$O(1)$ 计算。
- **空间**：$O(h)$ 递归栈，$h$ 为树高；最坏 $O(n)$（链），平均 $O(\log n)$。
- **对比**：暴力 $O(nh)$，链状树退化到 $O(n^2)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maxAncestorDiff(TreeNode* root) {
        int ans = 0;
        dfs(root, root->val, root->val, ans);
        return ans;
    }

private:
    void dfs(TreeNode* u, int mn, int mx, int& ans) {
        if (u == nullptr) return;
        // 用父路径上的极值结算，保证祖先与后代不是同一节点
        ans = max(ans, max(mx - u->val, u->val - mn));
        int nmn = min(mn, u->val);
        int nmx = max(mx, u->val);
        dfs(u->left, nmn, nmx, ans);
        dfs(u->right, nmn, nmx, ans);
    }
};
```

### Python

```python
class Solution:
    def maxAncestorDiff(self, root) -> int:
        ans = 0

        def dfs(u, mn: int, mx: int) -> None:
            nonlocal ans
            if u is None:
                return
            ans = max(ans, mx - u.val, u.val - mn)   # 用父路径极值结算
            nmn, nmx = min(mn, u.val), max(mx, u.val)
            dfs(u.left, nmn, nmx)
            dfs(u.right, nmn, nmx)

        dfs(root, root.val, root.val)
        return ans
```

## 8. 边界情况与易错点

1. **两个节点**：`[1,2]` → `|1-2| = 1`；`[5,5]` → 0。递归与初始化都要覆盖只有根 + 一个孩子的情形。
2. **链状树**：深度可达 5000，C++ 递归栈通常够（每帧很小），但 Python 默认递归上限 1000，必须 `sys.setrecursionlimit` 或改迭代。
3. **必须包含子树两侧**：根到叶路径可能经过左孩子并一路深入，容易只处理一条链；DFS 要同时递归左右。
4. **祖先不能是自己**：若先更新 $mn, mx$ 再结算，会把自身算入，但因为自差为 0 且差值非负，结果不会被抬高——不过语义上仍建议先结算。
5. **负差**：$mx - u.val$ 可能为负（当 $u$ 是路径最大值），但另一项 $u.val - mn \ge 0$，取 max 后天然非负；不要对单项取绝对值。
6. **值域**：$0 \le val \le 10^5$，`int` 足够；`ans` 初值 0 正确（差值非负）。
7. **空树**：题面保证 $n \ge 2$，若要防御，可在入口判空返回 0。
