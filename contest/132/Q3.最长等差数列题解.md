# LeetCode 最长等差数列 题解

## 1. 题目概述

- **标题 / 题号**：最长等差数列（#1027，medium）
- **链接**：https://leetcode.cn/problems/longest-arithmetic-subsequence/
- **来源**：LeetCode 第 132 场周赛 Q3
- **难度**：中等
- **标签**：数组、动态规划、哈希表

**题意**：给定整数数组 `nums`，返回其中最长的**等差子序列**长度。

- **子序列**：从原数组删去若干元素（也可不删）后保持相对顺序得到的序列；
- **等差**：存在 $d$，使序列中相邻两项之差恒为 $d$。

**约束**：

- $2 \le nums.length \le 1500$
- $0 \le nums[i] \le 500$

> 💡 值域很小（$\le 500$），所以公差 $d \in [-500, 500]$ 只有 $1001$ 种取值——这为「把公差放进 DP 状态」提供了空间上的可行性。

## 2. 示例

**示例 1**

```text
输入：nums = [3,6,9,12]
输出：4
解释：整个数组公差为 3，最长等差子序列就是它本身。
```

**示例 2**

```text
输入：nums = [9,4,7,2,10]
输出：3
解释：最长的是 [4,7,10]（下标 1、2、4），公差 3。
```

**示例 3**

```text
输入：nums = [20,1,15,3,10,5,8]
输出：4
解释：最长的是 [20,15,10,5]（下标 0、2、4、5），公差 -5。
```

## 3. 解题思路

### 3.1 暴力思路

- 枚举所有子序列（$2^n$ 个）判断等差：$n = 1500$，完全不可行。
- 枚举前两项 $(i, j)$ 确定公差 $d$，再在 $j$ 之后贪心找 $nums[k] = nums[j] + d$：最坏 $O(n^3)$，$1500^3 \approx 3.4 \times 10^9$，超时。

注意到第二条思路里「往后找下一个值」是重复劳动——同一个「以 $j$ 结尾、公差 $d$」的状态会被多次查询，应该**把它缓存下来**，这正指向 DP。

### 3.2 核心观察：以「末项 + 公差」为状态

![状态设计：dp[i][d] = 以 i 结尾、公差 d 的最长长度](images/wc132_q3_state_design.svg)

定义

$$dp[i][d] = \text{「以 } nums[i] \text{ 结尾、公差为 } d \text{ 的等差子序列」的最大长度}$$

关键性质：**等差子序列去掉末项仍是等差子序列，且公差不变**。于是

$$dp[i][d] = \max_{j < i,\ nums[i] - nums[j] = d} \bigl(dp[j][d] + 1\bigr)$$

其中 $dp[j][d] = 0$（表示不存在这样的序列）时，退化为「只有 $nums[j], nums[i]$ 两项」，长度为 2。

为什么要对同一个 $d$ 取所有 $j$ 的 $\max$？因为 $nums$ 可能有**重复值**：不同的 $j$ 会给出相同的 $d$，此时应取最长的那条链。

> 💡 这正是「**最长路径型 DP**」：状态是「末项下标 + 公差」，转移是「接在前一个符合公差的末项后面」。与最长递增子序列（LIS）的 $O(n^2)$ DP 是同一个骨架，只是状态多了一维公差。

由于 $nums[i] \in [0, 500]$，公差 $d = nums[i] - nums[j] \in [-500, 500]$，可以用长度 $1001$ 的数组存，下标为 $d + 500$。这样转移是 $O(1)$ 的数组访问，比哈希表更快。

### 3.3 算法流程

![算法流程：双重循环 + 公差偏移的二维表](images/wc132_q3_algorithm_flow.svg)

```text
1. n = len(nums)，ans = 2（任意两项都是公差为二者之差的等差子序列）
2. dp = n × 1001 的 0 表            # dp[i][d + 500]
3. for i = 0 .. n-1:
       for j = 0 .. i-1:
           d = nums[i] - nums[j] + 500
           len = (dp[j][d] == 0) ? 2 : dp[j][d] + 1
           dp[i][d] = max(dp[i][d], len)
           ans = max(ans, dp[i][d])
4. 返回 ans
```

### 3.4 示例演算

![示例演算：nums = [9,4,7,2,10] 的 DP 表](images/wc132_q3_walkthrough.svg)

以 `nums = [9,4,7,2,10]` 为例，记录若干关键状态（$d$ 为真实公差）：

| $i$ | $nums[i]$ | 考察的 $j$ | $d$ | 转移 | $dp[i][d]$ |
|---|---|---|---|---|---|
| 1 | 4 | 0（值 9） | −5 | 无 $dp[0][-5]$ → 2 | 2 |
| 2 | 7 | 0（值 9） | −2 | 无 → 2 | 2 |
| 2 | 7 | 1（值 4） | 3 | 无 $dp[1][3]$ → 2 | 2 |
| 3 | 2 | 1（值 4） | −2 | 无 → 2 | 2 |
| 4 | 10 | 1（值 4） | 6 | 无 → 2 | 2 |
| 4 | 10 | 2（值 7） | 3 | $dp[2][3] = 2$ → 3 | **3** |

最终答案 $3$，对应 $[4, 7, 10]$ ✓。示例 3 的 `[20,1,15,3,10,5,8]` 会走出 $dp[\cdot][-5]$ 的链 $20 \to 15 \to 10 \to 5$，长度 4。

## 4. 算法细节

1. **公差偏移**：$d + 500 \in [0, 1000]$，数组宽度 1001。C++ 用 `vector<vector<int>>(n, vector<int>(1001, 0))`。
2. **0 的含义**：`dp[i][d] = 0` 表示「不存在以 $i$ 结尾、公差 $d$ 的等差子序列」，转移时按长度 2 起算；不能用 1 当哨兵（会和「单元素序列」混淆）。
3. **重复值必须取 max**：`nums = [1,1,1]` 时 $d = 0$，多个 $j$ 给出同一个 $d$，应得到长度 3；用 `max` 累积才能正确。
4. **答案初值 2**：$n \ge 2$，任意两项都构成公差非零或零的等差子序列。
5. **`ans` 的更新位置**：在 `dp[i][d]` 更新后立即更新，避免漏掉最后一次转移。
6. **空间权衡**：$O(n \cdot 1001)$ 约 $1.5 \times 10^6$ 个 `int`（6 MB），可接受；若值域很大（如 $10^9$），改用 `vector<unordered_map<int,int>>`，空间 $O(n^2)$ 期望、时间 $O(n^2)$ 期望。
7. **哈希表与数组的取舍**：本题值域小，数组的常数更小；若 $nums[i]$ 可达 $10^9$，数组开不下，只能哈希。

## 5. 正确性证明

**引理 1（子结构）**：若 $S = (a_1, \dots, a_k)$ 是公差为 $d$ 的等差子序列，则 $(a_1, \dots, a_{k-1})$ 也是公差为 $d$ 的等差子序列。

**证明**：去掉末项后相邻差仍全为 $d$，且子序列性质（相对顺序）保持。∎

**引理 2（转移完备）**：设 $L$ 为以 $nums[i]$ 结尾、公差 $d$ 的最长等差子序列长度。
- 若 $L \ge 2$，则存在 $j < i$ 使 $nums[i] - nums[j] = d$，且 $L = 1 + \max\{dp[j][d] : j < i,\ nums[j] = nums[i] - d\}$（其中 $dp[j][d] = 0$ 视为长度 1 的前缀不存在，此时 $L = 2$）。
- 若 $L$ 不存在，则对一切 $j < i$ 都有 $nums[j] \ne nums[i] - d$。

**证明**：设 $S$ 是达到 $L$ 的最长序列，其倒数第二项必是某个 $nums[j]$（$j < i$），且 $nums[j] = nums[i] - d$。由引理 1，$S$ 的前 $L-1$ 项是以 $j$ 结尾、公差 $d$ 的等差子序列，故 $dp[j][d] \ge L - 1$，即 $L \le dp[j][d] + 1 \le$ 右端；反之任取 $j$ 使 $nums[j] = nums[i] - d$，把 $nums[i]$ 接在「以 $j$ 结尾、公差 $d$ 的最长序列」后面就得到长度 $dp[j][d] + 1 \ge 2$ 的合法序列，故右端 $\le L$。两边相等。若不存在这样的 $j$，则任何以 $nums[i]$ 结尾、公差 $d$ 的序列至少要有两项而第二项必须满足该等式，矛盾，$L$ 不存在。∎

**引理 3（DP 正确性）**：算法计算的 $dp[i][d]$ 恰为「以 $nums[i]$ 结尾、公差 $d$ 的最长等差子序列长度」（不存在时为 0）。

**证明**：对 $i$ 归纳。$i = 0$ 时任何长度 $\ge 2$ 的序列都不可能以唯一元素结尾，$dp = 0$ 正确。设所有 $j < i$ 正确，则算法枚举全部 $j < i$，对 $d = nums[i] - nums[j]$ 用 $dp[j][d] + 1$（或 2）更新 $dp[i][d]$，由引理 2 这正是最优值，且只写入「$nums[i] - nums[j] = d$」对应的槽位，不会写错公差。∎

**定理**：算法返回最长等差子序列的长度。

**证明**：任意等差子序列都有末项 $nums[i]$ 与公差 $d$，其长度 $\le dp[i][d]$（引理 3），故全局最优 $\le \max_{i,d} dp[i][d]$；反之每个 $dp[i][d]$ 都对应一条真实的等差子序列，故 $\max_{i,d} dp[i][d]$ 是可达的长度。算法取该最大值（初值 2 覆盖 $n \ge 2$ 时至少存在长度 2 的序列），结果正确。∎

## 6. 复杂度分析

- **时间**：$O(n^2)$，双重循环共 $\frac{n(n-1)}{2}$ 次转移，每次 $O(1)$；$n = 1500$ 时约 $1.1 \times 10^6$ 次，非常快。
- **空间**：$O(n \cdot V)$，$V = 1001$ 为公差种类数，约 6 MB；若改用哈希表为 $O(n^2)$ 期望。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int longestArithSeqLength(vector<int>& nums) {
        int n = (int)nums.size();
        const int OFF = 500, W = 1001;          // 公差 d ∈ [-500,500] → 下标 d+500
        vector<vector<int>> dp(n, vector<int>(W, 0));
        int ans = 2;                            // 任意两项都是等差子序列

        for (int i = 0; i < n; i++) {
            for (int j = 0; j < i; j++) {
                int d = nums[i] - nums[j] + OFF;
                int len = (dp[j][d] == 0) ? 2 : dp[j][d] + 1;
                if (len > dp[i][d]) dp[i][d] = len;
                if (dp[i][d] > ans) ans = dp[i][d];
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def longestArithSeqLength(self, nums: list[int]) -> int:
        n = len(nums)
        OFF, W = 500, 1001                     # 公差 d ∈ [-500,500] → 下标 d+500
        dp = [[0] * W for _ in range(n)]
        ans = 2                                # 任意两项都是等差子序列

        for i in range(n):
            for j in range(i):
                d = nums[i] - nums[j] + OFF
                length = 2 if dp[j][d] == 0 else dp[j][d] + 1
                if length > dp[i][d]:
                    dp[i][d] = length
                if dp[i][d] > ans:
                    ans = dp[i][d]
        return ans
```

## 8. 边界情况与易错点

1. **$n = 2$**：答案恒为 2，初值 `ans = 2` 已覆盖；循环也能算出 2。
2. **全部相同**：`[7,7,7]`，公差 0，答案 3。此时多个 $j$ 给出同一个 $d$，必须用 `max` 累积，不能直接覆盖。
3. **负公差**：`[20,15,10,5]` 公差不 −5，偏移 500 后为 495，不会越界；若忘记偏移会用负下标越界。
4. **`dp` 的 0 与 2 的语义**：`0` 表示不存在，`≥ 2` 表示真实长度；不要用 `1` 做初始化，否则长度为 2 的情况会被误判成 1。
5. **`ans` 更新遗漏**：只在循环结束后取 `max` 也行，但要在 `dp` 更新后立刻更新 `ans`，避免忘记最后一行。
6. **公差范围**：若把约束误认为 $nums[i] \le 10^9$，就必须用哈希表；本题值域 $\le 500$ 才允许开数组。
7. **子序列 ≠ 子数组**：不要求连续，所以转移可以跨过任意中间元素。
