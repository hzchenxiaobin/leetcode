# LeetCode 从先序遍历还原二叉树 题解

## 1. 题目概述

- **标题 / 题号**：从先序遍历还原二叉树（#1028，hard）
- **链接**：https://leetcode.cn/problems/recover-a-tree-from-preorder-traversal/
- **来源**：LeetCode 第 132 场周赛 Q4
- **难度**：困难
- **标签**：树、深度优先搜索、字符串、二叉树

**题意**：对一棵二叉树做 DFS 先序遍历，每个节点输出「$D$ 个短划线 + 该节点的值」，其中 $D$ 是节点的深度（根深度为 0，子节点深度为父节点深度加 1）。给定这样的字符串 $S$，还原出原来的树并返回根节点。

题面额外保证：**若某节点只有一个子节点，则该子节点一定是左孩子**。

**约束**：

- 原始树的节点数在 $[1, 1000]$ 内
- 每个节点的值在 $[1, 10^9]$ 内

> 💡 这个字符串同时编码了两件事：**节点的值**与**节点的深度**。先序 + 深度信息足以唯一确定树形，不需要中序。

## 2. 示例

**示例 1**

```text
输入："1-2--3--4-5--6--7"
输出：[1,2,5,3,4,6,7]
解释：根 1；1 的孩子是 2、5；2 的孩子是 3、4；5 的孩子是 6、7。
```

**示例 2**

```text
输入："1-2--3---4-5--6---7"
输出：[1,2,5,3,null,6,null,4,null,7]
解释：一条「一路向左」的链：1→2→3→4，以及 5→6→7。
```

**示例 3**

```text
输入："1-401--349---90--88"
输出：[1,401,null,349,88,90]
解释：值可以是多位数（401、349、90、88），解析时不能只取一位。
      401 只有左孩子 349（349 的孩子是 90），另有左孩子 88。
```

## 3. 解题思路

### 3.1 暴力思路

暴力做法是「枚举所有可能的切分」：把字符串解析成 $(depth, value)$ 序列后，尝试各种递归分割方式（每个位置都可能成为子树起点），检查能否拼成一棵合法的树。

序列长度为 $n$ 时，可能的分割方式是指数级的；而且大多数尝试会在中途失败。$n \le 1000$ 时完全不可行。

另一种想法是「按深度数值定位父节点」：深度 $d$ 的节点，父节点是深度 $d-1$ 的**最近一个**节点。这个观察是对的，但需要高效地维护「最近的深度 $d-1$ 节点」——这正是栈的作用。

### 3.2 核心观察：栈 = 当前先序路径

![解析：破折号数量就是深度](images/wc132_q4_parse_concept.svg)

**观察一**：先序遍历中，**父节点一定出现在它的所有后代之前**；并且深度 $d$ 的节点的父节点，是序列中它之前**最后一个深度为 $d-1$ 的节点**。

**证明直觉**：先序遍历在进入子树前先访问父节点；一旦离开子树（深度回退），再也不会回到同一棵子树。因此「深度 $\le d-1$ 的最近节点」就是当前路径上的祖先，其中深度最大者（$d-1$）就是父节点。

**观察二**：用一个栈保存**当前路径**（从根到「上一个被访问节点」）。处理新节点（深度 $d$）时：

1. 把栈弹出到大小恰为 $d$——栈中剩下的正是深度 $0, 1, \dots, d-1$ 的祖先；
2. 栈顶就是父节点；
3. 新节点入栈，成为当前路径末端。

**观察三（左右孩子）**：父节点 $p$ 的左孩子若为空，新节点就是左孩子；否则是右孩子。为什么？因为每个节点最多一个左孩子，若 $p.left$ 已存在，新节点不可能是左孩子，只能是右孩子；反之若 $p.left$ 为空而新节点是右孩子，就出现「只有右孩子」的情形，与题面保证矛盾。所以规则唯一确定。

> 💡 栈的大小恰好等于「当前深度」，这是整个算法最漂亮的地方：`while (st.size() > depth) st.pop_back();` 一条语句同时完成了「回溯到正确的父节点」。

### 3.3 算法流程

![算法流程：解析 → 弹栈到 depth → 挂到父节点](images/wc132_q4_flow.svg)

```text
1. st = []（栈），root = null，i = 0
2. while i < len(S):
       depth = 0
       while S[i] == '-':  depth += 1; i += 1
       val = 0
       while i < len(S) 且 S[i] 是数字:  val = val*10 + S[i]-'0'; i += 1
       while len(st) > depth:  st.pop()
       node = new TreeNode(val)
       若 st 为空:  root = node
       否则:
           p = st[-1]
           若 p.left 为空:  p.left = node
           否则:            p.right = node        # 题面保证不会出现「只有右孩子」
       st.push(node)
3. 返回 root
```

### 3.4 示例演算

![示例演算：\"1-2--3--4-5--6--7\" 的栈变化](images/wc132_q4_walkthrough.svg)

对 `"1-2--3--4-5--6--7"`，解析得到 $(0,1),(1,2),(2,3),(2,4),(1,5),(2,6),(2,7)$：

| 步 | $(d, v)$ | 弹栈 | 栈（自底向顶） | 挂接动作 |
|---|---|---|---|---|
| 1 | (0, 1) | — | [1] | 根 = 1 |
| 2 | (1, 2) | — | [1, 2] | 1 的左孩子 = 2 |
| 3 | (2, 3) | — | [1, 2, 3] | 2 的左孩子 = 3 |
| 4 | (2, 4) | 弹 3 | [1, 2, 4] | 2 的左孩子已占 → 右孩子 = 4 |
| 5 | (1, 5) | 弹 4、2 | [1, 5] | 1 的左孩子已占 → 右孩子 = 5 |
| 6 | (2, 6) | — | [1, 5, 6] | 5 的左孩子 = 6 |
| 7 | (2, 7) | 弹 6 | [1, 5, 7] | 5 的左孩子已占 → 右孩子 = 7 |

得到的树：1 的孩子 2、5；2 的孩子 3、4；5 的孩子 6、7，层序为 `[1,2,5,3,4,6,7]` ✓。

## 4. 算法细节

1. **解析多位数**：值可达 $10^9$，必须用循环累加 `val = val * 10 + digit`，不能用单字符转换。
2. **破折号计数即深度**：连续 `-` 的个数就是深度，因为每层恰好一个短划线。
3. **弹栈到 `size == depth`**：用 `while (st.size() > depth) st.pop_back();`。注意是 `>`（不是 `>=`），因为父节点要留在栈顶。
4. **左右孩子的判定**：`p->left == nullptr ? left : right`。题面保证「只有一个孩子时是左孩子」，所以不会出现「左空右有」的输入，规则无歧义。
5. **栈里存指针**：直接存 `TreeNode*`，弹栈不影响已建好的树。
6. **不用递归**：深度可达 1000，Python 递归上限 1000 恰好卡边界；迭代解析更安全。
7. **值域**：$10^9 < 2^{31}-1$，`int` 足够。
8. **字符串末尾**：循环条件 `i < n`，最后一组数字解析完后自然结束。

## 5. 正确性证明

设原树为 $T$，解析出的序列为 $(d_1, v_1), \dots, (d_n, v_n)$，其中 $(d_k, v_k)$ 是先序第 $k$ 个节点的深度与值。设 $p(k)$ 为第 $k$ 个节点的父节点编号（根无父节点），$a(k) = d_k$。

**引理 1（序列性质）**：$d_1 = 0$；对 $k \ge 2$，$d_k \le d_{k-1} + 1$；且第 $k$ 个节点的父节点是满足 $j < k$、$d_j = d_k - 1$ 的**最大** $j$。

**证明**：先序遍历先访问父再访问子，故父节点的下标严格小于子节点，且访问一个节点后下一步要么进入左孩子（深度 +1），要么回溯到某个祖先再进入其右孩子（深度不增），所以 $d_k \le d_{k-1} + 1$。

下面证明「最近前驱即父节点」。设 $d_k = d$，$j$ 是 $k$ 之前最后一个深度为 $d-1$ 的节点，$m$ 是 $k$ 在深度 $d-1$ 上的祖先（路径上唯一）。显然 $m$ 的下标 $< k$ 且深度为 $d-1$，故 $m$ 的下标 $\le j$。

若 $m \ne j$，即 $m$ 的下标 $< j < k$：访问完 $j$ 之后、访问 $k$ 之前，DFS 必须从深度 $d-1$ 下到深度 $d$（$k$ 的深度为 $d$）。若此时仍在 $j$ 的子树内，则路径要经过 $j$，即 $j$ 是 $k$ 在深度 $d-1$ 上的祖先，$j = m$，矛盾；若已经离开 $j$ 的子树，则重新下潜时必须再访问一个深度为 $d-1$ 的节点，它在 $j$ 之后、$k$ 之前，与 $j$ 的「最后一个」矛盾。故 $j = m$，即父节点就是最近前驱。∎

**引理 2（栈不变量）**：处理第 $k$ 个节点之前，栈中自底向顶恰为 $(d_k$ 之前的路径$)$，即「第 $k-1$ 个节点的祖先链 + 第 $k-1$ 个节点本身」；特别地，弹栈到大小 $d_k$ 后，栈顶是第 $k$ 个节点的父节点。

**证明**：对 $k$ 归纳。$k = 1$ 时栈空、$d_1 = 0$，弹栈后仍为空，根节点无父节点 ✓。设处理完第 $k-1$ 个节点后，栈为路径 $P_{k-1}$（深度 $0..d_{k-1}$）。由引理 1，第 $k$ 个节点的父节点是路径上深度 $d_k - 1$ 的节点，而路径上深度 $> d_k - 1$ 的节点都在父节点之后、不属于 $k$ 的祖先链，应被弹出。弹栈到大小 $d_k$ 后，栈中留下深度 $0..d_k-1$ 的节点，恰为 $k$ 的祖先链，栈顶即父节点 ✓。随后把 $k$ 入栈，栈变为 $P_k$ ✓。∎

**引理 3（孩子分配正确）**：设第 $k$ 个节点挂在父节点 $p$ 上。若 $p.left$ 为空则 $k$ 是 $p$ 的左孩子，否则是 $p$ 的右孩子。

**证明**：$k$ 必是 $p$ 的某个孩子（引理 2）。每个节点至多一个左孩子。若 $p.left$ 已非空，则 $k$ 不可能是左孩子，只能是右孩子。若 $p.left$ 为空而 $k$ 是右孩子，则 $p$ 只有右孩子，与题面保证「只有一个子节点时必为左孩子」矛盾。故 $k$ 是左孩子。∎

**定理**：算法重建的树与 $T$ 在结构和节点值上完全相同。

**证明**：由引理 2，算法为每个节点挂接的父节点与原树一致；由引理 3，挂接为左/右孩子也与原树一致；节点值由解析唯一确定。故按先序归纳可知两棵树的每个节点一一对应（值相同、父子关系相同、左右方向相同），即结构同构且值相等。∎

## 6. 复杂度分析

- **时间**：$O(n)$（$n$ 为字符串长度，与节点数同阶）。每个字符被扫描常数次；每个节点入栈、出栈各一次。
- **空间**：$O(h)$ 栈空间（$h$ 为树高，最坏 $O(n)$），加上建树本身的 $O(n)$ 节点空间。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    TreeNode* recoverFromPreorder(string traversal) {
        vector<TreeNode*> st;                  // st.size() == 当前路径深度
        TreeNode* root = nullptr;
        int i = 0, n = (int)traversal.size();

        while (i < n) {
            int depth = 0;
            while (i < n && traversal[i] == '-') { depth++; i++; }   // 破折号个数 = 深度
            int val = 0;
            while (i < n && traversal[i] >= '0' && traversal[i] <= '9') {
                val = val * 10 + (traversal[i] - '0');              // 值可能是多位数
                i++;
            }
            while ((int)st.size() > depth) st.pop_back();           // 回溯到父节点
            TreeNode* node = new TreeNode(val);
            if (st.empty()) {
                root = node;
            } else {
                TreeNode* p = st.back();
                if (p->left == nullptr) p->left = node;
                else p->right = node;                               // 题面保证不会出现「只有右孩子」
            }
            st.push_back(node);
        }
        return root;
    }
};
```

### Python

```python
class Solution:
    def recoverFromPreorder(self, traversal: str) -> TreeNode:
        st = []                                 # st.size() == 当前路径深度
        root = None
        i, n = 0, len(traversal)

        while i < n:
            depth = 0
            while i < n and traversal[i] == "-":
                depth += 1
                i += 1
            val = 0
            while i < n and traversal[i].isdigit():
                val = val * 10 + ord(traversal[i]) - ord("0")
                i += 1
            while len(st) > depth:
                st.pop()                        # 回溯到父节点
            node = TreeNode(val)
            if not st:
                root = node
            else:
                p = st[-1]
                if p.left is None:
                    p.left = node
                else:
                    p.right = node              # 题面保证不会出现「只有右孩子」
            st.append(node)
        return root
```

## 8. 边界情况与易错点

1. **单节点**：`"1"`，没有破折号，栈空 → 根 = 1，直接返回。
2. **多位数**：`"1-401--349---90--88"` 里 401、349、90、88 都是多位数，按位累加才行；用 `stoi` 一步读也可以，但要正确找到数字区间。
3. **弹栈条件写错**：必须是 `while (st.size() > depth)`；写成 `>=` 会把父节点也弹掉，挂接就无处可挂。
4. **左右孩子顺序**：必须「先左后右」，因为题面保证只有左孩子的单孩子情形；若反过来写，示例 2 的链会建到右边。
5. **`TreeNode` 的内存**：LeetCode 会负责释放；本地测试时注意不要重复 `new` 同一节点。
6. **递归爆栈**：不要用递归分治（深度 1000 链），迭代解析更稳。
7. **深度跳跃**：合法输入中 $d_k \le d_{k-1}+1$；若数据不合法（如 `"1---2"`），弹栈后可能栈顶不是真正的父节点，本题不需要处理。
8. **值域**：$10^9$ 用 `int` 安全；若值域到 $10^{18}$ 需换 `long long`。
