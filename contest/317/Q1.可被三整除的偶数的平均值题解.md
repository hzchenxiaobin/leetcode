# LeetCode 可被三整除的偶数的平均值 题解

## 1. 题目概述

- **标题 / 题号**：可被三整除的偶数的平均值（#2455，easy）
- **链接**：https://leetcode.cn/problems/average-value-of-even-numbers-that-are-divisible-by-three/
- **来源**：LeetCode 第 317 场周赛 Q1
- **难度**：简单
- **标签**：数组、数学

**题意**：给定一个由**正整数**组成的整数数组 `nums`，返回其中**可被 $3$ 整除的所有偶数**的平均值。$n$ 个元素的平均值等于**求和再除以 $n$**，结果**向下取整**；不存在满足条件的整数时返回 $0$。

**约束**：

- $1 \le \text{nums.length} \le 1000$
- $1 \le \text{nums}[i] \le 1000$

> 💡 本题在本仓库另有[每日题解 2455](../../solution/2401-2500/2455_可被三整除的偶数的平均值.md)：侧重 $\gcd/\text{lcm}$ **方法论**（互素折叠的推广与不互素反例）与面试问答。本篇按**周赛复盘视角**展开，侧重签到题的**最短提交路径**（读题 → 折叠条件 → 一趟遍历）与**两处易错点**（空集除零、向下取整），两篇互为印证。

## 2. 示例

**示例 1**

```text
输入：nums = [1,3,6,10,12,15]
输出：9
解释：6 和 12 是可以被 3 整除的偶数。(6 + 12) / 2 = 9。
```

**示例 2**

```text
输入：nums = [1,2,4,7,10]
输出：0
解释：不存在满足题目要求的整数，所以返回 0。
```

**示例 3**（自构造，覆盖"平均值非整数"的取整分支）

```text
输入：nums = [6,12,18,30]
输出：16
解释：四个数全部命中，sum = 66，66 / 4 = 16.5，向下取整得 16。
```

## 3. 解题思路

### 3.1 暴力思路：双条件逐一筛选（就是最优）

最直白的做法：一趟遍历，对每个 $x$ 检查「是偶数」**且**「被 $3$ 整除」，命中则累入 `sum` 与 `cnt`，最后 `cnt == 0` 返回 $0$，否则返回 `sum / cnt`：

```text
sum, cnt = 0, 0
for x in nums:
    if x % 2 == 0 and x % 3 == 0:
        sum += x; cnt += 1
return 0 if cnt == 0 else sum // cnt
```

时间 $O(n)$、空间 $O(1)$，**暴力与最优完全同阶**——本题没有任何可优化的复杂度维度。签到题的复盘价值不在"怎么优化"，而在两件事：

1. **最短路径**：从读题到提交控制在一分钟内，把时间留给后面的 Q3/Q4；
2. **不翻车**：本题能 WA 的点只有「空集除零」「且写成或」「取整方式」三处，见 §8。

### 3.2 核心观察：两个条件折叠为一个 `x % 6 == 0`

![核心观察：偶数 ∩ 被 3 整除 ⇔ 被 6 整除](images/2455_mod6_number_line_concept.svg)

读题时的第一个手速优化：**「偶数且被 $3$ 整除」$\iff$「被 $6$ 整除」**。因为 $2$ 与 $3$ 互素，$\text{lcm}(2, 3) = 6$，两次取模判定折叠成一次 `x % 6 == 0`。

在 $1 \sim 15$ 的数轴上直观可见：蓝色圆点（偶数）与橙色 $\wedge$（$3$ 的倍数）**同时**落下的格子只有 $6$ 和 $12$——恰是 $6$ 的倍数。

> ⚠️ 折叠的收益只是**每元素的判定常数减半**（两次取模 → 一次），不改变 $O(n)$ 的本质。$n \le 1000$ 下随手写双条件也能瞬 AC，但「互素条件可折叠」的识别习惯值得沉淀：条件更密、数据更大时它才变成实质优化。

### 3.3 算法流程：一趟过滤 + 整除兜底

两阶段流水：

1. **过滤累加**：一趟遍历，对每个 $x$ 判 `x % 6 == 0`，命中则 `sum += x`、`cnt += 1`；
2. **取整兜底**：遍历结束判 `cnt`：为 $0$ 返回 $0$（对应"不存在满足条件的整数"），否则返回 `sum / cnt`（整型除法天然向下取整）。

整个过程单趟、无序、无数据结构，$O(n)$ 时间、$O(1)$ 空间。

### 3.4 示例演算

![示例演算：过滤表与结果分支](images/2455_mod6_filter_walkthrough.svg)

**示例 1** `nums = [1,3,6,10,12,15]`：

| $x$ | $x \bmod 6$ | 命中 | `sum` | `cnt` |
|-----|-------------|------|-------|-------|
| 1 | 1 | ✗ | 0 | 0 |
| 3 | 3 | ✗ | 0 | 0 |
| 6 | 0 | ✓ | 6 | 1 |
| 10 | 4 | ✗ | 6 | 1 |
| 12 | 0 | ✓ | 18 | 2 |
| 15 | 3 | ✗ | 18 | 2 |

遍历结束 `cnt = 2 ≠ 0`，$\text{ans} = 18 / 2 = 9$ ✓。

**示例 2** `nums = [1,2,4,7,10]`：$x \bmod 6$ 依次为 $1, 2, 4, 1, 4$，无 $0$，`cnt = 0`，走兜底分支返回 $0$ ✓。

**示例 3** `nums = [6,12,18,30]`：全部命中，`sum = 66`、`cnt = 4`，$66 / 4 = 16.5$ 向下取整得 $16$ ✓——三个示例恰好覆盖「部分命中」「零命中」「取整生效」三条分支。

## 4. 算法细节

1. **条件折叠**：`x % 6 == 0` 一次取模同时表达「偶数」与「被 $3$ 整除」（$2$、$3$ 互素，$\text{lcm}(2,3) = 6$）。
2. **向下取整**：正整数域上 C++ 整型除法（向零截断）与 Python `//`（向负无穷）**都等价于向下取整**，直接 `/`、`//` 即可，无需任何取整函数。
3. **空集兜底**：`cnt == 0` 时必须返回 $0$——直接相除在 C++ 是未定义行为、在 Python 抛 `ZeroDivisionError`。
4. **值域核算**：`sum ≤ 1000 × 1000 = 10^6`，`cnt ≤ 1000`，`int` 富余三个数量级，无溢出风险。

## 5. 正确性证明

**引理 1**（条件折叠）：正整数 $x$ 是偶数且被 $3$ 整除 $\iff$ $x$ 被 $6$ 整除。

**证明**：
-（$\Rightarrow$）$2 \mid x$ 且 $3 \mid x$。从质因数分解看，$x$ 的因子中含至少一个 $2$ 与至少一个 $3$，故 $2 \cdot 3 = 6 \mid x$（一般地，$a \mid x,\ b \mid x,\ \gcd(a,b)=1 \Rightarrow ab \mid x$）。
-（$\Leftarrow$）$6 \mid x$，而 $2 \mid 6$、$3 \mid 6$，由整除的传递性得 $2 \mid x$ 且 $3 \mid x$。∎

**引理 2**（取整）：正整数域上，`sum / cnt`（C++ 整型除法）与 `sum // cnt`（Python）均等于 $\lfloor \text{sum} / \text{cnt} \rfloor$。

**证明**：C++ 整型除法向零截断，Python `//` 向负无穷取整；对非负的被除数与正除数，两者一致，且都等于向下取整。∎

**定理**：算法返回 `nums` 中被 $3$ 整除的所有偶数的向下取整平均值；当且仅当不存在这样的数时返回 $0$。

**证明**：由引理 1，筛选条件 `x % 6 == 0` 恰好选出目标集合 $S$ =「被 $3$ 整除的偶数」，遍历后 `sum` $= \sum_{x \in S} x$、`cnt` $= |S|$。若 $S = \varnothing$，则 `cnt == 0`，算法走兜底分支返回 $0$，与题意"不存在时返回 $0$"一致；否则由引理 2，返回值 `sum / cnt` $= \lfloor \sum S / |S| \rfloor$，恰为题意所求平均值。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。单趟遍历，每个元素一次取模与 $O(1)$ 累加；$n \le 1000$，瞬时完成。
- **空间复杂度**：$O(1)$。仅 `sum`、`cnt` 两个标量变量，无额外数据结构。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int averageValue(vector<int>& nums) {
        int sum = 0, cnt = 0;
        for (int x : nums) {
            if (x % 6 == 0) {
                sum += x;
                ++cnt;
            }
        }
        return cnt ? sum / cnt : 0;
    }
};
```

> 💡 `x % 6 == 0` 一次取模折叠两个判定；正整数域下整型除法天然向下取整；`cnt ? sum / cnt : 0` 三元兜底空集。

### Python

```python
class Solution:
    def averageValue(self, nums: List[int]) -> int:
        s, c = 0, 0
        for x in nums:
            if x % 6 == 0:
                s += x
                c += 1
        return s // c if c else 0
```

> 💡 `//` 对正数即向下取整；`s // c if c else 0` 兜底除零。也可写成两行生成器（`sum(x for x in nums if x % 6 == 0)`），但那是两趟扫描，单趟显式循环更贴合周赛"一次写对"的姿态。

## 8. 边界情况与易错点

1. **空集除零**：`cnt == 0` 时 `sum / cnt` 在 C++ 是未定义行为、在 Python 抛 `ZeroDivisionError`，必须兜底返回 $0$。示例 2 直接覆盖此分支。
2. **「且」写成「或」**：`x % 2 == 0 || x % 3 == 0` 会把 $3$（被 $3$ 整除的奇数）和 $10$（不被 $3$ 整除的偶数）都误收进来。示例 1 的 $3$ 与 $10$ 恰是两个方向的陷阱样本，提交前用示例 1 自测即可拦截。
3. **向下取整 ≠ 四舍五入**：如 $[6,12,18,30]$，平均值 $66/4 = 16.5$，应返回 $16$ 而非 $17$。整型除法天然正确；切勿转浮点再 `round`。
4. **别走浮点路径**：`double` 求平均再强转 `int` 在本题 $10^6$ 量级虽无精度风险，但纯属多余且是坏习惯，整型一步到位。
5. **溢出核算**：$\text{sum} \le 10^6$，`int`（上限约 $2.1 \times 10^9$）富余三个数量级，无需 `long long`。
6. **单命中 / 全命中**：$[6] \to 6$、$[6,12,18] \to 12$，同一套 `sum`/`cnt` 逻辑自然覆盖，无需特判。
