# LeetCode 美丽整数的最小增量 题解

## 1. 题目概述

- **标题 / 题号**：美丽整数的最小增量（#2457，medium）
- **链接**：https://leetcode.cn/problems/minimum-addition-to-make-integer-beautiful/
- **来源**：LeetCode 第 317 场周赛 Q3
- **难度**：中等
- **标签**：贪心、数学、数位、枚举

**题意**：给定正整数 $n$ 与 $target$。若一个整数**各数位之和**小于等于 $target$，称其为**美丽整数**（下记数位和为 $\mathrm{ds}(m)$）。求最小的非负整数 $x$，使 $n + x$ 是美丽整数。等价地：找最小的 $m \ge n$ 使 $\mathrm{ds}(m) \le target$，答案即 $x = m - n$。

**约束**：

- $1 \le n \le 10^{12}$（至多 13 位）
- $1 \le target \le 150$
- 输入保证总有解

> 💡 本题在本仓库另有[每日题解 2457](../../solution/2401-2500/2457_美丽整数的最小增量.md)：侧重「进位降和」的公式推导与面试问答。本篇按**周赛复盘视角**展开，侧重**赛场识别路径**（最小 $x$ → 想二分？位和不单调 → 转构造）、**候选族完备性的引理—定理证明**，以及两大 WA 高发点（**漏判 $x=0$**、**64 位溢出**），两篇互为印证。

输出：4
解释：16 的数位和 1+6=7 > 6；加 4 得 20，数位和 2+0=2 ≤ 6。
```

**示例 2**

```

**示例 3**

输出：0
解释：1 的数位和 1 ≤ 1，已是美丽整数——x = 0 分支。
```

```

## 3. 解题思路

### 3.1 暴力思路：逐格递增——以及为什么二分也不行

最朴素的做法：$x$ 从 $0$ 起逐一试探，首个 $\mathrm{ds}(n+x) \le target$ 即答案。但 $x$ 本身可达 $10^{11}$ 量级：如 $n = 888\,888\,888\,888$（数位和 $96$）、$target = 1$ 时，最优 $m = 10^{12}$，$x = 111\,111\,111\,112$——天文级循环次数，必超时。

> ⚠️ 赛场弯路：看到「最小 $x$」容易条件反射**二分答案**。但位和**不单调**：$19 \to 20 \to 21$ 的位和依次为 $10 \to 2 \to 3$，不存在使判定单调成立的阈值，二分不适用。正确方向是**构造**：直接刻画最优 $m = n + x$ 长什么样，再在 $O(\log n)$ 个候选里挑。

### 3.2 核心观察：进位是唯一「降位和」的手段

![核心观察：无进位加 1 位和只增，进位清零位和骤降](images/beautiful_int_carry_effect.svg)

**事实（进位降和）**：竖式加法每发生一次进位，位和净减 $9$；不发生进位时，加多少位和就涨多少。所以想让 $m$ 的位和变小，**只能靠进位把低位「折」进高位并清零尾部**——最优的 $m$ 必然「尾部挂 0」。

把「尾部挂 0」形式化，得到**上取整候选族**：取 $n$ 在第 $i$ 位以上（含第 $i$ 位）的前缀、给前缀整体 $+1$、把低 $i$ 位全部清零：

$$c_i = \left(\left\lfloor \frac{n}{10^i} \right\rfloor + 1\right) \cdot 10^i, \quad i = 0, 1, 2, \ldots$$

即 $c_i$ 是**严格大于 $n$ 的最小 $10^i$ 倍数**。加上 $n$ 自身（$x = 0$ 的「零候选」），候选总数不超过 14 个。

![候选族：前缀+1 尾部清零，首个可行即最优](images/beautiful_int_candidate_enum.svg)

§5 将严格证明两件事：**最优解必落在 $\{n\} \cup \{c_i\}$ 中**（完备性），且 $c_i$ 随 $i$ **单调不减**——因此从低位往高扫，**首个数位和 $\le target$ 的候选就是答案**。

### 3.3 算法流程

![算法流程：判自身，再从低位到高找首个可行候选](images/beautiful_int_algorithm_flow.svg)

1. 若 $\mathrm{ds}(n) \le target$，返回 $0$（零候选）。
2. 令 $\text{base} = 1$（即 $10^i$）。循环：若 $\mathrm{ds}(\lfloor n/\text{base} \rfloor + 1) \le target$，返回 $(\lfloor n/\text{base} \rfloor + 1) \cdot \text{base} - n$；否则 $\text{base} \gets \text{base} \times 10$。
3. 终止性：$\text{base} > n$ 时 $\lfloor n/\text{base} \rfloor = 0$，候选为 $10^i$、位和为 $1 \le target$（因 $target \ge 1$），循环至多 13 轮。

实现里的判定条件直接用 $\mathrm{ds}(\lfloor n/\text{base} \rfloor + 1)$ 而非 $\mathrm{ds}(c_i)$——候选末尾恰有 $i$ 个 $0$，不贡献位和（**位和捷径**）。

### 3.4 示例演算

![示例演算：n=467, target=6 的候选扫描表](images/beautiful_int_walkthrough.svg)

以示例 2（$n = 467$，$target = 6$）走查（完整表格见上图）：$\mathrm{ds}(467) = 17 > 6$ 进入循环；$i=0$ 候选 $468$ 位和 $18$ ✗；$i=1$ 候选 $470$ 位和 $11$ ✗；$i=2$ 候选 $500$ 位和 $5$ ✓——返回 $500 - 467 = 33$ ✓。

示例 4 则展示进位链的威力：$n = 999\,999\,999\,999$ 时 $c_0 = n + 1 = 10^{12}$，加 $1$ 触发 12 连进位，位和 $108 \to 1$，一步达标。

## 4. 算法细节

1. **候选生成**：$c_i = (\lfloor n/10^i \rfloor + 1) \cdot 10^i$，用变量 `base` 迭代乘 $10$ 即可，无需预解析 $n$ 的十进制串。「前缀 $+1$」自带进位链：$n = 4699$ 时 $c_2 = (46+1) \times 100 = 4700$；$n = 9999$ 时 $c_2 = (99+1) \times 100 = 10000$，进位可把位数顶长一位。
2. **零候选必须先判**：所有 $c_i$ 都**严格大于** $n$，故「$n$ 已美丽、答案为 $0$」这一分支只能单独覆盖。示例 3（$n=1$，$target=1$）若漏判，会被顶到 $c_1 = 10$ 而错误返回 $9$——本题头号 WA 点。
3. **位和捷径**：$\mathrm{ds}(c_i) = \mathrm{ds}(\lfloor n/10^i \rfloor + 1)$，末尾 $i$ 个 $0$ 不参与求和，循环条件里免算大数位和。
4. **首个可行即返回**：由候选单调不减（§5 引理 3），无需收集全部候选取最小；防御性写法（全部枚举取 min）同样正确，复杂度不变。
5. **类型与值域**：$n \le 10^{12}$、最优 $m \le 10^{12}$、$x < 10^{12}$，`base` 至多到 $10^{12}$——C++ 全程 `long long`（中间量 $(\lfloor n/\text{base} \rfloor + 1) \cdot \text{base} \le 10^{12}$，远低于 `long long` 上界 $\approx 9.2 \times 10^{18}$）；Python 天然无溢出。

## 5. 正确性证明

**引理 1**（进位降和公式）：设非负整数 $a, b$ 竖式相加共发生 $c$ 次进位，则 $\mathrm{ds}(a+b) = \mathrm{ds}(a) + \mathrm{ds}(b) - 9c$。

**证明**：按位记 $a_k, b_k \in [0, 9]$（不足位补 $0$），第 $k$ 位收到进位 $t_k$（$t_0 = 0$；本位和 $\le 9 + 9 + 1 = 19$，故 $t_{k+1} \in \{0,1\}$），输出位 $o_k = a_k + b_k + t_k - 10\,t_{k+1}$。对所有 $k$ 求和：

$$\sum_k o_k = \mathrm{ds}(a) + \mathrm{ds}(b) + \sum_{k \ge 0} t_k - 10 \sum_{k \ge 0} t_{k+1} = \mathrm{ds}(a) + \mathrm{ds}(b) - 9c,$$

其中 $c = \sum_{k \ge 1} t_k$ 恰为发生进位的位数（$t_0 = 0$ 使两处进位求和相消）。∎

**引理 2**（候选结构）：$c_i = (\lfloor n/10^i \rfloor + 1) \cdot 10^i$ 是**严格大于** $n$ 的最小 $10^i$ 倍数；其末 $i$ 位均为 $0$，且 $\mathrm{ds}(c_i) = \mathrm{ds}(\lfloor n/10^i \rfloor + 1)$。

**证明**：由 $\lfloor n/10^i \rfloor \cdot 10^i \le n < (\lfloor n/10^i \rfloor + 1) \cdot 10^i$ 得 $c_i > n$；任何大于 $n$ 的 $10^i$ 倍数必不小于 $c_i$（相邻倍数间隔恰为 $10^i$）。又 $c_i \bmod 10^i = 0$，末 $i$ 个 $0$ 对位和无贡献。∎

**引理 3**（候选单调）：$c_0 \le c_1 \le c_2 \le \cdots$；更精确地，$c_{i+1} - c_i = (9 - d_i) \cdot 10^i \ge 0$，其中 $d_i$ 为 $n$ 的第 $i$ 位数字。

**证明**：记 $a_i = \lfloor n/10^i \rfloor$，则 $a_i = 10 a_{i+1} + d_i$ 且 $d_i \in [0, 9]$，于是

$$c_{i+1} - c_i = (10 a_{i+1} + 10 - a_i - 1) \cdot 10^i = (9 - d_i) \cdot 10^i \ge 0. \quad \blacksquare$$

**定理**（候选族完备性）：设 $m^\*$ 为满足 $m \ge n$ 且 $\mathrm{ds}(m) \le target$ 的最小整数（存在性：取足够大的 $10^k \ge n$，位和 $1 \le target$），则 $m^\* = n$，或 $m^\* = c_i$（某个 $i \ge 0$）。

**证明**：$n$ 美丽时显然 $m^\* = n$。下设 $n$ 不美丽，则 $m^\* > n$。将 $m^\*$ 与 $n$ 按十进制逐位对齐（高位不足补 $0$），设 $j$ 为**最高不同位**：高于 $j$ 的位两者完全相同；由 $m^\* > n$ 知第 $j$ 位 $m^\*_j > n_j$，从而 $n_j \le 8$。考察 $c_j = (\lfloor n/10^j \rfloor + 1) \cdot 10^j$：$\lfloor n/10^j \rfloor$ 的末位恰为 $n_j \le 8$，故「$+1$」不向更高位进位，$c_j$ 的各位为「高于 $j$ 的位同 $n$、第 $j$ 位为 $n_j + 1$、低于 $j$ 的位全 $0$」。于是：

1. $c_j > n$（高位相同，第 $j$ 位更大）；
2. $c_j \le m^\*$（逐位比较：高位相同，第 $j$ 位 $n_j + 1 \le m^\*_j$，低位 $0$ 不超过对应位）；
3. $\mathrm{ds}(c_j) = S_{\text{高}} + (n_j + 1) \le S_{\text{高}} + m^\*_j \le \mathrm{ds}(m^\*) \le target$，其中 $S_{\text{高}}$ 为高于 $j$ 的公共位和。

即 $c_j$ 美丽且 $n < c_j \le m^\*$。由 $m^\*$ 的最小性，只能 $c_j = m^\*$。∎

**推论**（算法正确性与终止性）：算法先判 $n$，再按 $i = 0, 1, 2, \ldots$ 依序检查 $c_i$，在**首个**可行处返回 $c_i - n$；返回值恰为所求 $x^\*$，且循环至多 13 轮。

**证明**：若 $n$ 美丽，算法返回 $0 = m^\* - n$ ✓。否则 $m^\* = c_j$（定理），且任何美丽候选 $c \le m^\*$ 必 $c = m^\*$（候选均 $> n$，否则与 $m^\*$ 最小性矛盾）。设算法首个可行下标为 $i'$：由 $j$ 可行知 $i' \le j$，由引理 3 得 $c_{i'} \le c_j = m^\*$；又 $c_{i'}$ 美丽且 $> n$，故 $m^\* \le c_{i'}$，从而 $c_{i'} = m^\*$，返回 $m^\* - n = x^\*$。终止性：$n$ 不美丽时必有 $n < 10^{12}$（$10^{12}$ 的位和为 $1$，必美丽），取 $i = 12$ 有 $\lfloor n/10^{12} \rfloor = 0$、候选 $10^{12}$、位和 $1 \le target$，故循环在 $i \le 12$ 内必停。∎

## 6. 复杂度分析

- **时间复杂度**：$O(D^2)$，$D$ 为位数（$\le 13$）。外层至多 13 轮，每轮位和计算 $O(D)$，合计约 $13 \times 13 \approx 169$ 次基本运算——常数级。
- **空间复杂度**：$O(1)$。仅常数个整型变量，无递归、无额外数据结构。

## 7. 参考代码

### C++

```cpp
class Solution {
    static int digitSum(long long x) {
        int s = 0;
        for (; x > 0; x /= 10) s += x % 10;
        return s;
    }
public:
    long long makeIntegerBeautiful(long long n, int target) {
        if (digitSum(n) <= target) return 0;   // 零候选：n 已美丽
        long long base = 1;                    // base = 10^i
        while (digitSum(n / base + 1) > target)
            base *= 10;
        return (n / base + 1) * base - n;
    }
};
```

> 💡 循环条件直接判 $\mathrm{ds}(\lfloor n/\text{base} \rfloor + 1)$（位和捷径）；全程 `long long`，中间量 $(\lfloor n/\text{base} \rfloor + 1) \cdot \text{base} \le 10^{12}$ 不溢出。

### Python

```python
class Solution:
    def makeIntegerBeautiful(self, n: int, target: int) -> int:
        def dsum(x: int) -> int:
            s = 0
            while x:
                s, x = s + x % 10, x // 10
            return s
        if dsum(n) <= target:      # 零候选
            return 0
        base = 1                   # base = 10^i
        while dsum(n // base + 1) > target:
            base *= 10
        return (n // base + 1) * base - n
```

> 💡 Python 整数无界，无溢出顾虑；先判 $n$ 自身再扫候选，其余与 C++ 完全同构。

## 8. 边界情况与易错点

1. **漏判 $x = 0$（头号 WA）**：所有 $c_i$ 严格大于 $n$，不先判 $n$ 自身就永远返回不了 $0$。示例 3（$n=1$，$target=1$）漏判会返回 $9$；大 $n$ 如 $n = 467$、$target = 100$ 同样中招。
2. **32 位溢出**：$n$、`base`、候选、答案都达 $10^{12}$ 量级，C++ 里 `int`（上界约 $2.1 \times 10^9$）必溢出，全程 `long long`。函数签名已是 `long long`，但自己写的辅助变量容易顺手 `int`。
3. **位和不单调，二分陷阱**：$19 \to 20 \to 21$ 位和 $10 \to 2 \to 3$，「最小 $x$」不能用二分——赛场上及时从二分转向构造，是本题的分水岭。
4. **连续 9 使相邻候选重合**：$n = 999$ 时 $c_0 = c_1 = c_2 = 1000$（进位链吞并低位），对应 $d_i = 9$ 处相邻差为 $0$，不违反单调性，也无需去重。
5. **进位顶长位数**：$n = 999$（3 位）的最优 $m = 1000$（4 位）。枚举上界由「$\lfloor n/10^i \rfloor = 0$ 时候选必可行」兜底，无需预先知道 $m$ 的位数。
6. **$target \ge 108$ 恒为 $0$**：$n \le 10^{12}$ 的位和上界是 $999\,999\,999\,999$ 的 $9 \times 12 = 108$，故 $target \in [108, 150]$ 的任何输入都会在零候选一步直接返回——数据范围里藏着的退化分支。
7. **$n = 10^{12}$ 边界**：位和恰为 $1$，零候选直接返回 $0$，不会进入循环。
