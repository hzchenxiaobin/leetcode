# LeetCode 根据规则将箱子分类 题解

## 1. 题目概述

- **标题 / 题号**：根据规则将箱子分类（#2525，easy）
- **链接**：https://leetcode.cn/problems/categorize-box-according-to-criteria/
- **来源**：LeetCode 第 95 场双周赛 Q1
- **难度**：简单
- **标签**：数学

**题意**：给出一个箱子的三个维度 `length`、`width`、`height` 与质量 `mass`，按两条独立规则给箱子分类：

- **Bulky（大体积）**：至少有一个维度 $\ge 10^4$，**或者**体积（三维乘积）$\ge 10^9$；
- **Heavy（重）**：$mass \ge 100$。

两条件都满足返回 `"Both"`，只满足 Bulky 返回 `"Bulky"`，只满足 Heavy 返回 `"Heavy"`，都不满足返回 `"Neither"`。

**约束**：

- $1 \le length, width, height \le 10^5$
- $1 \le mass \le 10^3$

## 2. 示例

**示例 1**

```text
输入：length = 1000, width = 35, height = 700, mass = 300
输出："Heavy"
解释：任何维度都 < 10^4，体积 1000×35×700 = 24500000 < 10^9，不是 Bulky；
      但 mass = 300 ≥ 100，是 Heavy，故返回 "Heavy"。
```

**示例 2**

```text
输入：length = 200, width = 50, height = 800, mass = 50
输出："Neither"
解释：任何维度都 < 10^4，体积 200×50×800 = 8000000 < 10^9，质量 50 < 100，
      两个条件都不满足。
```

**示例 3（边界补充）**

```text
输入：length = 1000, width = 1000, height = 1000, mass = 5
输出："Bulky"
解释：维度都不足 10^4，但体积恰为 10^9，触发体积条件（注意是"大于等于"）。
```

## 3. 解题思路

### 3.1 暴力思路

本题是纯条件判断题，没有任何枚举空间，"暴力"就是把题面四个分支原样写成 `if-else`。真正的坑不在算法，而在**数值**：三个维度最大都是 $10^5$，乘积可达 $10^{15}$，远超 32 位 `int` 上限 $2^{31}-1 \approx 2.1 \times 10^9$。若在 C++ 里直接写 `length * width * height >= 1000000000`，会先按 `int` 相乘发生溢出（结果是未定义行为），再与 $10^9$ 比较，可能把真正的 Bulky 箱子误判成 "Neither"。

### 3.2 核心观察：先化成两个布尔值，再查表

![核心观察：两个布尔条件映射到四个类别](images/bw95_q1_decision_flow.svg)

题面的四条返回规则其实是二维布尔表 $(bulky, heavy)$ 的完全枚举：

| bulky | heavy | 返回 |
|-------|-------|------|
| 真 | 真 | `"Both"` |
| 真 | 假 | `"Bulky"` |
| 假 | 真 | `"Heavy"` |
| 假 | 假 | `"Neither"` |

因此实现分两步：

1. 用**一次**乘法（`long long`）算出 $volume = length \times width \times height$，用 `max` 算出最大维度，得到 `bulky = maxDim >= 10000 || volume >= 1000000000`；
2. 用 `heavy = mass >= 100`，按上表返回。

### 3.3 算法流程

```text
1. maxDim = max(length, width, height)
2. volume = (long long)length * width * height
3. bulky = (maxDim >= 10^4) 或 (volume >= 10^9)
4. heavy = (mass >= 100)
5. 按布尔表返回 "Both" / "Bulky" / "Heavy" / "Neither"
```

### 3.4 示例演算：溢出是怎么发生的

![乘法溢出示意：三个 9999 相乘已远超 int 范围](images/bw95_q1_overflow_demo.svg)

取一个溢出敏感的例子：$length = width = height = 9999$，$mass = 1$。

- 正确计算：$volume = 9999^3 = 999700029999 \approx 10^{12} \ge 10^9$，是 Bulky，质量 1 不是 Heavy，应返回 `"Bulky"`；
- 若用 32 位 `int` 相乘：$9999 \times 9999 = 99980001$ 尚未溢出，再乘 $9999$ 得 $999700029999$，二进制截断后得到一个**负数**（约 $-1.88 \times 10^9$），与 $10^9$ 比较为假，且三个维度都 $< 10^4$，于是错误地返回 `"Neither"`。

这就是本题作为签到题唯一需要"停下来想一想"的地方：**先把一个乘数强转成 `long long`（或整体用 `long long` 存参数）再相乘**。

## 4. 算法细节

1. **乘法必须 64 位**：C++ 中 `(long long)length * width * height` 从左到右结合，第一步就按 64 位算；Python 原生大整数无此问题。
2. **两个阈值都是"大于等于"**：$10^4$ 与 $10^9$ 都含等于，$100$ 同样含等于。边界值 $10000$、体积恰 $10^9$、$mass = 100$ 都要触发条件。
3. **`max({...})` 初始化列表版本**需要三个参数类型一致，把 `int` 显式转成 `long long` 再比较，避免重载歧义。
4. **先算布尔再查表**优于嵌套 `if`：四个分支互斥且完备，查表写法不易漏分支。
5. 体积条件用 `||` 与维度条件并联，逻辑上"至少一个维度 $\ge 10^4$ **或** 体积 $\ge 10^9$"与题面一一对应。

## 5. 正确性证明

**引理 1（数据范围）**：$volume = length \cdot width \cdot height \le (10^5)^3 = 10^{15}$，且 $volume$ 可以超过 $2^{31} - 1$；任何用 32 位整数直接计算 $volume$ 的做法都存在溢出的输入。

**证明**：三个维度彼此独立地取到上界 $10^5$ 时乘积最大，为 $10^{15}$。取 $length = width = height = 9999 < 10^4$，则 $volume = 9999^3 = 999700029999 > 2^{31}-1 \approx 2.147 \times 10^9$，且此时三条维度均不触发条件，唯一的 Bulky 依据就是体积——溢出截断后该依据可能丢失，导致分类错误。∎

**定理**：按 §3.3 流程计算的返回值与题面定义的类别一致。

**证明**：题面定义的类别是 $f(bulky, heavy)$，其中 $bulky = \big(\max(length,width,height) \ge 10^4\big) \vee \big(length \cdot width \cdot height \ge 10^9\big)$，$heavy = (mass \ge 100)$。流程第 1–4 步按定义精确计算这两个布尔值（由引理 1，用 64 位计算 $volume$ 后比较是无歧义的精确计算）；第 5 步的查表是 $(bulky, heavy)$ 取值集合 $\{\text{真},\text{假}\}^2$ 上的完全映射，与题面四条返回规则逐一对应：两真 → "Both"，真真假 → "Bulky"，假真 → "Heavy"，两假 → "Neither"。两个布尔值的每种组合都恰好命中一条规则，故返回值与定义一致。∎

## 6. 复杂度分析

- **时间**：$O(1)$。两次比较、一次三数乘法、一次查表，均为常数操作。
- **空间**：$O(1)$。只使用常数个标量变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    string categorizeBox(int length, int width, int height, int mass) {
        long long maxDim = max({(long long)length, (long long)width, (long long)height});
        long long volume = (long long)length * width * height;   // 最大 1e15，必须 long long
        bool bulky = maxDim >= 10000 || volume >= 1000000000LL;
        bool heavy = mass >= 100;
        if (bulky && heavy) return "Both";
        if (bulky) return "Bulky";
        if (heavy) return "Heavy";
        return "Neither";
    }
};
```

### Python

```python
class Solution:
    def categorizeBox(self, length: int, width: int, height: int, mass: int) -> str:
        bulky = max(length, width, height) >= 10**4 or length * width * height >= 10**9
        heavy = mass >= 100
        if bulky and heavy:
            return "Both"
        if bulky:
            return "Bulky"
        if heavy:
            return "Heavy"
        return "Neither"
```

> 💡 两份代码均通过官方示例（`"Heavy"`、`"Neither"`）、$10^4$ / $10^9$ / $100$ 三个阈值的等值边界，以及 20 万组（C++）/ 5 万组（Python）侧重边界值的随机数据与独立参考实现的对拍，`mismatch = 0`。

## 8. 边界情况与易错点

1. **乘法溢出**：本题最高频的 WA 原因。三个 `int` 直接相乘在 $volume > 2^{31}-1$ 时溢出，`9999 9999 9999` 这类输入会返回错误的 `"Neither"`。
2. **阈值是闭的**：`10000` 本身算 Bulky 维度，体积恰 $10^9$ 算 Bulky，`mass = 100` 算 Heavy。用 `>` 会漏掉这些点。
3. **`"Both"` 优先**：四个返回互斥，但如果写成链式 `if`，注意条件完备，别把「既 Bulky 又 Heavy」落到 `"Bulky"` 分支。
4. **Python 无溢出但注意运算符优先级**：`a * b * c >= 10**9 and ...` 中 `and` 优先级低于比较，写 `max(...) >= 10**4 or a*b*c >= 10**9` 是安全的，但别把 `or` 的两个条件用 `and` 连接。
5. **max 初始化列表的类型一致**：C++ 的 `max({a, b, c})` 要求元素同型，`int` 与 `long long` 混用需显式转换。
