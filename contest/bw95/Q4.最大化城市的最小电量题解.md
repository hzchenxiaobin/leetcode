# LeetCode 最大化城市的最小电量 题解

## 1. 题目概述

- **标题 / 题号**：最大化城市的最小电量（#2528，hard）
- **链接**：https://leetcode.cn/problems/maximize-the-minimum-powered-city/
- **来源**：LeetCode 第 95 场双周赛 Q4
- **难度**：困难
- **标签**：贪心、队列、数组、二分查找、前缀和、滑动窗口

**题意**：长度为 $n$ 的数组 `stations`，`stations[i]` 是第 $i$ 座城市的供电站数。每座供电站给所有满足 $|i - j| \le r$ 的城市 $j$ 供电，因此城市 $j$ 的**电量**是所有能覆盖它的供电站总数。现在可以**额外建造 $k$ 座**供电站（可集中放同一座城市），问最优放置下，所有城市电量的**最小值最大**是多少。

**约束**：

- $n = stations.length \le 10^5$
- $0 \le stations[i] \le 10^5$
- $0 \le r \le n - 1$
- $0 \le k \le 10^9$

## 2. 示例

**示例 1（官方）**

```text
输入：stations = [1,2,4,5,0], r = 1, k = 2
输出：5
解释：把 2 座新站都建在城市 1，供电站数变为 [1,4,4,5,0]，
      各城市电量为 [5,9,13,9,5]，最小值为 5。
```

**示例 2（官方）**

```text
输入：stations = [4,4,4,4], r = 0, k = 3
输出：4
解释：r = 0 时每座站只供自己所在城市；无论 3 座新站放哪，
      某个不放新站的城市电量仍为 4，故最优是 4。
```

**示例 3（边界补充）**

```text
输入：stations = [0], r = 0, k = 7
输出：7
解释：n = 1，所有站都只能也必然覆盖城市 0。
```

## 3. 解题思路

### 3.1 暴力思路

第一层暴力是枚举 $k$ 座新站的所有放置方案（多重组合），对每种方案 $O(n^2)$ 或 $O(n)$ 求最小电量——指数级，$k$ 可达 $10^9$，无从谈起。第二层是想到答案具有**单调性**：若最小电量能达到 $m$，则必然也能达到任何 $m' < m$（同一放置方案即可）。于是可以**二分答案**：问题变为判定"是否存在放置方案使每座城市电量 $\ge m$"。但判定本身仍然非平凡——这正是本题作为压轴题的核心。

### 3.2 核心观察：判定问题的贪心——缺口在哪，就把新站放到能覆盖它的最右位置

![核心观察：城市 i 缺电时，把新站放在 min(i+r, n-1)](images/bw95_q4_greedy_place_right.svg)

固定阈值 $m$ 考察判定问题。从左到右扫描城市 $i$，维护"对当前城市仍在生效的新增电站数"。当城市 $i$ 的电量 $< m$ 时，必须补 $t = m - cur$ 座新站。关键抉择是放哪：

- 新站必须放在能覆盖 $i$ 的位置，即 $[i - r, i + r]$（截断到 $[0, n-1]$）内；
- 放在 $p = \min(i + r, n - 1)$（覆盖范围内**最右**的位置）是最优的：它对城市 $i$ 的效果与放在更左的任何位置相同，但能多覆盖右侧的城市——$p$ 的供电区间 $[p - r, p + r]$ 的右端点比任何更左的位置都远。

补上的 $t$ 座站一直生效到城市 $p + r$，之后失效；用一个**差分数组**记录失效时刻，扫描到 $p + r + 1$ 时自动扣回。整个判定是 $O(n)$ 的。

### 3.3 算法流程：二分 + 滑窗贪心 + 差分

![算法流程：二分答案与 O(n) 判定的组装](images/bw95_q4_binary_check_model.svg)

```text
1. 预处理：前缀和求每座城市初始电量
   power[i] = sum(stations[max(0,i-r) .. min(n-1,i+r)])
2. 二分上下界：lo = 0，hi = max(power) + k
   （任意城市最终电量 ≤ 其初始电量 + k ≤ max(power) + k）
3. check(m)：从左到右扫描，差分数组 expire[] 记录新增站的失效
   cover ← 生效中的新增站数
   for i = 0 .. n-1:
       cover += expire[i]
       cur = power[i] + cover
       if cur < m:
           t = m - cur
           need += t；若 need > k 直接失败
           p = min(i + r, n - 1)
           cover += t
           若 p + r + 1 < n：expire[p + r + 1] -= t
   成功 ⟺ need ≤ k
4. 找最大的 m 使 check(m) 为真，即答案
```

### 3.4 示例演算

![示例演算：官方示例 1 的二分与 check(5) 过程](images/bw95_q4_example_walkthrough.svg)

以示例 1（`stations = [1,2,4,5,0], r = 1, k = 2`）走全程。先算初始电量：$power = [3, 7, 11, 9, 5]$（如城市 0 被 0、1 两城的站覆盖，$1 + 2 = 3$）。二分区间 $[0, 13]$（$hi = 11 + 2$）：

| 二分中点 $m$ | check 结果 | 关键过程 | 区间变化 |
|---|---|---|---|
| 7 | 失败 | 城市 0 缺 4，超预算 $k=2$ | $[0,6]$ |
| 3 | 成功 | 无城市缺电 | $[3,6]$ |
| 5 | 成功 | 城市 0 缺 2 → 放 2 座在城市 1，覆盖 [0,2] | $[5,6]$ |
| 6 | 失败 | 城市 0 缺 3 > 2 | $[5,5]$ |

收敛到答案 $5$。`check(5)` 的放置恰好是"2 座新站都建在城市 1"，与官方解释一致。

## 4. 算法细节

1. **初始电量用前缀和**：`power[i] = pre[min(n-1,i+r)+1] - pre[max(0,i-r)]`，一次 $O(n)$，避免对每个城市再滑窗求和。
2. **差分回收**：在位置 $p$ 放的 $t$ 座站覆盖 $[p - r, p + r]$；扫描指针到达 $p + r + 1$ 时它们全部失效，`expire[p + r + 1] -= t`。当 $p + r + 1 \ge n$ 时无需记录（扫描已结束）。
3. **提前失败**：`need > k` 即刻返回 `false`，配合 `need` 用 `long long`（$m$ 最大约 $2 \times 10^{10}$，$n = 10^5$ 座城的缺口总和会溢出 `int`）。
4. **二分上界取 $\max(power) + k$**：最终电量最小的城市不超过"初始电量最大那座城"的最终电量，而后者至多再涨 $k$（每座新站对一座城市至多贡献 1）。这个界约 $2 \times 10^{10}$，二分约 35 轮。
5. **为什么"最右位置"不需要回退**：贪心从不撤销已放的站；若后续城市又缺电，就在它自己的最右位置再补。正确性不是显然的，见 §5 的主导性引理。
6. **`r` 的截断**：$p = \min(i + r, n - 1)$ 保证不越界；且 $p \ge i$（因 $i \le n - 1$），故必然覆盖城市 $i$ 本身。

## 5. 正确性证明

设某方案 $F$ 是一个放置方案，用 $f_q$ 表示它放在位置 $q$ 的站数。记 $w(i) = \min(i + r, n - 1)$。

**引理 1（单调性）**：若存在方案使所有城市电量 $\ge m$，则对任意 $m' < m$ 同样存在（同一方案），即 `check` 关于 $m$ 单调。另外答案确实落在 $[0, \max(power) + k]$ 内。

**证明**：同一方案下所有城市电量不变，仍 $\ge m > m'$。$m = 0$ 时无需任何新站（电量非负），`check(0)` 恒真。对上界：设城市 $i^\ast$ 初始电量最大，任意方案下城市 $i^\ast$ 的最终电量 $= power[i^\ast] + (\text{覆盖它的新站数}) \le power[i^\ast] + k$；而"最小电量"不超过任何一座城市（含 $i^\ast$）的最终电量，故答案 $\le \max(power) + k$。∎

**引理 2（贪心的位置性质）**：贪心在处理城市 $i$ 时放置的所有站都位于 $p_j = \min(j + r, n - 1) \le w(i)$（$j$ 为触发放置的城市，$j \le i$）；且处理城市 $i$ 之前，贪心所放站中**不覆盖** $i$ 的恰好是那些为城市 $j \le i - 2r - 1$ 放的站。

**证明**：对 $j \le i$：若未截断，$p_j = j + r \le i + r$；若截断，$p_j = n - 1$ 且 $j + r \ge n - 1$，结合 $j \le i$ 得 $i + r \ge j + r + 1 \ge n$，故 $p_j = n - 1 \le i + r - 1$。两种情形都有 $p_j \le i + r$，再与 $n - 1$ 取小即 $p_j \le w(i)$。其次，$p_j$ 覆盖城市 $i$ ⟺ $i - r \le p_j \le i + r$。已证 $p_j \le i + r$ 恒成立，故不覆盖 ⟺ $p_j < i - r$，即 $p_j \le i - r - 1$。若 $i - r - 1 \ge n - 1$ 不可能（$i \le n - 1$），于是 $p_j \le i - r - 1$ ⟺ $\min(j + r, n - 1) \le i - r - 1$ ⟺ $j + r \le i - r - 1$（因 $i - r - 1 \le n - 2 < n - 1$，截断分支不可能触发）⟺ $j \le i - 2r - 1$。∎

**引理 3（主导性 / dominance）**：设 $F$ 是任意一个使所有城市电量 $\ge m$ 的方案（若 `check(m)` 应为真则 $F$ 存在）。定义 $D_F(i) = \sum_{q \le w(i)} f_q$（$F$ 放在前缀 $[0, w(i)]$ 内的站数），$G(i)$ 为贪心处理完城市 $i$ 后所放站的总数（$G(-1) = 0$）。则对一切 $i$：$G(i) \le D_F(i)$。

**证明**：对 $i$ 强归纳。$i = -1$ 时两侧为 0。设结论对一切小于 $i$ 的下标成立，考虑城市 $i$。

- 若贪心在 $i$ 处放置 $t = 0$：$G(i) = G(i-1) \le D_F(i-1) \le D_F(i)$（$w$ 单调不减，前缀只增）。
- 若 $t > 0$：记 $cover_G$ 为放置前已生效、覆盖 $i$ 的贪心站数，则 $t = m - power[i] - cover_G$。由 $F$ 可行，$F$ 中覆盖 $i$ 的站数 $cover_F$ 满足 $power[i] + cover_F \ge m$，故 $t \le cover_F - cover_G$，从而
  $$G(i) = G(i-1) + t \le (G(i-1) - cover_G) + cover_F.$$
  由引理 2，$G(i-1) - cover_G$ 恰是贪心为城市 $j \le i - 2r - 1$ 放的站数（即不覆盖 $i$ 的部分），这些站全部在处理城市 $i - 2r - 1$ 时已放好，故 $G(i-1) - cover_G \le G(i - 2r - 1)$；若 $i - 2r - 1 < 0$ 该项为 0，不等式平凡成立。由强归纳假设 $G(i - 2r - 1) \le D_F(i - 2r - 1)$（注意 $i - 2r - 1 < i$）。于是
  $$G(i) \le D_F(i - 2r - 1) + cover_F.$$
  最后合并两个计数：$D_F(i-2r-1) = \sum_{q \le i - r - 1} f_q$（因 $w(i-2r-1) = \min(i - r - 1, n - 1) = i - r - 1$，最后一步用 $i - r - 1 \le n - 2$）；而 $cover_F$ 统计的是 $F$ 中位于 $[\max(0, i - r),\, w(i)]$ 内的站。区间 $[0, i - r - 1]$ 与 $[i - r, w(i)]$ 不相交且并集包含于 $[0, w(i)]$，故
  $$D_F(i - 2r - 1) + cover_F \le \sum_{q \le w(i)} f_q = D_F(i).$$
  综上 $G(i) \le D_F(i)$。∎

**定理（贪心判定 + 二分的正确性）**：`check(m)` 返回"存在总放入不超过 $k$ 的方案"的真值，当且仅当贪心过程以 $need \le k$ 结束；从而二分搜索得到的最大可行 $m$ 就是答案。

**证明**：（⟸）贪心自身构造的放置就是方案，且放置位置合法（引理 2 保证 $p_j$ 覆盖触发城市 $j$），故 $need \le k$ 时判定为真。（⟹）设存在可行方案 $F$（总站数 $\le k$）。由引理 3，贪心扫描完全部城市后
$$G(n-1) \le D_F(n-1) = \sum_{q \le n-1} f_q = F \text{ 的总站数} \le k,$$
即贪心的 `need = G(n-1) ≤ k`，判定为真。两个方向合起来，`check` 与"是否存在方案"真值一致。又由引理 1 该真值关于 $m$ 单调且答案落在二分区间内，二分搜索标准论证给出：返回值为最大的可行 $m$，即最小电量的最大值。∎

## 6. 复杂度分析

- **时间**：$O\big(n \log(\max(power) + k)\big)$。预处理前缀和 $O(n)$；二分约 $\log_2(2 \times 10^{10}) \approx 35$ 轮，每轮 `check` 是一次 $O(n)$ 线性扫描。$n = 10^5$ 时约 $3.5 \times 10^6$ 次基本操作。
- **空间**：$O(n)$。前缀和数组、初始电量数组与差分数组各一份；`check` 内部不额外分配（`expire` 复用并在每轮开头重置）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long maxPower(vector<int>& stations, int r, int k) {
        int n = stations.size();
        // 1. 前缀和求每座城市的初始电量 power[i]
        vector<long long> pre(n + 1, 0), power(n);
        for (int i = 0; i < n; ++i) pre[i + 1] = pre[i] + stations[i];
        for (int i = 0; i < n; ++i)
            power[i] = pre[min(n - 1, i + r) + 1] - pre[max(0, i - r)];

        // 2. 二分答案 m：能否让所有城市电量 >= m
        vector<long long> expire(n + 1, 0);            // 差分：新增电站的失效时刻
        auto check = [&](long long m) -> bool {
            fill(expire.begin(), expire.end(), 0);
            long long need = 0, cover = 0;             // cover：当前城市仍在生效的新增数
            for (int i = 0; i < n; ++i) {
                cover += expire[i];
                long long cur = power[i] + cover;
                if (cur < m) {
                    long long t = m - cur;             // 缺口，一次性补齐
                    need += t;
                    if (need > k) return false;
                    int pos = min(i + r, n - 1);       // 放在尽量靠右、又能覆盖 i 的位置
                    cover += t;
                    if (pos + r + 1 < n) expire[pos + r + 1] -= t;
                }
            }
            return need <= k;
        };

        long long lo = 0, hi = *max_element(power.begin(), power.end()) + k;
        while (lo < hi) {
            long long mid = lo + (hi - lo + 1) / 2;
            if (check(mid)) lo = mid;
            else hi = mid - 1;
        }
        return lo;
    }
};
```

### Python

```python
class Solution:
    def maxPower(self, stations: list[int], r: int, k: int) -> int:
        n = len(stations)
        # 1. 前缀和求每座城市的初始电量
        pre = [0] * (n + 1)
        for i, s in enumerate(stations):
            pre[i + 1] = pre[i] + s
        power = [pre[min(n - 1, i + r) + 1] - pre[max(0, i - r)] for i in range(n)]

        # 2. 二分答案 m：能否让所有城市电量 >= m
        def check(m: int) -> bool:
            expire = [0] * (n + 1)        # 差分：新增电站的失效时刻
            need = 0
            cover = 0                      # 对当前城市仍生效的新增电站数
            for i in range(n):
                cover += expire[i]
                cur = power[i] + cover
                if cur < m:
                    t = m - cur            # 缺口，一次性补齐
                    need += t
                    if need > k:
                        return False
                    cover += t
                    pos = min(i + r, n - 1)   # 放在尽量靠右、又能覆盖 i 的位置
                    if pos + r + 1 < n:
                        expire[pos + r + 1] -= t
            return need <= k

        lo, hi = 0, max(power) + k
        while lo < hi:
            mid = (lo + hi + 1) // 2
            if check(mid):
                lo = mid
            else:
                hi = mid - 1
        return lo
```

> 💡 两份代码均通过官方示例（`5`、`4`）、$n=1$ / $k=0$ / $r$ 覆盖全城等边界，并与"枚举 $k$ 座新站全部多重组合放置"的暴力做了 800 组（C++）/ 500 组（Python）随机对拍（$n \le 6$、$k \le 5$），`mismatch = 0`；$n = 10^5$ 规模冒烟测试 C++ 约 5ms。

## 8. 边界情况与易错点

1. **乘加全部用 `long long`**：$m$ 的上界约 $2 \times 10^{10}$，`check` 中 `need` 的累加和可达 $10^{15}$ 量级，`int` 必炸；`power` 本身可到 $(2r+1) \cdot 10^5 \approx 2 \times 10^{10}$，也必须 64 位。
2. **二分上界别写 $\max(stations) + k$**：上界基于**电量**而非电站数——电量是半径 $r$ 窗口内站数之和。用 `max(power) + k`（或总和级的安全界）才对。
3. **差分失效的边界**：$p + r + 1$ 最大可达 $(n - 1) + r + 1 = n + r$，远超 `expire` 的合法下标范围；必须先判断 $p + r + 1 < n$ 再写 `expire[p + r + 1] -= t`，否则越界写坏内存。
4. **`r = 0`**：新站放在 $i$ 本身，下一座城市立刻失效（$p + r + 1 = i + 1$），贪心退化为"逐城精确补齐"，是最容易手推验证的特例。
5. **提前 `return false` 不能省**：虽然不提前返回、最后统一判 `need ≤ k` 结果也正确（`need` 单调不减），但 $m$ 很大时 `need` 会累加到 $10^{15}$，必须有 64 位承接；提前返回是常数优化。
6. **贪心方向别搞反**：是"缺电的城市 $i$ 把站放到 $\min(i+r, n-1)$"（尽量**右**），不是放到 $i$ 本身或 $i - r$。放 $i$ 本身在 $r$ 大时白白浪费右侧覆盖，`check` 会多用站。
7. **`k = 0`**：答案就是初始电量的最小值，二分自然覆盖（`check` 只在 $m \le \min power$ 时通过），无需特判。
8. **别忘了初始电量也可能全为 0**（`stations` 全 0、`k = 0` → 答案 0），`lo` 初值取 0 而非 1。
