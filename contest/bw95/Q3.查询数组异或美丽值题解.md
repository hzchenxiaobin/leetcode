# LeetCode 查询数组异或美丽值 题解

## 1. 题目概述

- **标题 / 题号**：查询数组异或美丽值（#2527，medium）
- **链接**：https://leetcode.cn/problems/find-xor-beauty-of-array/
- **来源**：LeetCode 第 95 场双周赛 Q3
- **难度**：中等
- **标签**：位运算、数组、数学

**题意**：给定下标从 0 开始、长度为 $n$ 的正整数数组 `nums`。三元组 $(i, j, k)$ 的**有效值**定义为 $((nums[i] \mid nums[j]) \And nums[k])$（先按位或、再按位与）。数组的**异或美丽值**是**所有** $0 \le i, j, k < n$ 的（有序）三元组有效值的异或和。返回这个美丽值。

**约束**：

- $1 \le nums.length \le 10^5$
- $1 \le nums[i] \le 10^9$

## 2. 示例

**示例 1（官方）**

```text
输入：nums = [1, 4]
输出：5
解释：8 个三元组的有效值分别为 1,0,1,4,1,4,0,4，
      异或起来：1 ^ 0 ^ 1 ^ 4 ^ 1 ^ 4 ^ 0 ^ 4 = 5。
```

**示例 2（官方）**

```text
输入：nums = [15,45,20,2,34,35,5,44,32,30]
输出：34
```

**示例 3（边界补充）**

```text
输入：nums = [123456789]
输出：123456789
解释：n = 1 时唯一三元组 (0,0,0) 的有效值即 nums[0] 本身。
```

## 3. 解题思路

### 3.1 暴力思路

按定义三重循环枚举 $(i, j, k)$，共 $n^3$ 个三元组。$n = 10^5$ 时是 $10^{15}$ 次操作，完全不可行。即便想到"位独立性"后按位统计，也需要先回答一个问题：这个三重求和的异或到底简化成了什么？本题的考点正是把这个看似纠缠了 $i, j, k$ 三个下标的表达式**化简到底**。

### 3.2 核心观察一：按位独立，只看每个二进制位的奇偶

![核心观察：异或按位独立，第 b 位只由命中次数的奇偶决定](images/bw95_q3_bit_independence.svg)

异或是逐位运算：答案的第 $b$ 位，等于所有三元组有效值第 $b$ 位的异或，也就是**第 $b$ 位为 1 的三元组个数 mod 2**。而有效值的第 $b$ 位有一个干净的展开：

$$\big((nums[i] \mid nums[j]) \And nums[k]\big)_b = \big(nums[i]_b \vee nums[j]_b\big) \wedge nums[k]_b$$

即第 $b$ 位贡献为 1 ⟺ $nums[k]$ 的第 $b$ 位为 1，**且** $nums[i]$、$nums[j]$ 中至少有一个第 $b$ 位为 1。于是固定一个二进制位 $b$，设数组中第 $b$ 位为 1 的元素个数为 $c$，则命中三元组数为

$$N_b = c \cdot \big(n^2 - (n - c)^2\big)$$

（$k$ 有 $c$ 种选法；$(i, j)$ 共 $n^2$ 种，其中两位全 0 的有 $(n-c)^2$ 种，需排除）。答案第 $b$ 位 $= N_b \bmod 2$。按位统计的做法是 $O(n \log V)$——但还有更彻底的化简。

### 3.3 核心观察二：对称性成对抵消，答案就是全体异或

![核心观察：i≠j 的项两两抵消，只剩 (i,i,k) 项](images/bw95_q3_symmetry_cancel.svg)

按位或满足交换律：$nums[i] \mid nums[j] = nums[j] \mid nums[i]$。因此把三元组按 $\{i, j\}$ 配对：

- **$i \ne j$ 的项全部抵消**：$(i, j, k)$ 与 $(j, i, k)$ 的有效值完全相同，两者异或为 0。$n^2$ 对 $(i,j)$ 中只剩 $i = j$ 的 $n$ 对；
- **剩下的是 $(i, i, k)$ 项**，有效值为 $(nums[i] \mid nums[i]) \And nums[k] = nums[i] \And nums[k]$。

于是

$$\text{答案} = \bigoplus_{i=0}^{n-1} \bigoplus_{k=0}^{n-1} (nums[i] \And nums[k])$$

再对第 $b$ 位分析：$nums[i] \And nums[k]$ 的第 $b$ 位为 1 要求两者第 $b$ 位都为 1，命中对数为 $c_b^2$，奇偶性与 $c_b$ 相同（$x^2 \equiv x \pmod 2$）。而"$\bigoplus$ 起所有元素第 $b$ 位的值 $= c_b \bmod 2$"正是全体异或的定义。**答案 $= nums[0] \oplus nums[1] \oplus \cdots \oplus nums[n-1]$**。

### 3.4 示例演算

![示例演算：nums=[1,4] 的按位分析](images/bw95_q3_example_walkthrough.svg)

用 $nums = [1, 4]$（二进制 $01$ 与 $100$）逐位验证：

| 二进制位 | 元素中该位为 1 的个数 $c_b$ | $N_b$ 或 $c_b^2$ 的奇偶 | 答案该位 |
|----------|------|------|------|
| 第 0 位（值 1） | 只有 1 → $c_0 = 1$ | 奇 | 1 |
| 第 1 位（值 2） | 无 → $c_1 = 0$ | 偶 | 0 |
| 第 2 位（值 4） | 只有 4 → $c_2 = 1$ | 奇 | 1 |

拼起来是 $101_2 = 5$，与官方输出一致；也正是 $1 \oplus 4 = 5$。示例 2 同理：10 个数全体异或 $15 \oplus 45 \oplus 20 \oplus 2 \oplus 34 \oplus 35 \oplus 5 \oplus 44 \oplus 32 \oplus 30 = 34$。

## 4. 算法细节

1. **最终实现只剩一个循环**：`ans ^= x` 遍历一遍数组。位独立性推导是"为什么对"，对称性推导是"为什么这么简单"。
2. **中间式也可以落地**：若不放心，可以用 $O(n \log V)$ 的按位计数 $c_b$、奇偶判断 $N_b \bmod 2$ 实现一遍对拍，确认与一行异或等价（本文对拍即用三重循环暴力）。
3. **值域**：$nums[i] \le 10^9 < 2^{30}$，异或结果不超过 $2^{30}$，`int` 足够；官方签名返回 `int`。
4. **有序三元组**：题目明确 $i, j, k$ 各自独立取遍 $[0, n)$，配对抵消的论证建立在有序枚举之上，无需担心"下标相同算不算"的问题——$(i, i, k)$ 是合法三元组，$i = j = k$ 也合法。
5. **异或的自消性**：$x \oplus x = 0$、$x \oplus 0 = x$、交换律、结合律是全部用到的性质。

## 5. 正确性证明

**引理 1（按位独立）**：对任意整数序列 $v_1, \dots, v_m$，$\bigoplus_{t=1}^{m} v_t$ 的第 $b$ 位等于 $\#\{t : (v_t)_b = 1\} \bmod 2$。

**证明**：异或的每一位是各运算数该位的模 2 和（不进位加法）。对 $t$ 归纳：$m = 1$ 显然；设结论对 $m$ 成立，$w = \bigoplus_{t=1}^{m+1} v_t = (\bigoplus_{t=1}^{m} v_t) \oplus v_{m+1}$，其第 $b$ 位为前 $m$ 个的模 2 和再异或 $v_{m+1}$ 的第 $b$ 位，即 $\big(\#\{t \le m\} + (v_{m+1})_b\big) \bmod 2$，恰为 $m+1$ 个数中该位为 1 的个数的奇偶。∎

**引理 2（或的交换性带来的配对抵消）**：$nums[i] \mid nums[j] = nums[j] \mid nums[i]$ 对一切 $i, j$ 成立，故三元组 $(i, j, k)$（$i \ne j$）与 $(j, i, k)$ 的有效值相等；把全体 $n^3$ 个三元组按 $k$ 固定、$\{i, j\}$ 无序对分组，$i \ne j$ 的组内两两异或为 0，整体异或只剩 $i = j$ 的项。

**证明**：交换律直接给出两有效值相等：$((a_i \mid a_j) \And a_k) = ((a_j \mid a_i) \And a_k)$（$a_t$ 记 $nums[t]$）。把 $\bigoplus_{i,j,k}$ 按下标对重排：$\{i \ne j\} \cup \{i = j\}$ 是对 $(i,j)$ 取值域的划分。前者可按无序对 $\{i,j\}$ 分组，每组恰含 $(i,j,k)$、$(j,i,k)$ 两项且两值相等，由 $x \oplus x = 0$ 每组贡献 0；后者每对 $(i, k)$ 恰一项 $(i, i, k)$，有效值为 $(a_i \mid a_i) \And a_k = a_i \And a_k$（按位或的幂等性）。故

$$\text{答案} = \bigoplus_{i, k} (a_i \And a_k).$$

∎

**定理**：$\bigoplus_{i,j,k} \big((a_i \mid a_j) \And a_k\big) = \bigoplus_{t=0}^{n-1} a_t$。

**证明**：由引理 2 只需证 $\bigoplus_{i,k} (a_i \And a_k) = \bigoplus_t a_t$。按引理 1 转为逐位比较奇偶。固定二进制位 $b$，设 $c = \#\{t : (a_t)_b = 1\}$。左边第 $b$ 位为 1 的 $(i, k)$ 对数是"两者第 $b$ 位都为 1"的对数 $c^2$，故左边第 $b$ 位 $= c^2 \bmod 2$；右边（全体异或）第 $b$ 位 $= c \bmod 2$。由 $c^2 \equiv c \pmod 2$（$c$ 为偶数时两者均 0，奇数时均 1），两侧每一位都相等，故整数相等。∎

> ⚠️ 顺带一提：若有人把有效值误记为 $(a_i \mid a_j) \oplus a_k$ 或 $(a_i \And a_j) \mid a_k$，本题答案将完全不同——推导每一步都依赖"或交换 + 与合取"这个具体结构，化简结论不可凭直觉平移。

## 6. 复杂度分析

- **时间**：$O(n)$。一次遍历、每步一次异或。（按位统计的做法是 $O(n \log V)$，$V = 10^9$ 约 30 位，也远快于暴力，但已无必要。）
- **空间**：$O(1)$。一个累加变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int xorBeauty(vector<int>& nums) {
        int ans = 0;
        for (int x : nums) ans ^= x;           // 答案恰为全体元素的异或
        return ans;
    }
};
```

### Python

```python
class Solution:
    def xorBeauty(self, nums: list[int]) -> int:
        ans = 0
        for x in nums:
            ans ^= x            # 答案恰为全体元素的异或
        return ans
```

> 💡 两份代码均通过官方示例（`5`、`34`）与 $n=1$ 边界，并与 $O(n^3)$ 三重循环暴力实现做了 5000 组（C++）/ 3000 组（Python）随机对拍（$n \le 8$、值域 $[0, 63]$），`mismatch = 0`；$n = 10^5$ 规模冒烟测试在毫秒级完成。

## 8. 边界情况与易错点

1. **别把"至少一个维度为 1"理解错**：本题 $i$、$j$、$k$ 是**独立**枚举的下标，可以两两相等甚至三者全等；漏掉 $i = j$ 的项（只留 $i < j$）会得到完全不同的答案。
2. **抵消依赖有序枚举**：$i \ne j$ 的项是"有序对"里的 $(i,j,k)$ 与 $(j,i,k)$ 成对消去；如果把三元组当无序组合枚举，抵消论证不成立。
3. **按位统计时是 $n^2 - (n-c)^2$ 而不是 $n^2 - (n-1)^2$**：两位全 0 的 $(i,j)$ 有 $(n-c)^2$ 对，误写 $n - c$（漏平方）会让奇偶判断出错。
4. **返回类型**：官方 C++ 签名返回 `int`，全体异或不超过 $2^{30}$，无需 `long long`。
5. **异或不要写成按位或/与**：三种位运算在"逐位模 2 和"意义下只有异或满足引理 1 的线性性，换成或/与整个推导崩塌。
6. **空数组**：约束保证 $n \ge 1$，但若防御性处理，空数组的异或美丽值应返回 0（空异或的幺元）。
