# LeetCode 恢复数组 题解

## 1. 题目概述

- **标题 / 题号**：恢复数组（#1416，hard）
- **链接**：https://leetcode.cn/problems/restore-the-array/
- **来源**：LeetCode 第 24 场双周赛 Q4
- **难度**：困难
- **标签**：字符串、动态规划

**题意**：某程序本应输出一个整数数组，却把分隔符弄丢，输出成了一整个数字字符串 $s$。已知原数组每个整数都在 $[1, k]$ 内且**无前导零**。求有多少个不同的原数组能产出字符串 $s$，答案对 $10^9 + 7$ 取模。

**约束**：

- $1 \le s.length \le 10^5$
- $s$ 只含数字且 $s[0] \ne 0$（$s$ 本身无前导零）
- $1 \le k \le 10^9$

**约束解读**：$|s|$ 高达 $10^5$，任何「枚举切分位置组合」的做法（$2^{n-1}$）不可行；$k \le 10^9$ 意味着合法段**至多 10 位**，这是把转移压缩到常数的关键。

## 2. 示例

**示例 1**

```text
输入：s = "1000", k = 10000
输出：1
解释：唯一方案 [1000]。
```

**示例 2**

```text
输入：s = "1000", k = 10
输出：0
解释：[1000] 超出 10；任何含 "0xx" 段的切分都有前导零，无解。
```

**示例 3**

```text
输入：s = "1317", k = 2000
输出：8
解释：[1317]，[131,7]，[13,17]，[1,317]，[13,1,7]，[1,31,7]，[1,3,17]，[1,3,1,7]。
```

**示例 4（题面补充）**

```text
输入：s = "2020", k = 30
输出：1
解释：只有 [20,20]；[2020] > 30，[2,020] 含前导零。
```

## 3. 解题思路

### 3.1 暴力思路

在 $n-1$ 个字符间隙里每个「切 / 不切」，共 $2^{n-1}$ 种切分，逐个检查每段无前导零且数值 $\le k$。$n = 10^5$ 直接爆炸。即使改成记忆化搜索「从位置 $i$ 出发的方案数」，若不限制段长，每个 $dp[i]$ 要枚举 $j = i \sim n-1$ 共 $O(n)$ 个后继，总复杂度 $O(n^2) = 10^{10}$ 仍然超时。突破口藏在数据范围里：$k \le 10^9$ 只有 $10$ 位，**任何合法段的长度都不超过 $\mathrm{len}(k) \le 10$**，转移天然被截断成常数个。

### 3.2 核心观察：按「首段」分情况的后缀计数

![分段 DP 模型：dp-i 由所有合法首段转移自 dp-j+1](images/bw24_q4_segment_dp_model.svg)

一个合法数组对应把 $s$ 切成若干段，每段满足：

1. **无前导零**：段首字符 $\ne 0$；
2. **数值 $\le k$**：段作为十进制数不越界。

设 $dp[i]$ 表示**后缀** $s[i..n-1]$ 的切分方案数（空后缀 $dp[n] = 1$）。按首段末位置 $j$ 分类，首段 $s[i..j]$ 一旦合法，剩余部分的方案数恰为 $dp[j+1]$，且不同 $j$ 的方案**互不相交、并起来完备**：

$$dp[i] = \sum_{\substack{i \le j < n \\ s[i..j] \text{ 合法}}} dp[j+1].$$

答案为 $dp[0]$。这就是**数位 DP 的标准后缀写法**——把「大问题」拆成「首段 + 更短后缀」。

### 3.3 核心观察：转移被段长截断为常数

![段合法性规则：段首非零、数值不超过 k；越界后立即停止延伸](images/bw24_q4_validity_rule.svg)

段长超过 $\mathrm{len}(k)$ 时数值必然 $> k$（无前导零的 $11$ 位数 $\ge 10^{10} > 10^9 \ge k$）；更妙的是**数值随 $j$ 单调不减**——一旦 $s[i..j]$ 的值超过 $k$，再往后拼字符只会更大（$\text{val}' = 10 \cdot \text{val} + d \ge \text{val}$，且无前导零保证 $\text{val} \ge 1$ 时严格递增）。所以内层循环可以**边延伸边累计、一旦越界立即 break**：

- 遇到 $s[i] = 0$：没有任何合法段以 $i$ 开头，$dp[i] = 0$；
- 从 $j = i$ 起累计 $\text{val} = 10 \cdot \text{val} + s[j]$：$\text{val} > k$ 就停，否则累加 $dp[j+1]$。

内层至多 $\min(n - i,\ \mathrm{len}(k) + 1) \le 11$ 步，总复杂度 $O(11n)$。

### 3.4 示例演算

![示例演算：s=1317, k=2000 的 dp 表逐步填充](images/bw24_q4_example_walkthrough.svg)

以 $s = \texttt{1317}$、$k = 2000$ 为例（$dp[4] = 1$）：

| $i$ | 候选首段（值 $\le 2000$） | 转移 | $dp[i]$ |
|-----|---------------------------|------|---------|
| 3 | `7` | $dp[4]$ | $1$ |
| 2 | `1`、`17` | $dp[3] + dp[4]$ | $1 + 1 = 2$ |
| 1 | `3`、`31`、`317` | $dp[2] + dp[3] + dp[4]$ | $2 + 1 + 1 = 4$ |
| 0 | `1`、`13`、`131`、`1317` | $dp[1] + dp[2] + dp[3] + dp[4]$ | $4 + 2 + 1 + 1 = 8$ |

$dp[0] = 8$，与示例 3 的八种方案一一对应：首段 `1` 对应 $dp[1]=4$ 种（`[3,1,7]` 型），首段 `13` 对应 $2$ 种，`131` 对应 $1$ 种，`1317` 对应 $1$ 种。

**反例走查**（示例 2，$s = \texttt{1000}$，$k = 10$）：$dp[3]$：段 `0` 前导零 → $0$；$dp[2]$：段首 `0` → $0$；$dp[1]$：段首 `0` → $0$；$dp[0]$：段 `1`（$\le 10$ ✓）→ $dp[1] = 0$；段 `10`（✓）→ $dp[2] = 0$；段 `100`（$> 10$ ✗ 停）。$dp[0] = 0$ ✓。

## 4. 算法细节

1. **后缀方向 DP**：$i$ 从 $n-1$ 倒序到 $0$，保证计算 $dp[i]$ 时 $dp[j+1]$（$j \ge i$）全部就绪；正序做前缀 DP（$f[i]$ = 前 $i$ 位的方案数）同样可行，转移为 $f[j+1] \mathrel{+}= f[i]$，两者互为镜像。
2. **数值增量计算**：`val = val * 10 + (s[j] - '0')` 边延伸边累计，避免反复调用子串转整数（`stoi` 每次构造子串是 $O(\text{len})$，虽同阶但常数大）。
3. **越界即停的正确性**：段无前导零时首段值 $\ge 1$，故 $\text{val}$ 随延伸严格递增，$\text{val} > k$ 后永不再合法，`break` 无损。
4. **溢出核算**：`val` 在停止前恒 $\le k \le 10^9$，最后一次更新至多 $10 \cdot 10^9 + 9 < 2^{63}$，用 `long long` 安全；`dp` 取模后 $\le 10^9 + 6$，加法不会溢出。
5. **取模位置**：每次累加后立即 `% MOD`。虽然单次累加 $\le 2 \times (10^9{+}6)$ 不溢 `long long`，但内层循环不加取模地累到第 11 项时和可达 $1.1 \times 10^{10}$，已经超出 `int`——用 `long long` 累加器与「每次取模」双保险最稳。
6. **特判 $s[0] = 0$**：约束保证不会出现，但通用实现中 $dp[0]$ 会自然为 $0$，无需额外分支。

## 5. 正确性证明

**引理 1（切分与合法数组一一对应）**：$s$ 的切分（把 $n$ 个字符依序切成非空连续段）与「能打印出 $s$ 的整数数组」一一对应；切分合法当且仅当每段无前导零且数值 $\in [1, k]$。

**证明**：数组元素按顺序拼接即得 $s$，故数组给出切分；反之切分的每段按值还原为数组元素，拼接还原 $s$。数值范围条件 $1 \le \text{val} \le k$ 等价于「$\le k$ 且无前导零」（无前导零且非空段的值 $\ge 1$；有前导零的段值可能落在范围内但违反题目约束，故合法性必须同时要求二者）。∎

**引理 2（不重不漏的分类）**：$s[i..n-1]$ 的合法切分集合，按首段末位置 $j \in [i, n-1]$ 划分为互不相交的子集，且每个子集的大小恰为「$s[i..j]$ 合法条件下 $s[j+1..n-1]$ 的合法切分数」。

**证明**：每个切分有唯一的首段（第一段的末位置 $j$ 唯一），故子集互不相交且并为全集。首段确定为 $s[i..j]$ 后，切分的其余部分恰是 $s[j+1..n-1]$ 的一个合法切分，且二者独立组合——拼接后每段仍合法（各段条件逐段满足，与拼接顺序无关）。∎

**定理（递推正确）**：设 $dp[n] = 1$、$dp[i] = \sum_{s[i..j] \text{ 合法}} dp[j+1]$，则 $dp[i]$ 等于 $s[i..n-1]$ 的合法切分数，答案 $dp[0]$ 正确。

**证明**：对 $i$ 从 $n$ 到 $0$ 归纳。$i = n$：空后缀恰一种「空切分」，$dp[n] = 1$ ✓。设对更大的下标成立。由引理 2，$s[i..n-1]$ 的切分数 $= \sum_j \#\{$首段为 $s[i..j]$ 的切分$\} = \sum_{j \text{ 合法}} dp[j+1]$（首段不合法时该子集为空），由归纳假设右边即递推式。∎

**推论（截断无损）**：递推中内层循环在 $\text{val} > k$ 时终止不漏计任何合法项。

**证明**：段无前导零时 $\text{val}(s[i..i]) \ge 1$，且每延伸一位 $\text{val}' = 10\,\text{val} + d \ge 10\,\text{val} > \text{val}$（$\text{val} \ge 1$），故 $\text{val}$ 关于 $j$ 严格递增；一旦 $> k$，其后所有更长段均 $> k$ 不合法，被跳过的项全为空集。∎

## 6. 复杂度分析

- **时间**：$O(n \cdot D)$，$D = \min(n, \mathrm{len}(k) + 1) \le 11$。每个位置至多延伸 11 个候选段；$n = 10^5$ 时约 $1.1 \times 10^6$ 次基本操作。
- **空间**：$O(n)$。$dp$ 数组长度 $n + 1$；内层 `val` 等为常数个变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int numberOfArrays(string s, int k) {
        const long long MOD = 1e9 + 7;
        int n = s.size();
        vector<long long> dp(n + 1, 0);
        dp[n] = 1;                               // dp[i]：s[i..n-1] 的拆分方案数
        for (int i = n - 1; i >= 0; --i) {
            if (s[i] == '0') continue;           // 前导零限制：0 不能作段首
            long long val = 0;
            for (int j = i; j < n; ++j) {
                val = val * 10 + (s[j] - '0');
                if (val > k) break;               // 更长的段只会更大
                dp[i] = (dp[i] + dp[j + 1]) % MOD;
            }
        }
        return (int)dp[0];
    }
};
```

### Python

```python
class Solution:
    def numberOfArrays(self, s: str, k: int) -> int:
        MOD = 10 ** 9 + 7
        n = len(s)
        dp = [0] * (n + 1)
        dp[n] = 1                                # dp[i]：s[i..n-1] 的拆分方案数
        for i in range(n - 1, -1, -1):
            if s[i] == '0':
                continue                          # 前导零限制：0 不能作段首
            val = 0
            for j in range(i, n):
                val = val * 10 + int(s[j])
                if val > k:
                    break                        # 更长的段只会更大
                dp[i] = (dp[i] + dp[j + 1]) % MOD
        return dp[0]
```

> 💡 两份代码均通过官方示例（`1`、`0`、`8`）与题面补充示例（`2020, 30 → 1`、`1234567890, 90 → 34`）；另与「递归枚举全部切分」的暴力对拍 $3000$ 组随机（含 $k = 1$、$10^9$ 极值与含大量零的串），`mismatch = 0`；并在 $|s| = 10^5$ 的四个极端串（全 9、`1` 后全 0、`1234567890` 循环、全 1）上完成 C++/Python 交叉验证一致。

## 8. 边界情况与易错点

1. **段首为 `0` 直接清零**：`s[i] == '0'` 时 $dp[i] = 0$，这是「无前导零」的唯一入口；漏掉它会把 `020` 这类段计入。
2. **`k = 10^9` 恰有 10 位**：段长 10 且值恰为 $10^9$ 时合法（$= k$），`val > k` 用严格大于，别写 `>=`。
3. **溢出**：`val` 单次更新上界 $10^{10} + 9$，必须 `long long`；`dp` 累加若不取模，11 项 $\times (10^9 + 6)$ 约 $1.1 \times 10^{10}$ 也超 `int`。
4. **取模忘了对 $10^9+7$**：题目要求取模，答案可能极大（全 9 串的方案数天文数字），样例小数据测不出漏取模，务必养成每次累加即取模的习惯。
5. **`dp[n] = 1` 别写成 0**：空后缀的「空切分」恰是一种方案，是所有边界转移的锚点。
6. **break 与 continue 的位置**：越界 break 只能出现在内层；外层遇到 `0` 是 continue（跳过该起点）而非 break（后者会错误终止整个 DP）。
7. **前缀/后缀方向别混**：倒序 DP 转移到 $dp[j+1]$（$j \ge i$，已算好）；若写成 $dp[j]$ 会引用未初始化值。
8. **大样例性能**：`string::substr` + `stoll` 的写法虽正确但每次 $O(\text{len})$ 建串，$10^5 \times 10$ 也勉强能过；增量累值 `val = val*10 + d` 是更稳的写法。
