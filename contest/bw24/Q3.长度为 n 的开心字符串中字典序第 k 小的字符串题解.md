# LeetCode 长度为 n 的开心字符串中字典序第 k 小的字符串 题解

## 1. 题目概述

- **标题 / 题号**：长度为 n 的开心字符串中字典序第 k 小的字符串（#1415，medium）
- **链接**：https://leetcode.cn/problems/the-k-th-lexicographical-string-of-all-happy-strings-of-length-n/
- **来源**：LeetCode 第 24 场双周赛 Q3
- **难度**：中等
- **标签**：字符串、回溯

**题意**：「开心字符串」指仅由 `a`、`b`、`c` 组成、且**相邻两个字符互不相同**的字符串。把所有长度为 $n$ 的开心字符串按**字典序**排序，返回第 $k$ 个；若总数不足 $k$ 个，返回空串。

**约束**：

- $1 \le n \le 10$
- $1 \le k \le 100$

**约束解读**：长度 $n$ 的开心字符串共 $3 \cdot 2^{n-1} \le 1536$ 个，全部生成再排序也能过；但「字典序第 $k$ 小」这一问法天然适合**按字典序 DFS + 子树计数整块跳过**，$O(n)$ 直达答案，是把规模推到 $n = 10^{18}$ 也不怕的正解。

## 3. 解题思路

### 3.1 暴力思路

按字典序 DFS 生成全部 $3 \cdot 2^{n-1}$ 个开心字符串，边生成边计数，数到第 $k$ 个输出。时间 $O(k \cdot n)$（其实生成到第 $k$ 个即可停），$n \le 10$、$k \le 100$ 时毫无压力；`itertools.product` 过滤再排序的写法是 $O(3^n \cdot n)$，同样能过。本题数据弱，暴力即正解；但「全生成」在 $n$ 变大时指数爆炸，掌握下述计数跳块才是这类题的通用钥匙。

### 3.2 核心观察：固定前缀后的「完成数」是 2 的幂

![计数树：首字符 3 个分支，其后每层 2 个分支，子树大小为 2 的幂](images/bw24_q3_counting_tree.svg)

把开心字符串的构造看成一棵树：根是空串，第 $i$ 层的每个节点有若干孩子（第 1 位可选 `a`/`b`/`c` 共 3 个；之后每位只能选与前一字符**不同**的 2 个）。**关键观察**：固定一个合法前缀 $p$（长 $i$）后，补全剩余 $L = n - i$ 位的方案数**与前缀内容无关**：

- $L = 0$：恰好 $1$ 个（前缀本身）；
- $L \ge 1$：每一位恰有 $2$ 种选择（不能与前一位相同），共 $2^{L-1}$ 个。

于是一位一位定答案：站在位置 $i$（前缀已定），候选字符按 `a`、`b`、`c` 枚举（跳过与前缀末位相同者），**每个候选字符「管辖」恰好 $2^{n-i-1}$ 个字符串**，且这些块按字典序连续排列。

### 3.3 算法流程：整块跳过

```text
per = 2^(n−1)                    # 位置 0 每个候选字符的完成数
若 k > 3 × 2^(n−1)：返回 ""      # 总数不足
ans = ""
for i = 0 .. n−1:
    for c in {'a','b','c'}（跳过 c == ans 末位）:
        若 k > per：k −= per；continue     # 整块跳过
        ans += c；break                    # 落在本块内
    per = per / 2                          # 剩余位数减一，块大小减半
返回 ans
```

正确性的直觉：字典序 = 「先按首字符分块，块内再按第二字符分块……」，每块大小已知，$k$ 落在哪块一目了然；块内问题规模缩小一位后完全同构。与「全生成后取第 $k$ 个」结果一致（§5 证明）。

### 3.4 示例演算

![示例演算：n=3, k=9 逐位跳块定位到 cab](images/bw24_q3_example_walkthrough.svg)

**演算**（$n = 3$，$k = 9$；总数 $3 \cdot 2^2 = 12$，$k \le 12$）：

| 位置 | per（块大小） | 候选 | 判定 | k 更新 | ans |
|------|----------------|------|------|--------|-----|
| 0 | 4 | `a`(4), `b`(4), `c`(4) | $9 > 4$ 跳 a，$5 > 4$ 跳 b，$1 \le 4$ 落 c | $9 \to 5 \to 1$ | `c` |
| 1 | 2 | `a`(2), `b`(2) | $1 \le 2$ 落 a | $1$ | `ca` |
| 2 | 1 | `b`(1), `c`(1) | $1 \le 1$ 落 b | $1$ | `cab` |

与示例 3 的列表对照：`c` 开头的块是第 9–12 名，`ca` 是其中前 2 名，`cab` 是第 9 名 ✓。

**$k$ 超界的判定**（示例 2/4）：$n = 1$ 时总数 $3 < 4$；$n = 2$ 时总数 $6 < 7$，直接返回 `""`。

## 4. 算法细节

1. **per 的初值与更新**：进入位置 $i$ 时 `per = 2^(n-1-i)`。初值 $2^{n-1}$ 用移位 `1 << (n-1)` 计算，每下一位 `per >>= 1`，末位恰好为 $1$。
2. **跳过前导候选时的减法顺序**：必须「先判 `k > per` 再减」，跳过整块后 $k$ 才是块内名次；判成 `k >= per` 会把块首元素错推到下一块。
3. **不变式保证不落空**：进入位置 $i \ge 1$ 时总有 $k \le 2 \cdot per$（上一位置落下时 $k \le per$，而新 per 减半），两个候选必有一个接住；位置 0 由前置的「$k \le 3 \cdot 2^{n-1}$」保证。
4. **`i > 0` 才跳过相同字符**：位置 0 无前驱，三个候选全部合法，`ans` 为空时不能调用 `ans.back()`（C++ 空串调用 `back()` 是未定义行为）。
5. **两种解法的关系**：全生成版 $O(3 \cdot 2^{n-1} \cdot n)$，计数跳块版 $O(3n)$；后者把「生成再选」变成「边数边走」，是字典序第 $k$ 小类问题的标准范式（同 [第 k 个排列](https://leetcode.cn/problems/permutation-sequence/)）。

## 5. 正确性证明

**引理 1（完成数）**：设 $p$ 是长度 $i$ 的合法前缀（相邻字符不同），则恰有 $2^{n-i}$ 个长度为 $n$ 的开心字符串以 $p$ 为前缀（$i < n$）。

**证明**：记 $C(L)$ 为「已固定前缀、还需追加 $L$ 位」的补全方案数。$C(0) = 1$（前缀即成品）。追加的下一位只需与**前一位**不同，恰有 $2$ 种选择，且选择数只依赖前一位是哪个字符、与前缀更早的历史无关，故 $C(L) = 2\,C(L-1)$，解得 $C(L) = 2^L$。取 $L = n - i$ 即得断言。进一步地，位置 $i$ 的**每个候选字符** $c$（与前缀末位不同）先消耗 1 位、剩 $n-i-1$ 位待补，故其管辖的完成数为 $2^{n-i-1}$（$i = n-1$ 时为 $2^0 = 1$）。完成数只由「还剩几位」决定，与具体前缀无关——这正是整块跳块可行的根基。∎

**引理 2（块连续且按字典序排列）**：位置 $i$ 处按候选字符 $c_1 < c_2 < c_3$（跳过与前缀末位相同者）生成的三（或二）块字符串，每块内部与块与块之间都按字典序连续排列，且第 $c_j$ 块全体小于第 $c_{j+1}$ 块全体。

**证明**：块内所有字符串前 $i+1$ 位相同（前缀 $p + c_j$），其后位的比较即块内字典序，与逐位生成的顺序一致；块间首不同位是第 $i+1$ 位，$c_j < c_{j+1}$ 使第 $c_j$ 块任意串小于第 $c_{j+1}$ 块任意串。∎

**定理（跳块定位正确）**：算法返回的字符串恰为字典序第 $k$ 小的开心字符串；若 $k > 3 \cdot 2^{n-1}$ 返回空串。

**证明**：对位置 $i$ 归纳，维护不变式：「前缀 $ans$ 已定，$k$ 是以 $ans$ 为前缀的开心字符串中的第 $k$ 小」。由引理 1、2，位置 $i$ 的候选块大小均为 $per = 2^{n-i-1}$ 且按字典序排布：若 $k > per$，第 $k$ 小不在当前候选块，跳过并令 $k$ 减 $per$ 后对下一候选块保持不变式；若 $k \le per$，第 $k$ 小在当前块内，固定该字符、$per$ 减半，进入位置 $i+1$ 时不变式仍成立（块内名次即新前缀意义下的名次）。由细节 3 的不变式 $k \le$ 候选数 $\times\ per$，循环内必有候选接住。终止时 $i = n$，前缀即完整字符串，$k = 1$（$per = 1$ 时 $k \le 1$），恰为该前缀本身——第 $k$ 小。前置判断 $k > 3 \cdot 2^{n-1}$ 时无解，返回空串正确。∎

## 6. 复杂度分析

- **时间**：$O(3n)$。每个位置至多枚举 3 个候选字符，做一次减法与比较；$n \le 10$ 时即常数级（对比全生成的 $O(3 \cdot 2^{n-1} \cdot n)$）。
- **空间**：$O(n)$ 存答案字符串（不计输出则 $O(1)$）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    string getHappyString(int n, int k) {
        int per = 1;
        for (int i = 1; i < n; ++i) per <<= 1;    // per = 2^(n-1)：每个首字符下的完成数
        if (k > 3 * per) return "";              // 总数 3·2^(n-1) 不够 k 个
        string ans;
        for (int i = 0; i < n; ++i) {
            for (char c = 'a'; c <= 'c'; ++c) {
                if (i > 0 && c == ans.back()) continue;   // 不能与前一个字符相同
                if (k > per) { k -= per; continue; }      // 整块跳过
                ans.push_back(c);
                break;
            }
            per >>= 1;                           // 剩余长度减一，完成数减半
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def getHappyString(self, n: int, k: int) -> str:
        per = 1 << (n - 1)                       # 每个候选字符下的完成数 2^(n-1)
        if k > 3 * per:
            return ""                           # 总数 3·2^(n-1) 不够 k 个
        ans = []
        for i in range(n):
            for c in "abc":
                if i > 0 and c == ans[-1]:       # 不能与前一个字符相同
                    continue
                if k > per:                      # 整块跳过
                    k -= per
                    continue
                ans.append(c)
                break
            per //= 2                            # 剩余长度减一，完成数减半
        return "".join(ans)
```

> 💡 两份代码均通过官方示例（`"c"`、`""`、`"cab"`）与题面补充示例（$n{=}2,k{=}7$ 返回空串、$n{=}10,k{=}100$ 返回 `abacbabacb`）；另与「全生成 + 排序」暴力对拍 $n \in [1,10] \times k \in [1,12]$ 全组合，`mismatch = 0`。

## 8. 边界情况与易错点

1. **$k$ 超过总数**：总数是 $3 \cdot 2^{n-1}$ 而不是 $3^n$（相邻不同的约束砍掉了 $\frac{2}{3}$ 的分支）；先判界再进循环，否则循环内可能出现「两个候选都被跳过、`ans` 缺字符」的静默错误。
2. **$n = 1$**：`per = 1`，三个候选各管 1 个串；$k \le 3$ 时直接命中，注意 `per >>= 1` 后变 0 但循环已结束，无影响。
3. **空串调用 `back()`**：C++ 中 `i > 0 && c == ans.back()` 的短路顺序不能颠倒，`ans` 为空时先调用 `back()` 是未定义行为。
4. **跳块条件是严格大于**：`k > per` 才跳；`k == per` 时正好是当前块的最后一个，必须留在本块。
5. **`per` 的减半时机**：在**选定字符之后**（进入下一位置之前）减半；若在候选循环里减半会把块大小算错一位。
6. **字典序就是候选枚举序**：`for c in "abc"` 按 ASCII 升序枚举即字典序；若手滑写成 `cba` 整个定位全反。
7. **返回类型**：无解时返回空串 `""` 而非 `None`/`"-1"`。

**延伸思考**：本题的「每个候选块大小恒为 $2^{n-i-1}$」依赖于**计数与历史无关**（均匀性）。把字符集推广到 $\Sigma$ 个字母、相邻不同的约束不变，块大小变为 $(|\Sigma|-1)^{n-i-1}$，做法逐字照搬；若约束改为「相邻 $k$ 位互不相同」（$k$-happy），完成数将依赖前 $k-1$ 位的排列，需要用状态压缩 DP 预计算每层的前缀计数——这正是 [LeetCode 1416](https://leetcode.cn/problems/restore-the-array/) 一类「按位分段 + 计数」思想在字典序定位上的推广。
