# LeetCode 和为 K 的最少斐波那契数字数目 题解

## 1. 题目概述

- **标题 / 题号**：和为 K 的最少斐波那契数字数目（#1414，medium）
- **链接**：https://leetcode.cn/problems/find-the-minimum-number-of-fibonacci-numbers-whose-sum-is-k/
- **来源**：LeetCode 第 24 场双周赛 Q2
- **难度**：中等
- **标签**：贪心、数学

**题意**：斐波那契数定义为 $F_1 = F_2 = 1$、$F_n = F_{n-1} + F_{n-2}$。给定 $k$，求**和恰为 $k$** 的斐波那契数字最少用几个（同一数字可重复使用）。

**约束**：

- $1 \le k \le 10^9$

**约束解读**：$k$ 高达 $10^9$，任何 $O(k)$ 的 DP 都不可行；但 $\le 10^9$ 的斐波那契数只有约 $44$ 个（$F_{45} \approx 1.1 \times 10^9$），提示从数的特殊结构入手。

## 2. 示例

**示例 1**

```text
输入：k = 7
输出：2
解释：7 = 2 + 5。
```

**示例 2**

```text
输入：k = 10
输出：2
解释：10 = 2 + 8。
```

**示例 3**

```text
输入：k = 19
输出：3
解释：19 = 1 + 5 + 13。
```

## 3. 解题思路

### 3.1 暴力思路

把「$\le k$ 的斐波那契数」当成**完全背包**物品（每个可无限次使用），求凑出 $k$ 的最少物品数：$f(j) = \min_{F_i \le j} \big(1 + f(j - F_i)\big)$，$O(k \cdot 44)$，$k = 10^9$ 时时间与空间双双爆炸。换「从大到小贪心」的直觉：每次拿走**不超过剩余值的最大斐波那契数**，不断减小剩余值。贪心是否最优？本篇的核心就是给出严格证明——贪心得到的恰好是 $k$ 的**齐肯多夫表示**（Zeckendorf 表示：互不相同且下标不相邻的斐波那契数之和），而它就是最优方案。

### 3.2 核心观察一：贪心产出的数「严格降级」

![贪心模型：每次取不超过剩余值的最大斐波那契数，剩余值急剧缩小](images/bw24_q2_greedy_model.svg)

设 $F_m$ 是不超过当前剩余值 $x$ 的最大斐波那契数。由 $x < F_{m+1} = F_m + F_{m-1}$ 得

$$x - F_m < F_{m-1}.$$

也就是说：**贪心一步后，剩余值立即降到比 $F_{m-1}$ 还小**。下一个能取的数至多是 $F_{m-2}$。于是贪心取出的序列下标 $m_1 > m_2 > \dots$ 每步**至少跳过一级**——既不重复，也永不相邻。这正是齐肯多夫表示的形态；配合齐肯多夫定理（该表示**存在且唯一**），贪心的输出被完全确定。

### 3.3 核心观察二：允许重复的「最优解」其实用不上重复

题目允许重复使用，但贪心天然不重复。要证明「不重复的齐肯多夫表示」在允许重复的世界里依然最优，思路是**归一化**：任取一个最优表示，反复应用三条「不增项数」的改写规则，把它变成齐肯多夫表示。规则如下（以值写出）：

![归一化规则：相等/相邻的斐波那契数不断合并，项数不增](images/bw24_q2_normalization_rules.svg)

- **R1**（两个 1）：$1 + 1 = 2 = F_3$，两项并一项；
- **R2**（相邻和）：$F_i + F_{i+1} = F_{i+2}$（$i \ge 2$），两项并一项；
- **R3**（相等对）：$F_i + F_i = F_{i+1} + F_{i-2}$（$i \ge 3$，验证 $2F_i = F_{i+1} + F_{i-2}$），项数不变、但「向两端散开」。

每条规则的**项数都不增**，且带一个严格递减的势函数（见引理 4），因此归一化必终止；终止态中既无相等对也无相邻对——恰好是齐肯多夫形式。于是任何表示的项数 $\ge$ 齐肯多夫项数，贪心最优。

### 3.4 算法流程与示例演算

```text
1. 生成所有 ≤ k 的斐波那契数 fib = [1, 1, 2, 3, 5, …, F_t]（F_t ≤ k < F_{t+1}）
2. ans = 0
3. while k > 0:
       从大到小弹出 fib 尾部，直到 fib 末项 ≤ k   # 不超过 k 的最大斐波那契数
       k −= fib 末项
       ans += 1
4. 返回 ans
```

由于贪心取数严格降级（§3.2），$k$ 每步至少「砍掉一个量级」，循环次数 $\le \log_\varphi k \approx 44$ 次。

![示例演算：k=19 依次取 13、5、1，共 3 项](images/bw24_q2_example_walkthrough.svg)

**演算**（$k = 19$）：斐波那契数 $1, 1, 2, 3, 5, 8, 13, 21$。取 $\le 19$ 的最大者 $13$，余 $6$；取 $\le 6$ 的最大者 $5$，余 $1$；取 $1$，余 $0$。共 $3$ 项：$19 = 13 + 5 + 1$，下标 $7, 5, 2$（或 $1$）互不相邻 ✓，正是齐肯多夫表示。

**$k = 7$**：取 $5$ 余 $2$，取 $2$ 余 $0$，共 $2$ 项；**$k = 10$**：取 $8$ 余 $2$，取 $2$，共 $2$ 项。

## 4. 算法细节

1. **斐波那契表只需生成一次**：$F_{45} = 1134903170 > 10^9 \ge F_{44} = 701408733$，表长 $\le 45$；用 `long long` 生成，避免最后一个溢出。
2. **取最大值用「尾部弹出」**：表本身升序，末尾就是最大的候选；`while (fib.back() > k) pop` 之后末项即所求，总弹出次数均摊 $O(\log k)$。
3. **$k = 1$ 与 $k = 2$ 的走查**：$k=1$ 直接取一个 $1$；$k=2$ 取 $2$（一步）——注意表里 $2$ 排在两个 $1$ 之后，尾部弹出逻辑天然先见到 $2$。
4. **贪心的两种等价实现**：递归「每次重新扫表找最大」是 $O(\log^2 k)$，也完全够用；本实现为 $O(\log k)$。
5. **不要用浮点黄金比例**：用 $\varphi$ 的闭式 $F_n \approx \varphi^n / \sqrt 5$ 判断边界有精度风险，老老实实递推加法。

## 5. 正确性证明

记斐波那契数 $F_1 = F_2 = 1$、$F_n = F_{n-1} + F_{n-2}$。为避免 $F_1, F_2$ 同值带来的下标歧义，**约定表示中只使用下标 $\ge 2$ 的项**（值 $1$ 一律记作 $F_2$）。称「各项下标互不相同、且任意两项下标之差 $\ge 2$（互不相邻）」的表示为**齐肯多夫表示**。

**引理 1（贪心产出齐肯多夫形式）**：贪心取出的项下标严格递减且两两不相邻。

**证明**：归纳。设当前剩余 $x$，取 $F_m \le x < F_{m+1}$，则新剩余 $x' = x - F_m < F_{m+1} - F_m = F_{m-1}$。于是后续取出的项均 $\le F_{m-2}$：与 $F_m$ 既不相等（更小）也不相邻（下标差 $\ge 2$）。对 $x'$ 递归即得全局结论；且值 $1$ 由 $F_2$ 提供符合约定。∎

**引理 2（两个交替和恒等式）**：对 $k \ge 1$ 有

$$F_2 + F_4 + \cdots + F_{2k} = F_{2k+1} - 1, \qquad F_1 + F_3 + \cdots + F_{2k-1} = F_{2k}.$$

**证明**：对 $k$ 归纳。$k=1$：$F_2 = 1 = F_3 - 1$ ✓，$F_1 = 1 = F_2$ ✓。设对 $k$ 成立，则 $F_2 + \cdots + F_{2k+2} = (F_{2k+1} - 1) + F_{2k+2} = F_{2k+3} - 1$ ✓；$F_1 + \cdots + F_{2k+1} = F_{2k} + F_{2k+1} = F_{2k+2}$ ✓。∎

**引理 3（齐肯多夫表示存在且唯一）**：每个正整数 $k$ 恰有一个（下标 $\ge 2$ 约定下的）齐肯多夫表示。

**证明**：存在性：贪心终止时给出和为 $k$ 的齐肯多夫形式（引理 1）。唯一性：反证，设 $S \ne T$ 为两个齐肯多夫表示，消去公共项后两边仍相等且不含公共项；设 $m$ 为剩余项的最大下标，不妨 $F_m \in S$、$F_m \notin T$。$T$ 的最大下标 $\le m-1$ 且各项不相邻，由引理 2（从 $m-1$ 开始每隔一级取一项，恰为交替和的全集）：

$$\sum T \le F_{m-1} + F_{m-3} + \cdots \le F_m - 1,$$

（$m-1$ 为偶数时末项 $F_2$，和恰为 $F_m - 1$；$m-1$ 为奇数时末项 $F_3$，和为 $(F_1 + F_3 + \cdots + F_{m-1}) - F_1 = F_m - 1$。）而 $\sum S \ge F_m > F_m - 1$，两表示相等矛盾。∎

**引理 4（归一化规则）**：以下改写规则保持总和、不增项数：

- **R1**：$F_2 + F_2 = F_3$（两个 $1$ 并成 $2$，项数减一）；
- **R2**：$F_i + F_{i+1} = F_{i+2}$（相邻合并，$i \ge 2$，项数减一）；
- **R3**：$F_i + F_i = F_{i+1} + F_{i-2}$（相等对拆开，$i \ge 3$，验证 $2F_i = F_{i+1} + F_{i-2}$，项数不变）。

**证明**：R1、R2 即递推式；R3 由 $F_{i+1} + F_{i-2} = F_i + F_{i-1} + F_{i-2} = F_i + F_i$ 直接验证。三条规则均不增加项数。∎

**引理 5（归一化终止）**：任取一个表示反复应用 R1–R3，过程必在有限步内终止。

**证明**：取势函数 $\Phi = \sum \text{各项下标}$（非负整数）。逐一核算：

- R1：$2 + 2 = 4 \to 3$，$\Phi$ 减一；
- R2（$i \ge 2$）：$2i + 1 \to i + 2$，$\Phi$ 减少 $i - 1 \ge 1$；
- R3（$i \ge 4$）：$2i \to (i+1) + (i-2) = 2i - 1$，$\Phi$ 减一；
- R3（$i = 3$，即两个 $2$ 拆成 $3 + 1$）：$6 \to 4 + 2 = 6$，$\Phi$ **不变**——唯一的平衡规则。

于是除「两个 $F_3$」外所有规则都严格减小 $\Phi$，而 $\Phi$ 是非负整数，严格递减的步数有限。再看平衡规则：它每触发一次**消耗两个 $F_3$、不产生任何 $F_3$**；而产生 $F_3$ 的规则只有 R1（两个 $F_2$）与 R3 的 $i = 5$ 情形（两个 $F_5 \to F_6 + F_3$），二者都严格减小 $\Phi$，只能发生有限次。故 $F_3$ 的总产生量有限，平衡规则也只能触发有限次。所有步骤合计有限，过程终止。∎

**定理（贪心最优）**：贪心取出的项数等于和为 $k$ 的最少斐波那契数字数目。

**证明**：设 $R$ 为任意一个和为 $k$ 的（允许重复的）表示，对其应用引理 4 的规则直到终止（引理 5 保证）。终止态中：无相等对（否则 R1 或 R3 可用）、无相邻对（否则 R2 可用）——恰为齐肯多夫形式；由引理 3 它与贪心输出**逐项相同**。整个过程项数不增，故 $|R| \ge$ 终止态项数 $=$ 贪心项数；又贪心输出本身合法，故贪心项数即最小值。∎

**推论（重复无益）**：最优表示中不存在重复项——「可重复使用」的放宽条件不影响答案。

## 6. 复杂度分析

- **时间**：$O(\log_\varphi k)$ 生成斐波那契表（约 $44$ 项），贪心取数次数不超过表长（每项至多被弹出一次），总计 $O(\log k)$。
- **空间**：$O(\log k)$ 存储斐波那契表，约 $45$ 个 `long long`。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int findMinFibonacciNumbers(int k) {
        vector<long long> fib = {1, 1};
        while (fib.back() <= k)                   // 预生成 ≤ k 的斐波那契数
            fib.push_back(fib[fib.size() - 1] + fib[fib.size() - 2]);
        int ans = 0;
        while (k > 0) {
            while (fib.back() > k) fib.pop_back();// 弹到不超过 k 的最大斐波那契数
            k -= (int)fib.back();                 // 贪心：大数优先
            ++ans;
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def findMinFibonacciNumbers(self, k: int) -> int:
        fib = [1, 1]
        while fib[-1] <= k:                       # 预生成 ≤ k 的斐波那契数
            fib.append(fib[-1] + fib[-2])
        ans = 0
        while k > 0:
            while fib[-1] > k:                   # 弹到不超过 k 的最大斐波那契数
                fib.pop()
            k -= fib[-1]                          # 贪心：大数优先
            ans += 1
        return ans
```

> 💡 两份代码均通过官方示例（`2`、`2`、`3`）；另与完全背包 DP 暴力对拍 $k = 1 \sim 600$ **全量核对**、$300$ 组随机 $k \in [1, 10^9]$ 与 C++/Python 交叉一致，`mismatch = 0`。

## 8. 边界情况与易错点

1. **$k = 1$ 与 $k = 2$**：分别取一个 $1$、一个 $2$；表里 $2$ 之前有两个 $1$，注意生成顺序（`fib = {1, 1}` 起步）别漏第二个 $1$ 导致 $k=1$ 死循环。
2. **生成终止条件**：`while (fib.back() <= k)` 停在第一个 $> k$ 的项，或直接生成到 $> k$ 为止——两种写法等价，但要保证**弹出逻辑**对应的表非空（$k \ge 1$ 时表至少有 $1$）。
3. **溢出**：$F_{45} > 10^9$ 已超 `int`，生成时用 `long long`；减法处 `(int)fib.back()` 已保证 $\le k$。
4. **贪心别「每次从头扫」**：写成「每步线性找最大」仍正确（$O(\log^2 k)$），但尾部弹出更优雅；反过来若把弹出条件写成 `>=` 会把恰等于 $k$ 的项也弹掉，死循环。
5. **「可重复使用」的干扰**：不要因为题目允许重复就往重复方向构造（如 $4 = 2+2$ 两项，其实 $4 = 3+1$ 也两项，齐肯多夫形式即 $3+1$）；证明表明重复无增益。
6. **两处下标歧义**：$F_1 = F_2 = 1$。证明里把值 $1$ 统一记作 $F_1$（势函数才能严格递减），代码里保留两个 $1$ 不影响结果——$k$ 减去 $1$ 时无论哪个都一样。
