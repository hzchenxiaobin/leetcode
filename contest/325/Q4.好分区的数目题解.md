# LeetCode 好分区的数目 题解

## 1. 题目概述

- **标题 / 题号**：好分区的数目（#2518，hard）
- **链接**：https://leetcode.cn/problems/number-of-great-partitions/
- **来源**：LeetCode 第 325 场周赛 Q4
- **难度**：困难
- **标签**：数组、动态规划、0-1 背包、计数、容斥原理

**题意**：给定正整数数组 `nums` 和整数 $k$。**分区** = 把数组划分成两个**有序**的组，每个元素恰好属于其中一个组。若分区中**每个组**的元素和都 $\ge k$，则称为**好分区**。返回不同好分区的数目，对 $10^9+7$ 取余。两个分区不同 $\iff$ 存在某元素 `nums[i]` 被分在不同的组中。

**约束**：

- $1 \le \text{nums.length},\ k \le 1000$
- $1 \le \text{nums}[i] \le 10^9$

> 💡 **读题关键**：①「有序组」$\Rightarrow$ 每个元素独立二选一，总分区数恰为 $2^n$，**不需要**除以 2 去重（示例 1 中 ([1,3],[2,4]) 与 ([2,4],[1,3]) 算两种）；② 判定条件是「**两侧同时** $\ge k$」，交集直接数很难，但反面「至少一侧 $< k$」是两个对称的**小子集**事件；③ 元素值 $10^9$ 远大于 $k \le 1000$，而和 $< k$ 的组里装不下任何大元素 $\Rightarrow$ 背包容量只需 $k$。

## 2. 示例

**示例 1**

```text
输入：nums = [1,2,3,4], k = 4
输出：6
解释：好分区为 ([1,2,3],[4]), ([1,3],[2,4]), ([1,4],[2,3]), ([2,3],[1,4]), ([2,4],[1,3]), ([4],[1,2,3])。
      注意组是有序的：([1,3],[2,4]) 与 ([2,4],[1,3]) 是两个不同分区。
```

**示例 2**

```text
输入：nums = [3,3,3], k = 4
输出：0
解释：S = 9 ≥ 2k = 8，但任何分组总有一侧和 < 4。
      bad = 和 < 4 的子集数 = ∅、{3}、{3}、{3} 共 4 个，答案 = 2³ − 2×4 = 0。
```

**示例 3**

```text
输入：nums = [6,6], k = 2
输出：2
解释：6 ≥ k，大元素进不了「和 < k」的组 ⇒ bad = 1（仅空集）。
      答案 = 2² − 2×1 = 2：两个 6 分居两组的两种放法。
```

## 3. 解题思路

### 3.1 暴力思路：枚举每个元素的归属

每个元素独立选组 1 / 组 2，共 $2^n$ 种分区，逐个检验两组和是否都 $\ge k$。$n = 1000$ 时 $2^{1000}$ 是天文数字；退一步想直接 DP「好分区」，状态也得携带组 1 的和（可达 $1000 \times 10^9 = 10^{12}$）——值域爆炸，状态根本开不下。

> ⚠️ 暴力的根病在于正面硬刚「两侧约束」。一旦意识到**正难则反**——好分区 = 全部分区 − 坏分区，而坏分区只由「**某一侧**和 $< k$」决定，一个容量 $k$ 的小背包就能数完——问题就从 $10^{12}$ 的值域塌缩到 $k \le 1000$ 的背包。

### 3.2 核心观察：正难则反 + 对称容斥

![核心观察：sum₁ 轴上两个对称的坏尾巴](images/2518_complement_counting_concept.svg)

把每个分区等同于「组 1 的元素子集」，只盯 $\text{sum}_1$（组 1 的元素和），记 $S = \sum \text{nums}[i]$：

1. **必要条件**：好分区要求 $\text{sum}_1 \ge k$ 且 $\text{sum}_2 = S - \text{sum}_1 \ge k$，相加得 $S \ge 2k$。故 **$S < 2k$ 直接返回 0**。
2. **总数**：$n$ 个元素各自独立二选一，总分区数 $= 2^n$。
3. **反面**：坏分区 = 「$\text{sum}_1 < k$」**或**「$\text{sum}_2 < k$」。前者恰好是「组 1 是一个和 $< k$ 的子集」，记这样的子集共 $\text{bad}$ 个。
4. **对称性**：交换两组标签是全体分区上的双射，把「组 1 和 $< k$」的分区一一映到「组 2 和 $< k$」的分区 $\Rightarrow$ 两类坏分区**各为 bad 个**。
5. **不相交**：$S \ge 2k$ 时两类不可能同时发生（否则 $S = \text{sum}_1 + \text{sum}_2 < 2k$，矛盾），容斥无需减交集。

于是：

$$\text{答案} = 2^n - 2 \cdot \text{bad} \pmod{10^9+7}$$

> 💡 **bad 是什么**：$\text{bad} = $ 「子集和 $< k$」的子集个数 $= \sum_{j=0}^{k-1} dp[j]$，其中 $dp[j]$ 是**和恰好为 $j$** 的子集数——标准 **0-1 背包计数**。空集（组 1 为空，和 $0 < k$）是合法的坏分区，计入 $\text{bad}$；「组 2 为空」的坏分区由对称的另一侧计入，两侧各数一次，无重无漏。

### 3.3 算法流程：0-1 背包数「和 < k」的子集

![算法流程：判 S≥2k → 0-1 背包 → 容斥相减](images/2518_knapsack_dp_flow.svg)

1. 求总和 $S$（`long long`），若 $S < 2k$ 返回 $0$。
2. 0-1 背包计数：`dp[0..k-1]`，`dp[0] = 1`；对每个 $x \in \text{nums}$：若 $x \ge k$ 直接跳过；否则 $j$ 从 $k-1$ **倒序**到 $x$：$dp[j] \mathrel{+}= dp[j-x]$。
3. $\text{bad} = \sum_{j=0}^{k-1} dp[j] \bmod p$。
4. 返回 $(2^n - 2\,\text{bad} + p) \bmod p$（先 $+p$ 防负数）。

### 3.4 示例演算

![示例演算：dp 表逐轮推进](images/2518_dp_walkthrough.svg)

以示例 1 为例：`nums = [1,2,3,4]`，$k=4$，$S=10 \ge 2k$。`4 ≥ k` 被跳过，背包只跑 `1,2,3` 三轮：`dp` 从 `[1,0,0,0]` 依次推进到 `[1,1,1,2]`，$\text{bad} = 1+1+1+2 = 5$（对应子集 $\varnothing,\{1\},\{2\},\{3\},\{1,2\}$），答案 $= 2^4 - 2 \times 5 = 6$ ✓。6 个好分区的组 1 集合是 $\{4\},\{1,3\},\{1,4\},\{2,3\},\{2,4\},\{1,2,3\}$——和恰好落在 $[k, S-k] = [4,6]$ 内。

## 4. 算法细节

1. **早退判定放最前**：$S < 2k$ 时好分区不可能存在（引理 2），返回 0；这也保证了后续「两类坏事件不相交」的前提（引理 4）。
2. **dp 的定义域是 $[0, k-1]$**：$dp[j]$ 只对 $j < k$ 有意义，$\text{bad}$ 只累加到 $k-1$。和恰好为 $k$ 的子集做组 1 已是**合法**的（$\ge k$），多加一个 $dp[k]$ 会过度扣除。
3. **$x \ge k$ 的元素跳过**：元素全是正数，含 $x$ 的组之和 $\ge x \ge k$，永远进不了「和 $< k$」的组。跳过既是剪枝（$10^9$ 级元素不进背包），也彻底排除下标越界的可能。
4. **倒序遍历**：一维滚动数组的 0-1 背包惯例——倒序时 `dp[j-x]` 尚未被本轮更新，仍是「前 $i-1$ 个元素」的值，保证每个元素至多选一次；正序会把同一元素用两次（§3.4 演算图的 ⚠ 框给出了 `x=1` 时数出 $\{1,1\}$ 的反例）。
5. **$2^n$ 的计算**：边乘边取模迭代 $n$ 次（$n \le 1000$）或快速幂均可，**不要**写 `1 << n`（$n=1000$ 直接溢出）。
6. **取模安全**：C++ 的 `%` 结果符号跟随被除数，$2^n \bmod p - 2\,\text{bad}$ 可能为负，务必 `+MOD` 再取模。

## 5. 正确性证明

**引理 1（子集双射）**：全体分区与 $[n]$ 的全部子集之间存在双射：分区 $\mapsto$ 组 1 的元素集。从而总分区数为 $2^n$，且「$\text{sum}_1 < k$」的分区数 = 「和 $< k$」的子集数 $\text{bad}$。

**证明**：每个元素恰属一组，分区等价于每个下标的 $\{1,2\}$ 二选一；组 1 的元素集唯一确定该选择序列，反之亦然。组 1 元素集的和即 $\text{sum}_1$。∎

**引理 2（必要条件）**：若存在好分区，则 $S \ge 2k$。

**证明**：好分区中 $\text{sum}_1 \ge k$ 且 $\text{sum}_2 \ge k$，相加得 $S = \text{sum}_1 + \text{sum}_2 \ge 2k$。逆否即：$S < 2k \Rightarrow$ 好分区数为 0。∎

**引理 3（对称性）**：「$\text{sum}_1 < k$」的分区数 = 「$\text{sum}_2 < k$」的分区数 $= \text{bad}$。

**证明**：设 $\sigma$ 为交换两组标签的映射，它是全体分区上的对合双射，且把「$\text{sum}_1 < k$」的分区恰好映到「$\text{sum}_2 < k$」的分区（原组 2 变成新组 1，和随之互换）。双射保计数。∎

**引理 4（不相交）**：$S \ge 2k$ 时，不存在分区同时满足 $\text{sum}_1 < k$ 与 $\text{sum}_2 < k$。

**证明**：若同时成立，则 $S = \text{sum}_1 + \text{sum}_2 \le (k-1)+(k-1) < 2k$，与 $S \ge 2k$ 矛盾。∎

**引理 5（背包计数正确）**：按算法处理完前 $i$ 个元素后，对一切 $0 \le j \le k-1$：$dp[j] = $ 从前 $i$ 个元素中选出的、和恰好为 $j$ 的子集数。

**证明**：对 $i$ 归纳。$i = 0$ 时仅空集，$dp[0]=1$、其余为 0，成立。设第 $i$ 轮处理元素 $x$。若 $x \ge k$：数组不更新；而任何含 $x$ 的子集之和 $\ge x \ge k > j$（$j \le k-1$），故和 $\le k-1$ 的子集都不含 $x$，计数不变，命题保持。若 $x < k$：和为 $j$ 且含第 $i$ 个元素的「前 $i$ 个」子集 = $\{x\} \cup$ （前 $i-1$ 个元素中和为 $j-x$ 的子集），需 $j \ge x$。倒序遍历 $j$ 时 $dp[j-x]$ 尚未被本轮更新，由归纳假设恰为「前 $i-1$ 个元素中和为 $j-x$」的计数；更新后 $dp[j] = (\text{不含 } x) + (\text{含 } x)$ 即为前 $i$ 个元素的完整计数。∎

**定理**：算法返回好分区数模 $10^9+7$。

**证明**：若 $S < 2k$，由引理 2 好分区数为 0，算法返回 0。若 $S \ge 2k$：坏分区集 $= A_1 \cup A_2$，其中 $A_i$ 为「第 $i$ 组和 $< k$」的分区集。由容斥原理与引理 3、4：$|A_1 \cup A_2| = |A_1| + |A_2| - |A_1 \cap A_2| = \text{bad} + \text{bad} - 0$。由引理 1 总分区数为 $2^n$，故好分区数 $= 2^n - 2\,\text{bad}$；由引理 5，$\text{bad} = \sum_{j=0}^{k-1} dp[j]$ 计算无误。全程对 $10^9+7$ 取模且减法前补偿 $+p$，保持同余。∎

## 6. 复杂度分析

- **时间复杂度**：$O(nk)$。背包每个元素至多 $k$ 次转移（$x \ge k$ 的元素 $O(1)$ 跳过），$n, k \le 1000$ 时至多 $10^6$ 次转移；另有求和的 $O(n)$ 与计算 $2^n$ 的 $O(n)$（或快速幂 $O(\log n)$）。
- **空间复杂度**：$O(k)$。一维滚动数组 `dp[0..k-1]`，与 $n$ 及元素值域无关。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int countPartitions(vector<int>& nums, int k) {
        constexpr long long MOD = 1'000'000'007LL;
        long long S = accumulate(nums.begin(), nums.end(), 0LL);  // S ≤ 1e12，需 long long
        if (S < 2LL * k) return 0;                                // 两组和不可能都 ≥ k
        vector<long long> dp(k, 0);
        dp[0] = 1;                                                // 空集
        for (int x : nums) {
            if (x >= k) continue;           // 大元素进不了「和 < k」的组
            for (int j = k - 1; j >= x; --j)                    // 倒序：每个元素至多选一次
                dp[j] = (dp[j] + dp[j - x]) % MOD;
        }
        long long bad = 0;
        for (int j = 0; j < k; ++j) bad = (bad + dp[j]) % MOD;   // bad = Σ_{j<k} dp[j]
        long long total = 1;
        for (size_t i = 0; i < nums.size(); ++i) total = total * 2 % MOD;  // 2^n 边乘边取模
        return (int)((total - 2 * bad % MOD + MOD) % MOD);       // 先 +MOD 防负数
    }
};
```

### Python

```python
class Solution:
    def countPartitions(self, nums: List[int], k: int) -> int:
        MOD = 1_000_000_007
        if sum(nums) < 2 * k:
            return 0
        dp = [1] + [0] * (k - 1)          # dp[j] = 和恰好为 j 的子集数
        for x in nums:
            if x >= k:
                continue                  # 大元素进不了「和 < k」的组
            for j in range(k - 1, x - 1, -1):
                dp[j] = (dp[j] + dp[j - x]) % MOD
        bad = sum(dp) % MOD
        return (pow(2, len(nums), MOD) - 2 * bad) % MOD   # Python 的 % 恒非负
```

## 8. 边界情况与易错点

1. **$S < 2k$ 必须早退**：否则两类坏事件相交（组 1、组 2 同时 $< k$ 的分区被减两次），公式失效。反例 `nums = [1,1], k = 2`：真答案 0，不早退会算出 $2^2 - 2 \times 3 = -2$，取模后错成 $10^9+5$。
2. **负数取模**：C++ 的 `%` 符号跟随被除数，`(2^n − 2·bad) % p` 可能为负，先 `+MOD` 再 `%`；Python 的 `%` 恒非负可省心。
3. **bad 只累加 $j \in [0, k-1]$**：「和 $= k$」的组 1 已满足 $\ge k$，把它算进坏分区会多扣。
4. **空集要计入 bad**：`dp[0] = 1` 对应「组 1 为空」（和 $0 < k$，天然坏）；它不与任何东西重复——「组 2 为空」由对称侧的 bad 计数。
5. **溢出**：$S \le 1000 \times 10^9 = 10^{12}$ 超 32 位；`2 * bad` 也逼近 $2 \times 10^9$，C++ 统一用 `long long` 最稳。
6. **不要除以 2**：两组**有序**，$2^n$ 就是总分区数；把答案除 2 或改用组合数 $\binom{n}{i}$ 都会错（示例 1 明确把两种顺序都列出）。
7. **`1 << n` 溢出**：$n$ 到 1000，幂必须边乘边取模（或快速幂）。
8. **两个方向都要减**：只减一个 bad（忘记对称性）会把答案偏大一倍。
9. **正序背包**：`j` 正序遍历会让 `dp[j-x]` 混入本轮更新，同一元素被重复使用（`x=1` 时数出 $\{1,1\}$），bad 偏大、答案偏小。

**延伸思考**：若两组**无序**（不可区分），好分区在交换标签下两两配对且无不动点，答案为 $(2^n - 2\,\text{bad}) \cdot 2^{-1} \bmod p$（模逆元）；推广到 $m$ 个有序组、每组 $\ge k$：$S \ge mk$ 时 $m$ 个坏事件仍两两不交，但 $|A_i| = \sum_{\text{sum}(T) < k} (m-1)^{n-|T|}$，背包转移改为「进组 $i$：$dp[j+x] \mathrel{+}= dp[j]$；不进：$dp[j] \mathrel{*}= (m-1)$」；若元素可负，「和 $< k \Rightarrow$ 只含小元素」失效，小背包不再够用；若 $k$ 大到 $10^{12}$ 而 $n \le 40$，可改用折半搜索统计子集和 $< k$ 的方案数。
