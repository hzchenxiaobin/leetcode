# LeetCode 到目标字符串的最短距离 题解

## 1. 题目概述

- **标题 / 题号**：到目标字符串的最短距离（#2515，easy）
- **链接**：https://leetcode.cn/problems/shortest-distance-to-target-string-in-a-circular-array/
- **来源**：LeetCode 第 325 场周赛 Q1
- **难度**：简单
- **标签**：数组、字符串

**题意**：给定下标从 0 开始的**环形**字符串数组 `words`（首尾相接，`words[i]` 的下一个元素是 `words[(i + 1) % n]`）和字符串 `target`。从 `startIndex` 出发，每一步可以移动到下一个或前一个单词。返回到达**任意一个**等于 `target` 的位置所需的最少步数；若 `target` 不存在则返回 `-1`。

**约束**：

- $1 \le \text{words.length} \le 100$
- $1 \le \text{words[i].length} \le 100$
- `words[i]` 和 `target` 仅由小写英文字母组成
- $0 \le \text{startIndex} < \text{words.length}$

## 2. 示例

**示例 1**

```text
输入：words = ["hello","i","am","leetcode","hello"], target = "hello", startIndex = 1
输出：1
解释："hello" 出现在下标 0 和 4。向左移动 1 步到达下标 0；或向右移动 3 步到达下标 4。最短距离为 1。
```

**示例 2**

```text
输入：words = ["a","b","leetcode"], target = "leetcode", startIndex = 0
输出：1
解释：向左移动 1 步绕环到达下标 2；向右需要 2 步。最短距离为 1。
```

**示例 3**

```text
输入：words = ["i","eat","leetcode"], target = "ate", startIndex = 0
输出：-1
解释：words 中不存在字符串 "ate"。
```

## 3. 解题思路

### 3.1 暴力思路

把环形数组当成图：从 `startIndex` 出发做 **BFS**，每步扩展到 $(i \pm 1) \bmod n$，首次遇到 `words[i] == target` 时返回当前层数。状态只有 $n$ 个，完全可行，但签到题不值得建队列。

更直接的变体是**按步数对称扩展**：枚举步数 $d = 0, 1, \dots, n-1$，同时检查 $(\text{start} + d) \bmod n$ 与 $(\text{start} - d + n) \bmod n$ 两处，首个命中即为答案（见 §4 写法二）。

### 3.2 核心观察：环形距离可以 O(1) 算出来

![环形数组上的双向距离](images/2515_circular_distance_concept.svg)

设 $n$ 为数组长度，$s = \text{startIndex}$。对任意匹配位置 $i$（即 `words[i] == target`）：

- **只向右**（+1 方向）走，最少步数为 $d_R = (i - s + n) \bmod n$；
- **只向左**（−1 方向）走，最少步数为 $d_L = (s - i + n) \bmod n$；
- **混合左右走不会更优**（§5 引理 3），故 $dist(i) = \min(d_R, d_L)$。

于是**一遍扫描**所有下标，对每个匹配位置 $O(1)$ 计算距离并取最小即可，连 BFS 都不用。

> 💡 有用的副产品：当 $i \ne s$ 时 $d_R + d_L = n$，因此 $dist(i) \le \lfloor n/2 \rfloor$——真实答案严格小于 $n$，可以用 $n$ 当「未找到」的哨兵值。

### 3.3 算法流程

1. 初始化 `ans = n`（哨兵，真实距离必 $< n$）。
2. 枚举 $i = 0 \dots n-1$：若 `words[i] == target`，用 $\min(d_R, d_L)$ 更新 `ans`。
3. 循环结束后 `ans == n` 说明无匹配，返回 `-1`；否则返回 `ans`。

### 3.4 示例演算

以示例 1 为例（$n = 5$，$s = 1$，`target = "hello"` 匹配下标 $0$ 和 $4$）：

| 匹配位置 $i$ | $d_R = (i-1+5) \bmod 5$ | $d_L = (1-i+5) \bmod 5$ | $dist(i)$ |
|---|---|---|---|
| $0$ | $4$ | $1$ | $\mathbf{1}$ |
| $4$ | $3$ | $2$（绕环 1→0→4） | $2$ |

答案 $= \min(1, 2) = 1$：向左 1 步到下标 0。

![示例 1 演算](images/2515_example_walkthrough.svg)

## 4. 算法细节

1. **两条取模公式**：$d_R = (i - s + n) \bmod n$，$d_L = (s - i + n) \bmod n$。**C++ 中 `(i - s) % n` 可能为负**，必须先 `+ n` 再取模；Python 的 `%` 对正模数天然非负，可直接写 `(i - s) % n`。
2. **哨兵值取 $n$**：由 §3.2，任意真实距离 $\le \lfloor n/2 \rfloor < n$（$n \ge 1$），故循环结束后 `ans == n` 当且仅当无匹配，省去 `INT_MAX` 判空。
3. **多个匹配位置**：答案要对**所有**匹配下标取全局最小，不能只取第一个出现的（示例 1 中若先扫到 idx 4 会得 2，正确答案是 idx 0 的 1）。

**写法二（按步数对称扩展）**：本质是把 $d_R$、$d_L$ 逐层向外试探，首个命中即返回，可提前终止：

```python
for d in range(n):
    if words[(startIndex + d) % n] == target:
        return d
    if words[(startIndex - d + n) % n] == target:
        return d
return -1
```

## 5. 正确性证明

**引理 1**：从 $s$ 出发只向右移动到达 $i$ 的最少步数恰为 $d_R = (i - s + n) \bmod n$。

**证明**：向右移动 $k$ 步到达位置 $(s + k) \bmod n$，故需 $s + k \equiv i \pmod n$。满足条件的非负整数构成 $\{d_R,\ d_R + n,\ d_R + 2n, \dots\}$（其中 $d_R \in [0, n)$），最小者为 $d_R$。∎

**引理 2**：只向左移动到达 $i$ 的最少步数恰为 $d_L = (s - i + n) \bmod n$。

**证明**：与引理 1 对称（左移 $k$ 步到达 $(s - k) \bmod n$，需 $k \equiv s - i \pmod n$）。∎

**引理 3**：任意移动策略（可混合方向）从 $s$ 到 $i$ 的总步数不少于 $\min(d_R, d_L)$。

**证明**：设右移 $a$ 次、左移 $b$ 次，则到达位置满足 $a - b \equiv i - s \pmod n$。若 $a \ge b$，则 $a - b$ 是非负且 $\equiv i - s \pmod n$ 的数，由引理 1 的证明知 $a - b \ge d_R$，故总步数 $a + b \ge a \ge a - b \ge d_R$；若 $b > a$，同理 $b - a \equiv s - i \pmod n$ 且非负，故 $b - a \ge d_L$，总步数 $a + b \ge b \ge b - a \ge d_L$。两种情况均有 $a + b \ge \min(d_R, d_L)$。∎

**定理**：算法返回从 `startIndex` 到达某个 `words[i] == target` 的最少步数；无匹配时返回 `-1`。

**证明**：由引理 1–3，最优答案 $= \min\{\, \min(d_R(i), d_L(i)) : \text{words}[i] = \text{target} \,\}$。算法枚举每个匹配 $i$ 并以 $O(1)$ 计算该值后取最小，与最优答案一致。无匹配时 `ans` 保持哨兵 $n$（真实答案 $< n$），返回 `-1`。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \cdot L)$，其中 $L = |\text{target}|$——每次字符串比较至多比较 $O(|\text{words}[i]| + L)$ 个字符。$n \le 100$，量级极小；若视比较为 $O(1)$ 则为 $O(n)$。
- **空间复杂度**：$O(1)$，只使用常数个额外变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int closestTarget(vector<string>& words, string target, int startIndex) {
        int n = words.size(), ans = n;
        for (int i = 0; i < n; i++) {
            if (words[i] == target) {
                ans = min({ans, (i - startIndex + n) % n, (startIndex - i + n) % n});
            }
        }
        return ans == n ? -1 : ans;
    }
};
```

### Python

```python
class Solution:
    def closestTarget(self, words: list[str], target: str, startIndex: int) -> int:
        n = len(words)
        ans = n
        for i, w in enumerate(words):
            if w == target:
                ans = min(ans, (i - startIndex) % n, (startIndex - i) % n)
        return -1 if ans == n else ans
```

## 8. 边界情况与易错点

1. **C++ 负数取模**：`(i - startIndex) % n` 可能为负，必须先 `+ n` 再 `%`；Python 的 `%` 结果符号随模数，无此坑。
2. **起点即目标**：`words[startIndex] == target` 时答案为 0，两条公式都自然给出 0。
3. **哨兵初始值**：用 `n` 依赖「真实答案 $\le \lfloor n/2 \rfloor$」这一事实；不确定时用 `INT_MAX` / `inf` 更稳妥。
4. **多个匹配取全局 min**：示例 1 中第一个匹配（idx 0）恰好最优，但一般情况必须遍历完所有匹配位置。
5. **n = 1**：若 `words[0] == target` 答案为 0，否则返回 `-1`；环形退化成单点，公式依然成立。
