# LeetCode 超级饮料的最大强化能量 题解

## 1. 题目概述

- **标题 / 题号**：超级饮料的最大强化能量（#3259，medium）
- **链接**：https://leetcode.cn/problems/maximum-energy-boost-from-two-drinks/
- **来源**：LeetCode 第 411 场周赛 Q2
- **难度**：中等
- **标签**：数组、动态规划

**题意**：给定长度均为 $n$ 的数组 `energyDrinkA` 与 `energyDrinkB`。每小时饮用 A、B 之一并获得对应数组在该小时的强化能量；从一种饮料**切换**到另一种时，需要等待一小时「梳理能量体系」——该小时收益为 $0$。起手可任选一种（无代价）。求 $n$ 小时内的最大总强化能量。

**约束**：

- $3 \le n \le 10^5$
- $1 \le \text{energyDrinkA}[i], \text{energyDrinkB}[i] \le 10^5$

> 💡 **赛点定位**：骨架是「动作间有强制冷却」的双状态线性 DP（与 309 冷冻期同款）。真正拉开差距的是两个坑：转移必须**隔一格回看**（$i-2$ 而非 $i-1$），以及总和上界 $10^{10}$ 需要 `long long`——前者示例 2 就能筛出来，后者专收 C++ 提交。

## 2. 示例

**示例 1**

```text
输入：energyDrinkA = [1,3,1], energyDrinkB = [3,1,1]
输出：5
解释：全程不切换：只喝 A（1+3+1）或只喝 B（3+1+1）都是 5。
```

**示例 2**

```text
输入：energyDrinkA = [4,1,1], energyDrinkB = [1,1,3]
输出：7
解释：第 1 小时喝 A（+4）→ 第 2 小时切换休整（+0）→ 第 3 小时喝 B（+3）。
```

**示例 3（自造：两次切换）**

```text
输入：energyDrinkA = [5,5,1,1,1,5,5], energyDrinkB = [1,1,9,9,9,1,1]
输出：37
解释：A,A,休整,B,B,B,休整,A ＝ 5+5+0+9+9+9+0+5。
     中间那波 B 太肥，两端用 A 包夹，两次切换各牺牲一小时仍然最优。
```

## 3. 解题思路

### 3.1 暴力思路：指数枚举与贪心的双重失败

每小时有三种状态（喝 A / 喝 B / 休整），朴素枚举 $3^n$ 条决策序列并校验合法性（休整必须夹在两次**相异**饮用之间），$n \le 10^5$ 直接爆炸。

贪心同样不可行：逐小时选「眼前收益最大」的分支短视。以示例 2 为例，贪心会走 $A(4) \to A(1) \to A(1) = 6$——第 2 小时不肯为「第 3 小时的 3」牺牲眼前的 1，而正确答案 7 恰恰要求**愿意用一格 0 换赛道**。「远处的肥格值不值得一次切换」本质是全局权衡，局部规则无法判定——必须把「当前在哪条道」编码进状态做 DP。

### 3.2 核心观察：方案 = 双车道行走，换道必须跨过一个 0 格

![双车道模型：直行续杯、换道跨休整格](images/energy_boost_two_lane_concept.svg)

**观察 1（休整的结构）**：每小时收益 $\ge 1$，所以任何「多余」的休整（不换道也休、换道后连休）都能被「续杯」严格改进；且休整本身就是切换的附属品——它的左侧必是旧饮料、右侧必是新饮料。于是**合法方案 = 若干段连续同饮区间，段与段之间恰好夹一个收益 0 的休整小时**。

**观察 2（无后效性）**：第 $i$ 小时之后还能拿到多少，只取决于 $(i, \text{当前饮料})$，与之前如何到达无关——历史信息被压缩成「在 A 还是在 B」一比特。

据此定义两个状态：

$$dpA[i] = \text{只考虑前 } i+1 \text{ 小时、且第 } i \text{ 小时喝 A 的最大总能量}$$

$$dpB[i] = \text{只考虑前 } i+1 \text{ 小时、且第 } i \text{ 小时喝 B 的最大总能量}$$

「第 $i$ 小时喝 A」按前一小时的形态二分：

- **① 续杯**：第 $i-1$ 小时也在喝 A → $dpA[i-1] + A[i]$；
- **② 切换**：第 $i-1$ 小时是休整——而休整左侧必喝 B，即**最近一次喝 B 恰在第 $i-2$ 小时** → $dpB[i-2] + 0 + A[i]$。

$$dpA[i] = \max\bigl(dpA[i-1],\ dpB[i-2]\bigr) + A[i] \qquad dpB[i] = \max\bigl(dpB[i-1],\ dpA[i-2]\bigr) + B[i]$$

> ⚠️ **为什么是 $dpB[i-2]$ 而不是 $dpB[i-1]$**：若第 $i-1$ 小时还在拿 $B[i-1]$ 的收益，休整小时就**无处安放**——切换的代价是牺牲一整个时间步，在转移里体现为隔一格回看。误用 $i-1$ 直连等价于「不休整瞬移换道」，示例 2 会算出 $4+1+3=8 \ne 7$，样例即可拦住。

**边界**：$dpA[0] = A[0]$、$dpB[0] = B[0]$（起手任选、免费）；$i = 1$ 时 $i - 2 < 0$，切换分支不存在，只剩续杯。**答案**：

$$\text{ans} = \max\bigl(dpA[n-1],\ dpB[n-1]\bigr)$$

合法方案末尾必是饮用小时（休整必须两侧夹饮用，「结尾休整」意味着切换到一种永远不喝的饮料），所以取两个末状态的最大值即完备。

### 3.3 算法流程：滚动变量线性 DP

![状态转移图：续杯看 i−1，切换跨休整格看 i−2](images/energy_boost_dp_transition.svg)

| 步骤 | 操作 | 说明 |
|------|------|------|
| ① 初始化 | $a1 = A[0]$，$b1 = B[0]$，$a2 = b2 = 0$ | $a1/b1$ 即 $dpA/dpB[i-1]$；$a2/b2$ 即 $dpA/dpB[i-2]$，0 占位 |
| ② 转移 | $i$ 从 $1$ 到 $n-1$：$curA = \max(a1, b2) + A[i]$，$curB = \max(b1, a2) + B[i]$ | 续杯 vs 切换，取较优 |
| ③ 滚动 | $a2, b2 \leftarrow a1, b1$；$a1, b1 \leftarrow curA, curB$ | 只保留最近两行，$O(1)$ 空间 |
| ④ 返回 | $\max(a1, b1)$ | 即 $\max(dpA[n-1], dpB[n-1])$ |

> 💡 $i = 1$ 时用 0 占位 $dpB[-1]$ 是安全的：占位值 $0$ 恒小于真实竞争者 $dpA[0] = A[0] \ge 1$，$\max$ 不会误选。一般原则是「占位值不得大于任何真实可达值」——本题收益下界为正，占位 0 天然满足；若收益可能为负须换成 $-\infty$。

### 3.4 示例演算

![示例演算与双切换示例](images/energy_boost_example_walkthrough.svg)

对示例 2 逐小时填表：

| $i$ | $A[i]$ | $B[i]$ | $dpA[i]$ | $dpB[i]$ | 备注 |
|-----|--------|--------|----------|----------|------|
| 0 | 4 | 1 | 4 | 1 | 起手任选，各自开喝 |
| 1 | 1 | 1 | $\max(4)+1=5$ | $\max(1)+1=2$ | $i-2<0$，只能续杯 |
| 2 | 1 | 3 | $\max(5,1)+1=6$ | $\max(2,\mathbf{4})+3=\mathbf{7}$ | $dpB[2]$ 抛弃续杯，从 $dpA[0]$ **切换**而来 |

答案 $\max(6, 7) = 7$。回溯 $dpB[2]$ 的来路正是官方解释的方案：**喝 A（+4）→ 休整（+0）→ 喝 B（+3）**。A 的开局太香（4 对 1）、B 的收尾太肥（3 对 1），中间牺牲一小时换赛道净赚 2。示例 3（自造）则展示**两次切换**：$5+5 \to 0 \to 9+9+9 \to 0 \to 5 = 37$，而全程 B 只有 31——转移天然支持任意次换道，无需任何特判。

## 4. 算法细节

1. **$i-2$ 是结构强制的，不是近似**：休整永远夹在「旧饮料最后一格」与「新饮料第一格」之间，所以「喝 A 于 $i$」的切换来路**恰**是「喝 B 于 $i-2$」——不存在「更早喝 B、中间空转」的合法形态（多余休整被收益 $\ge 1$ 严格压制，见引理 1）。转移的下标距离就是冷却长度的直接读数：**冷却 $k$ 小时 ⇒ 切换分支回看 $i-1-k$**。
2. **边界 $i = 1$ 单独处理**：不存在「开局休整」（第 0 小时没有前驱饮料，无切换可言），$dpA[1] = dpA[0] + A[1]$ 只剩续杯分支。滚动实现用 0 占位即可（安全性见 3.3 的 blockquote）。
3. **溢出**：总和上界 $10^5 \times 10^5 = 10^{10} > 2^{31}-1 \approx 2.1 \times 10^9$，C++ 全程 `long long`——本题接口本来就返回 `long long`，照抄即可，但中间变量别用 `int` 省。
4. **滚动次序**：`curA / curB` 必须都基于旧值算完再统一滚动；Python 元组赋值一行完成（等号右侧整体先求值），天然免疫覆盖顺序问题。
5. **等价变形（场外备胎）**：把休整记到「新饮料落位的那一小时」（名义已换道、收益记 0），可得两项转移 $fA[i] = \max(fA[i-1] + A[i],\ fB[i-1])$、$fB[i] = \max(fB[i-1] + B[i],\ fA[i-1])$，答案同为 $\max(fA[n-1], fB[n-1])$，数值与主版本完全一致——冷却类问题的「**代价记账位置可以平移**」。周赛场上挑顺手的那版写完就走，别在等价变形上耗时间。

## 5. 正确性证明

先固定**合法方案**的集合：给每小时指派「喝 A / 喝 B / 休整」，其中每个休整小时的左右两侧必须是**相异**的饮用小时（休整只能是切换的等待小时）；方案的总能量为各小时收益之和。

**引理 1（段结构）**：任何合法方案由若干极大同饮段构成，相邻段之间恰有一个休整小时；不存在连续休整、第 0 小时休整或第 $n-1$ 小时休整。

**证明**：休整的右侧必是饮用小时，故两个休整不可能相邻（左侧那个的右侧应是饮用）。第 0 小时无左侧、第 $n-1$ 小时无右侧，均不满足休整的夹逼条件，故首尾必是饮用小时。饮用小时按饮料异同分段：相异饮料的相邻饮用之间恰由一个休整衔接，同种饮料的相邻段会合并为同一段。∎

**引理 2（转移刻画）**：合法方案中「第 $i$ 小时喝 A（$i \ge 1$）」当且仅当「第 $i-1$ 小时喝 A」或「第 $i-2$ 小时喝 B 且第 $i-1$ 小时休整」（后者要求 $i \ge 2$）。

**证明**：（⟸）两种形态都直接构成合法方案片段：前者同饮续杯；后者由引理 1 是标准「B 段 → 休整 → A 段」衔接。（⟹）设第 $i$ 小时喝 A，考察第 $i-1$ 小时：若饮用且为 A，得前者；若饮用且为 B，则第 $i$ 小时是紧随 B 的 A，中间没有休整位置，与「相邻相异饮用必须隔休整」矛盾；若休整，其右侧是 A（饮用），由合法性左侧必是相异饮用即 B，得后者，且 $i-2 \ge 0$ 要求 $i \ge 2$。∎

**定理**：对一切 $0 \le i < n$，$dpA[i]$ 等于「前 $i+1$ 小时、第 $i$ 小时喝 A」的合法方案总能量最大值（$dpB$ 对称），且 $\max(dpA[n-1],\ dpB[n-1])$ 即为答案。

**证明（对 $i$ 归纳）**：$i = 0$ 时「喝 A」的方案只有从 A 起手一种，$dpA[0] = A[0]$ 成立。设结论对更小的下标成立。**（≤，可达性）**：两个转移分支各自拼接出合法方案——续杯分支把「第 $i$ 小时喝 A」接到任何「第 $i-1$ 小时喝 A」的最优前缀后；切换分支把「休整 + 喝 A」接到「第 $i-2$ 小时喝 B」的最优前缀后，由引理 1 拼出的仍是合法方案。故 $dpA[i]$ 是某个合法方案的能量，不超过最大值。**（≥，最优性）**：取一个「前 $i+1$ 小时、第 $i$ 小时喝 A」的最优合法方案，由引理 2 其局部形态必属两种之一；砍掉第 $i$ 小时（及切换形态下的休整小时）后得到同类的合法前缀方案，由归纳假设其能量不超过对应的 $dp$ 值，故原方案总能量 $\le \max(dpA[i-1],\ dpB[i-2]) + A[i] = dpA[i]$。两方向合并即 $dpA[i]$ 恰为最大值；$dpB$ 对称。最后由引理 1，末小时必为饮用小时，答案 $= \max(dpA[n-1],\ dpB[n-1])$。∎

> 💡 证明的关键杠杆是引理 1 的「夹逼结构」：它把休整钉死在换道夹缝里，使引理 2 的二分**不重不漏**，归纳自然闭合。若允许「无意义休整」进入方案集，DP 仍会给出正确答案（这类方案被续杯分支严格压制），但证明要多绕一层——用合法性定义直接排除更干净。

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。单趟循环，每步两个 $\max$ 与两次加法；$n \le 10^5$ 时约 $2 \times 10^5$ 次基本运算。
- **空间复杂度**：$O(1)$。滚动变量 4 个（$a1, b1, a2, b2$）；开两张 `long long` 数组的朴素版为 $O(n)$，同样可过。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long maxEnergyBoost(vector<int>& energyDrinkA, vector<int>& energyDrinkB) {
        int n = energyDrinkA.size();
        long long a1 = energyDrinkA[0], b1 = energyDrinkB[0];
        long long a2 = 0, b2 = 0;
        for (int i = 1; i < n; ++i) {
            long long curA = max(a1, b2) + energyDrinkA[i];
            long long curB = max(b1, a2) + energyDrinkB[i];
            a2 = a1; b2 = b1;
            a1 = curA; b1 = curB;
        }
        return max(a1, b1);
    }
};
```

### Python

```python
class Solution:
    def maxEnergyBoost(self, energyDrinkA: List[int], energyDrinkB: List[int]) -> int:
        a1, b1 = energyDrinkA[0], energyDrinkB[0]
        a2 = b2 = 0
        for i in range(1, len(energyDrinkA)):
            a1, b1, a2, b2 = (max(a1, b2) + energyDrinkA[i],
                              max(b1, a2) + energyDrinkB[i],
                              a1, b1)
        return max(a1, b1)
```

## 8. 边界情况与易错点

1. **$i-1$ 直连转移（思路头号坑）**：写成 $\max(dpA[i-1],\ dpB[i-1]) + A[i]$ 等于允许「不休整瞬移换道」，示例 2 得 $8 \ne 7$——样例即可拦截。冷却/间隔类题先自问：**代价折算成下标距离了吗？**
2. **`int` 溢出（提交头号坑）**：上界 $10^{10}$ 超 `int32`。C++ 中间变量与返回值全用 `long long`；Python 无此虑。
3. **$i = 1$ 边界**：切换分支引用 $dpB[-1]$ 不存在——数组版要 `if (i >= 2)` 跳过切换分支，滚动版用 0 占位（占位值须不大于真实可达值）。
4. **答案取两状态 max**：只回 `dpA[n-1]`（默认全程 A 阵营）会漏掉切换更优的方案；起手 B 的分支同理不可漏。
5. **末尾必为饮用小时**：由引理 1 无需考虑「末尾休整」形态，也**不必为休整单独设状态**——它是换道的附属品，已折叠进跨格转移。
6. **$n \ge 3$**：无极小 $n$ 特判；$i = 0, 1$ 各自只能续杯是天然边界。
