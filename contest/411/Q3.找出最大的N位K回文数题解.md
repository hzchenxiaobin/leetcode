# LeetCode 找出最大的 N 位 K 回文数 题解

## 1. 题目概述

- **标题 / 题号**：找出最大的 N 位 K 回文数（#3260，hard）
- **链接**：https://leetcode.cn/problems/find-the-largest-palindrome-divisible-by-k/
- **来源**：LeetCode 第 411 场周赛 Q3
- **难度**：困难
- **标签**：贪心、数学、数论、动态规划、字符串

**题意**：给定正整数 $n$ 和 $k$。若整数 $x$ 既是**回文数**，又能被 $k$ **整除**，则称 $x$ 是一个 **k 回文数**。以字符串形式返回**最大的** $n$ 位 k 回文数（不含前导零）。

**约束**：

- $1 \le n \le 10^5$
- $1 \le k \le 9$

> 💡 **赛点定位**：$n \le 10^5$ 排除一切「枚举候选再验证」的暴力，逼你从**结构**下手；而 $k \le 9$ 是出题人留的口子——数字 $0 \sim 9$ 恰好有 10 个，**不少于任何模周期的长度**，使得每个位置的可达余数集自动坍缩成「$\gcd$ 的倍数」，可行性判定 $O(1)$。本题两大的暗坑：奇数长度时**中间位系数只算一次**（算两次必 WA），以及 C++ 的**负数取模**。

## 2. 示例

**示例 1**

```text
输入：n = 3, k = 5
输出："595"
解释：595 是最大的 3 位 k 回文数。
```

**示例 2**




## 3. 解题思路

### 3.1 暴力思路：枚举与分类讨论的双重陷阱

- **从大到小枚举** $n$ 位数再验证回文 + 整除：候选多达 $10^{10^5}$ 个，直接爆炸；枚举「回文的一半」也有 $10^{5 \times 10^4}$ 种组合，同样不可行。
- **按 $k$ 分类讨论**：$k \in \{1,3,9\}$ 时数位和是 $9m$，全 9 即答案；$k=2$ 答案是 $8\cdots8$、$k=5$ 是 $5\cdots5$。但 $k \in \{4,6,7,8\}$ 需要讨论末两位、末三位与数位和的联动，分支繁杂极易翻车——赛场上写这种解法的人大多卡在 $k=6$、$k=8$ 的边界上。

正确姿势是找**统一的判定准则**：回文的自由度只有前一半，从高位往低位贪心，每位只问一个问题——「**剩下的位还能把余数凑成 0 吗？**」这个问题必须被精确回答，否则贪心会错杀或漏选。

### 3.2 核心观察：前一半决定一切，余数是线性量

![回文数由前一半决定：自由决策位与镜像位](images/kpalindrome_half_greedy_concept.svg)

**观察 1（结构降维）**：回文数由前一半完全决定。设 $m = \lceil n/2 \rceil$，只需求出前一半数字 $d_0, d_1, \dots, d_{m-1}$，后一半按镜像复制。所有 $n$ 位数等长，**数值大小比较 = 字典序比较 = 前一半的字典序比较**——这立刻提示：从 $d_0$ 开始逐位贪心。

**观察 2（余数线性可分解）**：把 $N \bmod k$ 拆到数位上。位置 $i$ 与对称位置 $n-1-i$ 承载同一个数字 $d_i$，各贡献一次位权，于是

$$N \equiv \sum_{i=0}^{m-1} d_i \cdot c_i \pmod{k}, \qquad c_i = \bigl(10^{\,n-1-i} + 10^{\,i}\bigr) \bmod k$$

**例外**：$n$ 为奇数时中间位 $i = m-1$ 只出现一次，其系数是 $c_{m-1} = 10^{\,m-1} \bmod k$ 而**不是**两倍——这是本题最大的陷阱。

**观察 3（可行性可 $O(1)$ 判定）**：固定前 $i$ 位后，剩余位置 $i+1 \dots m-1$ 能凑出的余数集合**恰好**是「$suf[i+1]$ 的全部倍数」，其中

$$suf[i] = \gcd\bigl(c_i,\ c_{i+1},\ \dots,\ c_{m-1},\ k\bigr), \qquad suf[m] = k$$

直观理由：单个位置取遍数字 $0 \sim 9$ 时，$d \cdot c_i \bmod k$ 能取到的值是 $\gcd(c_i, k)$ 的所有倍数（$k \le 9$，周期 $k/\gcd \le 9 < 10$，一轮数字必铺满整组）；而「若干个倍数集合相加」仍是某个 $\gcd$ 的倍数集合（§5 引理 2）。于是判定「剩余位能否凑出余数 $nr$」只需检查 $suf[i+1] \mid nr$——一步取模，无需 DP。

> ⚠️ **为什么 $k \le 9$ 是本质条件**：可达集是「完整子群」依赖「数字个数 $10 \ge$ 周期 $k/\gcd(c_i,k)$」。若 $k$ 可以很大（比如 $k \le 10^5$），单位置可达集只是子群的一小段，判定就得老老实实做后缀可行性 DP $f[i][r]$（$O(10 \cdot k \cdot n)$）。本题 $k \le 9$，DP 被数论观察**坍缩**成一个 gcd 数组。

### 3.3 算法流程：系数表 → 后缀 gcd → 逐位贪心

![算法流程：预处理、后缀 gcd、贪心判定与镜像拼接](images/kpalindrome_suffix_gcd_flow.svg)

| 步骤 | 操作 | 说明 |
|------|------|------|
| ① 预处理 | $pw[i] = 10^i \bmod k$，递推 $pw[i] = pw[i-1] \cdot 10 \bmod k$ | $pw[0] = 1 \bmod k$（$k=1$ 时为 0） |
| ② 系数 | $c_i = (pw[n-1-i] + pw[i]) \bmod k$；中间位（$n$ 奇）$c_{m-1} = pw[m-1]$ | 中间位只算一次！ |
| ③ 后缀 gcd | $suf[m] = k$；$suf[i] = \gcd(c_i, suf[i+1])$ | $suf[i+1]$ 的倍数集 = 后缀可达余数集 |
| ④ 贪心 | 维护所需余数 $r$（初始 0）。$d$ 从 9 试到 0：$nr = (r - d \cdot c_i) \bmod k$，首个满足 $suf[i+1] \mid nr$ 的 $d$ 即选中，$r \leftarrow nr$ | 判定精确 ⇒ 贪心正确 |
| ⑤ 拼接 | $ans = half + \text{reverse}(half[0..n-m-1])$ | $n-m = \lfloor n/2 \rfloor$，奇数时中间位不重复 |

**存在性锚点**：全 $k$ 串 $kk\cdots k = k \times \underbrace{11\cdots1}_{n}$ 永远是合法的 $n$ 位 k 回文数（$k \le 9$ 保证无前导零）。它同时给出两个免费结论——贪心**每一步必有可行数字**（至少能退化到它），且答案**首位 $\ge k \ge 1$**，无前导零问题无需特判。

### 3.4 示例演算

![示例演算：n=5, k=6 的逐位贪心过程](images/kpalindrome_example_walkthrough.svg)

对示例 3（$n=5, k=6$）逐位演算。预处理：$pw = [1,4,4,4,4]$，$m=3$，系数 $c = [5,2,4]$（中间位 $10^2 \bmod 6 = 4$），后缀 $suf = [1,2,2,6]$：

| $i$ | $c_i$ | $suf[i{+}1]$ | 试探过程 | 选中 $d_i$ | $r$ 变化 |
|-----|-------|--------------|----------|-----------|----------|
| 0 | 5 | 2 | $d{=}9$：$nr{=}3$，$3\nmid$ 被 2 整除 ✗ → $d{=}8$：$nr{=}2$，$2 \mid 2$ ✓ | **8** | $0 \to 2$ |
| 1 | 2 | 2 | $d{=}9$：$nr{=}2$，$2 \mid 2$ ✓（首位直接拿下） | **9** | $2 \to 2$ |
| 2 | 4 | 6 | $d{=}9$：$nr{=}2$，$2 \not\equiv 0 \pmod 6$ ✗ → $d{=}8$：$nr{=}0$ ✓ | **8** | $2 \to 0$ |

前一半 $=$ `898`，镜像补全得 `89898`，验证 $89898 = 6 \times 14983$ ✓。注意第 0 位「忍痛割 9」的理由：选 9 后剩余位（系数 2、4）只能凑出**偶数**余数，而需要凑的是 3；这正是 $suf[1] = \gcd(2,4,6) = 2$ 在判定中的体现。

## 4. 算法细节

1. **系数推导（中间位单独处理）**：$N = \sum_{j=0}^{n-1} a_j 10^{n-1-j}$，回文性 $a_j = a_{n-1-j}$ 把成对位合并为 $d_i \cdot (10^{n-1-i} + 10^i)$。$n$ 偶数时 $i \le m-1$ 与 $n-1-i \ge m$ 严格配对；$n$ 奇数时 $i = m-1$ 就是中间位，**只贡献一次** $10^{m-1}$。
2. **后缀 gcd 的哨兵**：$suf[m] = k$ 使最后一位（$i = m-1$）的判定退化为 $nr \bmod k = 0$——所有位都已固定时必须**恰好**落在余数 0 上，而不是「0 的某个倍数」。$suf$ 数组全部 $\ge 1$，无除零风险；$c_i = 0$（位权被 $k$ 整尽，如 $k=5$ 时所有 $pw[i \ge 1] = 0$）也天然正确，因为 $\gcd(0, x) = x$。
3. **贪心方向与 $r$ 的含义**：$r$ 是「剩余自由位贡献之和还需要凑出的余数」，即 $r \equiv -\sum_{j<i} d_j c_j \pmod k$。初始 $r = 0$；每锁定一位，$r \leftarrow (r - d \cdot c_i) \bmod k$。最终（$i = m$ 时）判定保证 $r = 0$。
4. **镜像拼接**：$ans = half + \text{reverse}(half[:\,n-m])$。奇数长度时 $n - m = m - 1$，正好跳过中间位；Python 切片务必写 `half[:n-m][::-1]`，写 `half[n-m-1::-1]` 会在 $n = 1$ 时因下标 $-1$ 语义翻转整个串。
5. **保底等价写法（想不出数论观察时）**：后缀可行性 DP $f[i][r] \in \{0,1\}$（位置 $i..m-1$ 能否凑出余数 $r$，倒序转移枚举 10 个数字），配合贪心使用，复杂度 $O(10 \cdot k \cdot n) \approx 4.5 \times 10^6$，同样能过——本文的后缀 gcd 就是它在 $k \le 9$ 下的坍缩形态。

## 5. 正确性证明

记 $\mathbb{Z}_k$ 为模 $k$ 余数集合，$M_g = \{0, g, 2g, \dots, k-g\}$（即 $g \mid k$ 时 $g$ 的全体倍数，$M_k = \{0\}$）。

**引理 1（单位可达集）**：对任意 $c \in [0, k)$，记 $g = \gcd(c, k)$，则 $\{d \cdot c \bmod k : d = 0, 1, \dots, 9\} = M_g$。

**证明**：$g \mid c$ 且余数均小于 $k$，故每个 $d \cdot c \bmod k$ 都是 $g$ 的倍数，即包含于 $M_g$。反之写 $c = g c'$，$k = g k'$，则 $\gcd(c', k') = 1$，映射 $d \mapsto d c' \bmod k'$ 在 $d = 0, \dots, k'-1$ 上是 $\mathbb{Z}_{k'}$ 的双射；而 $k' = k / g \le k \le 9 < 10$，数字 $0 \sim 9$ 覆盖完整周期，于是 $\{d \cdot c \bmod k\} \supseteq \{g \cdot (d c' \bmod k') : d < k'\} = M_g$。∎

**引理 2（子群合并）**：$M_a + M_b \triangleq \{x + y \bmod k : x \in M_a,\ y \in M_b\} = M_{\gcd(a,b)}$（要求 $a \mid k$、$b \mid k$）。

**证明**：$M_a, M_b$ 都是加法群 $\mathbb{Z}_k$ 的子群。一方面 $x = sa$、$y = tb$，故 $x + y$ 是 $\gcd(a,b)$ 的整数倍，得 $M_a + M_b \subseteq M_{\gcd(a,b)}$；另一方面由 Bézout 等式 $\gcd(a,b) = ua + vb$，且子群对整数倍封闭（$ua \in M_a$、$vb \in M_b$，无论 $u, v$ 符号），故 $\gcd(a,b) \in M_a + M_b$，进而其任一倍数 $w \cdot \gcd(a,b) = (wu)a + (wv)b \in M_a + M_b$，得反包含。∎

**定理 1（后缀可达集刻画）**：固定前 $i$ 位（$0 \le i \le m$）后，位置 $i..m-1$ 的贡献和的可达余数集恰为 $M_{suf[i]}$。

**证明（对 $m - i$ 归纳）**：$i = m$ 时无自由位，和恒为 $0$，即 $M_{suf[m]} = M_k = \{0\}$ ✓。设位置 $i+1..m-1$ 的可达集为 $M_{suf[i+1]}$。加入位置 $i$ 后可达集为

$$\bigcup_{d=0}^{9} \bigl(d \cdot c_i + M_{suf[i+1]}\bigr) = \{d \cdot c_i \bmod k\} + M_{suf[i+1]} = M_{\gcd(c_i, k)} + M_{suf[i+1]} = M_{\gcd(c_i,\ suf[i+1])} = M_{suf[i]}$$

三处等号分别由引理 1（$\{d \cdot c_i\}$ 恰为 $M_{\gcd(c_i,k)}$）、引理 2（$suf[i+1] \mid k$）与 $suf$ 的递归定义给出。∎

**定理 2（贪心正确性）**：贪心算法每一步都能选出可行数字，且输出为数值最大的 $n$ 位 k 回文数。

**证明**：**(a) 永不卡死**。归纳断言：按可行性锁定前 $i$ 位后，所需余数 $r_i \in M_{suf[i]}$。基例 $r_0 = 0$ 成立。由引理 2 逆用，$M_{suf[i]} = M_{\gcd(c_i,\ suf[i+1])} = M_{\gcd(c_i, k)} + M_{suf[i+1]}$，故可写 $r_i = u + x$，其中 $u \in M_{\gcd(c_i,k)}$（由引理 1 存在 $d \in [0,9]$ 使 $d \cdot c_i \equiv u$），$x \in M_{suf[i+1]}$。取该 $d$：$r_i - d \cdot c_i \equiv x \equiv 0 \pmod{suf[i+1]}$，判定通过，且 $r_{i+1} = x \in M_{suf[i+1]}$ 维持断言。**(b) 最大性**。由定理 1，判定条件**精确**（不多不少）：「选 $d$ 后仍可凑整」$\iff$ 判定通过。$n$ 位数比较即前一半的字典序比较。设最优解 $P$ 的前半与贪心前缀首次分歧在第 $i$ 位：贪心所选 $d$ 可行而 $p_i < d$ 时，以贪心前缀开头存在可行回文，字典序严格大于 $P$，与最优性矛盾；$p_i > d$ 时，$P$ 本身证明 $p_i$ 可行，与 $d$ 的最大性矛盾。故二者恒相等，归纳得贪心输出 $=$ 最优解。**(c) 无前导零**。全 $k$ 串 $kk \cdots k$ 是可行回文，其首位 $k \ge 1$ 通过第 0 位的判定，故贪心首位 $\ge k \ge 1$。∎

> 💡 证明的两个支点缺一不可：引理 1 是「**数字足够多**」（$10 > k$ 的周期铺满子群），引理 2 是「**子群相加仍是子群**」（倍数集体系对加法封闭）。前者若失效（$k$ 很大）须退回 DP；后者若换成乘法决策类问题则完全不成立——这套工具是「模加法下的自由变量组合」专属。

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。预处理 $pw$ 一趟 $O(n)$；系数与后缀 gcd 一趟 $O(m \log k)$（$k \le 9$，gcd 近似 $O(1)$）；贪心每位至多试 10 个数字，$O(10 m) = O(n)$；镜像拼接 $O(n)$。$n = 10^5$ 时总量约 $2 \times 10^6$ 次基本运算。
- **空间复杂度**：$O(n)$。$pw$（$n$ 个）、$c$ 与 $suf$（各 $m+1$ 个）、结果字符串。均可滚动压缩，但没必要。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    string largestPalindrome(int n, int k) {
        int m = (n + 1) / 2;
        vector<int> pw(n);
        pw[0] = 1 % k;
        for (int i = 1; i < n; ++i) pw[i] = pw[i - 1] * 10 % k;

        vector<int> c(m);
        for (int i = 0; i < m; ++i) {
            if (n % 2 == 1 && i == m - 1) c[i] = pw[i];      // 中间位只算一次
            else c[i] = (pw[n - 1 - i] + pw[i]) % k;
        }

        vector<int> suf(m + 1);
        suf[m] = k;                                          // 哨兵：末位须恰好落 0
        for (int i = m - 1; i >= 0; --i) suf[i] = gcd(c[i], suf[i + 1]);

        string half;
        int r = 0;                                           // 剩余位还需凑出的余数
        for (int i = 0; i < m; ++i) {
            for (int d = 9; d >= 0; --d) {
                int nr = ((r - d * c[i]) % k + k) % k;       // C++ 负取模修正
                if (nr % suf[i + 1] == 0) {                  // suf[i+1] 的倍数可达
                    r = nr;
                    half.push_back('0' + d);
                    break;
                }
            }
        }
        string ans = half;
        for (int i = n - m - 1; i >= 0; --i) ans.push_back(half[i]);
        return ans;
    }
};
```

### Python

```python
from math import gcd

class Solution:
    def largestPalindrome(self, n: int, k: int) -> str:
        m = (n + 1) // 2
        pw = [0] * n
        pw[0] = 1 % k
        for i in range(1, n):
            pw[i] = pw[i - 1] * 10 % k

        c = [0] * m
        for i in range(m):
            if n % 2 == 1 and i == m - 1:
                c[i] = pw[i]                     # 中间位只算一次
            else:
                c[i] = (pw[n - 1 - i] + pw[i]) % k

        suf = [k] * (m + 1)
        for i in range(m - 1, -1, -1):
            suf[i] = gcd(c[i], suf[i + 1])

        half, r = [], 0
        for i in range(m):
            for d in range(9, -1, -1):
                nr = (r - d * c[i]) % k
                if nr % suf[i + 1] == 0:
                    r = nr
                    half.append(str(d))
                    break
        return ''.join(half) + ''.join(reversed(half[:n - m]))   # n=1 时安全
```

## 8. 边界情况与易错点

1. **中间位重复计权（头号坑）**：$n$ 奇数时中间位系数是 $10^{m-1} \bmod k$，照抄配对公式会得到 $2 \cdot 10^{m-1}$。例：$n=5, k=6$ 时正确系数是 4，用错值 2 会贪出 `89798`（$89798 \bmod 6 = 5$，WA）。中间位是**一个**位置，只贡献一次位权。
2. **C++ 负数取模**：$(r - d \cdot c_i) \% k$ 可能为负，必须 `((x) % k + k) % k`；Python 的 `%` 天然非负，无此虑。
3. **哨兵 $suf[m] = k$ 而非 0**：末位判定是 $nr \bmod k = 0$（精确落零）。设成 0 会除零，设成 1 会放过一切非零余数。
4. **$k = 1$ 退化**：$pw[0]$ 应初始化为 $1 \% k = 0$；全部系数为 0，所有判定通过，答案即全 9 串 $99\cdots9$。
5. **$n = 1$**：$m = 1$，镜像循环不执行，答案就是那一位数字（$k$ 的最大个位倍数：如 $k=4$ 得 8）。
6. **首位零与卡死**：均无需特判——存在性锚 $kk\cdots k$ 保证贪心每步有解、首位 $\ge k \ge 1$。若你的贪心在某步 10 个数字全试失败，说明可行性判定写错了（多半是坑 1 或坑 3）。
7. **$c_i = 0$ 的位置**：位权被 $k$ 整除（如 $k=5$、$k \in \{2,4,6,8\}$ 的低位），这些位「白选」直接取 9；$\gcd(0, x) = x$ 保证后缀 gcd 无需特判。

- [LeetCode 866. 回文素数](https://leetcode.cn/problems/prime-palindrome/)：回文构造与整除/素性约束的组合，考察按位奇偶剪枝。

**延伸思考**：① 若 $k \le 10^5$（数字个数 10 < 周期），引理 1 失效，单位置可达集不再是完整子群——退回后缀可行性 DP $f[i][r]$，复杂度 $O(10 \cdot k \cdot n)$，思考何时仍可压缩；② 把「最大」改成「第 $q$ 大」：贪心改数位 DP 计数（每步统计可行前缀数）；③ 把「整除 $k$」改成「数位和恰为 $s$」：把 $k$ 维余数换成数位和维度，贪心 + 后缀可达性（可用满十进制的鸽笼简化）同样成立。
