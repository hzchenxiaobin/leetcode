# LeetCode 统计满足 K 约束的子字符串数量 II 题解

## 1. 题目概述

- **标题 / 题号**：统计满足 K 约束的子字符串数量 II（#3261，hard）
- **链接**：https://leetcode.cn/problems/count-substrings-that-satisfy-k-constraint-ii/
- **来源**：LeetCode 第 411 场周赛 Q4
- **难度**：困难
- **标签**：字符串、滑动窗口、前缀和、二分查找

**题意**：给定**二进制**字符串 $s$ 和整数 $k$。若子串中 `0` 的数量最多为 $k$，**或** `1` 的数量最多为 $k$（任一成立即可），则称该子串满足 **k 约束**。另有 $q$ 次查询，每次给出 $[l, r]$，要求统计**完全落在 $s[l..r]$ 内**的子串中满足 k 约束的数量，返回数组 $answer$。

**约束**：

- $1 \le n = s.length \le 10^5$
- $s[i]$ 是 `'0'` 或 `'1'`，$1 \le k \le n$
- $1 \le queries.length \le 10^5$
- $0 \le l_i \le r_i < n$，所有查询互不相同

> 💡 与同场 Q1（3258. I 版）的差别只有两处：$n$ 从 $50$ 放大到 $10^5$，以及从「数整串」变成「数区间」。Q1 题解延伸思考里预告的「把滑窗的 $L$ 数组留下来」正是本题的钥匙。

## 2. 示例

**示例 1**

```text
输入：s = "0001111", k = 2, queries = [[0,6]]
输出：[26]
解释：s[0..6] 的所有子串中，除 s[0..5] = "000111" 和 s[0..6] = "0001111"
     外，其余子串都满足 k 约束。
```

**示例 2**

```text
输入：s = "010101", k = 1, queries = [[0,5],[1,4],[2,3]]
输出：[15,9,3]
解释：s 的所有子串中，长度大于 3 的子字符串都不满足 k 约束。
```

**示例 3（自造，验证退化形态）**

```text
输入：s = "0000", k = 1, queries = [[0,3]]
输出：[10]
解释：任何子串的 ones = 0 ≤ k，全部满足，共 4×5/2 = 10 个。
     此时滑窗从不收缩，L[b] 恒为 0，答案退化为纯等差数列。
```

## 3. 解题思路

### 3.1 暴力思路

最朴素的暴力是对每个查询独立双重枚举子串 $[i, j]$ 并判定，单查询 $O\bigl((r-l+1)^2\bigr)$，最坏总计 $O(qn^2) = 10^{15}$，显然不可行。

温和一点的暴力是把 Q1 的 $O(n)$ 滑窗直接套到每个查询上——每次查询在 $[l, r]$ 上重跑一遍滑窗，总计 $O(nq) = 10^{10}$，依然超时。

问题出在**每个查询都从零开始**：$q$ 个查询共享同一个串、同一种约束，判定信息本可复用。突破口是把「每个右端点对应的最小合法左端点」**预处理成数组**，让每次查询只做 $O(\log n)$ 的组装工作。

### 3.2 核心观察：滑窗的副产品——L 数组单调不降

![查询分解：左区等差数列 + 右区前缀和](images/kconstraint_ii_query_split.svg)

把 Q1 滑窗每轮停下来时的 `left` 存成数组：$L[b]$ := 使得子串 $[j, b]$ 满足 k 约束的**最小** $j$。它有两条关键性质：

1. **后缀段结构**：以 $b$ 结尾的好子串，其左端点恰取遍连续区间 $[L[b],\, b]$，共 $p[b] = b - L[b] + 1$ 个（Q1 引理 3 的结论，$k \ge 1$ 保证 $L[b] \le b$，单字符恒好）。
2. **单调性**：$L$ 随 $b$ **单调不降**——$[L[b], b]$ 好 $\Rightarrow$ 其子集 $[L[b], b-1]$ 也好 $\Rightarrow L[b-1] \le L[b]$。

预处理只花一次 $O(n)$：滑窗过程中顺手记录 $L[b]$、$p[b]$,并对 $p$ 累加前缀和 $S[b] = p[0] + \dots + p[b]$（即「整串中前 $b+1$ 个右端点的好子串总数」）。

### 3.3 查询分解：max(l, L[b]) 与二分分界点

对查询 $[l, r]$，以 $b \in [l, r]$ 为右端点、且完全落在 $[l, r]$ 内的好子串个数是

$$b - \max(l,\, L[b]) + 1$$

——子串含于 $[l, r]$ 要求左端点 $j \ge l$，合法性要求 $j \ge L[b]$，两个下界取最大。于是

$$ans(l, r) = \sum_{b=l}^{r} \Bigl( b - \max\bigl(l,\, L[b]\bigr) + 1 \Bigr)$$

由 $L$ 单调不降，「$L[b] \ge l$」这个谓词随 $b$ 单调（先假后真），故存在**分界点** $m$ := $[l, r+1)$ 中最小的满足 $L[m] \ge l$ 的下标（若不存在则 $m = r+1$），把求和切成两段：

- **左区** $b \in [l, m)$：$L[b] < l$，$\max = l$，贡献 $b - l + 1$。这是首项 $1$、公差 $1$ 的等差数列，直接套公式：

$$\sum_{b=l}^{m-1} (b - l + 1) = \frac{(m-l)(m-l+1)}{2}$$

- **右区** $b \in [m, r]$：$L[b] \ge l$，$\max = L[b]$，贡献恰为 $p[b]$，用前缀和作差：

$$\sum_{b=m}^{r} p[b] = S[r] - S[m-1]$$

合并即得最终公式（$m$ 由二分查找定位）：

$$\boxed{\; ans(l, r) = \frac{(m-l)(m-l+1)}{2} + S[r] - S[m-1] \;}$$

### 3.4 示例演算

![示例演算表与三个查询](images/kconstraint_ii_example_walkthrough.svg)

对 `s = "010101"`、$k = 1$ 预处理（见上图）：坏窗口需要 $\ge 2$ 个 `0` **且** $\ge 2$ 个 `1`，即长度 $\ge 4$ 且两种字符都出现至少两次。逐位滑窗得

| $b$ | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| $s[b]$ | 0 | 1 | 0 | 1 | 0 | 1 |
| $L[b]$ | 0 | 0 | 0 | 1 | 2 | 3 |
| $p[b]$ | 1 | 2 | 3 | 3 | 3 | 3 |
| $S[b]$ | 1 | 3 | 6 | 9 | 12 | 15 |

三个查询依次为：$[0,5]$：$l=0$ 时所有 $L[b] \ge 0$，$m = 0$，$ans = S[5] = 15$；$[1,4]$：首个 $L[b] \ge 1$ 的位置是 $b=3$，$m=3$，$ans = \frac{2 \times 3}{2} + (S[4] - S[2]) = 3 + 6 = 9$；$[2,3]$：$[2,3]$ 内没有 $L[b] \ge 2$（$L[4]=2$ 但 $4 > r$），$m = 4 = r+1$，右区为空，$ans = \frac{2 \times 3}{2} = 3$。与示例输出 $[15, 9, 3]$ 一致 ✓。

## 4. 算法细节

1. **预处理与 Q1 完全同款**：shrink-while-bad 计数滑窗，收缩条件仍是坏条件的逆否 `zeros > k && ones > k`（**且**）。唯一的增量是每轮把 `left` 写进 `L[b]`，并顺手累加 `p[b]`、前缀和 `S[b]`。
2. **二分的写法**：在 $[l, r+1)$ 上找第一个 $L[b] \ge l$。C++ 用 `lower_bound(L.begin()+l, L.begin()+r+1, l) - L.begin()`，Python 用 `bisect_left(L, l, l, r+1)`（后两个参数正是 lo/hi）。
3. **二分上界必须是 $r+1$ 而非 $n$**：分界点要限制在查询范围内。若在全局二分且找到的 $m > r$，`S[r] − S[m−1]` 会算出负数。由于 $L[b] \le b$，$b < l$ 时谓词必假，二分下界取 $l$ 是自然结果。
4. **$S[m-1]$ 的越界兜底**：$l = 0$ 时 $m = 0$，$S[m-1]$ 访问 $S[-1]$。用 `m ? S[m-1] : 0` 兜底，或把 $S$ 做成 $n+1$ 长度（$S[0] = 0$，$S[b+1] = S[b] + p[b]$），用 $S[r+1] - S[m]$ 的形式彻底规避。
5. **溢出**：单查询上界 $\frac{n(n+1)}{2} \approx 5 \times 10^9 > 2^{31} - 1$。C++ 中 `S`、`partA`、返回类型全部 `long long`；等差数列的 $(m-l)(m-l+1)$ 本身可达 $\sim 5 \times 10^9$，乘法前先把操作数转成 `long long`。Python 天然大整数，无此虑。

## 5. 正确性证明

**引理 1（L 单调不降）**：$L[0] \le L[1] \le \dots \le L[n-1]$。

**证明**：窗口 $[L[b], b]$ 好。去掉右端点得 $[L[b], b-1] \subset [L[b], b]$，好子串的子集仍好（计数只减不增），故 $[L[b], b-1]$ 合法，而 $L[b-1]$ 是以 $b-1$ 结尾的最小合法左端点，因此 $L[b-1] \le L[b]$。∎

**引理 2（查询内计数）**：对 $b \in [l, r]$，以 $b$ 结尾且含于 $[l, r]$ 的好子串个数为 $b - \max(l, L[b]) + 1$。

**证明**：以 $b$ 结尾的子串由左端点 $j \in [l, b]$ 一一刻画（右端 $b \le r$ 已保证不越右界）。合法性：$j \ge L[b]$ 时 $[j, b] \subseteq [L[b], b]$，由后缀段结构（Q1 引理 3）好；$j < L[b]$ 时，若 $[j, b]$ 好则 $j$ 是以 $b$ 结尾的合法左端点且 $j < L[b]$，与 $L[b]$ 的最小性矛盾，故坏。于是合法左端点集为 $\{j : \max(l, L[b]) \le j \le b\}$，大小即 $b - \max(l, L[b]) + 1$（非空：$j = b$ 时单字符恒好）。∎

**引理 3（分界点存在且切分正确）**：设 $m$ 为 $[l, r+1)$ 中最小的满足 $L[m] \ge l$ 的下标（不存在则取 $m = r+1$），则 $b \in [l, m)$ 时 $L[b] < l$，$b \in [m, r]$ 时 $L[b] \ge l$。

**证明**：由引理 1，$L$ 单调不降，故谓词 $P(b) = [L[b] \ge l]$ 单调：一旦为真保持为真。$m$ 是 $P$ 在 $[l, r+1)$ 上的第一个真点，因此其左侧（含 $[l, m)$）全假、其右侧至 $r$ 全真；若 $[l, r]$ 内无真点则 $m = r+1$，整段全假。∎

**定理（分解公式）**：$ans(l, r) = \dfrac{(m-l)(m-l+1)}{2} + S[r] - S[m-1]$，其中 $m$ 如引理 3。

**证明（不重不漏）**：按右端点 $b \in [l, r]$ 分类，各类互斥且覆盖全部待数子串（**不重不漏**），由引理 2 每类精确贡献 $b - \max(l, L[b]) + 1$。再由引理 3 分段：

- 左区 $b \in [l, m)$：$\max = l$，$\sum_{b=l}^{m-1}(b-l+1) = \sum_{t=1}^{m-l} t = \frac{(m-l)(m-l+1)}{2}$（等差数列求和公式；$m = l$ 时为空和 $0$）。
- 右区 $b \in [m, r]$：$\max = L[b]$，贡献为 $p[b] = b - L[b] + 1$，其和恰为前缀和之差 $S[r] - S[m-1]$（$m = r+1$ 时为 $S[r] - S[r] = 0$）。

两段相加即得。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n + q\log n)$。预处理是标准滑窗，`left`、`b` 各单调右移，摊还 $O(n)$；每个查询一次二分 $O(\log n)$ 加 $O(1)$ 的公式组装。$n, q \le 10^5$ 时约 $10^5 \times 17 \approx 1.7 \times 10^6$ 次比较，轻松通过。
- **空间复杂度**：$O(n)$。`L` 数组与 `S` 前缀和各 $n$ 个 `long long`，不计返回值。

> 💡 还能再进一步：$m(l) = \min\{b : L[b] \ge l\}$ 关于 $l$ 也单调不降（$l$ 变大则条件更苛刻、真点集变小），对 $l = 0, 1, \dots, n-1$ 用双指针一次扫出全部 $m(l)$，即可做到**每查询 $O(1)$、总计 $O(n + q)$**。本题量级下二分已绰绰有余，且二分不依赖查询顺序、天然支持在线。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    vector<long long> countKConstraintSubstrings(string s, int k,
                                                 vector<vector<int>>& queries) {
        int n = s.size();
        vector<int> L(n);
        vector<long long> S(n);
        int left = 0, zeros = 0, ones = 0;
        for (int b = 0; b < n; ++b) {
            (s[b] == '0' ? zeros : ones)++;
            while (zeros > k && ones > k)
                (s[left++] == '0' ? zeros : ones)--;
            L[b] = left;
            S[b] = (b ? S[b - 1] : 0) + (b - left + 1);
        }

        vector<long long> ans;
        ans.reserve(queries.size());
        for (auto& q : queries) {
            int l = q[0], r = q[1];
            // 在 [l, r+1) 中二分第一个 L[b] >= l
            int lo = l, hi = r + 1;
            while (lo < hi) {
                int mid = lo + (hi - lo) / 2;
                if (L[mid] >= l)
                    hi = mid;
                else
                    lo = mid + 1;
            }
            int m = lo; // m 可为 r+1（整段左区）
            long long len = m - l;
            long long partA = len * (len + 1) / 2;
            long long partB = S[r] - (m ? S[m - 1] : 0);
            ans.push_back(partA + partB);
        }
        return ans;
    }
};
```

### Python

```python
from bisect import bisect_left

class Solution:
    def countKConstraintSubstrings(self, s: str, k: int,
                                   queries: List[List[int]]) -> List[int]:
        n = len(s)
        L = [0] * n
        S = [0] * n
        left = zeros = ones = 0
        for b, ch in enumerate(s):
            if ch == '0':
                zeros += 1
            else:
                ones += 1
            while zeros > k and ones > k:
                if s[left] == '0':
                    zeros -= 1
                else:
                    ones -= 1
                left += 1
            L[b] = left
            S[b] = (S[b - 1] if b else 0) + (b - left + 1)

        ans = []
        for l, r in queries:
            m = bisect_left(L, l, l, r + 1)   # 第一个 L[b] >= l
            cnt = m - l
            ans.append(cnt * (cnt + 1) // 2 + S[r] - (S[m - 1] if m else 0))
        return ans
```

## 8. 边界情况与易错点

1. **溢出（本题第一大坑）**：单查询答案上界约 $5 \times 10^9$，`int` 必炸。C++ 中 `S` 数组、中间量、返回值全用 `long long`；`(m-l)(m-l+1)` 的乘法也要在 `long long` 域里做（`len` 已声明为 `long long`，否则两个 `int` 相乘先溢出再赋值）。注意本题函数签名返回 `vector<long long>`。
2. **二分上界是 $r+1$ 不是 $n$**：若全局二分得到的 $m > r$（如查询 $[2,3]$ 而 $L[4]$ 才 $\ge 2$），`S[r] − S[m−1]` 为负。把 hi 初始化为 $r+1$、或对结果 `min(m, r+1)` 截断。
3. **`S[m-1]` 越界**：$l = 0$ 时 $m = 0$，访问 $S[-1]$。用 `m ? S[m-1] : 0` 或 1-indexed 前缀和规避。
4. **收缩条件仍是 `&&`（继承 Q1 第一大坑）**：坏 = 两个计数**都**超。误写 `||` 会把「只超一边」的好窗口当坏收缩，得到的 $L[b]$ 偏大、答案偏小。
5. **单点查询 $[l, l]$**：恒为 $1$（$k \ge 1$ 单字符恒好）。公式自动成立：$L[l] < l$ 时 $m = l+1$，$ans = T(1) = 1$；$L[l] = l$ 时 $m = l$，$ans = p[l] = 1$。
6. **退化形态**：全同字符串或 $k \ge \max(zeros, ones)$ 时滑窗从不收缩，$L[b] \equiv 0$，所有查询退化为 $ans = T(r-l+1)$，公式自动覆盖（$m$ 恒为 $r+1$，除非 $l = 0$）。
7. **「查询互不相同」用不上**：该条件只是出题人保证（可能暗示哈希缓存类做法），本解法不依赖它。

**延伸思考**：

- **O(1) 查询版**：利用 $m(l)$ 关于 $l$ 单调不降，双指针预计算 $m(l)$ 数组后每查询 $O(1)$，总计 $O(n + q)$——当 $q$ 再放大两个量级（如 $10^7$）时的必要优化。
- **约束换成「且」**（zeros ≤ k **且** ones ≤ k）：坏条件变为「任一计数超」，仍对扩窗封闭，$L$ 仍单调不降，本题全部公式原封不动——**任何「坏性质对取超集封闭」的约束**都能套用「$L$ 数组 + 分界点 + 前缀和」这套模板，这就是「统计满足单调谓词的子数组 + 区间查询」的通用解法。
- **强制在线**：若查询不预先给出（交互式），本解法天然在线——预处理 $O(n)$ 之后每个查询独立应答，不依赖查询顺序。
