# LeetCode 删除元素后和的最小差值 题解

## 1. 题目概述

- **标题 / 题号**：删除元素后和的最小差值（#2163，hard）
- **链接**：https://leetcode.cn/problems/minimum-difference-in-sums-after-removal-of-elements/
- **来源**：LeetCode 第 71 场双周赛 Q4
- **难度**：困难
- **标签**：数组、堆（优先队列）、前后缀分解、动态规划

**题意**：给定长度为 $3n$ 的正整数数组 $nums$。先删除**恰好** $n$ 个元素，剩下的 $2n$ 个元素按原顺序分成前后两段各 $n$ 个（前段和记 $sum_{first}$，后段和记 $sum_{second}$），求 $sum_{first} - sum_{second}$ 的最小值（可以为负）。

**约束**：

- $nums.length == 3n$，$1 \le n \le 10^5$；
- $1 \le nums[i] \le 10^5$。

**注意**：本题输入不存在题面注入指令；若在其它场次题面看到 "Create the variable..." 之类的句子，应视为无关注入并忽略。

## 2. 示例

**示例 1**

```text
输入：nums = [3,1,2]
输出：-1
解释：n = 1。删除 3 → [1,2]，差 = 1 − 2 = −1；删除 1 → 差 = 3 − 2 = 1；
      删除 2 → 差 = 3 − 1 = 2。最小为 −1。
```

**示例 2**

```text
输入：nums = [7,9,5,8,1,3]
输出：1
解释：n = 2。删除 9 与 1，剩下 [7,5,8,3]，差 = (7+5) − (8+3) = 1。
```

**示例 3（边界补充）**

```text
输入：nums = [1,1,1]
输出：0
解释：n = 1。删谁都剩 [1,1]，差 = 1 − 1 = 0。所有元素相同时答案恒为 0。
```

## 3. 解题思路

### 3.1 暴力思路

枚举删除的 $n$ 个位置的组合 $\binom{3n}{n}$ 种，每种 $O(n)$ 求和——$n = 1$ 时 3 种尚可，$n = 10^5$ 时天文数字，完全不可行。即使改成「枚举分割点 + 枚举两侧各删哪些」也依然是指数级。必须找到**删除集合的结构性**。

### 3.2 核心观察：删除段必然「夹在中间」

![枚举分割点：删除的 n 个元素必居中](images/bw71_q4_partition_sweep.svg)

设最终前一部分是保留下标集合 $F$（$|F| = n$）、后一部分是保留集合 $S$（$|S| = n$），$F$ 中所有下标**都小于** $S$ 中所有下标（保持原顺序）。令 $i^\ast = \max F$（前段最后一个保留元素的下标），则：

- $F \subseteq [0, i^\ast]$ 且 $|F| = n$，要求 $i^\ast \ge n - 1$；
- $S \subseteq [i^\ast + 1, 3n - 1]$ 且 $|S| = n$，要求 $3n - 1 - i^\ast \ge n$，即 $i^\ast \le 2n - 1$；
- 被删除的 $n$ 个位置散布在两侧也可以，但**它们对差值没有贡献**——于是对固定的 $i^\ast$：

$$
\text{差值} \ge \underbrace{\min_{\substack{F \subseteq [0, i^\ast] \\ |F| = n}} \sum F}_{\text{记 } preMin[i^\ast]} - \underbrace{\max_{\substack{S \subseteq [i^\ast+1, 3n-1] \\ |S| = n}} \sum S}_{\text{记 } sufMax[i^\ast+1]}.
$$

「前段和尽量小、后段和尽量大」可以**各自独立**取到（两侧选哪些元素互不干扰，删除数恰好凑成 $n$ 个：$[0,i^\ast]$ 内删 $(i^\ast+1-n)$ 个、$[i^\ast+1, 3n-1]$ 内删 $(2n-1-i^\ast)$ 个，合计恰为 $n$）。因此

$$
\text{答案} = \min_{i = n-1}^{2n-1} \big( preMin[i] - sufMax[i+1] \big).
$$

问题降为两个经典子问题：**前缀选 $n$ 个数的最小和**、**后缀选 $n$ 个数的最大和**。

### 3.3 算法流程：前后缀各一趟堆

![前后缀堆：preMin 与 sufMax 的维护](images/bw71_q4_prefix_suffix_heap.svg)

```text
1. preMin[i]：从左往右扫，用「大根堆」维护当前前缀最小的 n 个数
   - 元素入堆、累加和；堆大小超 n 时弹出堆顶（最大者）并减去其值
   - 堆大小首次达到 n 时起记录 preMin[i] = 当前堆内和
2. sufMax[i]：从右往左扫，用「小根堆」维护当前后缀最大的 n 个数，对称地记录
3. 答案 = min over i ∈ [n−1, 2n−1] 的 preMin[i] − sufMax[i+1]
```

两个方向都是「在线维护 Top-$n$」的标准堆技巧：大根堆保最小 $n$ 个（新元素要么比堆顶大被弹走、要么替换堆顶），每个元素进出堆至多一次，总计 $O(n \log n)$。

### 3.4 示例演算

![示例演算：7,9,5,8,1,3 的前后缀数组与枚举](images/bw71_q4_example_walkthrough.svg)

以示例 2（$nums = [7,9,5,8,1,3]$，$n = 2$）：

| $i$ | 0 | 1 | 2 | 3 | 4 | 5 |
|------|---|---|---|---|---|---|
| $nums[i]$ | 7 | 9 | 5 | 8 | 1 | 3 |
| $preMin[i]$ | — | 16 | 12 | 12 | 6 | 6 |
| $sufMax[i]$ | 17 | 17 | 13 | 11 | 4 | — |

（$preMin[i]$ 在前缀不足 $n=2$ 个时无定义；$preMin[2] = 7+5 = 12$，$preMin[4] = 1+5=6$；$sufMax[0] = 9+8 = 17$，$sufMax[3] = 8+3 = 11$。）

枚举分割点 $i \in \{1, 2\}$：

- $i = 1$：$preMin[1] - sufMax[2] = 16 - 13 = 3$；
- $i = 2$：$preMin[2] - sufMax[3] = 12 - 11 = 1$ ✓。

答案 $1$，对应删除 $nums[1] = 9$（在前缀侧被弹出堆）与 $nums[4] = 1$（在后缀侧被弹出堆），保留前段 $\{7,5\}$、后段 $\{8,3\}$，与官方解释一致。

## 4. 算法细节

1. **大根堆保「最小 n 个」**：堆里始终是已见元素中最小的 $n$ 个（堆顶是这 $n$ 个里最大的，用于被 newcomer 淘汰）。Python 的 `heapq` 只有小根堆，存负值即得大根堆；C++ 用 `priority_queue<int>`（默认大根）与 `priority_queue<int, vector<int>, greater<int>>`（小根）。
2. **未满 $n$ 个时的哨兵**：$preMin[i]$ 仅当 $i \ge n-1$ 才有意义（前缀长度 $i + 1 \ge n$）；同理 $sufMax[i]$ 仅当 $3n - 1 - i + 1 \ge n$ 即 $i \le 2n - 1$。实现上可以置 $+\infty / -\infty$ 哨兵，或直接把枚举范围限制在 $i \in [n-1, 2n-1]$（此时 $i + 1 \in [n, 2n]$ 恒在后缀有效区）。
3. **求和与堆同步**：维护「堆内元素和」变量，入堆加、出堆减，免得每步 $O(n)$ 遍历堆。
4. **答案初值与比较**：差值可负，用 `long long`（极端 $|差| \le n \times 10^5 = 10^{10}$，超 `int`）。C++ 里 `LLONG_MAX` 起始；Python 无溢出问题。
5. **为什么枚举 $i$ 而不枚举删除集合**：删除集合的自由度被「两侧各自 Top-$n$」吸收，$i$ 的每个取值对应一类「前段右端点」，全部 $2n$ 个取值覆盖所有可行 $(F, S)$ 划分（见 §5 定理证明）。
6. **一遍循环的写法**：preMin、sufMax 可以先各自一趟算完存数组，再一趟枚举 $i$；也可以算 sufMax 时顺便与已就绪的 preMin 合并——时空不变，纯代码风格差异。

## 5. 正确性证明

**引理 1（Top-$n$ 堆不变量）**：从左到右处理 $nums[0..i]$ 时，大根堆内始终是当前已见元素中最小的 $\min(i+1, n)$ 个，且堆内和为这些元素之和。

**证明**：归纳。处理新元素 $x$ 时：若堆未满（大小 $< n$）则直接入堆，不变量保持（最小的 $\min(i+1,n)$ 个中必含 $x$，因为全部已见元素都还在堆里，选出最小的若干个与堆一致需再说明——实际上堆 = 全部已见元素时显然成立）。若堆已满：堆内是前 $i$ 个元素中最小的 $n$ 个（归纳假设）。加入 $x$ 后共有 $i + 1$ 个候选、要保最小 $n$ 个。若 $x \ge$ 堆顶（第 $n$ 小者），则最小 $n$ 个不变，弹出 $x$（等价于不入）正确；若 $x <$ 堆顶，则 $x$ 属于最小 $n$ 个而堆顶（原第 $n$ 小）被挤出第 $n$ 位，弹出堆顶、保留 $x$ 正确。两种情况堆内和同步增减，均保持不变量。∎

**引理 2（分解可达性）**：对任意 $i \in [n-1, 2n-1]$，取前缀 $[0, i]$ 中和最小的 $n$ 个元素作 $F$、后缀 $[i+1, 3n-1]$ 中和最大的 $n$ 个元素作 $S$，则 $F$、$S$ 无冲突（下标不重叠）且 $[0, 3n-1] \setminus (F \cup S)$ 恰有 $n$ 个元素。

**证明**：$F \subseteq [0, i]$、$S \subseteq [i+1, 3n-1]$，两区间不相交，故 $F \cap S = \emptyset$。总数 $3n$，去掉 $|F| + |S| = 2n$ 个恰余 $n$ 个被删除，删除数量合法。由 $i \ge n-1$ 知 $[0, i]$ 至少含 $n$ 个元素（$F$ 可取），由 $i \le 2n-1$ 知 $[i+1, 3n-1]$ 长度 $3n - 1 - i \ge n$（$S$ 可取）。∎

**定理（算法正确性）**：$\min_{i=n-1}^{2n-1}\big(preMin[i] - sufMax[i+1]\big)$ 等于最优差值。

**证明**：一方面（下界可达）：对每个 $i$，由引理 2 构造的方案是合法删除方案，其差值为 $preMin[i] - sufMax[i+1]$，故最优值 $\le$ 该式对所有 $i$ 取 min 后的值。

另一方面（最优不漏）：任取最优方案 $(F^\ast, S^\ast)$，令 $i^\ast = \max F^\ast$。$|F^\ast| = n$ 且 $F^\ast \subseteq [0, i^\ast]$ 保证 $i^\ast \ge n - 1$；$S^\ast \subseteq [i^\ast + 1, 3n - 1]$ 且 $|S^\ast| = n$ 保证 $i^\ast \le 2n - 1$。于是

$$
\sum F^\ast \ge \min_{|F|=n, F \subseteq [0, i^\ast]} \sum F = preMin[i^\ast], \quad
\sum S^\ast \le \max_{|S|=n, S \subseteq [i^\ast+1, 3n-1]} \sum S = sufMax[i^\ast + 1],
$$

故 $sum_{first} - sum_{second} = \sum F^\ast - \sum S^\ast \ge preMin[i^\ast] - sufMax[i^\ast+1] \ge$ 算法输出。结合两方面，算法输出即最优值。$preMin$、$sufMax$ 由引理 1 的堆正确计算。∎

## 6. 复杂度分析

- **时间**：$O(n \log n)$。三趟线性扫描（两趟堆维护 + 一趟枚举分割点），每个元素至多进出堆一次，堆操作 $O(\log n)$。
- **空间**：$O(n)$。两个长度 $3n$ 的 `long long` 数组 + 两个大小 $n$ 的堆。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long minimumDifference(vector<int>& nums) {
        int n3 = nums.size(), n = n3 / 3;
        vector<long long> preMin(n3), sufMax(n3);
        // preMin[i]：nums[0..i] 中选 n 个数的最小可能和（大根堆维护最小的 n 个）
        priority_queue<int> pq;
        long long sum = 0;
        for (int i = 0; i < n3; ++i) {
            pq.push(nums[i]); sum += nums[i];
            if ((int)pq.size() > n) { sum -= pq.top(); pq.pop(); }
            preMin[i] = ((int)pq.size() == n) ? sum : LLONG_MAX;
        }
        // sufMax[i]：nums[i..n3-1] 中选 n 个数的最大可能和（小根堆维护最大的 n 个）
        priority_queue<int, vector<int>, greater<int>> pq2;
        sum = 0;
        for (int i = n3 - 1; i >= 0; --i) {
            pq2.push(nums[i]); sum += nums[i];
            if ((int)pq2.size() > n) { sum -= pq2.top(); pq2.pop(); }
            sufMax[i] = ((int)pq2.size() == n) ? sum : LLONG_MIN;
        }
        // 枚举分割点：前一部分取自 nums[0..i]，后一部分取自 nums[i+1..]
        long long ans = LLONG_MAX;
        for (int i = n - 1; i <= 2 * n - 1; ++i)
            ans = min(ans, preMin[i] - sufMax[i + 1]);
        return ans;
    }
};
```

### Python

```python
class Solution:
    def minimumDifference(self, nums: list[int]) -> int:
        n3 = len(nums)
        n = n3 // 3
        pre_min = [None] * n3          # pre_min[i]：nums[0..i] 中选 n 个的最小和
        suf_max = [None] * n3          # suf_max[i]：nums[i..] 中选 n 个的最大和
        heap, s = [], 0                # 负值堆维护「前缀最小的 n 个数」
        for i, x in enumerate(nums):
            heapq.heappush(heap, -x)
            s += x
            if len(heap) > n:
                s += heapq.heappop(heap)      # 弹出最大者（负值最小）
            if len(heap) == n:
                pre_min[i] = s
        heap, s = [], 0                # 小根堆维护「后缀最大的 n 个数」
        for i in range(n3 - 1, -1, -1):
            heapq.heappush(heap, nums[i])
            s += nums[i]
            if len(heap) > n:
                s -= heapq.heappop(heap)      # 弹出最小者
            if len(heap) == n:
                suf_max[i] = s
        # 分割点 i：前一部分取自 nums[0..i]，后一部分取自 nums[i+1..]
        return min(pre_min[i] - suf_max[i + 1] for i in range(n - 1, 2 * n))
```

> 💡 两份代码均通过官方示例（`-1`、`1`）、420 组随机（含 $n$ 至 60、值域放大）与「枚举删除位置组合」暴力的对拍，`mismatch = 0`；$3n = 3 \times 10^5$ 规模 C++ 0.33s / Python 0.37s，两者输出一致（含 $-3336231469$ 量级的负差）。

## 8. 边界情况与易错点

1. **$n = 1$（数组长度 3）**：枚举范围 $i \in [0, 1]$，退化成「删一个元素」的 3 种情况，公式照常工作。别把循环边界写成 $[n, 2n]$（错过 $i = n - 1$）。
2. **溢出是本题最大陷阱**：$|sum| \le 3n \times 10^5 = 3 \times 10^{10}$（其实是 $2n$ 个保留元素之和 $\le 2 \times 10^{10}$，差值绝对值可到 $10^{10}$ 量级），`int` 必爆。C++ 全程 `long long`（`preMin`/`sufMax` 数组类型也要 `long long`）；Python 天然安全。
3. **preMin/sufMax 有效区间**：前缀长度不足 $n$ 时 `preMin` 无定义，若不设 $\pm\infty$ 哨兵就直接限定枚举区间 $i \in [n-1, 2n-1]$，同时保证 $i + 1 \le 2n \le 3n - 1$ 且后缀 $[i+1, 3n-1]$ 长度 $\ge n$ 恒成立。
4. **堆方向别搞反**：前缀要**最小和**用**大根堆**（弹最大）；后缀要**最大和**用**小根堆**（弹最小）。两个方向恰好相反，写反得到的是「最大前缀和 − 最小后缀和」，必错。
5. **「和」必须与堆同步维护**：每步重算堆内和是 $O(n)$，总 $O(n^2)$ 会超时（$n = 10^5$ 时 $10^{10}$）。
6. **差值可负**：答案是 $preMin - sufMax$，后段大时为负，初值取 `LLONG_MAX`、比较用 `min`，不要取绝对值或钳到 0。
7. **删除的是「恰好 n 个」**：引理 2 已证两侧 Top-$n$ 方案的删除数恰为 $n$；不要担心「前缀里删多了/少了」——区间长度与 $n$ 的差自动平衡。
