# LeetCode 拆分数位后四位数字的最小和 题解

## 1. 题目概述

- **标题 / 题号**：拆分数位后四位数字的最小和（#2160，easy）
- **链接**：https://leetcode.cn/problems/minimum-sum-of-four-digit-number-after-splitting-digits/
- **来源**：LeetCode 第 71 场双周赛 Q1
- **难度**：简单
- **标签**：贪心、排序、数学

**题意**：给定四位正整数 $num$（$1000 \le num \le 9999$）。把 $num$ 的四个数位**全部用上**、任意顺序拼接成两个新整数 $new1$ 与 $new2$（允许**前导 0**，位数不限），求 $new1 + new2$ 的最小值。

**约束**：

- $1000 \le num \le 9999$，固定 4 个数位；
- 每个数位必须使用且仅使用一次；
- $new1$、$new2$ 允许前导 0，例如数位 $\{0,0,4,9\}$ 可拼出 $04$ 与 $09$。

## 2. 示例

**示例 1**

```text
输入：num = 2932
输出：52
解释：数位为 {2, 9, 3, 2}。最优拆分 [29, 23]，29 + 23 = 52。
```

**示例 2**

```text
输入：num = 4009
输出：13
解释：数位为 {4, 0, 0, 9}。最优拆分 [04, 09]，即 4 + 9 = 13（前导 0 是允许的）。
```

**示例 3（边界补充）**

```text
输入：num = 1000
输出：1
解释：数位 {1, 0, 0, 0} 拆成 00 与 01，和为 0 + 1 = 1。
```

## 3. 解题思路

### 3.1 暴力思路

四个数位的全排列共 $4! = 24$ 种，每个排列有 $1+3$、$2+2$、$3+1$ 三种拆分点，共 $72$ 种组合，逐一求和取最小即可——$O(1)$ 常数级，当然能过。但这题值得提炼的是**为什么最优解一定是「两位 + 两位」**，以及两位配对时数位怎么分工，这个观察可以把 72 种枚举压缩成一个排序加一行公式。

### 3.2 核心观察：两个两位数求和，十位权重是 10

![核心观察：最小两个数位放十位](images/bw71_q1_digit_split_concept.svg)

把四个数位排序为 $d_0 \le d_1 \le d_2 \le d_3$，任取「两位 + 两位」拆分，两个新数形如 $10a + b$ 与 $10c + d$，其中 $\{a,b,c,d\}$ 是四个数位的一个排列。于是

$$
(10a + b) + (10c + d) = 10 \times (a + c) + (b + d).
$$

**关键**：$b + d$（个位数字之和）与 $a + c$（十位数字之和）合起来恰是四个数位总和，是个**常数**；要让总和最小，只需让被乘 10 的 $a + c$ **尽量小**——即让最小的两个数位 $d_0, d_1$ 当十位、$d_2, d_3$ 当个位：

$$
\text{答案} = 10 \times (d_0 + d_1) + (d_2 + d_3).
$$

至于 $d_0$ 与 $d_1$ 谁跟 $d_2$ 配对、谁跟 $d_3$ 配对，**不影响和**（十位和与个位和都已固定）。

### 3.3 算法流程

```text
1. 逐位取出 num 的 4 个数位（% 10 与 / 10）
2. 升序排序得 d0 <= d1 <= d2 <= d3
3. 返回 10*(d0 + d1) + (d2 + d3)
```

### 3.4 示例演算

![示例演算：2932 与 4009 的拆分过程](images/bw71_q1_example_walkthrough.svg)

**示例 1**（$num = 2932$）：数位排序为 $[2, 2, 3, 9]$，答案 $= 10 \times (2+2) + (3+9) = 40 + 12 = 52$，对应拆分 $23 + 29$。

**示例 2**（$num = 4009$）：数位排序为 $[0, 0, 4, 9]$，答案 $= 10 \times (0+0) + (4+9) = 13$，对应拆分 $04 + 09 = 4 + 9$。前导 0 让「两位 + 两位」永远可行。

## 4. 算法细节

1. **取数位**：`for (int i = 0; i < 4; ++i) { d[i] = num % 10; num /= 10; }`，顺序无所谓，反正要排序。
2. **排序**：固定 4 个元素，任何排序（插入、`sort`）都是常数时间。Python 里 `sorted(str(num))` 直接得到字符序（数字字符的字典序与数值序一致）。
3. **配对无关性**：公式只依赖「十位数字集合 = $\{d_0, d_1\}$」，因此 $d_0d_2 + d_1d_3$ 与 $d_0d_3 + d_1d_2$ 相等，无需再枚举配对。
4. **为什么不会出现「位数不均」更优**：见 §5 引理 1，三位数（百位权重 100）必然劣于两位拆分。

## 5. 正确性证明

**引理 1（两位最优性）**：存在一个最优拆分，其中 $new1$ 与 $new2$ 都是两位数。

**证明**：设某拆分为「一位数 $u$ 与三位数 $\overline{abc}$」（$a$ 为百位数字）。构造两位拆分：把 $u$ 与 $a$ 中较小者记为 $x$、较大者记为 $y$，取 $new_1' = \overline{xb}$（$x$ 作十位、$b$ 作个位），$new_2' = \overline{yc}$。则

$$
new_1' + new_2' = 10(x + y) + (b + c) \le 100a + 10b + c + u,
$$

因为右边 $= 10(a + u) + 90a + (b + c)$，而 $x + y = a + u$，故右边减左边 $= 90a \ge 0$。即任意一位/三位拆分都能被某个两位拆分替代且和**不增**。两位/两位与一位/三位穷尽了所有位数组合（四位/零位即一个数为 0 等价于把全部数位给另一个数，四位数百位权重 100 同理更劣），故最优解可取两位拆分。∎

**引理 2（十位集合决定和）**：两位拆分 $new_1 = 10a + b$、$new_2 = 10c + d$ 的和为 $10(a+c) + (b+d)$，其中 $a + c + b + d = S$（四数位总和，常数）。

**证明**：直接展开 $10a + b + 10c + d = 10(a+c) + (b+d)$，且四个数位恰被 $a, b, c, d$ 不重不漏地使用。∎

**定理**：设 $d_0 \le d_1 \le d_2 \le d_3$ 为升序数位，则 $10(d_0 + d_1) + (d_2 + d_3)$ 是最小可能的和。

**证明**：由引理 1，只需在两位拆分中取最小。由引理 2，和 $= 10T + (S - T) = S + 9T$，其中 $T = a + c$ 是十位数字之和，$S$ 为常数。故最小化和 $T$：十位集合是四个数位中大小为 2 的子集，其和的最小值显然在取最小两个元素 $d_0, d_1$ 时达到（任取其它子集 $\{x, y\}$，若含 $d_2$ 或 $d_3$，则用 $d_0$ 或 $d_1$ 替换其中较大者不会增大和）。此时 $T = d_0 + d_1$，个位和为 $S - T = d_2 + d_3$，得证。∎

## 6. 复杂度分析

- **时间**：$O(1)$。固定 4 个数位的取出与排序均为常数操作（若视 $num$ 位数为变量则为 $O(k \log k)$，$k = 4$）。
- **空间**：$O(1)$。仅一个长度 4 的临时数组。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minimumSum(int num) {
        int d[4];
        for (int i = 0; i < 4; ++i) { d[i] = num % 10; num /= 10; }
        sort(d, d + 4);                       // d0 <= d1 <= d2 <= d3
        return 10 * (d[0] + d[1]) + (d[2] + d[3]);   // 两个最小数位当十位
    }
};
```

### Python

```python
class Solution:
    def minimumSum(self, num: int) -> int:
        d = sorted(str(num))                      # 四个数位升序
        return int(d[0] + d[2]) + int(d[1] + d[3])  # 最小两个当十位
```

> 💡 两份代码均通过官方示例（`52`、`13`）以及 $num \in [1000, 9999]$ 全量 9000 组与「全排列 × 三种拆分点」暴力的对拍，`mismatch = 0`。

## 8. 边界情况与易错点

1. **前导 0 必须利用**：$4009$ 的答案是 $04 + 09 = 13$ 而不是 $40 + 09$。若把 0 排除在十位候选之外就会错。
2. **重复数位**：$2932$ 有两个 2，排序后 $d_0 = d_1 = 2$，公式照常适用；不要去重。
3. **最小输入 $1000$**：数位 $[0,0,0,1]$，答案 $00 + 01 = 1$，不是 $10$——「两位数」允许是 $00$。
4. **别枚举配对**：$d_0$ 配 $d_2$ 还是 $d_3$ 结果相同，多写一层循环纯属浪费；但也别因此把个位/十位搞反（$10(d_2+d_3) + (d_0+d_1)$ 是**最大**和）。
5. **取位顺序**：`% 10` 从低位取起，顺序无需在意；若用字符串则注意 `str(num)` 长度恒为 4。
