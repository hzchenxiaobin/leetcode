# LeetCode 网格图中最少访问的格子数 题解

## 1. 题目概述

- **标题 / 题号**：网格图中最少访问的格子数（#2617，hard）
- **链接**：https://leetcode.cn/problems/minimum-number-of-visited-cells-in-a-grid/
- **来源**：LeetCode 第 340 场周赛 Q4
- **难度**：困难
- **标签**：动态规划、线段树、DAG 上 DP、矩阵、广度优先搜索

**题意**：给定 $m \times n$ 的 0-indexed 整数矩阵 `grid`，初始位于左上角 $(0,0)$。位于 $(i,j)$ 时可以移动到：

- **向右**：同行格子 $(i,k)$，要求 $j < k \le j + \text{grid}[i][j]$；
- **向下**：同列格子 $(k,j)$，要求 $i < k \le i + \text{grid}[i][j]$。

返回到达右下角 $(m-1,\,n-1)$ 时**访问过的最少格子数**（含起点与终点）；无法到达返回 $-1$。

**约束**：

- $1 \le m,\ n \le 10^5$，且 $1 \le m \times n \le 10^5$
- $0 \le \text{grid}[i][j] < m \times n$
- $\text{grid}[m-1][n-1] = 0$

## 2. 示例

**示例 1**

```text
输入：grid = [[3,4,2,1],[4,2,3,1],[2,1,0,0],[2,4,0,0]]
输出：4
解释：一条最优路径 (0,0) → (0,1) → (3,1) → (3,3)，共 4 格。
```

**示例 2**

```text
输入：grid = [[3,4,2,1],[4,2,1,1],[2,1,1,0],[3,4,1,0]]
输出：3
解释：最优路径 (0,0) → (3,0) → (3,3)，共 3 格。
```

**示例 3**

```text
输入：grid = [[2,1,0],[1,0,0]]
输出：-1
解释：能走到的格子 (0,1)、(0,2)、(1,0)、(1,1) 的 g 值都不足以跳到 (1,2)，
      右下角不可达。
```

## 3. 解题思路

### 3.1 暴力思路：BFS / 正向 DP 枚举邻居

「最少访问格子数」就是无权图最短路的**节点数**，第一反应是 BFS：从 $(0,0)$ 层序扩散，每格出队时枚举它向右 $O(n)$ 个、向下 $O(m)$ 个邻居。但每个格子的邻居多达 $O(m+n)$ 个，总运算量 $O\big(mn(m+n)\big)$；$mn \le 10^5$ 而 $m+n$ 最多约 $10^5$，最坏 $10^{10}$，必然超时。

正向 DP 也卡在同一个地方：$f[i][j]$ 的**前驱**是 $\{\,(i,k) : k < j \le k + \text{grid}[i][k]\,\} \cup \{\,(k,j) : k < i \le k + \text{grid}[k][j]\,\}$——这是按 $k + \text{grid}[\cdot]$ 过滤的**条件集合**，没有任何区间结构，逐个枚举仍是每格 $O(m+n)$。

### 3.2 核心观察：反向定义 DP，后继是连续区间

移动只让 $i$ 或 $j$ **严格增大**，移动图是 **DAG**。把 $f$ 反过来定义——

$$f[i][j] = \text{从 } (i,j) \text{ 出发到 } (m-1,\,n-1) \text{ 的最少访问格子数（含自身）}$$

则 $(i,j)$ 的**决策对象（后继）**恰好是两段**连续区间**（记 $g = \text{grid}[i][j]$）：

- 向右：行 $i$ 上的列区间 $[\,j+1,\ \min(j+g,\ n-1)\,]$
- 向下：列 $j$ 上的行区间 $[\,i+1,\ \min(i+g,\ m-1)\,]$

$$f[m-1][n-1] = 1, \qquad f[i][j] = 1 + \min\Big(\ \min_{k \in [\,j+1,\ \min(j+g,\,n-1)\,]} f[i][k],\quad \min_{k \in [\,i+1,\ \min(i+g,\,m-1)\,]} f[k][j]\ \Big)$$

区间为空或全为 $\infty$（不可达）时 $f[i][j] = \infty$。

![核心观察：从 (i,j) 出发的后继是两段连续区间，倒序 DP 用线段树查区间最小值](images/wc340_q4_reverse_dp_model.svg)

> 💡 正向的「前驱」是按 $k + \text{grid}[\cdot] \ge$ 目标过滤的**条件集合**，反向的「后继」是**连续下标区间**——这是从 $O(mn(m+n))$ 降到 $O(mn\log)$ 的关键一步，也是本题最值得沉淀的套路：**转移对象没结构时，换个方向定义状态。**

### 3.3 算法流程：倒序行优先扫描 + 每行/每列一棵区间最小线段树

按 $i$ 从 $m-1$ 到 $0$、$j$ 从 $n-1$ 到 $0$ 的**倒序行优先序**扫描（保证算 $(i,j)$ 时它右边、下面的格子全部算完），配合两组线段树：

- **行树** `rows[i]`：以**列下标**为叶子位置，维护已算出的 $f[i][\cdot]$ 的区间最小值；
- **列树** `cols[j]`：以**行下标**为叶子位置，维护已算出的 $f[\cdot][j]$ 的区间最小值。

处理 $(i,j)$ 时做两次**闭区间查询**取 `best`；若 `best = ∞` 说明该格到不了终点（不插入，树中永远只有有限值）；否则 $f = \text{best} + 1$，**同时**插入行树与列树。$(0,0)$ 是最后一个被处理的格子，算完即得答案。

![算法流程：倒序行优先扫描，每格两次区间查询 + 两次单点插入](images/wc340_q4_segment_tree_flow.svg)

### 3.4 示例演算

以示例 2 `grid = [[3,4,2,1],[4,2,1,1],[2,1,1,0],[3,4,1,0]]` 为例，倒序算出全部 $f$ 值（$\infty$ 表示该格出发不可达终点）：

| $f$ | $j{=}0$ | $j{=}1$ | $j{=}2$ | $j{=}3$ |
|-----|---------|---------|---------|---------|
| $i{=}0$ | **3** | 3 | 4 | $\infty$ |
| $i{=}1$ | 3 | 3 | 4 | $\infty$ |
| $i{=}2$ | 3 | 3 | 3 | $\infty$ |
| $i{=}3$ | 2 | 2 | 2 | **1** |

- 终点：$f[3][3] = 1$。
- 行 3（$g = [3,4,1,0]$，自右向左）：$f[3][2] = 1 + f[3][3] = 2$；$f[3][1] = 1 + \min(f[3][2], f[3][3]) = 2$；$f[3][0] = 1 + \min(f[3][1], f[3][2], f[3][3]) = 2$——**一次区间查询** `rows[3].查询(1, 3)` 直接拿到区间最小值。
- $f[0][0]$：向右查询 `rows[0].查询(1, 3)` 得 $\min(3,4,\infty) = 3$；向下查询 `cols[0].查询(1, 3)` 得 $\min(f[1][0], f[2][0], f[3][0]) = 2$；故 $f[0][0] = 1 + 2 = \mathbf{3}$。

![示例演算：f 值表与最优路径 (0,0)→(3,0)→(3,3)](images/wc340_q4_walkthrough.svg)

> ⚠️ 注意最后一列除终点外全是 $\infty$：这些格子 $g$ 太小，向右出界、向下够到的也都是 $\infty$ 格。$\infty$ 格**不入树**，后续查询自然返回 $\infty$，无需任何特判。

## 4. 算法细节

1. **线段树只需两种操作**：单点插入（只取更小值）+ 闭区间查 min。叶子只会被 chmin、从不增大，沿插入路径同步 chmin 祖先即可，迭代实现约 20 行。
2. **区间右端点必须截断**：向右区间右端是 $\min(j+g,\ n-1)$，向下是 $\min(i+g,\ m-1)$。$g$ 可达 $mn \le 10^5$ 量级，$j + g$ 不会溢出 int，但不截断会让查询下标越界。
3. **两棵树都要插**：$f[i][j]$ 既服务「行 $i$ 后续格子的向右查询」，也服务「列 $j$ 后续格子的向下查询」，插漏一棵会让另一方向的查询永远看不到该值，$f$ 系统性偏大。
4. **不可达格不入树**：树中只存在有限 $f$ 值，`best == ∞` 直接跳过；「查不到 = 不可达」的语义让代码不需要处理 $\infty$ 的传播。
5. **答案即 $f[0][0]$**：$f$ 的口径是「含自身的格子数」，终点为 $1$，全程不需要再 $+1$。
6. **特判 $m = n = 1$**：起点即终点，直接返回 $1$，避免与「终点初始化」分支纠缠。

## 5. 正确性证明

**引理 1（DAG 与倒序行优先序的合法性）**：每条移动规则都使 $i$ 或 $j$ 严格增大，故移动图无环，是 DAG；且对任意格 $(i,j)$，其全部后继——向右的 $(i,k)\,(k > j)$、向下的 $(k,j)\,(k > i)$——在「$i$ 从 $m-1$ 降到 $0$、$j$ 从 $n-1$ 降到 $0$」的倒序行优先扫描中都**先于** $(i,j)$ 被处理。

**证明**：同一行内 $j$ 更大者先处理（$j$ 降序），行号更大者先处理（$i$ 降序），二者恰好覆盖「$k > j$」与「$k > i$」两类后继。∎

**引理 2（转移方程）**：$f[i][j]$ 如 3.2 节定义，不可达记为 $\infty$，$g = \text{grid}[i][j]$。则 $f[m-1][n-1] = 1$；其余格满足 3.2 节的双重 min 递推，且区间为空或全 $\infty$ 时取 $\infty$。

**证明**：

1. $(i,j) = (m-1, n-1)$ 时路径仅含自身，$f = 1$。
2. $(i,j)$ 可达终点且非终点时：由题面，任何合法路径的第一步必落入两段后继区间之一，设第一步到达 $s$。
   - **上界**：取后继中 $f$ 最小的 $s^\ast$，「$(i,j)$ +（$s^\ast$ 出发的最优路径）」是合法路径，共 $1 + f[s^\ast]$ 格，故 $f[i][j] \le 1 + \min_s f[s]$；
   - **下界**：取 $(i,j)$ 出发的最优路径，设第一步到 $s_0$，其后缀是 $s_0$ 出发的一条路径，格子数为 $f[i][j] - 1$，故 $f[s_0] \le f[i][j] - 1$，即 $f[i][j] \ge 1 + \min_s f[s]$。两边夹逼得等号。
3. $(i,j)$ 不可达终点时：其任一后继均不可达（若某后继可达，则 $(i,j)$ 经它可达，矛盾），递推右侧为 $\infty$，与定义一致。∎

**定理**：上述「倒序行优先扫描 + 两组线段树」算法返回值等于 $f[0][0]$；$f[0][0] = \infty$ 时返回 $-1$。

**证明**：对倒序行优先序作归纳。由引理 1，处理 $(i,j)$ 时其全部后继已算出并已插入两棵树；行树/列树的「闭区间查 min」返回的恰是引理 2 递推右端的两个区间最小值（未插入即 $\infty$），故每个 $f[i][j]$ 均按引理 2 精确计算。$(0,0)$ 是最后处理的格子：可达则当场返回 $f[0][0]$；不可达则被跳过，扫描自然结束，算法返回 $-1$。∎

## 6. 复杂度分析

- **时间复杂度**：$O\big(mn \cdot \log \max(m, n)\big)$。每个格子至多 2 次区间查询 + 2 次单点插入，每次 $O(\log \max(m,n))$；$mn \le 10^5$ 时树内操作约 $4 \times 10^5 \times 17 \approx 7 \times 10^6$ 次，轻松通过。
- **空间复杂度**：$O(mn)$。行树 $m$ 棵、每棵 $2n$ 个节点，列树 $n$ 棵、每棵 $2m$ 个节点，合计 $4mn$ 个 int（$mn \le 10^5$ 时约 1.6 MB）。

## 7. 参考代码

### C++

```cpp
class Solution {
    struct MinTree {                      // 单点 chmin + 闭区间查 min
        int n;
        vector<int> t;
        MinTree(int n) : n(n), t(2 * n, INT_MAX) {}
        void upd(int i, int v) {
            i += n;
            t[i] = min(t[i], v);
            for (; i > 1; i >>= 1)
                t[i >> 1] = min(t[i >> 1], v);
        }
        int qry(int l, int r) {           // l > r 时为空区间
            int res = INT_MAX;
            for (l += n, r += n + 1; l < r; l >>= 1, r >>= 1) {
                if (l & 1) res = min(res, t[l++]);
                if (r & 1) res = min(res, t[--r]);
            }
            return res;
        }
    };

  public:
    int minimumVisitedCells(vector<vector<int>>& grid) {
        int m = grid.size(), n = grid[0].size();
        if (m == 1 && n == 1) return 1;          // 起点即终点
        vector<MinTree> rows, cols;
        rows.reserve(m);
        cols.reserve(n);
        for (int i = 0; i < m; ++i) rows.emplace_back(n);   // 行 i：按列下标
        for (int j = 0; j < n; ++j) cols.emplace_back(m);  // 列 j：按行下标

        for (int i = m - 1; i >= 0; --i)
            for (int j = n - 1; j >= 0; --j) {
                if (i == m - 1 && j == n - 1) {  // 终点：f = 1
                    rows[i].upd(j, 1);
                    cols[j].upd(i, 1);
                    continue;
                }
                int g = grid[i][j];
                int best = min(rows[i].qry(j + 1, min(j + g, n - 1)),  // 向右
                               cols[j].qry(i + 1, min(i + g, m - 1))); // 向下
                if (best == INT_MAX) continue;   // 不可达：不入树
                int v = best + 1;
                rows[i].upd(j, v);
                cols[j].upd(i, v);
                if (i == 0 && j == 0) return v;   // 最后处理的格子
            }
        return -1;                               // 扫描结束仍未返回
    }
};
```

### Python

```python
class Solution:
    def minimumVisitedCells(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        if m == 1 and n == 1:
            return 1
        INF = float("inf")

        def build(size):
            """单点插入（更小值）+ 闭区间查 min 的迭代线段树。"""
            t = [INF] * (2 * size)

            def upd(i, v):
                i += size
                if v < t[i]:
                    t[i] = v
                    i >>= 1
                    while i and v < t[i]:     # 沿祖先链向上 chmin
                        t[i] = v
                        i >>= 1

            def qry(l, r):                  # 闭区间 [l, r]，l > r 视为空
                if l > r:
                    return INF
                res = INF
                l += size
                r += size + 1
                while l < r:
                    if l & 1:
                        if t[l] < res:
                            res = t[l]
                        l += 1
                    if r & 1:
                        r -= 1
                        if t[r] < res:
                            res = t[r]
                    l >>= 1
                    r >>= 1
                return res

            return upd, qry

        row_upd, row_qry = [None] * m, [None] * m
        col_upd, col_qry = [None] * n, [None] * n
        for i in range(m):                  # 行 i：按列下标建树
            row_upd[i], row_qry[i] = build(n)
        for j in range(n):                  # 列 j：按行下标建树
            col_upd[j], col_qry[j] = build(m)

        for i in range(m - 1, -1, -1):
            for j in range(n - 1, -1, -1):
                if i == m - 1 and j == n - 1:   # 终点：f = 1
                    row_upd[i](j, 1)
                    col_upd[j](i, 1)
                    continue
                g = grid[i][j]
                best = min(row_qry[i](j + 1, min(j + g, n - 1)),  # 向右
                           col_qry[j](i + 1, min(i + g, m - 1)))  # 向下
                if best == INF:             # 不可达：不入树
                    continue
                v = best + 1
                row_upd[i](j, v)
                col_upd[j](i, v)
                if i == 0 and j == 0:       # 最后处理的格子
                    return v
        return -1
```

## 8. 边界情况与易错点

1. $m = n = 1$：起点即终点，返回 $1$。
2. **答案口径**：$f$ 含起点自身（终点 $=1$），最后不要再 $+1$；若把 $f$ 定义成「移动步数」（终点 $=0$）则答案要 $+1$，两套口径勿混用。
3. **区间右端截断**：$j + g$、$i + g$ 可远超 $n - 1$、$m - 1$，必须 $\min$ 截断，否则查询下标越界（$j + g \le 2 \times 10^5$ 本身不溢出 int，越界的是数组下标）。
4. **不可达格不入树**：若把 $\infty$ 插进树，后续所有涉及它的查询都要额外解释 $\infty$ 的语义，极易出错；不入树则「查不到 = 不可达」。
5. **空区间**：$g = 0$ 时区间 $[j+1,\ j]$ 为空，查询应返回 $\infty$（迭代线段树 $l \ge r$ 时自然返回初始值；Python 版显式判 $l > r$ 更稳）。
6. **行树/列树插漏**：只插行树时，后续格子的「向下查询」永远取不到该值，$f$ 系统性偏大，示例演算可以立刻暴露。
7. **返回 $-1$ 的时机**：$(0,0)$ 不可达时不能提前返回 $-1$，要等扫描结束（$(0,0)$ 是最后一格，处理完循环自然退出）。
8. **别用正向 DP 硬套线段树**：正向前驱是 $k + \text{grid}[\cdot] \ge$ 目标的条件集合、不是下标区间，直接对它做「区间查询」是错的；应反向定义状态（见 3.2）。
9. **C++ 求值顺序陷阱**：`t[i += n] = min(t[i], v)` 在 C++17 里右操作数先求值，`min(t[i], v)` 读到的是加 $n$ **之前**的旧下标——写法必须拆成 `i += n; t[i] = min(t[i], v);`（本篇参考代码实测踩过这个坑）。

**延伸思考**：

- **更优复杂度**：利用「最少格子数 = 单源 BFS 层序距离 $+1$」的性质可做到 $O(mn \cdot \alpha)$——每行/每列维护一个并查集「下一未访问」跳表，BFS 出队时批量取出区间内的**未访问**格并入队，详见[站内每日题解](../../solution/2601-2700/2617_网格图中最少访问的格子数.md)。DP 版的优势在于不依赖最短路性质、便于记录前驱还原路径。
- **正向版本**：正向 DP 也可行——把 $(i,k)$ 的贡献按「可达上界 $\min(k + \text{grid}[i][k],\ n-1)$」为下标插入线段树，转移时查**后缀最小**；官方标签中的 Heap / Monotonic Stack 即这一族按「可达上界」组织转移的写法变体。
- **还原路径**：在 DP 插入时顺带记录最优后继（方向 + 位置），最后从 $(0,0)$ 回溯即可输出具体路径；BFS 版同理记录父指针。
- **变体**：若每步代价不同（如格子带权），问题退化为一般最短路，需 Dijkstra；若允许向左/向上移动，DAG 性质消失，$O(mn\log)$ 的 DP 序也不再成立。
