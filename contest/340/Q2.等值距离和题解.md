# LeetCode 等值距离和 题解

## 1. 题目概述

- **标题 / 题号**：等值距离和（#2615，medium）
- **链接**：https://leetcode.cn/problems/sum-of-distances/
- **来源**：LeetCode 第 340 场周赛 Q2
- **难度**：中等
- **标签**：数组、哈希表、前缀和

**题意**：给定下标从 $0$ 开始、长度为 $n$ 的整数数组 `nums`，返回等长数组 `arr`，其中 $arr[i]$ 等于**所有满足 $\text{nums}[j] = \text{nums}[i]$ 且 $j \ne i$ 的下标 $j$** 的 $|i - j|$ 之和；不存在这样的 $j$ 时 $arr[i] = 0$。换言之：对每个位置，求它到**所有同值元素下标**的距离之和（到自身的距离为 $0$，可并入求和不影响结果）。

**约束**：

- $1 \le n \le 10^5$
- $0 \le \text{nums}[i] \le 10^9$

> 💡 本题与 [2121. 相同元素的间隔之和](https://leetcode.cn/problems/intervals-between-identical-elements/) **完全同题**。$n$ 达 $10^5$ 意味着 $O(n^2)$ 的两两枚举必然超时；值域达 $10^9$ 意味着**必须哈希表按值分组**而非开值域数组。突破口是：同值下标按下标顺序收集后**天然升序**，绝对值可以按「当前点左侧 / 右侧」安全脱去，用**前缀和**把每个位置的距离和降到 $O(1)$。

## 2. 示例

**示例 1**

```text
输入：nums = [1,3,1,1,2]
输出：[5,0,3,4,0]
解释：
i = 0：另两个 1 在下标 2、3，|0−2| + |0−3| = 2 + 3 = 5
i = 1：值 3 只出现一次，没有同值伙伴，arr[1] = 0
i = 2：另两个 1 在下标 0、3，|2−0| + |2−3| = 2 + 1 = 3
i = 3：另两个 1 在下标 0、2，|3−0| + |3−2| = 3 + 1 = 4
i = 4：值 2 只出现一次，arr[4] = 0
```

**示例 2**

```text
输入：nums = [0,5,3]
输出：[0,0,0]
解释：所有元素互不相同，每个位置都没有同值伙伴，结果全为 0。
```

**示例 3（边界补充）**

```text
输入：nums = [2,2,2]
输出：[3,2,3]
解释：全部同值成一组 [0,1,2]。
i = 0：|0−1| + |0−2| = 3；i = 1：1 + 1 = 2；i = 2：2 + 1 = 3。
```

## 3. 解题思路

### 3.1 暴力思路：按值分组 + 组内两两枚举

先用哈希表把每个值的下标收集成组，再对组内每个下标 $p_i$ 遍历组内所有 $p_j$ 累加 $|p_i - p_j|$。设某组大小为 $m$，该组开销 $O(m^2)$；最坏所有元素同值，退化为 $O(n^2) \approx 10^{10}$，**必然超时**。

> ⚠️ 暴力浪费在：对每个 $p_i$ 都重扫整组，**完全没有复用「组内下标有序」这一结构**。绝对值符号是唯一的拦路虎——一旦按当前点把组切成左右两半，绝对值就能去掉，整组信息被前缀和压缩成 $O(1)$ 可查。

### 3.2 核心观察：组内天然升序，去绝对值拆左右

![按值分组：同值下标天然升序，跨组互不贡献](images/wc340_q2_group_by_value.svg)

第一个观察是**只需在组内计算**：$|i-j|$ 只对同值下标对累加，不同值的下标之间没有任何贡献。按值分组后，组内下标按遍历顺序 `push_back` 收集，**天然严格升序**（无需排序）。

第二个观察是**去绝对值**：设某组为 $g = [p_0 < p_1 < \dots < p_{m-1}]$，对当前元素 $p_i$：

- 左侧 $j < i$：$p_j < p_i$，故 $|p_i - p_j| = p_i - p_j$；
- 右侧 $j > i$：$p_j > p_i$，故 $|p_i - p_j| = p_j - p_i$。

于是距离和按左右两半分别变成了「**个数 × 当前值 − 下标和**」的代数式，而「下标和」正是**前缀和**能 $O(1)$ 回答的东西：

![数轴上以 p₁ 为界拆左右：left = i·p − prefix，right = (total−prefix−p) − (m−1−i)·p](images/wc340_q2_split_left_right.svg)

记 $\text{prefix}[i] = p_0 + p_1 + \dots + p_{i-1}$（前 $i$ 项之和，$\text{prefix}[0] = 0$），$\text{total} = \sum_{j=0}^{m-1} p_j$，则

$$\text{left} = \sum_{j<i}(p_i - p_j) = i \cdot p_i - \text{prefix}[i]$$

$$\text{right} = \sum_{j>i}(p_j - p_i) = \underbrace{(\text{total} - \text{prefix}[i] - p_i)}_{\text{右侧下标和}} - (m-1-i) \cdot p_i$$

两式相加即得单点距离和。注意 $j = i$ 项 $|p_i - p_i| = 0$，因此**无需刻意排除自身**，把整组一并求和即可。

### 3.3 算法流程

![算法流程：哈希分组一趟，每组先求 total 再单趟滚动 prefix 套公式](images/wc340_q2_algorithm_flow.svg)

```text
1. pos ← 空哈希表
2. for i = 0 .. n-1:                     # 一趟分组，O(n)
3.     pos[nums[i]].push_back(i)         # 组内天然升序
4. for 每个 (值 v, 组 g) ∈ pos:
5.     total ← Σ g；prefix ← 0；m ← |g|
6.     for i = 0 .. m-1:                 # 一趟出答案，O(m)
7.         p ← g[i]
8.         left  ← i·p − prefix
9.         right ← (total − prefix − p) − (m−1−i)·p
10.        ans[p] ← left + right         # 写回原数组下标 p
11.        prefix += p                   # 滚动前缀和，免建数组
12. 返回 ans
```

> 💡 **两个实现细节**：① `prefix` 用单变量滚动累加，不必显式建前缀和数组；② `ans[p]` 的下标是**原数组下标** $p$，不是组内序号 $i$。所有组的主循环元素总数为 $\sum m = n$，整体严格线性。

### 3.4 示例演算

![示例演算：组 [0,2,3] 逐行套公式，prefix 滚动累加](images/wc340_q2_example_walkthrough.svg)

以示例 1 `nums = [1,3,1,1,2]` 中值 $1$ 的组 $g = [0, 2, 3]$ 为例，$m = 3$，$\text{total} = 0 + 2 + 3 = 5$：

| $i$ | $p = g[i]$ | prefix（进入时） | left $= i \cdot p - \text{prefix}$ | right $= (\text{total}-\text{prefix}-p) - (m-1-i) \cdot p$ | $arr[p]$ |
|:---:|:---:|:---:|:---|:---|:---:|
| 0 | 0 | 0 | $0 \cdot 0 - 0 = 0$ | $(5-0-0) - 2 \cdot 0 = 5$ | **5** |
| 1 | 2 | 0 | $1 \cdot 2 - 0 = 2$ | $(5-0-2) - 1 \cdot 2 = 1$ | **3** |
| 2 | 3 | $0+2 = 2$ | $2 \cdot 3 - 2 = 4$ | $(5-2-3) - 0 \cdot 3 = 0$ | **4** |

值 $3$ 的组 $[1]$ 与值 $2$ 的组 $[4]$ 均为 $m = 1$：代入公式得 $\text{left} = 0$、$\text{right} = (p - 0 - p) - 0 = 0$，天然输出 $0$，无需特判。最终 $arr = [5, 0, 3, 4, 0]$ ⭐。

## 4. 算法细节

1. **哈希分组**：值域 $0 \le \text{nums}[i] \le 10^9$ 开不了数组，用 `unordered_map<int, vector<int>>`（Python 用 `defaultdict(list)`）。C++ 若卡常可换 `map` 换成对 `(值, 下标)` 排序后分段，但本题 $n \le 10^5$ 哈希完全够。
2. **升序免费获得**：外层按下标 $i$ 从小到大遍历并 `push_back`，组内即严格升序（下标互异），**不要**再对组排序——多付 $O(m \log m)$ 纯属浪费。
3. **`total` 先求后用**：进组先花 $O(m)$ 求下标总和，主循环里才能 $O(1)$ 拿到「右侧下标和」$= \text{total} - \text{prefix} - p$。
4. **滚动前缀和**：`prefix` 在处理完 $p_i$ 之后才 `+= p`，保证第 $i$ 行用的是 $\text{prefix}[i]$（前 $i$ 项之和），与公式严格对应。
5. **公式合并形式**（可选）：$\text{left} + \text{right}$ 可合并为 $f(i) = p_i \cdot (2i - m) + \text{total} - 2\,\text{prefix}[i]$，按 §3.4 的组 $[0,2,3]$ 代入 $i=1$：$2 \cdot (2-3) + 5 - 0 = 3$ ✓。不过拆开写 `left`、`right` 两行语义更清楚、不易错，推荐保留拆分写法。
6. **溢出（C++）**：最坏 $n = 10^5$ 全同值，$f$ 最大约 $n^2/4 = 2.5 \times 10^9$、$\text{total}$ 最大约 $n^2/2 = 5 \times 10^9$，均超 32 位 `int`。本题接口返回 `vector<long long>`，中间变量 `total` / `prefix` / 乘法结果也必须 `long long`（让 $p$ 先落到 `long long` 变量再参与乘法，避免 `int * int` 先溢出）。

## 5. 正确性证明

**引理 1（升序脱绝对值）**：设 $g = [p_0 < p_1 < \dots < p_{m-1}]$ 严格升序。对任意组内 $i \ne j$：$j < i \Rightarrow |p_i - p_j| = p_i - p_j$；$j > i \Rightarrow |p_i - p_j| = p_j - p_i$。

**证明**：$j < i$ 时由严格升序的传递性 $p_j < p_i$，差 $p_i - p_j > 0$，绝对值即自身；$j > i$ 时 $p_j > p_i$ 同理。∎

**引理 2（左右和的前缀表示）**：记 $\text{prefix}[i] = \sum_{j=0}^{i-1} p_j$、$\text{total} = \sum_{j=0}^{m-1} p_j$，则

$$\sum_{j<i} |p_i - p_j| = i \cdot p_i - \text{prefix}[i], \qquad \sum_{j>i} |p_i - p_j| = (\text{total} - \text{prefix}[i] - p_i) - (m-1-i)\cdot p_i.$$

**证明**：由引理 1，$\sum_{j<i}|p_i - p_j| = \sum_{j<i}(p_i - p_j) = i \cdot p_i - \text{prefix}[i]$；$\sum_{j>i}|p_i - p_j| = \sum_{j>i}(p_j - p_i) = \big(\sum_{j>i} p_j\big) - (m-1-i) \cdot p_i$，而 $\sum_{j>i} p_j = \text{total} - \text{prefix}[i] - p_i$（全组和减左侧和减自身）。∎

**定理（算法正确性）**：算法对每个下标 $t$ 输出 $f(t) = \sum_{\text{nums}[s] = \text{nums}[t],\, s \ne t} |t - s|$。

**证明**：分组阶段把每个下标 $t$ 恰好放入组 $g = \text{pos}[\text{nums}[t]]$ 一次，且组内按下标升序。由题意，$arr[t]$ 只累加同组下标的距离，跨组下标不满足 $\text{nums}[s] = \text{nums}[t]$、贡献为零，因此各组独立计算后写回 `ans[p]` 覆盖互不冲突。设 $t = p_i$ 为 $g$ 中第 $i$ 个元素。因 $j = i$ 项 $|p_i - p_i| = 0$，目标值 $f(p_i) = \sum_{j \ne i} |p_i - p_j| = \sum_{j=0}^{m-1} |p_i - p_j|$；再按 $j < i$、$j > i$ 拆开，由引理 2 恰等于算法所算的 $\text{left} + \text{right}$。$m = 1$ 时组内无其他下标，代入得 $\text{left} = 0$、$\text{right} = (p_0 - 0 - p_0) - 0 = 0$，输出 $0$，与「无同值伙伴则为 $0$」一致。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。分组一趟 $O(n)$（哈希均摊）；每组先求 `total` 再跑主循环，两趟合计 $O(m)$，所有组元素总数 $\sum m = n$；无排序、无二分。
- **空间复杂度**：$O(n)$。哈希表存储全部下标共 $n$ 个，输出数组 $O(n)$；每组只用 `total` / `prefix` / 下标变量等 $O(1)$ 辅助空间。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    vector<long long> distanceSum(vector<int>& nums) {
        int n = nums.size();
        unordered_map<int, vector<int>> pos;
        for (int i = 0; i < n; ++i) {
            pos[nums[i]].push_back(i);        // 下标按遍历顺序加入，天然升序
        }
        vector<long long> ans(n);
        for (auto& [v, g] : pos) {
            long long total = 0;
            for (int p : g) total += p;        // 组内下标总和
            long long prefix = 0;              // 滚动前缀和：p_0 + ... + p_{i-1}
            int m = g.size();
            for (int i = 0; i < m; ++i) {
                long long p = g[i];            // 先落 long long，防 int*int 溢出
                long long left  = i * p - prefix;                            // 左侧 i 项
                long long right = (total - prefix - p)
                                - (long long)(m - 1 - i) * p;               // 右侧 m-1-i 项
                ans[p] = left + right;         // 写回原数组下标 p（不是 i！）
                prefix += p;
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def distanceSum(self, nums: List[int]) -> List[int]:
        pos = defaultdict(list)
        for i, v in enumerate(nums):
            pos[v].append(i)                   # 下标天然升序

        ans = [0] * len(nums)
        for g in pos.values():
            total = sum(g)                     # 组内下标总和
            prefix = 0                         # 滚动前缀和
            m = len(g)
            for i, p in enumerate(g):
                left = i * p - prefix                          # 左侧 i 项
                right = (total - prefix - p) - (m - 1 - i) * p  # 右侧 m-1-i 项
                ans[p] = left + right         # 写回原数组下标 p
                prefix += p
        return ans
```

## 8. 边界情况与易错点

1. **32 位溢出（最高频 WA）**：$n = 10^5$ 全同值时答案最大约 $2.5 \times 10^9$、`total` 约 $5 \times 10^9$，C++ 必须 `long long`；且 `i * p`、`(m-1-i) * p` 要保证至少一侧是 `long long`（先把 `p` 存进 `long long` 变量），否则 `int × int` 在赋值前就已溢出。Python 无此问题。
2. **答案写回下标写反**：`ans[p]` 用的是**原数组下标** `p = g[i]`，不是组内序号 `i`。写成 `ans[i]` 在样例上恰好"看起来对"（组 [0,2,3] 的 i 与 p 错位不明显），大样本必然 WA。
3. **`m = 1` 的单元素组**：公式天然给 $0$，无需特判；追求常数可加 `if (m == 1) continue;` 跳过整组。
4. **不要对组排序**：`push_back` 顺序即升序，排序多付 $O(m \log m)$；更不要对「值」排序——各组之间处理顺序无关。
5. **值域陷阱**：$0 \le \text{nums}[i] \le 10^9$，不能用值域数组（哪怕 `unordered_set` 判存在也不行，要的是按下标分组）；`nums[i] = 0` 作为哈希 key 完全正常。
6. **prefix 的更新时机**：必须**算完当前行再** `prefix += p`，保证行内用到的是前 $i$ 项之和；先加后用会把自身混进左侧（数值上表现为左侧多算一个 $0$ 项、恰好不错——但 `total - prefix - p` 的对应关系会被破坏，右侧随之算错）。
7. **`j = i` 无需排除**：$|p_i - p_i| = 0$ 对和无影响，把「$j \ne i$」当「整组求和」处理可简化代码；同理单元素组也自动归零。
