# LeetCode 最小化数对的最大差值 题解

## 1. 题目概述

- **标题 / 题号**：最小化数对的最大差值（#2616，medium）
- **链接**：https://leetcode.cn/problems/minimize-the-maximum-difference-of-pairs/
- **来源**：LeetCode 第 340 场周赛 Q3
- **难度**：中等
- **标签**：贪心、数组、排序、二分查找、动态规划

**题意**：给定下标从 $0$ 开始的整数数组 `nums` 和整数 $p$，需要选出 $p$ 个**下标对**（每个下标在所有对中**最多出现一次**），最小化这 $p$ 对差值 $|\text{nums}[i] - \text{nums}[j]|$ 的**最大值**，返回这个最小化的最大差值。空集（$p = 0$）的最大值定义为 $0$。

**约束**：

- $1 \le n \le 10^5$
- $0 \le \text{nums}[i] \le 10^9$
- $0 \le p \le \lfloor n / 2 \rfloor$

> 💡 题面写的是「下标对」，但**下标本身没有语义**：约束「每个下标最多用一次」翻译到数值层面就是「每个元素最多属于一个对」，目标又只依赖数值差——这暗示了第一个动作：**排序不失一般性**。而「最小化最大值」是**二分答案**的招牌句式：把求最优值翻转成判定「阈值 $t$ 下能否做到」，判定函数关于 $t$ 单调，正落在二分射程内。本题的另一半功夫在判定函数本身：$p$ 可达 $5 \times 10^4$，$O(np)$ 的 DP 状态高达 $5 \times 10^9$，必须靠**排序 + 相邻贪心**把单次判定压到 $O(n)$。

## 2. 示例

**示例 1**

```text
输入：nums = [10,1,2,7,1,3], p = 2
输出：1
解释：选下标对 (1,4)（值 1 与 1，差 0）和 (2,5)（值 2 与 3，差 1），
     最大差 = max(0, 1) = 1。
     差为 0 的对只能由两个 1 组成，只有 1 对，凑不够 2 对，
     所以答案不可能为 0；而 1 可以达到，故答案为 1。
```

**示例 2**

```text
输入：nums = [4,2,1,2], p = 1
输出：0
解释：选下标对 (1,3)（值 2 与 2），差为 0，最大差的最小值即 0。
```

**示例 3（边界补充）**

```text
输入：nums = [5], p = 0
输出：0
解释：p = 0 时一个下标对都不选，空集的最大值定义为 0。
```

## 3. 解题思路

### 3.1 暴力思路：枚举方案 / DP

**枚举方案**：从 $n$ 个下标中选 $2p$ 个再做任意完美匹配，方案数是组合天文数字，显然不可行。

**DP**：配对代价只依赖数值，先排序，再设 $dp[i][j]$ = 前 $i$ 个元素中配出 $j$ 对的最小化最大差。转移要么不配第 $i$ 个元素，要么与**相邻**的 $i-1$ 配对——但「只配相邻就够」本身就是需要证明的非平凡结论（见 §5）；退一步即使接受它，状态数也有 $O(np) \approx 10^5 \times 5 \times 10^4 = 5 \times 10^9$，**时间与空间双双爆炸**。

> ⚠️ DP 卡在「配几对」这个维度上。而「最小化最大值」类问题有一个普适的降维手段——**二分答案**：把「配恰好 $p$ 对且最小化最大差」翻转成「给定最大差阈值 $t$，判定能否配出至少 $p$ 对」。判定问题里 $p$ 只剩一次 $\ge$ 比较，状态维度瞬间消失。

### 3.2 核心观察：排序 + 二分答案 + 贪心判定

**观察 1（排序不失一般性）**：目标与约束都只关心数值多重集、与下标位置无关（§1 💡），先**升序排序**。

**观察 2（二分答案）**：定义判定函数

$$\text{check}(t) = \text{true} \iff \text{能选出} \ge p \text{ 个两两不相交的对，每对差} \le t$$

$t$ 变大只会放松约束，$\text{check}$ 关于 $t$ **单调不减**；答案就是**最小的可行 $t$**，标准闭区间二分即可。

![二分答案：check(t) 单调，最小可行 t 即答案](images/wc340_q3_binary_search_threshold.svg)

**观察 3（排序后贪心配对）**：排序后用**从左到右的贪心扫描**判定 $\text{check}(t)$：指针 $i$ 从左到右，若相邻两元素差 $a_{i+1} - a_i \le t$ 就**立刻配对**（$i$ 跳 2），否则**单跳**（$i$ 跳 1，当前元素报废）。单跳的安全性一眼可见：若 $a_{i+1} - a_i > t$，则对一切 $j > i$ 有 $a_j - a_i \ge a_{i+1} - a_i > t$——$a_i$ 与**右侧任何元素**都配不上，跳过它零损失。

![贪心 check：相邻差不超过 t 即配对，否则单跳](images/wc340_q3_greedy_check.svg)

> 💡 剩下的疑虑是「能配就配」会不会**因小失大**——比如把 $a_1$ 配给 $a_0$，挤掉了后面本可配出更多对的机会？答案是不会：交换论证可以证明这个贪心配出的对数**就是最大值**（§5 引理 2），直觉是「相邻配对最省元素，早配不亏」。

### 3.3 算法流程

```text
1. 将 nums 升序排序                                   # O(n log n)
2. 定义 check(t) → 能否配出 ≥ p 对：
3.     cnt ← 0, i ← 0
4.     while i + 1 < n:
5.         a[i+1] − a[i] ≤ t ?  cnt+1, i += 2        # 相邻配对
6.                                :  i += 1          # 单跳报废
7.     return cnt ≥ p
8. 在 [lo, hi] = [0, a[n−1] − a[0]] 上闭区间二分：     # O(n log V)
9.     mid ← ⌊(lo + hi) / 2⌋
10.    check(mid) 为真 → hi ← mid；否则 → lo ← mid + 1
11. 返回 lo
```

### 3.4 示例演算

![示例演算：check(0) 失败、check(1) 成功，答案为 1](images/wc340_q3_example_walkthrough.svg)

以示例 1 `nums = [10,1,2,7,1,3], p = 2` 为例。排序后 $a = [1,1,2,3,7,10]$，相邻差为 $0, 1, 1, 4, 3$，二分区间 $[0, 10]$，两次关键判定：

| $t$ | 扫描过程 | 配出对数 | $\text{check}(t)$ |
|:---:|:---|:---:|:---:|
| $0$ | $(1,1)$ 差 $0$ 配对；$2,3$ 差 $1 > 0$ 报废；$3,7$、$7,10$ 差更大全报废 | $1$ | ✗（$1 < 2$） |
| $1$ | $(1,1)$ 差 $0$ 配对；$(2,3)$ 差 $1$ 配对；$7,10$ 差 $3 > 1$ 报废 | $2$ | ✓（$2 \ge 2$） |

（完整二分轨迹：$mid{=}5$ ✓ → $hi{=}5$；$mid{=}2$ ✓ → $hi{=}2$；$mid{=}1$ ✓ → $hi{=}1$；$mid{=}0$ ✗ → $lo{=}1$，收敛。）故答案为 $1$ ⭐，对应原数组的下标对 $(1,4)$ 与 $(2,5)$。

## 4. 算法细节

1. **排序是贪心的前提**：「相邻差 $\le t$ 即配对」依赖「相邻即最近」的有序性，不排序全错；排序在二分**外部**只做一次，不要放进 check 里每轮重排。
2. **二分上下界**：$lo = 0$（$p = 0$ 或存在等值对时可能达到）；$hi = a_{n-1} - a_0$ 必可行——任取 $p$ 个对，每对差都不超过全局极差。
3. **跳格语义**：配对成功 $i \mathrel{+}= 2$（两个元素一起消费）；配不上**只跳 1**——当前元素报废，但下一个元素仍有权利与它的后继配对。
4. **判 $\ge$ 而非 $=$**：题目只要求「选出 $p$ 对」，多配不亏；贪心给出的最大对数 $\ge p$ 即可行。
5. **答案的取值域**：答案要么是 $0$，要么恰为某个**相邻差** $a_{i+1} - a_i$（二分收敛到的最小可行 $t$ 必被某个相邻差「卡住」）。因此也可以先对相邻差去重排序后在其上二分，把轮数降到 $O(\log n)$；但直接在 $[0, 10^9]$ 上二分只需约 30 轮，代码更省事。
6. **DP 替代贪心（保险写法）**：若赛时不放心贪心正确性，check 可用等价的 $O(n)$ DP：$f[i]$ = 前 $i$ 个元素最多配对数，$f[i] = \max(f[i-1],\ f[i-2] + [\,a_{i-1} - a_{i-2} \le t\,])$，复杂度与贪心同阶。

## 5. 正确性证明

**引理 1（单跳安全性）**：设 $a_0 \le a_1 \le \dots \le a_{n-1}$ 为排序后的数组。若 $a_{i+1} - a_i > t$，则对一切 $j > i$ 有 $a_j - a_i > t$。

**证明**：$j > i \Rightarrow a_j \ge a_{i+1} \Rightarrow a_j - a_i \ge a_{i+1} - a_i > t$。∎

**引理 2（贪心配对数最大）**：对任意阈值 $t$，设贪心扫描配出的对数为 $g(t)$，则对任何每对差 $\le t$ 的合法配对方案 $M$，有 $|M| \le g(t)$。

**证明**：对元素个数 $n$ 强归纳。$n \le 1$ 时两边皆为 $0$。看 $a_1 - a_0$ 与 $t$ 的大小：

- **情形 A：$a_1 - a_0 > t$。** 由引理 1（取 $i = 0$），$a_0$ 与任何元素差 $> t$，故 $M$ 不含 $a_0$，实际是 $a_1, \dots, a_{n-1}$ 上的方案；贪心同样先跳过 $a_0$，且在剩余元素上的行为恰等于对长度 $n-1$ 的有序数组跑同一贪心。由归纳假设 $|M| \le g(t)$。

- **情形 B：$a_1 - a_0 \le t$。** 贪心配出 $(a_0, a_1)$，随后在 $a_2, \dots, a_{n-1}$ 上递归，$g(t) = 1 + g'$，其中 $g'$ 为贪心在剩余 $n - 2$ 个元素上的产出。对任意方案 $M$，逐类归约到「$M$ 含 $(a_0, a_1)$」的标准形：

  1. $(a_0, a_1) \in M$：$M \setminus \{(a_0, a_1)\}$ 是剩余元素上的合法方案，由归纳假设 $|M| - 1 \le g'$，即 $|M| \le g(t)$。
  2. $a_0, a_1$ 均未配：$M$ 整体落在剩余元素上，$|M| \le g' < g(t)$。
  3. $a_0$ 未配、$a_1$ 配了 $a_k$（$k > 1$）：换成 $(a_0, a_1)$（差 $\le t$ 成立，$a_k$ 释放），规模不减，归入 1。
  4. $a_0$ 配了 $a_j$（$j > 1$）、$a_1$ 未配：换成 $(a_0, a_1)$，规模不减，归入 1。
  5. $a_0$ 配了 $a_j$、$a_1$ 配了 $a_k$（$1 < j < k$）：因 $a_j \ge a_1$，有 $a_k - a_j \le a_k - a_1 \le t$（后者由 $(a_1, a_k)$ 是 $M$ 中的合法对），故 $\{(a_0, a_1), (a_j, a_k)\}$ 可无损替换 $\{(a_0, a_j), (a_1, a_k)\}$，规模不减，归入 1。

  综上恒有 $|M| \le 1 + g' = g(t)$。∎

**引理 3（check 单调）**：$t_1 \le t_2$ 且 $\text{check}(t_1)$ 为真，则 $\text{check}(t_2)$ 为真。

**证明**：$\text{check}(t_1)$ 为真给出的那 $\ge p$ 个对每对差 $\le t_1 \le t_2$，同一组对即见证 $\text{check}(t_2)$。∎

**定理（算法正确性）**：二分返回值等于最优答案 $v$，即「选出 $p$ 对时最大差的最小值」。

**证明**：设 $v$ 为最优值。一方面，最优方案本身给出 $p$ 个差 $\le v$ 的对，故 $\text{check}(v)$ 为真；$v \ge 1$ 时若 $\text{check}(v-1)$ 为真，则存在方案最大差 $\le v - 1 < v$，与最优性矛盾，故 $\text{check}(v-1)$ 为假。另一方面，贪心 check 与「存在性」等价：由引理 2，贪心配出的对数就是最大可配对数，故 $\text{cnt} \ge p \iff$ 存在 $\ge p$ 对的合法方案。结合引理 3 的单调性，闭区间二分模板恰好收敛到最小真值，即 $v$。$v = 0$（含 $p = 0$）时最小真值为 $0$，与「空集最大值为 $0$」的定义一致。∎

## 6. 复杂度分析

- **时间复杂度**：$O\big(n(\log n + \log V)\big)$，其中 $V = a_{n-1} - a_0 \le 10^9$。排序 $O(n \log n)$；二分 $O(\log V) \approx 30$ 轮，每轮 check 线性扫一遍 $O(n)$。
- **空间复杂度**：$O(1)$ 额外空间（原地排序，指针与计数器仅常数个；不计语言自身的排序递归栈）。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int minimizeMax(vector<int>& nums, int p) {
        sort(nums.begin(), nums.end());
        int n = nums.size();

        auto check = [&](int t) {
            int cnt = 0;
            for (int i = 0; i + 1 < n; ++i) {
                if (nums[i + 1] - nums[i] <= t) {
                    ++cnt;          // 相邻差 ≤ t：立即配对
                    ++i;            // 配上循环自增，净跳 2 格
                }                   // 否则只报废当前元素，跳 1 格
            }
            return cnt >= p;
        };

        int lo = 0, hi = nums[n - 1] - nums[0];
        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            if (check(mid)) hi = mid;
            else lo = mid + 1;
        }
        return lo;
    }
};
```

### Python

```python
class Solution:
    def minimizeMax(self, nums: List[int], p: int) -> int:
        nums.sort()
        n = len(nums)

        def check(t: int) -> bool:
            cnt = 0
            i = 0
            while i + 1 < n:
                if nums[i + 1] - nums[i] <= t:
                    cnt += 1
                    i += 2          # 配对成功：两个元素一起消费
                else:
                    i += 1          # 当前元素报废，下一个继续
            return cnt >= p

        lo, hi = 0, nums[-1] - nums[0]
        while lo < hi:
            mid = (lo + hi) // 2
            if check(mid):
                hi = mid
            else:
                lo = mid + 1
        return lo
```

## 8. 边界情况与易错点

1. **$p = 0$**：答案为 $0$。check 恒真，闭区间二分自然收敛到 $lo = 0$，无需特判；但若改用「二分相邻差数组」的实现，需小心空数组边界。
2. **$n = 1$**：此时 $p$ 只能为 0，`hi = nums[0] - nums[0] = 0`，二分循环不进入，直接返回 0。
3. **忘记排序**：check 的「相邻即最近」完全依赖有序性，不排序必错。
4. **跳格数写反**：配对成功跳 2、失败跳 1。失败时跳 2 会把还有机会的下一个元素也误杀，是最高频的 WA 点。
5. **`cnt >= p` 写成 `==`**：多配不亏，判定应允许超过 $p$；「至少 $p$ 对」与「恰好 $p$ 对」在存在性上等价——能配出更多时任取其中 $p$ 对，最大差只会更小。
6. **溢出**：值域 $[0, 10^9]$，差最大 $10^9 < 2^{31} - 1$，C++ `int` 安全；若值域放宽（如含负数或 $> 2 \times 10^9$）需换 `long long`。
7. **「下标」的心智负担**：题面反复强调「下标对」，容易误导人去保留下标或担心排序破坏下标——其实唯一约束是「每个元素最多属于一个对」，排序后照常成立。
