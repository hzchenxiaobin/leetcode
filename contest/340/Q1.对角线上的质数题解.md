# LeetCode 对角线上的质数 题解

## 1. 题目概述

- **标题 / 题号**：对角线上的质数（#2614，easy）
- **链接**：https://leetcode.cn/problems/prime-in-diagonal/
- **来源**：LeetCode 第 340 场周赛 Q1
- **难度**：简单
- **标签**：数组、数学、矩阵、数论

**题意**：给定下标从 $0$ 开始的 $n \times n$ 二维整数数组 `nums`，返回位于**至少一条对角线**上的最大**质数**；若任一对角线上均不存在质数，返回 `0`。

- **主对角线**：`nums[i][i]`，$i = 0, 1, \dots, n-1$；
- **副对角线**：`nums[i][n-1-i]`，$i = 0, 1, \dots, n-1$；
- **质数**：大于 $1$ 且除 $1$ 与自身外无其他正因子。注意 $1$ **不是**质数。

**约束**：

- $1 \le \text{nums.length} \le 300$
- $\text{nums.length} == \text{nums[i].length}$（方阵）
- $1 \le \text{nums[i][j]} \le 4 \times 10^6$

> 💡 关键信号：方阵 + 对角线 ⇒ 候选至多 $2n \le 600$ 个；值域上界 $4 \times 10^6$ ⇒ $\sqrt{v} \le 2000$，**单点试除判质数**绰绰有余，无需预筛整个值域。

## 2. 示例

**示例 1**

```text
输入：nums = [[1,2,3],[5,6,7],[9,10,11]]
输出：11
解释：位于至少一条对角线上的数字为 1、3、6、9、11（中心 6 两条对角线都经过，只计一次）。
      其中质数有 3 与 11，最大为 11。
```

**示例 2**

```text
输入：nums = [[1,2,3],[5,17,7],[9,11,10]]
输出：17
解释：位于至少一条对角线上的数字为 1、3、9、10、17，其中质数有 3 与 17，最大为 17。
```

**示例 3（边界补充）**

```text
输入：nums = [[4,6],[8,10]]
输出：0
解释：主对角线 [4, 10]、副对角线 [8, 6]，全是合数，无质数，返回 0。
```

## 3. 解题思路

### 3.1 暴力思路：扫全矩阵判质数

最直白的做法是枚举整张矩阵的 $n^2$ 个元素，逐个判质数取最大。$n \le 300$ ⇒ $n^2 \le 9 \times 10^4$，每个试除 $O(\sqrt{V}) \approx 2000$，总量约 $1.8 \times 10^8$——C++ 勉强能过，Python 大概率超时。而且这 $n^2$ 次判定里只有至多 $2n$ 个位置有意义，其余全是无用功。抓住「只需对角线」这一结构，候选规模立刻降到 $2n \le 600$，工作量压低两个量级。

### 3.2 核心观察：收集 $2n$ 个候选 + 试除判质数

![两条对角线：主对角线 nums[i][i] 与副对角线 nums[i][n-1-i]，中心点重叠](images/wc340_q1_diagonal_prime_concept.svg)

把问题拆成两步：

1. **收集候选**：遍历 $i = 0 \dots n-1$，每行取两个候选 `nums[i][i]` 与 `nums[i][n-1-i]`。$n$ 为奇数时中心点满足 $i = n-1-i$，被采集两次。
2. **判质数取最大**：对候选 $v$ 调用 `isPrime(v)`，是质数则更新 $ans \leftarrow \max(ans, v)$；`ans` 初值取 $0$，天然兜底「无质数返回 0」。

> ⚠️ **$1$ 不是质数**：示例 1 的主对角线起点就是 $1$，`isPrime` 必须在 $v \le 1$ 处直接判否，这是本题最常见的 WA 点。

**试除法**：若 $v \ge 2$ 是合数，则它必有一个不超过 $\sqrt{v}$ 的因子（证明见 §5 引理 1），故只需枚举 $d \le \sqrt{v}$。再特判 $v = 2$（唯一偶质数）并排除其余偶数，之后只试奇因子 $d = 3, 5, 7, \dots$，工作量再减半。

### 3.3 算法流程

![算法流程：短路过滤 v > ans，再试除判质数，通过则刷新答案](images/wc340_q1_trial_division_flow.svg)

```text
1. ans ← 0
2. for i = 0 .. n-1:
3.     for v ∈ {nums[i][i], nums[i][n-1-i]}:
4.         if v > ans and isPrime(v):   # v > ans 先短路，省掉小候选的判定
5.             ans ← v
6. 返回 ans
```

> 💡 **短路的双重收益**：`v > ans` 放在 `isPrime(v)` 之前——只有比当前答案更大的候选才可能刷新答案，小候选直接跳过判定；同时第二次遇到中心点时 $v \le ans$ 被短路吞掉，**无需显式去重**。

### 3.4 示例演算

![示例 1 演算：候选依次为 1, 3, 6, 6, 11, 9，逐个判定并短路](images/wc340_q1_example_walkthrough.svg)

以示例 1 `nums = [[1,2,3],[5,6,7],[9,10,11]]` 为例，$n = 3$。候选按采集顺序为：

- $i=0$：主 `nums[0][0]=1`，副 `nums[0][2]=3`
- $i=1$：主 `nums[1][1]=6`，副 `nums[1][1]=6`（中心，重复）
- $i=2$：主 `nums[2][2]=11`，副 `nums[2][0]=9`

| 候选 $v$ | 来源 | $v > ans$? | 判定过程 | 质数? | $ans$ |
|----------|------|-----------|----------|:-----:|:-----:|
| 1 | $i=0$ 主 | ✓ | $v \le 1$ → 直接否 | 否 | 0 |
| 3 | $i=0$ 副 | ✓ | $d=3$：$3^2 = 9 > 3$ 停，无因子 | 是 | 3 |
| 6 | $i=1$ 主 | ✓ | $6 \bmod 2 = 0$ → 有因子 | 否 | 3 |
| 6 | $i=1$ 副（中心） | ✗ 短路 | 跳过，不判质数 | — | 3 |
| 11 | $i=2$ 主 | ✓ | $d=3$ 不整除；$d=5$：$25 > 11$ 停 | 是 | 11 |
| 9 | $i=2$ 副 | ✗ 短路 | 跳过，不判质数 | — | 11 |

最大质数为 $11$，返回 `11` ⭐。

## 4. 算法细节

1. **候选采集**：单层循环 $i = 0 \dots n-1$，每轮取 `nums[i][i]` 与 `nums[i][n-1-i]` 两个值，共至多 $2n$ 个候选，不需要显式集合存储。
2. **中心点重复**：$n$ 为奇数时 $i = n/2$ 处 $i = n-1-i$，同一格被采集两次。处理方式有两种：① 显式 `set` 去重；② 依靠 `v > ans` 短路——第二次遇到同一值时 $v \le ans$ 直接跳过。本文采用②，省去哈希开销。
3. **试除判定 `isPrime(v)`**：
   - $v \le 1$ → 否（$1$ 既非质数也非合数）；
   - $v = 2$ → 是（最小且唯一的偶质数）；
   - $v$ 为偶数 → 否；
   - 否则枚举奇因子 $d = 3, 5, \dots$，条件 $d \cdot d \le v$，遇到 $v \bmod d = 0$ 即否；跑完无因子则是。
4. **`d * d` 的写法**：$v \le 4 \times 10^6$ 时 $d \le 2001$，$d^2 \le 4.1 \times 10^6$，C++ `int`（上限约 $2.1 \times 10^9$）不溢出；但若值域放大到 $10^9$ 级别，须写 `1LL * d * d <= v` 或改判 `d <= v / d` 防溢出。

## 5. 正确性证明

**引理 1（试除上界）**：正整数 $v \ge 2$ 是合数，当且仅当存在 $d$ 满足 $2 \le d \le \lfloor\sqrt{v}\rfloor$ 且 $d \mid v$。

**证明**：(⇐) 若存在这样的 $d$，则 $v = d \cdot (v/d)$ 且两因子都大于 $1$，故 $v$ 是合数。(⇒) 设 $v = ab$，$2 \le a \le b < v$。若 $a > \sqrt{v}$，则 $b \ge a > \sqrt{v}$，得 $ab > v$，矛盾；故 $a \le \sqrt{v}$，取 $d = a$ 即可。∎

**推论**：$v \ge 2$ 是质数，当且仅当 $[2, \lfloor\sqrt{v}\rfloor]$ 内无 $v$ 的因子；$v \le 1$ 均非质数。这就是 `isPrime` 的判定规则，且排除偶数（$v=2$ 除外）后只需试奇因子——$2$ 的倍数因子必然以 $d=2$ 被先行排除。

**引理 2（候选集完备性）**：元素 `nums[r][c]` 位于至少一条对角线上，当且仅当 $r = c$ 或 $r + c = n - 1$。

**证明**：由题意定义，`val` 位于主对角线 ⟺ 存在 $i$ 使 `nums[i][i] = val`，即 $r = c$；位于副对角线 ⟺ 存在 $i$ 使 `nums[i][n-1-i] = val`，即 $c = n-1-r$，等价于 $r + c = n-1$。二者取或即得。∎

**定理**：算法返回的 `ans` 等于位于至少一条对角线上的元素中的最大质数；若不存在质数则返回 $0$。

**证明**：算法遍历的多重集 $C = \{\text{nums[i][i]}\} \cup \{\text{nums[i][n-1-i]}\}$（$0 \le i < n$）。由引理 2，$C$ 恰好覆盖所有位于至少一条对角线上的元素；中心点最多重复出现一次，不影响取最大值。对候选 $v$，`isPrime` 由引理 1 及其推论给出准确判定。对「任一时刻 `ans` 等于已处理候选中质数的最大值（若无为 $0$）」归纳：初始 `ans = 0` 成立；处理候选 $v$ 时——若 $v \le ans$，则 $v$ 是质数也不超过已见质数之最大值，不变式保持；若 $v > ans$ 且判定为质数，更新后 `ans = v` 仍为已处理质数之最大值；若判定非质数，不变式不变。遍历结束时 `ans` 即 $C$ 中最大质数，且初值 $0$ 兜底了全非质数的情形。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \sqrt{V})$。候选至多 $2n \le 600$ 个，每个试除至多 $O(\sqrt{V}) \le 2000$ 次（只试奇数再减半）；$n \le 300$、$V = 4 \times 10^6$，总量约 $10^6$ 量级，`v > ans` 短路后实际更少。对比扫全矩阵的 $O(n^2 \sqrt{V}) \approx 1.8 \times 10^8$，低两个量级。
- **空间复杂度**：$O(1)$。只用常数个变量，不建候选集合（短路替代去重）。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    bool isPrime(int v) {
        if (v <= 1) return false;          // 1 既非质数也非合数
        if (v == 2) return true;           // 最小质数，唯一偶质数
        if (v % 2 == 0) return false;      // 其余偶数都是合数
        for (int d = 3; 1LL * d * d <= v; d += 2) {  // 只试除奇因子
            if (v % d == 0) return false;
        }
        return true;
    }

    int diagonalPrime(vector<vector<int>>& nums) {
        int n = nums.size();
        int ans = 0;
        for (int i = 0; i < n; ++i) {
            for (int v : {nums[i][i], nums[i][n - 1 - i]}) {
                if (v > ans && isPrime(v)) {  // v > ans 短路：只判可能刷新答案的候选
                    ans = v;
                }
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def is_prime(self, v: int) -> bool:
        if v <= 1:
            return False
        if v == 2:
            return True
        if v % 2 == 0:
            return False
        d = 3
        while d * d <= v:        # 只试除奇因子到 √v
            if v % d == 0:
                return False
            d += 2
        return True

    def diagonalPrime(self, nums: List[List[int]]) -> int:
        n = len(nums)
        ans = 0
        for i in range(n):
            for v in (nums[i][i], nums[i][n - 1 - i]):
                if v > ans and self.is_prime(v):  # 短路避免无谓判质数
                    ans = v
        return ans
```

## 8. 边界情况与易错点

1. **$1$ 不是质数**：`isPrime` 必须先判 $v \le 1$ 返回否。示例 1 主对角线起点就是 $1$，漏判直接 WA。
2. **$2$ 是唯一偶质数**：特判顺序不能反——必须先判 $v = 2$ 再排除偶数，否则 $2$ 会被「偶数一律判否」误杀。
3. **奇数阶中心点重复采集**：$n$ 奇数时中心被采两次。用 `set` 去重可行，但 `v > ans` 短路即可天然吞掉重复，无需额外结构。
4. **`ans` 初值取 `0` 而非 `-1`**：全非质数时题目要求返回 `0`，初值 `0` 直接兜底；若用 `-1` 还需最后特判。
5. **`d * d` 溢出**：本题 $v \le 4 \times 10^6$，$d^2 \le 4.1 \times 10^6$ 不溢出；但值域放大到 $10^9$ 时 `int` 平方可溢出，稳妥写法 `1LL * d * d <= v` 或 `d <= v / d`。
6. **$n = 1$**：唯一元素同时在主、副对角线上，被采集两次，算法无需特判自然正确。
7. **不要扫全矩阵**：$n^2 \sqrt{V} \approx 1.8 \times 10^8$ 在 C++ 里紧张、Python 里几乎必 TLE；只扫两条对角线是本题结构性的优化点。
