# LeetCode 左叶子之和 题解

## 1. 题目概述

- **标题 / 题号**：左叶子之和（#404，easy）
- **链接**：https://leetcode.cn/problems/sum-of-left-leaves/
- **来源**：LeetCode 第 6 场周赛 Q1
- **难度**：简单
- **标签**：树、深度优先搜索、广度优先搜索、二叉树

**题意**：给定二叉树的根节点 `root`，求所有**左叶子**节点值之和。**叶子**是左右孩子都为空的节点；**左叶子**是「本身是叶子」且「是父节点的左孩子」的节点。注意只看叶子：左侧的内部节点、以及右侧的叶子都不贡献任何值，根节点也没有父节点，谈不上左右。

**约束**：

- 节点数 $1 \le n \le 1000$
- $-1000 \le \text{Node.val} \le 1000$
- 答案落在 $[-10^6,\,10^6]$ 内，32 位有符号整数足够

## 2. 示例

**示例 1**

```text
输入：root = [3,9,20,null,null,15,7]
输出：24
解释：左叶子是 9（3 的左孩子）与 15（20 的左孩子），9 + 15 = 24；
      7 虽然是叶子，但它是 20 的右孩子，不计入。
```

**示例 2**

```text
输入：root = [1]
输出：0
解释：根节点没有左孩子，也没有父节点，和为 0。
```

**补充自测（非官方）**

```text
输入：root = [1,2,3]
输出：2
解释：2 与 3 都是叶子，只有左孩子 2 计入。
```

## 3. 解题思路

### 3.1 暴力思路

最直白的三条路：

1. **叶子向上找父亲**：每遇到一个叶子，就向上找它的父节点，看自己挂在左边还是右边。没有 parent 指针时只能从根重新搜，单次 $O(n)$、总共 $O(n^2)$；$n=1000$ 时约 $10^6$ 步，能过但纯属浪费。
2. **先建 parent 表**：一次遍历记下「子节点 → 父节点 + 左右方向」，第二次遍历枚举叶子查表累加。时间 $O(n)$，但要额外 $O(n)$ 空间和一遍建表逻辑。
3. **dfs 传方向参数**：`dfs(node, isLeft)`，遇到叶子且 `isLeft` 为真就累加。时间 $O(n)$、空间 $O(h)$，已经是正解量级，但「方向」要靠参数一路传递：根节点得手动传 `false`，迭代写法的栈元素也要多存一位，容易漏。

三者的共同点：都在**子节点一侧**回答「我是不是左孩子」。能不能让父节点替孩子回答？

### 3.2 核心观察：把「叶子判定」搬到父节点

![在父节点处判定左叶子](images/wc6_q1_left_leaf_criterion.svg)

关键等价改写——站在节点 $x$ 上看它的左孩子：

$$y \text{ 是左叶子} \iff \exists\,x:\; y = x.\text{left} \;\wedge\; x.\text{left}.\text{left}=\text{null} \;\wedge\; x.\text{left}.\text{right}=\text{null}$$

于是每到一个节点 $x$，只要 `x.left` 非空、且 `x.left` 的左右孩子都为空，就把 `x.left.val` 计入答案。这个改写带来三个好处：

- **「左」的信息免费**：`x.left` 本身就表明方向，不需要 `isLeft` 参数，也不需要 `parent` 指针。
- **只数一次**：每个左叶子的父节点唯一，只会被它的父节点认领一次。
- **不用特判叶子**：递归照常进入两个孩子；左叶子没有孩子，进去后只会返回 0。

### 3.3 算法流程 / 状态转移

![dfs 递归流程图](images/wc6_q1_dfs_flow.svg)

记 $f(x)$ 为「**父节点落在子树 $x$ 内**的所有左叶子值之和」，$[\cdot]$ 为艾弗森括号（条件成立取 1，否则取 0），则

$$f(x)=\bigl[\,x.\text{left 是叶子}\,\bigr]\cdot x.\text{left}.\text{val}+f(x.\text{left})+f(x.\text{right}),\qquad f(\text{null})=0$$

答案为 $f(\text{root})$。其中 $x.\text{left.val}$ 只有在 $x.\text{left}$ 存在时才有意义，实现上用短路求值保证安全。

递归流程：

1. `node` 为空 → 返回 0。
2. 若 `node.left` 非空且 `node.left` 无孩子 → `total += node.left.val`。
3. `total += dfs(node.left) + dfs(node.right)`。
4. 返回 `total`。

迭代流程（把方向放进栈，替代递归）：

1. 栈元素为 `(node, isLeft)`，初始 `[(root, False)]`。
2. 弹栈：若 `node` 是叶子且 `isLeft` 为真 → `total += node.val`，`continue`。
3. 否则把 `(node.left, True)`、`(node.right, False)` 压栈。

两种写法只是「谁来判断」不同：递归版由父节点判断孩子，迭代版由孩子带着方向自报。BFS 用队列替换栈，结果完全相同——本题答案与遍历顺序无关。

### 3.4 示例演算

![示例走查表](images/wc6_q1_walkthrough.svg)

对 `[3,9,20,null,null,15,7]` 做前序遍历 $3\to9\to20\to15\to7$：

| 步骤 | 当前节点 | 左孩子 | 判定 / 动作 | 累计 |
|---|---|---|---|---|
| 1 | 3 | 9 | 9 是叶子 → $+9$ | 9 |
| 2 | 9 | 空 | 无左孩子 → 不加 | 9 |
| 3 | 20 | 15 | 15 是叶子 → $+15$ | 24 |
| 4 | 15 | 空 | 无左孩子 → 不加 | 24 |
| 5 | 7 | 空 | 无左孩子 → 不加 | 24 |

得到 $24$。注意第 3 步只检查 `20.left`：`7` 这个右叶子从头到尾没有被任何判据命中，所以不计入。

再走 `[1,2]`：根 1 的左孩子 2 是叶子 → 2；`[1,null,3]`：根没有左孩子 → 0，虽然 3 也是叶子。

## 4. 算法细节

1. **空指针顺序**：判据必须写成 `node.left && !node.left.left && !node.left.right`，先确认 `node.left` 非空，再访问它孩子的指针；顺序颠倒会空指针崩溃。
2. **递归出口只有一个**：`node == null` 返回 0。不需要给叶子单独写出口——叶子进来后两个子树都空，自然返回 0。
3. **$f(x)$ 的语义边界**：定义为「父节点在子树 $x$ 内的左叶子之和」，而不是「子树 $x$ 里的所有左叶子」。区别在 $x$ 自身：它可能是它父亲的左叶子，但不属于「父节点在 $\text{sub}(x)$ 内」的集合。这样定义才能与「父节点认领」一一对应，递推相加时不重不漏。
4. **左右子树都要递归**：只递归左子树会漏掉「右子树内部还有左叶子」，例如 `[1,2,3,null,null,4]` 中 4 是 3 的左叶子，答案是 $2+4=6$。
5. **迭代写法**：栈（或 BFS 的队列）中每项携带方向布尔值；叶子判定用 `node.left == null && node.right == null`。Python 用 `list` 当栈，C++ 用 `vector<pair<TreeNode*, bool>>`。
6. **数值范围**：$n\le 1000$、$|val|\le 1000$，最坏 $1000\times1000=10^6$，`int` 足够；但值可为负，累加中间量会变负，不要写「和为 0 就提前返回」之类的剪枝。
7. **递归深度**：链状树深度可达 1000。C++ 默认栈够用；Python 默认递归上限是 1000，本地实测 1000 节点全左链会抛 `RecursionError`，所以参考代码里显式 `sys.setrecursionlimit(10000)`，或改用第 5 条的显式栈。
8. **遍历顺序无关**：前序、后序、层序得到同一个和，因为每个左叶子恰有一个父节点、只被父节点认领一次；不要额外假设「必须先左后右」。

## 5. 正确性证明

**引理 1（判据等价）**：对任意非空节点 $x$，$x.\text{left}$ 是左叶子 $\iff$ $x.\text{left}$ 非空且 $x.\text{left}.\text{left}=x.\text{left}.\text{right}=\text{null}$。

**证明**：二叉树中每个非根节点的父节点唯一，$x.\text{left}$ 的父节点就是 $x$，故「$x.\text{left}$ 是 $x$ 的左孩子」自动成立。于是「$x.\text{left}$ 是左叶子」$\iff$「$x.\text{left}$ 是叶子」，而叶子即左右孩子皆空。∎

**引理 2（唯一认领）**：每个左叶子 $y$ 恰被一个节点认领，即它的父节点 $p$；认领时贡献 $y.\text{val}$ 一次。而 $y$ 自身作为递归入口时贡献 0。

**证明**：$y$ 是左叶子，故有父节点且父节点唯一，记作 $p$，则 $y=p.\text{left}$，$p$ 满足引理 1 的判据；若有别的节点 $q$ 也满足判据且 $q.\text{left}=y$，则 $q$ 也是 $y$ 的父节点，与唯一性矛盾，故只被认领一次。又 $y$ 是叶子，$y.\text{left}=y.\text{right}=\text{null}$，它作为递归入口时判据不成立，本节点项为 0。∎

**引理 3（递归式正确）**：对任意节点 $x$，`dfs(x)` 的返回值等于「父节点位于子树 $x$ 内的所有左叶子值之和」。

**证明**：对子树 $x$ 的节点数归纳。$x=\text{null}$ 时返回 0，子树为空，结论成立。设结论对 $x.\text{left}$、$x.\text{right}$ 成立。子树 $x$ 的节点集合分解为互不相交的三部分 $\{x\}$、$\text{sub}(x.\text{left})$、$\text{sub}(x.\text{right})$，因此「父节点在 $\text{sub}(x)$ 内的左叶子」也相应分成三组：父节点在 $\text{sub}(x.\text{left})$ 内的由归纳假设被 `dfs(x.left)` 正确求和，$\text{sub}(x.\text{right})$ 内的由 `dfs(x.right)` 正确求和；剩下的只可能是父节点恰为 $x$ 的左叶子，即 $x.\text{left}$ 本身，由引理 1、2，它当且仅当是叶子时被本节点项计入一次，且 $x.\text{left}$ 作为递归入口不会再贡献（引理 2 后半）。三部分相加即得结论。∎

**定理**：`sumOfLeftLeaves(root)` 返回所有左叶子值之和。

**证明**：$root\ne\text{null}$ 时取引理 3 中 $x=root$，得到「父节点在整棵树内的左叶子」之和，即全部左叶子之和；$root=\text{null}$ 时返回 0，空树没有左叶子，结论成立。∎

## 6. 复杂度分析

- **时间**：$O(n)$。每个节点恰好被访问一次，每处判据是常数次指针比较与一次加法，无回溯、无重复访问。
- **空间**：$O(h)$，$h$ 为树高。递归版只有调用栈，平衡树 $O(\log n)$、链状树最坏 $O(n)$（$n\le1000$ 时至多约 1000 层）；迭代版显式栈同阶。除此之外不使用任何数组或哈希表。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int sumOfLeftLeaves(TreeNode* root) {
        if (!root) return 0;                       // 空节点无贡献，也是唯一递归出口
        int total = 0;
        // 在父节点处判定：左孩子存在，且它自己是叶子
        if (root->left && !root->left->left && !root->left->right)
            total += root->left->val;
        return total + sumOfLeftLeaves(root->left) + sumOfLeftLeaves(root->right);
    }
};
```

### Python

```python
import sys
from typing import Optional


class Solution:
    def sumOfLeftLeaves(self, root: Optional[TreeNode]) -> int:
        # 节点数可达 1000，链状树会触及 Python 默认递归上限
        sys.setrecursionlimit(10000)

        def dfs(node: Optional[TreeNode]) -> int:
            if node is None:
                return 0
            total = 0
            # 在父节点处判定：左孩子存在，且它自己是叶子
            if node.left is not None and node.left.left is None and node.left.right is None:
                total += node.left.val
            return total + dfs(node.left) + dfs(node.right)

        return dfs(root)
```

## 8. 边界情况与易错点

1. **空树**：`root = null` 返回 0，不能直接解引用；虽然本题约束 $n\ge1$，但接口允许 null，写上判空更稳。
2. **只有一个节点**：`[1]` 返回 0。根节点即使自己是叶子，也不是任何节点的「左孩子」，别把「根是叶子」算进去。
3. **左右要分清**：`[1,2]` 返回 2，`[1,null,3]` 返回 0；两者都是「根 + 一个叶子」，答案却不同。
4. **左侧内部节点不计**：`[1,2,3,4]` 中 2 是左孩子但有孩子、不是叶子 → 不计，只有 4 计入，答案为 4。
5. **右子树内部仍有左叶子**：`[1,2,3,null,null,4]` 中 2 是左叶子（$+2$）、4 是 3 的左叶子（$+4$），答案是 6；只递归左子树就会漏掉 4。
6. **负值**：`val` 可为负，例如 `[-1,-2,-3]` 答案为 $-2$；不要用 0 当「没有」的哨兵，也不要因为中间和变负就以为出错。
7. **Python 递归上限**：1000 节点全左链在默认上限下必抛 `RecursionError`（本地实测），要么 `sys.setrecursionlimit`，要么改写成显式栈。
8. **判据的空指针顺序**：`node.left && !node.left.left && ...`，把非空判断放最前，靠短路求值保证安全。

**延伸思考**：

- 改成「所有左孩子之和（不管是不是叶子）」时，判据退化为 `node.left != null`，$f(x)=x.\text{left}.\text{val}+f(x.\text{left})+f(x.\text{right})$；改成「左叶子之积」则要先约定空积的单位元（无左叶子时返回 0 还是 1），并且小心值为 0 的节点。
- 要按层输出「每一层的左叶子之和」，把 DFS 换成 BFS、在队列里带层号即可，仍是 $O(n)$；若树深到 $10^5$ 级，递归版必须换成显式栈或 Morris 遍历才能把空间压到 $O(1)$。
- 「父节点认领」这个套路可迁移到「统计满足某关系的父子对」一类题：与其给孩子传上下文参数，不如在父节点处一次性判定它的孩子，往往能省掉参数、额外表和易错的分支。
