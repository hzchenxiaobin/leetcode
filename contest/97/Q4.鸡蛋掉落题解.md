# LeetCode 鸡蛋掉落 题解

## 1. 题目概述

- **标题 / 题号**：鸡蛋掉落（#887，hard）
- **链接**：https://leetcode.cn/problems/super-egg-drop/
- **来源**：LeetCode 第 97 场周赛 Q4
- **难度**：困难
- **标签**：数学、二分查找、动态规划

**题意**：有 $k$ 枚**完全相同**的鸡蛋，一栋 $n$ 层的楼（楼层 $1 \sim n$）。存在阈值 $f \in [0, n]$：从**高于** $f$ 的楼层扔下鸡蛋会碎，从 $f$ 层及以下扔下不会碎。每次操作可以拿一枚**完好**的鸡蛋从任意楼层 $x$ 扔下，碎了就少一枚、没碎可以继续用。求**最坏情况下确定 $f$ 所需的最少操作次数**。

**约束**：

- $1 \le k \le 100$
- $1 \le n \le 10^4$

## 2. 示例

**示例 1**

```text
输入：k = 1, n = 2
输出：2
解释：只有一枚蛋，必须从 1 楼开始逐层往上试（碎了就前功尽弃）。
     1 楼碎 → f = 0；1 楼不碎、2 楼碎 → f = 1；2 楼不碎 → f = 2。最坏 2 次。
```

**示例 2**

```text
输入：k = 2, n = 6
输出：3
解释：第一次在 3 楼扔。碎了 → 1 枚蛋查 1、2 层，共 2 次；没碎 → 2 枚蛋查 4~6 层，
     仍可在 2 次内解决（5 楼、再 4 或 6 楼）。最坏 3 次。
```

**示例 3**

```text
输入：k = 3, n = 14
输出：4
解释：3 枚蛋、4 次操作最多区分 C(4,1)+C(4,2)+C(4,3) = 4+6+4 = 14 层，正好够；
     3 次只能区分 3+3+1 = 7 层，不够。
```

## 3. 解题思路

### 3.1 暴力思路

正向定义状态：`dp[e][f]` = 用 $e$ 枚蛋确定 $f$ 层楼所需的最少操作数。枚举第一次扔的楼层 $x$：

$$dp[e][f] = 1 + \min_{1 \le x \le f} \max\big(dp[e-1][x-1],\ dp[e][f-x]\big)$$

含义是：碎了要把下方 $x-1$ 层查清（少一枚蛋），没碎要把上方 $f-x$ 层查清（蛋数不变），取最坏分支。

这个式子本身没错，但状态数是 $k \cdot n = 10^6$，每个状态还要枚举 $x$（最坏 $n = 10^4$），总复杂度 $O(k n^2) \approx 10^{10}$，必然超时。即使把内层换成二分（利用单调性），也只是 $O(k n \log n)$，仍偏大且实现容易写错边界。

### 3.2 核心观察：把「楼层」和「次数」对偶过来

![在第 x 层扔一枚蛋：两种结局各消耗 1 次操作](images/wc97_q4_decision.svg)

关键的一步是**换掉未知量**。正向 DP 问的是「给定楼层数，最少几次」，我们改成问：

> $F(t, k)$ = 用 $k$ 枚蛋、**最多 $t$ 次操作**，能**确保确定**的最大楼层数。

那么答案就是最小的 $t$ 使 $F(t, k) \ge n$。

**递推**：第一次在某个楼层扔，这一层本身的信息可以立刻确定（碎/不碎各对应一个区间），碎的支路还剩 $t-1$ 次、$k-1$ 枚蛋，最多覆盖它下面的 $F(t-1, k-1)$ 层；没碎的支路还剩 $t-1$ 次、$k$ 枚蛋，最多覆盖它上面的 $F(t-1, k)$ 层。故

$$F(t, k) = F(t-1, k-1) + 1 + F(t-1, k),\qquad F(0, k) = F(t, 0) = 0$$

这个递推的妙处是：**「楼层」不再出现在状态里**，$t$ 只需从 0 开始一路加，直到 $F(t,k) \ge n$。

**闭式解**：由帕斯卡恒等式可归纳得到

$$F(t, k) = \sum_{j=1}^{k} \binom{t}{j} = \binom{t}{1} + \binom{t}{2} + \cdots + \binom{t}{k}$$

直觉解释：$t$ 次操作中「哪些次是碎掉的」构成一个下标集合，若共有 $j$ 次碎，则这种模式的数目是 $\binom{t}{j}$，而 $j$ 最多为 $k$（只有 $k$ 枚蛋）。当 $k \ge t$ 时 $F(t,k) = 2^t - 1$——这就是「蛋足够多时纯二分」的经典结论。

![k = 2, n = 6 的决策树](images/wc97_q4_two_eggs_tree.svg)

上图是示例 2 的最优策略：第一次扔 3 楼，两条支路都只剩 2 次机会，而 2 枚蛋 2 次能覆盖 $2 + 1 = 3$ 层，恰好够。这也说明为什么答案是 3 而不是 2：2 次操作最多覆盖 $2 + 1 = 3 < 6$ 层。

### 3.3 算法流程

![dp 滚动表：k = 3 时每多一次操作覆盖多少层](images/wc97_q4_dp_table.svg)

用一维数组滚动 $t$：

```text
1. dp[0..k] = 0                      # dp[j] 即 F(当前 t, j)
2. t = 0
3. while dp[k] < n:
4.     t += 1
5.     for j = k down to 1:           # 必须倒序！
6.         dp[j] = dp[j] + dp[j-1] + 1
7. 返回 t
```

- 第 6 行的 `dp[j]` 在赋值前是 $F(t-1, j)$、`dp[j-1]` 是 $F(t-1, j-1)$，两者相加再加 1 正是 $F(t, j)$。
- 倒序遍历保证 `dp[j-1]` 还没被本轮更新，否则会把 $F(t, j-1)$ 当成 $F(t-1, j-1)$ 用，结果偏大。

### 3.4 示例演算

**演算一（$k = 2, n = 6$，答案 3）**

| $t$ | $F(t,1)$ | $F(t,2)$ | 是否 $\ge 6$ |
|-----|----------|----------|--------------|
| 0 | 0 | 0 | 否 |
| 1 | 1 | 1 | 否 |
| 2 | 2 | 3 | 否 |
| 3 | 3 | 6 | **是 → 答案 3** |

**演算二（$k = 3, n = 14$，答案 4）**

| $t$ | $F(t,1)$ | $F(t,2)$ | $F(t,3)$ | 是否 $\ge 14$ |
|-----|----------|----------|----------|----------------|
| 0 | 0 | 0 | 0 | 否 |
| 1 | 1 | 1 | 1 | 否 |
| 2 | 2 | 3 | 3 | 否 |
| 3 | 3 | 6 | 7 | 否 |
| 4 | 4 | 10 | **14** | **是 → 答案 4** |

第 4 行三个数的来源：$F(4,3) = F(3,2) + 1 + F(3,3) = 6 + 1 + 7 = 14$，而 $14 = \binom41 + \binom42 + \binom43 = 4 + 6 + 4$，闭式解与递推一致。

## 4. 算法细节

1. **状态压缩**：只保留「当前 $t$」的一行 $dp[0..k]$，空间从 $O(k \log n)$ 降到 $O(k)$。
2. **倒序更新**：这是滚动数组的关键。$F(t,j)$ 依赖 $F(t-1, j-1)$，倒序保证用到的是上一轮的值。
3. **终止条件**：`dp[k] >= n`。由于 $dp[k]$ 关于 $t$ 单调不减（每次至少 $+1$），循环必然终止，且 $t \le n$（一枚蛋逐层试的上界）。
4. **迭代次数**：$t \approx \log_2 n$（蛋足够多时），$n = 10^4$ 时 $t \le 14$，内层 $k$ 次，总计算量约 $100 \times 14 = 1400$。
5. **数值范围**：$F(t,k)$ 在 $n \le 10^4$ 时远小于 $2^{31}$（最大约 $2^{14}$），`int` 足够；若把 $n$ 放大到 $10^9$ 以上应改用 `long long` 并注意提前截断。
6. **等价写法**：也可以预先算出 $F(t,k)$ 的上界再对 $t$ 二分，但「边算边加、加到就停」更简单，也没有二分边界问题。
7. **不要用「蛋数取 min(k, log2 n)」之类的剪枝错误**：$k$ 大于等于 $t$ 时答案完全由 $2^t - 1 \ge n$ 决定，直接让循环跑即可。

## 5. 正确性证明

**引理 1（递推成立）**：设 $F(t,k)$ 为 $k$ 枚蛋、$t$ 次操作能确保确定的最大楼层数，则 $F(t,k) = F(t-1,k-1) + 1 + F(t-1,k)$。

**证明**：任意策略的第一次操作必然选中某一层 $x$。设它能把下方 $x-1$ 层与上方 $n-x$ 层都查清。

- 碎了：剩 $k-1$ 枚蛋、$t-1$ 次操作，只能确定下方（因为 $f < x$），故 $x - 1 \le F(t-1, k-1)$；
- 没碎：剩 $k$ 枚蛋、$t-1$ 次操作，确定上方，故 $n - x \le F(t-1, k)$。

于是 $n \le F(t-1,k-1) + 1 + F(t-1,k)$；又取 $x = F(t-1,k-1)+1$ 可让两条支路各自打满上界，故等号可达。边界 $F(0,k)=0$（不操作什么都确定不了）、$F(t,0)=0$（没蛋不能试）显然。∎

**引理 2（闭式解）**：$F(t,k) = \sum_{j=1}^{k} \binom{t}{j}$。

**证明**：对 $t$ 归纳。$t=0$ 时两边都是 0。设对 $t-1$ 成立，则

$$F(t,k) = \sum_{j=1}^{k-1}\binom{t-1}{j} + 1 + \sum_{j=1}^{k}\binom{t-1}{j} = \sum_{j=1}^{k}\binom{t-1}{j} + \sum_{j=0}^{k-1}\binom{t-1}{j}$$

由帕斯卡恒等式 $\binom{t}{j} = \binom{t-1}{j} + \binom{t-1}{j-1}$，两个求和逐项相加恰好得到 $\sum_{j=1}^{k}\binom{t}{j}$。∎

**定理**：最少操作次数等于最小的 $t$ 使 $F(t,k) \ge n$。

**证明**：

- **可行**：若 $F(t,k) \ge n$，由引理 1 的构造（第一次扔 $F(t-1,k-1)+1$ 层，之后递归）可在 $t$ 次内确定 $f$，故最优次数 $\le t$。
- **必要**：若某个策略在 $t$ 次内能确定 $f$，由引理 1 的证明，它最多能覆盖 $F(t,k)$ 层，故 $n \le F(t,k)$。因此最优次数 $\ge$ 最小的满足条件的 $t$。

两者合并即得结论。∎

**推论（信息论下界）**：当 $k \ge t$ 时 $F(t,k) = 2^t - 1$，故 $t \ge \lceil \log_2(n+1) \rceil$；蛋数不足时下界更松，正对应「蛋不够就只能线性试」。

## 6. 复杂度分析

- **时间**：$O(k \cdot T)$，其中 $T$ 为答案（所需操作次数），$T \le \lceil \log_2(n+1) \rceil \le 14$（$n \le 10^4$）且 $T \le n$。故最坏约 $O(k \log n)$，即 $100 \times 14$ 次加法。
- **空间**：$O(k)$，只有一个长度为 $k+1$ 的滚动数组。

对比正向 DP 的 $O(k n^2)$ 与二分优化的 $O(k n \log n)$，这里把「楼层」维度整个消掉了，是本题最优的复杂度。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int superEggDrop(int k, int n) {
        vector<int> dp(k + 1, 0);
        int t = 0;
        while (dp[k] < n) {
            t++;
            for (int j = k; j >= 1; j--) {
                dp[j] = dp[j] + dp[j - 1] + 1;
            }
        }
        return t;
    }
};
```

### Python

```python
class Solution:
    def superEggDrop(self, k: int, n: int) -> int:
        dp = [0] * (k + 1)          # dp[j]：j 枚蛋、当前步数下最多能确定的楼层数
        t = 0
        while dp[k] < n:
            t += 1
            for j in range(k, 0, -1):
                dp[j] = dp[j] + dp[j - 1] + 1
        return t
```

## 8. 边界情况与易错点

1. **忘记倒序**：`for j = 1..k` 正序更新会用到本轮已算出的 `dp[j-1]`，得到的是 $F(t,\cdot)$ 而非 $F(t-1,\cdot)$，结果偏小甚至错得不明显，是最难查的 bug。
2. **$n = 1$**：$t=1$ 时 $F(1,k) = 1 \ge 1$，答案为 1，循环只跑一轮。
3. **$k = 1$**：退化为逐层试，$F(t,1) = t$，答案正好是 $n$；此时 $t$ 会到 $10^4$，循环体仍是 $O(1)$，不会超时。
4. **$k > n$**：蛋比楼层还多，答案由二分下界决定（如 $n = 6$、$k = 100$ 时答案仍为 3）。递推天然处理，无需特判。
5. **$k$ 过大时的溢出**：$F(t,k)$ 随 $k$ 增长到 $2^t - 1$，若 $n$ 很大（如 $10^9$）需用 `long long`，或在 `dp[j] > n` 时截断为 $n$ 防止溢出。
6. **把「确定 $f$」误解成「找出最低会碎的楼层」**：$f = 0$ 与 $f = n$ 都是合法取值，因此 $n$ 层楼有 $n+1$ 种可能，这也是 $F(t,k) = 2^t - 1$（不是 $2^t$）的由来。
7. **`dp[0]` 必须恒为 0**：它是「0 枚蛋」的边界，虽然循环里不会更新它，但初始化必须正确。
