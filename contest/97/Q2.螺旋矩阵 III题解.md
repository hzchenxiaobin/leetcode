# LeetCode 螺旋矩阵 III 题解

## 1. 题目概述

- **标题 / 题号**：螺旋矩阵 III（#885，medium）
- **链接**：https://leetcode.cn/problems/spiral-matrix-iii/
- **来源**：LeetCode 第 97 场周赛 Q2
- **难度**：中等
- **标签**：数组、矩阵、模拟

**题意**：在 $rows \times cols$ 的网格上，从 $(rStart, cStart)$ 出发、**面朝东**，按**顺时针螺旋**在**无限大的平面**上行走：走出网格边界后仍然继续走（只是那些越界位置不记录），当网格内所有 $rows \times cols$ 个格子都被走到过时结束，按**被访问的先后顺序**返回这些格子的坐标。

**要点**：螺旋的半径不断增大，走出边界不是终止条件——边界外的位置只是「不记录」，螺旋照样向外扩张，最终一定会扫回网格内的剩余格子。

**约束**：

- $1 \le rows, cols \le 100$
- $0 \le rStart < rows$，$0 \le cStart < cols$

```text
输出：[[0,0],[0,1],[0,2],[0,3]]
解释：起点 (0,0) 记 1；接着向东走到 (0,1)；随后螺旋在 1 行的世界里大幅向外扩张，
     等半径长大后再次扫过第 0 行的 (0,2)、(0,3)。
```

## 3. 解题思路

### 3.1 暴力思路

如果按「贴着已访问格子的内旋」去模拟（像 LeetCode 54/59 那样撞墙右转），会立刻发现前提不成立：**这里没有「墙」**。网格外是一片空白，螺旋必须继续走出去，而内旋式模拟一旦出界就会原地打转、永远回不来。

另一种朴素想法是枚举所有可能落入网格的坐标、逐个判定「它是不是螺旋上的下一个」，但螺旋的序号没有闭式公式，只能模拟。

于是只能老老实实模拟**无限平面上的方形螺旋**，只是把「越界」当作值得忽略的一步。

### 3.2 核心观察：步长序列 1,1,2,2,3,3,…

![无限平面上的方形螺旋：步长 1,1,2,2,3,3,…](images/wc97_q2_spiral_steps.svg)

方形螺旋有一个非常干净的结构：**方向按东 → 南 → 西 → 北循环右转**，而每一段的**步数**是

$$1,\ 1,\ 2,\ 2,\ 3,\ 3,\ 4,\ 4,\ \dots$$

也就是「每个步长值连续用两次，然后加一」。因此模拟状态只需要四个量：

- 当前坐标 $(r, c)$、当前方向 $d \in \{0,1,2,3\}$（东、南、西、北）；
- 当前步长 $step$，以及「本步长已经走过几个方向」的计数。

每走一步就更新一次坐标：若新坐标落进网格就记入答案；落在网格外就**只更新坐标、不记录**。答案长度达到 $rows \times cols$ 时立即返回。

![示例 2 的访问次序](images/wc97_q2_example_walk.svg)

上图把示例 2 的 30 个格子按访问次序编号，可以直观看清两个现象：

1. 螺旋并不是「按行」或「按列」推进的，因此答案里出现顺序跳跃（第 16 个 (0,2) 之后直接跳到第 4 行）是**正常**的；
2. 越界的步数远多于有效步数——半径要涨到足够大才能覆盖整个 $5 \times 6$ 的矩形。

### 3.3 算法流程

![算法流程：按步长绕圈，集满即停](images/wc97_q2_spiral_flow.svg)

```text
1. ans = [(rStart, cStart)]；r = rStart，c = cStart；d = 东；step = 1
2. while len(ans) < rows * cols:
3.     for t = 1 .. 2:                       # 同一个步长走两个方向
4.         for s = 1 .. step:                # 沿方向 d 走 step 步
5.             (r, c) += dir[d]
6.             若 0 <= r < rows 且 0 <= c < cols:
7.                 ans.append((r, c))
8.                 若 len(ans) == rows * cols: 返回 ans
9.         d = (d + 1) % 4                    # 右转
10.    step += 1
11. 返回 ans
```

### 3.4 示例演算

以示例 1（$1 \times 4$，起点 $(0,0)$）为例，只列出**落入网格**的格子：

| 段号 | 方向 | 步数 | 走过的坐标（只列网格内） | 已收集 |
|------|------|------|--------------------------|--------|
| 起点 | — | — | (0,0) | 1 |
| 1 | 东 | 1 | (0,1) | 2 |
| 2 | 南 | 1 | — | 2 |
| 3 | 西 | 2 | — | 2 |
| 4 | 北 | 2 | — | 2 |
| 5 | 东 | 3 | — | 2 |
| 6 | 南 | 3 | (0,2) | 3 |
| 7 | 西 | 4 | — | 3 |
| 8 | 北 | 4 | — | 3 |
| 9 | 东 | 5 | — | 3 |
| 10 | 南 | 5 | (0,3) | 4 → 结束 |

可以看到：在 1 行的极端窄网格里，(0,2)、(0,3) 要等到螺旋半径涨到 3、5 才被扫到——**这正是「越界继续走」的含义**，也是本题与众不同的地方。

## 4. 算法细节

1. **方向表**：`dirs = {(0,1), (1,0), (0,-1), (-1,0)}` 对应东、南、西、北，右转就是 `d = (d + 1) % 4`，不需要额外判断边界。
2. **起点先入答案**：起点一定在网格内（题面保证），先 `push` 一次，后面循环只处理「走一步之后」的位置，避免重复记录。
3. **越界只跳过记录**：坐标仍然要 `+= dir`，这是与「撞墙右转」模拟最本质的区别。忘记更新坐标会让螺旋卡在原地。
4. **提前返回**：一旦 `ans.size() == rows*cols` 立刻 `return`，不必等一圈走完。内层循环里判断一次即可，代价是每步一次比较。
5. **终止性**：外层 `while` 一定会退出。螺旋第 $m$ 圈覆盖边长 $2m+1$ 的正方形，取 $m \ge \max(rows, cols)$ 即覆盖整个网格；而此时 `ans` 必然已集满。所以循环体内不需要额外保险。
6. **复杂度估算**：步数总量约为 $\sum_{k=1}^{2m} k \approx 2m^2$，其中 $m \approx \max(rows, cols)$。$rows, cols \le 100$ 时约 $2 \times 10^4$ 步，非常轻。

## 5. 正确性证明

**引理 1（步长与方向）**：设第 $k$ 段（$k = 1, 2, \dots$）的移动方向为 $d_k = (k-1) \bmod 4$、步数为 $L_k = \lfloor (k+1)/2 \rfloor$，则算法第 3–9 行产生的移动序列恰为 $(d_1, L_1), (d_2, L_2), \dots$。

**证明**：算法里 `t` 循环每轮走「同一 `step` 的两个方向」，两个方向走完才 `step += 1`。于是第 1、2 段步长为 1，第 3、4 段步长为 2，第 5、6 段步长为 3……即 $L_k = \lfloor (k+1)/2 \rfloor$。方向在每段结束时右转一次，从东开始，故 $d_k = (k-1) \bmod 4$。∎

**引理 2（不重复）**：无限平面上，上述螺旋路径的各个位置互不相同。

**证明**：把路径按「圈」分组：第 1 段与第 2 段构成以起点为中心、半径 1 的环（去掉起点后的正方形边框），随后第 3–4 段、第 5–6 段依次构成半径 $2, 3, \dots$ 的环。每个环上各点与起点的切比雪夫距离（$\max(|\Delta r|, |\Delta c|)$）恰好等于该环半径，而不同环的半径互不相同，故不同环的格子不重合；同一环内按顺时针方向各走一遍，也不重合。∎

**引理 3（覆盖性）**：网格内任意格子 $(r, c)$ 最终都会被访问到。

**证明**：设 $D = \max(rows, cols)$。螺旋走过第 $D$ 圈后，其轨迹包含以起点为中心、边长 $2D+1$ 的正方形边框，该正方形完整覆盖整个网格（网格任一点与起点的行、列偏移都小于 $\max(rows, cols)$）。由引理 2，路径上的位置都是新位置，因此网格内每个格子都会在某个时刻被走到。∎

**定理**：算法返回的序列恰为「按螺旋访问顺序排列的全部网格格子」，每个格子恰好一次。

**证明**：算法只在坐标落入网格时追加；由引理 1 它走的正是螺旋路径，由引理 2 路径无重复，因此 `ans` 中不会有重复格子，且其顺序就是真实的访问顺序。由引理 3，`ans` 最终会包含全部 $rows \times cols$ 个格子，此时长度判定触发返回，故返回的序列既不缺格也不多重。∎

## 6. 复杂度分析

- **时间**：$O\big((\max(rows, cols))^2\big)$。每走一步只做常数次比较与写入，总步数为前 $2m$ 段的步数之和，$m = O(\max(rows, cols))$，故为 $O(m^2)$。与「收集 $rows \cdot cols$ 个格子」的下界相比，多出来的是越界步数——这是本题绕不开的代价（示例 1 的 $1 \times 4$ 网格就要走几十步）。
- **空间**：$O(rows \cdot cols)$，即答案本身；除方向表与少量标量外没有额外结构。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<vector<int>> spiralMatrixIII(int rows, int cols, int rStart, int cStart) {
        int total = rows * cols;
        vector<vector<int>> ans{{rStart, cStart}};
        int r = rStart, c = cStart;
        int dirs[4][2] = {{0, 1}, {1, 0}, {0, -1}, {-1, 0}};
        int d = 0, step = 1;
        while ((int)ans.size() < total) {
            for (int k = 0; k < 2; k++) {
                for (int s = 0; s < step; s++) {
                    r += dirs[d][0];
                    c += dirs[d][1];
                    if (r >= 0 && r < rows && c >= 0 && c < cols) {
                        ans.push_back({r, c});
                        if ((int)ans.size() == total) return ans;
                    }
                }
                d = (d + 1) % 4;
            }
            step++;
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def spiralMatrixIII(self, rows: int, cols: int, rStart: int, cStart: int) -> list[list[int]]:
        total = rows * cols
        ans = [[rStart, cStart]]
        r, c = rStart, cStart
        dirs = [(0, 1), (1, 0), (0, -1), (-1, 0)]   # 东 → 南 → 西 → 北
        d, step = 0, 1
        while len(ans) < total:
            for _ in range(2):                       # 每个步长走两个方向
                dr, dc = dirs[d]
                for _s in range(step):
                    r += dr
                    c += dc
                    if 0 <= r < rows and 0 <= c < cols:
                        ans.append([r, c])
                        if len(ans) == total:
                            return ans
                d = (d + 1) % 4
            step += 1
        return ans
```

## 8. 边界情况与易错点

1. **出界不是终止条件**：这是本题最容易踩的坑。若照搬 LeetCode 54 的「撞墙右转」，出界后坐标不再更新，循环永远结束不了。
2. **越界时坐标要更新**：`r += dr; c += dc` 必须在判定之前执行，且无论是否越界都要执行。
3. **起点不能重复记录**：先把起点放进答案，循环里只处理「走完之后」的位置。
4. **`1 x 1` 网格**：起点即答案，`while` 条件立刻为假，直接返回 `[[rStart, cStart]]`。
5. **单行或单列网格**：如 `rows = 1`，螺旋要涨到很大半径才能扫到同一行的远端格子，答案看起来「跳跃」是正常的，不要据此判错。
6. **提前返回的位置**：返回点在内层循环内，此时 `ans` 长度已等于 `total`，外层循环不会再执行；若把判断提到外层，会多走一整段甚至溢出边界。
7. **坐标顺序**：返回的是 `[行, 列]`（`[r, c]`），不要写成 `[列, 行]`。
