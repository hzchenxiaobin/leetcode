# LeetCode 可能的二分法 题解

## 1. 题目概述

- **标题 / 题号**：可能的二分法（#886，medium）
- **链接**：https://leetcode.cn/problems/possible-bipartition/
- **来源**：LeetCode 第 97 场周赛 Q3
- **难度**：中等
- **标签**：深度优先搜索、广度优先搜索、并查集、图、二分图

**题意**：把 $1 \sim n$ 这 $n$ 个人分进**两个任意大小**的组，使得每条「不喜欢」关系 $\text{dislikes}[i] = [a_i, b_i]$ 的两个人都**不在同一组**。能做到返回 `true`，否则返回 `false`。

**约束**：

- $1 \le n \le 2000$
- $0 \le \text{dislikes.length} \le 10^4$
- $\text{dislikes}[i].length = 2$，$1 \le a_i, b_i \le n$，$a_i < b_i$，且列表内每组关系互不相同

## 2. 示例

**示例 1**

```text
输入：n = 4, dislikes = [[1,2],[1,3],[2,4]]
输出：true
解释：group1 = [1,4]，group2 = [2,3]。
     1 与 2、1 与 3、2 与 4 都跨组，全部满足。
```

**示例 2**

```text
输入：n = 3, dislikes = [[1,2],[1,3],[2,3]]
输出：false
解释：三个人两两都不喜欢，无论怎么分，总有一对落进同一组。
```

**示例 3**

```text
输入：n = 5, dislikes = [[1,2],[2,3],[3,4],[4,5],[1,5]]
输出：false
解释：这是一条 5 元环 1-2-3-4-5-1。沿着边交替染色，回到 5 时会与 1 同色（必然冲突）。
     注意它不是一个「明显的三角形」，说明只检查局部并不够，必须走完整条环。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的做法是枚举所有 $2^n$ 种分组（每个点选组 0 或组 1），逐个检查每条边是否跨组。判定一次 $O(m)$，总复杂度 $O(2^n m)$；$n \le 2000$ 时完全不可行，只能用于对拍小数据。

另一种「贪心」式想法——按人依次分配、谁都不喜欢就随便放——也是错的：一个点的组别由它的邻居决定，先放的顺序会影响后续，无法保证最优。

### 3.2 核心观察：这就是二分图判定

![「不喜欢」= 必须异色，本质是二分图判定](images/wc97_q3_bipartite_model.svg)

把每个人看成点、每条不喜欢关系看成无向边。题目要求「每条边的两端不同组」，等价于给点集做 **2 染色**：每条边两端颜色不同。这正是**二分图（bipartite graph）**的定义。

于是问题变成标准的二分图判定，有两条经典结论可直接借用：

- 一个图是二分图 **当且仅当** 它不含**奇环**（奇数长度的环）。示例 2 的三角形、示例 3 的 5 元环都是奇环，所以都无解。
- 判定方法：从任意未染色的点出发给它染 1 号色，然后 BFS/DFS 扩散，邻居必须染**相反色**（`3 - color[u]`）；若发现某个已染色的邻居与自己同色，立刻判定失败。

![奇环一定冲突](images/wc97_q3_odd_cycle.svg)

**为什么奇环一定会冲突？** 沿着环走一圈，每跨一条边颜色翻转一次。环长为奇数时总共翻转奇数次，回到起点时颜色必须翻转——但起点颜色是固定的，矛盾。

### 3.3 算法流程

![算法流程：逐连通块二染色](images/wc97_q3_color_flow.svg)

```text
1. 建邻接表：对每条 (a, b)，adj[a].push(b)，adj[b].push(a)
2. color[1..n] = 0（0 表示未染色）
3. for s = 1 .. n:
4.     若 color[s] != 0: 跳过
5.     color[s] = 1，把 s 入队
6.     while 队列非空:
7.         u = 出队
8.         for v in adj[u]:
9.             若 color[v] == 0: color[v] = 3 - color[u]，v 入队
10.            否则若 color[v] == color[u]: 返回 false
11. 全部连通块处理完，返回 true
```

### 3.4 示例演算

**示例 1（有解）**：边为 $1\text{-}2$、$1\text{-}3$、$2\text{-}4$。

| 步骤 | 处理 | 染色结果（color[1..4]） | 说明 |
|------|------|------------------------|------|
| 1 | 起点 1 | 1:1 | 染 1 号色 |
| 2 | 从 1 扩散 | 1:1, 2:2, 3:2 | 2、3 是 1 的邻居，染相反色 |
| 3 | 从 2 扩散 | 1:1, 2:2, 3:2, 4:1 | 4 是 2 的邻居，染 1 号色 |
| 4 | 队列空 | — | 无冲突 → `true` |

得到两组：$\{1,4\}$ 与 $\{2,3\}$，与题解给出的分组一致。

**示例 3（无解）**：环 $1\text{-}2\text{-}3\text{-}4\text{-}5\text{-}1$。按 BFS 的入队顺序走：

| 步骤 | 处理 | 染色（只列已染的） |
|------|------|--------------------|
| 1 | 起点 1 | 1:1 |
| 2 | 1 出队，邻居入队 | 2:2，5:2 |
| 3 | 2 出队 | 3:1 |
| 4 | 5 出队 | 4:1 |
| 5 | 3 出队，检查边 3-4 | color[3] = color[4] = 1 → **冲突，返回 false** |

冲突的根源是环长奇数：若沿环交替染色（$1 \to A$、$2 \to B$、$3 \to A$、$4 \to B$、$5 \to A$），最后 5 与 1 相邻却同为 $A$。BFS 只是按自己的顺序撞上同一处矛盾——它把 4 染成了 1（与 5 相反），而 3 也是 1（与 2 相反），于是边 3-4 两端同色。

## 4. 算法细节

1. **邻接表规模**：$n \le 2000$、$m \le 10^4$，用 `vector<vector<int>>` 即可；边数不大，无需前向星。
2. **多连通块**：外层 `for s = 1..n` 覆盖所有连通块。图可能不连通（例如 $n=2000$、只有一条边），漏掉外层循环会漏判。
3. **孤立点**：没有边的点染成 1 号色即可，不会产生冲突，也不影响答案。
4. **用 BFS 而非递归 DFS**：$n$ 最多 2000，递归深度可能到 2000，Python 默认递归上限 1000 会炸；BFS 无此问题。
5. **染色值取 `3 - color[u]`**：颜色只有 1、2 两种，减法比 `if/else` 更简洁且不会写错。
6. **冲突判定时机**：只在「邻居已染色」时比较颜色。若邻居未染色，直接染相反色入队，不需要回看。
7. **无需真的构造分组**：题目只问可行性，返回布尔值即可；若要输出分组，按颜色收集即可。

## 5. 正确性证明

**引理 1（染色合法 ⇒ 存在分组）**：若算法运行结束且未报告冲突，则把颜色为 1 的人放一组、颜色为 2 的人放另一组，是一个合法分组。

**证明**：任取一条边 $(u, v)$。$u$ 被染色时会把 $v$ 染成 `3 - color[u]`（若 $v$ 尚未染色），或者检查时要求 `color[v] != color[u]`。两种情形下都有 `color[v] != color[u]`，故 $u, v$ 必在不同组。所有边都跨组，分组合法。∎

**引理 2（冲突 ⇒ 无解）**：若算法报告冲突，即存在边 $(u,v)$ 使 `color[u] == color[v]`，则不存在合法分组。

**证明**：需要先说明「染色值的差」有组合意义。断言：对任意已染色的点 $x$，`color[x]` 等于「从它所在连通块的起点 $s$ 到 $x$ 的任意一条路径长度的奇偶性」决定的颜色，即路径长度为偶数时与 $s$ 同色、为奇数时异色。这可由 BFS 逐层归纳证明：BFS 树上的边每次翻转颜色，故结论对树边成立；非树边 $(u,v)$ 若满足 `color[u] == color[v]`，说明 $s \to u$、$s \to v$ 两条路径的奇偶性相同，于是 $s \to u \to v \to s$ 构成一个**奇环**。由「图是二分图当且仅当不含奇环」，该图不是二分图，故不存在合法分组。∎

**定理**：算法返回 `true` 当且仅当存在把 $n$ 人分成两组、使每条 dislike 关系跨组的方案。

**证明**：

- （⇐）若存在合法分组，把它看成 2 染色方案。算法的 BFS 从每个连通块任取起点染 1 号色，由于连通块内任意两点的颜色关系被路径奇偶性唯一确定（引理 2 的断言），而合法方案的染色也必须满足同样的相邻异色约束，两者至多相差整体换色，故算法不会遇到同色边，返回 `true`。
- （⇒）若算法返回 `true`，由引理 1 可构造出合法分组。

两个方向合起来即得结论。∎

## 6. 复杂度分析

- **时间**：$O(n + m)$。建图 $O(m)$；每个点入队、出队各一次，每条无向边被两个端点各扫描一次，共 $O(n + m)$。
- **空间**：$O(n + m)$。邻接表存 $2m$ 个整数，`color` 数组 $O(n)$，队列 $O(n)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool possibleBipartition(int n, vector<vector<int>>& dislikes) {
        vector<vector<int>> adj(n + 1);
        for (auto& e : dislikes) {
            adj[e[0]].push_back(e[1]);
            adj[e[1]].push_back(e[0]);
        }
        vector<int> color(n + 1, 0);
        for (int s = 1; s <= n; s++) {
            if (color[s]) continue;
            color[s] = 1;
            queue<int> q;
            q.push(s);
            while (!q.empty()) {
                int u = q.front();
                q.pop();
                for (int v : adj[u]) {
                    if (color[v] == 0) {
                        color[v] = 3 - color[u];
                        q.push(v);
                    } else if (color[v] == color[u]) {
                        return false;
                    }
                }
            }
        }
        return true;
    }
};
```

### Python

```python
from collections import deque

class Solution:
    def possibleBipartition(self, n: int, dislikes: list[list[int]]) -> bool:
        adj = [[] for _ in range(n + 1)]
        for a, b in dislikes:
            adj[a].append(b)
            adj[b].append(a)
        color = [0] * (n + 1)          # 0 未染色，1 / 2 为两种颜色
        for s in range(1, n + 1):
            if color[s]:
                continue
            color[s] = 1
            q = deque([s])
            while q:
                u = q.popleft()
                for v in adj[u]:
                    if color[v] == 0:
                        color[v] = 3 - color[u]
                        q.append(v)
                    elif color[v] == color[u]:
                        return False
        return True
```

## 8. 边界情况与易错点

1. **图不连通**：必须在外层遍历所有起点，只从 1 号点出发会漏掉其他连通块里的冲突。
2. **`n = 1` 或没有 dislike**：没有边，直接 `true`；代码里 `dislikes` 为空时邻接表全空，外层循环逐点染色，正常返回 `true`。
3. **奇环不是「局部三角形」**：示例 3 的 5 元环说明冲突可能出现在很长的环上，靠「检查每条边两端度数」之类的局部规则无法发现。
4. **递归深度**：Python 用递归 DFS 时 $n = 2000$ 的链会超过默认递归上限；用 BFS 或手动 `sys.setrecursionlimit` 规避。
5. **不要真的去「交换」分组**：一旦染色完成，冲突检测是 O(1) 的比较；如果写成回溯搜索（尝试两种颜色并回退），复杂度会退化。
6. **下标从 1 开始**：数组开 $n+1$，别把 `dislikes` 里的 1-based 编号当成 0-based 直接索引。
7. **重复边不会出现**：题面保证 `dislikes` 内每组不同，因此不必去重；即便出现重复边，算法也不会误判（重复边只是重复检查同色）。
