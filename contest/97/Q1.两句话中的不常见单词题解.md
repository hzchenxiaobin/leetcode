# LeetCode 两句话中的不常见单词 题解

## 1. 题目概述

- **标题 / 题号**：两句话中的不常见单词（#884，easy）
- **链接**：https://leetcode.cn/problems/uncommon-words-from-two-sentences/
- **来源**：LeetCode 第 97 场周赛 Q1
- **难度**：简单
- **标签**：哈希表、字符串、计数

**题意**：给两个句子 `s1`、`s2`（句子是由单个空格分隔的单词序列，单词只含小写字母），返回所有「不常见单词」：该单词在**其中一个句子中出现恰好一次**，而在**另一个句子中没有出现**。返回顺序任意。

换句话说，把两个句子拼成一个词流统一计数，某单词出现的**总次数恰好为 1** 时它才是答案——这就是本题唯一需要看穿的等价改写。

**约束**：

- $1 \le s_1.length, s_2.length \le 200$
- 只有小写字母与单个空格；无前导、尾随空格，词间不出现连续空格

## 2. 示例

**示例 1**

```text
输入：s1 = "this apple is sweet", s2 = "this apple is sour"
输出：["sweet","sour"]
解释：this / apple / is 在两个句子里都出现，总次数 2；
     sweet、sour 只出现在 s1 且各 1 次 → 都是不常见单词。
```

**示例 2**

```text
输入：s1 = "apple apple", s2 = "banana"
输出：["banana"]
解释：apple 在 s1 内部出现了 2 次，虽然 s2 里没有，但它在「其中一个句子中出现恰好一次」不成立；
     banana 只在 s2 出现 1 次 → 不常见。
```

**示例 3（自造，用于说明同词跨句）**

```text
输入：s1 = "a a b", s2 = "a c"
输出：["b","c"]（顺序任意）
解释：a 的总次数是 3；b、c 各 1 次。
```

## 3. 解题思路

### 3.1 暴力思路

最直白的写法：先各自把句子切成单词表 $W_1, W_2$，然后对每个词 $w$ 分别统计它在 $W_1$、$W_2$ 中的次数，再判断「一边恰好 1 次、另一边 0 次」。如果对每个词都在两个列表里各扫一遍，复杂度是 $O(n^2)$（$n$ 为总词数）。$n \le 400$ 时当然能过，但重复扫表毫无必要，而且判定条件写得啰嗦、容易漏掉「同一句子里重复两次」这一条。

### 3.2 核心观察：合并成一个词流，只看总次数

![两句话合并计数：出现 1 次的单词才留下](images/wc97_q1_freq_table.svg)

**关键观察**：题目要求「在一句中恰好一次，在另一句中没有出现」。设单词 $w$ 在两句中的出现次数分别为 $c_1, c_2$，则

$$\text{不常见} \iff (c_1 = 1 \wedge c_2 = 0) \ \vee\ (c_1 = 0 \wedge c_2 = 1) \iff c_1 + c_2 = 1$$

也就是说：**不需要区分两个句子，只要合并后的总次数为 1 即可**。这个等价改写把「两个条件」压成一个计数条件。

剩下的事情就是一次哈希计数：

- 把 `s1 + " " + s2` 按空格切成一个词流，长度 $n = n_1 + n_2$；
- 用哈希表 `cnt` 累加每个词的出现次数；
- 收集所有 `cnt[w] == 1` 的词，顺序任意。

反过来，`cnt[w] >= 2` 有两种可能，都被题意否决：出现在两句各一次（示例 1 的 `this`），或者在同一句里出现多次（示例 2 的 `apple`）。

### 3.3 算法流程

![算法流程：拼接 → 切分 → 计数 → 筛选](images/wc97_q1_scan_flow.svg)

```text
1. s = s1 + " " + s2
2. 按空格把 s 切成单词序列 words
3. cnt = 空哈希表
4. for w in words:  cnt[w] += 1
5. ans = [w for w in cnt 的键 if cnt[w] == 1]
6. 返回 ans
```

### 3.4 示例演算

对示例 1 的 `s1 = "this apple is sweet"`、`s2 = "this apple is sour"`，合并后是 8 个词：

| 单词 | 总次数 | 结论 |
|------|--------|------|
| this | 2 | 淘汰（两句各一次） |
| apple | 2 | 淘汰（两句各一次） |
| is | 2 | 淘汰（两句各一次） |
| sweet | 1 | **不常见** |
| sour | 1 | **不常见** |

答案为 `["sweet","sour"]`（顺序任意）。示例 2 中 `apple` 的次数是 2（同一句里重复），因此即便 `s2` 里完全没有 `apple` 也不能输出。

## 4. 算法细节

1. **切分**：C++ 里不用 `istringstream`，手写一遍字符扫描即可——遇到空格就把当前累积的单词结算一次。因为题面保证「单词间只有单个空格、无前导尾随空格」，实现不需要处理连续空格与空串。
2. **哈希表选型**：`unordered_map<string,int>` / `dict`。词数最多 400，键数不超过 400。
3. **输出顺序**：题目明确「任意顺序」。但哈希表遍历顺序依赖实现，做本地比对时建议先排序再比较，否则容易误判为 WA。
4. **C++ 手动切分的小尾巴**：最后一个单词后面没有空格，循环结束后要补一次 `if (!w.empty()) cnt[w]++`。
5. **不用 set 去重**：所有词本来就只统计一次（按键遍历），重复词不会重复计入答案。

## 5. 正确性证明

**引理 1（合并计数等价）**：对任意单词 $w$，设它在 `s1`、`s2` 中的出现次数为 $c_1, c_2$，则 $w$ 是不常见单词当且仅当 $c_1 + c_2 = 1$。

**证明**：题意要求「在一句中恰好一次」且「在另一句中没有出现」，即 $(c_1,c_2) = (1,0)$ 或 $(0,1)$。这两种情况的充要条件正是 $c_1 + c_2 = 1$（次数非负整数）。反之若 $c_1 + c_2 = 1$，则恰有一个为 1、另一个为 0，满足定义。∎

**引理 2（计数完整）**：算法结束时，对每个出现过的单词 $w$，`cnt[w]` 等于它在两个句子中的总出现次数。

**证明**：把 `s1 + " " + s2` 切分得到的词序列，恰好是把两个句子的词序列首尾相接（中间多出的那个空格只起分隔作用，不产生空词）。遍历该序列并对每个词自增一次，故 `cnt[w]` 等于 $w$ 在序列中的出现次数，即 $c_1 + c_2$。∎

**定理**：算法返回的列表恰为全部不常见单词，且每个只出现一次。

**证明**：不妨设遍历 `cnt` 的键集合为 $K$，它恰为出现过的所有单词（引理 2）。对 $w \in K$，算法把它放进答案当且仅当 `cnt[w] == 1`，由引理 1 这等价于 $w$ 是不常见单词；而按键遍历保证每个单词被判定一次，故答案既无遗漏也无重复。∎

## 6. 复杂度分析

- **时间**：$O(n)$，$n = n_1 + n_2$ 为两个句子的总字符数。切分与计数各扫一遍，均为 $O(n)$；哈希表单次插入均摊 $O(1)$（单词长度 $\le 200$，可视为常数上界）；最后按键遍历 $O(|K|) \le O(n)$。
- **空间**：$O(n)$。哈希表存至多 $\min(n, 400)$ 个键，字符串总量不超过原句长度；答案列表不超过 $|K|$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<string> uncommonFromSentences(string s1, string s2) {
        unordered_map<string, int> cnt;
        string all = s1 + " " + s2;
        string w;
        for (char c : all) {
            if (c == ' ') {
                cnt[w]++;
                w.clear();
            } else {
                w += c;
            }
        }
        if (!w.empty()) cnt[w]++;
        vector<string> ans;
        for (auto& kv : cnt) {
            if (kv.second == 1) ans.push_back(kv.first);
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def uncommonFromSentences(self, s1: str, s2: str) -> list[str]:
        cnt = {}
        for w in (s1 + " " + s2).split():
            cnt[w] = cnt.get(w, 0) + 1
        return [w for w, c in cnt.items() if c == 1]
```

## 8. 边界情况与易错点

1. **同句内重复 ≠ 不常见**：示例 2 的 `apple` 只出现在 `s1`，但出现了 2 次，必须淘汰。只检查「另一个句子有没有」是本题最常见的 WA。
2. **跨句各一次也要淘汰**：示例 1 的 `this`，两句各一次，总次数 2，同样不是不常见单词。
3. **答案顺序不确定**：题目说「任意顺序」，但本地对拍/自己测试时若直接和示例输出逐位比较，会因哈希遍历顺序不同而误报。比较前先排序。
4. **手动切分的收尾**：C++ 手写扫描时，最后一个单词后面没有空格，忘记在循环外补计一次就会漏掉（Python 的 `split()` 自动处理）。
5. **空串与空格**：题面保证无前导/尾随空格、无连续空格，因此不必写「跳过空词」的防御逻辑；但若把代码迁移到不那么严格的输入，应加上 `if (w.empty()) continue` 之类的保护。
6. **大小写**：题目保证只有小写字母，不需要统一大小写。
