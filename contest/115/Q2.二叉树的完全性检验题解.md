# LeetCode 二叉树的完全性检验 题解

## 1. 题目概述

- **标题 / 题号**：二叉树的完全性检验（#958，medium）
- **链接**：https://leetcode.cn/problems/check-completeness-of-a-binary-tree/
- **来源**：LeetCode 第 115 场周赛 Q2
- **难度**：中等
- **标签**：树、广度优先搜索、二叉树

**题意**：给定一棵二叉树的根 `root`，判断它是否为**完全二叉树**。完全二叉树的定义是：

- 除最后一层外，其余各层都被节点**填满**；
- 最后一层的节点全部**尽可能靠左**（中间不允许出现空位）。

**约束**：

- 节点数在 $[1, 100]$ 内
- $1 \le Node.val \le 1000$

## 2. 示例

**示例 1**

```text
输入：root = [1,2,3,4,5,6]
输出：true
解释：        1
            /   \
           2     3
          / \   /
         4   5 6
      除最后一层外每层都是满的；最后一层的 4、5、6 从左到右连续，故是完全二叉树。
```

**示例 2**

```text
输入：root = [1,2,3,4,5,null,7]
输出：false
解释：        1
            /   \
           2     3
          / \     \
         4   5     7
      第 3 层本应依次占据 6、7 两个位置，但 6 的位置为空而 7 有节点，
      即最后一层出现了"空位在左、非空在右"，不满足"尽可能靠左"。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的做法：先求树高 $h$，再做层序遍历把每层节点收集起来：

- 除最后一层外，第 $d$ 层必须恰好有 $2^d$ 个节点；
- 最后一层的节点必须连续出现在数组**前面**，中间不能夹杂"空位"。

麻烦在于"空位"需要显式地用 `nullptr` 占位，层序数组里要区分"最右侧缺失"和"中间缺失"；而且单看"节点数落在 $[2^h, 2^{h+1}-1]$"这种计数条件是**不够**的——例如示例 2 的节点数是 6，恰好落在 $[4,7]$ 内，但它并不是完全二叉树。

### 3.2 核心观察：堆式编号必须恰好是 $\{1,\dots,n\}$

![完全二叉树 ⟺ 堆式编号恰好填满 1..n](images/wc115_q2_heap_index.svg)

给每个节点按**堆的方式**编号：根编号为 1，编号为 $i$ 的节点，其左孩子编号 $2i$、右孩子编号 $2i+1$。这个编号的几何含义是"把树放到一个无限大的满二叉树里，该节点在满二叉树中的位置"。

**核心结论**：一棵有 $n$ 个节点的二叉树是**完全二叉树**，当且仅当它的节点编号集合恰好是

$$\{1, 2, 3, \dots, n\}.$$

直观理解：满二叉树的位置按"从上到下、从左到右"编号恰好是 $1,2,3,\dots$；"完全"就是"把前 $n$ 个位置全部占满，一个不空、一个不多"。示例 2 中节点 7 的编号是 7，但整棵树只有 6 个节点，编号 6 的位置空着，编号集合为 $\{1,2,3,4,5,7\}$，缺了 6，故不是完全二叉树。

于是问题转化为：**统计节点数 $n$，并求出最大的节点编号，判断二者是否相等**。

### 3.3 算法流程

![算法流程：带空标记的层序遍历](images/wc115_q2_bfs_flow.svg)

用**带空节点的层序遍历**（BFS）实现最直观——因为"堆式编号"的顺序恰好就是"层序 + 每层从左到右"：

```text
1. 队列放入 root，ended = false（是否已经遇到过空位）
2. while 队列非空:
       取出 cur
       若 cur == null:  ended = true; continue
       若 ended 已为 true:  return false     // 空位之后又出现了真实节点
       把 cur.left、cur.right 依次入队（允许 null 入队）
3. return true
```

也就是说：**在层序序列里，空节点只允许出现在末尾**。一旦出现过一次空位，后面再冒出任何非空节点，就说明编号集合出现了"洞"。

> 💡 另一种等价写法：DFS 时传堆式编号，统计 `count` 与 `maxIndex`，最后判断 `maxIndex == count`。编号会随深度指数增长（一条 100 个节点的链，最深编号可达 $2^{99}$），必须配合"编号超过 $n$ 立即剪枝"才安全，这也是下面易错点里强调的地方。

### 3.4 示例演算

![示例 2：层序序列 1,2,3,4,5,null,7 中 null 之后仍有节点](images/wc115_q2_walkthrough.svg)

对示例 2 的 `root = [1,2,3,4,5,null,7]`，层序遍历（含空位）得到序列：

| 位置（堆编号） | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|----------------|---|---|---|---|---|---|---|
| 节点值 | 1 | 2 | 3 | 4 | 5 | **null** | 7 |

位置 6 为空、位置 7 有节点 → 编号集合 $\{1,2,3,4,5,7\} \ne \{1,\dots,6\}$，算法在读到 7 时发现 `ended == true`，立即返回 `false`。

示例 1 的序列是 `1,2,3,4,5,6,null,null,...`，空位全部在末尾，返回 `true`。

## 4. 算法细节

1. **空节点也入队**：这是"层序 = 堆编号顺序"能成立的关键；若只把非空节点入队，就无法发现中间的洞。
2. **`ended` 标记一旦置位不再回退**：表示"已经越过最后一个真实节点"，之后再遇到非空即可判定失败。
3. **空节点不必再展开**：`cur == null` 时直接 `continue`，不必把 null 的"孩子"再入队（否则队列无限膨胀）。
4. **队列规模**：最坏情况（最后一层几乎填满）队列中约有 $O(n)$ 个元素，注意 `while` 里出队后立刻入队两个孩子的顺序不能颠倒（先左后右）。
5. **BFS 顺序与编号的对应**：根在深度 0 编号 1；深度 $d$ 的节点编号区间是 $[2^d, 2^{d+1}-1]$。层序遍历按深度递增、同层从左到右，恰好就是编号递增。
6. **DFS 编号法要剪枝**：`idx > n` 时可以直接判定失败并返回（因为 `maxIndex` 只会更大），这样既避免了 $2^{99}$ 溢出，也提前结束递归。
7. **空树**：题目保证节点数 $\ge 1$；若允许空树，`root == nullptr` 应返回 `true`（空树视为完全二叉树），代码中用 `if (!root) return true;` 兜底。
8. **不需要求树高**：完全性完全由"编号是否连续"刻画，求高度反而多一次遍历。

## 5. 正确性证明

**引理 1（层序序列等于堆编号顺序）**：设树有 $n$ 个节点，把缺失的孩子用"空位"补齐后做层序遍历，则序列中第 $k$ 个位置（从 1 开始）对应的堆式编号恰为 $k$。

**证明**：对深度 $d$ 归纳。深度 0 只有一个位置，编号 1。设深度 $d$ 的位置编号依次为 $2^d, 2^d+1, \dots, 2^{d+1}-1$。深度 $d$ 中编号为 $i$ 的节点，其左孩子编号 $2i$、右孩子编号 $2i+1$；当 $i$ 从 $2^d$ 递增到 $2^{d+1}-1$ 时，$2i$ 与 $2i+1$ 恰好依次取遍 $2^{d+1}, 2^{d+1}+1, \dots, 2^{d+2}-1$。而层序遍历正是"按深度递增、同层从左到右"，故第 $k$ 个位置编号为 $k$。∎

**引理 2（完全 ⟺ 编号集合为 $\{1,\dots,n\}$）**：有 $n$ 个节点的二叉树是完全二叉树，当且仅当其非空位置的堆式编号集合恰为 $\{1,2,\dots,n\}$。

**证明**：

- **必要性**：完全二叉树的每层（除最后一层）都被填满，最后一层从左端开始连续填充。由引理 1，层序位置按 $1,2,3,\dots$ 排列，因此被占据的位置正是前 $n$ 个，编号集合为 $\{1,\dots,n\}$。
- **充分性**：若编号集合恰为 $\{1,\dots,n\}$，设树高为 $h$（深度 $0..h$）。由引理 1，被占据的是层序序列的前 $n$ 个位置：先填满深度 $0,1,\dots,h-1$ 的所有位置（共 $2^h - 1$ 个），剩余 $n - (2^h - 1)$ 个位置从深度 $h$ 的最左端开始连续排列。这正是完全二叉树的定义。∎

**引理 3（算法判据等价）**：BFS 过程中"出现过空位之后又出现非空节点"当且仅当编号集合不是 $\{1,\dots,n\}$。

**证明**：由引理 1，BFS 的访问顺序就是编号 $1,2,3,\dots$ 的顺序。

- 若编号集合 $= \{1,\dots,n\}$：前 $n$ 个位置全部非空，第 $n+1$ 个位置起全部为空，故空位只出现在末尾，不会触发失败。
- 若编号集合 $\ne \{1,\dots,n\}$：由于非空位置共有 $n$ 个，必然存在某个 $k \le n$ 使位置 $k$ 为空，同时存在某个 $j > k$ 使位置 $j$ 非空（否则非空位置就是前 $n$ 个）。访问到位置 $k$ 时置 `ended = true`，访问到位置 $j$ 时就会返回 `false`。∎

**定理**：算法返回 `true` 当且仅当 `root` 是完全二叉树。

**证明**：算法返回 `true` ⟺ 从未出现"空位后接非空"，由引理 3 等价于编号集合 $=\{1,\dots,n\}$，再由引理 2 等价于完全二叉树。∎

## 6. 复杂度分析

- **时间**：$O(n)$。每个位置（最多 $2n$ 个，含空位）入队、出队各一次，每个节点做 $O(1)$ 的判断与入队操作。
- **空间**：$O(n)$。队列中同时存在的元素不超过"某一层的位置数"，最坏为 $O(n)$；递归写法（编号法）则是 $O(h) \le O(n)$ 的栈空间。

## 7. 参考代码

### C++

```cpp
#include <queue>

using namespace std;

class Solution {
public:
    bool isCompleteTree(TreeNode* root) {
        if (!root) return true;

        queue<TreeNode*> q;
        q.push(root);
        bool ended = false;              // 是否已经遇到过空位

        while (!q.empty()) {
            TreeNode* cur = q.front();
            q.pop();

            if (!cur) {
                ended = true;            // 越过最后一个真实节点
                continue;
            }
            if (ended) return false;     // 空位之后又出现真实节点 → 有洞

            q.push(cur->left);
            q.push(cur->right);
        }
        return true;
    }
};
```

### Python

```python
from collections import deque

class Solution:
    def isCompleteTree(self, root: "TreeNode") -> bool:
        if root is None:
            return True

        q = deque([root])
        ended = False                    # 是否已经遇到过空位

        while q:
            cur = q.popleft()

            if cur is None:
                ended = True             # 越过最后一个真实节点
                continue
            if ended:
                return False             # 空位之后又出现真实节点 → 有洞

            q.append(cur.left)
            q.append(cur.right)

        return True
```

## 8. 边界情况与易错点

1. **只有左孩子**：如 `[1,2]`，层序为 `1,2,null`，空位在末尾 → `true`。
2. **只有右孩子**：如 `[1,null,2]`，层序为 `1,null,2`，空位之后仍有节点 → `false`。这是最容易被漏判的形状。
3. **单节点**：`[1]` 是完全二叉树，返回 `true`。
4. **空节点必须入队**：只把非空节点入队的 BFS 无法区分"最后一层中间缺"与"最后一层右侧缺"。
5. **DFS 编号法会溢出**：一条 100 个节点的左链，最深节点编号为 $2^{99}$，`long long` 也装不下；必须"编号超过 $n$ 立即剪枝"或改用 BFS。
6. **节点数条件不足**：不能用"节点数在 $[2^h, 2^{h+1}-1]$"代替完全性判断（示例 2 就反例）。
7. **`ended` 的作用域**：它是整趟遍历共享的状态，不能每层重置；一旦为真，后续任何非空都非法。
8. **入队顺序**：先左后右，次序反了会让"靠左"的判定失效。
