# LeetCode 删列造序 III 题解

## 1. 题目概述

- **标题 / 题号**：删列造序 III（#960，hard）
- **链接**：https://leetcode.cn/problems/delete-columns-to-make-sorted-iii/
- **来源**：LeetCode 第 115 场周赛 Q4
- **难度**：困难
- **标签**：数组、字符串、动态规划

**题意**：给定 $n$ 个等长（设长度为 $m$）的小写字母字符串 `strs`。删除一组列（对每个字符串删除相同位置的字符），要求**每一行自己**都按字典序非降排列，即对每一行 $r$

$$strs[r][c_1] \le strs[r][c_2] \le \cdots \le strs[r][c_k]$$

（$c_1 < c_2 < \cdots < c_k$ 为保留下来的列）。求**最少**需要删除多少列。

> ⚠️ 注意与同场的「删列造序 II」（#955）区分：II 要求的是**行与行之间**有序（`strs[0] <= strs[1] <= ...`），本题要求的是**每一行内部**有序。两者约束方向不同，解法也不同。

**约束**：

- $n = strs.length$，$1 \le n \le 100$
- $1 \le m = strs[i].length \le 100$，所有字符串等长
- `strs[i]` 只含小写英文字母

## 2. 示例

**示例 1**

```text
输入：strs = ["babca","bbazb"]
输出：3
解释：删除第 0、1、4 列后得到 ["bc","az"]。
      "bc" 非降（b <= c），"az" 非降（a <= z），两行都满足；删 3 列已是最少。
```

**示例 2**

```text
输入：strs = ["edcba"]
输出：4
解释：单行 "edcba" 严格递减，最长非降子序列长度只有 1，最多保留 1 列，故删 4 列。
```

**示例 3**

```text
输入：strs = ["ghi","def","abc"]
输出：0
解释：每一行本身都已经是升序（g<h<i、d<e<f、a<b<c），不需要删任何列。
```

## 3. 解题思路

### 3.1 暴力思路

列数 $m \le 100$，暴力枚举所有删除子集，每个子集检查 $n$ 行是否非降：

- 时间 $O(2^m \cdot nm)$，$m = 100$ 时完全不可行；
- 检查本身 $O(nm)$ 也偏大，即便 $m$ 很小（$\le 20$）也只有 $2^{20}$ 的规模勉强能过。

问题的结构在于：删除列是**全局的**（所有行共用同一个删除集合），而合法性又只在每行**内部**体现，必须找到一种能"增量扩展"的表达方式。

### 3.2 核心观察：保留的列序列必须"逐行两两不降" → 最长链

![保留列必须构成一条"逐行不降"的链](images/wc115_q4_chain_model.svg)

设保留下来的列下标依次为

$$c_1 < c_2 < \cdots < c_k.$$

**观察 1（只需相邻保留列）**：每行删除后要非降，即对每行 $r$ 与每个相邻保留列对 $(c_t, c_{t+1})$ 有

$$strs[r][c_t] \le strs[r][c_{t+1}].$$

因为一行字符串非降当且仅当**每对相邻字符**非降，而删除后相邻的两个字符正好来自相邻的两个保留列。

**观察 2（传递性）**：若对每行 $r$ 都有 $strs[r][c_t] \le strs[r][c_{t+1}]$ 对所有 $t$ 成立，则由 $\le$ 的传递性，任意 $p < q$ 也满足 $strs[r][c_p] \le strs[r][c_q]$。所以"相邻保留列合法"与"任意两保留列合法"等价。

于是定义列之间的偏序关系：

$$u \preceq v \iff u < v \ \text{且}\ \forall r:\ strs[r][u] \le strs[r][v].$$

**问题转化**：要求"保留集合 $K$ 合法"，等价于 $K$ 是偏序 $\preceq$ 下的一条**链**（按列下标严格递增排列，且相邻元素满足 $\preceq$）。于是

$$\text{最少删除列数} = m - (\text{最长链长度}).$$

这正是一维"最长递增子序列"（LIS）在多关键字下的推广：每个"元素"是一整列（长度为 $n$ 的字符向量），比较方式是**逐分量 $\le$**。

### 3.3 状态转移

![DP：dp[c] = 以列 c 结尾的最长合法链](images/wc115_q4_dp.svg)

设 $dp[c]$ 表示"以第 $c$ 列作为链尾时，能保留的最多列数"。转移：

$$dp[c] = 1 + \max\{\,dp[u] \ :\ u < c,\ \forall r,\ strs[r][u] \le strs[r][c]\,\},$$

若集合为空则 $dp[c] = 1$（只保留自己这一列）。答案是

$$m - \max_{0 \le c < m} dp[c].$$

时间 $O(nm^2)$：$m^2$ 对列对，每对检查 $n$ 行；$n = m = 100$ 时约 $10^6$ 次字符比较。

### 3.4 示例演算

![示例 1 的列向量与合法转移](images/wc115_q4_walkthrough.svg)

对示例 1 的 `strs = ["babca","bbazb"]`（$n=2$ 行、$m=5$ 列），把每一列看成向量：

| 列 c | 0 | 1 | 2 | 3 | 4 |
|------|---|---|---|---|---|
| 第 0 行字符 | b | a | b | c | a |
| 第 1 行字符 | b | b | a | z | b |
| 向量 | (b,b) | (a,b) | (b,a) | (c,z) | (a,b) |

合法的 $u \preceq v$（$u < v$ 且逐分量不降）：

| 转移 | 逐分量检查 | 合法？ |
|------|-----------|--------|
| 0 → 3 | b≤c, b≤z | ✓ |
| 1 → 3 | a≤c, b≤z | ✓ |
| 1 → 4 | a≤a, b≤b | ✓ |
| 2 → 3 | b≤c, a≤z | ✓ |
| 0 → 1 | b≤a 不成立 | ✗ |
| 0 → 4 | b≤a 不成立 | ✗ |
| 2 → 4 | b≤a 不成立 | ✗ |
| 3 → 4 | c≤a 不成立 | ✗ |

于是每条链最长只有 2 个列（例如 2 → 3），$dp$ 的最大值为 2，答案 $5 - 2 = 3$，与示例输出一致：保留第 2、3 列得到 `"bc"` 与 `"az"`，各删 3 列。

示例 2 单行 `"edcba"` 是严格递减，任何 $u<v$ 都不满足 `strs[0][u] <= strs[0][v]`，故 $dp$ 全为 1，答案 $5 - 1 = 4$。示例 3 的列向量逐行递增，第 0、1、2 列构成链长 3，答案 $3 - 3 = 0$。

## 4. 算法细节

1. **列的比较写成"逐行检查 + 提前 break"**：一旦某行出现 `strs[r][u] > strs[r][v]` 就判不合法，能省掉大量比较。
2. **$dp$ 初值全为 1**：每列单独保留总是合法的（长度 1 的序列必然非降）。
3. **答案用 `m - max(dp)`**：不要忘了 `max`——最后保留的列不一定是最后一列。
4. **链的顺序是下标严格递增**：内层循环 `u` 必须取 $0 \le u < c$，不能取 $u > c$；这是"列序不可打乱"的体现。
5. **`<=` 而不是 `<`**：题目允许相等（非降），同字符的列可以共存，写成严格小于会多删列（示例 3 中若某行有重复字符就会出错）。
6. **只保留列数与顺序**：不需要真的构造删除后的字符串，所有判断都在原串上进行，省一次 $O(nm)$ 的构造。
7. **$n = 1$ 时退化为 LNDS**：单行时本题就是"最长非降子序列"，$O(m^2)$ 的写法正确但可以用 $O(m\log m)$ 的贪心 + 二分优化（多行时因逐分量比较没有全序，无法直接二分）。
8. **复杂度可接受**：$n, m \le 100$ 时 $10^6$ 次比较；若 $n$ 或 $m$ 放大到 $10^3$，需要把"逐分量比较"用 bitset 或预处理加速。

## 5. 正确性证明

**引理 1（合法性 ⟺ 相邻保留列逐行非降）**：设保留列序列为 $c_1 < \cdots < c_k$，删除这些列之外的列后每行都非降，当且仅当对每个 $t \in [1, k-1]$ 与每行 $r$ 有 $strs[r][c_t] \le strs[r][c_{t+1}]$。

**证明**：

- **必要性**：删除后第 $r$ 行是 $strs[r][c_1]\,strs[r][c_2]\cdots strs[r][c_k]$，它非降意味着每个相邻对满足 $\le$，即所求。
- **充分性**：若每个相邻对都满足 $\le$，则删除后的第 $r$ 行每对相邻字符非降，故整行非降。∎

**引理 2（相邻合法 ⟹ 任意两列合法）**：在引理 1 的条件下，对任意 $p < q$ 与任意行 $r$ 有 $strs[r][c_p] \le strs[r][c_q]$。

**证明**：对固定的 $r$，由引理 1 得 $strs[r][c_p] \le strs[r][c_{p+1}] \le \cdots \le strs[r][c_q]$，由 $\le$ 在字符上的传递性即得。∎

**引理 3（链与合法保留集合一一对应）**：保留集合 $K = \{c_1 < \cdots < c_k\}$ 合法，当且仅当 $c_1 \preceq c_2 \preceq \cdots \preceq c_k$。

**证明**：$\preceq$ 的定义就是"下标递增且逐行字符 $\le$"，与引理 1 的条件逐字对应。∎

**引理 4（DP 正确性）**：按 $c$ 递增计算，$dp[c]$ 等于"以 $c$ 结尾的最长合法链的长度"。

**证明**：对 $c$ 归纳（$c$ 从小到大）。$c = 0$ 时只能取 $\{0\}$，$dp[0] = 1$ 正确。设对所有 $u < c$ 成立，则以 $c$ 结尾的链去掉 $c$ 后是一条以某个 $u < c$ 结尾的合法链（若链长为 1 则 $u$ 不存在），且必须满足 $u \preceq c$。因此

$$dp[c] = \max\Big(1,\ 1 + \max_{u<c,\ u \preceq c} dp[u]\Big),$$

与转移式一致；由归纳假设 $dp[u]$ 已是最优，故 $dp[c]$ 也是最优。∎

**定理**：算法输出的 $m - \max_c dp[c]$ 等于最少需要删除的列数。

**证明**：设最优解保留 $k^*$ 列。由引理 3，这 $k^*$ 列构成一条链，故由引理 4 存在 $c$ 使 $dp[c] \ge k^*$，于是 $m - \max dp \le m - k^*$。反之，取 $c^*$ 使 $dp[c^*]$ 最大，引理 4 给出以 $c^*$ 结尾的长度为 $dp[c^*]$ 的链，由引理 3 该链对应的保留集合合法，故 $k^* \ge \max dp$，即 $m - k^* \le m - \max dp$。两个方向合并得 $m - \max dp = m - k^*$，即最少删除数。∎

## 6. 复杂度分析

- **时间**：$O(nm^2)$。外层 $m$ 列，内层每列枚举 $O(m)$ 个前驱，每个前驱逐行检查 $O(n)$（最坏情况全行都比较完）。$n, m \le 100$ 时约 $10^6$ 次字符比较。
- **空间**：$O(m)$，只有 $dp$ 数组；不需要存储 $m \times m$ 的合法关系矩阵（若预处理该矩阵则是 $O(m^2)$ 空间、同样 $O(nm^2)$ 时间）。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <string>
#include <algorithm>

using namespace std;

class Solution {
public:
    int minDeletionSize(vector<string>& strs) {
        int n = strs.size(), m = strs[0].size();
        vector<int> dp(m, 1);              // dp[c] = 以列 c 结尾的最长合法链长度

        for (int c = 0; c < m; c++) {
            for (int u = 0; u < c; u++) {
                bool ok = true;
                for (int r = 0; r < n; r++) {
                    if (strs[r][u] > strs[r][c]) {   // 逐行检查非降
                        ok = false;
                        break;
                    }
                }
                if (ok) dp[c] = max(dp[c], dp[u] + 1);
            }
        }

        return m - *max_element(dp.begin(), dp.end());
    }
};
```

### Python

```python
class Solution:
    def minDeletionSize(self, strs: list[str]) -> int:
        n, m = len(strs), len(strs[0])
        dp = [1] * m                        # dp[c] = 以列 c 结尾的最长合法链长度

        for c in range(m):
            for u in range(c):
                if all(strs[r][u] <= strs[r][c] for r in range(n)):
                    dp[c] = max(dp[c], dp[u] + 1)

        return m - max(dp)
```

## 8. 边界情况与易错点

1. **题意方向搞反**：本题要求**每一行内部**非降，不是行与行之间（那是 #955）。若按 #955 的贪心写，示例 1 会得到错误答案。
2. **`<=` 与 `<`**：相邻保留列允许字符相等；用严格小于会漏掉"相同列"的组合，答案偏大。
3. **`max(dp)` 而不是 `dp[m-1]`**：最长链的结尾未必是最后一列。
4. **链必须下标递增**：内层只枚举 $u < c$，不能把所有满足逐分量 $\le$ 的列都拿来转移，否则等于允许打乱列序。
5. **单行特例**：$n = 1$ 时是"最长非降子序列"，$dp$ 写法仍正确；但不要误用 $O(m\log m)$ 的 LIS 二分（多行时逐分量比较不构成全序，二分不成立）。
6. **$m = 1$**：只有一列，任何单列都非降，答案 0；`max(dp)` 为 1，$1-1=0$ 正确。
7. **重复列**：两列完全相同（逐行相等）时 $u \preceq c$ 成立，两列都能保留（因为允许相等）。
8. **逐行检查要覆盖所有行**：只检查第一行是常见错误——本题所有行共用同一个删除集合，必须同时满足。
