# LeetCode 由斜杠划分区域 题解

## 1. 题目概述

- **标题 / 题号**：由斜杠划分区域（#959，medium）
- **链接**：https://leetcode.cn/problems/regions-cut-by-slashes/
- **来源**：LeetCode 第 115 场周赛 Q3
- **难度**：中等
- **标签**：深度优先搜索、广度优先搜索、并查集、图、矩阵

**题意**：给定 $n \times n$ 的网格 `grid`，每个 $1\times1$ 方块的内容是 `'/'`、`'\\'` 或空格 `' '`。这些字符把整个大方块分割成若干**由线段围成**的区域，求区域个数。区域的判定按"共边"理解：仅在角点相接触的部分算作不同区域。

**约束**：

- $n = grid.length = grid[i].length$，$1 \le n \le 30$
- `grid[i][j]` 只能是 `'/'`、`'\\'` 或 `' '`

## 2. 示例

**示例 1**

```text
输入：grid = [" /","/ "]
输出：2
解释：两条斜线首尾相连，把 2×2 的大方块切成左右两块。
```

**示例 2**

```text
输入：grid = [" /","  "]
输出：1
解释：只有一条斜线，它没有把大方块切通，整个平面仍然是 1 个区域。
```

**示例 3**

```text
输入：grid = ["/\\","\\/"]
输出：5
解释：注意反斜杠在字符串里要转义，"\/" 表示 /" 与 "\"：第一行是 "/\"、第二行是 "\/"，
     四条斜线围出 5 个区域。
```

## 3. 解题思路

### 3.1 暴力思路：把网格放大 3 倍再染色

最直观的做法是"像素级放大"：把一个 $1\times1$ 方块放大成 $3\times3$ 的小格，把 `'/'` 画成主对角线上的 3 个格子、`'\\'` 画成副对角线上的 3 个格子，其余格子是可通行的空白。然后在 $3n \times 3n$ 的网格上做 flood fill，数连通块个数。

- 时间 $O(9n^2)$，$n \le 30$ 时约 $8\times10^3$ 个格子，完全够用；
- 空间 $O(9n^2)$；
- 缺点：需要额外处理"放大后坐标映射"，而且斜线方向容易画反（`'/'` 与 `'\\'` 在屏幕坐标系里很容易搞混），实现细节多。

### 3.2 核心观察：每个方块切成 4 个三角形，用并查集合并

![每个 1×1 方块切成上、右、下、左四个三角形](images/wc115_q3_triangles.svg)

一个 $1\times1$ 方块最多被两条对角线切成 **4 个三角形**（上、右、下、左）。关键事实是：

- 方块里**至多只有一条**斜线（`'/'` 或 `'\\'` 或没有），所以"哪些三角形被斜线隔开"完全由字符决定；
- **相邻方块**共享一条完整的边，共享边两侧的两个三角形必然属于同一区域（边界上没有斜线阻隔）；
- 于是"数区域"就变成了"数连通分量"：把每个三角形当成图的一个节点，把"能无阻穿过的相邻关系"当成边，**区域个数 = 连通分量个数**。

具体的合并规则（记四个三角形为上 0、右 1、下 2、左 3）：

| 字符 | 被斜线切成的两块 | 合并操作 |
|------|------------------|----------|
| `' '`（空） | 四块连通 | union(0,1)、union(1,2)、union(2,3) |
| `'/'`（左下→右上） | {上,左} 与 {右,下} | union(0,3)、union(1,2) |
| `'\\'`（左上→右下） | {上,右} 与 {下,左} | union(0,1)、union(2,3) |

跨方块只需两组合并：第 $(i,j)$ 格的**右**三角形与第 $(i,j+1)$ 格的**左**三角形；第 $(i,j)$ 格的**下**三角形与第 $(i+1,j)$ 格的**上**三角形。

![并查集建模：同格内按字符合并，跨格按共享边合并](images/wc115_q3_union_model.svg)

> 💡 **一句话总结**：把"平面被线段切割后的区域"翻译成"三角形节点图的连通分量"，几何问题就变成并查集模板题。

### 3.3 算法流程

```text
1. 节点编号：id(i, j, t) = 4 * (i * n + j) + t，t ∈ {0:上, 1:右, 2:下, 3:左}
2. 并查集初始化 4n² 个节点，各自为根
3. for 每个格子 (i, j):
       按字符合并格内三角形
       若 j + 1 < n:  union(id(i,j,右), id(i,j+1,左))
       若 i + 1 < n:  union(id(i,j,下), id(i+1,j,上))
4. 统计不同根的个数 → 即区域数
```

### 3.4 示例演算

![示例 1 的三角形与合并过程](images/wc115_q3_walkthrough.svg)

对示例 1 的 `grid = [" /","/ "]`（2×2）共 $4\times4 = 16$ 个三角形：

| 步骤 | 操作 | 效果 |
|------|------|------|
| 格 (0,0) = `' '` | 合并 上-右-下-左 | 该格 4 个三角形并成 1 块 |
| 格 (0,1) = `'/'` | 合并 (上,左)、(右,下) | 该格分成 2 块 |
| 格 (1,0) = `'/'` | 合并 (上,左)、(右,下) | 该格分成 2 块 |
| 格 (1,1) = `' '` | 合并 4 块 | 该格并成 1 块 |
| 跨格 | 右-左、下-上 相连 | 把相邻格子的边界打通 |

两条 `'/'` 首尾相接形成一条贯通的对角线，把大方块分成左右两部分，最终并查集恰好剩 **2** 个连通分量，与示例输出一致。示例 2 只有一条斜线，它停在大方块内部而没有贯通，故所有三角形仍连成 1 块。

## 4. 算法细节

1. **编号方式**：`id = 4 * (i * n + j) + t`，共 $4n^2$ 个节点；$n = 30$ 时为 3600 个，数组开得下。
2. **格内合并顺序**：`' '` 用两条边把四个三角形串起来即可（0-1、1-2、2-3），不必写六条边。
3. **跨格只处理右、下**：每对相邻格子只合并一次，避免重复；左、上的关系会由左边/上边的格子负责。
4. **并查集实现**：`parent` 数组 + 路径压缩即可；`find` 用迭代或递归都行（深度很小）。
5. **统计分量**：遍历全部 $4n^2$ 个节点，对 `find(i)` 去重计数；用 `unordered_set` 或标记数组都可以。
6. **字符转义**：C++ 里反斜杠写作 `'\\'`，Python 里写作 `"\\"`；从测试用例读入时字符串本身就是单个反斜杠字符。
7. **点接触不算连通**：两个三角形只在格点处相碰（比如对角相邻的两个格子）不能合并——区域的边界是线段，必须"共享一段正长度的边"才算同一区域。所以跨格只合并共享边，不处理对角。
8. **不要用放大法时**：如果坚持 3 倍放大，要注意 `'/'` 在屏幕坐标（y 轴向下）中是从左下到右上，容易画成 `'\\'`。

## 5. 正确性证明

**建模**：把每个 $1\times1$ 方块用两条对角线分成 4 个三角形（退化情形也按 4 块处理，只是它们彼此连通）。设三角形集合为 $T$，构造无向图 $G = (T, E)$，其中 $(u,v) \in E$ 当且仅当 $u, v$ 共享一条**正长度**的边，且这条边上没有斜线（即二者之间无阻挡）。并查集合并的正是 $E$ 中的全部边。

**引理 1（边集完备）**：$E$ 中的边恰好由三类构成：同一格内不被斜线隔开的三角形对、相邻格共享边界处的三角形对，此外没有别的相邻方式。

**证明**：三角形的边界只可能落在三类线段上：方块的两条对角线、方块的四条边。同一格内两个三角形若共享边，该边必是某条对角线——若这条对角线被画成斜线，则两三角形被隔开（不属于 $E$）；否则它们属于同一块，按字符规则合并。不同格的两个三角形若共享边，两个方块必相邻，且共享边是它们的公共边（右/左 或 下/上），按跨格规则合并。共享边长为 1（斜线情形为对角线的半段），均为正长度。∎

**引理 2（区域内连通）**：若两个三角形 $u, v$ 在 $G$ 中连通，则它们属于同一个平面区域。

**证明**：对路径长度归纳。长度为 0 时显然。设 $u$ 与 $w$ 相邻（共享一条无阻挡的边），且 $w$ 与 $v$ 已在同一区域。$u$ 与 $w$ 的公共边上没有斜线，因此可以从 $u$ 的内部穿过这条边走到 $w$ 的内部，全程不跨越任何线段；再沿 $w$ 到 $v$ 的路径走即可。故 $u, v$ 同区域。∎

**引理 3（区域间不连通）**：若两个三角形属于同一个平面区域，则它们在 $G$ 中连通。

**证明**：同一区域内任取两点 $p, q$，存在一条不跨越任何线段的折线路径连接它们（区域是道路连通的：区域的边界由有限条线段组成，内部是开集，可用折线逼近）。把这条路径上经过的三角形按顺序记下：每当路径从三角形 $u$ 走到 $v$，它必定在某点穿过两者的公共边；若公共边上有斜线，则路径跨越了线段，矛盾，故 $(u,v) \in E$。于是得到 $G$ 中的一条路径。∎

**定理**：并查集统计出的连通分量个数等于网格被分割出的区域个数。

**证明**：由引理 2、3，"三角形同区域"与"三角形在 $G$ 中连通"互为充要条件，因此区域与 $G$ 的连通分量一一对应；并查集合并了 $E$ 的全部边（引理 1），其连通分量与 $G$ 的连通分量一致。故分量个数 = 区域个数。∎

## 6. 复杂度分析

- **时间**：$O(n^2\alpha(n^2))$。共 $4n^2$ 个节点，每个格子做常数次（至多 5 次）`union`，跨格再做 $2n(n-1)$ 次；每次 `union` 摊还 $O(\alpha)$。$n = 30$ 时约万次操作。
- **空间**：$O(n^2)$，即并查集的 `parent` 数组（$4n^2$）与统计用的标记数组。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <string>
#include <numeric>

using namespace std;

class Solution {
public:
    int regionsBySlashes(vector<string>& grid) {
        int n = grid.size();
        int total = 4 * n * n;                  // 每个格子 4 个三角形
        parent.resize(total);
        iota(parent.begin(), parent.end(), 0);

        // t: 0 上, 1 右, 2 下, 3 左
        auto id = [n](int i, int j, int t) { return 4 * (i * n + j) + t; };

        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                char c = grid[i][j];
                if (c == '/') {                 // 左下 → 右上：{上,左} 与 {右,下}
                    unite(id(i, j, 0), id(i, j, 3));
                    unite(id(i, j, 1), id(i, j, 2));
                } else if (c == '\\') {         // 左上 → 右下：{上,右} 与 {下,左}
                    unite(id(i, j, 0), id(i, j, 1));
                    unite(id(i, j, 2), id(i, j, 3));
                } else {                        // 空格：四块连通
                    unite(id(i, j, 0), id(i, j, 1));
                    unite(id(i, j, 1), id(i, j, 2));
                    unite(id(i, j, 2), id(i, j, 3));
                }
                if (j + 1 < n) unite(id(i, j, 1), id(i, j + 1, 3));   // 右 - 左
                if (i + 1 < n) unite(id(i, j, 2), id(i + 1, j, 0));   // 下 - 上
            }
        }

        vector<bool> seen(total, false);
        int regions = 0;
        for (int v = 0; v < total; v++) {
            int r = find(v);
            if (!seen[r]) {
                seen[r] = true;
                regions++;
            }
        }
        return regions;
    }

private:
    vector<int> parent;

    int find(int x) {
        while (parent[x] != x) {
            parent[x] = parent[parent[x]];      // 路径压缩
            x = parent[x];
        }
        return x;
    }

    void unite(int a, int b) {
        int ra = find(a), rb = find(b);
        if (ra != rb) parent[ra] = rb;
    }
};
```

### Python

```python
class Solution:
    def regionsBySlashes(self, grid: list[str]) -> int:
        n = len(grid)
        total = 4 * n * n
        parent = list(range(total))

        def find(x: int) -> int:
            while parent[x] != x:
                parent[x] = parent[parent[x]]      # 路径压缩
                x = parent[x]
            return x

        def unite(a: int, b: int) -> None:
            ra, rb = find(a), find(b)
            if ra != rb:
                parent[ra] = rb

        def idx(i: int, j: int, t: int) -> int:
            # t: 0 上, 1 右, 2 下, 3 左
            return 4 * (i * n + j) + t

        for i in range(n):
            for j in range(n):
                c = grid[i][j]
                if c == "/":                       # 左下 → 右上
                    unite(idx(i, j, 0), idx(i, j, 3))
                    unite(idx(i, j, 1), idx(i, j, 2))
                elif c == "\\":                    # 左上 → 右下
                    unite(idx(i, j, 0), idx(i, j, 1))
                    unite(idx(i, j, 2), idx(i, j, 3))
                else:                              # 空格：四块连通
                    unite(idx(i, j, 0), idx(i, j, 1))
                    unite(idx(i, j, 1), idx(i, j, 2))
                    unite(idx(i, j, 2), idx(i, j, 3))

                if j + 1 < n:
                    unite(idx(i, j, 1), idx(i, j + 1, 3))   # 右 - 左
                if i + 1 < n:
                    unite(idx(i, j, 2), idx(i + 1, j, 0))   # 下 - 上

        return len({find(v) for v in range(total)})
```

## 8. 边界情况与易错点

1. **`'/'` 与 `'\\'` 的合并规则不能写反**：`'/'` 连接左下与右上，切出的两块是 {上,左} 与 {右,下}；`'\\'` 则相反。写反后示例 1 会得到 1 而不是 2。
2. **字符串转义**：题面中反斜杠用 `'\\'` 表示。C++ 字符常量写 `'\\'`，Python 写 `"\\"`；直接从 `grid[i][j]` 取值则是单个字符。
3. **点接触不算同区域**：不能把对角相邻的格子也合并（比如 (i,j) 的右下角与 (i+1,j+1) 的左上角）。只合并共享**边**的三角形。
4. **跨格只合并右与下**：如果四个方向都合并会重复劳动（不影响正确性但代码冗长），只做右、下即可覆盖全部相邻关系。
5. **节点总数是 $4n^2$**：开成 $n^2$ 会越界或把不同三角形混在一起；$n = 30$ 时是 3600，注意数组大小按 $4n^2$ 申请。
6. **空格子的合并条数**：只需 3 条边把 4 个三角形串成一条链，不需要 6 条。
7. **统计分量时要去重根**：直接数 `parent[i] == i` 会把"曾经是根但后来被合并"的节点漏算/多算，必须先 `find` 再判重。
8. **注意 $n = 1$**：单个格子只可能是 1 个区域（空格）、2 个区域（一条斜线）；跨格合并不执行，代码天然正确。
