# LeetCode 设计前中后队列 题解

## 1. 题目概述

- **标题 / 题号**：设计前中后队列（#1670，medium）
- **链接**：https://leetcode.cn/problems/design-front-middle-back-queue/
- **来源**：LeetCode 第 40 场双周赛 Q3
- **难度**：中等
- **标签**：设计、队列、数组、链表、双端队列

**题意**：设计支持**前、中、后**三个位置 push 与 pop 的队列 `FrontMiddleBackQueue`：

- `pushFront(val)` / `pushMiddle(val)` / `pushBack(val)`：在对应位置插入；
- `popFront()` / `popMiddle()` / `popBack()`：删除并返回对应位置的值，**队列为空时返回 $-1$**；
- 「中间位置」的约定：**有两个中间位置时取靠前的那个**——向长度为 5 的 `[1,2,3,4,5]` 的中间 push 6 得 `[1,2,6,3,4,5]`；从长度为 6 的 `[1,2,3,4,5,6]` popMiddle 返回 3（删掉的是下标 2）。

**约束**：

- $1 \le val \le 10^9$
- 最多调用 $10^3$ 次 push / pop 操作

## 2. 示例

**示例 1**

```text
输入：
["FrontMiddleBackQueue", "pushFront", "pushBack", "pushMiddle", "pushMiddle",
 "popFront", "popMiddle", "popMiddle", "popBack", "popFront"]
[[], [1], [2], [3], [4], [], [], [], [], []]
输出：
[null, null, null, null, null, 1, 3, 4, 2, -1]
解释：
pushFront(1)  → [1]
pushBack(2)   → [1,2]
pushMiddle(3) → [1,3,2]        （长度 2，中间取下标 1 之前）
pushMiddle(4) → [1,4,3,2]      （长度 3，中间取下标 1）
popFront()    → 1，剩 [4,3,2]
popMiddle()   → 3，剩 [4,2]    （长度 3，中间下标 1）
popMiddle()   → 4，剩 [2]      （长度 2，中间取靠前 = 下标 0）
popBack()     → 2，剩 []
popFront()    → -1（空队列）
```

## 3. 解题思路

### 3.1 暴力思路

用一个动态数组（`vector` / `list`）整体模拟：`pushFront` 在头部插入、`pushMiddle` 先算 $\lfloor n/2 \rfloor$ 再插入该下标前、pop 同理。每次操作 $O(n)$，总操作数 $10^3$、单次 $O(n) \le 10^3$，总 $10^6$ 完全可过——这是本题「能过但不优雅」的下限解。要在**每个操作 $O(1)$** 的标准下做题，必须把中点变成某个数据结构的端点。

### 3.2 核心设计：两个双端队列 L / R，中点恒为 L 的尾部

![核心设计：L 与 R 两个 deque，中点在 L 尾](images/bw40_q3_two_deques.svg)

把队列切成前半 `L` 与后半 `R`，并维护不变式：

$$|L| = |R| \quad \text{或} \quad |L| = |R| + 1$$

即**长度为 $2t$ 时 $|L|=|R|=t$，长度为 $2t+1$ 时 $|L|=t+1$、$|R|=t$**。在这个不变式下：

- 队头 = `L.front()`，队尾 = `R.back()`（$|R|=0$ 时即 `L.back()`）；
- **正中间**（偶数长度取靠前者）恰好是 `L.back()`：长度 $2t$ 时中间是下标 $t-1$（`L` 的最后一个），长度 $2t+1$ 时中间是下标 $t$（同样落在 `L` 尾）。

于是六个操作全部映射为 deque 的端点操作：`pushFront` = `L.push_front`，`pushBack` = `R.push_back`，`popFront` = `L.pop_front`，`popBack` = `R.pop_back`，`pushMiddle` / `popMiddle` = `L` 的**尾部** push / pop。每次操作后调用 `rebalance()` 把尺寸拉回不变式（至多搬一个元素）。

### 3.3 算法流程：操作 + 再平衡

![再平衡：L 太长溢尾到 R，R 太长溢头到 L](images/bw40_q3_rebalance_flow.svg)

```text
rebalance():
    while |L| > |R| + 1:  R.push_front(L.pop_back())   # L 超标，尾端送 R 头
    while |L| < |R|:      L.push_back(R.pop_front())   # R 超标，头端送 L 尾

pushFront(v):  L.push_front(v); rebalance()
pushBack(v):   R.push_back(v);  rebalance()
pushMiddle(v): 若 |L| > |R| 先 R.push_front(L.pop_back())   # 让出中点
               L.push_back(v)                              # v 落在正中
popFront():    空则 -1；v = L.pop_front(); rebalance(); 返回 v
popMiddle():   空则 -1；v = L.pop_back();  rebalance(); 返回 v
popBack():     空则 -1；若 R 空（只有 L 一个元素）v = L.pop_back()
               否则 v = R.pop_back(); rebalance(); 返回 v
```

`pushMiddle` 的预处理（先把 `L` 让到不超过 `R`）保证新元素 push 到 `L` 尾后恰好占据正中。分两种情况：操作前 $|L|=t+1,\ |R|=t$（奇长度），先搬 `L` 尾到 `R` 头得 $|L|=|R|=t$，再 `L.push_back(v)` 得 $|L|=t+1$、总长 $2t+1$，$v$ 落在下标 $t$，正是唯一中间；操作前 $|L|=|R|=t$（偶长度），直接 `L.push_back(v)` 得 $|L|=t+1$、总长 $2t+1$，$v$ 同样落在下标 $t$。两种情况殊途同归。`popBack` 的特例对应总长为 1 时元素在 `L` 里、`R` 为空。

### 3.4 示例演算

![官方示例回放：每步操作后的形态](images/bw40_q3_walkthrough.svg)

官方调用序列下：`pushFront(1)` 得 $L=[1],R=[]$；`pushBack(2)` 得 $L=[1],R=[2]$；`pushMiddle(3)`：$|L|=|R|$ 不搬运，`L.push_back(3)` 得 $L=[1,3],R=[2]$（队列 `[1,3,2]`）；`pushMiddle(4)`：$|L|>|R|$ 先搬 `L` 尾 3 到 `R` 头得 $L=[1],R=[3,2]$，再 `L.push_back(4)` 得 $L=[1,4],R=[3,2]$（队列 `[1,4,3,2]`）。弹出序列 $1,3,4,2,-1$ 与官方输出逐项一致。

## 4. 算法细节

1. **不变式是全部正确性的锚**：所有「中间」语义都由「$|L| \in \{|R|, |R|+1\}$ 且中点 = `L.back()`」推出。写任何操作前先把这句话写在注释里。
2. **pushMiddle 的让位分支**：与其它操作「先做后平衡」不同，它必须「先让位再插入」。反例推演：$|L|=t+1,\ |R|=t$ 时若直接 `L.push_back(v)` 再 rebalance，会得到 $|L|=t+2$，rebalance 把 `L` 尾（正是刚插入的 v）搬到 `R` 头——v 落到后半段开头，位置错了一格。所以让位必须发生在插入之前。
3. **popBack 的空 R 特判**：总长 1 时元素在 `L`；若不判而直接 `R.pop_back()` 会崩。popFront/popMiddle 无此问题（`L` 非空等价于队列非空）。
4. **空判统一**：`L` 与 `R` **同时**为空才算空队列；只判 `L` 空在「`L` 空、`R` 非空」的中间态下会误报（其实按不变式 `|L| ≥ |R|`，`L` 空必 `R` 空，但显式双判更防御）。
5. **语言选型**：C++ `std::deque` 与 Python `collections.deque` 的端点操作均摊 $O(1)$；Python 直接用 `list` 的 `pop(0)`/`insert` 是 $O(n)$，虽然本题数据规模能过，但既然是设计题就按标准写。
6. **`popMiddle` 偶数取靠前**：长度 $2t$ 时中点下标 $t-1$ 恰为 `L.back()`（$|L|=t$），无需在代码里做奇偶分支——不变式已把它消化掉。

## 5. 正确性证明

**引理 1（中点位置）**：若不变式 $|L| \in \{|R|, |R|+1\}$ 成立，记总长 $N = |L|+|R|$，则题意定义的「中间位置」（$N$ 偶时下标 $N/2 - 1$，$N$ 奇时下标 $(N-1)/2$）恰为 `L` 的最后一个元素。

**证明**：$N = 2t$ 时 $|L| = t$（不变式只允许 $|L|=|R|=t$），`L` 占下标 $0..t-1$，其最后元素在下标 $t-1 = N/2 - 1$ ✓。$N = 2t+1$ 时不变式强制 $|L| = t+1$、$|R| = t$（因 $|L| \ge |R|$ 且和为奇数，只能 $|L| = |R|+1$），`L` 占下标 $0..t$，最后元素在下标 $t = (N-1)/2$ ✓。∎

**引理 2（再平衡的终止与保持）**：`rebalance()` 在至多搬动一个元素后终止，且终止时不变式成立。

**证明**：每次搬动使 $|L|-|R|$ 减少 2（`L`→`R` 搬运）或增加 2（`R`→`L` 搬运），故至多 $\lceil \cdot \rceil$ 次后 $|L|-|R| \in \{0, 1\}$，两个 `while` 条件同时失效，终止。终止时 $|L| \le |R|+1$ 且 $|L| \ge |R|$，即 $|L| \in \{|R|, |R|+1\}$，不变式保持。搬运总数：任何单个操作至多使 $|L|-|R|$ 偏离合法区间 2（push/pop 改变一侧尺寸 1，pushMiddle 的让位又先反向搬一个），故至多搬 1 个元素，`rebalance` 是 $O(1)$。∎

**定理**：六个操作均以 $O(1)$ 摊还时间正确实现题意语义。

**证明**：语义：`pushFront` 改 `L` 头即队列头（`L` 占前缀，引理 1 同理 `L.front()` 恒为下标 0）✓；`pushBack` 改 `R` 尾即队列尾（`R` 占后缀，`R.back()` 恒为下标 $N-1$；`R` 空时队列只有一个元素且即 `L.back()`，`popBack` 特判覆盖）✓；`pushMiddle` / `popMiddle` 作用在 `L` 尾，由引理 1 恰为题意中点（含偶数取靠前）✓。时间：每个操作常数次 deque 端点操作 + 至多一次搬运（引理 2），deque 端点操作摊还 $O(1)$，故总计 $O(1)$。∎

## 6. 复杂度分析

- **时间**：每个操作 $O(1)$ 摊还。操作本体是一次 deque 端点 push/pop；`rebalance` 至多搬一个元素（引理 2）。总计 $10^3$ 次操作即 $O(10^3)$。
- **空间**：$O(N)$，$N$ 为当前队列长度（两个 deque 存住全部元素，每个元素恰存一份）。

## 7. 参考代码

### C++

```cpp
class FrontMiddleBackQueue {
    deque<int> L, R;                       // 不变式：|L| == |R| 或 |L| == |R|+1
    void rebalance() {
        while (L.size() > R.size() + 1) { R.push_front(L.back()); L.pop_back(); }
        while (L.size() < R.size())       { L.push_back(R.front()); R.pop_front(); }
    }
public:
    FrontMiddleBackQueue() {}

    void pushFront(int val) { L.push_front(val); rebalance(); }

    void pushMiddle(int val) {
        if (L.size() > R.size()) {          // 先让位，新元素才能落在正中
            R.push_front(L.back());
            L.pop_back();
        }
        L.push_back(val);
        rebalance();
    }

    void pushBack(int val) { R.push_back(val); rebalance(); }

    int popFront() {
        if (L.empty() && R.empty()) return -1;
        int v = L.front();
        L.pop_front();
        rebalance();
        return v;
    }

    int popMiddle() {
        if (L.empty() && R.empty()) return -1;
        int v = L.back();                   // 中点恒为 L 尾（偶数长度取靠前者）
        L.pop_back();
        rebalance();
        return v;
    }

    int popBack() {
        if (L.empty() && R.empty()) return -1;
        if (R.empty()) {                    // 只剩 L 中一个元素
            int v = L.back();
            L.pop_back();
            return v;
        }
        int v = R.back();
        R.pop_back();
        rebalance();
        return v;
    }
};
```

### Python

```python
from collections import deque

class FrontMiddleBackQueue:
    def __init__(self):
        self.L = deque()          # 不变式：len(L) == len(R) 或 len(R)+1
        self.R = deque()

    def _rebalance(self):
        while len(self.L) > len(self.R) + 1:
            self.R.appendleft(self.L.pop())
        while len(self.L) < len(self.R):
            self.L.append(self.R.popleft())

    def pushFront(self, val: int) -> None:
        self.L.appendleft(val)
        self._rebalance()

    def pushMiddle(self, val: int) -> None:
        if len(self.L) > len(self.R):       # 先让位，新元素才能落在正中
            self.R.appendleft(self.L.pop())
        self.L.append(val)
        self._rebalance()

    def pushBack(self, val: int) -> None:
        self.R.append(val)
        self._rebalance()

    def popFront(self) -> int:
        if not self.L and not self.R:
            return -1
        v = self.L.popleft()
        self._rebalance()
        return v

    def popMiddle(self) -> int:
        if not self.L and not self.R:
            return -1
        v = self.L.pop()                    # 中点恒为 L 尾（偶数长度取靠前者）
        self._rebalance()
        return v

    def popBack(self) -> int:
        if not self.L and not self.R:
            return -1
        if not self.R:                      # 只剩 L 中一个元素
            return self.L.pop()
        v = self.R.pop()
        self._rebalance()
        return v
```

> 💡 两份代码均通过官方调用序列回放（弹出序列 `1,3,4,2,-1`），另与「`list` 直接按下标模拟」的参考实现在 500 组（C++）/ 400 组（Python）随机操作流（每组 80 次混合操作）上对拍每个返回值，`mismatch = 0`；题面两条中点示例（`[1,2,3,4,5]` push 6 → `[1,2,6,3,4,5]`；`[1,2,3,4,5,6]` popMiddle → 3）也单独验证通过。

## 8. 边界情况与易错点

1. **空队列 pop 返回 −1**：三个 pop 都要判；判据是 `L`、`R` **同时**为空。
2. **总长为 1 时的 popBack**：元素在 `L`、`R` 为空，特判分支返回 `L.back()`；漏判会越界。
3. **pushMiddle 忘记让位**：直接 push 再 rebalance 的话，新元素会被 rebalance 搬去 `R` 头，位置错一格——本题最高频的 WA 点（见 §4.2 的推演）。
4. **奇偶长度中点语义**：偶数长度取靠前中间（下标 $N/2-1$），奇数取正中（下标 $(N-1)/2$）；两者恰好统一为 `L.back()`，但若不变式被破坏（例如 `|L| = |R| - 1`），中点就会漂到 `R` 里，popMiddle 立刻错。每次操作后务必 rebalance。
5. **`popFront` 后 `L` 变空**：`rebalance` 会把 `R` 头搬过来（若 `R` 非空），不变式自动恢复；不要在 pop 里手写搬运逻辑，统一交给 `rebalance`。
6. **值域**：$val \le 10^9$，`int` 安全；返回值用 `int` 即可。
