# LeetCode 最大重复子字符串 题解

## 1. 题目概述

- **标题 / 题号**：最大重复子字符串（#1668，easy）
- **链接**：https://leetcode.cn/problems/maximum-repeating-substring/
- **来源**：LeetCode 第 40 场双周赛 Q1
- **难度**：简单
- **标签**：字符串、动态规划、字符串匹配

**题意**：定义 `word` 的**重复值** $k$ 为最大的正整数，使得 `word` 连续重复 $k$ 次形成的字符串 `word * k` 是 `sequence` 的子串；若 `word` 本身都不是 `sequence` 的子串，重复值为 $0$。给定 `sequence` 与 `word`，返回最大重复值。

**约束**：

- $1 \le sequence.length \le 100$
- $1 \le word.length \le 100$
- 两者都只含小写英文字母

## 2. 示例

**示例 1**

```text
输入：sequence = "ababc", word = "ab"
输出：2
解释："abab" 是 "ababc" 的子串（前 4 个字符），而 "ababab" 放不下。
```

**示例 2**

```text
输入：sequence = "ababc", word = "ba"
输出：1
解释："ba" 是子串，"baba" 不是。
```

**示例 3**

```text
输入：sequence = "ababc", word = "ac"
输出：0
解释："ac" 根本不是子串。
```

## 3. 解题思路

### 3.1 暴力思路

从 $k=1$ 起逐个构造 `word * k`，用内置的子串查找（`find` / `in`）判断是否出现；首次失败即停。正确性依赖单调性：若 `word * (k+1)` 出现，则其前缀 `word * k` 也出现。总时间 $O\big(\frac{n}{m} \cdot n \cdot m\big)$，$n \le 100$ 下最多几百次字符比较，稳过。缺点是每次都从头搜，没有利用「重复段首尾相接」的结构——这正是 DP 优化点。

### 3.2 核心观察：以「结尾对齐」定义 DP，段与段天然拼接

![核心观察：f[i] = 以 i 结尾的重复段计数](images/bw40_q1_dp_model.svg)

设 $f[i]$ 为**最大的 $k$**，使得 `word * k` 恰好作为 `sequence` 的子串**结束于前缀长度 $i$ 处**（即覆盖区间 $[i-km, i-1]$）。那么：

- 若 `sequence[i-m .. i-1] == word`（结尾 $m$ 个字符与 word 完全一致），则 $f[i] = f[i-m] + 1$——把一段以 $i-m$ 结尾的重复段接上这一份 word；
- 否则 $f[i] = 0$。

答案为 $\max_i f[i]$。转移只依赖 $i-m$，每处比较 $O(m)$，总复杂度 $O(nm)$，无需任何子串搜索库函数。为什么「结尾对齐」可行而「开头对齐」不灵？因为重复段的右端点唯一确定了它与前一段的拼接关系（前一段右端点 = 本段左端点 $-1$），而左端点相同的重叠匹配可能有多个，需要额外处理。

### 3.3 算法流程

```text
1. n = len(sequence), m = len(word)；若 m > n 返回 0
2. f = [0] * (n+1)，ans = 0
3. 对 i = m..n：
       若 sequence[i-m : i] == word：
           f[i] = f[i-m] + 1
           ans = max(ans, f[i])
4. 返回 ans
```

Python 的切片比较 / C++ 的 `compare` 一行完成长度为 $m$ 的比对。

### 3.4 示例演算

![两种解法对照：逐 k 试探与结尾对齐 DP](images/bw40_q1_two_approaches.svg)

两种解法的对照与联系如上图：暴力「逐 $k$ 试探」依赖同一单调性（`word * k` 出现 ⇒ `word * (k-1)` 出现，从 $1$ 递增、首次失败即停）；DP「结尾对齐」则把每段的匹配结果沿下标链 $i \to i-m$ 传递，避免反复从头搜索。

![示例演算：k 从 1 递增试探](images/bw40_q1_walkthrough.svg)

以 `sequence = "ababc"`、`word = "ab"`（$m=2$）为例：$f[2]=1$（`ab` 结尾对齐），$f[3]=0$（`ba` ≠ `ab`），$f[4]=f[2]+1=2$（`ab`，拼上前段成 `abab`），$f[5]=0$（`bc` ≠ `ab`）。最大值 $2$，与示例一致。`word = "ba"` 时只有 $f[3]=1$，其余为 0，答案 1；`word = "ac"` 时所有比较失败，答案 0。

## 4. 算法细节

1. **下标语义**：$f$ 的下标是**前缀长度**（$1..n$），区间 $[i-m, i-1]$ 是「以 $i-1$ 结尾的 $m$ 个字符」，切片写 `sequence[i-m:i]` 不易错。
2. **比较必须整段相等**：不能只比首字符或哈希前缀——`word` 内部可能有周期（如 `word = "aa"`），部分匹配会虚增计数。
3. **单调性是暴力解的正确性来源，也是 DP 的退化保险**：$f$ 的转移链 $i \to i-m \to i-2m \to \dots$ 天然保证「$f[i]=k$ ⟹ 沿途每个 $jm$ 处 $f \ge j$」，即最大值一定能在某个「重复段右端点」处取到，无需再回头补查。
4. **短串保护**：$m > n$ 时循环体一次都不进，返回 0；`f` 数组长度 $n+1$ 足够（访问 $i-m \ge 0$）。
5. **想再快**：把「比较 $m$ 个字符」换成滚动哈希或 Z 函数可以到 $O(n)$，但 $n \le 100$ 下纯属屠龙刀；倒是把两者拼接后跑 KMP 是训练价值更高的写法（见延伸思考）。

## 5. 正确性证明

**引理 1（重复值的存在性单调）**：若 `word * (k+1)` 是 `sequence` 的子串，则 `word * k` 也是。

**证明**：`word * (k+1)` 在 `sequence` 中某处出现，设起始下标 $s$，则 `sequence[s .. s+km-1] = word * k`，即 `word * k` 也出现在 `sequence` 中（同一位置的前缀）。∎

**引理 2（DP 与出现性的等价）**：$f[i] \ge k$ 当且仅当 `word * k` 作为子串**恰好结束于前缀长度 $i$** 处。

**证明**：对 $k$ 归纳。$k=0$ 平凡（任何 $i$ 处空串都「结束」）。设对 $k$ 成立。若 $f[i] \ge k+1$：由转移定义，`sequence[i-m..i-1] == word` 且 $f[i-m] \ge k$，由归纳假设 `word * k` 结束于 $i-m$ 处，即 `sequence[i-(k+1)m .. i-m-1] = word * k`，再拼上 `sequence[i-m..i-1] = word` 得 `sequence[i-(k+1)m .. i-1] = word * (k+1)`，即 `word*(k+1)` 结束于 $i$。反之若 `word * (k+1)` 结束于 $i$，即 `sequence[i-(k+1)m .. i-1]` 与 `word*(k+1)` 逐位相等，则其末段 `sequence[i-m..i-1] = word`，且前缀段是结束于 $i-m$ 的 `word * k`，由归纳假设 $f[i-m] \ge k$，故转移给出 $f[i] \ge k+1$。∎

**定理**：$\max_{0 \le i \le n} f[i]$ 等于 `word` 的最大重复值。

**证明**：若答案为 $k \ge 1$，则 `word * k` 在某处出现，设其结束于前缀长度 $i$，由引理 2 得 $f[i] \ge k$，故 $\max f \ge k$；另一方面 $f[i] = t$ 时由引理 2 `word * t` 结束于 $i$，即 $t$ 是合法重复值，$t \le k$，故 $\max f \le k$。两者相等。$k=0$（word 不是子串）时由引理 2 的逆否，所有 $f[i]=0$，算法返回 0。∎

## 6. 复杂度分析

- **时间**：$O(nm)$。外层 $n-m+1$ 次，每次切片/`compare` 比较 $m$ 个字符；$n, m \le 100$，至多 $10^4$ 次字符比较。（暴力逐 $k$ 试探为 $O(\frac{n}{m} \cdot nm)$，同量级常数更大。）
- **空间**：$O(n)$，即 `f` 数组（比较用切片在 Python 中临时 $O(m)$）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maxRepeating(string sequence, string word) {
        int n = sequence.size(), m = word.size();
        if (m > n) return 0;
        vector<int> f(n + 1, 0);               // f[i]：以 i 结尾的最大重复次数
        int ans = 0;
        for (int i = m; i <= n; ++i) {
            if (sequence.compare(i - m, m, word) == 0) {
                f[i] = f[i - m] + 1;
                ans = max(ans, f[i]);
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maxRepeating(self, sequence: str, word: str) -> int:
        n, m = len(sequence), len(word)
        if m > n:
            return 0
        f = [0] * (n + 1)                      # f[i]：以 i 结尾的最大重复次数
        ans = 0
        for i in range(m, n + 1):
            if sequence[i - m:i] == word:
                f[i] = f[i - m] + 1
                ans = max(ans, f[i])
        return ans
```

> 💡 两份代码均通过官方三个示例，并与「逐 $k$ 构造整串再查找」的暴力在 4000 组（C++）/ 3000 组（Python）随机二进制串（$|sequence| \le 12$，$|word| \le 6$）上对拍，`mismatch = 0`。

## 8. 边界情况与易错点

1. **word 长于 sequence**：`"a"` 与 `"abc"` 这类直接 0；循环不进入，天然覆盖，但显式 `if m > n: return 0` 更能表达意图。
2. **word 内部有周期**：`word = "aa"`、`sequence = "aaaaa"` 时答案应为 2（`"aaaa"` 出现，`"aaaaaa"` 放不下）——$f$ 沿 $i, i-m, i-2m$ 链累加正确给出；若错用「数 word 出现次数」的贪心（如 `sequence.count`）会得 2 恰好对，但换 `word = "aba"`、`sequence = "ababa"` 时 count 是 1 而正确答案是 1，再换 `word="ab"`、`sequence="abab"` 时 count=2、答案 2——看似都对，可一旦 `word` 出现位置**不首尾相接**（`word="ab"`，`sequence="abxab"`，count=2 但答案 1）就露馅：计数 ≠ 连续重复。
3. **重叠匹配**：`word = "aa"`、`sequence = "aaa"` 答案 1（`"aa"` 出现，`"aaaa"` 不出现），DP 在 $f[2]=1, f[3]=1$ 后取 max 得 1，正确；别想当然认为字符多重复值就大。
4. **空串不在输入域**：约束保证两者非空，无需处理。
5. **返回的是次数不是长度**：别把 $k \cdot m$ 当答案返回。
