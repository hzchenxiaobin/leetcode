# LeetCode 奇怪的打印机 II 题解

## 1. 题目概述

- **标题 / 题号**：奇怪的打印机 II（#1591，hard）
- **链接**：https://leetcode.cn/problems/strange-printer-ii/
- **来源**：LeetCode 第 35 场双周赛 Q4
- **难度**：困难
- **标签**：图、拓扑排序、数组、有向无环图、矩阵

**题意**：一台奇怪的打印机按如下规则工作：

1. 每次操作用一个**同色矩形**打印，矩形覆盖的格子会变成该颜色（覆盖原有颜色）；
2. **每种颜色最多使用一次**（同一颜色不能打印两遍）。

给定目标矩阵 `targetGrid`（$m \times n$，颜色编号 $1 \sim 60$），判断是否存在一组合法操作序列恰好打印出 `targetGrid`。

**约束**：

- $1 \le m, n \le 60$
- $1 \le targetGrid[row][col] \le 60$

## 2. 示例

**示例 1**

```text
输入：targetGrid = [[1,1,1,1],[1,2,2,1],[1,2,2,1],[1,1,1,1]]
输出：true
解释：先整面打印 1，再在中间打印 2 的矩形即可。
```

**示例 2**

```text
输入：targetGrid = [[1,1,1,1],[1,1,3,3],[1,1,3,4],[5,5,1,4]]
输出：true
```

**示例 3**

```text
输入：targetGrid = [[1,2,1],[2,1,2],[1,2,1]]
输出：false
解释：不存在可行的打印顺序——1 与 2 互相包含对方颜色，谁都必须后于谁。
```

**示例 4**

```text
输入：targetGrid = [[1,1,1],[3,1,3]]
输出：false
解释：1 的边框矩形覆盖了 3，3 的边框矩形也覆盖了 1，形成依赖环。
```

## 3. 解题思路

### 3.1 暴力思路

枚举「颜色使用顺序」与「每次打印的矩形」：$60!$ 种顺序、每种颜色至多 $60^4$ 级别的矩形选择——完全不可行。即使做记忆化搜索（状态 = 当前网格 + 已用颜色），状态数也是 $61^{mn}$ 级别。必须利用**矩形覆盖的几何结构**把「矩形选择」这一维彻底消掉。

### 3.2 核心观察：每种颜色的打印矩形必然覆盖它的「边框矩形」——覆盖即依赖

![核心观察：颜色边框矩形与覆盖依赖](images/bw35_q4_bbox_dependency.svg)

对每种颜色 $c$，设 $B(c)$ 为它所占据格子的**边框矩形**（四方向包围盒）。关键事实：

> 打印颜色 $c$ 的那个矩形必须**覆盖 $B(c)$ 的每个格子**——因为 $c$ 色的每个格子最终都要变成 $c$，而 $c$ 只被打印一次，所有 $c$ 色格子必须同一次操作被覆盖。

于是**矩形选择被固定到了最小**：我们只需考虑每个颜色打印 $B(c)$ 这个矩形（更大的矩形可以缩小到 $B(c)$ 而不损失任何 $c$ 色格子；多覆盖的部分本就要被后续打印覆盖回去）。剩下的问题只是**顺序**。什么时候 $b$ 必须先于 $a$ 打印？

> 若格子 $(i,j) \in B(b)$ 且 $targetGrid[i][j] = a \ne b$：打印 $b$ 时该格被涂成 $b$，但它最终是 $a$ 色，而 $a$ 只打印一次，故 **$a$ 的打印必须晚于 $b$**。记依赖边 $b \to a$（"$b$ before $a$"）。

**结论：`targetGrid` 可打印 $\iff$ 上述依赖图无环**。有环则顺序要求自相矛盾；无环则按拓扑序打印每个颜色的 $B(c)$ 就能精确复现网格。

### 3.3 算法流程：求边框 → 建依赖边 → 拓扑排序判环

![算法流程：边框矩形建图与 Kahn 拓扑排序](images/bw35_q4_topo_flow.svg)

```text
1. 扫描网格，求每种颜色 c 的 minR/maxR/minC/maxC（边框 B(c)）
2. 对每种出现过的颜色 b，扫描 B(b) 内每个格子 (i, j)：
       a = targetGrid[i][j]
       若 a != b：加边 b -> a（去重）
3. 以出现过的颜色为节点做 Kahn 拓扑排序：
       入度为 0 的颜色入队；弹出 b 时将 b 指向的 a 的入度减 1
4. 若所有出现过的颜色都能出队（无环）返回 true，否则 false
```

### 3.4 示例演算

![示例演算：示例 3 与示例 4 的依赖环](images/bw35_q4_dep_graph.svg)

**示例 1**：$B(1)$ 是全网格（1 色占据四周），$B(2) = [1,2] \times [1,2]$。$B(1)$ 内含 2 色格 → 边 $1 \to 2$；$B(2)$ 内只有 2 色 → 无边。依赖图 $1 \to 2$ 无环 → `true`。打印顺序：先 1 后 2。

**示例 3**（棋盘）：$B(1)$ 与 $B(2)$ 都是整个 $3 \times 3$。$B(1)$ 内有 2 色格 → $1 \to 2$；$B(2)$ 内有 1 色格 → $2 \to 1$。环 $1 \rightleftarrows 2$ → `false` ✓。

**示例 4**：$B(1)$ = 全网格（含 $(1,0),(1,2)$ 的 3 色）→ $1 \to 3$；$B(3) = [1,1] \times [0,2]$，内含 $(1,1)$ 的 1 色 → $3 \to 1$。环 → `false` ✓。

**示例 2**：颜色 1 的边框覆盖全网格 → $1 \to 3, 1 \to 4, 1 \to 5$；$B(3) = [1,2]\times[2,3]$ 含 $(2,3)$ 的 4 色 → $3 \to 4$。图 $1 \to \{3,4,5\}$、$3 \to 4$ 无环 → `true`。一个可行打印序：$1, 5, 3, 4$（逐个覆盖各自的边框矩形即得目标网格）。

## 4. 算法细节

1. **边框矩形 $O(mn)$ 一次扫描**：对每个格子更新所在颜色的四方向极值，未出现的颜色以哨兵值标记（如 `maxR = -1`）。
2. **建边只扫边框内部**：颜色 $b$ 的边框面积 $\le m \times n$，全部颜色合计 $\le 60 \times 60 \times 60 = 216000$ 次格子访问，量级极小。
3. **去重**：同一对 $(b, a)$ 可能被多个格子触发，需去重后再统计入度。颜色 $\le 60$，用 `unsigned long long` 位掩码存每个颜色的邻接集（第 $a-1$ 位为 1 表示有边 $b \to a$）最省事，去重与入度统计一并完成。
4. **未出现的颜色不打印**：它不占格子、无边、不入队。用「出现过的颜色数」作为拓扑排序的期望出队数。
5. **Kahn 判环**：`done == present` 则无环；否则剩下的节点都在环上。节点 $\le 60$，扫描位掩码 $O(60^2)$ 足够。
6. **复杂度合计**：$O(C \cdot m \cdot n + C^2)$，其中 $C \le 60$。

## 5. 正确性证明

**引理 1（覆盖性）**：任何合法打印序列中，打印颜色 $c$ 的矩形 $R_c \supseteq B(c)$。

**证明**：$c$ 的每个最终格子 $(i,j)$ 都必须被某次操作染成 $c$；由于「同一颜色只能使用一次」，这次操作就是打印 $c$ 的那次，故 $(i,j) \in R_c$。于是 $R_c$ 包含全部 $c$ 色格子，而 $B(c)$ 是这些格子的包围盒，$R_c$ 是矩形，故 $R_c \supseteq B(c)$。∎

**引理 2（依赖边的必要性）**：若 $(i,j) \in B(b)$ 且 $targetGrid[i][j] = a \ne b$，则打印 $b$ 的时刻严格早于打印 $a$ 的时刻。

**证明**：由引理 1，打印 $b$ 时 $(i,j)$ 被涂成 $b$ 色。而 $(i,j)$ 的最终颜色是 $a \ne b$，颜色只会被「之后的打印」覆盖改变，故存在打印 $a$ 的操作发生在打印 $b$ 之后（$a$ 在最终网格出现，故 $a$ 确实被打印过）。∎

**定理（主判定）**：`targetGrid` 可被打印 $\iff$ 依赖图 $G$（节点为出现过的颜色，边 $b \to a$ 如引理 2）无环。

**证明**：

（$\Rightarrow$ 必要性）设存在合法序列。对 $G$ 中每条边 $b \to a$，由引理 2，$b$ 的打印时刻早于 $a$ 的打印时刻，即 $G$ 的所有边都与「打印时刻」这个全序一致。若 $G$ 含环 $b_1 \to b_2 \to \dots \to b_k \to b_1$，则时刻 $(b_1) < (b_2) < \dots < (b_k) < (b_1)$，矛盾。故 $G$ 无环。

（$\Leftarrow$ 充分性）设 $G$ 无环，取 $G$ 的任一拓扑序 $c_1, c_2, \dots, c_t$，按此顺序、每次打印 $B(c_k)$ 这个矩形。断言最终网格恰为 `targetGrid`。考察任意格子 $(i,j)$，设 $targetGrid[i][j] = a$：

- $a$ 自己的打印覆盖它：$(i,j)$ 是 $a$ 色格子 $\Rightarrow (i,j) \in B(a)$，第 $a$ 次打印（在拓扑序的某位置）把它染成 $a$。
- 对任何其他打印了覆盖 $(i,j)$ 的颜色 $b \ne a$：$b$ 打印的矩形是 $B(b)$，$(i,j) \in B(b)$ 且该格最终色 $a \ne b$，由建边规则存在依赖边 $b \to a$，拓扑序保证 $b$ 在 $a$ 之前打印。
- 因此**最后一个覆盖 $(i,j)$ 的打印是 $a$ 自己**，此后没有任何操作再触碰该格。最终颜色恰为 $a$。

每个格子都得到目标颜色，且每个颜色恰好使用一次（只打印出现过的颜色），规则全部满足。∎

**推论（构造）**：拓扑序即是一组合法打印方案——打印每个出现颜色的边框矩形。

**证明**：见定理充分性部分的构造。∎

## 6. 复杂度分析

- **时间**：$O(C \cdot m \cdot n + C^2)$。求边框 $O(mn)$；建边扫描所有颜色的边框内部 $\le C$ 个 $m \times n$ 矩形；拓扑排序节点 $\le C$、位掩码邻接扫描 $O(C^2)$。代入 $C, m, n \le 60$ 至多约 $2 \times 10^5$ 次基本操作。
- **空间**：$O(C)$ 级别的边框数组、位掩码邻接与入度数组（$C \le 60$），加上 $O(1)$ 的队列，忽略不计。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool isPrintable(vector<vector<int>>& targetGrid) {
        const int C = 60;
        int m = (int)targetGrid.size(), n = (int)targetGrid[0].size();
        int minR[C + 1], maxR[C + 1], minC[C + 1], maxC[C + 1];
        for (int c = 1; c <= C; ++c) {             // 哨兵值：未出现颜色
            minR[c] = m; minC[c] = n; maxR[c] = -1; maxC[c] = -1;
        }
        for (int i = 0; i < m; ++i)
            for (int j = 0; j < n; ++j) {          // 每种颜色的边框矩形
                int c = targetGrid[i][j];
                if (i < minR[c]) minR[c] = i;
                if (i > maxR[c]) maxR[c] = i;
                if (j < minC[c]) minC[c] = j;
                if (j > maxC[c]) maxC[c] = j;
            }
        unsigned long long dep[C + 1] = {0};       // dep[b] 的第 a-1 位：边 b -> a
        int indeg[C + 1] = {0};
        for (int b = 1; b <= C; ++b) {
            if (maxR[b] < 0) continue;             // 颜色 b 未出现，不打印
            for (int i = minR[b]; i <= maxR[b]; ++i)
                for (int j = minC[b]; j <= maxC[b]; ++j) {
                    int a = targetGrid[i][j];
                    if (a == b) continue;
                    if (!((dep[b] >> (a - 1)) & 1ULL)) {   // 去重后累计入度
                        dep[b] |= 1ULL << (a - 1);
                        indeg[a]++;
                    }
                }
        }
        queue<int> q;
        int done = 0, present = 0;                 // Kahn 拓扑排序
        for (int c = 1; c <= C; ++c)
            if (maxR[c] >= 0) { ++present; if (indeg[c] == 0) q.push(c); }
        while (!q.empty()) {
            int b = q.front(); q.pop(); ++done;
            for (int a = 1; a <= C; ++a)
                if ((dep[b] >> (a - 1)) & 1ULL)
                    if (--indeg[a] == 0) q.push(a);
        }
        return done == present;                    // 全部出队 <=> 依赖图无环
    }
};
```

### Python

```python
class Solution:
    def isPrintable(self, targetGrid: list[list[int]]) -> bool:
        C = 60
        m, n = len(targetGrid), len(targetGrid[0])
        min_r = [m] * (C + 1)
        min_c = [n] * (C + 1)
        max_r = [-1] * (C + 1)
        max_c = [-1] * (C + 1)
        for i, row in enumerate(targetGrid):       # 每种颜色的边框矩形
            for j, col in enumerate(row):
                min_r[col] = min(min_r[col], i)
                max_r[col] = max(max_r[col], i)
                min_c[col] = min(min_c[col], j)
                max_c[col] = max(max_c[col], j)
        present = [c for c in range(1, C + 1) if max_r[c] >= 0]
        dep = {b: set() for b in present}           # b -> a：b 必须先于 a 打印
        indeg = {c: 0 for c in present}
        for b in present:
            for i in range(min_r[b], max_r[b] + 1):
                for j in range(min_c[b], max_c[b] + 1):
                    a = targetGrid[i][j]
                    if a != b and a not in dep[b]:
                        dep[b].add(a)
                        indeg[a] += 1
        q = [c for c in present if indeg[c] == 0]   # Kahn 拓扑排序
        done = 0
        while q:
            b = q.pop()
            done += 1
            for a in dep[b]:
                indeg[a] -= 1
                if indeg[a] == 0:
                    q.append(a)
        return done == len(present)                 # 全部出队 <=> 依赖图无环
```

> 💡 两份代码均通过全部 4 个官方示例（`true`、`true`、`false`、`false`），并与**记忆化搜索暴力**（状态 = 当前网格 + 已用颜色，枚举全部矩形打印）对拍 4310 组：含纯随机、棋盘对抗、真实打印序列回放、嵌套回字结构四类生成器（结果分布 true=3210 / false=790），`mismatch = 0`。

## 8. 边界情况与易错点

1. **单色网格**：依赖图无边、单节点，恒为 `true`；此时直接一次打印 $B(c)$（可能就是全网格）。
2. **同一颜色不连通**：颜色可能散布多处，但只要打印一次覆盖其边框即可——**不要**试图对每个连通块单独打印（颜色只能用一次）。
3. **未出现的颜色**：不打印、不建边、不入队。若把它们也当节点，「present」计数就会对不上，需要格外小心 `done == present` 的口径统一。
4. **建边漏判「$a \ne b$」**：边框内大部分格子就是 $b$ 自己的颜色，不自环要去掉（自环会让拓扑排序永远失败）。
5. **去重影响入度**：同一个 $(b, a)$ 被 100 个格子触发时若不去重，入度会加 100，减完不归零，误判成有环。
6. **哨兵初值的边界**：用 `minR = m, maxR = -1` 表示未出现，扫描判断 `maxR[c] >= 0`；若把哨兵错设为 0/合法值，会把未出现颜色误当出现。
7. **为什么打印边框矩形「够用」而不必考虑更大矩形**：充分性证明中只用了「覆盖关系」与「先后关系」，缩小矩形只会**减少**它覆盖的格子、从而减少依赖边，构造仍合法；换言之任何可打印网格都可用「每色恰好打印其边框」的拓扑序实现（见 §5 推论）。
