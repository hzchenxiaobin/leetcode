# LeetCode 所有奇数长度子数组的和 题解

## 1. 题目概述

- **标题 / 题号**：所有奇数长度子数组的和（#1588，easy）
- **链接**：https://leetcode.cn/problems/sum-of-all-odd-length-subarrays/
- **来源**：LeetCode 第 35 场双周赛 Q1
- **难度**：简单
- **标签**：数组、数学、前缀和

**题意**：给定一个正整数数组 `arr`，求**所有可能的奇数长度子数组**的元素和之和。子数组定义为原数组中的连续子序列；同一子数组只统计一次，长度为 $1, 3, 5, \dots$ 的子数组都要算。

**约束**：

- $1 \le arr.length \le 100$
- $1 \le arr[i] \le 1000$
- 进阶：能否设计 $O(n)$ 时间复杂度的算法？

## 2. 示例

**示例 1**

```text
输入：arr = [1,4,2,5,3]
输出：58
解释：所有奇数长度子数组与其和为：
[1]=1, [4]=4, [2]=2, [5]=5, [3]=3
[1,4,2]=7, [4,2,5]=11, [2,5,3]=10
[1,4,2,5,3]=15
总和 = 1+4+2+5+3+7+11+10+15 = 58
```

**示例 2**

```text
输入：arr = [1,2]
输出：3
解释：只有 [1] 和 [2] 两个奇数长度子数组，和为 3。
```

**示例 3**

```text
输入：arr = [10,11,12]
输出：66
解释：[10]+[11]+[12]+[10,11,12] = 10+11+12+33 = 66。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的做法是枚举：$O(n^2)$ 个子数组配上前缀和 $O(1)$ 求区间和，总复杂度 $O(n^2)$。$n \le 100$ 时只有 $10^4$ 级别，比赛里可以直接写完交掉。但题目进阶明确要求 $O(n)$，而且「逐个求和」的做法完全没有利用**长度奇偶性**的结构——这正是签到题想考的观察点。

### 3.2 核心观察：贡献法——不枚举子数组，改为统计每个元素被算了多少次

![核心观察：固定元素后左右端点的奇偶配对](images/bw35_q1_parity_endpoints.svg)

与其枚举子数组再对每个子数组求和，不如反过来问：**元素 arr[i] 一共出现在多少个奇数长度子数组里**？设这个次数为 $c_i$，则答案就是

$$\text{ans} = \sum_{i=0}^{n-1} arr[i] \cdot c_i.$$

含 $arr[i]$ 的子数组由左端点 $l \in [0, i]$ 和右端点 $r \in [i, n-1]$ 唯一决定，共 $L = i + 1$ 个左端点、$R = n - i$ 个右端点。子数组长度为 $r - l + 1$，它是奇数当且仅当 $r - l$ 是偶数，即

> **$l$ 与 $r$ 同奇偶**。

把左端点按「与 $i$ 是否同奇偶」分成两类：同奇偶的有 $\lceil L/2 \rceil$ 个、不同奇偶的有 $\lfloor L/2 \rfloor$ 个；右端点同理（与 $i$ 同奇偶的有 $\lceil R/2 \rceil$ 个）。于是同奇偶的配对数为

$$c_i = \left\lceil \frac{L}{2} \right\rceil \cdot \left\lceil \frac{R}{2} \right\rceil + \left\lfloor \frac{L}{2} \right\rfloor \cdot \left\lfloor \frac{R}{2} \right\rfloor = \left\lceil \frac{L \cdot R}{2} \right\rceil = \frac{(i+1)(n-i) + 1}{2}.$$

一步整除就把 $c_i$ 算出来了——既不用分类讨论 $i$ 的奇偶，也不用枚举端点。

### 3.3 算法流程

```text
1. n = len(arr)
2. ans = 0
3. 对每个下标 i（0-based）：
       L = i + 1                 # 左端点个数
       R = n - i                 # 右端点个数
       c = (L * R + 1) // 2      # 含 arr[i] 的奇数长度子数组个数
       ans += arr[i] * c
4. 返回 ans
```

### 3.4 示例演算

![示例演算：数组 1,4,2,5,3 每个元素的出现次数与贡献](images/bw35_q1_walkthrough_table.svg)

以示例 1 `arr = [1,4,2,5,3]`（$n = 5$）逐位验证：

| $i$ | $arr[i]$ | $L$ | $R$ | $c_i = \frac{LR+1}{2}$ | 贡献 $arr[i] \cdot c_i$ |
|-----|----------|-----|-----|------------------------|------------------------|
| 0 | 1 | 1 | 5 | 3 | 3 |
| 1 | 4 | 2 | 4 | 4 | 16 |
| 2 | 2 | 3 | 3 | 5 | 10 |
| 3 | 5 | 4 | 2 | 4 | 20 |
| 4 | 3 | 5 | 1 | 3 | 9 |

$3 + 16 + 10 + 20 + 9 = 58$，与官方答案一致。手动抽验 $i = 2$：以 $arr[2]$ 为固定元素的奇数子数组是 $[2]$、$[1,4,2]$、$[4,2,5]$、$[2,5,3]$、$[1,4,2,5,3]$ 共 $5$ 个 ✓。

## 4. 算法细节

1. **计数公式的两个等价形式**：$c_i = \lceil LR/2 \rceil$ 或写成「同奇偶配对数」$\lceil L/2 \rceil\lceil R/2 \rceil + \lfloor L/2 \rfloor\lfloor R/2 \rfloor$。前者代码最短，后者更好记（奇配奇 + 偶配偶）。两者相等可用 $L = 2a + e_1$、$R = 2b + e_2$（$e \in \{0,1\}$）展开验证。
2. **+1 不能丢**：$(L \cdot R + 1) / 2$ 中的 $+1$ 负责「向上取整」。当 $L \cdot R$ 为奇数（$L, R$ 都是奇数）时，少了它就会漏掉一个子数组。比如 $i = 0, n = 1$ 时 $L = R = 1$，$c$ 必须是 $1$。
3. **溢出与整除顺序**：$L \cdot R$ 最大 $51 \times 50 = 2550$（$n = 100$ 中点），乘 $arr[i] \le 1000$ 后单点贡献 $\le 1275000$，总和 $\le 100 \times 1.275 \times 10^6 \approx 1.28 \times 10^8$，`int` 放得下但已接近舒适区上限，C++ 里用 `long long` 累加一步到位。
4. **整除在乘法之前**：先算 $c_i$ 再乘 $arr[i]$，不要把 $(L \cdot R + 1) \cdot arr[i]$ 一起除 2——那不是同一个数。
5. **为什么不需要前缀和**：贡献法把「区间和求和」转化成「单点计数 × 单点值」，区间和本身已经消失，前缀和自然也不需要了。标签里的「前缀和」对应的是暴力解法。

## 5. 正确性证明

**引理 1（奇长度判据）**：子数组 $[l, r]$ 的长度 $r - l + 1$ 为奇数，当且仅当 $l \equiv r \pmod 2$。

**证明**：$r - l + 1$ 为奇数 $\iff$ $r - l$ 为偶数 $\iff$ $r$ 与 $l$ 同奇偶。∎

**引理 2（同奇偶配对计数）**：$l \in [0, i]$ 中与 $i$ 同奇偶的有 $\lceil (i+1)/2 \rceil$ 个，$r \in [i, n-1]$ 中与 $i$ 同奇偶的有 $\lceil (n-i)/2 \rceil$ 个；于是「$l \equiv r$」的配对数为

$$c_i = \left\lceil \frac{L}{2} \right\rceil \cdot \left\lceil \frac{R}{2} \right\rceil + \left\lfloor \frac{L}{2} \right\rfloor \cdot \left\lfloor \frac{R}{2} \right\rfloor = \left\lceil \frac{LR}{2} \right\rceil.$$

**证明**：$[0, i]$ 中与 $i$ 同奇偶的数是 $i, i-2, i-4, \dots$，共 $\lfloor i/2 \rfloor + 1 = \lceil (i+1)/2 \rceil = \lceil L/2 \rceil$ 个，其余 $\lfloor L/2 \rfloor$ 个。$l \equiv r$ 的配对要么两端都与 $i$ 同奇偶，要么两端都与 $i$ 异奇偶（此时两端彼此同奇偶），这两类不重不漏，合计即上式。恒等式：记 $L = 2a + e_1$，$R = 2b + e_2$（$e_1, e_2 \in \{0,1\}$），则左边 $= (a+e_1)(b+e_2) + ab = 2ab + ae_2 + be_1 + e_1e_2$，而 $\lceil LR/2 \rceil = \lceil (4ab + 2ae_2 + 2be_1 + e_1e_2)/2 \rceil = 2ab + ae_2 + be_1 + e_1e_2$，两边相等。∎

**定理**：$\text{ans} = \sum_i arr[i] \cdot c_i$，其中 $c_i = \dfrac{(i+1)(n-i)+1}{2}$。

**证明**：按定义 ans 是所有奇数长度子数组之和。交换求和次序，把「每个子数组的和」拆成「每个元素的贡献」：元素 $arr[i]$ 的贡献 $= arr[i] \times$（含 $i$ 的奇数长度子数组个数）。「含 $i$」$\iff$ $l \le i \le r$，即 $l \in [0,i]$、$r \in [i, n-1]$ 任意组合，故该个数由引理 1、引理 2 给出 $c_i$。每个 (子数组，元素) 包含对恰好被计数一次，无重复无遗漏。∎

## 6. 复杂度分析

- **时间**：$O(n)$。一趟循环，每个下标常数次乘除加。
- **空间**：$O(1)$。只用了常数个计数变量（不含输入数组本身）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int sumOddLengthSubarrays(vector<int>& arr) {
        int n = (int)arr.size();
        long long ans = 0;
        for (int i = 0; i < n; ++i) {
            long long L = i + 1;                 // 左端点个数（0..i）
            long long R = n - i;                 // 右端点个数（i..n-1）
            long long oddCnt = (L * R + 1) / 2;   // 含 arr[i] 的奇数长度子数组个数
            ans += 1LL * arr[i] * oddCnt;
        }
        return (int)ans;
    }
};
```

### Python

```python
class Solution:
    def sumOddLengthSubarrays(self, arr: list[int]) -> int:
        n = len(arr)
        ans = 0
        for i, x in enumerate(arr):
            left = i + 1                          # 左端点个数（0..i）
            right = n - i                          # 右端点个数（i..n-1）
            ans += x * ((left * right + 1) // 2)  # 含 arr[i] 的奇数长度子数组个数
        return ans
```

> 💡 两份代码均通过全部官方示例（`58`、`3`、`66`）以及与 $O(n^3)$ / $O(n^2)$ 暴力枚举的 3.3 万组随机对拍（含 $n = 100$ 满规模），`mismatch = 0`。

## 8. 边界情况与易错点

1. **$n = 1$**：唯一的子数组就是整个数组本身，$c_0 = (1 \cdot 1 + 1)/2 = 1$，公式天然正确。
2. **向上取整的 +1**：`L * R` 为奇数时（$L$、$R$ 均为奇），漏写 `+1` 会让每个这类下标少算一个子数组，小数据（如 $n=1$）立刻能测出，大数据里则是「差一点点」的隐蔽错误。
3. **乘法溢出**：C++ 中 `1LL * arr[i] * oddCnt` 保证 64 位运算；全部用 `int` 也不会溢出本题范围，但养成习惯更稳。
4. **不要按「长度 1、3、5」分层枚举**：那会回到 $O(n^2)$；也不要把「奇数长度」误当成「奇数下标」——判据是端点同奇偶，与下标值本身无关。
5. **先除后乘**：$c_i$ 是独立整数，务必先算它再乘元素值，顺序写反会得到错误的舍入。
