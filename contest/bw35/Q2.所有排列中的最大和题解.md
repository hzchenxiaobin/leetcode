# LeetCode 所有排列中的最大和 题解

## 1. 题目概述

- **标题 / 题号**：所有排列中的最大和（#1589，medium）
- **链接**：https://leetcode.cn/problems/maximum-sum-obtained-of-any-permutation/
- **来源**：LeetCode 第 35 场双周赛 Q2
- **难度**：中等
- **标签**：贪心、数组、前缀和、排序

**题意**：给定整数数组 `nums` 与查询数组 `requests`，其中 `requests[i] = [start_i, end_i]` 表示第 $i$ 次查询求 `nums[start_i..end_i]` 的区间和。你可以**任意重排** `nums` 中的数字，目标是使**所有查询结果之和最大**，返回这个最大和对 $10^9 + 7$ 取模的结果。

**约束**：

- $n == nums.length$，$1 \le n \le 10^5$
- $0 \le nums[i] \le 10^5$
- $1 \le requests.length \le 10^5$
- $requests[i].length == 2$，$0 \le start_i \le end_i < n$

## 2. 示例

**示例 1**

```text
输入：nums = [1,2,3,4,5], requests = [[1,3],[0,1]]
输出：19
解释：取排列 [3,5,4,2,1]：
requests[0] -> nums[1]+nums[2]+nums[3] = 5+4+2 = 11
requests[1] -> nums[0]+nums[1] = 3+5 = 8
总和 11 + 8 = 19，是所有排列中最大的。
```

**示例 2**

```text
输入：nums = [1,2,3,4,5,6], requests = [[0,1]]
输出：11
解释：最优排列 [6,5,4,3,2,1]，查询和为 6+5 = 11。
```

**示例 3**

```text
输入：nums = [1,2,3,4,5,10], requests = [[0,2],[1,3],[1,1]]
输出：47
解释：最优排列 [4,10,5,3,2,1]，查询结果为 [19,18,10]，总和 47。
```

## 3. 解题思路

### 3.1 暴力思路

枚举 `nums` 的全部 $n!$ 种排列、对每种排列跑一遍全部查询——指数级，$n$ 只能到 7 左右，完全不可行。即使退一步注意到「每个下标被查询覆盖的次数与排列无关」，也需要先回答：**给每个下标安排一个值，怎么安排最优？** 直接搜索依然是排列枚举。

### 3.2 核心观察：总和只取决于「每个下标被覆盖的次数」——差分数组求覆盖次数 + 排序贪心配对

![核心观察：差分数组 O(n+R) 统计每个下标的查询覆盖次数](images/bw35_q2_diff_array.svg)

把总和展开：第 $i$ 个查询对答案的贡献是 $\sum_{k=start_i}^{end_i} nums[\pi(k)]$（$\pi$ 是把值放到下标的排列）。交换求和次序：

$$\text{total}(\pi) = \sum_{k=0}^{n-1} cnt[k] \cdot nums[\pi(k)],$$

其中 $cnt[k]$ 是**覆盖下标 $k$ 的查询个数**，它与排列无关！于是问题变成：给定系数 $cnt[0..n-1]$（非负整数），把 $nums$ 的值分配到下标上，最大化点积。这就是教科书级的**重排不等式**场景：

> **被查询覆盖次数多的下标，应该放大的数字。**

$cnt$ 怎么求？$10^5$ 个区间，逐区间加是 $O(nR) = 10^{10}$——用**差分数组**：区间 $[s,e]$ 加一只需 `diff[s]++`、`diff[e+1]--`，再一遍前缀和还原，总 $O(n + R)$。

### 3.3 算法流程：差分求 cnt → 双排序 → 同向配对求点积

![算法流程：cnt 与 nums 同向排序后逐位配对](images/bw35_q2_greedy_matching.svg)

```text
1. diff[0..n] 清零；对每个请求 [s, e]：diff[s] += 1, diff[e+1] -= 1
2. 前缀和还原 cnt[i]（下标 i 被覆盖的次数）
3. cnt 升序排序；nums 升序排序
4. ans = Σ cnt[i] * nums[i]（边乘边取模）
5. 返回 ans
```

### 3.4 示例演算

![示例演算：示例 1 的 cnt 数组与配对求和](images/bw35_q2_walkthrough.svg)

以示例 1 演算：$nums = [1,2,3,4,5]$，$requests = [[1,3],[0,1]]$。

| 步骤 | 内容 |
|------|------|
| 差分 | $[1,3]$：$diff[1]{+}{=}1, diff[4]{-}{=}1$；$[0,1]$：$diff[0]{+}{=}1, diff[2]{-}{=}1$ |
| 前缀和 | $cnt = [1, 2, 1, 1, 0]$（下标 0 被 $[0,1]$ 覆盖 1 次；下标 1 被两个查询各覆盖 1 次；下标 4 未被覆盖） |
| 排序 | $cnt$ 升序 $= [0,1,1,1,2]$，$nums$ 升序 $= [1,2,3,4,5]$ |
| 配对求和 | $0{\cdot}1 + 1{\cdot}2 + 1{\cdot}3 + 1{\cdot}4 + 2{\cdot}5 = 19$ ✓ |

对照官方解释的排列 $[3,5,4,2,1]$：值 $5$（最大）放在覆盖次数最高的下标 1，正是「大值配高次数」的实现。

## 4. 算法细节

1. **差分数组开到 $n+1$**：$e+1$ 最大取到 $n$，`diff` 容量必须是 $n+1$ 才不越界。
2. **覆盖次数的量级**：$cnt[i] \le requests.length \le 10^5$；$nums[i] \le 10^5$。单乘积 $\le 10^{10}$，超出 32 位——C++ 中 `cnt` 用 `long long` 存（或先取模再乘），乘完立刻对 $10^9+7$ 取模；Python 无此顾虑，最后统一取模即可（总和不超 $10^5 \cdot 10^5 \cdot 10^5 = 10^{15}$，在 64 位内）。
3. **排序方向必须同向**：两个都升序（或都降序）。若一升一降则得到的是**最小**点积（重排不等式的另一头）。
4. **为什么要取模后配对仍正确**：模意义下「先乘后取模」逐项进行，加法对模封闭，与先算完整和再取模结果一致。
5. **`cnt` 与 `nums` 长度相同**：未被任何查询覆盖的下标 $cnt=0$，天然吸收最小的值，无需特判。

## 5. 正确性证明

**引理 1（总和的重写）**：设排列 $\pi$ 把值安排到下标（下标 $k$ 放 $nums[\pi(k)]$），则所有查询结果之和 $T(\pi) = \sum_{k=0}^{n-1} cnt[k] \cdot nums[\pi(k)]$，其中 $cnt[k] = \#\{i : start_i \le k \le end_i\}$。

**证明**：$T(\pi) = \sum_i \sum_{k=start_i}^{end_i} nums[\pi(k)]$。交换求和次序，把「按查询求和」改为「按下标求和」：下标 $k$ 每被一个查询覆盖就贡献一次 $nums[\pi(k)]$，覆盖次数恰为 $cnt[k]$，故 $T(\pi) = \sum_k cnt[k] \cdot nums[\pi(k)]$。∎

**引理 2（重排不等式）**：设 $a_0 \le a_1 \le \dots \le a_{n-1}$，$b_0 \le b_1 \le \dots \le b_{n-1}$。对任意排列 $\sigma$，

$$\sum_i a_i b_{n-1-i} \;\le\; \sum_i a_i b_{\sigma(i)} \;\le\; \sum_i a_i b_i.$$

即**同序配对最大、逆序配对最小**。

**证明**：只需证最大侧。若 $\sigma$ 不是恒等排列且存在 $i < j$ 使 $b_{\sigma(i)} > b_{\sigma(j)}$，交换 $\sigma(i)$ 与 $\sigma(j)$ 后和的变化量为

$$(a_i b_{\sigma(j)} + a_j b_{\sigma(i)}) - (a_i b_{\sigma(i)} + a_j b_{\sigma(j)}) = (a_j - a_i)(b_{\sigma(i)} - b_{\sigma(j)}) \ge 0,$$

即任何「逆序对」都可交换而不减总和。逆序对个数有限，bubble-sort 式交换有限步后得到恒等排列，途中总和单调不减，故恒等排列（同序配对）取到最大值。∎

**定理**：将 $cnt$ 与 $nums$ 分别升序排序后逐位相乘求和（取模），即得最大总和。

**证明**：由引理 1，最大化 $T(\pi)$ 等价于在系数 $cnt$ 与值 $nums$ 之间做配对。由引理 2，同序配对取得最大值，即排序后逐位相乘。取模是环同态，不改变比较结果。∎

## 6. 复杂度分析

- **时间**：$O(n \log n + R)$。差分与前缀和 $O(n + R)$，两次排序 $O(n \log n)$ 主导，一遍配对 $O(n)$。$n, R \le 10^5$ 时毫秒级。
- **空间**：$O(n)$。差分数组与 $cnt$ 数组（排序原地进行；Python 的 `sort` 亦为原地）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maxSumRangeQuery(vector<int>& nums, vector<vector<int>>& requests) {
        const long long MOD = 1000000007LL;
        int n = (int)nums.size();
        vector<long long> diff(n + 1, 0);          // 差分数组，容量 n+1 防 e+1 越界
        for (const auto& r : requests) {
            diff[r[0]] += 1;
            diff[r[1] + 1] -= 1;
        }
        vector<long long> freq(n);
        long long cur = 0;
        for (int i = 0; i < n; ++i) {
            cur += diff[i];
            freq[i] = cur;                         // freq[i]：下标 i 被覆盖的次数
        }
        sort(freq.begin(), freq.end());
        sort(nums.begin(), nums.end());            // 两个同向排序
        long long ans = 0;
        for (int i = 0; i < n; ++i)
            ans = (ans + freq[i] * nums[i]) % MOD;
        return (int)ans;
    }
};
```

### Python

```python
class Solution:
    def maxSumRangeQuery(self, nums: list[int], requests: list[list[int]]) -> int:
        MOD = 10 ** 9 + 7
        n = len(nums)
        diff = [0] * (n + 1)                       # 差分数组，容量 n+1 防 e+1 越界
        for s, e in requests:
            diff[s] += 1
            diff[e + 1] -= 1
        freq = []
        cur = 0
        for i in range(n):
            cur += diff[i]
            freq.append(cur)                       # freq[i]：下标 i 被覆盖的次数
        freq.sort()
        nums.sort()                                # 两个同向排序
        return sum(f * x for f, x in zip(freq, nums)) % MOD
```

> 💡 两份代码均通过全部官方示例（`19`、`11`、`47`）以及与**全排列暴力枚举**的 4250 组随机对拍（$n \le 7$，含重复值、重叠区间），`mismatch = 0`。

## 8. 边界情况与易错点

1. **`e+1` 越界**：差分数组长度必须是 $n+1$。开成 $n$ 在 $e = n-1$ 时越界写坏相邻内存（Python 则直接 `IndexError`）。
2. **溢出**：$cnt \cdot nums$ 单项即可达 $10^{10}$，C++ 必须用 `long long` 参与乘法；若把 `freq` 存成 `int` 再乘就溢出了。边乘边模。
3. **排序方向弄反**：一个升序一个降序会算出最小值——用示例 1 自检（19 vs 最小值 11）即可发现。
4. **取模时机**：可以全程累加最后取模（Python 推荐），C++ 推荐逐项取模防溢出；两者结果一致。
5. **`requests` 为空**：约束保证至少 1 个，但即便为空，$cnt$ 全 0，答案为 0，代码也正确。
6. **重复值排列**：`nums` 有重复值时最优配对不唯一但最大值唯一，排序配对仍正确（重排不等式不要求互异）。
