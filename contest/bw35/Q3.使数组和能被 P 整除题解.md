# LeetCode 使数组和能被 P 整除 题解

## 1. 题目概述

- **标题 / 题号**：使数组和能被 P 整除（#1590，medium）
- **链接**：https://leetcode.cn/problems/make-sum-divisible-by-p/
- **来源**：LeetCode 第 35 场双周赛 Q3
- **难度**：中等
- **标签**：数组、哈希表、前缀和

**题意**：给定正整数数组 `nums` 与正整数 `p`，需要从中移除**最短**的一个**连续子数组**（可以为空），使得剩余元素之和能被 $p$ 整除。**不允许移除整个数组**。返回最短子数组的长度；若无法满足要求返回 $-1$。

**约束**：

- $1 \le nums.length \le 10^5$
- $1 \le nums[i] \le 10^9$
- $1 \le p \le 10^9$

## 2. 示例

**示例 1**

```text
输入：nums = [3,1,4,2], p = 6
输出：1
解释：元素和为 10，不能被 6 整除。移除子数组 [4]，剩余和为 6。
```

**示例 2**

```text
输入：nums = [6,3,5,2], p = 9
输出：2
解释：移除任何一个元素都无法使和被 9 整除，最优是移除 [5,2]，
剩余 [6,3] 的和为 9。
```

**示例 3**

```text
输入：nums = [1,2,3], p = 3
输出：0
解释：和恰好为 6，已被 3 整除，无需移除（移除空子数组）。
```

**示例 4**

```text
输入：nums = [1,2,3], p = 7
输出：-1
解释：除整段外，任何子数组的移除都无法使剩余和被 7 整除。
```

**示例 5**

```text
输入：nums = [1000000000,1000000000,1000000000], p = 3
输出：0
```

## 3. 解题思路

### 3.1 暴力思路

设 $total = \sum nums$。移除子数组 $[l, r]$ 后剩余和为 $total - (S_{r+1} - S_l)$（$S$ 为前缀和），要求它 $\equiv 0 \pmod p$。枚举全部 $O(n^2)$ 个子数组、$O(1)$ 判定，总 $O(n^2) = 10^{10}$——超时。瓶颈在于：**对每个右端点，我们重新枚举所有左端点**，而判定条件只依赖两个前缀和的**模 $p$ 余数**，这是典型的「哈希一次遍历」可消除的重复。

### 3.2 核心观察：模意义下的前缀和——找一段「余数差恰等于 total 余数」的子数组

![核心观察：前缀和取模，同余匹配即得可行移除段](images/bw35_q3_prefix_remainder.svg)

记 $r = total \bmod p$。

- 若 $r = 0$：整个数组和已整除，答案 $0$（移除空子数组）。
- 否则：移除子数组 $(i, j]$（即元素 $nums[i+1..j]$，长度 $j - i$）后剩余和为 $total - (S_j - S_i)$。要使它 $\equiv 0 \pmod p$，需要

$$S_j - S_i \equiv r \pmod p \quad\Longleftrightarrow\quad S_i \equiv S_j - r \pmod p.$$

于是问题变成：**对每个 $j$，找最小的 $j - i$，使得前缀和 $S_i$ 的余数等于 $(S_j - r) \bmod p$**。这与「和为 K 的子数组」完全同构，只是把「相等」换成了「模意义下的相等」，并且从「计数」换成了「求最短长度」——因此哈希表存的是**每个余数最近一次出现的下标**：同一个余数，下标越大，$j - i$ 越短。

### 3.3 算法流程：一遍扫描 + 哈希「余数 → 最近下标」

![算法流程：扫描 j，查 want 余数，更新哈希与最短长度](images/bw35_q3_scan_flow.svg)

```text
1. total = Σ nums；r = total % p
2. 若 r == 0：返回 0
3. last = {0 : 0}            # 前缀和 S_0 = 0，下标 0
   ans = n
4. 对 j = 1..n：
       cur = (cur + nums[j-1]) % p        # S_j mod p
       want = (cur - r + p) % p           # 需要的 S_i 余数
       若 want ∈ last：ans = min(ans, j - last[want])
       last[cur] = j                      # 保留最大下标
5. 返回 ans（若 ans == n，说明只匹配到整段，返回 -1）
```

### 3.4 示例演算

![示例演算：数组 6,3,5,2 与 p=9 的逐 j 扫描表](images/bw35_q3_walkthrough.svg)

以示例 2 `nums = [6,3,5,2]`、$p = 9$ 演算：$total = 16$，$r = 7$。前缀和（mod 9）依次为 $S_0 = 0, S_1 = 6, S_2 = 0, S_3 = 5, S_4 = 7$。

| $j$ | $S_j \bmod 9$ | want $= (S_j - 7) \bmod 9$ | 哈希命中 | 长度 $j - i$ | ans |
|-----|----------------|-----------------------------|----------|---------------|-----|
| 1 | 6 | $(6-7+9)\%9 = 8$ | 无 | — | 4 |
| 2 | 0 | $(0-7+9)\%9 = 2$ | 无 | — | 4 |
| 3 | 5 | $(5-7+9)\%9 = 7$ | 无 | — | 4 |
| 4 | 7 | $(7-7)\%9 = 0$ | $i = 2$（$S_2 = 0$，最近下标） | $4 - 2 = 2$ | **2** |

返回 $2$ ✓——对应移除子数组 $nums[3..4] = [5,2]$。注意 $S_0 = 0$ 也匹配 want $=0$，但 $i=0$ 给出长度 4；**哈希保留最近下标**保证取到更短的 $i = 2$。

## 4. 算法细节

1. **总和用 64 位**：$n \cdot nums[i] \le 10^5 \times 10^9 = 10^{14}$，C++ 必须用 `long long` 累加；取模后 $r < p \le 10^9$ 可放回 `int`。
2. **负余数防护**：`want = (cur - r) % p` 在 C++ 中可能为负，需 `((cur - r) % p + p) % p`；Python 的 `%` 对正模数恒非负，可直接写。
3. **哈希初始化**：`last[0] = 0` 对应空前缀 $S_0 = 0$——漏掉它会导致「移除前缀」的方案全部漏判（例如示例 1 中移除 $[4]$ 恰是「$S_2$ 与 want 匹配」而非前缀，但移除前缀型答案只有靠 $S_0$ 才能匹配到）。
4. **保留最近下标**：`last[cur] = j` 直接覆盖，因为更大的 $i$ 永远更优；无需保存全部出现位置。
5. **「不允许移除整个数组」的处理**：$r \ne 0$ 时，$S_n \equiv r$，则 want at $j=n$ 为 $0$，而 $S_0 = 0$ 必然匹配——即 $(0, n]$（整段）永远是一个候选但被禁止。它长度为 $n$；若最终 $ans = n$，说明没有更短的匹配，返回 $-1$。由于长度 $> n$ 的候选不存在，`ans == n` 的判定既覆盖「只匹配到整段」也覆盖「无任何匹配」两种情形。
6. **查询先于写入**：对每个 $j$，先查 `want` 再把 $cur$ 写入哈希，保证 $i < j$ 严格成立（本题移除空段只在 $r=0$ 时合法，否则子数组非空）。

## 5. 正确性证明

**引理 1（可行性的等价刻画）**：设 $r = total \bmod p \ne 0$。移除子数组 $(i, j]$（$0 \le i < j \le n$）后剩余和能被 $p$ 整除，当且仅当 $S_i \equiv S_j - r \pmod p$。

**证明**：剩余和 $= total - (S_j - S_i)$。它 $\equiv 0 \pmod p$ $\iff$ $S_j - S_i \equiv total \equiv r \pmod p$ $\iff$ $S_i \equiv S_j - r \pmod p$。∎

**引理 2（最近下标最优）**：对固定的 $j$，满足引理 1 条件的 $i$ 中，取**最大**的 $i^* = \max\{i < j : S_i \equiv S_j - r\}$ 使 $j - i$ 最小。

**证明**：候选长度就是 $j - i$，$j$ 固定时关于 $i$ 严格递减，故最大 $i$ 给出最小长度。∎

**定理**：算法返回的 $ans$ 是满足条件的最短移除长度；当且仅当唯一可行候选是整段（或无候选）时返回 $-1$。

**证明**：算法对每个 $j \in [1, n]$ 用哈希表在 $O(1)$ 内取到引理 2 的 $i^*$（表中存的是每个余数的最近下标，先查后写保证 $i < j$），对所有 $j$ 取最小即覆盖全部候选 $(i, j]$，由引理 1 每个候选被等价判定，故 $ans \le n$ 为最短可行长度。若 $ans < n$，它对应一个真子数组，合法，返回之。若 $ans = n$：唯一长度为 $n$ 的候选是 $(0, n]$（整段），它被禁止；而其余候选长度均 $< n$ 且未出现（否则会被取为更小的 ans），故无解，返回 $-1$。∎

## 6. 复杂度分析

- **时间**：$O(n)$。一遍扫描，每个 $j$ 做一次哈希查询与一次哈希写入（均摊 $O(1)$）。
- **空间**：$O(\min(n, p))$。哈希表中不同的余数至多 $\min(n+1, p)$ 个。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minSubarray(vector<int>& nums, int p) {
        int n = (int)nums.size();
        long long total = 0;
        for (int x : nums) total += x;            // 总和需 64 位
        int target = (int)(total % p);
        if (target == 0) return 0;                // 已整除：移除空子数组
        unordered_map<int, int> last;             // 余数 -> 最近出现的前缀下标
        last.reserve(2 * n);
        last[0] = 0;                              // 空前缀 S_0 = 0
        int ans = n;
        long long cur = 0;
        for (int j = 1; j <= n; ++j) {
            cur = (cur + nums[j - 1]) % p;
            int want = (int)(((cur - target) % p + p) % p);
            auto it = last.find(want);
            if (it != last.end()) ans = min(ans, j - it->second);
            last[cur] = j;                        // 覆盖为更大下标
        }
        return ans == n ? -1 : ans;               // 只匹配到整段 -> 无解
    }
};
```

### Python

```python
class Solution:
    def minSubarray(self, nums: list[int], p: int) -> int:
        total = sum(nums)
        target = total % p
        if target == 0:
            return 0                              # 已整除：移除空子数组
        n = len(nums)
        last = {0: 0}                             # 余数 -> 最近出现的前缀下标
        ans = n
        cur = 0
        for j in range(1, n + 1):
            cur = (cur + nums[j - 1]) % p
            want = (cur - target) % p             # Python % 恒非负
            if want in last:
                ans = min(ans, j - last[want])
            last[cur] = j                         # 覆盖为更大下标
        return ans if ans < n else -1             # 只匹配到整段 -> 无解
```

> 💡 两份代码均通过 5 个官方示例（`1`、`2`、`0`、`-1`、`0`）以及与「枚举全部子数组」暴力的 3.3 万组随机对拍（含 $nums[i], p \sim 10^9$ 的大数值档），`mismatch = 0`。

## 8. 边界情况与易错点

1. **$r = 0$ 直接返回 0**：这一步必须在建哈希之前完成，否则后面会错误地寻找「和 $\equiv 0$」的子数组，把空移除（合法答案 0）算成非零长度。
2. **漏初始化 `last[0] = 0`**：丢掉空前缀会漏判所有「移除前缀」型答案；构造反例：`nums = [1, 1, 1], p = 2`，移除前缀 `[1]` 即可，答案 1。
3. **负余数**：C++ 的 `%` 可为负，`want` 必须再 `+p` 取模；Python 无此坑，但两份代码逻辑须一致。
4. **溢出**：$total$ 达 $10^{14}$，C++ 用 `long long`；`cur` 在取模后 $< p \le 10^9$，`cur - target + p` 在 64 位内安全。
5. **`ans == n` 的语义**：它同时表示「无匹配」与「只匹配到整段」两种失败情形，不能只判「哈希从未命中」。
6. **先查后写**：若先把 $S_j$ 写入再查，$j - i = 0$ 的假解（空子数组）会在 $r \ne 0$ 时错误地出现——长度 0 永远匹配自己。
7. **本题不允许移除整段**：若题目变体允许移除整段（剩余和 0 天然可整除），`ans == n` 时应返回 `n` 而非 $-1$，判定条件需相应调整。
