# LeetCode 质数的最大距离 题解

## 1. 题目概述

- **标题 / 题号**：质数的最大距离（#3115，medium）
- **链接**：https://leetcode.cn/problems/maximum-prime-difference/
- **来源**：LeetCode 第 393 场周赛 Q2
- **难度**：中等
- **标签**：数组、数学、数论、素性测试

**题意**：给定整数数组 `nums`，选出**两个（不一定不同的）质数**，返回它们**下标**的**最大距离**——即最大化 $|i - j|$，其中 $\text{nums}[i]$ 与 $\text{nums}[j]$ 都是质数，且 $i$、$j$ 允许相等。

**约束**：

- $1 \le \text{nums.length} \le 3 \times 10^5$
- $1 \le \text{nums}[i] \le 100$
- 输入保证 `nums` 中**至少有一个质数**

> 💡 读题关键：两处细节决定整道题的走向。「**不一定不同**」意味着唯一质数时答案是 $0$ 而非无解，不存在失败分支；而 $1 \le \text{nums}[i] \le 100$ 的极小值域让素性判定近乎免费（试除上界仅 $\sqrt{100} = 10$）。更要紧的是：距离只依赖**下标**而非**数值**——这本质是一道「数组两端」题，不是数论题，数论只是门口的一张小门票。

## 2. 示例

**示例 1**

```text
输入：nums = [4, 2, 9, 5, 3]
输出：3
解释：nums[1]、nums[3] 和 nums[4] 是质数。因此答案是 |4 - 1| = 3。
```

**示例 2**

```text
输入：nums = [4, 8, 2, 8]
输出：0
解释：nums[2] 是质数。因为只有一个质数，所以答案是 |2 - 2| = 0。
```

**示例 3（补充：覆盖「1 不是质数」的干扰）**

```text
输入：nums = [97, 1, 100, 6, 11]
输出：4
解释：质数只有 97（下标 0）和 11（下标 4），1 既非质数也非合数，
      不能把下标 1 计入。答案 = 4 − 0 = 4。
```

## 3. 解题思路

### 3.1 暴力思路

枚举全部下标对 $(i, j)$，两者都是质数时用 $|i - j|$ 更新答案：$n = 3 \times 10^5$ 时下标对约 $4.5 \times 10^{10}$ 个，必然超时。退一步，先一趟把质数下标收集成列表再两两配对？最坏情形整个数组全是质数（如全 `2`），列表长度仍是 $n$，依旧 $O(n^2)$。

瓶颈出在「**成对枚举**」这个动作本身。而「最大」其实根本不需要成对看：**距离只由两端决定**——这是典型的「只关心最左最右」型问题。

### 3.2 核心观察：最左质数 × 最右质数，夹逼出最大距离

![夹逼核心观察：最左/最右质数下标决定答案](images/wc393_q2_first_last_squeeze.svg)

设 $\text{first}$ = **最左**质数下标、$\text{last}$ = **最右**质数下标（两者可以相等），则：

$$\text{答案} = \text{last} - \text{first}$$

**夹逼论证**：任取一对合法下标 $i \le j$（允许相等），由 $\text{first}$ 的最小性与 $\text{last}$ 的最大性，必有 $\text{first} \le i \le j \le \text{last}$，相减得 $j - i \le \text{last} - \text{first}$；而 $(\text{first}, \text{last})$ 本身就是一对合法选取（题目允许两个质数相同），上界恰好被取到。中间元素是什么、有多少个质数，全部无关紧要。

于是整道题塌缩成两件小事：

1. **判定质数**：值域 $[1, 100]$，试除上界 $\lfloor\sqrt{100}\rfloor = 10$，单次判定至多 9 次取模——甚至可以手写 25 个质数的硬编码表；
2. **一趟扫描**：`first` 只在**第一次**遇见质数时记录，`last` **每次**遇见质数都刷新，最后相减。

> 💡 一句话：**试除判素 + 一趟扫描记最左/最右质数下标，相减即答案**。

### 3.3 算法流程

![算法流程：一趟扫描维护 first 与 last](images/wc393_q2_scan_flow.svg)

流程三步（见上图）：

1. **判素函数** `isPrime(x)`：$x < 2$ 直接返回 `false`（把 1 挡在门外），否则试除 $d = 2 \dots \lfloor\sqrt{x}\rfloor$，整除即合数；
2. **扫描** $i = 0 \dots n-1$：命中质数时，若 `first` 尚未赋值则 `first = i`，随后无条件 `last = i`；
3. **返回** `last - first`——题目保证至少一个质数，`first` 必被赋值，无需无解分支。

### 3.4 示例演算

![示例演算：first 与 last 随扫描的变化](images/wc393_q2_walkthrough.svg)

以示例 1 `nums = [4,2,9,5,3]` 逐行走查（见上图上表）：

- **i = 1**（值 2，质数）：`first = 1` 唯一一次赋值，`last = 1`；
- **i = 3**（值 5，质数）：`last = 3`；
- **i = 4**（值 3，质数）：`last = 4`，扫描结束；
- 答案 $= 4 - 1 = 3$。

示例 2 `[4,8,2,8]` 中唯一质数 2 落在下标 2：`first = last = 2`，答案 $0$——「两个质数可以相同」由同一公式自动覆盖，无需任何特判。

## 4. 算法细节

1. **判素实现的三种选型**（值域 $\le 100$ 时都轻松通过，按口味选）：
   - **试除**（本篇主推）：零预处理、六行写完、`x < 2` 的判断**天然把 1 挡在门外**，本题最经典的坑被语法顺带消灭；单次至多试 $d = 2 \dots 10$，共 9 次取模；
   - **埃氏筛**：一次预处理出 101 格布尔表（值域内恰 25 个质数），此后每次 $O(1)$ 查询；但筛表只标记**合数**，`isComposite[1]` 恒为 `false`，判定条件必须带 $x \ge 2$，否则 `nums` 里的 1 会混进质数队伍把 `first` 拉错；
   - **硬编码**：直接写死 $\{2, 3, 5, \dots, 97\}$ 的 25 元集合，赛场上手速最快、零思维负担。
2. **first 与 last 的维护不对称**：`first` 用哨兵 `first == -1` 保证**只在首次命中**赋值，`last` 则**每次命中都覆盖**。两个条件别写混：若 `first` 也无条件覆盖，它就退化成 `last`；若 `last` 也带哨兵，它会永远停在第一次命中。
3. **双向扫描变体**：从左向右找**第一个**质数（找到即停）得 `first`，从右向左找**第一个**质数得 `last`。最坏复杂度不变，平均只扫两端一小段，且连哨兵都不需要——「首尾各取极值」的思想在代码上还有这层更直接的投影。
4. **「两个质数可相同」落在哪**：合法选取是 $(\text{first}, \text{last})$ 且允许相等。只有一个质数时 $\text{first} = \text{last}$，公式自然给出 $0$；如果题目硬性要求 $i \ne j$，则该情形变为无解，需要另行特判——本题为「不一定不同」，恰免去了这层讨论。
5. **保证至少一个质数的用处**：`first` 必然被赋值，`last - first` 不会是「垃圾值 − 垃圾值」；若去掉这条保证，需在扫描后检查 `first == -1` 返回无解标记。

## 5. 正确性证明

**引理 1**（试除判素的等价性）：对整数 $x \ge 2$，$x$ 是合数，当且仅当存在 $d$ 满足 $2 \le d \le \lfloor\sqrt{x}\rfloor$ 且 $d \mid x$。

**证明**：（⇐）若存在这样的 $d$，则 $x = d \cdot (x/d)$ 且 $1 < d < x$，故 $x$ 是合数。（⇒）设 $x$ 合数，写 $x = ab$，$1 < a \le b < x$。若 $a > \sqrt{x}$，则 $b \ge a > \sqrt{x}$，得 $x = ab > x$，矛盾；故 $a \le \sqrt{x}$，取 $d = a \in [2, \lfloor\sqrt{x}\rfloor]$ 即可。又 $x = 1$ 与 $x = 0$（若值域允许）被 `x < 2` 的前置判断挡下，$x \ge 2$ 的质数不满足任何 $d \mid x$，判定为真。∎

**引理 2**（距离上界）：任何一对合法选取 $(i, j)$（$\text{nums}[i]$、$\text{nums}[j]$ 均为质数，$i \le j$）满足 $j - i \le \text{last} - \text{first}$。

**证明**：$\text{first}$ 是全部质数下标的最小值、$\text{last}$ 是最大值，故 $\text{first} \le i$ 且 $j \le \text{last}$。两式相减（不等式同向相减）得 $j - i \le \text{last} - \text{first}$。∎

**引理 3**（可达性）：$(\text{first}, \text{last})$ 本身是一组合法选取，其距离恰为 $\text{last} - \text{first}$。

**证明**：$\text{nums}[\text{first}]$ 与 $\text{nums}[\text{last}]$ 都是质数；由输入保证质数存在，两下标均良定义。当 $\text{first} = \text{last}$（仅一个质数）时，由「两个质数不一定不同」条款，选同一个元素合法。∎

**定理**：算法返回值等于两个质数下标的最大距离。

**证明**：设合法距离集合 $D = \{j - i : \text{nums}[i], \text{nums}[j] \text{ 均质数},\ i \le j\}$。由引理 2，$\max D \le \text{last} - \text{first}$；由引理 3，$\text{last} - \text{first} \in D$，故 $\max D \ge \text{last} - \text{first}$；二者夹逼得 $\max D = \text{last} - \text{first}$。另一方面，一趟扫描中 `first` 只在首次命中时赋值，故其终值为最左质数下标；`last` 每次命中都被覆盖，故其终值为最右质数下标（与 $\text{first}$、$\text{last}$ 的定义一致）。引理 1 保证每次判素正确，从而算法输出恰为 $\max D$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n\sqrt{V})$，其中 $V = 100$ 为值域上界。试除版每个元素至多做 $\lfloor\sqrt{100}\rfloor - 1 = 9$ 次取模，总计约 $2.7 \times 10^6$ 次整数运算，常数极小；$V$ 视作常数时即 $O(n)$。若改用埃氏筛判素，则为预处理 $O(V\log\log V)$ + 扫描 $O(n)$，同样视作 $O(n)$。
- **空间复杂度**：$O(1)$。试除版只有 `first`、`last` 等常数个变量；筛表版为 $O(V) = 101$ 格布尔表，亦视作 $O(1)$。

## 7. 参考代码

### C++

```cpp
class Solution {
    bool isPrime(int x) {
        if (x < 2) return false;               // 1 既非质数也非合数，在这里挡下
        for (int d = 2; d * d <= x; ++d)       // 试除到 √x ≤ 10，至多 9 步
            if (x % d == 0) return false;
        return true;
    }

  public:
    int maximumPrimeDifference(vector<int>& nums) {
        int first = -1, last = -1;
        for (int i = 0; i < (int)nums.size(); ++i)
            if (isPrime(nums[i])) {
                if (first == -1) first = i;     // 哨兵：只在首次命中时定格
                last = i;                      // 每次命中都刷新
            }
        return last - first;                   // 保证至少一个质数，first 必被赋值
    }
};
```

### Python

```python
class Solution:
    def maximumPrimeDifference(self, nums: List[int]) -> int:
        def is_prime(x: int) -> bool:
            if x < 2:                          # 1 既非质数也非合数，在这里挡下
                return False
            d = 2
            while d * d <= x:                  # 试除到 √x ≤ 10，至多 9 步
                if x % d == 0:
                    return False
                d += 1
            return True

        first = last = -1
        for i, x in enumerate(nums):
            if is_prime(x):
                if first == -1:                # 哨兵：只在首次命中时定格
                    first = i
                last = i                       # 每次命中都刷新
        return last - first
```

## 8. 边界情况与易错点

1. **1 不是质数（本题最大的坑）**：试除版的 `x < 2` 天然挡下；若用埃氏筛，`isComposite[1]` 恒为 `false`（筛子只划合数），判定条件**必须**带上 $x \ge 2$，否则最左边的 1 会被当成质数把 `first` 拉错——示例 3 正是为此设计。
2. **「两个质数不一定不同」**：唯一质数时答案为 $0$，不是无解；$(\text{first}, \text{last})$ 允许相等已把它覆盖，不要画蛇添足写 `if first == last: return 0` 之类的特判（写了也不算错，但暴露没读懂公式）。
3. **「保证至少一个质数」**：`first` 必被赋值，返回值不会是垃圾差；若自己出变体题去掉这条保证，须先检查 `first == -1`。
4. **2 是唯一的偶质数**：若把试除「优化」成只试奇数 $d = 3, 5, \dots$，必须先单独判 $x = 2$，否则 2 会被误判为非质数（值域含 2，必踩）。
5. **别把建表塞进扫描循环**：若用埃氏筛，筛表在循环外建一次；写进循环内每次重建，复杂度退化成 $O(nV\log\log V)$。
6. **first / last 的更新条件不对称**：`first` 带哨兵只赋一次，`last` 无条件覆盖——两个都带哨兵或都无条件，结果分别是「last 停在首次」与「first 变成 last」，都是能过样例、WA 在大数据上的隐 bug。
7. **答案与数值无关**：距离作用在下标上，`nums[i]` 的数值只参与「是否质数」的判定，别把值也扯进距离计算。
