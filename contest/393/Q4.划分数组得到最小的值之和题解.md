# LeetCode 划分数组得到最小的值之和 题解

## 1. 题目概述

- **标题 / 题号**：划分数组得到最小的值之和（#3117，hard）
- **链接**：https://leetcode.cn/problems/minimum-sum-of-values-by-dividing-array/
- **来源**：LeetCode 第 393 场周赛 Q4
- **难度**：困难
- **标签**：位运算、动态规划、单调性、分组栈、前缀最小值

**题意**：给定长度为 $n$ 的数组 `nums` 与长度为 $m$ 的数组 `andValues`。**数组的「值」等于它的最后一个元素**。要求把 `nums` 划分为 $m$ 个**不相交的连续**子数组，第 $i$ 个子数组内所有元素的按位 AND 恰好等于 $\text{andValues}[i-1]$。返回所有合法划分中「子数组值之和」的最小值；不存在合法划分返回 $-1$。

**约束**：

- $1 \le n = \text{nums.length} \le 10^4$
- $1 \le m = \text{andValues.length} \le \min(n, 10)$
- $1 \le \text{nums}[i] < 10^5$
- $0 \le \text{andValues}[j] < 10^5$

> 💡 读题三关键：一是「值 = **组尾元素**」——不是组内最小值，组的代价在**闭合瞬间**一次性结算，这直接决定了 DP 转移形态；二是 $m$ 个子数组要**恰好铺满**整个数组（不重不漏）；三是 $m \le \min(n, 10)$——出题人明示「把 $m$ 乘进复杂度也扛得住」。另外本题按位 AND 随元素增多**只减不增**，这条单调性是全题的命脉。

> 💡 本题在本仓库另有[每日题解 3117](../../solution/3101-3200/3117_划分数组得到最小的值之和.md)：主解是**记忆化 DFS**（状态 $(i, j, \text{and})$，递归 + 哈希），扩展节给出**单调队列滑窗**版。本篇是赛场复盘视角，主打**自底向上的分层 DP + AND 分组栈**——无递归、无哈希、常数更小，与每日篇互为印证。

## 2. 示例

**示例 1**

```text
输入：nums = [1,4,3,3,2], andValues = [0,3,3,2]
输出：12

解释：唯一合法划分为 [1,4][3][3][2]：
      1 & 4 = 0；单元素组的 AND 就是它本身。
      各组值（组尾元素）之和 = 4 + 3 + 3 + 2 = 12。
```

**示例 2**

```text
输入：nums = [2,3,5,7,7,7,5], andValues = [0,7,5]
输出：17

解释：例如划分 [2,3,5][7,7,7][5]：
      各组 AND 为 0, 7, 5 全部命中，值和 = 5 + 7 + 5 = 17。
      在 7 上闭合第一组的切法（如 [2,3,5,7][7,7][5]）值和为 19。
```

**示例 3**

```text
输入：nums = [1,2,3,4], andValues = [2]
输出：-1

解释：整个数组的 AND 为 1 & 2 & 3 & 4 = 0 ≠ 2，
      连「分成一组」都做不到，返回 -1。
```

## 3. 解题思路

### 3.1 暴力思路：划分 DP 与它的 $O(n^2 m)$

划分型问题的标准起手式——定义

$$dp[j][i] = \text{前 } i \text{ 个元素恰好分成前 } j \text{ 个合法组的最小值和}$$

第 $j$ 组是某个子数组 $\text{nums}[s..i-1]$（0 下标），它的合法性条件是区间 AND 等于目标，代价是组尾元素，于是转移为：

$$dp[j][i] = \text{nums}[i-1] + \min\{\, dp[j-1][s] : \text{nums}[s] \wedge \cdots \wedge \text{nums}[i-1] = \text{andValues}[j-1] \,\}$$

边界 $dp[0][0] = 0$，答案是 $dp[m][n]$。状态数 $O(nm)$ 本身不大，问题出在转移：每个 $(j, i)$ 要枚举全部 $s \in [0, i-1]$，还要顺带算区间 AND——总量 $O(n^2 m) \approx 10^9$，必然超时。（更朴素的「在 $n-1$ 个间隙里挑 $m-1$ 刀」组合枚举则是 $\binom{9999}{9} \approx 2.7 \times 10^{30}$ 种，直接免谈。）

**卡点在哪？** 枚举 $s$ 时，绝大多数 $s$ 都是「陪跑」的——它们的区间 AND 各不相同吗？不，恰恰相反：大量 $s$ 的区间 AND **完全相同**，而同值者里我们只关心 $dp[j-1][s]$ 最小的那一个。把这条冗余压缩掉，就是本题的通关钥匙。

### 3.2 核心观察：固定右端点，子数组 AND 至多 18 种

固定右端点 $r$，记 $f_r(s) = \text{nums}[s] \wedge \cdots \wedge \text{nums}[r]$。三个环环相扣的观察：

![固定右端点时子数组 AND 的阶梯与分组](images/wc393_q4_and_groups.svg)

1. **AND 是「做减法」的运算**：往窗口里并入元素只会**清除**二进制位、绝不会置回。所以 $s$ 向左移（窗口变长）时 $f_r(s)$ 单调不增，且老值是新值的**子掩码**——$f_r$ 呈「阶梯式」下降。
2. **阶梯至多 18 级**：每出现一个严格更小的值，至少清掉原值中的一个 $1$ 位；而 $\text{nums}[r] < 10^5 < 2^{17}$ 至多 17 个 $1$ 位，故严格下降至多 17 次——**以 $r$ 结尾的子数组，AND 取值至多 $\lfloor \log_2 10^5 \rfloor + 2 = 18$ 种**。这正是 [898. 子数组按位或操作](https://leetcode.cn/problems/bitwise-ors-of-subarrays/) 的原型性质（OR 版对称成立）。
3. **同值起点连成一段**：由单调性，$\{s : f_r(s) = a\}$ 是连续区间（见 §5 引理 3）。于是 $n$ 个起点候选被折叠成 **≤ 18 个组**，每组只需保留一个数：

$$\text{best}(a) = \min\{\, dp[j-1][s] : f_r(s) = a \,\}$$

转移一步到位：若某个组的 $a$ 恰等于 $\text{andValues}[j-1]$（由严格递减，**至多命中一个组**），则 $dp[j][r+1] = \text{best}(a) + \text{nums}[r]$；否则 $dp[j][r+1] = \infty$。

### 3.3 算法流程：分组栈 + 滚动数组

剩下的工程问题是：$r$ 每右移一格，如何增量维护这 ≤ 18 个组？答案是**分组栈**——一个自栈顶（近端起点）向栈底 AND **严格递减**的列表，每步三更新：

![分组栈的增量维护三步](images/wc393_q4_stack_evolution.svg)

对第 $j$ 层（目标 $t = \text{andValues}[j-1]$）从左到右扫描 $r = 0 \dots n-1$：

1. **新组压栈顶**：起点 $s = r$ 的单元素组入栈，条目 $(\text{nums}[r],\; dp[j-1][r])$；
2. **旧组全体缩水**：栈中旧条目的 $a$ 全部 $a \,\&=\, \text{nums}[r]$（窗口统一变长一位）；
3. **相邻同值合并**：缩水后相邻条目可能出现相同 $a$，合并为一个、$\text{best}$ 取 $\min$——保持严格递减不变量。

随后在栈中查询 $a = t$：命中则 $dp[j][r+1] = \text{best} + \text{nums}[r]$；由于自顶向下严格递减，一旦 $a < t$ 即可提前 break。$m$ 层滚动做完，$dp[m][n]$ 即答案（$\infty$ 则返回 $-1$）。

### 3.4 示例演算

![示例 2 的分层填表与最优划分](images/wc393_q4_walkthrough.svg)

以示例 2（`nums = [2,3,5,7,7,7,5]`，`andValues = [0,7,5]`）走查：

- **第 1 层（目标 0）**：$[2,3,5]$ 起就能凑出 AND $= 0$，故 $dp[1][3] = 0 + 5 = 5$；继续向右并 7 仍是 0，得 $dp[1][4..6] = 7$；整段 AND 也是 0，$dp[1][7] = 5$。
- **第 2 层（目标 7）**：第 2 组可以是 $[7]$、$[7,7]$、$[7,7,7]$（7 的低三位全 1，怎么并都保持 7），接在第 1 层的 5 后面得 $dp[2][4..6] = 12$；但若把 5 也并进第 2 组，AND 变 5 ≠ 7，$dp[2][7] = \infty$。
- **第 3 层（目标 5）**：第 3 组必须从 5 起步，$dp[3][7] = dp[2][6] + 5 = 17$。

对比 17 与 19 的差别：**最优解让第一组收在小值 5 上、把大值 7 关进组内**（组内其余元素对值和「免费」）；在 7 上闭合第一组的切法值和都是 19。「最小化」的本质就是——**为每一次闭合挑最便宜的组尾**。

## 4. 算法细节

1. **状态与滚动数组**：$dp[j]$ 整层只依赖 $dp[j-1]$，用 `prev` / `cur` 两个长度 $n+1$ 的一维数组滚动，空间 $O(n)$；`prev[0] = 0`、其余 $\infty$（「前 0 个元素分成 0 组」代价为 0，非空前缀分 0 组非法）。
2. **三步合一的实现**：不必先整体缩水再合并——构建新列表时从新组起依次处理旧条目，边 `&= x` 边与列表末尾比较：同值则就地取 $\min$，异值则追加。一次遍历完成全部三步。
3. **查询提前 break**：栈内 $a$ 自顶向下严格递减，扫描时 $a = t$ 即命中返回；$a < t$ 即后面更小、直接退出。注意 $t = 0$ 时「$a < t$」永不触发（$a \ge 0$ 恒成立），命中 0 由「$a = t$」分支捕获，逻辑自洽。
4. **INF 守卫**：命中组的 $\text{best}$ 可能是 $\infty$（前驱层不可行）。C++ 中必须先判 `best < INF` 再加 `nums[r]`，否则哨兵值被反复累加而「漂移」；Python 的 `float('inf')` 加有限数仍是 `inf`，天然免疫（参考代码仍统一加了守卫，便于两语言对读）。
5. **三条路线对比**（同属 $O(n \cdot m \cdot \log U)$ 量级，仅常数与实现重量不同）：

| 路线 | 核心机制 | 特点 |
|------|----------|------|
| 记忆化 DFS | 状态 $(i, j, \text{and})$ + 哈希 + 单调剪枝 | 代码最短，思路好讲（见[每日题解](../../solution/3101-3200/3117_划分数组得到最小的值之和.md)） |
| **分组栈（本文）** | 增量维护 $(a, \text{best})$ 列表 | 无递归、无哈希、每步 $O(18)$，常数最小 |
| 稀疏表 + 二分 + 单调队列 | $O(1)$ 区间 AND 二分定位起点区间，滑窗取 $\min$ | 官方 tags（Segment Tree / Binary Search / Queue）所指，每层严格 $O(n)$，但码量大 |

## 5. 正确性证明

**引理 1（子掩码与单调性）**：固定 $r$，若 $s_1 < s_2 \le r$，则 $f_r(s_1)$ 是 $f_r(s_2)$ 的二进制子掩码；特别地 $f_r(s_1) \le f_r(s_2)$，即 $f_r$ 关于 $s$ 单调不增（$s$ 减小方向）。

**证明**：$f_r(s_1) = f_r(s_2) \wedge (\text{nums}[s_1] \wedge \cdots \wedge \text{nums}[s_2 - 1])$。按位 AND 只会清除位、不会置位，故 $f_r(s_1)$ 的每个 1 位在 $f_r(s_2)$ 中都是 1，即子掩码关系成立。∎

**引理 2（值域稀疏）**：$\{\,f_r(s) : 0 \le s \le r\,\}$ 至多 $\lfloor \log_2 U \rfloor + 2 = 18$ 个不同值（$U = 10^5$）。

**证明**：让 $s$ 从 $r$ 出发向左移动，$f_r(s)$ 构成不增序列。每次出现严格更小的值，新值是老值的真子掩码，至少比老值少一个 1 位；初始 $\text{nums}[r] < 2^{17}$ 至多 17 个 1 位，故至多严格下降 17 次，连同初始值至多 18 种取值。∎

**引理 3（同值连续性）**：对任意 $a$，集合 $S_a = \{\, s : f_r(s) = a \,\}$ 若非空则是连续区间。

**证明**：设 $s_1 < s_2 < s_3$ 且 $s_1, s_3 \in S_a$。由引理 1（取「$s$ 增大」方向的不等式 $f_r(s_1) \le f_r(s_2) \le f_r(s_3)$），$a \le f_r(s_2) \le a$，故 $s_2 \in S_a$。凸性即区间性。∎

**引理 4（栈不变量）**：第 $j$ 层扫描中，处理完位置 $r$ 后，分组栈恰由所有不同的 $f_r(s)$ 值各贡献一个条目 $\bigl(a,\ \min\{dp[j-1][s] : f_r(s) = a\}\bigr)$ 组成，且自栈顶向栈底严格递减。

**证明**：对 $r$ 归纳。层内首个位置 $r_0$ 时栈仅含 $(\text{nums}[r_0], dp[j-1][r_0])$，对应唯一起点，成立。设 $r$ 处成立，考察 $r + 1$（记 $x = \text{nums}[r+1]$）：新起点 $s = r+1$ 的条目按第 1 步压栈；对旧起点 $s \le r$，$f_{r+1}(s) = f_r(s) \wedge x$，故 $\{s \le r : f_{r+1}(s) = a\}$ 是若干个**相邻**旧同值区间的并（旧值相同的 $s$ 缩水后仍相同；旧值不同但缩水后相同的，由引理 1 的子掩码链性质只能出现在栈中相邻位置），其 $dp[j-1]$ 最小值恰为各成员最小值的 $\min$——与第 2、3 步「全体缩水 + 相邻合并取 $\min$」完全一致。缩水与并入 $x$ 均保持「越靠栈底值越小」（子掩码关系传递），合并相邻同值后严格递减。∎

**定理**：算法结束时 $dp[m][n]$ 等于合法划分的最小值和；无合法划分时为 $\infty$（返回 $-1$）。

**证明**：对 $j$ 归纳证明：$dp[j][i]$ 是「前 $i$ 个元素恰好分成前 $j$ 个合法组」的最小值和（不可行为 $\infty$）。$j = 0$ 时仅 $dp[0][0] = 0$，成立。设第 $j-1$ 层正确。任一上述划分唯一分解为「前 $s$ 个元素分成前 $j-1$ 组」加「第 $j$ 组 $\text{nums}[s..i-1]$」，后者合法当且仅当 $f_{i-1}(s) = \text{andValues}[j-1]$、代价为 $dp[j-1][s] + \text{nums}[i-1]$（值为组尾）。故

$$dp[j][i] = \text{nums}[i-1] + \min\{\, dp[j-1][s] : f_{i-1}(s) = \text{andValues}[j-1] \,\}$$

由引理 4，扫描到 $r = i-1$ 后栈中恰有每个 $f_{i-1}$ 值对应的 $\min\{dp[j-1][s]\}$，查询命中的条目正是上式右端（无命中则该 AND 值不出现于任何起点，$\min$ 为空集，$dp[j][i] = \infty$）。归纳完成，取 $j = m,\ i = n$ 即得。∎

## 6. 复杂度分析

- **时间复杂度**：$O\bigl(n \cdot m \cdot (\lfloor \log_2 U \rfloor + 2)\bigr) \approx 10^4 \times 10 \times 18 = 1.8 \times 10^6$。每层对每个 $r$ 做一次 $O(18)$ 的栈维护（缩水、合并）与一次 $O(18)$ 的查询，共 $m$ 层。
- **空间复杂度**：$O(n)$。两个滚动数组各 $n+1$，分组栈至多 18 项；不计输入。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int minimumValueSum(vector<int>& nums, vector<int>& andValues) {
        const int n = nums.size(), m = andValues.size();
        constexpr long long INF = LLONG_MAX / 4;
        vector<long long> prev(n + 1, INF);       // 第 0 层：空前缀代价 0，其余不可行
        prev[0] = 0;

        for (int j = 1; j <= m; ++j) {
            const int target = andValues[j - 1];
            vector<long long> cur(n + 1, INF);
            vector<pair<int, long long>> groups;  // (and 值, best)，自栈顶向栈底严格递减

            for (int r = 0; r < n; ++r) {
                const int x = nums[r];
                vector<pair<int, long long>> merged;
                merged.emplace_back(x, prev[r]);            // ① 新组压栈顶：起点 s = r
                for (auto& [a, b] : groups) {               // ② 旧组全体缩水 + ③ 相邻同值合并
                    int a2 = a & x;
                    if (a2 == merged.back().first)
                        merged.back().second = min(merged.back().second, b);
                    else
                        merged.emplace_back(a2, b);
                }
                groups = move(merged);

                for (auto& [a, b] : groups) {               // 查询：至多一个组命中目标
                    if (a == target) {
                        if (b < INF) cur[r + 1] = b + x;    // INF 守卫：不可行不累加组尾
                        break;
                    }
                    if (a < target) break;                  // 严格递减，后面不可能再命中
                }
            }
            prev = move(cur);
        }
        return prev[n] >= INF ? -1 : (int)prev[n];
    }
};
```

### Python

```python
class Solution:
    def minimumValueSum(self, nums: List[int], andValues: List[int]) -> int:
        n, m = len(nums), len(andValues)
        INF = float('inf')
        prev = [0] + [INF] * n                  # 第 0 层：空前缀代价 0，其余不可行

        for j in range(1, m + 1):
            target = andValues[j - 1]
            cur = [INF] * (n + 1)
            groups = []                         # [and 值, best]，自栈顶向栈底严格递减

            for r in range(n):
                x = nums[r]
                merged = [[x, prev[r]]]         # ① 新组压栈顶：起点 s = r
                for a, b in groups:             # ② 旧组全体缩水 + ③ 相邻同值合并
                    a &= x
                    if a == merged[-1][0]:
                        merged[-1][1] = min(merged[-1][1], b)
                    else:
                        merged.append([a, b])
                groups = merged

                for a, b in groups:             # 查询：至多一个组命中目标
                    if a == target:
                        if b < INF:
                            cur[r + 1] = b + x  # INF 守卫：不可行不累加组尾
                        break
                    if a < target:              # 严格递减，后面不可能再命中
                        break

            prev = cur

        return -1 if prev[n] == INF else prev[n]
```

> ⚠️ 两版代码已对三个示例及 3000 组随机用例（与暴力枚举切点对拍）验证一致；$n = 10^4, m = 10$ 的最坏规模下 Python 约 0.1 秒。

## 8. 边界情况与易错点

1. **「值 = 组尾元素」**：不是组内最小值、也不是组内任意值。转移里 `+ nums[r]` 只出现在闭合时刻，组内其余元素零贡献——示例 2 的 17 vs 19 全靠这一点。
2. **INF 漂移（C++ 头号坑）**：命中组的 `best` 可能是哨兵 $\infty$，直接 `best + x` 会让 $\infty$ 逐层膨胀、污染「不可行」判定（`long long` 下不至于溢出，但等于放弃了哨兵语义）；必须先判 `b < INF`。
3. **新组必须压栈顶**：分组栈的「自顶向下严格递减」不变量依赖「最近的起点 AND 最大」。若把新组插到栈底，缩水与合并的相邻性全部失效，答案错乱。
4. **提前 break 的比较符**：是 `a < target` 才 break，`a == target` 是命中分支；写成 `a <= target` 会在命中前一瞬错杀唯一答案。
5. **答案上界与整型**：$m = n$ 时值和为 $\sum \text{nums}[i] \le 10^4 \times (10^5 - 1) < 10^9$，`int` 勉强装得下但余量极小，C++ 建议直接 `long long` 存 DP。
6. **$m = 1$ 与 $m = n$**：前者要求整段 AND 等于 $\text{andValues}[0]$（示例 3 的 $-1$ 就死在这里）；后者每组单元素，等价于逐位对表 `nums[i] == andValues[i]`，算法自动覆盖，无需特判。
7. **第 0 层初始化**：`prev[0] = 0`、其余 $\infty$。若把整层初始化成 0，任何「前 $i > 0$ 个元素分 0 组」的非法前缀都会以 0 代价混进后续转移。

- [LeetCode 410. 分割数组的最大值](https://leetcode.cn/problems/split-array-largest-sum/)：「分成 $m$ 段连续子数组」的祖师爷，二分 / DP 双解模板，对比本题「代价 = 组尾」的更简结算。
- [LeetCode 2871. 将数组分割成最多数目的子数组](https://leetcode.cn/problems/split-array-into-maximum-number-of-subarrays/)：同样是 AND 约束下切分数组，反向问最少代价，贪心视角。
- [LeetCode 2464. 有效分割中的最少子数组数目](https://leetcode.cn/problems/minimum-subarrays-in-a-valid-split/)：把 AND 换成 gcd 的条件分组——gcd 随元素增多同样单调不增，套路可迁移。
- [每日题解 3117. 划分数组得到最小的值之和](../../solution/3101-3200/3117_划分数组得到最小的值之和.md)：同一道题的记忆化搜索主解与单调队列滑窗扩展，含「OR / XOR 能否照搬」的讨论，与本文互为印证。

**延伸思考**：若把按位 AND 换成 **OR**，单调性反向（只增不减），分组栈改维护「自顶向下严格递增」即可，结论照搬；换成 **gcd** 同样单调不增，合并时 `gcd` 代替 `&`，组数上界变为约数链长度；但换成 **XOR** 则单调性与「每步至少消一位」双双失效，候选 AND 值不再稀疏，需要另起炉灶（例如按位拆点建图）。另一个方向：若允许 $m$ 增大到 $n$ 量级，$O(n \cdot m \cdot \log U)$ 退化为 $O(n^2 \log U)$——此时要么利用 $\text{andValues}$ 的内部结构，要么接受平方级并转向 bitset / 分块优化。
