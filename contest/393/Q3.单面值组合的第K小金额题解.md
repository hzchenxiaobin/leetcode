# LeetCode 单面值组合的第 K 小金额 题解

## 1. 题目概述

- **标题 / 题号**：单面值组合的第 K 小金额（#3116，hard）
- **链接**：https://leetcode.cn/problems/kth-smallest-amount-with-single-denomination-combination/
- **来源**：LeetCode 第 393 场周赛 Q3
- **难度**：困难
- **标签**：二分查找、数学、容斥原理、数论、位运算、组合数学

**题意**：给定两两不同的面额数组 `coins` 与整数 `k`。每种面额的硬币无限量，但**一次只能用一种面额**——可制造的金额恰是「某个面额的正整数倍」。把所有可制造金额**去重**后从小到大排序，返回第 `k` 个。

**约束**：

- $1 \le \text{coins.length} \le 15$
- $1 \le \text{coins}[i] \le 25$
- $1 \le k \le 2 \times 10^9$
- `coins` 包含两两不同的整数

> 💡 读题关键：三条约束各埋一条线索。$n \le 15$ 直指 $2^n$ 子集枚举（容斥的标配规模）；$\text{coins}[i] \le 25$ 保证任意子集的 $\mathrm{lcm}$ 不超过 $\mathrm{lcm}(1..25) \approx 2.7 \times 10^{10}$，64 位整数装得下；$k \le 2 \times 10^9$ 一巴掌拍死所有「逐个取最小」的做法，逼你转向值域二分。另外咬文嚼字一句：「**不能**组合使用不同面额」意味着金额集合是若干「倍数集合」的**并集**，而不是子集和——这正是容斥原理能入场的前提。

## 2. 示例

**示例 1**

```text
输入：coins = [3, 6, 9], k = 3
输出：9
解释：6 的倍数、9 的倍数都是 3 的倍数，并集仍是 3 的倍数。
      去重后为 3, 6, 9, 12, 15, …，第 3 个是 9。
```

**示例 2**

```text
输入：coins = [5, 2], k = 7
输出：12
解释：5 的倍数：5, 10, 15, …；2 的倍数：2, 4, 6, 8, 10, 12, …
      合并去重：2, 4, 5, 6, 8, 10, 12, 14, 15, …，第 7 个是 12。
```

**示例 3（补充：整除关系下的退化）**

```text
输入：coins = [3, 6, 9], k = 4
输出：12
解释：金额集合仍是 3 的倍数，第 4 个是 12。
      倍数关系的面值不产生新金额（A₆ ⊆ A₃），容斥会自动把它们的贡献抵消掉。
```

## 3. 解题思路

### 3.1 暴力思路

**多路归并**：把每个面额的倍数看成一条有序链表，多路归并弹出第 $k$ 小。$k$ 高达 $2 \times 10^9$，每轮 $O(n)$ 选当前最小也要 $O(nk) \approx 3 \times 10^{10}$ 次，必然超时。

**最小堆 + 哈希去重**：堆中维护「下一枚弹出的金额」，弹出 $k$ 次即为答案。同样要弹 $k$ 次，且金额在值域低段非常密集（去重集合爆炸），时间空间都不可行。

两种做法死于同一点：**答案的「名次」巨大，而「数值」本身相对可控**（不超过 $k \times \min(\text{coins}) \le 5 \times 10^{10}$，二分只需 $\log_2 5 \times 10^{10} \approx 36$ 轮）。这类「$k$ 巨大的第 $k$ 小」问题的标准反制是——**值域二分 + 快速计数**。

### 3.2 核心观察：容斥原理快速计算 count(x)

定义 $\mathrm{count}(x) = $ 不超过 $x$ 的**可制造金额个数**。只要能快速算出 $\mathrm{count}(x)$，再配合它的单调性，二分就能定位答案。

单个面额 $c$ 的金额集合 $A_c = \{c, 2c, 3c, \dots\}$，其中不超过 $x$ 的有 $\lfloor x/c \rfloor$ 个。但多个面额的倍数集**互相重叠**（10 既是 2 的倍数又是 5 的倍数），直接相加会重复计数——这正是**容斥原理**的经典战场：

$$\mathrm{count}(x) = \sum_{\varnothing \ne S \subseteq \text{coins}} (-1)^{|S|+1} \left\lfloor \frac{x}{\mathrm{lcm}(S)} \right\rfloor$$

> 💡 为什么是 $\mathrm{lcm}$：若干倍数集合的**交集**是「公倍数」的集合——同时被 $a$、$b$ 整除 $\iff$ 被 $\mathrm{lcm}(a,b)$ 整除。而「不超过 $x$ 的 $L$ 的倍数」恰好 $\lfloor x/L \rfloor$ 个，计数免费。

![容斥原理：两个倍数集合的并去重计数](images/wc393_q3_inclusion_exclusion.svg)

由 $n \le 15$，非空子集至多 $2^{15} - 1 = 32767$ 个。预处理每个子集的 $\mathrm{lcm}$ 与符号 $(-1)^{|S|+1}$ 之后，一次 $\mathrm{count}(x)$ 只需 32767 次整数除法——"快速计数"达成。

### 3.3 算法流程：值域二分

$\mathrm{count}(x)$ 是若干 $\lfloor x/L \rfloor$ 之和，每一项都单调不减，故 $\mathrm{count}$ 单调不减——「$\mathrm{count}(x) \ge k$」在值域上**前缀成立**，可以二分最小达标点。

![值域二分：台阶图上找最小达标 x](images/wc393_q3_binary_search.svg)

流程四步：

1. **预处理子集**：枚举 $\text{mask} = 1 \dots 2^n - 1$，对每个非空子集 $S$ 累积求出 $\mathrm{lcm}(S)$，符号按 $|S|$ 的奇偶取 $+1/-1$；
2. **计数函数**：$\mathrm{count}(x) = \sum \text{sign}_S \cdot \lfloor x / \mathrm{lcm}(S) \rfloor$；
3. **二分**：$[\,1,\ k \times \min(\text{coins})\,]$ 上找最小的 $x$ 使 $\mathrm{count}(x) \ge k$；
4. **返回** $x$：由「落点引理」（见 §5 引理 3），最小达标 $x$ 必是某面额的倍数，直接就是答案，**无需任何后处理**。

上界为何取 $k \times \min(\text{coins})$：$\min(\text{coins})$ 自身的前 $k$ 个倍数 $1 \cdot c_{\min}, 2 \cdot c_{\min}, \dots, k \cdot c_{\min}$ 互不相同且都不超过 $k \cdot c_{\min}$，故右端处 $\mathrm{count} \ge k$ 必成立，答案必落在区间内。

### 3.4 示例演算

![示例演算：coins=[5,2], k=7 的子集表、二分过程与验证](images/wc393_q3_walkthrough.svg)

以 $\text{coins} = [5, 2]$，$k = 7$ 完整走查（见上图）：

- **子集表**：三个非空子集给出 $(5, +1)$、$(2, +1)$、$(10, -1)$，即 $\mathrm{count}(x) = \lfloor x/5 \rfloor + \lfloor x/2 \rfloor - \lfloor x/10 \rfloor$；
- **二分 4 轮**：区间 $[1, 14]$ 收敛——$\mathrm{mid}=7$ 时 $\mathrm{count}=4$ 拉高 $lo$；$\mathrm{mid}=11$ 时 $\mathrm{count}=6$ 继续拉高；$\mathrm{mid}=13$、$\mathrm{mid}=12$ 时 $\mathrm{count}=7 \ge 7$ 压低 $hi$，最终 $lo = hi = 12$；
- **验证**：$\le 12$ 的可制造金额 $\{2,4,5,6,8,10,12\}$ 恰好 7 个，第 7 个正是 12。∎

## 4. 算法细节

1. **子集 $\mathrm{lcm}$ 的预处理**：按 `mask` 从 $1$ 到 $2^n - 1$ 枚举，对 `mask` 内每个面值累积 $\mathrm{lcm}$，同时用 `__builtin_popcount` / 二进制中 1 的个数定符号，总量 $O(2^n \cdot n) \approx 4.9 \times 10^5$；
2. **64 位整数（C++ 头号坑）**：答案上界 $k \cdot c_{\min} \le 2 \times 10^9 \times 25 = 5 \times 10^{10}$；子集 $\mathrm{lcm}$ 上界 $\mathrm{lcm}(1..25) = 26771144400 \approx 2.7 \times 10^{10}$。两者都远超 `int`（约 $2.1 \times 10^9$），`lcm`、二分边界全部用 `long long`，且 $(\text{long long})k \times c_{\min}$ 的**显式转型别忘**；
3. **$\min$ 要真的取 $\min$**：`coins` 不保证有序，上界写 $k \times \text{coins}[0]$ 是隐 bug；直接写死 $k \times 25$ 也正确但更松；
4. **$\mathrm{lcm}$ 的求法**：$\mathrm{lcm}(a,b) = a / \gcd(a,b) \times b$，先除后乘防中间溢出（C++17 `std::lcm`、Python `math.lcm` 已内置）；若先乘后除，$25^{15}$ 级别的中间值在进入 `long long` 前就已溢出；
5. **按 $\mathrm{lcm}$ 合并符号（常数优化，不改也对）**：用哈希表把相同 $\mathrm{lcm}$ 的符号累加，净符号为 0 的项删除。例如 $[3,6,9]$：$\mathrm{lcm}=6$ 上 $\{6\}$ 的 $+1$ 与 $\{3,6\}$ 的 $-1$ 抵消，$\mathrm{lcm}=9$ 同理，$\mathrm{lcm}=18$ 上 $\{6,9\}$ 与 $\{3,6,9\}$ 抵消，最终 7 项塌缩成 $\mathrm{count}(x) = \lfloor x/3 \rfloor$ 一项。容斥本身会自动抵消，去重只是让二分判定更快；
6. **冗余面值的观察**：若某面值是另一面值的倍数，它对并集毫无贡献（$A_6 \subseteq A_3$），可安全删除。但别指望它降复杂度——删完后仍可能剩 15 个互不整除的面值（如 15 个不同质数）。

## 5. 正确性证明

**引理 1**（交集 = 公倍数集合）：设 $A_m = \{m, 2m, 3m, \dots\}$，对非空子集 $S \subseteq \text{coins}$ 有

$$\bigcap_{c \in S} A_c = A_{\mathrm{lcm}(S)}$$

**证明**：$x \in \bigcap_{c \in S} A_c \iff$ 每个 $c \in S$ 都整除 $x$ $\iff$ $\mathrm{lcm}(S)$ 整除 $x$（$\mathrm{lcm}$ 是各 $c$ 的公倍数中最小者，且整除每一个公倍数）$\iff x \in A_{\mathrm{lcm}(S)}$。∎

**引理 2**（容斥计数公式）：$\displaystyle \mathrm{count}(x) = \sum_{\varnothing \ne S \subseteq \text{coins}} (-1)^{|S|+1} \left\lfloor \frac{x}{\mathrm{lcm}(S)} \right\rfloor$。

**证明**：由引理 1，$\lfloor x/\mathrm{lcm}(S) \rfloor = |A_{\mathrm{lcm}(S)} \cap [1,x]| = \left|\bigcap_{c \in S} (A_c \cap [1,x])\right|$。对每个 $m \in [1, x]$，设 $D(m) = \{c \in \text{coins} : c \mid m\}$，则 $m$ 在右式中被计入的净次数为 $\sum_{\varnothing \ne S \subseteq D(m)} (-1)^{|S|+1}$。若 $D(m) = \varnothing$，该和为 $0$；否则记 $t = |D(m)| \ge 1$，由二项式恒等式 $\sum_{j=1}^{t} \binom{t}{j} (-1)^{j+1} = 1 - (1-1)^t = 1$，净次数恰为 $1$。于是右式 $= \#\{m \le x : m \text{ 是某面值的倍数}\} = \mathrm{count}(x)$。∎

**引理 3**（落点引理）：使 $\mathrm{count}(x) \ge k$ 成立的最小整数 $x_0$ 必是某面值的倍数。

**证明**：反设 $x_0$ 不是任何面值的倍数，则对每个 $c$ 都有 $x_0 \notin A_c$，从而 $A_c \cap [1, x_0] = A_c \cap [1, x_0 - 1]$。于是 $\mathrm{count}(x_0) = \mathrm{count}(x_0 - 1) \ge k$，与 $x_0$ 的最小性矛盾。∎

**定理**：二分返回值等于第 $k$ 小的可制造金额 $a_k$。

**证明**：**（区间合法性）** $c_{\min}$ 的前 $k$ 个倍数互不相同且均 $\le k \cdot c_{\min}$，故 $\mathrm{count}(k \cdot c_{\min}) \ge k$，即区间 $[1, k \cdot c_{\min}]$ 的右端达标；又 $\mathrm{count}$ 单调不减（引理 2 右式中每项都单调不减），「$\ge k$」呈前缀成立，二分正确收敛到区间内最小达标点 $x_0$。**（$x_0 = a_k$）** 可制造金额序列 $a_1 < a_2 < \dots < a_k$ 中，严格小于 $a_k$ 的恰有 $k - 1$ 个，故 $\mathrm{count}(a_k - 1) = k - 1 < k$；又 $a_1, \dots, a_k$ 均 $\le a_k$，得 $\mathrm{count}(a_k) \ge k$。于是 $a_k$ 是达标点，且一切 $x < a_k$ 由单调性有 $\mathrm{count}(x) \le \mathrm{count}(a_k - 1) < k$，均不达标，故 $x_0 = a_k$。引理 3 进一步印证 $a_k$ 本身就是可制造金额，无需后处理。∎

## 6. 复杂度分析

- **时间复杂度**：$O\!\left(2^n \cdot \left(n + \log(k \cdot c_{\min})\right)\right)$。预处理子集 $\mathrm{lcm}$ 为 $O(2^n \cdot n) \approx 4.9 \times 10^5$；二分 $\log_2(5 \times 10^{10}) \approx 36$ 轮，每轮 $2^{15} - 1 = 32767$ 次除法约 $1.2 \times 10^6$ 次。总计约 $1.7 \times 10^6$ 次基本运算，瞬间完成。
- **空间复杂度**：$O(2^n)$。存每个非空子集的 $(\mathrm{lcm}, \mathrm{sign})$，$n = 15$ 时 32767 项。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    long long findKthSmallest(vector<int>& coins, int k) {
        const int n = coins.size();
        vector<long long> lcms;     // 每个非空子集的 lcm
        vector<int> sign;           // 符号 (-1)^(|S|+1)
        lcms.reserve(1 << n);
        sign.reserve(1 << n);
        for (int mask = 1; mask < (1 << n); ++mask) {
            long long L = 1;        // lcm 上界 lcm(1..25)≈2.7e10，必须 64 位
            int cnt = 0;
            for (int i = 0; i < n; ++i)
                if (mask >> i & 1) {
                    L = lcm(L, (long long)coins[i]);
                    ++cnt;
                }
            lcms.push_back(L);
            sign.push_back(cnt & 1 ? 1 : -1);
        }

        long long lo = 1, hi = (long long)k * *min_element(coins.begin(), coins.end());
        while (lo < hi) {
            long long mid = lo + (hi - lo) / 2;
            long long c = 0;
            for (int i = 0; i < (int)lcms.size(); ++i)
                c += sign[i] * (mid / lcms[i]);     // 容斥计数 count(mid)
            if (c >= k) hi = mid;
            else        lo = mid + 1;
        }
        return lo;                  // 落点必是某面值的倍数，直接返回
    }
};
```

### Python

```python
from math import lcm

class Solution:
    def findKthSmallest(self, coins: List[int], k: int) -> int:
        n = len(coins)
        lcms, signs = [], []
        for mask in range(1, 1 << n):
            L, bits = 1, 0
            for i in range(n):
                if mask >> i & 1:
                    L = lcm(L, coins[i])    # lcm 上界约 2.7e10，Python 天然大整数
                    bits += 1
            lcms.append(L)
            signs.append(1 if bits % 2 else -1)

        lo, hi = 1, k * min(coins)          # min 的前 k 个倍数 ≤ k·min，右端必达标
        while lo < hi:
            mid = (lo + hi) // 2
            cnt = sum(s * (mid // L) for s, L in zip(signs, lcms))
            if cnt >= k:
                hi = mid
            else:
                lo = mid + 1
        return lo                            # 落点必是某面值的倍数，直接返回
```

## 8. 边界情况与易错点

1. **`int` 溢出（C++ 头号坑）**：答案上界 $5 \times 10^{10}$、子集 $\mathrm{lcm}$ 上界 $2.7 \times 10^{10}$，都远超 `int`。`lcm` 变量、二分边界必须 `long long`；`(long long)k * c_min` 若漏转型，$2 \times 10^9 \times 25$ 在 `int` 域内先乘后赋照样 UB。
2. **上界误用 `coins[0]`**：数组无序，`coins[0]` 不是最小面值，必须 `*min_element` / `min(coins)`。
3. **先乘后除求 `lcm`**：$\mathrm{lcm}(a,b) = a / \gcd(a,b) \times b$ 的顺序不能反，否则中间值溢出。
4. **空子集混入**：`mask` 必须从 1 起枚举；若把空集也按符号 $+1$ 计入 $\lfloor x/1 \rfloor$，整个计数整体偏大，样例都过不了。
5. **容斥符号写反**：$|S|$ **奇数取加、偶数取减**。写反后在「重叠多」的用例（如 $[2, 4]$）上必错，在「互质」用例（如 $[2, 5]$）上却照常正确——样例测不出来，最危险。
6. **不要「对齐到倍数」**：担心二分返回非倍数、再手动向下取整——落点引理保证返回值本来就是倍数；画蛇添足的一步反而会把 $[2, 4], k{=}1$（答案 2，二分返回 2，"对齐"后仍是 2）之外的密集用例如 $[2, 3], k{=}4$（答案 6）算错成 4 之类的怪值。
7. **面值 1 出现**：一切正整数都可制造，答案就是 $k$ 本身；公式自动成立（1 与其他面值的 $\mathrm{lcm}$ 即该面值，容斥仍精确），无需特判，但可作为自测用例。
8. **Python 版本**：`math.lcm` 需 3.9+（LeetCode 环境满足）；旧环境写 `a // gcd(a, b) * b`。
