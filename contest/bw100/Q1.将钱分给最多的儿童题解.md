# LeetCode 将钱分给最多的儿童 题解

## 1. 题目概述

- **标题 / 题号**：将钱分给最多的儿童（#2591，easy）
- **链接**：https://leetcode.cn/problems/distribute-money-to-maximum-children/
- **来源**：LeetCode 第 100 场双周赛 Q1
- **难度**：简单
- **标签**：贪心、数学

**题意**：把 $money$ 美元分给 $children$ 个儿童，规则：所有钱必须分完；每人至少 1 美元；**没有人恰好拿到 4 美元**。在满足规则的前提下，最大化**恰好拿到 8 美元**的人数；不存在任何合法分配时返回 $-1$。

**约束**：

- $1 \le money \le 200$
- $2 \le children \le 30$

## 2. 示例

**示例 1**

```text
输入：money = 20, children = 3
输出：1
解释：[8, 9, 3]：1 人拿 8。任何方案都无法让 2 人各拿 8（会剩 20−16=4 给最后一人，违规）。
```

**示例 2**

```text
输入：money = 16, children = 2
输出：2
解释：[8, 8]，两人都恰好 8 美元。
```

**示例 3（边界补充）**

```text
输入：money = 12, children = 2
输出：0
解释：[8,4] 违规（4 被禁）；[3,9] 合法但无人拿 8。
```

## 3. 解题思路

### 3.1 暴力思路

从小规模打表观察（或直接写搜索：把 $money$ 分成 $children$ 个 $\ge 1$ 且 $\ne 4$ 的部分，最大化"恰好 8"的个数），能发现规律。由于 $children \le 30$、$money \le 200$，记忆化搜索完全可以当对拍暴力；但正解只需**一次到位的分类讨论**。

### 3.2 核心观察：先垫底、再冲 8、算清余数

![分类决策流程图](images/bw100_q1_flow.svg)

把问题拆成三层约束：

1. **可行性**：每人至少 1 美元 → $money \ge children$，否则 $-1$。
2. **"恰好 8"的成本**：先每人发 1 美元（剩余 $extra = money - children \ge 0$），再让某个孩子**恰好** 8 就要**再**发 7 美元，所以 8 美元档的人数上界为 $q = \min(\lfloor extra / 7 \rfloor,\ children)$。
3. **余数陷阱**：让 $q$ 个人各拿 8 后，剩 $leftover = extra - 7q \in [0, 6]$ 美元要塞给其余 $children - q$ 个"每人才垫了 1 美元"的孩子，而**没有任何人能拿到 4 美元**：

![陷阱：最后一人被迫拿到 4 美元](images/bw100_q1_trap.svg)

- 若恰好**只剩 1 个孩子**（$children - q = 1$）且 $leftover = 3$：他被迫拿 $1 + 3 = 4$ 美元 → 该档位违规，**答案退一档为 $q - 1$**；
- 其余情形余数总能合法消化（见 §5 引理 1），答案就是 $q$。

另外还有 $q = children$（人人想拿 8）的分支：$extra = 7 \cdot children$ 时人人 8；$extra$ 更大时多出的钱只能塞给某人（他从 8 变成 $>8$），答案退到 $children - 1$。

### 3.3 算法流程

```text
1. 若 money < children → 返回 −1
2. extra = money − children；q = min(extra // 7, children)
3. 若 q == children：
       extra == 7*children → 返回 children      # 人人恰好 8
       否则              → 返回 children − 1   # 多余的钱必然砸破一个 8
4. leftover = extra − 7q
   若 children − q == 1 且 leftover == 3 → 返回 q − 1   # 1+3=4 陷阱
   否则 → 返回 q
```

### 3.4 示例演算

![示例演算：money=20, children=3](images/bw100_q1_walkthrough.svg)

**示例 1**（$20, 3$）：$extra = 17$，$q = \min(\lfloor 17/7 \rfloor, 3) = 2$，$leftover = 17 - 14 = 3$，$children - q = 1$ → 踩中陷阱 → $q - 1 = 1$ ✓。两个"8"意味着最后一人拿 $1+3=4$ 违规；改成 $[8, 9, 3]$ 只有 1 人拿 8。

**示例 2**（$16, 2$）：$extra = 14 = 7 \times 2$，$q = 2 = children$ 且 $extra = 7 \cdot children$ → 返回 $2$ ✓。

**示例 3**（$12, 2$）：$extra = 10$，$q = 1$，$leftover = 3$，只剩 1 人 → 返回 $0$ ✓（$[8,4]$ 违规，$[3,9]$ 合法）。

## 4. 算法细节

1. **为什么"每人先垫 1"是好视角**：把"每人 $\ge 1$"的硬约束一次消化掉，剩下的钱自由分配，讨论面大幅缩小。
2. **$q$ 的双重上界**：$\lfloor extra/7 \rfloor$ 是钱数限制，$children$ 是人数限制，取 min。
3. **$q = children$ 的分支不能漏**：$extra \ge 7 \cdot children$ 时"人人都拿 8"未必成立——除非 $extra$ 恰好等于 $7 \cdot children$，否则多出的钱必须砸在某个人头上破坏其"恰好 8"。
4. **陷阱的本质**：是"剩余 $leftover = 3$ 且只有一个垫底孩子"——$1+3=4$ 恰好撞上禁取值。注意 $leftover = 4$ 时那孩子拿 $1 + 4 = 5$，**没有**问题，别把陷阱记成"余 4"。
5. **数据规模**：全程 32 位整数即可，无溢出。

## 5. 正确性证明

**引理 1（固定档位数的可行性）**：设 $q$ 为目标"恰好 8"人数（$0 \le q \le children$）。记 $r = children - q$（不拿 8 的人数）、$L = money - 8q$（留给这 $r$ 人的钱）。当 $q < children$（$r \ge 1$）时，存在满足"这 $q$ 人恰好 8、其余 $r$ 人每人 $\ge 1$、无人取 4"的分配，当且仅当 $L \ge r$ 且**不是**（$r = 1$ 且 $L = 4$）。

**证明**：($\Rightarrow$) 总额约束给出 $L = \sum_{r \text{ 人}} \ge r$；若 $r=1$，唯一的孩子拿 $L$，$L=4$ 与"无人拿 4"矛盾。($\Leftarrow$) 构造：$r = 1$ 时该孩子拿 $L \ge 1$ 且 $L \ne 4$，合法。$r \ge 2$ 时：若 $L - r \ne 3$，给一个孩子发 $1 + (L - r)$、其余各发 $1$，唯一可能违规是 $1 + (L-r) = 4$ 即 $L - r = 3$，已排除；若 $L - r = 3$，改为发 $3, 2, 1, \dots, 1$（和为 $r + 3 = L$，$r \ge 2$ 保证 3、2 各有一人），无 4，合法。∎

**引理 2（档位单调回退）**：若某个 $q \ge 1$ 可行，则 $q - 1$ 也可行。

**证明**：把一个"恰好 8"的孩子退出该档：设 $q$ 档可行分配存在，看 $q - 1$ 档的参数 $r' = r + 1 \ge 2$、$L' = L + 8 \ge r + 8 > r'$，由引理 1 的 $r \ge 2$ 分支直接构造可行分配。∎

**定理（算法正确）**：设 $q^* = \min(\lfloor extra/7 \rfloor, children)$。答案为：$q^* = children$ 时按 $extra$ 是否等于 $7 \cdot children$ 取 $children$ 或 $children-1$；否则除陷阱情形（$children - q^* = 1$ 且 $leftover = 3$）取 $q^* - 1$ 外，其余取 $q^*$。

**证明**：**上界**：$q$ 个孩子恰好 8 需 $8q$ 美元，其余 $children - q$ 人至少 $children - q$ 美元，故 $money \ge 8q + (children - q) = children + 7q$，即 $q \le \lfloor extra / 7 \rfloor$；又 $q \le children$，故 $q \le q^*$。
**$q^* < children$ 时**：$L = money - 8q^* = (children - q^*) + leftover = r + leftover \ge r$ 恒成立（$leftover \ge 0$），由引理 1 唯一的不行是 $r = 1 \wedge leftover = 3$；此时 $q^* - 1$ 的参数为 $r' = 2$、$L' = r + leftover + 8 = 12 \ge 2$，引理 1 构造可行，再由引理 2 覆盖一切更小档位。
**$q^* = children$ 时**（$extra \ge 7 \cdot children$）：$q = children$ 要求钱恰好分完为 $8 \cdot children$，即 $extra = 7 \cdot children$，此时可行；否则 $q = children$ 不可行，而 $children - 1$ 档的参数 $r = 1$、$L = money - 8(children-1) = 8 + (extra - 7 \cdot children) \ge 9 \ne 4$，由引理 1 可行，故答案 $children - 1$。∎

## 6. 复杂度分析

- **时间**：$O(1)$，纯公式计算。
- **空间**：$O(1)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int distMoney(int money, int children) {
        if (money < children) return -1;          // 每人至少 1 美元都给不出
        int extra = money - children;             // 每人先发 1 美元后的剩余
        int q = min(extra / 7, children);         // 每个"恰好 8 美元"还要 7
        if (q == children)                        // 人人都想拿 8：多余的钱只能塞给某人
            return extra == 7 * children ? children : children - 1;
        int leftover = extra - 7 * q;             // 0..6
        if (children - q == 1 && leftover == 3)   // 最后一人会被迫拿到 1+3=4 美元
            return q - 1;
        return q;
    }
};
```

### Python

```python
class Solution:
    def distMoney(self, money: int, children: int) -> int:
        if money < children:
            return -1
        extra = money - children
        q = min(extra // 7, children)
        if q == children:
            return children if extra == 7 * children else children - 1
        leftover = extra - 7 * q
        if children - q == 1 and leftover == 3:
            return q - 1
        return q
```

> 💡 两份代码均通过官方示例（`1`、`2`）与 $(12,2) \to 0$、$(13,2) \to 1$、$(1,2) \to -1$、$(200,30)$、$(56,7)$ 等手工用例；并与记忆化搜索暴力（`g(i, rem)` = 把 rem 分给第 i 人后最多几个 8，每人 $\ge 1$ 且 $\ne 4$）对拍：**全量扫描** $money \in [1,200] \times children \in [2,30]$ 共 5800 组 + 200 组随机，四实现（C++ 解、Python 解、C++ DP、Python DP）全部一致，`mismatch = 0`。

## 8. 边界情况与易错点

1. **$money < children$ → $-1$**：唯一无解情形，先判。
2. **陷阱记反**：踩雷条件是"剩 1 人 + 垫底后剩 3 元"（该人合计 4 元），**不是**"剩 4 元"——$leftover=4$ 时那人是 $1+4=5$，合法。很多人把示例 1 的坑记成"余 4"，全量扫描一拍就露馅。
3. **$q = children$ 分支**：$extra$ 超过 $7 \cdot children$ 的部分无处安放（塞给谁谁就不再是 8），答案 $children - 1$；只有 $extra$ 恰为 $7 \cdot children$ 才能全员 8。
4. **$children = 1$ 的越界想象**：约束保证 $children \ge 2$，公式对 $children = 1$ 也碰巧兼容（如 $money=4$ 会返回 $-1$），不必特判但也别依赖。
5. **每步都要"钱分完"**：贪心时别漏掉"多余钱必须塞给某人"的总额守恒——它是 $q=children$ 分支和陷阱分支的根源。
6. **对拍是最强保险**：本题样例少、坑在深处，$200 \times 30$ 的全量 DP 对拍一分钟就能写完，比赛中强烈建议做。
