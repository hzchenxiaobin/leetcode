# LeetCode 最大化数组的伟大值 题解

## 1. 题目概述

- **标题 / 题号**：最大化数组的伟大值（#2592，medium）
- **链接**：https://leetcode.cn/problems/maximize-greatness-of-an-array/
- **来源**：LeetCode 第 100 场双周赛 Q2
- **难度**：中等
- **标签**：贪心、数组、双指针、排序

**题意**：给定整数数组 `nums`，把 `nums` 重新排列成 `perm`。定义**伟大值**为满足 $perm[i] > nums[i]$ 的下标 $i$ 的数目。求重新排列后伟大值的**最大值**。

**约束**：

- $1 \le nums.length \le 10^5$
- $0 \le nums[i] \le 10^9$

## 2. 示例

**示例 1**

```text
输入：nums = [1,3,5,2,1,3,1]
输出：4
解释：perm = [2,5,1,3,3,1,1]，下标 0、1、3、4 处 perm[i] > nums[i]。
```

**示例 2**

```text
输入：nums = [1,2,3,4]
输出：3
解释：perm = [2,3,4,1]，下标 0、1、2 处成立。
```

**示例 3（边界补充）**

```text
输入：nums = [7,7,7,7]
输出：0
解释：所有值相同，任何 perm[i] 都不可能严格大于 nums[i]。
```

## 3. 解题思路

### 3.1 暴力思路

枚举 `nums` 的所有全排列，逐个计算伟大值取最大——$O(n! \cdot n)$，$n > 8$ 就彻底不可行。由于伟大值只关心"值之间的相对大小"，先把数组**排序**损失一般性；排序后问题变成：把同一组值重新分配到排序后的位置上，最大化"值压过位置值"的对数——一个可贪心的**匹配问题**。

### 3.2 核心观察：排序 + 双指针，大数配"刚好比它大"的位置

![排序双指针配对](images/bw100_q2_sorted_pairing.svg)

把 `nums` 升序排序后，位置的下标与值都单调。维护两个"指针"的直觉版：

- $i$ 指向**最小的一个尚未配对的位置值**（配对成功一次就 $+1$）；
- $x$ 从左到右扫过排序后的值，充当 `perm` 的候选值：
  - 若 $x > nums[i]$：$x$ 恰好能压过当前最小的未配对位置 → 配对，$i{+}{+}$；
  - 若 $x \le nums[i]$：$x$ 连最小的未配对位置都压不过，更压不过后面的任何位置（位置值递增）→ $x$ 只能配给已配对的位置，**跳过不亏**。

扫描结束后 $i$ 就是答案。

另一个漂亮的刻画：**答案 $= n - \max\_freq$**（$n$ 减去众数的出现次数）。直觉：出现最多的值 $v^*$ 霸占了 $f$ 个位置，这些位置只能由值 $> v^*$ 的元素来"压"，而这样的元素恰好只有 $n - (\le v^* \text{ 的个数}) \le n - f$ 个。

![n − 最大频次的上界与构造](images/bw100_q2_maxfreq_bound.svg)

### 3.3 算法流程

```text
1. nums 升序排序
2. i = 0
3. for x in nums:              # x 依次当候选 perm 值
       若 x > nums[i]: i += 1  # 配对成功
4. 返回 i
```

等价一行刻画：`答案 = n − max(值出现次数)`（可作为对拍/自检的独立实现）。

### 3.4 示例演算

**示例 1**：排序得 $[1,1,1,2,3,3,5]$。扫描：$1,1,1$ 都压不过 $nums[0]=1$，跳过；$2 > 1$ 配对（$i{=}1$）；$3 > 1$（$i{=}2$）；$3 > 1$（$i{=}3$）；$5 > 2$（$i{=}4$）。答案 $4$ ✓（也 $= 7 - 3$，众数 $1$ 出现 3 次 ✓）。

**示例 2**：排序 $[1,2,3,4]$：$1$ 跳过；$2>1$、$3>2$、$4>3$ → $i = 3$ ✓（$= 4 - 1$）。

**示例 3**：全部相同，永远无法严格压过 → $0$（$=4-4$）✓。

## 4. 算法细节

1. **同一数组既当位置又当值**：`nums` 排序后，位置（按值排序）和候选值共用一个序列——这正是双指针能一行写完的原因。
2. **跳过 $x$ 的正确姿势**：$x \le nums[i]$ 时**不移动** $i$，只移动 $x$（$x$ 被消耗在已配对的位置上，不产生伟大值）。
3. **用频次版做自检**：`Counter` 数最大频次，$n - f$ 与双指针结果必须一致（两者在 §5 中被证明恒等）；比赛时花 20 秒写个对照，非常划算。
4. **溢出与边界**：只需比较，无算术溢出；$n = 1$ 时答案必为 0。
5. **不要稳定去重**：相等元素的位置与值一一对应即可，重不重复处理无所谓。

## 5. 正确性证明

以下把"位置"按其值升序记为 $a_0 \le a_1 \le \dots \le a_{n-1}$（由于伟大值只依赖值，位置可如此重排）。

**引理 1（上界）**：任何排列的伟大值 $\le n - f$，其中 $f$ 为某个值的最大出现次数。

**证明**：设 $v^*$ 是出现次数为 $f$ 的众数，集合 $S = \{j : a_j = v^*\}$（$|S| = f$），设 $p$ 为小于 $v^*$ 的元素个数（故 $\le v^*$ 的元素共 $p + f$ 个）。把被"压过"的位置按其值分类：值等于 $v^*$ 的被压位置（属于 $S$）收到的值必须 $> v^*$；值大于 $v^*$ 的被压位置收到的值也必须 $> v^*$（严格大于其位置值 $> v^*$）。这两类位置各自消耗一个**互不相同**的 $> v^*$ 的值，而 $> v^*$ 的值恰好有 $n - p - f$ 个，故被压位置数 $\le p + (n - p - f) = n - f$。∎

**引理 2（可达性构造）**：把排序后数组的**前 $n - f$ 个位置** $a_0, \dots, a_{n-f-1}$ 分别配上值 $a_{f}, a_{f+1}, \dots, a_{n-1}$（即整体"右移 $f$ 位"），则每对都满足 $a_{j+f} > a_j$，得到 $n - f$ 个伟大值。

**证明**：$a_{j+f} \ge a_j$ 显然（升序）；若 $a_{j+f} = a_j$，则值 $a_j$ 在排序数组中至少占据下标区间 $[j, j+f]$ 共 $f+1$ 个位置，即出现次数 $\ge f+1$，与 $f$ 是最大出现次数矛盾。故严格大于。配上的是同一数组的不同元素（下标区间 $[f, n-1]$ 与 $[0, n-f-1]$ 不重叠地消耗值侧），是合法排列的一部分。∎

**定理（贪心正确性）**：双指针算法返回 $n - f$，即最大伟大值。

**证明**：贪心产出的每一对（值 $x$，位置值 $a_i$）满足 $x > a_i$ 且各值、各位置互不相同，是一个合法匹配，其大小即返回值 $g$。由引理 1，$g \le n - f$。再证 $g \ge n - f$：对 $n - f$ 归纳给出交换论证——设 $\mathit{OPT}$ 为任意最大匹配，$x^*$ 为能压过最小未配对位置 $a_0$ 的最小值。若 $a_0$ 在 $\mathit{OPT}$ 中未配对且某值 $x > a_0$ 已配在别处，把 $x$ 改配给 $a_0$（该值仍严格压过 $a_0$），匹配数不减；若 $a_0$ 在 $\mathit{OPT}$ 中配的值 $x \ne x^*$，而 $x^*$ 配在某位置 $a_q$（必有 $a_q < x^*$）或未配上，交换二者：$a_0 \leftarrow x^*$（$x^* > a_0$ ✓），$a_q \leftarrow x$（由 $x \ge x^* > a_q$ ✓），匹配数不减。故存在最大匹配把最小的值 $x^*$ 配给最小的位置 $a_0$——与贪心的第一步一致；去掉这一对后剩余问题结构不变（值删 $x^*$、位置删 $a_0$，阈值结构保持），归纳得贪心的匹配数 $\ge \mathit{OPT} = n - f$。结合引理 2，$g = n - f$。∎

## 6. 复杂度分析

- **时间**：$O(n \log n)$，排序主导；扫描 $O(n)$。频次版 $O(n)$（值域哈希）更快，但两者同数量级。
- **空间**：$O(1)$ 额外（C++ 原地排序）；Python `sorted` 需 $O(n)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maximizeGreatness(vector<int>& nums) {
        sort(nums.begin(), nums.end());
        int i = 0;                               // i 指向最小的"未配对"位置值
        for (int x : nums)                       // x 依次充当 perm 的候选值
            if (x > nums[i]) ++i;                // 恰好能压过它 → 配对成功
        return i;
    }
};
```

### Python

```python
class Solution:
    def maximizeGreatness(self, nums: list[int]) -> int:
        nums.sort()
        i = 0                              # 指向最小的"未配对"位置值
        for x in nums:                     # x 依次充当 perm 的候选值
            if x > nums[i]:
                i += 1                     # 恰好能压过它 → 配对成功
        return i
```

> 💡 两份代码均通过官方示例（`4`、`3`）与全相同元素边界；并与"全排列枚举"暴力对拍 400 组随机数据（$n \le 7$、含大量重复值），同时用 $n - \max\_freq$ 的频次版做交叉自检，三实现全部一致，`mismatch = 0`。

## 8. 边界情况与易错点

1. **全相同元素**：答案 0；双指针版 $x > nums[i]$ 永不成立，天然正确。
2. **$n = 1$**：无法严格大于自身，答案 0。
3. **指针方向写反**：常见错误是把"值指针"和"位置指针"职责对调后忘记移动哪一个；记住**值每次都前进，位置只在配对成功时前进**。
4. **误用 $\ge$**：伟大值要求**严格**大于，相等不算；把判定写成 `>=` 会在重复值多的用例上出错（全相同数组会错答 $n$）。
5. **别把"频次版"误当唯一解**：$n - \max\_freq$ 需要另证（本文 §5），写题解或面试时不能只报结论。
6. **位权无关**：伟大值按"下标个数"计，与具体数值大小无关，排序后只做比较，无溢出。
