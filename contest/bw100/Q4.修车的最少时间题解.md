# LeetCode 修车的最少时间 题解

## 1. 题目概述

- **标题 / 题号**：修车的最少时间（#2594，medium）
- **链接**：https://leetcode.cn/problems/minimum-time-to-repair-cars/
- **来源**：LeetCode 第 100 场双周赛 Q4
- **难度**：中等
- **标签**：数组、二分查找

**题意**：`ranks[i]` 是第 $i$ 位机械工的能力值 $r$；能力值 $r$ 的机械工修 $n$ 辆车需要 $r \cdot n^2$ 分钟。共 `cars` 辆车需要修理，所有机械工**同时开工**，每辆车只需一个人修完。求修完所有车的**最少**时间。

**约束**：

- $1 \le ranks.length \le 10^5$
- $1 \le ranks[i] \le 100$
- $1 \le cars \le 10^6$

## 2. 示例

**示例 1**

```text
输入：ranks = [4,2,3,1], cars = 10
输出：16
解释：四人分别修 2、2、2、4 辆：16、8、12、16 分钟，最晚 16 分钟收工。
```

**示例 2**

```text
输入：ranks = [5,1,8], cars = 6
输出：16
解释：三人分别修 1、4、1 辆：5、16、8 分钟，最晚 16。
```

**示例 3（边界补充）**

```text
输入：ranks = [100], cars = 1
输出：100
解释：只有一名机械工修 1 辆车：100 × 1² = 100 分钟。
```

## 3. 解题思路

### 3.1 暴力思路

枚举每名机械工的修车数 $(n_1, \dots, n_m)$ 使 $\sum n_i = cars$，取 $\min \max_i r_i n_i^2$——组合数指数级，$cars = 10^6$ 时完全不可行（这个思路留作小规模对拍暴力）。反过来想：与其决定"每人修几辆"，不如先问一个问题——**给定总时间 $t$，最多能修多少辆？**

### 3.2 核心观察：给定时限 $t$，产能可以精确算出

![判定函数：每人限时产能 ⌊√(t/r)⌋](images/bw100_q4_capacity.svg)

能力值 $r$ 的机械工要在 $t$ 分钟内修 $n$ 辆车，需 $r \cdot n^2 \le t$，即

$$n \le \sqrt{t / r} \quad\Longrightarrow\quad n_{\max} = \left\lfloor \sqrt{t / r} \right\rfloor$$

于是总产能

$$cap(t) = \sum_{i=1}^{m} \left\lfloor \sqrt{t / r_i} \right\rfloor$$

$cap(t) \ge cars$ 即"$t$ 分钟内能修完"。

### 3.3 算法流程：二分答案

![二分答案：判定可行的时间构成前缀](images/bw100_q4_binary_search.svg)

$cap(t)$ 关于 $t$ **单调不减**（每个被开方式子都单调），所以"可行"的 $t$ 构成一段前缀闭区间，标准二分答案：

```text
lo = 1，hi = r_max × cars²          # 只靠最慢的一个人也能修完的上界
while lo < hi:
    mid = (lo + hi) / 2
    若 cap(mid) ≥ cars：hi = mid    # mid 可行 → 收紧
    否则：             lo = mid + 1 # 不可行 → 抬高
返回 lo
```

**上界说明**：$t = r_{\max} \cdot cars^2$ 时，光最慢的机械工一人就能修完所有车（$r_{\max} \cdot cars^2 \le t$），可行；故二分区间 $[1, r_{\max} \cdot cars^2]$ 一定包含答案。

### 3.4 示例演算

![示例 1 在 t=16 与 t=15 的判定](images/bw100_q4_walkthrough.svg)

**示例 1**（`ranks = [4,2,3,1]`, `cars = 10`）：

- $t = 16$：$\lfloor\sqrt{4}\rfloor + \lfloor\sqrt{8}\rfloor + \lfloor\sqrt{16/3}\rfloor + \lfloor\sqrt{16}\rfloor = 2+2+2+4 = 10 \ge 10$ ✓ 可行；
- $t = 15$：$1+2+2+3 = 8 < 10$ ✗ 不可行。

可行与不可行的交界即答案：$16$ ✓。

**示例 2**（`ranks = [5,1,8]`, `cars = 6`）：$t=16$：$1+4+1 = 6 \ge 6$ ✓；$t=15$：$1+3+1 = 5 < 6$ ✗ → $16$ ✓。

## 4. 算法细节

1. **整数平方根**：判定核心是 $\lfloor\sqrt{t/r}\rfloor$。C++ 用 `sqrtl` 得到近似值后**双向修正**（`while (c*c*r > t) --c; while ((c+1)*(c+1)*r <= t) ++c;`），杜绝浮点误差；Python 用 `math.isqrt(t // r)`，由于 $\lfloor\sqrt{\lfloor t/r\rfloor}\rfloor = \lfloor\sqrt{t/r}\rfloor$（开方单调），先除后开方完全等价。
2. **按能力值分桶**：$r_i \le 100$，可统计每个能力值的人数，判定从 $O(m)$ 降到 $O(100)$——$m = 10^5$、二分约 47 轮时，把 Python 从 470 万次循环压到 4700 次。
3. **上界别写小**：$r_{\max} \cdot cars^2 = 100 \times 10^{12} = 10^{14}$，必须 `long long`；C++ 写 `1LL * rmax * cars * cars` 防止中间溢出。
4. **提前终止**：判定循环中 `total >= cars` 即返回，既加速又避免溢出。
5. **平方和比较避免开方**：内层修正用 $c^2 r$ 与 $t$ 直接比较，全程整数运算。
6. **为什么不用三分**：目标并非单峰函数的极值，而是"满足条件的最小 $t$"，凸性无关，二分是正解。

## 5. 正确性证明

**引理 1（判定正确）**：时限 $t$ 内能修完所有车，当且仅当 $cap(t) = \sum_i \lfloor\sqrt{t/r_i}\rfloor \ge cars$。

**证明**：（$\Leftarrow$）对每个 $i$ 令 $n_i = \lfloor\sqrt{t/r_i}\rfloor$，则 $r_i n_i^2 \le t$（对 $n_i \ge 0$：$n_i^2 \le t/r_i$ 由取整定义保证），且 $\sum n_i \ge cars$；把超额的份额随意削减（$n_i$ 减小仍满足时限），得到恰 $\sum n_i = cars$ 的合法方案，完工时间 $\le t$。（$\Rightarrow$）设方案 $n_i$ 满足 $\max_i r_i n_i^2 \le t$，则对每个 $i$，$n_i \le \sqrt{t/r_i}$，整数即 $n_i \le \lfloor\sqrt{t/r_i}\rfloor$，故 $cars = \sum n_i \le cap(t)$。∎

**引理 2（单调性）**：$t_1 \le t_2 \Rightarrow cap(t_1) \le cap(t_2)$。

**证明**：$t/r_i$ 随 $t$ 不减，$\lfloor\sqrt{\cdot}\rfloor$ 单调不减，逐项求和保持单调。∎

**定理（二分正确性）**：二分结束时 $lo = \min\{t \ge 1 : cap(t) \ge cars\}$，即最少修车时间。

**证明**：由引理 2，谓词 $P(t) = [cap(t) \ge cars]$ 在整数域上单调（假…假，真…真）。二分维护不变量：$[lo, hi] \subseteq [1, r_{\max} cars^2]$，一切 $< lo$ 的 $t$ 都不可行、$hi$ 恒可行（初始 $hi$ 由引理 1 可行；每轮收缩后 $hi$ 仍取可行值）。每轮后区间严格缩小，终止时 $lo = hi$，它既"可行"又"以下皆不可行"，即最小可行 $t$。再由引理 1，"可行"就是"能在 $t$ 分钟内修完"，故 $lo$ 是最少时间；同时答案天然是整数（最优方案的最晚完工时间恰为某 $r_i n_i^2$ 的整数），二分整数域无损。∎

## 6. 复杂度分析

- **时间**：$O((m + 100 \log_{10^{14}}) )$ 量级，准确说：排序/分桶 $O(m)$；二分 $O(\log(r_{\max} cars^2)) \approx 47$ 轮，每轮 $O(m)$（朴素）或 $O(100)$（分桶）→ 总 $O(m \log(r_{\max} cars^2))$ 或 $O(m + 100\log(r_{\max} cars^2))$，$10^5 \times 47 \approx 4.7 \times 10^6$，轻松通过。
- **空间**：$O(1)$ 额外（分桶版 $O(100)$；Python `Counter` $O(100)$）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long repairCars(vector<int>& ranks, int cars) {
        long long lo = 1;
        long long hi = 1LL * *max_element(ranks.begin(), ranks.end()) * cars * cars;
        while (lo < hi) {
            long long mid = lo + (hi - lo) / 2;
            if (feasible(ranks, cars, mid)) hi = mid;   // mid 可行 → 收紧上界
            else lo = mid + 1;                          // 不可行 → 抬高下界
        }
        return lo;
    }
private:
    bool feasible(const vector<int>& ranks, long long cars, long long t) {
        long long total = 0;
        for (int r : ranks) {
            long long c = (long long)sqrtl((long double)t / r);   // ⌊√(t/r)⌋
            while (c > 0 && c * c * r > t) --c;         // 修正浮点误差
            while ((c + 1) * (c + 1) * r <= t) ++c;
            total += c;
            if (total >= cars) return true;             // 提前返回，防溢出
        }
        return total >= cars;
    }
};
```

### Python

```python
from collections import Counter
from math import isqrt


class Solution:
    def repairCars(self, ranks: list[int], cars: int) -> int:
        cnt = Counter(ranks)                     # 能力值至多 100，按值分桶

        def feasible(t: int) -> bool:            # t 分钟内能否修完 cars 辆
            return sum(c * isqrt(t // r) for r, c in cnt.items()) >= cars

        lo, hi = 1, max(ranks) * cars * cars
        while lo < hi:
            mid = (lo + hi) // 2
            if feasible(mid):
                hi = mid
            else:
                lo = mid + 1
        return lo
```

> 💡 两份代码均通过官方示例（`16`、`16`）、单机械工边界与 $10^5$ 机械工 × $10^6$ 车的大规模压力测试（Python 分桶版 0.05 秒）；并与"枚举每人修车数组合取 $\min \max r_i n_i^2$"的独立暴力对拍 300 组随机数据（$m \le 4$、$r \le 6$、$cars \le 12$），`mismatch = 0`。

## 8. 边界情况与易错点

1. **上界溢出**：$r_{\max} \cdot cars^2 = 10^{14}$，C++ 必须 `long long` 且乘法首个操作数先转 64 位；Python 无碍但别把 `hi` 写成 `cars * cars // max(ranks)` 之类的"聪明"式子。
2. **浮点开方**：`sqrt(1e14)` 附近浮点误差可能把 $\lfloor\sqrt{\cdot}\rfloor$ 算大/小 1，必须整数修正；Python 的 `isqrt` 是精确整数平方根，无此坑。**先除后开**时注意 $\lfloor\sqrt{\lfloor t/r\rfloor}\rfloor = \lfloor\sqrt{t/r}\rfloor$，直接 `t // r` 是安全的。
3. **二分边界**：区间是 $[1, r_{\max} cars^2]$ 闭区间、收缩模板 `hi = mid / lo = mid + 1`；写错容易死循环（如 `hi = mid - 1` 配 `lo <= hi`）。
4. **`cars = 0` / 单车**：约束保证 $cars \ge 1$；$cars=1$ 时答案是 $\min r_i$，可以拿来自检二分。
5. **分桶的前提**：$r_i \le 100$ 是题目给的强约束，分桶版依赖它；若值域变大就退回朴素 $O(m)$ 判定。
6. **答案为什么是整数**：最优解必为"某人恰好在最后一刻修完他的第 $n$ 辆车"，即某 $r_i n_i^2$，天然整数——所以二分整数域不漏解。
7. **别贪心"每次给最快完工的人派车"**：最小堆模拟派车（每步把下一辆车给最早可收工的人）本题恰好正确，但那需要另证且实现繁琐；二分是更稳的通用模板。
