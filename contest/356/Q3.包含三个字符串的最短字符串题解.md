# LeetCode 包含三个字符串的最短字符串 题解

## 1. 题目概述

- **标题 / 题号**：包含三个字符串的最短字符串（#2800，medium）
- **链接**：https://leetcode.cn/problems/shortest-string-that-contains-three-strings/
- **来源**：LeetCode 第 356 场周赛 Q3
- **难度**：中等
- **标签**：贪心、字符串、枚举

**题意**：给定三个字符串 $a$、$b$、$c$，找一个**最短**的字符串 $S$，使 $a$、$b$、$c$ 都是 $S$ 的**子串**；若有多个最短的，返回**字典序最小**的一个。

**约束**：

- $1 \le |a|, |b|, |c| \le 100$
- $a$、$b$、$c$ 只含小写英文字母

> 💡 **周赛定位**：本场分水岭。「枚举 $3! = 6$ 种排列」的念头不难冒出来，真正卡人的是两件事：一是敢不敢相信 6 种排列**完备**——一般的最短公共超串（SCS）可是 NP-hard，凭什么是 6 次尝试就够；二是「被包含的串」「字典序最小」带来的实现细节。本题站内已有 daily 版题解（[2800. 包含三个字符串的最短字符串](../../solution/2701-2800/2800_包含三个字符串的最短字符串.md)），采用「固定排列、枚举中间串**全部**重叠量」的视角并给出贪心反例；本篇周赛复盘采用与之**互为补集**的视角——**先删被包含者，再证「桥接」现象会被另一种排列吸收**，于是每条接缝只取最大重叠即可，还能顺手拿到「候选集完备」的定理（§5）。

## 3. 解题思路

### 3.1 暴力思路：从「枚举答案串」到「枚举拼接形态」

最朴素的做法是按长度 $L$ 从 $\max(|a|,|b|,|c|)$ 逐层枚举所有小写字母串——$26^L$ 天文数字，$L$ 到 $300$ 完全不可行。但这个徒劳的尝试给出两条有用信息：**答案长度有明确上下界**（下界 $\max$，上界 $|a|+|b|+|c|$，直接拼接就是合法超串），且答案一定由三个串「错开叠放」构成——候选空间是**拼接形态**而非任意字符串。

于是自然的想法是贪心：固定一种顺序，每次把下一个串按**最大重叠**拼到右边。⚠️ 这会翻车——固定输入顺序 $(\texttt{xab}, \texttt{aby}, \texttt{aba})$ 时最大重叠拼出 $\texttt{xabyaba}$（7），而真正的最优是 $\texttt{xababy}$（6）：$\texttt{aba}$ 横跨了 $\texttt{xab}$ 与 $\texttt{aby}$ 的接缝。看来「顺序」与「接缝」两个自由度都得动。daily 版的做法是把中间串的接缝**全部重叠量枚举**一遍（$O(L^3)$）；本篇走另一条路——先做一步**去重**，然后证明接缝只取**最大**重叠就够（$O(n^2)$），顺序交给 $3!=6$ 种排列。

### 3.2 核心观察：去重 + 阶梯 + 相邻最大重叠

![核心观察：去重排除嵌套，剩下的串按阶梯相邻重叠拼接](images/superstring_staircase_overlap.svg)

三个观察把搜索空间钉死：

1. **观察一（被包含者白拿）**：若 $x \subseteq y$，则任何包含 $y$ 的串自动包含 $x$——$x$ 从不用单独安放，直接删掉，超串集合**一个不差**（引理 1）。相等串只留一份，否则会互相判为子串而全部删光。
2. **观察二（出现区间是阶梯）**：删完被包含者后，最优解 $S^*$ 里三个串的出现区间**互不嵌套**——嵌套意味着子串关系，早已被观察一排除。互不嵌套 ⟹ 按起点排序后终点也递增（引理 2），像楼梯一样错开；$S^*$ 就是这段阶梯的**外壳**，中间没有空隙（引理 3）。
3. **观察三（相邻最大重叠就够）**：对排列 $(t_1,t_2,t_3)$，拼接 $M = t_1 + t_2[k_{12}:] + t_3[k_{23}:]$ 中两个重叠**只依赖相邻两个原串**、互相独立——各取最大即该排列的最短（引理 3）。而「桥接」并不例外：$\texttt{xababy}$ 里 $\texttt{aba}$ 出现在中间，恰好对应**排列** $(\texttt{xab},\texttt{aba},\texttt{aby})$ 的相邻最大重叠拼接（$k_{12}=2$ 的 $\texttt{ab}$、$k_{23}=1$ 的 $\texttt{a}$）。换一个排列，桥接就被吸收了，接缝不必枚举非最大重叠（定理）。

> ⚠️ 观察三与 daily 版的分工恰好互补：daily 版把排列固定为「首次出现顺序」后，中间串必须枚举**所有**重叠量才能看见桥接；本篇把三个串**全部换着排列**，于是桥接出现在「换排列」这一层，每条接缝只剩最大重叠一种取法。两条路都能精确求解，本篇的路少一层枚举、多一个完备性定理。

### 3.3 算法流程

![算法流程：去重 → 按剩余个数分流 → 枚举排列 → 相邻最大重叠拼接 → 双关键字取最小](images/superstring_algorithm_flow.svg)

1. **去重**：$x \subseteq y$（$x \ne y$）则删 $x$；相等串只留最前一份。
2. **分流**：剩 1 个串——它已包含全部三个串且最短超串必含它，直接返回；剩 2 / 3 个串——继续。
3. **枚举排列**：$2! = 2$ 或 $3! = 6$ 种，对每种排列计算**相邻两个原串**的最大重叠，拼出候选 $M$。
4. **取最优**：在全部候选中按（长度, 字典序）双关键字取最小，返回。

### 3.4 示例演算

![示例 1 演算：六种排列逐一拼接，两个长度 6 的并列，字典序取 aaabca](images/superstring_perm_walkthrough.svg)

以示例 1（$a=\texttt{abc}$，$b=\texttt{bca}$，$c=\texttt{aaa}$，互不包含）走查全部 6 种排列。注意重叠计算的两个易错点：$\operatorname{ov}(\texttt{abc},\texttt{bca}) = 2$ 但 $\operatorname{ov}(\texttt{bca},\texttt{abc}) = 1$（**不对称**）；$\operatorname{ov}(\texttt{aaa},\texttt{abc}) = 1$ 而不是 $0$（首字符 $\texttt{a}$ 对 $\texttt{a}$）：

| 排列 $(t_1,t_2,t_3)$ | $k_{12}$ | $k_{23}$ | 拼接结果 | 长度 |
|---|---|---|---|---|
| abc, bca, aaa | 2（bc） | 1（a） | abcaaa | 6 |
| abc, aaa, bca | 0 | 0 | abcaaabca | 9 |
| bca, abc, aaa | 1（a） | 0 | bcabcaaa | 8 |
| bca, aaa, abc | 1（a） | 1（a） | bcaaabc | 7 |
| **aaa, abc, bca** | 1（a） | 2（bc） | **aaabca** | **6** |
| aaa, bca, abc | 0 | 1（a） | aaabcabc | 8 |

最短长度 6 有两个并列：$\texttt{abcaaa}$ 与 $\texttt{aaabca}$，比较第 2 个字符 $\texttt{a} < \texttt{b}$，字典序取 $\texttt{aaabca}$ ✓（与题目输出一致）。

> 💡 **示例 2 验证**：$a=\texttt{ab}$，$b=\texttt{ba}$，$c=\texttt{aba}$。$a \subseteq c$、$b \subseteq c$，去重后只剩 $\{\texttt{aba}\}$，走「剩 1 个」分支直接返回 $\texttt{aba}$，长度 3 ✓。**补充示例验证**：$(\texttt{x},\texttt{x},\texttt{y})$ 去重后剩 $\{\texttt{x},\texttt{y}\}$，两种排列拼出 $\texttt{xy}$、$\texttt{yx}$，同长取字典序小的 $\texttt{xy}$ ✓。

## 4. 算法细节

1. **最大重叠的求法**：$\operatorname{ov}(x,y)$ 从 $k = \min(|x|,|y|)$ 递减到 $1$，第一个满足「$x$ 的长 $k$ 后缀 = $y$ 的长 $k$ 前缀」的 $k$ 即答案，$k=0$ 兜底（直接拼接）。单次 $O(n^2)$，$n \le 100$ 无需 KMP / 字符串哈希。
2. **重叠方向与不对称性**：$\operatorname{ov}(x,y)$ 是「$x$ 的**后缀**对 $y$ 的**前缀**」，方向写反必错；且它**不对称**——$\operatorname{ov}(\texttt{abc},\texttt{bca})=2$ 而 $\operatorname{ov}(\texttt{bca},\texttt{abc})=1$，排列枚举时必须按排列中「左串→右串」的方向取。
3. **去重判据**：对每个 $i$，若存在 $j \ne i$ 使 $s_i \subseteq s_j$ 则删 $s_i$；相等串（$s_i = s_j$）例外——只删下标靠后的那份，否则 $(\texttt{x},\texttt{x},\texttt{y})$ 会被删得只剩 $\texttt{y}$，连 $\texttt{x}$ 都不含。
4. **相邻原串 vs 累积串**：本篇的重叠始终在**相邻两个原串**之间计算，与 §5 定理一一对应。常见的另一种写法是拿「当前拼接结果」与下一串求重叠（累积式）——实测两组写法在本题数据下结果一致（对拍 40 万组随机无一不同），但累积式可能算出「后缀伸进前一个串贡献区」的跨段匹配，与定理形态脱节；推荐相邻式，证明与代码严丝合缝。
5. **双关键字比较**：直接比较元组 $(\text{len}(s),\, s)$，先短、同长再比字典序，一次比较完成，无需两段 if。
6. **剩 1 个串提前返回**：此时另外两个串都是它的子串（子串关系可传递），而任何超串都包含它 ⟹ 它就是唯一的最短超串。

## 5. 正确性证明

记 $x \subseteq y$ 为「$x$ 是 $y$ 的子串」。去重后剩 $m \in \{1,2,3\}$ 个两两不同、互不包含的串。对 $m$ 个串的排列 $(t_1,\dots,t_m)$，定义**相邻最大重叠拼接**：

$$t_1 \oplus t_2 \oplus \cdots \oplus t_m \;=\; t_1 + t_2[k_1:] + \cdots + t_m[k_{m-1}:]$$

其中 $k_i = \operatorname{ov}(t_i, t_{i+1})$。

**引理 1（被包含者可删）**：若 $x \subseteq y$（$x,y \in \{a,b,c\}$），则 $\{a,b,c\}$ 的超串集合与 $\{a,b,c\} \setminus \{x\}$ 的超串集合完全相同（相等串同删一份显然也不改变超串集合）。

**证明**：$S$ 是三串的超串 ⟺ $S$ 包含其余两串与 $x$。而 $x \subseteq y \subseteq S$ 时 $x \subseteq S$ 自动成立，故两个条件等价，超串集合逐个相同——长度与字典序的最优都不受影响。∎

**引理 2（出现区间是阶梯）**：设 $S^*$ 是去重后 $m$ 个串的最短超串，取每个串在 $S^*$ 中的一次出现（区间 $[s_i, e_i)$，即 $S^*[s_i..e_i) = t_i$）。这些区间互不嵌套；按起点排序后，起点与终点同时严格递增。

**证明**：若 $t_j$ 的出现区间含于 $t_i$ 的出现区间，则 $t_j$ 作为字符串是 $t_i$ 的子串，与去重后互不包含矛盾；起点相同的两个区间必有一个包含另一个（短的是长的前缀），也不可能。于是起点互异且互不嵌套；若 $s_i < s_j$ 而 $e_i \ge e_j$，则 $[s_j,e_j) \subseteq [s_i,e_i)$，嵌套，矛盾。故按起点排序后有 $s_1 < s_2 < \cdots < s_m$ 且 $e_1 < e_2 < \cdots < e_m$。∎

**引理 3（外壳、空隙与拼接上界）**：$S^*$ 等于其外壳 $[s_1, e_m)$，外壳内无空隙；且按阶梯顺序的最大重叠拼接满足 $|t_1 \oplus \cdots \oplus t_m| \le |S^*|$。

**证明**：由引理 2，所有出现区间都落在 $[s_1, e_m)$ 内，故外壳是超串；又外壳是 $S^*$ 的子串，由 $S^*$ 最短知二者等长，即 $S^*$ 就是外壳。记相邻出现的实际重叠 $o_i = \max(0,\, e_i - s_{i+1})$、空隙 $g_i = \max(0,\, s_{i+1} - e_i)$，逐项展开可得 $|S^*| = \sum_i |t_i| - \sum_i o_i + \sum_i g_i$（总长 = 各段长 − 重叠 + 空隙）。当 $o_i > 0$ 时 $S^*[s_{i+1}..e_i)$ 既是 $t_i$ 的后缀又是 $t_{i+1}$ 的前缀，故最大重叠 $k_i \ge o_i$；从而 $|t_1 \oplus \cdots \oplus t_m| = \sum|t_i| - \sum k_i \le \sum|t_i| - \sum o_i \le |S^*$。该拼接是合法超串，由最短性两处不等号同时取等——于是 $\sum g_i = 0$（无空隙）且 $k_i = o_i$（实际重叠全取到最大）。∎

**定理（完备性）**：每个最短超串都恰是某个排列的相邻最大重叠拼接。

**证明**：设 $S^*$ 是最短超串，$(t_1,\dots,t_m)$ 为其出现区间的阶梯顺序。由引理 3，$S^*$ 无空隙、每个相邻实际重叠 $o_i$ 都取到最大值 $k_i$。对偏移归纳：$t_1$ 在 $S^*$ 与拼接 $M$ 中都从最左端开始；设 $t_i$ 在两者中偏移一致，则 $t_{i+1}$ 在 $S^*$ 中起点为 $e_i - o_i = e_i - k_i$，在 $M$ 中也恰好落在前段末尾往前数 $k_i$ 处，偏移一致。$S^*$ 的每个位置都被某个 $t_i$ 的出现覆盖（无空隙），而覆盖区间的内容就是 $t_i$ 本身，故 $S^* = t_1 \oplus \cdots \oplus t_m$。∎

**推论（算法正确）**：算法的候选集 = 全部排列的相邻最大重叠拼接（$\le 3! = 6$ 个）。由定理，候选集包含**每一个**最短超串；又每个候选都是合法超串。故按（长度, 字典序）取最小，恰好返回全部最短超串中的字典序最小者，即题目答案。$m=1$ 时由引理 1，答案必含剩下的串 $t$，而 $|S| = |t|$ 且 $S \supseteq t$ 迫使 $S = t$，直接返回正确。∎

> 💡 定理的证明从未用到 $m \le 3$——「全排列 × 相邻最大重叠」对**任意**个数互不包含的串都精确成立（这正是 SCS 的经典 $O(2^m m^2)$ 状压 DP 精确解法的依据，见延伸思考）。

## 6. 复杂度分析

- **时间复杂度**：$O(n^2)$，$n = |a|+|b|+|c| \le 300$。去重做 $3 \times 3$ 次 $O(n^2)$ 子串判定；排列至多 $3! = 6$ 种，每种 $\le 2$ 次 $O(n^2)$ 重叠搜索 + $O(n)$ 拼接。全部是常数倍的小开销，实测远低于 1 ms 级别。
- **空间复杂度**：$O(n)$，存去重结果、候选串与答案。

> ⚠️ 与 daily 版（$O(L^3)$，$L=\max$ 单串长）相比，本篇省掉了「枚举中间串全部重叠量」整整一层循环——去重 + 换排列把那一层吃掉了。两者都轻松通过 $n \le 100$，但更低的复杂度意味着同样的思路可以直接搬到 $n \sim 10^4$ 的变体。

## 7. 参考代码

### C++（去重 + 全排列 + 相邻最大重叠拼接）

```cpp
class Solution {
public:
    string minimumString(string a, string b, string c) {
        auto overlap = [](const string& x, const string& y) {   // x 的后缀对 y 的前缀
            for (int k = min(x.size(), y.size()); k > 0; --k)
                if (x.compare(x.size() - k, k, y, 0, k) == 0) return (int)k;
            return 0;
        };

        string v[3] = {a, b, c};
        vector<string> keep;
        for (int i = 0; i < 3; ++i) {              // 去重：被包含者删除，相等只留最前一份
            bool subsumed = false;
            for (int j = 0; j < 3 && !subsumed; ++j)
                if (i != j && (v[i] != v[j] || j < i)
                    && v[j].find(v[i]) != string::npos)
                    subsumed = true;
            if (!subsumed) keep.push_back(v[i]);
        }
        if (keep.size() == 1) return keep[0];     // 唯一的最短超串就是它自己

        string ans;
        int n = keep.size();
        vector<int> idx(n);
        iota(idx.begin(), idx.end(), 0);
        do {
            string cur = keep[idx[0]];
            for (int t = 1; t < n; ++t)
                cur += keep[idx[t]].substr(       // 相邻两个【原串】的最大重叠处拼接
                    overlap(keep[idx[t - 1]], keep[idx[t]]));
            if (ans.empty() || cur.size() < ans.size() ||
                (cur.size() == ans.size() && cur < ans))
                ans = cur;                        // 双关键字：先短，同长再比字典序
        } while (next_permutation(idx.begin(), idx.end()));
        return ans;
    }
};
```

### Python（去重 + permutations + 相邻最大重叠拼接）

```python
from itertools import permutations

class Solution:
    def minimumString(self, a: str, b: str, c: str) -> str:
        def overlap(x: str, y: str) -> int:      # x 的长 k 后缀 == y 的长 k 前缀，取最大 k
            for k in range(min(len(x), len(y)), 0, -1):
                if x.endswith(y[:k]):
                    return k
            return 0

        strs, keep = [a, b, c], []
        for i, s in enumerate(strs):             # 去重：被包含者删除，相等只留最前一份
            if not any(i != j and s in t and (s != t or j < i)
                       for j, t in enumerate(strs)):
                keep.append(s)
        if len(keep) == 1:
            return keep[0]

        best = None
        for perm in permutations(keep):          # 2 个串 2 种、3 个串 6 种排列
            cur = perm[0]
            for i in range(1, len(perm)):
                cur += perm[i][overlap(perm[i - 1], perm[i]):]   # 相邻原串的最大重叠
            if best is None or (len(cur), cur) < (len(best), best):
                best = cur                       # 双关键字：先短，同长再比字典序
        return best
```

> 💡 两版结构完全同构：`overlap` 方向为「左串后缀对右串前缀」，循环体里 `perm[i-1]` 与 `perm[i]` 始终是**相邻两个原串**——与 §5 定理的拼接形态一一对应。代码均以 2000+ 组随机用例对拍过暴力枚举（含两个官方样例、相等串、全包含与桥接反例 $(\texttt{xab},\texttt{aby},\texttt{aba})$）。

## 8. 边界情况与易错点

1. **忘去重（高频 WA）**：不去重直接枚举 6 种排列会翻车。反例 $(\texttt{b},\texttt{aa},\texttt{aba})$：不去重时最优候选是 $\texttt{aabab}$（5），而正解是 $\texttt{aaba}$（4）——$\texttt{b} \subseteq \texttt{aba}$，去重后 $\{\texttt{aa},\texttt{aba}\}$ 拼一步即得。被包含的串不删，就会在某些排列里被「再拼一遍」。
2. **相等串互判子串、全删光**：$(\texttt{x},\texttt{x},\texttt{y})$ 中 $\texttt{x} \subseteq \texttt{x}$ 互相成立，若无「只留一份」的例外会把两个 $\texttt{x}$ 都删掉、返回不含 $\texttt{x}$ 的 $\texttt{y}$。判据必须带 $(s_i \ne s_j$ 或 $j < i)$ 的豁免。
3. **重叠方向写反、忘记不对称**：$\operatorname{ov}(\texttt{abc},\texttt{bca}) = 2$（后缀 $\texttt{bc}$ 对前缀 $\texttt{bc}$）而 $\operatorname{ov}(\texttt{bca},\texttt{abc}) = 1$（只有 $\texttt{a}$ 对 $\texttt{a}$）——排列反着算结果完全不同。另注意 $\operatorname{ov}(\texttt{aaa},\texttt{abc}) = 1$ 不是 $0$，首字符就能重叠。
4. **相邻重叠 vs 累积重叠**：`cur = merge(cur, next)`（拿累积串与下一串求重叠）是常见的另一种写法，本题实测同样正确；但证明对应的是「相邻两个**原串**」的重叠（§5 定理），累积式可能出现跨段后缀匹配、候选集合与定理脱节。按相邻式写，逻辑与代码一一对应。
5. **双关键字比较手滑**：必须**先比长度、同长才比字典序**。C++ 版三个条件 `cur.size() < ans.size() || (== && cur < ans)` 的括号层次短路顺序别写错；Python 直接比较 `(len(cur), cur)` 元组最稳。
6. **剩 1 个串别忘了分流**：此时直接返回该串（唯一最短），继续跑排列循环虽然也能对（单元素排列只有一种），但去重后两串已删、若相等串处理有 bug 会在此暴露。
7. **别拿「先拼重叠最大的一对」当算法**：贪心选最大重叠对先合并没有完备性保证（一般 SCS 的贪心合并只有近似保证），而且合并后再与第三个串求重叠又滑向「累积式」。本题 6 种排列全枚举几乎是免费的，严格正解就该全枚举。
8. **无溢出风险**：总长 $\le 300$，比较均为长度与字节序，`int` 足够。
