# LeetCode 木材运输的最小成本 题解

## 1. 题目概述

- **标题 / 题号**：木材运输的最小成本（#3560，easy）
- **链接**：https://leetcode.cn/problems/find-minimum-log-transportation-cost/
- **来源**：LeetCode 第 451 场周赛 Q1
- **难度**：简单
- **标签**：数学、贪心

**题意**：有两根长度分别为 $n$ 和 $m$ 的木材，要用 **3 辆卡车**运走。每辆卡车最多装**一根**长度不超过 $k$ 的木材。可以切割木材：每次把一段长 $x$ 的木材一分为二（$len_1 + len_2 = x$，总长不变），这次切割的成本为 $len_1 \times len_2$。求把木材全部装上卡车的最小总成本；若不需要切割则为 $0$。

**约束**：

- $2 \le k \le 10^5$
- $1 \le n, m \le 2k$
- 输入数据保证木材总存在能被运输的方案（即 $n$、$m$ 不可能同时大于 $k$，见 §5 引理 2）

## 2. 示例

**示例 1**

```text
输入：n = 6, m = 5, k = 5
输出：5
解释：把长度 6 的木材切成 1 + 5，成本 1 × 5 = 5；三段 1、5、5 分别装上三辆卡车。
```

**示例 2**

```text
输入：n = 4, m = 4, k = 6
输出：0
解释：两根木材都不超过 k，直接装车，无需切割。
```

**示例 3（自拟）**

```text
输入：n = 8, m = 3, k = 5
输出：15
解释：8 > 5 必须切：8 → 3 + 5，成本 3 × 5 = 15（若切成 4 + 4，成本 16，更差）。
```

## 3. 解题思路

### 3.1 暴力思路

若某根木材长度 $x > k$，它必须被切。**枚举切点** $t = 1, \dots, x-1$，当两段 $t$ 与 $x - t$ 都不超过 $k$ 时，用 $t \times (x - t)$ 更新答案。单次枚举 $O(k) \approx 10^5$，比赛完全能过——但切点其实可以直接算出来，做到 $O(1)$。

### 3.2 核心观察：至多切一刀，且"切掉恰好超出的部分"

![超长木材只需切一刀](images/log_transport_trucks_concept.svg)

三个关键观察：

1. **至多切一刀**：3 辆卡车、每辆至多装 1 段 ⇒ 最终至多 3 段；两根木材初始就是 2 段，每切一刀段数加 1 ⇒ 切割次数 $\le 3 - 2 = 1$。
2. **只有超长那根需要切**：长度 $x = \max(n, m) > k$ 的木材整根装不下，必须切；另一根由可行性保证 $\le k$，不切。
3. **切点取 $(x-k,\ k)$**：固定两段之和为 $x$ 时，乘积 $len_1 \times len_2$ 在两段**越不均等时越小**；而"每段 $\le k$"限定了最不均等只能到小段 $= x - k$（再小，大段就超过 $k$ 装不下了）。

![固定和的乘积：越不均等越小](images/log_cut_product_minimization.svg)

> 💡 **反直觉点**：固定和的两段乘积在**均分**时**最大**（$x^2/4$），在最不均等时**最小**——与"切木头均匀分"的生活直觉正好相反。最优策略是"**切掉恰好超出的部分**"：大段留满 $k$，小段只留 $x - k$。

### 3.3 算法流程

```text
1. 若 n ≤ k 且 m ≤ k：返回 0
2. 否则令 x = max(n, m)，返回 k × (x − k)
```

### 3.4 示例演算

| 输入 | 判断 | 切法 | 成本 |
|------|------|------|------|
| n=6, m=5, k=5 | max=6 > 5，m 已合格 | 6 → 1 + 5 | 1 × 5 = **5** |
| n=4, m=4, k=6 | 两根都 ≤ 6 | 不切 | **0** |
| n=8, m=3, k=5 | max=8 > 5，m 已合格 | 8 → 3 + 5 | 3 × 5 = **15** |

![示例演算：切与不切两种情形](images/log_transport_example_walkthrough.svg)

## 4. 算法细节

1. **判定被切者**：直接取 $x = \max(n, m)$。$n$、$m$ 不可能同时 $> k$（否则至少要切两刀、产生至少 4 段，超过 3 辆车，无可行方案，与题目保证矛盾），因此超长者必是较大者，无需讨论切哪一根。
2. **公式推导**：设切点（小段长度）为 $t$，约束"两段均 $\le k$"等价于 $x - k \le t \le k$。$f(t) = t(x - t)$ 是开口向下的抛物线，对称轴 $t = x/2$，在 $t \le x/2$ 上单调递增，故 $f$ 在允许区间的最左端 $t = x - k$ 处取最小值 $k(x - k)$。
3. **溢出**：$k \le 10^5$、$x - k \le 10^5$，乘积上界 $10^{10}$，超出 32 位 int（约 $2.1 \times 10^9$）。C++ 必须用 `long long`（题目接口返回值就是 `long long`），且让乘法在 `long long` 上进行；Python 天然无此问题。
4. **不切的分支**：`n <= k && m <= k` 时返回 0，别漏。

## 5. 正确性证明

**引理 1**（至多一刀）：任何可行方案中，切割总次数至多为 1。

**证明**：木材必须全部装车，每辆卡车至多装 1 段，故最终至多 3 段；初始为 2 段，每切一刀段数恰增加 1，故切割次数 $\le 3 - 2 = 1$。∎

**引理 2**（唯一被切者）：若 $x = \max(n, m) > k$，则可行方案必为"把长度 $x$ 的木材切恰好一刀，另一根不切"。

**证明**：$x > k$ 时该木材整根无法装车，必须至少切一刀；结合引理 1，恰好一刀且必花在它身上。若另一根也 $> k$，则它也至少需切一刀，与引理 1 矛盾——即此时根本无可行方案，被题目约束排除；故另一根 $\le k$，直接装车。∎

**引理 3**（最优切点）：设 $k < x \le 2k$，把 $x$ 切成 $t + (x - t)$ 且两段均 $\le k$，则成本 $t(x - t)$ 在 $t = x - k$ 时最小，最小值为 $k(x - k)$。

**证明**：不妨设 $t \le x - t$（$t$ 为小段）。大段 $x - t \le k$ 推出 $t \ge x - k$，故 $t \in [x - k,\ x/2]$（$x \le 2k$ 保证区间非空）。$f(t) = t(x - t)$ 是开口向下的抛物线，对称轴为 $t = x/2$，在 $(-\infty, x/2]$ 上单调递增，因此 $f$ 在区间左端点 $t = x - k$ 处取最小值 $f(x - k) = (x - k) \cdot k$。∎

**定理**：答案为 $0$（当 $\max(n, m) \le k$），否则为 $k \cdot (\max(n, m) - k)$。

**证明**：若 $n \le k$ 且 $m \le k$，两根直接装车，成本为 0；成本非负，故 0 即最优。否则由引理 2，唯一可行形态是"超长者切一刀、另一根不切"，再由引理 3，该刀的最小成本为 $k \cdot (\max(n, m) - k)$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(1)$。只有两次比较和一次乘法。
- **空间复杂度**：$O(1)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long minCuttingCost(int n, int m, int k) {
        if (n <= k && m <= k) {
            return 0;
        }
        long long x = max(n, m);
        return k * (x - k);
    }
};
```

### Python

```python
class Solution:
    def minCuttingCost(self, n: int, m: int, k: int) -> int:
        if n <= k and m <= k:
            return 0
        return k * (max(n, m) - k)
```

## 8. 边界情况与易错点

1. **溢出（本题最大的坑）**：$k(x-k)$ 最大 $10^5 \times 10^5 = 10^{10}$，远超 `int` 上界。C++ 用 `long long`，并保证乘法整体在 64 位上进行（如代码中先把 `x` 声明为 `long long`，或写 `1LL * k * (x - k)`）。
2. **均分陷阱**：固定和时均分乘积最大（$x^2/4$），最优恰恰相反——切得越不均等越好，直到"每段 $\le k$"的边界。
3. **小段下界**：小段不能任意小，必须 $\ge x - k$，否则大段超长装不下。
4. **两根同时超长**：约束保证不会出现（无可行方案），无需特判；也因此直接对 $\max(n, m)$ 计算是安全的。
5. **端点值**：$x = 2k$ 时切成 $k + k$，成本 $k^2$；某根恰为 $k$ 时正好装下，不切。
6. **读题细节**：切割成本只与两段长度的乘积有关，与切割次数无关；"3 辆卡车"是"至多切一刀"的关键（卡车数改多，结论会变），且不必用满所有卡车。
