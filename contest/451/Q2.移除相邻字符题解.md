# LeetCode 移除相邻字符 题解

## 1. 题目概述

- **标题 / 题号**：移除相邻字符（#3561，medium）
- **链接**：https://leetcode.cn/problems/resulting-string-after-adjacent-removals/
- **来源**：LeetCode 第 451 场周赛 Q2
- **难度**：中等
- **标签**：栈、字符串、模拟

**题意**：给定小写字母串 $s$。只要当前串中还存在「位置相邻**且**字母表连续」的一对字符，就不断删除其中**最左边**的一对，右侧字符左移补位（可能拼出新的可消对）。字母表看作**循环**的：`a` 与 `z` 也算连续，且顺序逆序均可（`a`/`b`、`b`/`a` 都行）。返回无法再操作时的最终串。

**约束**：

- $1 \le s.length \le 10^5$
- $s$ 仅由小写英文字母组成

## 2. 示例

**示例 1**

```text
输入：s = "abc"
输出："c"
解释：最左可消对是 (a,b)，删除后剩下 "c"，无更多操作。
```

**示例 2**

```text
输入：s = "adcb"
输出：""
解释：最左可消对是 (d,c)，删除后得 "ab"；再删 (a,b)，得空串。
```

**示例 3**

```text
输入：s = "zadb"
输出："db"
解释：z 与 a 环回相邻，删除 (z,a) 后剩 "db"，d、b 不相邻，结束。
```

**示例 4（自拟）**

```text
输入：s = "aabb"
输出：""
解释：相同字母 (a,a) 不可消；最左可消对是中间交叉的 (a,b)（下标 1,2），
      删除后得 "ab"，再删一次得空串。
```

## 3. 解题思路

### 3.1 暴力思路

每一轮：从左往右扫描当前串，找第一对可消字符（$O(n)$），删除并把后缀整体左移（$O(n)$）。最坏构造 $s = \texttt{z}^{n/2}\texttt{a}^{n/2}$：每轮都要扫到 z/a 边界才找到可消对，删掉后又出现新的 z/a 边界，共需 $n/2$ 轮，总计 $O(n^2) \approx 5 \times 10^9$ 次字符操作，必然超时。瓶颈在于**每轮从头重复扫描**与**删除后的整体搬移**。

### 3.2 核心观察：最左可消对只会是「栈顶 × 新读入的字符」

![循环字母表与栈的核心观察](images/adj_removal_stack_concept.svg)

1. **判定是 $O(1)$ 的**：设两字符为 $x$、$y$，令 $d = |x - y|$，则可消 $\iff d = 1$（普通相邻）或 $d = 25$（`z`↔`a` 环回）。
2. **已扫过的部分不必重扫**：用一个栈保存「已扫描前缀中幸存的字符」。读入新字符 $c$ 时，若栈顶与 $c$ 可消，则（栈顶，$c$）恰好就是当前串的**最左**可消对——因为栈里任何相邻两字符都在后者入栈时检查过不可消，而弹出只发生在栈顶，这些已检查的配对不会突然变成可消对。
3. **消去顺序是本质约束**：本题结果**依赖消去顺序**——`"abc"` 先消 `ab` 得 `"c"`，先消 `bc` 得 `"a"`。所以不能「看到可消就随便消」，必须忠实模拟题目的「最左」规则，而观察 2 恰好说明栈模拟与该规则一致（严格证明见 §5）。

> 💡 这与 1047「删除字符串中的所有相邻重复项」是同款**栈 + 相邻配对删除**套路，但有两处升级：判定从"相等"变成"字母表相邻（含环回）"；且因为消去顺序影响结果，必须想清楚"为什么栈顶配新字符 = 最左一对"。

### 3.3 算法流程

![栈模拟算法流程](images/adj_removal_algorithm_flow.svg)

```text
st ← 空栈
for c in s 从左到右:
    if st 非空 且 |st.top() − c| ∈ {1, 25}:
        st.pop()          # 栈顶与 c 这一对被删除，c 不入栈
    else:
        st.push(c)        # c 幸存
return st 从底到顶拼接
```

### 3.4 示例演算

![示例演算：zadb 与 adcb 的栈演变](images/adj_removal_example_walkthrough.svg)

**示例：s = "zadb"**

| 读入 | 栈（底→顶） | 判定 | 动作 |
|------|------------|------|------|
| z | z | 栈空 | 入栈 |
| a | ∅ | 差 25，环回可消 | 弹出 z，a 不入栈 |
| d | d | 栈空 | 入栈 |
| b | d b | 差 2，不可消 | 入栈 |

最终栈 `db` 即答案。

**示例：s = "adcb"**

| 读入 | 栈（底→顶） | 判定 | 动作 |
|------|------------|------|------|
| a | a | 栈空 | 入栈 |
| d | a d | 差 3，不可消 | 入栈 |
| c | a | 差 1，可消 | 弹出 d，c 不入栈 |
| b | ∅ | 差 1，可消 | 弹出 a，b 不入栈 |

最终栈空，答案为空串。

## 4. 算法细节

1. **可消判定**：`d = abs(st.back() - c)`，`d == 1 || d == 25`。取绝对值同时覆盖顺序/逆序；`25` 专门处理 `z`↔`a` 环回，**最容易漏**。
2. **一对只删两个字符**：弹出栈顶后，新暴露的栈顶**不会**与当前字符再比较——当前字符已随栈顶一起消失；新栈顶要等**下一个**读入的字符来配对。
3. **栈直接当答案容器**：C++ 用 `string` 本身当栈（`push_back` / `pop_back`），扫描结束后 `st` 从下标 0 到末尾恰好是**从左到右**的幸存字符，直接返回，无需反转。Python 用 `list` + `''.join`。
4. **删除 = 不入栈**：题目里"剩余字符左移补位"，在栈视角下就是这两个字符都不进栈，天然完成，无任何搬移开销。

## 5. 正确性证明

**约定**：称一对位置相邻且满足 $d \in \{1, 25\}$ 的字符为**可消对**；不含任何可消对的串称为**既约串**。题目过程 $\mathcal{P}$：反复删除当前串中最左边的可消对，直至串既约。

**引理 1（栈始终既约）**：栈模拟的任意时刻，栈中任意相邻两字符均不构成可消对。

**证明**：设 $v$ 入栈时紧贴其下的元素为 $u$（当时的栈顶），则 $(u, v)$ 已被检查为不可消。此后 $u$、$v$ 在栈中始终保持相邻，直到其中之一被弹出；而栈只能从顶端弹出，若 $v$ 尚在则 $u$（在 $v$ 之下）必未离开，故该相邻关系消失当且仅当 $v$ 先被弹出。因此任意时刻栈中相邻对都保留着"入栈时已检查不可消"的结论。∎

**引理 2（同步性）**：设栈算法已扫完某前缀，栈为 $A$（由引理 1，$A$ 既约），未读后缀为 $B$，且 $\mathcal{P}$ 的当前串为 $A \cdot B$。则 $\mathcal{P}$ 的下一次删除与栈算法继续扫描 $B$ 的下一次弹出删除的是**同一对**字符，且删除后两边回到同一形态（栈为既约的 $A'$，未读后缀为 $B'$，$\mathcal{P}$ 的当前串为 $A' \cdot B'$）。

**证明**：设 $B = b_1 b_2 \cdots$。$\mathcal{P}$ 在 $A \cdot B$ 中寻找最左可消对：$A$ 内部的相邻对（若有）均不可消（$A$ 既约），故最左可消对只有三种可能——

- **边界对 $(\mathrm{last}(A), b_1)$ 可消**：栈算法读 $b_1$ 时栈顶即 $\mathrm{last}(A)$，判定可消，弹出且 $b_1$ 不入栈。两边删除同一对；此后栈为 $A$ 去尾（仍既约），$\mathcal{P}$ 的当前串为 $(A\,\text{去尾}) \cdot b_2 b_3 \cdots$，回到同一形态。
- **$B$ 内部最左可消对 $(b_i, b_{i+1})$**：则边界对不可消，且 $(b_k, b_{k+1})$（$k < i$）均不可消。栈算法读 $b_1, \dots, b_i$ 时逐个入栈（每次检查的配对恰为上述不可消对），读 $b_{i+1}$ 时栈顶为 $b_i$，判定可消并弹出。两边删除同一对；此后栈为 $A \cdot b_1 \cdots b_{i-1}$，它既约（$A$ 既约、边界对与 $(b_k, b_{k+1})$ 均不可消），$\mathcal{P}$ 的当前串为 $A \cdot b_1 \cdots b_{i-1} b_{i+2} \cdots$，回到同一形态。
- **$A \cdot B$ 整体既约**：$\mathcal{P}$ 终止；栈算法把 $B$ 全部入栈（每次配对检查均不可消），最终栈恰为 $A \cdot B$。∎

**定理**：栈模拟删除的字符对序列与 $\mathcal{P}$ 完全一致（逐对相同、顺序相同），最终栈即题目答案。

**证明**：初始时 $A = \emptyset$、$B = s$，两过程处于引理 2 的同一形态。每应用一次引理 2，两过程完成一次相同的删除并回到同一形态，且参与串长严格减小 2；由引理 2 第三种情形终止。对删除次数归纳即得。∎

> ⚠️ **为什么不能换序消**：`"abc"` 先消 `ab` 得 `c`、先消 `bc` 得 `a`，两种终串都既约——本题的消去系统**不满足合流性**，「最左」规则是题目确定性的来源。引理 2 正是验证了栈模拟忠实实现了这一规则。

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。每个字符至多入栈一次、出栈一次，每次配对判定 $O(1)$。
- **空间复杂度**：$O(n)$。栈（即答案容器）最坏保留全部字符，例如 $s$ 全为同一字母时。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    string resultingString(string s) {
        string st;
        for (char c : s) {
            if (!st.empty()) {
                int d = abs(st.back() - c);
                if (d == 1 || d == 25) {
                    st.pop_back();
                    continue;
                }
            }
            st.push_back(c);
        }
        return st;
    }
};
```

### Python

```python
class Solution:
    def resultingString(self, s: str) -> str:
        st = []
        for c in s:
            if st and abs(ord(st[-1]) - ord(c)) in (1, 25):
                st.pop()
            else:
                st.append(c)
        return ''.join(st)
```

## 8. 边界情况与易错点

1. **环回漏判**：`z` 与 `a` 可消（$d = 25$）。只写 `d == 1` 会挂 `"zadb"` 这类用例。
2. **相同字符不可消**：$d = 0$，如 `"aa"` 原样保留；可消是"字母表连续"，不是"相等"。
3. **弹出后不要连续配对**：弹出栈顶后，新暴露的栈顶要等**下一个**字符读入才参与判定，不能拿当前已消费的字符再比一次。
4. **顺序敏感**：不能看到任意可消对就消（`"abc"` 换序消结果不同）；栈"从左到右、只配栈顶"恰好实现了"最左优先"。
5. **单字符**：$|s| = 1$ 时直接返回原串（上面的循环自然处理：入栈后返回）。
6. **结果为空**：可能整个串被消光（如 `"adcb"`），返回空串。
7. **性能**：$n$ 达 $10^5$，暴力每轮扫描加搬移是 $O(n^2)$，必须用栈的一趟扫描。
