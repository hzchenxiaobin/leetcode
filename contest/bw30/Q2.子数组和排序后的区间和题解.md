# LeetCode 子数组和排序后的区间和 题解

## 1. 题目概述

- **标题 / 题号**：子数组和排序后的区间和（#1508，medium）
- **链接**：https://leetcode.cn/problems/range-sum-of-sorted-subarray-sums/
- **来源**：LeetCode 第 30 场双周赛 Q2
- **难度**：中等
- **标签**：数组、双指针、二分查找、前缀和、排序

**题意**：给定含 $n$ 个正整数的数组 `nums`，把**所有非空连续子数组**的和（共 $n(n+1)/2$ 个）**升序排序**得到新数组。返回新数组中下标 `left` 到 `right`（从 1 开始，含两端）的元素之和，结果对 $10^9 + 7$ 取模。

**约束**：

- $1 \le n \le 10^3$
- $1 \le nums[i] \le 100$
- $1 \le left \le right \le n(n+1)/2$

## 2. 示例

**示例 1**

```text
输入：nums = [1,2,3,4], n = 4, left = 1, right = 5
输出：13
解释：全部子数组和为 [1,3,6,10, 2,5,9, 3,7, 4]，排序后
      [1,2,3,3,4,5,6,7,9,10]，下标 1..5 的和 = 1+2+3+3+4 = 13。
```

**示例 2**

```text
输入：nums = [1,2,3,4], n = 4, left = 3, right = 4
输出：6
解释：同上排序数组，下标 3..4 的和 = 3+3 = 6。
```

**示例 3**

```text
输入：nums = [1,2,3,4], n = 4, left = 1, right = 10
输出：50
解释：全部 10 个子数组之和，即 1+2+3+3+4+5+6+7+9+10 = 50。
```

## 3. 解题思路

### 3.1 暴力思路（本题正解）

「收集全部子数组和 → 排序 → 求区间和」就是 $n(n+1)/2$ 个数排序：$n = 10^3$ 时约 $5 \times 10^5$ 个和，排序 $O(N \log N)$（$N = n(n+1)/2$）约 $10^7$ 次比较，毫秒级完成。这**就是**符合数据范围的正解——先算清楚规模再谈优化是周赛的基本功。生成所有和用「固定左端点、向右延伸」的滚动累加即可 $O(n^2)$，连前缀和都不必显式建。

### 3.2 核心观察：所有正数 ⇒ 子数组和有单调结构（进阶视角）

![核心观察：正数数组中固定左端点的子数组和单调递增](images/bw30_q2_triangle_sums.svg)

正解之外值得想一步：若 $n$ 大到 $10^4$ 以上（$N \sim 5 \times 10^7$），排序不可行，如何只求「排序后第 $left \sim right$ 个的和」？利用**元素全为正**这一关键条件：

- 固定左端点 $i$，子数组 $[i, j]$ 的和 $s(i, j)$ 随 $j$ **严格递增**——$n$ 条各自有序的链；
- 「和 $\le x$ 的子数组个数」可用双指针在 $O(n)$ 内数出（每条链上一个单调指针），于是第 $k$ 小的和可以**二分答案** $x \in [1, 100n]$；
- 区间和 =（前 $right$ 个之和）−（前 $left-1$ 个之和），而「前 $k$ 小之和」又能在同一双指针框架下顺带累出。

整套进阶做法 $O(n \log(100n))$，是「求第 k 小而不构造」的经典套路。本题 $n \le 10^3$ 用不上，但值得在 §相关题目 中延伸。

### 3.3 算法流程（正解）

```text
1. sums = []
2. 对每个左端点 i = 0 .. n−1：
        s = 0
        对每个右端点 j = i .. n−1：
            s += nums[j]                # 滚动扩展，O(1) 得到 [i,j] 的和
            sums.push(s)
3. sort(sums)
4. 返回 sum(sums[left−1 .. right−1]) mod (10^9+7)
```

### 3.4 示例演算

![示例演算：1,2,3,4 的 10 个子数组三角形与排序结果](images/bw30_q2_walkthrough.svg)

以 `nums = [1,2,3,4]` 为例，按左端点分组的「和三角形」：

| 左端点 | 延伸的和（j 递增） |
|--------|--------------------|
| 0 | 1, 3, 6, 10 |
| 1 | 2, 5, 9 |
| 2 | 3, 7 |
| 3 | 4 |

共 $4 \times 5 / 2 = 10$ 个，排序后 $[1,2,3,3,4,5,6,7,9,10]$。示例 1 取前 5 个得 $13$；示例 3 取全部得 $50$。

## 4. 算法细节

1. **滚动累加生成**：固定 $i$ 后 $s$ 从 0 起、每右移一位加上 `nums[j]`，内层 $O(1)$；不要对每个 $(i, j)$ 重新求和（那是 $O(n^3)$，$10^9$ 次直接超时）。
2. **预分配空间**：`sums.reserve(n*(n+1)/2)`（C++）一次开够，避免 vector 反复扩容；Python 无此顾虑但可预估规模。
3. **取模时机**：排序必须用**原值**（取模会破坏大小关系！），只在**最后求和阶段**取模。区间内至多 $5 \times 10^5$ 个数、每个 $\le 10^5$（$n \cdot \max = 10^3 \times 100$），总和不超 $5 \times 10^{10}$，64 位整数稳稳放下——C++ 用 `long long` 累加、最后 `% MOD` 一次即可。
4. **下标转换**：题目下标从 1 开始，代码里是 `sums[left-1]` 到 `sums[right-1]` 闭区间，共 $right - left + 1$ 个元素。
5. **Python 的切片求和**：`sum(sums[left-1:right])` 天然表达闭开区间，配合取模干净利落。

## 5. 正确性证明

**引理 1（子数组计数）**：非空连续子数组 $(i, j)$（$0 \le i \le j \le n-1$）恰有 $n(n+1)/2$ 个，且算法生成的 `sums` 与之一一对应。

**证明**：以 $(i, j)$ 双指标计数，$i$ 有 $n$ 种取值，固定 $i$ 后 $j$ 有 $n - i$ 种，合计 $\sum_{i=0}^{n-1}(n-i) = n(n+1)/2$。算法的双重循环按 $(i, j)$ 遍历同一集合且 $s$ 的递推 $s_{i,j} = s_{i,j-1} + nums[j]$（$s_{i,i-1} = 0$）展开后恰为 $\sum_{t=i}^{j} nums[t]$，即子数组 $[i, j]$ 的和，对应关系成立。∎

**引理 2（取模不改变排序）**：若对 `sums` 排序后再取区间和并对 $10^9+7$ 取模，结果与「先取模再操作」的任何错误做法的区别仅在于排序破坏；算法在原值域排序，区间和的真实值 $T$ 满足 $0 \le T < 5.1 \times 10^{10}$，`long long` 精确表示，故返回 $T \bmod (10^9+7)$ 精确等于题目要求。

**证明**：排序在原值域进行，`sums` 的第 $k$ 小（原值）即题面新数组的第 $k$ 项。区间和 $T$ 是 $right-left+1 \le 5 \times 10^5$ 个 $\le 10^5$ 的整数之和，上界 $5 \times 10^{10} < 2^{63}$，整数加法无舍入。取模是题目规定的最后一步，$T \bmod (10^9+7)$ 即答案。∎

**定理**：算法返回值等于题面定义的区间和（模 $10^9+7$）。

**证明**：由引理 1，`sums` 恰为全部子数组和的多重集合；排序后第 $k$ 位与题面新数组第 $k$ 位相同（排序多重集合的唯一性）；由引理 2，区间求和与取模过程精确。∎

## 6. 复杂度分析

- **时间**：$O(n^2 \log n)$。生成 $N = n(n+1)/2 \approx 5 \times 10^5$ 个和是 $O(n^2)$；排序是 $O(N \log N) = O(n^2 \log n)$，为主导项；$n = 10^3$ 时约 $10^7$ 量级操作。
- **空间**：$O(n^2)$。`sums` 存 $5 \times 10^5$ 个 `int`（约 2 MB），是本题换时间的代价；进阶做法可降到 $O(n)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int rangeSum(vector<int>& nums, int n, int left, int right) {
        const long long MOD = 1e9 + 7;
        vector<int> sums;
        sums.reserve((size_t)n * (n + 1) / 2);
        for (int i = 0; i < n; ++i) {
            int s = 0;
            for (int j = i; j < n; ++j) {
                s += nums[j];
                sums.push_back(s);
            }
        }
        sort(sums.begin(), sums.end());
        long long ans = 0;
        for (int i = left - 1; i < right; ++i) ans += sums[i];
        return (int)(ans % MOD);
    }
};
```

### Python

```python
class Solution:
    def rangeSum(self, nums: list[int], n: int, left: int, right: int) -> int:
        MOD = 10 ** 9 + 7
        sums = []
        for i in range(n):
            s = 0
            for j in range(i, n):
                s += nums[j]
                sums.append(s)
        sums.sort()
        return sum(sums[left - 1:right]) % MOD
```

> 💡 两份代码均通过全部官方示例（$13$ / $6$ / $50$）及 $n = 1$ 边界；另与「显式前缀和 $P$、枚举 $(i,j)$ 取 $P[j+1]-P[i]$ 再排序」的独立实现在 40 组随机数组（$n \le 60$，含满规模 $n = 10^3$、全区间与随机子区间）上对拍，失配数为 0。

## 8. 边界情况与易错点

1. **排序前取模 = 大错**：若生成时就把每个和 `% MOD`，正数和不会超 $10^5$（$n \cdot \max(nums) = 10^5 < 10^9+7$），本题碰巧不炸；但把这种习惯带到「和可达 $10^{14}$」的变体里，排序大小关系立刻被模运算破坏。正确顺序永远是**原值排序、末尾取模**。
2. **累加溢出**：区间和上界约 $5 \times 10^{10}$，`int` 放不下（$\approx 2.1 \times 10^9$），C++ 必须用 `long long` 累加（单个和 $\le 10^5$ 用 `int` 存没问题）。
3. **下标从 1 开始**：`left-1`、`right-1` 的闭区间转换，最容易差一；写完可用「区间长 = right - left + 1」自查。
4. **$O(n^3)$ 陷阱**：内层若调 `accumulate(nums.begin()+i, nums.begin()+j+1, 0)`，总代价 $O(n^3) = 10^9$，超时；滚动累加必须形成肌肉记忆。
5. **内存预估**：$5 \times 10^5$ 个 int 约 2 MB，普通内存限制下无压力；但若内存卡到几 MB 就得转向进阶做法。
6. **left == right**：退化为取排序后单个第 $left$ 小，流程自然覆盖，无需特判。
