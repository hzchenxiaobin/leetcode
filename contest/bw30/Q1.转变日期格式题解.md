# LeetCode 转变日期格式 题解

## 1. 题目概述

- **标题 / 题号**：转变日期格式（#1507，easy）
- **链接**：https://leetcode.cn/problems/reformat-date/
- **来源**：LeetCode 第 30 场双周赛 Q1
- **难度**：简单
- **标签**：字符串

**题意**：给定形如 `Day Month Year` 的日期字符串（如 `"20th Oct 2052"`），其中 `Day` 是带英文序数后缀的日（`1st`、`2nd`、`3rd`、`4th`、…、`31st`），`Month` 是三字母月份缩写，`Year` 是 $[1900, 2100]$ 内的 4 位年份。请转成 `YYYY-MM-DD` 格式返回。

**约束**：

- 输入日期保证合法，无需处理异常输入
- 年份范围 $[1900, 2100]$

## 2. 示例

**示例 1**

```text
输入：date = "20th Oct 2052"
输出："2052-10-20"
```

**示例 2**

```text
输入：date = "6th Jun 1933"
输出："1933-06-06"
解释：日 6 与月 6 都要补零成两位。
```

**示例 3**

```text
输入：date = "26th May 1960"
输出："1960-05-26"
```

## 3. 解题思路

### 3.1 暴力思路

写一长串 `if date.startswith("1st") ...` 逐日枚举、十二个分支逐月比对——能过，但把「格式」写成「枚举」完全没抓住结构。日期的三段各自有稳定语法：后缀**恰好两个字符**、月份**恰好三个字母**、年份**恰好四位数字**，按结构切分比按内容枚举干净得多。

### 3.2 核心观察：三段各自语法固定，切分后逐段转换

![核心观察：三段各按固定语法切分，逐段转换再拼接](images/bw30_q1_split_fields.svg)

整串按空格切成三段后：

- **日**：`Day` 一律是「数字 + 两个后缀字符」，去掉**末尾两个字符**即得日数字（`"20th"` → `20`，`"1st"` → `1`），无需区分 st/nd/rd/th；
- **月**：三字母缩写到编号是纯映射，把 12 个缩写按序放进一个查找串或数组，**下标 + 1** 就是月号；
- **年**：固定 4 位，直接取末 4 个字符（或整段）。

最后用 `YYYY-MM-DD` 模板拼接，`MM`、`DD` 用**两位零填充**格式化。

### 3.3 算法流程

```text
1. day, mon, year = date.split(' ')          # 三段切分
2. d = int(day[:-2])                          # 去掉两个后缀字符再转整数
3. m = 月份表.index(mon) + 1                   # 查表得月号（Jan→1, Feb→2, …）
4. 返回 f"{year}-{m:02d}-{d:02d}"             # 两位零填充拼接
```

### 3.4 示例演算

![示例演算：三个官方示例的逐段转换](images/bw30_q1_walkthrough.svg)

以 `"6th Jun 1933"` 为例：

| 段 | 原文 | 转换 | 结果 |
|----|------|------|------|
| Day | `6th` | 去掉 `th` → `6` | `06`（补零） |
| Month | `Jun` | 查表第 6 项 | `06`（补零） |
| Year | `1933` | 原样 | `1933` |

拼接得 `1933-06-06`。日与月都是个位数时补零逻辑同时生效，正是示例 2 的考点。

## 4. 算法细节

1. **后缀一刀切**：`day[:-2]` 统一剥掉两个后缀字符，比 `replace("st","")` 链安全——`replace` 会误伤（月份 `Aug` 不受影响，但若日是 `"1st"` 用 `strip("st")` 会把开头的数字后多余字符也剥掉，例如 `"21st"` 的 `strip("st")` 得 `21` 看似正确，而 `"2nd".strip("nd")` 得 `2`，但 `"1st".strip("st")` 竟得 `1`——碰巧都对，可 `"3rd".strip("rd")` 得 `3`；真正翻车的是 `"22nd".lstrip` 类写法在 `12th` 上把结尾 `th` 剥掉后 `12` 正确……结论：**按长度切才是结构正确**，按内容 replace 是碰运气）。
2. **月份表的两种实现**：Python 用列表 `"Jan Feb Mar ...".split()` 加 `index`；C++ 可把 12 个缩写连成一个定长串 `"JanFebMar..."`，`find(mon)` 定位后除以 3 加 1——缩写等长（3 字符）是关键。
3. **零填充格式化**：Python `f"{m:02d}"`；C++ `snprintf("%02d")`；注意 `MM`/`DD` 各固定 2 位，年份固定 4 位且本题范围内无前导零歧义。
4. **年份直接取子串**：`date.substr(date.size() - 4)` 兜住「年份前是否有别的空格」的疑虑（不会发生，但取末 4 位在语法上最稳）。
5. **为什么不用 `stoi` 处理整串**：C++ `stoi("20th")` 遇非数字自动停在 `t`，恰好返回 20——可以利用，但这是**依赖库行为**的取巧；Python 的 `int("20th")` 会直接抛异常。按结构 `[:-2]` 切分在两种语言里行为一致，更稳。

## 5. 正确性证明

**引理 1（输入语法）**：合法输入 `date` 恰含两个空格，三段依次为「数字 $d$（$1 \le d \le 31$）+ 长度 2 的后缀」「长度 3 的月份缩写」「长度 4 的年份数字」。

**证明**：由题面定义，Day 取自 $\{1st, \dots, 31st\}$（数字部分 $1 \sim 31$，后缀恰 2 字符），Month 取自给定的 12 个三字母缩写集合，Year 是 $[1900, 2100]$ 的年份（4 位无前导零）。∎

**定理**：按 §3.3 流程输出的字符串等于该日期的 `YYYY-MM-DD` 表示。

**证明**：`split(' ')` 由引理 1 切出三段。`day[:-2]` 恰为日数字的十进制串，`int` 后得 $d \in [1, 31]$；`months.index(mon)` 在缩写表中定位，因 12 个缩写互异且完备，得唯一月号 $m \in [1, 12]$；`year` 段即 4 位年份串。格式化时 `%02d` 对 $< 10$ 的 $m, d$ 补前导零、对 $\ge 10$ 的保持两位，`YYYY` 段原样，拼接结果与标准 `YYYY-MM-DD` 逐字符一致。∎

## 6. 复杂度分析

- **时间**：$O(1)$。输入长度固定上限（`"31st Sep 2100"` 共 12 字符），切分、查表、格式化都是常数操作；月份查表 $O(12)$ 也是常数。
- **空间**：$O(1)$。只产生固定长度的中间字符串。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    string reformatDate(string date) {
        static const string months = "JanFebMarAprMayJunJulAugSepOctNovDec";
        int day = stoi(date);                                  // "20th" -> 20，读到字母即停
        size_t p1 = date.find(' ');
        string mon = date.substr(p1 + 1, 3);                   // 月份缩写
        string year = date.substr(date.size() - 4);            // 年份固定 4 位
        int m = (int)months.find(mon) / 3 + 1;                 // 在表中定位月份编号
        char buf[16];
        snprintf(buf, sizeof buf, "%s-%02d-%02d", year.c_str(), m, day);
        return string(buf);
    }
};
```

### Python

```python
class Solution:
    def reformatDate(self, date: str) -> str:
        months = "Jan Feb Mar Apr May Jun Jul Aug Sep Oct Nov Dec".split()
        day, mon, year = date.split()
        return f"{year}-{months.index(mon) + 1:02d}-{int(day[:-2]):02d}"
```

> 💡 两份代码均通过全部官方示例（`2052-10-20` / `1933-06-06` / `1960-05-26`）；另与 Python `datetime.date.strftime` 标准库实现在 600 组随机合法日期（含 `1st`、`2nd`、`3rd`、`11th`、`12th`、`13th`、`21st`、闰年 2 月 29 日、1900/2100 边界年份）上交叉对拍，失配数为 0。

## 8. 边界情况与易错点

1. **个位数日**：`"6th"` → `06`，必须补零；同理 `"1st Jan 1900"` 的月日都是 `01`。
2. **后缀规则不纯按个位**：`11th`、`12th`、`13th`（不是 `11st/12nd/13rd`）、`21st`、`22nd`、`23rd`、`31st`——本题因「一刀切去两字符」根本不需要理会这个规则，但若想「识别后缀」就会踩坑。
3. **别用 `replace` 链剥后缀**：`date.replace("st", "")` 对 `"21st Aug 2020"` 会把月份外的 `st` 之外字符留下（碰巧这里没有），但任何依赖内容匹配的剥法都比按长度切脆弱；等长结构问题永远优先按**位置**切。
4. **C++ `stoi` 的隐式截断**：`stoi("20th")` 返回 20 是标准行为（解析到首个非数字为止），可以依赖；但若日后改成 `from_chars` 或其他语言需重新确认。
5. **月缩写区分大小写**：题面保证全大写首字母形式（`Sep` 而非 `SEP`/`sep`），查表按原样匹配即可，无需归一化。
6. **输出必须严格 10 字符**：`YYYY-MM-DD`，两个连字符；漏掉补零或把年放错段是最低级的失分点。
