# LeetCode 距离相等的条形码 题解

## 1. 题目概述

- **标题 / 题号**：距离相等的条形码（#1054，medium）
- **链接**：https://leetcode.cn/problems/distant-barcodes/
- **来源**：LeetCode 第 138 场周赛 Q4
- **难度**：中等
- **标签**：贪心、数组、哈希表、计数、排序、堆（优先队列）

**题意**：给定数组 `barcodes`，重排其中元素，使得**任意两个相邻元素不相等**。返回任意一个合法排列（题目保证存在答案）。

**约束**：

- $1 \le \text{barcodes.length} \le 10^4$
- $1 \le \text{barcodes}[i] \le 10^4$

**一句话转化**：把出现次数最多的值「摊开」，用其他值当隔板，保证同值之间至少隔一个位置。

## 2. 示例

**示例 1**

```text
输入：barcodes = [1,1,1,2,2,2]
输出：[1,2,1,2,1,2]        （任何合法排列均可，例如 [2,1,2,1,2,1]）
解释：1 与 2 交替出现，任意相邻元素都不同。
```

**示例 2**

```text
输入：barcodes = [1,1,1,1,2,2,3,3]
输出：[1,2,1,2,1,3,1,3]
解释：众数 1 出现 4 次，占满全部 4 个偶数下标；2、3 补进奇数下标，全部相邻位置都不相同。
```

**补充示例（可用性边界）**

```text
输入：barcodes = [1,1,2]
输出：[1,2,1]
解释：众数出现 2 次，恰好等于 ⌈3/2⌉ = 2，仍然可行。
```

## 3. 解题思路

### 3.1 暴力思路

回溯：每次在当前位置尝试放入一个与前一位置不同、且仍有剩余的条形码，第一个填满的方案即为答案。正确但指数级；即使加剪枝，最坏情况的搜索树也难以控制。另一种朴素做法是「每次取当前剩余最多的值」，但若不做邻接检查，很容易在最后几步卡死（例如把 1 全用完后只剩相邻的 2、3 无法隔开）。

### 3.2 核心观察：先填偶数下标，再填奇数下标

![先填偶位、再填奇位](images/wc138_q4_slots.svg)

把结果数组的**偶数下标** $0, 2, 4, \ldots$ 看作一组「互不相邻」的槽位，**奇数下标** $1, 3, 5, \ldots$ 看作另一组。

- 同组内的槽位**一定不相邻**（至少隔一个位置）；
- 需要提防的只有形如 $(2k,\ 2k+1)$ 的**跨组**相邻对。

把出现次数**从大到小**排序后的序列记为 $A$（长度 $n$），先按顺序把 $A$ 的前 $\lceil n/2 \rceil$ 个元素填进偶数槽，再把剩下的填进奇数槽。

为什么这样能保证跨组的相邻对不相等？

![为什么一定合法](images/wc138_q4_pigeonhole.svg)

设某个值 $v$ 在 $A$ 中占据**连续**的一段下标 $[s, s + c - 1]$（$c$ 为出现次数）。若结果中 $v$ 同时出现在位置 $2k$ 与 $2k+1$，那么 $v$ 在 $A$ 中必须同时占据下标 $k$（偶数槽的第 $k$ 个）与下标 $\lceil n/2 \rceil + k$（奇数槽的第 $k$ 个），两者相隔 $\lceil n/2 \rceil$，故 $c \ge \lceil n/2 \rceil + 1$，与「众数不超过 $\lceil n/2 \rceil$」矛盾。

### 3.3 算法流程

```text
1. 统计每个值的频次
2. 按「频次降序、值升序」排序得到序列 items
3. idx = 0；依次取出 items 中的每个元素，重复其次数：
        res[idx] = 该值
        idx += 2
        若 idx >= n：idx = 1            # 偶数槽填完后接着填奇数槽
4. 返回 res
```

`idx` 从 0 开始每次加 2，走完 $0, 2, 4, \ldots$ 后越过末尾，回到 1 继续走 $1, 3, 5, \ldots$，正好等价于「先偶数槽、后奇数槽」。

### 3.4 示例演算

![示例 2 的填充过程](images/wc138_q4_walkthrough.svg)

`barcodes = [1,1,1,1,2,2,3,3]`，$n = 8$，频次排序后 $A = [1,1,1,1,2,2,3,3]$，$\lceil n/2 \rceil = 4$。

| 填充动作 | 槽位 | 结果数组 |
|----------|------|----------|
| 4 个 1 → 偶数槽 | 0, 2, 4, 6 | `[1,_,1,_,1,_,1,_]` |
| 2 个 2 → 奇数槽 | 1, 3 | `[1,2,1,2,1,_,1,_]` |
| 2 个 3 → 奇数槽 | 5, 7 | `[1,2,1,2,1,3,1,3]` |

检查所有相邻对：`1-2`、`2-1`、`1-2`、`2-1`、`1-3`、`3-1`、`1-3`，均不相同 ✓。

再验证示例 1：频次 1 出现 3 次、2 出现 3 次，排序后 $A = [1,1,1,2,2,2]$，前 3 个（三个 1）进偶数槽，后 3 个（三个 2）进奇数槽，得到 `[1,2,1,2,1,2]`。

## 4. 算法细节

1. **排序键要确定**：`(-频次, 值)` 让输出与输入顺序无关，便于对拍与复现；只按频次排序时，同频次的相对顺序依赖哈希表遍历顺序，输出不稳定。
2. **`idx` 的复位**：`if (idx >= n) idx = 1;` 只在越界时复位一次——因为单个元素的填充是逐次推进的，每步只可能越过一次末尾。
3. **不需要堆**：虽然标签里有「堆（优先队列）」，但「先偶位后奇位」的构造不需要动态取最大，排序一次即可，常数更小。
4. **频次统计**：值域 $10^4$，可用数组桶计数（$O(n + C)$），也可用哈希表；C++ 里用 `unordered_map` 后转 `vector<pair<int,int>>` 排序。
5. **`res` 预分配**：长度固定为 $n$，每个位置恰好被写一次，不会遗漏（填充次数之和等于 $n$）。
6. **合法性自检**：写完后可加一次 $O(n)$ 的相邻检查；正式提交时不必，但调试时很有用。

## 5. 正确性证明

**引理 1（可解条件）**：存在合法排列 $\iff$ 众数频次 $c \le \lceil n/2 \rceil$。

**证明**：($\Rightarrow$) 设某值出现 $c$ 次。这 $c$ 个位置两两不相邻，故相邻两个之间至少夹一个其他元素，需要至少 $c - 1$ 个「隔板」，于是 $n \ge 2c - 1$，即 $c \le (n+1)/2 = \lceil n/2 \rceil$。
($\Leftarrow$) 取频次最大的值先填偶数槽（共 $\lceil n/2 \rceil$ 个槽，$c \le \lceil n/2 \rceil$ 填得下），其余值继续按槽位顺序填，即本文构造，见定理。∎

**引理 2（填充等价于分段）**：上述流程等价于：把按频次降序排列的序列 $A$ 的前 $\lceil n/2 \rceil$ 个元素**依次**写入偶数下标，其余元素**依次**写入奇数下标。

**证明**：偶数下标恰好有 $\lceil n/2 \rceil$ 个，流程从 `idx = 0` 起每次加 2 连续写入，写完第 $\lceil n/2 \rceil$ 个元素后 `idx = 2⌈n/2⌉ ≥ n`，复位到 1，此后写入奇数下标。故前 $\lceil n/2 \rceil$ 个元素进偶位、其余进奇位，且各自保持相对顺序。∎

**引理 3（同值在 $A$ 中连续）**：排序后同一值的所有副本在 $A$ 中占据一段连续下标。

**证明**：排序按值分组，相同值的副本必然相邻。∎

**定理**：算法输出的数组满足「任意相邻元素不相等」。

**证明**：结果中相邻的两格必为 $(2k, 2k+1)$ 形式：偶数位置 $2k$ 的值来自 $A$ 的下标 $k$，奇数位置 $2k+1$ 的值来自 $A$ 的下标 $\lceil n/2 \rceil + k$。反设二者相等为 $v$，由引理 3，$v$ 在 $A$ 中占据连续区间 $[s, s+c-1]$，故 $k \ge s$ 且 $\lceil n/2 \rceil + k \le s + c - 1$。两式相减得 $c \ge \lceil n/2 \rceil + 1$，与引理 1 的 $c \le \lceil n/2 \rceil$ 矛盾。故任意相邻两格都不相等。∎

> 注：同一偶数槽组内部（如 $2k$ 与 $2k+2$）或同一奇数槽组内部间隔至少为 2，本来就不相邻，无需讨论。

## 6. 复杂度分析

- **时间**：$O(n + k \log k)$，其中 $k$ 为不同值的个数（$k \le \min(n, 10^4)$）。计数 $O(n)$，排序去重后的频次表 $O(k \log k)$，填充 $O(n)$。最坏 $O(n \log n)$。
- **空间**：$O(n)$ 存放结果数组；计数结构 $O(k)$（数组桶则为 $O(C)$，$C = 10^4$）。

## 7. 参考代码

### C++

```cpp
#include <algorithm>
#include <unordered_map>
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> rearrangeBarcodes(vector<int>& barcodes) {
        int n = (int)barcodes.size();
        unordered_map<int, int> cnt;
        for (int x : barcodes) cnt[x]++;
        vector<pair<int, int>> items;  // (count, value)
        for (auto& kv : cnt) items.push_back({kv.second, kv.first});
        sort(items.begin(), items.end(), [](const pair<int, int>& a, const pair<int, int>& b) {
            if (a.first != b.first) return a.first > b.first;   // 频次降序
            return a.second < b.second;                          // 频次相同按值升序
        });
        vector<int> res(n, 0);
        int idx = 0;
        for (auto& it : items) {
            for (int k = 0; k < it.first; k++) {
                res[idx] = it.second;
                idx += 2;
                if (idx >= n) idx = 1;
            }
        }
        return res;
    }
};
```

### Python

```python
from collections import Counter


class Solution:
    def rearrangeBarcodes(self, barcodes: list[int]) -> list[int]:
        n = len(barcodes)
        cnt = Counter(barcodes)
        res = [0] * n
        idx = 0
        for value, freq in sorted(cnt.items(), key=lambda kv: (-kv[1], kv[0])):
            for _ in range(freq):
                res[idx] = value
                idx += 2
                if idx >= n:
                    idx = 1
        return res
```

## 8. 边界情况与易错点

1. **`n == 1`**：只有一格，任意返回原数组；流程中 `idx = 0 → 2 >= 1 → 复位 1`，但循环已结束，结果正确。
2. **众数恰好 $\lceil n/2 \rceil$**：如 `[1,1,2]`、`[1,1,1,2,2]`，众数会占满整个偶数槽，此时奇数槽必须全部由其他值填充，构造仍然成立，不要误判为无解。
3. **只有两个不同的值且频次相同**：如 `[1,1,2,2]`，交替填充即可，注意别把同一个值连续写在偶位和奇位的接缝处。
4. **频次相同时的顺序**：只按频次排序会让输出依赖哈希遍历顺序，导致 Python 与 C++ 结果不同；用 `(-频次, 值)` 固定下来。
5. **`idx` 复位条件**：写成 `idx = (idx + 2) % (n + 1)` 之类会打乱奇偶分组，必须用「越界则置 1」。
6. **忘记保证「多集相同」**：构造只能重排、不能丢弃或新增元素，答案的元素频次必须与原数组一致。
7. **返回的不是唯一答案**：判题会用特判器验证相邻不同，因此不能直接与示例输出做字符串比较。
