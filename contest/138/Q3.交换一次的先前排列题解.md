# LeetCode 交换一次的先前排列 题解

## 1. 题目概述

- **标题 / 题号**：交换一次的先前排列（#1053，medium）
- **链接**：https://leetcode.cn/problems/previous-permutation-with-one-swap/
- **来源**：LeetCode 第 138 场周赛 Q3
- **难度**：中等
- **标签**：贪心、数组

**题意**：给定正整数数组 `arr`（**可以含重复元素**）。允许**恰好交换一次**两个位置的元素（也可以选择不交换），问能得到的、字典序**小于** `arr` 的**最大**排列。若不存在这样的排列，返回原数组。

**约束**：

- $1 \le \text{arr.length} \le 10^4$
- $1 \le \text{arr}[i] \le 10^4$（重复元素存在）

**一句话转化**：把所有「一次交换后变小」的结果都视为候选，求其中的字典序最大值；等价于 **`arr` 的前一个排列，且只允许交换一对位置**。

## 2. 示例

**示例 1**

```text
输入：arr = [3,2,1]
输出：[3,1,2]
解释：交换 2 和 1（下标 1 与 2）。
```

**示例 2**

```text
输入：arr = [1,1,5]
输出：[1,1,5]
解释：已经是最小排列，任何交换都不会变小，只能原样返回。
```

**示例 3**

```text
输入：arr = [1,9,4,6,7]
输出：[1,7,4,6,9]
解释：交换 9 和 7（下标 1 与 4）。
```

**补充示例（重复元素必须取最左）**

```text
输入：arr = [3,1,1,3]
输出：[1,3,1,3]
解释：下标 0 是唯一的下降点；右侧小于 3 的最大值是 1，且 1 出现两次（下标 1、2）。
      取最左的 1 交换得到 [1,3,1,3]；若与下标 2 交换会得到更小的 [1,1,3,3]。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有二元组 $(i, j)$（$i < j$）交换后判断是否变小，在变小者中取字典序最大。共 $O(n^2)$ 个候选，每个候选比较需要 $O(n)$，总计 $O(n^3)$；即使只做「字典序比较」的增量判断，也要 $O(n^2)$。$n = 10^4$ 时 $10^8$ 量级，风险很大，而且没有揭示结构。

### 3.2 核心观察：最靠右的下降点

![最靠右的下降点 i](images/wc138_q3_descent.svg)

设交换的是 $i < j$ 两个位置。交换后：

- 前缀 $\text{arr}[0..i-1]$ **不变**；
- 位置 $i$ 的值由 $\text{arr}[i]$ 变成 $\text{arr}[j]$。

要让结果**变小**，必须 $\text{arr}[j] < \text{arr}[i]$——这就是题目提示里说的「被换走的那个更大的数在哪儿」。而要让结果**尽可能大**，第一原则是**前缀尽量长**，即 $i$ 尽量靠右。

于是：

1. 从右往左找第一个满足 $\text{arr}[i] > \text{arr}[i+1]$ 的下标 $i$，即**最靠右的下降点**。找不到说明数组单调不降，已是字典序最小，直接返回。
2. $i$ 确定后，在 $i$ 右侧所有小于 $\text{arr}[i]$ 的元素里，挑**值最大**的那个换到位置 $i$（这样位置 $i$ 尽量大，结果字典序尽量大）。

**为什么 $i$ 右侧可以随便挑，不用担心中间被破坏？** 因为 $i$ 是最靠右的下降点，所以 $\text{arr}[i+1] \le \text{arr}[i+2] \le \cdots \le \text{arr}[n-1]$，后缀单调不降。交换 $(i, j)$ 只改动 $i$ 和 $j$ 两个位置，从 $i+1$ 到 $j-1$ 的值保持原样，$j$ 之后也保持原样。

### 3.3 算法流程

![在 i 右侧挑最大的更小值](images/wc138_q3_pick_j.svg)

```text
1. i = n-2；当 i >= 0 且 arr[i] <= arr[i+1] 时 i--
2. 若 i < 0：返回原数组（不存在更小的排列）
3. j = n-1；当 arr[j] >= arr[i] 时 j--      # 后缀不降 ⇒ 首个 < arr[i] 的即最大值
4. 若 arr[j-1] == arr[j] 则继续左移，直到取到该值的最左出现
5. 交换 arr[i], arr[j] 并返回
```

第 3 步之所以能一次从右扫到答案：后缀单调不降，从右往左遇到的**第一个**小于 $\text{arr}[i]$ 的元素，就是右侧所有更小元素中**最大**的那个。

第 4 步处理重复值：设这个最大候选值 $v = \text{arr}[j]$ 在右侧出现了多次，取**最左**的那次交换最优——因为交换后 $\text{arr}[i]$（比 $v$ 大）被放到 $j$ 位置，越靠左越能提升字典序。

### 3.4 示例演算

![三个示例的走查](images/wc138_q3_walkthrough.svg)

以 `arr = [1,9,4,6,7]` 为例：

| 步骤 | 结果 | 说明 |
|------|------|------|
| 找下降点 | $i = 1$ | `arr[1]=9 > arr[2]=4`；下标 2、3 处都是上升 |
| 后缀 | `[4,6,7]` | 单调不降，符合「$i$ 最靠右」 |
| 从右找 $j$ | $j = 4$ | `arr[4]=7 < 9`，是右侧小于 9 的最大值 |
| 重复检查 | 无需左移 | `arr[3]=6 ≠ 7` |
| 交换 | `[1,7,4,6,9]` | 答案 |

再看重复值例子 `[3,1,1,3]`：下降点 $i = 0$（`3 > 1`）；右侧小于 3 的最大值是 1；`arr[1] == arr[2] == 1`，左移到 $j = 1$，交换得到 `[1,3,1,3]`。

## 4. 算法细节

1. **下降点判定用 `<=`**：`arr[i] <= arr[i+1]` 时继续左移，即只有**严格下降**才算候选；相等不算下降（交换相等的值数组不变，不可能更小）。
2. **后缀不降的保证**：正因为 $i$ 是最靠右的下降点，才保证 $i$ 右侧非递减，从而「从右扫到的第一个更小值」就是最大候选。这是整个贪心的支点。
3. **重复值必须取最左**：只做 `while (arr[j] >= arr[i]) j--;` 会落在该值的**最右**出现处，得到的是更大值被放到更靠右的位置，字典序偏小。
4. **边界 `j - 1 > i`**：左移重复值时不能越过 $i$ 本身。
5. **原地交换后返回**：题目返回新数组，允许原地修改入参（LeetCode 会拷贝）。
6. **值域无关**：只做比较和交换，不涉及乘法，无溢出风险。

## 5. 正确性证明

记一次交换 $(i, j)$（$i < j$）得到数组 $A^{(i,j)}$。

**引理 1（交换变小的充要条件）**：$A^{(i,j)} < \text{arr}$ $\iff$ $\text{arr}[j] < \text{arr}[i]$。

**证明**：前缀 $\text{arr}[0..i-1]$ 两数组相同。位置 $i$ 处，$A^{(i,j)}[i] = \text{arr}[j]$，故若 $\text{arr}[j] < \text{arr}[i]$，在第一个不同位置 $i$ 上更小，$A^{(i,j)} < \text{arr}$；若 $\text{arr}[j] > \text{arr}[i]$ 则更大；若相等则两数在 $i, j$ 处互换后数组完全相同（值相同），既不更大也不更小。∎

**引理 2（后缀单调不降）**：设 $i^*$ 为最大下标使 $\text{arr}[i^*] > \text{arr}[i^*+1]$，则 $\text{arr}[i^*+1..n-1]$ 非递减。

**证明**：若存在 $k \ge i^*+1$ 使 $\text{arr}[k] > \text{arr}[k+1]$，则 $k$ 也是下降点且 $k > i^*$，与 $i^*$ 的最大性矛盾。∎

**引理 3（$i$ 取最右最优）**：设存在可变小交换，则所有可变小交换中 $i$ 的最大可能值就是 $i^*$；且任何 $i < i^*$ 的结果都小于用 $i^*$ 得到的最优结果。

**证明**：$A^{(i,j)}$ 与 `arr` 的第一个不同位置是 $i$。若 $i < i^*$ 且 $A^{(i,j)} < \text{arr}$，则比较 $A^{(i,j)}$ 与 $A^{(i^*, j')}$：两者前 $i$ 位都等于 `arr`；在位置 $i$ 上，前者 $=\text{arr}[j] < \text{arr}[i]$，而后者（若交换位置都在 $i$ 之后）在位置 $i$ 仍是 $\text{arr}[i]$，故后者更大。因此最优解的 $i$ 必须是 $i^*$（若 $i^*$ 存在可变小交换）。而 $i^*$ 处存在这样的 $j$（因为 $\text{arr}[i^*] > \text{arr}[i^*+1]$，取 $j = i^*+1$ 即可）。∎

**引理 4（$j$ 的取法最优）**：固定 $i = i^*$，令 $v^* = \max\{\text{arr}[j] : j > i^*,\ \text{arr}[j] < \text{arr}[i^*]\}$，$j^*$ 为 $v^*$ 在右侧的**最左**出现位置。则 $A^{(i^*, j^*)}$ 是所有以 $i^*$ 为交换左端的候选中的最大者。

**证明**：由引理 1，这些候选都 $< \text{arr}$，且它们的前 $i^*$ 位相同。位置 $i^*$ 上放的是 $\text{arr}[j]$，故取 $v^*$ 最大；若有两个 $j_1 < j_2$ 都等于 $v^*$，比较 $A^{(i^*,j_1)}$ 与 $A^{(i^*,j_2)}$：位置 $i^*$ 相同；在 $j_1$ 处，前者为 $\text{arr}[i^*]$，后者仍为 $v^* < \text{arr}[i^*]$，故前者更大。所以取最左的 $j^*$ 最优。∎

**定理**：算法输出即为题目要求的答案。

**证明**：由引理 3、4，若存在下降点，最优交换必为 $(i^*, j^*)$，算法第 1、3、4 步恰好求出 $i^*$ 与 $j^*$（第 3 步利用引理 2 从右扫到 $v^*$，第 4 步左移到最左出现），故输出最优。若无下降点，则对任意 $i < j$ 都有 $\text{arr}[j] \ge \text{arr}[i]$（后缀处处非递减，任意 $i<j$ 有 $\text{arr}[i] \le \text{arr}[j]$），由引理 1 不存在变小交换，返回原数组正确。∎

## 6. 复杂度分析

- **时间**：$O(n)$。找 $i$ 的循环最多走 $n-1$ 步；找 $j$ 与左移重复值合计也只向右半部分走一遍（两者都只单调左移，共 $O(n)$）。
- **空间**：$O(1)$。只用几个下标变量，交换原地完成。

## 7. 参考代码

### C++

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> prevPermOpt1(vector<int>& arr) {
        int n = (int)arr.size();
        int i = n - 2;
        while (i >= 0 && arr[i] <= arr[i + 1]) i--;
        if (i < 0) return arr;
        int j = n - 1;
        while (arr[j] >= arr[i]) j--;
        while (j - 1 > i && arr[j - 1] == arr[j]) j--;
        swap(arr[i], arr[j]);
        return arr;
    }
};
```

### Python

```python
class Solution:
    def prevPermOpt1(self, arr: list[int]) -> list[int]:
        n = len(arr)
        i = n - 2
        while i >= 0 and arr[i] <= arr[i + 1]:
            i -= 1
        if i < 0:
            return arr
        j = n - 1
        while arr[j] >= arr[i]:
            j -= 1
        while j - 1 > i and arr[j - 1] == arr[j]:
            j -= 1
        arr[i], arr[j] = arr[j], arr[i]
        return arr
```

## 8. 边界情况与易错点

1. **`n == 1`**：$i = -1$，直接返回原数组，不越界（`arr[i+1]` 在循环条件里已由 `i >= 0` 保护）。
2. **数组单调不降**：如 `[1,1,5]`，无下降点，返回原数组。这是「已经是最小排列」的唯一情形。
3. **相等元素不算下降**：`arr[i] == arr[i+1]` 时交换无变化，必须用严格大于判断下降点。
4. **重复候选值取最左**：漏掉第 4 步会得到 `[1,1,3,3]`（对 `[3,1,1,3]`），比正确答案小。
5. **`arr[j] >= arr[i]` 的左移不会越界**：因为 $i$ 是下降点，$j = i+1$ 处必有 $\text{arr}[i+1] < \text{arr}[i]$，循环一定在 $j > i$ 处停下。
6. **交换后不要排序后缀**：真正的「前一个排列」还会把后缀重排为降序，但本题限制**只能交换一次**，排序后缀会产生更小的结果、也违反规则。
7. **返回类型**：C++ 返回 `vector<int>`，可以原地改 `arr` 后返回它；不要返回引用以免判题比较出错。
