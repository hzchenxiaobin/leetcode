# LeetCode 二进制位得分 题解

## 1. 题目概述

- **标题 / 题号**：二进制位得分（#4092，easy）
- **链接**：https://leetcode.cn/problems/binary-digit-score/
- **来源**：LeetCode 第 525 场周赛 Q1
- **难度**：简单
- **标签**：位运算、数学

**题意**：给定两个整数 `a` 和 `b`。设 $s_1$、$s_2$ 分别为 `a`、`b` 的二进制表示中置位（值为 1 的位）的个数。两个整数的得分定义如下：

- 若 $s_1 \ge s_2$，得分为 $s_1 \times s_2$；
- 否则，得分为 $s_2 / s_1$（整数除法）。

返回 `a` 和 `b` 的得分。

**约束**：

- `1 <= a, b <= 100`

## 2. 示例

**示例 1**

```text
输入：a = 14, b = 6
输出：6
解释：14 = "1110"，s1 = 3；6 = "110"，s2 = 2。
      s1 > s2，得分 = s1 × s2 = 3 × 2 = 6。
```

**示例 2**

```text
输入：a = 5, b = 15
输出：2
解释：5 = "101"，s1 = 2；15 = "1111"，s2 = 4。
      s1 < s2，得分 = s2 / s1 = 4 / 2 = 2（整除）。
```

**示例 3**

```text
输入：a = 10, b = 12
输出：4
解释：10 = "1010"，s1 = 2；12 = "1100"，s2 = 2。
      s1 == s2，走 s1 >= s2 分支，得分 = 2 × 2 = 4。
```

## 3. 解题思路

### 3.1 暴力思路

签到题，按定义直接模拟：分别统计 `a`、`b` 二进制表示中 1 的个数，再按 $s_1$ 与 $s_2$ 的大小关系分支即可。没有更朴素的做法，也不存在需要优化的瓶颈。

### 3.2 核心观察：popcount + 不对称分支

![核心观察：popcount + 分支](images/binary_digit_score_flow.svg)

两个关键点：

1. **置位计数就是 popcount**：统计二进制中 1 的个数是标准位运算操作，C++ 用 `__builtin_popcount`，Python 用 `int.bit_count()`（3.10+）或 `bin(x).count('1')`，也可以手写「逐位检查 + 右移」。

2. **得分定义不对称，这是本题唯一的坑**：$s_1 \ge s_2$ 时用**乘法**，$s_1 < s_2$ 时用**整除**。也就是说交换 `a`、`b` 的位置，答案可能完全不同——例如 $(a,b)=(14,6)$ 得分为 $3 \times 2 = 6$，而 $(a,b)=(6,14)$ 得分为 $3 / 2 = 1$（整除）。不要想当然地把两数排序或交换。

### 3.3 算法流程

```text
1. s1 = popcount(a)，s2 = popcount(b)
2. 若 s1 >= s2：返回 s1 * s2
3. 否则：      返回 s2 / s1   （整数除法）
```

约束 `a, b >= 1` 保证 $s_1, s_2 \ge 1$，整除分支不存在除零风险。

### 3.4 示例演算

![示例演算：三个分支各走一遍](images/binary_digit_score_examples.svg)

| a | 二进制 | $s_1$ | b | 二进制 | $s_2$ | 分支 | 得分 |
|---|--------|-------|---|--------|-------|------|------|
| 14 | 1110 | 3 | 6 | 110 | 2 | $3 \ge 2$，乘 | $3 \times 2 = 6$ |
| 5 | 101 | 2 | 15 | 1111 | 4 | $2 < 4$，除 | $4 / 2 = 2$ |
| 10 | 1010 | 2 | 12 | 1100 | 2 | $2 = 2$，乘 | $2 \times 2 = 4$ |
| 6 | 110 | 2 | 14 | 1110 | 3 | $2 < 3$，除 | $3 / 2 = 1$（陷阱行） |

最后一行是示例 1 交换 `a`、`b` 后的结果：同样两个数，得分从 6 变成 1，直观体现了运算的不对称性。

## 4. 算法细节

1. **popcount 的实现**：
   - C++：`__builtin_popcount(x)`（GCC/Clang 内建函数），或 C++20 的 `std::popcount`；
   - Python：`x.bit_count()`（3.10+），低版本用 `bin(x).count('1')`；
   - 手写：`while (x) { cnt += x & 1; x >>= 1; }`。
2. **分支包含相等**：$s_1 = s_2$ 时走乘法分支（条件是 $s_1 \ge s_2$），不要写成严格大于。
3. **整数除法**：两个操作数均为正整数，C++ 的 `/` 与 Python 的 `//` 语义一致，直接使用。
4. **无需担心溢出**：`a, b <= 100`，则 $s_1, s_2 \le 6$（不超过 100 的数中最多 6 个置位，如 63 = 111111），乘积最大 36，`int` 绰绰有余。

## 5. 正确性证明

**引理 1**：`popcount(x)` 恰好返回 `x` 的二进制表示中值为 1 的位的个数。

**证明**：正整数 `x` 的二进制表示唯一且每一位非 0 即 1。无论逐位检查 `x & 1` 后右移（每位恰好被检查一次），还是内建函数（等价于按二进制表示计数），统计的都是所有取值为 1 的位。∎

**定理**：算法返回的正是题目定义的 `a`、`b` 的得分。

**证明**：由引理 1，$s_1$、$s_2$ 计算正确。按定义分两种情形：当 $s_1 \ge s_2$ 时算法返回 $s_1 \times s_2$，与定义一致；当 $s_1 < s_2$ 时算法返回 $\lfloor s_2 / s_1 \rfloor$，与定义中的整数除法一致。两分支覆盖所有情形且互斥，故返回值正确。∎

## 6. 复杂度分析

- **时间复杂度**：$O(\log a + \log b)$，即两次 popcount 的位数开销；在本题约束下（`a, b <= 100`，不超过 7 位二进制）为 $O(1)$。
- **空间复杂度**：$O(1)$，仅使用常数个变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int calculateScore(int a, int b) {
        int s1 = __builtin_popcount(a);
        int s2 = __builtin_popcount(b);
        return s1 >= s2 ? s1 * s2 : s2 / s1;
    }
};
```

### Python

```python
class Solution:
    def calculateScore(self, a: int, b: int) -> int:
        s1, s2 = a.bit_count(), b.bit_count()
        return s1 * s2 if s1 >= s2 else s2 // s1
```

## 8. 边界情况与易错点

1. **运算不对称**：$s_1 < s_2$ 时改用整除，交换 `a`、`b` 结果可能不同（如 $(14,6) \to 6$ 但 $(6,14) \to 1$）。不要排序、不要交换。
2. **相等情形**：$s_1 = s_2$ 走乘法分支，条件是 $\ge$ 而不是 $>$。
3. **整数除法**：Python 必须用 `//`；用 `/` 会得到浮点数导致答案错误。C++ 中两个 `int` 相除即为整除。
4. **除零不存在**：约束 `a, b >= 1` 保证 $s_1, s_2 \ge 1$。若约束放宽到允许 0（$s_1 = 0$ 且 $s_1 < s_2$ 时整除无定义），需要额外特判。
5. **popcount 别数错**：手写循环时注意终止条件是 `x != 0` 而非 `x > 1`；本题正数下无符号问题。
