# LeetCode 不同的平均值数目 题解

## 1. 题目概述

- **标题 / 题号**：不同的平均值数目（#2465，easy）
- **链接**：https://leetcode.cn/problems/number-of-distinct-averages/
- **来源**：LeetCode 第 91 场双周赛 Q1
- **难度**：简单
- **标签**：数组、哈希表、双指针、排序

**题意**：给定长度为偶数的数组 `nums`，重复执行「删掉最小值、删掉最大值、计算两数平均值」直到数组为空，返回过程中出现的**不同**平均值的数目。最小值/最大值有重复时删哪个都一样。

**约束**：

- $2 \le nums.length \le 100$，且长度为偶数
- $0 \le nums[i] \le 100$

## 2. 示例

**示例 1**

```text
输入：nums = [4,1,4,0,3,5]
输出：2
解释：三轮删除得到平均值 2.5（0 与 5）、2.5（1 与 4）、3.5（3 与 4），不同值共 2 个。
```

**示例 2**

```text
输入：nums = [1,100]
输出：1
解释：只有一轮 (1, 100)，平均值 50.5，共 1 个。
```

**示例 3（边界补充）**

```text
输入：nums = [0,0,0,0]
输出：1
解释：两轮平均值都是 0，去重后只有 1 个。
```

## 3. 解题思路

### 3.1 暴力思路

按题面逐轮模拟：每轮线性扫描找最小、最大并删除（`O(n)`），共 $n/2$ 轮，总复杂度 $O(n^2)$；再把每次的平均值（浮点）塞进哈希集合，最后返回集合大小。$n \le 100$ 时这也能过，但每轮都重新扫描既冗余又容易在浮点比较上膈应——平均值是 $(a+b)/2$，除数恒为 $2$，两个平均值相等当且仅当两个**和**相等，根本不必引入浮点。

### 3.2 核心观察：排序后「第 i 小配第 i 大」

![核心观察：排序后双指针收拢配对](images/bw91_q1_two_pointer_model.svg)

每轮删「一个最小 + 一个最大」，等价于把数组排序后**从两端向中间配对**：第 $i$ 轮删掉的恰好是排序后第 $i$ 小与第 $i$ 大的元素。于是排序 + 双指针（`i` 从左、`j` 从右同步收拢）即可得到所有配对，无需真的反复删除。

去重用「和」而不是「平均值」：$(a+b)/2 = (c+d)/2 \iff a+b = c+d$。数值范围 $0 \sim 100$，和的范围 $0 \sim 200$，一个长度 201 的布尔数组就能当哈希表用，**完全避开浮点精度问题**。

### 3.3 算法流程

```text
1. nums 升序排序
2. seen[0..200] 清零
3. i = 0, j = n−1
4. 当 i < j：
       seen[nums[i] + nums[j]] = true
       i++，j−−
5. 返回 seen 中 true 的个数
```

### 3.4 示例演算

![示例演算：三轮配对与去重](images/bw91_q1_walkthrough.svg)

以 `nums = [4,1,4,0,3,5]` 为例：排序得 $[0,1,3,4,4,5]$。配对 $(0,5) \to 2.5$、$(1,4) \to 2.5$、$(3,4) \to 3.5$；对应「和」$5, 5, 7$，去重后 $\{5,7\}$，答案 $2$。第二个 $4$ 无论被当作「最大」删掉还是留给下一轮，配对的值都不变——重复元素天然无需特判。

## 4. 算法细节

1. **排序是配对正确性的来源**：排序后第 $i$ 小必然与第 $i$ 大配对（证明见 §5），不要试图在原数组上边找边删。
2. **用布尔数组代替 `set<double>`**：`seen[nums[i]+nums[j]]`，下标范围 $0 \sim 200$，比浮点集合更快也更稳。
3. **双指针终止条件**：`i < j`。长度为偶数保证收拢时恰好两两配完，不会出现 `i == j` 的落单元素。
4. **Python 写法**：直接 `seen = set()` 存整数和即可，语言层面无需布尔数组优化。

## 5. 正确性证明

**引理 1（配对不变性）**：设排序后数组为 $a_0 \le a_1 \le \dots \le a_{n-1}$。逐轮「删一个最小 + 一个最大」的过程，第 $k$ 轮（$k$ 从 1 计）删掉的两个元素恰为 $a_{k-1}$ 与 $a_{n-k}$。

**证明**：对 $k$ 归纳。$k=1$ 时删掉的即全局最小与最大，排序后即 $a_0$ 与 $a_{n-1}$（若最小值有多个，删哪个值都相同，排序后仍对应 $a_0$）。设前 $k-1$ 轮删掉了 $a_0..a_{k-2}$ 与 $a_{n-k+2}..a_{n-1}$，剩余集合恰为 $\{a_{k-1}, \dots, a_{n-k}\}$，其最小为 $a_{k-1}$、最大为 $a_{n-k}$，故第 $k$ 轮删掉二者。∎

**引理 2（和与平均值等价）**：对任意四个数 $a,b,c,d$，$\frac{a+b}{2} = \frac{c+d}{2} \iff a+b = c+d$。

**证明**：等式两边同乘 2 即得。∎

**定理**：算法返回的值等于逐轮模拟得到的不同平均值数目。

**证明**：由引理 1，双指针每轮计算的 $nums[i]+nums[j]$ 恰为该轮两数之和；由引理 2，对这些和去重等价于对平均值去重。$i<j$ 恰执行 $n/2$ 轮，与模拟的轮数一致。∎

## 6. 复杂度分析

- **时间**：$O(n \log n)$，排序主导；双指针收拢与统计各 $O(n)$。
- **空间**：$O(n)$（排序）+ $O(C)$，$C = 201$ 为布尔数组大小；Python 的 `set` 至多存 $n/2 \le 50$ 个和。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int distinctAverages(vector<int>& nums) {
        sort(nums.begin(), nums.end());
        int n = (int)nums.size();
        vector<bool> seen(201, false);          // 和的范围 0..200
        for (int i = 0, j = n - 1; i < j; ++i, --j) {
            seen[nums[i] + nums[j]] = true;     // 平均值 = 和 / 2，用和去重
        }
        int ans = 0;
        for (bool b : seen) ans += b;
        return ans;
    }
};
```

### Python

```python
class Solution:
    def distinctAverages(self, nums: list[int]) -> int:
        nums.sort()
        seen = set()                     # 用两数之和去重（平均值 = 和 / 2）
        i, j = 0, len(nums) - 1
        while i < j:
            seen.add(nums[i] + nums[j])
            i += 1
            j -= 1
        return len(seen)
```

> 💡 两份代码均通过官方示例（`2`、`1`），并与「真实删除模拟 + 浮点集合」的暴力对拍 2000 组随机数据，结果完全一致。

## 8. 边界情况与易错点

1. **长度为 2**：只有一轮配对，答案至少为 1（两个数只有一个平均值）。
2. **浮点精度**：不要用 `(a+b)/2.0` 存 `set<double>`——本题数值下虽然恰好安全，但「用和去重」是无条件正确的习惯写法。
3. **重复的最小/最大**：删哪个副本不影响配对的**值**，排序天然消歧，无需任何特判。
4. **布尔数组大小**：`nums[i] ≤ 100`，两数之和最大 200，数组开 201；若照抄成 101 会越界（C++ 未定义行为）。
5. **`i < j` 而非 `i != j`**：虽然长度为偶数时二者等价，写 `i < j` 更防御性。
6. **不要真的每轮 `erase`**：$O(n^2)$ 的模拟虽能过，但排序 + 双指针才是这题想考的「化删除为收拢」。
