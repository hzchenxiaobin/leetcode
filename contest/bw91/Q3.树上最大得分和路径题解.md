# LeetCode 树上最大得分和路径 题解

## 1. 题目概述

- **标题 / 题号**：树上最大得分和路径（#2467，medium）
- **链接**：https://leetcode.cn/problems/most-profitable-path-in-a-tree/
- **来源**：LeetCode 第 91 场双周赛 Q3
- **难度**：中等
- **标签**：树、深度优先搜索、广度优先搜索、图、数组

**题意**：$n$ 个节点（$0$ 为根）的无向树，每个节点 $i$ 有一扇门，`amount[i]` 为偶数：正数表示开门加分、负数表示开门扣分。游戏规则：

- Alice 从节点 $0$ 出发，每一秒移到相邻节点，**朝着某个叶子**移动，到达叶子后停止；
- Bob 从节点 `bob` 出发，每一秒移到相邻节点，**朝着节点 0** 移动，到达后停止；
- 对自己路径上的每个节点，各自打开门获得加分/扣分：若门已被对方打开，则不加分不扣分；若**同时**到达同一节点，两人**平分**该节点的分数（各得 $c/2$）。

求 Alice 按最优路径移动能获得的最大净得分。Alice 与 Bob 的移动**互相独立**（各自到终点即停，不影响对方继续移动）。

**约束**：

- $2 \le n \le 10^5$
- $edges.length = n - 1$，表示一棵有效树
- $1 \le bob < n$
- $-10^4 \le amount[i] \le 10^4$，且为偶数

## 2. 示例

**示例 1**

```text
输入：edges = [[0,1],[1,2],[1,3],[3,4]], bob = 3, amount = [-2,4,2,-4,6]
输出：6
解释：Alice 走 0→1→3→4：节点 0 得 −2；节点 1 两人同时到达平分 4（各得 2）；
节点 3 的门已被 Bob 打开得 0；节点 4 得 6，总计 6。
```

**示例 2**

```text
输入：edges = [[0,1]], bob = 1, amount = [-7280,2350]
输出：-7280
解释：Alice 朝叶子 1 走，Bob 同时朝 0 走。节点 0 只有 Alice 在 t=0 到过（Bob t=1 才到），
Alice 得 −7280；节点 1 只有 Bob 到过，Alice 得 0。
```

**示例 3（边界补充）**

```text
输入：edges = [[0,1],[1,2]], bob = 2, amount = [2,-4,6]
输出：0
解释：链 0—1—2，Bob 走 2→1→0（bobTime = [2, 1, 0]）。唯一的叶子是 2，
Alice 只能走 0→1→2：节点 0 她先到（t=0 < 2）全得 +2；
节点 1 两人同时到达（t=1 = 1）平分 −4，各得 −2；
节点 2 的门 Bob 在 t=0 已打开，Alice 得 0。总计 2 − 2 + 0 = 0。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有「根到叶子」的路径，对每条路径逐节点模拟双方到达时刻并算分，取最大值——路径条数最坏 $O(n)$ 条、每条 $O(n)$ 长，总 $O(n^2)$，在 $n = 10^5$ 的链上不可行。另一个朴素想法是分别对每个节点记录「Alice 最早到达时间」「Bob 最早到达时间」再合成得分，方向正确，剩下的问题只是如何 $O(n)$ 地拿到这两个时间：**Alice 到每个节点的时刻就是该点的深度**（她从根匀速往下走）；**Bob 只在一条固定的路径上出现**（从 `bob` 到 0 的唯一路径），路径上第 $t$ 个点的到达时刻为 $t$。

### 3.2 核心观察：两人的到达时刻都能 $O(n)$ 预处理

![核心观察：时间对齐判定](images/bw91_q3_tree_time_alignment.svg)

> 💡 **三个一次性观察**：

1. **Alice 的选择不影响 Bob**：Bob 的路径 `bob → 0` 由树唯一确定（树上两点路径唯一），与 Alice 走哪条无关。
2. **Alice 到达节点 $u$ 的时刻 = $depth(u)$**：她从根出发每秒走一步、且总朝叶子方向（远离根）走，到 $u$ 恰好走 $depth(u)$ 步。她「朝某个叶子移动」的约束等价于「一直往下走」，因此她能到达的节点恰是所有节点，路径恰是某条根到叶路径的前缀。
3. **Bob 的到达时刻只在他那条路径上有定义**：设 $P = (p_0 = bob, p_1, \dots, p_L = 0)$，则 $bobTime(p_t) = t$；不在 $P$ 上的节点 Bob 永远不到，视为 $+\infty$。用 $depth$ 表示即 $bobTime(v) = depth(bob) - depth(v)$（$v \in P$）。

于是节点 $u$ 对 Alice 的贡献只由两个时间比较决定（$amount$ 均为偶数，$c/2$ 无舍入问题）：

$$gain(u) = \begin{cases} amount[u], & depth(u) < bobTime(u) \text{（先到或 Bob 不经过）} \\ amount[u]/2, & depth(u) = bobTime(u) \text{（同时到达）} \\ 0, & depth(u) > bobTime(u) \text{（门已被打开）} \end{cases}$$

### 3.3 算法流程：建树 → 标记 Bob 时刻 → 按序累加

![算法流程：两遍扫描](images/bw91_q3_algorithm_flow.svg)

```text
1. 建邻接表；从根 0 出发 BFS 求 parent[]、depth[] 与 BFS 序 order[]
2. bobTime[] 初始化为 +∞；v 从 bob 沿 parent 走到 0，
   逐点标 bobTime[v] = depth[bob] − depth[v]
3. score[0] = amount[0]（Alice 在 t=0 独占根：bob ≥ 1 保证 Bob 不可能在 t=0 到根）
   按 BFS 序（父先于子）累加：score[u] = score[parent[u]] + gain(u)
4. ans = max(score[u])，u 取遍所有叶子（非根且度数为 1 的节点）
```

全程迭代（BFS 代替 DFS 递归），$n = 10^5$ 的链也不会爆栈。

### 3.4 示例演算

![示例演算：bob=3 的完整走查](images/bw91_q3_walkthrough.svg)

示例 1（$bob=3$，Bob 走 $3 \to 1 \to 0$）：节点 0：$0 < 2$ 全得 $-2$；节点 1：$1 = 1$ 平分得 $+2$；节点 2：$2 < \infty$ 全得 $+2$；节点 3：$2 > 0$ 得 $0$；节点 4：$3 < \infty$ 全得 $+6$。叶子 2 得 $-2+2+2=2$，叶子 4 得 $-2+2+0+6=6$，答案 $6$。示例 2（链 $0-1$，$bob=1$）：Bob 走 $1 \to 0$，节点 0 Alice 在 $t=0$、Bob 在 $t=1$，全得 $-7280$；节点 1 门已被 Bob 在 $t=0$ 打开，Alice 得 $0$；答案 $-7280$。

## 4. 算法细节

1. **根的得分不需要特判成「平分」**：$bob \ge 1$ 意味着 $bobTime(0) = depth(bob) \ge 1 > 0$，Alice 在 $t=0$ 必然独占节点 0，直接取 $amount[0]$。但若照抄三分支模板，把 $bobTime(0) = depth(bob]$ 代入比较也自然得出「先到」结论——推荐显式写 `gain(0) = amount[0]` 免去歧义。
2. **BFS 序累加代替 DFS 回溯**：`order` 数组是入队顺序，天然满足「父节点先于子节点出现」，`score[u] = score[parent[u]] + gain(u)` 一次线性扫描完成，无需递归栈。
3. **叶子的定义**：非根且度数为 $1$。根节点度数为 $1$ 时（链的起点）**不是** Alice 的合法终点——她必须移动到「真正的叶子」；当 $n = 2$ 时根的邻居就是叶子，正常成立。
4. **`bobTime` 用 `INT_MAX / 2` 表示无穷**：避免与有限时刻比较时的溢出（`depth` 最大 $10^5$，`INT_MAX/2` 安全）。
5. **得分用 `long long` 累加**：最坏路径长 $10^5$、每点 $\pm 10^4$，极端和 $\pm 10^9$ 贴近 `int` 边界，C++ 用 `long long` 稳妥；本题实际保证 $|score| \le 10^9$ 内可 `int` 通过，但防御性写法无成本。
6. **Python 的 BFS**：用 `collections.deque`；或直接把 `order` 当栈弹出做 DFS 序也行——只要保证父先于子。

## 5. 正确性证明

**引理 1（Bob 路径唯一且确定）**：树上 $bob$ 到 $0$ 的简单路径唯一，Bob 每秒走一步、不回头（回头即离开通往 0 的方向，必然无法在时刻 $L$ 到达），故 $bobTime(v) = depth(bob) - depth(v)$ 对路径上所有 $v$ 成立，路径外节点 Bob 永不经过。

**证明**：树无环，两点间简单路径唯一。Bob 要在 $L = depth(bob)$ 步内走完长度 $L$ 的路径，每步都必须沿该路径向 0 逼近，任何偏离（走到路径外的分支或回头）都会使到达时刻超过 $L$，与「每一秒移动到相邻节点、到达 0 停止」的最短走法矛盾；而偏离后再回来更晚，只会让门更早被打开路径上的判定更不利于 Bob 自身，且 Bob 的行为只有「沿唯一路径匀速前进」这一种与题意相容。∎

**引理 2（Alice 的到达时刻）**：Alice 朝叶子移动等价于沿从根出发逐层向下的路径移动；她到达节点 $u$（在其所选路径上）的时刻恰为 $depth(u)$。

**证明**：Alice 每秒移动一步且移动方向「朝着某个叶子」，即所选路径为根到某叶子的简单路径（树上从根到叶路径唯一确定）。她从 $t=0$ 在根（$depth = 0$）出发，每步深度恰增 1（沿路径向下），归纳得 $t$ 时刻位于路径上 $depth = t$ 的节点。∎

**定理**：设 $gain(u)$ 按 §3.2 三分支定义，则 Alice 选择叶子 $z$ 时的净得分 $= \sum_{u \in path(0, z)} gain(u)$，且最优答案 $= \max_{z \text{ 为叶子}} \sum_{u \in path(0,z)} gain(u)$。

**证明**：先证得分分解。固定 Alice 的路径 $path(0, z)$ 与 Bob 的行程（由引理 1 与 Alice 选择无关）。对路径上节点 $u$：Alice 到达时刻 $depth(u)$（引理 2），Bob 到达时刻 $bobTime(u)$（路径外为 $\infty$）。门的规则按时间先後分三类：$depth(u) < bobTime(u)$ 时 Alice 先到或 Bob 不经过，她开门得 $amount[u]$（若此后 Bob 经过也不影响已结算的分数，规则只说「已打开则无额外加减」）；相等时同时到达平分 $amount[u]/2$；大于时门已被打开，得 $0$。各节点的结算互不干扰，总得分即逐点求和。再证最优性：Alice 的可选策略集合 = 所有根到叶路径（引理 2 说明不存在其他形态的策略），对每条路径求和取最大即最优。最后，$score[u]$ 沿 BFS 序的递推 $score[u] = score[parent[u]] + gain(u)$ 恰是根到 $u$ 路径上的 $gain$ 前缀和（树上根到 $u$ 的路径唯一），叶子处取最大值即上述枚举。∎

## 6. 复杂度分析

- **时间**：$O(n)$——建邻接表 $O(n)$，BFS $O(n)$，Bob 路径标记 $O(depth(bob)) \le O(n)$，按序累加与叶子统计 $O(n)$。
- **空间**：$O(n)$——邻接表、`parent/depth/order/bobTime/score` 各一个长度 $n$ 的数组。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int mostProfitablePath(vector<vector<int>>& edges, int bob, vector<int>& amount) {
        int n = (int)amount.size();
        vector<vector<int>> g(n);
        for (const auto& e : edges) {
            g[e[0]].push_back(e[1]);
            g[e[1]].push_back(e[0]);
        }
        // 1. 从根 0 出发 BFS，得到 parent / depth / BFS 序（迭代防爆栈）
        vector<int> parent(n, -1), depth(n, 0), order;
        order.reserve(n);
        parent[0] = 0;
        order.push_back(0);
        for (size_t h = 0; h < order.size(); ++h) {
            int u = order[h];
            for (int v : g[u]) {
                if (parent[v] == -1) {
                    parent[v] = u;
                    depth[v] = depth[u] + 1;
                    order.push_back(v);
                }
            }
        }
        // 2. Bob 从 bob 走到 0 的路径上各点到达时刻（其余点视为 +∞）
        const int INF = INT_MAX / 2;
        vector<int> bobTime(n, INF);
        for (int v = bob; v != 0; v = parent[v]) {
            bobTime[v] = depth[bob] - depth[v];
        }
        bobTime[0] = depth[bob];
        // 3. Alice 的到达时刻 = depth，沿 BFS 序累加得分
        vector<long long> score(n, 0);
        long long ans = LLONG_MIN;
        for (int u : order) {
            long long gain;
            if (u == 0) {
                gain = amount[0];                       // Alice 在时刻 0 已在根，必得全分
            } else if (depth[u] < bobTime[u]) {
                gain = amount[u];                       // Alice 先到 / Bob 不经过：全分
            } else if (depth[u] == bobTime[u]) {
                gain = amount[u] / 2;                   // 同时到达：平分
            } else {
                gain = 0;                               // Bob 已开门：零分
            }
            score[u] = (u == 0) ? gain : score[parent[u]] + gain;
            if (u != 0 && (int)g[u].size() == 1) {      // 叶子（非根、度数 1）
                ans = max(ans, score[u]);
            }
        }
        return (int)ans;
    }
};
```

### Python

```python
class Solution:
    def mostProfitablePath(self, edges: list[list[int]], bob: int, amount: list[int]) -> int:
        n = len(amount)
        g = [[] for _ in range(n)]
        for a, b in edges:
            g[a].append(b)
            g[b].append(a)
        # 1. 从根 0 出发 BFS：parent / depth / BFS 序
        parent = [-1] * n
        parent[0] = 0
        depth = [0] * n
        order = [0]
        head = 0
        while head < len(order):                    # 用列表当队列（指针代替 pop(0)）
            u = order[head]
            head += 1
            for v in g[u]:
                if parent[v] == -1:
                    parent[v] = u
                    depth[v] = depth[u] + 1
                    order.append(v)
        # 2. Bob 路径上各点的到达时刻，其余为无穷
        INF = float('inf')
        bob_time = [INF] * n
        v = bob
        while v != 0:
            bob_time[v] = depth[bob] - depth[v]
            v = parent[v]
        bob_time[0] = depth[bob]
        # 3. Alice 到达时刻 = depth，沿 BFS 序累加得分
        score = [0] * n
        ans = float('-inf')
        for u in order:
            if u == 0:
                gain = amount[0]                    # Alice 在时刻 0 已在根，必得全分
                score[u] = gain
            else:
                if depth[u] < bob_time[u]:
                    gain = amount[u]                # Alice 先到 / Bob 不经过：全分
                elif depth[u] == bob_time[u]:
                    gain = amount[u] // 2           # 同时到达：平分
                else:
                    gain = 0                        # Bob 已开门：零分
                score[u] = score[parent[u]] + gain
            if u != 0 and len(g[u]) == 1:           # 叶子（非根、度数 1）
                ans = max(ans, score[u])
        return ans
```

> 💡 两份代码均通过官方示例（`6`、`-7280`），并与「枚举全部根到叶路径 + 逐时刻事件模拟」的独立暴力对拍 7000 组随机树（链 / 星 / 随机形态混合，$n \le 10$），结果完全一致；$n = 10^5$ 的链与随机树上 C++ 约 0.29s（含 I/O），Python 约 0.17s。

## 8. 边界情况与易错点

1. **链状树爆栈**：$n = 10^5$ 的链上递归 DFS 深度即 $10^5$，Python 直接 `RecursionError`、C++ 可能栈溢出；用 BFS/迭代写法。
2. **根不是叶子**：链 $0-1-\dots$ 中根度数为 1，但 Alice 必须走到「真叶子」；判定叶子要加 `u != 0` 条件，否则会把根当候选终点（$n=2$ 时根的邻居才是叶子，逻辑不受影响）。
3. **`bob == 0` 不会出现**（约束 $1 \le bob$），但防御性代码里 `bobTime[0] = depth[bob]` 仍按公式写，勿写成 `bobTime[0] = 0`。
4. **平分的整数性**：`amount` 全为偶数，`c/2` 无舍入；若题目改成任意整数需要小心 C++ 负数除法（`-3/2 = -1`）与题意（`-1.5`）不一致。
5. **「门已打开」是单向的**：Bob 先开过的门 Alice 得 0，但 Alice 先开过的门 Bob 得 0——本题只问 Alice 分数，不必管 Bob 的得分，但别把「共享」错写成「两人都拿 $c/2$」：**同时到达才平分**，一先一后是后者得 0。
6. **两人停止互不影响**：Bob 到 0 后停下，不代表游戏结束；Alice 继续走完她的路径，路径上门的开关状态按时间线结算。
7. **负分也必须收下**：Alice 无法「跳过」路上的门，$gain$ 允许为负；极端全负的 `amount` 下答案是「最不亏的叶子」。
8. **`long long` 防御**：极端链上分数和可达 $\pm 10^9$ 量级，C++ 建议用 `long long` 累加。
