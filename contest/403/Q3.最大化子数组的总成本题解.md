# LeetCode 最大化子数组的总成本 题解

## 1. 题目概述

- **标题 / 题号**：最大化子数组的总成本（#3196，medium）
- **链接**：https://leetcode.cn/problems/maximize-total-cost-of-alternating-subarrays/
- **来源**：LeetCode 第 403 场周赛 Q3
- **难度**：中等
- **标签**：数组、动态规划、状态机 DP

**题意**：给定长度为 $n$ 的整数数组 `nums`，子数组 `nums[l..r]` 的**成本**定义为

$$\text{cost}(l, r) = \text{nums}[l] - \text{nums}[l+1] + \text{nums}[l+2] - \cdots + \text{nums}[r] \cdot (-1)^{r-l}$$

即段内符号按 $+\ -\ +\ -\ \cdots$ 交替、**段首恒为 $+$**。把 `nums` 分割成若干子数组（每个元素**恰好**属于一段），使所有子数组的成本之和**最大**；若不分割（$k = 1$），总成本即 $\text{cost}(0, n-1)$。返回最大总成本。

**约束**：

- $1 \le n \le 10^5$
- $-10^9 \le \text{nums}[i] \le 10^9$——总成本规模可达 $10^{14}$，C++ 必须全程 64 位整数

> 💡 **审题三个关键**：① 段内符号只由**段内偏移**决定——段首永远乘 $+$，之后 $-\ +\ -\ \cdots$ 交替；② 「开新段」的全部效果，仅仅是把符号**重置**为 $+$；③ 成本是逐元素求和——每个元素贡献 $\pm\,\text{nums}[i]$，于是「在哪里切」可以整体翻译成「给谁配负号」。本场 Q1/Q2 是纯结构观察题，Q3 开始上 DP，是典型的**分场胜负题**：想到符号转化，五分钟写完；想不到，就在 $O(n^2)$ 枚举里打转。

## 2. 示例

**示例 1**

```text
输入：nums = [1,-2,3,4]
输出：10
解释：分割成 [1,-2,3] 和 [4]，总成本 (1+2+3) + 4 = 10。
```

**示例 2**

```text
输入：nums = [1,-1,1,-1]
输出：4
解释：分割成 [1,-1] 和 [1,-1]，总成本 (1+1) + (1+1) = 4。
```

**示例 3**

```text
输入：nums = [0]
输出：0
解释：无法分割，答案为 0。
```

**示例 4**

```text
输入：nums = [1,-1]
输出：2
解释：整段选取，成本 1 - (-1) = 2。
```

**补充：贪心反例**

```text
输入：nums = [1,-2,-3]
输出：2
解释：只翻 -3：1 - 2 + 3 = 2；只翻 -2：1 + 2 - 3 = 0；两个都翻则相邻非法。
```

## 3. 解题思路

### 3.1 暴力思路：枚举分割方案

$n-1$ 条缝隙，每条「切 / 不切」，共 $2^{n-1}$ 种分割方案——$n \le 10^5$ 时是天文数字。

改良成**分段 DP**：设 $dp[i]$ 为前 $i$ 个元素（`nums[0..i-1]`）的最大总成本，枚举**最后一段**的起点 $j$：

$$dp[i] = \max_{0 \le j < i}\ \big(dp[j] + \text{cost}(j,\ i-1)\big)$$

配合交替前缀和 $A[i] = \sum_{k \le i} (-1)^k\,\text{nums}[k]$ 可把单次 $\text{cost}(j, i-1) = (-1)^j\,(A[i-1] - A[j-1])$ 压到 $O(1)$，但枚举 $j$ 本身就是 $O(n^2) \approx 10^{10}$，依然超时。

> ⚠️ **病根不在优化技巧，而在状态信息**：$dp[i]$ 只记了「切到哪」，没记**最后一段的符号相位**（当前轮到 $+$ 还是 $-$）。相位缺失，$\text{cost}(j, \cdot)$ 依赖段首 $j$ 的奇偶，只好回退枚举段首。把「当前元素是 $+$ 号还是 $-$ 号」补进状态，转移立刻变 $O(1)$——这正是 3.2 → 3.3 的路线。

### 3.2 核心观察：分割 ⇄ 给每个元素定符号

![核心观察：切分即符号重置](images/alt_cost_split_sign_concept.svg)

盯着成本公式看：段内第 $k$ 个元素（从 0 数）乘 $(-1)^k$——符号在段内 $+\ -\ +\ -$ 交替，段首恒为 $+$。而「开新段」的全部效果，仅仅是让符号从 $+$ 重新开始。

于是「怎么分段」可以翻译成「**给每个元素定符号**」$s_i \in \{+1, -1\}$，合法条件只有两条：

1. **首元素必为 $+$**（每段的段首都是 $+$，$s_0$ 是首段段首）；
2. **相邻两个 $-$ 非法**（$-$ 只出现在段内奇偏移，前一格必是同段的 $+$）。

直观验证两个方向：

- **分割 → 符号**：任何合法分割逐段誊写符号，段首 $+$、段内交替，自然满足两条规则；
- **符号 → 分割**：满足两条规则的符号序列，相邻组合只剩 $++$、$+-$、$-+$ 三种。$++$ 相邻处**必须**切一刀（同段内相邻符号必须交替，$++$ 无法同段），$+-$、$-+$ 处可切可不切。在所有 $++$ 处切开后，每段符号恰是 $+\ -\ +\ -\ \cdots$——还原出一个合法分割。

因此**分割的最优值 = 合法符号序列的最优值**：分割到符号虽是多对一（可选切点处切不切都行），但每个合法符号序列都至少被一个分割实现，两个值域重合（严格证明见第 5 节引理 1）。目标变成：

$$\max\ \sum_i s_i \cdot \text{nums}[i]$$

> 💡 一句话：**「在哪里分段」等价于「给谁翻负号」**。设翻负号的集合为 $F$（$0 \notin F$、$F$ 内无相邻元素），目标即 $\sum_i \text{nums}[i] - 2\sum_{i \in F} \text{nums}[i]$——在路径图上选一个「无相邻、不含 0 号」的集合，最小化其元素和。**这正是打家劫舍的结构**（[198. 打家劫舍](https://leetcode.cn/problems/house-robber/) 的「选了不能相邻」），详见第 4 节的换元视角。

**贪心为什么不行**：取 `nums = [1,-2,-3]`。翻 $-2$ 得 $1+2-3 = 0$；翻 $-3$ 得 $1-2+3 = 2$；两个都翻则相邻非法。「从左到右见到负数就翻」会先翻 $-2$，错过最优 $2$。翻 $i$ 会**封锁** $i \pm 1$ 的翻转资格——局部决策与全局约束耦合，必须 DP。

### 3.3 状态机 DP：keep / flip

![状态机转移：keep 与 flip](images/alt_cost_keep_flip_states.svg)

沿 3.2 的语义直接设状态：

- $\text{keep}_i$：第 $i$ 个元素**保持 $+$ 号**时，前缀 `nums[0..i]` 的最大总成本；
- $\text{flip}_i$：第 $i$ 个元素**翻成 $-$ 号**时的最大总成本。

转移方程（对应两条规则的逐格检查）：

$$\text{keep}_i = \max(\text{keep}_{i-1},\ \text{flip}_{i-1}) + \text{nums}[i]$$

$$\text{flip}_i = \text{keep}_{i-1} - \text{nums}[i]$$

- **keep 的两种身份**：$i$ 是**新段的段首**（前一格属于上一段，符号任意）；或 $i$ 是**段内偶偏移**（前一格是奇偏移、即 $-$ 号）。两种身份下前一格取 $+$ 取 $-$ 都可能，故对 $\text{keep}_{i-1}, \text{flip}_{i-1}$ 取 $\max$；
- **flip 的唯一身份**：$i$ 是段内奇偏移 $\ge 1$，**前一格必为同段偶偏移（$+$ 号）**——前驱只能是 keep。$\text{flip} \to \text{flip}$ 即相邻两个负号，非法。

边界与答案：

$$\text{keep}_0 = \text{nums}[0],\qquad \text{flip}_0 = -\infty,\qquad \text{ans} = \max(\text{keep}_{n-1},\ \text{flip}_{n-1})$$

> 💡 **实现细节**：$\text{flip}_0$ 的 $-\infty$ 可以偷懒写成 $\text{nums}[0]$——它**只**通过 $\max(\text{keep}, \text{flip})$ 影响后续，而初始 $\text{keep}_0 = \text{nums}[0]$ 永远支配它；$\text{flip}$ 的转移又只读 keep。**被支配的非法状态可以用任意足够小的值初始化**，比死磕 $-\infty$ 的溢出边界更稳。

### 3.4 示例演算

![示例演算：回溯出最优分割](images/alt_cost_walkthrough.svg)

以示例 1 演算（`nums = [1,-2,3,4]`）：

| $i$ | nums[i] | keep | flip | 最优符号前缀 |
|-----|---------|------|------|--------------|
| 0 | 1 | $1$ | $-\infty$ | $+$ |
| 1 | −2 | $\max(1,-\infty)-2 = -1$ | $1-(-2) = 3$ | $+\ -$ |
| 2 | 3 | $\max(-1,3)+3 = 6$ | $-1-3 = -4$ | $+\ -\ +$ |
| 3 | 4 | $\max(6,-4)+4 = 10$ | $6-4 = 2$ | $+\ -\ +\ \vert\ +$ |

答案 $\max(10, 2) = 10$，回溯：$\text{keep}_3 = 10$ 来自 $\text{keep}_2 = 6$——$+\ +$ 界面，切开新段；$\text{keep}_2 = 6$ 来自 $\text{flip}_1 = 3$——「翻 $-2$」的收益经 $\max$ 汇入续段决策；即符号 $+\ -\ +\ \vert\ +$，分割 $[1,-2,3],\ [4]$，成本 $(1+2+3) + 4 = 10$ ✓。

再演算贪心反例 `nums = [1,-2,-3]`：状态 $(1) \to (-1,\ 3) \to (0,\ 2)$，答案 $2$ 来自 $\text{flip}_2 = \text{keep}_1 - (-3) = -1+3 = 2$——DP 在相邻负数对「二选一」时自动弃 $-2$ 选 $-3$（翻转收益 $2 \times 3 > 2 \times 2$），而逐格贪心翻掉 $-2$ 后只能得 $0$。

最后验证示例 2（`nums = [1,-1,1,-1]`）：$(1) \to (0,\ 2) \to (3,\ -1) \to (2,\ 4)$，答案 $4$，对应符号 $+\ -\ +\ -$（整段）。注意官方解释的 $[1,-1],\ [1,-1]$ 与整段**是同一符号序列的两种切法**——$-+$ 界面切否皆可，这正是 3.2「多对一」的实例。

## 4. 算法细节

1. **相位是唯一自由度**：$\text{cost}(l, r) = \sum_{k=0}^{r-l} (-1)^k\,\text{nums}[l+k]$ 只依赖**段内偏移**的奇偶。两个切点之间的一段，其内部符号完全由段首决定——所以整个问题的决策变量就是「哪些界面切开」，等价于「符号序列」。把决策对象从「切点集合」（全局结构）换成「逐格符号」（局部选择）后，约束变成两条**局部**规则，DP 状态随之局部化，这是 $O(n^2) \to O(n)$ 的全部来源。
2. **转移的语义检查清单**：写方程前自查三问——$s_i = +$ 时 $s_{i-1}$ 有几种可能？（两种，取 max）；$s_i = -$ 时呢？（被规则②锁死为 $+$，只读 keep）；$s_0$ 能否为 $-$？（规则①禁止，flip 初值 $-\infty$）。三问答对，方程不会写错。
3. **flip 初值的支配替代**：$-\infty$ 只经 $\max$ 参与后续且被 $\text{keep}_0 = \text{nums}[0]$ 支配，故可用 $\text{nums}[0]$ 代替。若坚持写 $-\infty$，C++ 里用 `LLONG_MIN` 再参与加法会下溢（未定义行为），应改用 `LLONG_MIN / 4` 这类安全负大数——但被支配写法根本不碰这条边界。
4. **滚动变量与覆盖顺序**：转移只依赖上一格的 $(\text{keep}, \text{flip})$，两个变量足够。C++ 必须**先算出两个新值再统一覆盖**（$\text{nFlip}$ 要用旧 keep）；Python 的元组赋值 `keep, flip = ..., ...` 天然完成这件事。
5. **换元视角：打家劫舍的镜像**：由 $s_i = 1 - 2\,[i \in F]$，

   $$\text{ans} = \sum_i \text{nums}[i] - 2 \cdot \min_{F}\ \sum_{i \in F} \text{nums}[i]\qquad (F \subseteq \{1,\dots,n-1\},\ F \text{ 内无相邻})$$

   由于把 $i$ 放进 $F$ 当 $\text{nums}[i] \ge 0$ 时不会更优（去掉它仍合法、和不变或变小），最优 $F$ 可只含负数——「选互不相邻的负数，让 $2\sum|\text{nums}[i]|$ 的收益最大」即路径图上的**最小权独立集**（等价于打家劫舍的最大权独立集，权取 $-\text{nums}[i]$）。设 $\text{rob}_i / \text{notRob}_i$ 为「$i$ 翻 / 不翻」时 $\sum_F$ 的最小值，转移 $\text{rob}_i = \text{notRob}_{i-1} + \text{nums}[i]$、$\text{notRob}_i = \min(\text{rob}_{i-1}, \text{notRob}_{i-1})$，与 keep/flip 代数等价（对照第 7 节的变体实现）。

6. **回溯分割方案（可选）**：若要输出分割而非只求值，最省事的做法是先算出最优符号序列（滚动时顺手存每格 $s_i$，$O(n)$ 额外空间），再按引理 1 的构造在所有 $++$ 界面切一刀；注意方案不唯一（$-+$ 界面切否皆可）。

## 5. 正确性证明

**引理 1（符号刻画）**：符号序列 $s \in \{+1,-1\}^n$ 可由某个合法分割诱导，当且仅当 $s_0 = +1$ 且 $s$ 中不存在相邻两个 $-1$。

**证明**：

（$\Rightarrow$）设分割的某段为 $\text{nums}[l..r]$，其内偏移 $k$ 的符号为 $(-1)^k$：偏移 $0$（段首）为 $+$；若某格符号为 $-$，则其偏移 $k \ge 1$，前一格偏移 $k-1$ 与之同段且符号为 $+$。逐段誊写即得：序列中每格为 $-$ 时其前一格（若存在）必为 $+$，且 $s_0$ 作为首段段首为 $+$。故无 $--$ 相邻，$s_0 = +$。

（$\Leftarrow$）构造分割：在所有满足 $s_{i-1} = +,\ s_i = +$ 的界面 $i$ 处（$++$ 界面）切一刀，其余界面不切。每个切出来的段内部不含 $++$（全被切断），又由假设不含 $--$，故段内符号严格交替；段首要么是位置 $0$（$s_0 = +$），要么是某个 $++$ 界面的右侧（$s_i = +$）。一个从 $+$ 开始严格交替的序列恰为 $(-1)^{\text{偏移}}$，故该分割诱导出 $s$。∎

**引理 2（求和等式）**：若分割 $P$ 诱导符号序列 $s$，则 $P$ 的总成本 $= \sum_i s_i \cdot \text{nums}[i]$。

**证明**：总成本 $= \sum_{\text{段 } [l,r]} \sum_{k=0}^{r-l} (-1)^k\,\text{nums}[l+k]$；段内偏移 $k$ 的格子恰以 $s$ 中对应位置的符号贡献一次，各段拼起来覆盖每个格子恰好一次，逐段求和即逐格求和。∎

> ⚠️ **多对一为何不损最优值**：分割到符号的映射不是单射（$-+$ 界面切否皆可实现同一 $s$），但引理 1 的两个方向合起来说明：**可行值域相等**——每个分割给出一个合法 $s$（成本相同），每个合法 $s$ 至少被一个分割实现。因此两个优化问题的目标值集合相同，最优值相等。

**定理（DP 正确性）**：对每个 $i$，处理完 $i$ 后有 $\text{keep}_i = K_i$、$\text{flip}_i = F_i$，其中

$$K_i = \max\Big\{\textstyle\sum_{j \le i} s_j\,\text{nums}[j] :\ s_{0..i}\ \text{合法}，\ s_i = +\Big\},\qquad F_i = \max\{\cdots :\ s_i = -\}$$

（大括号为空时取 $-\infty$）。算法返回值等于最优分割的总成本。

**证明**：对 $i$ 归纳。

**基础** $i = 0$：$s_0 = -$ 违反规则①，故 $F_0 = -\infty$；唯一合法取值 $s_0 = +$ 给出 $K_0 = \text{nums}[0]$。与初始化一致（被支配写法见第 4 节第 3 点）。

**归纳步**：设 $i-1$ 时结论成立。注意两条规则都是**前缀局部**约束：$s_{0..i}$ 合法 $\iff$ $s_{0..i-1}$ 合法且新界面 $(s_{i-1}, s_i) \ne (--)$。

- 若 $s_i = +$：$s_{i-1}$ 取 $+$ 或 $-$ 均不违反规则（规则②只禁 $--$），两种前缀的约束互不影响，故 $K_i = \text{nums}[i] + \max(K_{i-1}, F_{i-1})$；
- 若 $s_i = -$：规则②强制 $s_{i-1} = +$，故 $F_i = -\text{nums}[i] + K_{i-1}$。

这正是两条转移方程。归纳完成。最后，任何全长合法序列的末位非 $+$ 即 $-$，故最大值 $= \max(K_{n-1}, F_{n-1}) = \max(\text{keep}_{n-1}, \text{flip}_{n-1})$，即算法返回值；由引理 1、2 及值域相等注记，它等于最优分割的总成本。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。单趟扫描，每步两次加减、一次比较、一次 $\max$，均为 $O(1)$。输入本身就有 $n$ 个数、读入即 $\Omega(n)$，一趟 DP 与读入同阶，渐近最优。
- **空间复杂度**：$O(1)$。仅两个滚动变量；若需回溯分割方案，额外 $O(n)$ 存每格符号。
- **数值规模**：$|\text{ans}| \le \sum_i \lvert \text{nums}[i] \rvert \le 10^5 \times 10^9 = 10^{14}$，中间量 keep/flip 同阶，均超出 32 位范围（$\approx 2.1 \times 10^9$），C++ 全程 `long long`。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    long long maximumTotalCost(vector<int>& nums) {
        long long keep = nums[0], flip = nums[0];          // flip 初值被 keep 支配，取 nums[0] 即可
        for (int i = 1; i < (int)nums.size(); ++i) {
            long long nKeep = max(keep, flip) + nums[i];   // 新段段首 / 段内偶偏移
            long long nFlip = keep - nums[i];              // 段内奇偏移：前一格必须是 + 号
            keep = nKeep;
            flip = nFlip;
        }
        return max(keep, flip);
    }
};
```

### C++（换元视角：打家劫舍镜像版）

```cpp
class Solution {
  public:
    long long maximumTotalCost(vector<int>& nums) {
        long long sum = nums[0];
        long long notRob = 0, rob = LLONG_MAX / 4;         // rob: i ∈ F；notRob: i ∉ F
        for (int i = 1; i < (int)nums.size(); ++i) {
            sum += nums[i];
            long long nRob = notRob + nums[i];             // i ∈ F ⇒ i−1 ∉ F
            long long nNot = min(notRob, rob);
            rob = nRob;
            notRob = nNot;
        }
        return sum - 2 * min(rob, notRob);                 // Σnums − 2·min Σ_F
    }
};
```

### Python

```python
class Solution:
    def maximumTotalCost(self, nums: List[int]) -> int:
        keep = flip = nums[0]              # flip 初值被 keep 支配，取 nums[0] 即可
        for x in nums[1:]:
            keep, flip = max(keep, flip) + x, keep - x
        return max(keep, flip)
```

> 💡 两处工程要点：**① 溢出**——答案规模 $10^{14}$，C++ 全程 `long long`；**② 覆盖顺序**——C++ 先算好两个新值再统一覆盖（`nFlip` 要用旧 keep），Python 的元组赋值天然完成这件事。

## 8. 边界情况与易错点

1. **$n = 1$**：答案就是 $\text{nums}[0]$（首元素不可翻，$\text{flip}_0$ 恒不参与答案）。
2. **溢出（最高频 WA）**：$10^{14}$ 远超 `int`；返回签名已是 `long long`，别在局部变量 `keep`/`flip` 上用 `int` 翻车。
3. **`LLONG_MIN` 参与加法**：若把 $-\infty$ 写成 `LLONG_MIN`，`flip` 转移中再减 $\text{nums}[i]$ 会下溢（UB）。用被支配值 $\text{nums}[0]$ 或 `LLONG_MAX / 4` 式安全大数。
4. **C++ 覆盖顺序**：先更新 `keep` 再用新值算 `flip` 是典型 bug——`nFlip` 必须读**旧** keep。
5. **相邻负数只能翻一个**：$[1,-2,-3]$ 答案 $2$（翻 $-3$），逐格贪心翻 $-2$ 只得 $0$；这是「必须 DP」的最小反例。
6. **答案可为负**：$[-1]$ 答案 $-1$；$[-1,-2,-3]$ 最优 $0$（分割 $[-1],\ [-2,-3]$）。别把任何一步写成「至少取 0」。
7. **答案可能来自 flip**：$[1,-1]$ 的 $2 = \text{flip}_1$，末状态必须 $\max(\text{keep}, \text{flip})$，漏掉 flip 等于强制末位为 $+$。
8. **方案不唯一**：$-+$ 界面切否皆可（示例 2 的 $4$ 整段与 $[1,-1]\mid[1,-1]$ 均可达），题目只要值——赛时别在「还原唯一分割」上耗时。

**延伸思考**：

- **环形版**：若 `nums` 首尾相接（相邻约束成环，且末段可与首段拼接），规则「$s_0$ 必为 $+$」与「末尾翻负」可能通过环上相邻性冲突——仿打家劫舍 II，按 $s_0$ 与 $s_{n-1}$ 的取值组合分类讨论拆环。
- **限制段数**：若要求**恰好 / 至多 $k$ 段**，给 DP 加一维「已用段数」，只有 keep 的「新段首」转移计段数 $+1$，$O(nk)$。
- **另一条 $O(n)$**：保留 3.1 的分段 DP，用交替前缀和把 $\text{cost}$ 拆开、再按 $j$ 的奇偶维护两个前缀最值——殊途同归但要处理 $A[-1]$ 边界，完整推导见[每日题解](../../solution/3101-3200/3196_最大化子数组的总成本.md)第 5 节。
- **动态化**：单点修改 $\text{nums}[i]$ 后即时询问最优总成本——把 keep/flip 的转移写成分段矩阵，用线段树维护「max, +」矩阵合成，正是 3165 的手法。
