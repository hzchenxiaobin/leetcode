# LeetCode 包含所有 1 的最小矩形面积 I 题解

## 1. 题目概述

- **标题 / 题号**：包含所有 1 的最小矩形面积 I（#3195，medium）
- **链接**：https://leetcode.cn/problems/find-the-minimum-area-to-cover-all-ones-i/
- **来源**：LeetCode 第 403 场周赛 Q2
- **难度**：中等
- **标签**：数组、矩阵

**题意**：给定 $m \times n$ 的二维**二进制**数组 `grid`，要找一个**边在水平方向和竖直方向上**（即轴对齐）的矩形，使 `grid` 中**所有的 1** 都落在矩形内部（含边界）。返回这个矩形可能的**最小面积**（按覆盖的格子数计）。

**约束**：

- $1 \le m = \text{grid.length},\ n = \text{grid}[i].\text{length} \le 1000$，格子总数最多 $10^6$
- `grid[i][j]` 是 0 或 1
- **保证 `grid` 中至少有一个 1**（无需处理"没有 1"的空集情形）

> 💡 **审题三个关键**：① 矩形**轴对齐**——不许旋转，四条边分别贴着某行/某列；② 只要求盖住 **1**，被顺手盖住的 0 **不额外收费**——所以答案与 1 的个数、连通性统统无关；③ 面积按**格子数**计，行、列都是**闭区间**，跨度要 **+1**。

## 2. 示例

**示例 1**

```text
输入：grid = [[0,1,0],[1,0,1]]
输出：6
解释：四个极值为 minRow=0, maxRow=1, minCol=0, maxCol=2，
     高 = 1−0+1 = 2，宽 = 2−0+1 = 3，面积 = 2 × 3 = 6。
```

**示例 2**

```text
输入：grid = [[0,0],[1,0]]
输出：1
解释：唯一的 1 在 (1,0)，包围盒就是它这一格，1 × 1 = 1。
```

**补充：对角两个 1**

```text
输入：grid = [[1,0],[0,1]]
输出：4
解释：1 分布在对角线上，包围盒是整张 2×2 的图——盖住的 0 也计入面积。
```

**补充：单行**

```text
输入：grid = [[1,1,1]]
输出：3
解释：高 = 1，宽 = 3；1 连成一片还是散着，答案相同。
```

## 3. 解题思路

### 3.1 暴力思路：枚举矩形的四条边

一个轴对齐矩形由上下左右四条边唯一确定，朴素做法是枚举行区间 $[r_1, r_2]$ 与列区间 $[c_1, c_2]$ 的所有组合，再逐一检验"是否盖住了全部 1"：

- 组合数 $O(m^2 n^2)$，单次检验 $O(mn)$，总计 $O(m^3 n^3)$，在 $m = n = 1000$ 下约 $10^{18}$，完全不可行；
- 即使用二维前缀和把单次检验压到 $O(1)$，枚举本身 $O(m^2 n^2) \approx 10^{12}$ 也远超时限。

瓶颈在于：把"所有 1"当成一个整体反复检验，却没有先**提取 1 的位置信息**。事实上，决定一个矩形能否盖住全部 1 的，只是所有 1 里"最靠边"的几个格子。

### 3.2 核心观察：答案 = 所有 1 的最小包围盒

![核心观察：包围盒由四个极值 1 决定](images/min_area_ones_bounding_box_concept.svg)

要盖住所有 1，行方向上必须盖住每一个 1 的**行号**，列方向上必须盖住每一个 1 的**列号**——两个维度互不干扰，可以分别投影到行轴、列轴上各自取极值：

- 行方向：任何可行矩形的行区间必须包含 $[\text{minRow}, \text{maxRow}]$（所有 1 的最小 / 最大行号）；
- 列方向：列区间必须包含 $[\text{minCol}, \text{maxCol}]$（所有 1 的最小 / 最大列号）。

把两个区间都收到最紧，最优矩形就是唯一的**最小包围盒**：

$$\text{ans} = (\text{maxRow} - \text{minRow} + 1) \times (\text{maxCol} - \text{minCol} + 1)$$

**整个答案只由 4 个格子决定**：最上的 1、最下的 1、最左的 1、最右的 1。其余的 1 和所有被盖住的 0 一样，全是"观众"——它们在盒内怎么分布、有多少个，都不影响答案。这正是本题作为 Q2 的定位：考察"轴对齐包围盒"这个几何构件的条件反射——同场 Q4（#3197，恰好 3 个不重叠矩形）会把这个构件反复复用。

### 3.3 算法流程：单趟扫描维护四个极值

![算法流程：单趟扫描维护四个极值](images/min_area_ones_scan_flow.svg)

```text
minRow = m, maxRow = -1, minCol = n, maxCol = -1   # 越界哨兵
for i in 0 .. m-1:
    for j in 0 .. n-1:
        if grid[i][j] == 1:
            minRow = min(minRow, i); maxRow = max(maxRow, i)
            minCol = min(minCol, j); maxCol = max(maxCol, j)
return (maxRow - minRow + 1) * (maxCol - minCol + 1)
```

四个极值都是"打擂台"变量：第一个命中的 1 会同时改写全部四个；之后的命中各自至多再压低一个 min、撑高一个 max。题目保证至少有一个 1，所以扫描结束时四个值必然有效，不需要任何空集特判。

### 3.4 示例演算

![示例演算：示例 1 的扫描过程](images/min_area_ones_example_walkthrough.svg)

以示例 1 为例，四元组 $(\text{minRow}, \text{maxRow}, \text{minCol}, \text{maxCol})$ 从越界哨兵 $(2, -1, 3, -1)$ 出发，被三个 1 依次更新为 $(0,0,1,1) \to (0,1,0,1) \to (0,1,0,2)$，最终：

$$\text{ans} = (1 - 0 + 1) \times (2 - 0 + 1) = 2 \times 3 = 6$$

注意两个"身兼数职"的细节：$(1,0)$ 一次更新同时锁定了 `maxRow` 与 `minCol`；而 $(0,1)$ 既是 `minRow` 的最终来源、也曾短暂"兼任" `minCol` / `maxCol`（随后被更左 / 更右的 1 顶掉）——极值变量只记"到目前为止"的极值，这正是单趟扫描正确性的关键（对应第 5 节引理 1 的归纳证明）。

## 4. 算法细节

1. **初始化用越界哨兵**：`minRow = m`、`minCol = n`（合法下标再小也小不过哨兵），`maxRow = maxCol = -1`（合法下标从 0 开始，−1 永远会被任何 1 顶掉）。这样第一个 1 必然把四个值全部拉进合法范围，省掉"首见特判"分支。
2. **行、列可以完全分开统计**：行极值只依赖"这一行有没有 1"，列极值同理——两个一维问题各自取极值再相乘。等价写法是先按行扫出每行最左 / 最右的 1，再在行间归并，与双重循环单趟扫描等价，本题没必要拆两步。
3. **Python 的轴投影两行版**：`rows = [i for i, r in enumerate(grid) if 1 in r]`，`cols = [j for j, c in enumerate(zip(*grid)) if 1 in c]`，答案即 `(rows[-1]-rows[0]+1) * (cols[-1]-cols[0]+1)`。`1 in r` 在行内命中即停；`zip(*grid)` 把列转成可迭代序列——两行写完整个题。
4. **乘法上界**：两个因子至多 $1000 \times 1000 = 10^6$，32 位 `int` 绰绰有余；但若哪天行列上限放开到 $10^5$，C++ 就必须换 `long long`——写乘法前先算上界是肌肉记忆。
5. **判据可替换**：`if (grid[i][j])` 足矣；若题目变形为"值 ≥ k 才算目标点"，判据换成一次比较，骨架完全不变。

## 5. 正确性证明

**引理 1（扫描正确性）**：行主序扫描结束后，四个变量分别等于全体 1 的最小行号、最大行号、最小列号、最大列号。

**证明**：对命中的 1 按扫描顺序归纳。归纳假设：每次命中后，四变量恰为**已扫描部分**全体 1 的四个极值。首个 1 命中时，四变量由越界哨兵改写为该格坐标，恰为单点集合的极值，成立。设某次命中 $(i, j)$ 前假设成立：已扫描集合新增单点 $(i, j)$ 后，新极值 = 旧极值与 $i$（或 $j$）取 min / max——正是代码所做的更新；未命中 1 的格子不触发更新，集合不变。扫描结束时"已扫描部分"即全集。∎

**引理 2（下界）**：设 $R$ 为任一盖住全部 1 的轴对齐矩形，行区间 $[r_1, r_2]$、列区间 $[c_1, c_2]$，则 $r_1 \le \text{minRow} \le \text{maxRow} \le r_2$ 且 $c_1 \le \text{minCol} \le \text{maxCol} \le c_2$，从而 $\text{area}(R) \ge (\text{maxRow}-\text{minRow}+1)(\text{maxCol}-\text{minCol}+1)$。

**证明**：取行号为 $\text{minRow}$ 的某个 1，它落在 $R$ 内部，故 $r_1 \le \text{minRow} \le r_2$；$\text{maxRow}$、$\text{minCol}$、$\text{maxCol}$ 同理。于是 $R$ 的行区间长度 $r_2 - r_1 + 1 \ge \text{maxRow} - \text{minRow} + 1$，列区间同理；两个正长度逐因子不小于包围盒的对应因子，面积之积亦然。∎

**引理 3（可达）**：包围盒 $B = [\text{minRow}, \text{maxRow}] \times [\text{minCol}, \text{maxCol}]$ 本身盖住全部 1，是可行解。

**证明**：任取一个 1，位于 $(i, j)$。由极值定义 $\text{minRow} \le i \le \text{maxRow}$ 且 $\text{minCol} \le j \le \text{maxCol}$，故 $(i, j) \in B$。∎

**定理**：最小面积恰为 $(\text{maxRow}-\text{minRow}+1) \times (\text{maxCol}-\text{minCol}+1)$。

**证明**：由引理 3，该面积可达；由引理 2，任何可行解面积不小于它。两方向夹逼，即为最小值。∎

> ⚠️ **轴对齐是不可删的前提**：引理 2 第一步"行区间盖住每个 1 的行号"依赖"矩形的边水平 / 竖直"。若允许旋转，最优矩形未必是包围盒（那是最小覆盖矩形问题，要上凸包 + 旋转卡壳）。另外注意 $(\text{minRow}, \text{minCol})$ 处**未必有 1**——四个极值可以来自四个不同的格子，这不影响证明，但提醒我们不要试图"找左上角那个 1"。

## 6. 复杂度分析

- **时间复杂度**：$O(mn)$。每个格子恰好访问一次、做一次比较，命中的格子额外至多 4 次 min/max；$m, n \le 1000$ 即至多 $10^6$ 格，毫秒级。这同时是**信息论下界**：任何未读的格子都可能藏着一个把盒子撑大的 1（对手论证），最坏情况必须读遍全图，单趟扫描已渐近最优。
- **空间复杂度**：$O(1)$。只有四个标量变量，不随输入规模增长（Python 轴投影写法额外 $O(m + n)$ 存行 / 列下标，仍可忽略）。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int minimumArea(vector<vector<int>>& grid) {
        int m = grid.size(), n = grid[0].size();
        int minRow = m, maxRow = -1, minCol = n, maxCol = -1;
        for (int i = 0; i < m; ++i) {
            for (int j = 0; j < n; ++j) {
                if (grid[i][j]) {
                    minRow = min(minRow, i);
                    maxRow = max(maxRow, i);
                    minCol = min(minCol, j);
                    maxCol = max(maxCol, j);
                }
            }
        }
        return (maxRow - minRow + 1) * (maxCol - minCol + 1);
    }
};
```

### Python

```python
class Solution:
    def minimumArea(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        min_row, max_row = m, -1
        min_col, max_col = n, -1
        for i, row in enumerate(grid):
            for j, v in enumerate(row):
                if v:
                    min_row = min(min_row, i)
                    max_row = max(max_row, i)
                    min_col = min(min_col, j)
                    max_col = max(max_col, j)
        return (max_row - min_row + 1) * (max_col - min_col + 1)
```

**Python 轴投影两行版**：

```python
class Solution:
    def minimumArea(self, grid: List[List[int]]) -> int:
        rows = [i for i, r in enumerate(grid) if 1 in r]
        cols = [j for j, c in enumerate(zip(*grid)) if 1 in c]
        return (rows[-1] - rows[0] + 1) * (cols[-1] - cols[0] + 1)
```

> 💡 `rows` / `cols` 按下标升序排列，首尾即极值。注意 `1 in r` 判断的是"这一行**有没有** 1"，不是统计个数——我们只关心"有没有"。

## 8. 边界情况与易错点

1. **忘记 +1（最高频 WA）**：写成 `(maxRow - minRow) * (maxCol - minCol)`，示例 2 的单点会算出 0。行、列都是**闭区间**，格子数 = 跨度 + 1；单点、单行、单列三个边界全都靠这个 +1 撑住。
2. **对角分布**：`[[1,0],[0,1]]` 的答案是 4 不是 2——包围盒照单全收盒内的 0。同理，1 的**个数**与**连通性**都与答案无关，不要去统计个数或找连通块。
3. **极值初始化方向**：min 类初始化成"不可能的大"（$m$ / $n$），max 类初始化成 $-1$。若方向反了（比如 `minRow` 初始化为 0），当 1 全在右下角时 `minRow` / `minCol` 会错误地留在 0。
4. **空集防御**：本题保证至少一个 1，无需特判；若这个保证被拿掉，需先检查 `maxRow == -1`（或扫描计数为 0）返回 0，否则哨兵会算出负面积。
5. **溢出意识**：$10^6$ 在 32 位 `int` 内安全；但行列上限一旦放大到 $10^5$，$10^5 \times 10^5 = 10^{10}$ 立刻超 `int`，C++ 必须上 `long long`。
6. **别把简单题做复杂**：本题不需要前缀和、BFS / DFS 或任何数据结构——四个标量打擂台就是全部。周赛 Q2 的价值在于**快速、零 bug** 地拿下，把时间留给 Q3 / Q4。
7. **读题别读一半**：「边在水平方向和竖直方向上」= 轴对齐；「所有的 1 都在矩形的内部」按 LeetCode 惯例含边界（示例 1 的 1 就贴在盒边），不必纠结"内部"是否严格排除边界。

**延伸思考**：

- **在线化**：若格子被反复翻转 0/1 且随时询问最小包围盒，可用线段树按行维护"每行最左 / 最右 1 的列号"，节点向上合并时顺手带出全局四个极值，单次修改 $O(\log m)$。
