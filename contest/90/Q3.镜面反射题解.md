# LeetCode 镜面反射 题解

## 1. 题目概述

- **标题 / 题号**：镜面反射（#858，medium）
- **链接**：https://leetcode.cn/problems/mirror-reflection/
- **来源**：LeetCode 第 90 场周赛 Q3
- **难度**：中等
- **标签**：几何、数学、数论、最大公约数、最小公倍数

**题意**：一个边长为 $p$ 的正方形房间，四面墙都是镜子。除**西南角**外，每个角落都有一个接收器：东南角编号 **0**、东北角编号 **1**、西北角编号 **2**。

一束激光从西南角射出，**首先**与东墙相遇，入射点到接收器 0 的距离为 $q$（即该点坐标为 $(p, q)$）。光线按镜面反射继续前进，题目保证它最终会打中某个接收器。求**最先**遇到的接收器编号。

**约束**：

- $1 \le q \le p \le 1000$

## 2. 示例

**示例 1**

```text
输入：p = 2, q = 1
输出：2
解释：光线先打到东墙的 (2,1)，反射后向左上方走，恰好落到西北角 (0,2)，
     即编号为 2 的接收器。
```

**示例 2**

```text
输入：p = 3, q = 1
输出：1
解释：光线在东西墙之间往返多次后打到东北角 (3,3)，即编号为 1 的接收器。
```

**示例 3**

```text
输入：p = 3, q = 2
输出：0
解释：先打到 (3,2)，再反射到 (0,1)…一路走下来最先命中的是东南角 (3,0)。
```

## 3. 解题思路

### 3.1 暴力思路

直接模拟反射也完全可行：把光线位置写成有理数，每步计算「到竖直墙的最近交点」与「到水平墙的最近交点」，取较早的那个，遇到墙就把对应方向分量取反；一旦落点坐标属于 $\{(p,0), (p,p), (0,p)\}$，就返回对应编号。

复杂度上：由下文的展开分析，光线最多穿越 $p + q \le 2p$ 面墙，$p \le 1000$ 时完全够用。但这份代码需要有理数运算、要处理「同时命中两面墙（即命中角落）」的判定、还要区分「恰好经过西南角」的退化情形，写起来长且容易出错。

更好的做法是**换个坐标系看问题**：把「光线反射」换成「光线走直线」。

### 3.2 核心观察：展开法 + 数论

![展开法：把「光线反弹」换成「光线走直线、房间镜像翻转」](images/wc90_q3_unfold_grid.svg)

**关键技巧（展开 / 镜像法）**：与其让光线在房间里反弹，不如让光线沿直线一直走，而把房间**沿墙镜像翻转**铺满整个平面。

这样，光线就是一条从原点出发、方向为 $(p, q)$ 的直线（因为它从 $(0,0)$ 出发，第一次打到东墙的点是 $(p, q)$，方向向量自然是 $(p, q)$）。直线上的点是

$$t \cdot (p,\ q), \qquad t > 0.$$

而房间的**角落**在展开平面上恰好对应所有形如 $(a p,\ b p)$ 的**格点**（$a, b$ 为非负整数）。于是：

> 光线命中角落 $\iff$ 存在正整数 $a, b$ 使 $t (p, q) = (a p, b p)$。

比较两坐标得 $a q = b p$。设 $g = \gcd(p, q)$，$p' = p/g$、$q' = q/g$，则 $p' \perp q'$，方程化为 $a q' = b p'$。由于 $\gcd(p', q') = 1$，必有 $p' \mid a$、$q' \mid b$，故**最小的正整数解**是

$$a = p', \qquad b = q'.$$

也就是说，光线第一次命中角落的位置是 $(p' p,\ q' p)$。

接下来只要判断这个格点折回房间后是哪个角。折叠规则：横向穿越了 $a$ 条网格线后，真实的 $x$ 坐标在 $0$ 与 $p$ 之间交替 ——

$$\text{真实 } x = \begin{cases} 0, & a \text{ 为偶数（西墙）}\\ p, & a \text{ 为奇数（东墙）}\end{cases}$$

纵向同理。于是：

| $p'$ | $q'$ | 落点 | 编号 |
|------|------|------|------|
| 偶数 | 奇数 | 西墙 + 北墙 = **西北角** | 2 |
| 奇数 | 偶数 | 东墙 + 南墙 = **东南角** | 0 |
| 奇数 | 奇数 | 东墙 + 北墙 = **东北角** | 1 |

$p'$ 与 $q'$ **不可能同为偶数**（否则 $\gcd \ge 2$，与约分矛盾），所以「落在西南角」这种无接收器的情形不会出现，正好对应题目「保证最终会遇到接收器」。

### 3.3 算法流程

![判定流程：先约分，再看两个数的奇偶性](images/wc90_q3_parity_flow.svg)

```text
1. g = gcd(p, q)
2. p' = p / g ,  q' = q / g
3. 若 p' 是偶数：返回 2
4. 若 q' 是偶数：返回 0
5. 否则：返回 1
```

三步判定，$O(\log p)$ 的复杂度全部花在求 gcd 上。

### 3.4 示例演算

![三个例子走一遍：编号只由「墙的奇偶」决定](images/wc90_q3_walkthrough.svg)

| $p, q$ | $g$ | 约分后 | 首个格点 $(a,b)$ | 落点 | 答案 |
|--------|-----|--------|------------------|------|------|
| $2, 1$ | 1 | $p'=2$（偶），$q'=1$ | $a=2,\ b=1$ | 西墙 + 北墙（西北） | 2 |
| $3, 1$ | 1 | $p'=3$，$q'=1$（均奇） | $a=3,\ b=1$ | 东墙 + 北墙（东北） | 1 |
| $3, 2$ | 1 | $p'=3$，$q'=2$（偶） | $a=3,\ b=2$ | 东墙 + 南墙（东南） | 0 |
| $4, 2$ | 2 | $p'=2$（偶），$q'=1$ | $a=2,\ b=1$ | 西墙 + 北墙（西北） | 2 |

最后一行说明**约分不改变落点**：$(4,2)$ 与 $(2,1)$ 是同一个方向的两种写法，得到同样的答案 2。

## 4. 算法细节

1. **方向向量的确定**：光线从 $(0,0)$ 出发、第一次与东墙（$x = p$）交于 $(p, q)$，所以方向向量就是 $(p, q)$，斜率 $q/p$。这一步不需要任何几何推导。
2. **约分是必须的**：$a q = b p$ 的最小正解要用 $\gcd$ 化简，否则会得到「$a = p, b = q$」这种非最小的解，导致多走好几圈、落点判断错。
3. **判定顺序很重要**：必须先看 $p'$ 的奇偶（决定东西墙），再看 $q'$ 的奇偶（决定南北墙）。因为 $p'$ 为偶时 $q'$ 必为奇（互质），所以第二、三条分支是互斥的。
4. **`gcd` 的实现**：C++17 用 `<numeric>` 里的 `std::gcd(p, q)`（不要用 GCC 扩展 `__gcd`，可移植性差）；Python 用 `math.gcd`。
5. **不需要任何浮点**：全部是整数除法与取模，$p \le 1000$ 时连溢出都不用考虑。
6. **不模拟也能验证**：想确认公式可以先写一个有理数模拟器（用 `Fraction` 或交叉相乘）对拍，本文的公式在 $1 \le q \le p \le 40$ 的全部 820 组输入上都与模拟一致。
7. **编号映射不要写反**：接收器 0 在**东南**（题目用「到接收器 0 的距离为 $q$」定义了它在东墙上），1 在东北，2 在西北，逆时针排列。

## 5. 正确性证明

设房间为正方形 $[0,p] \times [0,p]$，墙角在 $(0,0)$（西南，无接收器）、$(p,0)$（东南，0 号）、$(p,p)$（东北，1 号）、$(0,p)$（西北，2 号）。

**引理 1（展开引理）**：把正方形沿四面墙反复镜像，可铺满整个平面；光线在房间内的反射路径，与该平面内从原点出发的同方向**直线**一一对应。具体地，直线上的点 $(x, y)$ 折叠回房间的规则为

$$\text{fold}(x) = \begin{cases} x \bmod 2p, & (x \bmod 2p) \le p\\ 2p - (x \bmod 2p), & (x \bmod 2p) > p \end{cases}$$

纵向同理。特别地，当 $x = a p$ 时 $\text{fold}(x) = 0$（$a$ 偶）或 $p$（$a$ 奇）。

**证明**：对反射次数归纳。房间本身就是未被翻转的镜像；光线第一次撞墙后，反射等价于「光线继续直行进入相邻的镜像房间」。相邻镜像房间的坐标在撞墙方向上是房间坐标关于墙面的镜像，即 $x \mapsto 2p - x$（撞东/西墙）或 $y \mapsto 2p - y$。反复应用即得折叠公式（这是三角波 $x \mapsto$ 关于 $0, p, 2p, \dots$ 的折返），并且各段镜像是刚性变换，光线在每一段内保持直线方向，因此整体是一条直线。∎

**引理 2（方向向量）**：光线沿方向 $(p, q)$ 前进，即直线上点的参数化为 $(tp,\ tq)$。

**证明**：第一次与东墙相交的点坐标为 $(p, q)$（题面：该点到接收器 0 的距离为 $q$，而接收器 0 在 $(p,0)$ 处），故位移向量为 $(p - 0,\ q - 0) = (p, q)$。由引理 1，反射路径是直线，故参数化为 $t(p,q)$。∎

**引理 3（首次命中格点）**：直线 $t(p,q)$ 经过格点 $(ap, bp)$（$a,b$ 为非负整数）当且仅当 $a q = b p$；其中最小的正整数解为 $a = p/g,\ b = q/g$，$g = \gcd(p,q)$。

**证明**：$(tp, tq) = (ap, bp)$ 要求 $tp = ap$ 且 $tq = bp$，即 $t = a$ 且 $aq = bp$。

令 $p = g p'$、$q = g q'$，$\gcd(p',q') = 1$。方程 $a g q' = b g p'$ 即 $a q' = b p'$。由 $p' \mid a q'$ 与 $\gcd(p', q') = 1$ 得 $p' \mid a$，设 $a = k p'$，代回得 $k p' q' = b p'$，即 $b = k q'$。所以全部解为 $(a, b) = (k p', k q')$（$k \ge 1$），最小正解在 $k = 1$ 处取得。∎

**引理 4（角落归属）**：设光线首次命中角落时的格点为 $(p'p,\ q'p)$，则它折叠回房间后的坐标为

$$\big(p \cdot [p' \text{ 为奇}],\ \ p \cdot [q' \text{ 为奇}]\big).$$

**证明**：由引理 1，$x = p' p$ 时 $\text{fold}(x) = 0$（$p'$ 偶）或 $p$（$p'$ 奇）；对 $y$ 同理。∎

**定理**：按算法规则返回的编号就是光线最先命中的接收器编号。

**证明**：由引理 3，光线第一次经过的格点是唯一的 $(p'p, q'p)$，它对应房间的某个角落；由引理 4 与题意（东南 = 0、东北 = 1、西北 = 2）：

- $p'$ 偶 $\Rightarrow$ 西墙（$x = 0$），此时 $q'$ 必为奇（否则 $2 \mid p', 2\mid q'$ 与 $\gcd(p',q')=1$ 矛盾）$\Rightarrow$ 北墙 $\Rightarrow$ **西北角 = 2**；
- $p'$ 奇、$q'$ 偶 $\Rightarrow$ 东墙 + 南墙 $\Rightarrow$ **东南角 = 0**；
- $p'$ 奇、$q'$ 奇 $\Rightarrow$ 东墙 + 北墙 $\Rightarrow$ **东北角 = 1**。

三情形互斥且穷尽（$p', q'$ 不会同为偶），恰好覆盖算法的三条分支。另外，西南角 $(0,0)$ 只在 $p', q'$ 同为偶时出现，不可能发生，这与题面「保证最终会遇到接收器」一致。故返回值正确。∎

## 6. 复杂度分析

- **时间**：$O(\log \min(p, q))$。求 $\gcd$ 用辗转相除，其余只有常数次除法与取模。$p \le 1000$ 时几乎是 $O(1)$。
- **空间**：$O(1)$。只用到 $g, p', q'$ 三个整数。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int mirrorReflection(int p, int q) {
        int g = gcd(p, q);
        p /= g;
        q /= g;
        if (p % 2 == 0) return 2;
        if (q % 2 == 0) return 0;
        return 1;
    }
};
```

### Python

```python
from math import gcd


class Solution:
    def mirrorReflection(self, p: int, q: int) -> int:
        g = gcd(p, q)
        p //= g
        q //= g
        if p % 2 == 0:
            return 2
        if q % 2 == 0:
            return 0
        return 1
```

## 8. 边界情况与易错点

1. **$q = p$**：光线直接从西南角打到东北角，$g = p$，约分后 $p' = q' = 1$（均奇）→ 返回 1，正确。
2. **$q < p$ 但 $p$ 为偶数、$q$ 为奇数**：约分后 $p'$ 仍为偶数 → 返回 2。例如 `p = 2, q = 1`，这是示例 1。
3. **忘记约分**：直接按 $a = p, b = q$ 判断，$p=4,q=2$ 会算成 $a=4$（偶，西墙）、$b=2$（偶，南墙）→ 错误地落到西南角，而正确解是约分后的 $a=2, b=1$ → 西北角 2。
4. **编号写反**：题目用「到接收器 0 的距离为 $q$」把 0 号钉在**东南角**，若误以为 0 在西北，则三种情形全部对调。记住：0 东南、1 东北、2 西北。
5. **用浮点判断「是否命中角落」**：$q/p$ 是分数，浮点相等判断不可靠；本题的整数解彻底绕开了这个问题。
6. **`__gcd` 与 `gcd`**：`__gcd` 是 GCC 扩展，`std::gcd`（C++17）才是标准写法；提交到 LeetCode 时两者都能过，但写题解应使用可移植版本。
7. **认为会打到西南角**：$p'$、$q'$ 互质保证不会同时为偶，所以西南角永远不是首个落点，不需要处理「返回 -1」之类的兜底。
