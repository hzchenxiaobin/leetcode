# LeetCode 括号的分数 题解

## 1. 题目概述

- **标题 / 题号**：括号的分数（#856，medium）
- **链接**：https://leetcode.cn/problems/score-of-parentheses/
- **来源**：LeetCode 第 90 场周赛 Q2
- **难度**：中等
- **标签**：栈、字符串、括号序列

**题意**：给定一个平衡括号字符串 `S`，按三条规则计算分数：

1. `()` 得 **1** 分；
2. `AB` 得 `A + B` 分（`A`、`B` 都是平衡括号串）；
3. `(A)` 得 `2 × A` 分（`A` 是平衡括号串）。

求 `S` 的分数。

**约束**：

- `S` 是平衡括号字符串，只含 `(` 与 `)`
- $2 \le \lvert S \rvert \le 50$

## 2. 示例

**示例 1**

```text
输入："()"
输出：1
解释：直接套规则 1。
```

**示例 2**

```text
输入："(())"
输出：2
解释：外层套住内层的 "()"，由规则 3 得 2 × 1 = 2。
```

**示例 3**

```text
输入："()()"
输出：2
解释：两个并列的 "()"，由规则 2 得 1 + 1 = 2。
```

**示例 4**

```text
输入："(()(()))"
输出：6
解释：外层括号把它分成 "()" 与 "(())" 两块，分数为 2 × (1 + 2) = 6。
```

## 3. 解题思路

### 3.1 暴力思路

最朴素的做法完全照抄定义：写一个递归函数，先按「第一个 `(` 的匹配 `)`」把串拆成 `(A)B`，再分别处理 `A` 与 `B`。

这样虽然正确，但存在两个问题：

1. 找匹配括号、切子串都要 $O(n)$，最坏（完全嵌套）退化成 $O(n^2)$；
2. $n$ 只有 50，$O(n^2)$ 也能过，但「按结构递归」的写法在括号题里很容易写错（空串、并列块、嵌套层数都要单独判）。

其实这道题有一个非常干净的**栈**视角：把「当前这一层已经攒了多少分」放在栈里，遇到右括号就结算一层。

### 3.2 核心观察：栈里存「每层已累加的分数」

![栈里存「每层已累加的分数」，遇到右括号就结算一层](images/wc90_q2_stack_model.svg)

栈的每个元素表示**某一层括号内部已经累计到的分数**。规则可以翻译成三条动作：

- 遇到 `(`：新开一层，压入 `0`；
- 遇到 `)`：当前层结束，弹出它的分数 $v$，这一层作为一个整体值 `max(2v, 1)`，加到**新的栈顶**（也就是外层）；
- 扫描结束后，栈底元素就是整串的分数。

为什么结算值是 $\max(2v, 1)$？因为 `(A)` 的分数是 $2A$：

- $v > 0$：说明括号里确实有内容，$2v$ 就是 $2A$；
- $v = 0$：说明这对括号是**空的** `()`，按规则 1 得 1 分，而 $2 \times 0 = 0$ 显然不对。

用一个 `max` 就把「空对」与「非空」两种情况统一了，这是本题写法最优雅的地方。

![等价的更简视角：每个 "()" 贡献 2 的「外层括号对数」次方](images/wc90_q2_depth_pow.svg)

还有一个等价的**深度视角**：把 `S` 拆成若干「叶子对」`()`，每个叶子对 `()` 若外层还包裹了 $d$ 对括号，它对总分的贡献就是 $2^d$。因为每多套一层 `(A)`，分数就翻一倍。例如 `(()(()))` 的两个叶子对分别被包裹了 1 层和 2 层，贡献 $2^1 + 2^2 = 6$。这个视角只需要维护一个 `depth` 变量，空间 $O(1)$。

### 3.3 算法流程

```text
1. 栈 = [0]                     // 栈底哨兵：最外层的累加和
2. for c in S:
       若 c == '('：
           栈.push(0)
       否则：
           v = 栈.pop()
           栈.top += max(2 * v, 1)
3. 返回 栈.top
```

`max(2v, 1)` 的含义：`v == 0` 代表空对 `()`（记 1 分），`v > 0` 代表 `(A)`（记 $2v$ 分）。

### 3.4 示例演算

![示例演算：S = "(()(()))" 的逐对结算](images/wc90_q2_walkthrough.svg)

以 `S = "(()(()))"`（长度 8）为例，栈的演化如下（栈内自底向顶书写）：

| 位置 | 字符 | 操作后栈内容 | 动作 |
|------|------|--------------|------|
| 0 | `(` | 0, 0 | 压入新层 |
| 1 | `(` | 0, 0, 0 | 压入新层 |
| 2 | `)` | 0, 1 | 弹出 $v=0$，回加 $\max(0,1)=1$ |
| 3 | `(` | 0, 1, 0 | 压入新层 |
| 4 | `(` | 0, 1, 0, 0 | 压入新层 |
| 5 | `)` | 0, 1, 1 | 弹出 $v=0$，回加 1 |
| 6 | `)` | 0, 3 | 弹出 $v=1$，回加 $2 \times 1=2$，外层由 1 变 3 |
| 7 | `)` | 6 | 弹出 $v=3$，回加 $2 \times 3=6$ |

扫描结束时栈内只剩 `6`，与答案一致。

用深度视角复核：两个叶子对分别是位置 1–2 与 4–5，前者外层包裹 1 层、后者包裹 2 层，贡献 $2^1 + 2^2 = 2 + 4 = 6$，同样得 6。这也印证了 `(())` 里那层 `(A)` 的翻倍效应。

## 4. 算法细节

1. **栈底哨兵 `0`**：初始化 `[0]` 而不是空栈，可以让最后一个 `)` 的结算直接落在哨兵上，省掉「栈空」的特判。
2. **`max(2 * v, 1)` 而不是分两支写**：$v = 0$ 时取 1、$v \ge 1$ 时取 $2v$，一个 `max` 全部覆盖。注意 $v$ 一定是非负整数，所以 `max` 的行为完全符合预期。
3. **`v` 的语义**：弹出的值是这一对括号**内部**的总分。若内部为空则 $v = 0$；否则 $v \ge 1$ 且 $2v \ge 2 > 1$，`max` 不会误伤。
4. **C++ 用 `vector<int>` 当栈**：`push_back` / `back()` / `pop_back()` 比 `std::stack` 更快也更方便访问栈顶。
5. **Python 直接对列表操作**：`stack.append(0)`、`stack.pop()`、`stack[-1] += ...`，语义一目了然。
6. **数值范围**：$\lvert S \rvert \le 50$ 意味着最多 25 对括号，最坏完全嵌套时分数为 $2^{24} = 16777216 < 2^{31}$，`int` 足够；若放宽到 $10^5$ 长度就要考虑取模或大整数。
7. **深度视角的等价写法**：维护 `depth` 与 `ans`，遇到 `(` 时 `depth++`，遇到 `)` 时先 `depth--`，若前一个字符是 `(` 就 `ans += 1 << depth`。空间 $O(1)$，可作为栈版的替代实现。

## 5. 正确性证明

先给出**结构分解引理**——它是理解三条计分规则的基础。

**引理 1（唯一分解）**：任何非空平衡括号串 $S$ 可以唯一地写成 $S = (A)B$，其中 $A$ 是平衡串（可为空），$B$ 是平衡串（可为空）。

**证明**：$S$ 的首字符必为 `(`（否则前缀和为负）。从首字符开始累加括号深度，深度第一次回到 0 时的那个 `)` 记作匹配括号；它一定存在（因为 $S$ 平衡且非空），设其位置为 $k$。令 $A = S[1..k-1]$，$B = S[k+1..]$。$A$ 内部深度始终为正，故 $A$ 是平衡串；$S$ 整体平衡且 $S[0..k]$ 平衡，故 $B$ 也平衡。

唯一性：$k$ 是「深度首次归零」的位置，由 $S$ 唯一确定，故 $A$、$B$ 唯一。∎

有了引理 1，计分规则可以改写成递归形式：

$$
F(S) = \begin{cases}
1, & S = \texttt{()} \\
2\,F(A) + F(B), & S = (A)B,\ A \ne \varepsilon \\
1 + F(B), & S = \texttt{()}B
\end{cases}
$$

（第二、三行分别是「内部非空」与「内部为空」两种情形，与代码里的 `max(2v, 1)` 一一对应。）

**引理 2（栈不变式）**：对任意平衡串 $S$，从任意栈状态出发处理 $S$：处理过程中栈的深度净变化为 0（先增后减、配对抵消），且处理结束后**栈顶元素恰好增加 $F(S)$**，栈中其余元素不变。

**证明**：对 $\lvert S \rvert$ 做结构归纳。设 $S = (A)B$（引理 1）。

- 读到 `(`：压入 `0`，此时栈顶（新层）为 0。
- 处理 $A$：由归纳假设（$\lvert A \rvert < \lvert S \rvert$），$A$ 处理完后栈顶增加 $F(A)$，其余不变；特别地新层此时的值是 $F(A)$（空 $A$ 时为 0）。
- 读到 `)`：弹出 $v = F(A)$，把 $\max(2v, 1)$ 加到新的栈顶。由于 $F(A) \ge 0$：若 $A = \varepsilon$ 则 $v = 0$，回加 1；若 $A \ne \varepsilon$ 则 $F(A) \ge 1$，回加 $2F(A)$。
- 处理 $B$：由归纳假设，再给栈顶增加 $F(B)$。

合计增量：

- $A = \varepsilon$ 时：$1 + F(B) = F(\texttt{()}B) = F(S)$；
- $A \ne \varepsilon$ 时：$2F(A) + F(B) = F((A)B) = F(S)$。

而栈深净变化：$S$ 平衡，`(` 与 `)` 数量相等，每个 `(` 压栈、每个 `)` 弹栈，故净变化为 0。∎

**定理**：算法返回的值等于 $F(S)$。

**证明**：初始栈为 `[0]`。由引理 2，处理完整的 $S$ 后栈顶（也就是唯一剩余元素，因为栈深净变化为 0 且初始深度为 1）增加 $F(S)$，即最终栈内唯一的元素为 $0 + F(S) = F(S)$。算法返回该元素，故返回值等于 $F(S)$。∎

**引理 3（深度视角）**：把 $S$ 分解成若干叶子对 `()`，若某个叶子对外层包裹了 $d$ 对括号，则它对 $F(S)$ 的贡献为 $2^{d}$，且 $F(S)$ 等于所有叶子对贡献之和。

**证明**：对结构归纳。基础情形 $S = \texttt{()}$：只有一个外层对数 $d = 0$ 的叶子对，贡献 $2^0 = 1 = F(S)$。归纳：若 $S = (A)$（$A$ 非空），每个叶子对的外层对数都增加 1，由归纳假设 $F(A) = \sum 2^{d_i}$，故 $F(S) = 2F(A) = \sum 2^{d_i + 1}$。若 $S = AB$，两部分叶子对互不相干，外层对数不变，贡献相加即得 $F(S) = F(A) + F(B)$。∎

> 💡 深度视角与 `1 << depth` 的写法完全对应：代码在遇到形如 `()` 的右括号时，把 $2^{\text{depth}}$ 累加到答案里，正是引理 3 的逐项求和。

## 6. 复杂度分析

- **时间**：$O(\lvert S \rvert)$。每个字符恰好被处理一次，`(` 做一次压栈、`)` 做一次弹栈与一次加法，均为 $O(1)$。
- **空间**：栈版 $O(\lvert S \rvert)$，最坏情况是完全嵌套（栈深 $\lvert S \rvert/2 + 1$）；深度视角的写法只需 `depth` 与 `ans` 两个变量，额外空间 $O(1)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int scoreOfParentheses(string s) {
        vector<int> stack(1, 0);
        for (char c : s) {
            if (c == '(') {
                stack.push_back(0);
            } else {
                int cur = stack.back();
                stack.pop_back();
                stack.back() += max(2 * cur, 1);
            }
        }
        return stack.back();
    }
};
```

### Python

```python
class Solution:
    def scoreOfParentheses(self, s: str) -> int:
        stack = [0]
        for ch in s:
            if ch == '(':
                stack.append(0)
            else:
                cur = stack.pop()
                stack[-1] += max(2 * cur, 1)
        return stack[0]
```

## 8. 边界情况与易错点

1. **空对必须记 1 分**：`()` 的分数是 1，不是 $2 \times 0 = 0$。用 `max(2 * cur, 1)` 统一处理，若写成 `2 * cur` 会全错。
2. **栈底哨兵不能省**：若初始化为空栈，最后一个 `)` 弹栈后对空栈做 `top +=` 会越界（C++）或抛异常（Python）。
3. **并列块的累加**：`()()` 是两个独立的 `()` 都回加到同一层哨兵上，结果 2；不要误以为是 $2 \times 1$。
4. **深度是「外层对数」而不是「括号层数」**：`()` 的叶子对外层对数为 0，贡献 $2^0 = 1$；写成 `1 << (depth)` 时要在 `depth--` **之后**取值，否则会偏移一层。
5. **`1 << depth` 的溢出**：$\lvert S \rvert \le 50$ 时 $d \le 24$，`1 << 24` 安全；若题目放大长度，必须改用取模或高精度。
6. **不要用浮点**：分数都是 2 的幂次之和，用整数即可；任何 `pow` 都既慢又有精度隐患。
7. **最后返回的是栈内唯一剩余元素**：平衡串保证扫描结束时栈深回到 1，若返回 `stack[0]`（Python）或 `stack.back()`（C++）都可以，但不要在循环中途提前返回。
