# LeetCode 从字符串中移除星号 题解

## 1. 题目概述

- **标题 / 题号**：从字符串中移除星号（#2390，medium）
- **链接**：https://leetcode.cn/problems/removing-stars-from-a-string/
- **来源**：LeetCode 第 308 场周赛 Q2
- **难度**：中等
- **标签**：栈、字符串、模拟

**题意**：给定字符串 `s`，由小写字母和星号 `*` 组成。一次操作可以：选中一个 `*`，把它**左侧最近的那个非星号字符**和这个 `*` 自身一起删除。反复操作直到没有 `*`，返回结果串。操作顺序可以任选，但题目保证结果唯一。

**约束**：

- $1 \le \text{s.length} \le 10^5$
- `s` 仅由小写字母和 `*` 组成
- 题目保证操作总能执行（不存在「无字母可删」的星号）

> 💡 **一句话切入**：把 `*` 当成**退格键**——每按一下退格，就抹掉光标左边最近的一个字母。求整段打字过程结束后屏幕上剩下的文本。而「屏幕上还留着的字母 + 光标位置」正是文本编辑器的经典实现：一个栈。

## 2. 示例

**示例 1**

```text
输入：s = "leet**cod*e"
输出："lecoe"
解释：从左到右依次消除：
- 第 1 个 *：左侧最近的字母是 't' → "lee*cod*e"
- 第 2 个 *：左侧最近的字母是 'e' → "lecod*e"
- 第 3 个 *：左侧最近的字母是 'd' → "lecoe"
```

**示例 2**

```text
输入：s = "erase*****"
输出：""
解释：5 个连续 * 连删 "erase" 的后 5 个字母，整个字符串被删空。
```

**示例 3**（自构造：覆盖「中段星号 + 连续弹栈」的情形）

```text
输入：s = "abb*ca**"
输出："ab"
解释：逐字符推进栈：
a→[a]  b→[a,b]  b→[a,b,b]  *弹b→[a,b]  c→[a,b,c]  a→[a,b,c,a]  *弹a→[a,b,c]  *弹c→[a,b]
```

## 3. 解题思路

### 3.1 暴力思路：现场找星号、回头找字母

最朴素的模拟：在串里找一个 `*`，从它出发向左扫描定位最近的非星号字符，把两个位置一起删掉，循环直到没有 `*`。

每轮「查找 + 删除」都是 $O(n)$（删除引发元素前移），最坏 $\lfloor n/2 \rfloor$ 个星号，总计 $O(n^2)$。$n = 10^5$ 时约 $10^{10}$ 次字符移动，**必超时**。

瓶颈在于：每个 `*` 都要**回头**重新找目标。但「左侧最近的未删除字母」这个信息，其实在从左到右的扫描过程中可以被增量维护——它就是**栈顶**。

### 3.2 核心观察：`*` 是退格键，栈顶就是「左侧最近的未删字母」

![核心观察：星号是退格键，栈顶即左侧最近的未删字母](images/remove_stars_backspace_concept.svg)

三个层层递进的观察：

- **观察一（操作只向左）**：每个 `*` 删除的字母一定在它**左侧**，右侧的字符永远不受影响。因此从左到右扫描时，位置 $i$ 左边的「消除结果」可以先行确定，与右边的内容无关——这是单遍扫描可行的根基。
- **观察二（星号随到随消）**：`*` 自己注定被删，也永远不会成为别人的删除目标（目标必须是**非星号**字符）。所以星号根本不需要存储：扫描到它的一瞬间，立刻执行「弹掉左侧最近字母」即可。存活候选只有字母。
- **观察三（LIFO 恰好刻画「最近」）**：只把**尚未被删除的字母**按到达顺序入栈，则「当前扫描位置左侧最近的未删字母」正是**栈顶**——最近入栈、尚未弹出。`*` 的语义于是塌缩为一行：`stack.pop()`。

> 💡 文本编辑器正是这样实现的：输入缓冲区一个栈，退格键 = `pop`。本题就是这个模型的最裸版本。

### 3.3 算法流程

![算法流程：遇字母入栈、遇星号弹栈，一遍扫描后拼接](images/remove_stars_algorithm_flow.svg)

1. 维护栈 `st`（初值空）；
2. 从左到右遍历 `s` 的每个字符 `c`：
   - `c == '*'`：`st.pop()`（题目保证栈非空）；
   - 否则：`st.push(c)`；
3. 扫描结束，栈底到栈顶拼接即为答案。

### 3.4 示例演算

![示例演算：s = leet**cod*e 的六阶段栈快照](images/remove_stars_example_walkthrough.svg)

以 `s = "leet**cod*e"` 为例，把 11 个字符按操作类型分成 6 个阶段：

| 阶段 | 读入 | 操作 | 栈（底→顶） |
|------|------|------|------------|
| 1 | `leet` | 连续 push | `l e e t` |
| 2 | `*` | pop → 删 `t` | `l e e` |
| 3 | `*` | pop → 删 `e` | `l e` |
| 4 | `cod` | 连续 push | `l e c o d` |
| 5 | `*` | pop → 删 `d` | `l e c o` |
| 6 | `e` | push | `l e c o e` |

最终栈自底向顶为 `l e c o e`，拼接得 `"lecoe"` ✓。注意阶段 2、3 是**连按两次退格**：连续的 `*` 会连续弹栈，阶段 5 的 `*` 删的是 `cod` 里的 `d` 而不是更早的字母——「最近」二字始终由栈顶保证。

## 4. 算法细节

1. **C++ 直接拿 `string` 当栈**：`push_back` / `pop_back` 就是 push / pop，扫完 `st` 本身就是答案，无需 `stack<char>` 再倒一遍。
2. **Python 用 `list` + `join`**：切勿在循环里 `ans += c` 反复拼接不可变字符串（均摊 $O(n^2)$）；`''.join(st)` 一次性线性拼接。
3. **写指针原地版（$O(1)$ 额外空间）**：读指针 `i` 扫描、写指针 `j` 维护结果区右边界——遇字母 `s[j++] = s[i]`，遇 `*` 则 `--j`（把刚写入的字母抹掉），最后 `resize(j)`。本质是把栈复刻在原数组前缀上，仅适用于可变字符串（C++）；Python 串不可变，最低仍需 $O(n)$。
4. **星号从不入栈**：所以「栈里全是字母」，`*` 左侧最近的**非星号**字符 = 栈顶，无需任何过滤逻辑。分支条件写 `c == '*'` 即可——字符集只有小写字母和 `*`，`else` 分支必是字母；若字符集更杂，条件应显式写 `c != '*'`。
5. **`pop` 免判空的依据**：题目保证操作总能执行 ⟹ 扫描到 `*` 时它左侧必有可删字母 ⟹ 栈非空。若输入不受控，加一句 `if not st: ...` 守卫更稳。

## 5. 正确性证明

记一次操作为二元组 $(p, x)$：删除星号 $p$ 及其目标字母 $x$（$x$ 是当前串中 $p$ 左侧最近的非星号字符）。以下「串」均指某一中间状态的字符序列。

**引理 1**（交换不变性）：设当前串中有两个可执行操作 $(p, x)$、$(q, y)$，$p \ne q$，则先执行哪一个，执行完两步后的串相同。

**证明**：分两种情形。
（a）$x \ne y$：删除 $(p, x)$ 只移走一个星号和一个字母。对 $q$ 而言，若 $x$ 在 $q$ 右侧，$q$ 左侧字符集不变；若 $x$ 在 $q$ 左侧，则 $y$ 是 $q$ 左侧**最近**的非星号字符，$x$ 是更远的一个，移走 $x$ 不改变「最近」者是 $y$。故 $(q, y)$ 仍可执行且目标不变，两步删除的字符集合相同、剩余串相同。
（b）$x = y$（两个星号竞争同一字母）：设 $z$ 是 $x$ 左侧最近的非星号字符。先执行 $(p, x)$ 后，$q$ 的目标变为 $z$，两步共删除 $\{p, q, x, z\}$；先执行 $(q, x)$ 后，$p$ 的目标同样变为 $z$，两步仍共删除 $\{p, q, x, z\}$。剩余串相同。∎

**推论**（终态唯一）：对串长强归纳：串中无星号时终态即自身；有星号时，任意两条操作序列的首步 $(p,x)$、$(q,y)$ 可由引理 1 交换为相同的前两步，对更短的剩余串用归纳假设得相同终态。故**任何操作序列的终态相同**，记作 $R(s)$。

**引理 2**（栈不变量）：从左到右扫描 `s`，遇字母 push、遇 `*` pop，则扫完前缀 $s[0..i-1]$ 后，栈中内容（底→顶）恰为 $R(s[0..i-1])$。

**证明**（对 $i$ 归纳）：$i = 0$ 时空栈 = 空串。设 $i$ 时成立，考察 $s[i]$：
- $s[i] = c$ 为字母：$s[0..i]$ 中的所有星号都在 $c$ 左侧，操作只向左删，故 $c$ 永远存活，且前缀内部的消除不受影响，$R(s[0..i]) = R(s[0..i-1]) + c$，对应 `push(c)`。
- $s[i] = $ `*`：先消除前缀得 $R(s[0..i-1]) + $ `*`（全字母后跟一个星号）。这个星号必须被删，而它左侧最近的非星号字符恰是 $R(s[0..i-1])$ 的**末字母**（由归纳假设即栈顶），故 $R(s[0..i])$ 为 $R(s[0..i-1])$ 去掉末字母，对应 `pop()`。∎

**定理**：栈算法的输出等于 $R(s)$，即题目所求的唯一结果。

**证明**：取 $i = n$，由引理 2，扫描结束后栈（底→顶）$= R(s)$；拼接栈即得答案。由推论，$R(s)$ 与操作顺序无关，也是任意合法操作序列的终态。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。单遍扫描，每个字符恰好触发一次 `push` 或一次 `pop`，两者均摊 $O(1)$；最后拼接 $O(n)$。对照暴力版 $O(n^2)$，把「每个 `*` 回头线性找目标」降为「栈顶 $O(1)$ 弹出」。
- **空间复杂度**：$O(n)$。栈即结果的存放处，最坏（全是字母）深度 $n$；不计输出则写指针原地版可做到 $O(1)$ 额外空间（仅 C++）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    string removeStars(string s) {
        string st;                        // string 即栈：底 → 顶
        for (char c : s) {
            if (c == '*') st.pop_back();  // 删掉左侧最近的字母 = 栈顶
            else           st.push_back(c);
        }
        return st;
    }
};
```

写指针原地版（$O(1)$ 额外空间，把栈复刻在原数组前缀）：

```cpp
class Solution {
public:
    string removeStars(string s) {
        int j = 0;                        // 写指针：[0, j) 为保留区
        for (int i = 0; i < (int)s.size(); ++i) {
            if (s[i] == '*') --j;         // 回退一格 = 撤销最近写入
            else            s[j++] = s[i];
        }
        s.resize(j);
        return s;
    }
};
```

### Python

```python
class Solution:
    def removeStars(self, s: str) -> str:
        st = []
        for c in s:
            if c == '*':
                st.pop()                  # 题目保证栈非空
            else:
                st.append(c)
        return ''.join(st)
```

## 8. 边界情况与易错点

1. **`pop` 空栈**：题目保证「操作总能执行」⟹ 不会有前导 `*`，扫描到 `*` 时栈必非空。但 C++ 对空串 `pop_back()` 是**未定义行为**、Python 抛 `IndexError`——依赖该保证时要心里有数，工程上加 `if st:` 守卫。
2. **连续星号**：连续 `pop` 即可（示例 2 的 `"erase*****"`），`erase` 恰好 5 个字母对 5 个星号，结果为空串——`join` 空列表得 `""`，C++ 空 `string` 天然正确，**不要对空结果特殊处理**。
3. **答案顺序 = 栈底到栈顶**：即字母的原始相对顺序，直接拼接即可，**不要翻转**。
4. **别把星号入栈**：星号随到随消，栈里只存字母，「非星号」判定因此免费。若误写成「所有字符都 push、遇 `*` 弹到非星号为止」，逻辑能对但白绕一圈。
5. **分支条件**：字符集只有小写字母和 `*`，`else` 即字母；若字符集含其他符号，应显式判 `c != '*'` 入栈。
6. **Python 拼接陷阱**：循环内 `ans += c` 在最坏情形退化为 $O(n^2)$，必须 `list` + `join`。
7. **暴力超时红线**：每轮 `find('*')` + `erase` 的 $O(n^2)$ 写法在 $n = 10^5$ 下约 $10^{10}$ 次字符移动，比赛里直接 TLE。
8. **「操作顺序任意」不是干扰项**：由引理 1 的交换不变性，终态与顺序无关（题目也保证了这一点），所以从左到右这一种顺序就足够。
