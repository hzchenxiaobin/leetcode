# LeetCode 给定条件下构造矩阵 题解

## 1. 题目概述

- **标题 / 题号**：给定条件下构造矩阵（#2392，hard）
- **链接**：https://leetcode.cn/problems/build-a-matrix-with-conditions/
- **来源**：LeetCode 第 308 场周赛 Q4
- **难度**：困难
- **标签**：图、拓扑排序、有向无环图、数组、矩阵

**题意**：给定正整数 $k$ 与两组约束：`rowConditions[i] = [above, below]` 要求数字 `above` 所在的**行**严格在数字 `below` 所在行的**上方**；`colConditions[i] = [left, right]` 要求 `left` 所在的**列**严格在 `right` 所在列的**左边**。构造一个 $k \times k$ 矩阵，使 $1$ 到 $k$ **每个数字恰好出现一次**，其余位置为 $0$，且满足全部行列约束。返回任意一个合法矩阵；若不存在，返回空矩阵。

**约束**：

- $2 \le k \le 400$
- $1 \le \text{rowConditions.length}, \text{colConditions.length} \le 10^4$
- 条件中的整数都在 $1$ 到 $k$ 之间，且 `above != below`、`left != right`（保证无自环）

> 💡 **一句话切入**：「谁必须在谁的上面/左边」本质是一组**偏序关系**——行约束和列约束分别对应一张独立的有向无环图。每张图做一次**拓扑排序**：有环即无解返回空矩阵；无环则拓扑序直接给出每个数字的行号与列号，坐标拼装即得答案。

## 2. 示例

**示例 1**

```text
输入：k = 3, rowConditions = [[1,2],[3,2]], colConditions = [[2,1],[3,2]]
输出：[[3,0,0],[0,0,1],[0,2,0]]
解释：数字 1 在第 1 行、数字 2 在第 2 行 → 1 在 2 上面；数字 3 在第 0 行 → 3 在 2 上面。
数字 2 在第 1 列、数字 1 在第 2 列 → 2 在 1 左边；数字 3 在第 0 列 → 3 在 2 左边。
注意：答案不唯一，任何合法矩阵都接受（Special Judge）。
```

**示例 2**

```text
输入：k = 3, rowConditions = [[1,2],[2,3],[3,1],[2,3]], colConditions = [[2,1]]
输出：[]
解释：1→2→3→1 构成环：要求 row(1)<row(2)<row(3)<row(1)，矛盾，无解。
（其中重复条件 [2,3] 对结论没有影响。）
```

**示例 3**（自构造：部分数字不受任何约束）

```text
输入：k = 3, rowConditions = [[2,1]], colConditions = []
输出：[[0,2,0],[0,0,3],[1,0,0]]
解释：只有 2 必须在 1 上方（拓扑序 2,3,1 → 行 0,1,2）；
列无任何约束，1、2、3 按入队自然顺序分到列 0,1,2；
数字 3 不受任何约束，落在拓扑排序自然给出的位置。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的念头是枚举：数字 $1..k$ 的**行排列**有 $k!$ 种、**列排列**又有 $k!$ 种，组合后逐一检查——$k = 400$ 时 $k!$ 是天文数字，直接爆炸。

退一步想「逐个数字放置 + 回溯」：每个数字有 $k^2$ 个候选格子，冲突与约束检查复杂，最坏仍是指数级。卡点在于把「构造矩阵」当成**放置问题**；而约束里根本没有任何关于**具体行号 / 列号**的要求，只有**相对次序**——这是一组**偏序**，该用排序的武器，而不是搜索的武器。

### 3.2 核心观察：两组偏序 → 两张独立的 DAG

![核心观察：行、列条件是两张互相独立的 DAG](images/wc308_q4_two_dags.svg)

三个层层递进的观察：

- **观察一（约束即有向边）**：「$a$ 在 $b$ 上方」等价于 $\text{row}(a) < \text{row}(b)$，即 $a$ 在行序列中排在 $b$ 前面。把每个条件 `above → below` 建成一条边，行约束集合就是一张 $k$ 个点的**有向图** $G_r$；列约束同理得到 $G_c$（边 `left → right`）。
- **观察二（行列解耦）**：行条件**只**约束行的相对次序，列条件**只**约束列的相对次序，两组约束**互不感知**。数字 $v$ 的最终落点由 $(\text{row}(v), \text{col}(v))$ 两个独立分量拼装而成——行方案怎么选、列方案怎么选，拼起来都合法。
- **观察三（环即无解的充要判据）**：图里有环 ⟺ 无解。若 $G_r$ 中有环 $c_1 \to c_2 \to \dots \to c_t \to c_1$，则要求 $\text{row}(c_1) < \text{row}(c_2) < \dots < \text{row}(c_t) < \text{row}(c_1)$，严格不等号绕一圈回到自己，矛盾（示例 2 即是 3-环）；反之若两张图都无环，**拓扑排序**天然给出满足全部先后关系的合法安排。

于是困难题被拆成两次教科书级的**拓扑排序**加一步坐标拼装。

### 3.3 算法流程

![算法流程：两次 Kahn 拓扑排序 + 坐标拼装](images/wc308_q4_topo_flow.svg)

采用 **Kahn 算法**（BFS 拓扑排序），它把「排序」和「环检测」合成一遍完成：

1. **建图**：由 `rowConditions` 建行图 $G_r$（边 `above → below`），由 `colConditions` 建列图 $G_c$（边 `left → right`），同时维护每个点的入度。
2. **对 $G_r$ 做 Kahn 排序**：入度为 $0$ 的点入队；每出队一个点，把它的所有后继入度减一，减到 $0$ 就入队。**出队次序就是行下标**——第 $i$ 个出队的数字放在第 $i$ 行。
3. **环检测**：若出队总数 $< k$，说明有环上点的入度永远减不到 $0$，直接返回空矩阵 `[]`。
4. **对 $G_c$ 同样处理**，得到每个数字的列下标。
5. **拼装**：对每个数字 $v$，置 `ans[row[v]][col[v]] = v`，其余位置保持 $0$。

### 3.4 示例演算

![示例 1 演算：拓扑序拼装出矩阵](images/wc308_q4_walkthrough.svg)

以示例 1 走一遍全流程：

- **行图**：边 $1\to2$、$3\to2$，入度 $2$ 为 $2$，$1$、$3$ 为 $0$。初始队列 $\{1, 3\}$：出队 $1$（行 0）→ 出队 $3$（行 1）→ $2$ 的入度归零入队 → 出队 $2$（行 2）。行拓扑序 $1, 3, 2$。
- **列图**：边 $2\to1$、$3\to2$。出队 $3$（列 0）→ $2$ 入度归零 → 出队 $2$（列 1）→ $1$ 归零 → 出队 $1$（列 2）。列拓扑序 $3, 2, 1$。
- **拼装**：$1 \to (0,2)$，$2 \to (2,1)$，$3 \to (1,0)$，得到 $\left[\begin{smallmatrix}0&0&1\\3&0&0\\0&2&0\end{smallmatrix}\right]$。与官方示例输出 $\left[\begin{smallmatrix}3&0&0\\0&0&1\\0&2&0\end{smallmatrix}\right]$ 不同，但逐条检查行、列约束全部满足——Special Judge 判题下同样正确。

## 4. 算法细节

1. **图的数据结构**：点数固定为 $k+1$（下标 $1..k$），邻接表 `vector<vector<int>>` / 列表套列表加入度数组即可；$k \le 400$、边数 $\le 10^4$，规模极小，无需哈希表。
2. **Kahn 的「位置」语义**：出队序即拓扑序，**第 $i$ 个出队的点直接获得下标 $i$**——不需要显式数组存序，遍历 `order` 时用下标即可回填 `row[v] = i`。
3. **环检测藏在长度里**：Kahn 结束后若 `order.size() < k`，即存在环。这是「排序失败」与「检测有环」的一体两面，不需要 DFS 三色染色。
4. **落点无碰撞**：`row` 是 $0..k-1$ 的一个**排列**（每个数字出队恰一次、各得一个互不相同的行号），`col` 同理，因此 $(\text{row}(v), \text{col}(v))$ 两两不同——每行每列恰好各有一个非零数字，「每个数字恰好出现一次、其余为 0」自动成立。
5. **重复边无害**：同一条件（如示例 2 的两条 $2\to3$）重复建边时，入度的「加两次」与出队时的「减两次」严格抵消，Kahn 结果不变；若不放心可先去重，结论一致。
6. **无约束的数字**：不出现在任何条件中的数字入度为 $0$，第一轮即入队，被分配到某个确定位置——无需任何特判（示例 3 的数字 3）。
7. **返回值区分**：两张图**任一**有环都返回 `{}`（长度 0 的二维数组）；只有两张图都无环才进入拼装阶段。

## 5. 正确性证明

设 $V=\{1,2,\dots,k\}$，行条件建图 $G_r = (V, E_r)$，列条件建图 $G_c = (V, E_c)$。

**引理 1**（偏序可满足性）：一组行条件可被某个放置满足，当且仅当 $G_r$ 无环。

**证明**：(⟸) 若 $G_r$ 无环，取任一拓扑序 $v_0, v_1, \dots, v_{k-1}$，把 $v_i$ 放在第 $i$ 行。对任意边 $a \to b$，拓扑序保证 $a$ 的序号小于 $b$，故 $\text{row}(a) < \text{row}(b)$，即 $a$ 严格在 $b$ 上方，全部条件满足。(⟹) 反证：若存在环 $c_1 \to c_2 \to \dots \to c_t \to c_1$，则任何放置需同时满足 $\text{row}(c_1) < \text{row}(c_2) < \dots < \text{row}(c_t) < \text{row}(c_1)$，链式传递得 $\text{row}(c_1) < \text{row}(c_1)$，矛盾，故无可行放置。列条件同理对应 $G_c$。∎

**引理 2**（行列解耦）：一个 $k\times k$ 矩阵 $M$ 合法，当且仅当「行放置满足全部行条件」且「列放置满足全部列条件」，且这两个方案可以独立选取、任意组合。

**证明**：行条件只比较 $\text{row}(a)$ 与 $\text{row}(b)$ 的大小，列条件只比较 $\text{col}(a)$ 与 $\text{col}(b)$ 的大小，二者约束的变量集不相交。给定数字集合 $\{1..k\}$，任意「行分配」（$\text{row}: V \to \{0..k-1\}$ 为单射）与任意「列分配」（$\text{col}: V \to \{0..k-1\}$ 为单射）组合出的矩阵中，每个 $v$ 落在唯一的 $(\text{row}(v), \text{col}(v))$，且因 $\text{row}$ 为排列，各行恰一个数字，非零格子恰 $k$ 个——恰好每个数字出现一次、其余为 $0$。行条件的满足只依赖 $\text{row}$，列条件的满足只依赖 $\text{col}$，故组合保持合法性。∎

**引理 3**（Kahn 的正确性）：对无环图 $G$，Kahn 算法输出的序列是 $G$ 的一个拓扑序；对有环图，出队总数 $< k$。

**证明**：无环图中必有入度 $0$ 的点，算法每次出队点 $v$ 时，$v$ 的所有前驱都已出队（否则入度 $> 0$），故出队序满足「前驱先于后继」，即拓扑序；因无环，每个点入度最终都会归零并被出队，共 $k$ 个。有环时，环上点的入度在环内互相依赖，永不为 $0$，故出队数 $< k$。∎

**定理**：算法返回空矩阵当且仅当问题无解；否则返回的矩阵合法。

**证明**：无解判定：由引理 1，问题有解 ⟺ $G_r$ 与 $G_c$ 均无环；由引理 3，Kahn 出队数恰在「有环」时小于 $k$，故算法判空与问题无解等价。合法性：两张图无环时，由引理 3，`rows`、`cols` 分别是 $G_r$、$G_c$ 的拓扑序，按序号给每个 $v$ 分配行、列，由引理 2 的组合构造，所得矩阵每行恰一个数字、全部行条件与列条件满足，即为合法矩阵。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n + m + k + k^2)$，其中 $n$、$m$ 为两组条件数。
  - 建两张图各 $O(n + k)$、$O(m + k)$（初始化邻接表与入度数组）。
  - 两次 Kahn 排序各 $O(\text{点数} + \text{边数}) = O(n + k)$、$O(m + k)$。
  - 填矩阵 $O(k^2)$——这是**输出本身**的大小，无法省略。
  - 总量约 $2\times10^4 + 400 + 1.6\times10^5 \approx 1.8\times10^5$，远低于时限。

- **空间复杂度**：$O(n + m + k + k^2)$。两张邻接表与入度数组 $O(n + m + k)$，答案矩阵 $O(k^2)$（输出必需）；拓扑序等临时数组 $O(k)$。

## 7. 参考代码

### C++

```cpp
class Solution {
    // 对 edges 建图并做 Kahn 拓扑排序；有环时返回的序列长度 < k
    vector<int> topoOrder(int k, vector<vector<int>>& edges) {
        vector<vector<int>> g(k + 1);
        vector<int> indeg(k + 1);
        for (auto& e : edges) {
            g[e[0]].push_back(e[1]);
            indeg[e[1]]++;
        }
        queue<int> q;
        for (int v = 1; v <= k; ++v)
            if (indeg[v] == 0) q.push(v);
        vector<int> order;
        while (!q.empty()) {
            int v = q.front();
            q.pop();
            order.push_back(v);
            for (int w : g[v])
                if (--indeg[w] == 0) q.push(w);
        }
        return order;
    }

  public:
    vector<vector<int>> buildMatrix(int k, vector<vector<int>>& rowConditions,
                                    vector<vector<int>>& colConditions) {
        vector<int> rows = topoOrder(k, rowConditions);
        vector<int> cols = topoOrder(k, colConditions);
        if (rows.size() < k || cols.size() < k) return {};   // 任一图有环 → 无解

        vector<int> rowIdx(k + 1), colIdx(k + 1);
        for (int i = 0; i < k; ++i) {
            rowIdx[rows[i]] = i;    // 第 i 个出队 → 第 i 行
            colIdx[cols[i]] = i;    // 第 i 个出队 → 第 i 列
        }
        vector<vector<int>> ans(k, vector<int>(k));
        for (int v = 1; v <= k; ++v)
            ans[rowIdx[v]][colIdx[v]] = v;
        return ans;
    }
};
```

### Python

```python
from collections import deque

class Solution:
    def buildMatrix(self, k: int, rowConditions: List[List[int]],
                    colConditions: List[List[int]]) -> List[List[int]]:
        def topo_order(conditions):
            g = [[] for _ in range(k + 1)]
            indeg = [0] * (k + 1)
            for a, b in conditions:
                g[a].append(b)
                indeg[b] += 1
            q = deque(v for v in range(1, k + 1) if indeg[v] == 0)
            order = []
            while q:
                v = q.popleft()
                order.append(v)
                for w in g[v]:
                    indeg[w] -= 1
                    if indeg[w] == 0:
                        q.append(w)
            return order

        rows = topo_order(rowConditions)
        cols = topo_order(colConditions)
        if len(rows) < k or len(cols) < k:     # 任一图有环 → 无解
            return []

        row_idx = [0] * (k + 1)
        col_idx = [0] * (k + 1)
        for i, v in enumerate(rows):
            row_idx[v] = i    # 第 i 个出队 → 第 i 行
        for i, v in enumerate(cols):
            col_idx[v] = i    # 第 i 个出队 → 第 i 列

        ans = [[0] * k for _ in range(k)]
        for v in range(1, k + 1):
            ans[row_idx[v]][col_idx[v]] = v
        return ans
```

## 8. 边界情况与易错点

1. **环检测别只做一遍**：行图、列图**各查一次**，任一有环都返回 `[]`。示例 2 的 $1\to2\to3\to1$ 是 3-环，Kahn 队列初始即空，出队数为 $0 < 3$。
2. **边方向别建反**：行图是 `above → below`（上在前），列图是 `left → right`（左在前）。方向反了会输出「恰好全错」的矩阵——所有约束都反向满足，本地测试务必逐条核对。
3. **重复条件**：如示例 2 的两条 $[2,3]$。Kahn 中重复边让入度「加几次」与「减几次」严格配对，天然无害；但若换用「入度减到 0 才入队」以外的写法（如按邻接矩阵去重计数），要保证加、减两侧逻辑一致。
4. **答案不唯一**：判题是 Special Judge，任何合法矩阵都接受；本地对拍官方示例时输出可能不同，需写**合法性检查器**（逐条验证行列约束 + 每数恰一次）而非比对具体矩阵。
5. **无约束数字**：不出现在条件里的数字入度为 0 自然入队获得位置，无需特判；别误以为「没约束的数字要最后处理」。
6. **空矩阵的返回形态**：C++ 返回 `{}`（`vector<vector<int>>` 长度 0），Python 返回 `[]`；不要返回 `[[]]` 或 `k×0` 之类的「假空」。
7. **每数恰一次由排列性质保证**：行下标是 $0..k-1$ 的排列，非零格子恰好 $k$ 个且两两不同行、不同列——「恰好出现一次」无需额外判重逻辑。
8. **规模核对**：$k \le 400$、边数 $\le 10^4$，全程 `int` 无溢出风险；时间 $O(n+m+k^2) \approx 2\times10^5$，一次遍历轻松通过。
