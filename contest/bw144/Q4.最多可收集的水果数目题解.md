# LeetCode 最多可收集的水果数目 题解

## 1. 题目概述

- **标题 / 题号**：最多可收集的水果数目（#3363，hard）
- **链接**：https://leetcode.cn/problems/find-the-maximum-number-of-fruits-collected/
- **来源**：LeetCode 第 144 场双周赛 Q4
- **难度**：困难
- **标签**：数组、动态规划、矩阵

**题意**：有一个 $n \times n$ 的房间网格，`fruits[i][j]` 表示房间 $(i,j)$ 中的水果数。三个小朋友一开始分别站在**角**上：$(0,0)$、$(0,n-1)$、$(n-1,0)$。每位小朋友都**恰好移动 $n-1$ 次**，最终都必须到达 $(n-1,n-1)$，移动规则各不相同：

- **第一位**（从 $(0,0)$ 出发）：每一步可以到 $(i+1,j+1)$、$(i+1,j)$ 或 $(i,j+1)$；
- **第二位**（从 $(0,n-1)$ 出发）：每一步可以到 $(i+1,j-1)$、$(i+1,j)$ 或 $(i+1,j+1)$；
- **第三位**（从 $(n-1,0)$ 出发）：每一步可以到 $(i-1,j+1)$、$(i,j+1)$ 或 $(i+1,j+1)$。

进入房间即收走全部水果；若多个小朋友进入同一房间，只有第一个进入的能收（因为离开后房间就空了）。求三人**总共**最多能收集多少水果。

**约束**：

- $2 \le n = fruits.length = fruits[i].length \le 1000$
- $0 \le fruits[i][j] \le 1000$

$n$ 最大 $1000$，状态量 $n^2 = 10^6$，因此正解应是 $O(n^2)$ 的 DP；三人联合搜索（$3^{n-1}$ 级别的路径数）完全不可行。

## 2. 示例

**示例 1**

```text
输入：fruits = [[1,2,3,4],[5,6,8,7],[9,10,11,12],[13,14,15,16]]
输出：100
解释：第一位走对角线 (0,0)->(1,1)->(2,2)->(3,3)，收 1+6+11+16 = 34；
      第二位走 (0,3)->(1,2)->(2,3)->(3,3)，收 4+8+12（(3,3) 已被收走）= 24；
      第三位走 (3,0)->(3,1)->(3,2)->(3,3)，收 13+14+15 = 42；
      总计 34 + 24 + 42 = 100。
```

**示例 2**

```text
输入：fruits = [[1,1],[1,1]]
输出：4
解释：第一位走 (0,0)->(1,1) 收 1+1；第二位走 (0,1)->(1,1) 收 1；第三位走 (1,0)->(1,1) 收 1。
      四个格子全被走过，总计 4。
```

**示例 3（补充）**

```text
输入：fruits = [[0,0,0],[0,0,0],[0,0,0]]
输出：0
解释：所有房间都没有水果，任何走法都收 0 个；这说明"路径重叠"不会带来负数惩罚。
```

## 3. 解题思路

### 3.1 暴力思路

枚举三人的全部路径并取并集权值最大：每人的可行路径数约为 $3^{n-1}$ 级别，两两组合就是 $9^{n-1}$，$n = 1000$ 时完全不可能。

必须利用**移动规则的结构**把三人拆开。

### 3.2 核心观察：三条路径分别被锁死在三个区域

![三条路径的可行区域：主角只能走对角线，另两位分别被限制在上三角与下三角](images/bw144_q4_three_paths.svg)

**观察一（第一位只能走主对角线）**：他从 $(0,0)$ 出发，恰好走 $n-1$ 步到 $(n-1,n-1)$。把 $i+j$ 当作势能：初始为 $0$，目标为 $2n-2$，总增量正好是 $2(n-1)$。而三种移动对 $i+j$ 的增量分别是 $2$（$(i+1,j+1)$）、$1$（另两种），$n-1$ 步的最大总增量是 $2(n-1)$，恰好等于所需。所以**每一步都必须是 $(i+1,j+1)$**，路径被唯一确定为主对角线

$$(0,0) \to (1,1) \to \cdots \to (n-1,n-1).$$

**观察二（第二位被限制在 $j \ge i$）**：他每步都让行号加 $1$，且列号变化 $\in\{-1,0,+1\}$，所以

$$(j - i) \text{ 的变化量} \in \{-2,-1,0\},$$

即 $j - i$ **单调不增**。起点 $(0,n-1)$ 处 $j - i = n-1$，终点 $(n-1,n-1)$ 处 $j-i = 0$，因此他经过的每个格子都满足 $j \ge i$。

**观察三（第三位被限制在 $i \ge j$）**：对称地，他每步让列号加 $1$、行号变化 $\in\{-1,0,+1\}$，故 $i - j$ 单调不增，从 $n-1$ 降到 $0$，故经过的每个格子都满足 $i \ge j$。

**观察四（三人的交集只在主对角线）**：由观察二、三，第二位的格子满足 $j \ge i$、第三位满足 $i \ge j$，两人的公共格子必满足 $i = j$，即主对角线；而主对角线被第一位**全部**收走了。于是三人路径的并集可以**无重叠地分解**为

$$\underbrace{\{(i,i)\}}_{\text{第一位}}\ \cup\ \underbrace{\{(i,j) : j > i,\ \text{第二位经过}\}}_{\text{上三角}}\ \cup\ \underbrace{\{(i,j) : i > j,\ \text{第三位经过}\}}_{\text{下三角}} .$$

**观察五（三部分可以独立最大化）**：对角线和是常数 $D = \sum_i fruits[i][i]$；第二位的贡献只取决于上三角格子、第三位只取决于下三角格子，两者不共享任何格子，因此可以**分别**求最优再相加：

$$\text{ans} = D + \max_{\text{第二位路径}} \sum_{j > i} fruits[i][j] + \max_{\text{第三位路径}} \sum_{i > j} fruits[i][j] .$$

**观察六（DP 结构）**：以第二位为例，行号每步 $+1$，所以可以按行递推。设 $dp[i][j]$ 为"走完前 $i$ 行、第 $i$ 行停在第 $j$ 列"时能收集到的上三角水果最大值：

$$dp[i][j] = \max\big(dp[i-1][j-1],\ dp[i-1][j],\ dp[i-1][j+1]\big) + v(i,j), \qquad v(i,j) = \begin{cases} fruits[i][j], & j > i \\ 0, & j \le i \end{cases}$$

初值 $dp[0][n-1] = fruits[0][n-1]$（其余 $-\infty$），答案取 $dp[n-1][n-1]$。

**观察七（第三位复用同一段代码）**：把网格转置（$g'(i,j) = g(j,i)$）后，第三位的移动集合恰好变成第二位的移动集合（列 $+1$ 变行 $+1$，行 $\pm1$ 变列 $\pm1$），起点 $(n-1,0)$ 变成 $(0,n-1)$，终点不变，且"下三角 $i > j$"变成"上三角 $j > i$"。所以同一段 DP 只要换一个取值方向即可。

### 3.3 算法流程

![算法流程：对角线求和 + 两次对称的逐行 DP](images/bw144_q4_dp_flow.svg)

```text
1. D = sum(fruits[i][i])                     # 第一位固定走对角线
2. F(tr):                                     # tr=False 算第二位，tr=True 算第三位
3.     dp[*] = -inf;  dp[n-1] = 起点格子的值（tr ? fruits[n-1][0] : fruits[0][n-1]）
4.     for i = 1 .. n-1:
5.         ndp[*] = -inf
6.         for j = 0 .. n-1:
7.             best = max(dp[j-1], dp[j], dp[j+1])     # 越界视为 -inf
8.             if best == -inf: continue
9.             ndp[j] = best + (j > i ? (tr ? fruits[j][i] : fruits[i][j]) : 0)
10.        dp = ndp
11.    return dp[n-1]
12. 返回 D + F(false) + F(true)
```

时间 $O(n^2)$，空间 $O(n)$（滚动两行）。

### 3.4 示例演算

![示例 1 的两位小朋友的 DP 演算](images/bw144_q4_example_walkthrough.svg)

示例 1 的网格：

```text
      j=0   j=1   j=2   j=3
i=0    1     2     3     4
i=1    5     6     8     7
i=2    9    10    11    12
i=3   13    14    15    16
```

**第一位**：走对角线，$D = 1 + 6 + 11 + 16 = 34$。

**第二位**（只统计 $j > i$ 的格子）：从上往下逐行 DP，$v(i,j) = fruits[i][j]$ 当 $j>i$，否则 $0$。

| $i$ | $dp[i][0]$ | $dp[i][1]$ | $dp[i][2]$ | $dp[i][3]$ |
|-----|-----------|-----------|-----------|-----------|
| 0 | $-\infty$ | $-\infty$ | $-\infty$ | **4** |
| 1 | $-\infty$ | $-\infty$ | 12 | 11 |
| 2 | $-\infty$ | 12 | 12 | **24** |
| 3 | 12 | 12 | 24 | **24** |

以 $dp[1][2] = 12$ 为例：它只能从 $dp[0][3] = 4$ 转移（列 $3 \to 2$），再加上 $v(1,2) = fruits[1][2] = 8$，得 $12$。最终 $dp[3][3] = 24$（其余列的值更小，且都没有到达终点，不能取），对应路径 $(0,3) \to (1,2) \to (2,3) \to (3,3)$，收 $4 + 8 + 12 = 24$。

**第三位**（只统计 $i > j$ 的格子）：对称地得到 $42$，对应路径 $(3,0) \to (3,1) \to (3,2) \to (3,3)$，收 $13 + 14 + 15 = 42$。

总计 $34 + 24 + 42 = 100$，与示例输出一致。

## 4. 算法细节

1. **对角线的处理**：第一位收走整条主对角线，所以另外两位在 $i = j$ 的格子上**必须记 0**（水果已被收走），而不是跳过该格子——路径仍可以经过对角线（例如 $(3,3)$ 终点）。
2. **不可达状态用 $-\infty$**：$dp[0][j]$ 只有 $j = n-1$ 可达，其余是 $-\infty$；转移时若三个前驱都不可达就跳过，避免把 $-\infty$ 加上一个正值变成可用的错误状态。
3. **列的边界**：$j-1$ 可能为 $-1$、$j+1$ 可能为 $n$，必须判越界。
4. **终点唯一**：第二位必须落在 $(n-1,n-1)$，所以答案是 $dp[n-1][n-1]$，不能取最后一行的最大值（其他列表示"没到终点"，不合法）。
5. **转置复用**：`F(tr)` 里取值用 `tr ? fruits[j][i] : fruits[i][j]`，起点用 `tr ? fruits[n-1][0] : fruits[0][n-1]`，其余逻辑完全一致，避免复制一遍 DP。
6. **数值范围**：每格最多 $1000$，路径最多 $n$ 格，总和不超过 $10^6 \cdot 1000$ 中的实际可达值（$\le n^2 \times 1000 = 10^9$），`int` 勉强够但 `long long` 更安全；Python 无此问题。
7. **滚动数组**：每行只依赖上一行，故只需两个长度 $n$ 的数组，空间从 $O(n^2)$ 降到 $O(n)$。
8. **`n = 2` 的特例**：对角线 $2$ 格，第二位只有 $(0,1) \to (1,1)$，第三位只有 $(1,0) \to (1,1)$，DP 自然给出结果，无需特判。

## 5. 正确性证明

**引理 1（第一位路径唯一）**：从 $(0,0)$ 出发、走 $n-1$ 步、按第一位规则到达 $(n-1,n-1)$ 的路径只有主对角线一条。

**证明**：设第 $k$ 步后位置为 $(i_k, j_k)$，令 $s_k = i_k + j_k$。三种移动使 $s$ 分别增加 $2, 1, 1$，故每步增量 $\le 2$，走 $n-1$ 步后

$$s_{n-1} \le s_0 + 2(n-1) = 2n - 2 .$$

而终点要求 $s_{n-1} = (n-1) + (n-1) = 2n-2$，取等号，说明每一步的增量都必须是 $2$，即每步都是 $(i+1,j+1)$。于是 $i_k = j_k = k$，路径唯一。∎

**引理 2（区域限制）**：第二位经过的所有格子满足 $j \ge i$；第三位经过的所有格子满足 $i \ge j$。

**证明**：对第二位，设第 $k$ 步位置为 $(i_k,j_k)$，则 $i_k = k$，且 $j_{k+1} - j_k \in \{-1,0,1\}$，于是

$$(j_{k+1} - i_{k+1}) - (j_k - i_k) = (j_{k+1} - j_k) - 1 \in \{-2,-1,0\} \le 0,$$

即 $j - i$ 单调不增。又 $j_0 - i_0 = n-1$、$j_{n-1} - i_{n-1} = 0$，故对任意 $k$ 有 $j_k - i_k \ge 0$（若某步降为负数，之后只能继续减小，无法回到 $0$）。第三位同理（把行列互换）。∎

**引理 3（并集可无重叠分解）**：三人经过的格子集合的并集，其水果总和等于

$$\sum_{i} fruits[i][i] + \sum_{\substack{(i,j)\ \text{第二位经过}\\ j > i}} fruits[i][j] + \sum_{\substack{(i,j)\ \text{第三位经过}\\ i > j}} fruits[i][j] .$$

**证明**：由引理 2，第二位只在 $\{j \ge i\}$ 内、第三位只在 $\{i \ge j\}$ 内活动，两者的公共区域是 $\{i = j\}$，即主对角线；而由引理 1，第一位恰好经过整条主对角线，故对角线上每个格子都被第一位收走。于是三个集合可划分为"对角线（第一位）"、"严格上三角（第二位）"、"严格下三角（第三位）"三块，互不相交，且每块的水果只在对应的小朋友第一次进入时被收走一次。∎

**引理 4（DP 最优子结构）**：设 $dp[i][j]$ 表示第二位走完前 $i$ 行、第 $i$ 行停在第 $j$ 列时，所能收集到的严格上三角水果的最大值。则

$$dp[i][j] = \max_{j' \in \{j-1,j,j+1\}} dp[i-1][j'] + v(i,j)$$

（越界的前驱视为 $-\infty$），且该递推给出的正是最优值。

**证明**：第二位第 $i$ 行的位置只能是第 $i-1$ 行位置的列号 $\pm 1$ 或不变（这恰是他的三种移动），所以任何到达 $(i,j)$ 的路径，其前缀必是到达 $(i-1,j')$（$j' \in \{j-1,j,j+1\}$）的某条路径；反过来任意前缀都可延伸一步到 $(i,j)$。而 $(i,j)$ 处的贡献固定为 $v(i,j)$（$j>i$ 时收水果，否则已被第一位收走、记 0），与路径无关。故最优值等于"最优前缀 $+$ 当前格贡献"，对三种前驱取最大即可。这是标准的最优子结构论证。∎

**引理 5（独立最大化合法）**：第二位的最大上三角贡献与第三位的最大下三角贡献可以在同一局中同时实现。

**证明**：两人各自的路径选择互不影响——他们经过的格子分别在严格上三角与严格下三角，而每位小朋友的走法只受自身规则约束，与另一人的位置无关；被对方"抢先收走"的情况不会发生（两人的格子集合不交）。因此分别取各自最优路径即可。∎

**定理**：算法返回的值为三人能收集的水果数目最大值。

**证明**：由引理 3，任何一局游戏的总收获都等于"对角线和 $+$ 第二位在严格上三角的收获 $+$ 第三位在严格下三角的收获"；由引理 4，DP 对固定的行/列给出对应区域内的最大值，故任何一局的总收获不超过 $D + \text{DP}_2 + \text{DP}_3$（算法的输出）；由引理 4 与引理 5，取 DP 对应的两条路径即可达到该上界。所以算法输出既是上界又可取到，即为最大值。∎

## 6. 复杂度分析

- **对角线和**：$O(n)$。
- **两次 DP**：每次 $n-1$ 行、每行 $n$ 列、每格 $3$ 个前驱，共 $O(n^2)$；$n = 1000$ 时约 $3 \times 10^6$ 次比较，非常快。
- **总时间**：$O(n^2)$。
- **空间**：滚动数组两个长度 $n$ 的数组 $O(n)$（输入网格本身 $O(n^2)$ 不计入）；不递归。若不需要滚动，二维 DP 是 $O(n^2)$ 空间，也能接受但没必要。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maxCollectedFruits(vector<vector<int>>& fruits) {
        int n = fruits.size();
        long long diag = 0;
        for (int i = 0; i < n; i++) diag += fruits[i][i];   // 第一位小朋友只能走主对角线
        return (int)(diag + run(fruits, false) + run(fruits, true));
    }

private:
    // 从 (0, n-1) 出发、每步行号 +1、列号 -1/0/+1，恰好 n-1 步到 (n-1, n-1)
    // tr = false：第二位小朋友（只统计 j > i 的格子）；tr = true：在转置网格上跑，即第三位小朋友
    long long run(vector<vector<int>>& g, bool tr) {
        int n = g.size();
        const long long NEG = -(long long)1e18;
        vector<long long> dp(n, NEG), ndp(n, NEG);
        dp[n - 1] = tr ? g[n - 1][0] : g[0][n - 1];
        for (int i = 1; i < n; i++) {
            fill(ndp.begin(), ndp.end(), NEG);
            for (int j = 0; j < n; j++) {
                long long best = NEG;
                for (int pj = j - 1; pj <= j + 1; pj++)
                    if (pj >= 0 && pj < n && dp[pj] > best) best = dp[pj];
                if (best == NEG) continue;
                int val = (j > i) ? (tr ? g[j][i] : g[i][j]) : 0;
                ndp[j] = best + val;
            }
            dp.swap(ndp);
        }
        return dp[n - 1];
    }
};
```

### Python

```python
class Solution:
    def maxCollectedFruits(self, fruits: list) -> int:
        n = len(fruits)

        def run(tr: bool) -> int:
            # 从 (0, n-1) 出发，每步行号 +1、列号 -1/0/+1，恰好 n-1 步到 (n-1, n-1)
            # tr=True 时在转置网格上跑，等价于从左下角出发的第三位小朋友
            NEG = -1 << 60
            dp = [NEG] * (n + 1)
            dp[n - 1] = fruits[n - 1][0] if tr else fruits[0][n - 1]
            for i in range(1, n):
                ndp = [NEG] * (n + 1)
                for j in range(n):
                    best = NEG
                    for pj in (j - 1, j, j + 1):
                        if 0 <= pj < n and dp[pj] > best:
                            best = dp[pj]
                    if best == NEG:
                        continue
                    inside = (j > i)                    # 对角线及另一侧的水果已由对角路径收走
                    val = (fruits[i][j] if not tr else fruits[j][i]) if inside else 0
                    ndp[j] = best + val
                dp = ndp
            return dp[n - 1]

        diag = sum(fruits[i][i] for i in range(n))
        return diag + run(False) + run(True)
```

## 8. 边界情况与易错点

1. **第一位不是"可以选择"，而是"被迫"走对角线**：若按三选一的 DP 处理第一位，状态量会膨胀到 $O(n^3)$ 且容易写错；先证明路径唯一，问题立刻降维。
2. **对角格子必须记 0 而不是跳过**：路径可以经过对角线（尤其终点 $(n-1,n-1)$），只是水果已经被第一位收走。若把对角格子当成"不可进入"，就会漏掉所有合法路径。
3. **第二位不能进入下三角**：若 DP 允许 $j < i$ 的转移并计入水果，就会算出超过真实最优的值（那些格子第二位根本到不了）。
4. **终点必须取 $dp[n-1][n-1]$**：取最后一行的最大值是错的，因为其他人可能停在错误的列上（例如停在 $(n-1, n-2)$ 并未到达终点，不合法）。
5. **$-\infty$ 的加法**：不可达状态不能参与"加正值"的运算，否则 $-\infty + 1000$ 仍是个很大的负数，但如果用 `INT_MIN` 再 `+` 就会溢出成正值（UB）。用 `-1e18` 并先判断再相加。
6. **`n = 2`**：第二位只能 $(0,1)\to(1,1)$、第三位只能 $(1,0)\to(1,1)$，DP 无需特判即可正确；示例 2 正是这种情况（答案 4）。
7. **水果为 0 的格子**：不影响正确性，但说明"路径可以随便走也能收 0"，不会带来负数惩罚。
8. **转置实现的下标**：`tr=True` 时读取的是 `fruits[j][i]`（转置网格的 $(i,j)$），起点是 `fruits[n-1][0]`；写成 `fruits[i][j]` 会让第三位退化成第二位，答案偏小。
9. **`int` 与 `long long`**：每条路径只有 $n$ 个格子、每格 $\le 1000$，三部分之和不超过 $3 	imes 10^6$，`int` 足够；代码里用 `long long` 累加只是为了避免中间量（如 `-1e18` 哨兵）比较时的类型混用，最终答案能安全放回 `int`。
