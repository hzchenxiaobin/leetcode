# LeetCode 统计最大组的数目 题解

## 1. 题目概述

- **标题 / 题号**：统计最大组的数目（#1399，easy）
- **链接**：https://leetcode.cn/problems/count-largest-group/
- **来源**：LeetCode 第 23 场双周赛 Q1
- **难度**：简单
- **标签**：哈希表、数学、计数

**题意**：把 $1 \sim n$ 中每个数字按**数位和**分组（数位和相同同组，例如 $14$ 与 $5$ 的数位和都是 $5$，同组）。返回**元素数量最多**的组**有多少个**并列。

**约束**：

- $1 \le n \le 10^4$

**约束解读**：数位和的取值范围很小（$n \le 10^4$ 时数位和最大为 $9+9+9+9=36$），用一个桶数组即可完成全部统计。

## 2. 示例

**示例 1**

```text
输入：n = 13
输出：4
解释：按数位和分组为 [1,10]，[2,11]，[3,12]，[4,13]，[5]，[6]，[7]，[8]，[9]，
共 9 个组，其中大小为 2 的组有 4 个并列最大。
```

**示例 2**

```text
输入：n = 2
输出：2
解释：只有 [1]、[2] 两个大小为 1 的组，并列最大。
```

**边界补充**

```text
输入：n = 1
输出：1
解释：只有组 [1]，最大组唯一。
```

## 3. 解题思路

### 3.1 暴力思路

对每个 $i \in [1, n]$ 求出数位和 $s(i)$，用哈希表把 $i$ 追加进对应的组，最后遍历哈希表取组大小的最大值，再统计并列个数。这已经是 $O(n \cdot d)$（$d$ 为位数，$n \le 10^4$ 时 $d \le 4$）的线性做法，$n = 10^4$ 时毫秒级完成——本题不存在「暴力不可行」的问题，考点在于**意识到数位和的值域极小，可以放弃哈希表直接用桶数组**，以及一遍扫描时「求最大值与统计并列」合并处理的技巧。

真正会超时的写法是「先建好所有组的列表再反复扫描比较」，或者对每个数位和再回过头数一遍 $1 \sim n$ 中有多少数属于它（$O(37 \cdot n)$ 也能过，但完全没必要）。

### 3.2 核心观察：数位和值域小，分桶计数即可

![分桶模型：1到13按数位和流入各自的桶](images/bw23_q1_digit_sum_buckets.svg)

设 $cnt[s]$ 表示数位和为 $s$ 的数字个数。答案分两步：

1. 对每个 $i$ 求数位和并令 $cnt[s(i)]{+}{+}$，即**分桶计数**；
2. 找出桶大小的最大值 $best$，统计大小等于 $best$ 的桶的个数。

由于 $n \le 10^4$，$s(i) \in [1, 36]$（$n=10^4$ 本身数位和为 $1$，最大的数位和出现在 $9999$，为 $36$），开一个长度 $40$ 的数组就够，连哈希函数都省了。

求一个数 $x$ 的数位和只需不断「取余取整」：

```text
while x > 0: s += x % 10; x /= 10
```

### 3.3 算法流程

```text
1. cnt[0..39] 清零
2. for i = 1..n:
       s = i 的数位和（%10 / 10 循环）
       cnt[s] += 1
3. best = 0, ans = 0
4. for s = 1..36:                 # 跳过空桶 cnt[s] = 0
       若 cnt[s] > best：best = cnt[s], ans = 1     # 出现更大组，重置
       否则若 cnt[s] == best：ans += 1              # 并列最大，累加
5. 返回 ans
```

第 4 步把「求最大」与「计并列」合并成一趟：遇到更大的桶时重置计数为 $1$，遇到与当前最大值相等的桶时计数加一，避免先扫一遍求 $\max$ 再扫一遍统计。

### 3.4 示例演算

![示例演算：n=13 的九个组与并列计数](images/bw23_q1_example_walkthrough.svg)

以 $n = 13$ 为例，数位和分组与桶大小如下：

| 数位和 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 | 9 |
|--------|---|---|---|---|---|---|---|---|---|
| 成员 | 1,10 | 2,11 | 3,12 | 4,13 | 5 | 6 | 7 | 8 | 9 |
| 大小 | 2 | 2 | 2 | 2 | 1 | 1 | 1 | 1 | 1 |

扫描桶：$best$ 从 $0$ 升到 $2$（数位和 $1$ 时重置 $ans=1$），数位和 $2,3,4$ 与 $best$ 并列，$ans$ 累加到 $4$；数位和 $5 \sim 9$ 的桶大小为 $1 < 2$ 不影响答案。最终返回 $4$。

## 4. 算法细节

1. **桶的大小**：$n \le 10^4$，四位数 $9999$ 的数位和为 $36$ 最大，开 $40$ 即可（含 $s=0$ 冗余位，循环时跳过空桶）。
2. **求和用取余循环而非字符串**：`x % 10` 取最低位、`x /= 10` 去掉最低位，$4$ 次以内结束；转字符串再逐字符减 `'0'` 也对，但多一次临时对象。
3. **合并「求最大 + 计并列」**：见 §3.3 第 4 步。注意必须先判断「严格大于」再判断「等于」，且初始 $best = 0$ 时要跳过空桶，否则空桶会被误判为并列。
4. **为什么数位和从 1 开始**：$i \ge 1$ 保证至少有一位非零，数位和 $\ge 1$，桶 $0$ 永远为空，可安全跳过。

## 5. 正确性证明

**引理 1（数位和的值域）**：$1 \le i \le n \le 10^4$ 时，$s(i) \in [1, 36]$。

**证明**：$s(i)$ 关于各位数字单调（每一位的贡献独立且非负）。$i \le 10^4$：若 $i \le 9999$，则 $i$ 至多四位、每位至多 $9$，数位和 $\le 36$，且最大值在 $9999$ 处取得；$i = 10^4$ 时数位和为 $1$。数位和非零因 $i \ge 1$。故 $s(i) \in [1, 36]$，长度 $40$ 的桶数组覆盖全部可能取值。∎

**引理 2（分桶的完备性）**：$cnt[s] = \left|\{ i \in [1,n] : s(i) = s \}\right|$ 恰为「数位和为 $s$ 的组」的大小，且每个 $i$ 恰被计入一个桶。

**证明**：数位和函数 $s$ 是 $[1,n] \to [1,36]$ 的确定函数，$i$ 按函数值唯一落入桶 $s(i)$；计数器每处理一个 $i$ 恰自增一次，无遗漏无重复。∎

**定理**：算法返回值为 $\left|\{ s : cnt[s] = \max_{t} cnt[t] \}\right|$，即元素数量最多的组的个数。

**证明**：由引理 2，组大小恰为桶计数。算法对桶扫描一遍维护不变式：「$best$ 等于已扫描桶的最大值，$ans$ 等于已扫描桶中等于 $best$ 的桶数」。归纳：扫描新桶 $c$ 时，若 $c > best$，则已扫描桶的最大值更新为 $c$ 且此前无桶与之并列，$best \gets c$、$ans \gets 1$ 维持不变式；若 $c = best$，并列数加一；若 $c < best$，两者均不变。由引理 1，扫描覆盖所有非空桶，终止时 $best$ 为全局最大组大小、$ans$ 为并列个数。∎

## 6. 复杂度分析

- **时间**：$O(n \cdot d + V)$，$d \le 4$ 为最多位数，$V = 40$ 为桶数。主循环每个 $i$ 做 $d$ 次取余；$n = 10^4$ 时约 $4 \times 10^4$ 次基本操作。
- **空间**：$O(V)$，桶数组固定 $40$，与 $n$ 无关。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int countLargestGroup(int n) {
        int cnt[40] = {0};                       // 数位和最大 36，开 40 足够
        for (int i = 1; i <= n; ++i) {
            int s = 0;
            for (int x = i; x > 0; x /= 10) s += x % 10;
            ++cnt[s];                            // 按数位和分桶
        }
        int best = 0, ans = 0;
        for (int c : cnt) {
            if (c == 0) continue;
            if (c > best) { best = c; ans = 1; }  // 出现更大的组，重置计数
            else if (c == best) ++ans;           // 并列最大，累加
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def countLargestGroup(self, n: int) -> int:
        cnt = {}
        for i in range(1, n + 1):
            s = sum(int(ch) for ch in str(i))    # 数位和
            cnt[s] = cnt.get(s, 0) + 1           # 按数位和分桶
        best = max(cnt.values())
        return sum(1 for v in cnt.values() if v == best)
```

> 💡 两份代码均通过官方示例（`4`、`2`）与 $n=1$ 边界，并与独立实现的数位和分组暴力对拍 $3000$ 组随机 $n \in [1, 10^4]$，`mismatch = 0`。

## 8. 边界情况与易错点

1. **$n = 1$**：只有桶 $1$ 大小为 $1$，返回 $1$；不要把答案初始化成 $0$ 后忘记空桶跳过逻辑。
2. **空桶误判**：`best` 初始为 $0$ 时，若不跳过 `cnt[s] == 0`，第一个空桶会与 `best=0` 「相等」而把 `ans` 加一，得到错误答案。C++ 版用 `if (c == 0) continue;` 显式跳过。
3. **桶数组大小**：数位和最大 $36$，开 $10$ 或 $37$ 会越界/漏桶，开 $40$ 留冗余最稳。
4. **数位和求法**：`x > 0` 的循环对 $i \ge 1$ 一定至少执行一次，无需 `do-while`；若误写成 `while (x > 10)` 会漏掉最高位。
5. **「最大组」的语义**：题目问的是「并列最大的组**有几个**」，不是组的大小，也不是组内元素个数。返回的是计数。
6. **不必去重排序**：组内元素天然互不相同（$i$ 只出现一次），桶计数直接就是组大小。
