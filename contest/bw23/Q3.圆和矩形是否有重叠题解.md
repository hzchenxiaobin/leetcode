# LeetCode 圆和矩形是否有重叠 题解

## 1. 题目概述

- **标题 / 题号**：圆和矩形是否有重叠（#1401，medium）
- **链接**：https://leetcode.cn/problems/circle-and-rectangle-overlapping/
- **来源**：LeetCode 第 23 场双周赛 Q3
- **难度**：中等
- **标签**：几何、数学

**题意**：给定圆（半径 $radius$，圆心 $(xCenter, yCenter)$）与**边平行于坐标轴**的矩形（左下角 $(x_1, y_1)$，右上角 $(x_2, y_2)$），判断二者是否有公共点。圆与矩形都按**闭区域**处理——相切（恰好一个公共点）也算重叠。

**约束**：

- $1 \le radius \le 2000$
- $-10^4 \le xCenter, yCenter \le 10^4$
- $-10^4 \le x_1 < x_2 \le 10^4$，$-10^4 \le y_1 < y_2 \le 10^4$

**约束解读**：坐标与半径都是绝对值不超过 $10^4$ 的整数，全部运算可用**整数**完成，比较距离平方即可，完全不需要开方与浮点误差处理。

## 2. 示例

**示例 1**

```text
输入：radius = 1, xCenter = 0, yCenter = 0, x1 = 1, y1 = -1, x2 = 3, y2 = 1
输出：true
解释：圆与矩形有公共点 (1, 0)——恰好相切，闭区域下算重叠。
```

**示例 2**

```text
输入：radius = 1, xCenter = 1, yCenter = 1, x1 = 1, y1 = -3, x2 = 2, y2 = -1
输出：false
解释：圆心到矩形最近点 (1, -1) 的距离为 2 > 1。
```

**示例 3**

```text
输入：radius = 1, xCenter = 0, yCenter = 0, x1 = -1, y1 = 0, x2 = 0, y2 = 1
输出：true
解释：圆心 (0,0) 本身就在矩形边界上，公共点存在。
```

## 3. 解题思路

### 3.1 暴力思路

在圆与矩形的包围盒里**逐个整数点**判断「既在矩形内又在圆内」。由于本题全部输入是整数，最近点必为整点（见下），这个暴力在数学上其实是精确的——但范围 $10^4$ 量级下最坏要扫 $2 \times 10^8$ 个点，不可行，而且它把「区域相交」退化成了「离散点搜索」，思路本身就跑偏了。正确方向是把「有公共点」翻译成一个**距离不等式**。

### 3.2 核心观察：重叠 ⟺ 圆心到矩形的距离 ≤ 半径

![核心观察：圆心逐维 clamp 到矩形得到最近点，三类位置统一处理](images/bw23_q3_clamp_model.svg)

圆是**闭圆盘** $\{(x,y) : (x-x_c)^2 + (y-y_c)^2 \le r^2\}$，矩形是**闭区域** $[x_1, x_2] \times [y_1, y_2]$。二者有公共点，等价于矩形上存在一点到圆心的距离 $\le r$，即

$$\min_{(x,y) \in \text{矩形}} \sqrt{(x-x_c)^2 + (y-y_c)^2} \le r \quad\Longleftrightarrow\quad \min_{(x,y)} \big[(x-x_c)^2 + (y-y_c)^2\big] \le r^2 .$$

矩形上离圆心最近的点可以**逐维独立**求出：

$$n_x = \mathrm{clamp}(x_c,\ x_1,\ x_2), \qquad n_y = \mathrm{clamp}(y_c,\ y_1,\ y_2),$$

即把 $x_c$ 夹进 $[x_1, x_2]$、把 $y_c$ 夹进 $[y_1, y_2]$。这一步把圆心相对矩形的三类位置统一成一种写法：

1. **圆心在矩形内**：clamp 后 $n_x = x_c$、$n_y = y_c$，距离为 $0$，直接重叠；
2. **圆心在左/右/上/下「边带」**：只有一个维度被夹住，最近点在矩形的一条边上；
3. **圆心在四个「角域」**：两个维度都被夹住，最近点是矩形的一个**角**。

### 3.3 算法流程

```text
1. nx = clamp(xCenter, x1, x2)     # min(max(xCenter, x1), x2)
2. ny = clamp(yCenter, y1, y2)
3. dx = xCenter − nx, dy = yCenter − ny
4. 返回 dx² + dy² ≤ radius²
```

分类讨论的写法（圆心在矩形内 → 真；在边带 → 单维距离；在角域 → 四角取最近）与 clamp 写法完全等价，clamp 版四行搞定且不易漏分支。

### 3.4 示例演算

![示例演算：三个官方示例的最近点与距离判定](images/bw23_q3_example_walkthrough.svg)

| 示例 | clamp 最近点 | $(dx, dy)$ | 距离平方 | 与 $r^2$ 比较 | 结果 |
|------|--------------|------------|----------|----------------|------|
| 1 | $(1, 0)$ | $(-1, 0)$ | $1$ | $1 \le 1$ | 重叠（相切） |
| 2 | $(1, -1)$ | $(0, 2)$ | $4$ | $4 > 1$ | 不重叠 |
| 3 | $(0, 0)$ | $(0, 0)$ | $0$ | $0 \le 1$ | 重叠（圆心在边上） |

示例 2 走的是「下边带」位置：$x_c = 1 \in [1, 2]$ 只被 $y$ 维夹住；示例 1 的圆心在「左边带」——$x_c = 0 < x_1 = 1$ 被夹到 $x_1$，而 $y_c = 0 \in [-1, 1]$ 原样保留，最近点 $(1, 0)$ 落在矩形的左边上，恰为切点。

## 4. 算法细节

1. **clamp 的写法**：`min(max(v, lo), hi)` 与 `max(min(v, hi), lo)` 等价（$lo \le hi$ 时），两序嵌套即可，无需三分支 if。
2. **比较平方距离**：$\sqrt{dx^2+dy^2} \le r$ 两边平方得 $dx^2 + dy^2 \le r^2$，$r \ge 0$ 时等价，避免浮点。
3. **溢出核算**：$|dx| \le |x_c| + |x_1| \le 2 \times 10^4$，$dx^2 + dy^2 \le 8 \times 10^8$，`int`（上限约 $2.1 \times 10^9$）勉强放得下，但贴边；用 `long long` 一步到位，不做心算杂技。
4. **相切也算重叠**：闭圆盘 + 闭矩形，不等式带等号（$\le$），别写成 $<$。
5. **圆心可以在矩形外任意方向**：clamp 天然支持 $x_c < x_1$ 与 $x_c > x_2$ 两种越界方向，无需对称特判。
6. **矩形退化**：约束保证 $x_1 < x_2$、$y_1 < y_2$，矩形有正面积；即便退化为线段/点，clamp 逻辑依旧正确。

## 5. 正确性证明

**引理 1（一维投影）**：对任意 $x \in [x_1, x_2]$ 与任意实数 $p$，有 $|x - p| \ge |n_x - p|$，其中 $n_x = \mathrm{clamp}(p, x_1, x_2)$；等号可取到。

**证明**：$|x - p|$ 是 $p$ 到 $x$ 的距离。若 $p < x_1$，则 $|x - p| = x - p \ge x_1 - p = |n_x - p|$（$n_x = x_1$）；若 $p > x_2$，同理 $|x - p| \ge p - x_2 = |n_x - p|$（$n_x = x_2$）；若 $p \in [x_1, x_2]$，则 $n_x = p$，$|x - p| \ge 0 = |n_x - p|$。三种情形都取 $x = n_x$ 时等号成立（$n_x$ 本身在区间内）。∎

**引理 2（矩形最近点）**：点 $P = (x_c, y_c)$ 到矩形 $R = [x_1,x_2] \times [y_1,y_2]$ 上各点距离的最小值在 $N = (n_x, n_y)$（两维 clamp）处取得。

**证明**：对任意 $(x, y) \in R$，

$$(x-x_c)^2 + (y-y_c)^2 \ge (n_x-x_c)^2 + (n_y-y_c)^2$$

由引理 1 分别作用在 $x$ 维与 $y$ 维（各自非负，相加保持不等号）即得；且 $N \in R$（clamp 结果落在区间内），最小值可取得。∎

**定理（判定等价）**：闭圆盘 $D$（圆心 $P$，半径 $r$）与闭矩形 $R$ 有公共点 $\iff |PN|^2 \le r^2$，其中 $N$ 为 $R$ 上离 $P$ 最近的点。

**证明**：（$\Rightarrow$）取公共点 $Q \in D \cap R$，则 $|PQ| \le r$；由引理 2，$|PN| \le |PQ| \le r$，故 $|PN|^2 \le r^2$。（$\Leftarrow$）$|PN| \le r$ 说明 $N \in D$；又 $N \in R$，故 $N$ 是公共点。∎

**推论（整数精确性）**：本题坐标全为整数时 $n_x, n_y$ 均为整数，$|PN|^2$ 与 $r^2$ 都是整数，用整数比较无任何精度损失；这也是「逐整数点扫描」暴力在本题数据下碰巧精确的原因——最小值恰在整点取得。

## 6. 复杂度分析

- **时间**：$O(1)$。两次 clamp、两次减法、两次乘法与一次比较，与输入规模无关。
- **空间**：$O(1)$。仅常数个变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool checkOverlap(int radius, int xCenter, int yCenter,
                      int x1, int y1, int x2, int y2) {
        // 圆心坐标逐维夹到矩形范围内，得到矩形上离圆心最近的点
        long long nx = max(min((long long)xCenter, (long long)x2), (long long)x1);
        long long ny = max(min((long long)yCenter, (long long)y2), (long long)y1);
        long long dx = xCenter - nx, dy = yCenter - ny;
        return dx * dx + dy * dy <= (long long)radius * radius;
    }
};
```

### Python

```python
class Solution:
    def checkOverlap(self, radius: int, xCenter: int, yCenter: int,
                     x1: int, y1: int, x2: int, y2: int) -> bool:
        # 圆心坐标逐维夹到矩形范围内，得到矩形上离圆心最近的点
        nx = min(max(xCenter, x1), x2)
        ny = min(max(yCenter, y1), y2)
        dx, dy = xCenter - nx, yCenter - ny
        return dx * dx + dy * dy <= radius * radius
```

> 💡 两份代码均通过官方示例（`true`、`false`、`true`）；另与两个独立实现（分类讨论版 + 整数点全扫描版）三向对拍——穷举小范围 $2000$ 组、随机大范围 $5000$ 组，`mismatch = 0`，且 C++ 与 Python 交叉随机 $400$ 组一致。

## 8. 边界情况与易错点

1. **相切必须返回 true**：示例 1 中距离恰为 $1 = radius$。比较用 $\le$ 而不是 $<$。
2. **圆心在矩形内部**：clamp 后距离为 $0$，自然返回 true；不要漏掉这个「距离为零」的平凡情形，也不要在分类讨论里把它当成单独分支打错。
3. **圆心在角域**：最近点是矩形某个**角**而非最近边上的垂足——分类讨论版最容易在这里写错（把「到边的距离」当成最近距离）。
4. **溢出**：$dx^2 + dy^2$ 上界 $8 \times 10^8$，`int` 险些不够稳，`long long` 一劳永逸；Python 无此问题。
5. **浮点陷阱**：任何用 `sqrt` 再比较的写法都引入浮点；本题整数比较即可精确，平方后比较是标准手法。
6. **min/max 嵌套顺序**：`clamp(v, lo, hi)` 必须保证 $lo \le hi$（题目保证 $x_1 < x_2$、$y_1 < y_2$），顺序写反（先 `min(hi)` 再 `max(lo)` 之外的花样）可能得到区间外的值。
7. **注意是闭圆盘**：若把圆理解为「圆周」，判定会变成 $r \le \mathrm{dist} \le r$ 型的奇怪条件——题面明确两者都含边界，按闭区域做。
