# LeetCode 构造 K 个回文字符串 题解

## 1. 题目概述

- **标题 / 题号**：构造 K 个回文字符串（#1400，medium）
- **链接**：https://leetcode.cn/problems/construct-k-palindrome-strings/
- **来源**：LeetCode 第 23 场双周赛 Q2
- **难度**：中等
- **标签**：贪心、哈希表、字符串、计数

**题意**：给定字符串 $s$ 与整数 $k$，判断能否**用 $s$ 的全部字符**（每个字符恰好用一次）拼出**恰好 $k$ 个非空回文串**（串与串之间不要求字典序或互异，只要求把字符划分成 $k$ 份，每份内部可重排成一个回文）。

**约束**：

- $1 \le s.length \le 10^5$
- $s$ 只含小写字母
- $1 \le k \le 10^5$

**约束解读**：$|s|$ 与 $k$ 都到 $10^5$，任何「枚举划分」的做法都不可行；必须从字符计数的奇偶性出发，得到一个 $O(|s|)$ 的判定条件。

## 2. 示例

**示例 1**

```text
输入：s = "annabelle", k = 2
输出：true
解释：可行方案如 "anna" + "elble"、"anbna" + "elle"、"anellena" + "b"。
```

**示例 2**

```text
输入：s = "leetcode", k = 3
输出：false
解释：l、t、c、o、d 各出现奇数次，e 出现 3 次也是奇数次——奇计数字符多达 6 种，
至少需要 6 个回文串才装得下这些"落单"的字符。
```

**示例 3**

```text
输入：s = "true", k = 4
输出：true
解释：四个字符各出现一次，恰好每个字符单独成串。
```

## 3. 解题思路

### 3.1 暴力思路

把 $n$ 个字符的位置划分成 $k$ 个非空部分（第二类斯特林数量级，指数爆炸），再对每部分检查「多重集能否排成回文」。$n = 10^5$ 下完全不可行；$k$ 也不允许动态规划（状态里要装下 26 个计数）。本题的关键不是搜索，而是发现判定条件只依赖**每个字符计数的奇偶性**。

### 3.2 核心观察：回文的奇偶结构

![回文的奇偶结构：字符成对出现，至多一个字符落单在中心](images/bw23_q2_palindrome_parity.svg)

回文正读反读相同，除**中心**（长度为奇数时的那一个位置）外，其余位置关于中轴对称成对——每个字符在串内**成对出现**，至多一种字符的计数为**奇数**（它占据中心）。

于是设 $m$ 为 $s$ 中计数为**奇数**的字符种数：

- **必要条件 $m \le k$**：一种字符全局计数为奇数，它在 $k$ 个串中的计数之和为奇数，必有某个串中该字符计数为奇数（奇数个奇数相加才为奇数）；每个回文串至多容纳一种奇计数字符，故 $m$ 种奇计数字符至少需要 $m$ 个串。
- **必要条件 $k \le n$**：$k$ 个非空串至少要 $k$ 个字符。

### 3.3 核心观察：两个条件合起来就充分了

![可行区间：odd ≤ k ≤ n 时整段可行](images/bw23_q2_feasible_range.svg)

惊喜之处在于 $m \le k \le n$ **不只是必要，还是充分**：只要 $k$ 落在 $[m, n]$ 内，一定能构造出 $k$ 个非空回文串。直觉是把字符拆成「单字符」与「相同字符对」两类积木——单字符是回文、字符对也是回文、往任何回文两侧对称地加一对字符仍是回文，因此串数可以在 $[m, n]$ 内自由伸缩。严格证明见 §5 的定理（分「中心+挂对」与「多拆单」两种构造覆盖整个区间）。

算法因此退化为一行判定：

```text
统计计数为奇数的字符种数 m
返回 (m ≤ k ≤ n)
```

### 3.4 示例演算

![示例演算：annabelle 的计数与两种构造](images/bw23_q2_example_walkthrough.svg)

**示例 1**（$s=$ `annabelle`，$k=2$）：$a{:}2,\ n{:}2,\ b{:}1,\ e{:}2,\ l{:}2$，$m = 1$（只有 $b$），$n = 9$，$1 \le 2 \le 9$ 成立 → `true`。构造：$b$ 作中心挂上 $(a,a),(n,n)$ 对得 `anbna`；新串拿 $(l,l)$ 作底再挂 $(e,e)$ 得 `elle`。

**示例 2**（$s=$ `leetcode`，$k=3$）：$l{:}1,\ e{:}3,\ t{:}1,\ c{:}1,\ o{:}1,\ d{:}1$，$m = 6 > 3$ → `false`。6 种奇计数字符各自需要独占一个串的中心。

**示例 3**（$s=$ `true`，$k=4$）：4 种字符各 1 次，$m = 4$，$4 \le 4 \le 4$ → `true`，唯一构造是 4 个单字符串 `t`、`r`、`u`、`e`。

**再看一个中间情形**（$s=$ `aab`，$k=3$）：$m = 1$（$b$），$n = 3$。由于 $k = 3 > \frac{n+m}{2} = 2$，构造走「多拆单」路线：$J = 2k - n = 3$ 个单字符 `a`、`a`、`b` 恰好 3 个串。

## 4. 算法细节

1. **计数用长度 26 的数组**：小写字母共 26 种，一次遍历统计，无需哈希表。
2. **奇偶判断用 `c & 1`**：计数与 1 按位与，比 `% 2` 略快且语义清晰。
3. **比较写成一个不等式链**：`odd <= k && k <= n`，注意 $n$ 是字符串长度（C++ 中 `s.size()` 返回无符号数，与 `k` 比较前转成 `int` 防止符号陷阱）。
4. **不需要真的构造**：判定条件是充要的，构造只用于证明；若题目改成「输出一组方案」，按 §5 定理证明中的两种构造即可输出。
5. **复杂度与数据规模**：$O(n + 26)$ 时间、$O(26)$ 空间，$n = 10^5$ 下轻而易举。

## 5. 正确性证明

**引理 1（回文的奇计数字符至多一种）**：多重集 $T$ 能排成回文，当且仅当 $T$ 中至多一种字符计数为奇数。

**证明**：设回文串长 $L$。位置 $i$ 与 $L+1-i$ 关于中心对称，二者字符相同；把位置按对称对 $\{i, L+1-i\}$（$i < L+1-i$）与可能的中心 $\{i\}$（$i = L+1-i$，仅 $L$ 奇数时存在）划分，每对贡献同一种字符两个，故除中心外所有字符成对出现；奇计数字符至多占中心一种。反之，若至多一种字符 $c$ 计数为奇数，把其余字符对半分到两侧、$c$（若存在）放中心，即得回文。∎

**引理 2（必要性 $m \le k$）**：设字符 $c$ 在 $s$ 中计数为奇数，被划分到 $k$ 个串中计数为 $t_1, \dots, t_k$，则 $\sum t_i$ 为奇数，故有奇数个 $t_i$ 为奇数，特别地存在 $t_i$ 为奇数——串 $i$ 中 $c$ 为奇计数字符。由引理 1，一个串中至多一种奇计数字符；而**不同的**奇计数字符不能挤在同一个串里（每个串的奇计数字符名额至多一个），故 $m$ 种奇计数字符至少占据 $m$ 个互不相同的串，$k \ge m$。再加 $k$ 个串非空共需 $\ge k$ 个字符，得 $k \le n$。∎

**定理（充分性）**：若 $m \le k \le n$，则存在构造。

**证明**：记全体字符的「单字符拆分数」为 $J$——从多重集中取出 $J$ 个字符各自单独成串，剩下 $n - J$ 个字符必须**全部成对**（同种字符一对），这要求 $J$ 与 $n$ 同奇偶且 $0 \le J \le n$；又因奇计数字符的计数是奇数，它至少贡献一个落单者，故 $J \ge m$。于是：

- $J$ 个单字符串成立后，剩余 $\frac{n-J}{2}$ 个**字符对**都是合法回文积木，且两两可合并（`cc` 与 `dd` 拼成 `cddc`），也可整体挂到任何已有串两侧（`X` 与 `cc` 拼成 `cXc`）。因此这些对可以组成 $t$ 个非空串，$t$ 取遍 $[0, \frac{n-J}{2}]$ 中任意整数（每串至少一对，多余的并进去）。

- 于是「总串数」可达区间为 $[J,\ J + \frac{n-J}{2}] = [J, \frac{n+J}{2}]$。让 $J$ 取遍与 $n$ 同奇偶的 $[m, n]$，这些区间的并集恰是 $[m, n]$：
  - $k \le \frac{n+m}{2}$ 时取 $J = m$：因 $k - m \le \frac{n-m}{2}$，中心构造（$m$ 个奇字符各占一串，把 $\frac{n-m}{2}$ 个对中拿出 $k-m$ 个给新串打底、其余任意分配）给出 $k$ 个串；
  - $k > \frac{n+m}{2}$ 时取 $J = 2k - n$：由 $k \le n$ 得 $J \le n$，由 $k > \frac{n+m}{2}$ 得 $J > m$，且 $J \equiv n \pmod 2$。取 $J$ 个单字符、剩下 $\frac{n-J}{2} = n - k$ 个对每对自成一串，总数 $J + (n-k) = k$。∎

**推论（判定条件）**：$s$ 可拼成 $k$ 个非空回文串 $\iff m \le k \le n$，其中 $m$ 为奇计数字符种数、$n = |s|$。

**证明**：必要由引理 2、充分由定理，二者合并即得。∎

## 6. 复杂度分析

- **时间**：$O(n + 26)$。一遍统计计数 $O(n)$；统计奇数种数与比较 $O(26)$。$n = 10^5$ 下线性扫一遍即可。
- **空间**：$O(26)$。仅一个计数数组（哈希表亦可，但数组更快）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool canConstruct(string s, int k) {
        int cnt[26] = {0};
        for (char c : s) ++cnt[c - 'a'];
        int odd = 0;
        for (int c : cnt) odd += c & 1;          // 奇数次字符的种类数
        return odd <= k && k <= (int)s.size();   // 可行 ⇔ odd ≤ k ≤ n
    }
};
```

### Python

```python
class Solution:
    def canConstruct(self, s: str, k: int) -> bool:
        cnt = [0] * 26
        for ch in s:
            cnt[ord(ch) - 97] += 1
        odd = sum(c & 1 for c in cnt)            # 奇数次字符的种类数
        return odd <= k <= len(s)                # 可行 ⇔ odd ≤ k ≤ n
```

> 💡 两份代码均通过官方示例（`true`、`false`、`true`）；另与「枚举下标集合划分成 $k$ 部分并逐部检查可回文性」的暴力对拍 $2500$ 组随机小串（含 `aaa…`、`abab…`、全字母表等定向用例），`mismatch = 0`。

## 8. 边界情况与易错点

1. **$k > n$ 必假**：哪怕全部单字符成串也不够 $k$ 个。先判这一条可以提前剪枝，但注意还有 $m \le k$ 这一半，两个条件缺一不可。
2. **$m > k$ 必假**：如示例 2，$m = 6 > k = 3$。别把「奇计数字符」与「出现过的字符种数」搞混——后者是 $s$ 的去重大小，上限 26，与 $k$ 没有必然关系。
3. **$k = n$**：全部拆散单字符串，此时必须有 $m \le n$ 恒成立（奇计数字符种数不会超过总字符数），恒可行。
4. **$m = 0$**：所有字符成对。$k = 1$ 时把所有对拼成一个大回文即可；$k \ge 2$ 时分对。
5. **C++ 无符号比较陷阱**：`s.size()` 是 `size_t`，直接写 `k <= s.size()` 时 `k` 会提升为无符号数，虽本题 $k \ge 1$ 不出错，养成 `(int)s.size()` 或用 `int n = s.size()` 的习惯更稳。
6. **$k \le 0$ 不会出现**（约束 $k \ge 1$），无需特判。
7. **想复杂了的方向**：试图贪心地真的分配字符、或讨论「每个回文串该多长」——都不需要，奇偶计数给出的是充要条件。

**延伸思考**：本题的 $m$ 其实是「最少需要几个回文串」——$m$ 种奇计数字符决定了下界；而「最多」是 $n$（全拆散）。于是自然产生一个变体：**给定 $k$，求方案数**（把多重集划分成 $k$ 个可回文部分的数量），需要带奇偶约束的生成函数/DP，难度陡增。另一个变体是限制 $k$ 个串**长度相同**：此时需要讨论 $n$ 不被 $k$ 整除（无解）以及每串内部的奇偶分配，条件会变成 $\lceil m' \rceil$ 型的逐串约束。
