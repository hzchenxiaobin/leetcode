# LeetCode 统计坏数对的数目 题解

## 1. 题目概述

- **标题 / 题号**：统计坏数对的数目（#2364，medium）
- **链接**：https://leetcode.cn/problems/count-number-of-bad-pairs/
- **来源**：LeetCode 第 84 场双周赛 Q2
- **难度**：中等
- **标签**：数组、哈希表、数学、计数

**题意**：给下标从 0 开始的数组 `nums`。对 $i < j$，若 $j - i \ne \text{nums}[j] - \text{nums}[i]$，称 $(i, j)$ 是一个**坏数对**。返回坏数对总数。

**约束**：

- $1 \le \text{nums.length} \le 10^5$
- $1 \le \text{nums}[i] \le 10^9$

## 2. 示例

**示例 1**

```text
输入：nums = [4,1,3,3]
输出：5
解释：除 (1,3) 外其余 5 对全部是坏数对：
      (0,1): 1-0=1 ≠ 1-4=-3；(0,2): 2 ≠ -1；(0,3): 3 ≠ -1；
      (1,2): 1 ≠ 2；(2,3): 1 ≠ 0。
```

**示例 2**

```text
输入：nums = [1,2,3,4,5]
输出：0
解释：nums[i] = i+1 严格满足 nums[j]-nums[i] = j-i，全部是好数对。
```

**边界补充**

```text
输入：nums = [5,5,5,5]  输出：6      # 全相等：任何 j-i ≠ 0，C(4,2) 对全坏
输入：nums = [7]        输出：0      # 单元素无对
```

## 3. 解题思路

### 3.1 暴力思路

双重循环枚举全部 $\binom{n}{2} \approx 5 \times 10^9$ 对（$n = 10^5$），逐对判定——$O(n^2)$ 必然超时。坏数对直接判不好下手，因为它是一个**不等式**；经典套路是**取补集**：坏数对 = 总对数 − 好数对，而好数对是个等式条件，等式条件通常可以「变形 + 分组计数」。

### 3.2 核心观察：移项变形后，好对 ⟺ 同组配对

![变形与互补计数](images/bw84_q2_transform_model.svg)

对判定式做移项：

$$j - i \ne \text{nums}[j] - \text{nums}[i] \iff \text{nums}[i] - i \ne \text{nums}[j] - j$$

推导分两步：先把 $\text{nums}$ 项移到同一边得 $j - \text{nums}[j] \ne i - \text{nums}[i]$，再两边同乘 $-1$（相等关系不改变）得 $\text{nums}[i] - i \ne \text{nums}[j] - j$。

于是定义**关键值** $\delta(i) = \text{nums}[i] - i$：好数对 $(i, j)$ 就是「$\delta$ 值相等的两个下标配对」。把全部下标按 $\delta$ 值分组，组内两两组合都是好对：

$$\text{好对} = \sum_{v} \binom{c_v}{2}, \qquad \text{坏对} = \binom{n}{2} - \text{好对}$$

其中 $c_v$ 是 $\delta$ 值等于 $v$ 的下标个数。一次线性扫描 + 哈希计数即可，无需真的枚举任何数对。

### 3.3 算法流程

```text
cnt = 空哈希表, good = 0
遍历 i = 0..n-1：
    key = nums[i] - i
    good += cnt[key]          # 此前所有同 key 的下标都与 i 构成好对
    cnt[key] += 1
返回 n*(n-1)/2 - good
```

`good += cnt[key]` 发生在自增之前，等价于对每组累加 $\binom{c_v}{2}$（每来一个新成员，与组内先到者两两成对）。

### 3.4 示例演算

![示例 1 演算：按差值分组](images/bw84_q2_example_walkthrough.svg)

示例 1：`nums = [4,1,3,3]`，关键值依次为 $[4, 0, 1, 0]$。分组：$4 \to 1$ 个、$1 \to 1$ 个、$0 \to 2$ 个。好对 $= \binom{1}{2} + \binom{1}{2} + \binom{2}{2} = 0 + 0 + 1 = 1$（即 $(1,3)$：$j - i = 2$、$\text{nums}[3] - \text{nums}[1] = 2$）。总对数 $\binom{4}{2} = 6$，坏对 $= 6 - 1 = 5$。

## 4. 算法细节

1. **移项方向**：变形的中间量 $j - \text{nums}[j]$ 与 $\text{nums}[i] - i$ 都是合法的分组键（同乘 $-1$ 不改变分组），任选其一即可，前后一致就行。
2. **计数顺序**：先累加 `cnt[key]` 再自增——这样每个好对恰在其**右端点**处被计入一次，免去最后再遍历哈希表算 $\binom{c_v}{2}$。
3. **键的取值范围**：$\text{nums}[i] - i \in [1 - (n-1),\ 10^9]$，有负数有 $10^9$ 量级，C++ 哈希表键用 `int` 即可（$10^9 < 2^{31} - 1$），不要用数组计数。
4. **溢出**：$\binom{n}{2} \approx 5 \times 10^9$ 超出 `int`，C++ 里 $n$ 先转 `long long` 再相乘（题目返回类型即 `long`）；`good` 本身也最坏 $5 \times 10^9$，同样 64 位。
5. **全好对的特例**：`nums[i] = i + c`（整体平移）时全部下标同组，`good = C(n,2)`，答案 0——这是检验公式对称性的快速用例。

## 5. 正确性证明

**引理（变形等价）**：对任意 $i < j$，

$$j - i = \text{nums}[j] - \text{nums}[i] \iff \text{nums}[i] - i = \text{nums}[j] - j.$$

**证明**：从左式出发：$j - i = \text{nums}[j] - \text{nums}[i] \iff j - \text{nums}[j] = i - \text{nums}[i]$（两边同时减去 $\text{nums}[j] - \text{nums}[i]$ 与 $j - i$ 再移项），再两边同乘 $-1$ 即得右式。每一步都是可逆的恒等变形，故等价成立；取否定（不等号方向不变）即坏对判定也等价。∎

**定理**：坏数对总数为 $\binom{n}{2} - \sum_v \binom{c_v}{2}$，其中 $c_v = \#\{i : \text{nums}[i] - i = v\}$。

**证明**：全部下标对 $(i, j), i < j$ 恰有 $\binom{n}{2}$ 个，按好/坏二分。由引理，好对恰为「$\delta$ 值相等的下标对」；把下标按 $\delta$ 值分到 $m$ 个组，组间下标 $\delta$ 值不同必为坏对，组内任取两下标必为好对，故好对恰为 $\sum_{v=1}^{m} \binom{c_v}{2}$。两者相减即坏对数。∎

## 6. 复杂度分析

- **时间**：$O(n)$。一次扫描，哈希表单次操作均摊 $O(1)$；分组键 $\text{nums}[i] - i$ 逐个计算无额外开销。
- **空间**：$O(n)$。哈希表至多存 $n$ 个不同键（最坏情况全部互异）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long countBadPairs(vector<int>& nums) {
        long long n = (long long)nums.size(), good = 0;
        unordered_map<int, long long> cnt;            // nums[i] - i → 出现次数
        for (int i = 0; i < n; ++i) good += cnt[nums[i] - i]++;
        return n * (n - 1) / 2 - good;                // 坏对 = 总对数 - 好对数
    }
};
```

### Python

```python
from collections import Counter


class Solution:
    def countBadPairs(self, nums: list[int]) -> int:
        good = 0
        cnt = Counter()                            # nums[i] - i → 出现次数
        for i, x in enumerate(nums):
            good += cnt[x - i]                     # 此前同组元素都与 i 构成好对
            cnt[x - i] += 1
        n = len(nums)
        return n * (n - 1) // 2 - good             # 坏对 = 总对数 - 好对数
```

> 💡 两份代码均通过官方 2 个示例与 3 个补充边界（单元素 / 全等数组 / 全好对），并与「双重循环逐对判定」的暴力对拍：C++ 2 万组、Python 2 千组（$n \le 60$），`mismatch = 0`；另通过 $n = 10^5$ 大数据（全好对 → 0；formula 用例 → 4999950000）跨语言一致校验。

## 8. 边界情况与易错点

1. **溢出是本题最大的坑**：$\binom{10^5}{2} = 4\,999\,950\,000 > 2^{31}$，C++ 中 `n * (n - 1) / 2` 的 `n` 必须是 64 位类型再相乘；写成 `int` 相乘会回绕。
2. **别把好对条件写成 $\text{nums}[i] - \text{nums}[j] = j - i$**：移项时正负号容易错，用 $\delta(i) = \text{nums}[i] - i$ 分组后自检：同组两下标 $i<j$ 满足 $\text{nums}[j] - \text{nums}[i] = \delta(j) - \delta(i) + (j - i) = j - i$ ✓。
3. **计数先加后增**：`good += cnt[key]` 必须在 `cnt[key] += 1` 之前，否则把每个元素和自己也配了对。
4. **负键**：$\text{nums}[i] - i$ 可为负（$i$ 大、$\text{nums}[i]$ 小），哈希表对负键无压力，但若改用数组/桶计数必须平移下标。
5. **单元素 / $n = 1$**：总对数为 0，答案 0，公式天然覆盖，无需特判。
6. **直接枚举坏对不可行**：$O(n^2)$ 在 $10^5$ 规模下超时，必须走「补集 + 变形 + 分组」这条路。
