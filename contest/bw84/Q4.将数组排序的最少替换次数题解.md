# LeetCode 将数组排序的最少替换次数 题解

## 1. 题目概述

- **标题 / 题号**：将数组排序的最少替换次数（#2366，hard）
- **链接**：https://leetcode.cn/problems/minimum-replacements-to-sort-the-array/
- **来源**：LeetCode 第 84 场双周赛 Q4
- **难度**：困难
- **标签**：贪心、数组、数学

**题意**：每次操作可以把数组中**任意一个元素**替换成任意两个**和等于它**的数字（拆成两段，占据原位置）。要求若干次操作后数组**非递减**，求最少操作次数。

**约束**：

- $1 \le \text{nums.length} \le 10^5$
- $1 \le \text{nums}[i] \le 10^9$

## 2. 示例

**示例 1**

```text
输入：nums = [3,9,3]
输出：2
解释：9 → 3 和 6 得 [3,3,6,3]，再 6 → 3 和 3 得 [3,3,3,3,3]。
```

**示例 2**

```text
输入：nums = [1,2,3,4,5]
输出：0
解释：已经非递减。
```

**边界补充**

```text
输入：nums = [2,10,1]        输出：10   # 尾部为 1：全部拆成 1，总段数 13，操作 13-3
输入：nums = [5,4,3,2,1]     输出：10   # 严格递减，全部拆成 1，15 段 - 5 块
输入：nums = [1]             输出：0    # 单元素天然有序
输入：nums = [1,1,1,1]       输出：0    # 非递减含相等
```

## 3. 解题思路

### 3.1 暴力思路

从左往右 DP：$f(i, \text{lo})$ 表示「把 `nums[i..n-1]` 各块拆成非递减分段、首段 $\ge \text{lo}$ 的最少操作数」，枚举 `nums[i]` 的每个非递减分段转移——状态数 $O(n \cdot V)$、转移数巨大（整数拆分数），只适合小数据对拍（本文 §7 的对拍暴力正是它）。关键难点在于**从左往右时右边的约束尚未确定**；把方向反过来——**从右往左**，右邻对当前元素的约束已经完全确定，问题立刻塌缩成每步独立的局部决策。

### 3.2 核心观察：从右往左传播「上界」，每步只做一个局部最优决策

![从右往左的上界传播](images/bw84_q4_greedy_model.svg)

- **最右元素永不拆**：拆它只会让它前面的约束更紧（拆出的每段 $\le$ 原值），不会更优。于是初始上界 $b = \text{nums}[n-1]$。
- 从右往左处理位置 $i$，设当前上界 $b$（= 右侧相邻分块的**首段**，即 `nums[i]` 的每个分段都不得超过的值）：
  - 若 $\text{nums}[i] \le b$：不拆，新上界更新为 $\text{nums}[i]$；
  - 若 $x = \text{nums}[i] > b$：必须拆。每段 $\le b$、非递减、和为 $x$，**最少段数** $m = \lceil x / b \rceil$；在 $m$ 段的前提下**尽量均分**，首段最大可达 $\lfloor x/m \rfloor$，把它作为传给左侧的新上界。

一次替换只把一个元素拆成**两个**，所以 $m$ 段需要 $m - 1$ 次替换。

### 3.3 算法流程

![拆法选择：最少段数 + 均分首段最大](images/bw84_q4_split_optimal.svg)

```text
ans = 0, bound = nums[n-1]
从 i = n-2 倒序到 0：
    x = nums[i]
    若 x <= bound：bound = x
    否则：
        m = (x + bound - 1) / bound      # 至少拆成 m 段（上取整）
        ans += m - 1                     # m 段只需 m-1 次替换
        bound = x / m                    # 均分 → 首段最大 = ⌊x/m⌋
返回 ans
```

均分的合法性：$m = \lceil x/b \rceil \Rightarrow x \le m \cdot b \Rightarrow \lfloor x/m \rfloor \le b$，即首段不会超过上界；把余数摊到右边几段（$q$ 与 $q+1$ 搭配，$q = \lfloor x/m \rfloor$）即可保持非递减。

### 3.4 示例演算

![示例 1 演算：两次一分为二得到全 3 数组](images/bw84_q4_example_walkthrough.svg)

示例 1：`bound = 3`（最右的 3 不拆）。$i = 1$：$x = 9 > 3$，$m = \lceil 9/3 \rceil = 3$，代价 $+2$，新界 $\lfloor 9/3 \rfloor = 3$。$i = 0$：$x = 3 \le 3$ 不拆。答案 2。同一路径给出方案：$9$ 经两次「一分为二」变成 $[3,3,3]$，最终 $[3,3,3,3,3]$。

## 4. 算法细节

1. **为什么「尽量均分」**：分段非递减 ⇒ 首段 $\le$ 平均值 $\le \lfloor x/m \rfloor$，均分恰好把首段顶到上界；首段越大，传给左侧的 `bound` 越宽松，后续代价单调不增（见 §5 引理 2）。
2. **为什么不能多拆几段**：段数从 $m$ 增到 $m+1$，当前代价多 1，且首段上界降为 $\lfloor x/(m+1) \rfloor$，左侧代价只会更大——两头都不划算。
3. **上取整防溢出**：C++ 中 `m = (x + bound - 1) / bound` 在 $x \le 10^9$ 时 `x + bound - 1 ≤ 2 \times 10^9`，`int` 会回绕，必须先把 `x` 转成 `long long`。
4. **答案规模**：`bound` 被压到 1 时（如全数组严格递减到 1 结尾），每个 $10^9$ 的元素要拆 $10^9$ 段，$n = 10^5$ 时答案 $\approx 10^{14}$，必须 64 位累加。
5. **最右元素不拆**：别对 `nums[n-1]` 也套拆分逻辑——它右侧没有邻居，任何拆分都白白多花操作还收紧左侧约束。

## 5. 正确性证明

把最终数列看作 $n$ 个**块** $B_0, \dots, B_{n-1}$：$B_i$ 是 `nums[i]` 经若干次拆分得到的非递减正整数分段（不拆则单段）。整个数列非递减 ⟺ 每块内部非递减**且** $B_i$ 的末段 $\le B_{i+1}$ 的首段。一次替换使某个块增加一段，故总代价 $= \sum_i (|B_i| - 1)$。

**引理 1（段数下界与首段上界）**：把 $x$ 拆成 $m$ 段非递减、末段 $\le b$ 的分段可行 ⟺ $m \ge \lceil x / b \rceil$；且可行时首段至多 $\lfloor x/m \rfloor$，该上界由「$q, \dots, q, q+1, \dots, q+1$」（$q = \lfloor x/m \rfloor$）型均分取到。

**证明**：必要性：每段 $\le$ 末段 $\le b$，故 $x \le mb$。充分性：$m \ge \lceil x/b \rceil$ 时均分型分段各段取 $q$ 或 $q+1$，最大段 $q + 1 \le b$（由 $x \le mb$ 可得 $\lceil x/m \rceil \le b$，$q + 1 = \lceil x/m \rceil$ 当 $m \nmid x$，$q = x/m \le b$ 当 $m \mid x$），且首段 $q = \lfloor x/m \rfloor$ 达到上界——非递减分段的首段 $\le x/m$ 故 $\le \lfloor x/m \rfloor$。∎

**引理 2（上界单调性）**：固定剩余后缀时，左侧最少代价关于上界 $b$ 单调不增（$b$ 越大，可行分段集合越大，取 $\min$ 只会不增）。

**证明**：$b_1 \le b_2$ 时，「每段 $\le b_1$」的分段必是「每段 $\le b_2$」的分段，可行集是子集；后缀衔接条件相同。∎

**引理 3（最右不拆）**：存在最优解不拆 `nums[n-1]`。

**证明**：设最优解把 `nums[n-1]` $= x$ 拆成 $m \ge 2$ 段 $p_1 \le \dots \le p_m$。改为单块 $(x)$：由非递减性 $p_1 \le x$，故 $B_{n-2}$ 的末段 $\le p_1 \le x$，衔接合法；代价减少 $m - 1 \ge 1$。若原解确为最优则矛盾（更小），故最优解必不拆最后元素。∎

**定理（贪心正确性）**：从右往左按上述规则处理得到的总代价最少。

**证明**：归纳证明存在与贪心**逐块相同**的最优解。设已将最优解 $O$ 调整为「位置 $\ge i+1$ 的块与贪心完全一致」，记 $q_{i+1}$ 为贪心侧 $B_{i+1}$ 的首段（也是当前上界 $b$）。考察 $O$ 中 $B_i$（$t$ 段 $p_1 \le \dots \le p_t$，末段 $\le q_{i+1} = b$，$x = \text{nums}[i]$）：

- 若 $x \le b$：贪心不拆（单段 $(x)$，衔接合法因 $x \le b$）。若 $O$ 中 $t \ge 2$，把 $B_i$ 换成单块：$B_{i-1}$ 末段 $\le p_1 \le x$ 合法，代价减 $t - 1$，与最优矛盾；故 $t = 1$，两块一致，且新的贪心上界 $x$ 与 $O$ 侧相同。
- 若 $x > b$：$O$ 不可能单段（$p_1 = x > b \ge$ 末段，矛盾），故 $t \ge 2$；由引理 1，$t \ge m = \lceil x/b \rceil$。若 $t > m$，把 $B_i$ 换成贪心的均分块（首段 $\lfloor x/m \rfloor \ge \lfloor x/t \rfloor \ge p_1$，末段 $\le b$）：与 $B_{i-1}$、$B_{i+1}$ 的衔接都合法（$B_{i-1}$ 末段 $\le p_1 \le$ 新首段），代价从 $t - 1$ 降到 $m - 1$，矛盾；故 $t = m$，再把 $B_i$ 的分段换成贪心均分版（合法同上，代价不变，左邻约束更松），两块一致。

归纳至 $i = 0$，得到与贪心完全相同的最优解，故贪心代价 $=$ 最优值。∎

## 6. 复杂度分析

- **时间**：$O(n)$。从右往左一次扫描，每步只有常数次整数运算（一次上取整、一次整除）。
- **空间**：$O(1)$。只维护 `ans` 与 `bound` 两个变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long minimumReplacement(vector<int>& nums) {
        long long ans = 0;
        long long bound = nums.back();                 // 最右元素永不拆 → 初始上界
        for (int i = (int)nums.size() - 2; i >= 0; --i) {
            long long x = nums[i];
            if (x <= bound) {
                bound = x;                             // 无需拆分，新上界 = 自身
            } else {
                long long m = (x + bound - 1) / bound; // 至少拆成 m 段
                ans += m - 1;                          // m 段只需 m-1 次替换
                bound = x / m;                         // 尽量均分 → 首段最大 = ⌊x/m⌋
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def minimumReplacement(self, nums: list[int]) -> int:
        ans = 0
        bound = nums[-1]                       # 最右元素永不拆 → 初始上界
        for i in range(len(nums) - 2, -1, -1):
            x = nums[i]
            if x <= bound:
                bound = x                      # 无需拆分，新上界 = 自身
            else:
                m = (x + bound - 1) // bound    # 至少拆成 m 段
                ans += m - 1                   # m 段只需 m-1 次替换
                bound = x // m                 # 尽量均分 → 首段最大 = ⌊x/m⌋
        return ans
```

> 💡 两份代码均通过官方 2 个示例与 5 个手算边界（单元素 / 全等 / 严格递减 / 尾部为 1 / 递减到 4），并与「从左往右枚举全部非递减分段」的定义法记忆化 DFS 暴力对拍：C++ 2 万组（$n \le 7$、值 $\le 10$）、Python 1 千组（$n \le 6$、值 $\le 8$），`mismatch = 0`；另通过 $10^5$ 规模大数据校验（全 5 尾 1 → 399996；$10^9$ 严格递减 → 36764929713150，跨语言一致）。

## 8. 边界情况与易错点

1. **上取整溢出**：C++ 中 `x + bound - 1` 在 $x$、`bound` 均 $\le 10^9$ 时达 $2 \times 10^9$，`int` 相加回绕成负数、`m` 错成 0——必须用 `long long` 参与运算。
2. **答案要 64 位**：极端情形（如 $[10^9, 10^9-1, \dots]$ 长度 $10^5$）答案 $\approx 3.7 \times 10^{13}$，`int` 必炸；题目返回类型即 `long`。
3. **不要拆最后一个元素**：写循环时从 `n-2` 开始，且 `bound` 初始化为 `nums.back()`；顺手对 `nums[n-1]` 拆分是最常见的实现事故。
4. **`x / m` 是新上界不是段长**：贪心只需计数，不必真的生成分段；把 `bound` 误写成「$x \bmod m$」或「均分余量」会导致左邻约束错位。
5. **相等元素合法**：目标是**非递减**，`x == bound` 时不用拆（判别用 `x > bound` 而非 `x >= bound`）。
6. **单元素数组**：循环体不执行，返回 0；`nums.back()` 勿在空数组上调用（约束保证 $n \ge 1$）。
7. **若允许拆出 0 或负数**：非递减 + 末段 $\le b$ 仍强制每段 $\le b$、首段 $\le x/m$，段数下界不变，本算法依然正确——结论对分段符号不敏感。
