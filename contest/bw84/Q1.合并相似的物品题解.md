# LeetCode 合并相似的物品 题解

## 1. 题目概述

- **标题 / 题号**：合并相似的物品（#2363，easy）
- **链接**：https://leetcode.cn/problems/merge-similar-items/
- **来源**：LeetCode 第 84 场双周赛 Q1
- **难度**：简单
- **标签**：数组、哈希表、有序集合、排序

**题意**：两个二维数组 `items1`、`items2` 各表示一个物品集合，`items[i] = [value, weight]`。**每个集合内部价值唯一**。要求返回 `ret`，其中每项 `[value, weight]` 的 `weight` 是两个集合中**所有价值等于 `value` 的物品重量之和**，且 `ret` 按价值**升序**排列。

**约束**：

- $1 \le \text{items1.length}, \text{items2.length} \le 1000$
- `items1[i]`、`items2[i]` 长度为 2
- $1 \le \text{value}_i, \text{weight}_i \le 1000$
- `items1` 内价值唯一；`items2` 内价值唯一（两集合之间价值可以重叠、也可以只出现在一边）

## 2. 示例

**示例 1**

```text
输入：items1 = [[1,1],[4,5],[3,8]], items2 = [[3,1],[1,5]]
输出：[[1,6],[3,9],[4,5]]
解释：价值 1：1+5=6；价值 3：8+1=9；价值 4：只出现在 items1，重量 5。
```

**示例 2**

```text
输入：items1 = [[1,1],[3,2],[2,3]], items2 = [[2,1],[3,2],[1,3]]
输出：[[1,4],[2,4],[3,4]]
解释：每个价值都同时出现在两个集合，重量和均为 4。
```

**示例 3**

```text
输入：items1 = [[1,3],[2,2]], items2 = [[7,1],[2,2],[1,4]]
输出：[[1,7],[2,4],[7,1]]
解释：价值 7 只在 items2 出现，单独进入结果。
```

## 3. 解题思路

### 3.1 暴力思路

把两个数组拼起来排序，再线性合并相邻的同价值项：$O((n_1 + n_2) \log (n_1 + n_2))$，完全可行。更朴素地，对结果中每个候选价值（来自任一数组）分别到两个数组里线性扫一遍求和，$O((n_1 + n_2)^2)$，$n \le 1000$ 时约 $4 \times 10^6$ 也不会超时——但这道题想考察的是「**以价值为键做聚合**」的标准姿势。

### 3.2 核心观察：聚合 + 有序输出 = 哈希表累加，再按 key 排序

![以价值为键合并权重](images/bw84_q1_merge_model.svg)

价值是天然的**聚合键**：用一个「价值 → 累计重量」的映射，依次扫两个数组做 `weight[v] += w`，一趟完成合并。输出时按价值升序——要么用有序映射（C++ `map`、Python `sorted(dict)`），要么最后对键排序。两数组**内部**价值唯一，保证了同一个 `(v, w)` 在同一数组中不会出现两次，无需去重逻辑。

### 3.3 算法流程

```text
weight = 空映射
遍历 [v, w] ∈ items1：weight[v] += w
遍历 [v, w] ∈ items2：weight[v] += w
按 key 升序输出所有 [v, weight[v]] 到 ret
```

C++ 用 `map<int,int>` 时输出顺序天然升序；Python 用普通字典再 `sorted(weight)` 即可。

### 3.4 示例演算

![示例 3 演算：单边物品直接进结果](images/bw84_q1_example_walkthrough.svg)

示例 3：`items1 = [[1,3],[2,2]]`，`items2 = [[7,1],[2,2],[1,4]]`。聚合得 $1 \to 3+4=7$、$2 \to 2+2=4$、$7 \to 0+1=1$；升序输出 `[[1,7],[2,4],[7,1]]`。价值 7 在 `items1` 中无贡献（记 0），单边物品照样进入结果。

## 4. 算法细节

1. **键的选择**：聚合键是**价值**，重量永远只做加法；别把 `weight` 当键（那会丢失「谁是谁」的信息）。
2. **两数组内部价值唯一是隐含前提**：若同一数组内价值可重复，`+=` 依然正确（该题面下不需要，但写法上顺带兼容）。
3. **输出必须升序**：`map` 遍历天然有序；`unordered_map`/`dict` 则要显式 `sorted`，忘了排序是最常见的 WA 点。
4. **数据规模小**：价值与重量都 $\le 1000$，和 $\le 2000$，无溢出风险；数组最长 1000，任何合理实现都够快。
5. **返回类型**：二维数组 `vector<vector<int>>` / `list[list[int]]`，逐项构造即可。

## 5. 正确性证明

**引理（聚合的正确性）**：设 $W_1(v)$、$W_2(v)$ 分别为 `items1`、`items2` 中价值为 $v$ 的物品重量之和（不存在则为 0）。由于各数组内价值唯一，每个 $v$ 在每个数组中至多出现一次，扫描累加后 `weight[v] = W_1(v) + W_2(v)`。

**证明**：归纳扫描过程——每次处理一项 `[v, w]` 恰好使 `weight[v]` 增加 $w$；两数组扫完后，对每个 $v$，累加进 `weight[v]` 的正是数组中所有价值为 $v$ 的项的重量之和，即 $W_1(v) + W_2(v)$。∎

**定理**：算法输出恰为所求的 `ret`。

**证明**：`ret` 的定义要求：对每个出现过的价值 $v$，输出 $[v,\ W_1(v) + W_2(v)]$；未出现的不输出。由引理，映射中键集合恰为两数组出现过的价值全集，且值恰为总重量；输出阶段按 key 升序枚举全部键，与「按价值升序」的要求一致。∎

## 6. 复杂度分析

- **时间**：$O((n_1 + n_2) \log(n_1 + n_2))$。聚合为线性；排序键（或 `map` 的有序维护）贡献对数因子，$n \le 2000$ 时可忽略不计。
- **空间**：$O(n_1 + n_2)$。映射至多存 $n_1 + n_2$ 个键（去重后只会更少），输出同规模。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<vector<int>> mergeSimilarItems(vector<vector<int>>& items1, vector<vector<int>>& items2) {
        map<int, int> weight;                        // value → weight 累加，map 自带按 key 升序
        for (auto& it : items1) weight[it[0]] += it[1];
        for (auto& it : items2) weight[it[0]] += it[1];
        vector<vector<int>> ret;
        for (auto& [v, w] : weight) ret.push_back({v, w});
        return ret;
    }
};
```

### Python

```python
from collections import defaultdict


class Solution:
    def mergeSimilarItems(self, items1: list[list[int]], items2: list[list[int]]) -> list[list[int]]:
        weight = defaultdict(int)                 # value → weight 累加
        for v, w in items1:
            weight[v] += w
        for v, w in items2:
            weight[v] += w
        return [[v, weight[v]] for v in sorted(weight)]
```

> 💡 两份代码均通过官方 3 个示例与 2 个补充边界（完全同价值 / 两集合不相交），并与「收集全部价值再逐价值线性求和」的独立暴力对拍：C++ 3 万组、Python 3 千组（随机价值 $\le 25$、重量 $\le 50$），`mismatch = 0`。

## 8. 边界情况与易错点

1. **忘记按价值升序输出**：`unordered_map`/`dict` 直接遍历的顺序不可控，WA 的第一大来源；Python 侧 `sorted(weight)` 不能省。
2. **单边价值**：价值只在一个数组出现时也要进入结果（另一边记 0），别做交集过滤。
3. **价值相同但分散**：如示例 2，两数组都有同一价值，必须**相加**而不是覆盖。
4. **数组内价值唯一 ≠ 全局唯一**：别用 `weight[v] = w`（覆盖式）代替 `+=`。
5. **空数组**：约束保证长度 $\ge 1$，但代码写法上空数组也应自然返回空结果（本实现满足）。
6. **元素结构**：每项恰好 `[value, weight]` 两个数，C++ 里 `it[0]`、`it[1]` 取值即可，无需额外校验。
