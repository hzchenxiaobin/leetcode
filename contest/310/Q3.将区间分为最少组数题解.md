# LeetCode 将区间分为最少组数 题解

## 1. 题目概述

- **标题 / 题号**：将区间分为最少组数（#2406，medium）
- **链接**：https://leetcode.cn/problems/divide-intervals-into-minimum-number-of-groups/
- **来源**：LeetCode 第 310 场周赛 Q3
- **难度**：中等
- **标签**：贪心、数组、差分数组、排序、堆（优先队列）、扫描线

**题意**：给定 $n$ 个**闭区间** `intervals[i] = [left_i, right_i]`，将它们划分成若干**组**：每个区间恰好属于一个组，且**同一组内任意两个区间不相交**（不相交 = 没有公共整数点；端点相同也算相交，如 $[1,5]$ 与 $[5,8]$ 共享点 $5$）。返回最少组数。

**约束**：

- $1 \le n \le 10^5$
- `intervals[i].length == 2`
- $1 \le \text{left}_i \le \text{right}_i \le 10^6$

> 💡 本题是「会议室 II」家族的闭区间换皮题：**最少组数 = 任意时刻重叠区间数的最大值**。赛点的全部难度浓缩在两处：一是把「分组」翻译成「重叠深度」的对偶（识别即过半）；二是**闭区间**语义——覆盖一直延伸到右端点 $r$、在 $r+1$ 才释放，它决定了差分减号的位置与堆判定的严格不等号。值域 $\le 10^6$ 的约束更是直接送出 $O(n + V)$ 差分这条最短编码路径。

## 2. 示例

**示例 1**

```text
输入：intervals = [[5,10],[6,8],[1,5],[2,3],[1,10]]
输出：3
解释：第 1 组 { [1,5], [6,8] }，第 2 组 { [2,3], [5,10] }，第 3 组 { [1,10] }。
      点 5 被 [1,5]、[5,10]、[1,10] 三者覆盖，少于 3 组不可能。
```

**示例 2**

```text
输入：intervals = [[1,3],[5,6],[8,10],[11,13]]
输出：1
解释：区间两两不交（3 < 5、6 < 8、10 < 11），全部放进一个组。
```

**示例 3**（端点相接的链条）

```text
输入：intervals = [[1,2],[2,3],[3,4]]
输出：2
解释：[1,2] 与 [2,3] 共享 2，[2,3] 与 [3,4] 共享 3，看似节节纠缠，
      但 [1,2] 与 [3,4] 不交 → 分成 { [1,2], [3,4] } 与 { [2,3] } 两组即可。
      深度在点 2 与点 3 处各为 2 —— 组数由「最深处的拥挤程度」决定，与接触次数无关。
```

## 3. 解题思路

### 3.1 暴力思路

第一档是**枚举分组归属**：每个区间试遍所有已开的组、放不下就新开一组——本质是把分组方案当搜索空间，指数级，$n \le 10^5$ 下无意义。

第二档是**模拟分组**：逐个区间处理，线性扫描已有分组，找一个「组内最大右端点 $R < l$」的组放进去，找不到就新建。正确性没有问题，但最坏情形（$n$ 个区间两两相交）每个区间都要扫遍全部 $O(n)$ 个组，总代价 $O(n^2) \approx 10^{10}$，必然 TLE。

> ⚠️ 模拟法的浪费在于：我们其实**不关心放进哪个组**，只关心「**是否存在**一个可用的组」。而「存在 $R_G < l$」的判定只需要知道所有组最大右端点的**最小值**——把整趟扫描换成维护这个最小值，$O(n^2)$ 就坍缩成 $O(n \log n)$ 的小根堆，这是从暴力到正解的关键一跳。

### 3.2 核心观察：答案 = 最大重叠深度

![核心观察：竖直扫描线扫过数轴，x=5 处同时穿过三个区间，最大重叠深度即为最少组数](images/dig310_max_depth_concept.svg)

**观察一（深度是下界）**：固定点 $p$，覆盖 $p$ 的所有区间两两共享 $p$、两两相交，必须**两两异组**。若 $p$ 处覆盖数为 $k$，则任何方案至少 $k$ 组，即 $\text{ans} \ge \max_p \text{depth}(p)$。

**观察二（深度可达成）**：从左到右处理，维护每个组的最大右端点；新区间到来时复用任何一个已释放（$R < l$）的组。可以证明（§5）如此构造出的组数恰好不超过最大深度。两边夹逼，答案就是最大重叠深度。

**观察三（闭区间的语义）**：$[l, r]$ 的覆盖**含右端点**，在 $r+1$ 处才释放。差分实现里减号放在 $\text{delta}[r+1]$；堆实现里复用条件是**严格**的 $R < l$（当 $R = l$ 时组内区间与新区间共享点 $l$，仍然相交）。把闭区间当半开处理是本题 WA 率第一的来源。

> 💡 图论视角：把区间做成顶点、相交连边，得到**区间图**（interval graph）。区间图是完美图，其**色数 = 团数**，而区间图的最大团恰是数轴上最深处的重叠集。分组 = 染色，最少组数 = 最大重叠深度。253 会议室 II / 1094 拼车都是这条定理的应用。

### 3.3 算法流程：差分扫描线 与 排序 + 小根堆

![算法流程：左路差分扫描线（delta[l]++、delta[r+1]--、前缀和取最大），右路排序加小根堆（堆存各组最大右端点，堆顶与 left 比较决定复用或新建）](images/dig310_algorithm_flow.svg)

**实现 A：差分扫描线**（$O(n + V)$，$V = 10^6$）

1. 开长度 $V + 2$ 的数组 `delta`，每个区间 $[l, r]$：`delta[l] += 1`，`delta[r+1] -= 1`；
2. 从小到大求前缀和 `cur`，同时维护 `ans = max(ans, cur)`；
3. `cur` 在每个整数点 $x$ 上恰好等于覆盖 $x$ 的区间数，峰值即答案。

**实现 B：排序 + 小根堆**（$O(n \log n)$，值域无关）

1. 区间按 `left` 升序排序；
2. 小根堆存**每个组当前的最大右端点**；
3. 处理 $[l, r]$：若堆非空且**堆顶 $< l$**（存在已释放的组），弹出堆顶、压入 $r$（复用该组）；否则压入 $r$（新建组）；
4. 答案 = 终态堆大小（弹-压不改变堆大小、新建 $+1$，堆大小单调不减，终值即组数）。

**实现 C：事件排序**（$O(n \log n)$，B 的值域无关替代）：每个区间拆成 $(l, +1)$ 与 $(r+1, -1)$ 两个事件，按坐标排序、**同坐标先 $+1$ 后 $-1$**（闭区间在端点处仍重叠），扫一遍维护 `cur` 峰值。

### 3.4 示例演算

![示例 1 演算：差分数组 delta 与前缀和深度逐点走查，x=2 与 x=5 处深度达到峰值 3，即最终答案](images/dig310_example_walkthrough.svg)

**差分版**（示例 1，见上图）：`delta[1]=+2, delta[2]=+1, delta[4]=−1, delta[5]=+1, delta[6]=0, delta[9]=−1, delta[11]=−2`，前缀和（深度）在 $x \in \{2,3\}$ 与 $\{5,6,7,8\}$ 处达到峰值 $3$ → 答案 $3$ ✓。

**堆版**（按 `left` 排序后逐区间走查）：

| 区间 | 堆内容（各组最大右端点） | 判定 | 动作 | 组数 |
|------|------------------------|------|------|------|
| $[1,5]$ | $\{\}$ | 堆空 | 新建组①，$R{=}5$ | 1 |
| $[1,10]$ | $\{5\}$ | $5 \ge 1$，冲突 | 新建组②，$R{=}10$ | 2 |
| $[2,3]$ | $\{5,10\}$ | $5 \ge 2$，冲突 | 新建组③，$R{=}3$ | 3 |
| $[5,10]$ | $\{3,5,10\}$ | $3 < 5$ ✓ | 并入③，$R{=}10$ | 3 |
| $[6,8]$ | $\{5,10,10\}$ | $5 < 6$ ✓ | 并入①，$R{=}8$ | 3 |

终态三组：① $\{[1,5],[6,8]\}$、② $\{[1,10]\}$、③ $\{[2,3],[5,10]\}$——与官方解释的分组一致 ✓。注意 $[5,10]$ 复用的是堆顶 $3$（最早释放的组）而非任意一个：**只弹最小**正是把 $O(n^2)$ 扫描压成一次堆操作的原因。

## 4. 算法细节

1. **差分数组开 $V + 2$**：$r \le 10^6$ 时 $r+1$ 最大到 $10^6 + 1$，下标必须能落到 $10^6 + 1$，开 $10^6 + 2$ 才安全。坐标从 $1$ 起，无需偏移。
2. **堆版为何只看堆顶**：堆顶是所有组最大右端点的最小值。堆顶 $< l$ ⟺ 存在可用组；堆顶 $\ge l$ 则**所有**组都与新区间在点 $l$ 冲突（引理 1 的论证），必须新建。一次比较代替整趟扫描。
3. **弹-压的语义是「复用」**：`heapreplace(pq, r)` 弹出最早释放的组、把它的最大右端点更新为 $r$——组还是那个组，堆大小不变。堆大小只在新建时 $+1$，故**答案 = 终态堆大小**，无需另外计数。
4. **排序只需 `left` 主键**：同 `left` 的区间无论谁先处理，面对的「空闲组集合」完全相同，各自独立消耗一个空闲组或新建，结果可交换。C++ `sort` 与 Python 列表排序的默认字典序恰好可用。
5. **事件法的同坐标次序**：闭区间下 $(x, +1)$ 必须排在 $(x, -1)$ 之前，否则 $[1,5]$ 与 $[5,8]$ 会在点 $5$ 被误判为「先释放后进入」而非重叠。差分版天然无此坑——加减发生在**相邻**下标 $r$ 与 $r+1$ 上，前缀和自动保证先加后减。
6. **与 253 会议室 II 的一字之差**：253 是半开区间 $[s, e)$，$e$ 处即释放，差分减在 $e$、判定可写 $\le$；本题闭区间 $[l, r]$，减在 $r+1$、判定用严格 $<$。竞赛里见到「端点相接算不算重叠」的第一反应应是回去读题——它决定 $r$ 还是 $r+1$、`<` 还是 `<=`。
7. **Python 的两个惯用法**：`accumulate(delta)` 一行生成前缀和，`max(accumulate(delta))` 直接出深度峰值；堆版用 `heapreplace`（先弹后压）表达「复用」。由于调用时恒有堆顶 $< l \le r$，它与 `heappushpop`（先压后弹）在本题中结果恰好一致，但语义上应写前者。

## 5. 正确性证明

**引理 1**（复用判据）：区间按 `left` 非降序处理，设组 $G$ 当前最大右端点为 $R_G$。新区间 $[l, r]$ 与 $G$ 中已有区间均不交，当且仅当 $R_G < l$。

**证明**：（充分）$G$ 中任一区间 $[a, b]$ 满足 $b \le R_G < l \le r$，两区间无公共点。（必要）反设 $R_G \ge l$。取 $G$ 中右端点等于 $R_G$ 的区间 $[a, R_G]$；因 $G$ 中区间均已处理且按 `left` 非降序，$a \le l$。于是 $l \in [a, R_G] \cap [l, r]$，两区间相交，矛盾。∎

**引理 2**（深度下界）：对任意点 $p$，同时覆盖 $p$ 的区间两两相交，在任何合法分组中必须两两异组，故组数 $\ge \text{depth}(p)$。从而 $\text{OPT} \ge \max_p \text{depth}(p) = D$。

**证明**：覆盖 $p$ 的任意两个区间都含点 $p$，即相交；同一组内区间不许相交，故它们分属不同组，组数不少于其个数。∎

**引理 3**（堆大小不超过深度）：堆贪心的任意时刻，堆大小 $\le$ 已处理区间集合的最大重叠深度 $\le D$。

**证明**：对处理步数归纳。初始堆空，成立。设处理 $[l, r]$ 前堆大小为 $h \le D$。
- **弹-压**：堆大小不变，仍为 $h \le D$。
- **新建**：若堆空，新大小 $1 \le D$（$n \ge 1$ 时 $D \ge 1$）。若因「堆顶 $\ge l$」触发：堆顶是各组 $R_G$ 的最小值，故**所有**组都有 $R_G \ge l$；由引理 1 证明中的论证，每组各有一个区间覆盖点 $l$（左端点 $\le l \le$ 右端点 $R_G$），加上新区间自身，覆盖 $l$ 的区间至少 $h + 1$ 个，即 $h + 1 \le \text{depth}(l) \le D$。∎

**定理**：堆贪心返回的组数等于最大重叠深度 $D$，且为最优。

**证明**：由引理 1，算法每次把新区间放入组时都与该组已有区间不交，对每组归纳可知组内始终保持两两不交——算法输出的是合法分组，故算法组数 $\ge \text{OPT} \ge D$（后一个不等号用引理 2）。又由引理 3，算法组数 $\le D$。三边夹逼：算法组数 $= \text{OPT} = D$。∎

> 💡 与 Q2（子字符串的最优划分）的**交换论证**不同，本题走的是「**下界 + 构造不变量 + 夹逼**」路线：深度给下界，堆维护的不变量保证构造不越过下界，两边一挤答案唯一。这是「极值 = 某种峰值」类问题（会议室、拼车、最大重叠）的标准证法谱系。

**差分版的等价性**：对整数点 $x$，$\text{cur}(x) = \sum_{t \le x} \text{delta}[t] = \#\{\,i : l_i \le x \le r_i\,\} = \text{depth}(x)$——每个覆盖 $x$ 的区间在 $t = l_i \le x$ 处贡献 $+1$，且其 $-1$ 落在 $r_i + 1 > x$ 处尚未计入。深度仅可能在整数坐标处跳变（端点全为整数），故扫过全部整数点取最大即为 $D$。∎

## 6. 复杂度分析

- **时间复杂度**（差分版）：$O(n + V)$——$2n$ 次差分更新，加 $V \approx 10^6$ 次前缀累加，约 $10^6$ 次整数加法，实际耗时微秒级。
- **时间复杂度**（堆版）：$O(n \log n)$——排序 $O(n \log n)$，每区间至多一次堆操作 $O(\log n)$；$n = 10^5$ 时约 $1.7 \times 10^6$ 次比较。事件版同为 $O(n \log n)$。
- **空间复杂度**：差分版 $O(V)$（`int` 数组约 4 MB）；堆版 / 事件版 $O(n)$（最坏 $n$ 组，即所有区间两两相交时堆长到 $n$）。
- **赛时取舍**：值域 $\le 10^6$ 明示差分是期望解——代码最短、常数最小；堆 / 事件版是值域无关的通用模板，端点上 $10^9$、$10^{18}$ 时差分失效，它们接棒。

## 7. 参考代码

### C++（差分扫描线，赛时首选）

```cpp
class Solution {
public:
    int minGroups(vector<vector<int>>& intervals) {
        vector<int> delta(1000002, 0);
        for (auto& in : intervals) {
            ++delta[in[0]];
            --delta[in[1] + 1];          // 闭区间：覆盖延续到 r，r+1 才释放
        }
        int ans = 0, cur = 0;
        for (int x : delta) ans = max(ans, cur += x);
        return ans;
    }
};
```

### C++（排序 + 小根堆，值域无关）

```cpp
class Solution {
public:
    int minGroups(vector<vector<int>>& intervals) {
        sort(intervals.begin(), intervals.end());
        priority_queue<int, vector<int>, greater<int>> pq;   // 各组的最大右端点
        for (auto& in : intervals) {
            if (!pq.empty() && pq.top() < in[0])   // 严格 <：R == l 时仍在点 l 相交
                pq.pop();                          // 复用最早释放的组
            pq.push(in[1]);
        }
        return (int)pq.size();
    }
};
```

### Python（差分 + accumulate）

```python
class Solution:
    def minGroups(self, intervals: List[List[int]]) -> int:
        delta = [0] * (10**6 + 2)
        for l, r in intervals:
            delta[l] += 1
            delta[r + 1] -= 1            # 闭区间：减号在 r+1
        return max(accumulate(delta))
```

### Python（排序 + 小根堆）

```python
class Solution:
    def minGroups(self, intervals: List[List[int]]) -> int:
        intervals.sort()
        groups = []                          # 小根堆：各组的最大右端点
        for l, r in intervals:
            if groups and groups[0] < l:     # 严格 <，复用最早空闲的组
                heapq.heapreplace(groups, r)
            else:
                heapq.heappush(groups, r)    # 新建组
        return len(groups)
```

> 💡 赛时四选一：值域已知 $\le 10^6$ 时差分版 5 行核心逻辑、一遍常数级扫描，是最短路径；若担心 4 MB 数组或想写通用模板，堆版同样稳。两版答案必然一致（都等于 $D$），可互为对拍。

## 8. 边界情况与易错点

1. **闭区间的 $r+1$ 与严格小于**（头号坑）：差分减在 `delta[r+1]`、堆判定写 `top < left`。任何一处写成 $r$ 或 `<=`，都会在 $[1,5]$ 与 $[5,8]$ 型数据上把重叠漏算成不交、答案偏小。题目原文专门举了这个例子，等于明示考点。
2. **差分数组开小**：至少 $10^6 + 2$——`r+1` 的下标要到 $10^6 + 1$，开 $10^6 + 1$ 会让最后一个减号越界。
3. **端点相接的链条**：$[[1,2],[2,3],[3,4]]$ 的答案是 2 不是 3——组数由**最深处的重叠**决定，不是由「接触关系是否连成一片」决定，别把链条误当成需要逐段开组。
4. **全部相同区间**：$n$ 个 $[1,1]$ → 答案 $n$。顺手心算检验差分：$\text{delta}[1] = n$，峰值 $n$ ✓。
5. **单区间 / 全不交**：答案 1，三种实现都天然给出，无需特判。
6. **堆空时 `heapreplace` 非法**：必须先判 `groups and groups[0] < l`；第一个区间一定走 `else` 分支新建。
7. **事件法的排序键**：同坐标 $(x, +1)$ 排在 $(x, -1)$ 前，用元组 `(x, type)` 且起点 `type` 更小即可；写错次序只在端点相接的数据上出错，样例未必能暴露。
8. **C++ 返回 `pq.size()`**：类型是 `size_t`，返回 `int` 有窄化警告，显式 `(int)` 转换一下。
9. **不要顺手给差分加「排序」**：差分版与顺序无关，先排序白付 $O(n \log n)$；堆版才依赖排序。
10. **赛时节奏**：识别「会议室 II 闭区间版」（1 分钟）→ 确认 $r+1$ 与严格小于（1 分钟，拿示例 1 的 $[1,5]$ / $[5,10]$ 心算验证）→ 差分 5 行敲完提交（3 分钟）。省下的时间投给 Q4 的线段树优化 LIS。

> 本站已有该题的每日题解（`solution/2401-2500/2406_将区间分为最少组数.md`），以差分为主轴并附事件法与堆法的扩展；本文为周赛复盘视角，补全引理-定理结构的完整证明、闭区间语义的坑位清单与赛时取舍，并给出与同场 Q2 证明谱系的对照。

**延伸思考**：若值域升到 $10^{18}$，差分失效，堆 / 事件法 $O(n \log n)$ 接棒；若要求输出具体分组方案，堆元素换成 $(R, \text{组编号})$、复用时沿用编号即可，$O(n \log n)$ 不变；若放宽为「组内至多 $k$ 重叠」（$k$ 间会议室），答案是 $\max_x \lceil \text{depth}(x) / k \rceil$——差分前缀和除以 $k$ 上取整再取峰值；若区间带权、组内要求权和上限，则贪心退位给「按右端点排序 + 反悔堆」，那是从重叠计数滑向带约束调度的路径。
