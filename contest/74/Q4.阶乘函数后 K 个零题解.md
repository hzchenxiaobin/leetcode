# LeetCode 阶乘函数后 K 个零 题解

## 1. 题目概述

- **标题 / 题号**：阶乘函数后 K 个零（#793，hard）
- **链接**：https://leetcode.cn/problems/preimage-size-of-factorial-zeroes-function/
- **来源**：LeetCode 第 74 场周赛 Q4
- **难度**：困难
- **标签**：数学、二分查找

**题意**：记 $f(x)$ 为 $x!$ 末尾连续零的个数（约定 $0! = 1$，故 $f(0) = 0$）。给定整数 $k$，求满足 $f(x) = k$ 的**非负整数** $x$ 的个数。例如 $f(3) = 0$、$f(11) = 2$。

**约束**：

- $0 \le k \le 10^9$
- $k$ 可以非常大，但 $f(x)$ 关于 $x$ 单调不减且增长极慢，$f(x) \approx x/4$，因此「候选 $x$」的量级可达 $4 \times 10^9$，不能逐个枚举
- 答案只可能是 $0$ 或 $5$，这一点由下文的结构性引理给出

## 2. 示例

**示例 1**

```text
输入：k = 0
输出：5
解释：0!, 1!, 2!, 3!, 4! 末尾都没有 0，共 5 个 x 满足 f(x) = 0。
```

**示例 2**

```text
输入：k = 5
输出：0
解释：f(20) = 4，f(25) = 6，f 从 4 直接跳到 6，没有任何 x 使 f(x) = 5。
```

**示例 3**

```text
输入：k = 3
输出：5
解释：f(15) = f(16) = f(17) = f(18) = f(19) = 3，恰好 5 个 x。
```

## 3. 解题思路

### 3.1 暴力思路

对 $x = 0, 1, 2, \dots$ 依次用 Legendre 公式计算 $f(x)$，统计等于 $k$ 的个数，一旦 $f(x) > k$ 就停止。单次计算 $f(x)$ 需要 $O(\log_5 x)$ 次除法，总复杂度 $O(x_{\max} \log x_{\max})$；而 $x_{\max} \approx 4k \le 4 \times 10^9$，量级是 $10^{10}$ 次运算——完全不可行。必须把「枚举 $x$」换成「直接定位 $x$ 所在的整块」。

### 3.2 核心观察：每 5 个连续整数共享同一个 $f$ 值

![f 在 5 连块上恒定，答案只能是 0 或 5](images/wc74_q4_block_of_five.svg)

Legendre 公式给出

$$f(x) = \sum_{i \ge 1} \left\lfloor \frac{x}{5^i} \right\rfloor$$

把 $x$ 写成 $x = 5t + r$（$0 \le r \le 4$），对每个 $i \ge 1$ 都有

$$\left\lfloor \frac{5t + r}{5^i} \right\rfloor = \left\lfloor \frac{t + r/5}{5^{i-1}} \right\rfloor = \left\lfloor \frac{t}{5^{i-1}} \right\rfloor$$

最后一步成立是因为中间式 $= t/5^{i-1} + r/5^{i}$，而 $t/5^{i-1}$ 的小数部分是 $1/5^{i-1}$ 的整数倍、扰动项 $0 \le r/5^{i} < 1/5^{i-1}$ 不足一个粒度，凑不满下一个整数。于是

$$f(5t + r) = \sum_{i \ge 1}\left\lfloor \frac{t}{5^{i-1}} \right\rfloor = t + f(t)$$

**结论一**：$f$ 在每个块 $\{5t, 5t+1, \dots, 5t+4\}$ 上取值恒定，等于 $g(t) = t + f(t)$。因为块大小固定为 5，任何 $k$ 的**解数只能是 0 或 5**：整块命中，或整块落空。

**结论二**：$g(t+1) - g(t) = 1 + \bigl(f(t+1) - f(t)\bigr) = 1 + v_5(t+1) \ge 1$，其中 $v_5$ 是 $5$ 的指数，故 $g$ **严格递增**。于是每个「可达的」$k$ 恰被一个块命中，问题化为：判断 $k$ 是否落在 $\mathrm{Im}(g)$ 中。

### 3.3 算法流程：在 $t$ 上二分

![二分定位最小的 t 使 g(t) ≥ k](images/wc74_q4_binary_search_g.svg)

由于 $g$ 严格递增，「$g(t) \ge k$」是关于 $t$ 的单调判定，可以用一次 lower_bound 式的二分解决：

1. **定界**：$lo = 0$，$hi = k$。因为 $g(t) \ge t$，若 $g(t) = k$ 则必有 $t \le k$，上界取 $k$ 即可。
2. **收缩**：取 $mid = \lfloor (lo+hi)/2 \rfloor$，若 $g(mid) \ge k$ 则令 $hi = mid$（$mid$ 自己可能就是答案，不能写成 $mid-1$）；否则令 $lo = mid + 1$。
3. **终止**：$lo = hi$ 时，$lo$ 是满足 $g(t) \ge k$ 的最小下标，$g(lo)$ 是 $\mathrm{Im}(g)$ 中不小于 $k$ 的最小值。
4. **判定**：若 $g(lo) = k$，说明块 $lo$ 命中，返回 5；否则 $k$ 被 $g$ 跳过，返回 0。

整个过程只求值 $g$，不触碰任何 $x$ 的上界估计。

### 3.4 示例演算

![k=5 与 k=3 的二分走查](images/wc74_q4_walkthrough.svg)

以 $k = 5$ 为例：$lo=0, hi=5$，$mid=2$，$g(2) = 2 + f(2) = 2 < 5 \Rightarrow lo = 3$；$mid = 4$，$g(4) = 4 + f(4) = 4 < 5 \Rightarrow lo = 5$。终止时 $lo = hi = 5$，而 $g(5) = 5 + f(5) = 5 + 1 = 6 \ne 5$，故返回 0——这正是 $f(20) = 4$ 跳到 $f(25) = 6$ 留下的空隙。

再看 $k = 3$：$mid=1 \Rightarrow g(1) = 1 < 3 \Rightarrow lo = 2$；$mid = 2 \Rightarrow g(2) = 2 < 3 \Rightarrow lo = 3$；终止 $g(3) = 3 + f(3) = 3 = k$，返回 5，对应 $x = 15, 16, 17, 18, 19$。

## 4. 算法细节

1. **$f(x)$ 的 Legendre 循环**：从 $p = 5$ 开始，当 $p \le x$ 时累加 $\lfloor x/p \rfloor$ 并令 $p \leftarrow 5p$。注意循环条件必须带等号：$x = 5$ 时 $\lfloor 5/5 \rfloor = 1$ 必须计入。
2. **整数类型**：$k \le 10^9$，$t \le k$，故 $g(t) \le t + t/4 < 1.25 \times 10^9$，仍在 32 位有符号范围内，但 $5^{13} = 1220703125$ 已逼近 $2^{31}$、$5^{14}$ 必然溢出。**统一用 64 位整数**，避免在 $p \leftarrow 5p$ 上翻车。
3. **二分模板**：用 `while (lo < hi)` 配合 $hi \leftarrow mid$、$lo \leftarrow mid + 1$ 的 lower_bound 模板，天然收敛且不会漏掉答案；不要混用 $hi \leftarrow mid - 1$ 与 $mid \leftarrow \lfloor (lo + hi + 1)/2 \rfloor$ 的另一套模板，否则极易死循环。
4. **上界取 $k$ 的依据**：由 $g(t) \ge t$ 得「命中块 $t$ 必满足 $t \le k$」，所以 $[0, k]$ 一定包含答案（若存在）。若误写成 $hi = k - 1$，$k = 0$ 与命中 $t = k$ 的情形都会被漏掉。
5. **判定用等号而非存在性**：$g$ 严格递增，因此满足 $g(t) \ge k$ 的最小 $t$ 是唯一候选，只需检验 $g(lo) = k$ 是否成立，无需再向左右扩散或二次二分。
6. **块编号与 $x$ 的换算**：块 $t$ 对应 $x \in [5t, 5t+4]$，反查时 $t = \lfloor x/5 \rfloor$。若题目改问「返回其中一个 $x$」，答案是 $5t$，但本题只要个数。
7. **不要试图硬算阶乘**：$x$ 可达 $4 \times 10^9$，`math.factorial`、大整数阶乘都会直接爆内存；$f$ 只能用 Legendre 公式求。

## 5. 正确性证明

**引理 1（块内同值）**：对任意整数 $t \ge 0$ 与 $0 \le r \le 4$，有 $f(5t + r) = t + f(t)$。

**证明**：对 $i = 1$，由 $0 \le r \le 4$ 直接得 $\lfloor (5t+r)/5 \rfloor = t = \lfloor t/5^{0} \rfloor$。对 $i \ge 2$，拆分被除数：

$$\left\lfloor \frac{5t+r}{5^i} \right\rfloor = \left\lfloor \frac{t}{5^{i-1}} + \frac{r}{5^{i}} \right\rfloor$$

其中 $t/5^{i-1}$ 的小数部分是 $1/5^{i-1}$ 的整数倍（最小非零粒度恰为 $1/5^{i-1}$），而 $0 \le r/5^{i} \le 4/5^{i} < 5/5^{i} = 1/5^{i-1}$，扰动不足以把商顶到下一个整数，故取整结果仍是 $\lfloor t/5^{i-1} \rfloor$。将这些项相加：

$$f(5t+r) = t + \sum_{i \ge 2}\left\lfloor \frac{t}{5^{i-1}} \right\rfloor = t + \sum_{j \ge 1}\left\lfloor \frac{t}{5^{j}} \right\rfloor = t + f(t)$$

∎

**引理 2（$g$ 严格递增）**：$g(t+1) > g(t)$ 对一切 $t \ge 0$ 成立。

**证明**：$f(t+1) - f(t)$ 等于 $\{1, 2, \dots, t+1\}$ 中新增的因子 5 的个数，即 $v_5(t+1) \ge 0$。故 $g(t+1) - g(t) = 1 + v_5(t+1) \ge 1 > 0$。∎

**引理 3（二分区间足够）**：$g(t) \ge t$，故若存在 $t$ 使 $g(t) = k$，则 $t \le k$。

**证明**：$f(t) \ge 0$，故 $g(t) = t + f(t) \ge t$；结合 $g(t) = k$ 得 $t \le k$。∎

**定理 1（解集结构）**：$f(x) = k$ 有解当且仅当 $k \in \mathrm{Im}(g)$；若有解，解恰为某一块的 5 个整数 $x = 5t, \dots, 5t+4$。

**证明**：每个非负整数 $x$ 唯一写成 $x = 5t + r$（$0 \le r \le 4$），由引理 1 有 $f(x) = g(t)$，所以 $f(x) = k \iff g(\lfloor x/5 \rfloor) = k$。若 $k \in \mathrm{Im}(g)$，由引理 2 满足 $g(t) = k$ 的 $t$ 唯一，该块 5 个整数全是解，且其他块的值都不等于 $k$，故恰有 5 个解；若 $k \notin \mathrm{Im}(g)$，则没有块承载 $k$，无解。∎

**定理 2（算法正确性）**：算法返回的整数恰好是 $|\{x \ge 0 : f(x) = k\}|$。

**证明**：二分维持不变量「$g(t) < k$ 对 $t < lo$ 成立，$g(t) \ge k$ 对 $t \ge hi$ 成立」，初始时由引理 3 取 $hi = k$，不变量成立（$[0,k]$ 之外不存在命中块）。每轮若 $g(mid) \ge k$ 则 $hi = mid$ 保持右侧性质，否则 $lo = mid+1$ 保持左侧性质。终止时 $lo = hi = t^{*}$，$t^{*}$ 是满足 $g(t) \ge k$ 的最小下标，故 $k \in \mathrm{Im}(g) \iff g(t^{*}) = k$。由定理 1，前者对应 5 个解、后者对应 0 个解，与返回值一致。∎

## 6. 复杂度分析

- **时间**：二分轮数 $O(\log k) \le 30$；每轮求 $g(mid)$ 需要 $O(\log_5 k) \le 13$ 次整数除法。总时间 $O(\log^2 k)$，$k = 10^9$ 时不超过约 400 次基本运算。
- **空间**：$O(1)$，只用了若干个 64 位整数，无数组、无哈希表、无递归栈。

## 7. 参考代码

### C++

```cpp
class Solution {
    // f(x)：x! 末尾零的个数（Legendre 公式）
    long long f(long long x) {
        long long s = 0;
        for (long long p = 5; p <= x; p *= 5) s += x / p;
        return s;
    }

    // g(t) = t + f(t)：块 x ∈ [5t, 5t+4] 上恒定不变的 f 值
    long long g(long long t) { return t + f(t); }

public:
    int preimageSizeFZF(int k) {
        long long lo = 0, hi = k;              // g(t) >= t ⇒ 命中块 t 必不超过 k
        while (lo < hi) {
            long long mid = lo + (hi - lo) / 2;
            if (g(mid) >= k) hi = mid;         // mid 可能就是答案，不能减 1
            else lo = mid + 1;                 // mid 一定不是答案，可以跳过
        }
        return g(lo) == k ? 5 : 0;
    }
};
```

### Python

```python
class Solution:
    def preimageSizeFZF(self, k: int) -> int:
        def f(x: int) -> int:
            """x! 末尾零的个数：Legendre 公式"""
            s, p = 0, 5
            while p <= x:
                s += x // p
                p *= 5
            return s

        def g(t: int) -> int:
            """块 x ∈ [5t, 5t+4] 上恒定不变的 f 值"""
            return t + f(t)

        lo, hi = 0, k                     # g(t) >= t ⇒ 命中块 t 必不超过 k
        while lo < hi:
            mid = (lo + hi) // 2
            if g(mid) >= k:
                hi = mid                  # mid 可能就是答案
            else:
                lo = mid + 1              # mid 一定不是答案
        return 5 if g(lo) == k else 0
```

## 8. 边界情况与易错点

1. **$k = 0$**：答案 5（$0!$ 到 $4!$）。此时 $lo = hi = 0$、$g(0) = 0$，代码无需特判即可返回 5；但若二分区间写成 $[1, k]$ 或 $hi = k-1$，就会错判成 0。
2. **$k = 5, 11, 17, 23, 29, 30, \dots$**：这些值被 $g$ 跳过，答案是 0。$k = 5$ 是最容易踩的样例，必须靠 $g(lo) = k$ 的等号判定拦住。
3. **溢出的两道坎**：$p \leftarrow 5p$ 在 $t$ 接近 $10^9$ 时会算出 $5^{14}$ 量级的值，32 位下溢出；$g(t)$ 本身也接近 $1.25 \times 10^9$。C++ 一律用 `long long`。Python 无此问题，但要注意循环条件是 $p \le x$ 而非 $p < x$。
4. **二分边界的等号**：$hi = mid$（保留 $mid$）而非 $mid - 1$，否则当 $g(mid) = k$ 时会把唯一答案丢掉；反过来 $lo \leftarrow mid + 1$ 必须加一，否则 $lo = mid$ 在 $lo + 1 = hi$ 时死循环。
5. **返回值只能是 0 或 5**：若程序返回 1、2、3、4，说明块结构或二分下界写错了；可以拿 $k = 0, 3, 5$ 与暴力对拍快速自检。
6. **$x$ 的上界不要靠猜**：常见错误是枚举到 $x = 5k$ 或 $10k$ 后「截断」，而 $f(5k)$ 早已远超 $k$；正确的做法是把问题完全转到 $t$ 上，由 $t \le k$ 给出干净的上界。
