# LeetCode 有效的井字游戏 题解

## 1. 题目概述

- **标题 / 题号**：有效的井字游戏（#794，medium）
- **链接**：https://leetcode.cn/problems/valid-tic-tac-toe-state/
- **来源**：LeetCode 第 74 场周赛 Q1
- **难度**：中等
- **标签**：数组、矩阵

**题意**：给一个 $3\times 3$ 的棋盘 `board`（由 `'X'`、`'O'`、`' '` 组成），判断它是否可能是**合法对局中**某个时刻（含终局）的局面。合法对局规则：X 先手，双方轮流在空格落子；一旦某方在某行、某列或某条对角线上连成 3 个相同字符，**或** 9 格被填满，游戏立即结束，此后不允许再落子。

换个说法：需要判断「**是否存在一个落子序列**，把空盘一步步变成 `board`，且过程中没有任何人在游戏结束后继续落子」。

**约束**：

- `board.length == 3`，`board[i].length == 3`
- `board[i][j]` 为 `'X'`、`'O'` 或 `' '`
- 棋盘只有 9 格，全部状态数为 $3^9 = 19683$，所以 $O(1)$ 判定足够应付任何输入

## 2. 示例

**示例 1**

```text
输入：board = ["O  ", "   ", "   "]
输出：false
解释：先手必须放 'X'，不可能一步就出现 'O'。
```

**示例 2**

```text
输入：board = ["XOX", " X ", "   "]
输出：false
解释：X 有 3 个、O 只有 1 个；双方必须轮流落子，X 至多比 O 多一个。
```

**示例 3**

```text
输入：board = ["XOX", "O O", "XOX"]
输出：true
解释：X 与 O 各 4 个，棋盘上没有任何一条线被占满，可以正常下到此刻。
```

**补充示例**（下面分析会用到）

```text
输入：board = ["XXX", "XOO", "XOO"]   →  true（X 同时占满第 0 行与第 0 列，5 子）
输入：board = ["XXX", "OOO", "   "]   →  false（不可能两边同时连成线）
```

## 3. 解题思路

### 3.1 暴力思路

棋盘只有 9 格，完全可以从空盘开始**搜索**：DFS 枚举所有「合法」局面（每个局面只允许下一步棋的人、且游戏未结束时继续扩展），把结果的集合存起来，再看 `board` 是否落在集合里。

- 状态总数 $3^9 = 19683$，其中真正合法的只有 **5478** 个（本仓库验证脚本实测）。
- 复杂度：$O(3^9 \times 9)$，常数级，能过。
- 问题：代码要建集合 + 哈希，还需要额外论证「搜索剪枝等价于题面规则」；本质上是**枚举**而不是**判定**，$n\times n$ 推广后立刻爆炸（$3^{n^2}$）。

所以要找的是：能不能用**几条与落子顺序无关的不变量**，直接判定局面合法性。

### 3.2 核心观察：三条与顺序无关的不变量

![8 条获胜线：3 行 + 3 列 + 2 对角线](images/wc74_q1_win_lines.svg)

先约定：$c_X$ 为 `'X'` 的个数，$c_O$ 为 `'O'` 的个数；$W_X$、$W_O$ 分别表示 X / O 是否已经占满 8 条线中的某一条。

- **不变量 A（计数）**：任何时刻 $c_X = c_O$ 或 $c_X = c_O + 1$。
  X 先手、双方交替，所以 X 要么刚下完（比 O 多一子），要么轮到它下（与 O 相同）。
- **不变量 B（终局归属）**：若 $W_X$，则最后一手必定是 X；若 $W_O$，则最后一手必定是 O。
  因为「连成线」的瞬间游戏立刻结束，此后**不允许再落子**，所以成线那一方的子数必然落在「它刚下完」的那一档：
  $$W_X \implies c_X = c_O + 1, \qquad W_O \implies c_X = c_O$$
- **不变量 C（唯一性）**：$W_X$ 与 $W_O$ **不可能同时成立**。
  最后一手只落一个子，只能给一方凑成线；若在它之前另一方已经成线，那一局早就结束了。

> 💡 关键点：这三条都是**关于最终棋盘的一次性检查**，不需要关心具体落子顺序，于是判定被压缩成「数数 + 扫 8 条线」。

### 3.3 算法流程

![判定流程：计数 → 交替合法 → 求胜负 → 三条结论](images/wc74_q1_decision_flow.svg)

1. 遍历 9 个格子统计 $c_X, c_O$。
2. 若 $c_X \ne c_O$ 且 $c_X \ne c_O + 1$，返回 `false`（不变量 A）。
3. 扫 8 条线，分别得到 $W_X, W_O$（每条线 3 格字符是否相同且非空）。
4. 若 $W_X$ 且 $W_O$，返回 `false`（不变量 C）。
5. 若 $W_X$ 且 $c_X \ne c_O + 1$，返回 `false`；若 $W_O$ 且 $c_X \ne c_O$，返回 `false`（不变量 B）。
6. 以上都通过，返回 `true`。

### 3.4 示例演算

![五个局面的判定走查](images/wc74_q1_walkthrough.svg)

| 局面 | $c_X/c_O$ | 计数合法 | 成线情况 | 结论 |
|------|-----------|----------|----------|------|
| `["O  ","   ","   "]` | 0 / 1 | 否（O 先手） | — | false |
| `["XOX"," X ","   "]` | 3 / 1 | 否（差 2） | — | false |
| `["XOX","O O","XOX"]` | 4 / 4 | 是 | 无 | **true** |
| `["XXX","OOO","   "]` | 3 / 3 | 是 | X 与 O 同时成线 | false |
| `["XXX","XOO","XOO"]` | 5 / 4 | 是 | 仅 X（两条线） | **true** |

第 5 行是本题最容易踩的坑：X 同时占满第 0 行和第 0 列，**两条线是允许的**（把共享的角点留到最后一手即可），只要 O 没有成线、且 $c_X = c_O + 1$。

## 4. 算法细节

1. **先数数再判胜负**：两个计数各扫一遍棋盘即可，$c_X + c_O$ 也有用（判断满盘不算必需，但可作断言）。
2. **8 条线用扁平下标**：把 9 格拼成 `flat = board[0] + board[1] + board[2]`，8 条线的下标为 `(0,1,2),(3,4,5),(6,7,8),(0,3,6),(1,4,7),(2,5,8),(0,4,8),(2,4,6)`，配合「三字符相等且非空」一次判定。
3. **只用布尔累积，不要数「几条线」**：一个玩家可能同时占满两条线（见 3.4 第 5 行），用 `any` 即可，统计条数反而容易把合法局面误判成非法。
4. **O 赢的计数条件是 $c_X = c_O$，不是 $c_O+1$**：这是最常见的对称性错误。X 赢说明 X 刚下完（多一子），O 赢说明 O 刚下完（两边一样多）。
5. **两侧条件都要检查**：「X 赢则计数必须匹配」与「O 赢则计数必须匹配」是两条独立约束，不能只写一条。
6. **提前返回**：任何一条不满足立刻 `false`，顺序随意，但所有条件之间都是「与」关系，不能提前 `true`。
7. **注意 `' '` 是真空格**：C++ 里 `board` 是 `string` 数组，行尾空格会保留；不要对整行做 `trim`，否则列下标会错位。

## 5. 正确性证明

**引理 1（必要性·计数）**：任何合法过程到达的局面满足 $c_X = c_O$ 或 $c_X = c_O + 1$。

**证明**：对落子步数归纳。空盘 $c_X = c_O = 0$，成立。每一步由先手交替决定落子方：若当前 $c_X = c_O$（共 $2k$ 子），下一步必为 X，得 $c_X = c_O + 1$；若当前 $c_X = c_O + 1$（共 $2k+1$ 子），下一步必为 O，得 $c_X = c_O$。两种情形都保持在允许集合内。∎

**引理 2（必要性·终局归属）**：合法局面中不会同时出现 $W_X$ 与 $W_O$；且 $W_X \Rightarrow c_X = c_O + 1$，$W_O \Rightarrow c_X = c_O$。

**证明**：设最后一步落在格子 $p$，落子方为 $P$。既然 $p$ 真的被落下，说明落子前的局面中**没有任何一方成线**（否则游戏已结束，不允许再落子）。因此最终局面里每一条完整线都必须包含 $p$；而 $p$ 上是 $P$ 的子，对方根本不可能有一条线经过 $p$，所以成线的只能是 $P$，另一方不可能成线。再由引理 1：$P = X$ 时 $c_X = c_O+1$；$P = O$ 时 $c_X = c_O$。∎

**引理 3（充分性·可构造）**：设局面满足引理 1、2 的结论，则存在合法落子序列到达该局面。

**证明**：记 X 的落点集合为 $A$、O 的为 $B$，$|A| \ge |B|$。

- 情形一：$A$、$B$ 都不含完整线。则**任意**交替顺序（$A$ 的任一枚举与 $B$ 的任一枚举交错，X 先）都合法：中间局面的棋子集合是 $A\cup B$ 的子集，子集若含完整线则 $A \cup B$ 也含该线，与假设矛盾，故中途无人成线。
- 情形二：仅 $W_X$ 成立，$|A| = |B| + 1$。取 X 的一条成线 $L$，在其中选一格 $q$：若 X 只有这一条线，$q$ 任取 $L$ 中一格；若 X 有两条线，则两条线必共享一格（$3\times3$ 中两条不共享格的行/列要 6 子，而 $|A| \le 5$ 来自 $2|B|+1 \le 9$；三条线的并至少 6 格，同样不可能），取共享格。令 $A' = A \setminus \{q\}$，则 $A'$ 不含完整线。先按情形一的论证把 $A'$ 与 $B$ 交替放完（中途无人成线），最后落 $q$：此时 $X$ 占满 $L$，游戏结束，与局面一致。
- 情形三：仅 $W_O$ 成立，$|A| = |B|$。同情形二对 O 取 $q$，先放 $A \setminus \{a_0\}$ 与 $B \setminus \{q\}$ 交替（$|A|-1 = |B|-1$，X 先），再落 $a_0$（X），最后落 $q$（O）成线并结束。

三种情形都给出了具体序列，故局面可达。∎

**定理**：算法返回 `true` 当且仅当 `board` 是合法对局中可达的局面。

**证明**：若返回 `true`，则引理 1、2 的全部结论都成立，由引理 3 局面可达；若局面可达，由引理 1、2 它必然通过全部检查，算法返回 `true`。∎

## 6. 复杂度分析

- **时间**：$O(1)$。统计计数扫 9 格；8 条线、每条线比较 3 个字符；总计不超过 33 次常数操作，与输入无关。
- **空间**：$O(1)$。只用两个计数器与两个布尔量（拼 `flat` 最多 9 个字符）。
- 对比暴力：搜索版需要 $O(3^9)$ 时间与空间预处理，本题数据规模下也能过，但判定版没有额外存储、推广性更好。

## 7. 参考代码

### C++

```cpp
#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    bool validTicTacToe(vector<string>& board) {
        int cx = 0, co = 0;
        for (int i = 0; i < 3; i++)
            for (int j = 0; j < 3; j++) {
                if (board[i][j] == 'X') cx++;
                else if (board[i][j] == 'O') co++;
            }
        // 不变量 A：X 先手且交替落子
        if (!(cx == co || cx == co + 1)) return false;

        int lines[8][3] = {{0, 1, 2}, {3, 4, 5}, {6, 7, 8},
                           {0, 3, 6}, {1, 4, 7}, {2, 5, 8},
                           {0, 4, 8}, {2, 4, 6}};
        auto win = [&](char ch) -> bool {
            for (auto& L : lines) {
                int a = L[0], b = L[1], c = L[2];
                if (board[a / 3][a % 3] == ch && board[b / 3][b % 3] == ch &&
                    board[c / 3][c % 3] == ch)
                    return true;
            }
            return false;
        };
        bool wx = win('X'), wo = win('O');
        if (wx && wo) return false;              // 不变量 C
        if (wx && cx != co + 1) return false;    // 不变量 B：X 刚下完
        if (wo && cx != co) return false;        // 不变量 B：O 刚下完
        return true;
    }
};
```

### Python

```python
class Solution:
    def validTicTacToe(self, board: list[str]) -> bool:
        cx = sum(row.count('X') for row in board)
        co = sum(row.count('O') for row in board)
        if not (cx == co or cx == co + 1):      # 不变量 A
            return False

        lines = ((0, 1, 2), (3, 4, 5), (6, 7, 8),
                 (0, 3, 6), (1, 4, 7), (2, 5, 8),
                 (0, 4, 8), (2, 4, 6))
        flat = ''.join(board)

        def win(ch: str) -> bool:
            return any(flat[a] == flat[b] == flat[c] == ch for a, b, c in lines)

        wx, wo = win('X'), win('O')
        if wx and wo:                # 不变量 C：不可能双方成线
            return False
        if wx and cx != co + 1:      # 不变量 B：X 刚下完
            return False
        if wo and cx != co:          # 不变量 B：O 刚下完
            return False
        return True
```

## 8. 边界情况与易错点

1. **空盘**：`["   ","   ","   "]` → $c_X = c_O = 0$，无人成线，返回 `true`（比赛开局）。
2. **O 先手**：`["O  ","   ","   "]` → $c_X = 0, c_O = 1$，差值方向反了，必须返回 `false`；只判断 $\lvert c_X-c_O\rvert \le 1$ 会漏掉这类反例。
3. **满盘平局**：9 格填满且无人成线，如 `["XOX","XOO","OXX"]`，此时 $c_X=5, c_O=4$，返回 `true`；满盘本身不算违规。
4. **X 占两条线**：`["XXX","XOO","XOO"]` 合法（5 子），把它当非法是最典型的误判；若出现 $c_X = 6$ 之类的双线局面（如 `["XXX","XXX","OOO"]`），计数已经超标，必须返回 `false`。
5. **双方同时成线**：`["XXX","OOO","   "]` 计数 $3/3$ 合法，但成线唯一性被破坏，返回 `false`。
6. **O 成线时计数**：O 成线要求 $c_X = c_O$。反例 `["OOO","XX ","XX "]` 中 $c_X = 4, c_O = 3$，计数检查能过，但 O 既已连成线就不该再由 X 落子，故应为 `false`；把条件写成 $c_X = c_O+1$ 就会漏掉这类局面。
7. **提前结束后的落子**：`["XXX","OOO","   "]` 这类是「成线后还有子」的极端情形，规则上不允许；本题只判定局面，因此由不变量 C 覆盖，不需要模拟过程。
8. **行尾空格**：`["XOX"," X ","   "]` 的 `" X "` 若被 `trim` 掉首尾空格，会变成 `"X"` 导致列错位——务必按 3 字符定长处理。
