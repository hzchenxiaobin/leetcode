# LeetCode 可行数组的数目 题解

## 1. 题目概述

- **标题 / 题号**：可行数组的数目（#3468，medium）
- **链接**：https://leetcode.cn/problems/find-the-number-of-copy-arrays/
- **来源**：LeetCode 第 151 场双周赛 Q2
- **难度**：中等
- **标签**：数组、数学

**题意**：给定长度为 $n$ 的数组 `original` 和 $n \times 2$ 的二维数组 `bounds`（`bounds[i] = [uᵢ, vᵢ]`）。统计满足下面两个条件的长度为 $n$ 的数组 `copy` 的个数：

1. 对所有 $1 \le i \le n-1$，都有 $copy[i] - copy[i-1] = original[i] - original[i-1]$；
2. 对所有 $0 \le i \le n-1$，都有 $u_i \le copy[i] \le v_i$。

**约束**：

- $2 \le n \le 10^5$
- $1 \le original[i] \le 10^9$
- $bounds.length = n$，$1 \le u_i \le v_i \le 10^9$

## 2. 示例

**示例 1**

```text
输入：original = [1,2,3,4], bounds = [[1,2],[2,3],[3,4],[4,5]]
输出：2
解释：[1,2,3,4] 与 [2,3,4,5] 两组，都保持与原数组相同的相邻差 1。
```

**示例 2**

```text
输入：original = [1,2,3,4], bounds = [[1,10],[2,9],[3,8],[4,7]]
输出：4
解释：[1,2,3,4]、[2,3,4,5]、[3,4,5,6]、[4,5,6,7]，首项可以取 1~4。
```

**示例 3**

```text
输入：original = [1,2,1,2], bounds = [[1,1],[2,3],[3,3],[2,3]]
输出：0
解释：第 0 位必须取 1，但第 2 位被夹在 [3,3]，两者矛盾，无解。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的做法是枚举首项 $copy[0]$ 的所有可能取值（从 $\min u_i$ 到 $\max v_i$），再由差分条件唯一确定整个数组，逐项检查是否落在 `bounds` 内。单次检查 $O(n)$，而首项的值域可达 $10^9$，总复杂度 $O(10^9 \cdot n)$，显然不可行。

换个角度想：合法的 `copy` 之间只差一个**整体平移**，所以"枚举首项"的搜索空间其实是**一维**的。只要我们能把"首项必须满足什么"写成一个区间，问题就退化成数整数点。

### 3.2 核心观察：整条数组只能刚性平移

![刚性平移：整条 copy 相对 original 只能整体挪动](images/bw151_q2_offset_model.svg)

记 $d_i = original[i] - original[0]$（$d_0 = 0$，注意它可能为负，`original` 并不单调）。把差分条件逐项相加：

$$
copy[i] = copy[0] + \sum_{k=1}^{i}\big(original[k] - original[k-1]\big) = copy[0] + d_i
$$

也就是说：**一旦 $copy[0]$ 定了，其余每个位置的偏移量 $d_i$ 就全定了**，整条数组像一根刚性的尺子，只能左右平移。

接下来把边界条件代进去：

$$
u_i \le copy[0] + d_i \le v_i \iff u_i - d_i \le copy[0] \le v_i - d_i
$$

于是第 $i$ 个位置给 $copy[0]$ 贡献一个闭区间 $[L_i, R_i] = [u_i - d_i,\ v_i - d_i]$。所有位置同时满足，等价于

$$
copy[0] \in \Big[\max_i L_i,\ \min_i R_i\Big]
$$

答案就是交集中**整数**的个数。

### 3.3 算法流程

![每个位置翻译成一个区间，再求交集](images/bw151_q2_interval_intersect.svg)

```text
1. L = bounds[0][0], R = bounds[0][1]          # 用 long long
2. for i = 0 .. n-1:
       d  = original[i] - original[0]
       L  = max(L, bounds[i][0] - d)
       R  = min(R, bounds[i][1] - d)
3. 若 L > R: 返回 0
4. 返回 R - L + 1
```

因为区间取交满足交换律，顺序无关；一趟扫描即可完成，不需要额外数组。

### 3.4 示例演算

![示例 2 演算：四个区间逐步收窄到 1 至 4](images/bw151_q2_example_walkthrough.svg)

对示例 2：`original = [1,2,3,4]`，`d = [0,1,2,3]`。

| $i$ | $original[i]$ | $bounds[i]$ | $d_i$ | 对 $copy[0]$ 的区间 | 累计交集 |
|-----|---------------|-------------|-------|---------------------|----------|
| 0 | 1 | [1,10] | 0 | $[1,10]$ | $[1,10]$ |
| 1 | 2 | [2,9] | 1 | $[1,8]$ | $[1,8]$ |
| 2 | 3 | [3,8] | 2 | $[1,6]$ | $[1,6]$ |
| 3 | 4 | [4,7] | 3 | $[1,4]$ | $[1,4]$ |

交集为 $[1,4]$，整数个数 $4-1+1 = 4$，与输出 4 一致（见上图）。示例 1 的四段区间全是 $[1,2]$，交集大小 2；示例 3 的区间依次是 $[1,1],[1,2],[3,3],[1,2]$，$\max L = 3 > \min R = 1$，交集为空，输出 0。

## 4. 算法细节

1. **偏移量不假设单调**：$d_i$ 完全可能为负（例如 `original = [5,1,3]` 时 $d = [0,-4,-2]$），所以不能只看 $\max$ 与 $\min$ 的原始值，必须用 $d_i$ 逐项推区间。
2. **必须用 64 位整型**：$u_i \le 10^9$、$d_i \in (-10^9, 10^9)$，因此 $u_i - d_i$ 可能超出 `int` 范围（约 $\pm 2\times 10^9$），C++ 里要用 `long long`。
3. **答案范围**：交集长度最多 $10^9$（$1 \le copy[0] \le 10^9$），返回值是 `int`，但中间计算与最后一步 `R - L + 1` 建议都用 `long long` 再转 `int`。
4. **初始化技巧**：先在 $i = 0$ 处把 $L, R$ 设成 $bounds[0]$ 的上下界（$d_0 = 0$ 时区间就是 $[u_0,v_0]$），循环里从 $i = 0$ 开始也无妨，避免用 $-10^{18}$ 之类的哨兵值。

## 5. 正确性证明

**引理 1（差分定形）**：若 `copy` 满足条件 1，则对每个 $i$ 都有 $copy[i] = copy[0] + d_i$，其中 $d_i = original[i] - original[0]$。

**证明**：对 $i$ 归纳。$i = 0$ 时 $copy[0] = copy[0] + 0$ 成立。设 $copy[i-1] = copy[0] + d_{i-1}$，由条件 1 得

$$copy[i] = copy[i-1] + original[i] - original[i-1] = copy[0] + d_{i-1} + original[i] - original[i-1] = copy[0] + d_i$$

归纳完成。∎

**引理 2（逐位约束即区间）**：在引理 1 的前提下，$u_i \le copy[i] \le v_i$ 等价于 $L_i \le copy[0] \le R_i$，其中 $L_i = u_i - d_i$、$R_i = v_i - d_i$。

**证明**：把 $copy[i] = copy[0] + d_i$ 代入 $u_i \le copy[i] \le v_i$，两边同减 $d_i$ 即得。∎

**引理 3（计数）**：设 $L = \max_i L_i$、$R = \min_i R_i$，则满足全部约束的整数 $copy[0]$ 恰有 $\max(0, R - L + 1)$ 个。

**证明**：由引理 2，$copy[0]$ 需同时落入所有 $[L_i, R_i]$，即落入交集 $\bigcap_i [L_i,R_i] = [\max L_i, \min R_i] = [L, R]$（闭区间之交仍是闭区间）。闭区间 $[L,R]$ 中的整数个数当 $L \le R$ 时为 $R - L + 1$，否则为 0。∎

**定理**：算法返回的数等于满足条件的 `copy` 数组个数。

**证明**：由引理 1，每个合法 `copy` 由 $copy[0]$ 唯一确定，且不同 $copy[0]$ 给出不同数组（首项不同），故"数组个数 = 合法 $copy[0]$ 取值个数"。由引理 3，该个数为 $\max(0,R-L+1)$，算法返回的正是此值。∎

## 6. 复杂度分析

- **时间**：$O(n)$。一次遍历计算 $d_i$ 并收缩 $[L,R]$，每步常数次加减与比较，没有排序、没有二分。
- **空间**：$O(1)$ 额外空间（不计输入）。若要复现数组才需要 $O(n)$，本题只需要计数。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int countArrays(vector<int>& original, vector<vector<int>>& bounds) {
        long long lo = bounds[0][0], hi = bounds[0][1];
        for (int i = 0; i < (int)original.size(); i++) {
            long long d = (long long)original[i] - (long long)original[0];
            lo = max(lo, (long long)bounds[i][0] - d);
            hi = min(hi, (long long)bounds[i][1] - d);
        }
        if (lo > hi) return 0;
        return (int)(hi - lo + 1);
    }
};
```

### Python

```python
class Solution:
    def countArrays(self, original: list[int], bounds: list[list[int]]) -> int:
        lo, hi = bounds[0][0], bounds[0][1]
        for i, x in enumerate(original):
            d = x - original[0]
            lo = max(lo, bounds[i][0] - d)
            hi = min(hi, bounds[i][1] - d)
        return max(0, hi - lo + 1)
```

## 8. 边界情况与易错点

1. **`d_i` 可能为负**：这是本题最大的坑。$original$ 不保证单调，若误用"按差值累加都为正"的假设会算出错误的区间。
2. **溢出现场**：$u_i - d_i$ 与 $v_i - d_i$ 都可能达到 $2\times 10^9$ 量级，`int` 会溢出；C++ 用 `long long`，Python 天然无此问题。
3. **交集为空要显式判**：$L > R$ 时直接返回 0，绝不能返回负数。代码里 `if (lo > hi) return 0;` 这一行不能省。
4. **$n = 2$**：只有两个位置，两个区间相交即可，不需特判；但若把 $d_i$ 写成 `original[i]-original[i-1]`（前缀差而不是对 $original[0]$ 的差）就会错。
5. **返回值类型**：答案最大 $10^9$，能塞进 `int`，但中间量必须 64 位；否则 `R - L + 1` 在大值处先溢出后转类型，结果仍错。
6. **区间是闭区间**：答案不是 $R - L$，而是 $R - L + 1$，这是最常见的差一错误。
