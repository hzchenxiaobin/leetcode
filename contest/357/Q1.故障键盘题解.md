# LeetCode 故障键盘 题解

## 1. 题目概述

- **标题 / 题号**：故障键盘（#2810，easy）
- **链接**：https://leetcode.cn/problems/faulty-keyboard/
- **来源**：LeetCode 第 357 场周赛 Q1
- **难度**：简单
- **标签**：字符串、模拟、双端队列

**题意**：笔记本键盘坏了——每输入一个字符 `'i'`，屏幕上已有的字符串会整体反转；输入其他字符行为正常。给定字符串 `s`，按顺序依次输入其中的每个字符，返回最终屏幕上的字符串。

**约束**：

- `1 <= s.length <= 100`
- `s` 由小写英文字母组成
- `s[0] != 'i'`

## 2. 示例

**示例 1**

```text
输入：s = "string"
输出："rtsng"
解释：
输入第 1 个字符后，屏幕上的文本是："s" 。
输入第 2 个字符后，屏幕上的文本是："st" 。
输入第 3 个字符后，屏幕上的文本是："str" 。
因为第 4 个字符是 'i' ，屏幕上的文本被反转，变成 "rts" 。
输入第 5 个字符后，屏幕上的文本是："rtsn" 。
输入第 6 个字符后，屏幕上的文本是： "rtsng" 。
因此，返回 "rtsng" 。
```

**示例 2**

```text
输入：s = "poiinter"
输出："ponter"
解释：p、o 正常输入得 "po"；第 3 个字符 'i' 把屏幕反转成 "op"；
第 4 个字符又是 'i'，再反转回 "po"——两次反转相互抵消；
随后 n、t、e、r 正常追加，最终得到 "ponter" 。
```

## 3. 解题思路

### 3.1 暴力思路

直接模拟：维护一个字符列表 `res`，逐个处理 `s` 中的字符——遇到 `'i'` 就整体反转，其他字符追加到末尾：

```python
res = []
for c in s:
    if c == 'i':
        res.reverse()
    else:
        res.append(c)
return ''.join(res)
```

每次反转 $O(n)$，最坏（如 `"aiii…i"`）总时间 $O(n^2)$。本题 $n \le 100$，比赛时直接交即可。

### 3.2 核心观察：惰性反转——双端队列 + 方向标志

![核心观察：'i' 不搬数据，只翻转方向标志](images/faulty_keyboard_deque_concept.svg)

`'i'` 的语义是"把现有内容整体反转"。与其每次真的把数据搬一遍，不如**只记一个方向标志 `flag`，把"反转"惰性化**：

- 维护一个**双端队列** `dq` 和一个布尔标志 `flag`（当前屏幕的阅读方向）；
- `flag = →`（正向）：新字符 `push_back` 进**尾端**，屏幕 = `dq` **从左往右**读；
- `flag = ←`（反向）：新字符 `push_front` 进**头端**，屏幕 = `dq` **从右往左**读；
- 遇到 `'i'`：**只翻转 `flag`，不动任何数据**——一次"反转" $O(1)$ 完成。

> 💡 直观理解：**"反转"改变的是阅读方向，而不是内容的位置**。把"往哪边读"记在 `flag` 里，新字符按当前方向放进"正确的一端"，就等价于"先反转再追加"。

由此还有一个直接推论：**连续的 `'i'` 两两抵消**（反转偶数次等于没反转），如示例 2 的 `"poiinter"`。

### 3.3 算法流程

![算法流程：'i' 翻标志，其他字符按方向入队](images/faulty_keyboard_algorithm_flow.svg)

1. 初始化空双端队列 `dq`，`flag = false`（正向）；
2. 顺序扫描 `s` 的每个字符 `c`：
   - `c == 'i'`：`flag = !flag`（`'i'` 本身不进结果）；
   - `c != 'i'`：`flag` 正向则 `push_back(c)`，反向则 `push_front(c)`；
3. 扫描结束：`flag` 正向则从左到右拼接 `dq` 输出，反向则从右到左拼接输出。

### 3.4 示例演算

![示例演算：s = string 的逐步走查](images/faulty_keyboard_example_walkthrough.svg)

以 `s = "string"` 为例逐行走查：

| 步 | c | 动作 | dq（头→尾） | flag | 屏幕 |
|----|---|------|-------------|------|------|
| 1 | s | push_back | s | → | "s" |
| 2 | t | push_back | s t | → | "st" |
| 3 | r | push_back | s t r | → | "str" |
| 4 | i | flag = !flag | s t r（不动） | ← | "rts" |
| 5 | n | push_front | **n** s t r | ← | "rtsn" |
| 6 | g | push_front | **g** n s t r | ← | "rtsng" |

最终 `flag = ←`，从右往左读 `dq` 得 `"rtsng"` ✓。注意第 4 步 `'i'` 到来时 `dq` 完全不动，第 5、6 步的新字符改从头端进——这正是"惰性反转"在工作。

## 4. 算法细节

1. **数据结构**：`deque<char>`（C++）/ `collections.deque`（Python），两端插入均摊 $O(1)$。
2. **方向语义**：`flag = false` 表示正向（屏幕 = `dq` 左→右）；`flag = true` 表示反向（屏幕 = `dq` 右→左）。
3. **插入端点**：正向时新字符进尾端（等价于普通追加）；反向时新字符进头端（等价于"先反转屏幕、再追加、再反转回来"——旧内容相对新字符恰好都在右边）。
4. **输出**：`flag = false` 时从 `begin` 到 `end` 拼接，`flag = true` 时从 `rbegin` 到 `rend` 拼接；**全程只在最后读一次**。
5. **`'i'` 不入队**：`'i'` 只触发翻转，本身不出现在结果里。

## 5. 正确性证明

**引理 1**（不变量）：任意时刻，屏幕上的内容等于按 `flag` 当前方向读取 `dq` 得到的串（正向读为 $dq_0\,dq_1\cdots dq_{k-1}$，反向读为 $dq_{k-1}\cdots dq_1\,dq_0$）。

**证明**：对已处理的字符数做归纳。

- 初始时刻：`dq` 为空、`flag` 正向、屏幕为空，不变量成立。
- 假设某时刻不变量成立，考察处理下一个字符 `c`：
  - 若 $c = \texttt{'i'}$：屏幕变为原屏幕的反转串；算法仅翻转 `flag`，而按新方向读 `dq` 恰好得到原读取串的反转，不变量保持。
  - 若 $c \ne \texttt{'i'}$ 且 `flag` 正向：屏幕变为 $R + c$（$R$ 为原屏幕）；算法 `push_back(c)` 后正向读 `dq` 也是 $R + c$，成立。
  - 若 $c \ne \texttt{'i'}$ 且 `flag` 反向：屏幕变为 $R + c$；算法 `push_front(c)` 后，反向读（右→左）先读出全部旧内容（即 $R$），最后读到头端的 $c$，也是 $R + c$，成立。∎

**定理**：算法返回的字符串等于依次输入 `s` 各字符后屏幕上的字符串。

**证明**：对 `s` 的每个前缀反复应用引理 1，处理完所有字符后不变量依然成立；此时按 `flag` 方向读取 `dq` 即为最终屏幕内容，而这正是算法的输出步骤。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。每个字符要么 $O(1)$ 翻转 `flag`，要么均摊 $O(1)$ 地在双端队列一端插入；最后 $O(n)$ 读出一次。
- **空间复杂度**：$O(n)$。`dq` 存放除 `'i'` 外的所有字符，最坏 $n$ 个。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    string finalString(string s) {
        deque<char> dq;
        bool rev = false;
        for (char c : s) {
            if (c == 'i') {
                rev = !rev;
            } else if (rev) {
                dq.push_front(c);
            } else {
                dq.push_back(c);
            }
        }
        return rev ? string(dq.rbegin(), dq.rend())
                   : string(dq.begin(), dq.end());
    }
};
```

### Python

```python
from collections import deque

class Solution:
    def finalString(self, s: str) -> str:
        dq = deque()
        rev = False
        for c in s:
            if c == 'i':
                rev = not rev
            elif rev:
                dq.appendleft(c)
            else:
                dq.append(c)
        return ''.join(reversed(dq)) if rev else ''.join(dq)
```

## 8. 边界情况与易错点

1. **`'i'` 不进结果**：`'i'` 只负责翻转，不要把它当普通字符追加进 `dq`。
2. **连续 `'i'` 两两抵消**：如 `"aii"` 结果为 `"a"`；写成 `flag = !flag` 天然处理，无需特判。
3. **末尾是 `'i'`**：如 `"abi"`，最后一步翻转后 `flag = ←`，输出时必须记得按反向读，否则得到 `"ab"` 而非正确答案 `"ba"`。
4. **`s[0] != 'i'`**：题目保证首字符不是 `'i'`（对空串反转无意义），首个字符必然走追加分支，无需特判。
5. **别用字符串 `+` 硬拼**：Python 中 `res = res + c` 每次分配新串，且反转切片 `res[::-1]` 每次 $O(n)$；用列表/双端队列更稳。
6. **暴力也能过**：$n \le 100$ 时直接 `reverse()` 的 $O(n^2)$ 模拟同样 AC；双端队列解法的价值在于 $n$ 放大到 $10^6$ 量级时依然是线性。
