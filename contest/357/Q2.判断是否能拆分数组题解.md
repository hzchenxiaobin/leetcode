# LeetCode 判断是否能拆分数组 题解

## 1. 题目概述

- **标题 / 题号**：判断是否能拆分数组（#2811，medium）
- **链接**：https://leetcode.cn/problems/check-if-it-is-possible-to-split-array/
- **来源**：LeetCode 第 357 场周赛 Q2
- **难度**：中等
- **标签**：贪心、数组、动态规划

**题意**：给定长度为 $n$ 的数组 `nums` 与整数 $m$。从整个数组出发，每一步可以挑选一个**长度至少为 2** 的现有数组切成两段，且切出的**每一段都必须是「好」的**：长度为 $1$，或元素之和 $\ge m$。判断能否经过若干步，把数组完全拆成 $n$ 个数组（即全部化为长度 $1$ 的单元）。

**约束**：

- $1 \le n = \text{nums.length} \le 100$
- $1 \le \text{nums}[i] \le 100$
- $1 \le m \le 200$

## 2. 示例

**示例 1**

```text
输入：nums = [2, 2, 1], m = 4
输出：true
解释：[2,2,1] → [2,2] + [1]：[2,2] 长度 2 但和 4 ≥ 4，[1] 长度 1，两段都好；
      再把 [2,2] → [2] + [2]，两个长度 1，天然好。
```

**示例 2**

```text
输入：nums = [2, 1, 3], m = 5
输出：false
解释：第一刀只有两种切法——
      [2] + [1,3]：[1,3] 长度 2 但和 4 < 5，不是好数组；
      [2,1] + [3]：[2,1] 长度 2 但和 3 < 5，不是好数组。
      第一刀就下不去 → false。
```

**示例 3**

```text
输入：nums = [2, 3, 3, 2, 3], m = 6
输出：true
解释：中间的相邻对 3 + 3 = 6 ≥ 6 是「锚点」。保住它不动，依次剥出
      [2]、[3]、[2]，每次剩余段都含锚点对、和 ≥ 6；最后 [3,3] 一分为二。
```

## 3. 解题思路

### 3.1 暴力思路：指数搜索与区间 DP

最直接的想法是**枚举整个切分树**：每一步对所有长度 $\ge 2$ 的段枚举切点，搜索所有拆分序列——状态数是卡塔兰数级别的指数复杂度，$n = 100$ 完全不可行。

注意到每次操作只作用于**一个连续段**，且「好」只由段自身决定（长度 1 或和 $\ge m$），可以升级为**区间 DP**：

$$f(l, r) \;=\; \bigvee_{k=l}^{r-1} \Big[\, g(l,k) \,\wedge\, g(k{+}1,r) \,\wedge\, f(l,k) \,\wedge\, f(k{+}1,r) \Big]$$

其中 $g(a,b) = (a = b) \lor (\text{sum}(a..b) \ge m)$ 表示「段是好数组」，$f(l,r)$ 表示「段能被完整拆成单元」。答案为 $f(0, n-1)$。$O(n^3)$ 约 $10^6$ 次判断，比赛时是稳妥的保底做法。

但它没有回答本质问题：**这道题的答案到底由什么决定？** 数据范围小到纵容 $O(n^3)$，可一旦把 $n$ 放大到 $10^5$，DP 就失效了——需要看穿结构。

### 3.2 核心观察：答案只取决于「是否存在一对和 ≥ m 的相邻元素」

![核心观察：锚定一对相邻元素，其余逐个剥离](images/wc357_q2_adjacent_pair_concept.svg)

先看两个平凡情形：

- $n = 1$：无需任何操作，答案 `true`；
- $n = 2$：唯一的一刀切成两个长度 1 的单元，天然都是好数组，答案 `true`。

当 $n \ge 3$ 时，结论非常干净：

$$\text{答案} = \text{true} \iff \exists\, i \in [0, n-2],\ \text{nums}[i] + \text{nums}[i{+}1] \ge m$$

> 💡 **一句话直觉**：找一个「锚点对」——和达到 $m$ 的相邻二元组，**保住它不分开**，其余元素一个个从两端剥出去。切出的单元素段长度 1 天然好；剩余段永远**包含锚点对**，其和 $\ge \text{nums}[i] + \text{nums}[i{+}1] \ge m$，也必然是好数组。剥到最后只剩锚点对本身，一刀两半，全程合法。

回头看**示例 2** 为什么 false：相邻对 $(2,1)$、$(1,3)$ 的和分别为 $3$、$4$，全 $< 5$，没有任何锚点可保。第一刀切出的两段中必有一段长度 $\ge 2$，而两种切法下这一段的和都 $< 5$——第一刀就违法。必要性的一般性证明见 §5 的归纳论证。

而**示例 3** 里 $3 + 3 = 6 \ge 6$ 恰好踩线达标，整条剥离链路都能走通——这正是锚点对在工作的样子（逐步走查见 §3.4）。

### 3.3 算法流程

![算法流程：特判 n ≤ 2，一趟扫描相邻对](images/wc357_q2_decision_flow.svg)

1. 若 $n \le 2$：返回 `true`；
2. 令 $i$ 从 $0$ 扫到 $n-2$：若 $\text{nums}[i] + \text{nums}[i{+}1] \ge m$，立即返回 `true`；
3. 扫描结束仍未命中：返回 `false`。

### 3.4 示例演算

![示例演算：false 用相邻对扫描，true 用剥离构造](images/wc357_q2_example_walkthrough.svg)

**示例 2（false）**：$[2,1,3]$，$m=5$。相邻对 $2+1=3$、$1+3=4$，均 $< 5$ → 没有锚点 → `false`。

**示例 3（true）**：$[2,3,3,2,3]$，$m=6$。锚点对为下标 1、2 处的 $3+3=6 \ge 6$，剥离构造如下：

| 刀 | 操作 | 切出段 | 剩余段 | 两段合法性 |
|----|------|--------|--------|------------|
| 1 | 在下标 0 后切 | $[2]$ | $[3,3,2,3]$ | 长度 1 ✓；和 $11 \ge 6$ ✓ |
| 2 | 在下标 3 前切 | $[3]$ | $[3,3,2]$ | 长度 1 ✓；和 $8 \ge 6$ ✓ |
| 3 | 在下标 2 前切 | $[2]$ | $[3,3]$ | 长度 1 ✓；和 $6 \ge 6$ ✓ |
| 4 | 从中间切 | $[3]$ | $[3]$ | 长度 1 ✓；长度 1 ✓ |

四刀全部合法 → `true`。注意每一行的「剩余段」都包含锚点对 $(3,3)$——这正是不变量在发挥作用。

## 4. 算法细节

1. **判据的形状**：只看**相邻对**之和，不是前缀和、不是总和。例 2 总和 $6 \ge 5$ 仍然是 `false`；决定成败的是「局部相邻的二元组」。
2. **特判必须在前**：$n \le 2$ 时要么不存在相邻对（$n=1$），要么唯一切法无需任何和条件（$n=2$），都直接 `true`，不能落入扫描逻辑。
3. **构造的剥离顺序**：充分性构造中，从哪一端、按什么顺序剥外侧元素都无所谓——每一步剩余段始终含锚点对，不变量不破坏；实现时根本不用模拟剥离，一次扫描即可。
4. **不需要前缀和**：只比较两个相邻元素，直接相加即可；区间 DP 版才需要前缀和做 $O(1)$ 区间和。
5. **比赛策略**：若赛时没悟出贪心结论，区间 DP $O(n^3)$ 是可靠退路（$n \le 100$）；两个解法都能 AC，但贪心是「看穿结构」的那个解。

## 5. 正确性证明

**引理 1（充分性）**：若 $n \ge 3$ 且存在 $i \in [0, n-2]$ 使 $\text{nums}[i] + \text{nums}[i{+}1] \ge m$，则答案为 `true`。

**证明**：给出构造。称 $(\text{nums}[i], \text{nums}[i{+}1])$ 为锚点对，执行如下操作序列：

- 重复把**当前段最左端**的元素单独切出，共 $i$ 刀，直到锚点对到达段首；
- 重复把**当前段最右端**的元素单独切出，共 $n-2-i$ 刀，直到段只剩锚点对；
- 最后一刀把锚点对切成两个单元。

对刀数归纳验证：任何时刻的当前段（若长度 $\ge 2$）都包含锚点对，且**其余元素均为正数**（题设 $\text{nums}[j] \ge 1$），故当前段之和 $\ge \text{nums}[i] + \text{nums}[i{+}1] \ge m$，是好数组。于是每一刀切出的两段——单元素段长度 1 天然好，新当前段仍含锚点对、和 $\ge m$ 也好——全部合法；最后一刀切出两个长度 1 的段。构造成功。∎

**引理 2（必要性）**：若 $n \ge 3$ 且答案为 `true`，则存在 $i \in [0, n-2]$ 使 $\text{nums}[i] + \text{nums}[i{+}1] \ge m$。

**证明**：对 $n$ 强归纳，证明其逆否命题：**若所有相邻对之和 $< m$，则不存在合法的完整拆分**。

- 基础 $n = 3$：第一刀切成 $1+2$ 或 $2+1$ 两段，长度 2 的那段是好数组且长度 $\ge 2$，故其和 $\ge m$；但它是原数组的一对**相邻元素**，与「所有相邻对之和 $< m$」矛盾。
- 归纳步 $n \ge 4$：反设存在合法完整拆分，考察其**第一刀**：$\text{nums} = X \cdot Y$（$X, Y$ 为连续段），两段都是好数组。由 $n \ge 3$ 知两段长度之和 $\ge 3$，不妨设 $|X| \ge 2$，则 $\text{sum}(X) \ge m$：
  - 若 $|X| = 2$：$X$ 本身就是一对和 $\ge m$ 的相邻元素，矛盾；
  - 若 $|X| \ge 3$：方案中对 $X$ 及其子段的后续切分，构成 $X$ 的一个合法完整拆分（「好」只取决于段自身），且 $3 \le |X| \le n-1 < n$，由归纳假设，$X$ 内部存在和 $\ge m$ 的相邻对。$X$ 是 `nums` 的连续段，该对在原数组中同样相邻，矛盾。

两种情形均矛盾，逆否命题成立。∎

**定理**：答案为 `true` $\iff$ $n \le 2$，或存在 $i \in [0, n-2]$ 使 $\text{nums}[i] + \text{nums}[i{+}1] \ge m$。

**证明**：$n \le 2$ 直接验证：$n=1$ 无需操作；$n=2$ 唯一可行的切分产生两个长度 1 的段，天然好。$n \ge 3$ 时，由引理 1（$\Leftarrow$）与引理 2（$\Rightarrow$）合并即得。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。一次线性扫描检查 $n - 1$ 个相邻对，每对 $O(1)$；区间 DP 版为 $O(n^3)$，在 $n \le 100$ 下约 $10^6$，同样可过但远超必要。
- **空间复杂度**：$O(1)$。只用常数个变量；区间 DP 版为 $O(n^2)$（DP 表 + 前缀和）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool canSplitArray(vector<int>& nums, int m) {
        int n = nums.size();
        if (n <= 2) return true;
        for (int i = 0; i + 1 < n; ++i)
            if (nums[i] + nums[i + 1] >= m) return true;
        return false;
    }
};
```

### Python

```python
class Solution:
    def canSplitArray(self, nums: List[int], m: int) -> bool:
        if len(nums) <= 2:
            return True
        return any(a + b >= m for a, b in zip(nums, nums[1:]))
```

### 备选：区间 DP（赛时保底写法）

```python
from functools import lru_cache

class Solution:
    def canSplitArray(self, nums: List[int], m: int) -> bool:
        n = len(nums)
        pre = [0]
        for x in nums:
            pre.append(pre[-1] + x)

        def good(a, b):                      # [a..b] 是否为好数组
            return a == b or pre[b + 1] - pre[a] >= m

        @lru_cache(None)
        def f(l, r):                         # [l..r] 能否完整拆成单元
            if l == r:
                return True
            return any(good(l, k) and good(k + 1, r)
                       and f(l, k) and f(k + 1, r)
                       for k in range(l, r))

        return f(0, n - 1)
```

## 8. 边界情况与易错点

1. **特判顺序**：`n <= 2` 的判断必须在扫描之前——$n=1$ 时不存在相邻对，$n=2$ 时答案恒真，若先进入扫描会错误返回 `false`。
2. **是 `>=` 不是 `>`**：示例 3 中 $3 + 3 = 6$ 恰好等于 $m$，卡在边界上；用严格大于会 WA。
3. **别拿总和当判据**：$[2,1,3]$、$m=5$ 总和 $6 \ge 5$ 仍是 `false`；决定性的是**相邻**二元组的和。
4. **扫描边界**：$i \in [0, n-2]$，循环条件写成 `i + 1 < n`，避免越界。
5. **区间 DP 的两个坑**：长度 1 的段既「好」又「可拆分」，转移时不能再对它要求和 $\ge m$；整个原数组**自身不需要是好数组**——最终答案就是 `f(0, n-1)`，不要再额外套一层 `good(0, n-1)`。
6. **数据范围**：$n \le 100$、$\text{nums}[i] \le 100$、$m \le 200$，相邻对之和最大 200，`int` 毫无溢出风险。真正值得沉淀的是：把 $n$ 放大到 $10^5$ 时，唯有 $O(n)$ 的贪心结论存活。

**延伸思考**：
1. 若要求**恰好拆成 $k$ 段**（$k < n$）且每段仍需「好」，单对扫描不再够用——需按「前 $i$ 个元素拆成 $j$ 段」做划分 DP，用前缀和判段的好坏；
2. 若「好」**不豁免长度 1**（单元也要求和 $\ge m$），判据退化为「每个元素 $\ge m$」——此时任何切法都合法，问题的结构完全塌缩；
3. 题设 $\text{nums}[i] \ge 1 > 0$ 是贪心成立的隐藏前提：必要性（引理 2）对任意整数都成立，但充分性构造依赖「剩余段和 $\ge$ 锚点对和」——外围元素必须非负。若允许负数，贪心会**误判**：反例 $[5,5,-10,5,5]$、$m=10$，存在和恰为 $10$ 的相邻对 $(5,5)$，但无论怎么切都凑不出两段同时 $\ge 10$（DP 验证为 `false`），只能回退区间 DP。
