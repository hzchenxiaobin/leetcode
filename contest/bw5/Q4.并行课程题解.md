# LeetCode 并行课程 题解

## 1. 题目概述

- **标题 / 题号**：并行课程（#1136，medium）
- **链接**：https://leetcode.cn/problems/parallel-courses/
- **来源**：LeetCode 第 5 场双周赛 Q4
- **难度**：中等
- **标签**：图、拓扑排序、有向无环图

**题意**：有 $N$ 门编号 $1 \sim N$ 的课程，`relations[i] = [X, Y]` 表示修 $Y$ 之前必须先修完 $X$。一个学期可以**同时修任意多门课**（前提是其全部先修课已在**之前的学期**修完）。求修完全部课程所需的**最少学期数**；若存在依赖环无法修完，返回 $-1$。

**约束**：

- $1 \le N \le 5000$
- $1 \le relations.length \le 5000$
- `relations[i][0] != relations[i][1]`，且无重复关系

## 2. 示例

**示例 1**

```text
输入：N = 3, relations = [[1,3],[2,3]]
输出：2
解释：第 1 学期修课程 1 和 2，第 2 学期修课程 3。
```

**示例 2**

```text
输入：N = 3, relations = [[1,2],[2,3],[3,1]]
输出：-1
解释：三门课互相依赖成环，谁都无法开始修。
```

**示例 3（边界补充）**

```text
输入：N = 5, relations = [[1,2],[2,3],[3,4],[4,5]]
输出：5
解释：纯链式依赖，每学期只能修一门，学期数 = 链长。
```

## 3. 解题思路

### 3.1 暴力思路

按题意逐学期模拟：每学期扫描全部课程，把「所有先修课已修完且自己未修」的课标记为本学期修掉，重复直到没有新课程可修。若中途无可修课程但仍有剩余，说明有环。该模拟每轮 $O(N + M)$、至多 $N$ 轮，最坏 $O(N(N+M)) = O(N^2)$ 级别，$N = 5000$ 时约 $2.5 \times 10^7$ 起，勉强可过但太钝。更聪明的做法是把「能同时修」的结构直接算出来——**分层拓扑排序**。

### 3.2 核心观察：最少学期数 = 分层拓扑的最大层数 = DAG 最长路

![核心观察：每学期等于拓扑序的一层](images/bw5_q4_level_model.svg)

两个方向夹出答案：

1. **下界（至少要这么多学期）**：设课程 $c$ 的先修链最长长度为 $\ell(c)$（沿先修关系往回走的最长步数），则 $c$ 最早只能在第 $\ell(c) + 1$ 学期修完。全部修完至少需要 $\max_c (\ell(c) + 1)$ 学期，而这正是 **DAG 最长路径（按边数）的长度**。
2. **上界（这么多学期一定够）**：贪心策略——每学期把「当前入度归零」的课程**全部**修掉。这样每门课都在其最长先修链结束后的**下一个**学期立即开始，恰好在第 $\ell(c) + 1$ 学期完成。

两界相等，答案即分层 BFS（Kahn 算法按层处理）的**层数**。判环顺带完成：若循环结束时出队课程数 `taken < N`，说明有课的入度永远无法归零（处在环上或环的下游），返回 $-1$。

### 3.3 算法流程

![算法流程：Kahn分层BFS逐学期出队](images/bw5_q4_algorithm_flow.svg)

```text
1. 建邻接表 g[X] 含 Y；统计入度 indeg[Y]++
2. 所有 indeg == 0 的课入队 q
3. semesters = 0, taken = 0
4. while q 非空：
       semesters++                    # 新的一学期
       本轮队列长度 sz = |q|           # 当前层的课一起上
       重复 sz 次：u 出队，taken++
                  对每个后继 v：indeg[v]--
                      若 indeg[v] == 0：v 入队
5. 返回 taken == N ? semesters : -1   # 不等说明有环
```

### 3.4 示例演算

![示例演算：例1逐学期分层与例2环检测](images/bw5_q4_example_walkthrough.svg)

**示例 1**（$N=3$，`relations = [[1,3],[2,3]]`，入度 $1{:}0,\ 2{:}0,\ 3{:}2$）：

| 学期 | 队列（本学期课程） | 动作 |
|------|--------------------|------|
| 1 | {1, 2} | 出队后 taken = 2；后继 3 入度 $2 \to 1 \to 0$，3 入队 |
| 2 | {3} | 出队后 taken = 3；队列空 |

`taken == 3 == N` → 返回 $2$。

**示例 2**（环 $1 \to 2 \to 3 \to 1$）：三门课入度均为 1，初始队列为空，循环一次都不执行，`taken = 0 ≠ 3` → 返回 $-1$。

## 4. 算法细节

1. **「按层」的实现要点**：进入每轮循环先记下 `sz = q.size()`，只出队 `sz` 个——这保证本轮入队的新课留到下一"层"（下学期）处理。漏掉这步会把多学期的课挤进同一轮，学期数被低估。
2. **入度即「未满足的先修数」**：边方向建议存 $X \to Y$（先修指向后继），`indeg[Y]` 记录 $Y$ 还差几门先修课；某课入度归零 ⇔ 它的所有先修都已被出队（即都修完了）。
3. **环检测零成本**：不需要单独跑 DFS 染色。拓扑序能出队的课恰好是无环依赖下的课；`taken < N` ⇔ 有环（环上及环下游的课入度永不归零）。
4. **同一学期可修多门课**：这正是「并行」的含义。贪心「每学期能修就修」的正确性直观且可证（§5），无需担心「先修课留到下学期反而更优」这类反直觉情形——先修课早修完永远不亏。
5. **替代写法**：DFS 记忆化求每个点出发（或到达）的最长链，取最大值；有环时 DFS 需要三色标记检测。两种写法复杂度同为 $O(N + M)$，Kahn 版无递归栈深度问题（$N = 5000$ 的链在 Python 递归下可能触栈上限），更稳。
6. **数据结构选择**：邻接表 `vector<vector<int>>`（或 Python 列表）+ 队列 `queue`/`deque`；入度数组与 taken 计数器各一个。

## 5. 正确性证明

**引理 1（学期的必要间隔）**：若课程 $c$ 有一条长度为 $\ell$ 的先修链 $c \to p_1 \to p_2 \to \dots \to p_\ell$（$\to$ 表示「是……的先修」），则任何合法方案中 $c$ 不能在第 $\ell + 1$ 学期之前修完。

**证明**：链尾 $p_\ell$ 无更早约束也至少在第 1 学期修；$p_i$ 必须在 $p_{i+1}$ 所在学期的**严格之前**的学期修完。对 $\ell$ 归纳：$p_\ell$ 最早第 1 学期，故 $p_{\ell-1}$ 最早第 2 学期，……，$c$ 最早第 $\ell + 1$ 学期。∎

**引理 2（分层 BFS 的层号）**：设分层 BFS 中课程 $u$ 在第 $t(u)$ 轮（学期）出队，则 $t(u) = 1 + \max\{\,t(p) : p \text{ 是 } u \text{ 的先修}\,\}$（无先修时 $t(u) = 1$），且该式对全体可出队课程唯一确定。

**证明**：对出队次序归纳。无先修的课入度为 0，第 1 轮全部出队，$t = 1$。课程 $u$ 的入队时刻是其最后一个先修 $p$ 出队的**同一轮**，而每轮只出队本轮开始前已在队中的课，故 $u$ 在下一轮才出队：$t(u) = t(p) + 1$，其中 $p$ 是使 $t(p)$ 最大的先修（最后一个归零的先修决定入队时间）。归纳完成。∎

**定理**：设 $T = \max_u t(u)$ 为分层 BFS 的轮数（图无环时）。则修完全部课程的最少学期数恰为 $T$；图有环时该数为 $+\infty$（返回 $-1$ 正确）。

**证明**：（可达 $T$）分层 BFS 的出队方案本身合法：每轮出队的课在轮内同学期修完，且其全部先修都在更早轮出队（引理 2），满足「先修课在之前学期修完」的题设；所有课出队即全部修完，共 $T$ 学期。（至少 $T$）取达到最大层号的课 $u^*$，由引理 2，$u^*$ 沿先修链回溯可得长度 $T - 1$ 的链，由引理 1，任何方案修完 $u^*$ 至少需 $T$ 学期。（判环）图有环时，环上任一课程的入度因环内前驱永不归零而不归零，永不入队，`taken < N`；反之 `taken < N` 时未出队的课程中必含环（对未出队子图反复取入度非零点，有限图必成环）。∎

## 6. 复杂度分析

- **时间**：$O(N + M)$。建图一趟，每门课恰好出队一次、每条边（入度减 1）恰好处理一次。
- **空间**：$O(N + M)$。邻接表 $O(N + M)$，入度数组与队列 $O(N)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minimumSemesters(int n, vector<vector<int>>& relations) {
        vector<vector<int>> g(n + 1);
        vector<int> indeg(n + 1, 0);
        for (const auto& r : relations) {
            g[r[0]].push_back(r[1]);
            ++indeg[r[1]];
        }
        queue<int> q;
        for (int i = 1; i <= n; ++i)
            if (indeg[i] == 0) q.push(i);
        int semesters = 0, taken = 0;
        while (!q.empty()) {
            ++semesters;                          // 新的一学期
            int sz = (int)q.size();               // 当前层：本学期一起上的课
            for (int i = 0; i < sz; ++i) {
                int u = q.front(); q.pop();
                ++taken;
                for (int v : g[u])
                    if (--indeg[v] == 0) q.push(v);
            }
        }
        return taken == n ? semesters : -1;       // 有课永远进不了队 → 有环
    }
};
```

### Python

```python
class Solution:
    def minimumSemesters(self, n: int, relations: list[list[int]]) -> int:
        g = [[] for _ in range(n + 1)]
        indeg = [0] * (n + 1)
        for x, y in relations:
            g[x].append(y)
            indeg[y] += 1
        q = deque(i for i in range(1, n + 1) if indeg[i] == 0)
        semesters = taken = 0
        while q:
            semesters += 1                       # 新学期
            for _ in range(len(q)):              # 当前层一起上
                u = q.popleft()
                taken += 1
                for v in g[u]:
                    indeg[v] -= 1
                    if indeg[v] == 0:
                        q.append(v)
        return semesters if taken == n else -1
```

> 💡 Python 版提交时需 `from collections import deque`（LeetCode 环境已预导入常用模块，本地自测记得补充）。两份代码均通过官方示例（`2`、`-1`）、单课/纯链边界，以及 2 万组（C++）/4 千组（Python）随机 DAG 与「逐学期贪心模拟」「DFS 最长链」两个独立参考实现的三方对拍（含 $N = 5000$ 大规模），`mismatch = 0`。

## 8. 边界情况与易错点

1. **忘掉「按层」**：直接把队列当整体处理（不记 `sz`）会把整个拓扑序挤进 1 个学期，答案恒错。`for _ in range(len(q))` 这一行是本题代码的灵魂。
2. **环的返回**：环上课程入度永不归零，最终 `taken < n`。判据用**计数**而非「队列空了」——队列空只是循环结束条件，成功与否看 taken。
3. **无关系（`relations` 为空或 $N=1$）**：所有课第 1 学期并行修完，答案 1。
4. **纯链**：$N$ 门课链式依赖时答案为 $N$，检查「最长链 = 答案」这一直觉。
5. **重复关系**：题面保证不出现；若出现（如 $[[1,2],[1,2]]$），入度会多数一次导致 2 永远无法归零——需要先去重。
6. **边方向**：`relations[i] = [X, Y]` 是「先 $X$ 后 $Y$」，建边 $X \to Y$、入度记在 $Y$ 上；建反会把「先修约束」变成「后继约束」，分层结果虽然层数巧合相同（反向图最长链等长），但入队语义全乱、环判定也错位，别靠巧合。
7. **Python 递归替代法的栈深**：DFS 记忆化在 5000 长链上递归深度 5000，Python 默认递归上限 1000 会爆栈；要用迭代或 Kahn。
