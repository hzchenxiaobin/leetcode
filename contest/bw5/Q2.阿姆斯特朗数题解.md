# LeetCode 阿姆斯特朗数 题解

## 1. 题目概述

- **标题 / 题号**：阿姆斯特朗数（#1134，easy）
- **链接**：https://leetcode.cn/problems/armstrong-number/
- **来源**：LeetCode 第 5 场双周赛 Q2
- **难度**：简单
- **标签**：数学

**题意**：一个 $k$ 位数 $N$ 是**阿姆斯特朗数**（Armstrong number，又称自恋数 narcissistic number），当且仅当它**每一位数字的 $k$ 次幂之和等于它自身**。给定正整数 $N$，判断它是否为阿姆斯特朗数。

**约束**：

- $1 \le N \le 10^8$

## 2. 示例

**示例 1**

```text
输入：n = 153
输出：true
解释：153 是 3 位数，1³ + 5³ + 3³ = 1 + 125 + 27 = 153。
```

**示例 2**

```text
输入：n = 123
输出：false
解释：123 是 3 位数，1³ + 2³ + 3³ = 36 ≠ 123。
```

**示例 3（边界补充）**

```text
输入：n = 5
输出：true
解释：5 是 1 位数，5¹ = 5，所有一位数都是阿姆斯特朗数。
```

## 3. 解题思路

### 3.1 暴力思路

把 $N$ 转成字符串，位数 $k$ 就是串长，对每个字符取数字计算 $k$ 次幂求和再与 $N$ 比较。这本身已经是 $O(k^2)$（每位一次 $k$ 次乘法）的做法，$k \le 9$，怎么写都能过。真正的「暴力陷阱」在于**幂的写法**：每次调用库函数 `pow`（浮点实现）可能在边界上产生 $1$ ulp 的误差，把 `pow(10, 8)` 算成 `99999999.99…` 截断后差 1。正确姿势是用整数循环乘法（或 Python 的整数 `**`）。

### 3.2 核心观察：模 10 剥位，除 10 去位

![核心观察：模10与除10逐位取数](images/bw5_q2_digit_split_model.svg)

不借助字符串，仅用整数运算即可逐位拆解 $N$：

- $d = N \bmod 10$ 取出**最低位**；
- $N \gets \lfloor N / 10 \rfloor$ 把最低位**丢掉**；
- 重复直到 $N = 0$，共执行 $k$ 次（$k$ 为位数）。

于是算法是两遍循环：第一遍数出位数 $k$（也可以 `to_string(n).size()` 一步得到），第二遍逐位累加 $d^k$。**注意取位顺序是从低位到高位**，但加法交换律保证累加顺序无所谓，只要每一位都被取到恰好一次。

**溢出判断**：$N \le 10^8$ 是 9 位数上界，最大数位幂之和为 $9 \times 9^9 = 9 \times 387420489 = 3486784401 > 2^{31}-1$，理论上可能超出 `int`！用 `long long` 累加即可高枕无忧；若坚持用 `int`，可在累加中一旦 `sum > n` 提前返回 false（见 §8）。

### 3.3 算法流程

```text
1. k = 0；m = n
   while m > 0: k++, m /= 10          # 数位数
2. sum = 0；m = n
   while m > 0:
       d = m % 10                     # 取最低位
       sum += d^k                     # 整数幂：循环乘 k 次
       m /= 10                        # 去掉最低位
3. 返回 sum == n
```

### 3.4 示例演算

![示例演算：153成立与123不成立的逐位求幂](images/bw5_q2_example_walkthrough.svg)

**示例 1**（$n = 153$，$k = 3$）：取位序列 $3, 5, 1$；$3^3 + 5^3 + 1^3 = 27 + 125 + 1 = 153 = n$ → `true`。

**示例 2**（$n = 123$，$k = 3$）：取位序列 $3, 2, 1$；$3^3 + 2^3 + 1^3 = 27 + 8 + 1 = 36 \ne 123$ → `false`。

## 4. 算法细节

1. **位数求法二选一**：循环除 10 计数（纯整数、无字符串开销）或 `to_string(n).size()`（C++）/ `len(str(n))`（Python，直观）。两者都是 $O(k)$。
2. **整数幂避免浮点误差**：$d^k$ 用 `long long p = 1; for (i < k) p *= d;` 或 Python 的 `d ** k`（整数幂）。C++ 的 `std::pow` 返回 `double`，`pow(9, 9)` 附近可能丢精度，**不要**直接转 int 使用。
3. **`long long` 累加**：$9 \times 9^9 \approx 3.5 \times 10^9$ 已越过 `int` 上界约 $2.1 \times 10^9$；虽然实际只有 $999999999$ 这种 9 位数才会触发上界且它不是自恋数，但「累加器类型放大一级」是零成本的稳妥。
4. **提前剪枝**：数位幂非负、只增不减，一旦 `sum > n` 可立即 `return false`，平均能省一半计算（也顺便把 `int` 溢出的可能性封死）。
5. **一遍循环同时取位**：可以把「数位数」与「取位累加」合成一趟——先存下 $n$ 的所有数位（最多 9 个），再按数组长度取幂。差别不大，按个人口味即可。

## 5. 正确性证明

**引理 1（数位分解唯一性）**：设 $N$ 的十进制表示为 $a_{k-1} a_{k-2} \dots a_1 a_0$（$a_{k-1} \ne 0$），则循环「$m \gets N$；while $m>0$: 取 $d = m \bmod 10$，$m \gets \lfloor m/10 \rfloor$」依次输出 $a_0, a_1, \dots, a_{k-1}$，且恰好执行 $k$ 次。

**证明**：对执行次数 $t$ 归纳。$t = 0$ 时 $m = N = \sum_{i=0}^{k-1} a_i 10^i$。设第 $t$ 次迭代前 $m_t = \sum_{i=t}^{k-1} a_i 10^{i-t}$（即去掉低 $t$ 位后的剩余数）。当 $t < k$ 时 $m_t \ge a_{k-1} 10^{k-1-t} \ge 10^{k-1-t} \ge 1 > 0$，循环继续；且 $m_t \bmod 10 = a_t$（高位项都是 10 的倍数），$\lfloor m_t / 10 \rfloor = \sum_{i=t+1}^{k-1} a_i 10^{i-t-1} = m_{t+1}$。当 $t = k$ 时 $m_k = 0$，循环终止。故输出恰为 $a_0, \dots, a_{k-1}$，共 $k$ 次。∎

**定理**：算法返回 `true` 当且仅当 $N$ 的每一位数字的 $k$ 次幂之和等于 $N$（$k$ 为 $N$ 的位数）。

**证明**：由引理 1，第一个循环正确求得位数 $k$（迭代次数即数位个数），第二个循环把每个数位 $a_i$ 恰好取到一次并累加 $a_i^k$，终止时 $\text{sum} = \sum_{i=0}^{k-1} a_i^k$。算法返回 $\text{sum} == n$，与阿姆斯特朗数的定义逐字对应。∎

## 6. 复杂度分析

- **时间**：$O(k^2)$，其中 $k \le 9$ 为位数。数位数一趟 $O(k)$，每个数位计算 $k$ 次幂用循环乘法 $O(k)$；$k$ 为常数级，实际就是几十次整数乘法。
- **空间**：$O(1)$。只用了常数个整型变量（若用字符串法则 $O(k)$）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool isArmstrong(int n) {
        int k = 0;
        for (int m = n; m > 0; m /= 10) ++k;      // 位数 k
        long long sum = 0;
        for (int m = n; m > 0; m /= 10) {         // 逐位取数（低位在前）
            int d = m % 10;
            long long p = 1;
            for (int i = 0; i < k; ++i) p *= d;   // d^k：整数幂，避免浮点误差
            sum += p;
            if (sum > n) return false;            // 累加只增，超过即提前判负
        }
        return sum == n;
    }
};
```

### Python

```python
class Solution:
    def isArmstrong(self, n: int) -> bool:
        k = len(str(n))                     # 位数
        total, m = 0, n
        while m > 0:                        # 逐位取数（低位在前）
            d = m % 10
            total += d ** k                 # 整数幂，无浮点误差
            if total > n:                   # 提前判负
                return False
            m //= 10
        return total == n
```

> 💡 两份代码均通过官方示例（`true`、`false`）、穷举 $[1, 2 \times 10^6]$ 与 27 个已知自恋数全集（含 $88593477$）核对、20 万组大随机与字符串参考实现对拍，以及 $N = 10^8$ 边界，全部一致。

## 8. 边界情况与易错点

1. **浮点 `pow` 的坑**：C++ 的 `std::pow(d, k)` 是浮点实现，`pow(9, 9)` 附近可能差一个 ulp，强转 `int` 后少 1。务必用整数循环乘法（或 `long long` 累加器配整数幂）。
2. **累加器溢出**：$9 \times 9^9 \approx 3.49 \times 10^9 > 2^{31} - 1 \approx 2.15 \times 10^9$，`int` 累加在 9 位输入上有理论溢出风险，用 `long long`；「累加超过 $n$ 即返回」的剪枝同时消除了这一风险。
3. **一位数全是自恋数**：$1 \sim 9$ 满足 $d^1 = d$，都返回 `true`；$N = 1$ 是最小输入。
4. **上界 $10^8$**：它本身是 9 位数，$1^9 + 0 + \dots + 0 = 1 \ne 10^8$，返回 `false`；循环位数逻辑对它正常工作（`while m > 0` 跑 9 次）。
5. **不要改变 $n$ 本体**：数位数与取位都要用副本 `m = n`，直接在 `n` 上除会把判定对象改没。
6. **幂次是位数 $k$，不是固定 3**：经典「水仙花数」是 3 位特例，本题幂次随位数变化，153 与 1634 都是 `true`，但 370 是 `true` 而 3700 是 `false`（$3^4+7^4+0+0 = 4096 + 2401 = 6497 \ne 3700$）。
