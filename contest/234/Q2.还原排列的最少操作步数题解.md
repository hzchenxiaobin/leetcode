# LeetCode 还原排列的最少操作步数 题解

## 1. 题目概述

- **标题 / 题号**：还原排列的最少操作步数（#1806，medium）
- **链接**：https://leetcode.cn/problems/minimum-number-of-operations-to-reinitialize-a-permutation/
- **来源**：LeetCode 第 234 场周赛 Q2
- **难度**：中等
- **标签**：数组、数学、模拟

**题意**：给定偶数 $n$，初始时 `perm[i] = i`（下标从 0 开始）。每一步操作按固定规则重排：生成新数组 `arr`，偶数下标取 `arr[i] = perm[i/2]`，奇数下标取 `arr[i] = perm[n/2 + (i-1)/2]`，然后 `perm ← arr`。求 `perm` 第一次重新变回初始排列所需的**最小非零**操作步数。

**约束**：

- `2 <= n <= 1000`
- `n` 是偶数

> 💡 数据范围很小，按定义整组模拟即可通过；但这题的真正价值在于看穿操作的本质——**每一步执行的都是同一个固定置换（完美洗牌）**，答案就是该置换的阶。由此可以写出 $O(1)$ 空间、只追踪一个元素的解法，并得到一个干净的数论结论：答案是 2 在模 $n-1$ 意义下的乘法阶。

解释：最初 perm = [0,1]，一步操作后 perm = [0,1]。
操作虽然是恒等的，但题目要求最小非零步数，故答案为 1。
```

**示例 2**

解释：最初 perm = [0,1,2,3]

```

```

解释：[0,1,2,3,4,5,6,7] → [0,4,1,5,2,6,3,7] → [0,2,4,6,1,3,5,7] → [0,1,2,3,4,5,6,7]
注意 n=6 要 4 步、n=8 反而只要 3 步：答案由 n−1 的数论结构决定，不随 n 单调。
```

## 3. 解题思路

### 3.1 暴力思路：整组模拟

按定义每步重建整个数组，与初始排列比较，第一次相等时返回步数。终止性有保证：答案 $= \mathrm{ord}_{n-1}(2) \mid \varphi(n-1) \le n-2 < n$（见 §5），故总代价 $O(n^2) \le 10^6$，对 $n \le 1000$ 稳过。缺点：既没有解释**为什么**恰好是这么多步，也没有利用"每一步都是同一个重排"这一结构。

### 3.2 核心观察：每一步都是同一个固定置换（完美洗牌）

操作规则只依赖 $n$，与 `perm` 的当前内容无关——**每一步执行的都是同一个重排 $\sigma$**。把视角从"每个位置从哪里取值"换成"每个元素去哪里"：位于 $j$ 的元素一步后移动到

$$\sigma(j)=\begin{cases}2j, & j < n/2,\\ 2j-n+1, & j \ge n/2,\end{cases}$$

即**前半依序进入偶数位、后半依序进入奇数位**——这正是经典的完美洗牌（Faro out-shuffle）。合并成一个式子：对 $1 \le j \le n-2$，$\sigma(j) \equiv 2j \pmod{n-1}$；位置 $0$ 与 $n-1$ 是不动点。

![核心观察：一步操作等价于一次完美洗牌](images/1806_shuffle_concept.svg)

于是 $t$ 步后，初始位于 $j$ 的元素位于 $\sigma^t(j)$；`perm` 回到初始 $\iff$ 每个元素回家 $\iff$ $\sigma^t = \mathrm{id}$。**答案 = 置换 $\sigma$ 的阶 = $\sigma$ 各个不相交圈长的最小公倍数。**

### 3.3 算法流程：只追踪元素 1

要求"所有圈长的 lcm"，看似要遍历全部 $n$ 个位置；但本题的圈结构有一个关键性质：**元素 1 所在圈的长度，就是所有圈长的最小公倍数**（其他每个圈长都整除它，见 §5 引理 3）。于是只需 $O(1)$ 空间追踪元素 1 的位置：

![追踪单个元素：答案等于元素1所在圈的长度](images/1806_cycle_track.svg)

```text
1. pos = 1（元素 1 的当前位置），steps = 0
2. 循环执行：
   a. pos ← σ(pos)，即 pos < n/2 ? 2·pos : 2·pos − n + 1
   b. steps += 1
   c. 若 pos == 1：返回 steps
```

由 $\sigma(j) \equiv 2j \pmod{n-1}$ 还能进一步看穿：元素 1 的位置每步变为 $2 \cdot pos \bmod (n-1)$，所以它回家当且仅当 $2^k \equiv 1 \pmod{n-1}$。**答案 = 2 在模 $n-1$ 意义下的乘法阶**，即最小的 $k \ge 1$ 使 $(2^k - 1) \bmod (n-1) = 0$；$n = 2$ 时操作是恒等置换，答案为 1。

### 3.4 示例演算：n = 6

以 $n = 6$（$m = n - 1 = 5$）走查：高亮格是元素 1 当前所在位置，右列记录位置的变化——每步恰好 $\times 2 \bmod 5$：

![示例演算：n=6 逐步追踪元素1的位置](images/1806_walkthrough.svg)

元素 1 的位置 $1 \to 2 \to 4 \to 3 \to 1$，4 步回家；其余会动的元素都与 5 互素，圈长同样整除 4，第 4 步全体归位，答案为 4。

## 4. 算法细节

1. **两个等价的追踪方向**：题面递推式是"取值来源"方向 $f(i)$（位置 $i$ 读 $f(i)$）；本文用"元素去向"方向 $\sigma = f^{-1}$。二者互为逆置换，圈结构完全相同、阶相同，固定用哪个方向追踪都可以——但**只能用一个方向**，交替使用会每两步互相抵消，得到错误的小步数。
2. **为什么挑元素 1**：圈长公式 $\ell(j) = \mathrm{ord}_{m/\gcd(j,m)}(2)$（$m = n-1$）在 $\gcd(j, m) = 1$ 时取到最大值 $\mathrm{ord}_m(2)$，而 $\gcd(1, m) = 1$ 恒成立，元素 1 永远安全。随便挑别的元素可能挑到短圈：如 $n = 10$（答案 6）追元素 3 只会数出 2 步（圈 $3 \to 6 \to 3$）。
3. **循环必须"先走一步再判断"**（do-while 或等价写法）：一是题意要求**非零**步数；二是 $n = 2$ 时操作为恒等置换，先判断位置会永远不进循环或返回 0。
4. **数论写法的 $n = 2$ 特判**：模 $m = 1$ 意义下所有数同余于 0，判据 $2^k \bmod m = 1$ 永不成立，需直接返回 1；若把判据写成 $(2^k - 1) \bmod m = 0$，则 $n = 2$ 也被自然覆盖（任何数模 1 都余 0）。
5. **溢出**：$pos < n \le 1000$，中间量 $2 \cdot pos < 2000$，`int` 足够；若把 $n$ 放大到 $10^9$ 以上，乘法需换 64 位。

## 5. 正确性证明

记 $m = n - 1$（$n$ 为偶数，故 $m$ 为奇数，$\gcd(2, m) = 1$）。

**引理 1（元素移动公式）**：一次操作把位于下标 $j$ 的元素移动到下标 $\sigma(j)$，其中 $\sigma(j) = 2j$（$j < n/2$）、$\sigma(j) = 2j - n + 1$（$j \ge n/2$），且 $\sigma$ 是 $\{0, \dots, n-1\}$ 上的双射。

**证明**：由规则，新数组满足 $i$ 偶时 $\mathrm{arr}[i] = \mathrm{perm}[i/2]$、$i$ 奇时 $\mathrm{arr}[i] = \mathrm{perm}[n/2 + (i-1)/2]$。位于 $j$ 的元素（值 $\mathrm{perm}[j]$）的新位置是"规则右边取到 $j$"的那个 $i$：若 $j < n/2$，取 $i = 2j \le n-2$，为偶数且 $i/2 = j$；若 $j \ge n/2$，取 $i = 2j - n + 1 \in [1, n-1]$，为奇数且 $n/2 + (i-1)/2 = n/2 + j - n/2 = j$。两个分支恰好无遗漏地覆盖 $j \in [0, n/2)$ 与 $j \in [n/2, n)$，且每个 $j$ 给出唯一的 $i$，故 $\sigma$ 是双射。∎

**引理 2（模同余形式）**：$\sigma(0) = 0$，$\sigma(n-1) = n-1$；对 $1 \le j \le n-2$，$\sigma(j) = 2j \bmod m$（作为 $\{1, \dots, n-2\}$ 中的整数）。特别地，集合 $\{1, \dots, n-2\}$ 在 $\sigma$ 下不变。

**证明**：$\sigma(0) = 0$ 与 $\sigma(n-1) = 2(n-1) - n + 1 = n-1$ 直接代入。设 $1 \le j \le n-2$：若 $j < n/2$，则 $2 \le 2j \le n - 2 < m$，故 $2j \bmod m = 2j = \sigma(j)$；若 $n/2 \le j \le n-2$，则 $m < n \le 2j \le 2n - 4 < 2m$，故 $2j \bmod m = 2j - m = \sigma(j) \in [1, n-3]$。两种情况均有 $\sigma(j) \in \{1, \dots, n-2\}$。∎

**引理 3（圈长公式与整除关系）**：设 $n \ge 4$（$m \ge 3$）。对 $j \in \{1, \dots, m-1\}$，记 $\ell(j)$ 为元素 $j$ 首次回家所需的步数，则

$$\ell(j) = \min\{\, t \ge 1 : m \mid (2^t - 1)\,j \,\} = \mathrm{ord}_{m/\gcd(j,m)}(2),$$

且 $\ell(j) \mid \ell(1) = \mathrm{ord}_m(2)$。

**证明**：由引理 2 与归纳法，在不变集 $\{1, \dots, m-1\}$ 上有 $\sigma^t(j) \equiv 2^t j \pmod m$，且两侧都落在 $\{1, \dots, m-1\}$ 中（$2$ 模 $m$ 可逆，$j \not\equiv 0$，故 $2^t j \not\equiv 0 \pmod m$；剩余系中表示唯一）。于是 $\sigma^t(j) = j \iff (2^t - 1)j \equiv 0 \pmod m$。记 $d = m/\gcd(j, m)$，则 $m \mid (2^t - 1)j \iff d \mid (2^t - 1) \cdot \frac{j}{\gcd(j,m)}$，而 $\gcd\big(d, \frac{j}{\gcd(j,m)}\big) = 1$，故等价于 $d \mid (2^t - 1)$，即 $2^t \equiv 1 \pmod d$，所以 $\ell(j) = \mathrm{ord}_d(2)$。又 $d \mid m$，而 $2^{\ell(1)} \equiv 1 \pmod m \Rightarrow 2^{\ell(1)} \equiv 1 \pmod d$，由阶的最小性得 $\ell(j) = \mathrm{ord}_d(2) \mid \ell(1)$。∎

**定理**：$n \ge 4$ 时，答案 $= \mathrm{ord}_{n-1}(2) = \min\{\, k \ge 1 : 2^k \equiv 1 \pmod{n-1} \,\}$；$n = 2$ 时答案为 $1$。"追踪元素 1 直到回家"的算法返回的正是该值。

**证明**：初始排列为恒等排列，元素 $j$ 位于位置 $j$。$t$ 步后排列复原 $\iff$ 所有元素同时回家 $\iff \sigma^t(j) = j$ 对一切 $j$ 成立 $\iff t$ 是全体圈长的公倍数，最小正的这样的 $t$ 即 $\mathrm{lcm}\{\ell(j)\}$（不动点圈长为 1，不构成约束）。由引理 3，每个 $\ell(j)$ 整除 $\ell(1)$ 且 $\ell(1)$ 本身是圈长之一，故 $\mathrm{lcm} = \ell(1) = \mathrm{ord}_m(2)$。算法从 $pos = 1$ 出发反复施加 $\sigma$，首次回到 1 的步数恰为 $\ell(1)$。$n = 2$ 时 $\sigma = \mathrm{id}$（$n/2 = 1$，两分支分别给出 $\sigma(0) = 0$、$\sigma(1) = 1$），每步后排列都与初始相同，最小非零步数为 1。∎

> 💡 顺带得到暴力的终止性与答案上界：由 Euler 定理 $2^{\varphi(m)} \equiv 1 \pmod m$（因 $\gcd(2, m) = 1$），故 $\mathrm{ord}_m(2) \mid \varphi(m) \le m - 1 = n - 2 < n$，答案严格小于 $n$。

## 6. 复杂度分析

- **时间复杂度**：$O(\mathrm{ans})$，其中 $\mathrm{ans} = \mathrm{ord}_{n-1}(2) < n$，循环每步 $O(1)$。本题范围内最坏是 $n = 948$（$n - 1 = 947$ 是素数且 2 是其原根），需 946 步；$n = 1000$ 反而只需 36 步。
- **空间复杂度**：$O(1)$，只维护一个位置变量与一个计数器。
- **对比**：整组模拟为 $O(n \cdot \mathrm{ans}) \le O(n^2)$ 时间、$O(n)$ 空间，在本题约束下同样能过，但不揭示结构，也无法迁移到大 $n$ 场景。

## 7. 参考代码

### C++（追踪元素 1，推荐）

```cpp
class Solution {
  public:
    int reinitializePermutation(int n) {
        int pos = 1, steps = 0;
        do {
            pos = pos < n / 2 ? 2 * pos : 2 * pos - n + 1;  // 元素 1 的新位置 σ(pos)
            ++steps;
        } while (pos != 1);
        return steps;
    }
};
```

### C++（数论：求 2 模 n−1 的乘法阶）

```cpp
class Solution {
  public:
    int reinitializePermutation(int n) {
        if (n == 2) return 1;          // m = 1：恒等置换，特判
        int m = n - 1, k = 1, p = 2 % m;
        while (p != 1) {               // 最小的 k 使 2^k ≡ 1 (mod m)
            p = p * 2 % m;
            ++k;
        }
        return k;
    }
};
```

### Python（追踪元素 1）

```python
class Solution:
    def reinitializePermutation(self, n: int) -> int:
        pos, steps = 1, 0
        while True:
            pos = 2 * pos if pos < n // 2 else 2 * pos - n + 1
            steps += 1
            if pos == 1:
                return steps
```

### Python（整组模拟，暴力对照）

```python
class Solution:
    def reinitializePermutation(self, n: int) -> int:
        target = list(range(n))
        perm = target[:]
        steps = 0
        while True:
            perm = [perm[i // 2] if i % 2 == 0 else perm[n // 2 + (i - 1) // 2]
                    for i in range(n)]
            steps += 1
            if perm == target:
                return steps
```

## 8. 边界情况与易错点

1. **$n = 2$ 是最阴的边界**：操作是恒等置换，排列"一步都没变"，但答案是 1 而不是 0——题意要求**最小非零**步数。do-while 写法天然正确；数论写法若忘特判 $n = 2$，判据 $2^k \bmod 1 = 0 \ne 1$ 永不成立，直接死循环。
2. **不能追不动点**：追踪位置 0 或 $n-1$（永远原地踏步）会数出 1，只有 $n = 2$ 时碰巧正确。
3. **不能随便挑元素追**：必须挑与 $n - 1$ 互素的元素（1 永远互素）。反例：$n = 10$ 时答案 6，追元素 3 只数出 2（圈 $3 \to 6 \to 3$）。
4. **方向不能混用**：`pos ← σ(pos)`（元素去向）与 `pos ← f(pos)`（取值来源，即题面递推式）是互逆的两个映射，单独用哪个都对，交替用等于每两步抵消一次。
5. **暴力版"先比较后操作"会返回 0**：必须先执行一步再与初始排列比较（或用 do-while），否则 $n = 2$ 直接输出 0。
6. **别把"步数"数成"圈数"**：答案是从出发到首次回家的步数（圈长），不是置换分解出的圈的个数。
7. **大 n 扩展的溢出**：本约束下 $2 \cdot pos < 2000$ 无风险；若 $n$ 接近 `int` 上限的一半以上，`2 * pos` 需用 64 位。

**延伸思考**：

- 若 $n$ 高达 $10^{18}$，模拟不可行：注意到 $\mathrm{ord}_m(2) \mid \lambda(m)$（Carmichael 函数），可先用 Miller–Rabin 判素、Pollard-rho 分解 $m = n - 1$ 与 $\lambda(m)$，再从 $\lambda(m)$ 出发逐个质因子尝试降幂，在关于 $\log m$ 的多项式时间内求出阶。
- 若规则改成 **in-shuffle**（前半进奇数位、后半进偶数位），位置映射变为 $\sigma'(j) \equiv 2j + 1 \pmod{n+1}$，迭代 $t$ 次为 $2^t j + (2^t - 1) \bmod (n+1)$，答案仍归结为 $\mathrm{ord}(2 \bmod (n+1))$——框架完全不变，变的只是模数。
- 圈长公式的组合意义：$\{1, \dots, m-1\}$ 按"与 $m$ 的 gcd"分层，同层元素圈长相同，gcd 越小圈越长。这也是分析"重复执行某个固定重排何时复原"一类问题的通用套路：**显式写出位置映射 → 找到不动点与不变集 → 归结为乘法阶或圈长 lcm**。
