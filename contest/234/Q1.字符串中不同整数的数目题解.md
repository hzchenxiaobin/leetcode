# LeetCode 字符串中不同整数的数目 题解

## 1. 题目概述

- **标题 / 题号**：字符串中不同整数的数目（#1805，easy）
- **链接**：https://leetcode.cn/problems/number-of-different-integers-in-a-string/
- **来源**：LeetCode 第 234 场周赛 Q1
- **难度**：简单
- **标签**：哈希表、字符串

**题意**：给定一个由数字字符和小写英文字母组成的字符串 `word`。把每个**不是数字**的字符替换成空格，剩下的整数（相邻整数之间至少隔一个空格）构成一个序列。返回其中**不同**整数的数目。两个整数视为不同，当且仅当它们**不含前导零**的十进制表示不同。

**约束**：

- `1 <= word.length <= 1000`
- `word` 由数字字符 `'0'`-`'9'` 和小写英文字母组成

> ⚠️ 约束的关键影响：单个数字段最长可达 1000 位，数值可达 $10^{1000}$ 量级，任何 64 位整数（上限约 $1.8 \times 10^{19}$）都装不下——这决定了"转数值比较"这条路在 C++/Java 里**直接不可行**。

## 2. 示例

```text
输入：word = "a123bc34d8ef34"
输出：3
解释：不同的整数有 "123"、"34" 和 "8"。注意 "34" 只计数一次。
```

**示例 2**

```text
输入：word = "leet1234code234"
输出：2
```

**示例 3**

```text
输入：word = "a1b01c001"
输出：1
解释："1"、"01" 和 "001" 表示同一个整数，前导零在比较时被忽略。
```

```text
输入：word = "0a00b000"
输出：1
解释：三个段 "0"、"00"、"000" 都表示整数 0，只计数一次。
```

## 3. 解题思路

### 3.1 朴素思路：模拟 + 直接比较

按题意模拟：把非数字字符替换成空格、按空格切分得到每个整数的字符串形式，然后去重。朴素做法有两种，**各有各的问题**：

1. **转成数值再放进哈希集合**：段长可达 1000 位，`stoi`/`Long.parseLong` 会溢出或抛异常，直接不可行（Python 的大整数虽能算，但转换代价高，且思路不可迁移到静态语言）。
2. **不做处理，直接把段字符串丢进集合**：这不是"慢"，而是**错**——`"1"`、`"01"`、`"001"` 是三个不同的字符串，但表示同一个整数，会被当成三个不同整数，WA。

### 3.2 核心观察：归一化字符串 + 哈希集合

**关键洞察**：两个（允许带前导零的）十进制串表示同一个整数 $\iff$ **去掉前导零后两个串相等**。全零段（`"000"`）去掉前导零后统一映射到同一个表示即可。

所以根本不需要算出数值：把每个**极大连续数字段**去掉前导零，将归一化后的字符串直接作为 key 丢进 `unordered_set<string>`，集合大小就是答案。

![核心观察：极大数字段、归一化与哈希去重](images/1805_segment_concept.svg)

### 3.3 算法流程

![一次扫描提取极大段并归一化入集合的算法流程](images/1805_scan_flow.svg)

```text
1. i = 0，seen = 空哈希集合
2. 若 word[i] 不是数字：i += 1，回到 2
3. j 从 i 向右扫到段尾（极大段 = word[i..j)）
4. k 从 i 起跳过前导 '0'（条件 k+1 < j，保证全零段保留一个 '0'）
5. seen 插入 word[k..j)
6. i = j，回到 2；i 扫到结尾后返回 |seen|
```

### 3.4 示例演算

以示例 3 `word = "a1b01c001"` 走查一遍：字母直接跳过，三个段 `"1"`、`"01"`、`"001"` 归一化后都是 `"1"`，集合里始终只有一个元素，最终答案为 1。

## 4. 算法细节

1. **段提取**：双指针——`i` 停在每个数字段的起点，`j` 向右扫到第一个非数字（或串尾），极大段即 `word[i..j)`。提取完令 `i = j` 跳过整段。也可以直接用正则 `\d+` 一次取出全部段。
2. **归一化的两种等价写法**：
   - Python：`segment.lstrip('0')`，`"001"` → `"1"`，`"000"` → `""`（空串）；
   - C++：跳过前导 `'0'` 但保证至少留 1 位，`"001"` → `"1"`，`"000"` → `"0"`。
   - 关键不在于映射成空串还是 `"0"`，而在于**全局一致**：所有同值段必须得到同一个 key，两种写法内部各自一致，都没问题；但不能混用（例如一处保留一位、另一处削成空串）。
3. **为什么不转数值**：段最长 1000 位，转数值要么溢出要么抛异常；而归一化串本身就是数值等价类的**规范代表**，长度不超过段长，构建代价 $O(\text{段长})$。
4. **C++ 细节**：`word.substr(k, j - k)` 的第二个参数是**长度**不是下标；`isdigit` 的实参记得转成 `unsigned char`，避免有符号 char 的未定义行为。

## 5. 正确性证明

**引理 1（切分的正确性）**：把 `word` 中所有非数字字符替换为空格后，得到的整数列表（按出现顺序）恰好是 `word` 的全部极大连续数字段。

**证明**：替换操作只把字母变成空格，数字的位置与内容不变，故替换后串中两个字符相邻 $\iff$ 它们在 `word` 中相邻且都是数字。替换后串中一个不含空格的极大连续子串，其两侧要么是串边界、要么紧邻空格；对应回 `word` 中，恰是一个两侧（或边界）均被非数字字符夹住的极大连续数字子串。反之，`word` 的每个极大数字段替换后仍是两侧被空格（或边界）夹住的不含空格极大段。二者一一对应。∎

**引理 2（归一化的规范性）**：设 $s$ 是非空数字段，$v(s)$ 为其表示的数值，$\mathrm{norm}(s)$ 为删除全部前导零后得到的串（若 $s$ 全为 `'0'`，则 $\mathrm{norm}(s)$ 为空串，或只含一个 `'0'`——只要全局统一）。则
$$v(s) = v(t) \iff \mathrm{norm}(s) = \mathrm{norm}(t).$$

**证明**：先注意 $v(\mathrm{norm}(s)) = v(s)$：删除的只是前导 `'0'`，前导零对按位十进制求和的贡献为 0。

- （$\Leftarrow$）若 $\mathrm{norm}(s) = \mathrm{norm}(t)$，则 $v(s) = v(\mathrm{norm}(s)) = v(\mathrm{norm}(t)) = v(t)$。
- （$\Rightarrow$）若 $v(s) = v(t)$，则 $v(\mathrm{norm}(s)) = v(\mathrm{norm}(t))$，且 $\mathrm{norm}(s)$、$\mathrm{norm}(t)$ 均非空、均无前导零。无前导零的十进制表示唯一：设两串长度为 $p \le q$，若 $p < q$，则长串首位 $\ge 1$，数值 $\ge 10^{q-1}$，而短串数值 $\le 10^p - 1 \le 10^{q-1} - 1$，矛盾，故 $p = q$；再对首位比较（若首位不同则两值之差至少 $10^{p-1}$，与相等矛盾），去掉首位后归纳同理，得两串逐位相等。∎

**定理**：算法返回的 $\left| \{\,\mathrm{norm}(s) : s \text{ 是 } word \text{ 的极大数字段}\,\} \right|$ 等于 `word` 中不同整数的数目。

**证明**：由引理 1，待去重的多重集恰为全部极大数字段；由引理 2，两段表示同一整数 $\iff$ 归一化结果相等，即每个不同整数恰好对应归一化集合中的一个元素。哈希集合按字符串精确去重，故集合大小 = 不同整数的数目。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$，其中 $n = \text{word.length}$。每个字符至多被扫描常数次；所有段被拷贝进集合的总字符数 $\sum \text{段长} \le n$，对长为 $L$ 的 key 哈希为 $O(L)$，求和仍为 $O(n)$。
- **空间复杂度**：$O(n)$。最坏情况（整串都是数字）集合存一个长 $n$ 的串；一般情况所有归一化 key 的总长 $\le n$。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int numDifferentIntegers(string word) {
        int n = word.size();
        unordered_set<string> seen;
        for (int i = 0; i < n;) {
            if (!isdigit((unsigned char)word[i])) {  // 非数字：跳过
                ++i;
                continue;
            }
            int j = i;
            while (j < n && isdigit((unsigned char)word[j]))
                ++j;                                 // 极大段 = word[i..j)
            int k = i;
            while (k + 1 < j && word[k] == '0')
                ++k;                                 // 去前导零，全零段保留一个 '0'
            seen.insert(word.substr(k, j - k));
            i = j;
        }
        return seen.size();
    }
};
```

### Python

```python
class Solution:
    def numDifferentIntegers(self, word: str) -> int:
        seen = set()
        n, i = len(word), 0
        while i < n:
            if not word[i].isdigit():
                i += 1
                continue
            j = i
            while j < n and word[j].isdigit():  # 极大段 = word[i:j]
                j += 1
            seen.add(word[i:j].lstrip('0'))      # "001"→"1"；"000"→""（一致即可）
            i = j
        return len(seen)
```

正则一行版（`lstrip('0')` 对全零段返回空串，一致性依然成立）：

```python
import re

class Solution:
    def numDifferentIntegers(self, word: str) -> int:
        return len({s.lstrip('0') for s in re.findall(r'\d+', word)})
```

## 8. 边界情况与易错点

1. **全零段是最常见的 WA 点**：`"0"`、`"00"`、`"000"` 表示同一个整数 0，必须归一化到同一个 key。C++ 里若写 `while (word[k] == '0') ++k;` 而不带 `k + 1 < j` 保护，段 `"0"` 会削成空串——单独用这一种写法其实也对（所有零段都得到空串），但与"保留一位"写法混用就会把同一个整数映射成两个不同 key。
2. **不能转 int / long**：段最长 1000 位，`stoi`/`stol` 抛 `out_of_range` 异常，Java `Long.parseLong` 直接 `NumberFormatException`。
3. **不归一化直接存字符串是错的**：`"1"`、`"01"`、`"001"` 会被当成三个整数，WA 而非 TLE。
4. **全是字母**：如 `"abc"`，没有任何段，答案 0，扫描自然得到空集合，无需特判。
5. **整串都是数字**：如 `"12345"`，只有一个段，答案 1。
6. **去重对象是整段，不是单个数字字符**：别把 `"123"` 拆成 1、2、3 各自计数。
7. **段之间的极大性由扫描自动保证**：两个数字段之间至少隔一个非数字字符，否则它们本来就是同一段，无需额外判断。
