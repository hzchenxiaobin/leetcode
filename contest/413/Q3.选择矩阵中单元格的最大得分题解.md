# LeetCode 选择矩阵中单元格的最大得分 题解

## 1. 题目概述

- **标题 / 题号**：选择矩阵中单元格的最大得分（#3276，hard）
- **链接**：https://leetcode.cn/problems/select-cells-in-grid-with-maximum-score/
- **来源**：LeetCode 第 413 场周赛 Q3
- **难度**：困难
- **标签**：位运算、数组、动态规划、状态压缩、矩阵

**题意**：给定一个正整数矩阵 `grid`，从中选**一个或多个**格子，要求任意两个所选格子**不在同一行**，且所选格子的**值互不相同**。得分为所选值之和，求最大得分。

**约束**：

- $1 \le grid.length \le 10$
- $1 \le grid[i].length \le 10$
- $1 \le grid[i][j] \le 100$

> 💡 **数据范围的信号**：两条约束只涉及「**行**」与「**值**」，**列从头到尾没有约束**——一个格子本质上就是 (行, 值) 二元组，列坐标用不上。行 $\le 10$（$2^{10} = 1024$ 可压），值域 $1 \sim 100$（去重后至多 100 个值），天然指向「压行进状态、按值逐个决策」的状压 DP。本场 Q3、Q4 双双标困难，本题正是分水岭。

> 💡 本题另有[每日题解 3276](../../solution/3201-3300/3276_选择矩阵中单元格的最大得分.md)：采用「已占行集合**恰为** $mask$」的状态定义、$-1$ 可达标记与面试问答，与本文互为印证；本文侧重赛场推导路径，改用「所选行 $\subseteq mask$」的等价定义——**全 0 初始化、免不可达标记、答案直取 $dp[\text{全集}]$**，并给出完整的归纳证明。

## 2. 示例

**示例 1**

```text
输入：grid = [[1,2,3],[4,3,2],[1,1,1]]
输出：8
解释：选 3@行0、4@行1、1@行2——值互异、各占一行，得分 3 + 4 + 1 = 8。
```

**示例 2**

```text
输入：grid = [[8,7,6],[8,3,2]]
输出：15
解释：8@行1 + 7@行0 = 15。两个 8 只能取其一；6 与 7 同行冲突，3、2 与 8 同行冲突。
```

**补充示例（自造，后面当贪心反例用）**

```text
输入：grid = [[10,9],[10,1]]
输出：19
解释：10@行1 + 9@行0 = 19。若让 10 抢先行 0，9 就被堵死，只能得 10 + 1 = 11。
```

## 3. 解题思路

### 3.1 暴力思路：贪心翻车 + 枚举爆炸

**路线一：贪心「从大到小，能拿就拿」**——把所有格子按值降序排列逐个尝试，值没被用过且所在行空闲就拿。这一步在赛场上极其诱人，可惜是错的：

![贪心反例：大值占错行堵死后面的大值](images/c413_q3_greedy_fail.svg)

反例 `grid = [[10,9],[10,1]]`：贪心先抓走行 0 的 10，导致 9（同行冲突）与行 1 的 10（同值冲突）全部出局，只能补一个 1，得 11；最优解让 10 住进行 1、把行 0 留给 9，得 19。**行是共享资源**：拿走一个值时你并不知道它该住哪一行，占错行会把后面的大值整个堵死——「值 → 行」的安置必须全局统筹。

**路线二：朴素枚举**——每行有「选某一格 / 不选」共 $n+1$ 种选择，全部组合 $(n+1)^m \le 11^{10} \approx 2.6 \times 10^{10}$，直接爆炸。

### 3.2 核心观察：同值折叠，值当阶段、行集合当状态

![核心观察：格子折叠成值到行集合的映射](images/c413_q3_value_row_dp_model.svg)

**观察 1（列无关 → 同值折叠）**：约束里根本没有列，一个格子就是 (行, 值)。而值相同的格子命运完全一样——**选值 $v$ 时唯一要做的事是「占用一个含 $v$ 的行」**，具体是哪一列、哪一格无关紧要。于是把同值格子折叠成一张表：$rowOf[v] = $ 值 $v$ 出现过的行集合（bitmask，第 $i$ 行对应第 $i$ 位）。$10 \times 10$ 个格子折叠后至剩 $\le 100$ 个互异的值。

**观察 2（问题重述为安置）**：由观察 1，原问题等价于——从去重后的值里选一部分，给每个值分配一个**互不相同**的行，且值 $v$ 只能分到含 $v$ 的行，最大化所选值之和。左部是值、右部是行，这正是**二分图最大权匹配**的形态（行 $\le 10$，至多安置 10 个值）。

**观察 3（压小侧、枚举大侧）**：值 $\le 100$ 个（$2^{100}$ 不可压），行 $\le 10$ 个（$2^{10} = 1024$ 可压）。于是让**值当「阶段」**——像 0-1 背包的物品逐个决策，每个值恰好决策一次；**行占用情况当「状态」**。状态定义（本文采用「子集」语义）：

$$dp[mask] = \text{已处理的值中，能安置进行集合 } \subseteq mask \text{ 的最大总得分}$$

「$\subseteq$」的意思是允许**浪费**行：$dp[mask]$ 是「行只能从 $mask$ 里挑」下的最优，不必用满。空方案得 0 永远合法，因此**全 0 初始化**即可，不需要任何不可达标记。

### 3.3 状态转移：每个值一次 0/1 决策

![转移流程：跳过或放入空闲行，倒序原地更新](images/c413_q3_dp_transition_flow.svg)

处理值 $v$（行集合 $R = rowOf[v]$）时，两分支不重不漏：

- **跳过 $v$**：$dp'[mask] \leftarrow dp[mask]$；
- **选 $v$**：放入 $R$ 中任一**空闲**行 $r \in R \cap mask$：

$$dp'[mask] = \max\Big(dp[mask],\ \max_{r \in R \cap mask} dp[mask \setminus \{r\}] + v\Big)$$

转移源 $mask \setminus \{r\}$ 总比目标 $mask$ 小。于是可以**原地倒序**（`mask` 从全集降到 0）一套数组完成：读到的源全是本轮更新前的旧值，$v$ 恰好加入一次——与 0-1 背包「容量倒序」是同一个道理。⚠ 若原地**正序**更新，源可能已含本轮的 $v$，同一个值会被「选了又选」，退化成完全背包。

算法流程整理如下：

```text
1. 建表：rowOf[v] |= 1 << i（扫一遍 grid，值域 1..100 直接开数组）
2. 对每个出现的值 v 升序处理（顺序不影响答案）：
   mask 从 full 降到 0，对 R=rowOf[v] 与 mask 的每个公共位 r：
   dp[mask] = max(dp[mask], dp[mask ^ (1<<r)] + v)
3. 答案 = dp[full]（行全集，不受限）
```

处理完全部值后，任何合法方案用的行都 $\subseteq full$，所以**答案直接取 $dp[full]$**，无需再扫一遍 $\max$。

### 3.4 示例演算

![示例演算：dp 表逐值填出](images/c413_q3_example_walkthrough.svg)

以示例 1（$m = 3$ 行）为例，mask 三位从高位到低位是 $r_2 r_1 r_0$，四个值 $R(1) = \{r_0, r_2\}$、$R(2) = R(3) = \{r_0, r_1\}$、$R(4) = \{r_1\}$，逐值填表（加粗为本轮更新的格子）：

| $mask$ | $v=1$ | $v=2$ | $v=3$ | $v=4$ |
|--------|-------|-------|-------|-------|
| 000 | 0 | 0 | 0 | 0 |
| 001 | **1** | **2** | **3** | 3 |
| 010 | 0 | **2** | **3** | **4** |
| 011 | **1** | **3** | **5** | **7** |
| 100 | **1** | 1 | 1 | 1 |
| 101 | **1** | **3** | **4** | 4 |
| 110 | **1** | **3** | **4** | **5** |
| 111 | **1** | **3** | **6** | **8** ★ |

追一遍决胜转移：$v=4$ 只有行 $r_1$ 一个去处，倒序枚举到 $mask = 111$ 时读旧值 $dp[101] = 4$（行 0 放 3 + 行 2 放 1），得 $4 + 4 = 8$——即「行 0 放 3、行 1 放 4、行 2 放 1」，与官方答案一致。注意 $dp$ 全表没有 $-1$：$dp[100] \equiv 1$ 这种「只用了行 2」的格子行 0、行 1 都被浪费，但在 $\subseteq$ 语义下这是完全合法的状态。对照示例 2 只有 2 行、4 个 mask，同一张表填到 $dp[11] = 15$。

## 4. 算法细节

1. **行集合构建**：`rowOf[v] |= 1 << i` 逐格 OR。值域只有 $1 \sim 100$，直接开长度 101 的数组比哈希表更快更省；同一值在同一行重复出现时也只 OR 进一个位，自动去重。
2. **为什么全 0 初始化合法**：$\subseteq$ 语义下「什么都不选」对任何 $mask$ 都是合法方案、得 0；所有转移只在非负得分之间取 $\max$，永不引入不可达状态。对比「恰好占用」定义需要 $-1$ 标记 + 答案取 $\max(dp)$（见每日题解 3276），本文的定义省掉这两处心智负担。
3. **倒序原地的正确依据**：转移源 $mask \setminus \{r\} < mask$，倒序访问时源尚未被本轮更新；等价替代是每轮 `ndp = dp[:]` 拷贝推新（多 $O(2^m)$ 内存，逻辑最直白）。二选一，别都不选。
4. **值的处理顺序无关紧要**：每个值是独立的 0/1 决策（同 0-1 背包物品顺序无关），升序处理只为代码确定性。真正的红线是**每个值只过一轮**——这由倒序/拷贝保证。
5. **位技巧**：`for (t = R & mask; t; t &= t - 1)` 逐个取出可放行，免掉内层 $0 \sim m$ 的无效枚举；`b = t & -t` 取最低位。
6. **答案取 $dp[full]$**：$\subseteq$ 语义下 $dp$ 关于 $mask$ 单调不减（行多不亏），$dp[full]$ 就是全局最优。

## 5. 正确性证明

**引理 1（方案 = 值到行的部分单射）**：原问题的一个合法选择方案，与二元组 $(S, \rho)$ 一一对应，其中 $S$ 是去重后值的子集，$\rho: S \to \{0, \dots, m-1\}$ 是单射，且对每个 $v \in S$ 有 $\rho(v) \in rowOf[v]$。

**证明**：给定合法方案，把每个被选格子映为其 (值, 行)。「值互不相同」保证所有值构成集合 $S$ 且 $\rho$ 良定义；「任意两格不同行」保证 $\rho$ 为单射；行含该值即 $\rho(v) \in rowOf[v]$。反之给定 $(S, \rho)$，对每个 $v \in S$ 在行 $\rho(v)$ 中任取一个值为 $v$ 的格子（$\rho(v) \in rowOf[v]$ 保证存在）：值互异来自 $S$ 是集合，行互异来自 $\rho$ 单射，列无约束无须检验。两个构造互逆，故为一一对应。∎

**定理（DP 不变量）**：设值按任意固定顺序 $v_1, \dots, v_D$ 处理。记 $V_k = \{v_1, \dots, v_k\}$，则处理完前 $k$ 个值后（记该数组为 $dp_k$，初始 $dp_0 \equiv 0$）有

$$dp_k[mask] = \max\Big\{\, \textstyle\sum_{v \in S} v \;:\; S \subseteq V_k,\ \exists\, \text{单射}\ \rho: S \to mask,\ \rho(v) \in rowOf[v] \,\Big\}$$

（空集允许、得 0，右端恒良定义。）

**证明**：对 $k$ 归纳。$k = 0$：只有空集，$dp_0 \equiv 0$ 与全 0 初始化一致。设结论对 $k-1$ 成立，处理 $v_k$，记 $R = rowOf[v_k]$，只需证转移后数组等于 $dp_k$。

（每个转移值都 ≤ 真值）保留分支 $dp_{k-1}[mask]$ 由归纳假设是 $V_{k-1}$ 的某个 $(S, \rho)$ 的得分；放行分支 $dp_{k-1}[mask \setminus \{r\}] + v_k$（$r \in R \cap mask$）对应把 $v_k$ 安排进行 $r$、其余值沿用某个行集 $\subseteq mask \setminus \{r\}$ 的合法方案——因 $v_k \notin V_{k-1}$，不与已选值冲突。又倒序枚举保证放行分支读到的 $dp_{k-1}$ 尚未被本轮更新，$v_k$ 恰加入一次。两分支都取 $\max$，故 $dp_k[mask]$ 不超过真值。

（真值 ≤ 某个转移值）取使右端取到最大的 $(S, \rho)$。若 $v_k \notin S$，则 $(S, \rho)$ 也是 $V_{k-1}$、行集 $\subseteq mask$ 的合法方案，得分 $\le dp_{k-1}[mask]$，即保留分支。若 $v_k \in S$，记 $r = \rho(v_k) \in R \cap mask$；由 $\rho$ 单射，$S \setminus \{v_k\}$ 的行集 $\subseteq mask \setminus \{r\}$，它是 $V_{k-1}$ 的合法方案，故该方案得分 $\le dp_{k-1}[mask \setminus \{r\}]$，从而真值 $\le dp_{k-1}[mask \setminus \{r\}] + v_k$，恰是放行分支之一。∎

**推论（答案正确性）**：返回值 $dp_D[full]$ 等于原问题的最大得分，且自动满足「至少选一格」。

**证明**：任何 $(S, \rho)$ 的像集都是行集合的子集、$\subseteq full$，故 $dp_D[full]$ 按引理 1 恰为原问题答案的上确界，且由定理该值可达。又 $grid$ 非空、值全正：任取格子 $(i, c)$，其值 $v$ 单独成方案，处理 $v$ 那一轮的放行分支给出 $dp_D[full] \ge dp_{k-1}[full \setminus \{i\}] + v \ge v \ge 1 > 0$，故最优解必非空。∎

## 6. 复杂度分析

- **时间复杂度**：$O(mn + D \cdot 2^m \cdot m)$，其中 $D \le \min(mn, 100)$ 为互异值的个数。建表扫一遍矩阵 $O(mn)$；每个值枚举 $2^m \le 1024$ 个 mask、每个 mask 至多 $m \le 10$ 次放行转移，最坏 $100 \times 1024 \times 10 \approx 10^6$ 次基本操作，远低于时限。相比暴力的 $O((n+1)^m) \approx 2.6 \times 10^{10}$ 下降了四个数量级。
- **空间复杂度**：$O(2^m + V)$，其中 $V = 101$ 为值域表；dp 数组仅 $2^{10} = 1024$ 项，原地倒序实现无需滚动拷贝。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maxScore(vector<vector<int>>& grid) {
        int m = grid.size();
        array<int, 101> rowOf{};                    // 值 v -> 出现过 v 的行集合（bit i = 行 i）
        for (int i = 0; i < m; i++)
            for (int v : grid[i])
                rowOf[v] |= 1 << i;

        int full = (1 << m) - 1;
        vector<int> dp(full + 1, 0);                // dp[mask]: 所选行都 ⊆ mask 的最大得分
        for (int v = 1; v <= 100; v++) {
            if (!rowOf[v]) continue;
            for (int mask = full; mask >= 0; mask--) // 倒序：源更小、本轮尚未更新，读到旧值
                for (int t = rowOf[v] & mask; t; t &= t - 1) {
                    int b = t & -t;                 // 取出一个可放的行
                    dp[mask] = max(dp[mask], dp[mask ^ b] + v);
                }
        }
        return dp[full];                            // 行全集不受限，直取答案
    }
};
```

### Python

```python
class Solution:
    def maxScore(self, grid: List[List[int]]) -> int:
        m = len(grid)
        row_of = [0] * 101                    # 值 v -> 出现过 v 的行集合（bit i = 行 i）
        for i, row in enumerate(grid):
            for v in row:
                row_of[v] |= 1 << i

        full = (1 << m) - 1
        dp = [0] * (full + 1)                 # dp[mask]: 所选行都 ⊆ mask 的最大得分
        for v in range(1, 101):
            if row_of[v] == 0:
                continue
            for mask in range(full, -1, -1):  # 倒序：源更小、本轮尚未更新，读到旧值
                t = row_of[v] & mask
                while t:
                    b = t & -t                # 取出一个可放的行
                    t ^= b
                    if dp[mask ^ b] + v > dp[mask]:
                        dp[mask] = dp[mask ^ b] + v
        return dp[full]                       # 行全集不受限，直取答案
```

## 8. 边界情况与易错点

1. **单行矩阵（$m = 1$）**：值互异 + 不同行 ⇒ 至多选一格，答案就是该行最大值。$full = 1$，$dp[1]$ 自动正确；不要手写特判。
2. **别把列压进状态**：看到「矩阵」就想压 $(行, 列)$ 两维是本题最大的心理陷阱——列零约束，$2^{10} \times 2^{10}$ 的状态既爆炸又无意义。题面按 $grid[i].length$ 逐行给约束、各行长度理论上可不同，本解法只按行扫描，天然免疫。
3. **正序原地更新 = 完全背包 bug（最常见翻车点）**：源 $mask \setminus \{r\}$ 若已被本轮写过，值 $v$ 会被加两次以上。修法二选一：mask 倒序（本文）或每轮拷贝 `ndp = dp[:]` 推新（每日题解 3276 的写法）。
4. **「至少选一格」**：值域全正 ⇒ $dp[full] \ge \max_{i,j} grid[i][j] > 0 = dp[0]$，自动满足，无需特判空方案。
5. **两种状态定义别混搭**：「$\subseteq mask$」版全 0 初始化、答案取 $dp[full]$；「恰为 $mask$」版必须 $-1$ 标记不可达、答案取 $\max(dp)$。混用（例如恰版却全 0 初始化）会引入「行被占但没加分」的假状态。
6. **同值重复格子**：同一值在同一行多次出现只 OR 进一个位；同值跨行出现则聚成一个行集合——都不需要显式去重。
7. **溢出与类型**：总分 $\le 10 \times 100 = 1000$，`int` 绰绰有余；C++ 用 `array<int, 101>` 而非 `unordered_map`，省哈希开销。
8. **调试技巧**：打印小样例的整张 $dp$ 表逐值核对（§3.4 的表可直接当标准答案），重点检查「加粗格子」是否恰好是本轮 $R(v) \cap mask$ 可达的那些——多出来的加粗格通常是正序更新 bug 的第一现场。

- **行数增大怎么办**：$m = 20$ 时 $2^{20} \approx 10^6$ 个状态尚可（$20 \times 2^{20} \times D$ 已近 $10^9$、需滚动与按位批处理）；$m \ge 25$ 起 bitmask 彻底失效，正解切换到**二分图最大权匹配**——KM 算法 $O(n^3)$ 或最小费用最大流。本题本质就是指派问题（assignment problem），状压 DP 只是 $m \le 10$ 时的捷径。
- **值域与解法解耦**：值只是「阶段」不是「状态」，$D$ 上限由格子数 $mn$ 决定、与值域大小无关——把值域放到 $10^9$ 对本解法毫无影响，这是「压小侧、枚举大侧」的红利；反过来若**列**也加约束（不同列、不同行），状态就得带上列集合，$2^{20}$ 仍可行但已是极限。
- **负值 / 计数变体**：若值可能为负，「至少选一格」与「值不值得选」都要显式处理（$\subseteq$ 定义会把负值全部跳过）；若把目标改成「恰好选 $k$ 个值」，状态需附加已选个数维度 $dp[mask][j]$，转移与证明骨架不变。
