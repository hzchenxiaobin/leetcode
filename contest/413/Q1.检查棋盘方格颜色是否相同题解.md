# LeetCode 检查棋盘方格颜色是否相同 题解

## 1. 题目概述

- **标题 / 题号**：检查棋盘方格颜色是否相同（#3274，easy）
- **链接**：https://leetcode.cn/problems/check-if-two-chessboard-squares-have-the-same-color/
- **来源**：LeetCode 第 413 场周赛 Q1
- **难度**：简单
- **标签**：数学、字符串

**题意**：给两个字符串 `coordinate1` 和 `coordinate2`，表示 8×8 国际象棋棋盘上两个方格的坐标（先字母表示列 `a`~`h`，再数字表示行 `1`~`8`）。若两个方格颜色相同返回 `true`，否则返回 `false`。

**约束**：

- `coordinate1.length == coordinate2.length == 2`
- `'a' <= coordinate1[0], coordinate2[0] <= 'h'`
- `'1' <= coordinate1[1], coordinate2[1] <= '8'`
- 坐标总是有效，无需校验

## 2. 示例

**示例 1**

```text
输入：coordinate1 = "a1", coordinate2 = "c3"
输出：true
解释：两个方格均为黑色。
```

**示例 2**

```text
输入：coordinate1 = "a1", coordinate2 = "h3"
输出：false
解释：方格 "a1" 是黑色，而 "h3" 是白色。
```

**示例 3**

```text
输入：coordinate1 = "a1", coordinate2 = "a2"
输出：false
解释：上下相邻的两个方格必然一黑一白。
```

## 3. 解题思路

### 3.1 暴力思路：建棋盘查表

按国际象棋规则建一个 8×8 颜色表，再查两个格子颜色是否一致。可行但完全没必要——**方格颜色本身就被坐标唯一决定**，连表都不用建，直接算即可。

### 3.2 核心观察：颜色 =（列号 + 行号）的奇偶性

![棋盘染色与坐标奇偶性](images/chess_color_parity_concept.svg)

把列字母转成列号 $col \in [1,8]$（`a`→1，…，`h`→8），行字符转成行号 $row \in [1,8]$，则：

- $col + row$ 为**偶数** → **黑格**（如 `a1`：$1+1=2$）
- $col + row$ 为**奇数** → **白格**（如 `h3`：$8+3=11$）

因此**两格同色 ⟺ 两个坐标和的奇偶性相同**：

$$\text{同色} \iff (col_1 + row_1) \equiv (col_2 + row_2) \pmod 2$$

**字符编码捷径**：`'a'`~`'h'` 与 `'1'`~`'8'` 在 ASCII 中各自连续，所以 $(s[0]+s[1]) \bmod 2$ 与 $(col+row) \bmod 2$ 奇偶一致（引理 2 给出证明），连下标转换都省了，一行搞定。

### 3.3 算法流程

```text
1. 取 c1 = coordinate1[0], r1 = coordinate1[1]
2. 取 c2 = coordinate2[0], r2 = coordinate2[1]
3. 返回 (c1 + r1) % 2 == (c2 + r2) % 2
```

### 3.4 示例演算

| 坐标 | 字符码和 | 奇偶 | 颜色 |
|------|----------|------|------|
| `a1` | $97 + 49 = 146$ | 偶 | 黑 |
| `c3` | $99 + 51 = 150$ | 偶 | 黑 |
| `h3` | $104 + 51 = 155$ | 奇 | 白 |

- `a1` vs `c3`：146 与 150 同为偶数 → 同为黑格 → `true` ✓
- `a1` vs `h3`：146 偶、155 奇 → 一黑一白 → `false` ✗

![示例演算：同色与异色](images/chess_color_example_walkthrough.svg)

## 4. 算法细节

1. **下标转换**：$col = s[0] - \text{'a'} + 1$，$row = s[1] - \text{'0'}$，均落在 $[1,8]$。
2. **颜色判据**：$(col + row) \bmod 2$，偶为黑格、奇为白格（以题面示例 `a1` 为黑校准）。
3. **同色判定**：两个格子各自算奇偶值，比较是否相等即可，甚至无需真的区分黑白。
4. **字符码捷径的由来**：$col + row = (s[0] + s[1]) - (\text{'a'} + \text{'0'} - 1)$，而 $\text{'a'} + \text{'0'} - 1 = 97 + 48 - 1 = 144$ 是偶数，故 $s[0]+s[1]$ 与 $col+row$ 奇偶性相同，可直接用字符码求和取模。

## 5. 正确性证明

**引理 1**：8×8 棋盘上，方格 $(col, row)$ 的颜色由 $(col+row) \bmod 2$ 唯一决定，且相邻方格（左右或上下）颜色必然不同。

**证明**：国际象棋棋盘黑白相间：从任意方格向左/右移动一步 $col$ 变化 1，向上/下移动一步 $row$ 变化 1，二者都使 $col+row$ 的奇偶性翻转，颜色随之翻转。以题面校准 `a1` 为黑格（$1+1=2$ 为偶），归纳得坐标和为偶的是黑格、为奇的是白格。∎

**引理 2**：对任意合法坐标字符串 $s$，有 $(s[0] + s[1]) \bmod 2 = (col(s) + row(s)) \bmod 2$。

**证明**：$col(s) + row(s) = (s[0] + s[1]) - (\text{'a'} + \text{'0'} - 1) = (s[0] + s[1]) - 144$。两数相差偶数 144，奇偶性相同。∎

**定理**：`coordinate1` 与 `coordinate2` 同色，当且仅当 $(s_1[0] + s_1[1]) \bmod 2 = (s_2[0] + s_2[1]) \bmod 2$。

**证明**：由引理 1，同色 ⟺ $(col_1 + row_1) \equiv (col_2 + row_2) \pmod 2$；由引理 2，每个坐标的 $col + row$ 可替换为对应字符码之和且奇偶性不变，故等价于字符码和取模相等。∎

## 6. 复杂度分析

- **时间复杂度**：$O(1)$。只做 4 次字符读取、2 次加法与取模、1 次比较。
- **空间复杂度**：$O(1)$。仅常数个临时变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool checkTwoChessboards(string coordinate1, string coordinate2) {
        return (coordinate1[0] + coordinate1[1]) % 2 ==
               (coordinate2[0] + coordinate2[1]) % 2;
    }
};
```

### Python

```python
class Solution:
    def checkTwoChessboards(self, coordinate1: str, coordinate2: str) -> bool:
        return (ord(coordinate1[0]) + ord(coordinate1[1])) % 2 == \
               (ord(coordinate2[0]) + ord(coordinate2[1])) % 2
```

## 8. 边界情况与易错点

1. **不要建棋盘**：颜色由坐标奇偶性唯一决定，建 8×8 表是多余开销（虽也能过）。
2. **1 起始 vs 0 起始**：列号从 1 还是 0 开始算会让奇偶翻转，但只要两格用同一套约定，**同色判定不受影响**；只有需要明确回答"哪个是黑格"时才须校准（题面已给 `a1` 为黑）。
3. **坐标保证有效**：约束已限定字母 `a`~`h`、数字 `1`~`8`，无需合法性校验。
4. **自检手段**：相邻格必异色、同行同列相隔两格必同色，可用来快速验证实现。
5. **字符码捷径依赖 ASCII 连续性**：`'a'`~`'h'`、`'1'`~`'8'` 各自连续是捷径成立的前提，本题约束恰好保证。
