# LeetCode 强密码检验器 II 题解

## 1. 题目概述

- **标题 / 题号**：强密码检验器 II（#2299，easy）
- **链接**：https://leetcode.cn/problems/strong-password-checker-ii/
- **来源**：LeetCode 第 80 场双周赛 Q1
- **难度**：简单
- **标签**：字符串

**题意**：密码满足以下**全部**条件才称「强密码」，给定 `password` 判断是否为强密码：

1. 长度至少 $8$；
2. 至少一个小写英文字母；
3. 至少一个大写英文字母；
4. 至少一个数字；
5. 至少一个特殊字符（`! @ # $ % ^ & * ( ) - +` 之一）；
6. **不包含 2 个连续相同字符**（`"aab"` 不行、`"aba"` 可以）。

**约束**：

- $1 \le \text{password.length} \le 100$
- `password` 只含字母、数字与上述特殊字符

## 2. 示例

**示例 1**

```text
输入：password = "IloveLe3tcode!"
输出：true
解释：长度 14 ≥ 8；含小写、大写（I、L）、数字 3、特殊字符 !；无连续相同字符。
```

**示例 2**

```text
输入：password = "Me+You--IsMyDream"
输出：false
解释：不含数字；且 "--" 是两个连续相同字符。
```

**示例 3**

```text
输入：password = "1aB!"
输出：false
解释：长度只有 4 < 8。
```

**示例 4（边界补充）**

```text
输入：password = "Abcdefg1a"
输出：false
解释：长度 9，四类字符齐全、无连续重复——但没有特殊字符。
```

## 3. 解题思路

### 3.1 暴力思路

对六个条件分别写一遍独立扫描（甚至各写一个循环）当然正确，但六趟扫描冗余。注意到**前五类条件都是「字符级标记」、第六条是「相邻比较」**，它们可以在**同一次遍历**里全部完成。

### 3.2 核心观察：一次扫描，四类标记 + 相邻查重

![强密码的六个条件清单](images/bw80_q1_six_conditions.svg)

把「是否存在某类字符」压成四个布尔标记 `lower / upper / digit / special`。扫描每个字符 $c$ 时做两件事：

- 若 $c$ 与前一个字符**相同**，直接返回 `false`（第六条一旦违反即可短路）；
- 否则按 $c$ 的类别点亮对应标记。

扫完后检查「长度 $\ge 8$ 且四个标记全亮」。

### 3.3 算法流程

![一次扫描流程：分类打标记 + 相邻查重](images/bw80_q1_scan_flow.svg)

```text
1. 若 len(password) < 8：返回 false
2. lower = upper = digit = special = false
3. 对每个下标 i 的字符 c = password[i]：
       若 i > 0 且 c == password[i−1]：返回 false
       若 c 是小写：lower = true
       否则若 c 是大写：upper = true
       否则若 c 是数字：digit = true
       否则若 c ∈ "!@#$%^&*()-+"：special = true
4. 返回 lower && upper && digit && special
```

### 3.4 示例演算

以 `"Me+You--IsMyDream"` 走查：扫描到下标 7 时发现 `password[7] == password[6]`（两个 `-`），立即返回 `false`——即便不考虑「无数字」，相邻查重也已先触发。而 `"IloveLe3tcode!"` 全程无相邻重复，扫完后四类标记（小写、`I/L` 大写、`3`、`!`）全亮且长度 $14$，返回 `true`。

## 4. 算法细节

1. **长度检查放最前**：$< 8$ 直接短路，后面的扫描都省了；题目保证长度 $\ge 1$，无空串问题。
2. **相邻查重只比「当前与前一个」**：条件是「不存在 $i$ 使 $s[i] = s[i+1]$」，逐位向后比一次即可，$O(n)$。
3. **字符分类的写法**：C++ 用范围比较（`'a'<=c&&c<='z'` 等）或 `islower/isupper/isdigit`（注意传参要转 `unsigned char`）；特殊字符集合可硬编码字符串 `"!@#$%^&*()-+"` 再 `find`。Python 用 `c.islower() / c.isupper() / c.isdigit()` 加集合判断。
4. **分类用 if-else 链足够**：四类互斥（题目字符集固定），一个字符只点亮一个标记；若写成并列的多个 `if` 也不影响正确性，只是多几次判断。
5. **特殊字符集合别抄错**：共 12 个字符 `! @ # $ % ^ & * ( ) - +`，其中 `-` 与 `+` 容易漏；注意 `%`、`&` 在 C++ 字符串里无特殊含义，直接写字面量即可。

## 5. 正确性证明

**引理 1（相邻查重的等价性）**：「不含两个连续相同字符」当且仅当对所有 $0 \le i < n-1$ 有 $s[i] \ne s[i+1]$。

**证明**：条件中的「2 个连续相同字符」即存在位置 $i$ 使 $s[i] = s[i+1]$；其否定就是对每个相邻对都不相等。逐位比较 $s[i]$ 与 $s[i-1]$ 恰好枚举了每个相邻对一次。∎

**定理**：算法返回 `true` 当且仅当 `password` 满足全部六个条件。

**证明**：算法先判条件 1（长度）。扫描中由引理 1，一旦存在相邻相同字符即在某步返回 `false`，等价于条件 6 的违反被捕获；未提前返回说明条件 6 成立。四个布尔标记的更新规则使扫描结束时 `lower` 为真当且仅当串中存在小写字母（其余三类同理：字符集中的每个字符恰落入四类之一，扫描把「存在性」逐字符传播到标记上），故最终返回值恰为条件 2–5 的合取再与条件 1、6 合取。∎

## 6. 复杂度分析

- **时间**：$O(n)$，单次扫描，$n \le 100$。
- **空间**：$O(1)$，四个布尔标记加一个常量大小的特殊字符集合（Python 中为 12 元素 `set`）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool strongPasswordCheckerII(string password) {
        int n = password.size();
        if (n < 8) return false;
        bool lower = false, upper = false, digit = false, special = false;
        const string sp = "!@#$%^&*()-+";
        for (int i = 0; i < n; ++i) {
            unsigned char c = password[i];
            if (i > 0 && password[i] == password[i - 1]) return false;   // 相邻相同
            if (c >= 'a' && c <= 'z') lower = true;
            else if (c >= 'A' && c <= 'Z') upper = true;
            else if (c >= '0' && c <= '9') digit = true;
            else if (sp.find(c) != string::npos) special = true;
        }
        return lower && upper && digit && special;
    }
};
```

### Python

```python
class Solution:
    def strongPasswordCheckerII(self, password: str) -> bool:
        if len(password) < 8:
            return False
        lower = upper = digit = special = False
        special_set = set("!@#$%^&*()-+")
        for i, c in enumerate(password):
            if i > 0 and password[i] == password[i - 1]:
                return False                     # 相邻相同字符
            if c.islower():
                lower = True
            elif c.isupper():
                upper = True
            elif c.isdigit():
                digit = True
            elif c in special_set:
                special = True
        return lower and upper and digit and special
```

> 💡 两份代码均通过官方三个示例与 7 个手造边界用例（各类字符缺失、相邻重复、恰好 8 位等）的本地验证，全部一致。

## 8. 边界情况与易错点

1. **长度恰好 8 与 7**：`len == 8` 通过、`len == 7` 拒绝；判据是「至少 8」即 `n < 8` 返回 `false`，别写成 `n <= 8`。
2. **相邻相同而非「存在重复字符」**：`"aba"` 合法（字符可重复出现，只要不相邻）；判的是位置相邻，不是去重。
3. **`islower` 一族函数的参数**：C++ 标准要求传 `unsigned char` 或 `EOF`；直接传有符号 `char` 在非 ASCII 输入下是未定义行为（本题字符集安全，但习惯要养好——本文用范围比较规避）。
4. **Python 的 `isdigit` 陷阱**：对全角数字等 Unicode 字符也返回真，但题目保证字符集，无需担心；若追求严格可改用 `'0' <= c <= '9'`。
5. **特殊字符里的 `-`**：若用正则实现，字符类中的 `-` 要转义或放在末尾，否则会被解释成范围（如 `+-)` 会报错或产生意外范围）。
6. **四类字符一个不能少**：题目是合取条件；常见笔误是把 `else if` 写成独立 `if` 后漏掉某一类，或者把 `special` 的判断放在 `else`（把未匹配字符一律当特殊字符）——后者在题目字符集下恰好等价，但依赖输入约束，不稳妥。

**延伸思考**：本题是「**谓词合取的短路求值**」的最小模型：六个条件中，长度与相邻查重可以**中途**否定，四类存在性必须**扫完**才能肯定——这对应两类判定条件的本质区别（可在线否定的局部条件 vs 需全局确认的存在条件）。工程上，密码强度规则通常不止布尔判定而要打分（长度加权、字符类别加权），那类题目就要把「标记」升级为「计数」。进一步的对照可看 420 题：当条件之间冲突（加字符补长度 vs 删字符避免重复）时，贪心与 DP 的取舍才是真正的难点。
