# LeetCode 统计得分小于 K 的子数组数目 题解

## 1. 题目概述

- **标题 / 题号**：统计得分小于 K 的子数组数目（#2302，hard）
- **链接**：https://leetcode.cn/problems/count-subarrays-with-score-less-than-k/
- **来源**：LeetCode 第 80 场双周赛 Q4
- **难度**：困难
- **标签**：数组、二分查找、前缀和、滑动窗口

**题意**：数组的**分数**定义为「元素和 $\times$ 长度」。给定**正整数**数组 `nums` 与整数 $k$，返回分数**严格小于** $k$ 的**非空**子数组（连续）数目。

**约束**：

- $1 \le \text{nums.length} \le 10^5$
- $1 \le \text{nums}[i] \le 10^5$
- $1 \le k \le 10^{15}$

## 2. 示例

**示例 1**

```text
输入：nums = [2,1,4,3,5], k = 10
输出：6
解释：分数 < 10 的子数组：[2](2)、[1](1)、[4](4)、[3](3)、[5](5)、[2,1](6)。
     注意 [1,4] 分数 = 5×2 = 10 不小于 10，不算。
```

**示例 2**

```text
输入：nums = [1,1,1], k = 5
输出：5
解释：除 [1,1,1]（分数 9）外全部 5 个子数组分数都 < 5。
```

**示例 3（边界补充）**

```text
输入：nums = [100000], k = 1
输出：0
解释：k=1 时任何非空子数组分数 ≥ 1，「严格小于」一个都凑不出。
```

## 3. 解题思路

### 3.1 暴力思路

枚举全部 $O(n^2)$ 个子数组、维护区间和逐个判分——$n = 10^5$ 时 $10^{10}$ 级操作，超时。二分 + 前缀和（对每个右端点二分最短可行左端点，前缀和 $O(1)$ 取和）可降到 $O(n \log n)$，已能通过；但正数数组给了更强的结构，可以做到 $O(n)$。

### 3.2 核心观察：分数对窗口两端都单调 → 双指针

![单调性：固定左端扩张右端，score 严格增大](images/bw80_q4_monotonicity.svg)

由于 `nums` 全为**正数**：

- 固定左端 $l$，右端 $r$ 右移时**和与长度同时增大**，分数 $\text{sum}(l..r) \times (r-l+1)$ **严格递增**——一旦超标，$r$ 再怎么右移都救不回来，该 $l$ 对更大的 $r$ 永久失效；
- 固定右端 $r$，左端 $l$ 右移时和与长度同时减小，分数严格递减——收缩总能（在窗口非空的前提下）把分数压下来。

于是「合法左端点」随 $r$ 的推进**单调不降**，左指针 $l$ 无需回退——这正是**滑动窗口**适用的标准形态。

### 3.3 算法流程：右扩左缩，按右端点计数

![滑动窗口流程与计数含义](images/bw80_q4_sliding_window.svg)

```text
l = 0, sum = 0, ans = 0
对每个右端点 r = 0..n−1：
    sum += nums[r]
    while l ≤ r 且 sum × (r − l + 1) ≥ k：   # 分数不达标 → 收缩
        sum −= nums[l]，l += 1
    ans += r − l + 1                          # [l, r] 内每个起点都合法
返回 ans
```

计数的正确性在于：若窗口 $[l, r]$ 分数 $< k$，则其任何**更短**的后缀 $[l', r]$（$l' > l$）和与长度都更小、分数必然更小；反之 $l' < l$ 的更长子数组已在前面的收缩中被淘汰。故以 $r$ 结尾的合法子数组恰有 $r - l + 1$ 个。

### 3.4 示例演算

![示例走查：五步计数得 6](images/bw80_q4_example_walkthrough.svg)

以示例 1 走查（$k = 10$）：$r{=}0$ 分数 $2$，计 1；$r{=}1$ 窗口 $[0,1]$ 分数 $3 \times 2 = 6$，计 2；$r{=}2$ 窗口 $[0,2]$ 分数 $7 \times 3 = 21 \ge 10$，收缩两次（去掉 2 得 $5\times2{=}10$ 仍不达标，再去掉 1 得 $[4]$ 分数 4 达标），计 1；$r{=}3$、$r{=}4$ 各收缩一次后计 1。累计 $1+2+1+1+1 = 6$。特别注意 $[1,4]$ 的分数恰为 $10$——**严格小于**的边界就卡在这里。

## 4. 算法细节

1. **「严格小于」**：收缩条件是 $\ge k$，等于 $k$ 也必须收缩（示例 1 的 $[1,4]$、示例走查中 $5\times2=10$ 的窗口都是边界提醒）。
2. **计数加的是窗口长度**：`ans += r - l + 1` 而非 `ans += 1`——每个右端点一次性计入以它结尾的全部合法子数组，这保证不重不漏。
3. **左指针可能越过右指针**：当 $\text{nums}[r] \ge k$（单元素都不达标）时循环执行到 $l = r + 1$、`sum = 0`，本轮计数 $r - l + 1 = 0$；循环条件 `l <= r` 防止越界收缩。
4. **`long long` 三处**：区间和最大 $10^5 \times 10^5 = 10^{10}$、分数最大 $10^{10} \times 10^5 = 10^{15}$、答案最大 $n(n+1)/2 \approx 5 \times 10^9$——求和变量、乘法表达式、返回值都必须 64 位；$k$ 本身达 $10^{15}$，也在 `long long` 范围内（$< 9.2 \times 10^{18}$）。
5. **乘法写在收缩循环内**：每次收缩后窗口变小、分数立即重算，不要先把窗口收过头再判。
6. **为什么不用前缀和 + 二分也行**：固定 $r$，分数关于 $l$ 单调，可二分最小合法 $l$（配合前缀和 $O(1)$ 取区间和），$O(n \log n)$。双指针版本是它的单调性加强版：相邻 $r$ 的最小合法 $l$ 不降。

## 5. 正确性证明

**引理 1（双向单调性）**：对正数数组，固定 $l$ 时分数 $\text{score}(l, r) = \text{sum}(l..r) \cdot (r - l + 1)$ 关于 $r$ 严格递增；固定 $r$ 时关于 $l$ 严格递减。

**证明**：$r \to r+1$ 时，$\text{sum}$ 增加 $\text{nums}[r+1] > 0$、长度增加 $1$，两个正因子均严格增大，乘积严格增大。对称地，$l \to l+1$ 时和减少 $\text{nums}[l] > 0$（长度 $\ge 1$ 时和仍为正）、长度减少 $1$，两因子均严格减小，乘积严格减小。∎

**引理 2（合法左端点构成后缀区间且端点单调）**：记 $L_r = \{\,l \le r : \text{score}(l, r) < k\,\}$。则 $L_r$ 是形如 $[l_r, r]$ 的区间（含空），且 $l_r$ 关于 $r$ 单调不降；以 $r$ 结尾的合法子数组恰 $|L_r| = r - l_r + 1$ 个。

**证明**：由引理 1 的第二部分，若 $l \in L_r$ 则一切 $l' \in [l, r]$ 也在 $L_r$（分数更小），故 $L_r$ 是以 $r$ 为右端的区间，设其左端为 $l_r$（无解时记 $l_r = r + 1$，区间为空）。再证单调：若 $l \notin L_{r}$ 即 $\text{score}(l, r) \ge k$，由引理 1 的第一部分 $\text{score}(l, r') \ge \text{score}(l, r) \ge k$ 对一切 $r' > r$ 成立，故 $l \notin L_{r'}$。即 $L_{r'} \subseteq [l_r, r']$，得 $l_{r'} \ge l_r$。∎

**定理**：算法返回值等于分数严格小于 $k$ 的子数组总数。

**证明**：每个子数组由其右端点 $r$ 唯一归类。算法在第 $r$ 轮把窗口收缩到「分数 $< k$ 或为空」为止：由引理 1（第二部分）收缩停止时的 $l$ 恰为 $l_r$——若 $l > l_r$ 则 $l_r$ 合法但被跳过，与「收缩仅在分数 $\ge k$ 时发生」矛盾；若 $l < l_r$ 则窗口分数仍 $\ge k$，收缩不会停。故本轮计数 $r - l + 1 = |L_r|$，由引理 2 恰为以 $r$ 结尾的合法子数组数。对 $r$ 求和，全部子数组按右端点不重不漏地计入。∎

## 6. 复杂度分析

- **时间**：$O(n)$——$r$ 走 $n$ 步，$l$ 全程单调右移至多 $n$ 步，每次移动伴随 $O(1)$ 的和更新与一次乘法比较。
- **空间**：$O(1)$ 额外空间（仅指针、累加和与答案三个变量；对比前缀和 + 二分版本的 $O(n)$ 前缀数组）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long countSubarrays(vector<int>& nums, long long k) {
        long long ans = 0, sum = 0;
        int l = 0;
        for (int r = 0; r < (int)nums.size(); ++r) {
            sum += nums[r];
            while (l <= r && sum * (r - l + 1) >= k)   // 分数不小于 k → 左端收缩
                sum -= nums[l++];
            ans += r - l + 1;                           // 以 r 结尾的合法子数组
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def countSubarrays(self, nums: list[int], k: int) -> int:
        ans = 0
        l = 0
        s = 0
        for r, x in enumerate(nums):
            s += x
            while l <= r and s * (r - l + 1) >= k:   # 分数不小于 k → 左端收缩
                s -= nums[l]
                l += 1
            ans += r - l + 1                         # 以 r 结尾的合法子数组数
        return ans
```

> 💡 两份代码均通过官方示例（6、5）与边界用例（单元素 × 极端 $k$、全达标、收缩到空窗口），并与 $O(n^2)$ 枚举全部子数组的暴力在 **400 组随机数据**（$n \le 40$，含 $k$ 极小/极大、全相同元素）上对拍一致（`mismatch = 0`）；另在 $n = 10^5$ 随机大数组、四档 $k$ 下做了 C++/Python 双语言一致性验证。

## 8. 边界情况与易错点

1. **「严格小于」**：`>= k` 就收缩。$[1,4]$ 分数恰为 10 而被排除、示例 2 中 $[1,1]$ 分数 $4 < 5$ 被保留——两个官方示例都在敲打这个边界，本地务必用「分数恰等于 $k$」的用例自测。
2. **溢出（本题最大陷阱）**：分数可达 $10^{10} \times 10^5 = 10^{15}$，`int` 必炸；答案可达约 $5 \times 10^9$ 也超 `int`。C++ 中 `sum`、乘法、`ans` 全链路 `long long`；Python 天然大整数无虞。
3. **窗口可被收缩成空**：$\text{nums}[r] \ge k$ 时 $l$ 越过 $r$，本轮计 0；循环条件 `l <= r` 与计数 `r - l + 1`（可能为 0）都要能承载这种状态，别把空窗当非法中断。
4. **计数别写成 `ans += 1` 或 `ans += r - l`**：按右端点统计的是「起点 ∈ $[l, r]$」的全部子数组，差一错误会把答案系统性算小。
5. **正数条件不可去**：若有 0 或负数，引理 1 的单调性崩溃（负数让和可先减后增），双指针失效，须回到前缀和 + 有序结构或分治。本题约束明示正数，是滑动窗口的「许可证」。
6. **$k$ 上限 $10^{15}$ 恰在 `long long` 内**：不要因为「题目给了大数」就贸然用浮点（`double` 只有 53 位尾数，$10^{15}$ 边缘的比较会出错），全程整数运算。
