# LeetCode 将元素分配给有约束条件的组 题解

## 1. 题目概述

- **标题 / 题号**：将元素分配给有约束条件的组（#3447，medium）
- **链接**：https://leetcode.cn/problems/assign-elements-to-groups-with-constraints/
- **来源**：LeetCode 第 436 场周赛 Q2
- **难度**：中等
- **标签**：数组、哈希表、枚举

**题意**：给定整数数组 `groups`（`groups[i]` 为第 $i$ 组的大小）与整数数组 `elements`，为每个组分配**一个**元素：

- 若 `groups[i]` 能被 `elements[j]` 整除，元素 $j$ 可以分配给组 $i$；
- 多个元素满足条件时，取**最小的下标** $j$；
- 没有元素满足条件时，分配 $-1$。

返回数组 `assigned`。**一个元素可以分配给多个组**——组与组互不影响。

**约束**：

- $1 \le \text{groups.length} \le 10^5$
- $1 \le \text{elements.length} \le 10^5$
- $1 \le \text{groups[i]},\ \text{elements[j]} \le 10^5$

> 💡 **读题关键**：① 「元素可复用」说明这是 $n$ 个**互相独立**的查询，不是匹配/流问题；② 答案只取决于 `groups[i]` 的**数值**而非下标，同值组答案必然相同；③ 值域被压在 $10^5$——这是复杂度的钥匙（见 3.2）；④ 「取最小下标」意味着同值元素只有**首次出现**的有用，天然可去重。

## 2. 示例

**示例 1**

```text
输入：groups = [8,4,3,2,4], elements = [4,2]
输出：[0,0,-1,1,0]
解释：elements[0] = 4 分配给组 0、1、4；elements[1] = 2 分配给组 3；
      无法为组 2 分配任何元素，分配 -1。
```

**示例 2**

```text
输入：groups = [2,3,5,7], elements = [5,3,3]
输出：[-1,1,0,-1]
解释：elements[1] = 3 分配给组 1；elements[0] = 5 分配给组 2；
      无法为组 0 和组 3 分配任何元素。
```

**示例 3**

```text
输入：groups = [10,21,30,41], elements = [2,1]
输出：[0,1,0,1]
解释：偶数值的组被 elements[0] = 2 整除，奇数值的组被 elements[1] = 1 整除。
```

## 3. 解题思路

### 3.1 暴力思路

按题面直译：对每个组 `groups[i]` 从 $j=0$ 起顺序扫描 `elements`，返回第一个满足 `groups[i] % elements[j] == 0` 的下标，扫完无果则记 $-1$。单次最坏 $O(m)$，总体 $O(n \cdot m)$；上界 $n = m = 10^5$ 时约 $10^{10}$ 次取模，必然超时。

瓶颈在于：**大量组在重复扫描同一段 elements**，而整除关系只由两边的**数值**决定——相同数值的组做了成千上万遍完全相同的扫描。

### 3.2 核心观察：调转视角，值 $v$ 给倍数盖「首现下标」戳

![调转视角与盖戳概念](images/c436_q2_sieve_concept.svg)

三个观察把暴力压到线性对数：

1. **查询可合并**：组间独立 + 答案只依赖组值 $g$ ⇒ 本质是「对每个出现过的组值 $g$，求最小的 $j$ 使 $v_j \mid g$」的**重复查询**，相同的 $g$ 只需算一次；
2. **整除关系可反向摊销**：$v \mid m \iff m$ 是 $v$ 的倍数。与其让每个组去找因数，不如让每个**出现的元素值** $v$ 主动把 $v, 2v, 3v, \dots \le M$ 全部盖一遍戳——这正是埃氏筛「划掉倍数」的骨架。盖戳总量
$$\sum_{v=1}^{M} \left\lfloor \frac{M}{v} \right\rfloor \approx M \ln M \approx 1.2 \times 10^6$$
是调和级数，**与 $n$、$m$ 都无关**；
3. **同值去重留首现**：答案取最小下标 ⇒ 同值 $v$ 重复出现时，只有首次出现的下标 `first[v]` 可能成为答案，后到的同值永远被遮挡（示例 2 中第二个 3 就是摆设）。预处理 `first` 表后，每个值只盖一轮戳。

综合三者：预处理 `best[m]` = 「能整除 $m$ 的出现值中，`first[v]` 的最小值」，随后每组 $O(1)$ 查表。

### 3.3 算法流程：建表 → 盖戳 → 查表

![算法流程](images/c436_q2_algorithm_flow.svg)

1. **建 `first` 表**：`first[v]` 初始化为 $-1$，顺序扫描 `elements`，先到先得（天然留首现），$O(m)$；
2. **筛倍数盖戳**：`best[m]` 初始化为 $-1$；枚举 $v = 1 \dots M$，若 `first[v] ≠ -1`，对 $m = v, 2v, 3v, \dots \le M$ 更新 `best[m] = min(best[m], first[v])`；
3. **查表输出**：`assigned[i] = best[groups[i]]`，$O(n)$。

> ⚠️ 与埃氏筛的差别：埃氏筛可以从 $i^2$ 起步、布尔标记「划过即弃」；本题**必须从 $m = v$ 盖起**（组值恰为 $v$ 时要能查到自己），且同一 $m$ 会被多个 $v$ 重复盖戳（如 8 同时被 2 和 4 盖），靠 `min` 收敛，**不能「已盖就跳过」**。

### 3.4 示例演算

![示例演算](images/c436_q2_example_walkthrough.svg)

以示例 1 为例（`groups = [8,4,3,2,4]`，`elements = [4,2]`）：建表得 `first[4] = 0`、`first[2] = 1`；$v = 4$ 给 $4, 8, 12, \dots$ 盖 `0`，$v = 2$ 给 $2, 4, 6, 8, \dots$ 盖 `1`，重叠处取小；查表：$8 \to 0$、$4 \to 0$、$3 \to -1$（落空）、$2 \to 1$、$4 \to 0$，输出 `[0,0,-1,1,0]` ✓。

## 4. 算法细节

1. **先到先得 = 同值取 $\min$**：顺序扫描时只在 `first[elements[j]] == -1` 时写入，重复值自动被首现遮挡，无需显式 `min`；
2. **盖戳起点必须是 $m = v$**：若模仿埃氏筛从 $2v$ 起步，「组值恰等于元素值」的查询会落空；从 $v$ 起步同时保证 `best[v]` 有值；
3. **$-1$ 哨兵复用**：`best` 初始化 $-1$ 既表示「未盖戳」，又恰好是落空时的答案，查表阶段无需特判；
4. **盖戳上界可压到 $\max(\text{groups})$**：$m > \max(\text{groups})$ 的戳永远查不到，把 $M$ 取为组值最大值（而非固定 $10^5$）可省常数；同理外层枚举到 $M$ 即可停——$v > M$ 的值连一个可盖的倍数都没有；
5. **min 更新写法**：`if (best[m] == -1 || first[v] < best[m])` 两个分支缺一不可——直接写 `min(first[v], best[m])` 会在 `best[m] == -1` 时把 $-1$ 当成更小值留下，导致有解的组错误输出 $-1$；
6. **Python 写法**：内层 `for m in range(v, M + 1, v)`；外层 $10^5$ 次空转（值未出现时 `continue`）是可接受的常数。

## 5. 正确性证明

**引理 1（首现遮挡）**：设值 $v$ 在 `elements` 中出现于下标 $j_1 < j_2$，则在任何组的候选集中删除 $j_2$ 不改变答案。

**证明**：若 $v$ 可分配给某组 $g$（即 $v \mid g$），则 $j_1, j_2$ 同时满足条件，而题目取最小下标，$j_2$ 永远被 $j_1$ 遮挡；若 $v \nmid g$，两者都不可分配。故删除 $j_2$ 无影响。∎

**引理 2（答案表达式）**：对 $g = \text{groups[i]}$，有
$$\text{assigned}[i] = \min\{\, \text{first}[v] : v \text{ 出现于 elements 且 } v \mid g \,\},$$
集合为空时为 $-1$。

**证明**：记 $J = \{ j : \text{elements}[j] \mid g \}$，$F = \{ \text{first}[v] : v \text{ 出现且 } v \mid g \}$。
一方面，取 $j^* = \min J$，令 $v^* = \text{elements}[j^*]$，则 $\text{first}[v^*] \le j^*$ 且 $\text{first}[v^*] \in F$，故 $\min F \le j^*$；
另一方面，任取 $\text{first}[v] \in F$，它是值 $v$ 某次出现的下标且 $v \mid g$，故 $\text{first}[v] \in J$，从而 $\min J \le \text{first}[v]$，对全体成员取下界得 $\min J \le \min F$。
两侧夹得 $\min J = \min F$，且两集合同时为空（$v$ 出现且 $v \mid g$ ⇔ 存在 $j$ 使 $\text{elements}[j] = v \mid g$）。∎

**定理**：算法输出即为所求答案。

**证明**：先证盖戳阶段的不变量——对每个 $m \in [1, M]$，盖戳结束后
$$\text{best}[m] = \min\{\, \text{first}[v] : v \text{ 出现且 } v \mid m \,\} \quad (\text{空集记 } -1).$$
外层枚举了 $[1, M]$ 内全部 $v$，而约束保证出现值不超过 $M$，故每个「出现且整除 $m$」的 $v$ 恰有一轮盖戳，其内层循环覆盖 $m$ 当且仅当 $v \mid m$；`best[m]` 自 $-1$ 起对这些 `first[v]` 逐次取 `min`，恰收敛到集合最小值。再由约束 $\text{groups[i]} \le M$，查表 `best[groups[i]]` 命中该值，结合引理 2 即得 $\text{assigned}[i]$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n + m + M \log M)$。
  - 建 `first` 表 $O(m)$，查表输出 $O(n)$；
  - 盖戳 $\sum_{v=1}^{M} \lfloor M/v \rfloor \approx M \ln M$（调和级数）：一半的值盖不超过 $M/2$ 个戳、四分之三的值盖不超过 $M/4$ 个……越大的值戳越稀。$M = 10^5$ 时精确总和为 $1{,}166{,}750 \approx 1.2 \times 10^6$，纯 Python 亦能在 0.2 秒内完成；
  - 对照暴力 $O(n \cdot m) \approx 10^{10}$，快了将近四个数量级。
- **空间复杂度**：$O(M)$——`first` 与 `best` 两个值域数组，与 $n$、$m$ 无关。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> assignElements(vector<int>& groups, vector<int>& elements) {
        const int M = 100000;
        vector<int> first(M + 1, -1);
        for (int j = 0; j < (int)elements.size(); ++j) {
            if (first[elements[j]] == -1) {
                first[elements[j]] = j;   // 先到先得，同值留首现
            }
        }
        vector<int> best(M + 1, -1);
        for (int v = 1; v <= M; ++v) {
            if (first[v] == -1) continue;
            for (int m = v; m <= M; m += v) {   // 必须从 m = v 盖起
                if (best[m] == -1 || first[v] < best[m]) {
                    best[m] = first[v];   // 多戳取 min 收敛
                }
            }
        }
        vector<int> assigned;
        assigned.reserve(groups.size());
        for (int g : groups) {
            assigned.push_back(best[g]);  // -1 哨兵即落空答案
        }
        return assigned;
    }
};
```

### Python

```python
class Solution:
    def assignElements(self, groups: List[int], elements: List[int]) -> List[int]:
        M = 100_000
        first = [-1] * (M + 1)
        for j, v in enumerate(elements):
            if first[v] == -1:
                first[v] = j   # 先到先得，同值留首现
        best = [-1] * (M + 1)
        for v in range(1, M + 1):
            j = first[v]
            if j == -1:
                continue
            for m in range(v, M + 1, v):   # 必须从 m = v 盖起
                if best[m] == -1 or j < best[m]:
                    best[m] = j   # 多戳取 min 收敛
        return [best[g] for g in groups]    # -1 哨兵即落空答案
```

## 8. 边界情况与易错点

1. **值 1 出现**：$v = 1$ 整除一切，`best` 全被盖戳，任何组都不会落空——可作小数据自测的对照情形；
2. **组值为 1**：唯一可能的因数是 1，`m = 1` 只会被 $v = 1$ 盖到，`elements` 无 1 时正确落空 $-1$；
3. **去重不可省**：若按「每个下标 $j$ 都盖一轮戳」实现且 `elements` 全为 1，盖戳量退化到 $O(m \cdot M) = 10^{10}$；`first` 去重后同输入只需一轮 $10^5$ 个戳；
4. **盖戳起点**：从 $2v$ 或 $v^2$ 起步都会让「组值恰等于元素值」的查询落空（除非另有更小因数），是 WA 高发点；
5. **min 更新的哨兵分支**：`best[m] == -1` 必须先判断，直接 `min()` 会把 $-1$ 当成更小值保留，导致有解的组输出 $-1$；
6. **数组大小**：`first`/`best` 开 $M + 1$，保证 `best[groups[i]]` 不越界；C++ 记得 `assigned.reserve`；
7. **答案语义**：输出的是**下标**不是元素值，落空是 $-1$ 而非 0——示例 1 中组 3 拿到的是 `elements[1]` 的下标 1，别顺手输出元素值。
