# LeetCode 按对角线进行矩阵排序 题解

## 1. 题目概述

- **标题 / 题号**：按对角线进行矩阵排序（#3446，medium）
- **链接**：https://leetcode.cn/problems/sort-matrix-by-diagonals/
- **来源**：LeetCode 第 436 场周赛 Q1
- **难度**：中等
- **标签**：数组、矩阵、排序

**题意**：给定 $n \times n$ 整数方阵 `grid`，沿「左上 → 右下」（↘）方向把矩阵切成 $2n-1$ 条对角线，返回按下述规则调整后的矩阵：

- **左下角三角形**（包括主对角线）的对角线按**非递增**顺序排序；
- **右上角三角形**的对角线按**非递减**顺序排序。

**约束**：

- $1 \le n \le 10$
- $-10^5 \le grid[i][j] \le 10^5$

本场 Q1 官方评级 medium：算法上没有难度，但「主对角线归哪边」「沿什么顺序写回」两道小坎，正是「5 分钟签到位」与「WA 一发再罚 10 分钟」的分水岭。

## 2. 示例

**示例 1**

```text
输入：grid = [[1,7,3],[9,8,2],[4,5,6]]
输出：[[8,2,3],[9,6,7],[4,5,1]]
解释：左下三角（含主对角线）按非递增排序：
        主对角线 [1,8,6] → [8,6,1]；[9,5]、[4] 已符合要求
      右上三角按非递减排序：
        [7,2] → [2,7]；[3] 已符合要求
```

**示例 2**

```text
输入：grid = [[0,1],[1,2]]
输出：[[2,1],[1,0]]
解释：主对角线 [0,2] 按非递增排序变为 [2,0]，其余对角线不变。
```

**示例 3**

```text
输入：grid = [[1]]
输出：[[1]]
解释：只有一个元素的对角线无需修改。
```

## 3. 解题思路

### 3.1 暴力思路

最朴素的做法：枚举全部 $2n-1$ 条对角线，对每条线**扫一遍全矩阵**挑出满足 $i - j = d$ 的格子，排序后写回——每条线 $O(n^2)$，总计 $O(n^3)$。本题 $n \le 10$，这个都能过。

但 Q1 的目标从来不是「能过」，而是**又快又稳**。真正要做的只有两件事：

1. **枚举不重不漏**：每条对角线怎么 $O(1)$ 定位起点，一次走完？
2. **方向与写回顺序**：每条线升序还是降序？值放回格子时按什么顺序对齐？

### 3.2 核心观察：$d = i - j$ 是对角线的「身份证」

![对角线分区概念：d = i−j 的符号划分两个三角形](images/c436_q1_triangle_concept.svg)

三个关键事实：

1. **同一条对角线 ⇔ $i - j$ 相同**。沿 ↘ 方向走一步，$i$、$j$ 各加 1，差值 $d = i - j$ 保持不变；不同对角线的 $d$ 互不相同。$d \in [-(n-1),\, n-1]$，共 $2n-1$ 条。
2. **$d$ 的符号天然划分两个三角形**：$d \ge 0$ ⇔ $i \ge j$，格子全在主对角线及其左下方（**含主对角线 $d = 0$**），降序；$d < 0$ ⇔ $i < j$，格子全在右上三角，升序。**一次符号判断定方向**。
3. **起点可 $O(1)$ 定位**：$d \ge 0$ 的线从 $(d, 0)$ 出发，$d < 0$ 的线从 $(0, -d)$ 出发，之后每次 $i{+}{+}$、$j{+}{+}$ 直到出界，无需扫描全矩阵找成员。

再加上一条支撑「逐条独立处理」的性质：$2n-1$ 条对角线**恰好划分**全部 $n^2$ 个格子，每格只属于一条——对角线之间互不干扰，各自「取出 → 排序 → 写回」即可。

### 3.3 算法流程：取出 → 定向排序 → 写回

![算法流程：逐条对角线取出、按 d 的符号决定排序方向、写回](images/c436_q1_algorithm_flow.svg)

统一让 $d$ 从 $-(n-1)$ 遍历到 $n-1$，每轮三步：沿 ↘ 收集该线元素 → 用**一次判断 $d \ge 0$** 决定降序/升序 → **按收集时的顺序**（$i$ 递增）把第 $k$ 个值写回第 $k$ 个格子。取出与写回走同一方向，位置天然对齐，不会错位。

### 3.4 示例演算

![示例演算：五条对角线逐一排序得到输出矩阵](images/c436_q1_example_walkthrough.svg)

以示例 1 为例：$n = 3$，共 5 条对角线。主对角线 $[1,8,6]$ 降序为 $[8,6,1]$，沿 ↘ 依次放回 $(0,0)$、$(1,1)$、$(2,2)$；$d=1$ 的 $[9,5]$ 与 $d=2$ 的 $[4]$ 已是非递增，保持原样；右上三角 $d=-1$ 的 $[7,2]$ 升序为 $[2,7]$，$d=-2$ 的 $[3]$ 不变。拼起来即输出 `[[8,2,3],[9,6,7],[4,5,1]]`。

## 4. 算法细节

1. **两个三角形的下标推导**（代码里两段循环的来源）：
   - 左下三角 $d = i - j \ge 0$：格子 $(i,\, i-d)$，$i \in [d,\, n)$，即 `(i, i-d) for i in range(d, n)`；
   - 右上三角 $e = j - i \ge 1$：格子 $(i,\, i+e)$，$i \in [0,\, n-e)$，即 `(i, i+e) for i in range(n-e)`。
2. **写回对齐**：收集时沿 ↘（$i$ 递增）把第 $k$ 个元素记为 `vals[k]`，写回时同样沿 ↘ 把第 $k$ 个格子填上 `vals[k]`——**取出的顺序 = 写回的顺序**。
3. **主对角线 $d = 0$ 归左下三角**（题目明确「包括中间对角线」），走降序分支。
4. **原地修改**：直接在 `grid` 上写回并返回即可，无需新建矩阵。
5. **统一遍历**：Python 里可把两段循环合并成一段——对 $d = i - j$ 统一取 `i in range(max(0, d), n - max(0, -d))`，排序方向直接写 `reverse=(d >= 0)`：

```python
class Solution:
    def sortMatrix(self, grid: List[List[int]]) -> List[List[int]]:
        n = len(grid)
        for d in range(1 - n, n):                    # d = i - j
            rng = range(max(0, d), n - max(0, -d))   # 该线上所有 i
            vals = sorted((grid[i][i - d] for i in rng), reverse=d >= 0)
            for i, v in zip(rng, vals):              # 第 k 个值 → 第 k 个格
                grid[i][i - d] = v
        return grid
```

## 5. 正确性证明

**引理 1（划分）**：$d = i - j$ 把 $[0, n)^2$ 的全部格子划分为 $2n-1$ 个非空对角线集合，每个格子恰属于一条。

**证明**：$d$ 的取值范围是 $[-(n-1),\, n-1]$；对每个 $d$，格集非空——$d \ge 0$ 时 $(d, 0)$ 在集合中，$d < 0$ 时 $(0, -d)$ 在集合中。「$i - j$ 相等」是格子上的等价关系，等价类即对角线集合，故诸集合两两不交且并集为全集。∎

**引理 2（归属）**：$d \ge 0$ 的格子恰为左下三角（含主对角线），$d < 0$ 的格子恰为右上三角。

**证明**：$i - j \ge 0 \iff i \ge j$，即 $(i,j)$ 位于主对角线上或其左下方；$i - j < 0 \iff i < j$，即位于右上三角。∎

**引理 3（唯一性）**：满足题意的输出矩阵唯一。

**证明**：每条对角线的格集合与元素多重集由输入唯一确定（引理 1）。对固定多重集，非递增序列唯一：首元素必为最大值（否则与后继逆序），去掉首元素后对剩余多重集归纳同理；非递减情形对称。故每条线的目标序列唯一，整个输出矩阵唯一。∎

**定理**：算法返回的矩阵恰为唯一满足题意的矩阵。

**证明**：对每条 $d$，循环区间恰覆盖该对角线的全部格子各一次（引理 1 的构造及第 4 节的边界推导），故 `vals` 是该线元素的完整多重集；由引理 2，$d \ge 0$ 时排序为非递增、$d < 0$ 时为非递减，与题意一致；写回把排序后的序列沿 ↘ 依序放置，使该线满足方向要求。各对角线两两不交（引理 1），互不影响，故输出矩阵合法；再由引理 3，它就是唯一的合法输出。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n^2 \log n)$。所有对角线长度之和恰为 $n^2$，取出与写回共 $O(n^2)$；各线排序代价之和 $\sum L \log L \le \log n \cdot \sum L = O(n^2 \log n)$。
- **空间复杂度**：$O(n)$。辅助数组只存当前一条对角线，最长 $n$ 个元素；原地写回，不计返回矩阵。

> 💡 输出本身有 $n^2$ 个数，$O(n^2)$ 是不可逾越的下界，$O(n^2 \log n)$ 已非常接近最优；$n \le 10$ 下连「每线重扫全矩阵」的 $O(n^3)$ 暴力都能过，本题比的是谁写得又快又对。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<vector<int>> sortMatrix(vector<vector<int>>& grid) {
        int n = grid.size();

        // 左下三角（含主对角线）：d = i - j ∈ [0, n-1]，非递增
        for (int d = 0; d < n; d++) {
            vector<int> vals;
            for (int i = d; i < n; i++) {
                vals.push_back(grid[i][i - d]);   // 起点 (d, 0)，沿 ↘ 收集
            }
            sort(vals.rbegin(), vals.rend());     // 降序
            for (int i = d; i < n; i++) {
                grid[i][i - d] = vals[i - d];     // 按收集顺序写回
            }
        }

        // 右上三角：e = j - i ∈ [1, n-1]，非递减
        for (int e = 1; e < n; e++) {
            vector<int> vals;
            for (int i = 0; i + e < n; i++) {
                vals.push_back(grid[i][i + e]);   // 起点 (0, e)，沿 ↘ 收集
            }
            sort(vals.begin(), vals.end());       // 升序
            for (int i = 0; i + e < n; i++) {
                grid[i][i + e] = vals[i];         // 按收集顺序写回
            }
        }
        return grid;
    }
};
```

### Python

```python
class Solution:
    def sortMatrix(self, grid: List[List[int]]) -> List[List[int]]:
        n = len(grid)

        # 左下三角（含主对角线）：d = i - j ∈ [0, n-1]，非递增
        for d in range(n):
            vals = sorted((grid[i][i - d] for i in range(d, n)), reverse=True)
            for i, v in zip(range(d, n), vals):
                grid[i][i - d] = v

        # 右上三角：e = j - i ∈ [1, n-1]，非递减
        for e in range(1, n):
            vals = sorted(grid[i][i + e] for i in range(n - e))
            for i, v in zip(range(n - e), vals):
                grid[i][i + e] = v

        return grid
```

## 8. 边界情况与易错点

1. **主对角线归属**：$d = 0$ 属左下三角、走**降序**——题目明确「包括中间对角线」，这是本题最常见的 WA 点；
2. **方向写反的自测**：交之前用示例 1 核对主对角线 `[1,8,6] → [8,6,1]`；若得到 `[1,6,8]`，说明左下三角误写成升序；
3. **写回错位**：收集沿 ↘（$i$ 递增），写回必须同向；若反向放置，降序线沿 ↘ 读出来就变成了升序，肉眼很难发现，务必保持「第 $k$ 个值 → 第 $k$ 个格」；
4. **$n = 1$**：左下循环只处理主对角线单格，右上循环 `range(1, 1)` 为空，直接返回原矩阵；
5. **重复元素**：非递增/非递减**含等号**，`sort` 对重复值天然满足，如全 5 矩阵排序后不变；
6. **原地 vs 新建**：直接改 `grid` 并返回即可，LeetCode 不检查输入是否被修改；
7. **下标笔误**：左下线访问 `grid[i][i-d]`（$i$ 从 $d$ 起），右上线访问 `grid[i][i+e]`（$i$ 从 0 起），两个三角形的偏移方向相反，别混用。
