# LeetCode 使数组等于目标数组所需的最少操作次数 题解

## 1. 题目概述

- **标题 / 题号**：使数组等于目标数组所需的最少操作次数（#3229，hard）
- **链接**：https://leetcode.cn/problems/minimum-operations-to-make-array-equal-to-target/
- **来源**：LeetCode 第 407 场周赛 Q4
- **难度**：困难
- **标签**：贪心、差分数组、单调栈、动态规划

**题意**：给定两个长度相同的正整数数组 `nums` 和 `target`。一次操作可以任选 `nums` 的一个**连续子数组**，将其中每个元素整体 **+1 或 −1**。返回使 `nums` 恰好变成 `target` 的最少操作次数。

**约束**：

- $1 \le n = |\text{nums}| = |\text{target}| \le 10^5$
- $1 \le \text{nums}[i], \text{target}[i] \le 10^8$

> 💡 **转化关键**：令 $d_i = \text{target}_i - \text{nums}_i$。「对 `nums` 的某个子数组做 ±1 操作」等价于「对 `d` 做同样的操作」。于是问题变成：**从全 0 数组出发，每次选一个区间整体 ±1，把 `d` 精确砌出来**，求最少操作次数。这是典型的「区间加减 → 差分数组」场景，难点在于 $d$ 有正有负。

## 2. 示例

**示例 1**

```text
输入：nums = [3,5,1,2], target = [4,6,2,4]
输出：2

解释：
- nums[0..3] 整体 +1 → nums = [4,6,2,3]
- nums[3..3] 再 +1   → nums = [4,6,2,4]
```

**示例 2**

```text
输入：nums = [1,3,2], target = [2,1,4]
输出：5

解释：全部用单点操作（+1, −1×2, +2）共 5 次。
```

**补充示例 3**

```text
输入：nums = [3,3], target = [4,1]
输出：3

解释：d = [1, −2]，两个位置需求方向相反，无法共享任何操作，
     至少 1 + 2 = 3 次：+1 操作 [0,0] ×1，−1 操作 [1,1] ×2。
```

## 3. 解题思路

### 3.1 暴力思路

- **逐位独立**：对每个位置 $i$ 单独做 $|d_i|$ 次单点操作，总代价 $\sum_i |d_i|$。这是一 个合法上界，但完全没利用「区间可以共享」：示例 1 中 $d = [1,1,1,2]$，逐位要 5 次，实际 2 次就够。
- **搜索**：状态空间（数组所有可能取值）无界且巨大，BFS/DP 都不可行。

顺带一提，LeetCode 1526（形成目标数组的子数组最少增加次数）是本题的「只有 +1、目标非负」版本，答案是 $\sum_i \max(0, t_i - t_{i-1})$。本题允许 ±1 且 $d$ 有正有负，**直接对 $|d|$ 套这个公式是经典错误**（见 3.5）。

### 3.2 核心观察：一次操作 = 扩展差分上的一对 (+1, −1)

给 $d$ 两端补哨兵 $d_{-1} = 0$、$d_n = 0$，定义**扩展差分**：

$$g_i = d_i - d_{i-1}, \qquad 0 \le i \le n$$

对子数组 $[l, r]$ 做一次操作，在 $g$ 上只会留下**两个**非零痕迹：

- **+1 操作**：$g_l$ 处 $+1$，$g_{r+1}$ 处 $-1$；
- **−1 操作**：$g_l$ 处 $-1$，$g_{r+1}$ 处 $+1$。

![一次操作在扩展差分上的效果](images/min_ops_equal_target_diff_model.svg)

这带来两个直接推论：

1. **下界**：无论哪种操作，每次都恰好提供 1 个 $+1$ 和 1 个 $-1$。要把每个位置的净变化凑成 $g_i$，位置 $i$ 至少要落 $\max(0, g_i)$ 个 $+1$，所以操作次数 $\ge \sum_{i=0}^{n} \max(0, g_i)$。
2. **可达**：由望远镜求和 $\sum_{i=0}^{n} g_i = 0$，$+1$ 需求总数 = $-1$ 需求总数。把它们**任意两两配对**，每一对 $(i, j)$（$i \ne j$）恰好是一次可执行的操作：$+1$ 在前就做 $[i, j-1]$ 的 +1 操作，$-1$ 在前就做 $[j, i-1]$ 的 −1 操作。

$$\boxed{\ \text{最少操作数} = \sum_{i=0}^{n} \max(0, g_i)\ }$$

由于扩展差分总和为 0，正数和 = 负数绝对值和，答案也等于序列 $(0, d_0, d_1, \ldots, d_{n-1}, 0)$ **总变差的一半**。

### 3.3 算法流程

一次线性扫描即可：

```text
prev ← 0            # 哨兵 d[-1] = 0
ans  ← 0
for i = 0 .. n-1:
    cur ← target[i] − nums[i]
    ans ← ans + max(0, cur − prev)     # g[i] 的正数部分
    prev ← cur
ans ← ans + max(0, −prev)              # 末端哨兵 g[n] = −d[n−1]
返回 ans
```

正数和 = 1 + 4 = 5 ✓

按配对构造还能还原出恰好 5 次操作：$+1$ 操作 $[0,0]$×1、$-1$ 操作 $[1,1]$×2、$+1$ 操作 $[2,2]$×2——与官方解释完全一致。

**示例 1**：$d = [1,1,1,2]$，$g = [1,0,0,1,-2]$，正数和 $= 1 + 1 = 2$ ✓（对应 $+1$ 操作 $[0,3]$ 与 $+1$ 操作 $[3,3]$）。

### 3.5 常见误区与等价视角

**误区**：把 $|d|$ 当成目标直接套 LC 1526 公式。反例 $d = [1, -2, 2]$：$|d| = [1, 2, 2]$ 会算出 2，而正确答案是 5。原因是**符号翻转处两个位置的需求方向相反，任何一次操作都无法同时服务它们**，必须付满 $|a| + |b|$。

![符号翻转处不可共享](images/min_ops_equal_target_sign_trap.svg)

**等价视角（单调栈标签的来源）**：把 $d$ 按符号切成若干**极大同号段**，每段从 0 开始独立「砌墙」，段内正是 LC 1526 问题（层叠的区间操作，可用单调栈维护）；段与段之间方向相反不能共享。总代价 = 各段代价之和，与扩展差分公式完全等价（可以逐段验证：段内每次「上台阶」对应一个正的 $g_i$，段首从 0 爬起、段尾落回 0 的部分由哨兵与相邻段结算）。

## 4. 算法细节

1. **差数组**：$d_i = \text{target}_i - \text{nums}_i$，无需显式存储，扫描时逐位计算 `cur = target[i] - nums[i]`。
2. **两端哨兵**：首端 `prev` 初值取 0，使 $g_0 = d_0$；末端补 $g_n = -d_{n-1}$，即循环结束后 `ans += max(0, -prev)`。**忘记末端哨兵是高频 bug**：当 `d` 整体为负（如 `nums` 全大于 `target`）时会漏算 $|d_{n-1}|$。
3. **只累加正增量**：等价写法是「总变差 / 2」：
   $$\text{ans} = \frac{|d_0| + \sum_{i=1}^{n-1}|d_i - d_{i-1}| + |d_{n-1}|}{2}$$
4. **溢出**：$|g_i|$ 最大约 $2 \times 10^8$，$n$ 最大 $10^5$，答案可达约 $10^{13}$，C++ 必须用 `long long` 累加。
5. **零元素**：$d_i = 0$ 不需要任何特判，自然被公式处理（0 可归入任意符号段）。

## 5. 正确性证明

**引理 1（操作 ↔ 差分对）**：对数组 $x$（带哨兵 $x_{-1} = x_n = 0$）的区间 $[l, r]$ 整体加 $s \in \{+1, -1\}$，其扩展差分 $g$ 的净变化为：$g_l$ 增加 $s$，$g_{r+1}$ 减少 $s$，其余位置不变。

**证明**：$g_i = x_i - x_{i-1}$。操作后 $x_l, \ldots, x_r$ 均增加 $s$。当 $i = l$：分子 $x_l$ 增加而 $x_{l-1}$ 不变，故 $g_l$ 增加 $s$；当 $i = r+1$：分母 $x_r$ 增加，故 $g_{r+1}$ 减少 $s$；其余 $i$ 要么分子分母同增 $s$（$l+1 \le i \le r$），要么均不变，$g_i$ 不变。∎

**引理 2（下界）**：任何把全 0 数组变成 $d$ 的方案，操作数 $m \ge P$，其中 $P = \sum_{i=0}^{n} \max(0, g_i)$。

**证明**：由引理 1，每次操作恰在 $g$ 上放一个 $+1$ 和一个 $-1$，$m$ 次操作共放 $m$ 个 $+1$。位置 $i$ 的净需求为 $g_i = (\text{该位置 } +1 \text{ 个数}) - (\text{该位置 } -1 \text{ 个数})$，故该位置 $+1$ 个数 $\ge \max(0, g_i)$。对全部 $n+1$ 个位置求和即得 $m \ge P$。∎

**引理 3（上界 / 构造）**：$P$ 次操作足以把全 0 数组变成 $d$。

**证明**：由 $\sum_{i=0}^{n} g_i = 0$（望远镜求和），$+1$ 需求总数与 $-1$ 需求总数相等，均为 $P$。将二者任意两两配对。每对含位置 $i$ 的一个 $+1$ 需求（此时 $g_i > 0$）与位置 $j$ 的一个 $-1$ 需求（此时 $g_j < 0$），必有 $i \ne j$：

- 若 $i < j$：执行一次区间 $[i, j-1]$ 的 **+1 操作**；
- 若 $i > j$：执行一次区间 $[j, i-1]$ 的 **−1 操作**。

由引理 1，该操作恰好消耗这一对需求且不产生其他影响。所有配对执行完后，每个位置的净变化恰为 $g_i$；由差分与原数组的一一对应，数组即为 $d$。∎

**定理**：最少操作数 $= \sum_{i=0}^{n} \max(0, g_i)$。

**证明**：引理 2 给出下界，引理 3 给出达到该值的方案，二者相等。∎

**推论**：答案 = $\dfrac{1}{2} \times \text{TV}(0, d_0, \ldots, d_{n-1}, 0)$，其中 TV 为总变差（相邻差绝对值之和）。

**证明**：$\sum g_i = 0$ 说明正数和 = 负数绝对值和 $= \frac{1}{2}\sum |g_i|$，而 $\sum_{i=0}^{n} |g_i|$ 正是带哨兵序列的总变差。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。一次线性扫描，每步做一次减法、一次比较、一次累加。
- **空间复杂度**：$O(1)$。只维护 `prev` 与 `ans` 两个变量，不显式建差分数组。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    long long minimumOperations(vector<int>& nums, vector<int>& target) {
        long long ans = 0;
        long long prev = 0;  // 哨兵 d[-1] = 0
        int n = nums.size();
        for (int i = 0; i < n; ++i) {
            long long cur = (long long)target[i] - nums[i];
            if (cur > prev) {
                ans += cur - prev;  // g[i] 的正数部分
            }
            prev = cur;
        }
        if (prev < 0) {
            ans -= prev;  // 末端哨兵 g[n] = -d[n-1]
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def minimumOperations(self, nums: List[int], target: List[int]) -> int:
        ans = 0
        prev = 0  # 哨兵 d[-1] = 0
        for a, b in zip(nums, target):
            cur = b - a
            if cur > prev:
                ans += cur - prev
            prev = cur
        if prev < 0:  # 末端哨兵
            ans -= prev
        return ans
```

等价的「总变差 / 2」写法：

```python
class Solution:
    def minimumOperations(self, nums: List[int], target: List[int]) -> int:
        d = [b - a for a, b in zip(nums, target)]
        return (abs(d[0])
                + sum(abs(d[i] - d[i - 1]) for i in range(1, len(d)))
                + abs(d[-1])) // 2
```

## 8. 边界情况与易错点

1. **整数溢出**：答案最大约 $10^{13}$，C++ 必须用 `long long` 累加（`int` 会溢出）；作差 `target[i] - nums[i]` 本身在 `int` 范围内，但建议转 `long long` 保险。Python 无此问题。
2. **经典错误：对 $|d|$ 套 LC 1526 公式**：符号翻转处必须付满 $|a| + |b|$，例如 $d = [1, -2, 2]$ 会错误地算出 2（正确 5）。
3. **末端哨兵不能忘**：`ans += max(0, -prev)`。当 `d` 整体为负（`nums` 全大于 `target`）时，循环内可能一次都不加，全部代价都来自末端哨兵项。
4. **首端哨兵**：`prev` 初值必须是 0，不要误设为 `nums[0] - target[0]` 或其他值。
5. **别混淆「操作次数」与 $\sum |d_i|$**：后者是逐位单点操作的上界，区间共享才是优化点（同向连续需求叠层）。
6. **$d_i = 0$**：无需特判，0 可归入任意相邻符号段，公式自动处理。

**延伸思考**：

- 若操作对象改为**任意子序列**（不必连续）：相邻位置不再耦合，答案退化为 $\sum_i |d_i|$。
- 若改为**二维**（每次选一个矩形区域整体 ±1）：同样的配对论证推广到二维差分，答案 = 二维扩展差分的正数和。
- 若每次操作是整体 $\pm k$：当且仅当 $k \mid d_i$ 对所有 $i$ 成立时有解，把 $d$ 除以 $k$ 后按本题方法求解。
