# LeetCode 字符串元音游戏 题解

## 1. 题目概述

- **标题 / 题号**：字符串元音游戏（#3227，medium）
- **链接**：https://leetcode.cn/problems/vowels-game-in-a-string/
- **来源**：LeetCode 第 407 场周赛 Q2
- **难度**：中等
- **标签**：脑筋急转弯、数学、字符串、博弈

**题意**：给定字符串 `s`，小红（先手）与小明轮流操作：小红每回合必须移除 `s` 中一个含**奇数**个元音的非空子串，小明每回合必须移除一个含**偶数**个元音（可以是 0 个）的非空子串。第一个在其回合内无法操作的人输。两人都采取最优策略，判断小红是否必胜。元音指 `a, e, i, o, u`。

**约束**：

- $1 \le |s| \le 10^5$
- `s` 仅由小写英文字母组成

## 2. 示例

**示例 1**

```text
输入：s = "leetcoder"
输出：true
解释：小红移除 "leetco"（3 个元音，奇）→ s = "der"；
      小明移除 "d"（0 个元音，偶）→ s = "er"；
      小红移除 "er"（1 个元音，奇）→ s = ""；
      小明面对空串无法操作，小红胜。
```

**示例 2**

```text
输入：s = "bbcd"
输出：false
解释：s 中没有元音，任何非空子串都含 0 个（偶数个）元音，
      小红第一步就没有合法操作，直接落败。
```

**补充示例 3**

```text
输入：s = "aa"
输出：true
解释：小红移除一个 "a"（1 个元音，奇）→ s = "a"。
      小明面对单个元音字符：唯一的非空子串 "a" 含 1 个元音（奇数），
      对小明非法，小明无法操作，落败。
```

## 3. 解题思路

### 3.1 暴力思路

把「当前字符串」看作博弈状态，从小红开始递归搜索：每个状态枚举所有 $O(n^2)$ 个子串作为一次操作，删出剩余字符串（前缀 + 后缀拼接）作为后继状态，用必胜/必败态回溯。问题在于状态是**字符串本身**，即使记忆化，可达状态数也是指数级，$n = 10^5$ 下连状态都存不下。正解是脑筋急转弯：本题的胜负**只与 `s` 中元音的总数有关**。

### 3.2 核心观察：元音总数的奇偶性决定胜负

![三种情形：0 元音 / 奇数元音 / 偶数元音](images/vowel_game_three_cases.svg)

设 $cnt$ 为 `s` 中元音总数。三种情形：

| 元音总数 $cnt$ | 结论 | 一句话理由 |
|:---:|:---:|---|
| $0$ | 小红**输** | 任何非空子串都含 0 个（偶数个）元音，小红无合法操作 |
| 奇数 | 小红**赢** | 整个 `s` 就是含奇数个元音的子串，小红一把全删，小明面对空串卡死 |
| 偶数（$\ge 2$） | 小红**赢** | 小红先只删**一个元音字符**，此后小明永远无法清空字符串 |

> ⚠️ **最大陷阱**：直觉上「小红要奇数个元音」容易误判成「总数为奇数才赢」。反例就是示例 1——`"leetcoder"` 有 4 个元音（偶数），答案却是 `true`。偶数情形的必胜性由下面的奇偶不变量保证。

### 3.3 策略与不变量：小明永远清不空字符串

![偶数情形：奇偶不变量锁死小明](images/vowel_game_invariant.svg)

当 $cnt$ 为偶数（$\ge 2$）时，小红的必胜路线：

1. 第一步移除**一个元音字符**（长度为 1 的子串，恰含 1 个元音，合法）。剩余元音数 $cnt - 1$ 是**奇数 $\ge 1$**。
2. 轮到小明时，字符串含奇数 $\ge 1$ 个元音。小明移除含**偶数**个元音的子串，剩余元音数 $=$ 奇 $-$ 偶 $=$ 奇数 $\ge 1$（不能为 0，因为 0 是偶数）——**不变量保持**。特别地，小明若想清空必须移除整个字符串，但整串含奇数个元音，对他非法，所以**小明永远无法终结游戏**。
3. 轮到小红时字符串含奇数 $\ge 1$ 个元音，整串就是她的合法子串，直接**全部移除**，小明面对空串落败。

> 💡 **一句话总结**：小红赢 $\iff$ `s` 里至少有一个元音。答案就是「是否存在元音」，连奇偶性都不用真的算。

### 3.4 示例演算

![对局演算：leetcoder 的必胜路线](images/vowel_game_example_walk.svg)

以 `s = "leetcoder"`（元音 e, e, o, e，共 4 个，偶数）为例：

| 回合 | 移除子串 | 其元音数 | 剩余 | 剩余元音数 |
|---|---|:---:|---|:---:|
| 小红 | `"leetco"` | 3（奇）✓ | `"der"` | 1（奇） |
| 小明 | `"d"` | 0（偶）✓ | `"er"` | 1（奇） |
| 小红 | `"er"` | 1（奇）✓ | `""` | 0 |
| 小明 | 无合法操作 → **输** | | | |

注意小红第一步删了 3 个（奇数个）元音而不是只删 1 个——偶数情形下**任何**合法开局都必胜：她移除的一定是奇数个元音，偶 $-$ 奇 $=$ 奇 $\ge 1$，不变量自动成立；关键只在最后一步「整串是奇数个元音时收全场」。

## 4. 算法细节

1. **只需判断存在性**：结论只取决于「是否含元音」，不必统计个数、更不必算奇偶。
2. **元音集合**：只有 $a, e, i, o, u$，英文语境下**不含 y**；`s` 全小写，无需大小写转换。
3. **短路返回**：找到第一个元音即可返回 `true`；全辅音串才需要扫完，最坏 $O(n)$。
4. **「偶数包含 0」**：这是题面的关键设定——0 个元音也算偶数个，所以纯辅音子串是小明的合法操作（示例 1 中小明移除单个 `"d"`），同时也意味着 0 元音的串让小红直接卡死。
5. Python 可用 `any(c in "aeiou" for c in s)` 一行；C++ 手写循环逐字符比较即可。

## 5. 正确性证明

**引理 1（可行动性刻画）**：

（a）小红（需要含奇数个元音的子串）有合法操作 $\iff$ 当前字符串至少含 1 个元音；

（b）若当前元音总数为奇数，则小明**无法把字符串清空**。

**证明**：（a）（⇐）取任意一个元音字符本身，它是长度为 1 的子串，恰含 1 个元音（奇数），合法。（⇒）若字符串不含元音，则任何非空子串都含 0 个元音（偶数），小红无合法操作。（b）清空意味着移除整个字符串，其元音数等于当前总数——为奇数，不满足「偶数个元音」的合法性要求，故该操作非法。∎

**定理**：小红必胜 $\iff$ `s` 至少含一个元音。

**证明**：设元音总数为 $cnt$。

（⇐）$cnt \ge 1$。

- 若 $cnt$ 为奇数：整个字符串含奇数个元音，由引理 1(a) 是小红的合法操作；小红第一步移除整个字符串，小明面对空串无合法操作，落败。
- 若 $cnt$ 为偶数（$\ge 2$）：小红第一步移除任意一个元音字符，剩余元音数 $cnt - 1$ 为**奇数 $\ge 1$**。此后归纳维护不变量「轮到小明时剩余元音数为奇数 $\ge 1$」：小明的操作移除偶数个元音，剩余数 $=$ 奇 $-$ 偶 $=$ 奇数且非负，故仍为奇数 $\ge 1$；同时由引理 1(b)，小明无法清空字符串。于是轮到小红时字符串非空且含奇数 $\ge 1$ 个元音，整串是合法子串，小红移除整个字符串清场；小明面对空串落败。

（⇒）$cnt = 0$ 时由引理 1(a)，小红第一步即无合法操作，落败。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$，$n$ 为 `s` 的长度。最坏情况（全辅音）扫描整个字符串一次，找到元音即刻短路返回。
- **空间复杂度**：$O(1)$，只做逐字符判断，不维护额外状态。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool doesAliceWin(string s) {
        for (char c : s) {
            if (c == 'a' || c == 'e' || c == 'i' || c == 'o' || c == 'u') {
                return true;
            }
        }
        return false;
    }
};
```

### Python

```python
class Solution:
    def doesAliceWin(self, s: str) -> bool:
        return any(c in "aeiou" for c in s)
```

## 8. 边界情况与易错点

1. **偶数个元音 ≠ 小红输**：本题最大的坑。把答案写成「$cnt$ 为奇数才赢」会在示例 1（4 个元音）上直接 WA，必须把偶数情形的不变量想清楚。
2. **0 是偶数**：两个方向都别搞错——纯辅音子串是小明的合法操作；而全辅音的串让小红第一步就卡死。
3. **不要写博弈搜索**：状态是字符串、每个状态 $O(n^2)$ 种转移，指数级状态直接不可行；本题是脑筋急转弯，一条 if 都嫌多。
4. **$cnt = 1$ 与 $cnt$ 偶数的策略不同但结论一致**：前者一把全删，后者两步收场，证明中须分开讨论，代码里则统一为「有元音就赢」。
5. **元音别认错**：只有 `a e i o u`，没有 `y`；`s` 全小写，无需 `tolower`。
6. **短路优化**：找到一个元音立即返回，全辅音串才扫完，最坏也是一次线性扫描。
