# LeetCode 使两个整数相等的位更改次数 题解

## 1. 题目概述

- **标题 / 题号**：使两个整数相等的位更改次数（#3226，easy）
- **链接**：https://leetcode.cn/problems/number-of-bit-changes-to-make-two-integers-equal/
- **来源**：LeetCode 第 407 场周赛 Q1
- **难度**：简单
- **标签**：位运算

**题意**：给定两个正整数 `n` 和 `k`。每次操作可以选择 `n` 的二进制表示中任意一个值为 1 的位，并将其改为 0。返回使 `n` 等于 `k` 所需的最少操作次数；若无法实现，返回 -1。

**约束**：

- `1 <= n, k <= 10^6`

## 2. 示例

**示例 1**

```text
输入：n = 13, k = 4
输出：2
解释：n = (1101)₂，k = (0100)₂。
      关掉第 0 位和第 3 位后 n = (0100)₂ = k，共 2 次操作。
```

**示例 2**

```text
输入：n = 21, k = 21
输出：0
解释：n 与 k 已经相等，无需操作。
```

**示例 3**

```text
输入：n = 14, k = 13
输出：-1
解释：n = (1110)₂，k = (1101)₂。k 的第 0 位是 1，而 n 的第 0 位是 0，
      0 无法通过操作变成 1，故无解。
```

## 3. 解题思路

### 3.1 暴力思路

从 `n` 出发做 BFS：每个状态向「关掉任意一个仍为 1 的位」得到的所有后继连边，搜到 `k` 即返回层数。状态数上界 $2^{20}$（因 $10^6 < 2^{20}$），能过但毫无必要——因为操作只会把 1 变 0，`n` 的置位集合**单调收缩**，答案根本与顺序无关，逐位分析即可直接算出来。

### 3.2 核心观察：按位三分 + 子掩码判定

![按位三分：n→k 只能把 1 改成 0](images/bit_changes_case_analysis.svg)

操作是**单向的**：只能把 `n` 的 1 关成 0，不能把 0 变成 1。于是把 $n$、$k$ 按二进制逐位对齐，只有三种情形：

| $n$ 的位 | $k$ 的位 | 结论 |
|:---:|:---:|---|
| 1 | 1 | 必须**保留**（关掉就再也回不来），0 次操作 |
| 1 | 0 | 必须**关掉**，恰好 1 次操作 |
| 0 | 1 | **无解**：0 变不出 1，返回 -1 |

> 💡 **一句话总结**：可解当且仅当 $k$ 是 $n$ 的**子掩码**（$k$ 的每个 1 都落在 $n$ 的 1 上），即 $(n \,\&\, k) == k$；可解时答案就是**不同的那些位**的个数，即 $\operatorname{popcount}(n \oplus k)$。

### 3.3 算法流程

```text
1. 若 (n & k) != k：说明存在"n=0, k=1"的位，返回 -1
2. 否则返回 popcount(n ^ k)
```

### 3.4 示例演算

![示例演算：13→4 与 14→13](images/bit_changes_example_walk.svg)

| n | 二进制 | k | 二进制 | 判定 | 答案 |
|---|--------|---|--------|------|------|
| 13 | 1101 | 4 | 0100 | $k$ 是子掩码，$13 \oplus 4 = 1001$ | $\operatorname{popcount} = 2$ |
| 21 | 10101 | 21 | 10101 | 相等，异或为 0 | $0$ |
| 14 | 1110 | 13 | 1101 | $k$ 的 $b_0$ 无对应 | $-1$ |

注意 14 ⊕ 13 = 0001 的 popcount 是 1，但这个 1 是「无解位」数出来的——所以**必须先判定再计数**。

## 4. 算法细节

1. **子掩码判定**：$(n \,\&\, k) == k$、$(k \,\&\, {\sim}n) == 0$、$(n \,|\, k) == n$ 三种写法等价。推荐第一种，不易写反。
2. **答案的两种等价形式**：可解时 $\operatorname{popcount}(n \oplus k) = \operatorname{popcount}(n) - \operatorname{popcount}(k)$，因为此时 $k$ 的所有 1 位都包含在 $n$ 中，异或结果的 1 恰好是 $n$ 独有的 1。两种写法都对，异或版更不容易在边界上出错。
3. **popcount 的实现**：C++ 用 `__builtin_popcount`（或 C++20 `std::popcount`）；Python 3.10+ 用 `(x).bit_count()`，低版本用 `bin(x).count('1')`。
4. **数据范围**：$10^6 < 2^{20}$，20 位以内，`int` 完全够用，无溢出风险。

## 5. 正确性证明

**引理 1（单向性）**：任意操作序列之后得到的状态 $n'$ 必是初始 $n$ 的子掩码，即 $n' \,\&\, n = n'$。

**证明**：对操作次数归纳。每次操作把一个 1 位改为 0，其余位不变，因此新状态的 1 位集合是原 1 位集合的真子集（去掉一个元素）。子掩码关系在操作下传递，归纳即得。∎

**引理 2（可解性刻画）**：$n$ 能变成 $k$ 当且仅当 $k$ 是 $n$ 的子掩码（$(n \,\&\, k) == k$）。

**证明**：（⇒）终态 $k$ 由引理 1 必为初始 $n$ 的子掩码。（⇐）若 $k$ 是 $n$ 的子掩码，把所有满足 $n$ 的位为 1、$k$ 的位为 0 的位逐一关掉。每次关掉的位当前必为 1（后续操作不会影响它，因为操作彼此独立、只动自己那一位），故每步操作合法，最终恰得到 $k$。∎

**定理**：可解时，最少操作次数为 $\operatorname{popcount}(n \oplus k)$。

**证明**：设 $D = \{i : n$ 与 $k$ 在第 $i$ 位不同$\}$。每次操作至多改变一个二进制位，要使 $n$ 变为 $k$，$D$ 中每一位都必须被改变，故操作次数 $\ge |D|$（下界）。由引理 2 的构造，可解时不存在的「$n=0,k=1$」位，$D$ 全部由「$n=1,k=0$」位组成，构造恰好对 $D$ 中每一位操作一次，共 $|D|$ 次（上界）。而 $|D| = \operatorname{popcount}(n \oplus k)$，故最少操作次数恰为该值。∎

## 6. 复杂度分析

- **时间复杂度**：$O(\log \max(n,k))$，即一次按位与、一次异或和一次 popcount 的位数开销；本题约束下不超过 20 位，视为 $O(1)$。
- **空间复杂度**：$O(1)$，仅使用常数个变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minChanges(int n, int k) {
        return (n & k) == k ? __builtin_popcount(n ^ k) : -1;
    }
};
```

### Python

```python
class Solution:
    def minChanges(self, n: int, k: int) -> int:
        return (n ^ k).bit_count() if n & k == k else -1
```

## 8. 边界情况与易错点

1. **判定别写反**：是「$k$ 的 1 必须都在 $n$ 里」，即 $(n \,\&\, k) == k$。写成 $(n \,\&\, k) == n$（判成 $n$ 是 $k$ 的子掩码）在 $n \ne k$ 时必然误判。
2. **先判 -1 再 popcount**：$n \oplus k$ 会把「$n=0,k=1$」的无解位也数成 1（如 $14 \oplus 13 = 1$），不先判子掩码直接返回 popcount 是最典型的 WA。
3. **$n = k$ 情形**：返回 0，公式自然覆盖（子掩码成立且 popcount(0) = 0），无需特判。
4. **popcount 别数错**：手写循环时终止条件是 `x != 0`；本题输入为正数，无符号位问题。
5. **Python 版本**：`bit_count()` 需 3.10+，低版本用 `bin(x).count('1')` 替代。
