# LeetCode 恰有 K 根木棍可以看到的排列数目 题解

## 1. 题目概述

- **标题 / 题号**：恰有 K 根木棍可以看到的排列数目（#1866，hard）
- **链接**：https://leetcode.cn/problems/number-of-ways-to-rearrange-sticks-with-k-sticks-visible/
- **来源**：LeetCode 第 241 场周赛 Q4
- **难度**：困难
- **标签**：动态规划、数学、组合数学

**题意**：有 $n$ 根长度互不相同的木棍，长度为 $1 \dots n$ 的整数。将它们排成一排，一根木棍从左侧**可见**，当且仅当它的左侧**不存在比它更长的木棍**。例如排列 $[1,3,2,5,4]$ 中可见的是长度 $1$、$3$、$5$ 的木棍。给定 $n$ 与 $k$，求恰有 $k$ 根可见木棍的排列数目，答案对 $10^9+7$ 取模。

**约束**：

- $1 \le n \le 1000$
- $1 \le k \le n$

## 3. 解题思路

### 3.1 暴力思路

枚举 $1 \dots n$ 的全部 $n!$ 个排列，逐个从左到右扫描、数出左到右最大值的个数。$n \le 1000$ 时 $n!$ 是天文数字，完全不可行；而且「恰有 $k$ 个左到右最大值的排列数」**没有闭式公式**，组合恒等式这条路也走不通。计数题遇到「无闭式」时的赛时定式是**退而求递推**：找一个规模最小的决策点，把 $n$ 的问题干净地归约到 $n-1$。

### 3.2 核心观察：可见 = 左到右最大值；考察最短木棍的位置

![可见性概念：可见 = 左到右最大值（record）](images/sticks_visibility_concept.svg)

先把题意翻译成排列语言：一根木棍可见，当且仅当它比**左侧所有**木棍都长，即它是**左到右最大值**（left-to-right maxima，俗称 record）。本题 = 统计恰有 $k$ 次「刷新纪录」的排列数。

递推的决策点选谁？**考察高度为 $1$ 的最短木棍**放在哪——它比谁都矮，性质极端，结论干净：

- **情况 A：高度 1 在最左端。** 左侧空无一棍，它**必可见**；且它比谁都矮，**不会遮挡任何木棍**——其余 $n-1$ 根的可见性格局原样保留。删去它并把剩余高度 $2 \dots n$ **保序重标号**为 $1 \dots n-1$，恰好得到一个 $n-1$ 规模的同构子问题：剩余木棍需再有 $k-1$ 根可见，贡献 $\text{dp}[n-1][k-1]$。
- **情况 B：高度 1 在其余 $n-1$ 个位置之一。** 左侧必有木棍且都比它长 → 它**必被挡住**；同样它不挡任何棍 → 其余 $n-1$ 根的可见数**不多不少恰为 $k$**。插入位置有 $n-1$ 种选择，贡献 $(n-1) \cdot \text{dp}[n-1][k]$。

![核心观察：按最短木棍的位置分类，两种情况对应递推两项](images/sticks_shortest_concept.svg)

> 💡 **为什么考察最短而不是最长？** 最短木棍的可见性结论**不依赖左侧具体排列**：不在最左就必被挡，在最左就必可见。「按最小/最大元素的位置分类」是排列计数递推的第一试手方向；反过来若考察最长木棍，它放在任何位置都可见、还会遮挡其右侧全部木棍，右侧子问题的结构被破坏，分类立刻复杂化。

### 3.3 状态转移与算法流程

![状态转移与滚动数组实现](images/sticks_dp_flow.svg)

两种情况按「高度 1 的位置」划分，**不重不漏**，相加即得递推：

$$\text{dp}[i][j] = \text{dp}[i-1][j-1] + (i-1) \cdot \text{dp}[i-1][j]$$

- **状态定义**：$\text{dp}[i][j]$ = $i$ 根木棍（高度 $1 \dots i$）恰有 $j$ 根可见的排列数。
- **边界**：$\text{dp}[0][0] = 1$（空排列计 1 种）；$\text{dp}[i][0] = 0$（$i \ge 1$，最左端那根总可见，可见数不可能为 0）；$j > i$ 时 $\text{dp}[i][j] = 0$（$i$ 根棍至多 $i$ 根可见）。
- **答案**：$\text{dp}[n][k]$。

实现上只依赖上一行，用一维数组滚动：$j$ **倒序**更新保证读到的 $\text{dp}[j-1]$、$\text{dp}[j]$ 都是上一轮旧值；每轮结束把 $\text{dp}[0]$ 置 $0$。内层 $j$ 从 $\min(i,k)$ 起步即可——$j > i$ 的格子恒为 0，不必计算。

### 3.4 示例演算：n = 3, k = 2

![示例演算：n=3, k=2 的 DP 表与三个合法排列](images/sticks_walkthrough.svg)

| $i \backslash j$ | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| 0 | **1** | 0 | 0 | 0 |
| 1 | 0 | 1 | 0 | 0 |
| 2 | 0 | 1 | 1 | 0 |
| 3 | 0 | 2 | **3** | 1 |

$$\text{dp}[3][2] = \underbrace{\text{dp}[2][1]}_{\text{情况 A}} + 2 \cdot \underbrace{\text{dp}[2][2]}_{\text{情况 B}} = 1 + 2 \times 1 = 3$$

三个合法排列与递推的对应（加粗为可见木棍）：

- **情况 A** → $[{\bf 1},{\bf 3},2]$：高度 1 在最左且可见；删 1 重标号得 $[2,1]$（原 $[3,2]$），其中可见的只有 2，恰 $k-1=1$ 根 → 对应 $\text{dp}[2][1]=1$。
- **情况 B · 位 2** → $[{\bf 2},1,{\bf 3}]$：高度 1 在位 2 被挡；删 1 重标号得 $[1,2]$，可见 2 根恰为 $k$ → 对应 $\text{dp}[2][2]=1$。
- **情况 B · 位 3** → $[{\bf 2},{\bf 3},1]$：同理映射到同一个剩余排列 $[1,2]$ → 再对应 $1$ 份 $\text{dp}[2][2]$。

两个 B 位置映射到**同一个剩余排列**，这正是系数 $(n-1)$ 的来源：$1 + 2 \times 1 = 3$ ✓。

## 4. 算法细节

1. **保序重标号是子问题同构的关键**：可见性只由「谁比谁长」的**相对次序**决定，与绝对高度无关。删去高度 1 后把 $2 \dots n$ 压缩为 $1 \dots n-1$，任何两根木棍的长短关系、前后关系都不变，可见性格局原样保留——这保证情况 A/B 归约出的确实是「$n-1$ 根木棍」的原问题，递推才能自洽。
2. **内层 $j$ 从 $\min(i,k)$ 开始**：$j > i$ 时 $\text{dp}[i][j]$ 恒为 0，截断可省掉近一半计算量（不截也不出错）。
3. **滚动数组两件套**：$j$ **倒序**更新（$\text{dp}[j-1]$ 尚未被本轮覆盖，仍是 $i-1$ 轮旧值）；每轮结束 $\text{dp}[0] \leftarrow 0$（$i \ge 1$ 时不可能 0 根可见）。两件事缺一不可，见 §8。
4. **溢出**：转移项 $(i-1) \cdot \text{dp}[j] \le 999 \times (10^9+6) < 10^{13}$，C++ 必须 `long long`（`int` 相乘必爆）；两项相加后立即取模。Python 整数无上限，但仍应每步取模控制数值规模，避免大数乘法变慢。
5. **无需特判无效状态**：约束保证 $1 \le k \le n$，$\text{dp}[n][k] \ge 1$（至少全递增排列一种），不存在 $k=0$ 或 $k>n$ 的输入。

## 5. 正确性证明

**引理 1（可见性刻画）**：排列 $\pi$ 中位置 $i$ 的木棍可见 $\iff$ $\pi_i > \max(\pi_1, \dots, \pi_{i-1})$（约定 $i=1$ 时左侧为空、恒可见）。

**证明**：可见即「左侧不存在比它更长的木棍」，即左侧所有木棍都比它短：$\forall t < i,\ \pi_t < \pi_i \iff \pi_i > \max(\pi_1, \dots, \pi_{i-1})$。∎

**引理 2（最短木棍零遮挡）**：把高度 1 插入任意排列（或从任意非最左位置删去），**其余每根**木棍的可见性不变。

**证明**：任取其余木棍 $s$（高度 $\ge 2$）。$s$ 的可见性只取决于「左侧是否存在比 $s$ 长的木棍」。高度 1 短于 $s$，永远不会成为「比 $s$ 长的左侧木棍」；其余木棍间的相对次序不变。故 $s$ 的可见性不变。∎

**引理 3（最短木棍自身的可见性）**：高度 1 在最左端时可见；在其余任何位置时不可见。

**证明**：最左端时左侧无木棍，由定义可见；否则左侧非空且每根都比它长，由引理 1 不可见。∎

**定理（递推正确性）**：对所有 $n \ge 1$、$1 \le k \le n$，

$$f(n, k) = f(n-1, k-1) + (n-1) \cdot f(n-1, k)$$

其中 $f(n,k)$ 为 $n$ 根木棍中恰有 $k$ 根可见的排列数。

**证明**：设 $\mathcal{P}_{n,k}$ 为高度 $1 \dots n$ 的排列中恰有 $k$ 根可见者的集合，按高度 1 的位置 $p$ 划分为 $\mathcal{A} = \{p = 1\}$ 与 $\mathcal{B} = \{2 \le p \le n\}$，两类**不重不漏**。

**情况 A**：构造 $\phi: \mathcal{A} \to \mathcal{P}_{n-1, k-1}$——删去最左端的高度 1，剩余高度 $2 \dots n$ 保序重标号为 $1 \dots n-1$。由引理 3 被删的 1 可见，由引理 2 其余可见集不变，故 $\phi(\pi)$ 恰有 $k-1$ 根可见。$\phi$ 是双射：对 $\pi' \in \mathcal{P}_{n-1,k-1}$，逆重标号 $1 \dots n{-}1 \to 2 \dots n$ 后在最左端插回高度 1，由同样两条引理可见数恰增 1。故 $|\mathcal{A}| = f(n-1, k-1)$。

**情况 B**：构造 $\psi: \mathcal{B} \to \mathcal{P}_{n-1, k} \times \{2, \dots, n\}$，$\psi(\pi) = (\text{删 1 重标号},\ p)$。由引理 3 高度 1 不可见，由引理 2 删去后其余可见数不变，故第一分量恰有 $k$ 根可见。逆映射同理：对 $(\pi', p)$，逆重标号后把高度 1 插回位置 $p$。故 $|\mathcal{B}| = (n-1) \cdot f(n-1, k)$。

两类相加即得递推。∎

**推论（与 Stirling 数一致）**：$f(n,k)$ 等于无符号第一类 Stirling 数 $\begin{bmatrix} n \\ k \end{bmatrix}$（$n$ 元排列中恰含 $k$ 个轮换的个数）。

**证明思路（Foata 变换）**：把排列的每个轮换写成**最大元打头**、轮换按**最大元递增**排序，去掉括号得到一行排列：每个轮换首元比它之前的全部元素都大（此前都是更小轮换的元素）→ 是 record；每个非首元小于自己轮换的首元 → 不是 record。故 record 与轮换一一对应。以题面例子为证：轮换分解 $(1)(3\,2)(5\,4) \mapsto [1,3,2,5,4]$，$3$ 个轮换恰对应可见的 $1,3,5$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(nk) \le 10^6$。外层 $n$ 轮，第 $i$ 轮内层至多 $\min(i,k)$ 次常数时间转移，求和不超过 $nk = 10^6$，远低于时限。
- **空间复杂度**：滚动数组 $O(k)$；若写二维表则为 $O(nk)$（约 $10^6$ 个 `long long` ≈ 8 MB，也能过但无必要）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int rearrangeSticks(int n, int k) {
        const int MOD = 1e9 + 7;
        vector<long long> dp(k + 1, 0);
        dp[0] = 1;                                  // dp[0][0] = 1：空排列计 1 种
        for (int i = 1; i <= n; ++i) {
            for (int j = min(i, k); j >= 1; --j) {  // 倒序：dp[j-1] 还是上一轮旧值
                dp[j] = (dp[j - 1] + (long long)(i - 1) * dp[j]) % MOD;
            }
            dp[0] = 0;                              // i >= 1：不可能 0 根可见
        }
        return dp[k];
    }
};
```

### Python

```python
class Solution:
    def rearrangeSticks(self, n: int, k: int) -> int:
        MOD = 10 ** 9 + 7
        dp = [0] * (k + 1)
        dp[0] = 1                                   # 空排列计 1 种
        for i in range(1, n + 1):
            for j in range(min(i, k), 0, -1):       # 倒序滚动
                dp[j] = (dp[j - 1] + (i - 1) * dp[j]) % MOD
            dp[0] = 0                               # i >= 1：至少最左端可见
        return dp[k]
```

> 💡 二维 `dp[i][j]` 的朴素版本与逐行讲解见[每日姊妹篇](../../solution/1801-1900/1866_恰有K根木棍可以看到的排列数目.md)；赛时更推荐一步到位写滚动版。

## 8. 边界情况与易错点

1. **种子 $\text{dp}[0][0] = 1$ 不能漏**：它是整张表的唯一入口（$\text{dp}[1][1] = \text{dp}[0][0] + 0 \cdot \text{dp}[0][1] = 1$），初始化为 0 则全表归零。「空排列计 1」是组合计数的标准约定。
2. **滚动数组漏置 $\text{dp}[0] = 0$**：第一轮后 $\text{dp}[0]$ 残留为 1，下一轮 $j=1$ 的转移会多算 $\text{dp}[i-1][0]$。实测 $n=2, k=1$：漏置得 $\text{dp}[1] = 1 + 1 \times 1 = 2$，正确答案为 $1$（唯一排列 $[2,1]$）。
3. **滚动方向**：必须 $j$ 倒序。正序时 $\text{dp}[j-1]$ 已被改成 $i$ 轮新值，转移被污染——$n=2, k=1$ 同样会得 $2$ 而非 $1$。
4. **溢出**：$(i-1) \cdot \text{dp}[j]$ 最大约 $999 \times (10^9+6) \approx 10^{12}$，`int` 相乘直接爆，C++ 用 `long long` 存中间量。
5. **$j$ 的上界**：内层从 $\min(i,k)$ 起步是优化而非正确性要求——$j > i$ 的格子恒 0，多算不出错，只是白算。
6. **sanity check**：$k = n$ 时答案恒 $1$（全递增排列）；$k = 1$ 时答案为 $(n-1)! \bmod (10^9+7)$（仅最左端可见 $\iff$ 最长者 $n$ 在最左，其余任意）。提交前可用这两条快速自检。
