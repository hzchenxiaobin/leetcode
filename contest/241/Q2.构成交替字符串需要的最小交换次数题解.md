# LeetCode 构成交替字符串需要的最小交换次数 题解

## 1. 题目概述

- **标题 / 题号**：构成交替字符串需要的最小交换次数（#1864，medium）
- **链接**：https://leetcode.cn/problems/minimum-number-of-swaps-to-make-the-binary-string-alternating/
- **来源**：LeetCode 第 241 场周赛 Q2
- **难度**：中等
- **标签**：贪心、字符串、计数

**题意**：给定一个仅含 `'0'`、`'1'` 的字符串 $s$。一次**交换**可以任选**任意两个下标**（不必相邻）互换其字符。**交替串**指任意相邻字符都不相等的字符串（形如 `"0101…"` 或 `"1010…"`）。求把 $s$ 变成交替串所需的**最少交换次数**；无法做到则返回 $-1$。

**约束**：

- $1 \le n \le 1000$
- `s[i]` 为 `'0'` 或 `'1'`

> 💡 本题在本仓库另有[每日题解 1864](../../solution/1801-1900/1864_构成交替字符串需要的最小交换次数.md)：以「面试视角」展开——重点对照 1758 翻转版（翻转逐位独立、答案 $= \mathrm{mis}$；交换修复两处、答案 $= \mathrm{mis}/2$），并讨论互补 trick 的适用边界与面试问答。本篇按**周赛复盘视角**重写：侧重**赛时最短拿分路径**（判可行 → 数错位 → 除 2，三步一气呵成）、**下界–上界夹逼的完整证明**（单次交换至多修复两处 / 两类错位配对恰好达到），以及**奇数长度不做可行性判定会静默 WA** 的经典坑（`"110"` 反例逐步拆解），两篇互为印证。

```text
解释：交换下标 1 和 4："111000" -> "101010"，变为交替串。
```

**示例 2**


**示例 3**

```text
输入：s = "1110"
输出：-1
解释：4 个字符中有 3 个 '1'，交换不改变计数，无法交替。
```

**示例 4（奇数长度的典型坑）**

```text
输入：s = "110"
输出：1
解释：n = 3 为奇数，c1 = 2 = (n+1)/2，唯一可行目标是 "101"。

```

## 3. 解题思路

### 3.1 暴力思路：把字符串当状态 BFS

把每个字符串视为状态、每种交换视为一条边，从 $s$ 出发 BFS，首次到达交替串的深度即答案。状态数至多 $\binom{n}{c_1}$（`'1'` 的全部摆放方式），$n \le 1000$ 时是天文数字；即便 $n \le 16$ 也只配当对拍器，比赛时毫无价值。

**但 BFS 的「无效」恰好点破了两件事**：

1. **交换是位置上的置换，不改变 `'0'`/`'1'` 的个数**——先验地排除了大半输入（可行性判据）；
2. **搜索空间爆炸，是因为「交换的具体路径」无关紧要**——真正决定答案的只有「哪些位置错了位」。沿这条线索想下去，模拟就该被计数取代。

### 3.2 核心观察：两个目标 + 计数不变 + 一次交换修两处

![核心观察：两类错位配对，一次交换修复两个](images/altstr_pairing_concept.svg)

三个层层递进的观察：

1. **目标只有两个**：交替串由首字符唯一确定——$A =$ `"0101…"` 与 $B =$ `"1010…"`，别无其他（引理 1）。答案必是「变成 $A$ 的最少交换」与「变成 $B$ 的最少交换」中可行者的较小值。
2. **交换不改计数 ⇒ 可行性 = 计数匹配**：$A$ 需要 $c_1 = \lfloor n/2 \rfloor$，$B$ 需要 $c_1 = \lceil n/2 \rceil$。$n$ 偶时两者相同（要么都可行、要么都不可行）；$n$ 奇时**至多一个**可行——由谁多一个决定。
3. **一次交换至多修复两个错位，且恰好能做到**：错位分两类——**A 类**（$s_i=1$ 而 $t_i=0$）与 **B 类**（$s_i=0$ 而 $t_i=1$）。计数匹配时两类数量相等（引理 3），把一个 A 类与一个 B 类互换，两处同时归位。于是

$$\text{swaps}(t) = \frac{\mathrm{mis}(t)}{2}, \qquad \mathrm{mis}(t) = \#\{ i : s_i \ne t_i \}$$

三步合起来：**判可行 → 数错位 → 除以 2**，一次遍历即可完成，这就是赛时的最短拿分路径。

### 3.3 算法流程

![算法流程：判可行 → 数错位 → 除 2 取最小](images/altstr_decision_flow.svg)

流程要点：

1. **一趟统计** $c_1$；
2. **可行性判定**：$n$ 偶要求 $2c_1 = n$，此时两个目标都试；$n$ 奇要求 $2c_1 \in \{n-1,\ n+1\}$，只试「多出来的字符」开头的那一个；都不满足返回 $-1$；
3. 对每个可行目标一趟扫描数 $\mathrm{mis}$，代价 $= \mathrm{mis}/2$，取最小输出。

### 3.4 示例演算

![示例演算：s=111000 的两个目标各数一遍错位](images/altstr_walkthrough.svg)

以 `s = "111000"`（$n=6$，$c_1=3$）为例，两个形态都可行：

| 目标 | 逐位比对 | $\mathrm{mis}$ | 交换次数 |
|------|----------|----------------|----------|
| $A =$ `010101` | 错位 $i=0,2,3,5$ | $4$ | $4/2 = 2$ |
| $B =$ `101010` | 错位 $i=1,4$ | $2$ | $2/2 = 1$ |

- $A$ 的 4 个错位 $=$ 2 个 A 类（$i=0,2$ 的 `'1'`）$+$ 2 个 B 类（$i=3,5$ 的 `'0'`），两类相等 ✓；
- $B$ 的 2 个错位 $=$ 1 个 A 类（$i=1$）$+$ 1 个 B 类（$i=4$），恰好配成一对 ✓；
- 答案 $= \min(2, 1) = 1$：交换 $s[1] \leftrightarrow s[4]$ 即得 `"101010"`。

注意每个可行目标的 $\mathrm{mis}$ 都是**偶数**——这不是巧合，而是引理 3 的直接推论，也是检验实现是否正确的免费 assert。

## 4. 算法细节

1. **目标位公式**：首字符为 $st \in \{0,1\}$ 的目标满足 $t_i = st \oplus (i \bmod 2)$。一个异或即可代替按位奇偶的 if-else，两趟扫描共用同一套代码。
2. **候选目标的构造**：$n$ 偶且 $2c_1 = n$ → `starts = {0, 1}`；$n$ 奇且 $c_1 = (n+1)/2$ → `starts = {1}`；$c_1 = (n-1)/2$ → `starts = {0}`；其余 → $-1$。**`starts` 里只放可行目标**，这是奇数长度不翻车的关键（见 §8）。
3. **整除安全性**：可行目标的 $\mathrm{mis}$ 必为偶数（引理 3），`mis / 2` 无截断风险；反之若对某目标数出奇数 $\mathrm{mis}$，说明该目标不可行或判定写错——可加 `assert(mis % 2 == 0)` 防呆。
4. **单趟计数的推导**：设 $e_1$ = 偶数下标上 `'1'` 的个数，$o_1 = c_1 - e_1$ 为奇数下标上的 `'1'` 个数。$n$ 偶时对目标 $A$：$\mathrm{mis}_A = e_1 + o_0 = e_1 + (n/2 - o_1) = 2e_1$，故 $\text{cost}_A = e_1$；同理 $\text{cost}_B = n/2 - e_1$，答案 $= \min(e_1,\ n/2 - e_1)$，**一遍扫描、免第二趟**。$n$ 奇时唯一可行目标同理化简：多数是 `'1'` 时 $\text{cost} = (n+1)/2 - e_1$，多数是 `'0'` 时 $\text{cost} = e_1$。
5. **计数即构造**：所有 A 类错位彼此无区别（`'1'` 就是 `'1'`，放到哪个 B 类位置都一样），任意一一配对都最优。因此无需模拟交换、更无需构造目标串；若题目追问具体方案，把两类错位按下标序配对依次输出即可，$O(n)$。
6. **字符与整数别混用**：比较前统一 `s[i] - '0'`（C++）或 `int(ch)`（Python）；`'1' == 1` 恒为假，是两语言各自的经典笔误。

## 5. 正确性证明

**引理 1（目标形态唯一性）**：长度为 $n$ 的交替串 $t$ 满足 $t_i = t_0 \oplus (i \bmod 2)$；全体交替串恰为 $A$、$B$ 两个。

**证明**：相邻字符不等且字符集为 $\{0,1\}$，故 $t_{i+1} = 1 - t_i$，对 $i$ 归纳立得。∎

**引理 2（可行性 = 计数匹配）**：$s$ 可经有限次交换变成 $t$，当且仅当两者 `'1'` 的个数相同。

**证明**：（⇒）交换是位置上的置换，字符多重集不变。（⇐）记 $S_1 = \{i : s_i = 1\}$，$T_1 = \{i : t_i = 1\}$。若 $|S_1| = |T_1|$，则 $|S_1 \setminus T_1| = |T_1 \setminus S_1|$（两边都等于 $|S_1| - |S_1 \cap T_1|$）。把两集合任意一一配对 $(i, j)$，每次交换 $s_i$（`'1'`）与 $s_j$（`'0'`），两处同时与 $t$ 一致；配完即 $S_1 = T_1$。∎

**引理 3（两类错位相等）**：若 $|S_1| = |T_1|$，则 A 类错位数 $= $ B 类错位数 $=: a$，且 $\mathrm{mis} = 2a$ 为偶数。

**证明**：$i$ 是错位当且仅当 $s_i \ne t_i$，即 $i$ 恰属于 $S_1, T_1$ 之一，故错位集 $= (S_1 \setminus T_1) \uplus (T_1 \setminus S_1)$。前者即 A 类（$s_i=1, t_i=0$），后者即 B 类，两者大小都等于 $|S_1| - |S_1 \cap T_1|$，相等。∎

**引理 4（单次交换的下界）**：任意一次交换至多使 $\mathrm{mis}$ 减少 $2$。

**证明**：交换只改变两个下标的字符，其余 $n-2$ 位贡献不变；每个被改动的下标对 $\mathrm{mis}$ 的指示贡献变化至多 $1$，故总降幅 $\le 2$。∎

**定理**：对每个可行目标 $t$，最小交换次数恰为 $\mathrm{mis}(s,t)/2$；整题答案为对所有可行目标取最小。

**证明**：**下界**：设初始 $\mathrm{mis} = \mathrm{mis}_0$，由引理 4，$k$ 次交换后 $\mathrm{mis} \ge \mathrm{mis}_0 - 2k$；变成 $t$ 要求 $\mathrm{mis} = 0$，故 $k \ge \mathrm{mis}_0/2$。**上界**：由引理 3 取 $a = \mathrm{mis}_0/2$，将 A 类与 B 类错位任意一一配对，每对执行一次交换同时修复两处（引理 2 的构造），$a$ 次后 $\mathrm{mis} = 0$。两者夹逼，得 $\text{swaps}(t) = \mathrm{mis}_0/2$。再由引理 1 全局只有两个目标、引理 2 筛出可行集合，逐一代入取最小即全局最优。∎

**推论（$-1$ 判据）**：无可行目标当且仅当：$n$ 偶且 $c_1 \ne n/2$；或 $n$ 奇且 $c_1 \notin \{(n-1)/2,\ (n+1)/2\}$。$n$ 奇时两个目标不可能同时可行。

## 6. 复杂度分析

- **时间**：$O(n)$。统计 $c_1$ 一趟；每个可行目标（至多两个）各扫一趟数 $\mathrm{mis}$；单趟计数版（§4 第 4 点）合并为一次遍历。$n \le 1000$ 下连 $O(n^2)$ 的逐次模拟交换都能过，但计数版 15 行内写完、零调试，才是赛时正解。
- **空间**：$O(1)$。只需 $c_1$、$\mathrm{mis}$、$e_1$、`ans` 等常数变量；不构造目标串。
- **赛时视角**：本题的得分点不是复杂度，而是**不重不漏地枚举两个目标 + 可行性 gating**。三步流程（判可行 → 数错位 → 除 2）写完即交，别在「能否一遍扫」上恋战——那是复盘时的优化彩蛋。

## 7. 参考代码

### C++（主版本：双目标循环）

```cpp
class Solution {
public:
    int minSwaps(string s) {
        int n = s.size();
        int c1 = count(s.begin(), s.end(), '1');
        vector<int> starts;                    // 可行目标的首字符
        if (n % 2 == 0) {
            if (c1 * 2 != n) return -1;
            starts = {0, 1};
        } else {
            if (c1 == (n + 1) / 2) starts = {1};
            else if (c1 == (n - 1) / 2) starts = {0};
            else return -1;
        }
        int ans = INT_MAX;
        for (int st : starts) {
            int mis = 0;
            for (int i = 0; i < n; i++)
                if (s[i] - '0' != (st ^ (i & 1))) mis++;
            ans = min(ans, mis / 2);            // 可行时 mis 必为偶数
        }
        return ans;
    }
};
```

### C++（单趟计数版：只数 $e_1$）

```cpp
class Solution {
public:
    int minSwaps(string s) {
        int n = s.size(), c1 = 0, e1 = 0;       // e1 = 偶数下标上 '1' 的个数
        for (int i = 0; i < n; i++)
            if (s[i] == '1') { c1++; if ((i & 1) == 0) e1++; }
        if (n % 2 == 0) {
            if (c1 * 2 != n) return -1;
            return min(e1, n / 2 - e1);         // 目标 0101… 与 1010… 的代价
        }
        if (c1 == (n + 1) / 2) return (n + 1) / 2 - e1;  // 唯一目标 1010…1
        if (c1 == (n - 1) / 2) return e1;                 // 唯一目标 0101…0
        return -1;
    }
};
```

### Python（主版本：双目标循环）

```python
class Solution:
    def minSwaps(self, s: str) -> int:
        n, c1 = len(s), s.count('1')
        if n % 2 == 0:
            if c1 * 2 != n:
                return -1
            starts = (0, 1)
        elif c1 == (n + 1) // 2:
            starts = (1,)
        elif c1 == (n - 1) // 2:
            starts = (0,)
        else:
            return -1
        ans = n
        for st in starts:
            mis = sum(1 for i, ch in enumerate(s) if int(ch) != st ^ (i & 1))
            ans = min(ans, mis // 2)             # 可行时 mis 必为偶数
        return ans
```

### Python（单趟计数版）

```python
class Solution:
    def minSwaps(self, s: str) -> int:
        n = len(s)
        c1 = s.count('1')
        e1 = sum(ch == '1' for i, ch in enumerate(s) if i % 2 == 0)
        if n % 2 == 0:
            return -1 if c1 * 2 != n else min(e1, n // 2 - e1)
        if c1 == (n + 1) // 2:                   # 唯一目标 1010…1
            return (n + 1) // 2 - e1
        if c1 == (n - 1) // 2:                   # 唯一目标 0101…0
            return e1
        return -1
```

## 8. 边界情况与易错点

1. **奇数长度必须做可行性 gating（本题最大的坑）**：若不判可行、盲目对两个形态都算 `mis // 2` 再取最小，奇数 $\mathrm{mis}$ 整除会**静默**出小数偏小的答案。反例 `s = "110"`：正确答案 $1$（唯一可行目标 `"101"`，$\mathrm{mis}=2$）；错误实现对 `"010"` 数出 $\mathrm{mis}=1$，`1 // 2 = 0`，返回 $0$——WA 且毫无预警。
2. **$\mathrm{mis}$ 必为偶数**：可行目标的 $\mathrm{mis}$ 恒为偶数（引理 3）。若算出奇数，说明把不可行目标也数了进来，或 $-1$ 判据写错——值得加 assert。
3. **$-1$ 的完整判据**：$n$ 偶且 $c_1 \ne n/2$；$n$ 奇且 $c_1 \notin \{(n-1)/2,\ (n+1)/2\}$。$n$ 奇时**不可能两个目标同时可行**，`starts` 至多一个元素。
4. **「任意交换」是公式成立的前提**：`mis/2` 依赖「一次交换修复两处」。若题目限制**相邻交换**，问题变成完全不同的排序距离类问题（按下标差绝对值求和），不能套本题公式。
5. **$n = 1$**：单字符天然交替，答案 $0$；代码自然覆盖（$n$ 奇、$c_1$ 落在 $\{(n-1)/2,(n+1)/2\}$、$\mathrm{mis}=0$），无需特判。
6. **字符与整数混用**：`'1'` 不等于 `1`。C++ 用 `s[i] - '0'`，Python 用 `int(ch)`；忘了转换时每个 `if` 恒假，$\mathrm{mis}$ 恒 $0$，输出恒 $0$——样例 `"111000"` 直接暴露。
7. **溢出与上界**：$\mathrm{mis} \le n \le 1000$，答案 $\le n/2$，`int` 绰绰有余；$n$ 偶时还可由 $\mathrm{mis}_A + \mathrm{mis}_B = n$ 推出答案 $\le \lfloor n/4 \rfloor$，本地对拍时可用于范围校验。

- **$k$ 进制交替的推广**：错位按「谁该去哪」构成字符流环，一次交换仍至多修两处，但二值时同字符彼此无区别、总能拆成 A/B 两两配对，故恒 $\mathrm{mis}/2$；$k$ 值时可能出现长度 $\ge 3$ 的环（如 `"abc" \to` `"bca"` 三处错位需 2 次交换），最优值转为「错位总数 − 最大环分解数」
- **若要求输出具体交换序列**：直接把 A 类与 B 类错位按下标序一一配对输出，$O(n)$——「计数即构造」是本题最漂亮的性质，也是配对类问题值得沉淀的手感
- **对拍建议**：$n \le 16$ 时用 §3.1 的 BFS 当标程，随机 01 串 + 边界计数（全 0、全 1、恰好 $c_1 = n/2$）各来一组，能同时覆盖 $-1$ 判据与整除两处坑
