# LeetCode 找出所有子集的异或总和再求和 题解

## 1. 题目概述

- **标题 / 题号**：找出所有子集的异或总和再求和（#1863，easy）
- **链接**：https://leetcode.cn/problems/sum-of-all-subset-xor-totals/
- **来源**：LeetCode 第 241 场周赛 Q1
- **难度**：简单
- **标签**：位运算、数组、数学、回溯、枚举

**题意**：定义数组的**异或总和**（XOR total）为数组中所有元素按位异或的结果，**空数组**的异或总和规定为 $0$。给定数组 `nums`，返回其**所有子集**的异或总和**之和**。元素取值相同但下标不同的子集需**重复计数**。

**约束**：

- $1 \le \text{nums.length} \le 12$
- $1 \le \text{nums[i]} \le 20$

> 💡 本题在本仓库另有[每日题解 1863](../../solution/1801-1900/1863_所有子集的异或总和.md)：以「面试视角」展开——先讲 DFS 再推导公式，附二项式系数计数、半数引理的推广变体与面试问答。本篇按**周赛复盘视角**重写：侧重**签到题的最短拿分路径**（$n \le 12$ 时枚举即正解，别恋战）、**翻折配对的双射证明**（比二项式系数求和更直观，一分钟讲清）、以及**赛时用两条路径交叉验证**的防翻车习惯，两篇互为印证。

## 2. 示例

**示例 1**

```text
输入：nums = [1,3]
输出：6
解释：4 个子集的异或总和分别为 0、1、3、1^3=2，
      求和 0 + 1 + 3 + 2 = 6。
```

**示例 2**

```text

输出：28
解释：8 个子集的异或总和为 0、5、1、6、5^1=4、5^6=3、1^6=7、5^1^6=2，
      求和 0 + 5 + 1 + 6 + 4 + 3 + 7 + 2 = 28。
```

```text
输出：480
```

## 3. 解题思路

### 3.1 暴力思路：枚举全部子集

看到 $n \le 12$ 就该意识到：子集一共 $2^{12} = 4096$ 个，**直接枚举就是正解**。两种等价的枚举写法：

- **DFS「选 / 不选」**：每个元素二选一，递归树共 $2^n$ 个叶子；沿途维护当前异或值，到叶子时累加，无需维护子集列表。
- **位掩码枚举**：`mask` 从 $0$ 到 $2^n - 1$，第 $i$ 位为 1 表示选中 `nums[i]`，把选中的元素异或起来累加。

时间 $O(2^n)$（DFS 版沿途维护异或，每个节点 $O(1)$），在签到题的时限里毫无压力。**Q1 的目标是 3 分钟内拿分**，枚举完全够用；下面的公式是顺手可赚的彩蛋，不是必需品。

### 3.2 核心观察：按位独立 + 翻折配对 → 一行公式

![核心观察：翻折配对，恰有一半子集点亮该位](images/subsetxor_pairing_concept.svg)

两个关键洞察：

1. **按位独立**：异或是逐位进行的，「异或总和之和」可以按二进制位**拆开算**——第 $b$ 位的总贡献 $=$ 位权 $2^b \times$ 「异或结果在第 $b$ 位为 1 的子集个数」。求和是线性的，各互不干扰。
2. **翻折配对**：若第 $b$ 位在**至少一个**元素中为 1，取定这样的元素 $x$，把全体子集按「是否含 $x$」两两配对：$S \leftrightarrow S \oplus \{x\}$（翻转 $x$ 的选入状态）。每对中两个异或值恰差一个 $x$，而 $x$ 的第 $b$ 位是 1，故两者第 $b$ 位**必然一真一假**。$2^n$ 个子集配成 $2^{n-1}$ 对，每对恰贡献一个「点亮该位」的子集——**恰好一半**。

把两点合起来：在 OR 中出现过的每一位都贡献 $2^b \times 2^{n-1}$，未出现过的位贡献 $0$。于是

$$\text{ans} = 2^{n-1} \times \sum_{b \in \text{OR}} 2^b = \text{OR}(\text{nums}) \times 2^{n-1}$$

一行代码，$O(n)$。注意「一半」**与有几个元素在该位为 1 无关**（$k \ge 1$ 即可），这是很多同学会犹豫的点。

### 3.3 算法流程：赛时决策

![算法流程：枚举直接拿分，公式顺手验证](images/subsetxor_decision_flow.svg)

赛时的合理节奏：约束一读，$n \le 12$ → 枚举可过，**先把枚举版写完提交锁定分数**；若 3 分钟内顺带想到了按位拆解，再花一分钟用翻折配对说服自己，换成一行的公式版。两条路线答案必须一致——这正是天然的**交叉验证**。

### 3.4 示例演算

![按位演算：nums = [5,1,6] 的三位贡献](images/subsetxor_bit_walkthrough.svg)

以 `nums = [5, 1, 6]`（$n = 3$）为例，逐位核对：

| 位 | 权值 $2^b$ | 拥有该位的元素 | 在 OR 中？ | 点亮子集数 | 贡献 |
|----|-----------|---------------|-----------|-----------|------|
| bit 2 | 4 | 仅 6 | ✓ | $2^{n-1} = 4$ | $4 \times 4 = 16$ |
| bit 1 | 2 | 5、6 | ✓ | $4$ | $2 \times 4 = 8$ |
| bit 0 | 1 | 5、1 | ✓ | $4$ | $1 \times 4 = 4$ |

- 按位合计：$16 + 8 + 4 = 28$；
- 公式复核：$\text{OR} = 5 \mid 1 \mid 6 = 111_2 = 7$，$2^{n-1} = 2^2 = 4$，$\text{ans} = 7 \times 4 = 28$ ✓；
- 枚举复核：$0+5+1+6+4+3+7+2 = 28$ ✓。

三条路径答案一致。注意 bit 2 只被**一个**元素（6）拥有，点亮它的子集数同样是 4（含 6 的全部子集）；bit 0 被**两个**元素拥有，点亮子集数还是 4——「一半」与 $k$ 无关的直接体现。

## 4. 算法细节

1. **公式版实现**：一次遍历按位或出 `orAll`，返回 `orAll << (n - 1)`。$n \ge 1$ 保证移位量非负；`nums[i] <= 20 < 2^5`，OR 不超过 31，左移 11 位后最大 $31 \times 2^{11} = 63488$，`int` 足够。
2. **DFS 版实现**：递归参数携带当前异或值 `cur`，进入「选」分支时 `cur ^ nums[i]`。**异或的自逆性**（$a \oplus a = 0$）让增删元素天然用 XOR 模拟，不需要回溯还原子集列表——这是子集枚举题最值得沉淀的实现手感。
3. **位掩码版实现**：`mask` 从 $0$ 枚举到 $(1 \ll n) - 1$，内层 `if (mask >> i & 1) cur ^= nums[i]`。注意这版每个子集从头算异或，总时间 $O(n \cdot 2^n)$；DFS 沿途维护则整体 $O(2^n)$。
4. **重复元素按子集计数**：题目要求元素相同的不同子集重复计数。枚举按下标区分元素，天然正确；公式版同样正确——例如 `nums = [5,5]`：OR $= 5$，$n = 2$，ans $= 10$，与枚举 $\{0, 5, 5, 0\}$ 四个值之和一致。重复元素既不改 OR，又被 $2^{n-1}$ 的计数如实涵盖。
5. **空子集**：异或为 0，加和对结果无贡献。DFS 的 `i == n` 分支会累加一次 0；公式版的「一半」里空子集天然落在不点亮的一侧。都无需特判。

## 5. 正确性证明

**引理 1（按位线性拆解）**：记 $X(S)$ 为子集 $S$ 的异或总和，则

$$\text{ans} = \sum_{S \subseteq [n]} X(S) = \sum_{b \ge 0} 2^b \cdot N_b, \qquad N_b = \#\{\,S : X(S) \text{ 的第 } b \text{ 位为 } 1\,\}$$

**证明**：每个非负整数有唯一二进制表示，$X(S) = \sum_b 2^b \cdot [\text{$X(S)$ 的第 $b$ 位为 1}]$。对所有子集求和并交换有限求和次序，即得按位贡献分解。∎

**引理 2（翻折配对 / 半数引理）**：若第 $b$ 位在至少一个元素中为 1，则 $N_b = 2^{n-1}$；否则 $N_b = 0$。

**证明**：取定第 $b$ 位为 1 的元素 $x$（按题设存在），定义全体子集上的映射 $\phi(S) = S \triangle \{x\}$（对称差，即翻转「是否含 $x$」）。则：

- $\phi(\phi(S)) = S$，$\phi$ 是**对合**；
- $x \in S$ 与 $x \notin S$ 恰成立其一，故 $S \neq \phi(S)$，**无不动点**。

于是 $2^n$ 个子集被划分成 $2^{n-1}$ 个互不相交的无序对 $\{S, \phi(S)\}$。每对中两个子集的异或值相差恰一个 $x$，即 $X(\phi(S)) = X(S) \oplus x$；由于 $x$ 的第 $b$ 位为 1，$X(S)$ 与 $X(\phi(S))$ 的第 $b$ 位**互补**，每对恰贡献一个「第 $b$ 位为 1」的子集。故 $N_b = 2^{n-1}$，**与该位为 1 的元素个数无关**。若没有任何元素第 $b$ 位为 1，则一切子集的异或该位均为 0，$N_b = 0$。∎

**定理**：$\text{ans} = \text{OR}(\text{nums}) \times 2^{n-1}$。

**证明**：OR 的第 $b$ 位为 1 当且仅当存在元素的该位为 1，故由引理 2，$N_b = 2^{n-1} \cdot [\text{OR 的第 } b \text{ 位为 } 1]$。代入引理 1：

$$\text{ans} = \sum_b 2^b \cdot 2^{n-1} \cdot [\text{OR}_b = 1] = 2^{n-1} \sum_{\text{OR}_b = 1} 2^b = 2^{n-1} \times \text{OR}(\text{nums})$$

最后一个等号成立是因为 OR 的二进制表示恰由其置位构成。∎

枚举算法的正确性是平凡的：DFS 的「选 / 不选」二叉展开或位掩码的 $[0, 2^n)$ 遍历，均**不重不漏**地枚举全部 $2^n$ 个子集并按定义求和。样例 $6, 28, 480$ 与公式输出一致，构成交叉验证。

## 6. 复杂度分析

- **时间**：公式版 $O(n)$，一次遍历求 OR；DFS 版 $O(2^n)$（每个递归节点 $O(1)$）；位掩码版 $O(n \cdot 2^n)$（每子集从头重算异或）。$n \le 12$ 时三者都在时限内轻松通过。
- **空间**：公式版 $O(1)$；枚举版 $O(n)$ 递归栈（或位掩码版 $O(1)$）。
- **赛时视角**：签到题的瓶颈是**写代码与调试的时间**而非复杂度。枚举版代码量约 10 行、几乎不可能写错；公式版只有 1 行核心代码但需要配对论证撑腰。想清楚了就交公式版，想不清楚就交枚举版——**不要在 Q1 上为了优雅多花 10 分钟**。

## 7. 参考代码

### C++

```cpp
// 公式版：ans = OR(nums) << (n-1)
class Solution {
public:
    int subsetXORSum(vector<int>& nums) {
        int orAll = 0;
        for (int x : nums) orAll |= x;
        return orAll << (nums.size() - 1);
    }
};
```

### C++（赛时枚举版：DFS 选/不选）

```cpp
class Solution {
public:
    int subsetXORSum(vector<int>& nums) {
        int total = 0;
        dfs(nums, 0, 0, total);
        return total;
    }
private:
    void dfs(vector<int>& nums, int i, int cur, int& total) {
        if (i == (int)nums.size()) {
            total += cur;
            return;
        }
        dfs(nums, i + 1, cur, total);              // 不选 nums[i]
        dfs(nums, i + 1, cur ^ nums[i], total);    // 选 nums[i]
    }
};
```

### Python

```python
class Solution:
    def subsetXORSum(self, nums: List[int]) -> int:
        or_all = 0
        for x in nums:
            or_all |= x
        return or_all << (len(nums) - 1)
```

### Python（赛时枚举版：位掩码）

```python
class Solution:
    def subsetXORSum(self, nums: List[int]) -> int:
        n = len(nums)
        total = 0
        for mask in range(1 << n):
            cur = 0
            for i in range(n):
                if mask >> i & 1:
                    cur ^= nums[i]
            total += cur
        return total
```

## 8. 边界情况与易错点

1. **移位量是 $n-1$ 不是 $n$**：`orAll << (n-1)`。记错的代价是答案翻倍；记忆锚点——OR 的每个置位恰好被**一半**子集点亮，而不是全部。
2. **$n = 1$**：答案就是 `nums[0]`（唯一非空子集），公式退化为 `orAll << 0`，自然正确。约束保证 $n \ge 1$，但本地调试若传入空数组，`size() - 1` 会变成无符号下溢的大数、移位未定义——线上不会有此输入。
3. **该位为 1 的元素个数 $k$ 与答案无关**：不要写「$k$ 个元素贡献 $k \cdot 2^{n-1}$」之类的猜想。$k \ge 1$ 时恒为 $2^{n-1}$，bit2 只被 6 拥有、bit0 被 5 和 1 拥有，点亮子集数同为 4（见 §3.4）。
4. **别用 AND 代替 OR**：AND 只保留所有元素共有的位，会漏掉仅部分元素拥有的位。判据是「该位**至少出现一次**」，对应按位或。
5. **空子集无需特判**：异或为 0，加和为零贡献；DFS 会在 `i == n` 处累加一次 0，公式中它落在不点亮的一半。
6. **重复元素重复计数**：题目按子集（下标）计数，`[5,5]` 的答案是 10 而不是 5；枚举与公式都天然正确。
7. **溢出核查**：OR $\le 31$，$2^{n-1} \le 2048$，答案最大 63488，`int` / Python 均无压力。
