# LeetCode 索引处的解码字符串 题解

## 1. 题目概述

- **标题 / 题号**：索引处的解码字符串（#880，medium）
- **链接**：https://leetcode.cn/problems/decoded-string-at-index/
- **来源**：LeetCode 第 96 场周赛 Q3
- **难度**：中等
- **标签**：栈、字符串

**题意**：给定编码字符串 `s`，按如下规则解码：

- 读到**字母**：把该字母写到解码串末尾；
- 读到**数字** $d$：把当前整个解码串**再重复** $d-1$ 次（即整串变成原来的 $d$ 倍）。

给定 $k$，返回解码串中第 $k$ 个字符（$k$ 从 $1$ 开始）。保证 $k$ 不超过解码串长度，且解码串长度小于 $2^{63}$。

**关键点**：

- 解码串可能极长（示例 3 中是 $8.3\times10^{18}$），**绝不能真的构造出来**。
- 只要求第 $k$ 个字符，可以用「长度 + 折叠」定位，无需展开。
- 数字只出现 $2 \sim 9$，不会出现 `0` 或 `1`（后者不改变长度）。

**约束**：

- $2 \le s.length \le 100$
- `s` 只含小写字母与数字 $2 \sim 9$，以字母开头
- $1 \le k \le 10^9$，且 $k$ 不超过解码串长度
- 解码串长度 $< 2^{63}$

## 2. 示例

**示例 1**

```text
输入：s = "leet2code3", k = 10
输出："o"
解释：解码过程 "leet" → "leetleet"（8）→ +"code" = "leetleetcode"（12）→ ×3 = 36。
     第 10 个字符是 'o'。
```

**示例 2**

```text
输入：s = "ha22", k = 5
输出："h"
解释："ha" → ×2 = "haha" → ×2 = "hahahaha"（8），第 5 个字符是 'h'。
```

**示例 3**

```text
输入：s = "a2345678999999999999999", k = 1
输出："a"
解释：解码串是 'a' 重复 8301530446056247680 次，长度为天文数字，但第 1 个字符显然是 'a'。
```

## 3. 解题思路

### 3.1 暴力思路

按题意真正解码：维护一个字符串，遇字母追加、遇数字重复。示例 3 会让字符串长度膨胀到 $8.3\times10^{18}$——内存与时间都直接爆炸，**必然不可行**。

即使只保留前 $k$ 个字符（$k \le 10^9$）也不行：单次重复就要复制上亿字符，而 `s` 长度 100 时重复次数可达 100 次，累计 $10^{11}$ 级操作。

### 3.2 核心观察：只记长度，从后往前「折叠」

![第二遍：折叠 k](images/wc96_q3_fold_back.svg)

**第一遍（正向）**：维护解码串的当前长度 `size`：

- 遇字母：`size += 1`
- 遇数字 $d$：`size *= d`

这一步只用 $O(|s|)$ 次运算，就能得到解码串的**总长度**（用 64 位整数，题目保证 $<2^{63}$）。

**第二遍（逆向）**：从 `s` 的末尾往前走，逐步把 `size` 与 `k` 缩回上一层：

- 遇数字 $d$：说明这一层是把上层整串重复了 $d$ 次，于是 `size /= d` 回到上层长度，`k %= size` 把 $k$ 折回上层的位置（若 $k$ 恰好是 `size` 的倍数，取模为 $0$，表示落在上层的最后一个字符）。
- 遇字母：
  - 若 `k == size`（或折叠后 `k == 0`）：这个字母就是第 $k$ 个字符，返回它。
  - 否则：`size -= 1`，继续往前（相当于「剥掉」这一格字符）。

**正确性直觉**：每次折叠都保持「第 $k$ 个字符在解码串中的位置」不变——重复 $d$ 次的串里，位置 $k$ 与位置 $k \bmod size$ 指向同一个字符（模 `size` 为 $0$ 时指向末尾）。而字母处只可能对应「这一层长度恰好等于 $k$」的情形。

### 3.3 算法流程

```text
1. size = 0
2. for ch in s：
     若 ch 是数字：size *= int(ch)
     否则：size += 1
3. for ch in s 的逆序：
     若 ch 是数字：
         size /= int(ch)
         k %= size
     否则：
         若 k == size 或 k == 0：返回 ch
         size -= 1
4. 返回空串（不会走到）
```

### 3.4 示例演算

以 `s = "leet2code3"`、$k = 10$ 为例。

**第一遍求长度**：

| 读入 | `l` | `e` | `e` | `t` | `2` | `c` | `o` | `d` | `e` | `3` |
|------|-----|-----|-----|-----|-----|-----|-----|-----|-----|-----|
| `size` | 1 | 2 | 3 | 4 | **8** | 9 | 10 | 11 | 12 | **36** |

**第二遍折叠**（从 `3` 开始往前）：

| 逆序字符 | 操作 | `size` | `k` |
|---------|------|--------|-----|
| `3`（数字） | `size/=3`，`k%=12` | 12 | 10 |
| `e`（字母） | $k \ne 12$ 且 $k \ne 0$ → `size--` | 11 | 10 |
| `d`（字母） | 同上 | 10 | 10 |
| `o`（字母） | `k == size == 10` → **返回 `o`** | 10 | 10 |

答案 `"o"`，与示例一致。

再看示例 2（`s = "ha22"`，$k = 5$）：长度依次为 1、2、4、**8**。逆序：`2` → `size=4`、`k=5%4=1`；`2` → `size=2`、`k=1%2=1`；`a` → $k=1 \ne 2$、$k \ne 0$ → `size=1`；`h` → `k == size == 1` → 返回 `h`。正确。

## 4. 算法细节

1. **`size` 必须用 64 位整数**：题目保证长度 $<2^{63}$，C++ 用 `long long`；Python 整数无上限，天然安全。
2. **`k` 用 `int` 就够**：$k \le 10^9$，但折叠时 `k %= size` 的 `size` 可能很大，取模结果仍在 $[0, size)$，用 `long long` 更省心。
3. **`k %= size` 后可能为 0**：表示落在上层的最后一个字符，因此字母判定要写 `k == size || k == 0`。
4. **数字只可能是 $2\sim9$**：所以 `size` 单调不减，第一遍不会出现除以 0；也不用处理 `0`/`1`（$1$ 不改变长度、$0$ 会让长度归零）。
5. **`size /= d` 的整除性**：第一遍在数字处乘过 $d$，所以逆向时必然整除，不会有精度问题。
6. **返回类型是 `string`**：返回单个字符组成的字符串，不是 `char`。

## 5. 正确性证明

**定义**：对 `s` 的每个前缀 $s[0..i]$，记 $L(i)$ 为该前缀解码后的长度。设第一遍算法维护的 `size` 在处理到位置 $i$ 后等于 $L(i)$。

**引理 1（长度计算正确）**：第一遍结束后 `size` 等于整个 `s` 解码后的长度。

**证明**：对前缀长度归纳。空前缀长度为 $0$。设处理完 $s[0..i-1]$ 后 `size` $=L(i-1)$：若 $s[i]$ 是字母，解码串在其末尾追加一个字符，长度 $L(i) = L(i-1)+1$，算法 `size += 1` ✓；若 $s[i] = d$ 是数字，整串重复 $d$ 次，$L(i) = d \cdot L(i-1)$，算法 `size *= d` ✓。归纳成立。∎

**引理 2（折叠保持位置语义）**：设在逆向处理到某个位置时，当前 `size` 为某一层解码串的长度、`k` 为该层中目标字符的位置（$1 \le k \le size$），则折叠一步后，新层的 `size'`、`k'` 满足「新层第 $k'$ 个字符 = 原层第 $k$ 个字符」。

**证明**：分两种字符讨论。

- 数字 $d$：上一层长度 $size' = size/d$，本层是上一层的 $d$ 次重复，第 $k$ 个字符等于上一层第 $((k-1) \bmod size') + 1$ 个字符。算法取 `k' = k mod size'`，若 $k' = 0$ 则表示上一层第 $size'$ 个字符——正是 $((k-1)\bmod size')+1$ 的等价表示。✓
- 字母：本层长度 $size$ 比上一层多 $1$（该字母位于本层末尾）。若 $k = size$，目标字符就是该字母本身（算法在此返回）；否则 $1 \le k < size$，目标字符与上一层第 $k$ 个字符相同，算法 `size -= 1` 且 `k` 不变 ✓。∎

**定理**：算法返回解码串的第 $k$ 个字符。

**证明**：由引理 1，第一遍得到总长度。由引理 2，逆向每一步都保持「当前层第 $k$ 个字符」等于原解码串第 $k$ 个字符。逆向过程长度严格减小（数字处至少除以 2、字母处减 1），必然终止；终止时只能在某个字母处命中 `k == size || k == 0` 并返回该字母，此字母即所求字符。若 `s` 以字母开头（题目保证），至少有一个字母可被命中，故不会返回空串。∎

## 6. 复杂度分析

- **时间**：$O(|s|)$。两遍扫描，每遍 $|s| \le 100$ 次操作，与 $k$、解码长度无关。
- **空间**：$O(1)$。只维护 `size` 与 `k` 两个整数（不计输入）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    string decodeAtIndex(string s, int k) {
        long long size = 0;
        for (char ch : s) {
            if (isdigit(ch)) size *= ch - '0';
            else size += 1;
        }
        for (int i = s.size() - 1; i >= 0; i--) {
            char ch = s[i];
            if (isdigit(ch)) {
                size /= ch - '0';       // 回到上一层「模板」
                k %= size;              // k 落回模板内的位置，0 表示模板末尾
            } else {
                if (k == size || k == 0) return string(1, ch);
                size -= 1;              // 这一层的最后一个字符被剥掉
            }
        }
        return "";
    }
};
```

### Python

```python
class Solution:
    def decodeAtIndex(self, s: str, k: int) -> str:
        size = 0
        for ch in s:
            if ch.isdigit():
                size *= int(ch)
            else:
                size += 1
        # 从后往前：不断把 k 折回上一层
        for ch in reversed(s):
            if ch.isdigit():
                size //= int(ch)
                k %= size
            else:
                if k == size or k == 0:
                    return ch
                size -= 1
        return ""
```

## 8. 边界情况与易错点

1. **真的去解码**：示例 3 会直接内存爆炸。这是本题唯一的「陷阱型」错误。
2. **`size` 用 `int`**：长度可达 $8.3\times10^{18}$，`int` 立刻溢出，长度错则答案必错。
3. **漏掉 `k %= size`**：不取模会让 $k$ 一直大于上层长度，永远无法命中。
4. **字母判定只写 `k == size`**：折叠后 $k$ 可能为 $0$（表示上层末尾），漏判会继续往前走到错误的字母。
5. **`size //= d` 与 `k %= size` 的顺序**：必须先除再取模，反了会用到旧长度。
6. **`k` 可能为 0 吗（输入）**：题目保证 $k \ge 1$，但折叠过程中会变成 $0$，要按「0 表示末尾」处理。
7. **`s` 以数字开头**：题目保证以字母开头，所以第一层长度非零，不会出现「除以 0」或空串。
