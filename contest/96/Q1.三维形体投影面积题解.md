# LeetCode 三维形体投影面积 题解

## 1. 题目概述

- **标题 / 题号**：三维形体投影面积（#883，easy）
- **链接**：https://leetcode.cn/problems/projection-area-of-3d-shapes/
- **来源**：LeetCode 第 96 场周赛 Q1
- **难度**：简单
- **标签**：几何、数组、数学、矩阵

**题意**：在 $n \times n$ 的网格 `grid` 中，`grid[i][j]` 表示格子 $(i, j)$ 上**叠放**了这么多个 $1\times1\times1$ 的立方体（都贴着底面、沿 $z$ 轴堆叠）。求这个三维形体在 $xy$、$yz$、$zx$ 三个平面上的投影面积之和。

**关键点**：

- 从**顶部**看（$xy$ 平面投影）：只要格子上有一个或以上的立方体，就贡献 $1$ 个单位面积。
- 从**正面**看（$yz$ 平面投影，沿 $i$ 方向看）：每一**行**中最高的一摞决定这一行的投影高度。
- 从**侧面**看（$zx$ 平面投影，沿 $j$ 方向看）：每一**列**中最高的一摞决定这一列的投影高度。
- 空网格（全 $0$）不会有任何投影。

**约束**：

- $n = grid.length = grid[i].length$
- $1 \le n \le 50$
- $0 \le grid[i][j] \le 50$

## 2. 示例

**示例 1**

```text
输入：grid = [[1,2],[3,4]]
输出：17
解释：俯视 4 个格子都有立方体 → 4；
     正视两行最大值为 2 和 4 → 6；
     侧视两列最大值为 3 和 4 → 7；
     合计 4 + 6 + 7 = 17。
```

**示例 2**

```text
输入：grid = [[2]]
输出：5
解释：1×1 网格上叠了 2 个立方体。
     俯视 1；正视 2；侧视 2 —— 合计 1 + 2 + 2 = 5。
```

**示例 3**

```text
输入：grid = [[1,0],[0,2]]
输出：8
解释：俯视 2（只有对角两个格子非空）；
     正视 max(1,0) + max(0,2) = 1 + 2 = 3；
     侧视 同理 1 + 2 = 3；合计 2 + 3 + 3 = 8。
```

## 3. 解题思路

### 3.1 暴力思路

真的去「投影」：枚举三维空间中的每个单位立方体，把它分别投到三个平面上、用集合去重再数大小。坐标范围 $[0, n)\times[0,n)\times[0,50]$，立方体总数可达 $50^3 = 1.25\times10^5$，三个集合的插入与去重是 $O(n^2 \cdot \max grid)$。虽然 $n \le 50$ 也能过，但完全没必要——三个投影面积各有**闭式公式**，一遍扫描即可。

常见的错误「暴力」是按 `grid[i][j]` 直接累加三次（认为每个立方体在三面各投一个单位面积）——这会把**重叠**的投影重复计数。例如示例 1 直接累加会得到 $3 \times (1+2+3+4) = 30$，远大于正确答案 $17$。

### 3.2 核心观察：三个投影各有一个闭式公式

![三个量的公式](images/wc96_q1_formula.svg)

设 $n = grid.length$。

**俯视（$xy$ 投影）**：每个格子上的柱子只要高度 $> 0$，从正上方看就是一个 $1\times1$ 的方块，与高度无关：

$$\text{top} = \#\{(i,j) : grid[i][j] > 0\}$$

**正视（$yz$ 投影）**：固定行 $i$，沿列方向看过去，这一行所有柱子排成一排，其中**最高**的那摞决定了整个行的轮廓高度；较矮的柱子被它挡住：

$$\text{front} = \sum_{i=0}^{n-1} \max_{0 \le j < n} grid[i][j]$$

**侧视（$zx$ 投影）**：固定列 $j$，沿行方向看过去，同理：

$$\text{side} = \sum_{j=0}^{n-1} \max_{0 \le i < n} grid[i][j]$$

答案即 $\text{top} + \text{front} + \text{side}$。

**为什么「最大值」而不是「求和」？** 因为投影是一束平行光打过去，同一行（或列）中相邻的柱子会**互相遮挡**——矮的被高的挡在前面，只有最高的那摞的轮廓能被看到。这正是投影与「表面积」的本质区别。

### 3.3 算法流程

```text
1. top = front = side = 0
2. colMax = 长度 n 的数组，初值 0
3. for i in 0..n-1：
   3.1 rowMax = 0
   3.2 for j in 0..n-1：
         v = grid[i][j]
         若 v > 0：top += 1
         rowMax = max(rowMax, v)
         colMax[j] = max(colMax[j], v)
   3.3 front += rowMax
4. side = sum(colMax)
5. 返回 top + front + side
```

### 3.4 示例演算

对 `grid = [[1,2],[3,4]]`：

| 行 $i$ | 行内容 | `top` 增量 | `rowMax` | `front` 累计 | `colMax` 变化 |
|--------|--------|-----------|---------|-------------|--------------|
| 0 | 1, 2 | +2 | 2 | 2 | `[1, 2]` |
| 1 | 3, 4 | +2 | 4 | 6 | `[3, 4]` |

于是 $\text{top} = 4$、$\text{front} = 6$、$\text{side} = 3 + 4 = 7$，合计 $17$，与示例一致。

对示例 3（`[[1,0],[0,2]]`）：`top = 2`（两个非零格）、`front = 1 + 2 = 3`、`colMax = [1, 2]` 得 `side = 3`，合计 $8$。

## 4. 算法细节

1. **`top` 只判 $>0$**：写成 `top += grid[i][j]` 会把高度当面积，结果偏大。
2. **列最大值需要独立数组**：行最大值可以在扫行时现算，列最大值必须跨行累积，用一个长度 $n$ 的 `colMax` 数组（或再扫一遍矩阵）。
3. **`front` 与 `side` 的方向**：`front` 是「按行取最大」，`side` 是「按列取最大」，二者恰好转置。写反了在方阵上结果会互换，答案可能仍然「看起来合理」但示例 1 会给出 $7+6$ 交换——注意示例 1 的 $6$ 与 $7$ 不同，可以用来验证方向没写反。
4. **可以只扫一遍**：外层行循环里同时更新 `top`、`rowMax`、`colMax`，最后再对 `colMax` 求和。
5. **全 0 网格**：三个量都是 $0$，返回 $0$。
6. **数值范围**：$n \le 50$、值 $\le 50$，最大面积 $50^2 + 50 \times 50 + 50\times 50 = 7500$，`int` 足够。

## 5. 正确性证明

**引理 1（俯视）**：$xy$ 平面投影的面积等于非空格子数。

**证明**：每个格子 $(i,j)$ 上若 $grid[i][j] > 0$，其立方体在 $xy$ 平面的投影恰为格子本身（单位正方形），且不同格子的投影互不重叠；若 $grid[i][j] = 0$ 则无投影。故总面积为非空格子数。∎

**引理 2（正视）**：$yz$ 平面投影的面积等于 $\sum_i \max_j grid[i][j]$。

**证明**：固定行 $i$，该行所有立方体的 $yz$ 投影落在同一条「竖直条带」上（$y$ 坐标相同、$z$ 从 $0$ 到各自高度）。这些投影的并集是从 $z=0$ 到 $z=\max_j grid[i][j]$ 的整段（因为最矮的柱子从 $z=0$ 起填充，最高的柱子覆盖到最高处，中间无空隙），故该行贡献 $\max_j grid[i][j]$。不同行的条带 $y$ 坐标不同、互不重叠，可加。∎

**引理 3（侧视）**：$zx$ 平面投影的面积等于 $\sum_j \max_i grid[i][j]$，证明与引理 2 完全对称（把「行」换成「列」）。∎

**定理**：算法返回三个投影面积之和，即正确答案。

**证明**：算法按引理 1、2、3 的公式分别计算 `top`、`front`、`side`（`top` 在扫到 $>0$ 的格子时自增；`front` 累加每行最大值；`side` 由 `colMax` 求和得到），最后相加。由三条引理，三者分别等于三个投影的真实面积，故总和正确。∎

## 6. 复杂度分析

- **时间**：$O(n^2)$。矩阵只扫一遍，每个格子 $O(1)$ 更新。
- **空间**：$O(n)$。`colMax` 数组；其余为常数。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int projectionArea(vector<vector<int>>& grid) {
        int n = grid.size();
        int top = 0, front = 0, side = 0;
        for (int i = 0; i < n; i++) {
            int rowMax = 0;
            for (int j = 0; j < n; j++) {
                if (grid[i][j] > 0) top++;              // 俯视：每个非空格子贡献 1
                rowMax = max(rowMax, grid[i][j]);
            }
            front += rowMax;                            // 正视：每行最高的一列
        }
        for (int j = 0; j < n; j++) {
            int colMax = 0;
            for (int i = 0; i < n; i++) colMax = max(colMax, grid[i][j]);
            side += colMax;                             // 侧视：每列最高的一格
        }
        return top + front + side;
    }
};
```

### Python

```python
class Solution:
    def projectionArea(self, grid: list[list[int]]) -> int:
        n = len(grid)
        top = sum(1 for row in grid for v in row if v > 0)      # 俯视
        front = sum(max(row) for row in grid)                   # 正视
        side = sum(max(grid[i][j] for i in range(n)) for j in range(n))  # 侧视
        return top + front + side
```

## 8. 边界情况与易错点

1. **把高度当面积**：`top += grid[i][j]` 是本题第一大坑。俯视只看「有没有」，不看「多高」。
2. **正视/侧视写反**：`front` 用行最大、`side` 用列最大；示例 1 的 $6$ 与 $7$ 可以用来检验。
3. **全 0 网格**：三个量都是 $0$，返回 $0$；`max(row)` 对全 0 行返回 $0$，无需特判。
4. **单格网格**：`[[2]]` → $1 + 2 + 2 = 5$；`[[0]]` → $0$。
5. **行列最大值混用同一个变量**：`rowMax` 必须每行重置，`colMax` 必须跨行累积；混用会得到错误结果。
6. **用「每个立方体投影三次再相加」**：把遮挡关系算错，结果远大于答案（示例 1 会算成 $30$）。
