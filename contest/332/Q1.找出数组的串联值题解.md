# LeetCode 找出数组的串联值 题解

## 1. 题目概述

- **标题 / 题号**：找出数组的串联值（#2562，easy）
- **链接**：https://leetcode.cn/problems/find-the-array-concatenation-value/
- **来源**：LeetCode 第 332 场周赛 Q1
- **难度**：简单
- **标签**：数组、双指针、模拟、数学

**题意**：给定下标从 $0$ 开始的整数数组 `nums`。两个数字的**串联**是把二者拼成一个新的十进制数（如 $15$ 与 $49$ 串联得 $1549$）。`nums` 的串联值初始为 $0$，反复执行下述操作直到 `nums` 为空：

- 若长度 $>1$：取**首元素** $a$ 与**尾元素** $b$，把二者串联值累加进总串联值，再删去首尾两个元素；
- 若仅剩 $1$ 个元素：把该元素本身累加进总串联值，再删去它。

返回最终串联值。

**约束**：

- $1 \le \text{nums.length} \le 1000$
- $1 \le \text{nums[i]} \le 10^4$

> 💡 签到题的目标是**最短路径切题**：读题 30 秒内识别出「首尾配对 + 拼接」两个要素，直接双指针收拢 + 算术拼接，20 行内解决；真正值得沉淀的是**拼接的算术化公式**与 **long long 溢出边界**这两个坑位。

## 2. 示例

**示例 1**

```text
输入：nums = [7,52,2,4]
输出：596

解释：
- 第 1 步：首 7、尾 4 → 串联 74，累加后串联值 = 74，nums 变为 [52,2]
- 第 2 步：首 52、尾 2 → 串联 522，累加后串联值 = 596，nums 变为空
```

**示例 2（奇数长度，含中间单元素）**

```text
输入：nums = [5,14,13,8,12]
输出：673

解释：
- 第 1 步：首 5、尾 12 → 串联 512，串联值 = 512，nums 变为 [14,13,8]
- 第 2 步：首 14、尾 8 → 串联 148，串联值 = 660，nums 变为 [13]
- 第 3 步：只剩 13，直接累加，串联值 = 673
```

**示例 3（补充：$10^4$ 是 5 位数，单次拼接已达 $10^9$ 量级）**

```text
输入：nums = [10000, 10000]
输出：1000010000

解释：10000 与 10000 串联得 1000010000（b = 10⁴ 有 5 位，p = 10⁵）。
警示：n = 1000 时最多 500 对这样的拼接，累加和可达 ~5×10¹¹，超出 int 范围。
```

## 3. 解题思路

### 3.1 暴力思路：逐字模拟

按题面逐字翻译：用一个支持双端删除的容器（`deque` 或 `vector`），每轮取 `front` 与 `back`，用 `stoi(to_string(a) + to_string(b))` 算串联值累加，再弹出两端；剩一个时直接累加。能 AC（$n \le 1000$），但有两处「笨重」：

- `vector` 头部 `erase` 是 $O(n)$，整体 $O(n^2)$（用 `deque` 可消除）；
- 每对都做一次「整数→字符串→整数」的往返，平白引入分配与解析开销。

签到题真正要练的是把模拟语义**翻译成指针与算术**：删除不必真的删除，拼接不必经过字符串。

### 3.2 核心观察：删首尾 = 双指针收拢，拼接 = 算术平移

![核心观察：首尾双指针配对收拢，拼接公式 a×10^d(b)+b](images/concat_value_concept.svg)

**观察 ①（删除只是语义）**：第 $k$ 轮取的「首、尾」就是原数组的下标 $k-1$ 与 $n-k$。「删去首尾」等价于 $i$ 从左、$j$ 从右**相向收拢**，数组本身一动不动。

**观察 ②（拼接可以算术化）**：设 $b$ 的十进制位数为 $d(b)$，则 $a$ 后接 $b$ 的串联值为

$$a \times 10^{d(b)} + b$$

即「把 $a$ 整体左移 $d(b)$ 位，空出的低位恰好放下 $b$」。例如 $5$ 后接 $12 = 5\times10^2+12=512$，$14$ 后接 $8=14\times10^1+8=148$。

> ⚠️ $p = 10^{d(b)}$ 由**尾部** $b$ 的位数决定（$b$ 落在低位），千万别错用 $a$ 的位数。

### 3.3 算法流程

![算法流程：初始化 → i<j 求位数并算术拼接累加 → i==j 单元素累加 → 返回](images/concat_value_flow.svg)

1. 初始化 $i=0$，$j=n-1$，$\text{ans}=0$；
2. 当 $i<j$：连除 $10$ 求 $p=10^{d(\text{nums}[j])}$；$\text{ans} \mathrel{+}= \text{nums}[i]\times p+\text{nums}[j]$；$i\mathrel{+}=1$，$j\mathrel{-}=1$；
3. 若 $i=j$（$n$ 为奇数）：$\text{ans} \mathrel{+}= \text{nums}[i]$；
4. 返回 $\text{ans}$。

> ⚠️ 求位数用「$t \mathrel{/}= 10$」的整数循环，别写 $\log_{10}$：浮点在 $b=10^k$ 处可能算出 $k-1+\varepsilon$，截断后位数少 $1$，$p$ 缩小 $10$ 倍。整数连除精确且 $d(b)\le5$ 至多 5 次迭代。

### 3.4 示例演算

![示例 2 演算：三轮收拢 512 → 660 → 673](images/concat_value_walkthrough.svg)

以示例 2 `nums=[5,14,13,8,12]`（$n=5$，奇数）为例：

| 轮次 | 配对 $(a,b)$ | $d(b)$ | 拼接 $a\times10^{d(b)}+b$ | 收拢后剩余 | 串联值 |
|------|--------------|--------|---------------------------|------------|--------|
| 1 | $(5,12)$ | $2$ | $5\times100+12=512$ | $[14,13,8]$ | $512$ |
| 2 | $(14,8)$ | $1$ | $14\times10+8=148$ | $[13]$ | $660$ |
| 3 | 单元素 $13$ | — | 直接累加 $13$ | 空 | $673$ |

$n$ 为偶数时（示例 1）最后一轮收拢后 $i>j$ 直接结束，无单元素分支。

## 4. 算法细节

1. **位数计算**：`p = 1; for (t = b; t > 0; t /= 10) p *= 10;` —— 整数域精确，$b\le10^4$ 时至多 5 次迭代，$p\le10^5$。
2. **拼接公式**：贡献 $= a\times p + b$。$a$ 在高位整体平移，$b$ 原样落在低 $d(b)$ 位。
3. **溢出核算（C++）**：单次拼接最大 $10^4\times10^5+10^4=1{,}000{,}010{,}000$，勉强还在 `int` 范围内；但 $n=1000$ 时 500 对累加可达约 $5\times10^{11}$，**累加器必须 `long long`**（本题 C++ 接口返回值即 `long long`）。
4. **奇偶统一**：循环条件用严格 $i<j$，退出后 $i=j$ 恰好刻画「剩一个中间元素」；$n=1$ 时循环一次都不执行，直接走单元素分支。
5. **Python 无溢出问题**：整数任意精度，算术版与 `int(f"{a}{b}")` 字符串版都行，算术版更快更通用。

## 5. 正确性证明

**引理 1（配对一致性）**：第 $k$ 轮（$k$ 从 $1$ 计）循环体执行时，$i=k-1$ 且 $j=n-k$，即 $i,j$ 恰指向「删除前 $k-1$ 对首尾后」数组的首与尾。

**证明**（对 $k$ 归纳）：$k=1$ 时 $i=0,\ j=n-1$，即原数组首尾，成立。设第 $k$ 轮成立，执行 $i{+}{=}1,\ j{-}{=}1$ 后 $i=k,\ j=n-k-1$，恰为删除第 $k$ 对后的首尾，故第 $k+1$ 轮仍成立。∎

**引理 2（拼接公式）**：设 $1\le b\le10^4$，$d=d(b)$ 为其十进制位数，则 $a$ 与 $b$ 的串联值等于 $a\cdot10^{d}+b$。

**证明**：设 $b$ 的十进制表示为 $b=\sum_{t=0}^{d-1}c_t\,10^t$（$c_{d-1}\ge1$，无前导零）。$a$ 后接 $b$ 的数字串按位展开：$a$ 的各位数字全部抬高 $d$ 位（即乘 $10^d$），低 $d$ 位依次为 $c_{d-1},\dots,c_0$，其值恰为 $b$。故串联值 $=a\cdot10^{d}+b$。∎

**定理**：算法返回值等于按题意模拟得到的串联值。

**证明**：由引理 1，逐轮取到的 $(a,b)$ 与「删首尾再取首尾」的题意语义完全一致，共 $\lfloor n/2\rfloor$ 轮；$n$ 为奇数时循环退出 $i=j$，剩余的唯一中间元素按题意直接累加，$n$ 为偶数时 $i>j$ 无剩余。由引理 2，每轮累加的数值等于字符串拼接值。各轮贡献之和与累加顺序无关（加法交换律），故返回值正确。∎

## 6. 复杂度分析

- **时间复杂度**：$O(nD)$，其中 $D=\max d(b)\le5$ 为常数，即 $O(n)$。每轮一次位数循环（$\le5$ 次除法）加 $O(1)$ 累加，共 $\lfloor n/2\rfloor$ 轮；这已是最优——每个元素至少读一次。
- **空间复杂度**：$O(1)$ 额外空间（两个游标、一个累加器与常数临时量）。对照：`deque` 模拟版 $O(n)$ 额外空间，字符串拼接版每轮产生临时字符串分配。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long findTheArrayConcVal(vector<int>& nums) {
        long long ans = 0;
        int i = 0, j = (int)nums.size() - 1;
        while (i < j) {
            long long p = 1;
            for (int t = nums[j]; t > 0; t /= 10) p *= 10;  // p = 10^d(b)
            ans += (long long)nums[i] * p + nums[j];
            ++i; --j;                                        // 收拢
        }
        if (i == j) ans += nums[i];                          // 奇数长度单元素
        return ans;
    }
};
```

### Python

```python
class Solution:
    def findTheArrayConcVal(self, nums: List[int]) -> int:
        i, j = 0, len(nums) - 1
        ans = 0
        while i < j:
            a, b = nums[i], nums[j]
            p, t = 1, b
            while t > 0:
                p *= 10
                t //= 10
            ans += a * p + b
            i += 1
            j -= 1
        if i == j:
            ans += nums[i]
        return ans
```

## 8. 边界情况与易错点

1. **C++ 累加溢出（头号坑）**：单次拼接 $1{,}000{,}010{,}000$ 尚在 `int` 内，但 500 对累加可达 $5\times10^{11}$，`int` 累加器必然溢出——必须 `long long`，乘法处 `(long long)nums[i] * p` 同步转型。
2. **位数用 `log10` 的浮点陷阱**：$b=10^k$ 时 `log10(b)` 可能得 $k-1+\varepsilon$，截断成 $k-1$ 位，$p$ 小 10 倍、串联值算错。用连除 10 的整数循环。
3. **$p$ 由 $b$（尾部）的位数决定**：拼接方向是「$a$ 后接 $b$」，$b$ 落在低位；误用 $a$ 的位数在 $a,b$ 位数不同时必错。
4. **奇数长度漏单元素**：循环条件 $i<j$ 退出后若 $i=j$，需把 `nums[i]` 直接累加；漏掉则少加中间元素（示例 2 会输出 660）。
5. **$n=1$**：循环不执行，直接返回 `nums[0]`，无需特判但别把循环写成 `do-while`。
6. **$10^4$ 是 5 位数**：不要下意识以为 $10^4$ 以内是 4 位数，$b=10000$ 时 $d(b)=5$、$p=10^5$（示例 3）。
