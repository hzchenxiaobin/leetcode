# LeetCode 统计公平数对的数目 题解

## 1. 题目概述

- **标题 / 题号**：统计公平数对的数目（#2563，medium）
- **链接**：https://leetcode.cn/problems/count-the-number-of-fair-pairs/
- **来源**：LeetCode 第 332 场周赛 Q2
- **难度**：中等
- **标签**：数组、排序、双指针、二分查找

**题意**：给定下标从 $0$ 开始、长度为 $n$ 的整数数组 `nums`，以及两个整数 `lower` 与 `upper`。统计同时满足 $0 \le i < j < n$ 与 $lower \le nums[i] + nums[j] \le upper$ 的**下标对** $(i, j)$ 的个数（这样的数对称为「公平数对」）。

**约束**：

- $1 \le n \le 10^5$
- $-10^9 \le nums[i] \le 10^9$
- $-10^9 \le lower \le upper \le 10^9$

> 💡 题眼是「**计数**」而非「**找下标**」：只要个数、不要具体对，这是「排序破坏下标也无所谓」的通行信号；再配合「和落在一段**连续区间**」的双端条件，天然引出**排序 + 前缀差分 + 双指针**的经典组合。两个溢出坑（和与答案都可能超 `int`）让本题的 AC 率在赛中并不高。

## 2. 示例

**示例 1**

```text
输入：nums = [0,1,7,4,4,5], lower = 3, upper = 6
输出：6

解释：6 个公平数对 (0,3)、(0,4)、(0,5)、(1,3)、(1,4)、(1,5)，
对应数值配对 0+4、0+4、0+5、1+4、1+4、1+5，和分别为 4、4、5、5、5、6。
```

**示例 2（lower == upper，和必须恰好相等）**

```text
输入：nums = [1,7,9,2,5], lower = 11, upper = 11
输出：1

解释：仅 (2,3) 一对：9 + 2 = 11。
```

**示例 3（补充：重复元素按「下标对」计数，不去重）**

```text
输入：nums = [2,2,2,2], lower = 4, upper = 4
输出：6

解释：任意两个 2 的和都是 4，C(4,2) = 6 对。
警示：若先去重成 [2] 再数对，会错误地输出 0。
```

## 3. 解题思路

### 3.1 暴力思路：枚举所有下标对

双重循环枚举 $i < j$，逐一判断 $lower \le nums[i] + nums[j] \le upper$：时间 $O(n^2) \approx 10^{10}$，$n = 10^5$ 下必然超时。问题出在「**每一对都要单独看一眼**」——而公平与否只取决于**两个数值**，与它们在原数组中的位置无关，这正是排序类技巧的入口。

### 3.2 核心观察：排序不变性 + 前缀差分

![核心观察：排序不改变配对计数，区间计数等于两个前缀计数之差](images/fair_pairs_concept.svg)

**观察 ①（排序不影响答案）**：判定条件只含 $nums[i] + nums[j]$ 这一个**数值量**。排序只是把下标做了一次双射重排，任意一对数值在重排前后仍一一配对，公平数对总数不变。于是**先排序**，数组变成升序 $a_0 \le a_1 \le \dots \le a_{n-1}$，为「批量计数」铺路。

**观察 ②（区间计数 = 前缀之差）**：定义

$$F(U) = \#\{\,(i,j) : i < j,\ a_i + a_j \le U\,\}$$

即「和 $\le U$」的对数。由于元素都是整数，数对之和也是整数，而 $lower - 1 < lower$，故

$$\#\{lower \le a_i + a_j \le upper\} = F(upper) - F(lower-1)$$

**双端条件**被拆成两个**单端条件**之差——与「区间和 = 前缀和相减」同源。问题归约为：如何高效求 $F(U)$。

### 3.3 算法流程：双指针线性求 F(U)

![算法流程：排序后双指针求 F(U)，答案为 F(upper)−F(lower−1)](images/fair_pairs_flow.svg)

在**有序**数组上求 $F(U)$：置 $l = 0$，$r = n-1$，两指针相向而行：

- 若 $a_l + a_r \le U$：由有序性，$(l, r]$ 内任何 $a_q \le a_r$，故 $a_l$ 与它们**全部**配对都 $\le U$，**一次计入 $r - l$ 对**，然后 $l$ 右移；
- 否则 $a_l + a_r > U$：由有序性，$[l, r)$ 内任何 $a_p \ge a_l$，故 $a_r$ 与它们**任何**配对都 $> U$，含 $a_r$ 的未统计数对全部无资格，$r$ 左移。

每步 $O(1)$ 淘汰一个元素，单次 $F$ 为 $O(n)$；整体调用 $F(upper)$ 与 $F(lower-1)$ 两次，相减即得答案。

> ⚠️ C++ 中 $a_l + a_r$ 可达 $\pm 2 \times 10^9$，超出 `int`，比较前必须转 `long long`；答案上限 $\binom{n}{2} \approx 5 \times 10^9$，累加器同样必须 `long long`。

### 3.4 示例演算

![示例 1 演算：sorted=[0,1,4,4,5,7]，F(6)=7、F(2)=1，答案 7−1=6](images/fair_pairs_walkthrough.svg)

以示例 1 为例，排序后 $a = [0,1,4,4,5,7]$。

**求 $F(6)$**：

| 步 | $l$ | $r$ | $a_l + a_r$ | 与 $6$ 比较 | 动作 | 累计 |
|----|-----|-----|-------------|------------|------|------|
| 1 | 0 | 5 | $0+7=7$ | $>$ | $r{-}{-}$ | 0 |
| 2 | 0 | 4 | $0+5=5$ | $\le$ | $+4$ 对，$l{+}{+}$ | 4 |
| 3 | 1 | 4 | $1+5=6$ | $\le$ | $+3$ 对，$l{+}{+}$ | 7 |
| 4 | 2 | 4 | $4+5=9$ | $>$ | $r{-}{-}$ | 7 |
| 5 | 2 | 3 | $4+4=8$ | $>$ | $r{-}{-}$ | 7 |

$l = r$ 相遇结束，$F(6) = 7$。

**求 $F(2)$**：$0$ 与 $7, 5, 4, 4$ 的和都 $> 2$，连续 $r{-}{-}$ 直到 $r = 1$；此时 $0 + 1 = 1 \le 2$，$+1$ 对后 $l = r$ 结束，$F(2) = 1$。

**答案** $= F(upper) - F(lower-1) = 7 - 1 = 6$，与示例输出一致。

## 4. 算法细节

1. **排序**：升序 `sort`，$O(n \log n)$，是整个算法复杂度的瓶颈；排序后双指针的正确性完全依赖有序性。
2. **前缀差分**：只写一个「单端计数」函数 $F(U)$，调用 $F(upper)$ 与 $F(lower-1)$ 相减。双端条件、`lower == upper`（示例 2）、`lower < upper` 全部被统一处理，无需任何特判。
3. **双指针的两个视角**：
   - **批量计入**：$a_l + a_r \le U$ 时一次计入 $r - l$ 对而非 $1$ 对，这是双指针比逐对枚举快的根源；
   - **批量排除**：$a_l + a_r > U$ 时一次排除所有含 $a_r$ 的候选对。
   两个指针各自只单向移动，总移动步数 $\le 2n$，故单次 $F$ 为 $O(n)$。
4. **二分写法（同样正确）**：排序后对每个 $i$，在**后缀** $a_{i+1..n-1}$ 中二分统计值域 $[\,lower - a_i,\ upper - a_i\,]$ 内的元素个数（`upper_bound` 减 `lower_bound`）。总复杂度同为 $O(n \log n)$；关键在于**只在后缀里数**，天然避免「自己和自己配对」。
5. **溢出核算（C++）**：$a_l + a_r \in [-2 \times 10^9,\ 2 \times 10^9]$，两个 `int` 直接相加溢出，比较式必须 `(long long)nums[l] + nums[r]`；$F(upper)$ 上界 $\binom{10^5}{2} \approx 5 \times 10^9$，累加器必须 `long long`（本题接口返回值即 `long long`）。

## 5. 正确性证明

**引理 1（排序不变性）**：将 `nums` 任意重排后，公平数对的个数不变。

**证明**：设重排使原下标 $k$ 的元素落在新位置 $\pi(k)$。原数组中每个下标对 $(i, j)$，$i < j$，对应重排数组中的位置对 $\{\pi(i), \pi(j)\}$；反之，重排数组中每个位置对也唯一对应原数组的一个下标对。这是下标对集合之间的**双射**，且对应对的数值多重集都是 $\{nums[i], nums[j]\}$，故数对之和相等、公平性相同。因此公平数对的个数在双射下保持不变。∎

**引理 2（前缀差分）**：$\#\{(i,j) : i<j,\ lower \le a_i + a_j \le upper\} = F(upper) - F(lower-1)$。

**证明**：记 $P_U = \{(i,j) : i<j,\ a_i + a_j \le U\}$，由定义 $P_U$ 随 $U$ 单调不减，且 $lower - 1 < lower \le upper$ 给出 $P_{lower-1} \subseteq P_{upper}$。又 $a_i + a_j$ 为整数，故 $lower \le a_i+a_j \le upper \iff a_i+a_j \le upper \text{ 且 } a_i+a_j \ge lower \iff a_i+a_j \le upper \text{ 且 } a_i+a_j \not\le lower-1$。于是目标集合恰为 $P_{upper} \setminus P_{lower-1}$（差不交），计数相减即得。∎

**定理（双指针正确性）**：上述双指针过程返回 $F(U)$。

**证明**（不变量归纳）：声明**不变量 INV**：某轮循环开始时，所有满足 $i < l$ 或 $j > r$ 的 $F$-对（和 $\le U$ 的对）都已被**恰好计入一次**，且两端都落在 $[l, r]$ 内的对均未计入。初始 $l = 0$，$r = n-1$，INV 平凡成立。

- 若 $a_l + a_r \le U$：对任意 $q \in (l, r]$，有序性给出 $a_q \le a_r$，故 $a_l + a_q \le a_l + a_r \le U$，即 $(l, q)$ 全是 $F$-对；它们恰是以 $l$ 为第一下标的**全部**未计入对（第二下标 $> r$ 者已由 INV 计入）。计入 $r - l$ 对后 $l{+}{+}$，INV 保持。
- 若 $a_l + a_r > U$：对任意 $p \in [l, r)$，有序性给出 $a_p \ge a_l$，故 $a_p + a_r \ge a_l + a_r > U$，即含 $a_r$ 且第一下标 $\ge l$ 的对都不是 $F$-对（第一下标 $< l$ 者已计入）。故 $r{-}{-}$ 后 INV 保持。

每轮 $l$ 严格增或 $r$ 严格减，至多 $n-1$ 轮后 $l \ge r$ 终止；终止时窗口 $[l, r]$ 内不存在任何下标对，由 INV，全部 $F$-对被恰好计入一次，返回值 $= F(U)$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \log n)$。排序 $O(n \log n)$ 占主导；两次 $F(U)$ 各跑一轮双指针 $O(n)$。对照：二分写法为 $n$ 次 $\times O(\log n)$，同为 $O(n \log n)$；暴力为 $O(n^2)$。
- **空间复杂度**：$O(1)$ 额外空间（两个游标 + 一个累加器），不计排序自身的 $O(\log n)$ 递归栈（Python `sort` 另需 $O(n)$ 辅助数组）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long countFairPairs(vector<int>& nums, int lower, int upper) {
        sort(nums.begin(), nums.end());
        // f(U)：和 ≤ U 的下标对个数（双指针，一次 O(n)）
        auto f = [&](int U) -> long long {
            long long ans = 0;
            int l = 0, r = (int)nums.size() - 1;
            while (l < r) {
                if ((long long)nums[l] + nums[r] <= U) {  // 和可达 ±2e9，先转型
                    ans += r - l;                         // a[l] 与 (l, r] 全部配对
                    ++l;
                } else {
                    --r;                                 // a[r] 与 [l, r) 配对必超
                }
            }
            return ans;
        };
        return f(upper) - f(lower - 1);   // 前缀差分
    }
};
```

### Python

```python
class Solution:
    def countFairPairs(self, nums: List[int], lower: int, upper: int) -> int:
        nums.sort()

        def f(U: int) -> int:          # 和 ≤ U 的对数
            l, r = 0, len(nums) - 1
            ans = 0
            while l < r:
                if nums[l] + nums[r] <= U:
                    ans += r - l       # a[l] 与 (l, r] 全部配对
                    l += 1
                else:
                    r -= 1
            return ans

        return f(upper) - f(lower - 1)
```

## 8. 边界情况与易错点

1. **C++ 求和溢出（头号坑）**：`nums[l] + nums[r]` 两个 `int` 相加可达 $\pm 2 \times 10^9$，超 `int` 上溢是未定义行为——必须写 `(long long)nums[l] + nums[r]` 再比较。
2. **答案溢出**：$n = 10^5$ 时最多 $\binom{n}{2} \approx 5 \times 10^9$ 对，超出 `int` 范围；累加器与返回值必须 `long long`（Python 整数任意精度，无此问题）。
3. **重复元素不去重**：数的是**下标对**而非数值对，示例 3 中 `[2,2,2,2]`、`lower = upper = 4` 应输出 6；任何去重都会算错。
4. **lower == upper**：前缀差分自动覆盖「和恰好等于某个值」的退化情形（示例 2），无需特判。
5. **lower − 1 的边界**：$lower \ge -10^9$，故 $lower - 1 \ge -10^9 - 1$，仍在 32 位范围内可安全计算；但若题目把范围放到 $-2^{31}$，`lower - 1` 会下溢，稳妥起见参数可直接用 `long long` 传递。
6. **二分写法的自配对**：对每个 $i$ 在**整个**数组上二分 $[lower - a_i,\ upper - a_i]$ 时，区间可能包含 $a_i$ 自己——务必只在**后缀** $[i+1, n)$ 上统计，或按对称计数时想清楚自配对的补偿方式。
7. **n = 1**：不存在任何数对，`while (l < r)` 一次都不执行，天然返回 0，无需特判。
8. **全负数 / 负区间**：双指针的移动逻辑只依赖有序性与比较结果，与元素正负无关，不要手动添加「元素非负」的隐含假设。
