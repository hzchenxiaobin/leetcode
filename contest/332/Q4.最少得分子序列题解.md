# LeetCode 最少得分子序列 题解

## 1. 题目概述

- **标题 / 题号**：最少得分子序列（#2565，hard）
- **链接**：https://leetcode.cn/problems/subsequence-with-the-minimum-score/
- **来源**：LeetCode 第 332 场周赛 Q4
- **难度**：困难
- **标签**：双指针、字符串、二分查找、前后缀分解、贪心

**题意**：给定两个只含小写字母的字符串 `s` 和 `t`。你可以从 `t` 中删除任意数目的字符（也可以不删）：

- 若一个字符都不删，得分为 $0$；
- 否则记被删字符的最小下标为 $\text{left}$、最大下标为 $\text{right}$，得分为 $\text{right}-\text{left}+1$。

要求删除之后 `t` 的剩余部分是 `s` 的**子序列**，返回最小得分。

**约束**：

- $1 \le n = |s|,\ m = |t| \le 10^5$
- `s`、`t` 只含小写英文字母

> 💡 得分只由被删字符的**最左 / 最右下标**决定，中间删多删少不影响——这是把问题降维成「删除一个连续段」的钥匙。本题在本仓库另有[每日题解 2565](../../solution/2501-2600/2565_最少得分子序列.md)：按 **`s` 的切分点**枚举、最大化「保留的前后缀长度之和」，公式 $\text{ans} = m - \max_k(\text{pre}'[k] + \text{suf}'[k])$。本文与其互为对偶——按 **`t` 的删除区间**直接枚举、**最小化删除窗口**，更贴合得分定义，且天然引出「单调性 + 双指针 / 二分」的扫描结构。

## 2. 示例

**示例 1**

```text
输入：s = "abacaba", t = "bzaa"
输出：1

解释：删除下标 1 处的 'z'，t 变为 "baa"，是 "abacaba" 的子序列，
      得分 = 1 - 1 + 1 = 1。
```

**示例 2**

```text
输入：s = "cde", t = "xyz"
输出：3

解释：s 中没有 x / y / z，只能把 t 全部删空（空串是任意串的子序列），
      得分 = 2 - 0 + 1 = 3。
```

**示例 3**

```text
输入：s = "abcde", t = "ace"
输出：0

解释：t 本身就是 s 的子序列，一个字符都不用删，得分为 0。
```

## 3. 解题思路

### 3.1 暴力思路

枚举「删哪些字符」是 $2^m$ 级的子集枚举，直接排除。利用「得分只看跨度」，问题等价于：枚举删除的连续段 $[l, r]$（$O(m^2)$ 个），对每段验证 $t[0..l-1] + t[r+1..m-1]$ 是否为 $s$ 的子序列（单次 $O(n+m)$），总计 $O(m^2(n+m)) \approx 10^{15}$，不可行。

> ⚠️ 瓶颈在于**对每个候选段都从头做一次子序列匹配**。突破口：可行性只依赖「保留的前缀 / 后缀」这两截，把它们**预处理成两张以 `t` 下标为刻度的表**，之后每个候选段 $O(1)$ 判定。

### 3.2 核心观察一：只需考虑删除一个连续段

![核心观察一：离散删除集合补全为连续区间，得分不变、保留串更短](images/2565_interval_reduction.svg)

设某可行方案删除了下标集合 $D$，$l = \min D$，$r = \max D$，得分 $= r - l + 1$。把 $[l, r]$ 内**未删**的字符也一并删掉：

- **得分不变**：得分仍由 $(l, r)$ 这对端点决定；
- **依然可行**：保留串从 $t \setminus D$ 变成更短的 $t[0..l-1] + t[r+1..m-1]$，后者是前者的子序列，由子序列的传递性仍是 $s$ 的子序列。

于是**存在最优解删除的是一整段** $t[l..r]$，问题从「选子集」降维为「选区间」。

### 3.3 核心观察二：前后缀分解，pre / suf 两张贪心表

![前后缀分解模型：pre 与 suf 的定义、切分点与可行性判定](images/2565_presuf_split.svg)

把删除段记为 $[l, y-1]$（保留的后缀从 $y$ 开始），得分为 $y - l$。定义：

$$\text{pre}[l] = \min\{\, i : t[0..l-1] \text{ 是 } s[0..i-1] \text{ 的子序列} \,\}$$

$$\text{suf}[y] = \max\{\, i : t[y..m-1] \text{ 是 } s[i..n-1] \text{ 的子序列} \,\}$$

（不可行分别记作 $\infty$ / $-\infty$；约定 $\text{pre}[0] = 0$、$\text{suf}[m] = n$。）直觉上：

- $\text{pre}[l]$：**尽早**匹配完 `t` 的前缀，得到「最短消耗」的 `s` 前缀长度；
- $\text{suf}[y]$：**尽晚**开始匹配 `t` 的后缀，得到「最晚起点」下标。

两者都能一遍贪心求出（引理 2）。**删除段 $[l, y-1]$ 可行 $\iff \text{pre}[l] \le \text{suf}[y]$**（引理 3）：中间任何一个切分点 $i \in [\text{pre}[l], \text{suf}[y]]$ 都能把 `s` 无重叠地分给前缀和后缀。目标变为：

$$\min_{\,0 \le l \le y \le m,\ \text{pre}[l] \le \text{suf}[y]} (y - l)$$

### 3.4 单调性 → 双指针（或二分）

$\text{pre}$ 与 $\text{suf}$ 都是**非降**的：保留的前缀越长，需要的 `s` 前缀越长；保留的后缀越短（$y$ 越大），允许的起点越晚。因此固定 $l$ 时，最小可行 $y$ 就是从左往右**第一个**满足 $\text{suf}[y] \ge \text{pre}[l]$ 的位置；且这个 $y$ 随 $l$ 增大**单调不退**——双指针一遍扫完，$O(m)$。

若不想推单调性，也可对每个 $l$ 在非降的 $\text{suf}$ 上**二分**找最小可行 $y$，$O(m \log m)$——这正是本题标签 Binary Search 的来由；双指针是它的线性改进。

### 3.5 示例演算

![示例演算：pre/suf 表与双指针扫描，删 'z' 得 1](images/2565_walkthrough.svg)

以示例 1 $s = $ `abacaba`（$n=7$）、$t = $ `bzaa`（$m=4$）为例：

| $i$ | 0 | 1 | 2 | 3 | 4 |
|-----|---|---|---|---|---|
| $\text{pre}[i]$ | 0 | 2 | $\infty$ | $\infty$ | $\infty$ |
| $\text{suf}[i]$ | $-\infty$ | $-\infty$ | **4** | 6 | 7 |

- $\text{pre}[1] = 2$：`b` 在 $s[1]$ 匹配完；`z` 不存在于 `s`，故 $l \ge 2$ 全不可行；
- $\text{suf}[2] = 4$：`aa` 最晚可从 $s[4]$ 开始（用 $s[4]$、$s[6]$）；$\text{suf}[4] = 7$ 是空后缀哨兵。

双指针扫描：$l=0$ 时 $y$ 右移到 2，候选 $2-0=2$（删 `bz`）；$l=1$ 时 $y=2$ 已满足 $\text{suf}[2]=4 \ge 2$，候选 $2-1=1$（删 `z`）；$l=2$ 时 $\text{pre}=\infty$ 提前结束。**答案 1**：保留 `b` + `aa` = `baa` ⊆ `abacaba`。

## 4. 算法细节

1. **求 pre（左 → 右贪心）**：指针 $j$ 从 $0$ 起扫 `s`。对 $i = 0..m-1$：从 $j$ 起找第一个 $s[j] = t[i]$；找不到则更大的 $l$ 全不可行（置 $\infty$，直接 break）；否则 $\text{pre}[i+1] = j + 1$，$j$ 右移一位。$O(n)$。
2. **求 suf（右 → 左贪心）**：指针 $j$ 从 $n-1$ 起倒扫 `s`。对 $i = m-1..0$：从 $j$ 起向左找第一个 $s[j] = t[i]$；找不到则更小的 $y$ 全不可行（置 $-\infty$）；否则 $\text{suf}[i] = j$，$j$ 左移一位。$O(n)$。
3. **双指针取最小**：$y = 0$；对 $l = 0..m$：若 $\text{pre}[l] > n$ 则 break；$y \leftarrow \max(y, l)$；只要 $\text{suf}[y] < \text{pre}[l]$ 就 $y{+}{+}$（哨兵 $\text{suf}[m] = n$ 保证循环终止）；用 $y - l$ 更新答案。
4. **二分写法**：$\text{suf}$ 非降 ⇒ 对每个 $l$ 在 $[l, m]$ 上二分最小 $y$ 使 $\text{suf}[y] \ge \text{pre}[l]$，$O(m \log m)$，思路完全等价。
5. **初始值**：答案初始化为 $m$（删光 `t` 恒可行：$\text{pre}[0] = 0 \le \text{suf}[m] = n$），保证循环即使一个候选都没遇到也正确。

## 5. 正确性证明

**引理 1（区间化归）**：若删除非空集合 $D$ 可行，记 $l = \min D$，$r = \max D$，则删除整段 $[l, r]$ 也可行且得分相同。

**证明**：$t \setminus [l,r]$ 是 $t \setminus D$ 再删去若干字符所得，故是 $t \setminus D$ 的子序列；而 $t \setminus D$ 是 $s$ 的子序列，由传递性 $t \setminus [l,r]$ 也是 $s$ 的子序列。得分只由 $(l, r)$ 决定，两者同为 $r - l + 1$。∎

**引理 2（贪心刻画）**：「左 → 右、能配就配」的贪心恰好算出 $\text{pre}[l]$；「右 → 左、尽量靠右配」的贪心恰好算出 $\text{suf}[y]$。

**证明**（以 pre 为例，suf 对称）。设贪心把 $t[0..k-1]$ 匹配到 $p_1 < \cdots < p_k$，任取一组可行匹配 $q_1 < \cdots < q_k$，归纳证明 $p_j \le q_j$（从而 $\text{pre}[k] = p_k + 1$ 最小）：$p_1$ 取 $t[0]$ 在 `s` 中的最左出现，$p_1 \le q_1$；若 $p_j \le q_j$，则 $q_{j+1} > q_j \ge p_j$ 且 $s[q_{j+1}] = t[j]$，即 $q_{j+1}$ 是 $p_j$ 之后一个等于 $t[j]$ 的位置，而 $p_{j+1}$ 取的是其中最左者，故 $p_{j+1} \le q_{j+1}$。∎

**引理 3（切分等价）**：对 $0 \le l \le y \le m$，删除段 $[l, y-1]$ 可行 $\iff \text{pre}[l] \le \text{suf}[y]$（两侧均取有限值）。

**证明**：
（⇒）设拼接串 $t[0..l-1] + t[y..m-1]$ 是 `s` 的子序列，取其在 `s` 中的一组匹配，令 $i$ 为前缀部分最后一个匹配下标加 $1$（前缀为空时 $i = 0$；后缀为空时 $y = m$，$\text{suf}[m] = n \ge \text{pre}[l]$ 自然成立）。则 $t[0..l-1]$ 是 $s[0..i-1]$ 的子序列，故 $\text{pre}[l] \le i$；后缀部分的匹配位置全部 $\ge i$，即 $t[y..]$ 是 $s[i..]$ 的子序列，故 $\text{suf}[y] \ge i$。
（⇐）取 $i \in [\text{pre}[l], \text{suf}[y]]$：前缀可在 $s[0..\text{pre}[l]-1] \subseteq s[0..i-1]$ 内匹配，后缀可在 $s[\text{suf}[y]..] \subseteq s[i..]$ 内匹配；一个匹配全在 $i$ 之前、另一个从 $i$ 起，位置不冲突，拼接即得拼接串是 `s` 的子序列。∎

**引理 4（单调性）**：$\text{pre}$ 与 $\text{suf}$ 均非降；对每个 $\text{pre}[l] \le n$ 的 $l$，$f(l) = \min\{ y \in [l, m] : \text{suf}[y] \ge \text{pre}[l] \}$ 存在且随 $l$ 非降。

**证明**：若 $t[0..l]$ 是 $s[0..i-1]$ 的子序列，则其前缀 $t[0..l-1]$ 也是，故 pre 的可行集随 $l$ 增大而缩小，$\text{pre}$ 非降；同理若 $t[y..]$ 是 $s[i..]$ 的子序列则 $t[y+1..]$ 也是，故 suf 的可行集随 $y$ 增大而扩大，$\text{suf}$ 非降。存在性：$\text{suf}[m] = n \ge \text{pre}[l]$。单调性：$\text{pre}[l+1] \ge \text{pre}[l]$ 使满足 $\text{suf}[y] \ge \text{pre}[l+1]$ 的集合是满足 $\text{suf}[y] \ge \text{pre}[l]$ 的集合的子集，最小元只增不减，再与下界 $l+1$ 取 max 仍不减。∎

**定理**：算法输出最小得分。

**证明**：由引理 1，任意可行删除方案的得分都等于某个连续段方案的得分（不删的得分 $0$ 对应 $t \subseteq s$，即存在 $l = y$ 使 $\text{pre}[l] \le \text{suf}[l]$，含 $l = y = m$ 的情形），故只需在连续段中取最优。由引理 3，段 $[l, y-1]$ 的可行性与得分分别等价于 $\text{pre}[l] \le \text{suf}[y]$ 与 $y - l$。对每个可行的 $l$，最优的 $y$ 是 $f(l)$；由引理 4 的单调性，双指针中 $y$ 从不回退，恰好对每个 $l$ 计算了 $f(l) - l$；$\text{pre}[l] > n$ 时提前 break 不漏解（其后全不可行）。对所有候选取最小即全局最优。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n + m)$
  - 求 `pre`、`suf` 各一遍贪心，指针均单向移动，共 $O(n + m)$；
  - 双指针扫描中 $y$ 至多前进 $m$ 次，$O(m)$；
  - 二分写法为 $O(n + m \log m)$，同样能过。
- **空间复杂度**：$O(m)$，`pre`、`suf` 各 $m + 1$ 个元素。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minimumScore(string s, string t) {
        int n = s.size(), m = t.size();
        const int INF = n + 1;                        // pre 的不可行哨兵
        vector<int> pre(m + 1, INF), suf(m + 1, -1);  // suf 的不可行哨兵 -1
        pre[0] = 0;
        for (int i = 0, j = 0; i < m; ++i) {          // 左→右贪心：最短 s 前缀
            while (j < n && s[j] != t[i]) ++j;
            if (j == n) break;                        // 之后全部不可行
            pre[i + 1] = ++j;
        }
        suf[m] = n;
        for (int i = m - 1, j = n - 1; i >= 0; --i) { // 右→左贪心：最晚 s 起点
            while (j >= 0 && s[j] != t[i]) --j;
            if (j < 0) break;
            suf[i] = j--;
        }
        int ans = m;                                  // 删光 t 恒可行
        for (int l = 0, y = 0; l <= m; ++l) {
            if (pre[l] > n) break;                    // 前缀不可行，更长的更不可行
            y = max(y, l);
            while (suf[y] < pre[l]) ++y;              // suf[m] = n 保证终止
            ans = min(ans, y - l);
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def minimumScore(self, s: str, t: str) -> int:
        n, m = len(s), len(t)
        INF = n + 1
        pre = [INF] * (m + 1)
        suf = [-1] * (m + 1)
        pre[0] = 0
        j = 0
        for i in range(m):                    # 左→右贪心
            k = s.find(t[i], j)
            if k < 0:
                break
            j = k + 1
            pre[i + 1] = j
        suf[m] = n
        j = n - 1
        for i in range(m - 1, -1, -1):        # 右→左贪心
            k = s.rfind(t[i], 0, j + 1)
            if k < 0:
                break
            suf[i] = k
            j = k - 1
        ans = m
        y = 0
        for l in range(m + 1):
            if pre[l] > n:
                break
            y = max(y, l)
            while suf[y] < pre[l]:
                y += 1
            ans = min(ans, y - l)
        return ans
```

## 8. 边界情况与易错点

1. **`t` 本身就是 `s` 的子序列**：答案 0，无需特判——存在 $l = y$ 使 $\text{pre}[l] \le \text{suf}[l]$（如 $l = y = m$），最小候选为 0（示例 3）。
2. **哨兵不能省**：$\text{pre}[0] = 0$（不保留前缀）、$\text{suf}[m] = n$（不保留后缀）分别对应「删一段前缀」「删一段后缀」的极端方案，缺了会漏解。
3. **不可行的单调传播**：pre 一旦 $\infty$ 其后全 $\infty$、suf 一旦 $-\infty$ 其前全 $-\infty$，两处贪心都可以提前 break；主循环里 `pre[l] > n` 同理。
4. **`y` 必须抬到不低于 `l`**：`y = max(y, l)` 不可省，否则当 `suf` 前段全是 $-\infty$ 时会算出负得分。
5. **求 `suf` 的贪心方向**：必须「尽量靠右」匹配，得到的才是**最晚**起点；写成尽量靠左会使 `suf` 偏小，把可行方案误判为不可行。
6. **答案一定存在**：`l = 0, y = m`（删光 `t`）恒可行，答案上界为 $m$，初始化 `ans = m` 即可。
