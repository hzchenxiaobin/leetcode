# LeetCode 二叉树剪枝 题解

## 1. 题目概述

- **标题 / 题号**：二叉树剪枝（#814，medium）
- **链接**：https://leetcode.cn/problems/binary-tree-pruning/
- **来源**：LeetCode 第 79 场周赛 Q2
- **难度**：中等
- **标签**：树、深度优先搜索、二叉树

**题意**：给定一棵二叉树，节点值只可能是 $0$ 或 $1$。把「不含任何 $1$ 的子树」整棵删掉——注意删的是**子树**（节点自身 + 全部后代），删完后祖先可能又变成新的「不含 1 的子树」，需要连锁处理。返回剪枝后的根节点。

**约束**：

- 节点数 $n$ 满足 $1 \le n \le 200$
- $Node.val \in \{0, 1\}$

## 2. 示例

**示例 1**

```text
输入：root = [1,null,0,0,1]
输出：[1,null,0,null,1]
解释：根 1 的右孩子是 0，它的左孩子 0 子树里没有 1 → 删；右孩子 1 保留。
      注意这个值为 0 的节点本身被保留了，因为它还有含 1 的后代。
```

**示例 2**

```text
输入：root = [1,0,1,0,0,0,1]
输出：[1,null,1,null,1]
解释：根的左孩子 0 的两个孩子都是 0 → 整棵左子树被删；根的右孩子是 1，保留，
      但它自己的左孩子 0 是叶子（子树只有 0）→ 删，只留下右孩子 1。
```

**示例 3**

```text
输入：root = [1,1,0,1,1,0,1,0]
输出：[1,1,0,1,1,null,1]
解释：根左孩子的左孩子 0、根右孩子的左孩子 0，两个 0 都是叶子（子树只有自己），
      不含 1 → 各删一个节点；其余节点都有含 1 的后代，全部保留。
```

## 3. 解题思路

### 3.1 暴力思路

最直白的做法是「反复扫描」：每一轮遍历整棵树，对每个节点再扫一遍它的子树，判断是否「全是 0」，是就把它从父节点上摘掉；然后重新扫描，因为删掉一片全 0 子树后，它的祖先可能变成新的「全 0 子树」。

- 单轮扫描 $O(n)$ 个节点，每个节点扫子树 $O(n)$，即 $O(n^2)$；
- 最坏要 $O(n)$ 轮（比如一条很长的 0 链，必须一层一层由外向内剥），总 $O(n^3)$。

更本质的困难在于：**能不能删一个节点，取决于它的整棵子树；而「能删」这件事会沿着祖先链向上传染**。从上往下看，永远看不到完整信息。

### 3.2 核心观察：把「删不删」压缩成一个布尔量 hasOne

![节点去留只取决于子树是否含 1](images/wc79_q2_subtree_predicate.svg)

定义

$$hasOne(u) = \begin{cases} \text{false}, & u = \varnothing \\ [u.val = 1] \lor hasOne(u.left) \lor hasOne(u.right), & \text{否则} \end{cases}$$

其中 $[\cdot]$ 是示性函数。核心观察只有一句话：

> 节点 $u$ 保留 $\iff hasOne(u) = \text{true}$；被删的子树恰好就是 $hasOne = \text{false}$ 的那些子树。

于是「删除」不再是一个需要搜索的动作，而变成**父节点根据孩子返回的布尔值把指针置空**：$hasOne(u.left)$ 为 false 就令 `u.left = null`。连锁传染的问题也自动消失——孩子返回 false 时，祖先看到的就已经是「孩子不存在」。

并且 $hasOne(u)$ **只依赖两个孩子的返回值**，所以自底向上一遍后序 DFS 就够了：访问顺序是「先孩子、后自己」，一次遍历 $O(n)$。

### 3.3 算法流程 / 状态转移

![后序 DFS 流程](images/wc79_q2_postorder_flow.svg)

```text
dfs(u):
    if u == null: return false          # 空树不含 1
    l = dfs(u.left)                     # ① 先递归左孩子
    r = dfs(u.right)                    # ② 再递归右孩子
    if not l: u.left  = null            # ③ 孩子不含 1 → 剪掉（置空指针）
    if not r: u.right = null
    return u.val == 1 or l or r         # ④ 自己的子树是否含 1

pruneTree(root):
    return dfs(root) ? root : null      # 根也可能被整棵剪掉
```

四步严格按后序：**先拿到孩子的结论，再决定自己的指针，最后把自己的结论上报给父亲**。

### 3.4 示例演算

![示例 3 后序演算](images/wc79_q2_walkthrough.svg)

以示例 3 的 `[1,1,0,1,1,0,1,0]` 为例，节点记为 A=根(1)、B=A.left(1)、C=A.right(0)、D=B.left(1)、E=B.right(1)、F=C.left(0)、G=C.right(1)、H=D.left(0)，后序访问顺序与返回值：

| 步 | 节点 | 左返回 | 右返回 | 处理 | 返回 |
|----|------|--------|--------|------|------|
| 1 | H(0) | – | – | 叶子，自己是 0 | false |
| 2 | D(1) | H:false | – | 置空 D.left（剪 H） | true |
| 3 | E(1) | – | – | 叶子，自己是 1 | true |
| 4 | B(1) | D:true | E:true | 两个孩子都保留 | true |
| 5 | F(0) | – | – | 叶子，自己是 0 | false |
| 6 | G(1) | – | – | 叶子，自己是 1 | true |
| 7 | C(0) | F:false | G:true | 置空 C.left（剪 F） | true |
| 8 | A(1) | B:true | C:true | 两个孩子都保留 | true |

第 7 步是关键：C 自己虽然是 0，但右孩子 G 返回 true，所以 C 的 `hasOne = true`，C 必须保留 —— 它只是丢掉了左孩子。最终输出 `[1,1,0,1,1,null,1]`。

## 4. 算法细节

1. **必须在后序位置做决策**：先序时孩子的结论还没算出来，只能靠「再扫一遍子树」临时判断，退化成 $O(n^2)$。后序保证拿到 `l`、`r` 后再动指针。
2. **「删除」= 父节点把指针置空**，而不是把子树从内存里释放。LeetCode 判题只看结构；若手写 `delete`，要小心后续仍有悬垂指针被访问。
3. **返回值语义要唯一**：`dfs` 返回「子树是否含 1」，不要混用「这个节点是否被删」。前者让父节点可以直接用，后者需要额外约定「被删返回什么」。
4. **根节点也可能被剪**：整棵树没有 1 时答案是 `null`，所以入口必须判断 `dfs(root)` 的返回值，而不是无条件 `return root`（这是本题最高频的 WA 点）。
5. **空节点统一记为 false**：`hasOne(null) = false` 一条就同时处理了「叶子」「单孩子」「空树」三种情况，代码里不需要额外特判叶子。
6. **原地修改 + 返回值双保险**：指针置空保证了树结构正确，返回值保证父节点能判断自己的去留；两件事都不能省。
7. **递归深度**：$n \le 200$，退化链表也只有 200 层，递归完全安全。若数据放大到 $10^5$ 就必须改成显式栈的迭代后序。
8. **C++ 返回指针时不要返回局部变量地址**：`nullptr` 就是空树，直接用即可。

## 5. 正确性证明

**引理 1（dfs 返回值正确）**：对任意节点 $u$，`dfs(u)` 返回 true $\iff$ 以 $u$ 为根的子树中存在值为 1 的节点。

**证明**：对子树高度归纳。$u = \varnothing$ 时返回 false，空树确实不含 1。设高度为 $h$ 的节点两个孩子的高度都小于 $h$，由归纳假设 `dfs(u.left)` 与 `dfs(u.right)` 分别正确报告了左右子树是否含 1；而 `dfs(u)` 返回 `u.val == 1 || l || r`，正是「自己为 1 或某个孩子子树含 1」，即 $u$ 的子树含 1。∎

**引理 2（剪枝不改 hasOne）**：对任意节点 $u$，在以 $u$ 为根的子树内执行完 `dfs(u)` 后，该子树仍然含 1 当且仅当它原本含 1。

**证明**：由引理 1，`dfs(u)` 只在某个孩子返回 false（其子树原本不含 1）时把该孩子置空，删掉的都是不含 1 的子树，不会删掉任何值为 1 的节点，故含 1 性不变。∎

**引理 3（子树剪枝完全）**：执行完 `dfs(u)` 后，以 $u$ 为根的子树中保留下来的节点恰为原树中所有满足 $hasOne(v) = \text{true}$ 的 $v \in \text{subtree}(u)$。

**证明**：对高度归纳。叶子：$u.val = 1$ 时保留（$hasOne$ 为真），$u.val = 0$ 时 `dfs` 返回 false，父节点会把它置空（被删）。归纳步：设左右子树分别满足结论，对任一孩子 $c$，`dfs(c)` 为 false $\iff$ $c$ 的子树不含 1 $\iff$ 其中所有节点 $hasOne$ 为假，此时整片被置空；为 true 时整片按归纳假设保留正确。$u$ 自身被保留当且仅当父节点没有置空它，即 $hasOne(u)$ 为真。∎

**定理**：`pruneTree` 返回的树恰为原树中所有「子树含 1」的节点按原父子关系构成的树。

**证明**：`pruneTree` 直接返回 `dfs(root) ? root : null`。由引理 3（取 $u = root$），返回树中保留的节点集合恰为 $\{v : hasOne(v) = \text{true}\}$，且父子关系未被改动（只做了置空）。$hasOne(v) = \text{true}$ 正是「$v$ 的子树含 1」；又由引理 2，剪枝过程不会改变任何节点的含 1 性，所以判定与「原树中子树含 1」一致。若根也被剪，说明整棵树不含 1，返回 `null` 正确。∎

## 6. 复杂度分析

- **时间**：$O(n)$。`dfs` 对每个节点恰好调用一次，每次只做常数次比较与指针赋值，无任何重复扫描。
- **空间**：$O(h)$，$h$ 为树高，即递归栈深度；最坏（退化链）$O(n)$，$n \le 200$ 时约 200 层，安全。除此之外没有额外数组，是原地算法。

## 7. 参考代码

### C++

```cpp
/**
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right)
 *         : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    TreeNode* pruneTree(TreeNode* root) {
        return hasOne(root) ? root : nullptr;   // 整棵树不含 1 → null
    }

private:
    // 返回以 u 为根的子树中是否存在值为 1 的节点
    bool hasOne(TreeNode* u) {
        if (!u) return false;
        bool l = hasOne(u->left);
        bool r = hasOne(u->right);
        if (!l) u->left = nullptr;              // 后序：先拿结论，再动指针
        if (!r) u->right = nullptr;
        return u->val == 1 || l || r;
    }
};
```

### Python

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def pruneTree(self, root: TreeNode | None) -> TreeNode | None:
        def has_one(u: TreeNode | None) -> bool:
            if u is None:
                return False
            left_has = has_one(u.left)
            right_has = has_one(u.right)
            if not left_has:
                u.left = None
            if not right_has:
                u.right = None
            return u.val == 1 or left_has or right_has

        return root if has_one(root) else None
```

## 8. 边界情况与易错点

1. **整棵树全 0**：例如 `[0]`、`[0,0,0]`，答案必须是 `null`。只写 `return root;` 而忘记判断返回值就会 WA。
2. **值为 0 但孩子含 1**：示例 1 的 `root.right = 0` 必须保留。看到 0 就删是第二个高频错误——判据是「子树含 1」，不是「自己等于 1」。
3. **单个叶子 0**：叶子本身就是一棵子树，`[0]` 的子树只有它自己，因此必删；`[1]` 必留。
4. **单孩子节点**：置空一个孩子时不要把另一个也置空；`if (!l)` 与 `if (!r)` 必须彼此独立。
5. **递归返回后再访问已删子树**：置空指针后，父节点的后续代码不要再访问该孩子；本题只在置空之前读取返回值，安全。
6. **自己造测试时的序列化**：LeetCode 的层序输出会**去掉尾部 `null`**，本地对拍要同样裁剪，否则 `[1,null,0,null,1]` 可能被写成 `[1,null,0,null,1,null,null]` 影响比对。
7. **原地修改的副作用**：`pruneTree` 直接改传入的树，多次调用同一棵树时结果不会继续变化（幂等），但若在别处还持有被剪节点的引用，需要自己保证不再使用。
