# LeetCode 最大三角形面积 题解

## 1. 题目概述

- **标题 / 题号**：最大三角形面积（#812，easy）
- **链接**：https://leetcode.cn/problems/largest-triangle-area/
- **来源**：LeetCode 第 79 场周赛 Q1
- **难度**：简单
- **标签**：几何，数组，数学，多边形

**题意**：给定 X-Y 平面上 $n$ 个互不相同的整点 $points[i] = (x_i, y_i)$，任取**三个下标不同**的点组成三角形，返回所有三角形中**面积的最大值**。答案与真实值的误差在 $10^{-5}$ 以内即视为正确。

**约束**：

- $3 \le n = \text{points.length} \le 50$
- $-50 \le x_i, y_i \le 50$，坐标全为整数
- 所有点互不相同（但**可能共线**）

> 💡 签到题的关键不在复杂度：$\binom{50}{3} = 19600$ 个三元组随便枚举都能过。真正要选对的是**面积公式**——它决定了代码有没有精度风险。

## 2. 示例

**示例 1**

```text
输入：points = [[0,0],[0,1],[1,0],[0,2],[2,0]]
输出：2.00000
解释：5 个点中取 (0,0)、(0,2)、(2,0) 得到的红色三角形面积最大，为 2。
```

**示例 2**

```text
输入：points = [[1,0],[0,0],[0,1]]
输出：0.50000
解释：只有一组三点，两直角边长为 1，面积 1/2 = 0.5。
```

**示例 3**（自造，考察共线）

```text
输入：points = [[0,0],[1,1],[2,2],[3,3]]
输出：0.00000
解释：所有点共线，任何三点都不构成三角形，最大面积为 0。
```

## 3. 解题思路

### 3.1 暴力思路

最朴素的做法：三重循环枚举所有 $i < j < k$，对每个三角形求面积、取最大。复杂度 $O(n^3)$，在 $n = 50$ 时是 $19600$ 次面积计算，毫无压力——**这题就是让你暴力**。

但「求面积」这一步有两种写法，差别很大：

| 公式 | 表达式 | 问题 |
|------|--------|------|
| 海伦公式 | $S = \sqrt{s(s-a)(s-b)(s-c)}$ | 先算 3 个边长（各含 1 次开方），再套 1 次开方；退化三角形时 $s-a$ 可能因舍入变负，开方出 NaN |
| 叉积公式 | $S = \tfrac{1}{2}\lvert (B-A) \times (C-A) \rvert$ | 全是整数乘减，**零误差** |

海伦公式在 $n=50$ 时也能 AC，但它把一个本质上是整数的问题拖进了浮点：三次 `sqrt` 纯属浪费，还留下了「共线时可能算出负数再开方」的隐患。周赛里正确做法是**用叉积，全程整数，最后才除 2**。

### 3.2 核心观察：叉积的绝对值就是面积的两倍

![叉积的绝对值等于三角形面积的两倍](images/wc79_q1_cross_double_area.svg)

设三点 $A(x_1,y_1)$、$B(x_2,y_2)$、$C(x_3,y_3)$，令

$$\vec{u} = B - A = (x_2 - x_1,\; y_2 - y_1), \qquad \vec{v} = C - A = (x_3 - x_1,\; y_3 - y_1)$$

则以 $\vec{u},\vec{v}$ 为邻边的**平行四边形**面积等于二阶行列式的绝对值，而三角形恰好是它沿对角线 $BC$ 切开的一半：

$$2S = \bigl\lvert\, \vec{u} \times \vec{v} \,\bigr\rvert = \bigl\lvert (x_2 - x_1)(y_3 - y_1) - (y_2 - y_1)(x_3 - x_1) \bigr\rvert$$

这个式子带来三个直接好处：

1. **没有根号、没有除法**，$A$ 点平移出去后只需 4 次减法 + 2 次乘法 + 1 次减法。
2. 坐标是整数 ⇒ $2S$ 一定是**整数**（这正是 Pick 定理 $S = I + \frac{B}{2} - 1$ 里那个 $\frac{B}{2}$ 的来源）。
3. 于是可以把「比较面积」完全在整数域完成：只维护 $\max 2S$，最后一次性除以 2，比较过程没有任何精度损失。

再给出一个量的上界：$\lvert x_2 - x_1 \rvert, \lvert y_3 - y_1 \rvert \le 100$，故

$$2S \le 100 \times 100 + 100 \times 100 = 20000$$

$2 \times 10^4$ 远小于 `int` 上限，但代码里仍建议用 `long long`——换个坐标范围（如 $10^9$）就不用回头改。

### 3.3 算法流程

![三重枚举加整数叉积的算法流程](images/wc79_q1_enumeration_flow.svg)

1. `best2 = 0`，表示目前见过的最大两倍面积。
2. 第一层枚举 $i \in [0, n)$；第二层枚举 $j \in [i+1, n)$，立刻缓存 $\text{dx}_{21} = x_j - x_i$、$\text{dy}_{21} = y_j - y_i$（这两个量与第三层无关，必须提到最内层之外）。
3. 第三层枚举 $k \in [j+1, n)$，算

   $$\text{cross} = \text{dx}_{21}\cdot(y_k - y_i) - \text{dy}_{21}\cdot(x_k - x_i)$$

   取 `cross = abs(cross)`，再 `best2 = max(best2, cross)`。
4. 三重循环结束后返回 `best2 / 2.0`。注意是 `/ 2.0` 而不是 `/ 2`，否则整数除法会把 $2S = 1$ 截成 $0$。

下标严格递增（$i < j < k$）还有一个副作用：同一个无序三元组只被访问一次，把有序枚举的 $n(n-1)(n-2)$ 种情况压缩到 $\binom{n}{3}$，只剩原来的 $\frac{1}{6}$。

### 3.4 示例演算

![示例 1 的候选三角形与两倍面积对照](images/wc79_q1_walkthrough.svg)

示例 1 的 5 个点是 $(0,0),(0,1),(1,0),(0,2),(2,0)$，共 $\binom{5}{3} = 10$ 个三元组，节选如下：

| 三元组 | $\text{cross}$ 计算 | $2S$ | 面积 |
|--------|---------------------|------|------|
| $(0,0),(0,1),(1,0)$ | $0\cdot 0 - 1\cdot 1 = -1$ | 1 | 0.5 |
| $(0,0),(0,2),(1,0)$ | $0\cdot 0 - 2\cdot 1 = -2$ | 2 | 1.0 |
| $(0,0),(0,2),(2,0)$ | $0\cdot 0 - 2\cdot 2 = -4$ | **4** | **2.0** |
| $(0,0),(1,0),(2,0)$ | 共线 | 0 | 0.0 |
| $(0,1),(1,0),(2,0)$ | $1\cdot(-1) - (-1)\cdot 2 = 1$ | 1 | 0.5 |

$\max 2S = 4$，返回 $4 / 2.0 = 2.00000$，与示例输出一致。注意第二行 `cross = -2`、第五行 `cross = +1`，符号完全取决于三点的绕向：**必须取绝对值**，否则负的大面积会被 `max` 当成小值丢掉。

## 4. 算法细节

1. **缓存外层公共量**：`dx21, dy21` 只依赖 $i, j$，一定要写在第三层循环外，否则最内层每次多做两次减法。
2. **符号必须消掉**：`cross` 有正负（取决于 $A,B,C$ 的绕向是顺时针还是逆时针），先 `abs` 再取 `max`。偷懒写 `best2 = max(best2, cross)` 会在绕向为负时漏掉正确答案。
3. **整数域比较**：全程只用整数存 $2S$，返回时 `best2 / 2.0`（C++ 也可写 `(double)best2 / 2`）。这样「谁更大」的判断是精确的，浮点只在最后一步出现一次。
4. **初值取 0**：所有点共线时没有任何正面积，`best2` 保持 0，返回 `0.0`，逻辑自然闭合，不需要特判。
5. **`long long` 而非 `int`**：本题 $2S \le 20000$，`int` 也够；但用 `long long` 可让代码对更大的坐标范围（如 $10^9$，此时 $2S$ 可达 $2\times 10^{18}$ 的量级）依然安全，属于零成本的健壮性。
6. **可选的凸包剪枝**：最大面积三角形的三个顶点一定落在点集的**凸包**上，因此可以先求凸包（$h$ 个顶点）再枚举，复杂度降为 $O(h^3)$。$n=50$ 时收益很小，但这是通向 $O(h^2)$ 旋转卡壳的台阶。
7. **可选的提前退出**：若某次 `best2` 已达到凸包面积的两倍（三角形不可能超过凸包），可直接 `break` 全部循环。

## 5. 正确性证明

**引理 1**：对任意三点 $A, B, C$，令 $c = \lvert (x_2-x_1)(y_3-y_1) - (y_2-y_1)(x_3-x_1) \rvert$，则三角形 $ABC$ 的面积 $S = c / 2$。

**证明**：把坐标原点平移到 $A$，则 $B' = \vec{u} = (x_2-x_1,\,y_2-y_1)$，$C' = \vec{v} = (x_3-x_1,\,y_3-y_1)$，平移不改变面积。以 $\vec{u},\vec{v}$ 为邻边的平行四边形（顶点 $0,\vec{u},\vec{u}+\vec{v},\vec{v}$）面积为 $\lvert \det[\vec{u},\vec{v}] \rvert = \lvert u_x v_y - u_y v_x \rvert = c$；对角线 $B'C'$ 把它分成两个全等三角形，故 $S = c/2$。等价地，把鞋带公式

$$2S = \lvert x_1(y_2-y_3) + x_2(y_3-y_1) + x_3(y_1-y_2) \rvert$$

展开也可得到同一表达式。$\qquad\blacksquare$

**引理 2**：三重循环 $0 \le i < j < k < n$ 对每个三点子集恰好执行一次。

**证明**：任取三点子集 $\{p_a, p_b, p_c\}$（下标互异），将其下标升序排列得唯一的三元组 $(i,j,k)$ 且 $i<j<k$；循环按字典序遍历全部严格递增三元组，故该子集被访问且仅被访问一次；反之每个严格递增三元组也唯一对应一个三点子集。$\qquad\blacksquare$

**引理 3**：所有中间量在 64 位整数内不会溢出。

**证明**：由约束 $\lvert x_i \rvert, \lvert y_i \rvert \le 50$，故 $\lvert x_2-x_1 \rvert \le 100$、$\lvert y_3-y_1\rvert \le 100$，每个乘积 $\le 10^4$，$c \le 2\times 10^4 \ll 2^{63}-1$。$\qquad\blacksquare$

**定理**：算法返回的 `best2 / 2.0` 等于所有三点三角形面积的最大值。

**证明**：由引理 2，算法枚举了全部 $\binom{n}{3}$ 个三点子集，对每个子集由引理 1 得到其面积的精确两倍 $c$，并用 `max` 维护最大值（引理 3 保证该过程无溢出、无舍入）。故循环结束时 `best2` $= \max_{\{A,B,C\}} 2S$，除以 2 即得最大面积。浮点除法只引入一次 $< 2^{-52}$ 的相对误差，远小于 $10^{-5}$ 的容差。$\qquad\blacksquare$

## 6. 复杂度分析

- **时间**：三重循环共 $\binom{n}{3} = \frac{n(n-1)(n-2)}{6}$ 次迭代，每次 $O(1)$ 的整数运算，总计 $O(n^3)$。$n = 50$ 时约 $1.96\times 10^4$ 次内层计算，微秒级。若先求凸包（$O(n\log n)$）再枚举，则为 $O(n\log n + h^3)$，$h \le n$。
- **空间**：除输入外只用了 `best2`、三个下标与 `dx21/dy21/cross` 等常数个变量，$O(1)$。输出不需要保存候选三角形。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    double largestTriangleArea(vector<vector<int>>& points) {
        int n = points.size();
        long long best2 = 0;                       // 维护"两倍面积"的最大值，全程整数
        for (int i = 0; i < n; ++i) {
            for (int j = i + 1; j < n; ++j) {
                long long dx21 = points[j][0] - points[i][0];
                long long dy21 = points[j][1] - points[i][1];
                for (int k = j + 1; k < n; ++k) {
                    long long cross = dx21 * (points[k][1] - points[i][1])
                                    - dy21 * (points[k][0] - points[i][0]);
                    if (cross < 0) cross = -cross; // 绕向可能为负，先取绝对值
                    if (cross > best2) best2 = cross;
                }
            }
        }
        return best2 / 2.0;                        // 只有这里出现浮点
    }
};
```

### Python

```python
class Solution:
    def largestTriangleArea(self, points: list[list[int]]) -> float:
        n = len(points)
        best2 = 0
        for i in range(n):
            x1, y1 = points[i]
            for j in range(i + 1, n):
                x2, y2 = points[j]
                dx21, dy21 = x2 - x1, y2 - y1          # 提到最内层之外
                for k in range(j + 1, n):
                    x3, y3 = points[k]
                    cross = dx21 * (y3 - y1) - dy21 * (x3 - x1)
                    if cross < 0:
                        cross = -cross            # 面积非负，符号必须消掉
                    if cross > best2:
                        best2 = cross
        return best2 / 2.0                        # 除以 2.0，不能整除
```

## 8. 边界情况与易错点

1. **整除陷阱**：`return best2 / 2` 在 Python 3 里得到 `float` 没问题，但 C++/Java 中 `int / int` 会截断，$2S = 1$ 时返回 `0` 而不是 `0.5`。必须写 `/ 2.0` 或强转 `double`。
2. **漏取绝对值**：`cross` 的符号由三点绕向决定，$\vec{AB}\to\vec{AC}$ 顺时针时为负。若写成 `best2 = max(best2, cross)`，则绕向为负的那一半三角形永远比不过初值 0，它们的面积被整体丢弃。
3. **全部共线**：题面只保证点互不相同，没有保证不共线。此时所有 `cross = 0`，`best2` 保持 0，返回 `0.0`——`best2` 初值取 0 而非 `INT_MIN` 正是为此。
4. **海伦公式的虚假精度**：$s = (a+b+c)/2$ 与 $s-a$ 都要经过三次开方后的浮点差值，三点接近共线时 $s-a$ 可能被舍入成微负数，`sqrt` 直接返回 `NaN`，随后的 `max` 比较全部失效。整数叉积从根上没有这个问题。
5. **$n=3$ 最小规模**：只有一组三元组，循环自然只跑一次，无需特判；但要确认内层下界是 `j+1` 而不是 `j`，否则会取到同一个点两次。
6. **同一行/列的点**：如示例 1 的 $(0,0),(0,1),(0,2)$ 垂直共线，与某些第三点构成的三角形面积可能为 0，参与 `max` 无副作用，不必跳过。
7. **输出精度**：题目要求误差 $10^{-5}$，`double` 表示 $\le 10^4$ 的半整数精确无误差，任何常规打印格式（`%.5f`）都能过。

**延伸思考**：

1. 最大面积三角形一定以凸包顶点为顶点 ⇒ 若点集来自大规模数据，先求凸包再枚举可以把 $O(n^3)$ 降到 $O(h^3)$。凸包上的最大内接三角形存在 **Dobkin–Snyder** 的 $O(h^2)$ 旋转卡壳算法：固定一个顶点后，最优的另外两点随枚举方向单调移动，用"对踵点"推进，无需重扫。
2. 反过来求**最小面积三角形**（[最小面积矩形](https://leetcode.cn/problems/minimum-area-rectangle/) 的三角形版）要难得多，不存在凸包上的简单单调性，通常只能枚举底边 + 旋转卡壳做凸包切线，$O(h^2)$。
3. 整点三角形满足 Pick 定理 $S = I + \frac{B}{2} - 1$（$I$ 内部整点数，$B$ 边界整点数）。由 $2S$ 为整数可反推 $B$ 的奇偶性，这是许多"整点计数"题的桥梁。本题只需 $\max 2S$，但若题目改问"面积最大的三角形有多少个"，就需要在整数域里精确比较 $\max 2S$ 的出现次数，此时整数实现更是必需。
