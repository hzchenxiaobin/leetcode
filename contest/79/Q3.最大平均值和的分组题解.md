# LeetCode 最大平均值和的分组 题解

## 1. 题目概述

- **标题 / 题号**：最大平均值和的分组（#813，medium）
- **链接**：https://leetcode.cn/problems/largest-sum-of-averages/
- **来源**：LeetCode 第 79 场周赛 Q3
- **难度**：中等
- **标签**：数组、动态规划、前缀和

**题意**：把数组 `nums` 沿元素的间隙切成若干段，段数**至多** $k$ 段，每段都必须非空且连续，所有元素都要被覆盖。一次划分的**分数**定义为各段**平均值之和**，求所有合法划分中最大的分数（与标准答案误差在 $10^{-6}$ 内即可）。

**约束**：

- $1 \le n = \lvert \text{nums} \rvert \le 100$
- $1 \le \text{nums}[i] \le 10^4$
- $1 \le k \le n$

> 💡 `nums[i] >= 1`，即**全部为正数**。这一点让「至多 $k$ 段」可以无损收紧成「恰好 $k$ 段」，是本题状态设计能如此干净的关键，见 3.2 的引理。

## 2. 示例

**示例 1**

```text
输入：nums = [9,1,2,3,9], k = 3
输出：20.00000
解释：最优划分是 [9], [1,2,3], [9] → 9 + (1+2+3)/3 + 9 = 9 + 2 + 9 = 20。
      若划分为 [9,1], [2], [3,9] → 5 + 2 + 6 = 13，明显更差。
```

**示例 2**

```text
输入：nums = [1,2,3,4,5,6,7], k = 4
输出：20.50000
解释：最优划分是 [1,2,3,4], [5], [6], [7] → 10/4 + 5 + 6 + 7 = 2.5 + 18 = 20.5。
      把小数 1~4 打包成一段「垫底」，让大数 5、6、7 各自独占一段，才是最优策略。
```

**示例 3**（边界补充）

```text
输入：nums = [5], k = 1
输出：5.00000
解释：只有一个元素，唯一划分就是它自身，分数即 5。
```

## 3. 解题思路

### 3.1 暴力思路

划分等价于在 $n-1$ 个间隙中选至多 $k-1$ 个切点，方案数为 $\sum_{j=0}^{k-1} \binom{n-1}{j}$。取 $n=100,\ k=50$ 时约 $2^{98}$ 量级，无论怎么剪枝都爆。

但暴力枚举中**子问题高度重叠**：一旦「最后一刀」的位置定了，前面的部分就是一个「把前 $t$ 个数切成 $j-1$ 段」的同构子问题。既然同构，就可以把它的最优值缓存起来 —— 这正是**划分型 DP** 的入口。

### 3.2 核心观察：正数下多切一刀只会更赚

![多切一刀分数不会变差](images/wc79_q3_more_groups_better.svg)

**先看一个具体例子**：段 $A=[9,1]$ 的平均值是 5，单独一段 $B=[2]$ 的平均值是 2，合在一起 $[9,1,2]$ 的平均值是 4。分开算 $5+2=7$，合并算只有 4，**分开比合并多出 3**。

一般地，设 $A,B$ 非空、元素均为正，令 $p=|A|,\ q=|B|,\ a=\text{avg}(A),\ b=\text{avg}(B)$，则

$$\text{avg}(A)+\text{avg}(B)-\text{avg}(A\cup B)=\frac{qa+pb}{p+q}>0$$

因为 $a,b>0$ 且 $p,q\ge 1$，分子必然为正。**结论：只要还能切，切了就更优**。由于 $k\le n$，最多能切出 $n$ 段，所以最优解一定用满 $k$ 段 —— 于是「至多 $k$ 段」和「恰好 $k$ 段」的最优值相同。

> 💡 如果允许 $k>n$，则最优就是每个元素独占一段，答案 = 元素之和；本题约束已排除这种情况，代码里仍可写 `k = min(k, n)` 兜底。

### 3.3 状态转移与算法流程：枚举最后一刀

![dp 状态转移与循环结构](images/wc79_q3_dp_transition_flow.svg)

**状态**：$dp[i][j]$ 表示把前 $i$ 个数（即 `nums[0..i-1]`）切成**恰好** $j$ 段所能得到的最大分数。

**转移**：枚举最后一刀切在 $t$ 处（$j-1 \le t \le i-1$），前 $t$ 个数切成 $j-1$ 段，剩下的 `nums[t..i-1]` 单独成第 $j$ 段：

$$dp[i][j]=\max_{j-1\le t\le i-1}\left(dp[t][j-1]+\frac{pre[i]-pre[t]}{i-t}\right)$$

其中 $pre$ 是前缀和，$pre[i]-pre[t]$ 是尾段元素和，$i-t$ 是尾段长度，两者相除即尾段平均值。

**边界**：$dp[i][1]=pre[i]/i$（整段不分）；$i<j$ 的格子不可能合法，不参与转移。**答案**：$dp[n][k]$。

**循环顺序**：$j$ 从 2 到 $k$（外层），$i$ 从 $j$ 到 $n$（中层），$t$ 从 $j-1$ 到 $i-1$（内层）。算第 $j$ 层时第 $j-1$ 层已全部就绪，故每层只依赖上一层，可用两个一维数组滚动。

### 3.4 示例演算

![nums=[9,1,2,3,9], k=3 的 dp 表](images/wc79_q3_example_walkthrough.svg)

对 `nums = [9,1,2,3,9]`、$k=3$，前缀和为 $pre=[0,9,10,12,15,24]$：

| $i$ ↓ / $j$ → | 1 | 2 | 3 |
|-----------|---|---|---|
| 1 | $9/1=9$ | — | — |
| 2 | $10/2=5$ | $9+1=10$ | — |
| 3 | $12/3=4$ | $\max(9+1.5,\ 5+2)=10.5$ | $10+2=12$ |
| 4 | $15/4=3.75$ | $\max(9+2,\ 5+2.5,\ 4+3)=11$ | $\max(10+2.5,\ 10.5+3)=13.5$ |
| 5 | $24/5=4.8$ | $\max(9+3.75,\dots,3.75+9)=12.75$ | $\max(10+14/3,\ 10.5+6,\ 11+9)=20$ |

最后一行第 3 列给出答案 20，对应的最后一刀是 $t=4$：前 4 个数切成 2 段的最优值是 $dp[4][2]=11$，尾段 $[9]$ 平均值为 9，合计 20，正好还原出示例 1 的划分 `[9],[1,2,3],[9]`。

## 4. 算法细节

1. **前缀和统一用 `double` 存**：C++ 里 `(pre[i] - pre[t]) / (i - t)` 若两边都是 `int` 会做整数除法直接截断，必须保证至少一侧是浮点（用 `vector<double>` 存前缀和，或写 `1.0 *`）。
2. **枚举区间要卡死两端**：下界 $t\ge j-1$（前 $t$ 个数要切成 $j-1$ 个非空段）；上界 $t\le i-1$（尾段长度 $i-t\ge 1$）。少一端都会读到未初始化/非法状态。
3. **$i$ 从 $j$ 开始枚举**：$i<j$ 时不可能切成 $j$ 段非空段，这些格子干脆不填，保证被读到的 $dp[t][j-1]$ 一定合法。
4. **`best` 初值取 0 是安全的**：所有元素为正，任何划分的分数都严格为正，所以从 0 开始取 `max` 不会漏解；若要做通用模板，用 $-\infty$ 更稳。
5. **滚动数组**：$dp[\cdot][j]$ 只依赖 $dp[\cdot][j-1]$，用 `prev`/`cur` 两个长度 $n+1$ 的数组即可把空间从 $O(nk)$ 降到 $O(n)$。本题 $n\le100$ 不必优化，但这是划分型 DP 的通用套路。
6. **答案是 $dp[n][k]$ 而非 $\max_j dp[n][j]$**：靠 3.2 的引理保证「恰好 $k$ 段」不劣于更少段。如果不写这条证明，就必须在最后多扫一遍 $j$ 才安全。
7. **精度**：分子最大 $10^6$、除法后量级 $10^4$，$k\le100$ 次累加的双精度误差约 $10^{-12}$，远小于 $10^{-6}$ 的判定阈值，用 `double` 足够。

## 5. 正确性证明

**引理 1（拆分不减）**：设非空连续段 $C$ 被切成两个非空段 $A,B$，且元素全为正，则 $\text{avg}(A)+\text{avg}(B)>\text{avg}(C)$。

**证明**：记 $p=|A|,q=|B|,a=\text{avg}(A),b=\text{avg}(B)$，则 $\text{avg}(C)=(pa+qb)/(p+q)$。于是

$$\text{avg}(A)+\text{avg}(B)-\text{avg}(C)=\frac{(a+b)(p+q)-(pa+qb)}{p+q}=\frac{qa+pb}{p+q}$$

由 $a,b>0$、$p,q\ge1$ 得分子 $>0$，故差值 $>0$。∎

**引理 2（恰好 $k$ 段最优）**：$k\le n$ 时，存在一个恰好 $k$ 段的最优划分，其分数等于「至多 $k$ 段」的最优分数。

**证明**：任取一个段数 $m<k$ 的划分。因为 $m<k\le n$，$m$ 段中必有一段长度 $\ge2$，于是还能再切一刀，得到 $m+1$ 段的划分。由引理 1，切完分数严格变大，所以 $m$ 段的划分不可能是最优。反复操作可增至恰好 $k$ 段，分数只增不减。故「至多 $k$ 段」的最优解必落在「恰好 $k$ 段」中。∎

**引理 3（最优子结构）**：设某个恰好 $j$ 段的最优划分最后一刀切在 $t$ 处，则其前 $t$ 个元素的划分必是「前 $t$ 个数切成恰好 $j-1$ 段」的最优解。

**证明**：反设前段分数 $S<dp[t][j-1]$，则把前段换成一个分数为 $dp[t][j-1]$ 的划分，尾段不变，整体分数变为 $dp[t][j-1]+\text{avg}(\text{nums}[t..i-1])>S+\text{avg}(\cdot)$，与原划分最优矛盾（段数、连续性、覆盖性都不变）。∎

**定理**：3.3 节的 DP 正确，且 $dp[n][k]$ 等于题目所求的最大分数。

**证明**：对 $j$ 归纳。$j=1$ 时只有「整段不切」一种划分，$dp[i][1]=pre[i]/i$ 正确。设第 $j-1$ 层全部正确，对任意 $i\ge j$，任一恰好 $j$ 段的划分都有唯一的最后一刀位置 $t\in[j-1,i-1]$，其分数为「前段分数」$+\ \text{avg}(\text{nums}[t..i-1])$；由引理 3，前段取 $dp[t][j-1]$ 时不劣。转移对所有可行 $t$ 取最大，故 $dp[i][j]$ 是恰好 $j$ 段的最优值。最后由引理 2，$dp[n][k]$ 即「至多 $k$ 段」的最优值，命题成立。∎

## 6. 复杂度分析

- **时间**：$O(k\,n^2)$。前缀和 $O(n)$；三层循环中 $j$ 有 $k$ 种、$i$ 约 $n$ 种、$t$ 约 $n$ 种，每次转移 $O(1)$。$n\le100,\ k\le n$ 时约 $10^6$ 次运算，非常宽松。
- **空间**：$O(nk)$（$dp$ 表的 $n\times k$ 个双精度数）；用滚动数组可优化到 $O(n)$，前缀和另占 $O(n)$。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    double largestSumOfAverages(vector<int>& nums, int k) {
        int n = nums.size();
        k = min(k, n);                       // 兜底：段数不可能超过 n

        // 前缀和用 double 存，避免整数除法截断
        vector<double> pre(n + 1, 0.0);
        for (int i = 0; i < n; ++i) pre[i + 1] = pre[i] + nums[i];

        // dp[i][j]：前 i 个数切成恰好 j 段的最大分数
        vector<vector<double>> dp(n + 1, vector<double>(k + 1, 0.0));
        for (int i = 1; i <= n; ++i) dp[i][1] = pre[i] / i;   // 整段不分

        for (int j = 2; j <= k; ++j) {
            for (int i = j; i <= n; ++i) {                    // i < j 非法，不填
                double best = 0.0;                            // 分数恒正，取 0 起是安全的
                for (int t = j - 1; t <= i - 1; ++t) {        // 枚举最后一刀
                    double tail = (pre[i] - pre[t]) / (i - t);
                    best = max(best, dp[t][j - 1] + tail);
                }
                dp[i][j] = best;
            }
        }
        return dp[n][k];
    }
};
```

### Python

```python
class Solution:
    def largestSumOfAverages(self, nums: list[int], k: int) -> float:
        n = len(nums)
        k = min(k, n)                                  # 兜底：段数不可能超过 n

        pre = [0.0] * (n + 1)                          # 浮点前缀和，避免整除截断
        for i, v in enumerate(nums):
            pre[i + 1] = pre[i] + v

        # dp[i][j]：前 i 个数切成恰好 j 段的最大分数
        dp = [[0.0] * (k + 1) for _ in range(n + 1)]
        for i in range(1, n + 1):
            dp[i][1] = pre[i] / i                      # 整段不分

        for j in range(2, k + 1):
            for i in range(j, n + 1):                  # i < j 非法，不填
                best = 0.0
                for t in range(j - 1, i):              # 枚举最后一刀
                    tail = (pre[i] - pre[t]) / (i - t)
                    if dp[t][j - 1] + tail > best:
                        best = dp[t][j - 1] + tail
                dp[i][j] = best

        return dp[n][k]
```

## 8. 边界情况与易错点

1. **$k=1$**：不能切，直接返回整段平均值 $pre[n]/n$；此时内层 $j$ 循环不执行，依赖 $dp[i][1]$ 的初始化，别忘了它。
2. **$k=n$**：每个元素独占一段，答案应等于 `sum(nums)`。这也是对拍时最容易命中的强校验点，若输出小于总和说明漏了「恰好多切」的情形。
3. **$n=1$**：唯一划分，答案 $= \text{nums}[0]$。此时 $j$ 循环一次都不执行，结果完全依赖 $dp[1][1]$ 的初始化；若把初始化写成从下标 0 起算，就会返回 0。
4. **整数除法陷阱**：C++ 中 `(pre[i]-pre[t])/(i-t)` 若用 `int` 前缀和，会得到截断后的整数，示例 1 可能刚好碰巧对、示例 2 立刻错。一律用 `double`。
5. **「至多」误读成「恰好」时不要想当然**：本题的等价性来自元素全正；若题目允许 $0$ 或负数，引理 1 不成立，必须改成 $\max_{j\le k} dp[n][j]$ 才安全。
6. **浮点输出**：返回 `double`/`float` 值本身，不要自己格式化或四舍五入到固定小数位，判题器按 $10^{-6}$ 误差比较；C++ 用 `printf("%.5f")` 只适合本地打印。
7. **非法状态参与取 max**：如果为了省事把 $i<j$ 的格子填 0 后仍允许 $t$ 取到它们，会得到「凭空多出几段」的假高分，必须用左侧边界 $t\ge j-1$ 挡住。
