# LeetCode 变换二进制字符串的最少操作次数 题解

## 1. 题目概述

- **标题 / 题号**：变换二进制字符串的最少操作次数（#3980，medium）
- **链接**：https://leetcode.cn/problems/minimum-operations-to-transform-binary-string/
- **来源**：LeetCode 第 186 场双周赛 Q3
- **难度**：中等
- **标签**：贪心、字符串、动态规划、计数

**题意**：给定两个长度均为 $n$ 的二进制串 `s1`、`s2`。可以对 `s1` 反复执行两类操作：

1. **操作 1**：选一个满足 `s1[i] == '0'` 的下标 $i$，把它改成 `'1'`；
2. **操作 2**：选一个 $i$（$0 \le i < n-1$）且 `s1[i] == s1[i+1] == '1'`，把这两位同时改成 `'0'`。

求把 `s1` 变成 `s2` 的**最少操作次数**；无法做到时返回 $-1$。

**约束**：

- $1 \le n \le 10^5$
- 两串只含 `'0'` 与 `'1'`

## 2. 示例

**示例 1**

```text
输入：s1 = "11", s2 = "00"
输出：1
解释：对下标 0、1 做一次操作 2，"11" → "00"。
```

**示例 2**

```text
输入：s1 = "01", s2 = "10"
输出：3
解释：@0 用操作1 → "11"；@(0,1) 用操作2 → "00"；@0 用操作1 → "10"。
```

**示例 3**

```text
输入：s1 = "1", s2 = "0"
输出：-1
解释：n=1 时只有 1 个字符，既不能用操作1（当前是 1），也没有相邻对可用操作2。
```

## 3. 解题思路

### 3.1 暴力思路

把 `s1` 的位串当作状态，做 BFS 求最短路：每个状态有 $O(n)$ 种操作，状态总数 $2^n$。$n \le 10$ 时可行，可以用来**对拍验证**；$n = 10^5$ 时状态空间是天文数字，只能找结构性质。

观察操作的「方向性」：

- 操作 1 只能把 $0 \to 1$，所以**凭空造出 `1` 唯一的手段就是操作 1**；
- 操作 2 只能把 $1 \to 0$，所以**消掉 `1` 唯一的手段就是操作 2**，且必须成对相邻。

这两句话几乎把问题定死了：`1` 的「生」靠操作 1、`1` 的「死」靠操作 2。

### 3.2 核心观察：一个恒等式把代价压成单变量

![A 段（1→0 错位）的分段与 K 的计数](images/bw186_q3_runs.svg)

设整个方案用了 $M$ 次操作 1、$K$ 次操作 2，记 $\textit{ones}(x)$ 为串 $x$ 中 `1` 的个数。由于操作 1 恰使 `1` 的个数 $+1$、操作 2 恰使 `1` 的个数 $-2$，整个过程的「净变化」必须等于终态减初态：

$$\textit{ones}(s2) - \textit{ones}(s1) = M - 2K$$

于是 $M$ 被 $K$ 完全确定：

$$M = 2K + \Delta,\qquad \Delta = \textit{ones}(s2) - \textit{ones}(s1)$$

$$\textbf{总代价} = M + K = 3K + \Delta$$

$\Delta$ 是常数，所以**最小化总代价等价于最小化操作 2 的次数 $K$**。这把「两种操作权衡」的双变量优化，化简成了单变量问题。

接下来只看**必须被消掉的位置**：

$$A = \{\, i \mid s1[i] = 1,\ s2[i] = 0 \,\}$$

这些位置起于 `1`、终于 `0`，而只有操作 2 能实现 $1 \to 0$，故 $A$ 中每个位置都必须被至少一次操作 2 覆盖。把 $A$ 按**下标连续**分段，设某段长度为 $L$：

- 段内一次操作 2 最多覆盖该段的 $2$ 个位置；
- 若 $L$ 为奇数，段内两两配对后必剩一个位置，只能靠一条**跨出段边界**的操作 2 覆盖（它只贡献 $1$ 个本段内位置）。

故该段至少需要 $\lceil L/2 \rceil$ 次操作 2；不同段之间无法共用操作 2（两段之间至少隔着一个非 $A$ 位置，而一次操作 2 只作用于相邻两格）。因此

$$K_{\min} = \sum_{\text{A 段}} \left\lceil \frac{L}{2} \right\rceil$$

### 3.3 算法流程

![恒等式与 K 的化简](images/bw186_q3_identity.svg)

```text
1. delta = ones(s2) - ones(s1)
2. if n == 1:
3.     return s1 == s2 ? 0 : (s1 == "0" ? 1 : -1)
4. K = 0;  i = 0
5. while i < n:
6.     if s1[i] == '1' and s2[i] == '0':
7.         j = i
8.         while j+1 < n and s1[j+1] == '1' and s2[j+1] == '0':  j += 1
9.         L = j - i + 1
10.        K += (L + 1) // 2
11.        i = j + 1
12.    else:  i += 1
13. return 3*K + delta
```

时间复杂度 $O(n)$，额外空间 $O(1)$。

### 3.4 示例演算

**示例 1**：`s1 = "11"`，`s2 = "00"`。$\Delta = -2$，$A = \{0,1\}$，一段 $L = 2$，$K = \lceil 2/2 \rceil = 1$，答案 $= 3 \times 1 - 2 = 1$。

**示例 2**：`s1 = "01"`，`s2 = "10"`。$\textit{ones}(s1) = \textit{ones}(s2) = 1$，故 $\Delta = 0$。$A = \{1\}$，一段 $L = 1$，$K = \lceil 1/2 \rceil = 1$，答案 $= 3 \times 1 + 0 = 3$。

![示例 2 的三步操作](images/bw186_q3_example.svg)

三步依次是：`01 → 11`（操作 1 @0，为 A 位置「借」来一个相邻的 `1`）、`11 → 00`（操作 2 @(0,1)）、`00 → 10`（操作 1 @0，把邻居恢复成 `1`）。

**示例 3**：`n = 1`，`s1 = "1"`，`s2 = "0"`：$A = \{0\}$ 需要操作 2，但没有任何相邻对可用，答案 $-1$。

再看一个进阶例子：`s1 = "111"`，`s2 = "000"`。$A = \{0,1,2\}$，$L = 3$，$K = 2$，$\Delta = -3$，答案 $= 6 - 3 = 3$。具体是：操作 2 @(0,1) → `001`；操作 1 @1 → `011`；操作 2 @(1,2) → `000`。可以看到位置 1 被「清了又建」，这正是奇数段跨界借邻居的代价。

## 4. 算法细节

1. **$\Delta$ 与 $K$ 分开算**：$\Delta$ 可以一遍 `count` 得到，$K$ 需要扫描 $A$ 段，二者独立。
2. **`(L + 1) // 2` 即上取整**：C++ 写成 `(L + 1) / 2`，注意 `L` 是 `int` 时没有精度问题。
3. **$n = 1$ 必须特判**：长度为 1 时不存在任何相邻对，操作 2 完全不可用，只能判断 $0 \to 1$（需 1 次）与 $1 \to 1$（0 次）两种情形。
4. **只需要 $A$ 段，不需要 $B$ 段**：$B = \{i \mid s1[i]=0, s2[i]=1\}$ 中每个位置用一次操作 1 即可，其代价已经隐含在恒等式中，不需要单独相加。
5. **不要真的模拟**：模拟每一步的串会退化成 $O(n^2)$；本题只需两遍扫描。
6. **返回值可能为负？** 不会：$K \ge \lceil |A|/2 \rceil$，而 $\Delta = |B| - |A|$，故 $3K + \Delta \ge 3\lceil |A|/2\rceil - |A| + |B| \ge 0$。

## 5. 正确性证明

**引理 1（恒等式）**：任何可行方案都用 $M = 2K + \Delta$ 次操作 1，总代价恰为 $3K + \Delta$，其中 $K$ 为其操作 2 的次数。

**证明**：操作 1 使 `1` 的个数增加 $1$，操作 2 使其减少 $2$，中间没有其他改变手段，故终态 `1` 的个数 $\textit{ones}(s2) = \textit{ones}(s1) + M - 2K$，移项即 $M = 2K + \Delta$；总代价 $M + K = 3K + \Delta$。∎

**引理 2（$K$ 的下界）**：任何可行方案的操作 2 次数 $K \ge \sum_{\text{A 段}} \lceil L/2\rceil$。

**证明**：$A$ 中每个位置起点为 `1`、终点为 `0`，而唯一能把 `1` 变 `0` 的操作是操作 2，故每个 $A$ 位置至少被一次操作 2 覆盖（覆盖次数为奇数）。任取一条 $A$ 段，设 $c$ 为两次端点都落在段内的操作 2 次数、$b$ 为恰有一个端点落在段内的次数，则段内被覆盖的「位置次数」为 $2c + b \ge L$。该段被使用的操作 2 次数为 $c + b \ge c + (L - 2c) = L - c \ge L - \lfloor L/2\rfloor = \lceil L/2\rceil$。又因两个不同 $A$ 段之间至少隔着一个非 $A$ 位置，一条操作 2 的相邻两端不可能同时落在两个不同的段里，故不同段消耗的操作 2 互不重叠，求和后 $K \ge \sum \lceil L/2\rceil$。∎

**引理 3（$K$ 的下界可达）**：存在可行方案，其操作 2 次数恰为 $\sum_{\text{A 段}}\lceil L/2\rceil$（$n \ge 2$）。

**证明**：给出构造。

1. 对每条长度为偶数 $L$ 的 $A$ 段，把段内位置从左到右两两配对 $(p_1,p_2),(p_3,p_4),\dots$，每对做一次操作 2。配对时两个位置当前都还是初始的 `1`（配对过程互不影响），操作合法，共用 $L/2$ 次。
2. 对长度为奇数 $L$ 的 $A$ 段，先对前 $L-1$ 个位置两两配对（同上，$(L-1)/2$ 次）；剩下的位置 $q$ 取相邻位置 $p$：若 $q+1 < n$ 取 $p = q+1$，否则取 $p = q-1$（$n \ge 2$ 保证 $p$ 存在）。若此时 $p$ 的当前值为 `0`，用一次操作 1 把它置 `1`；再对 $(q,p)$ 做一次操作 2，$q$ 被清成 `0`（正是 $s2[q]$ 要求的）。若 $s2[p] = 1$，再补一次操作 1 把 $p$ 恢复为 `1`。
3. 最后处理未被清掉的 $B$ 位置（$s1[i]=0,s2[i]=1$）：它们当前都是 `0`，各用一次操作 1 置 `1`。

第 2 步中「$p$ 在段内」的情况（奇数段恰好覆盖整个串，如 `111`）同样可行：$p$ 已在第 1 步被清成 `0`，用操作 1 重新置 `1` 后再配对即可。三步合计使用的操作 2 次数正是 $\sum\lceil L/2\rceil$，且序列中每个操作都满足前置条件（操作 2 作用时两端皆 `1`，操作 1 作用时该位皆 `0`），终态与 $s2$ 逐位一致。∎

**定理**：算法返回值等于最少操作次数；无法完成时返回 $-1$。

**证明**：由引理 1，总代价 $= 3K + \Delta$ 是任意方案的固定形式，故最优方案必取 $K_{\min}$，代价为 $3K_{\min} + \Delta$。由引理 2 得 $K \ge \sum\lceil L/2\rceil$，由引理 3 该下界可达，故 $K_{\min} = \sum\lceil L/2\rceil$，算法返回的 $3K + \Delta$ 即最优代价。

唯一不可行情形是 $n = 1$ 且 $s1 = "1"$、$s2 = "0"$：此时 $A = \{0\}$ 需要操作 2，但不存在相邻对，$-1$。其余情形由引理 3 的构造保证可行。∎

## 6. 复杂度分析

- **时间**：$O(n)$。统计 $\textit{ones}$ 两遍 $O(n)$；扫描 $A$ 段时 `i` 严格递增、内层 `j` 只前进不回头，整体 $O(n)$。
- **空间**：$O(1)$。只用常数个计数器（不需要额外数组，也不需要对 $s$ 做拷贝）。

## 7. 参考代码

### C++

```cpp
#include <string>

using namespace std;

class Solution {
public:
    int minOperations(string s1, string s2) {
        int n = (int)s1.size();
        int ones1 = 0, ones2 = 0;
        for (int i = 0; i < n; i++) {
            ones1 += (s1[i] == '1');
            ones2 += (s2[i] == '1');
        }
        int delta = ones2 - ones1;
        if (n == 1) {
            if (delta == 0) return 0;
            return s1[0] == '0' ? 1 : -1;
        }
        long long K = 0;
        int i = 0;
        while (i < n) {
            if (s1[i] == '1' && s2[i] == '0') {
                int j = i;
                while (j + 1 < n && s1[j + 1] == '1' && s2[j + 1] == '0') {
                    j++;
                }
                int L = j - i + 1;
                K += (L + 1) / 2;
                i = j + 1;
            } else {
                i++;
            }
        }
        return (int)(3 * K + delta);
    }
};
```

### Python

```python
class Solution:
    def minOperations(self, s1: str, s2: str) -> int:
        n = len(s1)
        ones1 = s1.count('1')
        ones2 = s2.count('1')
        delta = ones2 - ones1
        if n == 1:
            return 0 if delta == 0 else (1 if s1[0] == '0' else -1)
        K = 0
        i = 0
        while i < n:
            if s1[i] == '1' and s2[i] == '0':
                j = i
                while j + 1 < n and s1[j + 1] == '1' and s2[j + 1] == '0':
                    j += 1
                L = j - i + 1
                K += (L + 1) // 2
                i = j + 1
            else:
                i += 1
        return 3 * K + delta
```

## 8. 边界情况与易错点

1. **$n = 1$ 且 `s1 = "1"`、`s2 = "0"`**：唯一的不可行情形，必须返回 $-1$；漏掉会返回 $2$（$3 \times 1 - 1$）。
2. **$n = 1$ 且 `s1 = "0"`、`s2 = "1"`**：用一次操作 1，答案 $1$；公式也给 $3 \times 0 + 1 = 1$，一致。
3. **`s1 == s2`**：$A$ 为空，$K = 0$，$\Delta = 0$，返回 $0$，正确。
4. **全 `1` → 全 `0`**：$A$ 是整串一段，$L = n$，$K = \lceil n/2 \rceil$，$\Delta = -n$。$n = 3$ 时答案为 $3$（不是直觉上的 $2$ 或 $4$），可用 BFS 验证。
5. **把「A 段」写成「所有错位位置」**：$B$ 位置（$0 \to 1$）不需要操作 2，混进去会系统性高估 $K$。
6. **忘记恒等式的 $\Delta$**：只用 $3K$ 会漏掉「造 `1`」的成本，示例 2 会错算成 $3$（碰巧对）而 `s1="000", s2="111"` 会错算成 $0$（正确应为 $3$：三处各用一次操作 1）。
7. **用模拟代替公式**：逐步模拟会 $O(n^2)$；本题必须利用「操作 2 只与 $A$ 段长度有关」的结构。
8. **越界**：奇数段借邻居时，若 $q = n-1$ 要改借 $q-1$；构造证明里用到这一点，而算法本身只统计 $L$，不受影响。
