# LeetCode 唯一中间元素 题解

## 1. 题目概述

- **标题 / 题号**：唯一中间元素（#3978，easy）
- **链接**：https://leetcode.cn/problems/unique-middle-element/
- **来源**：LeetCode 第 186 场双周赛 Q1
- **难度**：简单
- **标签**：数组、计数

**题意**：给定长度为奇数 $n$ 的整数数组 `nums`，取**下标中间**的元素 `nums[n/2]`（注意是下标中点，不是中位数）。若该值在数组中**恰好出现一次**则返回 `true`，否则返回 `false`。

**约束**：

- $1 \le n = \textit{nums.length} \le 100$，且 $n$ 为奇数
- $1 \le \textit{nums}[i] \le 100$

## 2. 示例

**示例 1**

```text
输入：nums = [1,2,3]
输出：true
解释：中间元素是 nums[1] = 2，只出现一次。
```

**示例 2**

```text
输入：nums = [1,2,2]
输出：false
解释：中间元素是 nums[1] = 2，出现了两次。
```

**示例 3**

```text
输入：nums = [4,1,1,1,9]
输出：false
解释：中间元素是 nums[2] = 1，出现了三次，仍不满足「恰好一次」。
```

## 3. 解题思路

### 3.1 暴力思路

最容易写错的地方不是算法，而是**下标的定义**。先确认三件事：

1. 「中间元素」= `nums[n/2]`（$n$ 为奇数时下标中点唯一）；
2. 要统计的是**这个值**在整个数组里出现的次数，而不是「其他值有没有等于它」这类变形；
3. 判定是「恰好一次」，出现 $2$ 次、$3$ 次都不行。

在这个前提下，暴力与最优解没有复杂度差异：都至少要扫一遍数组，$O(n)$ 已是下界。

### 3.2 核心观察：只需要一个计数器

![三组数组：高亮中间下标，统计该值出现次数](images/bw186_q1_middle.svg)

由于 $n$ 为奇数，$n/2$ 恰好指向正中那个下标，无需考虑「左中还是右中」。取到 `mid = nums[n/2]` 之后，问题退化成**一次线性计数**：

$$\text{answer} = \big[\ \#\{i : \textit{nums}[i] = \textit{mid}\} = 1\ \big]$$

值域只有 $100$，也可以开桶计数或提前退出，但都没有必要——$n \le 100$，一遍扫描足够快，也更不容易写错。

### 3.3 算法流程

![算法流程：取中点值 → 计数 → 判等](images/bw186_q1_flow.svg)

```text
1. mid = nums[len(nums) // 2]
2. cnt = 0
3. for x in nums:  if x == mid:  cnt += 1
4. return cnt == 1
```

### 3.4 示例演算

| 数组 | $n$ | 中间下标 | 中间值 | 该值出现次数 | 结果 |
|------|-----|---------|--------|------------|------|
| `[1,2,3]` | 3 | 1 | 2 | 1 | `true` |
| `[1,2,2]` | 3 | 1 | 2 | 2 | `false` |
| `[4,1,1,1,9]` | 5 | 2 | 1 | 3 | `false` |

注意第三行：中间值是 $1$，虽然它「唯一地占据中间位置」，但在数组中出现了三次，因此仍返回 `false`。这是本题最容易踩的坑——**「中间元素」只决定比较的是哪个值，判定用的仍是全数组的计数**。

## 4. 算法细节

1. **整除语义**：Python 的 `//` 与 C++ 的 `/` 对非负整数都是向下取整，`n/2` 在 $n$ 为奇数时即「正中间」；不需要 `(n-1)/2` 之类的变体。
2. **`mid` 只取一次**：先取下标再比较，避免在循环里重复算 `nums[len(nums)//2]`，也让代码意图更清楚。
3. **计数提前退出**：一旦 `cnt > 1` 就可以返回 `false`；本题规模下属于可选优化。
4. **不要排序**：排序后取中位数是**另一道题**（中位数一定会出现 $\ge 1$ 次，但本题问的是「下标中点」），混淆两者会得到完全不同的答案。
5. **`bool` 返回**：C++ 直接 `return cnt == 1;`，Python 返回 `cnt == 1` 的布尔值而非 `1/0`。

## 5. 正确性证明

**引理 1（中间下标唯一）**：$n$ 为奇数时，满足「左侧元素个数等于右侧元素个数」的下标唯一，且等于 $n/2$（整数除法）。

**证明**：设下标为 $k$，左右个数相等即 $k = n - 1 - k$，解得 $k = (n-1)/2$。因 $n$ 为奇数，$n - 1$ 为偶数，$(n-1)/2 = \lfloor n/2 \rfloor$。唯一性由方程唯一解给出。∎

**引理 2（计数正确）**：算法中的 `cnt` 等于 `nums` 中等于 `mid` 的元素个数。

**证明**：循环遍历 `nums` 的每个元素恰好一次，每当元素等于 `mid` 时 `cnt` 加一，否则不变。由计数原理，循环结束后 `cnt` 即为满足 `nums[i] == mid` 的下标个数。∎

**定理**：算法返回 `true` 当且仅当 `nums` 的下标中间元素在数组中恰好出现一次。

**证明**：由引理 1，`mid = nums[n/2]` 正是下标中间元素；由引理 2，`cnt` 是该值的出现次数；返回值为 `cnt == 1`，即「恰好出现一次」。两方向均为等价变形，故充要成立。∎

## 6. 复杂度分析

- **时间**：$O(n)$。取下标 $O(1)$，一次线性扫描 $O(n)$，比较 $O(1)$。
- **空间**：$O(1)$。只用了 `mid` 与 `cnt` 两个标量；（若改成桶计数则是 $O(V)$，$V \le 100$）。

## 7. 参考代码

### C++

```cpp
#include <vector>

using namespace std;

class Solution {
public:
    bool isMiddleElementUnique(vector<int>& nums) {
        int n = (int)nums.size();
        int mid = nums[n / 2];
        int cnt = 0;
        for (int x : nums) {
            if (x == mid) {
                cnt++;
            }
        }
        return cnt == 1;
    }
};
```

### Python

```python
from typing import List

class Solution:
    def isMiddleElementUnique(self, nums: List[int]) -> bool:
        mid = nums[len(nums) // 2]
        return sum(1 for x in nums if x == mid) == 1
```

## 8. 边界情况与易错点

1. **$n = 1$**：中点就是唯一元素 `nums[0]`，它必然出现一次，返回 `true`。不要因为「长度太短」而返回 `false`。
2. **「恰好一次」不是「至少一次」**：出现 $3$ 次同样返回 `false`（示例 3）。
3. **下标中点 ≠ 中位数**：`[1,1,9]` 的下标中点是 $1$（出现两次 → `false`），而中位数是 $1$；`[1,2,2]` 的下标中点也是 $2$。两者在本例中数值相同纯属巧合，逻辑上不能互换。
4. **$n$ 一定为奇数**：题目保证，所以不用处理「偶数长度的两个中点」。
5. **重复元素不影响下标**：即使 `mid` 值在别处也出现，中间位置依旧是 `n/2`，与值无关。
6. **返回值类型**：Python 要返回 `bool`，`sum(...) == 1` 已经是布尔值；若写成 `return 1 if ... else 0` 在类型检查上可能被拒。
