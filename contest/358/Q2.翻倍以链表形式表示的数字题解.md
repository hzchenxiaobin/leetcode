# LeetCode 翻倍以链表形式表示的数字 题解

## 1. 题目概述

- **标题 / 题号**：翻倍以链表形式表示的数字（#2816，medium）
- **链接**：https://leetcode.cn/problems/double-a-number-represented-as-a-linked-list/
- **来源**：LeetCode 第 358 场周赛 Q2
- **难度**：中等
- **标签**：栈、链表、数学

**题意**：给你一个**非空**链表的头节点 `head`，它表示一个**不含前导零**的非负整数，每位数字**正序存储**（头节点是最高位）。将该整数**翻倍**，返回表示结果的头节点。

**约束**：

- 链表中节点的数目在范围 $[1, 10^4]$ 内
- $0 \le \text{Node.val} \le 9$
- 输入满足：链表表示一个不含前导零的数字，除了数字 $0$ 本身

> 💡 本题是 [2. 两数相加](https://leetcode.cn/problems/add-two-numbers/) 的「方向反转」版：第 2 题**逆序**存储（头 = 个位），加法进位方向与遍历方向天然一致；本题**正序**存储（头 = 最高位），进位要从个位（尾部）传向最高位（头部），**与遍历方向相反**。破题点就是如何「从低位开始处理」。

## 2. 示例

**示例 1**

```text
输入：head = [1,8,9]
输出：[3,7,8]
解释：链表表示数字 189，翻倍后 189 × 2 = 378，返回链表 3 → 7 → 8。
```

**示例 2**

```text
输入：head = [9,9,9]
输出：[1,9,9,8]
解释：链表表示数字 999，翻倍后 999 × 2 = 1998，返回链表 1 → 9 → 9 → 8。
```

**补充示例 3**

```text
输入：head = [0]
输出：[0]
解释：数字 0 是唯一允许「前导零」的输入，翻倍后仍为 0。

输入：head = [5]
输出：[1,0]
解释：5 × 2 = 10，最高位翻倍产生进位，需要前插节点 1。
```

## 3. 解题思路

### 3.1 暴力思路：还原成整数再翻倍（溢出）

最直接的想法：遍历链表把整数还原出来 `num = num × 10 + val`，执行 `num *= 2`，再逐位拆回链表。

> ⚠️ 致命缺陷：链表最长 $10^4$ 位，而 `int64` 只能精确表示约 19 位十进制数，C++ / Java 必然溢出。Python 大整数虽不溢出，但「链表 → 整数 → 链表」的两趟转换完全没有利用链表结构，也偏离了题目考察意图。正确做法是**直接在链表上模拟竖式乘法**。

### 3.2 核心观察：反转链表，对齐个位

竖式乘法的规则：**从最低位（个位）开始逐位计算，进位向高位传递**。本题链表正序存储，个位在**尾部**——从头遍历的方向与进位传播的方向恰好相反。

**破题关键**：把链表**反转一次**，头节点变成个位，遍历方向就与进位方向一致了。此时逐位执行 $v = \text{val} \times 2 + \text{carry}$，写 $v \bmod 10$、进 $\lfloor v/10 \rfloor$，与第 2 题的逐位加法完全同构。处理完再反转回来，恢复正序。

![核心观察：反转一次，让个位站到队首](images/double_it_reverse_concept.svg)

以示例 1 `[1,8,9]`（189）走一遍：

1. 反转得 `[9,8,1]`，头是个位 9；
2. 个位 $9 \times 2 = 18$，写 8 进 1；
3. 十位 $8 \times 2 + 1 = 17$，写 7 进 1；
4. 百位 $1 \times 2 + 1 = 3$，写 3 进 0；
5. 反转回来得 `[3,7,8]`，即 378 ✓。

> 💡 **进位界的红利**：每位 $\text{val} \in [0,9]$，翻倍至多 $18$，加低位进位至多 $19$，故**进位只取 0 或 1**。这意味着最高位若仍溢出进位，前插一个值为 1 的节点即可，不存在更复杂的情况。

### 3.3 算法流程

![算法流程：反转、逐位翻倍、反转回来、处理进位](images/double_it_algorithm_flow.svg)

**完整步骤**：

1. **反转链表**：`rev = reverse(head)`，头节点变为个位；
2. **逐位翻倍**：`carry = 0`，从 `rev` 开始遍历每个节点：$v = \text{cur.val} \times 2 + \text{carry}$，写 `cur.val = v % 10`，更新 `carry = v / 10`；
3. **反转回来**：`head = reverse(rev)`，恢复正序；
4. **处理最高位进位**：若 `carry == 1`，返回 `ListNode(1, head)`；否则返回 `head`。

> ⚠️ 第 3、4 步的顺序不能反：必须**先**反转回正序，**再**在头部前插新节点。若先把节点接到反转表的尾部再反转，逻辑虽然等价，但边界更容易写错（见 §8 第 4 条）。

### 3.4 示例演算

以示例 2 `[9,9,9]`（999）为例。它是回文，反转后仍是 `[9,9,9]`，从个位（头）开始逐位翻倍：

![示例演算：999 逐位翻倍与进位传播](images/double_it_example_walkthrough.svg)

| 步骤 | 当前位 | carry（入） | $v = \text{位} \times 2 + \text{carry}$ | 写值 | carry（出） |
|------|--------|------------|------------------------------------------|------|------------|
| ① 个位 | 9 | 0 | $9 \times 2 + 0 = 18$ | 8 | 1 |
| ② 十位 | 9 | 1 | $9 \times 2 + 1 = 19$ | 9 | 1 |
| ③ 最高位 | 9 | 1 | $9 \times 2 + 1 = 19$ | 9 | 1 |
| 收尾 | — | 1 | 无更高位可写 | 前插 1 | — |

翻倍后反转表为 `[8,9,9]`，反转回来是 `[9,9,8]`，收尾 `carry == 1` 前插节点 1，得 `[1,9,9,8]` = 1998 ✓。

> 💡 三位全是 9 是**进位链最长**的最坏情况：每一位都向前进 1，且最高位的进位在循环里无处可写——「循环外单独处理 `carry`」必须覆盖这一边界。

## 4. 算法细节

1. **反转模板**：`reverse` 即 [206. 反转链表](https://leetcode.cn/problems/reverse-linked-list/) 的三指针迭代版（`prev / cur / nxt`），原地 $O(1)$ 空间，是本题唯一用到的「链表基本功」。
2. **翻倍只改值不动结构**：循环体内只写 `cur.val`，不增删节点；新节点只在收尾前插时才可能创建一个。
3. **进位推导**：设当前位原值 $a$、入进位 $c \in \{0,1\}$，则 $v = 2a + c \le 19$，写值 $v \bmod 10$、出进位 $\lfloor v/10 \rfloor \in \{0,1\}$——进位界在归纳下自保持（见 §5 引理 1）。
4. **收尾前插**：`carry == 1` 时执行 `new ListNode(1, head)`。节点值直接写常量 1 而不是 `carry` 也成立，因为进位界保证了它只能是 1。
5. **同构迁移**：把「×2」换成任意单操作数逐位运算（+1、×3、叠加另一个链表数），第 1、3 步不变，只换第 2 步的运算式——这是 445 / 369 一类「正序链表逐位运算」题的通用骨架。

## 5. 正确性证明

**引理 1（进位界）**：翻倍循环中，每轮开始时 $\text{carry} \in \{0, 1\}$。

**证明**：对循环轮数归纳。初始 `carry = 0` 成立。设某轮开始时 $\text{carry} \in \{0,1\}$，该轮 $v = 2 \cdot \text{val} + \text{carry} \le 2 \times 9 + 1 = 19$，故更新后 $\text{carry} = \lfloor v/10 \rfloor \le 1$ 且非负，仍属于 $\{0,1\}$。∎

**引理 2（反转对齐低位）**：设原链表从 `head` 起依次为 $a_{m-1}, a_{m-2}, \ldots, a_0$（即 $X = \sum_{i=0}^{m-1} a_i 10^i$），则反转后从左到右依次为 $a_0, a_1, \ldots, a_{m-1}$——恰是 $X$ 从个位到最高位的排列。

**证明**：反转只改变指针方向，节点集合不变、被遍历的次序完全倒置，值序列逐位倒序。∎

**引理 3（翻倍循环 = 竖式乘法）**：记 $c_0 = 0$。翻倍循环处理第 $k$ 个节点（值为 $a_k$）时读到的仍是原值，处理后该节点值为 $b_k = (2a_k + c_k) \bmod 10$，离开时的进位为 $c_{k+1} = \lfloor (2a_k + c_k)/10 \rfloor$。则循环结束后

$$2X \;=\; \sum_{k=0}^{m-1} b_k \, 10^k \;+\; c_m \, 10^m .$$

**证明**：循环体即递推式 $2a_k + c_k = b_k + 10 c_{k+1}$ 的直接翻译。对该式两边乘 $10^k$ 并对 $k = 0, \ldots, m-1$ 求和：

$$2X = \sum_{k=0}^{m-1} 2a_k 10^k = \sum_{k=0}^{m-1} b_k 10^k + \sum_{k=1}^{m} c_k 10^k - \sum_{k=0}^{m-1} c_k 10^k = \sum_{k=0}^{m-1} b_k 10^k + c_m 10^m,$$

最后一步用了 $c_0 = 0$（两个进位和式相消）。∎

**定理**：算法返回链表表示的整数恰为 $2X$，且除 $X = 0$ 外不含前导零。

**证明**：**数值**：由引理 2，翻倍后的反转表表示 $\sum_{k=0}^{m-1} b_k 10^k = 2X - c_m 10^m$；再反转回来不改数值。若 $c_m = 0$，即得 $2X$；若 $c_m = 1$（引理 1 排除其它值），前插节点 1 恰在最高位贡献 $10^m$，总和为 $2X$。**前导零**：若 $X \ge 1$，输入无前导零保证 $a_{m-1} \ge 1$；当 $c_m = 1$ 时新最高位为 1；当 $c_m = 0$ 时 $2a_{m-1} + c_{m-1} \le 9$（否则会产生 $c_m$），故最高位 $b_{m-1} = 2a_{m-1} + c_{m-1} \ge 2$。两种情况最高位均非零。若 $X = 0$，链表为 `[0]`，翻倍后仍 `[0]`，即 $2 \times 0 = 0$，是题意允许的唯一表示。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$，$n$ 为链表长度（$\le 10^4$）。两次反转 + 一趟翻倍，共 3 趟线性扫描。
- **空间复杂度**：$O(1)$。反转为原地指针操作，全程只用 `carry / cur / prev` 等常数个变量，不计返回链表本身。相比之下，用**栈**暂存节点或用**递归**回溯都需要 $O(n)$ 额外空间，递归还有 $10^4$ 深度的爆栈风险。

## 7. 参考代码

### C++

```cpp
class Solution {
    ListNode* reverse(ListNode* h) {          // 206. 反转链表 三指针模板
        ListNode* prev = nullptr;
        while (h) {
            ListNode* nxt = h->next;
            h->next = prev;
            prev = h;
            h = nxt;
        }
        return prev;
    }

public:
    ListNode* doubleIt(ListNode* head) {
        ListNode* rev = reverse(head);        // ① 反转：头变个位
        int carry = 0;
        for (ListNode* cur = rev; cur; cur = cur->next) {
            int v = cur->val * 2 + carry;     // ② 逐位翻倍
            cur->val = v % 10;
            carry = v / 10;
        }
        head = reverse(rev);                  // ③ 反转回正序
        if (carry) {                          // ④ 最高位仍有进位，前插 1
            return new ListNode(1, head);
        }
        return head;
    }
};
```

### Python

```python
class Solution:
    def doubleIt(self, head: Optional[ListNode]) -> Optional[ListNode]:
        def reverse(h: Optional[ListNode]) -> Optional[ListNode]:
            prev = None
            while h:
                h.next, prev, h = prev, h, h.next
            return prev

        rev = reverse(head)                   # ① 反转：头变个位
        carry = 0
        cur = rev
        while cur:
            v = cur.val * 2 + carry           # ② 逐位翻倍
            cur.val = v % 10
            carry = v // 10
            cur = cur.next
        head = reverse(rev)                   # ③ 反转回正序
        if carry:                             # ④ 前插新最高位 1
            return ListNode(1, head)
        return head
```

> 💡 Python 的 `h.next, prev, h = prev, h, h.next`：右侧先整体求值再从左到右赋值，等价于 C++ 的三步交换。比赛时间紧张时，这套「反转 + 逐位 + 反转」骨架可以闭眼默写。

## 8. 边界情况与易错点

1. **`[0]` → `[0]`**：数字 0 是唯一允许前导零的输入。翻倍后仍为 0，不能删节点、也不能返回空链表。
2. **单节点 `[5]` → `[1,0]`**：最高位翻倍即进位，是验证前插逻辑的最小用例。
3. **全 9 链表（进位链最长）**：如 `[9,9,9]` 每位都进 1。若漏掉循环外的 `carry` 处理，1998 会错成 998（丢掉最高位 1）。
4. **先反转、再前插**：`carry` 前插必须发生在**已恢复正序**的链表头部；顺序颠倒会把新节点送错位置。
5. **别用整数中转**：$10^4$ 位远超 `int64`（约 19 位），C++ / Java 必溢出；Python 虽能过但属于绕过考点。
6. **慎用递归**：从尾部回溯的递归写法深度达 $10^4$，有栈溢出风险；迭代反转最稳。
7. **允许修改输入**：本题原地改 `val` 与指针合法，无需复制链表。
