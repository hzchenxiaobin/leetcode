# LeetCode 操作使得分最大 题解

## 1. 题目概述

- **标题 / 题号**：操作使得分最大（#2818，hard）
- **链接**：https://leetcode.cn/problems/apply-operations-to-maximize-score/
- **来源**：LeetCode 第 358 场周赛 Q4
- **难度**：困难
- **标签**：单调栈、贡献计数、贪心、快速幂、数论（埃氏筛）

**题意**：给定长度为 $n$ 的正整数数组 `nums` 与整数 $k$。初始分数为 $1$，可以进行**至多 $k$ 次**操作：每次选择一个**之前没选过**的非空子数组 `nums[l..r]`，取其中**质数分数最高**的元素 $x$（并列时取**下标最小**者），把分数乘上 $x$。求最终分数的最大值，对 $10^9+7$ 取模。

其中**质数分数** $\mathrm{ps}(x)$ 定义为 $x$ 的不同质因子个数，例如 $300 = 2^2 \cdot 3 \cdot 5^2$ 的质数分数为 $3$。

**约束**：

- $1 \le n \le 10^5$
- $1 \le \text{nums}[i] \le 10^5$
- $1 \le k \le \min(n(n+1)/2,\ 10^9)$

> 💡 $k$ 的上界恰好是子数组总数 $n(n+1)/2$——这暗示本题的关键不是「怎么选子数组」，而是**每个值最多能被乘多少次**：把每个子数组的「胜者值」看成一个多重集合，答案就是从中选至多 $k$ 个数的最小乘积问题的对偶——**最大乘积**。

## 2. 示例

**示例 1**

```text
输入：nums = [8,3,9,3,8], k = 2
输出：81

解释：
所有元素质数分数都是 1（8 = 2³、9 = 3²、3 是质数），全程并列、全看下标。
- 选 nums[2..2]：唯一元素 9，分数 1 × 9 = 9
- 选 nums[2..3]：9 与 3 并列，取下标小的 9，分数 9 × 9 = 81
```

**示例 2**

```text
输入：nums = [19,12,14,6,10,18], k = 3
输出：4788

解释：
质数分数：19→1，12 = 2²·3→2，14 = 2·7→2，6 = 2·3→2，10 = 2·5→2，18 = 2·3²→2
- 选 nums[0..0]：19，分数 19
- 选 nums[5..5]：18，分数 19 × 18 = 342
- 选 nums[2..3]：14 与 6 并列，取下标小的 14，分数 342 × 14 = 4788
```

**示例 3**

```text
输入：nums = [1], k = 1
输出：1

解释：
唯一元素 1 的质数分数为 0，乘 1 分数不变，答案为 1。
```

## 3. 解题思路

### 3.1 暴力思路

枚举全部 $O(n^2)$ 个子数组，$O(n)$ 找每个子数组的胜者，得到「胜者值」多重集合；排序取前 $k$ 大求乘积。$n \le 10^5$ 时子数组多达 $5 \times 10^9$ 个，无法接受。

但暴力揭示了正确的**问题转化**：操作之间完全独立（每次选一个没用过的子数组，收益就是其胜者的值），因此

> **原问题 = 从「每个子数组胜者的值」构成的多重集合中，选至多 $k$ 个数，使乘积最大。**

剩下只需要高效回答一件事：**值 $\text{nums}[i]$ 在多重集合中出现了多少次？**

### 3.2 核心观察：贡献计数——每个元素赢下多少个子数组

![元素 i 赢下的子数组](images/max_score_prime_score_concept.svg)

固定元素 $i$，问：有多少个子数组的胜者是 $i$？由平局规则（分数并列时取**下标最小**）：

- 左侧的 $j < i$ 只要 $\mathrm{ps}[j] \ge \mathrm{ps}[i]$（分数**不更低**）就能抢走胜利——相等时下标更小者赢；
- 右侧的 $j > i$ 必须 $\mathrm{ps}[j] > \mathrm{ps}[i]$（**严格更高**）才能抢走——相等时 $i$ 赢。

于是定义两个边界：

- $L[i]$：$i$ 左侧最近的满足 $\mathrm{ps}[j] \ge \mathrm{ps}[i]$ 的下标 $j$，不存在则 $-1$；
- $R[i]$：$i$ 右侧最近的满足 $\mathrm{ps}[j] > \mathrm{ps}[i]$ 的下标 $j$，不存在则 $n$。

则 $i$ 是子数组 $[l, r]$ 的胜者 $\iff L[i] < l \le i \le r < R[i]$，即值 $\text{nums}[i]$ 在多重集合中恰好出现

$$\mathrm{cnt}[i] = (i - L[i]) \times (R[i] - i)$$

次：$l$ 有 $i - L[i]$ 种、$r$ 有 $R[i] - i$ 种独立选择。

### 3.3 单调栈求 L、R：两侧比较符号不对称

![平局规则导致的左右不对称](images/max_score_monotonic_stack.svg)

两个边界都是「最近的更大元素」类问题，是**单调栈**的标准应用——但两侧弹栈的比较符号**不对称**：

```text
求 L（从左往右扫）：弹栈条件 ps[top] <  ps[i]   ← 严格小的才弹，相等留下（取 ≥）
求 R（从右往左扫）：弹栈条件 ps[top] <= ps[i]   ← 相等也弹（取 >）
```

若两侧写成同一个符号，并列子数组会被 $0$ 个或 $2$ 个元素同时认领。免费的自检方法：**$\sum_i \mathrm{cnt}[i]$ 必须等于子数组总数 $n(n+1)/2$**。

### 3.4 贪心选取 + 示例演算

所有值 $\ge 1$，从多重集合中选至多 $k$ 个使乘积最大 → **按值从大到小、能取尽取**：对每个元素取 $t = \min(k, \mathrm{cnt}[i])$ 次，乘上 $\text{nums}[i]^t$（快速幂），$k \leftarrow k - t$，直到 $k = 0$。

![示例 2 演算](images/max_score_greedy_walkthrough.svg)

## 4. 算法细节

1. **质数分数批量预处理**：$\text{nums}[i] \le 10^5$，令 $V = \max(\text{nums})$，用类埃氏筛：从 $2$ 到 $V$ 扫一遍，`ps[p] == 0` 说明 $p$ 是质数（此前没有任何更小质数标记到它），给 $p$ 的所有倍数计数 `+1`。每个数恰被自己的每个质因子各计一次，结果就是不同质因子个数，总复杂度 $O(V \log \log V)$。
2. **单调栈求 L、R**：两次线性扫描，弹栈条件分别为 `<` 与 `<=`（见 3.3），每个下标进出栈各一次，$O(n)$。
3. **贪心 + 快速幂**：下标按 $\text{nums}[i]$ **降序**排序，依次取 $t = \min(k, \mathrm{cnt}[i])$，累乘 $\text{nums}[i]^t \bmod (10^9+7)$；$k$ 减去 $t$，减到 $0$ 提前退出。
4. **取模时机**：贪心比较用**真实值**（$\le 10^5$，远小于模数），只在累乘时用快速幂取模；指数 $t$ 可达 $\sim 2.5 \times 10^9$，C++ 中用 `long long`。

## 5. 正确性证明

**引理 1（胜者条件）**：元素 $i$ 是子数组 $[l, r]$ 的胜者 $\iff L[i] < l \le i \le r < R[i]$。

**证明**：
（充分）设 $L[i] < l \le i \le r < R[i]$。对任意 $j \in [l, i)$：若存在 $\mathrm{ps}[j] \ge \mathrm{ps}[i]$，则其中最近的那个位于 $(L[i], l)$ 内，与 $L[i]$ 是「左侧最近」矛盾，故 $\mathrm{ps}[j] < \mathrm{ps}[i]$。对任意 $j \in (i, r]$：同理不存在 $\mathrm{ps}[j] > \mathrm{ps}[i]$，故 $\mathrm{ps}[j] \le \mathrm{ps}[i]$。于是 $i$ 拥有子数组内最高质数分数；若有并列，$[l, i)$ 内无人与 $i$ 并列（都严格小），$(i, r]$ 内并列者下标更大，平局判给 $i$。
（必要）若 $l \le L[i]$，则 $L[i] \in [l, i)$ 且 $\mathrm{ps}[L[i]] \ge \mathrm{ps}[i]$：严格更大则 $L[i]$ 分数更高；相等则 $L[i]$ 下标更小。两种情况 $i$ 都不是胜者。若 $r \ge R[i]$，则 $R[i] \in (i, r]$ 且 $\mathrm{ps}[R[i]] > \mathrm{ps}[i]$，$i$ 同样不是胜者。∎

**推论**：胜者为 $i$ 的子数组恰有 $\mathrm{cnt}[i] = (i - L[i])(R[i] - i)$ 个（$l$、$r$ 独立计数）；每个子数组恰有一个胜者，故 $\sum_i \mathrm{cnt}[i] = n(n+1)/2$。

**引理 2（贪心最优）**：从多重集合 $S$（所有元素 $\ge 1$）中取至多 $k$ 个数使乘积最大，最优方案是把 $S$ 降序排列后取前 $k$ 个。

**证明**（交换论证）：设某方案取了 $v_j$ 而未取 $v_i$，其中 $v_i > v_j$ 且 $v_i$ 的可用次数未耗尽。把一个 $v_j$ 换成 $v_i$，乘积变化为乘以 $v_i / v_j > 1$（$v_j \ge 1$），严格增大，故原方案非最优；因此任何最优方案中，不存在「更大的值还有余量」的取法。又所有元素 $\ge 1$，多取不会使乘积变小，取满 $k$ 个（$k \le |S|$ 由约束保证）不劣。故降序取前 $k$ 个最优。∎

**定理**：本算法返回最大分数。

**证明**：由引理 1 推论，$\text{nums}[i]$ 在多重集合中恰出现 $\mathrm{cnt}[i]$ 次，单调栈在线性时间内正确求出全部 $L, R$；操作相互独立，原问题即引理 2 的选取问题；按值降序对每个元素取 $\min(k, \mathrm{cnt}[i])$ 与「降序取前 $k$ 个」等价（值相同的元素合并计数，先后无影响），由引理 2 为最优；每个因子以快速幂在模 $10^9+7$ 下正确累乘。∎

## 6. 复杂度分析

- **时间复杂度**：$O(V \log \log V + n \log n)$
  - 埃氏筛求质数分数：$O(V \log \log V)$，$V = \max(\text{nums}) \le 10^5$；
  - 单调栈两次扫描：$O(n)$；
  - 按值降序排序：$O(n \log n)$；
  - 每个元素一次快速幂：$O(n \log k)$。
- **空间复杂度**：$O(V + n)$（筛表 + 栈 + 下标数组）。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int maximumScore(vector<int>& nums, int k) {
        const int MOD = 1e9 + 7;
        const int n = nums.size();
        const int mx = *max_element(nums.begin(), nums.end());

        // 1. 埃氏筛求每个值的质数分数 ps[v]
        vector<int> ps(mx + 1, 0);
        for (int p = 2; p <= mx; ++p) {
            if (ps[p] == 0) {  // p 是质数，给所有倍数各计 1 个质因子
                for (int m = p; m <= mx; m += p) ps[m]++;
            }
        }

        // 2. 单调栈求 L / R：左取 >=（弹 <），右取 >（弹 <=）
        vector<int> score(n);
        for (int i = 0; i < n; ++i) score[i] = ps[nums[i]];
        vector<int> L(n, -1), R(n, n);
        stack<int> st;
        for (int i = 0; i < n; ++i) {
            while (!st.empty() && score[st.top()] < score[i]) st.pop();
            L[i] = st.empty() ? -1 : st.top();
            st.push(i);
        }
        while (!st.empty()) st.pop();
        for (int i = n - 1; i >= 0; --i) {
            while (!st.empty() && score[st.top()] <= score[i]) st.pop();
            R[i] = st.empty() ? n : st.top();
            st.push(i);
        }

        // 3. 按值降序贪心 + 快速幂
        vector<int> idx(n);
        iota(idx.begin(), idx.end(), 0);
        sort(idx.begin(), idx.end(),
             [&](int a, int b) { return nums[a] > nums[b]; });

        long long ans = 1, rest = k;  // cnt 可达 ~2.5e9，必须用 long long
        for (int i : idx) {
            if (rest <= 0) break;
            long long cnt = 1LL * (i - L[i]) * (R[i] - i);
            long long t = min(rest, cnt);
            ans = ans * qpow(nums[i], t, MOD) % MOD;
            rest -= t;
        }
        return (int)ans;
    }

  private:
    long long qpow(long long b, long long e, long long mod) {
        long long r = 1;
        b %= mod;
        while (e > 0) {
            if (e & 1) r = r * b % mod;
            b = b * b % mod;
            e >>= 1;
        }
        return r;
    }
};
```

### Python

```python
class Solution:
    def maximumScore(self, nums: List[int], k: int) -> int:
        MOD = 10 ** 9 + 7
        n = len(nums)
        mx = max(nums)

        # 1. 埃氏筛求质数分数
        ps = [0] * (mx + 1)
        for p in range(2, mx + 1):
            if ps[p] == 0:  # p 是质数
                for m in range(p, mx + 1, p):
                    ps[m] += 1

        # 2. 单调栈求 L / R：左取 >=（弹 <），右取 >（弹 <=）
        L, R = [-1] * n, [n] * n
        st = []
        for i in range(n):
            while st and ps[nums[st[-1]]] < ps[nums[i]]:
                st.pop()
            L[i] = st[-1] if st else -1
            st.append(i)
        st = []
        for i in range(n - 1, -1, -1):
            while st and ps[nums[st[-1]]] <= ps[nums[i]]:
                st.pop()
            R[i] = st[-1] if st else n
            st.append(i)

        # 3. 按值降序贪心 + 快速幂
        ans = 1
        for i in sorted(range(n), key=lambda j: -nums[j]):
            if k == 0:
                break
            t = min(k, (i - L[i]) * (R[i] - i))
            ans = ans * pow(nums[i], t, MOD) % MOD
            k -= t
        return ans
```

## 8. 边界情况与易错点

1. **溢出（最大坑）**：$\mathrm{cnt}[i] = (i - L[i]) \times (R[i] - i)$ 最多约 $\left(\frac{n}{2}\right)^2 \approx 2.5 \times 10^9$，`int` 必爆；$\sum \mathrm{cnt} \approx 5 \times 10^9$ 同理。C++ 中乘积与计数全程 `long long`。
2. **左右弹栈符号不对称**：左取 $\ge$（弹 `<`）、右取 $>$（弹 `<=`）。写反后平局子数组被重复/漏计数，用 $\sum \mathrm{cnt} = n(n+1)/2$ 快速自检。
3. **质数分数别逐个分解**：逐元素试除是 $O(n\sqrt V) \approx 3 \times 10^7$ 次除法，常数大易超时；埃氏筛批量处理最稳。
4. **全部为 1**：质数分数全为 0、任何操作乘 1，答案为 1；此时 $V = 1$，筛循环天然为空，代码无需特判。
5. **指数很大**：$k \le 10^9$、$t \le 2.5 \times 10^9$，快速幂指数用 `long long`（Python 天然大整数无此忧）。
6. **提前退出**：$k$ 用完即 `break`；由约束 $k \le n(n+1)/2 = \sum \mathrm{cnt}$，正常流程必然恰好用完。
7. **值相同时排序无影响**：值相同的元素贡献可合并，先后顺序不影响结果；排序比较用真实值即可（本题值域 $\le 10^5 < 10^9 + 7$，与取模互不干扰）。

**延伸思考**：

- **平局规则改为下标最大者胜**：两侧比较符号互换（左弹 `<=`、右弹 `<`），其余不变——先想清楚 tie-breaking 的方向，再写单调栈。
- **允许重复选同一子数组**：多重集合退化为「最大值出现无限次」，答案就是 $(\max \text{nums})^k$，单调栈不再必要。
- **「至多 $k$ 次」与「恰好 $k$ 次」**：本题所有值 $\ge 1$，两者等价；若值可以是 $1$ 以下（如 $0$ 或负数、分数），「必须选满」会引入完全不同的权衡。
- **值域扩大到 $10^9$**：筛表开不下，退路是只对出现过的**不同值**去重后用素数表试除分解（$\sqrt{10^9}$ 内约 3400 个素数），瓶颈从筛法转移到分解。
