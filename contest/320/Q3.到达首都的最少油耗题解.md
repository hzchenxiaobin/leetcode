# LeetCode 到达首都的最少油耗 题解

## 1. 题目概述

- **标题 / 题号**：到达首都的最少油耗（#2477，medium）
- **链接**：https://leetcode.cn/problems/minimum-fuel-cost-to-report-to-the-capital/
- **来源**：LeetCode 第 320 场周赛 Q3
- **难度**：中等
- **标签**：树、深度优先搜索、广度优先搜索、贪心

**题意**：给一棵 $n$ 个节点的树，节点 $0$ 是首都。每个城市恰好有一辆车、一位代表，所有代表都要去首都。每辆车最多载 `seats` 人（含司机），每辆车每经过一条边耗油 $1$ 升。代表可以在任意城市换车，多余的车辆可以停在城市不动。求所有代表都到达首都的最少总油耗。

**约束**：

- $1 \le n \le 10^5$
- `roads.length == n - 1`，`roads` 构成一棵合法的树
- $1 \le seats \le 10^5$

## 2. 示例

**示例 1**

```text
输入：roads = [[0,1],[0,2],[0,3]], seats = 5
输出：3

解释：
三个代表各自开车直达首都，每辆车各耗 1 升，共 3 升。
```

**示例 2**

```text
输入：roads = [[3,1],[3,2],[1,0],[0,4],[0,5],[4,6]], seats = 2
输出：7

解释：
- 代表 2 → 城市 3（1 升）
- 代表 2、3 同车 → 城市 1 → 首都（2 升）
- 代表 1 直达首都（1 升）
- 代表 5 直达首都（1 升）
- 代表 6 → 城市 4，与代表 4 同车 → 首都（2 升）
合计 7 升。
```

**示例 3**

```text
输入：roads = [], seats = 1
输出：0

解释：n = 1，首都自己就有代表，无人需要移动。
```

## 3. 解题思路

### 3.1 暴力思路

最直观的做法：每个代表**独立开车**走自己到首都的路径。由于树中路径唯一，总油耗为 $\sum_u \mathrm{depth}(u)$。

这是合法方案，但不一定最优——`seats` 较大时拼车能显著省油。而"谁和谁拼车、在哪换车"的组合方式指数级多，直接枚举或搜索状态空间（每辆车载了谁、停在哪）不可行。

反过来想：油耗不是按"人"算，而是按"**车过边**"算的。这提示我们换个视角——**不追踪每个人的行程，只统计每条边上的车流量**。

### 3.2 核心观察：每条边的人流量是定值

把树以 $0$ 为根。**树中任意两点路径唯一**，所以子树 $\mathrm{subtree}(u)$ 中的每一位代表去首都，都必然**恰好一次**经过边 $(u \to \mathrm{parent}(u))$，且不会走其他边进出该子树。

设 $cnt(u) = |\mathrm{subtree}(u)|$，则：

- 边 $(u \to \mathrm{parent}(u))$ 上的人流量**恒为** $cnt(u)$，与代表何时上车、怎么换车无关；
- 一辆车过这条边最多带 $seats$ 人，所以过这条边的**车辆数至少** $\lceil cnt(u) / seats \rceil$；
- 每辆车过一条边耗 $1$ 升，所以这条边贡献的油耗**恰好**是 $\lceil cnt(u) / seats \rceil$ 升。

![边的人流量与子树大小](images/min_fuel_subtree_people.svg)

$$\text{ans} = \sum_{u \ne 0} \left\lceil \frac{cnt(u)}{seats} \right\rceil$$

**怎么装车**：以 $cnt = 5, seats = 2$ 为例，把人装满前几辆车、最后一辆坐不满，共 $\lceil 5/2 \rceil = 3$ 辆车过边，油耗 $3$ 升。装不下的多余车辆留在 $u$ 城不再前进（停车不耗油）。

![拼车计数示意](images/min_fuel_ceil_cars.svg)

### 3.3 算法流程

只需一次自底向上的遍历求出所有 $cnt(u)$：

1. 由 `roads` 建无向邻接表；
2. 从 $0$ 出发 BFS（或迭代 DFS），记录每个点的父亲 `parent[u]` 与 BFS 序 `order`；
3. **按 BFS 序逆序**处理（保证儿子先于父亲）：
   - 若 $u \ne 0$：`ans += ceil(cnt[u] / seats)`，并 `cnt[parent[u]] += cnt[u]`；
4. 返回 `ans`。

> ⚠️ $n$ 可达 $10^5$，树可能是链状，递归 DFS 深度会爆栈（C++/Python 默认栈都扛不住），必须用迭代写法或 BFS 逆序。

## 4. 算法细节

1. **建图**：无向邻接表，两个方向都要加边。
2. **求父节点与顺序**：BFS 时用 `visited` / `parent` 防止走回头路；BFS 序的性质是任意节点排在所有后代之后，因此**逆序遍历时儿子一定先于父亲被处理**，此时它的 $cnt$ 已经是完整的子树大小。
3. **子树大小**：初始化 `cnt[u] = 1`（每个城市一位代表），儿子处理完后把 `cnt[u]` 累加给父亲。
4. **向上取整**：`ceil(cnt / seats)` 用整数写法 `(cnt + seats - 1) / seats`，避免浮点误差。
5. **溢出**：最坏情况（链 + `seats = 1`）答案量级为 $\sum_{k=1}^{n} k \approx n^2/2 \approx 5 \times 10^9$，超出 `int`，必须用 64 位整数累加。
6. **根节点不结算**：$u = 0$ 没有向上的边，跳过加油耗与上报。

## 5. 正确性证明

**引理 1（人流量恒定）**：对任意 $u \ne 0$，恰好有 $cnt(u)$ 位代表（即 $\mathrm{subtree}(u)$ 中的全部代表）各经过边 $e_u = (u, \mathrm{parent}(u))$ 一次。

**证明**：树中路径唯一。$\mathrm{subtree}(u)$ 中任一点 $v$ 到 $0$ 的路径必经 $e_u$；反之 $\mathrm{subtree}(u)$ 之外的点 $w$ 到 $0$ 的路径不经过 $e_u$（若经过则需先进出子树，与树的唯一路径矛盾）。∎

**引理 2（逐边下界）**：任何合法方案中，经过边 $e_u$ 的**车辆通行次数**至少 $\lceil cnt(u)/seats \rceil$，故该边油耗至少 $\lceil cnt(u)/seats \rceil$ 升。

**证明**：$cnt(u)$ 位代表要从 $u$ 一侧移动到 $\mathrm{parent}(u)$ 一侧，只能乘车过边，每辆车每次至多载 $seats$ 人，因此过边车次 $\ge \lceil cnt(u)/seats \rceil$；每车次耗油恰 $1$ 升。∎

**引理 3（下界可达）**：存在方案使每条边 $e_u$ 的车次**恰好**为 $\lceil cnt(u)/seats \rceil$。

**证明**（归纳法，自底向上构造）：对子树高度归纳。设 $u$ 的儿子 $c_1,\dots,c_k$ 已各自用 $\lceil cnt(c_i)/seats \rceil$ 辆车把人送到 $u$ 且不再产生额外油耗。此时 $u$ 处人数为 $cnt(u)$，可用车辆为 $1 + \sum_i \lceil cnt(c_i)/seats \rceil \ge 1 + \lceil \sum_i cnt(c_i) / seats \rceil \ge \lceil (1+\sum_i cnt(c_i))/seats \rceil = \lceil cnt(u)/seats \rceil$（上取整的次可加性）。把 $cnt(u)$ 人重新装进其中 $\lceil cnt(u)/seats \rceil$ 辆车（每人都在某辆车里），其余车留在 $u$。至根节点时所有代表到达，每条边车次恰为下界。∎

**定理**：最少总油耗为 $\displaystyle\sum_{u \ne 0} \lceil cnt(u)/seats \rceil$。

**证明**：由引理 2，任何方案总油耗 $\ge \sum_{u \ne 0} \lceil cnt(u)/seats \rceil$；由引理 3，该下界可以取到。两相结合即得。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$
  - 建邻接表 $O(n)$；
  - BFS 每点每边常数次访问 $O(n)$；
  - 逆序累加 $O(n)$。
- **空间复杂度**：$O(n)$
  - 邻接表 $O(n)$，`parent` / `cnt` / `order` 数组各 $O(n)$。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    long long minimumFuelCost(vector<vector<int>>& roads, int seats) {
        int n = roads.size() + 1;
        vector<vector<int>> g(n);
        for (auto& r : roads) {
            g[r[0]].push_back(r[1]);
            g[r[1]].push_back(r[0]);
        }

        vector<int> parent(n, -1), order;
        order.reserve(n);
        vector<bool> vis(n, false);
        queue<int> q;
        vis[0] = true;
        q.push(0);
        while (!q.empty()) {
            int u = q.front();
            q.pop();
            order.push_back(u);
            for (int v : g[u]) {
                if (!vis[v]) {
                    vis[v] = true;
                    parent[v] = u;
                    q.push(v);
                }
            }
        }

        vector<long long> cnt(n, 1);
        long long ans = 0;
        for (int i = n - 1; i >= 0; --i) {
            int u = order[i];
            if (parent[u] != -1) {
                ans += (cnt[u] + seats - 1) / seats;
                cnt[parent[u]] += cnt[u];
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def minimumFuelCost(self, roads: List[List[int]], seats: int) -> int:
        n = len(roads) + 1
        g = [[] for _ in range(n)]
        for a, b in roads:
            g[a].append(b)
            g[b].append(a)

        parent = [-1] * n
        order = []
        vis = [False] * n
        vis[0] = True
        q = deque([0])
        while q:
            u = q.popleft()
            order.append(u)
            for v in g[u]:
                if not vis[v]:
                    vis[v] = True
                    parent[v] = u
                    q.append(v)

        cnt = [1] * n
        ans = 0
        for u in reversed(order):
            p = parent[u]
            if p != -1:
                ans += (cnt[u] + seats - 1) // seats
                cnt[p] += cnt[u]
        return ans
```

## 8. 边界情况与易错点

1. **n = 1，roads 为空**（示例 3）
   - 答案为 0；`roads.size() + 1` 求 $n$ 的写法天然兼容，但 BFS 循环要能正确处理单节点。
2. **递归爆栈**
   - 链状树深度可达 $10^5$，C++/Python 递归 DFS 均有栈溢出风险，用 BFS + 逆序累加的迭代写法最稳。
3. **答案溢出 int**
   - 链 + `seats = 1` 时答案约 $n^2/2 \approx 5\times10^9$，必须 `long long` / Python 无所谓但 C++ 必须注意。
4. **上取整写法**
   - 用 `(cnt + seats - 1) / seats`，不要写浮点 `(double)cnt/seats` 再 `ceil`（有精度风险）。
5. **无向图遍历**
   - BFS 时需要 `visited`（或只向 `!= parent` 的邻居扩展），否则会沿边来回走导致死循环。
6. **根节点结算**
   - $u = 0$ 无向上的边，不要为它加油耗；同时它吸收所有儿子的 $cnt$ 但无需上报。
