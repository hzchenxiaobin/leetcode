# LeetCode 完美分割的方案数 题解

## 1. 题目概述

- **标题 / 题号**：完美分割的方案数（#2478，hard）
- **链接**：https://leetcode.cn/problems/number-of-beautiful-partitions/
- **来源**：LeetCode 第 320 场周赛 Q4
- **难度**：困难
- **标签**：字符串、动态规划、前缀和

**题意**：给定一个由数字 `'1'`~`'9'` 组成的字符串 `s`，以及整数 `k` 和 `minLength`。要求把 `s` **恰好**切成 `k` 段连续且互不相交的子串（并覆盖整个 `s`），使得每一段都满足：

- 长度 $\ge \text{minLength}$；
- 首字符是**质数数字**（`'2'`、`'3'`、`'5'`、`'7'`）；
- 尾字符是**非质数数字**（`'1'`、`'4'`、`'6'`、`'8'`、`'9'`）。

返回满足条件的分割方案数，对 $10^9+7$ 取模。

**约束**：

- $1 \le k, \text{minLength} \le |s| \le 1000$
- `s` 中每个字符都是 `'1'`~`'9'` 之一

## 2. 示例

**示例 1**

```text
输入：s = "23542185131", k = 3, minLength = 2
输出：3

解释：
"2354 | 218 | 5131"
"2354 | 21851 | 31"
"2354218 | 51 | 31"
```

```

```

## 3. 解题思路

### 3.1 暴力思路

最直接的枚举：在 `s` 的 $n-1$ 个内部位置中选 $k-1$ 个切割点，逐一验证每个条件。组合数高达 $\binom{n-1}{k-1}$，在 $n=1000$ 时不可行。

退一步是**朴素划分型 DP**：设 $f[j][i]$ 为「前 $i$ 个字符恰好分成 $j$ 段」的方案数，枚举最后一段的起点 $m$ 做转移。但每个状态 $(j, i)$ 都要重新扫一遍 $m$，总复杂度 $O(n^2 k)$；$n = k = 1000$ 时约 $10^9$，超时。

### 3.2 核心观察：切割点由相邻两个字符唯一决定

把一段的形态写出来：**首字符质数、尾字符非质数**，中间字符任意。于是若第 $t$ 段与第 $t+1$ 段的交界是位置 $m$（即第 $t+1$ 段从 $s[m]$ 开始），那么**切割点本身没有任何自由度**：

- $s[m-1]$ 必须是**非质数**（第 $t$ 段的尾）；
- $s[m]$ 必须是**质数**（第 $t+1$ 段的首）。

也就是说，整串的"可切位置集合" $\{m : s[m-1] \in N,\ s[m] \in P\}$ **只由字符串本身决定，与 $k$、$\text{minLength}$ 无关**，可以 $O(n)$ 预处理；剩下的只是"从可切点集合中恰选 $k-1$ 个、相邻间隔 $\ge \text{minLength}$"的计数问题——标准的划分型 DP。

![切割点与段的形态](images/wc320_q4_cut_points.svg)

再加上两道端点门卫：$s[0]$ 必须是质数数字（第 1 段开头）、$s[n-1]$ 必须是非质数数字（第 $k$ 段结尾），违反任意一条答案为 0。

### 3.3 状态设计与前缀和优化

设 $f[j][i]$ = 把 $s[0..i-1]$ 恰好分成 $j$ 个完美段的方案数，边界 $f[0][0] = 1$，答案 $f[k][n]$。按最后一段的起点 $m$ 分类：

$$f[j][i] = [s[i-1] \in N] \cdot \sum_{m=0}^{i-L} [s[m] \in P] \cdot f[j-1][m]$$

**关键观察**：求和式中与 $i$ 有关的只有上界 $i - L$，而被求和项的结构与 $i$ 完全无关 → 抽出**前缀和**：

$$P[x] = \sum_{m=0}^{x} [s[m] \in P] \cdot f[j-1][m]$$

则转移变成**单点查询**：$f[j][i] = [s[i-1] \in N] \cdot P[i - L]$。每层先 $O(n)$ 建 $P$、再 $O(n)$ 填 $f$，共 $k$ 层，总复杂度 $O(nk) \approx 10^6$。

![状态设计与前缀和优化](images/wc320_q4_dp_transition.svg)

> 💡 **两个门卫各管一半，缺一不可**：求和项里乘 $[s[m] \in P]$ 检查的是**新段开头**；而"前一段结尾 $s[m-1] \in N$"不需要显式检查——$f[j-1][m] > 0$ 本身就意味着 $s[m-1]$ 非质数（第 $j-1$ 段合法地以 $m-1$ 结尾）。同理，$[s[i-1] \in N]$ 检查的是当前段的结尾。

### 3.4 示例演算

以示例 1（`s = "23542185131"`，$k=3$，$L=2$）演算逐层 DP：

![示例 1 的逐层演算](images/wc320_q4_walkthrough.svg)

- 可切点集合为 $\{4, 7, 9\}$，恰好要选 $k-1=2$ 个、间隔 $\ge 2$；
- 第 1 层：$f_1[i]$ 在 $i \in \{4, 6, 7, 9, 11\}$（段尾非质数且长度够）处为 1；

- 第 3 层：$f_3[11] = P_3[9] = 3$，与三种分割方案一一对应。

## 4. 算法细节

1. **快速判零**：$s[0] \notin P$（首段开不了头）、$s[n-1] \in P$（末段收不了尾）、$n < k \cdot \text{minLength}$（总长度不够），任一成立直接返回 0，省掉整场 DP。
2. **指示函数**：$\text{isPrime}(c) \iff c \in \{2, 3, 5, 7\}$。
3. **滚动数组**：`g` 表示上一层 $f[j-1]$（长度 $n+1$），`f` 表示当前层 $f[j]$；初始 `g[0] = 1`（即 $f[0]$）。
4. **建前缀和**：`P[m] = P[m-1] + isPrime(s[m]) * g[m]`（`m = 0..n-1`，起点下标最多到 $n-1$；每项取模）。
5. **填当前层**：`i` 从 $j \cdot L$ 到 $n$（不足 $j$ 段每段 $\ge L$ 的前缀必为 0），仅当 $s[i-1]$ 为非质数数字时 `f[i] = P[i - minLength]`，其余保持 0。
6. 两数组交替滚动 `k` 轮，返回 $f[k][n]$。

## 5. 正确性证明

**引理 1（端点必要性）**：若 `s` 存在完美分割，则 $s[0] \in P$、$s[n-1] \in N$ 且 $n \ge k \cdot L$。

**证明**：第一段以 $s[0]$ 开头、第 $k$ 段以 $s[n-1]$ 结尾，按定义两字符分别必须是质数、非质数数字；$k$ 段长度均 $\ge L$，相加即得。∎

**引理 2（按末段起点分类的不重不漏）**：把"前 $i$ 个字符分成 $j$ 段的完美分割"的全体，按第 $j$ 段的起点 $m$ 分类，则每一类恰与「$s[0..m-1]$ 的 $j-1$ 段完美分割」$\times$「合法段 $[m, i-1]$」一一对应，其中合法等价于 $i - m \ge L$、$s[m] \in P$、$s[i-1] \in N$。

**证明**：一个完美分割的第 $j$ 段由 $m$ 唯一确定，故分类不重；反之，把任意一个 $j-1$ 段的完美前缀与一个满足三条件的段 $[m, i-1]$ 拼接，得到一个第 $j$ 段起点为 $m$ 的完美分割，故不漏。三条件即该段的长度、首、尾约束。∎

**引理 3（隐含的尾约束）**：若 $j \ge 1$、$m \ge 1$ 且 $f[j][m] > 0$，则 $s[m-1] \in N$。

**证明**：$f[j][m] > 0$ 时存在前 $m$ 个字符的 $j$ 段完美分割，其第 $j$ 段以 $m-1$ 结尾且合法，故 $s[m-1]$ 非质数。∎

> 引理 3 说明：转移式中显式乘上 $[s[m] \in P]$ 后，"切点另一侧 $s[m-1] \in N$"已被 $f[j-1][m]$ 隐含，无需重复检查（$m = 0$ 时 $f[j-1][0]$ 仅在 $j = 1$ 时非零，同样合法）。

**引理 4（转移等式）**：对 $j \ge 1$、$i \ge 1$，

$$f[j][i] = [s[i-1] \in N] \cdot \sum_{m=0}^{i-L} [s[m] \in P] \cdot f[j-1][m]$$

**证明**：由引理 2，方案数等于对 $m \le i - L$ 的各类计数求和；每类的方案数为 $f[j-1][m]$ 中"第 $j$ 段起点可为 $m$"的倍数。$s[i-1] \in N$ 是所有类共享的前提（当前段尾）；对给定 $m$，第 $j$ 段合法尚需 $s[m] \in P$，用指示函数把它并入求和项；而"前 $j-1$ 段以 $m-1$ 收尾"的约束由引理 3 已含于 $f[j-1][m] > 0$。∎

**定理**：算法返回值等于完美分割数对 $10^9+7$ 取模。

**证明**：对 $j$ 归纳证明第 $j$ 层正确。$j = 0$：$f[0][0] = 1$（空分割），$f[0][i > 0] = 0$。设第 $j-1$ 层正确，程序中 `P[m]` 按构造递推恰等于 $\sum_{t \le m} [s[t] \in P] f[j-1][t]$；于是对 $i \ge jL$，`f[i] = P[i-L]` 与引理 4 右端一致；对 $i < jL$，任何 $j$ 段完美分割总长 $\ge jL > i$（引理 1 第三条应用于前缀），程序保持 `f[i] = 0` 正确。归纳至 $j = k$ 取 $i = n$ 即答案；三种快速判零情形由引理 1 排除。∎

## 6. 复杂度分析

- **时间复杂度**：$O(nk)$。共 $k$ 层，每层建前缀和 $O(n)$、填表 $O(n)$；$n = k = 1000$ 时约 $10^6$ 次操作。
- **空间复杂度**：$O(n)$。滚动两个长度 $n+1$ 的数组与一个长度 $n$ 的前缀和数组（若按层保留全表 $f[j][i]$ 则为 $O(nk)$）。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int beautifulPartitions(string s, int k, int minLength) {
        const int MOD = 1e9 + 7;
        int n = s.size();
        auto isPrime = [](char c) { return c == '2' || c == '3' || c == '5' || c == '7'; };

        // 快速判零：首字符非质数 / 尾字符质数 / 总长度不够
        if (!isPrime(s.front()) || isPrime(s.back()) || n < k * minLength) return 0;

        vector<long long> f(n + 1), g(n + 1);
        g[0] = 1; // g = f[0]
        for (int j = 1; j <= k; ++j) {
            fill(f.begin(), f.end(), 0);
            vector<long long> P(n);
            for (int m = 0; m < n; ++m) {
                P[m] = m ? P[m - 1] : 0;
                if (isPrime(s[m])) P[m] = (P[m] + g[m]) % MOD;
            }
            for (int i = j * minLength; i <= n; ++i)
                if (!isPrime(s[i - 1])) f[i] = P[i - minLength];
            swap(f, g);
        }
        return g[n] % MOD;
    }
};
```

### Python

```python
class Solution:
    def beautifulPartitions(self, s: str, k: int, minLength: int) -> int:
        MOD = 10 ** 9 + 7
        n = len(s)
        is_prime = lambda c: c in "2357"

        if not is_prime(s[0]) or is_prime(s[-1]) or n < k * minLength:
            return 0

        g = [0] * (n + 1)  # g = f[0]
        g[0] = 1
        for j in range(1, k + 1):
            P = [0] * n
            for m in range(n):
                P[m] = P[m - 1] if m else 0
                if is_prime(s[m]):
                    P[m] = (P[m] + g[m]) % MOD
            f = [0] * (n + 1)
            for i in range(j * minLength, n + 1):
                if not is_prime(s[i - 1]):
                    f[i] = P[i - minLength] % MOD
            g = f
        return g[n] % MOD
```

## 8. 边界情况与易错点

1. **漏掉段尾门卫 $[s[i-1] \in N]$ 是最高频 WA**：`f[j][i]` 只有在 `s[i-1]` 为非质数数字时才可能非零，若转移时不检查，段尾是质数的非法方案会被计入。
2. **两个门卫各查一半**：切点条件是"$s[m-1]$ 非质数 **且** $s[m]$ 质数"。$s[m]$ 质数要在转移里显式乘；$s[m-1]$ 非质数已由 $f[j-1][m] > 0$ 隐含（引理 3）。只查其中一个都会出错。
3. **`P` 与 `f` 的下标范围不同**：`P[m]` 的下标是"下一段起点 $m$"，只到 $n-1$；`f[i]` 的下标是前缀长度，到 $n$。`f[j][n]` 查询 `P[n - minLength]`，由 $\text{minLength} \ge 1$ 保证不越界，但数组长度不要开错。
4. **快速判零三条件**：`s[0]` 非质数、`s[n-1]` 质数、`n < k * minLength`，任一成立返回 0（不做也能由 DP 得 0，但可以省掉整场 DP）。
5. **每层 `f` 必须清零**：滚动数组残留上一层的值会把"段尾为质数"的非法计数带回来。
6. **`i` 的枚举下界**：从 $j \cdot \text{minLength}$ 起（前 $i$ 个字符要装下 $j$ 个长度 $\ge L$ 的段）；若从 1 开始枚举，`P[i - minLength]` 会出现负下标越界。
7. **取模与溢出**：`P[m] = P[m-1] + g[m]` 两项均 $< 10^9+7$，和不超过 $2 \times (10^9+7)$，C++ `int` 勉强放得下但贴边，用 `long long` 更稳；每步同步取模防止累加溢出。
8. **`n = 1, k = 1`**：若 `s[0]` 是质数数字，它同时需要是非质数——判零条件 `isPrime(s.back())` 直接返回 0，无需特判。
