# LeetCode 使数组中位数等于 K 的最少操作数 题解

## 1. 题目概述

- **标题 / 题号**：使数组中位数等于 K 的最少操作数（#3107，medium）
- **链接**：https://leetcode.cn/problems/minimum-operations-to-make-median-of-array-equal-to-k/
- **来源**：LeetCode 第 392 场周赛 Q3
- **难度**：中等
- **标签**：贪心、数组、排序

**题意**：给定整数数组 $\text{nums}$ 和非负整数 $k$。一次操作可以把**任一元素** $+1$ 或 $-1$。求使 $\text{nums}$ 的**中位数**恰好变为 $k$ 的最少操作次数。中位数指数组**非递减排序**后最中间的元素；长度为**偶数**时取中间两个数的**较大值**。

**约束**：

- $1 \le \text{nums.length} \le 2 \times 10^5$
- $1 \le \text{nums}[i] \le 10^9$
- $1 \le k \le 10^9$

> ⚠️ 两个读题要点：① 偶数长度的中位数取**较大**的中间值（不是平均值、也不是较小值），它直接决定下标口径 $m = \lfloor n/2 \rfloor$；② 操作是逐次 $\pm 1$，把元素 $x$ 改成 $y$ 的最少代价**恰为** $\lvert x - y \rvert$，各元素代价独立可加。

## 2. 示例

**示例 1**

```text
输入：nums = [2,5,6,8,5], k = 4
输出：2
解释：将 nums[1] 和 nums[4] 各减 1 得到 [2,4,6,8,4]，
      排序后为 [2,4,4,6,8]，中位数为 4。
```

**示例 2**

```text
输入：nums = [2,5,6,8,5], k = 7
输出：3
解释：将 nums[1] 加 1 两次、nums[2] 加 1 一次，得到 [2,7,7,8,5]，
      排序后为 [2,5,7,7,8]，中位数为 7。
```

**示例 3**

```text
输入：nums = [1,2,3,4,5,6], k = 4
输出：0
解释：偶数长度取中间两数的较大值，即 4，已经等于 k，无需任何操作。
```

## 3. 解题思路

### 3.1 暴力思路

操作只改值不改长度，终态数组的取值无上界，直接搜索状态空间没有意义。最自然的朴素想法是：**排序后把中位下标上的元素改成 $k$ 就收工**，代价 $\lvert a[m] - k \rvert$。它在示例 1 上立刻翻车：

> 排序得 $a = [2,5,5,6,8]$，$m = 2$。把 $a[2] = 5$ 改成 $4$，终态多重集为 $\{2,4,5,6,8\}$，重排后中位数是 **5**——左半那个 $5$ 把它「顶」出了中位。示例 2 对称翻车：右半的 $6 < 7$ 会把中位「压」下去。

病根在于：**中位数是全序约束，不是单个位置的约束**。终态排序后第 $m$ 位恰好等于 $k$，等价于一整套要求：**左半全部 $\le k$、中位恰好 $= k$、右半全部 $\ge k$**。这才是「中位数等于 $k$」的完整刻画。

### 3.2 核心观察：终态三段刻画 + 逐位独立定价

![核心观察：终态三段刻画与逐位定价](images/wc392_q3_median_concept.svg)

把数组升序排序为 $a$，记 $m = \lfloor n/2 \rfloor$（偶数长度取较大中位数，0-indexed 下标恰为 $n/2$）。合法终态的排序形式 $b$ 必须满足 $b[i] \le k\ (i < m)$、$b[m] = k$、$b[i] \ge k\ (i > m)$。而把 $x$ 变成 $y$ 的代价恰为 $\lvert x - y \rvert$，于是**逐位独立定价**：

| 位置 | 终值约束 | 最便宜终值 | 代价 |
|------|----------|-----------|------|
| $i < m$（左半） | $\le k$ | $\min(a[i],\ k)$ | $\max(0,\ a[i] - k)$ |
| $i = m$（中位） | $= k$ | $k$ | $\lvert a[m] - k \rvert$ |
| $i > m$（右半） | $\ge k$ | $\max(a[i],\ k)$ | $\max(0,\ k - a[i])$ |

三段的最优终值拼接起来**仍然有序**（左半 $\le k$ = 中位 $\le$ 右半），逐位最优可以**同时取到**，答案就是三段代价直接求和：

$$\text{ans} = \lvert a[m] - k \rvert + \sum_{i < m} \max(0,\ a[i] - k) + \sum_{i > m} \max(0,\ k - a[i])$$

> 💡 直观理解：左半**超标**（$> k$）的元素必须压下来——压到**恰好 $k$** 即满足约束，多压一格纯亏；右半**不足**（$< k$）的元素对称地抬到恰好 $k$；中位本身一分不多一分不少地钉在 $k$。已达标的位置全部「白嫖」（代价 0），三类调整互不抢位置，代价天然可加。

### 3.3 算法流程

![算法流程：排序后三段一趟扫描，越界段提前收口](images/wc392_q3_algorithm_flow.svg)

流程一句话：排序 → 中位钉死 $\lvert a[m] - k \rvert$ → 从 $m-1$ 向左累加超标者 → 从 $m+1$ 向右累加不足者 → 返回。由于数组有序，左半的超标者是紧贴中位的**连续后缀**、右半的不足者是紧贴中位的**连续前缀**，两段扫描都可以在「不再越界」时提前 `break`（纯剪枝，$O(n)$ 全扫同样正确）。

### 3.4 示例演算

![示例演算：同一数组 k=4 与 k=7 两个方向的走查](images/wc392_q3_example_walkthrough.svg)

同一个数组 $\text{nums} = [2,5,6,8,5]$，排序后 $a = [2,5,5,6,8]$，$m = 2$：

**$k = 4$（中位数变小）**：左半 $a[1] = 5$ 超标要压；中位 $a[2] = 5$ 要降。

| 位置 | 0 | 1 | 2（中位） | 3 | 4 |
|------|---|---|-----------|---|---|
| 原值 | 2 | 5 | 5 | 6 | 8 |
| 终值 | 2 | **4** | **4** | 6 | 8 |
| 代价 | 0 | 1 | 1 | 0 | 0 |

总代价 $2$，终态 $[2,4,4,6,8]$ 的中位数 $= 4$ ✓

**$k = 7$（中位数变大）**：中位 $a[2] = 5$ 要升；右半 $a[3] = 6$ 不足要抬。

| 位置 | 0 | 1 | 2（中位） | 3 | 4 |
|------|---|---|-----------|---|---|
| 原值 | 2 | 5 | 5 | 6 | 8 |
| 终值 | 2 | 5 | **7** | **7** | 8 |
| 代价 | 0 | 0 | 2 | 1 | 0 |

总代价 $3$，终态 $[2,5,7,7,8]$ 的中位数 $= 7$ ✓

## 4. 算法细节

1. **下标口径**：$m = \lfloor n/2 \rfloor$（0-indexed）。奇数长度 $n=5$ 时 $m=2$ 是正中；偶数长度 $n=6$ 时 $m=3$ 恰是「中间两数的较大值」——题目规定取较大，正好落在 $n/2$，不要顺手写成 $n/2 - 1$。
2. **「白嫖」结构**：左半的代价只来自 $a[i] > k$ 的位置，右半只来自 $a[i] < k$ 的位置；排序保证前者是左半的**连续后缀**（紧贴 $m-1$）、后者是右半的**连续前缀**（紧贴 $m+1$）。
3. **提前收口**：左半从 $m-1$ 向左扫，遇 $a[i] \le k$ 即停；右半从 $m+1$ 向右扫，遇 $a[i] \ge k$ 即停。两个方向别写反。
4. **溢出**：$n \le 2 \times 10^5$、值域 $10^9$，答案上界约 $2 \times 10^{14}$，超出 32 位——C++/Java 的**累加器必须 64 位**；单次差值 $a[i] - k$ 不超 $10^9$ 不溢 `int`，但求和必须 `long long`。Python 天然大数无此顾虑。
5. **接口**：LeetCode 签名为 `long long minOperationsToMakeMedianK(vector<int>& nums, int k)`。
6. **可以更快吗**：用 `nth_element` 一轮划分即可让第 $m$ 小就位、左右两段各归其位（内部无序），随后照样统计，平均 $O(n)$；若要对**多个 $k$** 反复询问，再叠加排序 + 前缀和 + 二分，每次询问可降到 $O(\log n)$。

## 5. 正确性证明

一组操作方案等价于给每个原元素 $x_i$ 指定终值 $y_i$（逐元素 $\pm 1$ 的操作数下界恰为 $\lvert x_i - y_i \rvert$，且显然可取到），总代价 $\sum_i \lvert x_i - y_i \rvert$；唯一的约束是终值多重集 $Y$ 的中位数等于 $k$。

**引理 1（中位条件刻画）**：大小为 $n$ 的多重集 $Y$ 的中位数等于 $k$，当且仅当其排序形式 $b$ 满足 $b[m] = k$（$m = \lfloor n/2 \rfloor$）；此时必然 $b[i] \le k\ (i < m)$ 且 $b[i] \ge k\ (i > m)$。

**证明**：按定义，中位数是排序后最中间的元素，偶数长度取中间两数的**较大者**，两种情况统一为 $b[m]$，故「中位数 $= k$」⟺ $b[m] = k$。又 $b$ 非递减，$i < m$ 时 $b[i] \le b[m] = k$，$i > m$ 时 $b[i] \ge b[m] = k$。∎

**引理 2（同序配对最优）**：设 $a$、$b$ 均为长度 $n$ 的非递减序列，则对任意置换 $\sigma$，$\sum_i \lvert a[i] - b[\sigma(i)] \rvert \ge \sum_i \lvert a[i] - b[i] \rvert$。

**证明**：先证 2×2 交换不等式：若 $a_1 \le a_2$、$b_1 \le b_2$，则

$$\bigl(\lvert a_1 - b_2 \rvert + \lvert a_2 - b_1 \rvert\bigr) - \bigl(\lvert a_1 - b_1 \rvert + \lvert a_2 - b_2 \rvert\bigr) = 2 \cdot \max\bigl(0,\ \min(a_2, b_2) - \max(a_1, b_1)\bigr) \ge 0$$

（按 $a_1 \le a_2$ 与 $b_1 \le b_2$ 的六种交错次序逐一展开绝对值，差式均化归为上式；几何直观：**交叉配对比同序配对多付 $2 \times$ 两区间的交叠长度**，区间无交叠时恰好打平）。

对任意 $\sigma$，若存在逆序对 $i < j$（即 $\sigma(i) > \sigma(j)$），交换这两个配对就是上式的情形（$a[i] \le a[j]$，$b[\sigma(j)] \le b[\sigma(i)]$），总代价不增。冒泡排序式地消除全部逆序对后 $\sigma$ 变为恒等映射，代价一路不增，故同序配对代价最小。∎

**引理 3（逐位下界）**：对任意满足引理 1 条件的合法排序终态 $b$，都有 $\sum_i \lvert a[i] - b[i] \rvert \ge L$，其中

$$L = \lvert a[m] - k \rvert + \sum_{i < m} \max(0,\ a[i] - k) + \sum_{i > m} \max(0,\ k - a[i])$$

**证明**：逐位看。$i < m$ 时 $b[i] \le k$：若 $a[i] > k$，则 $b[i] \le k < a[i]$，$\lvert a[i] - b[i] \rvert = a[i] - b[i] \ge a[i] - k$；若 $a[i] \le k$，则 $\lvert a[i] - b[i] \rvert \ge 0 = \max(0,\ a[i] - k)$。$i = m$ 时 $b[m] = k$，该项恰为 $\lvert a[m] - k \rvert$。$i > m$ 时 $b[i] \ge k$，与左半对称。逐位求和即得。∎

**定理**：使中位数变为 $k$ 的最少操作数等于 $L$。

**证明**：任一合法方案把原多重集 $A$ 变成中位数为 $k$ 的多重集 $B$，其代价是 $A$ 到 $B$ 的某个元素匹配的代价，由引理 2 不低于同序配对代价 $\sum_i \lvert a[i] - b[i] \rvert$，再由引理 3 不低于 $L$。反过来，取 $b^*[i] = \min(a[i], k)\ (i < m)$、$b^*[m] = k$、$b^*[i] = \max(a[i], k)\ (i > m)$：与非递减序列逐位取 $\min$ / $\max$ 保持非递减，故 $b^*$ 非递减且满足引理 1 的全部条件（合法终态），其逐位代价恰为 $L$ 的三个被加项。下界与构造吻合，$L$ 即为答案。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \log n)$，排序主导；中位定价与两段扫描合计 $O(n)$。改用 `nth_element` 可降至平均 $O(n)$。
- **空间复杂度**：$O(1)$，原地排序加常数个变量（不计语言自身排序栈的开销）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long minOperationsToMakeMedianK(vector<int>& nums, int k) {
        sort(nums.begin(), nums.end());
        int n = nums.size(), m = n / 2;                  // 偶数长度取较大中位数
        long long ans = llabs((long long)nums[m] - k);   // 中位钉死 k
        for (int i = m - 1; i >= 0 && nums[i] > k; --i)  // 左半超标者是连续后缀
            ans += (long long)nums[i] - k;
        for (int i = m + 1; i < n && nums[i] < k; ++i)   // 右半不足者是连续前缀
            ans += (long long)k - nums[i];
        return ans;
    }
};
```

### Python

```python
class Solution:
    def minOperationsToMakeMedianK(self, nums: List[int], k: int) -> int:
        nums.sort()
        m = len(nums) // 2                                 # 偶数长度取较大中位数
        ans = abs(nums[m] - k)                             # 中位钉死 k
        ans += sum(x - k for x in nums[:m] if x > k)       # 左半超标压回 k
        ans += sum(k - x for x in nums[m + 1:] if x < k)   # 右半不足抬到 k
        return ans
```

## 8. 边界情况与易错点

1. **「只改中位下标」陷阱**（示例 1）：改完重排后中位可能「换人」——左半 $> k$ 的元素会顶上来、右半 $< k$ 的会压下去；必须按三段完整定价，缺一段就错。
2. **偶数长度的 $m$**：题目取较大中位数 ⟹ $m = n/2$（0-indexed）。若口径换成较小中位数则 $m = n/2 - 1$：$a = [1,10]$、$k = 1$ 时两种口径的答案分别是 $9$ 与 $0$，天差地别。
3. **$n = 1$**：$m = 0$，左右两段为空，答案就是 $\lvert \text{nums}[0] - k \rvert$，代码无需特判。
4. **溢出**：答案上界约 $2 \times 10^5 \times 10^9 = 2 \times 10^{14}$，C++/Java 必须 `long long` / `long`；单次差值不溢 `int`，但累加器必须 64 位。
5. **提前 break 的方向**：左半向左扫、右半向右扫，写反会把该算的漏掉；好在全扫 $O(n)$ 同样正确，break 只是常数剪枝，赛场上不确定就全扫。
6. **退化情形**：$k$ 小于全部元素 ⟹ 左半整段超标（加上中位降幅）；$k$ 大于全部元素 ⟹ 右半整段不足；中位已等于 $k$ 且两侧不越界（示例 3）⟹ 答案 0。均被公式自然覆盖，无需特判。
