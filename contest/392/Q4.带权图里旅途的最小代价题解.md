# LeetCode 带权图里旅途的最小代价 题解

## 1. 题目概述

- **标题 / 题号**：带权图里旅途的最小代价（#3108，hard）
- **链接**：https://leetcode.cn/problems/minimum-cost-walk-in-weighted-graph/
- **来源**：LeetCode 第 392 场周赛 Q4
- **难度**：困难
- **标签**：位运算、并查集、图、数组

**题意**：给定 $n$ 个节点的带权无向图（编号 $0 \sim n-1$），`edges[i] = [u_i, v_i, w_i]` 表示 $u_i$、$v_i$ 之间有一条权值为 $w_i$ 的无向边。一趟**旅途**（walk）是节点与边交替的序列，起点、终点均为图中的节点，且**可以重复经过同一条边、同一个节点**。若旅途依次经过的边权为 $w_0, w_1, \dots, w_k$，则这趟旅途的**代价**定义为 $w_0 \,\&\, w_1 \,\&\, \cdots \,\&\, w_k$（按位与）。给定查询数组 `query[i] = [s_i, t_i]`，对每个查询求从 $s_i$ 出发、在 $t_i$ 结束的旅途的**最小代价**；不存在这样的旅途则答案为 $-1$。

**约束**：

- $1 \le n \le 10^5$
- $0 \le \text{edges.length} \le 10^5$，$u_i \ne v_i$，$0 \le w_i \le 10^5$
- $1 \le \text{query.length} \le 10^5$，$0 \le s_i, t_i \le n - 1$（**允许 $s_i = t_i$**）

> ⚠️ 两个读题要点：① 代价不是边权**求和**而是按位 **AND**——参与 AND 的边越多，为 1 的二进制位只减不增，最优策略与最短路截然相反；② 「旅途」不是简单路径，**点和边都可以重复经过**，这是本题能一步塌缩到连通性的题眼。另注意 $s_i$ 可以等于 $t_i$，此时**不移动**即是一趟合法旅途（官方口径代价为 $0$，见 §8 的坑位讨论）。

## 2. 示例

**示例 1**

```text
输入：n = 5, edges = [[0,1,7],[1,3,7],[1,2,1]], query = [[0,3],[3,4]]
输出：[1,-1]
解释：查询 [0,3]：走 0→1(权 7)→2(权 1)→1(权 1)→3(权 7)，
      代价 = 7 & 1 & 1 & 7 = 1。
      查询 [3,4]：节点 4 是孤立点，无从 3 到 4 的旅途，答案 -1。
```

**示例 2**

```text
输入：n = 3, edges = [[0,2,7],[0,1,15],[1,2,6],[1,2,1]], query = [[1,2]]
输出：[0]
解释：走 1→2(权 1)→1(权 6)→2(权 1)，代价 = 1 & 6 & 1 = 0；
      再把 7、15 兜圈算进来也仍是 0，而 0 已是非负下界。
```

**补充边界示例**（官方口径，测试数据未覆盖但语义明确）

```text
输入：n = 2, edges = [[0,1,7]], query = [[0,0]]
输出：[0]
解释：s = t 时不需要走任何边（不移动的旅途代价为 0），而不是 7。
```

## 3. 解题思路

### 3.1 暴力思路

对每个查询独立搜索：从 $s$ 出发 BFS，状态为「（当前节点，已走边权 AND 累积值）」，每经一条权为 $w$ 的边就把累积值变换为 $\text{acc} \,\&\, w$，到达 $t$ 时取历史最小。

问题在于状态空间：$w_i \le 10^5 < 2^{17}$，AND 累积值至多 $2^{17}$ 种，总状态数高达 $n \cdot 2^{17} \approx 1.3 \times 10^{10}$，单次查询都不可行，$q$ 高达 $10^5$ 次更是雪上加霜。而且最短路式的松弛也救不了场：AND 不是「可加」度量，状态 $(u, a_1)$ 与 $(u, a_2)$ 之间**没有支配关系**（当前更小的累积值配上更差的后续边，可能反而更差），Dijkstra/BFS 框架全部失效。必须换视角。

### 3.2 核心观察：点边可重复 ⇒ 塌缩到「连通分量 + 全边 AND」

![核心观察：答案塌缩为连通分量与全边 AND](images/wc392_q4_component_and_concept.svg)

**观察 1（下界：多 AND 一条边，代价只小不大）**：任何从 $s$ 到 $t$ 的旅途都走不出 $s$ 所在的连通分量 $C$（旅途每条边的两端同属一个分量，对边数归纳即得），故其经过的边集 $E' \subseteq E_C$。按位 AND 参与的数越多，为 1 的位**只减不增**，因此代价 $\text{AND}(E') \ge \text{AND}(E_C)$——**分量内全部边权的 AND 是任何旅途代价的下界**。

**观察 2（上界：每一脚都踩得到）**：由于点、边可以重复经过，同分量内从 $s$ 到 $t$ 可以构造出**经过每条边至少一次**的旅途（DFS 树「下去—回来」+ 非树边折返，构造与证明见 §5 引理 2）。这趟旅途把分量内的边全部 AND 了一遍，代价恰为 $\text{AND}(E_C)$——**下界可以取到**。

两个观察一夹，结论水落石出：

$$s \ne t \text{ 且同分量} \;\Rightarrow\; \text{最小代价} = \text{AND}(E_C)$$

> 💡 二进制视角更好记：答案的第 $b$ 位为 $1$，当且仅当分量内**每一条边**的第 $b$ 位都是 $1$；只要有一条边该位是 $0$，就绕过去「踩一脚」，把这一位清掉。示例 1 里 $7\,\&\,7\,\&\,1 = 1$ 正是因为那条权 $1$ 的边把高两位清零了。

**观察 3（查询只看「分量 + 是否同点」）**：$s$、$t$ 属于不同分量 ⇒ 无旅途 ⇒ $-1$；$s = t$ ⇒ 不移动即是一趟旅途 ⇒ $0$（官方口径，见 §8）；其余 ⇒ $\text{AND}(E_C)$。

于是整道题塌缩成两件事：**判连通** + **每个分量维护边权 AND**——正是并查集的主场。

### 3.3 算法流程

![算法流程：两遍扫边与查询三分支](images/wc392_q4_query_flow.svg)

整体三步：

1. 初始化 `comp_and[i] = -1`——补码全 1，是 AND 的**单位元**；
2. **第一遍**扫边只做 `union`，把连通分量结构搭好；
3. **第二遍**扫边 `comp_and[find(u)] &= w`，把每条边权 AND 进所在分量的根上。

最后逐查询三分支判定：$s = t$ 返回 $0$；`find(s) != find(t)` 返回 $-1$；否则返回 `comp_and[find(s)]`。

### 3.4 示例演算

![示例演算：示例 1 与示例 2](images/wc392_q4_example_walkthrough.svg)

**示例 1**（$n = 5$）：分量 $\{0,1,2,3\}$ 边权 $\{7,7,1\}$，全边 AND $= 7 \,\&\, 7 \,\&\, 1 = 1$；节点 $4$ 孤立。

| 查询 | 判定 | 计算 | 答案 |
|------|------|------|------|
| `[0,3]` | 同分量、$s \ne t$ | $\text{AND}(\{7,7,1\}) = 1$ | $1$ |
| `[3,4]` | 异分量（4 孤立） | 无旅途 | $-1$ |

其中 `[0,3]` 的一趟最优旅途：$0 \to 1\,(7) \to 2\,(1) \to 1\,(1) \to 3\,(7)$，代价 $7 \,\&\, 1 \,\&\, 1 \,\&\, 7 = 1$，与全边 AND 吻合。

**示例 2**（$n = 3$）：分量 $\{0,1,2\}$ 边权 $\{7,15,6,1\}$（注意 $1$–$2$ 间有**重边**），全边 AND $= 0111_2 \,\&\, 1111_2 \,\&\, 0110_2 \,\&\, 0001_2 = 0$。

| 查询 | 判定 | 计算 | 答案 |
|------|------|------|------|
| `[1,2]` | 同分量、$s \ne t$ | $\text{AND}(\{7,15,6,1\}) = 0$ | $0$ |

一趟兑现旅途：$1 \to 2\,(1) \to 1\,(6) \to 2\,(1)$，代价 $1 \,\&\, 6 \,\&\, 1 = 0$，已是非负下界。重边在此毫无影响——AND 幂等，一条边 AND 多少次都一样。

## 4. 算法细节

1. **初值 $-1$ 是 AND 单位元**：`comp_and` 初值取 $-1$（补码全 1），与任何 $w$ 相 AND 结果仍为 $w$，保证「没累加过边」时值不受污染。孤立点分量保持 $-1$，但三分支判定下这个值**永远不会被返回**（$s = t$ 走 $0$ 分支、$s \ne t$ 走 $-1$ 分支），天然安全。
2. **两遍扫边必须分开**：若在合并的同时累加 AND，两个分量合并时会**丢掉被吞并一方根上的历史累积值**。替代写法是合并时显式融合 `comp_and[ry] = comp_and[rx] & comp_and[ry] & w`，一遍扫完；但「先合并完、再统一累加」的两遍写法最不易错，赛场优先。
3. **$s = t$ 特判返回 $0$**：官方题解明确「不移动时的旅途代价是 $0$」。例如 $n = 2$、`edges = [[0,1,7]]`、`query = [[0,0]]` 的正确答案是 $0$ 而非 $7$（详见 §8）。
4. **并查集实现**：路径压缩（递归或迭代）必加；按秩合并可选，叠加后单次操作均摊 $O(\alpha(n))$。$n \le 10^5$ 递归深度可控。
5. **值域**：$w \le 10^5 < 2^{17}$，AND 结果仍在该值域内，`int` 足够，无溢出问题。
6. **接口**：LeetCode 签名为 `vector<int> minimumCost(int n, vector<vector<int>>& edges, vector<vector<int>>& query)`。

## 5. 正确性证明

**引理 1（AND 的幂等与单调）**：对任意非负整数 $x$ 有 $x \,\&\, x = x$；对有限非负整数集 $S \subseteq T$，有 $\text{AND}(S) \ge \text{AND}(T)$。

**证明**：幂等显然。单调性按位论证：$\text{AND}(T)$ 的第 $b$ 位为 $1$，当且仅当 $T$ 中**所有**数的第 $b$ 位都是 $1$；此时 $S \subseteq T$ 中所有数的第 $b$ 位也都是 $1$，故 $\text{AND}(S)$ 的第 $b$ 位为 $1$。即 $\text{AND}(T)$ 为 $1$ 的位集是 $\text{AND}(S)$ 为 $1$ 的位集的子集，数值上 $\text{AND}(S) \ge \text{AND}(T)$。∎

**引理 2（全边覆盖旅途的存在性）**：设 $G = (V, E)$ 连通且 $|E| \ge 1$，$s, t \in V$（可以相同），则存在从 $s$ 到 $t$、**经过每条边至少一次**的旅途。

**证明**：以 $s$ 为根对 $G$ 做 DFS，得生成树 $T$。构造从 $s$ 出发的闭游走 $W$：按 DFS 访问顺序遍历——每条**树边**在「进入子树」与「回溯」时**各经过一次**；每条**非树边** $(u, v)$ 在首次抵达端点 $u$ 时以 $u \to v \to u$ 的**折返**经过。$W$ 从 $s$ 出发、最终回到 $s$，且每条边至少被经过一次（树边、非树边各恰两次）。$W$ 结束后，再从 $s$ 沿 $T$ 中唯一的树路径走到 $t$。两段拼接是合法旅途（旅途允许重复），且经过的边集包含 $E$ 中每条边。∎

![可达性构造：DFS 树折返游走](images/wc392_q4_euler_construction.svg)

> 💡 引理 2 的另一条证明路径：把每条无向边拆成两条**有向弧** $(u \to v)$、$(v \to u)$，则每个节点的入度 $=$ 出度 $=$ 原度数，且所有弧弱连通，故该有向图存在**欧拉回路**——从 $s$ 出发沿欧拉回路回到 $s$，再走到 $t$ 即可。

**定理**：对查询 $[s, t]$，最小旅途代价为：

1. $s$ 与 $t$ 属于不同连通分量（此时必有 $s \ne t$）：$-1$；
2. $s = t$：$0$；
3. $s \ne t$ 且同属分量 $C$（边集 $E_C \ne \varnothing$）：$\text{AND}(E_C)$。

**证明**：

(1) 对旅途的边数归纳：$0$ 条边时起点即终点，同点必同分量；若前 $k$ 条边构成的旅途从 $s$ 走到 $v$，由归纳假设 $s, v$ 同分量，而第 $k+1$ 条边 $(v, t)$ 的两端同分量，故 $s, t$ 同分量。因此不同分量间不存在旅途，答案 $-1$。

(2) 不移动（$0$ 条边）即是一趟从 $s$ 到 $s$ 的旅途，代价为 $0$；又边权非负 ⇒ 任何旅途的代价都是非负整数，$0$ 已是最小。

(3) **下界**：从 $s$ 到 $t$（$s \ne t$）的旅途至少经过一条边，且边集 $E' \subseteq E_C$，由引理 1，代价 $= \text{AND}(E') \ge \text{AND}(E_C)$。**上界**：由引理 2，存在经过边集 $E'' \supseteq E_C$ 的旅途，由引理 1（取 $S = E_C \subseteq T = E''$），其代价 $= \text{AND}(E'') \le \text{AND}(E_C)$。两向夹逼，最小代价 $= \text{AND}(E_C)$。∎

## 6. 复杂度分析

- **时间复杂度**：$O\bigl((n + m + q) \cdot \alpha(n)\bigr)$，其中 $m$、$q$ 为 `edges`、`query` 的长度，$\alpha$ 为反阿克曼函数。并查集初始化 $O(n)$；两遍扫边各 $m$ 次近似 $O(1)$ 的合并/查找；$q$ 次查询各常数次 `find`。$n, m, q \le 10^5$，总量约 $4 \times 10^5$ 次近似常数操作。
- **空间复杂度**：$O(n)$：并查集数组 `pa`（含按秩数组 `rk`）与分量 AND 数组 `comp_and` 均长 $n$（返回值不计）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> minimumCost(int n, vector<vector<int>>& edges, vector<vector<int>>& query) {
        vector<int> pa(n), rk(n, 0);
        iota(pa.begin(), pa.end(), 0);
        function<int(int)> find = [&](int x) -> int {
            return pa[x] == x ? x : pa[x] = find(pa[x]);
        };
        for (auto& e : edges) {                        // 第一遍：只管合并
            int a = find(e[0]), b = find(e[1]);
            if (a != b) {
                if (rk[a] < rk[b]) swap(a, b);
                pa[b] = a;
                if (rk[a] == rk[b]) rk[a]++;
            }
        }
        vector<int> compAnd(n, -1);                    // -1 = 全 1，AND 单位元
        for (auto& e : edges) compAnd[find(e[0])] &= e[2];  // 第二遍：边权 AND 进根
        vector<int> ans;
        ans.reserve(query.size());
        for (auto& q : query) {
            if (q[0] == q[1])                          // 不移动，代价 0（官方口径）
                ans.push_back(0);
            else if (find(q[0]) != find(q[1]))         // 无旅途
                ans.push_back(-1);
            else
                ans.push_back(compAnd[find(q[0])]);
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def minimumCost(self, n: int, edges: List[List[int]], query: List[List[int]]) -> List[int]:
        pa = list(range(n))

        def find(x: int) -> int:
            while pa[x] != x:
                pa[x] = pa[pa[x]]                      # 路径折叠
                x = pa[x]
            return x

        for u, v, _ in edges:                          # 第一遍：只管合并
            pa[find(u)] = find(v)
        comp_and = [-1] * n                            # -1 = 二进制全 1，AND 单位元
        for u, _, w in edges:                          # 第二遍：边权 AND 进根
            comp_and[find(u)] &= w

        ans = []
        for s, t in query:
            if s == t:                                 # 不移动，代价 0（官方口径）
                ans.append(0)
            elif find(s) != find(t):                   # 无旅途
                ans.append(-1)
            else:
                ans.append(comp_and[find(s)])
        return ans
```

## 8. 边界情况与易错点

1. **$s = t$ 必须特判返回 $0$**（最大的坑）：官方题解明确「当 $s = t$ 时，不移动时的旅途代价是 $0$」。本题**测试数据较弱**——不写此特判、直接返回 `comp_and[find(s)]`（即分量 AND，孤立点为 $-1$）也能 AC，不少赛后题解因此漏掉这个分支；但按题意，`n = 2, edges = [[0,1,7]], query = [[0,0]]` 的正确答案是 $0$ 而非 $7$，孤立点自环查询应为 $0$ 而非 $-1$。按官方口径补上 `if (s == t) return 0;` 才是完备解。
2. **初值不能用 0**：$0$ 会把任何 AND 结果污染成 $0$；必须用 $-1$（二进制全 1）作 AND 单位元。
3. **两遍扫边别合成一遍**：边合并边累加会丢被吞并一方的累积 AND；一定要一遍写，必须在合并时做 `comp_and[ry] &= comp_and[rx] & w` 的融合。
4. **孤立点与空图**：$m = 0$ 时全部点孤立，`comp_and` 保持 $-1$；三分支判定下查询只会得到 $0$（$s = t$）或 $-1$，无需特判。
5. **AND 不是最短路**：不要条件反射上 Dijkstra——$(u, a_1)$ 与 $(u, a_2)$ 之间无支配关系，松弛不成立。图上聚合问题先问「边能不能重复」，往往直接决定难度档位。
6. **重边**：题目允许重边（示例 2 的 $1$–$2$ 就是），AND 幂等，重复边无影响；$u_i \ne v_i$ 保证无自环。
7. **无溢出**：$w \le 10^5 < 2^{17}$，全程 `int` 即可，无需 64 位。
