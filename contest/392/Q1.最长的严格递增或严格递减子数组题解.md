# LeetCode 最长的严格递增或严格递减子数组 题解

## 1. 题目概述

- **标题 / 题号**：最长的严格递增或严格递减子数组（#3105，easy）
- **链接**：https://leetcode.cn/problems/longest-strictly-increasing-or-strictly-decreasing-subarray/
- **来源**：LeetCode 第 392 场周赛 Q1
- **难度**：简单
- **标签**：数组、动态规划、一次遍历

**题意**：给定整数数组 `nums`，返回其中**最长非空子数组**的长度，要求该子数组是**严格递增**或**严格递减**的。子数组必须是数组中**连续**的一段。

**约束**：

- $1 \le \text{nums.length} \le 50$
- $1 \le \text{nums}[i] \le 50$

> 💡 读题三个关键词，签到题的最短路径全在这里：**子数组**（连续，不是子序列——别条件反射写 LIS）、**严格**（相邻相等即断裂，`[3,3]` 两个方向都不合法）、**或**（增、减两个方向取并集，一次遍历要同时照顾两边）。

## 2. 示例

**示例 1**

```text
输入：nums = [1,4,3,3,2]
输出：2
解释：最长严格递增子数组 [1,4]，最长严格递减子数组 [4,3] 与 [3,2]，长度均为 2。
```

**示例 2**

```text
输入：nums = [3,3,3,3]
输出：1
解释：相邻元素全部相等，长度大于 1 的子数组既不严格递增也不严格递减，退化为单元素。
```

**示例 3**

```text
输入：nums = [3,2,1]
输出：3
解释：整个数组本身就是严格递减子数组。
```

## 3. 解题思路

### 3.1 暴力思路

枚举全部 $O(n^2)$ 个子数组，每个花 $O(n)$ 检查是否严格单调，总代价 $O(n^3) \approx 1.25 \times 10^5$ 次比较，$n \le 50$ 完全能过；固定左端点、方向一断就停的写法还能降到 $O(n^2)$。比赛中求稳交一发暴力也没问题。

但暴力重复比较了太多相邻对：一段长度为 $L$ 的单调段，被它的 $O(L^2)$ 个子段各自从头验证了一遍。**单调性只在相邻两个元素比较时才会断裂**——抓住这个局部性，就能一次遍历 $O(n)$ 解决。

### 3.2 核心观察：inc / dec 双计数器一次遍历

![核心概念：inc/dec 双计数器并行接龙](images/wc392_q1_dual_counter_concept.svg)

定义两个滚动变量：

- `inc`：**以 i 结尾**的最长**严格递增**子数组长度；
- `dec`：**以 i 结尾**的最长**严格递减**子数组长度。

只看相邻两个元素 `nums[i]` 与 `nums[i-1]`，转移恰好三路：

| 比较 | 转移 | 含义 |
|------|------|------|
| `nums[i] > nums[i-1]` | `inc += 1`，`dec = 1` | 递增段接龙；递减段断裂，退化为单元素 |
| `nums[i] < nums[i-1]` | `dec += 1`，`inc = 1` | 递减段接龙；递增段断裂 |
| `nums[i] == nums[i-1]` | `inc = dec = 1` | **严格**单调不容相等，两个方向同时断裂 |

最终答案为全程 $\max(\text{inc}, \text{dec})$ 的历史最大值。

**为什么相等必须双重置**？`[3,3]` 往任一方向延伸一步都是 `=`，既不满足 `>` 也不满足 `<`，两个方向的单调性**同时**被破坏。只重置一个计数器，就会在全等数组（示例 2）上错误地输出 2。

### 3.3 算法流程

![算法流程图：三路比较转移，max 打擂台](images/wc392_q1_algorithm_flow.svg)

1. `ans = inc = dec = 1`（单元素自身就是长度 1 的合法段，同时兜底 $n = 1$）；
2. `i` 从 $1$ 到 $n-1$：按上表三路转移 `inc` / `dec`；
3. 每轮 `ans = max(ans, inc, dec)` 打擂台；
4. 遍历结束返回 `ans`。

### 3.4 示例演算

![示例演算：nums=[1,4,3,3,2] 的逐步轨迹](images/wc392_q1_example_walkthrough.svg)

以 `[1,4,3,3,2]` 为例（逐步轨迹见上图）：

| i | nums[i] | 与前一位比较 | inc | dec | ans |
|---|---------|--------------|-----|-----|-----|
| 0 | 1 | —（初始） | 1 | 1 | 1 |
| 1 | 4 | `4 > 1` ↑ | **2** | 1 | **2** |
| 2 | 3 | `3 < 4` ↓ | 1 | **2** | 2 |
| 3 | 3 | `3 == 3` ✕ | 1 | 1 | 2 |
| 4 | 2 | `2 < 3` ↓ | 1 | **2** | 2 |

五步三起三落：`>` 把 inc 顶到 2；`<` 让 dec 接棒到 2；`＝` 把两个计数器同时打回 1；最后一个 `<` 又把 dec 拉回 2。`ans` 靠打擂台记下历史峰值 **2**，中间的断裂不会抹掉已拿到的最优。示例 3 `[3,2,1]` 则是连续两个 `<`，dec 一路 $1 \to 2 \to 3$ 无断裂，答案 **3**。

## 4. 算法细节

1. **状态对称**：`inc` / `dec` 是"以 i 结尾"两个方向的镜像状态，数组倒过来两者互换；写好一个方向的转移，另一方向照抄即可，不易出错。
2. **DP 压缩**：转移只依赖上一位的计数器值，DP 数组可压成两个滚动变量，空间 $O(1)$。
3. **打擂台必须在循环内**：最长段不一定以最后一位结尾（示例 1 结束时 `inc = dec = 1`，答案却是 2），`ans` 必须逐轮更新，不能等循环结束后再取。
4. **不变量 $\min(\text{inc}, \text{dec}) \equiv 1$**：由转移表，`>` 后 `dec = 1`，`<` 后 `inc = 1`，`=` 后双双为 1，初值又全为 1——任一时刻至多一个方向在接龙，因此 `max(inc, dec)` 恰是"以 i 结尾的最长合法段"，两个变量就足够，无需更多状态。
5. **接口名**：LeetCode 函数签名为 `longestMonotonicSubarray(vector<int>& nums)`。

## 5. 正确性证明

**引理 1**：子数组 `nums[l..r]` 严格递增，当且仅当对所有 $l \le k < r$ 有 `nums[k] < nums[k+1]`；严格递减同理（不等号反向）。

**证明**：必要性显然。充分性由 `<` 的传递性：任取 $l \le i < j \le r$，链式传递得 `nums[i] < nums[j]`。∎

**引理 2（循环不变量）**：处理完下标 $i$ 后，`inc` / `dec` 分别等于以 $i$ 结尾的最长严格递增 / 递减子数组长度，且 $\min(\text{inc}, \text{dec}) = 1$。

**证明**：对 $i$ 归纳。$i = 0$ 时初值 `inc = dec = 1`：单元素自身既是长度 1 的递增段也是长度 1 的递减段，成立。设结论对 $i-1$ 成立，考虑 `nums[i]` 与 `nums[i-1]`：

- 若 `nums[i] > nums[i-1]`：以 $i$ 结尾的递增子数组若长度 $\ge 2$，由连续性其倒数第二位必为 $i-1$；再由引理 1，它等价于"以 $i-1$ 结尾的递增段拼上 `nums[i]`"，故最长值为 $\text{inc}_{i-1} + 1$（长度 1 的情形也被覆盖，因 $\text{inc}_{i-1} + 1 \ge 2$）。而以 $i$ 结尾、长度 $\ge 2$ 的递减子数组要求 `nums[i] < nums[i-1]`，与前提矛盾，故递减方向最长为 1。
- 若 `nums[i] < nums[i-1]`：与上一情形完全镜像。
- 若 `nums[i] == nums[i-1]`：长度 $\ge 2$ 的递增段要求末步为 `>`、递减段要求末步为 `<`，均与前提矛盾，两个方向最长都为 1。

三种情形转移后均有 $\min(\text{inc}, \text{dec}) = 1$。∎

**定理**：算法返回 `nums` 中最长严格递增或严格递减子数组的长度。

**证明**：任一非空子数组以其右端点 $i$ 结束，其合法性由引理 1 完全由相邻比较决定；引理 2 说明处理完 $i$ 后 $\max(\text{inc}, \text{dec})$ 恰为以 $i$ 结尾的最长合法段长度。而全局答案 $= \max_{0 \le i < n}$（以 $i$ 结尾的最长合法段），算法恰在每轮循环内用 `ans = max(ans, inc, dec)` 取到了这个最大值。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。每个元素只与前一位比较一次，三路转移与打擂台均为 $O(1)$。
- **空间复杂度**：$O(1)$。仅 `ans` / `inc` / `dec` 三个滚动变量，是 DP 数组压缩后的结果。

> 💡 本题 $n \le 50$，$O(n^2)$ 暴力同样能过；但 $O(n)$ / $O(1)$ 的滚动写法不依赖数据范围，数据放大到 $10^6$ 也照跑，是这类"相邻符号"题的标准答案，比赛中按此模板写最稳。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int longestMonotonicSubarray(vector<int>& nums) {
        int ans = 1, inc = 1, dec = 1;
        for (int i = 1; i < (int)nums.size(); ++i) {
            if (nums[i] > nums[i - 1]) {
                ++inc;
                dec = 1;
            } else if (nums[i] < nums[i - 1]) {
                ++dec;
                inc = 1;
            } else {
                inc = dec = 1;   // 严格单调不容相等，双双重开
            }
            ans = max(ans, max(inc, dec));
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def longestMonotonicSubarray(self, nums: List[int]) -> int:
        ans = inc = dec = 1
        for a, b in zip(nums, nums[1:]):   # a = nums[i-1], b = nums[i]
            if a < b:
                inc, dec = inc + 1, 1
            elif a > b:
                dec, inc = dec + 1, 1
            else:
                inc = dec = 1              # 相等：两个方向同时断裂
            ans = max(ans, inc, dec)
        return ans
```

## 8. 边界情况与易错点

1. **$n = 1$**：循环体不执行，初值 1 恰好兜底，答案 1；`ans` 初值不能取 0（子数组非空）。
2. **全等数组**（`[3,3,3,3]`）：`＝` 分支双双重置，答案 1；漏掉任一侧的重置就会输出 2。
3. **严格 vs 非严格**：相等既不是递增也不是递减，不能并入任何一边续接龙。
4. **打擂台位置**：`ans` 更新必须放在循环体内；放到循环后会漏掉"峰值不在末尾"的情况（示例 1 结束时两个计数器都是 1）。
5. **别套 LIS**：本题是**子数组**（连续），与最长递增**子序列**（可跳选、$O(n\log n)$ 那套）是两回事，读题先分辨"子数组 / 子序列"。
6. **无溢出风险**：长度不超过 50，`int` 足够；无需 `long long`。
