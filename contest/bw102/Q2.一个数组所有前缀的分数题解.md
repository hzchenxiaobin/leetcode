# LeetCode 一个数组所有前缀的分数 题解

## 1. 题目概述

- **标题 / 题号**：一个数组所有前缀的分数（#2640，medium）
- **链接**：https://leetcode.cn/problems/find-the-score-of-all-prefixes-of-an-array/
- **来源**：LeetCode 第 102 场双周赛 Q2
- **难度**：中等
- **标签**：数组、前缀和

**题意**：定义数组 `arr` 的**转换数组** `conver`：$conver[i] = arr[i] + \max(arr[0..i])$（前缀最大值）；定义数组的**分数**为转换数组所有元素之和。给定长度为 $n$ 的数组 `nums`，返回长度为 $n$ 的数组 `ans`，其中 $ans[i]$ 是**前缀** $nums[0..i]$ 的分数。

**约束**：

- $1 \le nums.length \le 10^5$
- $1 \le nums[i] \le 10^9$

## 2. 示例

**示例 1**

```text
输入：nums = [2,3,7,5,10]
输出：[4,10,24,36,56]
解释：
前缀 [2]      的 conver = [4]          → 分数 4
前缀 [2,3]    的 conver = [4,6]        → 分数 10
前缀 [2,3,7]  的 conver = [4,6,14]     → 分数 24
前缀 [2,3,7,5] 的 conver = [4,6,14,12] → 分数 36
全数组         的 conver = [4,6,14,12,20] → 分数 56
```

**示例 2**

```text
输入：nums = [1,1,2,4,8,16]
输出：[2,4,8,16,32,64]
解释：前缀最大值与元素本身同步翻倍，conver[i] = 2·nums[i]，分数每次翻倍。
```

**示例 3（边界补充）**

```text
输入：nums = [1000000000]
输出：[2000000000]
解释：单个元素的 conver = [2×10⁹]，已超出 int32 范围。
```

## 3. 解题思路

### 3.1 暴力思路

对每个 $i$ 独立计算：扫一遍 $nums[0..i]$ 求前缀最大，再扫一遍累加 $conver[j] = nums[j] + \max(nums[0..j])$，共 $O(n^2)$。$n = 10^5$ 时约 $10^{10}$ 次操作，必然超时。观察浪费在哪里：从 $i-1$ 到 $i$，前缀只多了**一个元素**，前缀最大值与分数都只发生"增量式"变化——重复计算的关键正是这两个量。

### 3.2 核心观察：conver 的前缀和结构，一遍扫维护两个量

![核心观察：转换值等于元素加前缀最大，分数是转换数组的前缀和](images/bw102_q2_conver_concept.svg)

把定义式展开，第 $i$ 个位置的转换值只依赖两个**可增量维护**的量：

$$conver[i] = nums[i] + \max(nums[0..i])$$

- $\max(nums[0..i]) = \max\big(\max(nums[0..i-1]),\ nums[i]\big)$——**前缀最大**只需与当前元素取一次 max；
- $ans[i] = \sum_{j \le i} conver[j] = ans[i-1] + conver[i]$——**分数是 conver 的前缀和**，每步只加一项。

两个滚动变量 `runMax`、`score` 就把 $O(n^2)$ 压成 $O(n)$。

> ⚠️ **读题别读岔**：分数是 $\sum_j \big(nums[j] + \max_j\big)$，即 $nums$ 的前缀和 + 前缀最大值的前缀和；**不是** $\max(nums[0..i]) \times (i+1) - \text{sum}(nums[0..i])$ 那类"最大值重复计数"的公式。用示例 1 验算 $i = 2$：$4 + 6 + 14 = 24$ ✓。

### 3.3 算法流程

![算法流程：一遍扫描，同步维护 runMax 与 score](images/bw102_q2_onepass_flow.svg)

```text
1. runMax = 0（nums[i] ≥ 1 > 0，初值 0 安全），score = 0
2. 对 i = 0, 1, …, n-1：
       runMax = max(runMax, nums[i])      # 前缀最大
       score += runMax + nums[i]          # 累加 conver[i]
       ans[i] = score
3. 返回 ans
```

### 3.4 示例演算

![示例演算：nums、runMax、conver、ans 四行对照](images/bw102_q2_example_walkthrough.svg)

以示例 1（$nums = [2,3,7,5,10]$）为例：

| $i$ | $nums[i]$ | $runMax$ | $conver[i] = nums[i] + runMax$ | $score$（即 $ans[i]$） |
|-----|-----------|----------|-------------------------------|------------------------|
| 0 | 2 | 2 | 4 | 4 |
| 1 | 3 | 3 | 6 | 10 |
| 2 | 7 | 7 | 14 | 24 |
| 3 | 5 | 7 | 12 | 36 |
| 4 | 10 | 10 | 20 | 56 |

输出 `[4,10,24,36,56]`。✅ 注意 $i = 3$ 处 $runMax$ 保持 7 不变（元素 5 小于前缀最大），$conver[3] = 5 + 7 = 12$。

以示例 2（$nums = [1,1,2,4,8,16]$）为例：每个新元素都刷新前缀最大，$conver[i] = 2 \cdot nums[i]$，分数依次 $2, 4, 8, \dots, 64$，恰好逐项翻倍。✅

## 4. 算法细节

1. **初值的选取**：`runMax = 0` 依赖 $nums[i] \ge 1$ 的约束；更稳的写法是 `runMax = nums[0]` 起步（或用极小值初始化），在变体题（允许负数）里不会踩坑。
2. **conver 不必显式存**：$conver[i]$ 用完即弃，直接把 `runMax + nums[i]` 加进 `score`，省一个 $O(n)$ 数组；需要输出 conver 数组的变体再存。
3. **$ans$ 的递推式**：$ans[i] = ans[i-1] + nums[i] + runMax$，一步一写，无需两次遍历。
4. **溢出是本题真正的陷阱**：$nums[i] \le 10^9$，$conver[i] \le 2 \times 10^9$ **超过 int32**（$2^{31} - 1 \approx 2.147 \times 10^9$）；$ans$ 累计到 $n \cdot 2 \times 10^9 \approx 2 \times 10^{14}$。C++ 全程 `long long`，返回类型 `vector<long long>`；Python 天然大整数无此虞。
5. **"分数"概念的独立性**：$ans[i]$ 与 $ans[i-1]$ 只差一个 conver 项，说明分数满足前缀和的增量性——任何"每个前缀的聚合值"问法都先找这种增量结构。

## 5. 正确性证明

**引理 1（前缀最大的递推）**：记 $M[i] = \max(nums[0..i])$，则 $M[0] = nums[0]$，且 $M[i] = \max(M[i-1], nums[i])$。

**证明**：$nums[0..i] = nums[0..i-1] \cup \{nums[i]\}$，有限集的最大值满足 $\max(A \cup \{x\}) = \max(\max A, x)$；归纳即得。∎

**引理 2（分数的增量递推）**：记 $S[i] = \sum_{j=0}^{i} conver[j]$（即前缀 $[0..i]$ 的分数），则 $S[i] = S[i-1] + nums[i] + M[i]$（约定 $S[-1] = 0$）。

**证明**：$S[i] - S[i-1] = conver[i] = nums[i] + M[i]$，由定义式直接展开。∎

**定理**：一遍扫描后 `ans[i] = S[i]`，即算法返回每个前缀的分数。

**证明**：归纳。循环不变量：处理完下标 $i$ 后，`runMax` $= M[i]$ 且 `score` $= S[i]$。基础：$i = 0$ 时 `runMax = max(0, nums[0]) = nums[0] = M[0]`（用到 $nums[0] \ge 1 > 0$），`score = 0 + nums[0] + M[0] = S[0]`。归纳步：由引理 1，更新后的 `runMax` $= \max(M[i-1], nums[i]) = M[i]$；由引理 2，`score` 增加的正是 $nums[i] + M[i]$，故 `score` $= S[i-1] + nums[i] + M[i] = S[i]$。`ans[i]` 在循环内取自 `score`，得证。∎

## 6. 复杂度分析

- **时间**：$O(n)$。每个元素一次比较、一次加法、一次赋值；$n \le 10^5$ 毫无压力。
- **空间**：$O(1)$ 额外（不计输出数组 `ans` 的 $O(n)$）。两个滚动标量即可，conver 数组无需保留。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<long long> findPrefixScore(vector<int>& nums) {
        int n = nums.size();
        vector<long long> ans(n);
        long long runMax = 0, score = 0;
        for (int i = 0; i < n; ++i) {
            runMax = max(runMax, (long long)nums[i]);  // nums[0..i] 的最大值
            score += runMax + nums[i];                 // 累加 conver[i]
            ans[i] = score;                            // ans[i] = Σ conver[0..i]
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def findPrefixScore(self, nums: list[int]) -> list[int]:
        ans, run_max, score = [], 0, 0
        for x in nums:
            run_max = max(run_max, x)       # nums[0..i] 的最大值
            score += run_max + x            # 累加 conver[i] = nums[i] + 前缀最大
            ans.append(score)               # ans[i] = conver[0..i] 之和
        return ans
```

> 💡 两份代码均通过官方示例（`[4,10,24,36,56]`、`[2,4,8,16,32,64]`）与单元素 $10^9$ 边界（输出 `[2000000000]`），并与"每个前缀按定义重算 conver"的 $O(n^2)$ 暴力对拍 2004 组随机数据（C++ 与 Python 双侧交叉核对），`mismatch = 0`；另以 $n = 10^5$ 全 $10^9$ 做了溢出压力测试（末项 $2 \times 10^{14}$，符合手算）。

## 8. 边界情况与易错点

1. **conver 溢出 int32**：$2 \times 10^9$ 超出 `int` 上界，C++ 中 `score`、`runMax`、返回数组都必须是 `long long`；只把返回类型改对而中间量仍是 `int` 是常见翻车点。
2. **读题偏差**：分数是"conver 数组之和"，不是"前缀最大 × 长度 − 前缀和"之类的变体；动手前用示例 1 的 $i = 2$（答案 24）核一遍自己的公式。
3. **`runMax` 初值**：本题 $nums[i] \ge 1$，用 0 初始化安全；变体允许负数时必须用首元素或 $-\infty$ 起步。
4. **前缀从 $i = 0$ 开始**：$ans[0] = 2 \cdot nums[0]$，别漏掉首个元素或把 $ans$ 长度写成 $n - 1$。
5. **递增数组的特殊性**：示例 2 那种严格递增输入让 $conver[i] = 2 nums[i]$，容易让人误以为存在更巧的封闭公式——一般输入（示例 1 的第 4 位）立即打破这种错觉，验证时优先混入非递增数据。
6. **返回类型标注**：LeetCode 接口是 `long[]`（C++ `vector<long long>`），Python 侧 `list[int]`；签名不匹配会直接编译/提交失败。
