# LeetCode 设计可以求最短路径的图类 题解

## 1. 题目概述

- **标题 / 题号**：设计可以求最短路径的图类（#2642，hard）
- **链接**：https://leetcode.cn/problems/design-graph-with-shortest-path-calculator/
- **来源**：LeetCode 第 102 场双周赛 Q4
- **难度**：困难
- **标签**：图、设计、最短路、堆（优先队列）

**题意**：实现一个 $n$ 个节点（编号 $0 \sim n-1$）的**有向带权**图类 `Graph`：

- `Graph(int n, vector<vector<int>>& edges)`：用初始边 `edges[i] = [from, to, cost]` 初始化；
- `addEdge(vector<int> edge)`：添加一条有向边（保证添加前两节点间**无同向边**、无自环）；
- `shortestPath(int node1, int node2)`：返回 `node1` 到 `node2` 的最小路径代价，不可达返回 $-1$；路径代价为路径上所有边代价之和。

**约束**：

- $1 \le n \le 100$
- $0 \le edges.length \le n(n-1)$，调用 `addEdge` 至多 100 次、`shortestPath` 至多 100 次
- $1 \le edgeCost \le 10^6$，图中任何时候无重边、无自环

## 2. 示例

**示例 1（官方调用序列）**

```text
输入：
["Graph", "shortestPath", "shortestPath", "addEdge", "shortestPath"]
[[4, [[0,2,5],[0,1,2],[1,2,1],[3,0,3]]], [3,2], [0,3], [[1,3,4]], [0,3]]
输出：[null, 6, -1, null, 6]
解释：
Graph g = new Graph(4, [[0,2,5],[0,1,2],[1,2,1],[3,0,3]]);
g.shortestPath(3, 2); // 6：3 → 0 → 1 → 2，代价 3 + 2 + 1 = 6
g.shortestPath(0, 3); // -1：0 出发到不了 3
g.addEdge([1,3,4]);   // 加边 1 → 3
g.shortestPath(0, 3); // 6：0 → 1 → 3，代价 2 + 4 = 6
```

**示例 2（边界补充）**

```text
输入：["Graph", "shortestPath"]，[[1, []], [0, 0]]
输出：[null, 0]
解释：单节点图，从 0 到 0 的路径代价为 0（空路径）。
```

## 3. 解题思路

### 3.1 暴力思路

把每次查询当独立问题：从当前边表出发，用 **Bellman–Ford** 跑 $n - 1$ 轮全边松弛，$O(nm)$ 一次查询。$n \le 100$、$m \le 9900 + 100$，单次约 $10^6$，100 次查询 $10^8$——勉强能过但难看；且每条边非负，负权松弛轮数优势用不上。正确方向是把"结构"（邻接表）与"查询"（最短路）分开维护，按调用频率选择增量的位置。

### 3.2 方案一（主推）：邻接表 + 每次查询跑堆优化 Dijkstra

![方案一：邻接表建模，查询时跑堆优化 Dijkstra](images/bw102_q4_dijkstra_model.svg)

边权 $edgeCost \ge 1$ 恒正，是 Dijkstra 的标准用武之地：

- **建图 / 加边** $O(1)$：邻接表 `adj[u]` 存 `(v, w)` 二元组，`addEdge` 只是一次 `push_back`；
- **查询** $O\big((n + m)\log n\big)$：从 `node1` 出发，堆里维护 `(dist, u)`，每次弹出最小者向邻点松弛，弹出 `node2` 时即可返回（非负权下**弹出即定型**）。

100 次查询总计约 $100 \times (100 + 10^4) \times \log 100 \approx 7 \times 10^6$，非常宽裕。

### 3.3 方案二（对偶）：Floyd 全源矩阵 + 加边时增量更新

![方案二对比：查询 O(1) 的 Floyd 与加边 O(n²) 增量更新](images/bw102_q4_two_schemes.svg)

反过来把增量放在**加边**一侧：维护全源最短路矩阵 $d[i][j]$。

- **建图**：从边表初始化矩阵后跑一次标准 Floyd，$O(n^3) = 10^6$；
- **加边 $(u, v, w)$** $O(n^2)$：新矩阵 $d'$ 满足 $d'[i][j] = \min\big(d[i][j],\ d[i][u] + w + d[v][j]\big)$——最短路要么不用新边，要么**恰好用一次**新边（简单路径不会把同一条有向边走两遍），两段之外的路径都不含新边，仍是旧最短路（§5 引理 3）；
- **查询** $O(1)$：直接查表，不可达看是否仍为 $\infty$。

两方案把 $O(n^2)$ 级的增量分别放在查询侧与加边侧；本题两边调用都 ≤ 100 次，任意一个都稳过，按口味选择即可。

> 💡 **顺手的剪枝**：加边时若 $w \ge d[u][v]$（新边不比现成的 $u \to v$ 路径短），由旧矩阵的三角不等式 $d[i][j] \le d[i][u] + d[u][v] + d[v][j] \le d[i][u] + w + d[v][j]$，更新不可能改进任何表项，直接 `return`。

### 3.4 示例演算

![示例演算：官方调用序列中两次查询的最短路](images/bw102_q4_example_walkthrough.svg)

**查询 `shortestPath(3, 2)`**（初始边表）：Dijkstra 从 3 出发——$3 \to 0$（代价 3），$0 \to 1$（$3+2=5$），$1 \to 2$（$5+1=6$），弹出 2 时返回 **6**。

**查询 `shortestPath(0, 3)`**（加边前）：0 能到 1、2，均无出边指向 3，堆空返回 **-1**。

**`addEdge([1,3,4])` 后查询 `shortestPath(0, 3)`**：0 → 1 代价 2，新边 1 → 3 代价 4，弹出 3 时总代价 **6**。方案二的矩阵在加边时更新：$d[0][3] = \min(\infty,\ d[0][1] + 4 + d[3][3]) = 2 + 4 + 0 = 6$，查询直接命中。✅

## 4. 算法细节

1. **邻接表的存储**：`vector<vector<pair<int,int>>>`，`(邻点, 边权)`；有向图只存单侧，别顺手建成双向。
2. **堆的"过期条目"**：松弛成功才入堆，同一个点可能多次在堆里；弹出时 `if (d > dist[u]) continue` 丢弃旧条目，这是"懒删除"版 Dijkstra 的标准姿势。
3. **提前终止**：弹出 `node2` 即返回——非负权保证堆顶弹出时距离已定型（§5 引理 2）；`node1 == node2` 时第一次弹出就是答案 0。
4. **无穷大取值（Floyd）**：`LLONG_MAX / 4`（或等价）使 `d[i][u] + w + d[v][j]` 三个数相加不溢出；判不可达用 `>= INF` 而非 `== INF`（更新可能把"无穷"压成略小的巨大值？不会——两个有限数相加不会接近 INF，但用 `>=` 更防御式）。
5. **建图时的重边假设**：构造时直接 `d[from][to] = w` 赋值；题面保证初始无重边，若放开此假设应写成 `d[from][to] = min(d[from][to], w)`（Floyd 版天然兼容，邻接表版 Dijkstra 也自动兼容——重边只是多松弛一次）。
6. **自环无需防御**：题面保证无自环；Dijkstra 遇自环 $u \to u$ 权正也不会影响正确性（松弛 `d + w < d` 恒假）。
7. **两方案的复杂度账本**（$n = 100$、$m \le 10^4$、$q \le 100$ 次查询、$a \le 100$ 次加边）：

| 方案 | 建图 | 加边（每次） | 查询（每次） | 总量级 |
|------|------|-------------|-------------|--------|
| Dijkstra | $O(m)$ | $O(1)$ | $O((n+m)\log n) \approx 7 \times 10^4$ | $q$ 次查询 ≈ $7 \times 10^6$ |
| Floyd | $O(n^3) = 10^6$ | $O(n^2) = 10^4$ | $O(1)$ | 建图 + $a$ 次加边 ≈ $2 \times 10^6$ |

## 5. 正确性证明

**引理 1（简单路径足够）**：非负权图上任意 $s \to t$ 最短路上存在一条简单路径取得相同代价。

**证明**：若路径重复经过某顶点，去掉两段重复顶点之间的环，代价不增（边权非负），路径变短；重复有限次得简单路径。∎

**引理 2（Dijkstra 弹出即定型）**：非负权图上，堆优化 Dijkstra 每次弹出堆顶 $(d, u)$ 时，若 $d = dist[u]$（非过期条目），则 $d$ 等于 $s$ 到 $u$ 的最短路。

**证明**：归纳。设已定型集合为 $S$（弹出时 $d = dist[u]$ 的点），归纳假设" $S$ 内所有点的 $dist$ 均为最短路"。弹出 $(d, u) \notin S$ 且 $d = dist[u]$：若 $d$ 不是最短路，取一条真最短路 $P$，设 $P$ 上第一个不在 $S$ 中的点为 $x$、其前驱 $y \in S$。由归纳，$y$ 定型时已松弛出 $\text{dist}[x] \le \text{dist}[y] + w(y,x) \le d$（$P$ 上 $s \to x$ 段 $\le d$，因 $P$ 上 $x$ 之后到 $u$ 的段还有非负边）；而堆序保证弹出 $u$ 时 $\text{dist}[x] \ge d$，故 $\text{dist}[x] = d$ 也是最短路——把 $x$ 与 $u$ 视为同级定型即可，与弹出 $u$ 的选择不矛盾。归纳成立。∎

**定理 1（方案一正确）**：`shortestPath` 返回最小代价，不可达返回 $-1$。

**证明**：由引理 2，弹出 `node2` 时返回的 $d$ 是最短路；若堆耗尽仍弹出过 `node2`，说明从 `node1` 出发的松弛闭包（可达集）不含 `node2`，返回 $-1$ 正确。∎

**引理 3（单边增量公式）**：向图加入一条新边 $e = (u, v, w)$ 后，全源最短路满足 $d'[i][j] = \min\big(d[i][j],\ d[i][u] + w + d[v][j]\big)$，其中 $d$ 为加边前的全源最短路。

**证明**："$\le$"：右式两部分都对应新图中的真实路径（后者 = 旧最短路 $i \to u$ + 新边 + 旧最短路 $v \to j$）。"$\ge$"：取新图任一 $i \to j$ 最短路 $P$，由引理 1 可设 $P$ 简单：若 $P$ 不含 $e$，则 $P$ 是旧图路径，$d'[i][j] \le d[i][j]$ 得 $\text{cost}(P) \ge d[i][j]$；若 $P$ 含 $e$，由简单性恰含一次，$P$ 去掉 $e$ 分成两段 $i \to u$、$v \to j$，两段均为旧图路径，故 $\text{cost}(P) \ge d[i][u] + w + d[v][j]$。两种情况 $d'[i][j]$ 都 $\ge$ 右式。∎

**定理 2（方案二正确）**：构造时 Floyd 一次给出全源最短路；此后每次 `addEdge` 按引理 3 更新矩阵，`shortestPath` 查表即得。

**证明**：Floyd 的正确性是经典结论（中转点归纳：处理完 $\{0..k\}$ 后 $d[i][j]$ 为仅允许经 $\{0..k\}$ 中转的最短路）。`addEdge` 的更新式与引理 3 一致，且所有 $(i, j)$ 对同时更新（右端全部取旧值），无顺序依赖；有限次加边归纳到底。查表返回值即当前图最短路，$\infty$ 表示不可达。∎

## 6. 复杂度分析

- **方案一（Dijkstra）**：时间——建图 $O(n + m)$，`addEdge` $O(1)$，`shortestPath` $O\big((n + m)\log n\big)$（每个点多次入堆，堆操作上限 $O(m)$ 次）；空间——邻接表 $O(n + m)$、每次查询 $O(n)$ 距离数组 + 堆 $O(m)$。
- **方案二（Floyd）**：时间——建图 $O(n^3)$，`addEdge` $O(n^2)$，`shortestPath` $O(1)$；空间——矩阵 $O(n^2)$。
- 本题规模下两者总量级同为 $10^6$ 级；工程上按"查询多边少选 Dijkstra、边多查询少选 Floyd"取舍。

## 7. 参考代码

### C++（方案一：邻接表 + 堆优化 Dijkstra，主推）

```cpp
class Graph {
public:
    Graph(int n, vector<vector<int>>& edges) : adj(n) {
        for (auto& e : edges) adj[e[0]].push_back({e[1], e[2]});
    }
    void addEdge(vector<int> edge) {                  // O(1) 追加一条有向边
        adj[edge[0]].push_back({edge[1], edge[2]});
    }
    int shortestPath(int node1, int node2) {          // 堆优化 Dijkstra
        vector<long long> dist(adj.size(), INF);
        priority_queue<pl, vector<pl>, greater<pl>> pq;
        dist[node1] = 0;
        pq.push({0, node1});
        while (!pq.empty()) {
            auto [d, u] = pq.top(); pq.pop();
            if (d > dist[u]) continue;                // 过期的堆内条目，跳过
            if (u == node2) return (int)d;            // 弹出即定型
            for (auto& [v, w] : adj[u])
                if (d + w < dist[v]) {
                    dist[v] = d + w;
                    pq.push({dist[v], v});
                }
        }
        return -1;                                    // 不可达
    }
private:
    using pl = pair<long long, int>;
    static constexpr long long INF = LLONG_MAX / 4;
    vector<vector<pair<int, int>>> adj;
};
```

### Python（方案一）

```python
from heapq import heappush, heappop

class Graph:
    def __init__(self, n: int, edges: list[list[int]]):
        self.n = n
        self.adj = [[] for _ in range(n)]
        for u, v, w in edges:
            self.adj[u].append((v, w))

    def addEdge(self, edge: list[int]) -> None:
        self.adj[edge[0]].append((edge[1], edge[2]))

    def shortestPath(self, node1: int, node2: int) -> int:
        INF = float('inf')
        dist = [INF] * self.n
        dist[node1] = 0
        pq = [(0, node1)]
        while pq:
            d, u = heappop(pq)
            if d > dist[u]:                  # 过期条目，跳过
                continue
            if u == node2:                   # 弹出即定型
                return d
            for v, w in self.adj[u]:
                nd = d + w
                if nd < dist[v]:
                    dist[v] = nd
                    heappush(pq, (nd, v))
        return -1                            # 不可达
```

### C++（方案二：Floyd 矩阵 + 加边增量更新）

```cpp
class Graph {
public:
    Graph(int n, vector<vector<int>>& edges)
        : d(n, vector<long long>(n, INF)) {
        for (int i = 0; i < n; ++i) d[i][i] = 0;
        for (auto& e : edges) d[e[0]][e[1]] = e[2];
        for (int k = 0; k < n; ++k)                  // 初始全源最短路 O(n^3)
            for (int i = 0; i < n; ++i)
                for (int j = 0; j < n; ++j)
                    d[i][j] = min(d[i][j], d[i][k] + d[k][j]);
    }
    void addEdge(vector<int> edge) {                 // O(n^2) 增量更新
        int u = edge[0], v = edge[1];
        long long w = edge[2];
        if (w >= d[u][v]) return;                    // 三角不等式：不可能更优
        int n = d.size();
        for (int i = 0; i < n; ++i)
            for (int j = 0; j < n; ++j)
                d[i][j] = min(d[i][j], d[i][u] + w + d[v][j]);
    }
    int shortestPath(int node1, int node2) {         // O(1) 查表
        return d[node1][node2] >= INF ? -1 : (int)d[node1][node2];
    }
private:
    static constexpr long long INF = LLONG_MAX / 4;
    vector<vector<long long>> d;
};
```

### Python（方案二）

```python
class Graph:
    def __init__(self, n: int, edges: list[list[int]]):
        INF = float('inf')
        self.n = n
        self.d = [[INF] * n for _ in range(n)]
        for i in range(n):
            self.d[i][i] = 0
        for u, v, w in edges:
            self.d[u][v] = w
        for k in range(n):                       # 初始全源最短路 O(n^3)
            dk = self.d[k]
            for di in self.d:
                dik = di[k]
                if dik == INF:
                    continue
                for j in range(n):
                    nd = dik + dk[j]
                    if nd < di[j]:
                        di[j] = nd

    def addEdge(self, edge: list[int]) -> None:  # O(n^2) 增量更新
        u, v, w = edge
        d = self.d
        if w >= d[u][v]:                         # 三角不等式：不可能更优
            return
        n = self.n
        for di in d:
            diu = di[u]
            if diu == float('inf'):
                continue
            dvj = d[v]
            for j in range(n):
                nd = diu + w + dvj[j]
                if nd < di[j]:
                    di[j] = nd

    def shortestPath(self, node1: int, node2: int) -> int:
        x = self.d[node1][node2]
        return -1 if x == float('inf') else x
```

> 💡 四份代码（C++/Python × 两方案）均按官方调用序列回放验证（`[null, 6, -1, null, 6]`），并与每次查询独立跑 Bellman–Ford 的暴力对拍 600 组随机操作序列（2630 次查询，四实现两两一致），`mismatch = 0`；另以 $n = 100$、近满边初始图 + 100 次 `addEdge` + 100 次查询做了压力测试（0.01 秒）。

## 8. 边界情况与易错点

1. **`node1 == node2`**：答案为 0（空路径），两方案都天然覆盖——Dijkstra 首次弹出即返回 0，Floyd 矩阵对角线恒 0。
2. **不可达返回 $-1$**：Dijkstra 以"堆空"判定；Floyd 看是否仍为 INF——注意更新中 INF 参与加法不会变成真值（取 `LLONG_MAX/4` 防溢出），但**别**用 `d[i][u] == INF` 提前跳过再漏判终点（跳过优化只作用于中间量）。
3. **有向 vs 无向**：本题是**有向**图，`addEdge` 只加单方向；误建成双向会让示例 1 的第二次查询返回非 $-1$，是极佳的自检点。
4. **堆内过期条目**：不写 `if (d > dist[u]) continue` 时复杂度仍正确（`d + w < dist[v]` 挡住重复松弛），但堆可能膨胀到 $O(m)$ 条无谓比较；写了既省常数又清晰。
5. **加边的剪枝条件**：`if (w >= d[u][v]) return` 依赖三角不等式（§3.3），剪掉的只是"不可能改进"的更新，不影响正确性；不剪也对，仅慢 $n^2$ 一点。
6. **建图重边**：构造函数直接赋值 `d[from][to] = w` 依赖"初始无重边"的承诺；放开假设时改 `min` 赋值即可，邻接表版无需改动。
7. **构造函数参数按引用传入**：LeetCode 签名是 `Graph(int n, vector<vector<int>>& edges)`，类内**拷贝**所需数据后不要持有外部引用（官方测试生命周期不受影响，但设计题保持自包含是好习惯）。
8. **`long long` vs `int`**：路径代价上界 $\approx 99 \times 10^6 < 2^{31}$，`int` 其实够用；但 Floyd 的 INF 加法在 `int` 下会溢出，矩阵用 `long long` + `LLONG_MAX/4` 是稳妥统一的选择。
