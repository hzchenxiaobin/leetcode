# LeetCode 查询网格图中每一列的宽度 题解

## 1. 题目概述

- **标题 / 题号**：查询网格图中每一列的宽度（#2639，easy）
- **链接**：https://leetcode.cn/problems/find-the-width-of-columns-of-a-grid/
- **来源**：LeetCode 第 102 场双周赛 Q1
- **难度**：简单
- **标签**：数组、矩阵

**题意**：给定 $m \times n$ 整数矩阵 `grid`。一列的**宽度**定义为该列所有数字的**十进制字符串长度**的最大值（负号占一位，如 `-10` 长度为 3）。返回长度为 $n$ 的数组 `ans`，`ans[i]` 为第 $i$ 列的宽度。

**约束**：

- $m = grid.length$，$n = grid[i].length$
- $1 \le m, n \le 100$
- $-10^9 \le grid[r][c] \le 10^9$

## 2. 示例

**示例 1**

```text
输入：grid = [[1],[22],[333]]
输出：[3]
解释：唯一一列中 333 的字符串长度为 3，是三个数里最大的。
```

**示例 2**

```text
输入：grid = [[-15,1,3],[15,7,12],[5,6,-2]]
输出：[3,1,2]
解释：第 0 列 -15 长度 3；第 1 列都是 1 位数；第 2 列 12 与 -2 长度都是 2。
```

**示例 3（边界补充）**

```text
输入：grid = [[-1000000000],[1000000000],[0]]
输出：[11]
解释：-1000000000 共 10 位数字 + 1 个负号 = 11；0 占 1 位。
```

## 3. 解题思路

### 3.1 暴力思路

本题数据极小（$m, n \le 100$，共 $10^4$ 个数），任何"把每个数转成字符串测长度"的做法都是一遍过：Python `len(str(x))`、C++ `to_string(x).size()`，逐列取 max，$O(mn \cdot 10)$。真正值得写进题解的不是"怎么更快"，而是**不依赖库函数时如何正确手写数位长度**——负号、零、$10^9$ 这些边界才是签到题的陷阱所在。

### 3.2 核心观察：数位长度 = 除 10 计数，负号额外占一位

![核心观察：一个数的字符串长度由数位与负号两部分组成](images/bw102_q1_column_width.svg)

对整数 $x$，其十进制字符串长度由两部分拼成：

1. **数位个数** $\text{digits}(x)$：$x$ 的绝对值里有多少位十进制数字。$x = 0$ 是 1 位；$x \ne 0$ 时不断除以 10 计数。
2. **负号**：$x < 0$ 时额外 $+1$。

$$\text{len}(x) = \text{digits}(|x|) + [x < 0]$$

逐列扫描取最大值即可。$\pm 10^9$ 是 10 位（加负号 11 位），`int` 的极限范围（约 $\pm 2.1 \times 10^9$）也不会超过 11 位，一副十指就能数过来。

> ⚠️ **不建议用 `log10`**：$\log_{10}$ 是浮点函数，在 $10^k$ 这类边界上有表示误差，`floor(log10(x)) + 1` 在 $x = 10^9$ 附近可能算出 9 而不是 10。除法循环或字符串转换才是稳妥做法。

### 3.3 算法流程

![算法流程：手写数位长度 width(x) 的逐步处理](images/bw102_q1_digit_count.svg)

```text
1. 对每一列 j = 0, 1, …, n-1：
       w = 0
       对每一行 i = 0, 1, …, m-1：
           w = max(w, len(grid[i][j]))
       ans[j] = w
2. 返回 ans

其中 len(x)：
       计数器 t = 1            # 至少 1 位（覆盖 x = 0）
       若 x < 0：t += 1, x = -x
       当 x ≥ 10：t += 1, x = x / 10（整除）
       返回 t
```

### 3.4 示例演算

![示例演算：每个数标出字符串长度，逐列取最大](images/bw102_q1_example_walkthrough.svg)

以示例 2（`grid = [[-15,1,3],[15,7,12],[5,6,-2]]`）为例：

| | 第 0 列 | 第 1 列 | 第 2 列 |
|---|---------|---------|---------|
| 第 0 行 | $-15$ → **3** | $1$ → 1 | $3$ → 1 |
| 第 1 行 | $15$ → 2 | $7$ → 1 | $12$ → **2** |
| 第 2 行 | $5$ → 1 | $6$ → 1 | $-2$ → **2** |
| 列宽 | $\max = 3$ | $\max = 1$ | $\max = 2$ |

输出 `[3, 1, 2]`。✅

## 4. 算法细节

1. **`x = 0` 的处理**：`len = 1` 起步（而不是从 0 起步再 `while (x)` 计数），否则 0 会被数成 0 位。除法循环的条件写成 `while (x >= 10)`，天然兼容 0。
2. **负号与绝对值**：先判负号加一、再取绝对值进入数位循环；顺序颠倒会把负号算进数位（如把 `-1` 数成 2 位但把 `-10` 只数成 2 位——其实恰好也对，纯属巧合，别依赖）。
3. **转字符串的写法**：C++ `to_string(x)` 与 Python `str(x)` 都自动处理负号与零，是"最短路径"；手写循环的价值在于理解边界，两者都该会。
4. **遍历顺序**：按列扫会跳着访问内存（C++ 中 `grid[i][j]` 随 $j$ 步进），但 $m, n \le 100$ 完全无所谓；按行扫、维护 `ans[j] = max(ans[j], len(...))` 也一样对，无需纠结。
5. **返回类型**：宽度至多 11，`int` 足够；Python 侧直接返回 `list[int]`。

## 5. 正确性证明

**引理 1（数位长度的刻画）**：对非负整数 $y \ge 0$，其十进制表示的数位个数 $\text{digits}(y) = k$ 当且仅当 $10^{k-1} \le y < 10^{k}$（约定 $y = 0$ 时 $k = 1$）。

**证明**：归纳。$0 \le y \le 9$ 的数位个数是 1，与 $10^0 \le y < 10^1$ 一致。设结论对 $k$ 成立。$y$ 有 $k+1$ 位当且仅当其最高位非零且去掉最高位后是 $k$ 位以内的数，即 $y = 10k' + r$ 形式下 $\lfloor y / 10 \rfloor$ 有 $k$ 位——由归纳假设 $\lfloor y/10 \rfloor \in [10^{k-1}, 10^k)$，即 $y \in [10^k, 10^{k+1})$。∎

**引理 2（除法循环正确）**：`len(x)` 过程对任何 `int` 范围内的 $x$ 返回正确的字符串长度。

**证明**：设 $x < 0$，程序先加 1 计负号、转为 $y = |x| \ge 0$；此后循环在 $y \ge 10$ 时整除 10 并计数，由引理 1，$\text{digits}(y)$ 等于"整除 10 直到 $< 10$ 的次数 $+ 1$"。$y = 0$ 时不进循环、返回初值 1，符合约定。总长 = 数位 + 负号，与十进制字符串的构成（数字字符 + 可选负号）一致。∎

**定理**：算法返回的 `ans[j]` 等于第 $j$ 列所有元素字符串长度的最大值。

**证明**：对每列，`w` 以 0 起步、对每个元素做 `max(w, len(grid[i][j]))`，由 `max` 的结合性与引理 2，循环结束时 $w = \max_i \text{len}(grid[i][j])$（列非空由 $m \ge 1$ 保证）。逐列赋值即得。∎

## 6. 复杂度分析

- **时间**：$O(mn \cdot D)$，$D \le 11$ 为单数测长度的常数开销（除法循环至多 10 轮）；即 $O(mn)$。$m, n \le 100$ 时约 $10^4 \times 10$ 次操作。
- **空间**：$O(n)$——答案数组；不计输出则 $O(1)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> findColumnWidth(vector<vector<int>>& grid) {
        int m = grid.size(), n = grid[0].size();
        vector<int> ans(n);
        for (int j = 0; j < n; ++j) {          // 逐列求最大字符串长度
            int w = 0;
            for (int i = 0; i < m; ++i)
                w = max(w, width(grid[i][j]));
            ans[j] = w;
        }
        return ans;
    }
private:
    static int width(int x) {
        int len = 1;                           // 至少 1 位（x = 0 也是 1 位）
        if (x < 0) { len = 2; x = -x; }        // 负号额外占 1 位
        while (x >= 10) { ++len; x /= 10; }    // 每除掉一位，长度 +1
        return len;
    }
};
```

### Python

```python
class Solution:
    def findColumnWidth(self, grid: list[list[int]]) -> list[int]:
        def width(x: int) -> int:
            return len(str(x))                 # str() 自带负号，0 也占 1 位

        m, n = len(grid), len(grid[0])
        return [max(width(grid[i][j]) for i in range(m)) for j in range(n)]
```

> 💡 两份代码均通过官方示例（`[3]`、`[3,1,2]`）与边界 $\pm 10^9$、0（输出 `[11,10,1]` 一类）；C++ 手写循环版与 Python `str()` 参考实现对拍 2002 组随机矩阵（含极端值），`mismatch = 0`。

## 8. 边界情况与易错点

1. **$x = 0$ 占 1 位**：数位循环若写成 `while (x) { len++; x /= 10; }` 且初值 0，会把 0 数成 0 位；初值必须为 1 或改用 do-while。
2. **负号别忘 +1**：`-15` 是 3 位不是 2 位；先判负再取绝对值的顺序要固定。
3. **$-10^9$ 与 $10^9$**：恰好 10 位数字（加负号 11），是本题值域的"顶格"边界，务必进测试集。
4. **`log10` 浮点陷阱**：`floor(log10(x)) + 1` 在 $x$ 接近 $10^k$ 时可能因浮点误差少算一位（经典的 `log10(1000) = 2.999…` 问题），赛场上直接排除这种写法。
5. **矩阵不是方阵**：$m \ne n$ 时行列下标别写反（`grid[i][j]` 中 $i$ 是行、$j$ 是列）。
6. **空矩阵？** 约束保证 $m, n \ge 1$，无需特判，但防御式代码里 `grid[0].size()` 前应确认 `grid` 非空。
