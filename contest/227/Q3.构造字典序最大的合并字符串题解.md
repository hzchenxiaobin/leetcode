# LeetCode 构造字典序最大的合并字符串 题解

## 1. 题目概述

- **标题 / 题号**：构造字典序最大的合并字符串（#1754，medium）
- **链接**：https://leetcode.cn/problems/largest-merge-of-two-strings/
- **来源**：LeetCode 第 227 场周赛 Q3
- **难度**：中等
- **标签**：贪心，双指针，字符串

**题意**：给定两个字符串 `word1` 与 `word2`，反复执行以下操作直到两串皆空：从**任一非空串的队首**取一个字符接到 `merge` 末尾。每个串内部的相对顺序不能打乱，但两串之间可以任意交错。返回能构造出的**字典序最大**的 `merge`。

**约束**：

- $1 \le word1.length,\ word2.length \le 3000$
- `word1` 和 `word2` 仅由小写英文组成

> 💡 本题本质：在两个串的所有**保序交错**（interleaving）中找字典序最大者。字典序由**最早出现差异的位置**决定，因此天然导向「逐位放最大字符」的贪心形态——难点全部集中在**队首并列时怎么选**。

## 2. 示例

**示例 1**

```text
输入：word1 = "cabaa", word2 = "bcaaa"
输出："cbcabaaaaa"
解释：取 c(w1) → b(w2) → c(w2) → a(w1) → b(w1)，随后 5 个 'a' 全部接上。
```

**示例 2**

```text
输入：word1 = "abcabc", word2 = "abdcaba"
输出："abdcabcabcaba"
```

**补充示例（并列陷阱）**

```text
输入：word1 = "aa", word2 = "ab"
输出："abaa"
解释：首字符都是 'a'。若"并列就固定取 word1"，得到 "aaab"；
      正确做法是比较后缀："aa" < "ab"，先取 word2，得 "abaa" > "aaab"。
```

## 3. 解题思路

### 3.1 暴力思路：枚举交错方案

每一步有两种选择（取 `word1` 队首或取 `word2` 队首），全部交错方案共 $\binom{n+m}{n}$ 个，逐个生成再比大小是指数级。即使想到按 $\mathrm{opt}(i, j) = \max\big(word1[i] + \mathrm{opt}(i+1,\,j),\ word2[j] + \mathrm{opt}(i,\,j+1)\big)$ 做 DP，状态也有 $n \cdot m \approx 9 \times 10^6$ 个，且每个状态取 $\max$ 时要比较长为 $O(n+m)$ 的串，总量仍不可行。

但「字典序由最早差异位决定」提示我们换个视角：**逐位构造，每一步放下当前能放的最大字符**。若能证明「每一步取谁」只由两个剩余后缀的大小关系一锤定音，DP 就坍缩成一个双指针贪心。问题只剩一个：队首字符**相同**时，先消耗谁？

### 3.2 核心观察：比较整个后缀，后缀大者先出

![后缀比较贪心规则](images/merge_suffix_rule_concept.svg)

设当前剩余后缀 $A = word1[i:]$、$B = word2[j:]$：

1. **首字符不等**：直接取首字符大的一方——一位定胜负（§5 引理 1 级别的显然）。
2. **首字符相等**：这时取谁的队首，**输出的字符相同**，差别在之后能取到什么。必须比较 $A$ 与 $B$ **整串**的字典序，后缀大的一方「前景更好」，先消耗它。

![并列陷阱反例](images/merge_tie_trap_counterexample.svg)

> ⚠️ **两个典型陷阱**：① 并列随便取——`"aa"` + `"ab"` 上得到 `"aaab"`，正确答案是 `"abaa"`；② 比较只看固定几位——`"aaa"` vs `"aab"` 要比到第 3 位才分出胜负，任何截断长度都能构造出反例。**必须比较整个后缀**，包括「一方是另一方真前缀」的规则（短的更小）。

### 3.3 算法流程

双指针 $i, j$ 各指两串队首，`merge` 初始为空：

1. 两串均非空时：比较后缀 $word1[i:]$ 与 $word2[j:]$（标准字典序，真前缀更小）：
   - $word1[i:] \ge word2[j:]$ → 取 `word1[i]`，$i$ 右移；
   - 否则 → 取 `word2[j]`，$j$ 右移。
2. 一方取空：另一串的剩余部分**整段拼接**到 `merge` 末尾。
3. 重复直到两串皆空。

后缀完全相等时任取一方（两侧库存对称，见 §5 定理后的说明）。

### 3.4 示例演算

![示例演算表](images/merge_walkthrough_cabaa.svg)

以示例 1（`"cabaa"` + `"bcaaa"`）为例：步 1-3、5 都是首字符不等一位定胜负；**步 4** 首字符同为 `'a'`，比较后缀 `"abaa" > "aaa"`（第 2 位 `'b' > 'a'`），取 `word1` 让 `'b'` 尽早出场；**步 6** 遇到真前缀情形 `"aa" < "aaa"`，反取 `word2`；步 7-10 后缀相等或一方已空，怎么交错都一样。

## 4. 算法细节

1. **后缀比较的三种命中**：首字符不等——$O(1)$ 出结果；相等——逐位向后推进；一方推进到末尾——真前缀规则「短者更小」。三者合并为**一次标准字典序比较**，与 Python 的切片比较、C++ 的 `compare` 语义完全一致。
2. **Python 直接用切片比较**：`word1[i:] >= word2[j:]`，底层为 C 级实现。每次切片有 $O(\text{剩余长度})$ 的拷贝，最坏情形（两串全为同一字符）总代价约 $(n+m) \cdot \min(n, m) \le 1.8 \times 10^7$ 字符操作，无需任何优化。
3. **C++ 避免子串分配**：不要 `substr` 出子串再比；用 `word1.compare(i, npos, word2, j, npos)`，或手写双指针逐字符比较（本文参考代码采用后者，零额外分配）。
4. **结果累积**：Python 用 `list.append` + `''.join`，避免反复创建新串；C++ 先 `reserve(n + m)` 再 `push_back`。
5. **后缀相等时任取**：代码统一走 `>=` 分支取 `word1`，不影响正确性（§5）。

## 5. 正确性证明

记 $A = word1[i:]$、$B = word2[j:]$ 为当前剩余后缀，$A' = A[1:]$、$B' = B[1:]$；$\mathrm{opt}(A, B)$ 表示从状态 $(A, B)$ 出发能得到的最优合并；所有比较均为标准字典序（**真前缀 $<$ 原串**）。

**引理 1（严格首字符占优）**：若 $A, B$ 非空且 $A[0] > B[0]$，则 $\mathrm{opt}(A, B) = A[0] + \mathrm{opt}(A', B)$。

**证明**：任取以 $B[0]$ 开头的合并 $M = B[0] + R$，令 $M' = A[0] + W$，其中 $W$ 是 $(A', B)$ 的任意一个合并（如 $A' \cdot B$）。$M'$ 合法且首字符 $A[0] > B[0]$，故 $M' > M$——以 $B[0]$ 开头的合并永远不是最优。而以 $A[0]$ 开头的合并中，最大者恰为 $A[0] + \mathrm{opt}(A', B)$。∎

**引理 2（保大换垫引理）**：若 $X \ge Y$，则对任意串 $W$（可为空串）：

$$\mathrm{opt}(X,\ W Y)\ \ge\ \mathrm{opt}(W X,\ Y)$$

两边库存的字符多重集完全相同，唯一区别是公共「垫」串 $W$ 垫在大串 $X$ 前还是小串 $Y$ 前——**垫到小串前不亏**。

**证明**：对 $n = |W| + |X| + |Y|$ 强归纳。

- $W$ 为空或 $X = Y = \varepsilon$：两边状态相同，等号成立。
- $Y = \varepsilon$、$X \neq \varepsilon$：右边唯一合并为 $WX$，而「先耗尽 $W$ 再耗尽 $X$」正是 $(X, W)$ 的合法合并，故左边 $\ge WX$。
- $X = \varepsilon$：由 $X \ge Y$ 得 $Y = \varepsilon$，已处理。

以下设 $X, Y, W$ 均非空，记 $x = X[0]$、$y = Y[0]$、$w = W[0]$。由 $X \ge Y$ 知 $x \ge y$，且 $x = y$ 时 $X' \ge Y'$。按 $w$ 与 $x, y$ 的相对位置分三类（引理 1 用于「严格大者锁定」）：

**（一）$w > x \ge y$**：两边队首都被 $w$ 严格占优，各自取 $w$ 后，问题化为 $\mathrm{opt}(X, W'Y) \ge \mathrm{opt}(W'X, Y)$——即规模 $n - 1$ 的引理 2（前提 $X \ge Y$ 不变）。

**（二）$w < y \le x$**：两边分别锁定取 $x$ 与 $y$：

- $x > y$：首字符 $x > y$，左边更大；
- $x = y$：需证 $\mathrm{opt}(X', WY) \ge \mathrm{opt}(WX, Y')$。取 $\widetilde{W} = Wx$、$\widetilde{X} = X'$、$\widetilde{Y} = Y'$：由 $x = y$ 有 $\widetilde{W}\widetilde{Y} = WxY' = WY$、$\widetilde{W}\widetilde{X} = WxX' = WX$，故这正是规模 $n - 1$ 的引理 2；前提 $X' \ge Y'$ 由 $x = y$ 时的 $X \ge Y$ 给出。

**（三）$y \le w \le x$**，按并列情况细分：

- $x > w > y$：左边取 $x$、右边取 $w$，首字符定胜负；
- $x = w > y$：右边锁定取 $w$；左边两队首同为 $x$，选 $W$ 侧续接得 $x + \mathrm{opt}(X, W'Y) \ge w + \mathrm{opt}(W'X, Y)$（规模 $n - 1$ 的引理 2）；
- $x > w = y$：左边锁定取 $x$，右边首字符至多 $w < x$，被压过；
- $x = w = y$：两边都是并列队首，右边 $= x + \max\big(\mathrm{opt}(W'X, Y),\ \mathrm{opt}(WX, Y')\big)$ 的两项，分别被左边 $x + \max\big(\mathrm{opt}(X, W'Y),\ \mathrm{opt}(X', WY)\big)$ 中的对应项压住：前者由引理 2（$W'$ 版）给出 $\mathrm{opt}(X, W'Y) \ge \mathrm{opt}(W'X, Y)$；后者由引理 2（$\widetilde{W} = Wx$、$\widetilde{X} = X'$、$\widetilde{Y} = Y'$ 版，前提 $X' \ge Y'$）给出 $\mathrm{opt}(X', WY) \ge \mathrm{opt}(WX, Y')$。

所有递归调用的规模严格小于 $n$，归纳完成。∎

**定理（贪心正确性）**：每步取较大后缀的首字符（相等任取），输出 $\mathrm{opt}(word1, word2)$。

**证明**：对剩余总长 $|A| + |B|$ 强归纳。不妨 $A \ge B$（对称）。贪心输出为 $A[0] + \mathrm{opt}(A', B)$（归纳假设）。任一合并 $M$ 只有两种开头：

- 以 $A[0]$ 开头：$M = A[0] + V$，$V$ 是 $(A', B)$ 的合并，故 $M \le A[0] + \mathrm{opt}(A', B)$，即不超过贪心输出；
- 以 $B[0]$ 开头：$M = B[0] + V'$，$V'$ 是 $(A, B')$ 的合并，故 $M \le B[0] + \mathrm{opt}(A, B')$。若 $A[0] > B[0]$，$M$ 的首字符已被压过；若 $A[0] = B[0] = c$，由 $A \ge B$ 得 $A' \ge B'$，对 $W = c$、$X = A'$、$Y = B'$ 用引理 2 得 $\mathrm{opt}(A', B) = \mathrm{opt}(X, WY) \ge \mathrm{opt}(WX, Y) = \mathrm{opt}(A, B')$，于是 $M \le c + \mathrm{opt}(A', B)$，仍不超过贪心输出。

两种开头都不超过贪心输出，故贪心输出即最优合并。∎

> 💡 **引理 2 的直觉**：首字符并列时，「先消耗较大后缀」相当于把公共垫 $c$ 从大串挪到小串——手里攥着的仍是较大的那串，好牌先出、垫牌后补，怎么都不亏。另注：$A = B$ 时两侧库存完全对称，$\mathrm{opt}(A', B) = \mathrm{opt}(A, B')$，故后缀相等时任取一方。

## 6. 复杂度分析

- **时间复杂度**：共 $n + m$ 步，每步后缀比较最坏 $O\big(\min(n - i,\ m - j)\big)$，总计 $O\big((n+m) \cdot \min(n, m)\big) \le 6000 \times 3000 = 1.8 \times 10^7$。最坏输入（两串全为同一字符）实测 Python 也在百毫秒内。
- **空间复杂度**：$O(n + m)$ 存输出串；Python 每次切片另有 $O(\min(n, m))$ 临时空间。
- 进阶：若 $n, m$ 达到 $10^5$ 级，可对 $word1 + \# + word2$ 建后缀数组，每步后缀比较降为查 `rank` 的 $O(1)$，总 $O(n + m)$。

## 7. 参考代码

### C++（手写后缀比较，零额外分配）

```cpp
class Solution {
public:
    string largestMerge(string word1, string word2) {
        int n = word1.size(), m = word2.size(), i = 0, j = 0;
        string merge;
        merge.reserve(n + m);
        auto ge = [&](int i, int j) {          // word1[i:] >= word2[j:] ?
            while (i < n && j < m && word1[i] == word2[j]) ++i, ++j;
            if (j == m) return true;           // word2 后缀先耗尽（或同时）→ 不小于
            if (i == n) return false;          // word1 后缀是真前缀 → 更小
            return word1[i] > word2[j];
        };
        while (i < n && j < m) {
            if (ge(i, j)) merge.push_back(word1[i++]);
            else          merge.push_back(word2[j++]);
        }
        merge.append(word1, i, string::npos);
        merge.append(word2, j, string::npos);
        return merge;
    }
};
```

### Python（切片比较，最短写法）

```python
class Solution:
    def largestMerge(self, word1: str, word2: str) -> str:
        merge = []
        i, j = 0, 0
        n, m = len(word1), len(word2)
        while i < n and j < m:
            if word1[i:] >= word2[j:]:      # 标准字典序：真前缀更小，相等任取
                merge.append(word1[i])
                i += 1
            else:
                merge.append(word2[j])
                j += 1
        merge.append(word1[i:])
        merge.append(word2[j:])
        return ''.join(merge)
```

## 8. 边界情况与易错点

1. **并列随便取**：`"aa"` + `"ab"` 固定取 `word1` 得 `"aaab"`，正确答案 `"abaa"`——并列必须比较后缀。
2. **比较截断到固定长度**：`"aaa"` vs `"aab"` 要比到第 3 位；任何截断都有反例，必须比到分出胜负或一方耗尽。
3. **真前缀规则**：标准字典序里短的真前缀更小（演算表步 6 的 `"aa" < "aaa"`、步 8 的 `"a" < "aa"`）。手写比较时若先比长度、或把「先耗尽」当成更大，样例都过不去。
4. **后缀完全相等**：任取一方，结果不变（库存对称）。
5. **一方取空后**：另一串剩余部分**整段拼接**即可，不要再逐字符比较。
6. **Python 性能**：切片比较每步有 $O(\text{剩余长度})$ 拷贝，最坏 $1.8 \times 10^7$ 字符操作，无需优化；改成纯 Python 手写逐字符比较反而更慢。
7. **C++ 写法**：`substr` 比较会引入 $O(\text{长度})$ 的临时分配，常数大；应使用 `compare(i, npos, word2, j, npos)` 或手写双指针。
