# LeetCode 最接近目标值的子序列和 题解

## 1. 题目概述

- **标题 / 题号**：最接近目标值的子序列和（#1755，hard）
- **链接**：https://leetcode.cn/problems/closest-subsequence-sum/
- **来源**：LeetCode 第 227 场周赛 Q4
- **难度**：困难
- **标签**：中途相遇法、二分查找、排序、位运算、数组

**题意**：给定整数数组 `nums` 和目标值 `goal`。从 `nums` 中选出一个子序列（可以为空），设其元素和为 $sum$，返回 $\left| sum - goal \right|$ 可能的最小值。

**约束**：

- $1 \le nums.length \le 40$
- $-10^7 \le nums[i] \le 10^7$
- $-10^9 \le goal \le 10^9$

> 💡 **数据范围是最大的提示**：$n \le 40$ 恰好卡在"直接枚举 $2^{40}$ 不可行、折半后每边 $2^{20}$ 可行"的临界点上，是**中途相遇法（Meet in the Middle）**的标志性范围。

## 2. 示例

**示例 1**

```text
输入：nums = [5,-7,3,5], goal = 6
输出：0

解释：选择整个数组作为子序列，和为 5 - 7 + 3 + 5 = 6，
绝对差 |6 - 6| = 0。
```

**示例 2**

```text
输入：nums = [7,-9,15,-2], goal = -5
输出：1

解释：选出子序列 [7,-9,-2]，和为 -4，
|-4 - (-5)| = |1| = 1，是可能的最小值。
```

**示例 3**

```text
输入：nums = [1,2,3], goal = -7
输出：7

解释：所有子序列和都落在 [0, 6] 内，均不小于 -7，
最优是空子序列（和为 0），|0 - (-7)| = 7。
```

## 3. 解题思路

### 3.1 暴力思路

每个元素只有"选 / 不选"两种状态，共有 $2^n$ 个子序列。$n \le 40$ 时 $2^{40} \approx 1.1 \times 10^{12}$，即使每次判断只需 1 纳秒，也要约 18 分钟，不可行。

**能否用 0-1 背包 DP？** 把"可达的子序列和"作为状态。但 $|nums[i]| \le 10^7$ 且含负数，和的值域宽达 $8 \times 10^8$——无论用数组、哈希表还是位集（约 100 MB），空间都无法承受。

> ⚠️ **卡死的原因**：状态数既不能沿"元素个数"（$2^{40}$）也不能沿"和的值域"（$8 \times 10^8$）直接展开，必须找第三条路。

### 3.2 核心观察：折半枚举（中途相遇法）

**关键观察**：把数组从中间切成两半，任何子序列都被拆成"左半部分的选取"与"右半部分的选取"两个**互相独立**的决策，其和相应分解为

$$sum = x + y$$

其中 $x$ 是左半某个子集的和，$y$ 是右半某个子集的和。

![中途相遇法核心概念](images/closest_subseq_mitm_concept.svg)

于是问题转化为：在两个规模各为 $2^{n/2} \le 2^{20} \approx 10^6$ 的和集合 $X$、$Y$ 中，找一对 $(x, y)$ 最小化 $\left| x + y - goal \right|$：

- 枚举两半各自的子集和：各 $2^{20} \approx 10^6$ 个，完全可行；
- 将 $Y$ **排序**，对每个 $x$ 在 $Y$ 中**二分查找**最接近 $goal - x$ 的 $y$。

这样把 $2^{40}$ 的搜索空间压缩为"枚举 $2^{20}$ + 每次二分"，是指数级问题的经典降维手段。

### 3.3 算法流程

![算法流程图](images/closest_subseq_flow.svg)

1. **分半**：$left = nums[0 .. \lfloor n/2 \rfloor)$，$right = nums[\lfloor n/2 \rfloor .. n)$，两半各不超过 20 个元素。
2. **翻倍法枚举子集和**：从 $\{0\}$（空子集）出发，每加入一个元素 $a$，集合由 $S$ 变为 $S \cup \{s + a : s \in S\}$，长度逐次翻倍，最终得到 $2^{20}$ 个和。
3. **排序**：将右半的和数组 $Y$ 排序（可顺带去重缩小规模）。
4. **匹配**：遍历左半每个和 $x$，令 $t = goal - x$，在 $Y$ 中二分找到第一个 $\ge t$ 的位置 $i$，只需检查 $Y[i]$ 与 $Y[i-1]$ 两个候选，用 $\left| x + y - goal \right|$ 更新答案。
5. **提前终止**：一旦差为 0，即为全局最优，立即返回。

### 3.4 示例演算

以示例 1 演算：$nums = [5, -7, 3, 5]$，$goal = 6$。

![示例演算](images/closest_subseq_walkthrough.svg)

- 左半 $[5, -7]$ 的子集和：$X = \{0, 5, -7, -2\}$；
- 右半 $[3, 5]$ 的子集和排序后：$Y = [0, 3, 5, 8]$。

对每个 $x$ 计算 $t = 6 - x$，在 $Y$ 中找最近的 $y$：

| $x$ | $t = 6 - x$ | 二分候选 $y$ | 最优 $y$ | $\lvert x + y - 6 \rvert$ |
|:---:|:---:|:---:|:---:|:---:|
| $0$ | $6$ | $5,\ 8$ | $5$ | $1$ |
| $5$ | $1$ | $0,\ 3$ | $0$ | $1$ |
| $-7$ | $13$ | $8$（仅左邻） | $8$ | $5$ |
| $-2$ | $8$ | $5,\ 8$ | $8$ | $0$（命中） |

$x = -2$ 对应左半选 $\{5, -7\}$，$y = 8$ 对应右半选 $\{3, 5\}$，合并即整个数组，和为 6，答案 0。

## 4. 算法细节

1. **翻倍法枚举子集和**
   - 初始 `sums = [0]`（空子集的和为 0，天然覆盖"什么都不选"）；
   - 逐个加入元素 $a$：`sums += [s + a for s in sums]`（列表推导式先整体求值再拼接，边遍历边扩充是安全的）；
   - 长度按 $1, 2, 4, \dots, 2^{m}$ 增长，总操作数 $\sum_{k=0}^{m-1} 2^k = 2^{m} - 1$，即 $O(2^{n/2})$；
   - 相比"按位掩码逐一累加"的 $O(2^m \cdot m)$ 写法，翻倍法少一个因子，且缓存友好。

2. **二分找最近值**
   - 对固定 $x$，目标变为在有序数组 $Y$ 中找 $y$ 使 $\lvert y - t \rvert$ 最小（$t = goal - x$）；
   - `lower_bound` 返回第一个 $\ge t$ 的位置 $i$：$Y[i]$ 是 "$\ge t$ 中最小"，$Y[i-1]$ 是 "$< t$ 中最大"，最近值必居其一；
   - 边界：$i = 0$ 时无左候选，$i = |Y|$ 时无右候选，两个分支都要判空。

3. **分半与去重**
   - 从下标中间切开即可，无需随机化——两半元素个数平衡就足够（奇数时右半多 1 个，仍是 $\le 20$）；
   - 右半排序后去重可缩小二分范围（元素大量重复时收益明显），不去重也不影响正确性。

4. **提前退出**：匹配过程中发现 $\lvert x + y - goal \rvert = 0$ 即为全局最优，直接返回，省去剩余二分。

## 5. 正确性证明

**引理 1（分解定理）**：设 $X$ 为左半所有子集的和集合，$Y$ 为右半所有子集的和集合，则 `nums` 的子序列和集合恰为 $\{x + y : x \in X,\ y \in Y\}$。

**证明**：任取子序列 $S$，按元素下标是否落在左半将其划分为 $S_L$ 与 $S_R$，则 $sum(S) = sum(S_L) + sum(S_R)$，且 $sum(S_L) \in X$、$sum(S_R) \in Y$。反之，任取左半子集与右半子集，其并是 `nums` 的合法子序列，和恰为对应的 $x + y$。两个方向的构造互逆，故集合相等。∎

**引理 2（二候选引理）**：设 $Y$ 升序，$t$ 为任意整数，$i$ 为第一个满足 $Y[i] \ge t$ 的下标，则 $\min_{y \in Y} \lvert y - t \rvert$ 在 $y \in \{Y[i], Y[i-1]\}$ 处取得（越界者忽略）。

**证明**：当 $y \le t$ 时 $\lvert y - t \rvert = t - y$，随 $y$ 增大而严格减小；当 $y \ge t$ 时 $\lvert y - t \rvert = y - t$，随 $y$ 增大而严格增大。故 "$\le t$ 的候选"中最优者是其中最大者 $Y[i-1]$，"$\ge t$ 的候选"中最优者是其中最小者 $Y[i]$，全局最优必居其一。∎

**引理 3（空子集覆盖）**：空子序列（和为 0）在算法的搜索空间内。

**证明**：两半的子集和枚举都从 `[0]` 起步，$x = y = 0$ 对应两边都取空集，即整体空子序列。∎

**定理**：算法返回 $\min_{S} \lvert sum(S) - goal \rvert$，其中 $S$ 取遍 `nums` 的所有子序列。

**证明**：由引理 1，算法遍历的 $(x, y)$ 对与所有子序列之和一一对应，搜索空间无遗漏、无多余；由引理 2，对每个 $x$，二分检查的两个候选恰好包含使 $\lvert x + y - goal \rvert$ 最小的 $y$；对所有 $x$ 取最小值，即得全空间最小值。由引理 3，空子序列亦被覆盖。故算法返回值即所求最小值。∎

## 6. 复杂度分析

- **时间复杂度**：$O(2^{n/2} \cdot n)$
  - 翻倍法枚举两半子集和：$O(2^{n/2})$；
  - 右半排序：$O(2^{n/2} \log 2^{n/2}) = O(2^{n/2} \cdot n)$；
  - 匹配：$2^{n/2}$ 次二分，每次 $O(\log 2^{n/2}) = O(n)$。
  - $n = 40$ 时约 $2^{20} \times 20 \approx 2 \times 10^7$ 量级的基本操作，轻松通过。
- **空间复杂度**：$O(2^{n/2})$，存储两半的子集和数组（$n = 40$ 时各 $2^{20}$ 个，C++ `long long` 共约 16 MB；Python 列表约几十 MB，也在限制内）。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int minAbsDifference(vector<int>& nums, int goal) {
        int n = nums.size();
        int m = n / 2;

        auto subsetSums = [](const vector<int>& arr) {
            vector<long long> sums{0};
            for (int a : arr) {
                int sz = sums.size();
                for (int i = 0; i < sz; ++i)
                    sums.push_back(sums[i] + a);
            }
            return sums;
        };

        vector<long long> X = subsetSums({nums.begin(), nums.begin() + m});
        vector<long long> Y = subsetSums({nums.begin() + m, nums.end()});
        sort(Y.begin(), Y.end());

        long long ans = LLONG_MAX;
        auto upd = [&](long long s) {
            long long d = s - goal;
            ans = min(ans, d < 0 ? -d : d);
        };

        for (long long x : X) {
            long long t = (long long)goal - x;
            auto it = lower_bound(Y.begin(), Y.end(), t);
            if (it != Y.end()) upd(x + *it);
            if (it != Y.begin()) upd(x + *(it - 1));
            if (ans == 0) return 0;
        }
        return (int)ans;
    }
};
```

### Python

```python
from bisect import bisect_left
from math import inf

class Solution:
    def minAbsDifference(self, nums: List[int], goal: int) -> int:
        n = len(nums)
        m = n // 2

        def subset_sums(arr):
            sums = [0]
            for a in arr:
                sums += [s + a for s in sums]
            return sums

        X = subset_sums(nums[:m])
        Y = subset_sums(nums[m:])
        Y.sort()

        ans = inf
        for x in X:
            t = goal - x
            i = bisect_left(Y, t)
            if i < len(Y):
                ans = min(ans, abs(x + Y[i] - goal))
            if i > 0:
                ans = min(ans, abs(x + Y[i - 1] - goal))
            if ans == 0:
                return 0
        return ans
```

## 8. 边界情况与易错点

1. **整数溢出**：$\lvert sum \rvert \le 40 \times 10^7 = 4 \times 10^8$，$\lvert x + y - goal \rvert \le 1.4 \times 10^9$，已接近 `int` 上限 $2.1 \times 10^9$。C++ 中和数组、`goal` 参与的中间运算必须用 `long long`；Python 无此问题。
2. **空子序列**：必须包含"什么都不选"（和为 0）。翻倍法从 `[0]` 起步天然覆盖；若改用按掩码枚举，勿漏掉掩码 0。示例 3 中空子序列正是最优解。
3. **二分边界**：`lower_bound` 可能返回首（无左候选）或尾（无右候选），两侧都要判空，只查一侧会漏解。
4. **负数元素**：排序数组上的二分对负数完全适用，**不需要**值域偏移；切勿套用"下标即和"的非负技巧。
5. **n 为奇数或 n = 1**：$m = \lfloor n/2 \rfloor$ 使右半比左半多至多 1 个元素，两半仍 $\le 20$；$n = 1$ 时左半为空，`subset_sums` 返回 `[0]`，算法依然正确。
6. **内存**：两半各 $2^{20}$ 个和。若卡内存，可改为排序较小的一半、遍历较大的一半，或对排序侧去重。
7. **提前退出的位置**：应在循环体内更新 `ans` 后立即判断并返回，放到循环外就失去了剪枝效果。

**延伸思考**：

- **双指针替代二分**：把 $X$ 也排序后，可用双指针在 $O(2^{n/2})$ 内完成配对（一端从最小 $x$、另一端从最大 $y$ 出发，按 $x + y$ 与 $goal$ 的大小关系移动指针），此时排序成为复杂度瓶颈。
- **三段折半**：若 $n \le 60$，可拆成三段各 $2^{20}$ 枚举后两两合并，但实现复杂度陡增，比赛中极少使用。
- **与子集和问题的关系**：本题是"最近子集和"判定。经典子集和问题是 NP 困难的，仅在值域多项式有界时可伪多项式求解；本题值域爆炸，所以必须折半——这也解释了为什么 $n \le 40$ 恰是此套路的标准信号。
