# LeetCode 移除石子的最大得分 题解

## 1. 题目概述

- **标题 / 题号**：移除石子的最大得分（#1753，medium）
- **链接**：https://leetcode.cn/problems/maximum-score-from-removing-stones/
- **来源**：LeetCode 第 227 场周赛 Q2
- **难度**：中等
- **标签**：贪心，数学，堆（优先队列）

**题意**：面前有三堆石子，大小分别为 $a$、$b$、$c$。每回合必须从**两个不同的非空堆**中各取出一颗石子，得 $1$ 分；当存在**两个或更多空堆**时游戏停止。求可能获得的最大分数。

**约束**：

- $1 \le a, b, c \le 10^5$

## 2. 示例

**示例 1**

```text
输入：a = 2, b = 4, c = 6
输出：6
解释：(2,4,6) → (1,4,5) → (0,4,4) → (0,3,3) → (0,2,2) → (0,1,1) → (0,0,0)，
      前 2 回合取 (a,c)，后 4 回合取 (b,c)，两个小堆 6 颗全部灌入 c。
```

**示例 2**

```text
输入：a = 4, b = 4, c = 6
输出：7
解释：a+b = 8 > c = 6，三堆势均力敌，得 ⌊14/2⌋ = 7 分。
```

**示例 3**

```text
输入：a = 1, b = 8, c = 8
输出：8
解释：b、c 两堆互配 8 回合后同时取空；a 的 1 颗成为孤石，游戏停止。
```

**补充示例**

```text
输入：a = 1, b = 1, c = 2
输出：2
解释：先取 (b,c) 再取 (a,c)。若误取 (a,b)，则 a、b 同时取空只得 1 分（见 §3.4）。
```

## 3. 解题思路

### 3.1 暴力思路：优先队列模拟

最直接的做法：用优先队列维护三堆，每回合弹出**最大的两堆**各减 $1$、得分 $+1$，直到非空堆不足两个。总回合数不超过 $\frac{a+b+c}{2} \le 1.5 \times 10^5$，模拟本身 $O\left(\frac{a+b+c}{2}\right)$ 完全可过。

但只有三个整数的博弈，答案理应是一个**封闭公式**——模拟既没有沉淀可迁移的观察，也掩盖了问题的结构。我们转而寻找 $O(1)$ 公式。

### 3.2 核心观察：两个上界夹出答案

![两种形态的概念对比](images/stones_two_cases_concept.svg)

不妨**排序** $a \le b \le c$，把 $c$ 称为「大堆」、$a, b$ 合称「小堆」。设最优得分为 $s$，可以给出两个方向完全不同的上界：

1. **上界①（总量上界）**：每回合恰好消耗 $2$ 颗石子换 $1$ 分，共消耗 $2s$ 颗，故
   $$s \le \left\lfloor \frac{a+b+c}{2} \right\rfloor$$
2. **上界②（小堆上界）**：任何一回合要么涉及大堆 $c$（消耗 $1$ 颗小堆石子），要么是 $a,b$ 之间的回合（消耗 $2$ 颗小堆石子）——无论哪种，**每回合至少消耗 $1$ 颗小堆石子**。小堆总共只有 $a+b$ 颗，故
   $$s \le a + b$$

> 💡 **一句话结论**：$s \le \min\left(a+b,\ \left\lfloor \frac{a+b+c}{2} \right\rfloor\right)$，且这个值**总能取到**——瓶颈由「大堆吃不吃得下全部小石子」（即 $a+b$ 与 $c$ 的大小关系）决定：
>
> - **一家独大**（$c \ge a+b$）：小堆全部灌入大堆，得分恰为 $a+b$，大堆剩 $c-a-b$ 颗孤石；
> - **势均力敌**（$c \le a+b$）：三堆两两互配，消耗到只剩 $0$ 或 $1$ 颗，得分恰为 $\left\lfloor \frac{a+b+c}{2} \right\rfloor$。

两个分支在 $a+b = c$ 处无缝衔接（此时 $a+b = \left\lfloor \frac{a+b+c}{2} \right\rfloor$），因此一个 `min` 就覆盖全部情况。

### 3.3 算法流程

![公式化算法流程](images/stones_formula_flow.svg)

流程极简：排序（或只求最大值）→ 比较 $a+b$ 与 $c$（或直接对两个上界取 `min`）→ 输出。全程 $O(1)$。

若不放心公式，也可以写「每回合取**最大的两堆**」的贪心模拟作为对拍验证——注意是最大两堆，不是最小两堆（见 §3.4 的陷阱）。

### 3.4 示例演算

![示例演算与贪心陷阱](images/stones_walkthrough.svg)

**例 1：(2, 4, 6)**，$a+b = 6 = c$ 恰在边界：

| 回合 | 取堆 | 状态 (a,b,c) |
|------|------|--------------|
| 1 | (a,c) | (1, 4, 5) |
| 2 | (a,c) | (0, 4, 4) |
| 3 | (b,c) | (0, 3, 3) |
| 4 | (b,c) | (0, 2, 2) |
| 5 | (b,c) | (0, 1, 1) |
| 6 | (b,c) | (0, 0, 0) |

得分 $6 = a+b = \left\lfloor 12/2 \right\rfloor$，两个公式给出相同答案。

**贪心陷阱：(1, 1, 2)**，$\lfloor 4/2 \rfloor = 2$：

- 若每回合取**最小的两堆** $(a,b)$：一步后 $(0, 0, 2)$，两堆已空被迫停止，只得 $1$ 分 ✗
- 若每回合取**最大的两堆**：$(1,1,2) \xrightarrow{(b,c)} (1,0,1) \xrightarrow{(a,c)} (0,0,0)$，得 $2$ 分 ✓

直觉：只有 $3$ 堆时，把两个小堆互相配对会加速「非空堆数量」的衰减；而每回合让最大堆参与消耗，才能维持三堆势均力敌，把石子「两两配对」的结构保持到最后。

## 4. 算法细节

1. **排序统一方向**：设 $a \le b \le c$（代码中可用 `max({a,b,c})` 求大堆、`sum - max` 即小堆之和，避免显式排序）。
2. **两分支公式**：
   - $c \ge a+b$：答案 $= a+b = \text{sum} - \max$；
   - $c \le a+b$：答案 $= \left\lfloor \text{sum}/2 \right\rfloor$（C++ `/` 对正数即下取整）。
3. **统一写法**：$\min\left(\left\lfloor \text{sum}/2 \right\rfloor,\ \text{sum} - \max\right)$，无需分支判断。
4. **贪心模拟版**：每回合排序后取 $b, c$（最大的两堆）各减 $1$；循环条件是「非空堆数 $\ge 2$」，可用 `(a>0)+(b>0)+(c>0) >= 2` 优雅表达。
5. 本题 $a, b, c \le 10^5$，`int` 足够；若 $k$ 堆推广到 $10^{18}$ 级别，公式依然 $O(1)$ 直接算，模拟则不可行。

## 5. 正确性证明

**引理 1（总量上界）**：$s \le \left\lfloor \frac{a+b+c}{2} \right\rfloor$。

**证明**：$s$ 个回合共取走 $2s$ 颗石子，而石子总数为 $a+b+c$，故 $2s \le a+b+c$。∎

**引理 2（小堆上界）**：排序 $a \le b \le c$ 后，$s \le a+b$。

**证明**：将每个回合分类：涉及 $c$ 的回合（$c$ 与另一堆各取 $1$ 颗，消耗 $1$ 颗小堆石子）与不涉及 $c$ 的回合（只能是 $a, b$ 各取 $1$ 颗，消耗 $2$ 颗小堆石子）。两类回合每回合消耗的小堆石子数均 $\ge 1$，而小堆石子共 $a+b$ 颗，故回合总数 $s \le a+b$。∎

**引理 3（一家独大时可达）**：若 $c \ge a+b$，则存在合法方案得 $a+b$ 分。

**证明（构造）**：前 $a$ 个回合固定取 $(a, c)$，后 $b$ 个回合固定取 $(b, c)$。合法性：取 $(a,c)$ 的第 $i$ 个回合前，$a$ 剩 $a-i+1 \ge 1$，$c$ 剩 $c-i+1 \ge c-a+1 \ge b+1 \ge 1$；取 $(b,c)$ 的第 $j$ 个回合前，$b$ 剩 $b-j+1 \ge 1$，$c$ 剩 $c-a-j+1 \ge c-a-b+1 \ge 1$。全部 $a+b$ 个回合合法，结束时 $a = b = 0$（两堆空，游戏终止），得分 $a+b$。∎

**引理 4（势均力敌时可达）**：若 $a \le b \le c \le a+b$，则执行「每回合从最大的两堆各取一颗」的策略，恰得 $\left\lfloor \frac{a+b+c}{2} \right\rfloor$ 分。

**证明**：记不变量 $I$：「排序后最大堆 $\le$ 其余两堆之和」。初始 $c \le a+b$，$I$ 成立。分三步：

（a）**最大值不增**。回合前排序 $x \le y \le z$，策略取 $y, z$，新三元组为 $\{x, y-1, z-1\}$，新最大值 $\max(x, z-1) \le z$。

（b）**不变量保持**。设回合前 $x \le y \le z$ 且 $z \le x+y$（$I$ 成立）。取 $y, z$ 后新和 $\Sigma' = x+y+z-2$，新最大 $z' = \max(x, z-1)$（因 $z-1 \ge y-1$）：

- 若 $z' = z-1$：需 $2(z-1) \le \Sigma'$，即 $z \le x+y$，由 $I$ 成立 ✓；
- 若 $z' = x$（即 $x \ge z-1$）：需 $2x \le x+y+z-2$，即 $x \le y+z-2$；由 $x \le y$ 及 $z \ge 2$ 成立（若 $z = 1$ 则 $x = y = z = 1$，取后为 $(1,0,0)$ 直接终止，无需保持）✓；
- 边界 $y = 1$：则 $x = 1$，由 $I$ 知 $z \le 2$。若 $z = 1$，取后 $(1,0,0)$ 终止；若 $z = 2$，取后 $(1,0,1)$，排序为 $(0,1,1)$，$1 \le 0+1$，$I$ 保持 ✓。

（c）**终态剩余 $\le 1$**。终止时状态形如 $(r, 0, 0)$。考察最后一步前的状态：三堆非空 $(x,y,z)$ 时取 $(y,z)$ 恰使一堆变空，意味着 $y = 1$ 或 $z = 1$；前者由（b）的边界分析得 $x=1, z \le 2$，后者意味着 $(1,1,1)$。于是非终止的转移只有 $(1,1,2) \to (1,0,1)$，随后 $(1,1) \to (0,0)$。因此终态只能是 $(1,0,0)$ 或 $(0,0,0)$，即 $r \in \{0, 1\}$。

由 $2s = (a+b+c) - r$ 且 $r \equiv a+b+c \pmod 2$，得 $s = \left\lfloor \frac{a+b+c}{2} \right\rfloor$。∎

**定理**：最大得分 $= \min\left(a+b,\ \left\lfloor \frac{a+b+c}{2} \right\rfloor\right)$（排序 $a \le b \le c$ 后）。

**证明**：上界由引理 1、引理 2 给出。可达性：$c \ge a+b$ 时由引理 3 得 $a+b$ 分；$c \le a+b$ 时由引理 4 得 $\left\lfloor \frac{a+b+c}{2} \right\rfloor$ 分。又 $c \ge a+b$ 时 $2(a+b) \le a+b+c$，故 $a+b \le \left\lfloor \frac{a+b+c}{2} \right\rfloor$，$\min$ 取 $a+b$；$c \le a+b$ 时 $2(a+b) \ge a+b+c$，故 $a+b \ge \left\lfloor \frac{a+b+c}{2} \right\rfloor$，$\min$ 取后者。两个分支与 $\min$ 完全一致。∎

## 6. 复杂度分析

- **时间复杂度**：$O(1)$。一次求和、一次求最大值、一次比较。贪心模拟版为 $O(a+b+c)$，本题为 $3 \times 10^5$ 亦可过。
- **空间复杂度**：$O(1)$。仅常数个变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maximumScore(int a, int b, int c) {
        int sum = a + b + c;
        int mx = max({a, b, c});
        return min(sum / 2, sum - mx);   // 上界①与上界②取 min
    }
};
```

### C++（贪心模拟版，比赛时用于对拍验证）

```cpp
class Solution {
public:
    int maximumScore(int a, int b, int c) {
        int score = 0;
        while ((a > 0) + (b > 0) + (c > 0) >= 2) {
            if (a < b) swap(a, b);
            if (b < c) swap(b, c);
            if (a < b) swap(a, b);       // 排序 a >= b >= c
            a--; b--; score++;           // 每回合取最大的两堆
        }
        return score;
    }
};
```

### Python

```python
class Solution:

```

### Python（贪心模拟版）

```python
class Solution:
    def maximumScore(self, a: int, b: int, c: int) -> int:
        score = 0
        while (a > 0) + (b > 0) + (c > 0) >= 2:
            a, b, c = sorted((a, b, c))
            b -= 1                        # 取最大的两堆 b、c
            c -= 1
            score += 1
        return score
```

## 8. 边界情况与易错点

1. **边界 $a+b = c$**：两个公式给出相同答案（如例 1 的 $(2,4,6)$ 得 $6$），`min` 自动处理，分支条件写 $\le$ 或 $<$ 均可。
2. **总和为奇数**：势均力敌时剩 $1$ 颗孤石（如例 3 的 $(1,8,8)$，$17$ 颗消耗 $16$ 颗得 $8$ 分），下取整天然正确，勿写成四舍五入。
3. **贪心方向陷阱**：每回合应取**最大的两堆**，取最小两堆在 $(1,1,2)$ 上只得 $1$ 分（正确答案 $2$）。
4. **最小反例 $(1,1,1)$**：答案 $1$，取任意两堆后剩 $(1,0,0)$ 停止，公式 $\min(1, 1) = 1$ ✓。
5. **上界②的方向**：是「**小堆**之和 $a+b$」即 $\text{sum} - \max$，别写成大堆 $c$——大堆的石子可以全部被取走，$c$ 本身不是上界。
6. **不要记忆化搜索状态 $(a,b,c)$**：状态空间高达 $(10^5)^3$，而贪心结构决定了每次操作后状态高度受限，公式化才是正解。
7. 本题数值范围 `int` 无溢出风险；若为 $10^{18}$ 级别则必须用公式 + `long long`。
