# LeetCode 检查数组是否经排序和轮转得到 题解

## 1. 题目概述

- **标题 / 题号**：检查数组是否经排序和轮转得到（#1752，easy）
- **链接**：https://leetcode.cn/problems/check-if-array-is-sorted-and-rotated/
- **来源**：LeetCode 第 227 场周赛 Q1
- **难度**：简单
- **标签**：数组

**题意**：给定数组 `nums`，其**源数组**与 `nums` 元素完全相同但按**非递减顺序**排列。若 `nums` 能由源数组**轮转若干位置**（包括 0 个位置）得到，返回 `true`，否则返回 `false`。

> **轮转定义**：数组 $A$ 轮转 $x$ 位后得到长度相同的数组 $B$，满足 $B[i] = A[(i+x) \bmod n]$。源数组中**可能存在重复项**，因此判定必须允许相等元素。

**约束**：

- $1 \le n = \text{nums.length} \le 100$
- $1 \le \text{nums}[i] \le 100$

## 2. 示例

**示例 1**

```text
输入：nums = [3,4,5,1,2]
输出：true
解释：源数组为 [1,2,3,4,5]，轮转 x = 2 位得到 [3,4,5,1,2]。
```

**示例 2**

```text
输入：nums = [2,1,3,4]
输出：false
解释：[2,1,3,4] 存在两处下降（2→1 与环绕的 4→2），
      无法由任何非递减源数组轮转得到。
```

**示例 3**

```text
输入：nums = [1,2,3]
输出：true
解释：源数组即 [1,2,3]，轮转 x = 0 位（不转）。
```

## 3. 解题思路

### 3.1 暴力思路：枚举轮转偏移量

枚举每个偏移量 $x \in [0, n)$，把 `nums` 逆向还原成候选源数组 $[\text{nums}[(i+x) \bmod n]]$，检查是否非递减。每个 $x$ 验证 $O(n)$，总计 $O(n^2)$、空间 $O(n)$。$n \le 100$ 时约 $10^4$ 次操作完全可过，但**枚举偏移是多余的**——我们不需要知道「转了几位」，只需要判断「是否存在合法切点」。

### 3.2 核心观察：断点数是轮转不变量

![断点数是轮转不变量](images/sorted_rotated_ring_invariant.svg)

**断点**定义：满足 $\text{nums}[i] > \text{nums}[(i+1) \bmod n]$ 的位置 $i$，其中下标取模意味着**首尾环绕对** $(\text{nums}[n-1], \text{nums}[0])$ 也参与检查。

**两个关键事实**：

1. **非递减数组的断点数 $\le 1$**：内部相邻对全部非降，唯一可能下降的是环绕对 $(A[n-1], A[0])$（最大值绕回最小值处）；全相等时为 0。
2. **轮转不改变断点数**：$B[i] = A[(i+x) \bmod n]$ 只是环上元素的循环挪位，$B$ 的每个环绕相邻对 $(B[i], B[(i+1) \bmod n])$ 都与 $A$ 的某个环绕相邻对**完全相同**（一一对应）。

> 💡 **一句话结论**：`nums` 能由排序数组轮转得到 $\iff$ `nums` 的断点数 $\le 1$。把数组看成环，排序数组在环上至多一处「下坡」，轮转只是转环，不增不减下坡。

### 3.3 算法流程

![断点计数算法流程](images/sorted_rotated_breakpoint_flow.svg)

一次遍历统计断点数 `cnt`，最后判断 `cnt <= 1`。注意 $(i+1) \bmod n$ 的写法把内部对和首尾环绕对**统一**在同一循环里，无需特判。

### 3.4 示例演算

![三组样例的相邻对走查](images/sorted_rotated_pairs_walkthrough.svg)

| 数组 | 相邻对检查（含环绕） | 断点数 | 结论 |
|------|---------------------|--------|------|
| `[3,4,5,1,2]` | (3,4)✓ (4,5)✓ **(5,1)✗** (1,2)✓ (2,3)环绕✓ | 1 | true |
| `[2,1,3,4]` | **(2,1)✗** (1,3)✓ (3,4)✓ **(4,2)环绕✗** | 2 | false |
| `[1,2,3]` | (1,2)✓ (2,3)✓ **(3,1)环绕✗** | 1 | true |

注意第三个例子：**未轮转的有序数组在环绕对处天然有 1 个断点**，这正是判定条件取 $\le 1$ 而非 $= 0$ 的原因。

## 4. 算法细节

1. **统一环绕下标**：循环 `i = 0 … n-1`，比较 `nums[i]` 与 `nums[(i+1) % n]`，最后一个位置自动比较 `nums[n-1]` 与 `nums[0]`。
2. **严格大于才算断点**：题意是非递减（允许相等），故 `nums[i] == nums[(i+1)%n]` 不是断点，如 `[6,10,6]` 中 (6,6) 环绕对不计数。
3. **判定条件 `cnt <= 1`**：0 个断点对应全相等数组（轮转 0 位），1 个断点对应恰好转过一切的合法轮转，$\ge 2$ 个直接否决。
4. 计数器无需提前退出，$n \le 100$ 一遍扫完即可（也可在 `cnt >= 2` 时提前 `return false`）。

## 5. 正确性证明

**引理 1（轮转不变性）**：设 $B[i] = A[(i+x) \bmod n]$，则 $B$ 的环绕相邻对与 $A$ 的环绕相邻对一一对应相等，从而两者的断点数相同。

**证明**：对每个 $i \in [0, n)$，$(B[i], B[(i+1) \bmod n]) = (A[(i+x) \bmod n],\ A[(i+1+x) \bmod n])$。当 $i$ 取遍 $[0, n)$ 时 $j = (i+x) \bmod n$ 是 $[0, n)$ 上的双射，故 $B$ 的环绕对集合恰为 $\{(A[j], A[(j+1) \bmod n]) : j \in [0, n)\}$，与 $A$ 的完全相同。断点由对取值决定，断点数不变。∎

**引理 2（排序数组的断点数）**：非递减数组 $A$ 的断点数 $\le 1$，且等于 $0$ 当且仅当 $A$ 所有元素相等。

**证明**：内部对满足 $A[i] \le A[i+1]$，全部不构成断点。唯一剩余的环绕对 $(A[n-1], A[0])$：若 $A[0] < A[n-1]$ 则是一个断点（此时数组非全等）；若 $A[0] = A[n-1]$，由非递减性 $A[0] \le A[i] \le A[n-1]$ 夹逼得全部相等，断点数为 $0$。∎

**定理**：`nums` 可由某个非递减数组轮转得到 $\iff$ `nums` 的断点数 $\le 1$。

**证明**：

（$\Rightarrow$）设源数组 $A$ 非递减，`nums` 由 $A$ 轮转得到。由引理 2，$A$ 的断点数 $\le 1$；由引理 1，`nums` 的断点数与之相等，故 $\le 1$。

（$\Leftarrow$）对 `nums` 的断点数分类：

- **断点数为 0**：环绕全部非降，即 $\text{nums}[0] \le \text{nums}[1] \le \cdots \le \text{nums}[n-1] \le \text{nums}[0]$，链两端夹逼得所有元素相等，`nums` 自身非递减，取 $x = 0$ 即可。
- **恰有 1 个断点，位于位置 $k$**（$\text{nums}[k] > \text{nums}[(k+1) \bmod n]$）：从 $k+1$ 起环绕读取构造 $A = [\text{nums}[k+1], \ldots, \text{nums}[n-1], \text{nums}[0], \ldots, \text{nums}[k]]$。$A$ 的内部相邻对恰是 `nums` 中**除断点外**的全部环绕相邻对（均非降），故 $A$ 非递减；而 `nums` 是 $A$ 从位置 $k+1$ 处切开再首尾拼接的结果，即 $A$ 的某次轮转。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。一次遍历检查全部 $n$ 个环绕相邻对。
- **空间复杂度**：$O(1)$。仅用一个计数器 `cnt` 与循环变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool check(vector<int>& nums) {
        int n = nums.size(), cnt = 0;
        for (int i = 0; i < n; i++) {
            if (nums[i] > nums[(i + 1) % n]) {
                cnt++;
            }
        }
        return cnt <= 1;
    }
};
```

### Python

```python
class Solution:
    def check(self, nums: List[int]) -> bool:
        n = len(nums)
        cnt = sum(nums[i] > nums[(i + 1) % n] for i in range(n))
        return cnt <= 1
```

## 8. 边界情况与易错点

1. **$n = 1$**：唯一环绕对 $(a, a)$ 不构成断点，`cnt = 0`，返回 `true`。
2. **全相等数组**（如 `[1,1,1]`）：断点数为 0，返回 `true`（轮转 0 位）。
3. **未轮转的有序数组**（如 `[1,2,3]`）：环绕对 $(3,1)$ 是天然断点，`cnt = 1` 仍返回 `true`。**易错**：误以为有序数组应无断点而漏检环绕对，会把 `[1,2,3]` 判成 `false`。
4. **非递减而非严格递增**：相等对不是断点。`[6,10,6]` 的环绕对 $(6,6)$ 不计数，断点仅 $(10,6)$ 一处，返回 `true`（源数组 `[6,6,10]` 轮转 3 位）。
5. **两个断点必假**：如 `[2,1,3,4]`，内部断点 $(2,1)$ 与环绕断点 $(4,2)$ 并存，环上出现两处下坡，无论怎么转都无法变成单调序列。
6. 本题 $n \le 100$、元素 $\le 100$，无溢出风险；即便 $n$ 达 $10^9$ 级别流式输入，该算法依然线性可解。
