# LeetCode 使数组奇偶交替的最少操作 题解

## 1. 题目概述

- **标题 / 题号**：使数组奇偶交替的最少操作（#3854，medium）
- **链接**：https://leetcode.cn/problems/minimum-operations-to-make-array-parity-alternating/
- **来源**：LeetCode 第 177 场双周赛 Q3
- **难度**：中等
- **标签**：贪心、数组

**题意**：给定整数数组 `nums`。称数组**奇偶交替**，如果对每个 $0 \le i < n-1$，`nums[i]` 与 `nums[i+1]` 的奇偶性都不同（一奇一偶）。一次操作可以把任意元素加 1 或减 1。

要求返回长度为 2 的数组 $answer$：

- $answer[0]$：把数组变成奇偶交替所需的**最少操作次数**；
- $answer[1]$：在所有「**恰好**用了 $answer[0]$ 次操作」得到的奇偶交替数组中，$\max - \min$ 的**最小可能值**。

长度为 1 的数组视为奇偶交替。

**约束**：

- $1 \le \text{nums.length} \le 10^5$
- $-10^9 \le \text{nums}[i] \le 10^9$

## 2. 示例

**示例 1**

```text
输入：nums = [-2,-3,1,4]
输出：[2,6]
解释：模板「偶奇偶奇」下，下标 2 的 1（奇）与下标 3 的 4（偶）都错位：
      把 1 加 1 得 2，把 4 减 1 得 3 → [-2,-3,2,3]，交替成立，用了 2 次操作。
      此时 max - min = 3 - (-3) = 6，是所有恰好 2 次操作的方案中最小的。
```

**示例 2**

```text
输入：nums = [0,2,-2]
输出：[1,3]
解释：模板「偶奇偶」下只有下标 1 的 2 错位，减 1 得 1 → [0,1,-2]，用 1 次操作。
      max - min = 1 - (-2) = 3。
```

**示例 3**

```text
输入：nums = [7]
输出：[0,0]
解释：单元素数组天然交替；模板「奇」下 0 次操作，极差 7 - 7 = 0。
```

## 3. 解题思路

### 3.1 暴力思路

奇偶交替只有两种模板：**偶奇偶奇…**（下标 0 为偶）和 **奇偶奇偶…**（下标 0 为奇），记为 $A$、$B$。逐位对照模板统计「错位数」，就是该模板所需的最少操作数：错位意味着奇偶性不对，至少要改 1 次，而加 1 或减 1 恰好能翻转奇偶，所以 1 次就够。

于是 $answer[0] = \min(w_A, w_B)$，其中 $w$ 是错位数——这部分是 $O(n)$ 的。

麻烦在 $answer[1]$：错位的位置有 `v-1` 和 `v+1` 两种改法，朴素枚举所有 $2^{w}$ 种组合求极差，$w$ 可达 $10^5$，直接爆炸。

![两种奇偶模板：逐位比对，错位必须 ±1 翻转奇偶](images/bw177_q3_two_patterns.svg)

### 3.2 核心观察：把「恰好最少次数」翻译成「每位的取值集合固定」

> 💡 **关键一步**：由于总操作次数被钉死在最小值上，每个位置的操作次数也被钉死了。

- 一个位置如果**奇偶已正确**，它若被改动，改动次数必须是**偶数**次（否则奇偶会变）。而偶数次至少 2 次，会超出总预算，所以这类位置只能**保持原值**。
- 一个位置如果**奇偶错误**，改动次数必须是**奇数**次，至少 1 次；而总预算恰好等于错位数，所以它只能**恰好改 1 次**，取值只能是 $v-1$ 或 $v+1$。

也就是说，「恰好 $answer[0]$ 次操作得到的交替数组」= 「正确位取 $v$、错误位在 $\{v-1, v+1\}$ 里任选一个」的所有组合。极差只由**最大值和最小值**决定，而每个错误位只贡献一个数，于是可以**逐位独立**地贪心。

![极差收窄：正确位定住 lo 与 hi，错误位在 v−1 / v+1 中挑](images/bw177_q3_range_shrink.svg)

设正确位的最小、最大值分别为 $lo, hi$（因为它们不动，最终数组的 $\min \le lo$、$\max \ge hi$ 恒成立）。对某个错误位的值 $v$：

| 情形 | 贪心选择 | 理由 |
|------|---------|------|
| $v-1 \ge lo$ | 取 $v-1$ | 两个候选都不低于 $lo$，取下限不改变最小值，同时让上限尽可能小 |
| $v-1 < lo$ 且 $v+1 \le hi$ | 取 $v+1$ | $v+1$ 落在 $[lo,hi]$ 里，对两端都没影响；取 $v-1$ 会额外压低最小值 |
| $v-1 < lo$ 且 $v+1 > hi$ | 取任意 | 此时必有 $hi - lo \le 1$，只有 $hi = lo$ 可能发生，两种选法极差相同（差 1） |

合并成一句话就是：**若 $v-1 \ge lo$ 就取 $v-1$，否则取 $v+1$**。

### 3.3 算法流程

![算法流程：两个模板各算 (操作数, 极差)](images/bw177_q3_flow.svg)

```text
1. best_ops = +inf, best_rng = +inf
2. for start in {0, 1}:                       # 0 = 下标 0 取偶，1 = 下标 0 取奇
3.     ops = 0; lo = +inf; hi = -inf; bad = []
4.     for i, v in enumerate(nums):
5.         若 v 的奇偶 == (start + i) % 2:     # 该位已正确
6.             lo = min(lo, v); hi = max(hi, v)
7.         否则:
8.             ops += 1; bad.append(v)
9.     mn = lo; mx = hi
10.    for v in bad:
11.        c = (v - 1 >= lo) ? v - 1 : v + 1   # 贪心
12.        mn = min(mn, c); mx = max(mx, c)
13.    rng = mx - mn
14.    若 (ops, rng) 比当前最优更小（先比 ops，再比 rng）: 更新
15. 返回 [best_ops, best_rng]
```

### 3.4 示例演算

对示例 1 的 `nums = [-2,-3,1,4]`：

| 模板 | 逐位匹配情况 | $ops$ | 正确位 $[lo,hi]$ | 错误位贪心取值 | 极差 |
|------|-------------|-------|------------------|---------------|------|
| 偶奇偶奇 | ✓ ✓ ✗ ✗（下标 2、3 错） | 2 | $[-3,-2]$ | $1 \to 0$（$0 \ge -3$）；$4 \to 3$（$3 \ge -3$） | $3-(-3)=6$ |
| 奇偶奇偶 | ✗ ✗ ✓ ✓（下标 0、1 错） | 2 | $[1,4]$ | $-2 \to -1$（$-3 < 1$）；$-3 \to -2$（$-4 < 1$） | $4-(-2)=6$ |

两个模板操作数都是 2、极差都是 6，答案 $[2,6]$。示例 2 的 `[0,2,-2]` 中模板「偶奇偶」错位 1 个、极差 3，模板「奇偶奇」错位 2 个，因此取前者得 $[1,3]$。示例 3 只有一个元素，模板「奇」零错位、极差 0，答案 $[0,0]$。

## 4. 算法细节

1. **负数的奇偶**：C++ 里 `-3 % 2 == -1`，必须用 `((v % 2) + 2) % 2` 归一化到 $\{0,1\}$；Python 的 `%` 本身就返回非负值，可直接用。
2. **哨兵初值**：$lo$ 初始化为 $+\infty$、$hi$ 初始化为 $-\infty$。当某个模板下**所有位都错**（不存在正确位）时，贪心条件 $v-1 \ge lo$ 恒为假，代码会自动退化成「全取 $v+1$」，不会崩溃；而且这种模板必然不是最优（见下文引理 4）。
3. **极差用 64 位**：元素绝对值可达 $10^9$，$\max - \min$ 最坏约 $2\times10^9 + 2$，超过 32 位 `int` 的正向范围，必须用 `long long`。
4. **比较顺序**：先比 $ops$，$ops$ 相同再比 $rng$，两者都相同则无需更新。不要图省事把 $ops$ 与 $rng$ 拼成一个数比较（$rng$ 的量级会污染 $ops$ 的主导地位）。
5. **不需要真的修改数组**：全程只做统计与贪心选择，原数组保持不变，这也是 $O(1)$ 额外空间的关键。

## 5. 正确性证明

**引理 1（操作数与错位数）**：设某个模板下有 $w$ 个位置奇偶错误，则把 `nums` 变成该模板所需的最少操作数恰为 $w$，且总操作数恰好为 $w$ 时，每个正确位改动 0 次、每个错误位改动 1 次。

**证明**：一次操作改变元素奇偶性当且仅当该元素恰好被操作 1 次（奇数次）；要让错误位奇偶翻转，它必须被操作奇数次，至少 1 次，故总次数 $\ge w$。另一方面对每个错误位做一次 $+1$ 即可翻转奇偶，故 $w$ 次可达。若总次数恰为 $w$，则每个错误位都恰好用了 1 次，且没有多余次数分给正确位，故正确位 0 次。∎

**引理 2（取值集合）**：在「恰好 $answer[0]$ 次操作」且达到最少操作数的方案中，正确位的值恒为 $v$，错误位的值恒为 $v-1$ 或 $v+1$。

**证明**：由引理 1，正确位改动 0 次，值不变；错误位改动 1 次，只能是 $+1$ 或 $-1$。∎

**引理 3（逐位贪心最优）**：固定 $lo,hi$（正确位的极值），对任一错误位值 $v$，令 $c^\*$ 为贪心取值，则对任意其它合法取值 $c$，有 $\max(hi, c^\*) \le \max(hi, c)$ 且 $\min(lo, c^\*) \ge \min(lo, c)$，或两者同时成立/同时取等。

**证明**：按三种情形讨论。

- $v-1 \ge lo$：贪心取 $c^\* = v-1 < v+1 = c$。因为 $c^\* \ge lo$，故 $\min(lo,c^\*) = lo = \min(lo,c)$（$c = v+1 > lo$）；又 $c^\* < c$ 给出 $\max(hi,c^\*) \le \max(hi,c)$。两项都满足。
- $v-1 < lo$ 且 $v+1 \le hi$：贪心取 $c^\* = v+1 \in [lo,hi]$，于是 $\min(lo,c^\*) = lo$、$\max(hi,c^\*) = hi$；而 $c = v-1 < lo$ 给出 $\min(lo,c) = v-1 < lo$，上限项 $\max(hi,c) = hi$。上限不变、下限更小，故贪心更优（严格）。
- $v-1 < lo$ 且 $v+1 > hi$：由 $v-1 < lo$ 得 $v \le lo$，由 $v+1 > hi$ 得 $v \ge hi$，而恒有 $hi \ge lo$，于是 $hi \le v \le lo \le hi$，即 $v = lo = hi$。此时取 $v+1 = lo+1$ 得 $\min = lo$、$\max = lo+1$，极差 1；取 $v-1 = lo-1$ 得 $\min = lo-1$、$\max = hi = lo$，极差同样是 1。两者相同，贪心不劣。∎

**引理 4（全错模板不会成为最优）**：若某模板在 `nums` 上所有位置都错，则另一模板全部正确，即 $answer[0] = 0$，该模板不会被选中。

**证明**：全错意味着 $nums[i]$ 的奇偶 $= 1 - (start+i) \bmod 2$，那么对另一模板 $start' = 1-start$，$(start'+i) \bmod 2 = 1 - (start+i)\bmod 2 = nums[i]$ 的奇偶，即所有位都正确，$w = 0$。而全错模板的 $w = n \ge 1 > 0$，故不会取到最小操作数。∎

**定理**：算法返回的 $answer$ 与题目要求一致。

**证明**：两种模板覆盖了所有奇偶交替数组（交替模式由首元素奇偶唯一确定）。对每个模板，引理 1 给出最少操作数 $w$；引理 2 刻画了达到 $w$ 次操作时的全部可行取值；引理 3 说明贪心在每个错误位上都使极差不变差，而总极差 $= \max(hi, \max_i c_i) - \min(lo, \min_i c_i)$ 关于各 $c_i$ 单调（上限项单调不减、下限项单调不增），故逐位取贪心得到该模板下的最小极差。最后由比较规则在模板间先取 $ops$ 最小、再取 $rng$ 最小，正是题目的双重目标。∎

## 6. 复杂度分析

- **时间**：$O(n)$。两个模板各做一次线性扫描统计 $ops$ 与 $[lo,hi]$，再一次线性扫描处理错误位，常数约为 $4n$ 次算术运算。
- **空间**：$O(n)$ 用于存放错误位的值（`bad` 列表 / vector），其余变量为常数个。若改成就地二次扫描（先求 $[lo,hi]$ 再直接算 $mn,mx$），可降到 $O(1)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> makeParityAlternating(vector<int>& nums) {
        int bestOps = INT_MAX;
        long long bestRange = LLONG_MAX;
        for (int start = 0; start < 2; start++) {
            int ops = 0;
            long long lo = LLONG_MAX, hi = LLONG_MIN;
            vector<long long> bad;
            for (int i = 0; i < (int)nums.size(); i++) {
                long long v = nums[i];
                int par = (int)((v % 2 + 2) % 2);
                if (par == (start + i) % 2) {
                    lo = min(lo, v);
                    hi = max(hi, v);
                } else {
                    ops++;
                    bad.push_back(v);
                }
            }
            long long mn = lo, mx = hi;
            for (long long v : bad) {
                long long c = (v - 1 >= lo) ? v - 1 : v + 1;
                mn = min(mn, c);
                mx = max(mx, c);
            }
            long long rng = mx - mn;
            if (ops < bestOps || (ops == bestOps && rng < bestRange)) {
                bestOps = ops;
                bestRange = rng;
            }
        }
        return {bestOps, (int)bestRange};
    }
};
```

### Python

```python
class Solution:
    def makeParityAlternating(self, nums: list[int]) -> list[int]:
        best_ops = None
        best_range = None
        for start in (0, 1):
            ops = 0
            lo, hi = float("inf"), float("-inf")
            pairs = []
            for i, v in enumerate(nums):
                if v % 2 == (start + i) % 2:
                    lo = min(lo, v)
                    hi = max(hi, v)
                else:
                    ops += 1
                    pairs.append(v)
            mn, mx = lo, hi
            for v in pairs:
                c = v - 1 if v - 1 >= lo else v + 1
                mn = min(mn, c)
                mx = max(mx, c)
            rng = mx - mn
            if best_ops is None or ops < best_ops or (ops == best_ops and rng < best_range):
                best_ops, best_range = ops, rng
        return [best_ops, best_range]
```

## 8. 边界情况与易错点

1. **$n = 1$**：两种模板中必有一个零操作（数组本身就是交替的），答案 $[0,0]$；此时 `bad` 为空，极差就是 $hi - lo = 0$，代码无需特判。
2. **负数取模**：C++ 中 `-4 % 2 == 0` 没问题，但 `-3 % 2 == -1`，与 `1` 比较会误判成「既非 0 也非 1」。统一用 `((v % 2) + 2) % 2`。
3. **极差溢出**：$10^9 - (-10^9) = 2\times10^9$ 超过 `int` 上限（约 $2.147\times10^9$ 虽勉强，但加上 ±1 的修正就可能越界），用 `long long` / Python 原生大整数最稳。
4. **「恰好」二字**：如果把 $answer[1]$ 理解成「所有交替数组里极差最小」，就会允许正确位也被改动 2 次，答案偏小。必须严格限制在「恰好 $answer[0]$ 次操作」的方案集合内。
5. **两个候选相等吗**：$v-1$ 与 $v+1$ 相差 2，永远不会相等，所以不存在「选哪个都一样」的取值层面歧义。
6. **两个模板都要算完**：不能只算错位数少的那个模板就返回——当两个模板错位数相同时，极差可能不同，必须都比较（示例 1 恰好相同，容易掩盖这个问题）。
7. **贪心条件的方向**：写 `v - 1 >= lo`，不要写成 `v - 1 > lo` 或 `v + 1 <= hi`。前者在 $v-1 = lo$ 时也取 $v-1$（正确），后者在 $v+1 > hi$ 时会错误地拒绝最优解。
