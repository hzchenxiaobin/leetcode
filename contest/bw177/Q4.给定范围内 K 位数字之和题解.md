# LeetCode 给定范围内 K 位数字之和 题解

## 1. 题目概述

- **标题 / 题号**：给定范围内 K 位数字之和（#3855，hard）
- **链接**：https://leetcode.cn/problems/sum-of-k-digit-numbers-in-a-range/
- **来源**：LeetCode 第 177 场双周赛 Q4
- **难度**：困难
- **标签**：数学、分治、组合数学、数论

**题意**：给定 $l, r, k$。考虑所有**恰好 $k$ 位**的整数，其中每一位数字都**独立**地从区间 $[l, r]$ 中选取（若区间含 0 则允许前导零，前导零按位权自然贡献 0）。求所有这些整数之和，对 $10^9+7$ 取模后返回。

**约束**：

- $0 \le l \le r \le 9$
- $1 \le k \le 10^9$

> ⚠️ 注意 $k$ 高达 $10^9$：任何以 $k$ 为指数的枚举、甚至 $O(k)$ 的循环都不可行，答案必须写成「快速幂 + 闭式公式」的形式。

## 2. 示例

**示例 1**

```text
输入：l = 1, r = 2, k = 2
输出：66
解释：所有数：11, 12, 21, 22，和 = 66。
```

**示例 2**

```text
输入：l = 0, r = 1, k = 3
输出：444
解释：按位枚举得 000, 001, 010, 011, 100, 101, 110, 111
      （去掉前导零后是 0,1,10,11,100,101,110,111），和 = 444。
```

**示例 3**

```text
输入：l = 5, r = 5, k = 10
输出：555555520
解释：只有 5555555555 这一个数，5555555555 mod (10^9+7) = 555555520。
```

## 3. 解题思路

### 3.1 暴力思路

可选数字个数是 $C = r - l + 1 \le 10$。全部枚举要生成 $C^k$ 个数，每个数按位累加又是 $O(k)$，总时间 $O(k\,C^k)$。当 $k = 10^9$ 时连「枚举个数」这个量级都无法表示，完全不可行——暴力只能用来对拍小数据（如 $k \le 4$）。

### 3.2 核心观察：按位拆解，利用十进制表示的线性性

![按位拆解：固定一位，其余 k−1 位任意](images/bw177_q4_position_sum.svg)

一个十进制数可以写成按位权展开：

$$N = \sum_{p=0}^{k-1} d_p \cdot 10^p$$

**求和与按位展开可以交换顺序**（这是「线性性」最朴素的应用）：

$$\text{ans} = \sum_{\text{所有数字}} \sum_{p=0}^{k-1} d_p \cdot 10^p = \sum_{p=0}^{k-1} 10^p \cdot \left(\sum_{\text{所有数字}} d_p\right)$$

于是只需算**第 $p$ 位上所有数字取值的总和** $S_p$。而第 $p$ 位与其它位是**相互独立**的：把第 $p$ 位固定成 $d$，其余 $k-1$ 位各有 $C$ 种取法，共 $C^{k-1}$ 个数字带上这个 $d$。所以

$$S_p = C^{k-1} \cdot \sum_{d=l}^{r} d = C^{k-1} \cdot \frac{(l+r)(r-l+1)}{2}$$

这个结果**与 $p$ 无关**！所有位上的取值分布完全相同。剩下的就只有几何级数：

![公式落地：repunit、快速幂与模逆元](images/bw177_q4_formula.svg)

$$\text{ans} = \Big(\sum_{d=l}^{r} d\Big) \cdot C^{k-1} \cdot \sum_{p=0}^{k-1} 10^p = \Big(\sum_{d=l}^{r} d\Big) \cdot C^{k-1} \cdot \frac{10^k - 1}{9}$$

其中 $\frac{10^k-1}{9} = \underbrace{11\cdots1}_{k\ \text{个}}$ 就是 repunit（全 1 数）。

### 3.3 算法流程

```text
1. MOD = 1e9 + 7, C = r - l + 1
2. sumD = (l + r) * C / 2            # l,r <= 9，直接整除，无精度问题
3. repunit = (10^k - 1) * inv(9) mod MOD       # inv(9) = 9^(MOD-2) mod MOD
4. ans = sumD mod MOD * C^(k-1) mod MOD * repunit mod MOD
5. 返回 ans
```

两处幂运算（$10^k$、$C^{k-1}$）都用快速幂，指数是 `long long`。

### 3.4 示例演算

以示例 1 的 $l=1, r=2, k=2$ 为例，$C = 2$，$\sum d = 3$：

| 位 $p$ | 权 $10^p$ | 该位出现次数 $C^{k-1}$ | 该位取值之和 $\sum d$ | 该位贡献 |
|--------|-----------|----------------------|---------------------|---------|
| 1（十位） | 10 | 2 | $1+2=3$ | $10 \times 3 \times 2 = 60$ |
| 0（个位） | 1 | 2 | $1+2=3$ | $1 \times 3 \times 2 = 6$ |

合计 $60 + 6 = 66$ ✓。也可以直接套公式：$3 \times 2^{1} \times 11 = 66$。

示例 2：$l=0,r=1,k=3$，$C=2$，$\sum d = 1$，repunit $= 111$，故 $1 \times 2^{2} \times 111 = 444$ ✓——这里前导零不需要任何特殊处理，因为 0 乘上权仍然是 0，与「按位权展开」的定义完全一致。

示例 3：$l=r=5$，$C=1$，$\sum d = 5$，$C^{k-1}=1$，repunit $= 1111111111$，故 $5 \times 1111111111 = 5555555555$，取模得 $555555520$ ✓。

## 4. 算法细节

1. **$\sum d$ 的算法**：$l + r$ 与 $C$ 都是小整数，用 `(l + r) * C / 2` 直接整除即可（两者之积必为偶数），不需要在模意义下求 2 的逆元。
2. **除以 9 的处理**：模 $10^9+7$ 下不能直接除，用费马小定理 $9^{-1} \equiv 9^{10^9+5} \pmod{10^9+7}$，一次快速幂即可。也可以预先把 `inv9` 算成常量 `111111112`（因为 $9 \times 111111112 = 1000000008 \equiv 1$），代码里更直观。
3. **指数类型**：$k$ 最大 $10^9$，`int` 够存但快速幂的循环变量建议用 `long long`，避免 `k - 1` 在边界上的类型问题。
4. **取模顺序**：三个因子各自取模后再相乘，中间结果用 `long long`（两个 $10^9$ 量级相乘约 $10^{18}$，正好在 `long long` 范围内，不会溢出）。
5. **k = 1 的天然兼容**：$C^{k-1} = C^0 = 1$，repunit $= (10-1)/9 = 1$，答案退化为 $\sum d$，正是所有一位数字之和，无需特判。
6. **负数取模**：`(modPow(10,k) - 1 + MOD) % MOD` 里的 `+MOD` 不能省，否则 `10^k mod MOD == 0` 的极端情况下会得到负数。

## 5. 正确性证明

**引理 1（按位展开与求和可交换）**：设所有候选数字构成的集合为 $\mathcal{N}$，则 $\sum_{N \in \mathcal{N}} N = \sum_{p=0}^{k-1} 10^p S_p$，其中 $S_p = \sum_{N \in \mathcal{N}} d_p(N)$，$d_p(N)$ 表示 $N$ 在第 $p$ 位的数字。

**证明**：每个 $N$ 的十进制表示唯一，故 $N = \sum_{p=0}^{k-1} d_p(N) 10^p$ 恒成立（允许前导零不破坏这个等式）。把该式对 $N \in \mathcal{N}$ 求和，有限和可以交换次序，即得结论。∎

**引理 2（单位取值总和）**：对任意 $p$，$S_p = C^{k-1} \sum_{d=l}^{r} d$，其中 $C = r-l+1$。

**证明**：把 $\mathcal{N}$ 按第 $p$ 位的取值分组：$\mathcal{N} = \bigcup_{d=l}^{r} \mathcal{N}_d$，其中 $\mathcal{N}_d$ 是第 $p$ 位等于 $d$ 的数字集合。各组互不相交。在第 $p$ 位固定为 $d$ 后，其余 $k-1$ 位每一位都可以独立地从 $[l,r]$ 中取 $C$ 个值之一，由乘法原理 $|\mathcal{N}_d| = C^{k-1}$。于是 $S_p = \sum_d d \cdot |\mathcal{N}_d| = C^{k-1}\sum_d d$。∎

**引理 3（repunit 闭式）**：对任意 $k \ge 1$，$\sum_{p=0}^{k-1} 10^p = \dfrac{10^k - 1}{9}$。

**证明**：等比数列求和，公比 $10 \ne 1$，$\sum_{p=0}^{k-1} 10^p = \frac{10^k - 1}{10 - 1}$。∎

**定理**：$\text{ans} = \big(\sum_{d=l}^{r} d\big) \cdot C^{k-1} \cdot \frac{10^k-1}{9}$，且按算法在模 $10^9+7$ 下用逆元计算的结果与原式同余。

**证明**：把引理 2 代入引理 1 得 $\sum_{N} N = \big(\sum_d d\big) C^{k-1} \sum_{p=0}^{k-1} 10^p$，再用引理 3 替换最后一项即得闭式。同余性：$10^9+7$ 是素数且 $9 \not\equiv 0$，故 $9$ 在模 $10^9+7$ 下可逆，乘以 $9^{-1}$ 等价于除以 9，从而 $(10^k-1)\cdot 9^{-1} \equiv (10^k-1)/9 \pmod{10^9+7}$；有限次乘加在模运算下保序，故算法输出与原式同余。∎

## 6. 复杂度分析

- **时间**：$O(\log k)$。两次快速幂（$10^k$、$C^{k-1}$）各 $O(\log k)$，外加一次 $O(\log (10^9+7))$ 的求逆元快速幂。
- **空间**：$O(1)$，只有若干整数变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int sumOfNumbers(int l, int r, int k) {
        const long long MOD = 1000000007LL;
        long long cnt = r - l + 1;
        long long digitSum = (long long)(l + r) * cnt / 2 % MOD;
        long long repunit = (modPow(10, k) - 1 + MOD) % MOD * modPow(9, MOD - 2) % MOD;
        long long ans = digitSum * modPow(cnt, k - 1) % MOD * repunit % MOD;
        return (int)ans;
    }

private:
    long long modPow(long long base, long long exp) {
        const long long MOD = 1000000007LL;
        long long res = 1;
        base %= MOD;
        while (exp > 0) {
            if (exp & 1) res = res * base % MOD;
            base = base * base % MOD;
            exp >>= 1;
        }
        return res;
    }
};
```

### Python

```python
class Solution:
    def sumOfNumbers(self, l: int, r: int, k: int) -> int:
        MOD = 10 ** 9 + 7
        cnt = r - l + 1
        digit_sum = (l + r) * cnt // 2
        repunit = (pow(10, k, MOD) - 1) * pow(9, MOD - 2, MOD) % MOD
        return digit_sum % MOD * pow(cnt, k - 1, MOD) % MOD * repunit % MOD
```

## 8. 边界情况与易错点

1. **$k = 1$**：$C^{0}=1$、repunit $=1$，公式自动退化为 $\sum d$，不要额外写 `if (k == 1)` 分支（容易和取模写错）。
2. **$l = r = 0$**：只有全 0 一个数，答案应为 0。此时 $\sum d = 0$，公式给出 0 ✓；若把 $\sum d$ 写成 `(l + r) * C / 2` 再取模，也不会出问题。
3. **前导零**：允许前导零时「位数」是固定的 $k$，不要按「实际有效位数」去分类讨论；按位权展开天然把前导零算成 0 贡献。
4. **除以 9 不能用整数除法**：$10^k$ 在取模后已经失去真值，必须先取逆元再乘。反之 $\sum d$ 那一步的 `/2` 是**真值整除**，必须在取模之前做。
5. **取模负值**：$(10^k \bmod p) - 1$ 可能为 $-1$（当 $10^k \equiv 0$ 时不会发生，但保险起见仍加 `+MOD`）。
6. **乘法溢出**：三次连乘时每一步都要 `% MOD`，中间量用 64 位；Python 无此问题。
7. **指数不要用 `pow` 的浮点版**：C++ 里 `pow(10, 1e9)` 直接溢出成 `inf`，必须手写快速幂。
