# LeetCode 至少有 1 位重复的数字 题解

## 1. 题目概述

- **标题 / 题号**：至少有 1 位重复的数字（#1012，hard）
- **链接**：https://leetcode.cn/problems/numbers-with-repeated-digits/
- **来源**：LeetCode 第 128 场周赛 Q4
- **难度**：困难
- **标签**：数学、动态规划、数位统计

**题意**：给定正整数 $n$，返回 $[1, n]$ 范围内**至少有一位数字重复**（即十进制表示中存在两个相同数字）的正整数个数。

**约束**：

- $1 \le n \le 10^9$

> 💡 直接统计「有重复」很别扭，因为它不是「前缀性质」；但它的补集「**各位数字互不相同**」非常适合按位计数。这正是本题的突破口。

## 2. 示例

**示例 1**

```text
输入：n = 20
输出：1
解释：[1,20] 中只有 11 有重复数字。
```

**示例 2**

```text
输入：n = 100
输出：10
解释：11,22,33,44,55,66,77,88,99,100 共 10 个。
```

**示例 3**

```text
输入：n = 1000
输出：262
解释：1..1000 共 1000 个数，其中各位互不相同的有 738 个，故 1000 − 738 = 262。
```

**示例 4**

```text
输入：n = 9
输出：0
解释：一位数不可能有重复数字。
```

## 3. 解题思路

### 3.1 暴力思路

逐个枚举 $1 \sim n$，对每个数检查是否有一位重复（用 `bool seen[10]` 或字符串判重）。复杂度 $O(n \log n)$，$n = 10^9$ 时约 $10^{10}$ 次操作，绝无可能通过。

暴力的唯一价值是**校验**：写一个 $O(n)$ 的暴力，对 $n \le 10^4$ 的随机值对拍，可以很快验证组合计数是否正确。

### 3.2 核心观察：数「各位互不相同」的补集

![至少一位重复 = 总数 − 各位互不相同的数](images/wc128_q4_prefix_count.svg)

设 `cnt(n)` 表示 $[1, n]$ 中**各位数字互不相同**的数的个数，则答案

$$\text{answer} = n - \text{cnt}(n)$$

因为 $[1,n]$ 一共 $n$ 个数，每个数要么有重复、要么没有，二者互斥且穷尽。

`cnt(n)` 的难点在于「不能超过 $n$」，标准做法是把 $n$ 的十进制表示固定下来，按**位数**和**首次小于 $n$ 的位置**分类：

1. **位数比 $n$ 少**（$1 \le \ell < L$，$L$ 为 $n$ 的位数）：这些数一定小于 $n$，无需关心上界。
2. **位数等于 $L$**：逐位贴着 $n$ 的前缀走，在第一个「小于 $n$ 对应位」的位置上分叉，之后随便填（只要不重复）。

### 3.3 算法流程

![算法流程：短位数枚举 + 同位数前缀计数](images/wc128_q4_flow.svg)

```text
1. 取 n 的各位数字 d[0..L-1]
2. cnt = 0
3. for len = 1 .. L-1:
       cnt += 9 * P(9, len-1)          # 首位 9 选，其余从剩余 9 个里排列
4. used = 空集合
5. for i = 0 .. L-1:
       for x = (i == 0 ? 1 : 0) .. d[i]-1:
           若 x 不在 used:  cnt += P(9-i, L-1-i)
       若 d[i] 已在 used:  跳出（前缀已重复，后面不可能再合法）
       used 加入 d[i]
6. 若循环正常走完：cnt += 1          # n 自己也是合法数
7. 返回 n - cnt
```

其中 $P(a,b) = a(a-1)\cdots(a-b+1)$ 是**下降阶乘**（从 $a$ 个里选 $b$ 个排列），$b<0$ 或 $b>a$ 时为 0。

公式 $P(9-i, L-1-i)$ 的含义：前 $i$ 位已经和 $n$ 相同、第 $i$ 位取了一个更小的 $x$，此时一共用掉 $i+1$ 个不同数字，**还剩 $9-i$ 个可用数字**，要填满**剩下 $L-1-i$ 个位置**，方案数就是从 $9-i$ 个里取 $L-1-i$ 个排列。

### 3.4 示例演算

![示例演算：n = 245 的分段计数](images/wc128_q4_walkthrough.svg)

**先看示例 3 的 $n = 1000$**（$L = 4$）：

| 长度 | 计数公式 | 个数 | 累计 |
|---|---|---|---|
| 1 | $9 \times P(9,0) = 9$ | 9 | 9 |
| 2 | $9 \times P(9,1) = 9\times9$ | 81 | 90 |
| 3 | $9 \times P(9,2) = 9\times72$ | 648 | 738 |

同长度（4 位）部分：$n$ 的各位是 $1,0,0,0$。首位候选 $x < 1$ 为空；第 1 位候选 $x < 0$ 为空；第 2 位候选 $x < 0$ 为空——此时数字 0 已在 `used` 中，前缀出现重复，跳出。$n$ 本身也不合法（有两个 0）。故 $\text{cnt}(1000) = 738$，答案 $1000 - 738 = 262$ ✓。

**再看 $n = 245$**（$L = 3$，能展示同长度的分叉计数）：

| 步 | 位置 | $d[i]$ | 候选 $x$ | 可用 $x$ | 方案数 | `cnt` |
|---|---|---|---|---|---|---|
| 短位数 | — | — | — | — | $9 + 81$ | 90 |
| 1 | $i=0$ | 2 | 1 | 1 | $P(9,2) = 72$ | 162 |
| 2 | $i=1$ | 4 | 0,1,2,3 | 0,1,3（2 已用） | $3 \times P(8,1) = 24$ | 186 |
| 3 | $i=2$ | 5 | 0..4 | 0,1,3（2,4 已用） | $3 \times P(7,0) = 3$ | 189 |
| 收尾 | — | — | — | — | $n$ 自身合法，$+1$ | 190 |

答案 $245 - 190 = 55$。逐项理解：

- $i=0$ 取 $x=1$ 时，剩下两位从 9 个数字里排列：$9\times8 = 72$；
- $i=1$ 取 $x \in \{0,1,3\}$ 时，前两位用了 $\{2, x\}$，还剩 8 个数字填最后 1 位：每个 $x$ 贡献 8 种；
- $i=2$ 取 $x \in \{0,1,3\}$ 时已无剩余位置，每个 $x$ 贡献 1 种；
- 最后 $n = 245$ 自身三位互不相同，被计入。

## 4. 算法细节

1. **下降阶乘的实现**：`P(a,b)` 用循环乘 $b$ 次，$a \le 9$、$b \le 9$，最大 $9! = 362880$，不会溢出 `int`；但整体结果接近 $10^9$，用 `long long` 更稳。
2. **首位不能为 0**：同长度部分 $i=0$ 时 `x` 从 1 开始；短位数部分首位固定 9 种（$1\sim9$），后续位才可能取 0。
3. **「已用数字」集合**：只需 10 个布尔位，按 `d[i]` 依次标记；一旦发现 `d[i]` 已用过，说明 $n$ 的这个前缀本身就重复，后续所有同前缀的数都不合法，直接跳出。
4. **$n$ 自身是否计入**：只有前缀走完都没重复，$n$ 才是一个合法数，需要 $+1$。
5. **位数上限**：$n \le 10^9$，$L \le 10$；$P(9-i, L-1-i)$ 的参数始终满足 $L-1-i \le 9-i$（因为 $L \le 10$），不需要额外的越界保护。
6. **另一条路线（数位 DP）**：状态 `(位置, 已用数字的位掩码, 是否贴紧上界, 是否已开始)`，记忆化后同样是 $O(L \cdot 2^{10})$。组合计数法的常数更小、代码更短，但数位 DP 模板更容易迁移到「含前导零/任意进制」的变体。
7. **不重不漏的关键**：每个合法的 $L$ 位数，在「首次小于 $n$ 的位置」处被唯一计入——比它位数少的走第 3 步，位数相同的走第 5 步，$n$ 自己在收尾处。

## 5. 正确性证明

记 $S$ 为 $[1, n]$ 中各位数字互不相同的数的集合，$\text{cnt}(n) = |S|$。

**引理 1（补集关系）**：答案 $= n - \text{cnt}(n)$。

**证明**：$[1,n]$ 共有 $n$ 个正整数，按「各位是否互不相同」分成两类，互斥且穷尽；至少一位重复的个数 $= n - |S|$。∎

**引理 2（短位数计数）**：位数 $\ell < L$ 的各位互不相同的正整数恰有 $9 \cdot P(9, \ell-1)$ 个。

**证明**：首位可选 $1\sim9$ 共 9 种；其后第 $2, 3, \dots, \ell$ 位必须与前面所有位不同且互不相同，第 $k$ 位（$k \ge 2$）有 $10 - (k-1)$ 种选择。总方案数

$$9 \cdot 9 \cdot 8 \cdots (11-\ell) = 9 \cdot P(9, \ell-1)$$

其中 $P(9,\ell-1) = 9\cdot8\cdots(11-\ell)$。这些数位数更少，必然 $< n$，无需上界约束。∎

**引理 3（同位数分叉计数）**：固定长度 $L$，设某合法数 $m \le n$ 与 $n$ 的公共前缀长度为 $i$（即 $m[0..i-1] = d[0..i-1]$、$m[i] < d[i]$），则该 $m$ 被算法在第 $i$ 位唯一计数，方案数为 $P(9-i, L-1-i)$（当 $m[i]$ 未被前缀使用时）。

**证明**：设 $x = m[i]$ 且 $x$ 不在前缀 $\{d[0],\dots,d[i-1]\}$ 中。此时已确定 $i+1$ 个互不相同的数字，剩余可用数字数为 $10 - (i+1) = 9-i$；剩余 $L-1-i$ 位必须从中选互不相同的排列，方案数 $P(9-i, L-1-i)$。由于 $x < d[i]$ 且前缀相同，任何这样的 $m$ 都满足 $m < n$；反之任何满足「前缀相同、首次分叉小于 $d[i]$」的 $m \le n$ 都对应唯一的分叉位置 $i$ 与唯一取值 $x$。∎

**引理 4（唯一性）**：任意 $m \in S$，要么位数 $< L$，要么位数 $= L$ 且被算法的某一步恰计入一次；$n$ 本身若不重复则恰好被收尾的 $+1$ 计入。

**证明**：位数 $< L$ 由引理 2 计数；位数 $= L$ 时，若 $m < n$，取第一个使 $m$ 与 $n$ 不同的位置 $i$，必有 $m[i] < d[i]$，由引理 3 唯一计入；若 $m = n$，则所有位置都相同，算法走完前缀且无重复后 $+1$。三类互斥，故不重不漏。∎

**定理**：算法输出的 `cnt` 等于 $|S|$，返回值为至少一位重复的数的个数。

**证明**：由引理 2 与引理 3、4，算法把 $S$ 中的数按「短位数 / 同位数首次分叉位置 / $n$ 自身」三类不重不漏地计数，故 `cnt` $= |S|$。再由引理 1，`n - cnt` 即所求。∎

## 6. 复杂度分析

- **时间**：$O(L \cdot 10)$，其中 $L \le 10$ 是 $n$ 的位数。短位数枚举 $O(L)$ 次，每次 $P$ 计算 $O(L)$；同长度部分对每个位置枚举至多 10 个候选数字，每个候选计算一次 $P$（$O(L)$）。总操作数不超过 $10 \times 10 \times 10 = 1000$，是 $O(1)$ 级别的常数。
- **空间**：$O(L + 10)$，即数字数组与「已用」标记。若用数位 DP 则为 $O(L \cdot 2^{10})$ 的状态表。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int numDupDigitsAtMostN(int n) {
        vector<int> d;
        for (int x = n; x > 0; x /= 10) d.push_back(x % 10);
        reverse(d.begin(), d.end());
        int L = (int)d.size();

        long long cnt = 0;
        for (int len = 1; len < L; len++) cnt += 9LL * perm(9, len - 1);

        vector<bool> used(10, false);
        bool ok = true;
        for (int i = 0; i < L && ok; i++) {
            for (int x = (i == 0 ? 1 : 0); x < d[i]; x++) {
                if (!used[x]) cnt += perm(9 - i, L - 1 - i);
            }
            if (used[d[i]]) {
                ok = false;
            } else {
                used[d[i]] = true;
            }
        }
        if (ok) cnt += 1;

        return (int)((long long)n - cnt);
    }

private:
    long long perm(int a, int b) {
        if (b < 0 || b > a) return 0;
        long long r = 1;
        for (int i = 0; i < b; i++) r *= (a - i);
        return r;
    }
};
```

### Python

```python
class Solution:
    def numDupDigitsAtMostN(self, n: int) -> int:
        def perm(a: int, b: int) -> int:
            if b < 0 or b > a:
                return 0
            r = 1
            for i in range(b):
                r *= a - i
            return r

        d = [int(c) for c in str(n)]
        L = len(d)

        cnt = 0
        for length in range(1, L):
            cnt += 9 * perm(9, length - 1)

        used = set()
        ok = True
        for i, cur in enumerate(d):
            for x in range(1 if i == 0 else 0, cur):
                if x not in used:
                    cnt += perm(9 - i, L - 1 - i)
            if cur in used:
                ok = False
                break
            used.add(cur)
        if ok:
            cnt += 1

        return n - cnt
```

## 8. 边界情况与易错点

1. **$n$ 是一位数**：$L = 1$，短位数循环不执行，同长度部分只处理 $x < d[0]$ 的候选（每个贡献 $P(9,0)=1$），最后 $+1$，得 $\text{cnt}=n$，答案 0 ✓。
2. **首位候选从 0 开始**：会让「位数相同」的数出现前导零（实际变成更短位数），造成重复计数。
3. **忘记「前缀已重复就跳出」**：如 $n = 100$，若不跳出会继续统计出非法分支；正确做法是立即停止，因为所有以该前缀开头的数都含重复。
4. **忘记收尾 $+1$**：$n$ 自身若各位不重复，必须计入 `cnt`，否则答案偏大 1（示例 1 的 $n=20$ 就会错成 2）。
5. **`perm` 的 $b > a$ 情形**：$L$ 较大、$i$ 较小时理论上会出现，虽然本题 $L\le10$ 不会触发，仍应返回 0 以免越界。
6. **用 `int` 累加**：$\text{cnt} \le 10^9$，接近 `INT_MAX` 但不会溢出；不过在「答案 $= n - \text{cnt}$」中若中间量用无符号会下溢，统一用 `long long`。
7. **$n = 10^9$**：$L = 10$，首位之后全是 0，前缀在第 2 位就重复，`cnt` 只来自短位数部分（$9 + 81 + 648 + 4536 + \dots$），答案约 $9.94\times10^8$，仍在 `int` 范围内。
8. **把「至少一位重复」误当成「恰好一位重复」**：如 111 有三位重复，也只算一个数。
