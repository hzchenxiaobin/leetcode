# LeetCode 十进制整数的反码 题解

## 1. 题目概述

- **标题 / 题号**：十进制整数的反码（#1009，easy）
- **链接**：https://leetcode.cn/problems/complement-of-base-10-integer/
- **来源**：LeetCode 第 128 场周赛 Q1
- **难度**：简单
- **标签**：位运算、数学

**题意**：每个非负整数 $N$ 都有二进制表示（除 $N = 0$ 外不含前导零）。把它**每一位**取反（`1` 变 `0`、`0` 变 `1`）得到反码，返回该反码对应的十进制数。

**约束**：

- $0 \le N < 10^9$（即 $N < 2^{30}$）

> 💡 最容易错的是 $N = 0$：它的二进制表示是 `"0"`，取反得 `"1"`，答案是 **1** 而不是 0。

## 2. 示例

**示例 1**

```text
输入：N = 5
输出：2
解释：5 的二进制是 "101"，反码 "010"，即十进制 2。
```

**示例 2**

```text
输入：N = 7
输出：0
解释：7 的二进制是 "111"，反码 "000"，即 0。
```

**示例 3**

```text
输入：N = 10
输出：5
解释：10 的二进制是 "1010"，反码 "0101"，即 5。
```

**示例 4**

```text
输入：N = 0
输出：1
解释：0 的二进制是 "0"，反码 "1"，即 1。
```

## 3. 解题思路

### 3.1 暴力思路

把 $N$ 转成二进制字符串，逐位取反（`'1'` 换 `'0'`、`'0'` 换 `'1'`），再按二进制转回整数。复杂度 $O(\log N)$，完全可行，而且不容易错。

缺点是「字符串 ↔ 整数」来回转换的常数大、代码啰嗦，且容易在 `N = 0` 时得到空串。位运算做法只需三行，更值得掌握。

### 3.2 核心观察：取反 = 与「同长度的全 1 掩码」异或

![取反等价于与同位数全 1 掩码做异或](images/wc128_q1_mask_concept.svg)

设 $N$ 的二进制长度为 $b$（$N = 0$ 时约定 $b = 1$）。定义掩码

$$M = \underbrace{11\cdots1}_{b \text{ 个}} = 2^b - 1$$

则对 $N$ 的每一位：

$$N \oplus M \text{ 的第 } i \text{ 位} = \begin{cases} 1 - N_i, & i < b \\ 0, & \text{不存在}\end{cases}$$

也就是说，**异或全 1 掩码恰好就是逐位取反**，而且结果不会带上任何多余的高位（掩码的高位全是 0，异或后仍为 0）。于是

$$\text{answer} = N \oplus (2^b - 1)$$

其中 $b$ 是 $N$ 的二进制位数。掩码可以用一个循环边右移边拼出来：

```text
mask = 0
x = N
while x > 0:  mask = (mask << 1) | 1;  x >>= 1
```

`mask` 每轮左移补一个 1，循环次数正是 $N$ 的位数。

### 3.3 算法流程

![算法流程：求位数与掩码，再异或](images/wc128_q1_flow.svg)

```text
1. 若 N == 0：返回 1
2. mask = 0，x = N
3. while x > 0:
       mask = (mask << 1) | 1
       x >>= 1
4. 返回 N ^ mask
```

也可以直接求位数：`b = 32 - __builtin_clz(N)`（GCC/Clang 内建函数），但循环写法跨语言、跨编译器都成立。

### 3.4 示例演算

对示例 1、3、4 逐一走查：

| $N$ | 二进制 | 位数 $b$ | 掩码 $M$ | $N \oplus M$ | 结果 |
|---|---|---|---|---|---|
| 5 | `101` | 3 | `111` = 7 | `010` | 2 |
| 7 | `111` | 3 | `111` = 7 | `000` | 0 |
| 10 | `1010` | 4 | `1111` = 15 | `0101` | 5 |
| 0 | `0` | 1 | `1` = 1 | `1` | 1 |

可以看到 $N = 7 = 2^3 - 1$ 时反码为 0（全 1 取反全 0）；$N = 2^b - 1$ 必然是这类「反码为 0」的数。

## 4. 算法细节

1. **`N = 0` 特判**：循环 `while (x > 0)` 一次都不执行，`mask` 保持 0，异或结果还是 0——这与正确答案 1 不符，必须单独返回 1。
2. **掩码生成顺序**：`mask = (mask << 1) | 1` 每次在高位侧补 1，循环 $b$ 次后得到 $b$ 个 1；若写成 `mask = mask | (1 << i)` 也行，但要自己维护 $i$。
3. **不修改原值**：用临时变量 `x` 右移，保留 `N` 供最后的异或使用。
4. **位数上界**：$N < 10^9 < 2^{30}$，掩码最大 $2^{30}-1$，`int`（32 位）安全；若 $N$ 接近 $2^{31}$ 就要用 `unsigned int` 或 `long long`。
5. **`1 << b` 的风险**：当 $b = 31$ 时 `1 << 31` 在有符号 `int` 上是 UB；本题 $b \le 30$ 安全，但用「移位拼 1」的写法天然规避这个问题。
6. **一行写法**：`N ^ ((1 << (32 - __builtin_clz(N))) - 1)`，仅在 $N > 0$ 时成立。

## 5. 正确性证明

**引理 1（掩码的位数）**：设 $N > 0$ 的二进制长度为 $b$，则上述循环恰好执行 $b$ 次，结束时 $\text{mask} = 2^b - 1$。

**证明**：每轮 `x >>= 1` 把位数减 1，初始位数为 $b$，故执行 $b$ 次后 $x = 0$ 退出。归纳可证第 $t$ 轮结束时 $\text{mask} = 2^t - 1$（初始 $t=0$ 时 mask$=0$；每轮左移一位再或 1 即 $2(2^t-1)+1 = 2^{t+1}-1$），故结束时 mask $= 2^b - 1$，即 $b$ 个 1。∎

**引理 2（异或即取反）**：对任意 $0 \le N \le 2^b - 1$，$N \oplus (2^b - 1) = 2^b - 1 - N$，且其二进制恰好是 $N$ 的 $b$ 位逐位取反。

**证明**：$2^b - 1$ 的二进制是 $b$ 个 1，逐位异或 1 等于该位取反；由于 $N < 2^b$，其第 $b$ 位及以上均为 0，异或后仍为 0，故结果恰为 $b$ 位取反后的值，且等于 $2^b - 1 - N$（按位取反在 $b$ 位无符号数中就是「用全 1 减去它」）。∎

**引理 3（$N = 0$ 的特殊性）**：$N = 0$ 的反码是 1。

**证明**：$0$ 的二进制表示为 `"0"`（长度 1，题目明确规定这是唯一允许的写法），取反得 `"1"`，即 1。∎

**定理**：算法返回 $N$ 的二进制反码对应的十进制数。

**证明**：$N = 0$ 时算法按引理 3 返回 1。$N > 0$ 时由引理 1 掩码是 $b$ 个 1，由引理 2 异或结果就是 $b$ 位逐位取反的值。题目规定二进制表示不含前导零，故 $b$ 位取反（含前导 0 的位）正是题目定义的反码，转成十进制即为返回值。∎

## 6. 复杂度分析

- **时间**：$O(\log N)$。循环次数等于二进制位数，$N < 10^9$ 时至多 30 次；异或 $O(1)$。
- **空间**：$O(1)$。只用 `mask`、`x` 两个整型变量。
- 对比：字符串做法同样是 $O(\log N)$，但常数约为位运算的 10 倍以上。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int bitwiseComplement(int n) {
        if (n == 0) return 1;
        int mask = 0;
        for (int x = n; x > 0; x >>= 1) mask = (mask << 1) | 1;
        return n ^ mask;
    }
};
```

### Python

```python
class Solution:
    def bitwiseComplement(self, n: int) -> int:
        if n == 0:
            return 1
        mask = 0
        x = n
        while x > 0:
            mask = (mask << 1) | 1
            x >>= 1
        return n ^ mask
```

## 8. 边界情况与易错点

1. **`N = 0` 返回 1**：最常见的 WA 点。循环版与位运算版都必须特判，否则得到 0。
2. **`N = 1` 返回 0**：`"1"` 取反是 `"0"`，答案是 0 而不是 1——注意与上一条区分。
3. **`N = 2^k - 1` 返回 0**：全 1 取反全 0，如 $N = 7 \to 0$、$N = 1023 \to 0$。
4. **掩码多一位**：若把 `mask` 算成 $b+1$ 位，结果会多出最高位的 1，数值整体变成 $2^{b+1}-1-N$。
5. **掩码少一位**：若从 $N$ 的高位开始漏掉最高位，结果会丢掉最高位的取反。
6. **有符号移位**：`mask << 1` 在 `mask` 接近 $2^{30}$ 时仍安全（本题位数 $\le 30$）；若 $b = 31$，`1 << 31` 是 UB。
7. **用 `~N` 直接取反**：得到的是 32 位补码取反（负数），必须先与掩码 `&` 才能得到正确答案。
8. **字符串做法的空串**：`N = 0` 转二进制字符串为 `"0"`，若代码里用 `x > 0` 的循环生成字符串会得到空串，取反后转整数报错。
