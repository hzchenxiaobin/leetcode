# LeetCode 统计子串中的唯一字符 题解

## 1. 题目概述

- **标题 / 题号**：统计子串中的唯一字符（#828，hard）
- **链接**：https://leetcode.cn/problems/count-unique-characters-of-all-substrings-of-a-given-string/
- **来源**：LeetCode 第 83 场周赛 Q4
- **难度**：困难
- **标签**：哈希表、字符串、动态规划

**题意**：定义 $\mathrm{countUniqueChars}(t)$ 为字符串 $t$ 中**只出现一次**的字符个数（同一个字符出现多次只算 0 次）。给定只含大写字母的 $s$，求

$$\sum_{t \subseteq s} \mathrm{countUniqueChars}(t)$$

即对 $s$ 的**所有子串**（按下标区间计，重复内容的不同子串分别计数）求和。题目保证答案在 32 位整数范围内。

**约束**：

- $1 \le |s| \le 10^5$
- $s$ 仅含大写英文字母

**关键信息**：子串数量是 $O(n^2)$，逐个统计内部字符又是 $O(n)$，暴力是 $O(n^3)$；即使做到 $O(n^2)$ 也无法通过 $n = 10^5$。必须把求和对象从「子串」换成「字符」。

## 2. 示例

**示例 1**

```text
输入：s = "ABC"
输出：10
解释：6 个子串 "A","B","C","AB","BC","ABC" 全由唯一字符组成，
      长度和为 1+1+1+2+2+3 = 10。
```

**示例 2**

```text
输入：s = "ABA"
输出：8
解释：除 "ABA"（A 出现两次）贡献 1 外，其余子串贡献和示例 1 相同：
      1+1+1+2+2+1 = 8。
```

**示例 3**

```text
输入：s = "LEETCODE"
输出：92
解释：见 §3.4 的逐位演算。
```

## 3. 解题思路

### 3.1 暴力思路

枚举左右端点 $[l, r]$，用数组统计窗口内各字符出现次数，统计出现 1 次的字符数并累加。固定 $l$、让 $r$ 右移，可以做到每次 $O(1)$ 更新、总额外空间 $O(26)$，于是 $O(n^2)$ 时间。

$n = 10^5$ 时 $O(n^2) = 10^{10}$，必然超时。**瓶颈在于「枚举所有子串」本身**，所以必须换个求和顺序。

### 3.2 核心观察：按「字符-位置」数出它被算了几次

![按字符算贡献：每个下标管一段子串](images/wc83_q4_contribution_concept.svg)

把总和改写为

$$\sum_{t}\mathrm{countUniqueChars}(t) = \sum_{t}\sum_{i \in t} \left[\text{字符 } s[i] \text{ 在 } t \text{ 中只出现一次}\right] = \sum_{i}\#\{\,t : i \in t,\ s[i] \text{ 在 } t \text{ 中恰好出现一次}\,\}$$

也就是：**每个下标 $i$ 独立计算「有多少个子串，其中 $s[i]$ 恰好出现一次」**，再全部相加。这样复杂度从「子串数」降为「下标数」。

对固定的 $i$，记：

- $\mathrm{prev}[i]$：$i$ 左边最近的、与 $s[i]$ 相同的位置，不存在则 $-1$；
- $\mathrm{nxt}[i]$：$i$ 右边最近的、与 $s[i]$ 相同的位置，不存在则 $n$。

要让子串 $[l, r]$ 包含 $i$ 且 $s[i]$ 只出现一次，必须

- $l \in (\mathrm{prev}[i],\ i]$，共 $i - \mathrm{prev}[i]$ 种；
- $r \in [i,\ \mathrm{nxt}[i])$，共 $\mathrm{nxt}[i] - i$ 种。

两者独立，故 $i$ 的贡献为

$$\bigl(i - \mathrm{prev}[i]\bigr) \times \bigl(\mathrm{nxt}[i] - i\bigr)$$

答案就是所有 $i$ 的贡献之和。

### 3.3 算法流程

![两遍扫描求出 prev 与 nxt](images/wc83_q4_two_scans.svg)

```text
1. 正序扫描：last[26] 初始化为 −1
       prev[i] = last[s[i]]
       last[s[i]] = i
2. 逆序扫描：last[26] 初始化为 n
       nxt[i] = last[s[i]]
       last[s[i]] = i
3. ans = Σ (i − prev[i]) × (nxt[i] − i)
4. 返回 ans
```

两遍线性扫描各 $O(n)$，最后求和一遍 $O(n)$。

### 3.4 示例演算

![示例演算：LEETCODE 的逐位贡献](images/wc83_q4_walkthrough.svg)

对 $s = \text{"LEETCODE"}$（$n = 8$）：

| $i$ | $s[i]$ | $\mathrm{prev}[i]$ | $\mathrm{nxt}[i]$ | 贡献 |
|-----|--------|--------------------|-------------------|------|
| 0 | L | −1 | 8 | $1 \times 8 = 8$ |
| 1 | E | −1 | 2 | $2 \times 1 = 2$ |
| 2 | E | 1 | 7 | $1 \times 5 = 5$ |
| 3 | T | −1 | 8 | $4 \times 5 = 20$ |
| 4 | C | −1 | 8 | $5 \times 4 = 20$ |
| 5 | O | −1 | 8 | $6 \times 3 = 18$ |
| 6 | D | −1 | 8 | $7 \times 2 = 14$ |
| 7 | E | 2 | 8 | $5 \times 1 = 5$ |

总和 $8+2+5+20+20+18+14+5 = 92$，与示例 3 一致。

再看 $s = \text{"ABA"}$：$i=0$ 贡献 $1 \times 2 = 2$，$i=1$ 贡献 $(1+1) \times (3-1) = 4$，$i=2$ 贡献 $(2-0) \times (3-2) = 2$，合计 8 ✓。

## 4. 算法细节

1. **字母表定长**：$s$ 只含大写字母，用长度 26 的数组代替哈希表，读写都是 $O(1)$ 且常数极小。
2. **哨兵值**：`prev` 不存在时为 $-1$，`nxt` 不存在时为 $n$。这样 $(i - \mathrm{prev})$ 与 $(\mathrm{nxt} - i)$ 的公式无需任何特判，统一成立。
3. **两次扫描方向相反**：正序得到「最近左同字符」，逆序得到「最近右同字符」，用同一个 `last[26]` 数组即可，无需邻接表。
4. **贡献相乘而非相加**：左右端点的选择是**独立**的（$l$ 只受左边界限制、$r$ 只受右边界限制），所以是乘法原理。
5. **中间结果用 64 位**：$(i-\mathrm{prev})(\mathrm{nxt}-i)$ 单项最大可达约 $2.5\times10^9$，虽然题目保证**总和**在 32 位内，但单项仍可能越过 `int` 上界；C++ 用 `long long` 累加后再转回 `int` 最稳妥。
6. **不需要动态规划数组**：本题标签含 DP，但按贡献求和后只剩两个辅助数组，本质上是一次「换维求和」。

## 5. 正确性证明

**引理 1（固定 $i$ 的子串计数）**：设 $p = \mathrm{prev}[i]$、$q = \mathrm{nxt}[i]$。子串 $[l, r]$ 满足「包含 $i$ 且 $s[i]$ 在其中恰好出现一次」当且仅当 $l \in (p, i]$ 且 $r \in [i, q)$。

**证明**：
（必要性）若 $l \le p$，则 $p \in [l, r]$（因为 $p < i \le r$）且 $s[p] = s[i]$，出现两次，矛盾；若 $l > i$ 则子串不含 $i$，矛盾。故 $p < l \le i$。同理，若 $r \ge q$ 则 $q \in [l, r]$ 与 $s[q] = s[i]$ 冲突；若 $r < i$ 则不含 $i$。故 $i \le r < q$。
（充分性）当 $p < l \le i \le r < q$ 时，$[l, r]$ 中任何与 $s[i]$ 相同的位置 $j$ 必在 $(p, q)$ 内；由 $p, q$ 的定义，区间 $(p, q)$ 内除 $i$ 之外不存在与 $s[i]$ 相同的字符，故只有 $i$ 一个，恰好出现一次。∎

**引理 2（每个「子串-唯一字符」对恰被计一次）**：对任意子串 $t$ 与其中出现一次的字符位置 $i$，$i$ 的贡献恰好把 $t$ 计入一次；且 $t$ 中每个只出现一次的字符对应一个不同的 $i$。

**证明**：由引理 1，$i$ 的贡献枚举的正是「包含 $i$ 且 $s[i]$ 唯一」的全部子串，而 $t$ 满足该条件，故被 $i$ 计入；由于 $i$ 是 $t$ 中的一个具体下标，不同的唯一字符对应不同下标，不会重复计数。∎

**定理**：$\sum_i (i - \mathrm{prev}[i])(\mathrm{nxt}[i] - i) = \sum_{t \subseteq s}\mathrm{countUniqueChars}(t)$。

**证明**：由引理 1，第 $i$ 项等于满足条件的子串个数，也就等于「所有子串中 $s[i]$ 作为唯一字符出现的次数」。将这些次数按字符位置汇总，恰是把每个子串的 $\mathrm{countUniqueChars}$ 拆成若干 1 相加；由引理 2，这种拆分不重不漏。故等式成立。∎

## 6. 复杂度分析

- **时间**：$O(n)$。正向扫描 $O(n)$、反向扫描 $O(n)$、求和 $O(n)$，每步都是常数时间操作；$n = 10^5$ 时总运算量在百万级。
- **空间**：$O(n)$。`prev`、`nxt` 两个长度 $n$ 的数组，加上两个常数大小的 26 元数组；若把 `prev` 与求和合并，可降到 $O(1)$ 额外空间（只需 `nxt` 与 `last`）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int uniqueLetterString(string s) {
        int n = s.size();
        vector<int> prev(n, -1), nxt(n, n), last(26, -1);
        for (int i = 0; i < n; i++) {
            prev[i] = last[s[i] - 'A'];
            last[s[i] - 'A'] = i;
        }
        vector<int> lastR(26, n);
        for (int i = n - 1; i >= 0; i--) {
            nxt[i] = lastR[s[i] - 'A'];
            lastR[s[i] - 'A'] = i;
        }
        long long ans = 0;
        for (int i = 0; i < n; i++) ans += (long long)(i - prev[i]) * (nxt[i] - i);
        return (int)ans;
    }
};
```

### Python

```python
class Solution:
    def uniqueLetterString(self, s: str) -> int:
        n = len(s)
        prev = [-1] * n
        nxt = [n] * n
        last = [-1] * 26
        for i, ch in enumerate(s):
            prev[i] = last[ord(ch) - 65]
            last[ord(ch) - 65] = i
        last = [n] * 26
        for i in range(n - 1, -1, -1):
            nxt[i] = last[ord(s[i]) - 65]
            last[ord(s[i]) - 65] = i
        return sum((i - prev[i]) * (nxt[i] - i) for i in range(n))
```

## 8. 边界情况与易错点

1. **单字符**：$s = \text{"A"}$，`prev = -1`、`nxt = 1`，贡献 $1 \times 1 = 1$，答案 1。
2. **所有字符相同**：$s = \text{"AAAAA"}$，对每个 $i$ 都有 `prev = i-1`、`nxt = i+1`，贡献恒为 $1$，答案 $n$——因为只有长度为 1 的子串才含唯一字符，共 $n$ 个。
3. **一次扫描复用数组**：反向扫描前必须把 `last` 重新初始化为 $n$，否则会沿用正序扫描的残余值，得到的 `nxt` 全错。
4. **哨兵用 $n$ 而不是 $n-1$**：`nxt = n` 表示「右边没有同字符」，若误用 $n-1$ 会少算以最后一个下标结尾的子串。
5. **`s[i] - 'A'` 的下标范围**：$0 \sim 25$；用 `'a'` 或 `'A'` 都能算，但必须与数组大小 26 匹配；字符集若扩展到小写字母需要 52 或改用映射。
6. **乘法顺序与溢出**：先转 `long long` 再乘，写成 `(long long)(i - prev[i]) * (nxt[i] - i)`；若两个 `int` 直接相乘再赋给 `long long`，中间结果已溢出。
7. **返回值类型**：题目保证答案在 32 位内，但累加过程建议用 64 位，最后 `(int)` 转换。
8. **不要逐个字符对子串做 `count`**：这是 $O(n^3)$ 的写法，小数据能过、大数据必超时。
