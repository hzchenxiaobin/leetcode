# LeetCode 连续整数求和 题解

## 1. 题目概述

- **标题 / 题号**：连续整数求和（#829，hard）
- **链接**：https://leetcode.cn/problems/consecutive-numbers-sum/
- **来源**：LeetCode 第 83 场周赛 Q3
- **难度**：困难
- **标签**：数学、枚举

**题意**：给定正整数 $n$，统计有多少种方式把 $n$ 写成**至少一个连续正整数**之和。例如 $5 = 5 = 2+3$，共 2 种；$9 = 9 = 4+5 = 2+3+4$，共 3 种。

**约束**：

- $1 \le n \le 10^9$

**关键信息**：$n$ 可达 $10^9$，任何 $O(n)$ 的枚举（枚举起点或逐个累加）都会超时，必须把「拆法」压缩成**关于段长 $k$ 的一个整除判定**，而段长只有 $O(\sqrt n)$ 种可能。

## 2. 示例

**示例 1**

```text
输入：n = 5
输出：2
解释：5 = 5，或 5 = 2 + 3。
```

**示例 2**

```text
输入：n = 9
输出：3
解释：9 = 9 = 4 + 5 = 2 + 3 + 4。
```

**示例 3**

```text
输入：n = 15
输出：4
解释：15 = 15 = 7 + 8 = 4 + 5 + 6 = 1 + 2 + 3 + 4 + 5。
```

## 3. 解题思路

### 3.1 暴力思路

枚举起点 $a$ 与终点 $b$，判断 $\sum_{i=a}^{b} i = n$。用前缀和或等差数列公式可以做到 $O(n)$ 枚举起点；也可以枚举段长与起点做到 $O(n\sqrt n)$。但 $n = 10^9$ 时即使 $O(\sqrt n)$ 个起点也做不到——注意这里是 $O(n)$ 个起点，直接不可行。

关键问题是：**能不能不枚举起点？** 只要固定了「段长 $k$」，起点就被完全确定了。

### 3.2 核心观察：固定段长，起点由整除条件唯一确定

![把长度 k 的连续段写成公式](images/wc83_q3_length_formula.svg)

设这一段从正整数 $a$ 开始、长度为 $k$，则

$$n = a + (a+1) + \cdots + (a+k-1) = k\,a + \frac{k(k-1)}{2}$$

移项即可解出

$$a = \frac{n - \frac{k(k-1)}{2}}{k}$$

于是「存在以 $a \ge 1$ 开头、长度为 $k$ 的合法拆法」等价于两个条件：

1. **整除**：$k \mid \left(n - \frac{k(k-1)}{2}\right)$，保证 $a$ 是整数；
2. **正起点**：$a \ge 1$，等价于 $n \ge \frac{k(k+1)}{2}$。

而段长 $k$ 必须先满足 $1 + 2 + \cdots + k \le n$，即 $\frac{k(k+1)}{2} \le n$，故 $k = O(\sqrt n)$。$n \le 10^9$ 时 $k$ 最多只到 $\left\lfloor\sqrt{2n}\right\rfloor \approx 44721$，枚举量完全可控。

![答案等于 n 的奇数因子个数（另一种等价刻画）](images/wc83_q3_odd_divisor.svg)

> 💡 **另一个视角**：这题还有一个著名结论——拆法数恰好等于 $n$ 的**奇数因子个数**（因为 $n = 2^t \cdot m$ 中的 $2^t$ 不产生任何新拆法）。它是很好的验算工具，但下面的算法与证明都只依赖「枚举 $k$ + 整除判定」，不依赖这条结论。

### 3.3 算法流程

```text
1. ans = 0
2. for k = 1, 2, 3, ... 直到 k(k+1)/2 > n:
       if (n - k(k-1)/2) % k == 0:   ans += 1
3. 返回 ans
```

循环用 `k*(k+1)/2 <= n` 作为继续条件，同时天然保证了 $a \ge 1$（见下文引理 2），因此循环体内**只需判整除**。

### 3.4 示例演算

![示例演算：n = 15 枚举段长 k](images/wc83_q3_walkthrough.svg)

以 $n = 15$ 为例：

| $k$ | $k(k+1)/2$ | $n - k(k-1)/2$ | 对 $k$ 取模 | $a$ | 拆法 |
|-----|-----------|----------------|-------------|-----|------|
| 1 | 1 | 15 | 0 ✓ | 15 | [15] |
| 2 | 3 | 14 | 0 ✓ | 7 | [7,8] |
| 3 | 6 | 12 | 0 ✓ | 4 | [4,5,6] |
| 4 | 10 | 9 | 1 ✗ | — | — |
| 5 | 15 | 5 | 0 ✓ | 1 | [1..5] |
| 6 | 21 > 15 | — | — | — | 枚举结束 |

合法的 $k$ 为 $1,2,3,5$，共 4 种，与示例输出一致。

## 4. 算法细节

1. **变量类型**：$k$ 要开 `long long`，因为 $k(k+1)/2$ 在 $k$ 接近 $10^5$ 时已达 $5\times10^9$，超出 32 位整数范围（虽然本题 $k \le 44722$ 时 $k(k+1)/2 \le 10^9$ 仍在 int 内，但用 64 位更保险，且避免 `k*(k+1)` 中间溢出）。
2. **循环条件**：`k * (k + 1) / 2 <= n`。它同时是「段长可行」与「$a \ge 1$」的充要条件，因此不必在循环体内再判 $a \ge 1$。
3. **整除判定**：`(n - k * (k - 1) / 2) % k == 0`。注意 $k(k-1)/2$ 与 $k(k+1)/2$ 差一个 $k$，二者不要写混：前者是偏移量，后者是上界。
4. **不需要真的构造出 $a$**：题目只问方案数，判定整除后直接计数即可；若要输出方案，$a$ 就是被除数除以 $k$。
5. **枚举顺序**：$k$ 从小到大，每个 $k$ 至多贡献 1 种方案，因为 $a$ 被 $k$ 唯一确定，不存在重复计数。

## 5. 正确性证明

**引理 1（段长与起点一一对应）**：对任意正整数 $k$，至多存在一个正整数 $a$ 使 $\sum_{i=0}^{k-1}(a+i) = n$；且这样的 $a$ 存在当且仅当 $k \mid \left(n - \frac{k(k-1)}{2}\right)$ 且 $a = \frac{n - k(k-1)/2}{k} \ge 1$。

**证明**：由等差数列求和，$n = k a + \frac{k(k-1)}{2}$，这是关于 $a$ 的一次方程，系数 $k > 0$，故解唯一：$a = \frac{n - k(k-1)/2}{k}$。$a$ 为整数当且仅当分子被 $k$ 整除；又要求 $a$ 为正整数，即 $a \ge 1$。∎

**引理 2（循环条件等价于 $a \ge 1$）**：设 $k$ 满足整除条件，则 $\frac{k(k+1)}{2} \le n \iff a \ge 1$。

**证明**：由 $n = k a + \frac{k(k-1)}{2}$，

$$\frac{k(k+1)}{2} \le n \iff \frac{k(k+1)}{2} \le k a + \frac{k(k-1)}{2} \iff k \le k a \iff 1 \le a$$

最后一步用 $k > 0$ 两边同除 $k$。∎

**引理 3（不同段长给出不同拆法）**：若 $k_1 \ne k_2$ 都满足条件，则由它们确定的连续段不同。

**证明**：两个连续段的长度分别为 $k_1 \ne k_2$，而一个连续段的长度是其元素个数，长度不同则段必然不同（集合元素个数不同）。∎

**定理**：算法返回值等于把 $n$ 表示为连续正整数之和的方案数。

**证明**：设 $S$ 为全部合法拆法的集合，$K$ 为算法枚举并判定通过的所有 $k$。由引理 1，每个合法拆法由其段长 $k$ 唯一决定起点，故存在映射 $f: S \to K$；反之每个 $k \in K$ 由引理 1 唯一确定一个合法拆法，得到映射 $g: K \to S$。显然 $f \circ g = \mathrm{id}_K$、$g \circ f = \mathrm{id}_S$，故 $|S| = |K|$，即算法计数恰为方案数。引理 3 说明不存在两个不同 $k$ 对应同一拆法，计数不会重复。∎

## 6. 复杂度分析

- **时间**：$O(\sqrt n)$。循环条件 $\frac{k(k+1)}{2} \le n$ 给出 $k = O(\sqrt n)$，每次迭代做常数次 64 位算术。$n = 10^9$ 时约 $4.5 \times 10^4$ 次迭代。
- **空间**：$O(1)$。只用了循环变量与计数器。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int consecutiveNumbersSum(int n) {
        int ans = 0;
        for (long long k = 1; k * (k + 1) / 2 <= n; k++) {
            if ((n - k * (k - 1) / 2) % k == 0) ans++;
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def consecutiveNumbersSum(self, n: int) -> int:
        ans = 0
        k = 1
        while k * (k + 1) // 2 <= n:
            if (n - k * (k - 1) // 2) % k == 0:
                ans += 1
            k += 1
        return ans
```

## 8. 边界情况与易错点

1. **$n = 1$**：只有 $[1]$ 一种，循环 $k=1$ 时 $1 \le 1$、$1 - 0$ 被 1 整除，答案 1。
2. **$n = 2$**：$k=1$ 通过（$a=2$），$k=2$ 时 $k(k+1)/2 = 3 > 2$ 退出，答案 1；不要误以为 $2 = ?$ 还有别的拆法。
3. **溢出**：`k * (k + 1)` 在 32 位下会溢出，务必用 `long long` 或先做除法；Python 无此问题，但 `//` 与 `%` 的等价性依赖非负被除数——本题 $n - k(k-1)/2 \ge 0$，安全。
4. **两个前缀和的混淆**：偏移量是 $\frac{k(k-1)}{2}$（从 0 加到 $k-1$），上界是 $\frac{k(k+1)}{2}$（从 1 加到 $k$）。写反会出现「$a = 0$ 也被算进去」或「漏掉 $a=1$ 的拆法」。
5. **循环边界取等**：$k(k+1)/2 = n$ 时 $a = 1$ 仍然合法（如 $n = 15, k = 5$），必须是 `<=` 而不是 `<`。
6. **不要用 $k \le \sqrt{n}$ 收紧上界**：上界是 $\sqrt{2n}$，写成 $\sqrt n$ 会漏掉 $k$ 在 $(\sqrt n, \sqrt{2n}]$ 的拆法（例如 $n = 3$ 时 $k = 2$ 就落在其中）。
7. **答案范围**：答案是 $n$ 的奇数因子个数，不超过 $n$ 的因子个数（$10^9$ 以内的数量级只有千位），用 `int` 足够。

**延伸思考**：**答案等于 $n$ 的奇数因子个数**。理由是把 $2n = k\left(2a + k - 1\right)$ 里的两个因子按奇偶分类：二者必一奇一偶，把奇数那个记作 $d$，则 $d \mid n$，且 $k$ 为奇数时 $d = k$、$k$ 为偶数时 $d = 2n/k$。由此每个合法 $k$ 对应一个不同的奇数因子，反之每个奇数因子也唯一确定一个 $k$，于是方案数 $= d(m)$，其中 $n = 2^t \cdot m$、$m$ 为奇数。若题目要求输出所有方案，枚举 $k$ 的写法可以直接把 $a$ 与区间一并输出；若 $n$ 扩大到 $10^{18}$，则改为枚举到 $\sqrt{2n} \approx 1.4\times10^9$ 已不可行，此时必须走「质因数分解 + 统计奇数因子个数」的路线。
