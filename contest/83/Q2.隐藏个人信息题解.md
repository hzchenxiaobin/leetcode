# LeetCode 隐藏个人信息 题解

## 1. 题目概述

- **标题 / 题号**：隐藏个人信息（#831，medium）
- **链接**：https://leetcode.cn/problems/masking-personal-information/
- **来源**：LeetCode 第 83 场周赛 Q2
- **难度**：中等
- **标签**：字符串

**题意**：给定一条个人信息字符串 $s$，它要么是**邮箱地址**，要么是**电话号码**，要求按规则脱敏：

- **邮箱**：形如 `name@domain`，其中 `name` 只含字母，`domain` 只含字母与恰好一个位于中间的 `.`。输出时把 `name` 与 `domain` **全部转小写**，且 `name` 只保留**首字母 + 5 个 `*` + 尾字母**。
- **电话**：由 10～13 位数字和分隔符 `+ - ( ) 空格` 组成。去掉全部分隔符后，**后 10 位**是本地号码，前面剩下的 0～3 位是**国家代码**。输出固定为 `***-***-XXXX` 的形式，本地号码只保留**最后 4 位** `XXXX`；国家代码有几位就在前面加 `+` 与同样个数的 `*`。

**约束**：

- $s$ 一定是**合法**的邮箱或电话号码
- 邮箱：$8 \le |s| \le 40$，仅含字母、恰好一个 `@` 与若干 `.`
- 电话：$10 \le |s| \le 20$，仅含数字、空格、`(`、`)`、`-`、`+`

**关键信息**：两类输入**互斥**且格式已被保证合法，因此不需要写正则去校验，只要判断「有没有 `@`」，再各写一条极短的规则即可。

## 2. 示例

**示例 1**

```text
输入：s = "LeetCode@LeetCode.com"
输出："l*****e@leetcode.com"
解释：名字与域名都转小写，名字中间换成 5 个 *。
```

**示例 2**

```text
输入：s = "AB@qq.com"
输出："a*****b@qq.com"
解释：名字只有 2 个字母，中间仍然必须是 5 个 *。
```

**示例 3**

```text
输入：s = "1(234)567-890"
输出："***-***-7890"
解释：共 10 位数字，国家代码 0 位，本地号码取后 4 位 7890。
```

**示例 4（补充，含国家代码）**

```text
输入：s = "+1 (234) 567-8901"
输出："+*-***-***-8901"
解释：共 11 位数字 → 国家代码 1 位 → 前缀 "+*"。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的想法是「识别类型 → 逐字符构造输出」。真正容易踩坑的不是复杂度（输入长度只有几十），而是**规则的细节**：

- 邮箱的 `name` 可能只有 2 个字母，但中间永远是**固定 5 个** `*`，与名字长度无关；
- 电话号码分隔符的**位置、个数都不固定**，`+` 也可能出现也可能不出现，只能靠「数字总数」反推国家代码位数；
- 输出里 `+` 与 `*` 的个数由国家代码**位数**决定，而不是由原串里 `+` 的位置决定。

所以与其逐个字符模拟分隔符，不如先把**语义信息**（名字、域名、数字串）抽出来，再按模板拼装——这类「先抽取再格式化」的写法就是本题的正解。

### 3.2 核心观察：一条分支判断 + 两条模板

![先判断类型，再套各自的遮蔽规则](images/wc83_q2_two_branches.svg)

整个问题被 `'@'` 一分为二：

- **含 `@`**：用 `@` 把串切成 `name` 与 `domain`，两者转小写，`name` 输出为 `name[0] + "*****" + name[-1]`。
- **不含 `@`**：把所有数字字符抽出来得到 `digits`，令 $c = |digits| - 10 \in [0,3]$ 为国家代码位数，本地号码的后 4 位即输出中的 `XXXX`；当 $c = 0$ 时前缀为空，否则前缀为 `"+" + c 个 '*'`。

![邮箱遮蔽：名字留首尾，域名只转小写](images/wc83_q2_email_rule.svg)

### 3.3 算法流程

```text
1. 若 s 中含 '@':
       (name, domain) = s.split('@')
       name = lower(name), domain = lower(domain)
       返回 name[0] + "*****" + name[-1] + "@" + domain
2. 否则:
       digits = s 中所有数字字符（保持原顺序）
       last4 = digits[-4:]
       c = len(digits) - 10
       若 c == 0: 返回 "***-***-" + last4
       否则:      返回 "+" + "*" * c + "-***-***-" + last4
```

### 3.4 示例演算

![电话遮蔽：国家代码位数决定前缀](images/wc83_q2_phone_table.svg)

| 数字总数 | 国家代码位数 | 输出模板 |
|----------|--------------|----------|
| 10 | 0 | `***-***-XXXX` |
| 11 | 1 | `+*-***-***-XXXX` |
| 12 | 2 | `+**-***-***-XXXX` |
| 13 | 3 | `+***-***-***-XXXX` |

对示例 3 的 `"1(234)567-890"`：抽出数字得 `1234567890`（10 位），$c = 0$，取后 4 位 `7890`，输出 `***-***-7890` ✓。

## 4. 算法细节

1. **类型判定**：`s.find('@')`（C++）或 `'@' in s`（Python）即可。题目保证不会出现「电话号码里含 `@`」的输入。
2. **切分与转小写**：C++ 用 `substr(0, at)` / `substr(at + 1)`；Python 用 `partition('@')`，它天然返回三元组，`@` 只出现一次时语义清晰。
3. **数字抽取**：C++ 用 `isdigit`，Python 用 `c.isdigit()`（或 `c in '0123456789'`）。不要用 `atoi` 之类整体解析，因为分隔符位置任意。
4. **国家代码位数**：$c = |digits| - 10$。题目保证 $|digits| \in [10, 13]$，所以 $c \in [0,3]$ 天然成立，无需再判非法。
5. **模板拼接**：本地号码固定为 `***-***-` 加 4 位；`c > 0` 时再在最前面补 `+` 与 $c$ 个 `*`，注意中间还有一个 `-`。
6. **大小写**：`tolower` 对非字母是安全的（但本分支里名字与域名都只含字母），不必先判断字符类型。

## 5. 正确性证明

**引理 1（分支互斥且完备）**：合法输入要么含 `@`（邮箱），要么不含 `@`（电话），两种情况下算法分别走邮箱、电话规则，且不会互相污染。

**证明**：题目规定邮箱必须含恰好一个 `@`，电话号码的字符集不含 `@`。因此 `'@' in s` 的取值恰好区分两类输入，分支完备且互斥。∎

**引理 2（邮箱输出符合规则）**：设 `name` 长度为 $m \ge 1$，则输出 `name[0] + "*****" + name[m-1]` 恰好是「首字母 + 5 个 `*` + 尾字母」，且与 $m$ 无关；`domain` 已整体转小写。

**证明**：`name[0]` 是首字母，`name[-1]` 是尾字母，中间拼接的是长度恒为 5 的字面量 `"*****"`，正是规则要求的替换；两个部件都经过 `tolower`，满足「大写字母转小写」。∎

**引理 3（电话输出符合规则）**：设抽出的数字串为 $d$，$c = |d| - 10 \ge 0$。算法输出的前缀为 `"+" + c 个 '*'`（$c = 0$ 时为空），中间为 `***-***-`，末尾为 $d$ 的后 4 位。

**证明**：去掉分隔符后数字串长度即 $|d|$，前 $|d| - 10$ 位为国家代码、后 10 位为本地号码，故国家代码位数为 $c$；输出格式规定国家代码占 1 个 `+` 与 $c$ 个 `*`，本地号码只保留后 4 位，两处都与算法构造一致。∎

**定理**：算法对任意合法输入都返回题目要求的脱敏结果。

**证明**：由引理 1，输入必然落入两个分支之一；邮箱分支由引理 2 正确、电话分支由引理 3 正确。故输出满足全部脱敏规则。∎

## 6. 复杂度分析

- **时间**：$O(|s|)$。一次类型判定、一次切分/转小写（邮箱分支两次线性遍历）、一次数字抽取（电话分支），均为线性；拼接输出也是 $O(|s|)$。
- **空间**：$O(|s|)$。需要保存 `name`、`domain` 或 `digits`，以及长度 $O(|s|)$ 的输出字符串。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    string maskPII(string s) {
        size_t at = s.find('@');
        if (at != string::npos) {
            string name = s.substr(0, at);
            string domain = s.substr(at + 1);
            for (char& c : name) c = tolower(c);
            for (char& c : domain) c = tolower(c);
            return name.substr(0, 1) + "*****" + name.substr(name.size() - 1) + "@" + domain;
        }
        string digits;
        for (char c : s)
            if (isdigit(c)) digits.push_back(c);
        string local = digits.substr(digits.size() - 4);
        int cc = (int)digits.size() - 10;
        if (cc == 0) return "***-***-" + local;
        return "+" + string(cc, '*') + "-***-***-" + local;
    }
};
```

### Python

```python
class Solution:
    def maskPII(self, s: str) -> str:
        if '@' in s:
            name, _, domain = s.partition('@')
            name = name.lower()
            return name[0] + '*****' + name[-1] + '@' + domain.lower()
        digits = [c for c in s if c.isdigit()]
        last4 = ''.join(digits[-4:])
        cc = len(digits) - 10
        if cc == 0:
            return '***-***-' + last4
        return '+' + '*' * cc + '-***-***-' + last4
```

## 8. 边界情况与易错点

1. **名字只有 2 个字母**：示例 2 的 `"AB"`，输出中间仍是 5 个 `*`（`a*****b`），不能按「长度减 2」计算星号数。极端的单字母名字（首尾是同一个字母）会输出形如 `a*****a`，这也是「固定 5 星」规则的直接结果。
2. **域名全大写**：`"A@LEETCODE.COM"` 必须输出 `a*****a@leetcode.com`，域名也要转小写，只转名字是常见 WA。
3. **10 位数字没有国家代码**：此时输出**不带** `+`，前缀直接是 `***-***-`；多写一个 `+` 会错。
4. **分隔符位置任意**：`"+1(234)567-890"` 与 `"+1 234 567 890"` 必须等价；千万不要按固定下标切分。
5. **`+` 的位置不可信**：原串里出现 `+` 不代表国家代码为 1 位，一律以「数字总数减 10」为准。
6. **13 位数字**：前缀是 `+` 加 3 个 `*`，即 `+***-***-***-XXXX`，中间有三段 `***`，注意分隔的位数。
7. **数字字符串的末尾**：`digits[-4:]`（C++ 用 `substr(size()-4)`）在 $|digits| \ge 10$ 时永远安全；若先判长度再取值反而容易写错。
8. **`isdigit` 的返回值**：C++ 中 `isdigit` 返回非零值不保证等于 1，只做 `if` 判断，不要与 `true` 比较。
