# LeetCode 较大分组的位置 题解

## 1. 题目概述

- **标题 / 题号**：较大分组的位置（#830，easy）
- **链接**：https://leetcode.cn/problems/positions-of-large-groups/
- **来源**：LeetCode 第 83 场周赛 Q1
- **难度**：简单
- **标签**：字符串

**题意**：给定只含小写字母的字符串 $s$。相邻的**相同字符**连成一段，称为一个**分组**，用闭区间 $[start, end]$ 表示。若某个分组的长度 $\ge 3$，称它为**较大分组**。要求按**起始下标递增**的顺序返回所有较大分组的区间。

**约束**：

- $1 \le |s| \le 1000$
- $s$ 仅含小写英文字母

**关键信息**：分组是对整个字符串的**一种划分**——每个下标恰好属于一个分组，分组之间不重叠、且沿下标顺序排列。这条性质是后面「一遍扫描」的全部依据。

## 2. 示例

**示例 1**

```text
输入：s = "abbxxxxzzy"
输出：[[3,6]]
解释："xxxx" 是起始于 3、终止于 6 的较大分组。
```

**示例 2**

```text
输入：s = "abc"
输出：[]
解释："a"、"b"、"c" 长度都是 1，没有较大分组。
```

**示例 3**

```text
输入：s = "abcdddeeeeaabbbcd"
输出：[[3,5],[6,9],[12,14]]
解释：较大分组为 "ddd"、"eeee" 和 "bbb"。
```

**示例 4**

```text
输入：s = "aba"
输出：[]
解释：两段 "a" 被 "b" 隔开，各自长度都是 1。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有起点 $i$，再向右数出与 $s[i]$ 相同的字符个数，若 $\ge 3$ 就记录区间：

```text
for i = 0 .. n-1:
    j = i
    while j < n and s[j] == s[i]: j++
    if j - i >= 3: 记录 [i, j-1]
```

正确性没问题，但每个字符会被它的每个「左侧起点」重复访问一次，最坏（全串同一字符）是 $O(n^2)$。$n \le 1000$ 虽然也能过，但完全没有必要——分组划分本身只允许每个下标被数一次。

### 3.2 核心观察：跳跃式扫描，每个分组只看一次

![扫描连续相同字符切出分组，只有长度 ≥ 3 才输出](images/wc83_q1_scan_concept.svg)

既然分组互不重叠，那么**数完一个分组后，直接跳到它的末尾继续**，就不会有任何重复访问：

- $i$ 指向当前分组的起点；
- $j$ 从 $i$ 出发一路右移，直到 $s[j] \ne s[i]$ 或越界；
- 此时 $[i, j-1]$ 正是**完整**的一个分组，长度 $j - i$；
- 判定长度后令 $i \leftarrow j$，开始下一个分组。

由于 $j$ 单调不减、且每次都停在分组边界上，整个循环的 $i$ 与 $j$ 都只前进不后退，总移动次数为 $O(n)$。

### 3.3 算法流程

![双指针扫描的算法流程](images/wc83_q1_algorithm_flow.svg)

```text
1. res = []
2. i = 0
3. while i < n:
       j = i
       while j < n 且 s[j] == s[i]:  j += 1
       若 j - i >= 3:  res.append([i, j-1])
       i = j
4. 返回 res
```

### 3.4 示例演算

![示例演算：八个分组里只有 ddd、eeee、bbb 达标](images/wc83_q1_walkthrough.svg)

以示例 3 的 `s = "abcdddeeeeaabbbcd"` 为例，逐段走查：

| 分组 | 起点 | 终点 | 长度 | 是否输出 |
|------|------|------|------|----------|
| a | 0 | 0 | 1 | ✗ |
| b | 1 | 1 | 1 | ✗ |
| c | 2 | 2 | 1 | ✗ |
| ddd | 3 | 5 | 3 | ✓ [3,5] |
| eeee | 6 | 9 | 4 | ✓ [6,9] |
| aa | 10 | 11 | 2 | ✗ |
| bbb | 12 | 14 | 3 | ✓ [12,14] |
| c | 15 | 15 | 1 | ✗ |

输出 `[[3,5],[6,9],[12,14]]`，顺序天然按下标递增。

## 4. 算法细节

1. **双指针含义**：$i$ 是分组起点，$j$ 是「第一个不属于当前分组的下标」，因此分组区间是**左闭右闭**的 $[i, j-1]$，长度为 $j-i$。
2. **跳跃而不是逐字符判断**：`i = j` 保证每个下标只被作为「分组内元素」访问一次；若写成 `i++`，最坏退化到 $O(n^2)$。
3. **长度为 3 也算较大分组**：判定条件是 `>= 3`，不是 `> 3`。
4. **输出顺序**：按下标从左到右扫描，天然满足「起始位置递增」的要求，**不需要额外排序**。
5. **空间**：除返回值外只需两个整型指针，额外空间 $O(1)$。

## 5. 正确性证明

**引理 1（切出的块是完整分组）**：循环中当 $i$ 为某个分组的起点时，内层循环结束后 $[i, j-1]$ 恰好等于该分组。

**证明**：设 $i$ 是分组起点，即 $s[i-1] \ne s[i]$（或 $i=0$）。内层循环在 $s[j] == s[i]$ 时持续推进 $j$，因此 $j$ 从 $i$ 一直停在第一个满足 $s[j] \ne s[i]$（或 $j=n$）的位置。由分组定义，从 $i$ 开始的所有连续相同字符构成该分组，故 $[i, j-1]$ 正是分组的全部元素。∎

**引理 2（划分不重不漏）**：每次迭代后新的 $i \leftarrow j$ 恰好是下一个分组的起点，且各次得到的分组互不重叠、并集为整个字符串。

**证明**：$j$ 停在 $s[j] \ne s[i]$ 处，由于 $s[j-1] == s[i]$，所以 $j$ 是另一个分组的起点（或 $j = n$ 表示字符串结束）。因此下一次迭代的 $i$ 是下一个分组起点，归纳可知所有分组被依次枚举、且区间两两不交；循环在 $i = n$ 时终止，故并集覆盖全部下标。∎

**定理**：算法返回的正是全部较大分组，且按起点递增排序。

**证明**：由引理 1、2，算法对每个分组恰好判定一次，判定条件 $j-i \ge 3$ 与「较大分组」的定义一致，故输出集合恰为全部较大分组；又因为枚举顺序即起点递增顺序，输出天然有序。∎

## 6. 复杂度分析

- **时间**：$O(n)$。$i$ 与 $j$ 均单调不减，合计最多前进 $2n$ 次；每次内层循环的字符比较是常数时间。
- **空间**：$O(1)$ 额外空间（不计返回值）。返回值的空间为 $O(g)$，$g$ 为较大分组个数。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<vector<int>> largeGroupPositions(string s) {
        int n = s.size();
        vector<vector<int>> res;
        for (int i = 0; i < n; ) {
            int j = i;
            while (j < n && s[j] == s[i]) j++;
            if (j - i >= 3) res.push_back({i, j - 1});
            i = j;
        }
        return res;
    }
};
```

### Python

```python
class Solution:
    def largeGroupPositions(self, s: str) -> list[list[int]]:
        res = []
        n = len(s)
        i = 0
        while i < n:
            j = i
            while j < n and s[j] == s[i]:
                j += 1
            if j - i >= 3:
                res.append([i, j - 1])
            i = j
        return res
```

## 8. 边界情况与易错点

1. **长度恰好为 3**：`"aaa"` 是较大分组，判定必须是 `>= 3`；写成 `> 3` 会漏掉示例 3 的 `ddd` 与 `bbb`。
2. **字符串很短**：`|s| < 3` 时不可能有较大分组，循环照常跑完返回空列表，无需特判。
3. **整串相同**：`"aaaaaa"` 只有一个分组 $[0,5]$，返回 `[[0,5]]` 而不是多个长度 3 的块——分组是**极大**连续段。
4. **分组被不同字符隔开**：`"aba"` 的两段 `a` 长度各为 1，不能合并计数。
5. **终点是 `j-1` 而非 `j`**：$j$ 指向分组后的第一个字符（或 $n$），直接写 `j` 会多算一位。
6. **别漏掉末尾分组**：内层循环以 `j == n` 结束时，最后一个分组的区间仍然是 $[i, n-1]$，不要提前跳出。
