# LeetCode 检查一个字符串是否可以打破另一个字符串 题解

## 1. 题目概述

- **标题 / 题号**：检查一个字符串是否可以打破另一个字符串（#1433，medium）
- **链接**：https://leetcode.cn/problems/check-if-a-string-can-break-another-string/
- **来源**：LeetCode 第 25 场双周赛 Q3
- **难度**：中等
- **标签**：贪心、字符串、排序

**题意**：给定长度相等的字符串 $s_1$、$s_2$（均为小写字母）。字符串 $x$ 能**打破**字符串 $y$（长度同为 $n$），指存在 $x$ 的一个排列与 $y$ 的一个排列，使得逐位比较 $x_i \ge y_i$ 对所有 $i \in [0, n)$ 成立。要求判断：$s_1$ 能打破 $s_2$，或 $s_2$ 能打破 $s_1$，是否至少有一个成立。

**约束**：

- $1 \le n = |s_1| = |s_2| \le 10^5$
- 只含小写英文字母

## 2. 示例

**示例 1**

```text
输入：s1 = "abc", s2 = "xya"
输出：true
解释：s2 排列成 "ayx"，与 s1 的排列 "abc" 逐位比较：a≥a, y≥b, x≥c，s2 打破 s1。
```

**示例 2**

```text
输入：s1 = "abe", s2 = "acd"
输出：false
解释：s1 的任何排列都无法逐位压住 s2 的任何排列，反之亦然。
```

**示例 3**

```text
输入：s1 = "leetcodee", s2 = "interview"
输出：true
解释：排序后 s1 = "cdee eeilo"（ceeeee... 具体为 c,d,e,e,e,e,i,l,o,o），s2 = "eeeiinrtv"，
逐位比较 s2 打破 s1。
```

## 3. 解题思路

### 3.1 暴力思路

枚举 $s_1$ 的全部 $n!$ 个排列与 $s_2$ 的全部排列，两两逐位比较——$O((n!)^2 \cdot n)$，$n \ge 9$ 即天文数字，不可行。换一个角度：$x$ 能打破 $y$，等价于「把 $x$ 的字符分配给 $y$ 的字符，每个 $x$ 字符支配一个不同的 $y$ 字符且值不小于它」——这是一个**二分图完美匹配**存在性问题，可以用 Hall 定理或匈牙利算法判定，$O(n^{1.5})$ 级别可过，但仍嫌重。

### 3.2 核心观察：各自排序后逐位对齐即可

![核心观察：排序后逐位对齐比较](images/bw25_q3_sort_pairing_concept.svg)

$x$ 能打破 $y$ 的充要条件是：把 $x$、$y$ **分别升序排序**后，逐位 $x_{(i)} \ge y_{(i)}$ 全部成立。

直觉：让 $x$ 最大的字符去压 $y$ 最大的字符、次大压次大……这是"田忌赛马"的上等马对上等马策略。若上等马压不住对方上等马，则 $x$ 中没有字符能压住它（$y$ 的最大值需要 $x$ 的最大值来对付）；若能压住，则这种对齐方式**不损失任何后续机会**（交换论证见 §5）。两个方向各检查一次，任一成立即答案为 `true`。

### 3.3 算法流程

![算法流程：排序后一趟扫描同时判定两个方向](images/bw25_q3_algorithm_flow.svg)

```text
1. a ← sorted(s1)，b ← sorted(s2)
2. s1Breaks ← true，s2Breaks ← true
3. 对 i = 0..n-1：
       若 a[i] < b[i]：s1Breaks ← false    # s1 压不住 s2
       若 a[i] > b[i]：s2Breaks ← false    # s2 压不住 s1
4. 返回 s1Breaks or s2Breaks
```

两个方向可以**合并在同一趟循环**里判定：$a_i \ge b_i$ 的失败信息与 $b_i \ge a_i$ 的失败信息互补于同一比较结果。

### 3.4 示例演算

![示例演算：abc/xya 成立与 abe/acd 失败](images/bw25_q3_example_walkthrough.svg)

**示例 1**：$a = $ `abc`，$b = $ `axy`。逐位：`a=a`、`b<x`、`c<y`。$a_i \ge b_i$ 不全成立（$s_1$ 打不破 $s_2$）；但 $b_i \ge a_i$ 全成立（`a≥a, x≥b, y≥c`），故 $s_2$ 打破 $s_1$，返回 `true`。

**示例 2**：$a = $ `abe`，$b = $ `acd`。逐位：`a=a`、`b<c`、`e>d`。两个方向各有一位失败，返回 `false`。

## 4. 算法细节

1. **排序即可，无需计数排序**：$n \le 10^5$，`std::sort` / `sorted()` 的 $O(n \log n)$ 足够；若追求线性可用 26 桶计数后扫描。
2. **双向判定合并在一趟循环**：$a_i$ 与 $b_i$ 的一次比较同时为两个方向提供信息，写两次独立循环容易抄错下标。
3. **相等位不破坏任何方向**：$a_i = b_i$ 时两个方向都保持可能；任何方向只需**一位**严格小于即被否决（`all` 语义）。
4. **提前终止（可选）**：两个标志都变 `false` 后可 `break`，最坏仍 $O(n)$。
5. **用字符直接比较**：小写字母的字典序即 ASCII 序，无需转数字。

## 5. 正确性证明

设 $\mathrm{sorted}(x)$ 表示 $x$ 升序排序后的串，$x_{(0)} \le x_{(1)} \le \cdots \le x_{(n-1)}$。

**引理 1（匹配刻画）**：$x$ 能打破 $y$ 当且仅当存在单射 $\sigma$（$y$ 的位置到 $x$ 的位置），使 $x_{\sigma(j)} \ge y_j$ 对所有 $j$ 成立。

**证明**：$x$ 能打破 $y$ 即存在排列 $x', y'$ 使 $x'_i \ge y'_i$ 逐位成立。$x'$ 是 $x$ 的排列，故 $x'_i = x_{\tau(i)}$，$\tau$ 为双射；$y'_i = y_{\pi(i)}$。令 $\sigma = \tau \circ \pi^{-1}$，则对每个 $j$（令 $i = \pi^{-1}(j)$）：$x_{\sigma(j)} = x_{\tau(i)} = x'_i \ge y'_i = y_{\pi(i)} = y_j$，且 $\sigma$ 作为双射的复合是单射。反之，给定单射 $\sigma$，因 $|x| = |y| = n$，$\sigma$ 必为双射；令 $x'_i = x_{\sigma(\pi(i))}$、$y'_i = y_{\pi(i)}$ 任意取排列 $\pi$，则 $x'_i \ge y'_i$，即 $x$ 打破 $y$。∎

**引理 2（排序对齐是最优策略）**：存在满足引理 1 的单射 $\sigma$，当且仅当排序后逐位 $x_{(i)} \ge y_{(i)}$ 对所有 $i$ 成立。

**证明**：（⇐）若逐位成立，取 $\sigma(i) = i$（对排序后的两个串），即为合法单射。（⇒）设存在合法单射 $\sigma$。反证：若存在某个位置 $k$ 使 $x_{(k)} < y_{(k)}$，取最小的这样的 $k$。那么 $y$ 中至少有 $n - k$ 个字符 $\ge y_{(k)}$（即排序后的 $y_{(k)}, \dots, y_{(n-1)}$），它们都必须被 $x$ 中**不同**的且值不小于自身的字符支配。但 $x$ 中值 $\ge y_{(k)}$ 的字符至多 $n - k - 1$ 个：由 $x_{(k)} < y_{(k)}$ 及升序，$x_{(0)}, \dots, x_{(k)}$（共 $k+1$ 个）全部 $< y_{(k)}$，能支配 $\ge y_{(k)}$ 者只剩 $x_{(k+1)}, \dots, x_{(n-1)}$（至多 $n-k-1$ 个）。$n - k$ 个需求对 $n - k - 1$ 个供给，鸽巢原理下不存在完美支配，与 $\sigma$ 存在矛盾。∎

**定理**：`checkIfCanBreak(s1, s2)` 返回 `true` 当且仅当 $s_1$ 能打破 $s_2$ 或 $s_2$ 能打破 $s_1$。

**证明**：由引理 1、2，$s_1$ 打破 $s_2$ ⇔ 排序后 $a_i \ge b_i$ 逐位成立（$a = \mathrm{sorted}(s_1)$，$b = \mathrm{sorted}(s_2)$）；$s_2$ 打破 $s_1$ ⇔ $b_i \ge a_i$ 逐位成立。算法在单趟循环中同时验证两个条件，返回其析取，与题意一致。∎

## 6. 复杂度分析

- **时间**：$O(n \log n)$，排序主导；一趟比较 $O(n)$。若改用 26 桶计数排序可优化到 $O(n + |\Sigma|)$，但 $n \le 10^5$ 时无必要。
- **空间**：$O(n)$（Python 排序产生新串）或 $O(\log n)$（C++ 原地 `sort` 的递归栈；不计输入本身则近原地）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool checkIfCanBreak(string s1, string s2) {
        sort(s1.begin(), s1.end());
        sort(s2.begin(), s2.end());
        bool s1Breaks = true, s2Breaks = true;
        for (size_t i = 0; i < s1.size(); ++i) {
            if (s1[i] < s2[i]) s1Breaks = false;  // s1 逐位压不住 s2
            if (s1[i] > s2[i]) s2Breaks = false;  // s2 逐位压不住 s1
        }
        return s1Breaks || s2Breaks;
    }
};
```

### Python

```python
class Solution:
    def checkIfCanBreak(self, s1: str, s2: str) -> bool:
        a, b = sorted(s1), sorted(s2)
        s1_breaks = all(x >= y for x, y in zip(a, b))
        s2_breaks = all(x <= y for x, y in zip(a, b))
        return s1_breaks or s2_breaks
```

> 💡 两份代码均通过全部官方示例（3 组）；并与基于 **Hall 定理**的二分图完美匹配独立暴力（枚举 $s_2$ 的全部子集验证邻居条件）在 7 个特值 + 3000 组随机（$n \le 8$，小字母表制造大量碰撞）上对拍，`mismatch = 0`。

## 8. 边界情况与易错点

1. **"或"语义**：两个方向只要一个成立即 `true`；只检查单方向是错的（示例 1 中 $s_1$ 打不破 $s_2$，但反向成立）。
2. **相等串**：$s_1 = s_2$ 时逐位相等，两个方向都成立，返回 `true`——相等也算"打破"。
3. **不能只比总大小/字典序**：`sorted(s1) <= sorted(s2)` 的字符串字典序成立不代表逐位成立（如 `abe` 与 `acd` 字典序 `abe > acd`，但两个方向都有一位失败）。必须**逐位**判定。
4. **`all` 的短路**：Python 的 `all` 遇 `False` 提前返回；C++ 版可加 `if (!s1Breaks && !s2Breaks) break;` 提前退出，最坏复杂度不变。
5. **`n = 1`**：单字符直接比一次即可，排序后逻辑天然覆盖。
6. **别真的去枚举排列**：全排列复杂度 $O(n!)$，$n = 10^5$ 下毫无可能；识别"排列比较 = 多重集合比较"是本题第一层，"多重集合支配 = 排序对齐"是第二层。
