# LeetCode 拥有最多糖果的孩子 题解

## 1. 题目概述

- **标题 / 题号**：拥有最多糖果的孩子（#1431，easy）
- **链接**：https://leetcode.cn/problems/kids-with-the-greatest-number-of-candies/
- **来源**：LeetCode 第 25 场双周赛 Q1
- **难度**：简单
- **标签**：数组

**题意**：给定数组 `candies`，`candies[i]` 是第 $i$ 个孩子现有的糖果数；再给定整数 `extraCandies` 表示你手中的额外糖果。若把**全部**额外糖果都给第 $i$ 个孩子，他的糖果数变为 $candies[i] + extraCandies$。要求返回长度为 $n$ 的布尔数组 `result`：$result[i] = true$ 当且仅当第 $i$ 个孩子拿到全部额外糖果后，拥有的糖果数**不少于**所有孩子中的最大值（注意是"最多"里"不少于"的含义，允许多人并列最多）。

**约束**：

- $n = candies.length$，$2 \le n \le 100$
- $1 \le candies[i] \le 100$
- $1 \le extraCandies \le 50$

## 2. 示例

**示例 1**

```text
输入：candies = [2,3,5,1,3], extraCandies = 3
输出：[true,true,true,false,true]
解释：孩子 1：2+3=5 ≥ 5（最大值）；孩子 2：3+3=6 ≥ 5；孩子 3：5+3=8 ≥ 5；
孩子 4：1+3=4 < 5；孩子 5：3+3=6 ≥ 5。
```

**示例 2**

```text
输入：candies = [4,2,1,1,2], extraCandies = 1
输出：[true,false,false,false,false]
解释：只有 1 个额外糖果，只有孩子 1（4+1=5）能追平/超过全场最大值 4。
```

**示例 3**

```text
输入：candies = [12,1,12], extraCandies = 10
输出：[true,false,true]
解释：最大值 12，孩子 1、3 已是最大，加糖后仍最大；孩子 2 是 1+10=11 < 12。
```

## 3. 解题思路

### 3.1 暴力思路

对每个孩子 $i$，把 $candies[i] + extraCandies$ 与**其余所有孩子**逐个比较，判断是否全场最大——$O(n^2)$。$n \le 100$ 时至多 $10^4$ 次比较，完全可通过；但当 $n$ 达到 $10^5$ 级别就会浪费，面试/比赛里更希望一步到位。

### 3.2 核心观察：比较对象只需"全场最大值"一个数

![核心观察：只需与全场最大值比较一次](images/bw25_q1_max_compare_concept.svg)

判断"加上额外糖果后是否是全场最多"，等价于判断

$$candies[i] + extraCandies \ge \max_{j} candies[j]$$

原因很简单：**"不小于所有孩子" ⇔ "不小于其中的最大者"**。一次 $O(n)$ 扫描先求出全场最大值 $mx$，再对每个孩子做一次比较即可，总共 $O(n)$。

### 3.3 算法流程

![算法流程：求最大值后逐个比较](images/bw25_q1_algorithm_flow.svg)

```text
1. 扫描 candies 求最大值 mx
2. 对每个 i：result[i] = (candies[i] + extraCandies >= mx)
3. 返回 result
```

### 3.4 示例演算

![示例演算：每个孩子与阈值 5 的比较](images/bw25_q1_example_walkthrough.svg)

以示例 1（`candies = [2,3,5,1,3]`，`extraCandies = 3`）为例：$mx = 5$，阈值判断依次为 $5, 6, 8, 4, 6$ 与 $5$ 比较，得 `[true,true,true,false,true]`。

## 4. 算法细节

1. **比较用 $\ge$ 而非 $>$**：题目允许并列最多。$candies[i] + extraCandies = mx$ 时同样是"拥有最多的糖果"，必须判 `true`（示例 1 中孩子 1 的 $2+3=5$ 恰好等于 $mx$）。
2. **最大值包含自己**：$mx$ 是**全部**孩子的最大值（含第 $i$ 个孩子自己），不是"其余孩子"的最大值。含不含自己对本题结果无影响（$x + e \ge x$ 恒真，$e \ge 1 > 0$），但"含自己"实现上更省事，也和题面"所有孩子中"的表述一致。
3. **无需排序**：只要最大值，一次扫描即可，排序是 $O(n \log n)$ 的浪费。
4. **取值范围**：$candies[i] + extraCandies \le 150$，`int`/`bool` 无任何溢出风险。
5. **返回类型**：LeetCode 的 `vector<bool>` / `list[bool]` 是压缩存储，直接构造返回即可。

## 5. 正确性证明

**引理 1**：对任意实数集合 $S$ 与实数 $x$，"$x \ge s$ 对所有 $s \in S$ 成立" 当且仅当 "$x \ge \max S$"。

**证明**：设 $m = \max S \in S$。若 $x \ge s$ 对一切 $s \in S$ 成立，则对 $m \in S$ 也有 $x \ge m$。反之若 $x \ge m$，对任意 $s \in S$ 有 $s \le m \le x$，即 $x \ge s$。∎

**定理**：令 $mx = \max_j candies[j]$，则把全部额外糖果给第 $i$ 个孩子后其糖果数为全场最多的充要条件是 $candies[i] + extraCandies \ge mx$。

**证明**：给第 $i$ 个孩子全部额外糖果后，各孩子糖果数为 $c_1, \dots, c_n$，其中 $c_i = candies[i] + extraCandies$，$c_j = candies[j]\ (j \ne i)$。"第 $i$ 个孩子拥有最多" 即 $c_i \ge c_j$ 对所有 $j$ 成立。注意 $\max_j c_j = \max(mx,\ c_i)$（其余孩子的最大值就是 $mx$，而 $extraCandies \ge 1$ 时 $c_i$ 可能超过 $mx$）。由引理 1，条件等价于 $c_i \ge \max_j c_j$。分两种情形：若 $c_i \ge mx$，则 $\max_j c_j = c_i$，条件 $c_i \ge c_i$ 成立；若 $c_i < mx$，则 $\max_j c_j = mx > c_i$，条件不成立。故充要条件恰为 $c_i \ge mx$。∎

## 6. 复杂度分析

- **时间**：$O(n)$。一次扫描求最大值 + 一次扫描逐个比较，均为线性。
- **空间**：$O(1)$ 额外空间（不计返回数组；返回数组本身 $O(n)$）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<bool> kidsWithCandies(vector<int>& candies, int extraCandies) {
        int mx = 0;
        for (int c : candies) mx = max(mx, c);   // 全场最多糖果数
        vector<bool> res;
        res.reserve(candies.size());
        for (int c : candies)
            res.push_back(c + extraCandies >= mx);
        return res;
    }
};
```

### Python

```python
class Solution:
    def kidsWithCandies(self, candies: list[int], extraCandies: int) -> list[bool]:
        mx = max(candies)
        return [c + extraCandies >= mx for c in candies]
```

> 💡 两份代码均通过全部官方示例（3 组），并与 $O(n^2)$ 的"逐对比较"独立实现在 1500 组随机数据（$n \le 100$）上对拍，`mismatch = 0`。

## 8. 边界情况与易错点

1. **并列最多**：比较必须用 $\ge$，写成 $>$ 会把"恰好追平"（如示例 1 的孩子 1）错判为 `false`。
2. **最大值包含自己**：不要试图用"其余 $n-1$ 个孩子的最大值"简化——虽不影响正确性，但实现多一次分支且易错；直接用全场最大值。
3. **"全部额外糖果只给一个人"**：额外糖果不可拆分、不可不给，只考察"全给第 $i$ 个"这 $n$ 种方案，不是背包分配。
4. **溢出无忧但别乱开 long long**：数值上界 150，`int` 足够，无需长整型。
5. **空数组不会出现**：$n \ge 2$，`max(candies)` 安全；若在其他场景复用此写法，需先判空。
