# LeetCode 改变一个整数能得到的最大差值 题解

## 1. 题目概述

- **标题 / 题号**：改变一个整数能得到的最大差值（#1432，medium）
- **链接**：https://leetcode.cn/problems/max-difference-you-can-get-from-changing-an-integer/
- **来源**：LeetCode 第 25 场双周赛 Q2
- **难度**：中等
- **标签**：贪心、数学

**题意**：给你整数 $num$（十进制无前导零）。操作共进行**两次**，每次操作为：选一个数字 $x\ (0 \le x \le 9)$ 与一个数字 $y\ (0 \le y \le 9)$，把 $num$ 中**所有**等于 $x$ 的数位替换为 $y$（两次操作都基于原始 $num$）。设两次结果为 $a$、$b$，返回 $a - b$ 的最大值。限制：$a$、$b$ 都**不含前导零且不为 $0$**。

**约束**：

- $1 \le num \le 10^8$

## 2. 示例

**示例 1**

```text
输入：num = 555
输出：888
解释：a：把 5 全换成 9 得 999；b：把 5 全换成 1 得 111；差 999 - 111 = 888。
```

**示例 2**

```text
输入：num = 9
输出：8
解释：a = 9（不变），b：9→1 得 1，差 8。
```

**示例 3**

```text
输入：num = 123456
输出：820000
解释：a：1→9 得 923456；b：2→0 得 103456；差 923456 - 103456 = 820000。
```

**示例 4**

```text
输入：num = 10000
输出：80000
解释：a：1→9 得 90000；b 无法变小（非首位只有 0），保持 10000；差 80000。
```

**示例 5**

```text
输入：num = 9288
输出：8700
解释：a：2→9 得 9988；b：9→1 得 1288；差 8700。
```

## 3. 解题思路

### 3.1 暴力思路

一次操作的本质是「选 $num$ 中出现过的数位 $x$，全部替换为 $y$」，因此合法结果集合 $C$ 至多有 $10 \times 10 = 100$ 个元素（实际 $\le$ 出现数位数 $\times 10$）。暴力枚举 $C$ 中所有 $(a, b)$ 组合取最大差即可，$O(|C|^2)$，$|C| \le 100$，完全可过。本题正解只是把这个集合的 $\max$ 与 $\min$ 用**构造**直接写出来，省去枚举，顺便考察前导零的处理。

### 3.2 核心观察：差值 = 全局最大构造 − 全局最小构造

![核心构造：最大化把首个非 9 位变 9，最小化分两种情形](images/bw25_q2_max_min_construct.svg)

由于 $a, b$ 独立取自同一候选集 $C$，有

$$\max_{a,b \in C} (a - b) = \max_{c \in C} c - \min_{c \in C} c$$

于是只需分别构造**最大候选**与**最小候选**。数位长度固定，两个正整数先比长度（本题长度都相同）、再按字典序比大小，于是**越靠左的数位越具支配力**——这就是两条贪心的灵魂：

- **最大化**：把**最左边一个不是 9 的数位**（设为 $d$）全部替换为 9。若全是 9，则保持原数。
- **最小化**：分两种情形（见 3.3），核心障碍是**前导零**。

### 3.3 状态转移：最小化的两个分支

![最小化构造的两种情形与 11111、10000 特例](images/bw25_q2_min_cases.svg)

最小化要让尽量靠左的数位变小，但替换是"全部替换"，且首位不能变 0：

1. **首位不是 1**：把首位数位 $s_0$（连同所有等于 $s_0$ 的数位）替换为 **1**。首位 $s_0 \ge 2$ 变成 1，是首位能达到的最小值；任何不碰首位的替换结果首位仍是 $s_0 \ge 2$，必然更大，故此构造唯一最优。
2. **首位是 1**：首位已无法再小（不能变 0）。从左到右找**第一个**既不是 0 也不是 1 的数位 $d$，把所有 $d$ 替换为 **0**；若不存在这样的数位（形如 $11111$、$10000$、$101$），则**保持原数**——任何替换都不会更小。

注意两个细节坑：

- 首位是 1 时，为什么不选"首个非 1 数位"直接换 0？——若那个数位是 **0** 本身，替换无效；必须**跳过 0 和 1**（0 换 0 无意义、换别的会变大）。
- 首位是 1 且找到 $d$ 时，为什么不能把 $d$ 换成 1？——可以但非最优：$d$ 换 1 与换 0 的首变位相同，但该位上 $0 < 1$，换 0 更小。

### 3.4 示例演算

![示例演算：123456 与 9288 的构造过程](images/bw25_q2_example_walkthrough.svg)

| $num$ | 最大化 $a$ | 最小化 $b$ | 差值 |
|-------|-----------|-----------|------|
| 555 | 首个非 9 位 $5 \to 9$：999 | 首位 $5 \to 1$：111 | 888 |
| 9 | 全 9，$a = 9$ | 首位 $9 \to 1$：1 | 8 |
| 123456 | 首个非 9 位 $1 \to 9$：923456 | 首位是 1，首个非 0/1 位 $2 \to 0$：103456 | 820000 |
| 10000 | $1 \to 9$：90000 | 首位是 1，无非 0/1 位，保持 10000 | 80000 |
| 9288 | 首个非 9 位 $2 \to 9$：9988 | 首位 $9 \to 1$：1288 | 8700 |

## 4. 算法细节

1. **以字符串处理**：$num \le 10^8$ 至多 9 位，`to_string` 后按下标操作，最后 `stoi` 转回整数做减法（$a \le 999999999 < 2^{31}-1$，`int` 安全）。
2. **最大化扫描**：从头找第一个 `!= '9'` 的字符 $c$，把所有 $c$ 改成 `'9'`；找不到则 $a = num$（任何替换只会变小或不变）。
3. **最小化分支**：`s[0] != '1'` 时替换所有 `s[0]` 为 `'1'`；否则从下标 1 起找第一个不属于 `{'0','1'}` 的字符 $c$，替换所有 $c$ 为 `'0'`，找不到则 $b = num$。
4. **候选集大小**：出现过的数位至多 9 种，每次操作选 1 个 $x$ 和 1 个 $y$，合法候选 $\le 90$ 个——贪心构造只是"直接跳到 $\max$ / $\min$"，二者在对拍里互相印证（见 §7 末尾）。
5. **"全部替换"语义**：`str.replace(x, y)` 替换所有出现，不是只换一处；这也是 9288 中 9 换 1 时两个 9 一起变的原因。

## 5. 正确性证明

记 $s$ 为 $num$ 的十进制串（长 $L$，无前导零），$C$ 为所有"一次操作产生的合法数"（无前导零、非零）构成的集合。注意 $num \in C$（取 $y = x$），故 $C$ 非空。

**引理 1（差值分解）**：$\max_{a, b \in C}(a - b) = \max C - \min C$。

**证明**：对任意 $a, b \in C$，$a - b \le \max C - b \le \max C - \min C$；取 $a = \max C,\ b = \min C$ 即达到该值，而 $a, b$ 是两次**独立**操作的结果（两次都基于原 $num$），允许取到。∎

**引理 2（首变位支配）**：设候选 $c \in C$ 由替换 $x \to y$ 得到。若 $y > x$，则 $c$ 与 $s$ 的第一个不同位是 $x$ 在 $s$ 中的最左出现位置 $i(x)$，且 $c > s$；若 $y < x$，同理 $c$ 与 $s$ 的第一个不同位仍是 $i(x)$，且 $c < s$；若 $y = x$ 则 $c = s$。进而：对两个"增候选" $c_1, c_2$，若 $i(x_1) < i(x_2)$，则 $c_1 > c_2$；对两个"减候选"，若 $i(x_1) < i(x_2)$，则 $c_1 < c_2$。

**证明**：$y \ne x$ 时 $x$ 出现的每个位置都发生改变，其余位置不变，故第一处不同位即 $i(x)$。$s$ 与 $c$ 在 $i(x)$ 前完全相同，在 $i(x)$ 处 $c$ 为 $y$、$s$ 为 $x$：$y > x$ 则 $c > s$，$y < x$ 则 $c < s$（同长数字串的字典序即数值序）。再比较两个增候选 $c_1, c_2$：设 $i_1 = i(x_1) < i_2 = i(x_2)$。位置 $< i_1$ 处 $c_1, c_2$ 均与 $s$ 相同故彼此相同；位置 $i_1$ 处 $c_1$ 为 $y_1 > x_1 = s_{i_1}$，而 $c_2$ 在 $i_1$ 处未变（$i_2 > i_1$，故 $s_{i_1} \ne x_2$，即 $c_2$ 该位仍是 $s_{i_1} = x_1 < y_1$）。故 $c_1 > c_2$。减候选情形对称。∎

**定理 1（最大化构造）**：设 $p$ 为 $s$ 中最左边满足 $s_p \ne 9$ 的下标（若存在），则 $\max C = s$ 将 $s_p$ 全部替换为 9 的结果；若 $s$ 全为 9，则 $\max C = s$。

**证明**：候选分三类。恒等候选（$y = x$）值为 $s$。减候选（$y < x$）由引理 2 小于 $s$。增候选（$y > x$）中，$x$ 必须是 $s$ 中出现且 $x \ne 9$ 的数位（$y \le 9$），其首变位 $i(x)$ 是 $x$ 的最左出现位置；这些位置的最小值恰为 $p$——因为下标 $< p$ 处 $s_j = 9$ 不可能是任何 $x \ne 9$ 的出现位置，而 $s_p \ne 9$ 使 $p$ 可作为 $i(x)$（取 $x = s_p$）。由引理 2，增候选中首变位最小者最大；再把 $y$ 取到最大值 9，即得构造。它与 $s$ 比较是增候选，故超过 $s$ 与一切减候选。若 $s$ 全为 9，不存在增候选，$\max C = s$。∎

**定理 2（最小化构造）**：若 $s_0 \ne 1$，则 $\min C = s$ 将 $s_0$ 全部替换为 1 的结果；若 $s_0 = 1$，设 $q$ 为最左边满足 $q \ge 1$ 且 $s_q \notin \{0, 1\}$ 的下标（若存在），则 $\min C$ 为 $s$ 将 $s_q$ 全部替换为 0 的结果，否则 $\min C = s$。

**证明**：候选分三类。恒等候选值为 $s$。增候选大于 $s$，不可能为最小。减候选需 $y < x$ 且结果无前导零。若 $s_0 \ne 1$：任何"不改变首位"的替换（$x \ne s_0$）结果首位仍为 $s_0 \ge 2$，而把 $x = s_0$ 换成 $y = 1$ 的候选首位为 1；同长数字中首位 $1 < 2 \le s_0$ 支配一切，故最小候选必须由 $x = s_0, y = 1$ 产生（$y = 0$ 前导零非法，$y \ge 2$ 首位更大），该候选唯一。若 $s_0 = 1$：首位不可再小（$y = 0$ 非法），最小候选必保持首位 1，于是 $x \ne 1$（$x = 1, y \ge 2$ 使首位变大、$y = 0$ 非法）。减候选要求 $x \ge 2$ 且 $x$ 在下标 $\ge 1$ 处出现（$x$ 在下标 0 处的值是 1，不含 $x$）。对 $y$：$y = 0$ 使每个变化位达到最小，且首变位不变，由引理 2 的比较（同为减候选，且在首变位处 $0 < 1 \le$ 任何其他 $y$），$y = 0$ 不劣于 $y \ge 1$。对 $x$ 的选择：减候选 $c_x$ 的首变位是 $x$ 在下标 $\ge 1$ 中的最左出现 $i(x)$，由引理 2，首变位最小者最小；下标 $q$ 正是所有"出现于 $\ge 1$ 且值 $\notin \{0,1\}$ 的数位"的最左出现位置的最小者。若不存在这样的数位，则无非恒等减候选，$\min C = s$。∎

## 6. 复杂度分析

- **时间**：$O(L)$，其中 $L \le 9$ 是数位长度。两次线性扫描 + 两次整体替换。
- **空间**：$O(L)$。字符串副本；转整数用 `int` 返回差值。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maxDiff(int num) {
        string s = to_string(num);
        // a（最大化）：把第一个不是 9 的数位全部替换成 9
        string a = s;
        for (char c : s) {
            if (c != '9') {
                for (char& ch : a)
                    if (ch == c) ch = '9';
                break;
            }
        }
        // b（最小化）：首位不是 1 时把首位数字全部替换成 1；
        //              否则把第一个「非 0 非 1」的非首位数位替换成 0
        string b = s;
        if (s[0] != '1') {
            for (char& ch : b)
                if (ch == s[0]) ch = '1';
        } else {
            for (int i = 1; i < (int)s.size(); ++i) {
                if (s[i] != '0' && s[i] != '1') {
                    for (char& ch : b)
                        if (ch == s[i]) ch = '0';
                    break;
                }
            }
        }
        return stoi(a) - stoi(b);
    }
};
```

### Python

```python
class Solution:
    def maxDiff(self, num: int) -> int:
        s = str(num)
        # a（最大化）：把第一个不是 9 的数位全部替换成 9
        a = s
        for c in s:
            if c != '9':
                a = s.replace(c, '9')
                break
        # b（最小化）：首位不是 1 时把首位数字全部替换成 1；
        #              否则把第一个「非 0 非 1」的非首位数位替换成 0
        if s[0] != '1':
            b = s.replace(s[0], '1')
        else:
            b = s
            for i in range(1, len(s)):
                if s[i] != '0' and s[i] != '1':
                    b = s.replace(s[i], '0')
                    break
        return int(a) - int(b)
```

> 💡 两份代码均通过全部 5 个官方示例；C++ 与 Python 输出一致，并与「穷举全部 $(x, y)$ 替换组合」的暴力在 27 个特值 + 8000 组随机（$num \le 10^8$）上对拍，`mismatch = 0`。

## 8. 边界情况与易错点

1. **全 9 输入**（99999999）：最大化分支找不到非 9 位，$a = num$，别返回 0 或漏判。
2. **首位为 1 且无 2..9 位**（11111、10000、101）：最小化必须**保持原数**；写成"找不到就替换首位"或返回 0 都是错的。
3. **最小化跳过 0 和 1**：首位为 1 时，若把"第一个非 1 位"直接换 0，遇到 10000 这类（第一个非 1 位是 0）会做无效替换；必须限定 $s_i \notin \{0, 1\}$。
4. **首位为 1 时别忘排除"把 1 换成 1"**：恒等操作合法但无意义；把 1 换成 $\ge 2$ 会增大首位，直接排除。
5. **首位非 1 时替换目标只能是 1 不是 0**：把首位换成 0 产生前导零，非法；换成 1 是首位的最小合法值。
6. **两次操作相互独立**：都基于原始 $num$，第二次不是在第一次结果上进行，不要"链式"处理。
7. **溢出无忧**：$a < 10^9$、$b \ge 1$，差值 $< 10^9$，`int` 足够（C++ `stoi` 正常）。
