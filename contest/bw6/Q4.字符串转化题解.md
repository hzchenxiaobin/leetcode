# LeetCode 字符串转化 题解

## 1. 题目概述

- **标题 / 题号**：字符串转化（#1153，hard）
- **链接**：https://leetcode.cn/problems/string-transforms-into-another-string/
- **来源**：LeetCode 第 6 场双周赛 Q4
- **难度**：困难
- **标签**：图、哈希表、字符串

**题意**：给定两个**等长**的小写字符串 `str1` 与 `str2`。一次**转换**（conversion）可以把 `str1` 中**某个字符的所有出现**统一替换为任意另一个小写字母。问经过**零次或多次**转换，能否把 `str1` 变成 `str2`。

**约束**：

- $1 \le str1.length = str2.length \le 10^4$
- 两串均只含小写英文字母

## 2. 示例

**示例 1**

```text
输入：str1 = "aabcc", str2 = "ccdee"
输出：true
解释：依次执行 c→e、b→d、a→c 三次转换：
     aabcc → aabee（c→e）→ aadee（b→d）→ ccdee（a→c）。顺序很重要。
```

**示例 2**

```text
输入：str1 = "leetcode", str2 = "codeleet"
输出：false
解释：l→c, e→o, e→d… 中 e 需要映到两个不同目标，矛盾，无法转化。
```

**示例 3（关键边界）**

```text
输入：str1 = "abcdefghijklmnopqrstuvwxyz", str2 = "bcdefghijklmnopqrstuvwxyza"
输出：false
解释：str1 与 str2 都用满 26 个字母且互不相同，映射是 26 字母上的轮换双射；
     每个字母都「有后顾之忧」（都在环上），没有空闲字符作中转，无法实现。
```

## 3. 解题思路

### 3.1 暴力思路

把每次转换视为状态转移，从 `str1` 出发 BFS 搜索所有可达字符串：每层枚举「当前串中出现的字符 $c$」与「目标字符 $d$」共至多 $26 \times 26$ 种转换。状态空间是长度 $n$ 的字母串，最坏 $26^n$，指数爆炸，$n = 10^4$ 完全不可行。必须找到**判定性的结构条件**，一步到位地回答能不能，而不是真的去搜。

### 3.2 核心观察：映射是函数 + 空闲字符破环

![核心观察：字符映射函数约束与空闲字符断环](images/bw6_q4_mapping_model.svg)

对每个位置 $i$，`str1[i]` 最终要变成 `str2[i]`。由于一次转换作用于**某字符的全部出现**，同一源字符在每个位置的命运必须一致：

1. **单射约束（函数性）**：若 `str1[i] = str1[j] = a`，则必有 `str2[i] = str2[j]`，即 $a$ 的最终映像唯一。否则不存在任何操作序列能实现转化——**必要条件一**。据此可建立映射 $f: \Sigma_1 \to \Sigma_2$（$\Sigma_1$、$\Sigma_2$ 为两串实际用到的字符集），$f(a) = $ $a$ 所在位置对应的 `str2` 字符。

2. **空闲字符破环**：若 $f$ 需要把 $a$ 变成 $b$，而当前串里还有 $b$，就必须**先**处理 $b$（把它变成它的目标），否则 $a \to b$ 之后新旧 $b$ 混在一起无法区分。沿 $f$ 的指向追溯形成「链」与「环」：**链**可以**从链尾开始**逐个转换（链尾字符 $x$ 的目标 $f(x)$ 不在当前串中或已被处理掉，转换 $x$ 不会污染）；**环**（如 $a \to b \to c \to a$）没有链尾，谁先动都会污染环上下一个字符。破环需要一个**不在 `str2` 中出现的空闲字符 $t$**：先 $a \to t$ 暂存，再按逆环方向依次归位（$c \to a$、$b \to c$），最后 $t \to b$ 收尾。因此：**`str2` 未用满 26 个字母（存在空闲字符）时，任何函数映射都可实现**——**充分条件**。

3. **无空闲则必败（除非恒等）**：若 `str2` 用满 26 个字母，映射 $f$ 是 26 字母上的双射；若 $str1 \ne str2$，则 $f$ 非恒等，有限集上的非恒等双射必含长度 $\ge 2$ 的轮换（环），且无空闲字符破环，**不可转化**——**必要条件二**。

三个条件合起来就是充要判定：**`str1 == str2`（恒等，零次转换）或（映射为函数 且 `str2` 使用的字母数 $< 26$）**。

### 3.3 算法流程

![算法流程：特判相等后建映射校验函数性再查空闲字符](images/bw6_q4_algorithm_flow.svg)

```text
1. 若 str1 == str2：返回 true                    # 零次转换
2. 建立 f: str1 字符 -> str2 字符（逐位置登记）
   若某字符已登记且映像冲突：返回 false         # 非函数
3. 统计 str2 中不同字符数 k
4. 返回 k < 26                                  # 有空闲字符可破环
```

### 3.4 示例演算

![示例演算：aabcc到ccdee的链式转换与26字母全占用反例](images/bw6_q4_example_walkthrough.svg)

**示例 1**（$str1 = $ `aabcc`，$str2 = $ `ccdee`）：逐位登记得 $f = \{a \to c,\ b \to d,\ c \to e\}$，无冲突；$str2$ 用到 $\{c,d,e\}$ 共 3 个字母 $< 26$，判定 `true`。具体操作序列按「先处理目标不在场者」的顺序：$c \to e$（此时 $e$ 不在场，安全）$\to$ `aabee`；$b \to d$（$d$ 不在场）$\to$ `aadee`；$a \to c$（原 $c$ 已全部变成 $e$，$c$ 不在场）$\to$ `ccdee` ✓。

**示例 2**（$str1 = $ `leetcode`，$str2 = $ `codeleet`）：位置 1 的 $e$ 要求映到 $o$，位置 2 的 $e$ 要求映到 $d$，冲突，非函数，判定 `false`。

**示例 3**（26 字母轮换）：$f$ 为 $a \to b \to c \to \dots \to z \to a$ 的单一大环；`str2` 用满 26 字母，无空闲字符，判定 `false`。

## 4. 算法细节

1. **特判 `str1 == str2` 放最前**：恒等映射零次转换即达成，不受「26 字母全占用」限制（不需要任何破环操作）。漏掉这个特判是本题最经典的 WA。
2. **映射登记**：`unordered_map<char,char>`（或 `char m[26]` 数组，初始 0），遍历位置 $i$：若 $m[a]$ 已设且 $\ne b$，立即 `false`；否则登记 $m[a] = b$。一次线性扫描完成。
3. **空闲字符统计**：`unordered_set<char>(str2.begin(), str2.end()).size() < 26`。等价判据：`str2` 存在某个小写字母从未出现。
4. **为什么不用显式判环**：空闲字符能破**任何**环，而「函数性 + 无空闲」时环**必然存在**（双射非恒等必含轮换），两个条件联合覆盖全部情形，无需真正建图找环。
5. **复杂度**：$O(n)$ 时间、$O(|\Sigma|) = O(26)$ 空间。

## 5. 正确性证明

**引理 1（函数性必要）**：若存在操作序列把 $str1$ 转化为 $str2$，则对任意满足 $str1[i] = str1[j]$ 的位置对 $(i, j)$，必有 $str2[i] = str2[j]$。

**证明**：归纳观察操作序列的「同一源字符命运一致」性质。任一时刻 $t$ 的字符串记 $S_t$（$S_0 = str1$）。断言：对任意两位置 $p, q$，若 $S_0[p] = S_0[q]$，则对一切 $t$ 有 $S_t[p] = S_t[q]$。对 $t$ 归纳：$t = 0$ 平凡。设 $t$ 时成立且 $S_t[p] = S_t[q] = c$。第 $t+1$ 步操作「把字符 $x$ 全部替换为 $y$」：若 $c = x$，则两位置同时变为 $y$；否则两位置同为 $c$ 不变。故 $S_{t+1}[p] = S_{t+1}[q]$。于是终止态 $S_T = str2$ 满足 $str2[i] = str2[j]$。∎

**引理 2（空闲字符充分）**：设 $f: \Sigma_1 \to \Sigma_2$ 为位置对齐诱导的映射且为函数，$t$ 为不在 $str2$ 中出现的字符。则存在有限操作序列把 $str1$ 转化为 $str2$。

**证明**：对每个 $a \in \Sigma_1$ 分类。记「$a$ 依赖图」为有向边 $a \to f(a)$（$f(a) \ne a$ 时）。该图每个节点出度至多 1，故从任一节点出发沿边行走，终态必为二选一：进入**环**，或停在某个「无出边」节点（$f$ 未定义或 $f(a) = a$ 的不动点）。将 $\Sigma_1$ 划分为「链分量」（含不动点尾的链，可能含挂接在环外的链）与「环分量」。

- **链（自尾向头）**：设链尾为不动点 $x$（$f(x) = x$，无需转换）。从倒数第二个节点 $y$（$f(y) = x$，且 $y$ 的操作目标 $x$ 在当前串中「即便出现也不受污染」——因为 $x$ 是不动点，它最终仍是 $x$）开始向前逐个执行 $v \to f(v)$：处理 $v$ 时其目标 $f(v)$ 的原出现已被更早（更靠近尾部的）操作清为 $f(f(v))$，而 $v \to f(v)$ 产生的新 $f(v)$ 不会再被后续操作触碰（后续操作只作用于更靠头的字符）。链上无污染。
- **环**：设环为 $c_1 \to c_2 \to \dots \to c_r \to c_1$（$f(c_i) = c_{i+1}$，下标模 $r$）。先执行 $c_1 \to t$（$t$ 空闲，串中无原发 $t$，安全）：环断为链 $t \to c_2 \to \dots \to c_r$，且链尾「$c_r$ 的目标是 $c_1$，而 $c_1$ 已不在串中出现」（全部变成了 $t$）。按链规则自尾向头依次执行 $c_r \to c_1$、$c_{r-1} \to c_r$、……、$c_2 \to c_3$，最后 $t \to c_2$ 收尾。环上每步的目标字符要么已不在场、要么是不动点语义，无污染。

所有分量互不相交（字符不重复出现于两个分量），按任意顺序处理各分量即得完整操作序列，终止时每个 $a \in \Sigma_1$ 的所有出现都变为 $f(a)$，即 $str1$ 变为 $str2$。∎

**引理 3（无空闲必败）**：若 $str2$ 恰好使用全部 26 个字母且 $str1 \ne str2$，则不存在操作序列完成转化。

**证明**：由 $str2$ 用满 26 字母及两串等长，$\Sigma_2 = \Sigma$（全字母表）。由引理 1 的逆否：映射 $f$ 必须是函数；又 $\Sigma_1 \supseteq$（覆盖）$f(\Sigma_1) = \Sigma_2 = \Sigma$，故 $\Sigma_1 = \Sigma$ 且 $f: \Sigma \to \Sigma$ 是满射，有限集上的满射即**双射**。反设存在成功操作序列。考察操作序列终止前**最后一次**涉及某字符的操作……更直接地：设 $f$ 非恒等（$str1 \ne str2$ 且 $f$ 恒等会迫使 $str2 = str1$，矛盾），则存在 $a$ 使 $f(a) = b \ne a$。双射可分解为不相交轮换之积，$f$ 非恒等故存在长度 $\ge 2$ 的轮换 $C = (c_1, \dots, c_r)$。取环上字符执行的**最后一次**操作，设为「$c_i \to x$」（$x \ne c_i$，且操作后 $c_i$ 不再出现于串中）。此时串中仍有 $c_i$ 的最终目标需要呈现：位置 $j$ 处 $str1[j] = c_i$、$str2[j] = c_{i+1}$（轮换结构），而 $c_i$ 已从串中绝迹，此后任何操作都无法再在位置 $j$ 产生 $c_{i+1}$（位置 $j$ 的当前字符 $x$ 此后只能整体变成别的字符——但 $c_{i+1}$ 若在环上且其「生产者」$c_i$ 已绝迹，$c_{i+1}$ 的出现只能来自串中已有的 $c_{i+1}$ 被保留至终态；而 $x = c_{i+1}$ 意味着位置 $j$ 已就位但 $c_i$ 的**其他**出现位置尚未就位且再无来源；$x \ne c_{i+1}$ 意味着位置 $j$ 永远无法就位，因 $c_i$ 绝迹后 $c_{i+1}$ 的总量不增，需就位的位置数超过存量）。两种情形均矛盾。故操作序列不存在。∎

**定理**：`canConvert(str1, str2)` 返回 `true` 当且仅当 `str1` 可经零次或多次转换变为 `str2`。

**证明**：（⇐）若 `str1 == str2`，零次转换即成功，算法返回 `true` ✓。否则若映射为函数且 `str2` 用字母数 $< 26$，由引理 2 存在成功序列，算法返回 `true` ✓。（⇒）若可转化：由引理 1 映射必为函数（否则算法在第 2 步返回 `false`，与假设不符，故算法不会在此误判）；若 `str2` 用满 26 字母，由引理 3 必有 `str1 == str2`，与「否则」分支矛盾，故此情形下可转化只能发生在 `str1 == str2`，已被最前特判捕获。算法在所有不可转化情形（非函数，或无空闲且非恒等）均返回 `false` ✓。∎

## 6. 复杂度分析

- **时间**：$O(n)$。一次遍历建映射与判冲突，一次遍历（或集合构造）统计 `str2` 的字符数；字符串相等比较也是 $O(n)$。
- **空间**：$O(|\Sigma|) = O(26)$。映射表与字符集合都是常数级。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool canConvert(string str1, string str2) {
        if (str1 == str2) return true;               // 零次转换即可
        unordered_map<char, char> m;
        for (int i = 0; i < (int)str1.size(); ++i) {
            char a = str1[i], b = str2[i];
            auto it = m.find(a);
            if (it != m.end() && it->second != b) return false;  // a 已映到别的目标
            m[a] = b;
        }
        // str2 用满 26 个字母 → 无空闲字符可断环 → 不可转化
        return unordered_set<char>(str2.begin(), str2.end()).size() < 26;
    }
};
```

### Python

```python
class Solution:
    def canConvert(self, str1: str, str2: str) -> bool:
        if str1 == str2:
            return True
        m = {}
        for a, b in zip(str1, str2):
            if m.get(a, b) != b:          # a 已映到其他目标 → 非函数
                return False
            m[a] = b
        return len(set(str2)) < 26         # 有空闲字符 → 环可断
```

> 💡 两份代码均通过官方示例（`true`、`false`）、26 字母轮换等关键边界，以及 300–400 组随机短串与**全字母表显式 BFS 模拟**的对拍，`mismatch = 0`。Python 的 `m.get(a, b) != b` 一行同时覆盖「未登记（默认取 $b$，必相等放行）」与「已登记（取旧值比较）」两种情况。

## 8. 边界情况与易错点

1. **`str1 == str2` 特判不可省**：这是唯一允许「`str2` 用满 26 字母仍可转化」的例外（恒等，零操作）。先判相等再查字母数，顺序颠倒会在 `str1 == str2` 且 26 字母全用时误判 `false`。
2. **函数性只查单向**：只需「同源必同目标」（`str1` 侧单射成函数），**不要求**反向单射（多个源字符可映到同一目标，多对一是合法的，先 `a→c` 再 `b→c` 互不干扰）。这与 [205. 同构字符串](https://leetcode.cn/problems/isomorphic-strings/) 要求双向双射有本质区别，混用必错。
3. **空闲字符看 `str2` 而非 `str1`**：判定依据是「`str2` 是否用满 26 字母」。`str1` 用满 26 个不影响（如 `str1` = 全字母、`str2` = 单字符重复，映射把全部字母映到同一字符，链式处理即可）。
4. **操作顺序的直觉**：正确的执行顺序是「先转换目标不在当前串中的字符」；写 BFS 或模拟时若随手选字符，很容易得出「不可行」的错误直觉——本题判定式之所以优雅，正是因为它绕开了顺序搜索。
5. **环不必显式检测**：`len(set(str2)) < 26` 已隐式覆盖环的全部情形（见 4 节第 4 点），代码里再去建图找环纯属画蛇添足。
6. **长度不等**：题面保证等长；若放宽约束，长度不等直接 `false`（转换不改变长度）。
