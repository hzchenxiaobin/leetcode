# LeetCode 检查一个数是否在数组中占绝大多数 题解

## 1. 题目概述

- **标题 / 题号**：检查一个数是否在数组中占绝大多数（#1150，easy）
- **链接**：https://leetcode.cn/problems/check-if-a-number-is-majority-element-in-a-sorted-array/
- **来源**：LeetCode 第 6 场双周赛 Q1
- **难度**：简单
- **标签**：数组、二分查找

**题意**：给定一个**按非递减顺序排序**的数组 `nums` 和一个目标值 `target`，判断 `target` 是否是数组的**多数元素**（majority element）：即 `target` 在数组中的**出现次数**是否**严格大于** $N/2$，其中 $N$ 为数组长度。

**约束**：

- $1 \le nums.length \le 1000$
- $1 \le nums[i] \le 10^9$
- $1 \le target \le 10^9$
- `nums` 已按非递减序排序

## 2. 示例

**示例 1**

```text
输入：nums = [2,4,5,5,5,5,5,6,6], target = 5
输出：true
解释：5 出现了 5 次，数组长度为 9，5 > 9/2 = 4.5 成立，
     因此 5 是多数元素。
```

**示例 2**

```text
输入：nums = [10,100,101,101], target = 101
输出：false
解释：101 出现了 2 次，数组长度为 4，2 > 4/2 = 2 不成立（恰好一半不算），
     因此 101 不是多数元素。
```

**示例 3（边界补充）**

```text
输入：nums = [1,2,2,3], target = 2
输出：false
解释：2 出现 2 次，恰好占 4/2 = 2，不满足「严格大于」，返回 false。
```

## 3. 解题思路

### 3.1 暴力思路

从头到尾线性扫描一遍，统计 `target` 的出现次数 `cnt`，最后判断 $cnt \times 2 > N$。时间 $O(N)$、空间 $O(1)$，在 $N \le 1000$ 的范围内毫无压力。但题面特意强调**有序**——这是二分查找的招牌暗示：相等元素在有序数组中必然**连续**成一段，出现次数可以通过两次二分（左端点、右端点）以 $O(\log N)$ 得到。作为双周赛 Q1，考点正是把「有序」这个条件转化为「区间定位」能力。

### 3.2 核心观察：有序数组中相等元素连续 → 两次二分夹出出现区间

![核心观察：两次二分定位target的连续出现区间](images/bw6_q1_binary_search_range.svg)

因为数组**非递减**，所有等于 `target` 的元素必然挤在一段连续区间 $[lo, hi)$ 里。于是：

$$\text{出现次数} = hi - lo = \mathrm{upperBound}(target) - \mathrm{lowerBound}(target)$$

其中：

- $lo = \mathrm{lowerBound}(target)$：第一个 $\ge target$ 的下标。若 $lo = N$ 或 $nums[lo] \ne target$，说明 `target` 根本不在数组里，直接返回 `false`；
- $hi = \mathrm{upperBound}(target)$：第一个 $> target$ 的下标。

两个端点都可以用标准二分在 $O(\log N)$ 内求出，无需触碰中间的任何元素——这就是「有序」条件的全部价值。

### 3.3 算法流程

![算法流程：lowerBound/upperBound两次二分后比较2cnt与n](images/bw6_q1_algorithm_flow.svg)

```text
1. lo = 二分找第一个 >= target 的下标
2. 若 lo == N 或 nums[lo] != target：返回 false     # target 不存在
3. hi = 二分找第一个 > target 的下标
4. 返回 (hi - lo) * 2 > N                          # 次数严格大于一半
```

### 3.4 示例演算

![示例演算：两组官方示例的二分定位过程](images/bw6_q1_example_walkthrough.svg)

以示例 1 为例（$nums = [2,4,5,5,5,5,5,6,6]$，$target = 5$，$N = 9$）：

| 步骤 | 二分目标 | 结果 | 说明 |
|------|----------|------|------|
| 1 | $lo$：第一个 $\ge 5$ | $2$ | $nums[2] = 5$ ✓，存在 |
| 2 | $hi$：第一个 $> 5$ | $7$ | $nums[7] = 6$ |
| 3 | 次数 $= 7 - 2 = 5$ | $5$ | $5 \times 2 = 10 > 9$ ✓ |

示例 2（$nums = [10,100,101,101]$，$target = 101$，$N = 4$）：$lo = 2$，$hi = 4$，次数 $= 2$，$2 \times 2 = 4$ **不大于** $4$ → `false`。恰好卡在一半是本题最容易忽略的判定边界。

## 4. 算法细节

1. **两次二分的语义要区分开**：`lowerBound` 用 $a[mid] \ge t$ 收缩右边界，`upperBound` 用 $a[mid] > t$ 收缩右边界，仅一个等号之差，写混了次数就会差 1。
2. **先判存在再算次数**：$nums[lo] \ne target$ 时提前返回 `false`，避免对不存在的值硬算区间（那会得到一段「别的值」的区间，结果是错的）。
3. **整数比较避免浮点**：判断 $cnt > N/2$ 用 $cnt \times 2 > N$，不做除法，杜绝 `N/2` 向下取整或浮点误差两类坑。
4. **直接用标准库更省事**：C++ 的 `lower_bound` / `upper_bound`、Python 的 `bisect_left` / `bisect_right` 正是这两个语义，比赛中建议直接调用，快且不易错。
5. **数值范围**：$N \le 1000$，$cnt \times 2 \le 2000$，任何整型都不会溢出。

## 5. 正确性证明

**引理 1（连续性）**：若数组非递减且 $nums[i] = nums[j] = target$（$i < j$），则对一切 $i \le k \le j$ 有 $nums[k] = target$。

**证明**：由非递减性 $target = nums[i] \le nums[k] \le nums[j] = target$，故 $nums[k] = target$。∎

**引理 2（端点刻画）**：设 $S = \{i : nums[i] = target\} \ne \varnothing$，则 $S = [lo, hi)$，其中 $lo$ 是第一个 $\ge target$ 的下标，$hi$ 是第一个 $> target$ 的下标。

**证明**：先证 $S \subseteq [lo, hi)$。任取 $i \in S$：由 $nums[i] = target \ge target$ 且 $lo$ 是满足 $\ge target$ 的最小下标，得 $i \ge lo$；由 $nums[i] = target \le target$（即不大于 $target$）且 $hi$ 是第一个 $> target$ 的下标，得 $i < hi$。再证 $[lo, hi) \subseteq S$：$nums[lo] \ge target$；若 $nums[lo] > target$，则与 $S \ne \varnothing$ 矛盾（取 $i \in S$，有 $i \ge lo$，若 $i = lo$ 则 $nums[lo] = target$，若 $i > lo$ 则 $target = nums[i] \ge nums[lo] > target$ 不可能），故 $nums[lo] = target$，$lo \in S$；于是 $hi - 1 \ge lo$ 且 $nums[hi-1] \le nums[hi-1]$，由 $hi-1 < hi$ 得 $nums[hi-1] \le target$，又 $hi - 1 \ge lo$ 得 $nums[hi-1] \ge target$，故 $nums[hi-1] = target$，即 $lo, hi-1 \in S$，由引理 1 整段 $[lo, hi) \subseteq S$。∎

**定理**：算法返回 `true` 当且仅当 `target` 在 `nums` 中的出现次数严格大于 $N/2$。

**证明**：若 `target` 不在数组中，第 2 步拦截返回 `false`，与「次数 $0 > N/2$（$N \ge 1$）为假」一致。若存在，由引理 2 出现次数 $cnt = hi - lo$，算法返回 $(hi-lo) \times 2 > N \iff cnt > N/2$，正是多数元素的定义。∎

## 6. 复杂度分析

- **时间**：$O(\log N)$。两次独立二分，每次将区间折半。
- **空间**：$O(1)$。只使用常数个下标变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool isMajorityElement(vector<int>& nums, int target) {
        // lower_bound: 第一个 >= target 的下标
        int lo = lowerBound(nums, target);
        if (lo == (int)nums.size() || nums[lo] != target) return false;  // target 不存在
        int hi = upperBound(nums, target);          // 第一个 > target 的下标
        return (hi - lo) * 2 > (int)nums.size();    // 出现次数 > n/2
    }
private:
    int lowerBound(vector<int>& a, int t) {         // [0, n] 内第一个 >= t
        int lo = 0, hi = (int)a.size();
        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            if (a[mid] >= t) hi = mid;
            else lo = mid + 1;
        }
        return lo;
    }
    int upperBound(vector<int>& a, int t) {         // [0, n] 内第一个 > t
        int lo = 0, hi = (int)a.size();
        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            if (a[mid] > t) hi = mid;
            else lo = mid + 1;
        }
        return lo;
    }
};
```

### Python

```python
class Solution:
    def isMajorityElement(self, nums: list[int], target: int) -> bool:
        lo = bisect.bisect_left(nums, target)     # 第一个 >= target
        if lo == len(nums) or nums[lo] != target:
            return False                          # target 不存在
        hi = bisect.bisect_right(nums, target)    # 第一个 > target
        return (hi - lo) * 2 > len(nums)          # 出现次数 > n/2
```

> 💡 Python 版在文件头（LeetCode 环境外）自测时需 `import bisect`；LeetCode 提交环境中 `bisect` 已预导入。C++ 版刻意手写两个二分以演示模板；比赛实战可直接 `lower_bound` / `upper_bound`。

两份代码均通过官方全部示例（`true`、`false`）及 2000–3000 组随机数据与线性计数暴力的对拍。

## 8. 边界情况与易错点

1. **「严格大于」**：恰好一半（示例 3 的 $cnt = N/2$）必须返回 `false`；用 $cnt \times 2 > N$ 而非 $cnt \ge N/2$。
2. **target 不在数组中**：$lo$ 位置的判等不可省略，否则会把「别的值的区间长度」当成出现次数。
3. **$lo = N$ 越界**：`target` 大于所有元素时 `lowerBound` 返回 $N$，取 `nums[lo]` 前必须先判 `lo == N`。
4. **两个二分模板差一个等号**：`lowerBound` 判 $\ge$，`upperBound` 判 $>$；写反会导致次数差 1，恰在一半的边界数据上出错。
5. **单元素数组**：$N = 1$，命中即 $1 > 0.5$ 返回 `true`；未命中返回 `false`。
6. **不要用浮点除法**：`cnt > n / 2` 在整数除法下是**向下取整**的 $N/2$，本题为严格大于时恰好不出错，但写成 `cnt >= n / 2` 就错了；统一用乘法比较最稳。
