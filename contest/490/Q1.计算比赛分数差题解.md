# LeetCode 计算比赛分数差 题解

## 1. 题目概述

- **标题 / 题号**：计算比赛分数差（#3847，medium）
- **链接**：https://leetcode.cn/problems/find-the-score-difference-in-a-game/
- **来源**：LeetCode 第 490 场周赛 Q1
- **难度**：中等
- **标签**：数组、模拟

**题意**：给定整数数组 `nums`，`nums[i]` 表示第 $i$ 场比赛的得分。两位玩家中恰有一位**主动玩家**（初始为玩家①），对每场比赛 $i$ **按顺序**应用三条规则：① 若 `nums[i]` 为奇数，主动方与被动方互换角色；② 每第 6 场比赛（索引为 $5, 11, 17, \dots$）互换角色；③ 主动玩家参加第 $i$ 场并获得 `nums[i]` 分。求**分差** = 玩家①总分 − 玩家②总分。

**约束**：
- $1 \le nums.length \le 1000$
- $1 \le nums[i] \le 1000$

> 💡 本场 Q1 罕见地评到了**中等**，难点不在算法而在**规则解读**：两条互换规则都发生在**记分之前**，且同一场比赛可能**同时触发**——两次互换相互抵消。这是一道纯**状态模拟**题，一个符号变量即可通关。

## 2. 示例

**示例 1**

```text
输入：nums = [1,2,3]
输出：0
解释：第 0 场分数 1 为奇数 → 玩家②主动并得 1 分；第 1 场无互换 → 玩家②得 2 分；
     第 2 场分数 3 为奇数 → 玩家①主动并得 3 分。分差 = 3 − 3 = 0。
```

**示例 2**

```text
输入：nums = [2,4,2,1,2,1]
输出：4
解释：第 0~2 场玩家①得 2+4+2 = 8 分；第 3 场分数 1 为奇数 → 玩家②主动；
     第 5 场分数为奇数 → 互换，又因是第 6 场比赛 → 再互换，两次抵消，
     玩家②继续主动。玩家②共得 1+2+1 = 4 分。分差 = 8 − 4 = 4。
```

**示例 3**

```text
输入：nums = [1]
输出：-1
解释：第 0 场分数为奇数 → 玩家②主动并得 1 分。分差 = 0 − 1 = −1（注意可能为负）。
```

## 3. 解题思路

### 3.1 暴力思路：显式模拟两位玩家

最直接的做法完全照搬题面：用布尔量 `firstActive` 记录玩家①是否主动，用两个变量分别累计两人的得分，每场比赛依次执行三条规则，最后返回两得分之差。

- 时间 $O(n)$、空间 $O(1)$，$n \le 1000$ 毫无压力。

由于 $n$ 很小，**直接模拟本身就是最优复杂度**，这道题真正的陷阱在**规则细节**（见 §8）：

- 把两条互换规则写成 `if / else if` 互斥分支 → 在索引 $\equiv 5 \pmod 6$ 且分数为奇数时漏算一次互换（示例 2 恰好考这一点）；
- 误以为"先记分、后按奇数换人" → 弄错奇偶判断的时机。

### 3.2 核心观察：互换 = 翻转一个符号开关

![两条互换规则汇聚为一个翻转开关](images/score_diff_rule_model.svg)

既然只关心**分差**（玩家① − 玩家②），就不必分别记录两人得分：用一个符号变量 $s \in \{+1, -1\}$ 表示当前主动方（$+1$ 为玩家①，$-1$ 为玩家②），每场比赛对分差的贡献就是 $s \cdot nums[i]$。

"互换角色"这个动作，在符号视角下就是**翻转**：$s \leftarrow -s$。两条规则各自独立地翻转一次：

- 规则①：`nums[i]` 为奇数 → $s \leftarrow -s$
- 规则②：$i \bmod 6 = 5$ → $s \leftarrow -s$

**关键性质（XOR 语义）**：同一场比赛两条规则同时触发时，$s$ 被翻转**两次**，净效果为**不变**；且两条规则的**先后顺序无关紧要**——互换是对换，其复合只取决于总次数的奇偶性。这正是示例 2 第 5 场"换两次等于没换"的原因。

### 3.3 算法流程

1. 初始化 `s = 1`（玩家①主动），`diff = 0`。
2. 从左到右遍历 $i = 0, 1, \dots, n-1$：
   - 若 `nums[i]` 为奇数：`s = -s`；
   - 若 `i % 6 == 5`：`s = -s`；（两个条件**独立判断**，不是 else-if）
   - `diff += s * nums[i]`。
3. 返回 `diff`。

**闭式视角**（可选）：第 $i$ 场记分时的符号为

$$s_i = (-1)^{\,odd(0..i) \,+\, \lfloor (i+1)/6 \rfloor}$$

其中 $odd(0..i)$ 是 `nums[0..i]` 中奇数的个数（规则①用的是**本场**分数，翻转发生在记分之前，故包含 $nums[i]$ 自身），$\lfloor (i+1)/6 \rfloor$ 是不超过 $i$ 的索引中 $\equiv 5 \pmod 6$ 的个数。对每场贡献 $s_i \cdot nums[i]$ 做前缀和，即可 $O(1)$ 回答任意前缀的分差查询。

### 3.4 示例演算

![示例2逐步演算](images/score_diff_example2_walkthrough.svg)

以示例 2 `nums = [2,4,2,1,2,1]` 走查一遍（$s$ 初始为 $+1$）：

| $i$ | nums[i] | ①奇数换人 | ②第 6 场 | 记分时 $s$ | 贡献 | 累计分差 |
|---|---|---|---|---|---|---|
| 0 | 2 | 否 | 否 | $+1$ | $+2$ | $2$ |
| 1 | 4 | 否 | 否 | $+1$ | $+4$ | $6$ |
| 2 | 2 | 否 | 否 | $+1$ | $+2$ | $8$ |
| 3 | 1 | **是** | 否 | $-1$ | $-1$ | $7$ |
| 4 | 2 | 否 | 否 | $-1$ | $-2$ | $5$ |
| 5 | 1 | **是** | **是**（抵消） | $-1$ | $-1$ | $4$ |

最终 `diff = 4`，与期望输出一致。

## 4. 算法细节

- **状态设计**：只维护一个 `int s`（±1）与累计 `diff`，不显式记录两个玩家的得分——分差是"相对量"，符号化后一方的得分自然以正负号进入累加。
- **两条规则独立判断**：先判 `nums[i] % 2 == 1`，再判 `i % 6 == 5`，二者可同时成立（相互抵消），**不能**写成 `if / else if` 互斥分支。
- **"第 6 场"的判定**：题面明确索引为 $5, 11, 17, \dots$，即 0-indexed 下的 `i % 6 == 5`，不是 `i % 6 == 0`，也不是 1-indexed 计数。
- **记分时机**：两条互换规则都在记分**之前**生效，因此奇偶判断用的是**本场**的 `nums[i]`（"先换人、后得分"）。

## 5. 正确性证明

**引理 1**：角色互换是对换，$k$ 次互换的复合只取决于 $k$ 的奇偶性，与触发顺序无关。

**证明**：把"主动方是谁"的状态空间记为 $\{P_1, P_2\}$，一次互换是映射 $\sigma(P_1) = P_2$、$\sigma(P_2) = P_1$，满足 $\sigma \circ \sigma = \mathrm{id}$（对合）。故 $k$ 次复合为 $\sigma^k$：$k$ 为奇时是 $\sigma$，$k$ 为偶时是 $\mathrm{id}$，与顺序无关。∎

**定理**：上述模拟返回的 `diff` 等于玩家①总分减玩家②总分。

**证明**：对 $i$ 归纳，维护不变量：**第 $i$ 场记分前，$s = +1$ 当且仅当玩家①为主动方**。

- **基础**：$i = 0$ 前，$s = +1$ 且玩家①初始为主动方，成立。
- **归纳步**：设第 $i$ 场记分前不变量成立。由题面，规则①②均在该场记分前生效，各至多触发一次互换；由引理 1，它们对角色的影响只由触发总次数的奇偶性决定，而模拟中 `s` 被独立地翻转同样的次数，故记分瞬间 $s$ 与真实主动方一致，`diff += s * nums[i]` 精确累加该场对分差的贡献（玩家①得分则 $+nums[i]$，玩家②得分则 $-nums[i]$）。第 $i+1$ 场记分前，角色的真实状态与 $s$ 仍同步，不变量保持。

遍历全部 $n$ 场后，`diff` 为各场贡献之和，即玩家①总分 − 玩家②总分。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$，单次遍历，每场 $O(1)$ 的判断与累加。
- **空间复杂度**：$O(1)$，仅 `s` 与 `diff` 两个变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int scoreDifference(vector<int>& nums) {
        int diff = 0;
        int s = 1;                            // +1：玩家①主动；−1：玩家②主动
        for (int i = 0; i < (int)nums.size(); i++) {
            if (nums[i] % 2 == 1) s = -s;     // 规则①：奇数分 → 互换
            if (i % 6 == 5) s = -s;           // 规则②：每 6 场 → 互换（可与①同时触发，相互抵消）
            diff += s * nums[i];              // 两条规则之后再记分
        }
        return diff;
    }
};
```

### Python

```python
class Solution:
    def scoreDifference(self, nums: List[int]) -> int:
        diff = 0
        s = 1  # +1：玩家①主动；−1：玩家②主动
        for i, x in enumerate(nums):
            if x % 2 == 1:   # 规则①：奇数分 → 互换
                s = -s
            if i % 6 == 5:   # 规则②：每 6 场 → 互换（可与①同时触发）
                s = -s
            diff += s * x    # 两条规则之后再记分
        return diff
```

## 8. 边界情况与易错点

1. **双翻转抵消（本题最大陷阱）**：索引 $i \equiv 5 \pmod 6$ 且 `nums[i]` 为奇数时，两条规则同时触发，净效果是**不互换**（示例 2 第 5 场）。写成 `if / else if` 互斥分支会直接出错。
2. **规则先于记分**：奇偶判断用的是**本场**的 `nums[i]`——"先换人、后得分"。若误用上一场的分数判奇偶，示例 1 就会算错。
3. **"第 6 场"是 0-indexed**：题面明说索引为 $5, 11, 17, \dots$，判定条件是 `i % 6 == 5`，不是 `i % 6 == 0`。
4. **答案可为负**：玩家②可能总分更高（示例 3 输出 $-1$），不要取绝对值。
5. **溢出**：$|diff| \le 1000 \times 1000 = 10^6$，`int` 足够。
6. **n < 6**：第 6 场规则从不触发，`i % 6 == 5` 自然不成立，无需特判；$n = 1$ 时仅规则①可能生效。
