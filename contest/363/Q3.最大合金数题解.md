# LeetCode 最大合金数 题解

## 1. 题目概述

- **标题 / 题号**：最大合金数（#2861，medium）
- **链接**：https://leetcode.cn/problems/maximum-number-of-alloys/
- **来源**：LeetCode 第 363 场周赛 Q3
- **难度**：中等
- **标签**：数组、二分查找、二分答案

**题意**：公司有 $n$ 种金属和 $k$ 台机器。用第 $i$ 台机器造一份合金需要 $\text{composition}[i][j]$ 份金属 $j$；起初每种金属 $j$ 有 $\text{stock}[j]$ 份库存，每补购一份金属 $j$ 花费 $\text{cost}[j]$ 元。在总花费不超过 $\text{budget}$ 的前提下，求能制造的合金最大数量。**所有合金必须由同一台机器制造**。

**约束**：

- `1 <= n, k <= 100`
- `0 <= budget <= 10^8`
- `composition.length == k`，`composition[i].length == n`，`1 <= composition[i][j] <= 100`
- `stock.length == cost.length == n`，`0 <= stock[i] <= 10^8`，`1 <= cost[i] <= 100`

> 💡 **读题关键**：「同一台机器」是本题的题眼——它把「在 $k$ 台机器间做组合决策」直接砍成「逐台独立求最大产量、再取 $\max$」。而「预算内最大化产量」是**二分答案**最典型的形状：答案值域巨大（最高 $2 \times 10^8$ 份），但「给定份数判可行性」只要 $O(n)$。另注意 $n$ 是**金属种数**、$k$ 是**机器台数**，`composition` 是 $k \times n$ 矩阵（行是机器、列是金属），与直觉相反。

## 2. 示例

**示例 1**（无库存，纯花钱）

```text
输入：n = 3, k = 2, budget = 15,
      composition = [[1,1,1],[1,1,10]], stock = [0,0,0], cost = [1,2,3]
输出：2
解释：机器 1 每份 1+2+3 = 6 元，⌊15/6⌋ = 2 份（造 3 份要 18 元超支）。
      机器 2 每份光金属 3 就要 10 份 × 3 元 = 30 元，一份都造不起。
```

**示例 2**（库存救了"贵"机器）

```text
输入：n = 3, k = 2, budget = 15,
      composition = [[1,1,1],[1,1,10]], stock = [0,0,100], cost = [1,2,3]
输出：5
解释：机器 2 造 5 份：金属 1、2 各买 5 份花 5 + 10 = 15 元；
      金属 3 需 10×5 = 50 份而库存有 100 份，一分钱不用花。
      恰好用满预算。（机器 1 同样能造 5 份，见 §3.4。）
```

**示例 3**（多台机器逐一比较）

```text
输入：n = 2, k = 3, budget = 10,
      composition = [[2,1],[1,2],[1,1]], stock = [1,1], cost = [5,5]
输出：2
解释：机器 3：第 1 份两种金属全被库存白送，第 2 份各买 1 份花 10 元 ⇒ M₃ = 2。
      机器 1、2：m = 2 时缺口 3 份 × 5 元 = 15 元已超支 ⇒ M = 1。
```

## 3. 解题思路

### 3.1 暴力思路

固定一台机器后，从 $m = 0, 1, 2, \dots$ 逐份往上试，每步 $O(n)$ 结算一次总花费、一旦超预算就停。单步不贵，但答案可达 $2 \times 10^8$ 份（库存与预算各贡献 $10^8$，见 §4 上界推导），总操作数 $k \times 2 \times 10^8 \times n \approx 2 \times 10^{12}$，必然超时。瓶颈在于"逐份 +1 地试探"——产量是个**数**，就该在数上**二分**。

### 3.2 核心观察：开销关于产量单调 → 二分答案

记 $c_{ij} = \text{composition}[i][j]$（机器 $i$ 对金属 $j$ 的单份用量）、$s_j = \text{stock}[j]$（库存）、$w_j = \text{cost}[j]$（单价）、$B = \text{budget}$。固定机器 $i$、造 $m$ 份的最低花费为

$$f_i(m) = \sum_{j=0}^{n-1} \max\bigl(0,\ c_{ij} \cdot m - s_j\bigr) \cdot w_j$$

![固定机器的开销模型](images/alloys_cost_model.svg)

其中 $\max(0, \cdot)$ 就是**库存抵扣**：先用免费的 $s_j$，缺口部分才按 $w_j$ 购买。两个关键事实：

1. **造得越多花得越多**：每个被加项都随 $m$ 单调不减，故 $f_i(m)$ 单调不减；
2. **能造 $m$ 份就能造更少**：可行性关于 $m$ 呈「假…假真…真」的前缀形状，分界点即该机器的最大产量 $M_i$。

于是「预算内最大产量」$=$ 在 $[0, 2 \times 10^8]$ 上**二分最后一个 $f_i(m) \le B$ 的 $m$**。逐台机器独立做一遍，答案取 $\max_i M_i$。

### 3.3 算法流程

![逐台机器二分答案的流程与单调性示意](images/alloys_binary_search_flow.svg)

```text
1. ans = 0
2. 枚举机器 i = 0 .. k-1：
   a. lo = 0, hi = 2*10^8
   b. 循环二分 mid = (lo + hi) / 2：
        计算 f_i(mid)
        若 f_i(mid) <= budget：lo = mid + 1
        否则：hi = mid - 1
   c. M_i = hi（最后一个可行 m），ans = max(ans, M_i)
3. 返回 ans
```

### 3.4 示例演算

![示例 2 的逐机演算](images/alloys_example_walkthrough.svg)

以示例 2 走一遍（$B = 15$，$\text{stock} = [0,0,100]$，$\text{cost} = [1,2,3]$）：在 $m \le 10$ 时，两台机器的单份边际成本都恰好是 $1 + 2 + 0 = 3$ 元——机器 2 配方里唬人的「10 份金属 3」被 100 份库存整段白送，直到 $m > 10$ 才会现出原形。因此 $f_1(m) = f_2(m) = 3m$，由 $3m \le 15$ 得 $M_1 = M_2 = 5$（$f(5) = 15$ ✓，$f(6) = 18$ ✗），`ans = 5`。

## 4. 算法细节

1. **「同一台机器」的化简**：产量不能跨机器累加，各机器完全独立，逐台求 $M_i$ 再取 $\max$ 天然正确（定理）。另一种等价写法是全局二分 $m$、判定函数改为「**存在**一台机器 $f_i(m) \le B$」，两种写法每次判定同阶，本篇采用前者以突出「机器独立」这一结构性观察。
2. **花费公式**：造 $m$ 份消耗 $c_{ij} \cdot m$ 份金属 $j$，库存抵扣后缺口为 $\max(0,\ c_{ij} \cdot m - s_j)$，**必须与 0 取 $\max$**——库存富余时缺口为负，直接乘单价相当于"倒贴钱"（示例 2 金属 3 的缺口是 $50 - 100 = -50$）。
3. **二分上界 $2 \times 10^8$ 的推导**：由 $c_{ij} \ge 1$、$w_j \ge 1$、$s_j \le 10^8$、$B \le 10^8$，对任意 $j$ 都有 $f_i(m) \ge \max(0, m - s_j) \ge m - 10^8$，故 $f_i(m) \le B \Rightarrow m \le 2 \times 10^8$。该界是紧的：$n = 1$、配方 1、库存 $10^8$、单价 1、预算 $10^8$ 时恰好白拿 + 购买共 $2 \times 10^8$ 份。想要更紧可用 `budget + min(stock)`（付费份数 $\le B$、白拿份数 $\le \min_j s_j$），量级不变。
4. **$m = 0$ 恒可行**：$f_i(0) = 0 \le B$（$B$ 允许为 0），「找最后一个可行」的二分结果至少落在 0，`hi` 不会为负。
5. **溢出**：$c_{ij} \cdot m$ 最高 $100 \times 2 \times 10^8 = 2 \times 10^{10}$，再乘单价、累加 $n \le 100$ 项后约 $2 \times 10^{14}$——C++ 必须全程 `long long`（超出 `int32` 三个数量级）。
6. **check 内早停（可选）**：累加中一旦超过 `budget` 即可 `break`，判定结果不变、纯省时间；Python 大整数无溢出之忧。

## 5. 正确性证明

**引理 1（单调性）**：对任意机器 $i$，$f_i(m)$ 关于 $m$ 单调不减。

**证明**：每个被加项 $g_j(m) = \max(0,\ c_{ij} m - s_j) \cdot w_j$ 中，$c_{ij} \ge 1 > 0$，$c_{ij} m - s_j$ 是 $m$ 的增函数；$\max(0, \cdot)$ 与乘正数 $w_j \ge 1$ 都保持单调不减，故 $g_j$ 单调不减；单调不减项之和仍单调不减 ∎

**引理 2（前缀结构）**：机器 $i$ 的可行产量集合 $F_i = \{\, m \ge 0 : f_i(m) \le B \,\}$ 是非负整数的前缀段 $[0, M_i]$，且 $M_i \le 2 \times 10^8$。

**证明**：$f_i(0) = 0 \le B$，故 $0 \in F_i$、$F_i$ 非空。若 $m \in F_i$ 且 $0 \le m' \le m$，由引理 1 有 $f_i(m') \le f_i(m) \le B$，故 $m' \in F_i$，即 $F_i$ 为前缀。上界：由 $\max(0, x) \ge x$ 及 $c_{ij}, w_j \ge 1$，对任意 $j$ 有 $f_i(m) \ge \max(0,\ c_{ij} m - s_j)\, w_j \ge \max(0,\ m - s_j) \ge m - 10^8$，故 $m \in F_i \Rightarrow m \le B + 10^8 \le 2 \times 10^8$ ∎

**定理**：算法返回值等于各机器最大产量之最大值，即题目所求的最大合金数。

**证明**：由题意，任一可行方案的所有合金出自同一台机器 $i$，其产量 $m$ 满足 $f_i(m) \le B$，即 $m \le M_i$；反之，对每台 $i$，由引理 2 有 $M_i \in F_i$，取 $m = M_i$ 即得预算内的合法方案。故全局最大产量 $= \max_i M_i$。又由引理 2，$M_i$ 落在二分区间 $[0, 2 \times 10^8]$ 内且 $F_i$ 是前缀，标准「找最后一个真值」的二分恰好收敛到 $M_i$ ∎

## 6. 复杂度分析

- **时间复杂度**：$O(k \cdot n \cdot \log U)$，其中 $U = 2 \times 10^8$（$\log U \approx 28$）。每台机器二分约 28 次、每次判定累加 $n \le 100$ 项，总计约 $100 \times 28 \times 100 = 2.8 \times 10^5$ 次基本运算，毫秒级。
- **空间复杂度**：$O(1)$ 额外空间，只复用输入数组与常数个累加器。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int maxNumberOfAlloys(int n, int k, int budget, vector<vector<int>>& composition,
                          vector<int>& stock, vector<int>& cost) {
        long long ans = 0;
        for (int i = 0; i < k; i++) {
            long long lo = 0, hi = 200'000'000LL;
            while (lo <= hi) {
                long long mid = lo + (hi - lo) / 2;
                if (need(i, mid, n, composition, stock, cost) <= budget) {
                    lo = mid + 1;
                } else {
                    hi = mid - 1;
                }
            }
            ans = max(ans, hi);
        }
        return (int)ans;
    }

  private:
    long long need(int i, long long m, int n, vector<vector<int>>& composition,
                   vector<int>& stock, vector<int>& cost) {
        long long total = 0;
        for (int j = 0; j < n; j++) {
            long long buy = max(0LL, (long long)composition[i][j] * m - stock[j]);
            total += buy * cost[j];
        }
        return total;
    }
};
```

### Python

```python
class Solution:
    def maxNumberOfAlloys(self, n: int, k: int, budget: int,
                          composition: List[List[int]], stock: List[int],
                          cost: List[int]) -> int:
        def max_output(comp: List[int]) -> int:
            def ok(m: int) -> bool:
                return sum(max(c * m - s, 0) * w
                           for c, s, w in zip(comp, stock, cost)) <= budget

            lo, hi = 0, 2 * 10**8
            while lo <= hi:
                mid = (lo + hi) // 2
                if ok(mid):
                    lo = mid + 1
                else:
                    hi = mid - 1
            return hi

        return max(max_output(comp) for comp in composition)
```

## 8. 边界情况与易错点

1. **缺口必须 $\max(0, \cdot)$**：库存富余时 $c_{ij} \cdot m - s_j < 0$，直接乘单价会"倒贴钱"压低开销，示例 2 的金属 3（需 50、有 100）当场教做人。
2. **C++ 全程 `long long`**：`composition[i][j] * m` 按 `int` 相乘在 $m > 2.1 \times 10^7$ 时就溢出了；`max(0LL, ...)` 的字面量必须是 `0LL`，否则 `int` 与 `long long` 混算仍先按 `int` 溢出。溢出的典型表现是 **WA 而非 RE**，极难肉眼排查。
3. **上界别拍脑袋**：只拿 `budget` 当上界会漏掉库存白送的部分；正确上界是 $B + \max s_j \le 2 \times 10^8$。界取得过大只是白跑几轮二分，取小了直接 WA。
4. **二分模板要自洽**：本篇用「找最后一个可行」的闭区间模板，答案落在循环后的 `hi`；若换成 `lo = mid` 变体则 `mid` 必须**上取整**防死循环，两种模板别混搭，差一错误是二分的第一大提交杀手。
5. **budget = 0 也有正数答案**：纯靠库存也能造（$f_i(m) = 0$ 的 $m$ 可以很大），别把 0 当哨兵提前返回。
6. **$n$ 与 $k$ 别弄反**：`composition` 是 $k \times n$（行是机器、列是金属），`stock`/`cost` 长度是 $n$。方阵样例下写反看不出来，务必用 $k \ne n$ 的用例对拍；Python 里 `zip` 长度不齐时会**静默截断**，更要小心。
7. **不要跨机器凑产量**：题目要求同一台机器，"选最优一台"是正确化简；"多台机器各造一点凑数"违反题意，也不存在需要如此才能更优的情形（各机器本就独立取 max）。
