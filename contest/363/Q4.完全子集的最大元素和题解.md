# LeetCode 完全子集的最大元素和 题解

## 1. 题目概述

- **标题 / 题号**：完全子集的最大元素和（#2862，hard）
- **链接**：https://leetcode.cn/problems/maximum-element-sum-of-a-complete-subset-of-indices/
- **来源**：LeetCode 第 363 场周赛 Q4
- **难度**：困难
- **标签**：数组、数学、数论

**题意**：给定下标从 $1$ 开始、长度为 $n$ 的数组 `nums`。从中选出一个下标集合 $S$，要求 $S$ 中**任意两个不同下标** $i, j$ 的乘积 $i \cdot j$ 都是完全平方数（这样的集合叫**完全子集**）。返回完全子集元素和的最大值。注意：条件绑定的是**下标**而非元素值；单个下标（乃至空集）天然合法。

**约束**：

- $1 \le n = \text{nums.length} \le 10^4$
- $1 \le \text{nums}[i] \le 10^9$（元素全为正，这一点决定了「最优解整桶全拿」，见 §3.2）

> 💡 **读题关键**：条件是定义在整个子集上的**两两配对条件**（任意对，不是相邻对），且作用对象是下标。$n = 10^4$ 直接排除枚举子集；突破口是把「两两条件」升维成「个体标签」——看穿相容性其实是**等价关系**，问题便从「$2^n$ 个子集里搜索」坍缩为「至多 $n$ 个等价类里挑最大」。

## 2. 示例

**示例 1**

```text
输入：nums = [8,7,3,5,7,2,4,9]
输出：16
解释：选下标 2 和 8，2 × 8 = 16 = 4² 是完全平方数，元素和 7 + 9 = 16。
      注意下标 1、4 也相容（1 × 4 = 4 = 2²），但 8 + 5 = 13 < 16。
```

**示例 2**

```text
输入：nums = [8,10,3,8,1,13,7,9,4]
输出：20
解释：选下标 1、4、9（1×4=4、1×9=9、4×9=36 都是完全平方数），
      元素和 8 + 8 + 4 = 20。
```

**示例 3**（自造，覆盖 $n = 1$ 边界）

```text
输入：nums = [5]
输出：5
解释：非空子集只能取 {1}，单个下标无条件合法。
```

## 3. 解题思路

### 3.1 暴力思路

枚举 `nums` 的所有 $2^n$ 个子集，对每个子集逐一检查所有 $\binom{|S|}{2}$ 对下标乘积是否为平方数。$n = 10^4$ 时子集数是天文数字，显然不可行。

退一步，把相容关系建图：$i, j$ 之间有边当且仅当 $i \cdot j$ 是完全平方数，则完全子集恰是图上的**团**，所求即**最大权团**。一般图最大团是 NP-hard，无从下手——除非我们看穿这张图的结构。

> ⚠️ **瓶颈的根源**：把相容性当成一条条独立的边来处理，每次扩集都要重新检查旧成员。若能发现相容性是**等价关系**（同组全体相容、异组必不相容），图就退化成若干个互不相连的团（并查集形状），搜索空间瞬间坍缩。

### 3.2 核心观察：无平方因子核

从平方数判定入手。设 $i = \prod_p p^{\alpha_p}$、$j = \prod_p p^{\beta_p}$，则

$$i \cdot j \text{ 是完全平方数} \iff \forall p:\ \alpha_p + \beta_p \equiv 0 \pmod 2 \iff \forall p:\ \alpha_p \equiv \beta_p \pmod 2$$

**两个下标相容 ⟺ 它们对每个质数的指数奇偶性完全相同**。把这套「奇偶性模板」编码成一个数：定义 $P(x)$ 为 $x$ 的质因数分解中**指数为奇数**的质数之积，称为 $x$ 的**无平方因子核**（squarefree part）。例如 $P(8) = P(2^3) = 2$，$P(12) = P(2^2 \cdot 3) = 3$，$P(45) = P(3^2 \cdot 5) = 5$。

![核心观察：下标唯一分解为「核 × 平方数」，同核相乘必为平方数](images/wc363_q4_squarefree_kernel.svg)

由中心引理（§5 引理 2）：$i \cdot j$ 是完全平方数 $\iff P(i) = P(j)$。相容性于是成为等价关系，下标被划分成若干「桶」；又因 `nums[i]` 全为正，把合法子集扩成整桶只会更大，所以：

**最优解 = 元素和最大的那个整桶。**

而核为 $k$（$k$ 无平方因子）的桶有整齐的形状：

$$\{\, i \le n : P(i) = k \,\} = \{\, k \cdot 1^2,\ k \cdot 2^2,\ k \cdot 3^2, \dots \,\} \cap [1, n]$$

![下标按核分桶：桶内两两相容，桶间互不相容](images/wc363_q4_group_classes.svg)

> 💡 **直观记忆**：把每个下标剥掉所有平方因子，剩下的「核」是它的身份证——身份证相同的人两两相乘才是平方数。例如 $8 = 2 \cdot 2^2$ 与 $2 = 2 \cdot 1^2$ 同核，故 $2 \times 8 = 16 = 4^2$；而 $2$ 与 $3$ 核不同，$2 \times 3 = 6$ 不是平方数。

### 3.3 算法流程：两种等价实现

**视角一（正向生成，推荐）**：枚举桶核 $k = 1 \dots n$，对每个 $k$ 从 $m = 1$ 起累加下标 $k \cdot m^2$（$\le n$）上的元素值，取桶和最大者。

```text
1. ans = 0
2. for k = 1 .. n:                # 枚举桶核 k（无需判断 k 是否无平方因子）
3.     sum = 0, m = 1
4.     while k·m² ≤ n:            # 桶内下标 k·m²
5.         sum += nums[k·m² − 1]
6.         m += 1
7.     ans = max(ans, sum)
8. return ans
```

**视角二（反向归类）**：对每个下标 $i$ 试除平方因子求出 $P(i)$，哈希表按核分组累加，取组和最大者。

两个视角正确性一致、复杂度不同（§6）。特别地，视角一的双层循环**是 $O(n)$ 而不是直觉的 $O(n\sqrt n)$**：按 $m$ 统计访问次数，总访问数 $\sum_{m \ge 1} \lfloor n/m^2 \rfloor \le \frac{\pi^2}{6} n \approx 1.64 n$——内层步数 $\lfloor\sqrt{n/k}\rfloor$ 随 $k$ 增大而递减。

## 4. 算法细节

1. **为什么枚举 $k$ 不必判断它无平方因子**：若 $k$ 含平方因子，则 $\{k \cdot m^2\} \subseteq \{P(k) \cdot m^2\}$（因 $k \cdot m^2 = P(k) \cdot (m')^2$ 对某个 $m'$ 成立），枚举出的只是「真桶」的子集，桶和不会超过真桶，$\max$ 结果不变——只是常数级别的重复访问。省掉判断，代码更短更快。
2. **$O(n)$ 的计数**：按 $m$ 而不是按 $k$ 数——固定 $m$，满足 $k \cdot m^2 \le n$ 的 $k$ 恰有 $\lfloor n/m^2 \rfloor$ 个，总访问数 $\sum_{m=1}^{\sqrt n} \lfloor n/m^2 \rfloor \le \frac{\pi^2}{6}\, n \approx 1.64 n$（$n = 10^4$ 时实测 16307 次访问，Python 4~5 ms）。
3. **视角二求核的写法**：令 $d$ 从 2 起枚举，只要 $d^2 \mid k$ 就不断 $k \mathrel{/}= d^2$，直到 $d^2 > k$，剩下的 $k$ 即核。$d$ 不必是质数——除掉**任何**平方因子都不改变核（$P(x \cdot s^2) = P(x)$），合数的 $d^2$ 要么不整除、要么被更小的质数平方提前消化，正确性无虞。
4. **下标偏移**：题目下标从 1 开始、数组从 0 开始，访问 `nums[k*m*m - 1]`。
5. **64 位求和**：桶和最大 $10^4 \times 10^9 = 10^{13}$，超出 32 位上限约 2148 倍，C++ 必须用 `long long`（本题接口返回类型本来就是 `long long`）。
6. **中间乘积**：循环条件里 $k \cdot m \cdot m$ 第一次越过 $n$ 时约为 $n + 2\sqrt n + 1 \approx 10^4$ 出头，`int` 尚装得下；但让 $m$ 走 64 位最稳妥，也与桶和类型对齐。

## 5. 正确性证明

**引理 1（核分解的唯一性）**：每个正整数 $x$ 都能唯一地写成 $x = P \cdot m^2$，其中 $P$ 无平方因子；且 $P = P(x)$（指数为奇数的质数之积），$m^2$ 是 $x$ 的最大平方因子。

**证明**：设 $x = \prod_p p^{\alpha_p}$，取 $P = \prod_{\alpha_p \text{ 为奇}} p$、$m = \prod_p p^{\lfloor \alpha_p / 2 \rfloor}$，则 $x = P \cdot m^2$ 且 $P$ 无平方因子（每个质数至多出现一次）。唯一性：「指数为奇数的质数集合」被 $x$ 唯一确定，故 $P$ 唯一，进而 $m^2 = x / P$ 唯一 ∎

**引理 2（相容判据）**：$i \cdot j$ 是完全平方数 $\iff P(i) = P(j)$。

**证明**：
（⇐）设 $P(i) = P(j) = k$，由引理 1 写 $i = k a^2$、$j = k b^2$，则 $i \cdot j = k^2 a^2 b^2 = (kab)^2$，是完全平方数。
（⇒）反证：若 $P(i) \ne P(j)$，两核均无平方因子，其乘积中必有质数 $p$ 恰属于其中一个核（不妨 $p \mid P(i)$、$p \nmid P(j)$）。于是 $p$ 在 $i$ 中指数为奇、在 $j$ 中指数为偶，在 $i \cdot j$ 中指数为**奇数**，$i \cdot j$ 不是完全平方数，矛盾 ∎

**引理 3（桶的结构）**：对无平方因子的 $k$，$\{\, i \le n : P(i) = k \,\} = \{\, k \cdot m^2 \le n : m \ge 1 \,\}$。

**证明**：
（⊇）$m^2$ 的所有质数指数均为偶，不改变奇偶性模板，而 $k$ 无平方因子、各指数均为 1（奇），故 $P(k \cdot m^2) = k$。
（⊆）若 $P(i) = k$，由引理 1 写 $i = k \cdot m^2$ ∎

**引理 4（合法子集的形态）**：下标集合 $S$（$|S| \ge 2$）是完全子集 $\iff$ 存在核 $k$ 使 $S$ 含于核 $k$ 的桶中；单元素集合总是合法的。

**证明**：（⇒）任取 $i_0 \in S$，对任意 $j \in S \setminus \{i_0\}$，$i_0 \cdot j$ 是平方数，由引理 2 得 $P(j) = P(i_0)$，故 $S$ 整体同核，含于该核的桶。（⇐）同桶任意两点由引理 2 两两相容 ∎

**定理**：算法返回值 $\max_{1 \le k \le n} \sum_{k \cdot m^2 \le n} \text{nums}[k \cdot m^2 - 1]$ 等于完全子集元素和的最大值。

**证明**：
（≤）对每个 $k$，集合 $\{k \cdot m^2 \le n\}$ 中任意两点 $k a^2, k b^2$ 的乘积为 $(kab)^2$，是完全子集，故其和不超过最优值 $OPT$，从而 $\max \le OPT$。
（≥）设 $S^*$ 为最优完全子集。因 $nums[i] \ge 1 > 0$，把 $S^*$ 扩成其所在核 $t$ 的完整桶，元素和不减（引理 4 保证同桶内任意扩充仍合法），故可设 $S^*$ 就是核 $t$ 的完整桶，其中 $t$ 无平方因子且 $t \le n$。由引理 3，$S^* = \{t \cdot m^2 \le n\}$，恰为算法 $k = t$ 时的候选，故 $OPT \le \max$。两边结合即得相等 ∎

## 6. 复杂度分析

- **时间复杂度（视角一）**：$O(n)$。双层循环的总访问次数 $\sum_{m \ge 1} \lfloor n/m^2 \rfloor \le \zeta(2)\, n = \frac{\pi^2}{6} n \approx 1.64 n$；若按 $k$ 数内层步数 $\lfloor\sqrt{n/k}\rfloor$，同样得到 $\sum_k \sqrt{n/k} \approx 2n$ 的估计。$n = 10^4$ 时约 1.6 万次访问，毫秒级。
- **时间复杂度（视角二）**：$O(n\sqrt n)$，每个下标试除到 $\sqrt i$；$n = 10^4$ 时约 $10^6$ 次整除，Python 实测约 40 ms，同样能过。
- **空间复杂度**：视角一 $O(1)$ 额外空间（只有 `ans`、`sum` 等常数个变量）；视角二 $O(n)$（哈希表最多存 $n$ 个桶）。

## 7. 参考代码

### C++（视角一：枚举 $k \cdot m^2$，$O(n)$）

```cpp
class Solution {
public:
    long long maximumSum(vector<int>& nums) {
        int n = nums.size();
        long long ans = 0;
        for (int k = 1; k <= n; k++) {                    // 枚举桶核 k
            long long sum = 0;
            for (long long m = 1; k * m * m <= n; m++) {  // 桶内下标 k*m^2
                sum += nums[k * m * m - 1];
            }
            ans = max(ans, sum);
        }
        return ans;
    }
};
```

### Python（视角一：同款枚举）

```python
class Solution:
    def maximumSum(self, nums: List[int]) -> int:
        n = len(nums)
        ans = 0
        for k in range(1, n + 1):
            s, m = 0, 1
            while k * m * m <= n:
                s += nums[k * m * m - 1]
                m += 1
            ans = max(ans, s)
        return ans
```

### Python（视角二：求核 + 哈希分桶）

```python
from collections import defaultdict

class Solution:
    def maximumSum(self, nums: List[int]) -> int:
        n = len(nums)
        groups = defaultdict(int)          # 核 P(i) -> 桶内元素和
        for i in range(1, n + 1):
            k, d = i, 2
            while d * d <= k:             # 不断剥掉平方因子 d^2
                while k % (d * d) == 0:
                    k //= d * d
                d += 1
            groups[k] += nums[i - 1]       # 剩下的 k 就是核
        return max(groups.values())
```

## 8. 边界情况与易错点

1. **条件绑定的是下标不是元素值**：判的是 $i \cdot j$ 是否为平方数，与 $nums[i] \cdot nums[j]$ 无关。看错对象，方向全错。
2. **下标从 1 开始**：访问 `nums[k*m*m - 1]`，漏写 `-1` 是高频 WA 点；视角二的循环变量同样从 1 走到 $n$。
3. **溢出**：桶和最高 $10^4 \times 10^9 = 10^{13}$，C++ 累加器必须 `long long`；溢出的典型症状是 WA 而非 RE，肉眼难查。
4. **`ans` 初值取 0 安全**：$n \ge 1$ 时候选 $k = n$（单下标 $n$）桶和 $\ge 1$，答案必为正，不必用极小值初始化。
5. **单元素子集合法**：条件只约束「每对」不同下标，$n = 1$ 直接返回 `nums[0]`；枚举法天然覆盖（$k = n$ 时 $m$ 只能取 1）。
6. **别建图跑最大团**：一般图最大团 NP-hard；本题相容性是等价关系、图结构极其特殊，分桶统计即可。
7. **视角二的求核循环易写错**：内层 `while k % (d*d) == 0` 必须是**循环**——同一个 $d^2$ 可能连除多次（如 $16$ 对 $d=2$ 除两轮）；外层条件写 `d * d <= k`（$k$ 动态缩小、提前收尾），误写成 `d * d <= i` 仍正确但白跑。
8. **视角二的 `max` 安全性**：$n \ge 1$ 时 `groups` 非空，`max(groups.values())` 不会抛异常。
