# LeetCode 让所有学生保持开心的分组方法数 题解

## 1. 题目概述

- **标题 / 题号**：让所有学生保持开心的分组方法数（#2860，medium）
- **链接**：https://leetcode.cn/problems/happy-students/
- **来源**：LeetCode 第 363 场周赛 Q2
- **难度**：中等
- **标签**：数组、排序、枚举

**题意**：给一个长度为 $n$ 的数组 `nums`，`nums[i]` 是学生 $i$ 的"门槛值"。班主任要选出一组学生，设选中人数为 $k$。学生 $i$ 开心当且仅当满足以下之一：

- 被选中，且 $k > \text{nums}[i]$（选他的人足够多）；
- 未被选中，且 $k < \text{nums}[i]$（选他的人足够少）。

问有多少种分组方法能让**所有**学生开心。

**约束**：

- `1 <= nums.length <= 10^5`
- `0 <= nums[i] < nums.length`

> 💡 **读题关键**：答案问的是"分组方法的数目"。乍看像要枚举 $2^n$ 个子集，实则由于固定人数 $k$ 后每个学生的去留被唯一确定（见 §3.2），分组方法数就等于**可行的人数 $k$ 的个数**，取值只有 $n+1$ 种。

## 2. 示例

**示例 1**

```text
输入：nums = [1,1]
输出：2
解释：两种可行方法：
      ① 一个都不选（k=0）：两人都未选中且 0 < 1，开心；
      ② 全选（k=2）：两人都被选中且 2 > 1，开心。
      只选一人（k=1）：被选者要求 1 > 1 不成立，落选者要求 1 < 1 不成立，全不开心。
```

**示例 2**

```text
输入：nums = [6,0,3,3,6,7,2,7]
输出：3
解释：三种可行方法：
      ① k=1：只选 nums[i]=0 的那位（1 > 0 ✓，其余 1 < nums[i] ✓）；
      ② k=4：选 nums[i] ∈ {0,2,3,3} 的四位（4 > 3 ✓，其余 4 < 6/7 ✓）；
      ③ k=8：全选（8 > 7 ✓）。
```

**示例 3（单元素）**

```text
输入：nums = [0]
输出：1
解释：k=0 时该生未选中但 0 < 0 不成立，不可行；
      k=1 时被选中且 1 > 0 成立，可行。答案为 1。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的想法是枚举全部 $2^n$ 个子集、对每个子集逐一验证 $n$ 个学生，$n \le 10^5$ 时完全不现实。

退一步：只枚举人数 $k \in [0, n]$，再花 $O(n)$ 数一遍有多少学生 $\text{nums}[i] < k$、有没有 $\text{nums}[i] = k$，总复杂度 $O(n^2) = 10^{10}$，同样超时。瓶颈在于"验证一个 $k$"是 $O(n)$ 的——需要把它压到 $O(1)$。

### 3.2 核心观察：固定人数 k 后，分组方案唯一

![固定 k 时三类学生的去留](images/happy_students_threshold_concept.svg)

给定选中人数 $k$，逐个学生分析：

- **$\text{nums}[i] < k$ 的学生必须被选中**：若他不选，开心需要 $k < \text{nums}[i]$，与 $\text{nums}[i] < k$ 矛盾；
- **$\text{nums}[i] > k$ 的学生必须不被选中**：若他入选，开心需要 $k > \text{nums}[i]$，矛盾；
- **$\text{nums}[i] = k$ 的学生怎么选都不开心**：选中需要 $k > k$，不选需要 $k < k$，均不成立——$k$ 直接出局。

因此固定 $k$ 时**至多一个候选分组**：恰好选走全部 $\text{nums}[i] < k$ 的学生。它成立当且仅当

$$\#\{\,i : \text{nums}[i] < k\,\} = k \quad\text{且}\quad \#\{\,i : \text{nums}[i] = k\,\} = 0$$

又因为不同 $k$ 对应的分组人数不同、方案必然不同，所以

> 💡 **答案 = 可行 $k$ 的个数**，$k$ 只需枚举 $0 \sim n$ 共 $n+1$ 个值。

### 3.3 算法流程：排序把计数变成下标判断

将 `nums` 升序排序后，"$\text{nums}[i] < k$ 的学生个数"可以用相邻两个元素直接读出：

- $\#\{\text{nums}[i] < k\} \ge k \iff k = 0$ 或 $\text{nums}[k-1] < k$（第 $k$ 小的元素已小于 $k$）；
- $\#\{\text{nums}[i] \le k\} \le k$（即个数 $\le k$ 且无元素等于 $k$）$\iff k = n$ 或 $\text{nums}[k] > k$。

两个条件同时成立即 $k$ 可行，单次判定 $O(1)$。

![排序枚举 k 的判定流程](images/happy_students_flow.svg)

```text
1. nums 升序排序
2. ans = 0
3. 枚举 k = 0 .. n：
   若 (k == 0 或 nums[k-1] < k) 且 (k == n 或 nums[k] > k)：
       ans += 1
4. 返回 ans
```

### 3.4 示例演算

![示例 2 的逐 k 判定表](images/happy_students_walkthrough.svg)

以示例 2 走一遍：排序后 `nums = [0,2,3,3,6,6,7,7]`，$n = 8$。$k = 1, 4, 8$ 通过两道判定（绿色行），其余 $k$ 要么前缀不够 $k$ 个（$\text{nums}[k-1] \ge k$），要么撞上 $\text{nums}[k] \le k$（含"值恰好等于 $k$"的死结）。最终 `ans = 3`，与期望一致。

## 4. 算法细节

1. **排序的目的**：把"统计有多少个元素小于 $k$"从 $O(n)$ 的遍历变成 $O(1)$ 的下标比较——`nums[k-1]` 与 `nums[k]` 一刀切出三段。
2. **两个条件的统一写法**：`(k == 0 || nums[k-1] < k) && (k == n || nums[k] > k)`。$k = 0$ 时前半自动成立（没有元素 $< 0$），$k = n$ 时后半自动成立（没有元素 $\ge n$），省去特判分支。
3. **$k = n$ 恒可行**：由约束 $0 \le \text{nums}[i] < n$，全体学生被选中后每人满足 $n > \text{nums}[i]$，所以"全选"永远是一种方案——这解释了示例 1、2、3 的输出里都包含全选。
4. **$O(n)$ 桶计数优化**：值域恰为 $[0, n)$，可开桶 `cnt[v]` 统计每个值的出现次数，再滚动维护 $\#\{\text{nums}[i] < k\}$，免去排序，整体 $O(n)$。
   ```python
   cnt = [0] * (n + 1)
   for x in nums:
       cnt[x] += 1
   ans, less = 0, 0          # less = #{nums[i] < k}
   for k in range(n + 1):
       if less == k and (k == n or cnt[k] == 0):
           ans += 1
       less += cnt[k]         # 滚动为 #{nums[i] < k+1}
   ```

## 5. 正确性证明

**引理 1**：固定 $k$，若存在使所有学生开心的分组，则该分组必为 $S_k = \{\, i : \text{nums}[i] < k \,\}$；且 $S_k$ 可行 $\iff |S_k| = k$ 且不存在 $i$ 使 $\text{nums}[i] = k$。

**证明**：设某分组 $T$（$|T| = k$）使所有学生开心。对 $\text{nums}[i] < k$ 的学生 $i$：若 $i \notin T$，其开心需 $k < \text{nums}[i]$，与 $\text{nums}[i] < k$ 矛盾，故 $i \in T$，得 $S_k \subseteq T$；对 $\text{nums}[i] > k$ 的学生同理必有 $i \notin T$。于是 $T$ 恰由所有 $\text{nums}[i] < k$ 与部分 $\text{nums}[i] = k$ 的学生构成。若存在 $\text{nums}[i] = k$：$i \in T$ 需 $k > k$、$i \notin T$ 需 $k < k$，均不成立，故此时无解。若不存在 $\text{nums}[i] = k$，则 $T = S_k$，且 $|T| = |S_k| = k$。反之，当 $|S_k| = k$ 且无元素等于 $k$ 时，$S_k$ 中每人的开心条件 $k > \text{nums}[i]$ 成立，$S_k$ 之外每人的条件 $k < \text{nums}[i]$ 成立，$S_k$ 可行 ∎

**引理 2**：`nums` 升序排序后，对任意 $k \in [0, n]$：
(1) $\#\{\text{nums}[i] < k\} \ge k \iff k = 0$ 或 $\text{nums}[k-1] < k$；
(2) $\#\{\text{nums}[i] < k\} \le k$ 且 $\#\{\text{nums}[i] = k\} = 0 \iff k = n$ 或 $\text{nums}[k] > k$。

**证明**：(1) 当 $k = 0$ 时左边显然成立。当 $k \ge 1$：排序后 $\#\{\text{nums}[i] < k\} \ge k$ 等价于第 $k$ 小的元素（下标 $k-1$，若存在）小于 $k$，即 $\text{nums}[k-1] < k$（排序保证前 $k$ 个元素均 $\le \text{nums}[k-1] < k$）。(2) 注意 $\#\{\text{nums}[i] \le k\} = \#\{\text{nums}[i] < k\} + \#\{\text{nums}[i] = k\}$，故左边条件等价于 $\#\{\text{nums}[i] \le k\} \le k$。当 $k = n$ 时由 $\text{nums}[i] < n$ 恒成立，两边皆真；当 $k < n$ 时 $\#\{\text{nums}[i] \le k\} \le k$ 等价于第 $k+1$ 小的元素（下标 $k$）大于 $k$，即 $\text{nums}[k] > k$ ∎

**定理**：算法返回的 `ans` 等于使所有学生开心的分组方法数。

**证明**：任何分组的规模 $k \in [0, n]$，由引理 1，每个可行分组唯一对应一个可行 $k$（即分组本身为 $S_k$），不同的 $k$ 对应不同分组，故分组方法数 $= \#\{\,k \in [0,n] : k \text{ 可行}\,\}$。由引理 1、引理 2，$k$ 可行 $\iff$ `(k == 0 || nums[k-1] < k) && (k == n || nums[k] > k)`，算法对每个 $k$ 恰判定一次，无重无漏 ∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \log n)$——排序占主导；枚举 $n+1$ 个 $k$、每个 $O(1)$ 判定为 $O(n)$。换桶计数可降到 $O(n)$。
- **空间复杂度**：$O(1)$（原地排序，不计递归栈）；桶计数版为 $O(n)$。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int countWays(vector<int>& nums) {
        sort(nums.begin(), nums.end());
        int n = nums.size(), ans = 0;
        for (int k = 0; k <= n; k++) {
            if ((k == 0 || nums[k - 1] < k) && (k == n || nums[k] > k)) {
                ans++;
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def countWays(self, nums: List[int]) -> int:
        nums.sort()
        n = len(nums)
        return sum(
            (k == 0 or nums[k - 1] < k) and (k == n or nums[k] > k)
            for k in range(n + 1)
        )
```

## 8. 边界情况与易错点

1. **"分组方法数 = 可行 k 的个数"**：固定 $k$ 的可行分组唯一（引理 1），若没想通这一点，容易误以为要枚举子集或对固定 $k$ 做组合计数。
2. **值恰好等于 k 是死结**：判定必须写 $\text{nums}[k] > k$ 而非 $\ge k$，漏掉等号会把"有人 $\text{nums}[i] = k$"的错误 $k$ 计入。
3. **k = 0 与 k = n 的边界**：`k == 0` 时不能访问 `nums[-1]`、`k == n` 时不能访问 `nums[n]`，条件式中的短路顺序正好保护了这两个下标，交换操作数顺序会越界。
4. **下标别颠倒**：前缀条件用 `nums[k-1]`（第 $k$ 小），后缀条件用 `nums[k]`（第 $k+1$ 小），写反则两个条件都在查同一个位置。
5. **严格不等号**：开心条件是"严格大于/小于"，与 H 指数等题的 $\ge$ 类判定不同。
6. **全选恒可行**：$k = n$ 因 $0 \le \text{nums}[i] < n$ 恒成立，可用于对拍时快速 sanity check。
7. **桶计数版数组开到 n+1**：循环里访问 `cnt[k]` 且 $k$ 取到 $n$，桶只开 `n` 会越界（或对 `k == n` 提前短路）。
8. **不修改原数组的需求**：`sort` 会改动输入；若要求保持原序，先复制一份（本题接口无此要求）。
