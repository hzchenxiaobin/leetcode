# LeetCode 寻找最近的回文数 题解

## 1. 题目概述

- **标题 / 题号**：寻找最近的回文数（#564，hard）
- **链接**：https://leetcode.cn/problems/find-the-closest-palindrome/
- **来源**：LeetCode 第 29 场周赛 Q4
- **难度**：困难
- **标签**：数学，字符串

**题意**：给定一个十进制整数的字符串形式 `n`，在**所有回文整数中**（不含 `n` 自身）找与 `n` 的绝对差最小的那个，返回它的字符串形式；若最小值对应两个回文（一个在 `n` 左侧、一个在右侧），返回**较小的**那个。

**约束**：

- $1 \le \lvert n \rvert \le 18$
- `n` 只含数字、无前导零，即 $1 \le n \le 10^{18}-1$
- 答案可能比 `n` 多一位（如 $n = 10^{18}-1$ 的答案是 $10^{18}+1$），实现时注意用 64 位整数

## 2. 示例

**示例 1**

```text
输入：n = "123"
输出："121"
解释：候选回文有 121（差 2）、131（差 8）、111（差 12）、99（差 24），最小差为 2。
```

**示例 2**

```text
输入：n = "1"
输出："0"
解释：0 与 2 都是差 1 的回文，按「并列取小」返回 0。
```

## 3. 解题思路

### 3.1 暴力思路

最自然的写法是从 `n` 出发向两侧逐个数试探：`n-1, n+1, n-2, n+2, ...`，第一次遇到回文就停。

复杂度 $O(\Delta \cdot L)$，其中 $\Delta$ 是答案与 `n` 的间距。**$\Delta$ 可以极大**：长度为 $L$ 的回文由前 $\lceil L/2 \rceil$ 位决定，相邻「前缀块」的回文间距是 $10^{L-h}$，所以 $\Delta$ 最坏约为 $\tfrac{1}{2}\cdot 10^{\lfloor L/2 \rfloor}$；$L=18$ 时达到 $5\times 10^{8}$ 量级，逐位检查要做 $10^{10}$ 次字符比较，必然超时。

另一种暴力是「枚举全部回文」，数量同样是 $10^{9}$ 量级。必须换思路：**不回文地搜索，而是构造回文**。

### 3.2 核心观察：同长度回文只由前半段决定

![同长度回文由前半段决定](images/wc29_q4_prefix_determines.svg)

长度固定为 $L$ 的回文，前 $h = \lceil L/2 \rceil$ 位一旦写出，后半段就是前半段的镜像，没有任何自由度。记 $p$ 的 $h$ 位十进制串为 $s = s_1s_2\cdots s_h$，定义镜像映射

$$m(p) = \begin{cases} s\,\mathrm{rev}(s), & L \equiv 0 \pmod 2 \\ s\,\mathrm{rev}(s_1s_2\cdots s_{h-1}), & L \equiv 1 \pmod 2 \end{cases}$$

即偶数长度时镜像整个 $s$，奇数长度时镜像 $s$ 去掉末位后的前缀（中间那位只出现一次）；两种情形下 $m(p)$ 都恰好是 $L$ 位回文。把 `n` 的前 $h$ 位记作整数 $p$，则所有长度 $L$ 的回文恰好排成一条**严格递增**的序列

$$m(10^{h-1}) < m(10^{h-1}+1) < \cdots < m(10^{h}-1)$$

**关键推论**：注意 $n$ 落在区间 $[\,p\cdot 10^{L-h},\ (p+1)\cdot 10^{L-h}-1\,]$ 内（$L-h=\lfloor L/2\rfloor$ 是镜像段的位数），而

$$m(p-1) \le p\cdot 10^{L-h} - 1 < n < (p+1)\cdot 10^{L-h} \le m(p+1)$$

（$p$ 为 $h$ 位全 9 时，不存在前缀更大的同长度回文，链式不等式的右段由长一位哨兵接管。）也就是说：**前缀小于 $p$ 的同长度回文全部 $< n$，前缀大于 $p$ 的全部 $> n$**。于是

- 比 `n` 大的**最小**同长度回文，只能是 $m(p)$ 或 $m(p+1)$（取两者中 $> n$ 的较小者，$m(p+1)$ 必定 $> n$）；
- 比 `n` 小的**最大**同长度回文，只能是 $m(p)$ 或 $m(p-1)$（取两者中 $< n$ 的较大者，$m(p-1)$ 必定 $< n$）。

也就是说：**同长度回文里，最近的那个必在 $m(p-1), m(p), m(p+1)$ 三个值之中**，与 $n$ 有多少位、答案离得多远都无关。$p-1$ 或 $p+1$ 不足 / 超过 $h$ 位时没有对应的 $L$ 位回文，正好由下一节的两个哨兵接手。

### 3.3 算法流程 / 候选集合

![候选生成、过滤与选择流程](images/wc29_q4_candidate_flow.svg)

还要补上「长度不同」的两类回文，它们各自只需一个代表：

- **更短的回文**：任何少于 $L$ 位的回文都 $\le 10^{L-1}-1$（即 $L-1$ 个 9；$L=1$ 时它就是 0），而这个数本身就是回文，是这一类里离 `n` 最近的；
- **更长的回文**：任何多于 $L$ 位的回文都 $\ge 10^{L}+1$（形如 $1\underbrace{0\cdots 0}_{L-1}1$），而它本身是回文，是这一类里离 `n` 最近的。

于是候选集固定为 **5 个**：

1. $m(p-1)$
2. $m(p)$
3. $m(p+1)$
4. $10^{L}+1$（长一位哨兵）
5. $10^{L-1}-1$（短一位哨兵）

流程：生成 5 个候选 → 过滤（镜像构造时 `p±1` 的位数不再是 $h$ 则作废；候选等于 `n` 自身则剔除）→ 按键 $\bigl(\lvert x-n\rvert,\; x\bigr)$ 取最小 → 转字符串返回。

> 💡 为什么 `p±1` 位数会变？$p$ 是 $h$ 位的。$p = 10^{h-1}$ 时 $p-1$ 只剩 $h-1$ 位（退位）；$p = 10^{h}-1$ 时 $p+1$ 变成 $h+1$ 位（进位）。这两种退化情形正好被上面两个哨兵覆盖，所以**直接跳过**即可，不需要额外处理。

## 4. 算法细节

1. **参数量化**：$L = \lvert n \rvert$，$h = \lfloor (L+1)/2 \rfloor$，$p$ 取 `n` 的前 $h$ 位所表示的整数。全程只用整数与 `to_string`，不建逐位数组。
2. **镜像构造**：把 $p+\delta$ 转成字符串 $s$（长度为 $h$）。$L$ 偶数时取 $s+\mathrm{rev}(s)$；$L$ 奇数时取 $s+\mathrm{rev}(s_1\cdots s_{h-1})$，即倒序「$s$ 去掉末位」的前缀，结果恰好 $L$ 位。
3. **位数校验**：先判断 $\lvert s \rvert = h$，不等就 `continue`。这一步同时挡掉了 $p+\delta \le 0$ 的非法值（其十进制串长度必然 $< h$，唯一例外 $L=1$ 时 `"0"` 恰好合法，正好是 $n=1$ 的答案）。
4. **两个哨兵必须无条件加入**：$10^{L}+1$ 与 $10^{L-1}-1$。前者处理 $n = \underbrace{99\cdots9}_{L}$，后者处理 $n = 10^{L-1}$ 及其附近，这两处是三候选覆盖不到的死角。
5. **剔除自身**：$n$ 本身可能就是回文（如 `12321`），此时 $m(p)=n$，必须从候选集删除，否则会返回 `n`。
6. **并列取小的比较键**：把候选表示成对 $(\lvert x-n\rvert, x)$，按字典序取最小。这比「先找最小差、再扫一遍取小」少一次遍历，也不会漏掉并列。
7. **数值范围**：$n \le 10^{18}-1$，候选最大 $10^{18}+1 < 2^{63}-1$，C++ 用 `long long` + `stoll`/`to_string` 即可；若用 `int` 会在第 10 位就溢出。
8. **候选去重**：用 `set<long long>` / Python `set` 存候选，避免 $m(p-1)$ 与哨兵取到同一个值时重复比较；去重后最多 5 个元素。

## 5. 正确性证明

**引理 1（镜像映射是双射且严格单调）**：$h$ 位整数 $p \in [10^{h-1}, 10^{h}-1]$ 与长度 $L$ 的回文一一对应，且 $p < q \iff m(p) < m(q)$。

**证明**：长度 $L$ 的回文由前 $h$ 位唯一确定，故对应关系是双射。$m(p)$ 与 $m(q)$ 的前 $h$ 位分别就是 $p$、$q$；$p \ne q$ 时二者前 $h$ 位不同，大小关系由前 $h$ 位唯一决定，因此 $p<q \iff m(p)<m(q)$。∎

**引理 2（前缀邻域夹住 $n$）**：设 $p$ 是 $n$ 的前 $h$ 位，则 $m(p-1) < n < m(p+1)$；其中 $p-1$ 不足 $h$ 位时把 $m(p-1)$ 理解为更短的回文（仍 $< n$），$p+1$ 超过 $h$ 位时把 $m(p+1)$ 理解为更长的回文（仍 $> n$）。

**证明**：$n \in [\,p\cdot 10^{L-h},\ (p+1)\cdot 10^{L-h}-1\,]$。若 $p-1$ 仍是 $h$ 位，则 $m(p-1)$ 的前 $h$ 位是 $p-1$、后缀至多 $10^{L-h}-1$，故 $m(p-1) \le (p-1)\cdot 10^{L-h} + 10^{L-h}-1 = p\cdot 10^{L-h}-1 < n$；若 $p-1$ 只有 $h-1$ 位，更短的回文只会更小。若 $p+1$ 仍是 $h$ 位，则 $m(p+1) \ge (p+1)\cdot 10^{L-h} > n$；若 $p+1 = 10^{h}$（即 $p$ 是 $h$ 位全 9），此时 $n \le 10^{L}-1 < 10^{L}+1$，把 $m(p+1)$ 理解为长一位哨兵仍得 $> n$。∎

**引理 3（同长度最近者落在三个镜像值中）**：长度 $L$ 的回文中，大于 $n$ 的最小者属于 $\{m(p), m(p+1)\}$，小于 $n$ 的最大者属于 $\{m(p), m(p-1)\}$。

**证明**：任取长度 $L$ 的回文 $P = m(q)$，其前缀为 $q$。由引理 2，$q \le p-1$ 时 $P \le m(p-1) < n$，$q \ge p+1$ 时 $P \ge m(p+1) > n$。因此大于 $n$ 的同长度回文只能来自前缀 $p$ 或 $p+1$：前缀 $p$ 的只有 $m(p)$ 一个，前缀 $p+1$ 中最小的正是 $m(p+1)$；小于 $n$ 的情形对称（前缀 $p$ 或 $p-1$，后者中最大的是 $m(p-1)$）。∎

**引理 4（跨长度最优解是两个哨兵）**：少于 $L$ 位的回文中离 $n$ 最近的是 $10^{L-1}-1$；多于 $L$ 位的回文中离 $n$ 最近的是 $10^{L}+1$。

**证明**：少于 $L$ 位的回文 $x$ 满足 $x \le 10^{L-1}-1$，且 $10^{L-1}-1$ 本身是回文。由 $n \ge 10^{L-1}$ 得 $\lvert n-x\rvert = n-x \ge n-(10^{L-1}-1)$，等号在 $x = 10^{L-1}-1$ 处取得。多于 $L$ 位时对称：$x \ge 10^{L}+1$ 且 $n \le 10^{L}-1$，$\lvert x-n\rvert = x-n \ge 10^{L}+1-n$，等号在 $x = 10^{L}+1$ 处取得。∎

**定理**：算法返回的 $x^{*} = \arg\min_{x \in C}\bigl(\lvert x-n\rvert,\, x\bigr)$（字典序比较）就是题目所求。

**证明**：全体回文按位数分成「少于 $L$ 位、恰好 $L$ 位、多于 $L$ 位」三类，互不相交且穷尽。引理 4 给出第一、三类的最优者（$10^{L-1}-1$ 与 $10^{L}+1$，均在 $C$ 中），引理 3 给出第二类的最优者（在 $C$ 中）。故全局最优必属于 $C$，在 $C$ 上取最小值不会错过答案。比较键 $(\lvert x-n\rvert, x)$ 先比绝对差、差相同再比数值，恰好实现「差最小、并列取小」，与题面要求一致。∎

## 6. 复杂度分析

- **时间**：$O(L)$。候选只有 5 个；每个候选的镜像构造、字符串与整数互转、比较都是 $O(L)$，与 $n$ 的数值大小无关，18 位数也只有几十次字符操作。
- **空间**：$O(L)$。存放 5 个候选的 `set`（Python `set`）与常数个长度 $O(L)$ 的字符串。

## 7. 参考代码

### C++

```cpp
#include <string>
#include <set>
#include <cstdlib>
using namespace std;

class Solution {
public:
    string nearestPalindromic(string n) {
        int L = (int)n.size();
        int h = (L + 1) / 2;
        long long v = stoll(n);

        long long pow10 = 1;                     // 10^L
        for (int i = 0; i < L; i++) pow10 *= 10;

        set<long long> cand;
        cand.insert(pow10 + 1);                  // 长一位的最小回文 100..001
        cand.insert(pow10 / 10 - 1);             // 短一位的最大回文 99..9

        long long prefix = stoll(n.substr(0, h));
        for (long long d = -1; d <= 1; d++) {
            long long p = prefix + d;
            string s = to_string(p);
            if ((int)s.size() != h) continue;    // 进位/退位的情况交给哨兵
            string pal = s;
            if (L % 2 == 0) pal += string(s.rbegin(), s.rend());
            else            pal += string(s.rbegin() + 1, s.rend());
            cand.insert(stoll(pal));
        }
        cand.erase(v);                           // 排除自身

        long long best = -1;
        for (long long x : cand) {
            if (best < 0) { best = x; continue; }
            long long dx = llabs(x - v), db = llabs(best - v);
            if (dx < db || (dx == db && x < best)) best = x;   // 并列取小
        }
        return to_string(best);
    }
};
```

### Python

```python
class Solution:
    def nearestPalindromic(self, n: str) -> str:
        L = len(n)
        h = (L + 1) // 2
        v = int(n)
        prefix = int(n[:h])

        # 两个哨兵：更长一位的最小回文 10^L + 1，更短一位的最大回文 10^(L-1) - 1
        cand = {10 ** L + 1, 10 ** (L - 1) - 1}

        # 同长度回文只由前 h 位决定：只需尝试 prefix-1 / prefix / prefix+1
        for d in (-1, 0, 1):
            p = prefix + d
            s = str(p)
            if len(s) != h:          # 进位/退位已由哨兵覆盖
                continue
            pal = s + (s[::-1] if L % 2 == 0 else s[-2::-1])
            cand.add(int(pal))

        cand.discard(v)              # 答案不能是自身
        return str(min(cand, key=lambda x: (abs(x - v), x)))
```

> 两版实现都用「生成 5 个候选 → 丢弃自身 → 按 $(\lvert x-n\rvert, x)$ 取最小」，与第 3.3 节流程逐句对应；`s[-2::-1]` 就是「$s$ 去掉末位后倒序」，即奇数长度的镜像补位。

## 8. 边界情况与易错点

1. **`n` 自身就是回文**：`"12321"` 的原样镜像等于自身，必须 `discard`/`erase`，否则直接返回了非法答案；此时应改由 `prefix-1` 或 `prefix+1` 的镜像胜出。
2. **个位数**：`"1"` 的答案是 `"0"`（与 `"2"` 并列取小）。$L=1$ 时 $10^{L-1}-1 = 0$ 这个哨兵天然给出 `0`，但要注意 $p-1=0$ 时 `"0"` 的长度恰好等于 $h=1$，会额外加入一次（去重后无副作用）。
3. **全是 9**：`"999"` 的 `prefix+1=100` 变成 3 位，镜像作废；答案是 $10^{3}+1 = 1001$（差 2）。漏掉长一位哨兵就会错答成 989。
4. **10 的幂**：`"1000"` 的 `prefix-1=9` 退位，镜像作废；答案由短一位哨兵 $999$（差 1）给出。注意此时 `m(10)=1001` 差也是 1，**必须按并列取小返回 999**。
5. **并列取小的实现**：只比较差值、不比较数值，`"1000"` 会错答 `"1001"`，`"1"` 会错答 `"2"`。用键 $(\lvert x-n\rvert, x)$ 或「相等时取 `min`」都能避免。
6. **溢出**：C++ 里 `10^18 + 1` 超出 `int`，必须 `long long`；`pow10` 用 `long long` 累乘，否则 10 位之后溢出成负数。Python 无此问题。
7. **整数与字符串边界**：`stoll` 最多吃 19 位、`to_string` 不会加前导零；镜像时用 `len(s) == h` 判定，而不是比较原字符串前缀，才能正确处理退位/进位。
8. **哨兵也要参与去重和剔除**：$L=1$ 时哨兵 $0$ 与 $m(p-1)=0$ 重复；`"11"` 时哨兵 $9$ 与 $m(p)$ 之外的候选也可能撞值，用 `set` 去重最省心。
