# LeetCode 数组拆分 题解

## 1. 题目概述

- **标题 / 题号**：数组拆分（#561，easy）
- **链接**：https://leetcode.cn/problems/array-partition/
- **来源**：LeetCode 第 29 场周赛 Q2
- **难度**：简单
- **标签**：贪心、数组、计数排序、排序

**题意**：给定长度为 $2n$ 的整数数组 `nums`，把它分成 $n$ 个数对 $(a_i, b_i)$，使得 $\sum_{i=1}^{n}\min(a_i,b_i)$ 最大，返回这个**最大总和**。每个元素必须恰好使用一次，分对方式可任意选择。

**约束**：

- $1 \le n \le 10^4$，即数组长度 $2 \le 2n \le 2\times10^4$
- $-10^4 \le \texttt{nums[i]} \le 10^4$（**允许负数**，这一点决定了实现细节）

## 2. 示例

**示例 1**

```text
输入：nums = [1,4,3,2]
输出：4
解释：所有分法（忽略对顺序）：
      (1,4),(2,3) → 1 + 2 = 3
      (1,3),(2,4) → 1 + 2 = 3
      (1,2),(3,4) → 1 + 3 = 4  ← 最大
```

**示例 2**

```text
输入：nums = [6,2,6,5,1,2]
输出：9
解释：排序后为 [1,2,2,5,6,6]，相邻配对 (1,2),(2,5),(6,6)
      min 之和 = 1 + 2 + 6 = 9
```

**示例 3（负数，题面未给但必须能过）**

```text
输入：nums = [-4,-1,0,3]
输出：-4
解释：最优 ( -4,-1 ),( 0,3 ) → -4 + 0 = -4；
      其余分法 (-4,0),(-1,3) → -5，(-4,3),(-1,0) → -5，故为 -4。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有「完全匹配」：第一个元素有 $2n-1$ 种选择，第二个剩下 $2n-3$ 种……总方案数 $(2n-1)!!$，$n=10$ 时已达 $6.5\times10^8$。即使改成状压 DP，状态数是 $O(2^{2n})$ 的，$2n=2\times10^4$ 完全不可行。必须利用结构。

关键直觉来自题目的一个「牺牲」视角：**每一对里，只有较小者能进入答案，较大者等于被白白牺牲**。所以我们要让「被牺牲的元素」尽量小——而排序恰好把最小的元素排到最前面。

### 3.2 核心观察：排序后相邻配对

![排序后相邻配对更优](images/wc29_q2_sorted_pair_greedy.svg)

设升序排序后数组为

$$a_0 \le a_1 \le a_2 \le \cdots \le a_{2n-1}$$

**结论**：最优分法就是相邻配对 $(a_0,a_1),(a_2,a_3),\dots,(a_{2n-2},a_{2n-1})$，答案为

$$\text{answer} = a_0 + a_2 + a_4 + \cdots + a_{2n-2} = \sum_{i=0}^{n-1} a_{2i}$$

即**排序后取所有偶数下标元素之和**。

为什么相邻配对最优？用交换论证看全局最小的元素 $a_0$：无论它和谁配，$\min$ 都等于 $a_0$ 本身（它最小），所以 $a_0$ 的贡献是固定的。既然如此，就让它**只牺牲掉一个尽可能小的伙伴**，即 $a_1$——这样 $a_2$ 就被「释放」出来，可以自己去当某一对的较小者、为答案贡献自己。把 $a_0,a_1$ 拿掉后剩下 $2n-2$ 个元素，问题同构，归纳即得结论。

反过来看，任何「交叉」配对都会浪费资源：若 $a_0$ 配了 $a_j$（$j\ge2$），而 $a_1$ 只能去配某个 $a_k$（$k>j$），则这两对的贡献是 $a_0 + a_1$；改成 $(a_0,a_1)$ 与 $(a_j,a_k)$ 后贡献变成 $a_0 + a_j \ge a_0 + a_1$，**不会变差**（用到了 $a_j \ge a_1$）。这一步可以反复执行，直到没有任何交叉。

### 3.3 算法流程

![排序与隔位累加的算法流程](images/wc29_q2_algorithm_flow.svg)

流程极短，没有任何循环内决策：

1. 对 `nums` **升序**排序；
2. 以步长 $2$ 遍历下标 $0,2,4,\dots,2n-2$，把 `nums[i]` 累加；
3. 返回累加结果。

等价写法：`sum(nums[::2])`。排序是唯一非线性的开销，所以总复杂度 $O(n\log n)$。

### 3.4 示例演算

![示例 nums=[1,4,3,2] 的三种分法演算](images/wc29_q2_example_walkthrough.svg)

以 `nums = [1,4,3,2]`（$n=2$）为例，排序后为 $[1,2,3,4]$：

| 分法 | 每对取得的较小者 | 总和 |
|------|------------------|------|
| $(1,4),(2,3)$ | $1+2$ | $3$ |
| $(1,3),(2,4)$ | $1+2$ | $3$ |
| $(1,2),(3,4)$ | $1+3$ | $4$ ← 最优 |

最优值是偶数下标之和 $a_0+a_2=1+3=4$，与枚举结果一致。

再看 `nums = [6,2,6,5,1,2]`：升序为 $[1,2,2,5,6,6]$，偶数下标元素是 $1,2,6$，答案 $1+2+6=9$。注意重复值 $2,6$ 不影响结论——它们只是让某一对的两个数相等，$\min$ 仍取该值。

## 4. 算法细节

1. **升序排序，取偶数下标**：偶数下标（0-based）的 $n$ 个元素恰好是「相邻配对中每对的较小者」，而奇数下标元素是被牺牲的较大者。
2. **步长为 2 的循环**：C++ 写 `for (size_t i = 0; i < nums.size(); i += 2)`；Python 写 `sum(nums[::2])`，切片只读一次，$O(n)$。
3. **不要写成降序 + 取奇数位**：虽然数学上等价，但降序时「较小者」落在下标 $1,3,5,\dots$，极易写错一位，直接升序 + 偶数下标最不容易出错。
4. **溢出**：$n\le10^4$、$|nums[i]|\le10^4$，最大和 $10^8$，`int` 足够；但累加变量建议仍用 `long long` 再转换返回，避免以后改数据范围时踩坑。
5. **负数**：排序与取 $\min$ 的推导对**任意可比较的全序**成立，负数无需特殊处理；但不要用「先把答案置 0 再取 max」的写法，全负时会错。
6. **原地排序会修改输入**：LeetCode 判题不要求保留原数组，直接 `sort` 即可；若业务需要保留，先拷贝一份。
7. **计数排序优化（可选）**：值域只有 $[−10^4,10^4]$，开 $V=20001$ 个桶。按值从小到大展开成有序序列，展开时计数位置 `idx`，当 `idx` 为偶数时把这个值加入答案。时间 $O(n+V)$，空间 $O(V)$。

## 5. 正确性证明

**引理 1（相邻配对的得分）**：升序数组上做相邻配对 $(a_{2i},a_{2i+1})$，其得分恰为 $\sum_{i=0}^{n-1}a_{2i}$。

**证明**：由 $a_{2i}\le a_{2i+1}$ 得 $\min(a_{2i},a_{2i+1})=a_{2i}$，逐对求和即得结论。∎

**引理 2（任意分法的上界）**：对任意一种分成 $n$ 对的方案，其得分 $S\le\sum_{i=0}^{n-1}a_{2i}$。

**证明**：把该方案 $n$ 个较小者按升序记为 $m_1\le m_2\le\cdots\le m_n$，显然 $S=\sum_{i=1}^{n}m_i$。下面证明对每个 $i\in[1,n]$ 都有

$$m_i \le a_{2i-2}\qquad(\text{下标从 }0\text{ 起})$$

反设 $m_i>a_{2i-2}$。那么元素 $a_0,a_1,\dots,a_{2i-2}$ 共 $2i-1$ 个，全部严格小于 $m_i$。任取其中满足上述不等式的一个元素 $x$，设它所在的一对的较小者为 $m'$：

- 若 $x$ 是这对的较小者，则 $m'=x<m_i$；
- 若 $x$ 是这对的较大者，则 $m'\le x<m_i$。

两种情况都有 $m'<m_i$，即该对必属于「较小者为 $m_1,\dots,m_{i-1}$ 之一」的那 $i-1$ 对；而这 $i-1$ 对总共只能容纳 $2(i-1)=2i-2$ 个元素，却要容纳 $2i-1$ 个互不相同的元素，矛盾。故断言成立。

逐项相加得

$$S=\sum_{i=1}^{n}m_i \le \sum_{i=1}^{n}a_{2i-2} = \sum_{i=0}^{n-1}a_{2i}. \qquad\blacksquare$$

**定理**：题目的最大总和等于 $\sum_{i=0}^{n-1}a_{2i}$，即「升序排序后偶数下标之和」。

**证明**：引理 1 说明该值可以被某个具体分法达到（可达性），引理 2 说明没有分法能超过它（最优性），两者夹逼即得结论。∎

## 6. 复杂度分析

- **时间**：$O(n\log n)$。排序 $2n$ 个整数需 $O(n\log n)$（C++ `std::sort` 为内省排序，Python `sort` 为 Timsort），之后隔位累加 $O(n)$，故总时间由排序决定。
- **空间**：$O(\log n)$ 额外空间（排序递归栈，实现相关）；若使用计数排序则为 $O(V)$，$V=20001$ 为值域大小，与 $n$ 无关。不计返回值，没有其他额外数组。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int arrayPairSum(vector<int>& nums) {
        sort(nums.begin(), nums.end());          // 升序排序
        long long ans = 0;
        for (size_t i = 0; i < nums.size(); i += 2) {
            ans += nums[i];                      // 偶数下标即每对的较小者
        }
        return (int)ans;
    }
};
```

### Python

```python
from typing import List

class Solution:
    def arrayPairSum(self, nums: List[int]) -> int:
        nums.sort()                 # 原地升序排序
        return sum(nums[::2])       # 偶数下标即每对的较小者
```

## 8. 边界情况与易错点

1. **$n=1$（数组只有 2 个元素）**：答案就是两者较小值，排序后取 `nums[0]`；此时结果可能为负，例如 `[-3,5]` 返回 `-3`。
2. **全负数组**：不能把答案初始化为 `0` 再取 max，也不要对 `min` 的结果取绝对值，直接累加即可，例如 `[-4,-1,0,3]` 返回 `-4`。
3. **全部元素相同**：答案 $n\cdot v$，排序不改变任何东西；此时任意分法都是最优，验证算法与直觉一致性。
4. **下标奇偶搞反**：升序后偶数下标才是较小者，若误取奇数下标，会得到「较大者之和」，结果偏大且必然 WA（如 `[1,2,3,4]` 会输出 $2+4=6$ 而非 $4$）。
5. **用「最大配最小」的直觉**：这是本题最常见的错误思路。`[1,2,3,4]` 按 $(1,4),(2,3)$ 配对只得 $1+2=3$，比最优值 $4$ 更小；本题应「相邻配对」而非「首尾配对」。
6. **重复元素**：重复值不破坏证明（引理中的不等式取等号即可），无需去重。
7. **大输入性能**：$2n=2\times10^4$ 时 $O(n\log n)$ 毫无压力；若面试官追问「值域很小怎么再快一点」，答计数排序 $O(n+V)$。

**延伸思考**：本题是「分组取最小值之和」家族中最简单的一档。

- 若改为**最大化** $\sum\max(a_i,b_i)$：答为最大的 $n$ 个元素之和 $a_n+\cdots+a_{2n-1}$，因为较大者才是有效贡献。
- 若改为**最小化** $\sum\min(a_i,b_i)$：答为最小的 $n$ 个元素之和 $a_0+\cdots+a_{n-1}$（$n$ 个较小者互不相同，其和不可能小于最小 $n$ 个之和），由首尾配对达到。
- 推广到「每 $k$ 个一组、每组只取最小值」：排序后答案同样是固定下标集合 $\sum_{i}a_{ik}$，证明结构与本文引理 2 完全一致——只是把「$2i-1$ 个元素塞进 $2i-2$ 个位置」换成「$ki-1$ 个元素塞进 $k(i-1)$ 个位置」。
