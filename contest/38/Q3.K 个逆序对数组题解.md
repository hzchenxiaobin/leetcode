# LeetCode K 个逆序对数组 题解

## 1. 题目概述

- **标题 / 题号**：K 个逆序对数组（#629，hard）
- **链接**：https://leetcode.cn/problems/k-inverse-pairs-array/
- **来源**：LeetCode 第 38 场周赛 Q3
- **难度**：困难
- **标签**：动态规划、前缀和、滑动窗口

**题意**：给定 $n$ 与 $k$，统计由 $1$ 到 $n$ 的**全部数字**组成、且**恰好**有 $k$ 个逆序对的排列个数。逆序对指下标对 $(i,j)$ 满足 $i<j$ 且 $a_i>a_j$。答案对 $10^9+7$ 取模。注意统计的是**排列的个数**，而不是构造某一个排列。

**约束**：

- $1 \le n \le 1000$
- $0 \le k \le 1000$
- 答案对 $10^9+7$ 取模

**关键量级**：长度 $n$ 的排列最多有 $M=\frac{n(n-1)}{2}$ 个逆序对（$n=1000$ 时 $M=499500$），而本题的 $k$ 只有 $1000$，也就是只关心「逆序对很少」的那些排列。

## 2. 示例

**示例 1**

```text
输入：n = 3, k = 0
输出：1
解释：只有 [1,2,3] 恰好有 0 个逆序对。
```

**示例 2**

```text
输入：n = 3, k = 1
输出：2
解释：[1,3,2] 与 [2,1,3] 各有 1 个逆序对。
```

**补充示例**（官方题面只给两组，这里补一组供第 3.4 节演算）

```text
输入：n = 4, k = 2
输出：5
解释：n = 4 的 24 个排列中，逆序对数分布为
      1、3、5、6、5、3、1（k = 0..6），故 k = 2 时答案为 5。
```

## 3. 解题思路

### 3.1 暴力思路

**第一层暴力**：枚举 $1..n$ 的全部 $n!$ 个排列，逐个统计逆序对。$n=10$ 就要 $3.6\times10^6$ 次枚举，$n=1000$ 时 $n!$ 是天文数字，**完全不可行**。

**第二层暴力（朴素 DP）**：设 $dp[i][j]$ 为 $1..i$ 的排列中恰有 $j$ 个逆序对的个数，转移时枚举「新插入的数贡献了 $p$ 个逆序对」：

$$dp[i][j]=\sum_{p=0}^{\min(i-1,\,j)} dp[i-1][j-p]$$

这个递推**本身是对的**，但每个状态要累加 $O(i)$ 项，总复杂度 $O(n^2k)$。$n=k=1000$ 时约 $\sum_{i}i\cdot k\approx 5\times10^{8}$ 次加法，C++ 勉强、Python 必超时。

> ⚠️ 真正的瓶颈不是「状态设计」，而是「求和」这一步。只要把区间和压成 $O(1)$，问题立刻变成 $10^6$ 级别。

### 3.2 核心观察：插入最大数，位置与新增逆序对一一对应

![插入最大数 i：插入位置决定新增逆序对数](images/wc38_q3_insert_window.svg)

构造 $1..i$ 的排列最自然的办法，是拿一个 $1..i-1$ 的排列，把**当前最大的数 $i$** 插进去。由于 $i$ 比所有已有元素都大：

- $i$ 与它**前面**的元素不构成逆序对（前面元素都更小，且下标更靠前）；
- $i$ 与它**后面**的每个元素都构成一个逆序对（后面元素都更小）。

所以「新增几个逆序对」只取决于「插入后 $i$ 后面还剩几个元素」。插入位置共 $i$ 个（$i$ 后面可以是 $0,1,\dots,i-1$ 个元素），恰好对应新增 $p=0,1,\dots,i-1$ 个逆序对，**每个 $p$ 恰好一种插法**。

于是得到状态定义与转移：

- $dp[i][j]$ = $1..i$ 的排列中恰有 $j$ 个逆序对的个数；
- $dp[i][j]=\sum_{p=0}^{\min(i-1,\,j)} dp[i-1][j-p]$，其中 $dp[1][0]=1$、$dp[1][j>0]=0$。

> 💡 这一步把「枚举排列」换成了「枚举插入位置」，而插入位置与新增逆序对数是**一一对应**的——这正是能计数而不重不漏的原因。

### 3.3 算法流程：区间和 → 滑动窗口

![滑动窗口：窗口右移一格，加入右端、弹出左端](images/wc38_q3_sliding_window.svg)

转移式右边的求和，是上一行 $dp[i-1]$ 上一段**长度不超过 $i$ 的连续区间** $[j-i+1,\,j]$（下界截断到 $0$）。既然相邻的 $j$ 只让窗口移动一格，就用**滑动窗口**增量维护：

$$dp[i][j]=dp[i][j-1]+dp[i-1][j]-\begin{cases}dp[i-1][j-i], & j\ge i\\ 0, & j<i\end{cases}$$

三项的含义分别是：继承上一格的窗口和、把新的右端点 $dp[i-1][j]$ 加进来、把滑出窗口的旧左端点 $dp[i-1][j-i]$ 弹出去。当 $j<i$ 时窗口还没占满 $i$ 格，左端没有元素可弹，因此不减。

**流程**（滚动数组，只保留上一行）：

1. 初始化 $dp[0]=1$，表示 $i=1$ 时唯一排列 $[1]$ 有 $0$ 个逆序对；
2. 外层 $i$ 从 $2$ 到 $n$：新建当前行 $cur$，置 $cur[0]=1$（升序排列恒有 $0$ 个逆序对）；
3. 内层 $j$ 从 $1$ 到 $k$：执行上面的增量式，随后 `if (j >= i) cur[j] -= dp[j-i]`；
4. 每一轮结束 $dp \leftarrow cur$，最后返回 $dp[k]$。

> 💡 这样做出的 $dp$ 行恰好是 Mahonian 数的一行，行和等于 $i!$，可用于自检。

### 3.4 示例演算

![n = 4 的 dp 表：蓝色为三个加数，橙色为 dp[4][2]](images/wc38_q3_walkthrough_table.svg)

逐行递推（$j$ 只列到 $6$，因为 $n=4$ 时逆序对最多 $6$ 个）：

| $i$ | $j=0$ | 1 | 2 | 3 | 4 | 5 | 6 | 行和 |
|-----|-------|---|---|---|---|---|---|------|
| 1 | 1 | 0 | 0 | 0 | 0 | 0 | 0 | 1 |
| 2 | 1 | 1 | 0 | 0 | 0 | 0 | 0 | 2 |
| 3 | 1 | 2 | 2 | 1 | 0 | 0 | 0 | 6 |
| 4 | 1 | 3 | **5** | 6 | 5 | 3 | 1 | 24 |

**逐格走查 $i=4$**（上一行为 $dp[3]=[1,2,2,1,0,0,0]$）：

- $j=0$：$cur[0]=1$。
- $j=1$：$j<i=4$，不弹 → $cur[1]=cur[0]+dp[1]=1+2=3$。
- $j=2$：不弹 → $cur[2]=cur[1]+dp[2]=3+2=5$，即 $dp[3][0..2]=1+2+2=5$ ✓。
- $j=3$：不弹 → $cur[3]=cur[2]+dp[3]=5+1=6$。
- $j=4$：$j\ge i$，弹掉 $dp[0]$ → $cur[4]=cur[3]+dp[4]-dp[0]=6+0-1=5$。
- $j=5$：$j\ge i$，弹掉 $dp[1]=2$ → $cur[5]=cur[4]+dp[5]-dp[1]=5+0-2=3$。
- $j=6$：弹掉 $dp[2]=2$ → $cur[6]=cur[5]+dp[6]-dp[2]=3+0-2=1$。

**回代官方示例**：$n=3$ 时该行为 $[1,2,2,1]$，故 $k=0$ 得 $1$、$k=1$ 得 $2$，与示例 1、示例 2 一致；$n=4$ 时 $k=2$ 得 $5$，与补充示例一致。行和 $1,2,6,24$ 恰为 $1!,2!,3!,4!$，说明没有漏计或重复计数。

## 4. 算法细节

1. **状态与边界**：$dp[i][0]=1$ 对一切 $i$ 成立（只有升序排列），代码里直接给 $cur[0]$ 赋值，避免走 $j-1=-1$ 的越界写法。
2. **上界剪枝**：若 $k>\frac{n(n-1)}{2}$ 直接返回 $0$；同时内层只需要算到 $k$（而不是 $M$），因为更大的 $j$ 不在答案里。
3. **窗口左端点**：弹出项是 $dp[i-1][j-i]$，条件为 $j\ge i$（等价于原求和区间下界 $j-i+1\ge1$）。$j=i$ 时弹出的是 $dp[i-1][0]$，这个「等号方向」最容易写反。
4. **滚动数组**：$dp[i][\cdot]$ 只依赖 $dp[i-1][\cdot]$，用两个长度 $k+1$ 的数组交替即可，空间 $O(k)$；C++ 每轮必须 `fill` 清零，否则残留的旧行会污染当前行。
5. **取模**：C++ 中减法可能为负，需 `v %= MOD; if (v < 0) v += MOD;`；Python 的 `%` 天然返回非负，写 `(a - b) % MOD` 即可。
6. **增量式 ⇔ 前缀和**：若把 $dp[i]$ 行看成前缀和数组 $S$，则 $dp[i][j]=S[j]-S[j-i]$（$j<i$ 时 $S$ 的下标截断为 $0$）。两种写法等价，增量式常数更小。
7. **自检手段**：行和 $=i!$、对称性 $dp[n][k]=dp[n][M-k]$（把排列反序即得），$n=k=1000$ 的答案是 `663677020`，可当断言。

## 5. 正确性证明

**引理 1（插入是双射）**：对任意 $i\ge2$，映射 $\varphi:(\pi,t)\mapsto\sigma$（$\pi\in S_{i-1}$，$t\in\{0,1,\dots,i-1\}$ 表示把 $i$ 插到第 $t$ 个元素之前、即前面留 $t$ 个元素）是 $S_{i-1}\times\{0,\dots,i-1\}$ 到 $S_i$ 的双射。

**证明**：单射——从 $\sigma$ 中删去 $i$ 得到 $\pi$，$i$ 原来的下标即 $t$，故 $\sigma$ 唯一确定 $(\pi,t)$。满射——任给 $\sigma\in S_i$，删去 $i$ 得到 $\pi\in S_{i-1}$，记 $i$ 在 $\sigma$ 中的下标为 $t$，则 $\varphi(\pi,t)=\sigma$。∎

**引理 2（新增逆序对恰为 $i$ 后面的元素个数）**：在 $\pi$ 的第 $t$ 个位置前插入 $i$ 后，新增的逆序对数恰为 $i-1-t$。

**证明**：$i$ 大于 $\pi$ 中所有元素。$i$ 与它前面的 $t$ 个元素组成的数对，前者下标更小、值更小，不是逆序对；$i$ 与它后面的 $i-1-t$ 个元素组成的数对，前者值更大，全部是逆序对；$\pi$ 内部元素之间的相对顺序未变，逆序对数不变。∎

**引理 3（递推式成立）**：对 $i\ge2$、$j\ge0$ 有 $dp[i][j]=\sum_{p=0}^{\min(i-1,j)}dp[i-1][j-p]$。

**证明**：由引理 1，$S_i$ 的每个排列与唯一的 $(\pi,t)$ 对应，且由引理 2 其逆序对数为 $\mathrm{inv}(\pi)+(i-1-t)$。令 $p=i-1-t$，则 $t$ 遍历 $0..i-1$ 等价于 $p$ 遍历 $0..i-1$。于是按 $p$ 分组计数：恰有 $j$ 个逆序对的排列数等于 $\sum_p \#\{\pi:\mathrm{inv}(\pi)=j-p\}=\sum_p dp[i-1][j-p]$；$j-p<0$ 时贡献为 $0$，故上界截断到 $\min(i-1,j)$。∎

**引理 4（增量式与求和式等价）**：记 $W(i,j)=\sum_{p=0}^{\min(i-1,j)}dp[i-1][j-p]$，则
$$W(i,j)-W(i,j-1)=dp[i-1][j]-[\,j\ge i\,]\cdot dp[i-1][j-i].$$

**证明**：$W(i,j)$ 的求和区间是 $[j-i+1,\,j]$（下界截到 $0$），$W(i,j-1)$ 的区间是 $[j-i,\,j-1]$。两者相差「加入右端 $j$」与「弹出左端 $j-i$」两项；当 $j<i$ 时 $W(i,j-1)$ 的下界也截到 $0$，没有元素被弹出，即被减项为 $0$。∎

**定理**：算法结束时返回的 $dp[k]$ 等于「长度为 $n$ 且恰有 $k$ 个逆序对的排列数」模 $10^9+7$。

**证明**：对 $i$ 归纳证明第 $i$ 轮结束后 $dp[\cdot]$ 恰为 $S_i$ 中按逆序对数分布的计数。$i=1$ 时 $dp[0]=1$、其余为 $0$，与 $[1]$ 只有 $0$ 个逆序对相符。设第 $i-1$ 行正确，则引理 3 说明 $S_i$ 的计数可由第 $i-1$ 行精确算出，引理 4 说明代码用增量式算出的值与引理 3 的求和完全相同，故第 $i$ 行正确。归纳至 $i=n$ 得 $dp[n][k]$ 为所求计数。取模只作用在加减法上，同余关系在环运算下保持，故返回值为真值模 $10^9+7$。∎

**推论（行和校验）**：$\sum_{j\ge0}dp[i][j]=i!$。

**证明**：引理 1 的双射说明 $S_i$ 的排列与 $(\pi,t)$ 一一对应，共 $(i-1)!\cdot i=i!$ 个，而每个排列被且仅被统计一次。∎

## 6. 复杂度分析

- **时间**：$O\!\left(n\cdot\min\left(k,\frac{n(n-1)}{2}\right)\right)$。外层 $n-1$ 轮、内层 $k$ 格，每格 $O(1)$（两次加法/减法 + 取模）。$n=k=1000$ 时约 $10^6$ 次运算，实测 Python 0.13 s、C++ 0.007 s。
- **空间**：$O(k)$。只保留上一行与当前行两个长度 $k+1$ 的数组（二维写法为 $O(nk)$，本题不必要）。
- **对比**：朴素转移 $O(n^2k)\approx5\times10^8$，是本解法的 500 倍；枚举排列 $O(n!\cdot n^2)$ 完全不可行。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int kInversePairs(int n, int k) {
        const int MOD = 1000000007;
        if ((long long)k > 1LL * n * (n - 1) / 2) return 0;   // 逆序对总数上界
        vector<int> dp(k + 1, 0), cur(k + 1, 0);
        dp[0] = 1;                                           // i = 1：[1] 恰有 0 个逆序对
        for (int i = 2; i <= n; ++i) {
            fill(cur.begin(), cur.end(), 0);                 // 复用前必须清零
            cur[0] = 1;                                      // 升序排列恒有 0 个逆序对
            for (int j = 1; j <= k; ++j) {
                long long v = (long long)cur[j - 1] + dp[j]; // 窗口右移：加入右端
                if (j >= i) v -= dp[j - i];                  // 窗口已满：弹出左端
                v %= MOD;
                if (v < 0) v += MOD;                         // 负数修正
                cur[j] = (int)v;
            }
            dp.swap(cur);                                    // 滚动数组
        }
        return dp[k];
    }
};
```

### Python

```python
class Solution:
    def kInversePairs(self, n: int, k: int) -> int:
        MOD = 10**9 + 7
        if k > n * (n - 1) // 2:          # 逆序对总数上界
            return 0
        dp = [0] * (k + 1)                # 上一行 dp[i-1]
        dp[0] = 1                         # i = 1：[1]
        for i in range(2, n + 1):
            cur = [0] * (k + 1)
            cur[0] = 1                    # 升序排列恒有 0 个逆序对
            for j in range(1, k + 1):
                cur[j] = (cur[j - 1] + dp[j]) % MOD      # 加入右端
                if j >= i:
                    cur[j] = (cur[j] - dp[j - i]) % MOD  # 弹出左端
            dp = cur                      # 滚动数组
        return dp[k]
```

## 8. 边界情况与易错点

1. **$n=1$**：$k=0$ 返回 $1$（只有 $[1]$），$k>0$ 返回 $0$（上界 $M=0$，提前返回分支生效）。循环从 $i=2$ 开始，天然跳过。
2. **$k=0$**：任何 $n\ge1$ 都返回 $1$（唯一升序排列）。但若把 $cur[0]$ 也写成递推式，会访问 $cur[-1]$ 或 $dp[-1]$，Python 中 `dp[-1]` 会**静默取到最后一个元素**造成错答，务必直接赋值。
3. **$j<i$ 不能减**：此时 `j - i < 0`，C++ 越界、Python 负索引会读到错误位置；条件必须是 `j >= i` 而不是 `j > i`。
4. **减法的负数取模**：C++ 的 `%` 对负数返回负值，必须 `+ MOD` 修正；Python 无需处理。这是计数 DP 最常见的 WA 来源。
5. **$k$ 超上界**：$k>\frac{n(n-1)}{2}$ 时答案必为 $0$。不提前返回也能通过（表中全 $0$），但白白多算一轮；提前返回还顺带规避了 $n=1,k>0$ 的边界。
6. **滚动数组复用**：C++ 中 `cur` 若不清零，上一轮残留的旧值会被当成 $cur[j-1]$ 参与累加，结果虚高；`dp.swap(cur)` 后 `cur` 里是旧的 $dp$，下一轮必须先 `fill`。
7. **性能余量**：$n=k=1000$ 结果 `663677020`；若你改写成显式前缀和，注意前缀和也要每轮重算，不能跨轮复用。
