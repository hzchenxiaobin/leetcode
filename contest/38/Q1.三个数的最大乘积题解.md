# LeetCode 三个数的最大乘积 题解

## 1. 题目概述

- **标题 / 题号**：三个数的最大乘积（#628，easy）
- **链接**：https://leetcode.cn/problems/maximum-product-of-three-numbers/
- **来源**：LeetCode 第 38 场周赛 Q1
- **难度**：简单
- **标签**：数组、数学、排序

**题意**：给定整数数组 `nums`，从中选出**下标互不相同**的三个数，使它们的乘积最大，返回这个最大乘积。数组可能含负数与 $0$，返回值的符号不作保证，因此答案可能是负数（当 $n=3$ 且三数乘积为负时）。

**约束**：

- $3 \le \text{nums.length} \le 10^4$ → 枚举三元组是 $O(n^3)\approx 1.7\times10^{11}$，不可行；排序或 $O(n)$ 扫描都绰绰有余
- $-1000 \le \text{nums}[i] \le 1000$ → 三数乘积的绝对值不超过 $10^9$，用 32 位 `int` 即可装下，无需 64 位
- 允许重复值与 $0$；不保证数组中存在正数

## 2. 示例

**示例 1**

```text
输入：nums = [1,2,-3]
输出：-6
解释：只有三个数字 1、2、-3，最大乘积只能是 1 × 2 × (-3) = -6。
```

**示例 2**

```text
输入：nums = [1,2,3,4]
输出：24
解释：全部为正数，取最大的三个：2 × 3 × 4 = 24。
```

**示例 3**

```text
输入：nums = [-1,-2,-3]
输出：-6
解释：全部为负数，只能取这三个数：(-1) × (-2) × (-3) = -6。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有下标组合 $i<j<k$，维护乘积最大值：

```text
ans ← -∞
for i in [0, n) :
  for j in (i, n) :
    for k in (j, n) :
      ans ← max(ans, nums[i] * nums[j] * nums[k])
返回 ans
```

组合数 $\binom{n}{3} = n(n-1)(n-2)/6$，$n = 10^4$ 时约 $1.7\times10^{11}$ 次乘法，即使常数极小也远超时间限制（通常 $10^8$ 量级）。**瓶颈在于「选哪三个」被当成了无序暴力**，而乘积的结构只与「符号」和「绝对值」有关，可以先把数组规整成有序形态再讨论。

### 3.2 核心观察：排序后只剩两个候选

![核心观察：两个候选](images/wc38_q1_three_numbers_concept.svg)

把 `nums` 升序排序为 $a_0 \le a_1 \le \dots \le a_{n-1}$。三数乘积的**符号由负因子的个数决定**：奇数个负因子为负、偶数个为正。而要让乘积最大，就是「让符号为正，且让绝对值尽可能大」。于是只有两种形态有机会成为最优：

- **候选 A（三正形态）**：$A = a_{n-3}\,a_{n-2}\,a_{n-1}$，即**三个最大的数**。非负数相乘时，把任一因子换成更大的数，乘积不会变小，故「取最大的三个」是这一类里的最优。
- **候选 B（负负得正形态）**：$B = a_0\,a_1\,a_{n-1}$，即**两个最小的数（最负的两个）+ 最大数**。两个同号负数相乘得到正的大绝对值，再乘最大数，就能把「负负得正」的红利用满。

> 💡 一句话：负数只能靠**成对出现**来贡献正值；一旦用到负数，就一定要用**绝对值最大的那两个**（即最小的 $a_0, a_1$），而第三个因子固定取最大值 $a_{n-1}$。

反直觉的地方在于：**绝对不能只返回「三个最大数」的乘积**。例如 `nums = [-100,-98,1,2,3]`，三个最大数给出 $1\times2\times3=6$，而两个最负数配最大值给出 $(-100)\times(-98)\times3 = 29400$，后者完胜。

### 3.3 算法流程

![算法流程](images/wc38_q1_algorithm_flow.svg)

```text
输入：nums（长度 n ≥ 3）
1. 升序排序：a ← sorted(nums)                 # O(n log n)
2. A ← a[0] * a[1] * a[n-1]                    # 两个最负 + 最大
   B ← a[n-3] * a[n-2] * a[n-1]                # 三个最大
3. 返回 max(A, B)
```

如果 $n$ 很大、或输入以流的形式给出（不能整存），可以把排序换成**一次遍历维护极值**：同时记录最大的三个数 $\text{max}_1 \ge \text{max}_2 \ge \text{max}_3$ 与最小的两个数 $\text{min}_1 \le \text{min}_2$，最后返回

$$\max\bigl(\text{min}_1\cdot\text{min}_2\cdot\text{max}_1,\ \ \text{max}_1\cdot\text{max}_2\cdot\text{max}_3\bigr)$$

这样时间降到 $O(n)$、额外空间 $O(1)$。注意本题上界只有 $10^4$，排序版已经足够，不必过度优化。

### 3.4 示例演算

![示例走查](images/wc38_q1_walkthrough.svg)

以 `nums = [-100,-98,1,2,3]` 走一遍（$n = 5$，排序后 $a = [-100,-98,1,2,3]$）：

| 步 | 动作 | 计算 | 结果 |
|---|---|---|---|
| 1 | 排序 | $-100 \le -98 \le 1 \le 2 \le 3$ | — |
| 2 | 候选 A：$a_0,a_1,a_4$ | $(-100)\times(-98)\times 3 = 9800\times 3$ | $29400$ |
| 3 | 候选 B：$a_2,a_3,a_4$ | $1\times 2\times 3$ | $6$ |
| 4 | 取较大者 | $\max(29400,\ 6)$ | $\mathbf{29400}$ |

对照三个官方示例：

| nums | 排序后 | 候选 A | 候选 B | 答案 |
|---|---|---|---|---|
| `[1,2,-3]` | $-3,1,2$ | $(-3)\cdot1\cdot2=-6$ | 同 A（$n=3$） | $-6$ |
| `[1,2,3,4]` | $1,2,3,4$ | $1\cdot2\cdot4=8$ | $2\cdot3\cdot4=24$ | $24$ |
| `[-1,-2,-3]` | $-3,-2,-1$ | $(-3)(-2)(-1)=-6$ | 同 A（$n=3$） | $-6$ |

## 4. 算法细节

1. **下标别写错**：候选 B 的三个因子是 $a_{n-3}, a_{n-2}, a_{n-1}$（含 $n-3$），候选 A 的两个最小因子是 $a_0, a_1$，而最大值恒为 $a_{n-1}$。写成 $a_{n-2}a_{n-1}a_{n-1}$ 这类「重复取同一元素」是本题最常见的错法。
2. **必须先排序**：两个候选的正确性依赖「$a_0,a_1$ 是最小两个、$a_{n-3..n-1}$ 是最大三个」。若原数组未排序，同一公式毫无意义。
3. **$n=3$ 自动退化**：此时 $a_0 = a_{n-3}$、$a_1 = a_{n-2}$，候选 A 与候选 B 是同一组数，$\max$ 自然给出正确答案，无需特判。
4. **一次遍历版的下标语义**：维护极值时用「插入排序」式的链式更新，比较用**严格**不等号即可：

   ```python
   if x > max1:   max3, max2, max1 = max2, max1, x
   elif x > max2: max3, max2 = max2, x
   elif x > max3: max3 = x
   if x < min1:   min2, min1 = min1, x
   elif x < min2: min2 = x
   ```

   遇到与 `max1` 相等的重复值时走 `elif x > max2` 分支，仍能正确填满 `max2`、`max3`，所以重复元素不会漏。
5. **初值选取**：`max1..max3` 初始化为 $-\infty$、`min1..min2` 初始化为 $+\infty$。Python 里可以直接用 `float('-inf')` 与整数比较；C++ 里应初始化为 `INT_MIN` / `INT_MAX` 并保证 $n \ge 3$（题面保证），避免用哨兵值参与乘法。
6. **溢出无需担心**：$\lvert \text{nums}[i] \rvert \le 1000$，三数乘积 $\le 10^9 < 2^{31}-1 \approx 2.1\times10^9$，`int` 安全；若把上界改成 $10^6$，乘积可达 $10^{18}$，必须换成 `long long`。
7. **不要用「乘积必为正」的假设**：全负数且 $n=3$ 时答案为负（示例 3），因此不能把答案初始化为 $0$ 再取 $\max$。

## 5. 正确性证明

**引理 1（两数最大乘积）**：设 $b_0 \le b_1 \le \dots \le b_{m-1}$（$m \ge 2$），则对任意 $i < j$ 有
$$b_i b_j \le \max\bigl(b_0 b_1,\ b_{m-2} b_{m-1}\bigr).$$

**证明**：分三种符号情形。

- 若 $b_i \ge 0$，则 $b_i, b_j$ 均非负，由单调性 $b_i b_j \le b_{m-2} b_{m-1}$。
- 若 $b_j \le 0$，则两者均非正且 $|b_i| \le |b_0|$、$|b_j| \le |b_1|$，故 $b_i b_j = |b_i||b_j| \le |b_0||b_1| = b_0 b_1$。
- 若 $b_i < 0 \le b_j$，则 $b_i b_j \le 0$，此时两候选至少有一个非负：若数组至少有两个负数，$b_0 b_1 > 0$；若只有一个负数（必为 $b_0$），则 $b_{m-2}, b_{m-1} \ge 0$，故 $b_{m-2}b_{m-1} \ge 0$。总之 $\max(b_0b_1, b_{m-2}b_{m-1}) \ge 0 \ge b_i b_j$。

三种情形均成立。∎

**引理 2（上界）**：记 $A = a_0 a_1 a_{n-1}$、$B = a_{n-3}a_{n-2}a_{n-1}$，则**任意**三元组 $i<j<k$ 的乘积 $P = a_i a_j a_k$ 满足 $P \le \max(A, B)$。

**证明**：记 $M = a_{n-1}$。$n = 3$ 时三元组唯一，$P = A = B$，结论成立。以下设 $n \ge 4$。

**情形 1：$M \ge 0$。**

- 若三元组含 $M$：由引理 1 应用于前缀 $a_0..a_{n-2}$，另两个因子之积 $\le \max(a_0a_1,\ a_{n-3}a_{n-2})$。因 $M \ge 0$，两边同乘 $M$ 不改变不等式方向，得 $P \le \max(A, B)$。
- 若三元组不含 $M$ 且 $P \ge 0$：
  - 若三元组三个元素都 $\ge 0$，把其中最大者 $z$ 换成 $M \ge z$，另两因子非负，乘积不减；
  - 若三元组恰有两个负数（一个非负数），把那个非负数（即三者最大者）换成 $M$，两个负数之积为正，乘积不减；
  - 若三元组三个元素都 $\le 0$，则由 $P \ge 0$ 知其中有 $0$，从而 $a_1 \le 0$（三个元素都非正意味着最小的两个也非正），于是 $A = a_0a_1M \ge 0 = P$。

  前两种子情形换入 $M$ 后落入上一条「含 $M$」的情形，故 $P \le \max(A,B)$。
- 若三元组不含 $M$ 且 $P < 0$：此时负因子个数为 $1$ 或 $3$。
  - 有 $1$ 个负因子：三元组含两个非负数，故 $a_{n-2} \ge 0$。若 $a_{n-3} \ge 0$，则 $B \ge 0 > P$；若 $a_{n-3} < 0$，则整个数组恰有两个非负数 $a_{n-2}, a_{n-1}$，三元组中的两个非负数只能取它们，于是 $M$ 被选中，与非「不含 $M$」矛盾。故该子情形必有 $P \le B$。
  - 有 $3$ 个负因子：由 $M \ge 0$ 知 $a_1 \le 0$，故 $A = a_0a_1M > 0 > P$。

**情形 2：$M < 0$（全数组为负）。** 此时所有元素都 $< 0$。对三个非正数 $x,y,z$，乘积关于每个因子单调不减（如 $\partial (xyz)/\partial z = xy \ge 0$），故三非正数乘积在「三个因子都尽量大」时取最大，即 $P \le a_{n-3}a_{n-2}a_{n-1} = B$。

综上，任何三元组的乘积都不超过 $\max(A,B)$。∎

**引理 3（可达性）**：$A$ 与 $B$ 都是合法的三元组乘积。

**证明**：$n \ge 3$ 时，下标 $0, 1, n-1$ 互不相同（$n-1 \ge 2 > 1$），故 $A$ 对应三元组 $\{a_0,a_1,a_{n-1}\}$；下标 $n-3, n-2, n-1$ 互不相同，故 $B$ 对应三元组 $\{a_{n-3},a_{n-2},a_{n-1}\}$。两者都是数组中的三个不同元素。∎

**定理**：算法返回 $\max(A,B)$，它等于所有三元组乘积的最大值。

**证明**：由引理 3，$\max(A,B)$ 被某个三元组取到，故最大值 $\ge \max(A,B)$；由引理 2，任何三元组乘积 $\le \max(A,B)$，故最大值 $\le \max(A,B)$。两边夹逼得最大值恰为 $\max(A,B)$，算法输出正确。∎

> 备注：一次遍历版维护的 $\text{max}_1,\text{max}_2,\text{max}_3$ 就是 $a_{n-1}, a_{n-2}, a_{n-3}$，$\text{min}_1,\text{min}_2$ 就是 $a_0, a_1$（重复元素时取值相同、下标可互换），因此它与排序版计算的是同一个表达式，正确性证明完全复用。

## 6. 复杂度分析

- **时间**：排序版为 $O(n\log n)$，瓶颈在排序；两个候选与取 $\max$ 都是 $O(1)$。一次遍历版为 $O(n)$，每个元素做常数次比较与赋值。$n \le 10^4$ 时两者都在毫秒级。
- **空间**：额外空间 $O(1)$（不含输入）。C++ 的 `std::sort` 为原地排序，附加栈空间 $O(\log n)$；Python 的 `list.sort()` 原地排序，Timsort 最坏需要 $O(n)$ 的临时缓冲区。一次遍历版严格 $O(1)$。

## 7. 参考代码

### C++

```cpp
#include <algorithm>
#include <vector>
using namespace std;

class Solution {
public:
    int maximumProduct(vector<int>& nums) {
        sort(nums.begin(), nums.end());          // 升序，a[0] 最小、a[n-1] 最大
        int n = nums.size();
        int A = nums[0] * nums[1] * nums[n - 1];         // 两个最负 + 最大
        int B = nums[n - 3] * nums[n - 2] * nums[n - 1]; // 三个最大
        return max(A, B);
    }
};
```

### Python

```python
class Solution:
    def maximumProduct(self, nums: list[int]) -> int:
        nums.sort()                                  # 原地升序
        n = len(nums)
        two_min_max = nums[0] * nums[1] * nums[n - 1]        # 两个最负 + 最大
        three_max = nums[n - 3] * nums[n - 2] * nums[n - 1]  # 三个最大
        return max(two_min_max, three_max)
```

**进阶：$O(n)$ 一次遍历（不排序）**

```python
class Solution:
    def maximumProduct(self, nums: list[int]) -> int:
        INF = float('inf')
        max1 = max2 = max3 = -INF      # 最大的三个
        min1 = min2 = INF              # 最小的两个
        for x in nums:
            if x > max1:
                max3, max2, max1 = max2, max1, x
            elif x > max2:
                max3, max2 = max2, x
            elif x > max3:
                max3 = x
            if x < min1:
                min2, min1 = min1, x
            elif x < min2:
                min2 = x
        return max(min1 * min2 * max1, max1 * max2 * max3)
```

## 8. 边界情况与易错点

1. **$n = 3$**：全部元素都得选，答案可能是负数（示例 1、3）。公式不需特判，但**不能**把答案初始化为 $0$ 再取 $\max$，否则 `[1,2,-3]` 会错答 $0$。
2. **直觉陷阱：只取最大三个**。`[-100,-98,1,2,3]` 的正确答案是 $29400$，而「三个最大」只给出 $6$。凡是存在「至少两个负数且最大值大于 $0$」的数组，都必须比较候选 A。
3. **两个负数 + 零**：`[-4,-3,0,1,2]` 中，$-4\times-3\times2=24$ 才是答案；而 `[0,0,0]`、`[-1,0,1]` 这类答案为 $0$ 的用例会检验「不用 0 初始化答案」这一点。
4. **全部为负数**：$n=3$ 时直接乘三个；$n>3$ 时最优是**最靠近 $0$ 的三个**（即最大的三个），公式的候选 B 恰好覆盖，候选 A 只会更差——两者取 $\max$ 即可，无需单独分类。
5. **重复元素**：`[2,2,2,3]` 这类用例下，一次遍历版必须让相等的值也能依次填入 `max2/max3`（`elif` 链配合严格 `>` 已满足），若把条件写成 `>=` 并配合错误的更新顺序，容易出现「同一元素被用两次」。
6. **下标不要复用**：候选 A 中的最大值 $a_{n-1}$ 与候选 B 中相同，但 A 的两个小因子必须是 $a_0,a_1$（互异下标），不能写成 $a_0 \cdot a_0 \cdot a_{n-1}$。
7. **溢出与类型**：本题 $10^9$ 上限在 `int` 内；若数据加强到 $\lvert \text{nums}[i]\rvert \le 10^6$，必须用 `long long` / Python 的任意精度整数才安全。
