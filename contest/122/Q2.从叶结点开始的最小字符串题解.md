# LeetCode 从叶结点开始的最小字符串 题解

## 1. 题目概述

- **标题 / 题号**：从叶结点开始的最小字符串（#988，medium）
- **链接**：https://leetcode.cn/problems/smallest-string-starting-from-leaf/
- **来源**：LeetCode 第 122 场周赛 Q2
- **难度**：中等
- **标签**：树、深度优先搜索、字符串、回溯、二叉树

**题意**：给定一棵二叉树，每个结点有一个 $[0, 25]$ 的整数，分别映射到字母 `a`～`z`。对每个**叶结点**，把它到根的路径上的字母按「叶 → 根」的顺序拼成字符串，返回其中**字典序最小**的那个。

**约束**：

- 结点数在 $[1, 8500]$ 内
- $0 \le Node.val \le 25$

> ⚠️ 注意：字典序里**短前缀更小**（`"ab" < "aba"`），所以不同深度的叶子之间同样可以直接比较；而 8500 个结点可能有 8500 层深，Python 递归会撞默认的 1000 层限制，必须写成迭代版。

## 2. 示例

**示例 1**

```text
输入：root = [0,1,2,3,4,3,4]
输出："dba"
解释：四个叶子给出的字符串是 "dba"、"eba"、"dca"、"eca"，最小的是 "dba"。
```

**示例 2**

```text
输入：root = [25,1,3,1,3,0,2]
输出："adz"
解释：候选为 "bbz"、"dbz"、"adz"、"cdz"，首字母 a 的 "adz" 最小。
```

**示例 3**

```text
输入：root = [2,2,1,null,1,0,null,0]
输出："abc"
解释：叶子 0（右下）给出 "abc"，另一个叶子给出 "abcc"；"abc" 是 "abcc" 的前缀，更小。
```

## 3. 解题思路

### 3.1 暴力思路

枚举每个叶结点，各自独立地从该叶子沿父指针走到根拼出字符串，再取最小值。找父结点、重新回溯，需要额外的父指针表，代价 $O(n \cdot h)$；更糟的是若每次从根重新 DFS 到叶子，代价会变成 $O(n^2)$ 且代码繁琐。既然一次遍历就能同时知道「当前路径」，暴力法没有存在价值。

### 3.2 核心观察：下降时把字母「拼在前面」

![从叶到根的方向：每下降一层就把新字母拼在前面](images/wc122_q2_path_order.svg)

题目要的是**叶 → 根**，而 DFS 天然是**根 → 叶**。两种对齐方式：

- 按根到叶累积，到叶子处再 `reverse` 一次；
- **下降时前插**：子结点的串 = `chr(子)` + 父结点的串。

第二种方式下，走到叶子时栈里保存的字符串**已经**是「叶 → 根」，可直接参与比较，少一次反转、少一处出错。字符串的加法顺序因此值得单独想清楚：`path = chr(child.val) + path` 而不是 `path + chr(child.val)`。

比较直接用语言内置的字符串比较：C++ 的 `std::string::operator<` 与 Python 的 `str.__lt__` 都是逐字符比较、短前缀更小，与题目定义的字典序完全一致，无需自定义比较器。

### 3.3 算法流程

![迭代 DFS 的状态与分支](images/wc122_q2_dfs_compare.svg)

```text
1. best = 空，has = false
2. stack = [(root, chr('a' + root.val))]
3. while stack 非空:
       弹出 (node, path)
       若 node 是叶子:
           若 has 为假 或 path < best: best = path; has = true
           继续
       若 node.left  存在: 压入 (left,  chr(left.val)  + path)
       若 node.right 存在: 压入 (right, chr(right.val) + path)
4. 返回 best
```

用显式的 `has` 标志而不是把 `best` 初始化成空串：空串在字典序里是最小的，若用它当哨兵就永远不会被更新。

### 3.4 示例演算

![示例 1 的四个候选](images/wc122_q2_walkthrough.svg)

对示例 1 的 `[0,1,2,3,4,3,4]`，根为 `a`，四个叶子分别挂在 $1$（`b`）与 $2$（`c`）下面：

| 叶子路径 | 叶 → 根字符串 | 结论 |
|----------|----------------|------|
| $0 \to 1 \to 3$ | `dba` | 最小 ✓ |
| $0 \to 1 \to 4$ | `eba` | 淘汰 |
| $0 \to 2 \to 3$ | `dca` | 淘汰 |
| $0 \to 2 \to 4$ | `eca` | 淘汰 |

四个首字母分别是 `d, e, d, e`，`d` 最小的两个再比第二位 `b < c`，最终 `dba` 胜出。注意首字母来自**叶子**（值为 3 的结点 → `d`），而不是根。

## 4. 算法细节

1. **迭代而非递归**：深链可达 8500 层，Python 默认递归上限 1000 会抛 `RecursionError`；C++ 虽有较大栈，但统一用显式栈更安全。
2. **栈元素设计**：`(结点, 该结点到根的字符串)` 二元组。字符串随结点一起走，天然是「路径快照」。
3. **叶子判定**：`left == null && right == null`。注意单子结点的父结点**不是**叶子。
4. **比较时机**：只在叶子处比较；内部结点的前缀没有意义（它不是合法候选）。
5. **Python 类型标注**：`list[int]` 与 `str` 返回值写法与题面签名一致。
6. **空树**：题面保证结点数 $\ge 1$，代码不必处理 `root == null`；若工程上需要，可返回空串。

## 5. 正确性证明

**引理 1（路径不变式）**：算法执行过程中，栈内每个元素 `(v, s)` 满足 $s$ 恰为从 $v$ 到根路径上各结点字母按「$v$ → 根」顺序拼成的串。

**证明**：初始时栈中只有 `(root, chr(root.val))`，$s$ 就是根到自身的一个字符，成立。设某次弹出前不变式成立，弹出后对子结点 $u$ 压入 `(u, chr(u.val) + s)`：由于 $s$ 是 $v$ 到根，$u$ 到根即「$u$ 再拼上 $v$ 到根」，前插一个字符正好得到新的串，不变式保持。∎

**引理 2（覆盖性）**：每个叶结点被弹出并比较恰好一次。

**证明**：树是连通的 DAG，从根出发沿子边可达每个结点；算法对每个非叶结点把存在的子结点压栈，故每个结点都会被压栈一次（每个结点只有一个父结点），也只会被弹出一次。叶子被弹出时进入比较分支，非叶子不会进入。∎

**定理**：算法返回的字符串等于所有「叶 → 根」字符串中的字典序最小者。

**证明**：由引理 2，每个叶子的候选串都被生成，且由引理 1 其内容正确；算法的更新规则是「若当前候选更小则替换」，这是标准的最小值扫描，故最终 `best` 是所有候选中的最小者。`has` 标志保证第一次比较一定赋值，因此只要存在叶子（结点数 $\ge 1$ 时必有叶子），`best` 就非空。∎

## 6. 复杂度分析

- **时间**：$O(n \cdot h)$，其中 $n$ 为结点数、$h$ 为树高。每个结点被访问一次，但每次压栈要构造长度为「该结点深度」的新串，单结点代价 $O(\text{depth})$。链状树最坏 $O(n^2)$（$8500^2 \approx 7 \times 10^7$ 字符拷贝，实测可接受）；平衡树则为 $O(n \log n)$。
- **空间**：$O(h^2)$ 用于栈中各帧保存的路径串（栈内至多 $O(h)$ 个帧，每帧字符串长度 $O(h)$），另有 $O(n)$ 的结果串。若把路径改写成「共享一个可变栈 + 回溯」，空间可降到 $O(h)$，但代码复杂度上升，本题规模无需。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    string smallestFromLeaf(TreeNode* root) {
        string best;
        bool has = false;
        vector<pair<TreeNode*, string>> st;
        st.push_back({root, string(1, char('a' + root->val))});
        while (!st.empty()) {
            pair<TreeNode*, string> cur = st.back();
            st.pop_back();
            TreeNode* node = cur.first;
            const string& path = cur.second;
            if (!node->left && !node->right) {
                if (!has || path < best) {
                    best = path;
                    has = true;
                }
                continue;
            }
            if (node->left) st.push_back({node->left, string(1, char('a' + node->left->val)) + path});
            if (node->right) st.push_back({node->right, string(1, char('a' + node->right->val)) + path});
        }
        return best;
    }
};
```

### Python

```python
class Solution:
    def smallestFromLeaf(self, root) -> str:
        best = None
        stack = [(root, chr(ord('a') + root.val))]
        while stack:
            node, path = stack.pop()
            if node.left is None and node.right is None:
                if best is None or path < best:
                    best = path
                continue
            if node.left is not None:
                stack.append((node.left, chr(ord('a') + node.left.val) + path))
            if node.right is not None:
                stack.append((node.right, chr(ord('a') + node.right.val) + path))
        return best
```

## 8. 边界情况与易错点

1. **只有根结点**：根既是叶子，答案是单个字符，`has` 逻辑必须能处理「第一次就赋值」。
2. **拼接方向**：`chr(child) + path` 与 `path + chr(child)` 只差一个加号，结果截然相反；这是本题最高频的 WA。
3. **空串当哨兵**：`best = ""` 在字典序里最小，永远不会被替换，必须用 `None` / `false` 标志。
4. **递归深度**：$8500$ 个结点的链会让 Python 递归超限，务必迭代。
5. **单子结点不算叶子**：只有 `left` 或只有 `right` 的结点不是叶，不能参与比较。
6. **前缀比较**：`"abc" < "abcc"`（示例 3），不要用「长度优先」的错误比较器。
7. **字符偏移**：`Node.val` 是 $[0,25]$，直接 `chr(ord('a') + val)`，不要再 $+1$。
