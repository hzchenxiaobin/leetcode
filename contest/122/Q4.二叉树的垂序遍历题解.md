# LeetCode 二叉树的垂序遍历 题解

## 1. 题目概述

- **标题 / 题号**：二叉树的垂序遍历（#987，hard）
- **链接**：https://leetcode.cn/problems/vertical-order-traversal-of-a-binary-tree/
- **来源**：LeetCode 第 122 场周赛 Q4
- **难度**：困难
- **标签**：树、深度优先搜索、广度优先搜索、哈希表、二叉树、排序

**题意**：对根结点 `root` 定义坐标 $(0,0)$，其左右子结点分别为 $(row+1, col-1)$ 与 $(row+1, col+1)$。要求从**最左列到最右列**，把每一列的结点按「**行号升序**」输出；若同行同列有多个结点，则按**结点值升序**排列。返回二维数组。

**约束**：

- 结点总数在 $[1, 1000]$ 内
- $0 \le Node.val \le 1000$

> 💡 两个容易忽略的点：一是「列优先、行其次、值最后」的三级排序；二是**同一格可能落多个结点**（示例 2 的 5 与 6），此时只能靠值来决出先后，而不是靠遍历顺序。

## 2. 示例

**示例 1**

```text
输入：root = [3,9,20,null,null,15,7]
输出：[[9],[3,15],[20],[7]]
解释：列 −1 有 9；列 0 有 3、15（行号 0、2）；列 1 有 20；列 2 有 7。
```

**示例 2**

```text
输入：root = [1,2,3,4,5,6,7]
输出：[[4],[2],[1,5,6],[3],[7]]
解释：列 0 有 1（行 0）、5 与 6（均行 2，按值 5 < 6）。
```

**示例 3**

```text
输入：root = [1,2,3,4,6,5,7]
输出：[[4],[2],[1,5,6],[3],[7]]
解释：5 与 6 交换了树中位置，但仍落在 (2,0)，答案不变。
```

## 3. 解题思路

### 3.1 暴力思路

按列号从小到大枚举（列号范围 $[-n, n]$），对每个列号遍历整棵树收集该列的结点，再对收集到的结点按行号排序。复杂度 $O(n^2 + n^2 \log n)$，$n \le 1000$ 时约 $10^6$ 次访问，能过但明显浪费；而且列号范围需要事先知道，多一层猜测。

如果改成「BFS 按层收集、每层内按列排序再拼接」，虽然能保证行号有序，但**同一列跨层**的结点需要再合并，仍然要维护 $O(n)$ 个列表，代码更绕。

### 3.2 核心观察：一次全局排序就够了

![给每个结点打上 (row, col)](images/wc122_q4_coordinates.svg)

关键是把题目要求的三级顺序**编码成一个元组**：

$$\text{key} = (col,\; row,\; val)$$

- 第一关键字 `col`：保证结果按列从最左到最右；
- 第二关键字 `row`：同一列内从上到下；
- 第三关键字 `val`：同行同列（坐标完全重合）时按值升序。

只要对所有结点按这个三元组做一次升序排序，输出顺序就**唯一确定**，与 DFS/BFS 的访问顺序无关。随后线性扫描一遍，把 `col` 相同的连续段切成一组即可。

### 3.3 算法流程

![一次全局排序与分组](images/wc122_q4_sort_keys.svg)

```text
1. nodes = []
2. 用显式栈 DFS：栈元素 (node, row, col)，初始 (root, 0, 0)
      弹出后若 node 为空则跳过
      nodes 追加 (col, row, node.val)
      压入 (node.left,  row+1, col-1)
      压入 (node.right, row+1, col+1)
3. 对 nodes 按 (col, row, val) 升序排序
4. 线性扫描 nodes：col 与上一段不同则开新组，否则追加到当前组
5. 返回所有组
```

选 DFS 而非 BFS 的理由：只需要坐标，不需要「层」的概念；显式栈避免深链（$n \le 1000$）在 Python 里触发递归上限。

### 3.4 示例演算

![示例 2 的五列与输出](images/wc122_q4_walkthrough.svg)

对示例 2 的 `[1,2,3,4,5,6,7]`：

| 结点 | 坐标 $(row, col)$ | 键 $(col, row, val)$ |
|------|-------------------|----------------------|
| 1 | $(0,0)$ | $(0,0,1)$ |
| 2 | $(1,-1)$ | $(-1,1,2)$ |
| 3 | $(1,1)$ | $(1,1,3)$ |
| 4 | $(2,-2)$ | $(-2,2,4)$ |
| 5 | $(2,0)$ | $(0,2,5)$ |
| 6 | $(2,0)$ | $(0,2,6)$ |

排序后：$(-2,2,4), (-1,1,2), (0,0,1), (0,2,5), (0,2,6), (1,1,3), (2,2,7)$，按 `col` 分组即得 $[[4],[2],[1,5,6],[3],[7]]$。列 0 的三个结点先比行号（$0 < 2$），行号相同的 5 与 6 再比值。

## 4. 算法细节

1. **坐标传递**：`col` 可以取负，全程用 `int`，不要试图加偏移量转成下标——最后是按 `col` 排序，负值不碍事。
2. **空指针处理**：显式栈里可能压入 `null`（叶子结点的两个空儿子），弹出时判空跳过，避免写两遍「是否存在」判断。
3. **排序键顺序**：C++ 用 `tuple<int,int,int>` 的字典序比较，Python 用 `(col, row, val)` 元组，二者语义一致，不要手工写比较器时把 `row` 与 `val` 写反。
4. **分组边界**：扫描时只与**上一段的列号**比较，因此需要在分组时记录当前段的 `col`；用「若 `ans` 为空或列号变化则新开一组」最简洁。
5. **行号与值相同**：当两个结点坐标相同且值也相同时，先后无意义，任意顺序都对。
6. **复杂度落点**：排序是唯一非线性的环节，$O(n \log n)$；其余都是线性。

## 5. 正确性证明

**引理 1（坐标唯一）**：每个结点的 `(row, col)` 由它在树中的位置唯一确定，与 DFS 的访问次序无关。

**证明**：从根到结点 $v$ 的路径唯一（树无环且每个结点只有一个父结点）。每走一条左边 `col` 减 1、右边加 1，`row` 加 1，故 $row(v) = \text{depth}(v)$、$col(v) = (\text{右转次数}) - (\text{左转次数})$，两者都只依赖路径本身，路径唯一故坐标唯一。∎

**引理 2（排序即定序）**：按 $(col, row, val)$ 升序排序后，序列满足：列号非降；同列内行号非降；同行同列内值非降。

**证明**：元组字典序比较的定义即为「先比第一分量，相等再比第二分量，再相等比第三分量」。因此对任意相邻两项，要么 $col$ 严格增大，要么 $col$ 相等而 $row$ 严格增大，要么前两者相等而 $val$ 非降。逐条翻译就是三种非降性。∎

**引理 3（同列连续）**：排序后，同一 `col` 的所有结点占据一段连续区间。

**证明**：设 $u, w$ 的 `col` 都等于 $c$，而 $v$ 在排序序列中位于两者之间。由引理 2 的列号非降性，$\text{col}(u) \le \text{col}(v) \le \text{col}(w)$，即 $c \le \text{col}(v) \le c$，故 $\text{col}(v) = c$。∎

**定理**：算法返回的二维数组恰为题目要求的垂序遍历序列。

**证明**：由引理 1，每个结点的坐标正确；由引理 2，排序后序列满足「列升序、列内行升序、同格值升序」；由引理 3，按 `col` 切分得到的分组恰好覆盖每一列且不混入别的列。于是第 $k$ 组就是第 $k$ 列自上而下（同格按值）的结点列表，与题面定义逐字相符。∎

## 6. 复杂度分析

- **时间**：$O(n \log n)$。DFS 访问 $n$ 个结点、生成 $n$ 个三元组，$O(n)$；排序 $n$ 个三元组 $O(n \log n)$；分组线性扫描 $O(n)$。
- **空间**：$O(n)$。`nodes` 数组存 $n$ 个三元组；显式栈最多 $O(n)$（最深 $n$ 的链）；输出本身 $O(n)$。

对比暴力「每列遍历一次全树」的 $O(n^2)$，本解把「列」这个维度交给排序，避免了对列号的枚举。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<vector<int>> verticalTraversal(TreeNode* root) {
        vector<tuple<int, int, int>> nodes;
        vector<tuple<TreeNode*, int, int>> st;
        st.push_back(make_tuple(root, 0, 0));
        while (!st.empty()) {
            tuple<TreeNode*, int, int> cur = st.back();
            st.pop_back();
            TreeNode* node = get<0>(cur);
            int row = get<1>(cur), col = get<2>(cur);
            if (!node) continue;
            nodes.push_back(make_tuple(col, row, node->val));
            st.push_back(make_tuple(node->left, row + 1, col - 1));
            st.push_back(make_tuple(node->right, row + 1, col + 1));
        }
        sort(nodes.begin(), nodes.end());
        vector<vector<int>> ans;
        for (size_t i = 0; i < nodes.size(); i++) {
            int col = get<0>(nodes[i]), val = get<2>(nodes[i]);
            if (i == 0 || get<0>(nodes[i - 1]) != col) ans.push_back({});
            ans.back().push_back(val);
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def verticalTraversal(self, root) -> list[list[int]]:
        nodes = []
        stack = [(root, 0, 0)]
        while stack:
            node, row, col = stack.pop()
            if node is None:
                continue
            nodes.append((col, row, node.val))
            stack.append((node.left, row + 1, col - 1))
            stack.append((node.right, row + 1, col + 1))
        nodes.sort()
        ans = []
        for col, row, val in nodes:
            if not ans or ans[-1][0] != col:
                ans.append([col, []])
            ans[-1][1].append(val)
        return [g for _, g in ans]
```

Python 版用 `[col, []]` 临时携带段标记，最后再剥掉；若不想用这种写法，也可以先记录 `prev_col` 变量。

## 8. 边界情况与易错点

1. **只按 `(col, val)` 排序**：会打乱同一列的上下顺序，示例 1 的列 0 需要 $3$ 在 $15$ 之前，靠的是行号。
2. **同格多结点**：$(2,0)$ 上的 5 与 6 只能靠值排序（示例 2、3），不能依赖访问顺序。
3. **列号为负**：不要加偏移量转下标，直接按 `int` 排序即可。
4. **单结点树**：返回 `[[val]]`，分组逻辑要能从空 `ans` 正确开第一组。
5. **递归深度**：$n \le 1000$ 的链在 Python 中会触及递归上限，必须用迭代。
6. **空儿子入栈**：压入 `null` 后弹出判空，避免在压栈处写两种分支（写分支也正确，但更啰嗦）。
7. **分组条件写错**：判断「列号变化」要用**排序后的上一个元素**的列号，不能用「上一组的第一个元素」以外的猜测。
8. **值的范围**：$0 \le Node.val \le 1000$，无负数，但即使有负数排序逻辑也不受影响。
