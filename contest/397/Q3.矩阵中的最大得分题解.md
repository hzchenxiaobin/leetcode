# LeetCode 矩阵中的最大得分 题解

## 1. 题目概述

- **标题 / 题号**：矩阵中的最大得分（#3148，medium）
- **链接**：https://leetcode.cn/problems/maximum-difference-score-in-a-grid/
- **来源**：LeetCode 第 397 场周赛 Q3
- **难度**：中等
- **标签**：数组、动态规划、矩阵、前缀最小值

**题意**：给一个 $m \times n$ 的**正整数**矩阵 $\mathrm{grid}$。每一步可以从某格移动到**正下方或正右侧**的任意格子（**不必相邻**，一步可跨多格）。从值 $c_1$ 的格子走到值 $c_2$ 的格子得 $c_2 - c_1$ 分。你可以从**任意**格出发，但**必须至少移动一次**。求能获得的最大总得分。

**约束**：

- $2 \le m, n \le 1000$
- $4 \le m \cdot n \le 10^5$
- $1 \le \mathrm{grid}[i][j] \le 10^5$

> 💡 赛时读题抓三个信号：① 移动只向**下/右**（可跨格）⇒ 一切路径都是「行、列坐标不降」的单调折线；② 单步得分是「到达值 − 出发值」，一路**累加**；③ **至少动一次**——示例 2 直接给出 $-1$，说明全递减矩阵也只能「亏得最少」，打擂台必须从 $-\infty$ 起步。Q3 是分场胜负的关键题，拼的就是**谁最先看出得分与路径形状无关**。

## 2. 示例

**示例 1**

```text
输入：grid = [[9,5,7,3],[8,9,6,1],[6,7,14,3],[2,5,3,1]]
输出：9
解释：从 (0,1) 出发：(0,1)→(2,1) 得 7−5=2；(2,1)→(2,2) 得 14−7=7；总计 9。
```

**示例 2**

```text
输入：grid = [[4,3,2],[3,2,1]]
输出：-1
解释：从 (0,0) 移动到 (0,1)，得 3−4=−1。全矩阵递减，亏得最少也是 −1。
```

**示例 3（自造）**

```text
输入：grid = [[1,5],[9,2]]
输出：8
解释：直达 (0,0)→(1,0) 得 9−1=8；绕行 (0,0)→(0,1)→(1,1) 得 (5−1)+(2−5)=1，
      恰好等于 2−1。绕不绕、走几步，总分都是「终点值 − 起点值」。
```

## 3. 解题思路

### 3.1 暴力思路

最朴素是 DFS 枚举所有路径：每步可选「同列任意下方格」或「同行任意右侧格」，路径数指数级，直接放弃。

退一步，接受下节「得分只看首尾」的观察后再枚举所有（起点, 终点）对：合法对满足 $x \le i$、$y \le j$、$(x,y) \ne (i,j)$，可达性判定 $O(1)$，但点对共 $O((mn)^2) \approx 10^{10}$ 个（$mn = 10^5$），依然超时。浪费点一眼可见：**每个终点都把它的整个左上区域重扫一遍找最小起点**——这正是前缀预处理能一刀切掉的部分。

### 3.2 核心观察：裂项相消——得分只由首尾决定

![核心概念：路径得分裂项相消，总分只由首尾决定](images/wc397_q3_telescope.svg)

一条路径 $c_0 \to c_1 \to \cdots \to c_k$ 的总得分为

$$\sum_{t=1}^{k} (c_t - c_{t-1}) = (c_1 - c_0) + (c_2 - c_1) + \cdots + (c_k - c_{k-1}) = c_k - c_0$$

**中间格子两两成对抵消**（望远镜求和）。走一步还是一百步、直走还是绕行，都不影响总分——问题从「搜路径」坍缩为「选首尾」：

$$\mathrm{ans} = \max_{\text{终点 } (i,j)} \Big( \mathrm{grid}[i][j] - \min_{\substack{0 \le x \le i,\ 0 \le y \le j \\ (x,y) \ne (i,j)}} \mathrm{grid}[x][y] \Big)$$

配套两个事实：

1. **可达性**：起点 $(x,y)$ 能到达 $(i,j)$ $\iff$ $x \le i$、$y \le j$ 且 $(x,y) \ne (i,j)$——先同行右滑到 $(x,j)$、再同列下滑到 $(i,j)$，至多两步拼出合法路径（「不必相邻」允许跨格）。
2. **换视角**：这就是 [121. 买卖股票的最佳时机](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock/) 的**二维版**——「先买后卖」变成「左上买、右下卖」，前缀最小值从一维数组升格为二维矩形。

> ⚠️ 赛时最容易绕的弯路：看到「网格 + 只能右/下」就条件反射往**路径型 DP** 上想（像 64 题那样逐格转移）。但 telescoping 已经宣告路径维度是假的——无需关心走了几步、怎么走，维护**左上区域最小值**打擂台，一趟 $O(mn)$ 就完。

### 3.3 算法流程：二维前缀最小值 + 打擂台

![算法模型：可选起点区域=挖掉自身的左上矩形=上块∪左块](images/wc397_q3_prefix_min_rect.svg)

剩下唯一的工程问题：**「挖掉自身的左上矩形」的最小值怎么 $O(1)$ 拿到**。设 $premin[i][j]$ 为**含自身**的左上矩形 $[0..i] \times [0..j]$ 的最小值，则：

1. **递推**：$premin[i][j] = \min(\mathrm{grid}[i][j],\ premin[i-1][j],\ premin[i][j-1])$——正是 304 题二维前缀和「上、左两块合并」的骨架，把求和换成取最小。
2. **挖洞**：任何 $\ne (i,j)$ 的区域内格子，要么行号 $< i$（落入**上块** $[0..i-1] \times [0..j]$），要么行号 $= i$ 且列号 $< j$（落入**左块** $[0..i] \times [0..j-1]$）——两块并集恰好覆盖、无遗漏，块间重叠由 $\min$ 的幂等性吸收，无需真的「挖洞」。
3. **打擂台**：对每个 $(i,j)$，$\mathrm{best} = \min(premin[i-1][j],\ premin[i][j-1])$，若 $\mathrm{best} < +\infty$（仅 $(0,0)$ 无可选起点）则更新 $\mathrm{ans} = \max(\mathrm{ans},\ \mathrm{grid}[i][j] - \mathrm{best})$。

实现上把 $premin$ 开成 $(m+1) \times (n+1)$、第 0 行/列填 $+\infty$ 哨兵，下标整体平移一格，$i=0$、$j=0$ 的边界与「无起点」特判全部自动兜底，主循环零分支。

### 3.4 示例演算

![示例演算：premin 逐行快照与打擂台](images/wc397_q3_walkthrough.svg)

以示例 1 演算（滚动数组视角：`premin[j]` 未更新 = 上一行的上块、已更新 = 本行的左块，与二维表完全等价）：

| 处理完 | premin | ans | 本行最佳 |
|--------|--------|-----|----------|
| 第 0 行 | [9, 5, 5, 3] | 2 | (0,2)：7 − 5 = 2 |
| 第 1 行 | [8, 5, 5, 1] | 4 | (1,1)：9 − 5 = 4 |
| 第 2 行 | [6, 5, 5, 1] | **9** | (2,2)：14 − 5 = 9 ← |
| 第 3 行 | [2, 2, 2, 1] | 9 | (3,1)：5 − 2 = 3，未刷新 |

关键一步在 $(2,2)$：$\mathrm{best} = \min(\text{上块 } 5,\ \text{左块 } 5) = 5$，$14 - 5 = 9$——最优起点正是 $(0,1)$ 的 5，对应路径 $(0,1) \to (2,1) \to (2,2)$。示例 2 全矩阵递减，`ans` 全程停在 $-1$，印证「必须动一次 ⇒ 答案可为负」。

## 4. 算法细节

1. **哨兵平移**：$premin$ 开成 $(m+1) \times (n+1)$，第 0 行、第 0 列全填 $+\infty$，格子 $(i,j)$ 对应表位 $(i+1, j+1)$。行首无左块、行 0 无上块、$(0,0)$ 无可选起点，三种边界情形全部由哨兵吸收，主循环不写任何 `if (i == 0)` 分支。
2. **跳过 $\infty$ 是习惯而非侥幸**：$(0,0)$ 处 `best = INT_MAX`，`grid[i][j] - best` 的结果 $\in [-2147483646,\ -2147483547]$，恰好**仍在 `int` 范围内**（本题 $\mathrm{grid} \ge 1$ 救了它），且小到不可能当选——但这是踩在值域悬崖边的巧合：值域一变（比如允许负数或 $10^9$ 级）立刻有符号溢出 UB。`if (best < INF)` 一行保平安。
3. **滚动数组变体**：一维 `premin[n]` 行内从左到右更新——读 `premin[j]`（**未更新**）= 上一行的上块，读 `premin[j-1]`（**已更新**）= 本行的左块，一个物理数组在同一时刻承载两代数据，空间降到 $O(n)$。「左读新、上读旧」的图解见[每日题解](../../solution/3101-3200/3148_矩阵中的最大得分.md)。
4. **min 幂等是根基**：上块与左块在 $[0..i-1] \times [0..j-1]$ 重叠，重叠区域被取两次 $\min$ 也不影响结果——「两块并集」写法因此成立。
5. **赛场决策**：Q3 拼 15 分钟内的手速与准确率。二维哨兵版多花 $O(mn) \le 10^5$ 个 `int`（约 0.4 MB）内存，换来零边界分支，是最稳的写法；滚动版省空间但「读旧读新」要过脑子，留作手熟后的提速选项。

## 5. 正确性证明

**引理 1（裂项相消）**：任意合法路径 $c_0 \to c_1 \to \cdots \to c_k$（$k \ge 1$）的总得分为 $c_k - c_0$。

**证明**：总得分 $= \sum_{t=1}^{k}(c_t - c_{t-1}) = \sum_{t=1}^{k} c_t - \sum_{t=1}^{k} c_{t-1} = \sum_{t=1}^{k} c_t - \sum_{t=0}^{k-1} c_t$。两式中 $c_1, \cdots, c_{k-1}$ 各出现一次加、一次减，成对抵消，只剩 $c_k - c_0$。∎

**引理 2（可达性刻画）**：从 $(x,y)$ 出发存在合法移动序列到达 $(i,j)$ $\iff$ $x \le i$、$y \le j$ 且 $(x,y) \ne (i,j)$。

**证明**：（$\Rightarrow$）每次移动后行号、列坐标均不减小且至少一维严格增大，对步数归纳得 $x \le i$、$y \le j$；又至少移动一次，故起点 $\ne$ 终点。（$\Leftarrow$）若 $x = i$，则 $y < j$，一步右移直达（不必相邻）；若 $y = j$，一步下移直达；若 $x < i$ 且 $y < j$，先同行右移至 $(x, j)$、再同列下移至 $(i, j)$，每步均合法。∎

**引理 3（前缀最小值递推）**：$premin[i][j] = \min(\mathrm{grid}[i][j],\ premin[i-1][j],\ premin[i][j-1])$（越界取 $+\infty$）恰为矩形 $[0..i] \times [0..j]$ 的最小值。

**证明**：对 $i + j$ 归纳。基例 $i = j = 0$：区域只含自身，$premin[0][0] = \mathrm{grid}[0][0]$。归纳步：矩形 $[0..i] \times [0..j] = \{(i,j)\} \cup [0..i-1] \times [0..j] \cup [0..i] \times [0..j-1]$（任取区域内格子，若行号 $< i$ 落入上块，若行号 $= i$ 则列号 $\le j$，含自身或落入左块），故全区域 $\min$ 为三者 $\min$；两个子块由归纳假设（$i+j$ 更小）等于各自 $premin$，空块由 $+\infty$ 吸收。∎

**引理 4（挖洞覆盖）**：$\{(x,y) : 0 \le x \le i,\ 0 \le y \le j\} \setminus \{(i,j)\} = ([0..i-1] \times [0..j]) \cup ([0..i] \times [0..j-1])$。

**证明**：（$\supseteq$）右端两块均含于左端区域且均不含 $(i,j)$。（$\subseteq$）任取区域内 $\ne (i,j)$ 的格子 $(x,y)$：若 $x < i$，落入 $[0..i-1] \times [0..j]$；若 $x = i$，则必有 $y < j$（否则即 $(i,j)$），落入 $[0..i] \times [0..j-1]$。∎

**定理**：算法返回题意所求的最大总得分。

**证明**：由引理 1、2，最大总得分 $= \max$ over 合法（起点, 终点）对的 $\mathrm{grid}[\text{终点}] - \mathrm{grid}[\text{起点}]$。固定终点 $(i,j)$，该项随 $\mathrm{grid}[\text{起点}]$ 减小而增大，故最优起点值为引理 4 左端区域的最小值；由引理 3、4，$\mathrm{best} = \min(premin[i-1][j],\ premin[i][j-1]) = \min(\text{上块min},\ \text{左块min}) = \min(\text{并集min})$（min 的幂等性使重叠无害）恰为该值。算法对每个 $(i,j)$ 恰执行一次打擂台；$(0,0)$ 因 $\mathrm{best} = +\infty$ 被跳过，而其可选起点集本为空集、无贡献。故返回值即该最大值。∎

## 6. 复杂度分析

- **时间复杂度**：$O(mn)$。行优先一趟扫描，每格常数次 $\min$ / $\max$。
- **空间复杂度**：二维哨兵表 $O(mn)$（$\le 10^5$ 个 `int`，约 0.4 MB）；一维滚动版 $O(n)$。
- **值域安全**：$1 \le \mathrm{grid}[i][j] \le 10^5$，任意两格之差的绝对值 $< 10^5$，`int` 无溢出——但哨兵 $+\infty$ 本身是悬崖边的例外（见 §4 第 2 条）。

## 7. 参考代码

### C++（二维哨兵表：零边界分支，赛场首选）

```cpp
class Solution {
public:
    int maxScore(vector<vector<int>>& grid) {
        int m = grid.size(), n = grid[0].size();
        const int INF = INT_MAX;
        vector<vector<int>> premin(m + 1, vector<int>(n + 1, INF));
        int ans = INT_MIN;
        for (int i = 0; i < m; ++i) {
            for (int j = 0; j < n; ++j) {
                int best = min(premin[i][j + 1], premin[i + 1][j]); // 上块 / 左块
                if (best < INF) ans = max(ans, grid[i][j] - best);  // (0,0) 无起点，跳过
                premin[i + 1][j + 1] = min(best, grid[i][j]);       // 含自身的矩形最小值
            }
        }
        return ans;
    }
};
```

### Python（一维滚动：左读新、上读旧）

```python
from math import inf

class Solution:
    def maxScore(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        premin = [inf] * n
        ans = -inf
        for i in range(m):
            for j in range(n):
                best = premin[j]                    # 未更新 = 上一行：上块
                if j > 0:
                    best = min(best, premin[j - 1]) # 已更新 = 本行：左块
                if best < inf:
                    ans = max(ans, grid[i][j] - best)
                premin[j] = min(best, grid[i][j])
        return ans
```

## 8. 边界情况与易错点

1. **`ans` 初始化为 0**：全递减矩阵（示例 2）答案为负，初值取 $0$ 会错报 $0$。必须用 $-\infty$（`INT_MIN` / `-inf`）。
2. **哨兵 $\infty$ 参与减法**：$(0,0)$ 处 `best` 仍为 $\infty$，本题恰好因 $\mathrm{grid} \ge 1$ 而不溢出、且该候选值小到不可能当选——但换一道值域含负数（如 $-10^5 - 2^{31} < \mathrm{INT\_MIN}$）或 $10^9$ 级的题立刻 UB。别赌运气，判 `best < INF`。
3. **误把「正下方/正右侧」当「右下方」**：$(0,0)$ 不能一步斜跳到 $(1,1)$，但两步可达；由 telescoping 两者总分相同，答案层面无差别——不过可达性刻画 $x \le i \wedge y \le j$ 的正确性依赖「下或右的组合」，理解偏了容易在变体题翻车。
4. **用含自身的 $premin[i][j]$ 当 `best`**：等于把「原地不动」混进可行集。反例 $\mathrm{grid} = [[5, 1]]$：正确答案 $1 - 5 = -4$，错版算出 $1 - \min(5,1) = 0$（自身恰为区域最小时必出错）。
5. **行优先一维前缀 min 的陷阱**：把「扫描顺序在 $(i,j)$ 之前的所有格子」当可选起点——这会把上方 $y' > j$ 的格子也算进去，而它们在终点右侧、不可达。正确区域是二维矩形，不是一维扫描序。
6. **滚动数组读旧读新颠倒**：`premin[j]` 必须更新前读（上块）、`premin[j-1]` 更新后读（左块）；若先把 `premin[j]` 写掉再算 `best`，上块被本行值污染，递推作废。
7. **`m`、`n` 最小为 2**：恒有合法移动，答案必存在，无需特判「无法移动」。
