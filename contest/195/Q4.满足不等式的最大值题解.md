# LeetCode 满足不等式的最大值 题解

## 1. 题目概述

- **标题 / 题号**：满足不等式的最大值（#1499，hard）
- **链接**：https://leetcode.cn/problems/max-value-of-equation/
- **来源**：LeetCode 第 195 场周赛 Q4
- **难度**：困难
- **标签**：数组、滑动窗口、单调队列、堆（优先队列）

**题意**：给定点集 `points`（`points[i] = [x_i, y_i]` 表示二维平面上的点），已按横坐标 $x$ **严格递增**排序。再给定整数 $k$。在所有满足 $1 \le i < j \le n$ 且 $|x_i - x_j| \le k$ 的点对中，求

$$y_i + y_j + |x_i - x_j|$$

的**最大值**。题目保证至少存在一对满足距离约束的点。

**约束**：

- $2 \le \text{points.length} \le 10^5$
- $-10^8 \le x_i, y_i \le 10^8$
- $0 \le k \le 2 \times 10^8$
- 对所有 $1 \le i < j \le \text{points.length}$，均有 $x_i < x_j$（$x_i$ 构成严格递增序列）

## 2. 示例

**示例 1**

```text
输入：points = [[1,3],[2,0],[5,10],[6,-10]], k = 1
输出：4
解释：i=0, j=1 满足 |1-2| = 1 ≤ 1，得 3 + 0 + |1-2| = 4；
      i=2, j=3 满足 |5-6| = 1 ≤ 1，得 10 + (-10) + |5-6| = 1。
      两者中最大值为 4。
```

**示例 2**

```text
输入：points = [[0,0],[3,0],[9,2]], k = 3
输出：3
解释：只有 i=0, j=1 满足 |0-3| = 3 ≤ 3，得 0 + 0 + |0-3| = 3。
      点 (9,2) 与任何点的 x 距离都超过 3，无法参与配对。
```

**示例 3（补充：答案为负）**

```text
输入：points = [[0,-5],[1,-6]], k = 1
输出：-10
解释：唯一合法点对：-5 + (-6) + |0-1| = -10。
      答案可以为负，ans 不能初始化为 0。
```

## 3. 解题思路

### 3.1 暴力思路：枚举点对

双层循环枚举所有 $(i, j)$，过滤 $x_j - x_i > k$ 的对，取最大值，时间 $O(n^2)$。$n$ 可达 $10^5$，最坏 $10^{10}$ 次运算，**必然超时**。

一个常见的「伪优化」是固定 $j$ 只向左扫到 $x_j - x_i > k$ 为止（更左的点必然更远）：但 $x$ 间距可以任意密集，最坏窗口内仍可包含 $n$ 个点，复杂度还是 $O(n^2)$。

> ⚠️ 真正的瓶颈在于「对每个 $j$ 重复扫描窗口」。相邻 $j$ 的合法窗口高度重叠：$j$ 右移时，窗口右端纳入新点、左端按 $x_j - k$ 丢弃过远的点——这是标准的**滑动窗口最值**结构，应该用单调队列把每次查询降到均摊 $O(1)$。

### 3.2 核心观察：方程裂解 + 按 x 值滑动的窗口

![核心观察：绝对值消解后方程裂解为 (y−x)+(y+x)，对每个 j 在 x 距离 ≤ k 的窗口内找 (y−x) 最大](images/wc195_q4_equation_split_concept.svg)

**第一步：消绝对值**。$x$ 严格递增且 $i < j$，故 $|x_i - x_j| = x_j - x_i$，代入得

$$y_i + y_j + |x_i - x_j| = (y_i - x_i) + (y_j + x_j)$$

含绝对值的方程**裂解**为「只与 $i$ 有关的项 + 只与 $j$ 有关的项」。这一步是整题的钥匙。

**第二步：固定 $j$，问题变成窗口最值**。对每个 $j$，记 $v_i = y_i - x_i$，只需在窗口 $\{i < j : x_j - x_i \le k\}$ 中找最大的 $v_i$：

$$\text{candidate}(j) = (y_j + x_j) + \max_{\substack{i < j \\ x_j - x_i \le k}} (y_i - x_i)$$

**第三步：单调队列**。这与「滑动窗口最大值」完全同构，只换了两处皮：

| 对比项 | 经典滑窗最值 | 本题 |
|--------|-------------|------|
| 窗口定义 | 下标差 $\le k$ | $x$ 差 $\le k$（按 $x$ 值滑动） |
| 维护的值 | `nums[i]` | $y_i - x_i$ |

用双端队列存下标，使 $v$ 从队头到队尾**单调递减**，则队头永远是当前窗口内 $v$ 最大的下标，$O(1)$ 取用。

### 3.3 算法流程：单调队列三步走

![算法流程：对每个 j 依次执行过期出队、查询候选、入队弹尾](images/wc195_q4_monotonic_queue_flow.svg)

对每个 $j$（从左到右）依次执行：

1. **过期出队（左端）**：`while 队非空 且 x[队头] < x_j − k：pop_front`。$x$ 严格递增 ⇒ 队列中下标（即 $x$）从队头到队尾递增，过期的元素必然集中在队头。
2. **查询候选**：若队非空，`cand = (y[队头] − x[队头]) + (y_j + x_j)`，用 `cand` 更新 `ans`。
3. **入队弹尾（右端）**：`while 队非空 且 v[队尾] ≤ v_j：pop_back`，然后 `push_back(j)`。被弹掉的旧点「值不更大、$x$ 更小（更早过期）」，只要 $j$ 在窗口内它们就永不可能成为最大，可安全丢弃。

> ⚠️ **三步顺序不能反**：必须先过期、再查询、最后入队。若 $j$ 提前入队，会拿自己配自己（$i = j$ 非法）；若不过期就查询，队头可能已滑出窗口，算出非法候选。

### 3.4 示例演算

![示例演算：k=1 时 4 步遍历的队列变化与候选计算，第 3 步连续过期弹出是关键](images/wc195_q4_example_walkthrough.svg)

以示例 1 为例（$v_i = y_i - x_i$：$v_0 = 2,\ v_1 = -2,\ v_2 = 5,\ v_3 = -16$）：

| $j$ | $(x_j, y_j)$ | $v_j$ | 阈值 $x_j - k$ | 队列（下标:$v$） | 动作 | 候选 | ans |
|-----|--------------|-------|---------------|-----------------|------|------|-----|
| 0 | (1, 3) | 2 | 0 | `[0:2]` | 队空无候选；入队 0 | — | $-\infty$ |
| 1 | (2, 0) | −2 | 1 | `[0:2, 1:−2]` | $x_0=1 \ge 1$ 不过期；候选 $=2+(0+2)$；入队 | 4 | 4 |
| 2 | (5, 10) | 5 | 4 | `[2:5]` | $x_0=1 < 4$、$x_1=2 < 4$ 连续过期弹；队空无候选；入队 | — | 4 |
| 3 | (6, −10) | −16 | 5 | `[2:5, 3:−16]` | $x_2=5 \ge 5$ 不过期；候选 $=5+(-10+6)$；入队 | 1 | 4 |

**第 3 行是关键**：$v_0 = 2$ 是此前窗口内最大的值，但 $x_0 = 1$ 与 $x_2 = 5$ 的距离已超过 $k = 1$，必须丢弃——**过期看 $x$ 值而非下标**。第 4 行则相反：$x_2 = 5 = x_3 - k$，距离**恰好**为 $k$ 仍合法，不能误弹。

最终答案 $4$，来自 $i=0, j=1$：$(y_0 - x_0) + (y_1 + x_1) = 2 + 2 = 4$，即 $3 + 0 + |1-2| = 4$。

## 4. 算法细节

1. **队列存下标**而非值，$v = y - x$ 需要时现算：$x$ 严格递增 ⇒ 下标递增即 $x$ 递增，过期元素必然堆在队头，这是「过期出队从队头弹」的前提。
2. **过期条件用严格小于**：`x[队头] < x_j − k`。因为 $x_j - x_i \le k \iff x_i \ge x_j - k$，距离恰为 $k$ 的点仍合法。注意不能照抄经典滑窗的 `队头 < j − k`（那是按**下标**滑动的窗口，本题窗口按 **$x$ 值**滑动，$x$ 间距不均匀，两者不等价）。
3. **弹尾条件用 `≤`**：$(y-x)$ 相同的旧点 $x$ 更小、更早过期，留着无意义，只保留最新的，队列更紧凑。
4. **`ans` 初始化为 $-\infty$**：$j = 0$ 时窗口为空、不产生候选；且答案可能为负（示例 3），初始化为 0 会得到错误结果。
5. **每步先查询后入队**：$j$ 的贡献给**后续**的 $j' > j$ 使用，自己在当前步只当「右端点」。

## 5. 正确性证明

**引理 1（方程裂解）**：对所有 $i < j$，$y_i + y_j + |x_i - x_j| = (y_i - x_i) + (y_j + x_j)$。

**证明**：$x$ 严格递增，$i < j \Rightarrow x_i < x_j$，故 $|x_i - x_j| = x_j - x_i$，代入即得。∎

**引理 2（过期元素永不复活）**：若处理 $j$ 时下标 $b$ 满足 $x_b < x_j - k$，则对一切 $j' \ge j$ 仍有 $x_b < x_{j'} - k$。

**证明**：$x$ 递增 ⇒ $x_{j'} - k \ge x_j - k > x_b$。故从队头弹出的过期元素对当前及之后所有查询都非法，丢弃无损。∎

**引理 3（弹尾有见证）**：设下标 $b$ 在队列中被后来者 $t$ 弹尾，则 $x_b < x_t$ 且 $v_b \le v_t$。对任意后续查询 $j > t$：若 $b$ 属于窗口（$x_b \ge x_j - k$），则 $t$ 也属于窗口且 $v_t \ge v_b$。

**证明**：由 $x_b < x_t$ 及 $x_b \ge x_j - k$ 得 $x_t > x_j - k$，又 $t < j$，故 $t$ 在窗口内且 $v_t \ge v_b$。于是丢弃 $b$ 后，窗口内仍有 $v$ 不小于 $v_b$ 的元素。若 $t$ 日后也被弹尾，则被 $v$ 更大、$x$ 更大的新见证替代（对弹尾时刻逐次归纳，见证链不断，链尾留在队列中）。∎

**引理 4（查询时队头即窗口最大）**：处理 $j$ 的第 2 步时，队列中元素全部落在窗口内，且窗口内每个下标的 $v$ 都不超过队头的 $v$。

**证明**：第 1 步已把 $x < x_j - k$ 的元素从队头弹出；队列内 $x$ 从队头到队尾递增，故弹出停止后剩余元素全部满足 $x \ge x_j - k$ 且下标小于 $j$，全在窗口内。窗口内不在队列中的下标，由引理 2 要么已永久非法，由引理 3 要么存在仍在队列中的 $v$ 不小于它的见证；而队列内 $v$ 从队头到队尾递减，队头是队列内 $v$ 最大者。两者结合：队头的 $v$ 即窗口最大值。∎

**定理**：算法返回值等于 $\max\{y_i + y_j + |x_i - x_j| : i < j,\ x_j - x_i \le k\}$。

**证明**：

1. **每条候选都合法（ans ≤ 最优）**：算法累计的每个候选形如 $(y_i - x_i) + (y_j + x_j)$，其中队头 $i$ 经过期清理满足 $x_j - x_i \le k$，且第 3 步执行前 $j$ 尚未入队，故 $i < j$。由引理 1，该候选等于某合法点对的方程值，不超过最优值。
2. **最优值必被覆盖（ans ≥ 最优）**：取最优对 $(i^*, j^*)$。处理 $j^*$ 查询时 $i^*$ 属于窗口（$x_{i^*} \ge x_{j^*} - k$），由引理 4，队头的 $v$ 是窗口最大，故 $\text{candidate}(j^*) \ge v_{i^*} + (y_{j^*} + x_{j^*}) = $ 最优值，从而 ans ≥ 最优值。

两边夹逼，ans = 最优值。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。每个下标恰好入队 1 次，出队至多 1 次（过期或弹尾），两个 `while` 的总弹出次数 $\le n$；外层循环 $n$ 轮，每轮均摊 $O(1)$。
- **空间复杂度**：$O(n)$。队列最坏存全部下标（如 $v$ 整体递减且窗口一直不收缩时）。

$n = 10^5$ 时约 $2 \times 10^5$ 次队列操作，毫秒级完成。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int findMaxValueOfEquation(vector<vector<int>>& points, int k) {
        int n = points.size();
        deque<int> dq;  // 存下标，(y−x) 从队头到队尾递减
        long long ans = LLONG_MIN;
        for (int j = 0; j < n; ++j) {
            long long xj = points[j][0], yj = points[j][1];
            // ① 过期出队：x 距离超过 k 的队头永不可用
            while (!dq.empty() && points[dq.front()][0] < xj - k) {
                dq.pop_front();
            }
            // ② 查询队头（窗口内 y−x 最大者），计算候选
            if (!dq.empty()) {
                int i = dq.front();
                ans = max(ans, (long long)points[i][1] - points[i][0] + yj + xj);
            }
            // ③ 入队弹尾：值不大于 v_j 的旧点 x 更小、更早过期，永不可能成为最大
            while (!dq.empty() &&
                   (long long)points[dq.back()][1] - points[dq.back()][0] <= yj - xj) {
                dq.pop_back();
            }
            dq.push_back(j);
        }
        return (int)ans;
    }
};
```

### Python

```python
from collections import deque

class Solution:
    def findMaxValueOfEquation(self, points: List[List[int]], k: int) -> int:
        dq = deque()  # 存下标，(y−x) 从队头到队尾递减
        ans = float('-inf')
        for j, (xj, yj) in enumerate(points):
            # ① 过期出队
            while dq and points[dq[0]][0] < xj - k:
                dq.popleft()
            # ② 查询队头，计算候选
            if dq:
                i = dq[0]
                ans = max(ans, points[i][1] - points[i][0] + yj + xj)
            # ③ 入队弹尾
            while dq and points[dq[-1]][1] - points[dq[-1]][0] <= yj - xj:
                dq.pop()
            dq.append(j)
        return ans
```

## 8. 边界情况与易错点

1. **`ans` 初始化为 $-\infty$**（`LLONG_MIN` / `float('-inf')`）：$j=0$ 时左侧无点、无候选；答案可为负（示例 3 得 $-10$），初始化为 0 会返回错误的 0。
2. **过期条件是 `x[队头] < x_j − k`**：取 `<` 而非 `≤`——距离恰为 $k$（$x_i = x_j - k$）仍合法（示例 1 第 4 步）；也不要误写成经典滑窗的下标窗口 `队头 < j − k`，本题窗口按 $x$ 值滑动。
3. **三步顺序固定**：过期 → 查询 → 入队。$j$ 提前入队会自己配自己（$i = j$ 非法）；查询放在过期前会用上已滑出窗口的队头。
4. **弹尾用 `≤`**：同值只留最新（$x$ 更大、更晚过期）的；用 `<` 也正确但队列偏长。
5. **数值范围**：$|y \pm x| \le 2 \times 10^8$，候选绝对值 $\le 4 \times 10^8$，未超过 `int` 上限（约 $2.1 \times 10^9$）但已同量级，C++ 中间量建议用 `long long` 防溢出。
6. **题目保证有解**（$n \ge 2$ 且至少一对点距离合法），无需处理无解；若去掉该保证，需在 ans 仍为 $-\infty$ 时特判。
7. **$x$ 严格递增、无重复**：不存在两点 $x$ 相同，队列中下标与 $x$ 一一对应单调，无需去重逻辑。
