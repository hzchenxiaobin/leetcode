# LeetCode 单调数列 题解

## 1. 题目概述

- **标题 / 题号**：单调数列（#896，easy）
- **链接**：https://leetcode.cn/problems/monotonic-array/
- **来源**：LeetCode 第 100 场周赛 Q1
- **难度**：简单
- **标签**：数组

**题意**：若数组对任意 $i \le j$ 都有 $\text{nums}[i] \le \text{nums}[j]$，称其**单调递增**；若都有 $\text{nums}[i] \ge \text{nums}[j]$，称其**单调递减**。数组是单调的当且仅当它**单调递增或单调递减**。给定 `nums`，判断它是否单调。

**约束**：

- $1 \le \text{nums.length} \le 10^5$
- $-10^5 \le \text{nums}[i] \le 10^5$

> 💡 注意是「非严格」单调：相等不破坏单调性。

## 2. 示例

**示例 1**

```text
输入：nums = [1,2,2,3]
输出：true
解释：相邻差为 +1, 0, +1，从未下降 ⇒ 单调递增。
```

**示例 2**

```text
输入：nums = [6,5,4,4]
输出：true
解释：相邻差为 −1, −1, 0，从未上升 ⇒ 单调递减。
```

**示例 3**

```text
输入：nums = [1,3,2]
输出：false
解释：1→3 上升，3→2 下降，两个方向都出现过，既不递增也不递减。
```

## 3. 解题思路

### 3.1 暴力思路

按定义枚举所有下标对 $(i, j)$、$i \le j$，检查是否全部满足 $\le$（或全部满足 $\ge$）：$O(n^2)$，$n = 10^5$ 时 $10^{10}$，不可行。即使优化成「对每个 $i$ 检查与后面的关系」，仍是平方级。

### 3.2 核心观察：只需比较相邻元素

![两个布尔标志](images/wc100_q1_two_flags_concept.svg)

关键引理：数组单调递增 $\iff$ 对**所有相邻**下标 $i$ 都有 $\text{nums}[i] \le \text{nums}[i+1]$。

理由：任意 $i < j$ 的 $\text{nums}[i] \le \text{nums}[j]$ 可以由相邻不等式逐段传递得到（$a_0 \le a_1 \le \cdots \le a_j$ 的链式传递）；反之相邻对本身就是 $i \le j$ 的特例。递减同理。

于是只需一遍扫描，用两个布尔标志：

- `inc`：到目前为止没有出现过「下降」（`nums[i] < nums[i-1]`）；
- `dec`：到目前为止没有出现过「上升」（`nums[i] > nums[i-1]`）。

扫描结束若 `inc || dec` 为真，即为单调。

### 3.3 算法流程

```text
inc = true, dec = true
for i = 1 .. n-1:
    若 nums[i] < nums[i-1]: inc = false
    若 nums[i] > nums[i-1]: dec = false
return inc or dec
```

### 3.4 示例演算

![三个示例的判定过程](images/wc100_q1_walkthrough.svg)

| 数组 | 相邻比较 | 标志 | 结果 |
|------|----------|------|------|
| `[1,2,2,3]` | $1\le2$、$2\le2$、$2\le3$ | inc=true, dec=false | true |
| `[6,5,4,4]` | $6\ge5$、$5\ge4$、$4\ge4$ | inc=false, dec=true | true |
| `[1,3,2]` | $1<3$ 上升、$3>2$ 下降 | inc=false, dec=false | false |

第三个例子中两个标志同时被打破——这正是「既有上升又有下降」的判别方式。

## 4. 算法细节

1. **两个标志而不是一个方向变量**：若先找到第一个非零差值再定方向，需要额外处理「全相等」的情形；双标志写法天然覆盖。
2. **相等不算破坏**：比较用严格 `<` 与 `>`；写成 `<=` / `>=` 会把相等误判成破坏单调。
3. **提前返回可选**：一旦 `inc` 与 `dec` 都为假即可返回 `false`，是个小优化，但不是必需。
4. **长度为 1**：循环不执行，返回 `true`，符合「单个元素同时是递增与递减」的约定。
5. **值域**：$\pm 10^5$，相邻差在 `int` 范围内，无需 64 位。
6. **不要排序**：排序后比较会丢掉「原顺序」，$O(n \log n)$ 且逻辑错误。

## 5. 正确性证明

**引理 1（相邻判定等价）**：数组 `nums` 单调递增 $\iff$ 对所有 $1 \le i < n$ 有 $\text{nums}[i-1] \le \text{nums}[i]$。

**证明**：

- （$\Rightarrow$）取 $j = i$、$i = i-1$，直接由定义得到。
- （$\Leftarrow$）任取 $p < q$，由相邻不等式链
  $$\text{nums}[p] \le \text{nums}[p+1] \le \cdots \le \text{nums}[q]$$
  由 $\le$ 的传递性得 $\text{nums}[p] \le \text{nums}[q]$，故定义中「对所有 $p \le q$」成立。∎

递减版本对称（把 $\le$ 换成 $\ge$）。

**引理 2（标志语义）**：扫描结束后，`inc` 为真 $\iff$ 对所有相邻对都有 $\text{nums}[i-1] \le \text{nums}[i]$；`dec` 为真 $\iff$ 对所有相邻对都有 $\text{nums}[i-1] \ge \text{nums}[i]$。

**证明**：`inc` 初始为真，只有当存在某个 $i$ 使 $\text{nums}[i] < \text{nums}[i-1]$ 时才被置假。因此 `inc` 为真 $\iff$ 不存在下降的相邻对，即所有相邻对满足 $\ge$ 的反面——$\text{nums}[i] \ge \text{nums}[i-1]$，即 $\text{nums}[i-1] \le \text{nums}[i]$。`dec` 同理。∎

**定理**：算法返回 `true` $\iff$ `nums` 是单调数组。

**证明**：由引理 2，`inc || dec` 为真 $\iff$ 全部相邻对非降或全部相邻对非增；由引理 1，这等价于「单调递增或单调递减」，即单调数组的定义。∎

## 6. 复杂度分析

- **时间**：$O(n)$，一遍扫描，每个元素一次比较（两次判断）。
- **空间**：$O(1)$，只用两个布尔变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool isMonotonic(vector<int>& nums) {
        bool inc = true, dec = true;          // 先假设同时单调递增、单调递减
        for (int i = 1; i < (int)nums.size(); i++) {
            if (nums[i] < nums[i - 1]) inc = false;   // 出现下降 ⇒ 不是递增
            if (nums[i] > nums[i - 1]) dec = false;   // 出现上升 ⇒ 不是递减
        }
        return inc || dec;                    // 至少一种成立即可（相等不算破坏）
    }
};
```

### Python

```python
class Solution:
    def isMonotonic(self, nums: List[int]) -> bool:
        inc = dec = True                      # 先假设同时单调递增、单调递减
        for a, b in zip(nums, nums[1:]):
            if b < a:
                inc = False                   # 出现下降 ⇒ 不是递增
            if b > a:
                dec = False                   # 出现上升 ⇒ 不是递减
        return inc or dec                     # 至少一种成立即可（相等不算破坏）
```

## 8. 边界情况与易错点

1. **全相等数组**：如 `[2,2,2]`，两个标志都保持为真，返回 `true`——它同时是递增与递减，正确。
2. **严格不等号**：`nums[i] < nums[i-1]` 与 `nums[i] > nums[i-1]`，不能写成 `<=`/`>=`。
3. **长度为 1**：返回 `true`，别写成 `false` 或抛异常。
4. **只判断一种方向**：只检查 `inc` 会漏掉递减数组；两个标志缺一不可。
5. **「先升后降再升」**：如 `[1,3,2,4]`，两个标志都会变假，返回 `false`，正确。
6. **用排序代替**：排序后比较会误判（`[2,1,2]` 排序后是 `[1,2,2]`，但原数组不单调），且复杂度更高。
7. **大数组性能**：$10^5$ 数据量下 $O(n^2)$ 会超时，必须线性。
