# LeetCode 有序队列 题解

## 1. 题目概述

- **标题 / 题号**：有序队列（#899，hard）
- **链接**：https://leetcode.cn/problems/orderly-queue/
- **来源**：LeetCode 第 100 场周赛 Q4
- **难度**：困难
- **标签**：数学、字符串、排序、最小表示法

**题意**：给定字符串 $s$ 和整数 $k$。每次操作可以从 $s$ 的**前 $k$ 个字符**中任选一个，把它移到字符串末尾。可以进行任意多次操作（包括 0 次），返回能得到的**字典序最小**的字符串。

**约束**：

- $1 \le k \le s.length \le 1000$
- $s$ 只含小写英文字母

> 💡 难点不在实现，而在**证明 $k \ge 2$ 时答案就是全局升序排列**——这一步想通，代码只有三行。

## 2. 示例

**示例 1**

```text
输入：s = "cba", k = 1
输出："acb"
解释：只能把首字符移到末尾，等价于循环左移。
      "cba" → "bac" → "acb"，三种循环移位中 "acb" 最小。
```

**示例 2**

```text
输入：s = "baaca", k = 3
输出："aaabc"
解释：k ≥ 2 时任意排列都可达，升序排列 "aaabc" 即最小。
      注意最小循环移位是 "aacab"，并不是答案。
```

**示例 3**

```text
输入：s = "a", k = 1
输出："a"
```

## 3. 解题思路

### 3.1 暴力思路

从 $s$ 出发 BFS：每次枚举前 $k$ 个字符逐一移到末尾，把所有可达字符串入队，取字典序最小。状态数最坏是 $n!$ 级别（$n = 1000$），完全不可行；即便 $k = 1$，BFS 也等价于枚举 $n$ 个循环移位，可以直接做，但 $k \ge 2$ 时必须换思路。

### 3.2 核心观察：按 $k$ 分成两种完全不同的情形

![按 k 分两种情形](images/wc100_q4_case_split_concept.svg)

**情形一：$k = 1$。** 每一步只能把**第一个**字符移到末尾，这正是**循环左移一位**。进行 $i$ 次就得到第 $i$ 个循环移位，因此可达集合恰为 $s$ 的全部 $n$ 个循环移位，取字典序最小即可。

**情形二：$k \ge 2$。** 此时答案**必然是全局升序排列** `sorted(s)`。直觉是：多了一个可操作位，就能在「前两位」里实现**交换**，而交换 + 旋转可以生成全部排列。

具体地，对任意串 $a\,b\,R$（$|R| = n-2$，$a$ 在首位、$b$ 在第二位），三步即可交换这两个字符而不动 $R$：

1. 把位置 1 的 $b$ 移到末尾 ⇒ $a\,R\,b$；
2. 把现在的首位 $a$ 移到末尾 ⇒ $R\,b\,a$；
3. 依次把 $R$ 的每个字符移到末尾（共 $|R|$ 次）⇒ $b\,a\,R$。

第 1、2 步用的都是「把前 2 个之一移到末尾」（$k \ge 2$ 允许），第 3 步只用「把首位移到末尾」（$k \ge 1$ 即允许）。于是操作 (0 1) 交换是**无条件可达**的；再配合循环左移 $\rho$，就能得到任意相邻交换 $\rho^{i}(0\,1)\rho^{-i} = (i,\ i+1)$，它们生成整个对称群 $S_n$。所以**任意排列都可达**，最小者就是升序排列。

### 3.3 算法流程

```text
若 k >= 2:
    return sorted(s)                     # 任意排列可达 ⇒ 升序最小
否则:                                     # k == 1
    best = s
    for i = 1 .. n-1:
        best = min(best, s[i:] + s[:i])   # 第 i 个循环移位
    return best
```

### 3.4 示例演算

![示例演算](images/wc100_q4_walkthrough.svg)

**例 1（$k=1$，$s=\text{"cba"}$）**：三个循环移位为 `cba`、`bac`、`acb`，最小是 `acb` ✓

**例 2（$k=3$，$s=\text{"baaca"}$）**：$k \ge 2$ ⇒ 排序得 `aaabc` ✓

| 情形 | 可达集合 | 答案 |
|------|----------|------|
| $k = 1$ | $n$ 个循环移位 | 最小循环移位 |
| $k \ge 2$ | 全部 $n!$ 种排列 | `sorted(s)` |

注意示例 2 的陷阱：最小循环移位是 `aacab`，但正确答案是 `aaabc`——$k \ge 2$ 时千万不要退回「最小表示法」。

## 4. 算法细节

1. **分界点是 $k = 1$ 与 $k \ge 2$**：$k$ 再大也不会改变结论（$k \ge n$ 时同样只是「任意排列」）。
2. **$k = 1$ 的枚举**：`s[i:] + s[:i]` 生成第 $i$ 个循环左移，共 $n$ 个（有重复无妨），$O(n^2)$。$n \le 1000$ 时约 $10^6$ 字符比较，足够快。
3. **排序**：`sorted(s)` 直接给出升序字符序列，$O(n\log n)$；字符串只含小写字母时也可用计数排序 $O(n)$。
4. **$n = 1$**：两种情况答案都是 $s$ 本身。
5. **为什么 $k=1$ 不能排序**：只有旋转一个自由度，字符的相对循环顺序被固定，无法任意重排（`"cba"` 永远得不到 `"abc"`）。
6. **最小表示法**：$k=1$ 时若 $n$ 很大（如 $10^6$），枚举会超时，应改用 Booth 算法在 $O(n)$ 内求最小循环移位；本题 $n \le 1000$，枚举足够。
7. **字典序比较**：Python 字符串比较、C++ `std::string` 的 `<` 都是字典序，可直接用 `min`。

## 5. 正确性证明

记 $n = |s|$，$\rho$ 为循环左移一位（把首位字符移到末尾）。注意 $\rho$ 与「把第 $j$ 个字符移到末尾」都是**对位置的操作**，与字符内容无关：对任意串都成立。

**引理 1（$k=1$ 的可达集）**：$k = 1$ 时，从 $s$ 出发可达的字符串集合恰为 $\{\rho^i(s) : 0 \le i \le n-1\}$（即全部循环移位）。

**证明**：每次操作唯一可选的是首位，效果就是把首位字符移到末尾，即应用 $\rho$。进行 $i$ 次得到 $\rho^i(s)$；由 $\rho^n = \text{id}$，$i$ 只需取 $0..n-1$。故可达集恰为该集合。∎

**引理 2（$k \ge 2$ 时交换前两位可达）**：对任意串 $a\,b\,R$（$|R| = n-2$），存在合法操作序列把它变为 $b\,a\,R$。

**证明**：分三步，每步都是题目允许的操作：

1. 位置 1 的字符是 $b$，且 $1 < k$（因 $k \ge 2$），可把它移到末尾：得到 $a\,R\,b$。
2. 此时首位是 $a$，可移到末尾：得到 $R\,b\,a$。
3. 反复把首位移到末尾：$R$ 的字符依次被搬到末尾，共 $|R|$ 次后得到 $b\,a\,R$。

（$|R| = 0$ 时第 3 步跳过，仍正确。）∎

**引理 3（$k \ge 2$ 时可达集为全部排列）**：记 $G$ 为「可达操作」在位置置换群中生成的子群，则 $G = S_n$。

**证明**：$\rho$（循环左移）可达（把首位移到末尾），由引理 2 交换 $(0\,1)$ 也达。于是对任意 $i$，共轭 $\rho^{i}(0\,1)\rho^{-i} = (i,\ i+1)$ 均可达（$\rho^{-1}$ 可由 $\rho^{n-1}$ 实现）。相邻对换 $(0\,1), (1\,2), \dots, (n-2,\ n-1)$ 生成整个对称群 $S_n$，故 $G = S_n$。∎

**引理 4（升序排列是字典序最小）**：在所有字符多重集相同的字符串中，升序排列的字典序最小。

**证明**：设 $t$ 为升序排列。若某字符串 $u \ne t$ 在第一个不同位置 $i$ 有 $u[i] > t[i]$（由 $t$ 的构造，$t[i]$ 是该多重集中第 $i$ 小的字符，故 $u[i] \ge t[i]$，且 $u \ne t$ 意味着存在严格大于的位置），则 $u > t$。故 $t$ 最小。∎

**定理**：算法返回的正是可达字符串中字典序最小者。

**证明**：$k = 1$ 时，由引理 1 可达集为全部循环移位，算法取其中最小者，正确。$k \ge 2$ 时，由引理 3 可达集包含 $s$ 的全部排列（字符多重集相同的所有字符串），由引理 4 升序排列最小，算法返回 `sorted(s)`，正确。∎

## 6. 复杂度分析

- **时间**：
  - $k \ge 2$：排序 $O(n \log n)$（小写字母可用计数排序优化到 $O(n)$）。
  - $k = 1$：生成并比较 $n$ 个循环移位，每个 $O(n)$，共 $O(n^2)$；$n \le 1000$ 时可接受。若用 Booth 最小表示法可降到 $O(n)$。
- **空间**：$O(n)$（存储当前最优串；`sorted` 产生 $O(n)$ 字符的中间结果），除输入输出外无额外结构。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    string orderlyQueue(string s, int k) {
        if (k >= 2) {                              // 两个以上自由位 ⇒ 任意排列可达
            sort(s.begin(), s.end());
            return s;                              // 字典序最小就是升序排列
        }
        string best = s;                           // k == 1：只能循环左移
        for (int i = 1; i < (int)s.size(); i++) {
            best = min(best, s.substr(i) + s.substr(0, i));
        }
        return best;
    }
};
```

### Python

```python
class Solution:
    def orderlyQueue(self, s: str, k: int) -> str:
        if k >= 2:                              # 两个以上自由位 ⇒ 任意排列可达
            return "".join(sorted(s))           # 字典序最小就是升序排列
        # k == 1：只能把首字符移到末尾，等价于在所有循环移位里取最小
        return min(s[i:] + s[:i] for i in range(len(s)))
```

## 8. 边界情况与易错点

1. **$k \ge 2$ 千万不要用最小表示法**：示例 2 的 `aaabc` 与最小循环移位 `aacab` 不同，这是本题最大的陷阱。
2. **$k = 1$ 千万不要排序**：`"cba"` 排序得 `"abc"`，但 `abc` 不在可达集中（可达只有 `cba`、`bac`、`acb`）。
3. **$n = 1$**：两种分支都返回原串，注意 `s[i:] + s[:i]` 在 $i=0$ 时就是 `s`。
4. **重复字符**：循环移位可能重复（如 `"aa"`），枚举无妨，取最小即可。
5. **$k \ge n$**：等价于 $k \ge 2$，因为每次都只能从前 $n$ 个（即全部）里选，结论不变。
6. **$O(n^2)$ 的边界**：$n = 1000$ 时 $10^6$ 级别没问题；若题目把 $n$ 提到 $10^5$，必须换成 Booth 算法。
7. **字典序而非长度**：所有可达串长度相同，比较只看字典序；`min` 直接可用。
8. **操作可做 0 次**：所以 `s` 自身一定在可达集中，$k=1$ 的枚举要包含 $i=0$（代码里 `best = s` 已包含）。
