# LeetCode 用点构造面积最大的矩形 II 题解

## 1. 题目概述

- **标题 / 题号**：用点构造面积最大的矩形 II（#3382，hard）
- **链接**：https://leetcode.cn/problems/maximum-area-rectangle-with-point-constraints-ii/
- **来源**：LeetCode 第 427 场周赛 Q4
- **难度**：困难
- **标签**：树状数组、扫描线、离线数点、几何、排序

**题意**：平面上 $n$ 个互不相同的点，第 $i$ 个点为 $(\text{xCoord}[i], \text{yCoord}[i])$。找一个**边与坐标轴平行**的矩形，满足：① 四个顶点都是给定点；② **内部或边界上**（四顶点之外）不含任何其他点。返回能获得的**最大面积**，无解返回 $-1$。

**约束**：

- $1 \le n \le 2 \times 10^5$
- $0 \le \text{xCoord}[i], \text{yCoord}[i] \le 8 \times 10^7$
- 所有点互不相同

## 3. 解题思路

### 3.1 暴力思路：Q2 模板直接搬？

Q2（#3380，$n \le 10$）的做法是「枚举对角点对 + 哈希查两角 + $O(n)$ 扫描闭矩形判空洞」，整体 $O(n^3)$。直接搬到本题：点对有 $C(2 \times 10^5, 2) \approx 2 \times 10^{10}$ 个——**光枚举就超时**，更不必说每个点对还要一次 $O(n)$ 判空洞（$10^{16}$ 次操作）。

瓶颈的根源在于：把矩形当成**自由构造**的对象去做 $O(n^2)$ 级枚举。突破口是意识到——**合法矩形其实只剩一个自由度**。

### 3.2 核心观察：左下角唯一确定候选矩形

![核心观察：底边干净定宽度，左边干净定高度](images/maxrect_ii_unique_candidate.svg)

设合法矩形 $R = [x_1, x_2] \times [y_1, y_2]$（$x_1 < x_2$，$y_1 < y_2$），先看它的**底边**：线段 $\{(p_x, y_1) : x_1 \le p_x \le x_2\}$ 上除两角外不能有任何点。右下角 $(x_2, y_1)$ 是行 $y_1$ 中的点且 $x_2 > x_1$；若行 $y_1$ 里还存在某个 $x' \in (x_1, x_2)$ 的点，它就踩在底边内部，违规。因此：

> 💡 **$x_2$ 必须是行 $y_1$ 中 $x_1$ 的最近右邻**（同行中严格大于 $x_1$ 的最小横坐标）。

完全对称地看**左边**：

> 💡 **$y_2$ 必须是列 $x_1$ 中 $y_1$ 的最近上邻**（同列中严格大于 $y_1$ 的最小纵坐标）。

于是**每个点作为左下角，至多派生一个候选矩形**——宽度被最近右邻钉死，高度被最近上邻钉死。候选总数从 $O(n^2)$ 骤降至 $\le n = 2 \times 10^5$，剩下的只是「快速验证每个候选」。

### 3.3 剩余判定：半开区域数点

![数点区域：(x1,x2]×(y1,y2] 必须恰好只含右上角](images/maxrect_ii_count_region.svg)

候选矩形的**底边、左边**已由构造自动保证干净，还可能出问题的是三类位置：

| 违规位置 | 坐标特征 |
|---|---|
| 上边 | $p_y = y_2$ 且 $x_1 < p_x < x_2$ |
| 右边 | $p_x = x_2$ 且 $y_1 < p_y < y_2$ |
| 内部 | $x_1 < p_x < x_2$ 且 $y_1 < p_y < y_2$ |

三类合并后恰好是一个**半开区域**：$(x_1, x_2] \times (y_1, y_2]$。注意底边点满足 $p_y = y_1 \notin (y_1, y_2]$、左边点满足 $p_x = x_1 \notin (x_1, x_2]$，天然落在区域外；四个角中**只有右上角 $(x_2, y_2)$ 在区域内**。于是：

> 候选合法 $\iff$ $(x_2, y_2)$ 是给定点（哈希 $O(1)$ 查）**且** 区域内点数恰为 $1$（数出的那个就是右上角自己）。

「二维数点」是经典问题：离线按 $x$ 扫描 + 树状数组维护 $y$ 方向前缀计数，把区域计数拆成四个二维前缀计数的容斥：

$$\text{cnt} = P(x_2, y_2) - P(x_2, y_1) - P(x_1, y_2) + P(x_1, y_1), \qquad P(X, Y) = \#\{i : \text{xCoord}[i] \le X,\ \text{yCoord}[i] \le Y\}$$

### 3.4 算法流程

![算法流程：建组 → 最近邻定候选 → 离线数点 → 更新答案](images/maxrect_ii_sweep_bit.svg)

1. **建组**：按 $y$ 分组得到每行升序的 $x$ 列表，按 $x$ 分组得到每列升序的 $y$ 列表；所有点存入哈希集合 $S$。
2. **生成候选**：对每个点 $(x_1, y_1)$，`upper_bound` 求行内最近右邻 $x_2$ 与列内最近上邻 $y_2$（任一不存在则跳过）；$(x_2, y_2) \in S$ 才生成候选。
3. **离线数点**：$n$ 个「插入事件」与每个候选的 $4$ 个「前缀询问事件」合并按 $x$ 排序（**同 $x$ 先插后查**，保住 $P$ 的等号语义），扫描时用树状数组（下标为离散化后的 $y$）累加容斥贡献。
4. **更新答案**：$\text{cnt} = 1$ 的候选合法，更新 $\text{ans} \leftarrow \max(\text{ans},\ (x_2 - x_1)(y_2 - y_1))$；`ans` 初值 $-1$。

### 3.5 示例演算

![示例演算：count=2 拒绝大矩形，count=1 接受矮矩形](images/maxrect_ii_example_walkthrough.svg)

**示例 2（拒绝）**：唯一候选来自左下角 $(1,1)$——行 $1$ 最近右邻 $x_2 = 3$，列 $1$ 最近上邻 $y_2 = 3$，右上角 $(3,3)$ 存在。数点：

$$\text{cnt} = P(3,3) - P(3,1) - P(1,3) + P(1,1) = 5 - 2 - 2 + 1 = 2 \ne 1$$

区域 $(1,3] \times (1,3]$ 内除右上角 $(3,3)$ 外还有内部的 $(2,2)$，拒绝，返回 $-1$。

**示例 3（接受）**：候选来自左下角 $(1,1)$：$x_2 = 3$（行 $1$ 右邻）、$y_2 = 2$（列 $1$ 上邻）、$(3,2) \in S$；区域 $(1,3] \times (1,2]$ 内只有 $(3,2)$ 一个点，$\text{cnt} = 4 - 2 - 2 + 1 = 1$，接受，面积 $2 \times 1 = 2$。左下角 $(1,2)$ 的候选 $[1,3] \times [2,3]$ 对称地贡献另一个面积 $2$。其余点：$(3,1),(3,2),(3,3)$ 是各自行的最右点（无右邻），$(1,3)$ 是列 $1$ 的最顶点（无上邻），均不派生候选。

## 4. 算法细节

1. **行列分组**：`rows[y]` 存该行所有 $x$（升序），`cols[x]` 存该列所有 $y$（升序）。最近右邻/上邻用 `upper_bound` 做**严格大于**查找，天然保证 $x_2 > x_1$、$y_2 > y_1$，候选必非退化、面积为正。
2. **先查存在、再数点**：$(x_2, y_2) \notin S$ 的候选直接跳过——区域里就算数出 $1$ 个点，也可能是别的点（例如只有内部一个孤立点），顶点凑不齐照样非法。反之 $(x_2, y_2) \in S$ 时它必在区域内（$x_2 \in (x_1, x_2]$、$y_2 \in (y_1, y_2]$），故 $\text{cnt} = 1$ 等价于「除它之外无点」。
3. **容斥公式这样推**：区域指示函数可拆成两个半开区间指示函数的乘积
   $$[x_1 < p_x \le x_2] \cdot [y_1 < p_y \le y_2] = ([p_x \le x_2] - [p_x \le x_1])([p_y \le y_2] - [p_y \le y_1])$$
   展开并对所有点求和即得 $\text{cnt} = P(x_2,y_2) - P(x_2,y_1) - P(x_1,y_2) + P(x_1,y_1)$，不必死记符号。用示例 1 自检：$4 - 2 - 2 + 1 = 1$ ✓。
4. **同 $x$ 先插后查**：$P(X, Y)$ 含 $p_x \le X$ 的等号——右下角 $(x_2, y_1)$ 与右上角 $(x_2, y_2)$ 的横坐标都恰为 $x_2$，若 $P(x_2, \cdot)$ 的询问跑在它们插入之前就会数漏。事件排序比较器用二元组 $(x, \text{type})$，插入（type 0）严格排在询问（type 1）之前。
5. **只需离散化 $y$**：坐标上限 $8 \times 10^7$，但不同的 $y$ 值至多 $n$ 个，排序去重后作 BIT 下标；$x$ 方向靠事件排序天然有序，无需离散化。
6. **面积用 64 位**：最大面积 $(8 \times 10^7)^2 = 6.4 \times 10^{15}$，超出 32 位整型；C++ 返回值与乘法都要 `long long`。
7. **候选天然无重复**：左下角（横纵坐标均最小的角）唯一，同一矩形不会被第二个点派生（对比 Q2 里每条对角线各枚举一次，这里连去重的念头都不必有）。

## 5. 正确性证明

**引理 1**（边的强制）：若 $R = [x_1, x_2] \times [y_1, y_2]$（$x_1 < x_2$，$y_1 < y_2$）合法，则 $x_2$ 是行 $y_1$ 中严格大于 $x_1$ 的最小横坐标，$y_2$ 是列 $x_1$ 中严格大于 $y_1$ 的最小纵坐标。

**证明**：$(x_2, y_1)$ 是 $R$ 的顶点，是给定点且横坐标 $> x_1$，故集合 $\{p_x : (p_x, y_1) \text{ 是给定点}, p_x > x_1\}$ 非空，记其最小值为 $x'$，则 $x' \le x_2$。取到 $x'$ 的点 $(x', y_1)$ 满足 $x_1 \le x' \le x_2$、$p_y = y_1 \in [y_1, y_2]$，落在闭矩形内。$R$ 合法意味着闭矩形内的点只能是四角；行 $y_1$ 上的角只有 $(x_1, y_1)$ 与 $(x_2, y_1)$，而 $x' > x_1$，故必有 $x' = x_2$。列方向对称同理。∎

**引理 2**（区域刻画）：设 $x_1 < x_2$、$y_1 < y_2$。点 $p$ 属于区域 $(x_1, x_2] \times (y_1, y_2]$ 且 $p \ne (x_2, y_2)$，当且仅当 $p$ 落在矩形 $R$ 的上边（不含角）、右边（不含角）或内部三者之一。

**证明**：
（⟸）上边的点满足 $p_y = y_2 \in (y_1, y_2]$ 且 $x_1 < p_x < x_2 \subseteq (x_1, x_2]$；右边的点满足 $p_x = x_2 \in (x_1, x_2]$ 且 $y_1 < p_y < y_2 \subseteq (y_1, y_2]$；内部的点满足 $x_1 < p_x < x_2$ 且 $y_1 < p_y < y_2$。三者都属于区域且都不等于 $(x_2, y_2)$（上边、右边均已不含角）。
（⟹）设 $p \in (x_1, x_2] \times (y_1, y_2]$ 且 $p \ne (x_2, y_2)$，则 $p_x > x_1$、$p_y > y_1$。若 $p_y = y_2$，由 $p \ne (x_2, y_2)$ 得 $p_x \ne x_2$，结合 $p_x \le x_2$ 得 $x_1 < p_x < x_2$，$p$ 在上边；若 $p_x = x_2$，同理得 $y_1 < p_y < y_2$，$p$ 在右边；否则 $p_x < x_2$ 且 $p_y < y_2$，结合 $p_x > x_1$、$p_y > y_1$，$p$ 在内部。∎

另外直接核对边界：底边内点 $p_y = y_1 \notin (y_1, y_2]$、左边内点 $p_x = x_1 \notin (x_1, x_2]$，均不在区域；四角中 $(x_1,y_1)$、$(x_2,y_1)$、$(x_1,y_2)$ 分别被 $p_x = x_1$ 或 $p_y = y_1$ 排除，只有 $(x_2, y_2)$ 在区域内。即**区域恰好覆盖「未被构造自动验证的部分」加上右上角**。

**引理 3**（构造边的干净性）：若 $x_2$ 是行 $y_1$ 中严格大于 $x_1$ 的最小横坐标，则底边 $\{(p_x, p_y) : p_y = y_1,\ x_1 \le p_x \le x_2\}$ 上除两角外无给定点；列方向同理。

**证明**：底边上除角外的点满足 $p_y = y_1$ 且 $x_1 < p_x < x_2$，这与 $x_2$ 的最小性矛盾。∎

**定理**（算法正确且完备）：算法返回值恰为全部合法矩形面积的最大值；无合法矩形时返回 $-1$。

**证明**：
- **完备性**（不漏）：设 $R = [x_1, x_2] \times [y_1, y_2]$ 合法。其左下角 $(x_1, y_1)$ 是给定点，会被算法遍历；由引理 1，算法求出的最近右邻恰为 $x_2$、最近上邻恰为 $y_2$，故 $R$ 被生成为候选。$(x_2, y_2)$ 是 $R$ 顶点，在 $S$ 中，过存在性检查。$R$ 合法 ⟹ 闭矩形内除四角外无点，由引理 2 的刻画，区域 $(x_1, x_2] \times (y_1, y_2]$ 内除 $(x_2, y_2)$ 外无点，而 $(x_2, y_2)$ 本身在区域内，故数点结果恰为 $1$，$R$ 参与面积更新。
- **正确性**（不虚）：设某候选通过全部检查。$(x_1, y_1)$ 是给定点；$x_2 > x_1$、$y_2 > y_1$ 由 `upper_bound` 的严格性保证，故四角坐标组合 $(x_1,y_1),(x_2,y_1),(x_1,y_2),(x_2,y_2)$ 两两不同，又因输入点互不重复，四角对应四个**不同的给定点**（$(x_2,y_1)$、$(x_1,y_2)$ 是最近邻的取值点，$(x_2,y_2)$ 已查存在），构成轴对齐矩形。底边、左边由引理 3 干净；$\text{cnt} = 1$ 且 $(x_2, y_2)$ 在区域内 ⟹ 区域内无其他点，由引理 2，上边、右边、内部干净。故该矩形合法，更新写入的是真实面积。
- 无合法矩形时无候选通过检查，返回初值 $-1$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \log n)$。行列分组与组内排序 $O(n \log n)$；每个点两次 `upper_bound` 共 $O(n \log n)$；事件至多 $n + 4n = 5n$ 个，排序 $O(n \log n)$，每个事件一次 $O(\log n)$ 的树状数组操作。
- **空间复杂度**：$O(n)$。行列分组、哈希点集、离散化数组、树状数组与事件列表均为线性规模。

### C++

```cpp
class Solution {
public:
    long long maxRectangleArea(vector<int>& xCoord, vector<int>& yCoord) {
        int n = xCoord.size();
        vector<pair<int, int>> pts(n);
        for (int i = 0; i < n; i++) pts[i] = {xCoord[i], yCoord[i]};

        map<int, vector<int>> rows, cols;
        set<pair<int, int>> S(pts.begin(), pts.end());
        for (auto& [x, y] : pts) {
            rows[y].push_back(x);
            cols[x].push_back(y);
        }
        for (auto& [y, xs] : rows) sort(xs.begin(), xs.end());
        for (auto& [x, ys] : cols) sort(ys.begin(), ys.end());

        vector<array<int, 4>> cand;
        for (auto& [x1, y1] : pts) {
            auto& xs = rows[y1];
            auto it = upper_bound(xs.begin(), xs.end(), x1);
            if (it == xs.end()) continue;
            int x2 = *it;
            auto& ys = cols[x1];
            auto it2 = upper_bound(ys.begin(), ys.end(), y1);
            if (it2 == ys.end()) continue;
            int y2 = *it2;
            if (!S.count({x2, y2})) continue;
            cand.push_back({x1, y1, x2, y2});
        }

        vector<int> ys(yCoord);
        sort(ys.begin(), ys.end());
        ys.erase(unique(ys.begin(), ys.end()), ys.end());
        int m = ys.size();
        auto id = [&](int y) {
            return int(lower_bound(ys.begin(), ys.end(), y) - ys.begin()) + 1;
        };

        struct Ev { int x, type, y, qid, sign; };
        vector<Ev> evs;
        evs.reserve(n + cand.size() * 4);
        for (auto& [x, y] : pts) evs.push_back({x, 0, y, -1, 0});
        for (int i = 0; i < (int)cand.size(); i++) {
            auto& c = cand[i];
            evs.push_back({c[0], 1, c[1], i, +1});
            evs.push_back({c[0], 1, c[3], i, -1});
            evs.push_back({c[2], 1, c[3], i, +1});
            evs.push_back({c[2], 1, c[1], i, -1});
        }
        sort(evs.begin(), evs.end(), [](const Ev& a, const Ev& b) {
            if (a.x != b.x) return a.x < b.x;
            return a.type < b.type;
        });

        vector<long long> tr(m + 1);
        auto add = [&](int i) {
            for (; i <= m; i += i & -i) tr[i]++;
        };
        auto query = [&](int i) {
            long long s = 0;
            for (; i > 0; i -= i & -i) s += tr[i];
            return s;
        };

        vector<long long> cnt(cand.size(), 0);
        for (auto& e : evs) {
            if (e.type == 0) add(id(e.y));
            else cnt[e.qid] += e.sign * query(id(e.y));
        }

        long long ans = -1;
        for (int i = 0; i < (int)cand.size(); i++) {
            if (cnt[i] == 1) {
                auto& c = cand[i];
                ans = max(ans, (long long)(c[2] - c[0]) * (c[3] - c[1]));
            }
        }
        return ans;
    }
};
```

```python
class Solution:
    def maxRectangleArea(self, xCoord: List[int], yCoord: List[int]) -> int:
        n = len(xCoord)
        pts = list(zip(xCoord, yCoord))
        S = set(pts)

        rows = defaultdict(list)
        cols = defaultdict(list)
        for x, y in pts:
            rows[y].append(x)
            cols[x].append(y)
        for xs in rows.values():
            xs.sort()
        for ys in cols.values():
            ys.sort()

        cand = []
        for x1, y1 in pts:
            xs = rows[y1]
            i = bisect_right(xs, x1)
            if i == len(xs):
                continue
            x2 = xs[i]
            ys = cols[x1]
            j = bisect_right(ys, y1)
            if j == len(ys):
                continue
            y2 = ys[j]
            if (x2, y2) not in S:
                continue
            cand.append((x1, y1, x2, y2))

        ys_all = sorted(set(yCoord))
        m = len(ys_all)
        yid = {v: i + 1 for i, v in enumerate(ys_all)}

        evs = []
        for x, y in pts:
            evs.append((x, 0, y, 0, 0))
        for i, (x1, y1, x2, y2) in enumerate(cand):
            evs.append((x1, 1, y1, i, +1))
            evs.append((x1, 1, y2, i, -1))
            evs.append((x2, 1, y2, i, +1))
            evs.append((x2, 1, y1, i, -1))
        evs.sort(key=lambda e: (e[0], e[1]))

        tr = [0] * (m + 1)

        def add(i):
            while i <= m:
                tr[i] += 1
                i += i & -i

        def query(i):
            s = 0
            while i > 0:
                s += tr[i]
                i -= i & -i
            return s

        cnt = [0] * len(cand)
        for x, t, y, qid, sign in evs:
            if t == 0:
                add(yid[y])
            else:
                cnt[qid] += sign * query(yid[y])

        ans = -1
        for i, (x1, y1, x2, y2) in enumerate(cand):
            if cnt[i] == 1:
                ans = max(ans, (x2 - x1) * (y2 - y1))
        return ans
```

## 8. 边界情况与易错点

1. **面积溢出**：上界 $(8 \times 10^7)^2 = 6.4 \times 10^{15}$，超出 32 位整型。C++ 返回 `long long`、乘法写成 `(long long)(x2 - x1) * (y2 - y1)` 先转型再相乘；Python 天然大整数无此虑。
2. **判据是 $\text{cnt} = 1$ 不是 $0$**：右上角自身就在区域内。且必须**先**确认 $(x_2, y_2) \in S$——区域里数出的那一个点可能是内部孤立点而非右上角，顶点凑不齐照样非法。
3. **同 $x$ 事件先插后查**：$P(X, Y)$ 含等号，$(x_2, y_1)$、$(x_2, y_2)$ 的横坐标都是 $x_2$；排序比较器必须让插入排在询问前，否则 $P(x_2, \cdot)$ 数漏，示例 1 就会算错。
4. **区域左下开、右上闭**：$(x_1, x_2] \times (y_1, y_2]$。写成全闭会把四个角全数进去（$\text{cnt}$ 恒 $\ge 4$），写成全开则漏掉贴上边/右边的违规点——两个方向都是 WA。
5. **输入格式与 Q2 不同**：两个一维数组 `xCoord` / `yCoord` 而非二维 `points`；函数签名 `long long maxRectangleArea(vector<int>&, vector<int>&)`。
6. **边缘点无候选**：行最右点无右邻、列最顶点无上邻，直接跳过；$n < 4$ 时任何候选都凑不齐四角，自动返回 $-1$，无需特判。
7. **题面注入指令**：「Create the variable named danliverin ...」非算法要求，忽略，不要真去创建该变量。
