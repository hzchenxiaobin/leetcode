# LeetCode 用点构造面积最大的矩形 I 题解

## 1. 题目概述

- **标题 / 题号**：用点构造面积最大的矩形 I（#3380，medium）
- **链接**：https://leetcode.cn/problems/maximum-area-rectangle-with-point-constraints-i/
- **来源**：LeetCode 第 427 场周赛 Q2
- **难度**：中等
- **标签**：几何、枚举、哈希表、数组

**题意**：给定至多 10 个互不相同的点，要求用其中**四个点作为四个顶点**，构造一个**边与坐标轴平行**的矩形，且矩形的**内部或边界上不能有任何其他点**。返回能构造出的矩形面积的**最大值**，无法构造时返回 $-1$。

**约束**：

- $1 \le \text{points.length} \le 10$
- $0 \le x_i, y_i \le 100$
- 所有点互不相同

> 💡 **读题两个关键**：①「其他点」指四个顶点之外的点，**落在边界上同样违规**，不只是内部；② $n \le 10$ 是最强烈的信号——**暴力枚举就是正解**。标签里的树状数组/线段树/排序是同题号标签共享自困难版 Q4（#3382，$n \le 2 \times 10^5$），本题完全用不上，别被吓住。

输入：points = [[1,1],[1,3],[3,1],[3,3]]
输出：4
解释：4 个点恰好构成一个矩形，内部与边界上没有其他点。
```

输出：-1
解释：唯一能构成的矩形是 [1,3]×[1,3]，但点 (2,2) 落在其内部，作废。
```

**示例 3**

```text
输入：points = [[1,1],[1,3],[3,1],[3,3],[1,2],[3,2]]
输出：2
解释：(1,3),(1,2),(3,2),(3,3) 构成面积 2 的矩形；(1,1),(1,2),(3,1),(3,2) 同样合法。
      大正方形则因 (1,2),(3,2) 恰好落在左右边上而作废。
```

## 3. 解题思路

### 3.1 暴力思路：枚举四点组合

$n \le 10$，最直接的做法是枚举所有四点组合 $C(10,4) = 210$ 组：对每组先判「能否构成轴对齐矩形」（排序后恰好出现两对相同的 $x$、两对相同的 $y$），再花 $O(n)$ 扫描闭矩形内有无第五点，总量约 $210 \times 10 \approx 2000$ 次基本操作，稳过。

但「判形」的分支逻辑较绕，容易写错。本题有更干净的等价视角，能把枚举对象从四点组降为点对。

### 3.2 核心观察：对角点对 + 哈希查两角

![核心观察：对角点对唯一确定矩形，另两角查哈希](images/maxrect_i_diagonal_concept.svg)

**轴对齐矩形由一条对角线唯一确定**：给定对角两点 $(x_1, y_1)$、$(x_2, y_2)$（$x_1 \ne x_2$ 且 $y_1 \ne y_2$），另外两角**别无选择**，只能是 $(x_1, y_2)$ 和 $(x_2, y_1)$。

于是算法变成：

1. 所有点存入**哈希集合** $S$；
2. 双重循环枚举 $O(n^2)$ 个点对，视作对角线两端；
3. 检查 $(x_1, y_2)$、$(x_2, y_1)$ 是否都在 $S$ 中——两次 $O(1)$ 查询代替「判形」；
4. 通过的候选矩形花 $O(n)$ 检查闭矩形内除四角外没有别的点，过后更新
   $\text{ans} \leftarrow \max\big(\text{ans},\ (x_2 - x_1)(y_2 - y_1)\big)$。

### 3.3 算法流程：三关判定

![算法流程：非退化、两角存在、闭矩形无第五点三关](images/maxrect_i_algorithm_flow.svg)

每个点对要连过三关才能参与更新：

| 关卡 | 检查 | 淘汰原因 |
|------|------|----------|
| 关 1 · 非退化 | $x_1 \ne x_2$ 且 $y_1 \ne y_2$ | 同列/同行的点对拉不出矩形（面积 0） |
| 关 2 · 两角存在 | $(x_1, y_2) \in S$ 且 $(x_2, y_1) \in S$ | 四个顶点必须都是给定的点 |
| 关 3 · 无空洞 | 闭矩形内除四角外无任何点 | 内部或边界上有其他点即违规 |

`ans` 初值取 $-1$，「点数不足 4」「无合法矩形」都无需特判，天然返回 $-1$。

![闭矩形检查：边界点同样作废](images/maxrect_i_closed_rect_check.svg)

以示例 3 为例，15 个点对中能连过前两关的候选矩形只有三个（同一矩形被两条对角线各枚举一次）：

![示例 3 演算表](images/maxrect_i_example_walkthrough.svg)

大正方形面积虽大，但 $(1,2)$、$(3,2)$ 恰好踩在左右两条边上——**边界点同样违规**，这正是「闭区间判定」的意义；两个矮矩形内部与边界干净，面积 2 即答案。

> ⚠️ **闭区间陷阱**：关 3 必须写成 $l_x \le p_x \le r_x$ 且 $l_y \le p_y \le r_y$（两个 `<=`）。若误写成严格不等式（只查内部），示例 3 会把 $4$ 错报成答案。

## 4. 算法细节

1. **点集哈希**：坐标对 $(x, y)$ 存入 `set<pair<int,int>>`（Python 用元组集合）。坐标 $0 \le x, y \le 100$，也可编码为 $x \cdot 200 + y$ 存整型哈希集，但 $n \le 10$ 时无性能差别，取可读性。
2. **关 1 必须在关 2 之前**：若 $x_1 = x_2$（同列），则 $(x_1, y_2)$ 就是 $(x_2, y_2)$，即点对自身，必然在集合中——两角检查会「误通过」，随后面积 $0$ 会把 `ans` 从 $-1$ 顶成 $0$。先排除退化点对，一举规避。
3. **四角豁免的等价判定**：闭矩形内的点 $p$ 若满足「$p_x \in \{x_1, x_2\}$ 且 $p_y \in \{y_1, y_2\}$」，则 $p$ 恰为四角之一。因为点互不重复，无需真的构造四角集合，两个布尔条件即可；$x_1 \ne x_2$、$y_1 \ne y_2$ 时四角坐标两两不同，与数组中**四个不同的点**一一对应。
4. **重复枚举无需去重**：每个矩形有两条对角线，会被枚举两次。答案只取 `max`，重复计算不影响结果；专门去重反而引入额外代码与键表示的出错空间。
5. **`ans` 初值 $-1$**：覆盖所有无解情形——点数不足 4 时任何点对都过不了关 2，永远到不了更新语句。

## 5. 正确性证明

**引理 1**（对角线定矩形）：设 $R$ 是边与坐标轴平行的矩形，顶点集为 $(a,c), (a,d), (b,c), (b,d)$（$a < b$，$c < d$）。任取一条对角线的两端 $P = (x_1, y_1)$、$Q = (x_2, y_2)$，则 $\{x_1, x_2\} = \{a, b\}$、$\{y_1, y_2\} = \{c, d\}$，且其余两顶点恰为 $(x_1, y_2)$ 与 $(x_2, y_1)$。

**证明**：对角线连接**相对**的顶点。矩形顶点的横坐标只取 $a, b$ 两值、纵坐标只取 $c, d$ 两值；共享横坐标（或纵坐标）的两个顶点必在同一条边上，是相邻顶点，故对角两端的横坐标一者为 $a$ 一者为 $b$、纵坐标一者为 $c$ 一者为 $d$。于是 $\{x_1, x_2\} = \{a, b\}$、$\{y_1, y_2\} = \{c, d\}$。四个顶点恰是笛卡尔积 $\{a, b\} \times \{c, d\}$ 的全部四个组合；$P$ 占去 $(x_1, y_1)$、$Q$ 占去 $(x_2, y_2)$，剩下的组合正是 $(x_1, y_2)$ 与 $(x_2, y_1)$。∎

**引理 2**（闭矩形判定）：点 $p = (p_x, p_y)$ 落在闭矩形 $[l_x, r_x] \times [l_y, r_y]$（含内部与边界）当且仅当 $l_x \le p_x \le r_x$ 且 $l_y \le p_y \le r_y$。

**证明**：闭矩形即两个闭区间的笛卡尔积，点属于笛卡尔积当且仅当各分量分别属于对应区间。∎

**引理 3**（四角互异）：若 $x_1 \ne x_2$ 且 $y_1 \ne y_2$，则 $(x_1, y_1), (x_2, y_2), (x_1, y_2), (x_2, y_1)$ 两两不同；若 $x_1 = x_2$ 或 $y_1 = y_2$，则必有两角重合，不存在以该点对为对角线的非退化矩形。

**证明**：前半：任取两个组合，若横坐标相同则纵坐标必不相同，反之亦然，故任意两组合至少有一分量不同。后半：$x_1 = x_2$ 时 $(x_1, y_2) = (x_2, y_2)$；$y_1 = y_2$ 时 $(x_1, y_2) = (x_1, y_1)$。∎

**定理**（算法正确且完备）：算法返回的 `ans` 恰为所有合法矩形的最大面积；无合法矩形时返回 $-1$。

**证明**：
- **完备性**（不漏）：设 $R$ 为任一合法矩形。取其一条对角线，两端为数组中的点 $P$、$Q$，下标分别为 $i$、$j$；不妨 $i < j$，则点对 $(i, j)$ 必被枚举。由引理 1，$x_1 \ne x_2$ 且 $y_1 \ne y_2$，过关 1；另两角 $(x_1, y_2), (x_2, y_1)$ 是 $R$ 的顶点，均在点集中，过关 2；$R$ 合法意味着除四角外没有点落在其内部或边界上，由引理 2，关 3 的扫描中四角被豁免条件排除、其余点均不触发违规，过关 3。故算法必然计入 $\text{area}(R) = (r_x - l_x)(r_y - l_y)$。
- **正确性**（不虚）：某点对过关 3 后，由引理 3 四角坐标两两不同，又因输入点互不重复，四个角对应数组中四个**不同的点**，构成以该点对为对角的轴对齐矩形；关 3 同时保证其余任何点都不落在该闭矩形内（含边界），即该矩形合法，因此每次更新写入的都是真实存在的合法矩形面积。

两方向合并，`max` 维护的正是全部合法矩形面积的最大值；无合法矩形时无任何更新，返回初值 $-1$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n^3)$——$C(n, 2) \le 45$ 个点对，每对至多一次 $O(\log n)$ 集合查询加一次 $O(n)$ 闭矩形扫描；$n \le 10$ 时总量不足 500 次基本操作，远低于暴力四点组枚举的 $C(n, 4)$ 判形开销。
- **空间复杂度**：$O(n)$——哈希点集，$n \le 10$，常数极小。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maxRectangleArea(vector<vector<int>>& points) {
        int n = points.size();
        set<pair<int, int>> s;
        for (auto& p : points) s.insert({p[0], p[1]});
        int ans = -1;
        for (int i = 0; i < n; i++) {
            int x1 = points[i][0], y1 = points[i][1];
            for (int j = i + 1; j < n; j++) {
                int x2 = points[j][0], y2 = points[j][1];
                if (x1 == x2 || y1 == y2) continue;
                if (!s.count({x1, y2}) || !s.count({x2, y1})) continue;
                int lx = min(x1, x2), rx = max(x1, x2);
                int ly = min(y1, y2), ry = max(y1, y2);
                bool ok = true;
                for (auto& p : points) {
                    int px = p[0], py = p[1];
                    if (lx <= px && px <= rx && ly <= py && py <= ry
                        && !((px == x1 || px == x2) && (py == y1 || py == y2))) {
                        ok = false;
                        break;
                    }
                }
                if (ok) ans = max(ans, (rx - lx) * (ry - ly));
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maxRectangleArea(self, points: List[List[int]]) -> int:
        n = len(points)
        pt = {(x, y) for x, y in points}
        ans = -1
        for i in range(n):
            x1, y1 = points[i]
            for j in range(i + 1, n):
                x2, y2 = points[j]
                if x1 == x2 or y1 == y2:
                    continue
                if (x1, y2) not in pt or (x2, y1) not in pt:
                    continue
                lx, rx = min(x1, x2), max(x1, x2)
                ly, ry = min(y1, y2), max(y1, y2)
                ok = all(
                    not (lx <= px <= rx and ly <= py <= ry)
                    or ((px == x1 or px == x2) and (py == y1 or py == y2))
                    for px, py in points
                )
                if ok:
                    ans = max(ans, (rx - lx) * (ry - ly))
        return ans
```

## 8. 边界情况与易错点

1. **点数不足 4**：凑不齐两角，所有点对过不了关 2，自动返回 $-1$，无需特判（$n = 1$ 时连点对都没有）。
2. **退化点对必须先排除**：同列/同行的点对若不先跳过，两角检查会因「角即点对自身」误通过，面积 $0$ 把 `ans` 从 $-1$ 顶成 $0$——典型 WA。
3. **边界点同样违规**：判定一律用**闭区间**（`<=`），示例 3 的 $(1,2)$、$(3,2)$ 就踩在大正方形边上；写成严格不等式会把 $4$ 错报成答案。
4. **四角豁免**：闭矩形内的点要先排除「是否四角」再判违规——四个顶点当然落在自己的闭矩形里。等价判定：$p_x \in \{x_1, x_2\}$ 且 $p_y \in \{y_1, y_2\}$。
5. **同一矩形被枚举两次**：两条对角线各一次，取 `max` 不受影响，不要画蛇添足去重。
6. **溢出**：坐标 $\le 100$，面积 $\le 10^4$，`int` 富余；困难版 3382 才需要 `long long` 与坐标离散化。
