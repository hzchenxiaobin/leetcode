# LeetCode 丑数 III 题解

## 1. 题目概述

- **标题 / 题号**：丑数 III（#1201，medium）
- **链接**：https://leetcode.cn/problems/ugly-number-iii/
- **来源**：LeetCode 第 155 场周赛 Q2
- **难度**：中等
- **标签**：数学、二分查找、容斥原理、数论、最大公约数、最小公倍数、组合数学

**题意**：给定 $n, a, b, c$，称一个正整数为「丑数」，当且仅当它能被 $a$、$b$、$c$ 中至少一个整除。把丑数按升序排成序列，返回其中的第 $n$ 个。

**约束**：
- $1 \le n, a, b, c \le 10^9$
- $1 \le a \cdot b \cdot c \le 10^{18}$ —— 意味着 $\mathrm{lcm}(a,b,c)$ 最大可达 $10^{18}$，必须用 64 位整数
- 保证答案落在 $[1, 2 \times 10^9]$ 内 —— 这是二分的现成上界

> 💡 别被名字骗了：本题的「丑数」与 [264. 丑数 II](https://leetcode.cn/problems/ugly-number-ii/) 里「质因数只有 2、3、5」的丑数**完全是两个模型**。后者靠三指针 DP 逐项生成，本题靠「计数 + 二分答案」。

## 2. 示例

**示例 1**

输入：n = 3, a = 2, b = 3, c = 5
输出：4
解释：丑数序列为 2, 3, 4, 5, 6, 8, 9, 10, ...
      第 3 个是 4（注意 1 不是丑数，它不能被 2/3/5 整除）。
```

**示例 2**

输入：n = 4, a = 2, b = 3, c = 4
输出：6
解释：丑数序列为 2, 3, 4, 6, 8, 9, 10, 12, ...
      第 4 个是 6；这里 lcm(2,4) = 4，4 只算一次，容斥必须去重。
```

**示例 3**

```text
输入：n = 5, a = 2, b = 11, c = 13
输出：10
解释：丑数序列为 2, 4, 6, 8, 10, 11, 12, 13, ...
      第 5 个是 10；11、13 是「只被一个数整除」的稀疏项。
```

## 3. 解题思路

### 3.1 暴力思路

**做法 A（枚举 + 判定）**：从 $x = 1$ 开始逐个判断 $x$ 能否被 $a$、$b$、$c$ 整除，数到第 $n$ 个为止。单次判定 $O(1)$，但要枚举到答案本身——答案最大 $2\times 10^9$，最坏 $2\times 10^9$ 次循环，必然超时。更糟的是丑数在数轴上越来越稀疏（$a=b=c=10^9$ 时相邻两项差 $10^9$），枚举几乎全是白跑。

**做法 B（多路归并 / 三指针）**：像 264 题那样从 $a,b,c$ 出发每次取最小值并去重。但它必须**逐项生成** $n$ 个丑数，$n = 10^9$ 同样不可行。两者的共同瓶颈是复杂度依赖 $n$（或答案本身），破局点在于：把「求第 $n$ 个」换成「数一数 $\le x$ 的有几个」，后者可以 $O(1)$ 完成，于是复杂度只依赖**答案的数值范围**，可以二分。

### 3.2 核心观察：容斥原理在 O(1) 内计数

![容斥原理：单集合计数与重复统计](images/wc155_q2_ugly_count_inclusion.svg)

记 $A = \{x : a \mid x\}$，$B = \{x : b \mid x\}$，$C = \{x : c \mid x\}$，则 $x$ 是丑数 $\iff x \in A \cup B \cup C$。定义

$$\mathrm{count}(x) = \#\{\,k \in [1, x] : k \in A \cup B \cup C\,\}$$

在 $[1, x]$ 中，$a$ 的倍数有 $\lfloor x/a \rfloor$ 个；$A \cap B$ 中的数必须同时被 $a$ 和 $b$ 整除，即被 $L_{ab} = \mathrm{lcm}(a,b)$ 整除，共 $\lfloor x/L_{ab} \rfloor$ 个。由容斥原理

$$\mathrm{count}(x)=\left\lfloor\frac{x}{a}\right\rfloor+\left\lfloor\frac{x}{b}\right\rfloor+\left\lfloor\frac{x}{c}\right\rfloor-\left\lfloor\frac{x}{L_{ab}}\right\rfloor-\left\lfloor\frac{x}{L_{ac}}\right\rfloor-\left\lfloor\frac{x}{L_{bc}}\right\rfloor+\left\lfloor\frac{x}{L_{abc}}\right\rfloor$$

其中 $L_{abc} = \mathrm{lcm}(a,b,c)$。七次整数除法即可求值，$O(1)$。**这一步的意义**：`count` 是「可以被反复调用的廉价判定器」。只要判定器单次 $O(1)$，`count` 又单调，第 $n$ 个就变成了一个 lower_bound。

### 3.3 单调性 → 对答案二分

![count(x) 单调非降，二分找第一个 ≥ n 的位置](images/wc155_q2_binary_search_answer.svg)

$x$ 变大时 $[1,x]$ 只增不减，故 $\mathrm{count}$ 单调非降。于是

$$\text{第 } n \text{ 个丑数} = \min\{x \ge 1 : \mathrm{count}(x) \ge n\}$$

这是标准的下界二分，在 $[1, 2\times 10^9]$ 上搜索：

```text
lo = 1, hi = 2 * 10^9
while lo < hi:
    mid = (lo + hi) // 2
    if count(mid) >= n: hi = mid        # mid 可能就是答案，不能丢弃
    else:               lo = mid + 1
return lo
```

**为什么是 `hi = mid` 而不是 `mid - 1`**：`count` 是阶梯函数，一段平台上取值相同；当 $\mathrm{count}(mid) \ge n$ 时答案可能**正好**是 `mid`，把它排除就错了。反过来 $\mathrm{count}(mid) < n$ 时 `mid` 一定不是答案，才可以 `lo = mid + 1`。

## 4. 算法细节

1. **lcm 先除后乘**：$\mathrm{lcm}(x,y) = x / \gcd(x,y) \cdot y$。若先乘后除，$a \cdot b$ 可达 $10^{18}$，再乘 $c$ 就溢出；先除把中间值压到不超过 $10^{18}$。
2. **三个 lcm 分两层算**：先求 $L_{ab}, L_{ac}, L_{bc}$，再求 $L_{abc} = \mathrm{lcm}(L_{ab}, c)$，共 6 次 `gcd`，且只在二分之前算一次。
3. **全部用 64 位**：$L_{abc}$ 可达 $10^{18}$，C++ 里 `int` 会直接算错，统一转 `long long`；Python 大整数天然安全。
4. **上界取 $2\times 10^9$**：题面已保证答案范围，写死在代码里最简单。也可以取 $\min(a,b,c)\cdot n$，但它最大 $10^{18}$（需要 `long long`）且要多跑约 30 轮，没有收益。
5. **二分用下界形态**：`while (lo < hi)` + `hi = mid`，保证结束时 `lo` 是最小满足者。用 `while (lo <= hi)` + `hi = mid - 1` 的写法必须额外记录答案，否则可能返回不满足条件的位置。
6. **重复元素不需要特判**：$a = b$ 时 $L_{ab} = a$，公式自动退化为对 $\{a, c\}$ 两个集合的容斥；$a=b=c$ 时会一路化简成 $\lfloor x/a \rfloor$。手写去重反而容易引入 bug。
7. **把 `count` 写成闭包**：lcm 在闭包外算好，闭包内只做整数除法，既避免重复计算也保持二分主体干净。
8. **不需要处理 $x=0$**：`count(0) = 0 < n`，`lo` 从 1 起步即可，不必单独讨论。

## 5. 正确性证明

**引理 1（计数公式）**：对任意正整数 $x$，$\mathrm{count}(x)$ 等于 §3.2 中的七项表达式。

**证明**：由容斥原理，

$$\lvert A \cup B \cup C\rvert = \lvert A\rvert + \lvert B\rvert + \lvert C\rvert - \lvert A \cap B\rvert - \lvert A \cap C\rvert - \lvert B \cap C\rvert + \lvert A \cap B \cap C\rvert .$$

在 $[1,x]$ 中，$a$ 的倍数是 $a, 2a, \dots, \lfloor x/a\rfloor a$，共 $\lfloor x/a \rfloor$ 个；$A \cap B$ 中的数同时被 $a, b$ 整除 $\iff$ 被 $\mathrm{lcm}(a,b)$ 整除，共 $\lfloor x/L_{ab}\rfloor$ 个；$A \cap B \cap C$ 同理为 $\lfloor x/L_{abc}\rfloor$ 个。逐项代入即得。∎

**引理 2（单调性）**：$x_1 \le x_2 \Rightarrow \mathrm{count}(x_1) \le \mathrm{count}(x_2)$。

**证明**：$[1,x_1] \subseteq [1,x_2]$，其中的丑数集合也是子集，故计数不减。∎

**引理 3（最小满足者就是答案）**：令 $x^{*} = \min\{x \ge 1 : \mathrm{count}(x) \ge n\}$，则 $x^{*}$ 是丑数，且它是第 $n$ 个丑数。

**证明**：先证 $x^{*}$ 是丑数。若 $x^{*}$ 不被 $a, b, c$ 中任何一个整除，则 $[1,x^{*}]$ 与 $[1,x^{*}-1]$ 含有的丑数完全相同，$\mathrm{count}(x^{*}) = \mathrm{count}(x^{*}-1)$；由 $x^{*}$ 的最小性有 $\mathrm{count}(x^{*}-1) < n$，从而 $\mathrm{count}(x^{*}) < n$，与其定义矛盾。所以 $x^{*} \in A \cup B \cup C$，即 $x^{*}$ 是丑数，于是

$$\mathrm{count}(x^{*}) = \mathrm{count}(x^{*}-1) + 1 .$$

结合 $\mathrm{count}(x^{*}-1) < n \le \mathrm{count}(x^{*})$ 得到 $\mathrm{count}(x^{*}) = n$。也就是说，$[1,x^{*}]$ 内恰好有 $n$ 个丑数，而 $x^{*}$ 是其中最大的一个，故 $x^{*}$ 就是第 $n$ 个丑数。∎

**定理**：上述二分过程返回 $x^{*}$，即第 $n$ 个丑数。

**证明**：维护不变量

$$P:\quad \mathrm{count}(lo-1) < n \quad\text{且}\quad \mathrm{count}(hi) \ge n .$$

初值 $lo=1$ 时 $\mathrm{count}(0) = 0 < n$；$hi = 2\times10^9$ 时，由题面「答案落在 $[1, 2\times10^9]$」及引理 3，$x^{*} \le hi$，再由引理 2 得 $\mathrm{count}(hi) \ge \mathrm{count}(x^{*}) = n$，故 $P$ 成立。

设 $P$ 成立时取 $mid = \lfloor (lo+hi)/2\rfloor$。若 $\mathrm{count}(mid) \ge n$，由 $x^{*}$ 的最小性得 $x^{*} \le mid$，令 $hi = mid$，则 $\mathrm{count}(hi)\ge n$ 仍成立，$lo$ 未变，$P$ 保持；若 $\mathrm{count}(mid) < n$，由最小性得 $x^{*} > mid$，即 $x^{*} \ge mid+1$，令 $lo = mid+1$，此时 $\mathrm{count}(lo-1) = \mathrm{count}(mid) < n$，且 $hi$ 未变，$P$ 保持。

每轮区间长度严格减小且不越界，循环必在 $lo = hi$ 时终止。此时 $P$ 给出 $\mathrm{count}(lo-1) < n \le \mathrm{count}(lo)$，即 $lo$ 是满足 $\mathrm{count}(\cdot) \ge n$ 的最小下标，由引理 3，$lo = x^{*}$ 就是第 $n$ 个丑数。∎

## 6. 复杂度分析

- **时间**：$O(\log U)$，其中 $U = 2\times 10^9$，约 31 轮。每轮一次 `count` 调用（7 次整数除法，常数时间）；二分前的 lcm 预处理是常数次 `gcd`，$O(\log \min(a,b,c))$。总时间 $O(\log U)$，与 $n$ 无关。
- **空间**：$O(1)$。只存 4 个 lcm 与二分的两个端点，无数组、无哈希表。

## 7. 参考代码

### C++

```cpp
#include <numeric>
using namespace std;

class Solution {
public:
    int nthUglyNumber(int n, int a, int b, int c) {
        long long A = a, B = b, C = c;
        auto lcm = [](long long x, long long y) {
            return x / std::gcd(x, y) * y;   // 先除后乘，防溢出
        };
        long long ab = lcm(A, B), ac = lcm(A, C), bc = lcm(B, C);
        long long abc = lcm(ab, C);

        auto count = [&](long long x) -> long long {
            return x / A + x / B + x / C
                 - x / ab - x / ac - x / bc
                 + x / abc;
        };

        long long lo = 1, hi = 2000000000LL;
        while (lo < hi) {
            long long mid = lo + (hi - lo) / 2;
            if (count(mid) >= n) hi = mid;   // mid 可能就是答案
            else lo = mid + 1;
        }
        return (int)lo;
    }
};
```

### Python

```python
from math import gcd


class Solution:
    def nthUglyNumber(self, n: int, a: int, b: int, c: int) -> int:
        ab = a // gcd(a, b) * b
        ac = a // gcd(a, c) * c
        bc = b // gcd(b, c) * c
        abc = ab // gcd(ab, c) * c

        def count(x: int) -> int:
            return (x // a + x // b + x // c
                    - x // ab - x // ac - x // bc
                    + x // abc)

        lo, hi = 1, 2 * 10 ** 9
        while lo < hi:
            mid = (lo + hi) // 2
            if count(mid) >= n:
                hi = mid
            else:
                lo = mid + 1
        return lo
```

## 8. 边界情况与易错点

1. **$a = b = c$**：例如 $n=2,\ a=b=c=10^9$，答案是 $2\times10^9$（正好落在上界端点）。此时四个 lcm 全部等于 $10^9$，公式自动化简为 $\lfloor x/10^9 \rfloor$，**不要**加特判。
2. **溢出**：$L_{abc}$ 最大 $10^{18}$，C++ 用 `int` 存 lcm 会算错；即使 `long long` 也必须「先除后乘」，写成 `x * y / gcd(x, y)` 在 $x,y \approx 10^9$ 时不会溢出，但推广到 $10^{18}$ 量级就会。
3. **上界必须包含答案**：`hi = 2e9` 是闭区间端点。写成 `hi = 2e9 - 1`，或把区间当半开处理，当答案恰为 $2\times10^9$ 时会返回错误值。
4. **二分形态**：必须是 `hi = mid`（而不是 `mid - 1`）配 `while (lo < hi)`。写成 `lo <= hi` + `hi = mid - 1` 而不记录答案，会在最后一次收缩后返回一个**不满足条件**的位置。
5. **$n = 1$**：答案是 $\min(a,b,c)$。可自查 $\mathrm{count}(\min-1) = 0$、$\mathrm{count}(\min) = 1$，二分应恰好返回 $\min$。
6. **某个 lcm 等于单个数**：如 $a=2, b=4$，则 $L_{ab} = 4$，会出现「减 $x/4$、再加 $x/4$」的项，这是容斥的正常现象，公式整体仍正确；手动去重或省略项反而会错。
7. **不要试图生成序列**：相邻丑数的间隔没有常数上界（$a=b=c=10^9$ 时间隔就是 $10^9$），任何「逐项生成」的做法在 $n=10^9$ 时都不可行。

**延伸思考**：

1. **除数扩展到 $m$ 个**：若给定除数集合 $d_1,\dots,d_m$（$m \le 20$），容斥要枚举 $2^m - 1$ 个非空子集，每个子集算一次 lcm，单次 `count` 变成 $O(2^m \log)$，二分框架完全不变，总复杂度 $O(2^m \log U)$。这就是「第 $n$ 个能被给定集合中至少一个整除的数」的通解。
2. **改成「恰好被一个整除」**：设 $S_1$ 为三个单集合计数之和、$S_2$ 为三个两两交集计数之和、$S_3 = \lfloor x/L_{abc}\rfloor$。一个属于恰好 $k$ 个集合的数对 $S_1,S_2,S_3$ 的贡献分别是 $k, \binom{k}{2}, \binom{k}{3}$，故「恰好属于 1 个」的个数为 $S_1 - 2S_2 + 3S_3$（$k=1$ 得 1，$k=2$ 得 0，$k=3$ 得 0），二分依旧可用。
3. **改成「同时被 $a$ 和 $b$ 整除」**：问题退化为 $L_{ab}$ 的倍数序列，第 $n$ 个就是 $n \cdot L_{ab}$，连二分都不需要——容斥的每一项单独看都很简单，难点全在「并集」这一步。
