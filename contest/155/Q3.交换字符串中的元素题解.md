# LeetCode 交换字符串中的元素 题解

## 1. 题目概述

- **标题 / 题号**：交换字符串中的元素（#1202，medium）
- **链接**：https://leetcode.cn/problems/smallest-string-with-swaps/
- **来源**：LeetCode 第 155 场周赛 Q3
- **难度**：中等
- **标签**：并查集，深度优先搜索，广度优先搜索，哈希表，字符串，排序

**题意**：给出字符串 `s` 和「可交换索引对」数组 `pairs`，`pairs[i] = [a, b]` 表示允许交换 `s[a]` 与 `s[b]`，交换次数不限（可以是 0 次）。求经过若干次交换后 `s` 能变成的**字典序最小**的字符串。

**关键转述**：把下标看成点、把一个 `pairs[i]` 看成一条无向边，则「能交换」等价于「两点连通」。于是问题变成：在点集被划分成若干个连通分量的前提下，如何把每个分量内的字符重新摆放，使整串字典序最小。

**约束**：

- $1 \le \lvert s \rvert \le 10^5$
- $0 \le \lvert \text{pairs} \rvert \le 10^5$
- $0 \le \text{pairs}[i][0], \text{pairs}[i][1] < \lvert s \rvert$
- `s` 只包含小写英文字母

## 2. 示例

**示例 1**

```text
输入：s = "dcab", pairs = [[0,3],[1,2]]
输出："bacd"
解释：
交换 s[0] 和 s[3]，s = "bcad"
交换 s[1] 和 s[2]，s = "bacd"
```

**示例 2**

```text
输入：s = "dcab", pairs = [[0,3],[1,2],[0,2]]
输出："abcd"
解释：
交换 s[0] 和 s[3]，s = "bcad"
交换 s[0] 和 s[2]，s = "acbd"
交换 s[1] 和 s[2]，s = "abcd"
```

**示例 3**

```text
输入：s = "cba", pairs = [[0,1],[1,2]]
输出："abc"
解释：三个下标连成一条链，可以任意排列，升序排列后即 "abc"
```

## 3. 解题思路

### 3.1 暴力思路

最直接的建模是「把字符串当状态做 BFS」：从 `s` 出发，每次枚举 `pairs` 里的所有交换，记录所有可达状态，最后取字典序最小者。但一个大小为 $k$ 的连通分量最坏有 $k!$ 种排列可达，$k = 10^5$ 时状态空间爆炸，连样例规模都撑不住。

另一个诱人的想法是**单步贪心**：反复扫描 `pairs`，只要能通过一次交换让当前字符串变小就执行，直到扫不动为止。它同样不对。取 `s = "cab"`、`pairs = [[0,1],[0,2]]`：先交换 `(0,1)` 得到 `"acb"`（变小），此后交换 `(0,2)` 会得到 `"bca"`（变大），贪心卡在 `"acb"`；而正确答案是 `"abc"`——为了把 `b` 送到下标 1，不得不先让字符串暂时变大一次。**局部下降的路径不一定通向全局最小。**

### 3.2 核心观察：pairs 是边，连通分量内自由排列

![连通分量内的字符可以任意置换](images/wc155_q3_component_model.svg)

把 `pairs[i] = [a, b]` 看成无向边 $a \leftrightarrow b$。一次交换只会让字符在同一条边的两个端点之间移动，所以：

- **守恒律**：一个字符永远待在它出发时所在的连通分量里，跨分量换字符是不可能的；
- **可达律**：同一连通分量内，任意两个位置的字符都能对调——沿分量里的路径把字符一步步「挪」过去即可，路径上每一步都是合法的相邻交换。

两条合起来说明：**每个分量的字符多重集是不变量，而这个多重集的所有排列都可达**。于是「字典序最小」这个全局目标，就被拆成了若干互不干扰的子问题：

> 对每个分量，把它内部的字符按升序排列，再按**下标升序**依次填回去。

因为字符集固定时，让最小的字符占据该分量里最小的下标，逐位看都是最优的（严格论证见第 5 节）。

### 3.3 算法流程

![并查集分组、组内排序、顺序回填](images/wc155_q3_union_flow.svg)

1. **建并查集**：对每个 `pairs[i] = [a, b]` 执行 `union(a, b)`。
2. **分组收集**：遍历 `i = 0..n-1`，把 `s[i]` 追加到 `groups[find(i)]`。
3. **组内排序**：对每个 `groups[root]` 升序排序。
4. **升序回填**：再次遍历 `i = 0..n-1`，取 `groups[find(i)]` 中第 `ptr[find(i)]` 个字符（`ptr` 为该组已取出的数量），`ptr` 自增。

第 3、4 步的「两个升序」必须同向：组内字符升序 + 全局下标升序，才能让小组的字符压到小组的下标上。

### 3.4 示例演算

![示例 1 的分量划分与回填](images/wc155_q3_walkthrough.svg)

以 `s = "dcab"`、`pairs = [[0,3],[1,2]]` 为例：边只有 $0\!-\!3$ 与 $1\!-\!2$，于是分量 $A = \{0, 3\}$（字符 $\{d, b\}$）、$B = \{1, 2\}$（字符 $\{c, a\}$）。

| 下标 $i$ | 0 | 1 | 2 | 3 |
|----------|---|---|---|---|
| `s[i]` | d | c | a | b |
| 分量根 | 0 | 1 | 1 | 0 |
| 组内升序 | $\{b, d\}$ | $\{a, c\}$ | $\{a, c\}$ | $\{b, d\}$ |
| 回填字符 | **b** | **a** | **c** | **d** |

回填过程：`i = 0` 取 $A$ 的第 0 个字符 `b`；`i = 1` 取 $B$ 的第 0 个字符 `a`；`i = 2` 取 $B$ 的第 1 个字符 `c`；`i = 3` 取 $A$ 的第 1 个字符 `d`。得到 `"bacd"`。

若再加一对 `[0,2]`，四个下标并成同一个分量，字符 $\{d, c, a, b\}$ 升序为 $\{a, b, c, d\}$，一次回填直接得到 `"abcd"`——这就是示例 2。

## 4. 算法细节

1. **并查集要路径压缩**：`find` 用迭代写法边查边把节点挂到祖父上，均摊复杂度 $O(\alpha(n))$，链式结构下也不会退化。
2. **分组键要用最新的根**：`union` 之后必须用 `find(i)` 重新取根，不能直接用 `parent[i]`，否则会把同一个分量拆成两份。
3. **排序可用计数替代**：字母只有 26 种，每组维护 `cnt[26]`、回填时从小到大取，复杂度从 $O(\sum k_c \log k_c)$ 降到 $O(n + 26 \cdot \text{组数})$；数据范围内两种写法都过。
4. **`ptr` 数组而不是弹出队列**：用 `ptr[root]` 记「该组下一个待用字符的位置」，回填是纯随机访问；若用 `vector` 头删会引入 $O(k)$ 的搬移。
5. **`pairs` 里的自环与重复边无需处理**：`[i, i]` 的 `union` 是空操作，重复边只是重复合并同一对根，都不影响结果，也**不要**为它们特判。
6. **避免递归 DFS**：$10^5$ 的链在 Python 里递归会 `RecursionError`，C++ 也可能爆栈；并查集或迭代 BFS 更稳。
7. **输出构造**：C++ 预先 `string res(n, ' ')` 再按下标赋值；Python 用 `list` 收集后 `"".join(...)`，避免字符串拼接的 $O(n^2)$。

## 5. 正确性证明

**引理 1（分量守恒）**：任何一次交换至多改变两个字符的位置，且这两个位置由一条边相连，故交换前后每个字符所在的连通分量不变。

**证明**：交换只在边 $(a, b)$ 的两端点之间进行，字符 $s[a]$ 移动到 $b$、$s[b]$ 移动到 $a$，而 $a, b$ 属于同一连通分量，因此任何字符的所属分量是交换过程中的不变量。∎

**引理 2（分量内全排列可达）**：设某连通分量包含位置集合 $V$，$\lvert V \rvert = k$，则该分量上的字符可以到达 $V$ 上任意一个排列。

**证明**：取该分量的一棵生成树 $T$。对树边对应的对换 $\{(u, v) : (u,v) \in T\}$，先用归纳证明它们能生成 $V$ 上的整个对称群 $S_k$：$k = 1$ 时显然；设对 $k-1$ 个点的树成立，取 $T$ 的一片叶子 $v$ 及其唯一邻点 $u$，则 $T \setminus \{v\}$ 仍是树，由归纳假设可生成 $V \setminus \{v\}$ 上的任意对换；而对任意 $w \in V \setminus \{v\}$，有恒等式
$$(v, w) = (u, w)\,(v, u)\,(u, w),$$
右端三个对换都可用（$(u,w)$ 在子树内，$(v,u)$ 是树边），故 $(v, w)$ 可生成。任意置换都能写成对换之积，于是 $S_k$ 中的每个排列都可达；再由引理 1 的反向，交换可逆，故「可达」是对称关系。∎

**引理 3（逐位贪心最优）**：设当前待填的位置为 $i$，其分量为 $C$，$C$ 尚未使用的字符中最小者为 $m$。则任何可达结果在位置 $i$ 上的字符都 $\ge m$，且存在把 $m$ 放在位置 $i$ 的可达结果。

**证明**：位置 $i$ 只能放分量 $C$ 的字符（引理 1），故其字符属于 $C$ 的字符多重集，自然 $\ge m$。另一方面，由引理 2 该多重集的任意排列都可达，取一个把 $m$ 放在位置 $i$ 的排列即可（其余位置任意）。∎

**定理**：算法输出的字符串 $R$ 是所有可达字符串中字典序最小的。

**证明**：设 $T$ 是任一可达字符串。对下标 $i$ 归纳证明 $R[0..i] \le T[0..i]$ 且若前缀相等则两者在位置 $i$ 之后可用的字符多重集相同。初始时 $R$ 与 $T$ 的字符多重集总量相同（都是 `s` 的字符）。设前 $i$ 个位置已相等，则两个串剩余可用的字符（按分量）完全一致；在位置 $i$，$R$ 取的是该分量剩余字符中的最小值 $m$（引理 3 的贪心），而 $T[i] \ge m$。若 $T[i] > m$，则 $R < T$；若 $T[i] = m$，前缀继续相等，归纳继续。若所有位置都相等则 $R = T$。故 $R \le T$ 对一切可达的 $T$ 成立。∎

## 6. 复杂度分析

- **时间**：并查集建图 $O(m\,\alpha(n))$；分组收集 $O(n\,\alpha(n))$；组内排序合计 $O(\sum_c k_c \log k_c) \le O(n \log n)$；回填 $O(n)$。总计 $O(n \log n + m\,\alpha(n))$，近似线性对数。若改用 26 桶计数，排序部分降为 $O(n + 26 \cdot \text{组数})$。
- **空间**：并查集父数组 $O(n)$；分组容器总共存 $n$ 个字符 $O(n)$；`ptr` 数组 $O(n)$。合计 $O(n)$，与 $m$ 无关。

## 7. 参考代码

### C++

```cpp
#include <algorithm>
#include <string>
#include <unordered_map>
#include <vector>
using namespace std;

class Solution {
public:
    string smallestStringWithSwaps(string s, vector<vector<int>>& pairs) {
        int n = (int)s.size();
        vector<int> parent(n), ptr(n, 0);
        for (int i = 0; i < n; ++i) parent[i] = i;

        // 迭代版 find：路径减半，反复把节点挂到祖父上
        auto find = [&](int x) {
            while (parent[x] != x) {
                parent[x] = parent[parent[x]];
                x = parent[x];
            }
            return x;
        };

        for (auto& p : pairs) {
            int ra = find(p[0]), rb = find(p[1]);
            if (ra != rb) parent[ra] = rb;
        }

        // 按根分组：根 -> 该分量的全部字符
        unordered_map<int, vector<char>> groups;
        groups.reserve(n * 2);
        for (int i = 0; i < n; ++i) groups[find(i)].push_back(s[i]);
        for (auto& kv : groups) sort(kv.second.begin(), kv.second.end());

        // 下标升序回填，组内字符也升序取用
        string res(n, ' ');
        for (int i = 0; i < n; ++i) {
            int r = find(i);
            res[i] = groups[r][ptr[r]++];
        }
        return res;
    }
};
```

### Python

```python
from typing import List


class Solution:
    def smallestStringWithSwaps(self, s: str, pairs: List[List[int]]) -> str:
        n = len(s)
        parent = list(range(n))

        def find(x: int) -> int:
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x

        for a, b in pairs:
            ra, rb = find(a), find(b)
            if ra != rb:
                parent[ra] = rb

        groups = {}
        for i, ch in enumerate(s):
            groups.setdefault(find(i), []).append(ch)
        for g in groups.values():
            g.sort()

        ptr = {}
        res = []
        for i in range(n):
            r = find(i)
            k = ptr.get(r, 0)
            res.append(groups[r][k])
            ptr[r] = k + 1
        return "".join(res)
```

## 8. 边界情况与易错点

1. **`pairs` 为空**：任何字符都动不了，答案就是原串。此时每个下标自成分量，上面的流程天然返回 `s`，无需特判。
2. **`n = 1`**：只有一个分量、一个字符，`groups` 只有一项，回填即原样输出。
3. **只允许 `pairs` 里的边**：常见误解是「相邻字符都能换」。例如 `s = "cab"`、`pairs = [[0,1]]`，答案只能是 `"acb"`，不是 `"abc"`。
4. **回填必须按下标升序**：如果省掉「组内排序」，按字符被收集的原顺序回填，示例 1 里分量 $A$ 依次拿到 $\{d, b\}$、分量 $B$ 依次拿到 $\{c, a\}$，结果仍是 `"dcab"`——等于没做任何优化。
5. **分组键要用 `find(i)`**：`union` 后 `parent[i]` 可能只是中间节点，直接用会把一个分量拆成两份，导致同组字符被重复使用或漏用。
6. **自环与重复边**：`[i, i]`、`[[a,b],[a,b]]` 都不需要特判，但也不能当成「必须交换一次」的约束——题目允许 0 次交换。
7. **递归 DFS 的栈风险**：$10^5$ 的链、Python 默认递归深度约 1000，会直接 `RecursionError`；用并查集或迭代 BFS。
8. **输出长度**：回填后长度必须仍为 $n$（只重排不增删），可用断言或直接由 `n` 构造结果串自检。
