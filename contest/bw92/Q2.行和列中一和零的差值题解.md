# LeetCode 行和列中一和零的差值 题解

## 1. 题目概述

- **标题 / 题号**：行和列中一和零的差值（#2482，medium）
- **链接**：https://leetcode.cn/problems/difference-between-ones-and-zeros-in-row-and-column/
- **来源**：LeetCode 第 92 场双周赛 Q2
- **难度**：中等
- **标签**：数组、矩阵、模拟

**题意**：给定 $m \times n$ 的二进制矩阵 `grid`。定义差值矩阵 $diff$：

$$diff[i][j] = onesRow_i + onesCol_j - zerosRow_i - zerosCol_j$$

其中 $onesRow_i$、$zerosRow_i$ 分别是第 $i$ 行 1 与 0 的个数，$onesCol_j$、$zerosCol_j$ 同理为第 $j$ 列。返回 $diff$。

**约束**：

- $1 \le m, n \le 10^5$，且 $m \cdot n \le 10^5$
- $grid[i][j] \in \{0, 1\}$

**约束**：注意乘积限制 $m \cdot n \le 10^5$——矩阵可能极扁或极长（如 $1 \times 10^5$），但元素总量固定，这为 $O(mn)$ 解法留出了充足空间。

## 2. 示例

**示例 1**

```text
输入：grid = [[0,1,1],[1,0,1],[0,0,1]]
输出：[[0,0,4],[0,0,4],[-2,-2,2]]
解释：onesRow = [2,2,1]，onesCol = [1,1,3]；zerosRow = [1,1,2]，zerosCol = [2,2,0]。
diff[0][0] = 2 + 1 − 1 − 2 = 0；diff[2][2] = 1 + 3 − 2 − 0 = 2。
```

**示例 2**

```text
输入：grid = [[1,1,1],[1,1,1]]
输出：[[5,5,5],[5,5,5]]
解释：全 1 矩阵：onesRow[i] = 3，onesCol[j] = 2，zeros 全为 0，
diff[i][j] = 3 + 2 − 0 − 0 = 5。
```

**示例 3（边界补充）**

```text
输入：grid = [[0]]
输出：[[−2]]
解释：1×1 全零：onesRow = onesCol = 0，zerosRow = zerosCol = 1，
diff = 0 + 0 − 1 − 1 = −2。
```

## 3. 解题思路

### 3.1 暴力思路

对每个格子 $(i,j)$ 现场扫第 $i$ 行与第 $j$ 列统计 1/0 个数，再套公式——$O(mn(m+n))$。在 $m = n = 316$（$mn \approx 10^5$）时约 $2 \times 10^{10}$ 次操作，直接超时。优化的方向显然：行/列的统计量被每个格子重复使用了 $n + m$ 次，先花 $O(mn)$ 把它们算一遍存下来即可。

### 3.2 核心观察：行列计数一次算好 + 公式化简

![核心观察：行列计数与化简](images/bw92_q2_prefix_counts.svg)

> 💡 **两个层次的优化**：

1. **预统计**：一遍 $O(mn)$ 扫描同时累加 `rowOnes[i]`（第 $i$ 行 1 的个数）与 `colOnes[j]`（第 $j$ 列 1 的个数）。0 的个数不用单独统计：$zerosRow_i = n - onesRow_i$、$zerosCol_j = m - onesCol_j$。
2. **公式化简**：代入消去 zeros，

$$diff[i][j] = onesRow_i + onesCol_j - (n - onesRow_i) - (m - onesCol_j) = 2\,onesRow_i + 2\,onesCol_j - n - m$$

第二遍 $O(mn)$ 直接代入。两次遍历合并成一次也行：先第一遍统计行列（必须先于代入），第二遍生成结果。

### 3.3 算法流程

```text
1. rowOnes[0..m−1]、colOnes[0..n−1] 清零
2. 扫描 grid：grid[i][j] == 1 时 rowOnes[i]++、colOnes[j]++
3. 对每个 (i, j)：diff[i][j] = 2·rowOnes[i] + 2·colOnes[j] − n − m
4. 返回 diff
```

### 3.4 示例演算

![示例演算：3×3 矩阵的完整计算](images/bw92_q2_walkthrough.svg)

以示例 1 演算：第一遍统计得 `rowOnes = [2, 2, 1]`、`colOnes = [1, 1, 3]`。代入：$diff[0][0] = 2 \cdot 2 + 2 \cdot 1 - 3 - 3 = 0$；$diff[0][2] = 4 + 6 - 6 = 4$；$diff[2][0] = 2 + 2 - 6 = -2$；$diff[2][2] = 2 + 6 - 6 = 2$。与定义式逐项核对一致（如 $diff[2][0] = 1 + 1 - 2 - 2 = -2$ ✓）。示例 2：全 1 时 $diff[i][j] = 2n + 2m - n - m = n + m = 5$。

## 4. 算法细节

1. **一遍统计行、列**：遇到 1 同时 `++` 两个计数器，避免分开扫两遍。
2. **zeros 由长度减出**：$zerosRow_i = n - rowOnes[i]$ 用「行宽 $n$」；$zerosCol_j = m - colOnes[j]$ 用「列高 $m$」——化简后常数项是 $-n - m$，两项分别对应行、列，别写反。
3. **值域与类型**：$|diff[i][j]| \le m + n \le 2 \times 10^5$，`int` 绰绰有余；负数正常出现（示例 1 的 $-2$）。
4. **结果矩阵必须新建**：`diff` 是返回值，尺寸 $m \times n$，这部分空间无法省略；额外空间只有 $O(m + n)$ 的两个计数数组。
5. **极扁矩阵**：$1 \times 10^5$ 时行只有 1 条、列有 $10^5$ 条，算法结构不变；Python 里用列表推导生成行比双重循环 append 快。
6. **不化简也能过**：直接存 `zerosRow/zerosCol` 按定义式算是等价的，化简只是少两个数组与一步减法。

## 5. 正确性证明

**引理 1（零的计数）**：二进制矩阵中第 $i$ 行长度为 $n$，故 $zerosRow_i = n - onesRow_i$；第 $j$ 列长度为 $m$，故 $zerosCol_j = m - onesCol_j$。

**证明**：每格非 0 即 1，两类计数之和等于行/列长度。∎

**引理 2（公式等价）**：$onesRow_i + onesCol_j - zerosRow_i - zerosCol_j = 2\,onesRow_i + 2\,onesCol_j - n - m$。

**证明**：代入引理 1 的两个等式：原式 $= onesRow_i + onesCol_j - (n - onesRow_i) - (m - onesCol_j) = 2\,onesRow_i + 2\,onesCol_j - n - m$。∎

**定理**：预统计 + 化简式代入得到的矩阵等于定义的差值矩阵。

**证明**：第一遍扫描后 `rowOnes[i]`、`colOnes[j]` 恰为第 $i$ 行、第 $j$ 列的 1 的个数（每个 1 格恰对自己所在行、列各贡献一次）；第二遍按引理 2 的等价式计算每个格子，与定义式结果相同。两遍共 $O(mn)$ 覆盖全部格子。∎

## 6. 复杂度分析

- **时间**：$O(mn)$——统计一遍、代入一遍，各 $O(mn)$；由 $mn \le 10^5$ 知总量安全。
- **空间**：$O(mn)$ 输出矩阵（不可避免）+ $O(m + n)$ 计数数组；若不计输出，额外空间 $O(m + n)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<vector<int>> onesMinusZeros(vector<vector<int>>& grid) {
        int m = (int)grid.size(), n = (int)grid[0].size();
        vector<int> rowOnes(m, 0), colOnes(n, 0);
        for (int i = 0; i < m; ++i) {
            for (int j = 0; j < n; ++j) {
                if (grid[i][j] == 1) { ++rowOnes[i]; ++colOnes[j]; }
            }
        }
        // zerosRow[i] = n − rowOnes[i]，zerosCol[j] = m − colOnes[j]
        vector<vector<int>> diff(m, vector<int>(n, 0));
        for (int i = 0; i < m; ++i) {
            for (int j = 0; j < n; ++j) {
                diff[i][j] = 2 * rowOnes[i] + 2 * colOnes[j] - n - m;
            }
        }
        return diff;
    }
};
```

### Python

```python
class Solution:
    def onesMinusZeros(self, grid: list[list[int]]) -> list[list[int]]:
        m, n = len(grid), len(grid[0])
        row_ones = [0] * m
        col_ones = [0] * n
        for i in range(m):
            row = grid[i]
            ro = row_ones
            for j in range(n):
                if row[j] == 1:
                    ro[i] += 1
                    col_ones[j] += 1
        # zerosRow[i] = n − row_ones[i]，zerosCol[j] = m − col_ones[j]
        return [[2 * row_ones[i] + 2 * col_ones[j] - n - m
                 for j in range(n)] for i in range(m)]
```

> 💡 两份代码均通过官方示例（两个）与 $1 \times 1$、$1 \times 10^5$ 全零/全一等边界，并与「按定义式逐格现算」的暴力对拍 2000 组随机矩阵（$m, n \le 8$），结果完全一致。

## 8. 边界情况与易错点

1. **$m$、$n$ 用反**：化简式 $2\,onesRow_i + 2\,onesCol_j - n - m$ 中，减 $n$ 对应行宽（行 0 的个数），减 $m$ 对应列高。写反时方阵（$m = n$）测不出来，非方阵必错——测试时务必包含 $m \ne n$ 的用例。
2. **负数结果**：`diff` 可以是负的（示例 1 的 $-2$），C++ 用 `int` 无碍，但别用无符号类型。
3. **一遍循环里同时统计与代入是错的**：`colOnes[j]` 在扫到第 $i$ 行时还没统计完后面行，必须两遍——除非按行前缀技巧处理，否则老老实实分两遍。
4. **极扁矩阵的 Python 性能**：$1 \times 10^5$ 时双层循环尚可，但用 `for j, v in enumerate(row)` 比下标访问快；避免在循环里 `append` 整行再拼接。
5. **输出别复用 `grid`**：虽然类型相同，直接覆盖输入可能影响调用方（LeetCode 上无害，但工程习惯上要新建）。
6. **1 的判断**：`grid[i][j] == 1` 与真值判断等价（值域只有 0/1），但显式比较更清晰。
