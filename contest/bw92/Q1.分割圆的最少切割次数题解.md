# LeetCode 分割圆的最少切割次数 题解

## 1. 题目概述

- **标题 / 题号**：分割圆的最少切割次数（#2481，easy）
- **链接**：https://leetcode.cn/problems/minimum-cuts-to-divide-a-circle/
- **来源**：LeetCode 第 92 场双周赛 Q1
- **难度**：简单
- **标签**：几何、数学

**题意**：圆内一个**有效切割**是满足下列条件之一的线段：(a) 两个端点都在圆上且经过圆心（即**直径**）；(b) 一端在圆心、另一端在圆上（即**半径**）。给定整数 $n$，返回把圆分割成面积相等的 $n$ 等份所需的最少切割次数。

**约束**：

- $1 \le n \le 100$

## 2. 示例

**示例 1**

```text
输入：n = 4
输出：2
解释：两条互相垂直的直径把圆分成 4 个相等扇形，2 次切割足够；1 次切割至多产生 2 份。
```

**示例 2**

```text
输入：n = 3
输出：3
解释：三条相隔 120° 的半径把圆分成 3 等份；直径只能产生偶数份，2 次切割不够。
```

**示例 3（边界补充）**

```text
输入：n = 1
输出：0
解释：整个圆本身就是 1 等份，不需要任何切割。
输入：n = 2
输出：1
解释：一条直径即得两等份（两条半径拼起来也是这条直径，但不能省成 0 次）。
```

## 3. 解题思路

### 3.1 暴力思路

$n \le 100$ 可以打表或搜索，但这是纯规律题：切割只分「直径」与「半径」两类，直接从两类切割能产生的等分数入手分析即可，无需任何搜索。

### 3.2 核心观察：直径一刀顶两刀，但只对偶数等分有效

![核心观察：直径与半径两种切割](images/bw92_q1_diameter_radius.svg)

> 💡 **两条基本事实**：

1. **一条直径 = 两条共线的半径**，它把圆周「开两个口」，直接得到 2 个相等扇形；$d$ 条**互不重合**的直径产生 $2d$ 份。因此偶数 $n$ 用 $n/2$ 条直径。
2. **一条半径只开一个口**：单独一条半径甚至切不开圆（圆盘仍是连通的一块，只是边界多了个缺口）。$r$ 条半径（端点互不重合、不与直径端点重合地分布于圆周）配合已有的切口，把圆周分成若干段弧、每段弧对应一个扇形。

奇数 $n$ 时直径无用武之地：任何一组切割产生的份数 = 圆周上被切开的**弧段数**，直径贡献 2 个切口、半径贡献 1 个切口，总切口数 $= 2d + r$，份数 $= 2d + r$（切口互不重合时）。要得到奇数份，$r$ 必须为奇数——但直径的「性价比」（切口/刀 = 2）只有在偶数目标下才能兑现：奇数 $n$ 时若用了直径，切口数 $2d + r \equiv r \pmod 2$，要凑 $n$（奇）需要 $r$ 奇数条半径，总刀数 $d + r \ge n$ 的分析见 §5——结论是**奇数 $n$ 用 $n$ 条半径最省**。

### 3.3 算法流程

![三种情况的判定](images/bw92_q1_parity_cases.svg)

```text
1. 若 n == 1：返回 0
2. 若 n 为偶数：返回 n / 2
3. 若 n 为奇数：返回 n
```

### 3.4 示例演算

- $n = 4$：偶数，$4/2 = 2$ 条直径（互相垂直），4 个 90° 扇形 ✓；
- $n = 3$：奇数，3 条半径（相隔 120°），3 个 120° 扇形 ✓；
- $n = 6$：偶数，3 条直径（每 60° 一条端点），6 份；
- $n = 1$：特判 0 ✓。

## 4. 算法细节

1. **判断顺序**：先特判 $n = 1$（它也是奇数，若先走奇数分支会错误返回 1）。
2. **切口计数模型**：把「切割」翻译成「圆周上的切口」，直径 = 2 个切口，半径 = 1 个切口，互不重合的切口把圆周分成同样数量的弧、每段弧张开一个扇形——这是全部证明的骨架（§5）。
3. **无需求角度**：答案只依赖奇偶，不需要实际构造切割线；$n \le 100$ 也杜绝了浮点角度误差问题。
4. **代码就是三行**，但容易在「$n=1$ 返回 0」「$n=2$ 返回 1」这类边界上翻车（见 §8）。

## 5. 正确性证明

**引理 1（切口模型）**：一组互不重合的合法切割把圆分成若干块，当且仅当这些切割在圆周上的切口（直径记 2 个、半径记 1 个）互异且至少 2 个时，圆被真正切开；块的个数 = 切口的个数（切口把圆周分成等量的弧段，每段弧对应一块）。

**证明**：切割线段都在圆盘内部（端点在圆上/圆心）。把圆盘边界 $\partial D$ 看作一条闭曲线，切口是这条闭曲线上的点。没有切口（全为半径但所有半径端点…注意半径只有一个圆周端点）时圆周完整，圆盘连通为 1 块。$c \ge 2$ 个互异切口把圆周切成 $c$ 段开弧；每段弧与圆心区域的连接方式由切割线决定：过圆心的直径把两侧分开。归纳地看，每加一条切割，若其切口都是新切口，则把「含该线段的某个区域」一分为二（线段两端在圆周或圆心，落在某块内部，切开该块），块数恰加 1（切口一个新增时）或……更直接地：所有切口等分圆周的前提下（见引理 2），块数 = 弧段数 = 切口数。∎

**引理 2（等分要求切口等距）**：$n$ 等分等价于 $n$ 个切口把圆周 $n$ 等分（每段弧 $360°/n$）。特别地，切口数恰为 $n$（切口数 $c$ 段弧要组成 $n$ 个相等扇形，每块恰由一段弧张成，故 $c = n$）。

**证明**：相等的 $n$ 块面积且每块是以圆心为顶点的扇形（切割线全过圆心或为直径，分出的块都是扇形），面积相等 $\iff$ 圆心角相等 $\iff$ 弧长相等，即切口把圆周 $n$ 等分；$n$ 段弧需要 $n$ 个切口。∎

**定理**：最少切割数为 $n = 1$ 时 $0$；$n$ 偶时 $n/2$；$n$ 奇时 $n$。

**证明**：$n=1$ 无需切割显然最优。设 $d$ 条直径与 $r$ 条半径，切口数 $c = 2d + r$（互不重合，重合的直径是同一条切割、重合切口浪费刀数，最优解中不会出现）。由引理 2，$2d + r = n$。
- $n$ 偶：取 $r = 0$、$d = n/2$，刀数 $d + r = n/2$；任何方案刀数 $= d + r \ge \lceil (2d + r)/2 \rceil = \lceil n/2 \rceil = n/2$，达到下界。
- $n$ 奇：$2d + r = n$ 为奇迫使 $r \ge 1$（奇数）。刀数 $= d + r = d + (n - 2d) = n - d \ge n - \lfloor (n-1)/2 \rfloor = (n+1)/2$；取 $d = 0$、$r = n$ 得刀数 $n$。还需排除 $d \ge 1$ 的更优方案：若 $d \ge 1$，则 $r = n - 2d \ge 1$ 且为奇数，切口分布上直径的两个切口相差 180°，而 $n$ 等分要求切口均匀间隔 $360°/n$——偶数 $n$ 时 180° 是间隔的整数倍可行；奇数 $n$ 时 $180° = (n/2) \times (360°/n)$，$n/2$ 不是整数，即直径的两切口不可能同时落在均匀 $n$ 等分点上，与引理 2 矛盾。故奇数 $n$ 必须 $d = 0$、$r = n$，最少 $n$ 刀。∎

## 6. 复杂度分析

- **时间**：$O(1)$，一次奇偶判断。
- **空间**：$O(1)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int numberOfCuts(int n) {
        if (n == 1) return 0;                 // 已经是 1 份，无需切割
        return n % 2 == 0 ? n / 2 : n;        // 偶数：n/2 条直径；奇数：n 条半径
    }
};
```

### Python

```python
class Solution:
    def numberOfCuts(self, n: int) -> int:
        if n == 1:
            return 0                     # 已经是 1 份，无需切割
        return n // 2 if n % 2 == 0 else n   # 偶数：n/2 条直径；奇数：n 条半径
```

> 💡 两份代码均通过官方示例（`2`、`3`），并枚举 $n = 1 \sim 100$ 与「切口计数模型」逐一核对。

## 8. 边界情况与易错点

1. **$n = 1$ 必须特判**：1 是奇数，先走奇数分支会返回 1（错）；正确答案是 0——不切割就是 1 等份。
2. **$n = 2$ 返回 1**：一条直径；不要想成「两条半径各切一次」。
3. **「单独一条半径切不开圆」**：题面示例 2 特意说明「第一次切割无法将圆切割开」——半径切口只有 1 个，圆盘仍连通；这不是「浪费」，奇数等分正需要它。
4. **直径重合**：同一条直径切两次仍是同一条线段，不产生新切口；证明中「互不重合」的假设排除了这种浪费。
5. **奇数 + 直径的诱错**：直觉上「直径一刀顶两刀」似乎总不亏，但奇数等分的均匀切口要求把直径排除在外（§5 定理），容易想当然地写 `n/2` 向上取整。
6. **别按角度浮点构造**：$n \le 100$ 虽然能精确算，但本题只要求次数，纯奇偶判断即可。
