# LeetCode 第 K 个最小的质数分数 题解

## 1. 题目概述

- **标题 / 题号**：第 K 个最小的质数分数（#786，medium）
- **链接**：https://leetcode.cn/problems/k-th-smallest-prime-fraction/
- **来源**：LeetCode 第 72 场周赛 Q4
- **难度**：中等
- **标签**：数组、双指针、二分查找、排序、堆（优先队列）

**题意**：给定严格递增数组 `arr`，其中 `arr[0] = 1`、其余元素均为**质数**且互不相同。对所有满足 $0 \le i < j < n$ 的下标对，取分数 $arr[i]/arr[j]$；返回其中**第 $k$ 小**的那个分数，用长度为 2 的数组 $[arr[i], arr[j]]$ 表示（返回分子分母本身，而不是小数值）。

**约束**：

- $2 \le n \le 1000$
- $1 \le arr[i] \le 3\times10^4$
- $arr[0] = 1$，$arr[i]$（$i>0$）是质数，所有元素互不相同且严格递增
- $1 \le k \le \dfrac{n(n-1)}{2}$，即 $k$ 一定合法

> 💡 **进阶要求**：能否设计时间复杂度小于 $O(n^2)$ 的算法？本文给出两条路线：**多路归并（小根堆）**与**值域二分 + 双指针计数**，后者满足进阶要求。

## 2. 示例

**示例 1**

```text
输入：arr = [1,2,3,5], k = 3
输出：[2,5]
解释：全部 6 个分数升序为
      1/5(0.2), 1/3(0.333), 2/5(0.4), 1/2(0.5), 3/5(0.6), 2/3(0.667)
      第 3 小是 2/5，故返回 [2,5]。
```

**示例 2 与补充示例**（后者自行构造，覆盖 $k$ 接近上界的情形）

```text
输入：arr = [1,7], k = 1
输出：[1,7]
解释：只有 1/7 一个分数，k = 1 时它就是答案。

输入：arr = [1,2,3,5,7], k = 9
输出：[2,3]
解释：10 个分数升序为 1/7, 1/5, 2/7, 1/3, 2/5, 3/7, 1/2, 3/5, 2/3, 5/7
      第 9 小是 2/3。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有下标对 $(i,j)$，算出 $\binom{n}{2}$ 个分数并排序，取第 $k$ 个。$n = 1000$ 时共有 $499500$ 个分数，排序是 $O(n^2\log n)$、空间 $O(n^2)$。

它能在时限内跑完，但两处明显浪费：**完全没有利用 $arr$ 已排序**这一结构，也没回答「小于 $O(n^2)$」的进阶问题。正确的方向是把这些分数组织成若干条**已经有序的链**，只做「取前 $k$ 个」所需的工作。

### 3.2 核心观察：分数矩阵的列单调性

![分数矩阵的单调性](images/wc72_q4_fraction_matrix_monotone.svg)

把分数排成矩阵 $F[i][j] = arr[i]/arr[j]$（只在 $i < j$ 的上三角有定义）。在每列中固定分母 $j$、让分子下标 $i$ 从 $0$ 增大到 $j-1$：

$$\frac{arr[0]}{arr[j]} < \frac{arr[1]}{arr[j]} < \cdots < \frac{arr[j-1]}{arr[j]}$$

因为 $arr$ 严格递增、分母为正，分子变大分数就变大。**所以第 $j$ 列（$j = 1,\dots,n-1$）本身就是一条严格递增的链，长度恰为 $j$**，$n-1$ 条链合计 $\sum_{j=1}^{n-1} j = \binom{n}{2}$，不重不漏地覆盖全部分数。

于是原问题等价于：**对 $n-1$ 条升序链做 $k$ 路归并，取第 $k$ 个出堆元素**。归并只需暴露每条链的「链首」，而链首统一是 $arr[0]/arr[j]$，所以堆里最多只有 $n-1$ 个候选。

> 💡 行方向是递减的（分子固定、分母变大则分数变小），所以按列组织更自然：链首都是 $1/arr[j]$，边界处理最省事。

### 3.3 算法流程

**路线 A：小根堆归并**（主线，全整数比较，无精度风险）

![k 路归并流程](images/wc72_q4_heap_merge_flow.svg)

1. **初始化**：对每个 $j = 1,\dots,n-1$，把链首 $(0, j)$ 压入小根堆，堆按 $arr[i]/arr[j]$ 升序。
2. **循环 $k-1$ 轮**：弹出堆顶 $(i,j)$ —— 它是「尚未弹出的分数」中最小的；若 $i+1 < j$，把同列下一个 $(i+1,j)$ 压回堆，否则该列耗尽。
3. **返回**：此时堆顶就是第 $k$ 小，输出 $[arr[i], arr[j]]$。

比较两个分数时**交叉相乘**：$arr[i]/arr[j] < arr[i']/arr[j'] \iff arr[i]\cdot arr[j'] < arr[i']\cdot arr[j]$，全程整数，不需要浮点。

**路线 B：值域二分 + 双指针计数**（进阶，时间与 $k$ 无关）

![值域二分与双指针计数](images/wc72_q4_value_binary_search.svg)

第 $k$ 小的分数值 $v^{*}$ 是 $[0,1]$ 上的一个实数，且

$$\text{count}(x) = \#\{(i,j) : i<j,\ arr[i]/arr[j] \le x\}$$

关于 $x$ **单调不减**，并且 $\text{count}(x) \ge k \iff x \ge v^*$。于是在 $[0,1]$ 上二分 $x$，找**最小**的满足 $\text{count}(x) \ge k$ 的 $x$，它就是 $v^{*}$。

关键是 $\text{count}(x)$ 能 $O(n)$ 求出：对每个分母下标 $j$，满足条件的分子是一个**前缀** $\{arr[0],\dots,arr[i-1]\}$（因为 $arr$ 递增），而 $j$ 右移时 $x\cdot arr[j]$ 单调增大，故前缀只变长——指针 $i$ 不回退，双指针合计 $O(n)$。每轮顺便记下「$\le x$ 的最大分数」作为候选答案，二分结束后它就是答案。

### 3.4 示例演算

![示例演算](images/wc72_q4_walkthrough.svg)

以 `arr = [1,2,3,5]`、`k = 3` 为例（答案 $2/5$）。

**堆路线**（$k-1 = 2$ 轮，堆用升序书写）：

- 初始堆 1/5, 1/3, 1/2（三条链的链首）；
- 第 1 轮弹出 1/5$(0,3)$、压入 2/5$(1,3)$ ⇒ 堆变为 1/3, 2/5, 1/2；
- 第 2 轮弹出 1/3$(0,2)$、压入 2/3$(1,2)$ ⇒ 堆变为 2/5, 1/2, 2/3，堆顶即答案。

**二分路线**（每轮 $O(n)$ 计数）：

| mid | count(mid) | 与 $k=3$ 比较 | 动作 |
|-----|-----------|---------------|------|
| 0.5 | 4 | $\ge 3$ | `hi = 0.5`，候选 1/2 |
| 0.25 | 1 | $< 3$ | `lo = 0.25` |
| 0.375 | 2 | $< 3$ | `lo = 0.375` |
| 0.4375 | 3 | $\ge 3$ | `hi = 0.4375`，候选 2/5 |
| $\to 0.4$ | $\to 3$ | 收敛 | 候选固定为 2/5 ⇒ 返回 `[2,5]` |

以 $mid = 0.4375$ 为例核对计数：$j=1$ 时 $0.4375\times 2 = 0.875$，小于 $arr[0] = 1$，贡献 $0$；$j=2$ 时 $0.4375\times 3 = 1.3125$，只有 $1/3$，贡献 $1$；$j=3$ 时 $0.4375\times 5 = 2.1875$，$1/5$ 与 $2/5$ 都行，贡献 $2$。合计 $3 = k$，可行。

## 4. 算法细节

1. **堆元素只存下标对 $(i,j)$**，不存分数值；比较时用 $arr[i]\cdot arr[j']$ 与 $arr[i']\cdot arr[j]$，避免浮点。
2. **C++ `priority_queue` 是大根堆**：想要最小堆就要传「大于」语义的比较器；lambda 没有默认构造函数，必须写成 `priority_queue<T, vector<T>, decltype(cmp)> pq(cmp);` 把比较器对象传进构造函数。
3. **压入条件必须是 $i+1 < j$**：$i+1 = j$ 时分数为 $arr[j]/arr[j] = 1$，不是合法下标对；漏掉这个判断会得到错误答案甚至越界。
4. **Python 堆里用浮点键也是安全的**：任意两个不同分数的间距为 $\left|\frac{a}{b}-\frac{c}{d}\right| = \frac{|ad-bc|}{bd} \ge \frac{1}{9\times10^8} \approx 1.1\times10^{-9}$，而 double 在 $[0,1]$ 上的绝对误差约 $10^{-16}$，相差七个数量级，排序不会被舍入颠倒；元组写成 `(value, i, j)`，即使数值相等也有确定次序。
5. **二分版指针不回退的依据**：$j$ 增大 $\Rightarrow arr[j]$ 增大 $\Rightarrow mid\cdot arr[j]$ 增大 $\Rightarrow$ 条件 $arr[i] \le mid\cdot arr[j]$ 更容易成立，所以已纳入前缀的分子对后续 $j$ 仍然合法。
6. **二分版只在「可行」轮更新候选**：`cnt >= k` 时把本轮「$\le mid$ 的最大分数」记成答案并令 `hi = mid`；`cnt < k` 时只令 `lo = mid`。判定写成 `>` 等价于去找第 $k+1$ 小，答案整体偏大一档（$k$ 取上界时甚至会停在初值 $[0,1]$）；`cnt == k` 这一轮必须算「可行」。
7. **固定迭代 60 轮，而不是 `while (hi - lo > eps)`**：60 轮把区间缩到 $2^{-60} \approx 8.7\times10^{-19}$，既保证终止，也让精度可证；用 `eps` 判停在一对间距仅 $1.1\times10^{-9}$ 的分数附近可能提前退出。
8. **两种路线的取舍**：$k$ 很大时堆要做 $k-1$ 次出堆，是它的最坏场景；二分与 $k$ 无关，恒为 60 轮扫描。$n = 1000$、$k = 499500$ 的 Python 实测：堆约 217 ms，二分约 11 ms。

## 5. 正确性证明

**引理 1（列单调）**：固定 $j$，序列 $arr[0]/arr[j], arr[1]/arr[j], \dots, arr[j-1]/arr[j]$ 严格递增。

**证明**：由 $arr$ 严格递增得 $arr[i] < arr[i+1]$，同除以正数 $arr[j]$ 保序。∎

**引理 2（分数两两不等）**：若 $arr[i]/arr[j] = arr[i']/arr[j']$ 且 $i<j$、$i'<j'$，则 $i = i'$ 且 $j = j'$。

**证明**：记 $a=arr[i], b=arr[j], c=arr[i'], d=arr[j']$，交叉相乘得 $ad = cb$。每个元素要么是 $1$，要么是两两互不相同的质数，且 $a<b$、$c<d$。若 $a>1$ 为质数，则 $a \mid cb$；而 $b \in \{1\}\cup\mathbb{P}$ 且 $b \neq a$（因 $a<b$），故 $a \nmid b$，于是 $a \mid c$，由 $c$ 为质数得 $c = a$，进而 $d = b$。若 $a=1$，则 $d = cb$：若 $c>1$，则 $c \mid d$ 且 $d$ 为质数，得 $d = c$，与 $c<d$ 矛盾，故只能 $c=1$、$d = b$。两类情形都推出 $(a,b) = (c,d)$，而数组元素互不相同，故 $i=i'$、$j=j'$。∎

**引理 3（堆不变量）**：在第 $t$ 次出堆之前，堆中的元素恰为「每条尚未耗尽的链的当前最小未出堆元素」；因此出堆顺序就是全体分数的严格升序。

**证明**：初始时每列压入 $(0,j)$，由引理 1 它是该列最小。归纳：出堆 $(i,j)$ 后，若 $i+1<j$ 则压入 $(i+1,j)$，由引理 1 它是该列下一个最小元素；否则该列已空。其余列未受影响。于是每列未出堆的最小元素都在堆中，堆顶即全局最小；再由引理 2 全体分数互不相等，出堆序列严格递增。∎

**引理 4（计数正确且单调）**：双指针算出的 $\text{count}(x)$ 恰为满足 $arr[i]/arr[j] \le x$ 的下标对个数，且关于 $x$ 单调不减。

**证明**：固定 $j$，$\{i : arr[i] \le x\cdot arr[j]\}$ 是前缀（$arr$ 递增），故 $i$ 的取值个数就是该分母下的合法对数。$j$ 递增时 $x\cdot arr[j]$ 递增，前缀不会变短，指针不回退仍覆盖全部合法分子，因此总数正确。$x$ 增大时每个前缀只会变长，故单调。∎

**定理**：两条路线返回的 $[arr[i], arr[j]]$ 都是第 $k$ 小的分数。

**证明**：堆路线：由引理 3，前 $k-1$ 次出堆恰为最小的 $k-1$ 个分数，此后堆顶即第 $k$ 小。二分路线：设第 $k$ 小值为 $v^{*}$，由引理 4 有 $\text{count}(x) \ge k \iff x \ge v^*$，二分的右界 $hi$ 始终保持 $\text{count}(hi)\ge k$，且 60 轮后 $hi - lo < 8.7\times10^{-19}$，故 $hi$ 落在 $[v^*, v^* + 1.1\times10^{-9})$ 内；而「$\le hi$ 的最大分数」在该区间内只能是 $v^{*}$，即返回的正是第 $k$ 小。∎

## 6. 复杂度分析

- **堆路线时间**：$O\big((n + k)\log n\big)$。初始化 $n-1$ 次入堆，随后 $k-1$ 次出堆、至多 $k-1$ 次入堆，每次 $O(\log n)$。
- **二分路线时间**：$O\big(60n\big) = O\big(n\log\frac{1}{\varepsilon}\big)$，与 $k$ 无关；每轮双指针各走 $O(n)$ 步。
- **空间**：堆路线 $O(n)$（堆中每列至多一个下标对，共 $\le n-1$ 个）；二分路线 $O(1)$，只有若干标量。
- 对比暴力：$O(n^2\log n)$ 时间、$O(n^2)$ 空间；堆路线省掉「全量排序」，二分路线则把 $k$ 从复杂度里彻底消掉，满足进阶要求。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <queue>
#include <utility>
using namespace std;

class Solution {
public:
    vector<int> kthSmallestPrimeFraction(vector<int>& arr, int k) {
        int n = arr.size();
        // 小根堆：按 arr[i] / arr[j] 升序，用交叉相乘做整数比较
        auto cmp = [&arr](const pair<int, int>& a, const pair<int, int>& b) {
            return (long long)arr[a.first] * arr[b.second] >
                   (long long)arr[b.first] * arr[a.second];
        };
        priority_queue<pair<int, int>, vector<pair<int, int>>, decltype(cmp)> pq(cmp);

        for (int j = 1; j < n; ++j) pq.push({0, j});   // 每条链的链首

        for (int t = 1; t < k; ++t) {                  // 弹出最小的 k-1 个
            auto [i, j] = pq.top();
            pq.pop();
            if (i + 1 < j) pq.push({i + 1, j});        // 同列的下一个元素
        }

        auto [i, j] = pq.top();                        // 堆顶即第 k 小
        return {arr[i], arr[j]};
    }
};
```

### Python

```python
import heapq
from typing import List


class Solution:
    def kthSmallestPrimeFraction(self, arr: List[int], k: int) -> List[int]:
        n = len(arr)
        # 小根堆：(分数值, 分子下标, 分母下标)，初始压入 n-1 条链的链首
        heap = [(arr[0] / arr[j], 0, j) for j in range(1, n)]
        heapq.heapify(heap)

        for _ in range(k - 1):                 # 弹出最小的 k-1 个
            _, i, j = heapq.heappop(heap)
            if i + 1 < j:                      # 同列下一个候选
                heapq.heappush(heap, (arr[i + 1] / arr[j], i + 1, j))

        _, i, j = heap[0]                      # 堆顶即第 k 小
        return [arr[i], arr[j]]
```

**进阶：值域二分版（Python，$O(n\log\frac{1}{\varepsilon})$，满足「小于 $O(n^2)$」）**

```python
class Solution:
    def kthSmallestPrimeFraction(self, arr: list[int], k: int) -> list[int]:
        n = len(arr)
        lo, hi = 0.0, 1.0
        p, q = 0, 1                            # 候选答案 arr[p] / arr[q]
        for _ in range(60):                    # 60 轮后区间宽 ~8.7e-19
            mid = (lo + hi) / 2
            cnt = 0
            bi, bj = 0, 1                      # 本轮 <= mid 的最大分数
            i = 0                              # 分子指针，只增不减
            for j in range(1, n):
                while i < j and arr[i] <= mid * arr[j]:
                    if arr[i] * bj > bi * arr[j]:
                        bi, bj = arr[i], arr[j]
                    i += 1
                cnt += i                       # 分母 arr[j] 下共 i 个合法分数
            if cnt >= k:                       # 可行：答案不超过 mid
                p, q = bi, bj
                hi = mid
            else:                              # 不够 k 个：答案更大
                lo = mid
        return [p, q]
```

## 8. 边界情况与易错点

1. **$n = 2$**：只有 $1/arr[1]$ 一个分数，$k$ 必为 1；堆初始化 1 个元素、循环 0 轮，直接返回，不能假设堆里有多个元素。
2. **$k = 1$**：不进入弹出循环，堆顶是最小的链首 $1/arr[n-1]$，答案是 `[1, arr[-1]]`。
3. **$k = \binom{n}{2}$（最大）**：要做 $\binom{n}{2}-1$ 次出堆，结束时每列都耗尽、堆里只剩 1 个元素，取 `top` 不能越界。注意最大值**不一定**是 $arr[n-2]/arr[n-1]$：`[1,2,3,5]` 的最大分数是 $2/3$ 而不是 $3/5$，所以不能拿「最大的两个数」当 $k$ 最大时的特判。
4. **$i+1 = j$ 时不能压入**：那是 $arr[j]/arr[j] = 1$，不属于合法分数；条件写成 `i+1 <= j` 会多出非法项。
5. **C++ 交叉相乘用 `long long`**：$3\times10^4 \times 3\times10^4 = 9\times10^8$ 虽在 `int` 内，但用 `int` 存乘积再比较的写法在数组值域扩大后会溢出，统一 `long long` 更稳。
6. **比较器方向不能写反**：`priority_queue` 默认按 `<` 排出大根堆，自定义比较器要表达「$a$ 的优先级低于 $b$」（即 $a > b$），写反会变成取第 $k$ 大。
7. **二分版 `cnt >= k` 分支里必须同时更新候选**：若只更新 `hi` 不记候选，最后拿不到具体的分子分母（返回的必须是 $arr[p]/arr[q]$，不能拿 $mid$ 顶替）；反之 `cnt < k` 时更新候选则会记下错误的值。
