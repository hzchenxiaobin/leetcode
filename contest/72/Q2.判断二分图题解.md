# LeetCode 判断二分图 题解

## 1. 题目概述

- **标题 / 题号**：判断二分图（#785，medium）
- **链接**：https://leetcode.cn/problems/is-graph-bipartite/
- **来源**：LeetCode 第 72 场周赛 Q2
- **难度**：中等
- **标签**：深度优先搜索、广度优先搜索、并查集、图、图的着色、二分图

**题意**：给定 $n$ 个节点的**无向图**邻接表 `graph`，其中 `graph[u]` 列出与 $u$ 相邻的所有节点（无自环、无重边、无向对称，且**可能不连通**）。判断能否把节点集合划分成两个子集 $A$、$B$，使得每条边的两个端点分别属于不同的子集——即判断该图是否为**二分图**。

**约束**：

- `graph.length == n`，$1 \le n \le 100$
- $0 \le \text{graph}[u].\text{length} < n$
- $0 \le \text{graph}[u][i] \le n-1$，且 `graph[u]` 不含 $u$、元素互不相同
- 无向：$v \in \text{graph}[u] \iff u \in \text{graph}[v]$

> 💡 **审题关键**：两个容易漏掉的点——① 图**可能不连通**，必须对每个未染色的点重新起一次搜索；② 边约束是「**异色**」，冲突判定是「同色」，方向别写反。

## 2. 示例

**示例 1**（含三角形 ⇒ 非二分图）

```text
输入：graph = [[1,2,3],[0,2],[0,1,3],[0,2]]
输出：false
解释：0-1、0-2、1-2 构成三角形（奇环）。把 0 染成颜色 0 后，
      1 与 2 都必须染成颜色 1，可边 (1,2) 又要求两者异色，矛盾。
```

**示例 2**（四边形 ⇒ 二分图）

```text
输入：graph = [[1,3],[0,2],[1,3],[0,2]]
输出：true
解释：分成 {0, 2} 与 {1, 3} 两组，四条边 (0,1)(0,3)(1,2)(2,3) 全部跨越两组。
```

**示例 3**（补充用例：$n=1$ 的孤立点）

```text
输入：graph = [[]]
输出：true
解释：单点无边，(A = {0}, B = ∅) 满足每条边两端异色的要求。
```

## 3. 解题思路

### 3.1 暴力思路

枚举全部 $2^{n}$ 种「把每个点分到 $A$ 或 $B$」的方案，对每种方案检查每条边是否跨组。单次检查 $O(n+m)$，总计 $O(2^n (n+m))$——$n = 100$ 时天文数字，完全不可行。

但暴力已经点明了问题本质：这是一道**二染色（two-coloring）可行性**问题。暴力的浪费在于「重复枚举了约束传播本就能定死的东西」。

### 3.2 核心观察：异色约束具有传播性，染色方案唯一

![二分图与奇环：异色约束的传播与冲突](images/wc72_q2_bipartite_odd_cycle.svg)

考察一条边 $(u,v)$：只要 $u$ 的颜色已定，$v$ 的颜色就**只能**是 $1 - c_u$，没有任何选择余地。由此得到三个递进结论：

1. **传播性**：从任意点 $s$ 出发，沿「邻居染相反色」向外扩散，就能把 $s$ 所在连通分量全部定色，遇到冲突即说明该分量无法二分。
2. **唯一性**：固定 $c_s$ 之后，分量内每个点的颜色被唯一确定，且恰好等于 $c_s \oplus \operatorname{dist}(s, v) \bmod 2$（离起点的距离奇偶）——这与 BFS 分层天然一致。
3. **奇环判据**：冲突在几何上就是**奇环**。若边 $(u,v)$ 两端被染同色，说明 $s \to u$ 与 $s \to v$ 两条路径奇偶性相同，拼上 $(u,v)$ 就得到一条奇数长度的环；反之奇环上无论怎么染色都必然出现同色边。

于是二分图判定归结为一个纯奇偶性命题：

$$\text{图是二分图} \iff \text{不存在奇环} \iff \text{存在合法的二染色}$$

> 💡 **一句话**：二分图判定 = 从每个未染色点出发做一次**交替染色**，全程只看「边两端是否异色」，冲突就是非二分图。$O(n+m)$。

### 3.3 算法流程

![BFS 交替染色流程](images/wc72_q2_bfs_coloring_flow.svg)

$c$ 数组三态：$-1$ 未染色、$0$ 属 $A$、$1$ 属 $B$。

1. 外层 `for s in 0..n-1`：若 $c_s \ne -1$ 说明该点所在分量已处理，直接跳过；否则 $c_s \leftarrow 0$ 并入队（每个分量固定一次起点的颜色）。
2. BFS：弹出 $u$，遍历 $v \in \text{graph}[u]$：
   - $c_v = -1$ ⇒ 未染色，令 $c_v \leftarrow c_u \oplus 1$，$v$ 入队；
   - $c_v = c_u$ ⇒ 同色相邻，**立即返回 `false`**；
   - 否则（已染色且异色）⇒ 通过，继续看下一个邻居。
3. 队列清空后回到外层，换下一个分量；全部分量处理完仍无冲突则返回 `true`。

```text
for s in 0..n-1:
    if c[s] != -1: continue        # 该分量已染完
    c[s] = 0; q.push(s)
    while q not empty:
        u = q.pop()
        for v in graph[u]:
            if c[v] == -1:                     # 未染色：传播异色
                c[v] = c[u] ^ 1; q.push(v)
            else if c[v] == c[u]:              # 同色 ⇒ 奇环 ⇒ 非二分图
                return false
return true
```

### 3.4 示例演算

![示例 1 的 BFS 染色走查](images/wc72_q2_walkthrough.svg)

对示例 1 `graph = [[1,2,3],[0,2],[0,1,3],[0,2]]`：

| 步骤 | 出队 $u$ | 检查的邻居 $v$ | 动作 |
|------|----------|----------------|------|
| 1 | 0 | 1, 2, 3 | 均未染色 ⇒ 全染成颜色 1，依次入队 |
| 2 | 1 | 0 | $c_0 = 0 \ne c_1 = 1$，异色通过 |
| 3 | 1 | 2 | $c_2 = 1 = c_1$ ⇒ **冲突，返回 `false`** |

冲突边是 $(1,2)$，它与 $0$ 一起构成三角形——最小的奇环。

对示例 2 `graph = [[1,3],[0,2],[1,3],[0,2]]`：出队顺序 $0,1,3,2$，染色结果 $c_0 = c_2 = 0$、$c_1 = c_3 = 1$，四条边全部异色 ⇒ 返回 `true`，两组即 $\{0,2\}$ 与 $\{1,3\}$。

## 4. 算法细节

1. **三态数组而非两个布尔数组**：`color = [-1]*n` 一个数组同时承担「是否访问」与「属于哪组」两种语义；若拆成 `visited` + `color`，很容易出现「已访问但颜色未写对」的半初始化状态。
2. **异色用异或**：`color[v] = color[u] ^ 1` 比 `1 - color[u]` 或 `3 - color[u]` 更不容易在改动颜色编号时出错；Python 的 `^` 作用在整数上行为一致。
3. **外层循环不可省**：只从 0 号点出发做一次 BFS 会把其它分量的奇环全部漏掉。例如 $0$ 是孤立点、$1$–$5$ 构成五边形 $1\to2\to3\to4\to5\to1$：若只从 $0$ 出发，队列立刻为空、直接返回 `true`，而正确答案是 `false`。
4. **冲突即短路**：一旦发现同色边就 `return false`，不必把整个分量染完；这在高冲突数据上能显著提前退出。
5. **BFS 与 DFS 等价**：由 3.2 的唯一性，两种遍历得到同一套颜色，选哪个只影响常数与栈空间。本题 $n \le 100$ 递归不会爆栈，但推广到大图时 BFS（或显式栈）更稳。
6. **每条无向边检查两次**：邻接表是对称的，边 $(u,v)$ 会在 $u$ 出队和 $v$ 出队时各被看一遍，常数翻倍但仍是 $O(n + m)$，无需去重。
7. **不要用 `set` 记录访问**：`color` 数组就是访问标记，同一个点只在首次被染色时入队一次，队列中不会出现重复元素。
8. **并查集视角（备选实现）**：对每个 $u$ 依次处理邻居 $v$——若 $\operatorname{find}(u) = \operatorname{find}(v)$ 则 $u,v$ 被迫同色 ⇒ 非二分图；否则把 $v$ 与 $\text{graph}[u]$ 的其余邻居合并成一类（它们都与 $u$ 异色，故彼此同色）。适合需要**动态加边**的场景，本题用 BFS 更短。

## 5. 正确性证明

**引理 1（合法染色 ⇔ 二分划分）**：若存在颜色函数 $c: V \to \{0,1\}$ 使每条边 $(u,v)$ 都有 $c(u) \ne c(v)$，则 $(A, B) = (c^{-1}(0), c^{-1}(1))$ 是图的二分划分。

**证明**：由于每个点恰有一个颜色，$A \cup B = V$ 且 $A \cap B = \varnothing$。任取边 $(u,v)$，由 $c(u) \ne c(v)$ 知其一端在 $A$、另一端在 $B$，满足二分图定义。∎

**引理 2（二染色的唯一性）**：设 $v$ 与 $s$ 在同一连通分量，则任一合法染色都满足 $c(v) = c(s) \oplus \bigl(\operatorname{dist}(s,v) \bmod 2\bigr)$。特别地，固定 $c(s)$ 后该分量内所有颜色唯一。

**证明**：对最短路径长度 $k = \operatorname{dist}(s,v)$ 归纳。$k = 0$ 时 $v = s$，成立。设 $s = v_0, v_1, \dots, v_k$ 是一条最短路径，且已证 $c(v_{k-1}) = c(s) \oplus ((k-1) \bmod 2)$；边 $(v_{k-1}, v_k)$ 的两端必须异色（引理 1），故 $c(v_k) = c(v_{k-1}) \oplus 1 = c(s) \oplus (k \bmod 2)$。∎

**引理 3（分量被完整染色）**：内层 BFS 结束时，$s$ 所在连通分量的每个点都已确定颜色。

**证明**：对分量内任一点 $v$，取最短路径 $s = v_0, v_1, \dots, v_k = v$。$v_0$ 初始化即入队；若 $v_i$ 已入队，它出队时必然遍历到邻居 $v_{i+1}$，此时 $v_{i+1}$ 要么未染色被当场染色入队，要么早已染色。沿路径归纳即得 $v_k = v$ 最终被染色。∎

**定理**：算法返回 `true` **当且仅当**图是二分图。

**证明**：

- **（图二分 ⇒ 返回 `true`）**设图存在二分划分 $(A, B)$，取 $c^{*}$ 为它的指示函数，则由引理 1 每条边两端异色，且 $c^{*}$ 在每个分量上都是合法染色。算法对每个分量以 $c_s = 0$ 起染，得到的颜色或与 $c^{*}$ 在该分量上完全相同，或整体取反（引理 2 的唯一性，两种都合法）。故算法读到的每条边都满足 $c_v \ne c_u$，冲突分支永不触发，遍历完所有分量后返回 `true`。
- **（返回 `true` ⇒ 图二分）**若算法返回 `true`，说明它从未因同色返回，且由引理 3 每个分量的点都被染色，于是最终颜色函数 $c$ 对**所有**边都满足 $c(u) \ne c(v)$。由引理 1，按颜色分组即得合法二分划分。∎

## 6. 复杂度分析

- **时间**：$O(n + m)$，其中 $m$ 为无向边数（$m = \tfrac{1}{2}\sum_u \lvert \text{graph}[u] \rvert$）。外层循环 $O(n)$；每条边在两端各被检查一次，共 $2m$ 次 $O(1)$ 操作；队列每个点最多入队出队一次。冲突可提前退出，最坏仍是 $O(n+m)$。
- **空间**：$O(n)$。`color` 数组 $n$ 个整数，BFS 队列最坏存 $n$ 个点；不计输入邻接表本身的开销。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <queue>
using namespace std;

class Solution {
public:
    bool isBipartite(vector<vector<int>>& graph) {
        int n = graph.size();
        vector<int> color(n, -1);          // -1 未染色，0 / 1 表示两组
        queue<int> q;
        for (int s = 0; s < n; s++) {      // 图可能不连通，逐分量处理
            if (color[s] != -1) continue;
            color[s] = 0;                  // 每个分量固定起点颜色，其余随之唯一
            q.push(s);
            while (!q.empty()) {
                int u = q.front();
                q.pop();
                for (int v : graph[u]) {
                    if (color[v] == -1) {
                        color[v] = color[u] ^ 1;   // 邻居染相反色
                        q.push(v);
                    } else if (color[v] == color[u]) {
                        return false;              // 同色相邻 ⇒ 奇环 ⇒ 非二分图
                    }
                }
            }
        }
        return true;
    }
};
```

### Python

```python
from collections import deque
from typing import List


class Solution:
    def isBipartite(self, graph: List[List[int]]) -> bool:
        n = len(graph)
        color = [-1] * n                    # -1 未染色，0 / 1 表示两组
        for s in range(n):                  # 图可能不连通，逐分量处理
            if color[s] != -1:
                continue
            color[s] = 0                    # 固定起点颜色，分量内其余颜色唯一
            q = deque([s])
            while q:
                u = q.popleft()
                for v in graph[u]:
                    if color[v] == -1:
                        color[v] = color[u] ^ 1     # 邻居染相反色
                        q.append(v)
                    elif color[v] == color[u]:
                        return False                # 同色相邻 ⇒ 奇环
        return True
```

## 8. 边界情况与易错点

1. **不连通图**：必须外层遍历所有点，只从一个点出发会漏掉其它分量里的奇环，把 `false` 误判成 `true`。
2. **孤立点 / 空邻接表**：`graph[u]` 为空时该点自成一分量，随意染成 0 即可；$n = 1$、`graph = [[]]` 应返回 `true`（空集允许作为其中一组）。
3. **提前 `return true` 的位置**：循环内「队列空了」只说明**一个分量**染完，不代表全图合法；`return true` 必须放在双重循环之外，等所有分量都无冲突再执行。
4. **把「未染色」当成颜色值参与比较**：若用 `1 - color[u]` 却忘了先判未染色，$-1$ 的邻居会被染成 $2$，后续 `color[v] == color[u]` 的比较全部失真。先用 `color[v] == -1` 拦掉未染色，再判同色，顺序写死。
5. **自环（本题保证不存在）**：若存在 $u \in \text{graph}[u]$，$u$ 出队时会读到 $c_u = c_u$ 并立即返回 `false`——恰好是正确结论，代码无需特判。
6. **重边（本题保证不存在）**：同一对点被列两次只会多检查一遍，不影响结论，也不必去重。
7. **DFS 递归深度**：本题 $n \le 100$ 安全；若把同一模板搬到 $n = 10^5$ 的链式图上，递归 DFS 会爆栈，应改 BFS 或显式栈。
8. **并查集实现的两个坑**：合并顺序必须在「检查完 $u$ 的所有邻居」之前逐个判同集合；且无向边要对称处理，否则会漏检。
