# LeetCode 字母大小写全排列 题解

## 1. 题目概述

- **标题 / 题号**：字母大小写全排列（#784，medium）
- **链接**：https://leetcode.cn/problems/letter-case-permutation/
- **来源**：LeetCode 第 72 场周赛 Q1
- **难度**：中等
- **标签**：位运算，字符串，回溯

**题意**：给定字符串 `s`（含小写字母、大写字母、数字），我们可以把**任意一些字母**切换大小写来得到新串，数字不能改动。返回所有可能得到的字符串集合，顺序任意。

**约束**：

- $1 \le \lvert s \rvert \le 12$
- `s` 由小写英文字母、大写英文字母和数字组成

> 💡 签到题的信号很明确：$n \le 12$ 且答案是**全量枚举**，输出本身就有 $2^k$ 个串（$k$ 为字母个数）。所以复杂度目标是「输出敏感」——把每个结果串只花 $O(n)$ 造出来，总代价 $O(2^k \cdot n)$，不要多看一眼。

## 2. 示例

**示例 1**

```text
输入：s = "a1b2"
输出：["a1b2", "a1B2", "A1b2", "A1B2"]
解释：两个字母 a、b 各有「小写 / 大写」两种选择，2 × 2 = 4 个串；
      数字 '1'、'2' 在四条结果里始终原样出现。
```

**示例 2**

```text
输入：s = "3z4"
输出：["3z4", "3Z4"]
解释：只有 z 一个字母，2 种选择；数字 3、4 固定。
```

**补充示例（非官方，用于边界对照）**

```text
输入：s = "123"
输出：["123"]
解释：没有字母，$2^0 = 1$，答案是只含一个元素的列表，而不是空列表。

输入：s = "aA"
输出：["aa", "aA", "Aa", "AA"]（顺序任意）
解释：输入本身就混有大写，必须先把每个字母归一化成「小写 / 大写」两支，
      而不是简单地对原字符做一次「转大写」。
```

## 3. 解题思路

### 3.1 暴力思路

最自然的想法是 DFS：从左到右扫描 `s`，遇到数字只有一条分支（原样放入），遇到字母分两条分支（保持、切换），走到末尾就收集一个串。这棵搜索树恰好有 $2^k$ 个叶子，每条路径长度 $n$，总代价 $O(2^k \cdot n)$——**已经是最优复杂度**，因为输出本身就这么大。

真正会翻车的是「枚举所有 $2^n$ 种大小写组合再过滤」：把数字位也当成两个分支，会产生 $2^{n-k}$ 份完全重复的结果，最后还要用 `set` 去重。当 `s` 全是数字时（$k=0$）它会做 $2^{12} = 4096$ 次无用功，只返回 1 个答案；而 $2^k$ 枚举（$2^0 = 1$）一步到位。所以本题的「暴力」与「正解」只差一件事：**只为字母分配分支**。

### 3.2 核心观察：一个 k 位掩码就能描述全部选择

![字母位编码成 k 位掩码](images/wc72_q1_mask_branching.svg)

关键事实有两条：

1. **数字位与选择无关**。数字字符在题面里既不能被切换，也不参与比较，它在所有结果中的位置和内容都固定，因此不该占用任何「决策维度」。
2. **字母位彼此独立**。第 $j$ 个字母是转大写还是保持小写，不影响其它字母的处理方式，也不会改变字符串长度或其它位置。

于是把 $k$ 个字母按从左到右编号为 $b = 0,1,\dots,k-1$，用一个 $k$ 位二进制数 `mask` 表示决策：

$$\text{第 } b \text{ 个字母} = \begin{cases} \text{大写}, & \text{mask 的第 } (k-1-b) \text{ 位} = 1 \\[2pt] \text{小写}, & \text{mask 的第 } (k-1-b) \text{ 位} = 0 \end{cases}$$

`mask` 取遍 $[0,\,2^k)$ 就得到全部 $2^k$ 种选择向量。这里让**最左边的字母占最高位**，是为了让枚举顺序与样例输出 `["a1b2","a1B2","A1b2","A1B2"]` 一致（题面允许任意顺序，但「顺序对得上样例」在赛场上更好自查）。

### 3.3 算法流程

![算法流程：记录字母下标 → 枚举掩码 → 逐位写回](images/wc72_q1_algorithm_flow.svg)

```text
letters ← s 中所有字母的下标（从左到右）      # 只记位置，不记字符
k ← len(letters)
base ← s 的可变字符数组；res ← []
for mask in 0 .. 2^k - 1:
    for b in 0 .. k - 1:
        bit ← (mask >> (k - 1 - b)) & 1
        base[letters[b]] ← 大写 if bit == 1 else 小写
    res.append(join(base))                  # 数字位从没被写过，天然保持原样
return res
```

**为什么用一个可变的 `base` 缓冲区**：每个 `mask` 只改动 $k$ 个字母位置，其余 $n-k$ 个位置（数字）从头到尾没被写过；每轮结束把整个缓冲区拼成字符串即可。这样单轮是 $O(k)$ 次写入 $+\ O(n)$ 次拼接，而不是「每轮从 `s` 重新拷一份再逐字符判断」。

### 3.4 示例演算

![s = "a1b2" 的四个掩码与四个结果](images/wc72_q1_walkthrough.svg)

对 `s = "a1b2"`：字母下标 `letters = [0, 2]`，$k = 2$，所以 `mask` 取 `00, 01, 10, 11`。

| `mask` | bit 1（字母 a） | bit 0（字母 b） | 结果 |
|--------|-----------------|-----------------|------|
| `00` | 0 → 小写 `a` | 0 → 小写 `b` | `a1b2` |
| `01` | 0 → 小写 `a` | 1 → 大写 `B` | `a1B2` |
| `10` | 1 → 大写 `A` | 0 → 小写 `b` | `A1b2` |
| `11` | 1 → 大写 `A` | 1 → 大写 `B` | `A1B2` |

四个串互不相同，且与样例输出逐项一致。再验一个退化情形 `s = "123"`：`letters = []`、$k = 0$，循环区间是 $[0, 2^0) = \{0\}$，内层一次都不执行，直接产出 `"123"`，答案恰好一个元素。

## 4. 算法细节

1. **先收集下标，再做枚举**。`letters` 只存字母位置，枚举时用 `s[pos]` 取原始字符做 `toupper` / `tolower`，而不是在缓冲区上反复取反——反复取反一旦某轮漏写，下一轮就会带着上一轮的状态继续，产生错误答案。
2. **位方向要固定**。第 $b$ 个字母对应掩码第 $k-1-b$ 位（最左字母是最高位）。若改成第 $b$ 位，得到的**集合完全相同**（只是 $2^k$ 个结果的输出次序被镜像了），但输出顺序会与样例不符，自测时容易误判。
3. **`k = 0` 时 `1 << k` 仍是 1**。空字母表不会让循环「一次都不跑」，而是跑一次并产出原串——这正是全数字输入需要的答案，无需特判。
4. **大小写转换用 `isalpha` + `toupper`/`tolower`**，不要用 `ch >= 'a' && ch <= 'z'` 之类的范围判断：本题允许大写字母输入，只判小写会漏掉一半分支。C++ 里把 `char` 转 `unsigned char` 再传给 `toupper` 是消除负值 UB 的好习惯（本题字符都是 ASCII，但模板值得保留）。
5. **不要用 `set` 去重**。由 §5 引理 1，不同掩码必产出不同串，去重只会白白多付 $O(2^k \log 2^k)$ 的比较与哈希开销。
6. **预留容量**。`res.reserve(1 << k)`（C++）能避免 $4096$ 次扩容；Python 直接用 `list.append` 即可。
7. **回溯写法与位枚举等价**。DFS 在每个字母处先递归「小写」再递归「大写」，深度 $n \le 12$、叶子 $2^k$，复杂度同为 $O(2^k \cdot n)$，额外空间 $O(n)$ 递归栈；它的好处是天然按「低位先变」产出，正好等于样例顺序。位枚举则把递归栈也省掉了，Q1 赛场上两者随便挑一个写。

## 5. 正确性证明

**引理 1（选择向量与结果串一一对应）**：记字母下标为 $p_0 < p_1 < \dots < p_{k-1}$。对任意向量 $v \in \{0,1\}^k$，令 $T(v)$ 表示「把 $s[p_j]$ 置为大写当 $v_j = 1$、置为小写当 $v_j = 0$、其余位置照抄」得到的串。则 $T$ 是单射，且其像恰为题目允许得到的全部字符串。

**证明**：

- **单射**：设 $v \ne v'$，取最小的 $j$ 使 $v_j \ne v'_j$。在位置 $p_j$ 上，$T(v)$ 与 $T(v')$ 是同一个字母的两种不同大小写形式，二者必不相等，因此 $T(v) \ne T(v')$。
- **像的正确性**：题目允许的操作是「对任意字母子集各切换一次大小写」。由于切换两次回到原样，一串操作序列的净效果只取决于**每个字母最终停在大写还是小写**，这正是某个 $v$；反之任给 $v$，只对 $v_j = 1$ 的字母各切换一次即可实现 $T(v)$。∎

**引理 2（掩码枚举是双射）**：映射 $\varphi:\{0,1,\dots,2^k-1\} \to \{0,1\}^k$，$\varphi(\text{mask})_j = \bigl(\text{mask} \gg (k-1-j)\bigr) \wedge 1$，是双射。

**证明**：$\varphi$ 就是把 `mask` 写成恰好 $k$ 位的二进制展开，位序从高到低对应 $j = 0,1,\dots,k-1$。任何整数在固定长度下的二进制表示唯一存在，故 $\varphi$ 既是单射又是满射。∎

**定理**：`letterCasePermutation(s)` 返回的列表恰为题目允许得到的全部字符串，元素互不相同，个数为 $2^k$。

**证明**：算法对每个 `mask` $\in [0, 2^k)$ 构造一个串：由引理 2，这一步遍历了所有选择向量且不重复；由引理 1，不同向量产出的串互不相同，且所有产出的串都属于可行集合、可行集合中的每个串也都被某个向量产出。因此输出集合等于像 $T$，无重复，元素个数为 $\lvert \{0,1\}^k \rvert = 2^k$。数字位置从未被写入，保持原字符，符合题意。∎

## 6. 复杂度分析

- **时间**：$O(2^k \cdot n)$，其中 $k$ 是字母个数、$n = \lvert s \rvert$。外层枚举 $2^k$ 个掩码；内层写 $k$ 个字母位置（$O(k)$），再把长度 $n$ 的缓冲区拼成字符串（$O(n)$）。由于 $k \le n$，单轮 $O(n)$，总计 $O(2^k \cdot n)$。这与输出规模（$2^k$ 个长度 $n$ 的串）同阶，已达到下界，无法再优化。
- **空间**：结果数组 $O(2^k \cdot n)$（不可省，就是答案本身）；辅助空间只有 `letters` 的 $O(k)$ 与缓冲区 `base` 的 $O(n)$，即 $O(n)$。若改用 DFS，额外付出 $O(n)$ 递归栈（$n \le 12$）。
- **数值规模**：$k \le 12 \Rightarrow 2^k \le 4096$，每个串长度 $\le 12$，输出总量约 $4096 \times 12 \approx 49\text{KB}$，与内存限制相比可以忽略。

## 7. 参考代码

### C++

```cpp
#include <string>
#include <vector>
#include <cctype>
using namespace std;

class Solution {
public:
    vector<string> letterCasePermutation(string s) {
        vector<int> letters;                       // 只记录字母所在下标，数字不参与
        for (int i = 0; i < (int)s.size(); ++i)
            if (isalpha((unsigned char)s[i])) letters.push_back(i);
        int k = (int)letters.size();

        vector<string> res;
        res.reserve((size_t)1 << k);               // 结果恰好 2^k 个
        for (int mask = 0; mask < (1 << k); ++mask) {
            string cur = s;                        // 数字位原样保留
            for (int b = 0; b < k; ++b) {
                int pos = letters[b];
                unsigned char c = (unsigned char)s[pos];
                bool upper = (mask >> (k - 1 - b)) & 1;   // 第 b 个字母取高位
                cur[pos] = upper ? (char)toupper(c) : (char)tolower(c);
            }
            res.push_back(cur);
        }
        return res;
    }
};
```

### Python

```python
from typing import List

class Solution:
    def letterCasePermutation(self, s: str) -> List[str]:
        letters = [i for i, ch in enumerate(s) if ch.isalpha()]
        k = len(letters)
        base = list(s)                      # 可复用缓冲区，数字位永不改动
        res = []
        for mask in range(1 << k):           # k = 0 时只跑 mask = 0 这一轮
            for b, pos in enumerate(letters):
                upper = (mask >> (k - 1 - b)) & 1
                base[pos] = s[pos].upper() if upper else s[pos].lower()
            res.append("".join(base))
        return res
```

## 8. 边界情况与易错点

1. **全数字输入 `"123"`**：$k = 0$，必须返回 `["123"]`（一个元素）。若把循环写成 `for mask in range(1, 1 << k)`，$k=0$ 时区间为空，会错误地返回 `[]`。
2. **输入已含大写字母**：如 `"C"` 必须得到 `["c", "C"]`、`"aA"` 必须得到 4 个串。只写「转成大写」的分支会丢掉小写形态；正确做法是每个字母都显式取 `upper()` / `lower()`，而不是在原字符上做单侧变换。
3. **`isalpha` 的判定范围**：只用 `'a' <= ch <= 'z'` 会把大写字母当成「非字母」；用 `ch.isalpha()` 时要意识到它对非 ASCII 字符也返回 `True`（本题输入受限于字母数字，无风险，扩展题面时需改成 `ch.isascii() and ch.isalpha()`）。
4. **位方向写反**：`(mask >> b) & 1` 与 `(mask >> (k-1-b)) & 1` 产生的集合相同、顺序相反。若拿样例逐项比对（很多人自测就是直接比较数组），会误以为自己写错了，白花时间。
5. **`1 << k` 的整型宽度**：$k \le 12$ 时 `int` 足够；若题目放宽到 $k \ge 31$，`1 << k` 在 C++ 中是未定义行为，需要改用 `long long` 或 `1LL << k`，同时结果规模本身也已爆炸。
6. **复用缓冲区时的「漏写」**：如果某个 `mask` 分支只写了部分字母（例如加了 `continue` 跳过），下一次迭代会带着上一轮的字符继续，产生串味的结果。要么每轮把 $k$ 个字母全写一遍（本文写法），要么每轮从 `s` 重新拷贝。
7. **输出顺序**：题面明确「以任意顺序返回」，不要为了让顺序好看而排序（会多付 $O(2^k \cdot n \log)$），更不要假设样例顺序是字典序——ASCII 里 `'A'(65) < 'a'(97)`，而样例是「先小写后大写」，二者并不相同。

**延伸思考**：

- **只要第 $t$ 个结果**（1-based）：不需要枚举全部 $2^k$。把 $t-1$ 写成 $k$ 位二进制，直接按位构造一个串即可，时间 $O(n)$、空间 $O(n)$。
- **只要结果总数**：答案恒为 $2^k$，$k$ 可达 $10^5$ 时用快速幂算 $2^k \bmod p$，$O(\log k)$。
- **限制「恰好切换 $t$ 个字母」**：结果数为 $\binom{k}{t}$，需要一个「选 $t$ 个位置」的组合枚举（等价于在 $k$ 位掩码中枚举 popcount 为 $t$ 的那些），可用 Gosper's hack 在 $O(\binom{k}{t})$ 内逐个生成。
- **按字典序输出**：由于 ASCII 中大写字母排在小写字母之前，需要把 DFS 的分支顺序改成「先大写、后小写」，或者等价地把掩码的位序反过来解释——这再次说明「位序」只是约定，真正定义答案的是选择向量与串之间的双射（引理 1）。
