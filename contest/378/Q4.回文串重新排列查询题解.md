# LeetCode 回文串重新排列查询 题解

## 1. 题目概述

- **标题 / 题号**：回文串重新排列查询（#2983，hard）
- **链接**：https://leetcode.cn/problems/palindrome-rearrangement-queries/
- **来源**：LeetCode 第 378 场周赛 Q4
- **难度**：困难
- **标签**：数组、哈希表、字符串、前缀和

**题意**：给定长度为**偶数** $n$ 的字符串 $s$ 与 $q$ 个**相互独立**的查询 $queries[i] = [a_i, b_i, c_i, d_i]$。每个查询允许执行两步操作：

- 把**左半**子串 $s[a_i..b_i]$（$0 \le a_i \le b_i < n/2$）中的字符任意重排；
- 把**右半**子串 $s[c_i..d_i]$（$n/2 \le c_i \le d_i < n$）中的字符任意重排。

判断操作后 $s$ 能否变成**回文串**，返回布尔数组 $answer$。

**约束**：

- $2 \le n = s.length \le 10^5$，$1 \le queries.length \le 10^5$
- $0 \le a_i \le b_i < n/2 \le c_i \le d_i < n$
- $n$ 为偶数，$s$ 只含小写英文字母

> 💡 **周赛视角**：本场前三题（Q1 位运算签到、Q2/Q3 特殊子字符串双数据档）都有熟路可抄，Q4 才是真正的分水岭。工具一眼可见——$n, q$ 同为 $10^5$、字符集 26，必然是**前缀计数 + 逐查询 $O(26)$**；真正的难点在**判定条件本身的推导**：两次重排相互作用，怎样的字符计数条件才**恰好充要**？赛场上把「分类 + 计数配平」想清楚再动手，远快于写完一个假判定再对拍找反例。

## 2. 示例

**示例 1**

```text
输入：s = "abcabc", queries = [[1,1,3,5],[0,2,5,5]]
输出：[true,true]
解释：查询 1：s[3..5]="abc" 重排为 "cba" → "abccba" ✓
      查询 2：s[0..2]="abc" 重排为 "cba"，s[5..5] 单字符不动 → "cbaabc" ✓
```

**示例 2**

```text
输入：s = "abbcdecbba", queries = [[0,2,7,9]]
输出：[false]
解释：两个重排区间之外的中间位置 4/5 是 'd'、'e'，锁死且不相等，无法修复。
```

**示例 3**

```text
输入：s = "acbcab", queries = [[1,2,4,5]]
输出：[true]
解释：s[1..2]="cb" 重排为 "bc"、s[4..5]="ab" 重排为 "ba" → "abccba" ✓
```

## 3. 解题思路

### 3.1 暴力思路：枚举重排 / 逐查询全量扫描

最直白的暴力是枚举两段子串的全部排列逐一验证，单查询 $O\big((\tfrac{n}{2})!^2 \cdot n\big)$，$n = 6$ 就已爆炸。退一步的「半暴力」：每个查询独立扫描全串、统计两区间字符计数后判定，单查询 $O(26n)$，总量 $O(26nq) \approx 2.6 \times 10^{11}$，同样不可行。

但半暴力指明了方向：判定需要的所有量——**区间内字符计数、区间内失配位置数——都是前缀和可以 $O(1)$ 读出的**。剩下的核心问题是：读出哪些量、怎么组合成充要条件？

### 3.2 核心观察：镜像统一坐标系 + 四类位置 + 双池配平

![核心观察：右半镜像对齐后两个重排区间进入同一坐标系，位置分成四类](images/bw378_q4_mirror_zones.svg)

**观察① 镜像统一坐标系**。设 $m = n/2$，回文条件是 $\forall i \in [0, m):\ s[i] = s[n-1-i]$。把右半「翻转对齐」到左半：

$$x_i = s[i], \qquad y_i = s[n-1-i]$$

右区间 $[c, d] \subseteq [m, n)$ 在镜像坐标下变成 $[A, B] = [n-1-d,\ n-1-c] \subseteq [0, m)$。记 $U_1 = [a, b]$、$U_2 = [A, B]$，两次重排变成**同一坐标系**下对 $x$（在 $U_1$ 上）和 $y$（在 $U_2$ 上）的独立重排——两段区间从此**可能相交**，这是后续一切分析的地基。

**观察② 四类位置**。按 $i$ 落在哪个区间，$[0, m)$ 的每个位置分成四类：

| 类别 | 条件 | 命运 |
|------|------|------|
| 门外 | $i \notin U_1 \cup U_2$ | $x_i, y_i$ 都锁死，必须已相等 |
| 仅① | $i \in U_1 \setminus U_2$ | $x_i$ 进**左池**可换，$y_i$ 锁死 |
| 仅② | $i \in U_2 \setminus U_1$ | $y_i$ 进**右池**可换，$x_i$ 锁死 |
| 双 | $i \in U_1 \cap U_2$ | 两侧都自由，是两池之间唯一的「桥」 |

**观察③ 双池配平**。左池 $X$ 是 $\{x_i : i \in U_1\}$ 的多重集，右池 $Y$ 是 $\{y_i : i \in U_2\}$ 的多重集。对每个字母 $v$ 记：

- $X_v$、$Y_v$：两池中 $v$ 的个数（区间计数）；
- $Dx_v = \#\{i \in U_1 \setminus U_2 : y_i = v\}$：仅①位置的锁死 $y$，是对左池的**固定需求**；
- $Dy_v = \#\{i \in U_2 \setminus U_1 : x_i = v\}$：仅②位置的锁死 $x$，是对右池的固定需求。

关键在「双」位置：它从左右两池**各取一个字符且必须相等**。设配对值取 $v$ 的双位置共 $k_v$ 个，则两池各被消耗 $k_v$ 个 $v$，账本必须逐字母配平：

$$X_v = Dx_v + k_v, \qquad Y_v = Dy_v + k_v, \qquad k_v \ge 0$$

消去 $k_v$ 得到全题的**判定式**：

$$\forall v:\quad X_v - Dx_v \;=\; Y_v - Dy_v \;\ge\; 0$$

**观察④ 判定式的语义拆解**。把等式改写成 $X_v + Dy_v = Y_v + Dx_v$，即 $\mathrm{cntX}(v,\ U_1 \cup U_2) = \mathrm{cntY}(v,\ U_1 \cup U_2)$——**并集区域内，左半字符与右半（镜像后）字符总账相等**（条件 B）；不等式则是**左池喂饱自家门内的固定需求后仍有余量供给双位置**（条件 C）。

> ⚠️ **两个条件缺一不可**。反例：$s = $ `"abab"`，查询 $[0,0,2,2]$：$U_1 = \{0\}$、$U_2 = \{1\}$，并集总账两侧同为 $\{a, b\}$，条件 B 通过；但 $X_b = 0 < Dx_b = 1$，条件 C 失败——左池里根本没有 `b` 去配锁死的 $y_0 = $ `b`。事实上两段区间都是单字符，重排等于没排，`"abab"` 不是回文。**只查「总账相等」的写法必挂在此处。**

**观察⑤ 门外检查（条件 A）**。设 $\mathrm{bad}(l, r)$ 为 $[l, r]$ 内 $x_i \ne y_i$ 的位置数（失配前缀和），门外失配数用容斥一步算出：

$$\mathrm{bad}(0, m{-}1) - \mathrm{bad}(U_1) - \mathrm{bad}(U_2) + \mathrm{bad}(U_1 \cap U_2) \overset{!}{=} 0$$

### 3.3 算法流程

![算法流程：预处理前缀和，每个查询镜像统一后先查门外失配，再逐字母配平双池](images/bw378_q4_algorithm_flow.svg)

**完整步骤**：

1. **预处理** $O(26n)$：失配前缀和 $\mathrm{preBad}$；左半每字母前缀计数 $\mathrm{preX}_v$ 与镜像右半 $\mathrm{preY}_v$；
2. **逐查询** $O(26)$：
   - 镜像统一：$A = n{-}1{-}d$，$B = n{-}1{-}c$；交集 $I = [\max(a, A),\ \min(b, B)]$（可为空）；
   - **条件 A**：门外失配数（上式容斥）为 $0$，否则 `false`；
   - **条件 B + C**：逐字母 $v \in [0, 26)$，用前缀和读出 4 个量：$X_v = \mathrm{cntX}(a, b)$，$Y_v = \mathrm{cntY}(A, B)$，$Dx_v = \mathrm{cntY}(a, b) - \mathrm{cntY}(I)$，$Dy_v = \mathrm{cntX}(A, B) - \mathrm{cntX}(I)$；一旦 $X_v < Dx_v$ 或 $X_v - Dx_v \ne Y_v - Dy_v$，`false`；
   - 全部通过 → `true`。

> ⚠️ 三个易错点：① 交集 $I$ 为空时三处容斥都不能减（下标会交叉）；② 条件 C 的非负性检查绝不能省（见观察④的反例）；③ $A, B$ 是「先减 $d$ 后减 $c$」，顺序写反会得到反向区间。

### 3.4 示例演算

![示例演算：正例 acbcab 全配平为 true，陷阱例 abab 总账相等但非负性爆炸为 false](images/bw378_q4_walkthrough.svg)

**正例（示例 3）**：$s = $ `"acbcab"`，$n = 6, m = 3$，查询 $[1,2,4,5]$。$x = $ `acb`，$y = $ `bac`；$U_1 = [1,2]$，$U_2 = [n{-}1{-}5,\ n{-}1{-}4] = [0,2]$，交集 $I = [1,2]$。位置分类：$i=0$ 仅②，$i=1, 2$ 双，门外为空 → 条件 A ✓。逐字母账本：

| $v$ | $X_v$ | $Dx_v$ | $X_v - Dx_v$ | $Y_v$ | $Dy_v$ | $Y_v - Dy_v$ | 判定 |
|-----|-------|--------|--------------|-------|--------|--------------|------|
| a | 0 | 0 | 0 | 1 | 1 | 0 | ✓ |
| b | 1 | 0 | 1 | 1 | 0 | 1 | ✓ |
| c | 1 | 0 | 1 | 1 | 0 | 1 | ✓ |

三行全配平且非负 → `true`。构造方案：双位置 $\{1,2\}$ 的配对值取 $b, c$——左池 $\{c, b\}$ 拿出 $b, c$、右池 $\{b, a, c\}$ 拿出 $b, c$；仅②位置 $0$ 由右池剩余的 $a$ 配锁死的 $x_0 = a$ → `abccba`。

**陷阱例**：$s = $ `"abab"`，查询 $[0,0,2,2]$。$x = $ `ab`，$y = $ `ba`；$U_1 = \{0\}$，$U_2 = \{1\}$，无交集。账本：字母 a 两侧 $1 = 1$ ✓；字母 b 两侧 $-1 = -1$——**相等但为负**！条件 C 爆炸 → `false`。这正是「只查总账」的假算法翻车的地方。

**示例 2 的拦截方式**：$s = $ `"abbcdecbba"`，查询 $[0,2,7,9]$。$U_1 = [0,2]$ 与 $U_2 = [0,2]$ 完全重合，门外是 $i \in \{3, 4\}$：$x_4 = $ `d` 而 $y_4 = $ `e` 失配 → 条件 A 直接 `false`，根本轮不到算账本。

## 4. 算法细节

### 4.1 三组前缀和的设计

对 $i \in [0, m)$ 令 $xv = s[i]$、$yv = s[n-1-i]$：

- $\mathrm{preBad}[i]$：前 $i$ 个位置中 $xv \ne yv$ 的个数，一维，服务条件 A；
- $\mathrm{preX}[v][i]$：前 $i$ 个位置中 $x = v$ 的个数，服务左池计数；
- $\mathrm{preY}[v][i]$：前 $i$ 个位置中 $y = v$ 的个数，服务右池计数。

每组都是标准的「一行滚动一次」结构，总空间 $26 \times (m+1)$ 个整数。

### 4.2 镜像与交集

$A = n-1-d$、$B = n-1-c$——$d$ 是右区间**远离中点**的端点，镜像后反而成为**靠近 0** 的端点，所以「先减 $d$ 后减 $c$」。交集 $I = [\max(a, A),\ \min(b, B)]$，$lo > hi$ 即为空。

### 4.3 四个量的容斥读法

$U_1 \setminus U_2$ 从区间上看是 $[a, b]$ 挖掉 $I$，可能是**两段**（$I$ 夹在中间时）；但计数是线性的，$\mathrm{cntY}(a, b) - \mathrm{cntY}(I)$ 自动正确，无需关心剩下几段——这是用「计数」而非「区间」表达需求的红利。条件 A 的容斥、$Dx_v$ 的容斥、$Dy_v$ 的容斥**三处共用同一个 $I$**。

### 4.4 检查顺序与性能

先做 $O(1)$ 的条件 A 拦截，再进 26 循环——大量查询在门外就阵亡，平均代价远低于最坏值。CPython 中把 `preX[v]`、`preY[v]` 提为循环内局部变量，最坏（全 `true`）情形约 3 秒内可过；C++ 无压力。

## 5. 正确性证明

记 $\Sigma$ 为字母表，$X$、$Y$、$Dx$、$Dy$ 如 §3.2 定义。形式化「重排」：一次合法操作对应一对映射 $f: U_1 \to \Sigma$、$g: U_2 \to \Sigma$，满足 $\{f(i) : i \in U_1\} = X$、$\{g(i) : i \in U_2\} = Y$（多重集相等）——即「多重集不变地任意指派」。操作后位置 $i$ 的左半字符 $L_i = f(i)$（$i \in U_1$）否则 $x_i$；右半字符 $R_i = g(i)$（$i \in U_2$）否则 $y_i$。

**引理 1（操作刻画）**：查询可行（操作后可成回文）$\iff$ 存在上述 $f, g$ 使得 $\forall i \in [0, m):\ L_i = R_i$。

**证明**：回文 $\iff$ 每对对称位置 $(i, n-1-i)$ 的最终字符相等，即 $L_i = R_i$ 对所有 $i \in [0, m)$ 成立；而两次重排能且只能产生形如 $(f, g)$ 的字符指派。∎

**引理 2（判定式）**：查询可行 $\iff$ (A) 门外位置全部 $x_i = y_i$，且 (B) 对每个字母 $v$：$X_v \ge Dx_v$ 且 $X_v - Dx_v = Y_v - Dy_v$。

**证明**：

（⇒）设 $(f, g)$ 为引理 1 中的合法指派。门外位置 $f, g$ 均不作用，$L_i = x_i$、$R_i = y_i$，得 (A)。仅①位置 $g$ 不作用，$R_i = y_i$，故 $f(i) = y_i$——$f$ 在仅①位置消耗的字符恰构成多重集 $Dx$；于是 $f$ 在双位置取值的多重集逐字母为 $X_v - Dx_v$，作为计数非负。同理 $g$ 在双位置取值为 $Y_v - Dy_v$。双位置上 $f(i) = g(i)$，两个多重集逐字母相同，得 (B)。∎（此方向）

（⇐）设 (A)(B) 成立，令 $k_v = X_v - Dx_v = Y_v - Dy_v \ge 0$。先核对总量：

$$\sum_v k_v = |U_1| - |U_1 \setminus U_2| = |U_1 \cap U_2| = |U_2| - |U_2 \setminus U_1| = \sum_v (Y_v - Dy_v)$$

即 $k$ 的总质量恰等于双位置的个数。构造：把多重集 $\{v^{k_v}\}$ 任意分配到各个双位置并令 $f(i) = g(i) = $ 分配值；$i \in$ 仅① 令 $f(i) = y_i$；$i \in$ 仅② 令 $g(i) = x_i$。逐字母验证：$f$ 的取值多重集 $= k_v + Dx_v = X_v$ ✓，$g$ 同理 $= Y_v$ ✓，故 $(f, g)$ 是合法重排；门外位置由 (A) 相等。由引理 1，查询可行。∎

**定理**：本文算法（条件 A 的容斥检查 + 逐字母账本检查）的输出恰为查询的可行性。

**证明**：算法中条件 A 的容斥式与「门外失配数为零」等价（失配前缀和对 $U_1 \cup U_2$ 做并集容斥）；账本四量由前缀和正确读出：$X_v = \mathrm{cntX}(a, b)$、$Y_v = \mathrm{cntY}(A, B)$、$Dx_v = \mathrm{cntY}(U_1) - \mathrm{cntY}(I) = \mathrm{cntY}(U_1 \setminus U_2)$、$Dy_v = \mathrm{cntX}(U_2 \setminus U_1)$。由引理 2，检查通过 $\iff$ 可行。∎

## 6. 复杂度分析

- **时间复杂度**：$O(26 \cdot (n + q))$。预处理三组前缀和各 $O(26n)$；每个查询条件 A 为 $O(1)$ 容斥、条件 B+C 至多 26 次前缀和区间计数。$n = q = 10^5$ 时约 $5 \times 10^6$ 次基本操作。
- **空间复杂度**：$O(26n)$。$\mathrm{preX}$、$\mathrm{preY}$ 各 $26 \times (n/2 + 1)$ 个整数；$\mathrm{preBad}$ 为 $O(n/2)$。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    vector<bool> canMakePalindromeQueries(string s, vector<vector<int>>& queries) {
        int n = s.size(), m = n / 2;
        vector<int> preBad(m + 1, 0);
        vector<vector<int>> preX(26, vector<int>(m + 1, 0));
        vector<vector<int>> preY(26, vector<int>(m + 1, 0));
        for (int i = 0; i < m; ++i) {
            int xv = s[i] - 'a', yv = s[n - 1 - i] - 'a';
            preBad[i + 1] = preBad[i] + (xv != yv);
            for (int v = 0; v < 26; ++v) {
                preX[v][i + 1] = preX[v][i] + (v == xv);
                preY[v][i + 1] = preY[v][i] + (v == yv);
            }
        }

        vector<bool> ans;
        ans.reserve(queries.size());
        for (auto& q : queries) {
            int a = q[0], b = q[1], c = q[2], d = q[3];
            int A = n - 1 - d, B = n - 1 - c;      // 右区间镜像到左半坐标
            int lo = max(a, A), hi = min(b, B);    // 交集 I（可为空）
            bool hasI = lo <= hi;

            // 条件 A：门外失配 = 总失配 − U1 失配 − U2 失配 + 交集失配
            int badU = preBad[b + 1] - preBad[a] + preBad[B + 1] - preBad[A];
            if (hasI) badU -= preBad[hi + 1] - preBad[lo];
            bool ok = (preBad[m] == badU);

            if (ok) {
                for (int v = 0; v < 26 && ok; ++v) {
                    int Xv = preX[v][b + 1] - preX[v][a];
                    int Yv = preY[v][B + 1] - preY[v][A];
                    int Dx = preY[v][b + 1] - preY[v][a];
                    int Dy = preX[v][B + 1] - preX[v][A];
                    if (hasI) {
                        Dx -= preY[v][hi + 1] - preY[v][lo];
                        Dy -= preX[v][hi + 1] - preX[v][lo];
                    }
                    if (Xv < Dx || Xv - Dx != Yv - Dy) ok = false;
                }
            }
            ans.push_back(ok);
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def canMakePalindromeQueries(self, s: str, queries: List[List[int]]) -> List[bool]:
        n = len(s)
        m = n // 2
        preBad = [0] * (m + 1)
        preX = [[0] * (m + 1) for _ in range(26)]
        preY = [[0] * (m + 1) for _ in range(26)]
        for i in range(m):
            xv = ord(s[i]) - 97
            yv = ord(s[n - 1 - i]) - 97
            preBad[i + 1] = preBad[i] + (xv != yv)
            for v in range(26):
                preX[v][i + 1] = preX[v][i] + (v == xv)
                preY[v][i + 1] = preY[v][i] + (v == yv)

        ans = []
        for a, b, c, d in queries:
            A = n - 1 - d                       # 右区间镜像到左半坐标
            B = n - 1 - c
            lo, hi = max(a, A), min(b, B)       # 交集 I（可为空）
            hasI = lo <= hi

            badU = preBad[b + 1] - preBad[a] + preBad[B + 1] - preBad[A]
            if hasI:
                badU -= preBad[hi + 1] - preBad[lo]
            ok = preBad[m] == badU

            if ok:
                for v in range(26):
                    px = preX[v]                # 提局部变量，CPython 提速
                    py = preY[v]
                    Xv = px[b + 1] - px[a]
                    Yv = py[B + 1] - py[A]
                    Dx = py[b + 1] - py[a]
                    Dy = px[B + 1] - px[A]
                    if hasI:
                        Dx -= py[hi + 1] - py[lo]
                        Dy -= px[hi + 1] - px[lo]
                    if Xv < Dx or Xv - Dx != Yv - Dy:
                        ok = False
                        break
            ans.append(ok)
        return ans
```

> 💡 实测代码已通过三个官方示例与 3000 组随机数据对拍（暴力枚举两段区间全部排列做金标准），另含 `"abab"` 陷阱用例专项验证条件 C。

## 8. 边界情况与易错点

1. **非负性检查不能省**：`"abab"` + $[0,0,2,2]$ 总账逐字母相等但 $k_b = -1 < 0$，只查等式的写法必错——这是本题第一大陷阱。
2. **交集为空时三处容斥都不减**：条件 A 的 $+\mathrm{bad}(I)$、$Dx_v$ 与 $Dy_v$ 的 $-\mathrm{cnt}(I)$ 共用一个 `hasI` 开关；空交集硬减会访问交叉的下标。
3. **镜像端点顺序**：$A = n{-}1{-}d$、$B = n{-}1{-}c$，**先 $d$ 后 $c$**；写反得到反向区间，样例可能恰好不暴露。
4. **$n$ 是偶数，无中心字符**：$[0, m)$ 恰好覆盖全部 $\frac{n}{2}$ 个对称对，门外检查无需特判中点。
5. **条件 A 先查再查账本**：$O(1)$ 拦截大量 `false` 查询（如示例 2），顺序颠倒会白白跑 26 循环。
6. **CPython 性能**：全 `true` 的最坏情形 26 循环跑满，`preX[v]`/`preY[v]` 务必提为局部变量。
7. **内存布局**：`preX`/`preY` 是 $26 \times (m{+}1)$ 的二维数组，$n = 10^5$ 时约 $2 \times 26 \times 50001$ 个 int，C++ 约 20 MB 内、Python 用列表嵌套更胖——必要时可改为按行一维展开。

**延伸思考**：

- **区间不相交的退化形态**：$U_1 \cap U_2 = \varnothing$ 时 $k_v \equiv 0$，判定式退化为 $\mathrm{cntX}(v, U_1) = \mathrm{cntY}(v, U_1)$ 且 $\mathrm{cntY}(v, U_2) = \mathrm{cntX}(v, U_2)$——两段重排互不相干，每段必须「自己救自己」。
- **随机哈希为什么救不了条件 C**：给字母赋随机权值可把条件 B（总账相等）压成一次减法判零，但条件 C 的非负性是**逐字母的符号信息**，求和式哈希天然丢失——$O(26)$ 逐字母仍是主线；26 恰是本题给的隐性红利，字符集到 $10^5$ 级别就得考虑离散化 + 其他手段。
- **变体**：若允许三次操作（左半两段 + 右半一段），位置分类会升级成更多类，「桥」的拓扑更复杂——值得作为推广练习。
