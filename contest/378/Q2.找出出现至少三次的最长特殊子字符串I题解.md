# LeetCode 找出出现至少三次的最长特殊子字符串 I 题解

## 1. 题目概述

- **标题 / 题号**：找出出现至少三次的最长特殊子字符串 I（#2981，medium）
- **链接**：https://leetcode.cn/problems/find-longest-special-substring-that-occurs-thrice-i/
- **来源**：LeetCode 第 378 场周赛 Q2
- **难度**：中等
- **标签**：字符串、哈希表、二分查找、计数、滑动窗口

**题意**：给定仅由小写字母组成的字符串 `s`。仅由单一字符组成的字符串称为**特殊**字符串。求在 `s` 中出现**至少三次**的**最长特殊子字符串**长度，不存在则返回 `-1`。注意「出现」按**位置**计数，**重叠也算**。

**约束**：

- $3 \le s.length \le 50$
- `s` 仅由小写英文字母组成

> 💡 **周赛视角**：本场 Q2（本题，$n \le 50$）与 Q3（#2982，同题面、$n \le 10^5$）是**同题双数据档**。Q2 的定位是「Q3 的入场券」——$n \le 50$ 时 $O(n^2)$ 暴力就能过线拿分；但正解（分段计数 + 二分答案）代码与 Q3 完全同构，比赛时直接写正解可以一鱼两吃，Q3 复制粘贴即可。

## 2. 示例

**示例 1**

```text
输入：s = "aaaa"
输出：2
解释：出现三次的最长特殊子字符串是 "aa"：子字符串 "aa"aa、a"aa"a 和 aa"aa"。
三个出现位置两两重叠，重叠也算次数——这是本题最关键的计数规则。
```

**示例 2**

```text
输入：s = "abcdef"
输出：-1
解释：不存在出现至少三次的特殊子字符串，返回 -1。
```

**示例 3**

```text
输入：s = "abcaba"
输出：1
解释："a" 出现三次（下标 0、3、5），而任何长度 2 的特殊子串都凑不满三次。
```

## 3. 解题思路

### 3.1 暴力思路：哈希表逐出现计数

枚举每个起点 $i$，向右扩展 $j$（只要 `s[j] == s[i]` 就继续），每个 $(i, j)$ 对是特殊子串的一次出现，以 `(字符, 长度)` 二元组为键累加计数；最后在计数 $\ge 3$ 的键里取最长：

```python
from collections import defaultdict

def maximumLength(s: str) -> int:
    cnt = defaultdict(int)
    n = len(s)
    for i in range(n):
        for j in range(i, n):
            if s[j] != s[i]:
                break
            cnt[(s[i], j - i + 1)] += 1
    return max((k for (c, k), v in cnt.items() if v >= 3), default=-1)
```

- 全同字符时出现数最坏 $O(n^2)$，本题 $n \le 50$ 稳过（约 $10^3$ 量级）；
- 但孪生题 **2982** 把 $n$ 升到 $10^5$，$O(n^2)$ 直接超时——暴力只在 Q2 有效。

> ⚠️ 键用 `(字符, 长度)` 二元组而非子串本身，否则构造/哈希子串还要多乘一个 $O(n)$。这个细节已经在暗示：特殊子串的「身份」只由两个小整数决定。

### 3.2 核心观察：连续段计数 + 单调性 → 二分答案

![核心概念：特殊子串由(字符,长度)唯一确定，按连续段贡献计数](images/bw378_q2_run_counting.svg)

三条观察把问题从「数子串」折叠成「数段 + 二分」：

1. **特殊子串 ⇔ `(字符 c, 长度 k)`**：同字符同长度的特殊子串是**同一个串**。计数对象从 $O(n^2)$ 个子串坍缩为 $26 \times n$ 个二元组。
2. **连续段（run）贡献公式**：特殊子串不能跨字符边界。把 `s` 拆成极大同字符段，字符 $c$ 的某段长为 $L$，则 $c^k$ 在该段内恰好出现 $\max(0,\ L-k+1)$ 次（就是滑窗起点数，$k > L$ 时为 0）：

$$\text{count}(c, k) \;=\; \sum_{\text{c 的各段 } L_i} \max\!\big(0,\ L_i - k + 1\big)$$

   「长度 $k$ 是否可行」= 是否存在某个字符 $c$ 使 $\text{count}(c,k) \ge 3$，单次判定只需扫一遍所有段。
3. **单调性**：若 $c^k$ 出现 $\ge 3$ 次，取三个出现起点 $p_1 < p_2 < p_3$，则 $c^{k-1}$ 在**同样的三个起点**各出现一次（每次出现砍掉末尾字符）——所以 $k$ 可行 $\Rightarrow k-1$ 可行，**可行长度是一段前缀区间 $[1, K]$**，最大可行 $k$ 可以二分：

$$\text{ans} = \max\{\, k \;:\; \exists\, c,\ \text{count}(c, k) \ge 3 \,\}$$

> 💡 一句话：别数子串，数**段**——每段对每个 $k$ 的贡献用公式直接算出；再靠「$k$ 越小越容易凑满 3 次」的单调性，把线性扫描换成二分。

### 3.3 算法流程

![算法流程：分段计数加二分答案](images/bw378_q2_binary_search_flow.svg)

1. **分段**：一次线性扫描，把 `s` 拆成极大同字符段，按字符归组记录每段长度 `runs[c] = [L1, L2, ...]`；
2. **初始化**：`lo = 1, hi = n, ans = -1`；
3. **check(mid)**：对每个字符 `c` 累加 `max(0, L − mid + 1)`，某字符合计 `≥ 3` 即可行（26 桶互相独立，命中即短路）；
4. **收缩**：可行 → `ans = mid, lo = mid + 1`；不可行 → `hi = mid − 1`；
5. `lo > hi` 时结束，返回 `ans`（全程无可行长度则保持 `-1`）。

### 3.4 示例演算

![示例演算：aaabaaa 的分段、二分与出现位置验证](images/bw378_q2_walkthrough.svg)

以 `s = "aaabaaa"`（$n = 7$，官方示例之外的多段例子）为例。分段结果 `a: [3, 3]`、`b: [1]`，二分过程：

| lo | hi | mid | a 段计数 $(3-k+1)\times 2$ | 可行？ | 动作 |
|----|----|-----|--------------------|--------|------|
| 1 | 7 | 4 | $0 + 0 = 0$ | ✗ | `hi = 3` |
| 1 | 3 | 2 | $2 + 2 = 4 \ge 3$ | ✓ | `ans = 2, lo = 3` |
| 3 | 3 | 3 | $1 + 1 = 2 < 3$ | ✗ | `hi = 2` |

`lo = 3 > hi = 2`，二分结束，返回 **2**：`"aa"` 左段出现 2 次、右段 2 次，共 4 次 $\ge 3$；`"aaa"` 两段各 1 次共 2 次，不可行。

交叉验证官方示例：`"aaaa"` 单段 $L=4$，$k=2$ 时 $4-2+1=3$ 次 ✓（答案 2）；`"abcaba"` 中 `a` 有三段 $[1,1,1]$，$k=1$ 时 $1+1+1=3$ 次 ✓（答案 1）；`"abcdef"` 每字符仅一段长 1，任何 $k$ 都凑不满 3 次（返回 -1）。

## 4. 算法细节

### 4.1 分段（run 分解）

一次扫描：`i` 指向段首，`j` 向右推进直到 `s[j] != s[i]`，段长 `j - i` 落入 `runs[s[i]-'a']`，然后 `i = j` 跳到下一段。每字符一个桶，共 26 个；段数总和 $\le n$。

### 4.2 check 的实现要点

- 只读 `runs`，不修改——二分多轮调用无副作用；
- 每个字符的计数是独立的，用 `any` / 循环内提前 `return true` 短路；
- **截断不可省**：`max(L − k + 1, 0)`，$k$ 超过段长时贡献是 0 而非负数。

### 4.3 二分边界

闭区间模板：`lo = 1`（长度至少为 1，不含 0）、`hi = n`（最长就是整个字符串，如 $n$ 个同字符时 $k = n$ 需要 $n - n + 1 = 1$ 次，不够 3 次，但 `hi` 取 $n$ 不会漏解）、`ans = -1` 覆盖「一次都没可行过」。

### 4.4 进阶：前三大段直接出答案（$O(n)$，Q3 预备）

判定只关心「能否凑满 3 次」，而段越长贡献越多——每个字符其实只需要**最长的 3 个段**。设某字符的段长降序为 $r_1 \ge r_2 \ge r_3$，可行 $k$ 的候选只有三种凑法：

| 凑法 | 条件 | 候选 $k$ |
|------|------|----------|
| 一段连取 3 次 | $r_1 - k + 1 \ge 3$ | $r_1 - 2$ |
| 最长段 2 次 + 次长段 1 次 | $k \le r_1 - 1$ 且 $k \le r_2$ | $\min(r_1 - 1,\ r_2)$ |
| 三段各 1 次 | $k \le r_1, r_2, r_3$ | $\min(r_1, r_2, r_3)$ |

第 4 长及以后的段起手时 $k \le r_4 \le r_3$，被「三段各 1 次」支配，不可能给出更大的候选。对 26 个字符取所有候选的最大值即为答案。相比二分，这个公式法少一个 $\log$ 因子，且不需要写 `check`——Q3 中两种做法都可通过。

## 5. 正确性证明

**引理 1（出现不跨段 + 段内计数公式）**：设 $s[l..r]$ 是一个极大同字符段（字符 $c$，长 $L = r - l + 1$）。对任意 $1 \le k \le n$，$c^k$ 在 $s$ 中的每次出现都完整落在某个同字符段内；且落在该段的次数恰为 $\max(0,\ L - k + 1)$。

**证明**：$c^k$ 的一次出现是区间 $[i, i+k-1]$，满足 $s[i..i+k-1]$ 全为 $c$。若该区间与段 $[l, r]$ 相交但不被包含，则它包含 $s[l-1]$ 或 $s[r+1]$（若存在），由段的极大性这两个位置 $\ne c$，与全为 $c$ 矛盾。故每次出现完整落在某段内。段内出现要求 $l \le i \le r - k + 1$，起点恰 $\max(0, L - k + 1)$ 个。∎

**引理 2（计数可加）**：$\text{count}(c, k) = \sum_{\text{c 的各段 } L_i} \max(0, L_i - k + 1)$。

**证明**：各段互不相交，$c^k$ 的出现集合按「所在段」划分后无交并，由引理 1 对每段计数再求和即得。∎

**引理 3（单调性）**：若 $k \ge 2$ 且存在字符 $c$ 使 $\text{count}(c, k) \ge 3$，则 $\text{count}(c, k-1) \ge 3$。

**证明**：取 $c^k$ 的三个出现起点 $p_1 < p_2 < p_3$，对应区间都完整落在 $c$ 的段内。则 $[p_j, p_j + k - 2]$ 是 $c^{k-1}$ 的一次出现（每次出现的前缀），仍在同一段内，三个起点互不相同，故 $\text{count}(c, k-1) \ge 3$。∎

**定理**：设 $K = \max\{\, k \ge 1 : \exists c,\ \text{count}(c, k) \ge 3 \,\}$（不存在则记 $K = 0$）。上述算法返回 $K$，且 $K = 0$ 时返回 $-1$。

**证明**：由引理 3，谓词 $P(k) = \exists c,\ \text{count}(c,k) \ge 3$ 关于 $k$ 单调不增，可行集合是前缀 $\{1, \dots, K\}$。算法在闭区间 $[1, n]$ 上做标准二分：每轮以 $O(\text{段数})$ 的 `check` 无误判定 $P(\text{mid})$（由引理 2 的公式），可行时记录 `ans = mid` 并上移下界，不可行时下移上界，区间始终包含 $K$ 且严格缩小，至多 $O(\log n)$ 轮后区间为空。若 $K \ge 1$，最后一次记录的 `mid` 恰为 $K$；若 $K = 0$（如 `"abcdef"`），`check` 从未为真，`ans` 保持初值 $-1$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \log n)$。分段一次 $O(n)$；二分 $O(\log n)$ 轮，每轮 `check` 遍历所有段与 26 个桶，段数 $\le n$，单轮 $O(n)$。
- **空间复杂度**：$O(n)$。各字符的段长列表（段数总和 $\le n$）+ 26 个桶的常数开销。

对照：暴力逐出现计数 $O(n^2)$——Q2（$n \le 50$）可过，Q3（$n \le 10^5$）不可过；二分版对 $10^5$ 规模仍有富余，公式法（§4.4）还可再降到 $O(n)$。

## 7. 参考代码

### C++（分段 + 二分答案，Q3 原样复用）

```cpp
class Solution {
  public:
    int maximumLength(string s) {
        int n = s.size();
        // 1. 按字符收集所有连续段长度
        vector<vector<int>> runs(26);
        for (int i = 0; i < n; ) {
            int j = i;
            while (j < n && s[j] == s[i]) j++;
            runs[s[i] - 'a'].push_back(j - i);
            i = j;
        }
        // 2. check(k)：是否存在某字符长度为 k 的特殊子串出现 >= 3 次
        auto check = [&](int k) {
            for (auto& rs : runs) {
                int cnt = 0;
                for (int L : rs) cnt += max(L - k + 1, 0);
                if (cnt >= 3) return true;
            }
            return false;
        };
        // 3. 二分最大可行 k（可行 => 更短也可行，单调）
        int lo = 1, hi = n, ans = -1;
        while (lo <= hi) {
            int mid = lo + (hi - lo) / 2;
            if (check(mid)) { ans = mid; lo = mid + 1; }
            else            { hi = mid - 1; }
        }
        return ans;
    }
};
```

### Python（同解法）

```python
class Solution:
    def maximumLength(self, s: str) -> int:
        n = len(s)
        runs = [[] for _ in range(26)]
        i = 0
        while i < n:
            j = i
            while j < n and s[j] == s[i]:
                j += 1
            runs[ord(s[i]) - ord('a')].append(j - i)
            i = j

        def check(k: int) -> bool:
            return any(
                sum(max(L - k + 1, 0) for L in rs) >= 3
                for rs in runs
            )

        lo, hi, ans = 1, n, -1
        while lo <= hi:
            mid = (lo + hi) // 2
            if check(mid):
                ans = mid
                lo = mid + 1
            else:
                hi = mid - 1
        return ans
```

### Python（公式法：前三大段，$O(n)$）

```python
from collections import defaultdict

class Solution:
    def maximumLength(self, s: str) -> int:
        runs = defaultdict(list)
        i, n = 0, len(s)
        while i < n:
            j = i
            while j < n and s[j] == s[i]:
                j += 1
            runs[s[i]].append(j - i)
            i = j

        ans = -1
        for rs in runs.values():
            rs.sort(reverse=True)
            cand = rs[0] - 2                                 # 一段连取 3 次
            if len(rs) >= 2:
                cand = max(cand, min(rs[0] - 1, rs[1]))      # 最长段 2 次 + 次长段 1 次
            if len(rs) >= 3:
                cand = max(cand, min(rs[0], rs[1], rs[2]))   # 三段各 1 次
            ans = max(ans, cand)
        return ans if ans > 0 else -1
```

> 💡 三份代码在 Q3（#2982，$n \le 10^5$）均原样通过；比赛实战中 Q2 直接提交正解，Q3 复制粘贴是最稳的节奏。

## 8. 边界情况与易错点

1. **重叠出现也计数**：「出现至少三次」按位置数、重叠不算错——示例 1 `"aaaa"` 中 `"aa"` 的三个出现两两重叠，正是答案 2 的来源。若误按「不重叠」处理会漏解。
2. **贡献公式的截断**：`max(L − k + 1, 0)` 不可省——$k > L$ 的段贡献是 0 而非负数，否则会把别的段的计数抵消掉。
3. **`ans` 初值 `-1`**：二分全程未可行（如 `"abcdef"` 每字符仅一段长 1）时必须返回 `-1`，不要用 `ans = 0` 起手。
4. **二分下界从 1 开始**：子串非空，长度 0 不是合法答案；`lo = 0` 会在 `check(0)` 时把「任意段长 $\ge 3$」误判为可行长度 0。
5. **公式法的候选截断**：$r_1 = 2$ 时候选 $r_1 - 2 = 0$、$r_1 = r_2 = 1$ 时候选 $\min(r_1-1, r_2) = 0$——这些是「凑法本身不可行」的信号（合法长度至少 1），必须最终回落到 `-1`，是公式法最易翻车的边界。
6. **键用二元组**：暴力法若用子串本身做键，$n \le 50$ 勉强能过，但到 Q3 的规模会连哈希开销都爆炸——从 Q2 就养成 `(字符, 长度)` 的习惯。
7. **Q2 与 Q3 的取舍**：比赛时若时间紧张，Q2 先交 $O(n^2)$ 暴力保底，再回头写正解交 Q3；若节奏从容，直接写正解一次过两题。
