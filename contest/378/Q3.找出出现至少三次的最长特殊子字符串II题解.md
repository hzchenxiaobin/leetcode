# LeetCode 找出出现至少三次的最长特殊子字符串 II 题解

## 1. 题目概述

- **标题 / 题号**：找出出现至少三次的最长特殊子字符串 II（#2982，medium）
- **链接**：https://leetcode.cn/problems/find-longest-special-substring-that-occurs-thrice-ii/
- **来源**：LeetCode 第 378 场周赛 Q3
- **难度**：中等
- **标签**：字符串、哈希表、二分查找、计数、滑动窗口

**题意**：给定仅由小写字母组成的字符串 `s`。仅由单一字符组成的字符串称为**特殊**字符串。返回在 `s` 中出现**至少三次**的**最长特殊子字符串**的长度，不存在则返回 `-1`。「出现」按**起点位置**计数，**重叠也算**。

**约束**：

- $3 \le s.length \le 5 \times 10^5$
- `s` 仅由小写英文字母组成

> 💡 **周赛视角**：本题与 Q2（#2981）是**同题面双数据档**——$n$ 从 $50$ 放大到 $5 \times 10^5$（一万倍）。看到同题面的第一动作是**回头核验 Q2 解法的复杂度**：若 Q2 交的是 $O(n^2)$ 暴力，Q3 必须现场换解法；若 Q2 写的是正解（游程分解 + 二分，$O(n \log n)$），Q3 **复制粘贴即过**。本文沿「平移 → 升级」复盘：先确认二分解为何原样能过，再把它压缩到 $O(n)$——每字符只维护**前三大**。

## 2. 示例

**示例 1**

```text
输入：s = "aaaa"
输出：2
解释：出现三次的最长特殊子字符串是 "aa"："aa"aa、a"aa"a 和 aa"aa"。
三个出现位置两两重叠，重叠也算次数——这是本题最关键的计数规则。
```

**示例 2**

```text
输入：s = "abcdef"
输出：-1
解释：不存在出现至少三次的特殊子字符串。
```

**示例 3**

```text
输入：s = "abcaba"
输出：1
解释："a" 出现三次（下标 0、3、5）；任何长度 2 的特殊子串都凑不满三次。
```

## 3. 解题思路

### 3.1 暴力思路：数据放大一万倍后彻底死亡

枚举每个起点 $i$ 向右扩展（同字符才继续），以 `(字符, 长度)` 为键哈希计数，最后取计数 $\ge 3$ 的最长键。全同字符时出现总数为 $\binom{n+1}{2}$：

- Q2（$n \le 50$）：至多约 $1275$ 个出现，稳过；
- Q3（$n = 5 \times 10^5$）：约 $1.25 \times 10^{11}$ 个出现，哈希表同样要存 $O(n^2)$ 个键——**时间、空间双杀**，连 C++ 都救不回来。

> ⚠️ $5 \times 10^5$ 这个范围本身就是题面的一部分：只给 $O(n)$ 与 $O(n \log n)$ 留了门。Q2 里「暴力能过」的侥幸在 Q3 一文不值。
>
> 好消息：Q2 的正解（游程分解 + 二分答案，$O(n \log n)$，见同目录 `Q2.找出出现至少三次的最长特殊子字符串I题解.md`）平移到本档毫无压力——扫描 $5 \times 10^5$，二分约 $19$ 轮、每轮 $O(n)$ 判定，总量 $\approx 10^7$，**原样复制即过**，这是赛场最短路径。下面把复盘做完：还能一步到 $O(n)$。

### 3.2 核心观察：判定只看「第三大」

![核心概念：出现至少三次等价于长度不超过 len 值第三大](images/bw378_q3_top3_concept.svg)

Q2 已经把计数折叠到游程上：$\mathrm{occ}(c, k) = \sum_{c \text{ 的各段}} \max(0,\ L - k + 1)$。再往前推一步——定义 $len[i]$ 为**以 $i$ 结尾的同字符延续长度**（$s[i] = s[i-1]$ 时 $len[i] = len[i-1] + 1$，否则 $len[i] = 1$），则长 $L$ 的游程内部 $len$ 值恰为 $1, 2, \dots, L$ 各一次，于是

$$\mathrm{occ}(c, x) \;=\; \#\{\, i : s[i] = c,\ len[i] \ge x \,\}$$

（每个 $len[i] \ge x$ 的位置 $i$ 恰对应 $c^x$ 以 $i - x + 1$ 为起点的一次出现，一一对应。）**判定于是变成数数**：

$$\mathrm{occ}(c, x) \ge 3 \iff \text{至少 3 个 } len \text{ 值} \ge x \iff x \le \text{该字符 } len \text{ 值的第三大}$$

1. **阈值是 3** → 每个长度是否可行只由**前三大** $len$ 值决定，第 4 大及以后「轮不到」卡住第三个（§5 引理 3 严格化）；
2. **每字符的答案就是它的 $len$ 值第三大**，连二分的 `check` 都不用写；
3. 翻译回游程语言：设字符 $c$ 的三大游程长为 $r_1 \ge r_2 \ge r_3$（不足补 $0$），第三大 $= \max(r_1 - 2,\ \min(r_1 - 1, r_2),\ r_3)$——正是 Q2 §4.4 埋下的三候选公式，两条视角互为验证。

> 💡 一句话：Q2 用二分搜「最大可行长度」，这里直接给出闭式——**答案 = 各字符 $len$ 值第三大的最大值**，一次扫描、$26 \times 3$ 的小表就够了。

### 3.3 算法流程

![算法流程：一次扫描维护前三大表，收尾套三候选公式](images/bw378_q3_algorithm_flow.svg)

1. **扫描**：游程分解（与 Q2 完全相同的双指针），每段结束时把段长 $L$ **即时插入** $\mathrm{top3}[c]$——降序 3 槽、3 次比较，**不必存下全部段**（Q2 的 `runs` 列表整个省掉）；
2. **汇总**：对 26 个字符套三候选公式 $\mathrm{cand} = \max(r_1 - 2,\ \min(r_1 - 1, r_2),\ r_3)$；
3. **兜底**：$\mathrm{cand} \ge 1$ 才是合法长度，取全局最大；`ans` 初值 `-1`。

变体：不找段边界，**每个位置**把「当前延续长度」插入 $\mathrm{top3}[s[i]]$（游程内依次插 $1, 2, \dots, L$）——代码更短，第三大直接就是候选，见 §7。

### 3.4 示例演算

![示例演算：aaabaaa 两条视角同得答案 2](images/bw378_q3_walkthrough.svg)

以 $s = $ `"aaabaaa"`（与 Q2 演算同例，两版可对照）为例。**① 游程**：`a: [3, 3]`、`b: [1]`；**② len 值**：`1 2 3 | 1 | 1 2 3`，即 `a` 的多重集 $\{3,3,2,2,1,1\}$、`b` 为 $\{1\}$；**③ 取前三大**：

| 字符 | len 值多重集 | 前三大 | 三候选（$r_1{-}2$ / $\min(r_1{-}1, r_2)$ / $r_3$） | 候选 |
|------|-------------|--------|--------------------------------------------------|------|
| a | $\{3,3,2,2,1,1\}$ | $[3,3,2]$ | $1$ / $\min(2,3)=2$ / $0$ | **2** |
| b | $\{1\}$ | 不足 3 个 | — | 无 |

**④ 验证**：$\mathrm{occ}(a, 2) = (3-2+1) \times 2 = 4 \ge 3$ ✓；$\mathrm{occ}(a, 3) = 1 + 1 = 2 < 3$ ✗。两条视角同得 **2**。

官方三例速验：

| s | 关键计算 | 答案 |
|----|----------|------|
| `"aaaa"` | `a: [4]` → $\max(4-2,\ \min(3,0),\ 0) = 2$ | 2 |
| `"abcdef"` | 每字符 $[1]$ → 候选均 $< 1$ | $-1$ |
| `"abcaba"` | `a: [1,1,1]` → $\max(-1,\ \min(0,1),\ 1) = 1$ | 1 |

## 4. 算法细节

### 4.1 游程分解 + 3 槽插入的不变量

扫描始终维持不变量：$\mathrm{top3}[c]$ 是**已处理游程**长度的前三大（降序、不足补 $0$）。三次比较覆盖 $L$ 落入三个槽位的全部情况；**等值比较用严格 `>`**——第二个长 3 的游程落进 $t[1]$，重复长度被正确保留（得到 $[3,3,\dots]$ 而非丢掉一个 3）。

### 4.2 三候选公式的哨兵约定

$r_2, r_3$ 缺省取 $0$，正好兼任两种语义：**游程不存在**（该凑法无从谈起）与**候选 $\le 0$**（不是合法长度，子串非空）。所以统一判 `cand >= 1`，全局 `ans` 初值 `-1`，两者不要混用。

### 4.3 len 插入变体

每个位置把「当前延续长度」插入 $\mathrm{top3}[s[i]]$：游程内依次插 $1, 2, \dots, L$，**重复值天然保留**（两个长 3 的游程最终得到 $[3,3,2]$）；不用显式找段边界，`top3[c][2] > 0` 恰好表示该字符至少有 3 个 $len$ 值（哨兵 0 即「不足」）。

### 4.4 赛场取舍：平移还是重写

- **Q2 交了正解** → Q3 原样复制提交，省下的时间攻 Q4（困难题，时间很值钱）；
- **Q2 交了暴力** → Q3 必须现场写正解：三候选公式比二分少两处易错点（二分边界、`check` 截断），且天然 $O(n)$，推荐公式法；
- **复杂度核验习惯**：$n = 5 \times 10^5$ 下，$n^2 \approx 10^{11}$（死）、$n \log n \approx 10^7$（过）、$n = 5 \times 10^5$（从容）——先对量级，再动手。

## 5. 正确性证明

记 $\mathrm{occ}(c, x)$ 为 $c^x$ 在 $s$ 中的出现次数（按起点位置计、可重叠）；$len[i]$ 为以 $i$ 结尾的同字符延续长度；字符 $c$ 的游程长度降序为 $L_1 \ge L_2 \ge L_3 \ge \cdots$（不足补 $0$）。

**引理 1（段内计数公式）**：$\mathrm{occ}(c, x) = \sum_{c \text{ 的各游程}} \max(0,\ L - x + 1)$。

**证明**：$c^x$ 的一次出现是区间 $[i, i+x-1]$，全为 $c$；若它与某极大游程相交却不被包含，则必含该游程的相邻位置（由极大性 $\ne c$），矛盾。故每次出现完整落在某游程内，且游程内起点需满足 $l \le i \le r - x + 1$，恰 $\max(0, L - x + 1)$ 个；游程互不相交，求和即得。∎

**引理 2（len 等价）**：$\mathrm{occ}(c, x) = \#\{\, i : s[i] = c,\ len[i] \ge x \,\}$。

**证明**：$len[i] \ge x$ 当且仅当 $s[i-x+1..i]$ 全为 $c$（长度 $x$ 的窗口落在 $i$ 所在游程内），即 $c^x$ 以 $i - x + 1$ 为起点的一次出现；反之，每次出现去掉末尾字符即得一个这样的位置 $i$。两者一一对应。∎

**引理 3（三候选公式与支配性）**：

$$\max\{\, x \ge 1 : \mathrm{occ}(c, x) \ge 3 \,\} \;=\; \max\big(L_1 - 2,\ \min(L_1 - 1, L_2),\ L_3\big)$$

（右端 $\le 0$ 时左端集合为空）；特别地，**第 4 长及以后的游程不影响结果**。

**证明**：

（≥，三种凑法都可行）设 $y$ 为右端三候选之一且 $y \ge 1$，逐个验证 $\mathrm{occ}(c, y) \ge 3$：

- $y = L_1 - 2$：最长游程单独贡献 $L_1 - y + 1 = 3$（引理 1）；
- $y = \min(L_1 - 1, L_2)$：两大游程合计 $(L_1 - y + 1) + (L_2 - y + 1)$。若 $y = L_1 - 1$（此时 $L_2 \ge y$），等于 $2 + (L_2 - L_1 + 2) \ge 3$；若 $y = L_2$（此时 $L_2 \le L_1 - 1$），等于 $(L_1 - L_2 + 1) + 1 \ge 3$；
- $y = L_3$：三大游程各贡献 $L_i - L_3 + 1 \ge 1$，合计 $\ge 3$。

故右端每个 $\ge 1$ 的候选都是可行长度。

（≤，可行长度不超出三候选）设 $x \ge 1$ 且 $\mathrm{occ}(c, x) \ge 3$，按**贡献游程**（$L_i \ge x$ 者，其余贡献为 0）的个数 $m$ 分类：

- $m \ge 3$：$x \le$ 第 3 长贡献游程 $\le L_3$；
- $m = 2$：设两贡献游程长 $d_1 \ge d_2$，则 $(d_1 - x + 1) + (d_2 - x + 1) \ge 3$。由 $d_2 \ge x$ 得 $x \le d_2 \le L_2$；又若 $x \ge L_1$ 则 $d_1, d_2 \le x$，两项之和 $\le 2 < 3$，矛盾，故 $x \le L_1 - 1$。于是 $x \le \min(L_1 - 1, L_2)$；
- $m = 1$：$d_1 - x + 1 \ge 3 \Rightarrow x \le d_1 - 2 \le L_1 - 2$；
- $m = 0$：$\mathrm{occ}(c, x) = 0$，与 $\ge 3$ 矛盾。

三种情形分别被三个候选支配，故 $x \le \max(\text{三候选})$。∎

**引理 4（第三大刻画）**：若 $c$ 的 $len$ 值不足 3 个（即 $c$ 在 $s$ 中出现不足 3 次），则不存在可行 $x$；否则 $\max\{\, x : \mathrm{occ}(c, x) \ge 3 \,\}$ 等于 $c$ 的 $len$ 值（按位置计、含重复）的**第三大** $t_c$。

**证明**：由引理 2，$\mathrm{occ}(c, x) \ge 3 \iff$ 至少 3 个 $len$ 值 $\ge x \iff x \le t_c$（顺序统计量的定义）。$len$ 值总数恰为 $c$ 的出现次数。∎

**定理**：本文算法（一次扫描维护每字符前三大游程长，按引理 3 的公式逐字符求候选并取全局最大，全空时返回 $-1$）返回出现至少三次的最长特殊子字符串长度；`len` 插入变体（维护 $len$ 值前三大、直接取第三大）同样正确。

**证明**：答案是 $\max_c \max\{\, x \ge 1 : \mathrm{occ}(c, x) \ge 3 \,\}$（不存在则 $-1$）。由 §4.1 的不变量，算法收尾读到的 $(r_1, r_2, r_3)$ 就是 $(L_1, L_2, L_3)$；由引理 3，逐字符候选恰为内层最大值，`cand ≥ 1` 过滤掉「凑法不可行」的 $\le 0$ 候选，全局取最大即得答案。`len` 变体由引理 4 直接得出同一内层最大值。两个版本一致，且与 Q2 二分答案的输出相同——三者都是同一个 $\max$ 的定义式。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。一次扫描完成游程分解，每段 3 次比较插入；收尾对 26 个字符各 $O(1)$ 套公式。
- **空间复杂度**：$O(1)$。$26 \times 3$ 个整数的定长表，与 $n$ 无关（Q2 的二分解还需 $O(n)$ 存全部段长——平移时可保留，重写时可省掉）。
- **三档对照**（$n = 5 \times 10^5$）：暴力 $\approx 1.25 \times 10^{11}$ 不可过；二分平移 $\approx 10^7$ 可过（C++ 从容，CPython 建议把 `check` 写成紧循环）；公式法 $5 \times 10^5$ 次操作，从容。

## 7. 参考代码

### C++（游程 top3 + 三候选公式，$O(n)$ / $O(1)$）

```cpp
class Solution {
  public:
    int maximumLength(string s) {
        int top[26][3] = {};                  // top[c]：字符 c 的三大游程长（降序，缺省 0）
        int n = s.size(), i = 0;
        while (i < n) {                       // 游程分解（同 Q2），段长即时插入
            int j = i;
            while (j < n && s[j] == s[i]) j++;
            int L = j - i;
            int* t = top[s[i] - 'a'];
            if      (L > t[0]) { t[2] = t[1]; t[1] = t[0]; t[0] = L; }
            else if (L > t[1]) { t[2] = t[1]; t[1] = L; }
            else if (L > t[2]) { t[2] = L; }
            i = j;
        }
        int ans = -1;
        for (auto& t : top) {
            int cand = max({t[0] - 2, min(t[0] - 1, t[1]), t[2]});
            if (cand >= 1) ans = max(ans, cand);
        }
        return ans;
    }
};
```

### Python（同构）

```python
class Solution:
    def maximumLength(self, s: str) -> int:
        top = [[0, 0, 0] for _ in range(26)]   # top[c]：字符 c 的三大游程长（降序，缺省 0）
        i, n = 0, len(s)
        while i < n:
            j = i
            while j < n and s[j] == s[i]:
                j += 1
            L, t = j - i, top[ord(s[i]) - 97]
            if L > t[0]:
                t[0], t[1], t[2] = L, t[0], t[1]
            elif L > t[1]:
                t[1], t[2] = L, t[1]
            elif L > t[2]:
                t[2] = L
            i = j

        ans = -1
        for r1, r2, r3 in top:
            cand = max(r1 - 2, min(r1 - 1, r2), r3)
            if cand >= 1:
                ans = max(ans, cand)
        return ans
```

### Python（len 插入变体：第三大即答案）

```python
class Solution:
    def maximumLength(self, s: str) -> int:
        top = [[0, 0, 0] for _ in range(26)]   # top[c]：字符 c 的 len 值前三大（降序）
        run, prev = 0, ''
        for ch in s:
            run = run + 1 if ch == prev else 1
            prev = ch
            t = top[ord(ch) - 97]
            if run > t[0]:
                t[0], t[1], t[2] = run, t[0], t[1]
            elif run > t[1]:
                t[1], t[2] = run, t[1]
            elif run > t[2]:
                t[2] = run
        third = max(t[2] for t in top)          # 第三大 len（0 = 该字符不足 3 个值）
        return third if third > 0 else -1
```

> 💡 三份代码互为验证：前两份走「游程 → 三候选」，第三份走「len → 第三大」，同一答案两条路。Q2 题解的二分解（$O(n \log n)$）原样复制提交亦可通过，此处不再重复贴出。

## 8. 边界情况与易错点

1. **候选值的 0/负数截断**：$r_1 \le 2$ 时 $r_1 - 2 \le 0$、只有一段时 $\min(r_1-1, r_2) = 0$——这是「凑法不可行」的信号而非答案，必须 `cand >= 1` 才更新，最终回落 `-1`（公式法第一大翻车点，Q2 §4.4 同款）。
2. **前三大不去重**：`"aaabaaa"` 的 `a` 是 $[3,3,\dots]$，两个长 3 的游程都要保留，第三大才是 2——len 插入天然保留重复；游程插入用严格 `>` 也正确（第二个 3 落进 $t[1]$）。
3. **全同字符长串**：$n$ 个 `a` 时答案 $n - 2$（$r_1 - 2$ 生效）；`"aaa"` → 1。别把公式或二分上界错误地砍到 $n-2$ 以外。
4. **重叠计数**：示例 1 的 `"aa"` 在 `"aaaa"` 中算 3 次——按「出现起点」计数是全部公式的共同前提，读题漏了这半句全盘皆错。
5. **二分平移的边界**：若复制 Q2 二分解，闭区间 `lo = 1, hi = n` 模板别动；`check` 里 `max(L - k + 1, 0)` 的截断别删（负贡献会抵消其他段）。
6. **CPython 性能**：二分法约 $10^7$ 次内层迭代，C++ 从容、CPython 偏紧——把 `check` 写成紧循环，或直接用本文 $O(n)$ 解法。
7. **空间错觉**：按 `(字符, 长度)` 存哈希键是 $O(26n)$——Q2 可用但没必要，本档规模下更应直接上 $26 \times 3$ 小表。

- [LeetCode 875. 爱吃香蕉的珂珂](https://leetcode.cn/problems/koko-eating-bananas/)：二分答案 + $O(n)$ 判定的经典模板，Q2 二分解的骨架来源。
- [LeetCode 1759. 统计同质子字符串的数目](https://leetcode.cn/problems/count-number-of-homogenous-substrings/)：同一「游程内 $len$ 值 $1..L$」的计数视角，把「出现次数」换成「子串总数」（每游程贡献 $L(L+1)/2$）。
- [LeetCode 467. 环绕字符串中唯一的子字符串](https://leetcode.cn/problems/unique-substrings-in-wraparound-string/)：`len[i]` 视角做去重计数的招牌题。

**延伸思考**：

- **推广到「至少 $m$ 次」**：阈值换成 $m$ → 每字符维护前 $m$ 大（`len` 插入变体只改槽位数，第 $m$ 大直接就是候选）；三候选公式则需枚举「前 $j$ 长的段凑 $m$ 次」的 $j = 1 \dots m$ 种凑法。
- **改为不重叠计数**：段内贡献变为 $\lfloor L / x \rfloor$，可行性仍单调、二分仍可用；但「第三大」闭式失效（贡献不再是 $len$ 的线性函数）——这是「闭式解 vs 二分」适用边界的典型案例。
- **赛场策略沉淀**：出题人把同一题拆成双数据档（I/II）是常见赛制，读到同题面先核验已有解法复杂度，能省下一次完整的重新思考。
