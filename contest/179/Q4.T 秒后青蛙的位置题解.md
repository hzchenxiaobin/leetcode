# LeetCode T 秒后青蛙的位置 题解

## 1. 题目概述

- **标题 / 题号**：T 秒后青蛙的位置（#1377，hard）
- **链接**：https://leetcode.cn/problems/frog-position-after-t-seconds/
- **来源**：LeetCode 第 179 场周赛 Q4
- **难度**：困难
- **标签**：树、深度优先搜索、广度优先搜索、图、概率

**题意**：一棵 $n$ 个顶点的**无向树**（顶点编号 $1 \sim n$），青蛙从**顶点 1** 出发按秒跳跃：每秒跳到一个**未访问**过的相邻顶点（若有多条可选，**等概率**任选其一）；若没有未访问的相邻顶点，则**原地跳**（位置不变）。求 $t$ 秒后青蛙位于 `target` 的概率，误差不超过 $10^{-5}$。

**约束**：

- $1 \le n \le 100$；`edges.length` $= n - 1$（保证构成树）
- $1 \le t \le 50$；$1 \le \text{target} \le n$

> 💡 赛点复盘：本场 Q3（通知所有员工所需的时间）刚考完「树上一趟遍历传**时刻**」，Q4 立刻升级为「树上一趟遍历传**概率**」——骨架同款，叠加两处新毒点：① 概率要沿路径**连乘衰减**（除的是「跳出节点」的分支数，不是 target 的）；② 「**早到非叶必跳走**」的三态判定。赛时先把判定条件列全再动手，比边写边 debug 快得多。

## 2. 示例

**示例 1**（官方：恰时到达）

```text
输入：n = 7, edges = [[1,2],[1,3],[1,7],[2,4],[2,6],[3,5]], t = 2, target = 4
输出：0.16666666666666666
解释：青蛙从 1 起跳，第 1 秒有 1/3 概率跳到 2；
      第 2 秒在 2 处有 2 个未访问邻居 {4,6}，有 1/2 概率跳到 4。
      因此 2 秒后位于 4 的概率 = 1/3 × 1/2 = 1/6。
```

**示例 2**（官方：第 1 秒即命中）

```text
输入：n = 7, edges = [[1,2],[1,3],[1,7],[2,4],[2,6],[3,5]], t = 1, target = 7
输出：0.3333333333333333
解释：1 的未访问邻居 {2,3,7} 共 3 个，1 秒后跳到 7 的概率 = 1/3。
```

**示例 3**（自拟：早到被困在叶上）

```text
输入：n = 7, edges = [[1,2],[1,3],[1,7],[2,4],[2,6],[3,5]], t = 3, target = 4
输出：0.16666666666666666
解释：青蛙最快第 2 秒到 4（概率 1/6），4 是叶子无路可跳，
      之后每秒原地跳，第 3 秒仍在 4 —— 早到被困，概率不随等待衰减。
```

**示例 4**（自拟：早到但被迫跳走）

```text
输入：n = 7, edges = [[1,2],[1,3],[1,7],[2,4],[2,6],[3,5]], t = 2, target = 2
输出：0
解释：青蛙第 1 秒以 1/3 概率到 2，但 2 还有未访问邻居 {4,6}，
      第 2 秒必须跳走且再也回不来（无环）—— 早到非叶，概率清零。
```

## 3. 解题思路

### 3.1 暴力思路：模拟 + 访问历史

最直觉的做法是按秒推进分布：`dp[time][node]` 存「时刻 time 青蛙位于 node 的概率」，每秒把概率搬到未访问邻居或原地。**致命问题**在「未访问」依赖**历史路径**——同一个节点在不同时刻、经不同路径到达时，已访问集合不同，可选去向也不同，状态必须带上访问掩码：

$$\text{dp}[\text{time}][\text{node}][\text{mask}], \quad \text{mask} \in 2^{[n]}$$

$n = 100$ 时状态数 $2^{100}$，完全不可行。退而求其次做蒙特卡洛抽样，$10^{-5}$ 的绝对精度大约需要 $10^{10}$ 量级样本（$\sigma \sim 1/\sqrt{N}$），也跑不动。

> ⚠️ 两者的共同病灶：把「不能回访」当成需要记录历史的一般图问题。只要意识到输入是**树**，「已访问邻居」就坍缩成唯一的「父节点」，历史依赖瞬间消失——这正是本题从 $2^n$ 降到 $O(n)$ 的钥匙。

### 3.2 核心观察：无环 ⟹ 已访问邻居 = 父节点

![核心观察：树无环，已访问邻居恰是父节点，概率沿路径连乘 1/cnt 传播](images/wc179_q4_tree_prob_concept.svg)

推理链三步：

1. **轨迹即路径**：青蛙走过的顶点序列始终是从 1 出发的一条简单路径（若某步跳回先前顶点，则序列含环，与树无环矛盾）。于是任意时刻的**已访问集合 = 根到当前位置的路径**，而路径上与当前位置相邻的只有**父节点**一个；
2. **可选去向数**：站在 $u$（来自父节点）时，未访问邻居数恰为
   $$c(u) = \deg(u) - [u \ne 1]$$
   （顶点 1 无父节点，不减 1）；每个去向等概率 $1/c(u)$；
3. **概率连乘**：青蛙若要踩中 $v$，必须沿**唯一**的根到 $v$ 路径走（跳进别的子树后无环保证永远回不来），逐节点除以 $c(u)$ 累乘即 $p(v)$。

> ⚠️ **除的是「跳出节点」的 $c$，不是 $v$ 自己的**：$v$ 的 $c(v)$ 只在「早到判停留」时用（$c(v) = 0$ ⟹ 困在原地）。误写成对 $v$ 也除一次，会在 $v$ 为叶子时除以 0、在 $v$ 非叶时白白缩小概率。

### 3.3 算法流程：BFS 预计算 (depth, prob) + 三态判定

![算法流程：一趟 BFS 求出各点到达时刻与概率，末端按 depth 与 t 的关系三态串联判定](images/wc179_q4_bfs_judge_flow.svg)

一趟 BFS 从顶点 1 出发，同时算出每个顶点的**到达时刻** `depth[v]`（= 以 1 为根的深度，因为每跳一步深度恰 +1）与**到达概率** `prob[v]`；末端正对 `target` 做三态判定：

1. `depth[target] > t`：路径比时间还长，**没跳到** ⟹ 返回 0；
2. `depth[target] == t`：**恰在第 t 秒踩到**（此后是否跳走不影响「时刻 t 在此」）⟹ 返回 `prob[target]`；
3. `depth[target] < t`：**到早了**，青蛙必须在此后每一秒都停在 `target` 才行 ⟺ `target` 无孩子（叶子，或 $n=1$ 时的孤立根）⟹ 返回 `prob[target]`；否则被迫跳走且无环 ⟹ 永不返回，返回 0。

> 💡 BFS 里判「未访问」直接用 `depth[v] == -1`：父节点早已赋过深度，天然剔除来路，连 `parent` 数组都可省。判定「无孩子」用度数统一写法：`g[target].size() == (target != 1)`——$n=1$ 与 `target=1` 两种根特例被这一个表达式同时收编（见 §4 第 4 条）。

### 3.4 示例演算

![示例演算：同一棵树上 t=2/target=4、t=3/target=4、t=2/target=2 三种命运，覆盖三态判定](images/wc179_q4_walkthrough_three_cases.svg)

用官方那棵树（`1-{2,3,7}, 2-{4,6}, 3-{5}`）逐顶点走查 BFS 产出：

| 顶点 | 深度 depth | 分支数 $c$ | 到达概率 prob | 备注 |
|---|---|---|---|---|
| 1 | 0 | 3 | 1 | 根：$\deg(1)=3$ 不减 1 |
| 2 | 1 | 2 | 1/3 | 去掉来路 1 后剩 {4,6} |
| 3 | 1 | 1 | 1/3 | 剩 {5} |
| 7 | 1 | 0 | 1/3 | 叶子：被困原地 |
| 4 | 2 | 0 | **1/6** | $1/3 \times 1/2$ |
| 6 | 2 | 0 | 1/6 | 同上 |
| 5 | 2 | 0 | 1/3 | $1/3 \times 1$ |

三组参数对照三态（详图见上）：

- **Case A**（$t=2$，`target=4`）：`depth=2==t` 恰时踩点 ⟹ $1/6$ ✓；
- **Case B**（$t=3$，`target=4`）：`depth=2<t` 且 4 无孩子 ⟹ 困在叶上停到第 3 秒，$1/6$ ✓（**等待不掉价**）；
- **Case C**（$t=2$，`target=2`）：`depth=1<t` 但 2 有孩子 {4,6} ⟹ 第 2 秒必跳向 4 或 6（各 1/2），2 处清零 ✗。

结果分别为 $1/6$、$1/6$、$0$，与 §2 示例 1/3/4 一致 ✓。

## 4. 算法细节

1. **建图**：`g[1..n]` 无向邻接表，双向加边；`edges` 为空（$n=1$）时表为空、BFS 只访问根，不崩。
2. **BFS 判重代替 parent**：`depth[v] == -1` ⟺ $v$ 是 $u$ 的孩子（父节点早有深度，兄弟不会重复入队）。若喜欢显式记录 `parent[u]`，则「未访问邻居数」可写成 `count(v in g[u] if v != parent[u])`，两者等价。
3. **分支数就地计算**：`cnt = g[u].size() - (u != 1)`。$u$ 为叶时 `cnt=0`，但循环体不会执行（没有可入队的孩子），**不会除以 0**。
4. **「无孩子」的统一判式**：`stuck = (g[target].size() == (target != 1))`。展开验证：叶子（非根，度 1）✓；$n=1$ 时的孤立根（度 0 == 0）✓；`target=1` 且 $n>1$（度 $n-1 \ge 1 \ne 0$）不困 ✓。一个式子收编三个特例。
5. **剪枝（可选）**：`depth > t` 的层不必再扩展——$t$ 秒后青蛙不可能出现在比 $t$ 更深的顶点。$n \le 100$ 时收益微乎其微，且注意剪枝后「无孩子」判定仍须看**原始度数**，不能看「有没有被扩展」。
6. **精度账**：路径最多 99 步除法、每次除以至多 99 ⟹ 最小概率 $\sim 99^{-99} \approx 10^{-198}$，远高于 `double` 的最小正规数 $10^{-308}$，无下溢风险；`float` 约 7 位有效数字勉强但别赌，直接 `double`。

## 5. 正确性证明

**引理 1（轨迹即路径）**：设青蛙（跳离顶点 1 前）依次经过 $1 = v_0, v_1, \dots, v_k$，则该序列是从 1 到 $v_k$ 的一条简单路径，且任意时刻的已访问集合恰为 $\{v_0, \dots, v_j\}$（$j$ 为当前步数）。

**证明**：对步数归纳。初始时序列仅含 $v_0 = 1$，成立。设前 $j$ 步结论成立。第 $j+1$ 步只能跳向 $v_j$ 的某个**未访问**邻居，由归纳假设即某个 $v_i\ (i > j)$ 之外的顶点，序列仍两两相邻且无重复；若新顶点 $v_{j+1}$ 曾在序列中出现（$v_{j+1} = v_i,\ i \le j-1$），则 $v_i \to v_{i+1} \to \dots \to v_j \to v_{j+1} = v_i$ 构成环，与树无环矛盾。故序列是简单路径，已访问集合归纳成立。∎

**引理 2（路径上与当前位置相邻的旧顶点唯一）**：站在 $v_j$ 时，已访问的邻居恰为 $v_{j-1}$（父节点）一个。

**证明**：已访问集合是路径 $\{v_0, \dots, v_j\}$，其中与 $v_j$ 相邻的若还有 $v_i\ (i \le j-2)$，则 $v_i \to \dots \to v_j \to v_i$ 成环，与无环矛盾。故可选去向数 $c(v_j) = \deg(v_j) - [v_j \ne 1]$（$v_0 = 1$ 是唯一无父时刻）。∎

**引理 3（到达概率公式）**：青蛙恰在时刻 $\mathrm{depth}(v)$（$v$ 以 1 为根的深度）以概率
$$p(v) = \prod_{u \in \mathrm{path}(1 \to v),\, u \ne v} \frac{1}{c(u)}$$
**首次**到达 $v$；且一旦跳离路径上某节点进入其他子树，永远无法再到达 $v$。

**证明**：对深度归纳。$v = 1$ 时时刻 0 概率 1 成立。设 $u$ 是 $v$ 的父节点。由树上路径唯一性与引理 1，到达 $v$ 的必经方式是「时刻 $\mathrm{depth}(u)$ 首达 $u$，下一秒跳向 $v$」；由引理 2 该步概率为 $1/c(u)$，且各去向互斥等概，故 $p(v) = p(u) / c(u)$，展开即连乘式。跳离 $u$ 进入别的子树后，$u$ 已在已访问集合中且引理 1 保证已访问集合只增不减，故再也回不到 $u$，更到不了 $v$。∎

**引理 4（吸收条件）**：青蛙到达 $v$ 后从此每秒原地跳 ⟺ $c(v) = 0$（$v$ 无孩子，即叶子或孤立根）；若 $c(v) > 0$，则下一秒必跳走且 $v$ 进入已访问集合、永不返回。

**证明**：$c(v) = 0$ ⟹ 无未访问邻居 ⟹ 规则规定原地跳，且该状态自锁。$c(v) > 0$ ⟹ 有未访问邻居，规则不允许停留，必跳向其一；跳离后 $v$ 已访问，由引理 1 永不返回。∎

**定理（三态判定）**：
$$\Pr[\text{时刻 } t \text{ 位于 } target] = \begin{cases} p(target), & \mathrm{depth}(target) = t, \\ p(target), & \mathrm{depth}(target) < t \text{ 且 } c(target) = 0, \\ 0, & \text{其余（} \mathrm{depth} > t \text{，或 } \mathrm{depth} < t \text{ 且 } c(target) > 0\text{）}. \end{cases}$$

**证明**：事件「时刻 $t$ 在 `target`」⟺ 「首次到达时刻 $s \le t$」且「$(s, t]$ 内停在 `target`」。

- 由引理 3，首达时刻 $s = \mathrm{depth}(target)$（到达即首达，路径唯一）；
- $s > t$：不可能到达，概率 0；
- $s = t$：恰在第 $t$ 秒首达，概率 $p(target)$，之后是否跳走不影响「时刻 $t$ 在此」；
- $s < t$：需 $(s, t]$ 内每秒停留，由引理 4 ⟺ $c(target) = 0$，概率 $p(target)$；否则第 $s+1$ 秒起已离开且永不返回，概率 0。∎

**推论（算法正确性）**：BFS 入队的二元组恰为 $(v, \mathrm{depth}(v), p(v))$——初始 $(1, 0, 1)$ 成立；出队 $u$ 时由引理 2 的 $c(u)$ 把孩子以 $(v, \mathrm{depth}(u)+1,\ p(u)/c(u))$ 入队，归纳知全体正确，返回值按定理的三态计算即答案。∎

> ⚠️ 证明的全部地基是「树上无环 + 路径唯一」。若把图换成一般无向图，引理 1 即失效（可绕环回来），状态被迫带上历史——这正是 §3.1 掩码 DP 的困境来源，也划定了本题解法的适用边界。

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。建邻接表 $O(n)$；BFS 中每个顶点恰进出队一次、每条树边恰被查看常数次（双向各一次）；末端判定 $O(1)$。$n = 100$ 时微秒级，$t \le 50$ 完全用不上。
- **空间复杂度**：$O(n)$。邻接表 $2(n-1)$ 条边 + `depth` / `prob` 两个数组 + 队列峰值（最宽一层的顶点数）。
- **对比**：掩码 DP $O(n \cdot 2^n)$（$2^{100}$，天文数字）；逐秒模拟因「未访问」依赖历史无法仅按位置转移，修正成掩码版本后同爆炸；蒙特卡洛 $10^{10}$ 样本才够精度。一趟 BFS 是唯一同时满足精度与复杂度的做法。

## 7. 参考代码

### C++（主线：BFS 预计算 + 三态判定）

```cpp
class Solution {
public:
    double frogPosition(int n, vector<vector<int>>& edges, int t, int target) {
        vector<vector<int>> g(n + 1);
        for (auto& e : edges) {
            g[e[0]].push_back(e[1]);
            g[e[1]].push_back(e[0]);
        }
        vector<int> depth(n + 1, -1);
        vector<double> prob(n + 1, 0.0);
        depth[1] = 0;                       // 青蛙 0 秒时在顶点 1
        prob[1] = 1.0;
        queue<int> q;
        q.push(1);
        while (!q.empty()) {
            int u = q.front(); q.pop();
            int cnt = g[u].size() - (u != 1);      // 引理 2：未访问邻居数
            for (int v : g[u]) {
                if (depth[v] == -1) {              // 未访问 = 不是父节点
                    depth[v] = depth[u] + 1;
                    prob[v] = prob[u] / cnt;       // 引理 3：连乘传播
                    q.push(v);
                }
            }
        }
        if (depth[target] > t)  return 0.0;        // 三态①：没跳到
        if (depth[target] == t) return prob[target]; // 三态②：恰时踩点
        bool stuck = g[target].size() == (target != 1); // 三态③：早到，困住才有概率
        return stuck ? prob[target] : 0.0;
    }
};
```

### Python（同款 BFS）

```python
class Solution:
    def frogPosition(self, n: int, edges: List[List[int]], t: int, target: int) -> float:
        g = [[] for _ in range(n + 1)]
        for a, b in edges:
            g[a].append(b)
            g[b].append(a)

        depth = [-1] * (n + 1)
        prob = [0.0] * (n + 1)
        depth[1], prob[1] = 0, 1.0
        q = deque([1])
        while q:
            u = q.popleft()
            cnt = len(g[u]) - (u != 1)          # 未访问邻居数
            for v in g[u]:
                if depth[v] == -1:
                    depth[v] = depth[u] + 1
                    prob[v] = prob[u] / cnt
                    q.append(v)

        if depth[target] > t:
            return 0.0
        if depth[target] == t:
            return prob[target]
        stuck = len(g[target]) == (target != 1)  # 叶子 / 孤立根才困得住
        return prob[target] if stuck else 0.0
```

### Python 备选：DFS 三态递归

```python
class Solution:
    def frogPosition(self, n: int, edges: List[List[int]], t: int, target: int) -> float:
        g = [[] for _ in range(n + 1)]
        for a, b in edges:
            g[a].append(b)
            g[b].append(a)

        def dfs(u: int, parent: int, time: int, p: float) -> float:
            if time == t:                        # 到点：之后跳走与否不影响
                return p if u == target else 0.0
            cnt = sum(1 for v in g[u] if v != parent)
            if cnt == 0:                         # 卡住：原地跳到第 t 秒
                return p if u == target else 0.0
            return sum(dfs(v, u, time + 1, p / cnt)
                       for v in g[u] if v != parent)

        return dfs(1, -1, 0, 1.0)
```

> 💡 递归版把「分发 - 累加」写成隐式枚举，三态（到点 / 卡住 / 分发）与题面逐句对应、最好讲；BFS 版把 (depth, prob) 先算成表再末端判定，最不易写错边界。$n \le 100$ 递归深度无压力，两者赛场随便选；若数据范围放大到链状 $10^5$ 级（同场 Q3 的教训），迭代 BFS 版是唯一安全写法。

## 8. 边界情况与易错点

1. **早到非叶（最高频 WA）**：`depth < t` 且 `target` 有孩子 ⟹ 概率 0。规则不允许「有路却停留」，且跳走后无环永不回头（示例 4 / 演算 Case C）。
2. **早到被困叶**：答案 = `prob[target]`，**概率不随等待时间衰减**——「等待不掉价」，别手滑乘个 $\frac{1}{2^{t-\mathrm{depth}}}$ 之类的衰减因子（示例 3 / Case B）。
3. **恰时到达不看叶子**：`depth == t` 直接返回 `prob`，无论 `target` 是否叶子——「时刻 t 在此」与之后的去向无关（判定顺序上 ② 先于 ③）。
4. **$n = 1$**：`edges` 为空，青蛙永远困在顶点 1，`target = 1` 时答案 1（对任意 $t \ge 1$）。`stuck` 统一判式天然覆盖，无需特判。
5. **`target = 1` 且 $n > 1$**：根有未访问邻居 ⟹ 第 1 秒必离开（引理 4），$t \ge 1$ 时答案恒 0。易错：看到 `depth[1] = 0 < t` 就想判「停在根」——只有 $n = 1$ 的孤立根才困得住。
6. **别对 `target` 也除一次**：连乘除的是路径上「跳出节点」的 $c$；`target` 的 $c$ 只用于三态③的困住判定。误除在叶子情形直接除以 0。
7. **判「无孩子」要看原始度数**：`g[target].size() == (target != 1)`，不是「BFS 中是否给孩子分过概率」——若做了 §4 第 5 条的深度剪枝，两者会分叉，用度数才是对的。
8. **建图用 1-indexed**：顶点编号从 1 开始，数组开 $n+1$，别让顶点 0 混进邻接表。
9. **精度**：`double` 即可（最小概率 $\sim 10^{-198}$，远离下溢线）；C++ 别返回 `float`，Python 无此虑但同理别用 `numpy.float32`。
10. **别真去模拟 $t$ 秒**：逐秒转移需要「未访问」历史，状态膨胀；一趟 BFS 把「位置 × 时刻」压成「位置 → (深度, 概率)」即完成全部需要的模拟。
