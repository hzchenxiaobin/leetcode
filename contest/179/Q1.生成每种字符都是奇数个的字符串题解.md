# LeetCode 生成每种字符都是奇数个的字符串 题解

## 1. 题目概述

- **标题 / 题号**：生成每种字符都是奇数个的字符串（#1374，easy）
- **链接**：https://leetcode.cn/problems/generate-a-string-with-characters-that-have-odd-counts/
- **来源**：LeetCode 第 179 场周赛 Q1
- **难度**：简单
- **标签**：字符串、数学、构造

**题意**：给定整数 $n$，返回一个长度为 $n$ 的字符串，只含**小写英文字母**，且其中**每种出现的字符都恰好出现奇数次**。合法答案不唯一，返回任意一个即可。

**约束**：

- $1 \le n \le 500$

> 💡 签到题先抓两个关键点：一是判题协议为 **Special Judge**——任意合法串都通过，输出与示例不同不是错误；二是「每种字符奇数次」本质是**奇偶分拆**问题——想清楚「奇 + 奇 = 偶」，一次 `if-else` 就能构造完毕，不需要任何枚举。

## 2. 示例

**示例 1**

```text
输入：n = 4
输出："pppz"
解释：'p' 出现 3 次（奇），'z' 出现 1 次（奇）。"ohhh"、"love" 等同样合法。
```

**示例 2**

```text
输入：n = 2
输出："xy"
解释：'x' 与 'y' 各出现 1 次（奇）。"ag"、"ur" 等同样合法。
```

**示例 3**

```text
输入：n = 7
输出："holasss"
解释：h、o、l、a 各出现 1 次，s 出现 3 次——五个奇数之和 1+1+1+1+3 = 7。
```

**示例 4**（自拟：最小规模）

```text
输入：n = 1
输出："a"
解释：'a' 出现 1 次（奇），单字符即合法。
```

## 3. 解题思路

### 3.1 暴力思路：枚举奇数分拆或随机重试

「每种字符奇数次」等价于把 $n$ 写成**若干个奇正整数之和**（每个奇数是一种字符的频次）。朴素视角下这是个分拆枚举问题：仅 $n = 7$ 就有 $7$、$5+1+1$、$3+3+1$、$3+1+1+1+1$、$1 \times 7$ 等多种拆法，拆法个数随 $n$ 指数级膨胀，还要做字符分配与频次校验。另一条"憨"路是**随机生成 + 校验重试**：在全字母表上随机，长度 $500$ 的串 26 个频次全为奇数的概率仅约 $2^{-26}$，期望重试六千多万次，赛场上等于自杀。

两条路输在同一个认知偏差：把**构造题**当成了**搜索题**。题目接受任意合法解，根本不需要遍历解空间——该找的是**最简可行解**。

> ⚠️ 构造题的第一反应永远是「有没有一步到位的公式」，而不是「怎么枚举」。签到题的时间预算应该花在读清题意上，而不是写搜索框架。

### 3.2 核心观察：奇偶分拆——至多 2 种字符

![核心观察：把 n 分拆成奇数块，奇数用 1 种字符、偶数用 2 种字符](images/wc179_q1_parity_decompose_concept.svg)

合法串的频次表是一个**奇数多重集**，且总和为 $n$。按 $n$ 的奇偶分两种情形：

- **$n$ 为奇数**：用 **1 种字符**——`'a'` 重复 $n$ 次，$c_a = n$ 本身就是奇数，天然合法；
- **$n$ 为偶数**：单字符频次 $n$ 为偶数，不合法；但 $n-1$ 与 $n$ 奇偶相反必为奇数，拆成 $(n-1) + 1$——`'a'` 重复 $n-1$ 次再补一个 `'b'`，两个频次 $n-1$ 与 $1$ 都是奇数。

用模运算一句话概括：$k$ 个奇数之和 $\equiv k \pmod 2$，所以凑出 $n$ 只需取 $k \equiv n \pmod 2$——$k \in \{1, 2\}$ 就覆盖一切 $n \ge 1$，而字母表有 26 个字母，绰绰有余。示例 3 的官方输出 `"holasss"` 是五块拆分，本文构造是单块拆分——**拆法无穷，最简只需两块**。

### 3.3 算法流程：一次奇偶判断

![算法流程：判断 n 奇偶后各走一步构造](images/wc179_q1_construct_flow.svg)

1. 读入 $n$；
2. 若 $n$ 为奇数，返回 `'a'` 重复 $n$ 次；
3. 否则（$n$ 为偶数），返回 `'a'` 重复 $n-1$ 次再拼接一个 `'b'`。

整个算法是一次 `if-else` 加一趟字符串构造，没有循环、没有搜索、没有额外数据结构。

### 3.4 示例演算

![示例演算：n = 4 / 2 / 7 的构造与频次校验](images/wc179_q1_walkthrough.svg)

| $n$ | 奇偶 | 构造输出 | 频次表 | 校验 |
|-----|------|----------|--------|------|
| 4 | 偶 | `"aaab"` | $a{:}3,\ b{:}1$ | 3、1 均奇，$3+1=4$ ✓ |
| 2 | 偶 | `"ab"` | $a{:}1,\ b{:}1$ | 1、1 均奇，$1+1=2$ ✓ |
| 7 | 奇 | `"aaaaaaa"` | $a{:}7$ | 7 为奇 ✓ |
| 1 | 奇 | `"a"` | $a{:}1$ | 1 为奇 ✓ |

注意官方示例 $n=4$ 输出 `"pppz"`（$p{:}3 + z{:}1$），与本文构造 `"aaab"` 是**同一个 $3+1$ 拆分**，只是字母选择不同——两者同构，Special Judge 均判通过。

## 4. 算法细节

1. **字母选择任意**：`'a'` 与 `'b'` 只是占位符，任意两个**互不相同**的小写字母都行；关键是偶数分支必须引入第二种字符（见 §8 第 2 条）。
2. **统一三元写法**：先铺 `'a'` 重复 $n-1$ 次，末位按奇偶补——$n$ 奇补 `'a'`（拼成 $n$ 个 `'a'`），$n$ 偶补 `'b'`。一个表达式覆盖两个分支，见参考代码后的提示。
3. **$n-1$ 恒不越界**：偶数分支只在 $n \ge 2$ 时走到，$n-1 \ge 1$，不会构造出空串。
4. **为何止步于 2 种字符**：$n$ 偶时 $(n-1)+1$ 已是合法分拆，$n$ 奇时单块即合法；更多字符只是徒增频次表长度，无任何收益（§5 定理 2 还说明 2 恰是偶数情形的下界）。
5. **数据规模无忧**：$n \le 500$，无溢出、无超时风险；C++ `string(n, 'a')` 与 Python `'a' * n` 都是 $O(n)$ 一行构造。

## 5. 正确性证明

记字符串 $s$ 中字符 $x$ 的出现次数为 $c_x$，频次表为 $\{c_x : c_x > 0\}$。

**引理 1（合法性判据）**：$s$ 是 $n$ 的合法答案 $\iff$ 每个 $c_x$ 为奇数，且 $|s| = \sum_x c_x = n$，且 $s$ 只含小写字母。

**证明**：题设三条要求逐一对应：长度为 $n$ 即 $|s| = n$；「每种出现的字符恰好出现奇数次」即诸 $c_x$ 皆奇；「只含小写英文字母」即字符集约束。反之，三条一起恰构成题设的全部要求。∎

**引理 2（奇偶守恒）**：$k$ 个奇数之和 $\equiv k \pmod 2$。特别地，奇 + 奇 = 偶。

**证明**：设第 $i$ 个奇数 $o_i = 2m_i + 1$，则 $\sum_{i=1}^{k} o_i = 2\sum_{i=1}^{k} m_i + k \equiv k \pmod 2$。∎

**定理 1（构造正确性）**：对一切 $1 \le n \le 500$，算法输出是合法答案。

**证明**：逐情形验证引理 1 的三个条件（输出只含小写字母显然满足）。

- $n$ 奇：输出为 $n$ 个 `'a'` 组成的串，频次表为 $\{n\}$——诸频次奇、长度 $n$，合法。
- $n$ 偶（此时 $n \ge 2$）：输出为 $n-1$ 个 `'a'` 与 $1$ 个 `'b'` 的拼接，频次表为 $\{n-1,\ 1\}$。$n$ 偶 $\Rightarrow n-1$ 奇；$1$ 奇；长度 $(n-1) + 1 = n$。合法。∎

**定理 2（字符种数下界）**：$n$ 为偶数时任何合法串至少用 2 种字符；$n$ 为奇数时至少 1 种。本构造恰取到下界。

**证明**：只含 1 种字符的长度 $n$ 串频次表为 $\{n\}$，由引理 1 需 $n$ 为奇——$n$ 偶时矛盾，故至少 2 种。$n$ 奇时 1 种即被本构造取到。∎

**推论（$k$ 种字符的可行性判据）**：用恰好 $k$ 种字符构造长度 $n$ 的合法串，可行 $\iff$ $k \le \min(n, 26)$ 且 $k \equiv n \pmod 2$；可行时取分拆 $(n-k+1) + \underbrace{1 + \cdots + 1}_{k-1}$ 即可。

**证明**：必要性：$k$ 个正奇数之和为 $n$，每项 $\ge 1$ 故 $k \le n$；由引理 2，$n \equiv k \pmod 2$；小写字母只有 26 个。充分性：$k \equiv n \pmod 2$ 且 $k \le n$ 时，$n - k + 1 \ge 1$ 且 $n - k$ 为偶数从而 $n - k + 1$ 为奇数；把 $k$ 个频次取为 $n-k+1, 1, \ldots, 1$（共 $k$ 项、全奇、和为 $n$），分配给 $k$ 个不同字母即可。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。奇偶判断 $O(1)$，构造长度 $n$ 的输出串 $\Theta(n)$——输出本身就有 $n$ 个字符，这已是理论下界，不可能更快。
- **空间复杂度**：$O(n)$ 存放返回串（题目要求的输出，不计入额外空间）；不计输出的话额外空间 $O(1)$——只有常数个变量，无辅助数据结构。
- **签到性价比**：思考 30 秒 + 编码 30 秒，是标准的开门题节奏；复杂度由输出规模决定，无需也无从优化。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    string generateTheString(int n) {
        if (n % 2 == 1) return string(n, 'a');   // 奇：单字符 n 次
        return string(n - 1, 'a') + 'b';         // 偶：(n-1) 个 a + 1 个 b
    }
};
```

### Python

```python
class Solution:
    def generateTheString(self, n: int) -> str:
        if n % 2:
            return 'a' * n
        return 'a' * (n - 1) + 'b'
```

> 💡 **统一三元写法**（消掉分支）：`'a' * (n - 1) + ('a' if n % 2 else 'b')`——先铺 $n-1$ 个 `'a'`，末位按奇偶补 `'a'` 或 `'b'`；对 $n = 1$ 得 `'a' * 0 + 'a' = "a"`，同样正确，无需特判。

## 8. 边界情况与易错点

1. **$n$ 偶时千万别返回 `'a' * n`**：频次 $n$ 为偶数，不合法——这是本题唯一实质性的 WA 点；把奇偶判断写反或漏写都会踩中。
2. **偶数分支的第二种字符必须与第一种不同**：若补的仍是 `'a'`，频次合并回偶数，前功尽弃。
3. **$n = 1$**：走奇数分支返回 `"a"`；三元写法 `'a' * 0 + 'a' = "a"` 也安全，无需特判。
4. **别对拍示例输出**：Special Judge 下 `"aaab"` 与 `"pppz"` 等价，赛中对拍示例纯属浪费时间；本地自测应写**频次校验器**（数每个字母出现次数是否全奇、长度是否为 $n$），而不是逐字符比对。
5. **只准小写字母**：别顺手输出大写；$n \ge 1$ 保证输出非空。
6. **无溢出风险**：$n \le 500$，`int` 与 `string` 都毫无压力。
7. **别过度设计**：枚举分拆、随机重试、哈希计数校验都是杀鸡用牛刀——构造题先找最简分拆，一行 `if-else` 即满分。
