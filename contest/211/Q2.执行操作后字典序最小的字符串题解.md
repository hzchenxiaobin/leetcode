# LeetCode 执行操作后字典序最小的字符串 题解

## 1. 题目概述

- **标题 / 题号**：执行操作后字典序最小的字符串（#1625，medium）
- **链接**：https://leetcode.cn/problems/lexicographically-smallest-string-after-applying-operations/
- **来源**：LeetCode 第 211 场周赛 Q2
- **难度**：中等
- **标签**：广度优先搜索、字符串、枚举、哈希表

**题意**：给定长度为偶数、仅由数字 $0 \sim 9$ 组成的字符串 $s$，以及整数 $a$、$b$。可以按任意顺序、任意多次执行两种操作：**累加**——把 $a$ 加到所有奇数下标位的数字上（mod 10 循环）；**轮转**——把 $s$ 向右轮转 $b$ 位。返回最终能得到的**字典序最小**的字符串。

**约束**：

- $2 \le s.length \le 100$，且为偶数
- $s$ 仅由数字 $0 \sim 9$ 组成
- $1 \le a \le 9$
- $1 \le b \le s.length - 1$

## 2. 示例

**示例 1**

```text
输入：s = "5525", a = 9, b = 2
输出："2050"
解释：初态 "5525" → 轮转 "2555" → 累加 "2454" → 累加 "2353"
→ 轮转 "5323" → 累加 "5222" → 累加 "5121" → 轮转 "2151" → 累加 "2050"
无法获得字典序小于 "2050" 的字符串。
```

**示例 2**

```text
输入：s = "74", a = 5, b = 1
输出："24"
解释：初态 "74" → 轮转 "47" → 累加 "42" → 轮转 "24"。
```

**示例 3**

```text
输入：s = "0011", a = 4, b = 2
输出："0011"
解释：无法获得字典序小于 "0011" 的字符串（0 次操作也是合法方案）。
```

## 3. 解题思路

### 3.1 暴力思路：为什么"枚举操作序列"不可行

最直接的想法是搜索：每一步二选一「累加 / 轮转」，把每条路径的终点都比一遍。但这有两个致命问题：

1. **序列长度无上限**：操作可以执行任意多次，搜索树无限深；即使人为限制步数为 $L$，也是 $2^L$ 的指数爆炸。
2. **状态图有环**：对 `"5525"` 连续累加 10 次回到 `"5525"`、连续轮转 2 次也回到 `"5525"`——搜索会绕环打转。

反过来想：不管执行多少步，**能得到的"不同字符串"是否有限**？轮转只搬移字符位置，累加只改数字 mod 10，两者都困在「长度为 $n$ 的数字串」这个有限集合里。于是问题从「枚举无限的操作序列」转化为「枚举有限的可达状态」——这正是隐式图 BFS 的用武之地。

### 3.2 核心观察：无限的操作序列，有限的状态空间

![核心观察：操作序列无限长，不同的字符串只有有限个](images/wc211_q2_state_space_concept.svg)

两种操作各自带周期，且不同路径会**汇聚**到同一字符串：

1. **轮转有周期**：右轮 $b$ 位连做 $k$ 次等价于右轮 $kb \bmod n$ 位，可达偏移集合 $\{kb \bmod n\}$ 的大小为 $n/\gcd(n,b) \le n$；
2. **累加有周期**：奇数位连加 $k$ 次等价于加 $ka \bmod 10$，增量集合 $\{ka \bmod 10\}$ 的大小为 $10/\gcd(a,10) \le 10$；
3. **殊途同归**：图中「① 累加 → ② 轮转」与「② 轮转 → ① 累加」两条不同路径都到达 `"2454"`——必须用 `visited` 去重，否则搜索会绕环死循环。

粗略上界：偏移 $\le n$ 种 × 增量 $\le 10$ 种（$b$ 为奇数时偶数位也能被独立累加，再乘 10）$\Rightarrow$ 状态数 $\le n \times 100 = 10^4$，BFS 从容遍历。

> 💡 本题本质是**隐式图 BFS**：节点是字符串、边是两种操作；求的是「可达集合的最小值」而非最短路，所以 BFS、DFS 任何遍历顺序都正确，`visited` 去重是唯一的关键纪律。

### 3.3 算法流程

![算法流程：隐式图 BFS + visited，遍历所有可达状态取最小](images/wc211_q2_bfs_flow.svg)

```text
1. visited ← {s}，queue ← [s]，ans ← s
2. 当 queue 非空：
   a. cur ← queue 出队；ans ← min(ans, cur)
   b. t1 ← cur 奇数位各 +a (mod 10)
      若 t1 ∉ visited：visited.add(t1)，t1 入队
   c. t2 ← cur 右移 b 位
      若 t2 ∉ visited：visited.add(t2)，t2 入队
3. 返回 ans
```

注意 `ans` 初值必须是 $s$ 本身——「执行 0 次操作」也是合法方案（示例 3 的答案就是原串）。

### 3.4 示例演算

![示例演算：两条轮转轨道 × 十种累加](images/wc211_q2_walkthrough.svg)

以示例 1 `s = "5525", a = 9, b = 2` 为例，状态空间恰好是规整的「两条轨道 × 十种累加」：

- $n=4$、$b=2$、$\gcd(4,2)=2$ → 可达偏移只有 $\{0, 2\}$ 两种；$+9 \equiv -1 \pmod{10}$ → 每累加一次，奇数位数字减 1；
- **轨道 A**（偏移 0）首字符恒为 `5`，轨道内最优是 `5020`；**轨道 B**（偏移 2，即 `"2555"`）首字符恒为 `2`，字典序上必然更小，答案只能在轨道 B 中；
- 轨道 B 内奇数位随累加 $5 \to 4 \to 3 \to 2 \to 1 \to 0$ 递减，$k=5$ 时第二个字符到达 `0`，得 `"2050"` 即全局最小。

共 $2 \times 10 = 20$ 个可达状态，BFS 全遍历取 min 即得答案（可用代码实测验证）。

## 4. 算法细节

1. **状态直接用字符串**：无需把状态编码成（偏移, 增量）元组——字符串本身就是天然的状态键，`unordered_set<string>`（Python `set`）判重一次 $O(n)$。
2. **后继构造各 $O(n)$**：累加遍历奇数位逐字符 `(d + a) % 10`；轮转用切片拼接 `cur.substr(n-b) + cur.substr(0, n-b)`（Python：`cur[-b:] + cur[:-b]`）。
3. **判重时机在入队前**（而非出队时）：保证每个状态至多入队一次，队列长度不超过状态数。
4. **遍历顺序无关紧要**：题目要的是所有可达状态的最小值，不是最短路；DFS 同样正确，BFS 的迭代队列写法最不易翻车（无递归深度风险）。
5. **状态数上界**（证明见 §5）：$S \le \dfrac{n}{\gcd(n,b)} \cdot m \le 1000$（$b$ 为偶数）；$S \le \dfrac{n}{\gcd(n,b)} \cdot m^2 \le 10^4$（$b$ 为奇数），其中 $m = \dfrac{10}{\gcd(a,10)}$。

## 5. 正确性证明

**引理 1（正规形式）**：记 $\sigma_r$ 为「把串右轮 $r$ 位」的变换，$D_{x,y}$ 为「偶数位加 $x\cdot a$、奇数位加 $y\cdot a$（mod 10）」的变换（$x, y \ge 0$）。由于 $n$ 是偶数，任意有限操作序列作用于 $s$ 的结果都形如

$$D_{x,y}\big(\sigma_{kb \bmod n}(s)\big)$$

且当 $b$ 为偶数时恒有 $x = 0$。

**证明**：对操作次数 $m$ 归纳。$m = 0$ 时取 $k = x = y = 0$。设 $m$ 次操作后结果为 $D_{x,y}(\sigma_{kb}(s))$，考察第 $m+1$ 次操作：

- 若是**累加**：结果为 $D_{x,\,y+a}(\sigma_{kb}(s))$，形状保持；
- 若是**轮转**：由交换关系 $\sigma_b \circ D_{x,y} = D_{x',y'} \circ \sigma_b$（$b$ 偶时 $(x',y') = (x,y)$，$b$ 奇时 $(x',y') = (y,x)$），结果为 $D_{x',y'}(\sigma_{(k+1)b}(s))$，形状保持。

交换关系的来历：$\sigma_r$ 把原位置 $j$ 的字符送到位置 $(j + r) \bmod n$。$n$ 为偶数时，位置 $i$ 的原像 $(i - r) \bmod n$ 与 $i$ 同奇偶当且仅当 $r$ 为偶数——即右轮**偶数**位保持奇偶结构、右轮**奇数**位把两类的加量对调。

$b$ 为偶数时 $x$ 恒为 0：初始 $x = 0$；累加只改 $y$；轮转的交换在 $b$ 偶时保持 $(x, y)$ 不变，归纳即得。∎

**引理 2（状态数上界）**：可达字符串个数不超过 $\dfrac{n}{\gcd(n,b)} \cdot m$（$b$ 偶）或 $\dfrac{n}{\gcd(n,b)} \cdot m^2$（$b$ 奇），其中 $m = \dfrac{10}{\gcd(a,10)} \le 10$。

**证明**：偏移 $kb \bmod n$ 的取值集合是 $\mathbb{Z}_n$ 中由 $b$ 生成的循环子群，大小恰为 $n/\gcd(n,b)$；$x$、$y$ 均落在 $\{0, a, 2a, \dots\} \bmod 10$ 中，该集合大小为 $10/\gcd(a,10) = m$。由引理 1，每个可达字符串由三元组 $(k, x, y)$ 生成（$b$ 偶时 $x$ 恒 0），三元组取值数相乘即得上界。∎

**定理（BFS 的正确性与终止性）**：BFS 结束时 `visited` 恰为从 $s$ 出发的可达字符串集合 $R$，返回值等于 $\min R$。

**证明**：$R$ 对两种操作封闭（可达状态再执行一步仍可达）。

*可达性*：对「从 $s$ 到 $u$ 的最短操作步数 $d(u)$」归纳。$d = 0$ 的 $s$ 在初始化时入队。若 $d(u) = d \ge 1$，取一条最短路径，其倒数第二个状态 $v$ 满足 $d(v) = d - 1$，由归纳假设 $v$ 会出队；$v$ 出队时，后继 $u$ 若未标记则被标记并入队。故 $R$ 中每个状态都会进入 `visited`。

*反向*：`visited` 中每个状态入队时，其前驱已在 `visited` 中，沿入队顺序回溯即得一条从 $s$ 出发的操作路径，故 `visited` $\subseteq R$。于是 `visited` $= R$。

*终止性与答案*：每个字符串至多入队一次，而 `visited` $\subseteq R$ 有限（引理 2），队列必然变空。每次出队都执行 `ans ← min(ans, cur)`，恰好把 $R$ 的每个元素各比较一次，故 `ans` $= \min R$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(S \cdot n)$，其中 $S$ 为可达状态数。每个状态出队一次，构造两个后继、比较、哈希各 $O(n)$。由引理 2，$S \le 10^4$、$n \le 100$，总操作量约 $10^6$，远在时限之内。
- **空间复杂度**：$O(S \cdot n)$，`visited` 与队列合计至多存 $S$ 条长为 $n$ 的字符串，$\le 10^6$ 个字符。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    string findLexSmallestString(string s, int a, int b) {
        unordered_set<string> visited{s};
        queue<string> q;
        q.push(s);
        string ans = s;
        int n = s.size();
        while (!q.empty()) {
            string cur = q.front();
            q.pop();
            ans = min(ans, cur);
            string t1 = cur;
            for (int i = 1; i < n; i += 2)
                t1[i] = '0' + (t1[i] - '0' + a) % 10;
            if (visited.insert(t1).second) q.push(t1);
            string t2 = cur.substr(n - b) + cur.substr(0, n - b);
            if (visited.insert(t2).second) q.push(t2);
        }
        return ans;
    }
};
```

### Python

```python
from collections import deque

class Solution:
    def findLexSmallestString(self, s: str, a: int, b: int) -> str:
        visited = {s}
        q = deque([s])
        ans = s
        n = len(s)
        while q:
            cur = q.popleft()
            if cur < ans:
                ans = cur
            t1 = ''.join(str((int(c) + a) % 10) if i % 2 else c
                         for i, c in enumerate(cur))
            if t1 not in visited:
                visited.add(t1)
                q.append(t1)
            t2 = cur[-b:] + cur[:-b]
            if t2 not in visited:
                visited.add(t2)
                q.append(t2)
        return ans
```

## 8. 边界情况与易错点

1. **不加 visited 必死循环**：两种操作都是有限阶的（轮转阶 $n/\gcd(n,b)$、累加阶 $10/\gcd(a,10)$），状态图处处是环，裸搜索的队列 / 递归永远不会结束。
2. **轮转方向写反**：「向右轮转 $b$ 位」= 末尾 $b$ 个字符搬到最前面；方向写反不报错，但答案错（本地跑示例即可拦截）。
3. **ans 初值**：必须初始化为 $s$——执行 0 次操作是合法方案，示例 3 的最优解就是原串。
4. **mod 10 细节**：`(d + a) % 10` 一步到位；因 $1 \le a \le 9$、$0 \le d \le 9$，不存在负数取模问题。
5. **b 不与 n 互质时状态更少**：可达偏移只有 $n/\gcd(n,b)$ 种（示例 3 中 $n=4, b=2$，偏移仅 $\{0,2\}$）；只影响上界松紧，不影响 BFS 正确性。
6. **b 为奇数时状态膨胀**：偶、奇位增量独立可控（上界多乘一个 $m$），最坏 $10^4$ 个状态，依然轻松通过。
7. **「n 是偶数」是隐藏关键条件**：§5 中「奇偶互换」的整套论证依赖它（$n$ 为奇数时轮转会打乱奇偶结构）；题面已保证，无需特判，但改编题目时要警觉。
8. **Python 字符串不可变**：逐位修改需转 `list` 或用推导式重建，直接下标赋值会报错。
