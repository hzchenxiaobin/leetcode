# LeetCode 无矛盾的最佳球队 题解

## 1. 题目概述

- **标题 / 题号**：无矛盾的最佳球队（#1626，medium）
- **链接**：https://leetcode.cn/problems/best-team-with-no-conflicts/
- **来源**：LeetCode 第 211 场周赛 Q3
- **难度**：中等
- **标签**：数组、动态规划、排序、最长上升子序列变体

**题意**：你是球队经理，要从 $n$ 名球员中选出一个子集组成球队，球队得分为成员得分之和。约束是**不能有矛盾**：若一名**年龄更小**的球员得分**严格大于**一名年龄更大的球员，二人不能同时入选；同龄球员之间永不矛盾。求无矛盾球队的最大总得分。

**约束**：

- $1 \le n \le 1000$
- $1 \le scores[i] \le 10^6$
- $1 \le ages[i] \le 1000$

> 💡 **关键信号**：$n \le 1000$ → $O(n^2)$ DP 稳过；$ages[i] \le 1000$ 的窄值域还为树状数组优化留了后门（§4）。冲突规则是「年龄序与得分序打架」，典型的**排序消维 + LIS 变体**信号。

## 2. 示例

**示例 1**

```text
输入：scores = [1,3,5,10,15], ages = [1,2,3,4,5]
输出：34
解释：得分随年龄严格递增，谁也不和谁矛盾，全部入选：1+3+5+10+15 = 34。
```

**示例 2**

```text
输入：scores = [4,5,6,5], ages = [2,1,2,1]
输出：16
解释：选得分 [5,5,6] 的三名球员（年龄 1,1,2）。两名同龄 5 分球员不冲突，
      6 分球员比他们都年长且分更高，也不冲突。
```

**示例 3**

```text
输入：scores = [1,2,3,5], ages = [8,9,10,1]
输出：6
解释：选前三名老将 [1,2,3]。5 分球员只有 1 岁，比所有人都年轻且分更高，
      与三名老将全都矛盾，只能弃用。
```

## 3. 解题思路

### 3.1 暴力思路

枚举 $2^n$ 个球员子集，对每个子集两两检查矛盾再求和。$n = 1000$ 时 $2^{1000}$ 天文数字，完全不可行。

一个诱人的贪心是「按得分从高到低逐个加入，冲突就跳过」，但它没有反悔机制：高分年轻球员入选会一次性挡掉一批老将，而放弃他换来的总和可能更高（示例 3 中弃用 5 分天才、保住三名老将就是反例的雏形）。子集间不存在简单的局部最优交换，必须用 DP 全局考虑。

### 3.2 核心观察：排序归约为「最大和不下降子序列」

![核心观察：冲突的几何刻画与排序归约](images/wc211_q3_sort_reduce_concept.svg)

把每名球员看成平面上的点 $(age, score)$。两球有矛盾，当且仅当其中一人**年龄更小且得分严格更大**——在平面上就是「一个更靠左却更靠上」的**反向交叉**对。于是：

> **无冲突的两名球员 ⟺ 年龄与得分「同向」：年轻的一方得分不超过年长的一方。**

将球员按 $(age, score)$ **双关键字升序**排序。排好序后，排在前面的人年龄必然 $\le$ 后面的人，矛盾条件里「年龄」这一维被排序消掉，只剩一个纯得分条件：

$$
\text{无冲突球队} \iff \text{排序后序列的一个得分不下降子序列}
$$

目标是使子序列的得分**和**最大。这正是经典 **LIS（最长递增子序列）**的**求和变体**：把「长度最长」换成「和最大」，把「严格递增」换成「不下降」（同分球员可共存——注意排序第二关键字用 $score$，保证同龄球员内部也是按分升序，不会产生假冲突）。

### 3.3 算法流程

![排序 + 一维 DP 的流程图](images/wc211_q3_dp_flow.svg)

```text
1. 配对 players[i] = (age_i, score_i)，按 (age, score) 双关键字升序排序
2. for i = 0 .. n−1:
       dp[i] ← score_i                          # 单选自己成队（保底）
       for j = 0 .. i−1:
           若 score_j ≤ score_i:                 # 同分也允许
               dp[i] ← max(dp[i], dp[j] + score_i)
       ans ← max(ans, dp[i])
3. return ans
```

其中 $dp[i]$ 的含义是：**以排序后第 $i$ 名球员为「队尾」（排序意义下最大成员）的无冲突球队的最大总得分**。

### 3.4 示例演算

![示例 3 的 DP 演算](images/wc211_q3_walkthrough.svg)

以示例 3（`scores = [1,2,3,5]`, `ages = [8,9,10,1]`）为例。排序后依次为 $(1,5), (8,1), (9,2), (10,3)$，得分序列 $5, 1, 2, 3$：

| $i$ | $(age, score)$ | 可接前驱（$j < i$ 且 $s_j \le s_i$） | $dp[i]$ |
|-----|---------------|--------------------------------------|---------|
| 0 | $(1, 5)$ | 无 | $5$（天才单选） |
| 1 | $(8, 1)$ | 无（$s_0 = 5 > 1$） | $1$ |
| 2 | $(9, 2)$ | $j = 1$（$dp=1$） | $2 + 1 = 3$ |
| 3 | $(10, 3)$ | $j = 1, 2$（最大 $dp[2]=3$） | $3 + 3 = 6$ ← 峰值 |

答案 $\max(5, 1, 3, 6) = 6$，对应球队为三名老将 $[1, 2, 3]$；5 分天才因比后面所有人都「年轻且分高」，一个前驱也接不上，只能孤立成队。

## 4. 算法细节

1. **排序键**：$(age, score)$ **双关键字**。第一维消年龄，第二维保证同龄球员按得分升序——若只按 $age$ 排序，同龄中「高分在前、低分在后」会被 DP 误判为下降，产生假冲突。
2. **状态定义**：$dp[i]$ = 以 $i$ 结尾（即 $i$ 为队中排序意义下最后一名）的最大总得分。转移：
   $$dp[i] = score_i + \max\bigl(0,\ \max\{\,dp[j] : j < i,\ score_j \le score_i\,\}\bigr)$$
   与经典 LIS 的对应：累加的是 $score_i$ 而非 $1$，比较用 $\le$ 而非 $<$。
3. **转移条件用 $\le$**：得分相同不构成矛盾（「严格大于」才矛盾），同分球员（无论是否同龄）都可以同队。
4. **答案取 $\max_i dp[i]$**：最优球队不一定以排序后最后一名球员结尾；$dp[i]$ 初值 $score_i$ 已覆盖单人选队。
5. **树状数组优化（进阶）**：瓶颈在于「$j < i$ 且 $s_j \le s_i$」是两个约束的交集。**换排序键为 $(score, age)$** 后逐个处理，处理到球员 $i$ 时已入库球员的得分都 $\le s_i$，得分约束被排序免费满足，只剩 $\max\{dp[j] : age_j \le age_i\}$——**以年龄为下标建前缀最大值树状数组**，每次查询加更新 $O(\log A)$：
   $$dp_i = score_i + \text{query}(age_i),\qquad \text{update}(age_i,\ dp_i)$$
   由 $ages[i] \le 1000$，年龄可直接当数组下标，**免去离散化**。总复杂度 $O(n \log A)$。

## 5. 正确性证明

**引理 1（矛盾的二要素刻画）**：球员 $u, v$ 无矛盾 $\iff$ $age_u \le age_v \wedge score_u \le score_v$，或 $age_u \ge age_v \wedge score_u \ge score_v$（即二元组按分量可比）。

**证明**：不妨设 $age_u \le age_v$。若 $score_u \le score_v$：较年轻（或同龄）的 $u$ 得分不超过 $v$，「年轻且严格高分」不成立，无矛盾。若 $score_u > score_v$：$u$ 更年轻且得分严格更大，恰为矛盾定义。$age_u > age_v$ 时对称。∎

**引理 2（排序归约）**：将全部球员按 $(age, score)$ 字典序升序排列为 $p_0, \dots, p_{n-1}$。子集 $T$（按此顺序列出）无矛盾 $\iff$ $T$ 的得分序列不下降。

**证明**：充分性（无矛盾 $\Rightarrow$ 不下降）：反证，若 $T$ 中存在排在前的 $p_a$ 与排在后的 $p_b$ 使 $s_a > s_b$。排序保证 $age_a \le age_b$。若 $age_a < age_b$，则 $a$ 更年轻且得分严格更大，矛盾；若 $age_a = age_b$，与第二关键字升序矛盾。必要性（不下降 $\Rightarrow$ 无矛盾）：对 $T$ 中任意两人 $p_a$ 在前、$p_b$ 在后，有 $age_a \le age_b$（排序）且 $s_a \le s_b$（不下降的传递性），由引理 1 右支知无矛盾。∎

**定理（DP 正确性）**：对排序后序列，$dp[i] = s_i + \max\bigl(0, \max\{dp[j] : j < i, s_j \le s_i\}\bigr)$ 恒等于「以 $p_i$ 为队尾的无冲突球队最大总得分」，且算法返回值等于全局最优。

**证明**：对 $i$ 归纳。$i$ 最小时无前驱，$dp[i] = s_i$，即单选 $p_i$，成立。设对所有 $j < i$ 结论成立。

上界：设 $T$ 是任一以 $p_i$ 为队尾（排序意义下最后）的无冲突球队。若 $|T| = 1$，总值 $s_i \le dp[i]$ 显然。若 $|T| \ge 2$，设 $p_j$ 为 $T$ 中除 $p_i$ 外排序最后的成员，则 $j < i$；由引理 2（充分性用于 $T$ 整体）得 $s_j \le s_i$，且 $T \setminus \{p_i\}$ 是以 $p_j$ 为队尾的无冲突球队，由归纳假设总值 $\le dp[j]$，故 $T$ 的总值 $\le s_i + dp[j] \le dp[i]$。

可达：取达到内层最大值的 $j$（或无前驱时单选），设 $T_j$ 是 $dp[j]$ 对应的球队。对 $T_j$ 中任意 $q$：$q$ 排在 $p_j$ 之前，由引理 2 得 $s_q \le s_j \le s_i$ 且 $age_q \le age_j \le age_i$，故 $q$ 与 $p_i$ 按分量可比，由引理 1 无矛盾；于是 $T_j \cup \{p_i\}$ 无矛盾且以 $p_i$ 为队尾，总值为 $s_i + dp[j] = dp[i]$，即 $dp[i]$ 可被取到。

最后，任一无冲突球队以其排序最后的成员 $p_i$ 为队尾，其值 $\le dp[i] \le \max_i dp[i]$；而每个 $dp[i]$ 本身都对应一支合法球队，故返回 $\max_i dp[i]$ 正确。∎

## 6. 复杂度分析

- **时间复杂度**：排序 $O(n \log n)$ + 双重循环 DP $O(n^2)$，总计 $O(n^2)$；$n = 1000$ 时约 $10^6$ 次操作，轻松通过。树状数组版本为 $O(n \log A)$，$A = 1000$。
- **空间复杂度**：$O(n)$，存 `players` 与 `dp` 数组；树状数组版本为 $O(n + A)$。

## 7. 参考代码

### C++（$O(n^2)$ DP）

```cpp
class Solution {
  public:
    int bestTeamScore(vector<int>& scores, vector<int>& ages) {
        int n = scores.size();
        vector<pair<int, int>> players(n);        // (age, score)
        for (int i = 0; i < n; ++i) players[i] = {ages[i], scores[i]};
        sort(players.begin(), players.end());     // 双关键字升序

        vector<int> dp(n);
        int ans = 0;
        for (int i = 0; i < n; ++i) {
            dp[i] = players[i].second;            // 单选保底
            for (int j = 0; j < i; ++j)
                if (players[j].second <= players[i].second)   // 同分可共存
                    dp[i] = max(dp[i], dp[j] + players[i].second);
            ans = max(ans, dp[i]);
        }
        return ans;
    }
};
```

### Python（$O(n^2)$ DP）

```python
class Solution:
    def bestTeamScore(self, scores: List[int], ages: List[int]) -> int:
        players = sorted(zip(ages, scores))       # (age, score) 双关键字升序
        n = len(players)
        dp = [0] * n
        ans = 0
        for i in range(n):
            s = players[i][1]
            dp[i] = s                             # 单选保底
            for j in range(i):
                if players[j][1] <= s:            # 同分可共存
                    dp[i] = max(dp[i], dp[j] + s)
            ans = max(ans, dp[i])
        return ans
```

### C++（树状数组，$O(n \log A)$）

```cpp
class Solution {
  public:
    int bestTeamScore(vector<int>& scores, vector<int>& ages) {
        int n = scores.size();
        vector<pair<int, int>> players(n);        // (score, age)：换排序键
        for (int i = 0; i < n; ++i) players[i] = {scores[i], ages[i]};
        sort(players.begin(), players.end());

        vector<int> tree(1001, 0);                // 年龄域 [1,1000]，免离散化
        auto query = [&](int a) {                 // max{ dp[j] : age_j <= a }
            int best = 0;
            for (; a > 0; a -= a & (-a)) best = max(best, tree[a]);
            return best;
        };
        auto update = [&](int a, int v) {
            for (; a <= 1000; a += a & (-a)) tree[a] = max(tree[a], v);
        };

        int ans = 0;
        for (auto& [s, a] : players) {
            int dp = s + query(a);
            update(a, dp);
            ans = max(ans, dp);
        }
        return ans;
    }
};
```

### Python（树状数组，$O(n \log A)$）

```python
class Solution:
    def bestTeamScore(self, scores: List[int], ages: List[int]) -> int:
        players = sorted(zip(scores, ages))       # (score, age)：换排序键
        tree = [0] * 1001                         # 年龄域 [1,1000]，免离散化

        def query(a):                             # max{ dp[j] : age_j <= a }
            best = 0
            while a > 0:
                best = max(best, tree[a])
                a -= a & (-a)
            return best

        def update(a, v):
            while a <= 1000:
                tree[a] = max(tree[a], v)
                a += a & (-a)

        ans = 0
        for s, a in players:
            dp = s + query(a)
            update(a, dp)
            ans = max(ans, dp)
        return ans
```

## 8. 边界情况与易错点

1. **只按年龄排序、漏第二关键字**：同龄不同分的球员顺序不确定，可能把「同龄无矛盾」误判为冲突。必须按 $(age, score)$ 双关键字排序。
2. **转移条件误写成 $<$**：同分球员可以共存（矛盾要求「严格大于」），条件是 $score_j \le score_i$；写成严格小于会漏掉示例 2 的 $[5,5,6]$。
3. **`dp[i]` 忘了单选保底**：转移里的 $\max(0, \cdot)$ 不能省，否则「接不上任何前驱」的球员（如示例 3 的天才）会得到垃圾值。
4. **答案误取 `dp[n-1]`**：最优球队不一定以排序后最后一名结尾，必须取 $\max_i dp[i]$。`ans` 初值 0 是安全的（$n \ge 1$ 且得分全正，单选必超过 0）。
5. **溢出**：总得分上界 $1000 \times 10^6 = 10^9$，恰好低于 `int` 上限 $2^{31} - 1 \approx 2.1 \times 10^9$，`int` 勉强安全但已过半程；C++ 求稳可用 `long long`，Python 无此顾虑。
6. **别硬套经典 LIS 的贪心 + 二分**：`tail` 数组那一套只维护「长度」语义，无法回答「最大和」；求和变体的正确加速姿势是树状数组/线段树维护前缀最大值。
7. **树状数组下标域**：本题挂「年龄」（$\le 1000$，免离散化）比挂「得分」（$\le 10^6$，需离散化）更省事；两者排序键也要随之配套（见 §4 第 5 点）。
