# LeetCode 两个相同字符之间的最长子字符串 题解

## 1. 题目概述

- **标题 / 题号**：两个相同字符之间的最长子字符串（#1624，easy）
- **链接**：https://leetcode.cn/problems/largest-substring-between-two-equal-characters/
- **来源**：LeetCode 第 211 场周赛 Q1
- **难度**：简单
- **标签**：哈希表、字符串

**题意**：给定字符串 `s`，返回**两个相同字符之间**的最长子字符串的长度——子字符串严格夹在这两个字符中间，**不含**端点字符；若不存在出现两次的字符，返回 `-1`。

**约束**：

- `1 <= s.length <= 300`
- `s` 只含小写英文字母

## 2. 示例

**示例 1**

```text
输入：s = "aa"
输出：0
解释：最优子字符串是两个 'a' 之间的空子字符串（长度 0）。
```

**示例 2**

```text
输入：s = "abca"
输出：2
解释：两个 'a' 之间是 "bc"。
```

**示例 3**

```text
输入：s = "cbzxy"
输出：-1
解释：所有字符都只出现一次，不存在相同字符对。
```

**示例 4**

```text
输入：s = "cabbac"
输出：4
解释：最外层两个 'c' 之间是 "abba"；内层候选 "bb"（长度 2）与 ""（长度 0）都不如它。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有下标对 $0 \le i < j < n$ 且 $s[i] = s[j]$，取 $j - i - 1$ 的最大值。$n \le 300$ 时至多约 $4.5 \times 10^4$ 对，$O(n^2)$ 稳过。

但这个 $O(n^2)$ 完全没必要：相同字符的"配对"信息高度冗余——每个字符只关心**最远的一对**。

### 3.2 核心观察：首末配对

![核心观察：首末配对支配内层对](images/wc211_q1_first_last_concept.svg)

对字符 $c$ 的任意两次出现 $(i, j)$（$i < j$），都有 $first(c) \le i < j \le last(c)$，即内层对一定被**首次出现 ↔ 末次出现**包住：

$$j - i - 1 \le last(c) - first(c) - 1$$

于是**每个字符只有一对候选**：首末对。扫描时只需记住每个字符**第一次**出现的下标 `first[c]`，之后每次再遇到 $c$，就用 $i - first[c] - 1$ 更新答案；末次出现时自然取到该字符的最大候选。

### 3.3 算法流程

![一遍扫描流程图](images/wc211_q1_scan_flow.svg)

```text
first[26] ← 全部初始化为 −1（哨兵：尚未出现）
ans ← −1
for i = 0 .. n−1:
    c = s[i]
    若 first[c] == −1:  first[c] ← i                       # 首次出现，只记录
    否则:               ans ← max(ans, i − first[c] − 1)   # 再次出现，更新
return ans
```

`ans` 初值取 `-1` 恰好就是"无解"的返回值，循环结束直接返回，无需特判。

### 3.4 示例演算

![cabbac 一遍扫描走查](images/wc211_q1_walkthrough.svg)

以 `s = "cabbac"` 为例：

- `i = 0..2`：`c`、`a`、`b` 均为首次出现，只记录 `first[c]=0`、`first[a]=1`、`first[b]=2`，`ans` 保持 `-1`；
- `i = 3`（`b`）：`first[b]=2` 已存在，`ans = max(-1, 3-2-1) = 0`（对应两个 `b` 之间的空串）；
- `i = 4`（`a`）：`ans = max(0, 4-1-1) = 2`（对应 `"bb"`）；
- `i = 5`（`c`）：`ans = max(2, 5-0-1) = 4`（对应 `"abba"`），即最终答案。

## 4. 算法细节

1. **first 数组**：字符集只有 26 个小写字母，开 `first[26]` 初始化为 `-1` 当"未出现"哨兵；Python 用 `dict` 同理。
2. **更新公式**：$i - first[c] - 1$，**两端字符不计入**——这一步的 `-1` 是本题最高频的 WA 点。
3. **分支不能合并**：首次出现只记录、不更新（此时哨兵 `-1` 参与运算是垃圾值），`if/else` 两个分支职责分明。
4. **等价写法**：也可两遍扫描分别求 `first[c]`、`last[c]`，答案为 $\max_c\,(last(c) - first(c) - 1)$；一遍扫描在末次出现时取到同样的值。
5. **无需特判**：`ans` 初值 `-1` 与"无解"语义重合；单字符串（`n = 1`）扫描一次后原样返回 `-1`。

## 5. 正确性证明

**引理 1（首末夹逼）**：设字符 $c$ 在 $s$ 中出现至少两次，$first(c)$、$last(c)$ 分别为其最小、最大出现下标，则任意两次出现 $(i, j)$（$i < j$）满足 $first(c) \le i < j \le last(c)$。

**证明**：$i$、$j$ 都是 $c$ 的出现下标，自然不小于最小值、不大于最大值。∎

**引理 2（支配性）**：对任意两次出现 $(i, j)$，有 $j - i - 1 \le last(c) - first(c) - 1$。

**证明**：由引理 1，$j - i \le last(c) - first(c)$，两边同减 1 即得。∎

**定理**：题目所求等于 $\max_{c:\, cnt(c) \ge 2} \big( last(c) - first(c) - 1 \big)$（无这样的 $c$ 时为 $-1$），且一遍扫描算法正确返回它。

**证明**：答案的候选集是所有相同字符对 $(i, j)$ 的 $j - i - 1$。由引理 2，每个字符 $c$ 的候选被 $last(c) - first(c) - 1$ 支配，而首末对本身也是合法候选，故全局最大值恰为 $\max_c (last(c) - first(c) - 1)$。

对算法，归纳证明不变式：处理完下标 $i$ 后，`ans` 等于「两端点均 $\le i$ 的相同字符对」的最大 $j - i - 1$（不存在则 `-1`）。处理 $s[i] = c$ 时：若 `first[c] == -1`，$i$ 与之前的任何位置不成对，不变式保持；否则新增的对恰为 $(p, i)$（$p$ 取遍 $c$ 在 $i$ 之前的所有出现），其中最大者为 $(first[c], i)$，对应值 $i - first[c] - 1$——正是更新项，其余新对更小、不影响最大值。循环终止时覆盖所有对，返回值正确。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n + |\Sigma|) = O(n)$，单次扫描，每步仅常数次数组读写与比较（$|\Sigma| = 26$）。
- **空间复杂度**：$O(|\Sigma|) = O(26) = O(1)$，仅一个 `first` 数组与常数个变量。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int maxLengthBetweenEqualCharacters(string s) {
        vector<int> first(26, -1);
        int ans = -1;
        for (int i = 0; i < (int)s.size(); ++i) {
            int c = s[i] - 'a';
            if (first[c] == -1) {
                first[c] = i;
            } else {
                ans = max(ans, i - first[c] - 1);
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maxLengthBetweenEqualCharacters(self, s: str) -> int:
        first = {}
        ans = -1
        for i, ch in enumerate(s):
            if ch in first:
                ans = max(ans, i - first[ch] - 1)
            else:
                first[ch] = i
        return ans
```

## 8. 边界情况与易错点

1. **公式漏 `-1`**：写成 $i - first[c]$ 会把端点计入（`"cabbac"` 得 5 而非 4）。
2. **`ans` 初值误用 0**：`"aa"` 的答案是 0，0 不能当"无解"哨兵；必须用 `-1`。
3. **首次出现参与更新**：若不做 `if/else` 分支，哨兵 `-1` 会算出 $i - (-1) - 1 = i$ 之类的垃圾值，把 `"cbzxy"` 判成非 `-1`。
4. **空子串也算**：相邻两个相同字符（`"aa"`）答案为 0 而非 `-1`。
5. **单字符串**：`n = 1` 无重复字符，返回 `-1`，算法天然正确。
6. **别用滑动窗口**：本题不要求子串内部满足任何性质，与「无重复字符的最长子串」套路无关，不要条件反射开双指针。
