# LeetCode 带阈值的图连通性 题解

## 1. 题目概述

- **标题 / 题号**：带阈值的图连通性（#1627，hard）
- **链接**：https://leetcode.cn/problems/graph-connectivity-with-threshold/
- **来源**：LeetCode 第 211 场周赛 Q4
- **难度**：困难
- **标签**：并查集、数论、调和级数枚举、图

**题意**：有 $n$ 座城市，编号 $1$ 到 $n$。编号 $x$ 与 $y$ 的两座城市之间有一条道路，当且仅当存在整数 $z$ 同时满足 $z \mid x$、$z \mid y$ 且 $z > \text{threshold}$。给定 $n$、$\text{threshold}$ 与查询数组 `queries`，对每个 `queries[i] = [a_i, b_i]` 判断城市 $a_i$ 与 $b_i$ 是否连通（直接有路，或经任意次中转），返回布尔数组。

**约束**：

- $2 \le n \le 10^4$
- $0 \le \text{threshold} \le n$
- $1 \le \text{queries.length} \le 10^5$
- $1 \le a_i, b_i \le n$，$a_i \ne b_i$

> 💡 **关键信号**：「存在 $z$ 整除两者」一眼等价于 $\gcd(x, y) > \text{threshold}$，于是这是一张**由 gcd 决定边**的图 + 大量**连通性查询**——标准信号是并查集。真正的难点在建图方式：两两枚举点对求 gcd 是 $O(n^2 \log n)$ 级，必须把视角从「点对」换到「约数」，用类似埃氏筛的调和级数枚举批量合并。

## 2. 示例

**示例 1**

```text
输入：n = 6, threshold = 2, queries = [[1,4],[2,5],[3,6]]
输出：[false, false, true]
解释：各数大于 2 的因子：3:{3}，4:{4}，5:{5}，6:{3,6}，1、2 没有。
      只有城市 3 和 6 共享大于阈值的公约数 3，存在道路 3--6；
      1 与 4、2 与 5 之间均无路径。
```

**示例 2**

```text
输入：n = 6, threshold = 0, queries = [[4,5],[3,4],[3,2],[2,6],[1,3]]
输出：[true, true, true, true, true]
解释：阈值为 0 时 z = 1 就能连任意两数（1 整除一切且 1 > 0），
      所有城市互相连通。
```

**示例 3**

```text
输入：n = 5, threshold = 1, queries = [[4,5],[4,5],[3,2],[2,3],[3,4]]
输出：[false, false, false, false, false]
解释：只有城市 2 和 4 共享公约数 2 > 1，只有这两座城市连通。
      同一对城市可能被重复查询，[x,y] 与 [y,x] 等价。
```

## 3. 解题思路

### 3.1 暴力思路

对每个点对 $(x, y)$（$x < y$）计算 $\gcd(x, y)$，大于 $\text{threshold}$ 就 `union(x, y)`；建完后每个查询用 `find` 比较即可。点对数 $\binom{10^4}{2} \approx 5 \times 10^7$，每次 gcd 约 $O(\log n)$ 次取模，总量约 $7 \times 10^8$——C++ 勉强贴地飞行，Python 必然超时。何况这 $5 \times 10^7$ 对里绝大多数 gcd 很小，白白做功，必须换建图视角。

### 3.2 核心观察：把「点对」换成「约数」

![核心观察：d 的倍数构成团，以 d 为枢纽合并，共享倍数缝合不同的团](images/wc211_q4_clique_merge_concept.svg)

**第一步：翻译连边条件。**

$$x \text{ 与 } y \text{ 有边} \iff \exists\, d > \text{threshold},\ d \mid x \wedge d \mid y \iff \gcd(x, y) > \text{threshold}$$

- 正向：取 $d = \gcd(x, y)$，它本身就能充当那个 $z$。
- 反向：任何满足条件的 $z$ 都整除 $\gcd(x, y)$，故 $\gcd(x, y) \ge z > \text{threshold}$。

**第二步：从「边」升级到「团」。** 固定某个 $d > \text{threshold}$，所有 $d$ 的倍数城市 $\{d, 2d, 3d, \ldots\}$ **两两之间都有边**（任意两个的 gcd 至少是 $d$）。也就是说，每个这样的 $d$ 对应图中的一个**团**（clique）。

**第三步：合并一个团 ≠ 枚举团内点对。** 把团并入并查集，只需任选代表当**枢纽**——最自然的选择就是 $d$ 本身：对 $k = 2, 3, \ldots, \lfloor n/d \rfloor$ 执行 `union(d, kd)`。团内任意两点 $ad$、$bd$ 的连通性由「$ad - d - bd$」两条真实边保证，无需 $\binom{\lfloor n/d \rfloor}{2}$ 次两两合并。

**第四步：团与团自动缝合。** 不同 $d$ 的团通过**共享的倍数**合并：例如 $n = 12$、$\text{threshold} = 2$ 时，$d = 3$ 的团 $\{3, 6, 9, 12\}$ 与 $d = 4$ 的团 $\{4, 8, 12\}$ 共享城市 $12$，两轮合并后 $\{3, 4, 6, 8, 9, 12\}$ 全连通——这正是「传递闭包」要捕捉的中转路径。

**代价是调和级数。** 对每个 $d \in (\text{threshold}, n]$ 做 $\lfloor n/d \rfloor - 1$ 次合并：

$$\sum_{d=\text{threshold}+1}^{n} \left(\Bigl\lfloor \frac{n}{d} \Bigr\rfloor - 1\right) \le \sum_{d=1}^{n} \frac{n}{d} = O(n \log n)$$

$n = 10^4$、$\text{threshold} = 0$ 的最坏情形合并总数也不到 $10^5$ 次，比暴力少了三个数量级。

### 3.3 算法流程

![算法流程：先按约数批量合并，再逐查询判 find 相等](images/wc211_q4_algorithm_flow.svg)

```text
1. 初始化并查集：parent[i] = i（1 ≤ i ≤ n）
2. for d = threshold+1 … n:            # 所有可能成为 z 的约数
       for m = 2d, 3d, … (m ≤ n):      # d 的倍数（跳过自身）
           union(d, m)                 # 枢纽 d ↔ 倍数 m，gcd = d > threshold
3. for 每个查询 [a, b]:
       answer ← (find(a) == find(b))
```

两层循环就是「埃氏筛」的骨架：外层枚举筛子 $d$，内层跳着扫它的倍数。查询阶段纯 $O(\alpha(n))$。

### 3.4 示例演算

![示例演算：n=12, threshold=2 的合并过程与查询判定](images/wc211_q4_walkthrough.svg)

取 $n = 12$、$\text{threshold} = 2$（比赛示例 1 的放大版，能看清「缝合」）：

| $d$ | 倍数（$\le 12$） | 执行的合并 | 连通块变化 |
|-----|-----------------|-----------|-----------|
| 3 | 6, 9, 12 | `union(3,6)`、`(3,9)`、`(3,12)` | 凑出 $\{3,6,9,12\}$ |
| 4 | 8, 12 | `union(4,8)`、`(4,12)` | 经 12 牵线 → $\{3,4,6,8,9,12\}$ |
| 5 | 10 | `union(5,10)` | 凑出 $\{5,10\}$ |
| 6 | 12 | `union(6,12)`（已在同集） | 不变 |
| 7…12 | $2d > 12$，无倍数 | — | 不变 |

最终连通块：$\{3,4,6,8,9,12\}$、$\{5,10\}$、孤立点 $1, 2, 7, 11$。

注意查询 $[6, 4]$：$\gcd(6,4) = 2 \le 2$，**没有直接边**，但 $6 - 12 - 4$ 是合法路径（$\gcd(6,12) = 6$、$\gcd(12,4) = 4$），答案是 `true`——这就是传递闭包与并查集的价值。而城市 $2$ 与任何数的 gcd 只能是 $1$ 或 $2$，永远搭不出 $> 2$ 的桥，是天然孤点。比赛示例 1（$n = 6$）里只有 $d = 3$ 轮做了一次 `union(3,6)`，与答案 $[\text{false}, \text{false}, \text{true}]$ 吻合。

## 4. 算法细节

1. **为什么 $d$ 只需枚举到 $n$**：$z \mid x$ 且 $x \ge 1$ 蕴含 $z \le x \le \min(x, y) \le n$，合法的桥 $z$ 一定是 $[1, n]$ 内的城市；外层循环 $d \in [\text{threshold}+1,\ n]$ 恰好覆盖所有可能。
2. **内层从 $m = 2d$ 开始**：$m = d$ 是自身，跳过。把相邻倍数连成链（如 $6 - 12 - 18$）也能保证连通，但以 $d$ 为星的中心最直观，且每次 `union(d, m)` 的合法性一眼可见：$\gcd(d, kd) = d > \text{threshold}$。
3. **并查集实现**：路径压缩（或路径减半）+ 按大小合并，单次 `find` / `union` 均摊 $O(\alpha(n))$。$n$ 只有 $10^4$，数组开 $n + 1$ 即可。
4. **合并与查询解耦**：先做完所有合并再回答查询；查询相互独立、无顺序依赖，本题为一次性离线返回，顺序无所谓。
5. **重复合并不需要去重**：同一对点可能被多个 $d$ 的轮次重复触发合并（如 `union(6,12)` 在 $d=3$、$d=6$ 各一次），第二次起是空操作，无正确性影响。

## 5. 正确性证明

**引理 1（边的判定）**：对城市 $x \ne y$，$x$ 与 $y$ 之间有道路 $\iff$ $\gcd(x, y) > \text{threshold}$。

**证明**：（⇒）设有道路，则存在 $z > \text{threshold}$ 且 $z \mid x$、$z \mid y$。由 $z$ 同时整除 $x, y$ 知 $z \mid \gcd(x, y)$，故 $\gcd(x, y) \ge z > \text{threshold}$。（⇐）取 $z = \gcd(x, y) > \text{threshold}$，则 $z \mid x$、$z \mid y$、$z > \text{threshold}$ 三条件全部成立，故有道路。∎

**引理 2（安全性——只沿真实边合并）**：算法执行的每次 `union(d, m)` 中，$d$ 与 $m$ 在图中确有边。

**证明**：内层循环保证 $m = kd$（$k \ge 2$），故 $\gcd(d, m) = d > \text{threshold}$，由引理 1 知 $d$ 与 $m$ 之间有边。∎

**引理 3（完备性——每条真实边必被合并）**：若图中 $x$ 与 $y$ 有边，则算法结束后 $\mathrm{find}(x) = \mathrm{find}(y)$。

**证明**：设 $g = \gcd(x, y) > \text{threshold}$（引理 1），写 $x = ag$、$y = bg$。算法在 $d = g$ 的轮次对所有 $k = 2, \ldots, \lfloor n/g \rfloor$ 执行 `union(g, kg)`。若 $a = 1$，则 $x = g$，与 $g$ 平凡同集；若 $a \ge 2$，则 $x = ag \le n$ 是被合并的倍数之一，执行后 $x$ 与 $g$ 同集。$y$ 同理。故 $\mathrm{find}(x) = \mathrm{find}(y)$。∎

**定理（主定理）**：对任意查询 $[a, b]$，算法输出 `true` 当且仅当 $a$ 与 $b$ 在图中连通。

**证明**：（连通 ⇒ 同集）若 $a, b$ 连通，存在路径 $a = v_0, v_1, \ldots, v_k = b$，每对相邻 $(v_i, v_{i+1})$ 是图中边。由引理 3，每对相邻点算法结束后同集；同集合关系是等价关系，沿路径传递得 $\mathrm{find}(a) = \mathrm{find}(b)$，输出 `true`。（同集 ⇒ 连通）对合并序列归纳，维护不变式「**同一集合内任意两点在图中连通**」：初始各自成集，平凡成立；每次 `union(d, m)` 合并集合 $S_1 \ni d$ 与 $S_2 \ni m$，对任意 $u \in S_1$、$v \in S_2$，由归纳假设 $u$ 与 $d$ 连通、$m$ 与 $v$ 连通，又由引理 2 知 $d$ 与 $m$ 有边，拼接得 $u$ 与 $v$ 连通，不变式保持。算法结束后同集 ⟹ 图中连通。∎

## 6. 复杂度分析

- **时间复杂度**：合并阶段为调和级数 $O\bigl(n \log \frac{n}{\max(\text{threshold}, 1)}\bigr)$（$\text{threshold} = 0$ 时即 $O(n \log n)$，$n = 10^4$ 约为 $8 \times 10^4$ 次 union），查询阶段 $O(q \cdot \alpha(n))$。$n = 10^4$、$q = 10^5$ 时总计约 $2 \times 10^5$ 次近常数操作。
- **空间复杂度**：$O(n)$ 存并查集（输出数组不计入）。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    vector<bool> areConnected(int n, int threshold, vector<vector<int>>& queries) {
        vector<int> parent(n + 1), sz(n + 1, 1);
        iota(parent.begin(), parent.end(), 0);

        auto find = [&](int x) {                  // 迭代 + 路径减半
            while (parent[x] != x) {
                parent[x] = parent[parent[x]];
                x = parent[x];
            }
            return x;
        };
        auto unite = [&](int a, int b) {          // 按大小合并
            a = find(a); b = find(b);
            if (a == b) return;
            if (sz[a] < sz[b]) swap(a, b);
            parent[b] = a;
            sz[a] += sz[b];
        };

        for (int d = threshold + 1; d <= n; ++d)
            for (int m = 2 * d; m <= n; m += d)   // 埃氏筛式跳步扫倍数
                unite(d, m);

        vector<bool> ans;
        ans.reserve(queries.size());
        for (auto& q : queries)
            ans.push_back(find(q[0]) == find(q[1]));
        return ans;
    }
};
```

### Python

```python
class Solution:
    def areConnected(self, n: int, threshold: int, queries: List[List[int]]) -> List[bool]:
        parent = list(range(n + 1))
        size = [1] * (n + 1)

        def find(x: int) -> int:                  # 迭代 + 路径减半，防递归爆栈
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x

        def union(a: int, b: int) -> None:        # 按大小合并
            ra, rb = find(a), find(b)
            if ra == rb:
                return
            if size[ra] < size[rb]:
                ra, rb = rb, ra
            parent[rb] = ra
            size[ra] += size[rb]

        for d in range(threshold + 1, n + 1):
            for m in range(2 * d, n + 1, d):      # 埃氏筛式跳步扫倍数
                union(d, m)

        return [find(a) == find(b) for a, b in queries]
```

## 8. 边界情况与易错点

1. **threshold = 0**：$d$ 从 1 开始，第一轮就把 $1$ 与所有城市合并，全图连通，所有查询 `true`（示例 2）。别对 $d = 1$ 写特判跳过。
2. **threshold ≥ n**（题面允许取到 $n$）：外层循环为空，图中无任何边，所有查询 `false`。循环边界 $d \in [\text{threshold}+1, n]$ 天然处理，无需特判。
3. **不要照搬「质因子代表元」套路**：952 / 2709 这类 $\gcd > 1$ 的题只需按**质因子**合并，但本题是 $\gcd > \text{threshold}$——反例：$\text{threshold} = 2$ 时 $(4, 8)$ 的公共质因子只有 $2$（不超过阈值），但 $\gcd(4, 8) = 4 > 2$，二者应当连通。必须按**约数**而非质因子合并。
4. **查询问的是连通不是邻接**：像 $[6, 4]$ 这种「无直接边但可中转」的查询很容易误判，千万不要在查询时现算 $\gcd(a, b)$ 了事（那只是判断直接边）；中转结构必须靠并查集的传递闭包。
5. **内层循环起点**：$m$ 从 $2d$ 开始（$m = d$ 是自身无意义）；写成 `range(d, n+1, d)` 只是多一次无害的自合并，但 `range(2*d, ...)` 语义更干净。
6. **重复合并不影响正确性**：同一对点可能被多个 $d$ 的轮次重复合并，第二次起是空操作，无需判重。
7. **复杂度别按嵌套循环直觉估成 $O(n^2)$**：合并次数是调和级数 $O(n \log n)$，`for d … for m += d` 的结构与埃氏筛完全同构。
8. **Python 实现细节**：`find` 用迭代 + 路径减半避免递归深度问题；$q = 10^5$ 次查询用列表推导一次性产出。
