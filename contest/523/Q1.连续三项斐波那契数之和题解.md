# LeetCode 连续三项斐波那契数之和 题解

## 1. 题目概述

- **标题 / 题号**：连续三项斐波那契数之和（#4078，easy）
- **链接**：https://leetcode.cn/problems/three-fibonacci-sum/
- **来源**：LeetCode 第 523 场周赛 Q1
- **难度**：简单
- **标签**：数学、斐波那契、枚举

**题意**：斐波那契数列以 0、1 开头，之后每项等于前两项之和（0, 1, 1, 2, 3, 5, 8, 13, ...）。给定整数 $n$，判断是否存在数列中**下标连续的三项** $F(i), F(i+1), F(i+2)$ 使其和恰好为 $n$：存在返回 `true`，否则返回 `false`。

**约束**：

- $1 \le n \le 10^9$

## 2. 示例

**示例 1**

```text
输入：n = 16
输出：true
解释：连续三项 3、5、8 之和为 3 + 5 + 8 = 16。
```

**示例 2**

```text
输入：n = 8
输出：false
解释：虽然 1 + 2 + 5 = 8，但这三项在数列中下标并不连续，
      不存在和等于 8 的连续三项。
```

**示例 3**

```text
输入：n = 2
输出：true
解释：数列前三项之和为 0 + 1 + 1 = 2。
```

## 3. 解题思路

### 3.1 朴素思路

三元组 $(F(0), F(1), F(2)), (F(1), F(2), F(3)), \dots$ 的和依次为 $2, 4, 6, 10, 16, \dots$，随起点**单调递增**。于是直接滚动三元组：从 $(a, b, c) = (0, 1, 1)$ 出发，每步变为 $(b, c, b+c)$，直到三项和 $\ge n$，判断是否恰好相等。斐波那契数**指数增长**（第 $k$ 项 $\approx \varphi^k / \sqrt{5}$，$\varphi \approx 1.618$），$10^9$ 以内只有约 45 项，枚举本身已经飞快。

但签到题的价值在于**从题面到代码的最短路径**——三项之和有一个一步到位的恒等式，能把问题化成"n/2 是不是斐波那契数"。

### 3.2 核心观察：连续三项之和 = 2 × 最大项

由数列定义 $F(i) + F(i+1) = F(i+2)$，代入三项和：

$$F(i) + F(i+1) + F(i+2) = F(i+2) + F(i+2) = 2 \cdot F(i+2)$$

**连续三项之和恰等于最大项的两倍**：

| 三元组 | 和 | 即 |
|--------|----|----|
| (0, 1, 1) | 2 | 2 × 1 |
| (1, 2, 3) | 6 | 2 × 3 |
| (3, 5, 8) | 16 | 2 × 8 |
| (5, 8, 13) | 26 | 2 × 13 |

于是判定条件一步化为：**$n$ 为偶数，且 $n/2$ 是斐波那契数**（最大项下标 $\ge 2$）。奇数 $n$ 直接输出 `false`。

![连续三项之和恒等式](images/wc523_q1_triple_sum_identity.svg)

> 💡 一句话：**$n$ 能表示 $\iff$ $n/2$ 是斐波那契数**（顺带 $n$ 必须是偶数）。示例 2 的 8 之所以不行，是因为 4 不是斐波那契数。

### 3.3 算法流程

![判定流程：奇偶剪枝 + 一遍斐波那契扫描](images/wc523_q1_algorithm_flow.svg)

1. 若 $n$ 为奇数，返回 `false`（三项和 $2 \cdot F(i+2)$ 恒为偶数）
2. 令 $m = n / 2$
3. 从 $a = 0,\ b = 1$ 开始滚动生成斐波那契数：只要 $a < m$ 就执行 $(a, b) \leftarrow (b,\ a + b)$
4. 循环结束时必有 $a \ge m$，返回 $a == m$

### 3.4 示例演算

![示例演算](images/wc523_q1_example_walkthrough.svg)

- $n = 16$：$m = 8$，序列扫过 0, 1, 1, 2, 3, 5 后命中 8 → `true`（即 3 + 5 + 8）
- $n = 8$：$m = 4$，序列扫过 0, 1, 1, 2, 3 后下一项是 5，越过 4 → `false`
- $n = 2$：$m = 1$，序列第二项即命中 1 → `true`（即 0 + 1 + 1）
- $n = 1$：奇数，直接 `false`

## 4. 算法细节

1. **恒等式推导**：$F(i) + F(i+1) = F(i+2)$ 是数列定义，代入即得三项和 $= 2F(i+2)$；用前缀和 $\sum_{j=0}^{t} F(j) = F(t+2) - 1$ 做差可得 $F(i+4) - F(i+1) = 2F(i+2)$，两条路殊途同归。
2. **下标边界（$k \ge 2$）**：三元组从下标 $i \ge 0$ 出发，最大项下标 $i+2 \ge 2$。好在值 $1$ 恰好出现两次（$F(1) = F(2) = 1$），**每个正的斐波那契数值都在下标 $\ge 2$ 处出现**，所以"$m$ 是斐波那契数"的判定不需要排除任何值。
3. **两变量滚动**：只需 $a, b$ 即可生成整个序列，无需数组；判等在循环退出后一次完成，同时覆盖"命中"与"越过"两种停止方式。
4. **溢出**：$m \le 5 \times 10^8$，扫描越过 $m$ 后至多再算一项，最大中间值为 $F(45) \approx 1.13 \times 10^9$，`int` 尚能装下但已过半程，C++ 建议直接 `long long`。

## 5. 正确性证明

**引理 1（三项和恒等式）**：对任意 $i \ge 0$，$F(i) + F(i+1) + F(i+2) = 2F(i+2)$。

**证明**：由递推定义 $F(i+2) = F(i) + F(i+1)$，代入左边得 $F(i+2) + F(i+2) = 2F(i+2)$。∎

**引理 2（判定条件）**：$n$ 可表示为连续三项之和 $\iff$ $n$ 为偶数，且 $m = n/2$ 等于某个下标 $k \ge 2$ 的斐波那契数 $F(k)$。

**证明**：
（⇒）设 $n = F(i) + F(i+1) + F(i+2)$，$i \ge 0$。由引理 1，$n = 2F(i+2)$ 为偶数，且 $m = F(i+2)$，下标 $i + 2 \ge 2$。
（⇐）设 $m = F(k)$，$k \ge 2$。取三元组 $(F(k-2), F(k-1), F(k))$，三项下标 $k-2 \ge 0$ 均合法，由引理 1 其和为 $2F(k) = 2m = n$。∎

**定理**：算法对任意 $1 \le n \le 10^9$ 正确返回 $n$ 是否可表示。

**证明**：算法恰好逐条检验引理 2 的条件：先做奇偶判定，奇数时必要条件不成立，返回 `false` 正确；对偶数 $n$ 令 $m = n/2$，按 $F(0), F(1), F(2), \dots$ 顺序生成扫描。序列从 $0, 1$ 起单调不降（$F(1) = F(2) = 1$，之后严格递增），"扫到 $a \ge m$ 才停"保证：若 $m$ 是某个生成值，必在停止处命中 $a = m$；若未命中，则 $m$ 严格落在两个相邻生成值之间（生成无上界，循环必停于某个 $a \ge m$），不是斐波那契数。两种返回均与引理 2 一致。∎

## 6. 复杂度分析

- **时间复杂度**：$O(\log n)$。斐波那契数指数增长，第 $k$ 项 $\approx \varphi^k / \sqrt{5}$，生成到首次 $\ge m \le 5 \times 10^8$ 只需约 45 次迭代；奇数 $n$ 更是 $O(1)$ 剪枝。
- **空间复杂度**：$O(1)$。仅 `a`、`b` 两个滚动变量。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    bool threeFibonacciSum(int n) {
        if (n % 2 == 1) return false;
        long long m = n / 2;
        long long a = 0, b = 1;
        while (a < m) {
            long long c = a + b;
            a = b;
            b = c;
        }
        return a == m;
    }
};
```

### Python

```python
class Solution:
    def threeFibonacciSum(self, n: int) -> bool:
        if n % 2:
            return False
        m = n // 2
        a, b = 0, 1
        while a < m:
            a, b = b, a + b
        return a == m
```

## 8. 边界情况与易错点

1. **奇数必为 false**：三项和 $2F(i+2)$ 恒为偶数，$n = 1$ 这类输入直接返回，还省一半扫描。
2. **"连续"指下标连续**：示例 2 的坑——$1 + 2 + 5 = 8$ 数值上成立，但下标不连续。用"$n/2$ 是不是斐波那契数"判定，自动规避这类组合歧义。
3. **别去重数列**：$F(1) = F(2) = 1$，序列是 0, 1, **1**, 2, ...，两个 1 都要保留；$n = 2$ 依赖三元组 $(0, 1, 1)$。若把序列当严格递增处理（如去重后二分），会误判 $m = 1$。
4. **循环条件与判等分离**：`while (a < m)` 滚动、退出后 `return a == m`，一次扫描同时覆盖"命中"与"越过"；不要在循环体内判等后忘记越界返回。
5. **溢出贴边**：$m \le 5 \times 10^8$ 时扫描最大会碰到 $F(45) \approx 1.13 \times 10^9$，仍在 `int`（上限约 $2.1 \times 10^9$）范围内，但建议 `long long` 保险；Python 无此问题。

**延伸思考**：

- **O(1) 判定**：$m$ 是斐波那契数 $\iff$ $5m^2 + 4$ 或 $5m^2 - 4$ 是完全平方数。$m \le 5 \times 10^8$ 时 $5m^2 \approx 1.25 \times 10^{18}$，C++ 需 `long long`（Python 天然大数）。
- **推广到连续 $k$ 项之和**：由 $\sum_{j=0}^{t} F(j) = F(t+2) - 1$ 做差，$\sum_{j=i}^{i+k-1} F(j) = F(i+k+1) - F(i+1)$。$k = 3$ 时恰化简为 $2F(i+2)$；一般 $k$ 则要判断"$n + F(i+1)$ 是否为斐波那契数"，不再是一个简单的倍数关系。
- **与 Zeckendorf 定理对照**：任何正整数都可**唯一**表示成若干个**下标互不相邻**（$\ge 2$）的斐波那契数之和；本题反其道而行，要求恰好**连续三项**——可表示的 $n$ 因此非常稀疏（$10^9$ 内仅 42 个，即 $2F(k)$，$2 \le k \le 43$）。
