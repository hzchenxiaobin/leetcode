# LeetCode 子串的最大出现次数 题解

## 1. 题目概述

- **标题 / 题号**：子串的最大出现次数（#1297，medium）
- **链接**：https://leetcode.cn/problems/maximum-number-of-occurrences-of-a-substring/
- **来源**：LeetCode 第 168 场周赛 Q3
- **难度**：中等
- **标签**：哈希表、字符串、滑动窗口

**题意**：给定字符串 `s` 与三个整数 `maxLetters`、`minSize`、`maxSize`，在所有满足条件

- 子串中**不同字母的数目**不超过 `maxLetters`；
- 子串长度 $L$ 满足 $\text{minSize} \le L \le \text{maxSize}$；

的子串里，找出**出现次数最多**的那个，返回它的出现次数（出现位置可以重叠）。若没有任何合法子串，返回 `0`。

**约束**：

- $1 \le \lvert s \rvert \le 10^5$
- $1 \le \text{maxLetters} \le 26$
- $1 \le \text{minSize} \le \text{maxSize} \le \min(26, \lvert s \rvert)$
- `s` 只包含小写英文字母

注意 `maxSize` 被限制在 26 以内，这不是巧合——它暗示「长度维度的枚举是廉价的」，而真正的突破口在别处。

## 2. 示例

**示例 1**

```text
输入：s = "aababcaab", maxLetters = 2, minSize = 3, maxSize = 4
输出：2
解释：子串 "aab" 出现 2 次（下标 0 与 6），
      它只有 2 种字母且长度为 3，满足全部要求。
```

**示例 2**

```text
输入：s = "aaaa", maxLetters = 1, minSize = 3, maxSize = 3
输出：2
解释："aaa" 出现 2 次，两次出现重叠在下标 1 处。
```

**示例 3**

```text
输入：s = "aabcabcab", maxLetters = 2, minSize = 2, maxSize = 3
输出：3
解释：长度 2 的子串中 "ab" 出现 3 次，是出现次数最多的合法子串。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有子串（起点 $i$、终点 $j$，$O(n^2)$ 个），逐个判断不同字母数是否 $\le \text{maxLetters}$，再用哈希表统计频次。子串本身最长 26，判重与统计的代价是 $O(n^2 \cdot 26)$ 的字符量、$O(n^2)$ 个哈希键——$n = 10^5$ 时键的数量就是 $10^{10}$ 级，内存与时间都直接爆炸。

退一步想：即便只枚举「长度 $\in [\text{minSize}, \text{maxSize}]$」的窗口，窗口个数也有 $n \cdot (\text{maxSize} - \text{minSize} + 1)$，最坏 $26n = 2.6 \times 10^6$——这其实**已经是可接受的**。但还可以更省：下面证明，**只需**看长度恰好为 `minSize` 的窗口。

### 3.2 核心观察：最优长度一定是 minSize

![长窗口的每次出现都内含一次短前缀的出现](images/wc168_q3_min_size_dominates.svg)

把任意一个合法子串 $t$（长度 $L \ge \text{minSize}$）截取它的**前 minSize 个字符**，得到 $p$：

1. **$p$ 必然合法**：$p$ 的字母集合是 $t$ 的字母集合的子集，所以 $\text{distinct}(p) \le \text{distinct}(t) \le \text{maxLetters}$，长度也恰好落在 $[\text{minSize}, \text{maxSize}]$ 内。
2. **$p$ 的频次不低于 $t$**：$t$ 每在位置 $i$ 出现一次，$p$ 就也在位置 $i$ 出现一次（同一个起点，只是提前结束）。所以 $\text{freq}(p) \ge \text{freq}(t)$。

两者合起来说明：**对任何长度 $> \text{minSize}$ 的合法子串，总存在一个长度恰为 minSize 的合法子串，出现次数不少于它**。于是

$$\text{ans} = \max\{\, \text{freq}(w) \;:\; \lvert w \rvert = \text{minSize},\ \text{distinct}(w) \le \text{maxLetters} \,\}$$

`maxSize` 连一次比较都不需要做——它是个**冗余参数**（比赛时很多人在这里纠结枚举长度，白白多写一层循环）。

### 3.3 算法流程

![定长滑窗 + 频次哈希表](images/wc168_q3_sliding_window_flow.svg)

问题已经退化成「长度固定的窗口 + 频次统计」，是最标准的滑窗：

1. 维护一个长度恒为 `minSize` 的窗口，用 `cnt[26]` 记录窗口内每个字母的个数，`distinct` 记录不同字母的种数；
2. 右端加入 `s[i]`：`cnt` 由 0 变 1 时 `distinct++`；
3. 若窗口已超过 `minSize`，左端 `s[i - minSize]` 出窗：`cnt` 由 1 变 0 时 `distinct--`；
4. 若窗口已成形（`i >= minSize - 1`）且 `distinct <= maxLetters`，把窗口字符串作为键放进哈希表计数，并更新最大值；
5. 扫完返回最大值（一个合法窗口都没有时自然为 0）。

### 3.4 示例演算

![示例 s = aababcaab 的逐窗演算](images/wc168_q3_walkthrough.svg)

对示例 1（`s = "aababcaab"`，`maxLetters = 2`，`minSize = 3`），长度 3 的窗口共 $9 - 3 + 1 = 7$ 个：

| 起点 $i$ | 窗口 | 不同字母数 | 合法 | 该窗口累计频次 |
|----------|------|-----------|------|---------------|
| 0 | `aab` | 2 | 是 | 1 |
| 1 | `aba` | 2 | 是 | 1 |
| 2 | `bab` | 2 | 是 | 1 |
| 3 | `abc` | 3 | 否 | — |
| 4 | `bca` | 3 | 否 | — |
| 5 | `cab` | 3 | 否 | — |
| 6 | `aab` | 2 | 是 | **2** |

`aab` 在起点 0 与 6 各出现一次（互不重叠），最大值 2，与官方输出一致。作为对照，长度 4 的合法窗口只有 `aaba`、`abab`，各出现 1 次——确实打不过长度 3，正好印证 §3.2 的结论。

## 4. 算法细节

1. **`distinct` 的维护是 O(1)**：不要每次重新扫一遍窗口数不同字母（那是 $O(n \cdot \text{minSize})$ 的额外常数）。只有「计数 0→1」和「1→0」两个时刻才改变 `distinct`，这是写定长滑窗的通行模板。
2. **窗口的合法性判断时机**：`i >= minSize - 1` 保证窗口长度已满 `minSize`；此时 `distinct` 恰好是窗口内不同字母数，可以直接比较。
3. **哈希表的键**：直接用窗口子串 `s.substr(i - minSize + 1, minSize)` 做键。字符串哈希对每个窗口的代价是 $O(\text{minSize}) \le 26$，整体 $O(26n)$，实测 $n = 10^5$ 时毫秒级；想做到严格 $O(n)$ 可用 `string_view`（C++17，零拷贝）或多项式滚动哈希。
4. **不要忘记 `maxSize` 参数**：它出现在签名里却**完全不参与计算**。这是本题最反直觉的点，提交时保留参数即可，不必使用（编译器可能提示未使用，正常）。
5. **频次是「出现位置数」而非「不重叠次数」**：示例 2 的 `"aaa"` 在 `"aaaa"` 中出现在下标 0 与 1，答案是 2 而不是 1。滑窗统计天然按起点计数，正好符合要求。
6. **哈希表容量**：C++ 中先 `freq.reserve(2 * n)`，避免 25 万级插入引发多次 rehash；Python 的 `dict` 无需处理。
7. **答案初值取 0**：没有任何合法窗口时（如上面 `"abcde"` 那组）直接返回 0，不必额外特判。

## 5. 正确性证明

**引理 1（合法性的下封闭）**：若子串 $t$ 满足 $\text{distinct}(t) \le \text{maxLetters}$，则 $t$ 的任意子串 $u$ 也满足该条件。

**证明**：$u$ 的字母集合是 $t$ 的字母集合的子集，故 $\text{distinct}(u) \le \text{distinct}(t) \le \text{maxLetters}$。∎

**引理 2（固定偏移处频次单调）**：设 $\lvert t \rvert \ge \text{minSize}$，取 $p$ 为 $t$ 的前 `minSize` 个字符。则 $\text{freq}(p) \ge \text{freq}(t)$。

**证明**：设 $t$ 的出现起点集合为 $S$。对任意 $i \in S$，$s[i..i+\lvert t \rvert) = t$，于是 $s[i..i+\text{minSize}) = p$，即 $i$ 也是 $p$ 的一个出现起点。故 $p$ 的出现起点集合包含 $S$，取基数即得 $\text{freq}(p) \ge \text{freq}(t)$。∎

**引理 3（滑窗统计精确）**：算法对每个 $i \in [0, n - \text{minSize}]$ 恰好处理一次长度为 `minSize` 的窗口 $s[i..i+\text{minSize})$，且处理时 `distinct` 等于该窗口内不同字母的个数。

**证明**：循环变量 $i$ 单调递增，窗口为 $s[i-\text{minSize}+1..i]$；当 $i \ge \text{minSize}-1$ 时窗口长度恰为 `minSize`，起点 $i-\text{minSize}+1$ 遍历 $[0, n-\text{minSize}]$，每个起点恰好一次。`cnt` 在右端入、左端出时同步加减，其内容恒等于窗口内各字母的计数，而 `distinct` 在 0→1 与 1→0 时增减，恒等于计数非零的字母种数。∎

**定理**：算法返回值等于题目所求的最大出现次数。

**证明**：记 $\mathcal{W}$ 为所有长度 `minSize`、不同字母数 $\le \text{maxLetters}$ 的窗口字符串集合，$\mathcal{T}$ 为所有合法的长度 $\in [\text{minSize}, \text{maxSize}]$ 的子串集合。

- 由引理 3，算法返回 $\max_{w \in \mathcal{W}} \text{freq}(w)$（空集时为 0）。
- 一方面 $\mathcal{W} \subseteq \mathcal{T}$（长度恰为 `minSize` 且合法），故 $\max_{\mathcal{W}} \text{freq} \le \max_{\mathcal{T}} \text{freq}$。
- 另一方面任取 $t \in \mathcal{T}$，由引理 1 其长为 `minSize` 的前缀 $p \in \mathcal{W}$，由引理 2 得 $\text{freq}(p) \ge \text{freq}(t)$，故 $\max_{\mathcal{W}} \text{freq} \ge \max_{\mathcal{T}} \text{freq}$。

两向夹逼得到相等，即算法输出恰为最大出现次数。∎

## 6. 复杂度分析

- **时间**：$O(n \cdot \text{minSize}) \le O(26n)$。扫描一遍 $s$，每个下标做常数次计数更新；对每个合法窗口构造字符串键并计算哈希，代价 $O(\text{minSize}) \le 26$；哈希表插入期望 $O(1)$。若用 `string_view` 或滚动哈希则降为严格的 $O(n)$。
- **空间**：$O(n \cdot \text{minSize})$ 字符，即哈希表最坏存 $n - \text{minSize} + 1$ 个键、每个键长 `minSize`（$n = 10^5$、`minSize` $\le 26$ 时约数 MB）；计数数组 `cnt[26]` 与计数器是 $O(1)$ 的。若改用滚动哈希做键，空间降为 $O(n)$ 个 64 位整数。

## 7. 参考代码

### C++

```cpp
#include <string>
#include <vector>
#include <unordered_map>
#include <algorithm>
using namespace std;

class Solution {
public:
    int maxFreq(string s, int maxLetters, int minSize, int maxSize) {
        int n = (int)s.size();
        vector<int> cnt(26, 0);
        int distinct = 0, best = 0;
        unordered_map<string, int> freq;          // 窗口 -> 出现次数
        freq.reserve((size_t)n * 2);

        for (int i = 0; i < n; i++) {
            if (++cnt[s[i] - 'a'] == 1) distinct++;          // 右端入窗
            if (i >= minSize) {                              // 左端出窗
                int out = s[i - minSize] - 'a';
                if (--cnt[out] == 0) distinct--;
            }
            if (i >= minSize - 1 && distinct <= maxLetters) {
                best = max(best, ++freq[s.substr(i - minSize + 1, minSize)]);
            }
        }
        return best;                                          // maxSize 不参与
    }
};
```

### Python

```python
class Solution:
    def maxFreq(self, s: str, maxLetters: int, minSize: int, maxSize: int) -> int:
        n = len(s)
        cnt = [0] * 26
        distinct = 0
        freq = {}
        best = 0

        for i in range(n):
            c = ord(s[i]) - 97
            if cnt[c] == 0:                 # 右端入窗
                distinct += 1
            cnt[c] += 1

            if i >= minSize:                # 左端出窗
                o = ord(s[i - minSize]) - 97
                cnt[o] -= 1
                if cnt[o] == 0:
                    distinct -= 1

            if i >= minSize - 1 and distinct <= maxLetters:
                w = s[i - minSize + 1:i + 1]
                freq[w] = freq.get(w, 0) + 1
                if freq[w] > best:
                    best = freq[w]

        return best                         # maxSize 不参与
```

## 8. 边界情况与易错点

1. **`maxSize` 是冗余参数**：它只影响「哪些长度可选」，而最优长度必然是 `minSize`。若照着题面把 $[\text{minSize}, \text{maxSize}]$ 全部枚举，虽然也能过（$26n$ 量级），但代码与常数都翻倍。这是本题最值得记住的观察。
2. **一个合法窗口都没有**：如 `s = "abcde", maxLetters = 2, minSize = 3, maxSize = 3`，返回 `0`，不要返回 $-1$，也不要把未初始化的最大值留成 `INT_MIN`。
3. **`minSize == 1`**：滑窗退化成单字符，`i >= minSize - 1` 恒真；此时 `distinct` 为该字符（1），只要 `maxLetters >= 1` 就合法，答案等于 `s` 中出现最多的字符个数。
4. **`minSize == n`**：只有整个串一个窗口，注意循环里 `i >= minSize` 的出窗分支永远不会触发，别把判断写成 `i > minSize` 导致误删字符。
5. **重叠出现要重复计数**：`"aaaa"` 中 `"aaa"` 出现 2 次（下标 0、1）。用「起点」枚举天然正确，但若用 `find` + 跳 `len` 的方式统计（不重叠匹配）就会得到 1。
6. **频次上限**：同一窗口最多出现 $n - \text{minSize} + 1 \le 10^5$ 次，`int` 足够，不必用 `long long`。
7. **C++ 的临时字符串键**：`freq[s.substr(...)]` 每次都会构造并哈希一个临时 `string`，$n = 10^5$ 时累计拷贝约 $2.6 \times 10^6$ 字节，可接受；若追求极致可改用 `string_view` 作键，避免分配。
