# LeetCode 检查是否所有字符出现次数相同 题解

## 1. 题目概述

- **标题 / 题号**：检查是否所有字符出现次数相同（#1941，easy）
- **链接**：https://leetcode.cn/problems/check-if-all-characters-have-equal-number-of-occurrences/
- **来源**：LeetCode 第 57 场双周赛 Q1
- **难度**：简单
- **标签**：哈希表、字符串、计数

**题意**：给定字符串 $s$，若 $s$ 中**出现过的**每个字符出现次数都相同，则称 $s$ 为「好字符串」。判断 $s$ 是否为好字符串。注意判定的对象只有出现过的字符，没出现的字符不影响结论。

**约束**：

- $1 \le s.length \le 1000$
- $s$ 只包含小写英文字母

## 2. 示例

**示例 1**

```text
输入：s = "abacbc"
输出：true
解释：s 中出现过的字符为 'a'、'b'、'c'，均出现 2 次，次数相同。
```

**示例 2**

```text
输入：s = "aaabb"
输出：false
解释：'a' 出现 3 次，'b' 出现 2 次，次数不同。
```

**示例 3（边界补充）**

```text
输入：s = "zzzzz"
输出：true
解释：只出现一种字符 'z'，共 5 次；「出现过」的字符集合里只有一个成员，
自然所有成员次数相同（单桶全等的特例）。
```

## 3. 解题思路

### 3.1 暴力思路

对每个「出现过的字符」$c$，重新扫描一遍 $s$ 统计它的出现次数，再两两比较：外层 $O(26)$ 个候选字符、每趟 $O(n)$，总计 $O(26n)$，对本题 $n \le 1000$ 完全够用。但这个写法把同一份字符串扫了最多 26 遍，且实现上要先收集「出现过的字符」再比较，绕了弯路。更直接的暴力是对每个字符维护一个计数器（即哈希表），本质已经接近最优解——签到题的价值在于把它一次写对。

### 3.2 核心观察：26 个桶计数，非零桶全相等

![26 桶计数：非零桶高度必须全部相同](images/bw57_q1_count_bars.svg)

$s$ 只含小写字母，所以用一个长度 26 的数组 `cnt` 就是一张完美的哈希表：一趟扫描 `cnt[c-'a']++`。之后**好字符串的判定条件就是：所有非零的 `cnt[x]` 相等**（零桶代表「没出现过的字符」，按题意不参与判定）。取第一个非零桶作为基准值 `ref`，再检查其余非零桶是否都等于 `ref` 即可。

### 3.3 算法流程

![算法流程：计数 → 取基准 → 全等判定](images/bw57_q1_flow.svg)

```text
1. cnt[26] 清零
2. 顺序扫描 s，cnt[c - 'a']++
3. ref = 0
4. 遍历 cnt：
       若 cnt[x] > 0 且 ref == 0：ref = cnt[x]        # 第一个非零桶作基准
       否则若 cnt[x] > 0 且 cnt[x] != ref：返回 false
5. 返回 true
```

### 3.4 示例演算

以 `s = "abacbc"` 为例，一趟扫描后 26 桶中只有三个非零桶：`cnt[a] = 2`、`cnt[b] = 2`、`cnt[c] = 2`。基准 `ref = 2`（第一个非零桶），其余非零桶均为 2，判定通过，返回 `true`。

以 `s = "aaabb"` 为例：`cnt[a] = 3`、`cnt[b] = 2`。基准 `ref = 3`，检查到 `cnt[b] = 2 \ne 3`，返回 `false`。

## 4. 算法细节

1. **只比较非零桶**：出现次数为 0 的桶对应「未出现的字符」，必须跳过；若误把它纳入比较（例如取 `ref = cnt[0]` 而恰好 `s` 不含 `a`），单字符输入会误判为 `false`。
2. **基准值的取法**：不要用 `cnt[s[0]-'a']` 之外的硬编码（例如总除以 26），直接取「第一个非零桶」最稳妥；由于 $n \ge 1$，非零桶必然存在，基准不会落空。
3. **判等可用集合化简**：统计非零桶的 distinct 值个数（`len(set(v for v in cnt if v)) == 1`）是 Python 的惯用一行写法，语义与显式循环一致。
4. **无需排序**：对 26 个桶排序（$O(26 \log 26)$）再比较首尾虽然也对，但常数更大且无必要。

## 5. 正确性证明

**引理 1**：$s$ 是好字符串，当且仅当集合 $\{cnt[c] : c \in \Sigma,\ cnt[c] > 0\}$ 中恰有一个元素（即所有非零计数相等）。

**证明**：好字符串的定义为「出现过的所有字符出现次数相同」。字符 $c$ 出现过 $\iff cnt[c] > 0$，故「出现过的字符的次数集合」即非零计数集合；该集合所有元素相同 $\iff$ 集合大小为 1。∎

**定理**：上述算法对任意只含小写字母的 $s$ 返回 `true` 当且仅当 $s$ 是好字符串。

**证明**：一趟扫描后 `cnt` 恰为各字符的出现次数（计数正确性显然）。设非零桶中第一个为桶 $x_0$，算法取 `ref = cnt[x0]`，随后逐一检查其余非零桶是否等于 `ref`：全部相等时非零计数集合为 $\{ref\}$，由引理 1 是好字符串，返回 `true`；存在不等时集合大小 $\ge 2$，非好字符串，且算法必在检查到第一个不等桶时返回 `false`。∎

## 6. 复杂度分析

- **时间**：$O(n + 26)$。一趟扫描 $O(n)$，随后常数次桶检查；$n \le 1000$ 时远低于任何限制。
- **空间**：$O(26) = O(1)$。计数数组大小只与字母表相关，与 $n$ 无关。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool areOccurrencesEqual(string s) {
        int cnt[26] = {0};
        for (char c : s) cnt[c - 'a']++;
        int ref = 0;
        for (int x : cnt)
            if (x > 0) { ref = x; break; }          // 第一个非零桶作基准
        for (int x : cnt)
            if (x > 0 && x != ref) return false;
        return true;
    }
};
```

### Python

```python
class Solution:
    def areOccurrencesEqual(self, s: str) -> bool:
        cnt = [0] * 26
        for c in s:
            cnt[ord(c) - ord('a')] += 1
        ref = next(x for x in cnt if x > 0)
        return all(x == ref for x in cnt if x > 0)
```

> 💡 两份代码均通过官方示例（`"abacbc"` → `true`、`"aaabb"` → `false`）及单字符、全同字符等边界输入。

## 8. 边界情况与易错点

1. **单字符 / 全同字符**：如 `"zzzzz"`，只有一个非零桶，天然全等，返回 `true`——不要误以为「次数必须 ≥ 2」。
2. **未出现的字符必须忽略**：比较时跳过零桶；否则 `"bcd"` 这类不含 `a` 的串会被零桶拖累而误判。
3. **基准桶可能不是 `cnt[0]`**：先找第一个非零桶再比较，避免对 `cnt[0] == 0` 的输入取错基准。
4. **返回类型是布尔**：C++ 中 `return cnt[x] == ref;` 之类的表达式易把「存在不等」写成「存在相等」，方向别搞反。
