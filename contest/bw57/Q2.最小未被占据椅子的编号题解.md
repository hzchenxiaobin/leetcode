# LeetCode 最小未被占据椅子的编号 题解

## 1. 题目概述

- **标题 / 题号**：最小未被占据椅子的编号（#1942，medium）
- **链接**：https://leetcode.cn/problems/the-number-of-the-smallest-unoccupied-chair/
- **来源**：LeetCode 第 57 场双周赛 Q2
- **难度**：中等
- **标签**：数组、哈希表、堆（优先队列）、排序、模拟

**题意**：$n$ 个朋友开派对，椅子编号 $0,1,2,\dots$ 无限多。朋友 $i$ 在时刻 $arrival_i$ 到达、时刻 $leaving_i$ 离开。到达时占据**编号最小**的未被占据椅子；离开时椅子立刻空出（同一时刻若有人到达，可立刻占上）。给定 $times$ 与 $targetFriend$，返回朋友 $targetFriend$ 占据的椅子编号。所有到达时刻互不相同。

**约束**：

- $2 \le n \le 10^4$
- $1 \le arrival_i < leaving_i \le 10^5$
- $0 \le targetFriend \le n - 1$
- 每个 $arrival_i$ 互不相同

## 2. 示例

**示例 1**

```text
输入：times = [[1,4],[2,3],[4,6]], targetFriend = 1
输出：1
解释：
- 朋友 0 时刻 1 到达 → 占椅子 0
- 朋友 1 时刻 2 到达 → 占椅子 1
- 朋友 1 时刻 3 离开 → 椅子 1 空出
- 朋友 0 时刻 4 离开 → 椅子 0 空出
- 朋友 2 时刻 4 到达 → 占椅子 0
朋友 1 占据椅子 1，返回 1。
```

**示例 2**

```text
输入：times = [[3,10],[1,5],[2,6]], targetFriend = 0
输出：2
解释：朋友 1（时刻 1）占椅子 0，朋友 2（时刻 2）占椅子 1，
朋友 0（时刻 3）到达时 0、1 号都被占，只能占椅子 2。
```

**示例 3（边界补充：同刻交接）**

```text
输入：times = [[1,4],[2,5],[4,6]], targetFriend = 2
输出：0
解释：朋友 0（1→4）占椅 0，朋友 1（2→5）占椅 1。
时刻 4 朋友 0 离开与朋友 2 到达同刻：先释放椅 0，再入座，
朋友 2 拿到椅 0。若把释放条件误写成「离开 < 到达」，此例会错误地
给出 2（椅 0 尚未释放、椅 1 被占，只能开新椅）。
```

## 3. 解题思路

### 3.1 暴力思路

逐时刻模拟：把时间 $t$ 从 $1$ 扫到 $\max leaving$，每个时刻先执行所有 $leaving = t$ 的释放，再让 $arrival = t$ 的朋友从椅子 $0$ 开始线性找第一把空椅。时间 $O(T \cdot n)$（$T \le 10^5$），约 $10^9$ 次操作，超时。另一个朴素做法是按到达顺序处理每个朋友时，线性扫全部「已发出椅子」找空位，$O(n^2) = 10^8$，同样偏慢。瓶颈在于两件事：**「到了哪个时刻」可以按事件跳转**，以及**「最小空椅」可以用堆维护**。

### 3.2 核心观察：事件排序 + 两个小根堆

![双堆模型：busy 堆按离开时刻释放，free 堆按编号取最小](images/bw57_q2_two_heaps.svg)

把朋友按**到达时刻**排序后逐个处理，只需两个堆：

- **busy 堆**：元素为 $(leaving, chair)$，按 $leaving$ 的小根堆——堆顶是最早离开的人；
- **free 堆**：元素为椅子编号的小根堆——堆顶是当前最小空椅。

处理到达时刻为 $arr$ 的朋友时，先把 busy 堆中所有 $leaving \le arr$ 的人弹出、椅子放进 free 堆（题目保证「同一时刻离开/到达可立即交接」，所以是 $\le$ 而不是 $<$）；然后从 free 堆取堆顶，若空则启用下一把全新椅子 $nextChair++$。由于到达时刻互不相同，**记录 $targetFriend$ 的到达时刻**即可在排序后锁定它，处理到该时刻直接返回答案。

### 3.3 算法流程

```text
1. targetArr = times[targetFriend][0]            # 到达时刻互不相同 → 锁定目标
2. 按 arrival 升序得到处理顺序 idx[]
3. free 堆 ← 空，busy 堆 ← 空，nextChair = 0
4. 对每个朋友 i（按 arrival 升序）：
       a. while busy 非空 且 busy.top().leaving <= arrival[i]：
              弹出，其椅子 push 进 free
       b. chair = free 非空 ? free.top（弹出） : nextChair++
       c. 若 arrival[i] == targetArr：返回 chair
       d. busy.push({leaving[i], chair})
```

### 3.4 示例演算

![示例 1 的时间线演算：到达、释放与入座顺序](images/bw57_q2_timeline.svg)

以示例 1（$times = [[1,4],[2,3],[4,6]]$，$target = 1$，$targetArr = 2$）为例：

| 时刻 | 事件 | 释放 | free 堆 | 动作 | 结果 |
|------|------|------|---------|------|------|
| 1 | 朋友 0 到达 | 无 | {} | free 空 → 新椅 0 | busy = {(4, 0)} |
| 2 | 朋友 1 到达 | 无（堆顶 leaving=4 > 2） | {} | free 空 → 新椅 1 | **到达时刻 = targetArr → 返回 1** ✓ |

若继续模拟：时刻 3 朋友 1 离开 → free = {1}；时刻 4 朋友 0 离开 → free = {0, 1}，随后朋友 2 到达取最小空椅 0。

## 4. 算法细节

1. **释放条件是 $\le$**：$leaving \le arrival$ 即释放。题目明说「如果同一时刻有另一个朋友到达，可以立即占据这张椅子」，用 $<$ 会把这种交接推迟一个人，导致复用错误。
2. **targetFriend 用到达时刻锁定**：排序会打乱下标，直接找 `id == targetFriend` 需要在排序时携带原下标；更省事的做法是先取出 $targetArr = times[targetFriend][0]$，由于到达时刻互不相同，判 `arrival == targetArr` 即可唯一锁定。
3. **两个堆的键不同**：busy 堆键是**离开时刻**（决定谁先空出来），free 堆键是**椅子编号**（决定谁被优先复用）。C++ 里 `priority_queue<pair<int,int>, ..., greater<>>` 按 pair 字典序正好实现「先比 leaving，再比 chair」。
4. **全新椅子只需计数器**： chair 编号单调递增地「发新」，无需预建无限椅子；$n$ 个人最多用到编号 $n-1$。
5. **释放与人座在同一到达事件内完成**：多个朋友可能同时离开（$leaving$ 可以相同），`while` 循环一次性清空所有到期者，再取最小空椅。
6. **只模拟到目标到达即可**：目标入座后的事件（含它自己的离开）不影响答案，可直接返回，省掉一半事件。

## 5. 正确性证明

**引理 1（事件等价性）**：椅子占据状态只在「某人到达」或「某人离开」的时刻改变；因此按到达时刻排序、并在每个到达事件前统一释放所有 $leaving \le arrival$ 的人，与逐时刻模拟得到的状态完全一致。

**证明**：设当前处理到达时刻为 $a$ 的朋友，前一事件（到达或离开）之后状态为 $S$。逐时刻模拟中，时刻 $(prev, a)$ 内发生的变化只有离开事件（因到达时刻互不相同，区间内无到达）；其中 $leaving \le a$ 的离开全部在时刻 $a$ 之前（含 $a$）完成。算法在步骤 4a 中恰好把这些人的椅子全部释放，得到的状态与逐时刻模拟在时刻 $a$（先离开后到达的顺序）执行前的状态一致。归纳即得全程一致。∎

**引理 2（最小空椅）**：到达时 free 堆恰包含「曾发出且当前未被占据」的全部椅子，故 free 堆顶为最小空椅；若 free 为空，则所有已发出的椅子均被占据，最小空椅为从未发出的 $nextChair$。

**证明**：每把椅子离开 busy 堆的惟一途径是被释放并压入 free（步骤 4a），离开 free 的惟一途径是被某到达者取走（步骤 4b）并随即以 busy 状态入堆。归纳维护「busy ∪ free = 已发出椅子，且两者不相交」。因此 free 堆恰为全部空椅；小根堆顶即最小者。free 为空时已发出椅子全部占据，新椅 $nextChair$ 从未发出、必然空闲，且比它小的编号全部在场，故它是最小空椅。∎

**定理**：算法返回的椅子编号等于朋友 $targetFriend$ 在题意规则下占据的椅子编号。

**证明**：由引理 1，算法对每个到达事件前的状态与真实模拟一致；由引理 2，步骤 4b 取到的正是规则要求的「编号最小的未占据椅子」。到达时刻互不相同保证 `arrival == targetArr` 惟一标识 $targetFriend$ 的到达事件，算法在该事件处返回其所占椅子，即所求。∎

## 6. 复杂度分析

- **时间**：$O(n \log n)$。排序 $O(n \log n)$；随后每个朋友至多入堆出堆各一次，堆操作 $O(\log n)$，总计 $O(n \log n)$。$n = 10^4$ 时毫秒级。
- **空间**：$O(n)$。两个堆与下标数组，每个元素至多进出一次。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int smallestChair(vector<vector<int>>& times, int targetFriend) {
        int n = times.size();
        int targetArr = times[targetFriend][0];       // 到达时刻互不相同 → 锁定目标
        vector<int> idx(n);
        iota(idx.begin(), idx.end(), 0);
        sort(idx.begin(), idx.end(),
             [&](int a, int b) { return times[a][0] < times[b][0]; });

        priority_queue<int, vector<int>, greater<int>> freeChairs;   // 空椅：编号小根堆
        priority_queue<pair<int, int>, vector<pair<int, int>>,
                       greater<pair<int, int>>> busy;                // (leaving, chair)
        int nextChair = 0;                                           // 下一把全新椅子
        for (int id : idx) {
            int arr = times[id][0], lea = times[id][1];
            while (!busy.empty() && busy.top().first <= arr) {       // 离开 <= 到达 → 释放
                freeChairs.push(busy.top().second);
                busy.pop();
            }
            int chair;
            if (!freeChairs.empty()) {
                chair = freeChairs.top();
                freeChairs.pop();
            } else {
                chair = nextChair++;
            }
            if (arr == targetArr) return chair;
            busy.push({lea, chair});
        }
        return -1;
    }
};
```

### Python

```python
class Solution:
    def smallestChair(self, times: list[list[int]], targetFriend: int) -> int:
        target_arr = times[targetFriend][0]           # 到达时刻互不相同 → 锁定目标
        order = sorted(range(len(times)), key=lambda i: times[i][0])
        free_chairs: list[int] = []                   # 空椅：编号小根堆
        busy: list[tuple[int, int]] = []              # (leaving, chair) 小根堆
        next_chair = 0
        for i in order:
            arr, lea = times[i]
            while busy and busy[0][0] <= arr:         # 离开 <= 到达 → 释放
                _, chair = heapq.heappop(busy)
                heapq.heappush(free_chairs, chair)
            if free_chairs:
                chair = heapq.heappop(free_chairs)
            else:
                chair = next_chair
                next_chair += 1
            if arr == target_arr:
                return chair
            heapq.heappush(busy, (lea, chair))
        return -1
```

> 💡 两份代码均通过官方示例（`1`、`2`），并与「逐时刻模拟暴力」对拍 5000 组随机数据（含离开时刻 == 到达时刻的交接边界），`mismatch = 0`；另在 $n = 10^4$ 随机数据上做了 C++/Python 交叉验证。Python 版需 `import heapq`（LeetCode 环境已内置）。

## 8. 边界情况与易错点

1. **释放条件写成 $<$**：把 `busy.top().first <= arr` 写成 `<` 会在「离开时刻恰等于到达时刻」时漏释放，示例 1 的时刻 4（朋友 0 离开与朋友 2 到达同刻）就会出错。
2. **排序丢失身份**：若直接 `sort(times)` 再找 targetFriend，下标信息就没了；用到达时刻锁定或排序键携带原下标，二选一。
3. **busy 堆的键**：键必须是**离开时刻**而不是椅子编号——决定「谁先空出」的是离开时刻，编号只用于释放后归还。
4. **多把椅子同时释放**：`while` 而非 `if`；同一时刻可能有多人离开（$leaving$ 无互不相同约束）。
5. **targetFriend 第一个到达**：直接拿到椅子 0；不要假设目标总在后面。
6. **别忘了压回 busy**：目标之外的朋友入座后必须 `push` 进 busy，否则后续释放缺失、状态失真。
7. **无需真实无限椅子**：最多 $n$ 把椅子被使用，计数器即可，别开大数组或真去建「无限堆」。
