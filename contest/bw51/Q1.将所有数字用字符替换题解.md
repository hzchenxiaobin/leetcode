# LeetCode 将所有数字用字符替换 题解

## 1. 题目概述

- **标题 / 题号**：将所有数字用字符替换（#1844，easy）
- **链接**：https://leetcode.cn/problems/replace-all-digits-with-characters/
- **来源**：LeetCode 第 51 场双周赛 Q1
- **难度**：简单
- **标签**：字符串、模拟

**题意**：给定下标从 $0$ 开始的字符串 $s$，**偶数下标**处是小写英文字母，**奇数下标**处是数字。定义 $\mathit{shift}(c, x)$ 为字母表中 $c$ 后面第 $x$ 个字符（如 $\mathit{shift}(\text{'a'}, 5) = \text{'f'}$，$\mathit{shift}(\text{'x'}, 0) = \text{'x'}$）。要求把每个**奇数下标** $i$ 处的数字 $s[i]$ 替换为 $\mathit{shift}(s[i-1],\ s[i])$，返回全部替换后的字符串。题目保证替换结果不会超过 `'z'`。

**约束**：

- $1 \le s.length \le 100$
- $s$ 只包含小写英文字母和数字
- 对所有奇数下标 $i$，满足 $\mathit{shift}(s[i-1],\ s[i]) \le \text{'z'}$

## 2. 示例

**示例 1**

```text
输入：s = "a1c1e1"
输出："abcdef"
解释：s[1] → shift('a',1) = 'b'，s[3] → shift('c',1) = 'd'，s[5] → shift('e',1) = 'f'。
```

**示例 2**

```text
输入：s = "a1b2c3d4e"
输出："abbdcfdhe"
解释：s[1] → shift('a',1) = 'b'，s[3] → shift('b',2) = 'd'，
     s[5] → shift('c',3) = 'f'，s[7] → shift('d',4) = 'h'。
```

**示例 3（边界补充）**

```text
输入：s = "z0"
输出："zz"
解释：步数为 0 时 shift 原地不动，数字位被替换成与前一位相同的字母；长度为 1 的纯字母串则原样返回。
```

## 3. 解题思路

### 3.1 暴力思路

按定义"逐格走"：对每个奇数下标 $i$，从 $s[i-1]$ 出发在字母表上一步步数 $s[i]$ 格；或者建一个 `"abcdefghijklmnopqrstuvwxyz"` 字符串，先线性扫 26 个字母找到 $s[i-1]$ 的位置，再加上步数取出新字符。两种写法都是 $O(26n)$ 以内，$n \le 100$ 随便过。但这道签到题真正值得沉淀的是：**字母表移位根本不需要查表**——它就是一次字符码加法。

### 3.2 核心观察：shift 就是字符码加法

![shift 概念：在字母表条带上把 c 向后挪 x 格](images/bw51_q1_shift_concept.svg)

小写字母的 ASCII 字符码连续：`'a'` = 97，`'b'` = 98，……，`'z'` = 122，相邻字母字符码恰差 1。于是"字母表中 $c$ 后面第 $x$ 个字符"就是字符码直接相加：

$$\mathit{shift}(c, x) = \mathit{chr}\big(\mathit{ord}(c) + x\big)$$

数字字符 $s[i]$ 还原成整数步数只需减去 `'0'`（字符码 48），即 $x = s[i] - \text{'0'} \in [0, 9]$。整条替换公式压缩成一行：

$$s[i] \leftarrow s[i-1] + \big(s[i] - \text{'0'}\big)$$

### 3.3 算法流程

结构保证奇数下标与偶数下标交替出现，步长为 2 的一趟扫描即可，无需任何预处理：

```text
1. for i = 1, 3, 5, …, len(s)-1（步长 2，只访问奇数下标）
2.     s[i] ← s[i−1] + (s[i] − '0')
3. 返回 s
```

从左到右更新是安全的：奇数下标的替换只读取它**左侧紧邻的偶数下标**，而偶数下标永远不会被算法改写（见 §5）。

### 3.4 示例演算

![示例演算：a1b2c3d4e 逐对替换过程](images/bw51_q1_walkthrough.svg)

以 `"a1b2c3d4e"` 为例：每对「字母 + 数字」执行一次字符码加法——$97+1=98$（`'b'`）、$98+2=100$（`'d'`）、$99+3=102$（`'f'`）、$100+4=104$（`'h'`）；偶数位的 `a`、`b`、`c`、`d`、`e` 原样保留，拼出 `"abbdcfdhe"`。

## 4. 算法细节

1. **步数还原**：`s[i] - '0'` 把数字字符变成 $0 \sim 9$ 的整数。漏掉这步、直接把数字字符（字符码 $48 \sim 57$）加到字母上，会得到完全错误的字符。
2. **原地修改的安全性**：算法只写奇数下标、只读偶数下标，两者不相交，所以一趟扫完即可，不需要先拷贝一份原串。
3. **步长 2 自动对齐**：长度为偶数时最后一个下标是数字（会被替换），长度为奇数时最后一个是字母（跳过），都不需要特判。
4. **无需回绕**：题目保证 $\mathit{shift}$ 结果 $\le \text{'z'}$，因此不用做 `% 26`。若输入不满足该保证，加法会越出小写字母范围（产出字符码超过 122 的字符），但本题可以放心省略。
5. **Python 的字符串不可变**：先 `list(s)` 再改、最后 `"".join`，比反复切片拼接（每次 $O(n)$）更干净；$n \le 100$ 无所谓，但这是通用习惯。
6. **C++ 的有符号比较**：`s.size()` 是无符号数，`i < s.size()` 会把 `int` 提升为无符号，随手写 `(int)s.size()` 消除告警。

## 5. 正确性证明

**引理 1（字符码连续性）**：对小写字母 $c$ 与整数 $x$ 满足 $0 \le x \le \text{'z'} - \mathit{ord}(c)$，字符 $\mathit{chr}(\mathit{ord}(c) + x)$ 恰为字母表中 $c$ 后面第 $x$ 个小写字母。

**证明**：ASCII 码中小写字母连续排列，相邻字母字符码差 1。对 $x$ 归纳：$x = 0$ 时即 $c$ 本身；设结论对 $x$ 成立，则后第 $x+1$ 个字符是后第 $x$ 个字符的后一个字母，字符码再加 1，即 $\mathit{chr}(\mathit{ord}(c) + x + 1)$。∎

**定理**：算法返回的字符串 $t$ 与 $s$ 在所有偶数下标处相同，且每个奇数下标 $i$ 处 $t[i] = \mathit{shift}(s[i-1],\ s[i])$。

**证明**：算法只写奇数下标，故偶数下标处 $t$ 与 $s$ 相同。考察奇数下标 $i$ 被写入的时刻：它读取 $s[i-1]$，该下标为偶数、从未被写，故读到的是原始字母；写入值 $\mathit{chr}(\mathit{ord}(s[i-1]) + (s[i] - \text{'0'}))$，其中 $s[i] - \text{'0'}$ 是整数步数，由引理 1 它恰为 $\mathit{shift}(s[i-1],\ s[i])$。∎

## 6. 复杂度分析

- **时间**：$O(n)$。每个奇数下标做一次 $O(1)$ 的字符码加法，共约 $n/2$ 次；没有任何查找或排序。
- **空间**：C++ 原地修改，额外 $O(1)$；Python 因字符串不可变需 $O(n)$ 的字符列表。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    string replaceDigits(string s) {
        for (int i = 1; i < (int)s.size(); i += 2)   // 只扫奇数下标
            s[i] = char(s[i - 1] + (s[i] - '0'));    // 即 shift(s[i-1], s[i])
        return s;
    }
};
```

### Python

```python
class Solution:
    def replaceDigits(self, s: str) -> str:
        res = list(s)
        for i in range(1, len(res), 2):          # 只扫奇数下标
            res[i] = chr(ord(res[i - 1]) + int(res[i]))
        return "".join(res)
```

> 💡 两份代码均通过官方 2 组示例（`abcdef`、`abbdcfdhe`），另与「字母表查表 + 索引后移」的独立参考实现在 6000 组随机串上三方一致（题解 C++ / 题解 Python / 参考实现，含步数 0、步数 9、贴近 `'z'` 的极端字符）。

## 8. 边界情况与易错点

1. **长度为 1**：唯一下标 0 是字母，循环体不执行，原样返回——不要把"没有数字"当成非法输入。
2. **步数为 0**：如 `"a0"` → `"aa"`，`shift(c, 0) = c` 合法且必须照常替换，别当作"跳过"。
3. **忘减 `'0'`**：`s[i] + (int)` 形式的笔误会把数字字符码（48 起）直接加上去，是本题最常见的 WA 原因。
4. **别动偶数下标**：替换永远以"原始的左侧字母"为基准；本题结构下偶数位不被改写，天然安全。若题目变形为链式替换（替换结果继续参与下一个 shift），就必须先备份原串。
5. **溢出无虞但语义有边界**：加法最大到 `'z'`（122），`char` 完全装得下；真正要小心的是题目保证失效的场景——那时需要凯撒式回绕（见延伸思考）。
6. **循环边界**：`i += 2` 从 1 出发覆盖 $1, 3, 5, \dots$；写成 `i += 1` 会把偶数位也卷进来，对奇数位读取到的"字母"其实是数字，输出会错。
