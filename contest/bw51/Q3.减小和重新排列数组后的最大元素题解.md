# LeetCode 减小和重新排列数组后的最大元素 题解

## 1. 题目概述

- **标题 / 题号**：减小和重新排列数组后的最大元素（#1846，medium）
- **链接**：https://leetcode.cn/problems/maximum-element-after-decreasing-and-rearranging/
- **来源**：LeetCode 第 51 场双周赛 Q3
- **难度**：中等
- **标签**：贪心、数组、排序

**题意**：给定正整数数组 `arr`，允许执行任意多次两种操作：把任意元素**减小**为一个更小的正整数；任意**重排**数组。目标是使数组满足：第一个元素为 $1$；任意相邻两元素差的绝对值 $\le 1$。在所有满足条件的数组中，返回 `arr` 可能达到的**最大元素**。

**约束**：

- $1 \le arr.length \le 10^5$
- $1 \le arr[i] \le 10^9$

## 2. 示例

**示例 1**

```text
输入：arr = [2,2,1,2,1]
输出：2
解释：重排为 [1,2,2,2,1]，满足首元素为 1 且相邻差 ≤ 1，最大元素为 2。
```

**示例 2**

```text
输入：arr = [100,1,1000]
输出：3
解释：重排为 [1,100,1000]，再把第二个元素减为 2、第三个减为 3，得 [1,2,3]。
```

**示例 3**

```text
输入：arr = [1,2,3,4,5]
输出：5
解释：数组已满足条件，无需任何操作，最大元素为 5。
```

## 3. 解题思路

### 3.1 暴力思路

枚举 $n!$ 种排列，对每个排列求"该顺序下能达到的最大值"，再取全场最大——$n = 10^5$ 时天文数字，$n = 8$ 也已经 $40320$ 种。必须先找到"最优排列长什么样"的结构性结论，把排列维度整个消掉。

### 3.2 核心观察一：固定顺序下的两个天花板

![排序后逐位 min(cur+1, x)：台阶与天花板](images/bw51_q3_staircase_concept.svg)

对固定的排列，位置 $i$ 的最终值 $c[i]$ 同时被两个上界夹住：

- **只能减小**：$c[i] \le \mathit{arr}_i$（放在该位置的原值）；
- **相邻差限制**：$c[i] \le c[i-1] + 1$，且 $c[0] = 1$。

逐位取满两个上界的交（贪心）就得到"位置 $i$ 能达到的最大值"，即 $c[i] \le \min(c[i-1]+1,\ \mathit{arr}_i)$。巨值如 $1000$ 排在后面也会被"前值 + 1"削成 $3$。

### 3.3 核心观察二：存在升序的最优排列（交换论证）

![为什么升序排列最优：相邻逆序交换不会变差](images/bw51_q3_sort_why.svg)

直觉：小值放在前面"垫脚"，把"前值 + 1"的台阶一级级抬高；大值放在前面则先被 $c[0]=1$ 削平，还拖累了后面的上界。交换论证（§5 引理 1）证明：任何可行解的元素**重排成升序后仍然可行**，且最大值不变——于是最优解可以在升序排列中取到，排序 + 一趟贪心即为完整算法：

```text
1. 将 arr 升序排序，得 s
2. cur ← 0（哨兵：使 c[0] = min(0+1, s[0]) = 1）
3. 对每个 x = s[i]：cur ← min(cur + 1, x)
4. 返回 cur（cur 单调不减，末值即数组最大值）
```

### 3.4 示例演算

![三个官方示例的逐位演算](images/bw51_q3_walkthrough.svg)

三个官方示例逐位演算：$[2,2,1,2,1]$ 排序为 $[1,1,2,2,2]$，cur 走 $1 \to 1 \to 2 \to 2 \to 2$，返回 $2$；$[100,1,1000]$ 排序为 $[1,100,1000]$，cur 走 $1 \to 2 \to 3$（巨值被台阶削平），返回 $3$；$[1,2,3,4,5]$ 本身升序且相邻差恰为 1，cur 一路 $+1$ 到 $5$。

## 4. 算法细节

1. **哨兵 `cur = 0`**：把"首元素必须为 1"并入通项——$c[0] = \min(0+1,\ s[0]) = 1$（$s[0] \ge 1$），无需单独处理第一个位置。
2. **cur 单调不减**：排序后 $s[i-1] \le s[i]$，归纳可证 $c[i-1] \le s[i-1] \le s[i]$，故 $c[i] = \min(c[i-1]+1,\ s[i]) \ge c[i-1]$（§5 引理 3）。因此**最终的 cur 就是整个数组的最大值**——不排序时这一点不成立（如 $[1,100,1]$ 的 cur 序列为 $1,2,1$，最大值在中间）。
3. **答案的直观上界**：$c[i] \le i + 1$（从 1 出发每步至多 +1）且 $c[i] \le s[i]$，故答案 $\le \min(n,\ \max(\mathit{arr}))$；贪心恰好取到这个上界允许的最优值。
4. **无溢出**：cur $\le n \le 10^5$，全程 `int` 安全；排序比较 $10^9$ 也在 `int` 范围内。
5. **原地排序**：直接对入参 `arr` 排序即可，题目不要求保留原序。
6. **为什么"减小大数当垫脚石"没有收益**：贪心已让每个位置取到自身可达的最大值；把某个 $s[i]$ 主动降级只会让后续"前值 + 1"更小或不变，不可能抬高任何位置的上界。

## 5. 正确性证明

**引理 1（可行解可排序）**：设 $c$ 是满足条件的最终数组（$c[0]=1$、$|c[i]-c[i-1]| \le 1$、$c[i] \ge 1$），把其元素重排为升序数组 $c^{\uparrow}$，则 $c^{\uparrow}$ 也满足条件。

**证明**：$c$ 的元素都 $\ge 1$ 且 $c[0]=1$，故最小值为 1，$c^{\uparrow}[0]=1$。再证 $c$ 中出现的不同值之间不存在缺口 $\ge 2$：反设存在值 $v < w$ 均出现、且区间 $(v, w)$ 内无任何值，$w \ge v+2$。数组是一条连续序列，沿下标相邻差 $\le 1$；从某个取值 $\le v$ 的位置走到某个取值 $\ge w$ 的位置，值每次至多变化 1，由离散介值定理途中必取到 $v+1 \in (v, w)$，矛盾。因此升序排列中相邻两值之差 $\le 1$（相等则为 0），$c^{\uparrow}$ 满足条件。∎

**引理 2（多重集支配）**：若多重集 $C$ 由 $A$ 经"减小 + 重排"得到（存在双射把每个 $c \in C$ 配到某个 $a \in A$ 且 $c \le a$），则两者升序后逐点 $c^{\uparrow}[k] \le a^{\uparrow}[k]$。

**证明**：反设某 $k$ 有 $c^{\uparrow}[k] > a^{\uparrow}[k]$。考察 $c^{\uparrow}[k..n-1]$ 这 $n-k$ 个元素，每个都 $> a^{\uparrow}[k]$；它们各自的配对 $a \ge c > a^{\uparrow}[k]$，而 $A$ 中严格大于 $a^{\uparrow}[k]$ 的元素仅有 $a^{\uparrow}[k+1..n-1]$ 共 $n-k-1$ 个，双射下鸽笼矛盾。∎

**引理 3（升序贪心的逐点最优性）**：设 $s$ 为升序数组（$s[i] \ge 1$），定义 $b[0]=\min(1, s[0])=1$、$b[i]=\min(b[i-1]+1,\ s[i])$。则 (i) $b$ 满足条件且单调不减，其最大值为 $b[n-1]$；(ii) 任何满足条件且逐点 $\le s$ 的**升序**数组 $d$，都有 $d[i] \le b[i]$。

**证明**：(i) 归纳：$b[0]=1$；设 $b[i-1] \le s[i-1] \le s[i]$，则 $b[i]=\min(b[i-1]+1,\ s[i]) \ge b[i-1]$（当 $s[i] \ge b[i-1]$ 时右式两项均 $\ge b[i-1]$），且 $b[i] \ge 1$。故相邻差 $\in [0,1]$，条件满足、单调不减。(ii) 归纳：$d[0]=1=b[0]$；设 $d[i-1] \le b[i-1]$，则 $d[i] \le s[i]$ 且 $d[i] \le d[i-1]+1 \le b[i-1]+1$，故 $d[i] \le \min(b[i-1]+1,\ s[i]) = b[i]$。∎

**定理**：满足条件的最终数组的最大元素之最大值恰为 $b[n-1]$（升序贪心的末值）。

**证明**：**可达性**：$b$ 逐点 $\le s$ 且 $b[i] \ge 1$，把 $s$ 的第 $i$ 个元素减小到 $b[i]$ 即得到可行数组 $b$（由引理 3(i) 它满足条件），其最大值为 $b[n-1]$。**上界**：任取可行最终数组 $c$，由引理 1 其升序 $c^{\uparrow}$ 可行，由引理 2 逐点 $\le s$，由引理 3(ii) 逐点 $\le b$，于是 $\max c = \max c^{\uparrow} = c^{\uparrow}[n-1] \le b[n-1]$。两端夹逼，答案即 $b[n-1]$。∎

## 6. 复杂度分析

- **时间**：$O(n \log n)$，排序主导；一趟贪心 $O(n)$。$n = 10^5$ 时约 $10^6$ 量级操作。
- **空间**：$O(1)$ 额外（C++ 原地排序，`sort` 递归栈 $O(\log n)$；Python 的 `sort` 同为原地实现）。不计输入则额外空间可视为常数。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maximumElementAfterDecrementingAndRearranging(vector<int>& arr) {
        sort(arr.begin(), arr.end());            // 升序排列
        int cur = 0;                             // 前一个位置最终取得的值（哨兵 0）
        for (int x : arr) cur = min(cur + 1, x); // 受"值 x"与"前值+1"双重限制
        return cur;
    }
};
```

### Python

```python
class Solution:
    def maximumElementAfterDecrementingAndRearranging(self, arr: list[int]) -> int:
        arr.sort()                               # 升序排列
        cur = 0                                  # 前一个位置最终取得的值（哨兵 0）
        for x in arr:
            cur = min(cur + 1, x)                # 受"值 x"与"前值+1"双重限制
        return cur
```

> 💡 两份代码均通过官方 3 组示例；另与「枚举全部排列 + 区间 DP 求每个位置精确可达值」的暴力实现在 1800 组随机数组（$n \le 7$、含大量重复值）上对拍一致；$n = 10^5$、值域 $10^9$ 实测 C++ 约 140ms、Python 约 60ms。

## 8. 边界情况与易错点

1. **全部相同**：如 $[7,7,7,7]$，cur 走 $1 \to 2 \to 3 \to 4$，答案是 $n$ 而不是 $7$——"只能减小"决定了巨值帮不上忙，长度才是硬上界。
2. **长度 1**：$[5]$ 排序后 cur $= \min(1, 5) = 1$，答案是 $1$（首元素必须为 1）。
3. **忘记排序**：在原序上跑贪心会漏掉最大值——cur 序列可能先升后降（$[1,100,1] \to 1,2,1$），取末值就错了；本题贪心"末值即最大值"依赖排序后的单调性（§5 引理 3）。
4. **哨兵别写 1**：`cur = 1` 起步会让首位变成 $\min(2, s[0])$，当 $s[0] = 1$ 时输出 2，直接错。
5. **减小的方向别搞反**：只许减小不许增大，所以 $c[i] \le s[i]$ 是硬约束；若误写成 `cur = max(cur + 1, x)` 就变成"只增"的另一道题（见延伸思考的对偶题）。
6. **答案上界自查**：答案 $\le \min(n, \max(\mathit{arr}))$，对拍或构造极端用例时可用它快速 sanity check。
