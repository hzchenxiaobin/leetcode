# LeetCode 最近的房间 题解

## 1. 题目概述

- **标题 / 题号**：最近的房间（#1847，hard）
- **链接**：https://leetcode.cn/problems/closest-room/
- **来源**：LeetCode 第 51 场双周赛 Q4
- **难度**：困难
- **标签**：数组、二分查找、有序集合、排序

**题意**：酒店有 $n$ 个房间，`rooms[i] = [roomId_i, size_i]`，房间号互不相同。给定 $k$ 个查询 `queries[j] = [preferred_j, minSize_j]`：第 $j$ 个查询要找满足**面积至少为 `minSize_j`** 且**房间号与 `preferred_j` 的绝对值差最小**的房间 id；若差相等取**较小的 id**；不存在则返回 $-1$。返回长度为 $k$ 的答案数组。

**约束**：

- $n = \mathit{rooms.length}$，$1 \le n \le 10^5$
- $k = \mathit{queries.length}$，$1 \le k \le 10^4$
- $1 \le \mathit{roomId}_i,\ \mathit{preferred}_j \le 10^7$
- $1 \le \mathit{size}_i,\ \mathit{minSize}_j \le 10^7$
- 所有 $\mathit{roomId}_i$ 互不相同

## 2. 示例

**示例 1**

```text
输入：rooms = [[2,2],[1,2],[3,2]], queries = [[3,1],[3,3],[5,2]]
输出：[3,-1,3]
解释：查询 [3,1]：三个房间面积都 ≥ 1，id 最接近 3 的是 3 本身；
     查询 [3,3]：没有房间面积 ≥ 3，返回 -1；
     查询 [5,2]：候选 {1,2,3}，id=3 距离 2 最小。
```

**示例 2**

```text
输入：rooms = [[1,4],[2,3],[3,5],[4,1],[5,2]], queries = [[2,3],[2,4],[2,5]]
输出：[2,1,3]
解释：查询 [2,3]：候选 {1,2,3}，命中 2；查询 [2,4]：候选 {1,3}，
     前驱 1 与后继 3 距离同为 1，取较小的 1；查询 [2,5]：候选 {3}。
```

## 3. 解题思路

### 3.1 暴力思路

对每个查询线性扫全部房间，筛出面积达标的候选，再在候选里挑 $|\mathit{id} - \mathit{pref}|$ 最小（平局取小 id）的一个：$O(k \cdot n)$，最坏 $10^4 \times 10^5 = 10^9$，超时。瓶颈：每个查询都要重新"筛面积 + 找最近 id"，两件事都被重复做了 $k$ 遍。

### 3.2 核心观察一：离线交换——按 minSize 降序处理查询，房间只入库一次

![离线扫描：房间按面积降序入库，查询按 minSize 降序发问](images/bw51_q4_offline_sweep.svg)

每个查询的真实候选集只由一个阈值决定：$\{\,\mathit{roomId} : \mathit{size} \ge \mathit{minSize}\,\}$。**把查询按 `minSize` 从大到小重排**（离线，允许任意交换处理顺序），同时把房间按面积从大到小排序：处理某个查询时，所有面积 $\ge$ 其 `minSize` 的房间恰好都已"入库"。房间指针 $i$ 单调前进，每个房间至多入库一次——筛面积这一步就从"每查询 $O(n)$"摊还成"全程 $O(n)$"。

### 3.3 核心观察二：入库的 id 放进有序集合，前驱后继二分找最近

![有序集合中找最近 id：比较前驱与后继，平局取较小 id](images/bw51_q4_multiset_nearest.svg)

候选 id 集合随查询推进只增不减，需要支持"插入 + 查询某值的前驱后继"——**有序集合**（C++ `std::set`）正合适。对 `preferred` 做 `lower_bound`：命中点及其前一个元素是仅有的两个候选；比较 $|\mathit{id} - \mathit{pref}|$，平局取较小 id（前驱天然更小，用 $\le$ 覆盖后继即可）。

### 3.4 示例演算

![示例 2 演算：三个查询按 minSize 降序离线回答](images/bw51_q4_walkthrough.svg)

以示例 2 为例：房间按面积降序为 $(3,5), (1,4), (2,3), (5,2), (4,1)$；查询按 `minSize` 降序为 $[2,5], [2,4], [2,3]$。回答 $[2,5]$ 时入库 $(3,5)$，`ids = {3}`，答案 3；回答 $[2,4]$ 时再入 $(1,4)$，`ids = {1,3}`，前驱 1 与后继 3 距离均为 1，取 1；回答 $[2,3]$ 时再入 $(2,3)$，`ids = {1,2,3}`，命中 2。按原始查询顺序 $[2,3],[2,4],[2,5]$ 回填得 $[2,1,3]$。

## 4. 算法细节

1. **查询重排要记录原下标**：答案必须按原始顺序返回，排序前把 $0 \sim k-1$ 的下标放进 `order`，按 `minSize` 降序排序 `order`，答案写回 `ans[q]`。
2. **两个降序的一致性**：房间按面积降序、查询按 `minSize` 降序，扫描条件是 `rooms[i].size >= ms` 时入库——两个方向同为"从大到小"保证 `i` 不回退（换成 `<=` 的升序同样可行，只要两边同向）。
3. **前驱后继的取法**：`it = ids.lower_bound(pref)`；后继为 `*it`（`it != end()` 时），前驱为 `*prev(it)`（`it != begin()` 时）。**先判后继（严格 `<`），再判前驱（`<=`）**——平局时后写的前驱覆盖之，恰好实现"取较小 id"。
4. **集合为空即 -1**：`minSize` 大于所有房间面积时无候选；也可以在入库循环后用 `ids.empty()` 判断。
5. **Python 无 `std::set` 时的两条路**：LeetCode 环境有 `sortedcontainers.SortedList`（`bisect_left` + `add`，接口与 `set` 几乎一致）；若只用标准库，用**树状数组**（对离散化后的 id 做单点加 1，查"小于 pref 的已入库个数" $c$，则后继是第 $c+1$ 小、前驱是第 $c$ 小，都用 BIT 上二分求出），本文参考代码采用后者。
6. **复杂度记账**：排序 $O(n \log n + k \log k)$；入库 $n$ 次、查询 $k$ 次，各 $O(\log n)$；总 $O((n + k) \log n)$。

## 5. 正确性证明

**引理 1（候选集刻画）**：按 `minSize` 降序处理到查询 $q$ 时，有序集合 `ids` 恰等于 $\{\,\mathit{roomId} : \mathit{size} \ge \mathit{ms}_q\,\}$。

**证明**：房间按面积降序排列，入库循环把前缀中所有面积 $\ge \mathit{ms}_q$ 的房间插入。设房间降序序列中面积 $\ge \mathit{ms}_q$ 的最长前缀长为 $t$。对当前查询 $q$：此前的查询 $\mathit{ms}$ 均 $\ge \mathit{ms}_q$（降序），故此前指针已推进到某个 $i' \le t$ 的位置（每次只推进到当时阈值要求的边界，面积更大的房间一定更早被需要）；本次循环把 $i$ 从 $i'$ 推进到 $t$ 为止——恰好前 $t$ 个房间（即全部面积 $\ge \mathit{ms}_q$ 的房间）入库，且面积 $< \mathit{ms}_q$ 的房间（第 $t+1$ 个起）未被入库。∎

**引理 2（最近 id 的两候选性质）**：设有序集合 $S$ 非空，$p$ 为任意整数，$s^* = \min\{|\mathit{id} - p| : \mathit{id} \in S\}$（平局取最小 id）。记 $u = \min\{\mathit{id} \in S : \mathit{id} \ge p\}$（若存在），$l = \max\{\mathit{id} \in S : \mathit{id} < p\}$（若存在），则最优解必是 $u$ 或 $l$ 之一；且两者都存在、距离相等时答案为 $l$。

**证明**：任何 $\mathit{id} \ge p$ 的候选有 $|\mathit{id} - p| = \mathit{id} - p \ge u - p$，故 $\ge p$ 一侧的最优是 $u$；任何 $\mathit{id} < p$ 的候选有 $|\mathit{id} - p| = p - \mathit{id} \ge p - l$，故 $< p$ 一侧的最优是 $l$。全局最优在两者中取距离较小者。平局时 $l < p \le u$，较小 id 是 $l$。`lower_bound` 恰返回 $u$ 的位置（$S$ 中第一个 $\ge p$ 的元素），其前一个元素即 $l$。∎

**定理（离线算法正确性）**：对每个查询，算法返回 $\{\,\mathit{id} : \mathit{size} \ge \mathit{ms}\,\}$ 中与 $\mathit{pref}$ 距离最小（平局取小 id）的房间号，不存在时返回 $-1$。

**证明**：由引理 1，查询时的 `ids` 即该查询的真实候选集。集合为空时算法保持 $-1$，正确。集合非空时，算法用 `lower_bound` 取到 $u$ 与 $l$（由引理 2 二者至少存在其一，且最优解必在二者之中），按"后继严格更近才取后继，否则前驱以 $\le$ 覆盖"的次序比较，恰选出距离最小、平局取较小 id 的候选。查询按任意重排的顺序处理不影响单个查询的正确性，答案按 `order` 中记录的原下标回填，输出与输入查询一一对应。∎

## 6. 复杂度分析

- **时间**：$O(n \log n + k \log k + (n + k) \log n)$。房间排序 $O(n \log n)$、查询下标排序 $O(k \log k)$；入库 $n$ 次、每次 $O(\log n)$，查询 $k$ 次、每次前驱后继 $O(\log n)$（Python BIT 版同样 $O(\log n)$，常数略大）。代入 $n = 10^5$、$k = 10^4$ 约 $2 \times 10^6$ 量级。
- **空间**：$O(n + k)$。有序集合（或 BIT 与离散化数组）$O(n)$，查询下标与答案数组 $O(k)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> closestRoom(vector<vector<int>>& rooms, vector<vector<int>>& queries) {
        int n = rooms.size(), k = queries.size();
        sort(rooms.begin(), rooms.end(),
             [](const vector<int>& a, const vector<int>& b) { return a[1] > b[1]; });
        vector<int> order(k);                    // 查询按下标收集
        for (int t = 0; t < k; ++t) order[t] = t;
        sort(order.begin(), order.end(),
             [&](int a, int b) { return queries[a][1] > queries[b][1]; });

        vector<int> ans(k, -1);
        set<int> ids;                            // 当前候选房间的有序集合
        int i = 0;
        for (int q : order) {                    // minSize 降序逐个回答
            int pref = queries[q][0], ms = queries[q][1];
            while (i < n && rooms[i][1] >= ms) { // 面积达标的房间全部入库
                ids.insert(rooms[i][0]);
                ++i;
            }
            if (ids.empty()) continue;
            auto it = ids.lower_bound(pref);     // 第一个 >= pref 的 id
            int best = -1, bestAbs = INT_MAX;
            if (it != ids.end() && *it - pref < bestAbs) {
                best = *it;                      // 后继候选（较大 id）
                bestAbs = *it - pref;
            }
            if (it != ids.begin()) {
                --it;                            // 前驱候选（较小 id）
                if (pref - *it <= bestAbs) {     // 平局取较小 id：用 <= 覆盖后继
                    best = *it;
                    bestAbs = pref - *it;
                }
            }
            ans[q] = best;
        }
        return ans;
    }
};
```

### Python

```python
from bisect import bisect_left

class Solution:
    def closestRoom(self, rooms: list[list[int]], queries: list[list[int]]) -> list[int]:
        k = len(queries)
        order = sorted(range(k), key=lambda j: queries[j][1], reverse=True)
        rooms.sort(key=lambda r: r[1], reverse=True)

        ids = sorted(r[0] for r in rooms)         # 全部房间号离散化
        m = len(ids)
        tree = [0] * (m + 1)                      # 树状数组：记录每个 id 是否已入库

        def add(i, delta):                        # i 为 1 起始的位置
            while i <= m:
                tree[i] += delta
                i += i & (-i)

        def prefix(i):                            # 前 i 个位置已入库的 id 个数
            s = 0
            while i > 0:
                s += tree[i]
                i -= i & (-i)
            return s

        def kth(c):                               # 第 c 小的已入库 id（c >= 1）
            pos, pw = 0, 1 << (m.bit_length() - 1) if m else 0
            while pw:
                nxt = pos + pw
                if nxt <= m and tree[nxt] < c:
                    pos = nxt
                    c -= tree[nxt]
                pw >>= 1
            return ids[pos]                      # pos 恰为第 c 小者的 0 起始下标

        ans = [-1] * k
        n, i = len(rooms), 0
        for q in order:                           # minSize 降序逐个回答
            pref, ms = queries[q]
            while i < n and rooms[i][1] >= ms:    # 面积达标的房间全部入库
                add(bisect_left(ids, rooms[i][0]) + 1, 1)
                i += 1
            if i == 0:
                continue
            c = prefix(bisect_left(ids, pref))     # 已入库中小于 pref 的 id 个数
            best, bestAbs = -1, float('inf')
            if c < i:                             # 后继存在（>= pref 的最近 id）
                succ = kth(c + 1)
                best, bestAbs = succ, succ - pref
            if c >= 1:                            # 前驱存在（< pref 的最近 id）
                pred = kth(c)
                if pref - pred <= bestAbs:        # 平局取较小 id：用 <= 覆盖后继
                    best, bestAbs = pred, pref - pred
            ans[q] = best
        return ans
```

> 💡 两份代码均通过官方 2 组示例；另与「逐查询线性扫描全部房间」的暴力实现在 2500 组随机数据（$n \le 8$、$k \le 6$、含面积全不达标、平局、命中三种形态）上对拍一致；$n = 10^5$、$k = 10^4$ 满规模实测 C++ 约 270ms、Python（BIT 版）约 310ms。

## 8. 边界情况与易错点

1. **答案顺序**：查询被重排处理，务必用 `order` 记录原下标、写回 `ans[q]`；直接按排序后的顺序输出是最常见的 WA。
2. **平局规则**：距离相等取**较小 id**——比较次序必须是"后继严格 `<`、前驱 `<=`"，写成两个 `<` 会在平局时留下较大的后继。
3. **前驱后继的边界**：`it == end()` 时无后继（只能取前驱）；`it == begin()` 时无前驱（只能取后继）；两者判定独立，别用 `it - 1` 越界。
4. **候选集为空**：`minSize` 大于一切面积时返回 $-1$；在入库循环后用 `ids.empty()` / `i == 0` 提前跳过，避免对空集合做 `lower_bound` 后的前驱解引用。
5. **同向排序**：房间与查询必须**同向**排序（都降序或都升序），否则房间指针需要回退，双指针失效。
6. **BIT 版的细节**：离散化用**全部房间号**（而非查询的 preferred）——只有房间号会被插入；`kth` 的二分下降初值取 $\le m$ 的最大 2 的幂；`prefix(bisect_left(ids, pref))` 数的是严格小于 `pref` 的已入库 id。
7. **规模感**：$k$ 只有 $10^4$，但每个查询若在线重筛就是 $10^9$；离线交换后瓶颈回到排序，这正是本题作为困难题的核心考点。
