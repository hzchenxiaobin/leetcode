# LeetCode 皇后到达目标格子的最少移动步数 题解

## 1. 题目概述

- **标题 / 题号**：皇后到达目标格子的最少移动步数（#4061，easy）
- **链接**：https://leetcode.cn/problems/minimum-queen-moves-to-reach-target/
- **来源**：LeetCode 第 192 场双周赛 Q1
- **难度**：简单
- **标签**：数学、棋盘、找规律

**题意**：$8 \times 8$ 的空棋盘（行列下标从 $1$ 开始），一枚皇后从 `source` 出发，每步可沿**单条行、列或对角线**移动一个或多个方格（不能出界）。求**恰好**落在 `target` 的最少移动步数。

**约束**：

- `source.length == target.length == 2`
- $1 \le sr, sc, tr, tc \le 8$
- 本题**允许** `source == target`（示例 3），此时答案为 $0$

## 2. 示例

**示例 1**

```text
输入：source = [8,1], target = [1,8]
输出：1
解释：单次对角线移动即可让皇后直接从 (8,1) 到 (1,8)。
```

**示例 2**

```text
输入：source = [4,2], target = [1,3]
输出：2
解释：(4,2) → (4,3) → (1,3)，先沿行、再沿列，共 2 步。
```

**示例 3**

```text
输入：source = [1,1], target = [1,1]
输出：0
解释：皇后已处于目标位置，无需移动。
```

## 3. 解题思路

### 3.1 暴力思路

把 $64$ 个格子建图，每个格子向 $8$ 个方向的所有格子连边，从 `source` 做 BFS，复杂度 $O(64^2)$。对本题完全够用，但签到题的意义在于找到**从题面到代码的最短路径**：棋盘为空、无任何障碍，步数只由两格的相对位置决定，存在纯 $O(1)$ 判定。

### 3.2 核心观察：皇后 = 车 + 象，答案只能是 0 / 1 / 2

![皇后的一步版图与两步 L 形构造](images/bw192_q1_queen_lines.svg)

- **一步可达 ⟺ 共线**：目标与起点**同行**（$sr = tr$）、**同列**（$sc = tc$）或**同对角线**（$|sr - tr| = |sc - tc|$），一步直达。
- **两步上界（车式 L 形）**：皇后拥有车的全部走法，而车上任意两格至多两步——先沿行走到中转格 $(sr, tc)$，再沿列走到 $(tr, tc)$。中转格的行、列坐标分别取自起点与终点，**必然落在棋盘内**，无需任何特判。
- 因此答案 $\in \{0, 1, 2\}$：同格 $0$，共线 $1$，其余恰好 $2$。对角线走法只是把一部分「L 形两步」缩短为一步，不改变上界。

> 💡 与第 190 场双周赛 Q1 的**象版**对照：象只有对角线走法，存在颜色不变量，异色时返回 $-1$；皇后兼有车的走法，**任何格子都可达且至多两步**，不存在不可达情形。

### 3.3 判定流程

![判定流程：同格 → 共线 → 两步](images/bw192_q1_algorithm_flow.svg)

```text
1. 若 (sr,sc) == (tr,tc)                          → 0   （已在目标格）
2. 若 sr == tr 或 sc == tc 或 |sr−tr| == |sc−tc|    → 1   （共线，一步直达）
3. 否则                                             → 2   （车式 L 形两步）
```

**判定顺序不能换**：同格时 $|\Delta r| = |\Delta c| = 0$ 会命中对角线条件，必须先判同格，否则把 $0$ 误报成 $1$。

### 3.4 示例演算

![三个示例分别对应答案 1、2、0](images/bw192_q1_example_walkthrough.svg)

| 示例 | 起点 → 终点 | 判定 | 答案 |
|------|------------|------|------|
| 1 | (8,1) → (1,8) | $|8-1| = |1-8| = 7$，同对角线 | 1 |
| 2 | (4,2) → (1,3) | 不同行、不同列，$3 \ne 1$ 不同对角线 | 2 |
| 3 | (1,1) → (1,1) | 同格 | 0 |

三个官方示例恰好覆盖全部三类答案，没有多余情况。

## 4. 算法细节

1. **判定顺序**：同格 → 共线 → 其余返回 $2$。同格必须最先判（理由见 3.3）。
2. **共线三分支**：`sr == tr`（同行）、`sc == tc`（同列）、`abs(sr - tr) == abs(sc - tc)`（同对角线），三者取或，缺一不可——漏掉同行/同列就把皇后当成象了。
3. **两步构造无需实现**：中转格 $(sr, tc)$ 只用于证明上界，代码里直接返回 $2$。
4. **无越界风险**：中转格行坐标 $sr$ 与列坐标 $tc$ 都是合法输入，天然在 $[1,8] \times [1,8]$ 内。
5. **规模无关**：结论对任意 $n \times m$（$n, m \ge 1$）棋盘都成立，$8 \times 8$ 只是具体规模；若棋盘加入障碍物，则退化为 BFS 问题。

## 5. 正确性证明

**引理 1（一步刻画）**：皇后从 $A$ 一步到达 $B$ $\iff$ $A$、$B$ 同行或同列或同对角线。

**证明**：必要性：一步移动自始至终沿单条行、列或对角线行进，落点必在该线上。充分性：棋盘为空、无任何阻挡，行/列上的任意格可一步到达；对角线方向每前进一格行、列同时变化 $1$，故当且仅当 $|\Delta r| = |\Delta c|$ 时 $B$ 在 $A$ 的某条对角线上，可一步到达。∎

**引理 2（两步上界）**：任意两格 $S = (sr, sc)$、$T = (tr, tc)$ 至多两步可达。

**证明**：若同格，$0$ 步。若 $sr = tr$ 或 $sc = tc$，由引理 1 一步可达。否则取中转格 $M = (sr, tc)$：由 $1 \le sr, tc \le 8$ 知 $M$ 在棋盘内；由 $sc \ne tc$ 知 $S \to M$ 是非零的行移动，由 $sr \ne tr$ 知 $M \to T$ 是非零的列移动，两段均合法，两步可达。∎

**定理**：答案 $= 0$（同格）、$1$（共线）、$2$（其余），不存在其他取值。

**证明**：同格返回 $0$、共线返回 $1$ 分别是引理 1 的直接转写。其余情形不共线且不同格：由引理 1，一步不可达，排除 $0$ 和 $1$；由引理 2，两步可达。故恰好为 $2$。∎

**推论**：皇后在空棋盘上没有不可达的目标（对比象版的 $-1$）。∎

## 6. 复杂度分析

- **时间**：$O(1)$，仅常数次比较与一次绝对值运算。
- **空间**：$O(1)$，无额外数据结构。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minQueenMoves(vector<int>& source, vector<int>& target) {
        int sr = source[0], sc = source[1];
        int tr = target[0], tc = target[1];
        if (sr == tr && sc == tc) return 0;
        if (sr == tr || sc == tc || abs(sr - tr) == abs(sc - tc)) return 1;
        return 2;
    }
};
```

### Python

```python
class Solution:
    def minQueenMoves(self, source: list[int], target: list[int]) -> int:
        sr, sc = source
        tr, tc = target
        if (sr, sc) == (tr, tc):
            return 0
        if sr == tr or sc == tc or abs(sr - tr) == abs(sc - tc):
            return 1
        return 2
```

## 8. 边界情况与易错点

1. **`source == target` 必须先判**：本题允许同格（示例 3），若先判共线，$|\Delta r| = |\Delta c| = 0$ 成立会误返回 $1$。这是与 190 场象版（保证 `source != target`）最大的题面差异，也是本题唯一的 WA 点。
2. **别把皇后当象**：同行、同列同样一步直达，共线三分支缺一不可。
3. **对角线判定加绝对值**：`abs(sr - tr) == abs(sc - tc)`，直接写差值相等会漏掉副对角线方向。
4. **不存在 $-1$**：皇后兼有车的走法，任何目标至多两步，不要从象版迁移「异色返回 $-1$」的逻辑。
5. **别被 $8 \times 8$ 诱导写 BFS**：$O(64^2)$ 也能过，但签到题应沉淀 $O(1)$ 判定的最短路径。
6. **每步可走任意格**：不能按「一次走一格」数步数。
