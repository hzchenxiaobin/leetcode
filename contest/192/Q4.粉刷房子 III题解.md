# LeetCode 粉刷房子 III 题解

## 1. 题目概述

- **标题 / 题号**：粉刷房子 III（#1473，hard）
- **链接**：https://leetcode.cn/problems/paint-house-iii/
- **来源**：LeetCode 第 192 场周赛 Q4
- **难度**：困难
- **标签**：数组，动态规划

**题意**：$m$ 栋房子排成一排，用 $1..n$ 种颜色涂。`houses[i] = 0` 表示未涂，可任选颜色并支付 `cost[i][j-1]`；非 $0$ 表示已经涂成该色且**不允许重刷**（花费 $0$）。求总花费最小的涂法，使全部涂完后**恰好**分成 `target` 个街区。街区是「极大的连续同色段」，也就是说房子的颜色序列里出现几次颜色变化，就切出几段。无解返回 $-1$。

**约束**：

- $m = \lvert houses \rvert = \lvert cost \rvert$，$1 \le m \le 100$
- $n = \lvert cost[i] \rvert$，$1 \le n \le 20$
- $1 \le target \le m$
- $0 \le houses[i] \le n$
- $1 \le cost[i][j] \le 10^4$

## 3. 解题思路

### 3.1 暴力思路

对每栋未刷漆的房子枚举 $1..n$ 种颜色，共 $n^{z}$ 种方案（$z$ 为未刷漆房子数），每个方案再花 $O(m)$ 统计街区数与花费，总代价 $O(n^{z} \cdot m)$。当 $m = 100$、$n = 2$ 时是 $2^{100}$ 量级，完全不可行。

暴力的浪费在于：前缀中绝大多数细节对后续决策没有影响，真正决定未来的只有两件事——**最后一栋是什么颜色**、**已经形成了多少个街区**。把这两件事抽出来就能做成 DP。

### 3.2 核心观察：把「街区数」变成状态维度

![三维 DP 状态设计与两条转移分支](images/wc192_q4_state_design.svg)

关键的事实是街区数的**局部性**：

$$\text{街区数} = 1 + \#\{i \ge 2 : \text{color}[i] \ne \text{color}[i-1]\}$$

也就是说，一栋新房子对街区数的贡献只有两种：与前一栋**同色**（街区数不变）或**异色**（街区数 $+1$），而第一栋固定贡献 1。于是历史信息可以被压缩成两个量：前一栋的颜色、已形成的街区数。

由此定义三维状态：

$$dp[i][j][k] = \text{前 } i \text{ 栋房子均已涂完、第 } i \text{ 栋颜色为 } j \text{、恰好 } k \text{ 个街区的最小花费}$$

**为什么不能省掉 $k$ 这一维？** 因为花费与街区数是两个独立方向，会互相拉扯。比如 `houses=[0,0]`、`cost=[[1,100],[1,100]]`、`target=2`：最省钱的是 $[1,1]$（花费 $2$，但只有 $1$ 个街区），合法方案却只能是 $[1,2]$ 或 $[2,1]$（花费 $101$）。若只记录「每种末位颜色的最小花费」，花 $2$ 的方案会顶掉花 $101$ 的合法方案，答案就错了。

### 3.3 算法流程 / 状态转移

![推进顺序与滚动数组](images/wc192_q4_transition_flow.svg)

按房子顺序推进。处理第 $i$ 栋（$1$ 起编号）时，枚举它被涂成的颜色 $j$：

- 若 `houses[i-1]` 非 $0$，则 $j$ 只能是它，$paint(i,j) = 0$；
- 若 `houses[i-1] = 0`，则 $j$ 取遍 $1..n$，$paint(i,j) = cost[i-1][j-1]$。

转移只有两条路：

$$dp[i][j][k] = paint(i,j) + \min\Bigl(\underbrace{dp[i-1][j][k]}_{\text{同色：街区数不变}},\ \underbrace{\min_{j' \ne j} dp[i-1][j'][k-1]}_{\text{换色：街区数} + 1}\Bigr)$$

**初始化**：$dp[0][0][0] = 0$，其余为 $+\infty$。颜色 $0$ 是「空前缀」哨兵，专门让第一栋房子走「换色」分支、从而拿到 $k = 1$。

**答案**：$\min_j dp[m][j][target]$；若仍为 $+\infty$ 则无合法方案，返回 $-1$。

**滚动数组**：每层只依赖上一层，把 $i$ 维压掉，空间降到 $O(target \cdot n)$。

**可选加速**：固定 $k$，换色分支要取「除 $j$ 外所有颜色」的最小值。预先算出 $dp[i-1][\cdot][k-1]$ 的最小值 `min1`、次小值 `min2` 及其颜色 `arg1`，则 $j \ne arg1$ 时取 `min1`、否则取 `min2`，$O(1)$ 完成，总复杂度从 $O(m \cdot target \cdot n^2)$ 降到 $O(m \cdot target \cdot n)$。本题数据下 $4 \times 10^6$ 次转移已经足够快，参考代码保留朴素写法以保证可读性。

| $i$ | $j=1,k=1$ | $j=1,k=2$ | $j=1,k=3$ | $j=2,k=1$ | $j=2,k=2$ | $j=2,k=3$ |
|----|----|----|----|----|----|----|
| 1 | 1 | ∞ | ∞ | 10 | ∞ | ∞ |

| 5 | 27 | 18 | **9** | 23 | 14 | 14 |

挑几个格子核对：

- $dp[2][2][2] = 2$：方案 $[1,2]$，花费 $1 + 1 = 2$，两个街区，来自换色分支 $dp[1][1][1] + cost[1][1] = 1 + 1$。
- $dp[3][1][3] = 12$：方案 $[1,2,1]$，花费 $1 + 1 + 10 = 12$。
- $dp[5][1][3] = 9$：方案 $[1,2,2,1,1]$，花费 $1 + 1 + 1 + 1 + 5 = 9$，与官方答案一致。
- 终局 $\min(dp[5][1][3], dp[5][2][3]) = \min(9, 14) = 9$。

## 4. 算法细节

1. **哨兵颜色 0**：只允许在 $dp[0][0][0] = 0$ 这一处出现。第一栋房子通过换色分支 $dp[0][0][0] \to dp[1][j][1]$ 起步，从而天然获得 1 个街区。
2. **哨兵必须随滚动失效**：滚到第 2 层后 $dp[1][0][0]$ 必须变回 $+\infty$。实现上每层 `cur` 全填 $+\infty$、只写 $c \ge 1$ 的格子就自动满足；若图省事让 `prev[0][0]` 一直是 0，$k = 1$ 的行会凭空多出一个来源，街区数被系统性少算。
3. **已刷漆房子锁定颜色**：只枚举 `houses[i]` 这一种颜色、花费记 0，其余颜色直接跳过，不要用「极大花费允许改色」来绕。
4. **区间剪枝**：前 $i$ 栋最多 $i$ 个街区（$k \le i$），且第 $i$ 栋之后最多再新增 $m - i$ 个街区（$k \ge target - (m - i)$）。两条剪枝在 $target$ 接近 $m$ 时能省掉大量无效状态。
5. **无穷大的取值**：合法总花费不超过 $m \times 10^4 = 10^6$，取 $10^{18}$ 或 $10^9$ 都安全；C++ 必须用 `long long`，否则 $+\infty + paint$ 会溢出 `int`。判定无解用 $ans \ge INF$，不要让 $+\infty$ 参与答案比较。
6. **答案要扫全部颜色**：最后一栋的颜色没有「唯一正确值」，答案取 $\min_j dp[m][j][target]$，不能只取某个颜色对应的格子。
7. **内层循环顺序无关**：转移只读上一层的 `prev`，所以 $j$、$k$ 谁在外层都不影响正确性；若要做 top-2 优化，把 $k$ 放外层、$j$ 放内层更顺手。
8. **top-2 与哨兵**：候选旧颜色集合是 $0..n$（含哨兵），哨兵只在 $k-1 = 0$ 时有意义。若先把「空前缀」单独处理后让候选集合变成 $1..n$，注意 $n = 1$ 时「除 $j$ 外的颜色」是空集，换色分支应视为 $+\infty$；朴素写法把哨兵一起枚举，天然避开了这个坑。

## 5. 正确性证明

**引理 1（街区的局部性）**：对任意颜色序列 $c[1..m]$（$m \ge 1$），街区数等于 $1 + \#\{i \ge 2 : c[i] \ne c[i-1]\}$。

**证明**：把所有满足 $c[i] \ne c[i-1]$ 的位置 $i$ 作为切点，相邻切点之间的房子颜色相同、且与两侧颜色不同，因此恰好被切成极大同色段；切点有 $\#\{i \ge 2 : c[i] \ne c[i-1]\}$ 个，段数即切点数 $+1$，每段正是一个街区。∎

**引理 2（转移划分不重不漏）**：固定第 $i$ 栋的颜色 $j$，则「前 $i$ 栋合法、末位颜色 $j$、恰 $k$ 个街区」的方案，按「$c[i]$ 与 $c[i-1]$ 是否同色」被唯一划分为两类，分别对应转移的两条分支，且两类都只需在原有花费上再加上 $paint(i,j)$。

**证明**：设该方案去掉第 $i$ 栋得到前 $i-1$ 栋的方案 $T'$，其末位颜色为 $j'$、街区数为 $k'$。

- 若 $c[i] = c[i-1]$：$j' = j$，第 $i$ 栋不产生新的颜色变化，由引理 1 得 $k' = k$。
- 若 $c[i] \ne c[i-1]$：$j' \ne j$，第 $i$ 栋处新增一次颜色变化，由引理 1 得 $k' = k - 1$。

两种情形互斥，且覆盖了 $c[i-1]$ 存在的全部可能；第 $i = 1$ 栋没有前一栋，约定 $c[0]$ 为哨兵颜色 $0 \ne j$，于是必然走换色分支、$k = 1$，与初始化一致。两类都只是把第 $i$ 栋接在 $T'$ 后面，花费增加 $paint(i,j)$。∎

**引理 3（颜色锁定不产生非法方案）**：当 `houses[i] ≠ 0` 时，转移只保留 $j = houses[i]$ 且 $paint = 0$，因此所枚举的方案恰好满足「已刷漆的房子不重刷」。

**证明**：这类房子被题面禁止重刷，故 $c[i]$ 被迫等于 `houses[i]`；代码对其余颜色直接跳过，不写入任何状态，因此这些颜色不会出现在任何被最小化的方案里，也不会被计入 `ans`。∎

**定理**：算法返回值等于全体合法涂色方案的最小总花费；不存在合法方案时返回 $-1$。

**证明**：对 $i$ 归纳证明 $dp[i][j][k]$ 等于「前 $i$ 栋合法、末位颜色 $j$、恰 $k$ 个街区」方案集合 $S_i(j,k)$ 上的最小花费（$S_i(j,k) = \varnothing$ 时为 $+\infty$）。$i = 0$ 时只有空方案，$dp[0][0][0] = 0$ 与之对应，其余 $S_0$ 为空，成立。设 $i-1$ 成立，由引理 2，$S_i(j,k)$ 的方案与「$S_{i-1}(j,k)$ 接同色 $j$」以及「$\bigcup_{j' \ne j} S_{i-1}(j',k-1)$ 接异色 $j$」两族方案一一对应，且每一步的花费增量都是 $paint(i,j)$；因此对两族分别取最小再加 $paint(i,j)$，正是两条转移分支的最小值，转移方程给出的就是 $S_i(j,k)$ 上的最小花费。归纳成立。最后，任一合法完整方案都属于某个 $S_m(j, target)$，故 $\min_j dp[m][j][target]$ 是全体合法方案的最小花费；若全部为 $+\infty$，则所有 $S_m(\cdot, target)$ 为空，确实无解，返回 $-1$ 符合题意。∎

## 6. 复杂度分析

- **时间**：$O(m \cdot target \cdot n^2)$。状态数 $m \cdot target \cdot n$，每个状态枚举 $n+1$ 个旧颜色（含哨兵）取最小值；$m = 100$、$target \le 100$、$n = 20$ 时约 $4.2 \times 10^6$ 次比较，实测 Python 约 $0.2$ 秒。用 top-2 预存最值可降到 $O(m \cdot target \cdot n)$。
- **空间**：$O(target \cdot n)$，只保留上一层（最多 $101 \times 21$ 个 `long long`）；若保留全部层则退化为 $O(m \cdot target \cdot n)$。

## 7. 参考代码

### C++

```cpp
#include <algorithm>
#include <vector>
using namespace std;

class Solution {
public:
    int minCost(vector<int>& houses, vector<vector<int>>& cost, int m, int n, int target) {
        const long long INF = (long long)4e18;
        // prev[c][k]：前 i 栋已涂完、第 i 栋颜色为 c、恰好 k 个街区的最小花费
        // c = 0 是「空前缀」哨兵，只有 prev[0][0] = 0 有效
        vector<vector<long long>> prev(n + 1, vector<long long>(target + 1, INF));
        prev[0][0] = 0;
        for (int i = 0; i < m; ++i) {
            // 每层 cur 全填 INF，只写 c >= 1 的格子，哨兵自动失效
            vector<vector<long long>> cur(n + 1, vector<long long>(target + 1, INF));
            for (int c = 1; c <= n; ++c) {
                if (houses[i] != 0 && houses[i] != c) continue;   // 已刷漆：颜色锁定
                long long add = houses[i] ? 0 : cost[i][c - 1];
                for (int k = 1; k <= target; ++k) {
                    long long best = prev[c][k];                  // 同色：街区数不变
                    for (int j = 0; j <= n; ++j)                  // 换色：街区数 +1
                        if (j != c) best = min(best, prev[j][k - 1]);
                    if (best < INF) cur[c][k] = best + add;
                }
            }
            prev.swap(cur);
        }
        long long ans = INF;
        for (int c = 1; c <= n; ++c) ans = min(ans, prev[c][target]);
        return ans >= INF ? -1 : (int)ans;
    }
};
```

### Python

```python
from typing import List


class Solution:
    def minCost(self, houses: List[int], cost: List[List[int]], m: int, n: int, target: int) -> int:
        INF = 10 ** 18
        # prev[c][k]：前 i 栋已涂完、第 i 栋颜色为 c、恰好 k 个街区的最小花费
        # c = 0 是「空前缀」哨兵，只有 prev[0][0] = 0 有效
        prev = [[INF] * (target + 1) for _ in range(n + 1)]
        prev[0][0] = 0
        for i in range(m):
            # 每层 cur 全填 INF，只写 c >= 1 的格子，哨兵自动失效
            cur = [[INF] * (target + 1) for _ in range(n + 1)]
            colors = (houses[i],) if houses[i] else range(1, n + 1)
            for c in colors:
                add = 0 if houses[i] else cost[i][c - 1]
                for k in range(1, target + 1):
                    best = prev[c][k]                     # 同色：街区数不变
                    for j in range(n + 1):
                        if j != c and prev[j][k - 1] < best:
                            best = prev[j][k - 1]         # 换色：街区数 +1
                    if best < INF:
                        cur[c][k] = best + add
            prev = cur
        ans = min(prev[c][target] for c in range(1, n + 1))
        return -1 if ans >= INF else ans
```

## 8. 边界情况与易错点

1. **全部已刷漆**：此时没有决策空间，直接按引理 1 统计街区数即可：等于 `target` 返回 $0$，否则返回 $-1$（示例 4）。不要因为「没有可涂的房子」就无脑返回 $-1$。
2. **`target = m`**：必须两两异色，于是 $n = 1$ 且 $m \ge 2$ 时必然无解；$n \ge m$ 时答案才可能为正。
3. **`m = 1`**：只有 $1$ 个街区，`target` 只能是 $1$；已刷漆时答案为 $0$，未刷漆时答案为 $\min_j cost[0][j-1]$——注意要取所有颜色的最小值，而不是只看颜色 $1$。
4. **无解判定**：用 $ans \ge INF$（或 $\ge INF/2$）。合法花费上限只有 $10^6$，绝不会与 $10^{18}$ 混淆，但若用 `INT_MAX` 直接相加就会溢出，判等也会失效。
5. **哨兵残留**：见 §4 第 2 条。这个 bug 不会崩溃、不会越界，只会静默少算街区数，属于本题最难自查的错误。
6. **`k - 1` 越界**：$k$ 必须从 $1$ 开始枚举，`prev[j][k - 1]` 的下标最小为 $0$；写 `k` 从 $0$ 开始的双层循环会访问 `prev[j][-1]`。
7. **Python 的 `float('inf')`**：`inf + 7` 仍是 `inf` 看似可用，但与整数混用后比较、类型都不稳定；统一用整数 $10^{18}$ 表示不可达更稳妥。
8. **「恰好」而不是「至多」**：题目要求恰好 `target` 个街区。示例 3 那组 `cost` 交替、`target = 5`（`m = 5`）的用例，答案 $5$ 要求逐栋换色取便宜色；如果误按「街区数 ≤ target」做，会得到更小的非法答案。
