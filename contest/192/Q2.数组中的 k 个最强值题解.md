# LeetCode 数组中的 k 个最强值 题解

## 1. 题目概述

- **标题 / 题号**：数组中的 k 个最强值（#1471，medium）
- **链接**：https://leetcode.cn/problems/the-k-strongest-values-in-an-array/
- **来源**：LeetCode 第 192 场周赛 Q2
- **难度**：中等
- **标签**：数组、双指针、排序

**题意**：给定长度为 $n$ 的整数数组 `arr` 和整数 $k$。先把数组升序排序，取下标 $\lfloor (n-1)/2 \rfloor$ 处的元素作为中位数 $m$，然后定义「强」的偏序：$x$ 比 $y$ 强，当且仅当

$$|x - m| > |y - m| \quad \text{或} \quad \bigl(|x - m| = |y - m| \ \text{且}\ x > y\bigr)$$

要求返回数组中最强的 $k$ 个元素组成的列表，**顺序任意**。

**约束**：

- $1 \le n \le 10^5$
- $-10^5 \le arr[i] \le 10^5$
- $1 \le k \le n$

注意中位数取的是**下中位数**：排序后下标 $(n-1)/2$（整除），而不是 $n/2$。当 $n$ 为偶数时两者相差一格，会直接改变答案。

## 2. 示例

**示例 1**

```text
输入：arr = [1,2,3,4,5]，k = 2
输出：[5,1]（[1,5] 也正确）
解释：中位数 m = 3；按强度降序为 [5,1,4,2,3]；
      虽然 |5-3| = |1-3|，但 5 > 1，所以 5 比 1 更强。
```

**示例 2**

```text
输入：arr = [1,1,3,5,5]，k = 2
输出：[5,5]
解释：中位数 m = 3；强度顺序为 [5,5,1,1,3]，最强两个都是 5。
```

**示例 3**

```text
输入：arr = [6,7,11,7,6,8]，k = 5
输出：[11,8,6,6,7]（任意排列都正确）
解释：排序后 [6,6,7,7,8,11]，中位数 m = a[2] = 7；
      距离依次为 1,1,0,0,1,4，强度顺序为 [11,8,6,6,7,7]，
      取前 5 个即 [11,8,6,6,7]。
```

## 3. 解题思路

### 3.1 暴力思路

最直白的做法是模拟「每轮挑最强」：每一轮扫描剩余元素、算出 $|a[i]-m|$ 并维护最强下标，挑走 $k$ 次。时间复杂度 $O(nk)$，$n = k = 10^5$ 时是 $10^{10}$ 次比较，必然超时。

第二条朴素路线是按定义写自定义比较器，对整个数组排序后切前 $k$ 个：$O(n \log n)$ 可以过，但比较器里要反复求绝对值、且全排序为「只要前 $k$ 个」付出了多余代价。官方提示给的正是这条路线，而本题还有一个更清爽的结构性做法。

### 3.2 核心观察：有序后「距离」是单谷函数

![中位数两侧距离单调，最强值必在窗口两端](images/wc192_q2_median_two_pointer.svg)

记排序后的数组为 $a$，中位数下标 $p = (n-1)/2$，$m = a[p]$。

- **左段**（$i \le p$）：有 $a[i] \le m$，于是 $|a[i]-m| = m - a[i]$，随 $i$ 增大**单调不增**；越靠左离 $m$ 越远。
- **右段**（$i \ge p$）：有 $a[i] \ge m$，于是 $|a[i]-m| = a[i] - m$，随 $i$ 增大**单调不减**；越靠右离 $m$ 越远。

也就是说，距离沿着数组先从大到小（走到 $m$）、再从小到大，是一个**单谷**序列。

由此得到关键结论：**在任何一个连续窗口 $a[l..r]$ 中，最强元素只可能是 $a[l]$ 或 $a[r]$**。因为窗口内任意元素都夹在两个端点之间，它要么落在左段、被 $a[l]$ 支配，要么落在右段、被 $a[r]$ 支配（严格证明见 §5 引理 3）。

于是「每轮挑最强」退化为「每轮比较两个端点」，$O(1)$ 决定，总共 $O(k)$。

**等距的破平规则恰好和有序性对齐**：若 $|a[r]-m| = |a[l]-m|$，由于 $a[r] \ge a[l]$，更强的是 $a[r]$。因此两种情形可以合并成一个不等式：

$$|a[r] - m| \ge |a[l] - m| \implies \text{本轮取 } a[r]$$

### 3.3 算法流程

![排序后双指针左右夹取的流程图](images/wc192_q2_greedy_flow.svg)

1. 把 `arr` 升序排序，记为 $a$；
2. 取 $p = (n-1)/2$、$m = a[p]$，令 $l = 0$、$r = n-1$，结果列表 `res` 为空；
3. 重复 $k$ 轮：若 $|a[r]-m| \ge |a[l]-m|$，把 $a[r]$ 追加进 `res` 并令 $r \gets r-1$；否则把 $a[l]$ 追加进 `res` 并令 $l \gets l+1$；
4. 返回 `res`。

每轮只从窗口的**某一端**取走一个元素，所以剩余候选始终是连续子数组 $a[l..r]$，「最强值在端点」这一前提在每一轮都成立，可以直接归纳下去。

### 3.4 示例演算

![示例 3 的双指针逐轮走查表](images/wc192_q2_walkthrough.svg)

对 `arr = [6,7,11,7,6,8]`、$k = 5$：排序得 $a = [6,6,7,7,8,11]$，$p = 2$，$m = 7$。

| 轮次 | $l$ | $a[l]$ | $d_l$ | $r$ | $a[r]$ | $d_r$ | 判定 | 结果 |
|------|-----|--------|-------|-----|--------|-------|------|------|
| 1 | 0 | 6 | 1 | 5 | 11 | 4 | $4 > 1$，取右 | [11] |
| 2 | 0 | 6 | 1 | 4 | 8 | 1 | 等距取大，取右 | [11,8] |
| 3 | 0 | 6 | 1 | 3 | 7 | 0 | $1 > 0$，取左 | [11,8,6] |
| 4 | 1 | 6 | 1 | 3 | 7 | 0 | $1 > 0$，取左 | [11,8,6,6] |
| 5 | 2 | 7 | 0 | 3 | 7 | 0 | 等距且同值，取右 | [11,8,6,6,7] |

## 4. 算法细节

1. **中位数下标**：$p = (n-1)/2$ 才是题面定义的「中间位置」，对应下中位数；写成 $n/2$ 在 $n$ 为偶数时取到的是上中位数，答案会错（见 §8 第 2 条的反例）。
2. **判定方向**：比较必须带等号，写成 $|a[r]-m| \ge |a[l]-m|$ 就同时处理了「距离更大」与「等距取较大值」两种情形，不需要额外分支。若写成严格大于，等距时会误取左端的小值。
3. **原地双指针**：排序后直接在同一数组上用 $l, r$ 两个下标收缩，不需要复制窗口、也不需要堆；`res` 只存答案，$k$ 个元素。
4. **整数范围**：$|arr[i]| \le 10^5$，$|m| \le 10^5$，差的绝对值不超过 $2 \times 10^5$，`int` 完全放得下；但 C++ 里写成 `llabs((long long)arr[l] - m)` 更保险，也避免误用 `abs(int)` 在极端模板下的重载歧义。
5. **循环次数与指针安全**：因为 $k \le n$，每轮弹出一个元素，循环恰好执行 $k$ 次，$l \le r$ 始终成立；当 $l = r$ 时两端是同一个元素，取谁都一样，随后指针交错、循环也必然结束。
6. **输出顺序**：题面明确「答案可以以任意顺序返回」，所以不必再为降序多排一次；本地对拍时也不能按位置逐项比较，要按多重集比较。
7. **与自定义排序的等价性**：把整个数组按 $(-|x-m|, -x)$ 字典序升序排序、取前 $k$ 个，与本算法得到的多重集完全相同。区别只在于本算法把「排序」只花在数值大小上（一次普通 `sort`），把「强度」交给 $O(1)$ 的端点比较，省掉了 $O(n)$ 次带闭包的比较器调用。

## 5. 正确性证明

**引理 1（左段距离单调）**：对任意 $i < j \le p$，有 $|a[i]-m| \ge |a[j]-m|$。

**证明**：由 $i < j \le p$ 及数组有序得 $a[i] \le a[j] \le a[p] = m$，故 $|a[i]-m| = m - a[i] \ge m - a[j] = |a[j]-m|$。∎

**引理 2（右段距离单调）**：对任意 $p \le i < j$，有 $|a[j]-m| \ge |a[i]-m|$。

**证明**：由 $p \le i < j$ 及数组有序得 $m = a[p] \le a[i] \le a[j]$，故 $|a[j]-m| = a[j]-m \ge a[i]-m = |a[i]-m|$。∎

**引理 3（窗口最强值在端点）**：设剩余候选为连续窗口 $a[l..r]$，则其中不存在严格强于 $a[l]$ 且严格强于 $a[r]$ 的元素；即最强元素必属于 $\{a[l], a[r]\}$。

**证明**：任取 $l \le t \le r$。若 $t \le p$，由引理 1（取 $i = l$、$j = t$，注意 $l \le t \le p$）得 $|a[l]-m| \ge |a[t]-m|$：距离更大时 $a[l]$ 严格更强，距离相等时 $m - a[l] = m - a[t]$ 推出 $a[l] = a[t]$，两者一样强，故 $a[t]$ 不严格强于 $a[l]$。若 $t > p$，由引理 2（取 $i = t$、$j = r$）得 $|a[r]-m| \ge |a[t]-m|$：距离更大时 $a[r]$ 严格更强，距离相等时 $a[t] = a[r]$，一样强，故 $a[t]$ 不严格强于 $a[r]$。两种情形覆盖整个窗口，引理成立。∎

**引理 4（破平规则）**：若 $|a[r]-m| = |a[l]-m|$，则 $a[r]$ 不弱于 $a[l]$。

**证明**：等距时比较值大小；由数组有序知 $a[r] \ge a[l]$，故 $a[r]$ 更强或两者相同。∎

**定理**：算法输出的 `res` 与「按强度排序后的前 $k$ 个元素」作为多重集相同。

**证明**：对轮次归纳。第 $t$ 轮开始时剩余候选恰为连续窗口 $a[l..r]$（初始 $t=1$ 时是整段，之后每轮只从一端删除元素，窗口保持连续）。由引理 3，第 $t$ 轮取出的元素是当前窗口中的最强元素；由引理 4，等距时按判定式取 $a[r]$ 也确实取到不弱者，故本轮取出的元素是「剩余元素中的最强元素」。于是取出的序列按强度单调不增，前 $k$ 轮取出的多重集就是全体元素中最强的 $k$ 个（若存在多个同样强的元素，它们的距离相同、值也相同，即完全相同，替换不影响多重集）。∎

## 6. 复杂度分析

- **时间**：排序 $O(n \log n)$，双指针挑选 $k$ 轮、每轮 $O(1)$ 比较，合计 $O(n \log n + k) = O(n \log n)$。$n = 10^5$ 时约 $1.7 \times 10^6$ 次比较量级，非常宽裕。
- **空间**：除输入外只用了 $l, r, m$ 三个整型变量与答案列表 `res`（$k$ 个元素）；排序为原地排序（`std::sort` / Python 的 `sorted` 另开一份 $O(n)$，若用 `list.sort()` 可原地）。故额外空间 $O(1)$（不计输出）。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <algorithm>
#include <cstdlib>
using namespace std;

class Solution {
public:
    vector<int> getStrongest(vector<int>& arr, int k) {
        sort(arr.begin(), arr.end());
        int n = arr.size();
        int m = arr[(n - 1) / 2];          // 下中位数，注意不是 n / 2
        int l = 0, r = n - 1;
        vector<int> res;
        res.reserve(k);
        for (int t = 0; t < k; ++t) {
            long long dl = llabs((long long)arr[l] - m);
            long long dr = llabs((long long)arr[r] - m);
            if (dr >= dl) {                // 距离更远，或等距但值更大
                res.push_back(arr[r]);
                --r;
            } else {
                res.push_back(arr[l]);
                ++l;
            }
        }
        return res;
    }
};
```

### Python

```python
from typing import List


class Solution:
    def getStrongest(self, arr: List[int], k: int) -> List[int]:
        a = sorted(arr)
        n = len(a)
        m = a[(n - 1) // 2]          # 下中位数，不是 n // 2
        lo, hi = 0, n - 1
        res = []
        for _ in range(k):
            if abs(a[hi] - m) >= abs(a[lo] - m):
                res.append(a[hi])    # 距离更远，或等距但值更大
                hi -= 1
            else:
                res.append(a[lo])
                lo += 1
        return res
```

## 8. 边界情况与易错点

1. **$n = 1$**：数组只有一个元素，$p = 0$、$m = a[0]$，$l = r = 0$，第一轮取它即结束；`res` 长度为 $k = 1$，不要因为指针交错而提前退出。
2. **下中位数写成上中位数**：`arr = [1,2,3,4]`、$k = 2$。正确 $m = a[1] = 2$，距离为 $1,0,1,2$，排序后取前两个得 $\{4,3\}$；若误写成 $m = a[2] = 3$，距离变成 $2,1,0,1$，会输出 $\{4,1\}$。两者的第二强元素不同，中位数下标务必用 `(n - 1) / 2`。
3. **等距时必须取较大值**：`arr = [1,2,3,4,5]`、$k = 1$，两端距离都是 2，正确答案是 5；若判定写成 `>` 或误取左端，会得到 1。
4. **指针处理的先后顺序**：先取元素再移动对应指针，别写成「先 `++l` 再取 `a[l]`」，否则会跳过一个元素；`l == r` 时两端相同，取哪一个都不会影响多重集，但两个分支只能执行一个。
5. **重复元素**：本题答案按多重集比较，重复值要按出现次数输出（示例 2 输出两个 5）；双指针每次只弹出一个下标，天然保留重复计数。
6. **输出顺序**：不要为了凑成示例里的顺序而额外排序；如果本地用字符串直接比对期望输出，必须改成排序后比较或多重集比较，否则会把正确解判成错误。
7. **负数的绝对值**：`arr` 可全为负、$m$ 也可能为负，例如 `[-5,-4,-3,-2,-1]`；取绝对值前不要用无符号类型，C++ 用 `llabs` 或 `std::abs(long long)`，Python 直接用 `abs`。

**延伸思考**：把中位数改成「上中位数」$a[n/2]$，双指针框架依然成立，只需把 $p$ 换掉——单调性证明只依赖 $p$ 两侧的大小关系。若要求「输出必须按强度降序」，则在双指针的基础上多存一个顺序即可（本算法本身就是降序产出的，无需再排）。若把「强」改成距离的平方 $|x-m|^2$，因平方在非负区间单调，结论不变；但若改成「距离的奇偶分层」这类不单调的键，端点性质立即失效，只能退回排序或堆。若数组是流式插入且要支持任意时刻查询 top-$k$，则应维护有序容器 + 两端双端队列，或直接使用两个堆，此时本题的端点观察正好解释了「为什么堆里只需要放两端的候选」。
