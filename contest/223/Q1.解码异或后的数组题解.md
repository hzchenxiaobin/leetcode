# LeetCode 解码异或后的数组 题解

## 1. 题目概述

- **标题 / 题号**：解码异或后的数组（#1720，easy）
- **链接**：https://leetcode.cn/problems/decode-xored-array/
- **来源**：LeetCode 第 223 场周赛 Q1
- **难度**：简单
- **标签**：位运算、数组

**题意**：未知整数数组 `arr` 由 $n$ 个非负整数组成，编码后得到长度为 $n-1$ 的数组 `encoded`，满足 $\text{encoded}[i] = \text{arr}[i] \oplus \text{arr}[i+1]$（相邻两项的异或）。现给定 `encoded` 与原数组首元素 `first`（即 $\text{arr}[0]$），还原并返回原数组 `arr`。题目保证答案存在且唯一。

**约束**：

- $2 \le n \le 10^4$
- $\text{encoded.length} = n - 1$
- $0 \le \text{encoded}[i] \le 10^5$
- $0 \le \text{first} \le 10^5$

> 💡 **签到题的定位**：本题是「链式约束 + 已知起点」的模板签到题，从读题到写完代码应在 3 分钟内完成。快速拿分的路径是：一眼识别出 `encoded[i] = arr[i] ⊕ arr[i+1]` 把相邻两项绑成链条，而题目白送起点 `first`，于是**逐项异或前推**即可，无需任何搜索。

## 2. 示例

**示例 1**

```text
输入：encoded = [1,2,3], first = 1
输出：[1,0,2,1]
解释：若 arr = [1,0,2,1]，那么 first = 1 且
      encoded = [1 XOR 0, 0 XOR 2, 2 XOR 1] = [1,2,3]
```

**示例 2**

```text
输入：encoded = [6,2,7,3], first = 4
输出：[4,2,0,7,4]
```

**示例 3**（最小规模 $n = 2$）

```text
输入：encoded = [6], first = 3
输出：[3,5]
解释：arr[1] = arr[0] ⊕ encoded[0] = 3 ⊕ 6 = 5
```

## 3. 解题思路

### 3.1 暴力思路

最朴素的做法是把每个待求位置当成**搜索问题**：对 $k = 1, \dots, n-1$，在值域 $[0, 10^5]$ 内逐一枚举候选值 $v$，检验是否满足 $\text{arr}[k-1] \oplus v = \text{encoded}[k-1]$，命中则填入。

```text
for k in 1 .. n-1:
    for v in 0 .. 10^5:
        if arr[k-1] XOR v == encoded[k-1]:
            arr[k] = v; break
```

每个位置最坏扫完整个值域 $V = 10^5$，总复杂度 $O(n \cdot V) \approx 10^9$，必然超时。

> ⚠️ **症结**：约束 $\text{arr}[k-1] \oplus v = \text{encoded}[k-1]$ 是一个**等式**，$v$ 被唯一确定，根本不需要枚举。把「可计算」的量当作「可枚举」的量去扫描，是签到题上浪费时间的典型误区。

### 3.2 核心观察：异或自反性，一步反解

![核心观察：异或是自己的逆运算，链条从 first 逐项展开](images/decode_xored_chain_concept.svg)

关键洞察是异或运算的**自反性**（异或是其自身的逆运算）：

$$
a \oplus a = 0, \qquad a \oplus 0 = a
$$

对任意 $a, b, c$，若 $c = a \oplus b$，则两边同时异或 $a$：

$$
a \oplus c = a \oplus a \oplus b = 0 \oplus b = b
$$

套到编码等式 $\text{encoded}[i] = \text{arr}[i] \oplus \text{arr}[i+1]$ 上，两边异或 $\text{arr}[i]$，立刻得到解码公式：

$$
\boxed{\;\text{arr}[i+1] = \text{arr}[i] \oplus \text{encoded}[i]\;}
$$

于是从已知的 $\text{arr}[0] = \text{first}$ 出发，每步**一次异或**推出下一项，整条链逐项展开——无搜索、无回溯、每步唯一。

> 💡 **对比加法**：$a + b = c$ 中反解 $b$ 需要换一种运算（减法）；而异或的逆仍是异或，同一个运算符正反两用。这是异或在编码/加密场景好用的根本原因，也是本题 30 秒出思路的题眼。

### 3.3 算法流程

![算法流程：一趟循环，每轮一次异或](images/decode_xored_algorithm_flow.svg)

1. **初始化**：结果数组 `arr` 置入首元素，`arr[0] = first`。
2. **递推**：从 $i = 0$ 起，重复 $\text{arr}[i+1] = \text{arr}[i] \oplus \text{encoded}[i]$，`i` 自增。
3. **终止**：`encoded` 全部消费完（$i$ 达 $n-1$），返回 `arr`。

共 $n-1$ 轮，每轮一次异或加一次自增。

### 3.4 示例演算

以示例 1 `encoded = [1,2,3]`、`first = 1` 为例：

![示例演算：encoded=[1,2,3]，first=1，逐步解码得到 arr=[1,0,2,1]](images/decode_xored_example_walkthrough.svg)

| 步骤 $k$ | 来源 | 计算 | $\text{arr}[k]$ |
|----------|------|------|------|
| 0 | 已知 `first` | — | **1** |
| 1 | $\text{arr}[0] \oplus \text{encoded}[0]$ | $1 \oplus 1$ | **0** |
| 2 | $\text{arr}[1] \oplus \text{encoded}[1]$ | $0 \oplus 2$ | **2** |
| 3 | $\text{arr}[2] \oplus \text{encoded}[2]$ | $2 \oplus 3$ | **1** |

最终 `arr = [1, 0, 2, 1]`，反代回编码公式与 `encoded` 完全吻合 ✓。注意第 2 步 $0 \oplus 2 = 2$——零元是异或的单位元，前一项为 0 时下一项直接等于 `encoded[i]`。

## 4. 算法细节

1. **结果数组构造**：长度为 $n = \text{encoded.length} + 1$。C++ 预分配 `vector<int> arr(n)` 后按下标填入，避免动态扩容；Python 从 `[first]` 起逐个 `append`，写法最短。
2. **递推方向**：只能**从已知端向外推**。起点 `first` 固定 $\text{arr}[0]$，公式又唯一确定 $\text{arr}[1]$，归纳下去每项都被钉死，不存在分叉。
3. **异或无溢出**：异或是按位运算、不产生进位，结果的有效位数不超过操作数位数。值域 $\le 10^5 < 2^{17}$，32 位 `int` 绰绰有余，无需 `long long`。
4. **在原数组上做**：若允许原地修改，甚至可以边读 `encoded[i]` 边把它改写成 `arr[i+1]`（读旧写新互不冲突），把空间压到 $O(1)$；不过本题返回新数组更直观。

## 5. 正确性证明

**引理 1**（异或自反性）：对任意非负整数 $x$，有 $x \oplus x = 0$ 且 $x \oplus 0 = x$。

**证明**：异或按位独立运算且无进位。对每一二进制位，相同位（$0 \oplus 0$、$1 \oplus 1$）结果为 0，故 $x \oplus x = 0$；任意位与 0 异或保持原值，故 $x \oplus 0 = x$。∎

**引理 2**（解码公式）：若 $\text{encoded}[i] = \text{arr}[i] \oplus \text{arr}[i+1]$，则 $\text{arr}[i+1] = \text{arr}[i] \oplus \text{encoded}[i]$。

**证明**：对编码等式两边同时左异或 $\text{arr}[i]$，得 $\text{arr}[i] \oplus \text{encoded}[i] = \text{arr}[i] \oplus \text{arr}[i] \oplus \text{arr}[i+1] = (\text{arr}[i] \oplus \text{arr}[i]) \oplus \text{arr}[i+1] = 0 \oplus \text{arr}[i+1] = \text{arr}[i+1]$，末两步由引理 1 给出。∎

**定理**：按 $\text{arr}[0] = \text{first}$、$\text{arr}[i+1] = \text{arr}[i] \oplus \text{encoded}[i]$ 递推得到的长度为 $n$ 的数组，是唯一满足题意的原数组。

**证明**：**存在性**：对每个 $i \in [0, n-2]$，把递推式代入编码式：$\text{arr}[i] \oplus \text{arr}[i+1] = \text{arr}[i] \oplus (\text{arr}[i] \oplus \text{encoded}[i]) = \text{encoded}[i]$，即所有编码约束被满足，且 $\text{arr}[0] = \text{first}$。**唯一性**：$\text{arr}[0]$ 被给定；由引理 2，$\text{arr}[0]$ 唯一确定 $\text{arr}[1]$，归纳地每个 $\text{arr}[i+1]$ 由 $\text{arr}[i]$ 唯一确定，整条链无自由度。故答案唯一。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。单趟遍历 `encoded`，每轮一次异或 $O(1)$；$n \le 10^4$ 时约 $10^4$ 次位运算，远低于任何时限。异或是 CPU 单周期指令，瓶颈根本不在运算。
- **空间复杂度**：$O(1)$（不计返回的 `arr`，题目要求输出该数组；若计输出则为 $O(n)$）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> decode(vector<int>& encoded, int first) {
        int n = encoded.size() + 1;
        vector<int> arr(n);
        arr[0] = first;
        for (int i = 0; i + 1 < n; ++i) {
            arr[i + 1] = arr[i] ^ encoded[i];
        }
        return arr;
    }
};
```

### Python

```python
class Solution:
    def decode(self, encoded: List[int], first: int) -> List[int]:
        arr = [first]
        for e in encoded:
            arr.append(arr[-1] ^ e)
        return arr
```

> 💡 两种写法本质相同：**前一项 ⊕ encoded[i] → 追加到尾部**。Python 版适合赛时手速；C++ 版预分配按下标填入，无动态扩容开销。

## 8. 边界情况与易错点

1. **最小规模 $n = 2$**：`encoded` 只有 1 个元素，循环只跑 1 轮，输出恰 2 个元素，无需特判。
2. **结果长度别写错**：是 $\text{encoded.length} + 1$，赛时手误写成 `encoded.length` 会直接错样例。
3. **0 不是终止符**：`first` 可为 0，中间项也可为 0（此时下一项直接等于 `encoded[i]`）。不要把 0 当哨兵或终止条件。
4. **方向别推反**：必须**正向**从 `first` 往后推。虽然 $\text{arr}[i] = \text{arr}[i+1] \oplus \text{encoded}[i]$ 数学上也成立，但已知的是左端点，反向推没有起点。
5. **相邻异或 ≠ 前缀异或**：本题给的是 $\text{arr}[i] \oplus \text{arr}[i+1]$（相邻差分），不是累积前缀异或。赛时读串题（如 2433 找出前缀异或的原始数组）时两者解法方向不同，读错题意会白给一罚时。
6. **溢出无忧**：异或按位运算无进位放大，`int` 足够，不必开 `long long`（这是位运算题与加法/乘法题的一个重要区别）。
