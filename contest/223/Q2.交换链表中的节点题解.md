# LeetCode 交换链表中的节点 题解

## 1. 题目概述

- **标题 / 题号**：交换链表中的节点（#1721，medium）
- **链接**：https://leetcode.cn/problems/swapping-nodes-in-a-linked-list/
- **来源**：LeetCode 第 223 场周赛 Q2
- **难度**：中等
- **标签**：链表、双指针

**题意**：给定链表头节点 `head` 与整数 `k`，**交换**链表**正数第** $k$ **个节点**与**倒数第** $k$ **个节点**的**值**，返回链表头节点（下标从 1 开始）。题目保证 $1 \le k \le n$，无需考虑 $k$ 越界。

**约束**：

- 链表节点数目为 $n$
- $1 \le k \le n \le 10^5$
- $0 \le \text{Node.val} \le 100$

> 💡 **Q2 的定位**：中档双指针模板题，赛时应在 5 分钟内拿下。两个题眼：① 交换的是**值**而非节点——不用碰任何 `next` 指针，一次 `swap` 收工；② 「倒数第 $k$」是后向参照，恰好是 [19. 删除链表的倒数第 N 个节点](https://leetcode.cn/problems/remove-nth-node-from-end-of-list/) 的招牌「先发制造间距」技巧。

## 2. 示例

**示例 1**

```text
输入：head = [1,2,3,4,5], k = 2
输出：[1,4,3,2,5]
解释：正数第 2 个节点值为 2，倒数第 2 个节点值为 4，交换两值后
      链表变为 1 → 4 → 3 → 2 → 5。
```

**示例 2**

```text
输入：head = [7,9,6,6,7,8,3,0,9,5], k = 5
输出：[7,9,6,6,8,7,3,0,9,5]
解释：n = 10，正数第 5 个节点值为 7；倒数第 5 个即正数第
      10−5+1 = 6 个节点，值为 8，交换得上述结果。
```

**示例 3**（$k = 1$，头尾互换）

```text
输入：head = [1,2], k = 1
输出：[2,1]
解释：正数第 1 个是头节点，倒数第 1 个是尾节点，交换两值。
```

**示例 4**（两节点重合）

```text
输入：head = [1,2,3], k = 2
输出：[1,2,3]
解释：正数第 2 与倒数第 2 是同一个节点，自交换后链表不变。
```

## 3. 解题思路

### 3.1 暴力思路

链表不支持随机访问，最直白的做法是**借助数组**：一趟把 $n$ 个值拷进数组，交换 $\text{arr}[k-1]$ 与 $\text{arr}[n-k]$，再一趟写回链表。时间 $O(n)$，但额外空间 $O(n)$，且完全没有利用「只需定位两个节点」的结构。

稍作改进是**两趟扫描**：第一趟数出长度 $n$，把「倒数第 $k$」换算成「正数第 $n-k+1$」，第二趟分别走到两个位置交换值。时间 $O(n)$、空间 $O(1)$，已经能过——但「倒数」这个后向参照必须**先知道 $n$** 才能换算，于是不得不扫两趟。

> ⚠️ **症结**：单趟扫描时指针只能前进、无法回头，「倒数第 $k$」在触尾之前无从换算。破局钥匙是**让一个指针先发**，用「领先 $k-1$ 步」的前向间距提前编码这个后向参照。

### 3.2 核心观察：先发 $k-1$ 步，把「倒数」翻译成「间距」

![核心观察：先发 k−1 步制造间距，间距不变量把倒数第 k 翻译成前向间距](images/swap_nodes_gap_invariant_concept.svg)

**观察一（只换值）**：题面要求交换的是两个节点的**值**，不是节点本身。定位到两个节点后一次 `swap` 即可，全程不动 `next` 指针——无需哑节点、无需指针重连、头节点永不丢失。

**观察二（间距不变量）**：位置 $p$ 的节点身后有 $n - p$ 个节点，故

$$
\text{倒数第 } k \;\Longleftrightarrow\; \text{身后恰剩 } k - 1 \text{ 个节点} \;\Longleftrightarrow\; \text{距末尾 } k - 1 \text{ 条边}
$$

于是让 `first` 先走 $k - 1$ 步，停在**正数第 $k$**（第一个交换点）；再让 `second` 从 `head` 出发与之**同速推进**：两指针间距恒为 $k - 1$ 条边，当 `first` 停在最后一个节点时，`second` 距它恰 $k - 1$ 条边——**正是倒数第 $k$**（第二个交换点）。

> 💡 **本质**：「先发 $k-1$ 步」把「倒数第 $k$」这个**后向参照**（要看末尾才知道）提前编码成「领先 $k-1$ 步」这个**前向间距**（出发时就已锁定）。`second` 全程不需要知道 $n$，只管跟着 `first` 走到触尾。这与 19 题「快指针先走 $n$ 步拿前驱」同源，是链表定位类问题的万能模板。

### 3.3 算法流程

![算法流程：一趟扫描，先发定位正数第 k，跟随触尾得倒数第 k](images/swap_nodes_one_pass_flow.svg)

1. **先发**：`first = head`，向前走 $k - 1$ 步，`first` 停在正数第 $k$ 个节点（第一个交换点）。
2. **跟随**：`second = head`。
3. **同速推进**：当 `first` 的下一个节点存在时，`first` 与 `second` 各前进一步。
4. **交换**：循环结束时 `first` 在最后一个节点、`second` 恰在倒数第 $k$ 个节点，交换两者的 `val`。
5. **返回**：直接返回 `head`（只换了值，头指针不变）。

### 3.4 示例演算

以 `head = [1,2,3,4,5]`、`k = 2` 为例（$n = 5$，正数第 2 = 值 2，倒数第 2 = 值 4）：

![示例演算：[1,2,3,4,5], k=2，双指针逐步推进至交换](images/swap_nodes_example_walkthrough.svg)

| 阶段 | first 位置 | second 位置 | 说明 |
|------|-----------|-------------|------|
| 先发 | 2（值 2） | 1（值 1） | `first` 走 $k-1=1$ 步；间距 1 条边 |
| 推进 ① | 3 | 2 | 各前进一步，间距不变 |
| 推进 ② | 4 | 3 | 各前进一步，间距不变 |
| 推进 ③ | 5（值 5） | 4（值 4） | `first` 触尾停止，`second` 恰在倒数第 $k$ |
| 交换 | — | — | 交换 2 与 4 |

最终 `head = 1 → 4 → 3 → 2 → 5`。注意每行 `first` 与 `second` 的间距始终是 $k - 1 = 1$ 条边——间距不变是定位正确的根基。

## 4. 算法细节

1. **先发量是 $k-1$ 步而非 $k$ 步**：`first` 从位置 1 出发，步数 = 目标位置 − 起始位置 = $k - 1$，走完恰落在第 $k$ 个节点**本身**（第一个交换点），无需额外变量保存。
2. **循环条件是 `first->next` 非空而非 `first` 非空**：前者让 `first` 停在**最后一个节点**（位置 $n$），`second` 恰落在 $n-(k-1)=n-k+1$；后者会让 `first` 越过尾部变成空指针，`second` 多走一步错位到「倒数第 $k-1$」，且 $k=1$ 时 `second` 直接为空，解引用崩溃。
3. **交换的是 `val` 域**：`swap(first->val, second->val)` 后即返回，`next` 指针一概未动。链表结构与节点身份完全不变，天然规避了「交换节点」所需的四类指针重连边界。
4. **等价写法**：也可让 `first` 先走 $k$ 步、`second` 从 `head` 跟随至 `first` 为空，此时 `second` 在倒数第 $k$，但第一个交换点需另走 $k-1$ 步暂存。两种写法步数相同，本文取「指针直接停在交换点上」的版本更直观。
5. **无溢出风险**：$0 \le \text{Node.val} \le 100$，`int` 足够；全程无算术放大。

## 5. 正确性证明

**引理 1**（倒数换算）：设链表长度为 $n$，则倒数第 $k$ 个节点即正数第 $n-k+1$ 个节点。

**证明**：位置 $p$ 的节点身后有 $n-p$ 个节点。它是倒数第 $k$ 个节点，当且仅当 $n-p=k-1$，即 $p=n-k+1$。位置与节点一一对应，故得证。∎

**引理 2**（间距不变量）：若两指针所在位置相差 $d$ 条边，且每轮两者各前进一步，则任意轮后位置差仍为 $d$。

**证明**：对轮数归纳。初始差为 $d$；每轮两个位置各增加 $1$，差 $(p_1+1)-(p_2+1)=p_1-p_2$ 保持不变。∎

**定理**：算法终止时，`first` 指向正数第 $k$ 个节点，`second` 指向倒数第 $k$ 个节点；交换二者值后链表恰为所求。

**证明**：`first` 先走 $k-1$ 步后位于位置 $1+(k-1)=k$，即正数第 $k$。链表有限且每轮 `first` 严格前进，循环必终止；终止条件为 `first->next` 为空，故 `first` 停在位置 $n$（最后一个节点）。由引理 2，全程间距保持 $k-1$，故 `second` 位于 $n-(k-1)=n-k+1$，由引理 1 即倒数第 $k$。交换只改这两个节点的 `val`，其余节点与所有 `next` 均不变，结果恰为「交换正数第 $k$ 与倒数第 $k$ 的值」。∎

**推论**：当 $2k=n+1$（如 $n=1,k=1$ 或 $n=3,k=2$）时两个位置重合，`first` 与 `second` 指向同一节点，交换为自交换，链表不变，结果仍正确，无需特判。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。`first` 先走 $k-1$ 步，再与 `second` 同速推进 $n-k$ 步，合计恰 $n-1$ 步——**单趟扫描**，比两趟做法少一半遍历。
- **空间复杂度**：$O(1)$。仅 `first`、`second` 两个指针，无额外数据结构（对照暴力转数组的 $O(n)$）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    ListNode* swapNodes(ListNode* head, int k) {
        ListNode* first = head;
        for (int i = 1; i < k; ++i) {       // 先发 k-1 步 → 正数第 k
            first = first->next;
        }
        ListNode* second = head;
        while (first->next != nullptr) {    // 同速推进，first 触尾停
            first = first->next;
            second = second->next;
        }
        swap(first->val, second->val);      // 只换值，不动 next
        return head;
    }
};
```

### Python

```python
class Solution:
    def swapNodes(self, head: Optional[ListNode], k: int) -> Optional[ListNode]:
        first = head
        for _ in range(k - 1):              # 先发 k-1 步 → 正数第 k
            first = first.next
        second = head
        while first.next:                   # 同速推进，first 触尾停
            first = first.next
            second = second.next
        first.val, second.val = second.val, first.val
        return head
```

> 💡 两版逻辑逐行对应：**先发 $k-1$ 步 → 同速跟随 → 换值返回**。Python 的多重赋值天然就是 swap；C++ 用标准库 `swap`。

## 8. 边界情况与易错点

1. **$n=1, k=1$**：`first` 走 0 步停在 `head`；`first->next` 初始即为空，循环 0 轮；`first` 与 `second` 同指 `head`，自交换无变化。
2. **$k=1$（头尾互换）**：头节点的**值**被换走，但 `head` **指针本身不变**——只换值保证返回原 `head` 即可。若误做成「交换节点」，$k=1$ 时新头是原尾节点，必须返回新头，两者边界处理完全不同。
3. **两节点重合**（$n$ 为奇数且 $k=\lceil n/2 \rceil$）：由交换的幂等性兜底，无需特判（见推论）。
4. **先发量误写 $k$ 步**：`first` 落到第 $k+1$ 个节点；且 $k=n$ 时直接走出尾部，解引用空指针。
5. **循环条件误用 `first != nullptr`**：`second` 多走一步停到倒数第 $k-1$，且 $k=1$ 时 `second` 为空，交换时崩溃。这是与 19 题如出一辙的经典陷阱。
6. **不需要哑节点**：不删除、不换头、不重连指针，哑节点在此毫无用武之地——链表题并非无脑加 dummy。
