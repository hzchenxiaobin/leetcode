# LeetCode 给 N x 3 网格图涂色的方案数 题解

## 1. 题目概述

- **标题 / 题号**：给 N x 3 网格图涂色的方案数（#1411，hard）
- **链接**：https://leetcode.cn/problems/number-of-ways-to-paint-n-3-grid/
- **来源**：LeetCode 第 184 场周赛 Q4
- **难度**：困难
- **标签**：动态规划、状态机、计数、矩阵快速幂

**题意**：给一个 $n \times 3$ 的网格图涂色，每格从**红、黄、绿**三色中选一种，要求**共享水平边或垂直边的相邻格子颜色不同**。给定行数 $n$，返回合法涂色方案数对 $10^9 + 7$ 取模的结果。

**约束**：

- $1 \le n \le 5000$，网格固定 3 列

## 2. 示例

**示例 1**

```text
输入：n = 1
输出：12
解释：单行合法配色共 12 种——ABA 型（首尾同色）6 种 + ABC 型（三色各异）6 种。
```

**示例 2**

```text
输入：n = 2
输出：54
解释：末行 ABA 型 30 种 + 末行 ABC 型 24 种 = 54。
```

**示例 3**

```text
输入：n = 3
输出：246
```

**示例 4**

```text
输入：n = 7
输出：106494
```

**示例 5**

```text
输入：n = 5000
输出：30228214
解释：规模提示——线性递推 4999 轮即可，无需更高明的加速。
```

## 3. 解题思路

### 3.1 暴力思路：逐格 DFS 与 12 状态按行状压

**逐格搜索**：从上到下、从左到右，每格尝试 3 种颜色，与左边、上边不同才继续。总枚举量 $3^{3n} = 27^n$，$n = 5000$ 时是天文数字——必须利用**行与行之间的局部依赖**：第 $i$ 行只与第 $i-1$ 行冲突。

**按行状压 DP（赛时保底写法）**：一行内只有「左右相邻」约束，而第 1、3 格**不相邻**、可以同色，故单行合法配色共 $3 \times 2 \times 2 = 12$ 种。以行配色为状态：

$$dp[i][s] = \sum_{\substack{t:\ t_k \neq s_k,\ k = 1, 2, 3}} dp[i-1][t]$$

12×12 对兼容转移、每对检查 3 列，复杂度 $O(144n) \approx 7 \times 10^5$，$n \le 5000$ 稳过。**但 144 对转移里藏着大量重复**：上一行涂 121 还是 232，下一行的接法数一模一样——颜色只是「名字」不同。这份对称性冗余正是优化入口。

> 💡 赛时策略：没看出对称性塌缩时，直接写 12 状态状压 DP（预处理兼容表 + 滚动数组）也能 AC；看出后两变量递推只要 5 行。本题的难度在「想到」，不在「写对」。

### 3.2 核心观察：颜色对称 ⇒ 12 种配色塌缩成 2 个形状类

![单行12种配色按形状归为ABA与ABC两类](images/wc184_q4_shape_classes.svg)

三个环环相扣的观察：

1. **单行只有两种「形状」**。按首尾是否同色划分：**ABA 型**（首尾同色，$3 \times 2 = 6$ 种）、**ABC 型**（三色各异，$3! = 6$ 种），合计 12 种——正是 $n = 1$ 的答案（示例 1 ✓）。
2. **颜色置换保持一切**。红、黄、绿地位完全对称：任意置换 $\sigma$ 逐格作用后，「相邻不同色」约束与「形状类型」都不变。于是 121、232、313 等 6 个 ABA 涂法两两等价，ABC 同理——**12 个状态塌缩成 2 个等价类**。
3. **只需追踪两个数**：$aba[i]$（前 $i$ 行、末行为 ABA 型的方案数）与 $abc[i]$（末行为 ABC 型的方案数）。下一行怎么接，只依赖上一行的**形状**，不依赖具体颜色。

### 3.3 转移系数：取代表枚举一次

![取代表121与123枚举后继得转移系数3/2/2/2](images/wc184_q4_transition_graph.svg)

由观察 2，每类取一个代表——ABA 取 121、ABC 取 123——枚举其全部合法下一行（列约束逐格不同 + 行约束相邻不同）：

- **上一行 121**：ABA 后继 3 个（212、232、313），ABC 后继 2 个（213、312），共 5 个；
- **上一行 123**：ABA 后继 2 个（212、232），ABC 后继 2 个（231、312），共 4 个。

> ⚠️ 这四个系数 $3/2/2/2$ 是**整道题的命门**，赛时务必亲手枚举一遍（§5 引理 3 给出结构化推导，不用死记）。用 $n = 2$ 立刻可验：$aba = 3 \cdot 6 + 2 \cdot 6 = 30$，$abc = 2 \cdot 6 + 2 \cdot 6 = 24$，$30 + 24 = 54$ ✓（示例 2）。

于是得到转移方程（「谁贡献给我」的反向拉值写法）：

$$
\begin{aligned}
aba[i] &= 3 \cdot aba[i-1] + 2 \cdot abc[i-1] \\
abc[i] &= 2 \cdot aba[i-1] + 2 \cdot abc[i-1]
\end{aligned}
$$

初始 $aba[1] = abc[1] = 6$，答案为 $\big(aba[n] + abc[n]\big) \bmod (10^9 + 7)$。

## 4. 算法细节

1. **滚动两变量**：$aba$、$abc$ 同步更新——右边全读旧值、左边一次性写新值（Python 元组赋值天然如此；C++ 借临时变量），省掉 $dp[n][2]$ 表，空间 $O(1)$。
2. **取模时机**：每轮对两个新值各取一次模。取模前的中间量最大约 $3 \times (10^9 + 6) + 2 \times (10^9 + 6) \approx 5 \times 10^9$，超出 `int` 但远在 `long long`（上限约 $9.2 \times 10^{18}$）之内；返回前 $(aba + abc) \bmod p$ 补最后一次取模。
3. **单变量二阶递推（可选）**：转移矩阵 $M = \begin{pmatrix} 3 & 2 \\ 2 & 2 \end{pmatrix}$ 的特征多项式为 $\lambda^2 - 5\lambda + 2$，由 Cayley–Hamilton 定理（§5 推论）得 $f(n) = 5 f(n-1) - 2 f(n-2)$，其中 $f(1) = 12$、$f(2) = 54$。系数为负，取模要写成 `((5 * x - 2 * y) % MOD + MOD) % MOD` 防负数；两变量版全是正系数，更防手滑，赛时优先。
4. **矩阵快速幂（$n$ 极大时的装甲）**：$\begin{pmatrix} aba \\ abc \end{pmatrix}_n = M^{n-1} \begin{pmatrix} 6 \\ 6 \end{pmatrix}$，2×2 矩阵快速幂 $O(\log n)$。$n \le 5000$ 完全用不上；若 $n \le 10^{18}$ 则是唯一可行解法。
5. **别存 12 状态表**：$O(144n)$ 的状压版也能过（保底），但系数塌缩后的两变量版更短、更不易在兼容表上写错——「先保底、再优化」的典型节奏。

## 5. 正确性证明

**引理 1（单行配色的完备分类）**：一行 3 格的合法配色恰 12 种，且按首尾是否同色划分为 ABA 型 6 种、ABC 型 6 种。

**证明**：行内约束仅 $c_1 \neq c_2$、$c_2 \neq c_3$（第 1、3 格无公共边）。若 $c_1 = c_3 = A$：$A$ 有 3 选、$c_2 = B \neq A$ 有 2 选，共 $3 \times 2 = 6$ 种（ABA 型）；若 $c_1 \neq c_3$：三格两两不同，即 3 色全排列 $3! = 6$ 种（ABC 型）。两种情形互斥且穷尽所有配色。∎

**引理 2（形状等价类）**：设 $\sigma$ 为 $\{$红, 黄, 绿$\}$ 上任意置换，逐格作用于整个网格。则 (i) 合法涂色的像仍合法；(ii) 每行的 ABA/ABC 类型不变；(iii) 对任意两个同型的行涂色 $T, T'$，存在 $\sigma$ 使 $\sigma(T) = T'$，且 $\sigma$ 把「$T$ 的合法后继行集合」双射到「$T'$ 的合法后继行集合」。

**证明**：(i) 相邻格 $c \neq c' \iff \sigma(c) \neq \sigma(c')$（置换是双射）。(ii) $c_1 = c_3 \iff \sigma(c_1) = \sigma(c_3)$。(iii) 同型涂法只是颜色的重命名：ABA 型 $(A, B, A) \mapsto (A', B', A')$（$A \neq B$、$A' \neq B'$，映射 $A \mapsto A'$、$B \mapsto B'$ 可扩张为 3 色置换）；ABC 型的两个排列之间同理存在置换。又 $B$ 是 $T$ 的合法后继 $\iff$ $B$ 逐格异于 $T$ 且行内合法 $\iff$（由 (i)(ii)）$\sigma(B)$ 逐格异于 $T'$ 且行内合法，故后继集合的像恰为后继集合；$\sigma$ 可逆，为双射。∎

**引理 3（转移系数）**：任意 ABA 型行的合法后继中，ABA 型恰 3 个、ABC 型恰 2 个；任意 ABC 型行的合法后继中，两型各恰 2 个。

**证明**：由引理 2(iii)，系数与代表选取无关，取 121、123 验证。设下一行为 $(u, v, w)$。

上一行 $(1, 2, 1)$，约束为 $u \neq 1$、$v \neq 2$、$w \neq 1$、$u \neq v$、$v \neq w$：

- ABA 型 $(u, v, u)$：$u \neq 1$ 且 $u \neq v$ 且 $v \neq 2$。按 $u$ 分类：$u = 2$ 时 $v \in \{1, 3\}$，2 个；$u = 3$ 时 $v = 1$，1 个——共 **3** 个：212、232、313。
- ABC 型：$\{u, v, w\} = \{1, 2, 3\}$，且 $u \neq 1$、$w \neq 1$ 强制 $\{u, w\} = \{2, 3\}$，余下 $v = 1 \neq 2$ ✓，行约束自动满足——共 **2** 个：213、312。

上一行 $(1, 2, 3)$：

- ABA 型 $(u, v, u)$：$u \neq 1$ 且 $u \neq 3 \Rightarrow u = 2$；$v \neq 2 \Rightarrow v \in \{1, 3\}$——共 **2** 个：212、232。
- ABC 型：$\{u, v, w\} = \{1, 2, 3\}$ 且 $u \neq 1$、$v \neq 2$、$w \neq 3$，即 $(1, 2, 3)$ 的错位排列——恰 **2** 个：231、312。∎

**定理**：设 $aba_1 = abc_1 = 6$，$aba_{i+1} = 3\, aba_i + 2\, abc_i$，$abc_{i+1} = 2\, aba_i + 2\, abc_i$，则 $aba_n + abc_n$ 为 $n \times 3$ 网格的合法涂色总数。

**证明**：对 $n$ 归纳。$n = 1$ 即引理 1。设前 $i$ 行的合法涂色按末行类型分组计数恰为 $aba_i$、$abc_i$。每个 $i + 1$ 行的合法涂色唯一分解为「前 $i$ 行的合法涂色 + 末行的一个合法后继行」（行间约束只涉及相邻两行，故组合仍合法且分解唯一）；按新末行的类型计数：末行 ABA 型的涂色数为 $aba_i \times 3 + abc_i \times 2$，末行 ABC 型的为 $aba_i \times 2 + abc_i \times 2$（引理 3）。由引理 2，同型内部每个涂法的两类后继数一致，按类型分组求和不重不漏。归纳完成。∎

**推论（二阶递推）**：$f(n) = aba_n + abc_n$ 满足 $f(n) = 5 f(n-1) - 2 f(n-2)$，$f(1) = 12$、$f(2) = 54$。

**证明**：记 $v_i = (aba_i, abc_i)^T$，则 $v_{i+1} = M v_i$，其中 $M = \begin{pmatrix} 3 & 2 \\ 2 & 2 \end{pmatrix}$，$\operatorname{tr} M = 5$、$\det M = 2$，特征多项式 $\lambda^2 - 5\lambda + 2$。由 Cayley–Hamilton 定理 $M^2 = 5M - 2I$，故 $v_{i+2} = M^2 v_i = 5 v_{i+1} - 2 v_i$ 对每个分量成立，两分量相加即得。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。循环 $n - 1$ 轮，每轮 4 次乘加 + 2 次取模；$n = 5000$ 时约 2 万次运算，远低于时限。矩阵快速幂可降至 $O(\log n)$，但 $n \le 5000$ 无必要。
- **空间复杂度**：$O(1)$。仅两个滚动变量；不存 $dp[n][2]$ 表，更不存 12 状态的兼容表。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int numOfWays(int n) {
        const long long MOD = 1e9 + 7;
        long long aba = 6, abc = 6; // n = 1 初值
        for (int i = 2; i <= n; ++i) {
            long long naba = (3 * aba + 2 * abc) % MOD;
            long long nabc = (2 * aba + 2 * abc) % MOD;
            aba = naba;
            abc = nabc;
        }
        return (int)((aba + abc) % MOD);
    }
};
```

### Python

```python
class Solution:
    def numOfWays(self, n: int) -> int:
        MOD = 10**9 + 7
        aba = abc = 6
        for _ in range(n - 1):
            aba, abc = (3 * aba + 2 * abc) % MOD, (2 * aba + 2 * abc) % MOD
        return (aba + abc) % MOD
```

### 进阶：矩阵快速幂（Python，应对 $n \le 10^{18}$）

```python
class Solution:
    def numOfWays(self, n: int) -> int:
        MOD = 10**9 + 7

        def mul(A, B):
            return [[(A[i][0] * B[0][j] + A[i][1] * B[1][j]) % MOD
                     for j in range(2)] for i in range(2)]

        M = [[3, 2], [2, 2]]
        R = [[1, 0], [0, 1]]
        e = n - 1
        while e:
            if e & 1:
                R = mul(R, M)
            M = mul(M, M)
            e >>= 1
        # f(n) = [1,1] · M^(n-1) · (6,6)^T = 6 × M^(n-1) 全元素和
        return 6 * (R[0][0] + R[0][1] + R[1][0] + R[1][1]) % MOD
```

> 💡 注意 `n = 1` 时幂次为 0，`R` 保持单位阵，`6 × (1 + 0 + 0 + 1) = 12` 自动正确，无需特判。

## 8. 边界情况与易错点

1. **$n = 1$ 不进循环**：初值 $6 + 6 = 12$ 即答案。若把循环误写成 `range(n)`（多推一轮）会返回 54。
2. **单行别数成 6 种**：第 1、3 格不相邻、可同色，单行是 $3 \times 2 \times 2 = 12$ 种（ABA 6 + ABC 6）；误当「三格两两不同」会得到 6，全盘皆错。
3. **转移系数 $3/2/2/2$ 是最大 WA 源**：写错任意一个，$n = 2$（54）与 $n = 3$（246）对拍立刻现形——交前先心算这两组。
4. **C++ 溢出**：`int` 相乘即溢（$3 \times 10^9 > 2^{31} - 1$），dp 值与中间量必须 `long long`；每轮取模后单值 $< 10^9 + 7$，中间和 $< 5.1 \times 10^9$ 安全。Python 无溢出，但每轮取模可避免大数乘法变慢。
5. **二阶递推的负系数**：$f(n) = 5 f(n-1) - 2 f(n-2)$ 在模意义下相减可能为负，须补模（§4 第 3 点）。
6. **矩阵幂的幂次**：$v_n = M^{n-1} v_1$——漏成 $M^n$ 会整体错位一位；用 $n = 1$、$n = 2$ 两点即可验出。
7. **同步更新**：先算出两个新值再覆盖（或元组赋值）；顺序覆盖会让第二个式子读到已更新的 `aba`。
