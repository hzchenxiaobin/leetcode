# LeetCode 判断句子是否为全字母句 题解

## 1. 题目概述

- **标题 / 题号**：判断句子是否为全字母句（#1832，easy）
- **链接**：https://leetcode.cn/problems/check-if-the-sentence-is-pangram/
- **来源**：LeetCode 第 237 场周赛 Q1
- **难度**：简单
- **标签**：哈希表、字符串、位运算

**题意**：**全字母句**（pangram）指包含英语字母表 26 个小写字母**每个至少一次**的句子。给定仅由小写字母组成的字符串 `sentence`，判断它是否为全字母句：是返回 `true`，否则返回 `false`。

**约束**：

- `1 <= sentence.length <= 1000`
- `sentence` 仅由小写英文字母组成

## 2. 示例

**示例 1**

```text
输入：sentence = "thequickbrownfoxjumpsoverthelazydog"
输出：true
解释：sentence 包含英语字母表中每个字母至少一次。
```

**示例 2**

```text
输入：sentence = "leetcode"
输出：false
解释：只出现 l、e、t、c、o、d 共 6 个不同字母，不足 26 个。
```

**示例 3（补充：长度剪枝）**

```text
输入：sentence = "abc"
输出：false
解释：长度 3 < 26，物理上不可能装下全部 26 个字母。
```

## 3. 解题思路

### 3.1 暴力思路

对每个字母 `c ∈ {a..z}` 各扫一遍 `sentence`，判断 `c` 是否出现，26 次全真才返回 `true`。时间 `O(26n)`，`n ≤ 1000` 显然能过；但"哪个字母出现过"完全可以在**一遍扫描**里顺手记完，没必要扫 26 遍。

### 3.2 核心观察：字母打勾清单（哈希标记）

![核心观察：26 个字母的打勾清单](images/pangram_checklist_concept.svg)

只关心每个字母**是否出现**，与出现**次数无关**。准备 26 个格子的「清单」，一遍扫描，每遇到一个字母就在对应格子打一个勾；扫完后数勾数：

- 勾数 `== 26` → 每个格子都有勾 → 每个字母至少出现一次 → 全字母句
- 勾数 `< 26` → 有字母缺席 → 不是

由于 `sentence` 只含小写字母，不同字母数最多为 26，故 `== 26` 与 `>= 26` 等价。

> 💡 一句话总结：把「集合是否覆盖整个字母表」转成「打勾计数是否等于 26」，重复字母天然只打一次勾。

### 3.3 算法流程：位掩码一遍扫描

![算法流程：位掩码一遍扫描](images/pangram_bitmask_flow.svg)

用一个 26 位整数 `mask` 代替清单：第 `k` 位为 1 表示字母 `'a'+k` 已出现。

```text
mask |= 1 << (c - 'a')      # 扫到字符 c，在对应位打勾
mask == (1 << 26) - 1        # 终判：26 位是否全为 1
```

- **C++**：`int` 有 31 位可用，26 位掩码绰绰有余，无需 `long long`。
- **Python**：哈希集合天然去重，一行 `len(set(sentence)) == 26`。

### 3.4 示例演算

![示例演算：leetcode 与全字母句的对比](images/pangram_example_walkthrough.svg)

以 `"leetcode"` 为例，按首次出现顺序打勾：`l`(1) → `e`(2) → `t`(3) → `c`(4) → `o`(5) → `d`(6)，此后再无新字母，勾数 `6 ≠ 26` → `false`。

以 `"thequickbrownfoxjumpsoverthelazydog"` 为例，各字母首次出现恰好构成 26 连勾，最后两个新字母 `d`、`g` 直到串尾 `"...dog"` 才集齐，勾数 `26` → `true`。

## 4. 算法细节

1. **单遍扫描**：`for c in sentence`，每个字符 `O(1)` 更新标记。
2. **位掩码更新**：`mask |= 1 << (c - 'a')`，把 `'a'..'z'` 映射到位 `0..25`；`|=` 保证重复字母幂等。
3. **终判**：`mask == (1 << 26) - 1` 等价于 `__builtin_popcount(mask) == 26`。
4. **长度剪枝（可选）**：`n < 26` 直接返回 `false`；注意 `n >= 26` 不能直接返回 `true`，仍需扫描。
5. **提前终止（可选）**：一旦 `mask` 集齐 26 位立即返回 `true`；答案为假时无收益，不改变最坏复杂度。

## 5. 正确性证明

**引理 1**：`sentence` 是全字母句，当且仅当 `sentence` 中出现的**不同字母数恰为 26**。

**证明**：`sentence` 仅含小写字母，出现的不同字母数至多 26。全字母句要求 26 个字母每个至少出现一次，即 26 个字母全部出现，故不同字母数为 26；反之，不同字母数为 26 意味着 26 种小写字母无一缺席。∎

**引理 2**：扫描完前缀 `sentence[0..i]` 后，`mask` 的第 `k` 位为 1，当且仅当字母 `'a'+k` 在该前缀中出现过。

**证明**：对 `i` 归纳。`i = -1` 时空串无字母出现，`mask = 0` 各位为 0，成立。设对 `i-1` 成立；处理 `sentence[i] = c` 时仅执行 `mask |= 1 << (c - 'a')`：只置位 `c` 对应的那一位，其余位不变。由归纳假设，该位为 1 当且仅当它原来就是 1（`c` 已出现过）或本次被置 1（`c = sentence[i]` 出现），即 `c` 在前缀 `0..i` 中出现过。∎

**定理**：算法返回 `true`，当且仅当 `sentence` 是全字母句。

**证明**：由引理 2，扫描结束后 `mask` 中为 1 的位数恰为不同字母数；`mask == (1 << 26) - 1` 即 26 位全 1，即不同字母数为 26。结合引理 1，判定结果与全字母句定义一致。∎

## 6. 复杂度分析

- **时间复杂度**：`O(n)`，`n = len(sentence)`。单遍扫描，每字符一次 `O(1)` 位运算，终判 `O(1)`。
- **空间复杂度**：`O(1)`。`mask` 是单个 26 位整数；Python 的 `set` 中不同字母至多 26 个，同为常数空间。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool checkIfPangram(string sentence) {
        int mask = 0;
        for (char c : sentence) {
            mask |= 1 << (c - 'a');
        }
        return mask == (1 << 26) - 1;
    }
};
```

### Python

```python
class Solution:
    def checkIfPangram(self, sentence: str) -> bool:
        return len(set(sentence)) == 26
```

## 8. 边界情况与易错点

1. **运算符优先级坑**：C++ 中减法优先级高于移位，`1 << 26 - 1` 会解析为 `1 << 25`，必须写成 `(1 << 26) - 1`。
2. **`int` 足够**：26 < 31，`mask` 用 `int` 即可；但若字符集扩到 52（含大小写），单掩码放不下，需双掩码或数组。
3. **长度剪枝方向**：`n < 26` 必为 `false` 可提前返回；`n >= 26` 不代表为真。
4. **`== 26` 与 `>= 26`**：纯小写字母下二者等价；若可能混入其他字符，`set` 大小上界不再是 26，需先过滤或改判 `>=`。
5. **题目保证全小写**：无需处理空格、大写、标点；若不保证，`c - 'a'` 可能得到负下标或越界位，须先校验 `islower(c)`。
