# LeetCode 所有数对按位与结果的异或和 题解

## 1. 题目概述

- **标题 / 题号**：所有数对按位与结果的异或和（#1835，hard）
- **链接**：https://leetcode.cn/problems/find-xor-sum-of-all-pairs-bitwise-and/
- **来源**：LeetCode 第 237 场周赛 Q4
- **难度**：困难
- **标签**：位运算、数组、数学

**题意**：给定两个下标从 0 开始的非负整数数组 `arr1`（长 $n$）与 `arr2`（长 $m$）。对所有 $n \times m$ 个数对 $(i, j)$ 计算 $\text{arr1}[i] \mathrel{\&} \text{arr2}[j]$，得到一个长 $n \cdot m$ 的列表，返回该列表的**异或和**（所有元素逐个异或的结果；单元素列表的异或和就是该元素本身）。

**约束**：

- $1 \le n, m \le 10^5$ → 数对总数最高 $10^{10}$，**暴力枚举数对必然超时**
- $0 \le \text{arr1}[i], \text{arr2}[j] \le 10^9 < 2^{30}$ → 全程只有 30 个二进制位，`int` 即可

> 💡 本题在本仓库另有[每日题解 1835](../../solution/1801-1900/1835_所有数对按位与结果的异或和.md)，两篇为姊妹篇：每日版侧重「按位分解 + 乘积奇偶性」的四步计数推导与面试问答。本篇按周赛复盘视角展开：**AND 对 XOR 的分配律**这条一步到位的代数捷径、两步收拢的完整演算、引理-定理证明链（代数、计数双证法），以及赛场上「公式凭直觉猜错」的典型翻车反例。

## 2. 示例

**示例 1**

```text
输入：arr1 = [1,2,3], arr2 = [6,5]
输出：0
解释：列表 = [1&6, 1&5, 2&6, 2&5, 3&6, 3&5] = [0,1,2,0,2,1]，
      异或和 = 0⊕1⊕2⊕0⊕2⊕1 = 0。
```

**示例 2**

```text
输入：arr1 = [12], arr2 = [4]
输出：4
解释：列表 = [12&4] = [4]，异或和 = 4。
```

**示例 3（双数组多元素、答案非零）**

```text
输入：arr1 = [7,2], arr2 = [4,5,6]
输出：5
解释：列表 = [7&4, 7&5, 7&6, 2&4, 2&5, 2&6] = [4,5,6,0,0,2]，
      异或和 = 4⊕5⊕6⊕0⊕0⊕2 = 5。
      公式验证：⊕arr1 = 7⊕2 = 5，⊕arr2 = 4⊕5⊕6 = 7，5 & 7 = 5 ✓
```

## 3. 解题思路

### 3.1 暴力思路：$O(nm)$ 的数对枚举必超时

双重循环枚举所有数对，逐个 AND 并累异或，时间 $O(nm)$。本题 $n = m = 10^5$ 时高达 $10^{10}$ 次位运算——即使每次运算只要 1 纳秒也要跑 10 秒，必然 TLE；任何「内层用位运算加速」「常数再压一压」的修补都救不回来。

**自然的中间想法**：值域只有 30 位，而「异或和」类问题的第一反应应当是**按位独立**——固定某一位 $b$，只需知道有多少个数对的 AND 在该位为 1，再看个数的**奇偶**。统计 $c_1^{(b)}$（arr1 中该位为 1 的元素个数）与 $c_2^{(b)}$（arr2 中该位为 1 的元素个数）各需一次线性扫描，得到 $O(30(n+m))$ 的可行解。这已经能过，但还能再收一步：$c_1^{(b)} \bmod 2$ 恰好就是 $\bigoplus \text{arr1}$ 的第 $b$ 位——30 位循环可以坍缩成一行公式。

### 3.2 核心观察：AND 对 XOR 可分配

![核心观察：AND 对 XOR 的分配律](images/1835_distribute_law_concept.svg)

本题的灵魂是一条平时很少被显式使用的恒等式——**按位与对异或满足分配律**：

$$x \mathrel{\&} (y_1 \oplus y_2 \oplus \cdots) = (x \mathrel{\&} y_1) \oplus (x \mathrel{\&} y_2) \oplus \cdots$$

为什么成立？**逐位看**：固定任意一位，该位上 $\&$ 就是 0/1 之间的乘法，$\oplus$ 就是模 2 加法——而「乘法对加法分配」在 $\mathbb{F}_2$（GF(2)）上和普通代数一样天经地义。用单 bit 数值自测：$x=1$、$y=[1,0,1]$ 时，左边 $1 \mathrel{\&} (1\oplus0\oplus1) = 1\mathrel{\&}0 = 0$，右边 $1\oplus0\oplus1 = 0$ ✓。

> ⚠️ **直觉陷阱**：「加法对乘法不可分配，所以 & 对 ⊕ 肯定也不行」——这是把位运算当成了普通整数代数。正确的视角是逐位切换到 GF(2)：$\&$ 是乘法、$\oplus$ 是加法，方向恰好是「乘对加」分配。比赛时如果不敢确信，拿示例 2 一验：$n=m=1$ 时公式退化为 $12 \mathrel{\&} 4 = 4$ ✓，再拿示例 1 验一般情形，即可放心提交。

### 3.3 算法流程：两步收拢

![两步收拢演算](images/1835_two_step_collapse.svg)

把 $\bigoplus_{i,j} (a_i \mathrel{\&} b_j)$ 中的 $\mathrel{\&}$ 依次提出异或链：

```text
① 遍历 arr1，累异或得 X = arr1[0] ⊕ arr1[1] ⊕ … ⊕ arr1[n-1]
② 遍历 arr2，累异或得 Y = arr2[0] ⊕ arr2[1] ⊕ … ⊕ arr2[m-1]
③ 返回 X & Y
```

以示例 1 代入（见上图）：$6$ 项 → $3$ 项 → $1$ 项，每一步用的都是同一条分配律。最终答案：

$$\boxed{\;\text{答案} = \left(\bigoplus_i \text{arr1}[i]\right) \mathrel{\&} \left(\bigoplus_j \text{arr2}[j]\right)\;}$$

### 3.4 示例演算：代数路 × 计数路双验证

![示例 1 逐位验算](images/1835_bit_table_walkthrough.svg)

以示例 1 `arr1 = [1,2,3]`、`arr2 = [6,5]` 为例（3 位二进制）：

| bit | arr1 该位（$c_1$） | arr2 该位（$c_2$） | 数对数 $c_1 \times c_2$ | 奇偶 → 答案位 |
|-----|--------------------|--------------------|--------------------------|----------------|
| $b_2$ | 0,0,0 → 0 | 1,1 → 2 | $0 \times 2 = 0$ | 偶 → 0 |
| $b_1$ | 0,1,1 → 2 | 1,0 → 1 | $2 \times 1 = 2$ | 偶 → 0 |
| $b_0$ | 1,0,1 → 2 | 0,1 → 1 | $2 \times 1 = 2$ | 偶 → 0 |

- **代数路**（本篇主线）：$X = 1 \oplus 2 \oplus 3 = 000_2 = 0$，$Y = 6 \oplus 5 = 011_2 = 3$，$X \mathrel{\&} Y = 0$ ✓
- **计数路**（每日版主线）：三位全「偶」→ 答案 $000_2 = 0$ ✓

两条路在第 $b$ 位同时给出 $\text{parity}(c_1) \mathrel{\&} \text{parity}(c_2)$——因为 $\bigoplus \text{arr1}$ 的第 $b$ 位就是 $c_1$ 的奇偶。再用答案非零的示例 3 复核：$X = 7\oplus2 = 5$，$Y = 4\oplus5\oplus6 = 7$，$5 \mathrel{\&} 7 = 5$ ✓。

## 4. 算法细节

1. **分组自由**：异或满足交换律与结合律，$n \cdot m$ 项按 $i$ 分组再逐组合并完全合法——这是「两步收拢」的前提。
2. **收拢顺序**：先对 $j$ 收拢得 $\bigoplus_i (a_i \mathrel{\&} Y)$，再对 $i$ 收拢得 $X \mathrel{\&} Y$；两次用的都是引理 2，只是把 $x$ 与序列的角色互换（分配律对左右操作数都成立）。
3. **等价的按位计数实现**：对每个 bit $b \in [0, 30)$ 统计 $c_1, c_2$，若 `c1 & 1 && c2 & 1` 则答案置位——$O(30(n+m))$，与一行公式等价（引理 3），可作为赛场上对拍验证的第二实现。
4. **值域无忧**：$10^9 < 2^{30} < 2^{31}$，全程 `int` 无溢出；异或与按位与都不会放大值域。
5. **扫描顺序无关**：两遍扫描先后无所谓；分开写比合并成一个循环更清晰。

## 5. 正确性证明

**引理 1（异或 = 逐位模 2 加法）**：对任意整数序列 $z_1, \dots, z_k$，$\bigoplus_t z_t$ 的第 $b$ 位等于 $\left(\sum_t z_t^{(b)}\right) \bmod 2$，其中 $z_t^{(b)} \in \{0,1\}$ 是 $z_t$ 的第 $b$ 位；且各位之间互不影响（无进位）。

**证明**：$k$ 个 bit 的异或是 1 当且仅当其中 1 的个数为奇数，即模 2 和；按位运算逐位独立、不产生进位。∎

**引理 2（AND 对 XOR 的分配律）**：对任意整数 $x$ 与序列 $y_1, \dots, y_m$：

$$\bigoplus_{j=1}^{m} (x \mathrel{\&} y_j) = x \mathrel{\&} \left(\bigoplus_{j=1}^{m} y_j\right)$$

**证明**：由引理 1，两侧第 $b$ 位分别为 $\left(\sum_j x^{(b)} y_j^{(b)}\right) \bmod 2$ 与 $x^{(b)} \left(\sum_j y_j^{(b)}\right) \bmod 2$。当 $x^{(b)} = 0$ 时两者均为 0；当 $x^{(b)} = 1$ 时 $x^{(b)} y_j^{(b)} = y_j^{(b)}$，两者均等于 $\left(\sum_j y_j^{(b)}\right) \bmod 2$。逐位相等，故整数相等。∎

**引理 3（计数视角）**：设 $c_1^{(b)}$、$c_2^{(b)}$ 分别为 arr1、arr2 中第 $b$ 位为 1 的元素个数，则所有 $n \cdot m$ 个数对中，AND 结果第 $b$ 位为 1 的数对恰有 $c_1^{(b)} \cdot c_2^{(b)}$ 个。

**证明**：$a_i \mathrel{\&} b_j$ 第 $b$ 位为 1 当且仅当两因子该位同时为 1；满足条件的数对是从 $c_1^{(b)}$ 个「1」与 $c_2^{(b)}$ 个「1」中各取一个的笛卡尔积，共 $c_1^{(b)} \cdot c_2^{(b)}$ 对。∎

**定理**：$\bigoplus_{i,j} \left(\text{arr1}[i] \mathrel{\&} \text{arr2}[j]\right) = \left(\bigoplus_i \text{arr1}[i]\right) \mathrel{\&} \left(\bigoplus_j \text{arr2}[j]\right)$。

**证明（代数路，两步收拢）**：记 $Y = \bigoplus_j \text{arr2}[j]$。由异或的交换律与结合律，可按 $i$ 分组重排：

$$\bigoplus_{i,j} (a_i \mathrel{\&} b_j) = \bigoplus_{i=1}^{n} \left(\bigoplus_{j=1}^{m} (a_i \mathrel{\&} b_j)\right) \overset{\text{引理 2}}{=} \bigoplus_{i=1}^{n} \left(a_i \mathrel{\&} Y\right) = \bigoplus_{i=1}^{n} \left(Y \mathrel{\&} a_i\right) \overset{\text{引理 2}}{=} Y \mathrel{\&} \left(\bigoplus_{i=1}^{n} a_i\right)$$

其中第三步用了 $\&$ 的交换律，第四步是引理 2 中 $x$ 取 $Y$、序列取 $(a_i)$ 的用法。∎

**证明（计数路，交叉验证）**：由引理 1 与引理 3，答案第 $b$ 位为 $\left(c_1^{(b)} c_2^{(b)}\right) \bmod 2$；而乘积为奇当且仅当两因子同时为奇，即该位等于 $\left(c_1^{(b)} \bmod 2\right) \mathrel{\&} \left(c_2^{(b)} \bmod 2\right)$。由引理 1，这恰是 $\left(\bigoplus \text{arr1}\right)_b \mathrel{\&} \left(\bigoplus \text{arr2}\right)_b$。逐位相等，故整数相等。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n + m)$。两遍线性扫描各做 $n$、$m$ 次异或，再加一次按位与；相比暴力的 $O(nm) \approx 10^{10}$ 快约五个数量级。
- **空间复杂度**：$O(1)$。仅两个累异或变量，不随输入规模增长。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int getXORSum(vector<int>& arr1, vector<int>& arr2) {
        int x = 0, y = 0;
        for (int v : arr1) x ^= v;
        for (int v : arr2) y ^= v;
        return x & y;
    }
};
```

### Python

```python
from functools import reduce
from operator import xor

class Solution:
    def getXORSum(self, arr1: List[int], arr2: List[int]) -> int:
        return reduce(xor, arr1) & reduce(xor, arr2)
```

`reduce` 不给初值时要求序列非空，本题 $n, m \ge 1$ 天然满足；显式循环版本见每日题解。

## 8. 边界情况与易错点

1. **暴力侥幸（TLE）**：$nm \approx 10^{10}$，必须从「整体化简」而非「常数优化」入手。
2. **公式凭手感猜错（WA）**：
   - 猜成 $X \oplus Y$：示例 2 给出 $12 \oplus 4 = 8 \ne 4$，一步排除；
   - 猜成 $X \,|\, Y$：示例 2 给出 $12 \,|\, 4 = 12 \ne 4$，同样排除；
   - 「奇×奇 = 奇」对应**都为 1 才为 1**，是 AND 语义而非 XOR 语义——这是最后一步写成 `&` 而非 `^` 的本质原因。
3. **不敢相信分配律（耗时）**：怀疑 $x \mathrel{\&} (y_1 \oplus y_2) = (x\mathrel{\&}y_1) \oplus (x\mathrel{\&}y_2)$ 时，用单 bit 或小样例（如 $1\&6 \oplus 1\&5 = 1 = 1\&(6\oplus5)$）自测，不要在赛场上空想。
4. **C++ 无需 `long long`**：值域 $\le 10^9 < 2^{31}$，异或/与不放大值域，`int` 足够。
5. **$n = m = 1$ 退化**：公式退化为 $\text{arr1}[0] \mathrel{\&} \text{arr2}[0]$，与定义一致，无需特判。
6. **按位计数实现的位宽**：若写 30 位循环版本，上界取 30（$10^9 < 2^{30}$）即可，取 31/32 无害但多余。
7. **空数组**：约束保证 $n, m \ge 1$，无需处理 `reduce` 空序列异常；若题目变体允许为空，需补初值 0 并明确空列表异或和的约定。
