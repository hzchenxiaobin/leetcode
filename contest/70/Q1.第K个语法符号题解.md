# LeetCode 第K个语法符号 题解

## 1. 题目概述

- **标题 / 题号**：第K个语法符号（#779，medium）
- **链接**：https://leetcode.cn/problems/k-th-symbol-in-grammar/
- **来源**：LeetCode 第 70 场周赛 Q1
- **难度**：中等
- **标签**：位运算、递归、数学

**题意**：第 1 行写 `0`；之后每一行把上一行的每个字符按 `0 → 01`、`1 → 10` 展开，于是行长度逐行翻倍。给定行号 $n$ 与 1-based 的位置 $k$，返回第 $n$ 行第 $k$ 个字符。

**约束**：

- $1 \le n \le 30$
- $1 \le k \le 2^{n-1}$（第 $n$ 行长度恰为 $2^{n-1}$）

> 💡 看到 $n \le 30$ 就该警惕：第 30 行长度 $2^{29} \approx 5.4 \times 10^8$，**显式建行必然超时超内存**；只问一位，说明存在「逐层定位」的结构。

## 2. 示例

**示例 1**

```text
输入：n = 1, k = 1
输出：0
解释：第 1 行只有 "0"。
```

**示例 2**

```text
输入：n = 2, k = 1
输出：0
解释：第 2 行是 "01"，第 1 个字符是 0。
```

**示例 3**

```text
输入：n = 2, k = 2
输出：1
解释：第 2 行是 "01"，第 2 个字符是 1。
```

把前几行写出来，方便对照后文的演算：

```text
第 1 行：0
第 2 行：01
第 3 行：0110
第 4 行：01101001
```

## 3. 解题思路

### 3.1 暴力思路

逐行构造字符串：第 $i$ 行有 $2^{i-1}$ 个字符，总时间 $O(2^n)$、峰值空间 $O(2^{n-1})$。$n = 30$ 时是 5.4 亿字符——C++ 里一个 `string` 就要 512 MB，Python 更不可能。

注意「只保留最后一行」也躲不掉：要得到第 $n$ 行，就必须把前面每一行的每个字符都展开一遍。既然只需要**一个位置**，而每层的展开对位置的影响是局部的，就应该「只追踪 $k$」。

### 3.2 核心观察：第 n 行 = 第 n-1 行 + 取反(第 n-1 行)

![行翻倍结构：前半是父行，后半是父行取反](images/wc70_q1_doubling_structure.svg)

把第 $n-1$ 行记作 $c_1 c_2 \cdots c_m$（其中 $m = 2^{n-2}$）。每个 $c_i$ 展开成两个字符 $c_i,\ 1-c_i$，整行展开后按顺序拼起来就是

$$c_1,\ 1-c_1,\ c_2,\ 1-c_2,\ \dots,\ c_m,\ 1-c_m$$

现在把「每个块的第 1 个字符」与「每个块的第 2 个字符」分别收集，正好得到

$$\underbrace{c_1 c_2 \cdots c_m}_{\text{第 } n-1 \text{ 行}}\ \underbrace{(1-c_1)(1-c_2)\cdots(1-c_m)}_{\text{第 } n-1 \text{ 行取反}}$$

也就是说 **第 $n$ 行 = 第 $n-1$ 行拼接它的逐位取反**。例如 `0110` + `1001` = `01101001`，正是第 4 行。

由此立刻有两条推论：

- **前缀性质**：第 $n-1$ 行是第 $n$ 行的前缀，所以 $k \le 2^{n-2}$ 时第 $n$ 行第 $k$ 位与第 $n-1$ 行第 $k$ 位相同；答案实际上只与 $k$ 有关，$n$ 只是用来保证 $k$ 合法。
- **折半定位**：令 $mid = 2^{n-2}$，$k \le mid$ 说明落在「拷贝段」，$k > mid$ 说明落在「取反段」，且对应父层位置是 $k - mid$。

### 3.3 算法流程：自顶向下折半

![自顶向下折半的算法流程](images/wc70_q1_halving_flow.svg)

递归形式（就是官方 hint 说的「用 $(n-1, prevK)$ 表示 $(n,k)$」）：

$$
f(n,k)=
\begin{cases}
0, & n = 1,\\[2pt]
f(n-1,\ k), & k \le mid,\\[2pt]
1 - f(n-1,\ k-mid), & k > mid,
\end{cases}
\qquad mid = 2^{\,n-2}
$$

把递归摊平成循环，只需要两个变量：

```text
flip ← 0
while n > 1:
    mid ← 2^(n-2)
    if k > mid:   k ← k - mid;   flip ← flip ⊕ 1
    n ← n - 1
return flip            # 第 1 行只有 "0"，基准值就是 0
```

再进一步：每走一次「右半」就翻转一次，因此答案等于「$k-1$ 的二进制中 1 的个数的奇偶性」：

$$f(n,k) = \operatorname{popcount}(k-1) \bmod 2$$

这就是 **Thue–Morse 序列** $t(k-1)$。验证：$k=5$ 时 $k-1 = 100_2$，1 的个数为 1 → 答案 1；$k=6$ 时 $k-1 = 101_2$，1 的个数为 2 → 答案 0。

### 3.4 示例演算：n = 4, k = 5

![n = 4, k = 5 的逐层演算](images/wc70_q1_walkthrough.svg)

| 层 | $(n,k)$ | $mid=2^{n-2}$ | 判断 | 交给下一层 |
|----|---------|---------------|------|------------|
| 4 | (4, 5) | 4 | $5 > 4$，落右半 | $1 - f(3,1)$ |
| 3 | (3, 1) | 2 | $1 \le 2$，落左半 | $f(2,1)$ |
| 2 | (2, 1) | 1 | $1 \le 1$，落左半 | $f(1,1)$ |
| 1 | (1, 1) | — | 递归终止 | $0$ |

回代：$f(1,1)=0 \Rightarrow f(2,1)=0 \Rightarrow f(3,1)=0 \Rightarrow f(4,5)=1-0=1$，与第 4 行 `01101001` 的第 5 位（字符 `1`）一致。

位运算视角一步到位：$k-1 = 4 = 100_2$，`popcount` 为 1（奇数）→ 答案 **1**；换成 $k = 6$：$k-1 = 5 = 101_2$，2 个 1（偶数）→ 答案 0，而第 4 行第 6 位确实是 `0`。

## 4. 算法细节

1. **先特判 $n = 1$**：此时 $mid = 2^{-1}$ 在整数里没有意义。递归与迭代都以 `n == 1` 作为唯一出口，返回 0。
2. **$mid$ 用移位而不是 `pow`**：`1 << (n - 2)` 是整数且不会引入浮点误差；$n \le 30$ 时 $mid \le 2^{28}$，`int` 足够，不必开 `long long`。
3. **保持 $k$ 的 1-based 语义**：递归分支里是 `k - mid`（不是 `k - mid - 1`）；只有 `popcount` 闭式才把 $k$ 换成 $k-1$（0-based 位置）。
4. **$n$ 在闭式里不参与计算**：这是前缀性质的直接结果，所以 `kthGrammar(30, 1)` 与 `kthGrammar(1, 1)` 都返回 0，不要因为「行号大」就多跑循环。
5. **三种写法等价**：分治递归（贴合定义，$O(n)$ 栈）、迭代折半（$O(1)$ 空间）、`popcount`（$O(\log k)$ 位运算）。Q1 赛场上建议直接写第三种，一行收工。
6. **位运算优先级**：C++ 与 Python 里 `-` 都高于 `&`，但 `k - 1 & 1` 仍建议写成 `(k - 1) & 1`，避免阅读与维护时的歧义；`__builtin_popcount` 传 `unsigned` 更稳妥。
7. **Python 版本兼容**：`int.bit_count()` 需要 Python 3.10+，判题环境不确定时用 `bin(k - 1).count("1")`，两者都是 $O(\log k)$。

## 5. 正确性证明

**引理 1（拼接结构）**：设第 $n-1$ 行为 $c_1 c_2 \cdots c_m$，则第 $n$ 行恰为 $c_1 c_2 \cdots c_m\,(1-c_1)(1-c_2)\cdots(1-c_m)$。

**证明**：第 $n$ 行由每个 $c_i$ 按规则展开后顺序拼接而成，即 $c_1(1-c_1)\,c_2(1-c_2)\cdots c_m(1-c_m)$。把奇数位与偶数位分别抽出：奇数位是 $c_1 \cdots c_m$，偶数位是 $(1-c_1)\cdots(1-c_m)$，故第 $n$ 行 = 第 $n-1$ 行 + 它的逐位取反。∎

**引理 2（前缀性质）**：第 $n-1$ 行是第 $n$ 行的前缀；进而对任意 $n' \ge n$，第 $n$ 行都是第 $n'$ 行的前缀。

**证明**：由引理 1，第 $n$ 行的前 $2^{n-2}$ 个字符恰为第 $n-1$ 行。对 $n' - n$ 归纳即得第二个结论。∎

**引理 3（折半递推正确）**：设 $mid = 2^{n-2}$，则 $k \le mid$ 时 $f(n,k) = f(n-1,k)$；$k > mid$ 时 $f(n,k) = 1 - f(n-1,\,k-mid)$。

**证明**：由引理 1，第 $n$ 行前半段逐位等于第 $n-1$ 行，直接得到第一种情形。后半段第 $j$ 位（$1 \le j \le mid$）等于 $1 - c_j$，即 $1 - f(n-1,j)$；令 $j = k - mid$ 即得第二种情形。∎

**引理 4（闭式）**：对任意合法 $(n,k)$，$f(n,k) = \operatorname{popcount}(k-1) \bmod 2$。

**证明**：对 $n$ 归纳。$n=1$ 时必有 $k=1$，$\operatorname{popcount}(0) = 0$，成立。设结论对 $n-1$ 成立，考虑第 $n$ 行：

- 若 $k \le 2^{n-2}$，则 $k-1 < 2^{n-2}$，其最高位低于 $2^{n-2}$，由引理 3 与归纳假设，$f(n,k) = f(n-1,k) = \operatorname{popcount}(k-1) \bmod 2$。
- 若 $k > 2^{n-2}$，令 $j = k - 2^{n-2} \in [1,\,2^{n-2}]$，则 $k-1 = 2^{n-2} + (j-1)$ 且 $j-1 < 2^{n-2}$，二进制相加没有进位，故 $\operatorname{popcount}(k-1) = 1 + \operatorname{popcount}(j-1)$，奇偶性恰好翻转：$f(n,k) = 1 - f(n-1,j) = 1 - \bigl(\operatorname{popcount}(j-1) \bmod 2\bigr) = \operatorname{popcount}(k-1) \bmod 2$。

∎

**定理**：`kthGrammar(n, k)` 返回第 $n$ 行的第 $k$ 个字符。

**证明**：由引理 3，递归/迭代的每一步都把 $(n,k)$ 化为等价的 $(n-1,k')$ 并累积取反次数，归纳到 $n=1$ 时基准为 0，故返回值正确；由引理 4，`popcount` 闭式与递推等价。约束 $1 \le k \le 2^{n-1}$ 保证过程中 $k$ 始终落在合法区间，不会越界。∎

## 6. 复杂度分析

- **时间**：递归与迭代写法都是 $O(n)$，每层常数次移位与比较，且 $n \le 30$；`popcount` 闭式为 $O(\log k)$，最多 29 次位运算，实际是单条硬件指令。
- **空间**：迭代写法与闭式都是 $O(1)$ 额外空间；递归写法 $O(n)$ 递归栈（$\le 30$ 层）；暴力建行需要 $O(2^{n-1})$ 空间，不可取。
- **数值范围**：$mid \le 2^{28}$，`int` / `long long` 都不会溢出；$k-1 \le 2^{29}-1$，`popcount` 的入参也在 32 位内。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int kthGrammar(int n, int k) {
        if (n == 1) return 0;                 // 第 1 行只有 "0"
        int mid = 1 << (n - 2);               // 前半段长度 2^(n-2)
        if (k <= mid) return kthGrammar(n - 1, k);       // 落在拷贝段
        return 1 - kthGrammar(n - 1, k - mid);           // 落在取反段
    }
};
```

（等价的一行写法：`return __builtin_popcount((unsigned)(k - 1)) & 1;`）

### Python

```python
class Solution:
    def kthGrammar(self, n: int, k: int) -> int:
        flip = 0                       # 迭代折半：O(1) 空间
        while n > 1:
            mid = 1 << (n - 2)
            if k > mid:                # 落在后半：位置左移，翻转一次
                k -= mid
                flip ^= 1
            n -= 1
        return flip                    # 基准：第 1 行是 "0"
```

（等价的一行写法：`return bin(k - 1).count("1") & 1`；Python 3.10+ 可写 `(k - 1).bit_count() & 1`。）

## 8. 边界情况与易错点

1. **$n = 1$**：必须直接返回 0。若先算 `1 << (n - 2)`，C++ 是 `1 << -1`（未定义行为），Python 会抛「negative shift count」；若改写成 `2 ** (n - 2)`，则得到浮点 $0.5$，后面的 `k <= mid` 判断随之出错。
2. **$k = 1$**：任何一行的第一位都是 0（每行都以父行开头，而第 1 行是 0）。这是最快的自检断言。
3. **$k = 2^{n-1}$（最后一个字符）**：行尾每代都取反，答案固定为 $(n-1) \bmod 2$；用 $\operatorname{popcount}(2^{n-1}-1) = n-1$ 也算出同样结果，两种写法可以互相对拍。
4. **1-based / 0-based 混用**：递推里 `k` 是 1-based，所以右半是 `k - mid`；闭式里必须用 `k - 1`。这是本题最常见的 off-by-one。
5. **不要构造字符串**：`row.replace("0", "01").replace("1", "10")` 两步替换会互相污染——第二步会把第一步刚生成的 `1` 再展开一次，`"0"` 会变成 `"010"` 而不是 `"01"`；正确写法是逐字符生成 `"".join("01" if c == "0" else "10" for c in row)`。不过更根本的问题是长度 $2^{29}$ 直接爆内存。
6. **括号与类型**：`(k - 1) & 1` 建议显式加括号；`__builtin_popcount` 的形参是无符号类型，负数会被当成大正数，显式转 `unsigned` 最稳妥（本题 $k \ge 1$ 天然非负）。
