# LeetCode 重排数字的最小值 题解

## 1. 题目概述

- **标题 / 题号**：重排数字的最小值（#2165，medium）
- **链接**：https://leetcode.cn/problems/smallest-value-of-the-rearranged-number/
- **来源**：LeetCode 第 279 场周赛 Q2
- **难度**：中等
- **标签**：数学、贪心、排序

**题意**：
给定整数 `num`，**重排**其十进制数位（只能换位置，不能增删数位，**符号不变**），在结果**不含任何前导零**的前提下使数值**最小**，返回该重排结果。

**约束**：

- $-10^{15} \le \text{num} \le 10^{15}$（绝对值至多 16 位数）

> 💡 本题在本仓库另有[每日题解 2165](../../solution/2101-2200/2165_重排数字的最小值.md)：主线同为「符号定方向 + 排序 + 前导零修正」。本篇按**周赛复盘视角**展开：给出引理-定理化的完整正确性链（符号归约 → 同位数字典序比较 → 交换论证 → 前导零约束下的最小排列）、`swap` 一步修正与计数桶直接构造的等价性、以 $2900710$ 为例的前导零演算、`num = 0` 越界与负数误修正等赛场易错清单，以及求第 $k$ 小、大数版的变体，两篇互为印证。同场 Q1（#2164）是「按下标分组排序」的签到题，Q2 仍是排序，但叠了**符号**与**前导零**两层小陷阱。

## 3. 解题思路

### 3.1 暴力思路：枚举全部排列

提取 $|num|$ 的 $k$ 个数位（$k \le 16$），枚举全部 $k!$ 个全排列，过滤前导零后取最值，复杂度 $O(k! \cdot k)$。$16! \approx 2.09 \times 10^{13}$，远超时限——排列枚举只在数位极少时可行，必须**直接构造**最优排列。

### 3.2 核心观察：符号定方向，前导零只卡正数

![核心：符号决定排序方向，正数需处理前导零](images/2165_min_rearrange_concept.svg)

三个观察层层递进：

1. **位数不变，比较即字典序**：重排不增删数位，所有候选值位数相同，故「比数值大小」=「比数位串字典序」（§5 引理 2 形式化）。
2. **值 = 数位 × 权重的加权和，高位权重大**：正数要值最小，就把**小数位配大权重**——升序排列；负数 $-v$ 要最小，即 $v$ 要**最大**，就把**大数位配大权重**——降序排列。这正是**重排不等式**的定向配对（§5 引理 3 给出一步交换的微观论证）。
3. **前导零约束只影响正数**：正数升序后最小的数位（可能是 0）被排到首位；修正方法是**把最小非零数位 $d^\ast$ 换到首位**——由于 $num > 0$ 必有非零数位，该修正总可完成。负数降序后首位是**最大数位**，必非零，天然满足约束。

> ⚠️ **负数的直觉**：越负的数绝对值越大。最小化 $-v$ 等价于最大化 $v$，方向整体翻转——这是本题最经典的「符号陷阱」。

### 3.3 算法流程

![算法流程：判零、判符号，正数升序加修正，负数降序取负](images/2165_min_rearrange_flow.svg)

1. **判零**：`num == 0` 直接返回 0（唯一重排；同时避免下方「找非零位」越界）；
2. **正数分支**：`to_string(num)` → 升序排序 → 若首位为 `'0'`，与**首个非零位**交换 → `stoll` 返回；
3. **负数分支**：`to_string(-num)` → 降序排序 → 取负返回；无修正步骤。

### 3.4 示例演算

![示例演算：310 → 103 与 -7605 → -7650](images/2165_min_rearrange_walkthrough.svg)

**示例 1（`num = 310`，正数）**：数位 $[3,1,0]$ → 升序 $[0,1,3]$，首位为 0 非法 → 与首个非零位（下标 1 的 $1$）交换得 $[1,0,3]$ → $103$ ✓

**示例 2（`num = -7605`，负数）**：$|num| = 7605$ 数位 $[7,6,0,5]$ → 降序 $[7,6,5,0]$，首位 7 非零 ✓ → 取负 $-7650$ ✓

**示例 3（`num = 2900710`）**：升序 $[0,0,0,1,2,7,9]$ → 最小非零数位 $1$ 换到首位 → $1000279$ ✓

## 4. 算法细节

1. **字符串化处理**：用 `to_string` / `str` 一次性提出数位，避免 `% 10` 逐位弹出——$k \le 16$，性能无差，可读性优先。
2. **前导零修正的两种等价实现**：
   - **交换法**：升序后形如 $\underbrace{0\cdots0}_{k} d^\ast\, \text{rest}$，直接 `swap(s[0], s[k])`。被换走的只是个 `'0'`，后缀仍保持升序，一步到位；$k = 0$（无前导零）时 `swap` 自反，无需 `if` 分支。
   - **计数桶法**：统计 `cnt[0..9]`，首位取 `cnt > 0` 的最小非零 $d$，再按 $0 \to 9$ 顺序追加。直接构造出「$d^\ast$ + 升序后缀」形态（§5 引理 4），把复杂度降到 $O(k + 10)$。
3. **负数分支没有修正步**：降序首位 = 最大数位 $\ge d^\ast > 0$。若误把正数流程套给负数，$-7605$ 会得到 $-567$（错），因为负数要的是**绝对值最大**。
4. **溢出审计**：$|num| \le 10^{15} < 2^{63} - 1 \approx 9.22 \times 10^{18}$，故 `-num` 不溢出；结果也是 $|num|$ 的数位重排，$|\text{ans}| \le 10^{15}$，`stoll` 安全。危险只在 $num = \text{INT64\_MIN}$ 这类范围，本题已排除。
5. **`while (s[k] == '0') k++` 的安全性前提**：正数至少含一个非零数位且已特判 `num == 0`，故 $k$ 必然在界内停住。

## 5. 正确性证明

**约定**：$num \ne 0$ 时记 $D$ 为 $|num|$ 的数位多重集，$|D| = n$；$D$ 的排列写成数位串 $s = s_0 s_1 \cdots s_{n-1}$，对应值 $V(s) = \sum_{i=0}^{n-1} s_i \cdot 10^{n-1-i}$；$s$ **合法**指 $s_0 \ne 0$（$num = 0$ 的情形由算法直接返回，唯一重排即 0）。

**引理 1（符号归约）**：合法解集在 $num > 0$ 时为 $\{v : v \text{ 是 } D \text{ 的合法排列的值}\}$，在 $num < 0$ 时为 $\{-v\}$。因此 $num > 0$ 时最小化 $num \Leftrightarrow$ 最小化 $v$；$num < 0$ 时最小化 $-v \Leftrightarrow$ **最大化** $v$。

**证明**：重排不改变数位多重集与符号（题意），解集如上；$\pm v$ 关于 $v$ 严格单调，最值方向随之确定。∎

**引理 2（同位数比较 = 字典序）**：对 $D$ 的两个合法排列 $a, b$（同为 $n$ 位、首位非零），$V(a) < V(b) \Leftrightarrow$ $a$ 按字典序小于 $b$。

**证明**：设 $a, b$ 前 $i$ 位相同、第 $i$ 位首次不同（$a_i \ne b_i$）。则

$$V(b) - V(a) = (b_i - a_i)\, 10^{n-1-i} + \big(V(b_{\text{后缀}}) - V(a_{\text{后缀}})\big),$$

其中后缀差的绝对值 $\le 10^{n-1-i} - 1 < 10^{n-1-i}$，而首项是 $10^{n-1-i}$ 的非零倍数，故差的符号由 $b_i - a_i$ 决定。∎

**引理 3（交换论证：无约束极值排列）**：在 $D$ 的全部 $n$ 位排列（允许前导零）中，值最小者为**升序**排列，值最大者为**降序**排列。

**证明**：若排列 $s$ 存在相邻位置 $i, i+1$ 满足 $s_i > s_{i+1}$，交换二者，值变化为

$$(s_{i+1} - s_i)\left(10^{n-1-i} - 10^{n-2-i}\right) < 0,$$

即值严格变小。故最小排列不存在任何相邻「左大右小」，即处处非降——升序排列；对称地，最大排列处处非升——降序排列。∎

**引理 4（前导零约束下的最小排列）**：设 $D$ 含非零数位，$d^\ast$ 为其中最小非零数位。则 $D$ 的合法排列中值最小者为：**首位 $d^\ast$，其余数位升序**。

**证明**：

1. 合法排列的首位必是 $D$ 的某个非零数位，故首位 $\ge d^\ast$；而「$d^\ast$ 打头」的排列存在且合法（首位非零）。
2. 设 $T$ 为任一首位 $t_1 > d^\ast$ 的合法排列。因 $T$ 由 $D$ 排成且 $t_1 \ne d^\ast$，必有某个 $d^\ast$ 落在 $T$ 的非首位 $j$。交换第 $0$ 位与第 $j$ 位得 $T'$：首位 $d^\ast \ne 0$ 合法，且由引理 2（首位 $d^\ast < t_1$）知 $V(T') < V(T)$。故最优合法排列的首位必为 $d^\ast$。
3. 首位固定 $d^\ast$ 后 $V = d^\ast \cdot 10^{n-1} + V(\text{后缀})$，后缀是 $n-1$ 位串且允许前导零，由引理 3 其最小形态为升序。∎

**定理**：上述算法返回题目所求的最小重排。

**证明**：$num = 0$ 时唯一重排即 0，直接返回正确。$num > 0$ 时：升序排列 $D$ 得 $0^k\, d^\ast\, \text{rest}$（$k \ge 0$），`swap(s[0], s[k])` 后恰为 $d^\ast\, 0^k\, \text{rest}$——首位 $d^\ast$、其余升序，正是引理 4 的最小合法排列（计数桶写法构造的也是同一形态）。$num < 0$ 时：由引理 1 只需最大化 $v$；由引理 3 降序排列是全部排列的最大者，且其首位为最大数位 $\ge d^\ast > 0$ 天然合法，故也是合法排列中的最大者，输出 $-V(\text{降序})$ 即最小值。∎

## 6. 复杂度分析

- **时间复杂度**：排序版 $O(k \log k)$，$k$ 为数位个数（$k \le 16$）；提取数位 $O(k)$、修正交换 $O(k)$、拼回整数 $O(k)$ 均不主导。计数桶版 $O(k + 10) = O(k)$。本题 $k \le 16$，实际均为常数级。
- **空间复杂度**：$O(k)$ 存数位串（$k \le 16$，常数级）；计数桶版额外 $O(10)$。

## 7. 参考代码

### C++

```cpp
// 写法一：字符串排序 + 前导零交换修正，O(k log k)
class Solution {
  public:
    long long smallestNumber(long long num) {
        if (num == 0) return 0;          // 全零串：唯一重排就是 0，也避免下方找非零位越界
        if (num > 0) {
            string s = to_string(num);   // |num| <= 1e15，至多 16 位
            sort(s.begin(), s.end());    // 升序：小数位配大权重
            int k = 0;
            while (s[k] == '0') k++;     // 升序后前导零连成一段，k 停在首个非零位
            swap(s[0], s[k]);            // 最小非零数位换到首位；k == 0 时自反无害
            return stoll(s);
        } else {
            string s = to_string(-num);  // |num| <= 1e15 < 2^63-1，取负不溢出
            sort(s.begin(), s.end(), greater<char>());  // 降序：绝对值最大
            return -stoll(s);
        }
    }
};
```

```cpp
// 写法二：计数桶直接构造「d* + 升序后缀」/ 降序串，O(k + 10)
class Solution {
  public:
    long long smallestNumber(long long num) {
        if (num == 0) return 0;
        int cnt[10] = {0};
        for (char c : to_string(num > 0 ? num : -num)) cnt[c - '0']++;
        string res;
        if (num > 0) {
            for (int d = 1; d <= 9; d++)          // 首位：最小的非零数位
                if (cnt[d] > 0) { res.push_back('0' + d); cnt[d]--; break; }
            for (int d = 0; d <= 9; d++)          // 其余数位升序追加
                res += string(cnt[d], '0' + d);
        } else {
            for (int d = 9; d >= 0; d--)          // 降序拼接，绝对值最大
                res += string(cnt[d], '0' + d);
        }
        long long v = stoll(res);
        return num > 0 ? v : -v;
    }
};
```

### Python

```python
# 写法一：排序 + 前导零交换修正，O(k log k)
class Solution:
    def smallestNumber(self, num: int) -> int:
        if num == 0:
            return 0
        if num > 0:
            s = sorted(str(num))                    # 升序：小数位配大权重
            k = next(i for i, c in enumerate(s) if c != '0')
            s[0], s[k] = s[k], s[0]                 # 最小非零数位换到首位（k == 0 时无害）
            return int(''.join(s))
        return -int(''.join(sorted(str(-num), reverse=True)))  # 降序：绝对值最大
```

```python
# 写法二：计数桶直接构造，O(k + 10)
class Solution:
    def smallestNumber(self, num: int) -> int:
        if num == 0:
            return 0
        cnt = [0] * 10
        for c in str(abs(num)):
            cnt[int(c)] += 1
        if num > 0:
            res = next(str(d) for d in range(1, 10) if cnt[d])  # 首位：最小非零数位
            cnt[int(res)] -= 1
            return int(res + ''.join(str(d) * cnt[d] for d in range(10)))
        return -int(''.join(str(d) * cnt[d] for d in range(9, -1, -1)))
```

## 8. 边界情况与易错点

1. **`num = 0` 必须特判**：全零串找不到非零位，「找首个非零」的循环会越界（C++ 越界 UB、Python `next` 抛 `StopIteration`）；且 0 的唯一重排就是 0。这是本题最隐蔽的崩点，写法一、写法二都要先挡掉。
2. **负数不做前导零修正**：降序首位 = 最大数位，必非零。误按正数流程（升序 + 修正）处理 $-7605$ 会得到 $-567$——对负数而言那是**最大**（最接近 0）的排列，方向恰好反了。
3. **修正要兼容「无前导零」的情况**：正数升序后首位可能本来就是非零（如 $310$ 的升序 $013$ 有前导零，但 $123$ 的升序 $123$ 没有）；`swap(s[0], s[k])` 在 $k = 0$ 时自反，天然兼容，无需额外分支。
4. **溢出审计**：$|num| \le 10^{15}$，`-num` 与 `stoll` 结果都安全；若范围放宽到 $|num| < 2^{63}$，`-num` 在 $num = \text{INT64\_MIN}$ 时溢出，应改走字符串处理。
5. **位数感知**：$10^{15}$ 是 **16** 位数，`int` 显然装不下（$> 2^{31} - 1$）；幸而函数签名已是 `long long`，Python 则无此虑。
6. **三分支建议显式写全**：先判零、再判符号。`if (num > 0) ... else ...` 的二分支依赖「0 已被提前挡掉」，拆开写时别漏。
7. **Python 细节**：`sorted(str(num))` 返回字符列表，交换后必须 `''.join` 再 `int()`，直接 `int(s)` 会 `TypeError`。
