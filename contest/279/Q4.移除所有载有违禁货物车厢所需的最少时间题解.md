# LeetCode 移除所有载有违禁货物车厢所需的最少时间 题解

## 1. 题目概述

- **标题 / 题号**：移除所有载有违禁货物车厢所需的最少时间（#2167，hard）
- **链接**：https://leetcode.cn/problems/minimum-time-to-remove-all-cars-containing-illegal-goods/
- **来源**：LeetCode 第 279 场周赛 Q4
- **难度**：困难
- **标签**：动态规划、字符串、前后缀分解

**题意**：
给定下标从 0 开始的二进制字符串 $s$，表示一列车厢：$s_i = \texttt{'1'}$ 表示第 $i$ 节车厢载有违禁货物，$\texttt{'0'}$ 表示没有。要求把**所有**载有违禁货物的车厢清理出列车，三种操作均可执行任意多次：

1. 从**左端**移除一节车厢，代价 $1$；
2. 从**右端**移除一节车厢，代价 $1$；
3. 从**任意位置**移除一节车厢，代价 $2$。

返回最小总代价。空列车视为已清理完毕。

**约束**：

- $1 \le n = |s| \le 2 \times 10^5$
- $s_i$ 为 $\texttt{'0'}$ 或 $\texttt{'1'}$

> 💡 本题在本仓库另有[每日题解 2167](../../solution/2101-2200/2167_移除所有载有违禁货物车厢所需的最少时间.md)：主线同为「分割点 + 左右独立 DP + O(1) 空间变体」。本篇按**周赛复盘视角**展开：完整证明「任意操作序列都可规约为**左弹前缀 + 中段直删 + 右弹后缀**」的规范形态定理（每日版只叙述了这一骨架）、转移式 $\min(\text{直删},\ \text{弹端重置})$ 的正确性引理，以及丢掉 $\ell \le r$ 约束后「左右独立取最小」的经典陷阱。本场 Q1（#2164）奇偶下标排序签到、Q2（#2165）数位贪心、Q3（#2166）设计位集考摊还思想，Q4 以前后缀 DP 收官——「操作代价不对称 + 全局结构」的困难题套路非常典型。

## 3. 解题思路

### 3.1 暴力思路：枚举二维决策 (ℓ, r)

最朴素的做法是把每种操作当作搜索的一步、在剩余车厢序列上暴搜，状态空间指数级，不可行。比赛中真正可写的第一个暴力来自一个结构猜想：**左端弹掉的一定是一段前缀，右端弹掉的一定是一段后缀，剩下深处的 '1' 用直删**（直觉见 §3.2，严格证明见 §5）。于是只需枚举两个决策量：左弹到下标 $\ell$、右弹到下标 $r$（$0 \le \ell \le r \le n$），代价为

$$\mathrm{cost}(\ell, r) = \ell + (n - r) + 2 \times \mathrm{ones}(s[\ell..r))$$

其中 $\mathrm{ones}(s[\ell..r))$ 表示区间 $[\ell, r)$ 内 '1' 的个数。用前缀和把每组查询压到 $O(1)$，仍有 $O(n^2)$ 个组合——$n = 2 \times 10^5$ 时约 $2 \times 10^{10}$ 步，必然 TLE。

瓶颈在于 $\ell$ 与 $r$ **耦合**：中段的 '1' 数量同时依赖二者，无法各自独立优化。解耦的标准手法就是前后缀分解——把二维最小化拆成两个一维 DP 再按分割点合并。

### 3.2 核心观察：最优解的规范形态（三段式）

![核心：最优解可规约为左弹前缀 + 中段直删 + 右弹后缀的三段式](images/2167_contest_normal_form.svg)

两条直觉：

- **直删只该花在 '1' 上**：'0' 车厢本来就不必移除；若它挡在某个要左弹的 '1' 前面，随端弹掉只花 $1$，比直删（$2$）便宜。因此花费 $2$ 的操作只会落在「必须移除、又不值得为它连弹一串」的深层 '1' 上。
- **两端弹出的分别是原串的连续前缀与连续后缀**：左弹永远弹出「当前最左」，被左弹的车的原下标按弹出顺序递增；被弹到最深的那辆车左边的所有车（无论用什么方式移除）都已先消失。右端对称，且两条边界不会交叉（$\ell \le r$）。

于是最优解一定长成图中的三段式：左端连弹 $\ell$ 辆（沿途 '0' 也照付 $1$）、右端连弹 $n - r$ 辆、中段 $[\ell, r)$ 里每个 '1' 直删花 $2$、中段的 '0' 原地留守不花钱。整个问题变成在 $0 \le \ell \le r \le n$ 上最小化 $\mathrm{cost}(\ell, r)$。

### 3.3 算法流程：分割点 + pre/suf 两个一维 DP

![转移的两选项：直删/跳过 vs 弹端重置，二者取 min](images/2167_contest_dp_recurrence.svg)

设单步代价 $c_i$：$s_i$ 为 '1' 时取 $2$，为 '0' 时取 $0$。定义

$$\text{pre}[i] = \min_{0 \le \ell \le i}\big(\ell + 2 \times \mathrm{ones}(s[\ell..i))\big)$$

表示**只用左弹 + 直删**清理前 $i$ 辆车厢（下标 $0..i{-}1$）中所有 '1' 的最小代价；$\text{suf}[i]$ 对称地表示**只用右弹 + 直删**清理 $s[i..n)$ 的最小代价。关键在于两者都能一维递推：

$$\text{pre}[i] = \min\big(\underbrace{\text{pre}[i{-}1] + c_{i{-}1}}_{\text{直删 / 跳过第 } i \text{ 辆}},\ \underbrace{i}_{\text{弹端重置：连弹前 } i \text{ 辆}}\big)$$

$$\text{suf}[i] = \min\big(\text{suf}[i{+}1] + c_i,\ n - i\big)$$

「弹端重置」选项把「从零连弹到第 $i$ 辆」打包成单个候选值 $i$，使一维 DP 就吃掉了整个二维枚举。最后枚举分割点 $m$，左半交给 pre、右半交给 suf：

$$\mathrm{ans} = \min_{0 \le m \le n} \big(\text{pre}[m] + \text{suf}[m]\big)$$

三步流程：

1. **正向扫描**：递推 $\text{pre}$ 数组（$n + 1$ 项）；
2. **反向滚动**：$\text{suf}$ 只用一个变量从右往左递推，每步立刻与 $\text{pre}[i]$ 合并更新答案；
3. **初值**：`ans = pre[n]`（分割点 $m = n$，右半什么都不做）。

### 3.4 示例演算

![示例演算：s = "1100101" 的 pre/suf 合并表，答案 5](images/2167_contest_walkthrough.svg)

对示例 1 的 $s = \texttt{"1100101"}$（$n = 7$，'1' 在下标 0、1、4、6）：

| $m$ | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|---|---|---|---|---|---|---|---|---|
| $\text{pre}[m]$ | 0 | 1 | 2 | 2 | 2 | 4 | 4 | 6 |
| $\text{suf}[m]$ | 7 | 5 | 3 | 3 | 3 | 1 | 1 | 0 |
| $\text{pre}[m] + \text{suf}[m]$ | 7 | 6 | **5** | **5** | **5** | **5** | **5** | 6 |

最小值 $5$。取 $m = 2$ 解读：$\text{pre}[2] = 2$ 来自 $\ell = 2$——左弹两节 '1' 车 $s[0], s[1]$，各花 $1$（若都直删要 $4$）；$\text{suf}[2] = 3$ 来自 $r = 6$——右弹 $s[6]$ 花 $1$，再直删深处的 $s[4]$ 花 $2$。合计 $2 + 1 + 2 = 5$，正是题面方案一。题面方案二（左弹 2 次 + 右弹 3 次 = 5）对应 $r = 4$（右弹 $s[4..6]$ 共三辆、代价 $3$），与 $r = 6$ 在 $\text{suf}[2]$ 处并列取到最小。

## 4. 算法细节

1. **两个 DP 的语义边界**：$\text{pre}[i]$ 覆盖「前 $i$ 辆」（下标 $0..i{-}1$），$\text{pre}[0] = 0$；$\text{suf}[i]$ 覆盖「下标 $i..n{-}1$」，$\text{suf}[n] = 0$。合并时两段相接恰好覆盖全串、不重不漏。
2. **转移项与二维枚举的对应**：选项「直删/跳过」继承了 $\text{pre}[i{-}1]$ 的最优前缀决策，覆盖 $\ell \le i{-}1$ 的全部情形；选项「$= i$」是 $\ell = i$ 的唯一情形。两项取 min 恰好等于 $\min_{\ell \le i}$，没有漏项（§5 引理 4）。
3. **'0' 的代价**：'0' 无需移除；若它落在被弹的前缀/后缀里，$1$ 的代价已经计入 $\ell$ 与 $n - r$ 项。DP 中 $c_i = 0$ 表示「跳过」，绝不要为 '0' 再计一次 $1$ 或 $2$。
4. **反向滚动合并**：$\text{suf}$ 只需一个标量；每算出新的 $\text{suf}[i]$ 立即 `ans = min(ans, pre[i] + suf)`。`ans` 初值必须是 `pre[n]`（$m = n$ 分支），否则会漏掉「右侧什么都不做」的方案。
5. **数值范围**：答案 $\le \min(n,\ 2 \times \mathrm{ones}) \le 4 \times 10^5$，`int` 足够，C++ 无需 `long long`——与很多需要中途扩宽的 DP 题不同，本题连防溢出检查都省了。
6. **O(1) 空间变体**：把 $\mathrm{cost}(\ell, r)$ 拆成 $2C + \big(\ell - 2 \cdot \text{prefixones}(\ell)\big) + \big((n - r) - 2 \cdot \text{suffixones}(r)\big)$（$C$ 为 '1' 总数）后，反向扫 $\ell$、滚动维护右项在 $r \ge \ell$ 约束下的最小即可（完整推导见每日题解）。注意两个括号**不能**脱离 $\ell \le r$ 约束各自独立取最小（§8 第 1 条的反例）。

## 5. 正确性证明

**约定**：任取一个可行方案 $S$（一列合法操作）。记 $P$、$R$、$M$ 分别为被**左弹**、**右弹**、**直删**的原下标集合（三者互不相交），$P \cup R \cup M$ 恰为被移除的车，其中包含所有 '1' 的下标。每步操作恰好移除一节车、费用为 1/1/2，故 $\mathrm{cost}(S) = |P| + |R| + 2|M|$。「车 $x$ 在时刻 $t$ 被移除」均指原下标为 $x$ 的那节车。

**引理 1（不交叉）**：若 $P, R$ 均非空，则 $\max P < \min R$。

**证明**：反设存在 $p \in P, r \in R$ 且 $p > r$。设左弹 $p$ 发生在时刻 $t_p$：左弹移除的是当时最左的剩余车，故 $p$ 在 $t_p$ 时是剩余车中下标最小者，于是所有下标 $< p$ 的车（含 $r$）在 $t_p$ 之前已被移除；而 $r$ 的移除方式是右弹，即其移除时刻 $t_r < t_p$。对称地，右弹 $r$ 在时刻 $t_r$ 移除当时最右的剩余车，故所有下标 $> r$ 的车（含 $p$）在 $t_r$ 之前已被移除，于是 $p$ 的移除时刻 $t_p < t_r$。两式矛盾。∎

**引理 2（两侧全覆盖）**：令 $\ell = \max P + 1$（$P$ 为空时取 $0$）、$r = \min R$（$R$ 为空时取 $n$），则 $\ell \le r$，且 $[0, \ell)$ 与 $[r, n)$ 中**每一节**车都在 $S$ 中被移除。

**证明**：$\ell \le r$ 即引理 1。当 $P$ 非空时，$\max P$ 被左弹的瞬间它是当时最左的剩余车，故所有下标更小的车都已先被移除，连同其自身，$[0, \ell) = [0, \max P]$ 内全部被移除；$P$ 为空时该区间为空，结论平凡。$[r, n)$ 对称：$\min R$ 被右弹时所有下标更大的车都已先被移除。∎

**引理 3（规范形态下界）**：对任意可行方案 $S$，$\mathrm{cost}(S) \ge \ell + (n - r) + 2 \times \mathrm{ones}(s[\ell..r))$。

**证明**：按车分桶计价。$[0, \ell)$ 中每节车都被移除（引理 2），每节费用 $\ge 1$（端弹 1、直删 2），合计 $\ge \ell$；同理 $[r, n)$ 合计 $\ge n - r$。再看 $[\ell, r)$：$P$ 中下标都 $\le \ell - 1$、$R$ 中下标都 $\ge r$，故该区间内被移除的车只可能经直删、每节费用恰为 $2$；其中所有 '1' 车必须被移除，故此区间贡献 $\ge 2 \times \mathrm{ones}(s[\ell..r))$。三桶相加即得。∎

**定理 1（规范形态）**：最优值 $= \min_{0 \le \ell \le r \le n} \mathrm{cost}(\ell, r)$，且该值由如下方案达到：左弹 $[0, \ell)$、右弹 $[r, n)$、对 $s[\ell..r)$ 中每个 '1' 直删一次。

**证明**：**可达性**：该方案合法——左弹恰好执行 $\ell$ 次、每次取走当前最左的剩余车，取走的恰是 $[0, \ell)$；右弹对称；被直删的 '1' 位于 $[\ell, r)$，永远不会被端弹抢先移走，任意时刻执行其直删均合法；代价恰为 $\ell + (n - r) + 2 \times \mathrm{ones}(s[\ell..r))$。**下界**：任取可行方案 $S$，构造其 $\ell, r$，由引理 2 有 $\ell \le r$，由引理 3 有 $\mathrm{cost}(S) \ge \mathrm{cost}(\ell, r) \ge \min_{\ell \le r} \mathrm{cost}(\ell, r)$。两方面夹逼即得。∎

**引理 4（转移正确性）**：$\text{pre}[i] = \min\big(i,\ \text{pre}[i{-}1] + c_{i{-}1}\big)$，$\text{suf}$ 对称。

**证明**：由定义 $\text{pre}[i] = \min_{0 \le \ell \le i} \big(\ell + 2 \times \mathrm{ones}(s[\ell..i))\big)$，按最优决策 $\ell$ 拆开：若 $\ell = i$，项值 $= i + 2 \times \mathrm{ones}(\varnothing) = i$；若 $\ell \le i - 1$，项值 $= \big(\ell + 2 \times \mathrm{ones}(s[\ell..i{-}1))\big) + c_{i{-}1} \ge \text{pre}[i{-}1] + c_{i{-}1}$，且当 $\ell$ 取到 $\text{pre}[i{-}1]$ 的最优决策时取等。两分支取 min 即得。∎

**定理 2（算法正确性）**：$\mathrm{ans} = \min_{0 \le m \le n} \big(\text{pre}[m] + \text{suf}[m]\big)$，且等于最优值。

**证明**：一方面，对任意 $m$：设 $\text{pre}[m]$ 在某个 $\ell^* \le m$ 处取到、$\text{suf}[m]$ 在某个 $r^* \ge m$ 处取到（有限集上的 min 必可取到），则

$$\text{pre}[m] + \text{suf}[m] = \ell^* + (n - r^*) + 2 \times \mathrm{ones}(s[\ell^*..r^*)) = \mathrm{cost}(\ell^*, r^*) \ge \text{最优值}.$$

另一方面，对任意 $\ell \le r$：取 $m = \ell$，由定义 $\text{pre}[\ell] \le \ell$、$\text{suf}[\ell] \le (n - r) + 2 \times \mathrm{ones}(s[\ell..r))$，相加得 $\text{pre}[\ell] + \text{suf}[\ell] \le \mathrm{cost}(\ell, r)$。两个方向夹逼，最小值相等，算法返回的即最优值。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$——正向一趟 $n$ 步求 $\text{pre}$，反向一趟 $n$ 步滚动求 $\text{suf}$ 并同步合并答案，每步只有常数次比较与加法。$n = 2 \times 10^5$ 时约 $8 \times 10^5$ 次基本操作，比 $O(n^2)$ 枚举快 $n$ 倍以上。
- **空间复杂度**：$O(n)$——$\text{pre}$ 数组 $n + 1$ 个 `int`；$\text{suf}$ 与答案均为 $O(1)$ 滚动标量。需要时可用 §4 第 6 条的变体压到 $O(1)$ 额外空间。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int minimumTime(string s) {
        int n = s.size();
        // pre[i] = 只用「左弹 + 直删」清理前 i 辆中所有 '1' 的最小代价
        vector<int> pre(n + 1);
        for (int i = 1; i <= n; ++i)
            pre[i] = min(pre[i - 1] + (s[i - 1] == '1' ? 2 : 0), i);

        int ans = pre[n];   // 分割点 m = n：右半什么都不做
        int suf = 0;        // suf[n] = 0
        for (int i = n - 1; i >= 0; --i) {
            // 选项 A：直删/跳过 s[i]；选项 B：右弹到 i，共 n-i 辆
            suf = min(suf + (s[i] == '1' ? 2 : 0), n - i);
            ans = min(ans, pre[i] + suf);
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def minimumTime(self, s: str) -> int:
        n = len(s)
        # pre[i] = 只用「左弹 + 直删」清理前 i 辆中所有 '1' 的最小代价
        pre = [0] * (n + 1)
        for i in range(1, n + 1):
            pre[i] = min(pre[i - 1] + (2 if s[i - 1] == '1' else 0), i)

        ans = pre[n]        # 分割点 m = n：右半什么都不做
        suf = 0             # suf[n] = 0
        for i in range(n - 1, -1, -1):
            suf = min(suf + (2 if s[i] == '1' else 0), n - i)
            ans = min(ans, pre[i] + suf)
        return ans
```

## 8. 边界情况与易错点

1. **左右「独立取最小」的陷阱**：$\mathrm{cost}(\ell, r)$ 能拆成形如 $f(\ell) + g(r)$ 的两项，但**不能**脱离约束 $\ell \le r$ 各自取最小。反例 $s = \texttt{"111"}$：$f$ 在 $\ell = 3$ 最小、$g$ 在 $r = 0$ 最小，直接相加得到荒谬的 $0$——相当于把同一批车从两端各弹一遍（区间重叠）。pre/suf 分割点版把约束自动编码进 $m$，天然无此坑。
2. **把「弹端重置」写成 $\text{pre}[i{-}1] + 1$**：想让第 $i$ 辆车「只花 1 左弹」是不合法的——其左侧只要还有未移除的车，左弹就轮不到它；从零连弹到第 $i$ 辆的总价恰是 $i$。这是本题转移式最高频的写错点。
3. **'0' 的代价重复计**：'0' 落在被弹的前缀/后缀里时，$1$ 的费用已含在 $\ell$ 与 $n - r$ 项中；DP 里遇到 '0' 只能 $+0$ 跳过，再计 $1$ 或 $2$ 都会虚高。
4. **合并循环的边界**：`ans` 初值必须是 `pre[n]`（$m = n$ 分支）；反向循环里要用**更新后的** `suf`（即 $\text{suf}[i]$）与 `pre[i]` 合并，写反一步就会用错半步的值。
5. **全 '0' / 全 '1' / '1' 贴两端**：全 '0' 答案 $0$；全 '1' 答案 $n$（整列连弹，比全直删的 $2n$ 便宜一半）；"100…001" 答案 $2$（两端各弹一次）。用这三个用例可快速自测。
6. **$n = 1$**：`"0"` → $0$、`"1"` → $1$（弹端 1 优于直删 2）。
7. **复杂度误判**：$O(n^2)$ 枚举 $(\ell, r)$ 在 $n = 2 \times 10^5$ 时约 $2 \times 10^{10}$，必然 TLE；也别把「枚举分割点 $m$」（被 DP 吸收，共 $O(n)$）与「枚举 $(\ell, r)$ 二元组」混为一谈。
8. **数值范围**：答案上界 $\min(n,\ 2 \times \mathrm{ones}) \le 4 \times 10^5$，全程 `int` 无溢出风险。
