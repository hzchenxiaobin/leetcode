# LeetCode 对偶下标分别排序 题解

## 1. 题目概述

- **标题 / 题号**：对偶下标分别排序（#2164，easy）
- **链接**：https://leetcode.cn/problems/sort-even-and-odd-indices-independently/
- **来源**：LeetCode 第 279 场周赛 Q1
- **难度**：简单
- **标签**：数组、排序、计数排序

**题意**：
给定下标从 0 开始的整数数组 `nums`，按以下规则重排其中的值：

1. 将 **奇数下标** 上的所有值按 **非递增**（从大到小）顺序排列；
2. 将 **偶数下标** 上的所有值按 **非递减**（从小到大）顺序排列。

返回重排后形成的数组。注意：两类下标各自内部重排，值不会在奇偶下标之间流动。

**约束**：

- `1 <= nums.length <= 100`
- `1 <= nums[i] <= 100`

## 2. 示例

**示例 1**

```text
输入：nums = [4,1,2,3]
输出：[2,3,4,1]
解释：
奇数下标 1、3 上的值 {1,3} → 非递增 → [3,1]
偶数下标 0、2 上的值 {4,2} → 非递减 → [2,4]
交错写回 → [2,3,4,1]
```

**示例 2**

```text
输入：nums = [2,1]
输出：[2,1]
解释：只有一个偶数下标和一个奇数下标，各只放一个值，重排后不变。
```

**示例 3**（奇数长度：偶数位比奇数位多一个）

```text
输入：nums = [5,2,7,4,9]
输出：[5,4,7,2,9]
解释：
偶数下标 0、2、4 上的值 {5,7,9} → 非递减 → [5,7,9]
奇数下标 1、3 上的值 {2,4} → 非递增 → [4,2]
交错写回 → [5,4,7,2,9]
```

## 3. 解题思路

### 3.1 朴素思路：整组排序？——错！

最诱人的想法是"先把整个数组排序，再交错分配"。但这是**错**的：两类下标的值**互不流动**，全局排序会把奇数下标上的值搬到偶数下标上。例如 `[4,1,2,3]` 中全局最小值 1 属于奇数类，绝不能出现在偶数位上。

正确的最短路径是「**分离 → 各自按指定方向排序 → 交错写回**」，时间 $O(n \log n)$，对 $n \le 100$ 绰绰有余。

### 3.2 核心观察：奇偶独立 + 值域极小

![奇偶下标独立分组排序示意](images/even_odd_sort_concept.svg)

两个关键观察：

1. **奇偶独立**：重排规则只作用于各类下标内部，偶数下标上的值构成的多重集合在重排前后不变（奇数同理）。因此问题分解为两个互不相干的排序子问题。
2. **值域只有 1~100**：可以对奇偶两类**分别**建立计数桶 `cntEven[1..100]`、`cntOdd[1..100]`，用**计数排序**把复杂度降到 $O(n + V)$（$V = 101$）。

> ⚠️ **易错点**：计数桶必须**奇偶各建一个**。若只建一个全局桶，"偶数位取当前最小"会抢走本属于奇数类的值——例如 `[4,1,2,3]` 中属于奇数类的 1 会被错误地填到位置 0。

### 3.3 算法流程

![计数排序算法流程](images/even_odd_sort_flow.svg)

1. 扫描 `nums`，按奇偶下标分别累加 `cntEven[v]`、`cntOdd[v]`；
2. 维护双指针：`loE` 从 1 向上（找偶类剩余最小值）、`hiO` 从 100 向下（找奇类剩余最大值）；
3. 从左到右逐位填 `i`：
   - `i` 为偶数下标：跳过 `cntEven[loE] == 0` 的空桶，取 `loE`，计数减一；
   - `i` 为奇数下标：跳过 `cntOdd[hiO] == 0` 的空桶，取 `hiO`，计数减一。

### 3.4 示例演算

![示例 [4,1,2,3] 的计数排序逐步演算](images/even_odd_sort_walkthrough.svg)

以 `nums = [4,1,2,3]` 为例：`cntEven` 为 `{2:1, 4:1}`，`cntOdd` 为 `{1:1, 3:1}`。位置 0（偶）取偶类最小 2，位置 1（奇）取奇类最大 3，位置 2（偶）取 4，位置 3（奇）取 1，得到 `[2,3,4,1]`，与示例一致。

## 4. 算法细节

1. **桶大小**：值域 `[1,100]`，开长度 `101` 的数组（下标 0 弃用），奇偶各一个。
2. **指针推进**：`loE` 只在填偶数位前推进，`hiO` 只在填奇数位前推进；取值后对应计数减一，若清零则下次取值时指针自然跳过。填第 `i` 位时剩余总数为 `n - i > 0`，两类指针都不会越界。
3. **分离排序写回法**：`even = nums[0::2]` 升序、`odd = nums[1::2]` 降序，再交错写回：位置 `i` 为偶数时取 `even[i/2]`，奇数时取 `odd[i/2]`（整数除法下两者都恰为 `i/2`）。
4. **答案唯一性**：每类内部按指定方向排序后排列唯一（相等值交换无影响），故整个问题的合法输出唯一。

## 5. 正确性证明

**引理 1（类不变性）**：重排操作不改变"值属于哪类下标"，即重排后偶数下标上的值构成的多重集合与原数组相同，奇数下标同理。

**证明**：规则 1 只在奇数下标之间交换值，规则 2 只在偶数下标之间交换值，两类下标之间没有任何值移动。∎

**引理 2（计数取数单调）**：在计数桶上，"每次取剩余计数非零的最小值"依次取出的序列非递减；"每次取剩余计数非零的最大值"依次取出的序列非递增。

**证明**：归纳于取数次数。指针 `loE` 单调不减，故先后取出的最小值随时间不减，序列非递减；对称地，`hiO` 单调不增，序列非递增。∎

**定理**：上述算法的输出即题目要求的重排结果。

**证明**：由引理 1，只需分别给出偶类值在偶数下标上的非递减排列与奇类值在奇数下标上的非递增排列。由引理 2，算法恰好把偶类值按非递减填入偶数下标（从小到大依次取）、奇类值按非递增填入奇数下标（从大到小依次取）。又由 §4 的唯一性，该输出就是题目定义的唯一合法答案。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n + V)$，其中 $V = 101$。建桶 $O(n)$；`loE`、`hiO` 在整个过程中累计最多各推进 $V$ 步；填数 $O(n)$。分离排序版本为 $O(n \log n)$。
- **空间复杂度**：$O(V)$，两个计数桶（$V$ 为常数，可视为 $O(1)$）。分离排序版本为 $O(n)$（两个临时数组）。

## 7. 参考代码

### C++

```cpp
// 写法一：分离 + 分别排序 + 交错写回，O(n log n)
class Solution {
  public:
    vector<int> sortEvenOdd(vector<int>& nums) {
        int n = nums.size();
        vector<int> even, odd;
        for (int i = 0; i < n; i++) {
            (i % 2 == 0 ? even : odd).push_back(nums[i]);
        }
        sort(even.begin(), even.end());                // 偶数下标：非递减
        sort(odd.begin(), odd.end(), greater<int>());  // 奇数下标：非递增
        vector<int> ans(n);
        for (int i = 0; i < n; i++) {
            ans[i] = (i % 2 == 0) ? even[i / 2] : odd[i / 2];
        }
        return ans;
    }
};
```

```cpp
// 写法二：奇偶分别计数 + 双指针填数，O(n + V)
class Solution {
  public:
    vector<int> sortEvenOdd(vector<int>& nums) {
        int cntEven[101] = {0}, cntOdd[101] = {0};
        for (int i = 0; i < (int)nums.size(); i++) {
            if (i % 2 == 0) cntEven[nums[i]]++;
            else cntOdd[nums[i]]++;
        }
        int loE = 1, hiO = 100;  // loE：偶类剩余最小；hiO：奇类剩余最大
        for (int i = 0; i < (int)nums.size(); i++) {
            if (i % 2 == 0) {
                while (cntEven[loE] == 0) loE++;
                nums[i] = loE;
                cntEven[loE]--;
            } else {
                while (cntOdd[hiO] == 0) hiO--;
                nums[i] = hiO;
                cntOdd[hiO]--;
            }
        }
        return nums;
    }
};
```

### Python

```python
# 写法一：切片分离 + 排序 + 切片写回，O(n log n)
class Solution:
    def sortEvenOdd(self, nums: List[int]) -> List[int]:
        even = sorted(nums[::2])                # 偶数下标：非递减
        odd = sorted(nums[1::2], reverse=True)  # 奇数下标：非递增
        ans = [0] * len(nums)
        ans[::2] = even
        ans[1::2] = odd
        return ans
```

```python
# 写法二：奇偶分别计数 + 双指针填数，O(n + V)
class Solution:
    def sortEvenOdd(self, nums: List[int]) -> List[int]:
        cnt_even = [0] * 101
        cnt_odd = [0] * 101
        for i, v in enumerate(nums):
            if i % 2 == 0:
                cnt_even[v] += 1
            else:
                cnt_odd[v] += 1
        lo, hi = 1, 100  # lo：偶类剩余最小；hi：奇类剩余最大
        for i in range(len(nums)):
            if i % 2 == 0:
                while cnt_even[lo] == 0:
                    lo += 1
                cnt_even[lo] -= 1
                nums[i] = lo
            else:
                while cnt_odd[hi] == 0:
                    hi -= 1
                cnt_odd[hi] -= 1
                nums[i] = hi
        return nums
```

## 8. 边界情况与易错点

1. **方向读反**：奇数下标是**非递增**（大到小），偶数下标是**非递减**（小到大）——本题最大的坑，读题时先圈出两个方向词再动手。
2. **全局单桶计数**：只用一个计数桶会让偶数位抢走奇数类的值（如 `[4,1,2,3]` 的 1 被填到位置 0），必须奇偶分别建桶。
3. **n = 1**：只有偶数下标 0，奇数类为空。分离写法中 `odd` 为空列表，切片写回自然正确；计数写法中 `hiO` 永不被访问。
4. **奇数长度**：`n` 为奇数时偶数位比奇数位多 1 个，`even` 有 $\lceil n/2 \rceil$ 个元素、`odd` 有 $\lfloor n/2 \rfloor$ 个；写回映射统一用 `i/2`（整数除法）。
5. **"非递增 / 非递减"含等号**：重复值合法（如偶位 `[2,2]` 本身已非递减），无需去重；相等值的先后顺序无影响。
6. **读写在同一数组**：计数写法在 `nums` 上原地写回是安全的（所有值在建桶阶段已读入）；但分离写法必须先把两组值读全再写回，边读边写会覆盖未读数据。
