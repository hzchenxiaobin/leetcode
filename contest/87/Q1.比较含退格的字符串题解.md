# LeetCode 比较含退格的字符串 题解

## 1. 题目概述

- **标题 / 题号**：比较含退格的字符串（#844，easy）
- **链接**：https://leetcode.cn/problems/backspace-string-compare/
- **来源**：LeetCode 第 87 场周赛 Q1
- **难度**：简单
- **标签**：栈、双指针、字符串、模拟

**题意**：把字符串 `s` 和 `t` 分别输入空白的文本编辑器，其中 `#` 表示**退格**：删除光标左边的一个字符；若左边已经没有字符，则该次退格被忽略（文本继续为空）。判断两个字符串编辑后的文本是否相同。

**约束**：

- $1 \le s.length, t.length \le 200$
- `s` 和 `t` 只含小写字母与字符 `#`

> 💡 题面的进阶要求是 $O(n)$ 时间、$O(1)$ 空间。本题解直接给出满足进阶要求的**从右往左双指针**写法，栈模拟作为暴力基线对照。

## 2. 示例

**示例 1**

```text
输入：s = "ab#c", t = "ad#c"
输出：true
解释：s 中 # 删掉 b，t 中 # 删掉 d，两边都变成 "ac"。
```

**示例 2**

```text
输入：s = "ab##", t = "c#d#"
输出：true
解释：s 连退两次删掉 b、a；t 退格删掉 d、c，两边都变成空串。
```

**示例 3**

```text
输入：s = "a#c", t = "b"
输出：false
解释：s 退掉 a 后变成 "c"，t 仍是 "b"，不相等。
```

## 3. 解题思路

### 3.1 暴力思路

最直观的做法是用**栈**模拟编辑器：顺序扫描，遇到普通字符入栈，遇到 `#` 且栈非空就弹栈，最后比较两个栈的内容。时间复杂度 $O(|s|+|t|)$，空间 $O(|s|+|t|)$。

这个做法本身已经能通过本题（$n \le 200$），但它把「最终文本」显式构造了出来。进阶要求 $O(1)$ 空间，说明一定存在**不构造结果**的判定方式。

### 3.2 核心观察：从右往左扫描，退格只影响左侧

![从后往前看：字符去留由它身后的退格决定](images/wc87_q1_backward_pointer_concept.svg)

关键点：一个字符是否被删除，只取决于它**右侧**还有多少个尚未「配对」的 `#`，与左侧无关。

- 从右往左扫描时，用一个计数器 `skip` 记录「当前还有几个 `#` 等着删字符」；
- 遇到 `#`：`skip += 1`（这个 `#` 要删掉左边某个字符）；
- 遇到普通字符：若 `skip > 0`，说明它被右侧的某个 `#` 删掉了，令 `skip -= 1` 并跳过；若 `skip == 0`，它就是最终文本中的一个字符。

于是两个字符串各用一个指针从尾部向左扫，**动态产出最终文本的字符（逆序）**，逐字符比对即可。整个过程的额外状态只有两个指针与两个计数。

### 3.3 算法流程

![算法流程：两侧各自从右往左跳过被删字符，再逐字符比对](images/wc87_q1_two_pointer_flow.svg)

```text
1. i = |s|-1, j = |t|-1, skipS = skipT = 0
2. while i >= 0 or j >= 0:
3.     s 侧：while i >= 0:
4.         s[i] == '#'  → skipS++，i--
5.         skipS > 0    → skipS--，i--     // 该字符已被删除
6.         否则          → break            // s[i] 是有效字符
7.     t 侧：用 skipT 对 j 做同样处理
8.     两侧都有有效字符：s[i] != t[j] → 返回 false
9.     只有一侧还有有效字符：返回 false  // 最终文本长度不同
10.    i--，j--                          // 这一对有效字符相同，继续比对
11. 两侧同时耗尽 → 返回 true
```

### 3.4 示例演算

![示例演算：s = "ab#c" 与 t = "ad#c" 都退化成 "ac"](images/wc87_q1_example_walkthrough.svg)

对示例 1 的 `s = "ab#c"`，从右往左：

| 步骤 | i | s[i] | skipS | 动作 |
|------|---|------|-------|------|
| 1 | 3 | `c` | 0 | 有效字符，保留 `c` |
| 2 | 2 | `#` | 1 | `skipS ← 1` |
| 3 | 1 | `b` | 1 → 0 | 被删除，`skipS` 消耗一次 |
| 4 | 0 | `a` | 0 | 有效字符，保留 `a` |

`t = "ad#c"` 的过程完全对称（`#` 删掉 `d`），有效字符序列同样是 `c`、`a`。两串逐字符比较：`c == c`、`a == a`，返回 `true`。

## 4. 算法细节

1. **内层 `while` 的两个出口**：要么 `i < 0`（左侧已耗尽），要么停在 `skipS == 0` 的普通字符上。两种情况都必须正确处理，不能只判断 `#`。
2. **`#` 自身也要前进**：处理 `#` 时先 `skipS++` 再 `i--`，顺序不能反；`#` 本身永远不进入最终文本。
3. **一方耗尽、另一方还有效字符**：说明两份最终文本长度不同，直接 `false`。注意这种情况**只可能**在内层跳过之后出现，因为外层循环保证至少有一侧指针非负。
4. **原地比较**：不构造新字符串，也不修改输入；只在原串上移动下标，因此额外空间是常数。
5. **空文本退格**：`skip` 计数只涨不「借」——开头多出来的 `#` 会让 `skipS` 增大，但由于左侧没有字符可删，这些计数最终随着扫描结束自然作废，不需要特判。
6. **对称性**：`s` 侧与 `t` 侧的处理代码完全对称，可以用一个辅助函数消除重复，但比赛时直接展开两份更不容易写错边界。

## 5. 正确性证明

**引理 1（`skip` 的语义）**：设扫描到下标 $i$，当前计数为 $k$。则 $i$ 右侧（下标 $> i$ 的部分）中尚未与字符配对的 `#` 恰好有 $k$ 个，且这 $k$ 个 `#` 删除的正是接下来将被跳过的 $k$ 个普通字符。

**证明**：对扫描过程归纳。初始 $i = n-1$、$k=0$，右侧为空，成立。每一步：

- 若 $s[i] = \#$，该 `#` 必然删除它左边最近的、尚未被删除的字符，计数加一，$i$ 左移，语义保持；
- 若 $s[i]$ 是普通字符且 $k>0$，由归纳假设右侧有 $k$ 个待配对 `#`，其中最近的（也就是最靠左的）一个正好删除当前字符，于是 $k$ 减一，$i$ 左移；
- 若 $s[i]$ 是普通字符且 $k=0$，右侧没有待配对 `#`，它不会被删除。

三种情况都保持语义。∎

**引理 2（有效字符序列）**：上述扫描依次「保留」的字符，恰好是 `s` 编辑后文本的**逆序**。

**证明**：由引理 1，扫描结束时被保留的字符正是编辑后文本的全部字符；由于扫描方向是从右往左，输出顺序自然是编辑后文本的逆序。∎

**定理**：算法返回 `true` 当且仅当 `s` 与 `t` 编辑后的文本相等。

**证明**：

- 若返回 `true`：循环中每一对保留字符都比较过且相等，且最终两侧同时耗尽，说明两个逆序序列长度相同、逐位相同，故两份最终文本相等。
- 若返回 `false`：要么某对保留字符不等（逆序序列在该位不同），要么一方先耗尽而另一方仍有保留字符（长度不同）。两种情况下两份最终文本都不可能相等。

反之，若两份最终文本相等，则它们的逆序序列逐位相同、长度相同，算法不会触发任何 `false` 分支，最终返回 `true`。∎

## 6. 复杂度分析

- **时间**：$O(|s| + |t|)$。两个指针各自单调左移，`s` 的每个字符最多被内层循环访问一次，`t` 同理；外层循环的每一轮至少前进一个指针。
- **空间**：$O(1)$。只使用 `i`、`j`、`skipS`、`skipT` 四个整型变量，没有栈、没有新字符串。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool backspaceCompare(string s, string t) {
        int i = (int)s.size() - 1, j = (int)t.size() - 1;
        int skipS = 0, skipT = 0;
        while (i >= 0 || j >= 0) {
            while (i >= 0) {
                if (s[i] == '#') { skipS++; i--; }
                else if (skipS > 0) { skipS--; i--; }
                else break;
            }
            while (j >= 0) {
                if (t[j] == '#') { skipT++; j--; }
                else if (skipT > 0) { skipT--; j--; }
                else break;
            }
            if (i >= 0 && j >= 0) {
                if (s[i] != t[j]) return false;
            } else if (i >= 0 || j >= 0) {
                return false;
            }
            i--; j--;
        }
        return true;
    }
};
```

### Python

```python
class Solution:
    def backspaceCompare(self, s: str, t: str) -> bool:
        i, j = len(s) - 1, len(t) - 1
        skip_s = skip_t = 0
        while i >= 0 or j >= 0:
            while i >= 0:
                if s[i] == '#':
                    skip_s += 1
                    i -= 1
                elif skip_s > 0:
                    skip_s -= 1
                    i -= 1
                else:
                    break
            while j >= 0:
                if t[j] == '#':
                    skip_t += 1
                    j -= 1
                elif skip_t > 0:
                    skip_t -= 1
                    j -= 1
                else:
                    break
            if i >= 0 and j >= 0:
                if s[i] != t[j]:
                    return False
            elif i >= 0 or j >= 0:
                return False
            i -= 1
            j -= 1
        return True
```

## 8. 边界情况与易错点

1. **`#` 多于左侧字符**：如 `s = "###a"`，开头的 `#` 全部无效，最终文本是 `"a"`。代码中 `skip` 只会让指针继续左移，不会越界，天然正确。
2. **两个串都退成空串**：如示例 2，返回 `true`。不要在「一方为空」时提前返回 `false`，必须等两侧同时耗尽。
3. **一方耗尽、另一方还有效字符**：如 `"a#"`（空）与 `"a"`，必须返回 `false`；若只比较到较短一方结束就 `return true`，会漏判长度差。
4. **`#` 不能被当作普通字符比较**：`"#"` 与 `"#"` 都退化成空串，但 `"#"` 与 `"a"` 不同。跳过逻辑必须让 `#` 只影响计数、不参与比较。
5. **`#` 的处理顺序**：`skipS++` 必须在 `i--` 之前理解，但代码中两者可以写在同一分支里；千万不要先判断 `skipS > 0` 再判断 `#`，否则 `#` 会被当成「被删除的字符」而错位。
6. **下标从 `len-1` 开始**：长度至少为 1，不会出现空串输入；但循环条件必须是 `i >= 0` 的 `int` 判断，C++ 中若用 `size_t` 会下溢成巨大正数而死循环。
7. **不要修改输入字符串**：原地删除会让下标与长度同时变化，极易出错；本题只需移动指针。
