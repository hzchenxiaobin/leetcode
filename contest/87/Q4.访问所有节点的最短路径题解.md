# LeetCode 访问所有节点的最短路径 题解

## 1. 题目概述

- **标题 / 题号**：访问所有节点的最短路径（#847，hard）
- **链接**：https://leetcode.cn/problems/shortest-path-visiting-all-nodes/
- **来源**：LeetCode 第 87 场周赛 Q4
- **难度**：困难
- **标签**：位运算、广度优先搜索、图、动态规划、位掩码

**题意**：给定一个 $n$ 个节点的**无向连通图**，`graph[i]` 列出与节点 $i$ 直接相连的所有节点。求一条**可以访问所有节点**的最短路径长度（边数）。路径可以在**任意节点开始、任意节点结束**，允许重复访问节点、重复经过边。

**约束**：

- $n = graph.length$，$1 \le n \le 12$
- `graph[i]` 不含自环；边是双向的；输入图保证连通

## 2. 示例

**示例 1**

```text
输入：graph = [[1,2,3],[0],[0],[0]]
输出：4
解释：一种最优走法是 [1,0,2,0,3]，共 4 条边，访问了 1、0、2、3 全部节点。
```

**示例 2**

```text
输入：graph = [[1],[0,2,4],[1,3,4],[2],[1,2]]
输出：4
解释：一种最优走法是 [0,1,4,2,3]，共 4 条边。
```

**补充示例**

```text
输入：graph = [[]]
输出：0
解释：只有一个节点，起点即终点，不需要走任何边（也说明答案可以为 0）。
```

## 3. 解题思路

### 3.1 暴力思路

先看两种「自然但不可行」的做法：

1. **枚举访问顺序**：枚举起点与节点的访问排列，用两两最短路长度累加。$n = 12$ 时排列数是 $12! \approx 4.8 \times 10^8$，还要再乘上最短路计算，无法接受。
2. **暴搜走法**：从每个点出发 DFS 所有走法，直到访问完所有节点。由于允许重复经过边，走法数量随长度指数增长，且最短长度本身可以达到 $O(n^2)$ 量级，完全无法剪枝。

问题的根源是：**「走到哪里」和「已经访问过谁」必须一起记录**，否则无法判断是否完成；而只记录其中一个都会丢失信息。

### 3.2 核心观察：把「已访问集合」并入状态

![状态 = (已访问集合 mask, 当前节点)](images/wc87_q4_bitmask_state_concept.svg)

$n \le 12$ 是强烈的信号：**用一个 $n$ 位整数 `mask` 表示已访问的点集**，于是状态定义为

$$(\text{mask},\ u) \quad \text{表示「已访问点集为 mask，当前站在 } u」$$

- 初始状态：对每个 $i$，`(1 << i, i)`，距离 0——这等价于加一个虚拟超级源点，与所有起点相连，从而把「任意起点」统一处理；
- 转移：一条边 $u \to v$ 把状态 $(mask, u)$ 变成 $(mask \mid 2^v, v)$，距离 +1；
- 终止：某个状态满足 $mask = 2^n - 1$（全 1）。

状态总数是 $n \cdot 2^n \le 12 \times 4096 = 49152$，非常小。更妙的是**所有边的代价都是 1**，所以在状态图上跑 BFS，第一次取出 `mask` 全 1 的状态时，它的距离就是答案——BFS 的分层性质直接给出最短路。

> 关键理解：同一个 `mask` 下站在不同节点是**不同状态**。站在 $u$ 还是 $v$，决定下一步能去哪里，不能合并。

### 3.3 算法流程

![多源 BFS：把所有起点当作第 0 层一起出发](images/wc87_q4_multisource_bfs_flow.svg)

```text
1. full = (1 << n) - 1
2. dist[mask][u] 全部初始化为 -1
3. 对每个 i：dist[1<<i][i] = 0，把 (1<<i, i) 入队
4. while 队列非空：
5.     (mask, u) = 出队，d = dist[mask][u]
6.     若 mask == full：返回 d            // BFS 首次取出即最短
7.     对每个邻居 v：
8.         nm = mask | (1 << v)
9.         若 dist[nm][v] == -1：
10.            dist[nm][v] = d + 1，把 (nm, v) 入队
11. 返回 -1（连通图不会走到这里）
```

### 3.4 示例演算

![示例演算：BFS 第 4 层首次凑满 mask](images/wc87_q4_example_walkthrough.svg)

对示例 1 的星形图（`0` 连 `1,2,3`），从 4 个源出发逐层扩展：

| 层 $d$ | 新出现的状态 $(\text{mask}, u)$ | 含义 |
|--------|-------------------------------|------|
| 0 | (0001,0) (0010,1) (0100,2) (1000,3) | 4 个起点，各自只含自己 |
| 1 | (0011,1) (0101,2) (1001,3) | 从 0 出发走到一个叶子 |
| 2 | (0011,0) (0101,0) (1001,0) | 从叶子回到 0，mask 不变 |
| 3 | (0111,2) (1011,3) (1101,3) … | 再走第二个叶子 |
| 4 | (1111,3) ← mask 首次全 1 | 返回 4 |

最优走法 `1 → 0 → 2 → 0 → 3` 对应状态链 $(0010,1) \to (0011,0) \to (0111,2) \to (0111,0) \to (1111,3)$，长度 4。注意 `(0111,0)` 与 `(0111,2)` 的 `mask` 相同，但当前节点不同，必须分别存储。

## 4. 算法细节

1. **`dist` 的维度**：`dist[mask][u]`，大小 $2^n \times n$。用 `-1` 表示未访问，避免单独再开 `visited` 数组。
2. **多源初始化**：把 $n$ 个 `(1<<i, i)` 都设为距离 0 并入队。等价于建立一个虚拟源 `S` 连向所有起点、边权 0；由于边权非负且同层，BFS 依然正确。
3. **出队时判满**：在**出队**时检查 `mask == full` 是安全的；也可以在入队时检查（新状态刚凑满时立即返回 `d+1`），两者都正确，但出队判断写起来更简洁、不易漏算 `n = 1` 的情况。
4. **`n = 1` 的处理**：初始状态 `(1, 0)` 的 `mask` 已经等于 `full = 1`，出队时直接返回 0，不需要特判。
5. **状态去重**：同一状态可能由不同走法到达，`dist != -1` 时直接跳过——这保证每个状态只入队一次，是复杂度有界的关键。
6. **不用 Dijkstra**：所有转移代价都是 1，BFS 已经最优，Dijkstra 只会多一个 $\log$ 因子。
7. **返回值类型**：答案不超过 $O(n^2)$，`int` 足够；`mask` 用 `int`，$n \le 12$ 不会溢出。

## 5. 正确性证明

先定义状态图的节点集 $V' = \{(mask, u) \mid u \in [0,n)\}$，边为 $(mask, u) \to (mask \mid 2^v, v)$（对所有原图边 $u \to v$）。

**引理 1（状态序列与走法一一对应）**：从 $(1 \ll s, s)$ 出发、长度为 $d$ 的状态图路径，与「从 $s$ 出发、长度为 $d$ 的原图走法」一一对应；且路径终点为 $(mask, u)$ 时，$mask$ 恰好是该走法访问过的点集、$u$ 是终点。

**证明**：对 $d$ 归纳。$d = 0$ 时只有 $(1 \ll s, s)$，对应「停在 $s$、只访问了 $s$」，成立。若长度为 $d$ 的走法终点为 $u$、访问集为 $mask$，则再走一条边 $u \to v$ 得到长度 $d+1$ 的走法，访问集变为 $mask \cup \{v\}$、终点为 $v$，正好对应状态图的一条边；反过来状态图的每条边都来自原图的一条边，逆过程同理。∎

**引理 2（可达性与距离）**：`dist[mask][u] = d` 当且仅当存在一条从某个起点出发、长度恰为 $d$、访问集合为 $mask$、终点为 $u$ 的走法，且 $d$ 是这类走法的最小长度。

**证明**：BFS 从所有源（距离 0）出发，每条边扩展一层，由引理 1，第 $d$ 层的新状态正是所有「长度 $d$ 的走法」的终点状态；`dist` 只在首次到达时赋值，因而是最小长度。∎

**引理 3（BFS 分层正确）**：BFS 的出队顺序按距离单调不减。

**证明**：标准队列 BFS 性质：所有距离为 $d$ 的状态先于距离 $d+1$ 的状态入队，且每条边权为 1，故出队时距离非降。∎

**定理**：算法返回的值等于访问所有节点的最短路径长度。

**证明**：

- 设答案为 $L$，则存在长度 $L$、访问集为全集、终点为某 $u$ 的走法。由引理 2，`dist[full][u] = L`，该状态会在第 $L$ 层（或更早）被首次赋值。由引理 3，算法首次取出 `full` 状态时距离不超过 $L$，返回 $d \le L$。
- 另一方面，算法返回的 $d$ 对应某状态 $(full, u)$，由引理 2 存在长度为 $d$ 的走法访问了所有节点，故 $L \le d$。

两者夹逼得 $d = L$。∎

## 6. 复杂度分析

- **时间**：状态数 $n \cdot 2^n$，每个状态枚举其邻居，总转移次数 $\sum_{u} \deg(u) \cdot 2^n = 2^n \sum_u \deg(u) = O(2^n \cdot m)$，其中 $m$ 为边数（$m \le n(n-1)/2$）。最坏 $O(2^n n^2)$，$n = 12$ 时约 $4096 \times 144 \approx 5.9 \times 10^5$ 次转移，非常快。
- **空间**：`dist` 为 $2^n \times n$ 的整型数组，$O(2^n n)$；队列中每个状态最多出现一次，同样是 $O(2^n n)$。$n = 12$ 时约 5 万个整数。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int shortestPathLength(vector<vector<int>>& graph) {
        int n = (int)graph.size();
        int full = (1 << n) - 1;
        vector<vector<int>> dist(1 << n, vector<int>(n, -1));
        deque<pair<int, int>> q;
        for (int i = 0; i < n; i++) {
            dist[1 << i][i] = 0;
            q.push_back({1 << i, i});
        }
        while (!q.empty()) {
            auto [mask, u] = q.front();
            q.pop_front();
            int d = dist[mask][u];
            if (mask == full) return d;
            for (int v : graph[u]) {
                int nm = mask | (1 << v);
                if (dist[nm][v] == -1) {
                    dist[nm][v] = d + 1;
                    q.push_back({nm, v});
                }
            }
        }
        return -1;
    }
};
```

### Python

```python
from collections import deque

class Solution:
    def shortestPathLength(self, graph: list[list[int]]) -> int:
        n = len(graph)
        full = (1 << n) - 1
        dist = [[-1] * n for _ in range(1 << n)]
        q = deque()
        for i in range(n):
            dist[1 << i][i] = 0
            q.append((1 << i, i))
        while q:
            mask, u = q.popleft()
            d = dist[mask][u]
            if mask == full:
                return d
            for v in graph[u]:
                nm = mask | (1 << v)
                if dist[nm][v] == -1:
                    dist[nm][v] = d + 1
                    q.append((nm, v))
        return -1
```

## 8. 边界情况与易错点

1. **$n = 1$**：初始状态即 `full`，出队返回 0。若把「判满」写在入队处而忘记初始层，就会漏掉这个情况。
2. **星形 / 链形图**：答案可能**大于** $n-1$。星形图 `0` 连 `1,2,3` 的答案是 4，等于 $2n-4$：从叶子出发、回中心、再去下一个叶子，几乎每条「叶子—中心」边都要走两次；而链 `0-1-2-3-4` 的答案是 $n-1=4$（从一端走到另一端即可）。不要误以为答案总是 $n-1$，也不要以为链形需要折返。
3. **完全图**：答案就是 $n-1$（存在哈密顿路径），BFS 会在第 $n-1$ 层首次取出 `full`。
4. **`mask` 与节点下标**：`1 << v` 与 `1 << i` 不要写混；`mask | (1 << v)` 才是「访问 v 后」的新集合。
5. **同 mask 不同节点不能合并**：这是最常见的 WA 原因。站在叶子与站在中心，对未来可走的路影响完全不同。
6. **出队判满 vs 入队判满**：两者都对，但入队判满要返回 `d + 1`，容易写成 `d`；初学建议统一用出队判满。
7. **重复访问边**：BFS 状态里已经隐含「可以重复走边」（同一个 `mask` 下的不同节点会被重新入队），不需要额外去重边。
8. **队列用 `deque`**：C++ 用 `std::deque` 或 `std::queue` 均可；这是 BFS，不要用 `stack`。

**延伸思考**：

- 若要求**回到起点**（周游回路），在 `mask == full` 时不能立即返回，需要继续 BFS 直到终点是起点，或在 DP 上取 $\min_u dp[full][u] + \operatorname{dist}(u, s)$ 对所有起点 $s$ 取最小——复杂度不变，但要额外记录「起点」或在最后一层做转移。
- 若边带权，BFS 要换成 Dijkstra（或在状态图上做优先队列），状态定义不变。
- 若 $n$ 增大到 $20$ 左右，$2^n n$ 状态已到 $2 \times 10^7$，需要把 `dist` 压成 `short`/`int8` 并考虑双向 BFS 或 A*。
- 与「旅行商问题（TSP）」的关系：本题是「允许重复访问的 TSP 路径版」，把状态压缩 DP 的转移从「未访问点」改成「任意邻居」，就得到同一个算法。
