# LeetCode 数组中的最长山脉 题解

## 1. 题目概述

- **标题 / 题号**：数组中的最长山脉（#845，medium）
- **链接**：https://leetcode.cn/problems/longest-mountain-in-array/
- **来源**：LeetCode 第 87 场周赛 Q2
- **难度**：中等
- **标签**：数组、双指针、动态规划、枚举

**题意**：若数组 `arr` 的某个**连续子数组** `B` 满足：

1. `B.length >= 3`；
2. 存在下标 $i$（$0 < i < B.length-1$），使得 $B[0] < B[1] < \cdots < B[i]$ 且 $B[i] > B[i+1] > \cdots > B[B.length-1]$，

则称 `B` 是**山脉数组**。返回 `arr` 中最长山脉子数组的长度；不存在则返回 `0`。

**约束**：

- $1 \le arr.length \le 10^4$
- $0 \le arr[i] \le 10^4$

> 💡 题面进阶要求「仅用一趟扫描」「$O(1)$ 空间」。本题解给出的扫描器同时满足这两点。

## 2. 示例

**示例 1**

```text
输入：arr = [2,1,4,7,3,2,5]
输出：5
解释：最长的山脉子数组是 [1,4,7,3,2]，长度 5（up = 4→7，共 2 步；down = 7→3→2，共 2 步）。
```

**示例 2**

```text
输入：arr = [2,2,2]
输出：0
解释：全是相等的元素，没有任何严格上升或严格下降，不存在山脉。
```

**补充示例**

```text
输入：arr = [1,2,3,4]
输出：0
解释：只有上升、没有下降，不是山脉；山脉要求「先上后下」两段都非空。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有子数组的左右端点 $(l, r)$，再花 $O(n)$ 检查它是否为山脉，总复杂度 $O(n^3)$，$n = 10^4$ 时是 $10^{12}$ 级别，不可行。

退一步：枚举**山峰**位置 $p$（满足 `arr[p-1] < arr[p] > arr[p+1]`），再向左右两侧扩展到不能再扩展为止，得到以 $p$ 为峰的最长山脉。单峰扩展是 $O(n)$，最坏 $O(n^2)$（例如「锯齿形」数组会让很多峰都有很长的坡），$10^8$ 在 Python 下会超时，也拿不到「一趟扫描」的加分。

### 3.2 核心观察：山脉 = 极大上升段 + 紧跟的极大下降段

![山脉 = 一段严格上升 + 一段严格下降](images/wc87_q2_mountain_shape_concept.svg)

把数组看成「相邻元素比较」组成的序列，每条边只有三种状态：**升**、**降**、**平**。那么：

- 山脉就是以某个**升**开头、紧跟一段连续**升**、再紧跟一段连续**降**的区间；
- 平边（相等）会同时打断上升与下降——所以山脉内部不能有相等相邻元素；
- 峰顶既不能在端点，也不能落在平边上。

于是不需要枚举左右端点：只要找到每一段「极大上升段」的起点，数一数它后面跟了多少步上升（`up`）、多少步下降（`down`），以这段坡为骨架的山脉长度就是

$$up + down + 1$$

（`+1` 是因为顶点被两段共享）。把所有峰扫一遍取最大值即可，且指针**只前进不回退**，天然是 $O(n)$。

![一次扫描：跳过 → 数 up → 数 down → 更新答案](images/wc87_q2_scan_flow.svg)

### 3.3 算法流程

```text
1. ans = 0，i = 1
2. while i < n:
3.     while i < n 且 arr[i] <= arr[i-1]: i++      // 跳过平边和下降边，停在「上升段的起点」
4.     up = 0
5.     while i < n 且 arr[i] > arr[i-1]: up++，i++ // 数连续上升步数
6.     down = 0
7.     while i < n 且 arr[i] < arr[i-1]: down++，i++ // 数连续下降步数
8.     若 up > 0 且 down > 0: ans = max(ans, up + down + 1)
9. 返回 ans
```

三点说明：

- 第 3 步的 `<=` 同时吃掉「平」和「降」，保证第 5 步开始时一定站在一条上升边上；
- 第 7 步之后 `i` 停在下降结束后的第一个位置，下一轮从那里继续，**不回退**；
- 只有 `up > 0` 且 `down > 0` 才可能构成山脉，否则这一段只是单调坡，直接丢弃。

### 3.4 示例演算

![示例演算：arr = [2,1,4,7,3,2,5] 的两次候选](images/wc87_q2_example_walkthrough.svg)

对 `arr = [2,1,4,7,3,2,5]`：

| 轮次 | 起点 i | up | down | 候选长度 up+down+1 | ans |
|------|--------|----|------|--------------------|-----|
| 1 | 2 | 2（4→7） | 2（7→3→2） | 5 | 5 |
| 2 | 6 | 1（2→5） | 0 | 不构成山脉 | 5 |

第 1 轮对应子数组 `[1,4,7,3,2]`，是最长山脉；第 2 轮只剩一段上升，末尾的 `5` 没有下降坡，不能形成山脉。答案为 `5`。

## 4. 算法细节

1. **严格比较**：上升用 `arr[i] > arr[i-1]`，下降用 `arr[i] < arr[i-1]`；相等既不升也不降，会自然截断山脉（如 `[1,3,3,2]` 不是山脉）。
2. **跳过条件的 `<=`**：必须包含等号，否则遇到平台或下降段时 `up` 与 `down` 都为 0，`i` 不前进会死循环。
3. **`up`、`down` 是「步数」而不是「点数」**：`up` 步上升连接 `up+1` 个点，`down` 步下降连接 `down+1` 个点，共享峰顶，所以长度是 `up + down + 1`。
4. **指针不回退**：第 7 步结束时 `i` 已经越过了下降段末尾，下一轮从当前位置继续，因此总额外开销是线性的。
5. **答案初值 0**：长度不足 3 或没有下降段时自然返回 0，不需要单独处理 `n < 3`（此时循环不会产生候选）。
6. **等价 DP 写法**：令 `up[i]` 为以 `i` 结尾的最长严格上升段长度、`down[i]` 为以 `i` 开头的最长严格下降段长度，答案为 $\max_{up[i]>0,\,down[i]>0} (up[i]+down[i]-1)$。这是 $O(n)$ 时间、$O(n)$ 空间，作为思路对照；本节的扫描器是它的 $O(1)$ 空间版本。

## 5. 正确性证明

**引理 1（每轮处理的区间是「极大上升段 + 紧随的极大下降段」）**：第 3 步结束时，若 `i < n`，则 `i` 是某个**极大上升段**的左端点，即 `arr[i] > arr[i-1]`，且当 `i >= 2` 时 `arr[i-1] <= arr[i-2]`。

**证明**：第 3 步的条件 `arr[i] <= arr[i-1]` 在循环停止时变为假，即 `arr[i] > arr[i-1]`；而在此之前每一条被跳过的边都满足 `arr[k] <= arr[k-1]`，特别地 `arr[i-1] <= arr[i-2]`（当 `i-1 >= 1`）。故 `i` 处的上升边左侧不存在与之相连的上升边，是极大上升段的起点。∎

**引理 2（第 5、7 步数出的是完整的坡）**：从极大上升段起点出发，第 5 步数出的 `up` 恰好是该上升段的步数，第 7 步数出的 `down` 恰好是峰后极大下降段的步数；且 `up > 0` 当且仅当该段确实有上升边。

**证明**：第 5 步在 `arr[i] > arr[i-1]` 时持续前进，直到第一条非上升边为止，由极大性这正是整个上升段；第 7 步在 `arr[i] < arr[i-1]` 时持续前进，直到第一条非下降边为止，正是峰后的极大下降段。∎

**引理 3（每个峰恰好被枚举一次）**：每个满足 `arr[p-1] < arr[p] > arr[p+1]` 的峰 $p$，都恰好是某一轮第 5 步数出的上升段的**右端点**（最后一个顶点），且该轮第 7 步会从 $p$ 起继续数下降。

**证明**：由 `arr[p-1] < arr[p]`，边 $p-1 \to p$ 是上升边，属于某条极大上升段；由 `arr[p] > arr[p+1]`，$p$ 之后的第一条边不是上升边，故 $p$ 正是该极大上升段的右端点。极大上升段两两不相交且覆盖所有上升边，而每轮恰好处理一条极大上升段（引理 2），故 $p$ 只被处理一次。∎

**定理**：算法返回 `arr` 中最长山脉子数组的长度。

**证明**：

- **可行性**：每轮候选 `up+down+1` 对应子数组 `arr[l .. l+up+down]`，其中 `l` 为该轮起点。它先严格上升 `up` 步、再严格下降 `down` 步（引理 2），峰顶不在端点（`up>0`、`down>0`），长度不小于 3，所以是一个合法山脉，故 `ans` 不超过真实答案。
- **最优性**：设最长山脉为 `arr[l .. r]`，峰为 $p$。其上升部分必须以 $p$ 结尾且严格递增，下降部分必须以 $p$ 开头且严格递减；把两侧各扩展到极大，得到包含 `arr[l..r]` 的、以 $p$ 为峰的山脉，长度不小于 `arr[l..r]`。由引理 3，处理 $p$ 所在上升段的那一轮恰好枚举了这个极大山脉，其候选值不小于最长山脉长度；又由可行性它不超过最长山脉长度，故相等。

两部分合起来，`ans` 恰为最长山脉长度。∎

## 6. 复杂度分析

- **时间**：$O(n)$。第 3、5、7 步中的 `i++` 各自单调，`i` 在外层循环中总共前进至多 $n$ 次，每轮至少前进 1 步，故总操作数与 $n$ 同阶。
- **空间**：$O(1)$。只用了 `i`、`up`、`down`、`ans` 四个整型变量，没有额外数组。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int longestMountain(vector<int>& arr) {
        int n = (int)arr.size();
        int ans = 0;
        int i = 1;
        while (i < n) {
            while (i < n && arr[i] <= arr[i - 1]) i++;
            int up = 0;
            while (i < n && arr[i] > arr[i - 1]) { up++; i++; }
            int down = 0;
            while (i < n && arr[i] < arr[i - 1]) { down++; i++; }
            if (up > 0 && down > 0) ans = max(ans, up + down + 1);
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def longestMountain(self, arr: list[int]) -> int:
        n = len(arr)
        ans = 0
        i = 1
        while i < n:
            # 跳到一段严格上升的起点（同时吃掉平边与下降边）
            while i < n and arr[i] <= arr[i - 1]:
                i += 1
            up = 0
            while i < n and arr[i] > arr[i - 1]:
                up += 1
                i += 1
            down = 0
            while i < n and arr[i] < arr[i - 1]:
                down += 1
                i += 1
            if up > 0 and down > 0:
                ans = max(ans, up + down + 1)
        return ans
```

## 8. 边界情况与易错点

1. **`n < 3`**：不可能有山脉，循环不会产生候选，返回 0。不能漏掉这个下界。
2. **全相等**：如示例 2，第 3 步把整个数组跳完，返回 0。
3. **单调递增 / 单调递减**：`up` 或 `down` 有一个为 0，不更新答案；注意 `[1,2,3,4]` 返回 0 而不是 4。
4. **相等元素切断山脉**：`[1,3,3,2]` 中 `3 == 3` 使峰顶落在平边上，正确答案是 0；代码里下降循环要求严格小于，`down` 停在平边处为 0，正确。
5. **峰顶在端点**：`[1,2,3]` 的「峰」在最后一个位置，不满足 `down > 0`，不统计。
6. **跳过条件写成 `<` 会死循环**：若把第 3 步写成 `arr[i] < arr[i-1]`，遇到相等元素时 `i` 不前进，且 `up`、`down` 也都为 0，死循环。
7. **长度公式别写成 `up + down`**：峰顶被两段共享，必须 `+1`。
8. **多峰相邻**：`[1,3,2,4,3,2]` 有两个峰，扫描器会在两轮中分别处理 `[1,3,2]` 与 `[3,4,3,2]`，答案取 4，不会漏解。
