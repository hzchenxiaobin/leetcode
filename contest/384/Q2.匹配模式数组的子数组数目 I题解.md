# LeetCode 匹配模式数组的子数组数目 I 题解

## 1. 题目概述

- **标题 / 题号**：匹配模式数组的子数组数目 I（#3034，medium）
- **链接**：https://leetcode.cn/problems/number-of-subarrays-that-match-a-pattern-i/
- **来源**：LeetCode 第 384 场周赛 Q2
- **难度**：中等
- **标签**：数组、字符串匹配、哈希函数、滚动哈希

**题意**：给定长度为 $n$ 的整数数组 `nums` 和长度为 $m$ 的模式数组 `pattern`（元素只含 $-1, 0, 1$）。一个大小为 $m+1$ 的子数组 `nums[i..i+m]` 匹配 `pattern`，当且仅当对每个 $k \in [0, m)$：

- `pattern[k] == 1` 时 `nums[i+k+1] > nums[i+k]`；
- `pattern[k] == 0` 时 `nums[i+k+1] == nums[i+k]`；
- `pattern[k] == -1` 时 `nums[i+k+1] < nums[i+k]`。

返回匹配 `pattern` 的子数组**数目**。

**约束**：

- $2 \le n \le 100$
- $1 \le nums[i] \le 10^9$
- $1 \le m < n$，$-1 \le pattern[i] \le 1$

## 2. 示例

**示例 1**

```text
输入：nums = [1,2,3,4,5,6], pattern = [1,1]
输出：4
解释：模式 [1,1] 表示找长度为 3 且严格上升的子数组。
      [1,2,3]、[2,3,4]、[3,4,5]、[4,5,6] 均匹配，共 4 个。
```

**示例 2**

```text
输入：nums = [1,4,4,1,3,5,5,3], pattern = [1,0,-1]
输出：2
解释：[1,4,4,1]（升、平、降）与 [3,5,5,3] 均匹配，共 2 个。
```

**补充示例（答案为 0）**

```text
输入：nums = [3,2,1], pattern = [1]
输出：0
解释：cmp = [−1,−1]，两个窗口都不是 [1]，无匹配。
```

## 3. 解题思路

### 3.1 暴力思路

对每个长度为 $m+1$ 的子数组起点 $i \in [0, n-m-1]$，逐条检查 $m$ 个相邻对是否满足 `pattern[k]` 约束，满足则计数。时间 $O(nm) \le 100 \times 99 \approx 10^4$，本题数据范围下直接可过。**问题在于**：若直接在 `nums` 上比较，每一步都要写三分支判断，代码冗长且容易漏分支；更重要的是，当 $n$ 放大到 $10^6$（同场 Q4）时 $O(nm)$ 会超时——暴力没有揭示问题的**本质结构**。

### 3.2 核心观察：相邻关系压成三值符号序列 → 字符串匹配

![核心观察：符号化与子串判等](images/subarr_pattern_sign_concept.svg)

**关键观察**：`pattern` 约束的从来不是 `nums` 的**数值**，只是相邻元素的**大小关系**（升 / 平 / 降）。定义符号数组：

$$cmp[i] = \mathrm{sign}\big(nums[i+1] - nums[i]\big) \in \{-1, 0, 1\}, \quad i \in [0, n-2]$$

则三条匹配规则恰好对应"$cmp[i+k] = pattern[k]$"，于是：

> 子数组 `nums[i..i+m]` 匹配 `pattern` $\iff$ `cmp[i..i+m-1]` 与 `pattern` **逐位相等**。

`cmp` 可看作一个"字符集为 $\{-1,0,1\}$ 的字符串"，问题瞬间降维成**统计模式串 `pattern` 在文本 `cmp` 中（可重叠）出现的次数**——经典字符串匹配。$n \le 100$ 时逐窗口比对即可；Q4 中换 KMP / 滚动哈希即可平推。

### 3.3 算法流程

![算法流程图](images/subarr_pattern_flow.svg)

1. 一遍扫描构建 `cmp`（长度 $n-1$）；
2. 枚举窗口起点 $i \in [0, n-m-1]$（共 $n-m$ 个窗口）；
3. 逐位比较 `cmp[i..i+m-1]` 与 `pattern`，全等则 `ans++`（首位不等即提前退出）；
4. 枚举结束返回 `ans`。

### 3.4 示例演算

![示例 2 演算表](images/subarr_pattern_walkthrough.svg)

以示例 2 为例，`nums = [1,4,4,1,3,5,5,3]`，`pattern = [1,0,-1]`：

| 步骤 | 内容 | 结果 |
|------|------|------|
| 1 | 相邻差取符号 | cmp = [1, 0, −1, 1, 1, 0, −1] |
| 2 | 窗口 i=0 | [1,0,−1] = pattern ✓ |
| 3 | 窗口 i=1,2,3 | [0,−1,1] / [−1,1,1] / [1,1,0] ✗ |
| 4 | 窗口 i=4 | [1,0,−1] = pattern ✓ |
| 5 | 汇总 | ans = 2 ✓ |

## 4. 算法细节

1. **符号函数三值化**：`cmp[i] = (d > 0) - (d < 0)`，其中 `d = nums[i+1] - nums[i]`。这一步把"比较语义"编码成与 `pattern` 同值域的整数，是整个转化的核心。
2. **窗口口径**：`cmp` 长度为 $n-1$，长度为 $m$ 的窗口共 $(n-1)-m+1 = n-m$ 个，恰等于大小为 $m+1$ 的子数组个数——两个口径天然一致，枚举 `i ∈ [0, n-m-1]` 即可。
3. **提前剪枝**：逐位比较时遇到第一个不等位即 `break`，窗口首位不等的情况只需 $O(1)$。
4. **向 Q4 的迁移**：同场 Q4（#3036）将 $n$ 放大到 $10^6$，$O(nm)$ 不可接受；把第 3 步换成 KMP / Z 函数（或把 $-1,0,1$ 映射到 $1,2,3$ 后做滚动哈希）即可 $O(n+m)$ 解决，符号化转化完全复用。

## 5. 正确性证明

**引理 1（等价转化）**：对任意起点 $i$，子数组 `nums[i..i+m]` 匹配 `pattern` 当且仅当对每个 $k \in [0, m)$ 都有 $cmp[i+k] = pattern[k]$。

**证明**：`pattern[k]` 的三条规则分别要求相邻差 $d_k = nums[i+k+1] - nums[i+k]$ 为正、为零、为负。而 $\mathrm{sign}$ 恰好把 $d_k > 0$、$d_k = 0$、$d_k < 0$ 一一映射到 $1$、$0$、$-1$，故"规则 $k$ 成立 $\iff cmp[i+k] = pattern[k]$"。对 $m$ 条规则逐条取交即得引理。∎

**引理 2（窗口一一对应）**：长度为 $m+1$ 的子数组起点集合与 `cmp` 中长度为 $m$ 的窗口起点集合相同，均为 $\{0, 1, \ldots, n-m-1\}$，共 $n-m$ 个。

**证明**：子数组起点 $i$ 需满足 $i + m \le n - 1$；`cmp` 长度为 $n-1$，窗口起点 $i$ 需满足 $i + m - 1 \le n - 2$，即 $i + m \le n - 1$。两者约束相同，且同一 $i$ 的窗口 `cmp[i..i+m-1]` 恰描述子数组 `nums[i..i+m]` 内部的全部相邻关系。∎

**定理**：算法返回值等于匹配 `pattern` 的子数组数目。

**证明**：算法枚举的正是引理 2 给出的全部 $n-m$ 个起点，不多不少；对每个起点，由引理 1，"窗口与 `pattern` 逐位相等"与"子数组匹配"等价，算法的计数即匹配子数组的个数。∎

## 6. 复杂度分析

- **时间复杂度**：$O(nm)$。构建 `cmp` 为 $O(n)$；$n-m$ 个窗口、每窗至多 $m$ 次比较。$n \le 100$ 时约 $10^4$ 次操作，轻松通过；换成 KMP 后为 $O(n+m)$（Q4 的要求）。
- **空间复杂度**：$O(n)$。符号数组 `cmp` 占 $n-1$ 个整数；若不显式建 `cmp` 而是现场计算 `sign`，可降到 $O(1)$ 额外空间。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int countMatchingSubarrays(vector<int>& nums, vector<int>& pattern) {
        int n = nums.size(), m = pattern.size();
        vector<int> cmp(n - 1);
        for (int i = 0; i + 1 < n; i++) {
            int d = nums[i + 1] - nums[i];
            cmp[i] = (d > 0) - (d < 0);   // sign：1 / 0 / -1
        }
        int ans = 0;
        for (int i = 0; i + m <= n - 1; i++) {   // i ∈ [0, n-m-1]，共 n-m 个窗口
            bool ok = true;
            for (int k = 0; k < m; k++) {
                if (cmp[i + k] != pattern[k]) { ok = false; break; }
            }
            ans += ok;
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def countMatchingSubarrays(self, nums: List[int], pattern: List[int]) -> int:
        n, m = len(nums), len(pattern)
        sign = lambda x: (x > 0) - (x < 0)
        cmp_arr = [sign(nums[i + 1] - nums[i]) for i in range(n - 1)]
        return sum(cmp_arr[i:i + m] == pattern for i in range(n - m))
```

## 8. 边界情况与易错点

1. **不能拿差值直接和 `pattern` 比较**：`nums[i+k+1] - nums[i+k] == pattern[k]` 是典型错误——差值可能是 $\pm 5$ 等任意正负数，必须先取符号。这是本题最易犯的错。
2. **符号函数写法**：用 `(d > 0) - (d < 0)`；`d / abs(d)` 在 $d = 0$ 时除零，`sign` 无分支写法最稳。
3. **窗口数量口径**：答案窗口数是 $n - m$（不是 $n - m - 1$，也不是按 `cmp` 长度误算的 $n - 2$），见引理 2。Python 切片 `cmp_arr[i:i+m]` 越界时变短、不会误判相等，但显式 `range(n - m)` 语义更清晰。
4. **溢出**：$1 \le nums[i] \le 10^9$，相邻差绝对值 $< 10^9$，`int`（上限约 $2.1 \times 10^9$）安全；若值域更大需改 `long long`。
5. **答案可为 0**：如递减数组配 `pattern = [1]`，不要对 0 做特判。
6. **`m < n` 由题设保证**：`cmp` 至少长度 1，不存在空数组；但 `m = n - 1` 时仅一个窗口，循环边界仍正确。
7. **不建 `cmp` 直接双层判也能过**（$O(nm)$ 相同），但显式符号化让"字符串匹配"结构浮出水面，是通向 Q4 的钥匙。
