# LeetCode 回文字符串的最大数量 题解

## 1. 题目概述

- **标题 / 题号**：回文字符串的最大数量（#3035，medium）
- **链接**：https://leetcode.cn/problems/maximum-palindromes-after-operations/
- **来源**：LeetCode 第 384 场周赛 Q3
- **难度**：中等
- **标签**：贪心、数组、哈希表、字符串、计数、排序

**题意**：给定字符串数组 `words`（长度 $n$）。一次操作可选择任意两个位置——可以在同一个词内，也可以跨词——交换其中的字符，操作可执行**任意次**。返回若干操作后 `words` 中**回文串的最大数量**。

**约束**：

- $1 \le \text{words.length} \le 1000$
- $1 \le \text{words}[i].\text{length} \le 100$，总字符数不超过 $10^5$
- `words[i]` 仅由小写英文字母组成

> ⚠️ 读题关键：操作只**挪动**字符、不增删字符，所以每个词的**长度永远不变**——「词长」是每个词的固有属性，而「词里装哪些字符」是完全自由的。看穿这一点，题目瞬间退化。

## 2. 示例

**示例 1**

```text
输入：words = ["abbb","ba","aa"]
输出：3
解释：交换 words[0][0] 与 words[1][0]，words 变为 ["bbbb","aa","aa"]，
      三个串全部是回文。
```

**示例 2**

```text
输入：words = ["abc","ab"]
输出：2
解释：两次交换后 words 变为 ["aca","bb"]，两个串都是回文。
```

**示例 3**

```text
输入：words = ["cd","ef","a"]
输出：1
解释：所有字母互不相同，凑不出任何一对同字符；
      只有长度 1 的 "a" 天然是回文。
```

**补充示例（答案为 0）**

```text
输入：words = ["abc"]
输出：0
解释：Q = 0（无同字符对），造价 ⌊3/2⌋ = 1 买不起。
```

**补充示例（贪心方向）**

```text
输入：words = ["cd","ef","aabbcc"]
输出：2
解释：Q = 3。先买造价 1、1 的两个短词得 2 个回文（剩 Q = 1 < 3）；
      若先买造价 3 的长词（"aabbcc" → "abccba"），预算清零只剩 1 个。
```

## 3. 解题思路

### 3.1 暴力思路

最朴素的方向是枚举「哪些词最终成为回文」这个子集再验证：子集有 $2^n$ 个（$n \le 1000$）直接爆炸；而真的去模拟一串串交换操作更无从下手——操作可以任意嵌套，搜索空间无限大。突破口在于先翻译「操作」的真实含义：**任意两处字符可以交换（含词内），由交换的传递性，这等价于把全部字符倒进一个池子，再任意装回各个词**——唯一的限制是每个词长度不变。无限的交换序列由此被压缩成一个有限的多重集合划分问题，$2^n$ 的子集枚举也能被贪心一步到位。

### 3.2 核心观察：字符全池化 + 成对预算 + 按造价升序贪心

![核心观察：字符全池化，词长是唯一不变量](images/palin_ops_pool_concept.svg)

**观察 1（全池化）**：所有字符可任意重新分配到任何槽位，唯一不变的是每个词的长度 $L_i$。

**观察 2（回文的造价）**：长度为 $L$ 的回文串由 $\lfloor L/2 \rfloor$ 对**同字符**的镜像位，加上（$L$ 为奇数时）1 个**任意字符**的中间位构成。设全局字符频率为 $f_c$，则字符池最多能提供

$$Q = \sum_{c='a'}^{'z'} \lfloor f_c / 2 \rfloor$$

对同字符，这是唯一的硬预算。

**观察 3（中间位免预算）**：奇数长度词的中间位可以是**任何**字符，甚至来自「拆开的一对」——总量上已选词的总长不超过全局总长，剩余字符永远够填中心（严格论证见 §5 定理 1）。

于是问题变成：**预算 $Q$，每个词的造价是 $\lfloor L_i/2 \rfloor$，每买一件 +1 个回文，最多买几件？** 每件收益相同，当然从最便宜的买起——把词长**升序排序**，逐个扣减 $Q$，扣不动为止。

> 💡 **贪心方向反例**：`words = ["cd","ef","aabbcc"]`，$Q = 3$，造价 $[1, 1, 3]$。先买两个造价 1 的短词得 2 个回文；若先买造价 3 的长词，预算清零只得 1 个。**便宜优先才能最大化件数**。

### 3.3 算法流程

![算法流程图](images/palin_ops_greedy_flow.svg)

1. 遍历所有词，统计全局字符频率 `freq[26]`；
2. 求预算 $Q = \sum \lfloor \text{freq}[c]/2 \rfloor$；
3. 词长升序排序（造价 $\lfloor L/2 \rfloor$ 随 $L$ 单调不减，排长度即排造价）；
4. 逐词扣预算：`pairs ≥ ⌊L/2⌋` 则扣减并 `ans++`，否则 `break`（后面造价只高不低）；
5. 返回 `ans`。

### 3.4 示例演算

![示例 1 演算表](images/palin_ops_walkthrough.svg)

以示例 1 `words = ["abbb","ba","aa"]` 走一遍完整流程：

| 步骤 | 操作 | 结果 |
|------|------|------|
| 1 | 全局字符计数 | $f_a = 4$，$f_b = 4$ |
| 2 | 求预算 | $Q = 2 + 2 = 4$ |
| 3 | 词长升序排序 | $[2, 2, 4]$，造价 $[1, 1, 2]$ |
| 4 | 逐词扣预算 | 造价 1：$Q{:}4{\to}3$；造价 1：$3{\to}2$；造价 2：$2{\to}0$ |

最终 `ans = 3`，一种具体分配是 $[\text{"aa"}, \text{"aa"}, \text{"bbbb"}]$，与示例一致。顺带验证示例 3 `["cd","ef","a"]`：每个字符都只出现 1 次，$Q = 0$；长度 1 的词造价 0「白拿」（`"a"` 本身就是回文），长度 2 的词造价 1 买不起，故 `ans = 1`。

## 4. 算法细节

1. **频率与预算**：`freq[26]` 一遍扫描所有字符；$Q$ 是全池**不相交同字符对**的上限（引理 2），与字符具体落在哪个词无关。
2. **造价即长度**：$c_i = \lfloor L_i/2 \rfloor$ 关于 $L_i$ 单调不减，所以**排序词长（整数）等价于排序造价**，不必搬动字符串本体。
3. **扣减循环**：升序扫描，`pairs < L/2` 即 `break`——由单调性，后面的词只会更贵，继续扫也不可能再买到。
4. **中间位为什么免预算**：中心字符没有任何身份要求，且已选集合总长 $\le$ 全局总长保证剩余字符够用；「拆开一对」还能提供两个中心候选（构造见 §5 定理 1）。
5. **数据规模**：$n \le 1000$，$L \le 100$，$Q \le 5 \times 10^4$，全程 `int` 无溢出风险。

## 5. 正确性证明

**引理 1（全池化）**：任意多次操作后 `words` 的可达状态集合，恰为「各词长度不变、全局字符多重集不变」的所有填充方案。

**证明**：每次交换不改变任何词的长度与全局多重集，故可达状态必满足这两条。反之，任取满足这两条的目标填充，它与初始状态在每个词内部都是同一长度向量上的两个排列；由对换生成定理（冒泡排序原理），任意排列可由若干次「交换两个位置」复合得到，而每次这样的交换恰是题述操作（词内取 $i = j$，跨词取 $i \ne j$），故目标填充可达。∎

**引理 2（对数上界）**：从全局多重集（字符 $c$ 共 $f_c$ 个）中取出两两不交的同字符对，至多 $Q = \sum_c \lfloor f_c/2 \rfloor$ 对，且该上界可以取到。

**证明**：同字符对只能由同种字符组成，$f_c$ 个字符 $c$ 至多配出 $\lfloor f_c/2 \rfloor$ 对互不重叠的对；逐字符求和即得上界。取等构造：每种字符内部顺次两两配对即可。∎

**定理 1（可行集刻画）**：词集合 $S$ 可以同时变成回文 $\iff$ $\sum_{i \in S} \lfloor L_i/2 \rfloor \le Q$。

**证明**：
（⇒）设 $S$ 中每个词已排成回文。词 $i$ 的 $\lfloor L_i/2 \rfloor$ 组镜像位每组的两个位置字符相同，构成同字符对；不同词、不同组占用的位置互不重叠，故这些同字符对两两不交，由引理 2 其总数 $\le Q$。
（⇐）设 $P = \sum_{i \in S} \lfloor L_i/2 \rfloor \le Q$。由引理 2 的取等构造取出 $P$ 对同字符，给词 $i$ 的镜像位分 $\lfloor L_i/2 \rfloor$ 对。设 $M$ 为 $S$ 中奇长词个数，已选词总长 $2P + M = \sum_{i \in S} L_i \le T$（$T$ 为全局总字符数），故池中剩余 $T - 2P \ge M$ 个字符，任取 $M$ 个填中心位。最后剩余 $T - \sum_{i \in S} L_i$ 个字符的个数恰等于未选词的长度总和，任意填入即可。由引理 1，该填法可通过操作达到。∎

**定理 2（升序贪心最优）**：把造价 $c_i = \lfloor L_i/2 \rfloor$ 升序排序后从前到后「能买则买」，所得件数即最大回文数。

**证明**：贪心按序尝试，能买到前 $k$ 个词当且仅当前缀和 $C_k \le Q$。设贪心停在第 $k+1$ 个词，则 $Q - C_k < c_{k+1}$，即 $C_{k+1} > Q$。任意 $k+1$ 个词的造价和至少为最小的 $k+1$ 个造价之和 $C_{k+1} > Q$，由定理 1 不可行，故任何方案至多 $k$ 个回文；贪心恰好取得 $k$ 个。若贪心买完全部 $n$ 个词，则 $n$ 即上界。∎

## 6. 复杂度分析

- **时间复杂度**：$O(\sum L_i + n \log n)$。遍历计数 $O(\sum L_i) \le 10^5$；词长排序 $O(n \log n)$，$n \le 1000$；扣预算一轮 $O(n)$。
- **空间复杂度**：$O(n)$。词长数组占 $n$ 个整数；频率仅 26 个整数，视为 $O(1)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maxPalindromesAfterOperations(vector<string>& words) {
        int freq[26] = {0};
        for (const auto& w : words)
            for (char c : w) ++freq[c - 'a'];

        int pairs = 0;                              // 预算 Q：全局同字符对总数
        for (int c : freq) pairs += c / 2;

        vector<int> lens;
        for (const auto& w : words) lens.push_back((int)w.size());
        sort(lens.begin(), lens.end());             // 造价 ⌊L/2⌋ 随 L 单调，排长度即排造价

        int ans = 0;
        for (int L : lens) {
            if (pairs < L / 2) break;                // 造价单调不减，后面必然更贵
            pairs -= L / 2;
            ++ans;
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maxPalindromesAfterOperations(self, words: List[str]) -> int:
        freq = Counter(c for w in words for c in w)
        pairs = sum(v // 2 for v in freq.values())   # 预算 Q
        ans = 0
        for L in sorted(map(len, words)):            # 造价升序
            if pairs < L // 2:
                break                               # 后面造价更高，直接终止
            pairs -= L // 2
            ans += 1
        return ans
```

## 8. 边界情况与易错点

1. **忘掉全池化、逐词判断**：必须先看穿「任意交换 ⇒ 字符自由流动」，只盯着单个词的字符奇偶性（409 题式的判定）会完全做错方向。
2. **中间位单独设预算**：不必要且会算错。如 `["a","a","a"]`：$Q = 1$，三个词造价均为 0，全部是回文——中心可以拆对来凑，永远不构成瓶颈（定理 1）。
3. **贪心方向**：必须**升序**。反例 `["cd","ef","aabbcc"]`（$Q = 3$）：升序得 2，先买长词只 1。
4. **`break` 依赖升序的单调性**：只有排序后「当前买不起 ⇒ 后面都买不起」才成立；未排序只能老实 `continue`（或先排序再 `break`）。
5. **答案可为 0**：如 `words = ["abc"]`（$Q = 0$ 买不起造价 1），不要特判。
6. **长度 1 的词造价 0**：「白拿」的回文，但它仍消耗一个中心字符——不过定理 1 保证这不影响可行性。
7. **排序对象**：只排 `int` 词长，不要排序字符串本体（无谓的搬动开销，比较器也复杂）。
8. **$i = j$ 的操作是合法的**：题面明说可以在词内交换，这正是引理 1 里「词内重排」的依据。
