# LeetCode 修改矩阵 题解

## 1. 题目概述

- **标题 / 题号**：修改矩阵（#3033，easy）
- **链接**：https://leetcode.cn/problems/modify-the-matrix/
- **来源**：LeetCode 第 384 场周赛 Q1
- **难度**：简单
- **标签**：数组、矩阵

**题意**：给定一个 $m \times n$ 的整数矩阵 `matrix`（下标从 0 开始），新建矩阵 `answer` 并使其与 `matrix` 相同，然后将其中每个值为 `-1` 的元素替换为**所在列的最大元素**，返回 `answer`。

**约束**：

- $2 \le m, n \le 50$
- $-1 \le matrix[i][j] \le 100$
- 测试用例保证**每列至少包含一个非负整数**

## 2. 示例

**示例 1**

```text
输入：matrix = [[1,2,-1],[4,-1,6],[7,8,9]]
输出：[[1,2,9],[4,8,6],[7,8,9]]
解释：列 0/1/2 的最大值分别为 7、8、9。
     [0][2] 的 -1 替换为列 2 的最大值 9；
     [1][1] 的 -1 替换为列 1 的最大值 8。
```

**示例 2**

```text
输入：matrix = [[3,-1],[5,2]]
输出：[[3,2],[5,2]]
解释：列 1 的最大值为 2，[0][1] 的 -1 替换为 2。
```

**补充示例（同一列多个 -1）**

```text
输入：matrix = [[5,-1,-1],[-1,4,2],[3,1,-1]]
输出：[[5,4,2],[5,4,2],[3,1,2]]
解释：colMax = [5, 4, 2]。列 2 有两个 -1，都替换为 2。
```

## 3. 解题思路

### 3.1 朴素思路

对每个值为 `-1` 的格子 $(i, j)$，重新扫描第 $j$ 列的所有元素求最大值并填入。最坏情况下有 $O(m)$ 个 `-1`，每次扫一列 $O(m)$，总计 $O(m^2 n)$。本题 $m, n \le 50$，最多约 $1.25 \times 10^5$ 次操作也能通过，但同一列的最大值被重复计算了许多遍——**列最大值只依赖列号 $j$，与行号无关**，一次预计算即可消除全部冗余。

### 3.2 核心观察：列最大值与 -1 天然隔离

![核心观察：列最大值与 -1 的关系](images/modify_matrix_concept.svg)

**关键观察**：约束保证每列至少有一个非负整数，因此列最大值满足

$$\text{colMax}[j] \ge 0 > -1$$

由此直接得到三个结论：

1. **`-1` 永远不会成为列最大值**——求列最大值时无需过滤 `-1`，对整列直接取 `max` 即可；
2. **替换值严格大于 `-1`**——替换后不会再产生新的 `-1`，一遍替换即收敛；
3. **替换不改变列最大值**——填入的值本身就是该列最大值（见 §5 引理 2），因此各 `-1` 的替换顺序、先后关系互不影响。

### 3.3 算法流程

![修改矩阵算法流程图](images/modify_matrix_flow.svg)

两遍扫描：

1. **第一遍**：对每列 $j$ 求最大值 $\text{colMax}[j]$；
2. **第二遍**：复制 `matrix` 到 `answer`，遍历所有格子，遇到 `-1` 就填入 $\text{colMax}[j]$。

### 3.4 示例演算

![示例 1 的替换过程演算](images/modify_matrix_walkthrough.svg)

以示例 1 为例，`matrix = [[1,2,-1],[4,-1,6],[7,8,9]]`：

| 步骤 | 内容 | 结果 |
|------|------|------|
| 1 | 求各列最大值 | colMax = [7, 8, 9] |
| 2 | 复制矩阵 | answer = matrix |
| 3 | 扫到 [0][2] = -1 | 填入 colMax[2] = 9 |
| 4 | 扫到 [1][1] = -1 | 填入 colMax[1] = 8 |
| 5 | 扫描结束 | answer = [[1,2,9],[4,8,6],[7,8,9]] ✓ |

## 4. 算法细节

1. **列最大值预计算**：C++ 用一维数组 `colMax` 初始化为 `-1`（值域下界），双重循环逐格取 `max`；Python 用 `zip(*matrix)` 把矩阵按列转置，直接对每列 `max()`，一行完成。
2. **复制矩阵**：C++ 直接 `vector<vector<int>> answer = matrix;` 值拷贝；Python 用列表推导逐行复制，避免内外层列表共享引用。
3. **替换条件**：仅当 `matrix[i][j] == -1` 时写 `colMax[j]`，其余值原样保留。
4. **顺序要求**：必须**先完整求出每列最大值、再统一替换**，不能边扫描边用"当前前缀最大值"替换（陷阱见 §8 第 2 条）。

## 5. 正确性证明

**引理 1**：对任意列 $j$，$\text{colMax}[j] \ge 0$，从而 $\text{colMax}[j] > -1$。

**证明**：由题设，第 $j$ 列至少含一个非负整数 $x \ge 0$。$\text{colMax}[j]$ 是该列全体元素（包含 $x$）的最大值，故 $\text{colMax}[j] \ge x \ge 0 > -1$。∎

**引理 2**：将第 $j$ 列中任意个 `-1` 替换为 $\text{colMax}[j]$ 后，该列的最大值仍为 $\text{colMax}[j]$。

**证明**：替换仅发生在值为 `-1` 的格子，替换值为 $\text{colMax}[j]$ 本身；其余格子的值不变。替换后该列的最大值不超过原最大值 $\text{colMax}[j]$（新填入的值恰等于它）；又取得该最大值的那个非 `-1` 元素仍在列中，故最大值仍为 $\text{colMax}[j]$。∎

**定理**：算法返回的矩阵与题目定义的 `answer` 逐格相等。

**证明**：题目定义 `answer` 为 `matrix` 的副本中把每个 `-1` 替换为"所在列的最大元素"。设原矩阵第 $j$ 列最大值为 $\text{colMax}[j]$，算法对每个 $(i, j)$：若 $matrix[i][j] = -1$ 则输出 $\text{colMax}[j]$，否则输出原值，与定义逐格一致。若把"所在列的最大元素"理解为替换**过程中**的列最大值，由引理 2 其值仍为 $\text{colMax}[j]$，两种理解结果相同。∎

## 6. 复杂度分析

- **时间复杂度**：$O(mn)$。两遍扫描，每遍对每个格子做常数次操作；求列最大值与替换各贡献一遍。
- **空间复杂度**：$O(n)$ 为辅助数组 `colMax`（输出矩阵 $O(mn)$ 为题目要求返回的结果，通常不计入；若允许原地修改可省去复制，额外空间降至 $O(n)$）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<vector<int>> modifiedMatrix(vector<vector<int>>& matrix) {
        int m = matrix.size(), n = matrix[0].size();
        vector<int> colMax(n, -1);
        for (int i = 0; i < m; i++)
            for (int j = 0; j < n; j++)
                colMax[j] = max(colMax[j], matrix[i][j]);

        vector<vector<int>> answer = matrix;
        for (int i = 0; i < m; i++)
            for (int j = 0; j < n; j++)
                if (answer[i][j] == -1)
                    answer[i][j] = colMax[j];
        return answer;
    }
};
```

### Python

```python
class Solution:
    def modifiedMatrix(self, matrix: List[List[int]]) -> List[List[int]]:
        col_max = [max(col) for col in zip(*matrix)]
        return [[col_max[j] if x == -1 else x for j, x in enumerate(row)]
                for row in matrix]
```

## 8. 边界情况与易错点

1. **"每列至少一个非负整数"是题设保证**：因此整列直接取 `max` 无需排除 `-1`（引理 1）。若去掉该保证（某列可能全为 `-1`），必须先过滤 `-1` 再取最大值，否则会把 `-1` 本身当作列最大值。
2. **"前缀 max"陷阱**：若按行扫描、边扫边用"当前已见到的该列前缀最大值"替换，会出错。例如列 $[2, -1, 5]$：扫到 `-1` 时前缀最大值是 2，错填 2，而正确答案是 5。**必须先求完整列最大值，再统一替换。**
3. **`colMax` 初始化**：初始化为 `-1`（值域下界）即可被任何非负数覆盖；初始化为 0 在本题保证下碰巧也正确（列最大值 $\ge 0$），但以值域下界初始化更稳健、不依赖隐含保证。
4. **新建矩阵 vs 原地修改**：题目要求新建 `answer`。原地修改后返回在逻辑上也正确（由引理 2，替换值恰为列最大值，不影响后续替换），但先复制再替换更贴合题意。
5. $m, n \ge 2$：不存在空矩阵或空行，无需特判空输入。
