# LeetCode 统计为蚁群构筑房间的不同顺序 题解

## 1. 题目概述

- **标题 / 题号**：统计为蚁群构筑房间的不同顺序（#1916，hard）
- **链接**：https://leetcode.cn/problems/count-ways-to-build-rooms-in-an-ant-colony/
- **来源**：LeetCode 第 247 场周赛 Q4
- **难度**：困难
- **标签**：树、树形 DP、组合数学、数学、深度优先搜索、拓扑排序、费马小定理

**题意**：要构筑 $n$ 间编号 $0$ 到 $n-1$ 的房间，数组 `prevRoom` 给出扩建计划：构筑房间 $i$ 之前必须先构筑 `prevRoom[i]`，且两个房间直接相连；房间 $0$ 已建成（`prevRoom[0] = -1`）。一次只能构筑一个房间，但可以在已建成的相连房间之间自由穿行。求把所有房间构筑完成的**不同顺序数目**，对 $10^9+7$ 取余。

**约束**：

- $2 \le n \le 10^5$
- `prevRoom[0] == -1`；对 $1 \le i < n$ 有 $0 \le \text{prevRoom}[i] < n$
- 保证所有房间建成后从房间 $0$ 可以访问到每个房间

> 💡 **审题关键**：① 「可以在已建房间间自由穿行」说明**除了「父先于子」再无别的约束**——不必关心蚂蚁怎么走；② 「从 0 可达」+ 每个房间恰有一个前驱 → 依赖关系是一棵**以 0 为根的树**；③ $n$ 达 $10^5$ 且答案取模 → 计数是天文数字，闭式里的除法必须用**乘法逆元**在模意义下完成。

## 3. 解题思路

### 3.1 暴力思路：枚举排列

枚举全部 $n!$ 个排列，逐一检查「每个房间是否排在其父之后」，代价 $O(n \cdot n!)$；$n = 10^5$ 时连 $n!$ 本身都是天文数字，完全不可行。

> 浪费的根源在于**把结构化约束当成逐项局部检查**。约束结构是一棵树——树形计数的标准出路是**自底向上合并**：子树的方案数卷成父的方案数，一路卷到根。

### 3.2 核心观察：顺序 = 树的线性拓展

![核心观察：依赖构成一棵树，合法顺序 = 父先于子的排列](images/wc247_q4_tree_linear_extension.svg)

两个观察把问题「翻译」成经典模型：

1. **依赖是一棵树**：每个 $i \ge 1$ 恰有一个前驱 `prevRoom[i]`，加上「从 0 可达」保证连通 → $n$ 个房间构成以 $0$ 为根的树，`prevRoom[i]` 即 $i$ 的父节点。
2. **合法顺序 = 线性拓展**：构筑 $i$ 的唯一门槛是父节点已建成（已建房间始终连通含 $0$，蚂蚁可自由抵达任何已建房间）。于是合法顺序恰是满足「每个节点排在其父之后」的排列——**树拓扑序（线性拓展）**。

于是本题 = **数一棵树的线性拓展个数**，它有著名闭式：

$$\#\text{线性拓展} \;=\; \frac{n!}{\prod_{v} \text{sz}(v)}$$

其中 $\text{sz}(v)$ 是 $v$ 的**子树大小**。示例 2：$\dfrac{5!}{5 \cdot 2 \cdot 2 \cdot 1 \cdot 1} = \dfrac{120}{20} = 6$ ✓。

### 3.3 闭式从哪来：兄弟子树自由交错

![从递推到闭式：兄弟子树的序列可以自由交错（多项式系数）](images/wc247_q4_interleave_shuffle.svg)

设 $\text{dp}[v]$ 为构筑子树 $v$ 的合法顺序数：

- $v$ 必须是子树里**第一个**——其余任何节点的先祖链都含 $v$；
- $v$ 建好后，各孩子子树之间**互不依赖**：约束只沿父子边存在，跨子树没有任何先后要求。所以剩下 $\text{sz}(v)-1$ 个位置由各子树的序列**自由交错**填满，交错数是**多项式系数**；再乘上每棵子树内部自己的方案：

$$\text{dp}[v] \;=\; \underbrace{\frac{(\text{sz}(v)-1)!}{\prod_{c}\,\text{sz}(c)!}}_{\text{交错方案数}} \times \prod_{c} \text{dp}[c]$$

- **层层展开即得闭式**：归纳可证 $\text{dp}[v] = \text{sz}(v)! \big/ \prod_{u \in \text{subtree}(v)} \text{sz}(u)$——分母中每个节点恰贡献一次自己的子树大小，分子逐层约减只剩最外层阶乘（证明见 §5）。代入 $v = 0$ 即 $n!/\prod_v \text{sz}(v)$。

> 💡 这个 $\prod_v 1/\text{sz}(v)$ 正是**树版本的 hook length 公式**：把 $[n]$ 的均匀随机排列限制在子树 $v$ 上，$v$ 恰是子树最小元的概率为 $1/\text{sz}(v)$；「每个节点都是自己子树的最小元」合起来恰刻画合法顺序。树的特殊结构让这些事件独立成立，概率直接相乘。

### 3.4 算法流程：逆 BFS 序 + 一次费马逆元

![算法流程：逆 BFS 序求子树大小 + 一次费马逆元](images/wc247_q4_algorithm_flow.svg)

1. 由 `prevRoom` 建邻接表 `children`（根为 $0$）。
2. 从 $0$ 做 **BFS** 得到序列 `order`——BFS 序中父恒先于子出现。
3. **逆序遍历** `order`：`sz` 初始全 1，对每个 $u \ne 0$ 执行 `sz[parent[u]] += sz[u]`。逆 BFS 序保证孩子先于父，一遍累出全部子树大小（等价于**迭代后序**，天然防爆栈）。
4. 计算 $\text{fact} = n! \bmod p$ 与 $\text{prod} = \prod_v \text{sz}(v) \bmod p$（$p = 10^9+7$）。
5. 由**费马小定理**：$p$ 为质数且各 $\text{sz}(v) \le n < p$ 使 $\text{prod} \not\equiv 0 \pmod p$，故 $\text{prod}^{-1} \equiv \text{prod}^{\,p-2} \pmod p$，一次快速幂求出。
6. 返回 $\text{fact} \times \text{prod}^{\,p-2} \bmod p$。

> ⚠️ **不要按下标逆序偷懒**：`prevRoom[i]` 完全可以大于 $i$（如 `[-1,2,0]` 中 $1$ 的父是 $2$），「$i$ 从大到小」并不保证孩子先于父——必须用真实的 BFS/DFS 序。

### 3.5 示例演算

![示例演算：逆 BFS 序一遍求出所有子树大小](images/wc247_q4_example_walkthrough.svg)

BFS 序 `order = [0,1,2,3,4]`，逆序依次处理 $4, 3, 2, 1$：

| 处理 $u$ | parent | 操作 | sz 数组 |
|---|---|---|---|
| （初始） | — | 全 1 | [1, 1, 1, 1, 1] |
| 4 | 2 | sz[2] += sz[4] | [1, 1, 2, 1, 1] |
| 3 | 1 | sz[1] += sz[3] | [1, 2, 2, 1, 1] |
| 2 | 0 | sz[0] += sz[2] | [3, 2, 2, 1, 1] |
| 1 | 0 | sz[0] += sz[1] | [5, 2, 2, 1, 1] |

$\prod \text{sz} = 5 \cdot 2 \cdot 2 \cdot 1 \cdot 1 = 20$，答案 $= 5! \times 20^{\,p-2} \equiv 120 / 20 = 6 \pmod{10^9+7}$ ✓。

## 4. 算法细节

1. **「已建房间连通含 0」的归纳证明**：初始只有 $0$；每次新建的房间 $i$ 与已建的父相连，连通性保持。这保证蚂蚁总能从 $0$ 走到任何已建房间，「自由穿行」不构成额外约束——合法性完全由「父先于子」决定。
2. **逆 BFS 序 = 迭代后序**：BFS 序中父恒先于子，逆序则孩子先于父；子树大小只需孩子信息齐全即可算父，一遍逆序完成。既避免递归爆栈，也避开「按下标逆序」的错误捷径。
3. **除法怎么变乘法**：闭式含除法，模 $p$ 下除以 $x$ 即乘 $x^{\,p-2}$（费马小定理，$p$ 质数且 $p \nmid x$）。本题 $\text{sz}(v) \in [1, 10^5]$ 均小于 $p$，乘积必然非零，逆元恒存在。
4. **一次求逆 vs 逐个求逆**：把 $n$ 个 $\text{sz}$ 先累乘成 $\text{prod}$ 再整体做一次快速幂，代价 $O(n + \log p)$；逐个 `pow(sz, p-2)` 则是 $O(n \log p)$，$n = 10^5$ 时约慢 30 倍（也能过，前者更优雅）。
5. **阶乘边乘边取模**：C++ 必须循环取模防溢出；Python 也建议循环取模，避免先算出几十万位的大整数再取模。
6. **BFS 用数组自身当队列**：`order` 从 `[0]` 起，按下标遍历的同时把孩子 `append` 进去——每个节点恰入队一次，无需单独的队列结构。

## 5. 正确性证明

**引理 1（顺序刻画）**：排列 $\pi$ 是合法构筑顺序 $\Leftrightarrow$ 对每个 $i \ge 1$ 都有 $\pi^{-1}(\text{prevRoom}[i]) < \pi^{-1}(i)$（父排在子之前）。

**证明**：（⇒）构筑 $i$ 时其父必须已建成，而「已建成」即排在 $\pi$ 中 $i$ 之前。（⇐）对步数归纳：任何时刻已建集合是含 $0$ 的连通子树——初始 $\{0\}$；第 $k$ 步构筑 $\pi_k$ 时其父已在更早步建成，新区间与父相邻，连通保持。于是蚂蚁可从 $0$ 走到任何已建房间，构筑 $\pi_k$ 的条件「父已建成」成立，排列可被逐位执行。∎

**引理 2（交错递推）**：设 $v$ 的孩子为 $c_1, \ldots, c_k$，则

$$\text{dp}[v] = \frac{(\text{sz}(v)-1)!}{\prod_{j=1}^{k} \text{sz}(c_j)!} \times \prod_{j=1}^{k} \text{dp}[c_j], \qquad \text{dp}[\text{叶子}] = 1.$$

**证明**：合法顺序中 $v$ 必居首位：其余任何节点 $u$ 的先祖链含 $v$，由引理 1 知 $v$ 先于 $u$。去掉首位 $v$，剩 $\text{sz}(v)-1$ 个位置。约束只沿父子边存在，而任何节点的全部先祖都在它所在的孩子子树内，故**跨子树没有任何先后约束**。一方面，把一个合法顺序限制在单棵子树 $c_j$ 上仍是合法顺序（约束全保留），因此合法顺序 =「各子树各取一个合法顺序 + 交错放入剩余位置」；另一方面，固定每棵子树内部的序列（共 $\prod_j \text{dp}[c_j]$ 种组合）后，将 $k$ 条长度为 $\text{sz}(c_j)$ 的序列交错填入 $\text{sz}(v)-1 = \sum_j \text{sz}(c_j)$ 个位置的方式数为多重排列 $\frac{(\sum_j \text{sz}(c_j))!}{\prod_j \text{sz}(c_j)!}$（先给子树 $c_1$ 选位置、再给 $c_2$ 选……即逐个组合数相乘）。两个自由度独立相乘，且每种组合恰被计数一次。∎

**定理（闭式）**：$\text{dp}[0] = \dfrac{n!}{\prod_{v=0}^{n-1} \text{sz}(v)}$。

**证明**：对子树归纳证明更强命题：对任意节点 $v$，$\text{dp}[v] = \text{sz}(v)! \big/ \prod_{u \in \text{subtree}(v)} \text{sz}(u)$。叶子时 $\text{dp} = 1 = 1!/1!$ 成立。归纳步：由引理 2 与归纳假设，

$$\text{dp}[v] = (\text{sz}(v)-1)! \times \prod_{j} \frac{\text{dp}[c_j]}{\text{sz}(c_j)!} = (\text{sz}(v)-1)! \times \prod_{j} \frac{1}{\prod_{u \in \text{subtree}(c_j)} \text{sz}(u)} = \frac{(\text{sz}(v)-1)!}{\prod_{u \in \text{subtree}(v),\, u \ne v} \text{sz}(u)}$$

分子分母同乘 $\text{sz}(v)$ 即得命题。代入 $v = 0$：$\text{subtree}(0)$ 为全部节点且 $\text{sz}(0) = n$，得 $\text{dp}[0] = n! / \prod_v \text{sz}(v)$。∎

**推论（模实现正确）**：$p = 10^9 + 7$ 为质数，各 $\text{sz}(v) \le n \le 10^5 < p$，故 $\text{prod} = \prod_v \text{sz}(v) \not\equiv 0 \pmod p$，由费马小定理 $\text{prod}^{\,p-2}$ 是 $\text{prod}$ 的模逆元。因此算法输出 $\equiv n! \cdot \text{prod}^{-1} \equiv \text{dp}[0] \pmod p$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n + \log p)$。建邻接表 $O(n)$；BFS 每点、每条父子边各访问一次 $O(n)$；逆序累加 $O(n)$；累乘与阶乘各 $O(n)$；一次快速幂 $O(\log p)$（$p = 10^9+7$，约 30 次模乘）。
- **空间复杂度**：$O(n)$。邻接表、`order`、`sz` 各 $O(n)$；无递归栈开销。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int waysToBuildRooms(vector<int>& prevRoom) {
        const int MOD = 1e9 + 7;
        int n = prevRoom.size();
        vector<vector<int>> children(n);
        for (int i = 1; i < n; ++i) children[prevRoom[i]].push_back(i);

        // ① BFS 定序：order 自身当队列（父恒先于子）
        vector<int> order;
        order.reserve(n);
        order.push_back(0);
        for (int i = 0; i < n; ++i) {
            int u = order[i];
            for (int v : children[u]) order.push_back(v);
        }

        // ② 逆序累加子树大小（逆 BFS 序 = 孩子先于父）
        vector<int> sz(n, 1);
        for (int i = n - 1; i >= 1; --i) {
            int u = order[i];
            sz[prevRoom[u]] += sz[u];
        }

        // ③ fact = n!，prod = ∏ sz(v)（模 p）
        long long fact = 1, prod = 1;
        for (int i = 2; i <= n; ++i) fact = fact * i % MOD;
        for (int v = 0; v < n; ++v) prod = prod * sz[v] % MOD;

        // ④ 费马小定理：prod^(p-2) 即模逆元
        long long inv = 1, base = prod, e = MOD - 2;
        while (e) {
            if (e & 1) inv = inv * base % MOD;
            base = base * base % MOD;
            e >>= 1;
        }
        return (int)(fact * inv % MOD);
    }
};
```

### Python

```python
class Solution:
    def waysToBuildRooms(self, prevRoom: List[int]) -> int:
        MOD = 10**9 + 7
        n = len(prevRoom)
        children = [[] for _ in range(n)]
        for i in range(1, n):
            children[prevRoom[i]].append(i)

        order = [0]
        for u in order:                    # order 自身当队列
            order.extend(children[u])

        sz = [1] * n
        for u in reversed(order):          # 逆 BFS 序：孩子先于父
            if u:
                sz[prevRoom[u]] += sz[u]

        fact = 1
        for i in range(2, n + 1):
            fact = fact * i % MOD
        prod = 1
        for s in sz:
            prod = prod * s % MOD
        return fact * pow(prod, MOD - 2, MOD) % MOD
```

> 💡 两版逻辑一致：一次 BFS 定序、一遍逆序求 sz、一次快速幂求逆。Python 的 `for u in order:` 在遍历中 `extend` 是安全的——列表迭代器会跟随扩容，每个节点恰被访问一次。

## 8. 边界情况与易错点

1. **递归爆栈**：链状树深度达 $10^5$，递归 DFS 在 Python 直接 `RecursionError`，C++ 也可能爆系统栈；BFS + 逆序处理是万能替代。
2. **按下标逆序当后序**：`prevRoom[i]` 可以大于 $i$，「$i$ 从大到小」不保证孩子先于父——必须用真实 BFS/DFS 序（本题最常见的 WA 点）。
3. **模除法当普通除法**：`fact / prod` 在整数域会截断为 0 或出错；必须用费马逆元 `pow(prod, p-2, p)`。
4. **`prod` 是否可能为 0**：$\text{sz} \le 10^5 < p$，不可能被 $p$ 整除，逆元必存在；若 $n \ge p$（本题不会发生）则需逐因子小心处理。
5. **C++ 中间溢出**：累乘必须 `long long` 且每步 `% MOD`；两个 `int` 相乘直接溢出。
6. **最小规模 $n = 2$**：`[-1,0]`，答案 $2!/(2 \cdot 1) = 1$，算法无需特判。
7. **别先做浮点除法再取模**：闭式是精确整数，取模只是表示方式；`120/20` 在浮点下碰巧整除，大数时会丢精度。
