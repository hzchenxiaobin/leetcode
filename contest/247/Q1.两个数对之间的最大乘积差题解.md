# LeetCode 两个数对之间的最大乘积差 题解

## 1. 题目概述

- **标题 / 题号**：两个数对之间的最大乘积差（#1913，easy）
- **链接**：https://leetcode.cn/problems/maximum-product-difference-between-two-pairs/
- **来源**：LeetCode 第 247 场周赛 Q1
- **难度**：简单
- **标签**：数组、排序、一次遍历

**题意**：定义两个数对 $(a, b)$ 和 $(c, d)$ 之间的**乘积差**为 $(a \times b) - (c \times d)$。给定整数数组 `nums`，选出四个**不同的**下标 $w, x, y, z$，使数对 $(nums[w], nums[x])$ 与 $(nums[y], nums[z])$ 之间的乘积差**最大**，返回这个最大值。

**约束**：

- `4 <= nums.length <= 10^4`
- `1 <= nums[i] <= 10^4`

## 2. 示例

**示例 1**

```text
输入：nums = [5,6,2,7,4]
输出：34
解释：第一个数对取 (6, 7)，第二个数对取 (2, 4)，
乘积差 = (6 × 7) - (2 × 4) = 42 - 8 = 34。
```

**示例 2**

```text
输入：nums = [4,2,5,9,7,4,8]
输出：64
解释：第一个数对取 (9, 8)，第二个数对取 (2, 4)，
乘积差 = (9 × 8) - (2 × 4) = 72 - 8 = 64。
注意数组中有两个 4，"两个最小"是 2 和 4，值可以重复，只要下标不同。
```

**示例 3（边界）**

```text
输入：nums = [3,3,3,3]
输出：0
解释：n = 4，四个下标必须全选，乘积差 = 3 × 3 - 3 × 3 = 0。
```

## 3. 解题思路

### 3.1 暴力思路

枚举四个下标 $w, x, y, z$ 的所有组合并计算乘积差：

- 组合数为 $A_n^4 = O(n^4)$，$n = 10^4$ 时约 $10^{16}$ 次计算，**严重超时**。
- 即使只枚举两个数对（各 $O(n^2)$ 个）再配对，也是 $O(n^4)$。

必须利用乘积差的结构：**被减数要尽量大，减数要尽量小**。

### 3.2 核心观察：全为正数 ⇒ 最大两数之积 − 最小两数之积

![核心观察：大配大、小配小](images/max_prod_diff_concept.svg)

约束保证 $nums[i] \ge 1$，即**所有元素都是正数**。于是：

- 被减数对 $(nums[w], nums[x])$ 的乘积要**最大**：正数相乘，取**最大的两个数**即可；
- 减数对 $(nums[y], nums[z])$ 的乘积要**最小**：取**最小的两个数**即可；
- $n \ge 4$ 保证"最大两个"与"最小两个"对应四个**互不相同**的下标，方案合法。

> 💡 **一句话**：答案 = `最大两数之积 − 最小两数之积`。这是签到题里典型的"从题面到代码的最短路径"——识别出单调性后无需任何搜索。

### 3.3 算法流程：排序 or 一次遍历

**方法一：排序**

1. 对 `nums` 升序排序；
2. 返回 `nums[n-1] * nums[n-2] - nums[0] * nums[1]`。

**方法二：一次遍历（维护前二大 / 前二小）**

1. 维护四个变量：`max1 ≥ max2`（当前最大、次大）、`min1 ≤ min2`（当前最小、次小）；
2. 对每个元素 `x`：
   - 若 `x > max1`，则 `max2 = max1, max1 = x`；否则若 `x > max2`，则 `max2 = x`；
   - 若 `x < min1`，则 `min2 = min1, min1 = x`；否则若 `x < min2`，则 `min2 = x`；
3. 返回 `max1 * max2 - min1 * min2`。

两种方法分别对应 $O(n \log n)$ 与 $O(n)$，本题规模下都轻松通过；一次遍历版本是"维护前 k 大 / 前 k 小"的经典模板。

### 3.4 示例演算

以示例 1 `nums = [5,6,2,7,4]` 走查一次遍历：

| 元素 x | max1 | max2 | min1 | min2 |
|--------|------|------|------|------|
| 初始 | −∞ | −∞ | +∞ | +∞ |
| 5 | **5** | −∞ | **5** | +∞ |
| 6 | **6** | **5** | 5 | +∞ |
| 2 | 6 | 5 | **2** | **5** |
| 7 | **7** | **6** | 2 | 5 |
| 4 | 7 | 6 | 2 | **4** |

最终 `max1=7, max2=6, min1=2, min2=4`，答案 $= 7 \times 6 - 2 \times 4 = 42 - 8 = 34$ ✓

## 4. 算法细节

1. **排序法**：直接 `sort` 后取两端，注意是 `nums[n-1] * nums[n-2]`（最大两个）与 `nums[0] * nums[1]`（最小两个），别错写成 `nums[0] * nums[n-1]`（一最大一最小）。
2. **一次遍历的更新顺序**：先比较 `x > max1` 再比较 `x > max2`，用 `else if` 串联。若 `x` 恰好等于 `max1`（重复最大值），走 `else if` 分支写入 `max2`，保证相同值也能占据前两名。
3. **初始化**：C++ 中 `max1 = max2 = INT_MIN`、`min1 = min2 = INT_MAX`（需 `<climits>`）；由于 $n \ge 4$，循环结束后四个变量一定都被真实元素覆盖。
4. **下标互异**：无需显式检查——排序后取的是**位置**上的前二大与前二小，$n \ge 4$ 时两组位置必然不同；元素值相同（如两个 4）不违反"下标不同"。

## 5. 正确性证明

设排序后数组为 $x_1 \le x_2 \le \cdots \le x_n$（$n \ge 4$，且 $x_i \ge 1$）。

**引理 1**：任意两个**不同下标**的元素之积不超过 $x_{n-1} \cdot x_n$。

**证明**：设这两个元素为 $p \ge q$（值可能相等）。若 $p = x_n$，则 $q$ 取自其余 $n-1$ 个元素，故 $q \le x_{n-1}$；若 $p < x_n$，则 $p \le x_{n-1}$，亦有 $q \le x_{n-1}$。两种情况均有 $p \le x_n$ 且 $q \le x_{n-1}$，由 $p, q \ge 1 > 0$ 得 $pq \le x_n \cdot x_{n-1}$。∎

**引理 2**：任意两个**不同下标**的元素之积不小于 $x_1 \cdot x_2$。

**证明**：与引理 1 对称。设两元素 $p \ge q$，则 $q \ge x_1$；若 $q = x_1$ 则 $p$ 取自其余元素故 $p \ge x_2$，否则 $q \ge x_2 \ge x_1$。两种情况均有 $q \ge x_1$ 且 $p \ge x_2$，由正性得 $pq \ge x_1 \cdot x_2$。∎

**定理**：最大乘积差等于 $x_{n-1} \cdot x_n - x_1 \cdot x_2$。

**证明**：

- **可达性**：下标 $0, 1, n-2, n-1$ 在 $n \ge 4$ 时两两不同，故取 $w=n-1, x=n-2, y=0, z=1$ 是合法方案，其乘积差恰为 $x_{n-1} x_n - x_1 x_2$。
- **最优性**：任一合法方案的乘积差为 $P - Q$，其中 $P$ 是某两个不同下标元素之积，$Q$ 亦然。由引理 1，$P \le x_{n-1} x_n$；由引理 2，$Q \ge x_1 x_2$。故 $P - Q \le x_{n-1} x_n - x_1 x_2$。
- 综上，$x_{n-1} x_n - x_1 x_2$ 既是合法方案取值，又是所有取值的上界，即最大值。∎

> ⚠️ 两个引理的证明都依赖**正数性**（$p, q \ge 1 > 0$，不等式两边可放心放缩）。若数组含负数，"最小乘积"可能由两个负数构成（正数！），结论失效，见第 8 节。

## 6. 复杂度分析

- **时间复杂度**：
  - 排序法：$O(n \log n)$，瓶颈在排序；
  - 一次遍历法：$O(n)$，每个元素仅常数次比较与赋值。
- **空间复杂度**：
  - 排序法：$O(\log n)$（排序递归栈）；
  - 一次遍历法：$O(1)$，只用四个变量。

## 7. 参考代码

### C++（一次遍历，$O(n)$ / $O(1)$）

```cpp
class Solution {
public:
    int maxProductDifference(vector<int>& nums) {
        int max1 = INT_MIN, max2 = INT_MIN;  // max1 >= max2
        int min1 = INT_MAX, min2 = INT_MAX;  // min1 <= min2
        for (int x : nums) {
            if (x > max1) {
                max2 = max1;
                max1 = x;
            } else if (x > max2) {
                max2 = x;
            }
            if (x < min1) {
                min2 = min1;
                min1 = x;
            } else if (x < min2) {
                min2 = x;
            }
        }
        return max1 * max2 - min1 * min2;
    }
};
```

### Python（排序，最短路径）

```python
class Solution:
    def maxProductDifference(self, nums: List[int]) -> int:
        nums.sort()
        return nums[-1] * nums[-2] - nums[0] * nums[1]
```

> 💡 Python 也可用 `heapq.nlargest(2, nums)` / `heapq.nsmallest(2, nums)` 在 $O(n)$ 内得到前二大 / 前二小，等价于 C++ 版的一次遍历。

## 8. 边界情况与易错点

1. **n = 4**：四个下标必须全选，只有一种组合，答案仍为最大两积减最小两积，无需特判。
2. **全部元素相同**：如 `[3,3,3,3]`，答案为 0，公式自然成立。
3. **重复元素**：如示例 2 的两个 4，"最小两个"允许**值相同**（下标不同即可）。一次遍历的 `else if` 分支保证重复值能正确进入次大 / 次小。
4. **溢出**：$nums[i] \le 10^4$，乘积 $\le 10^8$，差值 $\in [-10^8, 10^8]$，32 位 `int`（上限约 $2.1 \times 10^9$）安全。若范围放大到 $10^6$ 以上，C++ 需改用 `long long`；Python 无此问题。
5. **负数陷阱（本题不触发，但要警惕）**：结论"最大两积减最小两积"依赖全正约束。若含负数，如 `[-5,-4,1,2]`，最大乘积是 $(-5) \times (-4) = 20$ 而非 $1 \times 2$。比赛中看到 `1 <= nums[i]` 应立刻意识到这是刻意放宽的"送分条件"。
6. **一次遍历初始化**：`max` 系初始化为 `INT_MIN`、`min` 系初始化为 `INT_MAX`，别弄反方向；若用 `else if` 漏写（写成两个独立 `if`），相等的值会同时顶掉 `max1` 和 `max2`，导致次大丢失。
