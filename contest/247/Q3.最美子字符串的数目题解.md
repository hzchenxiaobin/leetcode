# LeetCode 最美子字符串的数目 题解

## 1. 题目概述

- **标题 / 题号**：最美子字符串的数目（#1915，medium）
- **链接**：https://leetcode.cn/problems/number-of-wonderful-substrings/
- **来源**：LeetCode 第 247 场周赛 Q3
- **难度**：中等
- **标签**：位运算、哈希表、字符串、前缀和

**题意**：若一个字符串中**至多一个**字母出现**奇数次**（其余字母均出现偶数次，0 次也算偶数次），则称之为**最美**字符串。给定仅由前 10 个小写字母 `'a'`–`'j'` 组成的字符串 `word`，返回其中**非空最美子串**的数目；同一子串每次出现都要分别计数。

**约束**：

- $1 \le \text{word.length} \le 10^5$
- `word` 仅由 `'a'` 到 `'j'` 组成

> 💡 **审题关键**：① 「至多一个奇」**包含零个奇**——全偶子串也是最美，别漏；② 题目只关心每个字符出现次数的**奇偶性**而非精确次数——状态压缩的强烈信号；③ 字符集恰为 10 个，暗示 $2^{10} = 1024$ 种奇偶状态；④ $n$ 达 $10^5$ 且求**计数**，答案规模可远超 32 位 `int`。

## 2. 示例

**示例 1**

```text
输入：word = "aba"
输出：4
解释：4 个最美子串为 "a"、"b"、"a"、"aba"。
      "aba" 中 a 出现 2 次（偶）、b 出现 1 次（奇），至多 1 个奇 → 最美。
```

**示例 2**

```text
输入：word = "aabb"
输出：9
解释：9 个最美子串为 "a"、"a"、"b"、"b"、"aa"、"bb"、"aab"、"abb"、"aabb"。
```

**示例 3（自拟：全同字符的极端情形）**

```text
输入：word = "aaaa"
输出：10
解释：任何子串都只含 'a'，奇数字母至多 1 个 → 全部子串都最美，
      共 4+3+2+1 = 10 个。
      这也揭示答案上限：n(n+1)/2 ≈ 5×10⁹，超出 32 位 int 范围。
```

## 3. 解题思路

### 3.1 暴力思路：枚举所有子串

枚举所有 $O(n^2)$ 个子串并判断奇偶。判断无需每次重数：固定左端点 $i$ 向右扩展时，每读入一个字符只需翻转一个奇偶标记，单次判断 $O(1)$，总代价 $O(n^2)$。$n = 10^5$ 时约 $10^{10}$ 次操作，**必然超时**。

> 浪费的根源在于**状态重复**：奇偶状态只有 $2^{10} = 1024$ 种，子串却有 $10^{10}$ 量级——海量子串共享极少量状态，逐个枚举是对同一状态的重复劳动。出路是把「子串的奇偶」改写成「两个**前缀**的奇偶之差」，用配对计数一趟算清。

### 3.2 核心观察：奇偶掩码 + 前缀异或配对

![前缀掩码配对：异或至多 1 位即最美](images/wc247_q3_prefix_xor_pairs.svg)

三个关键观察：

1. **奇偶压成 10 位掩码**：定义 $\text{mask}[i]$ 为前缀 `word[0..i-1]` 中各字母出现次数的奇偶状态（第 $t$ 位为 1 表示字母 $t$ 出现奇数次，`a`→第 0 位、`j`→第 9 位），$\text{mask}[0] = 0$（空前缀全偶）。
2. **前缀异或 = 区间奇偶**：子串 `word[i..j-1]` 的奇偶状态恰为 $\text{mask}[j] \oplus \text{mask}[i]$——异或就是模 2 意义下的「后缀减前缀」。
3. **最美判据**：子串最美 $\Leftrightarrow$ 奇数字母至多 1 个 $\Leftrightarrow$ $\text{mask}[j] \oplus \text{mask}[i]$ 的**汉明重量 $\le 1$**，即满足以下两者之一：
   - $\text{mask}[j] = \text{mask}[i]$：异或为 0，全偶；
   - $\text{mask}[j] \oplus \text{mask}[i] = 2^t$（某个 $t \in [0, 9]$）：恰字母 $t$ 奇数次。

> 💡 本题与 1371（元音偶数次的最长子串）同属「前缀状态配对」范式：那题只配对**相等**状态、求**最长**；本题放宽为「相等或恰差一位」、改为**计数**——哈希表里存的从「首次出现位置」变成「出现次数」。

### 3.3 算法流程：一趟扫描 + 计数数组

![算法流程：翻转 → 11 次查询 → 登记](images/wc247_q3_hash_count_flow.svg)

1. 开长度 $1024$ 的计数数组 `count`，令 `count[0] = 1`（空前缀全偶，出现 1 次）。
2. 从左到右扫描，维护当前掩码 `mask`，每读入字符 $c$ 执行 `mask ^= 1 << (c - 'a')`。
3. 在每个位置 $j$（更新 `mask` 之后、登记之前）累加：
   - `ans += count[mask]`：之前有多少前缀与当前**相等** → 全偶子串；
   - `ans += count[mask ^ (1 << t)]`（$t = 0, 1, \ldots, 9$）：之前有多少前缀与当前**恰差第 $t$ 位** → 恰 1 奇子串。
4. `count[mask] += 1`，把当前前缀登记进统计。
5. 扫描结束返回 `ans`。

> ⚠️ **顺序必须是先查询、后登记**：查询统计的是 $i < j$ 的旧前缀；若先自增再查询，`count[mask]` 会把 $i = j$ 自己也算进去（对应空子串），凭空多算。

### 3.4 示例演算：word = "aba"

![示例演算：word = "aba" 的逐步计数](images/wc247_q3_aba_walkthrough.svg)

掩码只显示两位（左 $b$ 右 $a$，$a$ 为最低位）。前缀掩码依次为 $00 \to 01 \to 11 \to 10$：

| 步 $j$ | 读入 | mask | 全偶查询 `count[mask]` | 恰 1 奇查询 $\sum_t$`count[mask^(1<<t)]` | 新增 | 累计 ans | 登记后 |
|--------|------|------|------------------------|------------------------------------------|------|----------|--------|
| 初始 | — | 00 | — | — | — | 0 | `count[00]=1` |
| 1 | a | 01 | 0 | `count[00]=1`（翻 $a$ 位） | 1 | 1 | `count[01]=1` |
| 2 | b | 11 | 0 | `count[01]=1`（翻 $b$ 位） | 1 | 2 | `count[11]=1` |
| 3 | a | 10 | 0 | `count[11]=1`（翻 $a$ 位）+ `count[00]=1`（翻 $b$ 位） | 2 | 4 | `count[10]=1` |

最后一步同时命中两种翻转：翻 $a$ 位配上前缀 `"ab"` 得子串 `"a"`，翻 $b$ 位配上空前缀得子串 `"aba"`。最终答案 **4** ✓。

## 4. 算法细节

1. **11 次查询的含义**：对每个右端点 $j$，合法的左端点状态只有 11 种——与 $\text{mask}[j]$ 相等的 1 种、恰差一位的 10 种。枚举的是「**对方**的状态」$\text{mask}[j] \oplus 2^t$，与当前 `mask` 第 $t$ 位是 0 还是 1 无关，10 个 $t$ 全部枚举即可，无需筛选。
2. **`count[0] = 1` 的含义**：掩码 0 = 全偶，空前缀（$i = 0$，尚未读任何字符）就是这个状态；不初始化会漏掉所有从下标 0 开始的全偶子串（如 `"jj"` 整体）。
3. **先查后增**：保证每次查询时 `count` 里只有 $i < j$ 的前缀，配对天然对应非空子串。
4. **定长数组代替哈希表**：状态空间是 $[0, 1024)$ 的紧密整数区间，`long long count[1024]`（计数用 `int` 足够）比 `unordered_map` 更快更省，无哈希开销。
5. **答案类型**：上界 $\frac{n(n+1)}{2} \approx 5 \times 10^9$，C++ 累加与返回必须用 `long long`。
6. **一位翻转是纯查询**：`mask ^ (1 << t)` 计算「另一个状态」用于数组下标，不修改 `mask` 本身；`mask` 只在读入字符时更新。

## 5. 正确性证明

**引理 1（区间奇偶 = 前缀异或）**：对任意 $0 \le i \le j \le n$，子串 `word[i..j-1]` 的奇偶掩码等于 $\text{mask}[j] \oplus \text{mask}[i]$。

**证明**：对每个字母 $t$，设 $f_t(j)$ 为前缀 `word[0..j-1]` 中字母 $t$ 的出现次数，则 $\text{mask}[j]$ 的第 $t$ 位为 $f_t(j) \bmod 2$。子串中字母 $t$ 的出现次数为 $f_t(j) - f_t(i)$，其奇偶为
$$\bigl(f_t(j) - f_t(i)\bigr) \bmod 2 = \bigl(f_t(j) + f_t(i)\bigr) \bmod 2$$
（模 2 下减法与加法一致），恰等于两掩码第 $t$ 位的异或。对全部 10 位逐位成立。∎

**引理 2（最美判据）**：子串 `word[i..j-1]` 最美 $\Leftrightarrow$ $\text{mask}[j] \oplus \text{mask}[i] \in \{0\} \cup \{2^t : 0 \le t \le 9\}$。

**证明**：由引理 1，异或值中为 1 的位集恰是该子串中出现奇数次的字母集。「至多一个字母奇数次」即该位集大小（汉明重量）$\le 1$，等价于异或值为 $0$（空集）或 $2^t$（单元素集）。∎

**定理（不重不漏）**：算法返回的 `ans` 等于 `word` 中最美非空子串的数目。

**证明**：非空子串与数对 $(i, j)$（$0 \le i < j \le n$，对应子串 `word[i..j-1]`）一一对应，按 $j$ 分组计数。先证不变量：**在第 $j$ 步的查询时刻，`count[m]` 等于满足 $i < j$ 且 $\text{mask}[i] = m$ 的前缀个数**。对 $j$ 归纳：$j = 0$ 时（尚未读入字符）仅 `count[0] = 1`，对应 $i = 0$ 的空前缀；每步查询发生在自增之前，故查询时 `count` 不含 $i = j$，查询后自增恰把 $i = j$ 计入，不变量向下一步延续。于是第 $j$ 步的累加值为
$$\text{count}[\text{mask}[j]] + \sum_{t=0}^{9} \text{count}[\text{mask}[j] \oplus 2^t] = \#\{\, i < j : \text{mask}[i] \in \{\text{mask}[j]\} \cup \{\text{mask}[j] \oplus 2^t : 0 \le t \le 9\} \,\},$$
由引理 2 恰为以 $j$ 结尾的最美子串个数；$i < j$ 保证子串非空。对 $j = 1, \ldots, n$ 求和，每个数对恰在其 $j$ 步被计一次，不重不漏。∎

## 6. 复杂度分析

- **时间复杂度**：$O\bigl((|\Sigma| + 1) \cdot n\bigr) = O(11n) = O(n)$。每个字符一次翻转、11 次 $O(1)$ 数组访问、一次自增；$|\Sigma| = 10$ 为常数。
- **空间复杂度**：$O(2^{|\Sigma|}) = O(1024)$。计数数组大小只与字符集有关，与 $n$ 无关，视为 $O(1)$ 额外空间。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long wonderfulSubstrings(string word) {
        int count[1024] = {};
        count[0] = 1;                            // 空前缀全偶
        int mask = 0;
        long long ans = 0;
        for (char c : word) {
            mask ^= 1 << (c - 'a');
            ans += count[mask];                  // 相等 → 全偶子串
            for (int t = 0; t < 10; ++t) {
                ans += count[mask ^ (1 << t)];   // 差一位 → 恰 1 奇子串
            }
            ++count[mask];                       // 先查后增
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def wonderfulSubstrings(self, word: str) -> int:
        count = [0] * 1024
        count[0] = 1                             # 空前缀全偶
        mask = 0
        ans = 0
        for c in word:
            mask ^= 1 << (ord(c) - ord('a'))
            ans += count[mask]                   # 相等 → 全偶子串
            for t in range(10):
                ans += count[mask ^ (1 << t)]    # 差一位 → 恰 1 奇子串
            count[mask] += 1                     # 先查后增
        return ans
```

> 💡 两版逻辑完全一致。Python 无溢出之忧；C++ 的 `ans` 与返回值必须是 `long long`（题目接口已如此签名）。

## 8. 边界情况与易错点

1. **答案溢出**：全同字符时答案达 $\frac{n(n+1)}{2} \approx 5 \times 10^9 > 2^{31} - 1$，C++ 用 `int` 累加必然溢出，须 `long long`。
2. **忘初始化 `count[0] = 1`**：漏掉所有从下标 0 开始、经空前缀配对的最美子串，如 `"jj"` 会错误地返回 1（正确为 3："j"、"j"、"jj"）。
3. **先自增后查询**：把 $i = j$ 的空子串计入，整体偏多；务必先查后增。
4. **「至多一个」误读为「恰好一个」**：全偶子串（异或为 0）也是最美，`ans += count[mask]` 这一项不能省。
5. **翻转枚举不完整**：10 个 $t$ 要全部枚举（无论该位当前是 0 还是 1），漏掉任何一位都会丢掉对应的子串。
6. **字符映射越界**：掩码仅 10 位、`count` 仅 1024 格，依赖题目保证字符在 `'a'`–`'j'` 内；若字符越界，`mask` 超过 1023 会数组越界。
7. **单字符输入**：$n = 1$ 时答案为 1（该字符恰出现 1 次，奇数字母数 $1 \le 1$），算法无需特判天然正确。
