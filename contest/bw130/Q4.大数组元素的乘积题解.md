# LeetCode 大数组元素的乘积 题解

## 1. 题目概述

- **标题 / 题号**：大数组元素的乘积（#3145，hard）
- **链接**：https://leetcode.cn/problems/find-products-of-elements-of-big-array/
- **来源**：LeetCode 第 130 场双周赛 Q4
- **难度**：困难
- **标签**：位运算、数组、二分查找

**题意**：

- 非负整数 $x$ 的**强数组**是「元素都是 2 的幂、总和为 $x$ 的最短有序数组」。可以证明它唯一：$x$ 的二进制里每个置位对应一个 $2^b$，按 $b$ 升序排列。
- 把所有正整数 $1, 2, 3, \dots$ 的强数组首尾相接，得到 `big_nums`，开头是 $[1, 2, 1, 2, 4, 1, 4, 2, 4, 1, 2, 4, 8, \dots]$。
- 每个查询 `[l, r, mod]` 要求 $\left(\prod_{k=l}^{r} big\_nums[k]\right) \bmod mod$。

**约束**：

- $1 \le queries.length \le 500$
- $0 \le l \le r \le 10^{15}$
- $1 \le mod \le 10^5$

## 2. 示例

**示例 1**

```text
输入：queries = [[1,3,7]]
输出：[4]
解释：big_nums[1..3] = [2,1,2]，乘积 4，4 mod 7 = 4。
```

**示例 2**

```text
输入：queries = [[2,5,3],[7,7,4]]
输出：[2,2]
解释：第一个查询 big_nums[2..5] = [1,2,4,1]，乘积 8，8 mod 3 = 2；
      第二个查询 big_nums[7] = 2，2 mod 4 = 2。
```

**示例 3（边界补充）**

```text
输入：queries = [[0,0,1]]
输出：[0]
解释：big_nums[0] = 1，1 mod 1 = 0。模数为 1 时答案恒为 0。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的做法是把 `big_nums` 真的展开成数组，再对每个查询做区间乘积。问题在于下标可以到 $10^{15}$：数组长度约 $10^{15}$，光存储就要 PB 级，完全不可行。即便只展开到 $r$，单次查询也是 $O(r)$，$500 \times 10^{15}$ 更不可能。

所以必须**不展开**地定位「第 $k$ 个元素是什么」，并且要能**快速批量求和**。

### 3.2 核心观察：每个数贡献 popcount 个「2 的幂」

![把每个正整数的强数组首尾相接，得到 big_nums](images/bw130_q4_big_array.svg)

强数组的定义决定了：数 $x$ 的强数组就是 $x$ 的二进制分解，元素为 $2^b$（$b$ 取遍 $x$ 的所有置位），共 $\mathrm{popcount}(x)$ 个。于是 `big_nums` 有一个非常规整的结构：

- 数 $x$ 占用 `big_nums` 的连续 $\mathrm{popcount}(x)$ 个位置；
- 它贡献的这些元素都是 2 的幂，**指数**分别是 $x$ 的置位位号（升序）。

记 $s(x) = \sum_{b:\ \text{bit } b \text{ of } x = 1} b$ 为 $x$ 贡献的「指数和」。由于每一项都是 2 的幂，区间乘积可以**指数相加**：

$$\prod_{k=l}^{r} big\_nums[k] = 2^{\,E(l, r)}, \qquad E(l, r) = \sum_{k=l}^{r} \text{exponent}\big(big\_nums[k]\big)$$

再把 $E$ 写成前缀差：令 $S(p)$ 表示 `big_nums` **前 $p$ 个元素**（下标 $0 \sim p-1$）的指数和，则

$$E(l, r) = S(r+1) - S(l), \qquad \text{答案} = 2^{\,E(l,r)} \bmod mod$$

于是整个问题归结为：**给定 $p \le 10^{15}+1$，求 $S(p)$**。

### 3.3 算法流程

求 $S(p)$ 分三步：先用位计数求出「前 $n$ 个数一共贡献多少元素」，二分定位 $p$ 落在哪个数的强数组里，再把那个数不完整的部分补齐。

**(1) 位计数公式。**

设 $\mathrm{cnt}_b(n)$ 为 $[1, n]$ 中第 $b$ 位为 1 的整数个数。数值 $0$ 不贡献任何位，所以统计 $[0, n]$ 与统计 $[1, n]$ 等价，共 $n+1$ 个数。第 $b$ 位的取值以 $2^{b+1}$ 为周期，每个周期里后 $2^b$ 个为 $1$：

$$\mathrm{cnt}_b(n) = \left\lfloor \frac{n+1}{2^{b+1}} \right\rfloor \cdot 2^b + \max\Bigl(0,\ (n+1) \bmod 2^{b+1} - 2^b\Bigr)$$

![按周期切块统计第 b 位为 1 的个数](images/bw130_q4_bit_count.svg)

由此得到两条前缀：

$$g(n) = \sum_{b \ge 0} \mathrm{cnt}_b(n) = \sum_{x=1}^{n} \mathrm{popcount}(x) \quad (\text{前 } n \text{ 个数贡献的元素总数})$$

$$h(n) = \sum_{b \ge 0} b \cdot \mathrm{cnt}_b(n) = \sum_{x=1}^{n} s(x) \quad (\text{前 } n \text{ 个数贡献的指数和})$$

$b$ 只需枚举到约 $60$ 就够（$n \le 10^{15} < 2^{50}$，代码里取到 $62$ 留余量）。

**(2) 二分定位。**

$g(n)$ 关于 $n$ 严格递增（每个数至少贡献 1 个元素），且 $g(n) \ge n$，所以取上界 $hi = p$ 一定够。二分出最小的 $n$ 使 $g(n) \ge p$，则：

- 前 $n-1$ 个数是「完整」的，贡献指数和 $h(n-1)$；
- 第 $p$ 个元素落在 $n$ 的强数组里，还差 $k = p - g(n-1)$ 个元素（$1 \le k \le \mathrm{popcount}(n)$）。

**(3) 补齐尾部。**

$n$ 的强数组按指数升序排列，所以「前 $k$ 个元素」就是 $n$ 的**最低 $k$ 个置位**，把它们的位号相加即可：

$$S(p) = h(n-1) + \sum_{\substack{b:\ \text{bit } b \text{ of } n = 1 \\ \text{取最低的 } k \text{ 个}}} b$$

![二分定位 + 尾部补齐](images/bw130_q4_prefix_exp.svg)

```text
S(p):
    若 p <= 0：返回 0
    lo = 1, hi = p
    while lo < hi:                        // 二分最小的 n 使 g(n) >= p
        mid = (lo + hi) // 2
        if g(mid) >= p: hi = mid
        else: lo = mid + 1
    n = lo
    k = p - g(n-1)                        // 还差 k 个元素
    s = h(n-1)
    for b = 0, 1, 2, ...：                 // 从低位往高位补
        若 n 的第 b 位为 1：s += b, k -= 1
        若 k == 0：跳出
    返回 s

answer(l, r, mod) = pow(2, S(r+1) - S(l), mod)
```

### 3.4 示例演算

以示例 1（$l = 1, r = 3$）为例，先手算 $S(4)$：

- $g(2) = \mathrm{popcount}(1) + \mathrm{popcount}(2) = 1 + 1 = 2 < 4$，$g(3) = 1+1+2 = 4 \ge 4$，故 $n = 3$；
- $k = 4 - g(2) = 4 - 2 = 2$，即还要 $3$ 的最低 2 个置位（位 $0$ 与位 $1$）；
- $h(2) = 0 + 1 = 1$，补齐部分 $= 0 + 1 = 1$，所以 $S(4) = 1 + 1 = 2$。

而 $S(1) = 0$（前 1 个元素是 $1 = 2^0$），于是 $E = S(4) - S(1) = 2$，答案 $2^2 \bmod 7 = 4$，与输出一致。

再验证示例 2 的两个查询：

| 查询 | $S$ 的取值 | $E$ | 答案 |
|------|-----------|-----|------|
| $[2,5,3]$ | $S(6) = 4$，$S(2) = 1$ | $3$ | $2^3 \bmod 3 = 2$ |
| $[7,7,4]$ | $S(8) = 7$，$S(7) = 6$ | $1$ | $2^1 \bmod 4 = 2$ |

其中 $[7,7]$ 只含一个元素：`big_nums[7] = 2 = 2^1`，指数为 1，所以 $2^1 \bmod 4 = 2$。

## 4. 算法细节

1. **$b$ 的上界**：$r \le 10^{15} < 2^{50}$，二分得到的 $n$ 也不超过 $10^{15}$，所以 $b$ 枚举到 $60$ 就够；代码里取 $62$ 留余量，并用 `1LL << b` 构造 $2^b$，避免 `int` 移位溢出。
2. **$\mathrm{cnt}_b$ 用 $n+1$ 而不是 $n$**：统计的是 $[0, n]$ 共 $n+1$ 个数的完整周期；$0$ 的所有位都是 0，所以结果等于 $[1,n]$ 的计数。
3. **二分上界取 $p$**：因为 $g(n) \ge n$，所以 $g(p) \ge p$ 一定成立，不需要估算 $n$ 的量级；这比「取 $10^{15}$」更省事也更安全。
4. **$k$ 的范围**：$k = p - g(n-1) \in [1, \mathrm{popcount}(n)]$，所以循环一定能补满，不会越界。
5. **指数和用 64 位**：$h(10^{15}) \approx 6 \times 10^{17}$，接近但不超过 `long long` 上界（$9.2 \times 10^{18}$）；$S$ 的两项相减也用 64 位。
6. **快速幂的底数与指数**：底数是 2（取模后可能为 0 或 1），指数是 `long long`；$mod = 1$ 时 `1 % mod = 0`，答案恒为 0，不需要特判。
7. **$mod$ 不一定是质数**：$mod \le 10^5$ 可以是合数，所以**不能**用费马小定理把指数对 $mod-1$ 取模，只能老老实实做二进制快速幂（$O(\log E) \approx 60$ 步）。
8. **查询是闭区间**：$[l, r]$ 对应前缀 $S(r+1) - S(l)$，不要把 $r+1$ 写成 $r$。
9. **每个查询两次前缀**：共 $2 \times 500 = 1000$ 次，每次 $O(60 \log p)$，总运算量约 $3 \times 10^6$，非常宽裕。

## 5. 正确性证明

**引理 1（强数组 = 二进制分解）**：正整数 $x$ 的强数组恰为 $\{2^b : x \text{ 的第 } b \text{ 位为 } 1\}$ 按 $b$ 升序排列，长度为 $\mathrm{popcount}(x)$。

**证明**：设 $A$ 是一个强数组（元素为 2 的幂、和为 $x$、长度最短）。若 $A$ 中有两个相等的元素 $2^b, 2^b$，把它们替换成单个 $2^{b+1}$ 后和不变、长度减 1，与最短性矛盾，故 $A$ 的元素两两不同。于是 $A$ 是 $\{2^b\}$ 的一个子集且和为 $x$；而任意整数写成互不相同的 2 的幂之和的表示唯一（即二进制表示），故 $A$ 只能是 $x$ 的置位集合。反之该集合确实满足「元素为 2 的幂、和为 $x$」，且长度等于 $\mathrm{popcount}(x)$，不可能更短（每个元素至多贡献 1 个置位，见下），所以它就是强数组。∎

> 补一句「不可能更短」：长度为 $m$ 的 2 的幂之和，其二进制中 1 的个数不超过 $m$（求和时进位只会减少 1 的个数），故 $m \ge \mathrm{popcount}(x)$。

**引理 2（乘积转指数和）**：$\prod_{k=l}^{r} big\_nums[k] = 2^{E(l,r)}$，其中 $E(l,r)$ 是该区间内所有元素的指数之和。

**证明**：由引理 1，`big_nums` 的每个元素都是 $2^b$ 的形式，设其指数为 $b_k$。则 $\prod_k 2^{b_k} = 2^{\sum_k b_k}$，由同底数幂的乘法法则即得。∎

**引理 3（前缀计数公式）**：$\mathrm{cnt}_b(n) = \lfloor (n+1)/2^{b+1} \rfloor \cdot 2^b + \max(0, (n+1) \bmod 2^{b+1} - 2^b)$。

**证明**：在 $0, 1, \dots, n$ 这 $n+1$ 个连续整数中，第 $b$ 位的取值以 $2^{b+1}$ 为周期循环，每个完整周期内恰有后 $2^b$ 个数该位为 1。完整的周期数为 $\lfloor (n+1)/2^{b+1} \rfloor$，贡献 $\lfloor (n+1)/2^{b+1} \rfloor \cdot 2^b$；剩余 $rem = (n+1) \bmod 2^{b+1}$ 个数构成不完整周期，其中前 $2^b$ 个该位为 0、其后为 1，故额外贡献 $\max(0, rem - 2^b)$。又 $0$ 的所有位均为 0，所以 $[0,n]$ 的计数等于 $[1,n]$ 的计数。∎

**引理 4（$g$、$h$ 的含义）**：$g(n) = \sum_{x=1}^{n}\mathrm{popcount}(x)$ 是前 $n$ 个数在 `big_nums` 中占用的元素总数；$h(n) = \sum_{x=1}^{n} s(x)$ 是这些元素的指数和。

**证明**：交换求和次序。$g(n) = \sum_{x\le n}\sum_b [\text{bit } b \text{ of } x] = \sum_b \mathrm{cnt}_b(n)$；同理 $h(n) = \sum_{x \le n} \sum_b b\,[\text{bit } b \text{ of } x] = \sum_b b\,\mathrm{cnt}_b(n)$。由引理 1，$x$ 占用 $\mathrm{popcount}(x)$ 个元素、指数和为 $s(x)$，故两式正好是「前 $n$ 个数的总元素数」与「总指数和」。∎

**引理 5（$S(p)$ 的公式正确）**：设 $n$ 是最小的满足 $g(n) \ge p$ 的整数，$k = p - g(n-1)$，则
$$S(p) = h(n-1) + \bigl(n \text{ 的最低 } k \text{ 个置位的位号之和}\bigr).$$

**证明**：由 $n$ 的最小性，$g(n-1) < p \le g(n)$，故 $1 \le k \le g(n) - g(n-1) = \mathrm{popcount}(n)$。前 $n-1$ 个数完整出现，其元素恰好占据 `big_nums` 的前 $g(n-1)$ 个位置，指数和为 $h(n-1)$（引理 4）。剩下的 $k$ 个元素是 $n$ 的强数组的前 $k$ 项；由引理 1，强数组按位号升序排列，故前 $k$ 项正是最低的 $k$ 个置位。∎

**定理**：对每个查询，算法输出 $\left(\prod_{k=l}^{r} big\_nums[k]\right) \bmod mod$。

**证明**：由引理 2，区间乘积等于 $2^{E}$；由引理 5，$S(r+1)$ 与 $S(l)$ 分别等于对应前缀的指数和，两者之差正是 $E(l, r)$（区间 $[l, r]$ 与前缀 $[0, r]$、$[0, l-1]$ 的差集一致）。快速幂在 $O(\log E)$ 内算出 $2^E \bmod mod$，与直接连乘同余。故结果正确。∎

## 6. 复杂度分析

- **时间**：每个查询两次 $S(p)$，每次一次二分（$O(\log p) \approx 50$ 轮）乘上每轮 $O(60)$ 的位计数，再加 $O(60)$ 的尾部补齐，合计 $O(60 \log p)$；总 $O(q \cdot 60 \log r)$，约 $3 \times 10^6$ 次基本运算。
- **空间**：$O(1)$。只用了若干 64 位整数与循环变量，没有随 $r$ 增长的数组。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> findProductsOfElements(vector<vector<long long>>& queries) {
        vector<int> ans;
        for (auto& q : queries) {
            long long l = q[0], r = q[1];
            int mod = (int)q[2];
            long long e = prefixExp(r + 1) - prefixExp(l);   // [l, r] 的指数和
            ans.push_back((int)powMod(2, e, mod));
        }
        return ans;
    }

private:
    // [1, n] 中第 b 位为 1 的整数个数
    static long long cntBit(long long n, int b) {
        long long half = 1LL << b, period = half << 1;
        long long full = (n + 1) / period * half;
        long long rem = (n + 1) % period;
        return full + max(0LL, rem - half);
    }
    // g(n)：1..n 的强数组总长度 = 1..n 的 popcount 之和
    static long long totalLen(long long n) {
        long long s = 0;
        for (int b = 0; b < 62; ++b) s += cntBit(n, b);
        return s;
    }
    // h(n)：1..n 的强数组指数总和 = sum_b b * cntBit(n, b)
    static long long totalExp(long long n) {
        long long s = 0;
        for (int b = 0; b < 62; ++b) s += (long long)b * cntBit(n, b);
        return s;
    }
    // big_nums 前 x 个元素的指数和
    static long long prefixExp(long long x) {
        if (x <= 0) return 0;
        long long lo = 1, hi = x;                 // g(n) >= n，故 hi = x 足够
        while (lo < hi) {
            long long mid = lo + (hi - lo) / 2;
            if (totalLen(mid) >= x) hi = mid;
            else lo = mid + 1;
        }
        long long n = lo;                         // 第 x 个元素落在 n 的强数组里
        long long k = x - totalLen(n - 1);        // 需要 n 的最低 k 个置位
        long long s = totalExp(n - 1);
        for (int b = 0; k > 0; ++b)
            if ((n >> b) & 1) { s += b; --k; }
        return s;
    }
    static long long powMod(long long a, long long e, int mod) {
        long long r = 1 % mod;
        a %= mod;
        while (e > 0) {
            if (e & 1) r = r * a % mod;
            a = a * a % mod;
            e >>= 1;
        }
        return r;
    }
};
```

### Python

```python
class Solution:
    def findProductsOfElements(self, queries: list[list[int]]) -> list[int]:
        def cnt_bit(n, b):
            """[1, n] 中第 b 位为 1 的整数个数"""
            if n <= 0:
                return 0
            half = 1 << b
            period = half << 1
            return (n + 1) // period * half + max(0, (n + 1) % period - half)

        B = 62

        def total_len(n):
            """g(n)：1..n 的强数组总长度（= popcount 之和）"""
            return sum(cnt_bit(n, b) for b in range(B))

        def total_exp(n):
            """h(n)：1..n 的强数组指数总和"""
            return sum(b * cnt_bit(n, b) for b in range(B))

        def prefix_exp(x):
            """big_nums 前 x 个元素的指数和"""
            if x <= 0:
                return 0
            lo, hi = 1, x            # g(n) >= n，hi = x 必够
            while lo < hi:
                mid = (lo + hi) // 2
                if total_len(mid) >= x:
                    hi = mid
                else:
                    lo = mid + 1
            n = lo
            k = x - total_len(n - 1)
            s = total_exp(n - 1)
            b = 0
            while k > 0:
                if (n >> b) & 1:
                    s += b
                    k -= 1
                b += 1
            return s

        return [pow(2, prefix_exp(r + 1) - prefix_exp(l), m) for l, r, m in queries]
```

> 💡 两份代码通过官方两个示例（`[4]` 与 `[2,2]`）、$mod = 1$、$l = r$、$r = 10^{15}$ 等边界。位计数公式 $g(n)$、$h(n)$ 与直接统计 $\mathrm{popcount}$ 的暴力在 $n \le 2 \times 10^4$ 的数百个随机点上完全一致；前缀函数 $S(p)$ 与「真的构造 `big_nums` 并求前缀和」在 $p \le 400000$ 上逐点核对一致；区间乘积与暴力连乘在 300 组随机查询（$r \le 10^5$）上对拍，`mismatch = 0`。极端查询 $[0, 10^{15}, 10^9+7]$ 在毫秒级返回 `338563975`。

## 8. 边界情况与易错点

1. **$l = 0$**：$S(0) = 0$，前缀函数必须能处理 $p \le 0$ 直接返回 0，不能让二分在 $x = 0$ 上跑。
2. **$l = r$**：区间只有一个元素，$E$ 就是该元素的指数；示例 2 的第二个查询正是这种情况。
3. **$mod = 1$**：答案恒为 0；快速幂里 `1 % mod` 的初始化保证了这一点（不要写死 `res = 1`）。
4. **指数和的量级**：$h(10^{15}) \approx 6 \times 10^{17}$，必须用 `long long`；用 `int` 会在中间步骤直接溢出。
5. **位移溢出**：`1 << b` 在 $b \ge 31$ 时对 `int` 是未定义行为，必须写 `1LL << b`。
6. **`cnt_b` 的 $n+1$**：统计区间是 $[0, n]$ 共 $n+1$ 个数；写成 $n$ 会少算正好一个元素，进而让所有下标平移、答案全错。
7. **二分上界**：$g(n) \ge n$ 保证 `hi = p` 可行；若为了「保险」把上界设成 $10^{18}$，`(n+1)` 与 `period` 的计算仍不会溢出，但没必要。
8. **尾部补齐的 $k$**：$k$ 从 $p - g(n-1)$ 得到，必须落在 $[1, \mathrm{popcount}(n)]$；若用 $p' = g(n)$ 的边界（$p$ 恰好等于 $g(n)$）也要能正确返回 $h(n)$。
9. **闭区间转半开**：$[l, r]$ 对应 $S(r+1) - S(l)$，这是本题最容易写错一处的下标。
10. **答案类型**：Python 的 `pow(2, e, m)` 接受任意大指数；C++ 必须自己写快速幂，不能用 `std::pow`（浮点精度不够）。
