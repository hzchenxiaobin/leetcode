# LeetCode 正方形中的最多点数 题解

## 1. 题目概述

- **标题 / 题号**：正方形中的最多点数（#3143，medium）
- **链接**：https://leetcode.cn/problems/maximum-points-inside-the-square/
- **来源**：LeetCode 第 130 场双周赛 Q2
- **难度**：中等
- **标签**：数组、哈希表、字符串、二分查找、排序

**题意**：给定 $n$ 个点 `points[i] = [x, y]` 和长度为 $n$ 的标签串 `s`（`s[i]` 是第 $i$ 个点的标签）。考虑**中心在原点、边平行于坐标轴**的正方形（边长可以为 0）。若正方形内（含边界）**不存在两个标签相同的点**，则称它**合法**。求合法正方形最多能包含多少个点。

**约束**：

- $1 \le n \le 10^5$
- $-10^9 \le x, y \le 10^9$，点坐标互不相同
- `s` 只含小写英文字母，$|s| = n$

## 2. 示例

**示例 1**

```text
输入：points = [[2,2],[-1,-2],[-4,4],[-3,1],[3,-3]], s = "abdca"
输出：2
解释：边长 4（半边长 2）的正方形包含 (2,2) 与 (-1,-2)，标签分别为 a、b，互不相同。
      再扩大就会收进 r=3 上的 (-3,1) 与 (3,-3)，它们的标签是 c 与 a，a 重复，非法。
```

**示例 2**

```text
输入：points = [[1,1],[-2,-2],[-2,2]], s = "abb"
输出：1
解释：边长 2 的正方形只含 a(1,1)；边长 4 会同时收进两个标签为 b 的点，非法。
```

**示例 3**

```text
输入：points = [[1,1],[-1,-1],[2,-2]], s = "ccd"
输出：0
解释：两个标签为 c 的点「同进同出」（都在 r=1 的边界上），任何正方形都无法只收其一，
      所以合法正方形只能什么都不收。
```

**示例 4（边界补充）**

```text
输入：points = [[0,0]], s = "a"
输出：1
解释：边长为 0 的正方形就包含原点，单个点的标签必然不重复。
```

## 3. 解题思路

### 3.1 暴力思路

正方形的「大小」只有一个自由度，但它是实数。一个自然的暴力是：枚举所有「可能出现的最优边长」——也就是把某个点的 $d$ 值当作半边长——然后扫一遍所有点统计包含情况并判重。这样是 $O(n^2)$：$n = 10^5$ 时 $10^{10}$，无法接受。

### 3.2 核心观察：点的「入场半径」是 $d = \max(|x|, |y|)$

![半边长 r = max(|x|,|y|)：点进正方形的最小代价](images/bw130_q2_radius.svg)

中心在原点、边平行于坐标轴、半边长为 $r$ 的正方形，就是闭区域 $[-r, r] \times [-r, r]$。于是

$$\text{点 } (x, y) \text{ 在正方形内} \iff |x| \le r \ \text{且}\ |y| \le r \iff \max(|x|, |y|) \le r$$

记 $d_i = \max(|x_i|, |y_i|)$，它就是第 $i$ 个点的**入场半径**：$r < d_i$ 时它在外面，$r \ge d_i$ 时它在里面。

这一步把二维几何变成了**一维排序**：把点按 $d$ 升序排列，则半径 $r$ 包含的点集恰好是「$d \le r$ 的前缀」。而且这个集合随 $r$ 单调增大——**只增不减**。

> 💡 很多题解把这一步写成「滑窗」，但注意本题的窗口**不需要收缩**：合法的判据是「集合内标签互不相同」，一旦出现重复标签，扩容只会让重复更多。所以滑动窗口退化成「前缀一路推进，遇到冲突就停」。

### 3.3 算法流程

![按 r 排序分组：第一组冲突之后全部作废](images/bw130_q2_sort_groups.svg)

一个容易忽略的细节：**$d$ 相同的点必须整组处理**。因为 $r$ 是连续变量，而 $d$ 相同的点在任意 $r$ 下要么全在里面、要么全在外面，不存在只收其中一个的正方形（见下图的图解）。

```text
1. 计算每个点的 d = max(|x|, |y|)，按 d 升序排序
2. used[26] 全 false（已收标签），ans = 0
3. i = 0
4. 当 i < n：
       j = i，cur[26] 清空，bad = false
       当 j < n 且 d[ord[j]] == d[ord[i]]：          // 同一半径的一整组
           c = s[ord[j]] 的字母编号
           若 used[c] 或 cur[c]：bad = true         // 与已收标签或组内标签冲突
           cur[c] = true，j += 1
       若 bad：跳出循环                              // 该组非法，更大的 r 只会更糟
       used |= cur，ans += j - i，i = j
5. 返回 ans
```

### 3.4 示例演算

![同一 r 的点必须同进同出](images/bw130_q2_all_or_nothing.svg)

示例 1 的五个点按 $d$ 分组：

| 组 | 点 | 标签 | 累计标签集合 | 判定 |
|----|-----|------|--------------|------|
| $d = 2$ | $(2,2)$、$(-1,-2)$ | a、b | {a, b} | ✓ 收下，ans = 2 |
| $d = 3$ | $(-3,1)$、$(3,-3)$ | c、a | a 与已收标签重复 | ✗ 停 |
| $d = 4$ | $(-4,4)$ | d | — | 不再考虑 |

答案 2，与输出一致。示例 3 则是第一组（$d = 1$，标签 c、c）内部就重复，直接停在 0 个点——这正是「组内重复也要整组判死」的例子。

## 4. 算法细节

1. **排序键是 $d$，不是 $|x| + |y|$**：正方形边界是 $|x| = r$ 与 $|y| = r$，所以是切比雪夫距离，不是曼哈顿距离。
2. **同 $d$ 必须成组**：可以先排序再按 $d$ 分段，也可以把 $(d, \text{label})$ 排序后合并相邻同 $d$ 项；关键是不要「逐点收下、遇冲突就停在组中间」——那样会给出一个**不可实现**的半径（组内前一半被收、后一半没被收）。
3. **冲突立即终止**：一旦某组非法，所有更大的 $r$ 都不可能合法（单调性），直接 `break`；这也是复杂度保持 $O(n \log n)$ 的原因。
4. **标签用 26 位数组**：`used` 表示已收标签，`cur` 表示本组标签；两者都命中的情况都要判（`used[c] || cur[c]`）。
5. **坐标绝对值**：$|x| \le 10^9$，`abs` 在 `int` 范围内安全；若后续要算边长 $2r$ 则需注意 $2 \times 10^9$ 超出 `int`，用 `long long`。
6. **边长可以为 0**：$r = 0$ 只包含原点，是合法起点（若 $(0,0)$ 存在则 $d = 0$，它是第一组）。
7. **坐标互不相同**：题目保证没有重复坐标，但**标签可以重复**，重复标签才是唯一约束。
8. **答案上界是 $n$**，也是 $26$ 与「每个标签至多一个」的较小者——这可以作为自检：若某方案收了 27 个点，必然有重复标签。

## 5. 正确性证明

**引理 1（包含判据）**：点 $(x,y)$ 在以原点为中心、半边长为 $r$ 的轴平行正方形内（含边界），当且仅当 $\max(|x|,|y|) \le r$。

**证明**：该正方形是闭区域 $[-r,r]^2$，点在其中等价于 $|x| \le r$ 且 $|y| \le r$，而两个不等式同时成立等价于它们的最大值 $\le r$。∎

**引理 2（集合是前缀）**：按 $d$ 升序排列后，任一 $r$ 对应的包含点集恰为某个前缀（即满足 $d \le r$ 的那些点），且当 $r$ 增大时点集单调不减。

**证明**：由引理 1，包含条件只取决于 $d_i \le r$；排序后所有满足 $d_i \le r$ 的下标构成一个前缀（排序保证 $d$ 非降）。$r$ 增大时条件更容易满足，故集合单调不减。∎

**引理 3（同 $d$ 组不可拆分）**：若两个点 $d$ 相同，则不存在任何 $r$ 使其中一个在正方形内、另一个在外。

**证明**：设 $d_u = d_v = D$。若 $r \ge D$，由引理 1 两点都在内；若 $r < D$，两点都在外。故不可能只包含其一。∎

**引理 4（最优解只能是「最大合法前缀」）**：设按 $d$ 升序分组后，前 $g$ 组标签互不重复，而第 $g+1$ 组会引入重复，则答案等于前 $g$ 组的点数之和。

**证明**：由引理 2、3，任何正方形包含的点集都是「完整若干组」构成的前缀。前缀合法性随长度单调下降（多收点只会增加标签冲突的可能），所以合法的前缀构成一个初始段 $0, 1, \dots, g$。取 $r$ 等于第 $g$ 组的 $d$ 值即可实现前缀 $g$（$g = 0$ 时取 $r = 0$），故最多点数为前 $g$ 组的点数之和。∎

**定理**：算法返回的值等于合法正方形能包含的最多点数。

**证明**：算法按组推进，逐组检查「与已收标签冲突」和「组内冲突」，遇到第一个非法组就停止，累计的 `ans` 正是前 $g$ 组的点数之和。由引理 4，这就是最优值。算法在组内用 `cur` 暂存标签、确认整组合法后才并入 `used`，保证不会出现「半组」的非法状态。∎

## 6. 复杂度分析

- **时间**：$O(n \log n)$，排序主导；随后每组扫描一次，总 $O(n)$，组内 26 次合并为 $O(26 \cdot \text{组数}) \le O(26n)$，仍被排序覆盖。
- **空间**：$O(n)$ 存放下标与 $d$（也可对点数组原地排序做到 $O(n)$ 以内的额外空间），外加 $O(26)$ 的标签数组。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maxPointsInsideSquare(vector<vector<int>>& points, string s) {
        int n = points.size();
        vector<int> id(n), d(n);
        for (int i = 0; i < n; ++i) {
            id[i] = i;
            d[i] = max(abs(points[i][0]), abs(points[i][1]));
        }
        sort(id.begin(), id.end(), [&](int a, int b) { return d[a] < d[b]; });
        vector<char> used(26, 0);
        int ans = 0, i = 0;
        while (i < n) {
            int j = i;
            bool bad = false;
            vector<char> cur(26, 0);
            while (j < n && d[id[j]] == d[id[i]]) {   // 同一半径整组处理
                int c = s[id[j]] - 'a';
                if (used[c] || cur[c]) bad = true;     // 与已收标签或组内标签重复
                cur[c] = 1;
                ++j;
            }
            if (bad) break;                           // 该组非法，更大的半径只会更糟
            for (int c = 0; c < 26; ++c) used[c] = used[c] || cur[c];
            ans += j - i;
            i = j;
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maxPointsInsideSquare(self, points: list[list[int]], s: str) -> int:
        n = len(points)
        d = [max(abs(x), abs(y)) for x, y in points]      # 入场半径
        order = sorted(range(n), key=lambda i: d[i])
        used = [False] * 26
        ans = 0
        i = 0
        while i < n:
            j = i
            bad = False
            cur = [False] * 26
            while j < n and d[order[j]] == d[order[i]]:   # 同一半径整组处理
                c = ord(s[order[j]]) - 97
                if used[c] or cur[c]:                     # 与已收标签或组内标签重复
                    bad = True
                cur[c] = True
                j += 1
            if bad:                                       # 该组非法，更大的半径只会更糟
                break
            for c in range(26):
                used[c] = used[c] or cur[c]
            ans += j - i
            i = j
        return ans
```

> 💡 两份代码通过官方三个示例（`2` / `1` / `0`）与单点 $(0,0)$ 边界，并在 4000 组随机小数据（$n \le 9$，坐标 $\in [-4,4]$，3 种标签）上与「枚举所有候选半径 + 每次扫全表判重」的 $O(n^2)$ 暴力实现对拍，`mismatch = 0`；另与 400 组随机数据的另一份独立实现交叉验证一致。

## 8. 边界情况与易错点

1. **同 $d$ 组必须整组判定**：示例 3 就是组内重复（两个 c 都在 $r = 1$ 上），若逐点收下会在组中间停下，得到一个「只收一个 c」的非法答案。
2. **冲突后立即停**：合法性对 $r$ 单调，遇到非法组后继续往后扫是多余的；若忘记 `break` 而继续累加，答案会偏大。
3. **不要用 $|x| + |y|$**：那是曼哈顿距离，对应的是菱形/旋转正方形；本题正方形边平行坐标轴，必须用 $\max(|x|,|y|)$。
4. **边长为 0 合法**：$r = 0$ 只包含原点，是 $d = 0$ 的点能进的唯一情形，别把 $r$ 强制为正。
5. **全部同标签**：任意两个点都不能同时被包含，答案最多 1（若第一个 $d$ 组只含一个点）或 0（若第一组就有两个同标签点）。
6. **单点**：答案 1，不需要特殊处理（第一组只含它，`used` 无冲突）。
7. **坐标绝对值**：$10^9$ 的 `abs` 在 `int` 范围内没问题，但若把边长 $2r$ 也存下来要留意 $2 \times 10^9$ 溢出 `int`。
8. **标签只有 26 种**：因此任何合法正方形最多收 26 个点；若程序输出大于 26，一定是判重逻辑漏了。
