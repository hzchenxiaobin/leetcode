# LeetCode 判断矩阵是否满足条件 题解

## 1. 题目概述

- **标题 / 题号**：判断矩阵是否满足条件（#3142，easy）
- **链接**：https://leetcode.cn/problems/check-if-grid-satisfies-conditions/
- **来源**：LeetCode 第 130 场双周赛 Q1
- **难度**：简单
- **标签**：数组、矩阵

**题意**：给定 $m \times n$ 的矩阵 `grid`，要求**每一个格子**都满足：

- 若它**下面的格子存在**，则两者相等：$grid[i][j] = grid[i+1][j]$；
- 若它**右边的格子存在**，则两者**不相等**：$grid[i][j] \ne grid[i][j+1]$。

所有格子都满足返回 `true`，否则返回 `false`。

**约束**：

- $1 \le m, n \le 10$
- $0 \le grid[i][j] \le 9$

## 2. 示例

**示例 1**

```text
输入：grid = [[1,0,2],[1,0,2]]
输出：true
解释：三列各自上下相等（1=1, 0=0, 2=2），两行各自相邻都不同（1≠0, 0≠2）。
```

**示例 2**

```text
输入：grid = [[1,1,1],[0,0,0]]
输出：false
解释：第一行里 1 与 1 相邻且相等，违反「右边不等」。
```

**示例 3**

```text
输入：grid = [[1],[2],[3]]
输出：false
解释：只有一列，但列内 1、2、3 互不相等，违反「下边相等」。
```

**示例 4（边界补充）**

```text
输入：grid = [[7]]
输出：true
解释：1×1 矩阵没有下方格子也没有右侧格子，两个条件都空成立。
```

## 3. 解题思路

### 3.1 暴力思路

最直白的写法就是**逐格翻译题面**：对每个 $(i,j)$ 检查「下方存在则相等」「右侧存在则不等」，两件事都成立才继续。这就是正解，因为输入最多 $10 \times 10 = 100$ 个格子，任何 $O(mn)$ 的做法都已经是最优量级。

所以本题的「暴力」不是指复杂度，而是指**边界处理**：判断「下方/右侧是否存在」时容易越界，或者把两个方向的条件写反。把这两点处理好，代码就是五行。

### 3.2 核心观察：两个条件方向正交，且传递性只对其中一个成立

![列内必须相等，行内必须不等](images/bw130_q1_two_rules.svg)

两个条件作用在**不同方向**上，互不干扰：

- **列方向**要求「全等」，而相等具有传递性：同一列里只要每个格子都等于该列**第 0 行**的格子，那么该列任意两格都相等。所以列方向可以只做 $m-1$ 次比较（第 $i$ 行 vs 第 0 行），不必逐对比较。
- **行方向**要求「相邻不等」，而「不等」**没有传递性**：$1 \ne 0$、$0 \ne 1$ 都成立，但 $1$ 与 $1$ 相等。所以行方向**必须逐对相邻比较**，不能用「该行所有值互不相同」来代替。

这一点正是本题最容易踩的坑：`[1,0,1]` 这一行是完全合法的（相邻两对都不等），但它的首尾相等。用「全行互不相同」去判就会误判成 `false`。

### 3.3 算法流程

```text
1. 对 i = 0..m-1，j = 0..n-1：
       a. 若 i+1 < m 且 grid[i][j] != grid[i+1][j]：返回 false
       b. 若 j+1 < n 且 grid[i][j] == grid[i][j+1]：返回 false
2. 全部检查通过：返回 true
```

一趟双重循环同时完成两个方向的检查，遇到第一个违反就提前返回。

### 3.4 示例演算

![三种示例：一个通过，两个各有一处坏](images/bw130_q1_three_cases.svg)

| 示例 | 矩阵 | 列方向 | 行方向 | 结论 |
|------|------|--------|--------|------|
| 1 | $[[1,0,2],[1,0,2]]$ | 三列各自相等 ✓ | 两行各自相邻不等 ✓ | `true` |
| 2 | $[[1,1,1],[0,0,0]]$ | 每列相等 ✓ | $1=1$ 违反 ✗ | `false` |
| 3 | $[[1],[2],[3]]$ | $1 \ne 2$ 违反 ✗ | 无相邻元素（空成立） | `false` |
| 4 | $[[7]]$ | 无下方元素（空成立） | 无右侧元素（空成立） | `true` |

示例 3 值得单独看一眼：它是 $3 \times 1$ 的单列矩阵，行方向根本没有可比的对象，但**列方向仍然必须成立**，所以答案是 `false`。这类「维度退化」的输入是本题最常见的边界。

## 4. 算法细节

1. **边界判断写在比较内部**：`i + 1 < m` 与 `j + 1 < n` 用短路 `&&` 串在条件里，避免越界访问。
2. **两个条件用相反的比较符**：列方向是 `!=` 就报错（要求相等），行方向是 `==` 就报错（要求不等），两者不要写混。
3. **提前返回**：一旦发现违反立刻 `return false`，不需要跑完全部格子；最坏情况（全合法）才走满 $mn$。
4. **「空成立」是逻辑上的真**：$m = 1$ 时不存在「下方格子」，$n = 1$ 时不存在「右侧格子」，这些格子自动满足对应条件，不能因此判 `false`。
5. **值域是 0..9，不是布尔**：题面出现 2，所以不能把 `grid[i][j]` 当 `0/1` 用 `if (grid[i][j])` 之类的写法处理相等关系。
6. **不需要额外空间**：原地检查即可，返回 `bool`。
7. **可以合并成两趟**：先整列检查、再整行检查，逻辑更清晰；但一趟双重循环常数更小，两者都正确。

## 5. 正确性证明

**引理 1（列方向的传递性）**：若某列满足「每格等于其下方格子」，则该列所有格子两两相等。

**证明**：对行下标归纳。第 0 行等于第 1 行、第 1 行等于第 2 行……由相等关系的传递性，第 0 行等于该列任意一行，故任意两行相等。∎

**引理 2（算法检查的完整性）**：算法对每一对「相邻」的格子（竖直相邻或水平相邻）都恰好检查一次，且检查的就是题面要求的那个关系。

**证明**：外层 $i$ 遍历所有行、内层 $j$ 遍历所有列。竖直相邻对 $(i,j)$–$(i+1,j)$ 在 $i + 1 < m$ 时被检查，条件为「相等」；水平相邻对 $(i,j)$–$(i,j+1)$ 在 $j + 1 < n$ 时被检查，条件为「不等」。每个相邻对只被其上方/左侧的格子触发一次，因此不重不漏。∎

**定理**：算法返回 `true` 当且仅当所有格子都满足题面的两个条件。

**证明**：

- $(\Rightarrow)$ 算法返回 `true` 意味着没有触发任何一次 `return false`，即对每个格子，只要下方存在就有 $grid[i][j] = grid[i+1][j]$，只要右侧存在就有 $grid[i][j] \ne grid[i][j+1]$，这正是题面要求。
- $(\Leftarrow)$ 若所有格子都满足条件，则由引理 2，算法每次检查的比较结果都与题面要求一致，不会返回 `false`，最终返回 `true`。∎

## 6. 复杂度分析

- **时间**：$O(mn)$。每个格子常数次比较，最坏情况检查全部 $mn$ 个格子的两个方向。
- **空间**：$O(1)$。只用了循环变量，未开辟额外数组，也未修改输入。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool satisfiesConditions(vector<vector<int>>& grid) {
        int m = grid.size(), n = grid[0].size();
        for (int i = 0; i < m; ++i)
            for (int j = 0; j < n; ++j) {
                if (i + 1 < m && grid[i][j] != grid[i + 1][j]) return false;
                if (j + 1 < n && grid[i][j] == grid[i][j + 1]) return false;
            }
        return true;
    }
};
```

### Python

```python
class Solution:
    def satisfiesConditions(self, grid: list[list[int]]) -> bool:
        m, n = len(grid), len(grid[0])
        for i in range(m):
            for j in range(n):
                if i + 1 < m and grid[i][j] != grid[i + 1][j]:
                    return False
                if j + 1 < n and grid[i][j] == grid[i][j + 1]:
                    return False
        return True
```

> 💡 两份代码通过官方三个示例（`true` / `false` / `false`）与 $1 \times 1$、单行、单列边界，并与「先整列查相等、再整行查不等」的两趟独立实现在 5000 组随机小矩阵（$m, n \le 4$）上对拍，`mismatch = 0`。

## 8. 边界情况与易错点

1. **$1 \times 1$ 矩阵**：两个条件都「空成立」，必须返回 `true`；若把「没有下方格子」当成「下方不相等」，就会误判。
2. **单行（$m = 1$）**：只需检查行内相邻不等；单列（$n = 1$）只需检查列内相等。
3. **相邻不等**：`[1,0,1]` 是合法行，别用「整行互不相同」去判，否则误判 `false`。
4. **列内相等可用传递性**：与第 0 行比较即可，但若与上一行比较同样正确（链式相等）。
5. **越界**：`i + 1 < m` 与 `j + 1 < n` 的顺序要放在访问数组之前（短路求值保证不会先取越界下标）。
6. **值域 0..9**：矩阵元素不是布尔值，示例里有 2；用 `if (grid[i][j])` 做相等判断会出错。
7. **提前返回**：发现违反立即返回，别继续跑（虽然不影响正确性，但会漏掉「首个违反」的调试信息）。
8. **Python 的 `list[list[int]]` 注解**：老版本 Python 需要 `from typing import List`，LeetCode 环境已支持内建泛型写法。
