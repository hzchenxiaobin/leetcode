# LeetCode 分割字符频率相等的最少子字符串 题解

## 1. 题目概述

- **标题 / 题号**：分割字符频率相等的最少子字符串（#3144，medium）
- **链接**：https://leetcode.cn/problems/minimum-substring-partition-of-equal-character-frequency/
- **来源**：LeetCode 第 130 场双周赛 Q3
- **难度**：中等
- **标签**：哈希表、字符串、动态规划、计数

**题意**：把一个字符串 $s$ 分割成若干个**平衡子串**（子串中所有出现过的字符出现次数**完全相同**），求最少的段数。

**约束**：

- $1 \le |s| \le 1000$
- $s$ 只含小写英文字母

## 2. 示例

**示例 1**

```text
输入：s = "fabccddg"
输出：3
解释：可分成 ("fab","ccdd","g")：fab 各 1 次、ccdd 各 2 次、g 1 次；
      也可分成 ("fabc","cd","dg")，同样是 3 段。
```

**示例 2**

```text
输入：s = "abababaccddb"
输出：2
解释：("abab","abaccddb")：前者 a、b 各 2 次，后者 a、b、c、d 各 2 次。
```

**示例 3（边界补充）**

```text
输入：s = "a"
输出：1
解释：单字符子串必然平衡，至少需要 1 段。
```

**示例 4（边界补充）**

```text
输入：s = "aab"
输出：2
解释："aab" 整体不平衡（a 两次、b 一次）；("aa","b") 与 ("a","ab") 都是 2 段，故答案为 2。
```

## 3. 解题思路

### 3.1 暴力思路

最直白的是枚举所有分割点：$n-1$ 个间隙各切或不切，共 $2^{n-1}$ 种方案，每种方案再 $O(n)$ 检查各段是否平衡。$n = 1000$ 时是指数爆炸。

稍好的想法是：这题的形态是典型的「前缀最优分割」——第 $i$ 个前缀的最优解只依赖更短前缀的最优解，于是可以写成 DP。若**逐段判断平衡**用 $O(n)$，DP 共 $O(n^2)$ 个 $(j, i)$ 对，总 $O(n^3) = 10^9$，仍然太慢；但只要边扫边增量维护频次，判断就能降到 $O(1)$。

### 3.2 核心观察：平衡的判据是「最大频次 = 平均频次」

![平衡子串：每种出现过的字符频次完全相同](images/bw130_q3_balanced.svg)

设某子串长度为 $L$、其中出现过的**不同字符数**为 $k$、出现次数的**最大值**为 $M$。则该子串平衡，当且仅当

$$L = k \times M \quad\Longleftrightarrow\quad L \bmod k = 0 \ \text{且}\ M = \frac{L}{k}$$

**为什么只查最大值就够？** 因为 $k$ 个出现过的字符，它们的频次之和恰好是 $L$（每个位置只属于一个字符）。若每种频次都等于 $M$，自然有 $L = kM$；反过来，若 $L = kM$ 且最大频次为 $M$，则 $k$ 个频次都 $\le M$、和为 $kM$，只能是每个都恰好等于 $M$。所以「最大频次等于平均值」就自动蕴含「所有频次相等」。

有了这个判据，判断一段是否平衡只需要三个量：长度 $L$、不同字符数 $k$、最大频次 $M$——全都可以在**从右往左扩展**时增量维护。

### 3.3 算法流程 / 状态转移

![前缀 DP 的转移关系](images/bw130_q3_dp_model.svg)

定义 $dp[i]$ 为前缀 $s[0..i-1]$ 的最少段数，$dp[0] = 0$。转移枚举最后一段的起点 $j$：

$$dp[i] = 1 + \min\{\, dp[j] \;:\; 0 \le j < i,\ s[j..i-1] \text{ 平衡} \,\}$$

```text
1. dp[0] = 0，其余 dp[i] = INF（取 n+1 即可）
2. for i = 1..n:
       cnt[26] 清零，distinct = 0，mx = 0，best = INF
       for j = i-1 down to 0:                 // 从右往左扩展最后一段
           c = s[j]
           若 cnt[c] == 0：distinct += 1
           cnt[c] += 1，mx = max(mx, cnt[c])
           L = i - j
           若 L % distinct == 0 且 mx == L / distinct：
               best = min(best, dp[j] + 1)
       dp[i] = best
3. 返回 dp[n]
```

为什么 $j$ 要从右往左扫？因为这样最后一段是「不断向左延长」的，`cnt` 只需要**增加**字符，`distinct` 与 `mx` 都能 $O(1)$ 更新；若从左往右枚举起点，就得每次重建计数数组。

### 3.4 示例演算

![固定右端点 i=8，j 从 7 往前扫](images/bw130_q3_scan.svg)

以 $s = $ `"fabccddg"`、$i = 8$（即整串）为例，$j$ 从 7 递减到 0：

| $j$ | 最后一段 | 长度 | 不同字符数 | 最大频次 | 平衡？ |
|-----|----------|------|-----------|----------|--------|
| 7 | `g` | 1 | 1 | 1 | ✓ |
| 6 | `dg` | 2 | 2 | 1 | ✓ |
| 5 | `ddg` | 3 | 2 | 2 | ✗（$3 \bmod 2 \ne 0$） |
| 4 | `cddg` | 4 | 3 | 2 | ✗（$4 \bmod 3 \ne 0$） |
| 2 | `bccddg` | 6 | 4 | 2 | ✗（$6/4$ 不是整数） |
| 0 | `fabccddg` | 8 | 6 | 2 | ✗（$8/6$ 不是整数） |

于是 $dp[8] = 1 + \min(dp[7], dp[6])$。该串的 DP 表是

$$dp = [0,\ 1,\ 1,\ 1,\ 1,\ 2,\ 2,\ 2,\ 3]$$

其中 $dp[7] = 2$（`fab` | `ccdd`）、$dp[6] = 2$（`fabc` | `cd`），故 $dp[8] = 3$，与示例输出一致。

## 4. 算法细节

1. **判据的两个条件都不能少**：只判 $L \bmod distinct = 0$ 会把 `ddg` 误判为平衡（长度 3、2 种字符，但 d 出现 2 次、g 出现 1 次）；只判 $mx = L/distinct$ 在整除不成立时毫无意义。
2. **`distinct` 的更新时机**：`cnt[c]` 从 0 变 1 时才 `distinct += 1`，之后重复出现不再增加。
3. **`mx` 单调不减**：因为只会往里加字符，最大频次不会下降，用 `mx = max(mx, cnt[c])` 即可。
4. **单字符段一定平衡**：$j = i-1$ 时 $L = k = M = 1$，所以 `dp[i] <= dp[i-1] + 1`，DP 一定有有限解，不会出现无解。
5. **`INF` 取 $n+1$**：最多 $n$ 段，取 $n+1$ 足以表示「不可达」，且 `dp[j] + 1` 不会溢出。
6. **复杂度来源**：外层 $n$ 次、内层平均 $n/2$ 次，每次 $O(1)$，总计 $O(n^2) = 10^6$；每个 $i$ 还要清空 26 个计数，$O(26n)$ 可忽略。
7. **不需要哈希表**：字符集固定 26，数组比哈希更快；若字符集更大（如 Unicode）才需要用哈希。
8. **答案的上下界**：$1 \le dp[n] \le n$；全同字符串答案是 1（整体平衡），完全无重复的字符串答案是 1（每个字符各 1 次，整体也平衡）。

## 5. 正确性证明

**引理 1（平衡判据）**：设子串长度为 $L$、出现过的不同字符数为 $k$、频次最大值为 $M$，则子串平衡 $\iff L = kM$。

**证明**：

- $(\Rightarrow)$ 若平衡，则每个出现过的字符频次都相等，设均为 $t$。则最大频次 $M = t$，且 $L = kt = kM$。
- $(\Leftarrow)$ 设 $L = kM$。$k$ 个出现过的字符频次之和为 $L = kM$，而每个频次都不超过最大值 $M$；若存在某个频次 $< M$，总和就严格小于 $kM$，矛盾。故所有频次都等于 $M$，子串平衡。∎

**推论 1**：平衡 $\iff L \bmod k = 0$ 且 $M = L/k$（因为 $L = kM$ 等价于 $k \mid L$ 且 $M = L/k$）。

**引理 2（最优子结构）**：设 $s[0..i-1]$ 的某个最优分割的最后一段是 $s[j..i-1]$，则该分割在 $s[0..j-1]$ 上的部分也是 $s[0..j-1]$ 的最优分割。

**证明**：若 $s[0..j-1]$ 存在段数更少的分割，用它替换原分割的前半部分，就得到 $s[0..i-1]$ 的段数更少的分割，与原分割最优矛盾。∎

**定理**：$\displaystyle dp[i] = 1 + \min_{j:\, s[j..i-1]\text{ 平衡}} dp[j]$ 且 $dp[n]$ 等于最少段数。

**证明**：对 $i$ 归纳。

- 可行性：对任一使 $s[j..i-1]$ 平衡的 $j$，把 $s[0..j-1]$ 的某个最优分割接上这一段，得到 $s[0..i-1]$ 的可行分割，段数 $dp[j] + 1$，故 $dp[i]$ 不超过转移式右端。
- 最优性：设 $s[0..i-1]$ 的最优分割最后一段为 $s[j^\*..i-1]$（由引理 1 的判据，该段平衡，$j^\*$ 在枚举范围内）。由引理 2，前半部分段数 $\ge dp[j^\*]$，故最优段数 $\ge dp[j^\*] + 1 \ge$ 转移式右端。

两式合并即得等式。基态 $dp[0] = 0$ 表示空前缀无需分割。∎

## 6. 复杂度分析

- **时间**：$O(n^2 + 26n)$。外层 $n$ 次、内层至多 $n$ 次、每次常数操作；$n = 1000$ 时约 $5 \times 10^5$ 次内层迭代。
- **空间**：$O(n + 26)$。$dp$ 数组 $O(n)$，字符计数与状态几个变量 $O(26)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minimumSubstringsInPartition(string s) {
        int n = s.size(), INF = n + 1;
        vector<int> dp(n + 1, INF);
        dp[0] = 0;
        for (int i = 1; i <= n; ++i) {
            int cnt[26] = {0}, distinct = 0, mx = 0;
            for (int j = i - 1; j >= 0; --j) {
                int c = s[j] - 'a';
                if (cnt[c] == 0) ++distinct;
                if (++cnt[c] > mx) mx = cnt[c];
                int len = i - j;
                // 平衡 ⇔ 最大频次 = 平均频次（各字符频次之和恰为 len）
                if (len % distinct == 0 && mx == len / distinct)
                    if (dp[j] + 1 < dp[i]) dp[i] = dp[j] + 1;
            }
        }
        return dp[n];
    }
};
```

### Python

```python
class Solution:
    def minimumSubstringsInPartition(self, s: str) -> int:
        n = len(s)
        INF = n + 1
        dp = [0] + [INF] * n
        for i in range(1, n + 1):
            cnt = [0] * 26
            distinct = mx = 0
            best = INF
            for j in range(i - 1, -1, -1):
                c = ord(s[j]) - 97
                if cnt[c] == 0:
                    distinct += 1
                cnt[c] += 1
                if cnt[c] > mx:
                    mx = cnt[c]
                length = i - j
                # 平衡 ⇔ 最大频次 == 平均频次（频次之和恰为 length）
                if length % distinct == 0 and mx == length // distinct:
                    if dp[j] + 1 < best:
                        best = dp[j] + 1
            dp[i] = best
        return dp[n]
```

> 💡 两份代码通过官方两个示例（`3` / `2`）与 `"a"`、`"aab"`、`"ab"` 等边界；在 400 组随机小串（$n \le 11$，字母表 `abc`）上与「枚举所有分割点 + 逐段排序判频次」的指数暴力对拍，`mismatch = 0`；另在 300 组更长的随机串（$n \le 60$）上与「DP + 独立平衡检查」的实现对拍一致。最长输入 $n = 1000$ 的运行时间在 0.1 s 量级。

## 8. 边界情况与易错点

1. **`len % distinct` 的整除判断不能省**：`ddg`（长度 3、2 种字符）整除不成立，如果不判就会把 $3/2$ 取整后误判。
2. **`distinct` 为 0 不可能出现**：内层循环从 $j = i-1$ 开始，至少会加入一个字符，所以不会除零；但若把内层写成「先判断后加入」就会踩坑。
3. **`mx` 只增不减**：因为只往里加字符，不会删；如果错误地写成「每次重算 26 个频次的最大值」，复杂度会多一个 26 的常数（仍可过，但没必要）。
4. **单字符段兜底**：$j = i-1$ 一定平衡，保证 `dp[i]` 有解；若忘记把 $j$ 扫到 $i-1$，`dp` 可能残留 `INF`。
5. **`INF` 的选择**：取 $n+1$ 即可；若取 `INT_MAX`，`dp[j] + 1` 有溢出风险。
6. **`dp[0] = 0`**：空前缀不需要段，这是整个 DP 的基态；漏写会让所有包含 $j = 0$ 的转移失效（答案偏大）。
7. **字符串下标**：$s[j..i-1]$ 的长度是 $i-j$，不是 $i-j+1$；这是本题最常见的 off-by-one。
8. **空串不存在**：题目保证 $|s| \ge 1$，但若做通用实现，$n = 0$ 时应返回 0。
