# LeetCode 向下取整数对和 题解

## 1. 题目概述

- **标题 / 题号**：向下取整数对和（#1862，hard）
- **链接**：https://leetcode.cn/problems/sum-of-floored-pairs/
- **来源**：LeetCode 第 52 场双周赛 Q4
- **难度**：困难
- **标签**：数组、数学、计数、前缀和、枚举

**题意**：给定整数数组 `nums`，返回所有下标对 $0 \le i, j < n$（含 $i = j$、两个方向各算一次）的 $\lfloor \mathit{nums}[i] / \mathit{nums}[j] \rfloor$ 之和，对 $10^9 + 7$ 取模。

**约束**：

- $1 \le n = \mathit{nums.length} \le 10^5$
- $1 \le \mathit{nums}[i] \le 10^5$

## 2. 示例

**示例 1**

```text
输入：nums = [2,5,9]
输出：10
解释：商为 0 的有 ⌊2/5⌋、⌊2/9⌋、⌊5/9⌋；商为 1 的有 ⌊2/2⌋、⌊5/5⌋、⌊9/9⌋；
     ⌊5/2⌋ = 2，⌊9/2⌋ = 4，⌊9/5⌋ = 1；合计 1+1+1+2+4+1 = 10。
```

**示例 2**

```text
输入：nums = [7,7,7,7,7,7,7]
输出：49
解释：所有数对商均为 1，共 7×7 = 49 个有序对。
```

**示例 3（边界补充）**

```text
输入：nums = [1]
输出：1
解释：唯一数对 (0,0)：⌊1/1⌋ = 1。
```

## 3. 解题思路

### 3.1 暴力思路

双重循环直接求和：$O(n^2) = 10^{10}$，超时。瓶颈：把"每一对"当成独立单元处理。突破口在值域——$1 \le \mathit{nums}[i] \le 10^5$ 且商只依赖**两个值**，把数组折叠成值域计数后按值聚合，对的数量就从 $n^2$ 降到 $U^2$（$U = 10^5$，仍不够）再到 $U \log U$。

### 3.2 核心观察一：商的本质是"倍数计数"

![按分母 d 的倍数分段统计](images/bw52_q4_multiples_intervals.svg)

固定分母 $d$，对任意分子 $x$：

$$\left\lfloor \frac{x}{d} \right\rfloor = \#\{\,k \ge 1 : k \cdot d \le x\,\}$$

即"$x$ 除以 $d$ 的商"等于"不超过 $x$ 的 $d$ 的正倍数个数"。把求和顺序交换（**双重计数**）：

$$S(d) = \sum_i \left\lfloor \frac{\mathit{nums}[i]}{d} \right\rfloor = \sum_{k \ge 1} \#\{\,i : \mathit{nums}[i] \ge k \cdot d\,\}$$

数轴上按 $d$ 的倍数 $d, 2d, 3d, \dots$ 切段：落在 $[kd,\ (k+1)d)$ 内的数贡献商 $k$；等价地，每个倍数线 $kd$ 左侧的数都被"数一次"。整条数轴只需要**一个前缀和数组**就能 $O(1)$ 回答任何 $\#\{\mathit{nums} \ge t\}$。

### 3.3 核心观察二：按分母聚合 + 调和级数枚举

![cnt 前缀和：任意区间计数 O(1)](images/bw52_q4_prefix_count.svg)

设 $\mathit{cnt}[v]$ 为值 $v$ 的出现次数（$v \le U = \max(\mathit{nums})$），$\mathit{pre}[v] = \sum_{t \le v} \mathit{cnt}[t]$。分母为 $d$ 的有序对贡献系数 $\mathit{cnt}[d]$，于是：

$$\mathit{answer} = \sum_{d = 1}^{U}\ \mathit{cnt}[d] \cdot S(d), \qquad S(d) = \sum_{k=1}^{\lfloor U/d \rfloor} \big(n - \mathit{pre}[kd - 1]\big)$$

只对 $\mathit{cnt}[d] > 0$ 的 $d$ 枚举倍数，总计算量为调和级数 $\sum_{d=1}^{U} \lfloor U/d \rfloor \approx U \ln U \approx 1.2 \times 10^6$（$U = 10^5$）——与埃氏筛同一量级，**$O(U \log U)$**。

### 3.4 示例演算

![示例演算：nums = [2,5,9]，7+2+1 = 10](images/bw52_q4_walkthrough.svg)

以 $[2,5,9]$ 为例：$d=2$ 时倍数 $2,4,6,8$，$\#\ge 2,4,6,8 = 3,2,1,1$，$S(2) = 7 = \lfloor2/2\rfloor+\lfloor5/2\rfloor+\lfloor9/2\rfloor = 1+2+4$；$d=5$ 时 $S(5) = 2+0 = 2$；$d=9$ 时 $S(9) = 1$。其余值的 $\mathit{cnt}=0$ 跳过。$\mathit{answer} = 7 + 2 + 1 = 10$，与官方一致。

## 4. 算法细节

1. **值域计数与前缀和**：`cnt[v]`、`pre[v] = pre[v-1] + cnt[v]` 均 $O(U)$ 一趟建立；$\#\{\mathit{nums} \ge t\} = n - \mathit{pre}[t-1]$（$t \ge 1$，`pre[0] = 0`）。
2. **只枚举出现过的分母**：`cnt[d] == 0` 直接跳过——分母不存在的值贡献为零，这一剪枝在稀疏数据下把枚举量降到"不同值个数 × 各自倍数个数"。
3. **两种等价形式**：段计数式 $S(d) = \sum_k k \cdot \#\{\mathit{nums} \in [kd,\ (k+1)d)\}$（直觉）与后缀计数式 $S(d) = \sum_k (n - \mathit{pre}[kd-1])$（实现）由"每段贡献 $k$"翻转成"每条倍数线右侧各计一次"得来，后者代码最短。
4. **溢出**：$S(d) \le n \cdot U/d \le 10^{10}$（$d=1$ 且全部取 $10^5$ 时），单变量必须用 64 位；$\mathit{cnt}[d] \cdot S(d)$ 可达 $10^{15}$，`long long` 仍安全，但**每项乘完就取模**更稳。Python 无溢出问题，直接每项模即可。
5. **换边求和的对偶**：也可以枚举分子值 $v$——$\sum_d \mathit{cnt}[d]\lfloor v/d \rfloor = \sum_{k \ge 1} \mathit{pre}[\lfloor v/k \rfloor]$，配合**整除分块**每值 $O(\sqrt v)$；两种求和边的选择是同一张 $(d,k)$ 二维表的两种扫描方向（见延伸思考）。
6. **模运算时机**：`ans = (ans + cnt[d] % MOD * (s % MOD)) % MOD`——先各自缩到 $10^9$ 内再乘，中间量 $< 10^{18}$，`long long` 安然无恙。
7. **调和级数核对**：$\sum_{d=1}^{10^5} \lfloor 10^5/d \rfloor \approx 10^5 (\ln 10^5 + 0.577) \approx 1.2 \times 10^6$，这就是内层循环的总步数，Python 也只需百毫秒级。

## 5. 正确性证明

**引理 1（商的计数刻画）**：对正整数 $x$ 与正整数 $d$，$\lfloor x/d \rfloor = \#\{\,k \in \mathbb{Z}^+ : kd \le x\,\}$。

**证明**：$kd \le x \iff k \le x/d \iff k \le \lfloor x/d \rfloor$（$k$ 为整数），满足条件的正整数 $k$ 恰有 $\lfloor x/d \rfloor$ 个。∎

**引理 2（双重计数）**：$S(d) := \sum_{i=1}^{n} \lfloor \mathit{nums}[i]/d \rfloor = \sum_{k=1}^{\lfloor U/d \rfloor} \#\{\,i : \mathit{nums}[i] \ge kd\,\}$，其中 $U = \max(\mathit{nums})$。

**证明**：由引理 1，$S(d) = \sum_i \#\{k \ge 1 : kd \le \mathit{nums}[i]\} = \#\{\,(i, k) : k \ge 1,\ kd \le \mathit{nums}[i]\,\}$。交换求和顺序（有限个非零项，$kd \le \mathit{nums}[i] \le U$ 限制 $k \le \lfloor U/d \rfloor$），得 $\sum_{k=1}^{\lfloor U/d \rfloor} \#\{i : \mathit{nums}[i] \ge kd\}$。∎

**定理（主公式）**：记 $\mathit{pre}[v] = \#\{i : \mathit{nums}[i] \le v\}$（$\mathit{pre}[0] = 0$），则

$$\sum_{i,j} \left\lfloor \frac{\mathit{nums}[i]}{\mathit{nums}[j]} \right\rfloor = \sum_{d=1}^{U} \mathit{cnt}[d] \sum_{k=1}^{\lfloor U/d \rfloor} \big(n - \mathit{pre}[kd-1]\big)$$

**证明**：左边按分母取值分组：分母等于 $d$ 的下标 $j$ 有 $\mathit{cnt}[d]$ 个，每个贡献相同的内层和 $S(d)$，故左边 $= \sum_{d=1}^{U} \mathit{cnt}[d] \cdot S(d)$（$d$ 取遍值域，$\mathit{cnt}[d] = 0$ 的项自动为零）。对每个 $d$，由引理 2 及 $\#\{\mathit{nums} \ge t\} = n - \#\{\mathit{nums} \le t-1\} = n - \mathit{pre}[t-1]$（$t = kd \ge 1$），代入 $t = kd$ 即得右端。算法按右端逐项计算并对 $10^9+7$ 取模，同余意义下相等。∎

## 6. 复杂度分析

- **时间**：$O(n + U \log U)$。计数与前缀和 $O(n + U)$；倍数枚举总量 $\sum_{d:\ \mathit{cnt}[d] > 0} \lfloor U/d \rfloor \le \sum_{d=1}^{U} \lfloor U/d \rfloor \approx U \ln U \approx 1.2 \times 10^6$。代入 $n = U = 10^5$ 约 $2 \times 10^6$ 量级操作。
- **空间**：$O(U)$。`cnt`、`pre` 两个长度 $10^5 + 1$ 的数组；答案与累加器 $O(1)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int sumOfFlooredPairs(vector<int>& nums) {
        const long long MOD = 1000000007;
        int n = nums.size();
        int U = *max_element(nums.begin(), nums.end());
        vector<long long> cnt(U + 1, 0), pre(U + 1, 0);
        for (int x : nums) ++cnt[x];             // 值域计数
        for (int v = 1; v <= U; ++v) pre[v] = pre[v - 1] + cnt[v];

        long long ans = 0;
        for (int d = 1; d <= U; ++d) {           // 枚举作为分母的值 d
            if (cnt[d] == 0) continue;
            long long s = 0;                     // S(d) = Σ_i floor(nums[i]/d)
            for (long long m = d; m <= U; m += d)
                s += n - pre[m - 1];            // 每个 k：#nums >= k*d
            ans = (ans + cnt[d] % MOD * (s % MOD)) % MOD;
        }
        return (int)ans;
    }
};
```

### Python

```python
class Solution:
    def sumOfFlooredPairs(self, nums: list[int]) -> int:
        MOD = 10 ** 9 + 7
        n = len(nums)
        U = max(nums)
        cnt = [0] * (U + 1)
        for x in nums:
            cnt[x] += 1                          # 值域计数
        pre = [0] * (U + 1)
        for v in range(1, U + 1):
            pre[v] = pre[v - 1] + cnt[v]

        ans = 0
        for d in range(1, U + 1):               # 枚举作为分母的值 d
            if cnt[d] == 0:
                continue
            s = 0                                # S(d) = Σ_i floor(nums[i]/d)
            for m in range(d, U + 1, d):
                s += n - pre[m - 1]             # 每个 k：#nums >= k*d
            ans = (ans + cnt[d] * s) % MOD
        return ans
```

> 💡 两份代码均通过官方 2 组示例；另与 $O(n^2)$ 双重循环暴力在 1440 组随机数组（$n \le 200$、值域 $\le 1000$）上对拍一致；$n = 10^5$、值随机 $\le 10^5$（调和级数最坏形态）实测 C++ 约 100ms、Python 约 110ms。

## 8. 边界情况与易错点

1. **有序对含 $i = j$**：$\lfloor x/x \rfloor = 1$ 的 $n$ 项必须计入；只算 $i \ne j$ 会少 $n$。全相同数组 $[7 \times 7]$ 的答案 $49 = 7^2$ 是最直接的自检。
2. **溢出是本题最大的坑**：$S(1)$ 可达 $\sum \mathit{nums}[i] \le 10^{10}$，`int` 直接爆；C++ 内层累加器、`cnt`、`pre` 都用 `long long`，乘法先模再乘。Python 任意精度无此问题，但仍建议每项取模控制数值规模。
3. **`pre[m-1]` 的下标**：$m$ 从 $d$ 开始，$m - 1 \ge 0$；`pre[0] = 0` 必须显式存在（数组从下标 0 开到 $U$）。
4. **只枚举 `cnt[d] > 0` 的 $d$**：跳过空值既省时间又避免无意义的大循环；但注意 $d$ 的循环上限是 $U$（最大值），不是 $n$。
5. **模后比较**：与暴力对拍时，暴力也要对 $10^9 + 7$ 取模再比（两边的真值都可能超过模数）。
6. **值域小、个数多**：$n = 10^5$ 个值挤在小值域（如全部 $\le 100$）时 $\mathit{cnt}$ 高度集中，调和级数枚举反而更快——复杂度按 $U$ 而非 $n$ 走，这正是值域计数法的红利。

**延伸思考**：本题是**整除结构**上双重计数的教科书案例：$\lfloor x/d \rfloor$ 同时是"$x$ 对 $d$ 的商"和"不超过 $x$ 的倍数个数"，于是 $\sum_{i,j}$ 既可以按分母 $d$ 扫（本文实现，配前缀和），也可以按分子 $v$ 扫：$\sum_d \mathit{cnt}[d]\,\lfloor v/d \rfloor = \sum_{k \ge 1} \mathit{pre}[\lfloor v/k \rfloor]$——后者中 $\lfloor v/k \rfloor$ 只有 $O(\sqrt v)$ 个不同取值，可用**整除分块**（数论分块）把每个值压到 $O(\sqrt U)$，总体 $O(U \sqrt U)$（比调和级数差，但在"单点查询"场景必须用它）。把两个方向合起来看，就是数论中 $\sum_{d} \lfloor n/d \rfloor = \sum_{k} \mathit{pre}[n/k]$ 这一经典对偶：**换边求和**。
