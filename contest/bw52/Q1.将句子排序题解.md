# LeetCode 将句子排序 题解

## 1. 题目概述

- **标题 / 题号**：将句子排序（#1859，easy）
- **链接**：https://leetcode.cn/problems/sorting-the-sentence/
- **来源**：LeetCode 第 52 场双周赛 Q1
- **难度**：简单
- **标签**：字符串、排序

**题意**：一个句子是单词用单个空格连接、首尾无空格的序列，每个单词只含英文字母。给句子中每个单词加上从 $1$ 开始的**位置编号**（附在单词末尾），再打乱顺序得到 $s$。要求根据打乱的 $s$ 还原出原始句子。

**约束**：

- $2 \le s.length \le 200$
- $s$ 只包含大小写英文字母、空格和数字 $1 \sim 9$
- $s$ 中单词数为 $1 \sim 9$ 个，单词间以单个空格分隔，无前后缀空格
- 每个单词末尾恰有一个表示位置的数字，且编号恰好是 $1 \sim \mathit{cnt}$ 的排列

## 2. 示例

**示例 1**

```text
输入：s = "is2 sentence4 This1 a3"
输出："This is a sentence"
解释：按尾部编号排序得 This1 is2 a3 sentence4，去掉编号即原句。
```

**示例 2**

```text
输入：s = "Myself2 Me1 I4 and3"
输出："Me Myself and I"
解释：按尾部编号排序得 Me1 Myself2 and3 I4，去掉编号即原句。
```

**示例 3（边界补充）**

```text
输入：s = "LeetCode1"
输出："LeetCode"
解释：单词数为 1，无需任何重排，掐掉编号即可。
```

## 3. 解题思路

### 3.1 暴力思路

把单词切出来，对每个单词掐尾取编号，然后**真的做一次比较排序**（按尾部数字从小到大 `sort`），再拼接去编号。$O(m \log m)$（$m$ 为单词数 $\le 9$），毫无压力。但更妙的观察是：编号是 $1 \sim m$ 的排列，**根本不用排序**——每个单词直接"落桶"到自己的位置。

### 3.2 核心观察：尾部数字就是数组下标

![桶放置：单词尾部的数字就是它在原句中的位置](images/bw52_q1_bucket_place.svg)

编号范围 $1 \sim 9$ 与单词个数 $m$ 一一对应，正好开一个长度为 $m$ 的桶数组 `slot`：对每个单词 $w$（含尾部编号），执行

```text
slot[int(w[-1]) − 1] ← w[:-1]        # 掐掉尾编号，按编号直接放入对应下标
```

一趟放置，最后 `join` 还原。没有任何比较、任何排序——位置信息已经"编码"在数据里，题目只是要你把它读出来。

### 3.3 算法流程

```text
1. words = s.split()                    # 单个空格切分
2. slot = [""] * len(words)
3. 对每个 w in words：slot[int(w[-1]) − 1] = w[:-1]
4. 返回 " ".join(slot)
```

### 3.4 示例演算

![示例演算：Myself2 Me1 I4 and3 → Me Myself and I](images/bw52_q1_walkthrough.svg)

`"Myself2 Me1 I4 and3"` 切分得 4 个词：`Me1 → 桶 1`、`Myself2 → 桶 2`、`and3 → 桶 3`、`I4 → 桶 4`，按桶序拼接输出 `"Me Myself and I"`，与官方一致。

## 4. 算法细节

1. **切分用 `split()`**：题目保证单词间恰一个空格、无首尾空格，`split()` 与 `split(" ")` 等价且更稳（`split()` 自动忽略多余空白，虽然本题用不上）。
2. **`w[-1]` 是编号字符**：`int(w[-1]) - 1` 把 `'1'` 映射到下标 0——**别忘了减 1**，直接 `int(w[-1])` 当下标会越界（编号 9 时）或错位。
3. **掐尾**：`w[:-1]` 去掉最后一个字符；单词本体可能含大写开头（如 `This`），编号必在末尾一位，不需要 `isdigit()` 判断——题目保证单词本体只含字母。
4. **C++ 手工切分**：末尾补一个空格统一收尾逻辑（`s += ' '`），逐字符攒词、遇空格结算；或者用 `getline(cin, token, ' ')` 风格。攒词时 `cur.back() - '1'` 直接得到桶下标，`cur.pop_back()` 掐尾。
5. **桶长就是单词数**：编号恰是 $1 \sim m$ 的排列，`len(words)` 即桶数，无需 9。
6. **join 时补单空格**：输出必须与输入格式一致——单词间单个空格、无前后缀空格；Python `" ".join` 天然满足，C++ 手拼时首个词前不加空格。

## 5. 正确性证明

**引理 1（编号的下标性质）**：设单词数为 $m$，则编号集合恰为 $\{1, \dots, m\}$ 且互不相同，故对任意单词 $w$，$\mathit{int}(w[-1]) - 1 \in [0, m-1]$ 且两两不同。

**证明**：编号是对 $1 \sim m$ 中每个位置恰标注一次后打乱所得，是一个排列。∎

**定理（桶放置正确性）**：算法输出的句子，第 $i$ 个单词恰是原句中编号为 $i + 1$ 的单词去掉编号后的本体。

**证明**：由引理 1，每个单词被写入且仅被写入下标 $\mathit{int}(w[-1]) - 1$，即编号 $i+1$ 的单词落在 `slot[i]`；写入值掐去末位编号，保留本体（本体不含数字，末位必为编号）。`join` 按下标 $0 \sim m-1$ 顺序连接，第 $i$ 个输出单词即编号 $i+1$ 的本体，正是原始句子的第 $i + 1$ 个词（编号 $i+1$ 表示原句位置 $i+1$）。∎

## 6. 复杂度分析

- **时间**：$O(L)$，$L = |s|$ 为串长（$\le 200$）。切分、放桶、拼接各扫一遍，每个字符 $O(1)$ 处理。
- **空间**：$O(L)$。桶数组存全部单词本体；不计输出的额外空间 $O(m)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    string sortSentence(string s) {
        vector<string> slot(9);                   // 单词数最多 9，按编号直接放桶
        int cnt = 0;
        string cur;
        s += ' ';                                 // 末尾补空格，统一收尾逻辑
        for (char c : s) {
            if (c == ' ') {
                slot[cur.back() - '1'] = cur.substr(0, cur.size() - 1);
                ++cnt;
                cur.clear();
            } else {
                cur.push_back(c);
            }
        }
        string ans;
        for (int i = 0; i < cnt; ++i) {           // 按编号顺序拼接
            if (i) ans += ' ';
            ans += slot[i];
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def sortSentence(self, s: str) -> str:
        words = s.split()
        slot = [""] * len(words)                 # 单词数即桶数
        for w in words:
            slot[int(w[-1]) - 1] = w[:-1]       # 尾部数字即位置，掐头去尾入桶
        return " ".join(slot)
```

> 💡 两份代码均通过官方 2 组示例；另与「按尾字符比较排序 + 掐尾拼接」的独立参考实现在 6000 组随机打乱句（单词数 $1 \sim 9$、单词本体随机大小写字母）上三方一致（题解 C++ / 题解 Python / 参考实现）。

## 8. 边界情况与易错点

1. **单词数为 1**：只有一个词，桶放置后 `join` 无空格，别多拼出一个空格（C++ 手拼时首词前不加空格的逻辑要覆盖 `cnt = 1`）。
2. **编号减一**：`int(w[-1]) - 1` 才是 0 起始下标；直接当下标用，编号 9 会越界、编号 1 会错位。
3. **桶按单词数开**：开 9 个也行（编号最大 9），但按 `len(words)` 开能顺带用编号做完备性自查（若数据不合法会越界报错，容易发现）。
4. **掐尾只掐一位**：单词本体只含字母、编号恰占末尾一位；写成"去掉所有数字"在合法输入下等价，但对末位多数字的自造数据会歧义——按题目保证掐一位即可。
5. **C++ 补空格技巧**：`s += ' '` 让最后一个单词也走统一的"遇空格结算"分支，避免循环后单独处理残词。
6. **`sort` 是陷阱般的名字**：函数名 `sortSentence` 很容易诱导人真去 `sort`，$m \le 9$ 时也能过，但桶放置 $O(L)$ 更能体现"位置已编码在数据里"的观察。
