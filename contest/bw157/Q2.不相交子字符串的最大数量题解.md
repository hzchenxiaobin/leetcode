# LeetCode 不相交子字符串的最大数量 题解

## 1. 题目概述

- **标题 / 题号**：不相交子字符串的最大数量（#3557，medium）
- **链接**：https://leetcode.cn/problems/find-maximum-number-of-non-intersecting-substrings/
- **来源**：LeetCode 第 157 场双周赛 Q2
- **难度**：中等
- **标签**：贪心、哈希表、字符串、动态规划

**题意**：给定字符串 `word`。选出尽可能多的**互不相交**的子字符串，每个子串必须满足：

1. **首尾字母相同**；
2. **长度至少为 4**。

返回这样的子串数量的**最大值**。

**约束**：

- $1 \le |word| \le 2 \times 10^5$
- `word` 仅由小写英文字母组成

> 💡 长度下界 4 等价于「首尾下标之差 $\ge 3$」。这个「只差一个 1」的换算，是本题最容易写错的地方。

## 2. 示例

**示例 1**

```text
输入：word = "abcdeafdef"
输出：2
解释：可以选 "abcdea"（下标 0..5，首尾都是 a）与 "fdef"（下标 6..9，首尾都是 f）。
```

**示例 2**

```text
输入：word = "bcdaaaab"
输出：1
解释：能选的只有 "aaaa"；若选整串 "bcdaaaab" 就只剩 1 段，不如选 "aaaa" 后不能再选（右侧无剩余）。
```

**示例 3（自造）**

```text
输入：word = "aaaa"
输出：1
解释：整串首尾都是 a、长度 4，只能选出 1 段（"aa" 长度不足 4）。
```

## 3. 解题思路

### 3.1 暴力思路

一个自然的 DP：设 $f[i]$ 表示前缀 `word[0..i]` 内能选出的最大段数，则

$$f[i] = \max\Big(f[i-1],\ \max_{j \le i-3,\ word[j] = word[i]}\big(f[j-1] + 1\big)\Big)$$

时间复杂度 $O(n^2)$，$n = 2\times 10^5$ 时是 $4\times 10^{10}$，必然超时。注意到转移里对每个右端点 $i$ 都要枚举所有同字母的左端点 $j$，信息高度冗余——对固定的字母 $c$，只有**最早**出现的那个 $j$ 才可能最优。

### 3.2 核心观察：只用「最早出现的同字母」+ 立即收割

![贪心收割：能凑出长度 >= 4 的同字母子串就立即切](images/bw157_q2_greedy_cut.svg)

维护一个长度为 26 的数组 `first[c]`，含义是「**当前尚未被切割的那一段区间**里，字母 $c$ 最早出现的下标」。从左到右扫描 $i$：

- 若 `first[c]` 还没记录，令 `first[c] = i`；
- 否则若 $i - \text{first}[c] \ge 3$，说明 $[\text{first}[c],\ i]$ 是一段合法子串，**立刻收割**：答案 $+1$，并把整个 `first[]` 清空（下一段只能从 $i+1$ 开始）。

关键点：

1. **为什么只看最早的 $j$**：同一右端点 $i$ 下，左端点越靠左，子串越长、占用越多，且不改变「选到 1 段」的收益，所以最早的 $j$ 是最优的（甚至更靠左也无法再多出一段，因为已经收割过了）。
2. **为什么可以立即收割**：$i$ 是「当前区间内第一个能收割的位置」。任何其他合法方案若在这一区间里选了以 $q \ge i$ 结尾的段，把它的右端点换成 $i$ 不会让剩余区间变短——剩余区间是 $[i+1, n)$ 的后缀形式，右端点越小剩余越大。
3. **为什么收割后要清空**：子串不能相交，$i$ 及之前的字符都已被占用，新的候选左端点必须 $> i$。

### 3.3 算法流程

![一趟扫描的判定与收割](images/bw157_q2_flow.svg)

```text
1. first[26] 全部置 -1；ans = 0
2. for i = 0 .. n-1:
       c = word[i] - 'a'
       若 first[c] == -1:  first[c] = i            # 只记最早一次
       否则若 i - first[c] >= 3:                    # 长度 >= 4 且首尾同字母
           ans += 1
           first[] 全部置 -1                        # 从 i+1 开始重新计
3. 返回 ans
```

### 3.4 示例演算

![演算：abcdeafdef 的两个被收割子串](images/bw157_q2_example_walk.svg)

| $i$ | 字符 | `first[c]` | 判定 | 动作 |
|-----|------|-----------|------|------|
| 0 | a | - | 首次出现 | `first[a] = 0` |
| 1~4 | b,c,d,e | - | 首次出现 | 记 1,2,3,4 |
| 5 | a | 0 | $5-0=5 \ge 3$ | `ans = 1`，清空 `first` |
| 6,7,8 | f,d,e | - | 首次出现 | 记 6,7,8 |
| 9 | f | 6 | $9-6=3 \ge 3$ | `ans = 2`，清空 `first` |

最终答案 $2$，两段分别是 `"abcdea"` 与 `"fdef"`。示例 2 中 `"bcdaaaab"`：$i=3$ 首次记 a，$i=4,5$ 差不足 3，$i=6$ 时 $6-3=3$，收割 `"aaaa"`，此后没有剩余字符，答案为 1。

## 4. 算法细节

1. **`first[]` 的语义**：不是「历史上第一次出现」，而是「**当前未切割区间内**第一次出现」。所以每次收割后必须整体清空，否则会把已被占用的位置当成新左端点。
2. **判定顺序**：先判 `first[c] == -1`，再判差值，避免用 `-1` 参与减法得到假的「差很大」。
3. **长度换算**：长度 $= i - j + 1 \ge 4 \iff i - j \ge 3$。写成 $\ge 4$ 是本题最常见的 off-by-one。
4. **清空代价**：`fill(first, first+26, -1)` 是 $O(26)$，而收割次数不超过 $n/4$，合计仍与 $O(n)$ 同阶；也可以记录一个「当前区间起始位置」来避免清空。
5. **只记最早一次**：不需要记录每个字母的全部出现位置，因为同一字母第二次出现时若差不足 3，第三次出现时与首次的差一定更大（下标单调递增），迟早会满足条件。
6. **答案上界**：每段至少 4 个字符，所以答案 $\le \lfloor n/4 \rfloor$，用 `int` 足够。

## 5. 正确性证明

**引理 1（合法性）**：若算法在 $i$ 处收割 $[j, i]$（$j = \text{first}[c]$），则 `word[j] = word[i]` 且 $i - j + 1 \ge 4$。

**证明**：$j$ 是字母 $c = \text{word}[i]$ 在当前区间内的出现位置，故 `word[j] = word[i]`；判定条件为 $i - j \ge 3$，故长度 $i-j+1 \ge 4$。而 $j$ 属于当前未切割区间，即 $j$ 大于上一次收割的右端点，故与已选子串不相交。∎

**引理 2（贪心交换）**：设在当前区间（起点 $l$，此前已选 $k$ 段）中，$i$ 是第一个能形成合法子串的右端点（即存在 $j \ge l$ 使 `word[j] = word[i]` 且 $i-j\ge3$）。则存在一个最优解，其第 $k+1$ 段取 $[\text{first}[c], i]$。

**证明**：设某个最优解的第 $k+1$ 段为 $[a, b]$，$b \ge i$（$b < i$ 不可能，因为 $i$ 之前没有可收割的位置，而 $[a,b]$ 首尾同字母、长度 $\ge 4$ 意味着 $b$ 是可收割位置）。把该段换成 $[j, i]$，其中 $j = \text{first}[c] \ge l$：

- 由引理 1，$[j, i]$ 合法且与已选段不相交；
- 替换后剩余可用区间为 $[i+1, n)$，而原方案剩余区间为 $[b+1, n) \subseteq [i+1, n)$，剩余部分严格包含关系，故原方案在剩余部分能选的段数不超过替换后的；总数不变差；
- 段数仍为 $k+1$，不减少。

于是该最优解可被改造成包含 $[j, i]$ 的解，且总段数不减。∎

**定理**：算法的返回值等于题目要求的最大段数。

**证明**：对「已经收割的段数」做归纳：每次收割（引理 1）后状态仍是「已选若干不相交合法段 + 一段未使用区间」，由引理 2 可知贪心选择不劣于任何最优解的前缀选择。算法结束时（无法再收割）由引理 2 的论证，任何更优解都可以逐段替换成贪心解而不减少段数，故贪心值即最优值。∎

## 6. 复杂度分析

- **时间**：$O(26n) = O(n)$。每个字符 $O(1)$ 判定；收割时的清空是 $O(26)$，而收割次数 $\le n/4$，总清空代价 $O(26n/4)$，与主循环同阶。$n = 2\times 10^5$ 时约 $10^6$ 量级操作。
- **空间**：$O(26) = O(1)$。只有一个长为 26 的整数数组。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maxSubstrings(string word) {
        int n = (int)word.size();
        vector<int> first(26, -1);   // 当前「未切割区间」里每个字母最早出现的下标
        int ans = 0;
        for (int i = 0; i < n; i++) {
            int c = word[i] - 'a';
            if (first[c] < 0) {
                first[c] = i;        // 首次出现，记为左端点候选
            } else if (i - first[c] >= 3) {
                // 长度 >= 4 且首尾同字母：立刻收割，并以 i 之后作为新区间起点
                ans++;
                fill(first.begin(), first.end(), -1);
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maxSubstrings(self, word: str) -> int:
        n = len(word)
        first = {}          # 当前「未切割区间」里每个字母最早出现的下标
        ans = 0
        for i, ch in enumerate(word):
            if ch not in first:
                first[ch] = i          # 首次出现，记为左端点候选
            elif i - first[ch] >= 3:
                # 长度 >= 4 且首尾同字母：立刻收割，并以 i 之后作为新区间起点
                ans += 1
                first.clear()
        return ans
```

## 8. 边界情况与易错点

1. **长度判定要写 $\ge 3$（下标差）而不是 $\ge 4$**：`i - first[c] >= 3` 对应长度 4；写成 `>= 4` 会漏掉所有长度恰为 4 的子串。
2. **收割后必须清空 `first[]`**：否则会把已经用掉的字符当成新子串的左端点，选出相交的段。
3. **只记最早出现**：重复写入 `first[c] = i` 会丢掉最优左端点，答案偏小。
4. **`"aaaa"` 只能选 1 段**：首尾 a、长度 4；不能拆成两段 `"aa"`（长度不足 4）。
5. **`"abcdeafdef"` 的 5 与 3**：$i=5$ 时差为 5（≥3）也能收割，说明条件不是「恰好 3 或 4」。
6. **全部字符都只出现一次**（如 `"abcdefg"`）：答案 0，循环里不会触发收割，无需特判。
7. **`n < 4`**：不可能有合法子串，答案自然为 0。
