# LeetCode 给边赋权值的方案数 I 题解

## 1. 题目概述

- **标题 / 题号**：给边赋权值的方案数 I（#3558，medium）
- **链接**：https://leetcode.cn/problems/number-of-ways-to-assign-edge-weights-i/
- **来源**：LeetCode 第 157 场双周赛 Q3
- **难度**：中等
- **标签**：树、深度优先搜索、数学

**题意**：给定一棵以节点 $1$ 为根的 $n$ 个节点的无向树（用 `edges` 给出）。每条边初始权重为 $0$，你可以把它改成 $1$ 或 $2$。一条路径的**代价**是路径上所有边权之和。

选择一个**深度最大**的节点 $x$，返回「从根 $1$ 到 $x$ 的路径代价为**奇数**」的赋值方案数（只考虑这条路径上的边，其余边忽略），答案对 $10^9+7$ 取模。

**约束**：

- $2 \le n \le 10^5$
- `edges.length == n - 1`，`edges[i] == [u_i, v_i]`
- `edges` 表示一棵合法的树

> 💡 题目里「选择任意一个深度最大的节点」只是障眼法：所有最深节点的深度相同，路径长度一样，方案数也就一样。

## 2. 示例

**示例 1**

```text
输入：edges = [[1,2]]
输出：1
解释：路径只有 1 条边。取 1 时代价为奇，取 2 时代价为偶，故只有 1 种合法方案。
```

**示例 2**

```text
输入：edges = [[1,2],[1,3],[3,4],[3,5]]
输出：2
解释：最大深度为 2（节点 4、5）。路径 1→3→4 有 2 条边，(1,2) 与 (2,1) 两种赋值的代价为奇。
```

**示例 3（自造）**

```text
输入：edges = [[1,2],[2,3],[3,4],[3,5]]
输出：4
解释：最大深度为 3（节点 4、5），路径有 3 条边，奇数和方案数 = 2^(3-1) = 4。
```

## 3. 解题思路

### 3.1 暴力思路

先求最大深度 $d$（BFS/DFS 一遍即得），然后枚举这条路径上 $d$ 条边的全部 $2^d$ 种 $\{1,2\}$ 赋值，逐一统计代价为奇数的方案数。$d$ 最大可以到 $n-1 = 10^5$，$2^{10^5}$ 完全不可行——**必须找出方案数的闭合公式**。

### 3.2 核心观察：只看「权重为 1 的边数的奇偶性」

![最大深度 d 决定答案 2^(d-1)](images/bw157_q3_depth_model.svg)

- 权重只有 $1$（**奇**）和 $2$（**偶**）两种选择，所以**路径代价的奇偶性**等于路径上「权重为 $1$ 的边」个数的奇偶性，与「权重为 $2$ 的边」的个数无关。
- 于是问题化为：在 $d$ 个位置（每条边一个）各投一枚硬币（$1$ 或 $2$），问「出现奇数个 $1$」的投法数。
- 这是一个经典结论：$d \ge 1$ 时，**恰好一半**的投法含有奇数个 $1$，即

$$\text{方案数} = \frac{2^d}{2} = 2^{d-1}$$

直观解释（对合论证）：固定前 $d-1$ 条边的取值（共 $2^{d-1}$ 种），最后一条边**唯一确定**——想要奇数代价就取 $1$，想要偶数代价就取 $2$。因此奇、偶代价的赋值数都是 $2^{d-1}$。

### 3.3 算法流程

![算法流程（I 版）](images/bw157_q3_flow.svg)

```text
1. 建邻接表（无向）
2. BFS/DFS 从节点 1 出发，计算每个节点的 depth[]
3. maxDepth = max(depth)
4. 返回 2^(maxDepth-1) mod (1e9+7)        # n >= 2，故 maxDepth >= 1
```

### 3.4 示例演算

![d 条边上奇数代价的赋值数正好是一半](images/bw157_q3_pow2_parity.svg)

| 边数 $d$ | 全部赋值 | 代价为奇的赋值 | 数量 |
|---------|---------|---------------|------|
| 1 | $\{1\},\{2\}$ | $\{1\}$ | $2^0 = 1$ |
| 2 | $\{11,12,21,22\}$ | $\{12, 21\}$ | $2^1 = 2$ |
| 3 | 共 8 种 | 4 种（含奇数个 1） | $2^2 = 4$ |

对示例 2：最大深度为 $2$，路径 $1 \to 3 \to 4$ 有 2 条边，答案 $2^{2-1} = 2$，与官方输出一致。示例 1 的 $d = 1$ 得 $2^0 = 1$。

## 4. 算法细节

1. **深度定义**：根的深度为 $0$，每条边让深度 $+1$；路径上的边数恰等于终点的深度。
2. **无从根可达性问题**：输入保证是一棵合法树，从节点 1 出发 BFS 能访问全部节点，`depth` 不会残留 $-1$。
3. **指数非负**：$n \ge 2$ 保证 $d \ge 1$，指数 $d-1 \ge 0$，快速幂天然返回 $1$（$d=1$ 时）。
4. **取模**：$2^{10^5}$ 有 3 万多位十进制数，必须在计算过程中取模；用快速幂 $O(\log d)$，或预处理 $2$ 的幂表 $O(n)$。
5. **PyPy / Python 的 `pow(2, d-1, MOD)`** 是内置的三参数快速幂，直接可用。
6. **不要乘上路径外的边**：题目明确「忽略路径外的所有边」，因此答案与 $n$、与树的形状都无关，只与最大深度有关。

## 5. 正确性证明

**引理 1（奇偶性归约）**：路径代价的奇偶性 $\iff$ 路径上权重为 $1$ 的边数的奇偶性。

**证明**：设路径有 $a$ 条边取权 $1$、$b$ 条边取权 $2$，则代价 $= a + 2b$，于是 $a + 2b \equiv a \pmod 2$。∎

**引理 2（一半法则）**：对 $d \ge 1$ 条边的路径，使代价为奇数的赋值方案数恰为 $2^{d-1}$。

**证明**：构造映射 $f$：对任意赋值，翻转**最后一条边**的权重（$1 \leftrightarrow 2$）。$f$ 是赋值集合上的对合（$f \circ f = \mathrm{id}$）且没有不动点，同时由引理 1 翻转最后一条边会改变代价奇偶性（把 $a$ 变成 $a \pm 1$，奇偶性翻转）。因此 $f$ 给出「奇数代价赋值 $\leftrightarrow$ 偶数代价赋值」的双射，两类数量相等，各为 $2^d / 2 = 2^{d-1}$。∎

**引理 3（深度可加性）**：从根到节点 $x$ 的路径边数等于 $x$ 的深度。

**证明**：树中根到任意节点有唯一简单路径，深度按「父节点深度 $+1$」定义，对路径长度归纳即得。∎

**定理**：算法返回值为题目所求的方案数（对 $10^9+7$ 取模）。

**证明**：由引理 3，任取一个深度最大的节点 $x$，路径边数都是 $d = \text{maxDepth}$，与 $x$ 的具体选择无关；由引理 1、2，该路径上代价为奇的赋值方案数为 $2^{d-1}$。快速幂计算的正是 $2^{d-1} \bmod (10^9+7)$。∎

## 6. 复杂度分析

- **时间**：$O(n + \log d)$。建图 $O(n)$，BFS 每个节点、每条边各访问一次 $O(n)$，快速幂 $O(\log d) \le O(\log n)$。
- **空间**：$O(n)$。邻接表存 $2(n-1)$ 条有向弧，另有 `depth` 数组与队列，均为 $O(n)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int assignEdgeWeights(vector<vector<int>>& edges) {
        const int MOD = 1000000007;
        int n = (int)edges.size() + 1;
        vector<vector<int>> adj(n + 1);
        for (auto& e : edges) {
            adj[e[0]].push_back(e[1]);
            adj[e[1]].push_back(e[0]);
        }
        // BFS 求每个节点到根（节点 1）的深度，得到最大深度
        vector<int> depth(n + 1, -1);
        queue<int> q;
        q.push(1);
        depth[1] = 0;
        int maxDepth = 0;
        while (!q.empty()) {
            int u = q.front();
            q.pop();
            maxDepth = max(maxDepth, depth[u]);
            for (int v : adj[u]) {
                if (depth[v] == -1) {
                    depth[v] = depth[u] + 1;
                    q.push(v);
                }
            }
        }
        // 长度 d >= 1 的路径上，代价为奇数的赋值数 = 2^(d-1)
        long long ans = 1, base = 2;
        for (int e = maxDepth - 1; e > 0; e >>= 1) {
            if (e & 1) ans = ans * base % MOD;
            base = base * base % MOD;
        }
        return (int)ans;
    }
};
```

### Python

```python
class Solution:
    def assignEdgeWeights(self, edges: list[list[int]]) -> int:
        MOD = 10 ** 9 + 7
        n = len(edges) + 1
        adj = [[] for _ in range(n + 1)]
        for u, v in edges:
            adj[u].append(v)
            adj[v].append(u)
        # BFS 求深度，得到最大深度 d
        depth = [-1] * (n + 1)
        depth[1] = 0
        q = [1]
        max_depth = 0
        for u in q:                       # 列表当队列：按下标顺序遍历
            max_depth = max(max_depth, depth[u])
            for v in adj[u]:
                if depth[v] == -1:
                    depth[v] = depth[u] + 1
                    q.append(v)
        # 长度 d >= 1 的路径上，代价为奇数的赋值数 = 2^(d-1)
        return pow(2, max_depth - 1, MOD)
```

## 8. 边界情况与易错点

1. **$n = 2$（只有一条边）**：$d = 1$，答案 $2^0 = 1$，不要把指数写成 $d$。
2. **指数为 0**：$d = 1$ 时指数 $d-1 = 0$，快速幂的循环体不执行，`ans` 必须初始化为 $1$。
3. **把权重 $2$ 当成「两个 1」**：权重 $2$ 是偶贡献，不改变奇偶性；只有权重 $1$ 才翻转奇偶。
4. **误乘路径外的边**：题目明确忽略路径外的边，若乘上 $2^{n-1-d}$ 会得到错误答案。
5. **误以为要区分「选哪个最深节点」**：所有最深节点深度相同，方案数相同，不需要去重或求和。
6. **用 DFS 递归**：$n = 10^5$ 的链会递归 $10^5$ 层，Python 需要提高递归上限或改 BFS；C++ 也可能栈溢出，BFS 更稳妥。
7. **取模遗漏**：不取模时 `long long` 也会在 $d > 63$ 时溢出，必须在每步乘法后取模。
