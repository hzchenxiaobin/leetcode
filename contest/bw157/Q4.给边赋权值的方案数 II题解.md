# LeetCode 给边赋权值的方案数 II 题解

## 1. 题目概述

- **标题 / 题号**：给边赋权值的方案数 II（#3559，hard）
- **链接**：https://leetcode.cn/problems/number-of-ways-to-assign-edge-weights-ii/
- **来源**：LeetCode 第 157 场双周赛 Q4
- **难度**：困难
- **标签**：位运算、树、深度优先搜索、数组、数学、动态规划

**题意**：给定一棵以节点 $1$ 为根的 $n$ 个节点的无向树。每条边可赋权 $1$ 或 $2$。对每个查询 $[u_i, v_i]$，统计「从 $u_i$ 到 $v_i$ 的路径上、使路径代价为**奇数**」的赋值方案数（只考虑该路径上的边），对 $10^9+7$ 取模。

**约束**：

- $2 \le n \le 10^5$，`edges.length == n - 1`
- $1 \le \text{queries.length} \le 10^5$，$1 \le u_i, v_i \le n$
- `edges` 表示一棵合法的树

> 💡 与 I 版的关键差别：I 版只问「根到最深节点」，路径长度 = 最大深度；II 版问任意两点，路径长度要做 LCA 才能算。

## 2. 示例

**示例 1**

```text
输入：edges = [[1,2]], queries = [[1,1],[1,2]]
输出：[0,1]
解释：[1,1] 路径没有边，代价恒为 0（偶），0 种；[1,2] 有 1 条边，只有取 1 才为奇，1 种。
```

**示例 2**

```text
输入：edges = [[1,2],[1,3],[3,4],[3,5]], queries = [[1,4],[3,4],[2,5]]
输出：[2,1,4]
解释：[1,4] 路径 1→3→4，2 条边：(1,2)、(2,1) 共 2 种；
     [3,4] 1 条边，1 种；[2,5] 路径 2→1→3→5，3 条边，2^2 = 4 种。
```

**示例 3（自造）**

```text
输入：edges = [[1,2],[2,3]], queries = [[1,3],[2,2]]
输出：[2,0]
解释：[1,3] 有 2 条边 -> 2 种；[2,2] 同节点，0 种。
```

## 3. 解题思路

### 3.1 暴力思路

对每个查询，先沿父指针把 $u \to v$ 的路径上的边数 $d$ 求出来，再输出 $2^{d-1}$（$d = 0$ 时输出 $0$）。如果每个查询都用「两边同时向上爬」的方式求路径长度，单次 $O(n)$，总计 $O(nq) = 10^{10}$，超时。

求出路径长度后，$2^{d-1}$ 的结论与 I 版完全一致（见本节 3.2），所以真正的瓶颈只有「快速求两点路径的边数」。

### 3.2 核心观察：答案只依赖路径边数 $d$

![路径边数 d 由 LCA 决定，答案只与 d 有关](images/bw157_q4_lca_model.svg)

- 权重 $1$ 是**奇**贡献、$2$ 是**偶**贡献，所以路径代价的奇偶性 $=$ 路径上取权 $1$ 的边数的奇偶性。
- 在 $d$ 条边上各投一枚「$1/2$」硬币，翻转最后一条边构成「奇代价 $\leftrightarrow$ 偶代价」的双射，因此两类各占一半：

$$\text{ans}(u,v) = \begin{cases} 0, & d = 0 \\ 2^{d-1} \bmod (10^9+7), & d \ge 1 \end{cases}$$

- 路径边数用 LCA 一次算出：

$$d = \text{dep}[u] + \text{dep}[v] - 2\cdot\text{dep}\big[\text{lca}(u,v)\big]$$

直观理解：$\text{dep}[u] + \text{dep}[v]$ 把「根到 LCA」这段算了两遍，减掉一次就好。

### 3.3 算法流程

![倍增表：每个节点第 2^k 级祖先的预处理](images/bw157_q4_binary_lifting.svg)

```text
1. 建邻接表；BFS 从根 1 出发求 dep[] 与父节点 up[0][]
2. 倍增预处理：up[k][v] = up[k-1][ up[k-1][v] ]，k = 1..LOG-1
3. 预处理 2 的幂：pw[i] = 2^i mod (1e9+7)
4. 对每个查询 (u, v):
       w = lca(u, v)
       d = dep[u] + dep[v] - 2*dep[w]
       ans = (d == 0 ? 0 : pw[d-1])
```

LCA 的倍增写法：

```text
先把较深的节点跳到与较浅节点同层（按 dep 差的二进制位跳）
若此时相同，LCA 就是它
否则从高位到低位一起往上跳，跳到「LCA 的正下方」
最后再上跳一步得到 LCA
```

### 3.4 示例演算

![三个查询的 LCA 与答案](images/bw157_q4_example_walk.svg)

树为 `1-2`、`1-3`、`3-4`、`3-5`，深度：`dep[1]=0, dep[2]=dep[3]=1, dep[4]=dep[5]=2`。

| 查询 | LCA | $\text{dep}[u]+\text{dep}[v]-2\text{dep}[\text{lca}]$ | 答案 |
|------|-----|------|------|
| $[1,4]$ | 1 | $0+2-0 = 2$ | $2^1 = 2$ |
| $[3,4]$ | 3 | $1+2-2 = 1$ | $2^0 = 1$ |
| $[2,5]$ | 1 | $1+2-0 = 3$ | $2^2 = 4$ |
| $[1,1]$ | 1 | $0$ | $0$ |

与官方输出 $[2,1,4]$（以及示例 1 的 $[0,1]$）一致。

## 4. 算法细节

1. **深度与父节点一次 BFS 求出**：树是无向的，BFS 时用 `dep[v] == -1` 判断是否首次到达，顺便记录 `up[0][v] = u`。
2. **倍增表大小**：$n \le 10^5$，$\text{LOG} \approx 17$；循环条件写成 `while ((1 << LOG) <= n) LOG++`，保证最大跳距覆盖整棵树。
3. **根节点的祖先**：把 `up[k][1]` 统一设成 $1$ 自身，这样越界跳不会跳到 $0$ 号虚节点，LCA 的第二个循环也不会误判。
4. **LCA 的两段式跳跃**：先把深的跳到同层，若相同直接返回；否则从大到小枚举 $k$，只要 `up[k][a] != up[k][b]` 就同时上跳——这样最终停在 LCA 的两个不同子节点上，返回 `up[0][a]`。
5. **2 的幂预处理**：把 $2^i$ 全算出来存数组，单次查询 $O(1)$ 查表，比每次调用快速幂更省时间（$10^5$ 次查询）。
6. **$d = 0$ 的分支**：$u = v$ 时路径无边界，代价恒为 $0$（偶数），合法方案数为 $0$ 而不是 $1$ —— 这是本题最容易被 `2^{-1}` 绊倒的地方。
7. **取模时机**：$2^{d-1}$ 用预处理表并全程取模，最大值约 $10^5$ 位，不取模会溢出。

## 5. 正确性证明

**引理 1（路径长度公式）**：对任意两个节点 $u, v$，路径边数 $d = \text{dep}[u] + \text{dep}[v] - 2\,\text{dep}[w]$，其中 $w = \text{lca}(u,v)$。

**证明**：树中 $u \to v$ 的唯一简单路径必经过 $w$，且可分为 $u \to w$ 与 $w \to v$ 两段，边数分别为 $\text{dep}[u] - \text{dep}[w]$ 与 $\text{dep}[v] - \text{dep}[w]$（因为根到某节点的路径边数等于其深度，且 $w$ 是 $u$、$v$ 的公共祖先）。两段相加即得公式。∎

**引理 2（一半法则）**：$d \ge 1$ 时，使路径代价为奇数的赋值数恰为 $2^{d-1}$；$d = 0$ 时为 $0$。

**证明**：$d = 0$ 时代价恒为 $0$，无合法赋值。$d \ge 1$ 时，翻转最后一条边权重（$1 \leftrightarrow 2$）把代价奇偶性翻转，构成「奇 $\leftrightarrow$ 偶」的无不动点对合，故两类赋值数相等，各占 $2^d / 2 = 2^{d-1}$。∎

**引理 3（倍增 LCA 正确性）**：设 $w = \text{lca}(u,v)$。按深度差把 $u$ 跳到与 $v$ 同层后，若二者相同则该点即 $w$；否则对每个 $k$ 检查 $\text{up}[k][a] \ne \text{up}[k][b]$ 时同时上跳，循环结束后 $a,b$ 是 $w$ 的两个不同子节点，`up[0][a] = w`。

**证明**：深度差跳跃是把差值做二进制分解，每次跳 $2^k$ 级，正确性来自 $\text{up}$ 的定义（$\text{up}[k][x]$ 是 $x$ 的第 $2^k$ 级祖先）。同层后若 $a = b$ 则它就是最近公共祖先（此时两者已重合）。否则设 $L = \text{dep}[a] - \text{dep}[w]$。对任意 $k$，若 $2^k \le L$ 且 $\text{up}[k][a] \ne \text{up}[k][b]$，说明跳 $2^k$ 级后仍在 $w$ 之下，可以安全上跳；贪心地从大 $k$ 往小 $k$ 跳会恰好把 $L$ 消到 $0$，于是 $a, b$ 停在 $w$ 的两个子节点上（若不跳满则还会有更大的共同祖先，与 $w$ 的最近性矛盾）。∎

**定理**：对每个查询，算法输出等于题目要求的方案数。

**证明**：由引理 3 求得的 $w$ 是真 LCA，由引理 1 得到的 $d$ 是真路径边数，再由引理 2 得到方案数 $2^{d-1}$（或 $0$）。三者串联即得结论；取模运算与加法、乘法相容，故预处理表给出的是模意义下的正确值。∎

## 6. 复杂度分析

- **时间**：$O(n\log n + q\log n)$。BFS 建深度 $O(n)$；倍增表共 $\text{LOG}\times n \approx 17n$ 次赋值；每个查询做一次 LCA，$O(\log n)$，再 $O(1)$ 查表。
- **空间**：$O(n\log n)$。倍增表 $\text{LOG} \times (n+1)$ 个整数（$10^5 \times 17 \approx 1.7\times 10^6$，约 7 MB），另有邻接表、`dep`、$2$ 的幂表各 $O(n)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> assignEdgeWeights(vector<vector<int>>& edges, vector<vector<int>>& queries) {
        const int MOD = 1000000007;
        int n = (int)edges.size() + 1;

        vector<vector<int>> adj(n + 1);
        for (auto& e : edges) {
            adj[e[0]].push_back(e[1]);
            adj[e[1]].push_back(e[0]);
        }

        // ---- 1. BFS 求深度与父节点 ----
        int LOG = 1;
        while ((1 << LOG) <= n) LOG++;
        vector<vector<int>> up(LOG, vector<int>(n + 1, 1));
        vector<int> depth(n + 1, -1);
        queue<int> q;
        q.push(1);
        depth[1] = 0;
        while (!q.empty()) {
            int u = q.front();
            q.pop();
            for (int v : adj[u]) {
                if (depth[v] == -1) {
                    depth[v] = depth[u] + 1;
                    up[0][v] = u;
                    q.push(v);
                }
            }
        }

        // ---- 2. 倍增表：up[k][v] 为 v 的第 2^k 级祖先 ----
        for (int k = 1; k < LOG; k++) {
            for (int v = 1; v <= n; v++) {
                up[k][v] = up[k - 1][up[k - 1][v]];
            }
        }

        // ---- 3. 2 的幂预处理（2^(d-1) 直接查表）----
        vector<long long> pw(n + 1);
        pw[0] = 1;
        for (int i = 1; i <= n; i++) pw[i] = pw[i - 1] * 2 % MOD;

        auto lca = [&](int a, int b) {
            if (depth[a] < depth[b]) swap(a, b);
            int diff = depth[a] - depth[b];
            for (int k = 0; k < LOG; k++) {
                if ((diff >> k) & 1) a = up[k][a];
            }
            if (a == b) return a;
            for (int k = LOG - 1; k >= 0; k--) {
                if (up[k][a] != up[k][b]) {
                    a = up[k][a];
                    b = up[k][b];
                }
            }
            return up[0][a];
        };

        vector<int> ans;
        ans.reserve(queries.size());
        for (auto& qu : queries) {
            int u = qu[0], v = qu[1];
            int w = lca(u, v);
            int d = depth[u] + depth[v] - 2 * depth[w];   // 路径边数
            ans.push_back(d == 0 ? 0 : (int)pw[d - 1]);
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def assignEdgeWeights(self, edges: list[list[int]], queries: list[list[int]]) -> list[int]:
        MOD = 10 ** 9 + 7
        n = len(edges) + 1

        adj = [[] for _ in range(n + 1)]
        for u, v in edges:
            adj[u].append(v)
            adj[v].append(u)

        # ---- 1. BFS 求深度与父节点 ----
        LOG = max(1, n.bit_length())
        up = [[1] * (n + 1) for _ in range(LOG)]
        depth = [-1] * (n + 1)
        depth[1] = 0
        q = [1]
        for u in q:                       # 列表当队列
            for v in adj[u]:
                if depth[v] == -1:
                    depth[v] = depth[u] + 1
                    up[0][v] = u
                    q.append(v)

        # ---- 2. 倍增表 ----
        for k in range(1, LOG):
            prev, cur = up[k - 1], up[k]
            for v in range(1, n + 1):
                cur[v] = prev[prev[v]]

        # ---- 3. 2 的幂 ----
        pw = [1] * (n + 1)
        for i in range(1, n + 1):
            pw[i] = pw[i - 1] * 2 % MOD

        def lca(a: int, b: int) -> int:
            if depth[a] < depth[b]:
                a, b = b, a
            diff = depth[a] - depth[b]
            k = 0
            while diff:
                if diff & 1:
                    a = up[k][a]
                diff >>= 1
                k += 1
            if a == b:
                return a
            for k in range(LOG - 1, -1, -1):
                if up[k][a] != up[k][b]:
                    a = up[k][a]
                    b = up[k][b]
            return up[0][a]

        ans = []
        for u, v in queries:
            w = lca(u, v)
            d = depth[u] + depth[v] - 2 * depth[w]     # 路径边数
            ans.append(0 if d == 0 else pw[d - 1])
        return ans
```

## 8. 边界情况与易错点

1. **$u = v$（$d = 0$）**：答案必须是 $0$，不能套用 $2^{d-1}$（会得到 $2^{-1}$，取模后是 $(10^9+8)/2$ 这种荒谬值）。
2. **根节点的祖先越界**：`up[k][1]` 必须指向 $1$ 自身；若指向 $0$（未初始化），LCA 的第二个循环会拿 $0$ 参与比较，可能跳出错误结果。
3. **倍增表容量**：`LOG` 要满足 $2^{\text{LOG}} > n$，否则最深节点跳不到顶；$n$ 恰好是 $2$ 的幂时容易差一。
4. **深度差的跳跃方向**：`if (depth[a] < depth[b]) swap(a, b)` 之后，只能让 `a`（更深的）上跳，跳反会得到错误深度。
5. **LCA 第二个循环的方向**：必须从**高位**往低位枚举，否则一次跳不够、还需反复回跳。
6. **深链的栈溢出**：$n = 10^5$ 的链若用递归 DFS 建表，Python 会 `RecursionError`、C++ 可能栈溢出，用 BFS 迭代更稳。
7. **单查询也要取模**：$2^{d-1}$ 最大约 $10^{10^5}$，必须预处理取模，不能先求幂再取模（大整数会爆内存/超时）。
8. **答案数组类型**：结果都在 $[0, 10^9+7)$ 内，`vector<int>` 即可。
