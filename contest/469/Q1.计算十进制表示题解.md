# LeetCode 计算十进制表示 题解

## 1. 题目概述

- **标题 / 题号**：计算十进制表示（#3697，easy）
- **链接**：https://leetcode.cn/problems/compute-decimal-representation/
- **来源**：LeetCode 第 469 场周赛 Q1
- **难度**：简单
- **标签**：数组、数学

**题意**：给定正整数 $n$。若一个数能写成 $d \times 10^k$（数字 $d \in [1,9]$，$k$ 为非负整数），则称其为**10 进制分量**（如 500、30、7；而 537、102、11 不是）。请将 $n$ 表示为**个数最少**的 10 进制分量之和，返回这些分量组成的数组，要求按**降序**排列。

**约束**：

- $1 \le n \le 10^9$

## 2. 示例

**示例 1**

```text
输入：n = 537
输出：[500,30,7]
解释：537 = 500 + 30 + 7，无法用少于 3 个分量表示。
```

**示例 2**

```text
输入：n = 102
输出：[100,2]
解释：102 不是分量，需要 2 个分量：100 + 2。
```

**示例 3**

```text
输入：n = 6
输出：[6]
解释：6 = 6×10⁰ 本身就是一个分量。
```

## 3. 解题思路

### 3.1 暴力思路

候选分量只有 $d \times 10^k$（$d \in [1,9]$，$0 \le k \le 9$）共约 90 个，可以做 BFS / 记忆化搜索求"最少几个分量凑出 $n$"，但复杂度至少 $O(n \cdot 90)$，纯属杀鸡用牛刀。签到题应当直接观察结构。

### 3.2 核心观察：每个非零数位恰好对应一个分量

![按位拆分：每个非零数位对应一个 10 进制分量](images/decimal_component_split.svg)

写出 $n$ 的十进制表示：

$$n = \sum_{k} n_k \cdot 10^k, \quad n_k \in [0,9]$$

每个**非零**数位 $n_k \in [1,9]$ 产生的 $n_k \cdot 10^k$ 恰好就是一个 10 进制分量。于是**按位拆分**直接给出一组合法解，分量数 = 非零数位个数 $D(n)$。

进一步（证明见 §5）：**任何分解的分量数都不小于 $D(n)$**，所以按位拆分就是最优解。

### 3.3 算法流程

1. 从高位向低位（或从低位向高位）扫描 $n$ 的十进制数位；
2. 数位 $d$ 非零时，输出分量 $d \times 10^k$（$k$ 为该位的幂次）；
3. 数位为 0 时跳过（$d$ 必须在 $[1,9]$ 中）；
4. 从高位向低位扫描时输出天然降序，无需排序。

### 3.4 示例演算

![n=102 的逐位演算走查](images/decimal_walk_102.svg)

以 $n = 102$ 为例：百位 $1$ 产生 $100$，十位 $0$ 跳过，个位 $2$ 产生 $2$，输出 `[100, 2]`。

## 4. 算法细节

1. **逐位提取**：循环中 `d = n % 10` 取当前位，`n //= 10` 前进一位，幂次 `p *= 10` 同步递增；数位非零则记录 `d * p`。
2. **零位跳过**：$d = 0$ 时不产生分量——注意 $0 \times 10^k = 0$ 不是合法分量（数字必须在 1~9 中）。
3. **降序输出**：从低位向高位收集得到的是升序，最后 `reverse`；若转成字符串从高位向低位扫，则天然降序。
4. **两种等价实现**：数值逐位取模（C++ 版），或 `to_string` 后按字符扫描（Python 一行版）。

## 5. 正确性证明

**引理 1（可达性）**：按位拆分是合法分解，分量数为 $D(n)$（非零数位个数）。

**证明**：每个非零数位 $n_k \in [1,9]$，故 $n_k \cdot 10^k$ 是合法分量；这些分量之和恰为 $n$。∎

**引理 2（标准化）**：任何分解都可转化为"**每个幂次至多一个分量**"的分解，且分量数不增。

**证明**：若分解中存在两个同幂次分量 $d_1 \cdot 10^k$ 与 $d_2 \cdot 10^k$：

- 若 $d_1 + d_2 \le 9$：合并为 $(d_1 + d_2) \cdot 10^k$，仍是合法分量，分量数**减一**；
- 若 $d_1 + d_2 \ge 10$：替换为 $10^{k+1}$ 与 $(d_1 + d_2 - 10) \cdot 10^k$（后者当 $d_1 + d_2 = 10$ 时省去），分量数**不增**，冲突向更高幂次转移。

![同幂次分量的合并与进位处理](images/decimal_merge_carry.svg)

以（分量数，各分量幂次之和）作字典序势函数：合并操作使第一维严格减小；进位操作第一维不变、第二维严格增大。由于各分量之和恒为 $n$，任何分量的幂次不超过 $\lfloor \log_{10} n \rfloor + 1$，势函数有上界，故操作必然终止于"每个幂次至多一个分量"的分解，且分量数不超过原分解。∎

**定理**：最少分量数为 $D(n)$，按位拆分是一组最优解。

**证明**：由引理 1，$D(n)$ 个分量可达。任取一个最优解，由引理 2 可标准化为分量数不增、且每个幂次 $10^k$ 至多一个系数 $a_k \in [1,9]$ 的分解，满足 $\sum_k a_k \cdot 10^k = n$。由十进制表示的唯一性，$a_k = n_k$ 对所有 $k$ 成立，故该分解恰含 $D(n)$ 个分量。于是最优值 $\ge D(n)$，结合可达性得最优值 $= D(n)$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(\log n)$。循环次数为 $n$ 的十进制位数（$n \le 10^9$ 时至多 10 次）。
- **空间复杂度**：$O(\log n)$。结果数组最多存放 10 个分量（不计输出则为 $O(1)$）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> decimalRepresentation(int n) {
        vector<int> res;
        long long p = 1;
        while (n > 0) {
            int d = n % 10;
            if (d > 0) res.push_back((int)(d * p));
            n /= 10;
            p *= 10;
        }
        reverse(res.begin(), res.end());
        return res;
    }
};
```

### Python

```python
class Solution:
    def decimalRepresentation(self, n: int) -> List[int]:
        s = str(n)
        return [int(c) * 10 ** (len(s) - 1 - i)
                for i, c in enumerate(s) if c != '0']
```

## 8. 边界情况与易错点

1. **幂次累乘溢出（C++）**：$n = 10^9$ 时 `p` 要用到 $10^9$（int 尚可容纳），但循环最后一轮 `p *= 10` 会算到 $10^{10}$，超出 `int` 范围属于未定义行为——幂次变量用 `long long` 最稳妥。
2. **零位必须跳过**：$0$ 不是合法分量（$d \in [1,9]$），如 $n = 102$ 不能输出 `[100, 0, 2]`。
3. **降序要求**：从低位向高位收集是升序，忘记 `reverse` 会 WA；从字符串高位向低位扫则天然降序。
4. **单个数字**：$n \in [1,9]$ 时输出 `[n]` 本身。
5. **答案不唯一但个数唯一**：题目只要求分量个数最少，任意一组最优解均可；按位拆分是最自然的一组（如 $n = 11$ 时 `[10, 1]` 与 `[9, 2]` 都是 2 个分量，输出前者即可）。
