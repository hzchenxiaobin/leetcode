# LeetCode 最长公共前缀的长度 题解

## 1. 题目概述

- **标题 / 题号**：最长公共前缀的长度（#3043，medium）
- **链接**：https://leetcode.cn/problems/find-the-length-of-the-longest-common-prefix/
- **来源**：LeetCode 第 385 场周赛 Q2
- **难度**：中等
- **标签**：字典树（Trie）、数组、哈希表、字符串

**题意**：给定两个**正整数**数组 `arr1` 和 `arr2`。正整数的**前缀**是其最左边的一位或多位数字构成的整数（如 `123` 是 `12345` 的前缀，`234` 不是）。若整数 $c$ 同时是 $a$ 和 $b$ 的前缀，则称 $c$ 是 $a$、$b$ 的**公共前缀**。求所有数对 $(x, y)$（$x \in arr1$，$y \in arr2$）中**最长公共前缀的长度**；不存在则返回 `0`。

**约束**：

- $1 \le arr1.length,\ arr2.length \le 5 \times 10^4$
- $1 \le arr1[i],\ arr2[i] \le 10^8$

> 💡 **读题关键**：① 前缀从**最左边**起、**至少一位**；② 数对必须**跨数组**——同一数组内部元素之间的公共前缀不算（示例 2 里 `arr2` 三个 `4` 互为前缀，但与答案无关）；③ 求的是**长度**而非前缀本身。数值上界 $10^8$ 只有 **9 位**——「每个数的前缀极少」正是本题可解的钥匙。

## 2. 示例

**示例 1**

```text
输入：arr1 = [1,10,100], arr2 = [1000]
输出：3
解释：(1,1000) 的公共前缀是 1；(10,1000) 是 10；(100,1000) 是 100。
      最长为 100，长度 3。
```

**示例 2**

```text
输入：arr1 = [1,2,3], arr2 = [4,4,4]
输出：0
解释：任何跨数组数对都没有公共前缀。arr2 内部三个 4 互为前缀，但不作数。
```

**示例 3（自拟，覆盖「部分前缀命中」）**

```text
输入：arr1 = [5655359, 1223], arr2 = [56554, 43456]
输出：4
解释：5655359 与 56554 的最长公共前缀是 5655，长度 4；其余数对均无公共前缀。
```

## 3. 解题思路

### 3.1 暴力思路

枚举全部 $n \times m$ 个数对，把两数转成十进制字符串逐字符比较，取所有数对 LCP 的最大值。单次比较 $O(L)$，总计

$$O(n \cdot m \cdot L) \;=\; 5 \times 10^4 \times 5 \times 10^4 \times 9 \;\approx\; 2.25 \times 10^{10}$$

约两百亿次字符比较，必然超时。慢的根源是**重复劳动**：同一个 $x$ 要与 `arr2` 中每个 $y$ 各比一遍，而它「1、10、100……」的前缀结构被反复拆了几万遍。破局点是把「数对级」比较升维成「数组级」查询——**先把一侧的前缀信息一次性物化成一张结构，另一侧只管来查**。

### 3.2 核心观察：公共前缀 ⟺ 一侧前缀落在另一侧的前缀集合中

![前缀链与 Trie 深度](images/wc385_q2_trie_concept.svg)

**转化**：「$x$ 与 $y$ 有长度为 $k$ 的公共前缀」⟺「某个 $k$ 位整数**同时**是 $x$ 和 $y$ 的前缀」⟺「$y$ 的某个前缀出现在 $x$ 的前缀集合里」。于是

> 答案 = **arr2 的某个前缀**出现在 **arr1 全部前缀构成的集合**中的最大位数。

而「每个数的所有前缀」便宜得惊人：$10^8$ 只有 9 位，反复 $\lfloor x/10 \rfloor$ 砍末位就能折出全部前缀，两个数组合计至多 $9(n+m) \approx 10^6$ 个。落地成两种等价结构：

- **前缀哈希集合**：`arr1` 每个数砍末位得到的前缀全部塞进 `HashSet`；`arr2` 每个数的前缀**从长到短**查，首个命中即该数贡献的最长公共前缀，立刻换下一个数。
- **10 叉 Trie**：把前缀集合组织成字典树——一个数的所有前缀天然是**从根出发的一条链**，深度为 $k$ 的节点恰是长度为 $k$ 的前缀。查询 $y$ 时沿数字位逐层下走，**能走多深，公共前缀就多长**，走不动自然停。

> 💡 两种视角同构：哈希集合的元素 = Trie 的节点；「枚举前缀查集合」=「沿链下走」。赛时求快先写哈希版（十行代码）；Trie 版胜在一次行走天然**最长优先**，且范式可迁移（二进制位版本就是 421 异或 Trie）。

### 3.3 算法流程

![两阶段流程：建表 + 探测](images/wc385_q2_algorithm_flow.svg)

两阶段串行，`ans` 初值 0（天然覆盖「无任何公共前缀」）：

1. **建表**：遍历 `arr1`，对每个 $x$ 执行 `while x: add(x); x ← ⌊x/10⌋`，把沿途每个非零前缀放入结构（Trie 则按十进制位逐位插入）；
2. **探测**：遍历 `arr2`，对每个 $y$ 从最长前缀（$y$ 本身）开始查——命中则更新 `ans` 并**立即换下一个 $y$**（更短的前缀不可能更长）；未命中则砍末位继续查；折到 0 仍未命中，该 $y$ 贡献 0。Trie 版无需枚举，沿链走到走不动，停留深度即答案；
3. 全部探测完返回 `ans`。

### 3.4 示例演算

![示例演算：建表与从长到短探测](images/wc385_q2_walkthrough.svg)

**示例 1**：`arr1 = [1,10,100]` 建表得 $\{1, 10, 100\}$。探测 `y = 1000`：`1000` ✗ → `100` ✓，命中即停，长度 3，`ans = 3`。

**示例 3**：`arr1 = [5655359, 1223]` 建表得 11 个前缀 $\{5,56,565,5655,56553,565535,5655359\} \cup \{1,12,122,1223\}$。探测 `y = 56554`：`56554` ✗ → `5655` ✓，长度 4；探测 `y = 43456`：一路砍到 `0` 全部落空，贡献 0。`ans = 4` ✓。

**示例 2**：`arr1 = [1,2,3]` 建表得 $\{1,2,3\}$；`arr2 = [4,4,4]` 的每个 `y` 只有前缀 `4`，三次探测全 ✗，`ans = 0` ✓。

## 4. 算法细节

1. **前缀的算术枚举**：`while x: add(x); x //= 10`。前缀**至少一位**，`0` 不是任何正整数的前缀，正好折出 0 时做**终止哨兵**——它绝不能入集合（见第 8 节）。
2. **10 叉 Trie 的数组化实现**：`vector<array<int,10>> ch`，`ch[u][d]` 为节点 $u$ 经数字 $d$ 的孩子，`-1` 表空指针；插入即按 `to_string(x)` 逐位下走，无孩子就开新节点。无需终止标记——本题只问「能走多深」，不问「是否是完整单词」。
3. **哈希版必须「从长到短 + 首次命中 break」**：同一个 $y$ 的前缀链长度严格递减，首个命中的必是它能贡献的最长公共前缀；若从短到长查，必须查完全部才能取最大，还损失了提前停机。
4. **建表侧与查询侧严格分离**：表里**只放 arr1 的前缀**，只拿 **arr2 的前缀**来查。两侧角色对称，哪边建表都行；想让空间小一点，就把**元素个数少的一侧**拿来建表。
5. **位数统计**：哈希版命中时长度即 `to_string(y).size()`（或预存折位次数）；Trie 版深度就是长度，行走时计数即可。

## 5. 正确性证明

**引理 1（前缀链）**：设正整数 $x$ 的十进制表示长为 $L$，则 $x$ 的全部前缀恰为 $x,\ \lfloor x/10 \rfloor,\ \lfloor x/10^2 \rfloor,\ \dots,\ \lfloor x/10^{L-1} \rfloor$（共 $L$ 个），且其中长度为 $k$ 的前缀唯一，即 $\lfloor x/10^{L-k} \rfloor$。

**证明**：十进制表示唯一。$c$ 是 $x$ 的前缀 ⟺ $x = c \cdot 10^j + r$（$0 \le r < 10^j$，$j$ 为 $c$ 的位数）且 $c$ 的最高位非零 ⟺ $c = \lfloor x/10^j \rfloor$。对 $j = 0, 1, \dots, L-1$ 取值即得全部 $L$ 个前缀；$j \ge L$ 时 $\lfloor x/10^j \rfloor = 0$ 不是正整数、不是前缀。位数 $k$ 对应 $j = L-k$，一一对应故唯一。∎

**引理 2（集合交刻画）**：记 $P(z)$ 为 $z$ 的前缀集合，则题目所求

$$\text{ans} \;=\; \max\Big\{\, \text{len}(c)\ :\ c \in \Big(\bigcup_{x \in arr1} P(x)\Big) \cap \Big(\bigcup_{y \in arr2} P(y)\Big) \,\Big\}$$

（右侧为空集时 $\text{ans} = 0$，与「不存在公共前缀返回 0」一致）。

**证明**：$c$ 是某数对 $(x, y)$ 的公共前缀 ⟺ 存在 $x \in arr1$ 与 $y \in arr2$ 使 $c \in P(x)$ 且 $c \in P(y)$ ⟺ $c$ 同属两个并集，即 $c$ 落在交集里。「所有数对中最长的公共前缀」对数对取 max，而 $c$ 是否可行只与 $c$ 自身有关、与具体数对无关，故对数对的 max 可坍缩成对交集中元素的 max。∎

**引理 3（Trie 行走深度）**：把 $\bigcup_{x \in arr1} P(x)$ 的每个前缀按十进制位插入 Trie 后，对任意 $y$，沿 $y$ 的数字位从根下走能到达的最大深度

$$d(y) \;=\; \max\{\, \text{len}(c)\ :\ c \in P(y) \cap \bigcup\nolimits_{x \in arr1} P(x) \,\}$$

**证明**：Trie 中从根出发、逐位标记 $c$ 的十进制位的路径与集合中的前缀 $c$ 一一对应，且路径长度 = $\text{len}(c)$（引理 1 的唯一性保证同一前缀只有一条路径）。$y$ 沿自身数字位能走到深度 $k$ 的节点，当且仅当 $y$ 的前 $k$ 位构成的串是 Trie 中一条路径，即 $\lfloor y/10^{\text{len}(y)-k} \rfloor$（$y$ 的长度 $k$ 前缀）在集合中。故最大可达深度恰为 $y$ 与集合的最长公共前缀长度。∎

**定理**：本文算法（哈希版或 Trie 版）返回值等于题目所求。

**证明**：哈希版对每个 $y$ 从长到短枚举 $P(y)$（由引理 1，枚举顺序即长度严格递减序），首次命中的 $c$ 是 $P(y) \cap \bigcup P(arr1)$ 中最长者，取 $\text{len}(c)$ 与全局 `ans` 取 max；对所有 $y$ 取 max 后，由引理 2 等于所求。Trie 版由引理 3，每个 $y$ 的行走深度 $d(y)$ 即该 $y$ 的最长命中，对所有 $y$ 取 max 同理。两种实现都枚举且仅枚举 $\bigcup_{y \in arr2} P(y)$ 与 $\bigcup_{x \in arr1} P(x)$ 的交，无遗漏；`ans` 单调不减地取 max，无重复计数。∎

## 6. 复杂度分析

- **时间复杂度**：$O((n + m) \cdot L)$，其中 $L \le 9$ 是最长十进制位数。建表对 `arr1` 每个数走一遍前缀链 $O(nL)$，探测对 `arr2` 每个数至多查 $L$ 次 / 走 $L$ 步 $O(mL)$，总量 $\le 9 \times 10^5$ 次基本操作，轻松通过。
- **空间复杂度**：哈希集合 $O(nL)$ 个整数（$\le 4.5 \times 10^5$）；10 叉 Trie 至多 $nL$ 个节点、每节点 10 个孩子指针，最坏约 18 MB。若空间敏感，取**较小的一侧**建表，或直接用哈希版。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int longestCommonPrefix(vector<int>& arr1, vector<int>& arr2) {
        // 10 叉 Trie：ch[u][d] = 节点 u 经数字 d 的孩子，-1 表示无
        vector<array<int, 10>> ch(1);
        ch[0].fill(-1);

        auto insert = [&](int x) {
            int u = 0;
            for (char c : to_string(x)) {
                int d = c - '0';
                if (ch[u][d] == -1) {
                    ch[u][d] = ch.size();
                    ch.emplace_back();
                    ch.back().fill(-1);
                }
                u = ch[u][d];
            }
        };
        for (int x : arr1) insert(x);   // 阶段一：arr1 逐位插入

        int ans = 0;
        for (int y : arr2) {             // 阶段二：arr2 沿链下走
            int u = 0, depth = 0;
            for (char c : to_string(y)) {
                int d = c - '0';
                if (ch[u][d] == -1) break;   // 走不动即停，depth 已是最长
                u = ch[u][d];
                depth++;
            }
            ans = max(ans, depth);
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def longestCommonPrefix(self, arr1: List[int], arr2: List[int]) -> int:
        seen = set()
        for x in arr1:                  # 阶段一：arr1 每个数的所有前缀入集合
            while x:                    # 前缀至少一位，0 作终止哨兵不入集合
                seen.add(x)
                x //= 10

        ans = 0
        for y in arr2:                  # 阶段二：从长到短探测
            while y:
                if y in seen:           # 首次命中即该 y 的最长，break 换下一个
                    ans = max(ans, len(str(y)))
                    break
                y //= 10
        return ans
```

## 8. 边界情况与易错点

1. **0 的哨兵地位**：枚举前缀必须写 `while x`，不能写 `while x >= 0`——$0 // 10 = 0$ 死循环。更隐蔽的是把 0 误入集合：查询侧折到 0 会「命中」返回长度 1，而正确答案是 0。
2. **两侧前缀不能混进同一张表**：若 `arr2` 的前缀也塞进集合，查询侧 $y$ 的前缀必命中自己那侧的表项，答案恒等于 $\max \text{len}(y)$，「跨数组」语义丢失——示例 2 的 `arr2 = [4,4,4]` 会错答 1。
3. **`ans = max(ans, len)` + `break` 缺一不可**：只 `ans = len` 不 break，先命中的长前缀会被随后更短的命中覆盖；不 break 也会白查（不影响正确性，但哈希版失去提前停机）。
4. **无公共前缀返回 0**：`ans` 初值 0 天然覆盖，不要额外特判。
5. **一位数**：前缀就是自身（引理 1 中 $L = 1$ 的情形），通用逻辑自然覆盖，无需特判；两个相同的一位数（如 `arr1 = [5]`, `arr2 = [5]`）答案是 1。
6. **Trie 版的孩子初始化**：新节点 `fill(-1)` 别忘；判断用 `ch[u][d] == -1` 而非 `0`（节点编号 0 是根）。

**延伸思考**：

- **排序 + 二分做法**：把 `arr1` 全部转成字符串排序，`arr2` 的每个前缀串二分找插入位置，只需与左右邻居求 LCP（排序序中 LCP 向插入点单调）。能做，但多一个 $\log$，本题没必要。

- **在线版**：若 `arr2` 的查询逐个到达且 `arr1` 可动态插入，Trie 增量插入 $O(L)$、查询 $O(L)$，哈希集合同样支持；这也是周赛里这套路子反复出现的原因。
