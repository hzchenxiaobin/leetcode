# LeetCode 统计前后缀下标对 II 题解

## 1. 题目概述

- **标题 / 题号**：统计前后缀下标对 II（#3045，hard）
- **链接**：https://leetcode.cn/problems/count-prefix-and-suffix-pairs-ii/
- **来源**：LeetCode 第 385 场周赛 Q4
- **难度**：困难
- **标签**：字典树、字符串、字符串匹配、哈希函数、滚动哈希、Z 函数（扩展 KMP）

**题意**：给定字符串数组 `words`，定义 `isPrefixAndSuffix(str1, str2)`：当 `str1` **同时**是 `str2` 的前缀**和**后缀时为 true。返回满足 `i < j` 且 `isPrefixAndSuffix(words[i], words[j])` 为 true 的下标对 `(i, j)` 的数量。

**约束**：

- `1 <= words.length <= 10^5`
- `1 <= words[i].length <= 10^5`
- `words[i]` 仅由小写英文字母组成
- 所有 `words[i]` 的长度之和不超过 `5 * 10^5`

> 💡 题意与同场 Q1（#3042 统计前后缀下标对 I）**一字不差**，但 `words.length` 从 50 涨到 $10^5$、总长从 500 涨到 $5 \times 10^5$——暴力的 $O(n^2)$ 枚举彻底失效，必须把「逐对判定」重构为「批量查询」。

## 2. 示例

**示例 1**

```text
输入：words = ["a","aba","ababa","aa"]
输出：4
解释：(0,1)、(0,2)、(0,3) 中 "a" 是三个字符串的前后缀；
      (1,2) 中 "aba" 是 "ababa" 的前后缀。
```

**示例 2**

```text
输入：words = ["pa","papa","ma","mama"]
输出：2
解释：(0,1) "pa" 是 "papa" 的前后缀；(2,3) "ma" 是 "mama" 的前后缀。
```

**示例 3**

```text
输入：words = ["abab","ab"]
输出：0
解释：唯一候选 (0,1)，但 "abab" 比 "ab" 长，不可能是它的前后缀。
```

## 3. 解题思路

### 3.1 暴力思路

沿用 Q1 的做法：枚举所有 $i < j$，逐对判定。本题中下标对至多 $\binom{10^5}{2} \approx 5 \times 10^9$ 个，每次判定还要比较至多 $2 \times 10^5$ 个字符，总操作量天文数字，完全不可行。

瓶颈在于**把每个 `words[i]` 与每个 `words[j]` 逐一比对**。要突破 $O(n^2)$，需要换一个计数方向：处理 `words[j]` 时，不去检查之前的每个 `words[i]`，而是直接问「**之前有多少个字符串，恰好等于 `words[j]` 的某个合法候选**」。

### 3.2 核心观察：border（既是前缀又是后缀的子串）

![border 概念：既是前缀又是后缀](images/wc385_q4_border_concept.svg)

称字符串 $s$ 的子串为一个 **border**，如果它**同时**是 $s$ 的前缀和后缀（整个 $s$ 自身也算 border）。例如 `"ababa"` 的 border 长度为 $\{1, 3, 5\}$，对应 `"a"`、`"aba"`、`"ababa"`。

于是得到关键等价转化：

$$\text{isPrefixAndSuffix}(x, y) \iff x \text{ 等于 } y \text{ 的某个 border 前缀}$$

**证明**：若 $x$ 是 $y$ 的前缀，则 $x = y[0..|x|-1]$；若 $x$ 同时是 $y$ 的后缀，则 $y$ 的末尾 $|x|$ 个字符也是 $x$，即「长度为 $|x|$ 的后缀 = 长度为 $|x|$ 的前缀」，故 $|x|$ 恰是 $y$ 的 border 长度。反向显然。∎

这样，统计问题变为：

> 处理 `words[j]` 时，累加「之前出现过的、内容等于 `words[j]` 某个 border 前缀的字符串个数」。

剩下两个子问题：

1. 如何**快速求出一个串的所有 border**？——Z 函数（扩展 KMP）一遍线性扫描；
2. 如何**快速查询某个前缀之前出现过几次**？——把每个完整字符串插入字典树，节点计数。

### 3.3 算法流程：Z 函数求 border + 字典树查询

**第一步：Z 函数标记所有 border。**

![Z 函数一遍扫描求出所有 border](images/wc385_q4_z_function_border.svg)

设 $z[i]$ 为 $s$ 与其后缀 $s[i:]$ 的**最长公共前缀**长度。长度为 $d$ 的后缀是 border $\iff z[n-d] = d$（因后缀 $s[n-d:]$ 长度为 $d$，恒有 $z[n-d] \le d$，取等即「前缀与该后缀完全相同」）。Z 函数均摊 $O(|s|)$，一次扫描即可得到全部 border 标记——**不要**对每个长度单独比较，那会退化到 $O(|s|^2)$。

**第二步：字典树上「查询 + 插入」合一。**

![算法流程：查询与插入合为一次 Trie 遍历](images/wc385_q4_algorithm_flow.svg)

按输入顺序处理每个 `word`（记长度 $n$）：

1. Z 函数求出 `is_border[1..n]`（注意 `is_border[n] = 1`，自身也是 border）；
2. 从根出发沿 `word` 的字符逐个下走 Trie，**没有子节点就新建**；走到深度 $d$ 时若 `is_border[d]` 成立，则 `ans += cnt[node]`——`cnt` 记录「以该节点对应前缀为**完整内容**插入过的字符串个数」；
3. 走到叶子后 `cnt[终点] += 1`，把 `word` 自身记入 Trie，供后续查询。

> ⚠️ 两个时序要点：**查询先于插入**——本次遍历中新建的节点 `cnt = 0`，即使其深度恰为 border 也不会错误累加；**`d = n`（自身）也在 border 集合里**——重复串如 `["ab","ab"]` 会被自动计入。

### 3.4 示例演算

![示例 1 的 Trie 生长与累加过程](images/wc385_q4_trie_walkthrough.svg)

以 `words = ["a","aba","ababa","aa"]` 为例走一遍：`"a"` 查询加 0 后插入；`"aba"` 的 border `{1,3}` 中深度 1 命中已插入的 `"a"`（+1）；`"ababa"` 的 border `{1,3,5}` 中深度 1（+1）、深度 3（+1）命中；`"aa"` 的 border `{1,2}` 中深度 1 命中（+1）。累计 $0+1+2+1 = 4$，与示例输出一致。

## 4. 算法细节

1. **Z 函数（box 技巧）**：维护最右匹配框 $[l, r)$，若 $i < r$ 则用 $z[i-l]$ 作为初值继续暴力扩展；每次扩展成功都会右移 $r$，故总扩展次数均摊 $O(n)$。注意 $z[0]$ 各模板约定不一（0 或 $n$），代码中**不要依赖** `z[0]`，自身 border 直接用 `is_border[n] = 1` 特判。
2. **border 判定式**：对 $1 \le d < n$，`is_border[d] = (z[n-d] == d)`；加上 $d = n$ 共 $O(L)$ 个标记。
3. **数组 Trie**：`tr[N][26]`、`cnt[N]`，节点数上界 $\sum |w_i| + 1 \le 5 \times 10^5 + 1$；查询与插入共用一次从根到叶的遍历。
4. **答案类型**：对数上界 $\binom{10^5}{2} \approx 5 \times 10^9$，超过 `int32`，C++ 必须用 `long long`。
5. **多测复用**：类成员数组在函数开头只清「已用过的前 `idx+1` 行」，避免每次全量 `memset` 52 MB。
6. **Python 内存替代**：数组 Trie 在 Python 中开销过大，可用**双模数滚动哈希**边走边算每个前缀的哈希值 $O(1)$ 查 `Counter`——单模数可被构造数据卡掉，双模数（组合超过 $10^{17}$ 量级）碰撞概率可忽略；追求绝对无冲突则用 C++ 的 Trie 版本。
7. **KMP 等价写法**：用前缀函数 $\pi$ 从 $n$ 沿失配链 $n \to \pi[n-1] \to \pi[\pi[n-1]-1] \to \cdots$ 同样能枚举全部 border 长度，复杂度相同，任选其一。

## 5. 正确性证明

**引理 1（border 的 Z 函数刻画）**：对 $1 \le d < n$，长度为 $d$ 的后缀等于长度为 $d$ 的前缀 $\iff z[n-d] = d$。

**证明**：后缀 $s[n-d:]$ 长为 $d$，故 $z[n-d] \le d$。而 $z[n-d] = d$ 当且仅当 $s$ 的前 $d$ 个字符与 $s[n-d:]$ 逐位相同，即 $s[0..d-1] = s[n-d..n-1]$。∎

**引理 2（判定等价）**：$\text{isPrefixAndSuffix}(x, y)$ 成立 $\iff$ 存在 $y$ 的 border 长度 $d$（含 $d = |y|$）使 $x = y[0..d-1]$。

**证明**：（⇒）设 $|x| = d$，前缀条件给出 $x = y[0..d-1]$，后缀条件给出 $y[|y|-d..|y|-1] = x$，两式合并得长度 $d$ 的前后缀相等，$d$ 是 border 长度。（⇐）若 $x = y[0..d-1]$ 且 $d$ 是 border 长度，则 $x$ 是前缀；又 $y$ 的末尾 $d$ 个字符 $= y[0..d-1] = x$，故 $x$ 是后缀。∎

**定理**：算法返回值恰为满足条件的下标对数量。

**证明**：归纳断言：处理第 $j$ 个串 $w_j$ **之前**，Trie 中任意节点 $p$（对应前缀 $\sigma(p)$）满足 $cnt[p] = \#\{i < j : w_i = \sigma(p)\}$。$j = 0$ 时 Trie 为空，成立。设处理 $w_j$：沿其字符下走到深度 $d$ 的节点对应串 $w_j[0..d-1]$——已存在的节点由归纳假设给出正确计数；新建节点对应的前缀此前从未在 Trie 中出现，不可能等于任何 $w_i\ (i<j)$，且其 `cnt = 0`，等价仍成立。算法本次累加

$$T_j = \sum_{d \in B(w_j)} \#\{i < j : w_i = w_j[0..d-1]\}$$

其中 $B(w_j)$ 为 border 长度集合。由引理 2，满足判定的每个 $i$ 恰对应唯一 $d = |w_i| \in B(w_j)$ 且 $w_i = w_j[0..d-1]$，在 $T_j$ 中被计入一次；被计入的 $i$ 显然满足判定。故 $T_j = \#\{i < j : \text{isPrefixAndSuffix}(w_i, w_j)\}$。处理完后仅 $cnt[w_j\text{ 终点}]$ 增加 1，归纳断言对 $j+1$ 保持。对所有 $j$ 求和即得答案。∎

## 6. 复杂度分析

- **时间复杂度**：$O\!\left(\sum_i |w_i|\right)$。每个字符串花费一次 Z 函数 $O(L)$（box 均摊）+ 一次 Trie 遍历 $O(L)$，总计与总长度 $5 \times 10^5$ 同阶。
- **空间复杂度**：C++ 数组 Trie 为 $O(26 \cdot \sum |w_i|)$，节点数上界 $5 \times 10^5 + 1$，约 52 MB（实际只占所有前缀去重后的数量，通常远小于上界）；Python 双哈希版为 $O\!\left(\sum |w_i|\right)$，另需 $O(L)$ 的 Z 数组与标记数组（逐串复用）。

## 7. 参考代码

### C++

```cpp
class Solution {
    static constexpr int N = 500010;   // 节点数上界：Σ|w| + 1
    int tr[N][26];
    long long cnt[N];
    int idx;
public:
    long long countPrefixSuffixPairs(vector<string>& words) {
        for (int v = 0; v <= idx; v++) {   // 只清已用过的节点，兼容多次调用
            memset(tr[v], 0, sizeof(tr[v]));
            cnt[v] = 0;
        }
        idx = 0;
        long long ans = 0;
        for (const string& w : words) {
            int n = w.size();
            vector<int> z(n);
            for (int i = 1, l = 0, r = 0; i < n; i++) {   // Z 函数，z[0] 不用
                if (i < r) z[i] = min(r - i, z[i - l]);
                while (i + z[i] < n && w[z[i]] == w[i + z[i]]) z[i]++;
                if (i + z[i] > r) l = i, r = i + z[i];
            }
            vector<char> isBorder(n + 1);
            isBorder[n] = 1;                              // 自身也是 border
            for (int d = 1; d < n; d++) isBorder[d] = (z[n - d] == d);
            int cur = 0;
            for (int d = 1; d <= n; d++) {                // 查询与插入合一
                int c = w[d - 1] - 'a';
                if (!tr[cur][c]) tr[cur][c] = ++idx;
                cur = tr[cur][c];
                if (isBorder[d]) ans += cnt[cur];         // 新建节点 cnt=0，天然安全
            }
            cnt[cur]++;                                   // 走完后再插入 word 自身
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def countPrefixSuffixPairs(self, words: List[str]) -> int:
        MOD1, MOD2, B = 1_000_000_007, 998_244_353, 131
        cnt = defaultdict(int)   # (双哈希) -> 出现次数
        ans = 0
        for w in words:
            n = len(w)
            # Z 函数
            z = [0] * n
            l = r = 0
            for i in range(1, n):
                if i < r:
                    z[i] = min(r - i, z[i - l])
                while i + z[i] < n and w[z[i]] == w[i + z[i]]:
                    z[i] += 1
                if i + z[i] > r:
                    l, r = i, i + z[i]
            # border 标记
            is_border = bytearray(n + 1)
            is_border[n] = 1
            for d in range(1, n):
                if z[n - d] == d:
                    is_border[d] = 1
            # 滚动哈希：边走边算前缀哈希，border 深度处查表累加
            h1 = h2 = 0
            for d, ch in enumerate(w, 1):
                o = ord(ch)
                h1 = (h1 * B + o) % MOD1
                h2 = (h2 * B + o) % MOD2
                if is_border[d]:
                    ans += cnt[h1 << 32 | h2]
            cnt[h1 << 32 | h2] += 1
        return ans
```

## 8. 边界情况与易错点

1. **答案溢出**：最多 $\binom{10^5}{2} \approx 5 \times 10^9$ 对，超出 `int32` 上界，C++ 必须用 `long long`（Python 天然大数无碍）。
2. **自身也是 border**：`is_border[n] = 1` 别漏，否则相同串如 `["ab","ab"]` 的合法对会被漏计。
3. **`z[0]` 约定陷阱**：不同模板把 `z[0]` 定义为 $0$ 或 $n$，本解法完全不读 `z[0]`，用 `is_border[n] = 1` 特判替代，规避模板差异。
4. **时序顺序**：一定是「先沿路径累加查询、走完后 `cnt++` 插入」；反过来会把当前串和自己配对，多算一倍同长前缀的贡献。
5. **最坏用例全 `'a'` 串**：单串 border 数可达 $O(L)$，但标记与查询仍线性；千万别写成「对每个 border 单独 `slice` / 单独比较」，那是 $O(L^2)$。
6. **C++ 数组规模**：`tr[500010][26]` 约 52 MB，节点上限 $\sum|w|+1$；若类被复用多次调用，只清 `0..idx` 行，避免每次全量清零超时。
7. **哈希安全性**：Python 单模数滚动哈希可被特殊构造数据卡冲突，双模数组合后碰撞概率可忽略；要求绝对正确请用 C++ 的 Trie 版本。
8. **无需长度特判**：`words[i]` 长于 `words[j]` 时在 Trie 中走不到对应深度，天然不匹配——Q1 暴力解里「无符号下溢」的坑在这里结构性地消失了。
