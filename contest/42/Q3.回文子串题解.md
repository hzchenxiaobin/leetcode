# LeetCode 回文子串 题解

## 1. 题目概述

- **标题 / 题号**：回文子串（#647，medium）
- **链接**：https://leetcode.cn/problems/palindromic-substrings/
- **来源**：LeetCode 第 42 场周赛 Q3
- **难度**：中等
- **标签**：双指针、字符串、动态规划

**题意**：给定字符串 $s$，统计它有多少个**回文子串**。回文指正读反读相同；子串指连续的一段。**按位置计数**：内容相同但出现位置不同的两个子串算两个，长度 1 的子串一律是回文。

一句话：对每个中心向外扩到底，把每个中心能扩出的回文个数全部加起来。

**约束**：

- $1 \le \lvert s \rvert \le 1000$
- `s` 仅由小写英文字母组成
- 答案上界为 $\frac{n(n+1)}{2} = 500500$，32 位整数足够

## 2. 示例

**示例 1**

```text
输入：s = "abc"
输出：3
解释：三个回文子串："a"、"b"、"c"。
      任何长度 ≥ 2 的子串都不是回文（"ab"、"bc"、"abc" 均不是）。
```

**示例 2**

```text
输入：s = "aaa"
输出：6
解释：6 个回文子串："a"（下标 0）、"a"（下标 1）、"a"（下标 2）、
      "aa"（下标 0..1）、"aa"（下标 1..2）、"aaa"（下标 0..2）。
      注意两个 "aa" 内容相同但位置不同，必须分别计数。
```

**示例 3（补充，用于演算）**

```text
输入：s = "abba"
输出：6
解释："a"、"b"、"b"、"a"、"bb"、"abba"，共 6 个。
      本题最容易被忽略的是偶数长度回文 "bb" 与 "abba"。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有子串（共 $O(n^2)$ 个），对每个子串再用双指针判断是否回文（$O(n)$），总时间 $O(n^3)$。$n = 1000$ 时约 $10^9$ 次字符比较，超出时间限制。

两种标准优化路线：

| 路线 | 做法 | 时间 | 空间 |
|------|------|------|------|
| 区间 DP | 预处理回文判定表 | $O(n^2)$ | $O(n^2)$ |
| **中心扩展** | 枚举回文中心，向两侧扩展到失配 | $O(n^2)$ | $O(1)$ |

区间 DP 的转移为

$$\text{isPal}[l][r] = \bigl(s[l] = s[r]\bigr) \land \bigl(r-l < 2 \lor \text{isPal}[l+1][r-1]\bigr)$$

两者复杂度同阶，但中心扩展**省掉 $n^2$ 的表**，代码只有十几行，是本题最经济的写法。

### 3.2 核心观察：回文由「中心」唯一确定

![回文中心模型：2n−1 个中心](images/wc42_q3_center_model.svg)

关键观察：**一个回文子串被它的中心唯一确定**。

- 长度为**奇数**的回文，中心是某个字符 $s[i]$；
- 长度为**偶数**的回文，中心是相邻两个字符之间的**空隙** $(i, i+1)$。

于是全串共有 $n + (n-1) = 2n-1$ 个中心。反过来，从任意中心出发，半径 $1,2,3,\dots$ 对应的是**长度递增、且互不相同**的回文串（都共享这个中心），所以「按中心枚举 + 累加半径」既不重也不漏。

对比暴力枚举区间：同一中心上的多个回文会被反复独立判断，白做功；按中心枚举则一次外扩就把该中心的全部回文一次性数完。

### 3.3 算法流程

![中心扩展流程](images/wc42_q3_expand_flow.svg)

伪代码：

```text
ans = 0
for i in 0 .. n-1:
    ans += expand(i, i)        # 奇数中心
    ans += expand(i, i + 1)    # 偶数中心（空隙）
return ans

expand(l, r):
    cnt = 0
    while l >= 0 and r < n and s[l] == s[r]:
        cnt += 1; l -= 1; r += 1
    return cnt
```

**为什么「扩到失配就停」是安全的**：把中心记成窗口 $[l, r]$（奇数中心是单字符 $[i,i]$，偶数中心是空窗口 $[i+1, i]$）。第 $k$ 次成功匹配时，窗口变成 $[l-k, r+k]$：它在已有回文外侧又包了一对相等字符，因此仍是回文（引理 2 的逆）；而第一次失配或越界之后，任何更长的窗口都会把这对不相等的字符放到对称位置，必然不是回文。所以成功匹配的次数恰好等于该中心的回文个数，中途停下既不漏也不多。

### 3.4 示例演算

![s = "abba" 的中心扩展演算](images/wc42_q3_walkthrough.svg)

对 `s = "abba"`（$n=4$，$2n-1 = 7$ 个中心）：

| 中心 | 类型 | 扩展过程 | 贡献 |
|------|------|----------|------|
| $i=0$ | 奇 | `"a"`，再外扩越界 | 1 |
| 空隙 $0\lvert1$ | 偶 | `s[0]=a ≠ s[1]=b`，立即停 | 0 |
| $i=1$ | 奇 | `"b"`，`s[0]≠s[2]` | 1 |
| 空隙 $1\lvert2$ | 偶 | `"bb"` → `"abba"` → 越界 | 2 |
| $i=2$ | 奇 | `"b"`，`s[1]≠s[3]` | 1 |
| 空隙 $2\lvert3$ | 偶 | `s[2]=b ≠ s[3]=a` | 0 |
| $i=3$ | 奇 | `"a"`，越界 | 1 |

合计 $1+0+1+2+1+0+1 = 6$，与官方答案一致。再看 `"aaa"`：$6$ 次扩展的贡献为 $1+1+2+1+1+0 = 6$，其中中心 $i=1$ 一次贡献 $2$（`"a"` 与 `"aaa"`），正是「一个中心多个回文」的典型。

## 4. 算法细节

1. **统一接口**：奇数中心与偶数中心都写成 `expand(l, r)`，外层只负责传入 `(i, i)` 与 `(i, i+1)`，避免写两份几乎相同的循环。
2. **边界判断必须先于字符比较**：`while left >= 0 and right < n and s[left] == s[right]` 的顺序不能换。Python 的负下标会把 `left = -1` 解释成串尾字符，`right = n` 则直接抛 `IndexError`；把字符比较写在边界判断前面，程序会崩溃或读到错误位置。
3. **偶数中心的入口**：`i = n-1` 时传入 `(n-1, n)`，`right < n` 立刻为假，直接返回 0，属于无害的空调用；因此循环写 `for i in range(n)` 即可，不必特判。
4. **计数时机**：每成功匹配一次就 `cnt += 1`，此时 `s[l..r]` 恰是一个新回文，**不需要真的切片**去存子串；若每步都切片，单次 $O(\text{长度})$ 的拷贝会把总开销放大到 $O(n^3)$。
5. **奇数中心第一次比较恒真**：`(i, i)` 时 `s[i] == s[i]` 必然成立，所以每个奇数中心至少贡献 1，长度 1 的回文自然被计入，无需额外加 $n$。
6. **不要用「去重集合」**：题目按位置计数，`"aaa"` 中两个 `"aa"` 都要算；若用 `set` 存子串内容会得到 3 而不是 6。
7. **答案范围**：$n \le 1000$ 时最大值 500500，`int` 足够；若把题目推广到 $n = 10^5$（答案约 $5\times10^9$），C++ 需换 `long long`。
8. **迭代而非递归**：中心扩展写成 `while` 循环，递归深度可能到 $n/2$，在极端输入下不必要地消耗栈。

## 5. 正确性证明

**引理 1（中心唯一）**：任意非空回文子串 $s[l..r]$ 恰有一个中心，且该中心必在上述 $2n-1$ 个中心之中。

**证明**：长度 $L = r-l+1$。

- $L$ 为奇数：取 $c = \frac{l+r}{2}$（整数），则 $l = c-k$、$r = c+k$，其中 $k = \frac{L-1}{2}$。$s[l..r]$ 以字符 $s[c]$ 为中心，且这样的 $c$ 唯一。
- $L$ 为偶数：$l+r$ 为奇数，取 $i = \lfloor \frac{l+r}{2}\rfloor$，则 $l = i-k+1$、$r = i+k$，其中 $k = \frac{L}{2}$。$s[l..r]$ 以空隙 $(i, i+1)$ 为中心，同样唯一。

$c$ 取遍 $0..n-1$、$i$ 取遍 $0..n-2$，合计 $2n-1$ 个中心，故每个回文子串都被且仅被一个中心覆盖。∎

**引理 2（内层仍是回文，及其逆）**：若 $s[l..r]$ 是回文且 $l \le r$，则 $s[l+1..r-1]$ 也是回文（$l+1 > r-1$ 时约定空串是回文）；反之，若 $v$ 是回文且两侧字符相等，则 $x\,v\,x$ 仍是回文。

**证明**：设 $w = s[l..r] = x\,v\,x$ 且 $w = w^{R}$，其中 $x = s[l] = s[r]$，$v = s[l+1..r-1]$。由 $x\,v\,x = x\,v^{R}\,x$，两边去掉相同的首尾字符得 $v = v^{R}$，即 $v$ 是回文。

反之，若 $v = v^{R}$ 且 $x$ 是任意字符，则 $\overline{x\,v\,x} = x\,v^{R}\,x = x\,v\,x$（字符串反转把首尾互换），故 $x\,v\,x$ 是回文。∎

**引理 3（`expand` 计数精确）**：`expand(l, r)` 的返回值等于以 $(l, r)$ 为中心的回文子串个数。

**证明**：对 while 循环的次数归纳，维护不变量「当前窗口 $s[l..r]$ 是回文（$l > r$ 时为空窗口，视为回文）」。

- 初始：奇数中心 $l = r$，单字符是回文；偶数中心 $l = r+1$，空窗口是回文。
- 若 $s[l-1] = s[r+1]$：由引理 2 的逆，把这对相等字符包在回文外侧得到的 $s[l-1..r+1]$ 仍是回文，不变量保持，`cnt` 加 1；每次窗口严格变长，故已计数的回文两两不同。
- 若 $s[l-1] \ne s[r+1]$ 或越界：任何以该中心、严格更长的回文都必须把 $s[l-1]$ 与 $s[r+1]$ 放在对称位置（回文中对称字符相等），与不相等或非法下标矛盾，故之后不会再有新回文，循环结束。

因此 `cnt` 恰好等于该中心能扩出的回文个数。∎

**定理**：算法返回值等于 $s$ 的回文子串总数。

**证明**：由引理 1，所有回文子串按中心分成 $2n-1$ 个互不相交的类；由引理 3，`expand` 对每个中心给出的正是该类的大小，且非回文子串不会被计入（循环只在回文成立时计数）。对所有中心求和即得总数。∎

## 6. 复杂度分析

- **时间**：$O(n^2)$。以 $i$ 为奇数中心最多扩 $\min(i+1,\ n-i)$ 步，以空隙 $(i, i+1)$ 为中心的偶数中心最多扩 $\min(i+1,\ n-i-1)$ 步，故总比较次数为
  $$\sum_{i=0}^{n-1} \Bigl(\min(i+1,\ n-i) + \min(i+1,\ n-i-1)\Bigr) = O(n^2).$$
  最坏情况是全串为同一字符（如 `"aaaa...a"`），此时必须真的走到边界；最好情况是字符两两不同，每个中心只做 $O(1)$ 次比较，退化为 $O(n)$。$n = 1000$ 时约 $10^6$ 次比较。
- **空间**：$O(1)$。只用 `ans`、`cnt`、`l`、`r` 等常数个变量，没有 DP 表、没有子串拷贝；输入字符串本身不计。若改用区间 DP 则需 $O(n^2)$ 空间。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int countSubstrings(string s) {
        int n = (int)s.size();

        // 以 (l, r) 为中心向外扩展，返回该中心上的回文子串个数
        auto expand = [&](int l, int r) -> int {
            int cnt = 0;
            while (l >= 0 && r < n && s[l] == s[r]) {
                ++cnt;
                --l;
                ++r;
            }
            return cnt;
        };

        int ans = 0;
        for (int i = 0; i < n; ++i) {
            ans += expand(i, i);      // 奇数长度：中心是一个字符
            ans += expand(i, i + 1);  // 偶数长度：中心是相邻字符间的空隙
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def countSubstrings(self, s: str) -> int:
        n = len(s)

        def expand(left: int, right: int) -> int:
            cnt = 0
            # 先判边界再取字符：Python 负下标会绕回串尾，顺序不能换
            while left >= 0 and right < n and s[left] == s[right]:
                cnt += 1
                left -= 1
                right += 1
            return cnt

        ans = 0
        for i in range(n):
            ans += expand(i, i)      # 奇数长度：中心是一个字符
            ans += expand(i, i + 1)  # 偶数长度：中心是两个字符之间的空隙
        return ans
```

## 8. 边界情况与易错点

1. **单字符输入**：`s = "a"` → 1。循环只执行 `expand(0, 0)` 得 1、`expand(0, 1)` 得 0，无需特判。
2. **Python 负下标陷阱**：若把条件写成 `s[left] == s[right] and right < n and left >= 0`，`right = n` 时 `s[n]` 直接抛 `IndexError`，`left = -1` 又会被解释成串尾字符。**边界判断必须写最前面**，靠 `and` 短路挡住非法下标。
3. **偶数中心越界**：`i = n-1` 时 `(n-1, n)` 的 `right` 越界，靠 `right < n` 短路返回 0；不要为此把循环改成 `range(n-1)`，否则最后一个字符的奇数中心会被漏掉。
4. **按内容去重**：`"aaa"` 的正确答案是 6 而不是 3；用 `set` 收集子串内容必然错。
5. **重复计数**：同一中心上 `cnt` 每步加 1 是对的，因为它们长度不同、起点不同；但不要写成「每步加 2」（左右各算一次）。
6. **整数范围**：$n = 1000$ 时答案 500500 只用 `int`；若题目把 $n$ 放大到 $10^5$，答案约 $5\times 10^9$，C++ 必须用 `long long`。
7. **扩展顺序**：若先 `l--; r++` 再比较，第一个字符对就被跳过，长度 1 的回文会漏掉。
8. **递归实现**：用递归写扩展在 $n = 1000$ 的极端重复串上会产生约 500 层递归，纯属浪费；统一用 `while`。
