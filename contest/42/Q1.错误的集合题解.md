# LeetCode 错误的集合 题解

## 1. 题目概述

- **标题 / 题号**：错误的集合（#645，easy）
- **链接**：https://leetcode.cn/problems/set-mismatch/
- **来源**：LeetCode 第 42 场周赛 Q1
- **难度**：简单
- **标签**：位运算、数组、哈希表、排序

**题意**：集合本应恰好是 $\{1,2,\dots,n\}$。一次数据错误把其中一个数改成了集合里另一个数的值，于是**一个数出现两次**、**另一个数消失**。给定出错后的数组 `nums`（长度 $n$），返回 `[重复出现的数, 丢失的数]`。

**约束**：

- $2 \le \text{nums.length} \le 10^4$
- $1 \le \text{nums}[i] \le 10^4$
- 输入保证：所有值落在 $[1,n]$ 内，且恰有一个值出现两次、恰有一个值出现零次

## 2. 示例

**示例 1**

```text
输入：nums = [1,2,2,4]
输出：[2,3]
解释：2 出现了两次，3 没有出现。
```

**示例 2**

```text
输入：nums = [1,1]
输出：[1,2]
解释：n = 2，1 出现两次，2 缺失。
```

**补充示例（自测用）**

```text
输入：nums = [1,2,3,4,5,5]
输出：[5,6]
解释：n = 6，5 重复、6 缺失——缺失值可以等于 n，判定逻辑不要写死成「只看前 n-1 个」。
```

## 3. 解题思路

### 3.1 暴力思路

签到题的第一反应是「把每个数数一遍」：

- **计数数组**：开 `cnt[1..n]`，遍历 `nums` 累加；最后 `cnt[v] == 2` 的是重复值，`cnt[v] == 0` 的是缺失值。时间 $O(n)$、空间 $O(n)$。
- **排序**：升序排序后，相邻相等的一对给出重复值；再从 $1$ 扫到 $n$，第一个没出现的值给出缺失值。时间 $O(n\log n)$、空间 $O(1)$（不计排序自身开销）。

两者在 $n \le 10^4$ 时都能通过，但本题是练习**位运算**的好素材：借助异或的自反性，可以做到时间 $O(n)$、额外空间 $O(1)$，而且完全不修改输入数组。

### 3.2 核心观察：整体异或只剩 $d \oplus m$

![异或消去：正确值成对抵消，只留下重复值与缺失值](images/wc42_q1_xor_insight.svg)

把 $1..n$ 与 `nums` 的所有元素**放在一起异或**。异或满足交换律、结合律，且 $a \oplus a = 0$，于是每个数只看「出现次数的奇偶性」：

- 正确出现的数：理想集合里一次、`nums` 里一次 → 异或抵消为 $0$；
- 重复值 $d$：`nums` 里两次、理想集合里一次 → 共三次，净剩一次；
- 缺失值 $m$：理想集合里一次、`nums` 里零次 → 净剩一次。

所以

$$x = \Bigl(\bigoplus_{v \in \text{nums}} v\Bigr) \oplus \Bigl(\bigoplus_{v=1}^{n} v\Bigr) = d \oplus m$$

因为 $d \ne m$，必有 $x \ne 0$。取**最低设置位** $\text{low} = x \,\&\, (-x)$，它对应的二进制位就是 $d$ 与 $m$ **第一个不同的位**——在这一位上，二者必然一个为 $0$、一个为 $1$。

### 3.3 算法流程：按最低不同位分组

![按最低不同位把 1..n 与 nums 分到两个桶](images/wc42_q1_group_split.svg)

1. 求 $x = d \oplus m$，取 `low = x & (-x)`；
2. 把 `nums` 与 $1..n$ 中的**所有**数按 `v & low` 是否为 $0$ 分成两组，两组内部分别异或，得到 `a` 与 `b`；
3. 由于 $d$ 与 $m$ 在第 $\log_2 \text{low}$ 位不同，它们必然落在不同组，所以 $\{a,b\} = \{d,m\}$（引理 2）；
4. 判定方向：在 `nums` 里**出现过**的是重复值，**没出现过**的是缺失值。

### 3.4 示例演算

![示例 [1,2,2,4] 的逐步走查](images/wc42_q1_walkthrough.svg)

以 `nums = [1,2,2,4]`、$n = 4$ 为例：

| 步骤 | 计算 | 结果 |
|------|------|------|
| ① 理想集合异或 | $1 \oplus 2 \oplus 3 \oplus 4$ | $4$ |
| ② `nums` 异或 | $1 \oplus 2 \oplus 2 \oplus 4$ | $5$ |
| ③ 合并 | $x = 4 \oplus 5$ | $1 = 001_2$ |
| ④ 最低位 | `low = 1 & (-1)` | $1$ |
| ⑤ 组 `bit=1` | $1 \oplus 3 \oplus 1$ | $3$ |
| ⑥ 组 `bit=0` | $2 \oplus 4 \oplus 2 \oplus 2 \oplus 4$ | $2$ |
| ⑦ 判定 | $3 \notin$ `nums`，$2 \in$ `nums` | `[2,3]` |

## 4. 算法细节

1. **两轮异或的顺序无所谓**：先异或 `nums` 再异或 $1..n$，或者两轮合并成一个循环都可以，异或可交换。
2. **`low` 的求法**：`x & (-x)` 取出最低设置位，例如 $x = 12 = 1100_2$ → `low = 4`。题目保证 $x \ne 0$，所以 `low` 一定落在有效位上。
3. **分组时两个来源都要过**：`nums` 与 $1..n$ 都要按 `v & low` 分配到 `a` 或 `b`，漏掉任何一边都会破坏抵消关系。
4. **判定重复值用线性扫描**：`a in nums`（C++ 用 `find`/循环）代价 $O(n)$，整体复杂度不变；也可用 $\text{sum}(\text{nums}) - \frac{n(n+1)}{2} = d - m$ 在 $O(1)$ 内判定方向（C++ 需 `long long` 防溢出）。
5. **不要依赖 `nums` 有序**：异或法天然与顺序无关，这正是它比排序法省一个 $\log$ 因子的原因。
6. **不修改输入**：另一种 $O(1)$ 空间做法是把 `nums[v-1]` 取负做原地标记，但会破坏输入；异或法没有这个副作用。
7. **整数范围**：$n \le 10^4 < 2^{14}$，`x`、`low`、`a`、`b` 都远小于 `int` 上限，无需 `long long`；只有用求和判方向时才需要 64 位。

## 5. 正确性证明

**引理 1（异或恒等式）**：设 `nums` 由 $\{1,\dots,n\}$ 把 $m$ 替换成 $d$ 得到（$d \ne m$），则 $x = \bigl(\bigoplus_{v \in \text{nums}} v\bigr) \oplus \bigl(\bigoplus_{v=1}^{n} v\bigr) = d \oplus m$。

**证明**：记 $S = \bigoplus_{v=1}^{n} v$。`nums` 与理想集合只差一个元素：$m$ 被换成了 $d$，故 $\bigoplus_{v \in \text{nums}} v = S \oplus m \oplus d$（异或中「删去 $m$」与「加入 $d$」都是再异或一次）。于是 $x = (S \oplus m \oplus d) \oplus S = m \oplus d$，由交换律即 $d \oplus m$。∎

**引理 2（分组分离）**：设 $b$ 为 $d$ 与 $m$ 最低的不同二进制位，$\text{low} = 2^b$。把 $1..n$ 与 `nums` 的全部元素按第 $b$ 位分成两组、组内异或得到 $a,b$，则 $\{a,b\} = \{d,m\}$。

**证明**：对任意 $v \in \{1,\dots,n\}$，统计它在「理想集合 + `nums`」中的总出现次数：正确值出现 $2$ 次（偶数，异或抵消）；$d$ 出现 $3$ 次（`nums` 两次 + 理想集合一次，奇数，净剩 $d$）；$m$ 出现 $1$ 次（奇数，净剩 $m$）。因此两组合计贡献为 $d \oplus m$。又因 $d$ 与 $m$ 在第 $b$ 位上一个为 $1$、一个为 $0$，它们被分到不同组，各组只含其中一个异常值，故两组结果分别为 $d$ 与 $m$（顺序不定）。∎

**引理 3（重复/缺失的判定）**：$d$ 在 `nums` 中出现、$m$ 不在 `nums` 中出现。

**证明**：由题意，重复值出现两次、缺失值出现零次，而 $\{a,b\}=\{d,m\}$，故「是否在 `nums` 中出现」恰好把两者区分开。∎

**定理**：算法返回的数组恰为 `[重复值, 缺失值]`。

**证明**：由引理 1、2，候选集合 $\{a,b\}$ 等于 $\{d,m\}$；由引理 3，出现过的那个是 $d$、未出现的是 $m$；代码按此顺序返回。∎

## 6. 复杂度分析

- **时间**：$O(n)$。求 $x$ 是两轮 $O(n)$ 扫描；分组是两轮 $O(n)$ 扫描；最后判定重复值一次 $O(n)$ 扫描。总常数约 $5n$ 次位运算与比较。
- **空间**：$O(1)$。只使用 `x`、`low`、`a`、`b` 等常数个整型变量，不需要计数数组或哈希表，也不修改输入。

## 7. 参考代码

### C++

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> findErrorNums(vector<int>& nums) {
        int n = nums.size();
        int x = 0;
        for (int v : nums) x ^= v;          // nums 的整体异或
        for (int v = 1; v <= n; ++v) x ^= v; // 再异或 1..n，只剩 dup ^ missing
        int low = x & (-x);                  // 最低不同位

        int a = 0, b = 0;
        for (int v : nums) {                 // nums 按该位分两组
            if (v & low) a ^= v;
            else         b ^= v;
        }
        for (int v = 1; v <= n; ++v) {       // 1..n 也按该位分两组
            if (v & low) a ^= v;
            else         b ^= v;
        }

        bool aIsDup = false;
        for (int v : nums) {
            if (v == a) { aIsDup = true; break; }
        }
        return aIsDup ? vector<int>{a, b} : vector<int>{b, a};
    }
};
```

### Python

```python
class Solution:
    def findErrorNums(self, nums: list[int]) -> list[int]:
        n = len(nums)
        x = 0
        for v in nums:
            x ^= v
        for v in range(1, n + 1):
            x ^= v            # x = 重复值 ^ 缺失值，且 x != 0
        low = x & -x          # 最低不同位

        a = b = 0
        for v in nums:
            if v & low:
                a ^= v
            else:
                b ^= v
        for v in range(1, n + 1):
            if v & low:
                a ^= v
            else:
                b ^= v

        # 出现在 nums 里的是重复值，另一个是缺失值
        return [a, b] if a in nums else [b, a]
```

## 8. 边界情况与易错点

1. **$n = 2$ 的最小输入**：`[1,1]` → `[1,2]`，`[2,2]` → `[2,1]`。此时某个分组只有一个元素，异或结果仍是它本身，逻辑不受影响。
2. **缺失值等于 $n$**：`[1,2,3,4,5,5]` 缺 $6$。不要写成「在 $[1,n-1]$ 里找缺失值」，否则会漏掉 $n$。
3. **排序法的经典坑**：只在相邻位置找重复，容易把「末尾重复」漏掉（如 `[1,1,2,3,4,4]` 中的两个异常都要靠 $1..n$ 扫描确认），本题用异或法直接绕开。
4. **$x = 0$ 的防御**：题面保证 $d \ne m$，故 $x \ne 0$、`low` 有效。若把此题推广到「输入可能完全正确」，需要先判 $x = 0$ 直接返回。
5. **`low` 与分组位的一致性**：`v & low` 只检查那一位，不是 `v & x`；写成 `v & x` 会用到多个不同位，导致分组混乱。
6. **判定方向不能省**：`a`、`b` 的顺序取决于遍历与异或顺序，不保证 `a` 是重复值，必须显式判断后再拼返回值。
7. **C++ 的 `x & (-x)`**：`x` 为正数时补码语义下结果正确；不要为了「避免负数」写成 `x & (~x + 1)` 之外的复杂形式（等价但可读性差）。

**延伸思考**：若错误是「$k$ 个数被改坏」（出现 $k$ 个重复值、$k$ 个缺失值），一次异或只能得到 $\bigoplus$ 全部异常值，无法直接分组；此时可用**按位计数**（统计每个二进制位上 $1$ 的个数差）或**求和/平方和**列方程。若要求 $O(1)$ 空间且不修改数组，还可借助**位图分块**：用两级 bitset 先把值域压缩，再精确定位异常值。另一种思路是把「秩」看成数组下标与值的偏移量——把 $a_i$ 当作指向 $a_i-1$ 的边，则重复值对应入度为 $2$ 的结点、缺失值对应入度为 $0$ 的结点，可用原地置换或判圈定位。
