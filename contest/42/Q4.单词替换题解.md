# LeetCode 单词替换 题解

## 1. 题目概述

- **标题 / 题号**：单词替换（#648，medium）
- **链接**：https://leetcode.cn/problems/replace-words/
- **来源**：LeetCode 第 42 场周赛 Q4
- **难度**：中等
- **标签**：字典树、数组、哈希表、字符串

**题意**：给定词根词典 `dictionary` 与一个用单个空格分隔单词的句子 `sentence`。对句子里的每个单词 $w$，若存在词根 $r \in \text{dictionary}$ 满足 $r$ 是 $w$ 的**前缀**，则把 $w$ 替换为**最短**的这样的 $r$（注意是「最短」，不是「最先出现」）；若不存在任何前缀词根，则 $w$ 原样保留。最后把所有单词按原顺序用一个空格拼回字符串返回。

**约束**：

- $1 \le \lvert \text{dictionary} \rvert \le 1000$，$1 \le \lvert r \rvert \le 100$，词根只含小写字母
- $1 \le \lvert \text{sentence} \rvert \le 10^6$，仅含小写字母与空格
- 句子中单词总数 $\le 1000$，每个单词长度 $\le 1000$
- 单词之间恰有一个空格，句首句尾没有空格

## 2. 示例

**示例 1**

```text
输入：dictionary = ["cat","bat","rat"], sentence = "the cattle was rattled by the battery"
输出："the cat was rat by the bat"
解释：cattle 的前缀 cat 是词根 → cat；rattled → rat；battery → bat；
      而 the / was / by 没有任何前缀词根，保持原样。
```

**示例 2**

```text
输入：dictionary = ["a","b","c"], sentence = "aadsfasf absbs bbab cadsfafs"
输出："a a b c"
解释：每个单词的第一个字符就已经是词根（长度 1 的 "a"、"b"、"c"），
      最短词根长度为 1，于是四个单词都被替换成单字符。
```

**示例 3**（自造，考察「最短」而非「第一个出现在词典里」的陷阱）

```text
输入：dictionary = ["ab","a","abc"], sentence = "abc ab a"
输出："a a a"
解释：abc 的候选前缀词根有 "a"、"ab"、"abc"，取最短的 "a"。
```

## 3. 解题思路

### 3.1 暴力思路

对句子每个单词，枚举全部词根并用 `startswith` 判断，保留长度最短者。最坏情况词长 1000、词根 1000 个、每个词根前 1000 字符都要比一遍，单次比较代价 $O(L)$，总计 $O(\text{词数} \cdot \lvert D \rvert \cdot L)$，量级 $10^9$ 字符比较，必然超时。

第二种「聪明一点」的暴力：把词根放进哈希集合，枚举单词的**所有前缀** $w[0..1), w[0..2), \dots, w[0..L)$，每个前缀查一次表，取最短命中者。判定从 $O(\lvert D \rvert)$ 降到 $O(L)$ 次查表，但**构造** $L$ 个前缀子串本身是 $O(L^2)$ 的字符复制（Python 的切片、C++ 的 `substr` 都是复制）。$L = 1000$ 时单词内部就退化成 $10^6$，乘上 1000 个单词仍是 $10^9$ 级别。

两条暴力都卡在同一个地方：**我们想要的是「最短的、同时是前缀的」词根**，而判断前缀天然是「一条链」，哈希表把链上每个点独立看待，白白丢掉了结构。

### 3.2 核心观察：前缀就是 Trie 上的一条根路径

![Trie 结构与查询规则](images/wc42_q4_trie_structure.svg)

单词 $w$ 的**所有前缀**，恰好就是从根出发、依次经过 $w[0], w[1], \dots$ 的那条路径上的**所有节点**。于是

> 「哪些前缀本身是词根」 $\iff$ 「这条路径上哪些节点被打上了终结标记」

这个等价关系把问题从「枚举 $L$ 个前缀分别查表」变成「沿着一条路径走一遍」。更关键的是：路径是从浅到深走的，而长度从小到大也正好对应深度从小到大，所以**遇到的第一个终结节点就是最短词根**，命中即可停止，后面的字符根本不用看。

反方向同样重要：如果走到某个字符时该节点**没有**对应子节点，说明这条路径断了。任何前缀词根都必须沿这条路径下降，路断了就说明**一个都不存在**，立刻保留原词。三种结局（命中、断链、走完仍未终结）都不需要回溯。

### 3.3 算法流程

![单词查询流程图](images/wc42_q4_query_flow.svg)

1. **建树**：把每个词根插入 Trie，逐字符新建节点，最后一个节点置 `isEnd = true`。相同前缀自动共享节点，重复词根、前缀词根都不会破坏正确性。
2. **切分**：`sentence` 按空格切分得到单词列表（题目保证单词间恰好一个空格，无需处理空串）。
3. **逐词查询**：从根出发，对 $w$ 的每个字符找子节点：
   - 找不到 → 断链，返回原词 $w$；
   - 找到且落到终结节点 → 立刻返回前缀 $w[0..i]$，**停止下降**；
   - 找到且非终结 → 继续下一字符。
4. **收尾**：若整个单词走完都没落到终结节点，返回原词。
5. **拼接**：用单个空格把结果连接，保持原有顺序。

### 3.4 示例演算

![示例 1 逐词演算](images/wc42_q4_walkthrough.svg)

对示例 1，词典为 `["cat","bat","rat"]`，树上有 `c→a→t`、`b→a→t`、`r→a→t` 三条链，三个 `t` 都是终结节点：

| 单词 | 沿 Trie 下降 | 结局 | 输出 |
|------|--------------|------|------|
| the | `t` 节点没有 `h` 子节点 | 断链 | the |
| cattle | `c→a→t` 第 3 步命中终结 | 替换为前缀 | cat |
| was | 根节点没有 `w` 子节点 | 断链 | was |
| rattled | `r→a→t` 命中终结 | 替换为前缀 | rat |
| by | `b` 之后没有 `y` 子节点 | 断链 | by |
| battery | `b→a→t` 命中终结 | 替换为前缀 | bat |
| the | 同第一行 | 断链 | the |

拼接得到 `"the cat was rat by the bat"`。注意 `cattle` 的 `tle`、`battery` 的 `tery` 自始至终没有被读取——命中即停是「最短」与「线性时间」两个目标的共同保证。

## 4. 算法细节

1. **终结标记必须与子节点表分离**。C++ 用 `vector<array<int,26>> nxt`（全 `-1` 表示无子节点）+ `vector<bool> isEnd`；Python 用 `children: list[dict]` + `is_end: list[bool]`。**不要**把特殊键（如 `'#'`）塞进 `array<int,26>` 的下标里，也不要让 26 个字母的下标与哨兵冲突。
2. **插入时剪掉冗余词根**（可选优化）：若插入词根 $r$ 的过程中途经某个已标记终结的节点，说明已有更短的词根是 $r$ 的前缀，$r$ 永远不会被任何人使用（任何以 $r$ 为前缀的单词都会先命中那个更短的），可以直接跳过。省的是空间，不改结果。
3. **命中立刻返回**，不要「先记下所有候选再取最小」。后者要额外存储与比较，且破坏了提前终止带来的实际加速。
4. **三种未命中的出口都要覆盖**：根节点无该字符、中途断链、走完全词仍非终结。漏掉第三种（例如只在循环里判断、循环外直接返回空前缀）会把 `"ab"` 变成 `""`。
5. **节点规模**：树节点数上界为 $1 + \sum_{r} \lvert r \rvert \le 1 + 1000 \times 100 = 100001$。C++ 每节点 $26 \times 4$ B $= 104$ B，约 10 MB，可以接受；若用 `vector<vector<int>>` 反复 `resize` 会触发大量拷贝，建议 `push_back` 一个预填 `-1` 的 `array`。
6. **切分方式**：C++ 用 `stringstream`，或手写双指针逐字符扫描（句子可能长达 $10^6$，双指针是 $O(n)$ 且不额外分配内存）；Python 直接 `sentence.split(' ')`。注意 `cin >> word` 与 `getline` 混用会残留换行，本地测试时容易多读出一个空词。
7. **字符下标**：题目保证小写字母，`c = ch - 'a'` 直接索引即可；稳妥起见仍可加 `if (c < 0 || c > 25) return w;` 防御，代价可以忽略。

## 5. 正确性证明

**引理 1（路径与词根一一对应）**：对任意串 $p$，从根出发沿 $p$ 的字符下降能走通，当且仅当 $p$ 的每个前缀都作为某个词根的前缀出现过；此时终点节点被标记为终结节点 $\iff p$ 本身是词典中的词根。

**证明**：对 $\lvert p \rvert$ 归纳。$p$ 为空时终点就是根节点，而词根长度 $\ge 1$，根永远不会被标记为终结节点，结论成立。设 $p = p' + c$：由归纳假设，走到 $p'$ 的终点等价于 $p'$ 的所有前缀都被覆盖；再走字符 $c$ 存在子节点，等价于存在词根以 $p' + c$ 为前缀；插入词根时恰在其末字符对应节点置终结标记，故终点终结 $\iff p$ 是词根。∎

**引理 2（首次命中即最短）**：若单词 $w$ 至少有一个前缀词根，设
$$k^{*} = \min\{\, \lvert r \rvert : r \in D,\ r \text{ 是 } w \text{ 的前缀} \,\},$$
则查询过程在下降 $k^{*}$ 步时首次遇到终结节点。

**证明**：设 $r$ 取得该最小值，则 $r = w[0..k^{*})$ 是词根，由引理 1，沿 $w$ 下降 $k^{*}$ 步到达的节点是终结节点，故第 $k^{*}$ 步会命中。另一方面，任何在第 $j$ 步命中的终结节点，由引理 1 都对应长度恰为 $j$ 的前缀词根，因此 $j \ge k^{*}$。两者合起来说明第一次命中的步数恰为 $k^{*}$。∎

**引理 3（未命中意味着不存在）**：若查询过程在某个字符处断链，或走完 $w$ 的全部字符仍未遇到终结节点，则 $w$ 没有任何前缀词根。

**证明**：断链发生在下降 $k$ 步之后、找不到 $w[k]$ 的子节点。若有词根 $r$ 是 $w$ 的前缀，则由引理 1 有 $\lvert r \rvert \le \lvert w \rvert$ 且沿 $w$ 前 $\lvert r \rvert$ 个字符可走通，特别地前 $k+1$ 个字符可走通，与断链矛盾。若走完全词未终结，则每个前缀对应的终点都非终结，由引理 1 每个前缀都不是词根。∎

**定理**：输出的句子与题意要求的替换结果逐词一致。

**证明**：任意单词 $w$ 分三种情况。若存在前缀词根，由引理 2 过程在 $k^{*}$ 步命中并返回 $w[0..k^{*})$，长度最小，符合「最短词根」；若断链或走完未终结，由引理 3 不存在前缀词根，过程返回 $w$ 本身，符合「保留原词」。所有单词处理正确，拼接按原顺序、用单空格分隔，句子的字符组成与顺序因此与题目要求完全一致。∎

## 6. 复杂度分析

- **时间**：建树 $O\!\left(\sum_{r \in D} \lvert r \rvert\right) \le 10^5$；每个单词的查询只沿路径走，步数不超过单词长度（命中后更早停止），合计 $O\!\left(\sum_{w} \lvert w \rvert\right) \le \lvert \text{sentence} \rvert \le 10^6$；切分与拼接各 $O(\lvert \text{sentence} \rvert)$。总时间 $O\!\left(\sum \lvert r \rvert + \lvert \text{sentence} \rvert\right)$，与「词典大小 × 单词数」无关。
- **空间**：Trie 节点数 $O\!\left(\sum \lvert r \rvert\right) \le 10^5$；C++ 定长 26 子表约 10 MB，Python 用 `dict` 只存实际存在的分支，节点更省。此外输出字符串 $O(\lvert \text{sentence} \rvert)$，切分出的单词列表同量级。

## 7. 参考代码

### C++

```cpp
#include <array>
#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    string replaceWords(vector<string>& dictionary, string sentence) {
        vector<array<int, 26>> nxt(1);
        vector<bool> isEnd(1, false);
        nxt[0].fill(-1);

        // 建树：相同前缀共享节点，重复词根自动合并
        for (const string& root : dictionary) {
            int cur = 0;
            for (char ch : root) {
                int c = ch - 'a';
                if (nxt[cur][c] == -1) {
                    nxt[cur][c] = (int)nxt.size();
                    array<int, 26> fresh;
                    fresh.fill(-1);
                    nxt.push_back(fresh);
                    isEnd.push_back(false);
                }
                cur = nxt[cur][c];
            }
            isEnd[cur] = true;
        }

        // 单个单词的查询：命中终结节点即刻返回前缀
        auto translate = [&](const string& w) -> string {
            int cur = 0;
            for (int i = 0; i < (int)w.size(); i++) {
                int c = w[i] - 'a';
                if (c < 0 || c > 25 || nxt[cur][c] == -1) return w;   // 断链
                cur = nxt[cur][c];
                if (isEnd[cur]) return w.substr(0, i + 1);            // 首次命中即最短
            }
            return w;                                                // 走完仍非终结
        };

        // 双指针切分，避免额外分配
        string res, word;
        bool first = true;
        for (int i = 0; i <= (int)sentence.size(); i++) {
            if (i == (int)sentence.size() || sentence[i] == ' ') {
                if (!first) res += ' ';
                res += translate(word);
                first = false;
                word.clear();
            } else {
                word += sentence[i];
            }
        }
        return res;
    }
};
```

### Python

```python
class Solution:
    def replaceWords(self, dictionary: list[str], sentence: str) -> str:
        # children[i] 是节点 i 的子节点表，is_end[i] 表示节点 i 结束一个词根
        children = [{}]
        is_end = [False]
        for root in dictionary:
            cur = 0
            for ch in root:
                nxt = children[cur].get(ch)
                if nxt is None:
                    nxt = len(children)
                    children[cur][ch] = nxt
                    children.append({})
                    is_end.append(False)
                cur = nxt
            is_end[cur] = True

        def translate(word: str) -> str:
            cur = 0
            for i, ch in enumerate(word):
                nxt = children[cur].get(ch)
                if nxt is None:
                    return word              # 断链：没有任何前缀词根
                cur = nxt
                if is_end[cur]:
                    return word[:i + 1]      # 首次命中终结节点 = 最短词根
            return word                      # 走完整词仍非终结：保留原词

        return ' '.join(translate(w) for w in sentence.split(' '))
```

## 8. 边界情况与易错点

1. **「最短」不是「最先命中词典」**：`dictionary = ["ab","a"]`、`sentence = "ab"` 必须输出 `"a"`。若用「按输入顺序取第一个匹配」会得到 `"ab"`，错。Trie 天然按长度递增命中，正好避开这个坑。
2. **单词短于所有词根**：`dictionary = ["abc"]`、`"ab"` → `"ab"`。走完 2 个字符仍未落到终结节点，属于「走完全词仍未终结」这一出口，必须返回原词，不能返回空串或前缀。
3. **词根等于整个单词**：`dictionary = ["a"]`、`"a"` → `"a"`（替换后相同，但必须是「命中后返回前缀」而不是走到循环外漏判）。
4. **根节点直接断链**：`"was"` 在 `{"cat","bat","rat"}` 下第一个字符就找不到，属于最常见的未命中情形，`nxt[0][c] == -1` 的判断要在取 `cur` 之前完成。
5. **重复词根 / 前缀词根**：`["cat","cat","ca","cat"]` 全部插入也不会出错（重复插入只是重复置 `isEnd`）；`"ca"` 与 `"cat"` 共存时，查询 `"cat"` 会在深度 2 提前命中 `"ca"`，这正是最短语义。
6. **输出空格**：必须用单个空格连接，且不能用 `" ".join` 之外的方式随手拼出前导/尾随空格；C++ 里用 `first` 标记避免行首空格。
7. **规模与内存**：$10^6$ 字符的句子不要 `+` 拼接时反复重新分配（`res` 建议预留），$10^5$ 节点不要为每个节点开 `vector` 扩容；Python 递归也不需要，查询是纯迭代，避免递归深度问题。
8. **不要为句子建 Trie**：只有词典需要建树，句子只需要逐词查询，否则空间直接爆炸。
