# LeetCode 连接所有点的最小费用 题解

## 1. 题目概述

- **标题 / 题号**：连接所有点的最小费用（#1584，medium）
- **链接**：https://leetcode.cn/problems/min-cost-to-connect-all-points/
- **来源**：LeetCode 第 206 场周赛 Q3
- **难度**：中等
- **标签**：图、贪心、最小生成树、Prim 算法、并查集

**题意**：给定平面上 $n$ 个点 `points[i] = [xi, yi]`，连接两点的费用是它们的**曼哈顿距离** $|x_i - x_j| + |y_i - y_j|$。要求把所有点连成一个整体，使得**任意两点之间有且仅有一条简单路径**，返回最小总费用。

**约束**：

- $1 \le \text{points.length} \le 1000$：任意两点的距离都要考虑，本质是完全图，最多 $\binom{1000}{2} \approx 5 \times 10^5$ 条候选边
- $-10^6 \le x_i, y_i \le 10^6$：单条边权最大 $4 \times 10^6$
- 所有点两两不同（不会有自环的干扰）

## 3. 解题思路

### 3.1 暴力思路：为什么不能枚举

朴素的切入点有两个，都走不通：

- **枚举边子集**：完全图约 $5 \times 10^5$ 条边，子集数 $2^{5 \times 10^5}$，天文数字。
- **枚举生成树**：先退一步观察到最优解是一棵树（见下），但 $n$ 个标号点的生成树个数是 $n^{n-2}$（Cayley 公式），$1000^{998}$ 同样无法枚举。

正确姿势是套用经典结论：**连通所有点、总边权最小、恰好 $n-1$ 条边**——这正是**最小生成树（MST）**的定义。剩下的问题只是选哪个 MST 算法。

### 3.2 核心观察：题面翻译过来就是 MST

![核心观察：题面说的其实是「最小生成树」](images/connect_points_mst_concept.svg)

把题面那句绕口的话拆开：

- "任意两点之间**有**一条简单路径" $\iff$ 图**连通**；
- "任意两点之间**仅有**一条简单路径" $\iff$ 图**无环**（若两点间有两条不同简单路径，拼起来是一个环）。

连通 + 无环 $\iff$ **树**，而 $n$ 个点的树**恰好有 $n-1$ 条边**。于是本题等价于：

> 在以曼哈顿距离为边权的完全图 $K_n$ 上，选 $n-1$ 条边使总和最小——**最小生成树**。

> 💡 曼哈顿距离非负、对称，作为边权完全合法（MST 算法只要求边权可比较）。完全图必然连通，MST 一定存在。

### 3.3 算法流程：朴素 Prim，O(n²) 连堆都不用

![Prim 算法流程：每轮摘「离树最近」的点](images/connect_points_prim_flow.svg)

$n \le 1000$ 的**完全图是稠密图**，最合适的是**朴素 Prim**（不用堆）：

1. 维护数组 $\text{dist}[v]$ = 未入树点 $v$ 到「已入树点集 $S$」的**最近边权**，即 $\min_{u \in S} w(u, v)$；初始任选起点（如 0 号）入树，$\text{dist}[v] = w(\text{起点}, v)$
2. 重复 $n-1$ 轮：在未入树点中取 $\text{dist}$ 最小的 $u$，将其入树，$\text{ans} \mathrel{+}= \text{dist}[u]$（这条横跨边就是 MST 的一条边）
3. 用新入树的 $u$ **松弛**所有未入树的 $v$：$\text{dist}[v] \leftarrow \min(\text{dist}[v],\ w(u, v))$，其中 $w$ 现场计算曼哈顿距离

> ⚠️ **最容易写错的地方**：Prim 的松弛是 $\min(\text{dist}[v], w(u,v))$（**单边比较**，把整棵树当源），**不是** Dijkstra 的 $\text{dist}[u] + w(u,v)$（多跳路径累加）。写错就成了"到起点的最短路"，完全偏离 MST。

### 3.4 示例演算

![示例 1 演算：Prim 四轮长出最小生成树](images/connect_points_walkthrough.svg)

对示例 1 的 5 个点从 P0 起 Prim（$\text{dist}$ 按下标 P0..P4 排列）：

| 轮次 | 入树点 | dist（入树前） | 选中的边 | 累计费用 |
|------|--------|----------------|----------|----------|
| 初始 | P0 | $[0, 4, 13, 7, 7]$ | — | 0 |
| ① | P1 | 最小为 4 | P0–P1 (4) | 4 |
| ② | P3 | 最小为 3（P1 入树后 7→3） | P1–P3 (3) | 7 |
| ③ | P4 | 最小为 4（P3 入树后 7→4） | P3–P4 (4) | 11 |
| ④ | P2 | 最小为 9（P1 入树后 13→9） | P1–P2 (9) | 20 |

P1 入树时松弛把 $\text{dist}[2]$ 从 13 压到 9（$|2-3|+|2-10|=9$）、$\text{dist}[3]$ 从 7 压到 3（$|2-5|+|2-2|=3$）；P3 入树时把 $\text{dist}[4]$ 从 7 压到 4。四轮后全部入树，答案 $20$。

## 4. 算法细节

1. **dist 的语义是"到点集 $S$ 的最近距离"**：每入树一个新点必须立刻松弛，否则下一轮比较的仍是"到旧树的距离"
2. **边权现算不存储**：$w(u,v) = |x_u - x_v| + |y_u - y_v|$ 每次 $O(1)$，完全图无需邻接表/邻接矩阵，空间 $O(n)$
3. **起点任选**：MST 与起点无关（证明见 §5，任意切分下贪心选边都安全），习惯取 0 号点
4. **找最小用线性扫**：$n \le 1000$ 的稠密图上，朴素 $O(n^2)$ 恰是最优——堆优化 Prim 是 $O(n^2 \log n)$，反而多一个 $\log$
5. **Kruskal 对比**：需显式建 $\binom{n}{2}$ 条边并排序，时间 $O(n^2 \log n)$、空间 $O(n^2)$，代码也不短；本题规模下能过（约 $10^7$），但朴素 Prim 全面更优
6. **累加用 long long（C++）**：单边最大 $4 \times 10^6$，$999$ 条边理论上可累加到 $4 \times 10^9$ 超过 `int`（实际数据中答案约 $O(L\sqrt{n})$ 量级不会溢出，但稳妥为上）

## 5. 正确性证明

**引理 1（树刻画）**：$n$ 点图 $G$ 中"任意两点之间有且仅有一条简单路径" $\iff$ $G$ 是树，且此时 $G$ 恰有 $n-1$ 条边。

**证明**：（⇒）任取两点存在路径故 $G$ 连通；若 $G$ 含环，环上任两点间有两条不同简单路径，与"仅有"矛盾，故无环。无环连通即树，由树的基本定理恰有 $n-1$ 条边。（⇐）树连通保证任意两点间存在路径；若某两点间有两条不同简单路径，两者的对称差非空且每个顶点度数偶数，可从中提取出一个环，与树无环矛盾。∎

由引理 1，本题合法解恰为生成树，所求即最小生成树的总权。

**引理 2（切分定理）**：设 $S$ 是点集 $V$ 的非空真子集（切分），$e$ 是横跨 $(S, V \setminus S)$ 的边中**权最小**者，则存在一棵 MST 包含 $e$。

**证明**：完全图连通，生成树存在，取任一 MST $T$。若 $e \in T$ 即证。否则把 $e$ 加入 $T$，得到唯一的环 $C$。$e$ 横跨切分，环 $C$ 要回到起点必须再穿过切分奇数次，故 $C$ 上除 $e$ 外至少还有一条横跨边 $e'$。令 $T' = T + e - e'$：去掉环上一条边仍保持连通，边数仍为 $n-1$，故 $T'$ 是生成树。由 $e$ 的最小性 $w(e) \le w(e')$，故 $w(T') \le w(T)$，即 $T'$ 也是 MST 且包含 $e$。∎

**定理（Prim 正确性）**：Prim 算法输出的边集是一棵最小生成树。

**证明**：对轮数归纳，维护不变式：**存在一棵 MST $T$ 包含算法已选的全部边**。

- **初始**：已选边集 $E_0 = \emptyset$，任一 MST 满足。
- **归纳步**：设已选 $E_k$ 连成含起点的分量 $S$（Prim 每轮并入一个新点，$E_k$ 始终是 $S$ 上的一棵树），存在 MST $T \supseteq E_k$。本轮算法选择 $\text{dist}$ 最小的未入树点 $v^*$ 及对应边 $e = (u, v^*)$。由 $\text{dist}[v] = \min_{u' \in S} w(u', v)$，有 $w(e) = \min_{v \notin S} \text{dist}[v] = \min\{w(u',v) : u' \in S, v \notin S\}$，即 $e$ 是横跨切分 $(S, V \setminus S)$ 的最小权边。由引理 2，存在 MST $T' \supseteq E_k \cup \{e\}$，不变式保持。
- **终止**：算法恰执行 $n-1$ 轮。每轮并入的点原先不属于 $S$，新边是横跨边而非 $S$ 内部的边，故永远不会成环；结束时 $n$ 个点、$n-1$ 条边、连通无环，得到生成树 $T^*$。$T^*$ 被某棵 MST 包含，而 $T^*$ 已含 $n-1$ 条边，只能与该 MST 相等。故 $T^*$ 是 MST，其总权即最小总费用。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n^2)$。外层 $n$ 轮，每轮"线性找最小" $O(n)$ + "松弛" $O(n)$（曼哈顿距离 $O(1)$ 现算）。$n = 1000$ 时约 $2 \times 10^6$ 次基本操作，轻松通过。
- **空间复杂度**：$O(n)$。仅 `dist` 数组与入树标记两个长度 $n$ 的数组，边不显式存储。
- **对比 Kruskal**：时间 $O(n^2 \log n)$（排序 $5 \times 10^5$ 条边），空间 $O(n^2)$（显式存边），约为朴素 Prim 的 20 倍耗时与 500 倍空间。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minCostConnectPoints(vector<vector<int>>& points) {
        int n = points.size();
        vector<int> dist(n, INT_MAX);
        vector<bool> inTree(n, false);
        dist[0] = 0;
        long long ans = 0;
        for (int i = 0; i < n; ++i) {
            int u = -1;
            for (int v = 0; v < n; ++v)
                if (!inTree[v] && (u == -1 || dist[v] < dist[u]))
                    u = v;
            inTree[u] = true;
            ans += dist[u];
            for (int v = 0; v < n; ++v)
                if (!inTree[v]) {
                    int w = abs(points[u][0] - points[v][0])
                          + abs(points[u][1] - points[v][1]);
                    dist[v] = min(dist[v], w);
                }
        }
        return (int)ans;
    }
};
```

备选：Kruskal（建全部边 + 排序 + 并查集），$O(n^2 \log n)$，本题也能过：

```cpp
class Solution {
public:
    vector<int> fa;
    int find(int x) { return fa[x] == x ? x : fa[x] = find(fa[x]); }
    int minCostConnectPoints(vector<vector<int>>& points) {
        int n = points.size();
        fa.resize(n);
        iota(fa.begin(), fa.end(), 0);
        vector<array<int, 3>> edges;  // {w, u, v}
        for (int i = 0; i < n; ++i)
            for (int j = i + 1; j < n; ++j) {
                int w = abs(points[i][0] - points[j][0])
                      + abs(points[i][1] - points[j][1]);
                edges.push_back({w, i, j});
            }
        sort(edges.begin(), edges.end());
        long long ans = 0;
        int cnt = 0;
        for (auto& e : edges) {
            int a = find(e[1]), b = find(e[2]);
            if (a != b) {
                fa[a] = b;
                ans += e[0];
                if (++cnt == n - 1) break;
            }
        }
        return (int)ans;
    }
};
```

### Python

```python
class Solution:
    def minCostConnectPoints(self, points: List[List[int]]) -> int:
        n = len(points)
        dist = [inf] * n
        in_tree = [False] * n
        dist[0] = 0
        ans = 0
        for _ in range(n):
            u = -1
            for v in range(n):
                if not in_tree[v] and (u == -1 or dist[v] < dist[u]):
                    u = v
            in_tree[u] = True
            ans += dist[u]
            ux, uy = points[u]
            for v in range(n):
                if not in_tree[v]:
                    d = abs(ux - points[v][0]) + abs(uy - points[v][1])
                    if d < dist[v]:
                        dist[v] = d
        return ans
```

## 8. 边界情况与易错点

1. **单点（示例 5）**：答案 0。代码里 `dist[0] = 0`，第一轮摘起点累加 0，自然处理，无需特判——但前提是初始化正确
2. **两点（示例 4）**：只有一条边，答案即两点距离；注意坐标可负，距离必须用 `abs`
3. **松弛写成 Dijkstra 形式**：`dist[v] = dist[u] + w` 是最常见笔误，求出的是"最短路生成树"而非 MST，小数据可能碰巧一样、大数据必错
4. **忘记松弛 / 只在入树时算一次 dist**：`dist` 必须随 $S$ 的扩张持续更新，否则选边不是横跨最小边，贪心失效
5. **找最小时漏了"未入树"过滤**：已入树点 `dist` 可能更小，会被重复选中导致死循环或错误累加
6. **溢出**：C++ 用 `int` 累加在极端构型下可能超过 $2^{31}-1$（999 条边 × $4\times10^6$），稳妥用 `long long` 存累加值再返回
7. **`INT_MAX` 作初始值的安全性**：本算法只做比较不做 `dist[u] + w` 累加，不会加爆；若写 Dijkstra 风格需换成足够大的 `long long` 无穷
8. **不必建图**：完全图边数 $5 \times 10^5$，建显式邻接结构纯属浪费；现场 `abs` 计算即可
