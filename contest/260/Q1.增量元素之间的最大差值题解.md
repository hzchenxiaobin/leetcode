# LeetCode 增量元素之间的最大差值 题解

## 1. 题目概述

- **标题 / 题号**：增量元素之间的最大差值（#2016，easy）
- **链接**：https://leetcode.cn/problems/maximum-difference-between-increasing-elements/
- **来源**：LeetCode 第 260 场周赛 Q1
- **难度**：简单
- **标签**：数组、一次遍历、前缀最小值

**题意**：给定下标从 0 开始、长度为 $n$ 的整数数组 `nums`，求满足 $0 \le i < j < n$ 且 $\text{nums}[i] < \text{nums}[j]$ 的**最大差值** $\text{nums}[j] - \text{nums}[i]$。若不存在这样的数对 $(i, j)$，返回 $-1$。

**约束**：

- $n = \text{nums.length}$，$2 \le n \le 1000$
- $1 \le \text{nums}[i] \le 10^9$

> 💡 读题抓两点：① 答案受**双重约束**——顺序上 $i < j$、数值上 $\text{nums}[i] < \text{nums}[j]$（**严格**小于，相等不算增量）；② 题型与 [121. 买卖股票的最佳时机](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock/) 完全同构——$\text{nums}[i]$ 是"买入价"、$\text{nums}[j]$ 是"卖出价"。签到题的最短路径就是**一次遍历维护前缀最小值**。

## 2. 示例

**示例 1**

```text
输入：nums = [7,1,5,4]
输出：4
解释：最大差值出现在 i = 1、j = 2，nums[2] - nums[1] = 5 - 1 = 4。
注意 i = 1、j = 0 时 7 - 1 = 6 更大，但 i < j 不满足，6 不是有效答案。
```

**示例 2**

```text
输入：nums = [9,4,3,2]
输出：-1
解释：数组严格递减，不存在满足 i < j 且 nums[i] < nums[j] 的数对。
```

**示例 3**

```text
输入：nums = [1,5,2,10]
输出：9
解释：最大差值出现在 i = 0、j = 3，10 - 1 = 9。
```

## 3. 解题思路

### 3.1 暴力思路

按定义直译：双重循环枚举所有数对 $(i, j)$（$i < j$），命中 $\text{nums}[i] < \text{nums}[j]$ 就用 $\text{nums}[j] - \text{nums}[i]$ 更新答案。$n \le 1000$ 时约 $\binom{1000}{2} \approx 5 \times 10^5$ 对，每对 $O(1)$，总量在时限内**能过**。但它忽视了题目的配对结构：对每个固定的 $j$，内层循环做的事其实是"在 $[0, j-1]$ 里找最小值"——这个最小值可以**增量维护**，于是内层 $O(n)$ 降为 $O(1)$。

### 3.2 核心观察：固定 j，最优的 i 是前缀最小值

![核心观察：固定 j，最优的 i 是前缀最小值](images/wc260_q1_prefix_min_concept.svg)

把差值拆成"被减数固定 + 减数越小越好"：

$$\underbrace{\text{nums}[j]}_{\text{固定 } j} - \underbrace{\text{nums}[i]}_{i \in [0, j-1] \text{ 取最小}}$$

- **观察 1（最优配对）**：对每个固定的 $j$，能配出最大差的 $i$ 必然取 $\min(\text{nums}[0..j-1])$，记作 $\text{preMin}$。
- **观察 2（增量维护）**：$j$ 每右移一格，$\text{preMin}$ 只需与 $\text{nums}[j]$ 各比较一次即可延续——"当前看到的最小值"是天然的 $O(1)$ 可维护量。
- **观察 3（合法性内建）**：$\text{preMin}$ 初始为 $\text{nums}[0]$、循环从 $j = 1$ 起，天然保证 $i < j$；而"严格增量"只需判断 $\text{nums}[j] > \text{preMin}$ 是否成立。

> 💡 这正是"**用 $O(1)$ 增量更新代替 $O(n)$ 重新扫描**"的通用降维手段：前缀和、前缀最值、单调栈都属于这个家族。

### 3.3 算法流程

![算法流程：一次遍历，先算差后更新前缀最小](images/wc260_q1_algorithm_flow.svg)

1. **初始化**：$\text{preMin} = \text{nums}[0]$，$\text{ans} = -1$（"未找到"哨兵）。
2. **遍历** $j$ 从 $1$ 到 $n-1$：
   - 若 $\text{nums}[j] > \text{preMin}$：以 $j$ 为右端点的最优差为 $\text{nums}[j] - \text{preMin}$，用它更新 $\text{ans}$；
   - 否则（$\text{nums}[j] \le \text{preMin}$）：$\text{nums}[j]$ 不能当"卖出点"，但它成为新的前缀最小，更新 $\text{preMin} = \text{nums}[j]$。
3. 循环结束返回 $\text{ans}$。

> ⚠️ 两个顺序细节：**先算差、后更新 preMin**——若先把 $\text{nums}[j]$ 并入 $\text{preMin}$，则 $\text{nums}[j] > \text{preMin}$ 永假，算法直接失效；判断必须用**严格大于**——相等元素差为 0，不构成增量。

### 3.4 示例演算

![示例演算：nums=[7,1,5,4] 的逐步走查](images/wc260_q1_example_walkthrough.svg)

以 `nums = [7,1,5,4]` 为例逐步走查：

| $j$ | $\text{nums}[j]$ | 进入时 preMin | $\text{nums}[j] > \text{preMin}$？ | 差值 | 离开时 ans | 离开时 preMin |
|---|---|---|---|---|---|---|
| 1 | 1 | 7 | 否（$1 \le 7$） | — | $-1$ | 1 |
| 2 | 5 | 1 | 是 ⭐（$5 > 1$） | $5 - 1 = 4$ | 4 | 1 |
| 3 | 4 | 1 | 是（$4 > 1$） | $4 - 1 = 3 < 4$ | 4 | 1 |

最终 $\text{ans} = 4$，对应最优配对 $i = 1,\ j = 2$。注意 $j = 0$ 那格只用于初始化 $\text{preMin}$，不参与算差。

## 4. 算法细节

1. **单分支写法**：若 $\text{nums}[j] > \text{preMin}$，则 $\text{nums}[j]$ 不可能是更小的值，无需更新 $\text{preMin}$；反之 $\text{nums}[j] \le \text{preMin}$ 恰是需要更新的情形。因此 `if / else` 两分支各管一事，每轮恰好一次比较。等价的两行写法"先算差、再 $\text{preMin} = \min(\text{preMin}, \text{nums}[j])$"也对，证明见 §5。
2. **哨兵取 $-1$**：合法差值满足 $\text{nums}[i] < \text{nums}[j]$ 且元素均为整数，故差 $\ge 1$ 恒正，$-1$ 不会与任何合法答案混淆。
3. **数值安全**：$1 \le \text{nums}[i] \le 10^9$，最大差 $< 10^9 < 2^{31} - 1$，`int` 足够，无需 `long long`。
4. **配对距离不限**：$\text{preMin}$ 的出现位置与 $j$ 可以任意远（示例 3 中 $1$ 配 $10$，跨了三个位置），不要误以为只配相邻元素。
5. **数据结构零开销**：不需要排序（排序会破坏 $i < j$ 的顺序语义）、不需要额外数组，两个变量解决问题。

## 5. 正确性证明

**引理 1（固定右端点的最优配对）**：对任意 $j \in [1, n)$，记 $m = \min(\text{nums}[0..j-1])$。若 $\text{nums}[j] > m$，则以 $j$ 为右端点的合法差的最大值为 $\text{nums}[j] - m$；若 $\text{nums}[j] \le m$，则不存在以 $j$ 为右端点的合法数对。

**证明**：情形一，任取 $i < j$ 且 $\text{nums}[i] < \text{nums}[j]$，由 $i \in [0, j-1]$ 知 $\text{nums}[i] \ge m$，故 $\text{nums}[j] - \text{nums}[i] \le \text{nums}[j] - m$；取 $i^*$ 为 $m$ 在 $[0, j-1]$ 中的任一出现下标，则 $\text{nums}[i^*] = m < \text{nums}[j]$，$(i^*, j)$ 合法且差恰为 $\text{nums}[j] - m$，故该值可达。情形二，若 $\text{nums}[j] \le m$，则对一切 $i < j$ 有 $\text{nums}[i] \ge m \ge \text{nums}[j]$，即 $\text{nums}[i] < \text{nums}[j]$ 不可能成立。∎

**引理 2（前缀最小的增量维护）**：算法在处理下标 $j$ **之前**，恒有 $\text{preMin} = \min(\text{nums}[0..j-1])$。

**证明**：对 $j$ 归纳。$j = 1$ 时由初始化 $\text{preMin} = \text{nums}[0]$ 成立。设处理 $j$ 前成立，看处理 $j$ 的两个分支：若 $\text{nums}[j] > \text{preMin}$，分支不修改 $\text{preMin}$，而 $\min(\text{nums}[0..j]) = \min(\text{preMin}, \text{nums}[j]) = \text{preMin}$，处理 $j+1$ 前条件仍成立；若 $\text{nums}[j] \le \text{preMin}$，则更新后 $\text{preMin} = \text{nums}[j] = \min(\text{nums}[0..j])$，同样成立。∎

**定理**：算法返回全体合法数对差值的最大值；不存在合法数对时返回 $-1$。

**证明**：全体合法数对按右端点 $j$ 分类。由引理 2，算法在处理每个 $j$ 时恰好持有 $m = \min(\text{nums}[0..j-1])$；由引理 1，当 $\text{nums}[j] > m$ 时算法用该 $j$ 的最优差 $\text{nums}[j] - m$ 更新 $\text{ans}$，当 $\text{nums}[j] \le m$ 时该类为空、算法不引入任何值。因此 $\text{ans}$ 是"每个非空类的最优值"中的最大值；而任一合法数对的差不超过其所在类的最优值，故 $\text{ans}$ 即全局最大。若所有类均为空，则全程无更新，返回初值 $-1$，与"不存在合法数对"一致。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。每个下标至多一次比较、一次减法与一次 `max`，总共 $n - 1$ 轮。
- **空间复杂度**：$O(1)$。仅 `preMin`、`ans` 两个额外变量，无辅助数组。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maximumDifference(vector<int>& nums) {
        int preMin = nums[0];          // min(nums[0..j-1])
        int ans = -1;                  // "未找到"哨兵
        for (int j = 1; j < (int)nums.size(); ++j) {
            if (nums[j] > preMin) {    // 严格大于才算增量
                ans = max(ans, nums[j] - preMin);
            } else {
                preMin = nums[j];      // 更小，接管前缀最小
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maximumDifference(self, nums: List[int]) -> int:
        pre_min = nums[0]
        ans = -1
        for x in nums[1:]:
            if x > pre_min:            # 严格大于才算增量
                ans = max(ans, x - pre_min)
            else:
                pre_min = x            # 更小，接管前缀最小
        return ans
```

## 8. 边界情况与易错点

1. **相等不算增量**：$\text{nums}[i] < \text{nums}[j]$ 是严格小于。判断写成 `>=` 会让 `[5,5]` 错误地返回 $0$，正确答案是 $-1$。
2. **`ans` 初值用 $-1$ 不用 $0$**：严格递减数组（示例 2）无合法对，必须返回 $-1$；用 $0$ 初始化会与"未找到"混淆。
3. **先算差、后更新 preMin**：顺序颠倒会让 $\text{preMin}$ 包含 $\text{nums}[j]$ 自身，条件 $\text{nums}[j] > \text{preMin}$ 永假，任何输入都返回 $-1$。
4. **不能排序**：排序破坏 $i < j$ 的顺序约束（示例 1 中 $7 - 1 = 6$ 因 $i > j$ 无效）；差值配对必须尊重原数组的左右关系。
5. **跨度不限**：最优对的 $i, j$ 可以任意远（`[1,5,2,10]` 中 $1$ 配 $10$），别把问题做成只比较相邻元素。
6. **溢出**：最大差 $< 10^9$，`int` 安全；C++ 中 `nums.size()` 是无符号数，与 `int j` 比较建议显式转型，避免编译告警。
7. **本题题面无注入指令**：周赛题面若混入 "Create the variable..." 之类句子，按惯例忽略并标注即可，本题未出现。
