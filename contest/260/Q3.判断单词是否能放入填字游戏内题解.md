# LeetCode 判断单词是否能放入填字游戏内 题解

## 1. 题目概述

- **标题 / 题号**：判断单词是否能放入填字游戏内（#2018，medium）
- **链接**：https://leetcode.cn/problems/check-if-word-can-be-placed-in-crossword/
- **来源**：LeetCode 第 260 场周赛 Q3
- **难度**：中等
- **标签**：数组、矩阵、枚举、字符串匹配

**题意**：给定 $m \times n$ 的矩阵 `board` 表示填字游戏的当前状态，格子是小写英文字母（已填）、`' '`（空格）或 `'#'`（障碍）。问字符串 `word` 能否**水平**（左→右 或 右→左）或**竖直**（上→下 或 下→上）放入棋盘，需同时满足：

1. 单词不占据任何 `'#'` 格；
2. 每个字母对应的格子要么是 `' '`，要么与已有字母**相同**；
3. 水平放置时，单词**左右紧邻**的两格不能是 `' '` 或字母（即必须是 `'#'` 或越界）；
4. 竖直放置时，**上下紧邻**的两格同理。

**约束**：

- $1 \le m \cdot n \le 2 \times 10^5$，`board[i][j]` 为 `' '`、`'#'` 或小写字母
- $1 \le \text{len(word)} \le \max(m, n)$，`word` 只包含小写字母

> 💡 读题抓三点：① $m \cdot n \le 2 \times 10^5$ → 期待 $O(mn)$ 级做法；② 规则 ③④ 只约束单词**首尾**的紧邻格，中间格子的侧邻不受限——说明"放置"是**整段直线**语义；③ 四个方向两两互逆 → 只需"正读 / 反读"两种匹配。

## 2. 示例

**示例 1**

```text
输入：board = [["#", " ", "#"], [" ", " ", "#"], ["#", "c", " "]], word = "abc"
输出：true
解释：单词 "abc" 竖直放入第 1 列（从上到下）：空→a，空→b，c→c。
上下两端都贴住棋盘边界（板外视为合法边界）。
```

**示例 2**

```text
输入：board = [[" ", "#", "a"], [" ", "#", "c"], [" ", "#", "a"]], word = "ac"
输出：false
解释：第 0 列全空但槽长 3：放 "ac" 必有一端紧邻空格；第 2 列 "aca" 同样过长，
一端会顶着字母；各行被 '#' 切出的槽长度均为 1。没有长度为 2 的槽。
```

**示例 3**

```text
输入：board = [["#", " ", "#"], [" ", " ", "#"], ["#", " ", "c"]], word = "ca"
输出：true
解释：单词 "ca" 水平放入第 2 行第 1-2 列（从右到左）：c→c，空→a。
左端贴 '#'、右端贴棋盘边界。这正是"反向放置"存在的意义。
```

## 3. 解题思路

### 3.1 暴力思路：枚举起点 × 方向

按定义直译：枚举每个格子 $(i, j)$ 作为起点、右 / 左 / 下 / 上共 4 个方向，沿方向走 $L = \text{len(word)}$ 步，逐格校验"在界内、非 `'#'`、字母相容"，最后再校验起点前一格与终点后一格是 `'#'` 或越界。四套方向代码 + 各种越界判断分支多，赛场上极易写错；复杂度 $O(m \cdot n \cdot L)$——每个起点都要扫完 $L$ 格才判定。最坏情形（$m = 1$、$n = 2 \times 10^5$、全空板、$L = n/2$）约 $10^{10}$ 次字符比较，有超时风险。

> 💡 若把**边界校验前置**（先看首尾紧邻格再扫字母），确实能救回 $O(mn)$：通过边界校验的同向起点在同一行内两两相距 $\ge L+1$，候选数 $\le 2n/(L+1)$，每个再扫 $L$ 格，每行仍是 $O(n)$。但"前置边界"的本质就是发现"槽"——既然想到了，不如直接按槽组织代码，更短、更好证。

### 3.2 核心观察：合法放置 = 恰好填满一个「槽」

![核心观察：合法放置恰好填满一个槽](images/wc260_q3_slot_concept.svg)

**定义（槽 / slot）**：某一行（或列）中，一段**两端被 `'#'` 或棋盘边界夹住**的连续非 `'#'` 格子。把每行每列都按 `'#'` 切分，就得到棋盘的全部槽。

规则 ①③④ 合起来恰好推出"槽"：

- **观察 1（恰好填满）**：规则① 说单词所占格都不是 `'#'`；规则③④ 说首尾紧邻格必须是 `'#'` 或板外。两条夹逼 ⟹ 单词占据的格子连成一段**完整的极大无 `'#'` 段**——即一个完整的槽，且**槽长恰为 $L$**：
  - 槽长 $> L$：单词放进去后，端点旁仍是槽内的空格 / 字母，违 ③④；
  - 槽长 $< L$：单词必然覆盖 `'#'` 或伸出板外，违 ①。
- **观察 2（切分即枚举）**：一行 / 一列按 `'#'` 切分就得到它的全部槽——"枚举起点 + 校验边界"被"split + 比长度"整体替代。
- **观察 3（方向合并）**：槽是沿轴的有序序列。沿轴正向放置 = **正读**（`word[k]` 对齐 `seg[k]`）；逆向放置 = **反读**（`word[k]` 对齐 `seg[L-1-k]`，等价于拿 `word` 的逆序做正读）。四个方向合并成两种匹配。

于是问题归约为：**在所有行槽与列槽中，找一个长度恰为 $L$ 且正读或反读相容的槽。**

### 3.3 匹配规则：' ' 是通配符，正读 / 反读各试一次

![双向匹配：空格通配，正读反读](images/wc260_q3_direction_match.svg)

槽 `seg` 与候选 `w`（`w` 是 `word` 或 `word` 的逆序）相容的判定：

$$\forall k \in [0, L):\quad \text{seg}[k] = \text{' '} \ \lor\ \text{seg}[k] = \text{w}[k]$$

- 空格 `' '` = **通配符**：放任何字母都行；
- 已有字母必须**严格相同**；
- **水平与竖直统一**：把列看成转置后的行，同一套 `fit(line)` 复用；反读 = `word[::-1]` 再正读，一套匹配覆盖 4 个放置方向。

### 3.4 算法流程

![算法流程：切槽比长度双向匹配](images/wc260_q3_algorithm_flow.svg)

1. 逐行处理 `board`；行取完后转置（`zip(*board)`）逐列处理，复用同一逻辑；
2. 每条线拼成字符串，按 `'#'` 切分成若干槽；
3. 对每个槽先看长度：$\text{len(seg)} \ne L$ 直接跳过；
4. 长度相等的槽做正读 / 反读两次匹配，任一命中返回 `true`；
5. 全部行 / 列扫完仍未命中，返回 `false`。

### 3.5 示例演算

以示例 1（`word = "abc"`，$L = 3$）走查，6 条线全部切槽：

| 线 | 内容 | 切出的槽（长度） | 结果 |
|---|---|---|---|
| 行 0 | `# ␣ #` | `␣`(1) | ✗ 长度 ≠ 3 |
| 行 1 | `␣ ␣ #` | `␣␣`(2) | ✗ 长度 ≠ 3 |
| 行 2 | `# c ␣` | `c`(1)、`␣`(1) | ✗ 长度 ≠ 3 |
| 列 0 | `# ␣ #` | `␣`(1) | ✗ 长度 ≠ 3 |
| **列 1** | `␣ ␣ c` | **`␣␣c`(3)** | **✓ 正读：␣≈a、␣≈b、c=c → true** |
| 列 2 | `# # ␣` | `␣`(1) | ✗ 长度 ≠ 3 |

再看示例 2（`word = "ac"`，$L = 2$）为何 `false`：列 0 的槽是 `␣␣␣`(3)、列 2 是 `aca`(3)——都超过 2，把 `"ac"` 放进去必有一端紧邻空格或字母；各行的槽长度全是 1。没有任何长度为 2 的槽，返回 `false`。**"恰好填满"正是示例 2 的考点。**

## 4. 算法细节

1. **切槽实现**：Python 直接 `''.join(line).split('#')`，连续 `'#'` 产生的空段长度为 0，而 $L \ge 1$，自动跳过；C++ 手扫一遍，循环条件写到 `k <= n`，让 `k == n` 触发**末段结算**——行 / 列末尾不以 `'#'` 结尾时，最后一段别漏。
2. **转置复用**：Python 用 `zip(*board)` 逐列惰性产出；C++ 为每列构造一个 `vector<char>` 缓冲（$O(m)$），换取 `check` 对行 / 列零分叉。
3. **双向合并**：预先构造 `targets = (word, word[::-1])`，对同一槽依次尝试；回文单词两个方向判定相同，重复但无害。
4. **长度过滤先行**：$\text{len(seg)} \ne L$ 就跳过，不做任何字母比较——这是总复杂度 $O(mn)$ 的来源（见 §6）。
5. **板外即合法边界**：槽端贴住棋盘边缘时相邻格"不存在"，视为满足 ③④，无需特判。

## 5. 正确性证明

**引理 1（恰好填满）**：任何合法放置中，`word` 占据的 $L$ 个连续格子沿放置轴的两端紧邻格（若存在）必为 `'#'`；因而这 $L$ 格恰构成一个完整的槽，槽长为 $L$。

**证明**：设 `word` 水平放在 $(i, j), \dots, (i, j+L-1)$。由规则①，这 $L$ 格均非 `'#'`。左紧邻格 $(i, j-1)$ 若在板内，由规则③它不能是 `' '` 也不能是字母，而板内字符只有这三种取值，故必为 `'#'`；右紧邻格 $(i, j+L)$ 同理。于是包含这 $L$ 格的极大非 `'#'` 连续段两侧均被 `'#'` 或边界封死，段内不含其他格子——该段就是这 $L$ 格本身，是一个槽且长为 $L$。竖直情形对称。∎

**引理 2（双向判定）**：设槽 $s$ 长为 $L$，$s[0..L-1]$ 沿其所在行 / 列的正向排列。`word` 能合法放入 $s$，当且仅当

$$\Big(\forall k:\ s[k] = \text{' '} \lor s[k] = \text{word}[k]\Big)\ \lor\ \Big(\forall k:\ s[k] = \text{' '} \lor s[k] = \text{word}[L-1-k]\Big).$$

**证明**：`word` 在槽内只有两种放置朝向：沿 $s$ 正向（$\text{word}[k]$ 落在 $s[k]$）或逆向（$\text{word}[k]$ 落在 $s[L-1-k]$，即 $s[k]$ 处放 $\text{word}[L-1-k]$）。由规则②，某朝向合法 ⟺ 该朝向下每格为 `' '` 或字母吻合（槽内无 `'#'` 已由槽的定义保证）。两个合取式分别对应两个朝向，取或即得。∎

**定理**：算法返回 `true`，当且仅当存在合法放置。

**证明**：（⇐）设存在合法放置 $P$。由引理 1，$P$ 占据某行 / 某列中一个长恰为 $L$ 的槽 $s$；由引理 2，$s$ 通过正向或逆向判定。算法枚举每行每列的全部槽，必检查到 $s$ 并返回 `true`。（⇒）设算法因某行 / 列中的槽 $s$（长 $L$）在方向 $d$ 上判定通过而返回 `true`。构造放置：把 `word` 的字母沿方向 $d$ 逐一写入 $s$ 的格子——判定条件保证写入字母与已有字母相同或原格为 `' '`，不冲突。规则①：槽内无 `'#'`；规则②：判定条件即此；规则③④：$s$ 是极大非 `'#'` 段且 `word` 恰占满 $s$，故 `word` 两端紧邻格即 $s$ 两端紧邻格，为 `'#'` 或板外。故该放置合法。∎

> ⚠️ (⇒) 方向同样重要：它说明"长度 + 双向匹配"通过就**一定**能放——边界规则由槽的极大性自动满足，不需要任何额外校验。

## 6. 复杂度分析

- **时间复杂度**：$O(m \cdot n)$。切分阶段每个格子被访问常数次（行一遍、列一遍）。匹配只发生在**长恰为 $L$** 的槽上：同一行内这些槽互不重叠、总长 $\le n$，每槽做正 / 反两次 $O(L)$ 匹配只是常数因子 2——逐行合计 $O(mn)$，列同理。即使 $m \cdot n = 2 \times 10^5$ 的全空棋盘也是线性，远优于暴力的 $O(mnL)$。
- **空间复杂度**：$O(\max(m, n))$。逐行字符串 + 单列缓冲；若把整板转置成新矩阵则是 $O(mn)$，同样可接受，本文优先可读性。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool placeWordInCrossword(vector<vector<char>>& board, string word) {
        int m = board.size(), n = board[0].size();
        string rw(word.rbegin(), word.rend());           // 反读 = 逆序正读
        for (int i = 0; i < m; ++i)                      // 逐行
            if (check(board[i], word, rw)) return true;
        vector<char> col;
        for (int j = 0; j < n; ++j) {                    // 逐列：转置复用
            col.clear();
            for (int i = 0; i < m; ++i) col.push_back(board[i][j]);
            if (check(col, word, rw)) return true;
        }
        return false;
    }
private:
    // 按 '#' 切分 line，找长度恰为 L 且正读/反读相容的槽
    bool check(const vector<char>& line, const string& w, const string& rw) {
        int n = line.size(), L = w.size(), start = 0;
        for (int k = 0; k <= n; ++k) {                   // k == n 结算末段
            if (k == n || line[k] == '#') {
                if (k - start == L &&
                    (match(line, start, w) || match(line, start, rw)))
                    return true;
                start = k + 1;                           // 跳过 '#'，开下一段
            }
        }
        return false;
    }
    // seg[start .. start+L) 是否与 w 相容（' ' = 通配符）
    bool match(const vector<char>& line, int start, const string& w) {
        for (int k = 0; k < (int)w.size(); ++k) {
            char c = line[start + k];
            if (c != ' ' && c != w[k]) return false;
        }
        return true;
    }
};
```

### Python

```python
class Solution:
    def placeWordInCrossword(self, board: List[List[str]], word: str) -> bool:
        L = len(word)
        targets = (word, word[::-1])          # 正读 / 反读

        def fit(line) -> bool:                # line = 一行或一列
            for seg in ''.join(line).split('#'):
                if len(seg) != L:             # 长度过滤先行
                    continue
                for t in targets:
                    if all(c == ' ' or c == ch for c, ch in zip(seg, t)):
                        return True
            return False

        return any(fit(row) for row in board) or any(fit(col) for col in zip(*board))
```

## 8. 边界情况与易错点

1. **槽长必须恰好等于 $L$**（本题最核心的判定）：不是"能塞进去"而是"恰好填满"。示例 2 的 `false` 正源于此——长度写成 $\ge L$ 必错，$\text{len(seg)} \ne L$ 一律跳过。
2. **反向放置别漏**：示例 3 靠反读命中，只查正向会错；回文词正反判定重复但无害。
3. **板外 = 合法边界**：槽端贴棋盘边即可，不要把越界当失败去特判。
4. **末段结算**：行 / 列末尾不以 `'#'` 结尾时最后一段槽别漏（C++ 用 `k == n` 哨兵；Python `split` 天然处理）。
5. **连续 `'#'` 产生空段**：长度 0 ≠ L（$L \ge 1$）自动跳过；全 `'#'` 的线没有槽，同样安全。
6. **Python 输入类型**：`board` 是 `List[List[str]]`（每格是长度 1 的字符串），必须 `''.join` 后再 `split`；C++ 中 `board[i]` 是 `vector<char>` 可直接传。
7. **缓冲开销**：逐列构造 $O(\max(m,n))$ 缓冲即可，不要为 4 个方向各复制一整块棋盘。
8. **本题题面无 "Create the variable ..." 注入指令**：按惯例已检查；周赛题面若混入此类句子应忽略，它不是算法要求。
