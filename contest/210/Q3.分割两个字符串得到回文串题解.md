# LeetCode 分割两个字符串得到回文串 题解

## 1. 题目概述

- **标题 / 题号**：分割两个字符串得到回文串（#1616，medium）
- **链接**：https://leetcode.cn/problems/split-two-strings-to-make-palindrome/
- **来源**：LeetCode 第 210 场周赛 Q3
- **难度**：中等
- **标签**：双指针、字符串、回文

**题意**：给两个**等长**的小写字符串 $a$、$b$（长度 $n$）。选择一个下标 $i \in [0, n]$，把两个字符串在**同一位置**切开：$a = a_{prefix} + a_{suffix}$，$b = b_{prefix} + b_{suffix}$。判断 $a_{prefix} + b_{suffix}$ 或者 $b_{prefix} + a_{suffix}$ 能否拼成一个**回文串**。注意 $i$ 可以取 $0$ 或 $n$，即允许某一侧为空串。

**约束**：

- $1 \le a.length, b.length \le 10^5$
- $a.length == b.length$
- $a$、$b$ 都只包含小写英文字母

> 💡 典型的**双指针 + 回文判定**套路题：拼接串"左半来自一个串的头、右半来自另一个串的尾"，两端配对与分割点无关，只有中间一小段才依赖 $i$——把 $O(n)$ 个分割点的检查压缩成一次 $O(n)$ 的收缩。

## 2. 示例

**示例 1**

```text
输入：a = "x", b = "y"
输出：true
解释：取 i = 0：aprefix = ""，bsuffix = "y"，拼接 "" + "y" = "y" 是回文。
     单字符（乃至空串一侧）天然回文，n = 1 恒为 true。
```

**示例 2**

```text
输入：a = "xbdef", b = "xecab"
输出：false
解释：两个拼接方向、任何分割点都无法构成回文（见 §3.4 面板 ③）。
```

**示例 3**

```text
输入：a = "ulacfd", b = "jizalu"
输出：true
解释：在下标 i = 3 处分割：aprefix = "ula"，bsuffix = "alu"，
     拼接 "ula" + "alu" = "ulaalu" 是回文串。
```

**示例 4（方向性补充）**

```text
输入：a = "yx", b = "xz"
输出：true
解释：check(a, b) 方向无解，但 check(b, a) 方向：取 i = 1，
     bprefix = "x"，asuffix = "x"，拼接 "xx" 是回文。
     —— 两个拼接方向缺一不可。
```

## 3. 解题思路

### 3.1 暴力思路：枚举分割点逐个整串验证

枚举 $i \in [0, n]$ 共 $n+1$ 种分割，对每个候选拼接串做一次 $O(n)$ 的双指针回文验证，两个方向共约 $2(n+1)$ 次验证，总计 $O(n^2)$。$n = 10^5$ 时约 $2 \times 10^{10}$ 次字符比较，必然超时。

低效的根源：相邻分割点产生的拼接串只差**两个字符的归属**，却要整串重验——绝大多数配对结果被反复丢弃。应当把"与 $i$ 无关的部分"一次性算完。

### 3.2 核心观察：两端跨界配对，中间段自由

![核心观察：拼接串由 a 的头与 b 的尾组成，两端跨界配对与 i 无关，中间段整段同侧](images/wc210_q3_cross_pair_concept.svg)

以 $s_i = a_{prefix} + b_{suffix} = a[0{:}i] + b[i{:}n]$ 为例（另一方向 $b[0{:}i] + a[i{:}n]$ 完全对称）。按分割点 $i$：

$$s_i[k] = \begin{cases} a[k], & k < i \\ b[k], & k \ge i \end{cases}$$

$s_i$ 是回文 $\iff$ 每一对 $s_i[k] = s_i[n-1-k]$。把配对 $(k, n-1-k)$ 按位置分成三类：

- **跨界对**（$k < i \le n-1-k$）：左字符来自 $a$ 的头、右字符来自 $b$ 的尾，要求 $a[k] = b[n-1-k]$——**只要这对"跨过去"，具体 $i$ 在区间哪里无关紧要**；
- **左侧同段对**（$n-1-k < i$，即 $i > n/2$）：两个位置都落在 $a[0{:}i]$ 内，要求 $a[n-i..i-1]$ 是回文；
- **右侧同段对**（$i \le k$，即 $i < n/2$）：两个位置都落在 $b[i{:}n]$ 内，要求 $b[i..n-1-i]$ 是回文。

后两类不会同时非空。于是判定可以**去掉 $i$**：双指针 $l = 0$、$r = n-1$，从两端尽可能多地消化跨界对：

```text
while l < r and a[l] == b[r]: l++, r--
```

停止后只有两种局面：

- **自然汇合**（$l \ge r$）：中间段为空或单个字符，必然回文——直接成功；
- **失配停止**（$a[l] \ne b[r]$）：任何合法的 $i$ 都无法再让这对跨界（见 §5 引理 2），中间段 $[l, r]$ 必须**整段落到同一侧**——要么 $i = r+1$（中间全取 $a$，需 $a[l..r]$ 回文），要么 $i = l$（中间全取 $b$，需 $b[l..r]$ 回文）。

两种中间段**任一**回文即可成功。

> ⚠️ 关键易错：失配后**不能换字符继续配**，也**不能只试其中一个串的中间段**——$i = r+1$ 与 $i = l$ 对应两种不同的拼接串，两段都要检测。

### 3.3 算法流程

![算法流程：check(x,y) 先收缩跨界对，再依次检测 x、y 的中间段](images/wc210_q3_check_flow.svg)

```text
check(x, y)：判定 ∃i 使 x[0:i] + y[i:n] 为回文
  1. l = 0, r = n − 1
  2. while l < r 且 x[l] == y[r]：l++，r−−        # 消化跨界对
  3. 若 x[l..r] 是回文 → true                     # 对应 i = r+1，中间全取 x
  4. 若 y[l..r] 是回文 → true                     # 对应 i = l，  中间全取 y
  5. 返回 false

checkPalindromeFormation(a, b) = check(a, b) or check(b, a)
```

### 3.4 示例演算

![示例演算：收缩成功、失配后中间段救场、双向全灭三种结局](images/wc210_q3_walkthrough.svg)

**面板 ①（示例 3）**：`check("ulacfd", "jizalu")`

| 步骤 | 比较 | 结果 | 收缩后 |
|------|------|------|--------|
| 1 | $a[0]=$ `u` $\leftrightarrow$ $b[5]=$ `u` | ✓ | $l=1,\ r=4$ |
| 2 | $a[1]=$ `l` $\leftrightarrow$ $b[4]=$ `l` | ✓ | $l=2,\ r=3$ |
| 3 | $a[2]=$ `a` $\leftrightarrow$ $b[3]=$ `a` | ✓ | $l=3,\ r=2$ |
| — | $l \ge r$ 自然汇合 | 中间段空 | **true** |

取 $i = 3$：`"ula" + "alu" = "ulaalu"` ✓。

**面板 ②（自造）**：`check("ababa", "xyzww")`——第 1 步就失配：$a[0]=$ `a` $\ne$ $b[4]=$ `w`，指针冻结在 $l=0,\ r=4$。转中间段检测：$a[0..4]=$ `ababa` 是回文 ✓（取 $i=5$，`bsuffix` 为空）；$b[0..4]=$ `xyzww` 不是回文 ✗。两段只需一个成立 → **true**。

**面板 ③（示例 2）**：`check("xbdef", "xecab")`：`x` $\ne$ `b` 失配，$a$ 段 `xbdef` ✗、$b$ 段 `xecab` ✗ → false；换向 `check("xecab", "xbdef")`：`x` $\ne$ `f` 失配，同样两段皆非回文 → false。双向全灭，返回 **false** ✓。

## 4. 算法细节

1. **方向的对称性**：$a_{prefix}+b_{suffix}$ 与 $b_{prefix}+a_{suffix}$ 是两族不同的拼接串，必须分别调用 `check(a, b)` 与 `check(b, a)`（示例 4 中只有一个方向有解）。
2. **收缩循环的复合条件**：`l < r && x[l] == y[r]` 同时承担"还有跨界对"与"这对匹配"两个语义，二者缺一不可——漏掉 `l < r` 会在 $l = r$ 时越界比较甚至死循环。
3. **中间段检测用闭区间双指针**：`isPal(s, l, r)` 检查 $s[l..r]$，与收缩循环共用同一对 `l, r`，无需重算。
4. **Python 的切片写法**：`x[l:r+1] == x[l:r+1][::-1]` 一步完成回文检测，代价是 $O(n)$ 临时空间；C++ 用原位双指针则 $O(1)$ 额外空间。
5. **$i$ 的两种取法即分割点边界**：$i = r+1$ 表示 `aprefix` 一直吃到 $r$（$b$ 侧后缀只剩已配对的尾巴），$i = l$ 表示 `aprefix` 只保留已配对的头。二者已涵盖空前缀/空后缀（$i = 0$ 与 $i = n$）等价情形。

## 5. 正确性证明

**引理 1（配对分解）**：设 $s_i = a[0{:}i] + b[i{:}n]$，则 $s_i$ 为回文，当且仅当：

1. 对所有 $k < \min(i, n-i)$：$a[k] = b[n-1-k]$；
2. 若 $i > n/2$：$a[n-i..i-1]$ 是回文；若 $i < n/2$：$b[i..n-1-i]$ 是回文；若 $i = n/2$：无附加条件。

**证明**：$s_i$ 回文 $\iff$ 对每对 $k < n-1-k$ 有 $s_i[k] = s_i[n-1-k]$。按 $i$ 与这对位置的关系分类：若 $k < i \le n-1-k$，两侧分别读出 $a[k]$ 与 $b[n-1-k]$，即条件 1（$k < i$ 且 $k \le n-1-i$ 恰为 $k < \min(i, n-i)$）。若 $n-1-k < i$，则两位置都 $< i$，此时 $k$ 取遍 $[n-i, i-1]$，这些配对恰是 $a$ 的区间 $[n-i, i-1]$ 的全部对称对，等价于该区间回文（仅当 $i > n/2$ 时非空）。若 $k \ge i$，则两位置都 $\ge i$，同理等价于 $b$ 的区间 $[i, n-1-i]$ 回文（仅当 $i < n/2$ 时非空）。三类合起来即所述条件。∎

**引理 2（失配截断）**：若双指针停止时 $l < r$ 且 $a[l] \ne b[r]$，则任何满足引理 1 条件 1 的分割点 $i$ 必有 $i \le l$ 或 $i \ge r+1$。

**证明**：循环逐对验证了 $k = 0, 1, \dots, l-1$ 均有 $a[k] = b[n-1-k]$，而 $k = l$ 失败。若 $\min(i, n-i) > l$，则条件 1 要求 $k = l$ 也成立，矛盾。故 $\min(i, n-i) \le l$，即 $i \le l$ 或 $n - i \le l \iff i \ge n - l = r + 1$。∎

**定理**：`check(a, b)` 返回 true $\iff$ 存在 $i \in [0, n]$ 使 $a[0{:}i] + b[i{:}n]$ 是回文。

**证明**：

（$\Leftarrow$）设存在合法 $i$。由引理 1 条件 1，所有 $k < \min(i, n-i)$ 的跨界对都匹配，而收缩循环每轮验证一对，故停止时 $l \ge \min(i, n-i)$。若 $l \ge r$，区间 $[l, r]$ 至多一个字符，`isPal` 恒真，`check` 返回 true。若 $l < r$，由引理 2 只需分两种情形：

- $i \le l$：此时 $i \le l < r$ 给出 $i < n/2$，引理 1 条件 2 为 $b[i..n-1-i]$ 回文。由 $i \le l$ 及 $r = n-1-l$ 得 $[l, r] \subseteq [i, n-1-i]$，且 $l + r = n-1$ 说明 $[l, r]$ 是关于同一中心的对称子区间，其内部配对均已被大区间回文覆盖，故 $b[l..r]$ 回文，`isPal(b, l, r)` 为真；
- $i \ge r+1$：此时 $i \ge r+1 > l$ 给出 $i > n/2$，条件 2 为 $a[n-i..i-1]$ 回文，同理 $[l, r] \subseteq [n-i, i-1]$，故 $a[l..r]$ 回文。

两种情形下 `check` 均返回 true。

（$\Rightarrow$）设 `check` 返回 true。若因 $l \ge r$ 返回：所有 $k < l$ 的跨界对已匹配，取 $i = l$（$n$ 奇时 $l = r$，$n$ 偶时 $l = r+1$），则 $\min(i, n-i) \le l$，条件 1 成立；中间段 $b[l..r]$ 至多一个字符，回文，条件 2 成立。若因 `isPal(a, l, r)` 返回：取 $i = r+1$，则 $\min(i, n-i) = \min(r+1, l) = l$，$k < l$ 已全部匹配，条件 1 成立；且 $l < r$ 保证 $i = r+1 > n/2$，条件 2 恰为 $a[n-i..i-1] = a[l..r]$ 回文，成立。`isPal(b, l, r)` 的情形对称，取 $i = l$ 即可。三种情形都给出一个使 $s_i$ 回文的分割点。∎

由定理，`check(a, b) || check(b, a)` 恰好覆盖题目要求的两个拼接方向，算法正确。

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。单次 `check` 中收缩循环最多推进 $n/2$ 对，两次 `isPal` 各扫一段总长不超过 $n$ 的区间；两个方向共 4 次线性扫描，仍是 $O(n)$。$n = 10^5$ 时约几十万次字符比较，远低于暴力法的 $2 \times 10^{10}$。
- **空间复杂度**：$O(1)$（C++ 原位双指针，不计输入）。Python 切片写法产生 $O(n)$ 临时串，量级一次性的、不影响渐进时间。

## 7. 参考代码

### C++

```cpp
class Solution {
    bool isPal(const string& s, int l, int r) {
        while (l < r) {
            if (s[l] != s[r]) return false;
            ++l, --r;
        }
        return true;
    }
    bool check(const string& x, const string& y) {
        int l = 0, r = (int)x.size() - 1;
        while (l < r && x[l] == y[r]) ++l, --r;
        return isPal(x, l, r) || isPal(y, l, r);
    }
public:
    bool checkPalindromeFormation(string a, string b) {
        return check(a, b) || check(b, a);
    }
};
```

### Python

```python
class Solution:
    def checkPalindromeFormation(self, a: str, b: str) -> bool:
        def check(x: str, y: str) -> bool:
            l, r = 0, len(x) - 1
            while l < r and x[l] == y[r]:
                l += 1
                r -= 1
            sx, sy = x[l:r + 1], y[l:r + 1]
            return sx == sx[::-1] or sy == sy[::-1]
        return check(a, b) or check(b, a)
```

> 💡 `check` 里的 `x[l:r+1]` 是**失配后的中间段**（含自然汇合时的空串/单字符），切片回文比较一行搞定；两段是"或"的关系，对应 $i = r+1$ 与 $i = l$ 两个候选分割点。

## 8. 边界情况与易错点

1. **两个方向都要试**（最高频 WA）：只写 `check(a, b)` 会在示例 4（`a = "yx", b = "xz"`）上返回 false——解只在 `check(b, a)` 方向。
2. **中间段 $a$、$b$ 都要试**：失配后只检测其中一个串会漏掉另一半候选分割点（面板 ② 中 `b` 段失败但 `a` 段成功）。
3. **失配后不能"跳过"或"换字符"继续配**：双指针一旦失配立即停止，剩下的中间段必须整段同侧，继续硬配是错误思路。
4. **$n = 1$ 恒真**：单字符必回文，收缩循环因 `l < r` 不成立直接跳过，`isPal(空段)` 返回 true，无需特判。
5. **分割点含 $0$ 与 $n$**：题面允许空前缀/空后缀；双指针取法 $i = l$、$i = r+1$ 天然涵盖这些边界。
6. **收缩循环别漏 `l < r`**：否则 $l = r$ 时仍比较 `x[l] == y[r]`（把中心字符和自己错误的镜像比较），$l > r$ 后还会继续越界推进。
7. **Python 切片区间是 `x[l:r+1]`**：闭区间转半开区间漏掉 `+1` 会丢掉最后一个字符，单字符段甚至切成空串引发误判。
8. **别用 $O(n^2)$ 枚举**：$n = 10^5$ 下任何逐分割点整串验证的写法都会超时。
