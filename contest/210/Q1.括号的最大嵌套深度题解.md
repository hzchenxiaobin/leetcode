# LeetCode 括号的最大嵌套深度 题解

## 1. 题目概述

- **标题 / 题号**：括号的最大嵌套深度（#1614，easy）
- **链接**：https://leetcode.cn/problems/maximum-nesting-depth-of-the-parentheses/
- **来源**：LeetCode 第 210 场周赛 Q1
- **难度**：简单
- **标签**：栈、字符串、括号序列

**题意**：给定一个**有效括号字符串** `s`（其中还混有数字 `0-9` 与运算符 `+ - * /`，括号保证合法配对），返回 `s` 的**嵌套深度**——即嵌套括号的最大层数。例如 `(1+(2*3)+((8)/4))+1` 中数字 `8` 被三层括号包裹，深度为 $3$。

形式化地，有效括号串（VPS）与其深度的递归定义为：

- 空串或单个非括号字符是 VPS，深度为 $0$；
- 若 $A$、$B$ 是 VPS，则拼接 $AB$ 是 VPS，深度为 $\max(\mathrm{depth}(A), \mathrm{depth}(B))$；
- 若 $A$ 是 VPS，则 $(A)$ 是 VPS，深度为 $\mathrm{depth}(A) + 1$。

**约束**：

- $1 \le |s| \le 100$
- `s` 仅由数字 `0-9` 与字符 `+ - * / ( )` 组成
- 题目保证 `s` 为有效括号字符串（无需校验合法性）

> 💡 签到题拼的是「从题面到代码的最短路径」：一次观察——**深度就是当前还没闭合的 `(` 个数**——即可把整题压缩成一个计数器 + 一趟扫描。

## 2. 示例

**示例 1**

```text
输入：s = "(1+(2*3)+((8)/4))+1"
输出：3
解释：数字 8 在嵌套的 3 层括号中。
```

**示例 2**

```text
输入：s = "(1)+((2))+(((3)))"
输出：3
解释：数字 3 在嵌套的 3 层括号中。
```

**示例 3**

```text
输入：s = "()(())((()()))"
输出：3
```

**示例 4（边界补充）**

```text
输入：s = "1"
输出：0
解释：没有任何括号时深度为 0——ans 的初值必须是 0。
```

## 3. 解题思路

### 3.1 暴力思路：按定义解析 VPS

最直接的做法是把递归定义翻译成解析器：定位每对匹配的括号 $(A)$，递归求 $A$ 的深度再加 1，同级拼接取 $\max$。正确但实现繁琐——要找匹配括号、切子串、管理递归。另一种"半暴力"是用显式栈：遇 `(` 入栈、遇 `)` 出栈，栈的最大 `size()` 即答案，好写但空间 $O(n)$。本题 $n \le 100$ 两者都能过，但都不是最短路径——**题目只问深度，根本不需要把结构存下来**。

### 3.2 核心观察：深度 ≡ 未闭合的 '(' 数量

![核心观察：嵌套深度等于未闭合左括号数量](images/paren_depth_concept.svg)

从左到右扫描时，**任意时刻的嵌套深度恰好等于此前尚未闭合的 `(` 个数**：

1. 遇到 `(`：打开一层嵌套，`depth + 1`——深度只在此时上升，顺手刷新 $ans = \max(ans, depth)$；
2. 遇到 `)`：闭合一层嵌套，`depth - 1`；
3. 遇到数字 / 运算符：对深度毫无影响，直接跳过。

由于括号合法，`depth` 全程非负且最终回到 $0$；答案就是这条"深度曲线"的**峰值**。一个计数器足矣，无需栈、无需递归。

> ⚠️ 刷新 `ans` 只需放在 `(` 分支：深度只在 `(` 处上升，峰值必然出现在某个 `(` 之后；在 `)` 处刷新虽不出错但纯属多余。

### 3.3 算法流程

![算法流程：单趟扫描与计数器维护](images/paren_depth_flow.svg)

```text
1. depth = 0, ans = 0
2. 逐字符扫描 s：
   a. c == '(' → depth += 1；ans = max(ans, depth)
   b. c == ')' → depth -= 1
   c. 其他     → 跳过
3. 返回 ans
```

### 3.4 示例演算

![示例演算：depth 阶梯曲线与事件表](images/paren_depth_walkthrough.svg)

以示例 1 `s = "(1+(2*3)+((8)/4))+1"` 为例，只列括号事件：

| 步 | 字符 | 动作 | depth（处理后） | ans |
|----|------|------|-----------------|-----|
| 1 | `(` | depth+1，刷新 | 1 | 1 |
| 2 | `(` | depth+1，刷新 | 2 | 2 |
| 3 | `)` | depth−1 | 1 | 2 |
| 4 | `(` | depth+1，刷新 | 2 | 2 |
| 5 | `(` | depth+1，刷新 | **3** | **3** ← 峰值 |
| 6 | `)` | depth−1 | 2 | 3 |
| 7 | `)` | depth−1 | 1 | 3 |
| 8 | `)` | depth−1 | 0 | 3 |

数字 `1 2 3 8 4 1` 与运算符 `+ * + / +` 全部跳过；扫描结束返回 `ans = 3` ✓。

## 4. 算法细节

1. **状态只需两个整型**：`depth`（当前未闭合层数）与 `ans`（历史峰值）。不存括号本身、不记下标、不递归。
2. **`ans` 的刷新时机**：仅在 `(` 分支内、且在 `depth++` **之后**执行 `ans = max(ans, depth)`。先刷后加会把 `"()"` 类输入的答案整体少 1。
3. **数字 / 运算符分支可整体省略**：`if (c=='(') {...} else if (c==')') {...}` 之外连 `else` 都不用写。
4. **显式栈是等价但更贵的写法**：本题只有 `()` 一种括号，栈内元素全同，`stack.size() ≡ depth`，退化为计数器后空间从 $O(n)$ 降到 $O(1)$。多类型括号（`()[]{}`）需要类型匹配时才必须保留栈。
5. **数据范围极小**：$n \le 100$，深度上界 $\lfloor n/2 \rfloor = 50$，`int` 绰绰有余；即便 $n$ 放大到 $10^6$，本解法仍是线性最优。

## 5. 正确性证明

**引理 1（计数器语义）**：设 $\mathrm{diff}_i$ 为前缀 $s[0..i]$ 中 `(` 与 `)` 的个数差（$\mathrm{diff}_{-1} = 0$ 为空前缀）。算法扫描完该前缀后 `depth` 的值恰为 $\mathrm{diff}_i$，且 $\mathrm{diff}_i \ge 0$。

**证明**：对 $i$ 归纳。$i = -1$ 时 `depth` = 0 成立。设处理完 $s[0..i-1]$ 后成立：若 $s[i]$ 为 `(`，`depth++` 且 $\mathrm{diff}$ 增 1；若为 `)`，两者各减 1；否则均不变。故对 $i$ 成立。又 `s` 合法 ⇒ 任何前缀中 `(` 数不少于 `)` 数 ⇒ $\mathrm{diff}_i \ge 0$。∎

**引理 2（深度的前缀刻画）**：对有效括号串 $s$，其嵌套深度

$$D(s) = \max_{-1 \le i < |s|} \mathrm{diff}_i$$

**证明**：对 VPS 的递归结构归纳。

- **基础**（空串 / 单个非括号字符）：所有前缀差为 0，$D = 0$ ✓。
- **拼接 $AB$**：$AB$ 的前缀分两类——$A$ 的前缀（差 $\le D(A)$）；或 $A$ 的整串接上 $B$ 的前缀（$A$ 整串差为 0，故差恰为 $B$ 的前缀差 $\le D(B)$）。故 $\max \mathrm{diff} = \max(D(A), D(B)) = D(AB)$ ✓。
- **包裹 $(A)$**：前缀分三类——单独 `(`（差 1）；`(` 接 $A$ 的前缀（差 $= 1 + A\text{ 的前缀差} \le 1 + D(A)$，取 $A$ 中达到 $D(A)$ 的前缀时取等）；整串（差 0）。故 $\max \mathrm{diff} = 1 + D(A) = D((A))$ ✓。∎

**定理**：算法返回 `ans` $= D(s)$。

**证明**：由引理 1，扫描各时刻 `depth` 依次取值 $\mathrm{diff}_i$。设 $M = \max_i \mathrm{diff}_i$。算法仅在 `(` 分支（`depth` 上升一步之后）刷新 `ans`：

- 若 $M = 0$（无括号），`ans` 保持初值 $0 = M$；
- 若 $M > 0$，取**最早**达到 $M$ 的下标 $j$，则 $\mathrm{diff}_{j-1} < \mathrm{diff}_j = M$，该步差值只能增 1，即 $s[j]$ 为 `(`，且上升后 `depth` $= M$，算法在此处刷新得 `ans` $\ge M$；又每次刷新的取值 `depth` $\le M$，故 `ans` $\le M$。

两种情况均有 `ans` $= M = D(s)$（引理 2）。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。单趟扫描，每个字符只有 $O(1)$ 的分支判断；$n \le 100$ 下等同于常数级。
- **空间复杂度**：$O(1)$。仅 `depth`、`ans` 两个整型变量（显式栈写法需 $O(n)$，不必要）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maxDepth(string s) {
        int depth = 0, ans = 0;
        for (char c : s) {
            if (c == '(') {
                ++depth;
                ans = max(ans, depth);
            } else if (c == ')') {
                --depth;
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maxDepth(self, s: str) -> int:
        depth = ans = 0
        for c in s:
            if c == '(':
                depth += 1
                ans = max(ans, depth)
            elif c == ')':
                depth -= 1
        return ans
```

呼应 §5 中"前缀差"观点的一行写法（`accumulate` 产生逐步前缀差，取最大值即深度）：

```python
from itertools import accumulate

class Solution:
    def maxDepth(self, s: str) -> int:
        return max(accumulate((c == '(') - (c == ')') for c in s), default=0)
```

## 8. 边界情况与易错点

1. **返回 `depth` 而非 `ans`（最大坑）**：扫描结束后 `depth` 恒为 0，对任何输入都返回 0。必须返回扫描过程中的峰值 `ans`。
2. **`ans` 初值必须为 0**：无括号输入（如 `"1"`、`"1+2"`）的答案就是 0，初始化成 1 或其他值会错（示例 4）。
3. **刷新时机在 `depth++` 之后**：`ans = max(ans, depth+1)` 与 `ans = max(ans, depth++)` 这类顺序错误会让 `"()"` 类输入少 1。
4. **无需防御性检查**：题目保证括号合法，`depth` 不会为负，`)` 不会使计数器下穿 0，扫描结束必回 0。若取消该保证，才需在 `)` 分支校验 `depth > 0` 并检查终值（本题不用）。
5. **不要被数字 / 运算符带偏**：它们是纯干扰项，既不入栈也不参与计数；更不要试图真的求表达式值。
6. **别用栈硬做**：能用计数器就不要 $O(n)$ 空间的栈——周赛 Q1 拼的就是最短路径与手速。
