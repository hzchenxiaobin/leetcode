# LeetCode 统计子树中城市之间最大距离 题解

## 1. 题目概述

- **标题 / 题号**：统计子树中城市之间最大距离（#1617，hard）
- **链接**：https://leetcode.cn/problems/count-subtrees-with-max-distance-between-cities/
- **来源**：LeetCode 第 210 场周赛 Q4
- **难度**：困难
- **标签**：位运算、树、状态压缩、枚举、广度优先搜索、树的直径

**题意**：$n$ 个城市构成一棵树（$n-1$ 条边，任意两点间路径唯一）。一个**子树**是城市的一个子集 $S$，要求 $S$ 中任意两个城市都能只借助 $S$ 内的城市与边互通（即 $S$ 的诱导子图连通）；两棵子树不同当且仅当城市集合不同。对 $d = 1, 2, \dots, n-1$，统计**最大距离**（直径）恰好为 $d$ 的子树数目，返回长度为 $n-1$ 的数组，第 $d$ 项（下标从 1 开始）即答案。

**约束**：

- $2 \le n \le 15$
- `edges.length == n - 1`，`1 <= ui, vi <= n`，边互不相同
- 城市间路径唯一（保证是树）

> 💡 $n \le 15$ 是本题最大的明示：$2^{15} = 32768$，**直接枚举所有城市子集**可行。真正要想清楚的是两件事：怎么判定"是不是子树"（诱导子图的连通性），以及怎么快速求"子树内的最大距离"（直径）。

## 2. 示例

```text
输入：n = 4, edges = [[1,2],[2,3],[2,4]]
输出：[3,4,0]
解释：星形树，中心是 2。
直径 1：{1,2}、{2,3}、{2,4}，共 3 个。
直径 2：{1,2,3}、{1,2,4}、{2,3,4}、{1,2,3,4}，共 4 个。

```

```text
输入：n = 2, edges = [[1,2]]
输出：[1]
解释：唯一的 2 点子树 {1,2}，直径 1。
```

**示例 3**

```text
输入：n = 3, edges = [[1,2],[2,3]]
输出：[2,1]
解释：{1,2}、{2,3} 直径 1；{1,2,3} 直径 2。
```

## 3. 解题思路

### 3.1 暴力思路

枚举全部 $2^n$ 个子集，对每个子集在诱导子图里"从零开始"做全套图算法：先 BFS 判连通，再从子集内每个点各做一次受限 BFS 求出子图内的两两距离、取最大。复杂度 $O(2^n \cdot n^2)$，$n = 15$ 时约 $10^7$ 量级，其实也能通过——但它把"求同一对点的距离"在每个子集里重复了成千上万遍，代码又长又慢。真正值得提炼的观察是：**这些距离根本不需要按子集重算**。

### 3.2 核心观察：子树内的距离 ≡ 全树内同一对点的距离

![核心观察：路径包含引理——连通子树内两点的路径不离开子树](images/subtree_diameter_path_containment.svg)

**观察（路径包含）**：树上任意两点间的路径是**唯一**的。设子集 $S$ 连通（是合法子树），$u, v \in S$：$S$ 的诱导子图是树的子图，故无环，又连通，因此自身也是一棵树，其中存在一条 $u \to v$ 路径 $P'$；而 $P'$ 同时也是原树中的 $u \to v$ 路径，由唯一性，它**就是**原树中那条路径——于是 $P'$ 整条落在 $S$ 内，且

$$d_{T[S]}(u, v) = d_T(u, v)$$

**子树内两点的距离 = 全树中这两点的距离。** 因此只需对全树预处理一次距离矩阵 `dist`（每个点做一次 BFS，共 $O(n^2)$），之后任何连通子集的直径都是纯查表：

$$\operatorname{diam}(S) = \max_{u, v \in S} \operatorname{dist}[u][v]$$

反过来，**不连通**的子集根本不是子树，必须排除——此时全局 `dist` 虽然照样查得到值，但没有任何"子树直径"的含义，直接取 max 会误计数（插图中 $S' = \{1,3,6\}$ 就是反例）。

> ⚠️ 距离可以复用全局矩阵的前提是"连通"；先判连通、再查表，两步顺序不能反。

配合位掩码组织枚举：城市 $i+1$ 对应二进制的第 $i$ 位，一个 `mask` 就是一个子集，`mask >> i & 1` 表示城市 $i+1$ 是否入选。$2^n$ 个 mask 与"子树由城市集合唯一刻画"的定义严丝合缝，不重不漏。

### 3.3 算法流程

![算法流程：一次预处理 dist + 位掩码枚举 + 连通检查 + 逐对取 max](images/subtree_diameter_bitmask_flow.svg)

```text
1. 建邻接表 g（城市编号统一减一，用 0..n−1）
2. 预处理：从每个点 s 各做一次 BFS → 全源距离矩阵 dist[s][v]
3. 枚举 mask = 1 .. 2ⁿ−1：
   a. popcount(mask) < 2 → 跳过（单点子树直径 0，不在统计范围）
   b. 连通性检查：取 mask 最低位的顶点 start，
      只向"仍在 mask 中"的邻点扩展做 BFS
   c. 访问到的顶点数 ≠ popcount(mask) → 不连通，跳过
   d. d = max{ dist[i][j] : i < j 且 i, j ∈ mask }   ← 纯查表
   e. ans[d − 1] += 1
4. 返回 ans（长度 n − 1）
```

### 3.4 示例演算

![示例演算：星形树 15 个子集的完整归类](images/subtree_diameter_walkthrough.svg)

以示例 1 的星形树（中心 2）为例，预处理出的距离矩阵：

| dist | 1 | 2 | 3 | 4 |
|------|---|---|---|---|
| **1** | 0 | 1 | 2 | 2 |
| **2** | 1 | 0 | 1 | 1 |
| **3** | 2 | 1 | 0 | 2 |
| **4** | 2 | 1 | 2 | 0 |

15 个非空子集逐一归类：

| 归类 | 子集 | 个数 | 直径 | 去向 |
|------|------|------|------|------|
| 单点 | {1}、{2}、{3}、{4} | 4 | 0 | 不计入 |
| 不连通 | {1,3}、{1,4}、{3,4}、{1,3,4} | 4 | — | 跳过 |
| 子树 | {1,2}、{2,3}、{2,4} | 3 | 1 | ans[0] |
| 子树 | {1,2,3}、{1,2,4}、{2,3,4}、{1,2,3,4} | 4 | 2 | ans[1] |
| — | （不存在） | 0 | 3 | ans[2] |

$4 + 4 + 3 + 4 = 15$，非空子集全部对上号，返回 $[3, 4, 0]$ ✓。两个结构特征值得记住：星形树中**不含中心 2 的多点子集必不连通**；而任何连通子树的直径都不超过 2（所有路径都经过中心）。

## 4. 算法细节

1. **距离矩阵预处理**：树是稀疏图，从每个源点 BFS 一趟 $O(n)$，总计 $O(n^2)$；跑 Floyd–Warshall（$15^3 = 3375$ 步）也毫无压力，BFS 版常数更小。
2. **连通性检查**：起点取 `mask` 的最低位顶点（C++ 用 `__builtin_ctz(mask)`，Python 用 `(mask & -mask).bit_length() - 1`）；BFS 扩展时双重过滤——邻点在 `mask` 中、且未访问。**访问数等于 popcount ⟺ 连通**（引理 3，与起点选取无关）。
3. **直径计算**：双循环枚举 mask 内的点对 $i < j$，取 `dist[i][j]` 的最大值，至多 $\binom{15}{2} = 105$ 对。也可用"子树内两遍 BFS 求直径"（单子树 $O(|S|)$），但逐对取 max 更短更直白，$n \le 15$ 不必再省。
4. **计数下标**：`ans` 长度 $n-1$，直径 $d$ 计入 `ans[d-1]`。连通且 $|S| \ge 2$ 保证 $1 \le d \le n-1$（见 §5 定理），下标天然安全，无需防御性检查。
5. **位运算小抄**：`mask >> i & 1` 判属；`mask & -mask` 提取最低位的 1；popcount 用 `__builtin_popcount` / `bin(mask).count('1')`。
6. **不要按边集枚举子图**：题目按城市集合区分子树，mask ↔ 子树一一对应；按边集枚举既会重也会漏。

## 5. 正确性证明

**引理 1（树上路径唯一）**：树 $T$ 中任意两个不同顶点 $u, v$ 之间恰有一条简单路径。

**证明**：$T$ 连通，故至少存在一条 $u \to v$ 简单路径。若存在两条不同的简单路径 $P \ne P'$，则它们的并集中出现环，与 $T$ 无环矛盾。∎

**引理 2（路径包含 / 距离守恒）**：设 $S \subseteq V(T)$ 且诱导子图 $T[S]$ 连通。则对任意 $u, v \in S$，$T$ 中唯一的 $u \to v$ 路径的顶点全部属于 $S$，且 $d_{T[S]}(u, v) = d_T(u, v)$。

**证明**：$T[S]$ 是 $T$ 的子图，故无环；又连通，故 $T[S]$ 是树，其中存在唯一的 $u \to v$ 简单路径 $P'$。$P'$ 也是 $T$ 中的 $u \to v$ 简单路径；由引理 1，$T$ 中这样的路径唯一，故 $P'$ 即 $T$ 中唯一的 $u \to v$ 路径，其顶点全在 $S$ 中。同一条路径在两个图中的长度相等，故距离相等。∎

**引理 3（连通性判定）**：从 $S$ 中任一顶点 $s$ 出发、只在 $S$ 内部移动的 BFS 能访问 $S$ 的全部顶点，当且仅当 $T[S]$ 连通。

**证明**：（⇒）BFS 访问每个 $v \in S$ 时记录的前驱顶点构成一条 $s \to v$ 的路径，其顶点全在 $S$ 中，故 $S$ 内任两点经 $s$ 互通，$T[S]$ 连通。（⇐）若 $T[S]$ 连通，则 $S$ 内任一 $v$ 与 $s$ 之间存在 $T[S]$ 中的路径，路径上顶点全在 $S$ 中，BFS 沿该路径必然到达 $v$。∎

**定理**：算法返回的数组满足 `ans[d-1]`（$1 \le d \le n-1$）恰为最大距离等于 $d$ 的子树个数。

**证明**：题目定义两棵子树不同当且仅当城市集合不同，故 mask 与子树一一对应，枚举 $[1, 2^n)$ 不重不漏地覆盖所有城市子集。对每个 mask：由引理 3，算法恰在 $T[S]$ 连通时进入计数分支；由引理 2，此时 $d = \max_{u,v \in S} \mathrm{dist}[u][v]$ 即该子树的真实直径。再证 $d$ 落在合法区间：$|S| \ge 2$ 且连通时，任取 $u \ne v \in S$，树上唯一 $u \to v$ 路径至少含一条边，故 $d \ge 1$；又树上任意简单路径至多含 $n$ 个顶点、$n - 1$ 条边，故 $d \le n - 1$。单点子集（直径 0）与不连通子集均被跳过，不影响任何桶。因此每个直径为 $d$ 的子树恰使 `ans[d-1]` 增加 1。∎

## 6. 复杂度分析

- **时间复杂度**：$O(2^n \cdot n^2)$。预处理 $n$ 次 BFS 共 $O(n^2)$；主循环 $2^n$ 个 mask，每个做一次 $O(n)$ 的连通 BFS 和 $O(|S|^2) \le O(n^2)$ 的逐对取 max。$n = 15$ 时约 $2^{15} \times 225 \approx 7.4 \times 10^6$ 次操作，C++ / Python 都轻松通过。
- **空间复杂度**：$O(n^2)$。距离矩阵占大头；BFS 队列、访问标记与答案数组均为 $O(n)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> countSubgraphsForEachDiameter(int n, vector<vector<int>>& edges) {
        vector<vector<int>> g(n);
        for (auto& e : edges) {
            int u = e[0] - 1, v = e[1] - 1;
            g[u].push_back(v);
            g[v].push_back(u);
        }

        vector<vector<int>> dist(n, vector<int>(n, -1));
        for (int s = 0; s < n; s++) {
            queue<int> q;
            dist[s][s] = 0;
            q.push(s);
            while (!q.empty()) {
                int u = q.front(); q.pop();
                for (int v : g[u]) {
                    if (dist[s][v] == -1) {
                        dist[s][v] = dist[s][u] + 1;
                        q.push(v);
                    }
                }
            }
        }

        vector<int> ans(n - 1);
        for (int mask = 1; mask < (1 << n); mask++) {
            if (__builtin_popcount(mask) < 2) continue;

            int start = __builtin_ctz(mask);
            vector<int> vis(n);
            queue<int> q;
            q.push(start);
            vis[start] = 1;
            int cnt = 1;
            while (!q.empty()) {
                int u = q.front(); q.pop();
                for (int v : g[u]) {
                    if ((mask >> v & 1) && !vis[v]) {
                        vis[v] = 1;
                        cnt++;
                        q.push(v);
                    }
                }
            }
            if (cnt != __builtin_popcount(mask)) continue;

            int d = 0;
            for (int i = 0; i < n; i++) if (mask >> i & 1)
                for (int j = i + 1; j < n; j++) if (mask >> j & 1)
                    d = max(d, dist[i][j]);
            ans[d - 1]++;
        }
        return ans;
    }
};
```

### Python

```python
from collections import deque

class Solution:
    def countSubgraphsForEachDiameter(self, n: int, edges: List[List[int]]) -> List[int]:
        g = [[] for _ in range(n)]
        for u, v in edges:
            g[u - 1].append(v - 1)
            g[v - 1].append(u - 1)

        dist = [[-1] * n for _ in range(n)]
        for s in range(n):
            dist[s][s] = 0
            q = deque([s])
            while q:
                u = q.popleft()
                for v in g[u]:
                    if dist[s][v] == -1:
                        dist[s][v] = dist[s][u] + 1
                        q.append(v)

        ans = [0] * (n - 1)
        for mask in range(1, 1 << n):
            pc = bin(mask).count('1')
            if pc < 2:
                continue
            start = (mask & -mask).bit_length() - 1
            vis = {start}
            q = deque([start])
            while q:
                u = q.popleft()
                for v in g[u]:
                    if mask >> v & 1 and v not in vis:
                        vis.add(v)
                        q.append(v)
            if len(vis) != pc:
                continue
            d = max(dist[i][j]
                    for i in range(n) if mask >> i & 1
                    for j in range(i + 1, n) if mask >> j & 1)
            ans[d - 1] += 1
        return ans
```

## 8. 边界情况与易错点

1. **不查连通性就计数（最大坑）**：不连通子集（如示例 1 的 $\{1,3\}$）在全局 `dist` 里照样查得到距离 2，若不先判连通，会把它当成直径 2 的"子树"误计。
2. **单点子集**：直径 0。若不跳过，`ans[d-1]` 变成 `ans[-1]`——Python 里会静默给最后一格 +1（答案悄悄出错），C++ 里是下标越界的未定义行为。用 `popcount(mask) < 2` 挡住。
3. **下标双重偏移**：城市编号 $1..n$ 要减一成位下标 $0..n-1$；直径 $d$ 存到 `ans[d-1]`。两处偏移别搞混。
4. **`ans` 长度是 $n-1$**：$n = 2$ 时长度 1，只有一棵 2 点子树，答案是 `[1]`。
5. **别按边集枚举**：同一城市集合配不同边集不是不同的子树（题目只看城市集合）；按 mask 枚举天然不重不漏。
6. **BFS 起点任取**：连通性与起点无关（引理 3），取最低位顶点只是实现方便。
7. **性能直觉**：$2^{15} \times 225 \approx 7 \times 10^6$ 次查表比较，Python 也在秒级内；若实测偏慢，可把逐对取 max 换成子树内两遍 BFS，降到 $O(2^n \cdot n)$。
