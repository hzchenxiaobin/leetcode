# LeetCode 三段式数组 I 题解

## 1. 题目概述

- **标题 / 题号**：三段式数组 I（#3637，easy）
- **链接**：https://leetcode.cn/problems/trionic-array-i/
- **来源**：LeetCode 第 461 场周赛 Q1
- **难度**：简单
- **标签**：数组、模拟

**题意**：给定长度为 $n$ 的整数数组 `nums`。若存在索引 $0 < p < q < n-1$，使得 `nums[0..p]` **严格递增**、`nums[p..q]` **严格递减**、`nums[q..n-1]` **严格递增**（三段均为闭区间，共享端点 $p$、$q$），则称其为**三段式数组**（trionic）。判断 `nums` 是否为三段式数组。

**约束**：

- `3 <= n <= 100`
- `-1000 <= nums[i] <= 1000`

## 2. 示例

**示例 1**

```text
输入：nums = [1,3,5,4,2,6]
输出：true
解释：选 p = 2, q = 4：
  nums[0..2] = [1,3,5] 严格递增（1 < 3 < 5）
  nums[2..4] = [5,4,2] 严格递减（5 > 4 > 2）
  nums[4..5] = [2,6]   严格递增（2 < 6）
```

**示例 2**

```text
输入：nums = [2,1,3]
输出：false
解释：nums[1] < nums[0]，严格递增前缀为空，p 只能为 0，不满足 0 < p。
```

**示例 3（补充）**

```text
输入：nums = [1,2,3,2]
输出：false
解释：峰顶只能取 p = 2（极大递增前缀 [1,2,3]），此后递减段一路延伸到
末尾，q 只能为 3 = n−1，不满足 q < n−1。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有 $p \in [1, n-2]$、$q \in [p+1, n-2]$，对每个 $(p, q)$ 分别线性检查三段是否严格单调，时间复杂度 $O(n^3)$。$n \le 100$ 时约 $10^6$ 次比较，可以通过，但代码繁琐。签到题更值得一步写出 $O(n)$ 贪心扫描。

### 3.2 核心观察：峰顶与谷底被唯一确定

![三段式数组的形态：严格增、严格减、严格增](images/trionic_array_shape.svg)

关键观察：**若合法的 $(p, q)$ 存在，则 $p$ 与 $q$ 都被唯一确定**，根本无需枚举：

- **峰顶 $p$** = 从下标 0 出发的**极大严格递增前缀**的终点。因为 $q \ge p+1$ 蕴含 $nums[p+1] < nums[p]$，递增前缀不可能越过 $p$；
- **谷底 $q$** = 从 $p$ 出发的**极大严格递减段**的终点。因为 $q \le n-2$，第三段递增要求 $nums[q+1] > nums[q]$，递减段不可能越过 $q$。

于是只需一趟扫描依次走完"增 → 减 → 增"三个极大段，并检查**每段确实非空**（即 $p \ge 1$、$q \ge p+1$、$q \le n-2$）。

> 💡 换个角度：把相邻元素的比较方向写成 `↑ / ↓ / =`，数组是三段式当且仅当方向序列形如 `↑…↑ ↓…↓ ↑…↑`，三块都非空且再无其他符号。相邻相等 `=` 一出现就直接出局。

### 3.3 算法流程

![算法流程：三个 while 依次扫描，任一检查失败即 false](images/trionic_array_scan.svg)

共用游标 $i$ 的三阶段扫描：

1. **阶段①**：`while i < n and nums[i] > nums[i-1]: i += 1`，得 $p = i-1$，要求 $p \ge 1$；
2. **阶段②**：`while i < n and nums[i] < nums[i-1]: i += 1`，得 $q = i-1$，要求 $p < q < n-1$；
3. **阶段③**：`while i < n and nums[i] > nums[i-1]: i += 1`，最终要求 $i = n$。

任一检查失败立即返回 `false`；三条 while 全部通过且 $i$ 走到 $n$ 返回 `true`。

### 3.4 示例演算

`nums = [1,3,5,4,2,6]`（$n = 6$）：

| i | 相邻比较 | 方向 | 所属阶段 |
|---|----------|------|----------|
| 1 | 3 > 1 | ↑ | ① 递增 |
| 2 | 5 > 3 | ↑ | ① 递增，停下得 p = 2 |
| 3 | 4 < 5 | ↓ | ② 递减 |
| 4 | 2 < 4 | ↓ | ② 递减，停下得 q = 4 |
| 5 | 6 > 2 | ↑ | ③ 递增，走到 i = 6 = n |

检查：$p = 2 \ge 1$ ✓，$p = 2 < q = 4 < n-1 = 5$ ✓，$i$ 最终 $= 6 = n$ ✓ → 返回 `true`。

## 4. 算法细节

1. **游标复用**：三个 while 共享游标 $i$，每对相邻元素 $(i-1, i)$ 恰被消费一次，自然对应闭区间语义——`nums[p]` 同属递增段与递减段，`nums[q]` 同属递减段与递增段，无需特判端点。
2. **三段非空的判定**：
   - 第一段至少含一次比较 ⇔ $p \ge 1$；
   - 第二段 ⇔ $q \ge p+1$（否则一条 `↓` 都没走）；
   - 第三段 ⇔ $q \le n-2$（保证存在 $nums[q] < nums[q+1]$ 这一步）。
3. **相等即终止**：$nums[i] = nums[i-1]$ 使增、减两个循环同时停止，最终 $i < n$ 返回 `false`，正确反映"严格"单调的要求。
4. **n = 3 恒为 false**：三段各至少 2 个元素且共享 2 个端点，需要 $n \ge 4$；$0 < p < q < n-1 = 2$ 本身也无整数解。

## 5. 正确性证明

**引理 1（峰顶唯一）**：若 $(p, q)$ 合法，则 $p$ 是从下标 0 出发的极大严格递增前缀的终点。

**证明**：`nums[0..p]` 严格递增，故该前缀至少延伸到 $p$；又 $q \ge p+1$，递减段给出 $nums[p+1] < nums[p]$，故前缀不能延伸到 $p+1$。两相结合，极大递增前缀的终点恰为 $p$。∎

**引理 2（谷底唯一）**：若 $(p, q)$ 合法，则 $q$ 是从 $p$ 出发的极大严格递减段的终点。

**证明**：`nums[p..q]` 严格递减，故该段至少延伸到 $q$；又 $q \le n-2$，第三段递增要求 $nums[q+1] > nums[q]$，故递减段不能延伸过 $q$。两相结合，极大递减段的终点恰为 $q$。∎

**定理**：三阶段扫描返回 `true` 当且仅当 `nums` 是三段式数组。

**证明**：
（⇒）设扫描返回 `true`，记扫得的峰谷为 $p, q$。阶段①保证 `nums[0..p]` 严格递增且 $p \ge 1$；阶段②保证 `nums[p..q]` 严格递减且 $p < q \le n-2$；阶段③从 $q$ 一路比较到 $n$，保证 `nums[q..n-1]` 严格递增。故 $(p, q)$ 满足定义。
（⇐）设存在合法 $(p, q)$。由引理 1、2，扫描得到的峰谷恰为该 $(p, q)$（极大段终点唯一），故 $p \ge 1$、$p < q \le n-2$ 全部通过；又 `nums[q..n-1]` 严格递增使阶段③的比较全部成立，游标必推进到 $i = n$，返回 `true`。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。游标 $i$ 从 1 单调推进到 $n$，三条 while 拼起来恰好把每对相邻元素比较一次。
- **空间复杂度**：$O(1)$。仅使用常数个变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool isTrionic(vector<int>& nums) {
        int n = nums.size();
        int i = 1;
        while (i < n && nums[i] > nums[i - 1]) i++;
        int p = i - 1;
        if (p < 1) return false;
        while (i < n && nums[i] < nums[i - 1]) i++;
        int q = i - 1;
        if (q == p || q == n - 1) return false;
        while (i < n && nums[i] > nums[i - 1]) i++;
        return i == n;
    }
};
```

### Python

```python
class Solution:
    def isTrionic(self, nums: List[int]) -> bool:
        n = len(nums)
        i = 1
        while i < n and nums[i] > nums[i - 1]:
            i += 1
        p = i - 1
        if p < 1:
            return False
        while i < n and nums[i] < nums[i - 1]:
            i += 1
        q = i - 1
        if q == p or q == n - 1:
            return False
        while i < n and nums[i] > nums[i - 1]:
            i += 1
        return i == n
```

## 8. 边界情况与易错点

![三类典型反例：缺第一段、缺第二段、缺第三段](images/trionic_array_fail_cases.svg)

1. **n = 3 恒为 false**：$0 < p < q < 2$ 无解；等价地三段各含至少 2 个元素，要求 $n \ge 4$。
2. **开头不增**（`[2,1,3]`）：$p = 0 < 1$，false。
3. **一路递增**（`[1,2,3]`）：没有一条 `↓`，$q = p$，false。
4. **递减直达末尾**（`[1,2,3,2]`）：$q = n-1$，false。**这是最易漏的检查**——若漏写 $q < n-1$，`[1,2,3,2]` 会被误判为 true：阶段③的 while 一次都不执行，$i$ 已经等于 $n$。
5. **相邻相等**（`[1,3,3,2,4]`）：相等既非严格增也非严格减；任何相邻对 $(k, k+1)$ 必落入三段之一，故只要出现相等直接 false。
6. **负数**：只做相对比较，$-1000 \le nums[i] \le 1000$ 无影响。
