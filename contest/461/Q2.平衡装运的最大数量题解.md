# LeetCode 平衡装运的最大数量 题解

## 1. 题目概述

- **标题 / 题号**：平衡装运的最大数量（#3638，medium）
- **链接**：https://leetcode.cn/problems/maximum-balanced-shipments/
- **来源**：LeetCode 第 461 场周赛 Q2
- **难度**：中等
- **标签**：贪心、数组、栈、动态规划、单调栈

**题意**：给定按直线排列的 $n$ 个包裹的重量数组 `weight`。**装运**定义为包裹的一个连续子数组；若**最后一个包裹的重量严格小于该装运中所有包裹的最大重量**，则称为**平衡装运**。选出若干个**不重叠**的连续平衡装运（每个包裹至多出现在一次装运中，部分包裹可以不被装运），返回可以形成的平衡装运的**最大数量**。

**约束**：

- $2 \le n \le 10^5$
- $1 \le \text{weight}[i] \le 10^9$

## 2. 示例

**示例 1**

```text
输入：weight = [2,5,1,4,3]
输出：2
解释：装运 1 = [2,5,1]（末尾 1 < max 5），装运 2 = [4,3]（末尾 3 < max 4）。
无法通过其他划分获得超过两个平衡装运。
```

**示例 2**

```text
输入：weight = [4,4]
输出：0
解释：[4,4] 的末尾等于 max，[4] 单独成段末尾也等于 max，均不平衡，答案 0。
```

**示例 3（补充）**

```text
输入：weight = [1,2,3,1]
输出：1
解释：严格递增前缀 [1,2,3] 中任何后缀的末尾都是段内最大值，无法平衡；
唯一能闭合的位置是末尾的 1（1 < 3），故任何方案最多 1 段。
```

## 3. 解题思路

### 3.1 暴力思路：区间调度模型

把每个平衡装运看成一个区间 $[a, b]$（满足 $b > a$ 且 $\text{weight}[b] < \max(\text{weight}[a..b])$），问题就是经典的**不重叠区间选最多**（活动调度）：设 $f(i)$ 为前缀 $[0..i)$ 的最大装运数，枚举最后一段的终点转移。但平衡区间可多达 $O(n^2)$ 个——$n = 10^5$ 时约 $5 \times 10^9$ 个，光枚举就已超时，$O(n^2)$ 的 DP 无法承受，必须找到 $O(n \log n)$ 以内的做法。

### 3.2 核心观察：左扩展不变性与「最早闭合」贪心

![平衡装运向左扩展仍是平衡装运](images/wc461_q2_left_extend_insight.svg)

两个关键观察把问题变成一遍扫描：

1. **左扩展不变性**：平衡装运向左并入更多包裹后**仍然平衡**——末尾元素不动，而段最大值只增不减，即 $\max(w[a'..b]) \ge \max(w[a..b]) > w[b]$。
2. **最早闭合点可线性定位**：活动调度的贪心策略是「每次选结束最早的区间」。由观察 1，想知道**从当前位置出发结束最早的平衡装运**，根本不必枚举起点——直接从当前位置向右扫描，维护段内前缀最大值 `curMax`，**第一次遇到 $w < \text{curMax}$ 的位置就是全局最早的结束位置**。

闭合一段后，剩余后缀是**同结构的子问题**（仍是"从某断点向右找最早闭合点"），于是得到线性贪心：**能闭合就尽早闭合**。

> 💡 一句话：`curMax` 是"当前未闭合段中已扫部分的最大值"；出现比它小的元素，说明段内存在严格更大的包裹，末尾就落在它身上，立即闭合、从头再来。

### 3.3 算法流程

![算法流程：一遍扫描，能闭合就尽早闭合](images/wc461_q2_algorithm_flow.svg)

1. 初始化 `ans = 0`，`curMax = 0`（哨兵，小于任何重量）；
2. 从左到右遍历每个重量 $w$：
   - 若 $w < \text{curMax}$：当前段 $[\text{start}..i]$ 平衡，`ans += 1`，闭合该段，`curMax = 0`（下一段从 $i+1$ 重新统计）；
   - 否则：`curMax = w`，刷新段内最大值；
3. 扫描结束，返回 `ans`。末尾未能闭合的残留元素直接丢弃（允许部分包裹不被装运）。

### 3.4 示例演算

![示例 [2,5,1,4,3] 的逐步演算表](images/wc461_q2_example_walkthrough.svg)

`weight = [2,5,1,4,3]`：

| i | w | curMax（判断前） | 判断 | 动作 | ans |
|---|---|------------------|------|------|-----|
| 0 | 2 | 0 | 2 < 0 ✗ | curMax = 2 | 0 |
| 1 | 5 | 2 | 5 < 2 ✗ | curMax = 5 | 0 |
| 2 | 1 | 5 | 1 < 5 ✓ | **闭合 [2,5,1]**，curMax = 0 | 1 |
| 3 | 4 | 0 | 4 < 0 ✗ | curMax = 4 | 1 |
| 4 | 3 | 4 | 3 < 4 ✓ | **闭合 [4,3]**，curMax = 0 | 2 |

返回 `ans = 2`，与示例一致。

## 4. 算法细节

1. **curMax 的语义**：处理 $\text{weight}[i]$ 时，`curMax` 恰为 $\max(\text{weight}[\text{start}..i-1])$，其中 `start` 是当前段的起点（上一次闭合点的下一个位置）。判断 $\text{weight}[i] < \text{curMax}$ 等价于「$[\text{start}..i]$ 是平衡装运」。
2. **闭合后的重置**：`curMax = 0` 安全——因为 $\text{weight}[i] \ge 1 > 0$，下一个元素必然走更新分支、成为新段的初始最大值，恰好实现"下一段从 $i+1$ 开始"；用 $-\infty$ 哨兵同理。
3. **首个元素必然是更新分支**：初始 `curMax = 0 < weight[0]`，天然处理了段起点，无需特判。
4. **只比较、无运算**：重量上限 $10^9$，全程只做比较不累加，`int` 即可，无溢出风险。
5. **答案上界 $\lfloor n/2 \rfloor$**：每个平衡装运长度至少为 2（单元素装运的末尾恒等于段最大值），互不重叠的 $k$ 段至少覆盖 $2k$ 个位置。可作对拍时的 sanity check。

## 5. 正确性证明

**引理 1（左扩展不变性）**：若 $[a..b]$ 是平衡装运，则对任意 $a' \le a$，$[a'..b]$ 也是平衡装运。

**证明**：$\max(w[a'..b]) \ge \max(w[a..b]) > w[b]$，末尾 $w[b]$ 仍严格小于新段最大值。∎

**引理 2（最早闭合点）**：设当前段起点为 $s$（初始 $s=0$，每次闭合后更新为闭合点 $+1$）。若存在某个平衡装运 $[a..b]$ 满足 $a \ge s$，则贪心会在某个 $e \le b$ 处闭合，且 $[s..e]$ 是平衡装运。

**证明**：由 $a \ge s$ 及引理 1，$[s..b]$ 是平衡装运，故 $w[b] < \max(w[s..b])$，集合 $\{\, i > s : w[i] < \max(w[s..i]) \,\}$ 非空（至少含 $b$）。设 $e$ 为其中最小者，则 $e \le b$；贪心从 $s$ 起维护 `curMax`，恰在第一个满足该条件的位置闭合，即闭合于 $e$，且 $[s..e]$ 平衡。∎

**定理（贪心最优）**：上述贪心得到的装运数 $k$ 等于最大装运数 $m$。

**证明**：贪心解合法（每段按构造平衡、下一段起点恰为上一闭合点 $+1$，互不重叠），故 $k \le m$。再证 $k \ge m$：取任意最优解 $\text{OPT} = \{O_1, \dots, O_m\}$（按终点从左到右排列），对 $t = 0, 1, \dots, m$ 归纳证明命题 $P(t)$：存在 $m$ 个装运的合法解，其前 $t$ 个装运恰为贪心的前 $t$ 段 $G_1, \dots, G_t$（终点 $e_1 < \dots < e_t$）。

- $P(0)$ 平凡成立。
- 设 $P(t)$ 成立且 $t < m$：$\text{OPT}_{t+1} = [a..b]$ 与前 $t$ 段不重叠，故 $a \ge e_t + 1$。由引理 2（取 $s = e_t + 1$），贪心存在第 $t+1$ 次闭合 $G_{t+1} = [e_t+1..e_{t+1}]$ 且 $e_{t+1} \le b$。将 $O_{t+1}$ 替换为 $G_{t+1}$：它与前 $t$ 段不重叠（起点 $e_t + 1$），与 $O_{t+2}, \dots, O_m$ 也不重叠（终点 $e_{t+1} \le b <$ 后续装运起点），替换后仍是 $m$ 段合法解，即 $P(t+1)$ 成立。

归纳至 $t = m$：每一步归纳都推出「贪心能再闭合一次」，故贪心至少闭合 $m$ 次，$k \ge m$。综上 $k = m$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。每个元素被访问一次，每次只做一次比较和赋值。
- **空间复杂度**：$O(1)$。仅使用 `ans`、`curMax` 两个变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maxBalancedShipments(vector<int>& weight) {
        int ans = 0, curMax = 0;
        for (int w : weight) {
            if (w < curMax) {
                ans++;
                curMax = 0;
            } else {
                curMax = w;
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maxBalancedShipments(self, weight: List[int]) -> int:
        ans, cur_max = 0, 0
        for w in weight:
            if w < cur_max:
                ans += 1
                cur_max = 0
            else:
                cur_max = w
        return ans
```

## 8. 边界情况与易错点

1. **严格小于，不是 ≤**：`[4,4]` 无平衡装运，答案 0；若误写成 `<=`，`[4,4]` 会在第二个 4 处被错误闭合，答案错成 1。
2. **全递增 / 全相等数组答案为 0**：任何后缀的末尾元素都是（或等于）段内最大值，永远无法闭合。
3. **闭合后 curMax 必须归零**：闭合位置的包裹已属于刚结束的装运，切勿把它计入下一段的最大值统计；归零后下一个元素自然成为新段初始最大值。
4. **末尾残留直接丢弃**：扫描结束时未闭合的尾巴（如 `[4,3]` 之后再接一个 `10`）不影响答案，无需处理。
5. **无溢出**：只比较不累加，$10^9$ 用 `int` 即可；Python 无此顾虑。
6. **对拍校验**：答案不超过 $\lfloor n/2 \rfloor$；随机小数据可用 $O(n^2)$ 区间 DP 暴力对拍验证贪心。
