# LeetCode 三段式数组 II 题解

## 1. 题目概述

- **标题 / 题号**：三段式数组 II（#3640，hard）
- **链接**：https://leetcode.cn/problems/trionic-array-ii/
- **来源**：LeetCode 第 461 场周赛 Q4
- **难度**：困难
- **标签**：数组、动态规划、状态机 DP、最大子数组和（Kadane 推广）

**题意**：给定长度为 $n$ 的整数数组 $nums$。连续子数组 $nums[l..r]$（$0 \le l < r < n$）称为**三段式子数组**，若存在下标 $l < p < q < r$，使得 $nums[l..p]$ 严格递增、$nums[p..q]$ 严格递减、$nums[q..r]$ 严格递增。求**所有**三段式子数组的**元素和的最大值**。

**约束**：

- $4 \le n \le 10^5$
- $-10^9 \le nums[i] \le 10^9$
- 保证至少存在一个三段式子数组

> 💡 **审题关键**：① 三段**共享端点**——峰 $p$、谷 $q$ 各被相邻两段各计一次，且 $l < p < q < r$ 是四个**互异**下标，故每段长度都 $\ge 2$，最短窗口只有 4 个元素（示例 2 正是如此）；② 求的是**和最大**而非最长——数组可以全负（示例 1 答案为 $-4$），这决定了必须引入「Kadane 式重启」；③「严格」二字意味着**相邻相等元素会同时打断递增与递减**，这是转移里最易漏的分支。

## 2. 示例

**示例 1**

```text
输入：nums = [0,-2,-1,-3,0,2,-1]
输出：-4
解释：取 l=1, p=2, q=3, r=5，窗口 [-2,-1,-3,0,2]：
      [-2,-1] 严格递增，[-1,-3] 严格递减，[-3,0,2] 严格递增，
      和 = -4。数组几乎全负，答案也是负数。
```

**示例 2**

```text
输入：nums = [1,4,2,7]
输出：14
解释：取 l=0, p=1, q=2, r=3——最短的合法窗口（恰好 4 个元素），
      整个数组都被选上，和 = 1+4+2+7 = 14。
```

**示例 3（自拟，演示「负前缀要丢」）**

```text
输入：nums = [-100,1,5,3,6,-100]
输出：15
解释：最优窗口是 [1..4]：[1,5] 递增、[5,3] 递减、[3,6] 递增，和 = 15。
      两端的 -100 虽然能被单调性容纳，却只会拖累总和——
      左右端点都不必取「能延伸到的最远处」。
```

## 3. 解题思路

### 3.1 暴力思路：枚举四个端点

最朴素的做法是枚举 $(l, p, q, r)$ 四元组并逐一检验三段单调性，$O(n^4)$。稍加优化：预处理「以 $i$ 结尾的最大和严格上升段」「以 $i$ 开头的最大和严格上升段」后，只需枚举峰谷对 $(p, q)$（要求 $nums[p..q]$ 严格递减），左右两段的最优端点可直接查表，降到 $O(n^2)$。但 $n = 10^5$ 时 $O(n^2)$ 仍是 $10^{10}$ 量级，不可行。

> ⚠️ 暴力留给我们的真正启示是：**固定峰谷后，最优 $l$ 只依赖 $p$、最优 $r$ 只依赖 $q$**。既然每个自由度的最优解都只挂在一个端点上，就应该把「形状进度」全部压进「以 $i$ 结尾」的一趟扫描——这正是正解的形态。

### 3.2 核心观察：把「形状」编码成状态机

![三段式形状：严格递增 → 严格递减 → 严格递增，三段共享峰 p 与谷 q](images/wc461_q4_trionic_shape.svg)

三段式子数组的形状是**增（$\ge 2$）→ 降（$\ge 2$）→ 增（$\ge 2$）**。从左到右扫描数组，任何时刻一个「正在搭建中」的窗口必定处于以下四个**进度**之一：

| 进度 | 含义 | 对应形状 |
|------|------|----------|
| $f_1$ | 处于第一段上升中 | 上升段，长度 $\ge 1$ |
| $f_2$ | 第一段上升长度已达 2 | 上升段，长度 $\ge 2$（**峰候选**） |
| $f_3$ | 已越过峰、处于下降段 | 增（$\ge 2$）+ 降（$\ge 2$）（**谷候选**） |
| $f_4$ | 已越过谷、处于第三段上升 | 完整三段式（**可作为答案**） |

这本质上是**最大子数组和（Kadane）的状态机推广**：Kadane 只需一个状态 $f = \max(x,\ f + x)$，本题用四个状态编码「形状搭建进度」，状态间的转移由**相邻元素的大小关系**驱动——升则推进形状、降则推进形状、相等则推倒重来。

又因为数组可负，「和最大」要求 Kadane 式的**丢弃负前缀**能力：$f_1$ 可以随时重启（示例 3 中丢掉 $-100$）；但 $f_2, f_3, f_4$ 对应的形状无法凭空产生，断档即为 $-\infty$，**绝不能与 $0$ 取 max**（示例 1 全负时答案就是负数）。

### 3.3 状态设计与转移方程

![状态机 DP：f1 → f2 → f3 → f4，转移由相邻元素大小关系驱动](images/wc461_q4_state_machine.svg)

设 $f_j[i]$ 为所有「以 $i$ 结尾、形状进度为 $j$」的子数组的最大和（不存在则记 $-\infty$）。记 $x = nums[i]$，$prev = nums[i-1]$，转移只看 $x$ 与 $prev$ 的大小关系：

$$
\begin{aligned}
x > prev:\quad & f_1 = x + \max(0,\ f_1), \qquad && f_2 = x + f_1^{旧}, \qquad && f_4 = x + \max(f_3,\ f_4) \\
x < prev:\quad & f_3 = x + \max(f_2,\ f_3), \qquad && \text{其余状态清空为 } -\infty \\
x = prev:\quad & \text{仅剩 } f_1 = x，\text{其余清空为 } -\infty
\end{aligned}
$$

**答案** $= \max\limits_{i}\ f_4[i]$（题目保证存在，无需判无解）。

逐项解读四个转移来源：

1. **$f_1 = x + \max(0, f_1)$**：上升时既可延长旧段、也可在 $i$ 处重启单元素段（旧段和为负就丢，Kadane 核心）；不上升则只能 $f_1 = x$。
2. **$f_2 = x + f_1^{旧}$**：上升段长度达到 $\ge 2$ 的唯一方式是把「以 $i-1$ 结尾的上升段（长 $\ge 1$）」延长一步。**没有 $f_2$ 自环**：长度 $\ge 2$ 的上升段也是长度 $\ge 1$ 的上升段，$f_1 \ge f_2$ 恒成立，$x + f_1$ 已支配 $x + f_2$。
3. **$f_3 = x + \max(f_2, f_3)$**（要求 $x < prev$）：$f_2$ 项 = 峰恰在 $i-1$，下降段 $[i-1, i]$ 长度恰为 2；$f_3$ 项 = 下降段继续延长（谷候选维持）。
4. **$f_4 = x + \max(f_3, f_4)$**（要求 $x > prev$）：$f_3$ 项 = 谷恰在 $i-1$，第三段 $[i-1, i]$ 长度恰为 2；$f_4$ 项 = 第三段继续延长。第三段长度 $\ge 2$ 的约束恰好编码了 $q < r$。

### 3.4 示例演算

![示例 1 走查：数组、选中窗口与四个状态逐位置的取值表](images/wc461_q4_example_walkthrough.svg)

以示例 1 `nums = [0, -2, -1, -3, 0, 2, -1]` 走查（"—"表示 $-\infty$）：

| $i$ | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
|------|---|----|----|----|---|---|----|
| $x$ | 0 | −2 | −1 | −3 | 0 | 2 | −1 |
| $f_1$ | 0 | −2 | −1 | −3 | 0 | 2 | −1 |
| $f_2$ | — | — | −3 | — | −3 | 2 | — |
| $f_3$ | — | — | — | −6 | — | — | 1 |
| $f_4$ | — | — | — | — | −6 | **−4** | — |

- $i=2$：$-1 > -2$，$f_2 = -1 + f_1[1] = -3$（上升段 $[-2,-1]$，峰就绪）；
- $i=3$：$-3 < -1$，$f_3 = -3 + f_2[2] = -6$（越过峰，窗口 $[-2,-1,-3]$）；
- $i=4$：$0 > -3$，$f_4 = 0 + f_3[3] = -6$（越过谷，窗口 $[-2,-1,-3,0]$ 完整）；
- $i=5$：$2 > 0$，$f_4 = 2 + f_4[4] = -4$（尾段延长，窗口 $[1..5]$）。

$\max f_4 = -4$，与预期一致。注意 $i=6$ 处 $f_3 = -1 + f_2[5] = 1$ 又搭出一个新的「峰后下降」进度（窗口 $[0,2,-1]$），但它后面再无元素完成第三段——这正是「答案取历史最大、而非末位置」的原因。

## 4. 算法细节

1. **滚动变量 + 旧值语义**：四个状态只依赖上一位置，用 4 个变量即可。转移必须**全部使用旧值**——尤其 $f_2 = x + f_1^{旧}$，若先更新 $f_1$ 再算 $f_2$，会把「以 $i$ 结尾的段」错接到自己身上。Python 用元组赋值天然安全；C++ 用临时变量 `nf1..nf4` 统一提交（或按 $f_4 \to f_3 \to f_2 \to f_1$ 的顺序原地更新）。
2. **$-\infty$ 哨兵的安全用法**：C++ 用 `LLONG_MIN` 时**不能**直接加 $x$（有符号溢出是 UB），必须先判断「状态存在」再相加；Python 的 `float('-inf')` 则天然安全。
3. **溢出**：窗口和最大可达 $10^5 \times 10^9 = 10^{14}$，远超 32 位——C++ 全程 `long long`（官方函数签名即返回 `long long`）。
4. **初始化**：$f_1[0] = nums[0]$（单元素段恒存在），$f_2 = f_3 = f_4 = -\infty$，从 $i = 1$ 开始扫描；每个 $i$ 处理完后用 $f_4$ 更新答案。
5. **答案位置任意**：窗口可在任意下标结束，答案是对全部 $i$ 取 $\max$，而不是 $f_4[n-1]$。

## 5. 正确性证明

**引理 1（形状等价）**：$nums[l..r]$ 是三段式子数组 $\iff$ 它可拆成「上升段（长 $\ge 2$）+ 下降段（长 $\ge 2$）+ 上升段（长 $\ge 2$）」且三段首尾相接（共享峰、谷）。

**证明**：三段式定义中 $l < p < q < r$ 恰好等价于 $p - l \ge 1$、$q - p \ge 1$、$r - q \ge 1$，即三段长度分别为 $p-l+1 \ge 2$、$q-p+1 \ge 2$、$r-q+1 \ge 2$。反之，任何这样的三段拼接取 $p$、$q$ 为共享端点即满足定义。∎

**引理 2（可实现性——无虚值）**：若 $f_j[i] > -\infty$，则存在一个以 $i$ 结尾、满足进度 $j$ 对应形状的子数组，其元素和恰为 $f_j[i]$。

**证明**：对 $i$ 归纳。$i = 0$ 时 $f_1[0] = nums[0]$ 是长度 1 的上升段。设对 $i-1$ 成立，考察 $i$：

- $f_1$：若 $x \le prev$，取单元素段 $[i..i]$。若 $x > prev$：取 $0$ 时对应单元素段；取 $f_1[i-1]$ 时，由归纳假设存在以 $i-1$ 结尾的上升段 $W$，其末元素 $nums[i-1] < x$，故 $W \cup \{i\}$ 仍严格上升，和为 $f_1[i-1] + x = f_1[i]$。
- $f_2$（$x > prev$）：$f_2[i] = x + f_1[i-1]$，归纳假设给出以 $i-1$ 结尾、长 $\ge 1$ 的上升段 $W$，$W \cup \{i\}$ 长度 $\ge 2$ 且严格上升，和恰为 $f_2[i]$。
- $f_3$（$x < prev$）：取 $f_2[i-1]$ 时，$W$ 是以 $i-1$ 结尾、长 $\ge 2$ 的上升段，$W \cup \{i\}$ 中 $nums[i-1] > x$，构成「增（$\ge 2$）+ 降（$\ge 2$）」；取 $f_3[i-1]$ 时，$W$ 已是该形状且末元素处于下降段，延长一步后下降段仍长 $\ge 2$ 且严格下降。两 case 的和都等于转移式的值。
- $f_4$（$x > prev$）：取 $f_3[i-1]$ 时，$W$ 以谷 $i-1$ 结尾，$W \cup \{i\}$ 的第三段 $[i-1, i]$ 长度恰 2 且严格上升；取 $f_4[i-1]$ 时，$W$ 已完整，第三段延长后仍长 $\ge 2$ 且严格上升。∎

**引理 3（支配性——无漏值）**：设 $W = nums[l..i]$ 是以 $i$ 结尾、满足进度 $j$ 形状的任一子数组，则 $\mathrm{sum}(W) \le f_j[i]$。

**证明**：对 $i$ 归纳，按形状讨论其前缀 $W' = nums[l..i-1]$ 的归属：

- 进度 1（上升段长 $\ge 1$）：若 $l = i$ 则 $\mathrm{sum}(W) = x \le f_1[i]$；若 $l < i$ 则 $x > prev$ 且 $W'$ 是以 $i-1$ 结尾的上升段，$\mathrm{sum}(W') \le f_1[i-1]$，故 $\mathrm{sum}(W) \le x + f_1[i-1] \le x + \max(0, f_1[i-1]) = f_1[i]$。
- 进度 2（上升段长 $\ge 2$）：必有 $l \le i-1$、$x > prev$，$W'$ 是以 $i-1$ 结尾、长 $\ge 1$ 的上升段，$\mathrm{sum}(W) \le x + f_1[i-1] = f_2[i]$。
- 进度 3（增 + 降，降段长 $\ge 2$，$x < prev$）：设峰为 $p$。若 $p = i-1$，$W'$ 是以 $i-1$ 结尾、长 $\ge 2$ 的上升段，$\mathrm{sum}(W') \le f_2[i-1]$；若 $p \le i-2$，$W'$ 是以 $i-1$ 结尾的「增 + 降（降段长 $\ge 2$）」，$\mathrm{sum}(W') \le f_3[i-1]$。两种情况 $\mathrm{sum}(W) \le x + \max(f_2[i-1], f_3[i-1]) = f_3[i]$。
- 进度 4（完整三段式，$x > prev$）：设谷为 $q$。若 $q = i-1$，$W'$ 是进度 3 形状，$\mathrm{sum}(W') \le f_3[i-1]$；若 $q \le i-2$，$W'$ 已是完整三段式（第三段长 $\ge 2$），$\mathrm{sum}(W') \le f_4[i-1]$。故 $\mathrm{sum}(W) \le x + \max(f_3[i-1], f_4[i-1]) = f_4[i]$。∎

**定理**：算法返回的 $\max_i f_4[i]$ 等于所有三段式子数组的最大和。

**证明**：由引理 1，三段式子数组恰是进度 4 形状。一方面，由引理 2，每个有限的 $f_4[i]$ 都是某个三段式子数组的真实和，故 $\max_i f_4[i]$ 不超过最优解；另一方面，由引理 3，任意三段式子数组的和不超过其右端点处的 $f_4$，从而不超过 $\max_i f_4[i]$。两个不等式夹逼即得相等；又因题目保证至少存在一个三段式子数组，$\max_i f_4[i]$ 有限。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。单趟扫描，每个位置只做常数次比较与加减。
- **空间复杂度**：$O(1)$。仅 4 个滚动变量与答案变量，无需数组。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long maxSumTrionic(vector<int>& nums) {
        const long long NEG = LLONG_MIN;
        long long f1 = nums[0], f2 = NEG, f3 = NEG, f4 = NEG, ans = NEG;
        for (int i = 1; i < (int)nums.size(); ++i) {
            long long x = nums[i], prev = nums[i - 1];
            long long nf1, nf2 = NEG, nf3 = NEG, nf4 = NEG;
            if (x > prev) {                      // 上升：推进 f1/f2/f4
                nf1 = f1 > 0 ? x + f1 : x;       // max(x, x + f1)：可重启
                nf2 = x + f1;                    // f1 恒存在，无需判空
                if (f3 != NEG || f4 != NEG)      // -inf 不可直接相加
                    nf4 = x + max(f3, f4);
            } else if (x < prev) {               // 下降：推进 f3
                nf1 = x;
                if (f2 != NEG || f3 != NEG)
                    nf3 = x + max(f2, f3);
            } else {                             // 相等：严格性被破坏
                nf1 = x;                         // 全部断裂，仅 f1 重启
            }
            f1 = nf1; f2 = nf2; f3 = nf3; f4 = nf4;
            ans = max(ans, f4);
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maxSumTrionic(self, nums):
        NEG = float('-inf')
        f1 = nums[0]
        f2 = f3 = f4 = NEG
        ans = NEG
        for i in range(1, len(nums)):
            x, prev = nums[i], nums[i - 1]
            if x > prev:
                f1, f2, f3, f4 = x + max(0, f1), x + f1, NEG, x + max(f3, f4)
            elif x < prev:
                f1, f2, f3, f4 = x, NEG, x + max(f2, f3), NEG
            else:
                f1, f2, f3, f4 = x, NEG, NEG, NEG
            ans = max(ans, f4)
        return ans
```

## 8. 边界情况与易错点

1. **答案可以是负数**（示例 1 返回 $-4$）：绝不能用 $0$ 做答案下界。只有 $f_1$ 允许 Kadane 式重启（$\max(0,\cdot)$），$f_2, f_3, f_4$ 断档即 $-\infty$——若手滑对它们也取 $\max(0, \cdot)$，全负用例立刻 WA。
2. **相邻相等元素**：既不满足严格增也不满足严格减，$f_2, f_3, f_4$ 全部断裂、只剩 $f_1 = x$。漏写 $x = prev$ 分支（误并入 $>$ 或 $<$）是高频错误。
3. **转移必须用旧值**：同一轮里先更新 $f_1$ 再算 $f_2 = x + f_1$，会把新值当旧值用，导致「自己接自己」。用临时变量或元组赋值。
4. **溢出**：窗口和可达 $10^{14}$，C++ 必须用 `long long`；`LLONG_MIN` 哨兵不可直接参与加法（UB），先判存在性。
5. **答案取历史最大**：$\max_i f_4[i]$ 而非 $f_4[n-1]$——窗口可在任何位置结束（走查中 $i=6$ 新搭的进度就没能完成）。
6. **每段长度 $\ge 2$ 不是 $\ge 1$**：$l < p < q < r$ 强制三段长度都至少为 2。若误把进度设成「三段各 $\ge 1$」，会把 3 元素窗口（如 $[1,2,1]$）误判为合法。
7. **为什么 $f_2$ 没有自环**：长 $\ge 2$ 的上升段被 $f_1$ 支配（$f_1 \ge f_2$），转移 $x + f_1$ 已覆盖延长情形。多写一个 $x + f_2$ 分支不影响正确性，但说明尚未看透状态间的支配关系。

- [LeetCode 3637. 三段式数组 I](https://leetcode.cn/problems/trionic-array-i/)：同场 Q1 的判定版（整条数组是否三段式），本题是其「最大和子数组」强化。

**延伸思考**：① 改求**最长**三段式子数组（长度而非和）：同一状态机改维护最大长度，转移条件不变；② 段数推广为 $k$ 段交替（$k-1$ 个转折）：状态数变 $k$，$O(kn)$；③ 「严格」改「非严格」：相等元素不再断裂，但峰谷可能退化为平台，$l < p < q < r$ 的存在性需重新审视；④ 多次静态询问区间 $[L, R]$ 内的最大三段式和：仿「最大子段和」线段树，节点维护区间内各部分形状的最优值及两端单调 run 信息做拼接合并，可做但字段繁多。
