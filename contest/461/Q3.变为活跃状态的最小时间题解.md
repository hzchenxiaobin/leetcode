# LeetCode 变为活跃状态的最小时间 题解

## 1. 题目概述

- **标题 / 题号**：变为活跃状态的最小时间（#3639，medium）
- **链接**：https://leetcode.cn/problems/minimum-time-to-activate-string/
- **来源**：LeetCode 第 461 场周赛 Q3
- **难度**：中等
- **标签**：数组、二分查找、计数、有序集合

**题意**：给定长度为 $n$ 的字符串 $s$ 与整数数组 $order$（$[0, n-1]$ 的一个**排列**）。从时刻 $t = 0$ 开始，每个时间点把 $s[order[t]]$ 替换为 `'*'`。一个子串只要**含有至少一个** `'*'` 就称为**有效**子串；当整个字符串的有效子串总数 $\ge k$ 时称为**活跃**。返回**首次**变为活跃的时刻 $t$；若永远无法活跃，返回 $-1$。

**约束**：

- $1 \le n = s.length \le 10^5$
- $order.length = n$，$order$ 是 $[0, n-1]$ 的排列
- $s$ 由小写英文字母组成
- $1 \le k \le 10^9$

> 💡 **审题关键**：① 时刻 $t$ 表示**已完成前 $t+1$ 次替换**（$order[0..t]$ 皆已变 `'*'`），所以 $t=0$ 就可能已活跃（示例 1 答案为 0）；② 子串按**位置**计数、不去重——长度 $n$ 的串共有 $\frac{n(n+1)}{2}$ 个子串；③ $s$ 的字母内容毫无用处，只关心「哪些位置何时变 `'*'`」；④ $\frac{n(n+1)}{2}$ 可达约 $5 \times 10^9$，**C++ 必须用 64 位整数**。

## 2. 示例

**示例 1**

```text
输入：s = "abc", order = [1,0,2], k = 2
输出：0
解释：t=0 时 order[0]=1，s 变为 "a*c"。
      有效子串 "*"、"a*"、"*c"、"a*c" 共 4 个 ≥ 2，立刻活跃。
```

**示例 2**

```text
输入：s = "cat", order = [0,2,1], k = 6
输出：2
解释：t=0 → "*at"（有效 3 个）；t=1 → "*a*"（有效 5 个）；
      t=2 → "***"（全部 6 个子串有效）→ 首次达到 6。
```

**示例 3**

```text
输入：s = "xy", order = [0,1], k = 4
输出：-1
解释：全部替换后也只有 n(n+1)/2 = 3 个子串，永远到不了 4。
```

## 3. 解题思路

### 3.1 暴力思路：逐时刻从零重算

最直接的做法：枚举 $t$ 从 $0$ 到 $n-1$，每个 $t$ 构造替换后的串，枚举全部 $O(n^2)$ 个子串判是否含 `'*'`（借助 `'*'` 个数前缀和可把单个判定降到 $O(1)$），总复杂度 $O(n^3)$；即便每个 $t$ 用一遍扫描统计段长，也是 $O(n^2)$。$n = 10^5$ 时约 $10^{10}$ 次操作，不可行。

> ⚠️ 更深层的问题在于：这个框架完全无视了题目的关键结构——时刻每推进一步**只是多一个 `'*'`**，有效子串数只会增加、不会减少。这个**单调性**才是突破口。

### 3.2 核心观察：单调性 ⇒ 二分；正难则反 ⇒ O(n) 计数

![正难则反：'*' 把串切成若干极大无 '*' 段，有效子串数 = 总数 − Σ L(L+1)/2](images/wc461_q3_runs_count.svg)

**观察一（单调性——可以二分答案）**：设 $f(t)$ 为时刻 $t$ 的有效子串总数。从 $t$ 到 $t+1$ 只是多替换一个字符为 `'*'`：原先有效的子串依然有效，原先无效的子串可能翻转为有效。因此 $f(t)$ 关于 $t$ **单调不减**，「最小的满足 $f(t) \ge k$ 的 $t$」是标准的**二分答案**模型。

**观察二（正难则反——总数减无效）**：直接数「含至少一个 `'*'`」的子串，需要按 `'*'` 的位置做容斥，边界繁琐；反过来数**无效**子串则异常干净：

> 一个子串无效 $\iff$ 它**整段落入某段「极大无 `'*`' 连续区间」内部**。

设某段长度为 $L$，其内部子串（按位置）恰有 $\frac{L(L+1)}{2}$ 个，于是

$$f(t) = \frac{n(n+1)}{2} - \sum_{\text{各极大无 '*' 段}} \frac{L_i(L_i+1)}{2}$$

一次线性扫描即可求出：把 $order[0..t]$ 标记为 `'*'`，扫一遍统计各段连续非 `'*'` 位置的长度。

### 3.3 算法流程：二分答案

![算法流程：算总数判无解 → 二分 t → check 标记加扫描 → 收缩区间](images/wc461_q3_binary_flow.svg)

| 步骤 | 操作 | 说明 |
|------|------|------|
| ① 预判 | $total \leftarrow \frac{n(n+1)}{2}$，若 $total < k$ 返回 $-1$ | 全 `'*'` 也凑不够 $k$ 个 |
| ② 初始化 | $lo = 0$，$hi = n-1$ | 不变式：$f(hi) \ge k$ 恒成立 |
| ③ 取中 | $mid = \lfloor (lo+hi)/2 \rfloor$ | —— |
| ④ check | 标记 $order[0..mid]$，扫描各段长 $L_i$，$valid = total - \sum \frac{L_i(L_i+1)}{2}$ | $O(n)$ |
| ⑤ 收缩 | $valid \ge k$ 则 $hi = mid$，否则 $lo = mid + 1$ | 找**最小**可行 $t$ |
| ⑥ 终止 | $lo = hi$ 时返回 $lo$ | 即首个活跃时刻 |

### 3.4 进阶：增量贡献 $(p-a)(b-p)$——一遍扫描免二分

![进阶：新 '*' 落在 p，左右最近旧 '*' 为 a、b，新增有效子串 (p−a)(b−p) 个](images/wc461_q3_increment_contribution.svg)

换一个视角：**每个子串在它遇到的第一个 `'*'` 出现的那一刻被计入**。设时刻 $t$ 新替换的位置为 $p = order[t]$，$a$、$b$ 是此前已替换位置中 $p$ 的前驱与后继（不存在则取哨兵 $-1$ 与 $n$），那么**恰在此刻变为有效**的子串 $[l, r]$ 必须满足 $a < l \le p \le r < b$——左端点有 $p - a$ 种、右端点有 $b - p$ 种，故

$$f(t) = f(t-1) + (p-a)(b-p)$$

按 $t$ 从小到大扫一遍、用一个**有序集合**维护已替换位置，每步查前驱后继即可，整体 $O(n \log n)$ 且无需二分。以示例 2（$k=6$）走查：$\Delta f$ 依次为 $3, 2, 1$，$f$ 依次为 $3 \to 5 \to 6$，首达 $6$ 于 $t = 2$，与答案一致。

> 💡 两条路殊途同归：把 $A = p-a$、$B = b-p$ 代入观察二，$\frac{(A+B-1)(A+B)}{2} - \frac{(A-1)A}{2} - \frac{(B-1)B}{2} = AB$，正是增量公式。二分版好想好写，增量版一遍出解，都是赛时可行解。

## 4. 算法细节

1. **check 的哨兵写法**：扫描循环写成 `i <= n`，用 `i == n` 充当哨兵把最后一段 `run` 顺手结算，避免循环外补一行。
2. **二分安全的前提**：第 ① 步先判 $total < k$ 返回 $-1$，此后 $f(n-1) = total \ge k$ 恒成立，二分区间内答案必然存在，`hi = mid` 的写法（而非 `hi = mid - 1`）保证收敛到**最小**可行 $t$。
3. **溢出**：$n = 10^5$ 时 $total \approx 5 \times 10^9$，单个长段的 $\frac{L(L+1)}{2}$ 同量级，均超 32 位有符号上界——C++ 乘法前先写 `1LL`；比较两边统一为 `long long`。
4. **增量版的哨兵**：有序集合初始放入 $-1$ 与 $n$，新星落在边界（$p=0$ 或 $p=n-1$）时无需特判。
5. **标记数组复用**：二分各轮之间 `starred` 只 `fill` 清零、不重新分配，降低常数。
6. **Python 无现成有序集合**：`bisect.insort` 是 $O(n)$ 插入，最坏退化到 $O(n^2)$；替代方案是把时间**倒过来**——从 $t = n-1$（全 `'*'`，$f = total$）开始回退，用**双向链表**维护当前 `'*'` 位置集合，回退 $order[t]$ 时其链表邻居恰为 $a$、$b$，$O(1)$ 完成一次更新，整体 $O(n)$。

## 5. 正确性证明

**引理 1（单调性）**：$f(0) \le f(1) \le \dots \le f(n-1)$。

**证明**：时刻 $t$ 的 `'*'` 位置集合 $S_t \subseteq S_{t+1}$。若子串在 $t$ 有效，则它含 $S_t$ 中某位置，该位置也属于 $S_{t+1}$，故在 $t+1$ 仍有效。即有效子串集合随 $t$ 单调递增，计数不减。∎

**引理 2（计数公式）**：设时刻 $t$ 的 `'*'` 把 $s$ 切成若干极大无 `'*'` 段，长度为 $L_1, \dots, L_m$，则 $f(t) = \frac{n(n+1)}{2} - \sum_i \frac{L_i(L_i+1)}{2}$。

**证明**：子串与位置对 $(l, r)$（$l \le r$）一一对应，共 $\frac{n(n+1)}{2}$ 对。子串无效 $\iff$ $[l, r]$ 不含任何 `'*'` $\iff$ $[l, r]$ 整段落入某极大无 `'*'` 段。极大段互不相交，每个无效子串恰属于一段；长 $L$ 的段内位置对恰 $\frac{L(L+1)}{2}$ 个。总数减无效即得。∎

**定理 1（二分正确性）**：若 $\frac{n(n+1)}{2} \ge k$，算法返回 $t^* = \min\{\, t : f(t) \ge k \,\}$；否则返回 $-1$。

**证明**：若 $total < k$：$t = n-1$ 时全部位置为 `'*'`，无残留段，由引理 2 $f(n-1) = total < k$，任何时刻都不活跃，返回 $-1$ 正确。否则 $f(n-1) = total \ge k$，$t^*$ 存在。二分过程中维护不变式「$f(hi) \ge k$ 且 $t^* \in [lo, hi]$」：初始由 $f(hi) = f(n-1) \ge k$ 成立；每次 `check(mid)` 依引理 2 正确判定 $f(mid) \ge k$，为真则 $t^* \le mid$，收缩 $hi = mid$ 后不变式保持，为假则 $t^* > mid$，收缩 $lo = mid + 1$ 后亦保持。区间长度严格递减，终止时 $lo = hi = t^*$。∎

**引理 3（增量公式）**：设时刻 $t$ 替换位置 $p = order[t]$，$a$ 为 $S_{t-1}$ 中小于 $p$ 的最大元素（不存在取 $-1$），$b$ 为大于 $p$ 的最小元素（不存在取 $n$），则 $f(t) - f(t-1) = (p-a)(b-p)$。

**证明**：子串在 $t$ 首次生效 $\iff$ 它含 $p$ 但不含 $S_{t-1}$ 中任何位置 $\iff$ $l \in (a, p]$ 且 $r \in [p, b)$。这样的位置对恰 $(p-a)(b-p)$ 个。也可由引理 2 代数验证：替换前含 $p$ 的段长为 $(p-a-1) + (b-p-1) + 1 = b-a-1$，替换后裂为两段，无效数的减少量为 $\frac{(A+B-1)(A+B)}{2} - \frac{(A-1)A}{2} - \frac{(B-1)B}{2} = AB$，其中 $A = p-a$、$B = b-p$。∎

**定理 2（增量算法正确性）**：按 $t$ 从小到大累加引理 3 的增量，返回首个 $f \ge k$ 的 $t$（若始终 $< k$ 返回 $-1$），即正确答案。

**证明**：归纳可得扫描中维护的 $f$ 恰为各时刻真实值（$f(-1) = 0$ 起步，每步依引理 3 递推）。由引理 1 单调性，首个达标时刻即最小时刻；若 $n$ 步后仍 $< k$，则 $f(n-1) < k$，无解。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \log n)$。二分共 $O(\log n)$ 轮，每轮 `check` 标记加扫描 $O(n)$；增量版每步有序集合操作 $O(\log n)$，共 $n$ 步。倒序链表版可进一步降到 $O(n)$。
- **空间复杂度**：$O(n)$。标记数组 / 有序集合 / 链表的前驱后继数组，均为线性级别。

## 7. 参考代码

### C++（二分答案 + O(n) 计数）

```cpp
class Solution {
public:
    int minTime(string s, vector<int>& order, int k) {
        int n = s.size();
        long long total = 1LL * n * (n + 1) / 2;
        if (total < k) return -1;

        vector<char> starred(n);
        auto check = [&](int t) -> bool {
            fill(starred.begin(), starred.end(), 0);
            for (int i = 0; i <= t; ++i) starred[order[i]] = 1;
            long long invalid = 0, run = 0;
            for (int i = 0; i <= n; ++i) {
                if (i < n && !starred[i]) {
                    ++run;
                } else {  // 遇到 '*' 或 i==n 哨兵，结算一段
                    invalid += run * (run + 1) / 2;
                    run = 0;
                }
            }
            return total - invalid >= k;
        };

        int lo = 0, hi = n - 1;
        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            if (check(mid)) hi = mid;
            else lo = mid + 1;
        }
        return lo;
    }
};
```

### Python（二分答案 + O(n) 计数）

```python
class Solution:
    def minTime(self, s: str, order: List[int], k: int) -> int:
        n = len(s)
        total = n * (n + 1) // 2
        if total < k:
            return -1

        def check(t: int) -> bool:
            starred = [False] * n
            for i in range(t + 1):
                starred[order[i]] = True
            invalid = run = 0
            for i in range(n + 1):
                if i < n and not starred[i]:
                    run += 1
                else:  # 遇到 '*' 或 i==n 哨兵，结算一段
                    invalid += run * (run + 1) // 2
                    run = 0
            return total - invalid >= k

        lo, hi = 0, n - 1
        while lo < hi:
            mid = (lo + hi) // 2
            if check(mid):
                hi = mid
            else:
                lo = mid + 1
        return lo
```

### C++（进阶：增量 + 有序集合）

```cpp
class Solution {
public:
    int minTime(string s, vector<int>& order, int k) {
        int n = s.size();
        set<int> stars{-1, n};  // 哨兵
        long long f = 0;
        for (int t = 0; t < n; ++t) {
            int p = order[t];
            auto it = stars.insert(p).first;
            int a = *prev(it), b = *next(it);
            f += 1LL * (p - a) * (b - p);
            if (f >= k) return t;
        }
        return -1;
    }
};
```

### Python（进阶：倒序双向链表，O(n)）

```python
class Solution:
    def minTime(self, s: str, order: List[int], k: int) -> int:
        n = len(s)
        total = n * (n + 1) // 2
        if total < k:
            return -1

        prv = list(range(-1, n - 1))  # prv[i]：链表中 i 的前驱（哨兵 -1）
        nxt = list(range(1, n + 1))   # nxt[i]：链表中 i 的后继（哨兵 n）
        f = total                      # 从 t = n-1（全 '*'）开始回退
        for t in range(n - 1, 0, -1):
            p = order[t]               # 回退：t-1 时刻 p 变回普通字符
            a, b = prv[p], nxt[p]      # 当前最近的仍为 '*' 的位置
            f -= (p - a) * (b - p)     # 失效子串：l∈(a,p], r∈[p,b)
            if a >= 0:
                nxt[a] = b
            if b <= n - 1:
                prv[b] = a
            if f < k:                  # f(t-1) < k ⇒ t 即最小活跃时刻
                return t
        return 0                       # 一路回退到 t=0 仍未跌破 ⇒ 答案 0
```

## 8. 边界情况与易错点

1. **$t$ 的语义**：$t$ 时刻已完成 $t+1$ 次替换，答案**可以是 0**（示例 1）；二分下界取 $lo = 0$ 而非 $1$。
2. **溢出是头号陷阱**：$total \approx 5 \times 10^9$ 超 32 位上界，C++ 忘写 `1LL *` 往往「小样例全对、大样例玄学」，极难肉眼排查；`run` 也要用 `long long`，因为单个长段的 $\frac{L(L+1)}{2}$ 同样可达 $5 \times 10^9$。
3. **无解必须先判**：$total < k$ 直接返回 $-1$，这一步同时保证二分区间内答案必然存在，循环无需越界保护。
4. **尾段结算**：`check` 扫描结束后最后一段 `run` 别忘了累进 `invalid`（用 `i == n` 哨兵可天然处理）。
5. **增量版的哨兵**：$a$ 取 $-1$、$b$ 取 $n$，边界位置出现 `'*'` 时无需任何特判；倒序链表版注意「回退后链表恰好表示 replaced(t−1)」这一不变式。
6. **子串按位置计数、不去重**：`"*a*"` 中两个 `"*"` 是**不同**的子串，别拿去重后的个数比较 $k$。
7. **「≥ k」不是「= k」**：$f$ 的增量可能直接跨过 $k$（如示例 2 中 $f$ 从 $3$ 直接到 $5$，永远取不到 $4$），所以问「恰好等于」的变体并不能靠本题方法直接改出来。
