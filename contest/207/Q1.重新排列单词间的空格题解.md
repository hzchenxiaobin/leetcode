# LeetCode 重新排列单词间的空格 题解

## 1. 题目概述

- **标题 / 题号**：重新排列单词间的空格（#1592，easy）
- **链接**：https://leetcode.cn/problems/rearrange-spaces-between-words/
- **来源**：LeetCode 第 207 场周赛 Q1
- **难度**：简单
- **标签**：字符串、模拟

**题意**：给定字符串 `text`，由若干被空格包围的**单词**（连续小写字母）组成。要求重新排列空格：使每对相邻单词之间的空格数**相等**且**尽可能大**；分不完的空格全部放到字符串**末尾**。返回重排后的字符串，其长度与原串相同。

**约束**：

- $1 \le \text{text.length} \le 100$
- `text` 仅由小写英文字母和空格 `' '` 组成
- `text` 中至少包含一个单词

> 💡 本题在本仓库另有[每日题解 1592](../../solution/1501-1600/1592_重新排列单词间的空格.md)，含两趟扫描省空间写法与面试问答。本篇按**周赛复盘视角**重写：侧重**签到题的 30 秒切入定式**（两个统计量定全局）、**整除分配的引理-定理证明**，以及**赛时最容易翻车的 $n = 1$ 除零与 `split(' ')` 两个坑**。

## 2. 示例

**示例 1**

```text
输入：text = "  this   is  a sentence "
输出："this   is   a   sentence"
解释：共 9 个空格、4 个单词。9 / (4-1) = 3，每个间隔 3 个空格，恰好分完。
```

**示例 2**

```text
输入：text = " practice   makes   perfect"
输出："practice   makes   perfect "
解释：共 7 个空格、3 个单词。7 / (3-1) = 3 余 1，每个间隔 3 个空格，
      多余的 1 个空格放在字符串末尾。
```

**示例 3**

```text
输入：text = "a"
输出："a"
解释：只有一个单词，没有间隔，也没有空格需要安放。
```

## 3. 解题思路

### 3.1 签到切入：两个统计量定全局

签到题的目标是**从读题到 AC 的最短路径**。读题时先抓一个不变量：**重排只是搬动空格的位置，不增删空格**。于是整个答案只由两个统计量决定：

- **空格总数** $\text{spaces}$：一次遍历数出来；
- **单词数** $n$：以空格为分隔符切分后即得。

若从暴力角度想：从大到小枚举「每个间隔放 $k$ 个空格」，取第一个满足 $k \cdot (n-1) \le \text{spaces}$ 的 $k$ 即为答案——但这个 $k$ 显然就是 $\lfloor \text{spaces} / (n-1) \rfloor$，**枚举直接坍缩成一次整除**。签到题到此思路已完成，剩下的全是边界处理。

### 3.2 核心观察：空格守恒 + 整除分配

![核心观察：空格守恒，整除分配到 n−1 个间隔，余数归尾](images/wc207_q1_space_conservation_concept.svg)

**观察一：空格守恒。** 单词内容与顺序都不变、空格总数不变，所以结果串长度必等于原串长度——这也是赛时代码的天然自检：`len(结果) == len(text)`。

**观察二：整除即最优。** 间隔数固定为 $n - 1$，令

$$\text{per} = \left\lfloor \frac{\text{spaces}}{n-1} \right\rfloor, \qquad \text{extra} = \text{spaces} \bmod (n-1)$$

每个间隔放 `per` 个空格（相等且最大），余数 `extra` 全部追加到末尾，满足守恒式 $\text{per} \times (n-1) + \text{extra} = \text{spaces}$。

**观察三：单单词特判。** $n = 1$ 时间隔数为 0，除法直接除零——此时所有空格应堆到唯一单词的末尾。这是本题赛时最常见的 RE/WA 点。

**观察四：间隔不会为 0。** 题面保证两单词之间至少一个空格，故 $\text{spaces} \ge n - 1$，从而 $\text{per} \ge 1$，无需担心「空格不够分」。

### 3.3 算法流程

![算法流程：统计 → n=1 特判 → 整除分配 → 拼接](images/wc207_q1_algorithm_flow.svg)

1. **一次遍历**：数出空格总数 `spaces`，按空格切出单词列表 `words`；
2. **特判**：`n == 1` 时返回 `words[0]` + 全部空格；
3. **整除分配**：`per = spaces // (n-1)`，`extra = spaces % (n-1)`；
4. **拼接**：单词间各插 `per` 个空格连接，末尾补 `extra` 个空格。

### 3.4 示例演算

![示例演算：7 空格 3 词的字符级走查与 n=1 特判](images/wc207_q1_walkthrough.svg)

以示例 2 `" practice   makes   perfect"` 做字符级走查：

- **统计**：$\text{spaces} = 1 + 3 + 3 = 7$，$n = 3$，间隔数 $= 2$；
- **分配**：$\text{per} = \lfloor 7/2 \rfloor = 3$，$\text{extra} = 7 - 3 \times 2 = 1$；
- **结果**：`"practice   makes   perfect "`——两个间隔各 3 格、末尾 1 格，长度 27 = 原串长度 27 ✓。

对照单单词边界：`"  hi  "`（4 空格 1 词）→ `"hi    "`，4 个空格全部后置，长度仍为 6。

## 4. 算法细节

1. **统计与切分**（各语言的赛时最短路径）：
   - Python：`text.count(' ')` 数空格；`text.split()` 无参切分，自动跳过连续空格并去首尾；
   - C++：`count(text.begin(), text.end(), ' ')` 数空格；`istringstream >> w` 流式提取单词，运算符默认按空白切分。
2. **特判 $n = 1$**：间隔数 $n - 1 = 0$，除法非法，直接返回 `words[0] + spaces 个空格`。
3. **整除分配**：Python 用 `divmod(spaces, n - 1)` 一步得商与余数；C++ 用整型 `/` 与 `%`。
4. **拼接**：Python 用 `(' ' * per).join(words) + ' ' * extra` 一行完成；C++ 循环拼接，注意 `i > 0` 时才补间隔空格。
5. **坑：`split(' ')` ≠ `split()`**：前者按单个空格硬切，连续空格会产生空串元素（`"a  b".split(' ')` 得 `['a', '', 'b']`），导致 `len(words)` 虚高、间隔数算错；后者按任意连续空白切分且去首尾，恰好是本题需要的语义。

## 5. 正确性证明

**引理 1（可行性）**：设 $n \ge 2$，$\text{per} = \lfloor \text{spaces}/(n-1) \rfloor$，$\text{extra} = \text{spaces} - \text{per} \cdot (n-1)$，则 $0 \le \text{extra} \le n - 2$，且「每间隔 `per` 个、末尾 `extra` 个」恰好用尽全部空格。

**证明**：由带余除法，$\text{extra} = \text{spaces} \bmod (n-1)$，因 $n - 1 \ge 1$，余数范围恰为 $[0, n-2]$。摆放的空格总数为 $\text{per} \cdot (n-1) + \text{extra} = \text{spaces}$，恰好用尽。∎

**引理 2（最大化）**：任何满足「相邻间隔相等」的方案中，每间隔空格数 $k$ 必满足 $k \le \text{per}$。

**证明**：间隔共 $n - 1$ 个，每个放 $k$ 个空格，仅间隔就占用 $k \cdot (n-1)$ 个；又末尾空格数非负，故 $k \cdot (n-1) \le \text{spaces}$，即 $k \le \lfloor \text{spaces}/(n-1) \rfloor = \text{per}$。∎

**定理**：算法输出满足题目全部要求——相邻间隔相等且最大化、剩余空格置于末尾、长度与原串相等。

**证明**：间隔相等与空格用尽由引理 1 保证；每间隔取 `per` 达到引理 2 的上界，故最大化；余数 `extra` 追加到末尾即「剩余空格置于末尾」。长度方面：单词字符逐字保留共 $\sum_i \lvert \text{word}_i \rvert$ 个，加上恰好用尽的 $\text{spaces}$ 个空格，总长 $= \sum_i \lvert \text{word}_i \rvert + \text{spaces} = \lvert \text{text} \rvert$。$n = 1$ 时输出为单词 + 全部空格，长度同样相等。∎

## 6. 复杂度分析

- **时间复杂度**：$O(L)$，其中 $L = \lvert \text{text} \rvert$。一次遍历统计 + 一次结果拼接，均为线性。
- **空间复杂度**：$O(L)$。单词列表与结果串合计不超过 $O(L)$；$L \le 100$ 下完全无压力。

## 7. 参考代码

### C++（istringstream 切词 + 整除拼接）

```cpp
class Solution {
public:
    string reorderSpaces(string text) {
        int spaces = count(text.begin(), text.end(), ' ');
        vector<string> words;
        istringstream iss(text);
        string w;
        while (iss >> w) words.push_back(w);

        int n = words.size();
        if (n == 1) return words[0] + string(spaces, ' ');

        int gap = n - 1;
        int per = spaces / gap, extra = spaces % gap;
        string res;
        for (int i = 0; i < n; ++i) {
            if (i > 0) res += string(per, ' ');
            res += words[i];
        }
        return res + string(extra, ' ');
    }
};
```

### Python（count + split + divmod + join）

```python
class Solution:
    def reorderSpaces(self, text: str) -> str:
        spaces = text.count(' ')
        words = text.split()
        if len(words) == 1:
            return words[0] + ' ' * spaces
        per, extra = divmod(spaces, len(words) - 1)
        return (' ' * per).join(words) + ' ' * extra
```

> 💡 赛时最短路径就是 Python 这五行：`count` → `split` → 特判 → `divmod` → `join`，四个内置函数拼出签到答案，全程无需手写扫描。

## 8. 边界情况与易错点

1. **$n = 1$ 除零**：间隔数 $n - 1 = 0$，`spaces / (n-1)` 直接 RE（如输入 `"a"` 或 `"  hi  "`）。必须特判：所有空格堆到唯一单词末尾。这是本题最主要的翻车点。
2. **首尾空格要计入**：`spaces` 是**全部**空格数，包括前导与尾随空格（示例 1 中前导 2 个 + 尾随 1 个都算）。
3. **`split(' ')` 陷阱**：按单空格硬切会产生空串元素，单词数虚高、间隔数算错。必须用无参 `split()`。
4. **`extra` 不能丢**：余数空格必须补到末尾，否则结果串比原串短。提交前用 `len(结果) == len(text)` 自检（长度守恒）。
5. **C++ 手写扫描的收尾**：若不用 `istringstream` 而手动逐字符切词，循环结束后 `word` 可能仍非空（原串不以空格结尾），要记得入列。
6. **整数除法**：`per` 与 `extra` 用整型 `/`、`%` 即可，无需浮点运算。
