# LeetCode K 次乘运算后的最终数组 II 题解

## 1. 题目概述

- **标题 / 题号**：K 次乘运算后的最终数组 II（#3266，hard）
- **链接**：https://leetcode.cn/problems/final-array-state-after-k-multiplication-operations-ii/
- **来源**：LeetCode 第 412 场周赛 Q3
- **难度**：困难
- **标签**：数组、堆（优先队列）、模拟、数学

**题意**：给定整数数组 `nums`、整数 $k$ 与整数 `multiplier`（下记 $m$）。执行恰好 $k$ 次操作：每次取出 `nums` 的**最小值** $x$（并列时取**最前面**的），将其替换为 $x \cdot m$。全部操作结束后，把每个数对 $10^9 + 7$ 取余，返回最终数组。

**约束**：

- $1 \le n = \text{nums.length} \le 10^4$
- $1 \le \text{nums}[i] \le 10^9$
- $1 \le k \le 10^9$
- $1 \le m \le 10^6$

> 💡 **数据范围的两条信号**：① $k$ 高达 $10^9$——逐轮模拟必然超时，必须发现操作序列的**周期结构**整块快进；② 取余发生在**全部操作之后**——操作过程中比的是**真实大小**，这决定了「不能边乘边取模」（见 §8 易错点 2）。

## 2. 示例

**示例 1**

```text
输入：nums = [2,1,3,5,6], k = 5, multiplier = 2
输出：[8,4,6,5,6]
解释：
操作         结果                     说明
1 次操作后   [2, 2, 3, 5, 6]          最小值 1（下标 1）
2 次操作后   [4, 2, 3, 5, 6]          最小值 2（下标 0）
3 次操作后   [4, 4, 3, 5, 6]          最小值 2（下标 1，并列取最前）
4 次操作后   [4, 4, 6, 5, 6]          最小值 3（下标 2），3×2=6 取等继续
5 次操作后   [8, 4, 6, 5, 6]          最小值 4（下标 0）
取余操作后   [8, 4, 6, 5, 6]
```

**示例 2**

```text
输入：nums = [100000,2000], k = 2, multiplier = 1000000
输出：[999999307,999999993]
解释：
1 次操作后   [100000, 2000000000]     最小值 2000
2 次操作后   [100000000000, 2000000000]
取余操作后   [999999307, 999999993]
```

一开始 $2000 \times 10^6 > 100000 = mx$，是「零步模拟」直接停机的极端；剩余 $k = 2 = 1 \times 2 + 0$，两元素各乘一次 $10^6$。

**示例 3**（自拟，覆盖「k 提前用完」分支）

```text
输入：nums = [1,100], k = 2, multiplier = 2
输出：[4,100]
解释：1×2=2 ≤ 100、2×2=4 ≤ 100，两次操作都没触发停机，k 提前用完。
剩余 k = 0 → q = r = 0，分配公式退化为直接取模。
```

## 3. 解题思路

### 3.1 暴力思路：3264 的堆模拟为什么死了

简单版（同场 Q1，#3264）的做法：`(值, 下标)` 二元组入小根堆，$k$ 轮「弹顶 → 乘 → 塞回」，复杂度 $O(k \log n)$。放到本题规模下三条路全部堵死：

- **直接模拟**：$k \le 10^9$，堆操作总量 $\approx 1.4 \times 10^{10}$，必然超时；
- **边乘边取模压数值**：取模**破坏大小关系**——真值 $10^9 + 8$ 取模后变成 $1$，比 $3$ 还小，堆顶不再是真实最小，操作顺序全错；
- **大整数全程真值**：最终真值形如 $\text{nums}[i] \cdot m^{10^9}$，位数是天文数字，连一次乘法都做不起。

> 💡 三条死路指向同一结论：必须找到操作序列的**周期结构**，把 $10^9$ 次操作「整块快进」，而不是一次一次做。

### 3.2 核心观察：停机条件 + 周期轮转

![核心观察：停机条件把 10^9 次操作切成便宜模拟与周期快进两段](images/c412_q3_cycle_concept.svg)

**观察 1（停机条件——周期的起点）**：记某时刻数组最小值为 $\min$、初始最大值为 $mx$。一旦

$$\min \times m > mx$$

停机时刻便到来。关键在于由 $\min$ 的最小性，**所有**元素 $y$ 都满足 $y \cdot m \ge \min \cdot m > mx$——这个「全局性质」是轮转证明的基石（引理 3）。

**观察 2（停机后周期轮转）**：停机后每次操作取「当前最小」，乘后甩开所有未乘元素（$> mx$）；$n$ 次操作后全体恰好各乘一次 $m$，**相对次序完全复原**——周期为 $n$，永续循环。于是剩余 $k$ 次写作 $k = q \cdot n + r$：每人乘 $m^q$，升序前 $r$ 名多乘一次 $m$。

**观察 3（模拟阶段便宜且有界）**：停机前每次乘法的前提是 $\min \cdot m \le mx$，故每次乘积 $\le mx$——最大值全程不变，真值 $\le 10^9$ 不溢出。又 $m \ge 2$ 时每乘一次至少翻倍，每个元素至多被乘 $\lfloor \log_2 10^9 \rfloor \approx 30$ 次，**总模拟步数 $\le 30n \approx 3 \times 10^5$，与 $k$ 无关**。

**观察 4（$m = 1$ 必须特判）**：$\min \times 1 \le mx$ 恒成立，停机条件永假，主循环会傻跑满 $10^9$ 轮；而乘 $1$ 数组不变，开头直接返回即可。

**观察 5（真值定序、模值成答）**：模拟阶段用**真值**比较，分配阶段才切换到**模值**输出——两套数并行，绝不混用。

> ⚠️ **两个高频坑**：① 模拟阶段**绝不能取模**——破坏大小关系，堆顶失真；② 分配阶段的排序必须按 `(值, 下标)` 字典序——值相等时下标小者先被乘，与「并列取最前」一致，否则前 $r$ 名的归属就错了。

### 3.3 算法流程

![算法流程：特判、真值模拟到停机、周期快进](images/c412_q3_algorithm_flow.svg)

| 步骤 | 操作 | 要点 |
|------|------|------|
| ① 特判 | $m = 1$ 直接返回 | 停机条件永假，防跑满 $10^9$ 轮 |
| ② 建堆 | `(值, 下标)` 入小根堆，$mx = \max(\text{nums})$ | 字典序破平 = 「并列取最前」 |
| ③ 模拟 | `k > 0` 且 `堆顶×m ≤ mx` 时循环：弹顶 → ×m → 塞回 | 真值运算，绝不取模 |
| ④ 快进 | 依序出堆得升序表；$q, r = k \div n,\ k \bmod n$ | 出堆顺序 = 剩余操作的轮转顺序 |
| ⑤ 分配 | 第 $\text{rank}$ 名乘 $m^{q + [\text{rank} < r]} \bmod p$ | 快速幂；$k$ 用完时 $q=r=0$，两路合流 |

> 💡 第 ⑤ 步把「模拟耗尽」与「停机快进」两条出路**合流**成一个公式：$k$ 提前用完时 $q = r = 0$、$m^0 = 1$，同一行代码自然退化为「真值取模返回」，无需单独分支收尾。

### 3.4 示例演算

![示例 1 演算：模拟 4 步停机，剩余 1 次按轮转分配](images/c412_q3_example_walkthrough.svg)

以示例 1（$mx = 6$）为例：模拟阶段（条件 `堆顶×2 ≤ 6`）恰好执行 4 步——`1→2`、`2→4`、`2→4`、`3→6`，其中第 ④ 步 $3 \times 2 = 6 \le 6$ 是**取等**照样执行——条件是 $\le$ 不是 $<$。随后堆顶 $(4,0)$ 满足 $4 \times 2 = 8 > 6$，触发**停机**，剩余 $k = 1$。升序表为 $(4,0), (4,1), (5,3), (6,2), (6,4)$，$q = 0$、$r = 1$——只有 rank 0 即 $(4,0)$ 额外乘一次得 $8$，最终 `ans = [8,4,6,5,6]`，与逐步模拟完全一致。

示例 2 则是「零步模拟」：$2000 \times 10^6 > 100000$ 一开始就停机，$q = 1, r = 0$，两元素各乘一次 $10^6$ 后取模。

## 4. 算法细节

1. **堆与排序的破平规则必须一致**：堆存 `(值, 下标)` 二元组，弹出的就是「值最小、并列时下标最小」的元素，与题意「最前面的一个」严格一致；④ 中出堆得到的升序表天然沿用同一字典序，前 $r$ 名的归属才与逐轮模拟等价。
2. **停机条件用 $\le$ 不用 $<$**：取等（$\min \cdot m = mx$）时乘积只是**并列**最大，未必满足轮转证明需要的严格不等式；继续模拟严格对应逐轮操作，把停机的证明边界留在严格大于处（示例 1 的操作④ 正是取等）。
3. **中间量与溢出**：判断条件 `堆顶 × m ≤ mx` 中堆顶 $\le 10^9$、$m \le 10^6$，乘积可达 $10^{15}$——C++ 必须用 64 位整数；而真正执行的乘法满足乘积 $\le mx \le 10^9$，安全。
4. **分配阶段的模运算**：$v \cdot m^e \bmod p = \big((v \bmod p) \cdot (m^e \bmod p)\big) \bmod p$，两个因子都 $< p \approx 10^9$，乘积 $< 10^{18}$，64 位安全；指数 $e = q + [\text{rank} < r] \le 10^9 + 1$，用快速幂 $O(\log k)$ 计算。
5. **两路合流**：$k$ 在模拟阶段提前用完时 $q = r = 0$、$m^0 = 1$，⑤ 的公式自动退化为 $x \bmod p$——无需为「没停机」单独写收尾分支。

## 5. 正确性证明

**引理 1（模拟阶段不变式）**：阶段③ 中任意时刻所有元素 $\le mx$，且每次实际执行的乘法满足 $x \cdot m \le mx$。

**证明**：对操作次数归纳。初始时全体 $\le mx$。每轮执行乘法前，循环条件保证堆顶 $x$ 满足 $x \cdot m \le mx$；乘后的新值入堆、其余元素不变，不变式保持。∎

**引理 2（步数有界）**：$m \ge 2$ 时，阶段③ 至多执行 $\min(k,\ n \lfloor \log_2 mx \rfloor)$ 次。

**证明**：每轮消耗一次 $k$，得 $\le k$。又由引理 1，元素被乘后仍 $\le mx$；而每乘一次至少翻倍、初值 $\ge 1$，故单个元素至多被乘 $\lfloor \log_2 mx \rfloor \le 29$ 次，对 $n$ 个元素求和即得。∎

**引理 3（停机时刻的全局性质）**：设首次触发「堆顶 $\cdot\, m > mx$」时数组按 `(值, 下标)` 字典序排为 $v_0 \le v_1 \le \dots \le v_{n-1}$，则对**每个** $i$ 都有 $v_i \cdot m > mx$。

**证明**：堆顶即当前最小值 $v_0$。任意 $v_i \ge v_0$，故 $v_i \cdot m \ge v_0 \cdot m > mx$。∎

**引理 4（轮转周期）**：停机后第 $t$ 次操作（$t \ge 1$）作用于字典序排名为 $(t-1) \bmod n$ 的元素；且停机后已执行 $qn + s$ 次（$0 \le s < n$）时，排名 $r$ 的元素当前值为 $v_r \cdot m^{\,q + [r < s]}$。

**证明**：对停机后的操作次数归纳。$qn + s = 0$ 时显然。设命题在 $qn+s$ 时成立（$s < n$），考察下一个被乘者。对排名 $s$ 的元素，与其他元素比较：

- 对 $r > s$：当前值 $v_r m^q \ge v_s m^q$，相等时由字典序 $s$ 的下标更小，故堆顶不取 $r$；
- 对 $r < s$：当前值 $v_r m^{q+1}$，而 $v_s \le mx < v_r \cdot m$（引理 3），两边同乘 $m^q$ 得 $v_s m^q < v_r m^{q+1}$，故堆顶不取 $r$。

因此堆顶恰为排名 $s$ 者；执行后 $s \to s + 1$（$s = n-1$ 时归一为 $q+1,\ s=0$，全体恰好多乘一次 $m$），命题保持。∎

**引理 5（分配公式）**：停机时剩余 $k$ 次，$k = qn + r$，则最终排名 $\text{rank}$ 的元素真值为 $v_{\text{rank}} \cdot m^{\,q + [\text{rank} < r]}$。

**证明**：取引理 4 中 $t = k$，即 $qn + s$ 的 $(q, s) = (q, r)$ 情形。∎

**定理**：算法返回的数组等于「逐字模拟 $k$ 次操作、再对每项 $\bmod\ p$」的结果。

**证明**：$m = 1$ 时数组始终不变，① 直接返回正确。$m \ge 2$ 时：阶段③ 每轮都按真值取最小（引理 1 保证不溢出、无取模失真），与逐字模拟一致，直至 $k$ 用完或首次停机。$k$ 用完时 $q = r = 0$，输出 $v_i \bmod p$，显然正确。停机时，由引理 4、5，分配公式给出与逐轮模拟完全相同的**真值**；又由模乘法性质 $ab \bmod p = \big((a \bmod p)(b \bmod p)\big) \bmod p$，先取模再乘不改变最终余数。∎

## 6. 复杂度分析

- **时间复杂度**：$O\big(n \log V \cdot \log n + n \log k\big)$，其中 $V = \max(\text{nums}) \le 10^9$。建堆 $O(n)$；模拟阶段 $\le n \lfloor \log_2 V \rfloor \approx 30n$ 次堆操作，每次 $O(\log n)$；分配阶段 $n$ 次快速幂各 $O(\log k)$。$n = 10^4$ 时总量约 $4 \times 10^6$——$k$ 从乘数变成了**指数里的加项**。
- **空间复杂度**：$O(n)$，堆与升序表各存 $n$ 个二元组。

## 7. 参考代码

### C++（堆模拟 + 周期快进 + 快速幂）

```cpp
class Solution {
    static constexpr long long MOD = 1'000'000'007LL;

    // 快速幂：b^e mod MOD，e 可达 1e9
    static long long qpow(long long b, long long e) {
        long long r = 1;
        b %= MOD;
        for (; e > 0; e >>= 1, b = b * b % MOD)
            if (e & 1) r = r * b % MOD;
        return r;
    }

public:
    vector<int> getFinalState(vector<int>& nums, int k, int multiplier) {
        if (multiplier == 1) return nums;                     // ① 乘 1 = 没乘，且防死循环
        int n = nums.size();
        using P = pair<long long, int>;                       // (真值, 下标)
        priority_queue<P, vector<P>, greater<P>> pq;          //    小根堆，字典序破平
        long long mx = *max_element(nums.begin(), nums.end());
        for (int i = 0; i < n; ++i) pq.emplace(nums[i], i);
        while (k > 0 && pq.top().first * multiplier <= mx) {  // ② 堆顶×m > mx 时停机
            auto [x, i] = pq.top(); pq.pop();                 //    真值比较，不取模！
            pq.emplace(x * multiplier, i);                    //    乘积 ≤ mx ≤ 1e9，安全
            --k;
        }
        vector<P> order;                                      // ③ 依序出堆 = 升序表
        while (!pq.empty()) { order.push_back(pq.top()); pq.pop(); }
        long long q = k / n, r = k % n;                       //    剩余 k = q·n + r
        vector<int> ans(n);
        for (int rank = 0; rank < n; ++rank) {                // ④ 前 r 名多乘一次
            auto [x, i] = order[rank];                        //    k 用完时 q=r=0，退化 x%MOD
            ans[i] = (int)(x % MOD * qpow(multiplier, q + (rank < r)) % MOD);
        }
        return ans;
    }
};
```

### Python（heapq + 内置三参 pow）

```python
from heapq import heapify, heappop, heappush
from typing import List

class Solution:
    def getFinalState(self, nums: List[int], k: int, multiplier: int) -> List[int]:
        MOD = 10**9 + 7
        if multiplier == 1:                            # ① 乘 1 = 没乘，且防死循环
            return nums
        n = len(nums)
        heap = [(x, i) for i, x in enumerate(nums)]    # (真值, 下标) 小根堆
        heapify(heap)
        mx = max(nums)                                 #    模拟阶段 max 恒不变
        while k and heap[0][0] * multiplier <= mx:     # ② 堆顶×m > mx 时停机
            x, i = heappop(heap)                       #    真值比较，不取模！
            heappush(heap, (x * multiplier, i))
            k -= 1
        q, r = divmod(k, n)                            # ③ 剩余 k = q·n + r
        ans = [0] * n
        for rank, (x, i) in enumerate(sorted(heap)):   #    升序 = 后续轮转顺序
            ans[i] = x * pow(multiplier, q + (rank < r), MOD) % MOD
        return ans                                     #    k 用完时 q=r=0，退化 x%MOD
```

> 💡 Python 的三参 `pow(b, e, mod)` 自带模快速幂；`q + (rank < r)` 里布尔值当 0/1 用，「前 $r$ 名多乘一次」就藏在这个 `+1` 里。

## 8. 边界情况与易错点

1. **$m = 1$ 特判**：停机条件 $\min \times 1 \le mx$ 恒成立，主循环会跑满 $10^9$ 轮直接超时；乘 $1$ 数组不变，开头返回即可。这是「边界值杀死停机条件」的典型例子。
2. **模拟阶段绝不取模**：取余发生在全部操作之后，过程中比的是真实大小；边乘边取模会让堆顶失真（$10^9+8 \to 1$），操作顺序全错。
3. **停机条件是 $\le$ 不是 $<$**：取等时继续模拟（示例 1 操作④ 的 $3 \times 2 = 6$）；提前停机会踩进「并列最大」的证明盲区（引理 3 的严格不等式不再成立）。
4. **两处 64 位整数**：判断条件中堆顶 $\times m$ 可达 $10^{15}$；最终乘法 $(x \bmod p) \cdot m^e \bmod p$ 可达 $\approx 10^{18}$——C++ 两处都必须 `long long`。
5. **并列最小值的归属**：堆与分配排序都要用 `(值, 下标)` 字典序，「并列取最前」的题意规则贯穿到底，否则前 $r$ 名的归属就错了。
6. **$k$ 提前用完**：$q = r = 0$、$m^0 = 1$，公式退化为 $x \bmod p$，无需单独收尾分支（示例 3）；循环条件先判 `k > 0` 再判停机，保证耗尽即退出。
7. **单元素 / 全相等数组**：$n = 1$ 时 $x \cdot m > x = mx$ 立即停机，$q = k$ 一次算清 $x \cdot m^k$；全相等数组（如 `[5,5]`）同理从第 0 步就进入轮转——停机条件天然覆盖，无需特判。

- **为什么「可乘性」是周期的根基**：所有元素按同一比例 $m$ 缩放， $(值, 下标)$ 的次序不变，一轮后状态同构；若操作改成「乘后加一」等改变相对比例的形式，周期消失，只能退回 $O(k)$ 模拟——写堆模拟题前先问一句：操作序列会不会进入稳态？
