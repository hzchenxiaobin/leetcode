# LeetCode 统计近似相等数对 II 题解

## 1. 题目概述

- **标题 / 题号**：统计近似相等数对 II（#3267，hard）
- **链接**：https://leetcode.cn/problems/count-almost-equal-pairs-ii/
- **来源**：LeetCode 第 412 场周赛 Q4
- **难度**：困难
- **标签**：数组、哈希表、计数、枚举

**题意**：给定正整数数组 $nums$。若**至多两次**「选择 $x$ 或 $y$ 之一，交换该数的两个数位」可使 $x = y$，则称数对**近似相等**。注意每次操作**独立地**任选 $x$ 或 $y$——两次可以都放一边，也可以一边一次。返回满足 $i < j$ 且近似相等的数对数目。操作后允许**前导 0**（"30" 换成 "03" 就是 3）。

**约束**：

- $2 \le n \le 5000$
- $1 \le nums[i] < 10^7$（至多 7 位）

> 💡 **本场定位**：第 412 场双生题专场的收官。Q2（#3265）把 $n$ 卡在 100 放行平方暴力，本题三处同时收紧：① $n$ 放大到 5000，$O(n^2)$ 判定彻底不可行；② 操作放宽到**至多两次**，变体从 $\le 22$ 个膨胀到 $\le 463$ 个；③ 最隐蔽的是「两次操作一边一次」——判定条件看似是 $0{+}0 / 1{+}0 / 0{+}1 / 2{+}0 / 0{+}2 / 1{+}1$ 六种分配的并。本文的核心结论是：**补零 7 位定长串上，这一切塌缩成一句话——$y \in S(x)$**。Q2 的「补零 + 单向判定 + 先查后插」骨架一行不用改，只把变体闭包从一层循环扩成两层。

## 2. 示例

**示例 1**

```text
输入：nums = [1023,2310,2130,213]
输出：4
解释：
  1023 和 2310 —— 两次都放 1023：换第 0、2 位得 2013，再换第 1、3 位得 2310。
  1023 和 213  —— 换第 0、1 位得 0123=123，再对 123 换第 0、1 位得 213（前导 0 型）；
                  也可以一边一次：1023 换成 123、213 换成 123，在 123 会合。
  2310 和 213  —— 换第 0、1 位得 3210，再换第 0、3 位得 0213=213（前导 0 型）。
  2310 和 2130 —— 一次就够：换 2310 的第 1、2 位。
  另外（1023,2130）与（2130,213）不近似相等——补零串互差 4-循环，需 3 次对换。
```

**示例 2**

```text
输入：nums = [1,10,100]
输出：3
解释：全靠前导 0 型——10 换第 0、1 位 → 01 = 1；100 换第 0、2 位 → 001 = 1；
      100 换第 0、1 位 → 010 = 10。
```

**示例 3**（自拟，两步纯换位型）

```text
输入：nums = [12345,54321]
输出：1
解释：5 位逆序恰好是两个对换的复合：12345 → 52341 → 54321，两步都在 12345 上。
```

**示例 4**（自拟，防「闭包交集」误判）

```text
输入：nums = [123456,654321]
输出：0
解释：S(123456) 与 S(654321) 都含 653421（前者两步可达、后者一步可达），
      但互相变过去要把 6 个数位整体逆序 = 3 个不相交对换——超出两次。
      闭包有交 ≠ 近似相等。
```

## 3. 解题思路

### 3.1 暴力思路：逐对判定已死，逐元素生成登场

$n = 5000$，数对至多 $\binom{5000}{2} \approx 1.25 \times 10^7$ 个。逐对判定「≤2 步、可分摊两侧、允许前导 0」：

- 朴素做法对每对展开两步闭包再比较，单对开销数百，总量 $10^9$ 级，彻底不可行；
- 即使预计算每个 $S_i$ 再逐对查 $nums[j] \in S_i \lor nums[i] \in S_j$，也要 $2.5 \times 10^7$ 次哈希查询——C++ 勉强、Python 必超；而且「或」双向判定还要小心两个方向都命中的数对被计两次；
- 更隐蔽的坑：操作可以一边一次，判定看似是六种分配的并，逐种枚举既繁琐又容易重漏。

Q2 已经给出路：把「逐对判定」倒过来——**逐元素生成变体、哈希查之前的元素**，平方因子消成一趟线性扫描。剩下的问题只有一个：判定条件到底能不能写成单一方向？

### 3.2 核心观察：补零串上两步闭包天然对称——「分摊两侧」自动被覆盖

![核心观察：补零串上两步闭包对称，操作分摊两侧自动被覆盖](images/c412_q4_pad_two_step_concept.svg)

**观察 1（分摊被三角不等式吸收）**：设 $x$ 一步到 $v$、$y$ 一步到 $v$（1+1 分摊）。由 Q2 已证的「一步 ⟺ 补零串上一个对换」，$\bar x$、$\bar y$ 都与 $\bar v$ 至多差一个对换，于是对换距离 $d(\bar x, \bar y) \le d(\bar x, \bar v) + d(\bar v, \bar y) \le 2$——分摊情形自动落进「一边两步」的判定，**无需单独枚举**。

**观察 2（对称恢复）**：一次交换是补零串上一个对换 $\sigma$，两次就是复合 $\sigma_2 \circ \sigma_1$。关键封闭性：$(\sigma_2 \circ \sigma_1)^{-1} = \sigma_1^{-1} \circ \sigma_2^{-1}$ 仍是至多两个对换的复合——**可达关系对称**。于是定义

$$S(x) = \{x\} \cup \{\text{一步变体}\} \cup \{\text{两步变体}\}$$

（7 位补零串生成、**数值化**入集合、去重），则近似相等 $\iff y \in S(x) \iff x \in S(y)$，只需查一个方向，$|S| \le 1 + \binom{7}{2} + \binom{7}{2}^2 = 463$。

**观察 3（坏情形一步化）**：唯一看似漏网的情形——桥接两边的中间值 $m$ 比 $x$、$y$ 都长，两条一步路都「只能」从 $m$ 侧走——反而可以构造出 $x$ 与 $y$ 的**一步互换**（5 节引理 3）。判定塌缩至此完备。

> ⚠️ 两个方向的陷阱：**裸串闭包 ≠ 补零闭包**——213 的裸两步变体 $\{123,132,213,231,312,321\}$ 永远出不了 3 位数，到不了 1023；只有补零串上「把数字换进前导 0 区」才够得着。**闭包交集 ≠ 近似相等**——见示例 4。

### 3.3 算法流程

![算法流程：双层枚举对换生成两步闭包，先查后插](images/c412_q4_closure_flow.svg)

| 步骤 | 操作 | 要点 |
|------|------|------|
| ① 补零 | $t \leftarrow x$ 的 7 位定长串 | $nums[i] < 10^7$ ⟹ 位数 $\le 7$ |
| ② 初始化 | $S \leftarrow \{x\}$ | 零次操作：自身 |
| ③ 外层 | 枚举 21 种 $(i,j)$：换上 → `int` 入 $S$ | 一步变体；先不换回 |
| ④ 内层 | 枚举 21 种 $(a,b)$：换上 → `int` 入 $S$ → **换回** | 两步变体 = 对换复合，作用在已换的串上 |
| ⑤ 外层换回 | 换回 $(i,j)$ | 对合复用同一串，零拷贝 |
| ⑥ 先查 | $ans \mathrel{+}= \sum_{v \in S} seen[v]$ | $seen$ = 之前原值的出现次数 |
| ⑦ 后插 | $seen[x] \mathrel{+}= 1$ | 顺序不能反 |

> ⚠️ 与 Q2 唯一的结构差异就是 ③④⑤ 把「一层 21」扩成「嵌套两层 21」；两处「换回」缺一不可——少换回 = 对换级联叠加，$S$ 里混进三步、四步的产物，答案偏大。$(a,b)$ 与 $(i,j)$ 相同（净效果回到一步）或共享一位（复合出 3-循环）等退化情形，全部交给集合去重，无需特判。

### 3.4 示例演算

![示例 1 演算：对换距离决定命中](images/c412_q4_example_walkthrough.svg)

以示例 1 走一遍（$S$ 只列关键变体）：

| $j$ | $x$ | $S(x)$ 关键变体 | 命中 $seen$ | $ans$ |
|-----|-----|-----------------|-------------|-------|
| 0 | 1023 | 2013（一步）；2310、213（两步·前导 0） | — | 0 |
| 1 | 2310 | 2130（一步）；1023、213（两步） | $seen[1023]=1$ | 1 |
| 2 | 2130 | 2310（一步）；1023 ✗、213 ✗（4-循环 = 3 对换） | $seen[2310]=1$ | 2 |
| 3 | 213 | 123/231/312（一步）；1023、2310（两步·补零） | $seen[1023]{=}1,\ seen[2310]{=}1$ | 4 |

两个细节值得细看：

- **$j=2$ 双双未命中**：(1023, 2130) 与 (2130, 213) 的补零串互差一个 **4-循环**——4-循环最少要 3 个对换，超出「至多两次」。示例答案 4 恰好把这两对排除 ✓。
- **$j=3$ 靠补零命中**：213 的**裸串**两步变体只有 $\{123,132,213,231,312,321\}$，永远到不了 1023；但在**补零串** "0000213" 上先换第 4、5 位得 "0000123"（= 123 的补零形），再把首位 0 与 1 换（第 3、4 位）得 "0001023" = 1023——两步成立。真实操作序列在 1023 那侧（1023 → 2013 → 0213）。这正是「补零闭包 + 对称判定」的意义：**从短的一侧也能查到长的一侧的可达性**。该对还可行「一边一次」在 123 会合——塌缩进单向判定，算法无需任何特判。

## 4. 算法细节

1. **定长 7 位**：$nums[i] < 10^7$ ⟹ 位数 $\le 7$。统一补零后所有数共享同一个对换位置空间（$\binom{7}{2} = 21$ 种），位数差异被抹平——Q2 里它只影响「能不能配上」，在本题它升级为**判定正确性**的前提（5 节）。
2. **双层枚举 = 对换复合**：外层 $(i,j)$ 换上后不换回，内层在**已换**的串上再枚举 $(a,b)$，覆盖全部有序对换对 $\sigma_2 \circ \sigma_1$；$(a,b)$ 与 $(i,j)$ 相同、重叠、交换次序等重复由集合去重兜底。
3. **「换回」结构**：内层每次「换上 → `int` 入 $S$ → 换回」、内层循环结束后外层再换回，利用对合零拷贝复用同一串；若改成每次复制新串也可，但要保证两层各自独立、互不级联。
4. **键空间一致**：变体统一转 `int`（`stoi` / `int()` 自动消前导 0），`seen` 的键也是原值——两侧天然同空间。
5. **$S$ 含自身且去重**：含自身覆盖零次操作（$[88,88,88]$ 答案 $\binom{3}{2}=3$）；去重保证「多条交换路径到达同一值」不会让同一数对被重复累加。
6. **值域核查**：7 位补零串任意重排的数值 $\le 9\,999\,999 < 2^{31}-1$，`int` 安全；答案上界 $\binom{5000}{2} \approx 1.25 \times 10^7$，同样 `int` 安全。
7. **性能**：每元素生成 $\le 463$ 个候选并查哈希 $\le 463$ 次，总量 $\approx 2.3 \times 10^6$；Python 实测约 1 秒。重复值密集时可按值 memo 闭包（相同值只生成一次），$n \le 5000$ 下不加也过。

## 5. 正确性证明

记 $D = 7$；值 $v$ 的 $D$ 位补零串记 $\bar v$；$d(U, V)$ 为串 $U, V$ 的**对换距离**（变为对方所需的最少对换个数）。对换是对合，两个对换复合之逆仍是两个对换的复合，故 $d$ 是良定义的**度量**（对称、满足三角不等式）。

**事实 0**：每个 $D$ 位串都是其值的规范补零串（前导 0 只在左侧增多，剥掉后数值不变）。因此「值 ↔ 补零串」一一对应。

**引理 1（一步 ⟺ 一个对换）**：对值 $x, y$：存在一步操作使二者相等 $\iff d(\bar x, \bar y) \le 1$。且当对换跨界时，该步可实现放在**位数较多**的一方。

**证明**：（⟸ 操作 ⟹ 对换）一步作用于 $u$ 的当前串 $\mathrm{str}(u)$ 的第 $i < j$ 位得串 $s$，$\mathrm{value}(s) = v$。补零后 $\bar u$ 的对应两位做同一对换得 $0^{D-L_u} \cdot s$；由事实 0，它恰是 $\bar v$。（⟫ 对换 ⟹ 操作）设 $\bar y = \sigma_{i,j}(\bar x)$。若 $i, j$ 都落在 $\mathrm{str}(x)$ 的有效段（尾部 $L_x$ 位）：这就是对 $x$ 的一步操作，结果值为 $y$。否则跨界：$\bar x[j] = d \ne 0$ 是有效段数字、$\bar x[i] = 0$ 是补零位，于是 $\bar y$ 的有效段更长，$L_y = D - i > L_x$，且 $\mathrm{str}(y) = d \cdot \bar x[i{+}1..j{-}1] \cdot 0 \cdot \bar x[j{+}1..]$（$d$ 被挖到最前、原位留 0）。对 $y$ 做一步——交换首位 $d$ 与第 $j - i$ 位（正是那个 0）——得 $0 \cdot \bar x[i{+}1..j{-}1] \cdot d \cdot \bar x[j{+}1..]$，剥掉前导 0（$\bar x[i{+}1..j{-}1]$ 的前段全是补零 0）后恰为 $\mathrm{str}(x)$，值为 $x$。∎

**引理 2（桥分解）**：$d(\bar x, \bar y) \le 2 \iff$ 存在值 $m$ 使 $d(\bar x, \bar m) \le 1$ 且 $d(\bar m, \bar y) \le 1$。

**证明**：（⟹）对换链 $\bar x \to N \to \bar y$ 的中间串 $N$ 由事实 0 是某值 $m$ 的补零串。（⟸）三角不等式。∎

**引理 3（坏情形一步化）**：设 $d(\bar x, \bar m) \le 1$、$d(\bar m, \bar y) \le 1$，且 $L_m > L_x$、$L_m > L_y$（两条一步路都只能从 $m$ 侧实现）。则 $x$ 与 $y$ **一步**即可相等。

**证明**：记 $s = \mathrm{str}(m)$。从 $m$ 侧实现的两条一步路分别把 $s$ 变为 $0^{A}\,\mathrm{str}(x)$ 与 $0^{B}\,\mathrm{str}(y)$，其中 $A = L_m - L_x \ge 1$、$B = L_m - L_y \ge 1$。结果带前导 0 的对换必动首位（不动首位的对换不改变首位的非零数字），故两条路形如 $\tau = (0, r)$、$\rho = (0, q)$，且 $s[r] = s[q] = 0$（首位数字 $d_0 \ne 0$ 被换到 0 位）。$r \ne q$（否则 $x = y$，平凡）。设 $t^*$ 为 $s$ 中首个非零位置，则 $A = \min(t^*, r)$、$B = \min(t^*, q)$；注意 $r, q \ne t^*$（$s[r] = s[q] = 0 \ne s[t^*]$）。不妨 $A \ge B$，三种情形均给出一步互换：

1. **$q > t^*$ 且 $r > t^*$**：$A = B = t^*$，$\mathrm{str}(x)$ 与 $\mathrm{str}(y)$ 仅在 $(q - t^*,\ r - t^*)$ 两个位置上不同（一边是 $d_0$ 一边是 0）——对 $x$ 交换这两位即得 $y$。
2. **$q < t^* \le r$**：$A = t^*$、$B = q$，$\mathrm{str}(y) = d_0 \cdot s[q{+}1..]$。交换 $\mathrm{str}(y)$ 的首位与第 $r - q$ 位（该处是 $s[r] = 0$）：得 $0 \cdot s[q{+}1..r{-}1] \cdot d_0 \cdot s[r{+}1..]$，剥前导 0 后 $= s[t^*..r{-}1] \cdot d_0 \cdot s[r{+}1..] = \mathrm{str}(x)$——对 $y$ 一步得 $x$。
3. **$q < r < t^*$**：$A = r$、$B = q$，同样交换 $\mathrm{str}(y)$ 的首位与第 $r - q$ 位（$s[r] = 0$）：剥后 $= d_0 \cdot s[r{+}1..] = \mathrm{str}(x)$。

各下标均落在对应串的有效段内（$r, q \ge 1$；情形 2、3 中 $1 \le r - q \le L_y - 1$；情形 1 中两位置 $< L_x$）。∎

**定理（判定塌缩）**：$x, y$ 近似相等 $\iff d(\bar x, \bar y) \le 2 \iff y \in S(x)$。

**证明**：（⟹）设最优方案 $a$ 步放在 $x$、$b$ 步放在 $y$（$a + b \le 2$），最终共同值为 $v$。反复用引理 1 的「操作 ⟹ 对换」方向沿两侧链复合：$d(\bar x, \bar v) \le a$、$d(\bar y, \bar v) \le b$；三角不等式给出 $d(\bar x, \bar y) \le a + b \le 2$。（⟸）由引理 2 取桥 $m$。由引理 1，两条一步路各自可实现为「放在 $x$（或 $y$）上」或「只能放在 $m$ 上」（后者当且仅当 $m$ 比对方长）。若两条都能放在己方：一步在 $x$ 一步在 $y$、会合于 $m$，合法。若恰有一条只能放 $m$：两条都落在另一数的当前值序列上（第二步作用于第一步的结果值 $m$），仍是至多两步。若两条都只能放 $m$：$L_m > L_x$ 且 $L_m > L_y$，引理 3 直接给出一步方案。∎

**推论（计数正确性）**：算法返回值恰为 $\#\{(i, j) : i < j,\ nums[i] \text{ 与 } nums[j] \text{ 近似相等}\}$。

**证明**：对扫描位置归纳，不变式：$seen$ 是已处理原值的计数，$ans$ 是已处理前缀内的合法数对数。处理 $x = nums[j]$ 时增量为 $\sum_{v \in S(x)} seen[v] = \#\{i < j : nums[i] \in S(x)\}$（$S$ 去重保证每个 $i$ 至多计一次）；由定理，$nums[i] \in S(nums[j])$ 当且仅当近似相等。先查后插保证 $(x, x)$ 型不会命中自己。∎

## 6. 复杂度分析

- **时间复杂度**：$O\!\big(n \cdot \binom{D}{2}^{2} \cdot D\big) = O(n \cdot D^5)$，$D = 7$ 为定长串位数。每个元素生成 $\le 1 + 21 + 21^2 = 463$ 个候选变体（每次 $O(D)$ 拼串与数值化）并逐一查哈希；$n = 5000$ 时约 $2.3 \times 10^6$ 次查插，Python 实测约 1 秒。对照暴力 $O(n^2)$ 判定的 $1.25 \times 10^7$ 次对级检查，「先查后插」再次把平方因子消成一趟线性扫描。
- **空间复杂度**：$O(n + \binom{D}{2}^2)$。$seen$ 随不同原值数增长；单个 $S$ 至多 463 个 `int`，逐元素即弃。

## 7. 参考代码

### C++（补零 + 双层对换闭包 + 先查后插）

```cpp
class Solution {
public:
    int countPairs(vector<int>& nums) {
        const int D = 7;
        unordered_map<int, int> seen;          // 之前原值 → 出现次数
        int ans = 0;
        for (int x : nums) {
            string t = to_string(x);
            t = string(D - t.size(), '0') + t; // ① 补前导 0 到定长 7 位
            unordered_set<int> S{x};           // ② 零次操作：自身
            for (int i = 0; i < D; ++i)
                for (int j = i + 1; j < D; ++j) {
                    swap(t[i], t[j]);          // ③ 外层换上（一步变体）
                    S.insert(stoi(t));         //   "0001023" → 1023
                    for (int a = 0; a < D; ++a)
                        for (int b = a + 1; b < D; ++b) {
                            swap(t[a], t[b]);  // ④ 内层换上（两步变体）
                            S.insert(stoi(t)); //   作用在已换的串上 = 对换复合
                            swap(t[a], t[b]);  //   内层换回（对合！）
                        }
                    swap(t[i], t[j]);          // ⑤ 外层换回
                }
            for (int v : S)                    // ⑥ 先查
                if (auto it = seen.find(v); it != seen.end())
                    ans += it->second;
            ++seen[x];                         // ⑦ 后插
        }
        return ans;
    }
};
```

### Python（itertools.combinations 嵌套两层）

```python
from collections import Counter
from itertools import combinations
from typing import List

class Solution:
    def countPairs(self, nums: List[int]) -> int:
        pairs = list(combinations(range(7), 2))  # 21 种对换位置
        seen = Counter()                        # 之前原值 → 出现次数
        ans = 0
        for x in nums:
            s = list(f"{x:07d}")                # ① 补前导 0 到定长 7 位
            S = {x}                             # ② 零次操作：自身
            for i, j in pairs:
                s[i], s[j] = s[j], s[i]         # ③ 外层换上（一步变体）
                S.add(int(''.join(s)))          #   "0001023" → 1023
                for a, b in pairs:
                    s[a], s[b] = s[b], s[a]     # ④ 内层换上（两步变体）
                    S.add(int(''.join(s)))      #   作用在已换的串上
                    s[a], s[b] = s[b], s[a]     #   内层换回（对合！）
                s[i], s[j] = s[j], s[i]         # ⑤ 外层换回
            ans += sum(seen[v] for v in S)      # ⑥ 先查
            seen[x] += 1                        # ⑦ 后插
        return ans
```

> 💡 两份代码与 Q2 的版本逐行同构，差异只有：闭包从一层 `for` 变成嵌套两层、多一个「外层换回」。`stoi` / `int()` 自动消前导 0，与 `seen` 的数值键天然同空间。

## 8. 边界情况与易错点

1. **「至多两次」含零次与一次**：$S$ 必须含自身与全部一步变体。漏掉自身，全相同元素的 $\binom{n}{2}$ 全归零。
2. **操作可分摊两侧（一边一次）**：无需单独枚举——由对称性塌缩进单向判定（观察 1 + 定理）。若手写六种分配枚举，极易在 1+1 上重复计数或漏判。
3. **裸串闭包 ≠ 补零闭包**：213 的裸两步变体出不了 3 位数，补零闭包才含 1023。忘了补零（或只对长的一侧生成闭包），示例 1 的 (1023, 213) 直接丢失。这是 Q2 就埋过的命门，在 Q4 更隐蔽——两步变体更多，漏得悄无声息。
4. **闭包交集 ≠ 近似相等**：$[123456, 654321]$ 答案 0。$S$ 交含 653421，但互变需 3 个对换（6 位逆序 = 3 个不相交对换）。判据必须是 $y \in S(x)$，不是 $S(x) \cap S(y) \ne \varnothing$。
5. **两处「换回」缺一不可**：内层换回 + 外层换回。少一个，21 × 21 种对换就会级联叠加成三步、四步产物，$S$ 虚大、答案偏大。
6. **先查后插**：顺序反了会让 $x$ 命中自己（$S \ni x$），凭空多算 $(x, x)$ 对；顺序正确时 $i < j$ 由「表里只有之前的元素」天然保证。
7. **$S$ 去重**：交换两个相同数位、或两条路径到达同一值，都会产生重复候选；不去重则同一数对被重复累加。
8. **值域与答案**：变体 $\le 9\,999\,999$、答案 $\le \binom{5000}{2} \approx 1.25 \times 10^7$，`int` 均安全，无需 64 位。
9. **性能余量**：Python 按值 memoize 闭包可再省（重复值密集时同值只算一次），$n \le 5000$ 不加也过；真正卡死的是「逐对判定」思路，不是常数。
10. **别排序**：只需 $i < j$ 的计数，与顺序无关（同 Q2），排序反而绕远。
