# LeetCode 使二进制数组全部等于 1 的最少操作次数 II 题解

## 1. 题目概述

- **标题 / 题号**：使二进制数组全部等于 1 的最少操作次数 II（#3192，medium）
- **链接**：https://leetcode.cn/problems/minimum-operations-to-make-binary-array-elements-equal-to-one-ii/
- **来源**：LeetCode 第 133 场双周赛 Q3
- **难度**：中等
- **标签**：贪心、数组、动态规划

**题意**：给定二进制数组 $nums$。每次操作选择任意下标 $i$，把从 $i$ 到数组末尾的**全部元素**反转（0 变 1、1 变 0）。求把数组全部变成 1 的最少操作次数。

**约束**：

- $1 \le nums.length \le 10^5$
- $0 \le nums[i] \le 1$
- 一次操作翻转的是一整个**后缀**，长度可以是 1（即只翻最后一个元素）

**关键点**：本题**一定可行**——因为可以只翻最后一个元素（$i = n-1$），任何残留的 0 都能单独修掉。这一点与同场 Q2（长度固定为 3、可能无解）形成鲜明对比。剩下的问题只是：怎样用最少的后缀翻转搞定。

## 2. 示例

**示例 1**

```text
输入：nums = [0,1,1,0,1]
输出：4
解释：一种最优序列为
  翻 i=1 → [0,0,0,1,0]
  翻 i=0 → [1,1,1,0,1]
  翻 i=4 → [1,1,1,0,0]
  翻 i=3 → [1,1,1,1,1]
共 4 次。
```

**示例 2**

```text
输入：nums = [1,0,0,0]
输出：1
解释：翻 i=1 一次，后缀 [0,0,0] 全部变 1，数组成为 [1,1,1,1]。
```

**示例 3（边界补充）**

```text
输入：nums = [0]
输出：1
解释：只有一个元素，翻 i=0 即可；这是 n 取最小值的情形。
```

## 3. 解题思路

### 3.1 暴力思路

下标共 $n$ 种选择，每种翻或不翻，共 $2^n$ 种组合；枚举后模拟一遍是 $O(n2^n)$。即使做状态 BFS，状态空间也是 $2^n$，$n = 10^5$ 时完全不可行。暴力只在 $n \le 18$ 左右有验证价值。

### 3.2 核心观察：前缀不会被后来的操作触碰

![一次操作 = 翻转整个后缀，前缀毫发无损](images/bw133_q3_suffix_flip.svg)

后缀翻转有两个直接推论：

1. **操作可交换**：先翻 $i$ 再翻 $j$ 与先翻 $j$ 再翻 $i$ 结果相同（都是对相应后缀各取反一次），所以只需关心「每个下标翻了多少次」。
2. **位置 $i$ 只受起点 $\le i$ 的操作影响**：起点 $> i$ 的操作从 $i$ 的右侧开始，碰不到 $i$。

于是从左往右处理时，一旦我们跨过下标 $i$，$nums[i]$ 的最终值就已经**永久确定**了。这给了贪心一个非常干净的立足点：

> 处理到 $i$ 时，只需看「$nums[i]$ 当前（已考虑此前翻转）是多少」。若为 0，就在 $i$ 处翻一次；若为 1，什么都别做。

### 3.3 算法流程：用一个 bit 记录奇偶

![覆盖范围是三角形：位置 i 只被起点 0..i 的操作覆盖](images/bw133_q3_obligation.svg)

维护一个布尔量 `flip`，表示「从当前位置往后，已经被翻转了奇数次还是偶数次」。扫描时真实值是 $nums[i] \oplus flip$：

```text
ans = 0, flip = 0
for x in nums:
    cur = x ^ flip
    if cur == 0:            # 当前位置还是 0，必须在这里翻一次
        ans += 1
        flip ^= 1           # 后缀整体反相
    # cur == 1：不翻，flip 保持不变
return ans
```

`flip` 一旦为 1，后续每个元素读到的都是「取反后的值」，这正是后缀翻转的累积效果；而要消除这个累积效果，只需在下标 $i$ 处再翻一次（$flip$ 回到 0）。

### 3.4 示例演算

![示例走查：flip 的奇偶传播](images/bw133_q3_example_walk.svg)

$nums = [0,1,1,0,1]$：

| $i$ | $nums[i]$ | flip | cur | 动作 | ans |
|-----|-----------|------|-----|------|-----|
| 0 | 0 | 0 | 0 | 翻，flip → 1 | 1 |
| 1 | 1 | 1 | 0 | 翻，flip → 0 | 2 |
| 2 | 1 | 0 | 1 | 跳过 | 2 |
| 3 | 0 | 0 | 0 | 翻，flip → 1 | 3 |
| 4 | 1 | 1 | 0 | 翻，flip → 0 | 4 |

答案 4，与示例一致。注意第 3 步：原始值是 1，但因为 flip 已经是奇数，读到的是 1，所以什么都不做——这正是「后缀被翻过一次」的体现。

## 4. 算法细节

1. **`cur = x ^ flip` 是核心**：不要真的去改数组（那每次操作是 $O(n)$，总复杂度 $O(n^2)$）。异或一个 bit 就把「整段后缀被翻转的累积效果」压缩成了 $O(1)$。
2. **等价写法：与前一位比较**。维护 `prev = 0`（视作 $nums[-1] = 0$），从左到右遍历，若 $nums[i] \ne prev$ 则 `ans += 1; prev = nums[i]`。这利用了「后缀翻转只会改变相邻元素的相同/不同关系」，是本题最短的实现（见下方代码的可选写法思路）。
3. **答案上界**：最多 $n$ 次（每个位置翻一次），`int` 足够。
4. **不需要输出具体下标**：题目只问次数。若要输出方案，从左到右记录每次翻转的下标，天然升序。
5. **一定可行**：$i = n-1$ 的后缀长度为 1，可以单独修掉任意一个位置，所以不存在 $-1$ 的分支；编写时不必加无解判断。
6. **与 Q2 的对比**：Q2 的窗口长度固定为 3，末尾两格可能无人负责 → 可能无解；Q3 的后缀可以短到 1，永远有人负责 → 必有解。

## 5. 正确性证明

**引理 1（覆盖范围）**：起点为 $j$ 的操作只影响下标 $\ge j$ 的元素。因此位置 $i$ 的最终值只由起点 $j \le i$ 的操作决定。

**证明**：操作翻转的是后缀 $[j, n-1]$，其最小受影响下标为 $j$。若 $j > i$，则 $i \notin [j, n-1]$，值不变。∎

**引理 2（奇偶刻画与唯一性）**：设 $f_i \in \{0,1\}$ 表示在下标 $i$ 处操作次数的奇偶性。任何将所有元素变为 1 的方案，其 $(f_0, \dots, f_{n-1})$ 唯一确定，且总操作次数 $\ge \sum_i f_i$。

**证明**：位置 $p$ 的最终值为 $nums[p] \oplus \bigoplus_{j \le p} f_j$，要求其等于 1，即
$$\bigoplus_{j \le p} f_j = 1 - nums[p].$$
对 $p = 0$ 得 $f_0 = 1 - nums[0]$，唯一。设 $f_0, \dots, f_{p-1}$ 已唯一确定，则 $f_p = (1 - nums[p]) \oplus \bigoplus_{j < p} f_j$ 也唯一确定。归纳得全部 $f$ 唯一。又每个下标实际操作次数 $k_i \equiv f_i \pmod 2$ 且 $k_i \ge 0$，故 $k_i \ge f_i$，求和得总次数下界 $\sum f_i$。∎

**引理 3（贪心即最优奇偶解）**：算法中的 `flip` 恰等于 $\bigoplus_{j<i} f_j$，且算法在 $i$ 处翻转当且仅当 $f_i = 1$。

**证明**：对 $i$ 归纳。$i = 0$ 时 `flip` 为空异或 $= 0 = \bigoplus_{j<0} f_j$。设处理 $i$ 前 `flip` $= \bigoplus_{j<i} f_j$，则 `cur` $= nums[i] \oplus \bigoplus_{j<i} f_j$，而由引理 2 的递推式，$f_i = 1$ 当且仅当 $nums[i] \oplus \bigoplus_{j<i} f_j = 0$，即 `cur == 0`。算法正是在 `cur == 0` 时翻转，与 $f_i$ 一致；翻转后 `flip` 异或 1，等于 $\bigoplus_{j \le i} f_j$，归纳继续成立。∎

**定理**：算法返回的 `ans` 是使数组全为 1 的最少操作次数。

**证明**：由引理 3，算法在 $i$ 处操作当且仅当 $f_i = 1$，故总次数恰为 $\sum_i f_i$；由引理 2，任何合法方案的总次数 $\ge \sum_i f_i$。下界可达，故算法最优。又由「$i = n-1$ 的后缀可单独修正」知任何数组都有可行方案，所以不必返回 $-1$。∎

## 6. 复杂度分析

- **时间**：$O(n)$。一次线性扫描，每个元素做一次异或与一次比较。
- **空间**：$O(1)$。只维护 `ans` 与 `flip` 两个整型变量，不修改输入、不额外开数组。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minOperations(vector<int>& nums) {
        int ans = 0, flip = 0;          // flip：后缀已被翻转次数的奇偶
        for (int x : nums) {
            if ((x ^ flip) == 0) {      // 当前真实值为 0 → 必须在此翻转
                ++ans;
                flip ^= 1;              // 后缀整体反相
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def minOperations(self, nums: list[int]) -> int:
        ans = flip = 0                  # flip：后缀已被翻转次数的奇偶
        for x in nums:
            if x ^ flip == 0:           # 当前真实值为 0 → 必须在此翻转
                ans += 1
                flip ^= 1               # 后缀整体反相
        return ans
```

> 💡 两段代码通过官方示例（`4`、`1`）与 $nums = [0]$、$nums = [1,0]$ 等边界，并与 $2^n$ 状态 BFS 暴力在 $n \in [1,10]$ 上做了 400 组随机对拍，`mismatch = 0`。$n = 10^5$ 的输入耗时在毫秒级。

## 8. 边界情况与易错点

1. **$n = 1$**：$nums = [0]$ 返回 1，$nums = [1]$ 返回 0。此时「后缀」就是单个元素，公式照常成立。
2. **全 1 输入**：`flip` 始终为 0，`cur` 始终为 1，返回 0。
3. **别真的模拟翻转**：`nums[i..n-1]` 逐位取反是 $O(n)$，总 $O(n^2)$，$n = 10^5$ 会超时。必须用 `flip` 的奇偶代替。
4. **`flip` 只在翻转时取反**：跳过时不要改动它，否则会「凭空」反相整个后缀。
5. **异或优先级**：C++ 中 `^` 的优先级**低于** `==`，写 `if (x ^ flip == 0)` 会被解析成 `x ^ (flip == 0)`。必须加括号：`if ((x ^ flip) == 0)`。Python 中 `^` 的优先级高于 `==`，但为可读性同样建议加括号。
6. **不要声明 `bool flip` 再做算术**：语义上没问题，但 `bool` 参与 `^=` 容易在其他语言里踩坑；用 `int` 更稳。
7. **无解判断不要加**：本题恒有解，多写一个 `return -1` 分支只会让代码更难读（也容易被误触发）。
