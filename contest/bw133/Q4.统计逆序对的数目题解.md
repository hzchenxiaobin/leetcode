# LeetCode 统计逆序对的数目 题解

## 1. 题目概述

- **标题 / 题号**：统计逆序对的数目（#3193，hard）
- **链接**：https://leetcode.cn/problems/count-the-number-of-inversions/
- **来源**：LeetCode 第 133 场双周赛 Q4
- **难度**：困难
- **标签**：数组、动态规划

**题意**：给定 $n$ 与若干约束 $requirements[i] = [end_i, cnt_i]$，统计满足以下条件的 $0 \sim n-1$ 的排列 $perm$ 的个数：对每个 $i$，前缀 $perm[0..end_i]$ 中**恰好**有 $cnt_i$ 个逆序对。答案对 $10^9+7$ 取模。

逆序对指下标对 $(i,j)$ 满足 $i < j$ 且 $perm[i] > perm[j]$。

**约束**：

- $2 \le n \le 300$
- $1 \le requirements.length \le n$，且所有 $end_i$ 互不相同
- $0 \le end_i \le n-1$，$0 \le cnt_i \le 400$
- 输入保证至少有一个 $i$ 满足 $end_i = n-1$（即最终长度 $n$ 的逆序对数被固定）

**关键点**：$n$ 最大 300，$n!$ 级枚举不可能；但 $cnt \le 400$ 给出了一个**很窄的值域**——只需要关心逆序对数不超过 400 的状态，这正是 DP 的舞台。

## 2. 示例

**示例 1**

```text
输入：n = 3, requirements = [[2,2],[0,0]]
输出：2
解释：要求长度为 3 的整个排列恰有 2 个逆序对，且长度为 1 的前缀有 0 个（单元素必然为 0）。
满足条件的排列是 [2,0,1] 与 [1,2,0]，均恰有 2 个逆序对。
```

**示例 2**

```text
输入：n = 3, requirements = [[2,2],[1,1],[0,0]]
输出：1
解释：额外要求前缀 [2,0] 与 [1,2] 各有 1 个逆序对。
[1,2,0] 的前缀 [1,2] 逆序对为 0，被排除；只剩 [2,0,1]。
```

**示例 3**

```text
输入：n = 2, requirements = [[0,0],[1,0]]
输出：1
解释：长度为 2 且逆序对为 0 的排列只有 [0,1]。
```

## 3. 解题思路

### 3.1 暴力思路

枚举 $0 \sim n-1$ 的全部 $n!$ 个排列，逐个前缀数逆序对：$n = 300$ 时 $300!$ 是天方夜谭。即便只算「总逆序对数为 $k$ 的排列数」（无前缀约束的经典 Mahonian 数），也必须用 DP。所以本题的第一步就是**放弃枚举，转向计数 DP**。

### 3.2 核心观察：把「最大的数」插进去

![插入第 i 个（最大的）元素：贡献 t 个逆序对](images/bw133_q4_dp_model.svg)

计数排列的最常用技巧是**按值从小到大（或从大到小）逐个插入**。这里考虑：已知 $1 \sim i-1$（相对大小）的某个排列，把**当前最大的数**插入其中。

- 若插在最右端，它不与任何元素构成逆序对：新增 $t = 0$ 个。
- 若插在最左端，它与右侧全部 $i-1$ 个元素都构成逆序对：新增 $t = i-1$ 个。
- 一般地，插在从右往左数第 $t$ 个空隙，恰有 $t$ 个元素在它右边且更小，新增 $t$ 个逆序对。

由于插入的是最大元素，**它作为右侧元素不会被任何元素「超过」**，因此新增逆序对**只由插入位置决定**，且 $t$ 可以取遍 $0, 1, \dots, i-1$，每个 $t$ 恰好对应一个位置。于是定义

$$dp[i][j] = \text{用 } 1 \sim i \text{ 组成的排列中，逆序对数恰为 } j \text{ 的个数}$$

得到递推

$$dp[i][j] = \sum_{t=0}^{\min(i-1,\,j)} dp[i-1][j-t]$$

### 3.3 状态转移与前缀和优化

![转移是一段滑动窗口求和 → 用前缀和相减](images/bw133_q4_prefix_sum.svg)

上面的求和是一段**连续的滑动窗口**：固定 $i$，对 $j$ 递增时区间 $[j-(i-1), j]$ 整体右移一格。用前缀和 $pre[j] = \sum_{k \le j} dp[i-1][k]$ 可把每层从 $O(C \cdot i)$ 降到 $O(C)$：

$$dp[i][j] = pre[j] - pre[j-i] \quad (\text{当 } j-i < 0 \text{ 时后项记 } 0)$$

其中 $C = \max cnt_i \le 400$。总的转移代价 $O(nC)$。

### 3.4 约束如何落地

![requirements 的作用：把整行清空，只留一列](images/bw133_q4_requirement_mask.svg)

把约束 $[end_i, cnt_i]$ 映射成「前缀长度 $L = end_i + 1$」这一行：在算完 $dp[L][\cdot]$ 之后，把 $j \ne cnt_i$ 的项全部清零。这等价于「该行的分布被强制成一个脉冲」。最后一行的约束（题目保证存在 $end_i = n-1$）就是答案所在列，最终返回 $dp[n][cnt]$。

```text
need[0..n−1] = −1                      # need[e] = 前缀长度 e+1 的要求，−1 表示无要求
for (end, cnt) in requirements:
    need[end] = cnt
    C = max(C, cnt)

dp[0] = 1, 其余为 0                    # 空前缀只有 0 个逆序对
for i = 1 .. n:
    pre = prefix_sum(dp)
    for j = 0 .. C:
        dp'[j] = pre[j] − (j ≥ i ? pre[j−i] : 0)
    if need[i−1] != −1:
        for j != need[i−1]: dp'[j] = 0
    dp = dp'
return dp[need[n−1]]
```

## 4. 算法细节

1. **只保留 $j \le C$ 的列是正确的**：前缀逆序对数随长度**单调不减**（加一个元素不会减少已有逆序对）。因此一旦某个中间状态 $j > C$，它再也无法回到 $\le C$，而答案所在的 $dp[n][cnt_{n-1}]$ 要求 $cnt_{n-1} \le C$，所以这些状态对答案毫无贡献，直接截断即可。这一步把状态空间从 $O(n^2/2)$（$n=300$ 时约 4.5 万）压到 $C+1 \le 401$。
2. **行下标要 +1**：约束给的是「末尾下标」$end_i$，它描述的前缀长度是 $end_i + 1$。写成 `need[end_i]` 并在第 $i$ 步后检查 `need[i-1]`，二者一致，是最不容易写错的做法。
3. **清零要及时**：必须在算出 $dp[i][\cdot]$ 之后、进入下一层之前清零，否则被清零的行会「污染」后续层。
4. **前缀和要边算边取模**：$pre$ 累加时就取模，避免中间值超出 `long long`（其实 $401 \times 10^9$ 仍在范围内，但习惯上更安全）。
5. **减法要处理负数**：`pre[j] - pre[j-i]` 可能为负，C++ 中先 `% MOD` 再 `+ MOD` 再 `% MOD`；Python 的 `%` 天然返回非负，可直接用。
6. **空间**：滚动数组只需 $O(C)$；保留完整的 $n \times (C+1)$ 表也可以（$300 \times 401$ 个 `int`，约 480 KB），便于打印调试。
7. **约束天然冲突时返回 0**：若某个 $cnt_i$ 超过了该前缀长度能取到的最大逆序对数 $\frac{L(L-1)}{2}$，DP 会自然给出 0，不需要额外特判。
8. **$C$ 的定义**：取所有 $cnt_i$ 的最大值。若所有 $cnt_i = 0$（$C = 0$），数组退化为单列，代码仍正常工作。

## 5. 正确性证明

**引理 1（插入贡献的刻画）**：把一个比 $1 \sim i-1$ 全都大的新元素插入它们的某个排列，新增的逆序对数恰为该元素**右侧元素的个数** $t$，且 $t$ 可取遍 $0, 1, \dots, i-1$，每个 $t$ 唯一对应一个插入位置。

**证明**：新元素比所有已有元素都大，所以（a）它作为逆序对的**左侧**元素（下标更小、值更大）时，与它右边的每个元素都构成逆序对；（b）它作为**右侧**元素时永不构成逆序对（不存在比它更大的已有元素）。故新增数恰为其右侧元素数 $t$。插入位置共 $i$ 个（$i-1$ 个元素之间的空隙加上两端），从左到右右侧元素数依次为 $i-1, i-2, \dots, 0$，覆盖 $[0, i-1]$ 且一一对应。∎

**引理 2（DP 递推的正确性）**：设 $A_i(j)$ 表示 $i$ 个元素、逆序对数为 $j$ 的排列集合。则映射
$$\Phi: \bigcup_{t=0}^{i-1} A_{i-1}(j-t) \times \{t\} \to A_i(j),\quad (\pi, t) \mapsto \text{把最大元素插入 }\pi\text{ 从右数第 } t \text{ 个位置}$$
是双射，从而 $dp[i][j] = \sum_{t} dp[i-1][j-t]$。

**证明**：**良定义**：由引理 1，$\pi \in A_{i-1}(j-t)$ 插入后新增 $t$ 个逆序对，总数 $j$，故像确实落在 $A_i(j)$。**单射**：给定结果排列，删去其中的最大元素即唯一还原 $\pi$，其位置唯一确定 $t$，故 $\Phi$ 可逆。**满射**：任取 $\sigma \in A_i(j)$，删去最大元素得 $\pi$，设其新增贡献为 $t$，则 $\pi$ 有 $j-t$ 个逆序对，故 $(\pi,t)$ 是原像且被 $\Phi$ 映回 $\sigma$。于是 $|A_i(j)|$ 等于各 $|A_{i-1}(j-t)|$ 之和。∎

**引理 3（前缀和等价）**：对固定的 $i$，$dp[i][j] = pre[j] - pre[j-i]$（$j < i$ 时后项为 0），其中 $pre$ 是 $dp[i-1][\cdot]$ 的前缀和。

**证明**：$dp[i][j] = \sum_{t=0}^{\min(i-1,j)} dp[i-1][j-t]$，把求和变量换成 $k = j-t$ 得 $\sum_{k=\max(0, j-i+1)}^{j} dp[i-1][k] = pre[j] - pre[\max(0,j-i+1)-1]$。当 $j \ge i$ 时 $\max(0,j-i+1)-1 = j-i$，即 $pre[j]-pre[j-i]$；当 $j < i$ 时下界为 0，减去的项为空，即 $pre[j]$。两者统一为「$j-i<0$ 时后项记 0」。∎

**引理 4（截断与清零不改变答案）**：设 $C = \max_i cnt_i$。只保留 $j \le C$ 的状态、并按 $need$ 清零，不改变 $dp[n][cnt_{n-1}]$ 的取值。

**证明**：前缀逆序对数关于前缀长度单调不减（新元素插入后已有逆序对全部保留），故若某层存在 $j > C$，则此后所有层的值都 $> C \ge cnt_{n-1}$，永远无法贡献到答案列。清零操作只是把「不满足某个约束的排列」从计数中删去，而题目要求所有约束同时成立，删去它们正是所求。∎

**定理**：算法返回的 $dp[n][cnt_{n-1}]$ 即为满足全部 $requirements$ 的排列个数（模 $10^9+7$）。

**证明**：由引理 2、3，$dp[i][j]$ 在不考虑约束时正确计数了「前缀长度 $i$ 恰有 $j$ 个逆序对」的排列数。由引理 4，逐层清零等价于对满足各层约束的排列求交：第 $i$ 层清零后，$dp[i][\cdot]$ 只保留「前 $i$ 个位置构成某排列且其逆序对数等于 $cnt$（若有约束）」的那些排列，且计数不变（每个排列的贡献为 1，逐层相乘仍为 1）。因此最终 $dp[n][cnt_{n-1}]$ 恰为同时满足全部约束的排列数。∎

## 6. 复杂度分析

- **时间**：$O(n \cdot C)$，其中 $C = \max cnt_i \le 400$。$n \le 300$ 时约 $1.2 \times 10^5$ 次基本运算；前缀和、转移、清零各一遍 $O(C)$。若不做前缀和优化则为 $O(n^2 C) \approx 3.6\times 10^7$，在 $n=300$ 时也能勉强通过，但没有必要。
- **空间**：$O(C)$（滚动数组 + 前缀和数组）。若保留完整二维表则为 $O(nC)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int numberOfPermutations(int n, vector<vector<int>>& requirements) {
        const int MOD = 1000000007;
        vector<int> need(n, -1);              // need[e]：前缀长度 e+1 的逆序对要求
        int maxCnt = 0;
        for (const auto& r : requirements) {
            need[r[0]] = r[1];
            maxCnt = max(maxCnt, r[1]);
        }
        vector<long long> dp(maxCnt + 1, 0), ndp(maxCnt + 1, 0), pre(maxCnt + 1, 0);
        dp[0] = 1;                            // 空前缀：0 个逆序对
        for (int i = 1; i <= n; ++i) {
            long long s = 0;
            for (int j = 0; j <= maxCnt; ++j) {
                s = (s + dp[j]) % MOD;
                pre[j] = s;                   // pre[j] = dp[j] 的前缀和
            }
            for (int j = 0; j <= maxCnt; ++j) {
                long long v = pre[j] - (j >= i ? pre[j - i] : 0);
                ndp[j] = (v % MOD + MOD) % MOD;
            }
            int c = need[i - 1];
            if (c != -1) {                    // 有约束：整行清空，只留 j = c
                for (int j = 0; j <= maxCnt; ++j)
                    if (j != c) ndp[j] = 0;
            }
            dp.swap(ndp);
        }
        return (int)dp[need[n - 1]];          // 题目保证存在 end = n−1 的要求
    }
};
```

### Python

```python
class Solution:
    def numberOfPermutations(self, n: int, requirements: list[list[int]]) -> int:
        MOD = 10 ** 9 + 7
        need = [-1] * n                       # need[e]：前缀长度 e+1 的逆序对要求
        max_cnt = 0
        for end, cnt in requirements:
            need[end] = cnt
            max_cnt = max(max_cnt, cnt)

        dp = [0] * (max_cnt + 1)
        dp[0] = 1                             # 空前缀：0 个逆序对
        for i in range(1, n + 1):
            pre = [0] * (max_cnt + 1)
            s = 0
            for j in range(max_cnt + 1):      # 前缀和
                s = (s + dp[j]) % MOD
                pre[j] = s
            ndp = [0] * (max_cnt + 1)
            for j in range(max_cnt + 1):      # 滑动窗口 = 前缀和相减
                v = pre[j] - (pre[j - i] if j >= i else 0)
                ndp[j] = v % MOD
            c = need[i - 1]
            if c != -1:                       # 有约束：整行清空，只留 j = c
                ndp = [ndp[c] if j == c else 0 for j in range(max_cnt + 1)]
            dp = ndp
        return dp[need[n - 1]] % MOD
```

> 💡 两段代码通过全部官方示例（`2`、`1`、`1`）；与本篇独立实现的 $O(n^2C)$ 朴素 DP 在 $n \le 60$、随机约束下对拍；与 $n \le 9$ 时的全排列暴力对拍 300 组，`mismatch = 0`。$n = 300$、$cnt \le 400$ 的极限输入耗时在 0.1 秒以内。

## 8. 边界情况与易错点

1. **`end` 与「前缀长度」差一**：这是本题最高频的错。`requirements[i] = [0, 0]` 指的是「长度为 1 的前缀」，对应 `dp[1][0]`，也就是第 $i=1$ 层（用 `need[i-1]` 取值）。写成 `need[i]` 会整体错位一行。
2. **单元素前缀必为 0**：若出现 `[0, cnt]` 且 $cnt \ne 0$，答案直接是 0（DP 会自动算出 0，不必特判，但可以据此快速排查）。
3. **`j - i` 的边界**：当 $j < i$ 时窗口没被填满，减去的项应为 0。写成 `pre[j-i]` 会越界（C++ 是未定义行为，Python 会取到数组尾部的元素，产生难以察觉的错误）。
4. **截断上限取 `max cnt`**：不要固定成 400 或其他常数；也不要用 $n(n-1)/2$（那样状态数会膨胀，虽然也对但慢）。
5. **清零后不要忘记 `swap`**：`dp` 与 `ndp` 要交换而不是让 `ndp` 继续累积旧值；`ndp` 每层都会被完整重写，但若你改成「原地更新」，务必小心。
6. **模运算**：C++ 里 `pre[j] - ...` 为负时，`% MOD` 结果仍为负，必须 `+MOD` 修正；Python 无需处理。
7. **答案的列一定存在**：题目保证至少一个 $end_i = n-1$，所以 `need[n-1]` 不会是 $-1$。若不加这个保证，需要额外返回 $\sum_j dp[n][j]$。
8. **`maxCnt` 为 0**：所有 $cnt_i = 0$ 时数组长度为 1，`pre` 长度为 1，`j >= i` 永假（因为 $j = 0 < 1 \le i$），代码路径正确。
