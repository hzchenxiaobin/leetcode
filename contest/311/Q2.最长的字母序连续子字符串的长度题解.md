# LeetCode 最长的字母序连续子字符串的长度 题解

## 1. 题目概述

- **标题 / 题号**：最长的字母序连续子字符串的长度（#2414，medium）
- **链接**：https://leetcode.cn/problems/length-of-the-longest-alphabetical-continuous-substring/
- **来源**：LeetCode 第 311 场周赛 Q2
- **难度**：中等
- **标签**：字符串、线性扫描、动态规划（等价视角）

**题意**：**字母序连续字符串**是由字母表中连续字母组成的字符串，等价于 `"abcdefghijklmnopqrstuvwxyz"` 的某个子串——即内部每相邻两个字符满足后一个恰是前一个的「下一个字母」：$s[i] = s[i-1] + 1$。例如 `"abc"` 是，而 `"acb"`（不连续）、`"za"`（方向反了）不是。给定仅由小写英文字母组成的字符串 $s$，返回其**最长**的字母序连续子字符串的长度。

**约束**：

- $1 \le s.length \le 10^5$
- $s$ 仅由小写英文字母组成

> 💡 周赛第 2 题的典型形态：一道披着「字符串」外衣的**极大段扫描**模板题。从读题到写出 $O(n)$ 单趟扫描应控制在 5 分钟内——分水岭不在想到解法，而在**零调试一次通过**：初始化、重置、更新最大值三件事一次写对。

## 2. 示例

**示例 1**

```text
输入：s = "abacaba"
输出：2
解释：不同的字母序连续子字符串共 4 个："a"、"b"、"c"、"ab"，最长的是 "ab"，长度为 2。
```

**示例 2**

```text
输入：s = "abcde"
输出：5
解释："abcde" 整串都是字母序连续的，长度为 5。
```

**示例 3**（不存在任何相邻 $+1$ 对）

```text
输入：s = "za"
输出：1
解释：'z'→'a' 不满足 +1（字母表不循环环绕），最长的连续子串是任意单个字符，长度为 1。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有子串 $s[l..r]$，对每个子串检查内部每对相邻字符是否都满足 $+1$，取合法者的最大长度。枚举 $(l, r)$ 共 $O(n^2)$ 对、每对验证最坏 $O(n)$，总计 $O(n^3)$；即使把验证摊还进枚举（一旦某间隙断开就以它为新起点）也仍是 $O(n^2)$。对 $n = 10^5$ 完全不可行。

> ⚠️ 暴力把「每个子串当独立对象验证」，完全没利用「相邻间隙的判定可以**累加**」这一结构：某个间隙 $+1$ 成立，段长就天然 $+1$；不成立，段就在这个间隙处**唯一断开**。这正是把 $O(n^2)$ 压到 $O(n)$ 的杠杆。

### 3.2 核心观察：连续性只由相邻字符对决定

![核心观察：相邻字符差恰好 +1 才能续接，否则段断，串被切成极大段](images/alpha_run_concept.svg)

**关键观察**：「一个子串是否字母序连续」这个约束**只涉及相邻两个字符**——子串 $s[l..r]$ 连续 $\iff$ 对所有 $l < i \le r$ 都有 $s[i] = s[i-1] + 1$（见 §5 引理 1）。于是：

- 在每个**间隙**处做一次 $O(1)$ 判定：$s[i] - s[i-1] = 1$ 成立，则以 $i-1$ 结尾的段向右**延续**一个字符；不成立，段在间隙处**断开**，$s[i]$ 自成新段的第一个字符。
- 整个串被切分成若干**极大连续段**（runs），答案即最长段的长度——经典的「切分点 → 极大段」模型。

**实现**上无需真正记录段边界，滚动维护两个标量即可：

- $cur$：以**当前字符结尾**的最长连续段长；
- $ans$：全局最大值。

$$
cur_i = \begin{cases} cur_{i-1} + 1, & s[i] = s[i-1] + 1 \\ 1, & \text{否则} \end{cases}
$$

这正是**最长连续递增子数组**（LC 674）的字符版 DP，且 $cur$ 只依赖 $cur_{i-1}$，可滚动成一个变量。

### 3.3 算法流程

![算法流程：单趟扫描，滚动维护 cur 与 ans](images/alpha_run_scan_flow.svg)

1. 初始化 $cur = 1$、$ans = 1$（$n \ge 1$，单字符恒为合法段）；
2. 从 $i = 1$ 扫到 $n-1$，对每个间隙判定 $s[i] - s[i-1] = 1$：
   - 成立：$cur \leftarrow cur + 1$（段延续）；
   - 不成立：$cur \leftarrow 1$（段断开，$s[i]$ 自成新段起点）；
3. 每步执行 $ans = \max(ans, cur)$；
4. 扫描结束返回 $ans$。

> 💡 **可选剪枝**：小写字母只有 26 个，答案上限为 26。$cur$ 达到 26 时可直接返回，最坏省掉半趟扫描——心理安慰大于实际收益，$O(n)$ 本身已足够快。

### 3.4 示例演算

![示例演算：abacaba 的逐间隙判定与 cur/ans 变化](images/alpha_run_walkthrough.svg)

以 $s = $ `"abacaba"` 为例，逐步给出 $cur$ 与 $ans$ 的变化：

| $i$ | $s[i]$ | $s[i]-s[i-1]$ | 动作 | $cur$ | $ans$ |
|-----|--------|---------------|------|-------|-------|
| 0 | a | — | 初始化 | 1 | 1 |
| 1 | b | $+1$ | 延续 | 2 | **2** |
| 2 | a | $-1$ | 断开重置 | 1 | 2 |
| 3 | c | $+2$ | 断开重置 | 1 | 2 |
| 4 | a | $-2$ | 断开重置 | 1 | 2 |
| 5 | b | $+1$ | 延续 | 2 | 2 |
| 6 | a | $-1$ | 断开重置 | 1 | 2 |

注意 $i = 3$ 处：$a \to c$ 差为 $+2$，**跳过字母不算连续**，段照样重置。最终极大段划分为 $\{ab,\ a,\ c,\ ab,\ a\}$，答案 $2$ ✓。

## 4. 算法细节

1. **判定条件写「差」而不是「下一个字符」**：用 $s[i] - s[i-1] == 1$ 一目了然。若写成 `s[i] == s[i-1] + 1`，C++ 中 `char + int` 会提升为 `int` 再比较、结果等价，但 Python 里 `str` 与 `int` 不可加，`ord` 忘套就是比赛中的真实翻车点。
2. **滚动变量的初始化**：$cur$、$ans$ 都初始化为 **1**（不是 $0$）——$n \ge 1$ 保证单字符本身就是合法段。若把 $ans$ 初始化为 $0$ 而循环里只在「延续」分支更新，`"a"`、`"za"` 这类串会错误返回 $0$。
3. **重置后也要更新 $ans$**：$ans = \max(ans, cur)$ 放在 if/else **之外**。本题重置为 1 时不会刷掉已有的 $ans \ge 1$，但把它放进某个分支是「漏更新」类 bug 的温床——统一放置最稳。
4. **与 LC 674（最长连续递增子数组）的关系**：那题的条件是 $a[i] > a[i-1]$，本题是 $s[i] = s[i-1] + 1$——框架完全同构，都是「以 $i$ 结尾的最长合法段」的滚动 DP。识别出「约束只涉及相邻元素」即可套用同一模板。
5. **「极大段」视角的另一种实现**：也可先在所有 $s[i] \ne s[i-1] + 1$ 的间隙处打切分点，答案 = 相邻切分点的最大间距。与滚动写法等价，但多一遍统计，比赛中直接滚动最快。

## 5. 正确性证明

**引理 1**（相邻对判定）：子串 $s[l..r]$ 是字母序连续字符串 $\iff$ 对所有满足 $l < i \le r$ 的 $i$，都有 $s[i] = s[i-1] + 1$。

**证明**：（$\Rightarrow$）设 $s[l..r]$ 是字母表串 $T = $ `abc…xyz` 的子串。$T$ 中任何相邻两字母恰差 $1$，其子串保持相邻关系不变，故条件成立。（$\Leftarrow$）若所有相邻对差 $1$，则 $s[l..r]$ 的字符依次为 $c, c+1, \dots, c+(r-l)$（$c$ 为 $s[l]$ 的编码），恰是 $T$ 中从 $c$ 开始、长度 $r-l+1$ 的子串。∎

**引理 2**（滚动不变式）：扫描到下标 $i$ 时，$cur$ 等于「以 $i$ 结尾的最长字母序连续子串」的长度 $L(i)$；且 $L(i) = L(i-1) + 1$（若 $s[i] = s[i-1] + 1$），否则 $L(i) = 1$。

**证明**：对 $i$ 归纳。$i = 0$ 时，以 $0$ 结尾的连续子串只有 $s[0]$ 本身，$L(0) = 1 = cur$，成立。设 $i-1$ 时成立。若 $s[i] = s[i-1] + 1$：以 $i$ 结尾、长度 $\ge 2$ 的连续子串去掉末字符后是以 $i-1$ 结尾的连续子串（由引理 1，其相邻对条件仍全部成立），故以 $i$ 结尾的最长者恰由「以 $i-1$ 结尾的最长者」延长一位得到，$L(i) = L(i-1) + 1 = cur + 1$。若 $s[i] \ne s[i-1] + 1$：任何长度 $\ge 2$ 的以 $i$ 结尾的子串都含相邻对 $(i-1, i)$，由引理 1 不连续，故 $L(i) = 1$。∎

**定理**：算法返回 $\max_{0 \le i \le n-1} L(i)$，即最长字母序连续子字符串的长度。

**证明**：任何连续子串必以某个下标结尾，故全局最优 $= \max_i L(i)$。由引理 2，扫描中每个 $i$ 处 $cur = L(i)$，且每步执行 $ans = \max(ans, cur)$，扫描结束时 $ans = \max_i L(i)$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$——单趟扫描，每个间隙一次减法与一次比较，从 $i = 1$ 起共 $n - 1$ 步。相比暴力的 $O(n^2) / O(n^3)$，充分利用了相邻判定的可累加性。
- **空间复杂度**：$O(1)$——只维护 $cur$、$ans$ 两个标量（不计输入字符串本身）。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int longestContinuousSubstring(string s) {
        int n = s.size();
        int cur = 1, ans = 1;
        for (int i = 1; i < n; i++) {
            cur = (s[i] - s[i - 1] == 1) ? cur + 1 : 1;
            ans = max(ans, cur);
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def longestContinuousSubstring(self, s: str) -> int:
        cur = ans = 1
        for prev, ch in zip(s, s[1:]):
            cur = cur + 1 if ord(ch) - ord(prev) == 1 else 1
            ans = max(ans, cur)
        return ans
```

> 💡 `zip(s, s[1:])` 直接对齐相邻字符对；$n = 1$ 时循环体不执行、返回 $1$，边界天然正确。注意 Python 中不能写 `ch == prev + 1`（`str` 与 `int` 不可加），必须 `ord` 转码——跨语言复用思路时最常见的语法坑。

## 8. 边界情况与易错点

1. **$n = 1$（下界）**：循环不执行，必须返回 $1$——靠「$cur$、$ans$ 初始化为 $1$」保证；若初始化为 $0$ 且只在延续分支更新 $ans$，`"a"` 会返回 $0$。
2. **恰好 $+1$ 才算**：条件是 $s[i] - s[i-1] = 1$，不是「递增」也不是「相邻不重复」——$a \to c$（差 $+2$）要重置，$c \to a$（差 $-1$）也要重置。
3. **无环绕**：`"za"` 中 $z \to a$ 不算连续（字母表不是环），答案 $1$；同理以 `'z'` 结尾的段至多延续到 `'z'`，cur 不会再增长。
4. **答案上限 26**：小写字母仅 26 个，$cur$ 达 26 即可提前返回；写二分、哈希、后缀结构都属于过度设计——本题是「识别模板」而非「发明算法」。
5. **C++ 字符运算**：`s[i] - s[i-1]` 的差值范围是 $[-25, 25]$，与 $1$ 比较无溢出、无符号问题；比较运算两侧都会提升为 `int`，直接写即可。
6. **最大值更新位置**：`ans = max(ans, cur)` 必须对**每个** $i$ 执行（含重置后），放在分支外一行搞定；养成习惯可防同类题（如 LC 674 的变体）翻车。

**延伸思考**：

- 若允许**最多 $k$ 个间隙**不满足 $+1$（容错版最长连续段）？——把间隙的「成立/断开」压成 0/1 数组，用「窗口内断点数 $\le k$ 的最长窗口」双指针解决（LC 1004 最大连续 1 的个数 III 套路）。
- 若字母表**循环**（$z$ 之后接 $a$）？判定改为 $(s[i] - s[i-1] + 26) \bmod 26 = 1$，滚动扫描完全不变，答案上限仍是 26。
- 若给定**任意排列**作为字母表顺序（如 `qwerty…`）？预处理每个字符在排列中的排名，条件变成「排名差恰为 $1$」，仍是一趟扫描——模板的可迁移性正来自「约束只涉及相邻对」这一点。
