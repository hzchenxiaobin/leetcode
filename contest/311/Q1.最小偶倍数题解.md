# LeetCode 最小偶倍数 题解

## 1. 题目概述

- **标题 / 题号**：最小偶倍数（#2413，easy）
- **链接**：https://leetcode.cn/problems/smallest-even-multiple/
- **来源**：LeetCode 第 311 场周赛 Q1
- **难度**：简单
- **标签**：数学、数论、位运算

**题意**：给你一个正整数 $n$，返回 $2$ 和 $n$ 的**最小公倍数**（正整数）。

**约束**：

- $1 \le n \le 150$

> 💡 表面是「最小公倍数」，但其中一个操作数被**固定为 $2$**，$\gcd(2, n)$ 只可能是 $1$ 或 $2$——整个 LCM 问题退化为一次**奇偶判定**。签到题目标：读题到 AC 控制在 1 分钟内，一行代码解决。

## 2. 示例

**示例 1**

```text
输入：n = 5
输出：10
解释：5 和 2 的最小公倍数是 10。
```

**示例 2**

```text
输入：n = 6
输出：6
解释：6 和 2 的最小公倍数是 6。注意数字会是它自身的倍数。
```

**示例 3**（下界 $n = 1$）

```text
输入：n = 1
输出：2
解释：1 不是 2 的倍数，最小的公共倍数是 2。
```

## 3. 解题思路

### 3.1 暴力思路

最小公倍数的定义是「同时是 $2$ 的倍数和 $n$ 的倍数的最小正整数」。最朴素的实现是**枚举 $n$ 的倍数** $n, 2n, 3n, \dots$，逐个检查是否为偶数，**首个**偶数即答案：

- $n$ 为偶数：第 $1$ 个就命中，$1$ 步；
- $n$ 为奇数：第 $2$ 个（$2n$）命中，$2$ 步。

也可以反过来枚举 $2$ 的倍数 $2, 4, 6, \dots$ 找首个能被 $n$ 整除的，但奇数 $n$ 最坏要枚举约 $n$ 步（$n = 149$ 时走到 $298$），不如枚举 $n$ 的倍数聪明。两种写法都能 AC（$n \le 150$），但循环 + 判整除在签到题里是纯粹的**多余出错点**。

> ⚠️ 枚举法暴露一个关键事实：答案一定是 **$n$ 的某个倍数**（它必须是 $n$ 的倍数），而「首个偶倍数」至多出现在 $2n$——问题被压缩为「$n$ 还是 $2n$，二选一」。

### 3.2 核心观察：奇偶性决定一切

![核心观察：偶数 n 已含因子 2 返回 n；奇数 n 缺因子 2 补成 2n，一行位运算 n << (n & 1)](images/2413_parity_concept.svg)

利用 LCM 与 GCD 的对偶关系：

$$
\text{lcm}(2, n) = \frac{2n}{\gcd(2, n)}
$$

而 $\gcd(2, n)$ **只取决于 $n$ 的奇偶**：

| $n$ 的奇偶 | $\gcd(2, n)$ | $\text{lcm}(2, n)$ | 直觉 |
|-----------|--------------|--------------------|------|
| 偶数 | $2$ | $\dfrac{2n}{2} = n$ | $n$ 已含因子 $2$，自身就是 $2$ 的倍数 |
| 奇数 | $1$ | $\dfrac{2n}{1} = 2n$ | $n$ 不含因子 $2$，恰好补一个 $2$ |

于是答案化为一条**奇偶判定**：

$$
\text{ans} = \begin{cases} n, & n \text{ 为偶数} \\ 2n, & n \text{ 为奇数} \end{cases}
$$

> 💡 **一行位运算**：`n & 1` 即奇偶标志（奇数为 $1$、偶数为 $0$），于是 $\text{ans} = n \ll (n\,\&\,1)$——奇数左移 $1$ 位（乘 $2$），偶数左移 $0$ 位（不变）。把「补不补因子 $2$」直接编码成**移位量**，无分支。

### 3.3 算法流程

![算法流程：输入 n → 判偶 → 偶返回 n / 奇返回 2n，与暴力枚举、LCM 公式两条路径对照](images/2413_algorithm_flow.svg)

三条路径殊途同归，推荐第一条：

1. **奇偶判定**（推荐）：判 $n$ 是否偶数 $\to$ 偶返 $n$、奇返 $2n$，$O(1)$；
2. **LCM 公式**：$\text{lcm}(2, n) = 2n / \gcd(2, n)$，需 GCD 例程；对固定的 $2$ 来说 GCD 就是奇偶判定，故等价但更绕；
3. **暴力枚举**：沿 $n$ 的倍数找首个偶数，$O(1) \sim O(2)$ 步，能 AC 但多写一个循环。

### 3.4 示例演算

![示例演算：n=5 奇数沿倍数序列 5、10 找到首个偶数 10；n=6 偶数第一步即命中 6](images/2413_example_walkthrough.svg)

- **示例 1** $n = 5$（奇）：$5$ 的倍数 $5, 10, \dots$ 中，$5$ 是奇数 ✗，$10$ 是偶数 ✓ $\to$ 答案 $10 = 2n$。公式验证：$\gcd(2, 5) = 1$，$\text{lcm} = \dfrac{2 \times 5}{1} = 10$ ✓。
- **示例 2** $n = 6$（偶）：$6$ 本身已是 $2$ 的倍数，第一步命中 $\to$ 答案 $6 = n$。公式验证：$\gcd(2, 6) = 2$，$\text{lcm} = \dfrac{2 \times 6}{2} = 6$ ✓。
- **示例 3** $n = 1$（奇）：$1$ 不是 $2$ 的倍数，补一个因子 $2$ $\to$ 答案 $2 = 2n$ ✓。

## 4. 算法细节

1. **答案的候选集只有两个**：由「答案是 $n$ 的倍数」且「首个偶倍数 $\le 2n$」（见 §5 引理 2），答案 $\in \{n, 2n\}$，不存在第三个候选——这是本题能把算法压到一次判定的全部依据。
2. **奇偶判定的三种等价写法**：`n % 2 == 0`（取模）、`n & 1`（取最低位）、`n % 2`（直接当移位量）。比赛时写哪个都行，`n & 1` 最短。
3. **无分支折叠**：$\text{ans} = n \ll (n\,\&\,1)$ 把 if/else 折叠进移位量。对本题性能毫无影响（就一次运算），但它是「用算术消除分支」的最小范例，值得记住。
4. **走通用公式时的写法**：$\text{lcm}(a, b) = a / \gcd(a, b) \cdot b$——**先除后乘**防溢出。本题 $2n \le 300$ 无溢出风险，但习惯要养对。
5. **为什么不用辗转相除**：$\gcd(2, n)$ 的定义域小到只有 $\{1, 2\}$，一次位与就能求出，任何通用 GCD 例程（`__gcd`、`math.gcd`）在这里都是杀鸡用牛刀——**识别固定常数带来的退化**，是签到题提速的关键。

## 5. 正确性证明

**引理 1**（公倍数都是 $n$ 的倍数）：任何正整数 $m$ 若同时是 $2$ 与 $n$ 的倍数，则 $m$ 是 $n$ 的倍数；故 $\text{lcm}(2, n)$ 等于「$n$ 的正倍数中最小的偶数」。

**证明**：$m$ 是 $n$ 的倍数即 $n \mid m$，由定义直接成立。反之，「$n$ 的倍数中的偶数」必然同时是 $2$ 的倍数，两集合中的公共元一致，最小元即 $\text{lcm}(2, n)$。∎

**引理 2**（首个偶倍数的位置）：$kn$ 为偶数 $\iff$ $k$ 为偶数**或** $n$ 为偶数。故首个偶倍数在 $k = 1$（$n$ 偶）或 $k = 2$（$n$ 奇）取得，且不超过 $2n$。

**证明**：由素因子分解，$kn$ 含因子 $2$ 当且仅当 $k$ 或 $n$ 至少其一含因子 $2$。若 $n$ 偶，$k = 1$ 时 $n$ 已偶；若 $n$ 奇，$kn$ 偶 $\iff$ $k$ 偶，最小偶 $k$ 为 $2$，得 $2n$。∎

**定理**：$\text{lcm}(2, n) = \begin{cases} n, & 2 \mid n \\ 2n, & 2 \nmid n \end{cases}$

**证明**：由引理 1 只需在 $n$ 的倍数序列 $n, 2n, 3n, \dots$ 中取最小偶数。$n$ 偶时，$n$ 是序列首项且已偶，为最小，答案 $n$；$n$ 奇时，序列奇数项 $kn$（$k$ 奇）均为奇数，最小偶数项为 $k = 2$ 的 $2n$，答案 $2n$。两种情形均与 $2n / \gcd(2, n)$ 一致（$\gcd$ 分别为 $2$ 与 $1$）。∎

## 6. 复杂度分析

- **时间复杂度**：$O(1)$——一次位与、至多一次移位，常数步。对照：暴力枚举 $n$ 的倍数最多 $2$ 步也是 $O(1)$，但带循环与判整除的常数与出错面更大；通用 $\gcd$ 为 $O(\log \min(2, n)) = O(1)$，同样退化。
- **空间复杂度**：$O(1)$——无额外存储。

> 💡 本题是「通用算法因**固定常数**退化为判定」的极简范例：LCM + GCD 是 $O(\log)$ 的通用套路，固定一操作数为 $2$ 后，$\gcd$ 塌缩成一次位与。一旦两操作数都任意，就回到通用 GCD/LCM。

## 7. 参考代码

### C++（奇偶判定）

```cpp
class Solution {
public:
    int smallestEvenMultiple(int n) {
        return n & 1 ? n << 1 : n;
    }
};
```

### C++（一行位运算，无分支）

```cpp
class Solution {
public:
    int smallestEvenMultiple(int n) {
        return n << (n & 1);
    }
};
```

### Python

```python
class Solution:
    def smallestEvenMultiple(self, n: int) -> int:
        return n if n % 2 == 0 else n * 2
```

> 💡 Python 同样可写 `n << (n & 1)`；走通用公式则是 `2 * n // math.gcd(2, n)`，便于向「任意两数 LCM」推广。三种写法在 $n \le 150$ 下毫无性能差异，比赛中选最顺手的。

## 8. 边界情况与易错点

1. **$n = 1$（下界）**：答案是 $2$ 而不是 $1$——$1$ 不是 $2$ 的倍数。奇偶判定分支天然覆盖，无需特判，但**别顺手写成 `min(2, n)`**，那是把「最小公倍数」误读成「最小公**因**数级别」的典型错误。
2. **别答成 $n + 2$**：「补一个 $2$」是**乘**上因子 $2$（$2n$），不是加 $2$。比赛紧张时这类手滑比想象中常见。
3. **无溢出**：$n \le 150 \Rightarrow 2n \le 300$，`int` 绰绰有余；但走通用 LCM 公式时仍建议养成「先除后乘」的习惯（`a / gcd(a, b) * b`）。
4. **返回类型**：接口返回 `int`，正常实现不会越界；若用浮点（如 `pow(2, ...)`）反而引入精度风险，完全没必要。
5. **签到题的真正考点**：从「最小公倍数」一词**立刻**跳到「固定含 $2$，故只需判奇偶」——中间不经过枚举、不经过辗转相除。读题 $10$ 秒内定方案，是 Q1 拉开时间差的地方。
