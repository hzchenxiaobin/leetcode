# LeetCode 反转二叉树的奇数层 题解

## 1. 题目概述

- **标题 / 题号**：反转二叉树的奇数层（#2415，medium）
- **链接**：https://leetcode.cn/problems/reverse-odd-levels-of-binary-tree/
- **来源**：LeetCode 第 311 场周赛 Q3
- **难度**：中等
- **标签**：树、广度优先搜索、深度优先搜索、完美二叉树

**题意**：给定一棵**完美**二叉树的根节点 `root`（所有父节点都恰有两个子节点，且所有叶子节点在同一层）。节点的**层号**定义为它到根之间的边数（根为第 $0$ 层）。要求把每个**奇数层**的节点值按该层从左到右的顺序**整体反转**——例如某奇数层值为 $[2,1,3,4,7,11,29,18]$，反转后应变为 $[18,29,11,7,4,3,1,2]$。反转后返回树的根节点。

**约束**：

- 树中节点数目在 $[1, 2^{14}]$ 内（即深度至多 $13$ 的完美二叉树）
- $0 \le \text{Node.val} \le 10^5$
- `root` 是一棵完美二叉树

> 💡 周赛第 3 题的典型形态：**模板题 + 一个关键结构性质**。BFS 层序遍历是骨架，「反转 = 对称位置换值」是灵魂。分水岭在于能否第一时间把「反转一层」翻译成「层内第 $i$ 个与倒数第 $i$ 个交换」，从而避免任何序列化/重建的笨功夫——从读题到提交应控制在 10 分钟内。

## 2. 示例

```text
输出：[2,5,3,8,13,21,34]

```


**示例 3**（多层奇数层同时反转）

```text
输出：[0,2,1,0,0,0,0,2,2,2,2,1,1,1,1]
解释：第 1 层 [1,2] 反转为 [2,1]；第 3 层 [1,1,1,1,2,2,2,2] 反转为 [2,2,2,2,1,1,1,1]。
第 0 层和第 2 层是偶数层，保持不变。
```

## 3. 解题思路

### 3.1 暴力思路

最朴素的想法是「**序列化 → 反转 → 重建**」：层序遍历把所有值读进数组，利用完美二叉树的堆式下标——第 $d$ 层占据区间 $[2^d - 1,\ 2^{d+1} - 2]$——对每个奇数层反转对应区段，再按数组重建整棵树。这样做时间虽也是 $O(n)$，但要**两遍遍历 + 重建树 + $O(n)$ 辅助数组**，重建指针的代码又长又易错，在比赛里纯属给自己挖坑。

稍微收敛一点的是「**收集 → reverse → 回填**」三步 BFS：逐层把节点收进列表，奇数层反转值数组后再逐个写回节点。这已可 AC，但仍多出一趟「回填」。更朴素的对照则是 $O(n^2)$ 的两两枚举：对每对节点判断「是否同奇数层且层内位置对称」再交换——完全没利用层序天然有序的结构。

> ⚠️ 这些做法共同的浪费在于：没意识到「反转一层」根本**不需要**整体收集再回填——它就是若干次**不相交的对称对交换**，在层序遍历「路过」这一层时顺手就能做完。

### 3.2 核心观察：反转 = 对称位置的值交换

![核心观察：奇数层反转等于层内对称位置交换值，只动 val 不动指针](images/2415_bfs_level_swap_concept.svg)

**关键观察**：「反转一层」等价于「层内第 $i$ 个与倒数第 $i$ 个节点**交换值**」（见 §5 引理 1）。于是问题被拆成两个独立的小问题：

- **怎么按层拿节点**：标准 BFS 层序遍历，每轮取出完整一层，天然按从左到右有序；
- **怎么反转**：双指针 $l$ 从头、$r$ 从尾向中间逼近，每步 `swap(level[l]->val, level[r]->val)`。

更重要的一点是**值与结构分离**：交换的只是 `val`，`left` / `right` 指针一概不动。树的形状、后续层的遍历顺序完全不受影响——这正是「边遍历边交换」安全性的来源。而完美二叉树送了一份礼物：第 $d$ 层恰有 $2^d$ 个节点，**奇数层的节点个数必为偶数**，双指针配对不存在落单的中心节点。

### 3.3 算法流程：BFS + 双指针

![算法流程：层序 BFS，奇数层双指针交换值](images/2415_bfs_two_pointer_flow.svg)

1. `root` 入队，`depth = 0`；
2. 每轮循环开始时取层快照 `sz = q.size()`，把队首 `sz` 个节点依次弹出存入 `level` 数组（同时把各自的孩子入队）；
3. 若 `depth` 为奇数：令 $l = 0$、$r = sz - 1$，当 $l < r$ 时交换 `level[l]->val` 与 `level[r]->val`，然后 $l{+}{+}$、$r{-}{-}$；
4. `depth++`，回到第 2 步，直到队列为空，返回 `root`。

> 💡 每层只交换 $2^{d-1}$ 对（一半），全树合计不超过 $n/2$ 次交换——「反转」被摊还成了常数代价。

### 3.4 解法二：镜像成对 DFS（$O(\log n)$ 空间）

![解法二：镜像成对 DFS，一次递归同时站在两个对称位置](images/2415_dfs_mirror_pairs.svg)

完美二叉树左右严格镜像，于是可以定义 $\mathrm{dfs}(u, v, d)$：**同时**遍历两个关于中轴对称的节点 $u$、$v$。

- 入口：$\mathrm{dfs}(\text{root->left},\ \text{root->right},\ 1)$；
- $d$ 为奇数时交换 $u\to\text{val}$ 与 $v\to\text{val}$；
- 递归 $\mathrm{dfs}(u\to\text{left},\ v\to\text{right},\ d+1)$（外侧配对）与 $\mathrm{dfs}(u\to\text{right},\ v\to\text{left},\ d+1)$（内侧配对）；
- $u$ 为空即返回——完美树保证 $u$、$v$ 同生同灭，判一个即可。

每次调用恰好站在「层内第 $i$ 个」与「倒数第 $i$ 个」这对镜像位上，**路过即交换**，无需队列，递归栈深 = 树高 $\le 14$。这与 LC 101（对称二叉树）的成对遍历是同一套手法。

### 3.5 示例演算

![示例 3 演算：两个奇数层各反转一次，偶数层原封不动](images/2415_example_walkthrough.svg)

以示例 3 的 4 层完美树走查 BFS（层值按从左到右记）：

| 层号 $d$ | 层内节点数 | 层值序列 | 奇偶 | 动作 | 交换次数 |
|---------|-----------|---------|------|------|---------|
| 0 | 1 | $[0]$ | 偶 | 不动，孩子入队 | 0 |
| 1 | 2 | $[1, 2]$ | **奇** | $l=0, r=1$：swap → $[2, 1]$ | 1 |
| 2 | 4 | $[0, 0, 0, 0]$ | 偶 | 不动，孩子入队 | 0 |
| 3 | 8 | $[1,1,1,1,2,2,2,2]$ | **奇** | 4 对 swap → $[2,2,2,2,1,1,1,1]$ | 4 |

最终层序序列 $[0,2,1,0,0,0,0,2,2,2,2,1,1,1,1]$ ✓。全树 15 个节点只做了 5 次交换。

## 4. 算法细节

1. **层快照不可省**：进入每轮循环必须先 `sz = q.size()` 固定本层节点数，再循环弹出——否则「边弹边入」会让本层与新入队的孩子混在一段里，配对全部错位。这是 BFS 分层的标准纪律。
2. **双指针写 `while (l < r)`**：严格小于，只交换前一半。写成 `l <= r` 虽然结果不错（中间不存在的节点交换被跳过），但语义含糊；完美树奇数层恰偶数个节点，$l$ 与 $r$ 不会相遇在同一节点。
3. **交换的地址语义**：C++ 中 `swap(level[l]->val, level[r]->val)` 交换的是两个节点内部的值字段；千万不要写成 `swap(level[l], level[r])`（那只是交换数组里的指针，对树毫无影响）或去交换节点本身的 `left/right`。
4. **完美树的「判一得二」**：`if (u->left)` 成立则 `u->right` 必非空，两个孩子一起入队；同理 DFS 里判 `u` 为空即可同时挡住 $v$。这一性质**只在完美二叉树上成立**，是题目结构送的红利。
5. **DFS 入口的两种写法**：主推 $\mathrm{dfs}(\text{root->left}, \text{root->right}, 1)$，语义直白；也可写 $\mathrm{dfs}(\text{root}, \text{root}, 0)$——根与自身「配对」，$d=0$ 是偶数不交换，递归自然落到 $(\text{left}, \text{right}, 1)$，且对 $n=1$ 天然安全，但「自己和自己配对」的绕弯在比赛里更容易笔误。
6. **数组下标视角（对照理解用）**：完美树层序即堆序，第 $d$ 层占据下标区间 $[2^d-1,\ 2^{d+1}-2]$，反转即反转该区段。这个视角在本题是杀鸡用牛刀，但换成「给定数组直接问结果」类问题时很好用。
7. **`depth` 用传参递增而非全局变量**：BFS 里 `depth++` 放每轮末尾；DFS 里把 `d+1` 显式传入递归。两种写法都不易错，最忌讳的是「以为自己在第 $k$ 层其实差一」的 off-by-one。

## 5. 正确性证明

**引理 1**（反转的逐对分解）：设 $A = (a_0, a_1, \dots, a_{m-1})$ 为一序列，则「反转 $A$」等价于对所有满足 $0 \le i < \lfloor m/2 \rfloor$ 的下标 $i$，交换 $a_i$ 与 $a_{m-1-i}$。

**证明**：当 $i < \lfloor m/2 \rfloor$ 时恒有 $i \ne m-1-i$，故这些对换**两两不相交**（每个下标至多参与一次交换），执行顺序无关紧要。执行完毕后，位置 $i$ 上存放的是原 $a_{m-1-i}$（$i$ 参与了对换 $(i,\ m-1-i)$），位置 $m-1-i$ 上存放原 $a_i$；若 $m$ 为奇数，中间位置 $\lfloor m/2 \rfloor$ 未参与任何交换、保持原值——这正是反转序列的定义。∎

**引理 2**（BFS 层序不变式）：第 $d$ 轮循环开始时，队列恰好包含第 $d$ 层的全部 $2^d$ 个节点，且按从左到右排列。

**证明**：对 $d$ 归纳。$d = 0$：队列仅含 `root`，即第 0 层唯一节点。设第 $d$ 轮开始时命题成立：本轮按序弹出第 $d$ 层节点 $u_0, u_1, \dots, u_{2^d-1}$，每个 $u_j$ 依次压入 $u_j\to\text{left},\ u_j\to\text{right}$（完美树保证两孩子皆存在）。由二叉树的层次结构，第 $d+1$ 层从左到右恰为 $u_0\to\text{left},\ u_0\to\text{right},\ u_1\to\text{left}, \dots, u_{2^d-1}\to\text{right}$，与入队顺序一致，且本轮弹空后队列中再无其他节点，故第 $d+1$ 轮开始时命题成立。∎

**定理**（BFS 解法正确性）：算法结束后，每个奇数层的节点值序列恰为原序列的反转，偶数层及树的结构不变。

**证明**：由引理 2，第 $d$ 轮中 `level` 数组恰为第 $d$ 层从左到右的节点序列。当 $d$ 为奇数时，双指针循环对每对 $(i,\ 2^d-1-i)$（$0 \le i < 2^{d-1}$）执行一次值交换，由引理 1（此处 $m = 2^d$ 为偶数），该层值序列被反转。当 $d$ 为偶数时不执行交换，值不变。又因所有交换只触及 `val` 字段，指针未动，故由引理 2 的归纳过程，后续各轮的节点顺序与树的结构不受任何影响。归纳至队空，结论对每一层成立。∎

**引理 3**（镜像配对覆盖）：对每个 $d \ge 1$，DFS 在第 $d$ 层产生的全部调用 $(u, v)$ 恰为 $\{(\text{第 } d \text{ 层第 } i \text{ 个},\ \text{第 } d \text{ 层倒数第 } i \text{ 个}) : 0 \le i \le 2^d - 1\}$，即每对对称节点恰被一次调用覆盖。

**证明**：对 $d$ 归纳。$d = 1$：唯一调用 $(\text{root->left}, \text{root->right})$，即第 1 层的第 $0$ 个与倒数第 $0$ 个，成立。设第 $d$ 层某调用为 $(u, v)$，其中 $u$ 是第 $d$ 层从左数第 $i$ 个（$0$ 起），$v$ 是第 $j = 2^d - 1 - i$ 个。则 $u\to\text{left},\ u\to\text{right}$ 是第 $d+1$ 层的第 $2i,\ 2i+1$ 个；$v\to\text{left},\ v\to\text{right}$ 是第 $2j = 2^{d+1} - 2 - 2i$、$2j + 1 = 2^{d+1} - 1 - 2i$ 个。于是：

- 递归 $(u\to\text{left},\ v\to\text{right})$ 配对下标 $(2i,\ 2^{d+1} - 1 - 2i)$，恰为「第 $2i$ 个 ↔ 倒数第 $2i$ 个」；
- 递归 $(u\to\text{right},\ v\to\text{left})$ 配对下标 $(2i+1,\ 2^{d+1} - 2 - 2i)$，恰为「第 $2i+1$ 个 ↔ 倒数第 $2i+1$ 个」。

当 $i$ 取遍 $0 \sim 2^d - 1$ 时，$2i$ 与 $2i+1$ 合起来取遍 $0 \sim 2^{d+1} - 1$，故第 $d+1$ 层每个下标恰出现在一个配对中。∎

**定理**（DFS 解法正确性）：DFS 结束后，每个奇数层的值序列恰被反转，偶数层不变。

**证明**：入口深度为 $1$，递归深度增一，故到达第 $d$ 层的调用其参数 $d$ 恰等于层号。由引理 3，第 $d$ 层每对对称节点恰被一次调用访问；当 $d$ 为奇数时该调用执行一次值交换，由引理 1，该层序列反转；$d$ 为偶数时不交换。所有调用只交换 `val`，结构不变。∎

## 6. 复杂度分析

- **时间复杂度**（两种解法均为 $O(n)$）：BFS 每个节点恰好入队、出队各一次，交换次数合计 $\sum_{\text{奇 } d} 2^{d-1} \le n/2$；DFS 每次调用处理一对节点，调用总数 $= (n-1)/2$，每次 $O(1)$。
- **空间复杂度**：
  - BFS：$O(n)$——队列最宽时持有最底层的 $2^{D} \approx (n+1)/2$ 个节点指针（$D$ 为树高），另有所在层的 `level` 数组 $O(2^D)$；
  - DFS：$O(\log n)$——递归栈深 = 树高，$n \le 2^{14}$ 时至多 $14$ 层。完美二叉树「宽度指数、深度线性」的差距，正是 DFS 空间优势的来源。

## 7. 参考代码

### 解法一：BFS + 双指针（C++，比赛主推）

```cpp
class Solution {
  public:
    TreeNode* reverseOddLevels(TreeNode* root) {
        queue<TreeNode*> q;
        q.push(root);
        int depth = 0;
        while (!q.empty()) {
            int sz = q.size();
            vector<TreeNode*> level;
            level.reserve(sz);
            for (int i = 0; i < sz; i++) {
                TreeNode* u = q.front();
                q.pop();
                if (u->left) {          // 完美树：判 left 即知双子皆存
                    q.push(u->left);
                    q.push(u->right);
                }
                level.push_back(u);
            }
            if (depth & 1) {
                for (int l = 0, r = sz - 1; l < r; l++, r--)
                    swap(level[l]->val, level[r]->val);
            }
            depth++;
        }
        return root;
    }
};
```

### 解法一：BFS + 双指针（Python）

```python
class Solution:
    def reverseOddLevels(self, root: Optional[TreeNode]) -> Optional[TreeNode]:
        q, depth = deque([root]), 0
        while q:
            sz = len(q)                # 层快照
            level = []
            for _ in range(sz):
                u = q.popleft()
                if u.left:             # 完美树：双子同在
                    q.append(u.left)
                    q.append(u.right)
                level.append(u)
            if depth & 1:
                for l, r in zip(range(sz // 2), range(sz - 1, sz // 2 - 1, -1)):
                    level[l].val, level[r].val = level[r].val, level[l].val
            depth += 1
        return root
```

### 解法二：镜像成对 DFS（C++，$O(\log n)$ 空间）

```cpp
class Solution {
  public:
    TreeNode* reverseOddLevels(TreeNode* root) {
        dfs(root->left, root->right, 1);
        return root;
    }

  private:
    void dfs(TreeNode* u, TreeNode* v, int depth) {
        if (!u) return;                // 完美树：u、v 同生同灭
        if (depth & 1) swap(u->val, v->val);
        dfs(u->left, v->right, depth + 1);   // 外侧配对
        dfs(u->right, v->left, depth + 1);   // 内侧配对
    }
};
```

### 解法二：镜像成对 DFS（Python）

```python
class Solution:
    def reverseOddLevels(self, root: Optional[TreeNode]) -> Optional[TreeNode]:
        def dfs(u: Optional[TreeNode], v: Optional[TreeNode], depth: int) -> None:
            if not u:
                return
            if depth & 1:
                u.val, v.val = v.val, u.val
            dfs(u.left, v.right, depth + 1)
            dfs(u.right, v.left, depth + 1)

        dfs(root.left, root.right, 1)
        return root
```

> 💡 Python 也有更「行数最少」的写法：奇数层直接 `vals = [u.val for u in level][::-1]` 再逐个回填——思路即 §3.1 的三步版，正确但比双指针多一趟；比赛里选最不容易出错的那个。

## 8. 边界情况与易错点

1. **$n = 1$（下界）**：只有第 $0$ 层（偶数层），BFS 首轮不交换直接返回 `root`；DFS 入口 `root->left` 为空立即返回。两种写法都无需特判。
2. **层号从 $0$ 起**：根是第 $0$ 层，`root` 的孩子才是第 $1$ 个奇数层。「层号 = 到根的边数」不是「高度」也不是「节点个数编号」——比赛时把 `depth` 初始化成 $1$ 是最常见的翻车点。
3. **只换值、不动结构**：交换 `val` 字段，绝不交换节点指针或子树引用。虽然对「值序列」而言交换整棵子树看似等价，但那会改变树的结构（且实现远比 swap val 复杂），不符合题意。
4. **双指针边界 `l < r`**：只交换前一半；奇数层恰偶数个节点，不会出现 $l = r$ 的中心节点。
5. **层快照先行**：`sz = q.size()` 必须在弹出任何节点之前执行，否则本层与孩子层的节点在队列中粘连，配对错位且难以调试。
6. **完美树性质别过度外推**：「判 `left` 即知双子皆存」「$u$、$v$ 同生同灭」都依赖完美二叉树；换成任意二叉树，DFS 镜像配对直接失效（见延伸思考），BFS 仍成立但入队需分别判两个孩子。
7. **返回值就是 `root`**：所有修改都发生在原树上，最后返回原根即可；不要重新建树、也不要返回新节点。
8. **数值范围**：$0 \le \text{val} \le 10^5$，`int` 绰绰有余，无溢出问题——本题的坑全在「层号与配对」而非数值。

**延伸思考**：

- 若树是**任意**二叉树（非完美）？BFS 逐层收集 + 双指针反转依旧成立（每层节点照样有序入队，只是个数不再保证偶数，双指针遇到奇数个节点时中心自然不动）；但 DFS 镜像配对失效——左右子树形状不再镜像，$u$、$v$ 可能一有一无。**BFS 鲁棒、DFS 优雅**，这是两解法最本质的取舍。
- 若要求反转的是**第 $k$ 的倍数层**？把判定条件 `depth & 1` 换成 `depth % k == 0` 即可，配对结构完全不变——说明「分层 + 对称交换」是可复用的框架，奇偶只是最简参数。
- 若要反转的不是值而是**结构**（每个奇数层节点的左右孩子指针互换）？那就是「奇数层版」的 226：对每个奇数层节点 `swap(u->left, u->right)`，DFS 中把交换从 `val` 换成指针即可——注意此时递归入口与遍历顺序要在交换**之后**保持一致，才不会把配对走乱。
