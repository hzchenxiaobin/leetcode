# LeetCode 最长 V 形对角线段的长度 题解

## 1. 题目概述

- **标题 / 题号**：最长 V 形对角线段的长度（#3459，hard）
- **链接**：https://leetcode.cn/problems/length-of-longest-v-shaped-diagonal-segment/
- **来源**：LeetCode 第 437 场周赛 Q4
- **难度**：困难
- **标签**：记忆化搜索、动态规划、数组、矩阵

**题意**：给定 $n \times m$ 的矩阵 `grid`，元素只取 $0, 1, 2$。一条 **V 形对角线段** 是一串沿对角方向行进的格子，满足：

1. **首格值为 $1$**，后续格子的值按无限序列 $2, 0, 2, 0, \dots$ 依次排列；
2. 先沿某个对角方向（$\searrow \swarrow \nwarrow \nearrow$ 之一）直走；
3. 在**保持序列模式**的前提下，全程**至多允许一次顺时针 $90°$ 转向**到另一个对角方向。

求最长合法段的长度，不存在返回 $0$。

**约束**：

- $1 \le n, m \le 500$
- `grid[i][j]` $\in \{0, 1, 2\}$

本题的三个「隐藏自由度」——起点、初始方向、拐弯时机——叠加起来组合爆炸，但模式序列的特殊结构（周期 2 且后继单值）让状态设计可以非常省。

解释：(0,2) → (1,3) → (2,4) 沿 ↘ 走，值依次 1,2,0；

## 3. 解题思路

### 3.1 暴力思路：枚举一切

最朴素的做法：枚举**起点**（值为 $1$ 的格子）× **初始方向**（4 个）× **第一段长度** × **拐弯时机**，再沿拐弯后的方向一直走。对角线一步同时改变行列，一段最多走 $\min(n, m)$ 步，每个起点的检验代价是 $O\big(\min(n,m)^2\big)$；起点最多 $nm$ 个，总代价约 $4nm \cdot \min(n,m)^2$，在 $500 \times 500$ 下约 $2.5 \times 10^{11}$，完全不可行。

瓶颈在于**同一段路径被反复重走**：从拐弯点出发的第二段，与「不拐弯继续直走」的后缀高度重叠。这就是记忆化的切入点。

### 3.2 核心观察：后继值唯一 → 期望值不必入状态

![核心观察：后继值唯一与顺时针方向环](images/c437_q4_succ_concept.svg)

把模式序列写开：位置 $t = 0, 1, 2, \dots$ 上的值依次为 $1, 2, 0, 2, 0, \dots$。三个关键观察：

1. **后继单值**：序列中每个值的「下一个」是确定的——$\text{succ}(1) = 2$，$\text{succ}(2) = 0$，$\text{succ}(0) = 2$。也就是说，**知道当前格的值，下一格该填什么就完全定了**，状态里根本不用记录走了多少步（奇偶性）。
2. **$1$ 只出现在起点**：位置 $t \ge 1$ 上的值永远是 $0$ 或 $2$，所以值为 $1$ 的格子只能是段首。于是对任何格子，「它该匹配的期望值」若有，就必然等于它自己的 `grid` 值——记忆化按 $(i, j, d, \text{turned})$ 键控不会串味。
3. **顺时针方向环**：把 4 个对角方向按顺时针排成环 $\searrow \to \swarrow \to \nwarrow \nearrow \to \searrow$（行向下、列向右的屏幕坐标下，$(+1,+1) \to (+1,-1) \to (-1,-1) \to (-1,+1)$），则「顺时针 $90°$ 转向」就是取环上的下一个：$d' = (d + 1) \bmod 4$。

> 💡 观察 1 是本题能把状态压到四元组的根本原因：一般「按周期序列填值」的题需要在状态里带「步数 $\bmod$ 周期」，本题周期为 2 且后继函数单值，这一维被吸收进了格子自身的值里。

### 3.3 算法流程：四元组状态的记忆化 DFS

![状态设计与转移](images/c437_q4_state_dp.svg)

定义 $\text{dfs}(i, j, d, \text{turned})$：当前走到 $(i, j)$（**它的值已与模式匹配**），下一步沿方向 $d$ 行进；$\text{turned} = 0$ 表示尚未用掉那次转向（在 $(i,j)$ 处既可直行也可顺时针拐弯），$\text{turned} = 1$ 表示已转过（$d$ 已是拐弯后的方向，只能直行）。返回值是**从 $(i, j)$ 出发（含自身）能延展出的最长段长**。

转移（`best` 初值为 $1$，即当前格自身）：

- **直行**：设 $(\Delta_i, \Delta_j) = \text{DIRS}[d]$，落点 $\text{nxt} = (i + \Delta_i, j + \Delta_j)$，若在界内且 $\text{grid}[\text{nxt}] = \text{succ}(\text{grid}[i][j])$，则 $\text{best} = \max(\text{best},\ 1 + \text{dfs}(\text{nxt}, d, \text{turned}))$；
- **拐弯**（仅 $\text{turned} = 0$）：$d' = (d + 1) \bmod 4$，落点沿 $d'$，匹配条件同上，则 $\text{best} = \max(\text{best},\ 1 + \text{dfs}(\text{nxt}, d', 1))$。

主循环枚举所有 $\text{grid}[i][j] = 1$ 的格子作为起点：$\text{ans} \ge 1$（单格也是合法段）；再对 4 个方向 $d$，若邻格在界内且值为 $2 = \text{succ}(1)$，则 $\text{ans} = \max(\text{ans},\ 1 + \text{dfs}(\text{邻格}, d, 0))$。

> ⚠️ 「在起点处就拐弯」看似是漏网之鱼，实则得到的格子序列退化为沿拐弯后方向 $(d+1) \bmod 4$ 的直线段，已被「枚举该初始方向 + 不拐弯」覆盖。所以枚举 4 个初始方向不漏解，第一段长度至少为 1 的假设也不损失一般性。

### 3.4 示例演算

![示例演算：示例 1 的 V 形路径](images/c437_q4_walkthrough.svg)

以示例 1 为例：从 $(0,2)$ 出发（值 $1$），方向 $\searrow$：

| 格子 | 值 | 位置 $t$ | 期望值 | 结果 |
|------|----|----------|--------|------|
| $(0,2)$ | $1$ | $0$ | $1$（起点） | ✓ |
| $(1,3)$ | $2$ | $1$ | $\text{succ}(1) = 2$ | ✓ |
| $(2,4)$ | $0$ | $2$ | $\text{succ}(2) = 0$ | ✓ ← 拐点，$\searrow$ 顺时针转 $\swarrow$ |
| $(3,3)$ | $2$ | $3$ | $\text{succ}(0) = 2$ | ✓ |
| $(4,2)$ | $0$ | $4$ | $\text{succ}(2) = 0$ | ✓ |

从 $(2,4)$ 继续直行 $\searrow$ 会出界，$\text{dfs}$ 的直行分支到此为止；拐弯分支把长度从 $3$ 抬到 $5$。注意拐点 $(2,4)$ 本身的值在**进入时**已被上一格检查过，拐弯时无需再查。

## 4. 算法细节

1. **方向数组按顺时针序排列**：`DIRS = [(1,1), (1,-1), (-1,-1), (-1,1)]`（$\searrow \swarrow \nwarrow \nearrow$），拐弯即 `(d + 1) % 4`。方向数组一旦乱序，「顺时针」就错了——$\searrow$ 顺时针转 $90°$ 是 $\swarrow$，不是 $\nwarrow$；
2. **后继数组**：`SUCC = [2, 2, 0]`，即 $\text{succ}(0) = 2$、$\text{succ}(1) = 2$、$\text{succ}(2) = 0$；
3. **记忆化编码**：C++ 里把四元组压成一维下标 `((i * m + j) * 4 + d) * 2 + turned`，数组大小 $8nm \le 2 \times 10^6$，`int` 足够；Python 直接 `@lru_cache`；
4. **入口检查**：主循环从值为 $1$ 的格子出发时，邻格必须等于 $\text{succ}(1) = 2$ 才调 `dfs`——这一步等价于把「起点」也纳入后继链；
5. **递归深度**：一段沿对角方向最多走 $\min(n, m)$ 步，两段合计 $\le 2\min(n, m) \le n + m \approx 1000$ 层，Python 需调大递归上限；
6. **为什么不用记「期望值」**：`dfs` 只会被「值已匹配」的格子进入，而该格的期望值就等于它自身的 `grid` 值（见 §5 引理 2 的推论），后继链自洽。

## 5. 正确性证明

记 $p(t)$ 为模式在位置 $t$ 的值：$p(0) = 1$；$t \ge 1$ 时 $p(t) = 2$（$t$ 奇）、$0$（$t$ 偶）。

**引理 1（后继唯一）**：合法段中相邻两格的值 $v_t, v_{t+1}$ 满足 $v_{t+1} = \text{succ}(v_t)$，其中 $\text{succ}(1) = 2$，$\text{succ}(2) = 0$，$\text{succ}(0) = 2$。

**证明**：逐一检验 $v_t$ 的三种取值：$v_t = 1$ 仅出现在 $t = 0$，其后为 $p(1) = 2$；$v_t = 2$ 只出现在奇数 $t$，其后 $p(t+1) = 0$；$v_t = 0$ 只出现在偶数 $t \ge 2$，其后 $p(t+1) = 2$。∎

**引理 2（$1$ 只在段首）及其推论**：合法段中值为 $1$ 的格子恰为第一个格子。**推论**：记忆化按 $(i, j, d, \text{turned})$ 键控是良定义的——所有能以「当前格 $= (i,j)$」进入 `dfs` 的调用，隐含的期望值都等于 $\text{grid}[i][j]$，不会出现两个不同期望值共用同一状态的串味。

**证明**：$t \ge 1$ 时 $p(t) \in \{0, 2\}$，值 $1$ 不出现。对推论：进入 $(i,j)$ 前调用方已验证其值匹配；由引理 1，期望链上 $(i,j)$ 的期望值是唯一的，且必须等于 $\text{grid}[i][j]$ 才可能通过验证，故所有到达同一状态的调用期望值一致。∎

**引理 3（无环）**：状态转移图是 DAG，递归必然终止。

**证明**：一条递归链上，$\text{turned}$ 从 $0$ 变 $1$ 至多一次。$\text{turned} = 0$ 阶段方向恒为 $d$，每个直行转移使位置沿 $\vec u_d$ 前进一格，投影 $\langle \text{pos}, \vec u_d \rangle$ 严格增加；拐弯后 $\text{turned} = 1$，方向恒为 $d + 1$，投影 $\langle \text{pos}, \vec u_{d+1} \rangle$ 严格增加。状态沿链不重复，图无环。∎

**定理**：算法返回的 `ans` 等于最长合法 V 形对角线段的长度 $\text{OPT}$。

**证明**：分两个方向。

（$\text{ans} \le \text{OPT}$）主循环从值为 $1$ 的格子出发；由引理 1 归纳可知，被计入计数的格子序列严格符合模式 $1, 2, 0, 2, 0, \dots$；$\text{turned}$ 从 $0$ 只能变 $1$ 一次且转向方向恒为 $(d+1) \bmod 4$（顺时针 $90°$），故每个被数到的序列都是合法段，长度不超过 $\text{OPT}$。

（$\text{OPT} \le \text{ans}$）设 $P$ 是任一合法段，起点 $s$（值为 $1$，引理 2）。若 $|P| = 1$，主循环已有 $\text{ans} \ge 1$。若 $|P| \ge 2$，不妨设第一段至少一步（「起点即拐弯」的段退化为沿拐弯后方向的直线段，已被枚举该方向覆盖），记第一步方向为 $d_0$，则落点值为 $\text{succ}(1) = 2$，主循环会调用 $\text{dfs}(s + \vec u_{d_0}, d_0, 0)$。对 $P$ 的后缀按引理 3 的拓扑序（倒序）做强归纳：**断言**——若 $P$ 的某后缀从格 $c$ 开始、下一步方向为 $d$、拐弯状态为 $\text{turned}$，则 $\text{dfs}(c, d, \text{turned}) \ge$ 该后缀的长度。后缀只剩 $c$ 一格时 $\text{dfs} \ge 1$ 成立；后缀继续时，无论是直行还是（$\text{turned} = 0$ 时的）拐弯，$\text{dfs}$ 都有对应分支，且由引理 1，$P$ 合法保证落点值等于 $\text{succ}(\text{grid}[c])$、通过分支检查，由归纳假设该分支取值 $\ge 1 + $ 剩余后缀长度。于是 $\text{dfs}(s + \vec u_{d_0}, d_0, 0) \ge |P| - 1$，即 $\text{ans} \ge |P|$。两个方向合起来，$\text{ans} = \text{OPT}$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(nm)$。状态数 $4 \cdot 2 \cdot nm = 8nm \le 2 \times 10^6$（$500 \times 500$ 时），每个状态至多 2 个分支、每支 $O(1)$ 的越界与匹配检查；主循环再花 $O(4nm)$。实测 C++ 毫秒级，Python `lru_cache` 约 $0.3$ 秒；
- **空间复杂度**：$O(nm)$，即记忆化数组 $8nm$（约 8 MB `int`）；另有递归栈深 $O(n + m)$。

## 7. 参考代码

### C++

```cpp
class Solution {
    static constexpr int DIRS[4][2] = {{1, 1}, {1, -1}, {-1, -1}, {-1, 1}};  // ↘ ↙ ↖ ↗ 顺时针序
    static constexpr int SUCC[3] = {2, 2, 0};        // succ(0)=2, succ(1)=2, succ(2)=0
    int n, m;
    vector<vector<int>> grid;
    vector<int> memo;                                // ((i*m+j)*4+d)*2+turned

    int dfs(int i, int j, int d, int turned) {
        int& res = memo[((i * m + j) * 4 + d) * 2 + turned];
        if (res != -1) return res;
        int best = 1;
        int nxt = SUCC[grid[i][j]];                  // 下一格该填的值由当前格决定
        int ni = i + DIRS[d][0], nj = j + DIRS[d][1];
        if (ni >= 0 && ni < n && nj >= 0 && nj < m && grid[ni][nj] == nxt)
            best = max(best, 1 + dfs(ni, nj, d, turned));          // 直行
        if (turned == 0) {
            int d2 = (d + 1) % 4;                    // 顺时针 90° 转向
            ni = i + DIRS[d2][0]; nj = j + DIRS[d2][1];
            if (ni >= 0 && ni < n && nj >= 0 && nj < m && grid[ni][nj] == nxt)
                best = max(best, 1 + dfs(ni, nj, d2, 1));          // 拐弯
        }
        return res = best;
    }

public:
    int lenOfVDiagonal(vector<vector<int>>& g) {
        grid = move(g);
        n = grid.size(), m = grid[0].size();
        memo.assign(n * m * 8, -1);
        int ans = 0;
        for (int i = 0; i < n; ++i)
            for (int j = 0; j < m; ++j) {
                if (grid[i][j] != 1) continue;       // 值为 1 的格子只可能是起点
                ans = max(ans, 1);
                for (int d = 0; d < 4; ++d) {
                    int ni = i + DIRS[d][0], nj = j + DIRS[d][1];
                    if (ni >= 0 && ni < n && nj >= 0 && nj < m && grid[ni][nj] == 2)
                        ans = max(ans, 1 + dfs(ni, nj, d, 0));
                }
            }
        return ans;
    }
};
```

### Python

```python
import sys
from functools import lru_cache


class Solution:
    def lenOfVDiagonal(self, grid: List[List[int]]) -> int:
        sys.setrecursionlimit(1 << 20)   # 递归深度最多约 n + m
        n, m = len(grid), len(grid[0])
        DIRS = [(1, 1), (1, -1), (-1, -1), (-1, 1)]   # ↘ ↙ ↖ ↗ 顺时针序
        SUCC = (2, 2, 0)                              # succ(0)=2, succ(1)=2, succ(2)=0

        @lru_cache(None)
        def dfs(i, j, d, turned):
            best = 1
            nxt = SUCC[grid[i][j]]
            di, dj = DIRS[d]
            ni, nj = i + di, j + dj
            if 0 <= ni < n and 0 <= nj < m and grid[ni][nj] == nxt:
                best = max(best, 1 + dfs(ni, nj, d, turned))       # 直行
            if turned == 0:
                di, dj = DIRS[(d + 1) % 4]           # 顺时针 90° 转向
                ni, nj = i + di, j + dj
                if 0 <= ni < n and 0 <= nj < m and grid[ni][nj] == nxt:
                    best = max(best, 1 + dfs(ni, nj, (d + 1) % 4, 1))   # 拐弯
            return best

        ans = 0
        for i in range(n):
            for j in range(m):
                if grid[i][j] != 1:
                    continue
                ans = max(ans, 1)
                for d in range(4):
                    ni, nj = i + DIRS[d][0], j + DIRS[d][1]
                    if 0 <= ni < n and 0 <= nj < m and grid[ni][nj] == 2:
                        ans = max(ans, 1 + dfs(ni, nj, d, 0))
        return ans
```

## 8. 边界情况与易错点

1. **`succ(0) = 2` 别写成 $0$**：序列 $\dots, 2, 0, 2, 0, \dots$ 中 $0$ 的下一个是 $2$。写反会把答案算短（示例 1~3 全错），但 `[[1]]` 这类单点样例完全测不出——对拍小随机网格兜底最稳；
2. **转向必须是顺时针**：方向数组必须按顺时针序排列，拐弯是 `(d + 1) % 4`。屏幕坐标（行向下）下 $\searrow$ 顺时针转 $90°$ 得 $\swarrow$，转成 $\nwarrow$ 就是逆时针；
3. **`turned` 维不能省**：「至多一次转向」是硬约束，省掉它会数出拐两次弯的非法长路径；同理拐弯后只能直行；
4. **单个 $1$ 是合法段**：`ans` 从 $1$ 起步而非 $0$；整个网格没有 $1$ 时输出 $0$（全 $0$ / 全 $2$ 矩阵）；
5. **起点邻格必须是 $2$**：主循环调 `dfs` 前别漏掉这个检查，它就是后继链的第一环；
6. **递归深度**：最长段约 $2\min(n, m) \le 1000$ 格，Python 默认递归限制恰为 $1000$，必须调大；C++ 递归无碍；
7. **状态数与内存**：$8nm \le 2 \times 10^6$，`int` 下标不溢出、约 8 MB，无需 `long long`；
8. **记忆化键含方向 $d$**：同一格子沿不同方向的延展互不相同，漏掉 $d$ 会互相污染。

**延伸思考**：本题能省掉「步数 $\bmod$ 周期」这一维，全靠模式 $1,2,0,2,0,\dots$ 的后继函数是单值。若模式改成 $1,2,1,0,\dots$（$\text{succ}(1)$ 出现歧义），就必须在状态中加入步数对周期取模；若允许逆时针转向，`turned` 需扩展为三态（未转 / 顺转 / 逆转）；若允许至多 $k$ 次转向，则 `turned` 变为 $0 \dots k$，状态数乘 $k+1$，总复杂度仍是线性乘积 $O(knm)$——这类「网格 + 方向 + 剩余操作次数」的状态设计套路是可迁移的。
