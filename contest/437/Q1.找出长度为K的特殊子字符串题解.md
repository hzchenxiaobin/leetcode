# LeetCode 找出长度为 K 的特殊子字符串 题解

## 1. 题目概述

- **标题 / 题号**：找出长度为 K 的特殊子字符串（#3456，easy）
- **链接**：https://leetcode.cn/problems/find-special-substring-of-length-k/
- **来源**：LeetCode 第 437 场周赛 Q1
- **难度**：简单
- **标签**：字符串、双指针

**题意**：给定字符串 `s` 和整数 `k`，判断是否存在一个长度**恰好**为 `k` 的子字符串，满足：

1. 子串内**只包含一个唯一字符**（如 `"aaa"`、`"bbb"`）；
2. 子串**左侧**紧邻字符（若存在）必须与该字符**不同**；
3. 子串**右侧**紧邻字符（若存在）必须与该字符**不同**。

存在返回 `true`，否则返回 `false`。

**约束**：

- `1 <= k <= s.length <= 100`
- `s` 仅由小写英文字母组成

签到题，数据范围极小。重点是**快速把三个条件翻译成代码**，并避开「段长 $\ge k$ 即可」的最大陷阱。

## 2. 示例

**示例 1**

```text
输入：s = "aaabaaa", k = 3
输出：true
解释：s[4..6] == "aaa"：长度为 3、所有字符相同，
      前面的字符是 'b'（与 'a' 不同），后面没有字符。
```

**示例 2**

```text
输入：s = "abc", k = 2
输出：false
解释：不存在长度为 2、仅由一个唯一字符组成且满足所有条件的子字符串。
```

**示例 3（陷阱示例）**

```text
输入：s = "aaaa", k = 2
输出：false
解释：整串只有一个长为 4 的 'a' 段。任何长度为 2 的子串都嵌在段内，
      至少一侧紧邻字符仍是 'a'。若误判「段长 >= k」会错误返回 true。
```

## 3. 解题思路

### 3.1 暴力思路

枚举全部 $n-k+1$ 个长度为 $k$ 的子串起点 $i$，逐个做三项检查：

- `s[i..i+k-1]` 内字符全部相同（$O(k)$ 扫描）；
- 左侧不同：$i=0$ 或 $s[i-1] \ne s[i]$；
- 右侧不同：$i+k=n$ 或 $s[i+k] \ne s[i]$。

时间复杂度 $O(n \cdot k)$，本题 $n \le 100$ 稳过，作为签到题可以直接交。但同一段连续相同字符被起点们反复扫描，存在冗余——一次分组扫描就能把问题变干净。

### 3.2 核心观察：合法子串 ⇔ 存在长度恰为 k 的极长段

![核心观察：合法子串必须完整覆盖一个极长段](images/c437_q1_runs_concept.svg)

把 `s` 按**连续相同字符**切分成若干**极长段**（run），例如 `"aaabaaa"` → `aaa | b | aaa`。设某段字符为 $c$、长度为 $L$：

1. **$L > k$ 无解**：从段中任取连续 $k$ 个字符——居中放置，左右两侧都撞上段内同字符 $c$；贴左边界，右侧第 $k+1$ 个字符仍在段内（因为 $L > k$）；贴右边界同理左侧撞车。三种放法全军覆没；
2. **$L = k$ 恰好可行**：整段本身就是候选子串，而段的**极长性**保证段外紧邻字符（若存在）必然 $\ne c$，条件 2、3 自动满足；
3. **$L < k$ 放不下**：子串一旦伸出段外就混入别的字符，违反条件 1。

于是判定化归为一句话：**是否存在一个极长段，其长度恰好等于 $k$**。

> ⚠️ **最大陷阱**：把判等写成 $L \ge k$。反例 `s = "aaaa", k = 2`——段长 $4 \ge 2$，但正确答案是 `false`。**必须严格相等**。

### 3.3 算法流程：双指针分组扫描

![算法流程：双指针分组扫描](images/c437_q1_flow.svg)

双指针 `i`、`j`：`i` 指向当前段起点；`j` 从 `i` 出发向右扩展，直到字符不同或越过末尾；段长即 `j - i`，等于 `k` 立即返回 `true`，否则 `i` 直接跳到 `j`（下一段起点）。两指针均单调前进，段与段互不重叠。

### 3.4 示例演算

![示例演算：aaabaaa 的分组扫描过程](images/c437_q1_walkthrough.svg)

以 `s = "aaabaaa", k = 3` 为例：第一段 `aaa` 长度 $3 = k$，直接命中返回 `true`。若 `k = 4`：三段长度分别为 $3, 1, 3$，无一等于 $4$，扫描完整串后返回 `false`。

## 4. 算法细节

1. **极长段的定义**：与两侧字符都不同（或触及字符串边界）的极大连续同字符块。相邻两段字符天然不同，无需额外比较前后段；
2. **指针跳跃**：处理完一段后 `i = j` 而非 `i = i + 1`，整段一次性跳过，保证每字符至多被 `j` 访问一次。若写 `i = i + 1`，会在同一段内反复扩展，退化成 $O(n \cdot L)$（结果仍正确，但没必要）；
3. **判等严格性**：`j - i == k` 是严格相等，不是 `>=`；
4. **Python 一行版**：`itertools.groupby` 直接产出分组，判 `any(len(list(g)) == k)` 即可。

## 5. 正确性证明

**引理 1**：任何合法子串必然**恰好覆盖**一个完整的极长段。

**证明**：设合法子串 $t = s[i..i+k-1]$ 全为字符 $c$。取包含位置 $i$ 的极长 $c$-段 $[l, r)$：$s[l..r-1]$ 全为 $c$，且 $l=0$ 或 $s[l-1] \ne c$，$r=n$ 或 $s[r] \ne c$。由 $s[i] = c$ 知 $l \le i \le r-1$。

- 若 $i > l$：则 $i-1 \in [l, r)$，$s[i-1] = c$，即子串左侧紧邻字符与 $c$ 相同，违反条件 2；
- 若 $i + k < r$：则 $i+k \in [l, r)$，$s[i+k] = c$，违反条件 3。

故必有 $i = l$ 且 $i + k = r$，即子串完整覆盖该段，且 $k = r - l = L$。∎

**引理 2**：每个长度恰为 $k$ 的极长段本身就是一个合法子串。

**证明**：设极长段 $[l, r)$，$r - l = k$，字符为 $c$。段内字符全为 $c$，满足条件 1；由极长性，$l > 0$ 时 $s[l-1] \ne c$，满足条件 2；$r < n$ 时 $s[r] \ne c$，满足条件 3。∎

**定理**：存在合法子串，当且仅当 `s` 中存在长度恰为 `k` 的极长连续段。

**证明**：引理 1 给出「合法 $\Rightarrow$ 存在长为 $k$ 的段」，引理 2 给出「存在长为 $k$ 的段 $\Rightarrow$ 合法」，二者互为充要。算法将 `s` 划分为互不重叠、覆盖全部字符的极长段序列，逐一比较段长与 $k$，恰好完成该存在性判定。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。`i`、`j` 均单调前进不回退，每个字符至多被访问两次（一次被 `j` 扩展、一次作为段起点被跳过），总步数不超过 $2n$。
- **空间复杂度**：$O(1)$。仅使用两个指针变量，无需存储分组结果。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool hasSpecialSubstring(string s, int k) {
        int n = s.size();
        int i = 0;
        while (i < n) {
            int j = i;
            while (j < n && s[j] == s[i]) {
                j++;
            }
            if (j - i == k) {
                return true;    // 找到长度恰为 k 的极长段
            }
            i = j;              // 整段跳过，进入下一段
        }
        return false;
    }
};
```

### Python

```python
class Solution:
    def hasSpecialSubstring(self, s: str, k: int) -> bool:
        n = len(s)
        i = 0
        while i < n:
            j = i
            while j < n and s[j] == s[i]:
                j += 1
            if j - i == k:
                return True     # 找到长度恰为 k 的极长段
            i = j               # 整段跳过，进入下一段
        return False
```

## 8. 边界情况与易错点

1. **段长必须严格等于 k**：`s = "aaaa", k = 2` 为 `false`，是本题最大的坑；判等写 `>=` 直接错；
2. **k = n**：仅当整个字符串是同一字符时为 `true`（如 `"aaa", k = 3`），否则段长不足返回 `false`；
3. **单字符**：`s = "a", k = 1`，唯一段长 1 恰等于 `k`，返回 `true`；
4. **嵌在段内的 k = 1**：`s = "aaa", k = 1` 返回 `false`——中间的 `'a'` 两侧都是同字符，首尾字符也各有一侧撞同字符，无合法位置；
5. **跳段写法**：内层循环结束后 `i = j` 整段跳过；写 `i++` 结果不变但变慢；
6. **短路求值**：C++ 内层 `j < n && s[j] == s[i]` 边界判断必须在前，否则越界访问。
