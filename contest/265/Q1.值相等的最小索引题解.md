# LeetCode 值相等的最小索引 题解

## 1. 题目概述

- **标题 / 题号**：值相等的最小索引（#2057，easy）
- **链接**：https://leetcode.cn/problems/smallest-index-with-equal-value/
- **来源**：LeetCode 第 265 场周赛 Q1
- **难度**：简单
- **标签**：数组、枚举

**题意**：给定下标从 0 开始的整数数组 `nums`，返回满足 $i \bmod 10 = nums[i]$ 的最小下标 $i$；若不存在这样的下标，返回 $-1$。

**约束**：

- `1 <= nums.length <= 100`
- `0 <= nums[i] <= 9`

> 💡 关键点一：$i \bmod 10$ 只与下标的**个位数**有关；关键点二：$nums[i]$ 的值域恰好是 $[0, 9]$，与 $i \bmod 10$ 同域，可直接比较。

## 2. 示例

**示例 1**

```text
输入：nums = [0,1,2]
输出：0
解释：i=0 时 0 mod 10 = 0 == nums[0]，所有下标都满足，返回最小下标 0。
```

**示例 2**

```text
输入：nums = [4,3,2,1]
输出：2
解释：i=2 时 2 mod 10 = 2 == nums[2]，其余下标均不满足。
```

**示例 3**

```text
输入：nums = [1,2,3,4,5,6,7,8,9,0]
输出：-1
解释：任何下标都不满足 i mod 10 == nums[i]。
```

**示例 4**

```text
输入：nums = [2,1,3,5,2]
输出：1
解释：i=1 时 1 mod 10 = 1 == nums[1]，是唯一满足的下标。
```

## 3. 解题思路

### 3.1 暴力思路

从左到右逐个下标检查 $i \bmod 10 = nums[i]$，返回第一个满足的下标；扫描完整个数组仍无命中则返回 $-1$。由于 $n \le 100$，一次线性扫描本身就是最优做法——签到题的"暴力"即正解，比拼的是**读题后 30 秒内写出无 bug 代码**。

### 3.2 核心观察：$i \bmod 10$ 就是下标的个位数

![核心观察：i mod 10 即下标的个位数](images/smallest_index_concept.svg)

- $i \bmod 10$ 就是 $i$ 十进制表示下的**个位数字**：$12 \bmod 10 = 2$，$97 \bmod 10 = 7$。
- 条件 $i \bmod 10 = nums[i]$ 等价于「**下标的个位数等于该位置的元素值**」。
- 约束 $0 \le nums[i] \le 9$ 保证两侧都是一位数字，直接用 `==` 比较即可。
- 当 $i < 10$ 时 $i \bmod 10 = i$，条件退化为 $nums[i] = i$；$i \ge 10$ 后个位开始循环，但比较逻辑完全不变。

### 3.3 算法流程：从左到右线性扫描

![算法流程：从左到右扫描，命中即返回](images/smallest_index_flow.svg)

1. 从 $i = 0$ 开始向右扫描；
2. 若 $i \bmod 10 = nums[i]$，**立即返回** $i$（扫描顺序递增，首次命中即最小下标）；
3. 否则 $i{+}{+}$ 继续扫描；
4. 循环自然结束仍无命中，返回 $-1$。

### 3.4 示例演算

![示例演算：命中与全程未命中两种情况](images/smallest_index_walkthrough.svg)

以 `nums = [4,3,2,1]` 为例：

| $i$ | $i \bmod 10$ | $nums[i]$ | 命中？ |
|-----|--------------|-----------|--------|
| 0 | 0 | 4 | ✗ |
| 1 | 1 | 3 | ✗ |
| 2 | 2 | 2 | ✓ → 返回 2 |
| 3 | 3 | 1 | （不再扫描） |

再以 `nums = [1,2,3,4,5,6,7,8,9,0]` 为例：$i$ 从 0 到 9，$nums[i]$ 恰好比 $i \bmod 10$ 大 1（$i=9$ 时 $nums[9]=0$），全程未命中，返回 $-1$。

## 4. 算法细节

1. **取模运算**：下标 $i$ 非负，`i % 10` 在 C++/Python 中结果即个位数，无符号问题。
2. **首次命中即返回**：扫描顺序严格递增，第一个满足的下标天然最小，找到后立即 `return`，无需维护 `min` 变量。
3. **默认返回 −1**：循环结束后返回 $-1$，覆盖"不存在"的情况。
4. **值域对齐**：$i \bmod 10 \in [0,9]$ 且 $nums[i] \in [0,9]$，同为一位数字，无溢出或类型陷阱。

## 5. 正确性证明

**引理 1**：对任意非负整数 $i$，$i \bmod 10$ 等于 $i$ 的十进制个位数字。

**证明**：设 $i = 10q + r$，其中 $0 \le r \le 9$。由带余除法，$r = i \bmod 10$；又 $i$ 的十进制表示为 $\ldots q r$，其个位即 $r$。故 $i \bmod 10$ 即个位数字。∎

**引理 2**：从左到右扫描时，算法返回的下标是满足条件的下标中最小的。

**证明**：扫描顺序为 $i = 0, 1, \ldots, n-1$ 严格递增，且命中即返回。设首个命中的下标为 $i^\*$，则对所有 $i < i^\*$ 条件均不成立，算法恰在 $i = i^\*$ 时返回，而任何满足条件的下标都 $\ge i^\*$。∎

**定理**：算法返回满足 $i \bmod 10 = nums[i]$ 的最小下标；不存在时返回 $-1$，与题意一致。

**证明**：若存在满足条件的下标，由引理 2 算法返回其中最小者；若不存在，循环执行满 $n$ 次后自然结束，返回 $-1$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。最坏情况扫描整个数组（$n \le 100$），每次判断 $O(1)$。
- **空间复杂度**：$O(1)$。仅使用下标变量，无额外数据结构。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int smallestEqual(vector<int>& nums) {
        for (int i = 0; i < (int)nums.size(); ++i) {
            if (i % 10 == nums[i]) {
                return i;
            }
        }
        return -1;
    }
};
```

### Python

```python
class Solution:
    def smallestEqual(self, nums: List[int]) -> int:
        for i, v in enumerate(nums):
            if i % 10 == v:
                return i
        return -1
```

## 8. 边界情况与易错点

1. **单元素数组**：`nums = [0]` 时 $0 \bmod 10 = 0 == nums[0]$，返回 0；`nums = [5]` 返回 $-1$。
2. **全程无命中**：如示例 3，循环结束必须返回 $-1$，不要漏写默认返回。
3. **$i \ge 10$ 的下标**：条件是 $i \bmod 10$ 而非 $i$ 本身，例如 $i = 12$ 只比较 `nums[12]` 是否等于 2，勿误写成 `i == nums[i]`。
4. **不要排序或重排数组**：条件绑定"下标 ↔ 该位置的值"，打乱数组会改变答案。
5. **无需特判 $i = 0$**：$0 \bmod 10 = 0$，与常规取模一致。
