# LeetCode 二叉树的边界 题解

## 1. 题目概述

- **标题 / 题号**：二叉树的边界（#545，medium）
- **链接**：https://leetcode.cn/problems/boundary-of-binary-tree/
- **来源**：LeetCode 第 25 场周赛 Q3
- **难度**：中等
- **标签**：树、深度优先搜索、二叉树

**题意**：从根出发，**逆时针**输出整棵二叉树的边界，顺序为「根 → 左边界（自根向下） → 所有叶子（自左向右） → 右边界（自下而上）」；每个**节点**只出现一次，但**节点的值可以重复**。

其中「左边界」指根到**最左节点**的路径，「右边界」指根到**最右节点**的路径；若根没有左子树，则根自身就是左边界（右边界同理）。「最左节点」的定义是：从根开始，**有左子树就先走左子树，没有才走右子树**，重复直到叶子。注意这套定义**只对整棵输入树成立**，不能递归套用到子树。

**约束**：

- 节点数 $1 \le n \le 10^4$
- 节点值 $-1000 \le val \le 1000$
- 镜像题面未附约束段，上述范围与该题通行限制一致；$O(n)$ 的解法对更大规模同样适用

## 2. 示例

**示例 1**

```text
输入：root = [1,null,2,3,4]
输出：[1,3,4,2]
解释：根 1 没有左子树，所以根自己就是左边界（左边界段为空）；
      叶子是 3 和 4；右边界路径是 1→2→4，逆时针要自下而上，倒序后去掉叶子 4 只剩下 2；
      拼接得到 [1,3,4,2]。
```

**示例 2**

```text
输入：root = [1,2,3,4,5,6,null,null,null,7,8,9,10]
输出：[1,2,4,7,8,9,10,6,3]
解释：左边界 1,2,4（4 按定义是最左节点，却按「叶子」身份只出现一次）；
      叶子 4,7,8,9,10；右边界 1,3,6,10；
      逆时针拼接并去重得到 [1,2,4,7,8,9,10,6,3]。
```

**补充（边界情形，非官方示例）**

```text
输入：root = [1]        输出：[1]          单节点既是根也是叶子
输入：root = [1,2]      输出：[1,2]        根无右子树，右边界为空
输入：root = [1,2,3]    输出：[1,2,3]      2、3 都是叶子，左/右边界被跳过
```

## 3. 解题思路

### 3.1 暴力思路

最直白的做法是**逐节点判定**：对每个节点 $v$，判断它是否在「根到最左叶子的路径」上、是否为叶子、是否在「根到最右叶子的路径」上。每条路径的判定要一次 DFS，最坏 $O(h)$，总计 $O(nh)$，在 $10^4$ 个节点的链上退化成 $O(n^2)$。

另一种常见错解是**按层取两端**：直觉上边界节点「在每层的最左或最右」，但层序的两端并不等于边界——一个节点在不在右边界上，取决于从根下来的每一步是否都被迫向右，而不取决于它在同层中的位置。例如某个节点是所在层的最右节点，但它的父节点本身不在右侧路径上，它就不属于右边界。

还有一类错解是把定义**递归套到子树上**：对每个子树都求一遍它的左边界。题面特意声明定义只对整棵树成立，子树递归会产出多余的节点。

### 3.2 核心观察：四段分解

![边界 = 根 + 左边界 + 叶子 + 右边界（逆序）](images/wc25_q3_boundary_decomposition.svg)

边界天然可以拆成**四段首尾相接**的序列：

$$\text{ans} = [\text{root}] \;\|\; L \;\|\; \text{leaves}(T) \;\|\; \text{reverse}(R)$$

- $L$：从 `root.left` 出发，沿「有左先左、否则走右」一路到叶子的路径上，**除终点叶子以外**的所有节点；
- $\text{leaves}(T)$：全树叶子，按**自左向右**排列；
- $R$：从 `root.right` 出发，沿「有右先右、否则走左」一路到叶子的路径上，**除终点叶子以外**的所有节点。

关键在于：左边界与右边界各自就是**一条贪心路径**，而这条路径恰好等于「根到最左（最右）叶子」的节点序列——因为题面对最左叶子的定义（有左先左、无左走右）与贪心推进规则逐字一致。于是不需要任何「路径搜索 + 判重」，只要三条简单遍历。

四段**互不相交**是「不重复」的根源：左边界节点全在左子树、右边界节点全在右子树，两段都主动排除了叶子，而叶子单独成段，根只在开头出现一次。所以**无需 `visited` 或哈希去重**。

### 3.3 算法流程

![算法流程：四段拼接](images/wc25_q3_algorithm_flow.svg)

1. 空树返回 `[]`；把 `root.val` 放进答案。
2. 若 `root` 本身是叶子，直接返回 `[root.val]`（否则后面两段会把根重复计算）。
3. **左边界**：`cur = root.left`，循环中若 `cur` 不是叶子就收集；然后 `cur = cur.left ? cur.left : cur.right`。
4. **叶子**：用栈做「先右后左」的入栈顺序（等价于先左后右的 DFS），遇到叶子就收集。
5. **右边界**：`cur = root.right`，规则对称（有右先右），把非叶子节点压栈；最后把栈中元素**逆序**追加到答案。
6. 返回答案。

右边界为什么必须逆序：逆时针走完叶子后要**自下而上**回到根，而遍历只能自上而下，所以先按「上→下」收集，再整体反转。

### 3.4 示例演算

![示例 2 的逐段走查](images/wc25_q3_example_walkthrough.svg)

对示例 2 的树：

| 段 | 过程 | 结果 |
|----|------|------|
| 根 | 先放入根 | `1` |
| 左边界 | `1 → 2`，到 `4` 时发现是叶子，跳过并停止 | `2` |
| 叶子 | 先左后右 DFS：`4, 7, 8, 9, 10` | `4 7 8 9 10` |
| 右边界 | 自上而下 `3, 6`（`10` 是叶子被跳过），逆序 | `6 3` |
| 拼接 | `1 ｜ 2 ｜ 4 7 8 9 10 ｜ 6 3` | `[1,2,4,7,8,9,10,6,3]` |

对示例 1 的树 `[1,null,2,3,4]`：根 `1` 无左子树，左边界段为空；叶子为 `3, 4`；右侧路径 `1→2→4` 中只有 `2` 非叶子，逆序后追加 `2`，得到 `[1,3,4,2]`。两棵树的结果都与官方输出一致。

## 4. 算法细节

1. **根的特判位置**：先把根放进答案，再判「根是叶子」。若把叶子判断放在最前面，单节点树会返回空数组；若放在根之后又忘了 `return`，单节点树会先加根、再被叶子段加一次。
2. **左右边界都从孩子出发**：`cur` 初始化为 `root.left` / `root.right`，而不是 `root`。这是「根只出现一次」的实现保证，也让「无左子树 ⇒ 左边界就是根」自动成立（循环零次）。
3. **推进规则写成三元表达式**：`cur = cur->left ? cur->left : cur->right`。不能写成「两个方向都递归」，那会把整棵树都当边界；也不能只走左孩子，否则在左子树缺失时会提前中断，漏掉后续节点。
4. **边界段的节点是否入选用 `isLeaf` 判定**：只有叶子被排除，内部节点一律收集。不要用「值是否已出现」之类的条件代替，节点值可以重复。
5. **右边界用栈或 `vector` 反序**：先自上而下压栈，再逆序追加；也可以先构造 `vector` 后 `reverse`。试图写「自底向上递归」虽然可行，但控制返回顺序的代码更容易写错。
6. **叶子收集用显式栈**：入栈顺序先右后左，弹出时就是先左后右，叶子自然按从左到右输出。同时避免了递归深度问题——$10^4$ 的纯链在 Python 默认递归上限（1000 层）下会直接 `RecursionError`，C++ 也接近栈上限。
7. **不需要 `visited`**：四段在集合上互不相交（见 §5 引理 2），加去重表只会掩盖逻辑错误，并让复杂度多一项常数开销。

## 5. 正确性证明

**引理 1（左边界游走等价于根到最左叶的路径）**：设 $P_L$ 为「从根出发、有左先左、无左走右、直到叶子」的节点序列，则流程第 3 步收集到的恰是 $P_L$ 去掉最后一个节点。

**证明**：流程第 3 步中 `cur` 的初始值是 `root.left`，每次按「有左先左、否则走右」推进，与该题面「最左节点」的定义完全相同，故 `cur` 依次走过的节点序列就是 $P_L$ 去掉首元素 `root` 后的部分。又因为 $P_L$ 中除终点外每个节点都有孩子、都不是叶子，所以「非叶子才收集」等价于「收集 $P_L$ 去掉终点」。∎

**引理 2（三段互不相交）**：左边界段、叶子段、右边界段两两没有公共节点。

**证明**：左边界段的节点都在 `root.left` 的子树内，右边界段的节点都在 `root.right` 的子树内，两棵子树节点集合不交，故前两段不交。左、右边界段中的节点按引理 1 都是内部节点（非叶子），而叶子段只含叶子，故它们与叶子段不交。∎

**引理 3（叶子顺序）**：先右后左入栈的 DFS 弹出的叶子序列，恰好是自左向右的叶子顺序。

**证明**：对任意两个叶子 $u, v$ 且 $u$ 在 $v$ 左侧，二者的最近公共祖先 $w$ 满足 $u$ 在 $w$ 的左子树、$v$ 在 $w$ 的右子树。DFS 在 $w$ 处先压右子树、后压左子树，故左子树整体先于右子树被弹出并展开，$u$ 先于 $v$ 输出。由 $u,v$ 任意，序列自左向右。∎

**定理**：算法返回的序列恰为题目定义的逆时针边界。

**证明**：顺序性由构造直接得到：根在最前，接着是自上而下的左边界，再是自左向右的叶子（引理 3），最后是右边界自上而下结果的逆序，即自下而上，与逆时针绕行方向一致。完整性：任一边界节点按其身份属于四段之一——根、左边界内部节点、叶子、右边界内部节点；由引理 1 左/右边界内部节点都被收集到。不重复性：根只加一次，其余三段由引理 2 互不相交。∎

## 6. 复杂度分析

- **时间**：$O(n)$。叶子段的栈遍历对每个节点恰好访问一次；左、右边界游走各 $O(h)$ 且 $h \le n$；拼接与逆序都是线性的，总计 $O(n)$。
- **空间**：$O(n)$ 最坏、$O(h)$ 典型。显式栈在「满二叉树最后一层」这种最宽情形下会同时存放 $O(n)$ 个节点；左/右边界各用一个长度 $O(h)$ 的容器（右边界可直接复用答案数组尾部，额外空间为 $O(h)$）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> boundaryOfBinaryTree(TreeNode* root) {
        vector<int> ans;
        if (!root) return ans;

        auto isLeaf = [](TreeNode* n) { return n && !n->left && !n->right; };
        ans.push_back(root->val);
        if (isLeaf(root)) return ans;

        // 1) 左边界：自上而下，跳过叶子
        TreeNode* cur = root->left;
        while (cur) {
            if (!isLeaf(cur)) ans.push_back(cur->val);
            cur = cur->left ? cur->left : cur->right;
        }

        // 2) 叶子：先右后左入栈 => 先左后右出栈
        vector<TreeNode*> stk{root};
        while (!stk.empty()) {
            TreeNode* n = stk.back();
            stk.pop_back();
            if (isLeaf(n)) {
                ans.push_back(n->val);
                continue;
            }
            if (n->right) stk.push_back(n->right);
            if (n->left) stk.push_back(n->left);
        }

        // 3) 右边界：自上而下收集非叶子，再逆序追加
        vector<int> right;
        cur = root->right;
        while (cur) {
            if (!isLeaf(cur)) right.push_back(cur->val);
            cur = cur->right ? cur->right : cur->left;
        }
        for (int i = (int)right.size() - 1; i >= 0; --i) ans.push_back(right[i]);

        return ans;
    }
};
```

### Python

```python
from typing import List


class Solution:
    def boundaryOfBinaryTree(self, root: TreeNode) -> List[int]:
        if root is None:
            return []

        def is_leaf(node: TreeNode) -> bool:
            return node.left is None and node.right is None

        ans = [root.val]
        if is_leaf(root):
            return ans

        # 1) 左边界：自上而下，跳过叶子
        cur = root.left
        while cur is not None:
            if not is_leaf(cur):
                ans.append(cur.val)
            cur = cur.left if cur.left is not None else cur.right

        # 2) 叶子：先右后左入栈 => 先左后右出栈
        stk = [root]
        while stk:
            node = stk.pop()
            if is_leaf(node):
                ans.append(node.val)
                continue
            if node.right is not None:
                stk.append(node.right)
            if node.left is not None:
                stk.append(node.left)

        # 3) 右边界：自上而下收集非叶子，再逆序追加
        right = []
        cur = root.right
        while cur is not None:
            if not is_leaf(cur):
                right.append(cur.val)
            cur = cur.right if cur.right is not None else cur.left
        ans.extend(reversed(right))

        return ans
```

## 8. 边界情况与易错点

1. **空树**：虽然约束保证 $n \ge 1$，接口仍需返回 `[]`，否则访问 `root.val` 直接崩溃。
2. **单节点**：必须返回 `[root.val]` 而不是两次——先加根再判叶子并 `return`，顺序不能反。
3. **根缺一侧子树**：根无左子树时左边界段为空（根自己就是左边界）；根无右子树时右边界段为空，**不能**把根再补一次到末尾，否则答案出现两个根值。
4. **纯链**：全左链只有「根 + 中间节点 + 叶子」，右边界段为空；全右链对称。两侧都去补会重复。
5. **叶子同时位于边界上**：最左/最右节点必然是叶子，它们只允许出现在叶子段；边界段若忘记跳过叶子就会重复。
6. **节点值重复**：去重必须按节点身份，绝不能用 `set` 或值比较；本题的值域只有 $[-1000,1000]$，用值去重极易出错。
7. **深链爆栈**：$10^4$ 的链在 Python 递归 DFS 下会 `RecursionError`，C++ 递归也有风险；统一改成显式栈更稳。
