# LeetCode 最短独占单词缩写 题解

## 1. 题目概述

- **标题 / 题号**：最短独占单词缩写（#411，hard）
- **链接**：https://leetcode.cn/problems/minimum-unique-word-abbreviation/
- **来源**：LeetCode 第 7 场周赛 Q4
- **难度**：困难
- **标签**：位运算、数组、字符串、回溯

**题意**：给定目标串 `target`（长度 $m$）和词典 `dictionary`。缩写规则是：把串中任意若干段**连续**字符替换成该段长度对应的十进制数字。例如 `"word"` 的缩写有 `"word"`、`"1ord"`、`"w1rd"`、`"3d"`、`"w3"`、`"4"` 等；缩写中每个字母、每段数字都算 $1$ 个字符长度（如 `"a32bc"` 长度为 $4$）。要求返回 `target` 的一个缩写，使它**不是**词典中任何单词的缩写（即不与任何词典缩写冲突），且长度最小；多解时题目允许返回任意一个。本文固定取「长度最小、同长度字典序最小」的一个，输出确定且与官方示例一致。

**约束**：

- $1 \le m = \lvert target \rvert \le 21$，$1 \le n = \lvert dictionary \rvert \le 1000$
- $\log_2 n + m \le 20$
- 数据保证存在解，即词典不含 `target` 本身（否则 `target` 的任何缩写都是它自己的缩写，必然冲突）

## 2. 示例

**示例 1**

```text
输入：target = "apple", dictionary = ["blade"]
输出："a4"
解释："5" 是任何 5 字母单词的缩写；"4e" 也恰好是 "blade" 的缩写（跳过 4 位后正好是 e）；
      两者都冲突。"a4" 保留首字母 a，而 "blade"[0] = 'b' ≠ 'a'，不冲突，长度 2。
```

**示例 2**

```text
输入：target = "apple", dictionary = ["blade", "plain", "amber"]
输出："1p3"
解释："5" 与三者都冲突，"a4" 被 amber 拦下（两者首位都是 a），"4e" 被 blade 拦下；
      长度 3 的可行解有 "1p3"、"2p2"、"3l1"、"ap3"、"a3e" 等，题目允许任意一个，这里取字典序最小的 "1p3"。
```

## 3. 解题思路

### 3.1 暴力思路

每个位置只有两种命运：**保留字符**，或**被数字吞掉**（相邻被吞掉的位置合并成一段数字），所以 `target` 的缩写恰好有 $2^m$ 个，可以枚举。最直接的写法是给每个缩写生成字符串，再对每个词典单词逐字符模拟，单次检查 $O(m)$，总复杂度 $O(2^m \cdot n \cdot m)$；$m = 20$、$n = 1000$ 时约 $2 \times 10^{10}$，必然超时。

注意到约束 $\log_2 n + m \le 20$ 等价于 $n \le 2^{20-m}$，于是 $2^m \cdot n \le 2^{20} \approx 1.05 \times 10^6$。也就是说，**只要把「一个缩写是否与一个单词冲突」压到 $O(1)$**，枚举全部 $2^m$ 个缩写的总工作量就落在 $10^6$ 量级。这条看似奇怪的约束，正是官方在暗示「枚举所有掩码 + 常数时间冲突判定」。

### 3.2 核心观察：位掩码 + 子集判定

![位掩码建模：一个 5 位掩码确定一个缩写](images/wc7_q4_mask_model.svg)

用 $m$ 位掩码 $S$ 表示一个缩写：第 $i$ 位为 $1$ 表示保留 `target[i]`，为 $0$ 表示它被数字吞掉。$S$ 与缩写串一一对应，例如 `"apple"` 取 $S = \{0,3\}$（位串 `10010`）得到缩写 `"a2l1"`。

**冲突条件是全局最关键的观察**。设有等长词典单词 $w$。缩写 $A(S)$ 同时也能描述 $w$，当且仅当：在 $S$ 指定的每一个保留位上，$w$ 与 `target` 的字符都相同。原因是数字段只规定「跳过多少个字符」，不约束被跳过字符的内容；只有保留下来的字母必须逐位相等。

把「$w$ 与 `target` 字符相同的位置」也压成掩码 $M_k(w) = \{\, i \mid w[i] = target[i] \,\}$，那么 $A(S)$ 同时是 $w$ 的缩写 $\iff S \subseteq M_k(w)$。于是「$A(S)$ 不与词典冲突」等价于：对每个等长单词都有 $S \not\subseteq M_k(w)$，即一次位运算 $S \,\&\, \sim M_k(w) \ne 0$ 就能判掉一个单词，比逐字符模拟便宜一个 $O(m)$。

还有两条免费的剪枝：**不等长的单词直接丢弃**（数字段长度之和等于单词长度）；**删除冗余掩码**——若 $M_1 \subseteq M_2$，则满足 $S \subseteq M_1$ 的 $S$ 也满足 $S \subseteq M_2$，$M_1$ 的禁集被 $M_2$ 覆盖，可以删掉（保留超集、删除子集）。

缩写长度还有 $O(1)$ 公式：若 $S$ 中有 $p$ 个 $1$、$Z = \text{full} \oplus S$ 中有 $r$ 段连续的 $0$，则 $\operatorname{len}(S) = p + r$——每个保留字母贡献 $1$，每段连续数字贡献 $1$。

### 3.3 算法流程

![算法流程：位掩码枚举 + 子集冲突判定](images/wc7_q4_search_flow.svg)

1. 过滤出长度等于 $m$ 的词典单词，逐个计算 $M_k(w)$，去重。
2. 删除冗余掩码：若 $a \subseteq b$，则删去 $a$（$a$ 的禁集被 $b$ 覆盖）。
3. 若掩码集合为空，说明没有任何等长单词，全数字缩写 `str(m)` 长度 $1$ 已是最优，直接返回。
4. 枚举 $S = 0,1,\dots,2^m-1$：先算 $\operatorname{len}(S)$，超过当前最优长度就跳过；再对所有掩码做子集测试，命中即冲突跳过；否则按「长度优先、字典序次之」更新答案。
5. 枚举结束返回最优缩写。

### 3.4 示例演算

![示例演算："apple" 与 blade / plain / amber 的掩码表](images/wc7_q4_walkthrough.svg)

对 `target = "apple"`、词典 `["blade","plain","amber"]`：`plain` 与 `apple` 没有任何一位相同，$M_k = \varnothing$；`amber` 只有第 $0$ 位 `a` 相同，$M_k = \{0\}$；`blade` 只有第 $4$ 位 `e` 相同，$M_k = \{4\}$。

$\varnothing \subseteq \{0\}$，删去 $\varnothing$，保留 $\{0\}$ 与 $\{4\}$。于是 $S = \varnothing$ 被 $\{0\}$ 拦下，$S = \{0\}$ 被 $\{0\}$ 拦下，$S = \{4\}$ 被 $\{4\}$ 拦下。剩下的长度 3 候选有 `"1p3"`、`"2p2"`、`"3l1"`、`"ap3"`、`"a3e"`，其中 `"1p3"` 字典序最小，与官方输出一致。

## 4. 算法细节

1. **掩码语义**：`1 = 保留字母`、`0 = 被数字吞掉`，连续的 $0$ 合并成一段数字。构造缩写时按「遇到 $1$ 输出 `target[i]`；遇到 $0$ 数清整段长度输出数字」扫描一遍即可，$O(m)$。
2. **长度 $O(1)$ 计算**：令 $Z = \text{full} \oplus S$，$0$ 段起点集合为 $Z \,\&\, \bigl(\text{full} \oplus ((Z \ll 1) \,\&\, \text{full})\bigr)$，其中 $\text{full} = 2^m-1$ 用来把高位截掉。popcount 后加上 $\operatorname{popcount}(S)$ 即为长度。C++ 用 `__builtin_popcount`，Python 用 `bin(x).count("1")`。
3. **子集测试**：`S & ~Mk == 0` 表示 $S \subseteq M_k$，即冲突。C++ 里 `~Mk` 的高位是 $1$，但 $S$ 的高位是 $0$，按位与后仍为 $0$，结果正确；Python 的 `~` 是负无穷补码，$S$ 非负时结论同样正确。
4. **冗余删除的方向别写反**：删的是**子集**掩码 $a$（当存在超集 $b \supseteq a$ 时），因为 $a$ 的禁集 $\{S \mid S \subseteq a\}$ 被 $b$ 的禁集包含。写成「删超集」会漏判冲突。
5. **剪枝必须是严格大于**：只有 $\operatorname{len}(S) > \text{bestLen}$ 才能跳过；长度相等时仍要生成字符串比较字典序。`bestLen` 初值取 $m+1$。
6. **字符串只在可能更新答案时构造**：判定阶段全部用整数位运算，避免每次枚举都拼 $O(m)$ 的字符串，把常数压到最小。
7. **字典序就是 ASCII 序**：数字字符 `'1' < '2' < ... < '9' < 'a'`，直接比较完整缩写串即可；不要按数字段的**数值**比较（`"10"` 与 `"9"` 的数值序与字符序相反）。

## 5. 正确性证明

**引理 1（冲突判定）**：设 $w$ 是长度等于 $m$ 的词典单词，$S$ 是任一掩码。则缩写 $A(S)$ 同时是 $w$ 的缩写，当且仅当 $S \subseteq M_k(w)$。

**证明**：若 $A(S)$ 是 $w$ 的缩写，则 $A(S)$ 的每个字母位置 $i$ 必须满足 $w[i] = A(S)$ 在该位置的字符 $= target[i]$，故 $i \in M_k(w)$，即 $S \subseteq M_k(w)$。反之若 $S \subseteq M_k(w)$，把 $A(S)$ 的数字段照搬到 $w$ 上：数字段要求跳过的字符数相同，$w$ 与 `target` 等长故跳过量合法；保留位按假设字符相同。因此 $A(S)$ 确实是 $w$ 的缩写。∎

**引理 2（冗余删除）**：若 $M_1 \subseteq M_2$，则删去 $M_1$ 不改变「冲突掩码」的集合。

**证明**：$S \subseteq M_1 \Rightarrow S \subseteq M_2$，故 $\{S \mid S \subseteq M_1\} \subseteq \{S \mid S \subseteq M_2\}$。冲突集合是各掩码禁集的并集，删去被包含的 $M_1$ 后并集不变。∎

**引理 3（长度公式）**：$\operatorname{len}(S) = \operatorname{popcount}(S) + r$，其中 $r$ 是 $Z = \text{full} \oplus S$ 中连续 $0$ 段的数量。

**证明**：缩写串中每个保留位恰好输出一个字母；每段极大连续 $0$ 恰好输出一个数字。字母与数字段互不重叠、覆盖全部 $m$ 个位置，故字符总数即二者之和。∎

**定理**：算法返回的字符串是 `target` 的合法缩写、不与词典冲突、长度最小，且在同长度者中字典序最小。

**证明**：枚举 $S$ 覆盖了 `target` 的全部 $2^m$ 个缩写，无遗漏。由引理 1、2，子集测试恰好判定冲突，不会误杀也不会漏杀。由引理 3，长度计算精确。更新规则只在「长度更小」或「长度相同且字符串更小」时替换 `best`，因此最终 `best` 是所有可行缩写按 $(\operatorname{len}, \text{字典序})$ 排序后的最小值。可行集非空：取 $S = \text{full}$（保留全部字母），此时 $A(S) = target$，而 $S \subseteq M_k(w)$ 需要 $M_k(w) = \text{full}$，即 $w = target$，与「词典不含 `target`」矛盾，故 $S = \text{full}$ 必然可行。∎

## 6. 复杂度分析

- **时间**：$O(nm)$ 预处理每个单词的掩码；枚举 $2^m$ 个掩码，每个做 $O(d)$ 次子集测试（$d$ 为剪枝后的掩码数，$d \le n$），$2^m \cdot d \le 2^m \cdot n \le 2^{20}$；只有可能更新答案的掩码才花 $O(m)$ 构造字符串，最坏 $O(2^m \cdot m) \le 2\times 10^7$。整体约 $10^7$ 次基本操作，$m = 20$、$n = 1$ 时 Python 实测约 $0.6$ 秒。
- **空间**：$O(d)$ 存掩码（$d \le n$），$O(m)$ 存当前最优缩写，无递归栈。不需要存储所有缩写字符串，否则内存会到 $O(2^m \cdot m)$。

## 7. 参考代码

### C++

```cpp
#include <string>
#include <vector>
#include <set>
using namespace std;

class Solution {
public:
    string minAbbreviation(string target, vector<string>& dictionary) {
        int m = target.size(), full = (1 << m) - 1;
        set<int> ms;                        // 等长单词的「相同位」掩码
        for (const string& w : dictionary) {
            if ((int)w.size() != m) continue;
            int mk = 0;
            for (int i = 0; i < m; i++)
                if (w[i] == target[i]) mk |= 1 << i;
            ms.insert(mk);
        }
        if (ms.empty()) return to_string(m); // 全数字缩写，长度 1 已最优

        vector<int> masks(ms.begin(), ms.end()), keep;
        for (int a : masks) {                // 删去被其他掩码包含的子集
            bool redundant = false;
            for (int b : masks)
                if (b != a && (a & b) == a) { redundant = true; break; }
            if (!redundant) keep.push_back(a);
        }

        auto build = [&](int S) {            // 掩码 → 缩写串
            string out;
            for (int i = 0; i < m; ) {
                if ((S >> i) & 1) { out += target[i]; i++; }
                else {
                    int j = i;
                    while (j < m && !((S >> j) & 1)) j++;
                    out += to_string(j - i);
                    i = j;
                }
            }
            return out;
        };

        int bestLen = m + 1;
        string best;
        for (int S = 0; S <= full; S++) {
            int Z = full ^ S;                // 0 段起点数 = 数字段数
            int runs = __builtin_popcount((unsigned)(Z & (full ^ ((Z << 1) & full))));
            int len = __builtin_popcount((unsigned)S) + runs;
            if (len > bestLen) continue;
            bool ok = true;
            for (int mk : keep)
                if ((S & ~mk) == 0) { ok = false; break; }  // S ⊆ mk 即冲突
            if (!ok) continue;
            if (len < bestLen) { bestLen = len; best = build(S); }
            else {
                string cand = build(S);
                if (best.empty() || cand < best) best = cand;
            }
        }
        return best;
    }
};
```

### Python

```python
from typing import List


class Solution:
    def minAbbreviation(self, target: str, dictionary: List[str]) -> str:
        m = len(target)
        full = (1 << m) - 1

        masks = set()                      # 等长单词的「相同位」掩码
        for w in dictionary:
            if len(w) != m:
                continue
            mk = 0
            for i in range(m):
                if w[i] == target[i]:
                    mk |= 1 << i
            masks.add(mk)
        if not masks:
            return str(m)                  # 全数字缩写，长度 1 已最优

        masks = list(masks)
        # 若 a ⊆ b，则 S ⊆ a 也满足 S ⊆ b：a 的禁集被 b 覆盖，删 a
        masks = [a for a in masks if not any(b != a and (a & b) == a for b in masks)]

        def build(S: int) -> str:          # 掩码 → 缩写串
            out, i = [], 0
            while i < m:
                if (S >> i) & 1:
                    out.append(target[i])
                    i += 1
                else:
                    j = i
                    while j < m and not ((S >> j) & 1):
                        j += 1
                    out.append(str(j - i))
                    i = j
            return "".join(out)

        best_len, best = m + 1, None
        for S in range(1 << m):
            Z = full ^ S                   # 数字段数 = 0 段起点数
            runs = bin(Z & (full ^ ((Z << 1) & full))).count("1")
            length = bin(S).count("1") + runs
            if length > best_len:
                continue
            if any(S & ~mk == 0 for mk in masks):     # S ⊆ mk 即冲突
                continue
            if length < best_len:
                best_len, best = length, build(S)
            else:
                cand = build(S)
                if cand < best:
                    best = cand
        return best if best is not None else ""
```

## 8. 边界情况与易错点

1. **没有等长单词**：如 `target = "word"`、`dictionary = []`，答案是 `"4"`（长度 $1$，已是下界）。代码在掩码集合为空时直接返回 `str(m)`。
2. **字典含 `target`**：此时任何缩写都同时是 `target` 自己的缩写，问题无解；题目数据保证不会出现。代码保留空串兜底，避免返回 `None`。
3. **冗余掩码删除方向**：必须删「被别的掩码包含」的那个（子集），因为它的禁集更小、被超集覆盖。方向写反会把真实约束删掉，答案偏短且冲突（如示例 2 会错答 `"4e"`）。
4. **剪枝用 `>` 而不是 `>=`**：长度相同还要比较字典序，写成 `>=` 会跳过同长度候选，可能返回 `"2p2"` 而不是 `"1p3"`。
5. **$m = 1$**：`full = 1`，缩写只有 `"1"`（长度 $1$）和 `"a"`（长度 $1$）两种，长度公式与枚举逻辑都无需特判；`str(m)` 仍是单字符。
6. **数字段本身占一个字符**：长度是「字母数 + 段数」，不是「字母数 + 被吞掉的字符数」，$m = 21$ 时数字段最多两位（`"21"`），直接 `to_string` 即可，不需要按位拆。
7. **`~` 的符号位**：C++ 中 `~Mk` 高位为 $1$，但 $S$ 只用到低 $m$ 位，`S & ~Mk == 0` 依然等价于 $S \subseteq M_k$；若给 $S$ 也补了高位（如在别的实现里做 `S | ~full`）就会误判。
8. **不要用 `set<string>` 存全部缩写**：$2^{20}$ 个长度约 $20$ 的串，内存与哈希开销都会爆；位掩码枚举天然无重复，也不需要去重字符串。
