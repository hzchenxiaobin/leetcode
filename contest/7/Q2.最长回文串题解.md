# LeetCode 最长回文串 题解

## 1. 题目概述

- **标题 / 题号**：最长回文串（#409，easy）
- **链接**：https://leetcode.cn/problems/longest-palindrome/
- **来源**：LeetCode 第 7 场周赛 Q2
- **难度**：简单
- **标签**：贪心、哈希表、字符串、计数

**题意**：给定一个只含英文字母的字符串 `s`，从中挑出若干字符（每个字符最多用掉它在 `s` 中的出现次数）**任意重排**，拼成一个回文串，求能拼出的**最长长度**。注意这是「重排」而不是「取子串」，字符顺序完全不重要，只有**每个字符用了几个**重要；大小写敏感，`'A'` 与 `'a'` 不能配成一对，因此 `"Aa"` 只能构造出长度 1。

**约束**：

- $1 \le \lvert s \rvert \le 2000$
- `s` 只由大写和/或小写英文字母组成
- `'A'` 与 `'a'` 是两个不同字符，频次分别统计

## 2. 示例

**示例 1**

```text
输入：s = "abccccdd"
输出：7
解释：可以构造的最长回文串是 "dccaccd"，长度为 7。
      a、b 各 1 个且都落单，只能挑一个坐中心；c 的 4 个与 d 的 2 个全用上。
```

**示例 2**

```text
输入：s = "a"
输出：1
解释：只有一个字符，它自己就是长度为 1 的回文串（此时「中心」就是全部）。
```

**补充示例**（官方未给，用于强调大小写敏感）

```text
输入：s = "Aa"
输出：1
解释：'A' 与 'a' 是两个不同字符，各 1 个，凑不出一对，只能取其中一个。
      若误用 tolower 把它们合并成 2 个 'a'，会错误输出 2。
```

## 3. 解题思路

### 3.1 暴力思路

最直白的做法是枚举「用哪些字符、各用几个」，再枚举这些字符的所有排列，判断是否为回文，取最长者。长度为 $n$ 的字符串，子多重集最多 $\prod_c (\text{cnt}[c]+1) \le 2^{n}$ 个，每个多重集还要枚举 $O(n!)$ 种排列，复杂度是阶乘级的。

即使只枚举「多重集」而不枚举排列（回文的判定等价于「至多一个字符频次为奇数」），也需要先发现这个判定条件——那已经是最优解的核心了。所以本题不存在「先写暴力再优化」的中间态，$n \le 2000$ 也否定了任何指数做法。正确的路径是**直接从回文的结构推出计数公式**。

### 3.2 核心观察：镜像对称 ⇒ 成对消耗，中心至多一个

![回文的镜像结构：成对摆放，中心至多一个](images/wc7_q2_mirror_pairs.svg)

回文串的定义是 $P[i] = P[L-1-i]$。于是每个位置 $i$ 都有一个「镜像搭档」$L-1-i$：

- 当 $i \ne L-1-i$ 时，两个位置必须是**同一个字符**，这个字符就**成对**消耗了 2 个；
- 唯一可能没有搭档的位置是 $i = L-1-i$，即 $L$ 为奇数时的**正中心**，它只消耗 1 个字符。

由此得到两条硬约束：

1. 回文串中**频次为奇数的字符至多一个**（就是中心那个，可以没有）；
2. 字符 $c$ 在 `s` 中出现 $\text{cnt}[c]$ 次时，它在回文串里最多用 $2\lfloor \text{cnt}[c]/2 \rfloor$ 个——多出来的那 1 个（如果有）不能单独塞进某一侧，只能去竞争唯一的中心。

于是答案几乎可以直接写出来：

$$\text{ans} = 2\sum_{c} \left\lfloor \frac{\text{cnt}[c]}{2} \right\rfloor + \bigl[\exists c:\ \text{cnt}[c] \text{ 为奇数}\bigr]$$

最后那个 Iverson 括号的意思是：**只要还有落单字符，就能再往正中心放 1 个**；否则（全部频次都是偶数）一个都不能加。

> 💡 **一句话记忆**：先把所有字符两两配对摆在左右两侧，剩下凑不成对的字符里挑一个放正中间，其余的只能扔掉。

### 3.3 算法流程

![算法流程：计数 → 累加偶数部分 → 有落单则 +1](images/wc7_q2_greedy_flow.svg)

1. **统计频次**：遍历 `s`，`cnt[c]++`。大小写分开，`'A'` 与 `'a'` 落在不同下标。
2. **累加偶数部分**：对每个出现过的字符，把 $2\lfloor \text{cnt}[c]/2 \rfloor$ 加入 `ans`。
3. **补中心**：若 `ans < n`，说明还有字符没被用上，而它只能是落单的那个，于是 `ans += 1`。
4. **返回** `ans`。

第 3 步的判定条件 `ans < n` 不是随手写的，它精确等价于「存在奇数频次字符」。因为每个字符被舍弃的个数恰好是

$$\text{cnt}[c] - 2\left\lfloor \frac{\text{cnt}[c]}{2}\right\rfloor = \text{cnt}[c] \bmod 2 \in \{0,1\}$$

把所有字符的舍弃数加起来就是 $n - \text{ans}$，它正好等于**频次为奇数的字符个数**。所以不用额外的布尔变量，一个比较就够了。

### 3.4 示例演算

![示例演算：s = "abccccdd" 的逐字符走查](images/wc7_q2_walkthrough.svg)

以 `s = "abccccdd"`（$n = 8$）为例：

- 频次：`a:1`、`b:1`、`c:4`、`d:2`；
- 偶数部分：$0 + 0 + 4 + 2 = 6$，其中 `c` 贡献 $2\times 2 = 4$，`d` 贡献 $2 \times 1 = 2$；
- `ans = 6 < 8`，说明还有落单字符（`a` 与 `b` 各剩 1 个），**只挑一个**放中心 → $6 + 1 = 7$；
- 构造：左半 `dcc`，中心 `a`，右半 `ccd` 是左半的镜像，拼成 `dccaccd`，长度 7，与官方解释一致。

再看 `s = "aabbc"`：频次 `a:2 b:2 c:1`，偶数部分 $2+2=4$，`4 < 5` 故 $+1$，答案 5（构造 `abcba`）。注意这里只有 1 个落单字符；即使换成 `"aabbcde"` 有 3 个落单字符，中心也只能放 1 个，答案仍是 $4+1=5$。

## 4. 算法细节

1. **计数容器用数组**：`int cnt[128]` 直接按 ASCII 下标计数，$O(1)$ 取用；虽然只有 52 种字母，但 128 的常数开销可以忽略。C++ 里务必写 `cnt[(unsigned char)ch]++`，否则在 `char` 有符号的平台上，非 ASCII 字节会变成负下标而越界。
2. **绝对不要 `tolower`**：题面明确区分大小写，合并大小写会把 `"Aa"` 从 1 变成 2，是本题最常见的错误。
3. **中心判定用 `ans < n`**：等价于「$\exists c$，$\text{cnt}[c]$ 为奇数」，由 §3.3 的恒等式保证。也可以显式维护 `hasOdd` 布尔量，两者等价，但前者少一个变量、少一处易错点。
4. **中心最多加 1**：落单字符可能有 1 个、3 个、甚至 2000 个，但正中心只有一个位置，所以只加 1；把落单字符全部塞进去是错的。
5. **全偶数时不能加**：若所有频次都是偶数，则 `ans == n`，此时再 `+1` 就会超过字符串长度（例如 `"aaaa"` 会错误输出 5）。
6. **位运算写法**：`ans += cnt[i] & ~1` 等价于 `cnt[i] / 2 * 2`，在 C++ 里稍快一点，但可读性不如直接整除，周赛里推荐后者。
7. **若追问「输出具体回文串」**：先按任意顺序把每个字符重复 $\lfloor \text{cnt}[c]/2\rfloor$ 次拼成 `left`，取一个落单字符作 `mid`（没有就空串），答案是 `left + mid + reverse(left)`，复杂度仍是 $O(n)$。
8. **数值范围**：答案不超过 $n \le 2000$，`int` 足够，不需要 `long long`，也不存在取模或溢出问题。

## 5. 正确性证明

**引理 1（上界）**：设回文串 $P$ 由 `s` 的字符构成、长度为 $L$，字符 $c$ 在 $P$ 中出现 $e_c$ 次，则 $e_c \le \text{cnt}[c]$，且至多一个 $c$ 使 $e_c$ 为奇数；从而

$$L \le 2\sum_c \left\lfloor \frac{\text{cnt}[c]}{2}\right\rfloor + \bigl[\exists c:\ \text{cnt}[c] \text{ 为奇数}\bigr]$$

**证明**：$e_c \le \text{cnt}[c]$ 显然，因为 $P$ 的字符只能从 `s` 里取。把 $P$ 的 $L$ 个位置按 $i \leftrightarrow L-1-i$ 配对：若 $i \ne L-1-i$，由回文性 $P[i] = P[L-1-i]$，这两个位置贡献同一字符的 2 次出现；唯一不与自身配对的只有 $i = L-1-i$（此时 $L$ 为奇数），它是一个单独的位置。因此除可能的中心外，每个字符的出现次数都是偶数，即至多一个字符的 $e_c$ 为奇数。

对每个 $c$：若 $e_c$ 为偶数，则 $e_c \le \text{cnt}[c]$ 且 $e_c$ 偶，故 $e_c \le 2\lfloor \text{cnt}[c]/2\rfloor$；若 $e_c$ 为奇数，则它是唯一这样的字符，且 $e_c \le \text{cnt}[c]$、$e_c$ 奇，故 $e_c \le 2\lfloor \text{cnt}[c]/2\rfloor + 1$。把所有 $e_c$ 相加即得上界。∎

**引理 2（可达）**：引理 1 的上界可以被真正构造出来。

**证明**：对每个字符 $c$ 取 $k_c = \lfloor \text{cnt}[c]/2\rfloor$ 对，任取一个顺序把它们排成左半串 $A$（字符 $c$ 重复 $k_c$ 次），令 $L_0 = \sum_c k_c$。若存在奇数频次字符，任选一个（设为 $m$，必有 $\text{cnt}[m] - 2k_m = 1$，所以还有剩余可用）放在中间；否则中间留空。最终串为

$$P = A \;+\; [\,m\,] \;+\; \text{reverse}(A)$$

它的长度是 $2L_0$（或 $2L_0 + 1$），且关于中心对称，是回文串；字符 $c$ 的用量为 $2k_c \le \text{cnt}[c]$（中心字符额外用 1 个，仍有 $2k_m + 1 \le \text{cnt}[m]$），全部在配额之内。∎

**引理 3（中心判定）**：$n - 2\sum_c \lfloor \text{cnt}[c]/2\rfloor = \#\{c : \text{cnt}[c] \text{ 为奇数}\}$，因此 `ans < n` 与「存在奇数频次字符」等价。

**证明**：由 $\text{cnt}[c] - 2\lfloor \text{cnt}[c]/2\rfloor = \text{cnt}[c] \bmod 2 \in \{0,1\}$，对 $c$ 求和得 $n - \text{ans} = \sum_c (\text{cnt}[c] \bmod 2)$，而右边正是频次为奇数的字符个数，它是非负整数，故 `ans < n` 当且仅当该个数 $\ge 1$。∎

**定理**：算法返回的值等于可构造的最长回文串长度。

**证明**：由引理 3，算法第 3 步恰好在上界公式中含有 $+1$ 项时执行一次 `ans += 1`，否则不执行，故返回值等于引理 1 的上界。由引理 1，任何合法构造的长度都不超过该值；由引理 2，该值可以被构造达到。因此返回值即为最大值。∎

## 6. 复杂度分析

- **时间**：$O(n + \lvert \Sigma \rvert) = O(n)$。统计频次扫一遍 `s`，$O(n)$；随后遍历常数大小（52 或 128）的频次表累加，$O(\lvert \Sigma \rvert) = O(1)$。
- **空间**：$O(\lvert \Sigma \rvert) = O(1)$。只需要一张固定大小的频次表（128 个 `int`）；若用哈希表则是 $O(\min(n, \lvert\Sigma\rvert))$，本题规模下没有区别。不构造字符串，故不存在 $O(n)$ 的额外空间。

## 7. 参考代码

### C++

```cpp
#include <string>
using namespace std;

class Solution {
public:
    int longestPalindrome(string s) {
        int cnt[128] = {0};
        for (char ch : s) {
            cnt[(unsigned char)ch]++;          // 大小写分开计数
        }
        int ans = 0;
        for (int i = 0; i < 128; i++) {
            ans += cnt[i] / 2 * 2;             // 每个字符的偶数部分
        }
        // ans < n 等价于「存在奇数频次字符」，此时可以往正中心再放 1 个
        if (ans < (int)s.size()) {
            ans += 1;
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def longestPalindrome(self, s: str) -> int:
        cnt = {}
        for ch in s:
            cnt[ch] = cnt.get(ch, 0) + 1
        ans = 0
        for v in cnt.values():
            ans += v // 2 * 2
        # 只要还有落单字符，就能挑一个放到正中心
        if ans < len(s):
            ans += 1
        return ans
```

## 8. 边界情况与易错点

1. **单字符**：`"a"` → 1。偶数部分为 0，`0 < 1` 成立，`+1` 得到 1，不需要特判。
2. **全部同字符**：`"aaaa"` → 4，此时 `ans == n`，**不能** `+1`；写成「总是 +1」会输出 5。
3. **全部互不相同**：`"abcdef"` → 1，只能取一个字符坐中心；不要误以为能取 6。
4. **大小写混淆**：`"Aa"` → 1、`"AaB"` → 1（`A`、`a`、`B` 各 1 个，凑不出一对）。若用 `tolower` 把 `A` 并进 `a`，前者的频次变成 `a:2` 而错误输出 2，后者错误输出 3。
5. **多个落单字符**：`"aabbc"` → 5，`"aabbcde"` → 5。落单字符再多也只能加 1。
6. **判定条件写错**：把 `ans < n` 写成 `ans <= n` 会导致全偶数时多加 1；也可显式维护 `hasOdd` 布尔量来避免这个坑。
7. **`char` 下标越界**：C++ 中 `char` 可能是有符号的，若字符串含非 ASCII 字节，直接用 `cnt[ch]` 会得到负下标；统一转 `unsigned char` 更稳。
8. **不要真的去构造字符串**：本题只问长度，构造会引入 $O(n)$ 额外空间与拼接开销（Python 里 `left + mid + left[::-1]` 还是 $O(n)$，但没必要）。

**延伸思考**：

- 若要求**返回字典序最小**的最长回文串，贪心仍成立：左半按字符升序排列，中心取最小的可落单字符，再镜像即可，复杂度不变。
- 若要求「用掉全部字符，最少删除多少个才能成为回文」，答案是 $\#\{c: \text{cnt}[c] \text{ 为奇数}\} - 1$（没有落单字符时删 0 个），也等于 $n - \text{ans} - 1$（当 $n > \text{ans}$ 时）。
- 若每个字符带**权重**（用 1 个字符的收益不同），问题就不再是简单求和，而要按权重排序后贪心配对，甚至变成带约束的背包问题——这是本题从「计数」跨到「优化」的分水岭。
