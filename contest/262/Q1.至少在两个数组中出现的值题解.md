# LeetCode 至少在两个数组中出现的值 题解

## 1. 题目概述

- **标题 / 题号**：至少在两个数组中出现的值（#2032，easy）
- **链接**：https://leetcode.cn/problems/two-out-of-three/
- **来源**：LeetCode 第 262 场周赛 Q1
- **难度**：简单
- **标签**：位运算、数组、哈希表、计数

**题意**：给定三个整数数组 `nums1`、`nums2`、`nums3`，构造并返回一个**元素各不相同**的数组，由**至少出现在两个**数组中的所有值组成；返回顺序任意。

**约束**：

- $1 \le \text{nums1.length}, \text{nums2.length}, \text{nums3.length} \le 100$
- $1 \le \text{nums1}[i], \text{nums2}[j], \text{nums3}[k] \le 100$

> 💡 **审题关键**：①「至少在两个数组中出现」按**数组归属**计数，而非按出现次数——同一数组内的重复只算一个归属（示例 1 的 $1$ 在 `nums1` 里出现两次，照样落选）；② 结果**元素各不相同**，需去重；③ 值域仅 $[1,100]$、数组长度 $\le 100$，**值域桶**可用。三条合起来指向「一趟登记 + 一趟筛选」的 $O(n)$ 解法。

## 2. 示例

**示例 1**

```text
输入：nums1 = [1,1,3,2], nums2 = [2,3], nums3 = [3]
输出：[3,2]
解释：3 出现在全部三个数组；2 出现在 nums1、nums2；
      1 只出现在 nums1（出现两次也只算一个数组）→ 落选。
```

**示例 2**

```text
输入：nums1 = [3,1], nums2 = [2,3], nums3 = [1,2]
输出：[2,3,1]
解释：1 出现在 nums1、nums3；2 出现在 nums2、nums3；3 出现在 nums1、nums2
      —— 三个值都恰好属于两个数组，全部入选。
```

**示例 3**

```text
输入：nums1 = [1,2,2], nums2 = [4,3,3], nums3 = [5]
输出：[]
解释：三个数组两两不相交，没有任何值属于 ≥ 2 个数组。
```

## 3. 解题思路

### 3.1 暴力思路

签到题规模（总长 $\le 300$），先盘几条朴素路线：

1. **候选集 × 逐数组线性查找**：把三个数组的值去重后并成候选集（至多 $300$ 个），对每个候选值 $v$ 依次在三个数组里线性扫描数命中个数，$\ge 2$ 即收录。$O(U \cdot (n_1+n_2+n_3)) \approx 9 \times 10^4$，能过——但对每个候选值都把三个数组重扫一遍，重复劳动；正确方向是把「逐值查数组」倒过来变成「逐数组登记值」。
2. **集合代数**：三个数组各转 `set`，取两两交集再并：$(S_1 \cap S_2) \cup (S_1 \cap S_3) \cup (S_2 \cap S_3)$。正确（见 §7 Python 备选版），但要三次建集合、三次交集、两次并集；掩码路线把登记压成一遍扫描，还额外保留「具体出现在哪几个数组」的信息。
3. **按出现次数统计（错误！）**：对三个数组的所有元素直接计数，`cnt[v] >= 2` 就收录——**反例就是示例 1**：`nums1 = [1,1,3,2]` 里 $1$ 出现了两次，但它只属于一个数组，正确答案不含 $1$。这条「看起来最省事」的路线恰是本题唯一的坑：**判定维度是「出现在哪几个数组」，不是「出现几次」**。

### 3.2 核心观察：按值聚合 + 3 位归属掩码

![核心概念：三个数组按值聚合，归属用 3 位掩码登记，popcount ≥ 2 收录](images/wc262_q1_mask_concept.svg)

三个观察把代码压到最短：

1. **归属按集合不按次数**：问题问的是 $v$ 属于几个数组，每个数组应视作**集合**。数组内的重复既不该多记（次数陷阱），也无需专门去重（见下一条的幂等性）。
2. **3 位掩码编码归属**：令数组编号 $i = 0, 1, 2$，对每个值 $v$ 维护 $\text{mask}[v]$，第 $i$ 位为 $1$ 表示 $v$ 出现在第 $i+1$ 个数组：遍历数组 $i$ 时对其中每个元素执行 $\text{mask}[v] \mathrel{|}= 2^i$。三个集合只有 $2^3 = 8$ 种归属状态，3 位全编码。**位或幂等**（$x \mid b \mid b = x \mid b$）——同一数组重复登记不改变掩码，掩码法**天然免疫重复元素**，连 `set` 预去重都省了（计数法必须先去重，否则重复元素被多次计数）。
3. **popcount 判定 + 值域扫描收集**：「至少两个数组」$\iff \text{popcount}(\text{mask}[v]) \ge 2$。值域仅 $[1,100]$，最后直接扫 $v = 1 \dots 100$：每个值恰检查一次，产出天然**升序、互异**——「元素各不相同」的要求一步到位，无需排序/去重。

> 💡 **范式提炼**：「$k$ 个集合的归属判定」通用解 = $k$ 位掩码登记 + `popcount` 与阈值比较。「至少 / 恰好 / 至多 $m$ 个」都只是 popcount 的比较方式不同。

### 3.3 算法流程

![算法流程：建桶、三趟位或登记、值域扫描、popcount 判定收集](images/wc262_q1_scan_flow.svg)

1. **建桶**：`mask[0..100]` 全 $0$（值域数组，下标即值，下标 $0$ 弃用）；
2. **登记**：遍历 `nums1` 执行 `mask[v] |= 1`，遍历 `nums2` 执行 `mask[v] |= 2`，遍历 `nums3` 执行 `mask[v] |= 4`；
3. **收集**：$v$ 从 $1$ 扫到 $100$，`popcount(mask[v]) >= 2` 的值收入答案；
4. **返回** `ans`（升序，元素互异）。

### 3.4 示例演算

以示例 1 `nums1 = [1,1,3,2]`、`nums2 = [2,3]`、`nums3 = [3]` 演算：

![示例演算：三趟登记的掩码变化与值域扫描的筛选结果](images/wc262_q1_walkthrough.svg)

| 值 $v$ | b₂ (nums3) | b₁ (nums2) | b₀ (nums1) | 掩码 | popcount | 入选？ |
|--------|-----------|-----------|-----------|------|----------|--------|
| 1 | 0 | 0 | 1 | `001` = 1 | 1 | ✗（出现两次但只属一个数组） |
| 2 | 0 | 1 | 1 | `011` = 3 | 2 | ✅ |
| 3 | 1 | 1 | 1 | `111` = 7 | 3 | ✅ |

登记过程：扫 `nums1` 得 `mask[1]=001, mask[2]=001, mask[3]=001`（第二个 $1$ 的重复 `|=` 无变化）；扫 `nums2` 得 `mask[2]=011, mask[3]=011`；扫 `nums3` 得 `mask[3]=111`。扫描值域收录 $2, 3$，输出 `[2,3]`——与示例的 `[3,2]` 仅顺序不同（题目允许任意顺序）。

## 4. 算法细节

1. **桶大小与下标**：值域 $[1,100]$ 开 `mask[101]`，下标 $0$ 恒为 $0$ 弃用。值域直下标省掉哈希函数，比 `unordered_map` / `dict` 更快更省——「值域小用数组、值域大用哈希」的经典取舍。
2. **位编号**：`nums1 → bit0 (1)`、`nums2 → bit1 (2)`、`nums3 → bit2 (4)`。C++ 用三行展开（见 §7）比「数组指针 + 循环」更短更直白；Python 用 `enumerate((nums1, nums2, nums3))` 统一处理。
3. **为什么不用先 `set` 去重**：$x \mid b \mid b = x \mid b$，同一数组重复遇到同一值时掩码不变，幂等性自动吸收重复。对比计数法（`cnt[v] += 1`）：**必须**先 `set(arr)` 去重，否则 `nums1 = [1,1]` 会把 $1$ 记成 $2$ 个数组、误收入答案——幂等性正是掩码法对计数法的本质优势。
4. **popcount 的三种写法**：C++ `__builtin_popcount`（通常编译为单条 `POPCNT` 指令）；Python 3.10+ `int.bit_count()`；低版本 `bin(m).count('1')`。掩码仅 3 位时手写 `(m&1)+((m>>1)&1)+((m>>2)&1)` 也行——内置写法一行通用。
5. **返回顺序**：题目允许任意顺序，判题按集合相等比较；值域扫描天然产出升序序列，本地对拍最稳。集合代数路线（§7 备选版）加 `sorted` 只为输出确定。
6. **「至少」包含上界**：$\ge 2$ 含三个数组全中（popcount $= 3$）的情形，如示例 1 的 $3$；写成 $> 2$ 会漏掉三数组共有的值。

## 5. 正确性证明

**引理 1**（登记正确性 / 幂等性）：对 $i \in \{0,1,2\}$，遍历 $\text{nums}_{i+1}$ 的全部元素执行 $\text{mask}[v] \mathrel{|}= 2^i$ 后，对任意值 $v$：$\text{mask}[v]$ 的第 $i$ 位为 $1$ $\iff$ $v \in \text{nums}_{i+1}$。

**证明**：（$\Leftarrow$）若 $v \in \text{nums}_{i+1}$，遍历中至少遇到 $v$ 一次，该次操作把第 $i$ 位与 $1$ 相或，由 $0 \mid 1 = 1$ 该位置 $1$。（$\Rightarrow$）若第 $i$ 位为 $1$，考察其首次变为 $1$ 的那次操作 $\text{mask}[v'] \mathrel{|}= 2^i$，必有 $v' = v$ 且 $v$ 是 $\text{nums}_{i+1}$ 的元素。又位或只置位不清位（$x \mid b$ 的第 $i$ 位不低于 $x$ 的第 $i$ 位），重复登记不改变已置位的位，故重复元素无害。∎

**引理 2**（popcount 等价性）：登记完成后，$\text{popcount}(\text{mask}[v]) = $ 包含 $v$ 的数组个数。

**证明**：$\text{mask}[v]$ 仅低 3 位有效。由引理 1，第 $i$ 位为 $1$ $\iff$ 第 $i+1$ 个数组包含 $v$；popcount 统计 $1$ 的位数，与集合 $\{\, i : v \in \text{nums}_{i+1} \,\}$ 的元素个数一一对应。∎

**定理**：算法返回的数组恰为 $\{\, v \in [1,100] : v \text{ 至少出现在两个数组中} \,\}$ 的升序互异排列。

**证明**：算法对 $v \in [1,100]$ 各检查恰一次——升序、互异由扫描结构直接保证。由引理 2，收录条件 $\text{popcount}(\text{mask}[v]) \ge 2$ 等价于「至少两个数组包含 $v$」。凡收录者满足条件；凡满足条件者（数组元素都在值域内，故必在 $[1,100]$ 中）必被收录。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n_1 + n_2 + n_3 + V)$，其中 $V = 100$。三趟登记共 $\le 300$ 次位或（每次 $O(1)$），值域扫描 $100$ 次 popcount。$V$ 为常数，总体线性 $O(n_1+n_2+n_3)$，运算量在几百次量级。
- **空间复杂度**：$O(V) = O(1)$，即长度 $101$ 的整型桶。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> twoOutOfThree(vector<int>& nums1, vector<int>& nums2, vector<int>& nums3) {
        int mask[101] = {0};
        for (int v : nums1) mask[v] |= 1;   // bit0：nums1 归属（重复 |= 幂等，无需去重）
        for (int v : nums2) mask[v] |= 2;   // bit1：nums2 归属
        for (int v : nums3) mask[v] |= 4;   // bit2：nums3 归属
        vector<int> ans;
        for (int v = 1; v <= 100; ++v)
            if (__builtin_popcount(mask[v]) >= 2)   // ≥2：含三个全中的情形
                ans.push_back(v);
        return ans;
    }
};
```

### Python

```python
class Solution:
    def twoOutOfThree(self, nums1: List[int], nums2: List[int], nums3: List[int]) -> List[int]:
        mask = [0] * 101
        for i, arr in enumerate((nums1, nums2, nums3)):
            for v in arr:                     # 重复元素：重复 |= 同一位，幂等无害
                mask[v] |= 1 << i
        return [v for v in range(1, 101) if mask[v].bit_count() >= 2]
```

### Python 备选：集合代数一行版

```python
class Solution:
    def twoOutOfThree(self, nums1: List[int], nums2: List[int], nums3: List[int]) -> List[int]:
        s1, s2, s3 = set(nums1), set(nums2), set(nums3)
        return sorted(s1 & s2 | s1 & s3 | s2 & s3)   # 两两交集的并
```

> ⚠️ `int.bit_count()` 需 Python 3.10+；低版本用 `bin(mask[v]).count('1')`。集合版正确但丢掉了「具体在哪几个数组」的归属信息——需要该信息的变体题里，掩码版更通用。

## 8. 边界情况与易错点

1. **头号陷阱：按总出现次数统计**。`nums1 = [1,1]` 的 $1$ 出现两次但只属一个数组，不能入选——示例 1 即内置反例（正确答案 `[3,2]` 不含 $1$）。「至少在两个数组」按**归属**计数。
2. **计数法必须先去重，掩码法不用**。若写 `cnt[v] += 1`，必须先 `set(arr)`；掩码靠 $x \mid b \mid b = x \mid b$ 的幂等性天然免疫重复。
3. **「元素各不相同」**：若遍历数组（而非值域）收集结果，会引入重复（$v$ 同时在 $S_1 \cap S_2$ 与 $S_1 \cap S_3$ 里被加两次）；值域扫描 / 集合运算天然去重。
4. **空答案**：三个数组两两不相交（示例 3）→ 返回 `[]`，代码无需特判。
5. **值域从 1 开始**：`mask[0]` 恒为 $0$；若做含 $0$ 值域的变体，扫描起点改为 $0$、桶按值域开。
6. **「至少」含上界**：popcount $\ge 2$ 含 $= 3$（三数组全中，示例 1 的 $3$）；写 $> 2$ 漏解。
7. **返回顺序任意**：本地对拍按集合比较，别拿列表相等当错判；升序输出最稳。
8. **桶开 101 而非 100**：下标要用到 $100$。
