# LeetCode 将数组分成两个数组并最小化数组和的差 题解

## 1. 题目概述

- **标题 / 题号**：将数组分成两个数组并最小化数组和的差（#2035，hard）
- **链接**：https://leetcode.cn/problems/partition-array-into-two-arrays-to-minimize-sum-difference/
- **来源**：LeetCode 第 262 场周赛 Q4
- **难度**：困难
- **标签**：数组、位掩码、中途相遇法、二分查找、排序

**题意**：给定长度为 $2n$ 的整数数组 `nums`，把它分成**两个长度均为 $n$** 的数组，每个元素恰好归入其一；分别求两组的和，最小化两和之差的**绝对值**，返回这个最小差。

**约束**：

- $1 \le n \le 15$，$\text{nums.length} = 2n$（元素至多 30 个）
- $-10^7 \le \text{nums}[i] \le 10^7$ → 总和 $|S| \le 3 \times 10^8$，有正有负

> 💡 **审题关键**：$n \le 15$ 是全场最强的复杂度信号——$\binom{30}{15} \approx 1.55 \times 10^8$ 个 $n$ 元子集枚不动，但两半**各** $2^{15} = 32768$ 恰在甜区；而「两组**等长**」的约束堵死了背包（值域 $3 \times 10^8$ 存不下）与贪心，把人往**中途相遇法**（Meet in the Middle）逼。赛场上看到「$2n \le 30$ + 等长分组」，MITM 几乎是唯一候选。

## 2. 示例

**示例 1**

```text
输入：nums = [3,9,7,3]
输出：2
解释：最优分组 [3,9] 和 [7,3]，
     |(3+9) − (7+3)| = |12 − 10| = 2。
```

**示例 2（n = 1 退化）**

```text
输入：nums = [-36,36]
输出：72
解释：只能分成 [-36] 和 [36]，差为 |−36 − 36| = 72。
```

**示例 3（负数 + 可凑零）**

```text
输入：nums = [2,-1,0,4,-2,-9]
输出：0
解释：[2,4,-9] 和 [-1,0,-2]，两组和均为 −3，差为 0。
```

## 3. 解题思路

### 3.1 暴力思路

设总和 $S = \sum \text{nums}$。任取一个 $n$ 元子集作第一组，其和为 $s_1$，则第二组和为 $S - s_1$，差为

$$|s_1 - (S - s_1)| = |\,2 s_1 - S\,|$$

于是目标等价于：**让某个 $n$ 元子集的和 $s_1$ 尽可能接近 $\dfrac{S}{2}$**。

暴力做法是枚举全部 $\binom{2n}{n}$ 个 $n$ 元子集。$n = 15$ 时 $\binom{30}{15} \approx 1.55 \times 10^8$，逐个求和 $O(n)$，总量超 $2 \times 10^9$，**必超时**。瓶颈在于：$30$ 位的选择空间被当作一个整体枚举，指数压不下来。

### 3.2 核心观察：中途相遇法（Meet in the Middle）

![核心概念：数组劈成两半各自枚举 2^n 个子集，在中间按元素个数 k 会合](images/wc262_q4_mitm_concept.svg)

把 `nums` 切成前一半 $A$、后一半 $B$（各 $n$ 个）。任何一个 $n$ 元子集，必然**从 $A$ 取 $k$ 个、从 $B$ 取 $n-k$ 个**（$0 \le k \le n$）。于是：

1. 对 $A$、$B$ **各自独立**枚举全部 $2^n$ 个子集，按子集大小（`popcount`）分组：
   $\text{sums}_A[k]$ = 「$A$ 的大小为 $k$ 的子集」的和的列表，$\text{sums}_B$ 同理；
2. 枚举 $k$：把 $s_1 \in \text{sums}_A[k]$ 与 $s_2 \in \text{sums}_B[n-k]$ **配对**，配对出的就是「$A$ 取 $k$ 个 + $B$ 取 $n-k$ 个」的 $n$ 元子集之和 $s_1 + s_2$；
3. 目标：让 $s_1 + s_2$ 尽可能接近 $\dfrac{S}{2}$——把 $\text{sums}_B[n-k]$ **排序**，对每个 $s_1$ **二分**找最接近 $\dfrac{S}{2} - s_1$ 的 $s_2$。

> 💡 **为什么能省**：整体枚举 $\binom{2n}{n}$ 被拆成「两半各 $2^n$ 个任意大小子集 + 按个数配对」。由范德蒙恒等式 $\sum_{k=0}^{n} \binom{n}{k}\binom{n}{n-k} = \binom{2n}{n}$，配对空间恰好覆盖全部 $n$ 元子集、不重不漏；而每半只需 $2^{15} = 32768$ 个子集，配对阶段靠排序 + 二分压到对数级。总量从 $10^9$ 级降到 $10^5$ 级——**指数从 $2^{2n}$ 砍到 $2 \cdot 2^{n}$**。

### 3.3 算法流程

![算法流程：切半 → 位掩码枚举并按 popcount 分组 → 排序 → 对每个 k 二分配对](images/wc262_q4_pairing_flow.svg)

1. **切半**：$A = \text{nums}[0..n-1]$，$B = \text{nums}[n..2n-1]$，算出 $S$；
2. **枚举子集**：位掩码 $0 \sim 2^n - 1$ 扫两半，用「去掉最低位递推」$O(1)$ 求每个子集和，按 `popcount` 入桶得 $\text{sums}_A[\,]$、$\text{sums}_B[\,]$；
3. **排序**：对每个 $k$ 将 $\text{sums}_B[k]$ 排序（$\text{sums}_A$ 不排，直接遍历）；
4. **配对**：对每个 $k$、每个 $s_1 \in \text{sums}_A[k]$，在有序的 $\text{sums}_B[n-k]$ 中二分定位 $\text{target} = \dfrac{S}{2} - s_1$，检查**命中位置及其前一个**两个候选，用 $|2(s_1+s_2) - S|$ 更新答案；
5. 返回最小值。

### 3.4 示例演算

![示例演算：A=[3,9]、B=[7,3]，按 k 分组配对二分，最小差 2](images/wc262_q4_walkthrough.svg)

以示例 1 `nums = [3,9,7,3]`（$n=2$）走一遍：切半 $A=[3,9]$、$B=[7,3]$，$S=22$，目标 $\dfrac{S}{2}=11$。

**第一步：枚举各半子集，按大小分组**

| $k$ | $\text{sums}_A[k]$ | $\text{sums}_B[k]$（已排序） |
|-----|--------------------|------------------------------|
| 0   | $\{0\}$            | $\{0\}$                      |
| 1   | $\{3, 9\}$         | $\{3, 7\}$                   |
| 2   | $\{12\}$           | $\{10\}$                     |

**第二步：按 $k$ 配对，二分找最接近 $11 - s_1$ 的 $s_2$**

| $k$ | $s_1$ | target $= 11 - s_1$ | $\text{sums}_B[n-k]$ 中最近 $s_2$ | $s_1+s_2$ | $\|2(s_1+s_2)-S\|$ |
|-----|-------|---------------------|-------------------------------------|-----------|---------------------|
| 0   | 0     | 11                  | $\text{sums}_B[2]=\{10\}$ → 10      | 10        | $\|20-22\| = 2$     |
| 1   | 3     | 8                   | $\{3,7\}$ → 7（次近 3）             | 10        | 2                   |
| 1   | 9     | 2                   | $\{3,7\}$ → 3（次近 7）             | 12        | $\|24-22\| = 2$     |
| 2   | 12    | −1                  | $\text{sums}_B[0]=\{0\}$ → 0        | 12        | 2                   |

四个配对通道全部给出最小差 **2**，对应分组 $[3,7]$（和 10）与 $[9,3]$（和 12）。

## 4. 算法细节

1. **子集和用「去最低位」递推，别逐位重算**：`f[mask] = f[mask & (mask-1)] + arr[__builtin_ctz(mask)]`——每个子集和 $O(1)$ 得到，整个枚举阶段 $O(2^n)$ 而非 $O(2^n \cdot n)$。`mask & (mask-1)` 去掉最低位 1，`__builtin_ctz` 给出该位下标（Python：`i = (mask ^ (mask & (mask-1))).bit_length() - 1`）。
2. **按 `popcount` 分桶是等长约束的载体**：配对 $(s_1, s_2)$ 对应的子集大小为 $k + (n-k) = n$，恰满足「第一组 $n$ 个」；不分组直接混合配对会凑出错误大小的子集。
3. **只排序 $\text{sums}_B$**：$\text{sums}_A$ 各桶无需有序，作遍历方；一边有序即可二分，省一半排序。
4. **二分后查两个位置**：`lower_bound` 命中位置 `it` 与 `it - 1`（最后一个小于 target 的元素）——离 target 最近的必在这两处（引理 3），只查一处会漏。
5. **浮点定位的精确性**：$|S| \le 3 \times 10^8$、$|s_1 + s_2| \le 3 \times 10^8$，远小于 `double` 的 $2^{53} \approx 9 \times 10^{15}$ 精确整数域，`S / 2.0` 与 `half - s1` **逐位精确**（半整数也精确），二分比较无误差；最终答案由整数式 $|2(s_1+s_2) - S|$ 计算，浮点不参与输出。
6. **纯整数替代**（不放心浮点时）：想让 $s_2$ 逼近 $\dfrac{S - 2 s_1}{2}$，等价于让 $2 s_2$ 逼近 $S - 2 s_1$；用整数 `lower_bound` 定位后同样查两个位置即可，复杂度不变。
7. **溢出账**：子集和上限 $15 \times 10^7 = 1.5 \times 10^8$，$|2(s_1+s_2) - S| \le 9 \times 10^8$，`int` 恰好装得下但贴边；混合运算建议统一 `long long`，Python 无此虑。

## 5. 正确性证明

**引理 1**（差值化简）：对任意合法划分 $(P, Q)$，$|\sum P - \sum Q| = |\,2\sum P - S\,|$。

**证明**：$P \cup Q$ 恰为全体元素且不相交，故 $\sum Q = S - \sum P$，代入即得。∎

**引理 2**（配对完备性）：合法的 $n$ 元子集与三元组 $(k, X, Y)$（$X \subseteq A$，$|X| = k$；$Y \subseteq B$，$|Y| = n-k$）一一对应；从而算法的配对空间 $\{(k, s_1, s_2) : s_1 \in \text{sums}_A[k],\ s_2 \in \text{sums}_B[n-k]\}$ 恰好覆盖所有 $n$ 元子集的和。

**证明**：给定 $n$ 元子集 $P$，令 $X = P \cap A$、$Y = P \cap B$，则 $|X| + |Y| = n$，取 $k = |X|$ 即得一个三元组；反之给定 $(k, X, Y)$，$P = X \cup Y$ 是 $n$ 元子集，且补集 $\overline{P}$ 也恰有 $2n - n = n$ 个元素，是合法的另一组。两个方向的构造互逆，故为一一对应（计数上即范德蒙恒等式 $\sum_k \binom{n}{k}\binom{n}{n-k} = \binom{2n}{n}$）。又 $\text{sums}_A[k]$ 恰为全体 $X$ 的和、$\text{sums}_B[n-k]$ 恰为全体 $Y$ 的和，配对空间覆盖所有 $\sum P = s_1 + s_2$。∎

**引理 3**（二分两位置）：设 $b$ 为非降序列，$t$ 为任意实数，$p$ 为第一个 $b_p \ge t$ 的下标（不存在则 $p = |b|$），则距离 $t$ 最近的元素必在 $b_{p-1}$ 与 $b_p$ 之中。

**证明**：对任意 $i < p - 1$：$b_i \le b_{p-1} < t$，故 $t - b_i \ge t - b_{p-1} > 0$，$b_{p-1}$ 不比 $b_i$ 远；对任意 $i > p$：$b_i \ge b_p \ge t$，故 $b_i - t \ge b_p - t \ge 0$，$b_p$ 不比 $b_i$ 远。故最近者 $\in \{b_{p-1}, b_p\}$（越界位置跳过）。∎

**定理**（正确性）：算法返回的 `ans` 等于最小差 $\min_P |\,2\sum P - S\,|$（$P$ 取遍所有 $n$ 元子集）。

**证明**：设最优子集 $P^*$，其差 $D^* = |2\sum P^* - S|$。由引理 2，存在 $k$ 与 $s_1 \in \text{sums}_A[k]$、$s_2^* \in \text{sums}_B[n-k]$ 使 $s_1 + s_2^* = \sum P^*$。固定 $k, s_1$ 时，$g(s_2) = |2(s_1 + s_2) - S|$ 作为 $s_2$ 的函数关于 $s_2 = \dfrac{S - 2 s_1}{2}$ 对称且在其两侧单调，故最小值恰在 $s_2$ **最接近** $\dfrac{S}{2} - s_1$ 处取得。由引理 3，算法二分检查的 $b_{p-1}, b_p$ 中必有最接近者，故算法至少评估了 $g(s_2^*) \ge \min g$，即 $\text{ans} \le D^*$。反过来，算法评估的每个 $(s_1, s_2)$ 由引理 2 反向对应一个合法 $n$ 元子集，故 $\text{ans} \ge \min_P |2\sum P - S| = D^*$。两方面夹逼得 $\text{ans} = D^*$。∎

**定理**（复杂度）：算法时间 $O(2^n \cdot n)$、空间 $O(2^n)$。

**证明**：子集枚举递推 $O(2^n)$；排序 $\sum_k \binom{n}{k} \log \binom{n}{k} \le 2^n \cdot \max_k \log \binom{n}{k} \le 2^n \cdot \log\binom{15}{7} < 2^n \cdot 13$；配对阶段遍历 $\sum_k \binom{n}{k} = 2^n$ 个 $s_1$，每次二分 $O(\log \binom{n}{n-k}) \le O(n)$。三项合计 $O(2^n \cdot n)$。空间为两组子集和共 $2 \cdot 2^n$ 个数。∎

## 6. 复杂度分析

- **时间复杂度**：$O(2^n \cdot n)$。$n = 15$ 时约 $32768 \times 15 \approx 5 \times 10^5$ 次基本操作（枚举递推 $3 \times 10^4$、排序约 $4 \times 10^5$、配对二分约 $5 \times 10^5$），相比暴力 $\binom{30}{15} \cdot n \approx 2 \times 10^9$ **快四个数量级**。
- **空间复杂度**：$O(2^n)$。$\text{sums}_A$、$\text{sums}_B$ 共存 $2 \times 32768$ 个整数，约几百 KB。

## 7. 参考代码

### C++（递推子集和 + 二分定位）

```cpp
class Solution {
public:
    int minimumDifference(vector<int>& nums) {
        int n = nums.size() / 2;
        vector<int> A(nums.begin(), nums.begin() + n);
        vector<int> B(nums.begin() + n, nums.end());

        long long S = 0;
        for (int x : nums) S += x;

        // 位掩码递推求子集和：f[mask] = f[去掉最低位] + 最低位元素
        vector<long long> fA(1 << n), fB(1 << n);
        for (int mask = 1; mask < (1 << n); ++mask) {
            int lb = mask & (mask - 1);
            int i  = __builtin_ctz(mask);
            fA[mask] = fA[lb] + A[i];
            fB[mask] = fB[lb] + B[i];
        }
        vector<vector<long long>> sumsA(n + 1), sumsB(n + 1);
        for (int mask = 0; mask < (1 << n); ++mask) {
            int k = __builtin_popcount(mask);
            sumsA[k].push_back(fA[mask]);
            sumsB[k].push_back(fB[mask]);
        }
        for (int k = 0; k <= n; ++k)           // 只排序 B 侧，供二分
            sort(sumsB[k].begin(), sumsB[k].end());

        long long ans = LLONG_MAX;
        double half = S / 2.0;                  // |S| ≤ 3e8 < 2^53，double 精确
        for (int k = 0; k <= n; ++k) {
            auto& cand = sumsB[n - k];          // B 侧取 n−k 个
            for (long long s1 : sumsA[k]) {
                double target = half - s1;      // 想让 s1+s2 逼近 S/2
                auto it = lower_bound(cand.begin(), cand.end(), target);
                if (it != cand.end())           // 命中位置与前一个，两处都查
                    ans = min(ans, llabs(2 * (s1 + *it) - S));
                if (it != cand.begin())
                    ans = min(ans, llabs(2 * (s1 + *prev(it)) - S));
            }
        }
        return (int)ans;
    }
};
```

### Python（同构实现）

```python
import bisect

class Solution:
    def minimumDifference(self, nums: List[int]) -> int:
        n = len(nums) // 2
        A, B = nums[:n], nums[n:]
        S = sum(nums)

        def build(arr):
            # 按子集大小分桶的 arr 全部子集和（递推求和，O(2^n)）
            buckets = [[] for _ in range(n + 1)]
            f = [0] * (1 << n)
            for mask in range(1, 1 << n):
                lb = mask & (mask - 1)             # 去掉最低位
                i = (mask ^ lb).bit_length() - 1   # 最低位的下标
                f[mask] = f[lb] + arr[i]
            for mask in range(1 << n):
                buckets[mask.bit_count()].append(f[mask])
            return buckets

        sumsA, sumsB = build(A), build(B)
        for k in range(n + 1):                     # 只排序 B 侧，供二分
            sumsB[k].sort()

        ans = float('inf')
        half = S / 2.0
        for k in range(n + 1):
            cand = sumsB[n - k]                    # B 侧取 n−k 个
            for s1 in sumsA[k]:
                idx = bisect.bisect_left(cand, half - s1)
                for j in (idx - 1, idx):           # 命中位置与前一个，两处都查
                    if 0 <= j < len(cand):
                        ans = min(ans, abs(2 * (s1 + cand[j]) - S))
        return ans
```

> ⚠️ 两处高频翻车点：① 二分后只查命中位置不查前一个——target 落在两元素之间时答案恰在前一个；② `mask & (mask - 1)` 去掉的是**最低位**，配套取下标必须用 `__builtin_ctz` / `bit_length`，别顺手写成最高位逻辑。

## 8. 边界情况与易错点

1. **别漏 $k = 0$ 与 $k = n$**：对应「第一组全取自 $B$」和「全取自 $A$」的极端分组，循环边界必须是 $0 \le k \le n$ 双闭。
2. **二分查两位置**（最大坑）：只查 `lower_bound` 命中处，在 target 恰好被两元素夹住时返回次优——引理 3 的两个候选缺一不可。
3. **负数总和**：$S$ 可为负，$\frac{S}{2}$ 为负半整数也精确；若改用整数除法定位，C++ 负数除法向零截断，与数学上的下取整不一致，需自行校正（这也是推荐浮点定位的原因之一）。
4. **`n = 1` 退化**：两元素只能各归一组，算法在 $k=0,1$ 两个通道自然算出 $|\text{nums}[0] - \text{nums}[1]|$，无需特判（示例 2）。
5. **重复元素**：`sums` 桶内出现重复值无害——二分照常定位，重复候选多评估几次不影响正确性（示例 1 的两个 3）。
6. **切半方式不敏感**：前 $n$ / 后 $n$ 任意切都能保证引理 2 的双射成立，正确性与切法无关；但两侧规模均衡（各 $n$ 个）是复杂度的保障，别切成 $1 : 2n-1$。
7. **溢出**：`int` 上界 $2^{31} - 1 \approx 2.1 \times 10^9$，本题最坏 $9 \times 10^8$ 理论上安全，但 `2 * (s1 + s2)` 的中间量与乘法先后顺序容易踩线，统一 `long long` 一劳永逸。
8. **别把本题当背包**：值域 $|S| \le 3 \times 10^8$ 且有负数，`dp[和]` 的表存不下；「等长」约束使贪心 / 排序配对也无最优性保证——$n \le 15$ 就是出题人留给 MITM 的门。

- [LeetCode 2518. 好分区的数目](https://leetcode.cn/problems/number-of-great-partitions.md)（[题解](../../solution/2501-2600/2518_好分区的数目.md)）：同为「划分成两组」的计数变体，值域大时反向背包 + 容斥，与本题互为镜像。

**延伸思考**：① 若去掉等长约束（任意大小两组）：退化为 1755，可省去按 $k$ 分桶；② 若要求输出具体分组方案：配对时记录 `(s1 的 mask, s2 的 mask)`，二分命中后回溯两个掩码还原选集；③ 若 $2n$ 升到 40（$n=20$）：$2^{20} = 10^6$ 仍可行，但配对阶段需把「每桶排序 + 二分」换成「两桶归并双指针」压常数；④ 正难则反的姐妹问法：判定「差能否为 0」等价于判断是否存在和为 $S/2$ 的 $n$ 元子集——正是 805 的均值版。
