# LeetCode 获取单值网格的最小操作数 题解

## 1. 题目概述

- **标题 / 题号**：获取单值网格的最小操作数（#2033，medium；曾用名「使网格单值的最少操作次数」）
- **链接**：https://leetcode.cn/problems/minimum-operations-to-make-a-uni-value-grid/
- **来源**：LeetCode 第 262 场周赛 Q2
- **难度**：中等
- **标签**：数组、数学、矩阵、排序

**题意**：给定 $m \times n$ 整数网格 `grid` 与正整数 $x$，每次操作可任选一个元素**加 $x$ 或减 $x$**。求使**全部元素相等**（单值网格）所需的**最少操作次数**；无法做到返回 $-1$。

**约束**：

- $1 \le m \cdot n \le 10^5$（元素总数至多 $10^5$）
- $1 \le x,\ \text{grid}[i][j] \le 10^4$（值域上界 $10^4$）

> 💡 **审题关键**：① 操作只改**值**、与**位置**无关，二维网格纯属包装——可直接展平成一维数组；② 每步固定 $\pm x$，意味着元素 $\bmod x$ 的**余数是不变量**，先判可行性；③ 目标一旦确定，每个元素的代价独立可算（距离 $\div x$），问题收缩为「选哪个目标」——正是「到中位数的绝对偏差和」经典模型。

## 2. 示例

**示例 1**

```text
输入：grid = [[2,4],[6,8]], x = 2
输出：4
解释：所有元素除以 2 的余数均为 0，可行；全部变成 4：
      2 加 x 一次、6 减 x 一次、8 减 x 两次，共 4 次。
```

**示例 2**

```text
输入：grid = [[1,5],[2,3]], x = 1
输出：5
解释：x = 1 恒可行，全部变成 3：2 + 1 + 0 + 2 = 5 次操作。
```

**示例 3**

```text
输入：grid = [[1,2],[3,4]], x = 2
输出：-1
解释：1 除以 2 余 1、2 除以 2 余 0，余数不同的元素永远无法相等。
```

## 3. 解题思路

### 3.1 暴力思路

1. **枚举目标值**：可行目标必 $\equiv r \pmod x$（$r$ 为公共余数）且落在 $[\min, \max]$ 内，至多 $\lfloor(\max-\min)/x\rfloor + 1 \le 10^4$ 个候选；对每个候选 $t$ 计算 $\sum_i |a_i - t| / x$ 需 $O(N)$。最坏 $10^4 \times 10^5 = 10^9$ 次运算——C++ 勉强、Python 必超时，且完全没有必要。
2. **逐对 BFS 求距离**：把值域当节点、$\pm x$ 当边，对每对 $(a_i, t)$ 跑最短路——重复劳动更多；其实距离是显式的：$|a_i - t|/x$（可行时）。
3. **观察结构**：目标确定后代价**可分解**（各元素独立），因此问题只剩「不重不漏地锁定最优目标」——这恰是中位数定理的用武之地，一步到位。

### 3.2 核心观察：余数不变量 + 换元归一 + 中位数

![核心概念：余数不变量判可行、换元归一化为每次±1、中位数定目标](images/wc262_q2_mod_concept.svg)

三个观察串成一条链：

1. **余数不变量（可行性）**：一次操作把 $a_i$ 变成 $a_i \pm x$，而 $(a_i \pm x) \bmod x = a_i \bmod x$——**余数在任意操作序列下不变**。故单值网格可达 $\iff$ 全部元素 $\bmod x$ 同余；不同余直接返回 $-1$（示例 3）。检查一遍 $O(N)$。
2. **换元归一化（步长变 1）**：设公共余数为 $r$，令 $b_i = (a_i - r)/x$（整数）。目标 $t$ 必须 $\equiv r \pmod x$，对应 $t' = (t-r)/x$；每次操作 $\pm x$ 在 $b$ 的世界里就是 $\pm 1$。于是总代价 $= \sum_i |b_i - t'|$——**「每次某数 $\pm 1$，最少几步使数组相等」正是 LeetCode 462 的原题**。
3. **中位数（选目标）**：$\sum_i |b_i - t'|$ 是关于 $t'$ 的凸分段线性函数，最小值在**中位数**处取到。又因为 $a \mapsto b$ 是保序仿射映射，$b$ 的中位数恰是 $a$ 的中位数（排序后第 $\lfloor N/2 \rfloor$ 个元素，0-indexed）的像——**代码无需真的换元**：直接取 $\text{med} = a[N/2]$，答案 $= \sum_i |a_i - \text{med}| \, / \, x$。

> 💡 **范式提炼**：「固定步长 $\pm x$ 的凑齐问题」通用解 = 同余检查 + 除以 $x$ 归一 + 中位数定目标。L1 型代价看**中位数**，L2 型（平方和）才看**平均值**。

### 3.3 算法流程

![算法流程：同余检查、排序取中位数、距离和除以x](images/wc262_q2_median_flow.svg)

1. **展平**：`a ← grid 全部元素`（$N = m \cdot n$）；
2. **同余检查**：$r = a_0 \bmod x$，任一 $a_i \bmod x \ne r$ → `return -1`；
3. **排序取中位数**：$\text{med} = a[N/2]$（0-indexed；偶数 $N$ 时中间区间任一点皆可）；
4. **累加再除**：`sum = Σ|a_i − med|`（`long long`），`return sum / x`。

### 3.4 示例演算

![示例演算：示例1数轴收敛到中位数6、示例2一步除以1、示例3同余止损](images/wc262_q2_walkthrough.svg)

以示例 1 `grid = [[2,4],[6,8]]`、$x = 2$ 演算：

| 元素 $a_i$ | 目标 med | $\|a_i - 6\|$ | 次数 $= \div 2$ |
|-----------|---------|---------------|----------------|
| 2 | 6 | 4 | 2 |
| 4 | 6 | 2 | 1 |
| 6 | 6 | 0 | 0 |
| 8 | 6 | 2 | 1 |
| **合计** | — | **8** | **4** ✓ |

排序后 $[2,4,6,8]$，$N=4$，$\text{med} = a[2] = 6$（中间区间 $[4,6]$ 任取可达值代价相同：取 $4$ 得 $2+0+2+4=8$，同样 $8/2 = 4$）。示例 2 中 $x = 1$ 退化为 462 原题：排序 $[1,2,3,5]$，med $=3$，$2+1+0+2 = 5$。

## 4. 算法细节

1. **展平**：操作与行列位置无关，网格只是「数组的一层皮」；展平后只处理一维序列，连 $m$、$n$ 都不必保留。
2. **同余检查**：`r = a[0] % x`，遍历判 `v % x != r` 即返回 $-1$；等价写法 `(v − a[0]) % x != 0`。本题值全为正，C++ 取余无非负陷阱；若变体含负数，需 `(v % x + x) % x` 先归一。
3. **中位数下标**：0-indexed `med = a[N/2]`。$N$ 偶时 `a[N/2]` 与 `a[N/2−1]` 均为合法最优点（中间区间上代价恒定），但**必须取真实元素**（或至少 $\equiv r \pmod x$ 的值）：若取了不可达值（如 $a = [2,4]$、$x=2$ 取 $t=3$），逐项差 $\pm 1$ 不被 $x$ 整除，除法直接失真。
4. **排序的替身**：值域 $V \le 10^4$ → 计数排序 $O(N+V)$；只要第 $N/2$ 小 → `nth_element` 平均 $O(N)$。普通 `sort` $O(N \log N)$ 也绰绰有余（$N \log N \approx 1.7 \times 10^6$）。
5. **溢出**：$\sum |a_i - \text{med}| \le N \cdot V = 10^5 \times 10^4 = 10^9$，逼近 `int` 上界（$\approx 2.1 \times 10^9$）——用 `long long` 累加再除，稳。
6. **整除性**：`med` 与每个 $a_i$ 都 $\equiv r \pmod x$，故每项差、进而总和都是 $x$ 的倍数——先求和再整除与逐项整除等价，无精度损失。

## 5. 正确性证明

**引理 1**（余数不变量与可行性）：单值网格可达 $\iff$ 所有元素模 $x$ 同余。

**证明**：（必要性）一次操作把 $a_i$ 换成 $a_i \pm x$，而 $(a_i \pm x) \bmod x = a_i \bmod x$，故每个元素的余数在任意操作序列下不变；若最终全部元素相等，则初始时所有元素余数相同。（充分性）设全部元素 $\equiv r \pmod x$，取目标 $t = r$：每个 $a_i$ 可经 $|a_i - r|/x$ 次同向操作到达 $r$（差是 $x$ 的倍数），故可达。∎

**引理 2**（代价公式）：设所有元素 $\equiv r \pmod x$。目标 $t$ 可达 $\iff$ $t \equiv r \pmod x$，且此时把 $a_i$ 变为 $t$ 的最少操作次数恰为 $|a_i - t|/x$。

**证明**：$k$ 次操作后 $a_i$ 的取值为 $a_i + qx$（整数 $q$，$|q| \le k$）。要变为 $t$，需 $t - a_i = qx$：若 $t \not\equiv r \pmod x$，即 $t - a_i \not\equiv 0 \pmod x$，不是 $x$ 的倍数，不可达；若同余，则 $|q| \ge |t - a_i|/x$ 给出操作次数下界，且全部用同向操作（只加或只减）恰以 $|t-a_i|/x$ 次到达，下界可达。∎

**引理 3**（中位数最优）：设 $b_{(1)} \le \cdots \le b_{(N)}$ 为排序后的 $b_i$，则 $f(t') = \sum_i |b_i - t'|$ 在 $t' = b_{(\lfloor N/2 \rfloor + 1)}$（1-indexed）处取得最小值；且 $N$ 为偶数时中间区间 $[b_{(N/2)},\, b_{(N/2+1)}]$ 上 $f$ 恒为该最小值。

**证明**：$f$ 是 $N$ 个凸分段线性函数之和，故凸且分段线性。在非断点处，$t'$ 右移 $\delta$ 的增量为 $\delta \cdot (\#\{b_i \le t'\} - \#\{b_i > t'\})$（左侧项各增 $\delta$、右侧项各减 $\delta$）。设 $j = \#\{b_i \le t'\}$，斜率 $= 2j - N$：$j < N/2$ 时为负（$f$ 下降），$j > N/2$ 时为正（$f$ 上升）。故最小值出现在斜率变号处——$N$ 奇（$N = 2k+1$）时唯一最小点为中位数 $b_{(k+1)}$；$N$ 偶（$N = 2k$）时 $[b_{(k)}, b_{(k+1)}]$ 上斜率为 $0$，$f$ 取常数值即最小值。两种情形下 $b_{(\lfloor N/2 \rfloor + 1)}$（对应 0-indexed 的 $a[N/2]$）均为最小点之一。∎

**定理**：算法返回最小总操作数；返回 $-1$ 当且仅当单值网格不可达。

**证明**：由引理 1，同余检查正确区分可达 / 不可达。可达时，全体可行目标 $t$ 与整数 $t'$（$b_i = (a_i - r)/x$、$t' = (t - r)/x$）一一对应；由引理 2，对目标 $t$ 的总操作数为 $\sum_i |b_i - t'|$。映射 $a \mapsto b$ 严格保序，故排序后 $b_{(j)} = (a_{(j)} - r)/x$，即 $b$ 的中位数是 $a[N/2]$ 的像；由引理 3，取该点使 $\sum_i |b_i - t'|$ 最小。又所有 $|a_i - \text{med}|$ 均为 $x$ 的倍数（算法细节 6），$\sum_i |b_i - t'| = \big(\sum_i |a_i - \text{med}|\big)/x$ 为整数，算法返回值即最小操作数。∎

## 6. 复杂度分析

- **时间复杂度**：$O(N \log N)$，其中 $N = m \cdot n \le 10^5$——展平 $O(N)$、同余检查 $O(N)$、排序 $O(N \log N)$ 主导、累加 $O(N)$。换计数排序可降到 $O(N + V)$（$V \le 10^4$），`nth_element` 平均 $O(N)$。
- **空间复杂度**：$O(N)$，即展平出的一维数组（计数排序另需 $O(V)$ 的桶）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minOperations(vector<vector<int>>& grid, int x) {
        vector<int> a;
        for (auto& row : grid)
            for (int v : row) a.push_back(v);      // 展平：位置无关

        int r = a[0] % x;
        for (int v : a)
            if (v % x != r) return -1;             // 引理 1：余数不变量

        nth_element(a.begin(), a.begin() + a.size() / 2, a.end());
        int med = a[a.size() / 2];                 // 0-indexed 中位数（引理 3）

        long long sum = 0;
        for (int v : a) sum += abs(v - med);       // long long：上界 ~1e9
        return sum / x;                            // 差值都是 x 的倍数，整除安全
    }
};
```

### Python

```python
class Solution:
    def minOperations(self, grid: List[List[int]], x: int) -> int:
        a = [v for row in grid for v in row]       # 展平
        r = a[0] % x
        if any(v % x != r for v in a):             # 同余检查，不可行止损
            return -1
        a.sort()
        med = a[len(a) // 2]                       # 0-indexed 中位数
        return sum(abs(v - med) for v in a) // x   # 距离和 ÷ x
```

> ⚠️ 两份代码都把「÷ x」放在最后一步——先算 $\sum|a_i - \text{med}|$ 再整除；因为每项差都是 $x$ 的倍数，两种顺序等价，但「最后统一除」最不易漏。Python 的 `//` 对非负数与 C++ 整除一致。

## 8. 边界情况与易错点

1. **-1 判定要查所有元素**：只看 $\max - \min$ 是否被 $x$ 整除不够——反例 $[1,2,3]$、$x=2$：$3-1=2$ 可整除，但余数 $1,0,1$ 不全同，正确答案 $-1$。
2. **平均值陷阱**：最小化**绝对偏差和**的是中位数。$[1,1,1,1,100]$（$x=1$）：中位数 1 → 99 步；取均值邻近的 21 → 159 步。均值只在最小化**平方和**时才正确。
3. **偶数个元素**：中间区间任一点皆可，`a[N/2]` 与 `a[N/2−1]` 都对——别在此纠结写错下标。
4. **忘记 ÷ x**：把 $\sum |a_i - \text{med}|$ 直接当答案返回，示例 1 会输出 8 而非 4。
5. **溢出**：距离和上界 $\approx 10^9$，贴着 `int` 上限，用 `long long` 稳妥（算法细节 5）。
6. **C++ 负余数**：本题全正值无坑；含负数的变体中 `%` 可能出负，先 `(v % x + x) % x` 归一。
7. **单元素网格**：$N = 1$ 时 med 即唯一元素，答案 0，代码自然处理无需特判。
8. **x = 1**：余数全 0，恒可行，退化为 LeetCode 462 原题——可当对拍样例。
