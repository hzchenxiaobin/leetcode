# LeetCode 编码最短长度的字符串 题解

## 1. 题目概述

- **标题 / 题号**：编码最短长度的字符串（#471，hard）
- **链接**：https://leetcode.cn/problems/encode-string-with-shortest-length/
- **来源**：LeetCode 第 12 场周赛 Q4
- **难度**：困难
- **标签**：字符串、动态规划

**题意**：给定非空字符串 $s$，按规则 $k[\text{encoded\_string}]$ 编码——方括号里的内容恰好重复 $k$ 次，$k$ 为正整数且括号内非空、无多余空格。要求返回**编码后长度最短**的字符串；若编码不能让字符串变短，就返回原串。长度相同的最优解有多个时，返回任意一个即可。

**约束**：

- $1 \le \lvert s \rvert \le 160$
- $s$ 仅由小写英文字母组成
- 可以嵌套编码，例如 $2[2[abbb]c]$
- 编码不变短时不得编码；多解任意

## 2. 示例

**示例 1**

```text
输入：s = "aaa"
输出："aaa"
解释：任何编码（如 "3[a]"）长度都是 4，比原串长，所以不编码。
```

**示例 2**

```text
输入：s = "aabcaabcd"
输出："2[aabc]d"
解释："aabc" 连续出现两次，编码成 "2[aabc]"；尾部剩下的 "d" 无法并入周期。
```

**示例 3**

```text
输入：s = "abbbabbbcabbbabbbc"
输出："2[2[abbb]c]"
解释："abbbabbbc" 出现两次，它自身又能编码成 "2[abbb]c"，
      于是整体是 "2[2[abbb]c]"，长度 11（原串 18）。
```

## 3. 解题思路

### 3.1 暴力思路

把 $s$ 的所有编码枚举出来再取最短：在每个位置决定「保留字符」「开一段 $k[\cdot]$」「结束当前括号」，同时枚举 $k$ 与周期长度。合法编码的数量随 $n$ 指数增长，$n = 160$ 时完全不可行；即使只枚举「所有切分 × 所有周期」也是 $O(2^n)$ 量级。

另一个常见误区是**贪心**：对整串求最小周期，能压就压。它连示例 2 都过不了——整串不是周期串，但「前半段周期 + 尾部单字符」的拼接才是最优。正确做法是把「压缩」「拼接」都作为**同一层候选**交给 DP 选择。

### 3.2 核心观察：区间 DP 的三种转移

![区间 DP 的三种编码方式](images/wc12_q4_interval_dp_concept.svg)

**关键观察**：任意合法编码（无论嵌套多深）在区间 $[i, j)$ 这一层只有三种可能形态：

1. **原样输出** $s[i..j)$，长度 $j-i$；
2. **拆成两段**：在某个 $k$（$i < k < j$）处切开，左段、右段各自是一个合法编码，长度相加；
3. **整体压缩**：若区间长度为 $\text{len}$、存在周期长度 $L$ 使 $\text{len} \bmod L = 0$ 且 $s[i..j)$ 恰好是 $w = s[i..i+L)$ 重复 $t = \text{len}/L$ 次，则可以用 $t[E]$，其中 $E$ 是 $w$ 的一个合法编码。

于是定义

$$dp[i][j] = s[i..j) \text{ 的最短编码},\quad 0 \le i < j \le n$$

三种候选取长度最小者：

$$dp[i][j] = \min\Bigl\{\, s[i..j),\ \min_{i<k<j}\bigl(dp[i][k] + dp[k][j]\bigr),\ t\bigl[\,dp[i][i+L]\,\bigr] \,\Bigr\}$$

**为什么内层写 $dp[i][i+L]$ 而不是原串 $w$？** 因为 $w$ 自己也可能可以压缩：示例 3 的 $w = \text{"abbbabbbc"}$ 编码成 $2[abbb]c$（长度 8），外层才能得到长度 11；若外层直接包原串，得到的是 $2[\text{abbbabbbc}]$（长度 12）。这一处正是本题最容易写错的地方。

### 3.3 算法流程 / 状态转移

![按长度递增填表的算法流程](images/wc12_q4_dp_flow.svg)

```text
for len = 1 .. n:                       # 区间长度递增，保证子区间已算好
    for i = 0 .. n - len:
        j = i + len
        best = s[i..j]                  # 方案①：不编码
        for k = i+1 .. j-1:             # 方案②：拼接
            best = min(best, dp[i][k] + dp[k][j], by length)
        for L = 1 .. len/2:             # 方案③：周期压缩
            if len % L != 0: continue
            if s[i..j] is w^t where w = s[i..i+L]:
                cand = to_string(t) + "[" + dp[i][i+L] + "]"
                best = min(best, cand, by length)
        dp[i][j] = best
return dp[0][n]
```

周期判定可以只比较 $s[i+t]$ 与 $s[i + t \bmod L]$（$t = L \dots \text{len}-1$），代价 $O(\text{len})$；也可以直接判断 $s[i..j-L) == s[i+L..j)$。

### 3.4 示例演算

![示例 "abbbabbbcabbbabbbc" 的区间 DP 演算](images/wc12_q4_walkthrough.svg)

以 $s = \text{"abbbabbbcabbbabbbc"}$（$n = 18$）为例，按长度从小到大：

| 区间 | 子串结构 | 最优编码 | 长度 |
|------|----------|----------|------|
| $[0,4)$ | "abbb" | "abbb"（无周期） | 4 |
| $[0,8)$ | "abbb" × 2 | "2[abbb]"（$7<8$） | 7 |
| $[0,9)$ | "2[abbb]" + "c" | "2[abbb]c" | 8 |
| $[9,18)$ | 同前半 | "2[abbb]c" | 8 |
| $[0,18)$ | 两半相同，$t=2$ | "2[2[abbb]c]" | 11 |

注意 $k=9$ 的拼接候选是 $8+8=16$，比整段压缩得到的 11 差；而整段压缩之所以能到 11，是因为内层 $[0,9)$ 自己已经压到了 8。

## 4. 算法细节

1. **递推顺序**：外层按区间长度 $\text{len}$ 递增，这样 $dp[i][k]$、$dp[k][j]$（长度更小）与 $dp[i][i+L]$（$L < \text{len}$）都已经算好；无需记忆化递归。
2. **周期枚举范围**：$L$ 只需枚举到 $\lfloor \text{len}/2 \rfloor$ 且必须满足 $\text{len} \bmod L = 0$；$L = \text{len}$ 表示不重复，属于方案①。
3. **长度公式**：压缩候选长度为 $\text{digits}(t) + 2 + \lvert dp[i][i+L] \rvert$，其中 $\text{digits}(t)$ 表示 $t$ 的十进制位数（$t \ge 10$ 时是 2 位），不能用固定 1 位估算。
4. **平手规则**：只有候选**严格更短**时才替换 `best`，于是「编码不变短就不编码」自动满足；例如 `"aaa"` 的压缩候选 `"3[a]"` 长 4，被保留的原串 3 击败。
5. **多解说明**：平手时保留先出现的候选，因此本实现对 `"aaaaaaaaaa"` 输出 `"a9[a]"`（拼接分支先枚举）而不是官方示例写出的 `"10[a]"`；两者长度都是 5、都能解码回原串，均为合法答案。
6. **内层必须用 DP 值**：`dp[i][i+L]` 可能已经是嵌套编码（如 `2[abbb]c`），这正是示例 3 能再省 1 个字符的原因；写成 `s[i:i+L]` 会 WA。
7. **字符串操作开销**：每个候选都要做一次拼接；$n \le 160$、状态数约 $1.3 \times 10^4$，Python 下实测最坏约 0.3 s，完全够用，不必为常数优化牺牲可读性。
8. **非法编码的排除**：括号内不能为空、不能有多余空格，所以候选一律形如 $t[E]$ 且 $E$ 非空、$t \ge 2$；不要生成 $1[E]$。

## 5. 正确性证明

**引理 1（结构分解）**：$s[i..j)$ 的任意合法编码 $e$ 必属于以下三类之一：① $e = s[i..j)$；② $e = e_1 e_2$，其中 $e_1, e_2$ 分别是某个切点 $k$ 两侧区间的合法编码；③ $e = t[E]$，$s[i..j) = w^t$，$w = s[i..i+L)$，$L = (j-i)/t$，且 $E$ 是 $w$ 的合法编码。

**证明**：对编码的括号嵌套深度归纳。若 $e$ 不含任何方括号，它展开后就是 $s[i..j)$，属①。否则把 $e$ 在**最外层**按「方括号块 / 连续普通字符」切分成若干原子：普通字符原子展开成单个字母，方括号原子展开成某个串的 $t$ 次重复。若只有 1 个原子且是方括号原子，则整体形如 $t[E]$，$E$ 展开成 $w$、$s[i..j) = w^t$，属③（$t=1$ 不合规，故 $t \ge 2$）。若原子数 $\ge 2$，在任意两个原子之间切开即得②，且 $e_1, e_2$ 仍是合法编码。∎

**引理 2（拼接最优）**：若某最优编码的顶层可拆为两侧编码的拼接，则两侧各自取最短编码后总长度不增。

**证明**：拼接后总长度为 $\lvert e_1 \rvert + \lvert e_2 \rvert$，两侧独立；用 $\lvert dp\rvert$ 替换后每一项都不增，故总长度不增，且替换后的串仍然解码成原来的两段，合法性保持。∎

**引理 3（内层最优）**：对 $e = t[E]$，把 $E$ 换成 $w$ 的最短编码 $dp[i][i+L]$，长度不增且仍解码为 $s[i..j)$。

**证明**：$t[E]$ 的长度是 $\text{digits}(t) + 2 + \lvert E \rvert$，对 $\lvert E \rvert$ 单调递增；$E$ 展开必为 $w$，由 $dp[i][i+L]$ 的定义 $\lvert dp[i][i+L] \rvert \le \lvert E \rvert$。替换后 $t\bigl[dp[i][i+L]\bigr]$ 展开为 $w^t = s[i..j)$。∎

**定理**：算法返回的 $dp[0][n]$ 是 $s$ 的最短合法编码；当没有更短的编码时它等于 $s$ 本身。

**证明**：对区间长度归纳证明 $dp[i][j]$ 是 $s[i..j)$ 的最短合法编码。基础情形 $\text{len}=1$：只有原串候选，正确。归纳步：设所有更短区间已成立，任取 $s[i..j)$ 的一个最优编码 $e$。由引理 1，$e$ 属于三类：若为①，候选包含 $s[i..j)$；若为②，由引理 2 不妨设两段都是最短编码，候选 $dp[i][k] + dp[k][j]$ 长度不超过 $\lvert e \rvert$；若为③，由引理 3 不妨设内层是最短编码，候选 $t[dp[i][i+L]]$ 长度不超过 $\lvert e \rvert$。三类候选都被枚举，故 $dp[i][j]$ 长度不超过最优值；又每个候选本身都是合法编码，故恰为最优。最后，$dp$ 只在候选严格更短时替换初值 $s[i..j)$，所以若不存在更短编码，$dp[0][n] = s$，满足题意。∎

## 6. 复杂度分析

- **时间**：共 $O(n^2)$ 个区间；每个区间枚举 $O(n)$ 个切点，并对每个能整除 $\text{len}$ 的周期长度做一次 $O(\text{len})$ 校验（$\text{len} \le 160$ 时约数个数至多 15，可视作常数级），故结构上约 $O(n^3)$。若把候选字符串拼接/比较的字符开销也计入，上界为 $O(n^4)$；$n \le 160$ 时远低于该上界，实测 Python 最坏约 0.3 s、C++ 在毫秒级。
- **空间**：$O(n^3)$ 字符规模——DP 表有 $O(n^2)$ 个字符串，每个长度不超过区间长 $O(n)$；另外每个候选的临时串 $O(n)$。若只记录长度、最后回溯重建，可压到 $O(n^2)$ 个整数。

## 7. 参考代码

### C++

```cpp
#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    string encode(string s) {
        int n = (int)s.size();
        vector<vector<string>> dp(n + 1, vector<string>(n + 1));
        for (int len = 1; len <= n; ++len) {              // 区间长度递增
            for (int i = 0; i + len <= n; ++i) {
                int j = i + len;
                string best = s.substr(i, len);           // 方案①：不编码
                for (int k = i + 1; k < j; ++k) {         // 方案②：拼接
                    const string cand = dp[i][k] + dp[k][j];
                    if (cand.size() < best.size()) best = cand;
                }
                for (int L = 1; 2 * L <= len; ++L) {      // 方案③：周期压缩
                    if (len % L) continue;
                    bool ok = true;
                    for (int t = L; t < len && ok; ++t)
                        if (s[i + t] != s[i + t % L]) ok = false;
                    if (!ok) continue;
                    string cand = to_string(len / L) + "[" + dp[i][i + L] + "]";
                    if (cand.size() < best.size()) best = cand;
                }
                dp[i][j] = best;
            }
        }
        return dp[0][n];
    }
};
```

### Python

```python
class Solution:
    def encode(self, s: str) -> str:
        n = len(s)
        dp = [[""] * (n + 1) for _ in range(n + 1)]      # dp[i][j] ↔ s[i:j]
        for length in range(1, n + 1):
            for i in range(n - length + 1):
                j = i + length
                best = s[i:j]                            # 方案①：不编码
                for k in range(i + 1, j):                # 方案②：拼接
                    cand = dp[i][k] + dp[k][j]
                    if len(cand) < len(best):
                        best = cand
                for unit in range(1, length // 2 + 1):   # 方案③：周期压缩
                    if length % unit:
                        continue
                    if all(s[i + t] == s[i + t % unit] for t in range(unit, length)):
                        cand = str(length // unit) + "[" + dp[i][i + unit] + "]"
                        if len(cand) < len(best):
                            best = cand
                dp[i][j] = best
        return dp[0][n]
```

## 8. 边界情况与易错点

1. **长度 1 或全无周期**：如 `"a"`、`"abcd"`，任何 $k[\cdot]$ 都更长，必须原样返回；判断依据是「严格变短才替换」。
2. **不能编码的临界**：`"aaa"` 压缩成 `"3[a]"` 反而从 3 变 4，官方示例明确要求此时不编码；不要用 $\le$ 代替 $<$。
3. **多解不唯一**：`"aaaaaaaaaa"` 的最短编码有 `"10[a]"`、`"a9[a]"`、`"9[a]a"` 等多种，长度均为 5；本题接受任意最短解，本地对拍应比较**长度**与「能否解码回原串」，而不是字符串相等。
4. **周期必须整除长度**：`"abababa"`（长度 7）对 $L=2$ 也能通过逐字符周期校验，但 $7 \bmod 2 = 1$；漏掉整除判断会生成 `"3[ab]"`，它解码成 `"ababab"`，比原串少一个字符。
5. **内层写成原串**：`"2[" + s[i:i+unit] + "]"` 在示例 3 上得到 12 而不是 11，是本题最高频 WA 点。
6. **只枚举一个切点**：例如固定从中间切，会漏掉 `"aabcaabcd"`（需要在 8 处切开）这类答案。
7. **位数错误**：$t \ge 10$ 时只给 1 位会低估/高估长度；统一用 `to_string(t).size()` / `len(str(t))`。
8. **空括号或 $1[E]$**：题目要求 $k$ 为正整数、括号内非空且无多余空格；DP 里压缩分支从 $t \ge 2$ 开始，不会产生非法形式。
