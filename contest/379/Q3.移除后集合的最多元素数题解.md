# LeetCode 移除后集合的最多元素数 题解

## 1. 题目概述

- **标题 / 题号**：移除后集合的最多元素数（#3002，medium）
- **链接**：https://leetcode.cn/problems/maximum-size-of-a-set-after-removals/
- **来源**：LeetCode 第 379 场周赛 Q3
- **难度**：中等
- **标签**：贪心、数组、哈希表

**题意**：给定两个长度均为偶数 $n$ 的数组 $\text{nums1}$、$\text{nums2}$。必须从 $\text{nums1}$ 中**恰好**移除 $n/2$ 个元素、从 $\text{nums2}$ 中**恰好**移除 $n/2$ 个元素，然后把两个数组剩下的元素全部插入集合 $s$（集合自动去重）。返回 $|s|$ 可能的最大值。

**约束**：

- $n = \text{nums1.length} = \text{nums2.length}$，$1 \le n \le 2 \times 10^4$，$n$ 为偶数
- $1 \le \text{nums1}[i], \text{nums2}[i] \le 10^9$

> 💡 等价说法：每个数组各自保留**恰好** $n/2$ 个元素，最大化两侧保留元素合起来的不同值个数。$|s|$ 只与「哪些值至少留下一份拷贝」有关，与留几份无关——这是整道题的破题点。

## 2. 示例

**示例 1**

```text

输出：2
解释：各移除两个 1 后 nums1 = [2,2]、nums2 = [1,1]，s = {1,2}。
```

**示例 2**

```text
输入：nums1 = [1,2,3,4,5,6], nums2 = [2,3,2,3,2,3]

     s = {1,2,3,4,5}。独占值 1,4,5,6 共 4 个，但 nums1 名额只有 3 个，6 必须舍弃。
```

**示例 3**

```text
输入：nums1 = [1,1,2,2,3,3], nums2 = [4,4,5,5,6,6]
输出：6
解释：两数组无公共值，各保留 3 个独占值 {1,2,3} 与 {4,5,6}，s 恰有 6 个元素。
```

```text
输出：4
解释：每侧只留 2 个：nums1 保 {1,2}、nums2 保 {3,4}，s = {1,2,3,4}。
     名额虽被砍半，公共值可以在两侧间自由拆分，4 个值一个不丢。
```

## 3. 解题思路

### 3.1 暴力思路

从每个数组的 $n$ 个位置中各选 $n/2$ 个保留，组合数 $\binom{n}{n/2}^2$ 在 $n = 2 \times 10^4$ 时超过 $10^{6000}$，纯枚举毫无希望。

退一步换「值」的视角：记 $A = \mathrm{set}(\text{nums1})$、$B = \mathrm{set}(\text{nums2})$，$s$ 的大小只取决于 $A \cup B$ 中**哪些不同值**被保留，对每个值决策「由 nums1 保留 / 由 nums2 保留 / 不保留」，仍是 $3^{|A \cup B|}$ 的指数级搜索。

真正压垮指数的是两个结构性事实：

1. **两侧删除互相独立**：nums1 删哪些、nums2 删哪些互不干扰，可以分别构造再合并；
2. **可行性只依赖计数**：想让 nums1 剩余元素覆盖某个目标值集 $K \subseteq A$，当且仅当 $|K| \le n/2$——保留 $K$ 中每个值一份拷贝，其余槽位用重复元素凑数即可（见 §5 引理 1）。

于是「删哪些元素」的模拟彻底消失，问题坍缩成**纯计数 + 名额分配**。

### 3.2 核心观察：值域三分与名额分配

![按出现位置分流：独占值与公共值](images/max_set_size_classification.svg)

把 $A \cup B$ 的值按出现位置三分：

- **独占值₁**（$o_1$ 个）：只在 $A$ 中，$o_1 = |A \setminus B|$；
- **独占值₂**（$o_2$ 个）：只在 $B$ 中，$o_2 = |B \setminus A|$；
- **公共值**（$c$ 个）：两边都有，$c = |A \cap B|$。

配三条观察：

**观察一（名额语义）**：每个数组恰好剩 $n/2$ 个元素，所以每侧**至多** $n/2$ 个不同值进入 $s$；同一值留一份拷贝就够，多留只浪费名额。

**观察二（独占值无处借力）**：独占值₁ 只存在于 nums1，nums2 的名额再多也救不了它。因此 nums1 的 $n/2$ 个名额中，独占值₁ 至多占 $k_1 = \min(o_1, n/2)$ 个；同理 $k_2 = \min(o_2, n/2)$。

**观察三（独占优先的交换论证）**：公共值无论从哪边保留都只给 $|s|$ 贡献 1；独占值₁ 一旦因名额挤占被舍弃就**永远**损失 1。若某方案把 nums1 的一个名额花在公共值 $x$ 上、却舍弃了某个独占值₁ $u$，把那份名额换成 $u$：$x$ 若另有 nums2 兜底，$|s|$ 还 +1，否则不变——**换不亏**。故总存在「独占优先」的最优方案。

剩下的自由度全在公共值：nums1、nums2 分别剩 $r_1 = n/2 - k_1$、$r_2 = n/2 - k_2$ 个空名额，公共值两边都有拷贝、塞哪边都行，于是还能再吸收 $\min(c,\ r_1 + r_2)$ 个：

$$\mathrm{ans} = k_1 + k_2 + \min(c,\ r_1 + r_2)$$

### 3.3 算法流程

![名额分配：独占优先，空名额吸收公共值](images/max_set_size_budget_split.svg)

```text
1. s1 = set(nums1), s2 = set(nums2)                # 去重
2. c  = |s1 ∩ s2|                                  # 公共值个数
   o1 = |s1| − c,  o2 = |s2| − c                   # 两侧独占值个数
3. half = n / 2
   k1 = min(o1, half),  k2 = min(o2, half)         # 名额先保独占
   r1 = half − k1,      r2 = half − k2             # 各自剩余名额
4. 返回 k1 + k2 + min(c, r1 + r2)                  # 空名额吸收公共值
```

全程只做**集合计数**，完全不模拟「删哪 $n/2$ 个元素」。

### 3.4 示例演算

![示例 2 演算走查](images/max_set_size_walkthrough.svg)

以示例 2（$n = 6$，每侧名额 3）走全流程：

| 步骤 | 计算 | 结果 |
|------|------|------|
| 去重 | $A = \{1,2,3,4,5,6\}$，$B = \{2,3\}$ | 6 个值 / 2 个值 |
| 三分 | 独占₁ $= \{1,4,5,6\}$，公共 $= \{2,3\}$，独占₂ $= \varnothing$ | $o_1=4,\ c=2,\ o_2=0$ |
| 独占优先 | $k_1 = \min(4,3) = 3$（舍 6），$k_2 = 0$ | $r_1 = 0,\ r_2 = 3$ |
| 补公共值 | $\min(2,\ 0+3) = 2$：值 2、3 塞进 nums2 的空名额 | 再添 2 个 |
| 答案 | $3 + 0 + 2$ | **5** ✓ |

回验其余示例：示例 1 中 $o_1 = 1$（值 2）、$c = 1$（值 1）、$o_2 = 0$ → $1 + 0 + \min(1, 1+2) = 2$ ✓；示例 3 中 $o_1 = o_2 = 3$、$c = 0$ → $3 + 3 + 0 = 6$ ✓；示例 4 中 $o_1 = o_2 = 0$、$c = 4$ → $0 + 0 + \min(4, 2+2) = 4$ ✓。

## 4. 算法细节

1. **计数推导顺序**：先遍历 $s_1$ 查 $s_2$ 得公共值个数 $c$，再由 $o_1 = |s_1| - c$、$o_2 = |s_2| - c$ 得两侧独占数——一次遍历出全部三个数，不必额外构造差集。
2. **重复元素的唯一作用**：公式中不出现任何「出现次数」——重复元素只是保证「每个想留的值都能留下一份、删掉的恰好是 $n/2$ 个」的可行性缓冲（引理 1）。理解这点就不会误入「按元素做 DP」的歧途。
3. **公共值塞哪边无所谓**：公共值在两个数组里都至少有一份拷贝，$t = \min(c, r_1 + r_2)$ 个公共值任意划分成「nums1 保 $t_1 = \min(t, r_1)$ 个 + nums2 保 $t - t_1$ 个」都能落地，不存在「值只能从指定一边保留」的障碍。
4. **非负性免检**：$k_1 = \min(o_1, n/2) \le n/2$ 保证 $r_1 \ge 0$，代码里无需再写 $\max(0, \cdot)$。
5. **答案天然不超过 $n$**：$k_1 + k_2 \le n$ 且 $\min(c, r_1 + r_2) \le r_1 + r_2 = n - k_1 - k_2$，无需再套一层 $\min(n, \cdot)$。

## 5. 正确性证明

**引理 1**（名额可达性）：设 $A = \mathrm{set}(\text{nums1})$。对任意 $K \subseteq A$ 且 $|K| \le n/2$，存在合法的删除方案，使 nums1 剩余元素的不同值集合包含 $K$（对 nums2 同理）。

**证明**：保留 $K$ 中每个值各一份拷贝（$|K| \le n/2$ 份），再任取 $n/2 - |K|$ 个其他元素凑满「保留 $n/2$ 个」（元素总数 $n \ge n/2$，总是够取）；删除其余恰好 $n/2$ 个元素。如此 nums1 剩余元素的不同值集合 $\supseteq K$。∎

**引理 2**（逐项上界）：任一合法方案中，设 $s$ 含独占值₁ 共 $A'$ 个、独占值₂ 共 $B'$ 个、公共值共 $C'$ 个，则：

（1）$A' \le k_1 = \min(o_1, n/2)$，$B' \le k_2 = \min(o_2, n/2)$；

（2）$C' \le \min(c,\ n - A' - B')$。

**证明**：（1）$s$ 中的独占值₁ 只能来自 nums1 的剩余元素，而 nums1 恰好剩 $n/2$ 个元素、不同值至多 $n/2$ 个，故 $A' \le n/2$；独占值₁ 总共只有 $o_1$ 个，故 $A' \le o_1$。$B'$ 同理。

（2）公共值总共 $c$ 个，显然 $C' \le c$。再把 $s$ 中每个公共值记到「保留了它至少一份拷贝的那一边」（两边都保留时任记一边）：nums1 剩余的不同值至多 $n/2$ 个，其中独占值₁ 已占 $A'$ 个，故记在 nums1 名下的公共值至多 $n/2 - A'$ 个；同理记在 nums2 名下的至多 $n/2 - B'$ 个。相加得 $C' \le n - A' - B'$。∎

**定理**：$\mathrm{ans} = k_1 + k_2 + \min(c,\ r_1 + r_2)$，其中 $k_1 = \min(o_1, n/2)$、$k_2 = \min(o_2, n/2)$、$r_1 = n/2 - k_1$、$r_2 = n/2 - k_2$。

**证明**：

**上界**。由引理 2，

$$|s| = A' + B' + C' \le A' + B' + \min(c,\ n - A' - B') =: g(A', B').$$

固定 $B'$：当 $c \le n - A' - B'$ 时 $g = A' + B' + c$，随 $A'$ 每 +1 严格 +1；当 $c > n - A' - B'$ 时 $g = n$，与 $A'$ 无关。故 $g$ 关于 $A'$（同理关于 $B'$）单调不减。结合（1）的 $A' \le k_1$、$B' \le k_2$：

$$|s| \le g(k_1, k_2) = k_1 + k_2 + \min(c,\ n - k_1 - k_2) = k_1 + k_2 + \min(c,\ r_1 + r_2).$$

**可达性**。令 $t = \min(c, r_1 + r_2)$、$t_1 = \min(t, r_1)$、$t_2 = t - t_1$，由 $t \le r_1 + r_2$ 得 $t_2 = \max(0, t - r_1) \le r_2$。构造

$$K_1 = (\text{任选 } k_1 \text{ 个独占值₁}) \cup (\text{公共值中任选 } t_1 \text{ 个}), \qquad K_2 = (\text{任选 } k_2 \text{ 个独占值₂}) \cup (\text{公共值中任选 } t_2 \text{ 个})$$

则 $|K_1| = k_1 + t_1 \le k_1 + r_1 = n/2$，$|K_2| = k_2 + t_2 \le n/2$，且 $K_1 \subseteq A$、$K_2 \subseteq B$。由引理 1，两侧可分别构造删除方案，使实际保留的不同值集合分别包含 $K_1$、$K_2$，故 $|s| \ge |K_1 \cup K_2| = k_1 + k_2 + t$（三块互不相交）。与上界吻合，等号成立。∎

> 💡 交换论证（§3.2 观察三）给出「为什么贪心不亏」的直觉；上面的引理–定理链才是完整闭环：上界封顶 + 构造落地，二者严丝合缝。

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。建两个哈希集合各一次遍历，再遍历 $s_1$ 一次查 $s_2$ 计公共值，每步均摊 $O(1)$。
- **空间复杂度**：$O(n)$。两个哈希集合至多各存 $n$ 个值。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int maximumSetSize(vector<int>& nums1, vector<int>& nums2) {
        int half = nums1.size() / 2;
        unordered_set<int> s1(nums1.begin(), nums1.end());
        unordered_set<int> s2(nums2.begin(), nums2.end());

        int c = 0;                                   // 公共值个数
        for (int x : s1)
            if (s2.count(x)) ++c;
        int o1 = (int)s1.size() - c;                 // 仅 nums1 有的值
        int o2 = (int)s2.size() - c;                 // 仅 nums2 有的值

        int k1 = min(o1, half), k2 = min(o2, half);  // 名额先保独占
        int r1 = half - k1,     r2 = half - k2;      // 各自剩余名额
        return k1 + k2 + min(c, r1 + r2);            // 空名额吸收公共值
    }
};
```

### Python

```python
class Solution:
    def maximumSetSize(self, nums1: List[int], nums2: List[int]) -> int:
        half = len(nums1) // 2
        s1, s2 = set(nums1), set(nums2)
        c = len(s1 & s2)                        # 公共值个数
        o1, o2 = len(s1) - c, len(s2) - c       # 两侧独占值个数

        k1, k2 = min(o1, half), min(o2, half)   # 名额先保独占
        r1, r2 = half - k1, half - k2           # 各自剩余名额
        return k1 + k2 + min(c, r1 + r2)        # 空名额吸收公共值
```

> 💡 语言细节：Python 的 `s1 & s2` 一步求交集；C++ 标准库没有集合代数运算，遍历 `s1` 查 `s2` 计数即可。两侧公式完全对称，写成一行也不易错。

## 8. 边界情况与易错点

1. **配额是「各删 $n/2$」不是「共删 $n/2$」**：两侧删除数不能互相转账。若误按合计配额计算，示例 2 会得出 6（错，正确答案 5）。
2. **直觉公式 $\min(n, |A \cup B|)$ 是错的**：示例 2 中 $|A \cup B| = 6 = n$ 但答案为 5——独占值₁ 有 4 个而 nums1 名额只有 3 个，名额与值必须在**本侧**内匹配。
3. **两个 clamp 别丢**：$k_1 = \min(o_1, n/2)$ 砍掉超出名额的独占值；第三项 $\min(c, \cdot)$ 防止公共值超额计入。
4. **公共值从两侧各留一份不会多算**：$s$ 只记一次，贪心公式自动处理，但手工模拟删除时容易把 2、3 这类值重复数。
5. **不必担心「想留的值被迫删光」**：引理 1 保证 $|K| \le n/2$ 时总能各留一份；空出来的名额用重复元素填，不产生新值也不破坏合法性。
6. **值域 $10^9$**：用哈希集合，不要想用数组下标计数。
7. **$n$ 为偶数**是题面保证，$n/2$ 无需取整特判；$n = 2$ 时每侧只留 1 个，公式同样成立。
8. **不必排序**：排序 + 双指针求交是 $O(n \log n)$，能过但多余，哈希一遍即可。
