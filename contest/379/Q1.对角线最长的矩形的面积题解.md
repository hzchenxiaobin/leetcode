# LeetCode 对角线最长的矩形的面积 题解

## 1. 题目概述

- **标题 / 题号**：对角线最长的矩形的面积（#3000，easy）
- **链接**：https://leetcode.cn/problems/maximum-area-of-longest-diagonal-rectangle/
- **来源**：LeetCode 第 379 场周赛 Q1
- **难度**：简单
- **标签**：数组、枚举

**题意**：给定下标从 0 开始的二维整数数组 `dimensions`，第 $i$ 个矩形的长为 $dimensions[i][0]$、宽为 $dimensions[i][1]$。返回**对角线最长**的矩形的**面积**；若多个矩形对角线长度相同，返回其中**面积最大**者的面积。

**约束**：

- $1 \le \text{dimensions.length} \le 100$
- $dimensions[i].length = 2$
- $1 \le dimensions[i][0], dimensions[i][1] \le 100$

## 2. 示例

**示例 1**

```text
输入：dimensions = [[9,3],[8,6]]
输出：48
解释：矩形 [9,3] 的对角线 = sqrt(81+9) = sqrt(90) ≈ 9.487；
     矩形 [8,6] 的对角线 = sqrt(64+36) = 10。
     对角线最长的是 [8,6]，返回面积 8 × 6 = 48。
```

**示例 2**

```text
输入：dimensions = [[3,4],[4,3]]
输出：12
解释：两个矩形的对角线长度相同（sqrt(25) = 5），返回面积最大者 3 × 4 = 12。
```

**示例 3**（补充：对角线更长但面积更小）

```text
输入：dimensions = [[9,9],[13,2]]
输出：26
解释：[9,9] 的 d² = 162、面积 81；[13,2] 的 d² = 173、面积 26。
     [13,2] 对角线更长，尽管面积更小，答案仍是 26——更新条件必须是纯字典序。
```

## 3. 解题思路

### 3.1 暴力思路

对每个矩形计算对角线长度 $d = \sqrt{l^2 + w^2}$，再找 $d$ 最大、平局比 $l \times w$——这本身就是一趟 $O(n)$ 扫描，$n \le 100$ 怎么写都能过。作为 Q1，真正的分差点只有两处：

1. 比较对角线时**开不开方**——开 `double` 比较是浮点侥幸，比**平方和**才是整数正解；
2. 平局规则怎么**压进一次比较**——写成字典序（主键 + 次键），否则容易漏更新（见示例 3）。

### 3.2 核心观察：$\sqrt{\cdot}$ 单调 ⇒ 比平方和；平局规则 = 字典序

![核心观察：对角线只认 l²+w²，长边、周长都是片面代理](images/wc379_q1_diagonal_compare_concept.svg)

**观察 1（对角线必须整体比较，片面代理会翻车）**：长边更长不代表对角线更长——$9 \times 3$ 的长边 $9$ 大于 $8 \times 6$ 的 $8$，对角线却是 $\sqrt{90} \approx 9.49 < 10$；周长同理，$[3,4]$ 周长 $14$ 大于 $[1,5]$ 的 $12$，对角线却 $5 < \sqrt{26} \approx 5.10$。对角线是 $l^2 + w^2$ 的函数，比较对象只能是对角线本身。

**观察 2（$\sqrt{\cdot}$ 单调，比较不必开方）**：$\sqrt{\cdot}$ 在非负域上严格递增，对非负数 $a, b$ 有 $\sqrt a > \sqrt b \iff a > b$。比较 $\sqrt{l_1^2+w_1^2}$ 与 $\sqrt{l_2^2+w_2^2}$ 等价于直接比较整数 $l_1^2+w_1^2$ 与 $l_2^2+w_2^2$——**单调函数不改变比较结果**，把开方彻底赶出代码，零浮点误差。

**观察 3（平局规则 = 字典序）**：「对角线最长、平局取面积最大」即按二元组 $(d^2, area)$ 取**字典序最大**——主键 $d^2$ 分胜负，次键 $area$ 只在主键打平时登场：

$$\mathrm{ans} = \operatorname{area}\Big(\arg\max_{(l,\,w)} \big(l^2+w^2,\ l \cdot w\big)\Big)$$

> 💡 一句话：**「比谁的对角线长」翻译到整数域就是「比谁的 $l^2+w^2$ 大」，平局接一个面积次键——单趟扫描维护字典序最大的二元组，就是全部代码。**

### 3.3 算法流程

![算法流程：单趟扫描维护字典序最大的 (d², area)](images/wc379_q1_scan_flow.svg)

1. 初始化 `bestD2 = -1`、`bestArea = 0`（哨兵保证首个矩形必然写入）；
2. 对每个矩形 $[l, w]$ 计算 $d^2 = l^2 + w^2$ 与 $area = l \times w$；
3. 若 $d^2 > bestD2$，或 $d^2 = bestD2$ 且 $area > bestArea$（字典序更大），更新二元组；
4. 扫描结束返回 `bestArea`。

> ⚠️ 常见手误是把条件写成 `d2 >= bestD2 && area > bestArea`——「对角线更长但面积更小」（示例 3 的 `[[9,9],[13,2]]`）时会漏更新、错答 81。正确姿势是纯字典序：`d2 > bestD2 || (d2 == bestD2 && area > bestArea)`。

### 3.4 示例演算

![示例演算：两个官方示例的完整执行过程](images/wc379_q1_walkthrough.svg)

**示例 1**（`[[9,3],[8,6]]`）：

| 矩形 | $d^2 = l^2+w^2$ | $area$ | 与 best 比较 | best $(d^2, area)$ |
|------|------------------|--------|--------------|--------------------|
| $[9,3]$ | $81+9=90$ | $27$ | $90 > -1$ → 更新 | $(90, 27)$ |
| $[8,6]$ | $64+36=100$ | $48$ | $100 > 90$ → 更新 | $(100, 48)$ |

主键 $d^2$ 两度分出胜负，平局分支全程未触发，返回 $48$ ✓。

**示例 2**（`[[3,4],[4,3]]`）：

| 矩形 | $d^2 = l^2+w^2$ | $area$ | 与 best 比较 | best $(d^2, area)$ |
|------|------------------|--------|--------------|--------------------|
| $[3,4]$ | $9+16=25$ | $12$ | $25 > -1$ → 更新 | $(25, 12)$ |
| $[4,3]$ | $16+9=25$ | $12$ | $d^2$ 平局，$area$：$12 \not> 12$ → 不更新 | $(25, 12)$ |

第二个矩形触发平局分支但次键不分胜负，best 保持，返回 $12$ ✓。

## 4. 算法细节

1. **哨兵初始化**：$d^2 \ge 1^2 + 1^2 = 2 > -1$，第一个矩形必然写入，省去对首个元素的特判（约束保证 $n \ge 1$，不存在空输入）。
2. **更新条件是纯字典序**：`d2 > bestD2 || (d2 == bestD2 && area > bestArea)`，`||` 短路保证只有平局才看次键。
3. **值域与类型**：$d^2 \le 100^2 + 100^2 = 20000$、$area \le 10^4$，`int` 绰绰有余；推广到 $l, w \le 10^9$ 时 $d^2 \le 2 \times 10^{18}$，平方必须换 `long long`（`int` 域内 `l * l` 已溢出为负）。
4. **Python 元组比较**：元组天然按字典序比较，`(d2, area) > (best_d2, best_area)` 一行表达双条件，也可用 `max` 直接取字典序最大元组。

## 5. 正确性证明

**引理 1**（单调等价）：对非负实数 $a, b$：$\sqrt a > \sqrt b \iff a > b$，且 $\sqrt a = \sqrt b \iff a = b$。

**证明**：$f(x) = \sqrt x$ 在 $[0, \infty)$ 上严格递增：若 $0 \le b < a$，则两边平方得 $b < a$ 的逆否——由 $a > b \ge 0$ 平方保序得 $a^2$ 类似结论；具体地，$\sqrt a > \sqrt b$ 两边平方（均非负，保序）得 $a > b$；反之 $a > b \ge 0$ 时若 $\sqrt a \le \sqrt b$，平方得 $a \le b$，矛盾。相等情形同理：$\sqrt a = \sqrt b$ 平方得 $a = b$；$a = b$ 显然开方相等。∎

**引理 2**（平方和等价）：矩形 $(l_1, w_1)$ 的对角线长于 $(l_2, w_2)$ $\iff$ $l_1^2 + w_1^2 > l_2^2 + w_2^2$；对角线等长 $\iff$ 平方和相等。

**证明**：对角线 $d = \sqrt{l^2 + w^2}$，令 $a = l_1^2 + w_1^2 \ge 0$、$b = l_2^2 + w_2^2 \ge 0$，应用引理 1 于 $\sqrt a$、$\sqrt b$。∎

**定理**：算法返回「对角线最长、平局取面积最大」的矩形的面积。

**证明**：对已扫描矩形个数 $k$ 归纳，不变量为：$(bestD2, bestArea)$ 是前 $k$ 个矩形中字典序最大的 $(d^2, area)$。$k = 0$ 时哨兵 $-1$ 小于一切合法 $d^2$，首个矩形必然更新，$k = 1$ 时不变量成立。设第 $k+1$ 个矩形为 $(d^2, area)$：若其与 $(bestD2, bestArea)$ 的字典序比较为严格更大，条件命中、更新后不变量保持；否则不更新，而前 $k$ 个中的字典序最大者依然冠绝前 $k+1$ 个。由引理 2，主键 $d^2$ 的序即对角线的序，主键打平时次键 $area$ 恰为题目的平局规则，故扫描结束时 `bestArea` 即所求。若字典序最大者并列多个，则它们 $(d^2, area)$ 完全相等、面积必相等，返回值不受并列影响。∎

> 💡 证明的关键一步是把「带平局规则的最值」整理成「字典序的最值」——比较关系变成全序后，「单趟维护 top-1」的归纳不变量就是标准套路，可直接推广到 top-k（维护有序的 $k$ 元列表）。

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。每个矩形常数次乘加与比较；$\Omega(n)$ 也是读取下界——任何未读的矩形都可能是对角线最长者。
- **空间复杂度**：$O(1)$。只维护二元组 $(d^2, area)$ 与循环变量，不随输入规模增长。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int areaOfMaxDiagonal(vector<vector<int>>& dimensions) {
        int bestD2 = -1, bestArea = 0;                          // 哨兵：首个矩形必然写入
        for (auto& d : dimensions) {
            int d2 = d[0] * d[0] + d[1] * d[1];                 // 对角线平方，免开方
            int area = d[0] * d[1];
            if (d2 > bestD2 || (d2 == bestD2 && area > bestArea)) {   // 纯字典序
                bestD2 = d2;
                bestArea = area;
            }
        }
        return bestArea;
    }
};
```

### Python

```python
class Solution:
    def areaOfMaxDiagonal(self, dimensions: List[List[int]]) -> int:
        best_d2, best_area = -1, 0
        for l, w in dimensions:
            d2, area = l * l + w * w, l * w
            if d2 > best_d2 or (d2 == best_d2 and area > best_area):
                best_d2, best_area = d2, area
        return best_area
```

元组天然按字典序比较，可压成一行（展开后就是上面的单趟扫描）：

```python
class Solution:
    def areaOfMaxDiagonal(self, dimensions: List[List[int]]) -> int:
        return max((l * l + w * w, l * w) for l, w in dimensions)[1]
```

## 8. 边界情况与易错点

1. **对角线更长但面积更小必须更新**（示例 3 `[[9,9],[13,2]]`）：条件写成 `d2 >= bestD2 && area > bestArea` 会漏更新、错答 81，这是本题最大的坑。
2. **平局必须显式比面积**（示例 2）：`[3,4]` 与 `[4,3]` 的 $d^2$ 同为 25，「只记第一个出现的」恰好也能过此例纯属巧合——次键不写就是埋雷。
3. **不要开方**：本题小数值下 `double` 比较侥幸能过，但放大即翻车——$d^2 > 2^{53}$ 时 `double` 的 ulp 超过 1，不同的平方和可能舍入成同一个 `double`，平局误判后拿错误的次键分胜负。整数域比较稳定且可推广。
4. **别拿长边或周长代理对角线**：$9 \times 3$ 长边 $9$ 却输给 $8 \times 6$；$[3,4]$ 周长 $14$ 却输给 $[1,5]$ 的 $\sqrt{26} \approx 5.10$。片面对 $d^2$ 的逼近不保序。
5. **单矩形**（$n = 1$）：哨兵 $-1$ 保证直接写入并返回其面积，无需特判。
6. **数值放大时的类型**：$l, w \le 10^9$ 时 `d[0] * d[0]` 在 `int` 域溢出为负，须 `long long`；本题 $d^2 \le 20000$ 无此忧，但写法上要有值域意识。
7. **返回的是面积**：别顺手把 `bestD2` 或下标返回了——题目要的是面积。
