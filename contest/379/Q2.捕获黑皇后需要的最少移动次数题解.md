# LeetCode 捕获黑皇后需要的最少移动次数 题解

## 1. 题目概述

- **标题 / 题号**：捕获黑皇后需要的最少移动次数（#3001，medium）
- **链接**：https://leetcode.cn/problems/minimum-moves-to-capture-the-queen/
- **来源**：LeetCode 第 379 场周赛 Q2
- **难度**：中等
- **标签**：数学、枚举

**题意**：一个下标从 1 开始的 $8 \times 8$ 棋盘上有三枚棋子：白车 $(a,b)$、白象 $(c,d)$、黑皇后 $(e,f)$。只能移动白棋，每步移动一枚——车沿横竖直行任意格、象沿斜线任意格，都**不能跳过其他棋子**（既不能越过己方子，也不能越过皇后）。若车或象能移到皇后所在格即算捕获。皇后不动，求捕获皇后的最少移动次数。

**约束**：

- $1 \le a, b, c, d, e, f \le 8$
- 三枚棋子初始时互不在同一格。

> ⚠️ 答案不可能是 0：捕获的定义是「移到皇后所在格」，开局三子互不同格，至少要走 1 步。示例 1 解释里「起始没有任何棋子攻击皇后 ⇒ 移动次数不可能少于 2」正是这个逻辑——初始攻击到皇后 ⟺ 能 1 步吃到。

## 2. 示例

**示例 1**

```text
输入：a = 1, b = 1, c = 8, d = 8, e = 2, f = 3
输出：2
解释：车 (1,1) → (1,3) → (2,3)，两步吃到黑皇后。
初始时车、象都没有攻击到皇后，所以不可能 1 步完成。
```

**示例 2**

```text
输入：a = 5, b = 3, c = 3, d = 4, e = 5, f = 2
输出：1
解释：车与皇后同列（第 5 列），象不在中间，车一步走到 (5,2) 吃掉皇后；
象与皇后也在同一条斜线上（|3−5| = |4−2| = 2），象一步到 (5,2) 同样可以。
```

**示例 3**（补充：同线但被挡）

```text
输入：a = 4, b = 4, c = 4, d = 5, e = 4, f = 6
输出：2
解释：车与皇后同列，但象 (4,5) 恰好卡在线段中间，车无法直吃；
先把象斜移一步离开第 4 列，车再沿该列吃到皇后，共 2 步。
```

## 3. 解题思路

### 3.1 暴力思路：BFS

把「车的位置 × 象的位置」作为状态（皇后固定不动），状态空间至多 $64 \times 64 = 4096$。每个状态枚举车（至多 14 个可达格）与象（至多 13 个可达格）的滑动终点做转移，从初始局面 BFS，首次把某枚白棋滑到皇后格的层数即答案。

注意**皇后本身也参与遮挡**：白棋滑动时不能越过她（只能停在她格上完成捕获）。状态、转移都是常数级，单次查询约 $10^5$ 量级操作，写对必然通过。

但这是杀鸡用牛刀——本题输入只有 6 个整数、棋盘上只有 3 枚棋子，是**判定题**而非搜索题。真正的考点是：**答案的取值只有 1 和 2**，把「什么时候是 1」判对，剩下的全是 2。

### 3.2 核心观察：答案 $\in \{1, 2\}$

![棋盘与走法规则](images/queen_capture_rules.svg)

**观察一：答案是 1，当且仅当开局就有一枚白棋「攻击」到皇后。**

要在 1 步内捕获，必须把车或象直接移到 $(e,f)$，等价于该棋子与皇后**同线**且**线段中间没有第三枚棋子**：

- **车直吃**：同列 $a = e$ 或同行 $b = f$，且象不在这条线段中间；
- **象直吃**：同斜线 $|c - e| = |d - f|$，且车不在这条斜线段中间。

![一步取胜的两种判定](images/queen_capture_one_move.svg)

**观察二：直吃不成立时，2 步一定够。**

白车不能吃掉挡路的白象（同色不能互吃），所以遮挡只能「绕」或「让」，分两种情况构造：

- **构造 A（车与皇后不对齐，$a \ne e$ 且 $b \ne f$）**：车走 **L 形**两步——先竖移到与皇后同排（或先横移到同列），再一步吃掉。棋盘上只有一枚象可能挡路，而「先竖后横」与「先横后竖」两条 L 形路线的阻挡格集合互不相交，**象至多挡住一条**，另一条必畅通（证明见 §5 引理 2）。
- **构造 B（车与皇后同线，但被象挡住）**：让**象**先动。象沿斜线走一步，列、行坐标**同时改变**，必然离开挡住的那条列/行；象让开后车沿该线一步直吃（证明见 §5 引理 3）。

![两步兜底策略](images/queen_capture_two_moves.svg)

$$\mathrm{ans} = \begin{cases} 1, & \text{车或象直吃皇后（同线且中间无子）} \\ 2, & \text{否则（构造 A / B 必有一条两步路线）} \end{cases}$$

### 3.3 算法流程

坐标约定：$(a,b)$ 视为（列，行），$a = e$ 即同列、$b = f$ 即同行（行列互换不影响任何判定）。

```text
1. 判定「车能否 1 步吃后」：
   ① 若 a == e（同列）：象挡路 ⟺ c == a 且 min(b,f) < d < max(b,f)
   ② 否则若 b == f（同行）：象挡路 ⟺ d == b 且 min(a,e) < c < max(a,e)
   ①② 至多命中一个（否则车在皇后格上）；不挡 → 车可直吃
2. 判定「象能否 1 步吃后」：
   若 |c−e| == |d−f|（同斜线）：
   车挡路 ⟺ 车也在该斜线上（|a−c| == |b−d|）
              且 a 严格介于 c,e 之间、b 严格介于 d,f 之间
   不挡 → 象可直吃
3. 两问任一成立 → 返回 1；否则 → 返回 2
```

### 3.4 示例演算

![示例 1 演算](images/queen_capture_example.svg)

以示例 1 为例：车 $(1,1)$、象 $(8,8)$、皇后 $(2,3)$。

| 判定 | 核对 | 结果 |
|------|------|------|
| 车同列 | $a = 1 \ne e = 2$ | ✗ |
| 车同行 | $b = 1 \ne f = 3$ | ✗ |
| 象同斜线 | $\lvert c-e \rvert = 6 \ne \lvert d-f \rvert = 5$ | ✗ |

三判定全落空 → 无法 1 步 → 走构造 A 的 L 形：车 $(1,1) \to (1,3)$（第 1 列无阻挡），再 $(1,3) \to (2,3)$ 吃掉皇后，共 **2** 步。

示例 2 中车与皇后同列且象不在该列，判定①命中 → **1**；有趣的是象也在同斜线上且车不挡，判定③同样成立——本题车、象**双双**直吃，走哪枚都行。

## 4. 算法细节

1. **坐标只影响表述**：$(a,b)$ 看作（列，行），与插图一致；行列互换、棋盘翻转都是对称变换，不影响任何判定条件。
2. **「严格介于」是遮挡判定的核心**：线段端点恰是棋子自身的格子，挡路必须**严格**落在内部。同列 $a=e$ 时象挡路 ⟺ $c = a$ 且 $\min(b,f) < d < \max(b,f)$；象与车同列但在线段之外（皇后另一侧或车背后）不构成阻挡。
3. **斜线遮挡要三个条件锁定「公共线段」**：过一点有**两条**对角线，$|a-c| = |b-d|$ 只说明车在象的**某一条**对角线上，必须再要求行列都**严格介于**两端点之间，才保证车卡在象与皇后的公共线段内部。反例：象 $(2,2)$、后 $(6,6)$、车 $(3,5)$——行列都介于，但 $|3-2| = 1 \ne 3 = |5-2|$，车根本不在攻击线上。
4. **两个直吃判定相互独立，都要查**：车管行列、象管斜线，二者覆盖的输入不相交，漏查任何一个都会把 1 误报成 2。
5. **皇后也参与遮挡**：写 BFS 暴力时，白棋不能越过皇后；分类解中皇后只出现在路线终点，不受影响。
6. **2 步的达成方式不止 L 形**：同线被挡时靠「象让路 + 车直吃」（构造 B），别只在脑子里模拟车的走法而漏掉这条。

## 5. 正确性证明

**引理 1**（1 步判定）：答案为 1 $\iff$ 车与皇后同线（$a=e$ 或 $b=f$）且象不在线段中间，或象与皇后同斜线（$|c-e| = |d-f|$）且车不在线段中间。

**证明**：一次移动只动一枚白棋。1 步捕获即把车或象移到 $(e,f)$。车能合法移到 $(e,f)$ $\iff$ 与皇后同列或同行，且中间无其他棋子——可能的中间棋子只有象（皇后是终点）；象同理，可能的中间棋子只有车。∎

**引理 2**（L 形路线至少一条畅通）：设 $a \ne e$ 且 $b \ne f$，考虑车的两条 L 形路线

$$P_1:\ (a,b) \to (a,f) \to (e,f) \qquad P_2:\ (a,b) \to (e,b) \to (e,f)$$

则 $P_1$、$P_2$ 至少一条完全无阻挡。

**证明**：由 $a \ne e, b \ne f$ 知皇后 $(e,f)$ 不在 $P_1$ 的拐点 $(a,f)$、不在 $P_2$ 的拐点 $(e,b)$，也不在两条路线的任何途经格上（只作终点），故只需考察象 $(c,d)$。$P_1$ 失败仅当以下三种情形之一：

1. $c = a$ 且 $d$ 严格介于 $b, f$ 之间（挡住竖段）；
2. $d = f$ 且 $c$ 严格介于 $a, e$ 之间（挡住横段）；
3. $c = a$ 且 $d = f$（占据拐点 $(a,f)$）。

逐项验证此时 $P_2$（横段为行 $b$、竖段为列 $e$、拐点 $(e,b)$）均畅通：

- 情形 1：$d$ 严格介于 $b,f$ $\Rightarrow d \ne b$，象不在行 $b$ 上；$c = a \ne e$，象不在列 $e$ 上；拐点 $(e,b)$ 需 $c = e$ 且 $d = b$，均不成立。
- 情形 2：$d = f \ne b$，象不在行 $b$ 上；$c$ 严格介于 $a,e$ $\Rightarrow c \ne e$，象不在列 $e$ 上、也不在拐点 $(e,b)$。
- 情形 3：$c = a \ne e$ 且 $d = f \ne b$，行 $b$、列 $e$、拐点 $(e,b)$ 全与象无关。

故 $P_1$ 失败时 $P_2$ 必然可行；若三种情形都不发生，$P_1$ 本身畅通。∎

**引理 3**（同线被挡时让路可行）：设 $a = e$ 且象严格介于车与皇后之间（$c = a$ 且 $\min(b,f) < d < \max(b,f)$；$b = f$ 的情形对称），则象可以先斜走一步离开该列，随后车沿该列一步吃到皇后。

**证明**：$d$ 严格介于两个互异的 $b, f \in [1,8]$ 之间 $\Rightarrow 2 \le d \le 7$，故 $(a+1, d\pm1)$、$(a-1, d\pm1)$ 中至少有一个在棋盘内（$a$ 为边界列时上下各有一个方向可走）。这些候选格都在列 $a \pm 1$ 上，而车与皇后都在列 $a$ 上，故候选格未被占据；斜走一步没有途经格，移动必然合法。象移走后，列 $a$ 上车与皇后之间再无棋子，车滑动捕获。∎

**定理**：本题答案为 1 或 2，算法输出正确。

**证明**：捕获至少需 1 步（开局无白棋位于皇后格上）。若引理 1 的条件成立，答案恰为 1；否则：

- 若 $a \ne e$ 且 $b \ne f$，由引理 2，车两步捕获，答案为 2；
- 若 $a = e$ 或 $b = f$（二者不能同时成立），由引理 1 不成立知象严格介于车与皇后之间（否则车直吃成立），由引理 3，两步捕获，答案为 2。

算法的分支与上述分类一一对应，故输出正确。∎

> 💡 落笔后可机器对拍兜底：枚举 $8^6$ 组输入中三子互不同格的全部 249,984 个局面，用逐格滑动模拟求出精确步数与判定式比对——实测零失配（1 步 79,856 个、2 步 170,128 个，不存在 $\ge 3$ 步的局面）。

## 6. 复杂度分析

- **时间复杂度**：$O(1)$。车、象两个直吃判定合计十余次整数比较，无循环无搜索。
- **空间复杂度**：$O(1)$。只使用 6 个入参整数，无额外数据结构。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int minMovesToCaptureTheQueen(int a, int b, int c, int d, int e, int f) {
        // 车能否一步吃到：与皇后同列或同行，且象不在线段中间
        bool rookOne = false;
        if (a == e) {
            rookOne = !(c == a && min(b, f) < d && d < max(b, f));
        } else if (b == f) {
            rookOne = !(d == b && min(a, e) < c && c < max(a, e));
        }

        // 象能否一步吃到：与皇后同斜线，且车不在线段中间
        bool bishopOne = false;
        if (abs(c - e) == abs(d - f)) {
            bool blocked = min(c, e) < a && a < max(c, e) &&
                           min(d, f) < b && b < max(d, f) &&
                           abs(a - c) == abs(b - d);
            bishopOne = !blocked;
        }

        return (rookOne || bishopOne) ? 1 : 2;
    }
};
```

### Python

```python
class Solution:
    def minMovesToCaptureTheQueen(self, a: int, b: int, c: int, d: int,
                                   e: int, f: int) -> int:
        # 车能否一步吃到：与皇后同列或同行，且象不在线段中间
        if a == e:
            rook_one = not (c == a and min(b, f) < d < max(b, f))
        elif b == f:
            rook_one = not (d == b and min(a, e) < c < max(a, e))
        else:
            rook_one = False

        # 象能否一步吃到：与皇后同斜线，且车不在线段中间
        bishop_one = False
        if abs(c - e) == abs(d - f):
            blocked = (min(c, e) < a < max(c, e)
                       and min(d, f) < b < max(d, f)
                       and abs(a - c) == abs(b - d))
            bishop_one = not blocked

        return 1 if (rook_one or bishop_one) else 2
```

> 💡 语言细节：Python 的链式比较 `min(b, f) < d < max(b, f)` 一行表达「严格介于」，C++ 要拆成两个条件；六个整数都 $\le 8$，无溢出之忧。

## 8. 边界情况与易错点

1. **漏查象的直吃**：只判车会把大量「象一步斜吃」的局面误报成 2，两个判定必须都写。
2. **「严格介于」写成 $\le$**：端点格子恰是三枚棋子自身，本题靠「三子互不同格」的约束兜底不会出错，但语义上就该用严格不等号，变体题里不能赌运气。
3. **斜线遮挡的假阳性**：车行列都介于象与皇后之间、但不在同一条斜线上（$|a-c| \ne |b-d|$）时并不挡路；只写一个「介于」条件会把这种车误判成遮挡。
4. **同列且同行不可能同时成立**：$a=e$ 与 $b=f$ 同时成立意味着车在皇后格上，违反约束，所以车判定可放心用 if / else if。
5. **别把答案写成 0**：捕获必须实际走到皇后格，开局不可能已经完成；「初始攻击到」只说明能 1 步，不是 0 步。
6. **皇后也是障碍物**：改用 BFS 对拍时，白棋滑动不能越过皇后；分类解中皇后只在路线终点，无此顾虑。
7. **2 步不只有 L 形**：同线被挡的局面靠「象让路」达成，构造思路要两条都有。
