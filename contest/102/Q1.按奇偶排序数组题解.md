# LeetCode 按奇偶排序数组 题解

## 1. 题目概述

- **标题 / 题号**：按奇偶排序数组（#905，easy）
- **链接**：https://leetcode.cn/problems/sort-array-by-parity/
- **来源**：LeetCode 第 102 场周赛 Q1
- **难度**：简单
- **标签**：数组、双指针、排序

**题意**：给定整数数组 `nums`，把**所有偶数**搬到数组前面、**所有奇数**搬到数组后面，返回**任意一个**满足条件的数组。题目不要求组内有序，也不要求稳定。

**约束**：

- $1 \le nums.length \le 5000$
- $0 \le nums[i] \le 5000$，注意 $0$ 是偶数

## 2. 示例

**示例 1**

```text
输入：nums = [3,1,2,4]
输出：[2,4,3,1]
解释：[4,2,3,1]、[2,4,1,3] 和 [4,2,1,3] 也被视作正确答案——只要偶数全在奇数前面即可。
```

**示例 2**

```text
输入：nums = [0]
输出：[0]
解释：单元素，无需调整；0 属于偶数。
```

**示例 3（自造，全奇 / 全偶）**

```text
输入：nums = [1,3,5]
输出：[1,3,5]
解释：没有偶数，原数组已经合法，双指针会直接相遇返回。
```

**示例 4（自造，交替分布）**

```text
输入：nums = [1,2,3,4,5,6]
输出：[6,2,4,5,3,1]
解释：交换把右侧的偶数逐个换到左侧，最坏情况每次都要交换，但总交换次数不超过 n/2。
```

## 3. 解题思路

### 3.1 暴力思路

最直观的做法是**新建一个数组**：第一遍扫 `nums` 把所有偶数依次写入，第二遍把所有奇数写入，再把结果拷回。时间 $O(n)$、空间 $O(n)$，能过，但完全没必要多开一个数组。

另一种常见想法是**排序**：用 `nums[i] % 2` 作排序键，偶数键 0、奇数键 1，$O(n \log n)$。它把「分组」问题做成了「排序」问题，既要多做无用功，又会打乱组内相对顺序——而题目根本没要求组内有序。

注意到题目只要求「偶数在前、奇数在后」这一个**划分性质**，不关心组内顺序，因此一遍原地扫描就够。

### 3.2 核心观察：双指针从两端向中间夹

![双指针：左找奇数、右找偶数，就地交换](images/wc102_q1_two_pointer_concept.svg)

把数组看成三段：

- 左侧已就位的**偶区**；
- 右侧已就位的**奇区**；
- 中间**尚未处理**的区域。

用两个指针 $i$、$j$ 分别指向中间区域的左端和右端：

- `nums[i]` 是偶数 → 它本来就在偶区边界上，直接 $i{+}{+}$，偶区扩大一格；
- `nums[j]` 是奇数 → 它本来就在奇区边界上，直接 $j{-}{-}$，奇区扩大一格；
- 否则必然是「**左奇、右偶**」这一对错位的元素，交换它们，两个元素同时归位，再 $i{+}{+}$、$j{-}{-}$。

每个元素最多被指针经过一次，交换一次，整体线性。

### 3.3 算法流程

![算法流程：三个分支对应三种情况](images/wc102_q1_algorithm_flow.svg)

```text
1. i = 0, j = n - 1
2. while i < j:
3.     若 nums[i] 是偶数:        i++          # 偶区扩容
4.     否则若 nums[j] 是奇数:     j--          # 奇区扩容
5.     否则:                     swap(nums[i], nums[j]); i++; j--   # 左奇右偶，成对归位
6. 返回 nums
```

三个分支互斥且穷尽：只要 $i < j$，要么左指针可以推进，要么右指针可以推进，要么「左奇右偶」必须交换，不存在空转的情况。

### 3.4 示例演算

![示例演算：nums = [3,1,2,4] 的两轮交换](images/wc102_q1_walkthrough.svg)

| 轮次 | $i$ | $j$ | `nums` | 判定 |
|------|-----|-----|--------|------|
| 初始 | 0 | 3 | [3,1,2,4] | — |
| 第 1 轮 | 0 | 3 | [3,1,2,4] | `nums[0]=3` 奇、`nums[3]=4` 偶 → 交换 |
| 第 2 轮 | 1 | 2 | [4,1,2,3] | `nums[1]=1` 奇、`nums[2]=2` 偶 → 交换 |
| 结束 | 2 | 1 | [4,2,1,3] | $i > j$，停止 |

结果为 `[4,2,1,3]`：偶数 4、2 全在奇数 1、3 之前，是一个合法答案（虽然与官方输出的 `[2,4,3,1]` 不同，判题器只校验划分性质）。

## 4. 算法细节

1. **奇偶判定**：C++ 用 `nums[i] % 2 == 0` 判偶。数据范围非负，但写成 `% 2 == 0` 对负数同样正确（$-3 \bmod 2 = -1 \ne 0$），比 `nums[i] & 1` 的心智负担小。
2. **分支顺序**：先判左指针是否是偶数（可前进），再判右指针是否是奇数（可后退），最后才是交换。若顺序写反，可能在「左偶右奇」这种本该双指针各自前进的局面下误交换。
3. **C++ 用 `std::swap`、Python 用元组解包**：两者都是 $O(1)$ 交换，不引入临时数组。
4. **原地修改**：题目允许直接改 `nums` 并返回它（LeetCode 判题只读返回的数组），因此无需拷贝。
5. **循环条件 `i < j`**：两个指针相遇即停；中间剩下的单个元素无论奇偶都不会破坏划分性质（见 §5 的证明）。

## 5. 正确性证明

**引理 1（循环不变式）**：每次循环开始时，$[0, i)$ 内全是偶数，$(j, n-1]$ 内全是奇数，中间的 $[i, j]$ 是原数组尚未处理的元素。

**证明**：初始 $i = 0$、$j = n-1$，两个区间为空，中间即整个数组，成立。归纳地看三种分支：

- `nums[i]` 为偶数时 $i$ 右移：新纳入偶区的元素是偶数，偶区性质保持；奇区与中间区不变。
- `nums[j]` 为奇数时 $j$ 左移：新纳入奇区的元素是奇数，奇区性质保持。
- 交换时，左端的奇数被送到 $j$ 位置（进入奇区），右端的偶数被送到 $i$ 位置（进入偶区），随后 $i$ 右移、$j$ 左移，两个区同时扩大且性质保持。

三种分支穷尽了所有情况（左边非偶 ⇔ 左奇；右边非奇 ⇔ 右偶），因此不变式在每轮结束时成立。∎

**引理 2（元素多重集不变）**：算法只做交换，返回的数组是原数组的一个排列。

**证明**：除 `swap` 外没有任何赋值操作，交换不改变元素的多重集。∎

**定理**：算法终止时，数组中不存在「奇数在前、偶数在后」的下标对，即所有偶数都排在所有奇数之前。

**证明**：循环在 $i \ge j$ 时终止，分两种情形。

1. $i > j$：此时每个下标 $p$ 要么满足 $p < i$（属于偶区，值为偶数），要么满足 $p > j$（属于奇区，值为奇数）。任取 $p < q$，若 `nums[p]` 是奇数则 $p \ge i$，于是 $q > p \ge i > j$，推出 $q$ 属于奇区、`nums[q]` 也是奇数——不会出现「奇在前、偶在后」。
2. $i = j$：中间只剩一个下标 $m = i$。$[0, m-1]$ 全偶、$[m+1, n-1]$ 全奇。若 `nums[m]` 是偶数，则偶区延伸到 $m$，奇数全在 $m$ 之后；若 `nums[m]` 是奇数，则奇区延伸到 $m$，偶数全在 $m$ 之前。两种情况下划分性质都成立。

结合引理 2，返回的数组既是原数组的排列，又满足「偶数全部在前、奇数全部在后」。∎

## 6. 复杂度分析

- **时间**：$O(n)$。每轮循环要么 $i$ 增加、要么 $j$ 减少、要么两者同时变化，两个指针合计最多移动 $n$ 步，因此循环轮数不超过 $n$；每轮内部是 $O(1)$ 的取模、比较与交换。
- **空间**：$O(1)$。只用了两个整型指针，原地交换，没有辅助数组；返回值就是入参数组本身。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> sortArrayByParity(vector<int>& nums) {
        int i = 0, j = (int)nums.size() - 1;
        while (i < j) {
            if (nums[i] % 2 == 0) {
                i++;                       // 左端已是偶数，偶区扩容
            } else if (nums[j] % 2 == 1) {
                j--;                       // 右端已是奇数，奇区扩容
            } else {
                swap(nums[i], nums[j]);    // 左奇右偶：成对归位
                i++;
                j--;
            }
        }
        return nums;
    }
};
```

### Python

```python
class Solution:
    def sortArrayByParity(self, nums: list[int]) -> list[int]:
        i, j = 0, len(nums) - 1
        while i < j:
            if nums[i] % 2 == 0:
                i += 1
            elif nums[j] % 2 == 1:
                j -= 1
            else:
                nums[i], nums[j] = nums[j], nums[i]
                i += 1
                j -= 1
        return nums
```

## 8. 边界情况与易错点

1. **0 是偶数**：`0 % 2 == 0`，必须归入偶区。把判据写成 `if (nums[i] % 2)` 再取反、或误用 `nums[i] & 1 == 0` 的优先级问题（`==` 优先于 `&`）都会出错。
2. **全偶 / 全奇**：全偶时 `i` 一路推到 $n-1$，全奇时 `j` 一路退到 $0$，循环自然结束，不会越界，也不会做多余交换。
3. **单元素**：`i == j == 0`，循环不进入，直接返回原数组。
4. **不要与官方示例逐位比对**：本题是**多解题**（special judge），`[2,4,3,1]`、`[4,2,1,3]`、`[2,4,1,3]` 都算对；自测时应当校验「偶在前、奇在后 + 多重集一致」，而不是字符串相等。
5. **交换条件写反**：若在「左偶右奇」时也交换，会把已经就位的偶数搬到右边，破坏不变式。
6. **组内顺序**：题目不要求稳定；若题目改成「偶数之间保持原有相对顺序」，双指针交换就不再正确，需要另想办法。
