# LeetCode 水果成篮 题解

## 1. 题目概述

- **标题 / 题号**：水果成篮（#904，medium）
- **链接**：https://leetcode.cn/problems/fruit-into-baskets/
- **来源**：LeetCode 第 102 场周赛 Q2
- **难度**：中等
- **标签**：数组、哈希表、滑动窗口

**题意**：一排果树用 `fruits` 表示，`fruits[i]` 是第 $i$ 棵树的水果**种类**。你只有**两个篮子**，每个篮子只能装**一种**水果（容量无限）。你可以从任意一棵树开始，之后必须**逐棵向右**、每棵恰好摘一个，一旦遇到不属于两个篮子中任何一种的水果就必须停止。求最多能摘到的水果数目。

换句话说：求**最长的、至多包含两种不同值的连续子数组**的长度。

**约束**：

- $1 \le fruits.length \le 10^5$
- $0 \le fruits[i] < fruits.length$（值域被数组长度限制住，可以直接开桶计数）

## 2. 示例

**示例 1**

```text
输入：fruits = [1,2,1]
输出：3
解释：篮子装 1 和 2，三棵树都能摘。
```

**示例 2**

```text
输入：fruits = [0,1,2,2]
输出：3
解释：从下标 1 开始摘 [1,2,2]，长度 3；若从下标 0 开始，遇到 2 就必须停，只能摘 2 棵。
```

**示例 3**

```text
输入：fruits = [1,2,3,2,2]
输出：4
解释：摘 [2,3,2,2] 共 4 棵；从下标 0 开始只能摘 [1,2]。
```

**示例 4**

```text
输入：fruits = [3,3,3,1,2,1,1,2,3,3,4]
输出：5
解释：摘 [1,2,1,1,2] 共 5 棵。注意窗口并不一定贴着数组头部或尾部。
```

## 3. 解题思路

### 3.1 暴力思路

枚举左端点 $l$，从 $l$ 向右逐棵扩展并维护两个篮子的种类与计数，遇到第 3 种就停下，记录长度，然后 $l$ 右移一位重来。时间复杂度 $O(n^2)$：最坏情况（如整个数组只有一种水果）每个 $l$ 都要扫到末尾，$n = 10^5$ 时约 $10^{10}$ 次操作，必然超时。

暴力之所以浪费，是因为相邻的两个左端点对应的窗口**高度重叠**：$l$ 右移一格时，我们完全不必从头重新统计，只要把「被移出的那一棵」从篮子里扣掉即可。

### 3.2 核心观察：窗口内的种类数 ≤ 2

![窗口内最多两种水果：把第三种移出去](images/wc102_q2_window_concept.svg)

用**滑动窗口** $[left, right]$ 表示当前合法的采摘区间，并维护：

- `cnt[x]`：窗口内水果种类 $x$ 出现的次数；
- `distinct`：窗口内出现过的**不同种类数**。

关键观察只有一条：**窗口合法 ⇔ distinct ≤ 2**。于是右端可以放心扩张，一旦 `distinct` 变成 3，就必须从**左端**把某一整类水果彻底移出窗口——注意不是移一棵，而是「一直移，直到某类的计数归零，种类数回到 2」。

这一步的正确性依赖于「窗口收缩是单调的」：当右端加入第 3 种水果时，左端必须越过当前窗口内**最早出现的那一类**水果的全部出现位置，窗口才可能重新合法；越过之后，任何更靠右的起点都不会更优（因为长度更短）。

### 3.3 算法流程

![滑动窗口流程：先扩右端，再缩左端](images/wc102_q2_algorithm_flow.svg)

```text
1. cnt = 全 0 数组（长度 n），left = 0，distinct = 0，ans = 0
2. for right = 0 .. n-1:
3.     若 cnt[fruits[right]] == 0:  distinct++
4.     cnt[fruits[right]]++
5.     while distinct > 2:                       # 收缩到恰好两种
6.         cnt[fruits[left]]--
7.         若 cnt[fruits[left]] == 0:  distinct--
8.         left++
9.     ans = max(ans, right - left + 1)
10. 返回 ans
```

注意第 6、7 行的顺序：**先扣计数、再判零**，否则刚移出的那一类会被误判为「还在窗口里」。

由于每次右端只可能引入**一种**新水果，`distinct` 每次最多超过 2 一点，所以 `while` 循环每轮平均只走常数步（把它写成 `if` 也能通过，但 `while` 的语义更稳，不会因为将来的变体（比如篮子上限更大）而失效）。

### 3.4 示例演算

![示例演算：fruits = [1,2,3,2,2]](images/wc102_q2_walkthrough.svg)

对 `fruits = [1,2,3,2,2]`：

| right | fruits[right] | 篮子计数 | distinct | left | 窗口长度 |
|-------|---------------|----------|----------|------|----------|
| 0 | 1 | {1:1} | 1 | 0 | 1 |
| 1 | 2 | {1:1, 2:1} | 2 | 0 | 2 |
| 2 | 3 | 加入 3 → 3 种，移出 1 → {2:1, 3:1} | 2 | 1 | 2 |
| 3 | 2 | {2:2, 3:1} | 2 | 1 | 3 |
| 4 | 2 | {2:3, 3:1} | 2 | 1 | 4 |

答案为 4。可以观察到 `right = 2` 这一轮只把 `left` 推进了 **1** 格：移出 `fruits[0] = 1` 后，种类数立刻从 3 回到 2。

## 4. 算法细节

1. **计数容器**：由 $0 \le fruits[i] < n$，可直接开长度 $n$ 的 `vector<int> cnt(n, 0)`；若值域很大，则换 `unordered_map`（本题不必，数组更快）。值域开成 $10^5$ 也可以，但用 $n$ 更省。
2. **`distinct` 的维护**：只在「计数由 0 变 1」时加一，在「计数由 1 变 0」时减一，二者必须对称，不能只维护一边。
3. **收缩的边界**：`while distinct > 2` 内部每一次都要先自减计数；`left` 推进后不可能超过 `right`，因为窗口内至少还剩刚加入的那一棵水果所在的种类。
4. **答案更新时机**：在收缩**之后**更新，保证窗口一定合法；若放在收缩之前，会统计到含 3 种的非法窗口。
5. **单元素 / 全部相同**：`distinct` 始终不超过 2，`while` 一次都不执行，答案等于 $n$，符合直觉。

## 5. 正确性证明

**引理 1（窗口不变式）**：每次第 9 行更新答案时，窗口 $[left, right]$ 内不同水果种类数不超过 2。

**证明**：`while` 循环的退出条件正是 `distinct <= 2`；而 $[left, right]$ 中的所有元素都被 `cnt` 精确计数（加入时加一，移出时减一），故 `distinct` 就是窗口内的真实种类数。∎

**引理 2（以 right 结尾的最优性）**：第 9 行时，$[left, right]$ 是**以 $right$ 结尾的最长合法子数组**。

**证明**：若 $left = 0$ 则显然（左端已到数组边界）。否则，设最后一次收缩前左端为 $left-1$。此时窗口 $[left-1, right]$ 内的种类数为 3（否则不会进入 `while`），因此 $[left-1, right]$ 不合法。而对任意 $l \le left-1$，窗口 $[l, right]$ 是 $[left-1, right]$ 的超集，种类数只增不减，也不合法。故以 $right$ 结尾的合法子数组中，起点最小只能是 $left$，长度最大为 $right - left + 1$，正是被记录的值。∎

**定理**：算法返回的 `ans` 等于所有合法子数组长度的最大值。

**证明**：一方面，由引理 1，`ans` 记录的每个长度都来自合法窗口，故 `ans` 不超过真实最大值；另一方面，设 $[l^*, r^*]$ 是任意一个最长合法子数组，第 $r^*$ 轮迭代时由引理 2 得到的窗口长度不小于 $r^* - l^* + 1$，于是 `ans` 不小于真实最大值。两边夹逼，`ans` 恰为最大值。∎

## 6. 复杂度分析

- **时间**：$O(n)$。`right` 单调右移 $n$ 次；`left` 也只右移，全程累计最多 $n$ 次；`while` 内部每轮 $O(1)$，因此总循环次数 $O(n)$。没有嵌套的重复扫描。
- **空间**：$O(n)$。`cnt` 是长度 $n$ 的计数数组（由值域 $fruits[i] < n$ 决定）；除它之外只有常数个变量，没有额外容器。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int totalFruit(vector<int>& fruits) {
        int n = (int)fruits.size();
        vector<int> cnt(n, 0);
        int left = 0, distinct = 0, ans = 0;
        for (int right = 0; right < n; right++) {
            if (cnt[fruits[right]] == 0) distinct++;
            cnt[fruits[right]]++;
            while (distinct > 2) {
                cnt[fruits[left]]--;
                if (cnt[fruits[left]] == 0) distinct--;
                left++;
            }
            ans = max(ans, right - left + 1);
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def totalFruit(self, fruits: list[int]) -> int:
        n = len(fruits)
        cnt = [0] * n
        left = 0
        distinct = 0
        ans = 0
        for right, x in enumerate(fruits):
            if cnt[x] == 0:
                distinct += 1
            cnt[x] += 1
            while distinct > 2:
                y = fruits[left]
                cnt[y] -= 1
                if cnt[y] == 0:
                    distinct -= 1
                left += 1
            ans = max(ans, right - left + 1)
        return ans
```

## 8. 边界情况与易错点

1. **`cnt` 下标越界**：`fruits[i]` 取值范围是 $[0, n)$，开 $n$ 大小的数组刚好；若按「水果种类最大值」开，容易开小。
2. **收缩时「减计数」与「判零」的顺序**：必须先 `cnt[...]--` 再判 `cnt[...] == 0`，否则会把仍然是 0 的计数当成「已移空」，导致 `distinct` 多减。
3. **`while` 而不是「移一棵树」**：移出一棵树未必能让种类数从 3 降回 2（例如窗口 `[1,2,1,2,3]` 要移出两棵 1 才降到 2 种）。写成「只移一棵」会留下非法窗口，答案偏大。
4. **`ans` 在收缩后更新**：放在 `while` 之前会把含 3 种的窗口也算进去。
5. **全相同 / 单元素**：答案是 $n$，不要因为「两种篮子」而误以为需要特判。
6. **窗口不贴边**：示例 4 的最优窗口在中段，说明不能只考虑「从 0 开始」的窗口。
7. **不要把「两个篮子」理解成「两种水果各只能摘一个」**：篮子容量无限，篮子里可以反复出现同一种水果。
