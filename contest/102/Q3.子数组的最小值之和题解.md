# LeetCode 子数组的最小值之和 题解

## 1. 题目概述

- **标题 / 题号**：子数组的最小值之和（#907，medium）
- **链接**：https://leetcode.cn/problems/sum-of-subarray-minimums/
- **来源**：LeetCode 第 102 场周赛 Q3
- **难度**：中等
- **标签**：数组、栈、动态规划、单调栈

**题意**：给定整数数组 `arr`，对它的**每一个连续子数组** $b$ 求 $\min(b)$，把所有 $\min(b)$ 加起来，返回总和模 $10^9+7$ 的结果。

**约束**：

- $1 \le arr.length \le 3 \times 10^4$
- $1 \le arr[i] \le 3 \times 10^4$

子数组总数是 $\frac{n(n+1)}{2}$，$n = 3\times 10^4$ 时约 $4.5\times 10^8$ 个，**逐个子数组枚举**必然超时，必须换一个统计角度。

## 2. 示例

**示例 1**

```text
输入：arr = [3,1,2,4]
输出：17
解释：共 10 个子数组，最小值依次为
      [3]→3  [1]→1  [2]→2  [4]→4
      [3,1]→1  [1,2]→1  [2,4]→2
      [3,1,2]→1  [1,2,4]→1  [3,1,2,4]→1
      3+1+2+4+1+1+2+1+1+1 = 17
```

**示例 2**

```text
输入：arr = [11,81,94,43,3]
输出：444
解释：3 与 43 是两处「低谷」，把数组切成若干段，逐段用贡献法累加得到 444。
```

**示例 3**

```text
输入：arr = [50]
输出：50
解释：只有子数组 [50]，最小值就是 50。
```

## 3. 解题思路

### 3.1 暴力思路

两层循环枚举左右端点，内层顺带维护当前最小值：

```text
for l in 0..n-1:
    cur = INF
    for r in l..n-1:
        cur = min(cur, arr[r])
        ans += cur
```

时间 $O(n^2)$，$n = 3\times 10^4$ 时约 $4.5\times 10^8$ 次内层迭代，勉强能过但很不稳，而且完全没利用「最小值只在遇到更小元素时才改变」的结构。

### 3.2 核心观察：按「谁是最小值」统计贡献

![每个元素只统计「它为最小值」的那些子数组](images/wc102_q3_contribution_concept.svg)

不要枚举子数组，而是枚举**最小值落在哪个下标**。对每个下标 $i$，设「最小值为 `arr[i]`」的子数组个数为 $c_i$，则答案就是

$$\text{ans} = \sum_{i=0}^{n-1} arr[i] \cdot c_i.$$

剩下的问题只有一个：$c_i$ 怎么算？

固定 $i$ 后，一个子数组 $[l, r]$ 含 $i$ 且以 `arr[i]` 为最小值，当且仅当：

- $l$ 不能越过 $i$ 左边**第一个小于等于** `arr[i]` 的位置（越过了就会把更小或相等的元素拉进来）；
- $r$ 不能越过 $i$ 右边**第一个严格小于** `arr[i]` 的位置（越过了就会把更小的元素拉进来）。

记 $A_i$ 为 $i$ 左侧最近的满足 `arr[j] <= arr[i]` 的下标（不存在记 $-1$），$B_i$ 为 $i$ 右侧最近的满足 `arr[j] < arr[i]` 的下标（不存在记 $n$），则

$$c_i = (i - A_i)\,(B_i - i).$$

**为什么左右一松一严？** 因为数组可能有**重复值**，必须约定归属避免重复计数。约定：子数组的最小值**归属于最左边**那个达到最小值的下标。

- 左边出现**相等**元素时，$i$ 就不再是「最左」的那个，所以 $l$ 必须跨过所有相等元素 → 左界取「小于等于」；
- 右边出现**相等**元素时，$i$ 仍是最左的那个（相等元素在它右侧），不影响归属，只有**严格更小**才会破坏「`arr[i]` 是最小值」→ 右界取「严格小于」。

以示例 1 的 $i=1$（`arr[1] = 1`）为例：左侧没有 $\le 1$ 的元素，$A_1 = -1$，$l$ 有 $1-(-1)=2$ 种取法；右侧没有 $<1$ 的元素，$B_1 = 4$，$r$ 有 $4-1=3$ 种取法；$c_1 = 6$，贡献 $1 \times 6 = 6$。

### 3.3 算法流程：两遍单调栈

![单调栈：一遍求出每个元素左右边界](images/wc102_q3_mono_stack_flow.svg)

求「上一个 $\le$」和「下一个 $<$」都是单调栈的经典应用：

```text
1. 从左到右扫描，维护一个存放「待定下标」的栈：
2.     while 栈非空 且 arr[栈顶] > arr[i]:  弹出       # 弹出的是「还不够小」的
3.     left[i] = 栈空 ? i + 1 : i - 栈顶               # 左向可选起点个数
4.     压入 i
5. 从右到左镜像扫描：
6.     while 栈非空 且 arr[栈顶] >= arr[i]: 弹出
7.     right[i] = 栈空 ? n - i : 栈顶 - i              # 右向可选终点个数
8.     压入 i
9. ans = Σ arr[i] * left[i] * right[i]  (mod 1e9+7)
```

第 2 行弹掉 `>` 之后，栈顶就是最近的小于等于 `arr[i]` 的下标，正是 $A_i$；第 6 行弹掉 `>=` 之后，栈顶就是最近的严格更小下标，正是 $B_i$。两遍扫描中每个下标最多进出栈一次，均摊 $O(n)$。

### 3.4 示例演算

![示例演算：arr = [3,1,2,4]，答案 17](images/wc102_q3_walkthrough.svg)

对 `arr = [3,1,2,4]`：

| $i$ | `arr[i]` | $A_i$（左边 $\le$） | $B_i$（右边 $<$） | `left[i]` | `right[i]` | 贡献 |
|-----|----------|----------------------|-------------------|-----------|------------|------|
| 0 | 3 | $-1$ | 1（`arr[1]=1 < 3`） | 1 | 1 | $3 \times 1 \times 1 = 3$ |
| 1 | 1 | $-1$ | 4（无更小） | 2 | 3 | $1 \times 2 \times 3 = 6$ |
| 2 | 2 | 1（`arr[1]=1 ≤ 2`） | 4 | 1 | 2 | $2 \times 1 \times 2 = 4$ |
| 3 | 4 | 2（`arr[2]=2 ≤ 4`） | 4 | 1 | 1 | $4 \times 1 \times 1 = 4$ |

总和 $3 + 6 + 4 + 4 = 17$，与示例一致。

## 4. 算法细节

1. **严格性必须一松一严**：左侧取「$\le$」、右侧取「$<$」（对应归属给**最左**最小值）。若两边都取「$<$」，相等的元素会被两个下标各数一遍；若两边都取「$\le$」，相等元素夹住的子数组会两边都数不到（漏统）。
2. **单调栈的弹出条件**：左扫弹 `arr[栈顶] > arr[i]`（保留相等，栈内值**单调不减**）；右扫弹 `arr[栈顶] >= arr[i]`（弹掉相等，栈内值**严格递增**）。
3. **空栈的默认值**：空栈表示「该侧没有边界」，左侧可选起点数是 $i+1$（下标 $0..i$），右侧可选终点数是 $n-i$（下标 $i..n-1$）。差一就错。
4. **取模与溢出**：$arr[i] \cdot left[i] \cdot right[i]$ 最大约 $3\times10^4 \times 3\times10^4 \times 3\times10^4 \approx 2.7\times10^{13}$，超出 32 位；C++ 先转 `long long` 再逐步取模，Python 每步 `% MOD`。
5. **两遍扫描而不是一遍**：一趟同时维护左右两侧的答案需要处理「相等时归给谁」的耦合，容易写错；两遍分开写、各自单调，最稳。
6. **栈存下标而非值**：只有下标才能算「距离」，值只用来比较大小。

## 5. 正确性证明

**引理 1（窗口刻画）**：设 $A_i$ 为 $i$ 左侧最近的满足 `arr[j] <= arr[i]` 的下标（无则 $-1$），$B_i$ 为 $i$ 右侧最近的满足 `arr[j] < arr[i]` 的下标（无则 $n$）。则对任意 $l \le i \le r$：

$$i \text{ 是 } [l, r] \text{ 中最左的最小值位置} \iff A_i < l \text{ 且 } r < B_i.$$

**证明**：

*（$\Rightarrow$）* 设 $i$ 是 $[l, r]$ 中最左的最小值位置。

- 若 $A_i \ge l$，则 $A_i \in [l, i-1]$。若 `arr[A_i] < arr[i]`，与 `arr[i]` 是区间最小值矛盾；若 `arr[A_i] = arr[i]`，则 $A_i < i$ 是区间内更左的相等最小值，与「$i$ 最左」矛盾。故 $A_i < l$。
- 若 $B_i \le r$，则 $B_i \in (i, r]$ 且 `arr[B_i] < arr[i]`，与 `arr[i]` 是区间最小值矛盾。故 $r < B_i$。

*（$\Leftarrow$）* 设 $A_i < l$ 且 $r < B_i$。

- 对 $j \in [l, i-1]$：由 $j > A_i$ 与 $A_i$ 的「最近」性，$j$ 不可能满足 `arr[j] <= arr[i]`，故 `arr[j] > arr[i]`。于是 $[l, i-1]$ 内每个元素都**严格大于** `arr[i]`。
- 对 $j \in (i, r]$：由 $j < B_i$ 与 $B_i$ 的「最近」性，$j$ 不可能满足 `arr[j] < arr[i]`，故 `arr[j] >= arr[i]`。

两式合并得 `arr[i]` 是 $[l, r]$ 的最小值；又因为左侧元素都严格大于它，$i$ 是最左的最小值位置。∎

**引理 2（归属唯一）**：每个子数组 $[l, r]$ 恰有一个「最左最小值位置」$i$，且该 $i$ 满足 $A_i < l$ 与 $r < B_i$。

**证明**：$[l, r]$ 非空，最小值至少在某个下标取得，取其中最小的下标即为唯一的最左最小值位置 $i$；再由引理 1 的（$\Rightarrow$）方向得到两个不等式。∎

**定理**：算法输出 $\displaystyle\sum_{i=0}^{n-1} arr[i]\,(i-A_i)\,(B_i-i) \bmod (10^9+7)$ 等于所有子数组最小值之和模 $10^9+7$。

**证明**：由引理 2，全部子数组与「(归属下标 $i$, $l$, $r$) 三元组」之间构成一一对应。固定 $i$ 后，$l$ 的取法是 $A_i + 1, \dots, i$ 共 $i - A_i$ 种，$r$ 的取法是 $i, \dots, B_i - 1$ 共 $B_i - i$ 种，且由引理 1 每个组合都合法、每个合法组合都被计入。故这些子数组的最小值之和恰为 $arr[i] \cdot (i-A_i)\cdot(B_i-i)$。对 $i$ 求和即得全体子数组的最小值之和，取模不改变同余类。∎

## 6. 复杂度分析

- **时间**：$O(n)$。两遍单调栈，每个下标至多入栈一次、出栈一次，均摊 $O(1)$；最后一遍线性求和。总计 $O(n)$。
- **空间**：$O(n)$。`left`、`right` 两个长度 $n$ 的数组，以及一个最大长度 $n$ 的栈。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int sumSubarrayMins(vector<int>& arr) {
        const int MOD = 1000000007;
        int n = (int)arr.size();
        vector<int> left(n), right(n);
        vector<int> st;
        st.reserve(n);
        // 左界：最近的 <= arr[i]
        for (int i = 0; i < n; i++) {
            while (!st.empty() && arr[st.back()] > arr[i]) st.pop_back();
            left[i] = st.empty() ? i + 1 : i - st.back();
            st.push_back(i);
        }
        st.clear();
        // 右界：最近的 < arr[i]
        for (int i = n - 1; i >= 0; i--) {
            while (!st.empty() && arr[st.back()] >= arr[i]) st.pop_back();
            right[i] = st.empty() ? n - i : st.back() - i;
            st.push_back(i);
        }
        long long ans = 0;
        for (int i = 0; i < n; i++) {
            ans = (ans + (long long)arr[i] * left[i] % MOD * right[i]) % MOD;
        }
        return (int)ans;
    }
};
```

### Python

```python
class Solution:
    def sumSubarrayMins(self, arr: list[int]) -> int:
        MOD = 10 ** 9 + 7
        n = len(arr)
        left = [0] * n
        right = [0] * n

        st = []
        for i in range(n):
            while st and arr[st[-1]] > arr[i]:
                st.pop()
            left[i] = i + 1 if not st else i - st[-1]
            st.append(i)

        st = []
        for i in range(n - 1, -1, -1):
            while st and arr[st[-1]] >= arr[i]:
                st.pop()
            right[i] = n - i if not st else st[-1] - i
            st.append(i)

        ans = 0
        for i in range(n):
            ans = (ans + arr[i] * left[i] * right[i]) % MOD
        return ans
```

## 8. 边界情况与易错点

1. **重复值导致重复计数或漏统**：这是本题最主要的 WA 点。左侧必须弹 `>`（保留相等）、右侧必须弹 `>=`（弹掉相等）；两边对称地都弹 `>` 或都弹 `>=` 都不对。
2. **乘法溢出**：`arr[i] * left[i] * right[i]` 可达 $2.7\times 10^{13}$，C++ 用 `int` 会静默回绕；必须先转 `long long`，且 `(long long)arr[i] * left[i] % MOD * right[i]` 的中间值仍在 `long long` 范围内。
3. **空栈默认值差一**：左扫空栈时是 $i+1$ 而不是 $i$，右扫空栈时是 $n-i$ 而不是 $n-i-1$。
4. **单元素**：$n=1$ 时 `left[0]=right[0]=1`，答案 `arr[0]`，无需特判。
5. **右扫方向**：必须从右往左，否则求出的是「上一个更小」而不是「下一个更小」。
6. **只存值不存下标**：栈里必须存下标，否则算不出距离。
7. **忘记取模**：最终结果与中间累加都要取模；即便 Python 不会溢出，也必须输出模值。
