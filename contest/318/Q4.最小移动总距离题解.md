# LeetCode 最小移动总距离 题解

## 1. 题目概述

- **标题 / 题号**：最小移动总距离（#2463，hard）
- **链接**：https://leetcode.cn/problems/minimum-total-distance-traveled/
- **来源**：LeetCode 第 318 场周赛 Q4
- **难度**：困难
- **标签**：数组、动态规划、排序

**题意**：X 轴上有若干坏机器人和工厂。`robot[i]` 表示机器人位置，`factory[j] = [position_j, limit_j]` 表示工厂位置及其最大维修数量。每台机器人最终进入一个尚未达到容量上限的工厂，移动距离为两者位置的绝对差。求维修所有机器人的最小总移动距离。

**约束**：

- $1 \le n = \text{robot.length} \le 100$
- $1 \le m = \text{factory.length} \le 100$
- $-10^9 \le \text{robot}[i],\ \text{factory}[j][0] \le 10^9$
- $0 \le \text{limit}_j \le n$
- 机器人位置互不相同，工厂位置互不相同，但机器人可以与工厂重合
- 测试数据保证所有机器人都能被维修，即 $\sum_j \text{limit}_j \ge n$

> 💡 本题在本仓库另有[每日题解 2463](../../solution/2401-2500/2463_最小移动总距离.md)，其中给出了三维容量 DP 与工厂克隆写法。本篇按周赛复盘视角，使用更直接的「工厂前缀 × 机器人前缀」二维 DP，并重点证明为什么每个工厂只需接收一段连续机器人。

## 2. 示例

**示例 1**

```text
输入：robot = [0,4,6], factory = [[2,2],[6,2]]
输出：4
解释：位置 0、4 的机器人去位置 2 的工厂，距离分别为 2、2；
      位置 6 的机器人去位置 6 的工厂，距离为 0。
      总距离 = 2 + 2 + 0 = 4。
```

**示例 2**

```text
输入：robot = [1,-1], factory = [[-2,1],[2,1]]
输出：2
解释：位置 1 的机器人去位置 2 的工厂，位置 -1 的机器人去位置 -2 的工厂。
      总距离 = |2-1| + |-2-(-1)| = 2。
```

**示例 3**（容量为 0 的工厂直接跳过）

```text
输入：robot = [-3,5], factory = [[0,0],[4,2]]
输出：8
解释：位置 0 的工厂不能维修机器人，两台机器人都去位置 4 的工厂。
      总距离 = |4-(-3)| + |4-5| = 8。
```

## 3. 解题思路

### 3.1 暴力思路

枚举每台机器人被分配到哪个工厂，再检查每个工厂的维修数量是否超过上限。每台机器人最多有 $m$ 种选择，分配方案达到 $O(m^n)$；$n,m$ 均可为 $100$，无法承受。

暴力低效的原因是它把所有分配都看成彼此独立的选择，没有利用**所有位置都在一条直线上**这一结构。

### 3.2 核心观察：最优分配可以不交叉

![交叉配对交换为不交叉配对](images/wc318_q4_noncrossing_assignment.svg)

先将机器人位置、工厂位置分别升序排列。设两台机器人的位置为 $a \le b$，两个工厂的位置为 $c \le d$。若当前分配发生交叉：

- 机器人 $a$ 去较远的工厂 $d$；
- 机器人 $b$ 去较近的工厂 $c$。

交换它们的目的地后，总代价不会增加：

$$
|a-d| + |b-c| \ge |a-c| + |b-d|.
$$

这就是一维绝对值代价的 **Monge 性质**。交换只改变机器人与工厂的对应关系，不改变两个工厂各自的维修人数，因此不会破坏容量约束。

不断消除交叉，就能得到一个**单调不交叉的最优分配**：较靠左的机器人不会分到较靠右机器人之后的工厂。由此得到两个重要结论：

1. 按位置排序后，机器人与工厂可以按顺序处理；
2. 同一个工厂接收的机器人，在排序后的机器人序列中必然是一段**连续区间**。

> 💡 不需要真的枚举交换。这个结论只用于证明：把搜索范围限制在不交叉分配上，不会丢掉最优答案。

### 3.3 状态设计与转移

![二维 DP 的两种转移](images/wc318_q4_dp_transition.svg)

定义：

$$
f[i][j] = \text{前 }i\text{ 个工厂维修前 }j\text{ 台机器人的最小总距离}.
$$

工厂和机器人都已经按位置排序，下标从 $1$ 开始描述状态。考虑第 $i$ 个工厂，其位置为 $p_i$，容量为 $L_i$。

**情况一：不使用第 $i$ 个工厂。**

前 $j$ 台机器人全部由前 $i-1$ 个工厂维修，候选值为：

$$
f[i-1][j].
$$

**情况二：第 $i$ 个工厂维修 $k$ 台机器人。**

由不交叉性质，它维修的一定是当前机器人前缀的最后 $k$ 台，即下标 $j-k,\ldots,j-1$（对应代码的 0 下标）。前 $j-k$ 台由前 $i-1$ 个工厂负责，因此候选值为：

$$
f[i-1][j-k] + \sum_{t=j-k}^{j-1} |\text{robot}[t]-p_i|,
\qquad 1 \le k \le \min(L_i,j).
$$

两种情况取最小值：

$$
f[i][j] = \min\left(
 f[i-1][j],
 \min_{1 \le k \le \min(L_i,j)}
 \left\{f[i-1][j-k] + \sum_{t=j-k}^{j-1}|\text{robot}[t]-p_i|\right\}
\right).
$$

边界为 $f[0][0]=0$，$f[0][j>0]=+\infty$；没有机器人时 $f[i][0]=0$。最终答案为 $f[m][n]$。

### 3.4 算法流程

1. 将 `robot` 按位置升序排列，将 `factory` 按工厂位置升序排列。
2. 创建 $(m+1)\times(n+1)$ 的 DP 表，初始化为 $+\infty$，并设置边界状态。
3. 依次枚举工厂 $i$ 和机器人数量 $j$：
   - 先继承 `dp[i-1][j]`，表示跳过当前工厂；
   - 从第 $j$ 台机器人开始向左扩展连续段，逐个累加它到当前工厂的距离；
   - 扩展长度 $k$ 不超过 $j$ 与当前工厂容量，每次用 `dp[i-1][j-k] + cost` 更新答案。
4. 返回 `dp[m][n]`。

反向扩展连续段时，每增加一台机器人只需 $O(1)$ 累加距离，不必重新遍历整段求和。

### 3.5 示例演算

![示例 1 的分配方案与 DP 表](images/wc318_q4_example_walkthrough.svg)

示例 1 排序后不变：机器人为 $[0,4,6]$，工厂为 $(2,2),(6,2)$。

| 已考虑的工厂 | $j=0$ | $j=1$ | $j=2$ | $j=3$ |
|---|---:|---:|---:|---:|
| 无工厂 | $0$ | $\infty$ | $\infty$ | $\infty$ |
| 位置 2，容量 2 | $0$ | $2$ | $4$ | $\infty$ |
| 位置 2、6 | $0$ | $2$ | $4$ | $\mathbf{4}$ |

最优路径为：

1. 位置 2 的工厂维修机器人 $0,4$，所以 $f[1][2]=2+2=4$；
2. 位置 6 的工厂维修机器人 $6$，增加距离 $0$；
3. $f[2][3]=f[1][2]+0=4$。

第一台工厂容量只有 $2$，所以 $f[1][3]=\infty$；加入第二台工厂后才得到合法答案。

## 4. 算法细节

1. **两个数组都必须排序**：只排序机器人而不排序工厂，无法保证 DP 按工厂前缀处理时仍然对应不交叉分配。C++ 对 `factory` 直接按二元组排序即可，因为工厂位置互不相同。
2. **当前工厂对应末尾连续段**：在状态 $f[i][j]$ 中，如果第 $i$ 个工厂维修 $k$ 台，就必须选择机器人 $j-k,\ldots,j-1$，而不是任意 $k$ 台。这是二维 DP 成立的核心理由。
3. **连续段代价反向累加**：固定 $i,j$ 后，令 `cost = 0`，依次枚举 $k=1,2,\ldots$，每次加入 `abs(robot[j-k] - position)`。这样三层循环的总复杂度是 $O(mn^2)$，不会因再次求区间和而退化为 $O(mn^3)$。
4. **容量为 0 无需特判**：内层 $k$ 的范围为空，只保留“跳过工厂”的转移。
5. **使用 64 位整数**：单次距离最大为 $2\times10^9$，总答案最大约为 $100\times2\times10^9=2\times10^{11}$，必须使用 `long long`。计算距离时也要先提升类型再作差。
6. **不可达状态保留为无穷大**：前面工厂容量不足时，某些 $f[i][j]$ 不可达。最终一定有有限答案，因为题目保证总容量足够。

## 5. 正确性证明

**引理 1（不交叉引理）**：任意一个最优分配都可以转化为机器人与工厂均按位置单调对应的最优分配，且每个工厂接收的机器人构成连续区间。

**证明**：设 $a\le b$ 为两台机器人位置，$c\le d$ 为两个工厂位置。若分配为 $a\to d$、$b\to c$，交换目的地后，由绝对值代价的 Monge 性质：

$$
|a-c|+|b-d|\le|a-d|+|b-c|.
$$

交换前后两个工厂的维修人数不变，因此新分配仍满足容量约束，且总距离不增。每次消除一对交叉都会严格减少配对的逆序数量，故有限次交换后不存在交叉。此时机器人顺序与目的地工厂顺序一致，同一工厂接收的机器人必然是连续区间。∎

**引理 2（状态转移完备性）**：$f[i][j]$ 的两种转移恰好覆盖前 $i$ 个工厂维修前 $j$ 台机器人的所有最优可能，并计算出其最小代价。

**证明**：若第 $i$ 个工厂未使用，问题恰好化为前 $i-1$ 个工厂维修前 $j$ 台机器人，对应 $f[i-1][j]$。若它维修了 $k>0$ 台，由引理 1，在最优不交叉分配中，这 $k$ 台必为当前前缀的末尾 $k$ 台；其余 $j-k$ 台由前 $i-1$ 个工厂维修，其最小代价为 $f[i-1][j-k]$。当前工厂的段代价为 $\sum_{t=j-k}^{j-1}|\text{robot}[t]-p_i|$。枚举所有合法的 $k$ 并取最小值，因此不会遗漏最优方案，也不会计入不合法方案。∎

**定理**：算法返回维修全部 $n$ 台机器人的最小总移动距离。

**证明**：对工厂数量 $i$ 归纳。$i=0$ 时，$j=0$ 的代价为 $0$，$j>0$ 不可达，边界正确。假设前 $i-1$ 个工厂的所有状态均正确，则由引理 2，$f[i][j]$ 的每个候选值都对应一种合法分配，且所有最优分配均被枚举，所以 $f[i][j]$ 正确。归纳至 $i=m$、$j=n$，$f[m][n]$ 就是使用全部工厂维修全部机器人的最小总距离。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n\log n+m\log m+mn^2)$。排序分别需要 $O(n\log n)$ 和 $O(m\log m)$；DP 中每个 $(i,j)$ 最多枚举 $n$ 个连续段长度，且每次只做 $O(1)$ 更新。$n,m\le100$ 时约百万级转移。
- **空间复杂度**：$O(mn)$，用于保存二维 DP 表。由于 $f[i][j]$ 只依赖第 $i-1$ 行，也可滚动压缩到 $O(n)$。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    long long minimumTotalDistance(vector<int>& robot, vector<vector<int>>& factory) {
        sort(robot.begin(), robot.end());
        sort(factory.begin(), factory.end());

        int n = robot.size(), m = factory.size();
        const long long INF = 4e18;
        vector<vector<long long>> dp(m + 1, vector<long long>(n + 1, INF));
        dp[0][0] = 0;

        for (int i = 1; i <= m; ++i) {
            dp[i][0] = 0;
            long long position = factory[i - 1][0];
            int limit = factory[i - 1][1];

            for (int j = 1; j <= n; ++j) {
                dp[i][j] = dp[i - 1][j];
                long long cost = 0;
                for (int k = 1; k <= min(limit, j); ++k) {
                    cost += llabs((long long)robot[j - k] - position);
                    dp[i][j] = min(dp[i][j], dp[i - 1][j - k] + cost);
                }
            }
        }
        return dp[m][n];
    }
};
```

### Python

```python
class Solution:
    def minimumTotalDistance(self, robot: List[int], factory: List[List[int]]) -> int:
        robot.sort()
        factory.sort(key=lambda f: f[0])
        n, m = len(robot), len(factory)
        INF = 10 ** 18
        dp = [[INF] * (n + 1) for _ in range(m + 1)]
        dp[0][0] = 0

        for i in range(1, m + 1):
            dp[i][0] = 0
            position, limit = factory[i - 1]
            for j in range(1, n + 1):
                dp[i][j] = dp[i - 1][j]
                cost = 0
                for k in range(1, min(limit, j) + 1):
                    cost += abs(robot[j - k] - position)
                    dp[i][j] = min(dp[i][j], dp[i - 1][j - k] + cost)

        return dp[m][n]
```

## 8. 边界情况与易错点

1. **机器人与工厂重合**：距离为 $0$，直接计入即可，不需要额外特判。
2. **负坐标与工厂在机器人左侧**：统一使用绝对值，不能假定机器人一定向右移动。
3. **`limit = 0`**：该工厂不能使用，内层枚举自动跳过，只执行继承上一行的转移。
4. **忘记排序工厂**：即使机器人有序，乱序工厂也会破坏“当前工厂维修末尾连续段”的前提。
5. **把连续段写成任意子集**：同一工厂接收的机器人可以不连续的一般分配确实可能存在，但最优解中一定能化为连续段；DP 依赖的是引理 1，而不是题面直接规定。
6. **重复计算段代价**：若每个 $k$ 都重新遍历 $k$ 台机器人，会增加一层复杂度。应从右向左扩展并累加 `cost`。
7. **整数溢出**：坐标作差和总距离都应使用 64 位类型；Python 整数不受此限制。
8. **容量不足的部分状态**：保留 $+\infty$ 并继续处理后续工厂即可，不能提前返回；题目只保证所有工厂合计容量足够。
