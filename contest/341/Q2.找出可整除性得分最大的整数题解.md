# LeetCode 找出可整除性得分最大的整数 题解

## 1. 题目概述

- **标题 / 题号**：找出可整除性得分最大的整数（#2644，easy）
- **链接**：https://leetcode.cn/problems/find-the-maximum-divisibility-score/
- **来源**：LeetCode 第 341 场周赛 Q2
- **难度**：简单
- **标签**：数组、枚举、计数

**题意**：给定整数数组 `nums` 与 `divisors`。`divisors[i]` 的**可整除性得分**定义为 `nums` 中能被 `divisors[i]` 整除的元素个数。返回得分最大的 `divisors[i]`；若多个除数并列最大，返回**数值最小**的那个。

**约束**：

- $1 \le \text{nums.length}, \text{divisors.length} \le 1000$
- $1 \le \text{nums[i]}, \text{divisors[i]} \le 10^9$

> 💡 关键信号：两数组规模都 $\le 1000$，$n \cdot m \le 10^6$，两两枚举取模即可通过；值域却达 $10^9$，值域桶、倍数筛等预处理不可行。**规模小 + 值域大 = 暴力就是正解**。

## 2. 示例

**示例 1**

```text
输入：nums = [2,9,15,50], divisors = [5,3,7,2]
输出：2
解释：5 得分 2（15、50）；3 得分 2（9、15）；7 得分 0；2 得分 2（2、50）。
      5、3、2 三者并列最高分 2，返回数值最小的 2。
```

**示例 2**

```text
输入：nums = [4,7,9,3,9], divisors = [5,2,3]
输出：3
解释：5 得分 0；2 得分 1（仅 4）；3 得分 3（9、3、9）。3 得分最大，返回 3。
```

**示例 3**

```text
输入：nums = [20,14,21,10], divisors = [10,16,20]
输出：10
解释：10 得分 2（20、10）；16 得分 0；20 得分 1（仅 20）。10 得分最大，返回 10。
```

## 3. 解题思路

### 3.1 暴力思路：全部算完再排序

朴素做法：对每个除数算出得分存表，再按「得分降序、数值升序」排序取第一个，复杂度 $O(nm + m \log m)$。正确且能过，但排序是多余的——我们只需要「最大得分 + 并列最小值」。

另一个诱人的简化——直接照搬**同场 Q1** 的「顺序扫描 + 严格大于才换擂」——是**错的**：

- Q1 平局取**下标**最小，而扫描顺序恰好就是下标顺序，单条件天然正确；
- 本题平局取**数值**最小，与出现顺序无关。

反例：`divisors = [5, 3]` 得分同为 2 时，单条件扫描会错留先出现的 5，而正确答案是 3。

### 3.2 核心观察：纯值函数 + 双条件打擂台

![各除数独立计分](images/divscore_independent_counting.svg)

1. **各除数得分互相独立**：第 $i$ 个除数的得分只由它自己与 `nums` 决定，问题是纯计数。$n \cdot m \le 10^6$ 次取模毫秒级完成，无需任何预处理或数据结构。
2. **得分是纯「值」函数**：得分与下标、出现顺序无关，平局规则也基于值（取最小）。把两个目标合成一个比较键 $K(d) = (\mathrm{cnt}(d),\, -d)$ 取**字典序最大**，展开后正是双条件更新：

$$\mathrm{cnt} > \mathrm{bestCnt} \;\;\lor\;\; \bigl(\mathrm{cnt} = \mathrm{bestCnt} \;\land\; d < \mathrm{bestD}\bigr)$$

> 💡 **一句话总结**：并列取数值最小 = 把「数值取负」编进比较键，双条件打擂台一趟完成，连排序都省了。

### 3.3 算法流程

![双条件打擂台流程](images/divscore_tiebreak_flow.svg)

```text
1. 初始化 bestCnt = -1，bestD = 0        // 哨兵：首个除数必然上擂
2. 按输入顺序遍历每个除数 d ∈ divisors：
      cnt = 0
      对每个 x ∈ nums：若 x % d == 0 则 cnt++
      若 cnt > bestCnt 或（cnt == bestCnt 且 d < bestD）：
          bestCnt = cnt，bestD = d
3. 返回 bestD
```

### 3.4 示例演算

![示例演算走查表](images/divscore_walkthrough.svg)

以示例 1 `nums = [2,9,15,50]`、`divisors = [5,3,7,2]` 走查（判定列两个条件依次检查）：

- **步 1**：$d=5$，$\mathrm{cnt}=2$（15、50）。$2 > -1$ ✓ → 上擂，擂主 $(2, 5)$
- **步 2**：$d=3$，$\mathrm{cnt}=2$（9、15）。$2 > 2$ ✗；$2 = 2$ 且 $3 < 5$ ✓ → **平局换擂**，擂主 $(2, 3)$
- **步 3**：$d=7$，$\mathrm{cnt}=0$。两条件均 ✗ → 跳过，擂主不变
- **步 4**：$d=2$，$\mathrm{cnt}=2$（2、50）。$2 > 2$ ✗；$2 = 2$ 且 $2 < 3$ ✓ → **平局换擂**，擂主 $(2, 2)$

返回 `bestD = 2`。

## 4. 算法细节

1. **计数方式**：内层对 `nums` 逐个做 `x % d == 0` 判定并累加；整除判定用取模，不要用「除后乘回」验证（无必要且易错）。
2. **双条件更新**：`cnt > bestCnt || (cnt == bestCnt && d < bestD)`。两个条件分别对应比较键 $K(d)=(\mathrm{cnt}, -d)$ 的两维：第一维求最大（得分），第二维取负后求最大（数值最小）。
3. **初始化哨兵**：`bestCnt = -1`。得分最小为 0，$0 > -1$ 必然成立，保证第一个除数必然上擂，`bestD` 由此获得有效值；`divisors` 非空由约束保证。
4. **等价替代**：先把 `divisors` 升序排序（可顺带去重），即可退化为单条件「严格大于」——排序保证同分者中数值最小者最先出现。多花 $O(m \log m)$，逻辑更短，两种写法都对。
5. **重复除数无害**：相同值的除数得分相同，第二次遇到时两个条件都不满足，不更新也不出错；去重只是常数优化，不影响最坏复杂度。
6. **无溢出**：数值 $\le 10^9 < 2^{31} - 1$，C++ `int` 存得下；$\mathrm{cnt} \le n \le 1000$。

## 5. 正确性证明

**引理 1**：内层循环结束后，`cnt` 等于 $d$ 的可整除性得分 $s(d)$。

**证明**：循环逐一检验每个 $x \in \text{nums}$，当且仅当 $d \mid x$ 时 `cnt` 自增 1，共检验 $n$ 个元素，故 `cnt` 为满足整除的元素个数，即 $s(d)$。∎

**引理 2**（打擂台不变式）：处理完前 $k$ 个除数后，$(\mathrm{bestCnt}, -\mathrm{bestD}) = \max_{1 \le i \le k} \bigl( s(d_i),\, -d_i \bigr)$（字典序最大）。

**证明**：对 $k$ 归纳。$k = 1$ 时 $s(d_1) \ge 0 > -1 = \mathrm{bestCnt}$，第一条件成立，擂主更新为 $d_1$，等式成立。设 $k$ 时成立，处理第 $k+1$ 个除数 $d$。注意字典序比较可展开为

$$(s(d), -d) > (\mathrm{bestCnt}, -\mathrm{bestD}) \iff s(d) > \mathrm{bestCnt} \;\lor\; \bigl( s(d) = \mathrm{bestCnt} \land -d > -\mathrm{bestD} \bigr),$$

而 $-d > -\mathrm{bestD} \iff d < \mathrm{bestD}$，故程序中的更新条件**恰是**「新键严格大于当前擂主键」。触发时擂主变为 $d$，不触发时擂主不变；两种情形下擂主均为前 $k+1$ 个键的最大者，不变式得以延续。∎

**定理**：算法返回可整除性得分最大的除数中数值最小者。

**证明**：由引理 1、2，处理完全部 $m$ 个除数后 $(\mathrm{bestCnt}, -\mathrm{bestD})$ 是所有键的最大者：第一维 $\mathrm{bestCnt}$ 最大即得分最大；在得分最大的前提下第二维 $-\mathrm{bestD}$ 最大即 $\mathrm{bestD}$ 数值最小。故 `bestD` 即所求。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \cdot m)$。外层 $m$ 个除数、内层 $n$ 次取模，共 $\le 10^6$ 次基本运算，毫秒级。
- **空间复杂度**：$O(1)$。仅维护 `bestCnt`、`bestD`、`cnt` 三个标量（不计输入）。

> ⚠️ 不宜声称 $O(nm)$ 是该问题的下界：规模放大后可用「对每个 $\text{num}$ 在 $O(\sqrt{v})$ 内枚举因子」绕开两两检查（见延伸思考），本题的最优性是**针对签到级数据规模**而言的。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int maxDivScore(vector<int>& nums, vector<int>& divisors) {
        int bestCnt = -1, bestD = 0;
        for (int d : divisors) {
            int cnt = 0;
            for (int x : nums) cnt += (x % d == 0);
            if (cnt > bestCnt || (cnt == bestCnt && d < bestD)) {
                bestCnt = cnt;
                bestD = d;
            }
        }
        return bestD;
    }
};
```

### Python

```python
class Solution:
    def maxDivScore(self, nums: List[int], divisors: List[int]) -> int:
        best_cnt, best_d = -1, 0
        for d in divisors:
            cnt = sum(x % d == 0 for x in nums)
            if cnt > best_cnt or (cnt == best_cnt and d < best_d):
                best_cnt, best_d = cnt, d
        return best_d
```

## 8. 边界情况与易错点

1. **平局取数值最小，不是下标最小**：照搬 Q1 的单条件「严格大于」会在平局时错留**先出现**的除数。反例：`divisors = [5,3]` 同得 2 分，单条件错返 5，正确答案 3。（先升序排序可规避。）
2. **两个条件都别写反**：`d < bestD` 写成 `d > bestD` 会保留数值最大者；`==` 误写为其他关系则平局判定失效。
3. **全部得分为 0**：如 `nums = [7]`、`divisors = [5,3,2]`，得分全 0，应返回最小的 2。哨兵 `bestCnt = -1` 保证首个除数上擂后，靠第二条件继续把擂主换成更小值。
4. **bestCnt 别初始化为 0**：得分为 0 的首个除数不会上擂（$0 > 0$ 为假），`bestD` 停留在无效初值；若初值恰为 0 则直接返回错误答案 0。
5. **除数无 0**：约束 $\text{divisors[i]} \ge 1$，取模无除零风险，无需特判。
6. **重复除数**：无害，同值同分不触发更新；介意性能可去重（不改变最坏复杂度）。
7. **外层必须枚举除数**：擂主按除数记录；若外层枚举 `nums`，则需 $O(m)$ 得分数组 + 二次扫描，代码更绕。

**延伸思考**：

- **规模放大**：若 $n, m \le 10^5$，$O(nm) \approx 10^{10}$ 不可行。可对每个 $x \in \text{nums}$ 在 $O(\sqrt{x})$ 内枚举其全部因子，用哈希表累计「因子 → 可整除的 $x$ 个数」（总代价 $O(n\sqrt{v})$）；查询时每个去重后的 $d$ 查表得得分（查不到记 0），再按双条件打擂。注意得分全 0 时答案取 $\min(\text{divisors})$，仍由平局规则自然覆盖。
