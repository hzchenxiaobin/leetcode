# LeetCode 最小化旅行的价格总和 题解

## 1. 题目概述

- **标题 / 题号**：最小化旅行的价格总和（#2646，hard）
- **链接**：https://leetcode.cn/problems/minimize-the-total-price-of-the-trips/
- **来源**：LeetCode 第 341 场周赛 Q4
- **难度**：困难
- **标签**：树、深度优先搜索、树形 DP、动态规划、打家劫舍

**题意**：给一棵 $n$ 个节点的**无向、无根**树（边集 `edges`），节点 $v$ 的价格为 $\mathrm{price}[v]$。另给 $m$ 次旅行 `trips`，第 $i$ 次从 $\text{start}_i$ 走到 $\text{end}_i$，一条旅行的代价是其路径上**所有节点**的价格之和。在**所有旅行开始之前**，可以选**一些两两不相邻的节点**，把它们的**价格减半**。求所有旅行的价格总和的最小值。

**约束**：

- $1 \le n \le 50$，`edges.length == n − 1`
- $1 \le \mathrm{price}[i] \le 1000$，且 **$\mathrm{price}[i]$ 为偶数**
- $1 \le \text{trips.length} \le 100$，$0 \le \text{start}_i, \text{end}_i \le n-1$

> 💡 关键信号有两条：**「树」+「路径价格」**——树中任意两点路径唯一，旅行怎么走是定死的，不存在「选路」决策；**「非相邻节点减半」**——这是独立集的标志性约束，直接联想到树上打家劫舍。两条信号拼起来，就是「先数频次、再做树形 DP」的两阶段解法。

## 2. 示例

**示例 1**

```text
输入：n = 4, edges = [[0,1],[1,2],[1,3]], price = [2,2,10,6], trips = [[0,3],[2,1],[2,3]]
输出：23

解释：选择节点 0、2、3 减半（三者两两不相邻）。
      旅行 [0,3] 走 0→1→3，代价 1+2+3 = 6；
      旅行 [2,1] 走 2→1，代价 5+2 = 7；
      旅行 [2,3] 走 2→1→3，代价 5+2+3 = 10；
      总和 6+7+10 = 23。
```

**示例 2**

```text
输入：n = 2, edges = [[0,1]], price = [2,2], trips = [[0,0]]
输出：1

解释：选择节点 0 减半；旅行 [0,0] 的路径只含节点 0 自身，代价 1。
```

**示例 3（补充：贪心反例）**

```text
输入：n = 3, edges = [[0,1],[1,2]], price = [10,12,10], trips = [[0,2]]
输出：22

解释：路径 0→1→2，freq = [1,1,1]，total = 32，w = [5,6,5]。
      若贪心选权值最大的节点 1 减半：节省 6，答案 32−6 = 26；
      正确方案选两端 {0,2}（不相邻）：节省 5+5 = 10，答案 32−10 = 22。
```

## 3. 解题思路

### 3.1 暴力思路：枚举减半集合

最直接的做法是枚举「哪些节点减半」：$2^n$ 个子集，对每个子集先验证两两不相邻，再对每条旅行累加路径价格。$n \le 50$ 时 $2^{50}$ 直接爆炸；而且「给每条旅行找路径」这件事被重复执行了 $2^n$ 次，纯属浪费。

另一个诱人但**错误**的捷径是贪心：按 $\mathrm{price}[v]\cdot\mathrm{freq}[v]$ 从大到小逐个选点、跳过已选点的邻居——示例 3 就是反例：权值最大的中间点一旦选下就堵死两端，而两端合计反而更省。局部最优与独立集的全局约束冲突，必须整体求解，也就是 DP。

### 3.2 核心观察：路径唯一 ⟹ 频次统计 + 树上打家劫舍

![示例1三条旅行叠加与频次](images/min_trip_price_tree_path.svg)

**观察 1（路径唯一）**：树连通无环，任意两点间的简单路径**唯一**。因此每条旅行经过的节点集合与减半方案无关，是先验确定的。对每条旅行做一次 DFS 找路径，即可统计每个节点被经过的次数 $\mathrm{freq}[v]$。

**观察 2（费用分解）**：节点 $v$ 的价格影响且只影响经过它的旅行，恰共 $\mathrm{freq}[v]$ 次。若一个节点都不减半，总价为

$$\mathrm{total} = \sum_{v} \mathrm{price}[v] \cdot \mathrm{freq}[v]$$

**观察 3（减半 = 独立集）**：把 $v$ 减半恰省下 $\mathrm{price}[v]\cdot\mathrm{freq}[v]/2$，记 $w(v) = \mathrm{price}[v]\cdot\mathrm{freq}[v]/2$（$\mathrm{price}$ 为偶数保证 $w(v)$ 是整数）。「非相邻」正是**独立集**的约束：

![核心转化：频次统计与树上打家劫舍](images/min_trip_price_transform.svg)

$$\text{答案} = \mathrm{total} - \max_{S\ \text{为独立集}} \sum_{v \in S} w(v)$$

最大化 $\sum w$ 的独立集就是**树上打家劫舍**（最大权独立集），用树形 DP 求解。

### 3.3 算法流程：两阶段

**阶段① 频次统计**：对每条旅行 $(\text{start}, \text{end})$ 从 `start` 出发 DFS，命中 `end` 后沿途回传 `true`，回传链上的节点 $\mathrm{freq}{+}{+}$——一次 DFS 就标出整条路径。

**阶段② 树形 DP**：任取根（如 0），后序遍历：

![树形DP状态转移](images/min_trip_price_dp_model.svg)

- $dp[u][0]$：$u$ **不减半**时子树内最大节省，孩子随意：

$$dp[u][0] = \sum_{c} \max(dp[c][0],\ dp[c][1])$$

- $dp[u][1]$：$u$ **减半**时子树内最大节省，孩子必不减半：

$$dp[u][1] = w(u) + \sum_{c} dp[c][0]$$

答案 $= \mathrm{total} - \max(dp[r][0],\ dp[r][1])$。

### 3.4 示例演算

![示例1演算表](images/min_trip_price_walkthrough.svg)

以示例 1 走查（根取 0）：

- **频次与权值**：三条路径 $0\text{-}1\text{-}3$、$2\text{-}1$、$2\text{-}1\text{-}3$ 叠加，$\mathrm{freq} = [1,3,2,2]$，$\mathrm{total} = 2+6+20+12 = 40$，$w = [1,3,10,6]$。
- **后序 DP**（先叶后根，$2 \to 3 \to 1 \to 0$）：
  - 叶 2：$dp_0=0$，$dp_1=10$；叶 3：$dp_0=0$，$dp_1=6$
  - 节点 1：$dp_0=\max(0,10)+\max(0,6)=16$；$dp_1=3+0+0=3$（1 减半则孩子 2、3 必不减半）
  - 节点 0：$dp_0=\max(16,3)=16$；$dp_1=1+16=17$（0 减半，孩子 1 取不减半的最优 $dp_0=16$）
- **回溯方案**：根 0 取 $dp_1$（减半），节点 1 取 $dp_0$（不减半），2、3 各取 $dp_1$（减半）$\Rightarrow S=\{0,2,3\}$，与官方解释一致。
- **答案**：$40-\max(16,17)=40-17=23$ ✓

## 4. 算法细节

1. **找路径的「回传」技巧**：`findPath(u, fa, target)` 命中 `target` 时返回 `true`；任一子树回传 `true` 时当前节点 $\mathrm{freq}{+}{+}$ 并继续向上回传。这样**只有** `start→end` 路径上的节点被计数，其余节点天然不受污染——无需显式路径数组，也无需「先加后试、失败回退」的回溯写法。
2. **根的选取**：无根树的「相邻」是边关系，与根无关。阶段② 任取节点（如 0）为根做后序 DP 即可；两个 DFS（找路径、DP）都要记录父节点防止沿来路折返。
3. **权值整数性**：$\mathrm{price}$ 全为偶数 $\Rightarrow w(v)=\mathrm{price}[v]\cdot\mathrm{freq}[v]/2$ 恒为整数，全程整数运算，无精度问题。
4. **值域核算**：每条旅行至多经过 $v$ 一次，故 $\mathrm{freq}[v] \le m \le 100$，$\mathrm{total} \le 50 \times 1000 \times 100 = 5\times10^6$，`int` 即可，无溢出风险。
5. **一次返回两态**：DP 的 DFS 同时返回 $(dp_0, dp_1)$ 二元组，避免对每个状态各遍历一次。

## 5. 正确性证明

**引理 1（路径唯一）**：每条旅行的最优走法是唯一确定的简单路径，其节点集合固定。

**证明**：树中任意两点的简单路径唯一——若存在两条不同的 $x \to y$ 简单路径，二者的对称差构成环，与树无环矛盾。又价格按**节点**计且恒正，任何非简单的走法都包含一条简单路径作为节点子序列，删去绕圈部分只会去掉（重复的）节点、代价不增，故旅行总走该唯一简单路径。∎

**引理 2（费用分解）**：对任意减半集合 $S$（暂不要求合法），所有旅行的总价为

$$C(S) = \sum_{v} \mathrm{price}[v]\cdot\mathrm{freq}[v] \;-\; \sum_{v \in S} \frac{\mathrm{price}[v]\cdot\mathrm{freq}[v]}{2}$$

**证明**：由引理 1，每条旅行的节点集合先验固定，$v$ 恰被 $\mathrm{freq}[v]$ 条旅行经过。按节点归并求和：总价 $= \sum_{v} c_S(v)\cdot\mathrm{freq}[v]$，其中 $c_S(v)$ 为 $v$ 减半后的单价。代入 $c_S(v)=\mathrm{price}[v]-\frac{\mathrm{price}[v]}{2}[v \in S]$ 即得上式。∎

**引理 3（合法方案刻画）**：$S$ 是合法减半集合 $\iff$ $S$ 是独立集，且最小总价 $= \mathrm{total} - \max\{\sum_{v\in S} w(v) : S\ \text{独立}\}$，其中 $w(v)=\mathrm{price}[v]\cdot\mathrm{freq}[v]/2$。

**证明**：题设「非相邻」即独立集约束。由引理 2，$C(S)=\mathrm{total}-\sum_{v\in S}w(v)$ 对一切 $S$ 成立，合法性与其余部分无关，故最小化 $C$ 等价于在独立集上最大化 $\sum w$。∎

**引理 4（DP 最优子结构）**：以任意 $r$ 为根，$dp[u][0]$、$dp[u][1]$ 分别等于「在子树 $T_u$ 内选独立集、且 $u$ 不选 / 选」时 $\sum w$ 的最大值。

**证明**：对子树大小归纳。叶子 $u$：不选节省 $0$、选节省 $w(u)$，与定义一致。归纳步骤：设 $u$ 的孩子为 $c_1,\dots,c_k$，各孩子子树互不相交、仅经 $u$ 相连，子树间的独立集约束只发生在边 $(u,c_i)$ 上。

- $u$ 被选：每条边 $(u,c_i)$ 都要求 $c_i$ 不选，各子树内部独立取最优，最大节省 $=w(u)+\sum_i dp[c_i][0]$；
- $u$ 不选：$c_i$ 选或不选均不受 $u$ 限制，各子树独立取两态较优者，最大节省 $=\sum_i \max(dp[c_i][0],dp[c_i][1])$。

两种情况分别遍历了该状态下子树间全部合法组合，故均为该状态的最大值。∎

**定理**：算法返回所有旅行总价的最小值。

**证明**：任一独立集 $S$ 按根 $r$ 是否属于 $S$ 二分，由引理 4 的两状态恰好覆盖，故 $\max(dp[r][0],dp[r][1])=\max_{S\,\text{独立}}\sum_{v\in S}w(v)$。又由引理 1，`freq` 统计正确；由引理 3，最小总价 $=\mathrm{total}-\max\sum w$。算法输出即最小总价。∎

## 6. 复杂度分析

- **时间复杂度**：$O(nm + n)$。阶段① 每条旅行一次 DFS 至多 $O(n)$，共 $m \le 100$ 条；阶段② 树形 DP 每个节点处理一次 $O(n)$。$n \le 50$ 时总计不超过约 $5\times10^3$ 次基本操作。
- **空间复杂度**：$O(n)$。邻接表、`freq` 数组与两个递归栈（深度 $\le n$）。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int minimumTotalPrice(int n, vector<vector<int>>& edges, vector<int>& price,
                          vector<vector<int>>& trips) {
        vector<vector<int>> g(n);
        for (auto& e : edges) {
            g[e[0]].push_back(e[1]);
            g[e[1]].push_back(e[0]);
        }

        // 阶段①：命中 target 后沿途回传 true，路径节点 freq++
        vector<int> freq(n, 0);
        function<bool(int, int, int)> findPath = [&](int u, int fa, int target) {
            if (u == target) {
                freq[u]++;
                return true;
            }
            for (int v : g[u]) {
                if (v == fa) continue;
                if (findPath(v, u, target)) {
                    freq[u]++;
                    return true;
                }
            }
            return false;
        };
        for (auto& t : trips) findPath(t[0], -1, t[1]);

        // 阶段②：返回 (u 不减半的最大节省, u 减半的最大节省)
        function<pair<int, int>(int, int)> dfs = [&](int u, int fa) -> pair<int, int> {
            int dp0 = 0, dp1 = price[u] * freq[u] / 2;
            for (int v : g[u]) {
                if (v == fa) continue;
                auto [c0, c1] = dfs(v, u);
                dp0 += max(c0, c1);  // u 不减半，孩子随意
                dp1 += c0;          // u 减半，孩子必不减半
            }
            return {dp0, dp1};
        };

        int total = 0;
        for (int i = 0; i < n; i++) total += price[i] * freq[i];
        auto [s0, s1] = dfs(0, -1);
        return total - max(s0, s1);
    }
};
```

### Python

```python
class Solution:
    def minimumTotalPrice(self, n: int, edges: List[List[int]], price: List[int],
                          trips: List[List[int]]) -> int:
        g = [[] for _ in range(n)]
        for a, b in edges:
            g[a].append(b)
            g[b].append(a)

        # 阶段①：命中 target 后沿途回传 True，路径节点 freq++
        freq = [0] * n

        def find_path(u: int, fa: int, target: int) -> bool:
            if u == target:
                freq[u] += 1
                return True
            for v in g[u]:
                if v != fa and find_path(v, u, target):
                    freq[u] += 1
                    return True
            return False

        for s, e in trips:
            find_path(s, -1, e)

        # 阶段②：返回 (u 不减半的最大节省, u 减半的最大节省)
        def dfs(u: int, fa: int):
            dp0, dp1 = 0, price[u] * freq[u] // 2
            for v in g[u]:
                if v == fa:
                    continue
                c0, c1 = dfs(v, u)
                dp0 += max(c0, c1)  # u 不减半，孩子随意
                dp1 += c0           # u 减半，孩子必不减半
            return dp0, dp1

        total = sum(price[i] * freq[i] for i in range(n))
        s0, s1 = dfs(0, -1)
        return total - max(s0, s1)
```

## 8. 边界情况与易错点

1. **start == end 的旅行**（示例 2 的 `[0,0]`）：路径只含单点，`findPath` 在入口处 `u == target` 命中即可，`freq[start]++` 一次，后续 DP 照常工作，无需特判。
2. **贪心选点**：按 $w$ 从大到小逐个选、跳过邻居的贪心不正确（示例 3 反例：权最大的中间点堵死两端），必须整体求最大权独立集。
3. **找路径写成「先加后试、失败回退」**：若用 `freq[u]++; ...; freq[u]--` 的回溯写法，漏掉回退会把不在路径上的节点也计入。推荐「回传 true」写法，天然只标记真实路径。
4. **DP 加错权**：$dp[u][1]$ 加的是**节省** $w(u)=\mathrm{price}\cdot\mathrm{freq}/2$，不是 $\mathrm{price}\cdot\mathrm{freq}$；最终是 $\mathrm{total}-\max(\text{两态})$，别写成减 $\min$ 或直接返回 DP 值。
5. **忘记记录父节点**：树上两个 DFS 都必须带 `fa` 参数，否则沿来路折返导致死循环 / 栈溢出。
6. **减半的语义**：是在**所有旅行开始前**一次性选定集合、节点**单价**减半，之后所有旅行按新价计——不是每次旅行各选一次，也不是只对某条旅行打折。
7. **$n=1$**：`edges` 为空，旅行必为 `[0,0]`，`freq[0]=m`，代码无需特判自然正确。
8. **数值范围**：$\mathrm{total} \le 5\times10^6$，C++ `int` 足够；Python 无溢出之虞，但 `//` 整除不可写成 `/`（浮点）。

**延伸思考**：

- **规模放大**：若 $n, m$ 达 $10^5$，阶段① 的逐旅行 DFS（$O(nm)$）成为瓶颈。改用 **LCA + 树上差分**：对每条旅行 $(s,e)$ 记 $\mathrm{lca}=l$，打标记 $\mathrm{diff}[s]{+}{+},\ \mathrm{diff}[e]{+}{+},\ \mathrm{diff}[l]{-}{-},\ \mathrm{diff}[\mathrm{fa}(l)]{-}{-}$，一次自底向上求子树和即得 `freq`，复杂度降为 $O((n+m)\log n)$；树形 DP 部分原样保留。
- **一般图版本**：若把树换成一般无向图，路径不再唯一，「选路」与「减半」两个决策耦合（路径选择依赖减半方案），解耦失败，问题难度骤增——本题的可解性正建立在「树 ⟹ 路径唯一」上。
- **折扣变体**：减半推广为降价 $\frac{1}{k}$：转化完全不变，$w(v)=\mathrm{price}[v]\cdot\mathrm{freq}[v]\cdot\frac{k-1}{k}$，整数性由 $\mathrm{price}[v]\cdot\mathrm{freq}[v]$ 能否被 $k$ 整除决定。
