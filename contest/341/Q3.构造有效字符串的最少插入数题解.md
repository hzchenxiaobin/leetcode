# LeetCode 构造有效字符串的最少插入数 题解

## 1. 题目概述

- **标题 / 题号**：构造有效字符串的最少插入数（#2645，medium）
- **链接**：https://leetcode.cn/problems/minimum-additions-to-make-valid-string/
- **来源**：LeetCode 第 341 场周赛 Q3
- **难度**：中等
- **标签**：贪心、字符串、栈、动态规划

**题意**：给定仅含 `a`、`b`、`c` 的字符串 `word`，可在任意位置插入 `a`/`b`/`c` 任意次。若一个字符串能由 `"abc"` 串联若干次得到，则称其**有效**。返回使 `word` 变为有效字符串所需的最少插入次数。

**约束**：

- $1 \le \text{word.length} \le 50$
- `word` 仅由字母 `a`、`b`、`c` 组成

> 💡 关键信号：目标形态唯一（$("abc")^G$）且字母表只有三个。问题的本质不是「模拟在哪里插入」，而是**把 word 对齐进若干个 "abc" 组**，求最少组数——一旦想通这一层，连目标串都不用构造。

## 2. 示例

**示例 1**

```text
输入：word = "b"
输出：2
解释：在 "b" 前插 "a"、后插 "c"，得到 "abc"。
```

**示例 2**

```text
输入：word = "aaa"
输出：6
解释：每个 "a" 后依次插入 "b"、"c"，得到 "abcabcabc"。
```

**示例 3**

```text
输入：word = "abc"
输出：0
解释：word 已是有效字符串，无需修改。
```

**示例 4（补充）**

```text
输入：word = "abcacb"
输出：3
解释："abc" 自成一组；"ac" 中间补 "b" 成一组；"b" 前后补 "a"、"c" 成一组，
      得到 "abcabcabc"，共插入 3 个字符。
```

**示例 5（补充：相等也必须断开）**

```text
输入：word = "aa"
输出：4
解释：两个 "a" 不能同组（一组内三个字符互异），需拆成 "abc" + "abc"。
```

## 3. 解题思路

### 3.1 暴力思路：枚举组数 + 子序列判定

最朴素的思路是 BFS/DFS 枚举插入：每个空位可插 3 种字母或不插，分支因子 4、深度不定，方案数指数膨胀，完全不可行。

退一步的可行暴力：**组数 $G$ 从 1 起递增枚举**，用双指针判定 `word` 是否为 $("abc")^G$ 的子序列，取首个可行的 $G$。可行性关于 $G$ 单调（$("abc")^G$ 是 $("abc")^{G+1}$ 的前缀，故 $G$ 可行 $\Rightarrow G+1$ 可行），且 $G^\* \le D + 1 \le n$，总复杂度 $O(n^2)$——$n \le 50$ 下轻松通过。

> ⚠️ 这已经能过，但每个 $G$ 都要从头扫一遍 `word`，重复劳动。真正的问题——$G^\*$ 到底由什么决定——还没有被提炼出来。

### 3.2 核心观察：插入数 = 3G − n，最小化 G ⇔ 数断点

![有效串结构与子序列对齐](images/valid_str_min_add_target_structure.svg)

1. **目标形态唯一**：有效串只能是 $("abc")^G$（$G$ 组），长度 $3G$，别无选择。
2. **word 必是目标串的子序列**：插入只加字符不删字符，故 $G$ 可行 $\iff$ `word` 是 $("abc")^G$ 的子序列。
3. **插入数 $= 3G - n$**：$n$ 固定，**最少插入 $\iff$ 最小组数 $G^\*$**。

那 $G^\*$ 怎么求？关键在 `"abc"` 组内的字符**严格递增**且**互异**：

![断点必跨组与分段装组](images/valid_str_min_add_breakpoint_bound.svg)

- **断点必跨组（下界）**：同组内相邻两个被匹配的字符必须满足 $\text{word}[i-1] < \text{word}[i]$。因此凡 $\text{word}[i] \le \text{word}[i-1]$（下降**或相等**）处，前后两字符必然分属不同组——每个这样的「断点」都强制消耗一个组边界。
- **分段恰好装下（上界）**：在所有断点处切开 `word`，得到 $D+1$ 段（$D$ 为断点数），每段严格递增；而 `"abc"` 的子序列**恰好就是全部严格递增序列**，于是每段独立塞进一个组即可。

两方向夹逼，断点数直接定死组数：

$$G^\* = D + 1, \qquad D = \#\{\, i \ge 1 : \text{word}[i] \le \text{word}[i-1] \,\}$$

$$\text{答案} = 3G^\* - n$$

> 💡 **一句话总结**：不用构造、不用模拟插入——数一遍「相邻字符不严格递增」的位置，组数就出来了，答案 $3(D+1) - n$ 一步到位。

### 3.3 算法流程

![断点计数流程图](images/valid_str_min_add_flow.svg)

```text
1. G = 1                          # 至少一组
2. 对 i = 1 … n−1 扫描：
       若 word[i] <= word[i−1]：   # 相等也算断点
           G = G + 1              # 此处必须开新组
3. 返回 3 * G − n
```

**等价写法（周期游标贪心）**：维护游标 $j$ 沿 `"abc"` 周期循环（$0 \to 1 \to 2 \to 0 \to \cdots$）表示当前期望字符；`word` 的字符与期望相符则消耗它并推进 $j$，不相符则视为插入一个字符、只推进 $j$；扫描结束后补全末组 $\text{ans} \mathrel{+}= (3 - j) \bmod 3$。该贪心恰好把每个极大严格递增段压进同一组、在每个断点处换组，故算出的组数与断点计数一致（见 §4）。

### 3.4 示例演算

![示例演算 abcacb](images/valid_str_min_add_walkthrough.svg)

以 `word = "abcacb"`（$n = 6$）走查：

| 步 | 相邻对 | 比较 | 断点？ | 累计 $G$ |
|----|--------|------|--------|------|
| 1 | $(a, b)$ | $b > a$ | 否 | 1 |
| 2 | $(b, c)$ | $c > b$ | 否 | 1 |
| 3 | $(c, a)$ | $a \le c$ | **是** ✂ 开新组 | 2 |
| 4 | $(a, c)$ | $c > a$ | 否 | 2 |
| 5 | $(c, b)$ | $b \le c$ | **是** ✂ 开新组 | 3 |

- 断点数 $D = 2$，组数 $G^\* = 3$：按断点切段得 $\underbrace{abc}_{\text{组 1}} \mid \underbrace{ac}_{\text{组 2}} \mid \underbrace{b}_{\text{组 3}}$。
- 组 2 补 1 个字符（`b`），组 3 补 2 个字符（`a`、`c`），答案 $= 3 \times 3 - 6 = 3$，目标串 `"abcabcabc"`。

再用官方示例交叉验证：`"b"` 无断点，$G = 1$，$3 - 1 = 2$ ✓；`"aaa"` 两个断点，$G = 3$，$9 - 3 = 6$ ✓；`"abc"` 无断点，$G = 1$，$3 - 3 = 0$ ✓。

## 4. 算法细节

1. **断点判定用 $\le$ 而非 $<$**：`"abc"` 组内三字符**互异**且严格递增，相等字符（如 `"aa"`）同样不能同组，必须同样开新组。
2. **组数从 1 起计数**：$G = 1 + D$。$n = 1$ 时循环体不执行，$G = 1$、答案恒为 2，天然覆盖单字符用例。
3. **下界自动满足**：每段严格递增故长度 $\le 3$，断点计数自动保证 $G \ge \lceil n/3 \rceil$，无需额外取 $\max$。
4. **两种写法等价**：周期游标贪心的「最早合法位置」策略在每个断点处恰好走完当前组剩余位置、开新组消耗字符，与断点计数的分段一一对应；游标写法多出的只是末组补全 $(3-j) \bmod 3$。
5. **字符比较用天然字典序**：`a` < `b` < `c`，直接 `word[i] <= word[i-1]`，无需映射成数字。
6. **无溢出风险**：$3G \le 3n \le 150$，整型绰绰有余；无空串（$n \ge 1$），无需特判。

## 5. 正确性证明

**引理 1（目标刻画）**：`word` 能通过插入 $k$ 个字符变得有效 $\iff$ 存在正整数 $G$ 使 `word` 是 $("abc")^G$ 的子序列，且此时最少插入数为 $3G - n$。

**证明**：（$\Rightarrow$）设插入 $k$ 个字符后得到有效串 $T$，则 $T$ 形如 $("abc")^G$；插入只在 `word` 中加入字符，故 `word` 是 $T$ 的子序列，且 $n + k = |T| = 3G$，即 $k = 3G - n$。（$\Leftarrow$）若 `word` 是 $("abc")^G$ 的子序列，任取一组匹配位置，把 $T$ 中其余字符作为「插入」加回 `word` 即得 $T$，使用插入数 $3G - n$。对可行 $G$ 取最小值，最少插入数为 $3G^\* - n$。∎

**引理 2（下界）**：若 `word` 是 $("abc")^G$ 的子序列（任取一组匹配方案），则 $G \ge D + 1$，其中 $D$ 为断点数。

**证明**：设 $\text{word}[i]$ 匹配到 $("abc")^G$ 中的某位置。若 $\text{word}[i-1]$ 与 $\text{word}[i]$ 匹配到**同一组**，则组内匹配位置递增，而组内位置 $0,1,2$ 上的字符依次为 `a`、`b`、`c`（严格递增、互异），故 $\text{word}[i-1] < \text{word}[i]$。逆否即：断点处 $\text{word}[i] \le \text{word}[i-1]$，两字符必属不同组，其匹配位置之间至少隔一个组边界。第 $i$ 个断点对应的边界严格位于 $\text{word}[i-1]$、$\text{word}[i]$ 的匹配位置之间；不同断点的这种区间两两不交（第 $i$ 个断点的区间止于 $\text{word}[i]$ 之前，第 $j > i$ 个断点的区间起于 $\text{word}[j-1]$ 之后，而 $\text{word}[j-1]$ 不早于 $\text{word}[i]$），故各断点对应的组边界互不相同，$G$ 组至多有 $G-1$ 个内部边界，于是 $G - 1 \ge D$，即 $G \ge D + 1$。∎

**引理 3（上界）**：`word` 是 $("abc")^{D+1}$ 的子序列。

**证明**：在每个断点处把 `word` 切成 $D+1$ 段，每段严格递增。$\{a,b,c\}$ 上的非空严格递增序列只有 $a$、$b$、$c$、$ab$、$ac$、$bc$、$abc$ 七种，逐一检验都是 `"abc"` 的子序列。把第 $k$ 段匹配到第 $k$ 个 `"abc"` 组：段内匹配位置递增、段间组号递增，整体匹配位置严格递增，构成 $("abc")^{D+1}$ 的一个合法子序列匹配。∎

**定理**：最少插入数 $= 3(D+1) - n$，其中 $D = \#\{\, i \ge 1 : \text{word}[i] \le \text{word}[i-1] \,\}$。

**证明**：由引理 1，最少插入数为 $3G^\* - n$，其中 $G^\*$ 为使 `word` 成为 $("abc")^G$ 子序列的最小 $G$。由引理 2，$G^\* \ge D + 1$；由引理 3，$D + 1$ 可行，故 $G^\* \le D + 1$。两向夹逼得 $G^\* = D + 1$，代入即得 $3(D+1) - n$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。一趟扫描，每个相邻字符对做一次比较；断点计数与最终 $3G - n$ 均为 $O(1)$。
- **空间复杂度**：$O(1)$。仅维护组数计数器与循环下标，不构造任何字符串。

> ⚠️ $n \le 50$ 是「签到级」规模，$O(n^2)$ 枚举组数也能过；但断点计数是 $n$ 放大到 $10^6$ 也原样成立的线性解，值得作为最终形态提交。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int addMinimum(string word) {
        int n = word.size(), groups = 1;
        for (int i = 1; i < n; i++) {
            if (word[i] <= word[i - 1]) groups++;
        }
        return groups * 3 - n;
    }
};
```

### Python

```python
class Solution:
    def addMinimum(self, word: str) -> int:
        groups = 1
        for a, b in zip(word, word[1:]):
            if b <= a:
                groups += 1
        return groups * 3 - len(word)
```

**等价写法：周期游标贪心**（结果与断点计数一致，见 §4 第 4 条）：

```python
class Solution:
    def addMinimum(self, word: str) -> int:
        pat, j, ans = "abc", 0, 0
        for ch in word:
            while ch != pat[j]:
                ans += 1
                j = (j + 1) % 3
            j = (j + 1) % 3
        return ans + (3 - j) % 3
```

## 8. 边界情况与易错点

1. **断点判定误用 $<$**：相等字符不能同组（组内互异）。`"aa"` 用 $<$ 误判为一段，$G=1$ 得答案 1；正确 $G=2$，答案 4（`"abcabc"`）。
2. **组数初值漏 1**：$G$ 从 1 起而不是从 0 起。`"b"` 无断点，若初值为 0 会错算成 $3 \times 0 - 1 = -1$；正确答案 2。
3. **单字符输入**：$n=1$ 时循环不执行，`"a"`/`"b"`/`"c"` 答案均为 2（前后各补一个字符），说明「任意位置插入」确实允许插在两侧。
4. **已有效串的「回绕」不是断言**：`"abcabc"` 中有一处 $c \to a$ 断点，$G = 2$、答案恰为 0——回绕断点只贡献组号 +1，不产生插入，不要误以为断点多就是没对齐。
5. **答案上界**：全同字符（如 `"aaa"`）时 $D = n-1$、$G = n$，答案 $2n \le 100$，无溢出之虞。
6. **游标写法漏末组补全**：周期游标贪心忘记 $(3 - j) \bmod 3$ 时，`"b"` 只算出 1，错。断点计数法没有这个坑。
7. **别真的构造目标串**：任何「生成 ("abc")^G 再逐位比对」的写法都是无用功，计数即可。
