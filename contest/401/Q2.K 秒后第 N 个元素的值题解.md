# LeetCode K 秒后第 N 个元素的值 题解

## 1. 题目概述

- **标题 / 题号**：K 秒后第 N 个元素的值（#3179，medium）
- **链接**：https://leetcode.cn/problems/find-the-n-th-value-after-k-seconds/
- **来源**：LeetCode 第 401 场周赛 Q2
- **难度**：中等
- **标签**：数组、数学、组合数学、前缀和、模拟

**题意**：初始有一个长度为 $n$ 的数组 $a$，所有元素均为 $1$。每过一秒，**同时**把每个元素更新为「它前面所有元素（含自身）之和」，即 $a[i] \leftarrow a[0] + a[1] + \cdots + a[i]$（前缀和）。求 $k$ 秒后 $a[n-1]$ 的值，答案对 $10^9 + 7$ 取模。

**约束**：

- $1 \le n, k \le 1000$

> 💡 一句话结论：$k$ 轮前缀和作用在全 $1$ 数组上，末格恰好落在组合数上——答案就是 $\binom{n+k-1}{k} \bmod (10^9+7)$。

## 2. 示例

输入：n = 4, k = 5
输出：56
解释：数组演进为
      t=0: [1, 1, 1, 1]

      t=2: [1, 3, 6, 10]
      t=3: [1, 4, 10, 20]

```

输出：35
解释：t=3 时数组为 [1, 4, 10, 20, 35]，末元素为 35。
```

**示例 3（n = 1，数组永不变化）**

```text
输入：n = 1, k = 1000
输出：1

```

## 3. 解题思路

### 3.1 暴力思路：逐秒模拟，O(nk)

最直接的做法是把 $k$ 秒老老实实模拟过去：每秒对整个数组做一次前缀和。有个非常顺手的实现细节——**从左到右原地执行 `a[i] += a[i-1]`，效果恰好等于"同时更新为前缀和"**（更新 $a[i]$ 时 $a[i-1]$ 已是新值，正好是旧数组的前缀和）：

```python
a = [1] * n
for _ in range(k):              # k 秒
    for i in range(1, n):       # 一轮前缀和
        a[i] = (a[i] + a[i - 1]) % MOD
return a[n - 1]
```

- 时间 $O(nk) \le 10^6$、空间 $O(n)$，本题约束下**必然通过**，比赛现场写这个完全够用。
- 但这张演进表暗藏极强的规律（见 3.2），推成闭式后只需一次组合数计算，还能顺手应对 $n, k$ 更大的变体。

### 3.2 核心观察：k 轮前缀和 = 杨辉三角的斜线

![核心观察：状态表即杨辉三角斜线](images/nth_value_pascal_diagonal.svg)

把 $t = 0, 1, 2, \dots$ 的数组逐行写下来（以 $n = 4$ 为例），会发现整张表就是**斜过来看的杨辉三角**：$a_t[i] = \binom{t+i}{i}$。逐列验证：

- 第 $0$ 列恒为 $1 = \binom{t}{0}$；
- 最后一列（$i = n-1 = 3$）依次是 $1, 4, 10, 20, 35, 56$，正是组合数 $\binom{3}{3}, \binom{4}{3}, \binom{5}{3}, \binom{6}{3}, \binom{7}{3}, \binom{8}{3}$。

原因也不神秘："下一行 = 上一行的前缀和"翻译到杨辉三角上，就是经典的 **hockey stick（曲棍球）恒等式**

$$\sum_{j=0}^{i} \binom{j + t}{t} = \binom{i + t + 1}{t + 1}$$

于是答案一眼写出：

$$\text{ans} = a_k[n-1] = \binom{k + n - 1}{\,n-1\,} = \binom{n+k-1}{k}$$

验证：$n=4,\ k=5 \Rightarrow \binom{8}{5} = 56$ ✓；$n=5,\ k=3 \Rightarrow \binom{7}{3} = 35$ ✓。

> 💡 隔板法视角：$a_k[n-1]$ 也等于「从 $0 \sim n-1$ 中可重复地取 $k$ 个数（不计顺序）」的方案数 $\binom{n+k-1}{k}$——多轮前缀和天然在数"多重集"。

### 3.3 算法流程：一次组合数取模

![算法流程：DP 与闭式两条路线](images/nth_value_algorithm_flow.svg)

闭式路线三步：

1. 令 $N = n + k - 1 \le 1999$；
2. 线性预处理 $0! \sim N!$（模 $p = 10^9+7$），并用**费马小定理** $x^{-1} \equiv x^{p-2} \pmod p$ 求出 $\text{invFact}[N]$，倒序递推整张逆阶乘表；
3. 计算 $\binom{N}{k} = N! \cdot \text{invFact}[k] \cdot \text{invFact}[N-k] \bmod p$ 返回。

### 3.4 示例演算

![示例演算：n=4, k=5](images/nth_value_walkthrough.svg)

以 $n=4,\ k=5$ 走查：每轮新值 $b[i]$ 等于**旧行的前缀和**，如 $t=4 \to t=5$ 时 $b[3] = 1 + 5 + 15 + 35 = 56$。最后一列沿途留下 $1, 4, 10, 20, 35, 56$，终点正是 $\binom{8}{5} = 56$。

## 4. 算法细节

1. **原地前缀和的正确方向**：`for i in 1..n-1: a[i] += a[i-1]` 从左到右执行才是"同时前缀和"的等价实现；若从右到左遍历则完全错误。两种写法在手玩 `[1,1,1,1]` 上一验便知。
2. **为什么要取模**：$\binom{1998}{999}$ 是约 $600$ 位的大数，任何语言都不能裸算（Python 精确大数除外），必须在乘法之间逐步取模。
3. **逆元只需一次快速幂**：先对 $N!$ 用一次费马小定理求逆元，再倒序递推 $\text{invFact}[i-1] = \text{invFact}[i] \cdot i \bmod p$，避免 $N$ 次快速幂。
4. **表的大小**：阶乘表需要下标 $0 \sim n+k-1$ **含端点**，即长度 $n+k$；少开一格是最典型的越界点。
5. **另一种无需逆元的写法**：用帕斯卡公式 $\binom{N}{r} = \binom{N-1}{r-1} + \binom{N-1}{r}$ 递推第 $N$ 行组合数，$O(N \cdot \min(k, N-k)) \approx 2 \times 10^6$ 次模加法，本题约束下同样可过。

## 5. 正确性证明

**引理 1（hockey stick 恒等式）**：对任意 $i \ge 0$、$t \ge 0$，

$$\sum_{j=0}^{i} \binom{j + t}{t} = \binom{i + t + 1}{t + 1}.$$

**证明**：对 $i$ 归纳。$i = 0$ 时两边均为 $1$（$\binom{t}{t} = 1 = \binom{t+1}{t+1}$）。设对 $i - 1$ 成立，即 $\sum_{j=0}^{i-1} \binom{j+t}{t} = \binom{i+t}{t+1}$，则

$$\sum_{j=0}^{i} \binom{j+t}{t} = \binom{i+t}{t+1} + \binom{i+t}{t} = \binom{i+t+1}{t+1},$$

最后一步用帕斯卡公式 $\binom{m}{r} + \binom{m}{r-1} = \binom{m+1}{r}$。∎

**引理 2（$t$ 轮前缀和的闭式）**：对一切 $t \ge 0$、$0 \le i \le n-1$，$a_t[i] = \binom{t + i}{i}$。

**证明**：对 $t$ 归纳。$t = 0$ 时 $a_0[i] = 1 = \binom{i}{i}$。设 $t$ 时成立，则由更新规则与归纳假设，

$$a_{t+1}[i] = \sum_{j=0}^{i} a_t[j] = \sum_{j=0}^{i} \binom{t + j}{j} = \sum_{j=0}^{i} \binom{t + j}{t} = \binom{t + i + 1}{t + 1} = \binom{(t+1) + i}{i},$$

其中第三个等号用组合数对称性 $\binom{t+j}{j} = \binom{t+j}{t}$，第四个等号是引理 1，最后一个等号再次用对称性。∎

**定理**：$k$ 秒后 $a[n-1] = \dbinom{n + k - 1}{k} \pmod{10^9 + 7}$。

**证明**：在引理 2 中取 $t = k$、$i = n - 1$，得 $a_k[n-1] = \binom{k + n - 1}{n - 1}$；再由对称性 $\binom{n+k-1}{n-1} = \binom{n+k-1}{k}$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n + k + \log p)$。预处理 $N = n+k-1$ 个阶乘为 $O(n+k)$，一次快速幂 $O(\log p)$，其余为常数次乘法。DP 模拟为 $O(nk) \le 10^6$，同样通过。
- **空间复杂度**：$O(n + k)$，即阶乘与逆阶乘两张表；DP 模拟为 $O(n)$ 单数组。

## 7. 参考代码

### C++

```cpp
class Solution {
    static constexpr long long MOD = 1'000'000'007;

    static long long power(long long b, long long e) {
        long long r = 1;
        for (b %= MOD; e > 0; e >>= 1, b = b * b % MOD)
            if (e & 1) r = r * b % MOD;
        return r;
    }

public:
    int valueAfterKSeconds(int n, int k) {
        int N = n + k - 1;
        vector<long long> fact(N + 1), invFact(N + 1);
        fact[0] = 1;
        for (int i = 1; i <= N; ++i) fact[i] = fact[i - 1] * i % MOD;
        invFact[N] = power(fact[N], MOD - 2);
        for (int i = N; i >= 1; --i) invFact[i - 1] = invFact[i] * i % MOD;
        return fact[N] * invFact[k] % MOD * invFact[N - k] % MOD;
    }
};
```

### Python

```python
class Solution:
    def valueAfterKSeconds(self, n: int, k: int) -> int:
        MOD = 10**9 + 7
        N = n + k - 1
        fact = [1] * (N + 1)
        for i in range(1, N + 1):
            fact[i] = fact[i - 1] * i % MOD
        inv_fact = [1] * (N + 1)
        inv_fact[N] = pow(fact[N], MOD - 2, MOD)
        for i in range(N, 0, -1):
            inv_fact[i - 1] = inv_fact[i] * i % MOD
        return fact[N] * inv_fact[k] % MOD * inv_fact[N - k] % MOD
```

> 💡 Python 的偷懒写法：`return math.comb(n + k - 1, k) % (10**9 + 7)`——`math.comb` 精确计算约 600 位的大整数，毫秒级完成；C++ 没有这种待遇，必须模下运算。

## 8. 边界情况与易错点

1. **$n = 1$**：数组恒为 $[1]$，闭式给出 $\binom{k}{k} = 1$，无需特判，也是检验代码的最小用例。
2. **$k = 1$**：答案应为 $n$（一轮后 $a[n-1] = n$），闭式 $\binom{n}{1} = n$，可作快速自检。
3. **更新方向**：原地循环必须**从左到右** `a[i] += a[i-1]`；写成从右到左会把"前缀和"变成别的运算，结果全错。
4. **阶乘表长度**：需要下标 $0 \sim n+k-1$，数组长度开 $n+k$；开成 $n+k-1$ 会越界写。
5. **溢出**：模值约 $10^9$，乘法中间结果约 $10^{12}$，C++ 必须用 `long long`；`int` 相乘直接溢出。
6. **费马小定理前提**：模数为素数且与 $k!$ 互质（$k \le 1000 \ll p$ 自动满足）；若题目把模数换成合数，需改用扩展欧几里得或质因数分解法求逆元。
