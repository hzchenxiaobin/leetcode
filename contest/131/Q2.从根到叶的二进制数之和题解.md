# LeetCode 从根到叶的二进制数之和 题解

## 1. 题目概述

- **标题 / 题号**：从根到叶的二进制数之和（#1022，easy）
- **链接**：https://leetcode.cn/problems/sum-of-root-to-leaf-binary-numbers/
- **来源**：LeetCode 第 131 场周赛 Q2
- **难度**：简单
- **标签**：树、深度优先搜索、二叉树

**题意**：给定一棵二叉树，每个节点的值都是 `0` 或 `1`。对每一条从根到叶子的路径，把路径上的值按顺序拼成一个二进制数（根是最高位），求所有这样的数之和。

形式化地，设叶子集合为 $L$，从根到叶子 $\ell$ 的路径值依次为 $v_0, v_1, \dots, v_{d(\ell)}$，则答案为

$$\sum_{\ell \in L} \; \sum_{k=0}^{d(\ell)} v_k \cdot 2^{\,d(\ell)-k}$$

**约束**：

- 节点数在 $[1, 1000]$ 范围内
- $Node.val$ 仅为 $0$ 或 $1$
- 题目保证答案是一个 32 位整数

> 💡 由于二进制串「左移一位再补末位」就是乘 2 加 1，路径值可以**边递归边累加**，不必把整条路径存下来。

## 2. 示例

**示例 1**

```text
输入：root = [1,0,1,0,1,0,1]
输出：22
解释：四条根到叶路径分别是
      1→0→0 = (100)₂ = 4
      1→0→1 = (101)₂ = 5
      1→1→0 = (110)₂ = 6
      1→1→1 = (111)₂ = 7
      总和 4 + 5 + 6 + 7 = 22。
```

**示例 2**

```text
输入：root = [0]
输出：0
解释：只有一个节点，路径值就是 0。
```

**示例 3（自造，只有左孩子）**

```text
输入：root = [1,1]
输出：3
解释：根 1 只有左孩子 1，路径值 (11)₂ = 3。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的做法是「先把所有根到叶路径收集起来，再逐条求值」：

1. DFS 把所有路径存进一个列表（每条路径是一个 0/1 数组）；
2. 对每条路径从高位到低位累乘 2。

第 2 步对长度为 $d$ 的路径要 $O(d)$，而所有路径长度之和在最坏情况（一条长链、每层都分叉）可达 $O(n^2)$。$n \le 1000$ 时 $10^6$ 量级还能接受，但存路径本身浪费空间，且完全没有利用「前缀共享」这一结构。

### 3.2 核心观察：路径值是「前缀值」的线性延伸

![边递归边累加：路径值 = 前缀值 × 2 + 当前位](images/wc131_q2_prefix_value.svg)

设节点 $u$ 的深度为 $d$（根为第 0 层），从根到 $u$ 的路径值记为 $P(u)$。则对 $u$ 的任一孩子 $v$：

$$P(v) = 2 \cdot P(u) + val(v)$$

原因很直接：在二进制串末尾再补一位 $b$，等价于把原数左移一位（乘 2）再加上 $b$。

于是 DFS 时只需要携带一个整数 `cur` 沿路径往下传：

- 进入节点时 `cur = cur * 2 + u->val`；
- 若 $u$ 是叶子，把 `cur` 累加进答案；
- 否则继续递归左右子树。

**所有前缀共享同一个 `cur` 递推**，每个节点只算一次，总复杂度 $O(n)$，也不需要存路径。

> 💡 这个模式叫「**路径状态随 DFS 传递**」：凡是「从根到当前节点的累积量」都能这么写（路径和、路径最大值、路径异或……），是树形题第一梯队套路。

### 3.3 算法流程

![DFS 流程：携带 cur 下行，到叶子结算](images/wc131_q2_dfs_flow.svg)

```text
1. ans = 0
2. dfs(u, cur):
       若 u 为空: 返回
       cur = cur * 2 + u.val
       若 u 是叶子（左右孩子都为空）:
           ans += cur
           返回
       dfs(u.left, cur)
       dfs(u.right, cur)
3. dfs(root, 0)，返回 ans
```

注意「叶子」的判定是**左右孩子都为空**，而不是「没有左孩子」——只有单个孩子的节点不是叶子。

### 3.4 示例演算

![示例演算：四条路径的数值](images/wc131_q2_walkthrough.svg)

对 `root = [1,0,1,0,1,0,1]`（完全二叉树，层序）：

| 路径 | 递归中的 `cur` 轨迹 | 路径值 |
|---|---|---|
| 1→0→0 | 0 → 1 → 1·2+0=2 → 2·2+0=4 | 4 |
| 1→0→1 | 0 → 1 → 2 → 2·2+1=5 | 5 |
| 1→1→0 | 0 → 1 → 1·2+1=3 → 3·2+0=6 | 6 |
| 1→1→1 | 0 → 1 → 3 → 3·2+1=7 | 7 |

总和 $4+5+6+7 = 22$ ✓。

## 4. 算法细节

1. **`cur` 用值传递**：C++ 里写 `dfs(u->left, cur)`，每一层拿到的是自己的副本；若用引用传递，回溯时必须手动恢复，容易出错。
2. **叶子判定**：`if (!u->left && !u->right)`。空树单独处理（题面保证 $n \ge 1$）。
3. **答案用引用或成员变量**：C++ 传 `int& ans`，Python 用 `nonlocal` / 类成员。
4. **数值范围**：题面保证答案在 32 位内，说明测试数据的深度有限，`int` 足够；若深度可能达到 1000（如 `1111...` 长链）则需要大整数，实际不会出现。
5. **递归深度**：节点数 $\le 1000$，最坏链深 1000，C++ 默认栈足够；Python 默认递归限 1000 恰好卡边界，若要保险可改成显式栈迭代。
6. **迭代写法**（可选）：用栈存 `(node, cur)`，效果相同，能彻底避免递归深度问题。

## 5. 正确性证明

**引理 1（前缀值递推）**：对任意非根节点 $v$，设其父节点为 $u$，则 $P(v) = 2 P(u) + val(v)$。

**证明**：$P(u)$ 是从根到 $u$ 的二进制串的值，$P(v)$ 对应的串是 $P(u)$ 的串末尾追加 $val(v)$，即左移一位加 $val(v)$，故 $P(v) = 2P(u) + val(v)$。∎

**引理 2（DFS 不变量）**：每次调用 `dfs(u, cur)` 开始时，`cur` 恰为 $P(u)$ 的前缀值（即进入 $u$ 之前的路径值，根节点为 0）；进入函数体执行 `cur = cur * 2 + u->val` 后，`cur` 恰为 $P(u)$。

**证明**：对树做结构归纳。根节点调用时 `cur = 0`，执行后 `cur = val(root) = P(root)`。设对 $u$ 成立，则调用 `dfs(v, cur_u)` 时传入的是 $P(u)$，由引理 1 执行后得 $P(v)$。∎

**定理**：算法返回所有根到叶路径值之和。

**证明**：由引理 2，每次到达叶子 $\ell$ 时 `cur = P(\ell)`，算法把它累加进 `ans`；DFS 恰好访问每个节点一次，故每个叶子恰好被累加一次；非叶子不累加。因此 `ans` 等于 $\sum_{\ell \in L} P(\ell)$，正是题面所求。∎

## 6. 复杂度分析

- **时间**：$O(n)$，每个节点被访问一次，$O(1)$ 计算。
- **空间**：$O(h)$，$h$ 为树高，即递归栈深度；最坏 $O(n)$（链状树），最优 $O(\log n)$（平衡树）。不含输入输出。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int sumRootToLeaf(TreeNode* root) {
        int ans = 0;
        dfs(root, 0, ans);
        return ans;
    }

private:
    void dfs(TreeNode* u, int cur, int& ans) {
        if (u == nullptr) return;
        cur = cur * 2 + u->val;                     // 左移一位并补末位
        if (u->left == nullptr && u->right == nullptr) {
            ans += cur;                             // 叶子：结算整条路径
            return;
        }
        dfs(u->left, cur, ans);
        dfs(u->right, cur, ans);
    }
};
```

### Python

```python
class Solution:
    def sumRootToLeaf(self, root) -> int:
        ans = 0

        def dfs(u, cur: int) -> None:
            nonlocal ans
            if u is None:
                return
            cur = cur * 2 + u.val                    # 左移一位并补末位
            if u.left is None and u.right is None:
                ans += cur                           # 叶子：结算整条路径
                return
            dfs(u.left, cur)
            dfs(u.right, cur)

        dfs(root, 0)
        return ans
```

## 8. 边界情况与易错点

1. **单节点树**：`[0]` → 0，`[1]` → 1。根同时是叶子，必须在根处就结算。
2. **只有一个孩子的节点不是叶子**：`[1,1]` 中根不是叶子，答案来自左孩子，为 3。
3. **全 0 树**：每条路径值都是 0，答案 0，不要因为「累加没变化」而误判。
4. **`cur` 的值传递**：用引用传递会污染兄弟分支，务必按值传递（或显式回溯）。
5. **空树**：题面保证 $n \ge 1$，但代码里 `if (u == nullptr) return;` 让空树返回 0，是安全的兜底。
6. **`nonlocal`**：Python 嵌套函数里修改外层变量必须声明 `nonlocal ans`，否则会 `UnboundLocalError`。
7. **递归深度**：$n \le 1000$ 时链状树深度可达 1000，Python 恰好卡在默认上限；如需稳健可加 `sys.setrecursionlimit` 或改迭代。
