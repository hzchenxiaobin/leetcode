# LeetCode 删除最外层的括号 题解

## 1. 题目概述

- **标题 / 题号**：删除最外层的括号（#1021，easy）
- **链接**：https://leetcode.cn/problems/remove-outermost-parentheses/
- **来源**：LeetCode 第 131 场周赛 Q1
- **难度**：简单
- **标签**：栈、字符串、括号序列

**题意**：回忆两个定义：

- **有效括号字符串**：`""`、`"(" + A + ")"`、`A + B`（$A, B$ 都有效）；
- **原语（primitive）**：非空有效字符串，且不能写成两个非空有效字符串的拼接。

给定一个非空有效字符串 $s$，把它做**原语化分解** $s = P_1 + P_2 + \cdots + P_k$，然后**删掉每个 $P_i$ 的最外层一对括号**，返回拼接后的字符串。

**约束**：

- $1 \le s.length \le 1000$
- `s[i]` 为 `'('` 或 `')'`
- `s` 是有效括号字符串

> 💡 关键点：每个原语的最外层括号**不是** $s$ 的第一个和最后一个字符，而是「**前缀深度回到 0 的那些位置**」划分出的每一段的边界。

## 2. 示例

**示例 1**

```text
输入：s = "(()())(())"
输出："()()()"
解释：原语化分解为 "(()())" + "(())"；
      去掉各自最外层括号得 "()()" + "()" = "()()()"。
```

**示例 2**

```text
输入：s = "(()())(())(()(()))"
输出："()()()()(())"
解释：分解为 "(()())" + "(())" + "(()(()))"，
      得 "()()" + "()" + "()(())" = "()()()()(())"。
```

**示例 3**

```text
输入：s = "()()"
输出：""
解释：分解为 "()" + "()"，各去掉最外层后都是空串。
```

## 3. 解题思路

### 3.1 暴力思路

按定义直接做：先求原语分解，再逐段截取。

1. 扫一遍 `s`，用计数器 `bal`（遇到 `(` 加 1，遇到 `)` 减 1）记录每次 `bal` 回到 0 的位置，这些位置就是各原语的右端点；
2. 对每个原语 $s[l..r]$，把 $s[l+1..r-1]$ 拼到答案里。

这已经是 $O(n)$ 的，但需要**两遍扫描**并且要小心下标。更朴素的做法是对每个字符判断「它是否属于某个原语的最外层」——如果每次都重新扫一遍深度，就是 $O(n^2)$，$n = 1000$ 时虽能过，但完全没有必要。

### 3.2 核心观察：一个字符是否是「最外层括号」可以 O(1) 判断

![深度视角：前缀深度为 0 的位置切开原语](images/wc131_q1_depth_concept.svg)

设 `depth` 为**当前字符之前**的前缀深度（即已读入的 `(` 数减 `)` 数）。对有效括号串有两条事实：

- 一个 `(` 是**某个原语的最外层左括号** $\iff$ 读它之前 `depth == 0`（它开启了新原语）；
- 一个 `)` 是**某个原语的最外层右括号** $\iff$ 读它之前 `depth == 1`（它关闭了当前原语）。

于是可以一遍扫描、边走边判断：

- 遇到 `(`：若 `depth > 0` 就保留它；然后 `depth++`。
- 遇到 `)`：先 `depth--`；若 `depth > 0` 就保留它。

注意**两个分支的更新顺序不同**：`(` 是「先判断再自增」，`)` 是「先自减再判断」。这样判断条件都只需比较 `depth` 与 0。

> 💡 换个等价说法：把原语的最外层括号看作「深度从 0 升到 1」和「从 1 降到 0」的那两对括号，其余括号的深度都 $\ge 2$（内部）或恰好跨越（内部边界），都要保留。

### 3.3 算法流程

![算法流程：一次扫描，按深度决定去留](images/wc131_q1_algorithm_flow.svg)

```text
1. depth = 0, ans = []
2. for ch in s:
       若 ch == '(':
           若 depth > 0:  ans 追加 '('
           depth += 1
       否则:
           depth -= 1
           若 depth > 0:  ans 追加 ')'
3. 返回 ans 拼成的字符串
```

### 3.4 示例演算

![示例演算：s = "(()())(())" 的逐字符去留](images/wc131_q1_walkthrough.svg)

对 `s = "(()())(())"`：

| 下标 | 字符 | 读前 depth | 是否保留 | 读后 depth | 说明 |
|---|---|---|---|---|---|
| 0 | `(` | 0 | 否 | 1 | 开启第 1 个原语，最外层左括号 |
| 1 | `(` | 1 | 是 | 2 | 内部括号 |
| 2 | `)` | 2 | 是 | 1 | 内部括号 |
| 3 | `(` | 1 | 是 | 2 | 内部括号 |
| 4 | `)` | 2 | 是 | 1 | 内部括号 |
| 5 | `)` | 1 | 否 | 0 | 第 1 个原语的最外层右括号 |
| 6 | `(` | 0 | 否 | 1 | 开启第 2 个原语 |
| 7 | `(` | 1 | 是 | 2 | 内部括号 |
| 8 | `)` | 2 | 是 | 1 | 内部括号 |
| 9 | `)` | 1 | 否 | 0 | 第 2 个原语的最外层右括号 |

保留的字符依次是 `( ) ( )` + `( )`，即 `"()()()"` ✓。

再看 `s = "()()"`：下标 0 的 `(` 与下标 1 的 `)` 分别是第一个原语的最外层，全删；下标 2、3 同理，结果为空串 `""` ✓。

## 4. 算法细节

1. **更新顺序**：`(` 分支是「判断 `depth > 0` → 追加 → `depth++`」；`)` 分支是「`depth--` → 判断 `depth > 0` → 追加」。若把 `)` 分支写成「判断 `depth > 0` → 追加 → `depth--`」，就会把每个原语的右外层括号也保留下来。
2. **只需一个整数**：不需要显式栈。深度本身就是栈大小，而本题只关心「是不是最外层」，不需要知道括号的配对关系。
3. **`depth` 的取值**：$s$ 有效，故 `depth` 恒 $\ge 0$；原语边界恰是 `depth` 变为 0 的时刻。
4. **结果可能为空**：`"()()"` 这类全是最小原语的输入，答案为空串，必须允许空串返回。
5. **不复用原字符串**：边扫边拼到 `string`/`list` 里，最后 `join`；C++ 用 `string` 直接 `push_back` 即可（有平摊 $O(1)$ 的均摊扩容）。
6. **不需要额外验证 `s` 有效**：题面保证。

## 5. 正确性证明

记 $s$ 的原语分解为 $P_1, \dots, P_k$，$P_i = s[l_i .. r_i]$（$l_1 = 0$，$r_k = n-1$，$l_{i+1} = r_i + 1$）。记 $d(j)$ 为前缀 $s[0..j-1]$ 的深度（即读第 $j$ 个字符**之前**的深度）。

**引理 1（原语边界的深度刻画）**：$l_i$ 是某原语的左端点 $\iff d(l_i) = 0$ 且 $s[l_i] = \text{'('}$；$r_i$ 是某原语的右端点 $\iff d(r_i) = 1$ 且 $s[r_i] = \text{')'}$。

**证明**：
（$\Rightarrow$）$P_1$ 从下标 0 开始，$d(0) = 0$。对 $i \ge 2$，$P_i$ 紧随 $P_{i-1}$，而 $P_{i-1}$ 是有效括号串，读完它后深度回到 0，故 $d(l_i) = 0$。右端点：$P_i$ 是有效括号串，其内部前缀深度恒 $\ge 1$（相对起点），因此读最后一个字符 `)` 之前深度为 $d(l_i) + 1 = 1$。
（$\Leftarrow$）若 $d(j) = 0$ 且 $s[j] = \text{'('}$，则 $j$ 是某个「深度从 0 到 1」的位置。深度第一次回到 0 的位置之后才会出现下一个 $d = 0$，故 $j$ 必为某个原语的起点（起点集合恰是 $\{j : d(j) = 0\}$）。右端点同理：$d(j) = 1$ 且 $s[j] = \text{')'}$ 意味着读它之后深度变为 0，即某个原语在此闭合。∎

**引理 2（算法逐字符判定等价）**：算法对下标 $j$ 的字符「不追加」当且仅当它是某个原语的最外层括号。

**证明**：分两种情况。
- $s[j] = \text{'('}$：算法在 `depth > 0` 时追加，在 `depth == 0` 时不追加；而循环到 $j$ 时 `depth` 恰为 $d(j)$（归纳：每读一个字符后 `depth` 与真实深度一致）。由引理 1，$d(j) = 0 \iff j$ 是原语左端点 $\iff$ 该 `(` 是最外层左括号。
- $s[j] = \text{')'}$：算法先自减再判断，等价于判断「$d(j) = 1$ 时不追加」。由引理 1，$d(j) = 1 \iff j$ 是原语右端点 $\iff$ 该 `)` 是最外层右括号。∎

**引理 3（保留字符的顺序）**：算法保留的字符按原顺序构成 $\bigcup_{i=1}^{k} P_i[1..|P_i|-2]$ 的拼接。

**证明**：由引理 2，被删除的恰是每个 $P_i$ 的首字符与末字符（即最外层括号）；其余字符按原下标顺序保留，拼接顺序自然与 $P_1, \dots, P_k$ 一致。∎

**定理**：算法返回的字符串等于题面要求的「删除每个原语最外层括号后拼接」的结果。

**证明**：直接由引理 3。∎

## 6. 复杂度分析

- **时间**：$O(n)$，一次扫描，每个字符做 $O(1)$ 次比较与追加。字符串追加的均摊开销为 $O(1)$。
- **空间**：$O(n)$，用于存放结果字符串（不含输入时的额外空间为 $O(1)$）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    string removeOuterParentheses(string s) {
        string ans;
        int depth = 0;
        for (char ch : s) {
            if (ch == '(') {
                if (depth > 0) ans.push_back('(');   // 非最外层左括号才保留
                depth++;
            } else {
                depth--;
                if (depth > 0) ans.push_back(')');   // 降到 0 说明是最外层右括号
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def removeOuterParentheses(self, s: str) -> str:
        ans = []
        depth = 0
        for ch in s:
            if ch == "(":
                if depth > 0:
                    ans.append(ch)
                depth += 1
            else:
                depth -= 1
                if depth > 0:
                    ans.append(ch)
        return "".join(ans)
```

## 8. 边界情况与易错点

1. **`(` 与 `)` 的判断顺序相反**：这是本题唯一的坑。`(` 先判断后自增，`)` 先自减后判断。写反就会多保留/少保留一整层括号。
2. **单个原语且为空内容**：`s = "()"` → `""`；`s = "(())"` → `"()"`。
3. **全是极小原语**：`"()()"` → `""`，答案为空串，不能返回 `null` 或 `"()"`。
4. **嵌套很深**：如 `"(((())))"` → `"((()))"`，只删最外一层，不要递归删。
5. **深度不会为负**：$s$ 有效，若题目改成任意括号串则需先判合法性。
6. **不要用「首尾各删一个字符」的偷懒写法**：只有 $k = 1$ 时才碰巧成立；示例 1 有 2 个原语，直接删首尾会得到 `"()())(()"`（错误）。
