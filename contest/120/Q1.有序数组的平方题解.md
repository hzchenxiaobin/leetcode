# LeetCode 有序数组的平方 题解

## 1. 题目概述

- **标题 / 题号**：有序数组的平方（#977，easy）
- **链接**：https://leetcode.cn/problems/squares-of-a-sorted-array/
- **来源**：LeetCode 第 120 场周赛 Q1
- **难度**：简单
- **标签**：数组、双指针、排序

**题意**：给定按**非递减**顺序排好的整数数组 `nums`（可能含负数），返回每个元素平方后组成的新数组，要求结果同样**非递减**。

**约束**：

- $1 \le nums.length \le 10^4$
- $-10^4 \le nums[i] \le 10^4$
- `nums` 已按非递减顺序排序

> 💡 **进阶要求**：请设计时间复杂度为 $O(n)$ 的算法。这题真正的考点就在这里——平方后直接排序是 $O(n \log n)$，虽然也能过，但没拿到最优。

## 2. 示例

**示例 1**

```text
输入：nums = [-4,-1,0,3,10]
输出：[0,1,9,16,100]
解释：平方后为 [16,1,0,9,100]，再排序得到答案；但正确做法根本不需要排序。
```

**示例 2**

```text
输入：nums = [-7,-3,2,3,11]
输出：[4,9,9,49,121]
解释：平方后 [49,9,4,9,121]，排序后如上；两个 9 分别来自 -3 与 3。
```

**示例 3**

```text
输入：nums = [-5]
输出：[25]
解释：单元素，直接平方。
```

## 3. 解题思路

### 3.1 暴力思路

每个元素平方，然后整体排序：$O(n \log n)$。完全正确，但浪费了「原数组已排序」这个条件，也达不到题目的 $O(n)$ 进阶要求。

### 3.2 核心观察：平方后，最大值一定在两端

![平方后序列先减后增：最大值只可能在两端](images/wc120_q1_two_pointers.svg)

`nums` 升序，且可能含负数，所以平方后的序列 $nums[0]^2, nums[1]^2, \dots$ 是**先降后升**的（负数段绝对值递减，正数段递增）。也就是说：

- 全局最大平方值，必然出现在**左端**（最负的数）或**右端**（最大的正数）；
- 取走较大者之后，剩下的部分仍保持「两端大、中间小」的结构。

于是可以用**双指针 + 逆序填充**：左右指针分别指向未处理区间的两端，每次比较两端的平方值，把较大的那个填到结果数组的**末尾**，然后把对应指针向内收缩。这样从后往前填，天然得到非递减的结果。

### 3.3 算法流程

![双指针从两端取大者，逆序填入结果数组](images/wc120_q1_merge_order.svg)

```text
1. i = 0，j = n-1，结果数组 res 长度 n
2. for k = n-1 down to 0:
       若 nums[i]^2 > nums[j]^2:
           res[k] = nums[i]^2；i++
       否则:
           res[k] = nums[j]^2；j--
3. 返回 res
```

注意比较的是**绝对值**（或平方），不是原值——`-4` 比 `3` 大（平方意义下）。

### 3.4 示例演算

对示例 1 的 `nums = [-4,-1,0,3,10]`：

| 步 | $i$ | $j$ | 左端平方 | 右端平方 | 取谁 | 填入位置 | `res` 已填部分 |
|---|---|---|---|---|---|---|---|
| 1 | 0 | 4 | 16 | 100 | 右 | 4 | [_,_,_,_,100] |
| 2 | 0 | 3 | 16 | 9 | 左 | 3 | [_,_,_,16,100] |
| 3 | 1 | 3 | 1 | 9 | 右 | 2 | [_,_,9,16,100] |
| 4 | 1 | 2 | 1 | 0 | 左 | 1 | [_,1,9,16,100] |
| 5 | 2 | 2 | 0 | 0 | 右 | 0 | [0,1,9,16,100] |

结果 `[0,1,9,16,100]` ✓，全程只扫一遍。

## 4. 算法细节

1. **比较绝对值而不是原值**：`abs(nums[i]) > abs(nums[j])` 与「平方更大」等价，且避免了大数相乘（虽然本题不会溢出）。
2. **逆序填充**：因为先取到的是**最大**的平方值，所以要放在 `res` 的末尾；正序填会得到降序。
3. **指针相遇**：`i == j` 时该元素还没被处理，循环仍要执行一次，把它的平方填进剩下的位置。
4. **溢出**：$|nums[i]| \le 10^4$ → 平方 $\le 10^8$，`int` 足够；若数组元素到 $10^9$，需要用 `long long`。
5. **不修改输入**：双指针只读 `nums`，结果写在新数组里，可以安全复用输入。
6. **Python 的 `while` 与 `for`**：用 `for k in range(n-1, -1, -1)` 控制填充位置，指针更新在循环体内，语义最清晰。

## 5. 正确性证明

**引理 1（两端取大）**：设当前未处理区间为 $nums[i..j]$（$i \le j$），则区间内平方值最大者必为 $nums[i]^2$ 或 $nums[j]^2$。

**证明**：`nums` 升序，故 $nums[i] \le nums[i+1] \le \dots \le nums[j]$。平方函数在 $(-\infty, 0]$ 上递减、在 $[0, +\infty)$ 上递增。设负数的范围是 $nums[i..m]$（$nums[m] \le 0 < nums[m+1]$），则平方后：

- $nums[i]^2 \ge nums[i+1]^2 \ge \dots \ge nums[m]^2$（负数段递减）；
- $nums[m+1]^2 \le nums[m+2]^2 \le \dots \le nums[j]^2$（非负段递增）。

所以平方序列在区间内呈「先降后升」（单谷），最小值在中间，最大值只能出现在两个端点之一。∎

**引理 2（迭代不变式）**：第 $t$ 轮（$t = 0, 1, \dots$）开始时，`res` 的后 $t$ 个位置已按非递减顺序填好，且恰好是当前区间 $nums[i..j]$ 之外所有元素平方值中**最大的 $t$ 个**。

**证明**：对 $t$ 归纳。$t = 0$ 时空成立。设第 $t$ 轮前不变式成立，由引理 1，当前区间的最大值在两端；算法取两端较大者填入 `res[n-1-t]`，它不小于区间内任何平方值，也不大于此前填入的值（此前填的是更大或相等的值），且它是整个数组平方值中第 $t+1$ 大的，故不变式对 $t+1$ 成立。∎

**定理**：算法返回的数组是 `nums` 各元素平方后的非递减排列。

**证明**：循环执行 $n$ 轮后所有元素被取完（每轮至少收缩一个指针），由引理 2（取 $t = n$），`res` 全部填满、按非递减顺序、且恰为所有平方值，故正确。∎

## 6. 复杂度分析

- **时间**：$O(n)$。每轮比较 $O(1)$，共 $n$ 轮；没有排序步骤。
- **空间**：$O(n)$，仅结果数组（不计输入）；若允许原地则额外空间 $O(1)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> sortedSquares(vector<int>& nums) {
        int n = (int)nums.size();
        vector<int> res(n);
        int i = 0, j = n - 1;
        for (int k = n - 1; k >= 0; k--) {
            if (abs(nums[i]) > abs(nums[j])) {
                res[k] = nums[i] * nums[i];
                i++;
            } else {
                res[k] = nums[j] * nums[j];
                j--;
            }
        }
        return res;
    }
};
```

### Python

```python
class Solution:
    def sortedSquares(self, nums: list[int]) -> list[int]:
        n = len(nums)
        res = [0] * n
        i, j = 0, n - 1
        for k in range(n - 1, -1, -1):
            if abs(nums[i]) > abs(nums[j]):
                res[k] = nums[i] * nums[i]
                i += 1
            else:
                res[k] = nums[j] * nums[j]
                j -= 1
        return res
```

## 8. 边界情况与易错点

1. **全负数**：如 `[-3,-2,-1]`，平方后是 `[9,4,1]`，答案应为 `[1,4,9]`。此时右端是绝对值最小的数，双指针每轮都会取左端，结果数组从后往前填入 9、4、1，最终正好非递减。
2. **全非负**：退化为「每个元素平方后仍有序」，双指针每轮都取右端，等价于顺序平方。
3. **含 0**：0 的平方是 0，会落在中间；注意 `abs` 相同时走 `else` 分支，取右端，结果不变。
4. **正序填充**：写成 `res[k]` 且 `k` 从 0 递增会得到降序，必须逆序填。
5. **只比较原值**：`nums[i] > nums[j]` 是错的，`-4 > 3` 不成立但它的平方更大。
6. **溢出**：本题 $|nums[i]| \le 10^4$ 安全；面试若给 $10^9$ 量级，必须 `long long` / Python 无此问题。
7. **`n = 1`**：循环执行一次，`i == j == 0`，取右端（同一元素），结果正确。
