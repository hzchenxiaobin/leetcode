# LeetCode 最长湍流子数组 题解

## 1. 题目概述

- **标题 / 题号**：最长湍流子数组（#978，medium）
- **链接**：https://leetcode.cn/problems/longest-turbulent-subarray/
- **来源**：LeetCode 第 120 场周赛 Q2
- **难度**：中等
- **标签**：数组、动态规划、滑动窗口

**题意**：如果数组子数组 `A[i], A[i+1], ..., A[j]` 中每对相邻元素的**比较符号翻转**（`<` 和 `>` 交替出现），则称它是**湍流子数组**。返回 `arr` 的最长湍流子数组的**长度**。

形式化地，存在以下两种模式之一（$i \le k < j$）：

- 奇数 $k$ 时 $A[k] > A[k+1]$，偶数 $k$ 时 $A[k] < A[k+1]$；或
- 偶数 $k$ 时 $A[k] > A[k+1]$，奇数 $k$ 时 $A[k] < A[k+1]$。

**约束**：

- $1 \le arr.length \le 4 \times 10^4$
- $0 \le arr[i] \le 10^9$

> 💡 长度为 1 的子数组恒为湍流（没有相邻对需要检查）；长度为 2 的子数组只要两个元素**不相等**就是湍流。

## 2. 示例

**示例 1**

```text
输入：arr = [9,4,2,10,7,8,8,1,9]
输出：5
解释：arr[1] > arr[2] < arr[3] > arr[4] < arr[5]，即 4,2,10,7,8，
      符号序列 > < > < 严格交替，长度 5。
```

**示例 2**

```text
输入：arr = [4,8,12,16]
输出：2
解释：符号序列是 < < <，不交替；任意两个相邻元素都构成长度 2 的湍流子数组。
```

**示例 3**

```text
输入：arr = [100]
输出：1
解释：单元素，长度为 1。
```

**示例 4**

```text
输入：arr = [9,9]
输出：1
解释：两个元素相等，无法构成湍流（长度 2 的子数组要求严格不等）。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有子数组（$O(n^2)$），对每个子数组检查符号是否交替（$O(n)$），总 $O(n^3)$；即便用「从每个起点向右扩展、一旦不交替就停」的技巧，最坏仍是 $O(n^2)$（例如整个数组交替时）。$n = 4 \times 10^4$ 时 $1.6 \times 10^9$ 不可接受。

### 3.2 核心观察：只看相邻比较的符号序列

![把数组变成符号序列，问题变成「最长交替子串」](images/wc120_q2_turbulence_signs.svg)

定义符号序列 $s_k = \text{sign}(arr[k+1] - arr[k]) \in \{+1, -1, 0\}$（$0$ 表示相等）。子数组 $arr[i..j]$ 是湍流 $\iff$ $s_i, s_{i+1}, \dots, s_{j-1}$ **相邻两项都不同且非零**。

于是问题化为：在符号序列中找最长的「交替且无零」的连续段。这可以用一次线性扫描维护两个状态：

- `up`：以当前位置**结尾**、且**最后一步是上升**（$arr[k-1] < arr[k]$）的最长湍流长度；
- `down`：以当前位置**结尾**、且**最后一步是下降**的最长湍流长度。

转移只依赖前一位的状态：

$$arr[i] > arr[i-1] :\quad up = down + 1,\quad down = 1$$
$$arr[i] < arr[i-1] :\quad down = up + 1,\quad up = 1$$
$$arr[i] = arr[i-1] :\quad up = down = 1$$

答案取所有时刻的 $\max(up, down)$。

### 3.3 算法流程

![状态转移：up 与 down 互相接力](images/wc120_q2_dp_states.svg)

```text
1. up = down = 1，ans = 1
2. for i = 1 .. n-1:
       若 arr[i] > arr[i-1]:  up = down + 1；down = 1
       否则若 arr[i] < arr[i-1]: down = up + 1；up = 1
       否则:                  up = down = 1
       ans = max(ans, up, down)
3. 返回 ans
```

### 3.4 示例演算

对示例 1 的 `arr = [9,4,2,10,7,8,8,1,9]`：

| $i$ | $arr[i-1] \to arr[i]$ | 关系 | `up` | `down` | `ans` |
|---|---|---|---|---|---|
| 1 | 9 → 4 | 下降 | 1 | 2 | 2 |
| 2 | 4 → 2 | 下降 | 1 | 2 | 2 |
| 3 | 2 → 10 | 上升 | 3 | 1 | 3 |
| 4 | 10 → 7 | 下降 | 1 | 4 | 4 |
| 5 | 7 → 8 | 上升 | 5 | 1 | **5** |
| 6 | 8 → 8 | 相等 | 1 | 1 | 5 |
| 7 | 8 → 1 | 下降 | 1 | 2 | 5 |
| 8 | 1 → 9 | 上升 | 3 | 1 | 5 |

注意第 2 步：`4 → 2` 是连续下降，`down` 只能重置为 2（不能接上更早的 `9 → 4`，因为那会让符号连续两个 `-`），这正是「交替」约束的体现。最终答案 5，对应子数组 `[4,2,10,7,8]`。

## 4. 算法细节

1. **状态含义要精确**：`up`/`down` 都是「以当前元素结尾」的最长长度，不是全局最长；全局答案单独用 `ans` 累计。
2. **相等时两个状态都重置为 1**：`arr[i] == arr[i-1]` 使任何跨越这两个位置的子数组都含符号 0，必须断开。
3. **转移方向**：上升时新长度来自 `down`（前一步必须是下降，才能交替），不能来自 `up`。
4. **答案初值 1**：$n = 1$ 时循环不执行，必须返回 1。
5. **长度 2 的处理**：$arr[i] \ne arr[i-1]$ 时 `up` 或 `down` 至少为 2（$down = 1 + 1$），自然覆盖。
6. **不修改输入**：只读数组，无额外数组，空间 $O(1)$。

## 5. 正确性证明

**引理 1（问题等价于符号交替）**：子数组 $arr[i..j]$（$i < j$）是湍流 $\iff$ 对每个 $k \in [i, j-1]$ 有 $s_k \ne 0$ 且 $s_k \ne s_{k+1}$（$k < j-1$）。

**证明**：题目要求两种模式之一：符号从某个方向开始严格交替。$s_k \ne 0$ 保证每对相邻元素严格不等（否则符号为 0，两种模式都不满足）；$s_k \ne s_{k+1}$ 保证相邻符号翻转。二者合起来正是「从 $s_i$ 开始严格交替」，与题目的两种模式（起始符号为 $+$ 或 $-$）一一对应。∎

**引理 2（转移正确）**：设 `up[i]`、`down[i]` 分别为以 $i$ 结尾、最后一步为上升 / 下降的最长湍流长度（不存在时为 1）。则

- 若 $arr[i] > arr[i-1]$：`up[i] = down[i-1] + 1`，`down[i] = 1`；
- 若 $arr[i] < arr[i-1]$：`down[i] = up[i-1] + 1`，`up[i] = 1`；
- 若相等：两者均为 1。

**证明**：设 $arr[i] > arr[i-1]$（其余情形对称）。以 $i$ 结尾、最后一步上升的湍流子数组，若长度 $L \ge 2$，则其倒数第二步符号必须是 `-`（引理 1 要求交替），于是去掉最后一个元素后，得到的是以 $i-1$ 结尾、最后一步下降的湍流子数组，长度 $L - 1 \le down[i-1]$。故 $up[i] \le down[i-1] + 1$。反之，取以 $i-1$ 结尾、最后一步下降的最长湍流子数组，再拼上 $arr[i]$，其符号序列在末尾多了一个 `+`，与前一个 `-` 不同，仍严格交替，故长度 $down[i-1] + 1$ 可达。两者相等。另外此时不可能存在以 $i$ 结尾、最后一步下降且长度 $\ge 2$ 的子数组（最后一步由 $arr[i-1], arr[i]$ 唯一确定为上升），故 $down[i] = 1$。相等时任何长度 $\ge 2$ 的子数组都含符号 0，故均为 1。∎

**定理**：算法返回最长湍流子数组的长度。

**证明**：由引理 2，扫描到 $i$ 时 `up`、`down` 分别等于 $up[i]$、$down[i]$（归纳，$i = 0$ 时为 1，正确）。任何湍流子数组必以某个 $i$ 结尾且最后一步为上升或下降，其长度不超过 $\max(up[i], down[i])$；反之 $up[i]$、$down[i]$ 都对应真实的湍流子数组。故 $\max_i \max(up[i], down[i])$ 即为最长长度，正是算法维护的 `ans`。∎

## 6. 复杂度分析

- **时间**：$O(n)$，一次线性扫描，每次 $O(1)$ 状态转移。
- **空间**：$O(1)$，只用两个整型状态与答案。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maxTurbulenceSize(vector<int>& arr) {
        int n = (int)arr.size();
        int up = 1, down = 1, ans = 1;
        for (int i = 1; i < n; i++) {
            if (arr[i] > arr[i - 1]) {
                up = down + 1;
                down = 1;
            } else if (arr[i] < arr[i - 1]) {
                down = up + 1;
                up = 1;
            } else {
                up = down = 1;
            }
            ans = max(ans, max(up, down));
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maxTurbulenceSize(self, arr: list[int]) -> int:
        up = down = 1
        ans = 1
        for i in range(1, len(arr)):
            if arr[i] > arr[i - 1]:
                up, down = down + 1, 1
            elif arr[i] < arr[i - 1]:
                down, up = up + 1, 1
            else:
                up = down = 1
            ans = max(ans, up, down)
        return ans
```

## 8. 边界情况与易错点

1. **$n = 1$**：答案是 1，循环不执行，`ans` 初值必须为 1。
2. **相邻相等**：`[9,9]` 答案是 1，不是 2；相等时两个状态都要重置。
3. **连续同向**：`[4,8,12,16]` 答案是 2，不是 4；`up` 每次只能从 `down` 接力，`down = 1` 时 `up` 也长不了。
4. **交替数组**：`[1,2,1,2,1]` 答案是 5，整段都是湍流。
5. **转移写反**：上升时应 `up = down + 1`，若写成 `up = up + 1` 会把连续上升误判为湍流。
6. **Python 的元组赋值**：`up, down = down + 1, 1` 右侧先整体求值，不会互相污染；若分两行写要小心顺序（先算新值再覆盖）。
7. **状态没有「以 i 结尾」的含义**：把 `up` 当成「全局最长上升交替段」会在重置时出错，务必按定义使用。
