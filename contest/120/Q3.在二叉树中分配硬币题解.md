# LeetCode 在二叉树中分配硬币 题解

## 1. 题目概述

- **标题 / 题号**：在二叉树中分配硬币（#979，medium）
- **链接**：https://leetcode.cn/problems/distribute-coins-in-binary-tree/
- **来源**：LeetCode 第 120 场周赛 Q3
- **难度**：中等
- **标签**：树、深度优先搜索、二叉树、树形 DP

**题意**：二叉树有 $n$ 个节点，第 $u$ 个节点上有 $u.val$ 枚硬币，全树硬币总数为 $n$。一次**移动**可以把一枚硬币从某个节点移到相邻节点（父→子或子→父）。求让**每个节点恰好有 1 枚硬币**所需的**最少移动次数**。

**约束**：

- $1 \le n \le 100$
- $0 \le Node.val \le n$，且所有 $Node.val$ 之和恰为 $n$

> 💡 总硬币数 = 总节点数，所以「每个节点 1 枚」一定能做到，问题只在于**怎么搬最省**。

## 2. 示例

**示例 1**

```text
输入：root = [3,0,0]
输出：2
解释：根有 3 枚，两个子节点各 0 枚。从根分别向左、右各移动 1 枚，共 2 次。
```

**示例 2**

```text
输入：root = [0,3,0]
输出：3
解释：左孩子有 3 枚，根 0 枚、右孩子 0 枚。
      先把 2 枚从左孩子移到根（2 次），再把 1 枚从根移到右孩子（1 次），共 3 次。
```

**示例 3**

```text
输入：root = [1,0,2]
输出：2
解释：右孩子多 1 枚，左孩子缺 1 枚。把右孩子的 1 枚移到根，再从根移到左孩子，共 2 次。
```

## 3. 解题思路

### 3.1 暴力思路

把「每个节点的硬币数」当作状态做 BFS，每次尝试一次相邻移动，直到全 1。状态数是把 $n$ 枚硬币分到 $n$ 个节点的方案数 $\binom{2n-2}{n-1}$，$n = 100$ 时天文数字；即便 $n = 10$ 也已经不可行。这题必须找结构。

### 3.2 核心观察：每条边的净流量是**被迫**的

![子树的「收支」决定它必须通过父边运进/运出多少枚硬币](images/wc120_q3_excess_flow.svg)

考虑以 $u$ 为根的子树 $T_u$，记它包含 $s_u$ 个节点、共有 $c_u$ 枚硬币。由于每个节点最终要有 1 枚，$T_u$ 内部总共需要 $s_u$ 枚，于是：

- 若 $c_u > s_u$，多出的 $c_u - s_u$ 枚**必须**通过唯一的父边运出去；
- 若 $c_u < s_u$，缺少的 $s_u - c_u$ 枚**必须**通过父边运进来。

无论具体怎么搬，这条边上的**净流量**都被钉死为 $|c_u - s_u|$，而「移动次数 ≥ 净流量」是显然的（每搬一枚就计一次）。把每条边（除根外每个节点对应一条父边）的 $|c_u - s_u|$ 加起来，就是这个方案的下界；而这个下界**可以达到**：自底向上，每条边按需要的方向搬，子树内部先自平衡，正好不多不少。

于是问题变成：对每个节点，求它的子树节点数与硬币数。

### 3.3 算法流程

![后序遍历：先处理左右子树，再把「多退少补」的差额上报给父节点](images/wc120_q3_postorder.svg)

```text
dfs(u) 返回「子树 T_u 的盈余」= c_u - s_u（正数表示要运出）
    if u == null: return 0
    l = dfs(u->left)          # 左子树盈余
    r = dfs(u->right)         # 右子树盈余
    ans += |l| + |r|          # 这两条子边各自的搬运次数
    return u->val + l + r - 1 # 汇总后减去自己需要的 1 枚

主函数：ans = 0；dfs(root)；返回 ans
```

返回值 `u->val + l + r - 1` 的来历：左子树汇入 $l$ 枚、右子树汇入 $r$ 枚、自己原有 $u.val$ 枚，合计 $u.val + l + r$；自己留下 1 枚，剩下 `u->val + l + r - 1` 就是本子树要上报的盈余。

### 3.4 示例演算

对示例 2 的 `root = [0,3,0]`（根 0，左 3，右 0）：

| 节点 | 左子树盈余 | 右子树盈余 | 累加 `ans` | 返回盈余 |
|---|---|---|---|---|
| 左孩子（3） | 0 | 0 | +0 | $3 - 1 = 2$ |
| 右孩子（0） | 0 | 0 | +0 | $0 - 1 = -1$ |
| 根（0） | 2 | −1 | $+2 + 1 = 3$ | $0 + 2 - 1 - 1 = 0$ |

总移动次数 $0 + 0 + 3 = 3$ ✓：左孩子运出 2 枚（2 次），根再运 1 枚给右孩子（1 次）。

## 4. 算法细节

1. **返回值是「盈余」而不是「操作数」**：盈余可正可负，正表示要往外运；用带符号的数才能让父节点正确汇总。
2. **`ans` 累加 `abs(l) + abs(r)`**：每条子边的搬运次数等于盈余的绝对值，符号只表示方向。
3. **每个节点返回前减 1**：这 1 枚是「自己最终要留下的」，别忘了；根节点也减，减完应恰好为 0（总数守恒）。
4. **成员变量要重置**：`ans` 是成员变量时，每次进入 `distributeCoins` 都要清零；也可以像下面的 C++ 代码那样用引用参数传递，避免状态残留。
5. **空节点返回 0**：空子树的节点数与硬币数都是 0，盈余 0。
6. **`abs` 的类型**：`int` 足够（$n \le 100$，盈余绝对值 $\le 100$）。

## 5. 正确性证明

**引理 1（边流量被迫）**：对任意非根节点 $u$，设其子树 $T_u$ 有 $s_u$ 个节点、$c_u$ 枚硬币。则任何合法的最终配置都要求：跨越边 $(u, parent(u))$ 的**净流入** $T_u$ 的硬币数为 $s_u - c_u$。

**证明**：最终 $T_u$ 内每个节点恰有 1 枚，共需要 $s_u$ 枚；$T_u$ 与外界的唯一通道是父边，故外部净输入必为 $s_u - c_u$。∎

**引理 2（下界）**：任意移动方案的总次数 $\ge \sum_{u \ne root} |s_u - c_u|$。

**证明**：设方案中跨越边 $(u, parent(u))$ 的移动次数为 $m_u$。每次移动改变 $T_u$ 内硬币数 $\pm 1$，要产生净变化 $s_u - c_u$，由三角不等式 $m_u \ge |s_u - c_u|$。总次数 $= \sum_u m_u \ge \sum_u |s_u - c_u|$（根的边不计）。∎

**引理 3（下界可达）**：存在移动方案使总次数恰为 $\sum_{u \ne root} |s_u - c_u|$。

**证明**：自底向上处理。对每个非根节点 $u$，若 $c_u > s_u$（盈余 $e_u > 0$），把 $e_u$ 枚硬币沿父边运到父节点；若 $c_u < s_u$，从父节点取 $s_u - c_u$ 枚沿父边运入。处理顺序按「先深后浅」：处理 $u$ 时它的子树内部已经平衡（每个节点 1 枚），所以盈余可以整块搬运，恰好用 $|e_u|$ 次。搬完后 $T_u$ 平衡，父节点获得/失去对应数量，继续向上。每条边恰好被搬运 $|e_u|$ 次，总次数等于下界。∎

**引理 4（`dfs` 的返回值正确）**：`dfs(u)` 返回 $c_u - s_u$。

**证明**：对子树高度归纳。叶子：`dfs` 返回 $u.val - 1 = c_u - s_u$ ✓。内部节点：左右子树分别返回 $c_L - s_L$ 与 $c_R - s_R$（归纳假设），返回值为
$$u.val + (c_L - s_L) + (c_R - s_R) - 1 = (u.val + c_L + c_R) - (1 + s_L + s_R) = c_u - s_u$$
✓。∎

**定理**：算法返回最少移动次数。

**证明**：由引理 4，`dfs` 对每个节点 $u$ 返回 $c_u - s_u$，`ans` 累加的 `abs(l) + abs(r)` 正是「$u$ 的两条子边」对应的 $|s_v - c_v|$ 之和——遍历所有节点后，每条非根边恰好被累加一次，故 `ans` $= \sum_{u \ne root} |s_u - c_u|$。由引理 2 它是下界，由引理 3 它可达，故为最小值。∎

## 6. 复杂度分析

- **时间**：$O(n)$，每个节点访问一次，常数次算术运算。
- **空间**：$O(h)$ 递归栈，$h$ 为树高；最坏（链状）$O(n)$，$n \le 100$ 无压力。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int distributeCoins(TreeNode* root) {
        int ans = 0;
        dfs(root, ans);
        return ans;
    }

private:
    // 返回子树盈余（硬币数 - 节点数），正数表示需要向上运出
    int dfs(TreeNode* u, int& ans) {
        if (!u) return 0;
        int l = dfs(u->left, ans);
        int r = dfs(u->right, ans);
        ans += abs(l) + abs(r);           // 两条子边各需搬运的次数
        return u->val + l + r - 1;        // 留下自己那 1 枚
    }
};
```

### Python

```python
class Solution:
    def distributeCoins(self, root) -> int:
        self.ans = 0

        def dfs(u) -> int:
            """返回子树盈余（硬币数 - 节点数），正数表示需要向上运出。"""
            if u is None:
                return 0
            l = dfs(u.left)
            r = dfs(u.right)
            self.ans += abs(l) + abs(r)   # 两条子边各需搬运的次数
            return u.val + l + r - 1      # 留下自己那 1 枚

        dfs(root)
        return self.ans
```

## 8. 边界情况与易错点

1. **单节点**：`root = [1]`，`dfs` 返回 $1-1 = 0$，`ans = 0` ✓。
2. **整棵树已经平衡**：如 `[1,1,1]`，每个节点盈余 0，`ans = 0`，返回 0。
3. **链状树**：如 `[0,0,3]`（3 个节点的链，硬币全在末端），会连续 2 次上报盈余，`ans = 1 + 2 = 3`；注意盈余是**累积**的，不是单条边的差值。
4. **忘记减 1**：返回 `u->val + l + r` 会让盈余整体偏大 $n$，答案全错。
5. **`ans` 未重置**：类成员在多组测试间共享，必须每次清零（或用引用/局部变量）。
6. **把 `abs` 写在返回处**：应累加子边流量的绝对值，而返回值本身要保留符号，两者不能混。
7. **空树**：`root = null` 时返回 0；题目保证 $n \ge 1$，但写法上应安全。
8. **顺序无关**：先算左还是先算右不影响结果，但必须**后序**（先子树后自己），否则盈余算错。
