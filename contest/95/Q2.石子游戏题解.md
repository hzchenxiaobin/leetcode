# LeetCode 石子游戏 题解

## 1. 题目概述

- **标题 / 题号**：石子游戏（#877，medium）
- **链接**：https://leetcode.cn/problems/stone-game/
- **来源**：LeetCode 第 95 场周赛 Q2
- **难度**：中等
- **标签**：极小化极大、数组、数学、动态规划、博弈

**题意**：有**偶数**堆石子排成一行，第 $i$ 堆有 `piles[i]` 颗（正整数），总数是**奇数**（所以不会平局）。Alice 先手，两人轮流从**行首或行尾**取走整堆石子，直到取完。手中石子总数多者获胜。两人都发挥最优水平，返回 Alice 是否必胜（赢返回 `true`，输返回 `false`）。

**关键点**：

- 每回合只能取**两端之一**，取走的堆不再参与。
- 堆数为偶数、总数为奇数——这两个条件不是装饰，它们保证了「无平局」并且（见 §3.3）直接推出 Alice 必胜。

**约束**：

- $2 \le piles.length \le 500$，且为偶数
- $1 \le piles[i] \le 500$
- $\sum piles[i]$ 是奇数

## 2. 示例

**示例 1**

```text
输入：piles = [5,3,4,5]
输出：true
解释：Alice 取左端的 5，剩 [3,4,5]；Bob 无论取 3 还是 5，Alice 都能再拿下较多的那堆，
     最终 Alice 的分更高。最优对弈下 Alice 必胜。
```

**示例 2**

```text
输入：piles = [3,7,2,3]
输出：true
解释：Alice 先取 3（左端）即可锁定所有偶数位的堆（3 + 2 = 5 与 7 + 3 = 10 中较大者），必胜。
```

**示例 3**（补充，说明为什么「必胜」不是巧合）

```text
输入：piles = [1,5,233,7]
输出：true
解释：这类「偶数堆 + 总数奇数」的局面里，先手永远存在必胜策略，一个反例都构造不出来。
```

## 3. 解题思路

### 3.1 暴力思路

枚举「先取左 / 先取右」的所有走法：每回合 2 种选择、共 $n$ 回合，$O(2^n)$，$n = 500$ 时完全不可行。

注意到「剩余局面」只由**区间 $[i, j]$** 决定，而不由之前的取法决定——这是 DP 的信号。朴素 DP 状态数 $O(n^2)$、转移 $O(1)$，复杂度 $O(n^2)$，$n \le 500$ 时约 $2.5\times10^5$，非常轻。

### 3.2 核心观察：净胜分 + 区间 DP

![两种选择与「反号」转移](images/wc95_q2_interval_dp.svg)

不只关心「能拿多少」，而是关心**净胜分**：定义

$$dp[i][j] = \text{在区间 } piles[i..j] \text{ 上，当前行动者最终能比对手多拿的分数}$$

当前行动者有两个选择：

- 取左端 $piles[i]$，之后自己变成「对手」的角色，剩下区间 $[i+1, j]$ 的净胜分是 $dp[i+1][j]$，所以自己的净胜分是 $piles[i] - dp[i+1][j]$。
- 取右端 $piles[j]$，同理是 $piles[j] - dp[i][j-1]$。

两者取最大：

$$dp[i][j] = \max\big(piles[i] - dp[i+1][j],\ piles[j] - dp[i][j-1]\big)$$

边界：$dp[i][i] = piles[i]$（只剩一堆，当前行动者全拿）。

最终答案：$dp[0][n-1] > 0$，即 Alice 的净胜分为正。

**为什么转移里是「减」？** 因为 $dp$ 是「当前行动者 − 对手」的差分。对手在子区间里拿到的净胜分，换算到我这边正好是反号——他多拿一分，我就少一分。

**空间优化**：注意到 $dp[i][j]$ 只依赖 $dp[i+1][j]$（下一行）和 $dp[i][j-1]$（同一行左侧），可以用一维数组滚动：按区间长度从小到大、$i$ 从小到大更新，`dp[i]` 在更新前存的是上一长度（即 $dp[i][i+len-2]$）的值，更新后存 $dp[i][i+len-1]$。

### 3.3 更妙的观察：奇偶分组 ⇒ Alice 恒胜

![奇偶分组：Alice 能锁定较大的一组](images/wc95_q2_parity.svg)

把堆按**下标奇偶**分成两组：

- 偶数组：下标 $0, 2, 4, \ldots, n-2$
- 奇数组：下标 $1, 3, 5, \ldots, n-1$

两组各 $n/2$ 堆（$n$ 为偶数），且 $sum(偶) + sum(奇) = sum(piles)$ 为奇数，所以两组总和**必然不相等**，一组严格更大。

Alice 的策略是**锁定总和较大的那一组**（不妨设是偶数组）：

1. 第一手取左端（下标 $0$，偶数位）。
2. 此时剩余区间是 $[1, n-1]$，两端下标 $1$ 与 $n-1$ 都是**奇数**（因为 $n$ 偶 ⇒ $n-1$ 奇）。Bob 只能取奇数位的堆。
3. Bob 取完后，剩余区间两端变成「一奇一偶」，Alice 取那个**偶数位**的端。
4. 局面回到第 2 步的形态（剩余区间的两端又同为奇数位），如此循环。

于是 Alice 拿到的恰好是**全部偶数位**，Bob 拿到全部奇数位，两人各拿 $n/2$ 堆，Alice 的总和不小于 Bob，又因总和为奇数故严格大于，**Alice 必胜**。

同理，若奇数组更大，Alice 第一手取右端（下标 $n-1$ 是奇数位）即可锁定奇数组。

**因此本题答案恒为 `true`！** 这是本题最漂亮的结论。但由于它依赖「堆数为偶数 + 每堆为正 + 总数奇数」这三个条件，作为**通用博弈模板**，DP 解法更值得掌握（去掉任一条件，结论就不成立）。

### 3.4 示例演算

对 `piles = [5,3,4,5]`（$n = 4$），用一维滚动数组计算：

| 长度 | 区间 | 计算 | $dp$ 值 |
|------|------|------|--------|
| 1 | $[0,0],[1,1],[2,2],[3,3]$ | 初始为各堆 | 5, 3, 4, 5 |
| 2 | $[0,1]$ | $\max(5-3,\ 3-5) = 2$ | 2 |
| 2 | $[1,2]$ | $\max(3-4,\ 4-3) = 1$ | 1 |
| 2 | $[2,3]$ | $\max(4-5,\ 5-4) = 1$ | 1 |
| 3 | $[0,2]$ | $\max(5-dp[1][2],\ 4-dp[0][1]) = \max(5-1,\ 4-2)=4$ | 4 |
| 3 | $[1,3]$ | $\max(3-dp[2][3],\ 5-dp[1][2]) = \max(3-1,\ 5-1)=4$ | 4 |
| 4 | $[0,3]$ | $\max(5-dp[1][3],\ 5-dp[0][2]) = \max(5-4,\ 5-4)=1$ | **1** |

$dp[0][3] = 1 > 0$，返回 `true`。总石子数为 $5+3+4+5 = 17$，净胜 $1$ 分即 Alice 得 $9$ 分、Bob 得 $8$ 分。

## 4. 算法细节

1. **净胜分而非绝对分**：如果只记「当前行动者能拿多少」，转移时需要知道上一步是谁取的、还要额外传参；用差分（净胜分）可以把「轮到谁」的信息消掉，转移式极简。
2. **一维滚动的更新顺序**：外层按 `len` 从 2 到 $n$，内层 `i` 从小到大。此时 `dp[i+1]` 还是上一长度的值（$dp[i+1][i+len-1]$ 在上一长度时对应 $dp[i+1][i+len-2]$），`dp[i]` 尚未被本轮更新（本轮更新前的 `dp[i]` 是 $dp[i][i+len-2]$），两处都取到正确值。
3. **必须从长度 2 开始**：长度 1 的 `dp[i]` 就是 `piles[i]`，直接初始化。
4. **答案是 `> 0` 而非 `>= 0`**：题目保证总数奇数、无平局，所以 `dp[0][n-1]` 不会是 $0$；写 `> 0` 语义最清晰。
5. **数值范围**：$n \le 500$、$piles[i] \le 500$，总和不超 $2.5\times10^5$，`int` 足够。
6. **`n` 一定为偶数**：所以不用处理奇数长度的情形；若数据违约需要额外讨论。

## 5. 正确性证明

**引理 1（状态充分性）**：当前行动者的最优净胜分只取决于剩余区间 $[i,j]$，与之前如何取子无关。

**证明**：可行操作只依赖剩余区间（取左端或右端），且双方的最优策略是「从当前局面出发」的博弈值，与历史无关（无记忆性）。因此 $dp[i][j]$ 是良定义的。∎

**引理 2（转移正确）**：$dp[i][j] = \max(piles[i] - dp[i+1][j],\ piles[j] - dp[i][j-1])$。

**证明**：当前行动者取左端得 $piles[i]$ 分，剩余区间 $[i+1,j]$ 轮到对手，对手在该区间能取得的净胜分（对手减自己）为 $dp[i+1][j]$，故自己的净胜分为 $piles[i] - dp[i+1][j]$。取右端同理为 $piles[j] - dp[i][j-1]$。双方最优，故取两者最大。∎

**引理 3（DP 给出 Alice 净胜分）**：$dp[0][n-1]$ 等于 Alice 的最优得分减 Bob 的最优得分。

**证明**：由引理 1、2 归纳：区间长度从 1 到 $n$ 依次正确，最终 $dp[0][n-1]$ 是 Alice（先手）在整局上的净胜分。∎

**引理 4（奇偶策略可行）**：设偶数组总和 $\ge$ 奇数组总和，则 Alice 可以取到全部偶数位堆。

**证明**：Alice 第一手取下标 $0$（偶数位）。此后每当 Bob 取走一端，剩余区间的两端变为一奇一偶（相邻下标的奇偶性相反），Alice 取其中偶数位的那端。由于每轮 Alice 都消耗一个偶数位堆、Bob 消耗一个奇数位堆，$n/2$ 轮后 Alice 恰好拿完全部偶数位堆。∎

**定理**：Alice 必胜（函数恒返回 `true`）。

**证明**：由引理 4，Alice 能拿到总和较大的那一组（≥ 另一组）。两组总和之和为奇数，故不可能相等，于是 Alice 的总和**严格大于** Bob 的总和，获胜。∎

## 6. 复杂度分析

- **DP 解法**：时间 $O(n^2)$——共 $O(n^2)$ 个区间，每个 $O(1)$ 转移；空间 $O(n)$（一维滚动），若用二维表则 $O(n^2)$。
- **奇偶结论解法**：时间 $O(1)$、空间 $O(1)$，直接返回 `true`。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool stoneGame(vector<int>& piles) {
        int n = piles.size();
        vector<int> dp(piles);                 // dp[i]：区间 [i, i+len-1] 上先手净胜分
        for (int len = 2; len <= n; len++) {
            for (int i = 0; i + len - 1 < n; i++) {
                int j = i + len - 1;
                dp[i] = max(piles[i] - dp[i + 1], piles[j] - dp[i]);
            }
        }
        return dp[0] > 0;
    }
};
```

### Python

```python
class Solution:
    def stoneGame(self, piles: list[int]) -> bool:
        n = len(piles)
        dp = piles[:]                      # dp[i] = 区间 [i, i+len-1] 的先手净胜分
        for length in range(2, n + 1):
            for i in range(n - length + 1):
                j = i + length - 1
                dp[i] = max(piles[i] - dp[i + 1], piles[j] - dp[i])
        return dp[0] > 0
```

> 💡 **另解（$O(1)$）**：由引理 4 与定理，本题在「偶数堆 + 每堆为正 + 总数为奇数」的约束下先手必胜，函数体可直接写 `return true;`（Python 写 `return True`）。比赛中这样写能省下全部计算；但 DP 版本是可迁移到变体的通用模板，建议两者都掌握。

## 8. 边界情况与易错点

1. **返回值是布尔**：题目问「Alice 是否获胜」，不是问得分或最大得分。
2. **转移符号写反**：写成 $piles[i] + dp[i+1][j]$ 是最常见的错误——那表示「两个人得分相加」，与博弈无关。
3. **一维滚动的更新顺序**：内层 `i` 必须从小到大。若从大到小，`dp[i+1]` 可能已被本轮覆盖，得到错误值。
4. **忘记初始化长度为 1**：必须先把 `dp[i]` 设为 `piles[i]`（用 `piles` 拷贝初始化），否则长度 2 的转移会用到 0。
5. **`n = 2`**：只有一个转移，`dp[0] = max(p0 - p1, p1 - p0) = |p0 - p1| > 0`，正确（两堆时先手取较大者必胜）。
6. **`dp[0] == 0` 的情形**：由于总数是奇数，理论上不会出现；若数据违约出现平局，`> 0` 会把平局判为 Bob 胜——这与题目「无平局」的承诺一致。
7. **别被「每堆为正」忽略**：奇偶策略的证明只用到「两组总和不相等」，而总数为奇数保证了这一点；若允许负数堆，结论可能失效。
