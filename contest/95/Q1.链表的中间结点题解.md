# LeetCode 链表的中间结点 题解

## 1. 题目概述

- **标题 / 题号**：链表的中间结点（#876，easy）
- **链接**：https://leetcode.cn/problems/middle-of-the-linked-list/
- **来源**：LeetCode 第 95 场周赛 Q1
- **难度**：简单
- **标签**：链表、双指针

**题意**：给定单链表的头结点 `head`，返回链表的**中间结点**。若有两个中间结点（即结点个数为偶数），返回**第二个**中间结点。

**关键点**：

- 返回的是**结点本身**（后续整段链表），不是结点的值。
- 偶数个结点时明确要求返回「后一个」中间结点。

**约束**：

- 结点数在 $[1, 100]$ 内
- $1 \le Node.val \le 100$

## 2. 示例

**示例 1**

```text
输入：head = [1,2,3,4,5]
输出：[3,4,5]
解释：5 个结点，唯一的中间结点是 3，返回以 3 开头的后半段。
```

**示例 2**

```text
输入：head = [1,2,3,4,5,6]
输出：[4,5,6]
解释：6 个结点，两个中间结点是 3 和 4，返回第二个，即 4。
```

**示例 3**（补充，单结点）

```text
输入：head = [1]
输出：[1]
解释：只有一个结点，它自己就是中间结点。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的两趟做法：

1. 第一趟遍历，数出结点总数 $n$。
2. 第二趟从头走 $\lfloor n/2 \rfloor$ 步，停在中间结点。

复杂度 $O(n)$ 时间、$O(1)$ 空间，完全正确。也可以把结点指针存进数组再取 `n // 2`，但需要 $O(n)$ 额外空间。

还有一类「小聪明」：因为值域只有 $[1,100]$，有人想「数数出现的值」——这是错的，结点值可以重复且与位置无关。

两趟遍历的问题在于「需要先知道长度」。一趟能不能做到？可以，用**快慢指针**。

### 3.2 核心观察：快慢指针一趟定位中点

![逐轮演算：fast 走 2 步、slow 走 1 步](images/wc95_q1_walkthrough.svg)

设两个指针同时从 `head` 出发：

- `slow` 每次走 **1** 步；
- `fast` 每次走 **2** 步。

那么经过 $t$ 轮，`slow` 前进了 $t$ 个结点、`fast` 前进了 $2t$ 个结点。当 `fast` 走到链表末尾（无法再走满 2 步）时，`fast` 走过的距离约为 $n-1$，于是 $t \approx n/2$，`slow` 恰好在中间。

**为什么偶数长度返回的是「第二个」中间结点？** 设 $n = 2m$。`fast` 能从下标 $0$ 走到下标 $2m-2$（还要再走 2 步就到 $2m$，越界），共走 $m-1$ 轮；每轮 `slow` 走 1 步，故 `slow` 停在下标 $m-1$ 之后……精确地说，循环条件 `fast && fast->next` 保证每轮开始时 `fast` 至少还能走两步，第 $m-1$ 轮结束时 `fast` 在下标 $2m-2$、`slow` 在下标 $m-1$；下一轮 `fast->next` 为 `null`，循环停止，`slow` 停在下标 $m-1$。而两个中间结点是下标 $m-1$ 与 $m$，返回的应是 $m$——这里差了一格？

重新核对：$n = 6$，下标 $0..5$，两个中间结点是下标 $2$ 与 $3$，答案应为下标 $3$。模拟：初始 `slow=fast=0`。

- 轮 1：`fast` 非空且 `fast.next`（下标 1）非空 → `slow=1`，`fast=2`。
- 轮 2：`fast=2`，`fast.next=3` 非空 → `slow=2`，`fast=4`。
- 轮 3：`fast=4`，`fast.next=5` 非空 → `slow=3`，`fast=6`（`null`）。
- 轮 4：`fast` 为空 → 停。

`slow = 3`，正是「第二个中间结点」。**关键在于循环条件是 `fast && fast->next`，即每轮要求 `fast` 还能走满两步**；当 `n` 为偶数时，`fast` 最后会正好越过末尾一个结点（走到 `null`），此时 `slow` 多走了一格，于是指向第二个中间结点。如果循环条件写成 `fast->next && fast->next->next`，结果就会变成第一个中间结点。

### 3.3 算法流程

```text
1. slow = head，fast = head
2. while fast 非空 且 fast.next 非空：
   2.1 slow = slow.next
   2.2 fast = fast.next.next
3. 返回 slow
```

### 3.4 示例演算

对 `head = [1,2,3,4,5]`（$n = 5$）：

| 轮次 | `slow` 所在结点 | `fast` 所在结点 | 判断 `fast && fast.next` |
|------|----------------|----------------|------------------------|
| 初始 | 1 | 1 | 成立 |
| 1 | 2 | 3 | 成立 |
| 2 | 3 | 5 | `fast.next = null`，停止 |

返回结点 3（对应输出 `[3,4,5]`），与示例一致。

对 `head = [1,2,3,4,5,6]`（$n = 6$）的演算见上图，最终 `slow` 停在结点 4，返回 `[4,5,6]`。

## 4. 算法细节

1. **循环条件必须是 `fast && fast->next`**：`fast` 非空保证可以读 `fast->next`；`fast->next` 非空保证可以安全执行 `fast->next->next`。少判一个就会在偶数长度时空指针异常。
2. **`slow` 与 `fast` 同时起步于 `head`**：若让 `fast` 先走一步，偶数长度会返回第一个中间结点。
3. **返回 `slow` 而非 `slow->val`**：题目要求返回结点，返回结点的值是最常见的审题错误。
4. **`head` 为空**：题目保证结点数 $\ge 1$，无需特判；若做防御，可在入口返回 `nullptr`。
5. **单结点**：循环一次都不执行，返回 `head`，正确。
6. **不需要额外空间**：相比「存数组」的写法，快慢指针的空间是 $O(1)$。

## 5. 正确性证明

**引理 1（循环不变式）**：每轮循环开始时，若 `slow` 位于下标 $s$、`fast` 位于下标 $f$，则 $f = 2s$ 且 $s \le \lfloor (n-1)/2 \rfloor$。

**证明**：初始 $s = f = 0$，成立。每轮 `slow` 前移 1、`fast` 前移 2，故 $f' = f+2 = 2s+2 = 2(s+1) = 2s'$，关系保持。又循环能继续说明 `fast` 及其后继都存在，即 $f + 1 \le n-1$，从而 $2s \le n-2$，即 $s \le (n-2)/2 < n/2$。∎

**引理 2（终止位置）**：循环结束时 `slow` 位于下标 $\lfloor n/2 \rfloor$。

**证明**：分奇偶讨论。

- $n = 2m+1$（奇数）：由引理 1，循环在 $f = 2s$ 且 $f+1 > n-1 = 2m$ 时停止，即 $2s \ge 2m$，故 $s \ge m$；又 $s \le m$（引理 1 的上界取 $\lfloor (n-1)/2\rfloor = m$），故 $s = m = \lfloor n/2 \rfloor$。
- $n = 2m$（偶数）：停止条件是 $f = n$（`fast` 越过末尾变成 `null`）或 $f = n-1$（`fast.next` 为空）。若 $f = n-1$，则 $2s = 2m-1$ 为奇数，不可能；故 $f = n = 2m$，$s = m = \lfloor n/2\rfloor$。∎

**定理**：算法返回的结点是「中间结点」，偶数个结点时为第二个中间结点。

**证明**：由引理 2，`slow` 停在下标 $\lfloor n/2 \rfloor$。$n$ 为奇数时该下标是唯一的中点；$n$ 为偶数时中点为 $n/2-1$ 与 $n/2$，而 $\lfloor n/2\rfloor = n/2$ 正是**第二个**。∎

## 6. 复杂度分析

- **时间**：$O(n)$。`fast` 每轮前进 2 个结点，最多 $\lceil n/2 \rceil$ 轮，每轮 $O(1)$。
- **空间**：$O(1)$。只用了两个指针。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    ListNode* middleNode(ListNode* head) {
        ListNode* slow = head;
        ListNode* fast = head;
        while (fast && fast->next) {   // fast 走两步、slow 走一步
            slow = slow->next;
            fast = fast->next->next;
        }
        return slow;
    }
};
```

### Python

```python
class Solution:
    def middleNode(self, head):
        slow = fast = head
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next
        return slow
```

## 8. 边界情况与易错点

1. **返回结点的值而非结点**：`return slow.val` 是最常见的错误，题目要求返回 `ListNode`。
2. **循环条件漏判 `fast->next`**：$n$ 为偶数时 `fast->next->next` 会解引用空指针（Python 抛 `AttributeError`）。
3. **循环条件写成 `fast->next && fast->next->next`**：偶数长度会返回第一个中间结点，与题意相反。
4. **`fast` 起步晚一步**：同样会把「第二个中间结点」变成「第一个」。
5. **单结点链表**：必须在循环条件里正确处理，不能先执行一次 `slow = slow->next`。
6. **`n = 2`**：返回第二个结点（即 `head->next`）。验证：`fast` 有 `next`，走一轮后 `slow` 到第二个结点、`fast` 到 `null`，正确。

**延伸思考**：如果要求「删除中间结点」（而非返回），需要让 `slow` 停在中点的**前一个**，只需把循环条件改为 `fast->next && fast->next->next`，并在结束时执行 `slow->next = slow->next->next`。若链表长度未知且要求 $O(1)$ 空间返回倒数第 $k$ 个结点，可以让两个指针先拉开 $k$ 步再同步前进。若链表是双向链表，则可从两端同时向中间走，同样 $O(n)$、$O(1)$。
