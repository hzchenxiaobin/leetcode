# LeetCode 移除指定数字得到的最大结果 题解

## 1. 题目概述

- **标题 / 题号**：移除指定数字得到的最大结果（#2259，easy）
- **链接**：https://leetcode.cn/problems/remove-digit-from-number-to-maximize-result/
- **来源**：LeetCode 第 291 场周赛 Q1
- **难度**：简单
- **标签**：贪心、字符串、枚举

**题意**：给定表示正整数的字符串 `number` 和字符 `digit`。从 `number` 中**恰好移除一个**等于 `digit` 的字符，返回能得到的**最大**结果字符串。题目保证 `digit` 在 `number` 中至少出现一次。

**约束**：

- `2 <= number.length <= 100`
- `number` 仅由 `'1'` 到 `'9'` 组成（**不含 `'0'`**，无前导零问题）
- `digit` 是 `'1'` 到 `'9'` 中的一个数字，且在 `number` 中至少出现一次

## 2. 示例

**示例 1**

```text
输入：number = "123", digit = '3'
输出："12"
解释："123" 中只有一个 '3'，移除后结果为 "12"。
```

**示例 2**

```text
输入：number = "1231", digit = '1'
输出："231"
解释：移除第一个 '1' 得 "231"，移除第二个 '1' 得 "123"，231 > 123。
```

**示例 3**

```text
输入：number = "551", digit = '5'
输出："51"
解释：移除任一个 '5'，结果都是 "51"。
```

**示例 4**（体现贪心判定规则）

```text
输入：number = "1232", digit = '2'
输出："132"
解释：删 index 1 的 '2'（后继 '3' > '2'）得 "132"；删 index 3 的 '2' 只得 "123"。
```

## 3. 解题思路

### 3.1 暴力思路：枚举所有删除位置

`digit` 的每个出现位置都生成一个候选串，取字典序最大者：

```python
return max(number[:i] + number[i + 1:]
           for i, c in enumerate(number) if c == digit)
```

- 时间 $O(n^2)$（每个候选的拼接与比较都是 $O(n)$），`n <= 100` 完全可过。
- 签到题这样写最稳；但既然是周赛复盘，值得多想一步 $O(n)$ 贪心。

### 3.2 核心观察：两个候选的差异最早出现在哪里？

![核心观察：删 i 还是删 j](images/2259_remove_digit_concept.svg)

设 $i < j$ 是 `digit` 的两个出现位置，记删 $i$、删 $j$ 得到的结果分别为 $R_i$、$R_j$：

- 两串的前 $i$ 个字符相同（都保留 `number[0..i-1]`）；
- 下标 $i$ 处：$R_i[i] = number[i+1]$（后缀左移一位顶上来），而 $R_j[i] = number[i] = digit$（删 $j$ 不影响前缀）；
- **胜负在位置 $i$ 一分，后面的字符不用看。**

于是得到逐位判定规则：

| 条件 | 结论 |
|------|------|
| `number[i+1] > digit` | 删 $i$ 严格更优（对所有 $j > i$ 都成立） |
| `number[i+1] < digit` | 删 $i$ 严格更差，应往后看 |
| `number[i+1] == digit` | 删 $i$ 与删 $i+1$ 的结果**完全相同**，决策可顺延 |

**贪心策略**：从左到右扫描，遇到第一个满足 `number[i+1] > number[i]` 的 `digit` 出现位置就删它；若始终没有，说明任何提前删除都"不变好"，删**最后一个**出现位置最优。

### 3.3 算法流程

![算法流程图](images/2259_remove_digit_flow.svg)

1. 正向扫描 $i = 0, 1, \ldots, n-2$；
2. 若 `number[i] == digit` 且 `number[i+1] > digit`，立即删除位置 $i$ 并返回；
3. 扫描结束仍未触发，从右往左找到最后一个 `digit` 出现位置 $L$，删除并返回。

### 3.4 示例演算

![示例演算](images/2259_remove_digit_walkthrough.svg)

`number = "1231"`，`digit = '1'`：

| 删除位置 | 结果 | 首位字符 |
|----------|------|----------|
| index 0 | "231" | '2' |
| index 3 | "123" | '1' |

$i = 0$ 时 `number[1] = '2' > '1'`，直接删 index 0，返回 `"231"` ✓

`number = "551"`，`digit = '5'`：$i=0$ 时 `'5'` 不大于 `'5'`，$i=1$ 时 `'1'` 不大于 `'5'`，无提前删除点 → 走兜底分支删最后一个 `'5'`，返回 `"51"` ✓

## 4. 算法细节

1. **判定条件**：`number[i] == digit && i + 1 < n && number[i + 1] > digit`，注意最后一个位置没有后继，必须带 `i + 1 < n` 的越界保护。
2. **兜底分支**：扫描无果时从右往左找最后一个出现位置——每个出现位置的后继都不超过 `digit` 时，保留 `digit` 在原位不劣于任何提前删除，故让删除点尽量靠后。
3. **字符串拼接**：结果 = `number[:i] + number[i+1:]`，C++ 用两次 `substr` 拼接。
4. **比较即数值**：候选串等长且无前导零（`number` 不含 `'0'`），字典序比较等价于数值比较，无需转数字。

## 5. 正确性证明

**引理 1**（等长可比）：所有候选结果长度均为 $n-1$，且字符串字典序比较等价于数值比较。

**证明**：删除一个字符使长度减一；等长十进制数字串的字典序与数值大小一致，且 `number` 只含 `'1'`~`'9'`，无前导零干扰。∎

**引理 2**（首位差异）：设 $i < j$ 均为 `digit` 的出现位置，则 $R_i$ 与 $R_j$ 在下标 $0..i-1$ 上相同，且 $R_i[i] = number[i+1]$，$R_j[i] = digit$。

**证明**：删除位置 $\ge i$ 不影响前缀 `number[0..i-1]`，故两候选前 $i$ 位相同。$R_i$ 把 `number[i+1..]` 左移一位，位置 $i$ 放的是 $number[i+1]$；$R_j$ 中位置 $i$ 仍是原字符 $number[i] = digit$。∎

**定理**：上述贪心策略返回最大结果。

**证明**：分两种情形。

- **存在**满足 $number[i_0+1] > digit$ 的出现位置，取其中最小的 $i_0$（由 $i_0 + 1 < n$ 知 $i_0 \le n-2$）。
  - 对任意出现位置 $j > i_0$：由引理 2，$R_{i_0}$ 与 $R_j$ 首次差异在下标 $i_0$，$R_{i_0}[i_0] = number[i_0+1] > digit = R_j[i_0]$，故 $R_{i_0} > R_j$。
  - 对任意出现位置 $j < i_0$：由 $i_0$ 的最小性，$number[j+1] \le digit$。若 $number[j+1] < digit$，由引理 2 得 $R_j < R_{i_0}$；若 $number[j+1] = digit$，则 $j+1$ 也是出现位置，且连续两位相等时删左删右结果一样，即 $R_j = R_{j+1}$，可将 $R_j$ 等价替换为 $R_{j+1}$ 重复此论证（出现位置严格递增，过程必然终止），最终化为严格小于或到达 $i_0$。故 $R_j \le R_{i_0}$。
  - 因此删 $i_0$ 最优。
- **不存在**这样的位置，即所有满足 $i \le n-2$ 的出现位置都有 $number[i+1] \le digit$。设 $L$ 为最后一个出现位置。对任意出现位置 $j < L$：同理，首次差异在下标 $j$ 处 $R_j[j] = number[j+1] \le digit = R_L[j]$，严格小于则 $R_j < R_L$，相等则 $R_j = R_{j+1}$ 顺延。故 $R_j \le R_L$，删 $L$ 最优。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。最多两遍线性扫描（正向找提前删除点 + 反向找最后出现位置），最后拼接结果 $O(n)$。
- **空间复杂度**：$O(n)$ 用于存放返回串；若不计输出则为 $O(1)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    string removeDigit(string number, char digit) {
        int n = number.size();
        for (int i = 0; i + 1 < n; i++) {
            if (number[i] == digit && number[i + 1] > digit) {
                return number.substr(0, i) + number.substr(i + 1);
            }
        }
        for (int i = n - 1; i >= 0; i--) {
            if (number[i] == digit) {
                return number.substr(0, i) + number.substr(i + 1);
            }
        }
        return ""; // 不会到达：digit 至少出现一次
    }
};
```

### Python

```python
class Solution:
    def removeDigit(self, number: str, digit: str) -> str:
        n = len(number)
        for i in range(n - 1):
            if number[i] == digit and number[i + 1] > digit:
                return number[:i] + number[i + 1:]
        for i in range(n - 1, -1, -1):
            if number[i] == digit:
                return number[:i] + number[i + 1:]
        return ""
```

## 8. 边界情况与易错点

1. **`i+1` 越界**：判定条件必须带 `i + 1 < n`（或正向循环上界取 `n-1`），最后一个位置没有后继可比较。
2. **必须严格大于**：条件是 `number[i+1] > digit` 而非 `>=`。相等时提前删结果虽相同（引理 2 的顺延性质），但"严格大于"才是判定"更优"的正确语义，也和证明严格对应。
3. **`digit` 只出现一次**：正向扫描必然落空，兜底分支删掉它即可，如 `"123"` 删 `'3'`。
4. **连续相同的 `digit`**：如 `"551"`，删哪个结果都一样，兜底分支删最后一个。
5. **别转成整数**：`n` 可达 100 位（$10^{100}$ 量级），超出 `long long` 范围，必须全程按字符串处理。
6. **首位候选别漏**：`digit` 在首位且后继更大时（如 `"1231"` 删 index 0）正是贪心收益最大的情形。
