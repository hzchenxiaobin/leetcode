# LeetCode 字符串的总引力 题解

## 1. 题目概述

- **标题 / 题号**：字符串的总引力（#2262，hard）
- **链接**：https://leetcode.cn/problems/total-appeal-of-a-string/
- **来源**：LeetCode 第 291 场周赛 Q4
- **难度**：困难
- **标签**：字符串、哈希表、贡献法、动态规划

**题意**：字符串的**引力**定义为其中**不同字符**的数量（如 `"abbca"` 的引力为 $3$）。给定字符串 $s$，返回其**所有子字符串**的引力之和。子字符串是连续字符序列。

**约束**：

- $1 \le \text{s.length} \le 10^5$
- `s` 由小写英文字母组成

> 💡 本题在本仓库另有[每日题解 2262](../../solution/2201-2300/2262_字符串的总引力.md)：以「右端扩展 DP：$f(i) = f(i-1) + (i - \text{last}[s_i])$」为主线。本篇按**周赛复盘视角**展开，以**贡献法（按首次出现位置计数）**为主线——每个字符只在子串中的**首次出现**处贡献 $+1$，一步得到闭式 $\sum (i - \text{last}[s_i]) \times (n - i)$，并补齐**引理-定理化的严格证明**与**赛场易错清单**，两篇互为印证。同场 Q3 的「枚举子数组 + 按端点聚合」套路在这里的加权版。

## 3. 解题思路

### 3.1 暴力思路：枚举所有子串，增量数不同字符

照搬题意：枚举右端点 $i$，向左扩展左端点 $j$，用哈希集合增量维护窗口内出现过的字符，每扩一步把集合大小累加进答案：

```python
ans = 0
for i in range(n):
    seen = set()
    for j in range(i, -1, -1):      # 以 i 为右端，向左扩展
        seen.add(s[j])
        ans += len(seen)             # s[j..i] 的引力
```

内层虽然 $O(1)$ 增量维护，但子串总数达 $\frac{n(n+1)}{2} \approx 5 \times 10^9$（$n = 10^5$），**必然超时**。

> ⚠️ 浪费在于：对每个子串单独问「引力是多少」，而引力 $=$ 子串中不同字符数 $=$ $\sum_c [\text{子串含 } c]$。把「逐子串求和」改成「逐字符求和」，就能跳过 $O(n^2)$ 枚举——这是**贡献法**（换求和顺序）登场的信号。

### 3.2 核心观察：贡献法——每个字符只在「首次出现」处计数

![核心观察：位置 i 的字符作为子串中首次出现时，可选左端 (last, i] 与右端 [i, n-1] 独立组合](images/2262_appeal_concept.svg)

子串 $t$ 含字符 $c$，等价于「$c$ 在 $t$ 中的**首次出现位置**落在 $t$ 内」。于是每个子串的引力可以按「首次出现位置」逐点拆开：

$$\text{appeal}(t) = \#\{\, i \in t : s_i \text{ 是 } s_i \text{ 在 } t \text{ 中的首次出现} \,\}$$

对总引力换求和顺序，按**位置** $i$ 分组：设 $\text{last}_i$ 为 $s_i$ 在 $s[0..i-1]$ 中的最右出现下标（无则 $-1$），则

$$s_i \text{ 是 } s[j..k] \text{ 中该字符的首次出现} \iff \text{last}_i < j \le i \le k$$

- **左端** $j$ 落在 $(\text{last}_i,\ i]$，共 $i - \text{last}_i$ 个；
- **右端** $k$ 落在 $[i,\ n-1]$，共 $n - i$ 个。

左右独立，由**乘法原理**，位置 $i$ 的贡献为 $(i - \text{last}_i) \times (n - i)$。对所有位置求和：

$$\text{ans} = \sum_{i=0}^{n-1} \big(i - \text{last}[s_i]\big) \times (n - i)$$

> 💡 一句话：**每个位置的贡献 = 它到上一次同字符出现的距离 × 它到串尾的距离**。字符重复出现时只有最新的那次在「攒」贡献，旧的被顶掉——这正是 `last` 数组滚动维护的全部内容。

### 3.3 算法流程

![算法流程：初始化 last 为 -1 → 取 c 与 L=last[c] → ans 累加 (i−L)×(n−i) → 更新 last[c]=i → 循环](images/2262_appeal_flow.svg)

1. `last[26]` 全部初始化为 $-1$，`ans = 0`；
2. 从左到右遍历 $i = 0, \dots, n-1$，记 $c = s_i$：
   - `ans += (i - last[c]) * (n - i)`；
   - `last[c] = i`；
3. 遍历结束，返回 `ans`。

**与 DP 视角的等价**：每日题解的递推 $f(i) = f(i-1) + (i - \text{last}[s_i])$（$f(i)$ 为以 $i$ 结尾的子串引力之和）与本式一一对应——把贡献式按求和顺序重排：

$$\sum_{i=0}^{n-1} f(i) = \sum_{i=0}^{n-1} \sum_{k \le i} \big(k - \text{last}[s_k]\big) = \sum_{k=0}^{n-1} \big(k - \text{last}[s_k]\big) \times (n - k)$$

即「DP 逐右端点滚动」与「贡献法一步到位」是同一枚硬币的两面。

### 3.4 示例演算

![示例演算：s = abbca 逐位置计算 (i−last)×(n−i) 并累加](images/2262_appeal_walkthrough.svg)

以示例 1 `s = "abbca"`（$n = 5$，下标从 0 开始）走查：

| $i$ | $s_i$ | $\text{last}$ | $i-\text{last}$ | $n-i$ | 贡献 $(i-\text{last})(n-i)$ | `ans` |
|----|-------|--------------|-----------------|-------|------------------------------|-------|
| 0 | `a` | $-1$ | 1 | 5 | $1 \times 5 = 5$ | 5 |
| 1 | `b` | $-1$ | 2 | 4 | $2 \times 4 = 8$ | 13 |
| 2 | `b` | $1$ | 1 | 3 | $1 \times 3 = 3$ | 16 |
| 3 | `c` | $-1$ | 4 | 2 | $4 \times 2 = 8$ | 24 |
| 4 | `a` | $0$ | 4 | 1 | $4 \times 1 = 4$ | 28 |

**答案 = 28** ✓。注意 $i=2$ 的 `b`：左边已有 `b`，左端只能取 $\{2\}$，贡献骤降为 $3$——重复字符「稀释」贡献的直观体现。

## 4. 算法细节

1. **下标语义**：0-indexed，`last` 初始 $-1$ 表示「左侧未出现」。左端区间 $(\text{last},\ i]$ 是**左开右闭**（$j$ 必须 $> \text{last}$ 才能保证 $i$ 是首次出现），右端区间 $[i,\ n-1]$ 是**双闭**。
2. **乘法原理的独立性**：左端 $j$ 与右端 $k$ 的取值互不约束（$j \le i \le k$ 已由区间保证），故二元组数 $=$ 左端数 $\times$ 右端数，无需容斥。
3. **`last` 的更新时机**：必须**先**用 `last[c]` 计算贡献，**再**执行 `last[c] = i`；写反会把每个位置都当成「紧邻上一次出现」，贡献恒为 $n - i$，答案严重偏小。
4. **答案规模与溢出**：子串数 $\le \frac{n(n+1)}{2} \approx 5 \times 10^9$，每串引力 $\le 26$，总引力上界 $\approx 1.3 \times 10^{11}$；单步乘积 $(i - \text{last})(n - i)$ 在 $i$ 居中且字符首次出现时约为 $\frac{n^2}{4} \approx 2.5 \times 10^9$——**两者都已超出 32 位 `int`**（$\approx 2.1 \times 10^9$），C++ 中 `ans` 与中间乘积都必须用 `long long`。Python 整数任意精度，无此虑。
5. **字母表只影响空间**：`last` 只需 $O(26)$；即使把「小写字母」推广到任意大字符集（见延伸思考），`last` 换成哈希表仍是 $O(n)$ 时间。
6. **两种实现形态**（见 §7）：C++ 用贡献法闭式一步累加；Python 用 DP 滚动（`cur += i - last[c]; ans += cur`），由 §3.3 的重排保证二者等价。

## 5. 正确性证明

**引理 1（引力按首次出现分解）**：对任意子串 $t$，$\text{appeal}(t) = \#\{(c, p) : p \text{ 是 } c \text{ 在 } t \text{ 中的首次出现位置}\}$。

**证明**：对每个在 $t$ 中出现的字符 $c$，其出现位置构成非空集合，其中恰有一个最小元（首次出现）；反之每个首次出现位置 $p$ 唯一确定字符 $c = s_p$。故映射 $c \mapsto \text{first}_t(c)$ 是「$t$ 中出现的字符集」与「$t$ 中首次出现位置集」之间的双射，两边计数相等。∎

**引理 2（首次出现的子串刻画）**：设 $c = s_i$，$\text{last}$ 为 $c$ 在 $s[0..i-1]$ 中的最右出现下标（不存在则 $-1$）。对子串 $t = s[j..k]$（$j \le i \le k$）：

$$s_i \text{ 是 } c \text{ 在 } t \text{ 中的首次出现} \iff j > \text{last}$$

**证明**：

- （$⇐$）若 $j > \text{last}$：由 $\text{last}$ 的最大性，$s[j..i-1]$ 中无 $c$，而 $s_i = c$，故 $i$ 是 $c$ 在 $t$ 中的首次出现。
- （$⇒$）反证：若 $j \le \text{last}$，则 $j \le \text{last} < i \le k$，即 $s_{\text{last}} = c$ 落在 $t$ 中且位于 $i$ 之前，$i$ 不是首次出现，矛盾。∎

**定理**：$\displaystyle \text{ans} = \sum_{i=0}^{n-1} \big(i - \text{last}_i\big) \times (n - i)$，其中 $\text{last}_i$ 为 $s_i$ 在其左侧的最右同字符下标（无则 $-1$）。

**证明**：

$$\text{ans} = \sum_{t} \text{appeal}(t) = \sum_{t} \#\{(c, p) : p \text{ 是 } c \text{ 在 } t \text{ 中首次出现}\} \quad (\text{引理 1})$$

交换求和顺序，把每个配对 $(t, (c, p))$ 按 $p$ 分组（同一个 $t$ 内不同字符的首次出现位置互异，不同 $t$ 独立计数，分组不重不漏）：

$$= \sum_{i=0}^{n-1} \#\{ t = s[j..k] : j \le i \le k,\ s_i \text{ 是 } s_i \text{ 在 } t \text{ 中首次出现} \}$$

由引理 2，条件等价于 $\text{last}_i < j \le i \le k$。满足条件的 $(j, k)$ 二元组数为

$$\#\{j \in (\text{last}_i, i]\} \times \#\{k \in [i, n-1]\} = (i - \text{last}_i) \times (n - i)$$

（两区间取值独立，乘法原理）。求和即得结论。∎

**推论（与 DP 递推等价）**：记 $f(i)$ 为以 $i$ 结尾的子串引力之和，则 $f(i) = f(i-1) + (i - \text{last}[s_i])$，且 $\sum_i f(i)$ 等于定理右端。

**证明**：$\sum_{i=0}^{n-1} f(i) = \sum_{i} \sum_{k \le i} (k - \text{last}[s_k]) = \sum_{k} (k - \text{last}[s_k]) \cdot \#\{i : k \le i \le n-1\} = \sum_{k} (k - \text{last}[s_k])(n - k)$，与定理一致。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。单趟扫描 $n$ 个位置，每步一次数组读写、一次乘法、一次加法，均为 $O(1)$。
- **空间复杂度**：$O(|\Sigma|) = O(26)$。仅 `last` 数组（或哈希表）作为额外空间，与 $n$ 无关。

## 7. 参考代码

### C++（贡献法闭式）

```cpp
class Solution {
  public:
    long long appealSum(string s) {
        int n = s.size();
        vector<int> last(26, -1);
        long long ans = 0;
        for (int i = 0; i < n; ++i) {
            int c = s[i] - 'a';
            ans += 1LL * (i - last[c]) * (n - i);   // 定理：(i−last)×(n−i)
            last[c] = i;                             // 先算后更新
        }
        return ans;
    }
};
```

### Python（DP 滚动形态，与上等价）

```python
class Solution:
    def appealSum(self, s: str) -> int:
        n = len(s)
        last = {}
        ans = cur = 0
        for i, c in enumerate(s):
            cur += i - last.get(c, -1)   # f(i) = f(i-1) + i − last[c]
            ans += cur                   # ans 累加以 i 结尾的引力之和
            last[c] = i
        return ans
```

## 8. 边界情况与易错点

1. **整数溢出（C++）**：`ans` 上界 $\approx 26 \times \frac{n(n+1)}{2} \approx 1.3 \times 10^{11}$，且**单步乘积** $(i - \text{last})(n - i)$ 最大约 $\frac{n^2}{4} = 2.5 \times 10^9$ 已破 `int`——累加前必须转 `long long`（`1LL *` 前缀），只在 `ans` 上转型不够。
2. **先算后更新**：`last[c] = i` 必须在累加贡献**之后**执行；写反则每个位置的 $i - \text{last}$ 恒为 $n - i$ 量级错乱。
3. **0/1-indexed 混用**：0-indexed 配 `last` 初值 $-1$；若写 1-indexed（$f(i) = f(i-1) + i - \text{last}[s_i]$）则初值 $0$。两套坐标混着写是本场最常见的 WA 源。
4. **区间开闭方向**：左端是 $(\text{last},\ i]$ **左开**右闭（$j = \text{last}$ 时 $i$ 已非首次出现），右端是 $[i,\ n-1]$ 双闭，共 $n - i$ 个（不是 $n - i + 1$）。
5. **单字符串**：`"a"` → $1$；`"aaaa"` → $\frac{n(n+1)}{2} = 10$（每串引力恰 1），可作提交前 sanity check。
6. **全互异字符**：如 `"code"`，贡献为 $\sum (i+1)(n-i)$；此时答案也等于 $\sum_{L=1}^{n} L \times (n - L + 1)$（长度为 $L$ 的子串各有 $n - L + 1$ 个），可交叉验证。
7. **别把「不同字符」当「唯一字符」**：本题统计**出现至少一次**（首次出现处 $+1$）；[828. 统计子串中的唯一字符](https://leetcode.cn/problems/count-unique-characters-of-all-substrings-of-a-given-string/)统计**恰好一次**，贡献变为 $(i - \text{prev})(\text{next} - i)$，需要同时盯住前驱与后继——两题公式形似而义不同，考场上极易串门。
8. **`n - i` 的语义**：它是「以 $i$ 为首次出现时可选右端个数」，随 $i$ 递增而递减；把它写成 $i + 1$（左端个数）是 DP / 贡献两视角切换时的典型笔误。
