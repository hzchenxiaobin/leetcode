# LeetCode 找到两个数组的前缀公共数组 题解

## 1. 题目概述

- **标题 / 题号**：找到两个数组的前缀公共数组（#2657，medium）
- **链接**：https://leetcode.cn/problems/find-the-prefix-common-array-of-two-arrays/
- **来源**：LeetCode 第 103 场双周赛 Q2
- **难度**：中等
- **标签**：位运算、数组、哈希表

**题意**：给定两个长度为 $n$ 的排列 $A$、$B$（各含 $1 \sim n$ 恰好一次）。定义前缀公共数组 $C$：$C[i]$ 等于 $A[0..i]$ 与 $B[0..i]$ 两个前缀中**都出现过**的元素个数。返回 $C$。

**约束**：

- $1 \le n \le 50$
- $A$、$B$ 均为 $1 \sim n$ 的排列

## 2. 示例

**示例 1**

```text
输入：A = [1,3,2,4], B = [3,1,2,4]
输出：[0,2,3,4]
解释：i=0：{1} ∩ {3} 为空，C[0]=0；
      i=1：{1,3} ∩ {3,1} = {1,3}，C[1]=2；
      i=2：{1,2,3} ∩ {1,2,3}，C[2]=3；
      i=3：全部 {1,2,3,4}，C[3]=4。
```

**示例 2**

```text
输入：A = [2,3,1], B = [3,1,2]
输出：[0,1,3]
解释：i=0：{2} ∩ {3} 为空；i=1：{2,3} ∩ {3,1} = {3}；
      i=2：三个值全部出现于两个前缀。
```

**示例 3（边界补充）**

```text
输入：A = [1,2,3], B = [1,2,3]
输出：[1,2,3]
解释：A 与 B 完全相同时，每个下标 i 的前缀都完全一致，C[i] = i+1。
```

## 3. 解题思路

### 3.1 暴力思路

对每个下标 $i$，重建前缀集合 $\text{set}(A[0..i])$ 与 $\text{set}(B[0..i])$，求交集大小——$O(n^2)$（或带哈希常数）。$n \le 50$ 时 $2500$ 次操作当然能过，但它完全忽略了问题的**增量结构**：从下标 $i-1$ 到 $i$，两个前缀各自只多了一个元素，交集大小怎么可能凭空重建？哨兵观察是：$C$ 是**单调不减**的，且每一步的增量只由新加入的 $A[i]$、$B[i]$ 决定。

### 3.2 核心观察：值计数到 2 即"转正"

![核心观察：前缀逐步扩张，某个值在 A、B 两侧都出现过的时刻，计数恰好达到 2](images/bw103_q2_prefix_sets.svg)

逐位推进时维护一个计数数组 $\text{cnt}[1..n]$，初值为 $0$。处理下标 $i$ 时：

- $\text{cnt}[A[i]]$ 自增；若**恰好变成 2**，说明值 $A[i]$ 此刻在两个前缀中都出现过了，公共数 $+1$；
- $\text{cnt}[B[i]]$ 同理。

为什么"变成 2"是正确的信号？因为 $A$、$B$ 都是排列，任意值 $x$ 在两数组中**各出现恰好一次**，跨 $A$、$B$ 共出现恰好两次。它的计数从 $0 \to 1 \to 2$ 严格递增，且**达到 2 的那一步**正是它"补齐了另一半前缀"的时刻——恰好对应 $x$ 首次同时落入两个前缀集合。于是用一个滚动计数 `common`，处理完下标 $i$ 后直接 $C[i] = \text{common}$。

等价的**位掩码**写法：维护 $\text{mask}_A$、$\text{mask}_B$，每步 $\text{mask}_A \mathrel{|}= 2^{A[i]-1}$、$\text{mask}_B \mathrel{|}= 2^{B[i]-1}$，则 $C[i] = \text{popcount}(\text{mask}_A \,\&\, \text{mask}_B)$。$n \le 50$ 需要 64 位整型。

### 3.3 算法流程

![算法流程：每步两个计数自增，计数达 2 转正，公共数落盘到当前下标](images/bw103_q2_increment_count.svg)

```text
1. cnt[1..n] = 0，common = 0
2. for i = 0 .. n-1:
3.     cnt[A[i]] += 1；若 cnt[A[i]] == 2：common += 1
4.     cnt[B[i]] += 1；若 cnt[B[i]] == 2：common += 1
5.     C[i] = common
6. 返回 C
```

### 3.4 示例演算

![示例演算：A 为 1,3,2,4，B 为 3,1,2,4，逐步计数与转正时机](images/bw103_q2_example_walkthrough.svg)

以示例 1（$A = [1,3,2,4]$，$B = [3,1,2,4]$）演算：

| $i$ | 新加入 | 计数变化 | 转正的值 | common | $C[i]$ |
|-----|--------|----------|----------|--------|--------|
| 0 | $A{:}1,\ B{:}3$ | cnt[1]=1, cnt[3]=1 | — | 0 | 0 |
| 1 | $A{:}3,\ B{:}1$ | cnt[3]=2, cnt[1]=2 | $3,\ 1$ | 2 | 2 |
| 2 | $A{:}2,\ B{:}2$ | cnt[2]=2 | $2$ | 3 | 3 |
| 3 | $A{:}4,\ B{:}4$ | cnt[4]=2 | $4$ | 4 | 4 |

$i=2$ 处 $A[2] = B[2] = 2$，两次自增一次到位：`cnt[2]` 先到 2 记一次转正，再到 3 不再记——不会重复计数。

## 4. 算法细节

1. **计数数组开 $n+1$**：值域是 $1 \sim n$，`cnt` 下标 $0$ 弃用，避免 $-1$ 偏移错误。
2. **`== 2` 而非 `>= 2`**：每个值跨两数组恰好出现两次，计数只会经过 2 一次；用 `>=` 不会错（不会出现 3 以上），但 `== 2` 表达了"恰好转正"的语义。
3. **同位置相等值的一次到位**：$A[i] = B[i] = x$ 时，第一次自增就让 cnt$[x]$ 从 1 到 2（若 $x$ 已在另一侧前缀出现过）或从 0 到 1；第二次自增可能把它带到 3。判等 `== 2` 保证了这类值也只记一次。
4. **滚动变量替代每步全量求交**：`common` 单调不减，是"前缀集合只增不减"的直接体现——前缀集合的交自然也只增不减。
5. **位掩码版的细节**：$n = 50 > 32$，必须用 64 位（C++ 用 `1LL << (x-1)`，Python 天然大整数）；popcount 用 `__builtin_popcountll` / Python `int.bit_count()`。
6. **两法取舍**：计数版 $O(n)$ 时间 $O(n)$ 空间，位掩码版 $O(n)$ 时间 $O(1)$ 空间但乘上 64 位 AND/popcount 常数，本题规模下随意；把计数版作为主代码，因为它对"排列中每个值恰好出现两次"的依赖更少（值域有重复时依然正确）。

## 5. 正确性证明

**引理 1（计数的轨迹）**：$A$、$B$ 均为 $1 \sim n$ 的排列，故任意值 $x \in [1, n]$ 在 $A$、$B$ 中共出现恰好两次；算法运行中 $\text{cnt}[x]$ 的两次自增各发生在 $x$ 被 $A$ 或 $B$ 的某个前缀纳入之时，且计数严格沿 $0 \to 1 \to 2$ 变化。

**证明**：排列保证每个值在 $A$ 中出现一次、在 $B$ 中出现一次。算法只在处理到 $x$ 的那次出现时对 cnt$[x]$ 自增，共两次；自增序列即 $0 \to 1 \to 2$ ∎

**引理 2（转正时刻的刻画）**：处理完下标 $i$ 后 $\text{cnt}[x] = 2$，当且仅当 $x$ 同时出现在 $\text{set}(A[0..i])$ 与 $\text{set}(B[0..i])$ 中；且 cnt$[x]$ 恰在"第二个包含 $x$ 的前缀补齐"的那一步变成 2。

**证明**：cnt$[x]$ 的两次自增分别对应 $x$ 在 $A[0..i]$ 中的（唯一）出现与在 $B[0..i]$ 中的（唯一）出现（若均 $\le i$）。两次都发生当且仅当两个前缀都含 $x$，即计数为 2；仅一次发生时计数为 1，两个前缀只有一侧含 $x$。第二次自增恰发生在两个下标 $\text{pos}_A(x), \text{pos}_B(x)$ 中较大者被处理的那一步 ∎

**定理**：算法输出的 $C[i]$ 等于两个前缀的公共元素个数。

**证明**：由引理 2，处理下标 $i$ 时（无论 $A[i]$、$B[i]$ 是否触发），任意值 $x$ 属于两前缀交集当且仅当 cnt$[x] = 2$，且 cnt$[x]$ 达到 2 的那一步会且只会使 `common` 增加 1（引理 1 保证不重；每步至多两个值触发）。归纳可知 `common` 在处理完 $i$ 后恰等于"已转正值的个数" = 两前缀交集的大小，赋给 $C[i]$ 即得 ∎

## 6. 复杂度分析

- **时间**：$O(n)$。每个下标常数次自增与判断，无嵌套循环。
- **空间**：$O(n)$（计数数组）；位掩码实现为 $O(1)$ 额外空间（两个 64 位字）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> findThePrefixCommonArray(vector<int>& A, vector<int>& B) {
        int n = A.size();
        vector<int> cnt(n + 1, 0), C(n);
        int common = 0;                       // 当前已“双方都出现过”的值个数
        for (int i = 0; i < n; ++i) {
            if (++cnt[A[i]] == 2) ++common;   // A[i] 第二次出现 → 两侧都有
            if (++cnt[B[i]] == 2) ++common;   // B[i] 第二次出现 → 两侧都有
            C[i] = common;
        }
        return C;
    }
};
```

### Python

```python
class Solution:
    def findThePrefixCommonArray(self, A: List[int], B: List[int]) -> List[int]:
        n = len(A)
        cnt = [0] * (n + 1)
        C = []
        common = 0
        for i in range(n):
            cnt[A[i]] += 1
            if cnt[A[i]] == 2:
                common += 1
            cnt[B[i]] += 1
            if cnt[B[i]] == 2:
                common += 1
            C.append(common)
        return C
```

> 💡 两份代码均通过官方示例（`[0,2,3,4]`、`[0,1,3]`）与"两排列完全相同"的边界，并与"前缀集合逐点求交"的暴力对拍 4003 组随机排列（含 $A = B$、互反序等构造），`mismatch = 0`。

## 8. 边界情况与易错点

1. **$n = 1$**：$C = [1]$（$A[0] = B[0] = 1$，立即转正）。
2. **同一位置 $A[i] = B[i]$**：一次到位（0→1→2 中跳过中间态时判等仍准确），不会重复计数；写 `if (cnt[A[i]] == 2) common++; if (cnt[B[i]] == 2) common++;` 顺序执行即可，不要合并成 `else if`。
3. **两排列完全相同**：$C[i] = i + 1$，是检验下标偏移的好样例。
4. **计数数组大小**：值从 1 开始，开 $n+1$ 而不是 $n$，避免越界。
5. **位掩码版必须 64 位**：$n$ 可达 50，超过 32 位 `int`；C++ 里 `1 << (x-1)` 在 $x > 32$ 时是未定义行为，要写 `1LL << (x-1)`。
6. **别用排序+双指针**：会破坏"前缀"语义（公共数组要求按原下标前缀统计），且毫无必要。
