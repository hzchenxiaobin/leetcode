# LeetCode 销售价值减少的颜色球 题解

## 1. 题目概述

- **标题 / 题号**：销售价值减少的颜色球（#1648，medium）
- **链接**：https://leetcode.cn/problems/sell-diminishing-valued-colored-balls/
- **来源**：LeetCode 第 214 场周赛 Q3
- **难度**：中等
- **标签**：贪心、数组、数学、二分查找、排序、堆（优先队列）

**题意**：`inventory[i]` 表示第 $i$ 种颜色球的初始库存。顾客共要买 `orders` 个球，颜色可任意搭配；每卖出一个颜色 $i$ 的球，其售价等于**成交那一刻该颜色剩余的球数**（于是同一颜色的售价按 $inventory[i], inventory[i]-1, \dots$ 逐个递减）。你可以按任意顺序卖，求卖出 `orders` 个球后的**最大总售价**，对 $10^9+7$ 取模。

**约束**：

- $1 \le n = inventory.length \le 10^5$——单趟 $O(n)$ 遍历可用，但不能嵌套大循环
- $1 \le inventory[i] \le 10^9$——单项等差和可达 $\sim 5\times10^{17}$，取模与溢出必须小心
- $1 \le orders \le \min(\sum inventory[i],\ 10^9)$——$orders$ 本身可达 $10^9$，**逐球模拟不可行**；$\sum inventory[i]$ 可达 $10^{14}$，计数也须 64 位

> 💡 本题在本仓库另有[每日题解 1648](../../solution/1601-1700/1648_销售价值减少的颜色球.md)，侧重「削平高度阈值 $g(T)=\sum\max(0,\ inv-T)$ 视角、排序逐层削平写法与面试问答」。本篇按周赛复盘视角，用「**价值多重集 + 第 orders 大价值**」的等价模型重新推导，并给出引理—定理结构的完整证明与赛场易错清单，两篇互为印证。

## 3. 解题思路

### 3.1 暴力思路：最大堆逐个卖

直觉上「每次都卖当前最贵的球」是最优的（3.2 节证明），于是大根堆模拟：

```text
大根堆放入全部 inventory[i]
重复 orders 次：取堆顶 v → ans += v → 压回 v−1
```

复杂度 $O(orders \cdot \log n)$，$orders \le 10^9$ 时约 $3\times10^{10}$ 次堆操作，必然超时。**瓶颈**在于把同一颜色一整段递减的卖出拆成了单步——这一段本质是等差数列，应当批量求和。

### 3.2 核心观察：卖 orders 个球 = 取「价值多重集」中最大的 orders 个

![核心观察：价值阶梯与顶部横切](images/colored_balls_staircase_multiset.svg)

两步等价改写：

1. **顺序无关**：颜色 $i$ 卖出的第 $j$ 个球售价恒为 $inventory[i]-j+1$，与不同颜色间的穿插顺序无关（引理 1）。于是把每种颜色展开成**价值阶梯** $inventory[i],\ inventory[i]-1,\ \dots,\ 1$，全体并成多重集 $M$。
2. **最优 = 顶部横切**：总售价只取决于「每种颜色各卖几个」，最优方案恰是取 $M$ 中**最大的 $orders$ 个数**（引理 2）。第 $orders$ 大的价值记为阈值 $T^*$：**高于 $T^*$ 的球全部卖出，恰等于 $T^*$ 的球补 $rest$ 个**。

定义「价值 $\ge T$ 的球数」

$$
count(T) \;=\; \sum_{i} \max\bigl(0,\ inventory[i]-T+1\bigr)
$$

它随 $T$ **单调不增**，而 $T^* = \max\{\,T : count(T) \ge orders\,\}$ 正是第 $orders$ 大价值。

### 3.3 算法流程：二分找 T* + 等差批量求和

![算法流程：二分阈值与批量结算](images/colored_balls_threshold_flow.svg)

1. **二分阈值**：在 $[1,\ \max inventory]$ 上找最大的 $T$ 使 $count(T) \ge orders$。$count(1)=\sum inventory[i] \ge orders$（题目保证），解必存在。
2. **批量结算**：对每个 $v > T^*$ 的颜色，卖出价值 $v, v-1, \dots, T^*+1$，共 $v-T^*$ 个球，等差求和为

$$
\frac{\bigl(v+T^*+1\bigr)\bigl(v-T^*\bigr)}{2}
$$

3. **阈值补齐**：再卖 $rest = orders - count(T^*+1)$ 个球，每个恰值 $T^*$（从 $inventory[i] \ge T^*$ 的颜色里任选，每色至多一个）。
4. 全程对 $10^9+7$ 取模返回。

### 3.4 示例演算

![示例演算：inventory=[2,8,4,10,6], orders=20](images/colored_balls_walkthrough.svg)

以示例 3 为例，先列 $count(T)$：

| $T$ | 6 | 5 | 4 | 3 | 2 | 1 |
|-----|---|---|---|---|---|---|
| $count(T)$ | 9 | 12 | 16 | **20** | 25 | 30 |

$count(3)=20 \ge 20 > count(4)=16$，故 $T^*=3$（第 20 大价值是 3）。

**批量结算**（$v > 3$ 的列）：$inv=8$ 列卖 $4\sim8$ 得 $30$；$inv=4$ 列卖 $4$ 得 $4$；$inv=10$ 列卖 $4\sim10$ 得 $49$；$inv=6$ 列卖 $4\sim6$ 得 $15$；$inv=2$ 列不卖。合计 $98$，共 $16$ 个球。

**阈值补齐**：$rest = 20-16 = 4$，贡献 $4 \times 3 = 12$。

$$
ans = 98 + 12 = 110 \;\checkmark
$$

> 💡 二分轨迹：$lo=1,hi=10 \to mid=6$（$count=9<20$，$hi=5$）$\to mid=3$（$count=20\ge20$，$lo=3$）$\to mid=4$（$count=16<20$，$hi=3$）$\to T^*=3$。

## 4. 算法细节

1. **二分写法（上取中点）**：找「最大的满足 $count(T) \ge orders$ 的 $T$」，可行方向是 `lo = mid`，必须取 $mid=\lfloor(lo+hi+1)/2\rfloor$ **上取中点**，否则当区间收缩到 $[lo,\,lo+1]$ 时 $mid=lo$ 恒满足谓词，区间永不收缩，**死循环**。
2. **等差和的奇偶性**：$(v+T^*+1)$ 与 $(v-T^*)$ 奇偶性相反，乘积必为偶数——**先除 2 再取模**，避免在模意义下做除法（否则要请出模逆元）。
3. **补齐项的范围**：$0 < rest \le count(T^*)-count(T^*+1)=\#\{i: inventory[i] \ge T^*\}$。上界即「价值恰为 $T^*$ 的球数」（每种颜色至多一个），说明**有足够多的球可补**、也不会补穿到 $T^*-1$。
4. **溢出与取模（C++）**：$count$ 可达 $10^{14}$；单项等差和 $a\cdot b/2$ 约 $2\times10^{18}$（尚在 `long long` 内），但 $10^5$ 项**累加**必溢出——必须**逐项取模**；$rest \times T^*$ 同样先各自取模再乘。Python 原生大整数无此顾虑，最后统一取模即可。

## 5. 正确性证明

**引理 1（销售顺序无关）**：设最终颜色 $i$ 共卖出 $k_i$ 个球（$\sum_i k_i = orders$），则无论按何种顺序卖出，总售价恒为 $\sum_i \sum_{j=1}^{k_i}\bigl(inventory[i]-j+1\bigr)$。

**证明**：颜色 $i$ 卖出的第 $j$ 个球成交时，该颜色恰好已卖出 $j-1$ 个、剩余 $inventory[i]-(j-1)$ 个，售价即为此数——只依赖「它是该颜色的第几个」，与其它颜色的卖出穿插无关。∎

**引理 2（最优结构 = 取最大的 orders 个价值）**：将全部可能价值写成多重集 $M=\bigcup_i\{1,2,\dots,inventory[i]\}$，则最大总售价等于 $M$ 中最大的 $orders$ 个数之和。

**证明**：

- **上界**：任一卖出方案中颜色 $i$ 卖出 $k_i$ 个，由引理 1，其总售价等于「每种颜色取其降序前 $k_i$ 个、共 $orders$ 个数」之和；这 $orders$ 个数只是 $M$ 的一个 $orders$ 元子集，其和不超过 $M$ 中最大 $orders$ 个数之和。
- **可达**：设 $T^*$ 为第 $orders$ 大价值。卖出所有价值 $> T^*$ 的球（颜色 $i$ 从 $inventory[i]$ 削至 $T^*$），再从价值恰为 $T^*$ 的球中任取 $rest=orders-count(T^*+1)$ 个。由 $count(T^*) \ge orders > count(T^*+1)$ 得 $0 < rest \le \#\{i: inventory[i] \ge T^*\}$，方案可行；且每种颜色卖出的仍是其降序前缀，取到的恰是 $M$ 的最大 $orders$ 个数。∎

**定理**：上述算法（二分 $T^*$ + 等差求和 + 阈值补齐）返回最大总售价。

**证明**：$count(T)$ 中每项 $\max(0,\ inventory[i]-T+1)$ 关于 $T$ 不增，故 $count$ 单调不增；又 $count(1)=\sum inventory[i] \ge orders$、$count(\max inventory + 1)=0 < orders$，二分必收敛到 $T^*=\max\{T: count(T)\ge orders\}$，即第 $orders$ 大价值。对每个 $v > T^*$ 的颜色，卖出的价值构成连续等差数列 $T^*{+}1,\dots,v$，其和为 $\frac{(v+T^*+1)(v-T^*)}{2}$，共卖出 $count(T^*+1)$ 个；再补 $rest = orders - count(T^*+1)$ 个价值 $T^*$ 的球。由引理 2，该总和即 $M$ 中最大 $orders$ 个数之和，为最优售价。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n\log M)$，$M=\max inventory \le 10^9$，二分约 $30$ 轮、每轮 $O(n)$ 统计 $count$；结算阶段再一趟 $O(n)$。$n=10^5$ 时约 $3\times10^6$ 次运算。
- **空间复杂度**：$O(1)$。无需排序或建堆，原地遍历，仅常数额外变量。

## 7. 参考代码

### C++

```cpp
class Solution {
    static constexpr long long MOD = 1'000'000'007;
  public:
    int maxProfit(vector<int>& inventory, int orders) {
        long long lo = 1, hi = *max_element(inventory.begin(), inventory.end());
        while (lo < hi) {
            long long mid = lo + (hi - lo + 1) / 2;      // 上取中点：lo=mid 防死循环
            long long cnt = 0;
            for (int v : inventory)
                cnt += max(0LL, (long long)v - mid + 1); // 价值 >= mid 的球数
            if (cnt >= orders) lo = mid;                 // 还能更低 → T* 更大
            else hi = mid - 1;                           // 价值 >= mid 的不够卖
        }
        long long T = lo, ans = 0, cnt = 0;
        for (int v : inventory) {
            if (v <= T) continue;
            long long a = v + T + 1, b = v - T;          // 值 T+1..v 的等差和 = a*b/2
            if (a % 2 == 0) a /= 2; else b /= 2;         // a、b 必一奇一偶，先除 2
            ans = (ans + (a % MOD) * (b % MOD)) % MOD;   // 逐项取模防累加溢出
            cnt += v - T;
        }
        long long rest = orders - cnt;                   // 补齐：每个恰值 T
        ans = (ans + (rest % MOD) * (T % MOD)) % MOD;
        return (int)ans;
    }
};
```

### Python

```python
class Solution:
    def maxProfit(self, inventory: List[int], orders: int) -> int:
        MOD = 10 ** 9 + 7

        def count(T):  # 价值 >= T 的球数
            return sum(v - T + 1 for v in inventory if v >= T)

        lo, hi = 1, max(inventory)
        while lo < hi:
            mid = (lo + hi + 1) // 2          # 上取中点防死循环
            if count(mid) >= orders:
                lo = mid                      # T* 还能更大
            else:
                hi = mid - 1                  # 价值 >= mid 的不够卖
        T = lo

        ans = 0
        cnt = 0
        for v in inventory:
            if v > T:
                ans += (v + T + 1) * (v - T) // 2   # 等差数列 T+1..v 求和
                cnt += v - T
        ans += (orders - cnt) * T                   # 阈值补齐
        return ans % MOD
```

## 8. 边界情况与易错点

1. **别模拟**：$orders \le 10^9$，最大堆逐球卖 $O(orders\log n)$ 必超时；必须把「一整段递减卖出」压成等差数列求和。
2. **二分死循环**：`lo = mid` 型二分必须上取中点（`mid = (lo+hi+1)//2`），否则区间 $[lo,\,lo+1]$ 时 $mid=lo$ 恒满足谓词、区间永不收缩。
3. **计数溢出**：$count(T)$ 最大 $\approx 10^5 \times 10^9 = 10^{14}$，C++ 须用 `long long` 累加。
4. **模意义下除 2**：等差和 $\frac{a\cdot b}{2}$ 不能先取模再除——利用 $a,b$ 一奇一偶，**先把偶因子除 2** 再各自取模相乘；Python 大整数可直接 `//2`、最后统一取模。
5. **累加溢出**：单项等差和可达 $\sim2\times10^{18}$（`long long` 勉强容纳），但 $10^5$ 项之和必溢出，须逐项取模——示例 4 的 $5\times10^{17}$ 就是警告。
6. **$T^*$ 有解不用特判**：题目保证 $orders \le \sum inventory[i] = count(1)$，故 $T^* \ge 1$，二分区间 $[1,\ \max]$ 必有解，不存在「全卖光还不够」的情况。
7. **补齐数恒正**：$count(T^*+1) < orders$（否则 $T^*+1$ 也满足谓词，与 $T^*$ 最大性矛盾），故 $rest \ge 1$；又 $rest \le \#\{i: inventory[i]\ge T^*\}$，不会无球可补。注意别把 $rest$ 误写成 $count(T^*)-count(T^*+1)$——那是**可补上限**，不是实际补数。
8. **并列价值的取舍无关紧要**：价值同为 $T^*$ 的球分属不同颜色、售价相同，补哪几个不影响答案，实现里直接顺序扫过即可。
