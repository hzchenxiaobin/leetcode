# LeetCode 检查是否每一行每一列都包含全部整数 题解

## 1. 题目概述

- **标题 / 题号**：检查是否每一行每一列都包含全部整数（#2133，easy）
- **链接**：https://leetcode.cn/problems/check-if-every-row-and-column-contains-all-numbers/
- **来源**：LeetCode 第 275 场周赛 Q1
- **难度**：简单
- **标签**：数组、哈希表、矩阵

**题意**：给定一个 $n \times n$ 的整数矩阵 `matrix`，判断它是否为「有效矩阵」：**每一行**和**每一列**都包含 $1$ 到 $n$ 的全部整数（每个数恰好出现一次）。是则返回 `true`，否则返回 `false`。

**约束**：

- `n == matrix.length == matrix[i].length`
- $1 \le n \le 100$
- $1 \le matrix[i][j] \le n$（值域天然落在 $[1, n]$ 内）

> 💡 约束里「值域 $\subseteq [1,n]$」是本题最关键的前提：它把「包含全部 $1..n$」的检查化简成「无重复」的检查（见 3.2）。

## 2. 示例

**示例 1**

```text
输入：matrix = [[1,2,3],[3,1,2],[2,3,1]]
输出：true
解释：n = 3，每一行、每一列都恰好包含 1、2、3。
```

**示例 2**

```text
输入：matrix = [[1,1,1],[1,2,3],[1,2,3]]
输出：false
解释：第 0 行 [1,1,1] 缺少 2 和 3（第 0 列同理）。
```

**示例 3（n = 1 边界）**

```text
输入：matrix = [[1]]
输出：true
解释：n = 1，值域只剩 {1}，单格矩阵恒为有效矩阵。
```

## 3. 解题思路

### 3.1 暴力思路

对每一行、每一列：把 $n$ 个数收集成集合，与 $\{1,\dots,n\}$ 比较是否相等（或排序后逐位比对）。时间 $O(n^2)$（集合）或 $O(n^2 \log n)$（排序），$n \le 100$ 都能过，但写起来要建集合、要比对，签到题不应这么重。

### 3.2 核心观察：鸽巢原理——「无重复」⟺「包含全部」

![鸽巢原理：无重复等价于包含全部](images/valid_matrix_pigeonhole_concept.svg)

约束保证每个元素都在 $[1,n]$ 内，即一行 $n$ 个数全部落进**值域这 $n$ 个鸽巢**里：

- 若某行包含全部 $1..n$：$n$ 个互不相同的值，自然**无重复**；
- 若某行**无重复**：$n$ 个互不相同的值都取自大小仅为 $n$ 的值域 $[1,n]$，必然**恰好取遍**每个值。

于是「检查是否包含全部 $1..n$」退化为「检查是否有重复」——只需一个布尔数组标记，遇到已标记的值立即失败，连值域校验都省了（约束已保证不越界）。

> ⚠️ 注意「和校验」「异或校验」这类捷径**不充分**：$n=4$ 的行 $[1,1,4,4]$ 的和为 $10 = 1+2+3+4$，却不是排列；异或同样存在碰撞（如 $n=5$ 的 $[1,2,2,4,4]$ 与 $1\oplus2\oplus3\oplus4\oplus5$ 异或值相同）。唯一稳妥的判定就是查重复。

### 3.3 算法流程：行/列一趟同检

![行/列一趟同检流程图](images/valid_matrix_check_flow.svg)

- 外层枚举 $i = 0..n-1$，**同时**处理第 $i$ 行与第 $i$ 列，每轮重建 `seen_row`、`seen_col` 两个布尔数组（大小 $n+1$，下标 $1..n$）；
- 内层 $j = 0..n-1$：`matrix[i][j]` 参与行检查，`matrix[j][i]` 参与列检查（转置下标）；
- 任一值在对应 `seen` 数组里已被标记 → 立即返回 `false`；否则标记继续；
- 全部通过 → 返回 `true`。

### 3.4 示例演算

以示例 2 `[[1,1,1],[1,2,3],[1,2,3]]` 演算 $i=0$ 轮的行检查：

| j | matrix[0][j] | seen_row 状态 | 结果 |
|---|---|---|---|
| 0 | 1 | `seen[1]` 未标记 → 标记 | 继续 |
| 1 | 1 | `seen[1]` **已标记** | 重复！`return false` |
| 2 | 1 | ——（短路，未到达） | —— |

第 2 个 `1` 与第 0 个 `1` 撞车，两步即短路返回；第 0 列 $[1,1,1]$ 同样非法，但行检查先触发。

![示例 2 演算：第一行两个 1 撞车](images/invalid_matrix_walkthrough.svg)

## 4. 算法细节

1. **一趟同检（fused loop）**：外层 $i$ 固定时，第 $i$ 行元素是 `matrix[i][j]`、第 $i$ 列元素是 `matrix[j][i]`，共用一个内层循环即可，省去转置或两次遍历。
2. **布尔数组代替集合**：值域 $[1,n]$ 连续且小，`vector<char>` / `list[bool]` 比 `set`/`dict` 快且省内存；数组开 $n+1$，下标 $1..n$ 直接用值索引。
3. **每轮重建**：`seen_row`、`seen_col` 在外层循环内重新初始化，避免行间/列间残留脏标记（`fill` 或直接新建）。
4. **短路返回**：发现重复立即 `return false`，最坏 $O(n^2)$，最好 $O(1)$（左上角两个相同值）。
5. **Python 惯用写法**：`zip(*matrix)` 转置后，行、列统一用 `set(row) == target` 判断，两行代码即可。

## 5. 正确性证明

**引理 1（鸽巢原理）**：$n$ 个取值于 $[1,n]$ 的整数构成 $\{1,\dots,n\}$ 的排列，当且仅当它们互不相同。

**证明**：（⇒）排列即每个值恰好出现一次，互不相同。（⇐）设这 $n$ 个数互不相同，把它们构成的集合记为 $S$，则 $|S| = n$ 且 $S \subseteq \{1,\dots,n\}$；而 $|\{1,\dots,n\}| = n$，故 $S = \{1,\dots,n\}$，即取遍全部值。∎

**定理**：`matrix` 为有效矩阵，当且仅当每一行、每一列均无重复元素。

**证明**：一行含全部 $1..n$ ⟺ 该行无重复（引理 1，行有 $n$ 个取值于 $[1,n]$ 的数）；对每一列同理。故「每行每列都包含全部」⟺「每行每列都无重复」。∎

**算法正确性**：算法对每行每列逐一检测重复（标记数组命中即重复），发现任一重复立即返回 `false`，与定理的否命题对应；全部通过时每行每列均无重复，由定理返回 `true`。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n^2)$。每个元素恰好被行检查与列检查各访问一次，共 $2n^2$ 次标记/查询，每次 $O(1)$。
- **空间复杂度**：$O(n)$。仅两个长度 $n+1$ 的布尔数组，随外层循环复用。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool checkValid(vector<vector<int>>& matrix) {
        int n = matrix.size();
        for (int i = 0; i < n; ++i) {
            vector<char> rowSeen(n + 1, 0), colSeen(n + 1, 0);
            for (int j = 0; j < n; ++j) {
                if (rowSeen[matrix[i][j]]++) return false;  // 第 i 行重复
                if (colSeen[matrix[j][i]]++) return false;  // 第 i 列重复
            }
        }
        return true;
    }
};
```

### Python

```python
class Solution:
    def checkValid(self, matrix: List[List[int]]) -> bool:
        n = len(matrix)
        target = set(range(1, n + 1))
        return (all(set(row) == target for row in matrix)
                and all(set(col) == target for col in zip(*matrix)))
```

## 8. 边界情况与易错点

1. **n = 1 恒真**：值域只剩 $\{1\}$，单格矩阵必为有效矩阵，代码无需特判（自然成立）。
2. **只查行忘查列**（或反之）：题面两个条件缺一不可，示例 2 中行 1、行 2、列 1、列 2 都合法，偏偏第 0 行/第 0 列非法，漏查任一维度都会误判。
3. **和/异或校验陷阱**：$[1,1,4,4]$（$n=4$）和数正确但不是排列，必须查重复而非查和。
4. **数组下标从 1 开始**：`seen` 开 $n+1$ 大小；若不信任约束（值可能越界），需先判 `v >= 1 && v <= n` 防止越界访问。
5. **行间忘记重置** `seen` 数组，会把上一行的标记带到下一行造成误报。
6. **C++ 的 `rowSeen[v]++` 技巧**：后缀自增返回旧值，一句完成「查询 + 标记」，注意它等价于「先判后标」。
