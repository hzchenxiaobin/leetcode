# LeetCode 统计最大元素出现至少 K 次的子数组 题解

## 1. 题目概述

- **标题 / 题号**：统计最大元素出现至少 K 次的子数组（#2962，medium）
- **链接**：https://leetcode.cn/problems/count-subarrays-where-max-element-appears-at-least-k-times/
- **来源**：LeetCode 第 375 场周赛 Q3
- **难度**：中等
- **标签**：数组、滑动窗口、双指针、计数

**题意**：给定整数数组 `nums` 和正整数 `k`。「**nums 中的最大元素**」指的是**全局**最大值 `mx`。统计有多少个连续子数组 $[l, r]$，满足 $mx$ 在其中出现的次数**至少为 $k$**。子数组是连续的一段。

**约束**：

- $1 \le nums.length \le 10^5$
- $1 \le nums[i] \le 10^6$
- $1 \le k \le 10^5$

> 💡 读题先定性：本题最大的读题陷阱是「最大元素」四个字——它是**全局**最大值，不是子数组自身的最大值。先花 $O(n)$ 扫一遍拿到 $mx$，条件「子数组中 nums 的最大元素出现 $\ge k$ 次」就完全等价于「$mx$ 在子数组中出现 $\ge k$ 次」（子数组一旦包含 $mx$，它自己的最大值必然就是 $mx$）。于是问题降维成纯粹的**定值计数**：数有多少个窗口，其中值 $mx$ 的出现次数 $\ge k$。这是教科书级的「**单调性 → 滑动窗口正贡献**」模型。

## 2. 示例

**示例 1**

```text
输入：nums = [1,3,2,3,3], k = 2
输出：6
解释：mx = 3。包含 3 至少 2 次的子数组为：
      [1,3,2,3]、[1,3,2,3,3]、[3,2,3]、[3,2,3,3]、[2,3,3] 和 [3,3]。
```

**示例 2**

```text
输入：nums = [1,4,2,1], k = 3
输出：0
解释：mx = 4 只出现 1 次，凑不够 3 次，任何子数组都不合法。
```

**示例 3（自造，验证 k = 1 与答案规模）**

```text
输入：nums = [2,2,2], k = 1
输出：6
解释：mx = 2。所有 C(3+1, 2) = 6 个子数组都含 mx 至少 1 次。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有子数组再统计 $mx$ 出现次数是 $O(n^3)$；稍作改进：**枚举左端点 $l$，向右扩 $r$**，边扩边维护 `cnt`，一旦 `cnt` 达到 $k$，之后每个新 $r$ 都计入答案——这是 $O(n^2)$。

$n = 10^5$ 时最坏约 $5 \times 10^9$ 次操作，超时。瓶颈在于：同一个合法窗口被反复「重新发现」。破局点藏在单调性里。

### 3.2 核心观察：合法左端点是一段前缀 → 滑动窗口

![核心概念：固定右端点，第k个mx的位置决定左端点范围](images/wc375_q3_kth_occurrence_concept.svg)

三点观察，层层递进：

1. **固定右端点 $r$，合法左端点是一段前缀**。$l$ 越小窗口越大，$mx$ 的个数**单调不减**。所以合法的 $l$ 必然形如 $[0, L(r)]$：所有 $l \le L(r)$ 合法，所有 $l > L(r)$ 不合法。且 $L(r)$ 就是「窗口内从左数第 $k$ 个 $mx$」的下标——第 $k$ 个 $mx$ 落在哪，左端点就能伸到哪。
2. **每轮贡献直接算出**：以 $r$ 结尾的合法子数组恰有 $L(r) + 1$ 个（$L(r)$ 不存在则贡献 0）。总答案 $= \sum_r \bigl(L(r) + 1\bigr)$，计数无需逐个枚举子数组。
3. **$L(r)$ 关于 $r$ 单调不减**：$r$ 右移只会让窗口多装元素，第 $k$ 个 $mx$ 的位置只会右移（或从无到有）。因此 $L$ 可以用**双指针**维护——`left` 只前进、永不回退，两个指针各走一遍数组，总计 $O(n)$。

> ⚠️ 与「至多型」滑窗（如 LC 713）对偶着记：至多型收缩到**合法**，每轮贡献**窗口长度** `right - left + 1`；本题是「至少型」，收缩到**不合法**，每轮贡献 `left`（合法左端点的个数）。方向反了，贡献公式就反了——这是本题最高频的写错点。

### 3.3 算法流程

![算法流程：滑动窗口收缩与正贡献累加](images/wc375_q3_sliding_window_flow.svg)

实现上不显式记录 $L(r)$，而是维护一个「**不合法的最左窗口**」：

1. 预处理：一遍扫描求 $mx$；初始化 `left = cnt = ans = 0`。
2. `right` 从左到右前进；若 `nums[right] == mx` 则 `cnt++`（并入窗口）。
3. **收缩循环**：只要 `cnt >= k`，就把 `nums[left]` 移出窗口（若它等于 $mx$ 则 `cnt--`），`left++`。退出时窗口 $[left, right]$ 恰含 $k-1$ 个 $mx$（若从未达标则 `left` 仍为 0）。
4. **正贡献**：`ans += left`——此时合法左端点恰为 $l \in [0, left-1]$，共 `left` 个（`left = 0` 时贡献 0，自然覆盖）。

注意收缩的对称设计：进入循环前 `cnt ≥ k`（合法），退出后 `cnt < k`（不合法），**最后被移出的元素必然是 $mx$**（它把 `cnt` 从 $k$ 压到 $k-1$），停在 `left - 1` 处。这正是「第 $k$ 个 $mx$ 的下标」的化身：$L(r) = left - 1$。

### 3.4 示例演算

![示例1演算：逐行走查滑动窗口](images/wc375_q3_example_walkthrough.svg)

以示例 1（`nums = [1,3,2,3,3]`，`k = 2`，`mx = 3`）走查：

| $r$ | 并入后 cnt | 收缩动作 | 收缩后窗口 | 贡献 `left` | 累计 `ans` |
|-----|-----------|----------|-----------|------------|------------|
| 0 | 0 | 无（cnt < 2） | $[0,0]$，0 个 mx | 0 | 0 |
| 1 | 1 | 无（cnt < 2） | $[0,1]$，1 个 mx | 0 | 0 |
| 2 | 1 | 无（cnt < 2） | $[0,2]$，1 个 mx | 0 | 0 |
| 3 | 2 | 吐出 1、**3**，left 停在 2 | $[2,3]$，1 个 mx | 2 | 2 |
| 4 | 2 | 吐出 2、**3**，left 停在 4 | $[4,4]$，1 个 mx | 4 | 6 |

$r=3$ 结尾的合法子数组：$l \in \{0,1\}$，即 $[1,3,2,3]$、$[3,2,3]$；$r=4$ 结尾：$l \in \{0,1,2,3\}$，即 $[1,3,2,3,3]$、$[3,2,3,3]$、$[2,3,3]$、$[3,3]$。合计 $6$ ✓。示例 2 中 `cnt` 从未达到 3，`left` 恒为 0，答案 0 ✓。

## 4. 算法细节

1. **先求 $mx$ 再比较**：`mx = *max_element(...)` 一遍扫，判定一律写 `nums[i] == mx`。不要在子数组内部现求最大值——那是 $O(n^2)$ 的弯路，也完全没必要（条件只关乎全局 $mx$）。
2. **收缩循环必须同步维护 cnt**：`while (cnt >= k)` 里每移出一个元素，若它是 $mx$ 就 `cnt--`。若忘记维护，`cnt` 永远 $\ge k$，**死循环**。
3. **贡献是 `ans += left`**，不是窗口长度 `right - left + 1`。直觉校验：`left` 是「以当前 $r$ 结尾的合法左端点个数」，与 §3.2 的 $L(r)+1$ 一致。
4. **left 永不回退**：由 $L(r)$ 单调性保证（引理 3）。因此两个指针总移动量各 $\le n$，每轮均摊 $O(1)$，整体线性。
5. **答案用 `long long`**：最坏情形（全为 $mx$ 且 $k=1$，见自造示例 3）答案达 $\frac{n(n+1)}{2} \approx 5 \times 10^9$，超出 `int` 上限。C++ 必须开 `long long`（本题函数签名返回值就是 `long long`）；Python 无此虑。
6. **空窗口语义**：$k = 1$ 且窗口被收缩到 `left = right + 1` 时，$[left, right]$ 是空窗口，`cnt = 0 < k` 语义自洽，无需特判。

## 5. 正确性证明

**引理 1（条件转化）**：子数组 $[l, r]$ 被统计 $\iff$ $mx$ 在 $[l, r]$ 中的出现次数 $\ge k$。

**证明**：题面统计「nums 中的最大元素至少出现 $k$ 次」的子数组。$mx$ 是全局最大值，出现即压过子数组内一切元素；故「子数组中出现 $\ge k$ 次 nums 的最大元素」$\iff$「$cnt_{mx}(l, r) \ge k$」。∎

**引理 2（前缀性）**：固定 $r$，合法左端点集合 $S(r) = \{\, l : cnt_{mx}(l, r) \ge k \,\}$ 或为空，或为形如 $[0, L(r)]$ 的前缀。

**证明**：若 $l_1 < l_2$，则 $[l_2, r] \subseteq [l_1, r]$，故 $cnt_{mx}(l_2, r) \le cnt_{mx}(l_1, r)$。于是 $l_2 \in S(r) \Rightarrow l_1 \in S(r)$：$S(r)$ 是 $\{0, \dots, r\}$ 的「下封闭」子集，只能是空集或前缀 $[0, L(r)]$，且 $L(r)$ 恰为窗口内从左数第 $k$ 个 $mx$ 的下标。∎

**引理 3（上界单调）**：$r_1 < r_2$ 且 $S(r_1) \ne \varnothing$ $\Rightarrow$ $S(r_2) \ne \varnothing$ 且 $L(r_1) \le L(r_2)$。

**证明**：对任意 $l \le L(r_1)$，$[l, r_1] \subseteq [l, r_2]$，故 $cnt_{mx}(l, r_2) \ge cnt_{mx}(l, r_1) \ge k$，即 $S(r_2) \supseteq [0, L(r_1)]$；结合引理 2 的前缀结构得 $L(r_2) \ge L(r_1)$。∎（这是 `left` 不回退、算法正确且线性的根基。）

**定理**：算法返回 $|\{\,(l, r) : cnt_{mx}(l, r) \ge k\,\}|$。

**证明**：对每轮 `right` 论证循环不变式：**收缩结束、执行 `ans += left` 之时，(a) $cnt_{mx}(left, right) < k$；(b) $left = 0$，或 $nums[left-1] = mx$ 且 $cnt_{mx}(left-1, right) \ge k$**。

- **并入后不收缩**（$cnt_{mx}(left, right) < k$）：(a) 显然；(对 (b)：`left` 与上轮相同，若 `left > 0`，上轮已有 $cnt_{mx}(left-1, right-1) \ge k$，窗口再装进一个元素只会更多）。
- **收缩**：进入时 $cnt_{mx} \ge k$。`cnt` 只在移出 $mx$ 时减 1，从 $\ge k$ 降到 $< k$ 必然恰经过 $k - 1$，故**退出时窗口恰含 $k-1$ 个 $mx$，且最后移出的 $nums[left-1] = mx$**——移出它之前窗口 $[left-1, right]$ 恰含 $k$ 个 $mx$，(a)(b) 均成立。

由 (a) 与引理 2 单调性，所有 $l \ge left$ 不合法；由 (b)，所有 $l \le left-1$ 合法（窗口更大只会更多）。故 $S(right) = [0, left-1]$（`left = 0` 时为空），本轮累加的 `left` 恰是 $|S(right)|$。又每个子数组有唯一右端点，各轮贡献不重不漏，`ans` 即所求总数。∎

**系（复杂度）**：`right` 前进 $n$ 次，`left` 因单调不回退至多前进 $n$ 次，每步 $O(1)$，总计 $O(n)$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。三个线性阶段：求 $mx$ 一遍；主循环 `right` 走 $n$ 步；`left` 全程总移动量 $\le n$（不回退），收缩循环总代价均摊到每步 $O(1)$。
- **空间复杂度**：$O(1)$ 额外空间，只维护 `mx / left / cnt / ans` 四个变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long countSubarrays(vector<int>& nums, int k) {
        int mx = *max_element(nums.begin(), nums.end());
        long long ans = 0;
        int cnt = 0, left = 0, n = nums.size();
        for (int right = 0; right < n; ++right) {
            if (nums[right] == mx) ++cnt;
            while (cnt >= k) {
                if (nums[left] == mx) --cnt;
                ++left;
            }
            ans += left;
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def countSubarrays(self, nums: List[int], k: int) -> int:
        mx = max(nums)
        ans = cnt = left = 0
        for x in nums:
            if x == mx:
                cnt += 1
            while cnt >= k:
                if nums[left] == mx:
                    cnt -= 1
                left += 1
            ans += left
        return ans
```

> 💡 语言细节：两版逐行同构，即 §3.3 流程图的直译。C++ 注意 `ans` 声明为 `long long`（`left` 也参与 `ans += left`，`int` 累加到 `long long` 会隐式提升，安全）；Python 的 `max(nums)` 底层 C 实现，放心用。

## 8. 边界情况与易错点

1. **答案溢出 `int`（本题最高频罚时点）**：全为 $mx$ 且 $k=1$ 时答案 $\frac{n(n+1)}{2} \approx 5 \times 10^9$。C++ 用 `long long`（题目签名已强制）；Java 用 `long`。
2. **贡献公式写反**：写成 `ans += right - left + 1`（至多型）会把「以 $r$ 结尾的**不合法**窗口长度」加进来，全盘皆错。记口诀：**至少型加 `left`，至多型加窗口长**。
3. **把「最大元素」当子数组内部的最大值**：先全局求 $mx$。判定条件是 `== mx`，写 `> mx` 恒假（没有更大的数），写 `>= mx` 碰巧等价但语义含糊。
4. **收缩循环漏维护 `cnt`**：只 `++left` 不减 `cnt` → `cnt >= k` 永真 → 死循环 / 越界。
5. **$k$ 大于 $mx$ 总出现次数**：答案 0。算法中 `cnt` 从未达标，`left` 恒 0，自然覆盖，无需特判。
6. **$k = 1$ 的极端收缩**：窗口可能被收缩成空（`left = right + 1`），空窗口 `cnt = 0` 语义自洽；贡献 `ans += left = right + 1` 恰是「含至少一个 $mx$ 的左端点个数」，正确。
7. **重复计数**：正贡献法按右端点分桶，每个子数组只在其唯一右端点处被计入一次；切忌再按左端点统计一遍。
