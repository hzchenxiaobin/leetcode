# LeetCode 双模幂运算 题解

## 1. 题目概述

- **标题 / 题号**：双模幂运算（#2961，medium）
- **链接**：https://leetcode.cn/problems/double-modular-exponentiation/
- **来源**：LeetCode 第 375 场周赛 Q2
- **难度**：中等
- **标签**：数组、数学、快速幂、模拟

**题意**：给定二维数组 `variables`，其中 `variables[i] = [ai, bi, ci, mi]`，以及整数 `target`。若

$$\bigl((a_i^{\,b_i} \bmod 10)^{\,c_i}\bigr) \bmod m_i = target$$

则称 $i$ 为**好下标**。返回所有好下标组成的数组，顺序不限。公式的结构是三段式：先算 $a^b$ **对 10 取模**，把结果作为新底数再算 $c$ 次幂，最后**对 $m$ 取模**——两段幂运算、两次取模，这正是题名「双模」的由来。

**约束**：

- $1 \le variables.length \le 100$
- $variables[i] = [a_i,\ b_i,\ c_i,\ m_i]$，且 $1 \le a_i, b_i, c_i, m_i \le 10^3$
- $0 \le target \le 10^3$

> 💡 读题先定性：没有数据结构、没有搜索——这是**模板题**，考点唯一且锋利：$a^b$ 最大是 $1000^{1000}$（3001 位天文数字），幂值**不能算出来**，必须「边乘边取模」的**快速幂**。要写的其实是两个可迁移模板：C++ 手写快速幂 `mpow(base, exp, mod)`，以及 Python 的三参数内置 `pow(base, exp, mod)`。另有一个隐藏陷阱：内层的 $\bmod 10$ 是公式真值的一部分，**不能**把两段幂合并成 $a^{bc} \bmod m$（见 §3.2）。

## 2. 示例

**示例 1**

```text
输入：variables = [[2,3,3,10],[3,3,3,1],[6,1,1,4]], target = 2
输出：[0,2]
解释：下标 0：(2³ mod 10)³ mod 10 = 8³ mod 10 = 512 mod 10 = 2 ✓
      下标 1：(3³ mod 10)³ mod 1 = 7³ mod 1 = 343 mod 1 = 0 ≠ 2 ✗
      下标 2：(6¹ mod 10)¹ mod 4 = 6 mod 4 = 2 ✓
```

**示例 2**

```text
输入：variables = [[39,3,1000,1000]], target = 17
输出：[]
解释：39³ = 59319，mod 10 = 9；9^1000 mod 1000 = 1 ≠ 17，故无好下标。
      （9^1000 ≡ 1 (mod 8) 且 ≡ 1 (mod 125)，由中国剩余定理得 ≡ 1 (mod 1000)。）
```

**示例 3（自造，验证 $m=1$ 与尾数为 0）**

```text
输入：variables = [[10,5,2,7]], target = 0
输出：[0]
解释：10⁵ mod 10 = 0（底数尾数为 0）；0² mod 7 = 0 = target ✓
```

## 3. 解题思路

### 3.1 暴力思路

按题面把幂**完整算出来**再取模：先算 $a^b$（至多 3001 位），$\bmod\ 10$ 得到 $x \le 9$；再算 $x^c$（至多 955 位），$\bmod\ m$。

- **Python** 靠原生大数能过：100 个元素、每个几次大数乘幂，毫秒级——但这是「数据小惯的」，不是算法保证；
- **C++ / Java** 直接判死刑：`long long` 上限约 $9.2 \times 10^{18}$，$1000^7 = 10^{21}$ 就溢出，何况 $1000^{1000}$；换成 `double` 更糟——只有约 16 位有效数字，3001 位的整数必然失真。

还有第二种「半暴力」：朴素循环**边乘边模**（$r \leftarrow r \cdot a \bmod 10$），每元素 $O(b + c) \le 2000$ 次乘法，本题数据下也稳过。它其实已经拿到了正确做法的一半（同余取模），只差把指数**二分**这一步优化——不如直接写成通用模板。

### 3.2 核心观察：同余不变性——取模可以随时取

![核心概念：双模幂两段流水线，中间结果永不越界](images/wc375_q2_double_modpow_pipeline.svg)

两点观察让大数彻底出不了场：

1. **乘法对取模封闭**：$(u \cdot v) \bmod M = \bigl((u \bmod M) \cdot (v \bmod M)\bigr) \bmod M$。幂就是连乘，所以**每乘一次就取一次模**，最终余数不变，中间值永远小于 $M$。于是两段幂各自独立成一个「模幂」子问题，中间结果被两个模数闸门牢牢夹住：第一段 $x = a^b \bmod 10 \in [0, 10)$，第二段 $y = x^c \bmod m \in [0, m)$。
2. **快速幂压乘法次数**：平方–相乘（square-and-multiply）按指数二进制位逐位处理，每轮指数至少减半，把每段乘法次数从 $O(e)$ 压到 $O(\log e)$。

> ⚠️ **最危险的错觉：把两段幂合并**。有人看到 $(a^b)^c$ 就想写 $a^{bc} \bmod m$——错！内层的 $\bmod 10$ 是**真值的一部分**，不是化简提示。反例：$a=12,\ b=2,\ c=2,\ m=17$ 时，公式值 $= (12^2 \bmod 10)^2 \bmod 17 = 4^2 \bmod 17 = 16$，而 $12^4 \bmod 17 = 13 \ne 16$。事实上仅当 $m \mid 10$（即 $m \in \{1,2,5,10\}$）时合并才恒等（见延伸思考①）。

### 3.3 算法流程

整体流程：对每个下标 $i$ 串行跑两级快速幂，比较即判定。

1. 取出 $a, b, c, m$；
2. 第一段：$x \leftarrow mpow(a,\ b,\ 10)$；
3. 第二段：$y \leftarrow mpow(x,\ c,\ m)$；
4. 若 $y = target$，把 $i$ 收入答案。

快速幂 `mpow(base, e, M)` 的内循环是本题的模板核心：

![算法流程：快速幂平方相乘循环](images/wc375_q2_fastpow_flow.svg)

初始化 $res = 1 \bmod M$、$base \leftarrow base \bmod M$，然后只要 $e > 0$：若 $e$ 最低位为 1 则 $res \leftarrow res \cdot base \bmod M$；随后 $base \leftarrow base^2 \bmod M$、$e \leftarrow e \gg 1$。$e$ 归零时 $res$ 即为 $base^{e} \bmod M$。

### 3.4 示例演算

![示例1演算：逐行套两级快速幂](images/wc375_q2_example_walkthrough.svg)

以示例 1（`variables = [[2,3,3,10],[3,3,3,1],[6,1,1,4]]`，`target = 2`）为例：

| $i$ | $[a,b,c,m]$ | $x = a^b \bmod 10$ | $y = x^c \bmod m$ | 好下标 ? |
|-----|-------------|--------------------|-------------------|----------|
| 0 | $[2,3,3,10]$ | $2^3 \bmod 10 = 8$ | $8^3 \bmod 10 = 512 \bmod 10 = 2$ | ✓（$2 = target$） |
| 1 | $[3,3,3,1]$ | $3^3 \bmod 10 = 7$ | $7^3 \bmod 1 = 343 \bmod 1 = 0$ | ✗（$0 \ne 2$） |
| 2 | $[6,1,1,4]$ | $6^1 \bmod 10 = 6$ | $6^1 \bmod 4 = 6 \bmod 4 = 2$ | ✓（$2 = target$） |

再展开看下标 0 第一段的快速幂二进制轨迹（$mpow(2, 3, 10)$，$3 = (11)_2$）：

| 轮次 | 进入时 $e$ | 奇偶 | $res$ | $base$ | 结束时 $e$ |
|------|-----------|------|-------|--------|-----------|
| 1 | $3=(11)_2$ | 奇 | $1 \cdot 2 = 2$ | $2^2 = 4$ | $1$ |
| 2 | $1=(1)_2$ | 奇 | $2 \cdot 4 = 8$ | $4^2 = 16 \bmod 10 = 6$ | $0$ |

退出时 $res = 8 = 2^3 \bmod 10$ ✓。第二段 $mpow(8, 3, 10)$ 同理得 $512 \bmod 10 = 2$，命中 `target`。最终答案 $[0, 2]$。

## 4. 算法细节

1. **两段独立、串行接力**：模数不同（先 10 后 $m$）互不干扰，第一段的输出 $x$ 是第二段的底数——因为 $x < 10$，第二段的 $base \cdot base$ 至多 $9 \times 9 = 81$，连 `int` 都绰绰有余。
2. **快速幂写迭代版**：平方–相乘比递归版少函数调用开销且无栈深问题；循环体见 §3.3 流程图。
3. **`res = 1 % M` 而非 `res = 1`**：通用模板必须防「$M = 1$ 且指数为 0」的退化（此时应返回 0）。本题 $b, c \ge 1$，循环最后一轮必然执行一次 $res \leftarrow res \cdot base \bmod M = 0$，两种写法都对；但模板按稳妥写法走，换题零心智负担。
4. **乘法一律 `long long`**：本题 $M \le 10^3$，乘积 $< 10^6$，`int` 装得下；但模板要按 $M$ 可达 $10^9$ 设计——此时乘积达 $10^{18}$，恰在 `long long` 边界内、`int` 之外。养成习惯，比赛不赌。
5. **Python 用三参数 `pow`**：`pow(base, exp, mod)` 底层是 C 实现的快速幂，精确、$O(\log e)$，一行完成一段模幂，勿用 `a ** b` 先算大数再取模。
6. **无需特判 `target`**：$y < m \le 10^3$，若 $target \ge m$ 则该行必不命中，但「直接比较」已天然正确，特判只是心算排障时的快捷方式。

## 5. 正确性证明

**引理 1（同余乘法封闭）**：设 $u \equiv u' \pmod{M}$，$v \equiv v' \pmod{M}$，则 $uv \equiv u'v' \pmod{M}$。

**证明**：$uv - u'v' = u(v - v') + v'(u - u')$。右端第一项含因子 $v - v'$（$M$ 的倍数），第二项含因子 $u - u'$（$M$ 的倍数），故 $M \mid uv - u'v'$。∎

**推论**：$(u \bmod M)(v \bmod M) \equiv uv \pmod{M}$；再取一次 $\bmod\ M$ 后结果落在 $[0, M)$。因此对任意连乘**每步取模**不改变最终余数类，且全程数值 $< M$。对连乘长度归纳即得幂的情形：$a^e \bmod M$ 可在每步取模下计算。∎

**引理 2（迭代快速幂正确性）**：上述 `mpow` 返回 $a^e \bmod M$（$e$ 为传入指数，记 $E = e$）。

**证明**：证循环不变式：**进入每轮循环时 $res \cdot base^{e} \equiv a^{E} \pmod{M}$**。

- **初始**：$res = 1 \bmod M$，$base \equiv a$，$e = E$，左边 $\equiv 1 \cdot a^{E}$，成立。
- **保持**：分两步看一轮循环。若当前 $e$ 为奇数，先执行 $res \leftarrow res \cdot base \bmod M$，此时剩余指数相当于 $e - 1$，乘积 $res' \cdot base^{e-1} = res \cdot base^{e}$，不变式不变（由引理 1 推论，取模只截数值不动余数类）。随后统一执行 $base \leftarrow base^{2} \bmod M$、$e \leftarrow \lfloor e/2 \rfloor$：因 $(base^{2})^{\lfloor e'/2 \rfloor} = base^{2 \lfloor e'/2 \rfloor} = base^{e'}$（$e'$ 为奇数分支处理后的剩余指数），不变式仍成立。
- **终止**：$e$ 每轮至少减半，有限轮后 $e = 0$，循环退出。此时不变式化为 $res \equiv a^{E} \pmod{M}$，又因 $res$ 每次赋值后都取过模、恒有 $0 \le res < M$，故 $res = a^{E} \bmod M$。∎

> 注：$E = 0$ 时算法返回 $1 \bmod M$，与数学约定 $a^0 = 1$ 一致（$M = 1$ 时为 $0$）。本题 $b, c \ge 1$ 不触及此情形。

**定理**：对每个下标 $i$，算法的判定与题面公式 $\bigl((a_i^{b_i} \bmod 10)^{c_i}\bigr) \bmod m_i = target$ 逐点等价。

**证明**：第一段取 $M = 10$，由引理 2 得 $x = a^{b} \bmod 10$。第二段以 $x$ 为底、$c$ 为指数、$m$ 为模，再由引理 2 得 $y = x^{c} \bmod m$。二者复合恰为题面公式的嵌套结构，比较 $y = target$ 即题面判定。∎

## 6. 复杂度分析

- **时间复杂度**：$O\bigl(n \cdot (\log b + \log c)\bigr)$。每元素两段快速幂，各至多 $\lceil \log_2 1000 \rceil = 10$ 轮、每轮 2 次乘法；$n \le 100$ 时全程不超过 $100 \times 2 \times 2 \times 10 = 4000$ 次乘法。对比朴素边乘边模的 $O(n(b + c)) \le 2 \times 10^5$ 次——数据范围内都能过，但快速幂版本在数据放大后依然成立。
- **空间复杂度**：$O(1)$ 额外空间（不计收集答案的 $O(n)$ 输出）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long mpow(long long base, long long e, long long mod) {
        long long res = 1 % mod;
        base %= mod;
        while (e) {
            if (e & 1) res = res * base % mod;
            base = base * base % mod;
            e >>= 1;
        }
        return res;
    }

    vector<int> getGoodIndices(vector<vector<int>>& variables, int target) {
        vector<int> ans;
        for (int i = 0; i < (int)variables.size(); ++i) {
            auto& v = variables[i];
            long long x = mpow(v[0], v[1], 10);
            long long y = mpow(x, v[2], v[3]);
            if (y == target) ans.push_back(i);
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def getGoodIndices(self, variables: List[List[int]], target: int) -> List[int]:
        return [i for i, (a, b, c, m) in enumerate(variables)
                if pow(pow(a, b, 10), c, m) == target]
```

> 💡 语言细节：Python 的三参数 `pow(base, exp, mod)` 就是 C 层快速幂，一行完成一段模幂，两层 `pow` 嵌套即「双模幂」本尊；C++ 版把 §3.3 流程图逐字翻译成 `mpow`，`1 % mod` 与 `long long` 两个防御性写法见 §4。

## 8. 边界情况与易错点

1. **合并指数（本题最高频错误）**：$\bigl((a^b \bmod 10)^c\bigr) \bmod m \ne a^{bc} \bmod m$。反例 $[12, 2, 2, 17]$：公式值 $16$，合并值 $13$。仅当 $m \mid 10$（$m \in \{1,2,5,10\}$）时合并恒等，一般情形下内层 $\bmod 10$ 丢掉的信息正是外层 $\bmod m$ 需要的。
2. **误用浮点 `pow()`**：C/C++ 的 `pow(1000, 1000)` 走 `double`，直接溢出到 `inf`；即使数值不溢出，`double` 只有约 16 位有效数字，大整数必然失真。幂运算一律整数快速幂。
3. **中途不取模**：想「先算 $a^b$ 再 $\bmod 10$」——`long long` 在 $1000^7 \approx 10^{21}$ 就爆了。必须边乘边模。
4. **$m = 1$**：任何数 $\bmod\ 1 = 0$，第二段恒为 0，好下标 $\iff target = 0$。快速幂模板 `res = 1 % mod` 天然正确（示例 1 的下标 1 正是此情形）。
5. **底数尾数为 0**：$a \equiv 0 \pmod{10} \Rightarrow x = 0 \Rightarrow y = 0$（$c \ge 1$），快速幂自然算对，无需特判（见自造示例 3）。
6. **$target \ge m$ 必不命中**：$y < m \le target$ 时恒不等。心算排障用；代码无需特判。
7. **别误读公式优先级**：结构是「$\bigl((a^b \bmod 10)^c\bigr) \bmod m$」三段式，不要看成 $a^{b \bmod 10}$ 或 $a^b \bmod 10^c$——读题时先用括号把三段圈出来再动笔。
8. **答案顺序**：题面说顺序不限，但按 $i$ 升序收集最省事，也是判题器接受的形态。
