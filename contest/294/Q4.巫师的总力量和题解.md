# LeetCode 巫师的总力量和 题解

## 1. 题目概述

- **标题 / 题号**：巫师的总力量和（#2281，hard）
- **链接**：https://leetcode.cn/problems/sum-of-total-strength-of-wizards/
- **来源**：LeetCode 第 294 场周赛 Q4
- **难度**：困难
- **标签**：单调栈、栈、数组、前缀和

**题意**：给定下标从 $0$ 开始的整数数组 `strength`。对每个**非空连续子数组**（巫师组），其总力量定义为

$$\text{总力量} = \min(\text{子数组}) \times \sum(\text{子数组})$$

即「组中最弱者的力量」乘以「组中所有巫师力量之和」。求**所有**子数组的总力量之和，对 $10^9 + 7$ 取余。

**约束**：

- $1 \le \text{strength.length} \le 10^5$
- $1 \le \text{strength}[i] \le 10^9$

> 💡 本题在本仓库另有[每日题解 2281](../../solution/2201-2300/2281_巫师的总力量和.md)：以「907 迁移直觉 + 二重前缀和 + 面试问答」展开。本篇按**周赛复盘视角**重写：侧重**从题面到正解的三步切入路径**、**引理-定理化的严格证明**（管辖刻画 → 不重不漏 → 公式恒等）、**等值重复计数的 WA 实锤**，以及**一次遍历「出栈瞬间结算」的完整实现**，两篇互为印证。

## 2. 示例

解释：全部 10 个子数组的总力量：

[1,3]→1·4=4, [3,1]→1·4=4, [1,2]→1·3=3,
[1,3,1]→1·5=5, [3,1,2]→1·6=6, [1,3,1,2]→1·7=7
合计 1+9+1+4+4+4+3+5+6+7 = 44
```

```

**补充：等值陷阱 `[2,2]`（WA 实锤素材）**

```text
输入：strength = [2,2]
输出：16
解释：[2]→4，[2]→4，[2,2]→2×4=8，合计 16。
若边界两侧都取「严格更小」（等值不截断）：0 号管辖 [2]、[2,2]

总和 24 ≠ 16 —— 子数组 [2,2] 被重复计数。
```

## 3. 解题思路

### 3.1 暴力思路与比赛切入

**暴力**：固定左端点 $l$ 向右扫 $r$，同时维护 $\min$ 与 $\sum$，逐个累加——$O(n^2) \approx 10^{10}$，$n = 10^5$ 必然超时。必须换视角。

Q4 时间紧张，从题面到正解应当走三条反射：

1. **「所有子数组 × 最小值」** → [907. 子数组的最小值之和](https://leetcode.cn/problems/sum-of-subarray-minimums/) 的**贡献法**骨架：不枚举子数组，而是枚举每个元素作为最小值，统计它管辖的子数组；
2. **多乘一个 sum** → 907 只需个数 $(i-L)(R-i)$；本题还要「被管辖的所有子数组的**元素和之和**」；
3. **「和之和」→ 前缀和套两层** → 单个子数组的和用前缀和 $O(1)$；对一片前缀和值再求区间和，套**前缀和的前缀和（二重前缀和）$PP$**。

### 3.2 核心观察：贡献法 + 管辖窗口

![核心观察：枚举最弱者 i，用 L、R 圈出管辖窗口](images/wc294_q4_contribution_concept.svg)

对每个下标 $i$，定义两个**屏障**：

- $L(i)$：左侧第一个**严格更小**元素的下标（不存在取 $-1$）
- $R(i)$：右侧第一个**小于或相等**元素的下标（不存在取 $n$）

则「以 $i$ 为指定最小值」的子数组恰为左端点 $l \in [L+1,\, i]$、右端点 $r \in [i,\, R-1]$ 的那些，共 $(i-L)(R-i)$ 个。$i$ 对答案的贡献为

$$\text{contrib}(i) = \text{strength}[i] \times S(i), \qquad S(i) = \sum_{l=L+1}^{i} \sum_{r=i}^{R-1} \text{sum}(l, r)$$

其中 $\text{sum}(l,r)$ 是子数组 $[l,r]$ 的元素和。**左严格、右非严格**的取法把每个子数组唯一地归给其最小值等值簇中**最右侧**的元素——如示例 1 中 $[1,3,1]$ 归下标 2 而非下标 0——保证不重不漏（§5 引理 1、2）。

剩下的唯一难点：如何 $O(1)$ 算出 $S(i)$。

### 3.3 算法流程：二重前缀和 + 出栈瞬间结算

![算法流程：预处理 P、PP，单调栈出栈瞬间定边界并结算](images/wc294_q4_algorithm_flow.svg)

设 $P[k] = \sum_{j<k} \text{strength}[j]$（前缀和），$PP[k] = \sum_{j<k} P[j]$（**二重前缀和**），则 $\text{sum}(l,r) = P[r+1] - P[l]$，代入 $S(i)$ 拆双重求和（推导见 §4）得

$$S(i) = (i-L)\bigl(PP[R+1] - PP[i+1]\bigr) - (R-i)\bigl(PP[i+1] - PP[L+1]\bigr)$$

流程分四步：

1. **预处理**：一趟建 $P$（$n+1$ 项）、一趟建 $PP$（$n+2$ 项），均对 $10^9+7$ 取模；
2. **单调栈主循环**：$i$ 从 $0$ 到 $n$（$i=n$ 是值恒小的**哨兵**），栈存下标、对应值严格递增；当 $\text{val}[栈顶] \ge \text{val}[i]$ 时弹出 $j$——此刻 $j$ 的左右边界**同时确定**：$L = $ 新栈顶（栈空取 $-1$），$R = i$；
3. **出栈瞬间结算**：套上式 $O(1)$ 求 $S(j)$，$\text{ans} \mathrel{+}= \text{val}[j] \times S(j)$；
4. 压入 $i$ 继续；哨兵把栈清空后循环自然结束，返回 `ans`。

### 3.4 示例演算

![示例演算：P、PP 建表与逐元素结算，合计 44](images/wc294_q4_example_walkthrough.svg)

以 `strength = [1,3,1,2]` 为例，$P = [0,1,4,5,7]$，$PP = [0,0,1,5,10,17]$：

| $i$ | val | $L$ | $R$ | 窗口 $l \times r$ | $S(i)$ | 贡献 |
|-----|-----|-----|-----|------------------|--------|------|
| 0 | 1 | $-1$ | 2 | $1 \times 2$ | 5 | 5 |
| 1 | 3 | 0 | 2 | $1 \times 1$ | 3 | 9 |
| 2 | 1 | $-1$ | 4 | $3 \times 2$ | 26 | 26 |
| 3 | 2 | 2 | 4 | $1 \times 1$ | 2 | 4 |

合计 $5 + 9 + 26 + 4 = 44$ ✓。重点看两行：

- **$i=2$**：管辖 $3 \times 2 = 6$ 个子数组，$S = 5+7+4+6+1+3 = 26$，与公式 $O(1)$ 算出的值一致；
- **$i=0$**：右侧遇到**等值** $1$ 被截断在 $R=2$，$[1,3,1]$、$[1,3,1,2]$ 让给 $i=2$——等值防重的关键一环。

## 4. 算法细节

1. **$S(i)$ 公式推导（拆双重和的通用手法）**：

   $$S(i) = \sum_{l=L+1}^{i}\sum_{r=i}^{R-1}\bigl(P[r+1] - P[l]\bigr) = \underbrace{(i-L)\sum_{r=i}^{R-1} P[r+1]}_{P[r+1]\ 与\ l\ 无关} - \underbrace{(R-i)\sum_{l=L+1}^{i} P[l]}_{P[l]\ 与\ r\ 无关}$$

   再用 $PP$ 把两段 $P$ 的区间和各压成一次做差：$\sum_{j=a}^{b} P[j] = PP[b+1] - PP[a]$，即得 §3.3 公式。**「某因子与另一个下标无关就提出来」**是对多重求和降维的通用套路。

2. **数组尺寸**：$P$ 开 $n+1$、$PP$ 开 $n+2$——结算要访问 $PP[R+1]$，而 $R$ 最大为 $n$。少开一项会在「右侧无更小元素」时越界。
3. **出栈瞬间定边界（一次遍历写法的核心）**：弹栈条件保证栈内值**严格递增**。弹出 $j$ 时：
   - $R(j) = i$：若 $(j, i)$ 中存在 $\text{val} \le \text{val}[j]$ 的下标，取其中**最靠左**的 $k$——$k$ 入栈时 $j$ 必还在栈中（否则存在更早的违反者），$k$ 会把 $j$ 弹掉，$j$ 撑不到 $i$；故 $i$ 是右侧第一个 $\le$ 者；
   - $L(j) = $ 新栈顶 $p$：$v[p] < v[j]$ 由栈严格递增保证；若 $(p, j)$ 内有严格更小者 $q$，则 $q$ 在 $j$ 入栈前必已出栈，沿「被谁弹出」回溯得到一条下标递增、值都 $< v[j]$ 的链，链的末端在 $j$ 入栈时仍在栈中且位于 $(p, j)$——与 $p$ 紧贴 $j$ 下方矛盾。
4. **哨兵**：$i = n$ 取值 $0$（恒小于一切 $\text{strength}[j] \ge 1$），一趟清空栈，省去循环后补写结算代码。
5. **取模与溢出**：
   - $PP$ 不取模的真值上界约 $\tfrac{n(n+1)}{2} \cdot \max \approx 5 \times 10^{18}$，勉强贴着 `long long` 上限（$\approx 9.2 \times 10^{18}$），且随后的乘法必然溢出——**建表时就取模**；
   - 取模后的 $PP$ 做差可能为负：C++ 必须 `(a - b + MOD) % MOD`，Python 的 `%` 天然非负；
   - $\text{val}[j] \times S \le 10^9 \times 10^9 \approx 10^{18}$，`long long` 可承载，`int` 必炸。

## 5. 正确性证明

**约定**：记 $v[i] = \text{strength}[i]$；$L(i)$、$R(i)$ 如 §3.2 定义（左严格、右非严格）。

**引理 1（管辖刻画）**：子数组 $[l, r]$ 的最小值等值簇的**最右**位置为 $i$ $\iff$ $L(i) < l \le i \le r < R(i)$。

**证明**：（⇒）设 $i$ 是 $[l,r]$ 最小值等值簇的最右位置。若 $l \le L(i)$，则 $L(i) \in [l, i)$ 且 $v[L(i)] < v[i]$，与 $i$ 取到最小值矛盾；若 $r \ge R(i)$，则 $R(i) \in (i, r]$ 且 $v[R(i)] \le v[i]$——取 $<$ 与最小性矛盾，取 $=$ 与「最右」矛盾。
（⇐）设 $L(i) < l \le i \le r < R(i)$。对 $j \in [l, i)$：$L(i)$ 是**最近**的严格更小者，故 $(L(i), i)$ 内一切 $v[j] \ge v[i]$；对 $j \in (i, r]$：$R(i)$ 是**最近**的 $\le$ 者，故 $(i, R(i))$ 内一切 $v[j] > v[i]$。于是 $i$ 在 $[l,r]$ 中取到最小值且右侧无等值者，即 $i$ 是等值簇最右位置。∎

**引理 2（不重不漏）**：每个非空子数组恰被一个下标管辖，故 $\sum_i v[i] \cdot S(i)$ 恰等于全部子数组的总力量之和。

**证明**：任一非空子数组的最小值等值簇非空且有限，其最右位置存在且唯一；由引理 1，该子数组恰落入这一个 $i$ 的窗口，一个不多、一个不少。∎

**引理 3（和之和公式）**：$S(i) = (i-L)\bigl(PP[R+1]-PP[i+1]\bigr) - (R-i)\bigl(PP[i+1]-PP[L+1]\bigr)$。

**证明**：$\text{sum}(l,r) = P[r+1] - P[l]$ 为恒等式。双重求和中 $P[r+1]$ 与 $l$ 无关、$P[l]$ 与 $r$ 无关，分别提出因子 $(i-L)$ 与 $(R-i)$；再由 $PP$ 定义，$\sum_{r=i}^{R-1} P[r+1] = \sum_{j=i+1}^{R} P[j] = PP[R+1] - PP[i+1]$，$\sum_{l=L+1}^{i} P[l] = PP[i+1] - PP[L+1]$。全程为恒等变形。∎

**引理 4（单调栈求出 $L$、$R$）**：一次遍历中，$j$ 被 $i$ 弹出当且仅当 $i = R(j)$，且弹出后新栈顶（栈空视作 $-1$）恰为 $L(j)$。

**证明**：弹栈条件 `val[栈顶] ≥ val[i]` 保证栈内值严格递增。**先证 $R(j) = i$**：弹出时 $v[i] \le v[j]$；若存在 $k \in (j, i)$ 使 $v[k] \le v[j]$，取最靠左的这样的 $k$，则 $k$ 入栈时 $j$ 仍在栈中（否则 $(j,k)$ 内已有更早的 $\le v[j]$ 者，与最靠左矛盾），且 $j$ 上方的元素值均 $> v[j] \ge v[k]$，会被 $k$ 逐个弹出后轮到 $j$——故 $j$ 至迟在 $k < i$ 时已被弹出，矛盾。**再证 $L(j) = $ 新栈顶 $p$**：栈严格递增给出 $v[p] < v[j]$；若 $(p, j)$ 内存在 $v[q] < v[j]$，注意 $(p,j)$ 中所有下标在 $j$ 入栈前均已出栈（$p$ 在 $j$ 入栈时是栈顶），考察 $q$ 的「弹出者链」$q \leftarrow m_1 \leftarrow m_2 \leftarrow \cdots$：链上下标严格递增且均 $< j$（$j$ 只弹值 $\ge v[j]$ 者，不会成为链上元素的弹出者），值沿链不增且始终 $< v[j]$；有限链必终止于某个 $j$ 入栈时仍在栈中的元素，它位于 $(p, j)$——与 $p$ 紧贴 $j$ 下方矛盾。∎

**定理**：算法返回值与全部子数组总力量之和对 $10^9 + 7$ 同余。

**证明**：由引理 4，出栈瞬间结算所用的 $L$、$R$ 与引理 1 的定义一致；由引理 3，每个 $S(j)$ 被恒等地正确计算；由引理 2，$\sum_j v[j]\, S(j)$ 即所求总和。全部中间运算只含模意义下的加、乘与已修正为非负的减法，同余关系对加、减、乘封闭，故返回值与真值同余。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。预处理 $P$、$PP$ 各一趟；主循环中每个下标至多入栈、出栈各一次，每次出栈的结算 $O(1)$。$n \le 10^5$ 轻松通过，$O(n^2)$ 暴力约 $10^{10}$ 次运算相差两个数量级。
- **空间复杂度**：$O(n)$。$P$（$n+1$ 项）、$PP$（$n+2$ 项）与栈；一次遍历写法不显式存 $L$、$R$ 数组，出栈瞬间即用即弃。

## 7. 参考代码

### C++（一次遍历：哨兵 + 出栈瞬间结算）

```cpp
class Solution {
  public:
    int totalStrength(vector<int>& strength) {
        const int n = strength.size();
        const long long MOD = 1e9 + 7;

        vector<long long> P(n + 1), PP(n + 2);              // PP 开 n+2 项
        for (int i = 0; i < n; ++i) P[i + 1] = (P[i] + strength[i]) % MOD;
        for (int i = 0; i <= n; ++i) PP[i + 1] = (PP[i] + P[i]) % MOD;

        long long ans = 0;
        vector<int> st;                                      // 下标栈，对应值严格递增
        for (int i = 0; i <= n; ++i) {                       // i = n 是值恒小的哨兵
            int cur = (i < n) ? strength[i] : 0;
            while (!st.empty() && strength[st.back()] >= cur) {
                int j = st.back(); st.pop();                 // 出栈瞬间：边界已定
                int l = st.empty() ? -1 : st.back();
                int r = i;
                long long a = (PP[r + 1] - PP[j + 1] + MOD) % MOD;  // ΣP[j+1..r]
                long long b = (PP[j + 1] - PP[l + 1] + MOD) % MOD;  // ΣP[l+1..j]
                long long S = ((long long)(j - l) * a % MOD
                             - (long long)(r - j) * b % MOD + MOD) % MOD;
                ans = (ans + (long long)strength[j] * S) % MOD;
            }
            st.push_back(i);
        }
        return (int)ans;
    }
};
```

### Python（同一逻辑，大整数免溢出烦恼）

```python
class Solution:
    def totalStrength(self, strength: List[int]) -> int:
        n, MOD = len(strength), 10 ** 9 + 7

        P = [0] * (n + 1)
        for i, s in enumerate(strength):
            P[i + 1] = (P[i] + s) % MOD
        PP = [0] * (n + 2)                                  # PP 开 n+2 项
        for i in range(n + 1):
            PP[i + 1] = (PP[i] + P[i]) % MOD

        ans = 0
        st = []                                              # 下标栈，对应值严格递增
        for i in range(n + 1):                               # i = n 是值恒小的哨兵
            cur = strength[i] if i < n else 0
            while st and strength[st[-1]] >= cur:
                j = st.pop()                                 # 出栈瞬间：边界已定
                l = st[-1] if st else -1
                r = i
                a = (PP[r + 1] - PP[j + 1]) % MOD            # ΣP[j+1..r]
                b = (PP[j + 1] - PP[l + 1]) % MOD            # ΣP[l+1..j]
                S = ((j - l) * a - (r - j) * b) % MOD
                ans = (ans + strength[j] * S) % MOD
            st.append(i)
        return ans
```

> ⚠️ 两个 C++ 细节：① 取模后的 $PP$ 做差可能为负，每处做差都要 `+ MOD` 再 `%`（Python 的 `%` 对负数天然得非负值，可省）；② `(j - l) * a` 约 $10^{14}$、`strength[j] * S` 约 $10^{18}$，均在 `long long` 内，但任何一处用 `int` 承载都会溢出。

## 8. 边界情况与易错点

1. **等值重复计数（头号 WA）**：两侧都取严格更小 → `[2,2]` 得 24（正确 16），见 §2 补充示例。必须一侧严格、一侧非严格；本篇约定**左严格 / 右非严格**，每个子数组归最小值等值簇**最右**者。
2. **负数取模**：取模后的 $PP$ 做差为负时，C++ 的 `%` 得负值污染答案，须 `(a - b + MOD) % MOD`；Python 无此问题。
3. **`PP` 少开一项**：结算访问 $PP[R+1]$，$R$ 可为 $n$，故 $PP$ 需 $n+2$ 项；开 $n+1$ 会在「右侧无更小」时越界。
4. **`PP` 不取模会溢出**：真值上界约 $5 \times 10^{18}$，贴着 `long long` 上限，且后续乘法必溢出——建表即取模，别想着「先算真值最后再模」。
5. **`int` 溢出**：`strength[j] * S` 约 $10^{18}$、前缀和真值可达 $10^{14}$，C++ 全程 `long long`。
6. **$n = 1$**：$P = [0, s]$、$PP = [0, 0, s]$，哨兵弹出唯一的 $j = 0$ 时 $L = -1$、$R = 1$、$S = s$，答案 $s^2 \bmod p$，无需特判。
7. **弹栈条件写错方向**：一次遍历写法里弹栈必须是 `>=`（等值也弹，才能实现「右非严格」）；写成 `>` 会退化成两侧严格，回到第 1 条 WA。两次单调栈写法同理：左边界从左到右扫（弹 $\ge$）、右边界从右到左扫（弹 $>$），方向与条件都不能反。

- [LeetCode 2104. 子数组范围和](https://leetcode.cn/problems/sum-of-subarray-ranges/)：贡献法同时拆 $\max$ 与 $\min$ 之差，巩固「枚举元素算管辖」范式。
- [LeetCode 84. 柱状图中最大的矩形](https://leetcode.cn/problems/largest-rectangle-in-histogram/)：单调栈求「左右第一个更小」的起源题，2281 的边界预处理即其变体。

**延伸思考**：① **指标再升一层**：若贡献改为 $\min \times \text{sum}^2$（子数组和的平方），二重前缀和不再够用，需要「平方的前缀和」等更高阶工具——「对什么求和，就预备它的前缀和」可以层层推广。② **力量值带负数**：贡献法拆分是组合恒等式，不依赖数值非负，本文公式原样成立；但若指标改成 $\min \times \max$ 这类双端耦合，单一单调栈就不够，需分治或双栈。③ **在线区间询问**：若多次询问「某下标区间内所有子数组的总力量和」，需把单调栈版贡献改为按最值位置分治（类似笛卡尔树上的子树统计），配合差分询问做到近线性。
