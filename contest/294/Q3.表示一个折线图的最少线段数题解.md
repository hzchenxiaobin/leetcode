# LeetCode 表示一个折线图的最少线段数 题解

## 1. 题目概述

- **标题 / 题号**：表示一个折线图的最少线段数（#2280，medium）
- **链接**：https://leetcode.cn/problems/minimum-lines-to-represent-a-line-chart/
- **来源**：LeetCode 第 294 场周赛 Q3
- **难度**：中等
- **标签**：几何、排序、数组、数学、数论

**题意**：给定二维整数数组 `stockPrices`，其中 `stockPrices[i] = [day_i, price_i]` 表示股票在第 `day_i` 天的价格为 `price_i`。把每个 `(day, price)` 画成平面上的点，**按日期顺序**将相邻点用线段连成折线图。返回能完整表示这张折线图的**最少线段数**（一条线段可覆盖折线上一段连续共线的部分）。

**约束**：

- $1 \le \text{stockPrices.length} \le 10^5$
- $1 \le \text{day}_i,\ \text{price}_i \le 10^9$
- 所有 $\text{day}_i$ **互不相同**（但不保证输入按 day 有序！）

> 💡 本题在本仓库另有[每日题解 2280](../../solution/2201-2300/2280_表示一个折线图的最少线段数.md)：以「排序 + 叉积」的主线讲解与面试问答展开。本篇按**周赛复盘视角**重写：侧重**三分钟从题面到正解的切入路径**、**引理-定理化的严格证明**（极大共线链的刻画 → 下界 → 计数公式）、**double 精度反例的具体构造与实锤**，以及**乘法溢出的定量分析**，两篇互为印证。

## 2. 示例

**示例 1**

```text
输入：stockPrices = [[1,7],[2,6],[3,5],[4,4],[5,4],[6,3],[7,2],[8,1]]
输出：3
解释：(1,7)-(2,6)-(3,5)-(4,4) 斜率均为 −1，合并为段 1；
      (4,4)-(5,4) 斜率 0，单独成段 2；
      (5,4)-(6,3)-(7,2)-(8,1) 斜率均为 −1，合并为段 3。
```

**示例 2（乱序陷阱）**

```text
输入：stockPrices = [[3,4],[1,2],[7,8],[2,3]]
输出：1
解释：按 day 排序得 (1,2),(2,3),(3,4),(7,8)，四点共线，一条线段足够。
      若不排序直接扫「相邻三点」，会误判出多段。
```

**补充：double 精度反例（WA 实锤素材，坐标均在 $[1,10^9]$ 内）**

```text
输入：stockPrices = [[1,1],[333333335,333333334],[666666670,666666668]]
输出：2
解释：相邻方向 (333333334, 333333333) 与 (333333335, 333333334)，
      叉积 333333333×333333335 − 333333334×333333334 = −1 ≠ 0，三点不共线。
      但两个方向做 double 除法的斜率都舍入为 0.999999997，
      `==` 判相等 → 误判共线 → double 法返回 1，错！
```

## 3. 解题思路

### 3.1 比赛切入：一道披着几何皮的排序扫描题

周赛场上看到本题，三分钟内应当完成三步拆解：

1. **「折线图按日期连接」→ 顺序固定**：点怎么连不由我们决定，按 day 排好序依次相连。顺序固定意味着**不存在任何决策**——这不是构造题，是计数题；
2. **「一条线段是直的」→ 只能吃连续共线段**：线段不可能拐弯，它能覆盖的折线部分必须共线。于是答案就是「把排序后的点列切成最少的连续共线段」的段数；
3. **「切分点在哪」→ 相邻三点是否共线**：切分恰好发生在**斜率变化处**。答案 = 首段 1 + 斜率变化次数。

剩下的全部难度都在**实现细节**：输入乱序要先排序、斜率比较不能用除法、乘积会超 `int`——三颗雷分别对应 §8 的前三条易错点，本题 WA 的绝大多数都踩在这。

**暴力**：不排序、逐对算 `double` 斜率扫一遍——逻辑框架其实已经对了，但会同时踩中「乱序」与「精度」两颗雷，$O(n \log n)$ 的排序反而是最不会被漏掉的部分。

### 3.2 核心观察：极大共线链 = 答案

![核心观察：排序后数斜率变化，极大共线链有几条答案就是几](images/wc294_q3_slope_change_concept.svg)

把点按 day 升序排序后，定义**极大共线链**：一段**连续**的点区间 $P_a, \dots, P_b$，内部所有相邻边斜率相同，且向两端各延长一条边斜率就变（或到头）。核心观察是：

$$\text{答案} = \text{极大共线链的条数} = 1 + \text{相邻边斜率不同的次数} \quad (n \ge 2)$$

- **每条链一条线段就够了**（上界）：链内所有点共线（§5 引理 1），链首到链尾一条线段全覆盖；
- **每条链至少要一条线段**（下界）：线段是直的且是折线的子集，它覆盖的边必须与它共线、且在折线上连续——落进单条链里，跨不过链边界（§5 引理 2）。

### 3.3 算法流程：排序 + 叉积判变化

![算法流程：排序 → 特判 n≤1 → 扫描叉积比较 → 变化则计数并更新基准方向](images/wc294_q3_algorithm_flow.svg)

判断相邻边 $(P_{i-1}, P_i)$ 与 $(P_i, P_{i+1})$ 是否同斜率，**不做除法**，用整数叉积（交叉相乘）精确比较：

$$(y_i - y_{i-1})(x_{i+1} - x_i) = (y_{i+1} - y_i)(x_i - x_{i-1}) \iff \text{三点共线}$$

维护当前段的**基准方向** $(p_x, p_y)$（初值 $P_1 - P_0$），对每条新边 $(d_x, d_y)$ 比较 $d_y \cdot p_x$ 与 $p_y \cdot d_x$：不等则 `ans += 1` 并更新基准。流程：

1. **排序**：按 day 升序，$O(n \log n)$；
2. **特判**：$n \le 1$ 返回 $0$（单点无需线段）；
3. **初始化**：`ans = 1`，$(p_x, p_y) = P_1 - P_0$；
4. **扫描**：$i$ 从 $2$ 到 $n-1$，$(d_x, d_y) = P_i - P_{i-1}$；
5. **判变化**：$d_y \cdot p_x \ne p_y \cdot d_x$ 时 `ans += 1`，$(p_x, p_y) \leftarrow (d_x, d_y)$；
6. 返回 `ans`。

### 3.4 示例演算

![示例 1 逐边走查：叉积比较 7 条边，斜率变化 2 次](images/wc294_q3_example_walkthrough.svg)

示例 1（已有序）的 7 条边逐一走查：

| 相邻边 | $\Delta x$ | $\Delta y$ | 与基准 $(p_x, p_y)$ 比较 | 判定 |
|--------|-----------|-----------|--------------------------|------|
| (1,7)→(2,6) | 1 | $-1$ | —（首段，基准 $(1,-1)$） | ans = 1 |
| (2,6)→(3,5) | 1 | $-1$ | $(-1)\cdot 1 = (-1)\cdot 1$ 共线 | — |
| (3,5)→(4,4) | 1 | $-1$ | 共线 | — |
| (4,4)→(5,4) | 1 | $0$ | $0 \cdot 1 = 0 \ne (-1)\cdot 1 = -1$ | **新段**，ans = 2，基准 $(1,0)$ |
| (5,4)→(6,3) | 1 | $-1$ | $(-1)\cdot 1 = -1 \ne 0 \cdot 1 = 0$ | **新段**，ans = 3，基准 $(1,-1)$ |
| (6,3)→(7,2) | 1 | $-1$ | 共线 | — |
| (7,2)→(8,1) | 1 | $-1$ | 共线 | — |

变化 $2$ 次，$\text{ans} = 1 + 2 = 3$ ✓。示例 2 排序后相邻方向 $(1,1),(1,1),(4,4)$，全程 $d_y \cdot p_x = p_y \cdot d_x$，$\text{ans} = 1$ ✓。

## 4. 算法细节

1. **排序的比较器**：`stockPrices[i]` 是 `[day, price]`，C++ `sort` 对 `vector<vector<int>>` 的默认字典序、Python `list.sort()` 的默认行为都先按 day 再按 price——day 互不相同，恰好就是按 day 排序，无需自定义比较器。
2. **叉积形式的选择**：比较的是「当前边方向」与「基准方向」$d_y \cdot p_x$ vs $p_y \cdot d_x$，而非「当前边」与「上一条边」——两种写法等价（变化后基准即被更新为新边，归纳可证任意时刻基准 $\equiv$ 上一条边方向），但基准视角与「极大共线链」的定义直接对应，证明时表述更干净。
3. **无除零、无竖线特判**：day 互不相同且已排序 ⇒ 所有 $d_x > 0$，斜率分母永不为零。这是「叉积判共线」在本题比在一般几何题（如 149 题需处理竖直方向）更省事的原因。
4. **溢出的定量分析**：$|d_y| \le 10^9 - 2$，$|p_x| \le 10^9 - 2$，乘积上界 $999999998^2 = 999999996000000004 \approx 9.99999996 \times 10^{17} < 2^{63} - 1 \approx 9.22 \times 10^{18}$，`long long` 安全承载，余量约 $9.2$ 倍；但 `int` 上界 $\approx 2.1 \times 10^9$，差着约 $5$ 个数量级，**必炸**。
5. **精度反例的构造原理**：两个不相等的分数 $\frac{a}{b} \ne \frac{c}{d}$ 最小可差 $\frac{1}{bd}$；本题 $b, d$ 均可接近 $10^9$，故差可小至 $10^{-18}$，而 `double` 在 $1$ 附近的分辨率（ulp）约 $2.22 \times 10^{-16}$——**差比分辨率还小，两次除法舍入后位模式相同**，`==` 必然误判。§2 的反例取 $\frac{333333333}{333333334}$ 与 $\frac{333333334}{333333335}$，分子分母交叉相乘恰差 $1$（Farey 邻居），是构造此类反例的通用手法。
6. **为什么取 gcd 化简分数也可行**：把 $(d_x, d_y)$ 除以 $\gcd$ 后作为键比较（或 Python `Fraction`）同样精确，代价是每次多一个 $O(\log V)$ 的 gcd；本题只比较**相邻两条边**，连哈希表都不需要，纯叉积乘法最省。

## 5. 正确性证明

**约定**：将点按 day 升序排序为 $P_1, \dots, P_n$，边 $e_i = P_{i-1}P_i$（$2 \le i \le n$，按记 $e_2, \dots, e_n$ 或 $i$ 从 1 计均可，下文以「边 $i$」指 $P_{i-1} \to P_i$），其方向向量 $(x_i - x_{i-1},\ y_i - y_{i-1})$，斜率记 $k_i$；day 互不相同保证 $x_i - x_{i-1} > 0$，斜率有定义。「折线图」$F$ 是所有边之并（点集）。「一组线段表示 $F$」指这些线段的并集等于 $F$。**极大共线链**：形如 $\{P_a, \dots, P_b\}$ 的极大连续区间，使内部所有相邻边斜率相同，且 $(a > 1 \Rightarrow k_a \ne k_{a-1})$、$(b < n \Rightarrow k_{b+1} \ne k_b)$。

**引理 1（共线 $\Leftrightarrow$ 相邻边斜率一致）**：连续点区间 $P_a, \dots, P_b$（$a < b$）共线，当且仅当其中所有相邻边斜率相等。

**证明**：（⇒）诸点共线于直线 $\ell$，每条相邻边的两个端点都在 $\ell$ 上，故斜率均为 $\ell$ 的斜率。（⇐）对 $b - a$ 归纳：$b - a = 1$ 平凡。设 $P_a, \dots, P_{b-1}$ 共线于斜率为 $s$ 的直线 $\ell$。相邻边 $P_{b-1}P_b$ 的斜率也为 $s$；过 $P_{b-1}$ 且斜率为 $s$ 的直线唯一，即 $\ell$，故 $P_b \in \ell$。∎

**推论**：每条极大共线链的诸点共线，链首到链尾的线段恰好覆盖整条链。

**引理 2（一条线段困于一条链）**：任何表示 $F$ 的线段 $L$，其覆盖的边集非空时，必完整落在某一条极大共线链内；且不同链的边集互不相交。

**证明**：设 $L$ 位于直线 $\ell$（斜率 $s$）上。因 $L \subseteq F$，$L$ 的每点在某条边上；含于 $F \cap \ell$ 中的边其两个端点在 $\ell$ 上，故斜率为 $s$ 且恰为 $\ell$ 上的边。$F$ 中落在 $\ell$ 上的边至多 $n-1$ 条，在 $\ell$ 上按 $x$ 严格递增离散排列：相邻两条要么共享端点（在折线上对应相邻的边），要么中间有正长度的一段「空隙」（不属于 $F$ 的 $\ell$ 部分）。$L$ 是连通区间且 $L \subseteq F$，不能跨过空隙，故 $L$ 覆盖的边在 $\ell$ 上首尾相接、在折线序中连续、斜率均为 $s$——由引理 1 它们含于某条极大共线链。（若 $L$ 退化为一个点或只碰到链的端点，其覆盖边集为空，不影响计数。）链按边集划分、两两不交显然。∎

**定理（计数公式）**：$n \le 1$ 时答案为 $0$；$n \ge 2$ 时答案等于极大共线链的条数 $m$，且 $m = 1 + |\{\, i : 3 \le i \le n,\ k_i \ne k_{i-1} \,\}|$。

**证明**：$n \le 1$ 时 $F$ 为单点（或空），无线段可画，答案 $0$。下设 $n \ge 2$。**上界**：每条链取「链首到链尾」的线段，由推论覆盖整条链；诸线段之并覆盖所有边与所有顶点（顶点是边的端点），等于 $F$，且每条线段 $\subseteq F$ 不多出点——$m$ 条线段构成合法表示。**下界**：设某组合法表示用 $t$ 条线段。每条边作为点集有正长度，必被某条线段覆盖；由引理 2，每条线段覆盖的边都落在单条链内。链的边集两两不交且每条链非空，覆盖全部 $n - 1 \ge 1$ 条边需要每条链至少贡献一条线段，故 $t \ge m$。**计数**：沿边序扫描，链恰在「首边」与「斜率变化后的新边」处开始；首链贡献 $1$，此后每次 $k_i \ne k_{i-1}$ 恰好开一条新链（极大性由两端不等式保证，引理 1 排除了「隔段合并」的可能），故 $m = 1 + $ 变化次数。∎

**定理（叉积判定的正确性）**：算法中 $d_y \cdot p_x \ne p_y \cdot d_x$ 当且仅当当前边斜率 $\ne$ 当前链基准斜率。

**证明**：$d_x, p_x > 0$，故 $\frac{d_y}{d_x} = \frac{p_y}{p_x} \iff d_y p_x = p_y d_x$（交叉相乘保持等号方向，分母为正无需变号）。基准方向在每次变化时更新为新边方向，归纳可知比较时基准斜率恒等于当前链的首边斜率。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \log n)$，排序主导；一趟扫描中每步仅常数次 64 位乘法与比较，共 $O(n)$。$n = 10^5$ 轻松通过。
- **空间复杂度**：$O(1)$，只维护 `ans` 与基准方向两个标量；不计排序自身的开销（C++ `std::sort` 原地，Python Timsort 另需 $O(n)$）。

## 7. 参考代码

### C++（排序 + 叉积一趟扫描）

```cpp
class Solution {
  public:
    int minimumLines(vector<vector<int>>& stockPrices) {
        int n = stockPrices.size();
        if (n <= 1) return 0;
        sort(stockPrices.begin(), stockPrices.end());
        int ans = 1;
        long long px = stockPrices[1][0] - stockPrices[0][0];
        long long py = stockPrices[1][1] - stockPrices[0][1];
        for (int i = 2; i < n; ++i) {
            long long dx = stockPrices[i][0] - stockPrices[i - 1][0];
            long long dy = stockPrices[i][1] - stockPrices[i - 1][1];
            if (dy * px != py * dx) {
                ++ans;
                px = dx;
                py = dy;
            }
        }
        return ans;
    }
};
```

### Python（同一逻辑，大整数天然免疫溢出）

```python
class Solution:
    def minimumLines(self, stockPrices: List[List[int]]) -> int:
        n = len(stockPrices)
        if n <= 1:
            return 0
        stockPrices.sort()
        ans = 1
        px = stockPrices[1][0] - stockPrices[0][0]
        py = stockPrices[1][1] - stockPrices[0][1]
        for i in range(2, n):
            dx = stockPrices[i][0] - stockPrices[i - 1][0]
            dy = stockPrices[i][1] - stockPrices[i - 1][1]
            if dy * px != py * dx:
                ans += 1
                px, py = dx, dy
        return ans
```

> ⚠️ C++ 细节：`px`、`py`、`dx`、`dy` 必须声明为 `long long`——若声明为 `int`，赋值处（差值本身不溢出）看似无事，但 `dy * px` 会在 `int` 域内相乘截断，且**截断后可能碰巧相等也可能碰巧不等**，属于最隐蔽的一类 WA；乘积真值上界 $\approx 10^{18}$，`long long`（上限 $\approx 9.2 \times 10^{18}$）安全。

## 8. 边界情况与易错点

1. **不排序直接扫（头号 WA）**：题目只保证 day 互不相同，**不保证输入有序**。示例 2 乱序输入是最直接的提醒；乱序时「相邻三点共线」的判定对象完全是错的点对。C++ 默认 `sort` 与 Python 默认 `sort()` 即按 day 优先，无需比较器。
2. **double 除法比较斜率（二号 WA）**：本应不等的两个斜率差可小至 $10^{-18}$，小于 `double` 的分辨率 $2.22 \times 10^{-16}$，两次除法舍入到位模式相同，`==` 误判共线、少算线段（§2 反例实测：正确答案 2，double 法返回 1）。同理，`abs(k1 - k2) < eps` 的写法在 $10^9$ 坐标下也选不出安全的 eps。一律叉积。
3. **`int` 溢出（三号 WA）**：$999999998^2 \approx 10^{18}$，超 `int` 约 $5$ 个数量级，C++ 全程 `long long`；Python 大整数无此问题。
4. **$n = 1$ / $n = 2$**：$n \le 1$ 返回 $0$（单点画不出线段）；$n = 2$ 循环不执行，`ans` 初值 $1$ 即答案。两情形被「特判 + 初值」自然覆盖，无需额外分支。
5. **误以为是 DP 或「最少直线覆盖」**：顺序固定是本题能一趟扫描的关键；一旦允许任意顺序连点，就逼近 NP-hard 的最少线段覆盖问题（见延伸思考），考场上若往那个方向想会彻底卡死。
6. **斜率相等的「隔段迷惑」**：边斜率序列 $1, 2, 1$ 中首尾两条边斜率相同，但它们分属不同链（中间隔着斜率 2 的边，不连续），不能合并——计数只看**相邻**变化，跨段同斜率不干扰，这正是「极大**连续**」定义的价值。

**延伸思考**：① **线段允许「悬空」会更省吗**：若放宽为「线段并集只需包含折线」（允许线段上有多余点），答案确实可能变小——边斜率 $+1, -1, +1$ 的 W 形折线中，首尾两条链若恰好落在**同一条直线**上（如 $(0,0),(1,1)$ 与 $(3,-1),(5,1)$ 都在 $y=x$ 上），可用一条「悬空」线段 $[(0,0),(5,1)]$ 同时覆盖，3 链并作 2 条。此变体的答案退化为「承载至少一条边的不同直线的条数」，用「化简方向向量 + 哈希」一趟可数，恰是 149 题的工具反向应用。② **任意顺序连点**：变成「最少线段路径覆盖所有点」，一般情形 NP-hard，考场勿入。③ **同一天多个价格**：day 允许重复时出现竖直边（$d_x = 0$），叉积判定依然适用（无需斜率有定义），但引理 1 的归纳需改用方向向量成比例表述，竖直边也无法与斜边比较——可作练习。
