# LeetCode 两个数组间的距离值 题解

## 1. 题目概述

- **标题 / 题号**：两个数组间的距离值（#1385，easy）
- **链接**：https://leetcode.cn/problems/find-the-distance-value-between-two-arrays/
- **来源**：LeetCode 第 22 场双周赛 Q1
- **难度**：简单
- **标签**：数组、双指针、二分查找、排序

**题意**：给定整数数组 `arr1`、`arr2` 与整数 $d$。若 `arr1[i]` 满足对**所有** `arr2[j]` 都有 $|arr1[i] - arr2[j]| > d$，则称其为「远离元素」（即 `arr2` 中不存在与它距离不超过 $d$ 的元素）。返回 `arr1` 中远离元素的个数。

**约束**：

- $1 \le arr1.length, arr2.length \le 500$
- $-1000 \le arr1[i], arr2[j] \le 1000$
- $0 \le d \le 100$

## 2. 示例

**示例 1**

```text
输入：arr1 = [4,5,8], arr2 = [10,9,1,8], d = 2
输出：2
解释：4 最近的是 1（|4−1|=3 > 2）✓；5 最近的是 8（|5−8|=3 > 2）✓；
      8 与 8 距离 0 ≤ 2 ✗。共 2 个远离元素。
```

**示例 2**

```text
输入：arr1 = [1,4,2,3], arr2 = [-4,-3,6,10,20,30], d = 3
输出：2
解释：1 与 −3 距 4 > 3 ✓；2 与 6 距 4 > 3 ✓；4 与 6 距 2 ≤ 3 ✗；3 与 6 距 3 ≤ 3 ✗。
```

**示例 3**

```text
输入：arr1 = [2,1,100,3], arr2 = [-5,-2,10,-3,7], d = 6
输出：1
解释：只有 100 与 `arr2` 全部元素距离 > 6，其余都被 −2、7 等覆盖。
```

## 3. 解题思路

### 3.1 暴力思路

对每个 `arr1[i]` 扫一遍 `arr2`，检查是否所有距离都 $> d$：$O(nm)$，最多 $500 \times 500 = 2.5 \times 10^5$ 次比较，规模小到完全可过。暴力没有任何错误风险，本题作为签到题直接写也行。但如果 $n, m$ 大到 $10^5$ 量级，$O(nm)$ 就必须优化——优化的钥匙是「**只需要知道窗口里有没有元素**」。

### 3.2 核心观察：排序后「窗口内有没有元素」二分可判

![远离判定：arr2 排序后，只需检查 [x−d, x+d] 内有没有元素](images/bw22_q1_binary_search.svg)

把判定改写成区间语言：$x$ 是远离元素 ⇔ `arr2` 中**不存在**落在闭区间 $[x - d,\ x + d]$ 内的元素 ⇔ 该窗口为空。

把 `arr2` 排序后，窗口内的元素（若存在）必是一段**连续区间**。于是只需一次二分：`lower_bound(arr2, x - d)` 找到第一个 $\ge x - d$ 的元素 `arr2[j]`，若 `arr2[j] > x + d`（或 `j` 越界），窗口内没有任何元素，$x$ 远离。排序 $O(m \log m)$、每个询问 $O(\log m)$，总计 $O((n + m) \log m)$。

### 3.3 算法流程：排序 + 二分

```text
1. 对 arr2 排序
2. cnt = 0
3. 对每个 x ∈ arr1：
     j = lower_bound(arr2, x − d)      # 第一个 ≥ x−d 的下标
     若 j == m 或 arr2[j] > x + d：cnt += 1
4. 返回 cnt
```

其中 `lower_bound` 是 C++ STL / Python `bisect` 的标准件，语义「第一个大于等于目标的位置」，正好对准窗口左端。

### 3.4 双指针替代与示例演算

![双指针替代：两数组都排序后，i、j 一起往右扫](images/bw22_q1_two_pointers.svg)

排序后的 `arr1` 本身递增，窗口 $[x - d, x + d]$ 随 $x$ 单调右移，于是 `arr2` 的指针 $j$ **只需前进、永不回退**：对每个 $x$ 把 $j$ 推到第一个 $\ge x - d$ 的位置再判定。两指针合计各走一遍，$O(n + m)$（外加两次排序）。

以示例 1 演算（`arr1` 排序为 $[4,5,8]$，`arr2` 排序为 $[1,8,9,10]$，$d=2$）：

| $x$ | 窗口 $[x-d, x+d]$ | 判定元素 | 结果 |
|-----|--------------------|----------|------|
| 4 | $[2, 6]$ | 第一个 $\ge 2$ 的是 8，$8 > 6$ | 窗口空 ✓ |
| 5 | $[3, 7]$ | 第一个 $\ge 3$ 的是 8，$8 > 7$ | 窗口空 ✓ |
| 8 | $[6, 10]$ | 第一个 $\ge 6$ 的是 8，$8 \le 10$ | 窗口非空 ✗ |

计数 2，与示例一致。注意 $x = 8$ 时窗口命中 8、9、10 三个元素，二分只「探到第一个」即可判定非空。

## 4. 算法细节

1. **`lower_bound` 的语义**：找第一个 $\ge x - d$ 的位置。若改用 `upper_bound`（第一个 $> x - d$ 的位置）会漏掉恰好等于 $x - d$ 的元素——而端点相等时 $|x - y| = d \le d$，$x$ 不远离，漏判会错答。
2. **判定窗口空的两个分支**：`j == m`（全部元素都 $< x - d$）或 `arr2[j] > x + d`（第一个进入窗口左端的元素已越过右端）。两者合并为「窗口空」。
3. **`arr1` 不必排序（二分版）**：询问彼此独立，`arr1` 保持原序直接逐个二分。双指针版才需要排序 `arr1`。
4. **原地排序 `arr2` 是否允许**：题目未禁止修改入参数组；若想无副作用，复制一份再排。
5. **值域的启示**：$|值| \le 1000$、$d \le 100$，还可以开值域桶（$O(V)$ 数组标记 `arr2` 出现过的值，再前缀和查询窗口计数）——$O(n + m + V)$，本题规模下与二分无异，但值域扩大后失效，通用性不如二分。

## 5. 正确性证明

**引理 1（窗口刻画）**：$x$ 是远离元素 ⇔ 排序后的 `arr2` 中不存在下标 $j$ 使 $x - d \le arr2[j] \le x + d$。

**证明**：$|x - y| \le d \Leftrightarrow x - d \le y \le x + d$（绝对值不等式的等价展开）。远离的定义是「对所有 $j$ 都 $|x - arr2[j]| > d$」，其否定即「存在 $j$ 使 $|x - arr2[j]| \le d$」。排序不改变多重集合的元素构成，故「存在」在排序前后等价。∎

**引理 2（首元素判定）**：设 `arr2` 已升序，$j^* = \min\{j : arr2[j] \ge x - d\}$。则窗口非空 ⇔ $j^*$ 存在且 $arr2[j^*] \le x + d$。

**证明**：（⇐）若 $j^*$ 存在且 $arr2[j^*] \le x + d$，则 $x - d \le arr2[j^*] \le x + d$，窗口非空。（⇒）设窗口非空，取窗口内任一元素 $arr2[k]$，则 $arr2[k] \ge x - d$，故集合非空、$j^*$ 存在且 $j^* \le k$；由升序 $arr2[j^*] \le arr2[k] \le x + d$。∎

**定理**：算法返回的计数等于 `arr1` 中远离元素的个数。

**证明**：算法对每个 $x$ 计算 $j^*$（`lower_bound` 的定义即 $j^*$；全数组都 $< x - d$ 时返回 $m$），当 $j^* = m$ 或 $arr2[j^*] > x + d$ 时计数。由引理 2，此条件恰为「窗口空」的否定之否定（窗口空 ⇔ $j^*$ 不存在或 $arr2[j^*] > x + d$）；再由引理 1，窗口空 ⇔ $x$ 远离。故算法对每个 $x$ 的计数判定与远离定义逐一等价，计数正确。∎

## 6. 复杂度分析

- **时间**：$O(m \log m + n \log m)$——排序 `arr2` 一次、每个询问一次二分。$n, m \le 500$ 时约 $500 \times 9 + 500 \times 9 \approx 9000$ 次基本操作；即便放大到 $10^5$ 量级也只有 $O\big((n+m)\log m\big) \approx 3 \times 10^6$。双指针版为 $O(n \log n + m \log m + n + m)$，排序主导。
- **空间**：$O(1)$ 额外（原地排序 `arr2`，二分只用常数变量）；若不允许修改入参则 $O(m)$ 复制。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int findTheDistanceValue(vector<int>& arr1, vector<int>& arr2, int d) {
        sort(arr2.begin(), arr2.end());
        int cnt = 0;
        for (int x : arr1) {
            // lower_bound 找第一个 >= x-d 的元素
            auto it = lower_bound(arr2.begin(), arr2.end(), x - d);
            if (it == arr2.end() || *it > x + d) ++cnt;   // 窗口 [x-d, x+d] 为空
        }
        return cnt;
    }
};
```

### Python

```python
from typing import List
from bisect import bisect_left

class Solution:
    def findTheDistanceValue(self, arr1: List[int], arr2: List[int], d: int) -> int:
        arr2 = sorted(arr2)
        cnt = 0
        for x in arr1:
            j = bisect_left(arr2, x - d)     # 第一个 >= x-d 的位置
            if j == len(arr2) or arr2[j] > x + d:
                cnt += 1                     # 窗口 [x-d, x+d] 为空
        return cnt
```

> 💡 两份代码均通过官方 3 组示例（2、2、1），并与 $O(nm)$ 直接判定的暴力对拍 3000 组随机数据（$n, m \le 20$，值域与 $d$ 均取满范围）全部一致。

## 8. 边界情况与易错点

1. **端点相等的判定**：$|x - y| = d$ 时 $x$ **不**远离（题目要求严格 $> d$）。二分用 `bisect_left/lower_bound`（$\ge$ 语义）而非 `bisect_right/upper_bound`（$>$ 语义），否则会把恰好等于 $x - d$ 的元素漏出窗口，错把不远离的数计成远离。
2. **窗口空的两分支都要写**：`it == arr2.end()`（整个数组都在窗口左侧）与 `*it > x + d`（首元素已越过右端）缺一不可；漏掉前者会在「全部元素都太小」时解引用尾迭代器（C++ 未定义行为）。
3. **`d = 0`**：窗口 $[x, x]$ 只含 $x$ 自身，判定退化为「`arr2` 里有没有恰好等于 $x$ 的元素」，逻辑无需特判。
4. **排序前别忘 `arr2` 可能被重复元素充满**：重复值不影响判定（窗口只问有无），无需去重。
5. **负数与溢出**：值域 $\pm 1000$、$d \le 100$，`x - d` 最小 $-1100$、`x + d` 最大 $1100$，全在 `int` 舒适区。
6. **修改入参的副作用**：C++ 版原地排序了 `arr2`；若调用方之后还要用原序，先复制。
