# LeetCode 树中距离之和 题解

## 1. 题目概述

- **标题 / 题号**：树中距离之和（#834，hard）
- **链接**：https://leetcode.cn/problems/sum-of-distances-in-tree/
- **来源**：LeetCode 第 84 场周赛 Q4
- **难度**：困难
- **标签**：树、深度优先搜索、图、动态规划、树形 DP

**题意**：给定一棵有 $n$ 个节点（编号 $0 \sim n-1$）、$n-1$ 条边的无向连通树，边权为 1。返回长度 $n$ 的数组 `answer`，其中

$$\text{answer}[i] = \sum_{j \ne i} \mathrm{dist}(i, j)$$

即节点 $i$ 到其余所有节点的距离之和。

**约束**：

- $1 \le n \le 3 \times 10^4$
- $\text{edges.length} = n-1$，$\text{edges}[i] = [a_i, b_i]$，$0 \le a_i, b_i < n$，$a_i \ne b_i$
- 输入保证是一棵有效的树

**关键信息**：$n$ 达 $3\times10^4$，对每个节点各做一次 BFS 是 $O(n^2) \approx 9\times10^8$，在 Python 里必然超时（C++ 也很勉强）。树的无环结构允许我们**只算一次，再用换根公式把答案推到邻居**。

## 2. 示例

**示例 1**

```text
输入：n = 6, edges = [[0,1],[0,2],[2,3],[2,4],[2,5]]
输出：[8,12,6,10,10,10]
解释：dist(0,1)+dist(0,2)+dist(0,3)+dist(0,4)+dist(0,5) = 1+1+2+2+2 = 8，
      其余节点同理。
```

**示例 2**

```text
输入：n = 1, edges = []
输出：[0]
解释：只有一个节点，没有「其他节点」。
```

**示例 3**

```text
输入：n = 2, edges = [[1,0]]
输出：[1,1]
解释：两个节点互相距离为 1。
```

## 3. 解题思路

### 3.1 暴力思路

对每个节点 $s$ 做一次 BFS/DFS，求出所有 $\mathrm{dist}(s, \cdot)$ 并求和：

- 单次遍历 $O(n)$，共 $n$ 次，总时间 $O(n^2)$；
- $n = 3\times10^4$ 时约 $9\times10^8$ 次操作，缓存不友好，实际运行时间远超限制。

瓶颈在于「$n$ 次遍历之间没有复用」。但相邻两个节点的答案其实**只差一个可计算的量**——这正是换根 DP 的切入点。

### 3.2 核心观察：把根挪一条边，答案如何变化

![树形 DP 第一遍：子树大小与根的距离和](images/wc84_q4_subtree_dp.svg)

任选节点 $0$ 为根，定义：

- $\mathrm{depth}[v]$：$v$ 到根的距离；
- $\mathrm{sz}[v]$：以 $v$ 为根的**子树节点数**（含 $v$ 自己）。

第一遍 DFS 可以一次性求出：

$$\text{ans}[0] = \sum_{v}\mathrm{depth}[v] = \sum_{v \ne 0}\mathrm{dist}(0, v)$$

以及所有 $\mathrm{sz}[v]$（后序累加：$\mathrm{sz}[u] = 1 + \sum_{c \in \mathrm{child}(u)}\mathrm{sz}[c]$）。

接着考虑把根从 $u$ 挪到它的孩子 $v$：

![换根：从父节点的答案推出子节点的答案](images/wc84_q4_reroot_formula.svg)

把节点分成两组，比较 $\mathrm{dist}(v, x)$ 与 $\mathrm{dist}(u, x)$。记 $S = \mathrm{subtree}(v)$（含 $v$ 自己），$|S| = \mathrm{sz}[v]$：

- 对 $x \in S$：若 $x = v$，则 $\mathrm{dist}(v,v) = 0 = \mathrm{dist}(u,v) - 1$；若 $x \ne v$，则从 $v$ 到 $x$ 的路径完全落在子树内，比从 $u$ 出发少走边 $(u,v)$，同样**减 1**。故这 $\mathrm{sz}[v]$ 个点各减 1。
- 对 $x \notin S$：从 $v$ 到 $x$ 必须先经过边 $(u,v)$，比从 $u$ 出发多走一步，**加 1**。这样的点共 $n - \mathrm{sz}[v]$ 个。

于是得到**换根公式**：

$$\text{ans}[v] = \text{ans}[u] + \bigl(n - \mathrm{sz}[v]\bigr) - \mathrm{sz}[v] = \text{ans}[u] + n - 2\,\mathrm{sz}[v]$$

因为树中任意节点都可以由根沿唯一条路径到达，把这个公式沿着 DFS 序自上而下推一遍，就能得到所有节点的答案。

### 3.3 算法流程

```text
1. 建邻接表 g（无向边）
2. 迭代式 BFS/DFS 求 parent[]、depth[]、遍历序 order（避免递归过深）
3. sz 全部初始化为 1；按 order 的逆序累加：sz[parent[v]] += sz[v]
4. ans[0] = Σ depth[v]
5. 按 order 的正序（即父先于子）：ans[v] = ans[parent[v]] + n − 2·sz[v]
6. 返回 ans
```

### 3.4 示例演算

![示例演算：逐个节点套换根公式](images/wc84_q4_walkthrough.svg)

以示例 1 的树（边 $0\!-\!1$、$0\!-\!2$、$2\!-\!3$、$2\!-\!4$、$2\!-\!5$）为例，取 $0$ 为根：

| 节点 | 父节点 | $\mathrm{sz}$ | 换根计算 | $\text{ans}$ |
|------|--------|---------------|----------|--------------|
| 0 | — | 6 | $\sum \mathrm{depth} = 0+1+1+2+2+2$ | 8 |
| 1 | 0 | 1 | $8 + 6 - 2\times1$ | 12 |
| 2 | 0 | 4 | $8 + 6 - 2\times4$ | 6 |
| 3 | 2 | 1 | $6 + 6 - 2\times1$ | 10 |
| 4 | 2 | 1 | $6 + 6 - 2\times1$ | 10 |
| 5 | 2 | 1 | $6 + 6 - 2\times1$ | 10 |

输出 `[8,12,6,10,10,10]`，与示例一致。

## 4. 算法细节

1. **迭代代替递归**：$n = 3\times10^4$ 时链状树的递归深度可达 $3\times10^4$，Python 默认递归上限 1000 会直接 `RecursionError`，C++ 也可能爆栈。用显式栈或 BFS 队列得到 `order`，再按 `order` 的正/逆序遍历，完全避开递归。
2. **`order` 的构造**：从根开始，用「队列/栈 + parent 数组」扩展；由于是树，只要跳过 `parent[v]` 就不会回访。`order` 满足「父节点排在子节点之前」。
3. **逆序累加 `sz`**：`for v in reversed(order[1:])`，保证处理 $v$ 时它的所有孩子都已被累加过。
4. **正序推 `ans`**：`for v in order[1:]`，保证 `ans[parent[v]]` 先算好。
5. **`ans[0]` 的求法**：$\sum \mathrm{depth}[v]$，因为根到每个节点的距离就是它的深度；`depth[0] = 0` 不影响求和。
6. **溢出**：$n = 3\times10^4$ 时答案最大约为 $n^2/2 = 4.5\times10^8$（链的端点），在 32 位有符号范围内；但累加 `Σdepth` 建议用 `long long` 以防中间计算（如 `n - 2*sz` 与乘加）出现意外，最后转回 `int`。
7. **邻接表规模**：$2(n-1)$ 条有向边，用 `vector<vector<int>>` 或 Python 的列表数组即可；无需边权。

## 5. 正确性证明

以下所有结论均以「以 $0$ 为根」为前提，$u$ 是 $v$ 的父节点。

**引理 1（子树大小正确）**：按 `order` 逆序执行 $\mathrm{sz}[\mathrm{parent}[v]] \mathrel{+}= \mathrm{sz}[v]$ 后，对每个节点 $v$，$\mathrm{sz}[v]$ 等于其子树（含自身）的节点数。

**证明**：对 $v$ 在树中的深度做归纳。$v$ 为叶子时其子树只有自己，$\mathrm{sz}[v] = 1$ 成立，且它不会再有孩子被累加。设 $v$ 的所有孩子 $c$ 都满足 $\mathrm{sz}[c]$ 正确，则逆序处理时孩子先于父亲，处理到 $v$ 时 $\mathrm{sz}[v]$ 已经从每个孩子收到了正确的 $\mathrm{sz}[c]$，于是

$$\mathrm{sz}[v] = 1 + \sum_{c \in \mathrm{child}(v)} \mathrm{sz}[c]$$

正是子树的节点数。由于 `order` 逆序保证孩子先于父亲，归纳覆盖所有节点。∎

**引理 2（根的答案）**：$\text{ans}[0] = \sum_v \mathrm{depth}[v]$ 等于节点 $0$ 到其余所有节点的距离之和。

**证明**：在树上，$\mathrm{dist}(0, v)$ 就是 $0$ 到 $v$ 唯一路径的长度，也即 $v$ 的深度 $\mathrm{depth}[v]$（根深度为 0）。故 $\sum_{v \ne 0}\mathrm{dist}(0,v) = \sum_v \mathrm{depth}[v] - \mathrm{depth}[0] = \sum_v \mathrm{depth}[v]$。∎

**引理 3（换根公式）**：若 $v$ 是 $u$ 的孩子，则 $\text{ans}[v] = \text{ans}[u] + n - 2\,\mathrm{sz}[v]$。

**证明**：把「除 $v$ 之外」的节点分成两组：子树内的 $S = \mathrm{subtree}(v) \setminus \{v\}$（共 $\mathrm{sz}[v]-1$ 个）与子树外的 $T$（共 $n - \mathrm{sz}[v]$ 个，含 $u$）。

- 对 $x \in S$：从 $v$ 到 $x$ 不经过边 $(u,v)$，而从 $u$ 到 $x$ 必经过它，故 $\mathrm{dist}(v,x) = \mathrm{dist}(u,x) - 1$；
- 对 $x \in T$：从 $v$ 到 $x$ 必经过边 $(u,v)$，而从 $u$ 到 $x$ 不必，故 $\mathrm{dist}(v,x) = \mathrm{dist}(u,x) + 1$。

于是

$$\text{ans}[v] = \sum_{x \in S}\bigl(\mathrm{dist}(u,x)-1\bigr) + \sum_{x \in T}\bigl(\mathrm{dist}(u,x)+1\bigr)$$

把 $\text{ans}[u] = \sum_{x \ne u}\mathrm{dist}(u,x)$ 与上式对齐：两式覆盖的节点集合相差的只有 $x = u$ 与 $x = v$ 两个点，其中 $\mathrm{dist}(u,u) = 0$、$\mathrm{dist}(u,v) = 1$。整理得

$$\text{ans}[v] = \text{ans}[u] - 1 - \bigl(\mathrm{sz}[v]-1\bigr) + \bigl(n-\mathrm{sz}[v]\bigr) = \text{ans}[u] + n - 2\,\mathrm{sz}[v]$$

（其中 $-1$ 来自 $x=v$ 一项的贡献差，$-(\mathrm{sz}[v]-1)$ 来自 $S$ 中每个点距离减 1。）∎

**定理**：算法输出的数组满足 $\text{ans}[i] = \sum_{j \ne i}\mathrm{dist}(i,j)$。

**证明**：对节点在树中的深度归纳。深度 0 的根由引理 2 正确。设节点 $u$ 的答案正确，其孩子 $v$（深度加 1）由引理 3 得 $\text{ans}[v] = \text{ans}[u] + n - 2\mathrm{sz}[v]$，而引理 1 保证 $\mathrm{sz}[v]$ 是正确的子树大小，故公式成立，$\text{ans}[v]$ 也正确。由于算法按 `order` 正序（父先于子）计算，每个节点在被计算时父节点已正确，归纳成立。∎

## 6. 复杂度分析

- **时间**：$O(n)$。建图 $O(n)$；BFS/DFS 求 `order`、`parent`、`depth` 各 $O(n)$；逆序累加 `sz` 每条边一次 $O(n)$；正序推 `ans` 每个节点一次 $O(n)$。总计约 $4n$ 次操作。
- **空间**：$O(n)$。邻接表 $O(n)$，`parent`、`depth`、`order`、`sz`、`ans` 各 $O(n)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> sumOfDistancesInTree(int n, vector<vector<int>>& edges) {
        vector<vector<int>> g(n);
        for (auto& e : edges) {
            g[e[0]].push_back(e[1]);
            g[e[1]].push_back(e[0]);
        }
        vector<int> parent(n, -1), depth(n, 0), order;
        order.reserve(n);
        parent[0] = 0;
        order.push_back(0);
        for (size_t i = 0; i < order.size(); i++) {
            int v = order[i];
            for (int u : g[v]) {
                if (u == parent[v]) continue;
                parent[u] = v;
                depth[u] = depth[v] + 1;
                order.push_back(u);
            }
        }
        vector<int> sz(n, 1), ans(n, 0);
        long long base = 0;
        for (int i = 0; i < n; i++) base += depth[i];
        ans[0] = (int)base;
        for (int i = n - 1; i > 0; i--) sz[parent[order[i]]] += sz[order[i]];
        for (size_t i = 1; i < order.size(); i++) {
            int v = order[i];
            ans[v] = ans[parent[v]] + n - 2 * sz[v];
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def sumOfDistancesInTree(self, n: int, edges: list[list[int]]) -> list[int]:
        g = [[] for _ in range(n)]
        for a, b in edges:
            g[a].append(b)
            g[b].append(a)
        parent = [-1] * n
        depth = [0] * n
        order = [0]
        parent[0] = 0
        for v in order:
            for u in g[v]:
                if u == parent[v]:
                    continue
                parent[u] = v
                depth[u] = depth[v] + 1
                order.append(u)
        size = [1] * n
        ans = [0] * n
        ans[0] = sum(depth)
        for v in reversed(order[1:]):
            size[parent[v]] += size[v]
        for v in order[1:]:
            ans[v] = ans[parent[v]] + n - 2 * size[v]
        return ans
```

## 8. 边界情况与易错点

1. **$n = 1$**：`edges` 为空，`order = [0]`，`ans[0] = sum(depth) = 0`，循环体不执行，返回 `[0]`。
2. **$n = 2$**：`sz = [2,1]`，`ans[0] = 1`，`ans[1] = 1 + 2 - 2 = 1`，返回 `[1,1]`。
3. **链状树**：深度可达 $3\times10^4$，必须用迭代；Python 的 `for v in order:` 边遍历边 `append` 是合法的（列表迭代器会看到新元素），这是本题最简洁的 BFS 写法。
4. **`order` 构造中的父指针**：`parent[0] = 0` 且判断 `u == parent[v]`，保证不会沿父边回访；若把 `parent[0]` 留成 `-1`，根会被它的孩子重复访问。
5. **`sz` 与 `ans` 的遍历顺序不能对调**：必须先逆序累加 `sz`（后序），再正序推 `ans`（先序）；顺序错了会用到未定义的子树大小。
6. **多叉而非二叉树**：本题是任意度数的树，不能用「左孩子/右孩子」的下标技巧，必须建邻接表。
7. **答案规模**：单点答案最大约 $n^2/2 = 4.5\times10^8$，`int` 可容纳；但 `Σ depth` 与 `n - 2*sz` 的中间运算建议用 64 位，尤其是 C++ 中 `n - 2 * sz[v]` 在 `sz[v] > n/2` 时为负，与父答案相加不会溢出，但用 `long long` 更稳。
8. **数组顺序**：`ans` 与节点编号一一对应，不要按 DFS 顺序输出。
