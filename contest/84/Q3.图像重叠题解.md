# LeetCode 图像重叠 题解

## 1. 题目概述

- **标题 / 题号**：图像重叠（#835，medium）
- **链接**：https://leetcode.cn/problems/image-overlap/
- **来源**：LeetCode 第 84 场周赛 Q3
- **难度**：中等
- **标签**：数组、矩阵

**题意**：给定两个 $n \times n$ 的二进制矩阵 `img1`、`img2`（元素为 0/1）。可以把其中一张图向**上、下、左、右**平移任意单位后叠在另一张上，移出边界的 `1` 会被丢弃。**重叠**指两张图在同一位置**都是 1** 的位置个数。求所有平移方式中可能的最大重叠数。注意不允许旋转。

**约束**：

- $n = \text{img1.length} = \text{img1}[i]\text{.length} = \text{img2.length} = \text{img2}[i]\text{.length}$
- $1 \le n \le 30$
- $\text{img1}[i][j],\ \text{img2}[i][j] \in \{0, 1\}$

**关键信息**：平移只改变坐标、不改变点的相对结构，因此「一种平移」可以用一个**向量** $d$ 完全刻画；而重叠数只与「哪些 1 恰好对上」有关，与 0 无关。

## 2. 示例

**示例 1**

```text
输入：img1 = [[1,1,0],[0,1,0],[0,1,0]], img2 = [[0,0,0],[0,1,1],[0,0,1]]
输出：3
解释：将 img1 向右 1 格、向下 1 格，三个 1 与 img2 的 1 全部重合。
```

**示例 2**

```text
输入：img1 = [[1]], img2 = [[1]]
输出：1
解释：n = 1 时不移动即可重叠 1。
```

**示例 3**

```text
输入：img1 = [[0]], img2 = [[0]]
输出：0
解释：没有任何 1，重叠只能是 0。
```

**示例 4（补充，单边全 1）**

```text
输入：img1 = [[1,0],[0,0]], img2 = [[0,0],[0,1]]
输出：1
解释：向右 1 格、向下 1 格后两个 1 重合。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有平移向量。行偏移 $dr$ 与列偏移 $dc$ 各自落在 $[-(n-1), n-1]$，共 $(2n-1)^2$ 种；对每种平移，双层循环检查 $n^2$ 个位置并统计「双方都是 1」的个数：

```text
best = 0
for dr in -(n-1) .. n-1:
  for dc in -(n-1) .. n-1:
      cnt = 0
      for r in 0 .. n-1:
        for c in 0 .. n-1:
            if img1[r][c] == 1 且 0 <= r+dr < n 且 0 <= c+dc < n 且 img2[r+dr][c+dc] == 1:
                cnt += 1
      best = max(best, cnt)
```

复杂度 $O(n^4)$：$n = 30$ 时 $(2n-1)^2 n^2 \approx 3.1 \times 10^6$，**其实能过**。但其中绝大多数乘法都花在 0 上——两个 0 重合不计分，全 0 的平移完全是浪费。

### 3.2 核心观察：只有「1 对上 1」才产生重叠

![平移 = 给每个 1 加上同一个向量 d](images/wc84_q3_offset.svg)

把 `img1` 中所有 1 的坐标记为集合 $A$，`img2` 中所有 1 的坐标记为集合 $B$。平移 $d$ 后的重叠数就是

$$\mathrm{overlap}(d) = \#\{\,p \in A : p + d \in B\,\}$$

如果 $\mathrm{overlap}(d) > 0$，说明存在 $p \in A$ 使 $q = p + d \in B$，于是

$$d = q - p$$

也就是说：**任何产生正重叠的平移，都必然等于某个「$B$ 的 1 减去 $A$ 的 1」**。反过来，对每一对 $(p, q) \in A \times B$，向量 $q - p$ 都是一个「值得检查」的平移：在这个平移下 $p$ 恰好落到 $q$ 上。

于是把问题转成**计数**：

![枚举 1 对，把平移向量计数](images/wc84_q3_offset_count.svg)

- 枚举所有 $p \in A$、$q \in B$，计算 $d = q - p$，令 $\mathrm{cnt}[d] += 1$；
- 对每个 $d$，$\mathrm{cnt}[d]$ 恰好等于平移 $d$ 时的重叠数（每对重合贡献 1）；
- 答案就是 $\max_d \mathrm{cnt}[d]$（若 $A$ 或 $B$ 为空，答案为 0）。

枚举量从 $(2n-1)^2 \cdot n^2$ 降到 $|A| \cdot |B| \le n^4/16$，$n = 30$ 时最多 $8.1\times10^5$ 对，且每对只做一次哈希计数。

### 3.3 算法流程

```text
1. 收集 A = {(r,c) : img1[r][c] == 1}，B = {(r,c) : img2[r][c] == 1}
2. cnt = 空哈希表，best = 0
3. for p in A:
       for q in B:
           d = (q.r − p.r, q.c − p.c)
           cnt[d] += 1
           best = max(best, cnt[d])
4. 返回 best
```

### 3.4 示例演算

![示例演算：最大频次就是答案 3](images/wc84_q3_walkthrough.svg)

示例 1 中 $A = \{(0,0),(0,1),(1,1),(2,1)\}$，$B = \{(1,1),(1,2),(2,2)\}$，逐对计算 $d = q - p$：

| $p \in A$ | $q \in B$ | $d = q - p$ | 该 $d$ 的累计频次 |
|-----------|-----------|-------------|--------------------|
| (0,0) | (1,1) | (1,1) | 1 |
| (0,1) | (1,2) | (1,1) | 2 |
| (1,1) | (2,2) | (1,1) | **3** |
| (0,0) | (2,2) | (2,2) | 1 |
| (2,1) | (2,2) | (0,1) | 1 |
| (1,1) | (1,2) | (0,1) | 2 |
| 其余组合 | | 各不相同 | 1 |

最大频次为 3，对应 $d = (1,1)$，即把 `img1` 的每个 1 都加上 $(1,1)$——向右 1 格、向下 1 格，与示例解释一致。

## 4. 算法细节

1. **坐标表示**：`pair<int,int>` 或编码成整数 $r \cdot 64 + c$（$n \le 30$，乘 64 足够且不冲突）都能作为哈希键；C++ 用 `map<pair<int,int>,int>` 无需自定义哈希，$8\times10^5$ 次插入也很快。
2. **`d` 的方向**：$d = q - p$ 正是「让 $A$ 的点 $p$ 落到 $B$ 的点 $q$ 上」所需的位移，因此 `cnt[d]` 直接就是「把 `img1` 平移 $d$」时的重叠数。若反过来写成 $p - q$，答案不变（最大频次对取负封闭），但语义会变成「把 `img2` 平移 $-d$」，讲题时容易自相矛盾。
3. **不需要显式处理越界**：$d$ 只由 $A$、$B$ 内部的点相减得到，$p + d = q \in B$ 必然落在图内，因此枚举出的每个 $d$ 天然合法，不必判边界。
4. **即时更新 `best`**：每累加一次就比较一次，省去最后遍历哈希表；`cnt[d]` 只会增加，故 `best` 单调不减。
5. **空集处理**：$A$ 或 $B$ 为空时循环不执行，`best` 保持 0，正好是正确答案。
6. **不要去重**：$A$、$B$ 是集合语义，但每个 1 只出现一次，收集时天然无重复。

## 5. 正确性证明

**约定**：$A$、$B$ 分别是 `img1`、`img2` 中值为 1 的坐标集合。对向量 $d$，记

$$\mathrm{overlap}(d) = \#\{\,p \in A : p + d \in B\,\}$$

即「把 `img1` 平移 $d$ 后的重叠数」；再记 $c(d) = \#\{(p,q) \in A \times B : q - p = d\}$，即算法统计的频次。

**引理 1（正重叠的平移必来自某对 1）**：若 $\mathrm{overlap}(d) > 0$，则存在 $p \in A$、$q \in B$ 使 $d = q - p$。

**证明**：$\mathrm{overlap}(d) > 0$ 表示存在 $p \in A$ 满足 $p + d \in B$。令 $q = p + d$，则 $q \in B$ 且 $d = q - p$。∎

**引理 2（频次等于重叠数）**：对任意向量 $d$，$c(d) = \mathrm{overlap}(d)$。

**证明**：定义映射 $\varphi: \{(p,q) \in A \times B : q - p = d\} \to \{p \in A : p + d \in B\}$，$\varphi(p,q) = p$。
（像在目标集内）若 $q - p = d$，则 $q = p + d \in B$，故 $p + d \in B$。
（单射）若 $\varphi(p_1,q_1) = \varphi(p_2,q_2)$，则 $p_1 = p_2$，再由 $q = p + d$ 得 $q_1 = q_2$。
（满射）对任意满足 $p + d \in B$ 的 $p$，取 $q = p + d$，则 $(p,q) \in A \times B$ 且 $q - p = d$，是 $p$ 的原像。
故 $\varphi$ 是双射，两侧基数相等；右侧正是 $\mathrm{overlap}(d)$。∎

**定理**：算法返回值等于所有平移方式下的最大重叠数 $\max_d \mathrm{overlap}(d)$。

**证明**：记 $M = \max_d \mathrm{overlap}(d)$。
若 $M = 0$：任何平移的重叠数都是 0，算法中 `best` 初值为 0，且每次 `max` 都不会把它降下来，返回 0 $= M$。
若 $M > 0$：设 $d^*$ 取到 $M$。由引理 1，存在 $p \in A, q \in B$ 使 $d^* = q - p$，故 $d^*$ 会在双重循环中被枚举到；由引理 2，此时 $\mathrm{cnt}[d^*] = \mathrm{overlap}(d^*) = M$，于是 `best` $\ge M$。另一方面，任何一个被枚举的 $d$ 都对应一个真实平移，由引理 2 有 $\mathrm{cnt}[d] = \mathrm{overlap}(d) \le M$，故 `best` $\le M$。夹逼得 `best` $= M$。∎

## 6. 复杂度分析

- **时间**：$O(|A| \cdot |B| \cdot \log(|A||B|))$（用平衡树 `map`）或期望 $O(|A||B|)$（用哈希表）。$|A|, |B| \le n^2 \le 900$，最坏约 $8.1\times10^5$ 对。收集坐标 $O(n^2)$。
- **空间**：$O(|A||B|)$ 个不同平移向量（最坏 $8.1\times10^5$ 项），加上 $O(n^2)$ 的坐标表。若改用「按 $n^2$ 个平移暴力求交」则空间只需 $O(n^2)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int largestOverlap(vector<vector<int>>& img1, vector<vector<int>>& img2) {
        int n = img1.size();
        vector<pair<int, int>> a, b;
        for (int i = 0; i < n; i++)
            for (int j = 0; j < n; j++) {
                if (img1[i][j]) a.push_back({i, j});
                if (img2[i][j]) b.push_back({i, j});
            }
        map<pair<int, int>, int> cnt;
        int best = 0;
        for (auto& p : a)
            for (auto& q : b) {
                pair<int, int> d = {p.first - q.first, p.second - q.second};
                best = max(best, ++cnt[d]);
            }
        return best;
    }
};
```

### Python

```python
class Solution:
    def largestOverlap(self, img1: list[list[int]], img2: list[list[int]]) -> int:
        n = len(img1)
        a = [(i, j) for i in range(n) for j in range(n) if img1[i][j]]
        b = [(i, j) for i in range(n) for j in range(n) if img2[i][j]]
        cnt = {}
        best = 0
        for r1, c1 in a:
            for r2, c2 in b:
                d = (r1 - r2, c1 - c2)
                cnt[d] = cnt.get(d, 0) + 1
                if cnt[d] > best:
                    best = cnt[d]
        return best
```

## 8. 边界情况与易错点

1. **全 0 图**：$A$ 或 $B$ 为空，一轮循环都不执行，返回 0（示例 3）。
2. **$n = 1$**：只有 $(0,0)$ 一个位置，两张图都是 1 时返回 1，否则返回 0。
3. **`d` 的符号写反**：$d = p - q$ 与 $d = q - p$ 统计出的频次分布互为镜像，**最大值不变**，所以本题不影响答案；但若题目要求输出「移动几个单位」，必须先确认方向。
4. **平移可以为 0**：$d = (0,0)$ 是合法的「不移动」，不要漏掉；它对应 $p = q$ 的那些对。
5. **越界无需特判**：$d$ 由同图内的点相减得到，$p + d$ 必在图内；只有「按全部偏移枚举」的写法才需要判边界。
6. **不要旋转**：题目明确排除旋转，所以只有平移，向量模型成立；若允许旋转，坐标变换不再只差一个常向量，需转为枚举旋转角度。
7. **复杂度的直觉陷阱**：$n^4$ 的暴力在 $n = 30$ 时是 $3\times10^6$ 量级，其实能过；面试或复盘时应说明「为什么 $O(n^4)$ 可过，而 $O(|A||B|)$ 更好」——后者只统计有效对，常数与稀疏度相关。
8. **哈希键冲突**：若把 $(r,c)$ 压成 $r \cdot n + c$，取 $n$ 会被不同点共享（如 $n=3$ 时 $(1,0)$ 与 $(0,3)$ 冲突，虽然 $c < n$ 时不会发生）；用 `pair` 或乘 $n+1$ 更稳妥。
