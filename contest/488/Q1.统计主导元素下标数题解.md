# LeetCode 统计主导元素下标数 题解

## 1. 题目概述

- **标题 / 题号**：统计主导元素下标数（#3833，easy）
- **链接**：https://leetcode.cn/problems/count-dominant-indices/
- **来源**：LeetCode 第 488 场周赛 Q1
- **难度**：简单
- **标签**：数组、枚举、后缀和

**题意**：给定长度为 $n$ 的整数数组 `nums`。若下标 $i$ 满足

$$nums[i] > average(nums[i+1],\ nums[i+2],\ \ldots,\ nums[n-1])$$

即 $nums[i]$ **严格大于其右侧所有元素的平均值**，则称 $i$ 为主导下标。统计数组中主导下标的个数。数组的**最右侧元素**右侧为空，不算主导下标。

**约束**：

- $1 \le nums.length \le 100$
- $1 \le nums[i] \le 100$

> 💡 **审题关键**：① 平均的对象是**右侧后缀** $nums[i+1..n-1]$——不是前缀、不是整个数组，方向别搞反；② 是**严格大于**，恰好等于平均值不计（$[7,7,7]$ 答案为 0）；③ 最右元素天然豁免，$n = 1$ 时答案为 0；④ $n \le 100$，$O(n^2)$ 暴力稳过——Q1 的目标是**快速写对**，而「一遍扫描」的 $O(n)$ 写法代码量完全相同，顺手养成。

## 2. 示例

**示例 1**

```text
输入：nums = [5, 4, 3]
输出：2
解释：
- i = 0：5 > average(4, 3) = 3.5，是主导下标；
- i = 1：4 > average(3) = 3，是主导下标；
- i = 2：右侧为空，不计。答案为 2。
```

**示例 2**

```text
输入：nums = [4, 1, 2]
输出：1
解释：
- i = 0：4 > average(1, 2) = 1.5，是主导下标；
- i = 1：1 > average(2) = 2 不成立；
- i = 2：右侧为空，不计。答案为 1。
```

**示例 3（边界自造）**

```text
输入：nums = [7, 7, 7]
输出：0
解释：i = 1 时 7 > 7 不成立；i = 0 时 7 > 7 不成立——严格大于语义下全等数组答案为 0。
```

## 3. 解题思路

### 3.1 暴力思路：逐下标重算右侧平均

对每个 $0 \le i \le n-2$，内层重扫 $i+1 \ldots n-1$ 求和、除以个数、与 $nums[i]$ 比较，$O(n^2)$ 时间。$n \le 100$ 时至多约 $5000$ 次加法，稳过。

但存在明显的重复劳动：$i$ 每左移一格，右侧判定区间从 $[i+2, n-1]$ 变成 $[i+1, n-1]$，**恰好只多出一个元素** $nums[i+1]$——和却每次从头加起。

### 3.2 核心观察：从右往左一遍扫，增量维护右侧和

![核心观察：从右往左攒右侧和，交叉相乘整数判定主导](images/wc488_q1_suffix_sum_concept.svg)

判定下标 $i$ 只需要两个量：

- $s = nums[i+1] + nums[i+2] + \cdots + nums[n-1]$（右侧区间和）；
- $cnt = n - 1 - i$（右侧元素个数）。

这两个量随 $i$ 左移**单调增量变化**：让 $i$ 从 $n-2$ 递减到 $0$，进入下标 $i$ 时执行 $s \mathrel{+}= nums[i+1]$，$s$ 即为当前右侧区间和——**不需要显式的后缀和数组**，一个变量足矣，任意下标的判定降为 $O(1)$。

第二个细节是判定式的数值稳定性：直接写 $nums[i] > s / cnt$ 会引入浮点（$s / cnt$ 可能是 $1/3$ 这类循环小数，浮点比较在边界情形可能翻车）。**交叉相乘**消掉除法：

$$nums[i] > \frac{s}{cnt} \iff nums[i] \times cnt > s \qquad (cnt \ge 1)$$

两侧均为整数，比较精确无舍入。本题乘积上界 $100 \times 100 = 10^4$，`int` 轻松装下；约束放大到 $10^5 \times 10^9$ 时换 `long long` 即可（Python 天然大整数）。

### 3.3 算法流程

![算法流程：一遍从右往左扫描，入帐、交叉相乘判定、计数、左移](images/wc488_q1_algorithm_flow.svg)

| 步骤 | 操作 | 说明 |
|------|------|------|
| ① 初始化 | `ans = 0, s = 0, i = n-2` | 最右元素天然豁免，从 $n-2$ 起步 |
| ② 入帐 | `s += nums[i+1]` | 刚跨过的元素并入右侧和；$cnt = n-1-i$ 免单独维护 |
| ③ 判定 | `nums[i] * (n-1-i) > s` ? | 交叉相乘，纯整数比较 |
| ④ 计数 | 成立则 `ans++` | 下标 $i$ 为主导下标 |
| ⑤ 左移 | `i--`，回到 ② | 直到 $i < 0$ |
| ⑥ 返回 | `return ans` | $n = 1$ 时循环不执行，返回 0 |

### 3.4 示例演算

![示例演算：两个官方示例的从右往左走查表](images/wc488_q1_example_walkthrough.svg)

**示例 1** `nums = [5,4,3]`（从右往左）：

- $i=1$：先 $s \mathrel{+}= nums[2] = 3$ 得 $s = 3$，判 $4 \times 1 = 4 > 3$ ✓ 计数；
- $i=0$：再 $s \mathrel{+}= nums[1] = 4$ 得 $s = 7$，判 $5 \times 2 = 10 > 7$ ✓ 计数；
- 循环结束，`ans = 2` ✓。

**示例 2** `nums = [4,1,2]`：

- $i=1$：$s = 2$，判 $1 \times 1 = 1 > 2$ ✗；
- $i=0$：$s = 2 + 1 = 3$，判 $4 \times 2 = 8 > 3$ ✓ 计数；
- `ans = 1` ✓。

## 4. 算法细节

1. **扫描方向**：从右往左把「攒和」与「判定」合并进同一趟循环，空间 $O(1)$；若从左往右，须先花 $O(n)$ 空间预计算后缀和数组 $suf[i]$ 再正扫判定——两者等价，前者更省。
2. **$cnt$ 不设变量**：用表达式 $n-1-i$ 现算，它就是「下标 $i$ 右侧的元素个数」，语义自明，还省一次维护。
3. **循环起点 $n-2$**：最右元素的豁免不需要任何 `if` 特判——直接不进循环；$n = 1$ 时循环体一次不执行，自然返回 0。
4. **交叉相乘的合法性**：进循环必有 $i \le n-2$，故 $cnt = n-1-i \ge 1$，不等式两边同乘正数保序，等价性严格成立。
5. **溢出评估**：本题 $nums[i] \times cnt \le 100 \times 99 < 10^4$；推广到 $n \le 10^5$、$nums[i] \le 10^9$ 时上界约 $10^{14}$，C++ 需 `long long`，Python 无需处理。

## 5. 正确性证明

**引理 1（判定等价）**：对 $cnt \ge 1$，有 $nums[i] > s / cnt \iff nums[i] \times cnt > s$。

**证明**：$cnt \ge 1 > 0$，不等式两边同乘正数 $cnt$ 不改变方向，得 $nums[i] \times cnt > s$；该变换每一步可逆，故为等价。∎

**引理 2（增量不变式）**：算法从 $i = n-2$ 起递减，判定下标 $i$ 之前刚执行 $s \mathrel{+}= nums[i+1]$，则此时 $s = \sum_{j=i+1}^{n-1} nums[j]$。

**证明**：对 $i$ 归纳。奠基 $i = n-2$：$s$ 初值为 0（空区间之和），入帐后 $s = nums[n-1]$，恰为 $nums[(n-2)+1..n-1]$ 之和。归纳步：设判定 $i+1$ 前有 $s = \sum_{j=i+2}^{n-1} nums[j]$；则判定 $i$ 前执行 $s \mathrel{+}= nums[i+1]$，得 $s = \sum_{j=i+1}^{n-1} nums[j]$。∎

**定理**：算法返回值等于主导下标的个数。

**证明**：对任意 $0 \le i \le n-2$：由引理 2，判定时 $s$ 恰为右侧区间和、$cnt = n-1-i$ 恰为右侧元素个数；由引理 1，判定条件 $nums[i] \times cnt > s$ 与主导定义 $nums[i] > average(nums[i+1..n-1])$ 逻辑等价（严格大于，等于被排除）。$i = n-1$ 不进循环，与「最右元素不算主导」一致。因此每个下标恰在其为主导时被计数一次，返回值为所求。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。一遍从右往左扫描，每个下标一次加法、一次乘法、一次比较，均 $O(1)$。
- **空间复杂度**：$O(1)$。只维护 $s$ 与答案，不建后缀和数组。
- **量级对比**：暴力 $O(n^2)$ 在 $n \le 100$ 下约 $10^4$ 次运算同样能过；$O(n)$ 版本的意义在于**模式可迁移**——约束放大千倍依然线性通过。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int dominantIndices(vector<int>& nums) {
        int n = nums.size(), ans = 0;
        long long s = 0;                               // s = nums[i+1..n-1] 之和
        for (int i = n - 2; i >= 0; i--) {             // 最右元素不算主导
            s += nums[i + 1];                          // 刚跨过的元素入帐
            if ((long long)nums[i] * (n - 1 - i) > s)  // 交叉相乘，零浮点
                ans++;
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def dominantIndices(self, nums: list[int]) -> int:
        n, ans, s = len(nums), 0, 0
        for i in range(n - 2, -1, -1):        # 最右元素不算主导
            s += nums[i + 1]                  # 刚跨过的元素入帐
            if nums[i] * (n - 1 - i) > s:     # 交叉相乘，零浮点
                ans += 1
        return ans
```

> 💡 也可正扫 + 显式后缀和数组（$O(n)$ 空间），或 $O(n^2)$ 暴力（本题也能过）；「从右往左 + 一个变量 + 交叉相乘」是最短、最不易错的形态。

## 8. 边界情况与易错点

1. **最右元素豁免**：右侧为空、平均值无定义——循环从 $n-2$ 起步即可，无需 `if` 特判；$n = 1$ 时返回 0。
2. **严格大于**：$[7,7,7]$ 答案为 0，把 `>` 误写成 `>=` 会得到 2——读题时圈出「大于」是否带「严格」。
3. **浮点陷阱**：$s / cnt$ 可能是循环小数（如 $7/3$），浮点比较在「恰等于平均值」的边界可能翻车且行为随平台而异；交叉相乘后全程整数运算。
4. **方向搞反**：平均的是**右侧**后缀，不是左侧前缀——$[5,4,3]$ 答案 2，反转成 $[3,4,5]$ 答案 0。
5. **分母为零**：只在最右元素处出现，已被循环起点排除，判定式中 $cnt \ge 1$ 恒成立。
6. **溢出**：本题乘积上界 $10^4$，`int` 足够；若约束放大（$n \le 10^5$、值 $10^9$），C++ 记得 `long long`。
