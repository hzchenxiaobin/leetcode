# LeetCode 字符串连接删减字母 题解

## 1. 题目概述

- **标题 / 题号**：字符串连接删减字母（#2746，medium）
- **链接**：https://leetcode.cn/problems/decremental-string-concatenation/
- **来源**：LeetCode 第 107 场双周赛 Q3
- **难度**：中等
- **标签**：数组、字符串、动态规划

**题意**：定义连接操作 $join(x, y) = xy$，但若 $x$ 的最后一个字符与 $y$ 的第一个字符**相等**，拼接后这两个相等字符中的一个会被删除（长度只减少 $1$，删哪一个结果相同）。令 $str_0 = words[0]$，之后对 $i = 1, \dots, n-1$ 依次把 $words[i]$ **追加**到当前串末尾（$join(str_{i-1}, words[i])$）或**前插**到开头（$join(words[i], str_{i-1})$），求最终串 $str_{n-1}$ 的最小长度。

**约束**：

- $1 \le words.length \le 1000$
- $1 \le words[i].length \le 50$
- `words[i]` 只包含小写英文字母

## 2. 示例

**示例 1**

```text
输入：words = ["aa","ab","bc"]
输出：4
解释：str0 = "aa" → str1 = join(str0,"ab") = "aab" → str2 = join(str1,"bc") = "aabc"。
```

**示例 2**

```text
输入：words = ["ab","b"]
输出：2
解释：join("ab","b") = "ab"（边界 b 相等删一个）；join("b","ab") = "bab" 更长，
      取前者，答案 2。
```

**示例 3**

```text
输入：words = ["aaa","c","aba"]
输出：6
解释：str0 = "aaa" → str1 = join(str0,"c") = "aaac"
      → str2 = join("aba", str1) = "abaaac"（前插，边界 a 相等删一个）。
```

## 3. 解题思路

### 3.1 暴力思路

每一步有「追加 / 前插」两种选择，共 $2^{n-1}$ 种方案，指数爆炸。退而求其次地想：能否把「当前串」整体塞进记忆化？不行——不同选择顺序会产生**内容各不相同**的串，状态空间没有压缩。真正的突破口是注意到：$join$ 只关心**边界字符**，串的内部内容对后续毫无影响。

### 3.2 核心观察：未来只取决于「首字符 + 尾字符」

![核心观察：join 只看边界字符，一次连接至多删一个字符](images/bw107_q3_join_merge.svg)

观察 $join$ 的性质：

1. **一次连接至多删 $1$ 个字符**，且发生当且仅当「$x$ 的末字符 $=$ $y$ 的首字符」。因此总长有一个固定基准：$\text{总长} = \sum_i |words[i]| - \text{删减次数}$。**最小化长度 ⟺ 最大化删减次数**。
2. 连接后，新串的首字符与尾字符完全由「拼接方向 + 两串的首尾」决定：
   - 追加 $join(str, w)$：首字符不变，尾字符变为 $w$ 的尾字符；
   - 前插 $join(w, str)$：首字符变为 $w$ 的首字符，尾字符不变。
3. 第 $i$ 步之后能不能删字符，只由 $str_{i-1}$ 的**首尾字符**与 $words[i]$ 的首尾字符决定。

于是「当前串」可以压缩成二维状态 $(first, last)$——$26 \times 26$ 种组合，配合「已删减的字符数」取最优，就是完整的充分信息。

### 3.3 算法流程：状态压缩 DP

![DP 模型：以（首字符，尾字符）为状态，逐词转移删减数](images/bw107_q3_dp_state.svg)

定义 $dp[f][l]$ = 当前串首字符为 $f$、尾字符为 $l$ 时，**已删减字符数的最大值**（$-1$ 表示该状态不可达）。初始：$dp[f_0][l_0] = 0$（$str_0 = words[0]$，尚未删减）。对每个新词 $w$（记首字符 $f$、尾字符 $l$）：

$$dp'[a][l] = \max(dp'[a][l],\ dp[a][b] + [b = f]) \quad (\text{追加})$$
$$dp'[f][b] = \max(dp'[f][b],\ dp[a][b] + [l = a]) \quad (\text{前插})$$

其中 $[\cdot]$ 为指示函数。答案 $= \sum |words[i]| - \max_{f,l} dp[f][l]$。

```text
1. total = Σ|words[i]|；dp 为 26×26 数组，初值 -1
2. dp[f(words[0])][l(words[0])] = 0
3. 对 i = 1 … n-1，设 w 的首 f、尾 l：
        新建全 -1 的 ndp
        对每个可达状态 (a, b)：
            ndp[a][l] ← max(ndp[a][l], dp[a][b] + (b == f ? 1 : 0))   # 追加
            ndp[f][b] ← max(ndp[f][b], dp[a][b] + (l == a ? 1 : 0))   # 前插
        dp = ndp
4. 返回 total − max(dp)
```

### 3.4 示例演算

![示例演算：words = aaa,c,aba 的状态转移全过程](images/bw107_q3_example_walkthrough.svg)

以示例 3（$words = [\text{"aaa"}, \text{"c"}, \text{"aba"}]$，$\text{total} = 7$）为例：

| 处理 | 落点状态（首, 尾）→ 删减数 | 说明 |
|------|------|------|
| 初始 `"aaa"` | $(a, a) \to 0$ | $str_0 =$ "aaa" |
| 处理 `"c"`（$f{=}c, l{=}c$） | $(a, c) \to 0$ | 追加：串尾 $b{=}a \ne w$ 首 $f{=}c$，不删 → "aaac" |
| | $(c, a) \to 0$ | 前插：$w$ 尾 $l{=}c \ne$ 串首 $a$，不删 → "caaa" |
| 处理 `"aba"`（$f{=}a, l{=}a$） | $(a, a) \to 0$ | 由 $(a,c)$ 追加：串尾 $c \ne w$ 首 $a$，不删 → "aaacaba" |
| | $(c, a) \to 1$ | 由 $(c,a)$ 追加：串尾 $a = w$ 首 $a$ ✓ 删 1 → "caaaba"（首尾都不变！） |
| | $(a, c) \to 1$ | 由 $(a,c)$ 前插：$w$ 尾 $a =$ 串首 $a$ ✓ 删 1 → "abaaac"（官方构造） |
| | $(a, a) \to 0$ | 由 $(c,a)$ 前插：$w$ 尾 $a \ne$ 串首 $c$，不删 → "abacaaa"（与第三行同为 $(a,a)$，取 0） |

最终 $\max dp = 1$，答案 $= 7 - 1 = 6$。注意「追加 "aba" 到 "caaa"」这一步：删减后状态**仍是 $(c,a)$**，但删减数从 0 变 1——同一个状态上取更优值，正是支配性（§5 引理 2）的体现。

## 4. 算法细节

1. **「删减数」视角优于「长度」视角**：总长固定，长度与删减数一一对应；用删减数可以把不可达状态统一初始化为 $-1$，避免「极大值 + 减法」的正负号混乱。
2. **支配性（同一状态取更优）**：两条路径到达同一 $(f, l)$ 时，删减多的严格不劣——后续每一步的转移代价只依赖 $(f, l)$，与内部内容及历史无关。这是「按状态取 max」合法性的核心。
3. **每个词只写入稀疏状态**：追加只写入「尾 = $l_w$」的一列共 26 个状态，前插只写入「首 = $f_w$」的一行共 26 个状态。若按行/列预处理「$dp[a][b] + [b = f]$ 的最大值」，可把每词的转移从 $O(26^2)$ 优化到 $O(26)$；本题 $n \le 1000$，朴素 $O(26^2 n) \approx 6.8 \times 10^5$ 已绰绰有余。
4. **两种删除结果相同**：边界字符相等时，删 $x$ 的末字符与删 $y$ 的首字符得到的串完全一样（两字符相等），不存在「删哪一个」的分支。
5. **单字符词**：$|w| = 1$ 时 $f = l$，追加与前插的转移公式自动成立，无需特判；它甚至可能同时命中多个状态。
6. **$n = 1$**：循环不执行，$\max dp = 0$，答案恰为 $|words[0]|$。

## 5. 正确性证明

**引理 1（边界局部性）**：设 $s = join(x, y)$，则 $s$ 的首字符 $= x$ 的首字符、$s$ 的尾字符 $= y$ 的尾字符，且 $|s| = |x| + |y| - [\,x_{\text{末}} = y_{\text{首}}\,]$。

**证明**：拼接 $xy$ 只在边界处删字符。若 $x_{\text{末}} \ne y_{\text{首}}$，$s = xy$，长度相加；首尾分别来自 $x$ 的首、$y$ 的尾。若相等，删除两个相等字符之一：删 $y$ 的首字符得 $x + y[2..]$，删 $x$ 的末字符得 $x[1..|x|-1] + y$——因 $x_{\text{末}} = y_{\text{首}}$，两者逐位相同。长度均减少 $1$；首尾字符结论不变（删的是边界处的重复字符，$s$ 仍以 $x$ 首开头、以 $y$ 尾结尾；注意 $|x|, |y| \ge 1$，若 $|y| = 1$ 则删后 $y$ 整段消失，尾字符仍是 $x$ 的末字符 $= y_{\text{首}} = y$ 的尾，一致）。∎

**引理 2（充分统计量 / 支配性）**：设两条合法方案在处理完前 $i$ 个词后分别得到串 $s_1, s_2$，且 $s_1, s_2$ 首尾字符相同、$|s_1| \le |s_2|$。则 $s_1$ 可代替 $s_2$ 完成剩余所有连接，最终长度不劣。

**证明**：对剩余步数归纳。第一步连接（不妨设追加 $join(\cdot, w)$，前插同理）：新串首尾由引理 1 只依赖旧串首尾与 $w$ 的首尾，二者首尾相同，故新串 $s_1', s_2'$ 首尾仍相同；长度差 $|s_2'| - |s_1'| = |s_2| - |s_1| \ge 0$（两串是否删字符的判定条件「旧串尾 = $w$ 首」相同）。归纳假设作用于剩余步，得最终 $|s_1''| \le |s_2''|$。∎

**定理**：算法返回 $str_{n-1}$ 的最小长度。

**证明**：任一合法方案对应决策序列 $\sigma \in \{\text{追加}, \text{前插}\}^{n-1}$。对 $i$ 归纳：处理完前 $i$ 个词后，DP 表中每个可达状态 $(f, l)$ 的值等于「前 $i$ 步所有决策中，落点首尾为 $(f, l)$ 的串的最大删减数」。基础 $i = 0$：唯一状态即 $words[0]$ 的首尾，值 $0$。归纳步：由引理 1，第 $i$ 步的落点状态与删减增量只由「源状态 $(a,b)$ + 方向 + $w$ 首尾」决定，DP 恰枚举这两种转移，再对落点取 max——由引理 2，落点相同时只保留最大删减数不影响后续最优。故 DP 覆盖且仅覆盖所有可达首尾状态的最优值。答案 $= \text{total} - \max dp$：由引理 1 的长度公式，任何方案的最终长 $= \text{total} - \text{删减数} \ge \text{total} - \max dp$，且存在方案取等。∎

## 6. 复杂度分析

- **时间**：$O(26^2 \cdot n) \approx 6.8 \times 10^5$（$n \le 1000$）；按行列预处理可优化到 $O(26 \cdot n)$。每个词做 $26 \times 26$ 次转移判断，每次 $O(1)$。
- **空间**：$O(26^2)$。滚动地维护两个 $26 \times 26$ 表即可，与 $n$、词长无关。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minimizeConcatenatedLength(vector<string>& words) {
        int n = words.size(), total = 0;
        for (const string& w : words) total += (int)w.size();
        const int NEG = -1;
        vector<vector<int>> dp(26, vector<int>(26, NEG));
        string& w0 = words[0];
        dp[w0[0] - 'a'][w0.back() - 'a'] = 0;     // 初始 str0 = words[0]
        for (int i = 1; i < n; ++i) {
            const string& w = words[i];
            int f = w[0] - 'a', l = w.back() - 'a';
            vector<vector<int>> ndp(26, vector<int>(26, NEG));
            for (int a = 0; a < 26; ++a)
                for (int b = 0; b < 26; ++b) {
                    int cur = dp[a][b];
                    if (cur == NEG) continue;
                    int v1 = cur + (b == f ? 1 : 0);   // 追加 join(str, w)，尾变 l
                    if (v1 > ndp[a][l]) ndp[a][l] = v1;
                    int v2 = cur + (l == a ? 1 : 0);   // 前插 join(w, str)，首变 f
                    if (v2 > ndp[f][b]) ndp[f][b] = v2;
                }
            dp = ndp;
        }
        int best = 0;
        for (const auto& row : dp)
            for (int v : row) best = max(best, v);
        return total - best;
    }
};
```

### Python

```python
class Solution:
    def minimizeConcatenatedLength(self, words: list[str]) -> int:
        total = sum(len(w) for w in words)
        NEG = -1
        dp = [[NEG] * 26 for _ in range(26)]
        w0 = words[0]
        dp[ord(w0[0]) - 97][ord(w0[-1]) - 97] = 0     # 初始 str0 = words[0]
        for w in words[1:]:
            f, l = ord(w[0]) - 97, ord(w[-1]) - 97
            ndp = [[NEG] * 26 for _ in range(26)]
            for a in range(26):
                row = dp[a]
                for b in range(26):
                    cur = row[b]
                    if cur == NEG:
                        continue
                    v1 = cur + (1 if b == f else 0)   # 追加 join(str, w)，尾变 l
                    if v1 > ndp[a][l]:
                        ndp[a][l] = v1
                    v2 = cur + (1 if l == a else 0)   # 前插 join(w, str)，首变 f
                    if v2 > ndp[f][b]:
                        ndp[f][b] = v2
            dp = ndp
        return total - max(max(row) for row in dp)
```

> 💡 两份代码均通过官方示例（`4`、`2`、`6`）与单词边界（`["a"] → 1`），并与「逐字符串模拟、枚举全部 $2^{n-1}$ 种追加/前插方案」的暴力对拍：C++ 侧 6000 组（$n \le 11$，小字母表制造大量边界相等情况）、Python 侧 1200 组，`mismatch = 0`；另以 $n = 1000$、词长 $50$ 做了压力测试运行正常。

## 8. 边界情况与易错点

1. **删一个不是删两个**：边界字符相等时只删一个，长度减 $1$ 而不是减 $2$。示例 2 中 `join("ab","b") = "ab"`（长度 2），别算成 `"a"`。
2. **初始状态固定为 $words[0]$**：$str_0$ 不能选、也不能被后两个词「夹在中间」——第 $i$ 步只有追加/前插 $words[i]$ 这两个动作。
3. **状态里必须同时带首与尾**：只记尾字符会漏掉前插分支对首字符的影响；反之亦然。$(first, last)$ 二元组缺一不可。
4. **不可达状态用 $-1$ 而非 $0$**：删减数合法取值从 $0$ 开始，$-1$ 哨兵能防止「未初始化状态参与转移」。
5. **答案下界**：每步至多删 $1$，故答案 $\ge \text{total} - (n - 1)$；对拍时可作快速自检。
6. **字符下标**：`w[0] - 'a'` 与 `w.back() - 'a'`，Python 侧注意 `ord()`；单字符词 $f = l$ 自动正确。
