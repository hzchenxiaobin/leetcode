# LeetCode 构造最长的新字符串 题解

## 1. 题目概述

- **标题 / 题号**：构造最长的新字符串（#2745，medium）
- **链接**：https://leetcode.cn/problems/construct-the-longest-new-string/
- **来源**：LeetCode 第 107 场双周赛 Q2
- **难度**：中等
- **标签**：贪心、脑筋急转弯、数学、动态规划

**题意**：手里有 $x$ 个 `"AA"`、$y$ 个 `"BB"`、$z$ 个 `"AB"`（每种块都是长度为 $2$ 的字符串）。从中任选一个子集（可全选可不选），按任意顺序首尾相接拼成一个大字符串，要求结果中**不出现子串 `"AAA"` 或 `"BBB"`**。返回能拼出的最大长度。

**约束**：

- $1 \le x, y, z \le 50$

## 2. 示例

**示例 1**

```text
输入：x = 2, y = 5, z = 1
输出：12
解释：连接 "BB","AA","BB","AA","BB","AB" 得到 "BBAABBAABBAB"，
      长度 12，不存在更长的合法串。
```

**示例 2**

```text
输入：x = 3, y = 2, z = 2
输出：14
解释：连接 "AB","AB","AA","BB","AA","BB","AA" 得到 "ABABAABBAABBAA"，
      长度 14。
```

**示例 3（边界补充）**

```text
输入：x = 1, y = 1, z = 1
输出：6
解释：三块全用："AB" + "AA" + "BB" = "ABAABB"，无 AAA/BBB，长度 6。
```

## 3. 解题思路

### 3.1 暴力思路

把问题看成「从多重集合 $\{AA \times x,\ BB \times y,\ AB \times z\}$ 中选块排队，相邻两块的衔接不能产生 AAA/BBB，最大化块数（长度 = $2 \times$ 块数）」。直接 DFS 枚举每一步放哪种块是指数级；一个靠谱的暴力是**可达性 DP**：状态 $(a, b, c, last)$ 表示已用 $a$ 个 AA、$b$ 个 BB、$c$ 个 AB 且最后一块是 $last$，转移由相邻约束决定，$O(x \cdot y \cdot z \cdot 4)$ 个状态（$50^3 \times 4 \approx 5 \times 10^5$）可以过。但看穿结构后，本题其实是一个 $O(1)$ 公式题。

### 3.2 核心观察：三类块之间的「相邻约束表」

![核心观察：三类块拼接的相邻约束与 AB 链的位置](images/bw107_q2_block_adjacency.svg)

关键在于逐个检查**两块衔接处的 3 字符窗口**（拼接串内部不含 AAA/BBB，唯一可能违规的位置是衔接处，即「前块后两个字符 + 后块首字符」或「前块末字符 + 后块前两个字符」）：

| 前块 \ 后块 | AA | BB | AB |
|------|------|------|------|
| **AA** | ✗（AAA） | ✓ | ✗（AAA） |
| **BB** | ✓ | ✗（BBB） | ✓ |
| **AB** | ✓ | ✗（BBB） | ✓ |

从这张表可以读出三条结构性结论：

1. **AA 的直接后继只能是 BB**（不能接 AA 也不能接 AB）。
2. **BB 的直接后继可以是 AA 或 AB；AB 的直接后继可以是 AB 或 AA**（不能是 BB）。
3. 把所有 AB 抽掉，剩下的 AA/BB 序列**必然严格交错**：任何两个 AA 之间必有 BB（AA 之后紧跟的只能是 BB），任何两个 BB 之间必有 AA（BB 之后即便进入 AB 链，链也只能接 AA——AB 不能接 BB）。所以用 $a$ 个 AA 与 $b$ 个 BB 必须满足 $|a - b| \le 1$。
4. **AB 链（连续若干个 AB）只能出现在整个串的开头，或紧跟在某个 BB 之后**（因为 AA 后不能接 AB）；链后只能接 AA 或收尾。一条链可以任意长（AB→AB 永远合法）。

**结论**：所有 $z$ 个 AB 总能全部用上（一条链放最前或放在某个 BB 之后），而 AA/BB 的用量受「交错性」限制：$a \le x$、$b \le y$、$|a - b| \le 1$，故 $a + b \le 2\min(x, y) + [x \ne y]$。答案是

$$\text{ans} = 2z + 4\min(x, y) + \big(x \ne y\ ?\ 2 : 0\big)$$

### 3.3 算法流程：分情况构造

![构造方案：x>y、x<y、x=y 三种骨架与 AB 链的插入位置](images/bw107_q2_structure_cases.svg)

公式只是上界，还需要构造证明可达。三种情况的骨架（把 AB 链画成一条整体）：

```text
x > y（AA 是多数）：[AB…AB] + (AA BB)^y + AA      → 骨架以 AA 开头结尾
x < y（BB 是多数）：BB + [AB…AB] + (AA BB)^x + BB  → AB 链紧跟第一个 BB
x = y（数量相等）：[AB…AB] + (AA BB)^x            → 骨架以 AA 开头、BB 结尾
```

每种构造里，AB 链与相邻块的衔接（`AB|AA`、`BB|AB`）都查表合法；骨架内部本来就是 AA 与 BB 交错，衔接（`AA|BB`、`BB|AA`）也合法。于是三种情况都能取到上界，公式即答案。

### 3.4 示例演算

![示例演算：两组官方样例的构造与公式核对](images/bw107_q2_example_walkthrough.svg)

**示例 1**（$x=2, y=5, z=1$）：$\min = 2$，$x \ne y$，$\text{ans} = 2 \times 1 + 4 \times 2 + 2 = 12$。构造走「BB 是多数」分支：骨架 $BB\ AA\ BB\ AA\ BB$（3 个 BB、2 个 AA，交错且 $b = a + 1$），AB 链（1 个 AB）可以放在第一个 BB 之后（官方题解把它放在了串尾，`…BB|AB` 同样合法）：

$$BB\ AB\ AA\ BB\ AA\ BB = \text{“BBABAABBAABB”}\quad(\text{长度 } 12)$$

**示例 2**（$x=3, y=2, z=2$）：$\min = 2$，$x \ne y$，$\text{ans} = 2 \times 2 + 4 \times 2 + 2 = 14$。构造走「AA 是多数」分支：AB 链垒在最前，骨架 $AA\ BB\ AA\ BB\ AA$：

$$AB\ AB\ AA\ BB\ AA\ BB\ AA = \text{“ABABAABBAABBAA”}\quad(\text{长度 } 14)$$

## 4. 算法细节

1. **上界的三个来源**：$c \le z$（块只有这么多）、$a \le x, b \le y$、$|a - b| \le 1$（交错性）。三者相乘起来就是公式；别把 $+2$ 的条件写反——$x = y$ 时交错性允许 $a = b + 1$，但 $a = y + 1 > x$ 违反存量限制，所以 $x = y$ 时只能 $a = b$，**不加** $2$。
2. **AB 全部可用不等于随便放**：`AA|AB` 是非法衔接（拼出 `AAAB`），构造时 AB 链只能放串首或 BB 之后。常见的手滑构造「…AA BB … AA 然后尾巴上追加 AB」就会翻车。
3. **答案上界**：$2 \times 50 + 4 \times 50 + 2 = 302$，`int` 绰绰有余。
4. **z ≥ 1 保证答案至少为 2**：单独一个 `"AB"` 就是合法串；不存在输出 0 的情况。
5. **不放心公式的保底写法**：比赛时可用 $O(x y z)$ 的可达性 DP（状态 $(a, b, c, last)$，答案取可达状态的最大 $a+b+c$ 乘 2），它与公式在小规模上完全一致（本文对拍验证）。
6. **为什么不是 $2\min + 2$ 而是 $4\min + 2$**：$\min$ 数量的 AA 与 $\min$ 数量的 BB 共 $2\min$ 块，每块长 2，共 $4\min$ 个字符；多数类型再多一块贡献 2。

## 5. 正确性证明

**引理 1（相邻约束表）**：设合法串被划分为块序列 $B_1 B_2 \cdots B_k$（$B_i \in \{AA, BB, AB\}$），则相邻两块 $(B_i, B_{i+1})$ 的所有组合中，仅 $AA \to AA$、$AA \to AB$、$BB \to BB$、$AB \to BB$ 非法。

**证明**：各块内部不含 AAA/BBB；拼接串中横跨衔接处的 3 字符子串只有两个候选窗口——「$B_i$ 的后两字符 + $B_{i+1}$ 的首字符」与「$B_i$ 的末字符 + $B_{i+1}$ 的前两字符」。对 $3 \times 3 = 9$ 种组合逐一验证：$AA|AA$ 含窗口 AAA；$AA|AB$ 的前窗口为 $AAA$；$BB|BB$ 含 BBB；$AB|BB$ 的后窗口为 $BBB$；其余五种（$AA|BB$、$BB|AA$、$BB|AB$、$AB|AA$、$AB|AB$）两个窗口都不是 AAA/BBB。∎

**引理 2（AA/BB 交错性）**：合法串中去掉所有 AB 块后，AA 与 BB 严格交替，因此使用的数量 $a, b$ 满足 $|a - b| \le 1$。

**证明**：由引理 1，AA 若有后继则后继必为 BB；BB 的后继只能是 AA 或 AB，而一段 AB 链的后继只能是 AA（AB 不能接 BB）或链尾收串。故在「只看 AA/BB」的投影序列里，任何两个 AA 之间必然出现过 BB，任何两个 BB 之间必然出现过 AA，即严格交错。长度为 $k$ 的交错序列中两类元素数量之差至多为 $1$。∎

**引理 3（AB 可全用）**：对任意满足 $|a - b| \le 1$、$a, b \ge 1$ 的骨架用量，都存在合法拼接同时用满全部 $z$ 个 AB。

**证明**：构造。若骨架以 AA 开头（$a \ge b$ 时取骨架 $AA(BB\,AA)^{a-1} \cdots$ 型，交错且首块为 AA），把 $z$ 个 AB 连成一条链放在串首，衔接 $AB \to AA$ 合法（引理 1）。若骨架以 BB 开头（$a < b$，骨架为 $BB(AA\,BB)^{a} \cdots$ 型），把 AB 链放在第一个 BB 之后，衔接 $BB \to AB \to AA$ 两处均合法。∎

**定理**：最长合法串长度为 $2z + 4\min(x, y) + [x \ne y] \cdot 2$。

**证明**：**上界**：任取一个合法拼接，设其用 $a$ 个 AA、$b$ 个 BB、$c$ 个 AB，长度 $= 2(a+b+c)$。显然 $a \le x$、$b \le y$、$c \le z$；由引理 2，$|a - b| \le 1$。若 $x = y$：$a = b + 1$ 将推出 $a \ge y + 1 > x$ 矛盾，故 $a = b \le \min(x,y)$，$a + b \le 2\min(x,y)$；若 $x \ne y$：不妨 $a \ge b$，则 $a \le b + 1 \le \min(x,y) + 1$，且 $a + b \le 2\min(x, y) + 1$。于是长度 $\le 2z + 4\min(x,y) + [x \ne y] \cdot 2$。**下界**：取 $a = b = \min(x, y)$（$x = y$ 时）或 $a = \min+1, b = \min$（$x > y$ 时，对称地 $b = \min + 1$ 当 $y > x$），由引理 3 可与全部 $z$ 个 AB 拼成合法串，长度恰为公式值。上界与构造吻合，定理得证。∎

## 6. 复杂度分析

- **时间**：$O(1)$。一次比较与几次乘加；对比之下，可达性 DP 暴力为 $O(x y z)$，DFS 搜索为指数级。
- **空间**：$O(1)$。公式解不依赖任何数据结构。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int longestString(int x, int y, int z) {
        // 全部 AB 都能用上；AA/BB 受交错性限制，多数类型可多摆一块
        return 2 * z + 4 * min(x, y) + (x == y ? 0 : 2);
    }
};
```

### Python

```python
class Solution:
    def longestString(self, x: int, y: int, z: int) -> int:
        # 全部 AB 都能用上；AA/BB 受交错性限制，多数类型可多摆一块
        return 2 * z + 4 * min(x, y) + (0 if x == y else 2)
```

> 💡 两份代码均通过官方示例（`12`、`14`）。为验证公式，做了两级对拍：与「逐字符检查 AAA/BBB 的字符串级 DFS 穷举」在 $1 \le x, y, z \le 4$ 全部 64 组、$1 \le x,y,z \le 3$ 全部 27 组（Python）上比对；再与「相邻表可达性 BFS」在 $1 \le x, y, z \le 8$ 全部 512 组（C++）及 150 组随机（Python，$x,y,z \le 12$）上比对，`mismatch = 0`；另核验 $x=y=z=50 \to 300$、$x=50,y=z=1 \to 8$ 两个极值。

## 8. 边界情况与易错点

1. **$x = y$ 时不要多加 2**：交错性虽然允许 $\min + 1$ 块多数类型，但存量不允许——$a = b$ 封顶，公式退化为 $2z + 4x$。
2. **`AA` 之后不能接 `AB`**：`"AAAB"` 含 AAA。构造 AB 链位置时这是最容易踩的坑（本文引理 1 的表就是防它）。
3. **AB 链长度不限**：`ABABAB…` 永远合法，不必把 AB 分散到多个缝隙里。
4. **别把「块数」当「长度」**：答案要乘 2；先算块数上限 $2\min + [x \ne y]$ 再乘 2 也行，别混着乘。
5. **范围极小掩盖错误**：$x, y, z \le 50$ 时错误公式可能在小样例上恰好通过，建议像本文一样对 $1 \sim 4$ 穷举自测。
6. **官方提示的另一种理解**：若最终串以 A 开头，把没用完的 AB 全放最前；若以 BB 开头，把 AB 放在第二个 B 之后——与本文构造等价。
