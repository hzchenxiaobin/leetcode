# LeetCode 统计重新排列后包含另一个字符串的子字符串数目 I 题解

## 1. 题目概述

- **标题 / 题号**：统计重新排列后包含另一个字符串的子字符串数目 I（#3297，medium）
- **链接**：https://leetcode.cn/problems/count-substrings-that-can-be-rearranged-to-contain-a-string-i/
- **来源**：LeetCode 第 416 场周赛 Q3
- **难度**：中等
- **标签**：哈希表、字符串、滑动窗口

**题意**：给定两个字符串 `word1` 和 `word2`。若字符串 $x$ 重新排列后，`word2` 恰好是重排结果的**前缀**，则称 $x$ **合法**。统计 `word1` 中合法**子字符串**的数目。

**约束**：

- `1 <= word1.length <= 10^5`
- `1 <= word2.length <= 10^4`
- `word1` 和 `word2` 都只包含小写英文字母

## 2. 示例

**示例 1**

```text
输入：word1 = "bcca", word2 = "abc"
输出：1
解释：唯一合法的子字符串是 "bcca"，重排为 "abcc" 后 "abc" 是它的前缀。
```

**示例 2**

```text
输入：word1 = "abcabc", word2 = "abc"
输出：10
解释：除了长度为 1 和 2 的所有子字符串（共 21 个中的 10 个）都是合法的。
```

**示例 3（word2 需要重复字符）**

```text
输入：word1 = "abcabc", word2 = "aaabc"
输出：0
解释：任何子串中 'a' 至多出现 2 次，凑不出 "aaabc" 需要的 3 个 'a'。
```

## 3. 解题思路

### 3.1 暴力思路

`word1` 长度 $10^5$，子字符串共 $\frac{n(n+1)}{2} \approx 5 \times 10^9$ 个——**连枚举所有子串本身都不可行**，无论单个子串判定多快（哪怕 $O(1)$）都会超时。

一个常见误区是想到「异位词」套路（438. 找到字符串中所有字母异位词）：定长 $|\text{word2}|$ 的窗口逐个比较。但本题子串长度**不固定**——合法子串可以比 `word2` 长任意多，定长窗口直接出局。

> 💡 计数子串的通用套路是**固定一端数另一端**：固定右端点 $r$，统计以 $r$ 结尾的合法子串个数。这需要「合法左端点集合」有简洁结构——下面先刻画它。

### 3.2 核心观察：合法 ⟺ 字符多重集包含

「重排后 `word2` 是前缀」与顺序无关，只与每种字符的**个数下限**有关：

**引理 1（等价刻画）**：子串 $x$ 合法 $\iff$ 对每种字符 $c$ 都有 $\mathrm{cnt}_x[c] \ge \mathrm{need}[c]$，其中 $\mathrm{need}$ 是 `word2` 的字符计数。

也就是说，只要 $x$ 的字符「够数」，就能把 `word2` 所需的字符全部摆在最前面，剩下的随便排——前缀自然就是 `word2`。长度条件 $|x| \ge |\text{word2}|$ 被逐字符条件自动蕴含。

![核心观察：重排后是前缀等价于逐字符计数达标的示意](images/wc416_q3_multiset_prefix_concept.svg)

这是一个**「至少型」条件**：往窗口里加字符永远不会破坏合法性（计数只增不减）。这一单调性正是滑动窗口的入场券。

### 3.3 算法流程：固定 r 数左边 + 双指针 + less 计数器

由引理 1 的单调性立刻得到（引理 2，见 §5）：**若 $[l, r]$ 合法，则 $[l', r]$ 对一切 $l' \le l$ 合法**——合法性随窗口扩大只增不减。于是：

- 以 $r$ 结尾的合法子串的左端点恰是一段**前缀** $[0, l_{\max}(r)]$，个数 $= l_{\max}(r) + 1$；
- $l_{\max}(r)$ 随 $r$ 右移**单调不减**（$[l_{\max}(r), r]$ 合法 $\Rightarrow$ $[l_{\max}(r), r+1]$ 合法 $\Rightarrow$ $l_{\max}(r+1) \ge l_{\max}(r)$），于是左指针 $l$ 全程只前进——标准**双指针**。

![双指针模型：固定 r 时合法左端点是前缀，l_max 单调不减](images/wc416_q3_sliding_window_model.svg)

**流程**（实现时把窗口「恰好弹到失合法为止」，使 $l = l_{\max}(r) + 1$）：

1. 统计 `word2` 的需求 `need[26]`，令 `less` = `need` 中非零项个数（尚未达标的字符种数）；
2. 右端 $r$ 从左到右扫描：`word1[r]` 入窗（计数 $+1$，若恰好使 `cnt[c]` 达到 `need[c]` 则 `less--`）；
3. **当 `less == 0`（窗口合法）时不断弹出 `word1[l]`**，直到 `less > 0`——弹到刚破坏合法性为止。此时 $[l-1, r]$ 是以 $r$ 结尾的**最短合法窗口**；
4. `ans += l`（左端点 $0 \sim l-1$ 共 $l$ 个全部合法）；
5. `r` 右移重复，$l$ 不回退。

**$O(1)$ 合法性判定**靠 `less` 计数器：`less == 0` $\iff$ 每种所需字符都达标。加/删一个字符至多让一种计数跨越等号 `cnt[c] == need[c]`，$O(1)$ 维护。

### 3.4 示例演算

以 `word1 = "abcabc"`、`word2 = "abc"` 为例（$\mathrm{need}$：a×1、b×1、c×1，初始 `less = 3`）：

| $r$ | 加入 | less 变化 | while 弹出（弹到失合法） | 循环后 $l$ | 贡献 | ans 累计 |
|-----|------|-----------|--------------------------|-----------|------|----------|
| 0 | a | 3 → 2 | —（窗口不合法） | 0 | 0 | 0 |
| 1 | b | 2 → 1 | — | 0 | 0 | 0 |
| 2 | c | 1 → 0 ✓ | 弹 a（破等号） | 1 | 1 | 1 |
| 3 | a | 1 → 0 ✓ | 弹 b（破等号） | 2 | 2 | 3 |
| 4 | b | 1 → 0 ✓ | 弹 c（破等号） | 3 | 3 | 6 |
| 5 | c | 1 → 0 ✓ | 弹 a（破等号） | 4 | 4 | 10 |

![示例演算：word1 为 abcabc 时每轮的 less、弹出与贡献](images/wc416_q3_walkthrough.svg)

每轮结束时 $[l-1, r]$ 恰为以 $r$ 结尾的最短合法窗口（如 $r=5$ 时是 "abc"），本轮贡献 = $l$ = 合法左端点个数。累计 $1+2+3+4 = 10$，与示例 2 输出一致。

## 4. 算法细节

1. **`less` 的初值**是 `word2` 中**不同字符的种数**（不是 `word2` 的长度）：初始时窗口为空，每种所需字符都「欠账」。
2. **跨越等号才更新**：入窗时 `cnt[c]` 恰好追平 `need[c]`（`cnt[c] == need[c]`）才 `less--`；出窗时 `cnt[c]` 恰好等于 `need[c]`（再删就跌破）才 `less++`。若 `cnt[c]` 早已富余，两次操作都不动 `less`。每个字符计数每跨越一次等号只更新一次，不会重复计数。
3. **「弹到失合法」的越界设计**：while 循环条件是 `less == 0`，出口 `less > 0`——最后一次弹出总是**破坏合法性的那一个**。多弹的这一步不要还回去：循环后 $[l-1, r]$ 合法、$[l, r]$ 不合法，恰好 $l = l_{\max}(r) + 1$，`ans += l` 无需 $+1$、也无需特判「本轮窗口从未合法」——那种情况下 $l$ 保持不变，`ans += l` 中的历史不变量依然成立（见 §5 定理）。
4. **不会越界**：`word2` 非空 $\Rightarrow$ 空窗口的 `less ≥ 1` $\Rightarrow$ while 在 $l = r+1$（空窗）前必然停住，弹出时恒有 $l \le r$。
5. **计数数组**只需 26 个槽位；`need` 统计 $O(m + 26)$。

## 5. 正确性证明

**引理 1（合法性的多重集刻画）**：$x$ 重排后以 `word2` 为前缀 $\iff$ 对每种字符 $c$ 有 $\mathrm{cnt}_x[c] \ge \mathrm{need}[c]$。

**证明**：（$\Rightarrow$）设 $y$ 是 $x$ 的重排且 $y[0..m) = $ `word2`（$m = |\text{word2}|$）。$x$ 与 $y$ 字符多重集相同，而 $y$ 的前 $m$ 位消耗了 `word2` 的全部字符，故 $x$ 的多重集包含 `word2` 的多重集，即逐字符 $\mathrm{cnt}_x[c] \ge \mathrm{need}[c]$。（$\Leftarrow$）从 $x$ 的多重集中先取出 `word2` 需要的全部字符依次排好（条件保证取得出），剩余字符任意排在后面——得到一个以 `word2` 为前缀的重排。∎

**引理 2（对左端点的单调性）**：若 $[l, r]$ 合法，则任意 $l' \le l$ 的 $[l', r]$ 合法。

**证明**：$[l', r] \supseteq [l, r]$，计数逐字符只增不减，由引理 1 即得。∎

**推论**：以 $r$ 结尾的合法子串的左端点集合，要么为空，要么恰为区间 $[0, l_{\max}(r)]$，其中 $l_{\max}(r) = \max\{l : [l,r] \text{ 合法}\}$；其个数 $= l_{\max}(r) + 1$。

**引理 3（$l_{\max}$ 单调不减）**：$l_{\max}(r+1) \ge l_{\max}(r)$。

**证明**：$[l_{\max}(r), r]$ 合法，而 $[l_{\max}(r), r+1]$ 是它的扩窗（多一个字符），由引理 2 的对偶形式（扩窗保合法）仍合法，故 $l_{\max}(r+1) \ge l_{\max}(r)$。∎

**定理（计数正确性）**：设循环不变量为「每轮 while 结束时，要么 $l = 0$ 且 $[0, r]$ 不合法，要么 $[l-1, r]$ 合法且 $[l, r]$ 不合法」。则每轮 `ans += l` 恰等于以 $r$ 结尾的合法子串数，且 $l$ 从不需要回退。

**证明**：先证不变量。while 出口有 `less > 0`，即 $[l, r]$ 不合法；而**最后一次弹出的前一状态**满足 `less == 0`，即 $[l-1, r]$ 合法——若 while 本轮未执行（出口即入口），则 $l$ 沿用上一轮：上一轮已有 $[l-1, r-1]$ 合法（或 $l=0$），而 $[l-1, r] \supseteq [l-1, r-1]$ 由引理 2 仍合法（$l = 0$ 时即「$[0, r]$ 不合法」，本轮贡献 $l = 0$，正确）。再证计数：由不变量，$l_{\max}(r) = l - 1$（$l \ge 1$ 时），合法左端点 $0..l-1$ 共 $l$ 个，`ans += l` 正确；$l = 0$ 时以 $r$ 结尾的合法子串不存在，贡献 $0 = l$ 正确。最后由引理 3，下一轮的最优左指针不小于本轮，$l$ 单调右移、全程 $\le n$ 步，双指针不重不漏地统计了每个右端点。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n + m + \Sigma)$，其中 $\Sigma = 26$。右指针 $r$ 恰走 $n$ 步；左指针 $l$ 每步至多前进一次、全程 $\le n$ 步（引理 3）；每次指针移动 $O(1)$ 维护 `cnt` 与 `less`；`need` 统计 $O(m + \Sigma)$。$n = 10^5$ 轻松通过。
- **空间复杂度**：$O(\Sigma) = O(26)$，仅两个计数数组与若干标量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long validSubstringCount(string word1, string word2) {
        int need[26] = {0}, cnt[26] = {0};
        for (char c : word2) need[c - 'a']++;
        int less = 0;
        for (int c = 0; c < 26; c++) less += (need[c] > 0);  // 初始：所需字符全部欠账
        long long ans = 0;
        int l = 0, n = word1.size();
        for (int r = 0; r < n; r++) {
            int c = word1[r] - 'a';
            cnt[c]++;
            if (need[c] > 0 && cnt[c] == need[c]) less--;    // 恰好追平等号，欠账 -1
            while (less == 0) {                             // 窗口合法：弹到失合法为止
                int d = word1[l] - 'a';
                if (need[d] > 0 && cnt[d] == need[d]) less++;  // 这一弹会跌破等号
                cnt[d]--;
                l++;
            }
            ans += l;   // 左端点 0..l-1 共 l 个合法（l_max(r) = l-1）
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def validSubstringCount(self, word1: str, word2: str) -> int:
        need = [0] * 26
        for c in word2:
            need[ord(c) - 97] += 1
        cnt = [0] * 26
        less = sum(1 for x in need if x > 0)   # 未达标的字符种数
        ans = 0
        l = 0
        for ch in word1:
            c = ord(ch) - 97
            cnt[c] += 1
            if need[c] > 0 and cnt[c] == need[c]:
                less -= 1                       # 恰好追平等号
            while less == 0:                    # 合法就继续弹，弹到失合法
                d = ord(word1[l]) - 97
                if need[d] > 0 and cnt[d] == need[d]:
                    less += 1                   # 这一弹会跌破等号
                cnt[d] -= 1
                l += 1
            ans += l
        return ans
```

## 8. 边界情况与易错点

1. **答案爆 `int`**：子串总数达 $\frac{10^5 \times (10^5+1)}{2} \approx 5 \times 10^9 > 2^{31}-1$。C++ 必须用 `long long`——接口返回值类型本身就是提示（**「I」版（中等）同样要 64 位**，这是两版共有的坑，Python 无此问题）。
2. **`less` 初值**是 `word2` 的**不同字符种数**而非长度：`word2 = "aaabc"` 的 `less` 初值是 3 不是 5。
3. **`less` 的更新条件是「恰好跨越等号」**：入窗判 `cnt[c] == need[c]`、出窗也是删**前**判 `cnt[d] == need[d]`。写成 `>=` 或删后再判都会算错欠账次数。
4. **while 弹到失合法才停，多弹的一个不还回去**：循环后 `ans += l` 而不是 `l + 1`，也**不要**在 while 内部累加——「多弹一步」使 $l$ 恰为合法左端点个数。
5. **先缩窗后计数**：`ans += l` 必须在 while 之后；放在循环里会对同一 $r$ 重复累加。
6. **word2 含 word1 没有的字符 / `m > n`**：任何子串都不合法，答案 0——算法无需特判（多重集包含天然蕴含长度够、字符够）。
7. **别套定长异位词模板**：合法子串长度任意，只有「计数下限」是本质约束；438 题的定长窗口模板在此完全不适用。

**延伸思考**：

- **改成「恰好」**：若要求子串重排后**前 $m$ 位**恰为 `word2` 且子串长度恰为 $m$，退化为异位词计数（定长窗口 + 计数全等）；若长度任意但每种字符计数**恰等于** $\mathrm{need}$（不多不少），条件对扩窗不再单调，「至少型」双指针失效，需另寻分界讨论。
