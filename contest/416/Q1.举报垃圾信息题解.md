# LeetCode 举报垃圾信息 题解

## 1. 题目概述

- **标题 / 题号**：举报垃圾信息（#3295，medium）
- **链接**：https://leetcode.cn/problems/report-spam-message/
- **来源**：LeetCode 第 416 场周赛 Q1
- **难度**：中等
- **标签**：数组、哈希表、字符串

**题意**：给定字符串数组 `message` 与 `bannedWords`。若 `message` 中**至少存在两个单词**（按出现位置计）与 `bannedWords` 中的某个单词**完全相同**，则 `message` 是垃圾信息，返回 `true`；否则返回 `false`。

**约束**：

- `1 <= message.length, bannedWords.length <= 10^5`
- `1 <= message[i].length, bannedWords[i].length <= 15`
- `message[i]`、`bannedWords[i]` 仅由小写英文字母组成

## 2. 示例

**示例 1**

```text
输入：message = ["hello","world","leetcode"], bannedWords = ["world","hello"]
输出：true
解释："hello" 与 "world" 均出现在 bannedWords 中，命中 2 次。
```

**示例 2**

```text
输入：message = ["hello","programming","fun"], bannedWords = ["world","programming","leetcode"]
输出：false
解释：仅 "programming" 命中 1 次，不足 2 次。
```

**示例 3（重复单词，自构）**

```text
输入：message = ["leet","code","leet"], bannedWords = ["leet"]
输出：true
解释："leet" 在 message 中出现两次，按位置计数命中 2 次，是垃圾信息。
```

## 3. 解题思路

### 3.1 暴力思路

对 `message` 的每个单词线性扫描一遍 `bannedWords` 判等并计数：

- 时间复杂度 $O(n \cdot m \cdot L)$，其中 $n$、$m$ 为两数组长度，$L \le 15$ 为单词长度
- 最坏 $10^5 \times 10^5 \times 15 \approx 1.5 \times 10^{11}$ 次字符比较，**必然超时**

瓶颈在于**同一份静态黑名单被重复扫了 $n$ 遍**。退一步用「排序 + 二分」可降到 $O((n+m) \log m \cdot L)$，能过但没必要——成员查询本可以 $O(1)$。

### 3.2 核心观察：哈希集合 + 命中计数

整道题反复执行的操作只有一种：「单词 $w$ 在不在 `bannedWords` 里」——典型的**存在性查询**。把 `bannedWords` 装进**哈希集合**，每次查询均摊 $O(1)$；再对 `message` 顺序扫描计数即可。

![核心思路：黑名单建哈希集合，消息逐词查询计数](images/report_spam_concept.svg)

两个关键点：

- **计数语义**：统计的是 `message` 中满足 `message[i] ∈ banned` 的**下标个数**——同一个单词出现两次计 2 次，而不是去重后的「不同单词数」
- **短路时机**：第 2 次命中的瞬间即可定罪返回，只有命中不足 2 次时才需要扫完全部

### 3.3 算法流程

![算法流程：建集合、扫描计数、第二次命中即返回](images/report_spam_flow.svg)

1. `banned = set(bannedWords)`，计数器 `cnt = 0`
2. 顺序遍历 `message` 中每个单词 $w$：若 $w \in banned$，则 `cnt += 1`
3. `cnt` 一达到 2，**立即返回 `true`**（提前退出）
4. 遍历结束仍未凑满 2 次，返回 `false`

注意两条出口的不对称：`true` 出口在循环**内部**（第 2 次命中当场返回），`false` 出口在循环**之后**（必须扫完才能排除）。

### 3.4 示例演算

以示例 1（`banned = {"hello", "world"}`）走表：

| $i$ | $w$ | $w \in$ banned ? | cnt | 动作 |
|-----|------|------------------|-----|------|
| 0 | hello | ✓ 是 | 1 | 第 1 次命中，继续 |
| 1 | world | ✓ 是 | 2 | $\ge 2$，立即返回 true |
| 2 | leetcode | — | — | 已返回，无需检查 |

![示例演算：第二次命中即提前返回](images/report_spam_example_walkthrough.svg)

## 4. 算法细节

1. **建集合**：`bannedWords` 自身可能含重复单词，装入哈希集合自动去重，「存在某单词等于 $w$」的语义不变。
2. **按位置计数**：`cnt` 统计满足 `message[i] ∈ banned` 的下标数，**不是**去重后的不同单词数——切勿先对 `message` 去重再求交集大小（见 §8 易错点 1）。
3. **提前退出**：命中数一到 2 立即 `return true`；写法上把「查询命中」与「计数自增」放进同一个 `if`，用短路求值保证未命中时计数器不动。
4. **字符串键的代价**：单次哈希与判等是 $O(L)$（$L \le 15$），两侧总字符量 $\le 3 \times 10^6$，常数极小，无需考虑更花哨的键设计。

## 5. 正确性证明

**引理 1**：单词 $w$ 与 `bannedWords` 中某单词完全相同 $\iff$ $w \in B$，其中 $B$ 是 `bannedWords` 构成的哈希集合。

**证明**：哈希集合精确存储出现过的所有元素；数组含重复时集合仅去掉重复副本，「存在某元素等于 $w$」的语义不变。∎

**引理 2**：`message` 是垃圾信息 $\iff$ $\left|\{\, i : \text{message}[i] \in B \,\}\right| \ge 2$。

**证明**：题设条件为「至少存在两个（位置上的）单词与 `bannedWords` 中任一单词完全相同」。由引理 1，第 $i$ 个单词满足条件 $\iff \text{message}[i] \in B$。故条件成立 $\iff$ 满足条件的下标至少 2 个。∎

**定理**：上述算法返回 `true` 当且仅当 `message` 是垃圾信息。

**证明**：算法按序扫描，任意时刻 `cnt` 等于已扫前缀中满足 $\text{message}[i] \in B$ 的下标数（引理 1 保证每次判等正确）。

- 若扫描中某步 `cnt` 达到 2：此时满足条件的下标已至少 2 个，由引理 2 是垃圾信息，返回 `true` 正确。
- 若遍历结束 `cnt ≤ 1`：满足条件的下标总数不超过 1，由引理 2 非垃圾信息，返回 `false` 正确。∎

## 6. 复杂度分析

- **时间复杂度**：$O((n + m) \cdot L)$。建集合 $m$ 次插入、扫描 $n$ 次查询，单次哈希与判等 $O(L)$；$L \le 15$ 视作常数即 $O(n + m)$。代入约束约 $3 \times 10^6$ 次字符操作，宽松通过。
- **空间复杂度**：$O(m \cdot L)$。哈希集合存下整个黑名单（总字符 $\le 1.5 \times 10^6$）；计数器 $O(1)$。提前退出只改善常数，不改变最坏复杂度。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool reportSpam(vector<string>& message, vector<string>& bannedWords) {
        unordered_set<string> banned(bannedWords.begin(), bannedWords.end());
        int cnt = 0;
        for (const string& w : message) {
            if (banned.count(w) && ++cnt >= 2) {
                return true;
            }
        }
        return false;
    }
};
```

### Python

```python
class Solution:
    def reportSpam(self, message: List[str], bannedWords: List[str]) -> bool:
        banned = set(bannedWords)
        cnt = 0
        for w in message:
            if w in banned:
                cnt += 1
                if cnt == 2:
                    return True
        return False
```

## 8. 边界情况与易错点

1. **重复单词按位置计数**：`message = ["leet","code","leet"]`、`bannedWords = ["leet"]` 应返回 `true`（"leet" 命中 2 次）。若先对 `message` 去重、或用「两集合交集大小 ≥ 2」判定，此例会误判为 `false`——这是本题最大的语义陷阱。
2. **`message.length == 1`**：不可能命中两次，必返回 `false`，算法自然覆盖，无需特判。
3. **`bannedWords` 含重复**：集合自动去重，存在性判断不受影响。
4. **整词精确匹配**：前缀/子串都不算匹配（`"hello"` 不匹配 `"helloworld"`），判等时天然保证。
5. **提前退出的写法**：`banned.count(w) && ++cnt >= 2` 依靠短路求值——未命中时计数器不自增；写成 `sum(w in banned for w in message) >= 2` 虽也能通过（总量小），但失去短路，命中全挤在末尾的用例会白扫。
6. **复杂度陷阱**：不建集合直接双重循环是 $O(n \cdot m \cdot L) \approx 1.5 \times 10^{11}$，会 TLE——这是本题作为签到题唯一的「坑」。
