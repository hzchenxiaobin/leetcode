# LeetCode 最少的后缀翻转次数 题解

## 1. 题目概述

- **标题 / 题号**：最少的后缀翻转次数（#1529，medium）
- **链接**：https://leetcode.cn/problems/minimum-suffix-flips/
- **来源**：LeetCode 第 199 场周赛 Q2
- **难度**：中等
- **标签**：贪心、字符串、差分思想、位运算

**题意**：给定长度为 $n$、下标从 0 开始的二进制字符串 `target`。另有一个初始全 `'0'` 的等长字符串 `s`。一步操作可以选择下标 $i$（$0 \le i < n$），把**闭区间** $[i, n-1]$ 内所有位取反（`'0'` 变 `'1'`，`'1'` 变 `'0'`）。求让 `s` 与 `target` 相等的最少操作次数。

**约束**：

- $1 \le n \le 10^5$ → 线性扫描即可通过；$O(n^2)$ 的模拟会超时
- `target[i]` 为 `'0'` 或 `'1'` → 逐字符比较即可，无需转换成整数

## 2. 示例

**示例 1**

```text
输入：target = "10111"
输出：3
解释：s = "00000"。
翻转 [0, 4]："00000" → "11111"
翻转 [1, 4]："11111" → "10000"
翻转 [2, 4]："10000" → "10111"
（操作是异或叠加，可任意交换顺序，三次即达成目标。）
```

**示例 2**

```text
输入：target = "101"
输出：3
解释：翻 [0,2] → "111"，翻 [1,2] → "100"，翻 [2,2] → "101"。
```

**示例 3**

```text
输入：target = "00000"
输出：0
解释：s 初始就是全 0，无需任何操作。
```

**示例 4（自造，覆盖易错情况）**

```text
输入：target = "10"
输出：2
解释：翻 [0,1] → "11"，翻 [1,1] → "10"。
注意不是 1：0→1、1→0 各需要一次"拨动"，共 2 次。
```

## 3. 解题思路

### 3.1 朴素思路

两个方向都走不通或太慢：

- **爆搜 / BFS**：$n$ 个可选下标，操作序列空间是指数级，$n \le 10^5$ 直接放弃。
- **贪心模拟 + 物理翻转**：从左到右扫，一旦发现 $s[i] \ne \text{target}[i]$ 就执行一次后缀翻转（真的把 $[i, n-1]$ 全部取反）。直觉正确（证明见 §5），但每次翻转 $O(n)$、最坏翻 $O(n)$ 次，总计 $O(n^2) \approx 10^{10}$ 级别字符操作，$n = 10^5$ 必然超时。

还有一个高频直觉陷阱：**数「连续 1 的块数」不是答案**——`"10111"` 只有 2 块 1，答案却是 3。块数口径漏掉了"从 0 跨到 1"和"从 1 跨回 0"都是一次独立拨动的事实。

### 3.2 核心观察：异或差分——一次后缀翻转只拨动一个开关

![核心观察：后缀翻转等价于差分单点拨动](images/wc199_q2_diff_array_concept.svg)

在 `target` 前面**虚拟补一个 `'0'`**（对齐 `s` 的初始状态）得到 $u$：$u[0] = 0$，$u[k] = \text{target}[k-1]$（$1 \le k \le n$）。定义**异或差分**：

$$d[k] = u[k] \oplus u[k-1], \quad 1 \le k \le n$$

即 $u$ 中相邻两位是否不同。现在考察一次操作"翻转 $[i, n-1]$"对差分的影响（翻转作用于 $u$ 中下标 $\ge i+1$ 的所有位）：

- $k \le i$：$u[k]$、$u[k-1]$ 都没动 → $d[k]$ 不变；
- $k = i+1$：$u[i+1]$ 取反而 $u[i]$ 没动 → $d[i+1]$ **取反**；
- $k \ge i+2$：$u[k]$ 与 $u[k-1]$ **同时取反**，异或相互抵消 → $d[k]$ 不变。

> 💡 一句话：**一次后缀翻转 ⇔ 差分数组中恰好一个位置的 0/1 开关被拨动一次**。初始 `s` 全 0（差分全 0），每次操作只能拨动一个开关，而目标差分中每个 1 都需要被拨成 1——所以最少次数就是 $d$ 中 1 的个数，即 $u$ 的**相邻不等对数**。

### 3.3 算法流程：单趟扫描，失配即翻

![扫描贪心算法流程](images/wc199_q2_greedy_flow.svg)

```text
输入：target（长度 n）
1. prev ← '0'，ans ← 0        # prev = 当前位置 s 的实值，初始全 0
2. 对 i = 0 … n-1，c = target[i]：
   a. 若 c ≠ prev：ans ← ans + 1；发起翻转 [i, n-1]；prev ← c
   b. 若 c = prev：什么都不做
3. 返回 ans
```

关键在于**不必真的翻转数组**：翻转 $[i, n-1]$ 的效果是"后续所有位置的实值取反"，这个传染效果用一个 `prev` 标志就能 $O(1)$ 传递——失配时发起翻转，之后所有位置实值变为 $c$，故 `prev ← c`。

等价的计数口径：$ans = [\text{target}[0] = 1] + \sum_{i=1}^{n-1} [\text{target}[i] \ne \text{target}[i-1]]$，即虚拟补 `'0'` 后的相邻不等对数，也正是 $u$ 的极大同值段数减一（`"10111"` → `010111` 有 4 段 $\{0\}\{1\}\{0\}\{111\}$，$4 - 1 = 3$）。

### 3.4 示例演算

![示例 10111 的演算表与字符串演化](images/wc199_q2_example_walkthrough.svg)

对 `target = "10111"` 走查：下标 0、1、2 处失配各发起一次翻转，下标 3、4 匹配跳过；三次翻转后 `s = "10111"` 与目标一致，`ans = 3`。失配下标集合 $\{0,1,2\}$ 恰好就是差分 $d = 1,1,1,0,0$ 中为 1 的位置——两种口径完全吻合。

## 4. 算法细节

1. **两种等价实现**：
   - `prev` 扫描版：失配即计数并更新 `prev`（参考代码采用）；
   - 相邻不等对计数版：Python 一行即可 `sum(a != b for a, b in zip('0' + target, target))`——`zip` 配对出的恰是 $u$ 的全部 $n$ 个相邻对。

2. **`prev` 的语义**：处理完下标 $i$ 后，`prev` 恒等于"从 $i+1$ 起直到下一次翻转前 `s` 的实值"。失配时翻转后实值变为 $c$，故 `prev ← c`；匹配时实值本来就是 $c$，`prev` 不变。

3. **虚拟 `'0'` 的作用**：把初始态（`s` 全 0 ⇔ 差分全 0 ⇔ $u[0]=0$）编码进比较基准，使 `target` 以 `'1'` 开头的情形（首段就要一次翻转）无需特判。

4. **差分只是思维模型**：差分数组用于理解和证明，代码中不落地、不开数组，空间 $O(1)$。

5. **操作的可交换性**：翻转是异或叠加，操作之间可任意交换，同一位置翻两次等于没翻。因此一个"解"本质上是一个**每个下标至多翻一次的下标集合**——这是 §5 把解规约为集合的前提。

## 5. 正确性证明

以下均在 $u$（`'0'` + target）与差分 $d_c[k] = u_c[k] \oplus u_c[k-1]$（$1 \le k \le n$，$u_c[0]$ 为虚拟位 0）的框架下讨论。

**引理 1（单点拨动）**：对当前串 $c$ 执行翻转 $[i, n-1]$ 得到 $c'$，则对一切 $k \ne i+1$ 有 $d_{c'}[k] = d_c[k]$，且 $d_{c'}[i+1] = d_c[i+1] \oplus 1$。

**证明**：翻转等价于把 $u_c[k]$ 取反当且仅当 $k \ge i+1$。按 $k$ 分类：
- $k \le i$：$u_c[k]$、$u_c[k-1]$ 均未变，$d$ 不变；
- $k = i+1$：$u_c[i+1]$ 变而 $u_c[i]$ 不变，$d$ 取反；
- $k \ge i+2$：两位同时取反，$u_c[k] \oplus u_c[k-1]$ 不变。∎

**引理 2（差分是双射）**：固定 $n$，串 $c$ 与差分向量 $d_c$ 一一对应，且 $u_c[k] = \bigoplus_{t=1}^{k} d_c[t]$（前缀异或还原）。

**证明**：由 $d[k] = u[k] \oplus u[k-1]$ 与 $u[0] = 0$ 逐位递推得 $u[k]$ 等于 $d[1..k]$ 的异或和，故 $d$ 唯一确定 $c$；反向由差分定义直接计算。∎

**定理**：最少操作数 $= \sum_{k=1}^{n} d_{\text{target}}[k]$，即 $d_{\text{target}}$ 中 1 的个数。

**证明**：
- **下界**：初始 $d_s$ 全 0。由引理 1，每次操作恰好改变 $d$ 的一个分量。对每个 $k$，若 $d_{\text{target}}[k] = 1$，则 $k$ 必须被操作触及**奇数**次（至少一次）；若为 0 则需偶数次。因此总操作数 $\ge \sum_k d_{\text{target}}[k]$。
- **构造（可达）**：对每个满足 $d_{\text{target}}[k] = 1$ 的 $k$，令 $i = k - 1$，执行一次翻转 $[i, n-1]$。由引理 1，这些操作各自恰好把对应分量从 0 拨成 1、互不干扰，共 $\sum_k d_{\text{target}}[k]$ 次后 $d_s = d_{\text{target}}$，再由引理 2 得 $s = \text{target}$。∎

**推论（扫描贪心的正确性）**：归纳可证处理完下标 $i-1$ 后 `prev` $= u[i]$（初始 `prev` $= u[0] = 0$；失配时翻转后实值为 $c = u[i+1]$，匹配时实值保持 $u[i]$）。于是"$c \ne \text{prev}$"当且仅当 $d[i+1] = 1$，扫描计数恰等于定理给出的最优值，且隐式构造的操作集合即定理构造。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。单趟扫描，每个字符一次比较与 $O(1)$ 标量操作；$n \le 10^5$ 轻松通过。
- **空间复杂度**：$O(1)$。仅 `ans`、`prev` 两个标量；不开差分数组、不复制字符串。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int minFlips(string target) {
        int ans = 0;
        char prev = '0'; // s 初始全 0：等价于在 target 前虚拟补一个 '0'
        for (char c : target) {
            if (c != prev) {
                ++ans;    // 失配：发起一次后缀翻转 [i, n-1]
                prev = c; // 翻转后，后续所有位的实值变为 c
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def minFlips(self, target: str) -> int:
        ans = 0
        prev = '0'  # s 初始全 0：等价于在 target 前虚拟补一个 '0'
        for c in target:
            if c != prev:
                ans += 1   # 失配：发起一次后缀翻转 [i, n-1]
                prev = c   # 翻转后，后续所有位的实值变为 c
        return ans
```

> 💡 Python 一行版（相邻不等对口径）：`return sum(a != b for a, b in zip('0' + target, target))`

## 8. 边界情况与易错点

1. **`target` 全 `'0'`**：初始即相等，返回 0。`prev = '0'` 初值自动覆盖，无需特判。

2. **`prev` 初值必须是 `'0'`**（初始实值），不能初始化成 `target[0]`：否则 `"10"` 会被数成 1 次（正确答案 2 次）——首位的 `1` 本身就意味着一次翻转。

3. **「1 的连续块数」不是答案**：`"10111"` 只有 2 块 1，答案却是 3。正确口径是"相邻变化次数（含虚拟前导 0）"，即交替段数减一。

4. **不要物理模拟翻转后缀**：最坏 $n$ 次操作 × 每次 $O(n)$ = $O(n^2)$，$n = 10^5$ 时约 $10^{10}$ 次字符写操作，必然超时。翻转的传染效果用 `prev` 标志 $O(1)$ 传递。

5. **操作可交换、同位抵消**：翻转是异或叠加，"翻两次等于没翻"。因此最优解一定是互异下标的集合，且顺序无关——比赛中不必纠结操作顺序，计数即可。

6. **$n = 1$**：`"0"` → 0 次、`"1"` → 1 次，单字符路径自然覆盖。
