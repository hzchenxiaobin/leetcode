# LeetCode 好叶子节点对的数量 题解

## 1. 题目概述

- **标题 / 题号**：好叶子节点对的数量（#1530，medium）
- **链接**：https://leetcode.cn/problems/number-of-good-leaf-nodes-pairs/
- **来源**：LeetCode 第 199 场周赛 Q3
- **难度**：中等
- **标签**：树、深度优先搜索、二叉树、最近公共祖先、树形 DP

**题意**：给定二叉树的根结点 `root` 和整数 `distance`。若两个**叶**结点之间的最短路径长度 $\le \text{distance}$，它们就构成一组**好叶子节点对**。返回树中好叶子节点对的数量。

**约束**：

- 结点数 $1 \le n \le 2^{10} = 1024$ → 规模极小，任何多项式做法都能过；但「树高无限制」，链状树递归深度可达 $n$
- 结点值 $\in [1, 100]$，可能重复 → 配对按**结点**计数，与值无关
- $1 \le \text{distance} \le 10$ → 「距离」这一维度可以用一个长度 $\le 11$ 的桶数组（直方图）装下，这是本题的题眼

## 2. 示例

**示例 1**

```text
输入：root = [1,2,3,null,4], distance = 3
输出：1
解释：树如右：1 的孩子是 2、3；2 的右孩子是 4。
叶结点是 3 和 4，路径 4 → 2 → 1 → 3 长度为 3 ≤ 3，是唯一的好对。
```

**示例 2**

```text
输入：root = [1,2,3,4,5,6,7], distance = 3
输出：2
解释：满二叉树，叶 4/5/6/7。
好对：(4,5) 与 (6,7)，路径均为 2 ≤ 3。
(4,6) 的路径 4 → 2 → 1 → 3 → 6 长度为 4 > 3，不算。
```

**示例 3**

```text
输入：root = [100], distance = 1
输出：0
解释：单结点树，根即唯一叶子，凑不出任何叶子对。
```

**示例 4（自造，覆盖非对称树）**

```text
输入：root = [7,1,4,6,null,5,3,null,null,null,null,null,2], distance = 3
输出：1
解释：叶子为 6、5、2。好对只有 (2,5)：路径 2 → 3 → 4 → 5 长度 3。
(6,5) 路径 4、(6,2) 路径 5，均不满足。
```

## 3. 解题思路

### 3.1 朴素思路

本题 $n \le 1024$，暴力其实能过，常见的两条暴力路线：

- **以每个叶子为源 BFS 全树**：先收集全部叶子（至多 512 个），再从每个叶子出发 BFS 得到它到所有结点的距离，两两比对。$O(L \cdot n) \approx 5 \times 10^5$，能过，但把「整棵树」搜了一遍——绝大多数叶子彼此远在 `distance` 之外，纯属浪费。
- **逐对求 LCA 距离**：$\text{dist}(u,v) = \text{depth}(u) + \text{depth}(v) - 2 \cdot \text{depth}(\text{LCA}(u,v))$，对每对叶子上跳找 LCA，$O(L^2 \cdot h)$。同样能过但更绕，还要处理空指针细节。

还有一个**高频错误思路**：在每个结点统计「我子树内所有路径 $\le \text{distance}$ 的叶子对」再求和——同一对会在它的每个公共祖先处被重复计数（例 2 中 (4,5) 会在结点 2 和根 1 各数一次），答案直接翻倍。

> 💡 本题真正想考的是：`distance` 是个 **小常数**，把「距离」维度装进桶里，做一次**后序遍历**自底向上合并——$O(n \cdot \text{distance}^2)$，即使 $n$ 放大到 $10^5$ 也稳。这也是「树形 DP / 向上汇报子树统计信息」这个通用套路的又一实例。

### 3.2 核心观察：两叶路径必经 LCA，长度 = $d_1 + d_2$

![核心观察：两叶之间的最短路径必经最近公共祖先](images/wc199_q3_lca_path_concept.svg)

两个叶子 $u, v$ 的最近公共祖先 $w$ 必然存在且不是叶子，$u, v$ 分属 $w$ 的左右两棵孩子子树。树上两点间路径唯一，且必须「先上后下」：$u \to \cdots \to w \to \cdots \to v$，长度恰为

$$\text{dist}(u, v) = d(w, u) + d(w, v)$$

其中 $d(w,u), d(w,v) \ge 1$。于是判定一对叶子好不好，**只需要在它们的 LCA 处，知道两侧叶子到 LCA 的距离**。

这启发我们让每个结点向上汇报一个「距离直方图」：$cnt[d]$ = 我的子树里，到**我**距离恰为 $d$ 的叶子个数。好对在 LCA 处、且只在 LCA 处被统计：左出一个叶子、右出一个叶子，两边距离相加判定。

由于 $\text{distance} \le 10$，直方图只有 $\text{distance} + 1 \le 11$ 格，且距离超过 $\text{distance}$ 的叶子可以直接丢弃（上移只会更远，永远凑不成好对）。

### 3.3 算法流程：后序遍历合并距离直方图

![算法流程：后序遍历，自底向上合并距离直方图](images/wc199_q3_postorder_merge.svg)

```text
dfs(node)：
1. node 为空       → 返回全 0 数组（长度 distance+1）
2. node 是叶子     → 返回 [1, 0, …, 0]（自己距自己为 0）
3. 否则（后序）：
   L = dfs(node.left)，R = dfs(node.right)
   跨侧配对：对所有 i, j，若 (i+1) + (j+1) ≤ distance：
       ans += L[i] × R[j]        ← 距左孩子 i ⇒ 距本结点 i+1
   合并上移：cnt[d+1] = L[d] + R[d]，下标超出 distance 的丢弃
   返回 cnt
```

两个口径细节：

- **L[i] 的含义是「距左孩子 $i$」**，所以对结点 `node` 而言该叶子距离为 $i+1$，跨侧对的路径长度为 $(i+1)+(j+1)$；
- **合并即整体 +1**：孩子直方图里的每个叶子，到父结点的距离都比到孩子多 1。

### 3.4 示例演算

![示例演算：满二叉树 distance=3 的逐步走查](images/wc199_q3_example_walkthrough.svg)

对示例 2 走查：四个叶子各返回 `[1,0,0,0]`；结点 2 与结点 3 各叉乘出 $(0+1)+(0+1)=2 \le 3$，各贡献 1 对并上移 `[0,2,0,0]`；根 1 处跨侧 $(1+1)+(1+1)=4 > 3$，不再贡献。最终 `ans = 2`，好对恰为 $(4,5)$ 与 $(6,7)$——而 $(4,6)$ 的 LCA 是根，路径 $2+2=4$ 被正确排除。

## 4. 算法细节

1. **数组长度固定为 $\text{distance}+1$**：下标 $0 \sim \text{distance}$。空子树返回全 0，叶子返回 `cnt[0] = 1`，统一长度让合并逻辑无需任何分支判断。
2. **叉乘计数**：双重循环枚举 $i, j$，条件 $i + j + 2 \le \text{distance}$ 同时完成了判定与越界控制（不满足时内层循环直接退出）。也可用「L 的前缀和」把单结点开销从 $O(D^2)$ 降到 $O(D)$，但 $D \le 10$，无此必要。
3. **合并上移**：$cnt[d+1] = L[d] + R[d]$，$0 \le d \le \text{distance}-1$；$cnt[0] = 0$ 恒成立（内部结点自己不是叶子）。
4. **直方图的语义锚点**：$cnt[d]$ 永远是「到**当前**结点的距离」，+1 上移由父结点统一完成——不要在叶子处就记成「到父结点距离 1」，否则会双重 +1。
5. **计数无溢出风险**：叶子至多 512 个，对数上界 $\binom{512}{2} = 130816$，`int` 足够。
6. **递归深度**：二叉树不保证平衡，链状树深度可达 $n - 1 \approx 1023$，C++ 无压力，Python 在部分本地环境需调大递归限制（LeetCode 平台无碍）。

## 5. 正确性证明

**引理 1（路径必经 LCA）**：设 $u \ne v$ 为两叶子，$w = \mathrm{LCA}(u, v)$。则 $w$ 非叶，$u, v$ 分属 $w$ 的两棵不同孩子子树，且 $u$–$v$ 唯一路径经过 $w$，长度为 $d(w,u) + d(w,v)$。

**证明**：叶子没有任何后代，故 $u, v$ 互不为祖先，$w \notin \{u, v\}$；由 LCA 定义，$u, v$ 位于 $w$ 的两棵不同孩子子树中（因此 $w$ 至少有两个孩子，非叶）。树是连通无环图，任意两点间路径唯一。$u$ 所在孩子子树与 $v$ 所在孩子子树不相交，且二者之间任何通路必经 $w$，故 $u$–$v$ 路径分为 $u \to w$ 与 $w \to v$ 两段拼接，长度为 $d(w,u) + d(w,v)$。∎

**引理 2（直方图归纳正确）**：对每个结点 $x$，`dfs(x)` 返回的 `cnt` 满足：对一切 $0 \le d \le \text{distance}$，$cnt[d]$ 等于子树 $(x)$ 中到 $x$ 距离恰为 $d$ 的叶子个数；到 $x$ 距离 $> \text{distance}$ 的叶子不在数组中。

**证明**：对子树高度归纳。叶子：$cnt[0] = 1$，即它自己到自己的距离 $0$，成立。内部结点 $x$：其子树内任一叶子恰属于某个孩子子树；到 $x$ 距离为 $d \ge 1$ 的叶子个数 = 左右孩子子树中到对应孩子距离 $d-1$ 的叶子数之和，由归纳假设等于 $L[d-1] + R[d-1]$，与合并式一致（$d - 1 \le \text{distance} - 1$，归纳假设覆盖）。$cnt[0] = 0$ 因 $x$ 非叶；$d > \text{distance}$ 的格子按合并循环上界被丢弃。∎

**引理 3（配对恰好一次）**：叶对 $\{u,v\}$ 在算法中被计数，当且仅当处理 $w = \mathrm{LCA}(u,v)$ 时的叉乘步骤，且恰被计数一次；计数的条件是 $d(w,u) + d(w,v) \le \text{distance}$。

**证明**：叉乘只枚举「一个叶子来自左孩子直方图、一个来自右孩子直方图」的对，即 LCA 恰为当前结点的叶对。设 $x \ne w$ 是任一其它结点：若 $x$ 是 $w$ 的真祖先，则 $u, v$ 同在 $x$ 的某一棵孩子子树内（同侧），不被枚举；若 $x$ 是 $w$ 的真后代，则 $u, v$ 中至少有一个不在子树 $(x)$ 内，不被枚举。故枚举仅发生在 $w$。由引理 2，$w$ 的孩子直方图中下标 $i$ 的叶子到 $w$ 距离为 $i+1$，故判定条件 $(i+1) + (j+1) \le \text{distance}$ 即 $d(w,u) + d(w,v) \le \text{distance}$。∎

**定理**：算法返回的 `ans` 等于好叶子节点对的总数。

**证明**：由引理 1，叶对是好对当且仅当在其 LCA $w$ 处满足 $d(w,u) + d(w,v) \le \text{distance}$。由引理 3，每个叶对恰在 $w$ 处被判定一次、条件一致，好对恰被计一次，非好对计零次。还需确认截断不会误删好对的「在场性」：若 $\{u,v\}$ 是好对，则 $d(w,u) \le \text{distance} - 1$（因 $d(w,v) \ge 1$），故在 $w$ 的孩子直方图中 $u$ 的下标 $\le \text{distance} - 2$，由引理 2 的完备性仍在数组中，参与叉乘；被丢弃的叶子只可能属于「在 $w$ 处距离 $> \text{distance}$」的侧，那样的对本就不是好对。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \cdot D^2)$，其中 $D = \text{distance}$。每个结点做一次 $O(D^2)$ 的叉乘与 $O(D)$ 的合并；$n \le 1024$、$D \le 10$，总计约 $1.2 \times 10^5$ 次乘加，瞬间完成。
- **空间复杂度**：$O(h \cdot D)$。递归栈深度为树高 $h$（最坏链状树 $h = n$），每个活跃栈帧持有一个长度 $D+1$ 的数组；合计最坏 $O(n \cdot D) \approx 10^4$ 个整数。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int countPairs(TreeNode* root, int distance) {
        int ans = 0;
        dfs(root, distance, ans);
        return ans;
    }

  private:
    // cnt[d]：子树中到 node 距离恰为 d 的叶子个数（d ≤ distance，更远的已截断）
    vector<int> dfs(TreeNode* node, int distance, int& ans) {
        vector<int> cnt(distance + 1, 0);
        if (node == nullptr) return cnt;              // 空子树：全 0
        if (node->left == nullptr && node->right == nullptr) {
            cnt[0] = 1;                               // 叶子：自己距自己 0
            return cnt;
        }
        vector<int> L = dfs(node->left, distance, ans);
        vector<int> R = dfs(node->right, distance, ans);
        // 跨侧配对：距左孩子 i ⇒ 距本结点 i+1，路径 = (i+1) + (j+1)
        for (int i = 0; i <= distance; ++i)
            for (int j = 0; i + j + 2 <= distance; ++j)
                ans += L[i] * R[j];
        // 合并上移：整体 +1，越界（> distance）的格子丢弃
        for (int d = 0; d + 1 <= distance; ++d)
            cnt[d + 1] = L[d] + R[d];
        return cnt;
    }
};
```

### Python

```python
from typing import List, Optional


class Solution:
    def countPairs(self, root: Optional[TreeNode], distance: int) -> int:
        ans = 0

        def dfs(node: Optional[TreeNode]) -> List[int]:
            nonlocal ans
            cnt = [0] * (distance + 1)
            if node is None:                       # 空子树：全 0
                return cnt
            if node.left is None and node.right is None:
                cnt[0] = 1                         # 叶子：自己距自己 0
                return cnt
            left, right = dfs(node.left), dfs(node.right)
            # 跨侧配对：距左孩子 i ⇒ 距本结点 i+1，路径 = (i+1) + (j+1)
            for i, a in enumerate(left):
                for j, b in enumerate(right):
                    if i + j + 2 <= distance:
                        ans += a * b
            # 合并上移：整体 +1，越界（> distance）的格子丢弃
            for d in range(distance):
                cnt[d + 1] = left[d] + right[d]
            return cnt

        dfs(root)
        return ans
```

> 💡 两个易读变体：叶子也可以返回 `[1]` 而非定长数组（C++ 用 `vector` 天然支持变长，配对循环以长度为界）；叉乘可用 `L` 的前缀和优化到每结点 $O(D)$，本题规模下纯装饰。

## 8. 边界情况与易错点

1. **单结点树**：根即唯一叶子，无对，返回 0。代码走叶子分支直接返回，天然正确。
2. **distance = 1 恒为 0**：叶子的父结点必有另一个孩子（否则它不是叶子），故任何两叶路径 $\ge 2$。判定式 $(i+1)+(j+1) \ge 2 > 1$ 自动排除，无需特判。
3. **链状树**：每层仅一个孩子，只有一个叶子，答案 0；同时递归深度最深（约 $n$ 层），C++ 无碍，Python 本地测试记得 `sys.setrecursionlimit`。
4. **重复计数陷阱（本题最大坑）**：不要按「子树内所有距离 $\le \text{distance}$ 的叶子对」口径在每个结点累加——同一对会在每个公共祖先处被重数。必须只数**跨左右子树**的对（即 LCA 恰为当前结点的对）。
5. **直方图锚点错位**：$cnt[d]$ 的语义是「到当前结点」。叶子记 `cnt[0] = 1`（到自己是 0），+1 上移由父结点统一做；若在叶子处记 `cnt[1] = 1`（到父结点 1），父结点合并时再 +1 就双重偏移。
6. **合并越界**：`d + 1 > distance` 时必须丢弃（数组定长，否则越界）；叉乘条件 `i + j + 2 <= distance` 已隐式控制边界。
7. **空孩子不特判**：空子树返回全 0 直方图，叉乘自然为 0，左右不对称的树（如示例 1、4）无需分支处理。
8. **值重复无影响**：结点值 $\in [1,100]$ 而结点可达 1024 个，值必然重复——按结点配对，与值无关。
