# LeetCode 执行操作使两个字符串相等 题解

## 1. 题目概述

- **标题 / 题号**：执行操作使两个字符串相等（#2896，medium）
- **链接**：https://leetcode.cn/problems/apply-operations-to-make-two-strings-equal/
- **来源**：LeetCode 第 366 场周赛 Q3
- **难度**：中等
- **标签**：字符串、动态规划

**题意**：给定两个长度均为 $n$ 的二进制字符串 $s_1$、$s_2$ 和正整数 $x$，可对 $s_1$ 执行任意次操作：① 任选两个下标 $i, j$，同时反转 $s_1[i]$、$s_1[j]$，代价 $x$；② 选下标 $i < n-1$，反转 $s_1[i]$、$s_1[i+1]$，代价 $1$。返回使 $s_1 = s_2$ 的最小总代价；无法相等返回 $-1$。

**约束**：

- $1 \le n, x \le 500$
- $s_1$、$s_2$ 只包含字符 `0` 和 `1`

> ⚠️ 两个入手点都藏在「每次操作恰好翻 2 个字符」里：其一是**不变量**——差异位个数的奇偶性永远不变，直接决定 $-1$ 的判定；其二是**归约**——只有 $s_1[i] \ne s_2[i]$ 的位置需要被**净翻转奇数次**，其余位置翻偶数次即可自我抵消，所以真正需要研究的只有「差异位」这一小集合。

## 2. 示例

**示例 1**

```text
输入：s1 = "1100011000", s2 = "0101001010", x = 2
输出：4
解释：远程翻转 (0, 8) 代价 2；相邻翻转 (3,4)、(4,5) 代价 1 + 1。
      s1 → "0101001010" = s2，总代价 4。
```

**示例 2**

```text
输入：s1 = "10110", s2 = "00011", x = 4
输出：-1
解释：差异位为 [0, 2, 4]，共 3 个（奇数）。每次操作恰好翻 2 个字符，
      差异数的奇偶性不变，永远到不了 0 个差异。
```

**示例 3**（自造，感受「嵌套配对」何时更优）

```text
输入：s1 = "00000000000", s2 = "10110000001", x = 7
输出：8
解释：差异位 [0, 2, 3, 10]。顺序配对 (0,2) + (3,10)：min(7,2) + min(7,7) = 2 + 7 = 9；
      嵌套配对 (0,10) + (2,3)：min(7,10) + min(7,1) = 7 + 1 = 8，更优。
```

## 3. 解题思路

### 3.1 暴力思路：状态图最短路

把 $s_1$ 的每种状态（$2^n$ 个）看作节点，两种操作看作边权为 $x$ 和 $1$ 的边，在状态图上跑 Dijkstra / 01-BFS。$n \le 500$ 时状态数 $2^{500}$，直接爆炸。而且「绝对状态」并不重要：需要净翻转的只有差异位，非差异位翻偶数次即可抵消。问题应当归约到**差异位集合**上——真正要决策的只有：**差异位之间如何两两配对、每个配对花多少钱**。

### 3.2 核心观察：差异位两两配对，配对代价 $\min(x,\ b-a)$

![配对代价与凹性陷阱](images/wc366_q3_pair_cost.svg)

**观察一（奇偶不变量）**：每次操作恰好翻转 2 个字符，差异位个数的奇偶性全程不变。目标是 0 个差异（偶数），故**差异位个数为奇数时无解，返回 $-1$**。

**观察二（一对差异的消除代价）**：设两个差异位 $a < b$。

- **链式传播**：相邻翻转 $(a, a{+}1), (a{+}1, a{+}2), \ldots, (b{-}1, b)$，共 $b - a$ 次操作；中间每个位置各被翻 2 次、恰好自我抵消，净效果只有 $a$、$b$ 各翻一次，代价 $b - a$；
- **远程翻转**：一次操作①直接翻 $a$、$b$，代价 $x$，与距离无关。

两者取小，即消除一对差异的代价为 $w(a, b) = \min(x,\ b - a)$。

**观察三（凹性陷阱）**：$w$ 关于距离「先线性增长、到 $x$ 后封顶」，是**凹**函数——凹性意味着**按差异位顺序两两配对未必最优**，嵌套配对可能更便宜（反例见上图下半部）。所以不能贪心，需要 DP 决策配对结构。

### 3.3 算法流程：带「悬置」状态的一维 DP

![悬置 DP 状态机](images/wc366_q3_dp_states.svg)

记差异位从小到大为 $p_1, p_2, \ldots, p_m$，从左到右扫描，定义：

- $f[i][0]$：前 $i$ 个差异位**全部**配对完毕的最小代价；
- $f[i][1]$：前 $i$ 个差异位中恰有一个远程操作「悬置」——它的左半落在某个已处理的差异位上（**$x$ 已支付**），另一半将落在未来某个差异位上。

记 $d_i = \min(x,\ p_i - p_{i-1})$（差异位序列中相邻两位配成一对的代价），四条转移：

| 转移 | 含义 | 代价 |
|------|------|------|
| $f[i][1] \leftarrow f[i-1][0] + x$ | **开启**：$p_i$ 作为某个远程对的左端点，付 $x$ | $+x$ |
| $f[i][0] \leftarrow f[i-1][1]$ | **关闭**：悬置的另一半落在 $p_i$，免费 | $+0$ |
| $f[i][0] \leftarrow f[i-2][0] + d_i$ | **相邻配对**：$p_{i-1}$、$p_i$ 配成一对 | $+d_i$ |
| $f[i][1] \leftarrow f[i-2][1] + d_i$ | **相邻配对**（悬置保留） | $+d_i$ |

$m$ 为奇数直接返回 $-1$；否则答案为 $f[m][0]$。

两条性质解释了为什么「一个比特」的悬置状态就够：

1. **悬置不记位置**：$x$ 的代价与两个下标的距离无关，开启时就把 $x$ 整个付掉，另一半落在哪个未来差异位上都免费——嵌套配对结构由「开启 → 若干相邻配对 → 关闭」的路径天然覆盖，示例 3 的嵌套解正对应此路径；
2. **至多一个悬置**：若两个 $x$ 配对嵌套（花 $2x$），把四个端点重新配成两组更局部的对，代价 $\min(x, u) + \min(x, w) \le 2x$ 不增（§5 引理 4），故最优解不需要两个同时悬置。

### 3.4 示例演算

![示例演算](images/wc366_q3_example_walkthrough.svg)

以示例 1 为例：差异位 $[0, 3, 5, 8]$，$x = 2$，逐步演算见上图。最优路径为

$$f[0][0] \xrightarrow{\text{开启}(+2)} f[1][1] \xrightarrow{\text{配对}(3,5)(+2)} f[3][1] \xrightarrow{\text{关闭}(+0)} f[4][0] = 4$$

与官方解释的操作一一对应：远程翻转 $(0, 8)$ 代价 2（在 0 处开启、8 处关闭）；链式传播 $3 \to 5$ 即相邻翻转 $(3,4), (4,5)$ 代价 2（正是 $w(3,5) = \min(2, 2) = 2$）。（两组相邻配对 $(0,3) + (5,8)$ 同为 $2 + 2 = 4$，并列最优。）

## 4. 算法细节

1. **差异位提取**：`p = [i for i,(a,b) in enumerate(zip(s1,s2)) if a != b]`，之后只与 `p` 打交道，不再碰原字符串。
2. **先判奇偶**：`m % 2 == 1` 直接返回 $-1$，不要让 DP 在无解实例上输出无意义的哨兵值。
3. **$d_i$ 的语义**：$d_i = \min(x,\ p_i - p_{i-1})$ 是「**差异位序列**相邻」的两位配对代价，别误按「原字符串下标相邻」去配对。
4. **INF 哨兵**：转移中会出现 $\infty + x$，C++ 用 `long long` 当哨兵（$10^{18} + 500$ 不溢出）比 `INT_MAX` 安全；答案本身 $\le \frac{m}{2}\min(x, n-1) \le 125000$，`int` 绰绰有余，返回前转回 `int`。
5. **滚动数组**：$f[i]$ 只依赖 $f[i-1]$ 与 $f[i-2]$，每个状态保留最近两份即可把额外空间压到 $O(1)$；正文代码保留整个数组，便于对照转移表。
6. **DP 求的是配对总代价**：具体操作序列无需在 DP 中模拟——每个配对独立实现即可（$b - a \le x$ 走链式传播，否则走一次远程翻转），这正是 §5 引理 3 的内容。

## 5. 正确性证明

设差异位集合 $D = \{p_1 < p_2 < \cdots < p_m\}$（$m$ 为奇数时由引理 1 直接判 $-1$，以下设 $m$ 为偶数），$w(a,b) = \min(x,\ |a-b|)$。

**引理 1（奇偶不变量）**：操作序列能使命题成立的一个必要条件是 $m$ 为偶数。

**证明**：每次操作恰好翻转 2 个字符，差异位个数的奇偶性不变；终态差异数为 0（偶数），故 $m$ 必为偶数。∎

**引理 2（配对下界）**：任何可行操作序列的总代价 $C$，不小于 $D$ 上以 $w$ 为配对代价的最小费用**完美匹配** $\mathrm{OPT}$。

**证明**：把操作序列表示为位置 $\{0, \ldots, n-1\}$ 上的边多重图 $F$：操作① 加边 $(i, j)$、权 $x$；操作② 加边 $(i, i{+}1)$、权 $1$（多重边计入度数）。$s_1 = s_2$ 意味着每个位置被翻转次数的奇偶性恰为「是否属于 $D$」，即 $F$ 的奇度点集恰为 $D$。添加一个 dummy 点并向全部 $m$ 个奇度点各连一条边，全图变为偶度、存在欧拉回路；沿回路删去 dummy 点，$F$ 的全部边被分解为 $\frac{m}{2}$ 条边不相交的**迹**，两两配对 $D$ 中所有点。考察任一条连接 $a, b$ 的迹：若含操作①边则代价 $\ge x$；若全是相邻边，则是数轴上从 $a$ 到 $b$ 的游走，边数 $\ge |b - a|$；总之代价 $\ge \min(x, |b-a|)$。故

$$C = \sum_{\text{迹}} \text{代价} \ \ge\ \sum_{\text{配对}} \min(x, |a-b|) \ \ge\ \mathrm{OPT} \quad \square$$

**引理 3（配对可达）**：任何完美匹配 $M$ 都能被操作序列实现，总代价恰为 $\sum_{(a,b) \in M} w(a,b)$。

**证明**：每对独立实现：$b - a \le x$ 时用链式传播（代价 $b - a$），否则一次远程翻转（代价 $x$）。全部操作叠加：每个差异位恰作为某对的端点被净翻 1 次；链的内部位置各被翻 2 次；其余位置翻 0 次——非差异位净翻转均为偶数次，自我抵消。故 $s_1 \to s_2$，总代价即 $\sum w(a,b)$。∎

**定理 1（配对归约）**：答案 $= \mathrm{OPT}$。

**证明**：由引理 3，$\mathrm{OPT}$ 可被实现，答案 $\le \mathrm{OPT}$；由引理 2，任何可行序列代价 $\ge \mathrm{OPT}$。∎

**引理 4（结构定理）**：存在最优匹配 $M^*$ 满足：(i) 每个配对要么连接 $D$ 中**相邻**的两个差异位（即 $p_{i-1}, p_i$），要么其代价恰为 $x$；(ii) 任意两个代价为 $x$ 的配对互不嵌套、互不交错。

**证明**：在所有最优匹配中，取「总代价为第一关键字、总跨度 $\sum(\text{右端点} - \text{左端点})$ 为第二关键字」字典序最小者 $M^*$。

(i) 反设 $(a, b)$ 是跨过至少一个中间差异位的**链式**配对（$w(a,b) = b - a < x$）。取 $a, b$ 之间最右侧的差异位 $u$（存在），设其在 $M^*$ 中的配对另一方为 $v$（$v \ne a, b$）：

- 若 $v > b$：改为 $(a, u), (b, v)$，代价 $(u - a) + \min(x, v - b) < (b - a) + \min(x, v - u)$（$u - a < b - a$ 且 $v - b < v - u$），严格更优，矛盾；
- 若 $v < a$：改为 $(v, a), (u, b)$，代价 $\min(x, a - v) + (b - u) < \min(x, u - v) + (b - a)$（$a - v < u - v$ 且 $b - u < b - a < x$），严格更优，矛盾；
- 若 $a < v < b$：记 $c = \min(u, v),\ d = \max(u, v)$，改为 $(a, c), (d, b)$。四点均在 $[a, b]$ 内且各对距离均 $< b - a < x$，新旧代价分别为 $(b - a) + (d - c)$ 与 $(c - a) + (b - d)$，后者减前者 $= 2(c - d) < 0$，严格更优，矛盾。

故 (i) 成立：代价不足 $x$ 的配对只能是相邻差异位对。

(ii) 反设两个 $x$ 配对（代价均为 $x$）嵌套 $a_1 < a_2 < b_2 < b_1$ 或交错 $a_1 < a_2 < b_1 < b_2$。统一改为 $(a_1, a_2)$ 与靠右的两端点配对，新代价 $\min(x, a_2 - a_1) + \min(x, \text{右对距离}) \le 2x$ 不增；而总跨度严格减小（两情形分别变化 $2(a_2 - b_2) < 0$、$2(a_2 - b_1) < 0$），与 $M^*$ 的字典序最小性矛盾。∎

**定理 2（DP 正确性）**：上述 DP 输出 $\mathrm{OPT}$。

**证明**：由引理 4，存在最优匹配：其中每个配对或为相邻差异位对 $(p_{i-1}, p_i)$，或为代价 $x$ 的远程对，且远程对互不嵌套交错——即从左到右扫描时，任何时刻**至多一个**远程对张开（左端点已过、右端点未到）。DP 的两态恰编码「当前张开的远程对个数（0 或 1）」；四条转移与匹配的四种局部动作一一对应：$p_i$ 作远程对左端点（开启，$+x$）、作右端点（关闭，$+0$）、与 $p_{i-1}$ 结为相邻对（状态保持，$+d_i$，可发生在悬置之内或之外）。于是 DP 枚举的正是引理 4 刻画的全部候选结构并取其最小值；又由定理 1，每个候选结构的累加代价就是真实操作代价。终态取 $f[m][0]$（$f[m][1]$ 表示悬置未闭合，不构成完美匹配，正确地被排除）。∎

> 💡 引理 2 的「图分解为迹」是经典 T-join（奇集连接）视角的初等形式；引理 4 则是本题 $O(m)$ DP 的灵魂——**凹代价下最优配对可以嵌套，但「花 $x$ 的长对」至多嵌套一层**，整个嵌套维度因此被压缩成一个比特。

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。提取差异位扫描 $O(n)$，DP 递推 $O(m)$，$m \le n \le 500$。
- **空间复杂度**：$O(m)$（两个 DP 数组）；由 $f[i]$ 只依赖 $f[i-1], f[i-2]$，可滚动至 $O(1)$ 额外空间。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int minOperations(string s1, string s2, int x) {
        vector<int> p;                                   // 差异位
        for (int i = 0; i < (int)s1.size(); ++i)
            if (s1[i] != s2[i]) p.push_back(i);
        const int m = p.size();
        if (m & 1) return -1;                            // 奇偶不变量：无解

        const long long INF = 1e18;                      // 哨兵可安全参与加法
        vector<long long> f0(m + 1, INF), f1(m + 1, INF);
        f0[0] = 0;
        for (int i = 1; i <= m; ++i) {
            long long d = i >= 2 ? min((long long)x, (long long)p[i - 1] - p[i - 2]) : 0;
            f1[i] = f0[i - 1] + x;                       // 开启：付 x，悬置
            f0[i] = f1[i - 1];                           // 关闭：免费
            if (i >= 2) {                                // 相邻配对（状态保留）
                f0[i] = min(f0[i], f0[i - 2] + d);
                f1[i] = min(f1[i], f1[i - 2] + d);
            }
        }
        return (int)f0[m];
    }
};
```

### Python

```python
class Solution:
    def minOperations(self, s1: str, s2: str, x: int) -> int:
        p = [i for i, (a, b) in enumerate(zip(s1, s2)) if a != b]
        m = len(p)
        if m % 2:
            return -1                                    # 奇偶不变量：无解
        INF = float('inf')
        f0 = [INF] * (m + 1)                              # f[i][0]：全部配对完
        f1 = [INF] * (m + 1)                              # f[i][1]：悬置半个 x 操作
        f0[0] = 0
        for i in range(1, m + 1):
            d = min(x, p[i - 1] - p[i - 2]) if i >= 2 else 0
            f1[i] = f0[i - 1] + x                        # 开启：付 x
            f0[i] = f1[i - 1]                            # 关闭：免费
            if i >= 2:                                   # 相邻配对（状态保留）
                f0[i] = min(f0[i], f0[i - 2] + d)
                f1[i] = min(f1[i], f1[i - 2] + d)
        return f0[m]
```

## 8. 边界情况与易错点

1. **忘记判 $-1$**：差异位个数为奇数必须先返回 $-1$；直接跑 DP 会得到 INF 哨兵而非 $-1$。
2. **`s1 == s2`**：$m = 0$，`f0[0] = 0` 天然覆盖，答案 0，无需特判。
3. **$d_i$ 忘取 $\min$**：相邻配对代价是 $\min(x, p_i - p_{i-1})$；当间隙大于 $x$ 时远程翻转更便宜，写死距离会 WA。
4. **按原下标而非差异位序列配对**：`p` 是差异位列表，$p_{i-1}, p_i$ 之间可能隔着若干相同位；「相邻」指的是**序列相邻**。
5. **贪心顺序两两配对**：凹性反例（示例 3 / §3.2 反例图）——顺序配对差在「让一次超长距离绑架了一个便宜对」，嵌套用 $x$ 封顶反而更省，必须 DP。
6. **漏掉「悬置保留」转移** $f[i][1] \leftarrow f[i-2][1] + d_i$：嵌套结构（开着的悬置内部再配相邻对）全靠它，漏掉后示例 1 这类题会算错。
7. **INF 哨兵溢出**：C++ 中 `INT_MAX + x` 溢出为负、参与 `min` 后污染答案；用 `long long` 哨兵（或特判跳过 INF 来源）才安全。
8. **滚动时保留两份**：转移依赖 $i-1$ 与 $i-2$，滚动只留一份会错；稳妥起见 editorial 版保留整个数组。

**延伸思考**：若把配对代价换成一般的**凹**函数 $g(|a - b|)$ 且没有「与距离无关的封顶价」，悬置状态无法压缩（封顶价 $x$ 正是把整个嵌套维度压成一个比特的原因），需要回到 $O(m^2)$ / $O(m^3)$ 的区间 DP 或一般图最小权完美匹配（带花树）。两个退化形态值得手推：$x = 1$ 时 $w \equiv 1$，答案恒为 $m/2$；$x \ge n$ 时 $w = $ 纯距离，顺序两两配对恰好最优（此时不存在嵌套收益）。本题在本仓库 `solution/2801-2900/2896` 另有每日一题版题解，侧重面试表达，可与本篇互补阅读。
