# LeetCode 分类求和并作差 题解

## 1. 题目概述

- **标题 / 题号**：分类求和并作差（#2894，easy）
- **链接**：https://leetcode.cn/problems/divisible-and-non-divisible-sums-difference/
- **来源**：LeetCode 第 366 场周赛 Q1
- **难度**：简单
- **标签**：数学

**题意**：给定两个正整数 `n` 和 `m`。定义 `num1` 为 `[1, n]` 内所有**无法**被 `m` 整除的整数之和，`num2` 为 `[1, n]` 内所有**能够**被 `m` 整除的整数之和，返回 `num1 - num2`。

**约束**：

- `1 <= n, m <= 1000`

## 2. 示例

**示例 1**

```text
输入：n = 10, m = 3
输出：19
解释：无法被 3 整除：[1,2,4,5,7,8,10]，num1 = 37；
     能够被 3 整除：[3,6,9]，num2 = 18。返回 37 - 18 = 19。
```

**示例 2**

```text
输入：n = 5, m = 6
输出：15
解释：m > n，[1,5] 内没有 6 的倍数，num2 = 0，num1 = 15。返回 15。
```

**示例 3**

```text
输入：n = 5, m = 1
输出：-15
解释：任何整数都能被 1 整除，num1 = 0，num2 = 15。返回 -15。
```

## 3. 解题思路

### 3.1 暴力思路

签到题。`n <= 1000`，直接一遍循环：能被 `m` 整除就累加到 `num2`，否则累加到 `num1`，最后返回 `num1 - num2`，时间 $O(n)$，完全可以通过。

### 3.2 核心观察：互补分组 + 等差数列求和

![核心观察：按整除性分组与求和公式](images/divisible_sums_concept.svg)

`num1` 与 `num2` 是**互补**的：把 `[1, n]` 全体求和得 $total = \frac{n(n+1)}{2}$，则 $num_1 = total - num_2$，于是

$$ans = num_1 - num_2 = total - 2 \cdot num_2$$

而 `num2` 是首项为 $m$、公差为 $m$ 的等差数列之和，可 $O(1)$ 求出：

$$num_2 = m + 2m + \cdots + km = m \cdot \frac{k(k+1)}{2}, \qquad k = \left\lfloor \frac{n}{m} \right\rfloor$$

### 3.3 算法流程

1. 计算 $total = \frac{n(n+1)}{2}$；
2. 计算 $k = \lfloor n/m \rfloor$（整数除法天然向下取整）；
3. 计算 $num_2 = m \cdot \frac{k(k+1)}{2}$；
4. 返回 $total - 2 \cdot num_2$。

### 3.4 示例演算

![示例演算：n=10, m=3](images/divisible_sums_walkthrough.svg)

$n = 10$，$m = 3$：

| 步骤 | 计算 | 结果 |
|------|------|------|
| total | 10×11/2 | 55 |
| k | ⌊10/3⌋ | 3 |
| num2 | 3×(3×4)/2 | 18 |
| num1 | 55 − 18 | 37 |
| 答案 | 37 − 18 | 19 ✓ |

## 4. 算法细节

1. **互补关系**：$num_1 + num_2 = 1 + 2 + \cdots + n$，因此只需分别求出 $total$ 与 $num_2$，无需单独枚举不可整除部分。
2. **num2 的封闭形式**：$[1, n]$ 内 $m$ 的倍数恰为 $m, 2m, \ldots, km$（$k = \lfloor n/m \rfloor$），提取公因子 $m$ 后剩 $1 + 2 + \cdots + k$。
3. **整数除法安全**：$n(n+1)$ 与 $k(k+1)$ 均为相邻整数之积，必为偶数，先乘后除不丢精度。
4. **数据范围**：$n \le 1000$ 时 $total \le 500500$，`int` 足够；公式法即使 $n$ 高达 $10^{18}$ 依然是 $O(1)$（需换 `long long`）。

## 5. 正确性证明

**引理 1**：$[1, n]$ 中能被 $m$ 整除的整数恰为 $m, 2m, \ldots, km$，其中 $k = \lfloor n/m \rfloor$。

**证明**：正整数 $i$ 能被 $m$ 整除当且仅当 $i = jm$（$j$ 为正整数）；而 $jm \le n$ 当且仅当 $j \le \lfloor n/m \rfloor$。故这些数恰为 $m, 2m, \ldots, km$。∎

**引理 2**：$num_2 = m \cdot \frac{k(k+1)}{2}$。

**证明**：由引理 1，$num_2 = m + 2m + \cdots + km = m(1 + 2 + \cdots + k) = m \cdot \frac{k(k+1)}{2}$。∎

**定理**：$num_1 - num_2 = \frac{n(n+1)}{2} - m \cdot k(k+1)$，其中 $k = \lfloor n/m \rfloor$。

**证明**：$[1, n]$ 中每个整数恰属于「可整除」「不可整除」两组之一，故 $num_1 + num_2 = 1 + 2 + \cdots + n = \frac{n(n+1)}{2}$。于是

$$num_1 - num_2 = (num_1 + num_2) - 2 \cdot num_2 = \frac{n(n+1)}{2} - m \cdot k(k+1)$$

（最后一处代入引理 2）。∎

## 6. 复杂度分析

- **时间复杂度**：$O(1)$。仅常数次乘除运算（循环写法为 $O(n)$，在 $n \le 1000$ 下同样通过）。
- **空间复杂度**：$O(1)$。只使用常数个变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int differenceOfSums(int n, int m) {
        int k = n / m;
        int total = n * (n + 1) / 2;
        int num2 = m * k * (k + 1) / 2;
        return total - 2 * num2;
    }
};
```

### Python

```python
class Solution:
    def differenceOfSums(self, n: int, m: int) -> int:
        k = n // m
        total = n * (n + 1) // 2
        num2 = m * k * (k + 1) // 2
        return total - 2 * num2
```

> 💡 比赛求快也可以一行模拟：`return sum(i if i % m else -i for i in range(1, n + 1))`。

## 8. 边界情况与易错点

1. **m > n**：$k = 0$，$num_2 = 0$，答案即 $total$（示例 2）。
2. **m = 1**：所有数都可整除，$num_1 = 0$，答案为 $-total$（示例 3）。
3. **负数结果**：答案可以为负，切勿取绝对值或对符号做特判。
4. **溢出**：本题 `int` 足够；若 $n$ 放大到 $10^9$ 级别需 `long long`（Python 无此问题）。
5. **除法取整**：$k$ 必须向下取整，C++ 整数除法与 Python `//` 均天然如此，但若用浮点除法再转整型需自行 `floor`。
