# LeetCode 建造街区的最短时间 题解

## 1. 题目概述

- **标题 / 题号**：建造街区的最短时间（#1199，hard）
- **链接**：https://leetcode.cn/problems/minimum-time-to-build-blocks/
- **来源**：LeetCode 第 9 场双周赛 Q4
- **难度**：困难
- **标签**：贪心、数组、数学、堆（优先队列）

**题意**：给定数组 `blocks`，$blocks[i] = t$ 表示建造第 $i$ 个街区需要 $t$ 单位时间；一个街区**恰好由一个工人**建造。初始只有一个工人，他每时刻可以选择：

- **分裂**：变成两个工人，耗时 `split`（多个工人同时分裂则各自并行耗时 `split`）；
- **建造**：挑一个未建的街区建完，然后**下班回家**（不能再工作）。

求把**所有**街区建完的最短总时间。

**约束**：

- $1 \le blocks.length \le 1000$
- $1 \le blocks[i] \le 10^5$
- $1 \le split \le 100$

## 2. 示例

**示例 1**

```text
输入：blocks = [1], split = 1
输出：1
解释：唯一的工人直接建这块街区，耗时 1。
```

**示例 2**

```text
输入：blocks = [1,2], split = 5
输出：7
解释：先分裂（5），两个工人各自建一块，总时间 5 + max(1,2) = 7。
```

**示例 3**

```text
输入：blocks = [1,2,3], split = 1
输出：4
解释：工人 A 分裂后建第 3 块；工人 B 再分裂，两个新工人建前两块。
      总时间 1 + max(3, 1 + max(1,2)) = 4。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的想法是「搜」：状态是（剩余街区集合、当前空闲工人数、已耗时），每次转移选择「某个工人建某块」或「某些工人分裂」，搜索空间指数爆炸，$n = 1000$ 完全不可行。

退一步想贪心也不行——两个朴素贪心都会错：

- 「能建就建」：示例 2 中一个工人顺序建完两块要 $1 + 2 = 3 < 7$，看似更快，但**每个工人只能建一块**，第二块必须等分裂出来的工人建，而「先建再分裂」是 $1 + 5 + 2 = 8$，不如「先分裂再并行」的 7；
- 「先分裂到够用」：示例 3 中 $split = 1$ 很便宜，但「无脑分裂」与「恰到好处的分裂链」得到的工期可以差出一截。

官方提示给出的出路是 DP：把街区排序后定义 $dp[i][j]$（前 $i$ 大的街区、$j$ 个工人的最短工期），配合两个交换性质（**要建就建最大的**、**要分裂就全体一起分裂**）做到 $O(n^2)$。这是稳妥的「正解」，本文把它作为对拍基准放在第 4 节；主解采用更漂亮的 $O(n \log n)$ 做法。

### 3.2 核心观察：分裂结构是一棵满二叉树，问题即「哈夫曼」

![核心观察：调度对应分裂二叉树，完工时间 = 深度·split + 建造时间](images/bw9_q4_split_tree_model.svg)

把整个调度过程画出来：每个「分裂事件」是一个**内部节点**（有两个孩子——分裂出的两个工人），每个「建造事件」是一个**叶子**（该工人建的那块街区）。由于每个工人恰好要么分裂要么建一块就退休，整个过程就是一棵 **$n$ 叶满二叉树**（$n-1$ 个内部节点、恰好 $n-1$ 次分裂）。

树上每个叶子的完工时间可以精确写出：

$$\text{finish}(\ell) = depth(\ell) \cdot split + blocks[\ell]$$

其中 $depth(\ell)$ 是叶子 $\ell$ 的**祖先中分裂节点的个数**——$\ell$ 必须等它路径上所有分裂依次串行完成（$depth \cdot split$）才能开工，之后独占工人建 $blocks[\ell]$。各叶子并行互不干扰，因此

$$\text{总工期} = \max_\ell \big(depth(\ell) \cdot split + blocks[\ell]\big).$$

**问题转化**：给 $n$ 个权值（街区耗时）分配一棵满二叉树的叶子，最小化「深度加权 + 权值」的最大值——直觉立刻浮现：**大块放浅处，小块沉深处**。这正是**哈夫曼编码**的骨架，只是合并函数从「两权之和」换成了

$$\mathrm{merge}(a, b) = split + \max(a, b).$$

合并的语义：最小的两个「子树完工时间」$a \le b$ 共享同一个分裂节点（成为最深处的一对兄弟），它们组成的子树对外表现为一个完工时间为 $split + \max(a,b)$ 的整体（分裂结束后两支并行，谁慢等谁）。

### 3.3 算法流程

![算法流程：小根堆反复合并两个最小值](images/bw9_q4_huffman_flow.svg)

```text
1. 把所有 blocks 放入小根堆
2. 当堆中元素个数 > 1：
   2.1 弹出最小的两个 a、b（a ≤ b）
   2.2 把 split + b 压回堆中        # 两块共享一次分裂：split + max(a,b)
3. 返回堆中剩下的唯一元素            # “超级块”的完工时间即总工期
```

以示例 3（blocks = [1,2,3]，split = 1）演算：堆 $\{1,2,3\}$ → 弹出 1、2，压回 $1 + \max(1,2) = 3$，堆 $\{3,3\}$ → 弹出 3、3，压回 $1 + 3 = 4$ → 答案 4。与示例一致。

### 3.4 示例演算

![示例演算：示例 3 的合并序列与对应时间线](images/bw9_q4_example_walkthrough.svg)

| 步骤 | 堆内容 | 动作 | 新权值 | 对应结构 |
|---|---|---|---|---|
| 初始 | {1, 2, 3} | — | — | 三个独立叶子 |
| 1 | {3, 3} | 合并 1、2 | $1 + \max(1,2) = 3$ | 叶 1、2 成兄弟，挂在深度 1 的分裂节点下 |
| 2 | {4} | 合并 3、3 | $1 + \max(3,3) = 4$ | 根分裂：左子树是街区 3（深度 1，完工 $1+3=4$），右子树是上一步的结构（深度 2，完工 $1+1+2=4$） |

对应的时间线：$t=0$ 根部分裂，$t=1$ 工人 A 建第 3 块（$1+3=4$ 完成）、工人 B 同时再分裂，$t=2$ 两个新工人分别建第 1、2 块（$2+2=4$ 完成）。总工期 $\max(4,4) = 4$ ✓。

再看示例 2（blocks = [1,2]，split = 5）：堆 $\{1,2\}$ → 合并得 $5 + 2 = 7$ ✓——两块共享一次分裂，分裂后并行，快的等慢的。

## 4. 算法细节

1. **合并函数必须是 $split + \max(a,b)$ 而不是 $split + a$ 或 $split + (a+b)$**：兄弟两支在共享分裂结束后**并行**，子树完工时间由较慢的一支决定，是 $\max$；与「合并果子」的求和完全不同，这是本题与经典哈夫曼唯一的差异点。
2. **弹出的两个里较大者决定新权值**，小根堆保证 $a \le b$，故写 $split + b$。
3. **$n = 1$ 时不需要任何分裂**，循环体不执行，直接返回唯一的块耗时。
4. **数值范围**：最坏深度 $n - 1 = 999$，总工期 $\le 999 \times 100 + 10^5 < 2 \times 10^5$，`int` 足够。
5. **官方 DP（对拍基准与替代解法）**：将 `blocks` 从大到小排序后定义
   $$dp[i][j] = \min\Big(\max\big(blocks[i],\ dp[i+1][j-1]\big),\ \ split + dp[i]\big[\min(2j,\ n-i)\big]\Big),$$
   第一项是「派一个工人立刻建最大的剩余块」（该工人耗时与剩余部分的工期取 max），第二项是「全体工人同时分裂」（$j \to \min(2j, n-i)$，多出的工人无用故封顶）。注意 $j$ 必须**从大到小**枚举，因为第二项依赖同层更大的 $j$。边界 $dp[n][j] = 0$，答案 $dp[0][1]$，复杂度 $O(n^2)$。
6. **两个交换性质**（DP 正确性的支柱，贪心证明同样要用）：(a) 派工人建块时建**当前最大**的块不劣；(b) 分裂时**全体**一起分裂不劣。二者都可交换论证。

## 5. 正确性证明

**引理 1（树模型等价）**：任意合法调度的总工期 $\ge \max_\ell \big(depth(\ell) \cdot split + blocks[\ell]\big)$；反之，对任意 $n$ 叶满二叉树，存在调度恰好取得该值。

**证明**：方向一：调度中每个叶 $\ell$ 的建造必须在其全部祖辈分裂完成之后才开始，而这些分裂在该分支上**串行**（儿子分裂必须等父亲分裂产出工人），故开工时刻 $\ge depth(\ell) \cdot split$，完工 $\ge depth(\ell) \cdot split + blocks[\ell]$，取最大得下界。方向二：给定树，按「每个工人一出现就立刻分裂（若它是内部节点）或立刻开建（若它是叶子）」调度：归纳可知深度 $k$ 的内部节点恰在时刻 $k \cdot split$ 开始分裂、其孩子在 $(k+1) \cdot split$ 时刻就位，深度 $d$ 的叶子恰在 $d \cdot split$ 开工、$d \cdot split + blocks[\ell]$ 完工，各分支互不抢资源，总工期恰为 $\max_\ell (depth(\ell) \cdot split + blocks[\ell])$。∎

**引理 2（兄弟归约）**：设树 $T$ 中叶子 $x \le y$（按时长）是同一个分裂节点的两个孩子。把「$x, y$ 及其父分裂节点」整体替换成一个权为 $split + \max(x,y)$ 的叶子得树 $T'$（其余结构不变），则 $\mathrm{cost}(T) = \mathrm{cost}(T')$ 对应的合并问题等价：对任意权值多重集 $W$，若 $x, y$ 是其最小两个元素，
$$\mathrm{opt}(W) = \mathrm{opt}\big(W \setminus \{x,y\} \cup \{split + \max(x,y)\}\big).$$

**证明**：原树 $T$ 中，以该分裂节点为根的子树完工时间恰为 $split + \max(x, y)$（分裂耗时 $split$，随后两支并行取 max），而树中其余叶子、其余分裂的深度不变。把子树缩成一个「完工时间 $split+\max(x,y)$、位于原深度」的叶子后，其余叶子贡献不变，该叶子在原深度 $k$ 处的完工为 $k \cdot split + (split + \max(x,y)) = (k+1) \cdot split + \max(x,y)$，与原子树在深度 $k$（其叶子在 $k+1$）的完工完全一致。因此两棵树的 $\max_\ell(depth \cdot split + w_\ell)$ 逐项相同。反过来，任何 $W'$ 的树把该叶子展开成「分裂 + 兄弟 $x,y$」即得 $W$ 的同价树。故两集合的最优值相等。∎

**引理 3（兄弟可安置）**：对任意权值多重集 $W$（$|W| \ge 2$），存在一棵最优树，使最小的两个权 $x \le y$ 是**兄弟**。

**证明**：取一棵最优树 $T$。第一步（单调化）：若存在叶子 $u, w$，$u$ 比 $w$ 浅（$depth(u) < depth(w)$）但权值 $weight(u) < weight(w)$，交换二者的权：交换只影响这两个叶子的完工时间，交换后两者分别为 $depth(u) \cdot s + weight(w)$ 与 $depth(d) \cdot s + weight(u)$。由 $weight(u) \le weight(w)$ 与 $depth(u) \le depth(d)$，两项都不超过交换前两项的最大值（$depth(u) \cdot s + weight(w) \le depth(d) \cdot s + weight(w)$；$depth(d) \cdot s + weight(u) \le depth(d) \cdot s + weight(w)$），故总工期不增。重复交换后可设**权值随深度不减**（浅者不小）。第二步（安置 $x$）：设 $D$ 为最大深度，由单调化，某最深叶子 $u$ 的权为 $x$（$x$ 是最小权，最深叶子处必是它，否则可交换到它）。设 $v$ 为 $u$ 的兄弟，$weight(v) = z$。若 $z = y$ 则证毕。否则把 $y$（当前在深度 $d_y \le D$）与 $v$ 的权互换：互换后 $y$ 在深度 $D$、$z$ 在深度 $d_y$。互换前后仅这两个位置变化，考察两处完工时间之和的最大值：互换前为 $\max\big(d_y \cdot s + y,\ D \cdot s + z\big)$，互换后为 $\max\big(D \cdot s + y,\ d_y \cdot s + z\big)$。由 $y \le z$（$y$ 是次小权）与 $d_y \le D$：$D \cdot s + y \le D \cdot s + z$ 且 $D \cdot s + y \ge d_y \cdot s + y$，而 $d_y \cdot s + z \le D \cdot s + z$，两个新值都不超过旧的最大值 $\max(d_y \cdot s + y,\ D \cdot s + z)$，故总工期不增。于是 $x$ 与 $y$ 成为最深处的一对兄弟。∎

**定理**：贪心算法（反复合并最小的两个）返回最优总工期。

**证明**：对 $n$ 归纳。$n = 1$ 平凡。设 $n \ge 2$，$x \le y$ 为最小两个权。由引理 3，存在最优树使 $x, y$ 同父；由引理 2，$\mathrm{opt}(W) = \mathrm{opt}(W')$，其中 $W' = W \setminus \{x,y\} \cup \{split + \max(x,y)\}$，且贪心第一步恰把 $W$ 变成 $W'$。$|W'| = n - 1$，由归纳假设贪心在 $W'$ 上的输出为 $\mathrm{opt}(W')$。故贪心输出 $= \mathrm{opt}(W') = \mathrm{opt}(W)$。∎

> 💡 这套「最小两个做兄弟 + 缩点归约 + 归纳」正是哈夫曼最优性证明的标准骨架；本题把合并函数换成 $split + \max$ 后，引理 3 的交换论证依然成立（$\max$ 的单调性起了关键作用）。

## 6. 复杂度分析

- **时间**：$O(n \log n)$。建堆 $O(n)$，$n - 1$ 次合并各 $O(\log n)$。$n = 1000$ 时仅约 $10^4$ 次堆操作，远优于 DP 的 $O(n^2) = 10^6$。
- **空间**：$O(n)$，即堆本身。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minBuildTime(vector<int>& blocks, int split) {
        priority_queue<int, vector<int>, greater<int>> pq(
            blocks.begin(), blocks.end());     // 小根堆
        while (pq.size() > 1) {
            int a = pq.top(); pq.pop();       // 最小的两个完工时间
            int b = pq.top(); pq.pop();
            pq.push(split + b);                // 共享一次 split：split + max(a, b)
        }
        return pq.top();                       // 只剩一个“超级块”，即总工期
    }
};
```

### Python

```python
class Solution:
    def minBuildTime(self, blocks: list[int], split: int) -> int:
        import heapq
        heap = list(blocks)
        heapq.heapify(heap)                 # 小根堆
        while len(heap) > 1:
            a = heapq.heappop(heap)         # 最小的两个完工时间
            b = heapq.heappop(heap)
            heapq.heappush(heap, split + b)  # 共享一次 split：split + max(a, b)
        return heap[0]                      # 只剩一个“超级块”，即总工期
```

## 8. 边界情况与易错点

1. **$n = 1$**：不需要分裂，返回 `blocks[0]`；循环条件 `size() > 1` 天然处理。
2. **合并函数写错**：写成 $split + a$（较小的）或 $split + a + b$ 都会错——兄弟是**并行**的，慢的决定工期，只能是 $split + \max(a,b)$。
3. **忘了每个工人只能建一块**：这是「必须分裂出 $n$ 个工人、恰 $n-1$ 次分裂」的根源；想成「一个工人顺序建多块」就会误判示例 2。
4. **分裂可以重叠进行**：题面明确多个工人同时分裂各耗时 `split`（并行），树模型中不同分支的分裂天然并行，时间线不冲突。
5. **DP 方向**：若实现官方 DP，$j$ 必须倒序枚举（依赖同层 $2j$）；分裂转移封顶 $\min(2j, n-i)$ 防止越界与无意义状态。
6. **溢出检查**：最大总工期 $(n-1) \cdot split + \max blocks \le 999 \times 100 + 10^5 < 2 \times 10^5$，`int` 安全。
7. **对拍是刚需**：本文将贪心与「满二叉树全排列枚举」（$n \le 6$）和官方 DP（随机 $n \le 80$）分别对拍数千组，全部一致；这类「交换论证型贪心」最容易被构造数据打脸，务必验证后再提交。
