# LeetCode 进击的骑士 题解

## 1. 题目概述

- **标题 / 题号**：进击的骑士（#1197，medium）
- **链接**：https://leetcode.cn/problems/minimum-knight-moves/
- **来源**：LeetCode 第 9 场双周赛 Q2
- **难度**：中等
- **标签**：广度优先搜索、双向搜索、A* 搜索

**题意**：在一张**无限大**的棋盘（坐标从 $-\infty$ 到 $+\infty$）上，一枚骑士位于 $[0, 0]$。骑士每步可走「一个坐标方向 2 格 + 正交方向 1 格」，共 8 种走法。求走到 $[x, y]$ 的**最少步数**（题目保证可达）。

**约束**：

- $|x| + |y| \le 300$

## 2. 示例

**示例 1**

```text
输入：x = 2, y = 1
输出：1
解释：[0,0] → [2,1]，一步到位。
```

**示例 2**

```text
输入：x = 5, y = 5
输出：4
解释：[0,0] → [2,1] → [4,2] → [3,4] → [5,5]。
```

**示例 3（补充）**

```text
输入：x = 0, y = 0
输出：0
```

## 3. 解题思路

### 3.1 暴力思路

「最少步数 + 每步代价相同」天然指向 **BFS**：从 $(0,0)$ 出发逐层扩展，第一次碰到 $(x,y)$ 时的层数即答案。麻烦在于棋盘是**无限**的——直接开数组会无从下手。朴素补救是在一个足够大的固定棋盘（如 $[-700, 700]^2$）上 BFS：按「每步每坐标至多走 2 格」估算，答案 $d \le 160$ 左右，半径 $2d$ 的正方形足以覆盖。这能过，但要白白搜索上百万个格子，Python 下相当吃力；而且「多大才够大」依赖于对答案上界的粗糙估计。

### 3.2 核心观察：对称性化简 + 有界搜索盒

![核心观察：四象限对称化简与搜索盒](images/bw9_q2_symmetry_box.svg)

观察一：**对称性**。8 种走法 $(\pm 1, \pm 2), (\pm 2, \pm 1)$ 关于两条坐标轴完全对称——把一条路径整体沿 $x$ 轴翻转，每步仍是合法骑士步。因此四个象限里的目标 $(x, y), (-x, y), (x, -y), (-x, -y)$ 的答案完全相同，可以先把目标化简到**第一象限** $(a, b) = (|x|, |y|)$。

观察二：**最短路不必走远**。向第一象限的目标走，最短路径至多在两条坐标轴外「借道 2 格」——存在一条最短路径，其上所有格子都落在搜索盒

$$B = [-2,\, a+2] \times [-2,\, b+2]$$

之内。为什么需要留负方向的余量？看 $(1,1)$：它的两步路径只能是 $(0,0) \to (2,-1) \to (1,1)$ 或 $(0,0) \to (-1,2) \to (1,1)$，**必然**穿过负半轴一格；同理 $(2,2)$ 的四步最优路径会用到 $y=4 = b+2$ 处的格子。盒子的正确性可以用「走法重排引理」证明（见第 5 节），我们对题面范围内的全部输入做了穷举对拍验证。

于是在一个不超过 $305 \times 305$ 的盒子里做普通 BFS 即可：状态有限、无需求助哈希表、代码干净。

### 3.3 算法流程

![算法流程：对称化简后在搜索盒内 BFS](images/bw9_q2_algorithm_flow.svg)

```text
1. a = |x|, b = |y|                          # 对称化简到第一象限
2. 搜索盒 B = [-2, a+2] × [-2, b+2]，开 dist 二维数组（初值 -1）
3. 队列初始化：dist[0][0] = 0，(0,0) 入队
4. BFS 循环：取出队首 (cx, cy)
   4.1 若 (cx, cy) == (a, b)：返回 dist
   4.2 对 8 个方向 (dx, dy)：
       新格 (nx, ny) 在盒内且未访问 → dist = 当前+1，入队
5. （题目保证有解，循环必在第 4.1 步返回）
```

## 4. 算法细节

1. **对称化简只对目标做**：BFS 仍从 $(0,0)$ 出发、照常向 8 个方向扩展；化简只是把「搜向哪个象限」统一成第一象限，搜索盒因此可以做成以目标为锚的小矩形。
2. **dist 用二维数组而不是哈希表**：盒子大小已知（$(a+5) \times (b+5)$），数组下标加偏移 `+2` 即可，常数远小于哈希表；这也是相对「无界哈希 BFS」的主要提速点。
3. **命中即返回**：出队时判断是否为目标。因为 BFS 按层出队，第一次出队该格时的距离就是最短距离。
4. **边界判断合一**：越界（出盒）与已访问都直接跳过，两者都写在同一组条件里，减少嵌套。
5. **搜索盒的余量取 2 的依据**：$(1,1)$ 型目标（借道 1 格）与 $(2,2)$ 型目标（上探 $b+2$）说明余量 1 在下侧不够、余量 2 恰好覆盖；本文验证环节对 $a+b \le 300$ 的**全部** 45 451 个本质输入做了穷举对拍（盒子 BFS 对比 $[-400,400]^2$ 大棋盘 BFS 与经典距离公式），三方完全一致。
6. **复杂度与目标形态有关**：最坏出现在 $a=b=150$，盒子 $155 \times 155 \approx 2.4 \times 10^4$ 格；而 $(300, 0)$ 的盒子只有 $305 \times 5$，非常小。

## 5. 正确性证明

**引理 1（对称性）**：设 $\rho(u, v) = (|u|, v)$（沿 $x$ 轴的镜像）。则 $\rho$ 是无限骑士图的保邻映射，从而 $d\big((0,0), (x, y)\big) = d\big((0,0), (|x|, y)\big)$；对 $y$ 同理。

**证明**：8 种骑士步的集合 $M = \{(\pm 1, \pm 2), (\pm 2, \pm 1)\}$ 关于「第一分量取反」封闭：$(1, 2) \leftrightarrow (-1, 2)$、$(2, 1) \leftrightarrow (-2, 1)$ 等。因此若 $(u, v) \to (u + m_x, v + m_y)$ 是一条骑士步，则 $\rho(u, v) \to \rho(u + m_x, v + m_y)$ 也对应一条骑士步（$m_x \ne 0$ 时分量取反仍在 $M$ 中）。于是任意一条 $(0,0) \to (x,y)$ 的 $d$ 步路径逐点镜像后得到一条 $(0,0) \to (|x|, y)$ 的 $d$ 步路径，反之亦然（镜像的对合性），两方向距离相等。∎

**引理 2（基本下界与奇偶性）**：设 $d = d\big((0,0),(a,b)\big)$，$a, b \ge 0$，则

$$d \ge \left\lceil \frac{\max(a,b)}{2} \right\rceil, \qquad d \ge \left\lceil \frac{a+b}{3} \right\rceil, \qquad d \equiv a + b \pmod 2 .$$

**证明**：每步 $x$ 坐标至多变化 2，故 $a \le \sum |m_x| \le 2d$；每步 $|m_x| + |m_y| = 3$，故 $a + b \le \sum (m_x + m_y) \le \sum (|m_x| + |m_y|) = 3d$。又每步 $m_x + m_y \in \{\pm 1, \pm 3\}$ 均为奇数，故每走一步 $u+v$ 的奇偶性翻转一次，$d$ 步后 $u + v \equiv a + b \pmod 2$ 当且仅当 $d \equiv a+b \pmod 2$。∎

**引理 3（搜索盒引理）**：对任意 $a, b \ge 0$，存在一条从 $(0,0)$ 到 $(a,b)$ 的最短路径，其上所有格子都落在 $B = [-2, a+2] \times [-2, b+2]$ 内。

**证明思路**：关键是「走法重排」——一条路径就是走法（多重集合 $S$，$\sum S = (a,b)$）的一个排列，重排后仍是同样长度的合法路径，因此只需证明**存在**一个良性的排列。一维重排引理：若整数 $e_1, \ldots, e_d \in [-2, 2]$ 且 $\sum e_i \ge 0$，则按从大到小排列后所有前缀和 $\ge -2$。这是因为若某前缀和 $\le -3$，则后缀和 $\ge 3$，后缀中必有元素 $\ge 1$，从而**每个**前缀元素（都 $\ge$ 每个后缀元素）$\ge 1$，前缀和 $\ge k \ge 1$，矛盾。把它沿 $x$、$y$ 两个方向以及时间反演方向综合运用（配合 $(1,1)$、$(2,2)$ 等小目标的手工构造），即得二维版本的盒子界。完整的组合证明篇幅较长（本质是二维 Steinitz 型引理），此处从略；鉴于本题输入域是有限集（$|x|+|y| \le 300$，对称化后共 45 451 个本质输入），我们对**全部**输入做了穷举验证：盒内 BFS 的输出与 $[-400, 400]^2$ 大棋盘 BFS、与经典骑士距离公式（见延伸思考，其下界部分即引理 2）三方完全一致。∎

**定理**：算法返回 $(0,0)$ 到 $(x,y)$ 的最少步数。

**证明**：由引理 1，答案等于 $(0,0)$ 到 $(a,b) = (|x|,|y|)$ 的距离 $d$。BFS 运行在盒子 $B$ 的诱导子图上，返回值 $d_B \ge d$（子图中的路径都是全图路径）。由引理 3，存在长度恰为 $d$ 的路径整条落在 $B$ 内，故 BFS 必然在距离 $d$ 处发现目标，即 $d_B \le d$。二者结合 $d_B = d$。∎

## 6. 复杂度分析

- **时间**：$O\big((a+5)(b+5)\big)$。盒子大小即状态数，每个状态 8 条出边。约束 $a + b \le 300$ 下最坏 $155 \times 155 \approx 2.4 \times 10^4$ 个格子（$a=b=150$ 时），C++ 毫秒级，Python 也在几十毫秒内。
- **空间**：$O\big((a+5)(b+5)\big)$，即 `dist` 数组本身。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minKnightMoves(int x, int y) {
        x = abs(x);
        y = abs(y);                              // 对称性：四个象限完全等价
        int lo = -2, hiX = x + 2, hiY = y + 2;   // 搜索盒 [-2, x+2] × [-2, y+2]
        int W = hiX - lo + 1, H = hiY - lo + 1;
        vector<vector<int>> dist(W, vector<int>(H, -1));
        queue<pair<int, int>> q;
        dist[0 - lo][0 - lo] = 0;
        q.push({0, 0});
        static const int dx[8] = {1, 1, -1, -1, 2, 2, -2, -2};
        static const int dy[8] = {2, -2, 2, -2, 1, -1, 1, -1};
        while (!q.empty()) {
            pair<int, int> cur = q.front();
            q.pop();
            int cx = cur.first, cy = cur.second;
            if (cx == x && cy == y) return dist[cx - lo][cy - lo];
            for (int k = 0; k < 8; ++k) {
                int nx = cx + dx[k], ny = cy + dy[k];
                if (nx < lo || nx > hiX || ny < lo || ny > hiY) continue;
                if (dist[nx - lo][ny - lo] != -1) continue;
                dist[nx - lo][ny - lo] = dist[cx - lo][cy - lo] + 1;
                q.push({nx, ny});
            }
        }
        return -1;    // 题目保证有解，不会走到这里
    }
};
```

### Python

```python
class Solution:
    def minKnightMoves(self, x: int, y: int) -> int:
        x, y = abs(x), abs(y)                  # 对称性：四个象限完全等价
        lo = -2                                # 搜索盒 [-2, x+2] × [-2, y+2]
        w, h = x + 2 - lo + 1, y + 2 - lo + 1
        dist = [[-1] * h for _ in range(w)]
        dist[0 - lo][0 - lo] = 0
        q = [(0, 0)]
        head = 0
        while head < len(q):
            cx, cy = q[head]
            head += 1
            if cx == x and cy == y:
                return dist[cx - lo][cy - lo]
            for dx, dy in ((1, 2), (1, -2), (-1, 2), (-1, -2),
                           (2, 1), (2, -1), (-2, 1), (-2, -1)):
                nx, ny = cx + dx, cy + dy
                if (lo <= nx <= x + 2 and lo <= ny <= y + 2
                        and dist[nx - lo][ny - lo] == -1):
                    dist[nx - lo][ny - lo] = dist[cx - lo][cy - lo] + 1
                    q.append((nx, ny))
        return -1    # 题目保证有解，不会走到这里
```

## 8. 边界情况与易错点

1. **目标就是原点**：$(0,0)$ 应返回 0；出队时先判再扩展，天然覆盖。
2. **负坐标必须先取绝对值**：搜索盒以「目标在第一象限」为前提，忘掉 `abs` 会直接越界或搜不到。
3. **搜索盒余量不能小于 2**：$(1,1)$ 的两步路径必然穿过 $(2,-1)$ 或 $(-1,2)$，余量 0 或 1 的盒子会把它「拦住」，得到偏大的答案。
4. **盒子上界记得 +2**：$(2,2)$ 的最优路径会用到 $y = 4 = b+2$ 处的格子。
5. **用数组而非哈希表**：盒子大小可静态确定，`dist` 数组 + 下标偏移（`- lo`）比哈希表快数倍，也避免哈希冲突的坑。
6. **别用 DFS**：DFS 求的是可达性而非最短步数，步数统计会出错；DFS + 逐层迭代（IDDFS）正确但重复扩展，效率远差于 BFS。
7. **答案规模**：约束内最大答案出现在 $(300, 0)$ 型目标，为 150；`int` 足够。
8. **工程习惯**：写完这类「有界化」的搜索，务必与大棋盘无剪枝 BFS 对拍——本文对全部输入域做了穷举对拍，这也是发现「余量不足」类错误的唯一可靠手段。
