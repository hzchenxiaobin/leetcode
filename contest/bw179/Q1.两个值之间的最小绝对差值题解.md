# LeetCode 两个值之间的最小绝对差值 题解

## 1. 题目概述

- **标题 / 题号**：两个值之间的最小绝对差值（#3880，easy）
- **链接**：https://leetcode.cn/problems/minimum-absolute-difference-between-two-values/
- **来源**：LeetCode 第 179 场双周赛 Q1
- **难度**：简单
- **标签**：数组、枚举

**题意**：给定只含 $0,1,2$ 的整数数组 `nums`。若 $nums[i] = 1$ 且 $nums[j] = 2$，称下标对 $(i,j)$ 是**有效**的。返回所有有效下标对中 $|i-j|$ 的**最小值**；若不存在有效下标对，返回 $-1$。

**约束**：

- $1 \le \text{nums.length} \le 100$
- $0 \le nums[i] \le 2$

## 2. 示例

**示例 1**

```text
输入：nums = [1,0,0,2,0,1]
输出：2
解释：有效数对有 (0,3) 差 3、(5,3) 差 2；最小值为 2。
```

**示例 2**

```text
输入：nums = [1,0,1,0]
输出：-1
解释：数组里没有 2，构不成任何有效数对。
```

## 3. 解题思路

### 3.1 暴力思路

两层循环枚举所有下标对 $(i,j)$，若 $nums[i]=1$ 且 $nums[j]=2$ 就用 $|i-j|$ 更新答案。复杂度 $O(n^2)$，$n \le 100$ 完全可行。

但它做了大量无用功：对于每个 1，我们其实只需要看它**左右两侧最近的那个 2**，更远的 2 一定给出更大的距离。

### 3.2 核心观察：答案只与「最近的对方」有关

![最小绝对差值：边扫边记「最近的 1」和「最近的 2」](images/bw179_q1_last_seen.svg)

一边从左往右扫描，一边维护两个量：

- `last1`：截至当前位置，**最近一次**出现 1 的下标；
- `last2`：截至当前位置，**最近一次**出现 2 的下标。

每扫描到一个位置：

- 如果它是 1，就更新 `last1 = i`；
- 如果它是 2，就更新 `last2 = i`；
- 更新之后，若两个量都已被赋过值，就用 $|last1 - last2|$ 更新答案。

**为什么「最近的」就够？** 假设当前在位置 $i$ 遇到 1，此前出现过若干 2，位置分别是 $j_1 < j_2 < \dots < j_m < i$。距离 $|i - j|$ 随 $j$ 增大而减小，所以 $j_m$（最近的 2）给出最小距离；其它 2 都不可能更优。对称地，遇到 2 时只需看最近的 1。

> 💡 **一个重要细节**：只有当**当前位置本身是 1 或 2**时，才需要更新答案。若当前位置是 0，`last1`、`last2` 都没变，再算一次 $|last1-last2|$ 不会带来新信息（结果与上一次相同），所以跳过也无妨。

### 3.3 算法流程

![算法流程：一次扫描维护最近位置](images/bw179_q1_flow.svg)

```text
1. last1 = last2 = -1，best = +∞
2. for i = 0 .. n-1:
3.     若 nums[i] == 1: last1 = i
4.     若 nums[i] == 2: last2 = i
5.     若 last1 >= 0 且 last2 >= 0: best = min(best, |last1 - last2|)
6. 返回 best 未被更新过 ? -1 : best
```

### 3.4 示例演算

对示例 1 的 `nums = [1,0,0,2,0,1]`：

| 位置 | 值 | `last1` | `last2` | $\lvert \cdot \rvert$ | `best` |
|------|----|---------|---------|----------------------|--------|
| 0 | 1 | 0 | −1 | — | +∞ |
| 1 | 0 | 0 | −1 | — | +∞ |
| 2 | 0 | 0 | −1 | — | +∞ |
| 3 | 2 | 0 | 3 | 3 | 3 |
| 4 | 0 | 0 | 3 | 3 | 3 |
| 5 | 1 | 5 | 3 | 2 | **2** |

返回 2 ✓。示例 2 中 `2` 从未出现，`last2` 始终为 $-1$，答案从未更新，返回 $-1$ ✓。

## 4. 算法细节

1. **初值用 $-1$ 当哨兵**：$-1$ 不是合法下标，天然表示「还没出现过」，判定时用 `>= 0` 即可。
2. **`best` 的初值**：用 `+∞`（或一个足够大的数，如 $10^9$）。最后若仍是 $+\infty$ 就返回 $-1$。
3. **更新顺序**：先更新 `last1`/`last2`，再算答案——否则当前位置的贡献会漏掉。
4. **只有一个值时**：`last1` 或 `last2` 有且仅有一个被赋值，永远不会进入更新分支。
5. **不需要额外数组**：状态只有两个下标和一个答案，空间 $O(1)$。

## 5. 正确性证明

**记号**：设扫描到位置 $i$ 时，$L_1(i)$ 表示 $\le i$ 范围内最大的、值为 1 的下标（不存在时为 $-1$），$L_2(i)$ 同理（值为 2）。

**引理 1（`last` 记录正确）**：扫描完位置 $i$ 后，`last1` $= L_1(i)$，`last2` $= L_2(i)$。

**证明**：对 $i$ 归纳。$i = -1$（初始）时两个量都是 $-1$，符合定义。若扫描完 $i-1$ 时成立，则处理位置 $i$：若 $nums[i]=1$，`last1` 被更新为 $i$，而 $i$ 是 $\le i$ 中最大的 1，故仍正确；若 $nums[i] \ne 1$，`last1` 保持 $L_1(i-1)$，而由于 $\le i$ 中除 $i$ 外没有新的 1，$L_1(i) = L_1(i-1)$，仍正确。`last2` 同理。∎

**引理 2（最近者最优）**：设 $i$ 为某个值为 1 的位置，$j_1 < j_2 < \dots < j_m$ 是 $i$ 左侧所有值为 2 的位置。则 $\min_t |i - j_t| = i - j_m$。

**证明**：所有 $j_t < i$，故 $|i-j_t| = i - j_t$，它随 $j_t$ 严格递减，故最小值在最大的 $j_t = j_m$ 处取得。∎

**引理 3（不遗漏）**：任一有效数对 \((i,j)\)（\(nums[i]=1\)、\(nums[j]=2\)）的距离都已被算法在某个时刻以「不大于它的候选值」考虑过，即算法运行结束时 `best` $\le |i-j|$。

**证明**：设 $i < j$（$i > j$ 的情形对称）。在扫描到位置 $j$ 时，$nums[j] = 2$，`last2` 被更新为 $j$；而 $i \le j$ 且 $nums[i] = 1$，由引理 1，此时 `last1` 是 $\le j$ 范围内最大的 1 下标，故 `last1` $\ge i$。于是算法在该步用 $|last1 - j| = j - last1 \le j - i = |i-j|$ 更新 `best`，得到不大于原数对距离的值。∎

**定理**：存在有效数对时，算法返回所有有效数对距离的最小值；否则返回 $-1$。

**证明**：

- *下界*：算法每次更新 `best` 用的都是某个 1 与某个 2 的下标差，即某个有效数对的距离，所以 `best` 不可能小于真实最小值。
- *上界*：设最优数对为 $(i^*, j^*)$。由引理 3，算法在扫描到 $\max(i^*,j^*)$ 时会得到一个不大于 $|i^*-j^*|$ 的值；结合下界，`best` 恰好等于最小值。
- *无解*：若不存在有效数对，则 1 与 2 至少有一类从未出现，`last1`、`last2` 中至少有一个恒为 $-1$，更新分支永不进入，`best` 保持 $+\infty$，返回 $-1$。∎

## 6. 复杂度分析

- **时间**：$O(n)$，一遍扫描，每个位置常数次比较。
- **空间**：$O(1)$，只有 `last1`、`last2`、`best` 三个变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minAbsoluteDifference(vector<int>& nums) {
        int best = -1;
        int last1 = -1, last2 = -1;
        for (int i = 0; i < (int)nums.size(); i++) {
            if (nums[i] == 1) last1 = i;
            else if (nums[i] == 2) last2 = i;
            if (last1 >= 0 && last2 >= 0) {
                int d = abs(last1 - last2);
                if (best == -1 || d < best) best = d;
            }
        }
        return best;
    }
};
```

### Python

```python
class Solution:
    def minAbsoluteDifference(self, nums: list[int]) -> int:
        best = -1
        last1 = last2 = -1
        for i, v in enumerate(nums):
            if v == 1:
                last1 = i
            elif v == 2:
                last2 = i
            if last1 >= 0 and last2 >= 0:
                d = abs(last1 - last2)
                if best == -1 or d < best:
                    best = d
        return best
```

## 8. 边界情况与易错点

1. **只有 1 没有 2（或反之）**：如 `[1,0,1,0]`，返回 $-1$。哨兵初值 $-1$ 配合 `>= 0` 判定即可正确排除。
2. **`last` 是「最近一次」而不是「第一次」**：若写成记录首次出现的位置，会得到偏大的距离。示例 1 的 $(5,3)$ 就依赖 3 是「最近的 2」。
3. **更新顺序**：先更新状态再算差值。若先算差值再更新，当前位置就白扫了。
4. **同一个位置不可能既是 1 又是 2**，所以不存在 $|i-j| = 0$ 的情况，答案最小是 1。
5. **`best` 的哨兵值**：用 `10^9` 之类足够大即可（$n \le 100$，距离最大 99）；用 `INT_MAX` 时注意别在 `min` 里做加法。
6. **数组只有一个元素**：循环只跑一次，两类值中必有一类缺失，返回 $-1$。
