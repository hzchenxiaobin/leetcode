# LeetCode 网格图中最小异或路径 题解

## 1. 题目概述

- **标题 / 题号**：网格图中最小异或路径（#3882，medium）
- **链接**：https://leetcode.cn/problems/minimum-xor-path-in-a-grid/
- **来源**：LeetCode 第 179 场双周赛 Q3
- **难度**：中等
- **标签**：位运算、数组、动态规划、矩阵

**题意**：给定 $m \times n$ 的非负整数矩阵 `grid`。从左上角 $(0,0)$ 出发，每步只能**向右或向下**，走到右下角 $(m-1,n-1)$。路径代价定义为路径上**所有格子**（含起点与终点）取值的**按位异或**。返回所有合法路径中代价的**最小值**。

**约束**：

- $1 \le m, n \le 1000$，且 $m \times n \le 1000$
- $0 \le grid[i][j] \le 1023$

## 2. 示例

**示例 1**

```text
输入：grid = [[1,2],[3,4]]
输出：6
解释：两条路径：
      (0,0)→(0,1)→(1,1)：1 ^ 2 ^ 4 = 7
      (0,0)→(1,0)→(1,1)：1 ^ 3 ^ 4 = 6
      最小值为 6。
```

**示例 2**

```text
输入：grid = [[6,7],[5,8]]
输出：9
解释：6^7^8 = 9；6^5^8 = 11。最小 9。
```

**示例 3**

```text
输入：grid = [[2,7,5]]
输出：0
解释：只有一条路径，2 ^ 7 ^ 5 = 0。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有从左上到右下的路径：共 $\binom{m+n-2}{m-1}$ 条，每条算一次异或。$m,n$ 都可到 1000（虽然 $mn \le 1000$ 限制了总量，但例如 $2 \times 500$ 时有 $\binom{500}{1} = 500$ 条还算少，$31\times32$ 时约 $\binom{61}{30} \approx 10^{17}$ 条，直接爆炸）。

暴力不可行的根本原因是**路径数指数级**，但路径的「异或值」取值范围很小。

### 3.2 核心观察：状态不是「最大值」，而是「可达异或值集合」

![每格维护「可达异或值集合」，从上、左两格合并](images/bw179_q3_state_sets.svg)

普通网格 DP 存的是「到某格的最优值」，但异或**不满足最优子结构**：到 $(i,j)$ 的异或值小，不代表继续走下去能更小（异或会把高位翻来翻去）。例如 $x_1 = 1$、$x_2 = 8$，与 $7$ 异或后得到 $6$ 和 $15$，小的那个反而变大了。

所以正确做法是**把「所有可能性」都存下来**：

$$\text{dp}[i][j] = \{\text{从 } (0,0) \text{ 到 } (i,j) \text{ 的所有路径的异或值}\}$$

转移非常直接：一条到 $(i,j)$ 的路径，最后一步要么从上面 $(i-1,j)$ 来、要么从左边 $(i,j-1)$ 来，因此

$$\text{dp}[i][j] = \{\, x \oplus grid[i][j] \;:\; x \in \text{dp}[i-1][j] \cup \text{dp}[i][j-1] \,\}$$

起点单独处理：$\text{dp}[0][0] = \{grid[0][0]\}$。答案是 $\text{dp}[m-1][n-1]$ 中的最小值。

**状态量有多大？** 约束给出 $grid[i][j] \le 1023 = 2^{10}-1$，异或只是把 10 个二进制位翻来翻去，结果一定 $< 1024$。所以每个格子的集合最多 1024 个元素，总状态量 $mn \cdot 1024 \le 10^6$，完全可控。

### 3.3 算法流程

![实现：把「集合」写成 0/1 数组（或 bitset）](images/bw179_q3_bitset.svg)

```text
1. N = 大于 max(grid) 的最小 2 的幂        # 保证 x ^ v < N
2. dp[i][j] = 长度 N 的 0/1 数组（或 set）
3. dp[0][0][ grid[0][0] ] = 1
4. for i in 0..m-1:
5.     for j in 0..n-1:
6.         若 (i,j) == (0,0): 跳过
7.         v = grid[i][j]
8.         for x in 0..N-1:
9.             若 dp[i-1][j][x] 或 dp[i][j-1][x]:   dp[i][j][x ^ v] = 1
10. 返回最小的 x 使 dp[m-1][n-1][x] = 1
```

### 3.4 示例演算

对示例 1 的 `grid = [[1,2],[3,4]]`：

| 格子 | 值 | 来源 | 可达异或集合 |
|------|----|------|-------------|
| (0,0) | 1 | 起点 | $\{1\}$ |
| (0,1) | 2 | 左格 $\{1\}$ | $\{1 \oplus 2\} = \{3\}$ |
| (1,0) | 3 | 上格 $\{1\}$ | $\{1 \oplus 3\} = \{2\}$ |
| (1,1) | 4 | 上格 $\{3\}$ ∪ 左格 $\{2\}$ | $\{3\oplus4,\ 2\oplus4\} = \{7,6\}$ |

终点集合为 $\{7,6\}$，最小值 6 ✓。示例 2 同理得到 $\{9,11\}$，取 9 ✓。示例 3 只有一行，逐格只有一个元素：$2 \to 2\oplus7=5 \to 5\oplus5=0$，答案 0 ✓。

## 4. 算法细节

1. **状态表示**：C++ 用 `vector<vector<vector<char>>>`（每格 $N$ 个字节，总量约 1 MB）或 `bitset<1024>`（更省内存，但异或操作不是简单的位移，需要手写位重排，可读性差）。Python 用 `set`（元素最多 1024，实测很快）或整数 bitset。
2. **值域上界 N**：取大于等于 $\max grid + 1$ 的最小 2 的幂。因为 $grid \le 1023$，$N = 1024$；写成「动态计算」可以避免硬编码，也能处理更大值域（只要 $N$ 不大）。
3. **起点初始化**：`dp[0][0]` 直接置 `{grid[0][0]}`，并在循环中跳过它，避免把它当成「从上/左转移」。
4. **合并顺序**：先 `dp[i-1][j]` 再 `dp[i][j-1]`，顺序无关；重点是 `x ^ v` 只做一次映射。
5. **不可达格子**：`dp[i][j]` 若为空集合，表示该格不可达（本题每个格子都可达，但写成通用逻辑更稳）。
6. **滚动数组**：$mn \le 1000$ 时没必要，但若要支持大网格，可只保留两行（`prev`, `cur`），空间降到 $O(nN)$。

## 5. 正确性证明

**引理 1（集合转移完备）**：对每个格子 $(i,j)$，算法结束时 $\text{dp}[i][j]$ 恰为「从 $(0,0)$ 到 $(i,j)$ 的所有合法路径的异或值」构成的集合。

**证明**：对 $i+j$ 归纳。

- 基础：$i+j = 0$ 即 $(0,0)$，只有一条「原地」路径，异或值为 $grid[0][0]$，与初始化一致。
- 归纳：设对所有 $i'+j' < i+j$ 成立。任取一条到 $(i,j)$ 的路径 $P$，它的最后一步来自 $(i-1,j)$ 或 $(i,j-1)$（记为 $(i',j')$），且 $P$ 去掉最后一格后是到 $(i',j')$ 的合法路径，由归纳假设其异或值 $x \in \text{dp}[i'][j']$。于是 $P$ 的异或值为 $x \oplus grid[i][j]$，被算法第 8–9 行加入 $\text{dp}[i][j]$。反之，任何被加入的 $x \oplus grid[i][j]$ 都来自某个 $\text{dp}[i'][j']$ 中的 $x$，由归纳假设存在到 $(i',j')$ 的路径，接上 $(i,j)$ 即为到 $(i,j)$ 的合法路径。故两侧互相包含。∎

**引理 2（值域封闭）**：若 $N$ 是不小于 $\max(grid)+1$ 的 2 的幂，则所有可达异或值都落在 $[0, N)$。

**证明**：$N$ 是 2 的幂 ⟹ 任意 $a,b < N$ 都有 $a \oplus b < N$（异或不会产生高于 $N$ 最高位的比特）。起点 $grid[0][0] < N$，归纳可知所有中间异或值 $< N$。∎

**定理**：算法输出的最小值等于所有合法路径代价的最小值。

**证明**：由引理 1，终点集合恰为全部合法路径的异或值集合；集合非空（至少存在一条「一直向右再一直向下」的路径），故最小值存在。取集合最小值即在所有路径代价中取最小值。∎

## 6. 复杂度分析

- **时间**：$O(mnN)$。每个格子对 $N$ 个可能值扫一遍，$mn \le 1000$、$N \le 1024$，约 $10^6$ 次操作。若用 `set` 实现，复杂度为 $O(mn \cdot |S|)$，$|S|$ 为集合大小（同样的上界）。
- **空间**：$O(mnN)$ 的字符数组（约 1 MB）；用两行滚动可降到 $O(nN)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minCost(vector<vector<int>>& grid) {
        int m = (int)grid.size(), n = (int)grid[0].size();
        int maxV = 0;
        for (auto& row : grid)
            for (int v : row) maxV = max(maxV, v);
        int N = 1;
        while (N <= maxV) N <<= 1;

        vector<vector<vector<char>>> dp(m, vector<vector<char>>(n, vector<char>(N, 0)));
        dp[0][0][grid[0][0]] = 1;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (i == 0 && j == 0) continue;
                int v = grid[i][j];
                for (int x = 0; x < N; x++) {
                    bool ok = false;
                    if (i > 0 && dp[i - 1][j][x]) ok = true;
                    if (j > 0 && dp[i][j - 1][x]) ok = true;
                    if (ok) dp[i][j][x ^ v] = 1;
                }
            }
        }
        for (int x = 0; x < N; x++)
            if (dp[m - 1][n - 1][x]) return x;
        return -1;
    }
};
```

### Python

```python
class Solution:
    def minCost(self, grid: list[list[int]]) -> int:
        m, n = len(grid), len(grid[0])
        dp = [[set() for _ in range(n)] for _ in range(m)]
        dp[0][0] = {grid[0][0]}
        for i in range(m):
            for j in range(n):
                if i == 0 and j == 0:
                    continue
                reach = set()
                if i > 0:
                    reach |= dp[i - 1][j]
                if j > 0:
                    reach |= dp[i][j - 1]
                v = grid[i][j]
                dp[i][j] = {x ^ v for x in reach}
        return min(dp[m - 1][n - 1])
```

## 8. 边界情况与易错点

1. **异或没有最优子结构**：不能用「到每格的最小异或」做 DP。反例：到某格的两条路径异或值分别是 $1$ 和 $8$，下一格的值是 $8$，则 $1\oplus8=9$、$8\oplus8=0$——**小的那个反而变成了大的**，只保留最小值会得到 9，而真正的最优是 0。必须保留整个集合。
2. **单行 / 单列**：路径唯一，答案是所有元素的异或，直接跑 DP 也正确，不需要特判。
3. **起点等于终点（$1\times1$）**：答案是 $grid[0][0]$ 本身。代码中起点已初始化，循环跳过它，能正确返回。
4. **值域上界**：若硬编码 1024 而实际值域更大就会越界。稳妥做法是按 $\max grid$ 动态算 2 的幂。
5. **`x ^ v` 的下标**：异或结果一定 $< N$（引理 2），否则需要扩容；但若 $N$ 取得过小（例如取成 $\max grid$ 本身而不是 2 的幂），就会越界。
6. **空集合**：若某格不可达，其集合为空，转移时不应把空集合当成「含 0」。本题网格全可达，但要写对循环条件。
