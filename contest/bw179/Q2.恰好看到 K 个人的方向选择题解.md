# LeetCode 恰好看到 K 个人的方向选择 题解

## 1. 题目概述

- **标题 / 题号**：恰好看到 K 个人的方向选择（#3881，medium）
- **链接**：https://leetcode.cn/problems/direction-assignments-with-exactly-k-visible-people/
- **来源**：LeetCode 第 179 场双周赛 Q2
- **难度**：中等
- **标签**：数学、组合数学

**题意**：$n$ 个人排成一排，下标 $0 \sim n-1$，每个人**独立**选择方向：

- `'L'`：只对他们**右边**的人可见；
- `'R'`：只对他们**左边**的人可见。

站在下标 `pos` 的人观察其他人：

- 位于 $i < pos$ 的人**可见**当且仅当他选了 `'L'`；
- 位于 $i > pos$ 的人**可见**当且仅当他选了 `'R'`。

返回使 `pos` 处的人**恰好看到 $k$ 个人**的方向分配方案数，对 $10^9+7$ 取模。

**约束**：

- $1 \le n \le 10^5$
- $0 \le pos, k \le n-1$

## 2. 示例

**示例 1**

```text
输入：n = 3, pos = 1, k = 0
输出：2
解释：左侧只有下标 0，右侧只有下标 2。要看到 0 人：0 必须选 R、2 必须选 L。
      pos=1 自己选 L 或 R 都不影响计数 → 2 种方案。
```

**示例 2**

```text
输入：n = 3, pos = 2, k = 1
输出：4
解释：左侧有下标 0、1 两人，右侧无人。要看到 1 人：两人中恰好一个选 L（2 种选法）。
      每种选法下 pos=2 自己还有 2 种方向 → 2 × 2 = 4。
```

**示例 3**

```text
输入：n = 1, pos = 0, k = 0
输出：2
解释：只有一个人，看不到任何人；他自己的方向随意 → L 或 R 共 2 种。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有 $2^n$ 种方向分配，逐种统计 `pos` 能看到几个人并检查是否等于 $k$。复杂度 $O(2^n \cdot n)$，$n \le 10^5$ 时完全不可行，只能用于 $n \le 10$ 的对拍。

### 3.2 核心观察：左右两侧互不干扰，答案是一个组合和

![把人数拆成左右两段：左段选 L 可见，右段选 R 可见](images/bw179_q2_split.svg)

把除 `pos` 之外的人按位置分成两段：

- **左段**：$a = pos$ 个人（下标 $0 \sim pos-1$）；
- **右段**：$b = n - 1 - pos$ 个人（下标 $pos+1 \sim n-1$）。

观察到两件关键事实：

1. **可见人数 = 左段选 L 的人数 + 右段选 R 的人数**。左段的人选 `L` 才可见、选 `R` 不可见；右段相反。两段的选择互不影响，可见人数就是两段贡献之和。
2. **`pos` 本人的方向不影响任何人是否可见**。可见性规则里根本没有出现 `pos` 自己的方向：左段可见与否只看左段人自己的选择，右段同理。所以 `pos` 有 **2** 种自由选择，是一个固定的乘法因子。

于是：设左段里有 $i$ 人选 `L`、右段里有 $k-i$ 人选 `R`，方案数为

$$\binom{a}{i} \cdot \binom{b}{k-i}$$

对所有可行的 $i$ 求和，再乘上 `pos` 自己的 2 种方向：

$$\text{answer} = 2 \sum_{i=0}^{k} \binom{a}{i}\binom{b}{k-i}$$

这正是**范德蒙德卷积**的形式（当 $k \le \min(a,b)$ 时 $\sum_i \binom{a}{i}\binom{b}{k-i} = \binom{a+b}{k}$，但本题 $k$ 可能超过某一段的人数，直接按定义求和更稳妥）。

### 3.3 算法流程

![组合数演算：n = 3、pos = 2、k = 1 → 答案 4](images/bw179_q2_binom.svg)

```text
1. a = pos, b = n - 1 - pos
2. 预处理阶乘 fact[0..max(a,b)] 与逆阶乘 inv_fact[]（模 1e9+7）
3. total = 0
4. for i = 0 .. k:
5.     total += C(a, i) * C(b, k - i)      # 越界的组合数按 0 处理
6. 返回 total * 2 % MOD
```

其中 $C$ 用 `fact[n] * inv_fact[k] * inv_fact[n-k]` 计算，逆阶乘用一次费马小定理求 $fact[\max]^{-1}$，再倒推得到全部。

### 3.4 示例演算

对示例 2 的 $n = 3, pos = 2, k = 1$：$a = 2$、$b = 0$。

| $i$ | $\binom{a}{i} = \binom{2}{i}$ | $\binom{b}{k-i} = \binom{0}{1-i}$ | 乘积 | 含义 |
|-----|------|------|------|------|
| 0 | 1 | $\binom{0}{1} = 0$ | 0 | 右侧没人，凑不出 1 个 |
| 1 | 2 | $\binom{0}{0} = 1$ | 2 | 左段恰好 1 人选 L |

$\sum = 2$，再乘 2 得 **4** ✓。示例 1：$a = 1, b = 1, k = 0$，只有 $i = 0$ 一项 $\binom{1}{0}\binom{1}{0} = 1$，乘 2 得 **2** ✓。示例 3：$a = b = 0$，只有 $i=0$ 一项 $\binom{0}{0}\binom{0}{0} = 1$，乘 2 得 **2** ✓。

## 4. 算法细节

1. **预处理阶乘**：只需算到 $\max(a,b) \le n-1$；`C(n,k)` 在 $k<0$ 或 $k>n$ 时直接返回 0，这样求和时不必手写 `i` 的上下界。
2. **逆阶乘**：先 `inv_fact[m] = pow(fact[m], MOD-2, MOD)`，再 `inv_fact[i-1] = inv_fact[i] * i` 倒推，整体 $O(n + \log MOD)$。
3. **取模**：每一步乘法后都取模；`total` 用 64 位（C++ 里两次 $10^9$ 量级相乘逼近 $10^{18}$，`long long` 安全）。
4. **求和范围**：$i$ 从 0 到 $k$ 即可，$b$ 不够时 $\binom{b}{k-i}$ 自动为 0，无需额外收缩区间。
5. **`pos` 的因子 2**：别忘了。这是本题最容易漏的一步——它不影响可见性，但它是自由的。
6. **边界**：$n = 1$ 时 $a = b = 0$，$k$ 只能是 0，答案 2（示例 3）。

## 5. 正确性证明

**引理 1（可见人数可分解）**：设方向分配为 $d_0, \dots, d_{n-1}$，则 `pos` 看到的人数恰为
$$\#\{i < pos : d_i = L\} + \#\{i > pos : d_i = R\}$$

**证明**：由题意，$i<pos$ 的人可见 $\iff d_i = L$，$i>pos$ 的人可见 $\iff d_i = R$，且 $i = pos$ 不计入。两个集合不相交（下标分处两侧），故可见人数为其元素个数之和。∎

**引理 2（方案数分解）**：左段选 L 的人数固定为 $i$、右段选 R 的人数固定为 $k-i$ 时，方向分配方案数为 $\binom{a}{i}\binom{b}{k-i}$。

**证明**：左段共 $a$ 人，任选 $i$ 人指定为 L，其余 $a-i$ 人只能选 R，方案数 $\binom{a}{i}$；右段共 $b$ 人，任选 $k-i$ 人指定为 R，其余只能选 L，方案数 $\binom{b}{k-i}$。两段的选择相互独立（每个人只属于一段），由乘法原理得乘积。∎

**引理 3（`pos` 的方向无关）**：`pos` 本人的方向既不影响可见人数，也不影响其它人的选择自由。

**证明**：引理 1 的表达式只涉及 $i < pos$ 与 $i > pos$ 的人的方向，不包含 $d_{pos}$；而每个人独立选择方向，故 $d_{pos}$ 与其余选择无关，恒有 2 种可选。∎

**定理**：算法返回值等于满足条件的方案数，且模运算不改变结果。

**证明**：由引理 1，满足「恰好 $k$ 人可见」等价于「左段 L 人数与右段 R 人数之和为 $k$」。把满足条件的所有分配按「左段 L 人数 $i$」分类：不同 $i$ 对应的分配集合互不相交（$i$ 由分配唯一确定），且覆盖全部满足条件的分配。对每个 $i$，由引理 2 该类有 $\binom{a}{i}\binom{b}{k-i}$ 个分配；由引理 3，再乘 $d_{pos}$ 的 2 种取值。求和即得总数，正是算法的 `total * 2`。最后，模 $10^9+7$ 下加法与乘法保持同余，故返回值与真实方案数同余。∎

## 6. 复杂度分析

- **时间**：$O(n + k)$。预处理阶乘与逆阶乘 $O(\max(a,b))$，求和 $O(k)$，每次组合数 $O(1)$。（$n \le 10^5$）
- **空间**：$O(n)$，两个长度 $\max(a,b)+1$ 的数组。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int countVisiblePeople(int n, int pos, int k) {
        const long long MOD = 1000000007LL;
        int a = pos, b = n - 1 - pos;
        int sz = max(a, b);
        vector<long long> fact(sz + 1, 1), inv(sz + 1, 1);
        for (int i = 1; i <= sz; i++) fact[i] = fact[i - 1] * i % MOD;
        inv[sz] = modPow(fact[sz], MOD - 2);
        for (int i = sz; i >= 1; i--) inv[i - 1] = inv[i] * i % MOD;

        long long total = 0;
        for (int i = 0; i <= k; i++) {
            total = (total + comb(a, i, fact, inv) * comb(b, k - i, fact, inv)) % MOD;
        }
        return (int)(total * 2 % MOD);
    }

private:
    long long modPow(long long base, long long exp) {
        const long long MOD = 1000000007LL;
        long long res = 1;
        base %= MOD;
        while (exp > 0) {
            if (exp & 1) res = res * base % MOD;
            base = base * base % MOD;
            exp >>= 1;
        }
        return res;
    }

    long long comb(int n, int k, const vector<long long>& fact, const vector<long long>& inv) {
        const long long MOD = 1000000007LL;
        if (k < 0 || k > n) return 0;
        return fact[n] * inv[k] % MOD * inv[n - k] % MOD;
    }
};
```

### Python

```python
class Solution:
    def countVisiblePeople(self, n: int, pos: int, k: int) -> int:
        MOD = 10 ** 9 + 7
        a, b = pos, n - 1 - pos
        size = max(a, b)
        fact = [1] * (size + 1)
        for i in range(1, size + 1):
            fact[i] = fact[i - 1] * i % MOD
        inv_fact = [1] * (size + 1)
        inv_fact[size] = pow(fact[size], MOD - 2, MOD)
        for i in range(size, 0, -1):
            inv_fact[i - 1] = inv_fact[i] * i % MOD

        def comb(nn: int, kk: int) -> int:
            if kk < 0 or kk > nn:
                return 0
            return fact[nn] * inv_fact[kk] % MOD * inv_fact[nn - kk] % MOD

        total = 0
        for i in range(0, k + 1):
            total = (total + comb(a, i) * comb(b, k - i)) % MOD
        return total * 2 % MOD
```

## 8. 边界情况与易错点

1. **漏掉 `pos` 的因子 2**：这是最常见的 WA。`pos` 自己的方向永远自由，答案必须乘 2。
2. **$k > a + b$**：可见人数不可能超过总人数 $n-1$，但 $k$ 的约束是 $k \le n-1$，所以 $k \le a+b$ 恒成立；即使不成立，组合数自动为 0，代码也不会错。
3. **$k$ 大于某一段长度**：例如 $a = 2, b = 0, k = 1$，只有 $i=1$ 项有效。不要写死 $i \le \min(a,k)$ 之类的额外限制——$C(b,k-i)$ 越界返回 0 更不易错。
4. **$n = 1$**：$a = b = 0$，答案 2。若代码里对 $k=0$ 特判返回 1 就错了。
5. **阶乘数组大小**：只算到 $\max(a,b)$，但 `C(a,i)` 与 `C(b,k-i)` 的下标不会超过 $a$、$b$，所以安全；若统一算到 $n$ 也无妨。
6. **取模时机**：`total` 累加后立即取模；`2 * total` 后再取模一次。
7. **模逆元**：$10^9+7$ 是素数且 $fact[m]$ 与之互素（$m \le 10^5 < MOD$），费马小定理适用。
