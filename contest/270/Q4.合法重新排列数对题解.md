# LeetCode 合法重新排列数对 题解

## 1. 题目概述

- **标题 / 题号**：合法重新排列数对（#2097，hard）
- **链接**：https://leetcode.cn/problems/valid-arrangement-of-pairs/
- **来源**：LeetCode 第 270 场周赛 Q4
- **难度**：困难
- **标签**：深度优先搜索、图、欧拉路径、Hierholzer 算法

**题意**：给定二维整数数组 `pairs`，其中 `pairs[i] = [start_i, end_i]`。将 `pairs` **重新排列**，使得对每个下标 `i`（$1 \le i < n$）都有 $end_{i-1} = start_i$（前一个数对的尾 = 下一个数对的头，首尾相接成串）。返回**任意一个**合法排列。题目保证至少存在一个合法排列。

**约束**：

- $1 \le \text{pairs.length} \le 10^5$
- $0 \le start_i, end_i \le 10^9$ —— 值域极大，需哈希表而非数组建图
- $start_i \ne end_i$ —— 无自环
- 数对互不相同 —— 无重边（但算法天然支持重边，不依赖此条件）
- 至少存在一个合法排列 —— 图**必然存在**欧拉路径，无需判定存在性

> 💡 **审题关键**：① 每个数对 $[start, end]$ 恰是一条**有向边** $start \to end$；② 合法排列要求所有数对首尾相接成一条链 $v_0 \to v_1 \to \dots \to v_n$，每条边**用且只用一次**——这正是「**欧拉路径**」的定义；③ 返回**任意**合法排列即可，不要求字典序（区别于 [332. 重新安排行程](https://leetcode.cn/problems/reconstruct-itinerary/)）。

## 2. 示例

**示例 1（链状：半欧拉路径）**

```text
输入：pairs = [[5,1],[4,5],[11,9],[9,4]]
输出：[[11,9],[9,4],[4,5],[5,1]]
解释：end_0 = 9 == start_1 = 9，end_1 = 4 == start_2 = 4，
      end_2 = 5 == start_3 = 5，四条边首尾相接成 11→9→4→5→1。
```

**示例 2（环状：欧拉回路）**

```text
输入：pairs = [[1,3],[3,2],[2,1]]
输出：[[1,3],[3,2],[2,1]]
解释：1→3→2→1 首尾闭合，所有点入度 = 出度，从任一点出发均可。
```

**示例 3（起点有两条出边）**

```text
输入：pairs = [[1,2],[1,3],[2,1]]
输出：[[1,2],[2,1],[1,3]]
解释：节点 1 出度 2、入度 1（out−in=1，为起点），先走 1→2→1 回到 1，
      再走 1→3 结束。1→3 一路先入死胡同也不影响正确性（见证明）。
```

## 3. 解题思路

### 3.1 暴力思路

最朴素的做法是枚举 `pairs` 的所有排列并逐一校验首尾相接：

- **正确性**：穷举必然命中合法解。
- **效率**：$O(n! \cdot n)$，$n \le 10^5$ 时天文数字，完全不可行。

稍微聪明一点的搜索：以某个数对为开头，每次从剩余数对中挑「头等于当前尾」的接上（类似拼火车游戏）。这本质上是在图上做**深度优先搜索走边**，若每步都「一条路走到黑再回溯」，最坏仍是指数级——除非利用「每条边必须用」的结构性质，把搜索变成**线性构造**。

### 3.2 核心观察：数对 = 有向边，合法排列 = 欧拉路径

![数对=有向边，重排=欧拉路径](images/2097_euler_concept.svg)

把每个数对 $[start, end]$ 视为有向边 $start \to end$，得到有向图 $G$。合法排列要求把**全部** $n$ 条边排成一串、每条边恰好出现一次且相邻边首尾相接——即 $G$ 中一条**经过每条边恰好一次的迹**，也就是**欧拉路径**。

于是问题从「搜索排列」降维成「**构造欧拉路径**」，而构造欧拉路径有经典的 **Hierholzer 算法**，$O(V + E)$ 线性完成。题目保证解存在，即 $G$ 必有欧拉路径，连存在性判定都省了。

### 3.3 算法流程：度数定起点 + Hierholzer 后序入栈

![Hierholzer 求欧拉路径流程](images/2097_euler_flow.svg)

**第一步：建图与度数统计**。邻接表 `g[u]` 存 `u` 的所有出边，同时统计每个点的入度 `in` 与出度 `out`。

**第二步：按度数定起点**。有向图欧拉路径的起点判定：

| 情形 | 度数条件 | 起点 |
|------|----------|------|
| 半欧拉路径 | 恰有一点 $\text{out} - \text{in} = 1$、恰有一点 $\text{in} - \text{out} = 1$，其余平衡 | $\text{out} - \text{in} = 1$ 的点 |
| 欧拉回路 | 所有点 $\text{out} = \text{in}$ | 任一有出边的点 |

> ⚠️ **起点必须选对**：$\text{out} - \text{in} = 1$ 的点多一条未配对的出边，只能从它出发才用得掉；从平衡点出发，走到一半就会卡死，无法覆盖全部边。

**第三步：迭代版 Hierholzer**。用显式栈模拟 DFS：

```text
st = [start]
while st 非空:
    u = 栈顶
    if g[u] 非空:
        v ← g[u].pop()    # 取一条出边并删除（每条边只用一次）
        st.push(v)        # 沿边深入
    else:
        ans.append(u)     # 出边耗尽，后序入栈
        st.pop()
```

**第四步：逆序 + 配对**。`reverse(ans)` 得节点序列 $[v_0, v_1, \dots, v_n]$，相邻节点配成数对 $[v_i, v_{i+1}]$ 即为答案。

> 💡 **为什么「后序入栈 + 逆序」是对的？** `u` 被记入 `ans` 时出边已全部耗尽，是当前走到的「死胡同」末端。由于图存在欧拉路径，提前卡死的点恰好是真正的终点（非终点的点 $\text{in} = \text{out}$，进去后必然还能出来，不会死）。逆序后即得起点到终点的正序路径。

> ⚠️ **$n \le 10^5$ 必须迭代**：链状图的递归深度达 $O(E) = 10^5$，递归版有栈溢出风险（332 的 $E \le 300$ 无此顾虑），故用显式栈模拟。

### 3.4 示例演算

![示例 1 逐步演算](images/2097_euler_walkthrough.svg)

以示例 1（`pairs = [[5,1],[4,5],[11,9],[9,4]]`）演算：

**步骤 ① 度数统计定起点**：

| 节点 | out | in | out−in |
|------|-----|-----|--------|
| 11   | 1   | 0   | +1 ← **起点** |
| 9    | 1   | 1   | 0 |
| 4    | 1   | 1   | 0 |
| 5    | 1   | 1   | 0 |
| 1    | 0   | 1   | −1 ← **终点** |

**步骤 ② 沿唯一出边深入**：$11 \to 9 \to 4 \to 5 \to 1$，节点 1 无出边，死胡同。

**步骤 ③ 后序入栈**：回退阶段依次入栈 $1, 5, 4, 9, 11$，得 `ans = [1, 5, 4, 9, 11]`。

**步骤 ④ 逆序 + 配对**：逆序得节点路径 $[11, 9, 4, 5, 1]$，相邻配对输出 `[[11,9],[9,4],[4,5],[5,1]]`，长度恰为 4 条边，合法 ✓。

再看示例 3（`pairs = [[1,2],[1,3],[2,1]]`）中「先走进死胡同」的情形：从起点 1 出发，若先沿 $1 \to 3$ 深入，3 无出边即入栈；回退后继续 $1 \to 2 \to 1$，1 的出边耗尽后入栈。后序 `ans = [3, 1, 2, 1]`，逆序 $[1, 2, 1, 3]$，配对 `[[1,2],[2,1],[1,3]]` ✓——死胡同 3 恰是终点，逆序后被「挤」到末尾，正确性不受影响。

## 4. 算法细节

1. **值域 $10^9$，离散化靠哈希**：邻接表与度数表均用 `unordered_map` / `defaultdict`，不建数组。若想极致性能可先排序离散化成 $0 \sim 2n-1$ 的下标，$V \le 2E \le 2 \times 10^5$。
2. **邻接表用 `vector` + `pop_back()` 删边**：取边即删边，$O(1)$。本题任意合法排列均可，**无需排序**；332 要求字典序最小才需要最小堆 / 有序表。
3. **起点判定的实现**：扫描所有有出边的点，找 $\text{out} - \text{in} = 1$ 者；找不到（欧拉回路情形）回退取任一有出边的点，实现上直接用 `pairs[0][0]` 兜底——它必有出边。
4. **迭代 Hierholzer 的状态**：栈顶点「有出边就压入下一点、无出边就弹出并记录」。每条边恰好被 pop 一次、每点最多被弹出一次，总操作数 $O(V + E)$。
5. **节点序列 → 数对序列**：`ans` 逆序后长度为 $n + 1$，相邻配对得 $n$ 个数对。可断言 `len(res) == len(pairs)` 自检（起点选错或图不连通时此断言失败）。

## 5. 正确性证明

**引理 1（建模等价）**：`pairs` 的合法排列与 $G$（数对视为有向边）的欧拉路径一一对应。

**证明**：设排列 $e_1, e_2, \dots, e_n$ 合法，即 $e_{i-1}$ 的头等于 $e_i$ 的尾。记 $e_i = (v_{i-1}, v_i)$，则 $v_0 \to v_1 \to \dots \to v_n$ 是依次经过 $e_1, \dots, e_n$ 的迹；排列是 `pairs` 的重排且数对互异，故每条边恰好经过一次，即欧拉路径。反之，一条欧拉路径按边的经过顺序列出，相邻边自然首尾相接，构成合法排列。∎

**引理 2（度数条件）**：若 $G$ 存在欧拉路径 $v_0 \to v_1 \to \dots \to v_n$，则除起点、终点外每个点的入度等于出度；当 $v_0 \ne v_n$ 时起点满足 $\text{out} - \text{in} = 1$、终点满足 $\text{in} - \text{out} = 1$；当 $v_0 = v_n$（回路）时所有点 $\text{out} = \text{in}$。

**证明**：沿路径统计：路径每次**经过**一个点（非端点），贡献一进一出，配对抵消；起点作为端点只出不进（若非回路）多一次出，终点只进不出多一次进；回路情形下起点亦作为终点进出配对。而欧拉路径覆盖全部边，故图的实际度数即由路径贡献决定。∎

**推论**：本题保证合法排列存在，故由引理 2，图中要么恰有一点 $\text{out} - \text{in} = 1$（算法取它为起点，正确），要么所有点平衡（回路，任取有出边点为起点均正确）。因此算法的起点选取必然可行。

**引理 3（Hierholzer 的正确性）**：从引理 2 推论确定的起点出发，迭代 Hierholzer 终止时，`ans` 的逆序是一条欧拉路径。

**证明**：
（i）**每条边恰用一次**：出边仅在压栈时被 `pop` 删除，绝不被重复使用；反之每条 $(u, v)$ 只要还在邻接表中，`u` 位于栈顶时迟早会被取出。
（ii）**栈必空**（所有边被耗尽）：若循环终止时仍有边未用，取栈中**最深的**、仍有未用出边的点 $u$（由起点度数条件与图连通性，这样的点若存在必在栈上）。若 $u$ 是栈顶，矛盾（会继续取边）；若 $u$ 之上还有点，说明 $u$ 之上那段是「进入死胡同」的链，链尾点的出边已耗尽——而由引理 2，除终点外任何点 $\text{in} = \text{out}$（或起点 $\text{out} = \text{in} + 1$），「进入后出边耗尽」的点只能是真终点或起点：终点被弹出后，$u$ 重新露头继续取边；起点耗尽出边即整栈回空。故最终所有边被消耗，栈空终止。
（iii）**逆序即欧拉路径**：点 $u$ 被记入 `ans` 时出边已耗尽；对 `ans` 中相邻的两点（逆序后为 $x$ 后跟 $y$），$y$ 正是 $x$ 某次取边压入的「子调用」，即 $(x, y)$ 是一条被消耗的边。因此逆序序列的每对相邻点对应一条用过的边，共 $n$ 对、$n + 1$ 个点，恰用完 $n$ 条互不相同的边——即欧拉路径。∎

**定理**：算法输出的数对序列是 `pairs` 的一个合法排列。

**证明**：由引理 2 推论，起点选取正确；由引理 3，逆序节点序列 $[v_0, \dots, v_n]$ 是 $G$ 的欧拉路径；相邻配对 $[v_i, v_{i+1}]$ 列出的边按引理 1 对应一个合法排列，且长度 $n$、数对互异（数对即图的边，各用一次）。∎

## 6. 复杂度分析

- **时间复杂度**：$O(V + E)$
  - 建图与度数统计遍历所有边一次，$O(E)$；
  - Hierholzer 每条边恰被 pop 一次、每个点至多被弹出一次，$O(V + E)$；
  - 逆序与配对 $O(V)$。其中 $E = n \le 10^5$，$V \le 2E$。
- **空间复杂度**：$O(V + E)$
  - 邻接表 $O(V + E)$、度数哈希表 $O(V)$、显式栈与答案 $O(V)$，输出 $O(E)$。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    vector<vector<int>> validArrangement(vector<vector<int>>& pairs) {
        unordered_map<int, vector<int>> g;
        unordered_map<int, int> indeg, outdeg;

        for (const auto& p : pairs) {
            g[p[0]].push_back(p[1]);
            ++outdeg[p[0]];
            ++indeg[p[1]];
        }

        // 按度数找起点：out − in = 1 的点；不存在（欧拉回路）则任取有出边的点
        int start = pairs[0][0];
        for (const auto& [u, _] : g) {
            if (outdeg[u] - indeg[u] == 1) {
                start = u;
                break;
            }
        }

        // 迭代版 Hierholzer：显式栈模拟递归，避免 1e5 深度栈溢出
        vector<int> ans;
        vector<int> st{start};
        while (!st.empty()) {
            int u = st.back();
            if (!g[u].empty()) {
                int v = g[u].back();
                g[u].pop_back();   // 取一条出边并删除，每条边只用一次
                st.push_back(v);
            } else {
                ans.push_back(u);  // 出边耗尽，后序入栈
                st.pop_back();
            }
        }

        reverse(ans.begin(), ans.end());

        // 节点序列 → 相邻配对即数对序列
        vector<vector<int>> res;
        res.reserve(ans.size() - 1);
        for (size_t i = 0; i + 1 < ans.size(); ++i) {
            res.push_back({ans[i], ans[i + 1]});
        }
        return res;
    }
};
```

### Python

```python
class Solution:
    def validArrangement(self, pairs: List[List[int]]) -> List[List[int]]:
        g = defaultdict(list)
        indeg = defaultdict(int)
        outdeg = defaultdict(int)

        for u, v in pairs:
            g[u].append(v)
            outdeg[u] += 1
            indeg[v] += 1

        # 按度数找起点：out − in = 1 的点；否则任取有出边的点
        start = pairs[0][0]
        for u in g:
            if outdeg[u] - indeg[u] == 1:
                start = u
                break

        # 迭代版 Hierholzer
        ans = []
        st = [start]
        while st:
            u = st[-1]
            if g[u]:
                st.append(g[u].pop())   # 取一条出边并删除
            else:
                ans.append(u)           # 后序入栈
                st.pop()

        ans.reverse()

        # 节点序列 → 相邻配对
        return [[ans[i], ans[i + 1]] for i in range(len(ans) - 1)]
```

> 💡 **代码要点**：① 邻接表 `vector` / `list` 尾部 `pop` 取边，$O(1)$ 删边，无需排序（区别于 332 的最小堆）；② 迭代版栈中点「有出边压入、无出边弹出记录」，与递归后序等价；③ `g[u]` 访问不存在的键会插入空容器（哈希表 `operator[]` / `defaultdict` 特性），对终点节点无害；④ 输出长度必为 `len(pairs)`，比赛中可加断言自检。

## 8. 边界情况与易错点

1. **欧拉回路情形（示例 2/3）**：不存在 $\text{out} - \text{in} = 1$ 的点，若起点初始化为 0 或空值而非「有出边的点」，会直接输出空。务必用 `pairs[0][0]` 兜底。
2. **起点选错**：半欧拉图从平衡点出发，Hierholzer 会中途卡死、残留未用边，输出长度不足 $n$——这是起点判定写错最典型的症状。
3. **递归栈溢出**：$E = 10^5$ 的链状图递归深度 $O(E)$，递归版可能爆栈，必须用迭代版。
4. **忘记逆序**：后序 `ans` 是从末端往回的序列，直接配对会得到反向排列（`end → start`），路径情形必错。
5. **值域 $10^9$**：度数与邻接表不能用数组，须哈希表（或离散化）。
6. **`n = 1`**：单个数对自成合法排列，算法天然正确（起点即该数对的 start，一步入栈、一步出栈）。
7. **输出长度校验**：正常实现输出恰 $n$ 个数对；若想稳，可在返回前断言（也可用于对拍调试）。
8. **自环与重边**：本题约束排除了两者，但 Hierholzer 天然支持，无需特判——这套模板可直接迁移到一般有向图。
