# LeetCode 从二叉树一个节点到另一个节点每一步的方向 题解

## 1. 题目概述

- **标题 / 题号**：从二叉树一个节点到另一个节点每一步的方向（#2096，medium）
- **链接**：https://leetcode.cn/problems/step-by-step-directions-from-a-binary-tree-node-to-another/
- **来源**：LeetCode 第 270 场周赛 Q3
- **难度**：中等
- **标签**：树、二叉树、深度优先搜索、字符串、最近公共祖先

**题意**：给一棵 $n$ 个节点的二叉树（节点值恰为 $1 \sim n$ 且互不相同）与两个**不同**的节点值 `startValue`、`destValue`。返回从 `start` 节点到 `dest` 节点的**最短路径**上每一步的方向串：`'L'` 表示走向左孩子、`'R'` 表示走向右孩子、`'U'` 表示走向父节点。

**约束**：

- $2 \le n \le 10^5$，树形态任意 —— 可退化为链，树高最坏为 $n - 1$
- 节点值互不相同；`startValue != destValue` 且两者都在树中
- 二叉树节点**只有 `left` / `right` 指针**，没有父指针 —— 但方向串允许 `'U'`

> 💡 **审题关键**：① 输出的是**方向串**而非节点序列，这提示用「根路径方向序列」来编码路径；② 树中任意两节点间路径**唯一**（无环），「最短路径」就是这条唯一简单路径；③ 路径形态必然是「先向上、再向下」，转折点即 **LCA**；④ `start` / `dest` 给的是**值**，搜索时按 `val` 比较。

## 2. 示例

**示例 1**

```text
输入：root = [5,1,2,3,null,6,4], startValue = 3, destValue = 6
输出："UURL"
解释：最短路径为 3 → 1 → 5 → 2 → 6：
      3→1、1→5 两步向上（UU），5→2 向右（R），2→6 向左（L）。
```

**示例 2（start 为根：纯下行）**

```text
输入：root = [2,1], startValue = 2, destValue = 1
输出："L"
解释：start 就是根，pathStart 为空串，答案即根到 dest 的下行方向 "L"。
```

**补充（dest 为祖先：纯上行）**

```text
输入：root = [1,2], startValue = 2, destValue = 1
输出："U"
解释：pathStart = "L"，pathDest = ""（dest 即根），公共前缀 i = 0，
      上行段 'U'×1，下行段为空 —— 全程向上。
```

**补充（start 是 dest 的祖先：前缀耗尽型分岔）**

```text
输入：root = [5,1,2,3,null,6,4], startValue = 1, destValue = 3
输出："L"
解释：pathStart = "L"，pathDest = "LL"，公共前缀长度 i = 1 = depth(LCA)。
      上行段 'U'×(1−1) 为空，答案 = pathDest[1:] = "L"。
```

## 3. 解题思路

### 3.1 朴素思路：把树当一般图

两条常见的绕路：

- **建无向图跑 BFS**：把每条父子边变成双向边，从 `start` 层层扩展到 `dest`，沿途记录方向。正确（树无环，BFS 找到的就是最短路），但要 $O(n)$ 建邻接表 + 队列 + 每步的方向回溯，把树当一般无向图处理，**丢掉了「树中路径唯一、必经 LCA」的全部结构信息**，代码量也最大。
- **先显式找 LCA 再各搜一遍**：用 236 的后序 DFS 拿到 LCA **节点指针**，再从 LCA 分别向下 DFS 到 `start` 与 `dest`，把前一段逆序反转成 `'U'`。正确，但要三次遍历，且「找 LCA」「找方向」两套逻辑拼接，比赛现场最容易在「反转时机」和「空段特判」上写挂。

其实两条根路径的**字符串本身**就携带了 LCA 的全部信息——公共前缀的终点就是分岔点。

### 3.2 核心观察：两条根路径 + 剥公共前缀 = LCA 拆上下两段

![核心观察：两条根路径剥公共前缀，LCA 拆成「上行 U + 下行 L/R」](images/2096_dirs_concept.svg)

三层直觉接力：

1. **路径必经 LCA，先上后下**：树中两点间简单路径唯一，形如 `start` 上行到 LCA、再下行到 `dest`。这个「转折点」是同时为两者祖先的最深节点。
2. **根路径 = 方向序列**：从 `root` 出发 DFS 到 `start`，沿途向左记 `'L'`、向右记 `'R'`，得到串 $P_s$，其长度恰为 $\dep(\text{start})$；同理得 $P_d$。**根到任何节点的路径唯一**，所以方向串与节点一一对应。
3. **公共前缀的终点 = LCA**：两条根路径从根出发并肩同行，走到分岔处才各奔东西——分岔点正是 LCA。剥掉公共前缀后：
   - `start` 侧剩余：LCA → start 的**下行**方向序列。`start` 要逆着走回 LCA，每一步都是从孩子走向父亲，与原来走的是 `'L'` 还是 `'R'` 无关——**全部记 `'U'`，个数就是剩余长度**；
   - `dest` 侧剩余：LCA → dest 的下行方向序列，**原样照抄**。

$$\boxed{\ \text{answer} \;=\; \text{'U'} \times \bigl(\lvert P_s\rvert - i\bigr) \;+\; P_d[i:], \quad i = \text{公共前缀长度}\ }$$

> 💡 **为什么不用显式求 LCA 节点？** 剥字符串本身就完成了 LCA 定位——`i` 停在哪里，分岔就在哪里。整个算法不需要任何节点指针层面的祖先判断，这是它比赛时比别人快半拍的原因。

### 3.3 算法流程

![算法流程：两次 DFS 取根路径，剥公共前缀，拼 U 段与下行段](images/2096_dirs_flow.svg)

1. **回溯 DFS 找 $P_s$**：进左子树压 `'L'`、进右子树压 `'R'`，失配弹回；命中 `startValue` 时路径串即成。
2. **同法找 $P_d$**。
3. **剥公共前缀**：`i` 从 0 起逐位比较 $P_s[i]$ 与 $P_d[i]$，相等则 `i++`；**任一串耗尽或字符不同即停**。
4. **拼接**：`'U' × (len(Ps) − i) + Pd[i:]`。

### 3.4 示例演算

![示例演算：start=3, dest=6，剥出 UURL](images/2096_dirs_walkthrough.svg)

以示例 1 演算：

- **步骤 ①② 取根路径**：根→3 经过 5→1→3，得 $P_s = $ `"LL"`；根→6 经过 5→2→6，得 $P_d = $ `"RL"`。
- **步骤 ③ 剥前缀**：第 0 位 `'L' ≠ 'R'`，即刻停止，$i = 0$ → 两条根路径在根就分岔，**LCA = 根 5**。
- **步骤 ④ 拼接**：上行段 `'U' × (2−0) = "UU"`（3→1→5），下行段 $P_d[0:] = "RL"$（5→2→6），**answer = "UURL"** ✓。

对照「补充（前缀耗尽型分岔）」：$P_s = $"L"，$P_d = $"LL"，较短串耗尽时 $i = 1$，LCA = 节点 1 本身，上行段为空，答案纯下行 `"L"`——前缀耗尽与字符不同两种终止被同一个 `while` 条件统一处理。

## 4. 算法细节

1. **`findPath` 回溯模板**：`path.push_back('L')` → 递归左子树 → 失败则 `pop_back()` 回退，再试右子树。命中返回 `true` 并**沿途短路**（不再弹栈），保证函数返回时 `path` 恰为根→命中点的方向序列——这正是「DFS 栈 = 当前路径」的回溯不变量。
2. **按值比较而非指针**：题给的是 `startValue` / `destValue`，且值互不相同，`node->val == target` 即可唯一定位，无需先遍历一遍把指针找出来。
3. **`'U'` 段与原方向字母无关**：上行段只关心**步数** $\lvert P_s\rvert - i$，不关心 $P_s$ 剩余部分是 `'L'` 还是 `'R'`——从孩子走回父亲永远记 `'U'`。切勿把 `startRemain` 「反转」成别的字母。
4. **`while` 三条件缺一不可**：`i < len(Ps) && i < len(Pd) && Ps[i] == Pd[i]`。两个长度条件处理「一条路径是另一条前缀」的祖先情形；漏掉任何一个都会越界或提前/滞后停止。
5. **两次 DFS 可合并为单趟**：一次遍历同时找两个目标，双命中后短路返回（见 §7 变体）。最坏仍 $O(n)$，只是省一遍遍历的常数。
6. **空间由树高决定**：路径串长度、递归栈深度均为 $O(h)$，链状树时 $h = n - 1$。

## 5. 正确性证明

约定 $\dep(v)$ 为 $v$ 的深度（$\dep(\text{root}) = 0$）；$P_s, P_d$ 为根到 `start` / `dest` 的下行方向串；$\mathrm{LCA}$ 为同时是两者祖先的节点中深度最大者。

**引理 1（路径形态）**：树中 `start` 到 `dest` 的唯一简单路径，恰为「`start` ↑ LCA ↓ `dest`」两段拼接。

**证明**：存在性：祖先链唯一，`start` 沿父指针上行到 LCA、再沿 LCA 到 `dest` 的下行路径存在。唯一性：树是无环连通图，任意两节点间简单路径唯一（若有两条，取其对称差可导出环，矛盾）。再证唯一简单路径必经 LCA：设该路径为 $v_0, \dots, v_k$，取路径上**深度最小**的节点 $m$。$v_0 \to m$ 的每一步必为走向父亲（否则出现「下行后又上行」的折返，折返点重复经过其父亲，非简单路径）；$m \to v_k$ 的每一步必为走向孩子（同理）。故 $m$ 是 `start` 与 `dest` 的公共祖先，且路径 = `start` ↑ $m$ ↓ `dest`。若 $m$ 不是 LCA，则 LCA 是 $m$ 的真后代，`start` 上行到 $m$ 必经过 LCA，`dest` 从 $m$ 下行也必经过 LCA，路径重复经过 LCA，与简单性矛盾。故 $m = \mathrm{LCA}$。∎

**引理 2（前缀对应）**：$P_s$ 与 $P_d$ 的最长公共前缀长度 $i = \dep(\mathrm{LCA})$；且 $P_s[i:]$ 是 LCA → `start` 的下行方向序列，$P_d[i:]$ 是 LCA → `dest` 的下行方向序列。

**证明**：从任一节点出发，`'L'` / `'R'` 各指定唯一的孩子，故方向串与从根出发的节点序列一一对应：两串前 $i$ 位相同 ⟺ 两条根路径的前 $i$ 步走到同一节点序列。设公共前缀的终点为 $u$（两路径最后共用、第 $i$ 步之前到达的节点）。$u$ 在两条根路径上，故是公共祖先，$\dep(u) \le \dep(\mathrm{LCA})$。另一方面 LCA 也在两条根路径上（它是祖先），于是根→LCA 的方向序列是两串的公共前缀，$i \ge \dep(\mathrm{LCA})$，即 $\dep(u) \ge \dep(\mathrm{LCA})$。二者结合 $u = \mathrm{LCA}$，$i = \dep(\mathrm{LCA})$。又根→`start` 路径 = 根→LCA 拼接 LCA→`start`，方向串相应分解，后缀即 LCA→`start` 的下行序列；$P_d$ 同理。∎

**定理**：算法输出 $R = $ `'U'` $\times (\lvert P_s\rvert - i) + P_d[i:]$ 恰为 `start` → `dest` 最短路径的方向串，且 $\lvert R\rvert = \dep(\text{start}) + \dep(\text{dest}) - 2\dep(\mathrm{LCA})$。

**证明**：由引理 1，最短路径 = `start` 上行到 LCA 再下行到 `dest`。上行段共 $\lvert P_s\rvert - i$ 步（由引理 2，即 LCA→`start` 下行步数的逆序），每步从孩子走向父亲，方向均记 `'U'`，与原下行字母无关；下行段的方向序列由引理 2 为 $P_d[i:]$。故 $R$ 逐字符描述该路径。长度 $\lvert R\rvert = (\lvert P_s\rvert - i) + (\lvert P_d\rvert - i) = \dep(\text{start}) + \dep(\text{dest}) - 2\dep(\mathrm{LCA})$，正是两点在树上的距离。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。两次 DFS 各至多遍历全部 $n$ 个节点（目标位置未知时必须扫到命中为止）；前缀比较 $O(\min(\lvert P_s\rvert, \lvert P_d\rvert)) \le O(h)$，被遍历项吸收。$n = 10^5$ 时约两趟树的遍历，远低于时限。
- **空间复杂度**：$O(h)$。递归调用栈深度 = 树高 $h$，两条路径串总长 $\le 2h$，答案串长度 $= \lvert P_s\rvert + \lvert P_d\rvert - 2i \le 2h$。平衡树 $O(\log n)$，链状树最坏 $O(n)$——对比 BFS 建图法的 $O(n)$ 邻接表，平均场景更省。

## 7. 参考代码

### C++（两次 DFS + 剥前缀，推荐）

```cpp
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 * };
 */
class Solution {
    // 从 node 出发找 target，path 记录 root→target 的下行方向（回溯模板）
    bool findPath(TreeNode* node, int target, string& path) {
        if (node == nullptr) return false;
        if (node->val == target) return true;   // 命中即短路，沿途不弹栈
        path.push_back('L');
        if (findPath(node->left, target, path)) return true;
        path.pop_back();                        // 左侧失配，回退
        path.push_back('R');
        if (findPath(node->right, target, path)) return true;
        path.pop_back();                        // 右侧失配，回退
        return false;
    }
public:
    string getDirections(TreeNode* root, int startValue, int destValue) {
        string ps, pd;
        findPath(root, startValue, ps);
        findPath(root, destValue, pd);

        int i = 0;                              // 剥公共前缀：i 停在分岔处 = LCA 深度
        while (i < ps.size() && i < pd.size() && ps[i] == pd[i]) ++i;

        return string(ps.size() - i, 'U') + pd.substr(i);
    }
};
```

### Python

```python
class Solution:
    def getDirections(self, root: Optional[TreeNode], startValue: int, destValue: int) -> str:
        # 回溯 DFS：path 恰为 root→target 的下行方向序列
        def find_path(node: Optional[TreeNode], target: int, path: list) -> bool:
            if not node:
                return False
            if node.val == target:
                return True
            path.append('L')
            if find_path(node.left, target, path):
                return True
            path.pop()
            path.append('R')
            if find_path(node.right, target, path):
                return True
            path.pop()
            return False

        ps, pd = [], []
        find_path(root, startValue, ps)
        find_path(root, destValue, pd)

        i = 0
        while i < len(ps) and i < len(pd) and ps[i] == pd[i]:
            i += 1

        return 'U' * (len(ps) - i) + ''.join(pd[i:])
```

### C++（单趟 DFS 变体：双目标短路）

```cpp
class Solution {
    string ps, pd;
    bool foundS = false, foundD = false;

    void dfs(TreeNode* node, string& cur, int s, int d) {
        if (!node || (foundS && foundD)) return;        // 双命中，整体短路
        if (node->val == s) { ps = cur; foundS = true; }
        if (node->val == d) { pd = cur; foundD = true; }

        cur.push_back('L'); dfs(node->left,  cur, s, d); cur.pop_back();
        cur.push_back('R'); dfs(node->right, cur, s, d); cur.pop_back();
    }
public:
    string getDirections(TreeNode* root, int startValue, int destValue) {
        string cur;
        dfs(root, cur, startValue, destValue);
        int i = 0;
        while (i < ps.size() && i < pd.size() && ps[i] == pd[i]) ++i;
        return string(ps.size() - i, 'U') + pd.substr(i);
    }
};
```

> ⚠️ **Python 的深链风险**：$n = 10^5$ 的链状树使递归深度达 $10^5$，可能触发 `RecursionError`。若评测环境递归上限较低，需 `sys.setrecursionlimit(300000)`，或将 `find_path` 改成显式栈的迭代版（逻辑完全等价）。C++ 默认栈下每帧极小，一般可直接递归。

## 8. 边界情况与易错点

1. **`start` 为根（$P_s$ 空串）**：`i = 0` 直接停在上行段为空，答案纯下行——示例 2 正是此情形，无需特判。
2. **一条根路径是另一条的前缀（祖先-后代）**：`while` 以「较短串耗尽」终止，此时 LCA 是较浅的那个端点，上行段或下行段为空，公式依然成立——两种终止（耗尽 / 字符不同）被三个条件统一覆盖。
3. **`while` 条件残缺**：漏 `i < len(Ps)` 或 `i < len(Pd)` 会越界（祖先情形必炸）；漏字符相等条件则剥过头，`'U'` 个数偏少、下行段被吃掉前几位。
4. **回溯忘 `pop_back` / `pop`**：失败分支的 `'L'` / `'R'` 残留在串里，路径串不再对应真实 DFS 栈，输出长度错乱。
5. **上行段「反转」错方向**：常见误写是把 `startRemain` 逆序后原样输出——上行段每个字符都应是 `'U'`（个数 = 剩余长度），与原字母 `'L'` / `'R'` 无关。
6. **`pd.substr(i)` 而非 `substr(i + 1)`**：`i` 是**首位不同**的下标（或较短串长度），分岔从第 `i` 步开始，$P_d$ 从 `i` 起截取。
7. **深链递归栈**：链状树高 $n - 1 = 10^5$，Python 注意递归上限（见 §7 警告框），必要时改显式栈迭代。
8. **题面保证**：`startValue != destValue` 且都在树中，无需处理「同值」「目标不存在」；值域 $1 \sim n$ 互不相同，按 `val` 比较即可，不必担心哈希冲突或多解。
9. **输出必须是大写** `'U'` / `'L'` / `'R'`，方向串不许含其他字符。
