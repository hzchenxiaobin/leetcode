# LeetCode 按距离统计房屋对数目 I 题解

## 1. 题目概述

- **标题 / 题号**：按距离统计房屋对数目 I（#3015，medium）
- **链接**：https://leetcode.cn/problems/count-the-number-of-houses-at-a-certain-distance-i/
- **来源**：LeetCode 第 381 场周赛 Q2
- **难度**：中等
- **标签**：广度优先搜索、图、枚举（官方标签里的「前缀和」是给 II 版 O(n) 解法预备的）

**题意**：编号 $1 \sim n$ 的房屋排成一条链（$i$ 与 $i+1$ 之间有街道，共 $n-1$ 条），**另有一条**街道连接房屋 $x$ 与 $y$（$x$ 可以等于 $y$）。对每个 $k$（$1 \le k \le n$），统计**最少经过街道数恰为 $k$** 的**有序房屋对** $[\text{house}_1, \text{house}_2]$ 数量，返回下标从 1 开始、长度为 $n$ 的数组 `result`，其中 `result[k]` 即距离为 $k$ 的有序对数。

**约束**：

- $2 \le n \le 100$
- $1 \le x, y \le n$

> ⚠️ **读题两个坑**：
> 1. **有序对**：$(1,2)$ 与 $(2,1)$ 各计一次，因此 $\sum_k \text{result}[k] = n(n-1)$，是最方便的自检不变式；
> 2. **$x$ 可以等于 $y$**：此时额外街道是**自环**（自己连自己），任何最短路都用不上它，等价于没有这条边。

> 💡 **赛时背景**：本场 Q4（[3017. 按距离统计房屋对数目 II](https://leetcode.cn/problems/count-the-number-of-houses-at-a-certain-distance-ii/)）就是本题把 $n$ 放大到 $10^5$。Q2 考的是把距离公式与计数写对，Q4 才考 $O(n)$ 的计数技巧——把 Q2 的距离闭式立住，Q4 的分类讨论就水到渠成。

## 2. 示例

**示例 1**

```text
输入：n = 3, x = 1, y = 3
输出：[6,0,0]
解释：弦 1–3 与链 1–2–3 构成三元环，任意两房之间距离都是 1，
     3 个无序对 × 2 = 6 个有序对。
```

**示例 2**

```text
输入：n = 5, x = 2, y = 4
输出：[10,8,2,0,0]
解释：弦 2–4 缩短了 4 个点对（(1,4)、(1,5)、(2,4)、(2,5)，见 §3.4 演算），
     距离 1、2、3 的有序对分别有 10、8、2 个。
```

**示例 3**

```text
输入：n = 4, x = 1, y = 1
输出：[6,4,2,0]
解释：x = y，弦是自环，图退化为纯链：距离 k 的有序对 = 2(n−k)。
```

## 3. 解题思路

### 3.1 暴力思路：建图 + 全源 BFS

图只有 $n$ 个点、$n$ 条边（链上 $n-1$ 条 + 弦 1 条）。从每个源点做一次 BFS 得到它到其余各点的最短路，再把 $n(n-1)$ 个有序距离逐个进桶，时间 $O(n^2)$，$n \le 100$ 时约 $10^4$ 规模，轻松通过（代码见 §7）。更无脑的 Floyd–Warshall 是 $O(n^3) = 10^6$，也能过。

「建图 → BFS」对**任何边集**都成立，是周赛里最稳的保底路线。但它完全没有利用本题「链 + 一条弦」的特殊结构——这个结构里藏着一个 $O(1)$ 的距离闭式，连图都不用建。

### 3.2 核心观察：链 + 一条弦，最短路只有两类候选

![核心观察：链加一条弦，最短路只有两类候选](images/wc381_q2_cycle_chord_concept.svg)

链 $1 \to 2 \to \cdots \to n$ 是一棵**树**（树上两点间路径唯一），弦 $x$–$y$ 在树上添出一个环。考察任意点对 $i < j$（不妨设 $x \le y$），最短路只有两类候选：

- **候选 ① 直走（不过弦）**：树路唯一，长度就是 $j - i$；
- **候选 ② 绕弦（恰过一次）**：先沿链走到 $x$（$|i-x|$ 步），过弦（$1$ 步），再沿链走到 $j$（$|j-y|$ 步），合计 $|i-x| + 1 + |j-y|$。

$$d(i,j) = \min\bigl(\,j - i,\ \ |i - x| + 1 + |j - y|\,\bigr)$$

> 💡 三个「为什么」：
> 1. **为什么弦至多过一次**：最短路总可取**简单路径**（不走回头路），而「链 + 一条弦」上的简单路径至多过弦一次（§5 引理 2）；
> 2. **为什么绕行只写一项**：过弦有两个方向，$|i-x|+1+|j-y|$ 与 $|i-y|+1+|j-x|$；当 $i \le j$、$x \le y$ 时前者恒不大于后者（§5 引理 3），留一项即可（写两项进 `min` 也正确，只是冗余）；
> 3. **为什么 $x = y$ 不用特判**：$|i-x| + 1 + |j-x| \ge (j-i) + 1 > j - i$（三角不等式），绕行恒比直走多，公式自动退化为纯链。

### 3.3 算法流程

![算法流程：归一化、枚举点对、O(1) 公式、进桶](images/wc381_q2_algorithm_flow.svg)

1. 读入 $n, x, y$，初始化 `res = [0] × n`；
2. 若 $x > y$ 则交换，统一成 $x \le y$（边是无向的）；
3. 双重循环枚举 $1 \le i < j \le n$；
4. $d = \min(j-i,\ |i-x|+1+|j-y|)$；
5. `res[d-1] += 2`（一个无序对 = 两个有序对）；
6. 枚举完毕返回 `res`。

全程**不建图**：没有邻接表、没有队列、没有距离数组，每对只做一次减法、两次绝对值、一次 `min`。

### 3.4 示例演算

![示例演算：n=5, x=2, y=4 逐对进桶](images/wc381_q2_example_walkthrough.svg)

以示例 2 `n = 5, x = 2, y = 4` 演算（$x \le y$ 已满足）。10 个无序对中，4 对绕弦更短：$(1,4)$ 从 3 缩到 2、$(1,5)$ 从 4 缩到 3、$(2,4)$ 从 2 缩到 1、$(2,5)$ 从 3 缩到 2；其余 6 对直走更短。逐对 $\times 2$ 进桶后 `res = [10, 8, 2, 0, 0]`，且 $\sum \text{res} = 20 = 5 \times 4$，通过自检 ✓。

## 4. 算法细节

1. **归一化 $x \le y$**：边是无向的，$(x,y)$ 与 $(y,x)$ 是同一条弦。不交换的话 $|i-x|+1+|j-y|$ 是「走错方向」的绕行，引理 3 的方向归并失效，部分点对会算出偏大的距离（反例见 §8 第 3 条）。

2. **距离 $O(1)$ 闭式**：`d = min(j - i, abs(i - x) + 1 + abs(j - y))`。两个候选分别对应「不过弦」与「恰过弦一次」（两个绕行方向已由引理 3 合并成一项）。

3. **有序对 $\times 2$**：枚举的是 $i < j$ 的无序对，题目要有序对，进桶要 `res[d-1] += 2`。BFS 版则天然按有序对计数（源点 × 终点），不要画蛇添足再乘 2。

4. **下标与值域**：$k$ 从 1 数起而数组从 0 数起，进桶下标是 $d-1$。$d$ 的值域是 $[1, n-1]$——弦只会让距离变短，上界在纯链（$x = y$）的端点对 $(1, n)$ 处取得——因此 `res[d-1]` 永不越界，且 `res` 最后一格（$k = n$）恒为 0。

5. **自环自动退化**：$x = y$ 时公式自动退化为 $d = j - i$（§5 定理 1），既不用特判也不会死循环；BFS 版里自环边被「已访问」判定天然挡掉。

6. **对拍保底**：赛时若不放心公式，$n \le 100$ 允许「BFS 版 + 公式版」双写对拍（§7 附 BFS 版代码），两个 $O(n^2)$ 都瞬间出结果。

## 5. 正确性证明

**引理 1（链上路径唯一）**：去掉弦后，图是一条链（树）。$i$ 到 $j$（$i < j$）的不含弦路径唯一，即 $i, i+1, \ldots, j$，长度 $j - i$；任何不含弦的行走长度 $\ge j - i$。

**证明**：树是无环连通图，任意两点间路径唯一。链上从 $i$ 走到 $j$ 必须覆盖区间 $[i, j]$ 的每个顶点，而简单路径恰好逐格走过去；任何行走若长度小于 $j-i$，由每步至多前进 1 知不可能跨越距离 $j - i$。∎

**引理 2（简单路径至多过弦一次）**：最短路可取简单路径（无重复顶点）；在「链 + 一条弦」上，简单路径要么不含弦（长度恰为 $j - i$），要么恰含弦一次，长度为 $|i-p| + 1 + |j-q|$，其中 $(p, q)$ 取 $(x, y)$ 或 $(y, x)$。

**证明**：若路径重复访问某顶点，删去两次访问之间的闭环段得到不更长的路径，故最短路是简单路径。简单路径至多经过弦一次：弦的每次遍历都要同时踏进 $x$ 与 $y$，两次遍历必使某个端点被重复访问，与简单性矛盾。不含弦的简单路径由引理 1 长度恰为 $j-i$。恰含弦一次的简单路径形如「链段 $i \to p$ + 弦 $p$–$q$ + 链段 $q \to j$」；链上不重复顶点的行走就是沿区间直走，两段长度分别为 $|i-p|$ 与 $|j-q|$，故总长为所述公式。∎

**引理 3（方向归并）**：设 $i \le j$ 且 $x \le y$，则 $|i-x| + |j-y| \le |i-y| + |j-x|$。

**证明**：按 $i, j$ 落在区间 $[x, y]$ 内（内）/ 左（$< x$）/ 右（$> y$）的位置分类（$i \le j$ 排除「$i$ 右、$j$ 左」等不可能组合，恰余六类），逐类展开绝对值，记 $\Delta = (|i-x|+|j-y|) - (|i-y|+|j-x|)$：

| $i$ 的位置 | $j$ 的位置 | $\Delta$ |
|-----------|-----------|---------|
| 内 | 内 | $2(i-j) \le 0$ |
| 左 | 左 | $0$ |
| 右 | 右 | $0$ |
| 左 | 内 | $2(x-j) \le 0$ |
| 内 | 右 | $2(i-y) \le 0$ |
| 左 | 右 | $2(x-y) \le 0$ |

六类均有 $\Delta \le 0$。∎

**定理 1（距离闭式）**：对任意 $1 \le i < j \le n$（$x \le y$），$d(i,j) = \min\bigl(j-i,\ |i-x|+1+|j-y|\bigr)$；特别地 $x = y$ 时 $d(i,j) = j - i$。

**证明**：由引理 2，最短路是简单路径，只有「不含弦」「恰含弦一次」两种形态，长度分别属于 $\{j-i\}$ 与 $\{|i-x|+1+|j-y|,\ |i-y|+1+|j-x|\}$；反之这三个候选都对应真实可行的行走（直走、两个方向绕弦），故 $d$ 等于三者最小值。再由引理 3，$|i-x|+1+|j-y| \le |i-y|+1+|j-x|$，化简得闭式。$x = y$ 时绕行项为 $|i-x|+1+|j-x| \ge (j-i)+1 > j-i$（三角不等式），恒不取，$d = j-i$。∎

**定理 2（计数正确性）**：算法返回的 `res` 满足 $\text{res}[k-1] = \#\{(a,b) : a \ne b,\ d(a,b) = k\}$。

**证明**：算法枚举每个无序对 $\{i, j\}$（$i < j$）恰一次，按定理 1 计算距离 $d$ 并给 $\text{res}[d-1]$ 加 2。距离为 $k$ 的互异有序对 $(a, b)$ 与互异无序对 $\{a, b\}$ 一一对应（每个无序对恰对应 $(i,j)$、$(j,i)$ 两个有序对），由定理 1 距离计算无误，故 $\text{res}[k-1]$ 恰为距离 $k$ 的有序对数。又每个互异有序对的距离唯一，$\sum_k \text{res}[k] = n(n-1)$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n^2)$。枚举 $\binom{n}{2} = \frac{n(n-1)}{2}$ 个无序对，每对 $O(1)$（一次减法、两次绝对值、一次 `min`），$n = 100$ 时约 $5 \times 10^3$ 次运算。BFS 版同为 $O(n^2)$（$n$ 次 BFS，每次摊还处理 $n$ 条边各一遍），但含建图与队列常数。
- **空间复杂度**：$O(1)$（返回数组不计入）——公式版不需要任何辅助数据结构；BFS 版需 $O(n)$ 的邻接表、队列与距离数组。

## 7. 参考代码

### C++（公式枚举）

```cpp
class Solution {
  public:
    vector<int> countOfPairs(int n, int x, int y) {
        if (x > y) swap(x, y);              // 边无向，统一 x <= y
        vector<int> res(n, 0);
        for (int i = 1; i <= n; ++i)
            for (int j = i + 1; j <= n; ++j) {
                int d = min(j - i, abs(i - x) + 1 + abs(j - y));
                res[d - 1] += 2;            // (i,j) 与 (j,i) 两个有序对
            }
        return res;
    }
};
```

### Python（公式枚举）

```python
class Solution:
    def countOfPairs(self, n: int, x: int, y: int) -> List[int]:
        if x > y:
            x, y = y, x                    # 边无向，统一 x <= y
        res = [0] * n
        for i in range(1, n + 1):
            for j in range(i + 1, n + 1):
                d = min(j - i, abs(i - x) + 1 + abs(j - y))
                res[d - 1] += 2            # (i,j) 与 (j,i) 两个有序对
        return res
```

### Python（BFS 保底，可作对拍）

```python
from collections import deque

class Solution:
    def countOfPairs(self, n: int, x: int, y: int) -> List[int]:
        g = [[] for _ in range(n + 1)]
        for i in range(1, n):              # 链：i — i+1
            g[i].append(i + 1)
            g[i + 1].append(i)
        g[x].append(y)                     # 弦：x — y（x == y 时是自环，无害）
        g[y].append(x)

        res = [0] * n
        for s in range(1, n + 1):          # 每个源点做一次 BFS
            dist = [-1] * (n + 1)
            dist[s] = 0
            q = deque([s])
            while q:
                u = q.popleft()
                for v in g[u]:
                    if dist[v] == -1:
                        dist[v] = dist[u] + 1
                        res[dist[v] - 1] += 1   # 源点 × 终点：天然有序对，无需 ×2
                        q.append(v)
        return res
```

> 💡 两版恰好互补：公式版枚举**无序对再 ×2**，BFS 版按「源点 × 终点」直接枚举**有序对**。赛时把两版对着跑一遍随机数据，公式有没有抄错一目了然。

## 8. 边界情况与易错点

1. **有序对漏乘 2**（公式版）：枚举 $i < j$ 后必须 `res[d-1] += 2`，否则示例 1 会输出 `[3,0,0]` 而非 `[6,0,0]`。自检式：$\sum \text{res} = n(n-1)$。
2. **$x = y$ 自环**：无需特判。公式版自动退化为 $d = j - i$（定理 1）；BFS 版自环边被已访问判定挡掉。
3. **忘 swap 归一化**：$x > y$ 时不交换会让绕行方向算反。例如 $n=4, x=3, y=1$，点对 $(1,3)$ 不交换算出 $d = \min(2,\ 2+1+2) = 2$，交换后正确值为 $1$（弦 1–3 使其相邻）。
4. **下标偏移**：$k$ 从 1 开始、数组从 0 开始，进桶用 $d-1$ 不是 $d$。
5. **$d$ 不会等于 $n$**：距离上界是 $n-1$（纯链端点对），`res` 最后一格恒为 0；若算出 $d = n$，多半是直走项写成了 $j-i+1$ 或绕行项多加了 1。
6. **min 不能省候选**：弦不一定更短。如 $x=2, y=4$ 下点对 $(1,2)$ 直走 1 步、绕行 4 步，两项都必须留在 `min` 里。
7. **答案长度是 $n$ 不是 $n-1$**：$k$ 取到 $n$，虽然最后一格恒为 0，长度必须给足。
8. **溢出与规模**：$n \le 100$ 全 `int` 无溢出风险；Floyd $O(n^3) = 10^6$ 也能过但没必要。数据放大到 $10^5$（3017）时两个 $O(n^2)$ 双双超时，必须转向分类讨论 + 差分。
