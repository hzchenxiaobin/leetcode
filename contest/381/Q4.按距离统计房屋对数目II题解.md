# LeetCode 按距离统计房屋对数目 II 题解

## 1. 题目概述

- **标题 / 题号**：按距离统计房屋对数目 II（#3017，hard）
- **链接**：https://leetcode.cn/problems/count-the-number-of-houses-at-a-certain-distance-ii/
- **来源**：LeetCode 第 381 场周赛 Q4
- **难度**：困难
- **标签**：图、分类讨论、差分数组（官方标签 Graph / Prefix Sum——其中的 Prefix Sum 正是本题把 $O(n^2)$ 压到 $O(n)$ 的钥匙）

**题意**：与本场 Q2（#3015）完全同题：编号 $1 \sim n$ 的房屋排成一条链（$i$ 与 $i+1$ 相邻），**另有一条**街道连接房屋 $x$ 与 $y$（可以相等）。对每个 $k$（$1 \le k \le n$），统计最少经过街道数**恰为 $k$** 的**有序**房屋对 $[\text{house}_1, \text{house}_2]$ 数量，返回下标从 1 开始、长度为 $n$ 的数组 `result`。

**约束**：

- $2 \le n \le 10^5$（Q2 是 $100$）
- $1 \le x, y \le n$

> ⚠️ **规模是唯一差别，难度却是断崖**：$n$ 放大 $10^3$ 倍后，Q2 的两个 $O(n^2)$ 做法都变成 $5 \times 10^9 \sim 10^{10}$ 量级，必须换思路。距离闭式原封不动地沿用，本题的全部新意在**计数**。

> 💡 **赛时路线**：先把 Q2 的距离公式立住（那是 Q4 的地基），再在 Q4 上做「分类 + 差分」。两个读题坑与 Q2 相同——**有序对**（$\sum_k \text{result}[k] = n(n-1)$ 是最方便的自检不变式）与 **$x$ 可以等于 $y$**（自环；本题的解法甚至不必为它写特判，见 §8）。

## 2. 示例

**示例 1**

```text
输入：n = 3, x = 1, y = 3
输出：[6,0,0]
解释：弦 1–3 与链 1–2–3 构成三元环，任意两房距离都是 1，
      3 个无序对 × 2 = 6 个有序对。
```

**示例 2**

```text
输入：n = 5, x = 2, y = 4
输出：[10,8,2,0,0]
解释：弦 2–4 使 4 个点对受益（(1,4)、(1,5)、(2,4)、(2,5)，见 §3.4 演算），
      距离 1、2、3 的有序对分别有 10、8、2 个。
```

**示例 3**

```text
输入：n = 4, x = 1, y = 1
输出：[6,4,2,0]
解释：x = y，弦是自环，图退化为纯链：距离 k 的有序对 = 2(n−k)。
```

## 3. 解题思路

### 3.1 暴力思路：$O(n^2)$ 逐对计数——规模不容应

链 + 一条弦共 $n$ 个点、$n$ 条边。Q2 的两个做法——枚举全部 $\binom{n}{2} \approx 5 \times 10^9$ 个无序对逐个进桶、或从每个源点做一次 BFS——都是 $\Theta(n^2)$。$n = 10^5$ 时：

- 枚举 + $O(1)$ 公式：约 $5 \times 10^9$ 次运算；
- 全源 BFS：约 $10^{10}$ 次（还要建图、开队列）。

两者都远超时限（周赛经验上限约 $10^8$）。**「逐对计数」必须整体抛弃**——但 Q2 立住的 $O(1)$ 距离闭式不但不过时，反而是本题的地基。

### 3.2 核心观察：「环 + 尾巴」模型，弦只负责「搬桶」

![核心观察：链加一条弦等于环加两条尾巴](images/wc381_q4_cycle_tail_model.svg)

仍设 $x \le y$（否则交换），记 $d = y - x$。链上 $x \to x+1 \to \cdots \to y$ 这段与弦 $x$–$y$ 围成一个**环**（环长 $C = d + 1$），链的剩余部分是挂在环两侧的**左尾巴** $[1, x-1]$ 与**右尾巴** $[y+1, n]$。

距离闭式与 Q2 完全相同。对点对 $a < b$ 记：

- **旧距离（直走，不过弦）**：$t = b - a$；
- **新距离（绕弦，恰过一次）**：$W = |a - x| + 1 + |b - y|$；

$$d(a, b) = \min(\,t,\ W\,)$$

于是弦的作用只有一个：**当 $W < t$（称该点对「受益」）时，把这个点对从 $t$ 桶搬进 $W$ 桶**。无序对的距离分布可以写成

$$\text{cnt}[k] = \underbrace{(n - k)}_{\text{纯链基线}} + \#\{\text{受益对} : W = k\} - \#\{\text{受益对} : t = k\}$$

> 💡 **为什么这样转化**：纯链的分布是现成的（距离 $k$ 的无序对恰 $n-k$ 个），一分钱不用算；弦的影响被压缩成「哪些点对受益、它们的 $t$ 与 $W$ 各是多少」。只要按位置分类数清楚受益对，剩下的全是加减法。

### 3.3 五类位置：受益条件与计数方式

![五类位置的分类与受益条件](images/wc381_q4_region_classification.svg)

按 $a$、$b$ 落在**左尾巴 / 环 / 右尾巴**的组合（$T_L = [1, x-1]$，$V = [x, y]$，$T_R = [y+1, n]$），点对（$a < b$）恰分五类。统一记 $p = |a - x|$、$q = |b - y|$（于是 $W = p + q + 1$ 恒成立）：

| 类型 | 位置 | 旧 $t$ | 新 $W$ | 受益条件 | 计数方式 |
|------|------|--------|--------|----------|----------|
| 同侧 | 同在 $T_L$ 或同在 $T_R$ | $b-a$ | $\ge t + d + 3$ | 永不 | 不修正 |
| 异侧 | $a \in T_L$，$b \in T_R$ | $p+q+d$ | $p+q+1$ | $d \ge 2$ | 按 $m = p+q$ 逐点 |
| 左尾—环内 | $a \in T_L$，$b \in V$ | $d+p-q$ | $p+q+1$ | $2q \le d-2$ | 按受益 $q$ 区间加 |
| 环内—右尾 | $a \in V$，$b \in T_R$ | $d+q-p$ | $p+q+1$ | $2p \le d-2$ | 按受益 $p$ 区间加 |
| 环内—环内 | $a, b \in V$，间距 $t$ | $t$ | $C - t$ | $2t \ge d+2$ | 按受益 $t$ 点加 |

三个「为什么」：

1. **为什么同侧永不受益**：两点在同一条尾巴上，绕弦要「走到环再折返」，至少多走 $d + 3$ 步（§5 定理 2(a)）；
2. **为什么受益条件长这样**：以「左尾—环内」为例，从 $a$ 先走到 $x$（$p$ 步）后，$x$ 到 $b$ 有环上两个方向——沿链直行 $d - q$ 步、绕弦 $1 + q$ 步，绕弦更短当且仅当 $2q \le d - 2$，直观即 **$b$ 越过环心偏 $y$ 端**；「环内—环内」则是最纯粹的环上两方向取短：$\min(t, C - t)$；
3. **为什么每类都能 $O(1)$ 摊还**：受益条件只依赖**一个**参数（$q$ 或 $p$ 或 $t$）；固定它之后另一个参数取连续区间，$W$ 与 $t$ 随之取**连续区间**——「对连续下标统一 $\pm 1$」正是差分数组的一行操作。

**算法流程**：

1. 交换使 $x \le y$，令 $d = y - x$；开差分数组 `diff`（下标 $1 \sim n$）；
2. **异侧**（需 $d \ge 2$）：令 $P = x - 1$、$Q = n - y$，对 $m = 2, \ldots, P+Q$ 求 $f(m) = \#\{(p, q) : p + q = m\}$（$O(1)$ 公式），点加 `+f(m)` 于 $m+1$、`-f(m)` 于 $m+d$；
3. **左尾—环内**：对每个受益 $q \in [0, \lfloor (d-2)/2 \rfloor]$，区间加 `+1` 于 $[q+2,\ q+x]$、`-1` 于 $[d+1-q,\ d+x-1-q]$；
4. **环内—右尾**：对称地，对每个受益 $p \in [0, \lfloor (d-2)/2 \rfloor]$，区间加 `+1` 于 $[p+2,\ p+n-y+1]$、`-1` 于 $[d+1-p,\ d+n-y-p]$；
5. **环内—环内**：对每个受益 $t \in [\lceil (d+2)/2 \rceil,\ d]$（该间距恰 $d+1-t$ 对），点加 `-(d+1-t)` 于 $t$、`+(d+1-t)` 于 $d+1-t$；
6. 一遍前缀和还原 `diff` 得修正量，加上基线 $n - k$，整体 $\times 2$ 输出。

### 3.4 示例演算

![示例演算：n=5, x=2, y=4 的完整流程](images/wc381_q4_example_walkthrough.svg)

以示例 2 `n = 5, x = 2, y = 4` 演算：$d = 2$、$C = 3$、环 $= [2,4]$、左尾 $= \{1\}$、右尾 $= \{5\}$。

**基线**（当作纯链）：`cnt = [4, 3, 2, 1, 0]`（无序对）。

**受益对恰 4 个**（$d = 2$ 使四类受益条件全部打开）：

| 点对 | 类型 | $t$ | $W$ | 修正 |
|------|------|-----|-----|------|
| (1,5) | 异侧 | 4 | 3 | `cnt[3]+1, cnt[4]−1` |
| (1,4) | 左尾—环内 | 3 | 2 | `cnt[2]+1, cnt[3]−1` |
| (2,5) | 环内—右尾 | 3 | 2 | `cnt[2]+1, cnt[3]−1` |
| (2,4) | 环内—环内 | 2 | 1 | `cnt[1]+1, cnt[2]−1` |

正是 Q2 §3.4 列出的那 4 个被缩短的点对。**还原**：`cnt = [4+1, 3+2−1, 2+1−2, 1−1, 0] = [5, 4, 1, 0, 0]`；**×2**（有序对）得 `res = [10, 8, 2, 0, 0]`，与官方输出一致；自检 $\sum \text{res} = 20 = 5 \times 4$ ✓。

## 4. 算法细节

1. **归一化 $x \le y$**：与 Q2 同因——不交换则「方向归并」（§5 引理 2）失效，绕弦候选会算偏。

2. **基线放最后**：差分数组只装「受益修正」，还原时 `cnt[k] = 前缀和 + (n−k)`，避免与基线混在一起做区间减法。

3. **异侧类的 $f(m)$**：$p \in [1, x-1]$、$q \in [1, n-y]$ 的卷积。合法 $p$ 区间是 $[\max(1, m - Q),\ \min(P, m - 1)]$，其长度即 $f(m)$——随 $m$ 先增、平台、后减的梯形函数；逐 $m$ $O(1)$，总计 $O(P + Q) \le O(n)$。

4. **两类「尾—环」的区间端点**：以左尾—环内为例，固定受益 $q$ 后 $p = 1, \ldots, x-1$ 连续取值，故 $W = p + q + 1 \in [q+2,\ q+x]$、$t = d + p - q \in [d+1-q,\ d+x-1-q]$ 都是**连续区间**，两个「区间整体 $\pm 1$」搞定一个 $q$。注意 $q$ **从 0 开始**——$q = 0$ 即 $b = y$（挂在环右端点上的点对也是受益对，容易漏）。

5. **环内—环内的个数**：间距为 $t$ 的点对恰 $d + 1 - t$ 个（$a$ 从 $x$ 取到 $y - t$），点加的量就是它。

6. **$x = y$ 与 $d = 1$ 自动退化，无需特判**：此时 $d \ge 2$ 挡住异侧类、$\lfloor (d-2)/2 \rfloor < 0$ 使两个「尾—环」循环为空、$\lceil (d+2)/2 \rceil > d$ 使环内循环为空——全部修正落空，只剩纯链基线。直觉：自环 / 连接相邻房屋的弦不比链路更短，无人受益。

7. **溢出**：差分前缀和的峰值出现在 $x = 1$、$y \approx n$（几乎是纯环）时，约 $\frac{n^2}{8} \approx 1.25 \times 10^9$，未超 `int` 但余量不足 2 倍——C++ 直接用 `long long` 最稳；最终答案每个分量 $\le 4n$，`int` 足够。

## 5. 正确性证明

**引理 1（简单路径形态）**：「链 + 一条弦」上从 $a$ 到 $b$（$a < b$）的最短路长度只可能是 $b - a$、$|a - x| + 1 + |b - y|$、$|a - y| + 1 + |b - x|$ 三者之一，且三者都对应真实可行的行走。

**证明**：最短路总可取简单路径（若重复访问某顶点，删去两次访问之间的闭环段，长度不减）。简单路径至多过弦一次：弦的每次遍历都要同时踏入 $x$ 与 $y$，两次遍历必使某个端点被重复访问，与简单性矛盾。不含弦的简单路径是链上唯一的树路，长度 $b - a$；恰含弦一次的简单路径形如「链段 $a \to u$ + 弦 + 链段 $v \to b$」，$(u, v) \in \{(x, y), (y, x)\}$，两条链段长度分别为 $|a - u|$ 与 $|b - v|$。∎

**引理 2（方向归并）**：设 $a \le b$ 且 $x \le y$，则 $|a - x| + |b - y| \le |a - y| + |b - x|$。

**证明**：令 $g(u) = |u - x| - |u - y|$。按 $u$ 与区间 $[x, y]$ 的位置展开：$u \le x$ 时 $g(u) = x - y$；$x \le u \le y$ 时 $g(u) = 2u - x - y$（关于 $u$ 单调增）；$u \ge y$ 时 $g(u) = y - x$。故 $g$ 在全轴单调不减，$a \le b \Rightarrow g(a) \le g(b)$，而
$$\bigl(|a - y| + |b - x|\bigr) - \bigl(|a - x| + |b - y|\bigr) = g(b) - g(a) \ge 0. \qquad \blacksquare$$

**定理 1（距离闭式）**：对 $1 \le a < b \le n$（$x \le y$），$d(a,b) = \min\bigl(b - a,\ |a - x| + 1 + |b - y|\bigr)$。

**证明**：由引理 1，最短路等于三个候选的最小值；由引理 2，候选 $|a - y| + 1 + |b - x|$ 不小于 $|a - x| + 1 + |b - y|$，可从 $\min$ 中去掉。∎

**定理 2（五类分解与受益条件）**：记 $T_L = [1, x-1]$、$V = [x, y]$、$T_R = [y+1, n]$、$d = y - x \ge 1$、$C = d + 1$；对 $a < b$ 统一记 $p = |a - x|$、$q = |b - y|$、$t = b - a$、$W = p + q + 1$。则：

- (a) **同侧**（$a, b$ 同属 $T_L$ 或同属 $T_R$）：$W - t \ge d + 3 > 0$，永不受益；
- (b) **异侧**（$a \in T_L,\ b \in T_R$）：$t = p + q + d$，$W - t = 1 - d$，受益 $\iff d \ge 2$；
- (c) **左尾—环内**（$a \in T_L,\ b \in V$）：$t = d + p - q$，$W - t = 2q + 1 - d$，受益 $\iff 2q \le d - 2$；
- (d) **环内—右尾**（$a \in V,\ b \in T_R$）：$t = d + q - p$，$W - t = 2p + 1 - d$，受益 $\iff 2p \le d - 2$；
- (e) **环内—环内**（$a, b \in V$）：$W = C - t$，$W - t = d + 1 - 2t$，受益 $\iff 2t \ge d + 2$，且间距为 $t$ 的点对恰 $d + 1 - t$ 个。

**证明**：按 $a, b$ 所在区域组合分类（$a < b$ 排除「$a$ 在右、$b$ 在左」型组合，共六种，同侧两种合并为 (a)），穷尽且互斥。每类内 $a, b$ 与 $x, y$ 的大小关系确定，直接展开绝对值：

- (a) $b \le x - 1$ 时 $W - t = (x - a) + (y - b) + 1 - (b - a) = x + y + 1 - 2b \ge x + y + 1 - 2(x - 1) = d + 3$；$a \ge y + 1$ 时 $W - t = 2a - x - y + 1 \ge d + 3$；
- (b) $t = (y + q) - (x - p) = p + q + d$，$W - t = 1 - d$；
- (c) $t = (y - q) - (x - p) = d + p - q$，$W - t = 2q + 1 - d$；
- (d) 与 (c) 关于「左右镜像」（$u \mapsto n + 1 - u$ 同时交换 $x \leftrightarrow y$、$a \leftrightarrow b$）完全对称；
- (e) 此时 $p = a - x$、$q = y - b$，$W = p + q + 1 = (y - x) + 1 - (b - a) = C - t$；间距 $t$ 要求 $a \in [x, y - t]$，共 $(y - t) - x + 1 = d + 1 - t$ 个点对。∎

**定理 3（搬移计数）**：设 $H = \{(a, b) : a < b,\ W(a, b) < t(a, b)\}$ 为全体受益对，则无序距离分布满足

$$\text{cnt}[k] = (n - k) \cdot [\,1 \le k \le n - 1\,] + \#\{(a, b) \in H : W = k\} - \#\{(a, b) \in H : t = k\}$$

（$[\cdot]$ 为示性括号）。**证明**：无序对按是否受益二分，两类互斥且穷尽。非受益对（$W \ge t$）由定理 1 距离为 $t$，恰被基线 $(n - k) = \#\{\text{对} : t = k\}$ 计入，无需修正；受益对（$W < t$）距离为 $W$，基线把它错计入 $t$ 桶，故在 $t$ 处 $-1$、$W$ 处 $+1$。每个点对至多被修正一次，且涉及的桶都在 $[1, n-1]$ 内（$W \ge 1$，$t \le n - 1$）。∎

**定理 4（实现正确性）**：§3.3 的流程输出 `res[k−1] = 2·cnt[k]`。

**证明**：验证各操作的参数化不重不漏。异侧类：$(a, b) \leftrightarrow (p, q) \in [1, x-1] \times [1, n-y]$ 是双射，按 $m = p + q$ 分组，组大小即 $f(m)$。左尾—环内类：受益条件只含 $q$，固定受益 $q$ 后 $p \in [1, x-1]$ 与 $W$ 的取值区间 $[q+2, q+x]$、$t$ 的取值区间 $[d+1-q, d+x-1-q]$ 均一一对应；环内—右尾类同理。环内—环内类：$(a, b) \leftrightarrow t = b - a \in [1, d]$，间距 $t$ 的 $d+1-t$ 个点对共享同一组 $(t, W)$。因此所有点加 / 区间加恰好实现定理 3 的两个计数项；差分数组一遍前缀和还原 `cnt`，最后 $\times 2$ 化无序为有序（距离对称，每个无序对对应两个有序对）。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。异侧类循环 $P + Q \le n - 1$ 次、每次 $O(1)$；两个「尾—环」循环各至多 $\lfloor (d-2)/2 \rfloor + 1 \le d/2 + 1 \le n/2 + 1$ 次、每次 $O(1)$；环内循环至多 $d \le n$ 次；前缀和还原 $O(n)$。$n = 10^5$ 时总计 $10^5$ 量级的常数操作，远低于时限。
- **空间复杂度**：$O(n)$——差分数组 `diff` 与输出数组（若返回值不计，辅助空间即 $O(n)$ 的差分数组）。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    vector<int> countOfPairs(int n, int x, int y) {
        if (x > y) swap(x, y);                     // 弦无向，统一 x <= y
        int d = y - x;                             // 环长 C = d + 1
        vector<long long> diff(n + 2, 0);          // 差分：cnt[l..r] 整体 +v
        auto add = [&](int l, int r, long long v) {
            l = max(l, 1); r = min(r, n);
            if (l > r) return;
            diff[l] += v; diff[r + 1] -= v;
        };
        if (d >= 2) {                              // ② 异侧尾巴：t=m+d, W=m+1
            int P = x - 1, Q = n - y;              // p∈[1,P], q∈[1,Q]
            for (int m = 2; m <= P + Q; ++m) {     // m = p + q
                long long f = min((long long)P, (long long)m - 1)
                            - max(1, m - Q) + 1;
                if (f > 0) { add(m + 1, m + 1, f); add(m + d, m + d, -f); }
            }
        }
        for (int q = 0; 2 * q <= d - 2; ++q) {     // ③ 左尾—环内：2q <= d-2
            add(q + 2, q + x, 1);                  // W = p+q+1, p∈[1,x-1]
            add(d + 1 - q, d + x - 1 - q, -1);     // t = d+p-q
        }
        for (int p = 0; 2 * p <= d - 2; ++p) {     // ④ 环内—右尾：2p <= d-2
            add(p + 2, p + n - y + 1, 1);          // W = p+q+1, q∈[1,n-y]
            add(d + 1 - p, d + n - y - p, -1);     // t = d+q-p
        }
        for (int t = (d + 3) / 2; t <= d; ++t) {   // ⑤ 环内—环内：2t >= d+2
            long long c = d + 1 - t;               // 间距 t 的点对数
            add(t, t, -c);
            add(d + 1 - t, d + 1 - t, c);          // W = C - t
        }
        vector<int> res(n);
        long long s = 0;
        for (int k = 1; k <= n; ++k) {
            s += diff[k];                          // 前缀和还原修正量
            long long cnt = s + (k < n ? n - k : 0);
            res[k - 1] = (int)(2 * cnt);           // 加基线，×2 成有序对
        }
        return res;
    }
};
```

### Python

```python
class Solution:
    def countOfPairs(self, n: int, x: int, y: int) -> List[int]:
        if x > y:
            x, y = y, x                    # 弦无向，统一 x <= y
        d = y - x                          # 环长 C = d + 1
        diff = [0] * (n + 2)               # 差分：cnt[l..r] 整体 +v

        def add(l, r, v):
            l, r = max(l, 1), min(r, n)
            if l <= r:
                diff[l] += v
                diff[r + 1] -= v

        if d >= 2:                         # ② 异侧尾巴：t=m+d, W=m+1
            P, Q = x - 1, n - y            # p∈[1,P], q∈[1,Q]
            for m in range(2, P + Q + 1):  # m = p + q
                f = min(P, m - 1) - max(1, m - Q) + 1
                if f > 0:
                    add(m + 1, m + 1, f)   # 搬入新桶 W = m+1
                    add(m + d, m + d, -f)  # 搬出旧桶 t = m+d
        for q in range((d - 2) // 2 + 1):  # ③ 左尾—环内：2q <= d-2
            add(q + 2, q + x, 1)           # W = p+q+1, p∈[1,x-1]
            add(d + 1 - q, d + x - 1 - q, -1)   # t = d+p-q
        for p in range((d - 2) // 2 + 1):  # ④ 环内—右尾：2p <= d-2
            add(p + 2, p + n - y + 1, 1)   # W = p+q+1, q∈[1,n-y]
            add(d + 1 - p, d + n - y - p, -1)   # t = d+q-p
        for t in range((d + 3) // 2, d + 1):    # ⑤ 环内—环内：2t >= d+2
            c = d + 1 - t                  # 间距 t 的点对数
            add(t, t, -c)
            add(d + 1 - t, d + 1 - t, c)   # W = C - t

        res, s = [], 0
        for k in range(1, n + 1):
            s += diff[k]                   # 前缀和还原修正量
            res.append(2 * (s + (n - k if k < n else 0)))  # + 基线，×2
        return res
```

> 💡 赛后自检三板斧：(1) $\sum \text{res} = n(n-1)$；(2) `res[n−1] == 0`（距离上界 $n-1$）；(3) 与 Q2 的 $O(n^2)$ 枚举版在 $n \le 100$ 的随机数据上对拍（本文两份代码均已在 $n \le 14$ 全量 + 随机数据上与 BFS 暴力对拍通过）。

## 8. 边界情况与易错点

1. **$x = y$（自环）与 $d = 1$（弦连相邻房屋）都不用特判**：所有受益条件自动落空（§4 第 6 条）。但想清楚「为什么能退化」再省特判——异侧类的 $d \ge 2$ 门禁是**必须**的：$d = 0$ 时若误入该类，会产生 $W = m + 1 > t = m$ 的**反向搬移**（把点对搬远了）。
2. **忘 swap 归一化**：$x > y$ 不交换则引理 2 的方向归并失效。沿用 Q2 反例：$n = 4, x = 3, y = 1$，点对 $(1, 3)$ 不交换算出 $2$，交换后正确值为 $1$。
3. **左尾—环内的 $q$ 从 0 开始**：$q = 0$ 即 $b = y$（点对终点恰是环的右端点），是容易漏的受益对；同理环内—右尾的 $p = 0$（$a = x$）。
4. **受益是严格不等**：$W < t \iff 2q + 1 < d \iff 2q \le d - 2$，取整时别写成 $2q < d$。顺带一提，即便把 $W = t$ 的临界对也算进「受益」，$+1@W$ 与 $-1@t$ 落在同一个桶、自动抵消，无伤大雅——但**千万别把 $W > t$ 的对算进来**（那才是真正的错误搬移）。
5. **C++ 中间量用 `long long`**：差分前缀和峰值约 $n^2/8 \approx 1.25 \times 10^9$（$x = 1$、$y \approx n$ 的近纯环形态，由⑤类贡献），未超 `int` 上限 $2.1 \times 10^9$ 但余量不足 2 倍；最终答案分量 $\le 4n$，`int` 足够。
6. **有序对 ×2 与下标偏移**：全程按无序对计数、最后统一 $\times 2$；进桶用 1-based 的 $k$，输出 `res[k−1]`。
7. **答案长度是 $n$ 不是 $n-1$**：$k$ 取到 $n$，虽然最后一格恒为 0（距离上界 $n-1$），长度必须给足。
8. **别把 Q2 的代码直接交上来**：$n = 10^5$ 时枚举版约 $5 \times 10^9$ 次运算、BFS 版约 $10^{10}$ 次，必然 TLE——本题的得分点正是把逐对计数改成区间计数。
