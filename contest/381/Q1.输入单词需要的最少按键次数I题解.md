# LeetCode 输入单词需要的最少按键次数 I 题解

## 1. 题目概述

- **标题 / 题号**：输入单词需要的最少按键次数 I（#3014，easy）
- **链接**：https://leetcode.cn/problems/minimum-number-of-pushes-to-type-word-i/
- **来源**：LeetCode 第 381 场周赛 Q1
- **难度**：简单
- **标签**：贪心、数学、字符串

**题意**：给定仅由**互不相同**的小写字母组成的字符串 `word`，允许把编号 $2 \sim 9$ 的 **8 个按键**重新映射到不同的字母集合：每个键可挂**任意多个**字母（也可空着），每个字母必须**恰好**挂到一个键上。挂某键第 $p$ 位的字母，每输入一次要连按 $p$ 次键。请自行设计映射，使输入整个 `word` 的总按键次数最少，返回该最小值。

**约束**：

- $1 \le \text{word.length} \le 26$；
- `word` 仅由小写英文字母组成；
- `word` 中所有字母**互不相同**。

> 💡 **赛时背景**：本题的放开版正是本场 Q3（[3016. 输入单词需要的最少按键次数 II](https://leetcode.cn/problems/minimum-number-of-pushes-to-type-word-ii/)）——那边允许字母重复、串长放到 $10^5$。两题共用同一套「8 键分层」洞察：本题是「每层放 8 个**字母**」，Q3 升级为「每层放 8 个**频率**」。先把本题的层计数闭式立住，Q3 只是多一步统计与排序。

## 2. 示例

**示例 1**

```text
输入：word = "abcde"
输出：5
解释：5 个字母各占一个键的第 1 位，各按 1 次：1×5 = 5。
```

**示例 2**

```text
输入：word = "xycdefghij"
输出：12
解释：x ~ h 共 8 个字母占 8 个键的第 1 位（各按 1 次）；
      i、j 挤到某键第 2 位（各按 2 次）。
      总代价 = 8×1 + 2×2 = 12。
```

**补充示例（自造，覆盖满字母表）**

```text
输入：word = "abcdefghijklmnopqrstuvwxyz"
输出：56
解释：26 = 8+8+8+2：三层满员 + 2 个字母落第 4 位。
      总代价 = 8×1 + 8×2 + 8×3 + 2×4 = 8 + 16 + 24 + 8 = 56。
```

## 3. 解题思路

### 3.1 暴力思路

把 $m \le 26$ 个互异字母分到 8 个键、再排定每个键内部的先后次序，方案数是 $m!$ 量级的组合爆炸（每个键还是有序列表）。搜索彻底没戏——但签到题的正确打开方式本来也不是想怎么搜，而是抓住题面的两个关键词：**互不相同**（每个字母只被计费一次）与 **8 个键**（位次供给按层翻倍），直接奔贪心闭式去。

### 3.2 核心观察：字母互异 ⇒ 答案只由长度 $n$ 决定

![核心观察：八键分层，每层 8 个浅槽](images/wc381_q1_keypad_layers.svg)

**观察一：每个字母只交一次「位次税」。** `word` 中字母互不相同，每个字母恰出现一次，其贡献就是它的位次 $p$：

$$\text{ans} = \sum_{c} \text{pos}(c)$$

是**哪些**字母、挂到**哪个**键、同位次内部谁先谁后，统统不影响代价——既不需要哈希计数，也不需要排序，甚至连字母本身都不必保留。

**观察二：位次供给分层，每层 8 个。** 8 个键各自都能提供第 $1$ 位、第 $2$ 位、……，所以任何合法映射中位次 $\le p$ 的槽至多 $8p$ 个。把 $n$ 个字母「前 8 个占第 1 位、接着 8 个占第 2 位、……」分层填入，恰好把每层供给顶满。因 $n \le 26 = 8+8+8+2$，位次至多 4。

两件事合起来：答案只是 $n = |\text{word}|$ 的函数

$$\text{ans}(n) = \sum_{i=1}^{n} \Bigl\lceil \tfrac{i}{8} \Bigr\rceil$$

### 3.3 算法流程：一层循环，或一步闭式

两种写法任选其一：

1. **循环版**：`ans = Σ (i//8 + 1)`，$i$ 从 0 到 $n-1$——第 $i$ 个字母落在第 $\lfloor i/8 \rfloor + 1$ 层；
2. **闭式版**：设 $n = 8q + r$（$0 \le r < 8$），满 $q$ 层贡献 $8 \times (1 + 2 + \dots + q) = 4q(q+1)$，余下 $r$ 个字母落第 $q+1$ 层各贡献 $q+1$，合并得

$$\text{ans} = (q+1)(4q + r)$$

全程不构造任何键盘方案——$O(1)$ 直出。

### 3.4 示例演算

![示例演算：三档长度一键验算](images/wc381_q1_example_walkthrough.svg)

| $n$ | $q$ | $r$ | 分层 | 计算 | 答案 |
|-----|-----|-----|------|------|------|
| 5（`abcde`） | 0 | 5 | $5 \times 1$ | $(0+1) \times 5$ | 5 |
| 10（`xycdefghij`） | 1 | 2 | $8{\times}1 + 2{\times}2$ | $2 \times (4+2)$ | 12 |
| 26（全字母） | 3 | 2 | $8{\times}1 + 8{\times}2 + 8{\times}3 + 2{\times}4$ | $4 \times (12+2)$ | 56 |

三档分别对应「不满一层」「一层半」「满三层 + 零头」，闭式 $(q+1)(4q+r)$ 一网打尽 ✓

## 4. 算法细节

1. **互异性是题眼**：不需要 `Counter`、不需要排序、不需要知道字母是谁——$\text{len(word)}$ 就是全部输入。赛时手速版一行 `sum(i // 8 + 1 for i in range(len(word)))` 即可收工。
2. **层号 off-by-one 自检**：0 下标第 $i$ 个的代价是 $\lfloor i/8 \rfloor + 1$。自检两格：$i = 7$ 代价 1，$i = 8$ 代价 2。
3. **闭式推导**：$\sum_{i=1}^{n} \lceil i/8 \rceil = 8(1 + \dots + q) + r(q+1) = 4q(q+1) + r(q+1) = (q+1)(4q+r)$，其中 $n = 8q + r$。
4. **分档速查**（每深一层单价 +1）：$n \le 8$ 时答案即 $n$；$9 \sim 16$ 时 $8 + 2(n-8)$；$17 \sim 24$ 时 $24 + 3(n-16)$；$25 \sim 26$ 时 $48 + 4(n-24)$。
5. **键不必用满**：供给上限是「至多」而非「恰要」，字母不足 8 个时多余键自然空置（示例 1 只用 5 个键）；键内字母数也不设上限，分层填法每键每层至多一个只是最优方案恰好长这样。
6. **溢出估算**：上界 $4n \le 104$，`int` 绰绰有余。

## 5. 正确性证明

**引理 1（供给约束）**：任何合法映射中，位次 $\le p$ 的槽至多 $8p$ 个。

**证明**：设第 $j$ 个键挂 $t_j$ 个字母，其位次为 $1 \sim t_j$，其中位次 $\le p$ 的恰有 $\min(t_j, p) \le p$ 个；8 个键合计 $\sum_j \min(t_j, p) \le 8p$。∎

**引理 2（位次逐格下界）**：任一合法映射下，把 $n$ 个字母的位次升序排列为 $c_1 \le c_2 \le \cdots \le c_n$，则对每个 $i$ 有 $c_i \ge \lceil i/8 \rceil$。

**证明**：反证。若 $c_i < \lceil i/8 \rceil$，取 $p = \lceil i/8 \rceil - 1$，则 $8p < i$ 且 $c_i \le p$；由升序性，前 $i$ 个位次全 $\le p$，即位次 $\le p$ 的字母至少 $i > 8p$ 个，与引理 1 矛盾。∎

**定理（分层最优）**：最少总按键次数恰为 $\displaystyle \sum_{i=1}^{n} \lceil i/8 \rceil$。

**证明**：

**（可达）**把第 $1 \sim 8$ 个字母分到 8 个不同键的第 1 位，第 $9 \sim 16$ 个分到各键第 2 位，依此类推——每个键每层至多挂一个字母，是合法映射，总代价即 $\sum_{i=1}^{n} \lceil i/8 \rceil$。

**（下界）**任取合法映射，其总代价为 $\sum_i c_i$（字母互异，每个字母贡献恰为其位次）。由引理 2 逐格 $c_i \ge \lceil i/8 \rceil$，求和得 $\sum_i c_i \ge \sum_{i=1}^{n} \lceil i/8 \rceil$。

综合两方面，$\text{OPT} = \sum_{i=1}^{n} \lceil i/8 \rceil$。∎

**推论（答案只依赖 $n$）**：字母互异时所有字母权重相同（均为 1），「哪些字母占浅层」的任何选择代价一致；同位次内挂到哪个键也不影响。故输出与具体键盘方案、与字母集合本身均无关，只由 $n$ 决定。

## 6. 复杂度分析

- **时间复杂度**：$O(n)$——读一遍串取长度（若视 $n$ 已知则闭式为 $O(1)$）。$n \le 26$，任何写法都是常数级。
- **空间复杂度**：$O(1)$。不建任何计数容器，只存 $q, r$ 与累加器。

## 7. 参考代码

### C++（循环版：分层计数）

```cpp
class Solution {
  public:
    int minimumPushes(string word) {
        int ans = 0;
        for (int i = 0; i < (int)word.size(); ++i)
            ans += i / 8 + 1;          // 第 i 个字母（0 下标）落第 i/8 + 1 层
        return ans;
    }
};
```

### C++（闭式版：O(1) 直出）

```cpp
class Solution {
  public:
    int minimumPushes(string word) {
        int n = word.size(), q = n / 8, r = n % 8;
        return (q + 1) * (4 * q + r);  // 8×(1+…+q) + r×(q+1)
    }
};
```

### Python（闭式版）

```python
class Solution:
    def minimumPushes(self, word: str) -> int:
        q, r = divmod(len(word), 8)
        return (q + 1) * (4 * q + r)
```

一行循环版（比赛中两种写法二选一即可）：

```python
class Solution:
    def minimumPushes(self, word: str) -> int:
        return sum(i // 8 + 1 for i in range(len(word)))
```

## 8. 边界情况与易错点

1. **可用键是 8 个，不是 10/12 个**：只有 $2 \sim 9$ 映射字母，`1`、`*`、`#`、`0` 不对应任何字母——分母是 8，不是 10。
2. **$n \le 8$**：每字母独占一键第 1 位，答案就是 $n$ 本身。
3. **$n = 26$ 满字母表**：$8 + 16 + 24 + 8 = 56$，位次封顶 4；这也是本题答案的全域上界。
4. **层号 off-by-one**：0 下标代价 $\lfloor i/8 \rfloor + 1$；自检 $i = 7 \to 1$、$i = 8 \to 2$。误写 $\lceil i/8 \rceil$（0 下标）会把第 8 个字母多压一层。
5. **别顺手 `Counter`**：本题用不上频率统计（Q3 才需要）——多写无妨，但说明没抓住「互异」这个题眼。
6. **自带不存在的约束**：老式 T9「每键 3 个字母」「8 键必须用满」都不是本题条件；键可空着，键内字母数不限。
7. **答案上界 104**：无溢出风险，`int` 安全。
