# LeetCode 施咒的最大总伤害 题解

## 1. 题目概述

- **标题 / 题号**：施咒的最大总伤害（#3186，medium）
- **链接**：https://leetcode.cn/problems/maximum-total-damage-with-spell-casting/
- **来源**：LeetCode 第 402 场周赛 Q3
- **难度**：中等
- **标签**：数组、哈希表、排序、动态规划、双指针、计数

**题意**：给定数组 `power`，每个元素是一个咒语的伤害值，可能有多个咒语伤害值相同。若使用了某个伤害值为 $d$ 的咒语，就**不能**再使用伤害值为 $d-2$、$d-1$、$d+1$、$d+2$ 的咒语；每个咒语最多使用一次。求可获得的伤害总和的最大值。

**约束**：

- $1 \le power.length \le 10^5$
- $1 \le power[i] \le 10^9$

> 💡 **周赛现场策略**：看到"禁用 $\pm 2$"应立刻联想到 [740. 删除并获得点数](https://leetcode.cn/problems/delete-and-earn/)——那是禁用 $\pm 1$ 的版本。本题是它的**双重加强**：冲突带从 $\pm 1$ 加宽到 $\pm 2$，值域从 $10^4$ 涨到 $10^9$。第一反应把 740 的值域桶数组搬过来会 MLE，正解是"哈希计数 + 排序去重 + 值域上的打家劫舍"。想清楚"同值可以全取"这一步，状态转移就水到渠成。

## 2. 示例

**示例 1**

```text
输入：power = [1,1,3,4]
输出：6
解释：可以使用咒语 0、1、3，伤害值分别为 1、1、4，总伤害值为 6。
      1 与 4 相差 3（恰好安全），1 与 3 相差 2 冲突，3 与 4 相差 1 冲突。
```

**示例 2**

```text
输入：power = [7,1,6,6]
输出：13
解释：可以使用咒语 1、2、3，伤害值分别为 1、6、6，总伤害值为 13。
      两个 6 同值互不禁用、全取得 12；7 与 6 相差 1，只能二选一。
```

**示例 3（同值堆叠）**

```text
输入：power = [5,5,5,5]
输出：20
解释：四个 5 互不冲突（禁用列表是 3、4、6、7，不含 5 自己），全取得 20。
```

## 3. 解题思路

### 3.1 暴力思路：子集枚举与贪心双双失效

最直接的做法是枚举咒语子集并检查任意两个所用值之差都不属于 $\{1,2\}$，子集数 $2^n$，$n \le 10^5$ 直接爆炸；即使在 $m$ 个**不同值**上枚举，$m$ 仍可达 $10^5$。

按"伤害从大到小能取就取"的贪心也不对：`power = [2,2,3]` 中先取 3 会禁掉两个 2（得 3），而最优是全取两个 2（得 4）。**互斥的代价按"值"结算，收益却按"个数"累积**——结算口径的不对称正是"必须 DP"的经典信号。

### 3.2 核心观察：同值捆绑 + 值域打家劫舍

![取值禁区与同值全取](images/spell_damage_conflict_zone.svg)

**观察一（同值要么全用、要么全不用）**：伤害同为 $v$ 的咒语互不冲突——禁用列表是 $v \pm 1$ 与 $v \pm 2$，不含 $v$ 本身。一旦用了第一个 $v$，禁区 $[v-2, v+2]$ 的"代价"就已付清，之后每个 $v$ 都是零额外代价的纯收益（伤害为正）。因此最优解中每个值要么 $cnt(v)$ 个全用、要么一个不用，收益聚合为 $v \cdot cnt(v)$。

**观察二（排序后兼容集是前缀）**：把不同值升序排列为 $\text{vals}$。与 $v$ 冲突的值只能落在 $[v-2, v+2]$ 内；比 $v$ 小的兼容值恰是"$\le v-3$ 的全体"，在有序数组中构成**一个前缀**。设 $j$ 为满足 $\text{vals}[j] \ge v-2$ 的最小下标，则兼容前缀为 $\text{vals}[0..j-1]$。

于是问题变成：**在升序值序列上，每个值可选可不选、相近值互斥，最大化加权收益**——打家劫舍在值域上的推广。

### 3.3 算法流程：哈希计数 + 双指针 DP

![DP 转移模型](images/spell_damage_dp_model.svg)

定义 $dp[i]$ 为只考虑前 $i$ 小的不同值能取得的最大总伤害，$dp[0] = 0$：

$$dp[i+1] = \max\big(dp[i],\ \ dp[j] + \text{vals}[i] \cdot cnt(\text{vals}[i])\big)$$

1. **计数**：哈希表统计每个值 $v$ 的出现次数 $cnt(v)$；
2. **排序**：取出全部不同值，升序得 $\text{vals}[0..m-1]$；
3. **递推**：对 $i = 0, \ldots, m-1$，先双指针前移 `while vals[j] < vals[i] - 2: j++`，再做上述转移；
4. 返回 $dp[m]$。

### 3.4 示例演算

![示例逐步走查表](images/spell_damage_walkthrough.svg)

以 `power = [1,1,3,4]` 为例，$\text{vals} = [1,3,4]$，$cnt = \{1{:}2,\ 3{:}1,\ 4{:}1\}$：

| $i$ | $v$ | $j$（首个 $\ge v-2$） | $dp[j]$ | 不取 $dp[i]$ | 取 $dp[j]+v\cdot cnt$ | $dp[i+1]$ |
|-----|-----|----------------------|---------|--------------|----------------------|-----------|
| 0 | 1 | 0 | 0 | 0 | $0+1\times2=2$ | 2（取） |
| 1 | 3 | 0（值 1 与 3 差 2，冲突） | 0 | 2 | $0+3\times1=3$ | 3（取） |
| 2 | 4 | 1（值 3 差 1 冲突，值 1 差 3 兼容） | 2 | 3 | $2+4\times1=6$ | 6（取） |

$dp[3] = 6$：选值 $1$（两个，共 2）与值 $4$，$2+4=6$ ✓。

再看 `power = [7,1,6,6]`，$\text{vals} = [1,6,7]$，$cnt = \{1{:}1,\ 6{:}2,\ 7{:}1\}$：

| $i$ | $v$ | $j$ | $dp[j]$ | 不取 $dp[i]$ | 取 $dp[j]+v\cdot cnt$ | $dp[i+1]$ |
|-----|-----|-----|---------|--------------|----------------------|-----------|
| 0 | 1 | 0 | 0 | 0 | $0+1=1$ | 1（取） |
| 1 | 6 | 1（值 1 差 5，前移） | 1 | 1 | $1+12=13$ | 13（取） |
| 2 | 7 | 1（值 6 差 1，停住） | 1 | 13 | $1+7=8$ | 13（不取） |

$dp[3] = 13$ ✓。注意最后一行：值 7 与值 6 冲突，取 7 的基准必须退回 $dp[1]$，收益 8 反而不如已有的 13——这正是"取/不取都要保留"的体现。

## 4. 算法细节

1. **值域 $10^9$ 不能建桶**：740 的值域 $10^4$ 可以开桶数组按下标 DP；本题必须"哈希计数 + 键排序"，复杂度与值域无关、只与元素个数相关。
2. **同值收益聚合**：把值 $v$ 的所有咒语合成一笔收益 $v \cdot cnt(v)$，DP 只在 $m \le n$ 个不同值上进行。
3. **双指针求 $j$**：$\text{vals}[i]-2$ 随 $i$ 单调不减，故 $j$ 单调不回退，整个循环中 $j$ 总移动量 $\le m$，均摊 $O(1)$；且 $\text{vals}[i] \ge \text{vals}[i]-2$ 恒成立，`while` 最多停在 $j=i$，**天然无越界，不需要上界保护**。
4. **等价二分写法**：$j$ 也可用 `lower_bound(vals.begin(), vals.end(), vals[i]-2) - vals.begin()` 一次求出，单次 $O(\log m)$；双指针更省。
5. **回看距离是常数**：$\text{vals}$ 互异且有序，$[v-2, v-1]$ 内至多容纳 2 个整数，故 $i - j \le 2$——$dp[i+1]$ 只依赖最近 3 项，`dp` 数组可压成 3 个滚动变量（`vals` 本身仍需 $O(m)$，属锦上添花）。
6. **64 位整数**：单值收益最大 $10^9 \times 10^5 = 10^{14}$，答案上界 $\sum power[i] \le 10^{14}$，C++ 必须在**乘法前**转 `long long`，否则 `int × int` 当场截断。

## 5. 正确性证明

**引理 1（同值全取）**：存在最优方案，对每个伤害值 $v$，要么使用全部 $cnt(v)$ 个伤害为 $v$ 的咒语，要么一个也不用。

**证明**：禁用关系是对称的——伤害 $a$ 的咒语禁用伤害 $b$ 的咒语当且仅当 $|a-b| \in \{1,2\}$（此时 $a$ 也落在 $b$ 的禁用列表中）。设某最优方案用了 $k$ 个值为 $v$ 的咒语且 $0 < k < cnt(v)$。由可行性，方案所用值两两之差不属于 $\{1,2\}$，特别地不含 $v \pm 1$ 与 $v \pm 2$。把剩下的 $cnt(v)-k$ 个值为 $v$ 的咒语全部加入：所用值集合没有变化（仍是原来的值），仍两两之差不在 $\{1,2\}$ 中，故方案仍可行；而总伤害增加 $(cnt(v)-k)\cdot v > 0$，与最优性矛盾。∎

**引理 2（可行方案 = 独立值集）**：咒语集合 $S$ 可行，当且仅当 $S$ 中出现的所有互异伤害值两两之差的绝对值 $\ge 3$。

**证明**：由对称禁用关系，$S$ 可行 $\iff$ 不存在两个所用咒语的值差属于 $\{1,2\}$ $\iff$ 互异值之差 $\notin \{0,1,2\}$（同值差为 0 是允许的）$\iff$ 互异值两两之差 $\ge 3$。∎

**定理（DP 正确性）**：按 §3.3 转移递推，$dp[i]$ 恰为仅在 $\text{vals}[0..i-1]$ 上取值的可行方案的最大总伤害，从而 $dp[m]$ 为答案。

**证明**：对 $i$ 归纳，$dp[0]=0$ 显然。设 $dp[0..i]$ 均正确，考虑前 $i+1$ 个值上的最优方案 $S$（由引理 1，可设 $S$ 对每个值全取或不取）：

- 若 $S$ 不含 $\text{vals}[i]$：则 $S$ 是前 $i$ 个值上的可行方案，$w(S) \le dp[i]$；反之 $dp[i]$ 对应的方案在前 $i+1$ 个值上仍可行（去掉一个值不影响其余值两两差 $\ge 3$），故 $dp[i+1] \ge dp[i]$。
- 若 $S$ 含 $\text{vals}[i]$：由引理 2，$S$ 中其余值与 $\text{vals}[i]$ 之差 $\ge 3$，又都 $\le \text{vals}[i]$，故都 $\le \text{vals}[i]-3$，即整数意义下都 $< \text{vals}[i]-2$，全落在兼容前缀 $\text{vals}[0..j-1]$ 内（$j$ 为首个 $\ge \text{vals}[i]-2$ 的下标）。这些其余值构成前 $j$ 个值上的可行方案，故 $w(S) \le dp[j] + \text{vals}[i] \cdot cnt(\text{vals}[i])$；反之，"$dp[j]$ 的最优方案 + 全部值为 $\text{vals}[i]$ 的咒语"中，新值与兼容前缀中每个值之差 $\ge 3$，由引理 2 可行，收益恰为 $dp[j] + \text{vals}[i] \cdot cnt(\text{vals}[i])$。

两种情形取 max，$dp[i+1]$ 恰为前 $i+1$ 个值上的最优，归纳成立；取 $i = m$ 即全局答案。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \log n)$。哈希计数 $O(n)$；键排序 $O(m \log m)$（$m$ 为不同值个数，$m \le n$）；DP 循环 $O(m)$——双指针 $j$ 总移动量 $\le m$，均摊每次 $O(1)$。
- **空间复杂度**：$O(m)$。哈希表、值数组与 `dp` 数组均按不同值个数计；`dp` 可进一步压成 $O(1)$ 滚动变量（§4 第 5 点），但排序所需的值数组不可避免。

## 7. 参考代码

### C++（哈希计数 + 双指针 DP）

```cpp
class Solution {
public:
    long long maximumTotalDamage(vector<int>& power) {
        unordered_map<int, int> cnt;
        for (int p : power) cnt[p]++;
        vector<int> vals;
        for (auto& [v, c] : cnt) vals.push_back(v);
        sort(vals.begin(), vals.end());
        int m = vals.size();
        vector<long long> dp(m + 1);          // dp[i]: 前 i 个不同值的最大总伤害
        int j = 0;                            // 首个 vals[j] >= vals[i]-2 的下标
        for (int i = 0; i < m; i++) {
            while (vals[j] < vals[i] - 2) j++;
            dp[i + 1] = max(dp[i], dp[j] + 1LL * vals[i] * cnt[vals[i]]);
        }
        return dp[m];
    }
};
```

### Python

```python
from collections import Counter

class Solution:
    def maximumTotalDamage(self, power: List[int]) -> int:
        cnt = Counter(power)
        vals = sorted(cnt)
        m = len(vals)
        dp = [0] * (m + 1)                    # dp[i]: 前 i 个不同值的最大总伤害
        j = 0                                 # 首个 vals[j] >= v - 2 的下标
        for i, v in enumerate(vals):
            while vals[j] < v - 2:
                j += 1
            dp[i + 1] = max(dp[i], dp[j] + v * cnt[v])
        return dp[m]
```

> 💡 两个易替换件：把双指针换成 `j = bisect_left(vals, v - 2)` 效果等价（整体仍 $O(n\log n)$）；把 `dp` 数组换成 3 个滚动变量可省一份 $O(m)$ 空间（回看距离 $\le 3$，见 §4 第 5 点）。核心转移一行不变。

## 8. 边界情况与易错点

1. **乘法溢出是第一坑**：$v \cdot cnt$ 最大 $10^{14}$，`int × int` 在乘法处就截断——C++ 必须写 `1LL * vals[i] * cnt[...]`；返回类型为 `long long`（本题签名已约定）。
2. **同值漏乘个数**：只把值入 DP、忘记乘 $cnt(v)$，示例 2 会算出 8 而非 13——同值必须聚合为 $v \cdot cnt(v)$。
3. **把禁带误写成 $\pm 3$**：差恰好为 3 的两个值**兼容**（示例 1 的 1 与 4）；$j$ 的界定是 `vals[j] < v - 2`（即兼容前缀 $\le v-3$），off-by-one 是本题最典型的 WA。
4. **双指针要不要加越界保护**：`while (vals[j] < vals[i] - 2)` 不需要 `j < m`——`vals[i] ≥ vals[i]-2` 恒成立，$j$ 必停在 $\le i$；加保护反而不必要。
5. **哈希计数后忘记排序**：`unordered_map` 遍历顺序无序，DP 前必须按键排序（Python 直接 `sorted(cnt)`）。
6. **$m = 1$（所有咒语同值）**：答案 $v \cdot n$，首步转移 $dp[1] = \max(0,\ g)$ 自然覆盖，无需特判；$n = 1$ 同理。
7. **贪心心魔**：从最大值开始"能取就取"会被 `[2,2,3]` 这类用例反杀，必须把"取 / 不取"两种决策都留在 max 里。
