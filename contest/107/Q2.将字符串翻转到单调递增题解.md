# LeetCode 将字符串翻转到单调递增 题解

## 1. 题目概述

- **标题 / 题号**：将字符串翻转到单调递增（#926，medium）
- **链接**：https://leetcode.cn/problems/flip-string-to-monotone-increasing/
- **来源**：LeetCode 第 107 场周赛 Q2
- **难度**：中等
- **标签**：字符串、动态规划

**题意**：二进制字符串若形如「若干 0 后面跟若干 1」（任一侧可以为空），则称其**单调递增**。给定二进制串 `s`，每次操作可以把一个 `0` 翻成 `1`、或把一个 `1` 翻成 `0`，求使 `s` 单调递增的**最少**翻转次数。

**约束**：

- $1 \le \text{s.length} \le 10^5$
- `s[i]` 为 `'0'` 或 `'1'`

## 2. 示例

**示例 1**

```text
输入：s = "00110"
输出：1
解释：翻转最后一个 0 → "00111"。
```

**示例 2**

```text
输入：s = "010110"
输出：2
解释：可翻成 "011111"（把第 1 位的 0 变 1）或 "000111"（把第 4 位的 1 变 0），都是 2 次。
```

**示例 3**

```text
输入：s = "00011000"
输出：2
解释：全部翻成 "00000000"（把两个 1 翻掉），或翻成 "00011111" 也是 2 次。
```

## 3. 解题思路

### 3.1 暴力思路

先想清楚「最终形态」长什么样：单调递增的二进制串必然是 $0^a 1^{n-a}$，由**分界点** $a$ 唯一决定（$0 \le a \le n$）。

于是最朴素的暴力是：枚举 $a = 0, 1, \dots, n$，对每个 $a$ 统计
$$\text{cost}(a) = \#\{\text{s}[0..a) \text{ 中的 } 1\} + \#\{\text{s}[a..n) \text{ 中的 } 0\}$$
取最小值。复杂度 $O(n^2)$：$n = 10^5$ 时约 $10^{10}$ 次运算，**超时**。

若预处理后缀 0 的个数，则单次 $O(1)$、总 $O(n)$。这已经很好了，但还能更省：**不必知道每个 $a$ 的代价，只需要在线维护最小代价**。

### 3.2 核心观察：扫描到第 $i$ 位时，只需两个数

![单调递增 ⇔ 存在分界点](images/wc107_q2_split_concept.svg)

顺序扫描，维护：

- `ones`：当前**前缀**中 `1` 的个数；
- `flips`：使**当前前缀**单调递增所需的最小翻转数。

关键的一步是遇到 `0` 时的抉择。设当前前缀为 $p$，$p$ 的最后一个字符是 `0`：

- **方案一**：把这个 `0` 翻成 `1`。那么前缀除最后一位外已经单调，代价 $= \text{flips} + 1$；
- **方案二**：这个 `0` 保持 `0`。由于它是最右边的字符，保持 `0` 意味着**整个前缀必须全是 0**，于是此前所有的 `1` 都得翻掉，代价 $= \text{ones}$。

两者取小：
$$\text{flips} \leftarrow \min(\text{flips} + 1,\ \text{ones})$$

遇到 `1` 时无需抉择：把 `1` 接在任意单调前缀的末尾仍单调，代价不变，只需 `ones += 1`。

> 💡 妙处在于：**方案二把「分界点」隐含地记录了下来**。`ones` 就是「若此刻设为分界点，左侧需要翻掉的 1 的个数」，无需真正枚举 $a$。

### 3.3 算法流程

![线性 DP：ones 与 flips 两个状态量](images/wc107_q2_dp_flow.svg)

```text
1. ones = 0, flips = 0
2. for c in s:
       if c == '1':  ones += 1
       else:         flips = min(flips + 1, ones)
3. 返回 flips
```

循环结束时 `flips` 就是「整个串的最优代价」，因为每个前缀都会被处理一次，最后一个前缀就是全串。

### 3.4 示例演算

![示例演算：s = "00110"](images/wc107_q2_walkthrough.svg)

`s = "00110"`：

| c | ones | flips | 说明 |
|---|------|-------|------|
| `0` | 0 | $\min(0+1, 0) = 0$ | 保持 0 更省 |
| `0` | 0 | 0 | 同上 |
| `1` | 1 | 0 | 接上 1，代价不变 |
| `1` | 2 | 0 | 同上 |
| `0` | 2 | $\min(0+1, 2) = 1$ | 翻成 1 比翻掉前面的 2 个 1 更省 |

答案 1，对应把最后一个 `0` 翻成 `1` 得到 `"00111"`，与官方解释一致。

再看 `s = "010110"`：

| c | ones | flips |
|---|------|-------|
| `0` | 0 | 0 |
| `1` | 1 | 0 |
| `0` | 1 | $\min(1, 1) = 1$ |
| `1` | 2 | 1 |
| `1` | 3 | 1 |
| `0` | 3 | $\min(2, 3) = 2$ |

答案 2，与官方输出一致。

## 4. 算法细节

1. **`flips` 的初值**：0。空前缀天然单调，代价 0。
2. **只在遇到 `0` 时更新 `flips`**：遇到 `1` 时若更新会把「把 1 翻成 0」当成候选，那是更差的方案（见引理 2）。
3. **不变量**：`flips` 始终等于「当前前缀」的最优代价；`ones` 始终等于「当前前缀」中 `1` 的个数。两者都是对**已处理前缀**的统计，不涉及未来。
4. **`ones` 可以很大**：$n \le 10^5$，`int` 足够；`flips ≤ ones ≤ n`。
5. **无需后缀统计**：方案二的 `ones` 已经等价于「把当前前缀全部翻成 0」，因此不必真的知道后半段有多少 0。

## 5. 正确性证明

记 $p_i = s[0..i)$ 为长度 $i$ 的前缀，$O_i$ 为其中 `1` 的个数，$F_i$ 为「使 $p_i$ 单调递增的最小翻转数」。算法的 `flips` 在扫描完前 $i$ 个字符时即 $F_i$。

**引理 1（最终形态）**：任何单调递增的二进制串都形如 $0^a 1^{n-a}$，其中 $a \in [0, n]$；反之亦然。

**证明**：单调递增意味着不存在 $i < j$ 使 $s[i] = 1$、$s[j] = 0$，即「所有的 0 都在所有 1 之前」，故 0 构成前缀、1 构成后缀。反之形如 $0^a1^{n-a}$ 的串显然不存在逆序对。∎

**引理 2（单个前缀的代价公式）**：$F_i = \min_{0 \le a \le i} \bigl(O_a + (i - a - (O_i - O_a))\bigr) = \min_{0 \le a \le i}\bigl(O_a + Z_{a,i}\bigr)$，其中 $O_a$ 是 $p_a$ 中 1 的个数、$Z_{a,i}$ 是 $p_i \setminus p_a = s[a..i)$ 中 0 的个数。

**证明**：由引理 1，$p_i$ 的单调目标形态由分界点 $a$ 决定：$p_a$ 全变 0、$s[a..i)$ 全变 1。$p_a$ 中每个 1 需翻一次（共 $O_a$ 次），$s[a..i)$ 中每个 0 需翻一次（共 $Z_{a,i}$ 次），二者互不重叠、计数精确。对 $a$ 取最小即最优。∎

**引理 3（`ones` 的作用）**：当 $s[i] = 0$ 时，引理 2 的候选可分为两类：
- $a = i$（分界点落在当前字符之后）的候选代价为 $O_i$；
- $a < i$ 的候选代价均 $\ge$ 某个由 $F_i$ 之前状态决定的值，且其中最小者恰为 $F_{i} = \min(F_{i-1}+1, O_i)$。

**证明**：当 $s[i] = 0$ 时，把分界点取在 $i$ 处意味着**当前 0 保持为 0**，但要求 $p_i$ 全为 0（因为分界点之后才是 1 区）。于是整个 $p_i$ 必须变成 0，代价就是 $O_i$——这正是「方案二」。

若分界点 $a < i$，则 $s[i] = 0$ 落入 1 区，必须翻成 1。此时 $p_i$ 的目标形态等同于「$p_{i-1}$ 的目标形态（某个 $0^{a}1^{i-1-a}$）再把末位 0 翻成 1」，于是代价 $= (\text{对 } p_{i-1} \text{ 的某个代价}) + 1$，对 $a$ 取最小即 $F_{i-1} + 1$——这正是「方案一」。

两类候选取最小得 $F_i = \min(F_{i-1} + 1, O_i)$。∎

**引理 4（`1` 的处理）**：当 $s[i] = 1$ 时 $F_i = F_{i-1}$。

**证明**：任取 $p_{i-1}$ 的最优目标形态 $0^a1^{i-1-a}$，在其末尾添上 $s[i] = 1$ 得到 $0^a1^{i-a}$，仍是单调形态且翻转数不变，故 $F_i \le F_{i-1}$。反之，任取 $p_i$ 的目标形态 $0^{a}1^{i-a}$：若末位 1 由原字符保留而来（原字符就是 1），则去掉末位得到 $p_{i-1}$ 的合法单调形态，代价不增，故 $F_{i-1} \le F_i$；若末位 1 由翻转而来，则该方案代价 $\ge$ 同样分界点下「末位保留 1」的方案代价，不会更优。故 $F_i \ge F_{i-1}$。两者合起来 $F_i = F_{i-1}$。∎

**定理**：算法返回 $F_n$，即把整个 `s` 变为单调递增的最小翻转次数。

**证明**：对 $i$ 归纳证明 `flips` $= F_i$、`ones` $= O_i$。$i = 0$ 时两者都是 0。设对 $i-1$ 成立：若 $s[i-1] = 1$，算法令 `ones` $= O_{i-1}+1 = O_i$、`flips` 不变 $= F_{i-1} = F_i$（引理 4）；若 $s[i-1] = 0$，算法令 `ones` $= O_{i-1} = O_i$、`flips` $= \min(F_{i-1}+1, O_i) = F_i$（引理 3）。故循环结束时 `flips` $= F_n$。由引理 2，$F_n$ 正是使全串单调的最小翻转数。∎

## 6. 复杂度分析

- **时间**：$O(n)$，每个字符一次比较与常数次加法/取小。
- **空间**：$O(1)$，仅两个整型变量（无需前缀和数组，也无需后缀统计）。
- **常数**：比「前缀和 + 后缀和」的 $O(n)$ 写法少一半内存访问，$n = 10^5$ 时几乎无感，但写法更短、更不易错。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minFlipsMonoIncr(string s) {
        int ones = 0;    // 已处理前缀中的 '1' 个数
        int flips = 0;   // 使已处理前缀单调递增的最小翻转数
        for (char c : s) {
            if (c == '1') {
                ones++;             // 1 可以直接接在后面，不产生新翻转
            } else {
                // 选择一：把这个 0 翻成 1 → flips + 1
                // 选择二：把它当作分界点之后的 0 → 前面的 1 全部翻成 0 → ones
                flips = min(flips + 1, ones);
            }
        }
        return flips;
    }
};
```

### Python

```python
class Solution:
    def minFlipsMonoIncr(self, s: str) -> int:
        ones = 0     # 前缀中 '1' 的个数
        flips = 0    # 使前缀单调的最小翻转数
        for c in s:
            if c == '1':
                ones += 1
            else:
                flips = min(flips + 1, ones)
        return flips
```

## 8. 边界情况与易错点

1. **已经是单调串**：`"0011"` → 0；不要因为初始 `flips = 0` 就在遇到 `1` 时误加。
2. **全为 0**：`"0000"` → 0（`min(1, 0) = 0`，正确）。
3. **全为 1**：`"1111"` → 0（没有任何 `0` 触发更新）。
4. **逆序串**：`"10"` → `min(1, 1) = 1`；`"1100"` → 第 3 位 `0`：`min(1, 2) = 1`，第 4 位 `0`：`min(2, 2) = 2`，答案 2（可验证：翻成 `"1111"` 需 2 次，`"0000"` 也需 2 次）。
5. **只考虑三种操作中的两种**：本题允许把 0 翻 1 与把 1 翻 0；不要漏掉「全翻成 0」「全翻成 1」这两类边界分界点（$a = n$ 与 $a = 0$），它们分别由 `ones` 与 `flips+1` 覆盖。
6. **`min` 的参数顺序**：写成 `min(ones, flips + 1)` 结果相同，但注释里要说明「谁是谁」，否则容易把 `ones` 误解成「当前代价」。
7. **长度 $10^5$**：`int` 足够（答案 $\le 10^5$），无需 `long long`。
