# LeetCode 二进制反射排序 题解

## 1. 题目概述

- **标题 / 题号**：二进制反射排序（#3769，easy）
- **链接**：https://leetcode.cn/problems/sort-integers-by-binary-reflection/
- **来源**：LeetCode 第 479 场周赛 Q1
- **难度**：简单
- **标签**：数组、排序、位运算

**题意**：定义**二进制反射**——把一个正整数的二进制表示（无前导零）按位反转，忽略反转后开头的前导零，再转回十进制。要求按每个元素的反射值**升序**排序；反射值相同时，**原始值较小**的排在前面。返回排序后的数组。

**约束**：

- $1 \le \text{nums.length} \le 100$
- $1 \le \text{nums}[i] \le 10^9$

## 2. 示例

**示例 1**

```text
输入：nums = [4, 5, 4]
输出：[4, 4, 5]
解释：4 = (100)₂ → (001)₂ → 1；5 = (101)₂ → (101)₂ → 5。
按反射值排序得 [4, 4, 5]。
```

**示例 2**

```text
输入：nums = [3, 6, 5, 8]
输出：[8, 3, 6, 5]
解释：反射值：3→3（11 反转仍是 11）、6→3（110 反转 011）、5→5（101 回文）、8→1（1000 反转 0001）。
按 (反射值, 原值) 排序：(1,8) < (3,3) < (3,6) < (5,5)，输出 [8, 3, 6, 5]。
```

## 3. 解题思路

### 3.1 暴力思路

签到题，$n \le 100$，直接模拟题意：对每个数求出反射值，再按「反射值、原值」双关键字排序即可，没有任何卡常压力。真正的考点只有两个：

1. 如何 $O(\log V)$ 地求反射值（而不是转字符串再反转）；
2. 平局时按**原值**升序（不是按出现顺序）。

### 3.2 核心观察：逐位弹出 = 二进制逆序

![二进制反射概念](images/bin_reflection_concept.svg)

求反射值不需要字符串操作：**从 x 的最低位开始，逐位弹出，追加到 r 的末尾**：

```text
r = 0
while x > 0:
    r = r * 2 + (x & 1)   # 弹出 x 的最低位，接到 r 后面
    x >>= 1
```

这和十进制「整数反转」是同一个循环骨架，只是进制换成 2。**前导零天然被忽略**：循环在 $x=0$ 时停止，反转串开头的 `0` 对应的数位贡献为 0，无需任何特判。

![逐位弹出求反射的过程](images/bin_reflection_bit_loop.svg)

### 3.3 排序键：二元组 (反射值, 原值)

题目要求的顺序 = 先按反射值升序、平局按原值升序，**恰好是键 $\text{key}(x) = (\mathrm{reflect}(x),\ x)$ 的字典序**。预计算每个数的键，直接比较排序：

```text
keys = [(reflect(x), x) for x in nums]
sort(keys)          # 字典序
ans  = [x for (_, x) in keys]
```

### 3.4 示例演算

以 `nums = [3, 6, 5, 8]` 为例：

| 原数 | 二进制 | 反射值 | 排序键 |
|------|--------|--------|--------|
| 3 | 11 | 3 | (3, 3) |
| 6 | 110 | 3 | (3, 6) |
| 5 | 101 | 5 | (5, 5) |
| 8 | 1000 | 1 | (1, 8) |

按键升序：$(1,8) < (3,3) < (3,6) < (5,5)$，输出 `[8, 3, 6, 5]` ✓

![示例 2 演算](images/bin_reflection_example_walkthrough.svg)

## 4. 算法细节

1. **反射函数**：`r = r*2 + (x & 1); x >>= 1` 循环至 `x == 0`，位数为 $k = \lfloor \log_2 x \rfloor + 1$，复杂度 $O(\log x)$。
2. **键的构造**：C++ 里把 `(reflect(x), x)` 存进 `vector<pair<int,int>>`，对 `pair` 排序默认就是字典序，无需自定义比较器；Python 直接 `sorted` 元组。
3. **预计算优于现场计算**：若在比较器里现场算反射，同一元素会被重复计算 $O(\log n)$ 次；先算好键再排序更干净。
4. **溢出检查**：$\text{nums}[i] \le 10^9 < 2^{30}$，反射值也 $< 2^{30}$，`int` 即可，无溢出风险。

## 5. 正确性证明

**引理 1**：上述循环返回 $x$ 的二进制反射值。

**证明**：设 $x$ 的二进制表示（无前导零）为 $b_{k-1} b_{k-2} \cdots b_1 b_0$，其中 $b_{k-1} = 1$。第 $i$ 轮（$i = 0, 1, \cdots, k-1$）先取出 $b_i$（因为每轮右移一位后最低位恰为 $b_i$），再执行 $r \leftarrow 2r + b_i$。对轮数归纳：$i$ 轮后 $r = \sum_{j=0}^{i-1} b_j \cdot 2^{i-1-j}$。故 $k$ 轮后

$$r = \sum_{j=0}^{k-1} b_j \cdot 2^{k-1-j},$$

其二进制正是 $b_0 b_1 \cdots b_{k-1}$，即反转串。若 $b_0 = 0$（反转串带前导零），对应项 $b_0 \cdot 2^{k-1} = 0$，前导零不产生贡献；且循环共执行 $k$ 轮（$x$ 的有效位数），在 $x$ 变 0 时停止，不会多算高位。∎

**定理**：按键 $(\mathrm{reflect}(x),\ x)$ 的字典序排序，输出即题目要求的数组。

**证明**：题目要求的全序为：$x \prec y \iff \mathrm{reflect}(x) < \mathrm{reflect}(y)$，或（反射值相等且 $x \ne y$）$x < y$。这恰是二元组 $(\mathrm{reflect}(x), x)$ 与 $(\mathrm{reflect}(y), y)$ 的字典序比较。比较排序按键升序输出；键完全相同的元素只能来自值相等的重复元素，其相对顺序不影响结果。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \log V + n \log n)$。求反射值共 $n$ 次、每次 $O(\log V)$（$V \le 10^9$，至多 30 轮）；排序 $O(n \log n)$ 次比较、每次 $O(1)$。本题 $n \le 100$，总开销可忽略。
- **空间复杂度**：$O(n)$。存储键数组；排序自身 $O(\log n)$ 栈空间。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> sortByReflection(vector<int>& nums) {
        auto reflect = [](int x) {
            int r = 0;
            while (x > 0) {
                r = r * 2 + (x & 1);
                x >>= 1;
            }
            return r;
        };
        vector<pair<int, int>> keyed;
        keyed.reserve(nums.size());
        for (int x : nums) {
            keyed.emplace_back(reflect(x), x);
        }
        sort(keyed.begin(), keyed.end());
        vector<int> ans;
        ans.reserve(nums.size());
        for (auto& [r, x] : keyed) {
            ans.push_back(x);
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def sortByReflection(self, nums: List[int]) -> List[int]:
        def reflect(x: int) -> int:
            r = 0
            while x:
                r = r * 2 + (x & 1)
                x >>= 1
            return r

        return [x for _, x in sorted((reflect(x), x) for x in nums)]
```

## 8. 边界情况与易错点

1. **平局规则是「原值」不是「出现顺序」**：例 2 中 3 与 6 反射值同为 3，必须 3 在前；只按反射值做**稳定排序**在 `[6, 3]` 输入下会得到错误顺序 `[6, 3]`（正确应为 `[3, 6]`）。
2. **前导零无需特判**：循环到 `x == 0` 自然停止，`1000 → 0001 → 1` 自动完成。
3. **2 的幂反射值恒为 1**：如 8 反射为 1，会排在最前面。
4. **回文二进制反射等于自身**：如 5 = (101)₂ → 5，可用于快速自测。
5. **重复元素**：相同值的键完全相同，顺序无关紧要。
6. **溢出**：$10^9 < 2^{30}$，反射值 $< 2^{30}$，`int` 足够；若数据范围升到 $10^{18}$ 需换 `long long`。
7. **别用字符串反转当主路径**：`int(bin(x)[2:][::-1], 2)` 也能过，但位运算版更快且更通用，建议养成位运算习惯。
