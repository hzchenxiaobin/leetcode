# LeetCode 树中子图的最大得分 题解

## 1. 题目概述

- **标题 / 题号**：树中子图的最大得分（#3772，hard）
- **链接**：https://leetcode.cn/problems/maximum-subgraph-score-in-a-tree/
- **来源**：LeetCode 第 479 场周赛 Q4
- **难度**：困难
- **标签**：树、动态规划、换根 DP、深度优先搜索

**题意**：给一棵 $n$ 个节点（编号 $0 \sim n-1$）的无向树（$n-1$ 条边 `edges`）与数组 `good`（$good[i]=1$ 为好节点，$0$ 为坏节点）。子图的**得分** = 好节点数 − 坏节点数。对每个节点 $i$，求**包含 $i$ 的所有连通子图**中的最大得分，返回长度为 $n$ 的答案数组。

**约束**：

- $2 \le n \le 10^5$
- `edges.length == n − 1`，$0 \le a_i, b_i < n$，输入保证是一棵有效树
- $good[i] \in \{0, 1\}$

> 💡 **审题三处关键**：① 得分只跟「选了哪些点」有关——把点权写成 $w(v) = +1$（好）/ $-1$（坏），得分即 $\sum_{v \in S} w(v)$，「连通子图」等价于「连通点集」（树上连通点集的导出子图自动连通，边不用挑）；② 要对**每个点**各答一次「包含它的最优块」——这是**换根 DP** 的标志特征；③ $n$ 达 $10^5$，逐点重做 DP 的 $O(n^2)$ 必须避免，链状树下递归还会爆栈。

## 2. 示例

**示例 1**

```text
输入：n = 3, edges = [[0,1],[1,2]], good = [1,0,1]
输出：[1,1,1]
解释：对每个节点，包含它的最优连通子图都是整棵树：2 个好节点 − 1 个坏节点 = 1。
```

**示例 2**

```text
输入：n = 5, edges = [[1,0],[1,2],[1,3],[3,4]], good = [0,1,0,1,1]
输出：[2,3,2,3,3]
解释：节点 0 取 {0,1,3,4}：3 − 1 = 2；节点 1、3、4 取 {1,3,4}：3 − 0 = 3；
      节点 2 取 {1,2,3,4}：3 − 1 = 2。
```

**示例 3**

```text
输入：n = 2, edges = [[0,1]], good = [0,0]
输出：[-1,-1]
解释：带上对方只会多扣 1 分，最优是只留自己，得分为 −1。
```

## 3. 解题思路

### 3.1 暴力思路：逐点做树形 DP

点权化 $w(v) = 2 \cdot good[v] - 1$ 后，「包含根、只往下走」的最优块用一次树形 DP 就能求：$f[v] = w(v) + \sum_{\text{孩子 } c} \max(0, f[c])$。但本题要对**每个点**回答，把根换成 $i$ 重做一遍就是 $O(n)$ × $n$ 次 = $O(n^2) \approx 10^{10}$，铁定超时。

> 💡 暴力的浪费一眼可见：把根从 $p$ 挪到相邻的孩子 $u$ 时，$u$ 子树内的一切**分毫未变**，却被整套重算。真正变化的只有「$p$ 一侧（$u$ 的子树之外）」的信息——把它沿边**下传**即可。

### 3.2 核心观察：分支独立拼装 + 减法换根

![核心观察：包含 u 的最优连通块 = u + 各方向分支独立拼装](images/subgraph_score_reroot_model.svg)

**观察一（分支独立）**：删掉 $u$，树裂成 $\deg(u)$ 块「领地」（每个邻居一块）。任取包含 $u$ 的连通点集 $S$，$S \setminus \{u\}$ 恰好按领地切成互不相交的若干块，每块是**该领地内包含对应邻居**的连通点集（可为空）；反之，$u$ 加上每块领地里任选的一个「含邻居的连通块」仍是连通的。于是各方向的贡献**独立、可加、可选可弃**——每个方向要么整支不要（贡献 $0$），要么取该方向的**最优块**：

$$\text{ans}[u] = w(u) + \sum_{\text{邻居方向}} \max(0,\ \text{该方向最优})$$

**观察二（down，自底向上）**：以任意点为根（取 $0$）定向后，孩子方向的最优值就是经典树形 DP：

$$\text{down}[u] = w(u) + \sum_{\text{孩子 } c} \max(0,\ \text{down}[c])$$

负收益的孩子分支整支剪掉——正是 [124. 二叉树中的最大路径和](https://leetcode.cn/problems/binary-tree-maximum-path-sum/) 的 $\max(0,\cdot)$ 技巧搬到多叉树。

**观察三（父侧，减法换根）**：剩下的只有「父方向」这一块领地：**包含 $p$、完全避开 $u$ 子树**的连通块最优值，记作 $\text{up}(u)$。关键一步来了——$p$ 自己的答案 $g[p]$ 是各方向贡献**求和**：

$$g[p] = w(p) + \sum_{\text{孩子 } c} \max(0, \text{down}[c]) + \max(0, \text{up}(p))$$

其中 $u$ 那份被记入的正是 $\max(0, \text{down}[u])$。**把它减掉，剩下的就是「$p$ + 除 $u$ 外的所有方向」**，恰好等于 $\text{up}(u)$：

$$\text{up}(u) = g[p] - \max(0, \text{down}[u])$$

> 💡 **求和型聚合的「可减性」**是本题换根只需一条公式的根源：贡献是加法，减去一支即得其余。对照「取 max 型」换根（如 [2246. 相邻字符不同的最长路径](https://leetcode.cn/problems/longest-path-with-different-adjacent-characters/)），必须维护前两大或前后缀数组才能表达「除 $u$ 外的最优」，一条减法是不够的。

**收尾**：把父侧并回观察一，得到最终的一行转移（$p = \text{parent}(u)$）：

$$\boxed{\,g[u] = \text{down}[u] + \max\bigl(0,\ g[p] - \max(0, \text{down}[u])\bigr)\,}\qquad g[\text{root}] = \text{down}[\text{root}]$$

不需要显式的 `up` 数组、不需要预处理「孩子贡献和」，每个点一条公式完成换根。

### 3.3 算法流程

![算法流程：BFS 定序，逆序求 down，正序换根](images/subgraph_score_flow.svg)

| 步骤 | 操作 | 说明 |
|------|------|------|
| ① 建图定序 | 建双向邻接表；从 0 出发 BFS 得 `order[]` 与 `parent[]` | BFS 序保证**父先于子** |
| ② 自底向上 | 逆序扫 `order`：$\text{down}[u] = w(u) + \sum_{\text{子}} \max(0, \text{down})$ | 逆 BFS 序即**孩子先于父亲** |
| ③ 自顶向下 | 正序扫 `order`：$g[u] = \text{down}[u] + \max(0, g[p] - \max(0, \text{down}[u]))$ | $g[0] = \text{down}[0]$ |
| ④ 返回 | 输出 `g` | 全程迭代，无爆栈风险 |

### 3.4 示例演算

![示例 2 演算：两遍扫描逐步算 down 与 g](images/subgraph_score_walkthrough.svg)

以示例 2 走一遍（$w = [-1, +1, -1, +1, +1]$，BFS 序 $[0,1,2,3,4]$，$parent = [-1,0,1,1,3]$）：

**第一遍：逆序 $4 \to 3 \to 2 \to 1$（0 为根不上抛）**

| 节点 | 计算 | down |
|------|------|------|
| 4 | $+1$ | $+1$ |
| 3 | $+1 + \max(0, +1)$ | $+2$ |
| 2 | $-1$（无正孩子） | $-1$ |
| 1 | $+1 + \max(0, -1) + \max(0, +2)$ | $+3$ |
| 0 | $-1 + \max(0, +3)$ | $+2$ |

**第二遍：正序换根（$g[0] = \text{down}[0] = 2$）**

| 节点 | 计算 | g |
|------|------|---|
| 1 | $3 + \max(0,\ 2 - 3)$ | $3$ |
| 2 | $-1 + \max(0,\ 3 - 0)$ | $2$ |
| 3 | $2 + \max(0,\ 3 - 2)$ | $3$ |
| 4 | $1 + \max(0,\ 3 - 1)$ | $3$ |

得 $[2,3,2,3,3]$ ✓。两个亮点：节点 2 自己 $\text{down} = -1$，**全靠父侧借来 3 分翻盘**（父侧块 $\{1,3,4\}$ 经由父边接入）；节点 1 的父侧贡献 $\max(0, 2-3) = 0$——往节点 0 方向带人是亏的，$\max(0,\cdot)$ 把它剪干净。

## 4. 算法细节

1. **点权化**：$w = 2 \cdot good - 1 \in \{+1, -1\}$。所有中间量（down、g、父侧贡献）都落在 $[-n, n]$，`int` 即可，无溢出风险。
2. **BFS 定序**：`order` 数组本身当队列（边遍历边追加），一遍得 `parent`。正序 = 父先于子（换根用），逆序 = 孩子先于父亲（求 down 用），**无需递归、无需显式栈、无需 DFS 时间戳**。
3. **$\max(0,\cdot)$ 的实现**：逆序循环里 `if (down[u] > 0) down[parent[u]] += down[u];`——负的干脆不上抛，等价于取 $0$。
4. **换根一步到位**：转移只依赖 `g[p]` 和 `down[u]`，正序扫描时两者必已就绪，直接一条公式；对比「维护 total + base 再分发给每个孩子」的写法（daily 版采用），少一层循环、少两个数组，更难写错。
5. **减法必须减 $\max(0, \text{down}[u])$，不能减 $\text{down}[u]$**：$g[p]$ 中 $u$ 分支**实际记入**的份额是 $\max(0, \text{down}[u])$；若减 $\text{down}[u]$，当 $\text{down}[u] < 0$ 时等于把从没记过的负数再扣一遍，父侧被系统性高估。反例：$n=2$，`edges=[[0,1]]`，`good=[1,0]`：正确答案 $[1, 0]$（节点 1 取 $\{0,1\}$ 得 $0$），错误减法算出 $g[1] = -1 + (1-(-1)) = 1$，凭空多 1 分。
6. **根任取**：公式推导对根无要求（根只是「没有父侧分支」），取 $0$ 即可；答案与根的选择无关。

## 5. 正确性证明

先固定一个标准事实：树上点集 $S$ 的导出子图连通 $\iff$ $S$ 中任意两点的树上路径都含于 $S$。（方向 ⇐ 对路径长度归纳；方向 ⇒ 显然，连通须有边路径，而树上两点间边路径唯一。）

**引理 1（分支分解）**：设 $S$ 为包含 $u$ 的连通点集。对 $u$ 的每个邻居 $v$，记 $T_v$ 为删边 $(u,v)$ 后 $v$ 所在分量（$u$ 的一个「分支」），$S_v = S \cap T_v$。则每个非空 $S_v$ 是包含 $v$ 的连通点集；反之，任取每个分支内一个包含对应邻居的连通点集（可为空），与 $\{u\}$ 的并是包含 $u$ 的连通点集。且 $w(S) = w(u) + \sum_{v} w(S_v)$。

**证明**：设 $x \in S_v$（$x \ne u$）。由标准事实，树上路径 $\text{path}(x, u) \subseteq S$，其最后一条边是 $(v', u)$，而 $v'$ 由 $x$ 所在分支唯一确定（树上 $x$ 到 $u$ 必经 $u$ 的某个邻居 $v'$，且 $x \in T_{v'}$），故 $v' = v$，且 $\text{path}(x, v) \subseteq S \cap T_v = S_v$。于是 $S_v$ 中任一点到 $v$ 的路径都在 $S_v$ 内，由标准事实 $S_v$ 连通且含 $v$（$v$ 是 $u$ 的邻居且 $v \in S$，否则边 $(u,v)$ 不在导出子图中、$S_v$ 与 $u$ 不连通，与 $S$ 连通矛盾）。反之，每个非空 $S_v$ 含邻居 $v$，与 $u$ 有边相连，并集连通显然；点权和按分支划分显然。∎

**引理 2（down 的正确性）**：$\text{down}[u]$ 等于「$u$ 子树内包含 $u$ 的连通点集」的最大得分，且递推 $\text{down}[u] = w(u) + \sum_{\text{孩子 } c} \max(0, \text{down}[c])$ 成立。

**证明**：对子树大小归纳。叶节点时只有 $\{u\}$ 可选，$\text{down}[u] = w(u)$ ✓。对内部节点 $u$，限制在子树内应用引理 1（分支 = 各孩子子树）：包含 $u$ 的子树内连通点集 $S$ 的得分 $= w(u) + \sum_c w(S_c)$，各 $S_c$ 独立取值于「子树 $c$ 内包含 $c$ 的连通点集 ∪ \{空\}」。由归纳假设该集合的最大得分为 $\max(0, \text{down}[c])$（空集贡献 $0$）。各分支独立最大化，总和即最大，得递推式。∎

**引理 3（父侧贡献的减法剥离）**：设 $p = \text{parent}(u)$，则「包含 $p$、不含 $\text{subtree}(u)$ 任何点」的连通点集的最大得分 $\text{up}(u) = g[p] - \max(0, \text{down}[u])$。

**证明**：对 $p$ 在**全树**视角应用引理 1：$p$ 的分支集合 = $p$ 的所有孩子子树 ∪ $p$ 的父方向分支。由引理 2，孩子 $c$ 方向的最优为 $\text{down}[c]$；记父方向最优为 $b^*$（孩子方向的结论对「任意分支」同样成立：分支 $T_v$ 内包含 $v$ 的连通点集最大得分，对父方向分支记作 $b^*$，其存在性与引理 2 的论证相同）。于是

$$g[p] = w(p) + \sum_{\text{孩子 } c} \max(0, \text{down}[c]) + \max(0, b^*)$$

两式相减，$u$ 分支一项 $\max(0, \text{down}[u])$ 恰好消去，得

$$g[p] - \max(0, \text{down}[u]) = w(p) + \sum_{\text{孩子 } c \ne u} \max(0, \text{down}[c]) + \max(0, b^*)$$

另一方面，对满足「包含 $p$、避开 $\text{subtree}(u)$」的连通点集应用引理 1（分支 = 除 $u$ 外的孩子 ∪ 父方向），其得分 $= w(p) + \sum_{c \ne u} w(S_c) + w(S_{\text{父}})$，各分支独立取最优（可为空），最大值恰为上式右端。∎

**定理**：算法输出 $g$ 满足 $g[u]$ = 包含 $u$ 的（全树）连通点集的最大得分。

**证明**：对 $u$ 按根到 $u$ 的深度归纳。$u$ 为根时，包含 $u$ 的连通点集都在子树内，由引理 2，$g[\text{root}] = \text{down}[\text{root}]$ ✓。$u$ 非根时，对 $u$ 全树视角应用引理 1（分支 = 孩子们 ∪ 父方向）：

$$g[u] = w(u) + \sum_{\text{孩子 } c} \max(0, \text{down}[c]) + \max(0, \text{up}(u)) = \text{down}[u] + \max(0, \text{up}(u))$$

（前一项由引理 2 的论证同样适用于「子树内分支」的独立最大化）。由引理 3 代入 $\text{up}(u) = g[p] - \max(0, \text{down}[u])$，即得算法所用转移；由归纳假设 $g[p]$ 已是正确值（BFS 序保证父先算）。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。建邻接表 $O(n)$；BFS 每条边两端各访问一次，$\sum \deg = 2(n-1)$；两遍扫描同理各 $O(n)$。$n = 10^5$ 时毫秒级（实测 Python 链树约 0.1s）。
- **空间复杂度**：$O(n)$。邻接表 $2(n-1)$ 条记录，`order / parent / down / g` 四个长度 $n$ 的数组。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    vector<int> maxSubgraphScore(int n, vector<vector<int>>& edges, vector<int>& good) {
        vector<vector<int>> adj(n);
        for (auto& e : edges) {
            adj[e[0]].push_back(e[1]);
            adj[e[1]].push_back(e[0]);
        }

        vector<int> parent(n, -1), order;
        vector<char> vis(n, 0);
        order.reserve(n);
        order.push_back(0);
        vis[0] = 1;
        for (int i = 0; i < n; ++i) {                 // BFS：order 本身当队列
            int u = order[i];
            for (int v : adj[u])
                if (!vis[v]) {
                    vis[v] = 1;
                    parent[v] = u;
                    order.push_back(v);
                }
        }

        vector<int> down(n);
        for (int i = 0; i < n; ++i) down[i] = good[i] ? 1 : -1;
        for (int i = n - 1; i >= 1; --i) {            // 逆 BFS 序：孩子先于父亲
            int u = order[i];
            if (down[u] > 0) down[parent[u]] += down[u];
        }

        vector<int> g(n);
        g[0] = down[0];                               // 根无父侧
        for (int i = 1; i < n; ++i) {                 // 正 BFS 序：父先于子
            int u = order[i], p = parent[u];
            g[u] = down[u] + max(0, g[p] - max(0, down[u]));
        }
        return g;
    }
};
```

### Python

```python
class Solution:
    def maxSubgraphScore(self, n: int, edges: List[List[int]], good: List[int]) -> List[int]:
        adj = [[] for _ in range(n)]
        for a, b in edges:
            adj[a].append(b)
            adj[b].append(a)

        parent = [-1] * n
        order = [0]
        vis = [False] * n
        vis[0] = True
        for u in order:                               # 迭代中追加，即为 BFS
            for v in adj[u]:
                if not vis[v]:
                    vis[v] = True
                    parent[v] = u
                    order.append(v)

        down = [1 if x else -1 for x in good]
        for i in range(n - 1, 0, -1):                 # 逆 BFS 序：孩子先于父亲
            u = order[i]
            if down[u] > 0:
                down[parent[u]] += down[u]

        g = [0] * n
        g[0] = down[0]                                # 根无父侧
        for i in range(1, n):                         # 正 BFS 序：父先于子
            u = order[i]
            p = parent[u]
            g[u] = down[u] + max(0, g[p] - max(0, down[u]))
        return g
```

## 8. 边界情况与易错点

1. **爆栈是第一杀手**：$n = 10^5$ 的链树递归深度 $10^5$——Python 默认上限 1000 必爆（`sys.setrecursionlimit` 也救不了段错误风险），C++ 同样可能栈溢出。BFS 序 + 两遍循环彻底规避。
2. **减法减 $\max(0, \text{down}[u])$ 而非 $\text{down}[u]$**：见 §4 第 5 点的反例（`good=[1,0]` 两点树，错误版本把 $0$ 算成 $1$）。
3. **根别漏初始化**：$g[0] = \text{down}[0]$，根没有父侧分支；正序循环从 $i=1$ 起跳过根。
4. **答案可以为负**：全坏时答案是 $-1$（单点子图只有 $w(u) \ge -1$，故答案下界恰为 $-1$）。$\max(0,\cdot)$ 只作用于**分支**，绝不作用于**整体**——别把答案下界设成 $0$。
5. **无向边双向建表**，BFS 用 `vis`（或 `parent` 判重）防止走回头路；用 `v != parent[u]` 判重依赖「无重边自环」，题面虽保证有效树，`vis` 写法更稳。
6. **`parent` 初始化 −1 不与节点号冲突**（节点号非负），根的判断用 `parent[u] == -1` 或直接靠 BFS 序下标。
7. **「连通子图」=「连通点集」**：得分与选边无关，树上连通点集的导出子图天然连通——不必纠结边集怎么选，也不必担心「子图」一词要求边数更多。
8. **溢出无忧但别乱改类型**：所有值 $\in [-n, n] \subseteq [-10^5, 10^5]$，`int` / `list[int]` 足够；本题也不存在前缀和那样的 64 位陷阱。

- [LeetCode 124. 二叉树中的最大路径和](https://leetcode.cn/problems/binary-tree-maximum-path-sum/)：$\max(0,\cdot)$ 剪掉负收益分支——本题 down 转移的技巧源头，可视为「只求一个点答案」的特例。
- [LeetCode 2246. 相邻字符不同的最长路径](https://leetcode.cn/problems/longest-path-with-different-adjacent-characters/)：取 max 型换根，必须前两大/前后缀分解——对照本题「求和可减」的实现差异。
- [LeetCode 310. 最小高度树](https://leetcode.cn/problems/minimum-height-trees/)：把根挪到邻居后高度如何增量更新——换根思想最简入门。

**延伸思考**：① 若 $w(v)$ 推广为任意整数，算法原样适用；若只求全树「得分最大的连通块」而不指定包含谁，一次树形 DP 内顺带取 $\max_v \text{down}[v]$（拼接两条正分支）即可，$O(n)$。② 若图不再是树——一般图上的「最大权连通子图」是经典 NP-hard 问题（可由 Steiner 树归约），本题的线性可解完全依赖「删点裂块、块间独立」的树结构。③ 动态版（单点翻转 `good` 后在线询问所有答案）需要树链剖分 / 动态 DP 维护 down 与换根信息，复杂度与代码量都上了一个量级，感兴趣可深入。
