# LeetCode 最小化两个数组中的最大值 题解

## 1. 题目概述

- **标题 / 题号**：最小化两个数组中的最大值（#2513，medium）
- **链接**：https://leetcode.cn/problems/minimize-the-maximum-of-two-arrays/
- **来源**：LeetCode 第 94 场双周赛 Q3
- **难度**：中等
- **标签**：数学、二分查找、数论、容斥原理、最小公倍数

**题意**：往两个初始为空的数组中添加互不相同的正整数：`arr1` 恰含 $uniqueCnt1$ 个互不相同的正整数且每个都**不能被 $divisor1$ 整除**；`arr2` 恰含 $uniqueCnt2$ 个互不相同的正整数且每个都**不能被 $divisor2$ 整除**；两数组元素也互不相同。返回两数组中**最大元素的最小值**。

**约束**：

- $2 \le divisor1, divisor2 \le 10^5$
- $1 \le uniqueCnt1, uniqueCnt2 < 10^9$，$2 \le uniqueCnt1 + uniqueCnt2 \le 10^9$

## 2. 示例

**示例 1**

```text
输入：divisor1 = 2, divisor2 = 7, uniqueCnt1 = 1, uniqueCnt2 = 3
输出：4
解释：arr1 = [1]，arr2 = [2,3,4]，最大值为 4。
```

**示例 2**

```text
输入：divisor1 = 3, divisor2 = 5, uniqueCnt1 = 2, uniqueCnt2 = 1
输出：3
解释：arr1 = [1,2]，arr2 = [3]，最大值为 3。
```

**示例 3**

```text
输入：divisor1 = 2, divisor2 = 4, uniqueCnt1 = 8, uniqueCnt2 = 2
输出：15
解释：arr1 = [1,3,5,7,9,11,13,15]，arr2 = [2,6]，最大值为 15。
```

## 3. 解题思路

### 3.1 暴力思路

从 $m = 1, 2, 3, \dots$ 逐个尝试「只用 $[1, m]$ 中的数能否同时喂饱两个数组」。对每个 $m$ 做可行性判定本身也不平凡：两数组的候选池互相重叠（都可用「两不整除」的自由数），且 $uniqueCnt1, uniqueCnt2$ 可达 $10^9$，逐个配数必然超时。正确姿势是把**可行性判定**写成 $O(1)$ 的计数公式，再用**二分**把「逐个尝试」压到 $O(\log)$ 次——典型的「二分答案 + 计数检查」。

### 3.2 核心观察：$[1, m]$ 的四分类与归属限制

![1..m 按整除性分成四类，各类只能进特定数组](images/bw94_q3_number_categories.svg)

设 $d_1 = divisor1$、$d_2 = divisor2$、$L = \mathrm{lcm}(d_1, d_2)$。$[1, m]$ 中每个数按「被谁整除」分为四类：

| 类别 | 判定 | 个数 | 可进 arr1？ | 可进 arr2？ |
|------|------|------|------------|------------|
| both（$\div d_1$ 且 $\div d_2$） | $\div L$ | $B = \lfloor m/L \rfloor$ | ✗ | ✗ |
| only1（$\div d_1$ 不 $\div d_2$） | | $A_1 = \lfloor m/d_1 \rfloor - B$ | ✗ | ✓ |
| only2（$\div d_2$ 不 $\div d_1$） | | $A_2 = \lfloor m/d_2 \rfloor - B$ | ✓ | ✗ |
| free（两不整除） | | $F = m - A_1 - A_2 - B$ | ✓ | ✓ |

于是「arr1 只能从 $A_2 + F$ 中取、arr2 只能从 $A_1 + F$ 中取、且 arr1 ∩ arr2 = ∅」。

### 3.3 计数公式：容斥 + 二分判定

![一个 lcm 周期内的容斥计数](images/bw94_q3_inclusion_exclusion.svg)

$F$ 的计数正是**容斥原理**：$[1, m]$ 中既不被 $d_1$ 也不被 $d_2$ 整除的个数

$$F = m - \left\lfloor \frac{m}{d_1} \right\rfloor - \left\lfloor \frac{m}{d_2} \right\rfloor + \left\lfloor \frac{m}{L} \right\rfloor$$

在每个长为 $L$ 的完整周期里，这个值等于 $L - \frac{L}{d_1} - \frac{L}{d_2} + 1$（周期内 $L$ 恰被自身整除一次）。可行性判定只需三个**Hall 型条件**（见 §5 引理 3）：$A_2 + F \ge u_1$、$A_1 + F \ge u_2$、$A_1 + A_2 + F \ge u_1 + u_2$。三条都随 $m$ 单调不减，故可二分最小的可行 $m$。

### 3.4 算法流程

![二分答案的判定与区间收缩](images/bw94_q3_binary_search.svg)

```text
1. 计算 g = gcd(d1, d2)，L = d1 / g * d2
2. 二分区间 [1, 2(u1+u2)+2]：
       mid = (lo+hi)/2，按四分类计数
       三条件全满足 → hi = mid；否则 lo = mid + 1
3. 返回 lo
```

上界 $2(u_1+u_2)+2$ 的来历：$d_1, d_2 \ge 2$ 使「非 $d_1$ 倍数」的密度至少 $\frac{1}{2}$（同理 $d_2$），于是 $m = 2(u_1+u_2)+2$ 时三个池子必然同时够用（§5 引理 4）。

### 3.5 示例演算

对示例 3（$d_1 = 2, d_2 = 4, u_1 = 8, u_2 = 2$）验证 $m = 15$：$L = 4$，$B = \lfloor 15/4 \rfloor = 3$（4、8、12，两数组都不能用），$A_1 = 7 - 3 = 4$（2、6、10、14，只能进 arr2），$A_2 = 3 - 3 = 0$，$F = 15 - 7 - 3 + 3 = 8$（奇数，两边都能进）。判定：$A_2 + F = 8 \ge 8$ ✓、$A_1 + F = 12 \ge 2$ ✓、总量 $12 \ge 10$ ✓，可行；而 $m = 14$ 时 $F = 7$、$A_2 + F = 7 < 8$ ✗，不可行。故答案 $15$，与示例给出的构造（arr1 拿全部奇数）吻合。

## 4. 算法细节

1. **$\mathrm{lcm}$ 用 `long long`**：$d_1, d_2 \le 10^5$ 时 $L \le 10^{10}$，`int` 直接溢出；先除 $\gcd$ 再乘，`L = d1 / g * d2`。
2. **二分上界**：$2(u_1 + u_2) + 2 \le 2 \times 10^9 + 2$，也超出 `int` 的一半安全区，全程 `long long`（Python 无碍）。
3. **三条件缺一不可**：分别对应「arr1 池够」「arr2 池够」「自由数不被重复消耗」。漏第三条会在 $u_1 + u_2$ 很大时把自由数重复分配给两个数组。
4. **单调性**：$A_1, A_2, F, B$ 都是 $\lfloor m/x \rfloor$ 型，随 $m$ 不减，故判定函数单调，二分合法。
5. **为什么不用管 both 类**：它谁都进不了，只在容斥中作「被减两次的补回项」出现。
6. **复杂度**：每次判定 $O(1)$，总共 $O(\log(2(u_1+u_2))) \approx 31$ 次判定。

## 5. 正确性证明

**引理 1（四分类计数）**：对任意 $m \ge 1$，$[1, m]$ 中 both、only1、only2、free 四类的个数分别为 $B = \lfloor m/L \rfloor$、$A_1 = \lfloor m/d_1 \rfloor - B$、$A_2 = \lfloor m/d_2 \rfloor - B$、$F = m - \lfloor m/d_1 \rfloor - \lfloor m/d_2 \rfloor + \lfloor m/L \rfloor$。

**证明**：$\lfloor m/d \rfloor$ 即 $[1, m]$ 中 $d$ 的倍数个数（每 $d$ 个数恰好贡献一个倍数）。被 $d_1$ 或 $d_2$ 整除的数由容斥为 $\lfloor m/d_1 \rfloor + \lfloor m/d_2 \rfloor - \lfloor m/L \rfloor$（同时被两者整除 $\iff$ 被 $\mathrm{lcm}$ 整除）；两边都不整除者即总数减之，得 $F$。only 类为「被一个整除的集合」扣除交集。在每个周期 $(tL, (t+1)L]$ 内各项周期化，得周期公式 $L - L/d_1 - L/d_2 + 1$。∎

**引理 2（归属限制）**：合法方案中 arr1 $\subseteq$ only2 ∪ free，arr2 $\subseteq$ only1 ∪ free，且 arr1 ∩ arr2 = ∅；反之任何满足这三条且大小正确的选取都合法。

**证明**：被 $d_1$ 整除的数（both ∪ only1）不得进入 arr1，被 $d_2$ 整除者不得进入 arr2，题面要求两数组元素互不相同即交集为空。反之按类别归属选取自然满足整除限制与互异性。∎

**引理 3（可行性 = 三条件）**：$[1, m]$ 中存在合法分配当且仅当

$$A_2 + F \ge u_1,\qquad A_1 + F \ge u_2,\qquad A_1 + A_2 + F \ge u_1 + u_2$$

**证明**：必要性：由引理 2，arr1 的 $u_1$ 个数取自 only2 ∪ free，故 $A_2 + F \ge u_1$；同理 $A_1 + F \ge u_2$；两数组共取 $u_1 + u_2$ 个互不相同的数，全部落在 only1 ∪ only2 ∪ free 中（both 不可用），故第三个不等式成立。充分性（构造）：先把 only2 全给 arr1、only1 全给 arr2（定向部分免费且「不占自由数」）；记缺口 $g_1 = u_1 - A_2$、$g_2 = u_2 - A_1$（若为负按 0 计）。第一、二条件保证 $g_1, g_2 \le F$ 剩余，第三个条件保证 $g_1 + g_2 \le F$（当 $A_i$ 过剩时 $g_1 + g_2 \le u_1 + u_2 - A_1 - A_2 \le F$，用 $g$ 的定义放缩即得）。于是从 free 中任取 $g_1$ 个补 arr1、$g_2$ 个补 arr2（自由数两边都合规，且互不相同），分配完成。∎

**引理 4（二分上界可行）**：$m_0 = 2(u_1 + u_2) + 2$ 满足三条件，且三条件关于 $m$ 单调不减。

**证明**：单调性：$A_1, A_2, F$ 都是若干 $\lfloor m/x \rfloor$ 与 $m$ 的非负组合，随 $m$ 增大不减。上界：$d_1 \ge 2$ 时「非 $d_1$ 倍数」的个数 $A_2 + F = m - \lfloor m/d_1 \rfloor \ge m/2 = u_1 + u_2 + 1 \ge u_1$，对称地 $A_1 + F \ge u_2$；可用总数 $A_1 + A_2 + F = m - \lfloor m/L \rfloor \ge m/2 = u_1 + u_2 + 1$（$L \ge 2$）。∎

**定理**：二分返回的 $lo$ 即两数组最大元素的最小值。

**证明**：设 $m^{*}$ 为使 $[1, m]$ 可行的最小 $m$（由引理 4 存在，二分在 $[1, m_0]$ 内收敛到它）。「答案 $\le m$」$\iff$「存在只用 $[1, m]$ 数字的合法方案」$\iff$ 引理 3 的条件成立 $\iff$ $m \ge m^{*}$。于是最大元素的最小值恰为 $m^{*}$：$m^{*}$ 可行给出上界，而任何方案若最大元素 $< m^{*}$ 则其数字全落在 $[1, m^{*}-1]$ 中、与 $m^{*}$ 的最小性矛盾。∎

## 6. 复杂度分析

- **时间**：$O\big(\log(u_1 + u_2)\big)$。二分约 $31$ 次判定，每次 $O(1)$（含一次 $\gcd$ 预计算 $O(\log)$）。
- **空间**：$O(1)$。只用常数个整型变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minimizeSet(int divisor1, int divisor2, int uniqueCnt1, int uniqueCnt2) {
        long long d1 = divisor1, d2 = divisor2;
        long long u1 = uniqueCnt1, u2 = uniqueCnt2;
        long long a = d1, b = d2;
        while (b) { long long t = a % b; a = b; b = t; }   // a = gcd
        long long L = d1 / a * d2;                         // 最小公倍数
        long long lo = 1, hi = 2 * (u1 + u2) + 2;          // 上界：正数密度至少 1/2
        while (lo < hi) {
            long long m = lo + (hi - lo) / 2;
            long long both = m / L;                        // 同时被整除：两边都不能去
            long long only1 = m / d1 - both;               // 只被 d1 整除：只能进 arr2
            long long only2 = m / d2 - both;               // 只被 d2 整除：只能进 arr1
            long long freeCnt = m - m / d1 - m / d2 + both;// 两边都不被整除：自由
            bool ok = only2 + freeCnt >= u1
                    && only1 + freeCnt >= u2
                    && only1 + only2 + freeCnt >= u1 + u2;
            if (ok) hi = m;
            else lo = m + 1;
        }
        return (int)lo;
    }
};
```

### Python

```python
class Solution:
    def minimizeSet(self, divisor1: int, divisor2: int, uniqueCnt1: int, uniqueCnt2: int) -> int:
        a, b = divisor1, divisor2
        while b:
            a, b = b, a % b                    # a = gcd
        L = divisor1 // a * divisor2            # 最小公倍数

        def ok(m: int) -> bool:
            both = m // L                      # 同时被整除：两边都不能去
            only1 = m // divisor1 - both       # 只被 d1 整除：只能进 arr2
            only2 = m // divisor2 - both       # 只被 d2 整除：只能进 arr1
            free_cnt = m - m // divisor1 - m // divisor2 + both
            return (only2 + free_cnt >= uniqueCnt1
                    and only1 + free_cnt >= uniqueCnt2
                    and only1 + only2 + free_cnt >= uniqueCnt1 + uniqueCnt2)

        lo, hi = 1, 2 * (uniqueCnt1 + uniqueCnt2) + 2
        while lo < hi:
            mid = (lo + hi) // 2
            if ok(mid):
                hi = mid
            else:
                lo = mid + 1
        return lo
```

> 💡 两份代码均通过官方示例（`4`、`3`、`15`），并通过**穷举 $d_1, d_2 \in [2,6] \times u_1, u_2 \in [1,8]$ 全部 1600 组**与 600 组随机大参数（$d \le 30$、$u \le 60$）的「逐数字 DP 分配」暴力对拍，`mismatch = 0`。

## 8. 边界情况与易错点

1. **$\mathrm{lcm}$ 溢出**：$L$ 可达 $10^{10}$，C++ 全程 `long long`；只写 `d1 * d2 / g` 会在乘法处先溢出，务必先除后乘。
2. **二分上界也要 `long long`**：$2 \times 10^9 + 2$ 大于 `int` 的常规安全使用范围，返回值虽在 `int` 内，中间量不在。
3. **三条件漏一必错**：只查「各自池够」不查总量，会在自由数上重复计数（把同一个数同时划给两数组）。
4. **both 类是纯损失**：被 $L$ 整除的数谁都进不了，密度越大（$d_1 \mid d_2$ 时尤甚）答案越被迫抬高——示例 3 中 $L = 4$，每 4 个数损失 1 个。
5. **答案不是 $\mathrm{lcm}$ 的倍数**也无妨：二分收的是「最小可行 $m$」，尾部不完整周期由整除下取整自然处理。
6. **$u_1, u_2$ 本身可达 $10^9$**：不能开数组逐个分配，计数公式是唯一出路。
7. **别把整除方向搞反**：arr1 禁 $d_1$ 的倍数，所以「only1（$\div d_1$）」只能进 **arr2**——名字里的 1/2 很容易和数组编号对调出错，建议在代码注释里写清楚。
