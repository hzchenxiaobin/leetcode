# LeetCode 统计同位异构字符串数目 题解

## 1. 题目概述

- **标题 / 题号**：统计同位异构字符串数目（#2514，hard）
- **链接**：https://leetcode.cn/problems/count-anagrams/
- **来源**：LeetCode 第 94 场双周赛 Q4
- **难度**：困难
- **标签**：哈希表、数学、字符串、组合数学、计数、费马小定理

**题意**：字符串 $s$ 由一个或多个**单词**组成，单词间以单个空格分隔。若 $t$ 的第 $i$ 个单词是 $s$ 的第 $i$ 个单词的一个**排列**（重排），则称 $t$ 是 $s$ 的同位异构字符串（不同位置可以选不同的排列，但不能调换单词顺序）。求 $s$ 的同位异构字符串数目，对 $10^9 + 7$ 取模。

**约束**：

- $1 \le s.length \le 10^5$
- 只含小写字母与空格，相邻单词间恰一个空格

## 2. 示例

**示例 1**

```text
输入：s = "too hot"
输出：18
解释：单词内排列方案数分别为 3!/2! = 3 与 3! = 6，乘法原理得 3 × 6 = 18。
```

**示例 2**

```text
输入：s = "aa"
输出：1
解释：只有一个单词 "aa"，任意重排仍是 "aa"，故只有 1 种。
```

**示例 3（边界补充）**

```text
输入：s = "abc"
输出：6
解释：单个单词 "abc" 无重复字母，3! = 6 种排列。
```

## 3. 解题思路

### 3.1 暴力思路

枚举每个单词的所有排列再乘起来。单词长可达 $10^5$，排列数是天文数字；即便去重后枚举，单个长度为 50 的单词就有约 $\frac{50!}{30!} \approx 10^{40}$ 个不同排列。暴力既不可枚举也不可数——必须用**计数公式**直接算出每个单词的排列方案数。

### 3.2 核心观察：多重集排列数 + 乘法原理

![单词内多重集排列：too 的 3!/2! = 3 种](images/bw94_q4_multinomial.svg)

两个独立的事实叠出答案：

1. **单词间**：$t$ 的第 $i$ 个词只由 $s$ 的第 $i$ 个词决定，各词的排列选择互不影响——**乘法原理**，总数为各词方案数之积。
2. **单词内**：长为 $L$、字母计数为 $c_a, c_b, \dots$ 的单词，其不同排列数为**多重集排列数**（多项式系数）：

$$\frac{L!}{\prod_{c} c_c!}$$

即先视同字母为可区分（$L!$ 种），再对每个字母内部的 $c_c!$ 种顺序去重。于是

$$ans = \prod_{w \in s} \frac{|w|!}{\prod_{c} cnt_w(c)!} \pmod{10^9+7}$$

### 3.3 除法取模：费马小定理求逆元

模域下不能直接「除」：需要把 $\frac{L!}{\prod c_c!}$ 改写为 $L! \cdot \prod (c_c!)^{-1}$。模数 $p = 10^9 + 7$ 是**素数**，且每个 $c_c! \le L! < p$ 非零，**费马小定理**给出逆元：

$$x^{-1} \equiv x^{p-2} \pmod p$$

![阶乘与逆元表的预计算及整句乘法原理](images/bw94_q4_product_inverse.svg)

预计算 `fact[0..n]` 与 `invFact[0..n]`（只做一次 $O(\log p)$ 快速幂，再用 $invFact[i-1] = invFact[i] \cdot i$ 倒推），每个单词的方案数即可 $O(26)$ 查表得到。

### 3.4 算法流程

```text
1. n = |s|；预计算 fact[0..n]、invFact[0..n]（模 p）
2. 按空格切分 s 为单词
3. ans = 1
4. 对每个单词 w：
       统计 26 个字母计数 cnt[c]
       ways = fact[len] × Π invFact[cnt[c]]
       ans = ans × ways mod p
5. 返回 ans
```

### 3.5 示例演算

对 `s = "too hot"`：单词 `"too"` 长 3，$cnt_t = 1, cnt_o = 2$，方案数 $\frac{3!}{1!\,2!} = 3$（too、oto、oot）；单词 `"hot"` 长 3、字母互异，方案数 $3! = 6$。答案 $3 \times 6 = 18$。

## 4. 算法细节

1. **阶乘表按 $|s|$ 开**：最长单词 $\le |s| \le 10^5$，直接预计算到 $n$ 一劳永逸，无需按单词长度单独开。
2. **逆元表倒推**：`invFact[n] = powm(fact[n], p-2)` 一次快速幂，再 `invFact[i-1] = invFact[i] * i % p` 线性回填——避免对每个阶乘单独做 $O(\log p)$ 幂。
3. **切分**：按题面单词间单空格，`split(' ')`（Python）或手扫到空格（C++）皆可；若有连续空格，`split(' ')` 产生空串——空串 `fact[0] = 1`、`invFact[0] = 1` 贡献 1，无害。
4. **计数就地累乘**：逐单词统计 `cnt[26]`，`ways` 用 `long long` 中间乘（C++ 中 `fact * invFact` 两个 $< p$ 的数乘积 $< 10^{18}$，在 `long long` 内），每步取模。
5. **答案初值 1**：至少一个单词，乘法原理从 1 起乘。
6. **不必担心 $c_c! \equiv 0$**：$c_c \le 10^5 < p$，阶乘在模域非零，逆元存在。

## 5. 正确性证明

**引理 1（单词独立 / 乘法原理）**：$s$ 的同位异构字符串个数 $= \prod_{i=1}^{W} f(w_i)$，其中 $f(w)$ 是单词 $w$ 的不同排列数。

**证明**：$t$ 是 $s$ 的同位异构字符串当且仅当对每个 $i$，$t$ 的第 $i$ 个词是 $w_i$ 的一个排列；各词的排列**独立选取**，且不同的选取组合产生不同的 $t$（$t$ 可由其各位置的词唯一还原）。故由乘法原理，总数为各词排列数的乘积。∎

**引理 2（多重集排列数）**：长为 $L$、字母 $x$ 出现 $c_x$ 次的单词（$\sum_x c_x = L$）的不同排列数 $f(w) = \frac{L!}{\prod_x c_x!}$。

**证明**：法一（去重计数）：把同字母看作两两可辨（加下标），则 $L$ 个互异符号的排列共 $L!$ 个。每个实际的字符串 $u$ 对应「同字母重新标号」后的恰好 $\prod_x c_x!$ 个可辨排列（字母 $x$ 的 $c_x$ 个副本内部次序任意），故 $L! = f(w) \cdot \prod_x c_x!$。法二（位置选取）：依次为每个字母选位置：$\binom{L}{c_{x_1}}\binom{L-c_{x_1}}{c_{x_2}} \cdots = \frac{L!}{\prod_x c_x!}$。∎

**引理 3（模域除法 = 乘逆元）**：$p = 10^9 + 7$ 为素数；对 $0 < a < p$，$a^{-1} \equiv a^{p-2} \pmod p$；且 $invFact[i-1] \equiv invFact[i] \cdot i \pmod p$。

**证明**：$a$ 与 $p$ 互素，由费马小定理 $a^{p-1} \equiv 1 \pmod p$，两边乘 $a^{-1}$ 得 $a^{-1} \equiv a^{p-2}$。又 $(i-1)! \cdot i = i!$，两边取模逆元：$\big((i-1)!\big)^{-1} \equiv (i!)^{-1} \cdot i$，即回推式成立（逆元在模域唯一，因模素数下非零元可逆）。∎

**定理**：算法返回 $s$ 的同位异构字符串数目对 $p$ 的余数。

**证明**：由引理 1，答案为 $\prod_w f(w) \bmod p$；由引理 2，$f(w) = fact[|w|] \prod_c invFact[cnt_w(c)]$ 在整数意义上成立，由引理 3 右式在模域与该整数同余（模域中「除以 $c!$」合法地实现为乘其逆元），逐词累乘保持同余；循环结束时累乘值 $\equiv \prod f(w) \pmod p$。∎

## 6. 复杂度分析

- **时间**：$O(|s| + 26 \cdot W)$。预计算阶乘与逆元各 $O(|s|)$（另加一次 $O(\log p)$ 快速幂）；每个单词统计计数 $O(|w|)$、求方案数 $O(26)$，求和线性。
- **空间**：$O(|s|)$。两张阶乘表；计数数组 $O(26)$。

## 7. 参考代码

### C++

```cpp
class Solution {
    static constexpr long long MOD = 1000000007;
public:
    int countAnagrams(string s) {
        int n = s.size();
        vector<long long> fact(n + 1), invFact(n + 1);
        fact[0] = 1;
        for (int i = 1; i <= n; ++i) fact[i] = fact[i - 1] * i % MOD;
        invFact[n] = powm(fact[n], MOD - 2);              // 费马小定理求逆元
        for (int i = n; i >= 1; --i) invFact[i - 1] = invFact[i] * i % MOD;

        long long ans = 1;
        int i = 0;
        while (i < n) {
            int j = i;
            while (j < n && s[j] != ' ') ++j;             // 切出一个单词
            int len = j - i, cnt[26] = {0};
            for (int t = i; t < j; ++t) ++cnt[s[t] - 'a'];
            long long ways = fact[len];
            for (int c = 0; c < 26; ++c) ways = ways * invFact[cnt[c]] % MOD;
            ans = ans * ways % MOD;                       // 乘法原理：单词间独立
            i = j + 1;
        }
        return (int)ans;
    }
private:
    long long powm(long long a, long long e) {
        long long r = 1;
        for (; e > 0; e >>= 1, a = a * a % MOD)
            if (e & 1) r = r * a % MOD;
        return r;
    }
};
```

### Python

```python
class Solution:
    def countAnagrams(self, s: str) -> int:
        MOD = 10 ** 9 + 7
        n = len(s)
        fact = [1] * (n + 1)
        for i in range(1, n + 1):
            fact[i] = fact[i - 1] * i % MOD
        inv_fact = [1] * (n + 1)
        inv_fact[n] = pow(fact[n], MOD - 2, MOD)     # 费马小定理求逆元
        for i in range(n, 0, -1):
            inv_fact[i - 1] = inv_fact[i] * i % MOD

        ans = 1
        for w in s.split(' '):
            ways = fact[len(w)]
            for c in set(w):
                ways = ways * inv_fact[w.count(c)] % MOD
            ans = ans * ways % MOD                  # 乘法原理：单词间独立
        return ans
```

> 💡 两份代码均通过官方示例（`18`、`1`）、全同字母/无重复字母/多词边界，以及 3010 组随机小句与「穷举去重排列」暴力（含 `mississippi`、`abcdefghij` 等定向样例）的对拍，`mismatch = 0`。

## 8. 边界情况与易错点

1. **全同字母单词**：$\frac{L!}{L!} = 1$，如 `"aa"`（示例 2）——若漏乘某个 `invFact[cnt[c]]` 会错把它算成 $L!$。
2. **阶乘表大小**：开 $|s| + 1$ 而不是「最长单词」——一次遍历求上界啰嗦，直接按 $|s|$ 开最省心且必然够用。
3. **逆元表回推方向**：`invFact[i-1] = invFact[i] * i`，初值在**高端**做一次快速幂；方向或初值写错会全盘崩。
4. **C++ 中间乘法溢出**：两个 $< 10^9+7$ 的数相乘达 $10^{18}$，`long long` 恰好放得下（上限约 $9.2 \times 10^{18}$），但若先乘三项再取模必溢出——坚持「乘一次、模一次」。
5. **切分细节**：题面保证单词间单个空格、无前后缀空格；若数据更野（连续空格），`split(' ')` 会出空串，贡献 $fact[0] = 1$，不影响结果，但 C++ 手扫版会跳过它，两版行为对结果一致无害。
6. **不要把「同位异构」理解成整句重排**：单词顺序不能换、词间空格结构固定，只有**词内**字母可动（`"def cab"` 不是 `"abc def"` 的同位异构字符串）。
7. **模数固定 $10^9+7$ 为素数**是逆元存在的前提；若模数换成合数（如 $10^9+9$ 之类素数以外），费马小定理失效，需扩展欧几里得。
