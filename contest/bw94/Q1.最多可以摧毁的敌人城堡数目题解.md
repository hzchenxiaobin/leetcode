# LeetCode 最多可以摧毁的敌人城堡数目 题解

## 1. 题目概述

- **标题 / 题号**：最多可以摧毁的敌人城堡数目（#2511，easy）
- **链接**：https://leetcode.cn/problems/maximum-enemy-forts-that-can-be-captured/
- **来源**：LeetCode 第 94 场双周赛 Q1
- **难度**：简单
- **标签**：数组、双指针

**题意**：数组 `forts` 中 `forts[i] ∈ {-1, 0, 1}`：$-1$ 是**没有城堡的空位**，$0$ 是**敌人城堡**，$1$ 是**你控制的城堡**。你可以把军队从某个己方城堡位置 $i$ 移动到某个空位 $j$，要求 $i, j$ **之间经过的位置全是敌人城堡**（$0$）。移动时途经的敌人城堡全部被摧毁。求**最多**能摧毁多少；无法移动或没有己方城堡时返回 $0$。

**约束**：

- $1 \le forts.length \le 1000$
- $-1 \le forts[i] \le 1$

## 2. 示例

**示例 1**

```text
输入：forts = [1,0,0,-1,0,0,0,0,1]
输出：4
解释：从位置 8 出发走到位置 3，沿途位置 4~7 共 4 个敌人城堡被摧毁；
若从位置 0 走到位置 3，只能摧毁 2 个。
```

**示例 2**

```text
输入：forts = [0,0,1,-1]
输出：0
解释：唯一的己方城堡（位置 2）紧挨空位（位置 3），沿途没有敌人城堡可摧毁。
```

**示例 3（边界补充）**

```text
输入：forts = [-1, -1]
输出：0
解释：没有己方城堡，无法移动，返回 0。
```

## 3. 解题思路

### 3.1 暴力思路

枚举每一对 $(i, j)$：若 $forts[i] = 1$、$forts[j] = -1$ 且两者之间**全为 0**，则可摧毁 $|i - j| - 1$ 个，取最大。这是 $O(n^2)$（内层还要验证区间），$n \le 1000$ 时约 $10^6$ 次操作，能过但浪费——移动被「区间内全 0」严格限制，说明合法的 $(i, j)$ 对一定是**相邻两个非零位置**，天然可以一次线性扫描解决。

### 3.2 核心观察：合法移动只会发生在相邻非零位置之间

![从己方城堡向两侧扫描连续的 0](images/bw94_q1_scan_directions.svg)

若从 $i$ 到 $j$ 之间全为 0，那么 $j$ 一定是**从 $i$ 出发遇到的第一个非零位置**（否则中间那个非零位置挡住了去路）。于是只需对每个 $forts[i] = 1$ 的位置，向**左、右**两个方向数连续 0 的个数，直到碰到第一个非零位置——若它是 $-1$，用这段 0 的个数更新答案；若是另一个 $1$ 或越界，该方向作废。问题化归为「求每对**相邻非零位置**之间 0 段的最大长度，且两端分别为 $1$ 与 $-1$」。

### 3.3 算法流程

```text
1. ans = 0
2. 对每个 i 使 forts[i] == 1：
       向左：c = 连续 0 的个数；若停在 j 且 forts[j] == -1，ans = max(ans, c)
       向右：同上
3. 返回 ans
```

### 3.4 示例演算

![示例 1 的两个方向扫描](images/bw94_q1_example_walkthrough.svg)

对示例 1 `forts = [1,0,0,-1,0,0,0,0,1]`：

| 出发点 | 方向 | 途径 0 | 停在 | 是否 −1 | 可摧毁 |
|--------|------|--------|------|---------|--------|
| 0 | 向右 | 2 个 | 位置 3（−1） | 是 | 2 |
| 8 | 向左 | 4 个 | 位置 3（−1） | 是 | **4** |

最大值 $4$。

## 4. 算法细节

1. **两个方向都要扫**：己方城堡两侧都可能有「0 串 + 空位」的组合，漏一侧会 WA（示例 1 的答案恰在左侧）。
2. **碰到 1 也要停**：两个己方城堡之间的 0 段不能作为移动路径（终点必须是空位 $-1$），停止后检查「停下的位置是否为 $-1$」即可一并处理。
3. **一遍扫描的紧凑写法**：维护 `last`（上一个非零位置）与 `zeros`（到当前为止连续 0 的个数），遇到非零位置时若 `forts[last] + forts[cur] == 0` 且 `forts[last] != 0`（即一端为 1、另一端为 −1），用 `zeros` 更新答案。本篇采用逐点双向扫，逻辑更显式。
4. **返回 0 的情形**：没有 $1$、没有 $-1$、或所有相邻非零对都是 $(1, 1)$，全程不更新 `ans`。

## 5. 正确性证明

**引理 1（合法移动的刻画）**：从 $i$ 到 $j$ 的一次移动合法，当且仅当 $forts[i] = 1$、$forts[j] = -1$ 且对一切 $\min(i,j) < k < \max(i,j)$ 有 $forts[k] = 0$；此时摧毁数为 $\max(i,j) - \min(i,j) - 1$，恰为区间内 0 的个数。

**证明**：按题面定义直接对照：出发点必须是己方城堡、目标必须是空位、途径全为敌人城堡；区间长度为 $|i - j| + 1$ 的下标中除去两端 $i, j$，剩下的 $|i - j| - 1$ 个位置全为 0，即摧毁数。∎

**定理**：算法返回最多可摧毁的敌人城堡数目。

**证明**：一方面，算法枚举的每个「1 出发向一侧扫到第一个非零位置」的情形都对应一次合法移动（引理 1），故答案候选全部可行，算法输出 $\le$ 真实最优。另一方面，任取最优的合法移动 $(i, j)$，设 $j$ 是从 $i$ 出发该方向上遇到的第一个非零位置——若 $j' \ne j$ 是更近的非零位置，则 $i, j$ 之间含非零位置，与引理 1 矛盾；故 $(i, j)$ 恰是算法在 $i$ 处该方向扫到的对，其摧毁数被算法计入候选。两端取遍所有 $i$ 与方向，真实最优必在候选中，故算法输出 $\ge$ 真实最优。∎

## 6. 复杂度分析

- **时间**：$O(n)$。每个位置至多被「出发扫描」经过常数次；所有方向的扫描总步数不超过 $2n$。
- **空间**：$O(1)$。只使用计数变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int captureForts(vector<int>& forts) {
        int n = forts.size(), ans = 0;
        for (int i = 0; i < n; ++i) {
            if (forts[i] != 1) continue;             // 只从己方城堡出发
            int c = 0;
            for (int j = i - 1; j >= 0; --j) {       // 向左扫
                if (forts[j] == 0) ++c;
                else { if (forts[j] == -1) ans = max(ans, c); break; }
            }
            c = 0;
            for (int j = i + 1; j < n; ++j) {        // 向右扫
                if (forts[j] == 0) ++c;
                else { if (forts[j] == -1) ans = max(ans, c); break; }
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def captureForts(self, forts: list[int]) -> int:
        n = len(forts)
        ans = 0
        for i, f in enumerate(forts):
            if f != 1:                        # 只从己方城堡出发
                continue
            j = i - 1                         # 向左扫过连续的 0
            while j >= 0 and forts[j] == 0:
                j -= 1
            if j >= 0 and forts[j] == -1:
                ans = max(ans, i - j - 1)
            j = i + 1                         # 向右扫过连续的 0
            while j < n and forts[j] == 0:
                j += 1
            if j < n and forts[j] == -1:
                ans = max(ans, j - i - 1)
        return ans
```

> 💡 两份代码均通过官方示例（`4`、`0`）、全 −1 / 全 0 / 紧邻等边界，以及 5000 组随机数组与「枚举全部 $(i, j)$ 对」暴力的对拍，`mismatch = 0`。

## 8. 边界情况与易错点

1. **没有己方城堡 / 没有空位**：全程无法更新，返回 $0$（示例 3）。
2. **己方城堡紧挨空位**：摧毁 0 个，但**这次移动本身合法**——答案里 0 与「无法移动」不可区分，本题都返回 0，无需特判（示例 2）。
3. **两个 1 之间的 0 段不算**：停止条件里必须区分「停在 $-1$」与「停在 $1$」，不要把非零一概当作有效终点。
4. **方向别漏**：从同一个 1 出发左右两段的 0 个数不同（示例 1）。
5. **从 $-1$ 出发移动是非法的**：题目规定军队从**你控制的**城堡出发，不要「对称地」从 −1 扫 1。
6. **不要用排序/滑动窗口过度设计**：这就是一个分段扫描题，$O(n^2)$ 也能过，但线性写法只有几行。
