# LeetCode 奖励最顶尖的 K 名学生 题解

## 1. 题目概述

- **标题 / 题号**：奖励最顶尖的 K 名学生（#2512，medium）
- **链接**：https://leetcode.cn/problems/reward-top-k-students/
- **来源**：LeetCode 第 94 场双周赛 Q2
- **难度**：中等
- **标签**：数组、哈希表、字符串、排序、堆（优先队列）

**题意**：给定正面词表 `positive_feedback` 与负面词表 `negative_feedback`（两表无交集）。学生评语为 `report[i]`、学号为 `student_id[i]`（互不相同）。每个正面词给学生的分数 **加 3 分**，每个负面词**减 1 分**。返回按**分数从高到低**排名的前 $k$ 名学生；分数相同者 **ID 较小者在前**。

**约束**：

- $1 \le positive\_feedback.length, negative\_feedback.length \le 10^4$
- $1 \le$ 词长 $\le 100$，均只含小写字母
- $1 \le n \le 10^4$，$1 \le report[i].length \le 100$，单词间单个空格分隔
- $1 \le student\_id[i] \le 10^9$，互不相同
- $1 \le k \le n$

## 2. 示例

**示例 1**

```text
输入：positive_feedback = ["smart","brilliant","studious"], negative_feedback = ["not"],
     report = ["this student is studious","the student is smart"], student_id = [1,2], k = 2
输出：[1,2]
解释：两人各命中一个正面词得 3 分；分数相同，ID 小的 1 排在前面。
```

**示例 2**

```text
输入：positive_feedback = ["smart","brilliant","studious"], negative_feedback = ["not"],
     report = ["this student is not studious","the student is smart"], student_id = [1,2], k = 2
输出：[2,1]
解释：学生 1 命中 1 个正面词和 1 个负面词，得 3 - 1 = 2 分；
学生 2 命中 1 个正面词，得 3 分。学生 2 排前。
```

**示例 3（边界补充）**

```text
输入：positive_feedback = ["a"], negative_feedback = ["b"],
     report = ["a a a b b", "b b", "a"], student_id = [10, 7, 3], k = 3
输出：[3,10,7]
解释：分数分别为 7、-2、3：按分数排 3 > 10 > 7（7 号为 -2 分仍需入榜，因为 k = n）。
```

## 3. 解题思路

### 3.1 暴力思路

对学生 $i$ 的每个单词，线性扫描 `positive_feedback` 与 `negative_feedback` 判定归属。单词总数 $W \le n \cdot 50 = 5 \times 10^5$，每次判定 $O(2 \times 10^4)$，总量约 $10^{10}$——必然超时。瓶颈在**单词归属判定**：词表固定、查询海量，标准解法是哈希集合 $O(1)$ 查询。

### 3.2 核心观察：哈希计分 + 元组排序

![评分流水线：切分、集合查询、累分](images/bw94_q2_scoring_pipeline.svg)

把两张词表各建成一个**哈希集合**，评语按空格切分后逐词查询：命中正面集合 $+3$，命中负面集合 $-1$（两表无交集，无歧义）。得到每人分数后，排名规则「分数降序、同分 ID 升序」恰好等价于把元组 $(-score,\ id)$ **升序排序**——一维化处理，不需要自定义比较器的多关键字分支。

### 3.3 算法流程

![按（-分数, ID）排序取前 k](images/bw94_q2_ranking_table.svg)

```text
1. pos = 正面词哈希集合；neg = 负面词哈希集合
2. 对每个学生 i：切分 report[i]，score = 3·(命中 pos 的词数) − 1·(命中 neg 的词数)
3. 生成元组 (-score, student_id[i])，全部升序排序
4. 返回前 k 个元组的 id 部分
```

### 3.4 示例演算

对示例 2 演算：

| 学生 | 评语切分 | 命中 | 分数 | 元组 |
|------|----------|------|------|------|
| 1 | this / student / is / **not** / **studious** | 正面 1、负面 1 | $3 - 1 = 2$ | $(-2, 1)$ |
| 2 | the / student / is / **smart** | 正面 1 | $3$ | $(-3, 2)$ |

排序后 $(-3, 2) < (-2, 1)$，前 $k=2$ 名为 $[2, 1]$。

## 4. 算法细节

1. **建集合的成本**：$O(P + N)$ 一次性建好；词表无交集（题面保证），无需处理「一词两属」的优先级。
2. **切分**：C++ 用 `istringstream >> w` 自动按空白切分；Python 用 `rpt.split(' ')`（题面保证单词间单空格，`split()` 亦可行）。
3. **排序关键字**：$(-score, id)$ 的自然升序 == 「分数降序、ID 升序」。若分数范围小也可计数排序，但 $n \le 10^4$ 时直接排最省心。
4. **只取前 k**：排序后截前 $k$ 即可；若 $k \ll n$ 且 $n$ 巨大，可用大小为 $k$ 的堆维护前 $k$ 名，$O(n \log k)$。
5. **ID 上界 $10^9$**：超过 16 位整型的一半但仍在 `int` 内；注意不要把 ID 当数组下标。
6. **分数可为负**：初值 0、负面词多则总分低，排序不受影响（元组已一维化）。

## 5. 正确性证明

**引理 1（计分正确性）**：学生 $i$ 的得分为 $score_i = 3 \cdot p_i - 1 \cdot q_i$，其中 $p_i$、$q_i$ 分别是评语中命中正面、负面词表的单词数（按出现次数计，同一单词重复出现重复计分）。

**证明**：题面规定每个正面词 $+3$、每个负面词 $-1$，词表无交集故每个单词的归属唯一；哈希集合查询在单词匹配上是精确的（集合成员判定无假阳/假阴），逐词累加即得。∎

**引理 2（排名的线性化）**：「分数降序、同分 ID 升序」的全序关系与元组 $(-score, id)$ 的字典序升序完全一致。

**证明**：比较两元组 $(-s_a, id_a)$ 与 $(-s_b, id_b)$：第一分量更小 $\iff s$ 更大，与「分数高在前」一致；第一分量相等（$s_a = s_b$）时比较第二分量，ID 小者在前，与平局规则一致。反之该规则下相邻可交换的每对都被字典序保持，两序相同。∎

**定理**：算法返回题目要求的 Top-$k$ 学生 ID 序列。

**证明**：由引理 1 各学生分数计算正确；由引理 2，对全体元组升序排序后，序列前 $k$ 项恰为按规则排名的前 $k$ 名（$k \le n$ 保证不越界），输出其 ID 部分即答案。∎

## 6. 复杂度分析

- **时间**：$O(P + N + W + n \log n)$。建集合 $O(P + N)$；计分需切分并查询全部 $W$ 个单词，$W \le \sum |report_i| / 2 \le 5 \times 10^5$，每次 $O(1)$；排序 $O(n \log n)$。
- **空间**：$O(P + N + n)$。两个哈希集合与排序缓冲区（切分的临时串为 $O(单串长)$）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> topStudents(vector<string>& positive_feedback, vector<string>& negative_feedback,
                            vector<string>& report, vector<int>& student_id, int k) {
        unordered_set<string> pos(positive_feedback.begin(), positive_feedback.end());
        unordered_set<string> neg(negative_feedback.begin(), negative_feedback.end());
        int n = report.size();
        vector<pair<int, int>> rank(n);              // (-score, id)，升序即按规则排名
        for (int i = 0; i < n; ++i) {
            int score = 0;
            istringstream in(report[i]);
            string w;
            while (in >> w) {
                if (pos.count(w)) score += 3;
                else if (neg.count(w)) score -= 1;
            }
            rank[i] = {-score, student_id[i]};
        }
        sort(rank.begin(), rank.end());
        vector<int> ans;
        for (int i = 0; i < k; ++i) ans.push_back(rank[i].second);
        return ans;
    }
};
```

### Python

```python
class Solution:
    def topStudents(self, positive_feedback: list[str], negative_feedback: list[str],
                    report: list[str], student_id: list[int], k: int) -> list[int]:
        pos = set(positive_feedback)
        neg = set(negative_feedback)
        rank = []                             # (-score, id)，升序即按规则排名
        for rid, rpt in zip(student_id, report):
            score = 0
            for w in rpt.split(' '):
                if w in pos:
                    score += 3
                elif w in neg:
                    score -= 1
            rank.append((-score, rid))
        rank.sort()
        return [rid for _, rid in rank[:k]]
```

> 💡 两份代码均通过官方示例（`[1,2]`、`[2,1]`）、负分/全命中/平局边界，以及 2000 组随机数据与「逐词线性扫描词表」朴素暴力的对拍，`mismatch = 0`。

## 8. 边界情况与易错点

1. **平局看 ID**：不要只按分数排，平局规则用 $(-score, id)$ 一并编码，杜绝自定义比较器写错。
2. **分数可以为负**：初值 0、负面词多则入负；不要把分数当「出现次数」下界处理。
3. **同一单词重复出现**：每出现一次计一次分（示例 3 的 "a a a" 得 9 分），哈希集合逐词查询天然满足。
4. **正负词表无交集**是题面保证；若两表可能重叠需明确优先级（本题无此分支）。
5. **切分**：单词间保证单个空格；`split(' ')` 与流式 `>>` 都安全，但不要 `split()` 后假设恰好词数（题面无前后缀空格，若有则 `split(' ')` 会产生空串——空串命中不了词表，无害）。
6. **ID 不是下标**：$id \le 10^9$，用 `pair`/元组携带，别开 `id` 大小的数组。
7. **$k = n$**：全员入榜，包括 0 分与负分学生。

**延伸思考**：若词表带**权重**（每个正面词分值不同），把「命中集合 +3」升级为「哈希映射 + 分值」即可，复杂度不变；若评语以流式到达、$k$ 固定且 $n$ 不可预知，改用大小为 $k$ 的大根堆维护「当前第 k 名」，达到 $O(1)$ 单词均摊、$O(\log k)$ 淘汰——这是实时榜单（排行榜）问题的通用骨架。另外，「同分 ID 小在前」的多关键字排序，工程上永远优先用元组线性化而不是手写比较器。
