# LeetCode 解码斜向换位密码 题解

## 1. 题目概述

- **标题 / 题号**：解码斜向换位密码（#2075，medium）
- **链接**：https://leetcode.cn/problems/decode-the-slanted-ciphertext/
- **来源**：LeetCode 第 267 场周赛 Q3
- **难度**：中等
- **标签**：字符串、模拟、矩阵、下标映射

**题意**：一种「斜向换位密码」按两步加密。第一步，把原文 `originalText` 沿「左上 → 右下」的对角线写入一个行数固定为 `rows` 的矩阵：第 0 条对角线从 $(0,0)$ 出发走到最后一行，第 1 条从 $(0,1)$ 出发……依次类推；写完文本后，剩余格子全部补空格，列数 `cols` 由编码方选定（保证最右一列含文本字符）。第二步，**按行**从左到右读出整个矩阵，拼接得到 `encodedText`。现给定 `encodedText` 与 `rows`，还原 `originalText`。

**约束**：

- $0 \leq |\text{encodedText}| \leq 10^6$
- `encodedText` 仅由小写英文字母和空格组成
- 输入保证是某个**不含尾随空格**的原文的有效编码，且答案唯一
- $1 \leq \text{rows} \leq 1000$

> 💡 **审题关键**：① 「斜向写入」的对角线**全部从顶行出发**，向右下推进——矩阵左下三角（列号 < 行号）的格子**永远不会被文本经过**；② 「按行读出」意味着 `encodedText` 恰是矩阵的行主序展开，长度 $= \text{rows} \times \text{cols}$，`cols` 可以直接除出来；③ 还原出的字符串尾部混着填充空格，而题目承诺原文**无尾随空格**——所以只 `rstrip`、千万别 `strip`（前导空格是文本的一部分，见示例 4）。

## 3. 解题思路

### 3.1 暴力思路：还原矩阵，再走对角线

先 $cols = n / \text{rows}$（$n$ 为 `encodedText` 长度），把串切成 `rows` 段按行摆进二维数组；再按对角线序遍历矩阵收集字符；最后去掉尾随空格。

- **正确性**：显然正确，与编码过程严格互逆。
- **复杂度**：时间 $O(n)$，但**额外开一个 rows×cols 的矩阵**，且字符被搬运两次（一次进矩阵、一次进结果）。$10^6$ 规模完全能过——但这题真正的分水岭不在复杂度，而在**想清楚对角线如何枚举**。矩阵从头到尾只是「下标换算」的具象。

### 3.2 核心观察：矩阵是幻觉，一个乘法就够了

![对角线写入与按行读出](images/wc267_q3_diagonal_concept.svg)

两个观察把矩阵彻底干掉：

**观察一（行主序双射）**：`encodedText` 就是矩阵的行主序展开——格子 $(i, j)$ 与下标 $i \times cols + j$ 一一对应。想「看」矩阵里的任何一个格子，不需要真的建矩阵：`encodedText[i*cols + j]` 就是它。

**观察二（对角线序的枚举方式）**：所有被文本经过的格子都满足 $j \geq i$（对角线从顶行 $(0,k)$ 出发向右下走，列号始终不小于行号）。按编码顺序访问它们，等价于：依次枚举对角线起点 $(0, k)$（$k = 0, 1, \dots, cols-1$），沿 $(i, k+i)$ 步进，直到 $i$ 触底或 $j$ 触右边界。

于是整个解码 = 三行下标运算：外层枚举 $k$，内层沿对角线收集 `encodedText[i*cols + j]`，末尾 `rstrip`。

> 💡 一个容易被忽略的副产品：左下三角（$j < i$ 的格子，当 $cols \geq rows$ 时共 $\text{rows}(\text{rows}-1)/2$ 个）**从头到尾不参与编码**，它们只是按行读出时混进 `encodedText` 的「噪声」。因此读出的字符总数 $|D| = \sum_{k=0}^{cols-1} \min(\text{rows},\, cols-k)$，当 $\text{rows} \geq 2$ 时严格小于 $n$——千万别指望「输出长度 = 输入长度」。

### 3.3 算法流程

![解码算法流程](images/wc267_q3_decode_flow.svg)

| 步骤 | 操作 | 说明 |
|------|------|------|
| ① | $cols = n / \text{rows}$ | 矩阵被完整读出，必整除；$n=0$ 时 $cols=0$ |
| ② | 外层 $k = 0 \to cols-1$ | 第 $k$ 条对角线的起点是 $(0, k)$ |
| ③ | 内层 $(i, j)$ 从 $(0, k)$ 出发 | 沿右下方向推进 |
| ④ | 收集 `s[i*cols + j]` | 仅当 $i < \text{rows}$ **且** $j < cols$，两个边界缺一不可 |
| ⑤ | $i{+}{+},\ j{+}{+}$ | 对角线步进，回到 ④ |
| ⑥ | 对角线用尽后 $k{+}{+}$ | 回到 ② |
| ⑦ | `rstrip` 后返回 | **只删尾部**的填充空格 |

## 4. 算法细节

1. **`cols` 的求法**：$n = |\text{encodedText}|$ 必是 `rows` 的整数倍（编码按行读出**整个**矩阵），$cols = n / \text{rows}$。$n = 0$ 时 $cols = 0$，循环体不执行，直接返回空串，无需特判。
2. **内层循环的双边界**：`while (i < rows && j < cols)`。只判 $i < \text{rows}$：当 $j \geq cols$ 时下标 $i \times cols + j$ 会**折叠到下一行**，静默读错数据；只判 $j < cols$：$i$ 到达 `rows` 后越界访问字符串。
3. **收集器**：Python 用 `list` + `''.join`（避免 `+=` 拼接的坏习惯）；C++ 用 `std::string` + `push_back`，先 `reserve(n)`。
4. **去尾**：Python 一句 `.rstrip()`；C++ 用 `while (!res.empty() && res.back() == ' ') res.pop_back();`。**只去尾部**，前导与中间空格是文本。
5. **下标规模**：$n \leq 10^6$，$i \times cols + j < n$，`int` 足够，无溢出风险。

## 5. 正确性证明

**引理 1（行主序双射）**：设矩阵 $M$ 为 $\text{rows} \times cols$，则按行读出的结果中第 $i \times cols + j$ 个字符（0 起）恰为 $M[i][j]$；解码时 $cols = n / \text{rows}$ 唯一确定，故 $M[i][j] = \text{encodedText}[i \times cols + j]$ 无损还原每个格子。

**证明**：按行读出即依次固定 $i$、按 $j = 0, \dots, cols-1$ 输出；在格子 $(i,j)$ 之前恰已输出 $i \times cols + j$ 个字符。∎

**引理 2（对角线序）**：编码的写入顺序为：第 $k$ 条对角线（$k = 0, 1, \dots, cols-1$）从 $(0,k)$ 出发依次写 $(i, k+i)$，$i = 0, 1, \dots, \min(\text{rows}-1,\, cols-1-k)$；写完第 $k$ 条才写第 $k+1$ 条。被写格子全体为 $D = \{(i,j) : 0 \leq i < \text{rows},\ i \leq j < cols\}$。

**证明**：对角线自顶行向右下推进，每步 $(i,j) \to (i+1, j+1)$，故第 $k$ 条对角线恰为 $\{(i, k+i)\}$，终止于触底（$i = \text{rows}-1$）或触右边界（$k+i = cols-1$），取先到者，即 $i \leq \min(\text{rows}-1, cols-1-k)$。$j = k + i \geq i$ 给出 $D$；不同 $k$ 的对角线互不相交且并为 $D$。∎

**引理 3（前缀结构）**：按引理 2 的顺序拼接 $D$ 中所有格子的字符，结果恰为 `originalText` 后接 $m$ 个空格，$m = |D| - |\text{originalText}| \geq 0$。

**证明**：设 $L = |\text{originalText}|$。编码时原文第 $t$ 个字符（0 起）写入 $D$ 按该顺序的第 $t$ 个格子，故 $L \leq |D|$（否则矩阵装不下，与「有效编码」矛盾）；$D$ 中其余 $m$ 个格子按规则补空格。拼接即得原文加 $m$ 个尾部空格。∎

**定理**：算法输出 `originalText`。

**证明**：由引理 1，算法中 `encodedText[i*cols + j]` 即 $M[i][j]$；算法的双重循环恰以引理 2 的顺序访问 $D$ 的每个格子各一次，故拼接结果为 `originalText` + $m$ 个尾部空格（引理 3）。由题设原文不含尾随空格，其最后一个字符（若存在）非空格，故 `rstrip` 恰删除 $m$ 个填充空格；又 `rstrip` 只作用于右端，原文的前导空格与中间空格不受影响。综上输出 = `originalText`。∎

> 💡 **唯一性从何而来**：给定 $(\text{encodedText}, \text{rows})$，$cols$、$D$ 及其遍历序均被上述构造唯一确定，再叠加「原文无尾随空格」的约定，`rstrip` 的结果唯一——这正是题目「仅存在一个可能的 originalText」的由来。若允许原文带尾随空格，解码将不再唯一（尾部空格和填充空格无法区分）。

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。内层收集的总步数 $= |D| \leq n$，`rstrip` 至多再扫一遍；外层枚举 $k$ 的开销被内层吸收。
- **空间复杂度**：$O(n)$ 存输出（不可避免）；**不计输出则 $O(1)$**——这就是不建矩阵的意义：暴力法要多存一份 rows×cols 的矩阵并把字符搬运两次，本做法用一次下标乘法完成全部「搬运」。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    string decodeCiphertext(string encodedText, int rows) {
        int n = encodedText.size();
        int cols = n / rows;
        string res;
        res.reserve(n);
        for (int k = 0; k < cols; ++k) {              // 第 k 条对角线，起点 (0, k)
            for (int i = 0, j = k; i < rows && j < cols; ++i, ++j) {
                res.push_back(encodedText[i * cols + j]);   // M[i][j] 的化身
            }
        }
        while (!res.empty() && res.back() == ' ') res.pop_back();  // 只去尾随空格
        return res;
    }
};
```

### Python

```python
class Solution:
    def decodeCiphertext(self, encodedText: str, rows: int) -> str:
        n = len(encodedText)
        cols = n // rows
        out = []
        for k in range(cols):                          # 第 k 条对角线，起点 (0, k)
            i, j = 0, k
            while i < rows and j < cols:               # 两个边界缺一不可
                out.append(encodedText[i * cols + j])  # M[i][j] 的化身
                i += 1
                j += 1
        return ''.join(out).rstrip()                   # 只去尾随空格
```

> 💡 两个版本都**没有出现二维结构**——矩阵只活在 `i * cols + j` 这个乘法里。这就是「模拟题的最高境界：模拟而不构造」。

## 8. 边界情况与易错点

1. **`strip` 用成 `strip()` / `lstrip()`**：前导空格属于文本（示例 4 输出 `" abc"`）。必须且只能去尾部。
2. **内层只判一个边界**：只判 $i < \text{rows}$ 时，$j \geq cols$ 的「幽灵格子」经 $i \times cols + j$ 折叠到**下一行**，静默读错；只判 $j < cols$ 则字符串越界。必须 `i < rows && j < cols` 同时判。
3. **Python 切片陷阱**：`encodedText[k::cols+1]` 看似一行搞定第 $k$ 条对角线（步长恰为 $cols+1$），但切片会越过右边界继续采到**下一行**的格子——那些是左下三角的填充空格。当文本较长、恰好延伸到尾部几条短对角线之后时，多采的空格会混进输出**中部**，`rstrip` 救不回来。反例：$\text{rows}=4$、原文 `"abcdefghijklmnopqrstuv"`（22 个字母）时 `encodedText = "aeimqtv bfjnru  cgkos   dhlp"`（$cols=7$），切片法输出 `"abcdefghijklmnopqrstu v"`（u 与 v 之间凭空多一个空格）。老老实实写 `while` 最稳。
4. **Python 循环内 `+=` 拼字符串**：$n$ 达 $10^6$，标准姿势是 `list.append` + `''.join`；C++ 记得 `reserve`。
5. **$n = 0$**：$cols = 0$，循环不执行，返回 `""`，天然无需特判。
6. **$\text{rows} = 1$**：每条对角线只有 1 格，输出 = 输入（示例 3）。此时「最右列非空」保证原文恰好占满整串，`rstrip` 是空操作。
7. **别假设「输出长度 = 输入长度」**：左下三角的格子从不被输出（§3.2），输出长度是 $|D|$ 而非 $n$，调试时别拿这个对账。
