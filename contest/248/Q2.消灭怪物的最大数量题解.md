# LeetCode 消灭怪物的最大数量 题解

## 1. 题目概述

- **标题 / 题号**：消灭怪物的最大数量（#1921，medium）
- **链接**：https://leetcode.cn/problems/eliminate-maximum-number-of-monsters/
- **来源**：LeetCode 第 248 场周赛 Q2
- **难度**：中等
- **标签**：贪心、排序、数组、调度

**题意**：城市遭受 $n$ 只怪物侵袭。第 $i$ 只初始距城市 $\text{dist}[i]$ 千米，以恒定速度 $\text{speed}[i]$ 千米/分逼近。你有一件需要**一分钟充电**的武器，每次充满可消灭**一只**怪物；游戏开始时武器**恰好充满**，怪物从第 0 分钟起移动。**一旦任一怪物抵达城市（距离为 0）即判负**——「恰好在某分钟开始时抵达」同样先判负、再轮到你出手。求判负前最多能消灭多少只；若能全灭返回 $n$。

**约束**：

- $n = \text{dist.length} = \text{speed.length}$，$1 \le n \le 10^5$
- $1 \le \text{dist}[i], \text{speed}[i] \le 10^5$

> 💡 本题在本仓库另有[每日题解 1921](../../solution/1901-2000/1921_消灭怪物的最大数量.md)：侧重审题四要点的拆解与「计算截止线 → 排序 → 逐槽位分配」调度模板向 253 / 630 的推广及面试问答。本篇按周赛复盘视角，聚焦「静态化 → 槽位模型 → 最早截止者优先」的最短切入路径，并补齐引理-定理化的正确性证明与赛场易错清单，两篇互为印证。

## 3. 解题思路

### 3.1 暴力思路

最朴素的是**逐分钟模拟**：每分钟开始时扫一遍所有存活怪物的位置（$\text{pos} = \text{dist} - t \cdot \text{speed}$），出现 $\le 0$ 即判负，否则消灭一只——至于消灭哪只，若没有洞察就只能枚举甚至搜索整个消灭顺序（$n!$ 种排列）。即便只做模拟不做搜索，最坏 $10^5$ 只怪物 × $10^5$ 分钟 $= 10^{10}$ 次位置更新，必然超时。

> ⚠️ 暴力法的浪费在于「动态地追怪物」。怪物**恒速**移动，命运由 $(\text{dist}[i], \text{speed}[i])$ **静态决定**——它何时抵达可以一次除法算出来，根本不需要逐分钟推进。把每只怪物折叠成一个数字后，剩下的只是「每分钟一发子弹往哪些怪物身上装」的纯静态调度问题。

### 3.2 核心观察：怪物折成截止线，消灭装进分钟槽位

![核心观察：怪物折成截止线，消灭装进分钟槽位](images/wc248_q2_deadline_concept.svg)

**观察一（恒速 ⇒ 解析到达时刻）**。第 $i$ 只怪物的位置是线性函数 $\text{pos}_i(t) = \text{dist}[i] - t \cdot \text{speed}[i]$，抵达城市（$\text{pos} = 0$）的真实时刻为

$$t_i = \frac{\text{dist}[i]}{\text{speed}[i]} \quad (\text{实数})$$

这是它的**生死截止线**：必须在此刻**之前**消灭它。

**观察二（整数分钟 ⇒ 整数截止线）**。你只能在整数分钟 $0, 1, 2, \ldots$ 出手（开局满电，第 0 分钟即可发射），故把实数截止线折成整数分钟截止线：

$$a_i = \left\lceil \frac{\text{dist}[i]}{\text{speed}[i]} \right\rceil = \left\lfloor \frac{\text{dist}[i] + \text{speed}[i] - 1}{\text{speed}[i]} \right\rfloor$$

> 💡 **为什么向上取整？** 题目规定「恰好在某分钟开始时抵达（距离为 0）」也算输，且**先判负、再轮到你出手**。若 $\text{dist}/\text{speed}$ 恰为整数 $m$，第 $m$ 分钟开始时它已站在城门口，你不能在第 $m$ 分钟打它。$\lceil \cdot \rceil$ 配合下述严格大于判定，恰好把「第 $m$ 分钟」这一枪禁掉（见 §5 引理 1）。

**观察三（每分钟一发 ⇒ 槽位模型）**。第 $k$ 次消灭**固定**发生在第 $k$ 分钟——第 $k$ 分钟是一个「槽位」，槽位 $k$ 装得下怪物 $i$ 当且仅当

$$a_i > k$$

问题于是变成经典的**带截止时间的单机调度**：$n$ 个任务各耗时 $1$ 分钟、各有一条整数截止线，机器从第 0 分钟起每分钟干一个任务，最大化按时完成的任务数。最优策略是 **EDF（Earliest Deadline First，最早截止者优先）**：把 $a_i$ 升序排序后逐槽位装填。

$$\boxed{\text{排序后第 } k \text{ 只可消灭} \iff a_{(k)} > k，\quad \text{答案} = \text{首个失败下标（或 } n\text{）}}$$

> 💡 **一句话总结**：每只怪物一个数字 $a_i = \lceil \text{dist}[i]/\text{speed}[i] \rceil$，排序后逐分钟判定 $a_{(k)} > k$——$O(n \log n)$ 排序贪心收工。

### 3.3 算法流程

![算法流程：计算截止线、排序、逐槽位贪心判定](images/wc248_q2_algorithm_flow.svg)

1. 对每个 $i$ 计算 $a_i = (\text{dist}[i] + \text{speed}[i] - 1) / \text{speed}[i]$（整数向上取整）。
2. 将 $a$ **升序排序**。
3. 从 $k = 0$ 起单趟扫描：若 $a_{(k)} > k$ 则继续；**首个** $a_{(k)} \le k$ 处立即返回 $k$。
4. 若 $n$ 只全部通过，返回 $n$。

> ⚠️ **为什么失败即停？** 第 $k$ 分钟开始时排序后第 $k$ 只（未消灭者中最迫近的）已抵达，游戏**在这一刻结束**，根本不存在第 $k+1$ 分钟。答案由「最长合法前缀」定义——即便后面某只 $a_{(j)} > j$ 也轮不到你出手（严格论证见 §5 定理）。

### 3.4 示例演算

![示例演算：三个样例的 arrival 与逐分钟判定](images/wc248_q2_example_walkthrough.svg)

以示例 3 演算「折叠 → 排序 → 判定」全过程：

| 怪物 | dist | speed | 真实到达 $t = \text{dist}/\text{speed}$ | 截止线 $a = \lceil t \rceil$ |
|------|------|-------|----------------------------------------|------------------------------|
| 0 | 3 | 5 | 0.6 | 1 |
| 1 | 2 | 3 | $\approx 0.67$ | 1 |
| 2 | 4 | 2 | 2 | 2 |

排序后 $a = [1, 1, 2]$：$k=0$：$1 > 0$ ✓；$k=1$：$1 \le 1$ ✗（第 1 分钟开始时第 2 只已越过城门）→ 答案 **1**。三只怪物中两只截止线同为 $1$，而第 0 分钟的槽位只有 $1$ 个——「截止线撞车、槽位不够」是本题最典型的失败形态，示例 2 与示例 3 殊途同归。

> 💡 **观察要点**：① 示例 1 的截止线 $[1,3,4]$ 互不冲突，逐分钟各装一只，全灭；② 示例 2 揭示「恰好整分钟抵达也算输」——判定必须**严格大于**；③ 示例 3 揭示「速度只决定截止线的相对次序」——0.6 分与 0.67 分的快慢毫无意义，折叠成 $\lceil \cdot \rceil$ 后都是截止线 $1$。

## 4. 算法细节

1. **整数向上取整**：`(dist[i] + speed[i] - 1) / speed[i]`。C++ / Python 的整数除法对正数即向下取整，加除数减一后恰为向上取整；全程纯整数，零浮点精度风险（`math.ceil(d / s)` 语义直白但依赖浮点，本题 $10^5$ 规模下虽不至出错，整数版是更稳的肌肉记忆）。
2. **计数等价式**：$a_{(k)} > k \iff c(k) \le k$，其中 $c(k) = \#\{i : a_i \le k\}$ 是截止线不超过 $k$ 的怪物数。由此排序可换成**值域桶**：$a_i \le 10^5$，开桶计数后前缀累加，找首个 $c(k) > k$ 即答案（见 §7 Python 桶版）。
3. **EDF 直觉**：每分钟该打谁？「最迫近的」——若先打截止线更晚的，更早的可能在你回头前抵达；交换相邻逆序不损失合法性，故升序最优。注意本题的严格证明走的是计数条件（§5），比交换论证更干净。
4. **失败即停**：答案是最长合法前缀的长度，首个 $a_{(k)} \le k$ 的下标 $k$ 即答案；循环内 `return k`，不要 `continue`。
5. **原地省空间**：直接把 `dist[i]` 改写成 $a_i$ 再排序，省去 $O(n)$ 辅助数组（LeetCode 不复用入参，安全；工程代码需确认调用方不依赖原值）。
6. **值域检查**：$a_i \le \text{dist}[i] \le 10^5$，`int` / `int` 乘加无溢出（`(d + s - 1) ≤ 2 \times 10^5 - 1`）。

## 5. 正确性证明

**引理 1（到达判据）**：记 $a_i = \lceil \text{dist}[i] / \text{speed}[i] \rceil$。对非负整数 $k$：第 $k$ 分钟开始时怪物 $i$ 尚未抵达城市 $\iff a_i > k$。

**证明**：第 $k$ 分钟开始时其位置为 $\text{dist}[i] - k \cdot \text{speed}[i]$，未抵达 $\iff \text{dist}[i] - k \cdot \text{speed}[i] > 0 \iff k < \text{dist}[i]/\text{speed}[i]$（记该实数为 $x > 0$）。只需证：对整数 $k$ 与正实数 $x$，$k < x \iff k < \lceil x \rceil$。若 $k < x$：$x$ 为整数时 $k < x = \lceil x \rceil$，否则 $k < x < \lceil x \rceil$。反之若 $k < \lceil x \rceil$：$x$ 为整数时 $k < x$，否则 $k \le \lceil x \rceil - 1 < x$。两方向皆立。∎

**引理 2（必要性）**：若某方案在第 $0 \sim m-1$ 分钟各消灭一只怪物且其间游戏未结束，则对一切 $0 \le t < m$ 有 $c(t) \le t$，其中 $c(t) = \#\{ i : a_i \le t \}$。

**证明**：固定 $t < m$。第 $t$ 分钟的射击能够发生，说明第 $t$ 分钟开始时所有**未被消灭**的怪物都未抵达。由引理 1，凡 $a_i \le t$ 的怪物此刻都已（或恰好）抵达，故必须已在第 $0 \sim t-1$ 分钟内被消灭——共 $t$ 个槽位，装下 $c(t)$ 只怪物，故 $c(t) \le t$。∎

**引理 3（充分性）**：设 $a_{(0)} \le a_{(1)} \le \cdots \le a_{(n-1)}$ 为升序排列。若对一切 $0 \le t < m$ 有 $c(t) \le t$，则「按升序逐分钟消灭」可连续完成 $m$ 次。

**证明**：对 $t$ 归纳：前 $t$ 次依次消灭第 $0 \sim t-1$ 小者（$t = 0$ 时 vacuously 成立）。第 $t$ 分钟开始时未消灭者为第 $t \sim n-1$ 小者，其中最迫近的是 $a_{(t)}$。由 $c(t) \le t$：若 $a_{(t)} \le t$，则第 $0 \sim t$ 小共 $t+1$ 只的截止线均 $\le t$，即 $c(t) \ge t+1$，矛盾；故 $a_{(t)} > t$。由引理 1，所有未消灭者（含最迫近的）此一刻都还活着，武器每分钟充满一次，第 $t$ 发合法射出、消灭第 $t$ 小者。归纳完成。∎

**定理**：答案 $= \max\{\, m : a_{(t)} > t \ \text{对一切}\ 0 \le t < m \,\}$，即首个满足 $a_{(k)} \le k$ 的下标 $k$（不存在则为 $n$）。

**证明**：设某方案最多消灭 $m^*$ 只。由引理 2，对一切 $t < m^*$ 有 $c(t) \le t$，而引理 3 证明中所证 $c(t) \le t \iff a_{(t)} > t$，故 $m^*$ 不超过右端最大值；反之取 $m$ 为右端最大值，$c(t) \le t$（$t < m$）处处成立，由引理 3 升序方案达成 $m$ 次消灭，故 $m^* \ge m$。两向夹逼相等。又「全体 $t < m$ 通过」的 $m$ 恰构成 $\{0, 1, \ldots, j\}$（$j$ 为首个失败下标），故该最大值即 $j$；无失败时为 $n$。∎

**推论（顺序无关性）**：答案只由多重集 $\{\lceil \text{dist}[i]/\text{speed}[i] \rceil\}$ 决定，与输入顺序无关。

**证明**：定理右端仅依赖排序后的值。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \log n)$。计算截止线一趟 $O(n)$，排序 $O(n \log n)$（瓶颈），单趟判定 $O(n)$；桶计数版为 $O(n + \min\{n, 10^5\})$。$n \le 10^5$ 远在时限内。
- **空间复杂度**：$O(n)$ 存放 `arrival` 数组；原地改写 `dist` 的版本除排序栈 $O(\log n)$ 外仅需常数个变量（代价是破坏入参）。

## 7. 参考代码

### C++（排序贪心，赛场首选）

```cpp
class Solution {
public:
    int eliminateMaximum(vector<int>& dist, vector<int>& speed) {
        int n = dist.size();
        vector<int> arrival(n);
        for (int i = 0; i < n; ++i) {
            arrival[i] = (dist[i] + speed[i] - 1) / speed[i];   // ⌈dist/speed⌉
        }
        sort(arrival.begin(), arrival.end());
        for (int k = 0; k < n; ++k) {
            if (arrival[k] <= k) {
                return k;    // 第 k 分钟开始时怪物已抵达，游戏结束
            }
        }
        return n;            // 全部消灭
    }
};
```

### Python（排序贪心）

```python
class Solution:
    def eliminateMaximum(self, dist: List[int], speed: List[int]) -> int:
        arrival = sorted((d + s - 1) // s for d, s in zip(dist, speed))
        for k, t in enumerate(arrival):
            if t <= k:
                return k
        return len(arrival)
```

### Python（桶计数版，c(k) ≤ k 视角）

```python
class Solution:
    def eliminateMaximum(self, dist: List[int], speed: List[int]) -> int:
        n = len(dist)
        cnt = [0] * (n + 1)
        for d, s in zip(dist, speed):
            cnt[min((d + s - 1) // s, n)] += 1   # 截止线 ≥ n 等价于「永不过期」
        c = 0
        for t in range(n):
            c += cnt[t]
            if c > t:
                return t
        return n
```

> 💡 **写法对照**：排序版是 EDF 的直译，$O(n \log n)$ 通用可靠；桶版把 $a_{(k)} > k$ 换成等价的 $c(k) \le k$，利用值域 $10^5$ 降到线性，呼应 §5 的计数证明；原地版省一个数组但破坏入参。四版答案一致。

## 8. 边界情况与易错点

1. **取整方向**：必须向上取整。反例：`dist = [3,3], speed = [2,2]`——真实到达均为 $1.5$ 分，第 1 分钟开始时尚在城外 $1$ 千米处，两只都可消灭（答案 $2$）；向下取整得 $a=[1,1]$，第 1 分钟判定失败，错答 $1$。
2. **「恰好抵达」必须严格大于**：判定用 $a_{(k)} > k$ 而非 $\ge$。示例 2 中 $a_{(1)} = 1 = k$，恰为「第 1 分钟开始时距离归零」，先判负再轮到你——写成 $\ge$ 会错答 $2$。
3. **浮点直除的习惯风险**：`ceil(d / s)` 在本题范围（$10^5$）内不至出错，但整数版 `(d + s - 1) // s` 零精度依赖、跨语言一致，是更稳的首选。
4. **失败后继续扫**：首个 $a_{(k)} \le k$ 即返回 $k$。不要跳过失败下标去找后面 $a_{(j)} > j$ 的怪物——游戏在第 $k$ 分钟开始时已结束，答案由最长合法前缀决定。
5. **全灭返回 $n$**：循环自然走完时返回 `n`，别顺手返回 `0` 或漏写。
6. **$n = 1$ 与首发时机**：武器开局满电，第 $0$ 分钟即可发射；$a_i \ge 1 > 0$ 恒成立，单只怪物必可消灭，统一公式零特判。若误把首发记在第 $1$ 分钟，全场少打一发。
7. **原地版破坏入参**：把 `dist` 改写成截止线后原值不可恢复；LeetCode 判题不复用入参故安全，工程代码需调用方知情。

- **多武器（每分钟可消灭多只）**：退化为多机调度——按截止线排序后，用最小堆维护各武器的下次空闲时刻，把怪物分给「最早空闲且赶得上」的武器。
- **怪物加速（速度随时间递增）**：位置不再线性，到达时刻需解方程（如匀加速则 $\text{speed} \cdot t + \tfrac{1}{2} a t^2 = \text{dist}$）求根——只要「每怪物独立截止线 + 单位时间消灭一只」的结构不变，$\lceil \text{根} \rceil$ 后排序贪心依旧成立。
