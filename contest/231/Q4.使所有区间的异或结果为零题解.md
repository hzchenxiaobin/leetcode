# LeetCode 使所有区间的异或结果为零 题解

## 1. 题目概述

- **标题 / 题号**：使所有区间的异或结果为零（#1787，hard）
- **链接**：https://leetcode.cn/problems/make-the-xor-of-all-segments-equal-to-zero/
- **来源**：LeetCode 第 231 场周赛 Q4
- **难度**：困难
- **标签**：位运算、数组、哈希表、动态规划、计数

**题意**：给定长度为 $n$ 的整数数组 $\textit{nums}$ 和整数 $k$。一次「更改」指把某个元素改成**任意整数**。区间 $[l, r]$ 的异或结果是 $\textit{nums}[l] \oplus \textit{nums}[l+1] \oplus \cdots \oplus \textit{nums}[r]$。要求修改后**所有长度恰为 $k$ 的连续区间**（共 $n-k+1$ 个）的异或结果都等于 $0$，返回最少需要更改的元素个数。

**约束**：

- $1 \le k \le n \le 2000$
- $0 \le \textit{nums}[i] < 2^{10}$（即元素取值在 $[0, 1024)$ 内——这是本题状态设计的命门）

> 💡 **比赛视角**：压轴困难题，三步观察环环相扣：① 从「所有窗口异或为零」这种全局约束里，用**相邻窗口相消**挖出数组的**周期结构**；② 按下标 $\bmod k$ 分组后，问题落成「$k$ 组各选一个值、总异或为零、最小化改动」——值域只有 $1024$，天然适合以异或和为状态做 DP；③ 每组选值时「组内未出现的值」有将近 $1024$ 个且代价全相同，逐个枚举会超时——用「**至多一组需要取未出现值**」的交换论证把它压成一次 $O(1)$ 的**占位转移**。三步缺一不可，是典型的「结构 → 状态 → 转移优化」完整链条。

## 2. 示例

**示例 1**

```text
输入：nums = [1,2,0,3,0], k = 1
输出：3
解释：k = 1 时每个长度 1 的区间（即每个元素自身）异或都要为 0，
      全部改成 0 即可：[1,2,0,3,0] → [0,0,0,0,0]，改 3 个。
```

**示例 2**

```text
输入：nums = [3,4,5,2,1,7,3,4,7], k = 3
输出：3
解释：改成以 [3,4,7] 为周期循环：[3,4,7,3,4,7,3,4,7]。
      3 ⊕ 4 ⊕ 7 = 0，任何长度 3 的窗口都是 {3,4,7} 的整体平移，异或恒为 0。
```

**示例 3**

```text
输入：nums = [1,2,4,1,2,5,1,2,6], k = 3
输出：3
解释：改成 [1,2,3,1,2,3,1,2,3]。注意第三组原值是 {4,5,6}，
      而 1 ⊕ 2 = 3 迫使第三组取 3——一个组内从未出现过的值，整组全改。
```

**示例 4（自造边界：n = k，唯一窗口）**

```text
输入：nums = [1,2], k = 2
输出：1
解释：只有一个窗口 [1,2]，异或为 3 ≠ 0。没有相邻窗口，不存在周期约束，
      只需两数相等：改成 [1,1] 或 [2,2]，改 1 个元素即可。
```

## 3. 解题思路

### 3.1 暴力思路：直接枚举最终数组

最直觉的做法是枚举「改哪些位置、各改成什么」。但每个位置的可选值是任意整数，方案数是天文数字；即使意识到最优解的值可以限制在 $[0, 1024)$ 内（见 §5 引理 3），每个位置仍有 $1024$ 种选择，组合数 $1024^n$ 直接爆炸。

退一步想：约束耦合了所有窗口，但窗口之间高度重叠——**重叠意味着相消**。暴力枚举没有利用这层结构，而它恰恰是解开全局约束的钥匙。

### 3.2 核心观察一：窗口条件 ⟺ 周期 + 首窗口异或为零

![核心观察：相邻窗口相消推出周期性，按 mod k 分组](images/wc231_q4_period_grouping.svg)

把起点为 $i$ 和 $i+1$ 的两个相邻窗口的异或结果**异或起来**：中间 $k-1$ 个公共元素两两出现、自我相消，只剩下 $\textit{nums}[i] \oplus \textit{nums}[i+k]$。两个窗口异或都为 $0$，于是

$$\textit{nums}[i] \oplus \textit{nums}[i+k] = 0 \iff \textit{nums}[i] = \textit{nums}[i+k] \qquad (0 \le i \le n-k-1)$$

**XOR 的消去律**把「所有窗口为零」这个 $n-k+1$ 条全局约束，压缩成了两条局部结构（§5 引理 1 证明二者等价）：

1. **周期性**：$\textit{nums}[i] = \textit{nums}[i+k]$，即最终数组由前 $k$ 个值 $v_0, v_1, \dots, v_{k-1}$ 以 $k$ 为周期完全决定；
2. **首窗口为零**：$v_0 \oplus v_1 \oplus \cdots \oplus v_{k-1} = 0$。

于是**按下标 $\bmod k$ 把 $n$ 个位置分成 $k$ 组**：第 $r$ 组（下标 $r, r+k, r+2k, \dots$，共 $sz_r$ 个位置）必须统一取值 $v_r$。位置 $i$ 需要修改当且仅当 $\textit{nums}[i] \ne v_{i \bmod k}$，所以第 $r$ 组的修改数为 $sz_r - cnt_r[v_r]$，其中 $cnt_r[v]$ 是值 $v$ 在第 $r$ 组的出现次数。

> 💡 **问题重述**：选 $v_0, \dots, v_{k-1} \in [0, 1024)$，满足 $v_0 \oplus \cdots \oplus v_{k-1} = 0$，最小化
> $$\sum_{r=0}^{k-1} \bigl(sz_r - cnt_r[v_r]\bigr)$$
> ——「$k$ 组独立代价 + 一个异或约束」，标准的**分组 + 异或状压 DP** 形态。

### 3.3 核心观察二：按组 DP，「双轨」处理未出现值

![算法流程：dp / g 双轨 DP，占位转移把未出现值延迟到最后结算](images/wc231_q4_dp_tracks.svg)

值域只有 $2^{10} = 1024$，自然以**已处理组的异或和**为状态：

- $dp[x]$：前若干组全部取「组内出现过的值」，异或和为 $x$ 的最小修改数；
- 转移：处理第 $j$ 组时，枚举组内**出现过的**每个值 $v$（共 $t_j = |cnt_j|$ 种），代价 $sz_j - cnt_j[v]$：
  $$dp'[x \oplus v] = \min\bigl(dp'[x \oplus v],\ dp[x] + sz_j - cnt_j[v]\bigr)$$

麻烦在**未出现过的值**：代价全部是 $sz_j$（整组全改），却有多达 $1024 - t_j$ 个，逐个枚举最坏每组 $O(1024^2)$。两个观察联手解决：

**观察 A（交换论证，§5 引理 2）**：最优解中**至多一组**取未出现值。两组都整组全改太浪费——把 A 组改成它已有的某个值 $a$（至少省 1 处改动），B 组本来就要整组全改，值相应调整为 $f_A \oplus f_B \oplus a$ 保持总异或不变，总代价严格下降。所以「两组都取未出现值」的方案永远不是最优。

**观察 B（占位转移）**：既然至多一次，而且未出现值的**代价与具体取值无关**，处理到这一组时就不必定值——只记下代价 $sz_j$，让它的异或贡献**先空着**，状态 $x$ 原地不动，最后统一「结算」。于是增加第二条轨道：

- $g[x]$：**恰有一组**取了「未出现值（占位待结算）」，其余组取出现值，已确定部分的异或和为 $x$ 的最小修改数。

每组 $j$ 的完整转移只有三种：

| 转移 | 方向 | 代价 | 复杂度 |
|------|------|------|--------|
| 出现值转移 | $dp[x] \to dp'[x \oplus v]$ | $sz_j - cnt_j[v]$ | $O(1024 \cdot t_j)$ |
| 出现值转移 | $g[x] \to g'[x \oplus v]$ | $sz_j - cnt_j[v]$ | $O(1024 \cdot t_j)$ |
| **占位转移** | $dp[x] \to g'[x]$（异或和不变！） | $sz_j$ | $O(1)$ 每状态 |

最后结算：占位那组的取值被总异或为零**逼死**为其余组的异或和 $x$，若 $x$ 未在该组出现，代价恰为已记的 $sz$；若碰巧出现，真实代价只会更小。答案：

$$\textit{ans} = \min\Bigl(dp[0],\ \min_x g[x]\Bigr)$$

> ⚠️ **别只看 $dp[0]$**：示例 3 中三组原值 $\{1\},\{2\},\{4,5,6\}$ 根本凑不出全出现值的异或零组合，$dp[0] = \infty$，答案完全靠占位轨道 $g[3] = 3$ 撑起来。

### 3.4 示例演算

![示例演算：示例 3 的双轨 DP 逐步走查](images/wc231_q4_walkthrough.svg)

以示例 3 为例，$\textit{nums} = [1,2,4,1,2,5,1,2,6]$，$k = 3$，分组：组 0 $= [1,1,1]$，组 1 $= [2,2,2]$，组 2 $= [4,5,6]$。只列出可达状态（$\varnothing$ 表示全为 $\infty$）：

| 处理到 | 计数（代价） | $dp$（全出现值） | $g$（含一组占位） |
|--------|-------------|------------------|-------------------|
| 初始 | — | $\{0: 0\}$ | $\varnothing$ |
| 组 0 | $\{1{:}3\}$（取 1 代价 0） | $\{1: 0\}$ | $\{0: 3\}$（组 0 占位） |
| 组 1 | $\{2{:}3\}$（取 2 代价 0） | $\{3: 0\}$ | $\{1: 3,\ 2: 3\}$ |
| 组 2 | $\{4{:}1, 5{:}1, 6{:}1\}$（各代价 2） | $\{7{:}2,\ 6{:}2,\ 5{:}2\}$ | $\{3{:}3,\ 4{:}5,\ 5{:}5,\ 6{:}5,\ 7{:}5\}$ |

- $dp[0] = \infty$：组 0 只能取 1、组 1 只能取 2，逼出 $1 \oplus 2 = 3$，而 3 不在组 2 出现——**全出现值无解**；
- $g[3] = 3$：组 2 走占位转移（$dp[3] = 0$ 直接平移，代价 $+3$），结算时占位值取 $3$，恰好未在组 2 出现，代价就是 3；
- 答案 $= \min(\infty, 3) = 3$，对应把第 2 组整组改成 3，即 $[1,2,\mathbf{3},1,2,\mathbf{3},1,2,\mathbf{3}]$ ✓。

> 💡 **看清楚占位的结算机制**：$g[3] = 3$ 这条路径里，组 0 取 1、组 1 取 2 之后已确定异或 $1 \oplus 2 = 3$；占位的组 2 想让总和为零，取值被**逼死**为 $3$——「延后决定」不是「不用决定」，而是把决定推迟到信息齐全（其余 $k-1$ 组都定完）的那一刻。

## 4. 算法细节

1. **分组计数**：`cnt[r][v]` 统计下标 $\bmod k = r$ 的位置中值 $v$ 的出现次数，`sz[r]` 为组大小。$n$ 不被 $k$ 整除时，**尾部若干组的大小会少 1**（组 $r$ 的大小是 $\lfloor (n-1-r)/k \rfloor + 1$），计数时按实际位置累加即可，无需特判。
2. **状态定义**：$dp[x]$ / $g[x]$ 两轨同时滚动。$dp$ 的初值 $dp[0] = 0$（没处理任何组、异或和为零）；$g$ 初值全 $\infty$（占位必须发生在某一具体组上，不能凭空开始）。
3. **占位转移的写法**：处理组 $j$ 时先整轨赋值 `ng[x] = dp[x] + sz[j]`（注意是**直接赋值**而非取 min——$g$ 是新的一轮，占位恰好发生在组 $j$；更早占位的旧 $g$ 值走的是出现值转移进入 `ng`）。
4. **出现值转移**：枚举 $v \in cnt_j$，对全部 $1024$ 个源状态 $x$ 松弛 $x \oplus v$。内层总数 $\sum_j 1024 \cdot t_j \le 1024 \cdot n \approx 2 \times 10^6$——**关键不等式 $t_j \le sz_j$**（出现值种数不超过组大小），$\sum_j sz_j = n$。
5. **结算**：$\textit{ans} = \min(dp[0],\ \min_x g[x])$。$g$ 轨道不需要检查结算值 $x$ 是否未出现：若 $x$ 恰好在占位组出现过，真实代价是 $sz - cnt[x] <$ 记录值，答案只会更优且被正确解覆盖（§5 定理证明的两面）。
6. **值域封闭**：DP 只在 $[0, 1024)^k$ 内搜索，而题面允许改成任意整数。由 §5 引理 3，任何可行方案都能转成值域内、代价不增的方案，故不漏最优。
7. **INF 设计（C++）**：取 `INF = INT_MAX / 4`。污染值每经过一组至多增加 $sz_j$，整条链累计不超过 $\sum sz_j = n \le 2000$，`INF + 2000` 远离 `int` 上界，加法安全；真实答案 $\le n \le 2000$，污染值 $\ge 5 \times 10^8$ 永远不会污染结果。

## 5. 正确性证明

**引理 1（结构引理）**：数组 $A$ 的所有长度为 $k$ 的区间异或为零 $\iff$ (a) $A[i] = A[i+k]$ 对所有 $0 \le i \le n-k-1$ 成立，且 (b) $A[0] \oplus \cdots \oplus A[k-1] = 0$。

**证明**：（$\Rightarrow$）设起点 $i$ 与 $i+1$ 的窗口异或均为零（$0 \le i \le n-k-1$，两窗口都存在）。二式异或，公共的 $k-1$ 个元素成对相消，得 $A[i] \oplus A[i+k] = 0$，即 (a)；起点 $0$ 的窗口直接给出 (b)。

（$\Leftarrow$）设 (a)(b) 成立。对任意窗口起点 $j \in [0, n-k]$：若 $j \ge k$，窗口 $[j, j+k-1]$ 与 $[j-k, j-1]$ 的元素按 (a) 一一配对相等（配对要求 $j-k+t \le n-k-1$，即 $j+t \le n-1$，由窗口存在性保证），故两窗口异或相等，对 $j$ 归纳可下推至 $j \bmod k < k$。若 $j < k$：
$$\text{XOR}(j) = \text{XOR}(0) \oplus \underbrace{\bigl(A[0] \oplus \cdots \oplus A[j-1]\bigr)}_{\text{多出}} \oplus \underbrace{\bigl(A[k] \oplus \cdots \oplus A[k+j-1]\bigr)}_{\text{少掉}}$$
而 (a) 给出 $A[k+t] = A[t]$（$t \le j-1 \le n-k-1$ 由 $j + k - 1 \le n - 1$ 保证），两个括号相消，$\text{XOR}(j) = \text{XOR}(0) = 0$（用 (b)）。∎

**引理 2（至多一组取未出现值）**：任何满足 $v_0 \oplus \cdots \oplus v_{k-1} = 0$ 且**至少两组**取「本组未出现的值」的方案，都能被代价严格更小的可行方案替代。

**证明**：设组 $A \ne B$ 分别取未出现值 $f_A, f_B$。因 $k \le n$，每组至少含一个位置，组 $A$ 必有出现值，任取一个 $a$（$cnt_A[a] \ge 1$）。构造新方案：$v_A' = a$，$v_B' = f_A \oplus f_B \oplus a$，其余不变。总异或不变（$f_A \oplus f_B$ 被 $a \oplus v_B'$ 抵消）。代价变化：
$$\Delta = \underbrace{\bigl(sz_A - cnt_A[a]\bigr) - sz_A}_{= -\,cnt_A[a] \, \le -1} + \underbrace{\bigl(sz_B - cnt_B[v_B']\bigr) - sz_B}_{=\, -\,cnt_B[v_B'] \,\le\, 0} < 0$$
即严格改进。反复应用直到至多一组取未出现值。∎

**引理 3（值域封闭）**：任何异或为零的方案 $(v_0, \dots, v_{k-1})$（$v_r$ 为任意非负整数）都能转换为取值全在 $[0, 1024)$ 内、代价不增的可行方案。

**证明**：对取「未出现值」的组数分类（注意 $cnt_r$ 只在 $[0,1024)$ 内非零，故取值 $\ge 1024$ 必是未出现值）。若为 0，所有 $v_r$ 都有 $cnt_r[v_r] \ge 1$，自动在值域内。若 $\ge 2$，由引理 2 的交换可使其严格减少且代价不增，归纳到恰剩 1 组 $m$：令 $v_m' = \bigoplus_{r \ne m} v_r$。异或和仍为零；由 $v_r' \in [0,1024)$（其余各组此时均取出现值）知 $v_m' \in [0, 1024)$；代价 $sz_m - cnt_m[v_m'] \le sz_m$ 不增。∎

**定理（DP 正确性）**：$\min\bigl(dp[0], \min_x g[x]\bigr) = \text{OPT}$（所有合法修改方案的最小代价）。

**证明**：由引理 1，合法方案与「$(v_0,\dots,v_{k-1})$ 异或为零」一一对应且代价为 $\sum_r (sz_r - cnt_r[v_r])$；由引理 3，OPT 在 $[0,1024)^k$ 内取到。

（$\ge$）$dp[0]$ 对应一个全出现值、异或为零的可行方案，故 $dp[0] \ge \text{OPT}$。对 $\min_x g[x]$：取达最小值的路径还原方案——占位组 $m$ 取结算值 $x$，其余组取各自出现值，异或和 $x \oplus x = 0$，是可行方案；其真实代价为 $\bigl(sz_m - cnt_m[x]\bigr) + \text{（其余组记录代价）} \le g[x]$（$cnt_m[x] \ge 0$），故 $g[x] \ge \text{OPT}$。

（$\le$）取值域内最优方案 $W$。若 $W$ 全组取出现值：按组顺序做出值转移，得 $dp[0] \le \text{cost}(W)$。若恰有组 $m$ 取未出现值（引理 2）：组 $m$ 之前各组走 $dp$ 的出现值转移，组 $m$ 走占位转移（$dp \to g$，状态不变，代价 $+sz_m = sz_m - cnt_m[v_m]$，因 $cnt_m[v_m] = 0$ 吻合），之后各组走 $g$ 的出现值转移；终态 $x^* = \bigoplus_{r \ne m} v_r = v_m$（总和为零），故 $g[x^*] \le \text{cost}(W) = \text{OPT}$。

两面合夹，等号成立。∎

## 6. 复杂度分析

**时间复杂度**：$O\bigl(2^{10} \cdot (n + k)\bigr) \approx 4 \times 10^6$

- 出现值转移：每组 $O(2^{10} \cdot t_j)$，总计 $O\bigl(2^{10} \cdot \sum_j t_j\bigr) \le O(2^{10} \cdot n)$（关键：$t_j \le sz_j$，$\sum sz_j = n$）；
- 占位转移与每轮初始化：每组 $O(2^{10})$，总计 $O(2^{10} \cdot k)$；
- 分组计数 $O(n)$，最终结算 $O(2^{10})$。

**空间复杂度**：$O(2^{10} + n)$

- $dp, g, dp', g'$ 四个 $1024$ 长度数组滚动；计数表 $O(n)$（Python 字典）或 $O(2^{10} \cdot k)$（C++ 二维数组约 8 MB，也可换成哈希表压到 $O(n)$）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minChanges(vector<int>& nums, int k) {
        const int X = 1024;                 // 值域大小 2^10
        const int INF = INT_MAX / 4;        // 污染值每轮至多 +sz，累计 +n，不会溢出
        int n = nums.size();

        vector<int> sz(k, 0);
        vector<vector<int>> cnt(k, vector<int>(X, 0));
        for (int i = 0; i < n; i++) {       // 按下标 mod k 分组计数
            cnt[i % k][nums[i]]++;
            sz[i % k]++;
        }

        vector<int> dp(X, INF), g(X, INF), ndp(X), ng(X);
        dp[0] = 0;                          // 零组、异或和 0
        for (int j = 0; j < k; j++) {
            // 占位转移：第 j 组整组改为某个未出现值，取值延后结算，异或和不变
            for (int x = 0; x < X; x++) ng[x] = dp[x] + sz[j];
            fill(ndp.begin(), ndp.end(), INF);
            // 出现值转移：dp、g 两轨都只枚举组内出现过的值
            for (int v = 0; v < X; v++) {
                int c = cnt[j][v];
                if (c == 0) continue;
                int cost = sz[j] - c;
                for (int x = 0; x < X; x++) {
                    int y = x ^ v;
                    ndp[y] = min(ndp[y], dp[x] + cost);
                    ng[y] = min(ng[y], g[x] + cost);
                }
            }
            dp.swap(ndp);
            g.swap(ng);
        }
        int ans = dp[0];                    // 全出现值且异或为零
        for (int x = 0; x < X; x++)         // 占位组结算成 x，逼出异或零
            ans = min(ans, g[x]);
        return ans;
    }
};
```

### Python

```python
class Solution:
    def minChanges(self, nums: List[int], k: int) -> int:
        X = 1024
        cnt = [dict() for _ in range(k)]
        for i, v in enumerate(nums):        # 按下标 mod k 分组计数
            j = i % k
            cnt[j][v] = cnt[j].get(v, 0) + 1

        dp = [0] + [float('inf')] * (X - 1)  # 全出现值轨道
        g = [float('inf')] * X               # 恰有一组占位的轨道
        for j in range(k):
            c, sz = cnt[j], sum(cnt[j].values())
            # 占位转移：异或和原地不动，代价 +sz
            ng = [d + sz for d in dp]
            ndp = [float('inf')] * X
            for v, occ in c.items():         # 出现值转移：只枚举组内出现过的值
                cost = sz - occ
                for x in range(X):
                    y = x ^ v
                    w = dp[x] + cost
                    if w < ndp[y]:
                        ndp[y] = w
                    w = g[x] + cost
                    if w < ng[y]:
                        ng[y] = w
            dp, g = ndp, ng
        return min(dp[0], min(g))            # 结算：占位值被异或零逼出
```

> 💡 Python 版内层双循环总量约 $2^{10} \cdot n \approx 2 \times 10^6$ 次，实测最坏不到半秒；若仍嫌慢，可把出现值转移改写成 `[dp[x ^ v] + cost for x in range(X)]` 列表推导配合 `map(min, ...)` 整轨合并，常数再降 3~4 倍。

## 8. 边界情况与易错点

1. **值域是 $2^{10} = 1024$，不是 $2^k$**：状态维度由**元素值域**决定（约束里写死的 $2^{10}$），与窗口长度 $k$ 无关。把两者搞混，状态数组直接开错。
2. **别漏了 $\min_x g[x]$**：只返回 $dp[0]$ 会在示例 3 上输出 $\infty$——全出现值组合可能根本不存在，「必须整组全改」的情形完全靠占位轨道兜底。
3. **占位转移是赋值不是取 min**：`ng[x] = dp[x] + sz[j]` 必须整轨覆盖。若写成 `min(ng[x], ...)` 且忘记清空上一轮的 `ng`，会把「占位两次」的非法方案混进 $g$（虽然由引理 2 它不会赢，但那是碰巧不是正确性）。
4. **尾部小组**：$n \bmod k \ne 0$ 时，前 $n \bmod k$ 组大小为 $\lceil n/k \rceil$、其余 $k - (n \bmod k)$ 组少 1（例如 $n=5, k=3$ 时组 $\{0,3\},\{1,4\}$ 大小 2、组 $\{2\}$ 大小 1）。按位置实际累加 `sz` 即可，不要用 $n/k$ 统一初始化。
5. **$k = 1$**：窗口就是单个元素，全部必须为 0。框架自动覆盖——单组、$v_0$ 被异或约束逼为 0，答案 $n - cnt_0[0]$（示例 1）。
6. **$n = k$**：唯一窗口、无相邻窗口可消，周期约束为空，所有组大小为 1，退化为「任选 $n$ 个异或为零的值」（示例 4）。占位轨道此时至关重要——单元素组之间常常凑不出异或零。
7. **INF 溢出（C++）**：`INT_MAX` 直接 `+ cost` 会爆。用 `INT_MAX / 4` 并确认污染值整链累计增量 $\le n$（见 §4 第 7 点），或者干脆在源状态为 INF 时 `continue`。
8. **分组方向是 $i \bmod k$ 不是 $i / k$**：周期是 $k$，同组下标相差 $k$ 的倍数；写成分块（$i/k$）会把结构彻底搞反。
9. **XOR 消去律的适用前提**：引理 1 中相邻窗口必须**重叠 $k-1$ 个元素**（$k \ge 1$ 恒成立）；但「相邻窗口」要求两个都存在，即 $i \le n-k-1$，越界一步约束就不成立——$n = k$ 时没有任何周期约束（与第 6 点呼应）。
10. **修改值不受值域限制但可安全封闭**：题面允许改成任意整数；引理 3 保证最优解总在 $[0, 1024)$ 内取到，不必担心「改成一个巨大的数」会更优。
