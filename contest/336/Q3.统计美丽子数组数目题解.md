# LeetCode 统计美丽子数组数目 题解

## 1. 题目概述

- **标题 / 题号**：统计美丽子数组数目（#2588，medium）
- **链接**：https://leetcode.cn/problems/count-the-number-of-beautiful-subarrays/
- **来源**：LeetCode 第 336 场周赛 Q3
- **难度**：中等
- **标签**：位运算、数组、哈希表、前缀异或

**题意**：给定下标从 $0$ 开始的整数数组 `nums`。每次操作可以：选两个**不同**下标 $i \ne j$ 和一个非负整数 $k$，要求 $\text{nums}[i]$ 与 $\text{nums}[j]$ 的二进制第 $k$ 位**都是 $1$**，然后把两数**都减去 $2^k$**（等价于把这两个第 $k$ 位同时从 $1$ 变 $0$）。若某子数组经若干次（可为 $0$ 次）操作后能变成全 $0$ 数组，则称它**美丽**。求美丽子数组的数目。

**约束**：

- $1 \le n = \text{nums.length} \le 10^5$
- $0 \le \text{nums}[i] \le 10^6$

> 💡 **读题定位**：题面的操作「两数同位都减 $2^k$」翻译成位级语言就是——**在同一个二进制位上成对地消去两个 $1$**。「成对」暗示每位 $1$ 的个数奇偶性是**不变量**；「统计子数组个数」+「区间上的不变量」则直指**前缀 + 哈希计数**。本题是 LC 560「和为 K 的子数组」的异或版换皮：把运算子 $+$ 换成 $\wedge$，把目标 $k$ 固定为 $0$。

## 2. 示例

**示例 1**

```text
输入：nums = [4,3,1,2,4]
输出：2
解释：美丽子数组有 [4,(3,1,2),4] 中的 (3,1,2) 和 (4,3,1,2,4) 整段。
- (3,1,2)：k=1 消 3 和 2 的第 1 位 → [1,1,0]；k=0 消两个 1 → [0,0,0]。
- 整段 [4,3,1,2,4]：k=2 消两端的 4；k=0 消 3、1；k=1 消两个 2 → 全 0。
```

**示例 2**

```text
输入：nums = [1,10,4]
输出：0
解释：任何子数组都有某位上 1 的个数为奇数，无法全变 0。
```

**示例 3**（自造：零元素白送）

```text
输入：nums = [0,0]
输出：3
解释：[0]、[0]、[0,0] 全都无需操作即为全 0，全部美丽。
单个 0 也是美丽子数组——「包括 0 次操作」直接白送。
```

**示例 4**（自造：奇偶分明）

```text
输入：nums = [2,2,2,2]
输出：4
解释：2 = (10)₂。3 个长度 2 的子数组（每位两个 1，偶）+ 整段长度 4
（第 1 位四个 1，偶）都美丽；长度 1、3 的子数组第 1 位上 1 的个数为奇，不美丽。
```

## 3. 解题思路

### 3.1 暴力思路：枚举所有子数组判异或和

枚举每个起点 $l$，向右滚动异或并维护区间异或和 $s$（$s \mathrel{\wedge}= \text{nums}[r]$，$O(1)$ 更新），$s = 0$ 则计数。总时间 $O(n^2) = 10^{10}$，$n = 10^5$ 下必然超时。它暴露的结构是：判定本身已是 $O(1)$，瓶颈全在**子数组数目是平方级**——必须把「一段区间的异或和」压缩成「两个前缀之间的关系」，才能批量计数。

### 3.2 核心观察：操作 = 按位成对消 1，奇偶不变 → 异或和为 0

![核心观察：一次操作在同一个二进制位上成对消去两个 1，各 bit 互不干扰；美丽 ⟺ 每位 1 的个数为偶 ⟺ 子数组异或和为 0](images/wc336_q3_bit_pair_cancel.svg)

**关键洞察**：减 $2^k$ 只在「第 $k$ 位原来是 $1$」的前提下发生，此时减法**无借位**，效果恰是把该位 $1 \to 0$、其余位原封不动。于是：

- **各二进制位完全独立**：一次操作只触碰一个位，位与位之间互不干扰；
- **每次操作 = 在第 $k$ 位上同时消去两个 $1$**：该位 $1$ 的总数恰减 $2$，**奇偶性不变**——这是操作的不变量；
- **终态全 $0$ 的每个位上 $1$ 的个数都是 $0$（偶数）**，故初始时每个位上 $1$ 的个数都必须是偶数；反过来，只要每位都是偶数个 $1$，就可以**每位内部两两配对、逐对执行操作**消到全 $0$（充分性）。

而「每个二进制位上 $1$ 的个数为偶数」有一个极简的等价刻画：**子数组异或和为 $0$**——异或正是无进位的模 $2$ 加法，第 $k$ 位的异或结果就是该位 $1$ 个数的奇偶。

$$
\text{子数组美丽} \iff \forall k:\ \#\{i : \text{nums}[i] \text{ 的第 } k \text{ 位为 } 1\} \text{ 为偶} \iff \bigoplus_{i \in \text{子数组}} \text{nums}[i] = 0
$$

以示例 1 的 $(3,1,2)$ 为证：$(011)_2, (001)_2, (010)_2$，第 $2/1/0$ 位上 $1$ 的个数分别为 $0, 2, 2$，全偶 → 异或和 $0$ → 美丽 ✓；而 $(1)$ 单独一位上是奇数个 $1$，永远消不成 $0$。

> ⚠️ **「包括 0 次」白送零**：全 $0$ 子数组天然美丽（示例 3）。异或判据自动覆盖：全 $0$ 子数组异或和当然是 $0$，无需特判。

### 3.3 算法流程：前缀异或 + 哈希计数

![算法流程：维护滚动前缀异或 s 与计数哈希表（预置 cnt[0]=1 空前缀），每步先查 ans += cnt[s] 再 ++cnt[s]，一趟扫描返回](images/wc336_q3_prefix_hash_flow.svg)

定义前缀异或 $P_0 = 0$，$P_j = \text{nums}[0] \wedge \text{nums}[1] \wedge \dots \wedge \text{nums}[j-1]$。由 $x \wedge x = 0$，子数组 $\text{nums}[l..r]$ 的异或和为

$$
P_l \wedge P_{r+1} \quad (= 0 \iff P_l = P_{r+1}).
$$

于是「统计异或和为 $0$ 的子数组」=「统计前缀序列中**值相等的前缀对**数目」。一趟扫描即可：

1. **初始化**：滚动前缀 $s = 0$，答案 $\text{ans} = 0$，哈希表 $\text{cnt}[0] = 1$（**空前缀** $P_0$ 入表）；
2. **滚动**：$s \mathrel{\wedge}= \text{nums}[j-1]$ 得到 $P_j$；
3. **先查**：$\text{ans} \mathrel{+}= \text{cnt}[s]$——每个早先出现的相同前缀与 $P_j$ 配成一个美丽子数组；
4. **后插**：$\mathrel{+}\mathrel{+}\text{cnt}[s]$，回到第 2 步；
5. 扫描结束返回 $\text{ans}$。

> 💡 **与 LC 560 的同构**：把「前缀和 + 查 $\text{cnt}[\text{sum} - k]$」换成「前缀异或 + 查 $\text{cnt}[s \wedge 0] = \text{cnt}[s]$」，模板逐行对应。异或版反而更友好：前缀异或值域**不膨胀**（始终 $< 2^{20}$），不像前缀和会累加溢出。

### 3.4 示例演算

![示例演算：[4,3,1,2,4] 的前缀异或序列 0,4,7,6,4,0，两次相等配对 (P1,P4) 与 (P0,P5) 分别对应子数组 [3,1,2] 与整段，答案 2](images/wc336_q3_example_walkthrough.svg)

以示例 1 `nums = [4,3,1,2,4]` 为例，前缀异或序列为 $P = [0, 4, 7, 6, 4, 0]$：

| 步 $j$ | $x$ | $s = P_j$ | 命中 $\text{cnt}[s]$ | ans | 配对的子数组 |
|--------|-----|-----------|----------------------|-----|--------------|
| — | — | 0 | （预置 $\text{cnt}[0]=1$） | 0 | 空前缀 $P_0$ 入表 |
| 1 | 4 | 4 | 0 | 0 | — |
| 2 | 3 | 7 | 0 | 0 | — |
| 3 | 1 | 6 | 0 | 0 | — |
| 4 | 2 | 4 | **1** | **1** | $P_1 = P_4 = 4$ → $\text{nums}[1..3] = [3,1,2]$ |
| 5 | 4 | 0 | **1** | **2** | $P_0 = P_5 = 0$ → 整段 $[4,3,1,2,4]$ |

返回 $2$ ✓。示例 2 `[1,10,4]`：$P = [0,1,11,15]$ 全不同值，零配对，返回 $0$ ✓；示例 4 `[2,2,2,2]`：$P = [0,2,0,2,0]$，值 $0$ 出现 $3$ 次、值 $2$ 出现 $2$ 次，$\binom{3}{2} + \binom{2}{2} = 4$ ✓。

## 4. 算法细节

1. **前缀异或的「差」性质**：异或的逆运算是它自己（$a \wedge b \wedge b = a$），故 $P_l \wedge P_{r+1}$ 恰消去公共前缀、留下区间异或和；$a \wedge b = 0 \iff a = b$ 把「区间异或为 $0$」翻译成「前缀相等」，这一步是整个计数的地基；
2. **$\text{cnt}[0] = 1$ 的预置**：哈希表初始必须放入空前缀 $P_0 = 0$，否则一切**从下标 $0$ 开始**的美丽子数组（如示例 1 的整段）全部漏计——这是本题最高频的 WA 点；
3. **先查后插**：处理 $P_j$ 时先累加 $\text{cnt}[P_j]$ 再自增，保证只与**更早**的前缀配对（$l < j$），区间非空且不重复计数；若先插后查会错把 $P_j$ 与自己配成空区间；
4. **答案必须 64 位**：全 $0$ 数组时**所有** $\binom{n+1}{2} \approx 5 \times 10^9$ 个子数组都美丽，超 32 位 `int` 上限约 2.3 倍，C++ 的 `ans` 必须 `long long`；
5. **值域有界，可开桶**：$0 \le \text{nums}[i] \le 10^6 < 2^{20}$，前缀异或值域不膨胀、恒 $< 2^{20}$，C++ 可用 `int cnt[1 << 20]`（4 MiB）替代哈希表，免去哈希开销；
6. **滚动变量即可**：$s$ 一个标量滚动维护，无需显式前缀数组。

## 5. 正确性证明

以下将「子数组中第 $k$ 位为 $1$ 的元素个数」记为 $c_k$，多位统称按位计数。二进制下标从 $0$ 开始。

**引理 1（无借位消位）**：若整数 $x$ 的第 $k$ 位为 $1$，则 $x - 2^k$ 与 $x$ 仅第 $k$ 位不同（$1 \to 0$）。

**证明**：写 $x = y + 2^k$，其中 $y$ 的第 $k$ 位为 $0$ 且各位分解中不含 $2^k$ 项，则 $x - 2^k = y$，故除第 $k$ 位由 $1$ 变 $0$ 外其余位全同。∎

**引理 2（奇偶不变量）**：子数组上执行任意合法操作序列，$c_k \bmod 2$ 对每个 $k$ 都不变。

**证明**：一次操作选取第 $k$ 位均为 $1$ 的两个元素各减 $2^k$。由引理 1，两个元素均仅第 $k$ 位 $1 \to 0$，其余位不变，故 $c_k$ 恰减 $2$，$c_j$（$j \ne k$）不变。全体 $c_k$ 的奇偶性逐操作保持。∎

**引理 3（美丽三判据等价）**：子数组美丽 $\iff$ 每个 $c_k$ 为偶数 $\iff$ 子数组异或和为 $0$。

**证明**：
（$\Leftarrow$ 构造）设每个 $c_k$ 为偶。对每个位 $k$，将第 $k$ 位为 $1$ 的元素下标任意两两配对，每对执行一次 $k$ 位操作。各位互不干扰（引理 1：一次操作只触碰一个位），执行完毕后每位 $1$ 全部消去，得全 $0$。
（$\Rightarrow$ 不变量）终态全 $0$ 时 $c_k = 0$ 为偶；由引理 2，初始 $c_k$ 与终态同奇偶，故初始每个 $c_k$ 为偶。
（后一等价）异或是按位模 $2$ 加法：$n$ 个数的异或和的第 $k$ 位 $= c_k \bmod 2$。故异或和为 $0 \iff$ 每位 $c_k \bmod 2 = 0 \iff$ 每个 $c_k$ 为偶。∎

**定理（前缀配对计数）**：设前缀异或 $P_0 = 0$，$P_j = \text{nums}[0] \wedge \dots \wedge \text{nums}[j-1]$。美丽子数组数为
$$
\bigl|\{\, (l, r) : 0 \le l \le r < n,\ P_l = P_{r+1} \,\}\bigr| \;=\; \sum_{v} \binom{\text{cnt}(v)}{2},
$$
其中 $\text{cnt}(v)$ 是 $P_0, \dots, P_n$ 中值 $v$ 的出现次数。算法的一趟扫描（先查后插）恰好算出它。

**证明**：子数组 $\text{nums}[l..r]$ 的异或和 $= P_l \wedge P_{r+1}$（公共部分 $\text{nums}[0..l-1]$ 异或两次自消），由 $a \wedge b = 0 \iff a = b$，它为 $0$ 当且仅当 $P_l = P_{r+1}$；结合引理 3，美丽子数组与二元组 $(l, r+1)$（$l < r+1$，即 $l \le r$）中前缀相等者一一对应。按值分组，组内任取两下标即一组配对，得组合数求和公式。扫描至第 $j$ 步时哈希表恰含 $P_0, \dots, P_{j-1}$，先查 $\text{cnt}[P_j]$ 把满足 $l < j$ 且 $P_l = P_j$ 的每个 $l$ 恰计一次，后插更新；遍历完毕每对相等前缀恰被计一次，不重不漏。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$——一趟扫描，每步一次异或、一次哈希查询、一次哈希插入，均摊 $O(1)$；$n = 10^5$ 时约 $3 \times 10^5$ 次表操作，远低于时限。C++ 桶数组版连哈希开销都省去，只剩 $n$ 次数组访问；
- **空间复杂度**：$O(\min(n, 2^{20}))$——哈希表至多存 $\min(n+1, 2^{20})$ 个键（前缀异或值域 $[0, 2^{20})$，$n+1$ 个前缀中互异值不超过两者取小）；桶数组版固定 $2^{20}$ 个 `int` 即 4 MiB。另有滚动变量 $O(1)$。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    long long beautifulSubarrays(vector<int>& nums) {
        unordered_map<int, int> cnt;
        cnt[0] = 1;                 // 预置空前缀 P0 = 0
        long long ans = 0;          // 全 0 数组时答案 ~5e9，必须 64 位
        int s = 0;                  // 滚动前缀异或
        for (int x : nums) {
            s ^= x;
            ans += cnt[s];          // 先查：与每个更早的相同前缀配成美丽子数组
            ++cnt[s];               // 后插：避免和自身配成空区间
        }
        return ans;
    }
};
```

> 💡 **提速版**：值域 $< 2^{20}$，可换 `static int cnt[1 << 20]; memset(cnt, 0, sizeof cnt);` 的桶数组，循环体只剩 `ans += cnt[s ^= x]++;`，实测约为哈希版速度的数倍（4 MiB 内存放得下，无需担心内存限制）。

### Python

```python
from collections import defaultdict

class Solution:
    def beautifulSubarrays(self, nums: List[int]) -> int:
        cnt = defaultdict(int)
        cnt[0] = 1                  # 空前缀 P0 = 0
        s = 0
        ans = 0
        for x in nums:
            s ^= x
            ans += cnt[s]           # 先查
            cnt[s] += 1             # 后插
        return ans
```

> 💡 两种语言逻辑逐行等价。Python 整数任意精度无溢出之虞；C++ 的 `long long` 是本题唯一的"隐性"提交门槛（与 Q2 的前缀和溢出如出一辙，罚时点同源）。

## 8. 边界情况与易错点

1. **答案溢出（头号罚时点）**：$n = 10^5$、全 $0$ 数组时所有 $\frac{n(n+1)}{2} \approx 5 \times 10^9$ 个子数组都美丽，超 32 位 `int` 约 2.3 倍。C++ 的 `ans` 必须 `long long`（哈希表的计数本身 $\le n+1$ 用 `int` 即可）；
2. **忘预置 $\text{cnt}[0] = 1$**：所有从下标 $0$ 开始的美丽子数组被整体漏计。自造最小复现：`[4,3,1,2,4]` 答案错成 1（丢整段）；`[0]` 答案错成 0（丢唯一子数组）；
3. **先插后查**：会把 $P_j$ 与自己配成空区间，`[1]` 也会错输出 1。正确顺序是**查完再加**；
4. **单元素子数组**：$[x]$ 美丽 $\iff x = 0$（一位上恰一个 $1$，奇）。可作最小样例手验：`[0]→1`、`[5]→0`；
5. **「操作只能在子数组内部」**：题面限定 $i, j$ 取自子数组内。但按位计数 $c_k$ 只统计子数组自身元素，前缀差 $P_l \wedge P_{r+1}$ 也恰好只圈出区间内的数——判定天然局部，无需关心下标越界；
6. **别把异或想成加法**：判据是「前缀**相等**」而非「前缀差为定值」——异或的逆元是自身，$P_l \wedge P_{r+1} = 0 \iff P_l = P_{r+1}$，不要类比前缀和写出 $\text{cnt}[s - 0]$ 之类的幻觉代码；
7. **与 LC 560 迁移时的差异**：前缀**和**会累加膨胀（需 `long long` 前缀），前缀**异或**值域恒 $< 2^{20}$ 不膨胀（前缀可用 `int`）——但**答案计数**反而会溢出，两题的溢出点位置不同；
8. **零元素不是干扰项**：$0$ 与任何值异或不改变 $s$，全 $0$ 段会让前缀值反复回摆、大量配对（示例 3 的 $[0,0]$ 有 3 对），属于正常计数而非重复计数。
