# LeetCode 将单词恢复初始状态所需的最短时间 II 题解

## 1. 题目概述

- **标题 / 题号**：将单词恢复初始状态所需的最短时间 II（#3031，hard）
- **链接**：https://leetcode.cn/problems/minimum-time-to-revert-word-to-initial-state-ii/
- **来源**：LeetCode 第 383 场周赛 Q4
- **难度**：困难
- **标签**：字符串、字符串匹配、哈希函数、滚动哈希

**题意**：给定下标从 0 开始、长度为 $n$ 的字符串 `word` 与整数 $k$。每一秒必须**同时**执行两种操作：① 移除 `word` 的前 $k$ 个字符；② 在末尾添加 $k$ 个**任意**字符（不必与被移除的相同）。返回 `word` 恢复到初始状态所需的最短时间（必须大于零）。

**约束**：

- $1 \le n = \text{word.length} \le 10^6$
- $1 \le k \le n$
- `word` 仅由小写英文字母组成

> ⚠️ 本题与同场 Q2（#3029）题面**完全相同**，唯一区别是 $n$ 从 $50$ 放大到 $10^6$：Q2 的「逐 $t$ 线性判定」总量 $O(n^2/k)$ 在 $k$ 较小时退化为 $O(n^2)$，必须把单个候选的判定从 $O(n)$ 压到 $O(1)$，难度由中等跳到困难。

## 2. 示例

**示例 1**

```text
输入：word = "abacaba", k = 3
输出：2
解释：第 1 秒删前缀 "aba"、补 "bac" → "cababac"；
      第 2 秒删 "cab"、补 "aba" → "abacaba"，恢复初态。
```

**示例 2**

```text
输入：word = "abacaba", k = 4
输出：1
解释：第 1 秒删 "abac"、补 "caba" → "abacaba"，1 秒即还原。
```

**示例 3**

```text
输入：word = "abcbabcd", k = 2
输出：4
解释：t=1,2,3 的存活后缀 "cbabcd" / "abcd" / "cd" 都不是前缀；
      第 4 秒 t·k = 8 ≥ n，原字符删光，整串照抄重建。
```

**补充示例（可行性关于 $t$ 不单调）**

```text

输出：2
解释：z = [7,0,0,0,3,0,0]：i=4 → z[4]=3=n−i ✓ → t=2 可行；
      但 i=6 → z[6]=0 < 1 ✗，t=3 反而不可行，t=4（删光）才再次可行。
      可行秒数集合为 {2, 4}——不能对 t 二分！
```

## 3. 解题思路

### 3.1 暴力思路（即 Q2 做法）及其瓶颈

Q2 已完整论证（见同场 Q2 题解 §5，本文 §5 亦复述）：$t$ 秒后的串 $=$ 确定的**存活后缀** `word[t·k:]` ＋ 完全可控的**自由填充区**，于是

$$t \text{ 秒可还原} \iff t\cdot k \ge n \ \ \text{或}\ \ \text{word}[t\cdot k:] = \text{word}[:n - t\cdot k]$$

Q2 的做法：$t$ 从 1 升序枚举到 $\lceil n/k \rceil$，每个 $t$ 花 $O(n)$ 逐字符比较存活后缀与等长前缀，总量

$$\sum_{t \ge 1} (n - t\cdot k) \le \frac{n^2}{2k}$$

$n = 10^6$、$k = 1$ 时约 $5 \times 10^{11}$ 次字符比较，必然超时。**瓶颈不在枚举**（候选至多 $\lceil n/k \rceil \le n$ 个）**而在每个候选的判定**——把单次判定降到 $O(1)$，就是本题的全部工作。

### 3.2 核心观察：判定 ＝ 查一次 Z 数组

「后缀 `word[i:]` 整段是前缀」这类**后缀对前缀**的匹配信息，正是 **Z 函数**（扩展 KMP）的定义域：

$$z[i] \;=\; \mathrm{LCP}\big(\text{word},\ \text{word}[i:]\big)$$

后缀 `word[i:]` 长 $n - i$，它整段成为前缀 $\iff$ LCP 覆盖整个后缀 $\iff z[i] \ge n - i$；又因 $z[i] \le n - i$ 恒成立，判据即 $z[i] = n - i$。

![核心判据：z[i] ≥ n − i 的命中与差一位失配](images/revert_word_ii_zfunction.svg)

于是算法只剩两步：**一遍 $O(n)$ 预处理 Z 数组**；**$t$ 从 1 起、$i = t\cdot k$ 步进 $k$ 逐格点查询**，$i \ge n$（删光）或 $z[i] \ge n - i$（后缀即前缀）任一命中即返回 $t$。判定部分从 $O(n^2/k)$ 降到 $O(n/k)$，总体 $O(n)$。

> 💡 判据换装：Q2 的 `word.startswith(word[t*k:])` ⟶ 本题的 `z[t*k] == n - t*k`。枚举框架一行不改，只把「逐字比较」换成「查表」——这是字符串题最典型的「判定提速」范式（同类：KMP 之于暴力匹配）。

### 3.3 算法流程

![算法流程：Z 数组预处理 + 逐格点 O(1) 判定](images/revert_word_ii_algorithm_flow.svg)

1. 计算 Z 数组 $z[0..n-1]$（Z-box 均摊，$O(n)$，实现见 §4.1）；
2. $t \leftarrow 1$，$i \leftarrow k$；
3. 若 $i \ge n$：返回 $t$（原字符删光，整串自由重建）；
4. 若 $z[i] \ge n - i$：返回 $t$（存活后缀即前缀，尾部照抄）；
5. 否则 $t \leftarrow t + 1$，$i \leftarrow i + k$，回到第 3 步。$t = \lceil n/k \rceil$ 必走第 3 步分支，循环必然终止。

### 3.4 示例演算

![示例演算：abcbabcd, k=2 的 Z 数组逐格点判定](images/revert_word_ii_walkthrough.svg)

以示例 3（`word = "abcbabcd"`，$k=2$，$n=8$，$z = [8,0,0,0,3,0,0,0]$）走一遍：

| $t$ | $i = t\cdot k$ | 后缀 `word[i:]` | 需等于 `word[:n−i]` | $z[i]$ | $n-i$ | 判定 |
|-----|-----|------------|--------------|--------|-------|------|
| 1 | 2 | `"cbabcd"` | `"abcbab"` | 0 | 6 | ✗ 首位 `c`≠`a` |
| 2 | 4 | `"abcd"` | `"abcb"` | 3 | 4 | ✗ 前 3 位同、第 4 位 `d`≠`b` |
| 3 | 6 | `"cd"` | `"ab"` | 0 | 2 | ✗ `c`≠`a` |
| 4 | 8 | （空） | — | — | 0 | ✓ $i \ge n$，删光重建 → **返回 4** |

示例 1 / 2（`abacaba`，$z = [7,0,1,0,3,0,1]$）：$k=4$ 时首个格点 $i=4$，$z[4] = 3 = n-i$ ✓ 返回 1；$k=3$ 时 $i=3$（$z=0$ ✗）、$i=6$（$z[6] = 1 = n-i$ ✓）返回 2。注意 $z[4]=3$ 这个「后缀即前缀」的位置在 $k=3$ 时**不是格点**——查询只发生在 $k$ 的倍数上。

## 4. 算法细节

### 4.1 Z 数组的线性实现（Z-box 复用）

逐个朴素比较最坏 $O(n^2)$（如 `"aaaa…a"`）。线性写法维护**最右 Z-box** $[l, r)$：所有已算出的 $z$ 中右端点最远者，$r = l + z[l]$，满足 $\text{word}[l:r] = \text{word}[0:r-l]$（整段等于前缀）。

计算 $z[i]$ 时若 $i < r$：由 box 内已知 $\text{word}[i:r] = \text{word}[i-l:r-l]$，可**免费复用**镜像个体的 $z[i-l]$（截断到 $r-i$，越出 box 后信息失效）；只有越过 $r$ 的部分才逐字符扩张，并把 $r$ 推向更右。

![Z-box 复用机制与均摊 O(n)](images/revert_word_ii_zbox.svg)

核心代码模式（与 §7 一致）：

```cpp
for (int i = 1, l = 0, r = 0; i < n; i++) {
    if (i < r) z[i] = min(r - i, z[i - l]);                     // box 内免费复用
    while (i + z[i] < n && word[z[i]] == word[i + z[i]]) z[i]++; // 越出 r 才扩张
    if (i + z[i] > r) { l = i; r = i + z[i]; }                   // r 单调右移
}
```

线性性证明见 §5 引理 4。

### 4.2 枚举上界与循环写法

1. **上界 $\lceil n/k \rceil$**：删光分支保证答案存在且不超过它，枚举区间 $t \in [1, \lceil n/k \rceil]$ 完备；C++ 写 `t * k < n + k`（即 $t \cdot k \le n + k - 1$）恰好覆盖。
2. **溢出无忧**：$t \cdot k \le n + k \le 2 \times 10^6$，`int` 足够。
3. **先判 $i \ge n$ 再查 $z[i]$**：$k \mid n$ 时最后一步恰有 $i = n$，而 `z` 数组下标只有 $0..n-1$，两个条件的短路顺序不能颠倒。
4. **$z[0]$ 的约定无关紧要**：取 $0$ 或 $n$ 皆可——$i = t\cdot k \ge k \ge 1$，永远不会查询 $z[0]$。

### 4.3 两条替代路线（同为 $O(n)$）

1. **滚动哈希**（题目标签之一）：预处理 $h[i] = (h[i-1]\cdot B + w_i) \bmod P$ 与幂表 $B^j$，任意子串哈希 $O(1)$，把判据换成 $\text{hash}(w[i:n]) = \text{hash}(w[0:n-i])$。代码更短，但 $n = 10^6$ 的判等密集场景下，单模数 / 自然溢出哈希存在被对抗数据**构造碰撞**卡掉的风险，比赛需双模数或大随机 $B, P$——这也是确定性的 Z 函数更受青睐的原因。
2. **KMP border 链**：判定 $\text{word}[i:] = \text{word}[:n-i]$ 等价于「长度 $L = n - i$ 的 **border**（相等前后缀）」。沿 $\pi[n-1] \to \pi[\pi[n-1]-1] \to \cdots$ 从最长 border **降序**枚举全部 border（链总步数 $O(n)$），首个满足 $k \mid (n - L)$ 的 $L$ 给出 $t = (n-L)/k$（$L$ 最大 ⟺ $t$ 最小）；无命中则返回 $\lceil n/k \rceil$。验证示例 1（$k=3$）：border 链 $L = 3 \to 1$，$L=3$ 时 $n-L=4$ 非 $k$ 的倍数 ✗，$L=1$ 时 $n-L=6=2k$ ✓ → $t=2$，与 Z 函数解一致。

> 💡 三条路线殊途同归：Z 函数「逐格点查表」、哈希「逐格点判等」、border 链「从最长 border 下行走」——本质都在一遍线性预处理后回答「哪些后缀是前缀」。

## 5. 正确性证明

**引理 1（形态引理）**：对满足 $t\cdot k \le n$ 的非负整数 $t$，$t$ 秒后的串恒为 $\text{word}[t\cdot k:] + X$，其中 $X$ 是长为 $t\cdot k$ 的串，每个字符可在被添加的那一秒任取。

**证明**：对 $t$ 归纳。$t = 0$：$\text{word} = \text{word}[0:] + \varepsilon$ ✓。设 $t$ 时成立且 $(t+1)k \le n$，则存活后缀长 $n - tk \ge k$，第 $t+1$ 秒删除的前 $k$ 个字符恰为原字符段 $\text{word}[tk:(t+1)k]$，剩 $\text{word}[(t+1)k:] + X$，再补 $k$ 个任取字符 $x$ 得 $\text{word}[(t+1)k:] + (X + x)$。∎

**引理 2（删光引理）**：若 $t\cdot k \ge n$，则 $t$ 秒后可还原；从而答案存在且 $\le \lceil n/k \rceil$。

**证明**：取 $s = \lceil n/k \rceil$。引理 1 适用于 $s-1$：此时存活原字符 $n - (s-1)k \le k$ 个。第 $s$ 秒删掉的 $k$ 个字符 ＝ 全部存活原字符 ＋ $X$ 的前 $s\cdot k - n$ 个，再补 $k$ 个任取字符后，整串 $n$ 位全部由我们任取，照抄 `word` 即还原；此后每秒删补的都是任取字符，全任意性保持。∎

**引理 3（判据引理）**：对 $t \ge 1$、$i = t\cdot k < n$：$t$ 秒后可还原 $\iff z[i] \ge n - i$。

**证明**：由引理 1，$t$ 秒后的串前 $n - i$ 位恒为 $\text{word}[i:]$（与填充策略无关）。（⇒）若某策略使串等于 `word`，则前 $n-i$ 位逐位相同，$\text{word}[i:] = \text{word}[:n-i]$，即后缀整段是前缀，LCP 覆盖全长后缀，$z[i] \ge n-i$。（⇐）取 $X = \text{word}[n-i:]$：串 $= \text{word}[i:] + \text{word}[n-i:] = \text{word}[:n-i] + \text{word}[n-i:] = \text{word}$。∎

**引理 4（Z 算法线性性）**：§4.1 的 Z 数组算法字符比较总次数 $\le 2n$。

**证明**：归纳可证不变式：任意时刻维护的 $[l, r)$ 满足 $\text{word}[l:r] = \text{word}[0:r-l]$。考察计算 $z[i]$ 的扩张阶段：若复用值 $z_{\text{init}} < r - i$，则镜像位置 $i - l + z_{\text{init}} < r - l$ 处当初正是失配才停下，box 内平移关系使 $\text{word}[i + z_{\text{init}}] \neq \text{word}[z_{\text{init}}]$，**首次比较必失败**，该 $i$ 仅付 1 次比较。若 $z_{\text{init}} \ge r - i$（或 $i \ge r$ 无 box 可复用），则扩张从下标 $\ge r$ 处开始，每次**成功**比较都使最终右端点 $i + z[i]$ 在旧 $r$ 之外又前进一格，结束时 $r$ 更新为 $i + z[i]$。$r$ 在全程单调不降且 $\le n$，故成功比较总数 $\le n$；失败比较每个 $i$ 至多 1 次，总数 $\le n$。合计 $\le 2n$。∎

**定理**：算法返回的正是使 `word` 可还原的最小正整数秒数。

**证明**：算法按 $t$ 升序逐一检验谓词「$t\cdot k \ge n$ 或 $z[t\cdot k] \ge n - t\cdot k$」。由引理 2、3，该谓词恰为「$t$ 秒可还原」的等价刻画（两分支分别覆盖 $t\cdot k \ge n$ 与 $t\cdot k < n$ 的全部情形），故算法在首个可行 $t$ 处返回，即最小值；由引理 2，$t = \lceil n/k \rceil$ 必可行，循环必然终止；枚举起点 $t = 1$，返回值 $> 0$，满足「时间大于零」。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。Z 数组预处理一遍线性（引理 4，至多 $2n$ 次比较）；枚举至多 $\lceil n/k \rceil \le n$ 个候选、每个 $O(1)$ 查询。$n = 10^6$ 时 C++ 毫秒级，Python 约 $10^6$ 次循环同样可通过。
- **空间复杂度**：$O(n)$。Z 数组（或哈希前缀数组 / $\pi$ 数组）不可避免。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minimumTimeToInitialState(string word, int k) {
        int n = word.size();
        vector<int> z(n);
        z[0] = n;                                           // 约定 z[0]=n，本题不会查询
        for (int i = 1, l = 0, r = 0; i < n; i++) {
            if (i < r) z[i] = min(r - i, z[i - l]);         // box 内免费复用镜像值
            while (i + z[i] < n && word[z[i]] == word[i + z[i]]) z[i]++;
            if (i + z[i] > r) { l = i; r = i + z[i]; }      // 维护最右 Z-box
        }
        for (int t = 1; t * k < n + k; t++) {               // t 上界 = ⌈n/k⌉
            int i = t * k;
            if (i >= n || z[i] == n - i) return t;          // 删光 或 后缀即前缀
        }
        return -1;                                          // 不可达，仅安抚编译器
    }
};
```

### Python

```python
class Solution:
    def minimumTimeToInitialState(self, word: str, k: int) -> int:
        n = len(word)
        z = [0] * n
        l = r = 0
        for i in range(1, n):
            if i < r:
                z[i] = min(r - i, z[i - l])             # box 内免费复用镜像值
            while i + z[i] < n and word[z[i]] == word[i + z[i]]:
                z[i] += 1
            if i + z[i] > r:
                l, r = i, i + z[i]
        t, i = 1, k
        while True:
            if i >= n or z[i] == n - i:                 # 删光 或 后缀即前缀
                return t
            t += 1
            i += k
```

> 💡 循环写法说明：`t * k < n + k` ⟺ $t \le \lceil n/k \rceil$，该上界处 $t\cdot k \ge n$ 必走「删光」分支，故 Python 版的 `while True` 不会死循环。

## 8. 边界情况与易错点

1. **先判 $i \ge n$、再查 $z[i]$**：$k \mid n$ 时最后一步恰有 $i = n$，先查 `z[i]` 即数组越界（C++ 未定义行为、RE）——两个条件的短路顺序不能颠倒。
2. **判据必须「整段覆盖」**：$z[i] \ge n - i$ 差一位也不行，如 `"abcbabcd"` 的 $z[4] = 3 < 4$；误把「部分匹配」当命中会得到偏小答案。因 $z[i] \le n - i$ 恒成立，写 `==` 与 `>=` 等价。
3. **可行性对 $t$ 不单调，禁止二分**：`"abcdabc"`、$k=2$ 的可行集是 $\{2, 4\}$——$t=2$ 可行而 $t=3$ 不可行，谓词不单调，只能升序枚举到首个命中。
4. **滚动哈希的碰撞风险**：$n = 10^6$ 且判等多达 $\lceil n/k \rceil$ 次，单模数（尤其自然溢出）可被对抗数据构造碰撞卡掉；比赛场景用双模数或大随机基/模，或干脆用确定性的 Z 函数。
5. **$z[0]$ 的约定**：取 $0$ 或 $n$ 均不影响结果（$i \ge 1$ 永不查询），但与队友 / 题解对表时先统一约定，避免调试混乱。
6. **$k = n$ 秒删光**：答案恒为 1；$k = 1$ 最坏答案为 $n$（如 `word` 无任何可用周期，只能删光兜底），枚举 $n$ 轮仍 $O(n)$。
7. **答案必须大于零**：哪怕 1 秒即还原（`word` 有长为 $k$ 的周期，如 `"aaaa"`、$k=1$）也不能返回 0，枚举从 $t = 1$ 起天然满足。
8. **别去模拟「每秒填什么」**：「任意字符」是判定条件里的自由度，不是要搜索的空间——结构引理已把填充问题归结为前后缀判等。

- 变体：若每秒必须**原样补回**刚删掉的 $k$ 个字符（操作退化为循环左移 $k$ 位），则还原 $\iff t\cdot k \equiv 0 \pmod{n}$，答案为 $n / \gcd(n, k)$——示例 3 的题面解释用的正是这种朴素策略，耗时 4 恰为该情形在该样例下的取值。
