# LeetCode 找出网格的区域平均强度 题解

## 1. 题目概述

- **标题 / 题号**：找出网格的区域平均强度（#3030，medium）
- **链接**：https://leetcode.cn/problems/find-the-grid-of-region-average/
- **来源**：LeetCode 第 383 场周赛 Q3
- **难度**：中等
- **标签**：数组、矩阵、前缀和

**题意**：给定 $m \times n$ 灰度图 `image`（像素值 $[0,255]$）与非负整数 `threshold`。**相邻像素**指曼哈顿距离恰为 1（上下左右）的两像素。一个 $3\times 3$ 子网格是**区域**，当且仅当其内部任意相邻像素的强度差绝对值 $\le$ `threshold`；一个像素可同时属于多个区域。求结果网格 `result`：`result[i][j]` 等于覆盖 $(i,j)$ 的所有区域的「区域平均强度 $\lfloor S/9 \rfloor$」的**平均值再向下取整**；不属于任何区域时等于 `image[i][j]`。

**约束**：

- $3 \le m, n \le 500$
- $0 \le \text{image}[i][j] \le 255$
- $0 \le \text{threshold} \le 255$

> ⚠️ 读题三关键：① 相邻**不含对角**——$|a-c|+|b-d| = 1$ 恰好排除对角线；② 取整是**两层**的——每个区域先 $\lfloor S/9 \rfloor$，跨区域再对**取整后的值**求平均并再取整；③ 不属于任何区域的像素**原样保留**。

## 2. 示例

**示例 1**

```text
输入：image = [[5,6,7,10],[8,9,10,10],[11,12,13,10]], threshold = 3
输出：[[9,9,9,9],[9,9,9,9],[9,9,9,9]]
解释：两个区域均合法。区域① S = 81 → 平均 9；区域② S = 87 → 平均 9.67，
      先向下取整为 9 再参与平均：(9 + 9) / 2 = 9。每个像素至少属于一个区域，
      故 result 全为 9。
```

**示例 2**

```text
输入：image = [[10,20,30],[15,25,35],[20,30,40],[25,35,45]], threshold = 12
输出：[[25,25,25],[27,27,27],[27,27,27],[30,30,30]]
解释：区域①（行 0–2）平均 25，区域②（行 1–3）平均 30。
      行 0 仅属① → 25；行 1、2 属①+② → ⌊(25+30)/2⌋ = ⌊27.5⌋ = 27；
      行 3 仅属② → 30。
```

**示例 3**

```text
输入：image = [[5,6,7],[8,9,10],[11,12,13]], threshold = 1
输出：[[5,6,7],[8,9,10],[11,12,13]]
解释：纵向差均为 3 > 1，全图无合法区域，result 原样返回 image。
```

## 3. 解题思路

### 3.1 暴力思路：按定义逐块模拟

枚举全部 $(m-2)(n-2)$ 个 $3\times 3$ 左上角 $(r,c)$：块内逐一检查 12 对相邻差（6 横 + 6 纵）是否都 $\le$ `threshold`；合法则累加块和 $S$，令 $\text{avg} = \lfloor S/9 \rfloor$，给块内 9 个像素的累加器 `tot` 加 avg、计数器 `cnt` 加 1。全部块处理完后，`cnt > 0` 的像素取 $\lfloor \text{tot}/\text{cnt} \rfloor$，否则保留原值。

每块约 12 次判定 + 9 次求和 + 9 次累加 ≈ 30 次基本操作，总量约 $30 \times 248004 \approx 7.5\times 10^6$——C++ 直接通过（这也是官方预期解）。但纯 Python 逐块裸跑 12 对检查加嵌套求和，最坏要上千万次解释器操作，有超时风险；更重要的是，把「判定」与「求和」都压到 $O(1)$ 只需两个经典前缀和套路，值得顺手沉淀。

### 3.2 核心观察：邻接判定局部化 + 二维前缀和 O(1) 查询

![核心概念：12 对邻接判定与二维前缀和 O(1) 查询](images/region_avg_concept.svg)

三个观察把每块成本降到 $O(1)$：

1. **判定局部化**：块合法 $\iff$ 块内 12 对相邻差全部合格。把「坏对」做成 0/1 矩阵——`HB[i][j]` 标记水平对 $(i,j)$–$(i,j{+}1)$ 超阈值、`VB[i][j]` 标记垂直对——则块 $(r,c)$ 涉及的坏对恰好落在 `HB` 的子矩形 $[r, r{+}3) \times [c, c{+}2)$ 与 `VB` 的子矩形 $[r, r{+}2) \times [c, c{+}3)$ 里；
2. **非负矩形和为 0 $\iff$ 全零**：对 `HB`、`VB` 建二维前缀和 `PH`、`PV`，两个矩形和均为 0 $\iff$ 块合法——判定 $O(1)$；
3. **块和同样前缀化**：对 `image` 建前缀和 `PS`，$S(r,c)$ 四角查询 $O(1)$，$\text{avg} = \lfloor S/9 \rfloor$。

> 💡 本题与 [2132. 用邮票贴满网格](https://leetcode.cn/problems/stamping-the-grid/) 完全同构：那里是「判断 $3\times 3$ 邮票能否贴上（前缀和）+ 二维差分标记覆盖」，这里是「判断 $3\times 3$ 区域是否合法（前缀和）+ 矩形累加平均」——**二维前缀和判合法性 + 矩形更新** 的组合拳，值得作为模板沉淀。

### 3.3 算法流程

![算法流程图](images/region_avg_flow.svg)

1. 预处理 `PH`、`PV`、`PS` 三个 $(m{+}1)\times(n{+}1)$ 二维前缀和（`HB`/`VB` 边界补零，统一形状）；
2. 双重循环枚举块左上角 $(r, c)$，$r \in [0, m-3]$，$c \in [0, n-3]$：
   - 横向坏对和 $= \text{PH}[r{+}3][c{+}2] - \text{PH}[r][c{+}2] - \text{PH}[r{+}3][c] + \text{PH}[r][c]$，非 0 → 跳过；
   - 纵向坏对和 $= \text{PV}[r{+}2][c{+}3] - \text{PV}[r][c{+}3] - \text{PV}[r{+}2][c] + \text{PV}[r][c]$，非 0 → 跳过；
   - $S = \text{PS}$ 四角查询，$\text{avg} = S \div 9$（非负整数除法即向下取整），块内 9 像素 `tot += avg`、`cnt += 1`；
3. 收尾：`cnt[i][j] > 0` → $\lfloor \text{tot}/\text{cnt} \rfloor$，否则 `result[i][j] = image[i][j]`。

### 3.4 示例演算

![示例演算：示例 2 的两个区域与逐行取值](images/region_avg_walkthrough.svg)

以示例 2（$4\times 3$，threshold = 12）走一遍，块位置仅 $(0,0)$ 与 $(1,0)$ 两处：

| 块 | 覆盖范围 | 坏对数 | 块和 $S$ | avg $=\lfloor S/9\rfloor$ |
|----|---------|--------|---------|--------------------------|
| $(0,0)$ | 行 0–2 | 0（横向差全 10、纵向差全 5，均 ≤ 12） | 225 | 25 |
| $(1,0)$ | 行 1–3 | 0 | 270 | 30 |

- 行 0：仅被块 $(0,0)$ 覆盖，cnt = 1 → 25；
- 行 1、2：被两块同时覆盖，cnt = 2 → $\lfloor (25+30)/2 \rfloor = \lfloor 27.5 \rfloor = 27$；
- 行 3：仅被块 $(1,0)$ 覆盖，cnt = 1 → 30。

示例 1（$3\times 4$，threshold = 3）则展示**两层取整**：块 $(0,1)$ 的 $S = 87$，平均 $9.67$ **先取整为 9**，再与块 $(0,0)$ 的 9 求平均，`result` 全为 9——若误让 $9.67$ 直接参与平均，本例结果恰好不变，但语义已经错了（反例见 §8 第 1 条）。

## 4. 算法细节

1. **坏邻接矩阵补零**：`HB` 取 $m \times n$（$j = n-1$ 处恒 0），`VB` 取 $m \times n$（$i = m-1$ 处恒 0）——补零让 `PH`/`PV`/`PS` 统一为 $(m{+}1)\times(n{+}1)$，查询下标天然不越界，省去两套尺寸的心智负担。
2. **查询区间推导**：块覆盖行 $[r, r+2]$、列 $[c, c+2]$，但**内部水平间隙只有列 $c, c{+}1$ 两条** → `HB` 列区间 $[c, c{+}2)$；内部垂直间隙只有行 $r, r{+}1$ 两条 → `VB` 行区间 $[r, r{+}2)$。$3\times 3$ 块的分割线各只有 2 条（比格子数少 1），两套查询区间不同，是最容易写错的地方。
3. **两层取整的分离实现**：`tot` 累加的是 $\lfloor S/9 \rfloor$（第一层），`cnt` 计区域数，最后 $\lfloor \text{tot}/\text{cnt} \rfloor$（第二层）——顺序与题意严格对齐，绝不合并成 $\lfloor \sum S / (9\cdot\text{cnt}) \rfloor$。
4. **Python 加速**：行前缀用 `itertools.accumulate`（C 实现）；块循环里把 `PH[r+3]` 等整行引用缓存为局部变量，避免内层重复二维索引；累加循环用 `for i in (r, r+1, r+2)` 显式展开。实测 $500\times 500$ 全合法最坏情形约 0.6 s。
5. **数值范围**：$S \le 9 \times 255 = 2295$；单个像素至多被 9 个块覆盖（左上角 $r \in \{i{-}2, i{-}1, i\}$、$c \in \{j{-}2, j{-}1, j\}$ 各至多 3 种取值），故 cnt $\le 9$、tot $\le 9 \times 255 = 2295$——`int` 绰绰有余，无溢出风险。

## 5. 正确性证明

**引理 1（邻接对计数）**：覆盖行 $r..r{+}2$、列 $c..c{+}2$ 的 $3\times 3$ 子网格内部，曼哈顿距离为 1 的像素对恰有 12 对：6 横 + 6 纵。

**证明**：横相邻对 $(i,j)$–$(i, j{+}1)$ 要求 $i \in \{r, r{+}1, r{+}2\}$、$j \in \{c, c{+}1\}$，共 $3 \times 2 = 6$ 对；纵相邻对 $(i,j)$–$(i{+}1, j)$ 要求 $i \in \{r, r{+}1\}$、$j \in \{c, c{+}1, c{+}2\}$，共 $2 \times 3 = 6$ 对；块内其余像素对的曼哈顿距离均 $\ge 2$（块内距离为 1 的对必为横或纵），故共 12 对。∎

**引理 2（前缀和判定等价）**：块 $G(r,c)$ 是合法区域 $\iff$ `HB` 子矩形 $[r, r{+}3) \times [c, c{+}2)$ 与 `VB` 子矩形 $[r, r{+}2) \times [c, c{+}3)$ 的元素之和均为 0。

**证明**：`HB[i][j] = 1` $\iff$ 水平对 $(i,j)$–$(i, j{+}1)$ 超阈值。由引理 1，$G$ 内 6 个水平对与 `HB` 子矩形 $[r, r{+}3) \times [c, c{+}2)$ 的 6 个格子一一对应，`VB` 与 6 个垂直对同理。于是 $G$ 是区域 $\iff$ 这 12 个格子的值全为 0。前缀和四角运算取出的正是子矩形内 0/1 值之和，而非负整数之和为 0 当且仅当每项为 0。∎

**定理**：算法返回的 `result` 与题目定义一致。

**证明**：枚举遍历全部 $(m-2)(n-2)$ 个块位置，故对任意像素 $(i,j)$，循环结束后 `cnt[i][j]` = 覆盖 $(i,j)$ 的合法区域数（合法性由引理 2 等价刻画），`tot[i][j]` = 这些区域的 $\lfloor S/9 \rfloor$ 之和——对块的处理顺序归纳：每个合法块恰好给其 9 个像素各加一次 avg 与 1。若 cnt $= 0$，算法返回 `image[i][j]`，符合定义；若 cnt $= k > 0$，所有量非负，整数除法即向下取整，故 $\lfloor \text{tot}/k \rfloor = \big\lfloor \tfrac{1}{k} \sum_{G \ni (i,j)} \lfloor S_G / 9 \rfloor \big\rfloor$，恰为「取整后平均值的向下取整」。∎

## 6. 复杂度分析

- **时间复杂度**：$O(mn)$。预处理 3 个二维前缀和各 $O(mn)$；枚举 $(m-2)(n-2)$ 个块，每块 $O(1)$ 判定 + $O(1)$ 求和；累加共 $9(m-2)(n-2) = O(mn)$；收尾 $O(mn)$。$m = n = 500$ 时约 $2.5 \times 10^5$ 个块，C++ 实测约 5 ms，Python 约 0.6 s。
- **空间复杂度**：$O(mn)$。`PH`/`PV`/`PS` 共 $3(m{+}1)(n{+}1)$ 个整数，另加 `tot`/`cnt`/`result` 各 $mn$；若在原数组上就地重建前缀和可再压缩，本题无此必要。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<vector<int>> resultGrid(vector<vector<int>>& image, int threshold) {
        int m = image.size(), n = image[0].size();
        // PH / PV / PS：坏水平对 / 坏垂直对 / 强度 的 (m+1)×(n+1) 二维前缀和
        vector<vector<int>> PH(m + 1, vector<int>(n + 1)),
                            PV(m + 1, vector<int>(n + 1)),
                            PS(m + 1, vector<int>(n + 1));
        for (int i = 0; i < m; i++)
            for (int j = 0; j < n; j++) {
                int hb = j + 1 < n && abs(image[i][j + 1] - image[i][j]) > threshold;
                int vb = i + 1 < m && abs(image[i + 1][j] - image[i][j]) > threshold;
                PH[i + 1][j + 1] = PH[i][j + 1] + PH[i + 1][j] - PH[i][j] + hb;
                PV[i + 1][j + 1] = PV[i][j + 1] + PV[i + 1][j] - PV[i][j] + vb;
                PS[i + 1][j + 1] = PS[i][j + 1] + PS[i + 1][j] - PS[i][j] + image[i][j];
            }

        vector<vector<int>> tot(m, vector<int>(n)), cnt(m, vector<int>(n));
        for (int r = 0; r + 3 <= m; r++)
            for (int c = 0; c + 3 <= n; c++) {
                if (PH[r + 3][c + 2] - PH[r][c + 2] - PH[r + 3][c] + PH[r][c]) continue; // 横向坏对 > 0
                if (PV[r + 2][c + 3] - PV[r][c + 3] - PV[r + 2][c] + PV[r][c]) continue; // 纵向坏对 > 0
                int avg = (PS[r + 3][c + 3] - PS[r][c + 3] - PS[r + 3][c] + PS[r][c]) / 9;
                for (int i = r; i < r + 3; i++)
                    for (int j = c; j < c + 3; j++)
                        tot[i][j] += avg, cnt[i][j] += 1;
            }

        vector<vector<int>> res(m, vector<int>(n));
        for (int i = 0; i < m; i++)
            for (int j = 0; j < n; j++)
                res[i][j] = cnt[i][j] ? tot[i][j] / cnt[i][j] : image[i][j];
        return res;
    }
};
```

### Python

```python
from itertools import accumulate
from typing import List

class Solution:
    def resultGrid(self, image: List[List[int]], threshold: int) -> List[List[int]]:
        m, n = len(image), len(image[0])

        def prefix2d(rows):                          # m 行 n 列 → (m+1)×(n+1) 前缀和
            P = [[0] * (n + 1)] + [list(accumulate(r, initial=0)) for r in rows]
            for i in range(1, m + 1):
                Pi, Pp = P[i], P[i - 1]
                for j in range(n + 1):
                    Pi[j] += Pp[j]
            return P

        PS = prefix2d(image)
        PH = prefix2d([[int(j + 1 < n and abs(image[i][j + 1] - image[i][j]) > threshold)
                        for j in range(n)] for i in range(m)])   # 水平坏对（末列补 0）
        PV = prefix2d([[int(i + 1 < m and abs(image[i + 1][j] - image[i][j]) > threshold)
                        for j in range(n)] for i in range(m)])   # 垂直坏对（末行补 0）

        tot = [[0] * n for _ in range(m)]
        cnt = [[0] * n for _ in range(m)]
        for r in range(m - 2):
            ph3, ph0 = PH[r + 3], PH[r]              # 缓存行引用，避免内层重复索引
            pv2, pv0 = PV[r + 2], PV[r]
            ps3, ps0 = PS[r + 3], PS[r]
            for c in range(n - 2):
                if ph3[c + 2] - ph0[c + 2] - ph3[c] + ph0[c]:    # 横向坏对 > 0
                    continue
                if pv2[c + 3] - pv0[c + 3] - pv2[c] + pv0[c]:    # 纵向坏对 > 0
                    continue
                avg = (ps3[c + 3] - ps0[c + 3] - ps3[c] + ps0[c]) // 9
                for i in (r, r + 1, r + 2):
                    ti, ci = tot[i], cnt[i]
                    for j in (c, c + 1, c + 2):
                        ti[j] += avg
                        ci[j] += 1

        return [[image[i][j] if cnt[i][j] == 0 else tot[i][j] // cnt[i][j]
                 for j in range(n)] for i in range(m)]
```

## 8. 边界情况与易错点

1. **两层取整不可合并**：构造块和为 80 与 88 的两个合法区域覆盖同一像素——分开算 $\lfloor 80/9 \rfloor = 8$、$\lfloor 88/9 \rfloor = 9$，平均 $\lfloor (8+9)/2 \rfloor = 8$；合并算 $\lfloor 168/18 \rfloor = 9$。结果不同！`tot` 必须存**取整后**的值，示例 1 的 $9.67 \to 9$ 亦同。
2. **无区域覆盖要回落原值**：threshold = 0 且图像不均匀、或梯度普遍超阈值时（示例 3）全图无区域，`result = image`。用 `cnt` 判断，别把 `result` 初始化为 0 后忘了覆盖路径。
3. **对角不算相邻**：$|a-c|+|b-d| = 1$ 精确排除对角；块内判定只查 6 横 + 6 纵共 12 对，多查对角会误杀合法区域。
4. **块枚举范围**：左上角 $(r,c) \in [0, m-3] \times [0, n-3]$，即 `range(m-2)` × `range(n-2)`（左闭右开）；写成 `range(m-1)` 会越界，写成 `range(m-3)` 会漏块。
5. **前缀和四角下标**：块行区间 $[r, r+3)$、列区间 $[c, c+3)$；但 `HB` 只查列 $[c, c+2)$、`VB` 只查行 $[r, r+2)$——间隙比格子少 1，两套查询区间不同，务必分开推导。
6. **threshold = 0 合法**：要求相邻像素完全相等。均匀图（如全 255）+ 任意 threshold 时所有块都合法，是累加部分的最坏情形（$500\times500$ 全合法约 220 万次单点累加）。
7. **非负整数除法**：Python `//` 与 C++ `/` 对非负数都是向下取整，与题意一致；值域 $[0,255]$ 保证不出现负数，两种语言行为无分叉。
8. **cnt 上界是 9 不是 4**：一个像素可同时被左上角在 $\{i{-}2, i{-}1, i\} \times \{j{-}2, j{-}1, j\}$ 的至多 9 个块覆盖，中间像素 `cnt` 可达 9，数组按此上界估算即可。
