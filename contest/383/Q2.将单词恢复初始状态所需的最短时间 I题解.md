# LeetCode 将单词恢复初始状态所需的最短时间 I 题解

## 1. 题目概述

- **标题 / 题号**：将单词恢复初始状态所需的最短时间 I（#3029，medium）
- **链接**：https://leetcode.cn/problems/minimum-time-to-revert-word-to-initial-state-i/
- **来源**：LeetCode 第 383 场周赛 Q2
- **难度**：中等
- **标签**：字符串、字符串匹配、哈希函数、滚动哈希

**题意**：给定下标从 0 开始的字符串 `word`（长度 $n$）与整数 $k$。每一秒必须**同时**执行两种操作：① 移除 `word` 的前 $k$ 个字符；② 在末尾添加 $k$ 个**任意**字符（不必与被删字符相同）。返回 `word` 恢复到**初始状态**所需的最短时间，该时间必须**大于零**。

**约束**：

- $1 \le n = \text{word.length} \le 50$
- $1 \le k \le n$
- `word` 仅由小写英文字母组成

> ⚠️ 读题三关键：① 每秒**必须**删头补尾各 $k$ 个——串长恒为 $n$，不能只删不加；② 尾部补的是「**任意**」字符，填什么由我们掌控，这是求解的全部自由度；③ 答案必须 $> 0$，哪怕 1 秒就能还原也不能返回 0。

## 2. 示例

**示例 1**

```text
输入：word = "abacaba", k = 3
输出：2
解释：第 1 秒删前缀 "aba"、补 "bac" → "cababac"；
      第 2 秒删 "cab"、补 "aba" → "abacaba"，恢复初态。
```

**示例 2**

```text
输入：word = "abacaba", k = 4
输出：1
解释：第 1 秒删 "abac"、补 "caba" → "abacaba"，1 秒即还原。
```

**示例 3**

```text
输入：word = "abcbabcd", k = 2
输出：4
解释：前 3 秒存活后缀都不是前缀，无法还原；
      第 4 秒 t·k = 8 ≥ n，原字符删光，整串照抄重建。
```

**补充示例（可行性关于 $t$ 不单调）**

```text
输入：word = "abcdabc", k = 2
输出：2
解释：t=2 时存活后缀 word[4:] = "abc" 恰是前缀 word[:3] ✓；
      但 t=3 时 word[6:] = "c" ≠ 前缀 "a" ✗，t=4（删光）才再次可行。
      可行秒数集合为 {2, 4}——t=3 反而不可行，故不能对 t 二分！
```

## 3. 解题思路

### 3.1 暴力思路：先刻画「$t$ 秒后串长什么样」

「任意字符」让逐字模拟无从下手——真去枚举每秒填什么字符是指数级的死路。正确的切入点是先刻画 $t$ 秒后串的**形态**：每秒删的永远是当前串**最前** $k$ 个、加的永远在**最后**，于是**原字符永远顶在最前面，且相对顺序不变**。归纳可知，$t$ 秒共删掉原串的前 $t \cdot k$ 个字符、尾部累计补上 $t \cdot k$ 个任意字符（$t \cdot k \le n$ 时）：

$$\text{word}_t = \underbrace{\text{word}[t \cdot k:]}_{\text{存活后缀，} n - t\cdot k \text{ 个}} \;+\; \underbrace{\text{任意字符} \times t \cdot k}_{\text{我们说了算}}$$

于是「$t$ 秒能否还原」只需看**存活后缀 `word[t·k:]` 是否恰为 `word` 的前缀**——是则尾部 $t \cdot k$ 个任意位照抄 `word` 的尾部补齐即可；若 $t \cdot k \ge n$，原字符已全部删光，整串任意重建，必然可行。

$n \le 50$：$t$ 从 1 枚举到 $\lceil n/k \rceil \le 50$，每个 $t$ 花 $O(n)$ 判一次前后缀相等，$O(n^2/k)$ 稳过——这就是 Q2 的全部。

### 3.2 核心观察：判定条件 = 「存活后缀是前缀」

![核心概念：删头补尾后，存活后缀顶在最前](images/revert_word_suffix_concept.svg)

两个要点把问题化到最简：

1. **自由度全部集中在尾部**：$t$ 秒后的串 = 确定的存活后缀 + 完全可控的任意尾部。「能否还原」与「怎么填」无关，只取决于前 $n - t\cdot k$ 位——它们必须逐位等于 `word` 的前 $n - t\cdot k$ 位；
2. **判定即前后缀判等**：$\text{word}[t\cdot k:] = \text{word}[:n - t\cdot k]$，一次线性扫描即可，无需任何数据结构。

> 💡 把「秒数 $t$」翻译成「起点 $i = t \cdot k$」（只落在 $k$ 的倍数格点上），问题就变成「哪些格点开头的后缀能当前缀」——这个视角在同场 Q4（#3031，$n \le 10^6$）里换上 Z 函数 / KMP / 滚动哈希即可平推到 $O(n)$。

### 3.3 算法流程

![算法流程图](images/revert_word_flow.svg)

1. 读入 `word`、`k`，令 $n = \text{len(word)}$；
2. $t$ 从 1 升序枚举：
   - 若 $t \cdot k \ge n$：原字符已删光，返回 $t$；
   - 若 $\text{word}[t\cdot k:] = \text{word}[:n - t\cdot k]$：存活后缀是前缀，返回 $t$；
   - 否则 $t \gets t + 1$；
3. 上界 $t = \lceil n/k \rceil$ 时必有 $t \cdot k \ge n$，循环必然终止，答案必存在。

### 3.4 示例演算

![示例演算：三组样例逐秒判定](images/revert_word_walkthrough.svg)

以示例 1（`word = "abacaba"`，$k=3$，$n=7$）走一遍：

| $t$ | $i = t\cdot k$ | 存活后缀 `word[i:]` | 需等于的前缀 `word[:n−i]` | 判定 |
|-----|----------------|---------------------|--------------------------|------|
| 1 | 3 | `"caba"` | `"abac"` | ✗（首位 `c` ≠ `a`） |
| 2 | 6 | `"a"` | `"a"` | ✓ → 返回 2 |

- $t=1$：存活后缀 `"caba"` 的首字符 `c` 与 `word` 首字符 `a` 对不上，1 秒回不去；
- $t=2$：存活后缀只剩 `"a"`，恰是前缀，尾部 6 个任意位照抄 `"bacaba"` 即还原——答案 2。

示例 2（$k=4$）：$t=1 \to i=4$，`word[4:] = "aba" = word[:3]` ✓ 返回 1。示例 3（`"abcbabcd"`，$k=2$）：$t=1,2,3$ 的存活后缀 `"cbabcd"` / `"abcd"` / `"cd"` 都不是前缀，落到兜底分支返回 $\lceil 8/2 \rceil = 4$（删光重建）。

## 4. 算法细节

1. **形态不变量（归纳证明见 §5 引理 1）**：删除总发生在最前、追加总发生在最后 ⇒ 原字符的存活者永远占据串的前段且保持原顺序。这是「$t$ 秒后 = 存活后缀 + 任意填充」的根基，也是本题唯一需要的洞察。
2. **枚举上界 $\lceil n/k \rceil$**：$t = \lceil n/k \rceil$ 是首个满足 $t \cdot k \ge n$ 的时刻，删光必可行，因此枚举区间 $[1, \lceil n/k \rceil]$ 完备，答案必在其中命中。
3. **判定写法**：Python 一行 `word.startswith(word[t*k:])`；C++ 建议手写下标循环 `word[i] == word[i - t*k]`（$i \in [t\cdot k, n)$）——既避免 `substr` 在 $t\cdot k > n$ 时抛 `out_of_range` 异常，也省去 $O(n)$ 的临时串。
4. **提前剪枝**：逐位比较遇到首个不等位即退出；多数非法 $t$ 在首字符处就被否决，实际远快于最坏 $O(n)$。
5. **向 Q4 迁移**：同场 Q4（#3031）把 $n$ 放大到 $10^6$，$O(n^2/k)$ 不可接受。把判定换成 Z 函数（$z[t\cdot k] \ge n - t\cdot k$）、KMP border 链或滚动哈希，每个 $t$ 降为 $O(1)$，总体 $O(n)$，枚举框架完全复用。

## 5. 正确性证明

**引理 1（形态引理）**：对满足 $t \cdot k \le n$ 的非负整数 $t$，$t$ 秒后必有 $\text{word}_t = \text{word}[t\cdot k:] + X$，其中 $X$ 是长度为 $t \cdot k$ 的串，其每个字符可在相应秒末被任取（与策略无关地，前 $n - t\cdot k$ 位恒为存活原字符）。

**证明**：对 $t$ 归纳。$t=0$：$\text{word}_0 = \text{word} = \text{word}[0:] + \varepsilon$ ✓。设 $t$ 时结论成立且 $(t+1)k \le n$，则 $|\text{word}[t\cdot k:]| = n - t\cdot k \ge k$，第 $t+1$ 秒删除的前 $k$ 个字符恰为 $\text{word}[t\cdot k : (t+1)k]$，剩下 $\text{word}[(t+1)k:] + X$，再补上 $k$ 个任取字符得 $\text{word}_{t+1} = \text{word}[(t+1)k:] + (X + x)$，且 $X + x$ 为长度 $(t+1)k$ 的任意串。∎

**引理 2（删光必可行）**：若 $t \cdot k \ge n$，则 $t$ 秒后可还原（即答案 $\le \lceil n/k \rceil$，必存在）。

**证明**：设 $s = \lceil n/k \rceil$，则 $(s-1)k < n \le s\cdot k$，引理 1 适用于 $s-1$：$\text{word}_{s-1} = \text{word}[(s-1)k:] + X$，其中存活后缀长度 $n - (s-1)k \le k$。第 $s$ 秒删除的前 $k$ 个字符 = 全部存活原字符 $+ X$ 的前 $s\cdot k - n$ 个，剩下的是 $X$ 的后 $n-k$ 位，再补 $k$ 个任取字符——整串 $n$ 位全部由我们任取，照抄 `word` 即还原。对 $t > s$，每秒删补的都是任取字符，全任意性保持。∎

**引理 3（判定引理）**：对 $t \ge 1$ 且 $t \cdot k < n$：$t$ 秒后可还原 $\iff$ $\text{word}[t\cdot k:] = \text{word}[:n - t\cdot k]$。

**证明**：（⇐）取 $X = \text{word}[n - t\cdot k:]$，则 $\text{word}_t = \text{word}[t\cdot k:] + \text{word}[n-t\cdot k:] = \text{word}[:n-t\cdot k] + \text{word}[n-t\cdot k:] = \text{word}$。（⇒）无论采取何种填充策略，由引理 1，$\text{word}_t$ 的前 $n - t\cdot k$ 位恒为 $\text{word}[t\cdot k:]$；若某策略使 $\text{word}_t = \text{word}$，则比较前 $n - t\cdot k$ 位即得 $\text{word}[t\cdot k:] = \text{word}[:n-t\cdot k]$。∎

**定理**：算法返回的正是使 `word` 可还原的最小正整数秒数。

**证明**：算法按 $t = 1, 2, \ldots$ 升序逐一检验「$t \cdot k \ge n$ 或 $\text{word}[t\cdot k:] = \text{word}[:n-t\cdot k]$」。由引理 2、3，该谓词恰为「$t$ 秒后可还原」的等价刻画（两分支覆盖 $t\cdot k \ge n$ 与 $t\cdot k < n$ 的全部情形），故算法在首个可行 $t$ 处返回，即最小值；又由引理 2，$t = \lceil n/k \rceil$ 必可行，循环必然终止且返回值 $\ge 1$，满足「时间大于零」。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n^2/k)$。共至多 $\lceil n/k \rceil$ 个候选 $t$，第 $t$ 个判定至多比较 $n - t\cdot k$ 对字符，总计 $\sum_{t \ge 1} (n - t\cdot k) \le \frac{n^2}{2k}$；$n \le 50$ 时不超过约 $1250$ 次字符比较，轻松通过。换 Z 函数 / KMP / 哈希后为 $O(n)$（Q4 的要求）。
- **空间复杂度**：$O(1)$。C++ 下标比较只需常数变量；Python 切片写法产生 $O(n)$ 临时串，可忽略不计。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minimumTimeToInitialState(string word, int k) {
        int n = word.size();
        for (int t = 1; t * k < n; t++) {              // 只需检查 t*k < n 的 t
            bool ok = true;
            for (int i = t * k; i < n; i++)            // word[t*k:] vs word[:n-t*k]
                if (word[i] != word[i - t * k]) { ok = false; break; }
            if (ok) return t;                          // 存活后缀恰是前缀
        }
        return (n + k - 1) / k;                        // 删光重建的兜底 = ⌈n/k⌉
    }
};
```

### Python

```python
class Solution:
    def minimumTimeToInitialState(self, word: str, k: int) -> int:
        n = len(word)
        for t in range(1, n + 1):
            if t * k >= n or word.startswith(word[t * k:]):
                return t
```

> 💡 Python 极简版：`return next(t for t in range(1, n + 1) if word.startswith(word[t * k:]))`——当 $t \cdot k \ge n$ 时 `word[t*k:]` 是空串，而任何串都 `startswith("")`，删光分支被空串判定天然吸收，无需显式判断。

## 8. 边界情况与易错点

1. **答案必须大于 0**：哪怕 `word` 全同字符、1 秒即还原（如 `"aaaa"`、$k=1$），也绝不能返回 0；枚举从 $t=1$ 起即天然保证。
2. **$t \cdot k = n$ 属于「删光」**：存活后缀为空串，空串是任何串的前缀，与 $t\cdot k > n$ 统一处理；Python 的 `startswith("")` 恒真正是这一点的语言级体现。
3. **C++ `substr` 越界**：`word.substr(t * k)` 在 $t\cdot k > n$ 时抛 `std::out_of_range`，必须先判 `t * k >= n` 或改用下标循环。
4. **可行性关于 $t$ 不单调，不能二分**：`"abcdabc"`、$k=2$ 的可行集是 $\{2, 4\}$——$t=2$ 可行而 $t=3$ 不可行。谓词不单调，二分答案会得到错误结果，只能升序线性枚举到首个可行。
5. **极端参数**：$k = n$ 时第 1 秒即删光，答案恒为 1；$k = 1$ 时答案最坏为 $n$（如各位置都凑不出前缀，只能删光兜底）。
6. **别去模拟「填什么字符」**：「任意」是判定条件里的自由度，不是要枚举的搜索空间——把自由度用在「照抄尾部」的构造性证明上即可。
7. **别把「还原」误解为前缀对齐即可**：判定要求存活后缀与 `word` **等长前缀**逐位相等（$n - t\cdot k$ 位），不是「是某个前缀的子串」之类的宽松条件。
