# LeetCode 通过交换使数组相等的最小花费 题解

## 1. 题目概述

- **标题 / 题号**：通过交换使数组相等的最小花费（#3868，medium）
- **链接**：https://leetcode.cn/problems/minimum-cost-to-equalize-arrays-using-swaps/
- **来源**：LeetCode 第 178 场双周赛 Q3
- **难度**：中等
- **标签**：贪心、数组、哈希表、计数

**题意**：给定两个长度都为 $n$ 的数组 `nums1`、`nums2`，可以任意次执行两类操作：

1. **数组内部交换**：选同一数组里的两个下标 $i, j$，交换它们的值。此操作**免费**。
2. **跨数组交换**：选一个下标 $i$，交换 `nums1[i]` 与 `nums2[i]`。此操作**花费 1**。

求使两个数组**完全相同**（每个下标上的值都相等）的最小花费；若不可能，返回 $-1$。

**约束**：

- $2 \le n \le 8\times 10^4$
- $1 \le nums1[i], nums2[i] \le 8\times 10^4$

## 2. 示例

**示例 1**

```text
输入：nums1 = [10,20], nums2 = [20,10]
输出：0
解释：免费交换 nums2[0] 与 nums2[1]，nums2 变成 [10,20]，与 nums1 相同。花费 0。
```

**示例 2**

```text
输入：nums1 = [10,10], nums2 = [20,20]
输出：1
解释：付 1 次跨数组交换（比如下标 0），得到 nums1 = [20,10]、nums2 = [10,20]；
      再免费交换 nums2[0] 与 nums2[1] → nums2 = [20,10]。两数组相同，花费 1。
```

**示例 3**

```text
输入：nums1 = [10,20], nums2 = [30,40]
输出：-1
解释：值 30、40 只出现在 nums2，10、20 只出现在 nums1，无论怎么换都凑不出两个相同的数组。
```

## 3. 解题思路

### 3.1 暴力思路

搜索状态空间：每次尝试所有 $n$ 个下标做跨数组交换，用 BFS 找最少花费。状态数是指数级的（每个下标上的值都可能变化），$n = 8\times10^4$ 时完全不可行；即使 $n = 5$ 也只能用来对拍。

暴力之所以没用，是因为它没有利用**「数组内部交换免费」**这个关键条件——它让**位置**变得毫无意义：只要两个数组的**多重集**（每个值出现的次数）相同，我们总能用免费的内部交换把它们排成完全一样的顺序。

### 3.2 核心观察：位置无关，只看频次

![只与频次有关：同数组内交换免费，位置信息可以丢掉](images/bw178_q3_freq_diff.svg)

**第一步：判断可行性。** 最终两个数组相同，记最终每个值 $v$ 出现 $T[v]$ 次。因为交换不改变「两个数组合起来」的多重集，所以 $2T[v] = cnt1[v] + cnt2[v]$ 必须成立：

$$T[v] = \frac{cnt1[v] + cnt2[v]}{2}$$

**只要存在某个值的总数是奇数，就无解**，返回 $-1$；否则目标多重集 $T$ 唯一确定。

**第二步：数最少要换几次。** 定义差额

$$\text{diff} = \sum_v \big| cnt1[v] - cnt2[v] \big|$$

它衡量「两个多重集差了多少」。一次跨数组交换把 `nums1` 里的 $a$ 与 `nums2` 里的 $b$ 互换：

- 值 $a$：$cnt1$ 减 1、$cnt2$ 加 1 → 该项的 $|cnt1-cnt2|$ 减少 2；
- 值 $b$：$cnt1$ 加 1、$cnt2$ 减 1 → 该项也减少 2（只要方向选对）；
- 其它值不受影响。

所以**一次交换最多让 diff 减少 4**，于是最少花费 $\ge \text{diff} / 4$。

![一次跨数组交换如何让 diff 减少 4](images/bw178_q3_swap_fix.svg)

**第三步：这个下界能取到吗？** 能。把 $cnt1 > cnt2$ 的值称作「`nums1` 多出来的」（记集合 $A$），$cnt2 > cnt1$ 的值称作「`nums2` 多出来的」（记集合 $B$）。只要 $\text{diff} > 0$，由 $\sum_v (cnt1[v] - cnt2[v]) = 0$ 可知 $A, B$ 都非空。取 $a \in A$、$b \in B$，先在各自数组内部免费交换，把 $a$、$b$ 挪到**同一个下标** $i$ 上，再花 1 次跨数组交换——diff 就实打实减少 4。重复 $\text{diff}/4$ 次即可让 diff 归零，此时两个多重集相同。

由于每个 $|cnt1[v] - cnt2[v]|$ 都是偶数（$cnt1+cnt2$ 为偶数 ⟹ 两者同奇偶），并且 $\sum(cnt1-cnt2)=0$ 让正负相抵，可以证明 $\text{diff}$ 一定是 **4 的倍数**，所以 $\text{diff}/4$ 是整数，不需要向上取整。

### 3.3 算法流程

```text
1. cnt1, cnt2 = 两个数组的频次表
2. diff = 0
3. for v in (cnt1 的键 ∪ cnt2 的键):
4.     a = cnt1[v]（缺省 0），b = cnt2[v]（缺省 0）
5.     若 (a + b) 为奇数: 返回 -1          # 目标多重集不存在
6.     diff += |a - b|
7. 返回 diff / 4
```

### 3.4 示例演算

对示例 2 的 `nums1 = [10,10]`、`nums2 = [20,20]`：

| 值 $v$ | $cnt1[v]$ | $cnt2[v]$ | $a+b$ | $T[v]$ | $\lvert a-b \rvert$ |
|--------|-----------|-----------|-------|--------|---------------------|
| 10 | 2 | 0 | 2（偶 ✓） | 1 | 2 |
| 20 | 0 | 2 | 2（偶 ✓） | 1 | 2 |

$\text{diff} = 4$，答案 $= 4/4 = 1$ ✓。也就是说目标数组是 $[10,20]$ 的某种排列（每个值各一个），只需要 1 次跨数组交换。

对示例 1：两个数组的频次完全相同（10、20 各一个），每个值的 $|a-b| = 0$，$\text{diff} = 0$，答案 0 ✓——这正是「免费内部交换就够了」的情形。

对示例 3：值 30、40 的 $a+b = 1$ 为奇数，直接返回 $-1$ ✓。

## 4. 算法细节

1. **频次表**：值域 $\le 8\times10^4$，可用数组桶（更快）或哈希表（更通用）。本文代码用哈希表 + 键集合合并。
2. **缺省 0**：某个值只在一个数组里出现时，另一个数组的计数按 0 处理，不要漏掉这些键——它们恰恰是决定可行性的关键。
3. **奇偶判定与 diff 统计可以同一次循环完成**：只要在遍历时先判 $(a+b)$ 的奇偶，再累加 $|a-b|$。
4. **答案公式**：`diff / 4` 用整除即可，无需特判余数（可行时必为 4 的倍数）；若担心除不尽，可以先判 `diff % 4` 再返回，但按上面的证明它恒为 0。
5. **不真的模拟交换**：只算差额，$O(\text{不同值个数})$ 时间，避免任何与 $n$ 成正比的交换模拟。
6. **返回值范围**：`diff/4` 最大约 $n/2 = 4\times10^4$，`int` 足够。

## 5. 正确性证明

**引理 1（可行性判定）**：存在使两数组相同的操作序列，当且仅当对每个值 $v$，$cnt1[v] + cnt2[v]$ 都是偶数。

**证明**：

必要性：说明「两数组相同」时每个值在两个数组中各出现 $T[v]$ 次，故 $cnt1[v] + cnt2[v] = 2T[v]$ 是偶数。而交换操作（无论内部还是跨数组）都不改变「两个数组合起来」的多重集，因此 $cnt1[v] + cnt2[v]$ 在整个过程中不变。

充分性：若每个 $cnt1[v]+cnt2[v]$ 都是偶数，令 $T[v] = (cnt1[v]+cnt2[v])/2$，且 $\sum_v T[v] = \frac{1}{2}(\sum_v cnt1[v] + \sum_v cnt2[v]) = n$。于是 $T$ 是一个合法的「长度 $n$ 的多重集」。按算法做 $\text{diff}/4$ 次跨数组交换后（下面引理 3 证明其可行），$cnt1 = cnt2 = T$；再用免费的内部交换把两个数组都排成同一个顺序（例如按 $T$ 的升序），即得两数组逐位相同。∎

**引理 2（单次交换对 diff 的影响）**：一次跨数组交换使 $\text{diff}$ 的变化量属于 $\{-4, 0, +4\}$，且至多减少 4。

**证明**：交换的是 `nums1` 中的 $a$ 与 `nums2` 中的 $b$（允许 $a = b$）。只有值 $a$ 与 $b$ 的计数发生变化：

- $cnt1[a] \to cnt1[a]-1$，$cnt2[a] \to cnt2[a]+1$：$cnt1[a]-cnt2[a]$ 减少 2，故 $|cnt1[a]-cnt2[a]|$ 的变化量属于 $\{-2, +2\}$（绝对值函数在差值减 2 时的变化）。
- $cnt1[b] \to cnt1[b]+1$，$cnt2[b] \to cnt2[b]-1$：差值增加 2，$|{\cdot}|$ 的变化量同样属于 $\{-2,+2\}$。

两项合计至多减少 4。∎

**引理 3（下界可达）**：若 $\text{diff} > 0$ 且所有 $cnt1[v]+cnt2[v]$ 为偶数，则存在一次跨数组交换使 diff 恰好减少 4。

**证明**：令 $A = \{v \mid cnt1[v] > cnt2[v]\}$、$B = \{v \mid cnt2[v] > cnt1[v]\}$。由 $\sum_v (cnt1[v]-cnt2[v]) = 0$ 且 diff $> 0$，必有 $A, B$ 均非空。取 $a \in A$、$b \in B$。因为内部交换免费，可分别把 `nums1` 中的某个 $a$ 与 `nums2` 中的某个 $b$ 换到同一个下标 $i$（把 $a$ 换到 `nums1[i]`、把 $b$ 换到 `nums2[i]`，两者互不影响）。此时 $cnt1[a] > cnt2[a]$ 且 $cnt1[b] < cnt2[b]$，一次跨数组交换使两项的 $|cnt1-cnt2|$ 各减少 2，diff 减少 4。∎

**引理 4（diff 是 4 的倍数）**：在可行性条件下，$\text{diff} \equiv 0 \pmod 4$。

**证明**：由 $cnt1[v]+cnt2[v]$ 为偶数得 $cnt1[v] \equiv cnt2[v] \pmod 2$，故每个 $|cnt1[v]-cnt2[v]|$ 都是偶数。记 $P = \sum_v \max(cnt1[v]-cnt2[v], 0)$，则 $\text{diff} = 2P$（正负部分相等，均为 $P$）。每一项 $\max(cnt1[v]-cnt2[v],0)$ 都是偶数，故 $P$ 为偶数，$\text{diff} = 2P \equiv 0 \pmod 4$。∎

**定理**：算法返回最少花费；无解时返回 $-1$。

**证明**：无解情形由引理 1 处理。可行时，引理 2 给出任意操作序列的花费下界 $\text{diff}/4$（每次最多减少 4，最终必须降到 0）；引理 3 说明存在恰好 $\text{diff}/4$ 次交换达到 0，故最少花费恰为 $\text{diff}/4$，与算法输出一致。由引理 4，整除无余数。∎

## 6. 复杂度分析

- **时间**：$O(n + V)$，$V$ 为不同值个数（$\le 2n$）。统计两个频次表各 $O(n)$，合并遍历 $O(V)$，哈希操作均摊 $O(1)$。
- **空间**：$O(V)$，两张频次表加一个键集合。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minCost(vector<int>& nums1, vector<int>& nums2) {
        unordered_map<int, int> cnt1, cnt2;
        for (int x : nums1) cnt1[x]++;
        for (int x : nums2) cnt2[x]++;
        unordered_set<int> keys;
        for (auto& kv : cnt1) keys.insert(kv.first);
        for (auto& kv : cnt2) keys.insert(kv.first);
        int diff = 0;
        for (int v : keys) {
            int a = cnt1.count(v) ? cnt1[v] : 0;
            int b = cnt2.count(v) ? cnt2[v] : 0;
            if ((a + b) % 2 == 1) return -1;
            diff += abs(a - b);
        }
        return diff / 4;
    }
};
```

### Python

```python
class Solution:
    def minCost(self, nums1: list[int], nums2: list[int]) -> int:
        cnt1, cnt2 = {}, {}
        for x in nums1:
            cnt1[x] = cnt1.get(x, 0) + 1
        for x in nums2:
            cnt2[x] = cnt2.get(x, 0) + 1
        diff = 0
        for v in set(cnt1) | set(cnt2):
            if (cnt1.get(v, 0) + cnt2.get(v, 0)) % 2 == 1:
                return -1
            diff += abs(cnt1.get(v, 0) - cnt2.get(v, 0))
        return diff // 4
```

## 8. 边界情况与易错点

1. **某个值总数是奇数 → 直接 $-1$**：这是唯一的无解判据。例如 `nums1 = [1,2]`、`nums2 = [1,1]`：值 1 总数 3（奇）→ $-1$。
2. **示例 1 那种「0 花费」**：两个数组的多重集本来就相同，diff = 0，答案 0。不要因为「两个数组看起来不一样」就想去做交换。
3. **不要在统计 diff 时跳过只出现于一个数组的值**：那正是 diff 的主要来源，漏掉会得到 0。
4. **除以 4 而不是 2**：diff 统计的是「两个方向的差之和」，一次交换同时修好两处，所以是 /4。若改成只统计一侧正差额 $P$，则答案是 $P/2$——两种写法等价，但**不要混用**。
5. **位置无关**：不能把「下标必须对上」当成额外约束。内部交换免费意味着任意排列都可达，所以只要多重集能对上就一定可行。
6. **`n` 很大**：$n \le 8\times10^4$，$O(n^2)$ 的配对模拟会超时；必须只做频次统计。
7. **值域与哈希**：值域 $\le 8\times10^4$ 时桶数组更快；哈希表更通用，代价是常数稍大。
