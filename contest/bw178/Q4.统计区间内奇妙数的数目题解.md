# LeetCode 统计区间内奇妙数的数目 题解

## 1. 题目概述

- **标题 / 题号**：统计区间内奇妙数的数目（#3869，hard）
- **链接**：https://leetcode.cn/problems/count-fancy-numbers-in-a-range/
- **来源**：LeetCode 第 178 场双周赛 Q4
- **难度**：困难
- **标签**：数学、动态规划

**题意**：先定义两层概念。

- **好数**：一个整数的数位序列**严格递增**或**严格递减**（按从左到右的顺序）。所有一位数都算好数。
- **奇妙数**：一个整数**本身是好数**，**或者它的数位和是好数**。

给定 $l, r$，返回区间 $[l, r]$ 内奇妙数的个数。

**约束**：

- $1 \le l \le r \le 10^{15}$

## 2. 示例

**示例 1**

```text
输入：l = 8, r = 10
输出：3
解释：8、9 是一位数 → 好数 → 奇妙数；
      10 的数位 [1,0] 严格递减 → 好数 → 奇妙数。共 3 个。
```

**示例 2**

```text
输入：l = 12340, r = 12341
输出：1
解释：12340 的数位 [1,2,3,4,0] 不单调 → 不是好数；
      数位和 1+2+3+4+0 = 10，而 10 的数位 [1,0] 严格递减 → 10 是好数 → 12340 是奇妙数。
      12341 的数位 [1,2,3,4,1] 不单调，数位和 11 的数位 [1,1] 也不单调 → 不是奇妙数。
```

**示例 3**

```text
输入：l = 123456788, r = 123456788
输出：0
解释：数位 [1,2,3,4,5,6,7,8,8] 不单调；数位和 44，[4,4] 不单调 → 不是奇妙数。
```

## 3. 解题思路

### 3.1 暴力思路

直接枚举 $[l, r]$ 里的每个数，判断它本身是否好数、再判断数位和是否好数。单次判断 $O(\log N)$，总复杂度 $O((r-l)\log N)$。

但 $r$ 可达 $10^{15}$，区间长度可能是 $10^{15}$ 量级，暴力必然超时——它只能用于小数据对拍。

### 3.2 核心观察：好数极少，而「数位和好数」必须靠数位 DP

![先把「好数」全枚举出来：去重后只有 1524 个](images/bw178_q4_good_sets.svg)

**观察 1：好数可以全部枚举出来。** 好数的数位**严格单调**，所以数位**互不相同**：

- 严格递增：数位里不能有 0（0 无法比任何数位更小且仍在最高位前），所以数位取自 $\{1,\dots,9\}$，共 $2^9 - 1 = 511$ 个；
- 严格递减：数位取自 $\{0,\dots,9\}$，去掉空集和 $\{0\}$（那会得到数字 0），共 $2^{10} - 2 = 1022$ 个；
- 两者都满足的只有一位数 $1..9$，重复 9 个。

所以不同好数一共 $511 + 1022 - 9 = 1524$ 个，最大的是 $9876543210 < 10^{15}$。**这个集合小到可以打表**，「本身是好数」这一支直接枚举即可。

**观察 2：数位和的范围很小。** $r \le 10^{15}$，最多 16 位，数位和最大是 $9 \times 15 = 135$（$10^{15}$ 本身数位和是 1）。把 $[1,135]$ 里所有好数筛出来，得到集合 `good_sums`（共 99 个）。于是「数位和是好数」等价于「数位和 $\in$ `good_sums`」——这是一个**只关心数位和落在某个集合里**的计数问题，正是数位 DP 的拿手场景。

![集合拆分：奇妙数 = 数位和好 ∪ 本身好](images/bw178_q4_decompose.svg)

**观察 3：按集合的「不重不漏」拆分。** 记

- $A$ = 数位和是好数的整数集合；
- $B$ = 本身是好数的整数集合。

奇妙数就是 $A \cup B$。直接 $|A| + |B|$ 会把交集算两遍，于是拆成

$$|A \cup B| = |A| + |B \setminus A|$$

也就是：

- **第一项**：数位和 $\in$ `good_sums` 的整数个数 → **数位 DP**；
- **第二项**：本身是好数、但数位和**不是**好数的整数个数 → **枚举 1524 个好数逐个查表**。

两项都能在 $O(\text{位数} \times \text{数位和} \times 10)$ 或 $O(1524)$ 内完成，再配一个 $f(r) - f(l-1)$ 的前缀差分即可。

### 3.3 算法流程

![数位 DP：按「第一个小于 N 的位」把 0 到 N 切块](images/bw178_q4_digit_dp.svg)

```text
1. 预处理：
   good_sum[s] = (s 是好数)，s ∈ [1,135]
   ways[m][s]  = 用 m 个 0..9 的数位凑出数位和 s 的方案数
   good_nums   = 全部好数（递增子集 + 递减子集，去重）
2. count_sum_good(N)：  # 数位和 ∈ good_sums 的 x ∈ [1,N] 的个数
3.    把 N 写成字符串 s，长度 L
4.    res = 0, prefix = 0
5.    for i in 0..L-1:
6.        d = s[i]
7.        for x in 0..d-1:                     # 第 i 位取比 d 小的值
8.            for sm in 0..9*(L-i-1):
9.                若 good_sum[prefix + x + sm]:  res += ways[L-i-1][sm]
10.       prefix += d
11.   若 good_sum[prefix]: res += 1            # N 本身
12.   返回 res
13. count_good_not_sum(N)： 枚举 good_nums 中 ≤ N 且数位和 ∉ good_sums 的个数
14. 答案 = [count_sum_good(r) - count_sum_good(l-1)]
        + [count_good_not_sum(r) - count_good_not_sum(l-1)]
```

第 5–11 行是标准的「按位切块」：在第 $i$ 位第一次小于 $N$ 的位置，前缀已被固定、当前位取 $0..d-1$，剩余 $L-i-1$ 位可以任意填，用 `ways` 直接查表。

### 3.4 示例演算

对示例 2 的 $N = 12340$（只看单点 $[12340, 12340]$，即 $f(12340) - f(12339)$）：

| 步骤 | 内容 | 结果 |
|------|------|------|
| 本身是好数？ | 数位 $[1,2,3,4,0]$，$3 < 4$ 之后又出现 $0$，既不递增也不递减 | ✗ |
| 数位和 | $1+2+3+4+0 = 10$ | 10 |
| 10 是好数？ | 数位 $[1,0]$ 严格递减 | ✓ |
| 结论 | 命中第二项（数位和好数） | 计数 1 |

而 $12341$：数位 $[1,2,3,4,1]$ 不单调，数位和 $11$ 的数位 $[1,1]$ 也不单调（相等不叫严格），两项都不命中 → 计数 0。所以 $[12340,12341]$ 内共 1 个奇妙数 ✓。

再看示例 1：$8$ 和 $9$ 是一位数（好数，数位和也是好数），$10$ 的数位 $[1,0]$ 严格递减 → 三个都是奇妙数，答案 3 ✓。

## 4. 算法细节

1. **`ways` 的递推**：$ways[0][0] = 1$，$ways[m][s] = \sum_{d=0}^{9} ways[m-1][s-d]$。它统计的是**允许前导零**的 $m$ 位数位串，正好对应「剩余位任意填」。
2. **切块的求和方式**：对每个 $x \in [0, d-1]$，剩余位的数位和 $sm$ 只要满足 `prefix + x + sm ∈ good_sums` 就累加 $ways[L-i-1][sm]$。写成双重循环即可，$L \le 16$、$sm \le 144$，总量约 $16 \times 10 \times 145$。
3. **好数枚举**：用二进制掩码表示数位集合。递增方向对 $\{1..9\}$ 的每个非空子集按升序拼数；递减方向对 $\{0..9\}$ 的每个非空子集按降序拼数（跳过得到 0 的那个）。最后 `sort + unique` 去重（一位数会被两种方向各生成一次）。
4. **枚举好数时的上界**：好数最大 $9876543210 < 10^{15}$，所以「好数 $\le N$」只需逐个 $O(1)$ 比较，不需要二分（若要更快可以对有序表二分）。
5. **区间转前缀**：所有计数函数都算「$\le N$」，区间用 $f(r) - f(l-1)$。注意 $l = 1$ 时 $f(0) = 0$。
6. **0 的处理**：数位 DP 里 0 会被算作「16 位全零」，但它的数位和是 0，而 `good_sum[0]` 设为 `false`，因此不会被计入；「本身是好数」那一支也只枚举 $\ge 1$ 的好数。由于 $l \ge 1$，把 0 排除与题目一致。
7. **位宽**：$N \le 10^{15}$，`long long` / Python 原生整数都可；答案最大 $10^{15}$，也在 `long long` 内。

## 5. 正确性证明

**引理 1（好数枚举完备）**：一个整数是好数，当且仅当它等于「$\{1,\dots,9\}$ 的某个非空子集按升序拼成的数」或「$\{0,\dots,9\}$ 的某个非空子集按降序拼成的非零数」。

**证明**：若 $x$ 严格递增，其数位两两不同且从左到右递增，故数位集合就是 $\{1..9\}$ 的一个非空子集（不能含 0：若含 0 则 0 必须是首位，而首位不能是 0），按升序拼接正是 $x$。若 $x$ 严格递减，数位两两不同，集合是 $\{0..9\}$ 的非空子集且最大数位 $> 0$（否则 $x = 0$，而 $x \ge 1$），按降序拼接正是 $x$。反之两种拼法显然都给出严格单调的数位序列。∎

**引理 2（`ways` 正确）**：$ways[m][s]$ 等于长度为 $m$、每位取自 $0..9$ 且各位之和为 $s$ 的串的个数。

**证明**：对 $m$ 归纳。$m = 0$ 时只有空串，和为 0，$ways[0][0] = 1$，其余为 0。设对 $m-1$ 成立，则长度 $m$ 的串由「长度 $m-1$ 的串 + 最后一位 $d$」唯一分解，$d$ 可取 $0..9$，故 $ways[m][s] = \sum_{d=0}^{9} ways[m-1][s-d]$。∎

**引理 3（切块不重不漏）**：设 $N$ 的十进制为 $s_0 s_1 \cdots s_{L-1}$。把 $[0, N]$ 中的整数按「与 $N$ 的公共前缀长度」划分为 $L+1$ 类：对每个 $i \in [0, L-1]$，第 $i$ 类是「前 $i$ 位与 $N$ 相同、第 $i$ 位小于 $s_i$」的整数；最后一类是 $N$ 本身。这些类互不相交且并集为 $[0, N]$。

**证明**：任意 $x \in [0, N]$ 写成 $L$ 位（允许前导零）的数位串。若 $x = N$ 则属于最后一类；否则存在最小的 $i$ 使 $x_i \ne s_i$，由 $x < N$ 知 $x_i < s_i$，于是 $x$ 属于第 $i$ 类，且这个 $i$ 唯一。不同 $i$ 对应的类显然不相交（第一次不同的位置不同）。∎

**引理 4（`count_sum_good` 正确）**：`count_sum_good(N)` 返回 $[0, N]$ 中数位和属于 `good_sums` 的整数个数。

**证明**：算法的外层循环恰好枚举引理 3 中的第 $0..L-1$ 类，内层对「第 $i$ 位取 $x < s_i$」的每种取值，用 $ways[L-i-1][sm]$ 统计剩余位的所有填法，并按 `good_sum` 过滤数位和，故每一类中被计数的恰是其中数位和好的整数；第 11 行单独处理 $N$ 本身。由引理 3 的分划与引理 2 的计数正确性，总数正确。数位和为 0 的只有整数 0，而 `good_sum[0] = false`，故 0 不被计入，返回的是 $[1, N]$ 的计数。∎

**引理 5（`count_good_not_sum` 正确）**：由引理 1 枚举出的好数集合完备，逐个判断「$\le N$」与「数位和不属于 `good_sums`」，即得 $[1,N]$ 中「本身好但不是数位和好」的个数。

**证明**：枚举集合与真实好数集合相等（引理 1，去重后无重复），判定条件与定义逐字对应，计数即为所求。∎

**定理**：$\text{answer} = \big(f_A(r) - f_A(l-1)\big) + \big(f_{B\setminus A}(r) - f_{B\setminus A}(l-1)\big)$ 等于 $[l,r]$ 内奇妙数的个数。

**证明**：由引理 4、5，$f_A(N)$ 与 $f_{B\setminus A}(N)$ 分别是 $[1,N]$ 中 $A$ 与 $B\setminus A$ 的元素个数，相减得到区间内的个数（$A$ 与 $B\setminus A$ 不交，且 $l-1 \ge 0$ 时前缀差分合法）。又 $A \cup B = A \,\dot\cup\, (B \setminus A)$，故两者之和恰为 $[l,r]$ 内奇妙数的个数。∎

## 6. 复杂度分析

- **时间**：
  - 预处理：`good_sum` 判 $135$ 个好数 $O(135\log 135)$；`ways` 表 $O(16 \times 145 \times 10)$；好数枚举 $O(2^9 + 2^{10})$。
  - 每次查询：`count_sum_good` 为 $O(L \cdot 10 \cdot 145) = O(16 \cdot 1450)$；`count_good_not_sum` 为 $O(1524)$。
  - 总计 $O(L \cdot S \cdot 10 + 1524)$，其中 $L \le 16$、$S \le 145$，常数极小。
- **空间**：$O(L \cdot S + 1524)$，即 `ways` 表 16×145 与好数列表。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long countFancy(long long l, long long r) {
        init();
        long long ans = 0;
        ans += countSumGood(r) - countSumGood(l - 1);
        ans += countGoodOnly(r) - countGoodOnly(l - 1);
        return ans;
    }

private:
    bool goodSum[400];
    long long ways[17][145];
    vector<long long> goodNums;
    bool built = false;

    bool isGood(long long x) {
        string s = to_string(x);
        if (s.size() == 1) return true;
        bool inc = true, dec = true;
        for (size_t i = 0; i + 1 < s.size(); i++) {
            if (!(s[i] < s[i + 1])) inc = false;
            if (!(s[i] > s[i + 1])) dec = false;
        }
        return inc || dec;
    }

    void init() {
        if (built) return;
        built = true;
        for (int i = 0; i < 400; i++) goodSum[i] = false;
        for (int s = 1; s <= 135; s++) goodSum[s] = isGood(s);
        for (int m = 0; m <= 16; m++)
            for (int s = 0; s <= 144; s++) ways[m][s] = 0;
        ways[0][0] = 1;
        for (int m = 1; m <= 16; m++) {
            for (int s = 0; s <= 144; s++) {
                long long t = 0;
                for (int d = 0; d <= 9 && d <= s; d++) t += ways[m - 1][s - d];
                ways[m][s] = t;
            }
        }
        for (int mask = 1; mask < (1 << 9); mask++) {
            long long v = 0;
            for (int b = 0; b < 9; b++)
                if (mask >> b & 1) v = v * 10 + (b + 1);
            goodNums.push_back(v);
        }
        for (int mask = 1; mask < (1 << 10); mask++) {
            long long v = 0;
            for (int b = 9; b >= 0; b--)
                if (mask >> b & 1) v = v * 10 + b;
            if (v > 0) goodNums.push_back(v);
        }
        sort(goodNums.begin(), goodNums.end());
        goodNums.erase(unique(goodNums.begin(), goodNums.end()), goodNums.end());
    }

    long long countSumGood(long long n) {
        if (n <= 0) return 0;
        string s = to_string(n);
        int L = (int)s.size();
        long long res = 0;
        int prefix = 0;
        for (int i = 0; i < L; i++) {
            int d = s[i] - '0';
            for (int x = 0; x < d; x++) {
                int base = prefix + x;
                for (int sm = 0; sm <= 144; sm++) {
                    if (base + sm < 400 && goodSum[base + sm]) res += ways[L - i - 1][sm];
                }
            }
            prefix += d;
        }
        if (goodSum[prefix]) res += 1;
        return res;
    }

    long long countGoodOnly(long long n) {
        if (n <= 0) return 0;
        long long res = 0;
        for (long long g : goodNums) {
            if (g > n) continue;
            int s = 0;
            long long t = g;
            while (t > 0) {
                s += (int)(t % 10);
                t /= 10;
            }
            if (!goodSum[s]) res++;
        }
        return res;
    }
};
```

### Python

```python
class Solution:
    def countFancy(self, l: int, r: int) -> int:
        def is_good(x: int) -> bool:
            d = [int(c) for c in str(x)]
            if len(d) == 1:
                return True
            inc = all(d[i] < d[i + 1] for i in range(len(d) - 1))
            dec = all(d[i] > d[i + 1] for i in range(len(d) - 1))
            return inc or dec

        good_sum = [False] * 200
        for s in range(1, 136):
            good_sum[s] = is_good(s)

        digits = 16
        max_sum = 9 * digits
        ways = [[0] * (max_sum + 1) for _ in range(digits + 1)]
        ways[0][0] = 1
        for m in range(1, digits + 1):
            for s in range(max_sum + 1):
                tot = 0
                for d in range(10):
                    if s >= d:
                        tot += ways[m - 1][s - d]
                ways[m][s] = tot

        def count_sum_good(n: int) -> int:
            if n <= 0:
                return 0
            s = str(n)
            L = len(s)
            res = 0
            prefix = 0
            for i, ch in enumerate(s):
                d = int(ch)
                for x in range(d):
                    base = prefix + x
                    for sm in range(max_sum + 1 - base):
                        if good_sum[base + sm]:
                            res += ways[L - i - 1][sm]
                prefix += d
            if good_sum[prefix]:
                res += 1
            return res

        good_numbers = set()
        for mask in range(1, 1 << 9):
            v = 0
            for b in range(9):
                if mask >> b & 1:
                    v = v * 10 + (b + 1)
            good_numbers.add(v)
        for mask in range(1, 1 << 10):
            v = 0
            for b in range(9, -1, -1):
                if mask >> b & 1:
                    v = v * 10 + b
            if v > 0:
                good_numbers.add(v)

        def count_good_not_sum(n: int) -> int:
            if n <= 0:
                return 0
            res = 0
            for g in good_numbers:
                if g <= n and not good_sum[sum(int(c) for c in str(g))]:
                    res += 1
            return res

        return (count_sum_good(r) - count_sum_good(l - 1)) + (
            count_good_not_sum(r) - count_good_not_sum(l - 1)
        )
```

## 8. 边界情况与易错点

1. **「严格」单调**：`11` 的数位 $[1,1]$ 不严格递增也不严格递减，**不是**好数（示例 2 正是靠这一点把 12341 排除）。
2. **一位数都算好数**：$1..9$ 全都直接是好数，所以 $[1,9]$ 的答案就是 9。而 0 虽也是一位数，但不是正整数区间的元素，可以不管。
3. **数位和的上界**：$r \le 10^{15}$ 时最多 15 个 9（$10^{15}$ 本身只有 16 位且和是 1），最大数位和 $135$。把 `good_sum` 数组开到 $144$ 以上并循环到 $135$ 即可，别按「16 位 × 9 = 144」写出越界。
4. **前导零**：`10` 的数位是 $[1,0]$ 而不是 $[0,1,0]$，判断好数时必须用**标准十进制表示**（不补前导零），否则 `10` 会被误判成递减以外的形态。
5. **去重**：一位数在「递增枚举」和「递减枚举」里各出现一次，必须去重，否则 `count_good_not_sum` 会重复计数（虽然一位数的数位和就是它自己、一定属于 `good_sums` 因而不被计入，但依赖这个巧合太脆弱）。
6. **交集**：$A \cap B$ 不能重复加。把「本身好」的那一支限制为「数位和不好」才是不重不漏的写法。
7. **$l = 1$ 与 $f(0)$**：$l-1 = 0$ 时计数函数应返回 0，写 `if (n <= 0) return 0;` 一行即可，别让它进入数位 DP。
8. **答案规模**：$[1, 10^{15}]$ 内的奇妙数约 $9\times10^{14}$ 个，超过 `int`，必须用 `long long`；返回类型 `long`。

**延伸思考**：如果「奇妙数」改成「本身好 **且** 数位和好」，答案就退化成两个集合求交，只能枚举好数逐个检查，因为「数位和好」与「数位模式好」在 DP 状态里需要同时携带「上一位数位」和「当前和」，状态量变成 $16 \times 145 \times 10 \times 2$，依然可做但更麻烦。如果数位条件从「严格单调」放宽为「非降/非增」，好数数量会从 1524 个暴涨到接近 $10^5$ 量级，枚举法失效，必须改用数位 DP 同时统计「数位模式」和「数位和」。
