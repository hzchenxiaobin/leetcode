# LeetCode 找出缺失的元素 题解

## 1. 题目概述

- **标题 / 题号**：找出缺失的元素（#3731，easy）
- **链接**：https://leetcode.cn/problems/find-missing-elements/
- **来源**：LeetCode 第 474 场周赛 Q1
- **难度**：简单
- **标签**：数组、哈希表、排序

**题意**：给定一个由**互不相同**整数组成的数组 `nums`。它原本包含某个范围内的**所有**整数，但现在可能缺失了其中一部分；保证该范围的**最小**整数和**最大**整数仍在 `nums` 中。返回该范围内所有缺失整数组成的**升序**列表；若无缺失，返回空列表。

**约束**：

- `2 <= nums.length <= 100`
- `1 <= nums[i] <= 100`
- `nums` 中整数互不相同

## 2. 示例

**示例 1**

```text
输入：nums = [1,4,2,5]
输出：[3]
解释：最小整数为 1，最大整数为 5，完整范围应为 [1,2,3,4,5]，其中只有 3 缺失。
```

**示例 2**

```text
输入：nums = [7,8,6,9]
输出：[]
解释：完整范围为 [6,7,8,9]，所有整数均已存在，没有缺失。
```

**示例 3**

```text
输入：nums = [5,1]
输出：[2,3,4]
解释：完整范围为 [1,5]，缺失 2、3、4。
```

## 3. 解题思路

### 3.1 暴力思路

签到题。最直接的做法：先求出 `min` 与 `max`，然后对 `[min, max]` 中的每个整数 `x`，**线性扫描** `nums` 判断是否存在，不存在就收集。时间复杂度 `O(n · R)`（`R` 为区间长度）。本题 `n ≤ 100`、值域 ≤ 100，暴力也能通过，但"存在性判断"完全可以做到 `O(1)`。

### 3.2 核心观察：min/max 锁定区间 + 哈希集合判存在

![核心观察：min/max 锁定区间，哈希集合判存在](images/missing_elements_concept.svg)

三个关键观察：

1. **区间端点是"免费"的**：题面保证范围内的最小、最大整数仍在 `nums` 中，所以完整范围就是 `[min(nums), max(nums)]`，一趟遍历即可锁定，无需猜测范围。
2. **互不相同 + 哈希集合**：`nums` 元素互不相同，全部放入哈希集合后，任意 `x` 的存在性判断为 `O(1)`。
3. **升序扫描天然有序**：按 `x` 从 `min` 到 `max` 递增枚举，收集到的缺失数自动升序，**无需再排序**。

### 3.3 算法流程

![算法流程图：建集合后升序扫描区间](images/missing_elements_flow.svg)

流程总结：求 `min/max` → 建哈希集合 `S` → 升序枚举 `x = min … max`，`x ∉ S` 则加入答案 → 枚举结束返回答案。

### 3.4 示例演算

![示例演算：nums=[5,1] 的逐步扫描表](images/missing_elements_walkthrough.svg)

以 `nums = [5, 1]` 为例：`S = {1, 5}`，区间 `[1, 5]`。依次检查 `1✓ 2✗ 3✗ 4✗ 5✓`，收集得 `ans = [2, 3, 4]`。

## 4. 算法细节

1. **求端点**：一趟遍历同时维护 `lo` 与 `hi`（或 `min_element` / `max_element`）。
2. **建集合**：C++ 用 `unordered_set`（平均 `O(1)` 查询），Python 直接 `set(nums)`。由于值域仅 `1..100`，也可用 `bool exist[101]` 数组代替，更朴素且更快。
3. **扫描收集**：`for x in [lo, hi]`（注意闭区间，Python 的 `range` 右开需 `hi + 1`），`x` 不在集合中则 `push_back`。
4. **做法 B（排序法）**：将 `nums` 排序后，对每一对相邻元素 `(a, b)`，开区间 `(a, b)` 内的整数全部缺失，依次加入答案。由于元素互不相同，`b ≥ a + 1`，不会产生重复。该做法只遍历数组、不依赖值域大小，适合值域很大但数组很短的场景。

## 5. 正确性证明

**引理 1**：缺失整数集合恰为 $[\min, \max] \setminus \mathrm{set}(nums)$。

**证明**：设原范围为 $[L, R]$。题面保证 $L$ 与 $R$ 仍存在于 `nums` 中，故 $\min(nums) \le L$ 且 $\max(nums) \ge R$；另一方面 `nums` 中所有元素原本都属于 $[L, R]$，故 $\min(nums) \ge L$ 且 $\max(nums) \le R$。两组不等式合并得 $L = \min(nums)$、$R = \max(nums)$，即原范围就是 $[\min, \max]$。又 `nums` 元素互不相同，"缺失"的整数恰为 $[\min, \max]$ 中未在 `nums` 中出现的那些。∎

**定理**：算法返回完整且升序的缺失整数列表。

**证明**：算法按升序枚举 $[\min, \max]$ 中的每个 $x$，当且仅当 $x \notin S$ 时收集。由集合的定义，$x \notin S \iff x$ 不在 `nums` 中；结合引理 1，收集的恰好是全部缺失整数，无遗漏也无多余。枚举顺序为升序，故输出列表升序。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n + R)$，其中 $R = \max - \min + 1 \le 100$。一趟遍历求端点 $O(n)$，建集合 $O(n)$，区间扫描 $O(R)$。
- **空间复杂度**：$O(n)$，哈希集合存储全部元素（若用 `bool exist[101]` 则为 $O(V)$，$V = 101$，仍是常数级）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> findMissingElements(vector<int>& nums) {
        int lo = *min_element(nums.begin(), nums.end());
        int hi = *max_element(nums.begin(), nums.end());
        unordered_set<int> s(nums.begin(), nums.end());
        vector<int> ans;
        for (int x = lo; x <= hi; ++x) {
            if (!s.count(x)) {
                ans.push_back(x);
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def findMissingElements(self, nums: List[int]) -> List[int]:
        s = set(nums)
        return [x for x in range(min(nums), max(nums) + 1) if x not in s]
```

## 8. 边界情况与易错点

1. **无缺失**：如 `[7,8,6,9]`，返回**空列表** `[]`，不是 `None`。
2. **只有两个元素**：`n = 2` 时中间可能整段缺失（如 `[5,1]` → `[2,3,4]`），这也是缺失数最多的极端情况。
3. **循环边界**：闭区间 `x <= hi`；Python `range(lo, hi + 1)` 右开，漏写 `+1` 会丢掉 `max` 本身（虽然 `max` 必在集合中不影响答案，但属于隐性错误）。
4. **输出有序性**：升序枚举天然有序；若改用"集合差集再输出"，顺序不保证，必须额外排序。
5. **值域小可用数组**：`1 <= nums[i] <= 100`，用布尔数组比哈希表更省、更快，面试中可作为优化点提一句。
6. **无需特判**：`min/max` 保证存在于 `nums` 中且 `n >= 2`，区间必非空，不用处理空区间。
