# LeetCode 相邻字符串之间的最长公共前缀 题解

## 1. 题目概述

- **标题 / 题号**：相邻字符串之间的最长公共前缀（#3598，medium）
- **链接**：https://leetcode.cn/problems/longest-common-prefix-between-adjacent-strings-after-removals/
- **来源**：LeetCode 第 456 场周赛 Q2
- **难度**：中等
- **标签**：数组、字符串、前缀/后缀分解

**题意**：给定字符串数组 `words`（长度 $n$），对每个下标 $i$ **独立**执行：删掉 `words[i]`（其余元素顺序不变），在剩余数组中求所有**相邻对**的**最长公共前缀（LCP）**长度的最大值，记为 `answer[i]`。若删除后不存在相邻对（剩 0 或 1 个元素），或所有相邻对都没有公共前缀，则 `answer[i] = 0`。

**约束**：

- $1 \le n \le 10^5$
- $1 \le |\text{words}[i]| \le 10^4$，仅含小写字母
- $\sum_i |\text{words}[i]| \le 10^5$

> 💡 **读题关键**：① $n$ 次询问**互不影响**，每次都从原数组出发，不是真删；②「相邻」指删除后紧挨着的两串；③ 取的是所有相邻对 LCP 的**最大值**；④ 约束给「总长度 $\le 10^5$」而非单串长度——期望复杂度与**总字长**线性相关。

## 2. 示例

**示例 1**

```text
输入：words = ["jump","run","run","jump","run"]
输出：[3,0,0,3,3]
解释：移除下标 0 后数组为 ["run","run","jump","run"]，相邻对 ("run","run") 的
      公共前缀 "run" 长度 3，是所有相邻对中最大的；其余同理。
```

**示例 2**

```text
输入：words = ["dog","racer","car"]
输出：[0,0,0]
解释：无论移除哪个元素，剩余相邻对都没有公共前缀。
```

**示例 3（自拟，覆盖「跨坑新对独撑答案」）**

```text
输入：words = ["ab","ab","ab"]
输出：[2,2,2]
解释：删中间那个后 w0 与 w2 变成新的相邻对，LCP("ab","ab") = 2 ——
      answer[1] 完全由「跨坑新对」贡献，左右两侧的原邻对都帮不上忙。
```

## 3. 解题思路

### 3.1 暴力思路

对每个 $i$ 重建数组 `words[:i] + words[i+1:]`，扫一遍剩余的 $n-2$ 个相邻对逐对求 LCP 再取最大。单次询问要枚举 $O(n)$ 个对，$n$ 次询问就是 $O(n^2)$ 次对枚举（还没算每对 LCP 的比较代价），$n = 10^5$ 时约 $10^{10}$，**必然超时**。

可改进点在于：删除一个元素后，**绝大多数相邻对根本没变**——只有包含 $i$ 的两条对消失了，外加一条新对诞生。每个 $i$ 都把全部相邻对重算一遍纯属浪费。

### 3.2 核心观察：删除是局部扰动 → 前缀/后缀最大值

![删除只扰动两条相邻对，前后缀最大值加新对现算](images/wc456_q2_lcp_prefix_suffix.svg)

先把「相邻对」的 LCP 预处理成数组：记 $\text{lcp}[j] = \text{LCP}(\text{words}[j],\ \text{words}[j+1])$，$j = 0, \dots, n-2$。删除 `words[i]` 后，原数组的 $n-1$ 条相邻对分成四类：

| 相邻对 | 删除后的状态 |
|--------|--------------|
| $(0,1), \dots, (i-2,\, i-1)$ | **原样保留**（成员都在 $i$ 左侧，相对顺序不变，LCP 直接复用） |
| $(i-1,\, i)$ 与 $(i,\, i+1)$ | **消失**（成员 $i$ 被删） |
| $(i-1,\, i+1)$ | **新诞生**（跨过空洞相邻，需现场计算） |
| $(i+1,\, i+2), \dots, (n-2,\, n-1)$ | **原样保留**（都在 $i$ 右侧） |

「保留部分的最大值」用**前缀最大值 + 后缀最大值** $O(1)$ 直取：$\text{pre}[k] = \max(\text{lcp}[0..k])$、$\text{suf}[k] = \max(\text{lcp}[k..n-2])$，左半段取 $\text{pre}[i-2]$，右半段取 $\text{suf}[i+1]$，于是

$$\text{answer}[i] = \max\big(\text{pre}[i-2],\ \ \text{LCP}(\text{words}[i-1],\, \text{words}[i+1]),\ \ \text{suf}[i+1]\big)$$

不存在的项（$i$ 在边界）一律记 $0$：$i = 0$ 时无左半段也无新对，$i = n-1$ 时无右半段也无新对。

> 💡 **一句话总结**：删除是**局部扰动**——左半段、右半段查 pre/suf 表 $O(1)$ 直取，唯一的增量是「跨坑新对」，单独现算即可。与 [238. 除自身以外数组的乘积](https://leetcode.cn/problems/product-of-array-except-self/) 的前缀积 × 后缀积是孪生套路，只是聚合运算从乘积换成最大值，外加一点局部增量。

### 3.3 算法流程

![算法流程：预处理 lcp 与前后缀最大值，逐 i 三项取最大](images/wc456_q2_algorithm_flow.svg)

流程四步：① 一趟预处理 $\text{lcp}$ 数组（每对比较止于首个失配）；② 正反两趟扫出 `pre`/`suf`；③ 对每个 $i$ 三项条件判断、缺项记 0 取最大；④ 收集返回。三个条件**彼此独立**，各自判断存在性，不需要任何特判分支。

### 3.4 示例演算

对 `words = ["jump","run","run","jump","run"]` 预处理后逐 $i$ 查表：

![示例演算走查表](images/wc456_q2_walkthrough.svg)

$\text{lcp} = [0, 3, 0, 0]$，$\text{pre} = [0, 3, 3, 3]$，$\text{suf} = [3, 3, 0, 0]$。$i = 0$ 的 3 来自右半段 `suf[1]`，$i = 3$ 的 3 由左半段 `pre[1]` 与新对 `LCP(run, run)` 同时贡献，$i = 4$ 的 3 来自左半段 `pre[2]`，输出 `[3,0,0,3,3]` ✓。

## 4. 算法细节

1. **lcp 的计算**：双指针逐字符比较，止于**首个失配**或较短的串扫完，单对代价 $\min(|w_j|, |w_{j+1}|)$。每个字符串至多作为左成员登场一次，故 $\sum_j \min(|w_j|, |w_{j+1}|) \le S$，一趟线性。
2. **pre/suf 下标推导**：先默写「删除后保留的对区间是 $[0, i-2]$ 与 $[i+1, n-2]$」，再由区间端点倒推下标 $\text{pre}[i-2]$、$\text{suf}[i+1]$——**不要**凭感觉写成 $\text{pre}[i-1]$（会把已消失的对 $(i-1,i)$ 算进去）。
3. **边界统一**：三个 `if` 各自判断存在性（$i \ge 2$、$i+1 \le n-2$、$1 \le i \le n-2$），缺项一律记 0，$n = 1$、$n = 2$、$i = 0$、$i = n-1$ 全部自动覆盖，无需特判。
4. **新对现算的总代价**：$\sum_i \min(|w_{i-1}|, |w_{i+1}|) \le \sum_i |w_{i-1}| \le S$（第 $i$ 项电荷记到左串 $w_{i-1}$ 头上，每串至多被记一次），仍是线性。
5. **实现小节**：C++ 用 `const string&` 接住字符串避免拷贝；比较循环上限取 `min(a.size(), b.size())` 防越界。

## 5. 正确性证明

**引理 1（删除的局部性）**：删除 `words[i]` 后，对每个 $j \le i-2$ 或 $j \ge i+1$，原相邻对 $(\text{words}[j], \text{words}[j+1])$ 仍是相邻对且 LCP 值不变；含 $i$ 的两条对 $(i-1, i)$、$(i, i+1)$ 消失；当且仅当 $0 < i < n-1$ 时，新相邻对 $(i-1,\, i+1)$ 诞生，且除此之外无任何其他新相邻对。

**证明**：删除不改变剩余元素的**相对顺序**。若 $j \le i-2$，则 $j, j+1 < i$，二者之间的元素一个没少，删除前后都紧邻；$j \ge i+1$ 同理。含 $i$ 的两条对因成员被删而消失。当 $0 < i < n-1$ 时，删除后 $i-1$ 与 $i+1$ 之间恰无其它剩余元素，故相邻；而对任意其余不相邻的二元组，两成员之间必有残留元素，不可能变相邻。LCP 是两串自身的函数，成员不变则值不变。∎

**引理 2（线性代价）**：设 $S = \sum_j |w_j|$，则 $\sum_{j=0}^{n-2} \min(|w_j|, |w_{j+1}|) \le S$，且 $\sum_{i=1}^{n-2} \min(|w_{i-1}|, |w_{i+1}|) \le S$。

**证明**：由 $\min(a, b) \le a$，第一个和式的第 $j$ 项不超过 $|w_j|$，对 $j$ 求和即 $\le S$；第二个和式的第 $i$ 项不超过 $|w_{i-1}|$，而 $i$ 取遍 $1, \dots, n-2$ 时 $w_{i-1}$ 恰好取遍 $w_0, \dots, w_{n-3}$，互不重复，求和亦 $\le S$。∎

**定理（答案公式）**：对一切 $0 \le i \le n-1$，

$$\text{answer}[i] = \max\big(\text{pre}[i-2],\ \text{LCP}(w_{i-1}, w_{i+1}),\ \text{suf}[i+1]\big)$$

其中 $\text{pre}[k] = \max(\text{lcp}[0..k])$、$\text{suf}[k] = \max(\text{lcp}[k..n-2])$，下标越界的项记 $0$。

**证明**：由引理 1，删除 $i$ 后相邻对的集合恰为三块互斥并集：$\{(j, j+1) : 0 \le j \le i-2\}$、$\{(i-1, i+1)\}$（可能为空）、$\{(j, j+1) : i+1 \le j \le n-2\}$。$\text{answer}[i]$ 是这三块中所有对 LCP 值的最大值（空集贡献 0，恰与题面「不存在公共前缀记 0」一致）。第一块的最大值即 $\max_{0 \le j \le i-2} \text{lcp}[j] = \text{pre}[i-2]$（$i < 2$ 时为空记 0）；第三块同理为 $\text{suf}[i+1]$（$i + 1 > n-2$ 时为空记 0）；中间块当 $0 < i < n-1$ 时为 $\text{LCP}(w_{i-1}, w_{i+1})$，否则为空记 0。max 对并集可分配，得证。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n + S)$，$S = \sum_i |\text{words}[i]| \le 10^5$。预处理 `lcp` 一趟由引理 2 第一式为 $O(S)$；`pre`/`suf` 正反两趟 $O(n)$；回答每个 $i$ 时左右两项 $O(1)$，新对现算总和由引理 2 第二式为 $O(S)$。
- **空间复杂度**：$O(n)$。`lcp`、`pre`、`suf` 三个长度 $n-1$ 的数组（返回值不计入）。若用「最大值 + 次大值」计数写法可降到 $O(1)$ 额外空间，见延伸思考。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    vector<int> longestCommonPrefix(vector<string>& words) {
        int n = words.size();
        vector<int> ans(n, 0);
        if (n == 1) return ans;  // 删完无相邻对

        auto lcp = [](const string& a, const string& b) {
            int k = 0, lim = min(a.size(), b.size());
            while (k < lim && a[k] == b[k]) k++;
            return k;
        };

        vector<int> lcpArr(n - 1);
        for (int j = 0; j + 1 < n; j++) lcpArr[j] = lcp(words[j], words[j + 1]);

        vector<int> pre = lcpArr, suf = lcpArr;
        for (int j = 1; j < n - 1; j++) pre[j] = max(pre[j - 1], lcpArr[j]);
        for (int j = n - 3; j >= 0; j--) suf[j] = max(suf[j + 1], lcpArr[j]);

        for (int i = 0; i < n; i++) {
            int best = 0;
            if (i >= 2) best = max(best, pre[i - 2]);              // 左半段
            if (i + 1 <= n - 2) best = max(best, suf[i + 1]);      // 右半段
            if (i >= 1 && i + 1 < n) {                             // 跨坑新对
                best = max(best, lcp(words[i - 1], words[i + 1]));
            }
            ans[i] = best;
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def longestCommonPrefix(self, words: List[str]) -> List[int]:
        n = len(words)
        if n == 1:
            return [0]

        def lcp(a: str, b: str) -> int:
            k, lim = 0, min(len(a), len(b))
            while k < lim and a[k] == b[k]:
                k += 1
            return k

        arr = [lcp(words[j], words[j + 1]) for j in range(n - 1)]

        pre = arr[:]                      # pre[k] = max(lcp[0..k])
        for j in range(1, n - 1):
            pre[j] = max(pre[j - 1], arr[j])
        suf = arr[:]                      # suf[k] = max(lcp[k..n-2])
        for j in range(n - 3, -1, -1):
            suf[j] = max(suf[j + 1], arr[j])

        ans = []
        for i in range(n):
            best = 0
            if i >= 2:
                best = max(best, pre[i - 2])            # 左半段
            if i + 1 <= n - 2:
                best = max(best, suf[i + 1])            # 右半段
            if 1 <= i <= n - 2:                         # 跨坑新对
                best = max(best, lcp(words[i - 1], words[i + 1]))
            ans.append(best)
        return ans
```

## 8. 边界情况与易错点

1. **$n = 1$**：删完剩 0 个元素，`answer = [0]`；**$n = 2$**：删任一个都只剩单元素，`answer = [0, 0]`。用「缺项记 0 + 三个独立 if」后无需特判（$n=1$ 提前 return 仅为省一趟空扫描）。
2. **下标 off-by-one 是本题最大陷阱**：左半段取 $\text{pre}[i-2]$ 而非 $\text{pre}[i-1]$，右半段取 $\text{suf}[i+1]$ 而非 $\text{suf}[i]$——后者会把**已消失**的对 $(i-1,i)$、$(i,i+1)$ 的值错误地算进来，在全同字符串的用例上直接 WA。
3. **新对存在条件**是 $1 \le i \le n-2$：$i = 0$ 无左邻、$i = n-1$ 无右邻，都没有新对；但 $i = n-2$ **有**新对（左邻 $n-3$、右邻 $n-1$），别和「无右半段」搞混。
4. **最长可能由新对贡献**（自拟示例 3：`["ab","ab","ab"]` 删中间得 2），三项缺一不可，别只查左右半段。
5. **LCP 比较上限**取 $\min(|a|, |b|)$，防止越界；比较止于首个失配，别把整串扫完。
6. **复杂度错觉**：看似「每个 $i$ 现算一次 LCP，最坏 $O(n \cdot L)$」，实际由引理 2 总代价 $\le 2S$ 仍是线性——这正是题目给「总长度」约束而非单串约束的原因。

**延伸思考**：

- **$O(1)$ 空间写法**：删除 $i$ 只会从 `lcp` 数组移除两个元素 $\text{lcp}[i-1]$、$\text{lcp}[i]$，维护全局最大值（及其出现次数）与次大值即可 $O(1)$ 判断剩余部分的最大值——与 238 题的空间优化同思路；需小心「最大值恰好只出现在被删的两格里」的分支。
- **「跳过头」优化**：由 LCP 的传递性，$\text{LCP}(w_{i-1}, w_{i+1}) \ge \min(\text{lcp}[i-1], \text{lcp}[i])$（三串在前 $\min$ 长度内全同），计算新对时可从该长度起接着比。渐进不变，但「大片相同串」的用例（如全体同串）每次新对计算直接 $O(1)$。
