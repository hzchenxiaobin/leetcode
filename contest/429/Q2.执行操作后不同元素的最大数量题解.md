# LeetCode 执行操作后不同元素的最大数量 题解

## 1. 题目概述

- **标题 / 题号**：执行操作后不同元素的最大数量（#3397，medium）
- **链接**：https://leetcode.cn/problems/maximum-number-of-distinct-elements-after-operations/
- **来源**：LeetCode 第 429 场周赛 Q2
- **难度**：中等
- **标签**：贪心、数组、排序

**题意**：给定整数数组 `nums` 和整数 `k`。可以对每个元素**至多执行一次**操作：把一个 $[-k, k]$ 内的整数加到该元素上。等价地，每个 $nums[i]$ 可以保持不变，也可以变成区间 $[nums[i]-k,\ nums[i]+k]$ 内的任意一个整数。返回操作后 `nums` 中**不同元素个数**的最大值。

**约束**：

- $1 \le nums.length \le 10^5$
- $1 \le nums[i] \le 10^9$
- $0 \le k \le 10^9$

## 2. 示例

**示例 1**

```text
输入：nums = [1,2,2,3,3,4], k = 2
输出：6
解释：对前四个元素执行操作，nums 变为 [-1, 0, 1, 2, 3, 4]，6 个元素全部互异。
```

**示例 2**

```text
输入：nums = [4,4,4,4], k = 1
输出：3
解释：对 nums[0] 加 -1、nums[1] 加 1，得 [3, 5, 4, 4]，不同元素为 {3, 4, 5}。
```

**示例 3（自造，覆盖 k 较大、四个相同值全救活的情形）**

```text
输入：nums = [4,4,4,4], k = 2
输出：4
解释：分别加 -2、-1、0、+1，得 [2, 3, 4, 5]，四个值全部互异。
```

## 3. 解题思路

### 3.1 暴力思路（枚举 / 二分图匹配）

每个元素有 $2k+1$ 种改法（加 0 即不动），直接枚举组合是 $O((2k+1)^n)$，$k$ 高达 $10^9$，连枚举空间都不存在。正经一点的暴力是把问题建成**二分图匹配**：左侧 $n$ 个元素，右侧是所有候选整数值，元素 $i$ 与值 $v$ 有边当且仅当 $v \in [x_i-k,\ x_i+k]$，答案即最大匹配数。但值域宽达 $4\times 10^9$，即使离散化，单个值能被大量元素选中，边数最坏 $O(n^2) = 10^{10}$，Hopcroft–Karp 也无力回天。$n \le 10^5$ 的规模在明示：这题存在 $O(n \log n)$ 的**排序贪心**。

### 3.2 核心观察：排序后区间端点单调，「能放多小放多小」

把每个元素看成一条**闭区间** $I_i = [x_i - k,\ x_i + k]$：操作后它能变成区间内任意整数。问题改写为：**从尽量多的区间里各选一个整数，使选出的整数两两不同**。

![核心观察：区间视图与贪心放置](images/wc429_q2_interval_greedy.svg)

两个关键观察：

1. **排序后区间端点同时单调**。将 `nums` 升序排序后，所有区间的左端点 $L_i = x_i-k$ 与右端点 $R_i = x_i+k$ 都随 $i$ 非降——小元素的整个可选范围整体偏左。因此**先安置小元素、把较小的值用掉，不会伤及大元素**（它们的区间更靠右）。
2. **放得越小越好**。放置的值必然严格递增，设当前已放的最大值为 $last$，处理区间 $[L, R]$ 时选 $\max(L,\ last+1)$——即**区间内比 $last$ 大的最小整数**。放得越小，给后续区间留下的余地越大；只有当 $\max(L,\ last+1) > R$（整个区间都 $\le last$，被彻底堵死）才忍痛放弃这个元素（它保持原值）。

### 3.3 算法流程

![算法流程：排序 + 一趟扫描](images/wc429_q2_algorithm_flow.svg)

1. 将 `nums` 升序排序；
2. 维护 $last$（上一个成功放置的值，初始为 $-\infty$）与计数 $ans$；
3. 对每个 $x$：算 $cur = \max(x-k,\ last+1)$；若 $cur \le x+k$ 则放置（$last \leftarrow cur$，$ans{+}{+}$），否则跳过（$last$ 不变）；
4. 所有元素处理完，返回 $ans$。

### 3.4 示例演算

![示例演算：nums = [1,2,2,3,3,4], k = 2](images/wc429_q2_walkthrough.svg)

对示例 1 排序后逐元素演算（见上图）：$i=0$ 时区间左端 $-1$ 远小于 $last+1=-\infty$，取 $L$；$i=1$ 处两者同为 $0$；从 $i=2$ 起区间左端追不上 $last+1$，一律取 $last+1$，最终放下 $-1,0,1,2,3,4$ 共 6 个互异值。示例 2 则演示了「堵死」分支：$[4,4,4,4]$、$k=1$ 的四个区间都是 $[3,5]$，依次放 $3,4,5$ 后第 4 个区间被堵死（$last+1=6>5$），保持原值 $4$，答案 3。

## 4. 算法细节

1. **必须先排序**：区间端点单调是贪心正确性的前提。反例：$nums = [5,1]$，$k=1$，不排序直接按原序贪心——放 $4$ 后第二个区间 $[0,2]$ 被堵死，只得 1；排序后区间为 $[0,2],[4,6]$，放 $0,4$ 得 2。
2. **`last` 只在成功放置时更新**：跳过时 $cur$ 是区间外的非法值，若误写 `last = cur` 会让后续放置错位变少。
3. **64 位整数**：$x+k$ 最大 $2\times 10^9$、$x-k$ 最小约 $-10^9$，均超 `int32` 范围，C++ 全程用 `long long`。
4. **$last$ 的初始化**：取 `LLONG_MIN` 会让首次 `last + 1` 溢出，应取 `LLONG_MIN / 2` 这类安全小值（或单独先放置第一个元素）。
5. **「跳过」的元素不必强行操作**：题目允许至多操作一次，保持原值即可。§5 引理 2 保证这个原值必然与某个已放置值重合，不会破坏计数、也不会凭空多出新值。
6. **与 945 的同源性**：本题是「使数组唯一」家族的推广——945 的操作是 $+1$，相当于区间为半无穷 $[x, +\infty)$；本题区间有界，但「$last+1$ 往右推进」的贪心骨架完全一致，有界反而给了向左腾挪的自由度。

## 5. 正确性证明

**引理 1（端点单调）**：排序后 $L_i \le L_{i+1}$ 且 $R_i \le R_{i+1}$。

**证明**：$L_i = x_i - k$、$R_i = x_i + k$ 都是 $x_i$ 的严格递增函数，而排序保证 $x_i \le x_{i+1}$。∎

**引理 2（贪心计数的语义）**：设贪心放置的值依次为 $g_1 < g_2 < \cdots < g_t$。被跳过的元素，其原值必等于 $\{g_1, \ldots, g_t\}$ 中某个值。于是贪心结束后数组的不同值集合恰为 $\{g_1, \ldots, g_t\}$，即**返回值 $t$ 就是所得数组的不同元素个数**。

**证明**：设元素 $i$（原值 $x_i$）被跳过，跳过时刻 $last = g_j$（最后放置值），跳过条件给出 $x_i \le R_i \le g_j$；又 $x_i \ge L_i \ge L_{i_1} = g_1$（$i_1 = 0$，首个元素必放置且取左端点；$L$ 非降）。若 $x_i$ 不等于任何 $g_q$，则存在相邻放置值 $g_q < x_i < g_{q+1}$（$q < j$）。考察 $g_{q+1} = \max(L_{i_{q+1}},\ g_q + 1)$：若 $g_{q+1} \ge g_q + 2$，则 $g_{q+1} = L_{i_{q+1}}$，由引理 1 及 $i > i_{q+1}$（跳过发生在放置 $g_{q+1}$ 之后）得 $x_i \ge L_i \ge L_{i_{q+1}} = g_{q+1}$，矛盾；若 $g_{q+1} = g_q + 1$，则开区间 $(g_q,\ g_{q+1})$ 中没有整数，$x_i$ 无处容身，矛盾。∎

**引理 3（支配性）**：对任意可行方案（选出 $m$ 个元素并赋互异值），贪心放置数 $t \ge m$。

**证明**：先规范化方案：若它给下标 $p < q$ 的元素赋值 $v_p > v_q$，由引理 1 有 $v_q \ge L_q \ge L_p$ 且 $v_q < v_p \le R_p \le R_q$，故 $v_q \in I_p$、$v_p \in I_q$，交换两个赋值仍合法且互异集合不变。重复交换，可设方案选的元素 $j_1 < \cdots < j_m$ 的赋值 $v_1 < \cdots < v_m$ 随下标严格递增。

再对 $l$ 归纳证明：贪心第 $l$ 次放置的值 $g_l \le v_l$，且其元素下标 $i_l \le j_l$（$1 \le l \le m$）。

- $l = 1$：首个元素必放置，$g_1 = L_0 \le L_{j_1} \le v_1$，$i_1 = 0 \le j_1$。
- 步骤：设结论对 $l$ 成立。若贪心在 $(i_l,\ j_{l+1}]$ 内已有第 $l+1$ 次放置，则 $g_{l+1} = \max(L_{i_{l+1}},\ g_l + 1) \le \max(L_{j_{l+1}},\ v_l + 1) \le v_{l+1}$（引理 1、$i_{l+1} \le j_{l+1}$、整数严格递增 $v_l + 1 \le v_{l+1}$、以及 $L_{j_{l+1}} \le v_{l+1}$），且 $i_{l+1} \le j_{l+1}$。若直到 $j_{l+1}$ 都未放置，则处理 $j_{l+1}$ 时 $last = g_l \le v_l < v_{l+1} \le R_{j_{l+1}}$，即区间未被堵死（$last < R_{j_{l+1}}$，故 $cur = \max(L,\ last+1) \le R$），第 $l+1$ 次放置恰在元素 $j_{l+1}$ 处发生，归入上一情形。∎

**定理**：贪心返回值等于最优解。

**证明**：贪心本身是可行方案，由引理 2 其返回值恰为所得数组的不同元素个数；由引理 3 它不小于任何可行方案的不同元素个数，故为最大值。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \log n)$。排序占主导；随后每个元素 $O(1)$ 判断放置或跳过，单趟共 $O(n)$。
- **空间复杂度**：$O(\log n)$（排序的递归栈；不计输出的原地排序），额外只用常数个变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maxDistinctElements(vector<int>& nums, int k) {
        sort(nums.begin(), nums.end());
        long long last = LLONG_MIN / 2;   // 安全小值，last + 1 不溢出
        int ans = 0;
        for (int x : nums) {
            long long cur = max((long long)x - k, last + 1);
            if (cur <= (long long)x + k) {
                last = cur;
                ans++;
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maxDistinctElements(self, nums: List[int], k: int) -> int:
        nums.sort()
        ans = 0
        last = float('-inf')
        for x in nums:
            cur = max(x - k, last + 1)
            if cur <= x + k:
                last = cur
                ans += 1
        return ans
```

## 8. 边界情况与易错点

1. **溢出**：$x + k$ 最大 $2 \times 10^9$，超出 `int32`；C++ 中参与比较与赋值的 `cur`、`last` 必须用 `long long`，且 `last` 初始化不能取 `LLONG_MIN`（首次 `last + 1` 溢出 UB），用 `LLONG_MIN / 2` 或先单独放置第一个元素。
2. **忘排序直接贪心**：区间端点不再单调，支配性证明失效。反例 $[5,1]$、$k=1$，原序贪心得 1，正确答案 2。
3. **跳过时误更新 `last`**：跳过意味着 $cur > x + k$，`cur` 在区间外，若执行 `last = cur` 会让后续元素错误地「绕开」一个本可放置的值，计数变少。
4. **$k = 0$**：区间退化为单点，贪心自然退化为「统计不同原值个数」，无需特判。
5. **「至多一次」的语义**：跳过的元素保持原值即可，不要为了「都用上操作」强行改动——引理 2 已证明保持原值零损失；反过来若题目改成「恰好一次且必须加非零整数」，被堵死时反而无解可救，两种语义答案可能不同。
6. **$n = 1$**：单个元素总能放置（$cur = x - k \le x + k$ 恒成立），答案恒为 1。
