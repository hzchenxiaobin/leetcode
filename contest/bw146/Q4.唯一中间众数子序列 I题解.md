# LeetCode 唯一中间众数子序列 I 题解

## 1. 题目概述

- **标题 / 题号**：唯一中间众数子序列 I（#3395，hard）
- **链接**：https://leetcode.cn/problems/subsequences-with-a-unique-middle-mode-i/
- **来源**：LeetCode 第 146 场双周赛 Q4
- **难度**：困难
- **标签**：数组、哈希表、数学、组合数学

**题意**：给定整数数组 `nums`，统计长度为 $5$ 的**子序列**（不必连续）中，满足「**中间那个元素是唯一众数**」的个数，答案对 $10^9 + 7$ 取模。

具体地：取 $i_0 < i_1 < i_2 < i_3 < i_4$，设 $seq = [\text{nums}[i_0], \dots, \text{nums}[i_4]]$。若 $seq$ 中出现次数**最多**的值只有唯一一个，且这个值恰好是 $seq[2] = \text{nums}[i_2]$，则该子序列合法。

**约束**：

- $5 \le \text{nums.length} \le 1000$
- $-10^9 \le \text{nums}[i] \le 10^9$

> 💡 关键量级：$n \le 1000$ 时，$\binom{n}{5} \approx 8 \times 10^{12}$，枚举五元组绝无可能；而 $O(n^2) = 10^6$ 完全够用。解法核心是**枚举中间位置**，把「众数」这个全局条件化成**局部的计数组合**。

## 3. 解题思路

### 3.1 暴力思路

枚举所有五元组 $i_0 < i_1 < i_2 < i_3 < i_4$，对每个五元组统计频次、判断唯一众数是否为 $\text{nums}[i_2]$。复杂度

$$O\!\left(\binom{n}{5} \cdot 5\right) = O(n^5)$$

$n = 1000$ 时约 $8 \times 10^{12}$ 次，完全不可能。即使只枚举「中间位置 + 两侧组合」中的一侧，复杂度也仍是 $O(n^3)$ 量级。

必须换视角：**枚举中间位置 $i$，然后解析地数出合法的两侧选择数**，而不是逐对枚举。

### 3.2 核心观察：把「唯一众数」化成「$a$ 至少要再出现几次」

![固定中间位置 i，令 a = nums[i]；t 是两侧 4 个元素中等于 a 的个数](images/bw146_q4_model.svg)

固定中间位置 $i$，记 $a = \text{nums}[i]$。两侧一共要选 $4$ 个元素（左选 $2$ 个、右选 $2$ 个）。设

$$t = \text{两侧 4 个元素中等于 } a \text{ 的个数}$$

则 $a$ 在这 5 个元素中的总出现次数为 $m = 1 + t$。而**其他任何值**只能在剩下 $4 - t$ 个位置里出现，出现次数至多 $4 - t$。

「$a$ 是唯一众数」$\iff$ 对每个 $v \ne a$ 都有 $\text{cnt}(v) < 1 + t$。按 $t$ 分类讨论：

| $t$ | $m = 1+t$ | 其他值的最大可能次数 | 合法？ | 说明 |
|-----|-----------|----------------------|--------|------|
| 0 | 1 | 4 | ✗ | 其他值至少出现 1 次，而 $m = 1$ 不满足「严格大于」 |
| 1 | 2 | 3 | **有条件** ✓ | 剩下 3 个元素必须**两两不同**（此时每个都只出现 1 次） |
| 2 | 3 | 2 | ✓ 恒合法 | 剩下 2 个元素即使相同也只有 2 次 $< 3$ |
| 3 | 4 | 1 | ✓ 恒合法 | 只剩 1 个位置 |
| 4 | 5 | 0 | ✓ 恒合法 | 五个元素全是 $a$ |

于是问题被拆成两块：

- **$t \ge 2$ 的部分**：直接组合计数，$t = 2, 3, 4$ 分别是「两侧各取几个 $a$」的 6 种组合；
- **$t = 1$ 的部分**：需要「另外 3 个元素两两不同」这一额外约束，用**容斥**计算。

### 3.3 核心观察：$t=1$ 时「其余三个两两不同」怎么数

![t = 1 时的容斥：先去掉 u 的全部出现，再减掉同值对](images/bw146_q4_count.svg)

以「多出的那个 $a$ 来自左半」为例（来自右半完全对称）。此时：

- 左半选 $2$ 个：$1$ 个是 $a$（$la$ 种选法），另 $1$ 个是某个**非 $a$** 的元素 $u$；
- 右半选 $2$ 个：都必须是**非 $a$**，且它们的值必须与 $u$ 不同、且彼此不同。

记右半前缀 $a$ 出现 $ra$ 次、非 $a$ 元素共 $ro$ 个；对某个值 $u$，右半中 $u$ 出现 $R_u$ 次；再记

$$eqR = \sum_{v} \binom{\text{cnt}_R(v)}{2}$$

即右半区间内「同值对」的总数（含 $a$ 的同值对 $\binom{ra}{2}$）。那么固定 $u$ 之后，右半合法的选择数为

$$V(u) = \binom{ro - R_u}{2} - \left[eqR - \binom{ra}{2} - \binom{R_u}{2}\right]$$

- 第一项：从「右半非 $a$ 且不等于 $u$」的 $ro - R_u$ 个元素里任取 2 个；
- 第二项：减去其中「两个元素同值」的情况——把 $eqR$ 里属于 $a$ 的 $\binom{ra}{2}$ 与属于 $u$ 的 $\binom{R_u}{2}$ 剔除后，剩下的正是所有「值 $v \notin \{a, u\}$ 的同值对」。

于是 $t = 1$ 且多出的 $a$ 在左侧的总贡献为

$$la \cdot \sum_{p < i,\ \text{nums}[p] \ne a} V(\text{nums}[p])$$

右侧对称：$ra \cdot \sum_{q > i,\ \text{nums}[q] \ne a} V'(\text{nums}[q])$，其中 $V'$ 把 $ro, ra$ 换成 $lo, la$、$eqR$ 换成 $eqL$。

### 3.4 算法流程

```text
1. 把 nums 离散化成 0..D-1 的编号，维护左半计数 cntL、右半计数 cntR
   以及同值对计数 eqL、eqR（初始 cntR 含全部元素，cntL 为空）
2. ans = 0
3. for i = 0 .. n-1:
       a = nums[i]
       把 nums[i] 从右半移出（cntR[a]--，eqR -= cntR[a]）
       L = i，R = n-1-i；la = cntL[a]，ra = cntR[a]；lo = L-la，ro = R-ra
       # ① t >= 2 的 6 种组合
       ans += C(la,2)*C(ro,2)      # t=2，两个 a 都来自左
            + la*lo * ra*ro         # t=2，左右各一个 a
            + C(lo,2)*C(ra,2)       # t=2，两个 a 都来自右
            + C(la,2)*ra*ro         # t=3
            + la*lo*C(ra,2)         # t=3
            + C(la,2)*C(ra,2)       # t=4
       # ② t = 1，a 来自左侧
       if la > 0 and lo > 0 and ro >= 2:
           ans += la * Σ_{p < i, nums[p] != a} V(nums[p])
       # ③ t = 1，a 来自右侧
       if ra > 0 and ro > 0 and lo >= 2:
           ans += ra * Σ_{q > i, nums[q] != a} V'(nums[q])
       把 nums[i] 加入左半（cntL[a]++，eqL += 旧 cntL[a]）
4. return ans mod 1e9+7
```

注意 ②③ 里对「每个位置」求和，而不是对「每个不同值」求和——同一值在左半出现多次时，每一次作为 $u$ 都是一次不同的选择，正好由 $\sum_{p}$ 逐个计入（等价于按值归并后乘上出现次数）。

### 3.5 示例演算

![示例 2 的逐个中间位置演算](images/bw146_q4_walkthrough.svg)

以示例 2 的 `nums = [1,2,2,3,3,4]` 为例，逐中间位置统计（$a$ 为中间值）：

| $i$ | $a$ | 左半 | 右半 | 合法子序列数 | 说明 |
|-----|-----|------|------|--------------|------|
| 0 | 1 | 空 | $[2,2,3,3,4]$ | 0 | 左侧取不到 2 个 |
| 1 | 2 | $[1]$ | $[2,3,3,4]$ | 0 | 左侧只有 1 个元素 |
| 2 | 2 | $[1,2]$ | $[3,3,4]$ | 2 | 左必须取 $\{1,2\}$（$t=1$）；右取 $\{3,4\}$ 的两种（凑成 $\{1,2,3,4\}$ 的三个非 $a$ 元素互异），取 $\{3,3\}$ 则 3 出现 2 次与 $a$ 并列 ✗ |
| 3 | 3 | $[1,2,2]$ | $[3,4]$ | 2 | 右必须取 $\{3,4\}$（$t=1$）；左取 $\{1,2\}$ 的两种（两个 2 任选其一） |
| 4 | 3 | $[1,2,2,3]$ | $[4]$ | 0 | 右侧只有 1 个元素 |
| 5 | 4 | $[1,2,2,3,3]$ | 空 | 0 | 右侧取不到 2 个 |

合计 $2 + 2 = 4$，与输出一致。示例 1 全部元素为 1 时，只有 $t = 4$ 项非零：$i = 2$ 贡献 $\binom{2}{2}\binom{3}{2} = 3$，$i = 3$ 贡献 $\binom{3}{2}\binom{2}{2} = 3$，合计 6。

## 4. 算法细节

1. **离散化**：`nums[i]` 可达 $10^9$，先映射成 $0 \sim D-1$ 的编号，后续才能用数组做 $O(1)$ 计数（C++ 用 `unordered_map` 或排序去重 + 二分）。
2. **左右半的增量维护**：$i$ 从小到大扫描，右半是「后缀」，每次先 `cntR[a]--`、`eqR -= cntR[a]`（新的重复对数）；处理完 $i$ 之后 `cntL[a]++`、`eqL += cntL[a] - 1`（即旧的 `cntL[a]`）。这两个增量公式来自 $\binom{c}{2} - \binom{c-1}{2} = c-1$。
3. **$t \ge 2$ 的 6 项不能合并**：它们分别对应「$t=2$ / $t=3$ / $t=4$」与「$a$ 从哪一侧来」的组合，必须逐项列出，漏一项就少算。
4. **$t = 1$ 的容斥要减两件东西**：$eqR$ 里既包含 $a$ 的同值对，也包含 $u$ 的同值对，两项都必须剔除，写成 $\binom{ro-R_u}{2} - eqR + \binom{ra}{2} + \binom{R_u}{2}$。
5. **剪枝条件**：$la > 0$、$lo > 0$、$ro \ge 2$ 缺一不可（否则 $V$ 恒为 0）；加上剪枝还能避免 $eqR$ 计算出无意义的中间负值。
6. **取模**：单项可能达到 $\binom{500}{2}^2 \approx 1.5 \times 10^{10}$，C++ 用 `long long` 累加，最后统一取模；Python 无此问题但也要在循环内取模防止数值过大。
7. **复杂度**：每个 $i$ 扫一遍左侧与右侧，合计 $O(n^2)$；$n = 1000$ 时约 $10^6$ 次运算。

## 5. 正确性证明

**引理 1（$t$ 的判定）**：设中间位置为 $i$、$a = \text{nums}[i]$，两侧 4 个元素中等于 $a$ 的个数为 $t$。则「$a$ 是这 5 个元素的唯一众数」当且仅当

$$t \ge 2,\quad \text{或者}\quad \big(t = 1 \text{ 且另外 3 个元素两两不同}\big)$$

**证明**：$a$ 的总出现次数为 $1 + t$。「唯一众数」要求所有 $v \ne a$ 满足 $\text{cnt}(v) \le t$（严格小于 $1+t$）。

- $t = 0$：另外 4 个元素都 $\ne a$，它们出现次数之和为 4，故至少有一个 $v$ 出现 $\ge 1 = t$ 次，不满足 $\text{cnt}(v) \le t = 0$。✗
- $t = 1$：另外 3 个元素和不为 $a$，和为 3。若其中有两个相同值，则该值出现 $\ge 2 > t = 1$，✗；若三者两两不同，则每个只出现 1 次 $\le 1$，✓。
- $t \ge 2$：另外 $4 - t \le 2$ 个元素，任何非 $a$ 值出现次数 $\le 4 - t \le 2 \le t$，✓。

综上，充要条件得证。∎

**引理 2（$t \ge 2$ 的计数完备）**：设左半有 $la$ 个 $a$、$lo$ 个非 $a$，右半有 $ra$ 个 $a$、$ro$ 个非 $a$。则「$t \ge 2$ 的选择数」恰为 §3.4 中 ① 的 6 项之和。

**证明**：$t \ge 2$ 时，从两侧各选 2 个元素、其中恰有 $x$ 个 $a$ 来自左、$y$ 个 $a$ 来自右，$x + y = t \ge 2$，且 $x, y \in \{0,1,2\}$，左选 $x$ 个 $a$ 与 $2-x$ 个非 $a$ 的方案数为 $\binom{la}{x}\binom{lo}{2-x}$，右侧同理。逐项列出 $(x,y) \in \{(2,0),(1,1),(0,2),(2,1),(1,2),(2,2)\}$ 即得 6 项，它们互斥且穷尽所有 $t \ge 2$ 的情形，故求和即总数。∎

**引理 3（$t = 1$ 的容斥正确）**：固定「多出的 $a$ 来自左半」，再固定左半那个非 $a$ 元素 $u$（值记为 $u$，右半出现 $R_u$ 次）。则右半合法的 2 元素选择数为

$$V(u) = \binom{ro - R_u}{2} - \Big[eqR - \binom{ra}{2} - \binom{R_u}{2}\Big]$$

**证明**：右半必须选 2 个**非 $a$** 元素（因为 $t = 1$ 且 $a$ 已由左半贡献），故候选池为右半的非 $a$ 元素，共 $ro$ 个。又要求这 2 个元素的值既不为 $u$、彼此也不相同：先剔除值等于 $u$ 的 $R_u$ 个元素，剩 $ro - R_u$ 个，任取 2 个有 $\binom{ro - R_u}{2}$ 种；其中「两元素同值」的被多算了，需要减去。同值对总数在右半全体上是 $eqR$，其中值为 $a$ 的对有 $\binom{ra}{2}$ 个（已不在候选池中）、值为 $u$ 的对有 $\binom{R_u}{2}$ 个（已被第一步剔除），故候选池内的同值对为 $eqR - \binom{ra}{2} - \binom{R_u}{2}$。相减即得 $V(u)$。∎

**引理 4（无重复计数）**：不同的中间位置 $i$ 统计到的五元组互不相同；同一 $i$ 下，§3.4 的 ①②③ 三部分互不重叠。

**证明**：一个五元组 $i_0 < \dots < i_4$ 的「中间位置」唯一确定为 $i_2$，故按中间位置分类是划分而非覆盖。对同一 $i$，① 统计 $t \ge 2$ 的情形、② 统计「$t = 1$ 且多出的 $a$ 在左」、③ 统计「$t = 1$ 且多出的 $a$ 在右」，$t$ 取值与 $a$ 的来源共同构成互斥完备的分类。∎

**定理**：算法返回值为满足条件的长度 5 子序列个数（模 $10^9+7$）。

**证明**：由引理 4，全部合法五元组被唯一地分配到某个 $(i, \text{类别})$ 中；由引理 1，每类中的计数条件正是合法性条件；由引理 2、引理 3，②③ 与 ① 的计数公式分别精确数出对应类别的方案数。故累加结果恰为合法五元组总数。∎

## 6. 复杂度分析

- **离散化**：排序去重 $O(n \log n)$。
- **扫描与计数**：对每个 $i$，$t \ge 2$ 的 6 项为 $O(1)$；$t = 1$ 的两侧求和分别扫左半与右半，合计 $O(n)$。故总时间 $O(n^2)$，$n = 1000$ 时约 $10^6$ 次基本运算。
- **空间**：$O(n + D)$ 的计数数组与离散化表，$D \le n$。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <algorithm>
#include <unordered_map>

using namespace std;

class Solution {
public:
    int subsequencesWithMiddleMode(vector<int>& nums) {
        const int MOD = 1000000007;
        int n = (int)nums.size();

        vector<int> sorted = nums;
        sort(sorted.begin(), sorted.end());
        sorted.erase(unique(sorted.begin(), sorted.end()), sorted.end());
        unordered_map<int, int> id;
        for (int i = 0; i < (int)sorted.size(); i++) id[sorted[i]] = i;
        int D = (int)sorted.size();
        vector<int> a(n);
        for (int i = 0; i < n; i++) a[i] = id[nums[i]];

        auto C2 = [](long long x) -> long long {
            return x >= 2 ? x * (x - 1) / 2 : 0;
        };

        vector<int> cntR(D, 0), cntL(D, 0);
        for (int v : a) cntR[v]++;
        long long eqR = 0, eqL = 0;
        for (int v = 0; v < D; v++) eqR += C2(cntR[v]);

        long long ans = 0;
        for (int i = 0; i < n; i++) {
            int m = a[i];
            cntR[m]--;
            eqR -= cntR[m];

            long long left = i, right = n - 1 - i;
            long long lm = cntL[m], rm = cntR[m];
            long long lo = left - lm, ro = right - rm;

            long long total = C2(lm) * C2(ro) + lm * lo * rm * ro + C2(lo) * C2(rm)
                            + C2(lm) * rm * ro + lm * lo * C2(rm) + C2(lm) * C2(rm);

            if (lm > 0 && lo > 0 && ro >= 2) {
                long long s = 0;
                for (int p = 0; p < i; p++) {
                    int u = a[p];
                    if (u == m) continue;
                    s += C2(ro - cntR[u]) - eqR + C2(rm) + C2(cntR[u]);
                }
                total += lm * s;
            }
            if (rm > 0 && ro > 0 && lo >= 2) {
                long long s = 0;
                for (int q = i + 1; q < n; q++) {
                    int u = a[q];
                    if (u == m) continue;
                    s += C2(lo - cntL[u]) - eqL + C2(lm) + C2(cntL[u]);
                }
                total += rm * s;
            }

            ans = (ans + total) % MOD;
            cntL[m]++;
            eqL += lm;
        }
        return (int)ans;
    }
};
```

### Python

```python
class Solution:
    def subsequencesWithMiddleMode(self, nums: list[int]) -> int:
        MOD = 10 ** 9 + 7
        n = len(nums)
        comp = {v: i for i, v in enumerate(sorted(set(nums)))}
        a = [comp[v] for v in nums]
        D = len(comp)

        def c2(x: int) -> int:
            return x * (x - 1) // 2 if x >= 2 else 0

        cnt_r = [0] * D
        for v in a:
            cnt_r[v] += 1
        eq_r = sum(c2(c) for c in cnt_r)
        cnt_l = [0] * D
        eq_l = 0

        ans = 0
        for i in range(n):
            m = a[i]
            cnt_r[m] -= 1
            eq_r -= cnt_r[m]

            left, right = i, n - 1 - i
            lm, rm = cnt_l[m], cnt_r[m]
            lo, ro = left - lm, right - rm

            total = (c2(lm) * c2(ro) + lm * lo * rm * ro + c2(lo) * c2(rm)
                     + c2(lm) * rm * ro + lm * lo * c2(rm) + c2(lm) * c2(rm))

            if lm and lo and ro >= 2:
                s = 0
                for p in range(i):
                    u = a[p]
                    if u != m:
                        s += c2(ro - cnt_r[u]) - eq_r + c2(rm) + c2(cnt_r[u])
                total += lm * s

            if rm and ro and lo >= 2:
                s = 0
                for q in range(i + 1, n):
                    u = a[q]
                    if u != m:
                        s += c2(lo - cnt_l[u]) - eq_l + c2(lm) + c2(cnt_l[u])
                total += rm * s

            ans = (ans + total) % MOD
            cnt_l[m] += 1
            eq_l += lm
        return ans
```

## 8. 边界情况与易错点

1. **$t = 0$ 一律不合法**：很容易漏掉「$m = 1$ 不严格大于其他值的 1 次」这个细节，误把「全不同」的情形算进去（示例 3 专门考这一点）。
2. **$t = 1$ 必须检查「其余三个两两不同」**：示例 2 中 `[1,2,2,3,4]` 合法、`[1,2,3,3,4]` 合法，而 `[1,2,2,3,4]` 若把右侧选成两个 3 就退化为「2 与 3 并列」，正是容斥要排除的情形。
3. **容斥别漏项**：$V(u) = \binom{ro - R_u}{2} - eqR + \binom{ra}{2} + \binom{R_u}{2}$，少减 $eqR$ 或多减 $\binom{R_u}{2}$ 都会导致系统性偏差（本题最隐蔽的 bug，建议用小数据对拍验证）。
4. **左右对称性**：③ 与 ② 的公式只把 $ro/ra/eqR$ 换成 $lo/la/eqL$，不要顺手写成同一个变量。
5. **`eqR` 的维护顺序**：必须先把当前元素从右半移出，再计算 $ra$，否则 $ra$ 会多算一个 $a$。
6. **$n = 5$**：只有 1 个五元组，答案只能是 0 或 1；注意 `c2()` 在 $x < 2$ 时返回 0，避免出现负数。
7. **取模**：C++ 中 `total` 可能为 $10^{10}$ 量级，`long long` 足够；Python 任意精度，但循环内取模能避免大整数拖慢速度。
8. **离散化后的编号**：C++ 用 `unordered_map` 时注意不要把 `id[nums[i]]` 写成 `id[i]`。

**延伸思考**：如果把这道模型放大到 $n \approx 10^5$（II 版的量级），$O(n^2)$ 的逐位置扫描会超时。此时需要把 ②③ 里的 $\sum_{p} V(\text{nums}[p])$ 改写成「按值归并」的形式：对每个值 $v$，$\binom{ro - R_v}{2}$ 与 $R_v$ 相关，而 $eqR, \binom{ra}{2}$ 对所有 $v$ 相同，于是只需统计每个值在左半的出现次数 $L_v$，并把 $\sum_v L_v \binom{ro - R_v}{2}$ 维护起来——用树状数组或对每个值单独维护「左右计数」即可做到 $O(n \log n)$。这也说明：本题的 $O(n^2)$ 并非最优，只是 $n \le 1000$ 下最直观的写法。
