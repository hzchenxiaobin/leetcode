# LeetCode 统计异或值为给定值的路径数目 题解

## 1. 题目概述

- **标题 / 题号**：统计异或值为给定值的路径数目（#3393，medium）
- **链接**：https://leetcode.cn/problems/count-paths-with-the-given-xor-value/
- **来源**：LeetCode 第 146 场双周赛 Q2
- **难度**：中等
- **标签**：位运算、数组、动态规划、矩阵

**题意**：给定 $m \times n$ 的非负整数矩阵 `grid` 与整数 $k$。从左上角 $(0,0)$ 出发，每步只能**向右**或**向下**走到右下角 $(m-1, n-1)$。统计「路径上所有数字（含起点与终点）的异或值恰为 $k$」的路径数目，答案对 $10^9 + 7$ 取模。

**约束**：

- $1 \le m = \text{grid.length} \le 300$，$1 \le n = \text{grid}[r]\text{.length} \le 300$
- $0 \le \text{grid}[r][c] < 16$
- $0 \le k < 16$

> 💡 题眼：**$\text{grid}$ 的每个元素都小于 $16$**，而异或运算不会把位数「越算越大」，所以路径的异或值永远落在 $[0, 15]$ 这 **16 个**可能值里。于是「路径异或值」可以作为 DP 的一维状态，状态总数只有 $300 \times 300 \times 16$。

## 2. 示例

**示例 1**

```text
输入：grid = [[2,1,5],[7,10,0],[12,6,4]], k = 11
输出：3
解释：3 x 3 矩阵的单调路径共有 C(4,2) = 6 条，其中 3 条的异或值为 11：
      (0,0)→(1,0)→(2,0)→(2,1)→(2,2)：2⊕7⊕12⊕6⊕4 = 11
      (0,0)→(1,0)→(1,1)→(1,2)→(2,2)：2⊕7⊕10⊕0⊕4 = 11
      (0,0)→(0,1)→(1,1)→(2,1)→(2,2)：2⊕1⊕10⊕6⊕4 = 11
```

**示例 2**

```text
输入：grid = [[1,3,3,3],[0,3,3,2],[3,0,1,1]], k = 2
输出：5
```

**示例 3**

```text
输入：grid = [[1,1,1,2],[3,0,3,2],[3,0,2,2]], k = 10

```


## 3. 解题思路

### 3.1 暴力思路

枚举所有单调路径（从 $(0,0)$ 到 $(m-1,n-1)$ 共有 $\binom{m+n-2}{m-1}$ 条），逐条算异或值。

$m = n = 300$ 时路径数约 $\binom{598}{299} \approx 10^{178}$，这是天文数字。暴力没有任何优化空间——必须换思路：**把「路径」的枚举换成「状态」的递推**。

### 3.2 核心观察：异或值只有 16 种可能

![异或值的取值空间被 4 位截断，只需要 16 个桶](images/bw146_q2_state_space.svg)

**观察 1（值域封闭）**：$\text{grid}[r][c] < 16$ 说明每个数最多 4 个二进制位。异或不会增加位数，所以路径异或值 $X \in [0, 15]$。这是整个 DP 能「把值域塞进数组」的前提。

**观察 2（最优子结构）**：设 $P$ 是一条到达 $(i,j)$ 的路径，其异或值为 $X$。那么把 $(i,j)$ 的值异或进来得到 $X \oplus \text{grid}[i][j]$，而这个新值**只依赖 $X$**，与路径的具体形状无关。因此到达 $(i,j)$ 且异或值为 $x$ 的路径条数，可以由「到达 $(i-1,j)$ 与 $(i,j-1)$ 的路径条数」按 $x$ 分类求和得到。

**观察 3（两条入边）**：到达 $(i,j)$ 的最后一步要么来自上方 $(i-1,j)$，要么来自左方 $(i,j-1)$。两个来源的路径集合**不重叠**（倒数第二步位置不同），所以条数可以安全相加。

于是定义

$$dp[i][j][x] = \text{从 } (0,0) \text{ 走到 } (i,j) \text{、且异或值为 } x \text{ 的路径条数}$$

转移（$(i,j) \ne (0,0)$，令 $g = \text{grid}[i][j]$）：

$$dp[i][j][x \oplus g] \mathrel{+}= dp[i-1][j][x] + dp[i][j-1][x]$$

初值 $dp[0][0][\text{grid}[0][0]] = 1$，答案 $dp[m-1][n-1][k]$。

> ⚠️ 注意方向：入边是「来自 $x$」，出边是「变成 $x \oplus g$」。写反（把 $g$ 异或到入边）会得到完全不同的结果。

### 3.3 算法流程

![状态转移：一个格子从上方与左方两个格子按异或值聚合](images/bw146_q2_dp_transfer.svg)

```text
1. dp[m][n][16] 全 0；dp[0][0][grid[0][0]] = 1
2. for i = 0 .. m-1:
       for j = 0 .. n-1:
           if (i, j) == (0, 0): continue
           g = grid[i][j]
           for x = 0 .. 15:
               ways = (i > 0 ? dp[i-1][j][x] : 0) + (j > 0 ? dp[i][j-1][x] : 0)
               if ways > 0:
                   dp[i][j][x ^ g] = (dp[i][j][x ^ g] + ways) % MOD
3. return dp[m-1][n-1][k]
```

由于转移只依赖上方一行与左方一格，实际实现可以用**滚动数组**把空间从 $O(mn \cdot 16)$ 压到 $O(n \cdot 16)$；下文代码保留三维写法以便对照公式，空间 $300 \times 300 \times 16 \times 4\text{B} \approx 5.8\text{ MB}$，完全可以接受。

## 4. 算法细节

1. **异或值域**：因为 $\text{grid}$ 值 $<16$，DP 第三维开 $16$ 足够。若把题目放宽到 $<2^{10}$，就开 $1024$，道理不变。
2. **转移方向**：先算 `ways`（来自上/左的旧异或值 $x$ 的条数），再把它加到 `x ^ g` 上。不要写成 `dp[i][j][x] += dp[i-1][j][x ^ g]`（那是把 $g$ 算进了来路，等价于把当前格算了两次）。
3. **取模时机**：`ways` 用 `long long` 累加两个已取模的值（$< 2 \times 10^9$，不会溢出 `int`，但用 `long long` 更稳），加进 DP 后再取模。
4. **起点初始化**：$dp[0][0][\text{grid}[0][0]] = 1$，**不是** $dp[0][0][0] = 1$。若把起点当「空路径」处理，最后会漏掉起点的值。
5. **单行/单列**：$m = 1$ 或 $n = 1$ 时，每个格子只有一个入边，代码里的 `i > 0` / `j > 0` 判断自然处理。
6. **滚动数组优化**：由于 `dp[i][j]` 只依赖 `dp[i-1][j]` 与 `dp[i][j-1]`，可以只保留一维 `dp[j][x]`（行内从左到右更新即可，因为 `dp[j-1]` 已是本行的新值）。这是把空间降到 $O(n \cdot 16)$ 的标准做法。

## 5. 正确性证明

**引理 1（值域封闭）**：任何从 $(0,0)$ 到 $(m-1,n-1)$ 的路径，其异或值都在 $[0, 15]$ 内。

**证明**：每个 $\text{grid}[r][c] < 16$，即二进制最高位不超过第 3 位。异或运算逐位独立，结果的第 $b$ 位只依赖各操作数的第 $b$ 位，因此结果也不会出现第 4 位及更高位，值域为 $[0, 2^4 - 1]$。∎

**引理 2（路径分解唯一）**：任意到达 $(i,j)$（$(i,j) \ne (0,0)$）的路径，去掉最后一步后唯一对应一条到达 $(i-1,j)$ 或 $(i,j-1)$ 的路径；且这两类路径集合不相交。

**证明**：路径的最后一步只能是「从上方下移」或「从左方右移」，二者互斥，对应去掉末格后的前缀路径终点分别为 $(i-1,j)$、$(i,j-1)$，故分解唯一、两类不交。∎

**引理 3（DP 不变式）**：按算法填完表后，对任意 $(i,j)$ 与 $x \in [0,15]$，$dp[i][j][x]$ 恰为「从 $(0,0)$ 到 $(i,j)$、异或值为 $x$ 的路径条数」（模 $10^9+7$）。

**证明**：对 $i + j$ 归纳。

- 基础：$(0,0)$ 只有一条「长度为 0 步」的路径，其异或值是 $\text{grid}[0][0]$，与初始化一致。
- 归纳：设 $(i,j) \ne (0,0)$，且所有 $i' + j' < i + j$ 的格子已满足不变式。由引理 2，到 $(i,j)$ 且异或值为 $y$ 的路径，按最后一步分成「末步来自上方」与「末步来自左方」两部分。来自上方的那部分，其前缀异或值必为 $x = y \oplus \text{grid}[i][j]$（因为 $x \oplus \text{grid}[i][j] = y$），条数为 $dp[i-1][j][x]$；左方同理为 $dp[i][j-1][x]$。两部分相加，正是算法在 $x = y \oplus g$ 时执行的累加，覆盖了全部可能，无重复无遗漏。∎

**定理**：算法返回值为异或值等于 $k$ 的单调路径条数（模 $10^9+7$）。

**证明**：取 $(i,j) = (m-1,n-1)$、$x = k$，由引理 3 即得。∎

## 6. 复杂度分析

- **状态数**：$m \times n \times 16$。
- **转移**：每个状态 $O(1)$（常数次加法和一次异或）。
- **时间**：$O(mn \cdot 16)$，$m = n = 300$ 时约 $1.44 \times 10^6$ 次操作。
- **空间**：三维写法 $O(mn \cdot 16)$，约 $5.8\text{ MB}$；滚动数组写法 $O(n \cdot 16)$。

## 7. 参考代码

### C++

```cpp
#include <vector>

using namespace std;

class Solution {
public:
    int countPathsWithXorValue(vector<vector<int>>& grid, int k) {
        const int MOD = 1000000007;
        int m = (int)grid.size(), n = (int)grid[0].size();
        vector<vector<vector<int>>> dp(m, vector<vector<int>>(n, vector<int>(16, 0)));
        dp[0][0][grid[0][0]] = 1;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (i == 0 && j == 0) continue;
                for (int x = 0; x < 16; x++) {
                    long long ways = 0;
                    if (i > 0) ways += dp[i - 1][j][x];
                    if (j > 0) ways += dp[i][j - 1][x];
                    if (ways == 0) continue;
                    int y = x ^ grid[i][j];
                    dp[i][j][y] = (int)((dp[i][j][y] + ways) % MOD);
                }
            }
        }
        return dp[m - 1][n - 1][k];
    }
};
```

### Python

```python
class Solution:
    def countPathsWithXorValue(self, grid: list[list[int]], k: int) -> int:
        MOD = 10 ** 9 + 7
        m, n = len(grid), len(grid[0])
        dp = [[[0] * 16 for _ in range(n)] for _ in range(m)]
        dp[0][0][grid[0][0]] = 1
        for i in range(m):
            for j in range(n):
                if i == 0 and j == 0:
                    continue
                s_xor = grid[i][j]
                for x in range(16):
                    ways = 0
                    if i > 0:
                        ways += dp[i - 1][j][x]
                    if j > 0:
                        ways += dp[i][j - 1][x]
                    if ways:
                        y = x ^ s_xor
                        dp[i][j][y] = (dp[i][j][y] + ways) % MOD
        return dp[m - 1][n - 1][k]
```

## 8. 边界情况与易错点

1. **起点初始化**：必须是 $dp[0][0][\text{grid}[0][0]] = 1$。写成 $dp[0][0][0] = 1$ 会把起点「当作空路径」漏算，单格矩阵直接错。
2. **转移方向别写反**：是「旧异或值 $x$ 的条数搬到 $x \oplus g$」，不是「从 $x \oplus g$ 搬到 $x$」。
3. **取模位置**：两个入边之和已达 $2 \times 10^9$ 量级，用 `long long` 或先模后加；C++ 里 `int` 相加再取模在极端情况下（两个都接近 $10^9+6$）会溢出 `int`。
4. **`%` 与负数**：本题数值非负，无此问题；但注意 Python 的 `%` 与 C++ 在负数上语义不同，若改成有符号异或输入需留意。
5. **单格矩阵**：$m = n = 1$ 时答案为 $[\text{grid}[0][0] = k]$，循环体一次都不执行，直接返回初值。
6. **$k \ge 16$ 不会发生**：约束保证 $k < 16$，若为健壮性考虑，可以提前 `if (k > 15) return 0;`。
7. **异或值维度的上界**：若把第三维错开成 $16$ 以外的数（如按 $\max(\text{grid})$ 开），会越界；固定用 $16$ 最安全。
