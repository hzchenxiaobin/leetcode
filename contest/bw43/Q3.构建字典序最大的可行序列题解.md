# LeetCode 构建字典序最大的可行序列 题解

## 1. 题目概述

- **标题 / 题号**：构建字典序最大的可行序列（#1718，medium）
- **链接**：https://leetcode.cn/problems/construct-the-lexicographically-largest-valid-sequence/
- **来源**：LeetCode 第 43 场双周赛 Q3
- **难度**：中等
- **标签**：数组、回溯

**题意**：给定 $n$，构造长为 $2n-1$ 的序列，使得：数字 $1$ **恰好出现一次**；$2 \sim n$ 每个数**恰好出现两次**，且两个 $i$ 的下标距离（差的绝对值）恰为 $i$。要求返回其中**字典序最大**的序列。题目保证解存在。

**约束**：

- $1 \le n \le 20$

## 2. 示例

**示例 1**

```text
输入：n = 3
输出：[3,1,2,3,2]
解释：[2,3,2,1,3] 也合法，但 [3,1,2,3,2] 字典序更大。
```

**示例 2**

```text
输入：n = 5
输出：[5,3,1,4,3,5,2,4,2]
```

**边界示例**

```text
输入：n = 1
输出：[1]
解释：序列长 2×1−1 = 1，唯一的数就是 1。
```

## 3. 解题思路

### 3.1 暴力思路

把多重集 $\{1, 2,2, 3,3, \dots, n,n\}$ 的所有排列枚举一遍，逐个检查距离约束，取合法者中字典序最大的。$n = 6$ 时已有 $11!/2^5 \approx 1.2 \times 10^6$ 个排列，$n = 20$ 完全不可行。但枚举思路给了正确的对拍基准（小规模），也提示了重要事实：**答案不唯一时比的是最左边的差异位**。

### 3.2 核心观察：位置从左到右填、值从大到小试

![目标序列的结构：两个相同数字的距离约束](images/bw43_q3_structure.svg)

两个关键观察把搜索空间砍到极小：

1. **只关心第一个空位**。设 $pos$ 是当前最靠前的空位。任何未使用的数字 $v \ge 2$ 放在 $pos$，它的另一个副本只能放在 $pos + v$：因为 $pos - v < pos$ 的位置都已填好且填的是别的数字（$v$ 还没用过），不可能容纳第二个 $v$。于是「放哪个数」是唯一自由度，不存在「放哪个位置」的自由度。
2. **字典序 = 越靠左的位越优先**。若在 $pos$ 放 $v$ 能走到底、放 $v' < v$ 也能走到底，则前者必字典序更大（前面的位完全相同）。所以**从大到小试**，第一个成功的值就是最优的。

数字 $1$ 特殊：只出现一次，所以把它放在 $pos$ 本身（没有第二个副本）。

### 3.3 回溯流程

![回溯流程图：从大到小试值，失败则撤销](images/bw43_q3_backtrack_tree.svg)

```text
dfs(pos)：
    若 pos 走到头 → 成功，一路返回 true
    若 seq[pos] 已被占用 → 直接看 pos+1
    for v = n … 2（从大到小）：
        若 v 未用且 pos+v 在界内且为空：
            放置 v 于 pos 和 pos+v；递归；成功 → 返回；失败 → 撤销
    若 1 未用：放置 1 于 pos；递归；失败 → 撤销
    返回 false
```

### 3.4 示例演算

![n 等于 5 的回溯演算，含一次贪大失败与回溯](images/bw43_q3_walkthrough.svg)

以 $n = 5$ 为例：`pos0` 放 5；`pos1` 想放 4 但 $1+4=5$ 已被占，退而放 3；`pos2` 先试 4（放 2 和 6）——但这样后面 `pos7` 需要放 2 而 $7+2=9$ 越界，整支死掉；回溯后 `pos2` 放 1；`pos3` 放 4；`pos6` 放 2，全部填满，得到 $[5,3,1,4,3,5,2,4,2]$。注意**回溯是必要的一步**，纯贪心（只试最大）会在 `pos2` 卡死。

## 4. 算法细节

1. **两个辅助数组**：`seq`（当前序列，0 表示空）与 `used[v]`（数字 v 是否已放置）。放置 $v \ge 2$ 时同时写 `seq[pos]` 与 `seq[pos+v]`。
2. **剪枝条件**：`pos+v < len` 且 `seq[pos+v] == 0` 且 `!used[v]` 三者同时成立才尝试；缺一不可。
3. **1 的处理放在循环之后**：因为它只有一个副本、且是最小的候选值，最后尝试符合「从大到小」的次序。
4. **成功即返回**：用一个 `bool` 返回值层层短路，避免找到解后继续搜索。
5. **复杂度的直觉**：$n \le 20$、序列长 39，每层只有少量候选；又因解存在且「贪大」大体正确，回溯非常浅。实测最大 $n = 20$ 也是毫秒级。
6. **为什么不会漏解**：搜索在每个空位上枚举了所有能自洽的值，并完整回溯；由题面保证有解，`dfs(0)` 必然返回 `true`。

## 5. 正确性证明

**引理 1（放置位置的唯一性）**：在任何合法序列 $T$ 中，设 $p$ 是 $T$ 中第一个出现 $v$（$v \ge 2$）的下标，则另一处 $v$ 在 $p + v$；并且 $T$ 的每个前缀里，若 $p$ 是尚未填写的最左位置，$T[p]$ 是某个尚未「配完对」的数字。

**证明**：两个 $v$ 的下标差恰为 $v$，故另一处在 $p - v$ 或 $p + v$。若在 $p - v$：则 $p - v < p$，即第一个 $v$ 出现得更早，与 $p$ 是第一处矛盾（序列中先出现的 $v$ 才使 $p-v$ 处有值）。∎

（更精确地说：若当前序列已按算法填好前缀，且 $v$ 未使用，那么第一个空位 $pos$ 左侧没有任何 $v$，因此 $v$ 的两处只能落在 $pos$ 与 $pos+v$——**搜索的每一步都不损失任何解**。）

**引理 2（贪大正确性）**：设当前前缀 $S$（含部分数字的已放置副本）相同，$v^*$ 为「使 $S$ 能扩展成完整合法序列」的最大可放值。则算法在 $pos$ 依次尝试 $n, n-1, \dots$，只有尝试到 $v^*$ 才会最终成功，更小的值之前的失败不影响最优性。

**证明**：算法按从大到小的顺序试值，每个值的子树被完整搜索。若某个 $v > v^*$ 的子树返回成功，则存在以值 $v$ 扩展 $S$ 的完整解，与 $v^*$ 的最大性矛盾；故所有 $v > v^*$ 的尝试都失败，算法最终在 $v^*$ 处成功。∎

**定理（字典序最大）**：算法返回的第一个完整解即字典序最大的合法序列。

**证明**：对差异位归纳。设 $T^*$ 为字典序最大的合法序列，算法输出 $A$。两者若不同，设第一个差异下标为 $i$；在 $i$ 之前算法的每一步选择都与 $T^*$ 一致——因为：前缀相同时，$T^*$ 在下一空位的取值 $t$ 是可扩展的（扩展成 $T^*$ 本身），由引理 2，算法在该位会取到「可扩展的最大值」$v^* \ge t$，若 $v^* > t$ 则 $A$ 在 $i$ 处更大，与 $i$ 是首个差异矛盾（说明 $v^* = t$，前缀继续一致）；若处处一致则 $A = T^*$。又因算法输出合法（每步满足距离约束、used 保证次数），归纳成立，$A = T^*$。∎

> ⚠️ 引理 1 依赖「1 只出现一次、其余数字恰两次」的题设：若允许 $v$ 出现三次，「另一端必在 $pos+v$」不再成立，需要更复杂的枚举。

## 6. 复杂度分析

- **时间**：最坏 $O(n!)$ 级别，但实际搜索树极窄（每层有效候选约 $O(n)$，剪枝 + 题目保证有解），$n \le 20$ 毫秒出解。若需要多项式界，可理解为「输出敏感」算法。
- **空间**：$O(n)$——序列与 used 数组、递归深度 $\le 2n-1$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> constructDistancedSequence(int n) {
        int len = 2 * n - 1;
        vector<int> seq(len, 0);
        vector<char> used(n + 1, 0);
        dfs(seq, used, 0, n);
        return seq;
    }
private:
    bool dfs(vector<int>& seq, vector<char>& used, int pos, int n) {
        if (pos == (int)seq.size()) return true;          // 填满即成功
        if (seq[pos] != 0) return dfs(seq, used, pos + 1, n);  // 已被另一端占用
        for (int v = n; v >= 2; --v) {                   // 从大到小尝试放 v
            int j = pos + v;                             // 另一个 v 只能在 pos+v
            if (!used[v] && j < (int)seq.size() && seq[j] == 0) {
                seq[pos] = seq[j] = v;
                used[v] = 1;
                if (dfs(seq, used, pos + 1, n)) return true;
                seq[pos] = seq[j] = 0;                   // 回溯
                used[v] = 0;
            }
        }
        if (!used[1]) {                                  // 1 只出现一次，放当前位置
            seq[pos] = 1;
            used[1] = 1;
            if (dfs(seq, used, pos + 1, n)) return true;
            seq[pos] = 0;
            used[1] = 0;
        }
        return false;
    }
};
```

### Python

```python
class Solution:
    def constructDistancedSequence(self, n: int) -> list[int]:
        seq = [0] * (2 * n - 1)
        used = [False] * (n + 1)

        def dfs(pos: int) -> bool:
            if pos == len(seq):
                return True              # 全部填满即得答案
            if seq[pos] != 0:            # 该位置已被另一端占用
                return dfs(pos + 1)
            for v in range(n, 1, -1):    # 从大到小尝试放 v
                j = pos + v              # 另一个 v 只能在 pos+v
                if not used[v] and j < len(seq) and seq[j] == 0:
                    seq[pos] = seq[j] = v
                    used[v] = True
                    if dfs(pos + 1):
                        return True
                    seq[pos] = seq[j] = 0   # 回溯
                    used[v] = False
            if not used[1]:              # 1 只出现一次，放当前位置
                seq[pos] = 1
                used[1] = True
                if dfs(pos + 1):
                    return True
                seq[pos] = 0
                used[1] = False
            return False

        dfs(0)
        return seq
```

> 💡 两份代码均通过官方示例（`[3,1,2,3,2]`、`[5,3,1,4,3,5,2,4,2]`），$n = 1 \dots 6$ 与全排列枚举逐一比对一致，$n = 7 \dots 20$ 通过合法性校验，且 C++/Python 输出完全相同。

## 8. 边界情况与易错点

1. **$n = 1$**：序列就是 `[1]`，循环 `v = n..2` 不执行，1 落在 pos 0 ✓。
2. **忘了「1 只出现一次」**：把 1 也按两个副本放置会直接把序列撑长为 $2n$，输出全错；也正因 1 只出现一次，它永远是字典序上「最后的选择」。
3. **回溯必须两处一起撤销**：放置时写了 `seq[pos]` 与 `seq[pos+v]`，撤销漏掉任何一处或漏掉 `used[v]`，后续搜索会污染。
4. **`pos+v` 越界判断**：`j < len` 是严格小于；越界时该值不可能放在 $pos$（另一端必须存在），不要误把它放进去了再撤销。
5. **不要用「取剩余最小可用位置」代替「第一个空位」**：只有最靠前的空位才决定字典序优先级。
6. **复杂度侥幸心理**：纯贪心（不回溯）在 $n=5$ 就错了（见 3.4 的死支）；这题的正确性来自「贪大 + 完整回溯」的组合。
