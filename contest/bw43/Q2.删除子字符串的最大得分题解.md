# LeetCode 删除子字符串的最大得分 题解

## 1. 题目概述

- **标题 / 题号**：删除子字符串的最大得分（#1717，medium）
- **链接**：https://leetcode.cn/problems/maximum-score-from-removing-substrings/
- **来源**：LeetCode 第 43 场双周赛 Q2
- **难度**：中等
- **标签**：贪心、栈、字符串

**题意**：给字符串 `s` 与整数 $x, y$。每次可删除一个相邻子串 `"ab"` 得 $x$ 分，或删除 `"ba"` 得 $y$ 分；删除后两侧字符拼接，可能产生新的可删子串（连锁）。求最大总得分。

**约束**：

- $1 \le s.length \le 10^5$
- $1 \le x, y \le 10^4$
- `s` 只含小写字母

## 2. 示例

**示例 1**

```text
输入：s = "cdbcbbaaabab", x = 4, y = 5
输出：19
解释：先删 ba（+5），再删 ab（+4），再删两个 ba（+5+5），合计 19。
```

**示例 2**

```text
输入：s = "aabbaaxybbaabb", x = 5, y = 4
输出：20
```

**补充示例（x == y）**

```text
输入：s = "abba", x = 3, y = 3
输出：6
解释：删 (a,b) 与 (b,a) 各一对即可，两种顺序得分相同。
```

## 3. 解题思路

### 3.1 暴力思路

在当前串里枚举每一个出现的 `"ab"` / `"ba"`，任选一个删除后递归，取最大值。用记忆化（串 → 最大得分）可以压住重复状态，但最坏状态数仍是指数级，只适合 $|s| \le 12$ 的对拍。正解必须利用**贪心结构**：删除的顺序有明确的最优偏好。

### 3.2 核心观察：高分子串优先删，且两遍栈扫描互不干扰

![策略流程：比较 x 与 y 决定先删哪种子串](images/bw43_q2_greedy_order.svg)

直觉上 $x \ge y$ 时应当先把 `"ab"` 删干净再删 `"ba"`。这不是显然的——先删 `"ab"` 可能"用掉"本可凑成 `"ba"` 的字符——但可以证明：**按「高分优先」的两遍栈扫描同时达到「高分对数」与「总对数」两个理论最大值**（见 §5），因此不会吃亏。

`x == y` 时两种顺序得分相同；`y > x` 时对称地把 `"ba"` 放前面。代码里只需一次 `if`。

### 3.3 一遍栈扫描 = 连锁删除到底

![示例 1 两遍栈扫描走查](images/bw43_q2_stack_pass.svg)

删除某种子串不必反复扫：用**栈**一遍完成。以删 `"ab"` 为例：依次入栈，若当前字符是 `b` 且栈顶是 `a`，则弹栈并计分——这恰好等价于「反复删除所有相邻 `ab` 直到不存在」的最终结果，因为新产生的连锁机会一定由「刚弹掉一对后的新栈顶」暴露。

对示例 1（$x=4 < y=5$，先删 `"ba"`）：第一遍删 3 个 `ba` 得 15 分，剩余 `cdbcab`；第二遍删 1 个 `ab` 得 4 分，剩余 `cdbc`，总分 $19$ ✓。

### 3.4 关键结构：删光 "ab" 后的残余必是 b…b a…a

![残余串结构：栈内每段必为 b 的堆叠加 a 的堆叠](images/bw43_q2_residual_form.svg)

第一遍（删 `ab`）结束后栈内形态有个可爱的不变量：**某个 `a` 一旦入栈，之后入栈的 `b` 一定会把它弹掉**（`b` 只有在栈顶是 `a` 时才触发配对，否则入栈后 `a` 沉底）。于是栈里每个「无惰性字符段」都是若干个 `b` 在下、若干个 `a` 在上。设第一遍删了 $A^*$ 对、某段残余 $p$ 个 `b` 与 $q$ 个 `a`，则第二遍恰好再删 $\min(p,q)$ 对，且

$$A^* + \min(p,q) = \min(c_A, c_B),$$

其中 $c_A, c_B$ 是该段 `a`/`b` 总数——即**删除总对数达到「字符数」这一资源上界**。

## 4. 算法细节

1. **一遍栈扫描的正确实现**：判断条件是「栈顶 == first 且当前字符 == second」，两者缺一不可；弹栈后新栈顶可能又与下一个字符配对，连锁自动发生。
2. **第二遍的输入是第一遍的栈内容**（`join` 成字符串再扫一遍），不要直接在原串上再扫一次。
3. **顺序选择**：`x >= y` 先删 `ab`，否则先删 `ba`。两遍的模式串和得分作为参数传给同一个函数，避免复制代码。
4. **惰性字符免费隔离**：`c`、`d` 等非 `a`/`b` 字符永远不会被删，天然把串切成若干独立段，无需显式分段。
5. **计分类型**：最多删 $\lfloor |s|/2 \rfloor = 5\times 10^4$ 次、每次 $\le 10^4$ 分，总分 $\le 5\times 10^8$，`int` 可容纳但贴近上界，用 `long long` 累加更稳。
6. **复杂度**：两遍栈扫描各 $O(|s|)$，总 $O(|s|)$ 时间、$O(|s|)$ 空间。

## 5. 正确性证明

把一次完整过程看成一个**删除方案** $P$：一组互不相交的位置对（每个对是原串中一前一后两个字符），加上使每对在被删时刻相邻的删除顺序。每对要么是 `a` 前 `b` 后（**ab 对**），要么是 `b` 前 `a` 后（**ba 对**）。得分 $= x\cdot\#ab(P) + y\cdot\#ba(P)$。以下默认 $x \ge y$（$y > x$ 时把 `a`/`b` 角色互换即可）。

**引理 1（方案的结构限制）**：可行方案 $P$ 中，(i) 各对不相交；(ii) 任一对的两个字符之间没有惰性字符（非 `a`/`b`）；(iii) 任意两对不交叉（不存在 $x_1 < x_2 < y_1 < y_2$）。

**证明**：(i) 每个字符只删一次。(ii) 一对被删时中间字符已全部删光，而惰性字符永远删不掉。(iii) 若对 $(x_1,y_1)$ 与 $(x_2,y_2)$ 交叉：前者被删时要求 $x_2$ 已删，后者被删时要求 $y_1$ 已删，即"$x_2$ 所在的删除在 $(x_1,y_1)$ 之前"且"$(x_1,y_1)$ 在 $(x_2,y_2)$ 之前"……准确地说，$(x_1,y_1)$ 的删除时刻早于 $x_2$ 的删除时刻（即 $(x_2,y_2)$ 的时刻），而 $(x_2,y_2)$ 的删除时刻又早于 $y_1$ 的删除时刻（即 $(x_1,y_1)$ 的时刻），矛盾。∎

**引理 2（资源上界）**：每段内 $|P| \le \min(c_A, c_B)$——每次删除消耗一个 `a` 和一个 `b`。∎

**引理 3（高分对数上界）**：设 $A^*$ 为「栈式贪心删 `ab`」在该段删除的对数，则任何可行方案的 $\#ab(P) \le A^*$。

**证明**：由引理 1，$P$ 的所有 ab 对构成一个**两两不交叉、不跨惰性字符**的 `a` 前 `b` 后匹配。先证一般事实：对任一串 $t$，「两两不交叉、不跨惰性字符的 ab 匹配」的最大对数恰为贪心栈的对数 $A^*(t)$，对 $|t|$ 归纳：

- 若贪心一次都没弹栈：那么每个到达的 `b` 面对的栈顶都不是 `a`。若某段中存在 `a` 在 `b` 前面，取最靠左的这种 `b`，它前一个字符若是 `a` 则会触发弹栈，若是 `b` 则那个 `b` 同样有 `a` 在其前、与最靠左矛盾。故每段形如 `b…b a…a`，不存在任何 ab 对，最大匹配数 $0 = A^*$。
- 若贪心第一次弹栈发生在位置对 $(u, u+1)$（弹栈前没有任何删除，栈顶就是 $s[u]$，故它一定相邻）。对任意最大匹配 $M$：
  - 若 $(u,u+1) \in M$，直接归纳；
  - 若 $u$ 已匹配到 $v \ne u+1$：若 $u+1$ 未匹配，则 $M \cup \{(u,u+1)\}$ 是更大的不交叉匹配，矛盾于最大性（相邻对不与任何对交叉）；故 $u+1$ 匹配到某 $w < u$，把 $(w,u+1)$ 与 $(u,v)$ 换成 $(u,u+1)$ 与 $(w,v)$——新对不交叉也不跨惰性字符（区间被原两对覆盖），规模不变且含 $(u,u+1)$；
  - 若 $u$ 未匹配：则 $u+1$ 必已匹配到某 $w$（否则可加入 $(u,u+1)$），把 $(w,u+1)$ 换成 $(u,u+1)$，规模不变且含 $(u,u+1)$。
  
  于是存在含 $(u,u+1)$ 的最大匹配 $M^*$；删去 $(u,u+1)$ 后它在 $t' = t \setminus \{u, u+1\}$ 上仍是合法匹配，故 $\max(t) \le 1 + \max(t')$，再用归纳假设 $\max(t') \le A^*(t') = A^*(t) - 1$（贪心在第一次弹栈后行为与 $t'$ 完全一致）。∎

**引理 4（贪心同时把总对数删满）**：第一遍栈扫描后每段残余为 $p$ 个 `b` 接 $q$ 个 `a`（`b` 只有在栈顶非 `a` 时才会入栈，`a` 之上只会再堆 `a`）；第二遍删 `ba` 恰得 $\min(p,q)$ 对（从最内侧 `b…a` 相邻对开始逐层嵌套可行）。于是两遍总对数 $= A^* + \min(p,q) = \min(c_A, c_B)$（因 $c_B = A^* + p$、$c_A = A^* + q$），达到引理 2 的上界。∎

**定理（两遍贪心最优）**：$x \ge y$ 时，两遍栈扫描的得分 $= y \cdot \min(c_A, c_B) + (x - y) \cdot A^*$，而任意可行方案

$$x\,\#ab(P) + y\,\#ba(P) = y\,|P| + (x-y)\,\#ab(P) \le y \cdot \min(c_A, c_B) + (x - y) \cdot A^*,$$

分别由引理 2 与引理 3 放缩，故贪心得分不小于任何方案。$y > x$ 时对换两种子串的角色，同理。∎

> 💡 证明的关键在于两个上界（总对数、高分对数）能被**同一方案**同时取到——这正是"先删高分再删低分"结构的价值。

## 6. 复杂度分析

- **时间**：$O(|s|)$——两遍栈扫描，每个字符入栈、出栈至多一次。
- **空间**：$O(|s|)$——栈与中间串；可以复用两个栈避免第二次 `join`，但量级不变。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maximumGain(string s, int x, int y) {
        long long score = 0;
        if (x >= y) {                                   // 高分的 "ab" 先删
            string t = removePairs(s, 'a', 'b', x, score);
            removePairs(t, 'b', 'a', y, score);         // 再在剩余串上删 "ba"
        } else {                                        // y > x 时对称：先删 "ba"
            string t = removePairs(s, 'b', 'a', y, score);
            removePairs(t, 'a', 'b', x, score);
        }
        return (int)score;
    }
private:
    // 栈式删除子串 first+second（天然支持连锁删除），返回剩余串，得分累计进 score
    static string removePairs(const string& s, char first, char second, int pts, long long& score) {
        string st;
        for (char c : s) {
            if (!st.empty() && st.back() == first && c == second) {
                st.pop_back();
                score += pts;
            } else {
                st.push_back(c);
            }
        }
        return st;
    }
};
```

### Python

```python
class Solution:
    def maximumGain(self, s: str, x: int, y: int) -> int:
        def remove_pairs(t: str, first: str, second: str, pts: int):
            stack = []
            gain = 0
            for c in t:
                if stack and stack[-1] == first and c == second:
                    stack.pop()          # 栈顶 first + 当前 second → 删除计分
                    gain += pts
                else:
                    stack.append(c)
            return ''.join(stack), gain

        score = 0
        if x >= y:                       # 高分的 "ab" 先删
            t, g = remove_pairs(s, 'a', 'b', x)
            score += g
            t, g = remove_pairs(t, 'b', 'a', y)
            score += g
        else:                            # y 更高时对称：先删 "ba"
            t, g = remove_pairs(s, 'b', 'a', y)
            score += g
            t, g = remove_pairs(t, 'a', 'b', x)
            score += g
        return score
```

> 💡 两份代码均通过官方示例（`19`、`20`），并与「枚举所有删除顺序」的 DFS 暴力对拍：字母表 $\{a,b,x\}$、长度 $\le 8$ 的全部 $524{,}280$ 个串 × 6 组 $(x,y)$ 全部一致，另有 4000 组随机全字母串测试一致。

## 8. 边界情况与易错点

1. **$x = y$**：两种删除顺序等价，代码里 `x >= y` 分支即可，不要漏掉等号。
2. **第二遍要在第一遍的残余上做**，否则会把已经被连锁改变的位置重复处理。
3. **全惰性字符**（如 `"xyz"`）：两遍各得 0 分，返回 0；栈实现天然处理。
4. **溢出**：总分上限 $5 \times 10^8$，`int` 边缘安全，累加建议 `long long`。
5. **不要用 `while` 反复扫描**：最坏 `"ababab…"` 每轮只删一半，$O(|s|^2)$ 在 $10^5$ 长度下会超时；栈一遍即到底。
6. **误把「先删谁」当成可以中途切换**：证明依赖「一种删干净再删另一种」的全序结构，交替删除不改变集合意义下的最优值，但实现上两遍栈最简洁。
