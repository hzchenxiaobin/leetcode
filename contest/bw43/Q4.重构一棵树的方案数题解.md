# LeetCode 重构一棵树的方案数 题解

## 1. 题目概述

- **标题 / 题号**：重构一棵树的方案数（#1719，hard）
- **链接**：https://leetcode.cn/problems/number-of-ways-to-reconstruct-a-tree/
- **来源**：LeetCode 第 43 场双周赛 Q4
- **难度**：困难
- **标签**：树、图、哈希表、模拟

**题意**：给数组 `pairs`（无重复，$x_i < y_i$）。统计满足下列条件的**有根树**个数 `ways`：树的节点恰为 `pairs` 中出现过的值；数对 $[x, y]$ 出现在 `pairs` 中 **当且仅当** $x$ 是 $y$ 的祖先或 $y$ 是 $x$ 的祖先（注意不一定是二叉树）。返回 $0 / 1 / 2$，其中 $2$ 表示 $\text{ways} > 1$（两棵树不同 ⟺ 某节点父节点不同）。

**约束**：

- $1 \le pairs.length \le 10^5$
- $1 \le x_i < y_i \le 500$
- `pairs` 中元素互不相同

## 2. 示例

**示例 1**

```text
输入：pairs = [[1,2],[2,3]]
输出：1
解释：唯一的树：2 为根，孩子 1 和 3。
```

**示例 2**

```text
输入：pairs = [[1,2],[2,3],[1,3]]
输出：2
解释：三点两两成对，任何一条链（如 1→2→3）都合法，且根有 3 种选法。
```

**示例 3**

```text
输入：pairs = [[1,2],[2,3],[2,4],[1,5]]
输出：0
解释：5 个点中最大度数是 2（节点 2），没有点与其余 4 点都成对，无解。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有有根树：根有 $m$ 种选择，其余每个点任选父亲（$m^{m-1}$ 级别），逐个验证祖先对集合是否与 `pairs` 完全一致。$m \le 6$ 时可以穷举对拍，$m$ 到几百完全不可行。但暴力给了三个重要观察的来源——度数、邻域、层次。

### 3.2 核心观察一：邻域嵌套与度数单调

把每个点 $v$ 的**邻域** $\text{adj}(v)$（与它成对的点集）看成它的「势力范围」。若 $y$ 是 $x$ 的祖先，则

$$\text{adj}(x) \setminus \{y\} \;\subseteq\; \text{adj}(y) \setminus \{x\},$$

即**祖先的邻域（去掉彼此后）包含后代的邻域**，特别地 $\deg(x) \le \deg(y)$：祖先的度数不小于后代。于是**按度数从大到小处理，父节点一定先于子节点出现**（除非度数相等——那是方案数 $2$ 的来源，见 3.4）。

![根必须与其余所有点成对，度数为 m 减一](images/bw43_q4_root_condition.svg)

第一个推论：**根与所有点成对，度数 $= m-1$**。若最大度数不是 $m-1$，直接返回 $0$（示例 3 即此情形）。

### 3.3 核心观察二：按度数降序逐点挂父，且「已处理邻点」必须是纯祖先链

![按度数降序处理，S 必须恰为最深邻点的祖先链](images/bw43_q4_degree_layers.svg)

处理点 $x$ 时，看它**已处理**的邻点集合 $S$。在合法树中，$x$ 的邻点 = 祖先 ∪ 后代，而度数保证了：祖先基本都已处理、后代基本都未处理（等度数的例外只有「独子」情形）。因此 $S$ 应当是**一条从根下来的祖先链**：取 $S$ 中最深的点作 $x$ 的父亲，并校验 $S$ 恰好等于该父亲的整条祖先链——

- 链上有人不在 $S$ 里（不与 $x$ 成对）→ 说明这个「祖先」其实不该是祖先，返回 $0$；
- $S$ 里有人在链外 → 混进了后代或旁支，返回 $0$。

最后再用**计数**收口：树上祖先对总数 $= \sum_x \text{depth}(x)$，必须恰好等于 $|pairs|$。多了说明树把不成对的点连成了祖先关系，少了说明还有成对的点没连上——都不合法。（链检查已保证「每对成对点是祖先关系」「每个祖先是成对点」，计数保证不多不少。）

### 3.4 核心观察三：度数相等的成对点可以交换 → 方案数 2

![等度数成对点可整体交换，方案数至少为二](images/bw43_q4_ambiguity.svg)

若成对的 $x, y$ 度数相等，则任何合法树中一个是另一个的祖先（设 $y$ 是 $x$ 的祖先）。由邻域包含且大小相等得 $\text{adj}(x)\setminus\{y\} = \text{adj}(y)\setminus\{x\}$——二者在 `pairs` 里「除彼此外不可区分」。此时把 $x, y$ 的位置整体对调（$x$ 升到 $y$ 的位置、$y$ 落到 $x$ 的位置、原子树随之改挂），**所有点的邻域都不变**，即得到另一棵合法树：ways $\ge 2$。示例 2 中三点度数全为 $2$，正是这种交换性的极致体现。

反过来，若所有成对点度数互不相等，父节点度数严格大于子节点，整棵树被度数序唯一钉死：ways $= 1$。

### 3.5 算法流程

```text
1. 统计 adj / deg，取出现过的点集（m 个）
2. 若最大度 ≠ m−1 → 返回 0
3. 按 (deg 降序, 值升序) 排序，依次处理 x（第一个为根）：
       S = {已处理且与 x 成对的点}
       deepest = S 中 depth 最大者
       沿 deepest 的 parent 链走到根：链上每个点必须与 x 成对，且链长 = |S|
       否则返回 0
       parent(x) = deepest，depth(x) = depth(deepest) + 1
4. 若 Σ depth ≠ |pairs| → 返回 0
5. 若存在成对点 (x,y) 使 deg(x) = deg(y) → 返回 2；否则返回 1
```

## 4. 算法细节

1. **值域小（$\le 500$）**：直接开 $501$ 大小的数组做邻接矩阵 `adjM[u][v]`（`bool`）与邻接表 `adj[u]`，判「是否成对」$O(1)$。
2. **链校验的写法**：从 `deepest` 沿 `parent` 上溯到根，逐点查 `adjM[x][z]`，同时数步数；走完（或步数超过 $|S|$）即停，最后比较步数与 $|S|$。一次上溯 $O(\text{depth})$，总复杂度 $O(m^2)$ 级别。
3. **为什么计数校验放在最后**：链校验已保证「pairs ⊆ 祖先对」且「祖先 ⊆ pairs」（每个祖先都在邻域里），再用 $\sum \text{depth} = |pairs|$ 断言两边集合大小一致，即完全相等。比逐对验证祖先关系更快（$O(m)$ vs $O(|pairs| \cdot m)$）。
4. **等度数判定**：只需扫一遍 `pairs` 看是否有 `deg[p[0]] == deg[p[1]]`，与建树解耦。
5. **多种子并存**：多个度数为 $m-1$ 的点彼此成对且等度数，自然落入「等度数 → 2」的判定，无需特判。
6. **实现规模**：$m \le 500$、$|pairs| \le 10^5$：建图 $O(P)$、排序 $O(m\log m)$、处理与校验 $O(m^2 + P)$，轻松通过。

## 5. 正确性证明

记 $m$ 为 `pairs` 中出现的点数。以下「合法树」指祖先对集合恰等于 `pairs` 的有根树。

**引理 1（根的度数）**：合法树的根与所有其余点成对，故 $\deg(\text{root}) = m - 1$。

**证明**：根是每个点的祖先，故每对 (root, v) 都在 `pairs` 中。∎

**引理 2（邻域包含与度数单调）**：合法树中若 $y$ 是 $x$ 的祖先，则 $\text{adj}(x) \setminus \{y\} \subseteq \text{adj}(y) \setminus \{x\}$，从而 $\deg(x) \le \deg(y)$。

**证明**：$\text{adj}(x)$ = $x$ 的祖先 ∪ 后代。取 $z \in \text{adj}(x), z \ne y$：若 $z$ 是 $x$ 的祖先，则 $z$ 或是 $y$ 的祖先、或落在 $y$ 到 $x$ 的路径上（后者是 $y$ 的后代），都 $\in \text{adj}(y) \setminus \{x\}$；若 $z$ 是 $x$ 的后代，则 $z$ 是 $y$ 的后代且 $z \ne x$。两边去掉彼此后按大小比较即得度数不等式。∎

**引理 3（等度数成对点 ⟺ 可交换）**：设 $(x,y) \in pairs$ 且 $\deg(x) = \deg(y)$，则任何合法树中一个恰是另一个的祖先，且交换二者位置（连同子树改挂）后仍是合法树；反之，若所有成对点度数互异，则合法树（若存在）唯一。

**证明**：成对点在合法树中必为祖先关系（成对 ⟺ 祖先关系），设 $y$ 为祖先。由引理 2 的包含关系与度数相等，得 $\text{adj}(x)\setminus\{y\} = \text{adj}(y)\setminus\{x\}$。此时 $y$ 到 $x$ 的路径上没有岔路（岔路上的点会属于 $\text{adj}(y)\setminus\text{adj}(x)$），即从 $y$ 向下到 $x$ 是一条链、$x$ 的子树之外 $y$ 再无其他后代。把 $x$ 提到 $y$ 的位置、$y$ 放到 $x$ 的位置（原 $x$ 的子树改挂到 $y$ 下、链上节点与两侧祖先/后代关系随之平移）：逐类检查可知每个点的邻域都不变——链上节点、$x$ 的旧子树、$y$ 的旧祖先对 $x,y$ 均已成对（它们都在公共邻域 $S$ 中），无关的点完全不动。故交换后的树合法且父节点不同。反之若所有成对点度数互异，由引理 2 任何父子对满足 $\deg(\text{父}) > \deg(\text{子})$，于是「按度数降序」是任何合法树的唯一拓扑序：父亲被度数序唯一确定（见引理 5 的链校验），树至多一棵。∎

**引理 4（构造成功 ⟹ 有解）**：若算法第 3 步未返回 0 且 $\sum \text{depth} = |pairs|$，则建出的 `parent` 映射是一棵合法树。

**证明**：逐步验证：parent(x) ∈ S ⊆ adj(x)，父子都成对；parent 只指向更早处理的点，无环且都可达根，是合法有根树。任意成对点 $(a,b)$：设 $b$ 后处理，则 $a \in S(b)$，而链校验要求 $S(b)$ 恰为最深邻点的祖先链，故 $a$ 是 $b$ 的祖先——**pairs ⊆ 祖先对**。反过来，链校验中「链上每点都与 $x$ 成对」说明 $x$ 的每个祖先都与 $x$ 成对——**祖先对 ⊆ pairs**。两集合相等（也可由 $\sum \text{depth} = |pairs|$ 与单侧包含推出）。∎

**引理 5（有解 ⟹ 构造不返回 0）**：若存在合法树 $T$，算法的处理与校验全部通过。

**证明**：对处理序号归纳，维护不变量：存在与 $T$ 等价（至多经过若干引理 3 的交换）的合法树 $T'$，使得已处理点的 `parent` 与其在 $T'$ 中一致。首点 $r$ 度数最大：由引理 1，$T$ 的根度数为 $m-1$；若根不是 $r$，二者都度数 $m-1$ 且成对，由引理 3 交换后可令 $r$ 为根。归纳步处理 $x$：在 $T'$ 中 $x$ 的邻点 = 祖先 ∪ 后代。由引理 2，度数严格更大的祖先都已处理、度数严格更小的后代都未处理；度数相等的邻点由引理 3 的结构只能是「紧邻的独子链」，即至多一个等度数祖先（$x$ 的父亲）与至多一个等度数后代（$x$ 的独子），它们是否已处理取决于并列次序。分情况：若等度数祖先已处理（或不存在），则 $S$ 恰为 $x$ 在 $T'$ 中的全部祖先（可能再多一个已处理的独子 $z$，此时 $z$ 是 $S$ 中最深者，且 $z$ 的祖先链正是 $x$ 的祖先链），链校验通过，`parent(x)` 取到 $T'$ 中的真父亲（或与独子 $z$ 交换后一致，由引理 3 保持合法性）；若等度数祖先 $p$ 未处理，则 $S$ = 除 $p$ 外的祖先（∪ 独子 $z$），同样是 $z$（或最深祖先）的完整祖先链，校验通过，相当于先执行了 $x$ 与 $z$ 的交换。归纳完成。∎

**定理**：算法返回 $0 / 1 / 2$ 正确刻画 ways $= 0 / 1 / >1$。

**证明**：返回 $0$ 的三个出口（无根、链校验失败、计数不符）分别由引理 1、5、4 的逆否保证 ⟺ 无解。有解时构造成功，由引理 3：存在等度数成对点 ⟺ ways $\ge 2$，返回 $2$；否则树唯一，返回 $1$。∎

> ⚠️ 这题的难点全在「构造 + 校验」的耦合上：单独的链校验、单独的计数校验都不够，二者合起来才把「不多、不少、不串层」三件事同时钉死。

## 6. 复杂度分析

- **时间**：$O(P + m \log m + m^2)$，其中 $P = |pairs| \le 10^5$、$m \le 500$。建图线性；排序可省（值域桶排 $O(m)$）；每个点扫邻域 $O(\deg)$ 共 $O(P)$，链上溯总计 $O(\sum \text{depth}) = O(m^2)$；等度数扫描 $O(P)$。
- **空间**：$O(m^2 + P)$——邻接矩阵 $m^2 \le 2.5 \times 10^5$、邻接表 $O(P)$；也可用 `unordered_set` 邻域代替矩阵，空间 $O(P)$，判成对均摊 $O(1)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int checkWays(vector<vector<int>>& pairs) {
        // 值域 1..500，直接开数组：邻接矩阵 + 邻接表 + 度数
        vector<vector<char>> adjM(501, vector<char>(501, 0));
        vector<vector<int>> adj(501);
        vector<int> deg(501, 0), parent(501, 0), depth(501, 0), order;
        vector<char> seen(501, 0), done(501, 0);
        for (auto& p : pairs) {
            adjM[p[0]][p[1]] = adjM[p[1]][p[0]] = 1;
            adj[p[0]].push_back(p[1]);
            adj[p[1]].push_back(p[0]);
            deg[p[0]]++;
            deg[p[1]]++;
            if (!seen[p[0]]) { seen[p[0]] = 1; order.push_back(p[0]); }
            if (!seen[p[1]]) { seen[p[1]] = 1; order.push_back(p[1]); }
        }
        int m = (int)order.size();
        sort(order.begin(), order.end(), [&](int a, int b) {
            return deg[a] != deg[b] ? deg[a] > deg[b] : a < b;
        });
        if (deg[order[0]] != m - 1) return 0;   // 根必须与其余所有点成对
        int root = order[0];
        done[root] = 1;
        long long ancPairs = 0;                 // 树上祖先对总数 = Σ depth
        for (int i = 1; i < m; ++i) {
            int x = order[i];
            int deepest = -1, szS = 0;
            for (int z : adj[x])
                if (done[z]) {                  // S = 已处理且与 x 成对的点
                    ++szS;
                    if (deepest == -1 || depth[z] > depth[deepest]) deepest = z;
                }
            if (deepest == -1) return 0;
            int cnt = 0;
            for (int z = deepest;; z = parent[z]) {  // S 必须恰为 deepest 的祖先链
                if (!adjM[x][z]) return 0;      // 链上有人未和 x 成对 → 无解
                if (++cnt > szS) return 0;
                if (z == root) break;
            }
            if (cnt != szS) return 0;           // S 中混进了非祖先点 → 无解
            parent[x] = deepest;
            depth[x] = depth[deepest] + 1;
            ancPairs += depth[x];
            done[x] = 1;
        }
        if (ancPairs != (long long)pairs.size()) return 0;  // 祖先对必须不多不少
        for (auto& p : pairs)                    // 等度数的成对点可交换 → 不唯一
            if (deg[p[0]] == deg[p[1]]) return 2;
        return 1;
    }
};
```

### Python

```python
class Solution:
    def checkWays(self, pairs: list[list[int]]) -> int:
        adj = {}
        for x, y in pairs:
            adj.setdefault(x, set()).add(y)
            adj.setdefault(y, set()).add(x)
        m = len(adj)
        order = sorted(adj, key=lambda v: (-len(adj[v]), v))
        if len(adj[order[0]]) != m - 1:       # 根必须与其余所有点成对
            return 0
        root = order[0]
        parent = {}
        depth = {root: 0}
        anc_pairs = 0
        for x in order[1:]:
            done = [z for z in adj[x] if z in depth]   # 已处理且与 x 成对的点
            if not done:
                return 0
            deepest = max(done, key=lambda z: depth[z])
            cnt, z = 0, deepest
            while True:                      # done 必须恰为 deepest 的祖先链
                if z not in adj[x]:
                    return 0
                cnt += 1
                if z == root:
                    break
                z = parent[z]
            if cnt != len(done):
                return 0
            parent[x] = deepest
            depth[x] = depth[deepest] + 1
            anc_pairs += depth[x]
        if anc_pairs != len(pairs):          # 祖先对必须与 pairs 完全一致
            return 0
        for x, y in pairs:
            if len(adj[x]) == len(adj[y]):   # 等度数的成对点可交换
                return 2
        return 1
```

## 8. 边界情况与易错点

1. **最大度数 $\ne m-1$**：一步返回 $0$，别急着建树（示例 3）。
2. **多个度数 $m-1$ 的点**：它们彼此成对且等度数，方案数 $2$；排序时任取一个做根即可，交换性兜底。
3. **链校验的两个方向都要**：链上缺人（不成对的祖先）与 $S$ 里多人都判 $0$，只查一边会漏判。
4. **计数校验不可省**：只建树不比对 $\sum \text{depth}$，会把「树上多出的祖先对」误判为合法。
5. **度数相等的判定对象是成对点**，不是任意两点——等度数但不成对的点不影响唯一性。
6. **parent 链上溯别越界**：走到根即停（根没有 parent）；实现里 `parent` 未初始化的槽位不要被读到。
7. **`pairs` 无重复且 $x_i < y_i$**：建邻接矩阵时对称赋值一次即可；若题目变体允许重复，需先去重。
