# LeetCode 计算力扣银行的钱 题解

## 1. 题目概述

- **标题 / 题号**：计算力扣银行的钱（#1716，easy）
- **链接**：https://leetcode.cn/problems/calculate-money-in-leetcode-bank/
- **来源**：LeetCode 第 43 场双周赛 Q1
- **难度**：简单
- **标签**：数学、等差数列

**题意**：Hercy 周一开始每天往银行存钱：第一天（周一）存 $1$ 块；同一周内每天比前一天**多存 $1$ 块**；下个周一比**上一个周一多存 $1$ 块**。给定天数 $n$，求第 $n$ 天结束时存款总额。

**约束**：

- $1 \le n \le 1000$

## 2. 示例

**示例 1**

```text
输入：n = 4
输出：10
解释：第 4 天后总额为 1 + 2 + 3 + 4 = 10。
```

**示例 2**

```text
输入：n = 10
输出：37
解释：(1+2+3+4+5+6+7) + (2+3+4) = 28 + 9 = 37。第二个周一存 2 块。
```

**示例 3**

```text
输入：n = 20
输出：96
解释：(1+…+7) + (2+…+8) + (3+4+5+6+7+8) = 28 + 35 + 33 = 96。
```

## 3. 解题思路

### 3.1 暴力思路

从第 $0$ 天循环到第 $n-1$ 天逐天累加。设天编号 $i$ 从 $0$ 起，则第 $i$ 天存的钱是

$$\text{deposit}(i) = \lfloor i/7 \rfloor + (i \bmod 7) + 1,$$

即「第几周（0 起）+ 周内第几天（0 起）+ 1」。$O(n)$ 模拟对 $n \le 1000$ 完全够用，也是很好的对拍基准；但本题可以直接 $O(1)$。

### 3.2 核心观察：整周求和是等差数列

![存钱日历：每周一首日加一块，周内每天加一块](images/bw43_q1_week_grid.svg)

把日子按周切开。第 $w$ 周（$w$ 从 $0$ 起）的七天依次存入 $w+1, w+2, \dots, w+7$，因此

$$\text{第 } w \text{ 周总和} = 7w + (1+2+\cdots+7) = 7w + 28,$$

它是关于 $w$ 的等差数列（首项 $28$、公差 $7$）。设 $W = \lfloor n/7 \rfloor$ 为完整周数、$d = n \bmod 7$ 为剩余天数，则

$$\text{整周部分} = \sum_{w=0}^{W-1} (7w + 28) = 28W + 7 \cdot \frac{W(W-1)}{2}.$$

### 3.3 余日部分

不足一周的尾巴处于第 $W$ 周（0 起），第 $j$ 天（$j = 0..d-1$）存 $W + j + 1$，故

$$\text{余日部分} = \sum_{j=0}^{d-1} (W + j + 1) = dW + \frac{d(d+1)}{2}.$$

### 3.4 示例演算

![整周与余日两段求和公式拆解，n 等于 20 的演算](images/bw43_q1_sum_split.svg)

以 $n = 20$ 为例：$W = 2$，$d = 6$。

| 部分 | 公式代入 | 数值 |
|------|----------|------|
| 整周 | $28 \times 2 + 7 \times \frac{2 \times 1}{2}$ | $63$ |
| 余日 | $6 \times 2 + \frac{6 \times 7}{2}$ | $33$ |
| 合计 | — | $96$ ✓ |

## 4. 算法细节

1. **周编号从 $0$ 起**更省心：第 $w$ 周周一存 $w+1$，避免了「第 1 周存 1」与 $w$ 差 1 的偏移错误。
2. **两个求和公式**：整周部分是首项 $28$、公差 $7$ 的等差数列求和 $= \frac{(28 + (7(W-1)+28)) \times W}{2}$，化简即 $28W + 7W(W-1)/2$；余日部分是 $d$ 项、首项 $W+1$、公差 $1$ 的等差数列，和为 $dW + d(d+1)/2$。
3. **溢出**：$n \le 1000$ 时 $W \le 142$，总和上界约 $\frac{1000 \times 15}{2} \approx 7600$，`int` 绰绰有余；用 `long long` 只是保险。
4. **divmod 一次到位**：`divmod(n, 7)` / `n / 7, n % 7` 同时代出 $W$ 和 $d$，避免两次除法。

## 5. 正确性证明

**引理 1（逐日公式）**：第 $i$ 天（$i$ 从 $0$ 起）存入的钱恰为 $\lfloor i/7 \rfloor + (i \bmod 7) + 1$。

**证明**：对 $i$ 归纳。$i = 0$：第一个周一存 $1 = 0 + 0 + 1$ ✓。设第 $i$ 天存 $\lfloor i/7 \rfloor + (i \bmod 7) + 1$。看第 $i+1$ 天：若 $i \bmod 7 < 6$，则周内推进一天且未跨周，$\lfloor (i+1)/7 \rfloor = \lfloor i/7 \rfloor$、$(i+1) \bmod 7 = (i \bmod 7) + 1$，存款 $+1$，符合「周内每天比前一天多存 1」；若 $i \bmod 7 = 6$，第 $i$ 天是周日、第 $i+1$ 天是下一个周一，$\lfloor (i+1)/7 \rfloor = \lfloor i/7 \rfloor + 1$、$(i+1) \bmod 7 = 0$，新周一存款 $= (\lfloor i/7 \rfloor + 1) + 0 + 1 = (\lfloor i/7 \rfloor + 6 + 1) + 1$，恰比上一个周一多 $1$，符合规则。∎

**定理**：设 $W = \lfloor n/7 \rfloor$、$d = n \bmod 7$，则前 $n$ 天总额等于 $28W + 7W(W-1)/2 + dW + d(d+1)/2$。

**证明**：把前 $n$ 天按周分段：前 $W$ 段是完整周，第 $w$ 段（$0 \le w < W$）由引理 1 求和为 $\sum_{j=0}^{6}(w + j + 1) = 7w + 28$；最后一段是第 $W$ 周的前 $d$ 天，和为 $\sum_{j=0}^{d-1}(W + j + 1) = dW + d(d+1)/2$。三部分相加即得。∎

## 6. 复杂度分析

- **时间**：$O(1)$——只有常数次算术运算（模拟法为 $O(n)$，亦可接受）。
- **空间**：$O(1)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int totalMoney(int n) {
        int weeks = n / 7, days = n % 7;
        // 完整 weeks 周：第 w 周（w 从 0 起）存入 (w+1)+…+(w+7) = 7w + 28
        long long full = 28LL * weeks + 7LL * weeks * (weeks - 1) / 2;
        // 余 days 天处于第 weeks 周，存入 weeks+1, …, weeks+days
        long long part = 1LL * days * weeks + 1LL * days * (days + 1) / 2;
        return (int)(full + part);
    }
};
```

### Python

```python
class Solution:
    def totalMoney(self, n: int) -> int:
        weeks, days = divmod(n, 7)
        # 第 w 周（0 起）整周存入 7w + 28；对 w = 0..W-1 求等差和
        full = 28 * weeks + 7 * weeks * (weeks - 1) // 2
        # 余 days 天处于第 weeks 周，存入 weeks+1 .. weeks+days
        part = days * weeks + days * (days + 1) // 2
        return full + part
```

> 💡 两份代码均通过官方示例（`10`、`37`、`96`），并与逐日模拟在 $n = 1 \dots 1000$ 上逐一比对一致。

## 8. 边界情况与易错点

1. **$n < 7$**：$W = 0$，整周部分为 $0$，只有余日部分；$n = 1$ 时答案为 $1$。
2. **$n$ 恰为 7 的倍数**：$d = 0$，余日部分必须为 $0$——注意余日公式在 $d=0$ 时自然为 $0$，无需特判。
3. **偏移量差 1**：最常见的错误是认为「第 $w$ 周周一存 $w$」，正确是 $w+1$；建议用 $n=4$（答案 $10$）和 $n=10$（答案 $37$）自测。
4. **整数除法**：$7W(W-1)/2$ 中 $W(W-1)$ 必为偶数，先乘后除不会丢精度，但建议按公式顺序写，避免中间向下取整。
5. **「第 n 天结束」**：包含第 $n$ 天当天的存款，即前 $n$ 天总和，不要少算最后一天。
