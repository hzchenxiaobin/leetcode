# LeetCode 找出第 K 小的数对距离 题解

## 1. 题目概述

- **标题 / 题号**：找出第 K 小的数对距离（#719，hard）
- **链接**：https://leetcode.cn/problems/find-k-th-smallest-pair-distance/
- **来源**：LeetCode 第 56 场周赛 Q4
- **难度**：困难
- **标签**：数组，双指针，二分查找，排序

**题意**：给定整数数组 `nums` 与整数 `k`，考察所有满足 `0 <= i < j < n` 的下标对，数对距离定义为 $|nums[i]-nums[j]|$。返回全部 $\binom{n}{2}$ 个距离中**第 $k$ 小**的那个值（从 1 开始计数，相等的距离分别计数）。

**约束**：

- $2 \le n \le 10^4$
- $0 \le nums[i] \le 10^6$
- $1 \le k \le \frac{n(n-1)}{2}$

数对总数最大约 $5\times10^7$，而距离值域只有 $10^6$：前者否决「枚举全部距离再排序」，后者提示「**在答案值域上二分**」。

## 2. 示例

**示例 1**

```text
输入：nums = [1,3,1], k = 1
输出：0
解释：三对数对的距离为 (1,1)->0、(1,3)->2、(3,1)->2，
      升序排列 [0,2,2]，第 1 小是 0。
```

**示例 2**

```text
输入：nums = [1,1,1], k = 2
输出：0
解释：三对距离全为 0，第 1、2、3 小都是 0。
```

**示例 3**

```text
输入：nums = [1,6,1], k = 3
输出：5
解释：距离为 0、5、5，第 3 小是 5（恰好等于 max - min）。
```

## 3. 解题思路

### 3.1 暴力思路

最直接：枚举 $\binom{n}{2}$ 对求距离，排序后取第 $k$ 个。$n=10^4$ 时有 $5\times10^7$ 个整数，时间 $O(n^2\log n)$、空间 $O(n^2)$，时间与内存双双越界。

再聪明一点：排序后把「以 $i$ 为左端点的距离」看成 $n-1$ 条有序队列，用小根堆做 $k$ 路归并，每次弹出一个最小值。复杂度 $O\bigl((n+k)\log n\bigr)$，但 $k$ 最大 $5\times10^7$，仍是超时。**症结在于 $k$ 可能极大，任何「逐个产出距离」的方案都没戏。**

### 3.2 核心观察：计数函数单调，可以二分答案

![二分答案：最小的 d 使 F(d) ≥ k](images/wc56_q4_binary_search_answer.svg)

对任意非负整数 $d$，定义计数函数

$$F(d) = \#\{(i,j) \mid i<j,\ |nums[i]-nums[j]| \le d\},$$

即「距离不超过 $d$ 的数对有多少个」。$d$ 变大时被计入的数对只增不减，所以 $F$ **单调不减**。于是「第 $k$ 小的距离」可以改写成

$$a^{*} = \min\{\,d \ge 0 \mid F(d) \ge k\,\}.$$

理由：把全部距离升序排成 $v_1 \le v_2 \le \dots \le v_m$（$m=\binom n2$），$F(d)$ 恰好是「$\le d$ 的距离个数」，第一个让计数达到 $k$ 的位置就是 $v_k$ 本身。因此 $a^{*}$ 必定是某个真实出现的数对距离，不会落在空隙里。

问题由此从「找第 $k$ 小」变成「**判定 + 二分**」：值域 $[0,\ \max(nums)-\min(nums)] \subseteq [0,10^6]$，只需约 $\log_2 10^6 \approx 20$ 轮；剩下唯一的关键是**每轮如何快速算出 $F(d)$**。

### 3.3 判定：排序 + 双指针，$O(n)$ 数出 $F(d)$

![双指针统计距离不超过 d 的数对](images/wc56_q4_two_pointer_count.svg)

先把 `nums` 升序排序，此后对 $i<j$ 有 $|nums[i]-nums[j]| = nums[j]-nums[i]$，绝对值自动消失。

固定右端点 $r$。由于数组升序，$nums[r]-nums[i]$ 随 $i$ 增大而减小，所以「满足 $nums[r]-nums[i]\le d$ 的下标 $i$」构成**连续区间** $[l_r,\ r]$，个数为 $r-l_r$。把所有 $r$ 的贡献相加：

$$F(d) = \sum_{r=1}^{n-1}\bigl(r - l_r\bigr),\qquad l_r = \min\{\,i \mid 0 \le i \le r,\ nums[r]-nums[i] \le d\,\}.$$

更关键的是 $l_r$ **关于 $r$ 单调不减**：$r$ 右移时 $nums[r]$ 变大，门槛 $nums[r]-d$ 也抬高，左边界只会右移。因此维护一个只增不减的指针 $l$，每个 $r$ 上做 `while nums[r]-nums[l] > d: l++` 即可；$l$ 全程最多移动 $n$ 次，**整轮判定 $O(n)$**。

算法三层结构就此确定：**排序 → 在 $[0,\max-\min]$ 上二分答案 $d$ → 双指针判 $F(mid)\ge k$**。

### 3.4 示例演算

![示例演算：二分答案的逐步走查](images/wc56_q4_walkthrough.svg)

先看补充样例 `nums = [1,3,4,7]`、`k = 4`（距离升序为 $1,2,3,3,4,6$，答案应为 3）：

| 轮次 | $lo$ | $hi$ | $mid$ | $F(mid)$ | 判定 | 动作 |
|------|------|------|-------|----------|------|------|
| 1 | 0 | 6 | 3 | 4 | $4 \ge 4$ | $hi = 3$ |
| 2 | 0 | 3 | 1 | 1 | $1 < 4$ | $lo = 2$ |
| 3 | 2 | 3 | 2 | 2 | $2 < 4$ | $lo = 3$ |

此时 $lo = hi = 3$，输出 3。其中第 1 轮 $d=3$ 的双指针统计为：$r=1$ 贡献 1 对、$r=2$ 贡献 2 对、$r=3$ 时 $l$ 移到 2 贡献 1 对，合计 $F(3)=4$。

官方样例的走查见上图：示例 1 里 $F(0)=F(1)=1 \ge k=1$，两轮就把区间压到 $[0,0]$，答案为 0；示例 3 里 $F(2)=F(4)=1 < 3$，$lo$ 被一路推到 5，$lo=hi=5$ 得答案 5。

## 4. 算法细节

1. **二分区间取紧**：$lo = 0$，$hi = \max(nums)-\min(nums)$（排序后即 $nums[n-1]-nums[0]$）。$hi$ 必然可行，因为 $F(hi)=\binom n2 \ge k$，这一点由约束 $k \le \frac{n(n-1)}{2}$ 保证，不需要额外检查。
2. **循环写法**：`while (lo < hi) { mid = lo + (hi - lo) / 2; ... }`，`F(mid) >= k` 时 `hi = mid`，否则 `lo = mid + 1`；结束时 `lo` 就是答案。用 `lo + (hi-lo)/2` 既避免加法溢出，也保证 `mid < hi`。
3. **双指针不能重置**：$l$ 在一轮判定内只右移。若对每个 $r$ 都从 0 重新找 $l$，单轮退化成 $O(n^2)$，整体变成 $O(n^2\log V)$，优化全部作废。
4. **$l$ 不会越界**：条件 `nums[r]-nums[l] > d` 在 $l=r$ 时为假（差为 0，而 $d \ge 0$），故恒有 $l \le r$，内层循环一定会停。
5. **计数用 64 位**：$n=10^4$ 时数对上限 $4.9995\times10^7$，32 位 `int` 还装得下，但书写上统一用 `long long`／Python 无此顾虑；比较时写 `>= (long long)k` 更稳妥。
6. **答案必是真实距离**：收敛时 $F(a^{*}-1) < k \le F(a^{*})$，说明恰好在 $a^{*}$ 这一档新计入了数对，$a^{*}$ 必然出现在距离集合中。
7. **判定可提前退出**：`cnt >= k` 时立即返回 true，最坏仍是 $O(n)$，但实际轮次里通常更早结束。
8. **重复元素不影响正确性**：相等的元素贡献距离 0，正符合「相等距离分别计数」的题意；$F(0)$ 就等于重复对的数量。

## 5. 正确性证明

**引理 1（单调性）**：若 $0 \le d_1 \le d_2$，则 $F(d_1) \le F(d_2)$。

**证明**：任一满足 $|nums[i]-nums[j]| \le d_1$ 的数对，由 $d_1 \le d_2$ 也满足 $|nums[i]-nums[j]| \le d_2$。故 $\{$距离 $\le d_1\}$ 的集合被 $\{$距离 $\le d_2\}$ 的集合包含，取基数即得不等式。∎

**引理 2（双指针统计正确）**：对排序后的数组与任意 $d \ge 0$，双指针得到的 `cnt` 等于 $F(d)$。

**证明**：设处理完 $r$ 后指针为 $l_r$。数组升序 $\Rightarrow$ $nums[r]-nums[i]$ 关于 $i$ 单调不增，故在 $0 \le i \le r$ 中满足 $nums[r]-nums[i] \le d$ 的 $i$ 恰为区间 $[l_r, r]$，共 $r-l_r$ 个；它们正是所有以 $r$ 为较大下标的合法数对，且不同 $r$ 对应的数对集合互不相交。把各 $r$ 的贡献相加，恰好覆盖全部满足条件的数对，故 `cnt` $=F(d)$。∎

**推论（$l_r$ 单调不减）**：$r$ 增大时左边界不会回退，因此单轮判定的总移动次数为 $O(n)$。

**证明**：设 $i < l_r$，则 $nums[r]-nums[i] > d$。由 $nums[r+1] \ge nums[r]$ 得 $nums[r+1]-nums[i] \ge nums[r]-nums[i] > d$，故 $i$ 对 $r+1$ 仍不合法，新的左边界 $l_{r+1} \ge l_r$。$l$ 从 0 出发、只增不减且不超过 $n-1$，总移动次数不超过 $n$。∎

**引理 3（二分不变式）**：记 $a^{*} = \min\{d \ge 0 \mid F(d) \ge k\}$。循环过程中恒有 $lo \le a^{*} \le hi$ 且 $F(hi) \ge k$。

**证明**：初始 $lo = 0 \le a^{*}$，$hi = \max-\min$ 满足 $F(hi)=\binom n2 \ge k$，故 $a^{*} \le hi$。设某轮取 $mid$：若 $F(mid) \ge k$，由 $a^{*}$ 的最小性得 $a^{*} \le mid$，令 $hi = mid$ 后 $F(hi) \ge k$ 仍成立；若 $F(mid) < k$，则 $mid$ 不可行，故 $mid < a^{*}$，令 $lo = mid+1 \le a^{*}$。两种情形不变式均保持。∎

**定理**：算法返回值等于全部数对距离中第 $k$ 小的值。

**证明**：由引理 2 判定函数精确计算 $F(d)$；由引理 3，循环终止时 $lo = hi$ 且 $lo \le a^{*} \le hi = lo$，故返回 $a^{*}$。将距离升序排列为 $v_1 \le \dots \le v_m$，由定义 $F(d) \ge k \iff v_k \le d$；于是 $a^{*} = \min\{d \ge 0 : v_k \le d\} = v_k$。故返回值正是第 $k$ 小的数对距离。∎

## 6. 复杂度分析

- **时间**：排序 $O(n\log n)$；二分共 $\lceil \log_2(\max-\min+1)\rceil \le 20$ 轮（值域 $10^6$），每轮双指针 $O(n)$，故总计 $O\bigl(n\log n + n\log V\bigr)$，其中 $V = \max-\min$。$n=10^4$ 时约 $2\times10^5$ 次基本操作。
- **空间**：除排序外只使用常数个指针与计数器，额外空间 $O(1)$。Python 的 `sorted` 会复制一份列表，为 $O(n)$；C++ 原地 `sort` 的栈开销为 $O(\log n)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int smallestDistancePair(vector<int>& nums, int k) {
        sort(nums.begin(), nums.end());
        int n = nums.size();

        // 统计距离 <= d 的数对个数 F(d)
        auto countPairs = [&](int d) -> long long {
            long long cnt = 0;
            int l = 0;                        // 左指针只增不减
            for (int r = 0; r < n; ++r) {
                while (nums[r] - nums[l] > d) ++l;
                cnt += r - l;                 // 以 r 结尾的合法数对
            }
            return cnt;
        };

        int lo = 0, hi = nums[n - 1] - nums[0];
        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            if (countPairs(mid) >= (long long)k) hi = mid;
            else lo = mid + 1;
        }
        return lo;
    }
};
```

### Python

```python
class Solution:
    def smallestDistancePair(self, nums: list[int], k: int) -> int:
        nums = sorted(nums)
        n = len(nums)

        def count_pairs(d: int) -> int:
            cnt = 0
            l = 0                             # 左指针只增不减
            for r in range(n):
                while nums[r] - nums[l] > d:
                    l += 1
                cnt += r - l                  # 以 r 结尾的合法数对
            return cnt

        lo, hi = 0, nums[-1] - nums[0]
        while lo < hi:
            mid = (lo + hi) // 2
            if count_pairs(mid) >= k:
                hi = mid
            else:
                lo = mid + 1
        return lo
```

## 8. 边界情况与易错点

1. **$k=1$ 且数组有重复**：答案为 0。$lo$ 初值必须是 0；若想当然取 1，会漏掉距离 0 这一档。
2. **$k=\binom n2$**：答案是 $\max-\min$；$hi$ 必须取到 `nums[n-1]-nums[0]`（取 `1e6` 也能通过，只是多跑几轮）。
3. **数组全相同**：所有距离为 0，$F(0)=\binom n2 \ge k$，第一轮就把 $hi$ 压到 0，返回 0，不会死循环。
4. **内层条件写错**：若写成 `while nums[r]-nums[l] >= d`，距离恰为 $d$ 的数对会被排除，计数偏小、答案偏大；应当是严格大于才移动。
5. **双指针重置**：每轮判定内部 $l$ 从头开始、在该轮内只右移；若在每个 $r$ 上重置 `l = 0`，单轮退化 $O(n^2)$。
6. **计数溢出**：本题 $5\times10^7$ 尚在 `int` 内，但 `cnt` 仍建议用 `long long`，比较时写 `>= (long long)k`，避免后续改动量级时踩坑。
7. **`mid` 取法导致死循环**：若写成 `mid = (lo+hi+1)/2`，`F(mid) >= k` 分支的 `hi = mid` 可能原地不动；必须用向下取整的 `lo + (hi-lo)/2`。
8. **返回值的含义**：返回二分终点的 `lo`（第一个可行值），不要返回最后一轮算出的 `F(mid)` 或距离数组里不存在的中间值。
