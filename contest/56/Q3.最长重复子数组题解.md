# LeetCode 最长重复子数组 题解

## 1. 题目概述

- **标题 / 题号**：最长重复子数组（#718，medium）
- **链接**：https://leetcode.cn/problems/maximum-length-of-repeated-subarray/
- **来源**：LeetCode 第 56 场周赛 Q3
- **难度**：中等
- **标签**：数组，动态规划，滑动窗口，哈希函数，滚动哈希，二分查找

**题意**：给定两个整数数组 `nums1`、`nums2`，求同时出现在两个数组中的**连续子数组**（即公共子数组）的**最大长度**。注意「子数组」要求下标连续，且两段公共部分必须**逐元素相同、长度相同**，返回的是长度而不是子数组本身。

**约束**：

- $1 \le \lvert nums1 \rvert, \lvert nums2 \rvert \le 1000$
- $0 \le nums1[i], nums2[i] \le 100$
- 答案不超过 $\min(\lvert nums1 \rvert, \lvert nums2 \rvert)$

> 💡 与「最长公共子序列」（1143 题）只差一个字，但连续性彻底改变了解法：子序列可以跳过元素，公共子数组一旦断掉就必须重新开始计数，这个「断点」正是 DP 状态的天然边界。

## 2. 示例

**示例 1**

```text
输入：nums1 = [1,2,3,2,1]，nums2 = [3,2,1,4,7]
输出：3
解释：最长的公共子数组是 [3,2,1]（nums1[2..4] 与 nums2[0..2]），长度 3。
```

**示例 2**

```text
输入：nums1 = [0,0,0,0,0]，nums2 = [0,0,0,0,0]
输出：5
解释：最长的公共子数组是 [0,0,0,0,0]，两个数组完全相同，长度 5。
```

**示例 3（补充：无公共元素）**

```text
输入：nums1 = [1,2,3]，nums2 = [4,5,6]
输出：0
解释：任何一对元素都不相等，不存在长度 ≥ 1 的公共子数组，返回 0。
```

## 3. 解题思路

### 3.1 暴力思路

枚举 `nums1` 的起点 $i$、`nums2` 的起点 $j$，再从 $(i,j)$ 开始逐元素比较、能延伸多长就延伸多长：

$$O(mn \cdot \min(m,n)) \approx 10^9$$

当两数组完全相同（如示例 2）时，每一对起点都要比到较短数组的末尾，最坏约 $10^9$ 次比较：在 Python 里必然超时，在 C++ 里也只在时限边缘徘徊。比复杂度更糟的是它做了大量无用功——从 $(i,j)$ 和从 $(i+1,j+1)$ 出发的答案几乎完全重复，后者只是在前者前面再接一个元素。

### 3.2 核心观察：匹配段就是网格对角线

![公共子数组落在网格对角线上](images/wc56_q3_match_diagonal.svg)

把 `nums1` 的每个元素作为一行、`nums2` 的每个元素作为一列，得到一张 $m \times n$ 的比较网格：格子 $(i,j)$ 涂黑当且仅当 `nums1[i-1] == nums2[j-1]`。

> 关键 observation：**长度 $L$ 的公共子数组，对应网格上一条主对角线方向（右下）上连续的 $L$ 个黑格**。

一次「公共子数组」等价于：存在 $i, j$（0 起始下标，分别指向两段的**最后一个**元素），使得下式对 $k = 0, 1, \dots, L-1$ 都成立

$$nums1[i-k] = nums2[j-k]$$

也就是在网格里从格 $(i+1, j+1)$ 往左上角连续数 $L$ 个匹配格。于是问题变成「网格里最长的对角连续黑段有多长」，自然定义（以下 $dp$ 的下标一律 1 起始）：

$$dp[i][j] = \text{以 } nums1[i-1] \text{ 与 } nums2[j-1] \text{ 结尾的最长公共后缀长度}$$

**状态转移**：若两元素相等，就把当前这一对接到左上格所代表的公共后缀后面，长度加一；若不等，这个位置不可能作为任何公共子数组的结尾，直接归零：

$$dp[i][j] = \begin{cases} dp[i-1][j-1] + 1, & nums1[i-1] = nums2[j-1] \\ 0, & \text{否则} \end{cases}$$

答案不是 $dp[m][n]$，而是**整张表的最大值**：

$$\text{ans} = \max_{0 \le i \le m,\; 0 \le j \le n} dp[i][j]$$

### 3.3 算法流程 / 状态转移

![状态转移与一维滚动数组](images/wc56_q3_dp_transition.svg)

1. **边界**：$dp[0][j] = dp[i][0] = 0$，表示「至少一方是空前缀」时公共后缀长度为 0，同时充当哨兵，省去 $i-1 \ge 0$ 的判断。
2. **填表**：按行优先遍历 $i = 1 \dots m$、$j = 1 \dots n$，用上面的转移式算出 $dp[i][j]$，同时用 `best` 记录出现过的最大值。
3. **压成一维**：$dp[i][\cdot]$ 只依赖 $dp[i-1][\cdot]$，所以只需保留一行。由于 $dp[j]$ 依赖左上角的 $dp[j-1]$，**$j$ 必须从 $n$ 逆序扫到 1**，此时 $dp[j-1]$ 还没被本行覆盖，仍是上一行的值（即 $dp[i-1][j-1]$）。
4. **答案**：返回 `best`。填表结束时 $dp[n]$ 只是「以末元素结尾」的局部答案，不能作为结果。

> 💡 一张表同时回答了「最长」和「在哪里」：若要还原子数组，记录 `best` 取到最大时的 $i$，答案就是 `nums1[i-best .. i-1]`。

### 3.4 示例演算

![示例 1 的填表走查](images/wc56_q3_walkthrough.svg)

以示例 1 为例，行看 `nums1 = [1,2,3,2,1]`、列看 `nums2 = [3,2,1,4,7]`：

| $i \backslash j$ | 3 | 2 | 1 | 4 | 7 |
|---|---|---|---|---|---|
| **1** | 0 | 0 | 1 | 0 | 0 |
| **2** | 0 | 1 | 0 | 0 | 0 |
| **3** | 1 | 0 | 0 | 0 | 0 |
| **4** | 0 | 2 | 0 | 0 | 0 |
| **5** | 0 | 0 | **3** | 0 | 0 |

- $dp[1][3] = 1$、$dp[2][2] = 1$：孤立的单点匹配，左上角没有可接的格子，长度卡在 1。
- $dp[3][1] = dp[2][0] + 1 = 1$，$dp[4][2] = dp[3][1] + 1 = 2$，$dp[5][3] = dp[4][2] + 1 = 3$：三者沿对角线连成 `[3,2,1]`。
- 全表最大值 $3$，对应 `nums1[2..4] = [3,2,1]` 与 `nums2[0..2] = [3,2,1]`，与官方答案一致。

## 4. 算法细节

1. **先交换成「外层长、内层短」**：把较长的数组放在外层循环、较短的作为列，一维 `dp` 的长度取较短者，空间降到 $O(\min(m,n))$。公共子数组的定义对两个数组对称，交换不影响答案。
2. **哨兵 $dp[0]$ 永不写入**：循环从 $j = n$ 到 $1$，不触碰下标 0，因此 $dp[0] = 0$ 恒成立，等价于 $dp[i][0] = 0$；若误写成 `for j in range(n-1, 0, -1)` 就会漏掉最后一列。
3. **逆序是压维的正确性前提**：正序时 $dp[j-1]$ 已被本行覆盖，读到的是 $dp[i][j-1]$（左边），会把「同行相邻」误当成「左上方」，答案偏大。正序写法必须额外用临时变量保存旧的 $dp[j-1]$。
4. **`best` 在转移时更新，而不是最后取 `dp` 最大值**：一维数组只保留最后一行，填完就已丢失历史行，所以必须在每次赋值时顺手比较。
5. **长度上界**：答案不超过 $\min(m,n)$，数组值域 $[0,100]$ 与答案无关，不需要按值域开桶；`int` 完全够用（最大 1000）。
6. **等价的另一条路线（滑动窗口对齐）**：固定偏移 $d = j - i$，沿每条对角线扫描一遍并统计连续相等段，偏移量共 $m + n - 1$ 条，复杂度 $O((m+n)\cdot\min(m,n))$，常数比 DP 更小，适合「内存极紧但可以多扫几遍」的场合。
7. **更「高级」的路线（二分 + 滚动哈希）**：答案具有单调性——存在长度 $L$ 的公共子数组必然存在所有更短长度；于是二分长度，用 Rabin-Karp 把 `nums1` 每个长 $L$ 的窗口哈希进集合，再查 `nums2` 的窗口，复杂度 $O((m+n)\log \min(m,n))$。本题状态数只有 $10^6$，DP 更短更稳，哈希方案留作大数据的备选。

## 5. 正确性证明

**引理 1（$dp$ 的含义）**：$dp[i][j]$ 等于最大的 $k$（$0 \le k \le \min(i,j)$），使得 $nums1[i-k..i-1] = nums2[j-k..j-1]$（$k = 0$ 时两侧都是空串，约定成立）。

**证明**：对 $i + j$ 归纳。$i = 0$ 或 $j = 0$ 时只能取 $k = 0$，命题成立。

若 $nums1[i-1] \ne nums2[j-1]$：$k \ge 1$ 要求两个后缀的末元素相等，矛盾，故最大 $k = 0$，与转移式给出的 $dp[i][j] = 0$ 一致。

若 $nums1[i-1] = nums2[j-1]$：任何 $k \ge 1$ 的公共后缀去掉末元素后，就是 $(i-1, j-1)$ 处长度为 $k-1$ 的公共后缀；由归纳假设，那里的最大长度为 $k' = dp[i-1][j-1]$，于是此处最大 $k = k' + 1$，与转移式一致。∎

**引理 2（答案必被枚举）**：若存在长度 $L$ 的公共子数组，则存在 $(i,j)$ 使 $dp[i][j] \ge L$。

**证明**：设 $nums1[p..p+L-1] = nums2[q..q+L-1]$，取 $i = p + L$、$j = q + L$，则这对元素结尾的公共后缀长度至少为 $L$，由引理 1 得 $dp[i][j] \ge L$。∎

**引理 3（滚动数组不改变结果）**：逆序更新的一维数组在第 $i$ 轮结束时满足 $dp[j] = dp_{\text{二维}}[i][j]$。

**证明**：对 $j$ 从 $n$ 递减归纳。更新 $dp[j]$ 时，下标 $j-1$ 尚未在本轮被写入，其值仍为 $dp_{\text{二维}}[i-1][j-1]$；转移式与二维完全一致，故写入后 $dp[j] = dp_{\text{二维}}[i][j]$。$j = 0$ 保持 0，与 $dp[i][0]$ 一致。∎

**定理**：算法返回的值等于最长公共子数组的长度。

**证明**：设答案为 $L^*$。由引理 2，$\max dp \ge L^*$；由引理 1，任何 $dp[i][j] = k > 0$ 都对应一对真实的、长度为 $k$ 的公共子数组，故 $\max dp \le L^*$。两者相等。算法按引理 3 正确维护一维数组，并在每次赋值时取最大值，故 `best` 恰为 $\max dp = L^*$；无公共元素时全表为 0，返回 0 也正确。∎

## 6. 复杂度分析

- **时间**：$O(mn)$。状态数 $m \times n \le 10^6$，每个状态 $O(1)$ 转移（一次比较、一次加法、一次取最大值）；交换长短数组不改变乘积。
- **空间**：$O(\min(m,n))$。滚动数组长度为较短数组长度加 1，只额外使用常数个变量；若保留二维表则为 $O(mn) = 10^6$ 个 `int`（约 4 MB），本题也在限制内，但没必要。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int findLength(vector<int>& nums1, vector<int>& nums2) {
        if (nums1.size() < nums2.size()) swap(nums1, nums2);
        int m = (int)nums1.size(), n = (int)nums2.size();
        vector<int> dp(n + 1, 0);   // dp[j]：以当前元素结尾的公共后缀长度
        int best = 0;
        for (int i = 1; i <= m; i++) {
            int a = nums1[i - 1];
            for (int j = n; j >= 1; j--) {   // 逆序：dp[j-1] 仍是上一行
                if (a == nums2[j - 1]) {
                    dp[j] = dp[j - 1] + 1;
                    best = max(best, dp[j]);
                } else {
                    dp[j] = 0;
                }
            }
        }
        return best;
    }
};
```

### Python

```python
from typing import List


class Solution:
    def findLength(self, nums1: List[int], nums2: List[int]) -> int:
        # 让 nums2 成为较短的那个，一维 dp 的长度取较短数组
        if len(nums1) < len(nums2):
            nums1, nums2 = nums2, nums1
        m, n = len(nums1), len(nums2)
        dp = [0] * (n + 1)          # dp[j]：以当前元素结尾的公共后缀长度
        best = 0
        for i in range(1, m + 1):
            a = nums1[i - 1]
            # 逆序更新：此时 dp[j-1] 仍是上一行的值，即 dp[i-1][j-1]
            for j in range(n, 0, -1):
                if a == nums2[j - 1]:
                    dp[j] = dp[j - 1] + 1
                    if dp[j] > best:
                        best = dp[j]
                else:
                    dp[j] = 0
        return best
```

## 8. 边界情况与易错点

1. **完全没有公共元素**：如示例 3，全表为 0，`best` 初值必须是 0，不能初始化为 1 或 $-1$ 后忘记处理。
2. **单元素数组**：`nums1 = [5]`、`nums2 = [5]` 时循环只跑一轮，$dp[1] = dp[0] + 1 = 1$，返回 1；`[5]` 与 `[6]` 返回 0。要保证 $n \ge 1$ 时 `dp` 至少长 2。
3. **全是同一个数**：如示例 2，答案就是 $\min(m,n)$，此时每个格子都命中，转移链最长，也最容易暴露「正序更新」的 bug（正序会把答案算成同一行的连续长度，结果仍是 5，但换组数据就会出错）。
4. **把答案写成 $dp[m][n]$**：这是最典型的错误。$dp[m][n]$ 只统计「以两个数组末元素结尾」的那一段，示例 1 中 $dp[5][5] = 0$，而正确答案是 3。
5. **逆序变正序**：正序时 `dp[j-1]` 已被本轮覆盖，读到的是左边格而非左上格，相当于把问题错解成「同一行内连续相同」，必须用临时变量保存旧值或改逆序。
6. **漏掉 $j = n$**：逆序循环的起点必须是 $n$，写成 $n-1$ 会少算最后一列，答案偏小。
7. **交换数组后仍按原长度开数组**：交换后必须重新取 $m, n$，否则 `dp` 长度与内层循环上界不匹配，可能越界。

- [LeetCode 583. 两个字符串的删除操作](https://leetcode.cn/problems/delete-operation-for-two-strings/)：用 LCS 长度反推最少删除次数，与本题共享「公共部分」这一核心量。

**延伸思考**：

1. 若把「两个数组」推广到 $k$ 个数组，状态需要 $k$ 维，空间随 $k$ 指数增长；标准做法是二分长度，再对每个数组求「长度为 $L$ 的窗口哈希集合」并取交集。
2. 若两数组长度升到 $10^5$，$O(mn)$ 不可行；此时二分答案 $L$ 并用双哈希（或后缀数组 + LCP）把判定压到 $O(m+n)$，总复杂度 $O((m+n)\log\min(m,n))$，代价是要处理哈希碰撞（可像 1044 题那样命中后再逐元素确认）。
3. 若要输出**所有**最长公共子数组而不只是一个长度，可在 DP 时额外记录「达到最大值的位置集合」，再按位置切片去重；注意同一段可能在两个数组中多次出现，需要集合去重。
