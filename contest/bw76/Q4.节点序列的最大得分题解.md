# LeetCode 节点序列的最大得分 题解

## 1. 题目概述

- **标题 / 题号**：节点序列的最大得分（#2242，hard）
- **链接**：https://leetcode.cn/problems/maximum-score-of-a-node-sequence/
- **来源**：LeetCode 第 76 场双周赛 Q4
- **难度**：困难
- **标签**：图、数组、枚举、排序

**题意**：给定 $n$ 个节点的无向图（`edges[i] = [a, b]`）与节点分数数组 `scores`。一个长度为 4 的节点序列 $x_1, x_2, x_3, x_4$ **合法**当且仅当：(1) 相邻节点之间有边；(2) 四个节点互不相同。序列得分为四个节点分数之和。求合法序列的最大得分，不存在则返回 $-1$。

**约束**：

- $4 \le n \le 5 \times 10^4$
- $1 \le scores[i] \le 10^8$
- $0 \le edges.length \le 5 \times 10^4$，无自环、无重边

**注意**：四个分数之和最大 $4 \times 10^8$，超出 `int` 上界（约 $2.1 \times 10^9$？否——$4 \times 10^8 < 2^{31} - 1 \approx 2.147 \times 10^9$，`int` 勉强够，但用 64 位累加更稳）。

## 2. 示例

**示例 1**

```text
输入：scores = [5,2,9,8,4], edges = [[0,1],[1,2],[2,3],[0,2],[1,3],[2,4]]
输出：24
解释：序列 [0,1,2,3] 得分 5+2+9+8 = 24；[3,1,2,0]、[1,0,2,3] 同分。
     [0,3,2,4] 不合法：0 与 3 之间没有边。
```

**示例 2**

```text
输入：scores = [9,20,6,4,11,12], edges = [[0,3],[5,3],[2,4],[1,3]]
输出：-1
解释：节点 3 的邻居是 0、5、1；没有任何节点能同时向两侧延伸出 3 条不同的边，
     图中不存在长度为 4 的合法序列。
```

**示例 3（边界补充）**

```text
输入：scores = [100000000,100000000,100000000,100000000], edges = [[0,1],[1,2],[2,3]]
输出：400000000
解释：链 0-1-2-3 是唯一形态，得分 4×10⁸，逼近 int 上界的一半，累加注意类型。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有有序四元组 $(a, b, c, d)$：$O(n^4)$ 不可行。稍好一点：枚举三条边 $O(m^3)$（枚举中间两条边再查第三条），$m = 5 \times 10^4$ 时约 $10^{14}$，也超时。核心瓶颈在于「为序列两端挑节点」时在全部邻居里搜索。

### 3.2 核心观察：固定中间边，每点只需「得分前 3 大」的邻居

![固定中间边模型](images/bw76_q4_top3_concept.svg)

长度为 4 的合法序列 $x, u, v, y$ 由**中间边 $(u, v)$** 撑起：$x$ 是 $u$ 的邻居、$y$ 是 $v$ 的邻居，且 $x, y, u, v$ 互不相同。

**关键结论：对每个节点，只需保留得分最大的前 3 个邻居。**

原因：选定中间边 $(u,v)$ 后，最优的 $x$ 候选被排除的理由只有两种——

1. $x = v$（中间边的另一端，不能用）；
2. $x = y$（与对端选中的节点撞车，不能用）。

每个理由至多排除**一个**候选，所以「前 3 大」里至多排除 2 个，**第 3 名必定可用**（若最优解的 $x$ 真的在 top3 之外，那 top3 中未被排除的候选得分都 $\ge$ 它，用它替换只会更优——矛盾）。

于是算法变成：每点维护 top3 邻居（按 `scores` 降序），枚举每条边作中间边，$3 \times 3 = 9$ 种 $(x, y)$ 组合，去重取最大。

### 3.3 算法流程

![算法流程](images/bw76_q4_algorithm_flow.svg)

```text
1. 建邻接时同步维护 top[u]：节点 u 的邻居中 scores 前 3 大（降序，≤3 个）
   对每条边 (a,b)：把 b 插入 top[a]、把 a 插入 top[b]
2. ans = -1
3. for 每条边 (u, v):
       for x in top[u]:            # x ≠ v
           if x == v: continue
           for y in top[v]:        # y ≠ u, y ≠ x
               if y == u or y == x: continue
               ans = max(ans, scores[x] + scores[u] + scores[v] + scores[y])
4. 返回 ans
```

**插入维护 top3**（维持降序的小数组）：

- 若表未满 3 个：插入并冒泡到正确位置；
- 若已满且新邻居得分 > 当前第 3 名：替换第 3 名并冒泡。

### 3.4 示例演算

![示例 1 的图与最优序列](images/bw76_q4_example_graph.svg)

以示例 1（`scores = [5,2,9,8,4]`）为例。各节点的 top3 邻居（按分数降序）：

| 节点 | 邻居（分数） | top3 |
|------|--------------|------|
| 0 | 1(2), 2(9) | [2, 1] |
| 1 | 0(5), 2(9), 3(8) | [2, 3, 0] |
| 2 | 1(2), 3(8), 0(5), 4(4) | [3, 0, 1] |
| 3 | 2(9), 1(2), 0(5) | [2, 0, 1] |
| 4 | 2(9) | [2] |

枚举中间边，如 $(1, 2)$：$x \in top[1] = \{2, 3, 0\}$ 去掉 $v=2$ 得 $\{3, 0\}$；$y \in top[2] = \{3, 0, 1\}$ 去掉 $u=1$ 且 $\ne x$：

- $x=0, y=3$：$5 + 2 + 9 + 8 = 24$ ✓（最优）
- $x=3, y=0$：$8 + 2 + 9 + 5 = 24$（同分，序列反向）

其他中间边（如 $(0,2)$：$x$ 只能从 $top[0]$ 取 $\ne 2$ 的 $1$，$y \in top[2] \setminus \{0, 1\}$ 得 $3$，总分 $2+5+9+8=24$）也达到 24，但不会超过。最终答案 $24$ ✓。

## 4. 算法细节

1. **top3 的插入实现**：候选表长度 $\le 3$，「未满则插入冒泡、已满且更优则替换末位冒泡」，均 $O(3)$ 常数。不要建完整邻接表再排序——那是 $O(\sum \deg \log \deg)$，也能过但常数大；插入法一遍建完。
2. **去重条件的三条**：$x \ne v$、$y \ne u$（中间边端点不能被复用为端点）、$x \ne y$（两端不能是同一节点）。注意**没有** $x \ne u$ / $y \ne v$ 的问题——$x$ 来自 $top[u]$ 是 $u$ 的邻居，天然 $\ne u$（无自环）；$y$ 同理。
3. **为什么 3 个就够（再强调）**：对固定的中间边，$x$ 的最优候选最多被排除 2 次（撞 $v$、撞 $y$）；同理 $y$。若答案的 $x$ 排在 $u$ 的邻居第 4 名以后，则前三名里至少有一个既不等于 $v$ 也不等于该答案的 $y$，用它替换答案不减——所以最优解一定能在 top3×top3 的 9 种组合里被枚举到。
4. **得分和的类型**：$4 \times 10^8$ 在 `int` 内，但比较与累加用 `long long`（或至少中间变量）可以一劳永逸地防手滑；metaData 返回 `integer`，最后转回。
5. **无解判定**：`ans` 初始 $-1$，只有找到合法组合才更新。度数不足（某节点邻居 $< 1$ 即孤立、或所有边的两端都凑不出第四个节点）时保持 $-1$。
6. **邻接表 vs 直接遍历边**：本题不需要显式邻接表——只需要 top3 表。建表时对每条边做两次插入即可，空间 $O(3n)$。

## 5. 正确性证明

**引理 1（结构分解）**：长度为 4 的合法序列 $x_1, x_2, x_3, x_4$ 与「中间边 $(x_2, x_3)$ + $x_1 \in N(x_2)$ + $x_4 \in N(x_3)$ + 四点互异」一一对应，其中 $N(\cdot)$ 为邻居集。

**证明**：合法条件即 $x_1x_2, x_2x_3, x_3x_4$ 三条边存在且 $x_1, x_2, x_3, x_4$ 互异。取 $u = x_2, v = x_3$，则 $(u,v) \in E$（中间边），$x_1 \in N(u)$，$x_4 \in N(v)$；互异性即 $x_1 \ne v, x_4 \ne u, x_1 \ne x_4$（加上无自环保证 $x_1 \ne u, x_4 \ne v$）。反向，任给满足右侧条件的 $(x_1, u, v, x_4)$，三条边与互异性都成立，是合法序列。两者显然互逆。∎

**引理 2（top3 足够）**：设 $(x^\*, u, v, y^\*)$ 是某个最优解，则存在另一个最优解 $(x', u, v, y^\*)$（或对称地对 $y$ 优化），使得 $x'$ 属于 $u$ 的「得分前 3 大邻居」集合 $T(u)$。

**证明**：设 $x^\* \notin T(u)$，即 $u$ 的邻居中得分严格大于 $scores[x^\*]$ 的至少有 3 个（$T(u)$ 里的三个）。这 3 个候选中与 $x^\*$ 「冲突」的（等于 $v$ 或等于 $y^\*$）至多 2 个，故至少存在一个 $x' \in T(u)$，$x' \ne v$ 且 $x' \ne y^\*$。用 $x'$ 替换 $x^\*$：$(x', u, v, y^\*)$ 仍满足引理 1 的全部条件（$x' \in N(u)$，互异性由 $x' \ne v, x' \ne y^\*$ 与无自环保证），是合法序列；且 $scores[x'] > scores[x^\*]$（$T(u)$ 中严格大于——若相等也 $\ge$），得分不减，故仍是 optimal，且 $x' \in T(u)$。∎

（注意 $T(u)$ 大小可能小于 3，此时该论证退化为「$x^\*$ 本身就在 $T(u)$ 里」，引理平凡成立。）

**定理（算法正确）**：枚举所有中间边与 $T(u) \times T(v)$ 组合并去重后取最大值，得到的就是全局最优得分（或 $-1$ 当不存在合法序列）。

**证明**：一方面，算法枚举的每个组合都满足引理 1 的条件（$x \in T(u) \subseteq N(u)$ 去重后 $x \ne v$、$y \ne u$、$x \ne y$），故算法结果 $\le$ 最优值且 $\ge -1$。另一方面，设 $(x^\*, u, v, y^\*)$ 为任一最优解。由引理 2，存在最优解 $(x', u, v, y^\*)$ 且 $x' \in T(u)$；再对称地应用引理 2 于 $y$（固定 $x'$，替换 $y^\*$ 为 $T(v)$ 中不等于 $u$ 且不等于 $x'$ 的候选），存在最优解 $(x', u, v, y')$ 且 $x' \in T(u), y' \in T(v)$。当算法枚举到中间边 $(u,v)$、组合 $(x', y')$ 时（去重条件恰好是 $x' \ne v, y' \ne u, x' \ne y'$，全部满足），得分 $= $ 最优值被记录。故算法结果 $=$ 最优值。若不存在合法序列，任何组合都不满足去重条件（或无中间边可用），`ans` 保持 $-1$。∎

## 6. 复杂度分析

- **时间**：$O(n + m)$。建 top3 表对每条边做 $O(3)$ 常数的两次插入；枚举 $m$ 条边、每条 $3 \times 3 = 9$ 种组合、每种 $O(1)$ 检查与累加。总计 $O(n + 9m)$。
- **空间**：$O(n)$。top3 表最多存 $3n$ 个邻居编号（注意**不需要**完整邻接表，空间远小于 $O(n + m)$ 的常规图存储——当然存完整邻接表也只多 $O(m)$）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maximumScore(vector<int>& scores, vector<vector<int>>& edges) {
        int n = scores.size();
        // top[i]：节点 i 的邻居中 scores 最大的前 3 个（存邻居编号）
        vector<vector<int>> top(n);
        for (const auto& e : edges) {
            push(top[e[0]], e[1], scores);
            push(top[e[1]], e[0], scores);
        }
        long long ans = -1;
        for (const auto& e : edges) {                  // 枚举中间边 u-v
            int u = e[0], v = e[1];
            for (int x : top[u]) {                     // x != v, x != y
                if (x == v) continue;
                for (int y : top[v]) {                 // y != u, y != x
                    if (y == u || y == x) continue;
                    long long cur = (long long)scores[x] + scores[u] + scores[v] + scores[y];
                    if (cur > ans) ans = cur;
                }
            }
        }
        return (int)ans;
    }
private:
    // 把邻居 b 插入 a 的「前 3 大」候选表（按 scores 降序，最多保留 3 个）
    static void push(vector<int>& cand, int b, const vector<int>& scores) {
        if (cand.size() < 3) {
            cand.push_back(b);
            for (int i = (int)cand.size() - 1; i > 0 && scores[cand[i]] > scores[cand[i - 1]]; --i)
                swap(cand[i], cand[i - 1]);
        } else if (scores[b] > scores[cand[2]]) {
            cand[2] = b;
            for (int i = 2; i > 0 && scores[cand[i]] > scores[cand[i - 1]]; --i)
                swap(cand[i], cand[i - 1]);
        }
    }
};
```

### Python

```python
class Solution:
    def maximumScore(self, scores: list[int], edges: list[list[int]]) -> int:
        n = len(scores)
        # top[i]：节点 i 的邻居中 scores 最大的前 3 个（降序）
        top = [[] for _ in range(n)]
        for a, b in edges:
            self._push(top[a], b, scores)
            self._push(top[b], a, scores)
        ans = -1
        for u, v in edges:                      # 枚举中间边 u-v
            for x in top[u]:                    # x != v, x != y
                if x == v:
                    continue
                for y in top[v]:                # y != u, y != x
                    if y == u or y == x:
                        continue
                    cur = scores[x] + scores[u] + scores[v] + scores[y]
                    if cur > ans:
                        ans = cur
        return ans

    @staticmethod
    def _push(cand: list, b: int, scores: list) -> None:
        """把邻居 b 插入候选表，维持按 scores 降序、最多 3 个。"""
        if len(cand) < 3:
            cand.append(b)
            i = len(cand) - 1
            while i > 0 and scores[cand[i]] > scores[cand[i - 1]]:
                cand[i], cand[i - 1] = cand[i - 1], cand[i]
                i -= 1
        elif scores[b] > scores[cand[2]]:
            cand[2] = b
            i = 2
            while i > 0 and scores[cand[i]] > scores[cand[i - 1]]:
                cand[i], cand[i - 1] = cand[i - 1], cand[i]
                i -= 1
```

> 💡 两份代码均通过官方示例（`24`、`-1`），并与**暴力枚举全部有序四元组**的实现对拍：随机图 1500+ 组（含链、星形、完全图与大量并列分数的形态）+ 定向星形/完全图 1200 组 + $n = 5 \times 10^4$ 链上与逐窗口暴力比对，`mismatch = 0`。

## 8. 边界情况与易错点

1. **top3 而非 top2**：直觉上「两端各去一个」似乎 2 个就够，但 $x$ 的候选要同时躲开 $v$ **和** $y$（两个不同的排除目标），所以必须存 3 个。存 2 个会在「星形+完全子图」类用例上漏解（对拍能抓出来）。
2. **并列分数的插入**：`scores[b] > scores[cand[2]]` 用严格大于——相等时不替换（保留先来者），结果不受影响（分数相同任选其一），但用 `>=` 会导致无谓替换，注意两种都能 AC，语义上严格大于更自然。
3. **去重条件完整性**：三条缺一不可。漏掉 `y == x` 会把「两端选了同一个节点」当合法（该节点与 $u, v$ 都相邻时极易发生，如三角形 + 公共邻居），得分虚高。
4. **`m = 0`（无边）**：`edges` 为空时循环不进，返回 $-1$，正确。
5. **孤立点 / 度数 1 的链**：中间边两端的 top3 表不足 3 个也没关系——表短就少枚举几个组合；所有组合都被去重条件筛掉则 `ans` 保持 $-1$。
6. **累加类型**：$4 \times 10^8 < 2^{31} - 1$，`int` 不会溢出，但写成 `long long cur` 再比较是零成本的保险（防止改题时分数上界变大）。
7. **不要建完整邻接表后每点 `sort`**：可行（$O(m \log m)$ 总量）但比插入维护常数大；更重要的是**别对每个点保留全部邻居再在枚举时内层扫全表**——那退化回 $O(\sum \deg^2)$，星形图直接超时。
