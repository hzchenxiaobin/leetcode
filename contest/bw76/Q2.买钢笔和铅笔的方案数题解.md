# LeetCode 买钢笔和铅笔的方案数 题解

## 1. 题目概述

- **标题 / 题号**：买钢笔和铅笔的方案数（#2240，medium）
- **链接**：https://leetcode.cn/problems/number-of-ways-to-buy-pens-and-pencils/
- **来源**：LeetCode 第 76 场双周赛 Q2
- **难度**：中等
- **标签**：数学、枚举

**题意**：你有 `total` 元钱，钢笔单价 `cost1`、铅笔单价 `cost2`。可以花部分或全部的钱买任意数量的两种笔（也可以什么都不买）。求不同的购买方案数——两种数量组成的有序对 $(p, q)$ 互不相同即视为不同方案。

**约束**：

- $1 \le total, cost1, cost2 \le 10^6$

**注意**：最坏情形（$total = 10^6$、两价均为 1）方案数为 $\binom{10^6+2}{2} \approx 5 \times 10^{11}$，需要 64 位整数。

## 2. 示例

**示例 1**

```text
输入：total = 20, cost1 = 10, cost2 = 5
输出：9
解释：买 0 支钢笔时可买 0..4 支铅笔（5 种）；买 1 支时可买 0..2 支（3 种）；
     买 2 支时只能 0 支（1 种）。共 5 + 3 + 1 = 9 种。
```

**示例 2**

```text
输入：total = 5, cost1 = 10, cost2 = 10
输出：1
解释：两种笔都买不起，唯一方案是 (0, 0)。
```

**示例 3（边界补充）**

```text
输入：total = 1000000, cost1 = 1, cost2 = 1
输出：500001500001
解释：p + q ≤ 10⁶ 的非负整数对个数 = (10⁶+1)(10⁶+2)/2。
```

## 3. 解题思路

### 3.1 暴力思路

双重循环枚举 $(p, q)$，检查 $p \cdot cost_1 + q \cdot cost_2 \le total$。最坏内层各 $10^6$ 次，总计 $10^{12}$ 量级，超时。但注意**内层可以直接用除法算出**，不需要循环——这就是正解。

### 3.2 核心观察：固定一个变量，另一个只剩算术

![枚举钢笔数](images/bw76_q2_enumerate.svg)

方案 $(p, q)$ 合法当且仅当 $p \cdot cost_1 + q \cdot cost_2 \le total$。**枚举钢笔数 $p$**（满足 $p \cdot cost_1 \le total$，共 $\lfloor total / cost_1 \rfloor + 1$ 个取值），则铅笔的可选数量为

$$q \in \left[0,\; \left\lfloor \frac{total - p \cdot cost_1}{cost_2} \right\rfloor\right]$$

共 $\left\lfloor \frac{total - p \cdot cost_1}{cost_2} \right\rfloor + 1$ 种。全部相加：

$$ans = \sum_{p = 0}^{\lfloor total / cost_1 \rfloor} \left( \left\lfloor \frac{total - p \cdot cost_1}{cost_2} \right\rfloor + 1 \right)$$

### 3.3 算法流程

```text
1. ans = 0
2. for p = 0; p * cost1 <= total; p++:
       ans += (total - p * cost1) / cost2 + 1     # 整除
3. 返回 ans
```

循环次数 $\lfloor total / cost_1 \rfloor + 1 \le 10^6 + 1$（当 $cost_1 = 1$ 时最多），每次 $O(1)$。

### 3.4 示例演算

![格点模型](images/bw76_q2_lattice.svg)

把 $(p, q)$ 看成第一象限的**整格点**，约束 $p \cdot cost_1 + q \cdot cost_2 \le total$ 是一条斜率为负的直线以下的三角形区域。以示例 1（$total=20, cost_1=10, cost_2=5$）为例：

| $p$ | 剩余 $total - 10p$ | $\lfloor 剩余/5 \rfloor + 1$ | 方案 |
|-----|--------------------|------------------------------|------|
| 0 | 20 | $4 + 1 = 5$ | $q \in \{0,1,2,3,4\}$ |
| 1 | 10 | $2 + 1 = 3$ | $q \in \{0,1,2\}$ |
| 2 | 0 | $0 + 1 = 1$ | $q = 0$ |

合计 $5 + 3 + 1 = 9$ ✓。竖直数格点（按 $p$ 分列）正是「枚举一维、算术求另一维」的几何解释。

## 4. 算法细节

1. **枚举维度选择**：枚举 $cost_1$（钢笔）与 $cost_2$（铅笔）在数学上对称，循环次数由「贵的那支」决定更少——但两者都 $\le 10^6 + 1$ 次循环，选哪个都能过。若想保险起见，可以枚举 $\max(cost_1, cost_2)$ 对应的那一支。
2. **整除与取整**：语言内置整除（C++ `/` 对非负整数即下取整、Python `//`）直接可用；注意全程数值非负，无负数取整陷阱。
3. **乘法用 64 位**：C++ 中 `p * cost1` 在 $p, cost_1 \le 10^6$ 时可达 $10^{12}$，**必须**把 `p` 声明为 `long long`（或先转型再乘）。答案本身也是 `long long`（metaData 返回 `long`）。
4. **「部分或全部」包含零消费**：什么都不买 $(0,0)$ 也是方案，公式里 $p = 0$ 行的 $+1$ 已包含 $q = 0$，无需特判。
5. **进一步的封闭式（拓展）**：记 $m = \lfloor total/cost_1 \rfloor$，利用整除分块（floor sum）技术可把 $\sum_p \lfloor (total - p\,cost_1)/cost_2 \rfloor$ 在 $O(\log)$ 时间内求出（类似 `atcoder` 库的 `floor_sum`）。本题 $10^6$ 循环足够，不必上工具。

## 5. 正确性证明

**引理 1（双射）**：购买方案与满足 $p \cdot cost_1 + q \cdot cost_2 \le total$ 的非负整数对 $(p, q)$ 一一对应。

**证明**：一种购买方案由「钢笔数 $p$、铅笔数 $q$」完全刻画（同种笔之间无差别），其花费为 $p \cdot cost_1 + q \cdot cost_2$，题目允许花费部分或全部的钱，即花费 $\le total$；反之任何满足约束的非负整数对都能被购买。故方案数 = 可行 $(p,q)$ 对数。∎

**定理（求和公式正确）**：

$$\#\{(p,q) : p, q \ge 0,\; p\,cost_1 + q\,cost_2 \le total\} = \sum_{p=0}^{\lfloor total/cost_1 \rfloor} \left( \left\lfloor \frac{total - p\,cost_1}{cost_2} \right\rfloor + 1 \right)$$

**证明**：把可行集合按 $p$ 的取值划分成互斥的类 $\{p = p_0\}$。$p$ 可行的充要条件是 $p\,cost_1 \le total$（此时 $q = 0$ 总可行），即 $0 \le p \le \lfloor total / cost_1 \rfloor$。固定 $p$ 后，$q$ 的可行条件为 $q \le \frac{total - p\,cost_1}{cost_2}$，非负整数解的个数为 $\lfloor (total - p\,cost_1)/cost_2 \rfloor + 1$（从 $q = 0$ 到 $q_{\max}$ 共 $q_{\max} + 1$ 个）。各类数目相加即总数。∎

**推论（循环边界正确）**：代码 `while p * cost1 <= total`（或 for 循环条件）恰好枚举 $p \in [0, \lfloor total/cost_1 \rfloor]$，与定理一致；超出后剩余钱为负，公式不再有意义，循环终止正确。∎

## 6. 复杂度分析

- **时间**：$O(total / cost_1 + 1)$，最坏 $10^6 + 1$ 次迭代（$cost_1 = 1$），每次一次乘法、一次除法、一次累加，实测毫秒级。
- **空间**：$O(1)$，只有几个计数变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long waysToBuyPensPencils(int total, int cost1, int cost2) {
        long long ways = 0;
        for (long long pens = 0; pens * cost1 <= total; ++pens) {
            ways += (total - pens * cost1) / cost2 + 1;   // 铅笔可买 0..剩余/cost2
        }
        return ways;
    }
};
```

### Python

```python
class Solution:
    def waysToBuyPensPencils(self, total: int, cost1: int, cost2: int) -> int:
        ways = 0
        pens = 0
        while pens * cost1 <= total:            # 枚举钢笔数
            ways += (total - pens * cost1) // cost2 + 1
            pens += 1
        return ways
```

> 💡 两份代码均通过官方示例（`9`、`1`），并与**双重循环暴力枚举**（小数据）对拍 4000+ 组随机用例（含单价超过总额、两笔同价等边界），另以 $total = 10^6$、两价均为 1 验证闭式 $\frac{(T+1)(T+2)}{2} = 500001500001$，`mismatch = 0`。

## 8. 边界情况与易错点

1. **C++ 溢出是最大陷阱**：`pens * cost1` 若 `pens` 是 `int` 会先按 32 位相乘（$10^6 \times 10^6 = 10^{12}$ 溢出为垃圾值）再与 `total` 比较，循环边界直接错乱。`pens` 必须是 `long long`（或 `(long long)pens * cost1`）。答案累加同理。
2. **两笔都买不起**（$cost_1, cost_2 > total$）：循环只执行 $p = 0$ 一轮，结果为 $0 + 1 = 1$（唯一方案什么都不买），与示例 2 一致，无需特判。
3. **「部分或全部」**：允许不花完，也能一分不花；公式天然覆盖，别画蛇添足地排除 $(0,0)$。
4. **枚举哪支笔**：若误以为必须枚举便宜的（次数多），在 $cost_1 = 10^6, cost_2 = 1$、$total = 10^6$ 时枚举铅笔会有 $10^6+1$ 轮（也 OK）；反之枚举钢笔只有 2 轮。两个方向都在时限内，但意识到「枚举贵的那支更快」是有益的直觉。
5. **别用浮点**：`(total - p * cost1) / cost2` 用整数除法；浮点除再取整在边界处（整除恰好的情形）可能因精度差 1。
6. **答案规模**：最大约 $5 \times 10^{11}$，Java/C++ 需 `long`/`long long`；Python 无碍。
