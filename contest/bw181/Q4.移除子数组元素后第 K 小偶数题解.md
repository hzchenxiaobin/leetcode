# LeetCode 移除子数组元素后第 K 小偶数 题解

## 1. 题目概述

- **标题 / 题号**：移除子数组元素后第 K 小偶数（#3911，hard）
- **链接**：https://leetcode.cn/problems/k-th-smallest-remaining-even-integer-in-subarray-queries/
- **来源**：LeetCode 第 181 场双周赛 Q4
- **难度**：困难
- **标签**：数组、二分查找、前缀和

**题意**：给定**严格递增**的整数数组 `nums`，以及若干查询 `queries[i] = [l, r, k]`。对每个查询：

1. 取子数组 `nums[l..r]`；
2. 从无限序列 $2, 4, 6, 8, 10, \dots$（全体正偶数）中**删掉**所有在 `nums[l..r]` 里出现过的偶数；
3. 求删除后序列里**第 $k$ 小**的整数。

返回每个查询的答案组成的数组。

**约束**：

- $1 \le n \le 10^5$，$1 \le nums[i] \le 10^9$，`nums` 严格递增
- $1 \le queries.length \le 10^5$，$queries[i] = [l_i, r_i, k_i]$
- $0 \le l_i \le r_i < n$，$1 \le k_i \le 10^9$

## 2. 示例

**示例 1**

```text
输入：nums = [1,4,7], queries = [[0,2,1],[1,1,2],[0,0,3]]
输出：[2,6,6]
解释：查询 0 删除 {4}，剩余 2,6,8,…，第 1 小是 2；
     查询 1 删除 {4}，剩余 2,6,8,…，第 2 小是 6；
     查询 2 子数组为 [1]（无偶数），剩余 2,4,6,…，第 3 小是 6。
```

**示例 2**

```text
输入：nums = [2,5,8], queries = [[0,1,2],[1,2,1],[0,2,4]]
输出：[6,2,12]
解释：查询 0 删除 {2}，第 2 小是 6；查询 1 删除 {8}，第 1 小是 2；
     查询 2 删除 {2,8}，剩余 4,6,10,12,…，第 4 小是 12。
```

**示例 3**

```text
输入：nums = [3,6], queries = [[0,1,1],[1,1,3]]
输出：[2,8]
解释：查询 0 删除 {6}，第 1 小是 2；查询 1 同样只删 {6}，第 3 小是 8（4、8 之间 6 被删）。
```

## 3. 解题思路

### 3.1 暴力思路

对每个查询，把子数组里的偶数收集成集合（$O(n)$），再从 $2$ 开始逐个偶数检查是否被删、数到第 $k$ 个（$O(k)$）。$k$ 可达 $10^9$，单次查询就要 $10^9$ 次枚举，$10^5$ 个查询直接爆炸；即便把 $k$ 压到 $10^5$，$O(n \cdot q)$ 也是 $10^{10}$。

所以必须把「数到第 $k$ 个」这一步压缩成**一次判定**：给定候选偶数 $m$，用 $O(\log n)$ 算出「删除后 $\le m$ 的剩余偶数个数」，然后**二分**最小的 $m$。

### 3.2 核心观察：被删掉的偶数构成「连续片段」

![模型：从全体正偶数里挖掉子数组中的偶数](images/bw181_q4_model.svg)

- **只关心偶数**：答案一定在偶数序列里，删除只影响那些恰好等于某个 `nums[i]` 的偶数。
- **关键恒等式**：设候选偶数为 $m$，若一个偶数都没被删，则 $\le m$ 的偶数有 $m/2$ 个。被删的偶数里有多少个 $\le m$？设其为 $c(m)$，则

$$\operatorname{count}(m) = \frac{m}{2} - c(m)$$

就是删除后 $\le m$ 的剩余偶数个数。答案就是最小的偶数 $m$ 使 $\operatorname{count}(m) \ge k$。

- **$c(m)$ 用前缀和一次算出**：$c(m) = $ 子数组 `nums[l..r]` 中「值 $\le m$ 的偶数」的个数。由于 `nums` **严格递增**，先用 `upper_bound` 在 `nums[l..r]` 上找到最后一个 $\le m$ 的位置 $pos$，再用「偶数个数的前缀和」$pref$ 得到区间 $[l, pos]$ 里的偶数个数，即 $c(m) = pref[pos+1] - pref[l]$（$pos < l$ 时为 0）。
- **单调性**：$m$ 增大时 $m/2$ 每次加 1，而 $c(m)$ 可能加 1 也可能不变，故 $\operatorname{count}(m)$ **单调不减**，可以二分。

### 3.3 算法流程

![二分答案：count(m) 是 m 的单调不减函数](images/bw181_q4_binary_search.svg)

```text
1. 预处理：pref[i] = nums[0..i-1] 中偶数的个数，O(n)
2. 对每个查询 (l, r, k)：
     lo = k, hi = k + (r - l + 1)          // 以「第几个偶数」为单位二分
     while lo < hi:
         mid = (lo + hi) / 2
         m = 2 * mid
         pos = upper_bound(nums[l..r], m) - 1
         c = (pos < l) ? 0 : pref[pos + 1] - pref[l]
         if mid - c >= k: hi = mid else: lo = mid + 1
     答案 = 2 * lo
```

**为什么二分的是「第几个偶数」而不是数值**：令 $x = m/2$，则 $\operatorname{count}(m) = x - c(2x)$，搜索区间是 $x \in [k, k + (r-l+1)]$——下界 $k$ 是「一个都没删」时的答案，上界是「最坏情况全部删掉」时的答案（被删的偶数个数不超过子数组长度）。这个区间与 $nums[i]$ 的数值范围无关，天然避开了 $10^9$ 量级的大范围。

### 3.4 示例演算

![示例 2 演算：三个查询各自删除不同的偶数](images/bw181_q4_walkthrough.svg)

以示例 2 的 `nums = [2,5,8]`、查询 `[0,2,4]` 为例（删除 $\{2, 8\}$）：

| $x$ | $m = 2x$ | $c(m)$（$\le m$ 的被删偶数） | $\operatorname{count} = x - c$ | $\ge 4$？ |
|-----|----------|-------------------------------|--------------------------------|-----------|
| 4 | 8 | 2（2 和 8） | 2 | ✗ |
| 5 | 10 | 2 | 3 | ✗ |
| 6 | 12 | 2 | 4 | ✓ |

最小可行 $x = 6$，答案 $2 \times 6 = 12$，与题面一致。再看查询 `[0,1,2]`（删除 $\{2\}$）：$x = 2, m = 4$ 时 $c = 1$，$\operatorname{count} = 1 < 2$；$x = 3, m = 6$ 时 $c = 1$，$\operatorname{count} = 2 \ge 2$，答案 $6$。

## 4. 算法细节

1. **偶数前缀和**：`pref[i+1] = pref[i] + (nums[i] % 2 == 0)`，$O(n)$ 预处理，查询时 $O(1)$ 取区间偶数个数。
2. **`upper_bound` 的范围**：只在 `nums[l..r]` 上二分（`nums.begin()+l` 到 `nums.begin()+r+1`），不要在全数组上二分后再截断，否则要多写一次越界判断。
3. **`pos < l` 的处理**：说明子数组内没有 $\le m$ 的元素，$c(m) = 0$，此时 `pref[pos+1] - pref[l]` 会算出负值，必须先判空区间。
4. **二分的边界**：`lo = k`、`hi = k + len`，其中 `len = r - l + 1`。`hi` 一定可行：最坏情况子数组里的偶数全部 $\le 2 \cdot hi$ 且被删，此时 $\operatorname{count}(2\,hi) = hi - len \ge k$。
5. **溢出**：$2 \times (10^9 + 10^5) = 2.0002 \times 10^9 < 2^{31}-1$，`int` 刚好够，但中间量 `2 * mid` 与比较建议统一用 `long long`，避免边界上险象环生。
6. **答案一定是偶数**：删除只发生在偶数上，序列里只有偶数，无需再判奇偶。

## 5. 正确性证明

**引理 1（计数公式）**：对任意偶数 $m$，删除后 $\le m$ 的剩余偶数个数为 $\operatorname{count}(m) = m/2 - c(m)$，其中 $c(m)$ 是子数组内值 $\le m$ 的偶数个数。

**证明**：$\le m$ 的正偶数共有 $m/2$ 个。删除操作恰好删去「子数组内出现过的偶数」，其中 $\le m$ 的部分就是 $c(m)$ 个，其余被删的偶数都 $> m$、不影响 $\le m$ 的计数。故剩余个数为 $m/2 - c(m)$。∎

**引理 2（$c(m)$ 的计算正确）**：`pos = upper_bound(nums[l..r], m) - 1`，则 $c(m) = pref[pos+1] - pref[l]$（$pos < l$ 时 $c(m) = 0$）。

**证明**：`nums` 严格递增，`upper_bound` 给出 $[l, r]$ 中第一个 $> m$ 的位置，故 $[l, pos]$ 恰是子数组内所有 $\le m$ 的元素；$pref$ 是该区间的偶数个数前缀和，相减即得区间内偶数个数。若 $pos < l$ 则区间为空，$c = 0$。∎

**引理 3（单调性）**：$\operatorname{count}(2x) = x - c(2x)$ 关于 $x$ 单调不减。

**证明**：$c(2x)$ 随 $x$ 增大只增不减，且 $c(2x+2) - c(2x) \le 1$（只多包含一个候选偶数）。于是 $\operatorname{count}(2x+2) - \operatorname{count}(2x) = 1 - (c(2x+2) - c(2x)) \ge 0$。∎

**定理**：算法对每个查询返回删除后第 $k$ 小的偶数。

**证明**：由引理 3，$\operatorname{count}(2x)$ 单调不减，二分可在区间 $[k, k+len]$ 内找到最小的 $x^\*$ 使 $\operatorname{count}(2x^\*) \ge k$（该区间右端点可行，因为最多删除 $len$ 个偶数）。由引理 1、2，$\operatorname{count}$ 就是真实的剩余个数，故第 $k$ 小的偶数正是 $2x^\*$：$\le 2x^\*-2$ 的剩余偶数不足 $k$ 个，而 $\le 2x^\*$ 的至少有 $k$ 个，说明第 $k$ 个恰好是 $2x^\*$。∎

## 6. 复杂度分析

- **时间**：预处理 $O(n)$；单次查询二分 $O(\log len)$ 轮，每轮一次 `upper_bound` 为 $O(\log len)$，故 $O(\log^2 n)$，总计 $O(n + q \log^2 n)$。$n, q = 10^5$ 时约 $10^5 \times 17 \times 17 \approx 3 \times 10^7$ 次比较，实测 C++ 约 $0.3$ s、Python 约 $0.7$ s。
- **空间**：$O(n)$（偶数前缀和数组）+ $O(q)$（答案数组）；额外工作变量 $O(1)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> kthRemainingInteger(vector<int>& nums, vector<vector<int>>& queries) {
        int n = nums.size();
        vector<int> pref(n + 1, 0);
        for (int i = 0; i < n; i++) pref[i + 1] = pref[i] + (nums[i] % 2 == 0 ? 1 : 0);
        vector<int> ans;
        ans.reserve(queries.size());
        for (auto& q : queries) {
            int l = q[0], r = q[1];
            long long k = q[2];
            long long lo = k, hi = k + (r - l + 1);
            while (lo < hi) {
                long long mid = (lo + hi) / 2;
                long long m = 2 * mid;
                int pos = int(upper_bound(nums.begin() + l, nums.begin() + r + 1, m) - nums.begin()) - 1;
                long long removed = (pos < l) ? 0 : (long long)(pref[pos + 1] - pref[l]);
                if (mid - removed >= k) hi = mid;
                else lo = mid + 1;
            }
            ans.push_back((int)(2 * lo));
        }
        return ans;
    }
};
```

### Python

```python
from bisect import bisect_right


class Solution:
    def kthRemainingInteger(self, nums: list[int], queries: list[list[int]]) -> list[int]:
        n = len(nums)
        pref = [0] * (n + 1)
        for i, v in enumerate(nums):
            pref[i + 1] = pref[i] + (v % 2 == 0)

        def removed_le(l: int, r: int, m: int) -> int:
            pos = bisect_right(nums, m, l, r + 1) - 1
            if pos < l:
                return 0
            return pref[pos + 1] - pref[l]

        ans = []
        for l, r, k in queries:
            lo, hi = k, k + (r - l + 1)
            while lo < hi:
                mid = (lo + hi) // 2
                if mid - removed_le(l, r, 2 * mid) >= k:
                    hi = mid
                else:
                    lo = mid + 1
            ans.append(2 * lo)
        return ans
```

## 8. 边界情况与易错点

1. **子数组里没有偶数**：$c(m) \equiv 0$，答案就是 $2k$。示例 1 的查询 2 即此类，答案是 $6 = 2 \times 3$。
2. **$k = 1$ 且最小偶数被删**：如 `nums = [2]`、$k = 1$，答案必须是 $4$。二分下界取 $x = k = 1$ 时 $\operatorname{count}(2) = 0 < 1$，会自然右移到 $x = 2$。
3. **`pos < l` 的负值陷阱**：`pref[pos+1] - pref[l]` 在 `pos = l-1` 时为 $0$，但若 `pos = -1`（`upper_bound` 返回 `begin()+l`）会变成 `pref[0] - pref[l]`，负数！必须先判空。
4. **二分区间上界**：必须取 `k + len`，只取 `k` 会在「子数组全是偶数」时死循环或返回错误。
5. **`int` 与 `long long`**：$2 \times (10^9 + 10^5)$ 仍在 `int` 范围内，但 `mid + hi` 之类的中间运算建议用 `long long`，防止极端测试被卡。
6. **删除的是「值」而不是「下标」**：即便同一个偶数在别处也出现，只要它在子数组内出现过就被删；本题 `nums` 严格递增，天然不会重复。
7. **答案与 `nums` 的值域无关**：即使 `nums[i]` 全是奇数、全都大于候选区间，答案也不受影响——题目删的是「偶数序列里的值」，只有偶数才对判定有贡献。
