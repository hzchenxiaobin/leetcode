# LeetCode 统计节点和为偶数的连通子图 题解

## 1. 题目概述

- **标题 / 题号**：统计节点和为偶数的连通子图（#3910，hard）
- **链接**：https://leetcode.cn/problems/count-connected-subgraphs-with-even-node-sum/
- **来源**：LeetCode 第 181 场双周赛 Q3
- **难度**：困难
- **标签**：位运算、深度优先搜索、广度优先搜索、并查集、图、数组、枚举

**题意**：给定 $n$ 个节点的无向图，节点 $i$ 的值为 $nums[i] \in \{0, 1\}$，边集为 `edges`。对节点的**非空**子集 $s$，其**诱导子图**是「只保留 $s$ 中的点、只保留两端都在 $s$ 中的边」得到的图。

求同时满足下面两条的非空子集 $s$ 的个数：

1. $s$ 的诱导子图**连通**；
2. $s$ 中节点值之和为**偶数**。

**约束**：

- $1 \le n \le 13$
- $nums[i] \in \{0, 1\}$
- $0 \le edges.length \le \frac{n(n-1)}{2}$，边两两不同，且 $edges[i] = [u_i, v_i]$ 满足 $u_i < v_i$

## 2. 示例

**示例 1**

```text
输入：nums = [1,0,1], edges = [[0,1],[1,2]]
输出：2
解释：图为 0-1-2 一条链。逐个子集检查：
     {0} 连通、和为 1（奇）✗        {1} 连通、和为 0（偶）✓
     {2} 连通、和为 1 ✗             {0,1} 连通、和为 1 ✗
     {0,2} 不连通（0 与 2 无边）✗   {1,2} 连通、和为 1 ✗
     {0,1,2} 连通、和为 2（偶）✓    答案 = 2
```

**示例 2**

```text
输入：nums = [1], edges = []
输出：0
解释：唯一的非空子集 {0} 连通，但和为 1（奇数），故答案为 0。
```

## 3. 解题思路

### 3.1 暴力思路

把所有非空子集枚举出来，对每个子集判断「诱导子图是否连通」与「节点和奇偶性」。除了枚举本身，没有任何已知的多项式算法——**统计连通导出子图**在一般图上是 #P 难问题，因此本题的关键不在算法技巧，而在 $n \le 13$ 这个数据范围：

$$2^{13} - 1 = 8191$$

只有 8191 个非空子集，每个子集做一次 $O(n)$ 的连通性检查，总计约 $10^5$ 次基本操作，完全可以直接暴力。**看到 $n \le 13$ 就该条件反射地想到「枚举子集 + 位掩码」。**

### 3.2 核心观察：子集 = 掩码，连通性 = 位运算扩散

![枚举子集：一个 n 位掩码描述一个诱导子图](images/bw181_q3_bitmask_model.svg)

- **子集编码**：用一个 $n$ 位整数 $mask$ 表示子集，第 $i$ 位为 $1$ 表示节点 $i$ 被选中。把 $mask$ 从 $1$ 枚举到 $2^n - 1$ 就覆盖了全部非空子集，天然不重不漏。
- **奇偶性 O(1)**：因为 $nums[i] \in \{0,1\}$，子集和就是「选中了多少个值为 1 的节点」。把值为 1 的位置另存为一个掩码 `onesMask`，则

$$\sum_{i \in s} nums[i] \bmod 2 = \operatorname{popcount}(mask \ \&\ onesMask) \bmod 2$$

`__builtin_popcount` / Python 的 `bin(x).count("1")` 都是 $O(1)$（常数级指令）。
- **诱导子图自动成立**：BFS 只在 `mask` 内的节点上扩散（把邻居集合与 `mask` 取交），扩散范围自动就是**诱导子图**，天然只走了两端都在 $s$ 中的边。
- **连通性判定**：从 $s$ 中编号最小的节点出发扩散，结束时若「访问集合 == mask」则连通；否则不连通（示例 1 的 `{0,2}` 正是这种情况）。

### 3.3 算法流程

![连通性判定：把邻接表压成位掩码，用「扩散 + 与掩码」做 BFS](images/bw181_q3_connectivity.svg)

```text
1. 预处理：adj[u] = 邻接节点掩码；onesMask = {i | nums[i] == 1}
2. ans = 0
3. for mask = 1 .. 2^n - 1:
     a. 若 popcount(mask & onesMask) 为奇数：跳过        // 和为奇数
     b. seen = frontier = mask & (-mask)                 // 最低位置位，作为起点
     c. while frontier 非空：
            nb = 所有 frontier 中节点的 adj 之并
            frontier = nb & mask & ~seen
            seen |= frontier
     d. 若 seen == mask：ans++
4. 返回 ans
```

每次扩散的「并」用循环 `for (f = frontier; f; f &= f - 1)` 逐位取出节点，`__builtin_ctz` 定位下标，避免再开一个队列数组。

### 3.4 示例演算

![示例 1 演算：7 个非空子集只有 2 个满足条件](images/bw181_q3_walkthrough.svg)

对 `nums = [1,0,1], edges = [[0,1],[1,2]]`，`onesMask = 101`：

| 子集 | mask | `popcount(mask & ones)` | 连通？ | 计入 |
|------|------|--------------------------|--------|------|
| `{0}` | 001 | 1（奇） | 是 | ✗ |
| `{1}` | 010 | 0（偶） | 是 | ✓ |
| `{2}` | 100 | 1（奇） | 是 | ✗ |
| `{0,1}` | 011 | 1（奇） | 是 | ✗ |
| `{0,2}` | 101 | 2（偶） | **否** | ✗ |
| `{1,2}` | 110 | 1（奇） | 是 | ✗ |
| `{0,1,2}` | 111 | 2（偶） | 是 | ✓ |

最终答案 $2$。注意 `{0,2}` 是「和为偶数但不连通」的反例，`{1}` 是「连通且和为偶数」的最小正例——两条判定必须都做。

## 4. 算法细节

1. **邻接掩码**：`adj[u] |= 1 << v`（双向各一次）。$n \le 13$，`int` 足够；用 `unsigned` 可避免移位符号问题（本题 $n \le 13$ 不会有符号位）。
2. **起点取最低位**：`mask & (-mask)` 取出最低置位，`__builtin_ctz` 得到下标；Python 用 `(mask & -mask).bit_length() - 1`。若从任意固定节点出发会漏掉「该节点不在子集内」的情况。
3. **扩散与掩码取交**：`frontier = nb & mask & ~seen`，两个 `& mask` 的作用是「不越出诱导子图」。C++ 中 `~seen` 的高位是 1，但再与 `mask` 取交后无害。
4. **终止条件**：`frontier` 为空即扩散结束；此时 `seen` 恰为「$mask$ 内包含起点的连通分量」。
5. **剪枝顺序**：先判奇偶（$O(1)$）再判连通（$O(n)$），可省掉约一半子集的 BFS。
6. **答案规模**：最多 $2^{13} - 1 = 8191$，`int` 足够。

## 5. 正确性证明

**引理 1（掩码与子集一一对应）**：$mask$ 从 $1$ 枚举到 $2^n-1$ 恰好不重不漏地覆盖全部非空子集。

**证明**：固定的 $n$ 位二进制串与 $\{0, \dots, n-1\}$ 的子集一一对应（第 $i$ 位为 $1$ 表示 $i$ 在子集中），整数 $1 \sim 2^n-1$ 的二进制表示恰好是全部非零的 $n$ 位串。∎

**引理 2（奇偶性公式）**：$\sum_{i \in s} nums[i]$ 为偶数 $\iff$ $\operatorname{popcount}(mask \ \&\ onesMask)$ 为偶数。

**证明**：因 $nums[i] \in \{0,1\}$，$\sum_{i \in s} nums[i] = |\{i \in s : nums[i] = 1\}|$。而 `mask & onesMask` 的第 $i$ 位为 $1$ 当且仅当 $i \in s$ 且 $nums[i] = 1$，故其 popcount 正是该集合的大小，模 2 相同。∎

**引理 3（扩散的正确性）**：算法第 3c 步结束时，`seen` 等于「$mask$ 对应的诱导子图中，与起点连通的全部节点」。

**证明**：对扩散轮数归纳。初始 `seen = {start}`，是起点可达集的子集。设第 $t$ 轮开始前 `seen` 恰为距离起点不超过 $t$ 的节点集合，则 `nb` 是这些节点在**原图**中的邻居并集，与 `mask` 取交后正是「诱导子图中与 `seen` 相邻且在 $mask$ 内的节点」，去掉已访问者即为距离恰为 $t+1$ 的节点；加入后 `seen` 变为距离不超过 $t+1$ 的集合。扩散结束时不再有新节点可达，故 `seen` 就是整个连通分量。∎

**定理**：算法返回的 `ans` 等于满足「诱导子图连通且节点和为偶数」的非空子集个数。

**证明**：由引理 1，枚举覆盖全部非空子集且每个恰好一次。对每个 $mask$：第 3a 步按引理 2 精确过滤掉和为奇数的子集；第 3c、3d 步按引理 3 判定 `seen == mask` 当且仅当整个子集构成一个连通分量，即诱导子图连通。故 `ans` 恰好对每个满足两条的子集累加一次，不多不少。∎

## 6. 复杂度分析

- **时间**：$O(2^n \cdot n)$。共 $2^n - 1$ 个掩码；每个掩码的奇偶判定 $O(1)$，扩散最多 $n$ 轮、每轮处理不超过 $n$ 个节点、每次取 `adj` 为 $O(1)$，故单子集 $O(n^2)$ 的上界更松，实际因 `seen` 单调增长而接近 $O(n)$；$n = 13$ 时约 $10^5 \sim 10^6$ 次操作。
- **空间**：$O(n)$。只存 `adj`（$n$ 个整数）与若干标量；没有递归栈（扩散是迭代的），也不存子集列表。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int evenSumSubgraphs(vector<int>& nums, vector<vector<int>>& edges) {
        int n = nums.size();
        vector<int> adj(n, 0);
        for (auto& e : edges) {
            adj[e[0]] |= 1 << e[1];
            adj[e[1]] |= 1 << e[0];
        }
        int onesMask = 0;
        for (int i = 0; i < n; i++)
            if (nums[i] == 1) onesMask |= 1 << i;
        int ans = 0;
        for (int mask = 1; mask < (1 << n); mask++) {
            if (__builtin_popcount((unsigned)(mask & onesMask)) & 1) continue;
            int seen = mask & (-mask), frontier = seen;
            while (frontier) {
                int nb = 0;
                for (int f = frontier; f; f &= f - 1) nb |= adj[__builtin_ctz((unsigned)f)];
                frontier = nb & mask & ~seen;
                seen |= frontier;
            }
            if (seen == mask) ans++;
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def evenSumSubgraphs(self, nums: list[int], edges: list[list[int]]) -> int:
        n = len(nums)
        adj = [0] * n
        for u, v in edges:
            adj[u] |= 1 << v
            adj[v] |= 1 << u
        ones = 0
        for i, v in enumerate(nums):
            if v == 1:
                ones |= 1 << i
        ans = 0
        for mask in range(1, 1 << n):
            if bin(mask & ones).count("1") % 2:
                continue
            start = mask & -mask
            seen = start
            frontier = start
            while frontier:
                nb = 0
                f = frontier
                while f:
                    low = f & -f
                    nb |= adj[low.bit_length() - 1]
                    f ^= low
                frontier = nb & mask & ~seen
                seen |= frontier
            if seen == mask:
                ans += 1
        return ans
```

## 8. 边界情况与易错点

1. **`n = 1`**：唯一子集 `{0}`；若 $nums[0] = 1$ 则为奇数、答案 $0$（示例 2），若 $nums[0] = 0$ 则答案 $1$。
2. **孤立节点**：无边时每个单点集都连通，答案 = 值为 0 的节点个数。多个孤立点组成的子集一律不连通。
3. **「连通但和奇」与「和偶但不连通」都是陷阱**：示例 1 的 `{0,1}` 与 `{0,2}` 各踩一个，两个判定必须都执行，不能因为已判奇偶就跳过连通性。
4. **起点必须在子集内**：用 `mask & (-mask)` 取最低位置位；若硬编码从节点 0 出发，会漏掉所有不含 0 的子集。
5. **`~seen` 的符号位**：C++ 中 `~seen` 高位为 1，务必再与 `mask` 取交；Python 的 `~seen` 是负无穷位补码，同样靠 `& mask` 收敛。
6. **不要尝试多项式算法**：统计连通导出子图是 #P 难的，$n \le 13$ 就是出题人给的暴力许可；写成状压 DP（如按位枚举连通块）也不会更快。
7. **`edges` 可能为空数组**：直接进入枚举即可，无需特判。
