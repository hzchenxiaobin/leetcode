# LeetCode 找出前缀异或的原始数组 题解

## 1. 题目概述

- **标题 / 题号**：找出前缀异或的原始数组（#2433，medium）
- **链接**：https://leetcode.cn/problems/find-the-original-array-of-prefix-xor/
- **来源**：LeetCode 第 314 场周赛 Q2
- **难度**：中等
- **标签**：位运算、数组、前缀异或、差分还原

**题意**：给定长度为 $n$ 的整数数组 `pref`，找出并返回满足下述条件的长度为 $n$ 的数组 `arr`：

$$\text{pref}[i] = \text{arr}[0] \oplus \text{arr}[1] \oplus \cdots \oplus \text{arr}[i]$$

即 `pref` 是 `arr` 的**前缀异或**数组（`^` 表示按位异或）。题目保证答案唯一。

**约束**：

- $1 \le \text{pref.length} \le 10^5$
- $0 \le \text{pref}[i] \le 10^6$

> 💡 **读题眼**：`pref` 给的是「前缀」而非「相邻」异或——认清这一点，就知道这是「前缀和做差分还原原数组」的异或版，一行公式的事。$n$ 到 $10^5$ 说明 $O(n)$ 或 $O(n \log n)$ 都可过，本题实际只需 $O(n)$。

## 2. 示例

**示例 1**

```text
输入：pref = [5,2,0,3,1]
输出：[5,7,2,3,2]

解释：从数组 [5,7,2,3,2] 可以得到如下结果：
- pref[0] = 5
- pref[1] = 5 ^ 7 = 2
- pref[2] = 5 ^ 7 ^ 2 = 0
- pref[3] = 5 ^ 7 ^ 2 ^ 3 = 3
- pref[4] = 5 ^ 7 ^ 2 ^ 3 ^ 2 = 1
```

**示例 2**

```text
输入：pref = [13]
输出：[13]

解释：pref[0] = arr[0] = 13。
```

**示例 3**

```text
输入：pref = [0,0,0,0]
输出：[0,0,0,0]

解释：前缀全为 0，说明 arr 每一项都把累积值「归零」，只能全 0。
（arr[k] ⊕ arr[k] = 0 是唯一能持续抵消的方式吗？——不是靠自抵消，
 而是每次 arr[i] = pref[i] ⊕ pref[i−1] = 0 ⊕ 0 = 0。）
```

## 3. 解题思路

### 3.1 暴力思路：边走边维护累积器

最直观的还原方式是**从左到右递推**，维护一个「当前累积异或」`cur`，让它始终等于 $\text{pref}[i-1]$：

- 首元素：$\text{arr}[0] = \text{pref}[0]$（前缀只有一项）；
- 对 $i \ge 1$：由 $\text{cur} \oplus \text{arr}[i] = \text{pref}[i]$，两边异或 `cur` 解出 $\text{arr}[i] = \text{cur} \oplus \text{pref}[i]$，随后更新 `cur ⊕= arr[i]`。

时间 $O(n)$、额外空间 $O(1)$（不算输出），已经正确。**但它把一个可由 `pref` 直接读出的量当成了独立状态维护**——每次更新后 `cur` 恰好等于 $\text{pref}[i-1]$，这是个**冗余变量**。比赛中这么写完全没问题，但意识到冗余能写出更短、更不易错的代码。

### 3.2 核心观察：异或自反性 → 相邻 pref 作差

![核心观察：相邻 pref 作差即还原 arr](images/2433_prefix_xor_diff_concept.svg)

由前缀定义，对 $i \ge 1$：

$$\text{pref}[i] = \text{pref}[i-1] \oplus \text{arr}[i]$$

两边同时异或 $\text{pref}[i-1]$，利用**异或自反性**（$a \oplus a = 0$，$a \oplus 0 = a$）：

$$\text{pref}[i] \oplus \text{pref}[i-1] = \underbrace{\text{pref}[i-1] \oplus \text{pref}[i-1]}_{= \, 0} \oplus \text{arr}[i] = \text{arr}[i]$$

> ⚠️ **决定性事实**：异或运算的「减法」与「加法」是**同一个算符** $\oplus$。于是「前缀异或的差分还原」与「前缀和的差分还原」完全同构——把 $+$ 换成 $\oplus$、把 $-$ 也换成 $\oplus$ 即可：
>
> | 模型 | 前向（累积） | 逆向（还原） |
> |------|------|------|
> | 前缀**和** | $\text{pref}[i] = \sum_{k \le i} \text{arr}[k]$ | $\text{arr}[i] = \text{pref}[i] - \text{pref}[i-1]$ |
> | 前缀**异或** | $\text{pref}[i] = \bigoplus_{k \le i} \text{arr}[k]$ | $\text{arr}[i] = \text{pref}[i] \oplus \text{pref}[i-1]$ |

### 3.3 算法流程

![算法流程：一次遍历做相邻异或差分](images/2433_algorithm_flow.svg)

一次遍历即可：

1. **首元素**：$\text{arr}[0] = \text{pref}[0]$（前缀只有一项，直接复制）；
2. **循环** $i = 1 \to n-1$：$\text{arr}[i] = \text{pref}[i] \oplus \text{pref}[i-1]$；
3. **返回** `arr`。

无需哨兵（对比前缀和里 `prefix[0] = 0` 的设定）：`arr[0]` 由 `pref[0]` 直接给出，循环从 $i = 1$ 起，`pref[i-1]` 始终在界内。

若追求 $O(1)$ 额外空间，可**倒序原地**改写：从 $i = n-1$ 到 $1$ 执行 `pref[i] ^= pref[i-1]`——先消费右侧的 `pref[i]`，再使用尚未被改写的左侧 `pref[i-1]`，原地完成差分（`pref[0]` 本就等于 `arr[0]`，不动）。

### 3.4 示例演算

![示例演算：pref = [5,2,0,3,1] → arr = [5,7,2,3,2]](images/2433_example_walkthrough.svg)

以 `pref = [5,2,0,3,1]` 为例：

- $i=0$：$\text{arr}[0] = \text{pref}[0] = 5$；
- $i=1$：$\text{arr}[1] = 2 \oplus 5 = 7$；
- $i=2$：$\text{arr}[2] = 0 \oplus 2 = 2$；
- $i=3$：$\text{arr}[3] = 3 \oplus 0 = 3$；
- $i=4$：$\text{arr}[4] = 1 \oplus 3 = 2$。

得 `arr = [5,7,2,3,2]`。**回代验证**：$5 \to 5\oplus7{=}2 \to {\oplus}2{=}0 \to {\oplus}3{=}3 \to {\oplus}2{=}1$，逐项吻合 `pref`。✓

## 4. 算法细节

1. **还原公式**：`arr[0] = pref[0]`；`arr[i] = pref[i] ^ pref[i-1]`（$i \ge 1$）。整题的全部逻辑就这两行。
2. **异或的性质清单**（本题用到的）：交换律、结合律（保证「前缀」良定义且可任意结合消去）；自反性 $a \oplus a = 0$（消去 `pref[i-1]`）；单位元 $a \oplus 0 = a$（`cur = 0` 起步的递推版依据）。
3. **为何不用按位拆**：$\oplus$ 是整字运算，$\text{pref}[i] \le 10^6 < 2^{20}$，单次异或 $O(1)$。
4. **倒序原地方向**：`for i in range(n-1, 0, -1): pref[i] ^= pref[i-1]`。倒序是**必须**的：正序会先把 `pref[i-1]` 覆写成 $\text{arr}[i-1]$，算 $i+1$ 时旧前缀已丢失。
5. **输出与输入分离**：若题目要求不修改输入（本题未要求），另开 `arr` 数组；比赛场景直接原地最省事。

## 5. 正确性证明

**引理 1**：对任意 $i \ge 1$，$\text{pref}[i] = \text{pref}[i-1] \oplus \text{arr}[i]$。

**证明**：由前缀定义 $\text{pref}[i] = \text{arr}[0] \oplus \cdots \oplus \text{arr}[i]$，$\text{pref}[i-1] = \text{arr}[0] \oplus \cdots \oplus \text{arr}[i-1]$。由 $\oplus$ 的交换律与结合律：

$$\text{pref}[i-1] \oplus \text{arr}[i] = (\text{arr}[0] \oplus \cdots \oplus \text{arr}[i-1]) \oplus \text{arr}[i] = \text{pref}[i]. \qquad \blacksquare$$

**引理 2**（消去律）：若 $x \oplus z = y \oplus z$，则 $x = y$。

**证明**：两边同异或 $z$：$x \oplus z \oplus z = y \oplus z \oplus z$，由自反性 $z \oplus z = 0$ 与单位元性质，得 $x = y$。∎

**定理 1**（还原公式正确）：设 `pref` 是某个数组 `arr` 的前缀异或数组，则 $\text{arr}[0] = \text{pref}[0]$，且对 $i \ge 1$ 有 $\text{arr}[i] = \text{pref}[i] \oplus \text{pref}[i-1]$。

**证明**：$\text{pref}[0] = \text{arr}[0]$ 是前缀定义在 $i = 0$ 处的直接情形。对 $i \ge 1$，由引理 1 有 $\text{pref}[i] \oplus \text{pref}[i-1] = \text{pref}[i] \oplus (\text{pref}[i-1] \oplus \text{arr}[i])$（再次用引理 1 代入右侧）；由交换律、结合律与自反性，右侧 $= (\text{pref}[i] \oplus \text{pref}[i]) \oplus \text{arr}[i] = 0 \oplus \text{arr}[i] = \text{arr}[i]$。∎

**定理 2**（答案唯一性）：满足条件的 `arr` 唯一，即由定理 1 的公式逐项确定，无任何自由度；且该公式产出的数组确实以 `pref` 为前缀异或数组。

**证明**：唯一性：`arr` 的每一项要么由 `pref[0]` 直接给出，要么由 `pref[i]`、`pref[i-1]` 唯一确定，故至多存在一个解。存在性：对公式产出的 `arr` 归纳证明其前缀异或等于 `pref`：$i=0$ 时 $\text{arr}[0] = \text{pref}[0]$ ✓；设前 $i-1$ 项累积为 $\text{pref}[i-1]$，则第 $i$ 项累积 $= \text{pref}[i-1] \oplus \text{arr}[i] = \text{pref}[i-1] \oplus \text{pref}[i] \oplus \text{pref}[i-1] = \text{pref}[i]$ ✓。故该 `arr` 是解。结合两者，答案唯一。∎

> 💡 换个角度看唯一性：`arr ↦ pref`（前缀异或）与 `pref ↦ arr`（相邻差分）互为逆映射，前缀异或是数组空间上的**双射**——这正是题面「可以证明答案唯一」的含义。

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。单次遍历，每个位置一次整字异或 $O(1)$。
- **空间复杂度**：另开 `arr` 数组为 $O(n)$（不计返回值则为 $O(1)$）；倒序原地写法**额外空间 $O(1)$**，直接在 `pref` 上改写后返回。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    vector<int> findArray(vector<int>& pref) {
        int n = pref.size();
        vector<int> arr(n);
        arr[0] = pref[0];
        for (int i = 1; i < n; ++i) {
            arr[i] = pref[i] ^ pref[i - 1];
        }
        return arr;
    }
};
```

### C++（倒序原地，O(1) 额外空间）

```cpp
class Solution {
  public:
    vector<int> findArray(vector<int>& pref) {
        for (int i = (int)pref.size() - 1; i > 0; --i) {
            pref[i] ^= pref[i - 1];
        }
        return pref;
    }
};
```

### Python

```python
class Solution:
    def findArray(self, pref: List[int]) -> List[int]:
        arr = [pref[0]]
        for i in range(1, len(pref)):
            arr.append(pref[i] ^ pref[i - 1])
        return arr
```

### Python（倒序原地，O(1) 额外空间）

```python
class Solution:
    def findArray(self, pref: List[int]) -> List[int]:
        for i in range(len(pref) - 1, 0, -1):
            pref[i] ^= pref[i - 1]
        return pref
```

## 8. 边界情况与易错点

1. **`n = 1`**：输出就是 `[pref[0]]`。倒序原地写法中 `range(0, 0, -1)` 为空循环，天然正确，无需特判。
2. **原地差分必须倒序**：正序 `pref[i] ^= pref[i-1]` 会在处理 $i+1$ 时用到已被覆写的 `pref[i]`，整组答案错乱。这是「差分还原原地化」的通用坑：**先消费下游、再使用上游**。
3. **`pref[i] = 0` 的情况**：前缀为 0 不代表 `arr[i] = 0`，例如 `pref = [5,0]` 时 `arr = [5,5]`（$5 \oplus 5 = 0$）。不要把前缀值与元素值混淆。
4. **元素上界**：$\text{pref}[i] \le 10^6$，异或结果不超过 $2^{20}$，`int` / Python int 均无溢出风险。
5. **不要引入不必要的累积器**：3.1 节的 `cur` 写法虽然正确，但多一个状态就多一处初始化/更新出错的机会（例如忘记更新 `cur`）。能从输入直接读出的量，不要另行维护。
6. **「前缀」vs「相邻」**：本题与 [1720. 解码异或后的数组](https://leetcode.cn/problems/decode-xored-array/) 一字之差——1720 给的是**相邻**异或 `encoded[i] = arr[i] ^ arr[i+1]` 且另给首项 `first`，用**逐项前推**还原；本题给的是**累积前缀**，用**相邻差分**还原。赛场上读错题意会用错还原方向。

**延伸思考**：

- 若改成「前缀**与**」或「前缀**或**」，还能做差分还原吗？——不能：$\land$ 与 $\lor$ **不可逆**（信息会丢失），没有消去律。可逆性是差分还原的命门。
- 若给的是 `arr` 的**前缀和模 $k$** 数组（值域 $[0,k)$），如何还原？`arr[i] ≡ pref[i] − pref[i−1] (mod k)`——差分还原在模算术域同样成立，但答案不唯一（每项可加 $k$ 的倍数）。
- 若允许查询任意区间的异或而不还原原数组，直接用前缀异或作端点差即可（同 1310），无需还原——「还原」与「区间查询」是前缀技术的两个互补用法。
