# LeetCode 判断矩阵是否是一个 X 矩阵 题解

## 1. 题目概述

- **标题 / 题号**：判断矩阵是否是一个 X 矩阵（#2319，easy）
- **链接**：https://leetcode.cn/problems/check-if-matrix-is-x-matrix/
- **来源**：LeetCode 第 299 场周赛 Q1
- **难度**：简单
- **标签**：数组、矩阵、模拟、一次遍历

**题意**：给定 $n \times n$ 的二维整数数组 `grid` 表示一个正方形矩阵。若它满足下述**全部**条件，则称之为 **X 矩阵**：矩阵**对角线**上的所有元素都**不是 0**，矩阵中**所有其他元素**都是 **0**。是则返回 `true`，否则返回 `false`。

**约束**：

- $n = grid.length = grid[i].length$，$3 \le n \le 100$
- $0 \le grid[i][j] \le 10^5$

> 💡 **签到题读题抓形态**：「对角线」必须读成**两条**——主对角线（左上 → 右下）与副对角线（右上 → 左下）。整道题的全部工作量就是把「X 形」这个几何条件翻译成**下标等式**，然后单趟扫描逐格核对。比赛目标：3 分钟内 AC，一次写对不返工。

## 2. 示例

**示例 1**

```text
输入：grid = [[2,0,0,1],[0,3,1,0],[0,5,2,0],[4,0,0,2]]
输出：true
解释：主对角线 2,3,2,2 与副对角线 1,1,5,4 均非 0，其余全为 0。
```

**示例 2**

```text
输入：grid = [[5,7,0],[0,3,1],[0,5,0]]
输出：false
解释：(0,1)=7 不在对角线上却非 0；(0,2)、(2,0)、(2,2) 在对角线上却为 0——共 6 格违例。
```

**补充示例：奇数阶中心格同属两条对角线**

```text
输入：grid = [[1,0,2],[0,3,0],[4,0,5]]
输出：true
解释：n=3 时中心格 (1,1) 同时落在主、副对角线上，只按「对角线」计一次，须非 0——此处为 3，合规。
```

```text
输入：grid = [[1,0,2],[0,0,0],[4,0,5]]
输出：false
解释：仅中心格 (1,1)=0 违例（对角线上为 0），其余 8 格全部合规——单格违例即整体 false。
```

## 3. 解题思路

### 3.1 暴力思路：预存对角线集合再核对

最直觉的写法是先把两条对角线上的位置「圈」出来存进集合，再逐格核对：在集合里查 $\ne 0$，不在集合里查 $= 0$。正确性没问题，本约束 $n \le 100$ 下也必然 AC，但有多余开销：多花 $O(n)$ 空间存集合，且把「$(i,j)$ 是否在对角线上」这件 **$O(1)$ 可判定**的事绕道了哈希结构。更隐蔽的风险是构造集合时对**奇数阶中心格**忘记去重（主、副对角线在中心重叠）——虽然本题判定语义下不去重也不出错，但思路已经绕远了。

> 💡 转机在于：格子是否落在任一对角线上，**两个下标等式即可就地判定**。整个问题塌缩为「单趟遍历 + 每格一次 0 比较」。

### 3.2 核心观察：两个下标等式就地判定「X 形」

![核心观察：染色成 X 与两个对角线下标等式](images/wc299_q1_xshape_concept.svg)

下标从 $0$ 计起的 $n \times n$ 矩阵中：

- **主对角线**：行下标等于列下标，即 $i = j$；
- **副对角线**（反对角线）：行列下标之和为定值 $n-1$，即 $i + j = n - 1$。

任一格 $(i,j)$ 是否「在对角线上」由一次布尔或得出：

$$\text{onDiag} = (i = j)\ \lor\ (i + j = n - 1)$$

于是每格按角色核对**一个条件**：

| 角色 | 期望 |
|------|------|
| `onDiag == true` | $grid[i][j] \ne 0$ |
| `onDiag == false` | $grid[i][j] = 0$ |

> ⚠️ **奇数阶中心格**：$n$ 为奇时，中心 $(\lfloor n/2 \rfloor, \lfloor n/2 \rfloor)$ 同时满足 $i = j$ 与 $i + j = n - 1$。布尔或天然只计一次，它就是「对角线格」，须非 0——与题意一致，**无需显式去重**（对照 1572 矩阵对角线之和：求和时中心格会被两条对角线各算一次，那里才需要减去一次）。

> 💡 **短路思想**：一旦某格违例立即 `return false`，不必扫完整张矩阵；最坏情况（合法矩阵）才遍历全部 $n^2$ 格。

### 3.3 算法流程

![算法流程：单趟扫描·角色分流·违例短路](images/wc299_q1_algorithm_flow.svg)

双层循环行优先遍历每个 $(i, j)$：

1. 计算 `onDiag = (i == j) || (i + j == n - 1)`；
2. 若 `onDiag` 且 `grid[i][j] == 0` → 返回 `false`（对角线上不该为零）；
3. 若非 `onDiag` 且 `grid[i][j] != 0` → 返回 `false`（非对角线不该非零）；
4. 扫完所有格子均合规 → 返回 `true`。

无预处理、无集合、无方向分支，原地一次扫描。

### 3.4 示例演算

![示例演算：示例1 全合规 / 示例2 首违例短路](images/wc299_q1_example_walkthrough.svg)

**示例 1**（$n=4$，合法）逐格核对（行优先）：

| 格子 $(i,j)$ | 角色 | 值 | 期望 | 结果 |
|------|------|----|----|------|
| $(0,0)$ | 主对角 | 2 | $\ne 0$ | ✓ |
| $(0,1)$ | 非对角 | 0 | $= 0$ | ✓ |
| $(0,2)$ | 非对角 | 0 | $= 0$ | ✓ |
| $(0,3)$ | 副对角 | 1 | $\ne 0$ | ✓ |
| … | … | … | … | ✓ |
| $(3,3)$ | 主对角 | 2 | $\ne 0$ | ✓ |

全部 16 格合规 → 返回 `true`。

**示例 2**（$n=3$，非法）行优先扫描，第 2 格即短路：

| 格子 $(i,j)$ | 角色 | 值 | 期望 | 结果 |
|------|------|----|----|------|
| $(0,0)$ | 主对角 | 5 | $\ne 0$ | ✓ |
| $(0,1)$ | 非对角 | **7** | $= 0$ | ✗ 命中违例 |

扫描到 $(0,1)$ 时发现「非对角线却非零」→ 立即 `return false`，**不再检查** $(0,2)$ 及之后。

> 💡 示例 2 实际共 **6 格违例**：对角线上 3 个 0（$(0,2),(2,0),(2,2)$）与非对角线 3 个非零（$(0,1),(1,2),(2,1)$）。但短路使算法只验到第 2 格就停——非法输入常能极早终止，这是「遇违例即返回」的平均价值。

## 4. 算法细节

1. **就地判定，零数据结构**：`onDiag` 是两个整数等式的布尔或，$O(1)$ 时间；不构造对角线坐标集合，省下 $O(n)$ 空间与哈希查询常数。
2. **短路写法**：违例检查放循环体内直接 `return false`；合法路径必须扫满 $n^2$ 格才能确认（全局「所有」量词），这是判定型问题的读取下界。
3. **分支 vs 异或合并**：两分支（对角查 $\ne 0$ / 其余查 $= 0$）可读性最好；也可合并为一行 `if (onDiag != (grid[i][j] != 0)) return false;`——「在对角线上」与「值非零」两个布尔必须同真同假。比赛中两种都能一遍写对，选顺手的。
4. **值域无陷阱**：$0 \le grid[i][j] \le 10^5$，`int` 无溢出；判断只做 `== 0` / `!= 0`，与具体数值无关。

## 5. 正确性证明

**引理 1（对角线位置刻画）**：在 $n \times n$ 矩阵（下标从 $0$ 起）中，格 $(i,j)$ 落在主对角线上 $\iff i = j$；落在副对角线上 $\iff i + j = n - 1$。

**证明**：主对角线是从 $(0,0)$ 到 $(n-1,n-1)$ 的格子序列，其上每格行号列号同步递增，故 $i = j$；反之凡 $i = j$ 的格子都在该序列上。副对角线是从 $(0,n-1)$ 到 $(n-1,0)$ 的格子序列，每向下一行列号减一，全程 $i + j$ 保持 $0 + (n-1) = n - 1$；反之凡 $i + j = n - 1$ 的格子都在该序列上。∎

**引理 2（违例刻画）**：`grid` 不是 X 矩阵 $\iff$ 存在格 $(i,j)$ 使得「$onDiag(i,j)$ 且 $grid[i][j] = 0$」或「$\lnot\, onDiag(i,j)$ 且 $grid[i][j] \ne 0$」之一成立。

**证明**：由引理 1，「对角线上的所有元素都不是 0」即 $\forall (i,j):\ onDiag(i,j) \Rightarrow grid[i][j] \ne 0$；「所有其他元素都是 0」即 $\forall (i,j):\ \lnot\, onDiag(i,j) \Rightarrow grid[i][j] = 0$。X 矩阵 = 两条件同时成立；对其取否定（析取到存在量词），得「非 X 矩阵 $\iff$ 存在格违反任一蕴含」，展开蕴含的否定即得引理。∎

**定理**：算法返回 `true` $\iff$ `grid` 是 X 矩阵。

**证明**：算法逐格计算的 `onDiag` 与引理 1 的刻画一致；循环体内检查的恰是引理 2 中两种违例形式，扫完全部格子无一命中时才返回 `true`，即「不存在违例格」，由引理 2 等价于「是 X 矩阵」。短路只是提前报告已发现的违例，不改变返回值与正确性的对应关系。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n^2)$。最坏（合法矩阵）遍历全部 $n^2 \le 10^4$ 格，每格两个整数等式 + 一次 0 比较；非法矩阵常因短路提前终止，渐进不变、常数更小。读取输入本身即 $\Omega(n^2)$，单趟判定已最优。
- **空间复杂度**：$O(1)$。仅下标 $i$、$j$、布尔 `onDiag` 与 $n$ 几个标量，原地判定（预存集合的写法需 $O(n)$）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool checkXMatrix(vector<vector<int>>& grid) {
        int n = grid.size();
        for (int i = 0; i < n; ++i) {
            for (int j = 0; j < n; ++j) {
                bool onDiag = (i == j) || (i + j == n - 1);
                if (onDiag) {
                    if (grid[i][j] == 0) return false;
                } else {
                    if (grid[i][j] != 0) return false;
                }
            }
        }
        return true;
    }
};
```

### Python

```python
class Solution:
    def checkXMatrix(self, grid: List[List[int]]) -> bool:
        n = len(grid)
        for i in range(n):
            for j in range(n):
                on_diag = (i == j) or (i + j == n - 1)
                if on_diag:
                    if grid[i][j] == 0:
                        return False
                elif grid[i][j] != 0:
                    return False
        return True
```

> 💡 Python 亦可用生成器一行表达：`return all((grid[i][j] != 0) == ((i == j) or (i + j == n - 1)) for i in range(n) for j in range(n))`——两个布尔相等即「角色与期望一致」，`all` 天然短路。

## 8. 边界情况与易错点

1. **副对角线公式写错**：下标从 $0$ 起时是 $i + j = n - 1$；写成 $i + j = n$（1 基下标的公式）会整体偏移一格，$n=3$ 时会把 $(0,3)$（越界）漏掉、错杀 $(0,2)$。矩阵题先确认下标基再写等式。
2. **只查一条对角线**：只判 $i = j$ 会漏掉副对角线上的违例，示例 1 会误判为 `false`、副对角违例的矩阵误判为 `true`。
3. **奇数阶中心格**：同属两条对角线，`||` 判定天然只计一次、须非 0，与题意一致——无需也不应做任何去重或特判（求和类题目如 1572 才需要减重复）。
4. **逻辑写反**：对角线查 `!= 0`、其余查 `== 0`，两个方向恰好相反；紧张时最容易把某个等号方向写反，提交前用示例 1（对角非零）+ 中心为 0 的奇数矩阵各验一遍。
5. **约束保证 $n \ge 3$**：无空矩阵、单格矩阵等退化输入，循环写法天然兼容更小的 $n$，无需特判。
6. **无需溢出防护**：值至多 $10^5$ 且只做 0 比较，`int` 足够；若题面改为带负数的大值求和类变体才需考虑溢出。
