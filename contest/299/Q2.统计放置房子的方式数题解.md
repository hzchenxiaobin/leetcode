# LeetCode 统计放置房子的方式数 题解

## 1. 题目概述

- **标题 / 题号**：统计放置房子的方式数（#2320，medium）
- **链接**：https://leetcode.cn/problems/count-number-of-ways-to-place-houses/
- **来源**：LeetCode 第 299 场周赛 Q2
- **难度**：中等
- **标签**：动态规划、计数、斐波那契、乘法原理

**题意**：一条街道两侧各有 $n$ 个地块（共 $2n$ 个），每边按 $1$ 到 $n$ 编号，每个地块都可放一所房子。要求**同一侧**不能存在两所**相邻**的房子（两侧之间无任何约束——同一编号的地块「对脸」各放一所也合法）。求放置方式总数，对 $10^9+7$ 取余后返回。

**约束**：

- $1 \le n \le 10^4$
- 答案对 $10^9+7$ 取模

> 💡 **比赛定位**：Q2 套路题，目标 10 分钟内 AC。识别信号是「**相邻不取 + 计数**」——这是 [198. 打家劫舍](https://leetcode.cn/problems/house-robber/) 的计数版（把 $\max$ 换成 $+$）；本题再外套一层「**两侧独立 → 平方**」的乘法原理。两条观察各 30 秒，剩下的功夫全在把递推与取模一次写对。

> 💡 本题在本仓库另有[每日题解 2320](../../solution/2301-2400/2320_统计放置房子的方式数.md)：含矩阵快速幂 $O(\log n)$ 扩展与面试问答式展开。本篇按周赛复盘视角展开，侧重**赛场套路识别、「不是一条长 $2n$ 链」的陷阱判别、乘法原理 + 递推的引理-定理完整证明与边界清单**，两篇互为印证。

## 3. 解题思路

### 3.1 暴力思路：逐侧枚举 01 串

把一侧 $n$ 个地块的「放 / 不放」编码为长度 $n$ 的 01 串（放房 = 1），「同侧无相邻房」等价于「**无连续两个 1**」。枚举全部 $2^n$ 个串、逐个检查，统计出一侧方案数 $g(n)$ 后平方。时间 $O(2^n \cdot n)$（用位运算判断「无相邻 1」可把单串检查压到 $O(1)$，整体仍为 $O(2^n)$）：$n = 10^4$ 时状态数约 $10^{3010}$，**完全不可行**。

> ⚠️ 暴力把「相邻」当成**事后验证**，浪费了约束的**局部性**：第 $i$ 个地块是否合法只取决于第 $i-1$ 个地块的状态——这正是线性递推能接管的地方，也是打家劫舍家族的共同骨架。

### 3.2 核心观察一：两侧独立 → 答案是平方

![核心观察一：两侧互不耦合，答案为 g(n) 的平方](images/wc299_q2_independence_square.svg)

题面明说「一侧第 $i$ 个地块放房**不影响**另一侧第 $i$ 个地块」。合法性条件**逐侧成立**、互不涉及对方：

$$\text{全局合法} \iff \text{上侧合法} \land \text{下侧合法}$$

于是任取一对单侧合法方案 $(A, B)$ 都唯一拼出一个全局方案，反之亦然。设 $g(n)$ 为**一侧** $n$ 个地块的合法方式数，由**乘法原理**：

$$\text{ans} = g(n) \times g(n) = g(n)^2 \bmod (10^9+7)$$

> ⚠️ 两侧是**两条独立的长度 $n$ 链**，不是一条长 $2n$ 的链。若误把 $2n$ 个地块排成一条链做「无连续 1」递推，会虚构出「第 $n$ 与第 $n+1$ 个地块（分属两侧）不得同放」的约束：$n=1$ 时算出 $g(2)=3 \ne 4$，**对脸方案被误杀**——用示例 1 当场判别。

### 3.3 核心观察二：末位二分 → 斐波那契递推

![核心观察二与流程：末位二分推出斐波那契递推，滚动变量递推后一次平方](images/wc299_q2_fib_recurrence_flow.svg)

对一侧前 $i$ 个地块的合法方案，按**第 $i$ 个地块放不放房**二分：

| 情形 | 条件与归约 | 数量 |
|------|-----------|------|
| A：第 $i$ 位不放 | 第 $i$ 位为 0 不产生任何相邻对，前 $i-1$ 位任意合法 | $g(i-1)$ |
| B：第 $i$ 位放房 | 第 $i-1$ 位**必空**（否则同侧相邻违例），前 $i-2$ 位任意合法 | $g(i-2)$ |

两种情形按第 $i$ 位状态二分，**互斥且覆盖全部方案**，由加法原理：

$$g(i) = g(i-1) + g(i-2),\qquad g(0)=1,\quad g(1)=2$$

- $g(0)=1$：「零个地块、全不放」本身就是一种合法方案（空方案，作递推地基）；
- $g(1)=2$：单个地块放或不放。

展开得 $g(2)=3$、$g(3)=5$、$g(4)=8$、$g(5)=13,\dots$ 恰是斐波那契的平移：$g(n)=\text{Fib}(n+2)$（$\text{Fib}(1)=\text{Fib}(2)=1$）。

**算法流程**：滚动变量 $a=g(0)=1$、$b=g(1)=2$，$i$ 从 $2$ 到 $n$ 迭代 $c=(a+b)\bmod p$、$a\leftarrow b$、$b\leftarrow c$；循环结束后 $\text{ans}=b\times b\bmod p$。递推只依赖前两项，无需数组。

### 3.4 示例演算

![示例演算：n=2 时一侧 3 种方案，3×3 组合网格共 9 种](images/wc299_q2_example_walkthrough.svg)

**一侧递推**（$g(0)=1$、$g(1)=2$，$g(i)=g(i-1)+g(i-2)$）：

| $i$ | $g(i-2)$ | $g(i-1)$ | $g(i)$ | 一侧合法 01 串 |
|----|----------|----------|--------|----------------|
| 0 | — | — | 1 | （空串） |
| 1 | — | — | 2 | 0、1 |
| 2 | 1 | 2 | **3** | 00、01、10 |
| 3 | 2 | 3 | **5** | 000、001、010、100、101 |
| 4 | 3 | 5 | **8** | $=\text{Fib}(6)$ |
| 5 | 5 | 8 | **13** | $=\text{Fib}(7)$ |

**平方得答案**：$n=1: 2^2=4$ ✓；$n=2: 3^2=9$ ✓；$n=3: 5^2=25$；$n=4: 8^2=64$。

> 💡 $n=2$ 的 $3\times 3$ 组合网格中，对角格（上②下②、上③下③）正是「两侧同编号地块都放房」的**对脸方案**——它们合法，是「两侧独立」最直观的证据；而 11 串只在**一侧内部**被禁止，与跨侧无关。

## 4. 算法细节

1. **01 串双射**：一侧方案 $\leftrightarrow$ 长度 $n$、无连续 1 的 01 串。「同侧无相邻房」逐字翻译成「无连续 1」后，计数对象正是经典斐波那契计数（[70. 爬楼梯](https://leetcode.cn/problems/climbing-stairs/) 的近亲）。
2. **二分位置选末位**：按首位或末位二分对称皆可；选末位时「情形 B 中第 $i-1$ 位必空」的论证最短，比赛时按此写最稳。
3. **初值自洽**：$g(0)=1$ 使 $g(2)=g(1)+g(0)=3$ 自然成立，免去对 $i=2$ 特判；若误设 $g(0)=0$ 则 $g(2)=2$，恰好漏掉「放 1 不放 2」一种。初值必须与转移方程**联立自洽**（同 [70. 爬楼梯](https://leetcode.cn/problems/climbing-stairs/) 令 $f(0)=1$ 的讨论）。
4. **滚动实现**：递推只依赖前两项，$a/b$ 两个标量滚动即可；开 $O(n)$ 的 DP 数组也可但无必要。
5. **取模纪律**：加法与平方**每步取模**。递推中 $a,b < p < 2^{30}$，平方 $b^2 < (10^9+7)^2 \approx 10^{18}$，仍在 `long long`（上限约 $9.2\times10^{18}$）内，一次乘法不必中途拆分。
6. **两种等价写法**：直接递推 $g$（初值 $1,2$，循环 $2\dots n$）；或递推 $\text{Fib}(n+2)$（初值 $1,1$，循环 $3\dots n+2$）再平方。逻辑同构，比赛选顺手的。

## 5. 正确性证明

**引理 1（两侧独立双射）**：全局合法方案集与「上侧合法方案 $\times$ 下侧合法方案」的笛卡尔积之间存在双射。

**证明**：全局合法性即「上侧无相邻房 $\land$ 下侧无相邻房」，两个条件各自只涉及本侧地块。把全局方案投影到上侧得 $A$、投影到下侧得 $B$，则 $A$、$B$ 各自合法；反之给定合法对 $(A,B)$，按原侧拼回得全局方案——同侧相邻关系与单独考察时完全一致，故拼回方案合法。投影与拼回互逆，构成双射。∎

**引理 2（末位二分）**：设 $S(i)$ 为一侧前 $i$ 个地块的合法方案集（$i \ge 2$），按第 $i$ 位是否放房分为 $S_A$ 与 $S_B$，则这是 $S(i)$ 的划分，且 $|S_A| = g(i-1)$、$|S_B| = g(i-2)$。

**证明**：第 $i$ 位只有放 / 不放两种状态，故 $S_A \cup S_B = S(i)$ 且 $S_A \cap S_B = \varnothing$，是划分。
$|S_A|$：删去取值为 0 的第 $i$ 位。合法性只由同侧相邻位决定，末位为 0 不与第 $i-1$ 位构成任何相邻违例，故删去前后合法性等价，得 $S_A$ 与 $S(i-1)$ 的双射。
$|S_B|$：第 $i$ 位放房时，若第 $i-1$ 位也放则同侧相邻违例，故第 $i-1$ 位必空；删去末两位（一位放、一位必空）后剩下前 $i-2$ 位，其合法性与原来一致，得 $S_B$ 与 $S(i-2)$ 的双射；反向拼接时，第 $i-1$ 位的 0 阻断了第 $i$ 位与更前位置的相邻关系，合法性保持。∎

**定理**：$g(0)=1$、$g(1)=2$，且对 $i \ge 2$ 有 $g(i)=g(i-1)+g(i-2)$；所求答案 $= g(n)^2 \bmod p$（$p = 10^9+7$），数值上 $g(n)=\text{Fib}(n+2)$。

**证明**：$g(0)=1$（空方案唯一）、$g(1)=2$（放 / 不放）显然；$i \ge 2$ 时由引理 2 的划分与加法原理，$g(i)=|S_A|+|S_B|=g(i-1)+g(i-2)$。由引理 1 的双射与乘法原理，答案 $=g(n)\cdot g(n)=g(n)^2$；同余乘法良定义（$(x \bmod p)(y \bmod p) \equiv xy \pmod p$），故全程逐步取模再平方取模不改变结果。序列 $1,2,3,5,8,\dots$ 与 $\text{Fib}(2),\text{Fib}(3),\text{Fib}(4),\dots$ 初值与递推均相同，归纳得 $g(n)=\text{Fib}(n+2)$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。单层循环 $n-1$ 次加法取模，外加一次乘法，$n = 10^4$ 毫秒级通过。对照暴力 $O(2^n \cdot n)$，关键归约是把「相邻不放房」写成只依赖前两项的递推，把指数级枚举压成线性。理论最优可到 $O(\log n)$（矩阵快速幂，见延伸思考），本题范围无必要。
- **空间复杂度**：$O(1)$。仅 $a/b/c$ 三个滚动标量与常数 MOD，无 DP 数组。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int countHousePlacements(int n) {
        const long long MOD = 1e9 + 7;
        long long a = 1, b = 2;              // g(0), g(1)
        for (int i = 2; i <= n; ++i) {
            long long c = (a + b) % MOD;
            a = b;
            b = c;
        }
        return (int)(b * b % MOD);           // ans = g(n)^2 mod p
    }
};
```

### Python

```python
class Solution:
    def countHousePlacements(self, n: int) -> int:
        MOD = 10**9 + 7
        a, b = 1, 2  # g(0), g(1)
        for _ in range(2, n + 1):
            a, b = b, (a + b) % MOD
        return (b * b) % MOD
```

> 💡 `n = 1` 时循环体不执行，`b` 保持初值 $g(1)=2$，平方得 4，与示例 1 一致——初值即答案，无需特判。Python 整数无限宽，理论上不取模也对，但 $g(n) \approx \varphi^{n+2}/\sqrt5$（$\varphi \approx 1.618$）在 $n=10^4$ 时有逾两千位，全程取模既正确又快。

## 8. 边界情况与易错点

1. **把两侧错当一条长 $2n$ 的链**：虚构「跨侧相邻」约束，$n=1$ 时得 3 而非 4。两侧是**两条独立链**，靠乘法原理平方组合，不拼链。
2. **$g(0)=1$ 而非 0**：「全不放」是合法方案；设成 0 则 $g(2)=2$，漏掉「放 1 不放 2」。
3. **平方溢出**：`int` 承接 $b \times b$ 可达 $\approx 10^{18}$，溢出；C++ 用 `long long`，返回前 `% MOD` 落回 `int` 区间。
4. **平方后忘取模**：C++ 中先溢出、Python 中虽不溢出但答案未取模，均错。
5. **斐波那契下标平移错**：$g(n)=\text{Fib}(n+2)$ 依赖 $\text{Fib}(1)=\text{Fib}(2)=1$ 的约定；直接递推 $g$ 则完全避开下标换算，比赛推荐直推。
6. **「相邻」只限同侧**：对脸（同编号两侧）、斜对均无约束；用 $n=2$ 的 9 格图自查最直观。
7. **读题漏「两侧各有 $n$ 个」**：总数 $2n$ 个地块但每侧只有 $n$ 个，递推长度是 $n$ 不是 $2n$（与第 1 条同源的粗心变体）。
