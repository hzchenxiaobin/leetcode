# LeetCode 拼接数组的最大分数 题解

## 1. 题目概述

- **标题 / 题号**：拼接数组的最大分数（#2321，hard）
- **链接**：https://leetcode.cn/problems/maximum-score-of-spliced-array/
- **来源**：LeetCode 第 299 场周赛 Q3
- **难度**：困难
- **标签**：数组、动态规划、Kadane、最大子数组和

**题意**：给定两个长度均为 $n$ 的下标从 0 开始的整数数组 `nums1` 与 `nums2`。可以选择两个整数 $\text{left} \le \text{right}$，把子数组 `nums1[left...right]` 与 `nums2[left...right]` **整体交换**（该操作可执行一次或不执行）。操作后，数组的**分数**取 $\max(\sum \text{nums1},\ \sum \text{nums2})$。返回可能的最大分数。

**约束**：

- $n = \text{nums1.length} = \text{nums2.length}$，$1 \le n \le 10^5$
- $1 \le \text{nums1}[i],\ \text{nums2}[i] \le 10^4$（元素全为正，但差值可正可负）

> 💡 **比赛定位**：本场分胜负的 Q3（困难）。识别信号是「**至多一次操作 + 两个量的和取 max**」——一次操作类题目的标准套路是先把操作改写成**增量**，再看增量落在哪个经典子结构上。本题交换一段对两个和的增量恰好是**差值数组上一段和的 $\pm$ 倍**，于是归约到 [53. 最大子数组和] 的 **Kadane**；再用「外层 $\max$ 可拆」分成**两个独立候选**，一趟扫描 $O(n)$ 收工。识别到「差分 + Kadane」这条链，5 分钟出解。

> 💡 本题在本仓库另有[每日题解 2321](../../solution/2301-2400/2321_拼接数组的最大分数.md)：含「凸函数端点」视角的归约链、拆分版双趟代码与面试问答式展开。本篇按周赛复盘视角展开，侧重**赛场套路识别、「max 可拆成两个独立候选」的最短推导、引理-定理完整证明与溢出/空段边界清单**，两篇互为印证。

## 2. 示例

**示例 1**

```text
输入：nums1 = [60,60,60], nums2 = [10,90,10]
输出：210
解释：交换 left = 1, right = 1，nums1 = [60,90,60]，nums2 = [10,60,10]。
分数 = max(210, 80) = 210。
```

**示例 2**

```text
输入：nums1 = [20,40,20,70,30], nums2 = [50,20,50,40,20]
输出：220
解释：交换 left = 3, right = 4，nums1 = [20,40,20,40,20]，nums2 = [50,20,50,70,30]。
分数 = max(140, 220) = 220。
```

**示例 3**

```text
输入：nums1 = [7,11,13], nums2 = [1,1,1]
输出：31
解释：不交换。分数 = max(31, 3) = 31。
```

三个示例恰好覆盖三种形态：交换让 nums1 受益、交换让 nums2 受益、不交换最优——是天然的对拍用例。

## 3. 解题思路

### 3.1 暴力思路：枚举所有交换区间

最直白的做法是枚举全部 $O(n^2)$ 个区间 $[\text{left},\text{right}]$。用前缀和可以 $O(1)$ 算出交换后两个数组的和（模拟交换再整体求和则是 $O(n^3)$），总复杂度 $O(n^2)$：$n = 10^5$ 时约 $10^{10}$ 次运算，**不可行**。

但暴力暴露了本题最关键的量：交换一段后，两个数组和的变化**只取决于这一段上两数组的逐位之差**——「选哪个区间」其实是在一个差值数组上「选一段求和」。

> ⚠️ 重复枚举区间是暴力的根源。把逐位差抽成 `diff` 数组后，区间选择就坍缩成 diff 上的**子数组求和**问题，Kadane 的主场。

### 3.2 核心观察一：交换一段 = diff 上的一段和

![核心观察：交换一段 = 在 diff 上选一段求和，两个候选各自独立](images/wc299_q3_diff_concept.svg)

令 $\text{diff}[i] = \text{nums2}[i] - \text{nums1}[i]$。若交换区间 $[\text{left},\text{right}]$，记 $S = \sum_{i=\text{left}}^{\text{right}} \text{diff}[i]$，则：

$$
\sum \text{nums1}' = \text{sum1} + S, \qquad \sum \text{nums2}' = \text{sum2} - S
$$

即**同一次交换，把 $S$ 从 nums2 手里挪给 nums1**（$S$ 可正可负，负数表示越换越亏）。特别地，不交换对应空段 $S = 0$。

### 3.3 核心观察二：外层 max 可拆 → 两个独立的 Kadane

交换后的分数是 $\max(\text{sum1} + S,\ \text{sum2} - S)$。对所有区间（含空段）取最大时，**外层的 $\max$ 可以拆进两个分支分别取**：

$$
\text{ans} = \max\Big(\max_{\text{区间}}(\text{sum1}+S),\ \max_{\text{区间}}(\text{sum2}-S)\Big)
$$

直观说法：最终的分数总由**某一个数组当「分数载体」**——要么 nums1 当载体，要么 nums2 当载体，两类方案分别取最优后再比大小：

- **候选 A（nums1 当载体）**：帮 nums1 抢 diff 上**和最大**的一段，$\text{ans}_A = \text{sum1} + \text{maxS}$，其中 $\text{maxS} = \max(0,\ \text{最大子数组和})$；
- **候选 B（nums2 当载体）**：帮 nums2 抢 diff 上**和最小**的一段（$S$ 越负，$\text{sum2} - S$ 越大），$\text{ans}_B = \text{sum2} - \text{minS}$，其中 $\text{minS} = \min(0,\ \text{最小子数组和})$。

$$
\boxed{\ \text{ans} = \max(\text{sum1} + \text{maxS},\ \text{sum2} - \text{minS})\ }
$$

$\text{maxS} \ge 0 \ge \text{minS}$（初值取 0 即允许空段），**自动覆盖「不交换」基线**。两个候选各是一遍 Kadane，且 max 系与 min 系互不干扰，可以塞进同一趟循环。

> 💡 「max 可拆」是本题最短推导：不需要分析 $\text{score}(S)$ 的凸性，两行不等式就完成正确性证明（见 §5）。每日题解中的「V 形凸函数、最值在端点」是同一结论的另一条推导路线。

### 3.4 算法流程

![算法流程：一趟循环双 Kadane 同跑，两个候选取大](images/wc299_q3_kadane_flow.svg)

1. **预处理**：$\text{sum1} = \sum \text{nums1}$，$\text{sum2} = \sum \text{nums2}$；初始化 $\text{curMax} = \text{maxS} = \text{curMin} = \text{minS} = 0$。
2. **一趟遍历** $i$ 从 $0$ 到 $n-1$：
   - 即时计算 $d = \text{nums2}[i] - \text{nums1}[i]$（不必建 diff 数组）；
   - **Kadane 求最大**：$\text{curMax} = \max(d,\ \text{curMax} + d)$，$\text{maxS} = \max(\text{maxS},\ \text{curMax})$；
   - **Kadane 求最小**：$\text{curMin} = \min(d,\ \text{curMin} + d)$，$\text{minS} = \min(\text{minS},\ \text{curMin})$。
3. **返回** $\max(\text{sum1} + \text{maxS},\ \text{sum2} - \text{minS})$。

### 3.5 示例演算

![示例演算：一趟双 Kadane 同时维护 maxS 与 minS](images/wc299_q3_example_walkthrough.svg)

**示例 2**：`nums1=[20,40,20,70,30]`，`nums2=[50,20,50,40,20]` → `diff=[+30,−20,+30,−30,−10]`，$\text{sum1}=\text{sum2}=180$

| 步骤 | $d$ | curMax | maxS | curMin | minS |
|------|-----|--------|------|--------|------|
| 初始 | — | 0 | 0 | 0 | 0 |
| ① i=0 | +30 | 30 | 30 | 30 | 0 |
| ② i=1 | −20 | 10 | 30 | −20 | −20 |
| ③ i=2 | +30 | 40 | **40** | 10 | −20 |
| ④ i=3 | −30 | 10 | 40 | −30 | −30 |
| ⑤ i=4 | −10 | 0 | 40 | −40 | **−40** |

- $\text{maxS} = 40$ 来自子段 $[+30,-20,+30]$（下标 0–2）→ 候选 A $= 180 + 40 = 220$（把 50,20,50 换给 nums1）；
- $\text{minS} = -40$ 来自子段 $[-30,-10]$（下标 3–4）→ 候选 B $= 180 - (-40) = 220$（把 70,30 换给 nums2）。

$\text{ans} = \max(220, 220) = 220$ ✓（$\text{sum1} = \text{sum2}$ 时两候选对称，殊途同归）

> ⚠️ **示例 3 的「不交换」**：`diff = [−6,−10,−12]` 全负，Kadane 求最大时 $\text{curMax}$ 步步为负、$\text{maxS}$ 始终停在初值 $0$；$\text{minS} = -28$。候选 A $= 31 + 0 = 31$、候选 B $= 3 + 28 = 31$，$\text{ans} = 31$ ✓。这正是 $\text{maxS}/\text{minS}$ **初值取 0（允许空段）**的意义：任何实际交换都会拖累分数时，自动退回不交换。

## 4. 算法细节

1. **一趟双 Kadane**：max 系（`curMax/maxS`）与 min 系（`curMin/minS`）是两套完全独立的状态，转移互不引用，故可合并到同一趟循环；$d$ 即时计算，空间 $O(1)$。
2. **转移式**：
   - 求最大：$\text{curMax} \leftarrow \max(d,\ \text{curMax}+d)$——「以 $i$ 结尾的最大子数组和」要么单取 $d$，要么接上前一段；
   - 求最小完全对称：$\text{curMin} \leftarrow \min(d,\ \text{curMin}+d)$。
3. **允许空段的写法**：初值/极值与 $0$ 比较。等价写法是 `cur = max(0, cur + d)`（负前缀截断重启），两种写法在本题设定下等价。
4. **溢出处理（C++）**：$n \le 10^5$、元素 $\le 10^4$ ⇒ $\text{sum1}, \text{sum2}, \text{maxS}, |\text{minS}|$ 均可达 $10^9$，$\text{sum1} + \text{maxS}$ 上界 $2 \times 10^9$，已逼近 `INT_MAX ≈ 2.147 × 10^9`——虽然恰好不超但极其危险，**必须 `long long`**：`accumulate` 第三参传 `0LL`，$d$ 显式转 `long long`。Python 无此虞。
5. **返回值**：$\max(\text{sum1} + \text{maxS},\ \text{sum2} - \text{minS})$，无需再单独比较不交换的 $\max(\text{sum1}, \text{sum2})$（已被覆盖）。

## 5. 正确性证明

**引理 1（交换的增量表示）**：对任意 $0 \le \text{left} \le \text{right} < n$，交换 `nums1[left...right]` 与 `nums2[left...right]` 后，两数组的和变为

$$
\sum \text{nums1}' = \text{sum1} + S, \qquad \sum \text{nums2}' = \text{sum2} - S, \qquad S = \sum_{i=\text{left}}^{\text{right}} \text{diff}[i].
$$

**证明**：交换只改动下标落在 $[\text{left},\text{right}]$ 内的元素：nums1 在该段失去 $\sum \text{nums1}[i]$、得到 $\sum \text{nums2}[i]$，故增量恰为 $\sum_i (\text{nums2}[i] - \text{nums1}[i]) = S$；nums2 反向，增量为 $-S$。∎

**引理 2（Kadane 求允许空段的极值子数组和）**：从 $0$ 出发按 $\text{curMax} \leftarrow \max(d_i,\ \text{curMax} + d_i)$ 扫描并维护 $\text{maxS} = \max(\text{maxS},\ \text{curMax})$，得到的 $\text{maxS}$ 等于 $\max(0,\ \max_{\text{非空子数组}} \sum \text{diff})$；对称地，$\text{minS} = \min(0,\ \min_{\text{非空子数组}} \sum \text{diff})$。

**证明**：经典 Kadane 结论（[53. 最大子数组和](https://leetcode.cn/problems/maximum-subarray/)）：$\text{curMax}$ 归纳地等于「以 $i$ 结尾的最大（非空）子数组和」——转移式对应「单取 $d_i$」与「接上以 $i-1$ 结尾的最优段」两种互斥完备的选择；对所有 $i$ 取最大即得全局最大。极值再与初值 $0$ 取大即允许空段。最小侧对称。∎

**定理**：$\text{ans} = \max(\text{sum1} + \text{maxS},\ \text{sum2} - \text{minS})$，其中 $\text{maxS} \ge 0 \ge \text{minS}$ 为允许空段的最大 / 最小子数组和。

**证明**：

- **（≥，可实现）**：取到 $\text{maxS}$ 的段（可能为空）按引理 1 交换后，分数 $= \max(\text{sum1} + \text{maxS},\ \text{sum2} - \text{maxS}) \ge \text{sum1} + \text{maxS}$；取到 $\text{minS}$ 的段交换后，分数 $\ge \text{sum2} - \text{minS}$。两者都是合法策略（含不交换），故 $\text{ans} \ge \max(\text{sum1} + \text{maxS},\ \text{sum2} - \text{minS})$。
- **（≤，无遗漏）**：任一合法策略（交换某段或不交换）对应某个 $S$，且 $\text{minS} \le S \le \text{maxS}$。于是

$$
\text{score}(S) = \max(\text{sum1} + S,\ \text{sum2} - S) \le \max(\text{sum1} + \text{maxS},\ \text{sum2} - \text{minS}),
$$

因为 $\text{sum1} + S \le \text{sum1} + \text{maxS}$ 且 $\text{sum2} - S \le \text{sum2} - \text{minS}$（$\max$ 对两分量分别单调）。对所有 $S$ 取上确界即得 $\text{ans} \le$ 右端。

两方向合并即证。∎

> 💡 证明的关键一步就是「max 可拆」：两个不等式逐分量成立，故 $\max$ 传递——这正是 §3.3 框架的严谨版，全程不需要 $\text{score}(S)$ 的凸性。

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。求 $\text{sum1}/\text{sum2}$ 一趟 $O(n)$；双 Kadane 合并成同一趟 $O(n)$，每个位置仅常数次加减与比较。
- **空间复杂度**：$O(1)$。仅 `sum1/sum2`、`curMax/maxS`、`curMin/minS` 六个滚动变量，不构造 diff 数组。

$n \le 10^5$ 时约几百万次基本运算，远低于时限；相比暴力的 $O(n^2)$，关键归约在于把「交换子数组」翻译成「差值数组上的子数组和」。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    long long maximumsSplicedArray(vector<int>& nums1, vector<int>& nums2) {
        long long sum1 = accumulate(nums1.begin(), nums1.end(), 0LL);
        long long sum2 = accumulate(nums2.begin(), nums2.end(), 0LL);

        long long curMax = 0, maxS = 0;   // 帮 nums1：diff 最大子数组和（允许空段）
        long long curMin = 0, minS = 0;   // 帮 nums2：diff 最小子数组和（允许空段）
        for (int i = 0; i < (int)nums1.size(); ++i) {
            long long d = (long long)nums2[i] - nums1[i];
            curMax = max(d, curMax + d);
            maxS = max(maxS, curMax);
            curMin = min(d, curMin + d);
            minS = min(minS, curMin);
        }
        return max(sum1 + maxS, sum2 - minS);
    }
};
```

### Python

```python
class Solution:
    def maximumsSplicedArray(self, nums1: List[int], nums2: List[int]) -> int:
        sum1, sum2 = sum(nums1), sum(nums2)

        cur_max = max_s = 0   # 帮 nums1：diff 最大子数组和（允许空段）
        cur_min = min_s = 0   # 帮 nums2：diff 最小子数组和（允许空段）
        for a, b in zip(nums1, nums2):
            d = b - a
            cur_max = max(d, cur_max + d)
            max_s = max(max_s, cur_max)
            cur_min = min(d, cur_min + d)
            min_s = min(min_s, cur_min)
        return max(sum1 + max_s, sum2 - min_s)
```

## 8. 边界情况与易错点

1. **溢出（C++ 头号坑）**：$\text{sum1} + \text{maxS}$ 上界 $2 \times 10^9$，距 `INT_MAX`（约 $2.147 \times 10^9$）只差 7%，侥幸不超但一步改动（如中途 `int` 累加溢出）即翻车。必须全程 `long long`：`accumulate` 第三参传 `0LL`（传 `0` 会在 `int` 上累加后才转换，中途已溢），$d$ 显式 cast。

2. **空段初值**：`maxS/minS` 初值取 $0$（允许空段 = 不交换），**不能**照搬 53 题的「至少取一个元素」初值——全负 diff（示例 3）会把 $\text{maxS}$ 算成最大负数，错失「不交换」这个最优解。比赛时用示例 3 当对拍用例即可当场发现。

3. **diff 方向别搞反**：本篇定义 $\text{diff} = \text{nums2} - \text{nums1}$，「正的 $d$ = nums2 更大 = 值得抢给 nums1」。若定义成 $\text{nums1} - \text{nums2}$，则 $\text{maxS}$ 对应帮 nums2、$\text{minS}$ 对应帮 nums1，两个候选公式必须整体对调；定义与公式混用必错。

4. **一次交换同时作用于两个数组**：不是「nums1、nums2 各自独立换一段」。妙处在于外层 $\max$ 可拆，**分别**优化两个候选恰好等价于原问题——若目标改成 $\min(\sum\text{nums1}, \sum\text{nums2})$（最小化较小者），这一拆分失效，需另作分析（见延伸思考）。

5. **不要漏掉外层 max**：不交换时分数 $= \max(\text{sum1}, \text{sum2})$，已被 $\text{maxS} \ge 0$、$\text{minS} \le 0$ 自动覆盖，无需特判；但若实现时只算了单个候选（只帮 nums1 或只帮 nums2），示例 2 这类「受益方是 nums2」的用例就会答错。

6. **$n = 1$**：交换区间只能是 $[0,0]$ 或不交换，Kadane 自动处理，无需特判。
