# LeetCode 从树中删除边的最小分数 题解

## 1. 题目概述

- **标题 / 题号**：从树中删除边的最小分数（#2322，hard）
- **链接**：https://leetcode.cn/problems/minimum-score-after-removals-on-a-tree/
- **来源**：LeetCode 第 299 场周赛 Q4
- **难度**：困难
- **标签**：树、深度优先搜索、位运算、数组

**题意**：给定一棵 $n$ 个节点（编号 $0 \sim n-1$）的无向连通树（$n-1$ 条边），节点 $i$ 的权值为 $\text{nums}[i]$。**删除两条不同的边**，树被切成三个连通分量；对每个分量求其所有节点权值的**异或值**，该方案的**分数** = 三个异或值中的 $\max - \min$。返回所有删边方案中的最小分数。

**约束**：

- $3 \le n \le 1000$
- $1 \le \text{nums}[i] \le 10^8$
- `edges` 表示一棵有效的树

> 💡 **比赛定位**：本场收官困难题，识别信号有三条叠满：① **数据范围 $n \le 1000$** 是出题人明示 $O(n^2)$ 的通行暗号——$\binom{n-1}{2} \approx 5 \times 10^5$ 个点对随便扫；② **树上删边**提示「删边 = 摘子树」，子树的聚合量理应一次 DFS 预处理；③ **异或**自带消去律 $x \oplus x = 0$，让「差集」「剩余部分」都能 $O(1)$ 代数算出。三条合流：预处理子树 XOR + DFS 时间戳，$\binom{n-1}{2}$ 个断点对逐对 $O(1)$ 打分。核心代码不到 20 行，难在把「几何的删边」翻译成「代数的子树运算」这一步。

> 💡 本题在本仓库另有[每日题解 2322](../../solution/2301-2400/2322_从树中删除边的最小分数.md)：递归 DFS 版实现、两种时间戳约定的对照与面试问答式展开。本篇按周赛复盘视角展开，侧重**赛场识别链、迭代 DFS 规避爆栈、引理-定理完整证明与边界清单**，两篇互为印证。

## 2. 示例

**示例 1**

```text
输入：nums = [1,5,5,4,11], edges = [[0,1],[1,2],[1,3],[3,4]]
输出：9
解释：删边 (0,1) 与 (1,2)：
  分量 {0} 异或 1；{2} 异或 5；{1,3,4} 异或 5^4^11 = 10。
  分数 = 10 − 1 = 9。
```

**示例 2**

```text
输入：nums = [5,5,2,4,4,2], edges = [[0,1],[1,2],[5,2],[4,3],[1,3]]
输出：0
解释：删边 (1,2) 与 (1,3)：
  分量 {2,5} 异或 0；{3,4} 异或 0；{0,1} 异或 0。
  分数 = 0 − 0 = 0。
```

示例 2 里三个分量异或**全为 0**——分数非负，取到 $0$ 即理论下界。这提示「让三段相等」是理想打法，也说明答案对「构造」敏感：同一棵树换个删法分数天差地别，逐对枚举反而是最稳的完全之策。

## 3. 解题思路

### 3.1 暴力思路：枚举边对，每对重算三分量

最直白的做法：在 $\binom{n-1}{2} \approx 5 \times 10^5$ 种删边方案里，每次**重新遍历**三个分量求异或。每方案 $O(n)$，总计 $O(n^3) \approx 10^9$，$n=1000$ 下超时。

浪费点一眼可见：**同一棵子树在不同方案里被反复遍历求异或**。子树异或是一个封闭、可预计算的量——把它提前算好，每个方案就只剩「查表 + 常数次异或」。

### 3.2 核心观察一：删一条边 = 摘走一棵子树

![核心观察：删一条边等于摘走一棵子树，子树 XOR 一次 DFS 备好](images/wc299_q4_subtree_xor_concept.svg)

把树**以 0 定根**。此时每条边都唯一地是某个非根节点 $c$ 的**父边** $(c,\ \text{parent}[c])$——「删边」与「摘子树」一一对应。一次后序 DFS 算出：

- $\text{xor}[c]$：子树 $c$ 内所有点权的异或；
- $\text{total} = \text{xor}[0]$：全树异或（根的子树 XOR 就是全树 XOR，无需另算）。

于是删一条父边后的两段 XOR 为 $(\text{xor}[c],\ \text{total} \oplus \text{xor}[c])$——「其余部分」不用遍历，靠消去律 $x \oplus x = 0$ 从 $\text{total}$ 里**抠掉**子树即可。全程唯一的公式工具就是这条消去律。

### 3.3 核心观察二：两条断点只有两种拓扑

![两条断点的两种拓扑：平行不相交与祖先嵌套，各自的三分量公式](images/wc299_q4_two_cases.svg)

删两条边即摘两棵子树，断点记为 $i, j$（被摘子树的根）。树有一个漂亮的性质（引理见 §5）：**任意两棵子树要么完全不相交，要么一棵真包含另一棵**，绝无「部分重叠」。于是三分量 XOR 只有两种公式：

| 拓扑 | 三分量 XOR | 直觉 |
|------|-----------|------|
| 不相交（平行） | $\text{xor}[i],\ \text{xor}[j],\ \text{total} \oplus \text{xor}[i] \oplus \text{xor}[j]$ | 各摘一棵，第三段 = 全树去掉两棵 |
| $i$ 是 $j$ 的祖先 | $\text{xor}[j],\ \text{xor}[i] \oplus \text{xor}[j],\ \text{total} \oplus \text{xor}[i]$ | 摘 $j$ 藏在 $i$ 内，中段 = $i$ 再抠掉 $j$ |

（$j$ 是 $i$ 的祖先时把 $i, j$ 对调即得第三种形式。）关键在嵌套情形的**中段**：摘外子树 $i$ 时内子树 $j$ 还在里面，所以是 $\text{xor}[i] \oplus \text{xor}[j]$（差集）而不是 $\text{xor}[i]$。

而「哪一种拓扑」用 DFS 进/出时间戳 $O(1)$ 判定：$i$ 是 $j$ 的祖先 $\Leftrightarrow \text{tin}[i] < \text{tin}[j] < \text{tout}[i]$。

### 3.4 算法流程

![算法流程：迭代 DFS 预处理，枚举点对，判拓扑选公式，取分数最小](images/wc299_q4_algorithm_flow.svg)

1. **预处理**（$O(n)$）：建邻接表，以 0 为根做**迭代 DFS**（两阶段栈），得到 $\text{xor}[]$、$\text{tin}[]$、$\text{tout}[]$，$\text{total} = \text{xor}[0]$。
2. **枚举**（$O(n^2)$）：非根点对 $1 \le i < j \le n-1$（每个非根节点 ↔ 一条父边，恰好不重不漏覆盖所有删两条边的方案）。
3. **判定与打分**（每对 $O(1)$）：时间戳判拓扑 → 选三分量公式 → $\text{score} = \max - \min$，$\text{ans} = \min(\text{ans}, \text{score})$。
4. 返回 $\text{ans}$。

### 3.5 示例演算

![示例 1 演算：枚举全部 6 个断点对，最优 (1,2) 分数 9](images/wc299_q4_example_walkthrough.svg)

**示例 1** 以 0 定根后：

| 节点 | 4 | 3 | 2 | 1 | 0 |
|------|---|---|---|---|---|
| 子树 XOR | 11 | $4 \oplus 11 = 15$ | 5 | $5 \oplus 5 \oplus 15 = 15$ | $1 \oplus 15 = 14$ = total |

6 个断点对逐对打分（三分量 XOR 与分数）：

| 点对 | 拓扑 | 三分量 XOR | 分数 |
|------|------|-----------|------|
| **(1,2)** | $i \supset j$ | **(5, 10, 1)** | **9 ✓** |
| (1,3) | $i \supset j$ | (15, 0, 1) | 15 |
| (1,4) | $i \supset j$ | (11, 4, 1) | 10 |
| (2,3) | 平行 | (5, 15, 4) | 11 |
| (2,4) | 平行 | (5, 11, 0) | 11 |
| (3,4) | $i \supset j$ | (11, 4, 1) | 10 |

$\text{ans} = 9$ ✓。手算 $(1,2)$ 这一行即可当场校验嵌套公式：中段 $= \text{xor}[1] \oplus \text{xor}[2] = 15 \oplus 5 = 10$，正是 $\{1,3,4\}$ 的异或 $5 \oplus 4 \oplus 11$。

**示例 2 为何得 0**：$\text{xor}[2] = 2 \oplus 2 = 0$、$\text{xor}[3] = 4 \oplus 4 = 0$、$\text{total} = 0$；断点 $(2,3)$ 平行，三分量 $(0, 0, 0)$，分数 $0$——非负下界即最优。

## 4. 算法细节

1. **迭代 DFS（两阶段栈）**：栈存「节点 + 是否为离开阶段」。首次弹出记 $\text{tin}$、初始化 $\text{xor}[u] = \text{nums}[u]$，先压回 $(u, \text{true})$ 再压所有孩子；再次弹出记 $\text{tout}$，并把 $\text{xor}[u]$ 并给父亲。「离开阶段」天然排在所有孩子的离开之后——自底向上合并无须递归。选迭代而非递归的原因见 §8 第 3 条：$n = 1000$ 的链状树递归深度恰为 1000，压在 Python 默认递归上限上，迭代写法一劳永逸，且 C++/Python 两份代码结构完全一致。
2. **$O(1)$ 判祖先**：$i$ 是 $j$ 的真祖先 $\Leftrightarrow \text{tin}[i] < \text{tin}[j] < \text{tout}[i]$（DFS 区间的嵌套性，证明见 §5 引理 3）。每个点对先判一个方向、再判另一方向、都不中即平行，三分支 `if / elif / else`。
3. **点对 ↔ 边对一一对应**：非根节点 $v$ ↔ 父边 $(v, \text{parent}[v])$，故枚举 $1 \le i < j \le n-1$ 恰好不重不漏覆盖全部 $\binom{n-1}{2}$ 种「删两条不同边」的方案。
4. **total = xor[0]**：根的子树 XOR 即全树 XOR，不必单独累加。
5. **打分**：`max({a, b, c}) - min({a, b, c})`，三分量对称，无须关心哪段是哪段。

## 5. 正确性证明

**引理 1（异或的划分律）**：若点集 $V$ 被划分为不相交的部分 $V = A_1 \sqcup A_2 \sqcup \cdots \sqcup A_k$，则 $\text{xor}(V) = \text{xor}(A_1) \oplus \text{xor}(A_2) \oplus \cdots \oplus \text{xor}(A_k)$；特别地，任一部分 $A$ 的补集异或 $= \text{xor}(V) \oplus \text{xor}(A)$。

**证明**：异或是**逐位的模 2 加法**。右端每个点权恰好出现一次，故对任意二进制位，右端该位为 1 的总个数等于 $A_1, \dots, A_k$ 中该位为 1 的个数之和，奇偶性与左端一致。∎

**引理 2（子树拓扑二分性）**：$i \ne j$ 时，$\text{subtree}(i)$ 与 $\text{subtree}(j)$ 要么不相交，要么一棵真包含另一棵。

**证明**：「$w \in \text{subtree}(u)$」$\Leftrightarrow$ $u$ 是 $w$ 的祖先（含自身）。树上任一点 $w$ 的祖先构成**一条全序链**（根到 $w$ 的唯一路径上的节点，按深度可比）。若存在 $w$ 同属两棵子树，则 $i, j$ 同在 $w$ 的祖先链上，必可比，于是 $i$ 是 $j$ 的真祖先（或反之），两子树呈真包含；若无公共点则不相交。∎

**引理 3（时间戳判祖先）**：$i$ 是 $j$ 的真祖先 $\Leftrightarrow \text{tin}[i] < \text{tin}[j] < \text{tout}[i]$。

**证明**：DFS 进入 $i$ 之后才可能进入其后代，且离开 $i$ 之前必已离开其全部后代，故 $\text{subtree}(i)$ 内所有节点的 $\text{tin}/\text{tout}$ 均严格落在开区间 $(\text{tin}[i], \text{tout}[i])$ 内。反之若 $\text{tin}[j] \in (\text{tin}[i], \text{tout}[i])$：DFS 时间戳区间要么嵌套要么不相交，而 $j$ 的区间与 $i$ 的区间已有交（含 $\text{tin}[j]$），故只能嵌套；嵌套且 $\text{tin}[j] > \text{tin}[i]$ 说明 $j$ 严格在 $i$ 内，即 $j$ 是 $i$ 的后代。∎

**定理（三分量公式与枚举的完全性）**：对每个非根点对 $1 \le i < j \le n-1$，按引理 2 的两种拓扑用 §3.3 公式计算三分量并取 $\max - \min$，所有点对的最小值即答案。

**证明**：

- **（每对都算对）** 点对 $(i, j)$ 对应删父边 $(i, \text{parent}[i])$ 与 $(j, \text{parent}[j])$，两条边不同，是合法方案，切出的三个分量依拓扑只有两种形态：
  - **不相交**：分量为 $\text{subtree}(i)$、$\text{subtree}(j)$、其余。由引理 1（三分量构成全树的划分），三分量 XOR 为 $\text{xor}[i]$、$\text{xor}[j]$、$\text{total} \oplus \text{xor}[i] \oplus \text{xor}[j]$。
  - **嵌套（$i$ 是 $j$ 的真祖先）**：分量为 $\text{subtree}(j)$、$\text{subtree}(i) \setminus \text{subtree}(j)$、其余。$\text{subtree}(i)$ 被划分为 $\text{subtree}(j)$ 与差集，由引理 1 差集 XOR $= \text{xor}[i] \oplus \text{xor}[j]$；其余 XOR $= \text{total} \oplus \text{xor}[i]$。$j$ 是 $i$ 的祖先时对称。
- **（不漏）** 任一「删两条不同边」的方案，两条边各唯一对应一个非根断点，构成被枚举的点对。
- **（不重）** 点对到删边方案的映射是单射，重复计算不影响最小值。

三分句合并即证。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n^2)$。迭代 DFS 预处理 $O(n)$；双重循环枚举非根点对 $\binom{n-1}{2} \approx n^2 / 2$ 个，每对仅两次比较判拓扑 + 常数次异或与比较，$O(1)$。$n \le 1000$ 时约 $5 \times 10^5$ 对，远低于时限。
- **空间复杂度**：$O(n)$。邻接表与 $\text{xor}/\text{tin}/\text{tout}/\text{parent}$ 四个数组各 $O(n)$，迭代栈最坏 $O(n)$（链状树每节点压两次）。

相比暴力的 $O(n^3)$，关键归约在于把「每个方案重算三分量」重构为「预处理子树 XOR + 时间戳，方案打分变 $O(1)$」——$n \le 1000$ 正是给 $O(n^2)$ 留的活口。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int minimumScore(vector<int>& nums, vector<vector<int>>& edges) {
        int n = nums.size();
        vector<vector<int>> g(n);
        for (auto& e : edges) {
            g[e[0]].push_back(e[1]);
            g[e[1]].push_back(e[0]);
        }

        int total = 0;
        for (int x : nums) total ^= x;

        vector<int> xr(n), tin(n), tout(n), parent(n, -1);
        int timer = 0;
        vector<pair<int, bool>> st;      // (节点, 是否为离开阶段)
        st.push_back({0, false});
        while (!st.empty()) {
            auto [u, done] = st.back();
            st.pop_back();
            if (done) {                  // 离开：记 tout，子树 XOR 并给父亲
                tout[u] = timer++;
                if (parent[u] != -1) xr[parent[u]] ^= xr[u];
            } else {                     // 进入：记 tin，压回离开阶段再压孩子
                tin[u] = timer++;
                xr[u] = nums[u];
                st.push_back({u, true});
                for (int v : g[u]) {
                    if (v != parent[u]) {
                        parent[v] = u;
                        st.push_back({v, false});
                    }
                }
            }
        }

        int ans = INT_MAX;
        for (int i = 1; i < n; ++i) {
            for (int j = i + 1; j < n; ++j) {
                int a, b, c;
                if (tin[i] < tin[j] && tin[j] < tout[i]) {        // i 是 j 的祖先
                    a = xr[j]; b = xr[i] ^ xr[j]; c = total ^ xr[i];
                } else if (tin[j] < tin[i] && tin[i] < tout[j]) { // j 是 i 的祖先
                    a = xr[i]; b = xr[j] ^ xr[i]; c = total ^ xr[j];
                } else {                                          // 两棵子树不相交
                    a = xr[i]; b = xr[j]; c = total ^ xr[i] ^ xr[j];
                }
                ans = min(ans, max({a, b, c}) - min({a, b, c}));
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def minimumScore(self, nums: List[int], edges: List[List[int]]) -> int:
        n = len(nums)
        g = [[] for _ in range(n)]
        for a, b in edges:
            g[a].append(b)
            g[b].append(a)

        total = 0
        for x in nums:
            total ^= x

        xr = [0] * n
        tin = [0] * n
        tout = [0] * n
        parent = [-1] * n
        timer = 0
        st = [(0, False)]                 # (节点, 是否为离开阶段)
        while st:
            u, done = st.pop()
            if done:                      # 离开：记 tout，子树 XOR 并给父亲
                tout[u] = timer
                timer += 1
                if parent[u] != -1:
                    xr[parent[u]] ^= xr[u]
            else:                         # 进入：记 tin，压回离开阶段再压孩子
                tin[u] = timer
                timer += 1
                xr[u] = nums[u]
                st.append((u, True))
                for v in g[u]:
                    if v != parent[u]:
                        parent[v] = u
                        st.append((v, False))

        ans = float("inf")
        for i in range(1, n):             # 非根点对：每个 v ↔ 删父边 (v, parent[v])
            for j in range(i + 1, n):
                if tin[i] < tin[j] < tout[i]:            # i 是 j 的祖先
                    a, b, c = xr[j], xr[i] ^ xr[j], total ^ xr[i]
                elif tin[j] < tin[i] < tout[j]:          # j 是 i 的祖先
                    a, b, c = xr[i], xr[j] ^ xr[i], total ^ xr[j]
                else:                                    # 两棵子树不相交
                    a, b, c = xr[i], xr[j], total ^ xr[i] ^ xr[j]
                ans = min(ans, max(a, b, c) - min(a, b, c))
        return ans
```

## 8. 边界情况与易错点

1. **只枚举非根节点**：根 $0$ 没有父边，循环必须从 $i = 1$ 起；把根也枚举进去等于凭空多算「不存在的边」。

2. **嵌套时中段要 $\oplus \text{xor}[内]$**：差集 XOR $= \text{xor}[外] \oplus \text{xor}[内]$，不是 $\text{xor}[外]$——摘外子树时内子树还在里面。三个 case 的公式混用是本题最大 WA 源；比赛时拿示例 1 手算 $(1,2)$ 一行即可当场校验（中段 $= 15 \oplus 5 = 10$ 恰是 $\{1,3,4\}$ 的异或）。

3. **Python 递归深度压线**：链状树递归深度恰为 $1000$，正好卡在默认上限上，`RecursionError` 风险极高（即使侥幸通过也是定时炸弹）。迭代 DFS 一劳永逸；退而求其次 `sys.setrecursionlimit`。本篇代码用迭代版根治，且与 C++ 版逐行同构。

4. **XOR 无溢出之虞**：$\text{nums}[i] \le 10^8 < 2^{27}$，任意异或结果 $< 2^{27}$，`int` 富余——与 Q3「求和逼近 `INT_MAX`」形成对照：异或是按位运算不进位，值域天然有界。

5. **判祖先用严格不等号**：本篇判据 $\text{tin}[i] < \text{tin}[j] < \text{tout}[i]$ 在 $i = j$ 时自然为假；若改用含等号的双侧版 $\text{tin}[u] \le \text{tin}[v] \wedge \text{tout}[v] \le \text{tout}[u]$，则 $\text{isAnc}(u, u)$ 为真——本题因 $i < j$ 两种写法都对，但混用时要想清楚语义（每日题解用的是含等号版）。

6. **$n = 3$**：只有两条边、一个点对，循环自然覆盖，无需特判；答案一定被更新，`ans` 初值取极大即可。

7. **`total` 别另算一遍**：$\text{total} = \text{xor}[0]$，单独再异或一遍虽不错但多余——顺便可用它自检 DFS 正确性。

- [LeetCode 2538. 最大价值和与最小价值和的差](https://leetcode.cn/problems/difference-between-maximum-and-minimum-price-sum/)：同样「删边取分量极值差」，但只删一条边 → 换根 DP $O(n)$；与本题「删两条边 → 枚举 $O(n^2)$」互为复杂度对照。

**延伸思考**：

- **若 $n$ 放大到 $10^5$**：$O(n^2)$ 失效。「分数 $= \max - \min$」不可分解为逐边独立的量，朴素枚举无以为继；需固定一条断点后，沿 DFS 序在子树 XOR 集合里快速查询「最接近目标值的第二个断点」（排序 + 二分 / 启发式合并维护），远超周赛难度。$n \le 1000$ 正是出题人给 $O(n^2)$ 留的活口——**读数据范围反推预期复杂度**本身就是周赛核心技能。
- **若删 $k$ 条边求极值差最小**：$k = 2$ 时「枚举断点对 + 拓扑分类」的套路尚可；$k$ 更大时拓扑组合爆炸，需按分数的具体定义另寻结构（经典的树上分组背包只处理「可加」的分数，极值差这类不可分解目标要具体问题具体分析）。
- **若分数改为「最大 XOR − 次大 XOR」**：枚举框架原封不动，只是三分量取极值的姿势变了——本题真正的模板价值在「删边 → 子树代数」这层翻译，而非极值本身。
