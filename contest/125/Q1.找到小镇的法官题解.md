# LeetCode 找到小镇的法官 题解

## 1. 题目概述

- **标题 / 题号**：找到小镇的法官（#997，easy）
- **链接**：https://leetcode.cn/problems/find-the-town-judge/
- **来源**：LeetCode 第 125 场周赛 Q1
- **难度**：简单
- **标签**：图、数组、哈希表

**题意**：小镇有 $n$ 个人，编号 $1 \sim n$。传言中有一位**法官**，满足：

1. 法官**不信任任何人**；
2. 除法官外的**每个人**都信任法官；
3. 只有一个人同时满足这两条。

给定 `trust` 数组，其中 `trust[i] = [a, b]` 表示 $a$ 信任 $b$。若法官存在且唯一，返回其编号，否则返回 $-1$。

**约束**：

- $1 \le n \le 1000$
- $0 \le trust.length \le 10^4$
- 所有 `trust[i]` 互不相同，$a_i \ne b_i$，$1 \le a_i, b_i \le n$

> 💡 「信任」是**有向**关系，$a \to b$ 中的方向很重要。两条要求恰好对应有向图中一个点的**出度**和**入度**。

## 2. 示例

**示例 1**

```text
输入：n = 2, trust = [[1,2]]
输出：2
解释：1 信任 2，2 谁也不信任 → 2 是法官。
```

**示例 2**

```text
输入：n = 3, trust = [[1,3],[2,3]]
输出：3
解释：1、2 都信任 3，3 不信任任何人。
```

**示例 3**

```text
输入：n = 3, trust = [[1,3],[2,3],[3,1]]
输出：-1
解释：3 虽然被两人信任，但 3 自己信任了 1，不满足第一条。
```

## 3. 解题思路

### 3.1 暴力思路

枚举每个候选人 $c$，检查「所有 $a_i \ne c$」且「$c$ 出现在每条信任关系的 $b$ 位置共 $n-1$ 次」。每个候选人扫一遍 `trust`，复杂度 $O(n \cdot m)$，$n = 1000$、$m = 10^4$ 时是 $10^7$ 次判断，可以过但不必要——统计度数只需一遍。

### 3.2 核心观察：入度与出度

![法官 = 入度 n−1、出度 0 的唯一点](images/wc125_q1_judge_degrees.svg)

把 `trust` 看成有向图：边 $a \to b$ 表示 $a$ 信任 $b$。定义

- $\text{outdeg}(v)$：以 $v$ 为起点的边数，即 $v$ 信任的人数；
- $\text{indeg}(v)$：以 $v$ 为终点的边数，即信任 $v$ 的人数。

于是两条要求翻译为：

$$\text{outdeg}(c) = 0 \quad\wedge\quad \text{indeg}(c) = n - 1 .$$

- $\text{outdeg} = 0$ 排除了「法官信任别人」（示例 3 的 3 就是这里被淘汰）；
- $\text{indeg} = n-1$ 表示除自己外的所有人都信任他。

因为 `trust[i]` 互不相同，直接计数不会重复累加。

### 3.3 算法流程

```text
1. indeg[1..n] = 0，outdeg[1..n] = 0
2. for (a, b) in trust:
       outdeg[a] += 1
       indeg[b]  += 1
3. for v in 1..n:
       若 indeg[v] == n-1 且 outdeg[v] == 0: 返回 v
4. 返回 -1
```

只需两遍线性扫描：一遍统计度数，一遍找满足条件的人。

### 3.4 示例演算

![示例 3 的度数表](images/wc125_q1_walkthrough.svg)

对示例 3 的 `trust = [[1,3],[2,3],[3,1]]`：

| 人 | 入度 | 出度 | 判定 |
|----|------|------|------|
| 1 | 0 | 1 | 入度不足 |
| 2 | 0 | 1 | 入度不足 |
| 3 | 2 | 1 | 入度够，但出度 $=1 \ne 0$ |

无人满足 → 返回 $-1$。对照示例 2，3 的入度为 2、出度为 0 → 返回 3。

## 4. 算法细节

1. **下标从 1 开始**：数组开 $n+1$ 大小，`indeg[0]` 闲置，避免 `-1` 偏移。
2. **两遍扫描**：第一遍统计度数，第二遍挑人。也可以边统计边判断，但会出现「后面还有边没算完」的问题，两遍最稳。
3. **唯一性由条件保证**：若两个人都满足 $\text{indeg} = n-1$，则他们都得被对方信任，于是各自 $\text{indeg} \ge 1$ 且存在边，与 $\text{outdeg} = 0$ 矛盾。所以不用额外去重。
4. **$n = 1$**：没有信任关系，1 号人 $\text{indeg} = 0 = n-1$、$\text{outdeg} = 0$，返回 1。
5. **自环不存在**：题面保证 $a_i \ne b_i$，不需要处理「自己信任自己」。
6. **空 trust**：$n \ge 2$ 时无人入度达到 $n-1$，返回 $-1$。

## 5. 正确性证明

**引理 1（条件等价）**：人 $c$ 满足题面两条要求，当且仅当 $\text{outdeg}(c) = 0$ 且 $\text{indeg}(c) = n-1$。

**证明**：
（必要性）法官不信任任何人 $\Rightarrow$ 没有以 $c$ 为起点的边 $\Rightarrow \text{outdeg}(c) = 0$。除法官外每个人都信任法官 $\Rightarrow$ 其余 $n-1$ 个人各贡献一条指向 $c$ 的边，且由于 $a_i \ne b_i$ 无人自环、`trust` 互不相同故不重复，得 $\text{indeg}(c) = n-1$。
（充分性）$\text{outdeg}(c) = 0$ 说明没有任何边从 $c$ 出发，即 $c$ 不信任任何人。$\text{indeg}(c) = n-1$ 说明恰有 $n-1$ 条边指向 $c$；可能的起点集合大小为 $n-1$（除 $c$ 外的人），而 `trust` 中 $(a,b)$ 互不相同意味着同一对 $(a,c)$ 不会重复，故这 $n-1$ 条边的起点恰好是除 $c$ 外的全部人。两条要求均满足。∎

**引理 2（至多一人）**：满足引理 1 条件的人至多一个。

**证明**：假设 $c_1 \ne c_2$ 都满足。由 $c_1$ 的 $\text{indeg} = n-1$，存在边 $c_2 \to c_1$；但由 $c_2$ 的 $\text{outdeg} = 0$，不存在从 $c_2$ 出发的边，矛盾。∎

**定理**：算法返回的编号恰为法官；若不存在则返回 $-1$。

**证明**：算法遍历所有 $v$，返回第一个满足引理 1 条件的点。由引理 1，它满足法官的两条要求；由引理 2，最多只有一个这样的点，所以「第一个」就是唯一的法官，且没有更优的候选被跳过。若没有点满足条件，说明不存在法官（引理 1 的等价性保证），返回 $-1$ 正确。∎

## 6. 复杂度分析

- **时间**：$O(n + m)$，其中 $m = trust.length$。统计度数遍历 $m$ 条边，找人遍历 $n$ 个点。
- **空间**：$O(n)$，两个长度为 $n+1$ 的计数数组。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int findJudge(int n, vector<vector<int>>& trust) {
        vector<int> indeg(n + 1, 0), outdeg(n + 1, 0);
        for (const auto& e : trust) {
            outdeg[e[0]]++;
            indeg[e[1]]++;
        }
        for (int v = 1; v <= n; v++) {
            if (indeg[v] == n - 1 && outdeg[v] == 0) return v;
        }
        return -1;
    }
};
```

### Python

```python
class Solution:
    def findJudge(self, n: int, trust: list[list[int]]) -> int:
        indeg = [0] * (n + 1)
        outdeg = [0] * (n + 1)
        for a, b in trust:
            outdeg[a] += 1
            indeg[b] += 1
        for v in range(1, n + 1):
            if indeg[v] == n - 1 and outdeg[v] == 0:
                return v
        return -1
```

## 8. 边界情况与易错点

1. **示例 3 的陷阱**：只看「被多少人信任」会把 3 判成法官，必须同时检查出度为 0。
2. **$n = 1$**：返回 1（自己就是法官），不要因为 `trust` 为空就返回 $-1$。
3. **方向搞反**：$a$ 信任 $b$，出度加在 $a$ 上、入度加在 $b$ 上，写反会全错。
4. **入度条件用 $n-1$ 而非 $n$**：法官不信任自己（题面保证 $a_i \ne b_i$），所以最多 $n-1$ 个人信任他。
5. **重复边**：题面保证 `trust[i]` 互不相同，无需去重；若变体允许重复，需要改用集合。
6. **数组下标**：编号从 1 开始，开 $n+1$ 的数组，访问 `indeg[v]` 时 $v$ 从 1 到 $n$。
7. **多个候选人**：由引理 2 不可能有两个，代码不需要额外处理。
