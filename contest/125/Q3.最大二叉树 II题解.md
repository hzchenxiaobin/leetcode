# LeetCode 最大二叉树 II 题解

## 1. 题目概述

- **标题 / 题号**：最大二叉树 II（#998，medium）
- **链接**：https://leetcode.cn/problems/maximum-binary-tree-ii/
- **来源**：LeetCode 第 125 场周赛 Q3
- **难度**：中等
- **标签**：树、二叉树

**题意**：**最大树**定义为每个结点的值都大于其子树中任何其它值的二叉树。给定最大树的根 `root`（它由某个数组 $a$ 经 `Construct(a)` 递归构造而来：取 $a$ 的最大元素为根，左子树由最大元素左侧的部分递归构造，右子树由右侧部分递归构造），并给定整数 `val`。设 $b$ 是 $a$ 的副本末尾追加 `val` 后的数组，要求返回 `Construct(b)`。

**约束**：

- 树中结点数在 $[1, 100]$ 内
- $1 \le Node.val \le 100$，结点值互不相同
- $1 \le val \le 100$，且 `val` 与树中所有值都不同

> 💡 题目不会直接给出数组 $a$，但最大树的**中序遍历**就是 $a$。真正的解法不需要还原 $a$，只需利用「追加在末尾」这一事实。

## 2. 示例

**示例 1**

```text
输入：root = [4,1,3,null,null,2], val = 5
输出：[5,4,null,1,3,null,null,2]
解释：a = [1,4,2,3]，b = [1,4,2,3,5]，5 是最大值，成为新根，原树整体成为左子树。
```

**示例 2**

```text
输入：root = [5,2,4,null,1], val = 3
输出：[5,2,4,null,1,null,3]
解释：a = [2,1,5,4]，b = [2,1,5,4,3]，3 比根 5 小，插入到右子树的右侧。
```

**示例 3**

```text
输入：root = [5,2,3,null,1], val = 4
输出：[5,2,4,null,1,3]
解释：a = [2,1,5,3]，b = [2,1,5,3,4]，4 取代 3 成为 5 的右子，3 变成 4 的左子。
```

## 3. 解题思路

### 3.1 暴力思路

先用中序遍历还原数组 $a$，在末尾追加 `val` 得到 $b$，再按定义用递归 `Construct(b)` 重建整棵树。复杂度 $O(n^2)$（每次找最大值 $O(n)$），$n \le 100$ 当然能过，但完全没有利用「已经有一棵最大树」这个信息，属于重建而非增量修改。

### 3.2 核心观察：新值只可能出现在「最右侧那条链」上

![新值只落在最右侧的链上](images/wc125_q3_insert_rule.svg)

关键事实有两条：

1. 最大树的中序遍历等于原数组，**根是数组最大值**，左子树对应最大值的左侧前缀，右子树对应右侧后缀。
2. `val` 被追加到数组**最末尾**，所以在 $b$ 中它位于所有原有元素的**右边**。

于是：

- 若 $val > root.val$：$val$ 是 $b$ 的最大值，直接成为新根，原来的整棵树成为它的**左子树**（因为所有旧元素都在 $val$ 左边）。
- 否则：根不变（$root.val$ 仍是最大值）。$val$ 在数组里位于根的右侧，因此它必然落在**右子树**里，递归处理 `root.right`。

递归的每一层都只往右走，所以真正被修改的只是「从根一路向右」的那条链，深度不超过树高。

### 3.3 算法流程

```text
insertIntoMaxTree(root, val):
    若 root 为空: 返回新结点 TreeNode(val)
    若 val > root.val:
        node = TreeNode(val)
        node.left = root
        返回 node
    root.right = insertIntoMaxTree(root.right, val)
    返回 root
```

第三种情形（`root` 为空）只在 `val` 一路比到底、需要挂在某个叶子的右子位置时出现。

### 3.4 示例演算

![示例 3 的插入过程](images/wc125_q3_walkthrough.svg)

对示例 3 的 `root = [5,2,3,null,1]`、`val = 4`：

| 层 | 当前结点 | 比较 | 动作 |
|----|----------|------|------|
| 1 | 5 | $4 < 5$ | 递归右子树 |
| 2 | 3 | $4 > 3$ | 4 成为该位置的根，3 挂到 4 的左边 |

结果：`5` 的右子由 `3` 换成 `4`，`3` 成为 `4` 的左子，最终 `[5,2,4,null,1,3]`，与题面一致。对照示例 1：$5 > 4$（根），直接新根 + 旧树作左子。

## 4. 算法细节

1. **只走右链**：递归调用只出现在 `root.right`，左子树完全不碰，这是复杂度的来源。
2. **新根情形**：`node.left = root`，`node.right` 保持空——因为 `val` 是最大值，右侧没有元素。
3. **空结点情形**：`root == null` 时返回新结点，对应「`val` 比右链上所有值都小」的收尾。
4. **不修改原树的其它部分**：其余子树原样保留，指针直接复用。
5. **递归深度**：树高最坏 $n = 100$，C++/Python 都安全。
6. **值互不相同**：题面保证，因此不会出现「相等时挂左还是挂右」的歧义。

## 5. 正确性证明

记 `Construct(x)` 为题目定义的构造过程：取 $x$ 的最大值（下标 $m$）为根，左子树 `Construct(x[0..m-1])`，右子树 `Construct(x[m+1..])`。

**引理 1（中序还原）**：`Construct(a)` 的中序遍历结果恰为 $a$。

**证明**：对数组长度归纳。长度为 0 时为空。设根取 $a[m]$，按中序「左—根—右」遍历，先得 `Construct(a[0..m-1])` 的中序即 $a[0..m-1]$（归纳假设），再得 $a[m]$，最后得 $a[m+1..]$，拼接即 $a$。∎

**引理 2（根是最大值，前缀/后缀划分子树）**：设 `root = Construct(a)`，最大值下标为 $m$，则 `root.left = Construct(a[0..m-1])`、`root.right = Construct(a[m+1..])`。

**证明**：直接来自 `Construct` 的定义。∎

**引理 3（末尾元素的位置）**：设 `root = Construct(a)`，$b = a \cdot [val]$。若 $val > root.val$，则 `Construct(b)` 的根为 $val$，其左子树为 `root`；若 $val < root.val$，则 `Construct(b)` 与 `Construct(a)` 有相同的根，且其右子树为 `Construct(a[m+1..] \cdot [val])`。

**证明**：$b$ 的最大值：若 $val > root.val$，则最大值为 $val$，位置在末尾 $|a|$，故左子树为 `Construct(b[0..|a|-1]) = Construct(a) = root`，右子树为空。若 $val < root.val$，最大值仍为 $a[m]$，位置不变；$b$ 中 $a[m]$ 右侧的部分是 $a[m+1..] \cdot [val]$，故右子树为 `Construct(a[m+1..] \cdot [val])`，左子树与根均不变。∎

**定理**：`insertIntoMaxTree(root, val)` 返回的树恰为 `Construct(b)`。

**证明**：对右链长度（即递归层数）归纳，结合引理 3。设当前 `root = Construct(a)` 且待插入的 $val$ 追加在 $a$ 末尾：

- 若 `root == null`，对应 $a$ 为空，则 $b = [val]$，`Construct(b)` 就是单结点 `TreeNode(val)`，与代码一致。
- 若 $val > root.val$，由引理 3 第一种情形，结果应为「根 $val$、左子树 `root`」，与代码一致。
- 若 $val < root.val$，由引理 3 第二种情形，结果的根与左子树不变，右子树就是「把 $val$ 插入 `root.right` 对应的数组末尾」，正是递归调用的语义；由归纳假设递归返回正确结果。

三种情形覆盖全部输入，归纳成立。∎

## 6. 复杂度分析

- **时间**：$O(h)$，$h$ 为树高。每层只做一次比较并决定是否继续向右，最多走到最右叶。最坏（链状树）$O(n)$，平均 $O(\log n)$。
- **空间**：$O(h)$ 递归栈；新建结点 1 个。树本身是原地修改，不复制。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    TreeNode* insertIntoMaxTree(TreeNode* root, int val) {
        if (!root) return new TreeNode(val);
        if (val > root->val) {
            TreeNode* node = new TreeNode(val);
            node->left = root;
            return node;
        }
        root->right = insertIntoMaxTree(root->right, val);
        return root;
    }
};
```

### Python

```python
class Solution:
    def insertIntoMaxTree(self, root, val: int):
        if root is None:
            return TreeNode(val)
        if val > root.val:
            node = TreeNode(val)
            node.left = root
            return node
        root.right = self.insertIntoMaxTree(root.right, val)
        return root
```

## 8. 边界情况与易错点

1. **`val` 大于根**：新根 + 旧树作左子，别把旧树挂到右边（示例 1）。
2. **`val` 最小**：会一路走到最右叶的右子位置，触发 `root == null` 分支；漏了这个分支会空指针。
3. **只走右链**：误改成同时考虑左右子树（例如比较大小后往左走）会破坏最大树性质。
4. **不要重建整棵树**：虽然 $n \le 100$ 时重建也能过，但会丢失「增量修改」的题意。
5. **值重复**：题面保证互不相同；若允许重复，「等于」时挂哪边需要额外约定。
6. **修改原树**：函数会就地挂接 `root.right`，若调用方还要用原树需先深拷贝（本题不需要）。
7. **返回根**：新根情形要返回新建的 `node`，其余情形返回原 `root`，别漏掉 `return`。
