# LeetCode 网格照明 题解

## 1. 题目概述

- **标题 / 题号**：网格照明（#1001，hard）
- **链接**：https://leetcode.cn/problems/grid-illumination/
- **来源**：LeetCode 第 125 场周赛 Q4
- **难度**：困难
- **标签**：数组、哈希表

**题意**：有一个 $n \times n$ 的网格，每格一盏灯，初始全灭。给定 `lamps`（要打开的灯的位置，同一位置可能重复列出，重复不影响状态）与 `queries`。一盏亮着的灯会照亮**自身**以及同一**行**、同一**列**、两条**对角线**上的所有格子。对每个查询 $(r, c)$：若该格被照亮返回 $1$，否则返回 $0$；随后**关闭**该格及其周围 $8$ 邻域（共 $3 \times 3$）内所有亮着的灯。

**约束**：

- $1 \le n \le 10^9$
- $0 \le lamps.length, queries.length \le 2 \times 10^4$
- $0 \le row_i, col_i < n$

> 💡 $n$ 高达 $10^9$，**不可能**开 $n \times n$ 的网格；但灯最多 $2 \times 10^4$ 盏，所以只能围绕「灯」而不是「格子」做文章。

## 2. 示例

**示例 1**

```text
输入：n = 5, lamps = [[0,0],[4,4]], queries = [[1,1],[1,0]]
输出：[1,0]
解释：(1,1) 与 (0,0) 在同一条主对角线上，被照亮；随后关掉 (0,0) 等邻域的灯，
      (1,0) 不再被照亮。
```

**示例 2**

```text
输入：n = 5, lamps = [[0,0],[4,4]], queries = [[1,1],[1,1]]
输出：[1,1]
解释：两次查询同一格；第一次关灯后 (4,4) 那盏仍亮着（距离 3，不在 3×3 内）。
```

**示例 3**

```text
输入：n = 5, lamps = [[0,0],[0,4]], queries = [[0,4],[0,1],[1,4]]
输出：[1,1,0]
解释：查询 (0,4) 自身是灯 → 1，随后它被关掉；(0,1) 仍被 (0,0) 照亮 → 1，
      但 (0,0) 在 (0,1) 的 3×3 邻域内被关掉；(1,4) 于是变暗 → 0。
```

## 3. 解题思路

### 3.1 暴力思路

开一个 $n \times n$ 的布尔网格，为每盏灯把它所在的整行、整列、两条对角线全部标记为照亮；每次查询 $O(n)$ 判断，再清空 $3 \times 3$ 邻域的灯并反向取消照亮。时间 $O(L n + Q n)$、空间 $O(n^2)$，在 $n = 10^9$ 下彻底不可行。即使只存「被照亮的格子」，数量也高达 $O(Ln)$。

### 3.2 核心观察：一盏灯只影响「四条线」

![一盏灯照亮四族直线](images/wc125_q4_four_families.svg)

格子 $(r, c)$ 被照亮，当且仅当存在一盏亮着的灯 $(r', c')$ 满足

$$r' = r \quad \text{或}\quad c' = c \quad \text{或}\quad r' - c' = r - c \quad \text{或}\quad r' + c' = r + c .$$

四种情形分别对应「同一行」「同一列」「同一条主对角线」「同一条副对角线」（含灯自身，因为 $r'=r$ 且 $c'=c$ 时前两条成立）。

因此不需要「照亮哪些格子」，只需要知道**每条线有没有灯**。用四个哈希表统计：

$$\text{row}[r],\ \text{col}[c],\ \text{diag}[r-c],\ \text{anti}[r+c]$$

即「该行/列/对角线上的灯数」。查询 $(r,c)$ 时，只要这四个值有一个 $> 0$ 就返回 1。

**为什么用计数而不是布尔**？因为一条线上可能有多盏灯，关掉一盏不能让整条线变暗，必须记录数量，减到 0 才表示这条线真的没有灯了。

### 3.3 算法流程

![四个计数器 + 灯集合](images/wc125_q4_counters.svg)

```text
1. 建表：对每盏灯 (r, c)（去重后）
       row[r]++，col[c]++，diag[r-c]++，anti[r+c]++，并把 (r,c) 放入灯集合
2. 对每个查询 (r, c)：
       ans 追加 [row[r] > 0 或 col[c] > 0 或 diag[r-c] > 0 或 anti[r+c] > 0]
       对 3×3 邻域内的每格 (nr, nc)：
           若 (nr, nc) 在灯集合中：
               从灯集合删除
               row[nr]--，col[nc]--，diag[nr-nc]--，anti[nr+nc]--
3. 返回 ans
```

**关键点**：关灯时**先查灯集合**，只有确实是灯才做减一；不是灯的格子什么都不用做。

### 3.4 示例演算

![示例 1 的两次查询](images/wc125_q4_walkthrough.svg)

对 $n = 5$、`lamps = [[0,0],[4,4]]`：

| 查询 | 判定 | 结果 | 关灯动作 |
|------|------|------|----------|
| $(1,1)$ | $\text{diag}[1-1=0] = 1$（灯 $(0,0)$ 在对角线上） | 1 | $(0,0)$ 在 3×3 内 → 关闭，四个计数器各减一 |
| $(1,0)$ | $\text{row}[1]=0$、$\text{col}[0]=0$（灯已关）、$\text{diag}[1]=0$、$\text{anti}[1]=0$ | 0 | $(4,4)$ 距离 3，不在邻域内 |

答案 $[1,0]$。第二盏灯 $(4,4)$ 始终没被关掉，但它所在的四条线都离 $(1,0)$ 很远，所以不影响结果。

## 4. 算法细节

1. **灯去重**：`lamps` 中同一位置可能重复出现，重复的灯只算一盏（否则计数器会虚高，关灯后仍 $>0$）。
2. **坐标压缩成键**：C++ 用 `r * n + c` 作为 `long long` 键，$r, c < n \le 10^9$ 时最大约 $10^{18}$，正好在 `long long` 范围内；也可以直接用 `(r, c)` 二元组。
3. **计数器可清零删除**：C++ 版在计数减到 0 时 `erase`，既省内存也避免哈希表无限膨胀（不删也正确，只是浪费空间）。
4. **3×3 邻域要判越界**：$nr, nc$ 必须满足 $0 \le nr, nc < n$，否则会去删不存在的灯（虽然查不到，但越界键本身无害，判一下更严谨）。
5. **顺序**：先回答问题，再关灯——题面明确「在第 j 次查询之后」关灯。
6. **同一查询重复**：如示例 2，两次查询都返回 1，因为第二次判定发生在关灯之前、且相关灯没被关掉。
7. **灯自身也照亮自己**：灯所在格属于「同一行」，`row[r] > 0` 即可覆盖，不需要额外特判。

## 5. 正确性证明

固定灯泡集合 $S$（当前亮着的灯）。定义 $L(r,c) \equiv$ 格子 $(r,c)$ 被照亮。

**引理 1（照亮判定）**：$L(r,c)$ 成立当且仅当存在 $(r',c') \in S$ 使得 $r'=r$ 或 $c'=c$ 或 $r'-c'=r-c$ 或 $r'+c'=r+c$。

**证明**：灯光沿四个方向传播：同一行的格子 $r'=r$；同一列的 $c'=c$；主对角线（左上—右下）上 $r-c$ 恒等；副对角线（右上—左下）上 $r+c$ 恒等。灯照亮的正是这四条线的并集（含自身，因自身同时满足 $r'=r$）。故充要。∎

**引理 2（计数器不变式）**：任意时刻，$\text{row}[r]$ 等于 $S$ 中第 $r$ 行的灯数，$\text{col}[c]$、$\text{diag}[d]$、$\text{anti}[s]$ 同理，分别等于 $S$ 中列号为 $c$、$r-c=d$、$r+c=s$ 的灯数。

**证明**：初始建表时，对每个 $(r,c) \in S$ 各加一次，且重复位置已去重，故四个计数分别等于对应集合的大小。开灯不再发生；关灯时对每个被删除的 $(r,c) \in S$ 恰好做一次四个减一，且同一盏灯只会被删除一次（删后即从 `S` 中移除），故不变式保持。∎

**引理 3（查询判定正确）**：算法对查询 $(r,c)$ 的返回值等于 $L(r,c)$ 的指示。

**证明**：由引理 2，`row[r] > 0` $\iff$ 存在灯 $(r', c')$ 满足 $r' = r$，其余三项同理。四个条件之或正好是引理 1 的右端，故返回值等于 $L(r,c)$。∎

**引理 4（关灯正确）**：算法关闭的灯集合恰为 $S \cap \{(r+dr, c+dc) : dr, dc \in \{-1,0,1\}\}$。

**证明**：算法遍历 3×3 邻域中的每格，仅当它属于灯集合 $S$ 时删除，否则跳过；因此被删除的恰是邻域内属于 $S$ 的灯，不多不少。∎

**定理**：算法返回的数组恰为题面要求的答案。

**证明**：对查询次数归纳。第 0 次查询前，引理 2 保证四个计数器与初始灯集一致。设第 $k$ 次查询前计数器正确，由引理 3 该次返回值正确；由引理 4，关灯后灯集变为「原灯集减去 3×3 邻域内的灯」，再由引理 2，计数器随之正确更新。归纳成立，全部查询结果正确。∎

## 6. 复杂度分析

- **时间**：$O(L + 9Q)$ 次哈希操作（期望 $O(1)$ 每次）。建表遍历 $L$ 盏灯；每次查询做 4 次查表 + 至多 9 次「查灯集合 + 删灯」，每次删灯再做 4 次减一。总计 $O(L + Q)$，与 $n$ 无关。
- **空间**：$O(L)$。四个哈希表最多各存 $L$ 项，灯集合存 $L$ 项；与 $n$ 无关，这正是能处理 $n = 10^9$ 的原因。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> gridIllumination(int n, vector<vector<int>>& lamps, vector<vector<int>>& queries) {
        unordered_map<long long, int> rows, cols, diag, anti;
        unordered_set<long long> lampSet;
        for (const auto& l : lamps) {
            long long r = l[0], c = l[1];
            long long key = r * (long long)n + c;
            if (lampSet.count(key)) continue;
            lampSet.insert(key);
            rows[r]++;
            cols[c]++;
            diag[r - c]++;
            anti[r + c]++;
        }
        vector<int> ans;
        ans.reserve(queries.size());
        for (const auto& q : queries) {
            long long r = q[0], c = q[1];
            bool lit = rows[r] > 0 || cols[c] > 0 || diag[r - c] > 0 || anti[r + c] > 0;
            ans.push_back(lit ? 1 : 0);
            for (int dr = -1; dr <= 1; dr++) {
                for (int dc = -1; dc <= 1; dc++) {
                    long long nr = r + dr, nc = c + dc;
                    if (nr < 0 || nr >= n || nc < 0 || nc >= n) continue;
                    long long key = nr * (long long)n + nc;
                    auto it = lampSet.find(key);
                    if (it == lampSet.end()) continue;
                    lampSet.erase(it);
                    if (--rows[nr] == 0) rows.erase(nr);
                    if (--cols[nc] == 0) cols.erase(nc);
                    if (--diag[nr - nc] == 0) diag.erase(nr - nc);
                    if (--anti[nr + nc] == 0) anti.erase(nr + nc);
                }
            }
        }
        return ans;
    }
};
```

### Python

```python
from collections import defaultdict


class Solution:
    def gridIllumination(self, n: int, lamps: list[list[int]], queries: list[list[int]]) -> list[int]:
        rows = defaultdict(int)
        cols = defaultdict(int)
        diag = defaultdict(int)
        anti = defaultdict(int)
        lamp_set = set()
        for r, c in lamps:
            if (r, c) in lamp_set:
                continue
            lamp_set.add((r, c))
            rows[r] += 1
            cols[c] += 1
            diag[r - c] += 1
            anti[r + c] += 1
        ans = []
        for r, c in queries:
            lit = rows[r] > 0 or cols[c] > 0 or diag[r - c] > 0 or anti[r + c] > 0
            ans.append(1 if lit else 0)
            for dr in (-1, 0, 1):
                for dc in (-1, 0, 1):
                    p = (r + dr, c + dc)
                    if p in lamp_set:
                        lamp_set.remove(p)
                        pr, pc = p
                        rows[pr] -= 1
                        cols[pc] -= 1
                        diag[pr - pc] -= 1
                        anti[pr + pc] -= 1
        return ans
```

## 8. 边界情况与易错点

1. **`lamps` 重复位置**：不去重会让计数器偏大，关灯后仍显示「有灯」，答案错误。
2. **`n` 很大**：任何 $O(n)$ 或 $O(n^2)$ 的做法都会爆；键必须用 `long long`（$r \cdot n + c$ 可达 $10^{18}$，`int` 溢出）。
3. **先判定后关灯**：顺序反了会把本次查询自己的灯先关掉，示例 3 的第一次查询就会返回 0。
4. **只关邻域内的灯**：不要清空整行/整列的灯，示例 2 就是靠「(4,4) 距离 3 未被关」才两次都返回 1。
5. **不用 visited**：灯集合本身就是判重结构，不需要额外数组。
6. **对角线编号**：$r-c$ 可能为负，用整数做键没问题；不要错误地加上偏移量或取绝对值（取绝对值会把两条不同对角线合并）。
7. **空输入**：`lamps` 或 `queries` 为空时，循环自然不执行，返回空数组。
8. **减到 0 的处理**：C++ 版 `erase` 掉 0 值项是优化，不 erase 也正确；但要保证减一操作只在「确实是灯」时执行，否则会出现负数计数。
