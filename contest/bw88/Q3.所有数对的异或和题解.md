# LeetCode 所有数对的异或和 题解

> 💡 本题在本仓库另有[每日题解 2425](../../solution/2401-2500/2425_所有数对的异或和.md)。本篇按**周赛复盘视角**展开：配对矩阵的展开推导、奇偶抵消的引理–定理证明链，以及「乘反了」「单元素数组」等赛时易错清单。

## 1. 题目概述

- **标题 / 题号**：所有数对的异或和（#2425，medium）
- **链接**：https://leetcode.cn/problems/bitwise-xor-of-all-pairings/
- **来源**：LeetCode 第 88 场双周赛 Q3
- **难度**：中等
- **标签**：位运算、脑筋急转弯、数组

**题意**：给定两个非负整数数组 `nums1`（长 $n_1$）与 `nums2`（长 $n_2$）。构造数组 `nums3`，它包含 `nums1` 中每个整数与 `nums2` 中每个整数**恰好配对一次**的全部 $n_1 \cdot n_2$ 个异或和。返回 `nums3` 中所有整数的**异或和**。

**约束**：

- $1 \le \text{nums1.length}, \text{nums2.length} \le 10^5$
- $0 \le \text{nums1}[i], \text{nums2}[j] \le 10^9$

## 2. 示例

**示例 1**

```text
输入：nums1 = [2,1,3], nums2 = [10,2,5,0]
输出：13
解释：nums3 有 3 × 4 = 12 个元素（如 [8,0,7,2,11,3,4,1,9,1,6,3]），
      全部异或起来是 13。
```

**示例 2**

```text
输入：nums1 = [1,2], nums2 = [3,4]
输出：0
解释：四个数对异或为 2, 5, 1, 6；2 ⊕ 5 ⊕ 1 ⊕ 6 = 0。
```

## 3. 解题思路

### 3.1 暴力思路

双重循环把 $n_1 \cdot n_2$ 个 $a \oplus b$ 全部异或——总量最高 $10^{10}$，时间和（若真存下 nums3）空间都爆。一眼就该意识到：**求的是异或和，而异或对「重复出现」极其敏感**——任何出现偶数次的值都会自我湮灭，根本不需要真的展开。

### 3.2 核心观察：配对矩阵里，每个数出现的次数只由「对面长度」决定

![m×n配对矩阵：每个数到底出现几次](images/bw88_q3_pairing_grid.svg)

把数对摆成 $n_1 \times n_2$ 的矩阵：第 $i$ 行第 $j$ 列是 $\text{nums1}[i] \oplus \text{nums2}[j]$。逐行摊平来看：

- 每个 $\text{nums1}[i]$ 与 `nums2` 的**每个**元素各配一次 → 它（作为「加数」）总共出现 $n_2$ 次；
- 每个 $\text{nums2}[j]$ 与 `nums1` 的**每个**元素各配一次 → 它总共出现 $n_1$ 次。

于是整批数对的异或和完全由 $n_1, n_2$ 的**奇偶性**决定：出现偶数次的一律抵消，出现奇数次的一律只留一个。

### 3.3 奇偶抵消与最终公式

![成对抵消：偶数次出现等于没出现](images/bw88_q3_cancel_pairs.svg)

利用异或的交换律、结合律与自反律 $x \oplus x = 0$：

- 若 $n_2$ 为**偶数**：每个 $\text{nums1}[i]$ 出现偶数次，整组自我抵消；为**奇数**时全部保留，等价于贡献 $\bigoplus_i \text{nums1}[i]$；
- 若 $n_1$ 为**偶数**：$\text{nums2}$ 整组抵消；为**奇数**时贡献 $\bigoplus_j \text{nums2}[j]$。

记 $x_1 = \bigoplus_i \text{nums1}[i]$、$x_2 = \bigoplus_j \text{nums2}[j]$，用 Iverson 括号 $[P]$（条件 $P$ 成立取 $1$，否则取 $0$）把两种情形写成一条式子：
$$\text{answer} = x_1 \cdot [\,n_2 \text{ 为奇数}\,] \;\oplus\; x_2 \cdot [\,n_1 \text{ 为奇数}\,]\text{。}$$

先各花 $O(n_1 + n_2)$ 求出两个数组的异或和 `x1`、`x2`，再按两个长度的奇偶拼装即可。

> ⚠️ 最容易翻车的记法是「谁乘谁」：$\text{nums1}[i]$ 的出现次数是**对面** `nums2` 的长度 $n_2$。写成 `if n1 % 2: ans ^= x1` 就正好乘反——例 1 会得到 `x2` 没贡献的错误结果 0。

### 3.4 示例演算

![示例演算：奇偶组合的四种情形](images/bw88_q3_example_walkthrough.svg)

**示例 1**：$n_1 = 3$（奇），$n_2 = 4$（偶）。`x1 = 2⊕1⊕3 = 0`，`x2 = 10⊕2⊕5⊕0 = 13`。$n_2$ 偶 → nums1 整组抵消；$n_1$ 奇 → 答案含 `x2`。answer $= 0 \oplus 13 = 13$ ✓。

**示例 2**：$n_1 = n_2 = 2$（双偶）。两组全部成对抵消，answer $= 0$ ✓。

## 4. 算法细节

1. **两个前缀异或一遍算**：`x1`、`x2` 各一次线性扫描，别想着边扫边判断奇偶——先算好再装配，逻辑分层不易错。
2. **奇偶判断放在「长度」上**：`len(nums2) & 1` 决定 `x1` 去留，`len(nums1) & 1` 决定 `x2` 去留。**对面长度**控制本组命运，这条要在写代码前默念一遍。
3. **$0$ 元素无害**：$x \oplus 0 = x$，值为 0 的元素参与抵消与否都不影响结果，无需特判。
4. **溢出**：所有值 $\le 10^9 < 2^{30}$，异或结果仍在该量级，C++ `int` 足够（Python 无此虑）。
5. **复杂度已经最优**：读入就要 $O(n_1 + n_2)$，本解法一次扫描即出答案，没有任何多余常数。

## 5. 正确性证明

**引理 1（重排自由）**：有限多个整数的总异或与它们书写的顺序无关；且 $x \oplus x = 0$、$0 \oplus y = y$。

**证明**：异或按位是模 2 加法，交换律与结合律继承自整数加法；$x \oplus x$ 每一位要么 $0\oplus0$ 要么 $1\oplus1$，均为 0；$0 \oplus y$ 逐位等于 $y$。∎

**引理 2（偶次湮灭）**：在总异或中，任何出现偶数次的值可以整组删去；出现奇数次的一组等价于出现一次。

**证明**：由引理 1 任意重排，把同值元素排成相邻，两两配对为 $x \oplus x = 0$，偶数个清零、奇数个剩一个。∎

**定理**：`nums3` 全体元素的异或和等于 $(n_2$ 为奇数 ? $\bigoplus \text{nums1}$ : $0) \oplus (n_1$ 为奇数 ? $\bigoplus \text{nums2}$ : $0)$。

**证明**：`nums3` 的总异或按行分组展开：
$$\bigoplus_{i=1}^{n_1} \underbrace{\bigoplus_{j=1}^{n_2} \bigl(\text{nums1}[i] \oplus \text{nums2}[j]\bigr)}_{\text{第 } i \text{ 行}}\text{。}$$
固定 $i$：由引理 1 任意重排第 $i$ 行，把 $\text{nums1}[i]$ 的 $n_2$ 个副本聚在一起、把各 $\text{nums2}[j]$ 聚在一起，得
$$\text{第 } i \text{ 行} = \underbrace{(\text{nums1}[i] \oplus \cdots \oplus \text{nums1}[i])}_{n_2 \text{ 个}} \oplus \text{x2}\text{，}$$
其中第一个括号由引理 2 化为「$n_2$ 奇时保留 $\text{nums1}[i]$，偶时湮灭」。再把 $n_1$ 行合起来：每个 $\text{nums1}[i]$ 在全部行里**总共**出现 $n_2$ 次（只在自己那行出现），故全体 nums1 元素合并后恰是「$n_2$ 奇 ? $\bigoplus \text{nums1}$ : 0」；而 $\text{x2}$ 每行出现一次、共 $n_1$ 次，由引理 2 是「$n_1$ 奇 ? $\text{x2}$ : 0」。两项异或即得公式。∎

## 6. 复杂度分析

- **时间**：$O(n_1 + n_2)$——两次线性扫描求 `x1`、`x2`，常数次奇偶判断与异或。
- **空间**：$O(1)$ 额外——两个累加变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int xorAllNums(vector<int>& nums1, vector<int>& nums2) {
        int n = (int)nums1.size(), m = (int)nums2.size();
        int x1 = 0, x2 = 0;
        for (int v : nums1) x1 ^= v;
        for (int v : nums2) x2 ^= v;
        return ((m & 1) ? x1 : 0) ^ ((n & 1) ? x2 : 0);
    }
};
```

### Python

```python
class Solution:
    def xorAllNums(self, nums1: list[int], nums2: list[int]) -> int:
        x1 = x2 = 0
        for v in nums1:
            x1 ^= v
        for v in nums2:
            x2 ^= v
        ans = 0
        if len(nums2) & 1:              # nums2 长度为奇数才保留 nums1 的异或和
            ans ^= x1
        if len(nums1) & 1:
            ans ^= x2
        return ans
```

> 💡 两份代码均通过官方示例（`13`、`0`），并与「真的双重循环展开 $n_1 \cdot n_2$ 个数对」的暴力实现做了 2 万组（C++）/ 3 千组（Python）随机对拍（长度 $1 \sim 60$，值域 $[0, 65535]$，覆盖全部四种奇偶组合），`mismatch = 0`。

## 8. 边界情况与易错点

1. **奇偶条件乘反**：$\text{nums1}$ 的异或和 `x1` 由 `len(nums2)` 的奇偶决定（它出现 $n_2$ 次）。把条件写成 `len(nums1) & 1` 才保留 `x1` 是最高频错误，例 1 会从 13 错成 0。
2. **单元素数组**：$n_1 = 1$ 时答案必含 `x2`（$n_1$ 奇）；$n_2 = 1$ 时必含 `x1`。极端情形 `nums1 = [0], nums2 = [0]` → 答案 0。
3. **双偶直接 0**：两个长度都是偶数时答案恒为 0——可以直接短路返回，也可走通用公式（等价）。
4. **别把「数对和」当「和」**：`nums3` 的元素是 $\text{nums1}[i] \oplus \text{nums2}[j]$，先异或后聚合；不要把两数组的总异或先加起来再异或。
5. **移位写法**：`(m & 1) ? x1 : 0` 的三元写法在 C++ 里注意括号；Python 的 `if ... & 1` 两段判断更可读。
6. **大小写类型**：值域 $< 2^{30}$，C++ `int` 即可，但养成把「异或累加器」直接声明成输入元素类型的习惯，题目一改值域也不炸。
