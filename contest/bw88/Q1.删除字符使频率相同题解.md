# LeetCode 删除字符使频率相同 题解

## 1. 题目概述

- **标题 / 题号**：删除字符使频率相同（#2423，easy）
- **链接**：https://leetcode.cn/problems/remove-letter-to-equalize-frequency/
- **来源**：LeetCode 第 88 场双周赛 Q1
- **难度**：简单
- **标签**：哈希表、字符串、计数

**题意**：给定只含小写字母的字符串 `word`，必须**恰好选择一个下标并删除该处字符**。若删除后剩余每个字母的出现频率全部相同，返回 `true`，否则 `false`。

**约束**：

- $2 \le \text{word.length} \le 100$
- `word` 只包含小写英文字母

## 2. 示例

**示例 1**

```text
输入：word = "abcc"
输出：true
解释：删掉下标 3 的 c，得 "abc"，每个字母频率都是 1。
```

**示例 2**

```text
输入：word = "aazz"
输出：false
解释：删 a 剩 {a:1, z:2}，删 z 剩 {a:2, z:1}，都不相等。
```

**示例 3（边界补充）**

```text
输入：word = "cccd"
输出：true
解释：删掉唯一的 d，只剩 c:3 一种字母——"全部相同"成立。
```

## 3. 解题思路

### 3.1 暴力思路

对每个下标 $i$，真的把字符抠掉、重新统计 $O(n)$ 遍频率、再 $O(26)$ 检查是否全等，总 $O(n^2)$。$n \le 100$ 当然能过，但这个暴力把「删哪个下标」当成决策点——其实**同一字母的任意一次出现完全等价**，真正要枚举的决策是「删哪个**字母**的一个出现」，至多 26 种。

### 3.2 核心观察：26 个频率桶，逐字母试删一个

![26个频率桶：枚举删哪个字母的一个出现](images/bw88_q1_try_delete.svg)

先花 $O(n)$ 统计 26 个桶的频率 `freq[0..25]`。然后对每个**非空**字母 $c$：把 `freq[c]` 减一（模拟删掉它的一个出现），检查剩余的**非零**频率是否只剩一个不同取值；可行立即返回 `true`，否则恢复 `freq[c]` 继续试。26 次尝试 × 每次 $O(26)$ 检查，常数极小。

> ⚠️ 「删除后全部频率相同」的准确判据是：**非零**频率的取值集合大小 $\le 1$。只剩一种字母（如删掉 `"cccd"` 的 `d`）当然算相同；而频率 0 的桶不参与比较——如果把 0 也算进去，`{a:1, b:0, c:0, ...}` 会被误判为「频率有 1 和 0 两种」。

### 3.3 算法流程

```text
1. freq[26] = {0}；统计 word 中每个字母的出现次数
2. for c in 0..25:
       若 freq[c] == 0：跳过（没得删）
       freq[c] -= 1                    # 模拟删除一个字母 c
       检查：非零频率的取值是否唯一
       若唯一：返回 true
       freq[c] += 1                    # 恢复，试下一个字母
3. 返回 false
```

### 3.4 示例演算

![示例演算：true 与 false 各是什么样子](images/bw88_q1_example_walkthrough.svg)

**`"abcc"`**：`{a:1, b:1, c:2}`。删 a → `{1, 2}` ✗；删 b → `{1, 2}` ✗；删 c → `{1, 1}` ✓，返回 `true`。

**`"aazz"`**：`{a:2, z:2}`。删 a → `{1, 2}` ✗；删 z → `{2, 1}` ✗，返回 `false`。

**`"cccd"`**：`{c:3, d:1}`。删 c → `{2, 1}` ✗；删 d → `{3}`（唯一非零取值）✓，返回 `true`。

## 4. 算法细节

1. **枚举字母而非下标**：删除同一字母的任意一个出现，剩余频率向量完全相同——26 种选择覆盖了全部 $n$ 种下标选择，把 $O(n^2)$ 暴力降到 $O(n + 26^2)$。
2. **检查函数**：遍历 26 个桶，记录第一个非零值 `ref`；再遇到不同的非零值即失败。「非零值集合大小 ≤ 1」的等价实现，不需要排序或哈希集合（Python 里 `{x for x in freq if x > 0}` 一行也行）。
3. **恢复现场**：`freq[c] += 1` 别忘——下一次尝试要在原始频率上进行。也可以复制数组，$26 \times 26$ 的量级怎么写都行，但原地加减最省事也最快。
4. **必须恰好删一个**：即使原字符串频率已经全部相同（如 `"aabb"`），也**必须**删一个再看（`"aabb"` 删谁都是 `{1,2}`，返回 `false`）；不能因为「本来就相同」直接返回 `true`。
5. **复杂度上界**：$n \le 100$，但解法对 $n \le 10^6$ 同样线性可过，套路不受数据范围约束。

## 5. 正确性证明

**引理（下标枚举 ⟺ 字母枚举）**：删除下标 $i$ 后剩余频率全等，当且仅当删除「字母 $\text{word}[i]$」一次后剩余频率全等（在原始频率向量上减一）。

**证明**：删除下标 $i$ 仅使 `freq[word[i]]` 减一，与删掉该字母的任何其他出现得到的结果相同；剩余字符串的字母多重集完全一致，频率向量也一致。∎

**定理（算法正确）**：算法返回 `true` 当且仅当存在一个合法删除使剩余所有字母频率相同。

**证明**：（充分性）算法只在「删某个非空字母一次后非零频率取值唯一」时返回 `true`，由频率向量与实际删除的等价性（引理），对应一个合法删除。（必要性）若存在合法删除，设删的字母为 $c$，则 `freq[c] ≥ 1`，算法迭代到 $c$ 时计算的正是该删除后的频率向量，检查必通过并返回 `true`（即使提前在别的字母处返回，也同样是 `true`）。∎

## 6. 复杂度分析

- **时间**：$O(n + 26^2)$——统计一遍 + 26 次尝试、每次 $O(26)$ 检查；$n = 100$ 时几乎为零。
- **空间**：$O(26)$——频率数组，常数。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool equalFrequency(string word) {
        int freq[26] = {0};
        for (char c : word) ++freq[c - 'a'];
        for (int c = 0; c < 26; ++c) {
            if (freq[c] == 0) continue;
            --freq[c];                       // 模拟删除一个字母 c
            int ref = 0;
            bool ok = true;                  // 剩余非零频率是否全相等
            for (int x : freq)
                if (x > 0) {
                    if (ref == 0) ref = x;
                    else if (x != ref) ok = false;
                }
            if (ok) return true;
            ++freq[c];                       // 恢复
        }
        return false;
    }
};
```

### Python

```python
class Solution:
    def equalFrequency(self, word: str) -> bool:
        freq = [0] * 26
        for c in word:
            freq[ord(c) - 97] += 1
        for c in range(26):
            if freq[c] == 0:
                continue
            freq[c] -= 1                     # 模拟删掉一个字母 c
            values = {x for x in freq if x > 0}
            if len(values) <= 1:             # 只剩一种频率
                return True
            freq[c] += 1                     # 恢复
        return False
```

> 💡 两份代码均通过官方示例（`true`、`false`）与手工边界（`"aa"`、`"ab"`、`"aabbcc"`、`"cccd"` 等），并与「逐下标真实删除 + 重新统计」的暴力实现做了 **20 万组（C++）/ 4 万组（Python）** 随机对拍（长度 $2 \sim 13$、字母表 $1 \sim 26$），`mismatch = 0`。

## 8. 边界情况与易错点

1. **必须删且只删一个**：`"aabb"` 本身频率全等，但删一个后变成 `{1,2}`，答案是 `false`——「不删也行」是错误读题。
2. **只剩一种字母也算相同**：`"dd"`、`"cccd"`（删 d 后只剩 c）都是 `true`；判据是「非零频率取值唯一」，不是「至少两种字母」。
3. **频率 0 不参与比较**：检查时只看非零桶，否则任何答案都会被 0 干扰成 `false`。
4. **别只检查「最大频率减一后等于其余」这类单次判断**：诸如「排序后看频次向量是否形如 `k,k,...,k,k+1`」的判法容易漏掉「只剩一种字母」的分支；枚举字母 + 完整检查最防呆。
5. **恢复现场**：试删失败后 `freq[c] += 1`，否则后续尝试基于错误状态。
6. **空桶跳过**：`freq[c] == 0` 时不能减成 $-1$——不仅语义错，还会让「非零」判断把负值漏掉或误伤。
