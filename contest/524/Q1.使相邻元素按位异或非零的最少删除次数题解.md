# LeetCode 使相邻元素按位异或非零的最少删除次数 题解

## 1. 题目概述

- **标题 / 题号**：使相邻元素按位异或非零的最少删除次数（#4083，easy）
- **链接**：https://leetcode.cn/problems/minimum-deletions-to-make-array-sharp/
- **来源**：LeetCode 第 524 场周赛 Q1
- **难度**：简单
- **标签**：位运算、贪心、数组

**题意**：给定整数数组 `nums`，可以删除任意多个元素，剩余元素保持原有相对顺序。若结果数组中**每对相邻元素**的按位异或都不为 0（长度不超过 1 的数组直接视为合法），则称其为「相邻异或非零数组」。求最少删除多少个元素。

**约束**：

- $2 \le nums.length \le 100$
- $1 \le nums[i] \le 100$

## 2. 示例

**示例 1**

```text
输入：nums = [1,1,2,2,2,3]
输出：3
解释：删除一个 1 和两个 2，得到 [1,2,3]，
      相邻异或 1⊕2=3、2⊕3=1 均非零。
```

**示例 2**

```text
输入：nums = [4,4,9,4]
输出：1
解释：删除下标 1 的 4，得到 [4,9,4]，相邻异或均非零；
      注意首尾两个 4 不相邻，无需处理。
```

**示例 3**

```text
输入：nums = [7,7,7,7]
输出：3
解释：整段相同，只保留一个 7，长度 1 的数组合法。
```

## 3. 解题思路

### 3.1 朴素思路

最直接的想法是枚举保留哪些元素：$n$ 个元素有 $2^n$ 个子集，$n \le 100$ 直接爆炸。退一步可以做 $O(n^2)$ DP——$f[i]$ 表示**以 $i$ 结尾**的最长合法保留子序列长度：

$$f[i] = 1 + \max\{f[j] : j < i,\ nums[j] \oplus nums[i] \ne 0\}$$

答案即 $n - \max_i f[i]$。$10^4$ 的转移量当然能过，但对签到题来说是杀鸡用牛刀——约束「异或非零」里藏着一个一步到位的观察。

### 3.2 核心观察：异或为零 ⟺ 两数相等

按位异或逐位比较：$x \oplus y = 0$ 当且仅当 $x$ 与 $y$ 的**每个二进制位都相同**，即 $x = y$。于是整个约束瞬间坍缩：

> **「相邻异或非零」=「相邻元素互不相等」**

异或在这里只用到这一条性质，不需要任何位运算技巧。问题变成：最少删多少个元素，使剩余数组**相邻两两不等**？

把数组切成若干**极大连续相等段**（run），例如 $[1,1,2,2,2,3]$ 切成 $[1,1]\,[2,2,2]\,[3]$ 三段。每段里元素全相等，**至多只能保留一个**；而相邻两段的值必然不同，**每段各保留一个（比如首元素）一定合法**。所以：

- 最长合法保留子序列长度 = 段数 $R$
- 最少删除次数 = $n - R = \sum_{\text{段}} (\text{段长} - 1)$ = **相邻相等对数** $\#\{i \ge 1 : nums[i] = nums[i-1]\}$

![核心观察：异或为零等价于相等](images/wc524_q1_xor_zero_insight.svg)

> 💡 一句话：**答案就是「相邻相等对」的个数**。示例 1 中 $(0,1),(2,3),(3,4)$ 三对相等，答案 3；不相邻的重复值（如 $[1,2,1]$ 里的两个 1）完全不用管。

### 3.3 算法流程

![算法流程：一遍扫描](images/wc524_q1_algorithm_flow.svg)

1. 初始化 `last = nums[0]`（保留首个元素），`ans = 0`
2. 从左到右扫描 $i = 1 \dots n-1$：
   - 若 $nums[i] = last$：该元素与本段保留元素相同，删除，`ans += 1`
   - 否则：保留，`last = nums[i]`
3. 返回 `ans`

### 3.4 示例演算

![示例演算](images/wc524_q1_example_walkthrough.svg)

- $[1,1,2,2,2,3]$：三段 $[1,1]/[2,2,2]/[3]$，删 $1+2+0 = 3$ 个 → $[1,2,3]$
- $[4,4,9,4]$：三段，删 1 个 → $[4,9,4]$，首尾两个 4 不相邻、合法共存
- $[7,7,7,7]$：一段，删 3 个只剩 $[7]$，长度 1 也合法
- $[1,2,1,2]$：没有相邻相等对，一个不删，答案是 0

## 4. 算法细节

1. **恒等式的逐位论证**：$x \oplus y$ 的第 $k$ 位为 0 ⟺ $x,y$ 的第 $k$ 位相同；所有位都相同 ⟺ $x = y$。反之 $x = y$ 时每一位异或显然为 0。这把「异或约束」完全翻译成「相等约束」。
2. **与 `last` 比较和与 $nums[i-1]$ 比较等价**：`last` 始终是当前段被保留的那个元素。若 $nums[i] \ne nums[i-1]$，说明 $nums[i]$ 开启了新段，与旧段任何元素（含 `last`）都不同；若 $nums[i] = nums[i-1]$，则仍在原段，必等于 `last`。因此贪心版与「直接统计 $nums[i] = nums[i-1]$ 的对数」答案一致，后者可写成一行：`sum(nums[i] == nums[i-1] for i in range(1, len(nums)))`。
3. **为什么每段删到只剩一个是最优**：段内任意保留两个，它们在保留子序列中必然相邻（中间原数组全是同值元素，留谁都会相邻相等），非法；而每段各留一个跨段必不等，合法。上界与下界在此汇合（严格论证见 §5）。
4. **无需真正构造删除后的数组**，也不需要双指针原地压缩（那是对齐 LC 26 的写法），一遍计数即可。

## 5. 正确性证明

**引理 1（异或恒等式）**：对任意非负整数 $x, y$：$x \oplus y = 0 \iff x = y$。

**证明**：$x \oplus y$ 的第 $k$ 个二进制位为 0 当且仅当 $x$ 与 $y$ 的第 $k$ 位相同。故 $x \oplus y = 0$ ⟺ 所有位都相同 ⟺ $x = y$。∎

**引理 2（段内上界）**：任何合法保留子序列从每个极大连续相等段中至多保留一个元素。

**证明**：反证。设某段（值为 $v$ 的连续区间）中被保留了两个下标 $i < j$。段是原数组的连续区间，$(i, j)$ 内所有下标都属于该段、值均为 $v$。取保留子序列中来自该段的元素里下标最小的两个 $k_1 < k_2$：区间 $(k_1, k_2)$ 内没有任何保留元素（否则与 $k_1, k_2$ 的最小性矛盾，因为该区间内的元素也属于该段）。于是 $k_1, k_2$ 在保留子序列中**相邻**且值相等，由引理 1 其异或为 0，与合法性矛盾。∎

**引理 3（可达性）**：每个极大连续相等段各保留首元素，得到的长度为 $R$（段数）的子序列合法。

**证明**：相邻两个段的值不同（否则可合并为一段），故保留子序列中任意相邻两个元素来自值不同的两段，即 $a[i] \ne a[i+1]$，由引理 1 异或非零。∎

**定理**：最少删除次数 $= \#\{\, i : 1 \le i < n,\ nums[i] = nums[i-1] \,\}$。

**证明**：最少删除次数 $= n - $ 最长合法保留子序列长度。由引理 2，保留长度 $\le R$；由引理 3，保留长度可达 $R$；故最长保留恰为 $R$，最少删除 $= n - R$。另一方面，设各段长为 $\ell_1, \dots, \ell_R$（$\sum \ell_j = n$），每个相邻相等对 $(i-1, i)$ 恰属于唯一一个段，且长为 $\ell$ 的段内含 $\ell - 1$ 个这样的对，故相邻相等对总数 $= \sum (\ell_j - 1) = n - R$，两式相等。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。单趟扫描，每个元素只做一次 $O(1)$ 的比较。
- **空间复杂度**：$O(1)$。仅维护 `last` 与 `ans` 两个变量。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int minDeletions(vector<int>& nums) {
        int ans = 0;
        int last = nums[0];
        for (int i = 1; i < (int)nums.size(); i++) {
            if (nums[i] == last) {
                ans++;
            } else {
                last = nums[i];
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def minDeletions(self, nums: list[int]) -> int:
        ans = 0
        last = nums[0]
        for x in nums[1:]:
            if x == last:
                ans += 1
            else:
                last = x
        return ans
```

## 8. 边界情况与易错点

1. **别做成全局去重**：答案不是 $n - |\text{distinct}(nums)|$。反例 $[1,2,1]$：去重答案算 1，实际相邻两两不等、答案是 0。只有**相邻**的相等才需要拆散。
2. **每段删 $\ell - 1$ 个，不是 $\ell$ 个**：$[7,7,7,7]$ 删 3 留 1，长度 1 的数组合法——题面明说「长度不超过 1 也被视为合法」，保留 0 个反而多删。
3. **删除会改变相邻关系**：删掉元素后，原本不相邻的元素变成邻居。代码里 `last` 永远是「当前保留子序列的末尾」，天然正确；直接数 $nums[i] = nums[i-1]$ 在本题恰好等价（见 §4.2），但要明白为什么。
4. **别被「按位异或」吓到**：本题异或的全部作用就是「$\oplus = 0 \iff$ 相等」，不需要 popcount、掩码等任何位运算技巧。
5. **无溢出风险**：$n \le 100$、值域 $[1,100]$，`int` 绰绰有余。
6. **空数组 / 单元素**：约束保证 $n \ge 2$，循环从 $i=1$ 开始也不会越界；即使 $n = 1$，代码也正确返回 0。

**延伸思考**：

- **删除改成修改**：若允许把元素改成任意新值（而非删除），使相邻两两不等，则每段长 $\ell$ 最少改 $\lfloor \ell/2 \rfloor$ 个（段内相等对构成一条链，最少点覆盖大小 $\lfloor \ell/2 \rfloor$，交替改值即达），总答案 $\sum_j \lfloor \ell_j / 2 \rfloor$；需注意改成的新值别与相邻段撞车（值域受限时要挑空闲值）。
- **约束升级**：若要求相邻异或值不仅非零、还要 $\ge k$ 或恰为 2 的幂，单指针扫描不再够用，需回到 $O(n^2)$ 或按值域状态设计的 DP。
- **去掉「保持相对顺序」**：若允许重排数组，则排序后相同值全部聚成一段，答案变为 $n - |\text{distinct}(nums)|$——对比本题，可见「保持相对顺序」这一条件的分量。
