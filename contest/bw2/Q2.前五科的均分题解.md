# LeetCode 前五科的均分 题解

## 1. 题目概述

- **标题 / 题号**：前五科的均分（#1086，easy）
- **链接**：https://leetcode.cn/problems/high-five/
- **来源**：LeetCode 第 2 场双周赛 Q2
- **难度**：简单
- **标签**：数组、哈希表、排序、堆

**题意**：给定一个成绩单列表 `items`，其中 `items[i] = [id_i, score_i]` 表示学号为 `id_i` 的学生拿到了成绩 `score_i`。每个学生**至少有 5 个成绩**。对每个学生，取其**最高的 5 个成绩**，用**整数除法**求平均；输出所有学生的 `[id, 平均分]`，且**按 id 升序**排列。

**约束**：

- $1 \le items.length \le 1000$
- `items[i].length == 2`
- $1 \le id \le 1000$
- $1 \le score \le 100$
- 每个学生至少有 5 个成绩

## 2. 示例

**示例 1**

```text
输入：items = [[1,91],[1,92],[2,93],[2,97],[1,60],[2,77],[1,65],[1,87],[1,100],[2,100],[2,76]]
输出：[[1,87],[2,88]]
解释：学生 1 的前五高为 100,92,91,87,65，和为 435，平均 87；
     学生 2 的前五高为 100,97,93,77,76，和为 443，平均 88.6，
     整数除法得 88。
```

**示例 2**

```text
输入：items = [[1,100],[7,100],[1,100],[7,100],[1,100],[7,100],[1,100],[7,100],[1,100],[7,100]]
输出：[[1,100],[7,100]]
解释：两个学生各恰有 5 个成绩且全为 100，前五高的平均都是 100；
     输出按 id 升序：1 在 7 前面。
```

## 3. 解题思路

### 3.1 暴力思路

一种朴素做法：枚举每个出现过的学生 id，**重新扫描整个 `items`** 收集其成绩再取前五——$O(U \cdot m)$（$U$ 为学生数、$m$ 为记录数），最坏 $10^6$，能过但浪费。另一种：把 `items` 整体按 `(id 升, 分数降)` 排序后顺序分组，每组取前 5——$O(m \log m)$，也能过。两种做法都没有利用「**同一条记录只属于一个学生**」这一结构：更自然的形状是**先分组、再逐组处理**。

### 3.2 核心观察：哈希分组 + 组内取前五

![核心观察：按 id 哈希分组，组内取前五](images/bw2_q2_group_by_id.svg)

两个关键观察：

1. **分组是 O(1) 路由**：每条记录 `(id, score)` 唯一归属学生 `id`，用**哈希表**（C++ `map`/`unordered_map`，Python `dict`）一趟遍历即可把 $m$ 条记录分发到各自的成绩表里——不重不漏。
2. **前五高是独立的 top-K 问题**：每个学生内部，只需要「最大的 5 个数」。规模小时**降序排序取前 5**最直接；规模大时换成**大小为 5 的小根堆**（新分数大于堆顶则替换），把每组开销从 $O(k \log k)$ 降到 $O(k \log 5)$。

最后一个输出要求是**按 id 升序**：C++ 直接用 `std::map`（有序映射，遍历即升序）；Python 用 `dict` 分组、最后 `sorted(by_id)` 遍历。

### 3.3 算法流程

![算法流程：建哈希表后逐个学生取前五平均](images/bw2_q2_algorithm_flow.svg)

```text
highFive(items):
1. byId ← 空哈希表（id → 成绩列表）
2. for (id, score) in items:            # 一趟建表
3.     byId[id].append(score)
4. ans ← 空列表
5. for id in byId 按 id 升序:            # map 有序 / sorted(by_id)
6.     scores ← byId[id] 降序排序
7.     sum ← scores[0..4] 之和           # 前 5 高（每生至少 5 个成绩）
8.     ans.append([id, sum / 5])        # 整数除法
9. 返回 ans
```

### 3.4 示例演算

![示例演算：两个学生的前五均分](images/bw2_q2_example_walkthrough.svg)

以官方示例 1 为例，分组后：

| 学生 | 原始成绩 | 降序后 | 前 5 高 | 之和 | 平均 | 计入输出 |
|------|----------|--------|---------|------|------|----------|
| 1 | 91,92,60,65,87,100 | 100,92,91,87,**65**,60 | 100,92,91,87,65 | 435 | 435/5 = 87 | `[1,87]` |
| 2 | 93,97,77,76,100 | 100,97,93,77,76 | 全部 5 个 | 443 | 443/5 = 88.6 → 88 | `[2,88]` |

两个易错点都在这组演算里：学生 1 有 **6** 个成绩，第 6 高的 60 被**挤掉**；学生 2 的 443/5 = 88.6 按**整数除法**（向零取整）得 88，而不是四舍五入的 89。

## 4. 算法细节

1. **C++ 用 `std::map<int, vector<int>>`**：既完成哈希分组，又让遍历顺序天然是 id 升序，省掉输出前的排序；`unordered_map` 则必须再对 key 排序。
2. **降序排序**：`sort(scores.begin(), scores.end(), greater<int>())`；或升序排序后取**末尾** 5 个。
3. **整数除法的语义**：`sum / 5` 在 C++ 与 `sum // 5` 在 Python 中对正数都是**向零取整**（等价于向下取整）。分数全为正，两种语言行为一致，不要误用浮点再四舍五入。
4. **堆的替代写法**：对每个学生维护一个大小为 5 的**小根堆**，堆顶是「当前前五中的守门员」；新成绩大于堆顶才替换。总复杂度 $O(m \log 5 + U \log U)$。本题 $m \le 1000$ 用不上，但数据量大或**流式输入**时是标准套路。
5. **桶的替代写法**：$1 \le id \le 1000$ 且 $1 \le score \le 100$，可以直接开 `vector<vector<int>> buckets(1001)`，避免哈希；分数值域小还可以按分数桶计数从高到低凑满 5 个，$O(m + 100)$。

## 5. 正确性证明

**引理 1（分组不重不漏）**：遍历 `items` 一趟后，`byId[id]` 恰好包含学生 `id` 的**全部**成绩，每条成绩恰出现一次。

**证明**：初始时各组为空。遍历中第 $i$ 条记录 `(id_i, score_i)` 只执行一次 `byId[id_i].append(score_i)`，且不进入任何其他组。遍历结束后，每条记录恰被其 id 对应的组收集一次；同组内不同记录是不同列表元素，故组内元素与该学生的成绩序列一一对应（顺序与 `items` 中出现顺序一致）。∎

**引理 2（前五高的正确性）**：设学生 `id` 的成绩序列降序排序后为 $b_1 \ge b_2 \ge \cdots \ge b_k$（$k \ge 5$）。则 $b_1, \dots, b_5$ 是该生成绩中最大的 5 个（允许并列），且其和 $b_1 + \cdots + b_5$ 为任取 5 个成绩之和的最大值。

**证明**：排序是原序列的一个重排，故 $b_1, \dots, b_5$ 都是原成绩。反设存在 5 个成绩之和更大，则按降序贪心选取必然不劣：对任意 5 元子集 $\{c_1, \dots, c_5\}$，排序后与 $b$ 对位比较，逐位有 $c_{(i)} \le b_i$（因为 $b_i$ 是第 $i$ 大者，任何 5 元子集中第 $i$ 大的数不超过 $b_i$），逐项求和即得 $\sum c_i \le \sum_{i=1}^{5} b_i$。故取前 5 达到最大。∎

**引理 3（输出顺序）**：按 `map`（或 `sorted(by_id)`）遍历产生的输出按 id **严格递增**；id 互异（同一 id 只输出一行），故升序即题目要求的顺序。

**证明**：`map` 的遍历序是 key 的严格升序；`sorted` 同理。每个 id 只产生一个 `[id, avg]`。∎

**定理**：算法返回的二维数组恰为「每个学生前五高成绩的整数平均，按 id 升序」。

**证明**：由引理 1，每个学生的成绩被完整收集；由引理 2，每组求和的对象是该生前五高，`sum / 5` 为题意要求的整数除法平均；由引理 3，行序满足按 id 升序。∎

## 6. 复杂度分析

- **时间**：$O(m \log m)$ 上界的直观拆分——建表 $O(m)$；$U$ 个组内排序合计 $O(\sum k_i \log k_i) \le O(m \log m)$；每组取前 5 与求和 $O(1)$（对固定 5）。`map` 插入带 $O(\log U)$ 因子，总量 $O(m \log U)$。本题 $m \le 1000$，任何写法都是毫秒级；若用小根堆版本则为 $O(m \log 5 + U \log U)$。
- **空间**：$O(m)$ 存哈希表与各组成绩（输出不计），或 $O(m + U)$ 的桶。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<vector<int>> highFive(vector<vector<int>>& items) {
        map<int, vector<int>> byId;                       // id → 成绩表（map 自动按 id 升序）
        for (const auto& it : items)
            byId[it[0]].push_back(it[1]);
        vector<vector<int>> ans;
        for (auto& [id, scores] : byId) {
            sort(scores.begin(), scores.end(), greater<int>());   // 成绩降序排序
            int sum = 0;
            for (int i = 0; i < 5; ++i) sum += scores[i];        // 取前 5 高求和
            ans.push_back({id, sum / 5});                 // 整数除法（正数即向下取整）
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def highFive(self, items: list[list[int]]) -> list[list[int]]:
        by_id = {}                                        # id → 成绩表
        for sid, score in items:
            by_id.setdefault(sid, []).append(score)
        ans = []
        for sid in sorted(by_id):                         # 按 id 升序输出
            scores = sorted(by_id[sid], reverse=True)     # 成绩降序排序
            ans.append([sid, sum(scores[:5]) // 5])       # 前 5 高的整数平均
        return ans
```

## 8. 边界情况与易错点

1. **整数除法不是四舍五入**：88.6 → 88（向零取整/向下取整）。写 `round(sum / 5)` 或 `int(sum / 5 + 0.5)` 都是错的；直接 `sum / 5`、`sum // 5` 才对。
2. **输出必须按 id 升序**：用 `unordered_map` 后不排序直接遍历，顺序是哈希序，必 WA。`map` / `sorted(...)` 二选一。
3. **「前五高」允许并列分数**：示例 2 中 5 个 100 全部计入；取的是**前 5 个位置**，不是「大于第 5 高的所有分数」。
4. **每生至少 5 个成绩是题面保证**：`scores[0..4]` 下标合法，不必特判 `len < 5`；但也别写 `min(5, len)` 之类引入错误直觉（如果少于 5 个，题意本身没有定义）。
5. **恰好 5 个成绩的学生**：全部成绩都计入（见示例 2 的演算）。
6. **`items` 无序、id 不连续**：分组必须遍历全表，输出顺序与 `items` 中 id 首次出现的顺序无关。
7. **数值范围**：$id \le 1000$、$score \le 100$、$m \le 1000$，`int` 与 `sum`（至多 500）毫无溢出风险。
8. **二维数组的行构造**：C++ 写 `ans.push_back({id, sum / 5})`（初始化列表构造 2 元 vector），别手写两列循环。
