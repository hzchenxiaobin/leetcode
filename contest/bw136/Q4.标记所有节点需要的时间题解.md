# LeetCode 标记所有节点需要的时间 题解

## 1. 题目概述

- **标题 / 题号**：标记所有节点需要的时间（#3241，hard）
- **链接**：https://leetcode.cn/problems/time-taken-to-mark-all-nodes/
- **来源**：LeetCode 第 136 场双周赛 Q4
- **难度**：困难
- **标签**：树、深度优先搜索、图、动态规划、树形 DP

**题意**：给定一棵 $n$ 个节点（编号 $0 \sim n-1$）的无向树，边由 $edges$ 给出。初始所有节点未标记。标记规则如下——

- 若 $i$ 是**奇数**节点：当时刻 $x-1$ 时 $i$ 有至少一个已标记的邻居，则 $i$ 在时刻 $x$ 被标记（即需要 **1** 个时间单位）；
- 若 $i$ 是**偶数**节点：当时刻 $x-2$ 时 $i$ 有至少一个已标记的邻居，则 $i$ 在时刻 $x$ 被标记（即需要 **2** 个时间单位）。

对每个起点 $i$（在时刻 $t = 0$ 把 $i$ 标记），求"树中所有节点都被标记"的时刻 $times[i]$。各问独立：回答第 $i$ 问时其余节点都未标记。

**约束**：

- $2 \le n \le 10^5$
- $edges.length = n - 1$，$edges[i].length = 2$
- $0 \le edges[i][0], edges[i][1] \le n - 1$，输入保证构成一棵合法的树

$n$ 达 $10^5$，"对每个起点各跑一次 BFS"的 $O(n^2) = 10^{10}$ 必然超时；目标是**一次 $O(n)$ 的换根 DP** 求出全部答案。

## 2. 示例

**示例 1**

```text
输入：edges = [[0,1],[0,2]]
输出：[2,4,3]
解释：树是 1 - 0 - 2。
      起点 0：节点 1（奇）在 t=1 标记，节点 2（偶）在 t=2 标记 → max = 2。
      起点 1：节点 0（偶）在 t=2，节点 2（偶）再由 0 传播，t=2+2=4 → max = 4。
      起点 2：节点 0 在 t=2，节点 1（奇）在 t=2+1=3 → max = 3。
```

**示例 2**

```text
输入：edges = [[0,1]]
输出：[1,2]
解释：起点 0：节点 1（奇）在 t=1 → 1。
      起点 1：节点 0（偶）在 t=2 → 2。
```

**示例 3**

```text
输入：edges = [[2,4],[0,1],[2,3],[0,2]]
输出：[4,6,3,5,5]
解释：树为 1 - 0 - 2 - 3，且 2 - 4。
      起点 1：1 → 0（2）→ 2（2）→ 4（2），耗时 2+2+2 = 6，是最远的叶子。
```

## 3. 解题思路

### 3.1 暴力思路

对每个起点 $i$ 跑一次 DFS/BFS：从 $i$ 出发沿树传播标记时刻，取最大值。单次 $O(n)$、共 $n$ 个起点 ⇒ $O(n^2) = 10^{10}$，无法通过。注意到"每个起点的答案都是同一种量的最大值"，这强烈暗示可以用**换根 DP**（rerooting）把"以每个点为根"的答案一次性推出来。

### 3.2 核心观察：标记时刻 = 树上"加权路径和"

![把标记时刻翻译成边权：进入节点 v 要花 w(v)](images/bw136_q4_edge_weight.svg)

关键是把"标记规则"翻译成**路径上的加法**。定义节点 $v$ 的"进入代价"

$$w(v) = \begin{cases} 1, & v \text{ 为奇数} \\ 2, & v \text{ 为偶数} \end{cases}$$

由于是树，从起点 $s$ 到任意 $v$ 的**路径唯一**，标记只能沿这条路径一步一步传过去（没有第二条路可走）。于是

$$T_s(v) = \sum_{u \in \text{path}(s \to v),\ u \ne s} w(u)$$

而 $times[s] = \max_{v} T_s(v)$（$v = s$ 时为 0，不影响最大值）。

> 💡 起点自身的 $w(s)$ **不计入**：它在时刻 0 就被标记，是"免费的"。

![换根 DP：down 看子树，up 看"外面"](images/bw136_q4_reroot.svg)

问题于是变成：**对每个节点 $u$，求"从 $u$ 出发到任意点的最大加权路径和"**。这是换根 DP 的标准形态：

- $down[u]$：从 $u$ 出发、走向**子树内**节点的最大加权路径和（不含 $u$ 自己的 $w$），即 $down[u] = \max_{c \text{ 是 } u \text{ 的子节点}} \bigl(w(c) + down[c]\bigr)$，叶子为 $0$；
- $up[u]$：从 $u$ 出发、走向**子树外**节点的最大加权路径和；$up[\text{root}] = 0$（根的外面没有节点）。
- 答案 $times[u] = \max\bigl(down[u],\ up[u]\bigr)$。

**换根转移**：设 $c$ 是 $u$ 的子节点。任何 $c$ 子树之外的节点 $v$，其路径都先到 $u$，故

$$up[c] = w(u) + \max\Bigl(up[u],\ \max_{s \text{ 是 } u \text{ 的其它子节点}} \bigl(w(s) + down[s]\bigr)\Bigr)$$

这里 $w(u)$ 是"从 $c$ 走到 $u$"的代价（注意不是 $w(c)$）；括号里的两项分别对应"继续往上走"和"拐进兄弟子树"。为了让转移 $O(1)$，对每个 $u$ 预处理子节点中 $w(c) + down[c]$ 的**最大值与次大值**（并记下最大值来自哪个子节点），这样"排除 $c$ 后的最大值"可以 $O(1)$ 取出。

### 3.3 算法流程

```text
1. 建邻接表；w[v] = (v 偶 ? 2 : 1)
2. 迭代 DFS 以 0 为根，求出父节点数组 par 和一个"父先于子"的访问序 order
3. 逆序遍历 order（后序）：
       对 u 的每个子节点 c：val = w[c] + down[c]，维护 best1 / best2 / who
       down[u] = best1
4. 正序遍历 order（前序）：
       对 u 的每个子节点 c：
           sib = (who[u] == c ? best2[u] : best1[u])
           up[c] = w[u] + max(up[u], sib)
5. 对每个 u：ans[u] = max(down[u], up[u])
```

### 3.4 示例演算

![示例 3 演算：每个起点的最远路径与耗时](images/bw136_q4_example_walkthrough.svg)

以示例 3 的树为例：节点 $0$（偶，$w=2$）、$1$（奇，$w=1$）、$2$（偶，$w=2$）、$3$（奇，$w=1$）、$4$（偶，$w=2$）；边为 $1-0$、$0-2$、$2-3$、$2-4$。

以 $0$ 为根，先算 $down$：

| 节点 | 子节点 | 候选 $w(c) + down[c]$ | $down$ |
|---|---|---|---|
| 3 | 无 | - | 0 |
| 4 | 无 | - | 0 |
| 2 | 3, 4 | $1 + 0 = 1$，$2 + 0 = 2$ | 2 |
| 1 | 无 | - | 0 |
| 0 | 1, 2 | $1 + 0 = 1$，$2 + 2 = 4$ | 4 |

再算 $up$（$up[0] = 0$）：

| 节点 | 计算 | $up$ |
|---|---|---|
| 1 | $w(0) + \max(up[0] = 0,\ \text{兄弟 } 2 \text{ 的分支} = 2 + 2 = 4) = 2 + 4$ | 6 |
| 2 | $w(0) + \max(0,\ \text{兄弟 } 1 \text{ 的分支} = 1 + 0 = 1) = 2 + 1$ | 3 |
| 3 | $w(2) + \max(up[2] = 3,\ \text{兄弟 } 4 \text{ 的分支} = 2 + 0 = 2) = 2 + 3$ | 5 |
| 4 | $w(2) + \max(up[2] = 3,\ \text{兄弟 } 3 \text{ 的分支} = 1 + 0 = 1) = 2 + 3$ | 5 |

最终 $ans[u] = \max(down[u], up[u])$：

| $u$ | $down$ | $up$ | $times[u]$ |
|---|---|---|---|
| 0 | 4 | 0 | **4** |
| 1 | 0 | 6 | **6** |
| 2 | 2 | 3 | **3** |
| 3 | 0 | 5 | **5** |
| 4 | 0 | 5 | **5** |

答案数组 $[4, 6, 3, 5, 5]$，与示例输出一致。

## 4. 算法细节

1. **迭代 DFS 而不是递归**：$n$ 可达 $10^5$，链状树递归深度 $10^5$ 会爆栈（C++ 默认栈约 8MB，Python 默认 1000 层直接报错）。用显式栈求 `order`。
2. **`order` 的性质**：用栈做 DFS 时，父节点一定先入 `order` 后入栈，故 `order` 是"父先于子"的前序；逆序遍历即为"子先于父"的后序。
3. **子树信息的写法**：`down[u] = best1[u]`，其中 `best1`、`best2` 是子节点 $w(c) + down[c]$ 的最大、次大值，`who[u]` 记录取到最大值的是哪个子节点。
4. **排除自身的兄弟最大值**：若 `who[u] == c` 则取 `best2[u]`，否则取 `best1[u]`。没有兄弟时这两个值都是 0，正好对应"从 $c$ 走到 $u$ 就停"的情形。
5. **`up[u] >= 0` 恒成立**：因此 `max(up[u], sib)` 不必特判空集（子节点为空时 `sib = 0`）。
6. **权重定义在"被进入的节点"上**：`w[u] = (u % 2 == 0) ? 2 : 1`。转移时往下走用 $w(c)$，换根时往上走用 $w(u)$——两者容易写混。
7. **答案范围**：最大路径和不超过 $2(n-1) \approx 2 \times 10^5$，`int` 足够。
8. **建图**：无向树，每条边双向加入；用 `par[v] == -1` 判断是否访问过（也可用 `v != par[u]`，因为树无环）。
9. **根的选择**：任选（代码选 0）。$up[\text{root}] = 0$ 表示"根的外面没有节点"，参与 `max` 时不会产生错误的最大值。

## 5. 正确性证明

以 $s$ 为起点时，记 $M(v)$ 为节点 $v$ 实际被标记的时刻，$W(v)$ 为从 $s$ 到 $v$ 路径上（不含 $s$）的 $w$ 之和。

**引理 1（标记时刻等于加权路径和）**：对任意 $v$，$M(v) = W(v)$。

**证明**：标记规则可写成：$v$ 在时刻 $x$ 被标记，当且仅当某邻居 $u$ 满足 $M(u) \le x - w(v)$，且 $x$ 是满足此条件的最小值。故

$$M(v) = w(v) + \min_{u \in N(v)} M(u), \qquad M(s) = 0$$

（树连通，标记会不断向外扩散，所有 $M(v)$ 有限。）

*下界* $M(v) \ge W(v)$：对标记的先后顺序做强归纳。设 $v$ 是被标记的节点，$u$ 是促成它的邻居，即 $M(v) = M(u) + w(v)$。

- 若 $u$ 是 $v$ 在 $s$-根树中的父节点，则 $W(v) = W(u) + w(v)$，由归纳假设 $M(u) = W(u)$，故 $M(v) = W(v)$。
- 若 $u$ 是 $v$ 的子节点，则 $W(u) = W(v) + w(u) > W(v)$，由归纳假设 $M(u) = W(u)$，故 $M(v) = W(u) + w(v) > W(v)$。

两种情形都有 $M(v) \ge W(v)$。

*上界* $M(v) \le W(v)$：对 $v$ 到 $s$ 的距离归纳。距离 1 时父节点是 $s$，$M(s) = 0$ 已标记，故 $v$ 最迟在 $0 + w(v) = W(v)$ 被标记。距离 $d > 1$ 时，父节点 $p$ 由归纳假设满足 $M(p) \le W(p)$；$p$ 一旦被标记就成为"已标记邻居"，故 $M(v) \le M(p) + w(v) \le W(p) + w(v) = W(v)$。

结合两个方向得 $M(v) = W(v)$。∎

**推论**：$times[s] = \max_v W(v) = \max_v T_s(v)$，即"从 $s$ 出发的最大加权路径和"。

**引理 2（$down$ 正确）**：按后序计算的 $down[u] = \max_{c \text{ 子}} (w(c) + down[c])$（叶子为 0）满足：$down[u] = \max\{T_u(v) : v \text{ 在 } u \text{ 的子树中}, v \ne u\}$。

**证明**：对子树高度归纳。$u$ 为叶子时集合为空，最大值取 0，成立。设 $u$ 有子节点 $c_1, \dots, c_k$。任何 $v \ne u$ 在 $u$ 的子树中，其路径先到某个 $c_i$，故 $T_u(v) = w(c_i) + T_{c_i}(v)$，于是

$$\max_v T_u(v) = \max_i \Bigl(w(c_i) + \max_{v \in \text{subtree}(c_i)} T_{c_i}(v)\Bigr) = \max_i \bigl(w(c_i) + down[c_i]\bigr)$$

（第二个等号用了归纳假设，注意 $v = c_i$ 时 $T_{c_i}(c_i) = 0$ 也包含在内）。∎

**引理 3（$up$ 正确）**：设 $c$ 是 $u$ 的子节点，按

$$up[c] = w(u) + \max\Bigl(up[u],\ \max_{s \text{ 是 } u \text{ 的子节点}, s \ne c} \bigl(w(s) + down[s]\bigr)\Bigr)$$

计算（$up[\text{root}] = 0$，空集的最大值记 0），则 $up[c] = \max\{T_c(v) : v \text{ 不在 } c \text{ 的子树中}\}$。

**证明**：任何 $v$ 不在 $c$ 的子树中，从 $c$ 到 $v$ 的路径必经 $u$，故 $T_c(v) = w(u) + T_u(v)$。而 $v$ 分三类：

- $v = u$：$T_u(u) = 0 \le up[u]$（$up \ge 0$）；
- $v$ 在 $u$ 的子树之外：$T_u(v) \le up[u]$，且 $up[u]$ 是这类节点（含 $v=u$）的最大值（归纳假设）；
- $v$ 在某个兄弟子树 $\text{subtree}(s)$（$s \ne c$）中：$T_u(v) = w(s) + T_s(v) \le w(s) + down[s]$，且上界可达（引理 2）。

三类合起来的最大值正是括号中的 $\max(up[u], \max_{s \ne c}(w(s)+down[s]))$，乘上外层 $w(u)$ 后即为 $up[c]$。∎

**定理**：算法输出 $ans[u] = \max(down[u], up[u]) = times[u]$。

**证明**：$u$ 的"子树内"与"子树外（含 $u$ 自身）"两类节点覆盖了整棵树，由引理 2、3 及推论，

$$\max(down[u], up[u]) = \max_{v} T_u(v) = times[u]$$

又由引理 2、3 的转移与算法中对 `best1` / `best2` 的维护，代码计算出的正是这两个量（"排除子节点 $c$ 后的最大值"由最大值来源判断后取 `best2` 得到）。故输出数组即为所求。另外，换根转移只依赖父节点的 $up$ 与兄弟分支，前序遍历保证父节点先于子节点处理，故所有值都按正确顺序算出。∎

## 6. 复杂度分析

- **时间**：$O(n)$。建图 $O(n)$；一次 DFS 求 `order` $O(n)$；后序求 $down$、前序求 $up$ 各遍历每条边一次 $O(n)$；最后汇总 $O(n)$。
- **空间**：$O(n)$。邻接表 $O(n)$、`order`/`par`/`w`/`down`/`up`/`best1`/`best2`/`who` 各 $O(n)$；递归栈被显式栈替代，最坏 $O(n)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> timeTaken(vector<vector<int>>& edges) {
        int n = edges.size() + 1;
        vector<vector<int>> g(n);
        for (const auto& e : edges) {
            g[e[0]].push_back(e[1]);
            g[e[1]].push_back(e[0]);
        }
        vector<int> w(n);
        for (int i = 0; i < n; ++i) w[i] = (i % 2 == 0) ? 2 : 1;  // 进入该点的耗时
        vector<int> par(n, -1), order;
        order.reserve(n);
        par[0] = -2;
        vector<int> st{0};
        while (!st.empty()) {                 // 迭代 DFS 定根为 0
            int u = st.back(); st.pop_back();
            order.push_back(u);
            for (int v : g[u])
                if (v != par[u]) { par[v] = u; st.push_back(v); }
        }
        vector<int> down(n, 0), up(n, 0), best1(n, 0), best2(n, 0), who(n, -1);
        for (int k = n - 1; k >= 0; --k) {    // 逆序：子树信息先就绪
            int u = order[k];
            for (int v : g[u]) {
                if (v == par[u]) continue;
                int val = w[v] + down[v];
                if (val > best1[u]) {
                    best2[u] = best1[u]; best1[u] = val; who[u] = v;
                } else if (val > best2[u]) {
                    best2[u] = val;
                }
            }
            down[u] = best1[u];
        }
        for (int u : order) {                 // 顺序：父的 up 先就绪
            for (int v : g[u]) {
                if (v == par[u]) continue;
                int sib = (who[u] == v) ? best2[u] : best1[u];
                up[v] = w[u] + max(up[u], sib);
            }
        }
        vector<int> ans(n);
        for (int i = 0; i < n; ++i) ans[i] = max(down[i], up[i]);
        return ans;
    }
};
```

### Python

```python
class Solution:
    def timeTaken(self, edges: list[list[int]]) -> list[int]:
        n = len(edges) + 1
        g = [[] for _ in range(n)]
        for u, v in edges:
            g[u].append(v)
            g[v].append(u)
        w = [2 if i % 2 == 0 else 1 for i in range(n)]   # 进入该点的耗时
        par = [-1] * n
        par[0] = -2
        order, st = [], [0]
        while st:                                        # 迭代 DFS 定根为 0
            u = st.pop()
            order.append(u)
            for v in g[u]:
                if v != par[u]:
                    par[v] = u
                    st.append(v)
        down = [0] * n
        best1 = [0] * n
        best2 = [0] * n
        who = [-1] * n
        for u in reversed(order):                        # 逆序：子树信息先就绪
            b1 = b2 = 0
            for v in g[u]:
                if v == par[u]:
                    continue
                val = w[v] + down[v]
                if val > b1:
                    b2, b1, who[u] = b1, val, v
                elif val > b2:
                    b2 = val
            best1[u], best2[u], down[u] = b1, b2, b1
        up = [0] * n
        for u in order:                                  # 顺序：父的 up 先就绪
            for v in g[u]:
                if v == par[u]:
                    continue
                sib = best2[u] if who[u] == v else best1[u]
                up[v] = w[u] + max(up[u], sib)
        return [max(down[i], up[i]) for i in range(n)]
```

> 💡 两份代码均通过官方示例（`[2,4,3]`、`[1,2]`、`[4,6,3,5,5]`）与 $n = 2$ 边界，并与"对每个起点各跑一次加权 DFS 取最大值"的暴力解在 400 组随机树（$n \le 10$）上对拍一致（`mismatch = 0`）；$n = 10^5$ 的链与菊花图耗时分别约 $0.23$ 秒、$0.18$ 秒（C++），Python 在链上约 $0.09$ 秒。

## 8. 边界情况与易错点

1. **递归爆栈**：$10^5$ 的链会让递归 DFS 直接 RE（Python 默认递归深度 1000）。必须用显式栈迭代。
2. **奇偶权重方向**：$w(v) = 1$（$v$ 奇）、$w(v) = 2$（$v$ 偶）；别把节点的奇偶与"距离的奇偶"混为一谈。
3. **起点不计 $w$**：路径和只累加"路径上除起点外的节点"，否则答案会整体偏大。
4. **换根用的是 $w(u)$ 而不是 $w(c)$**：$up[c] = w(u) + \dots$，因为从 $c$ 走到 $u$ 要花的是"进入 $u$"的代价。
5. **`best2` 的初值**：子树只有一个孩子时 `best2 = 0`，代表"走到 $u$ 就停"；这正好与"排除该孩子后没有兄弟分支"相符，不需要特判。
6. **`up[root] = 0`**：根的"外面"没有节点；若初始成 $-\infty$ 反而不便（`max` 里要额外判断），用 0 是安全的，因为路径和恒非负。
7. **父节点判定的哨兵值**：代码里 `par[0] = -2`（而非 -1）以避免与"未访问"混淆；也可以用 `visited` 数组。
8. **答案类型**：最大约为 $2(n-1) \le 2\times10^5$，`int` 足够；但若要答"路径和之和"之类就需 `long long`。
9. **$n = 2$**：`down` 为 $w$ 或 0，`up` 对称，答案 `[w(1) 或 w(0)]` 正确（示例 2 得 `[1, 2]`）。
10. **多棵子树的最大值维护**：直接对每个子节点重新扫一遍其它子节点会退化成 $O(n^2)$（星形图），必须用 `best1` / `best2` / `who` 的 $O(1)$ 取法。

**延伸思考**：若把"奇数 1 秒、偶数 2 秒"改成"每个点有任意耗时 $w(v)$"，本题代码一行都不用改——加权路径和的框架本来就支持任意非负权。若标记规则改成"需要**两个**已标记邻居"（类似火灾/感染模型的阈值传播），问题立刻变成 NP-hard 味道的难题，因为传播不再沿单一路径，需要完全不同的建模。另一个自然变体是求"所有点都被标记的时间之和"或"每个点的标记时刻"，前者可在换根时同时维护计数与和，后者则要对每个起点输出全部 $T_s(v)$，复杂度升到 $O(n^2)$。
