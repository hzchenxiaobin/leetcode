# LeetCode 最少翻转次数使二进制矩阵回文 I 题解

## 1. 题目概述

- **标题 / 题号**：最少翻转次数使二进制矩阵回文 I（#3239，medium）
- **链接**：https://leetcode.cn/problems/minimum-number-of-flips-to-make-binary-grid-palindromic-i/
- **来源**：LeetCode 第 136 场双周赛 Q2
- **难度**：中等
- **标签**：数组、双指针、矩阵

**题意**：给定 $m \times n$ 的二进制矩阵 $grid$。若某一行（列）从前往后与从后往前读相同，则称它回文。可以翻转任意格子（$0 \leftrightarrow 1$）。要求做到**二选一**：

- 所有行都是回文的；或
- 所有列都是回文的。

求最少翻转次数。

注意是"要么行、要么列"，**不要求同时成立**——这是本题与下一题（II）的核心区别，也是难度从这里开始分叉的原因。

**约束**：

- $m = grid.length$，$n = grid[i].length$
- $1 \le m \times n \le 2 \times 10^5$
- $0 \le grid[i][j] \le 1$

总格子数 $2 \times 10^5$，允许 $O(mn)$ 的常数次遍历。

## 2. 示例

**示例 1**

```text
输入：grid = [[1,0,0],[0,0,0],[0,0,1]]
输出：2
解释：走"所有行回文"：第 0 行 1,0,0 需把末位翻成 1（1 次）；
      第 1 行 0,0,0 已回文；第 2 行 0,0,1 需把首位翻成 1（1 次）。共 2 次。
```

**示例 2**

```text
输入：grid = [[0,1],[0,1],[0,0]]
输出：1
解释：走"所有列回文"：第 0 列 0,0,0 已回文；第 1 列 1,1,0 只需把最后一行翻成 1。共 1 次。
      若走"所有行回文"则要 2 次（前两行各 1 次），故答案是 1。
```

**示例 3**

```text
输入：grid = [[1],[0]]
输出：0
解释：每行只有一个元素，行回文天然成立。
```

**示例 4（边界补充）**

```text
输入：grid = [[0,1]]
输出：0
解释：每列只有一个元素，列回文天然成立。
```

## 3. 解题思路

### 3.1 暴力思路

"翻转哪些格子"有 $2^{mn}$ 种选择，$mn$ 最大 $2 \times 10^5$，不可能枚举。即使退一步"只翻必须翻的格子"，也需要先把目标结构看清楚——而一旦看清楚，答案就是简单的计数。

### 3.2 核心观察：一行回文 ⟺ 每对对称位置相等，代价恰为不匹配对数

![行回文：左右对称配对，不等的对必须翻一个](images/bw136_q2_row_pairs.svg)

考虑单独一行 $row$。它回文当且仅当对每个 $j < n/2$ 都有 $row[j] = row[n-1-j]$。

- 若某对已经相等：不需要动（动任意一个反而要再动回来）；
- 若某对不相等：**至少**要翻其中一个（翻别的格子改变不了这两个位置的值），而翻其中一个恰好就能让它们相等。

所以这一行的最少翻转次数 = **不等的对称对数**。更关键的是：不同的对**互不相交**（每对是两个不同下标，且不同对之间没有公共下标），因此可以独立处理，总代价就是各行代价之和。

同理，让所有列回文 = 对每列统计"上下对称位置不等的对数"，再对所有列求和。

### 3.3 算法流程

![两条互斥路线，取代价更小者](images/bw136_q2_two_targets.svg)

```text
1. rowFlips = 0
   for i in 0..m-1:
       for j in 0..n/2-1:
           if grid[i][j] != grid[i][n-1-j]: rowFlips += 1
2. colFlips = 0
   for j in 0..n-1:
       for i in 0..m/2-1:
           if grid[i][j] != grid[m-1-i][j]: colFlips += 1
3. 返回 min(rowFlips, colFlips)
```

只做统计、**不真的修改矩阵**——因为两条路线互相独立地统计，互不干扰。

### 3.4 示例演算

以示例 2 的 $grid = [[0,1],[0,1],[0,0]]$（3 行 2 列）为例。

**路线 1：所有行回文**（每行只有 2 个数，一对）

| 行 | 内容 | 对称对 | 是否相等 | 代价 |
|---|---|---|---|---|
| 0 | 0, 1 | (0, 1) | 不等 | 1 |
| 1 | 0, 1 | (0, 1) | 不等 | 1 |
| 2 | 0, 0 | (0, 0) | 相等 | 0 |

$rowFlips = 2$。

**路线 2：所有列回文**（每列 3 个数，一对 + 中心）

| 列 | 内容 | 对称对 | 是否相等 | 代价 |
|---|---|---|---|---|
| 0 | 0, 0, 0 | (0, 2) | 相等 | 0 |
| 1 | 1, 1, 0 | (1, 0) | 不等 | 1 |

$colFlips = 1$。

答案 $\min(2, 1) = 1$，与示例输出一致。

## 4. 算法细节

1. **中心元素不用管**：长度为奇数的行（列），中间那个格子在任何配对之外，翻它只会白白浪费，不需要统计。
2. **两趟统计互不影响**：`rowFlips` 与 `colFlips` 都是基于**原始**矩阵算的，不要在第一趟里真的翻转（那会污染第二趟）。
3. **循环边界**：行路线内层 `j < n/2`，列路线内层 `i < m/2`，注意与 `<=` 的区别。
4. **下标不越界**：`n - 1 - j` 在 $j < n/2$ 时恒 $\ge j$，且最大为 $n-1$。
5. **复杂度常数**：两趟各访问约 $mn/2$ 个格子，总计 $mn$ 次比较。
6. **不需要分类讨论 $m$、$n$ 的奇偶**：奇偶只影响"中心行/列"是否存在，而中心行（列）回文性……**注意**：若 $m$ 为奇数，中间那行若 $n$ 为偶数，它仍然需要满足左右对称！行路线里我们遍历了所有 $i \in [0, m-1]$，自然包含了它；列路线遍历所有 $j$，也包含了中间列。所以无需特判。
7. **答案上界**：$\min(rowFlips, colFlips) \le mn/2$，`int` 足够。

## 5. 正确性证明

**引理 1（行回文的等价条件）**：一行 $row$（长度 $n$）回文，当且仅当对每个 $0 \le j < n/2$ 都有 $row[j] = row[n-1-j]$。

**证明**：回文的定义是对每个 $j$ 有 $row[j] = row[n-1-j]$。当 $j < n/2$ 时，$n-1-j > n/2$，与下标 $n-1-j$ 处的条件重复；当 $j = n-1-j$（即 $j$ 是中心）时条件自动成立。故只需检查 $j < n/2$ 的一半下标。∎

**引理 2（单行最优代价）**：使一行回文所需的最少翻转次数等于该行中"不相等的对称对数"。

**证明**：设不相等的对称对为 $P_1, \dots, P_r$，每对由两个不同下标记为 $\{a, b\}$。

*下界*：对任意一对 $P_k = \{a, b\}$，初始 $row[a] \ne row[b]$，而回文要求终态 $row'[a] = row'[b]$。由于翻转只改变被翻格子的值，若 $a, b$ 都不被翻转则两者都不变、仍然不等，故 $P_k$ 中至少有一个格子被翻。不同对互不相交，因此总翻转次数 $\ge r$。

*上界*：对每个不相等对，只翻其中一个格子（例如翻 $a$），则 $P_k$ 变相等；对相等对不翻。总共 $r$ 次，且各对互不干扰，终态每对都相等，由引理 1 该行回文。∎

**引理 3（行间独立性）**：使所有行回文的最少总翻转次数等于各行最少代价之和。

**证明**：目标"所有行回文"是 $m$ 个行条件的合取，而每次翻转只改变某一个格子、只影响它所在的那一行。因此问题分解为 $m$ 个互不耦合的子问题，每个子问题的最优代价由引理 2 给出，最优总代价为它们之和（下界：每一行都必须各自达标，故总次数不少于各行下界之和；上界：各行按引理 2 的构造同时执行，构造之间不冲突）。∎

**引理 4（列路线）**：同理，使所有列回文的最少总翻转次数等于"各列上下对称位置不等的对数"之和。

**证明**：把矩阵转置后与引理 1~3 完全对称。∎

**定理**：答案为 $\min(rowFlips, colFlips)$。

**证明**：可行方案集是"使所有行回文"与"使所有列回文"两个集合之并。两个集合上的最小值分别由引理 3 与引理 4 给出为 $rowFlips$ 与 $colFlips$，故并集上的最小值为两者较小者。∎

## 6. 复杂度分析

- **时间**：$O(mn)$。行路线约 $mn/2$ 次比较，列路线约 $mn/2$ 次比较。
- **空间**：$O(1)$ 额外空间（只用了两个计数器），不复制矩阵。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minFlips(vector<vector<int>>& grid) {
        int m = grid.size(), n = grid[0].size();
        int rowFlips = 0, colFlips = 0;
        for (int i = 0; i < m; ++i)                 // 让每一行回文
            for (int j = 0; j < n / 2; ++j)
                if (grid[i][j] != grid[i][n - 1 - j]) ++rowFlips;
        for (int j = 0; j < n; ++j)                 // 让每一列回文
            for (int i = 0; i < m / 2; ++i)
                if (grid[i][j] != grid[m - 1 - i][j]) ++colFlips;
        return min(rowFlips, colFlips);
    }
};
```

### Python

```python
class Solution:
    def minFlips(self, grid: list[list[int]]) -> int:
        m, n = len(grid), len(grid[0])
        row_flips = 0
        for i in range(m):                    # 让每一行回文
            for j in range(n // 2):
                if grid[i][j] != grid[i][n - 1 - j]:
                    row_flips += 1
        col_flips = 0
        for j in range(n):                    # 让每一列回文
            for i in range(m // 2):
                if grid[i][j] != grid[m - 1 - i][j]:
                    col_flips += 1
        return min(row_flips, col_flips)
```

> 💡 两份代码均通过官方示例（`2`、`1`、`0`）与 $1 \times 1$、单行、单列等边界，并与"枚举所有 $2^{mn}$ 个目标矩阵、检查行/列回文、取最小汉明距离"的暴力解在 300 组随机小矩阵（$m, n \le 5$）上对拍一致（`mismatch = 0`）；$mn = 2 \times 10^5$ 的极限输入耗时约 $0.13$ 秒。

## 8. 边界情况与易错点

1. **$1 \times 1$**：行、列都只有一个元素，天然回文，答案 0。
2. **单行 $1 \times n$**：每列长度为 1，列回文自动成立 ⇒ $colFlips = 0$，答案 0；但行路线仍需统计（可能非零），最终取 min 得 0。
3. **单列 $m \times 1$**：对称地，答案 0。
4. **不要真的翻转**：若在行路线里就地翻转 `grid`，列路线的统计就会基于被改坏的矩阵，结果错误。
5. **中心行列要参与统计**：当 $m$ 为奇、$n$ 为偶时，中间行仍然有左右配对，必须计入。循环用"遍历所有 $i$"就自动包含，别写成 `i < m/2`。
6. **严格二选一**：不要尝试"部分行 + 部分列"的混合方案，题目没给这种自由度。
7. **整数类型**：$mn \le 2\times10^5$，`int` 足够，无需 `long long`。
8. **下标对称公式**：行用 `n - 1 - j`，列用 `m - 1 - i`，别写反（写成 `n - 1 - i` 属常见笔误）。
