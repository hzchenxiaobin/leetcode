# LeetCode 有序矩阵中的第 k 个最小数组和 题解

## 1. 题目概述

- **标题 / 题号**：有序矩阵中的第 k 个最小数组和（#1439，hard）
- **链接**：https://leetcode.cn/problems/find-the-kth-smallest-sum-of-a-matrix-with-sorted-rows/
- **来源**：LeetCode 第 187 场周赛 Q4
- **难度**：困难
- **标签**：数组、二分查找、矩阵、堆（优先队列）

**题意**：给定 $m \times n$ 的矩阵 `mat`，每一行都按**非递减**排列。从**每一行恰好选一个**元素，拼成长度为 $m$ 的数组，一共有 $n^m$ 种选法。返回所有选法的和里**第 $k$ 小**的那个和（相同和按重数分别计数）。

**约束**：

- $m = \text{mat.length}$，$n = \text{mat}[i]$ 的长度（各行等长），$1 \le m, n \le 40$
- $1 \le k \le \min(200,\, n^m)$
- $1 \le \text{mat}[i][j] \le 5000$
- `mat[i]` 非递减

## 2. 示例

```text
输出：7

      和依次为 3, 5, 5, 7, 7，第 5 个是 7。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有 $n^m$ 种选法，求和后取第 $k$ 小。组合数 $40^{40}$ 是天量，即便 $k \le 200$、只想「边枚举边维护前 $k$ 小」，也无法剪枝：最坏情况下前 $k$ 小可能散落在枚举序的任意位置。必须利用「每行有序」这一结构。

### 3.2 核心观察：和矩阵行列有序 + 截断引理

![两个非递减序列的笛卡尔和构成行列有序矩阵](images/wc187_q4_cartesian_sorted.svg)

设已经处理完前 $t-1$ 行，得到的**前 $k$ 小和**排好序为 $A = [a_0 \le a_1 \le \cdots]$（长度 $p \le k$）；第 $t$ 行是 $B = [b_0 \le b_1 \le \cdots]$（长度 $n$）。那么「前 $t$ 行的和」就是所有 $a_i + b_j$，把它们排成矩阵

$$M[i][j] = a_i + b_j,\qquad 0 \le i < p,\ 0 \le j < n$$

因为 $A$、$B$ 各自非递减，所以 $M$ **每行非递减**（固定 $i$ 只让 $j$ 增大），**每列也非递减**（固定 $j$ 只让 $i$ 增大）。于是「取前 $k$ 小」就是**杨氏矩阵的左上角扩展**，这正是 [378. 有序矩阵中第 K 小的元素](https://leetcode.cn/problems/kth-smallest-element-in-a-sorted-matrix/) 的套路：从 $(0,0)$ 出发用最小堆向右、向下扩展，弹出 $k$ 次即可。

两个关键保证：

1. **规模被 $k$ 卡住**：每轮只保留前 $k$ 小（截断引理），$p \le k$，候选格子最多 $k \cdot n$；
2. **每格只入堆一次**：给扩展方向规定一个「父节点」，避免同一个组合被重复计数。

### 3.3 算法流程

![逐行合并与堆的生成规则](images/wc187_q4_heap_expand.svg)

1. `dp = [0]`，表示「一行都没选」时唯一的前缀和；
2. 依次取每一行 `row`，令 $p = \lvert dp \rvert$、$n = \lvert row \rvert$，`take = min(k, p*n)`；
3. 堆初始只放 `(dp[0]+row[0], 0, 0)`，即 $M$ 的左上角；
4. 重复 `take` 次：弹出堆顶 $(s,i,j)$，把 $s$ 追加到 `nxt`；然后
   - 若 $i+1 < p$，把 $(dp[i+1]+row[j],\, i+1,\, j)$ 入堆（**向下**）；
   - 若 $i = 0$ 且 $j+1 < n$，把 $(dp[0]+row[j+1],\, 0,\, j+1)$ 入堆（**只在第一行向右**）；
5. `dp = nxt`（长度为 `take`），回到第 2 步；全部行处理完后返回 `dp[k-1]`。

「只在第一行向右」是为了**去重**：若每个格子都同时向右、向下扩展，$(i,j)$ 会被 $(i-1,j)$ 与 $(i,j-1)$ 两条路径各推一次，前 $k$ 小就被重复计数了。规定 $(i,j)$ 只能由 $(i-1,j)$（$i \ge 1$）或 $(0,j-1)$（$i = 0$）生成，每个格子恰好入堆一次。

### 3.4 示例演算

![示例 1 的堆弹出顺序](images/wc187_q4_walkthrough.svg)

以 `mat = [[1,3,11],[2,4,6]]`、$k = 5$ 为例：

| 轮次 | 合并的行 | 合并前 `dp` | 归并得到的前 `take` 小 |
| ---- | -------- | ----------- | ---------------------- |
| 1 | `[1,3,11]` | `[0]` | `[1, 3, 11]`（只有 3 个） |
| 2 | `[2,4,6]` | `[1,3,11]` | `[3, 5, 5, 7, 7]` |

第 2 轮的 $3 \times 3$ 和矩阵为

```text
      2   4   6
 1    3   5   7
 3    5   7   9
11   13  15  17
```

堆的弹出顺序是 $3 \to 5 \to 5 \to 7 \to 7$，第 5 次弹出的 $7$ 就是答案。

## 4. 算法细节

1. **`dp` 的初值是 `[0]`**：它是「零行之和」的退化情形，让第一行也走同一套归并逻辑（此时 $p = 1$，结果就是该行前 $\min(k,n)$ 个元素），不必特判。
2. **`take = min(k, p*n)` 不能省**：前几行可选组合数可能不足 $k$，若强行弹 $k$ 次会从空堆取元素；同时 `dp` 长度要按 `take` 截断，否则后一轮的 $p$ 会虚高。
3. **堆元素用三元组 `(sum, i, j)`**：`sum` 相同时靠 `(i, j)` 打破平局，保证堆序稳定；Python 元组天然可比较，C++ 用 `tuple` + `greater<>`。
4. **生成规则要「单向」**：$(i,j)$ 只在 $i = 0$ 时向右生长，否则只向下生长。写错成「两个方向都推」会让同一和重复出现，答案偏小。
5. **截断到 $k$ 是安全的**：第 $k$ 名之外的和加上任何行元素，都不可能挤进新的前 $k$ 名（见引理 2），所以每轮 `dp` 只需保留 `take` 项。
6. **备选实现（更短）**：不用堆，直接生成 $p \times n$ 个和并排序截断 —— `dp = sorted(a+b for a in dp for b in row)[:k]`，复杂度 $O(m \cdot kn \log(kn))$，本题规模下同样秒过；堆版本在 $k$ 接近 $pn$ 时优势不明显，但它是 $O(m k \log k)$ 的正统解法。
7. **为什么不二分答案**：本题要判定「和 $\le X$ 的组合数」需要跨行卷积计数，规模 $n^m$ 且无简单闭式，判定比原问题还难；二分的适用前提是计数可行，这里不成立。
8. **整数范围**：最大和 $m \times 5000 = 2 \times 10^5$，`int` 完全够用，不需要 `long long`。

## 5. 正确性证明

**引理 1（和矩阵行列有序）**：若 $A$、$B$ 非递减，则 $M[i][j] = a_i + b_j$ 满足 $M[i][j] \le M[i][j+1]$ 且 $M[i][j] \le M[i+1][j]$。

**证明**：两式相减即得

$$M[i][j+1] - M[i][j] = b_{j+1} - b_j \ge 0,\qquad M[i+1][j] - M[i][j] = a_{i+1} - a_i \ge 0$$

不等式分别来自 $B$、$A$ 的非递减性。∎

**引理 2（截断不丢前 $k$ 小）**：设 $S$ 为前 $t-1$ 行全部和的多重集，$T \subseteq S$ 是其中最小的 $\min(k, \lvert S \rvert)$ 个（按重数）。则对任意非递减行 $B$，把 $T$ 与 $B$ 逐对求和所得多重集的前 $k$ 小，等于把 $S$ 与 $B$ 逐对求和所得多重集的前 $k$ 小。

**证明**：若 $\lvert S \rvert \le k$ 则 $T = S$，显然。否则 $\lvert T \rvert = k$。任取 $s \in S \setminus T$ 与 $b \in B$：因 $T$ 取的是最小的 $k$ 个，存在 $k$ 个元素 $s_1, \dots, s_k \in T$ 满足 $s_i \le s$，于是 $s_i + b \le s + b$ 且有 $k$ 个（按重数），故 $s+b$ 严格排在前 $k$ 名之外，丢弃它不会改变前 $k$ 小。∎

**引理 3（堆不漏不重）**：按 3.3 的生成规则，(a) 每个格子 $(i,j)$ 至多入堆一次；(b) 任一时刻，堆顶恰为 $M$ 中尚未弹出的最小格子。

**证明**：

- (a) 若 $i \ge 1$，$(i,j)$ 只可能由 $(i-1,j)$ 通过「向下」规则生成；若 $i = 0$，只可能由 $(0,j-1)$ 通过「向右」规则生成。两条路径的触发条件（$i = 0$ 与否）互斥，且每个父节点弹出时只生成一次，故每格至多入堆一次。
- (b) 设当前未被弹出的最小格子是 $(i,j)$，其值记为 $v$。若 $(i,j) = (0,0)$，它开局就在堆中。否则取它在生成规则下的父节点 $P$，由引理 1 有 $P$ 的值 $\le v$。若 $P$ 已被弹出，则 $(i,j)$ 已被生成、正在堆中，值为 $v$；若 $P$ 未被弹出，则 $P$ 是值 $\le v$ 的未弹出格子，由 $v$ 的最小性得 $P$ 的值 $= v$，继续对 $P$ 取父节点，链条有限（坐标单调减小），终点必是 $(0,0)$，于是链上某个格子已在堆中且值 $\le v$。又堆中所有格子的值都 $\ge v$（$v$ 是最小未弹出值），故堆顶 $= v$。∎

**引理 4（每轮 `dp` 正确）**：处理完前 $t$ 行后，`dp` 恰好是「前 $t$ 行全部和」中最小的 $\min(k, \cdot)$ 个，且非递减。

**证明**：对 $t$ 归纳。$t = 0$ 时 `dp = [0]`，即空和，成立。设前 $t-1$ 行正确，则候选集恰为 $M[i][j] = dp_i + row_j$（引理 2 保证截断后仍是完整候选集的前缀）。由引理 3，堆每次弹出的都是未弹出格子的最小值，弹出 `take` 次正好得到 $M$ 的前 `take` 小，且顺序非递减，故 `nxt` 有序且正确；再按引理 2 截断到 $k$ 仍保持「前 $k$ 小」语义。∎

**定理**：算法返回全部 $n^m$ 个数组和中的第 $k$ 小。

**证明**：由引理 4，$t = m$ 时 `dp` 是全部和集的前 $\min(k, n^m)$ 小；由约束 $k \le n^m$，`dp` 长度恰为 $k$ 且非递减，故 `dp[k-1]` 就是第 $k$ 小。∎

## 6. 复杂度分析

- **时间**：$O(m \cdot k \log k)$。每行最多弹出 `take ≤ k` 次，每次入堆/出堆 $O(\log k)$（堆大小 $\le k+1$），共 $m \le 40$ 行，合计约 $40 \times 200 \times 8$ 量级的堆操作；`dp` 赋值是 $O(k)$ 拷贝。
- **空间**：$O(k)$。堆中元素 $\le k + 1$，`nxt` 与 `dp` 各 $O(k)$，与 $m, n$ 无关（除输入本身）。
- 备选的排序截断版：时间 $O(m \cdot kn \log(kn))$，空间 $O(kn)$，即 $40 \times 8000 \log 8000$，在本题同样安全。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <queue>
#include <tuple>
#include <algorithm>
#include <utility>
using namespace std;

class Solution {
public:
    int kthSmallest(vector<vector<int>>& mat, int k) {
        vector<int> dp{0};                       // 0 行时的前 k 小和
        for (const auto& row : mat) {
            int p = (int)dp.size(), n = (int)row.size();
            int take = min(k, p * n);            // 本行合并后保留的项数
            priority_queue<tuple<int, int, int>,
                           vector<tuple<int, int, int>>, greater<>> pq;
            pq.emplace(dp[0] + row[0], 0, 0);    // 从左上角出发
            vector<int> nxt;
            nxt.reserve(take);
            while ((int)nxt.size() < take) {
                auto [s, i, j] = pq.top();
                pq.pop();
                nxt.push_back(s);
                if (i + 1 < p)                                   // 向下
                    pq.emplace(dp[i + 1] + row[j], i + 1, j);
                if (i == 0 && j + 1 < n)                         // 只在第一行向右
                    pq.emplace(dp[0] + row[j + 1], 0, j + 1);
            }
            dp = std::move(nxt);
        }
        return dp[k - 1];
    }
};
```

### Python

```python
import heapq
from typing import List


class Solution:
    def kthSmallest(self, mat: List[List[int]], k: int) -> int:
        dp = [0]                                  # 0 行时的前 k 小和
        for row in mat:
            p, n = len(dp), len(row)
            take = min(k, p * n)                  # 本行合并后保留的项数
            heap = [(dp[0] + row[0], 0, 0)]       # (和, dp 下标, row 下标)
            nxt = []
            while len(nxt) < take:
                s, i, j = heapq.heappop(heap)
                nxt.append(s)
                if i + 1 < p:                     # 向下
                    heapq.heappush(heap, (dp[i + 1] + row[j], i + 1, j))
                if i == 0 and j + 1 < n:          # 只在第一行向右，避免重复入堆
                    heapq.heappush(heap, (dp[0] + row[j + 1], 0, j + 1))
            dp = nxt
        return dp[k - 1]
```

## 8. 边界情况与易错点

1. **`take` 与 `dp` 越界**：前几行组合数不足 $k$ 时 `p*n < k`，必须取 `min`；否则会在空堆上 `pop`，或最后访问 `dp[k-1]` 越界。题目保证 $k \le n^m$，因此走完全部行后 `dp` 长度一定等于 $k$。
2. **重复和必须按重数计数**：`[1,1,10]` 里两个 `1` 是两个不同组合，不能用 `set` 去重；堆里相同的和而 $(i,j)$ 不同，就是不同组合。
3. **生成规则写错会重复计数**：若既推 $(i+1,j)$ 又推 $(i,j+1)$，一个格子会被两条路径入堆，前 $k$ 小被重复计数，答案偏小。
4. **`i == 0` 判的是 `dp` 的下标**：它的含义是「当前最小的那个和 $dp[0]$ 所在的第 0 行」，不是「值最小的格子」，也不要改成比较 `s` 或 `dp[i]` 的大小。
5. **单行矩阵**：$m = 1$ 时答案就是该行第 $k$ 小的单个元素，因为 $p = 1$、$n$ 个候选直接排序截断，逻辑自动正确。
6. **Python 的堆元组比较**：`(sum, i, j)` 三元组在 `sum` 相等时会比较 `i`、`j`，不会抛异常；若改用 `(sum, (i,j))` 也等价，但别只存 `sum`。
7. **空间别开 $m \times n \times k$ 的表**：`dp` 只需滚动一行，逐行覆盖更新即可，否则 $40 \times 40 \times 200$ 虽可行但没必要。
