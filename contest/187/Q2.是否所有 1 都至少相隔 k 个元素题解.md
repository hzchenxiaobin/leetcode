# LeetCode 是否所有 1 都至少相隔 k 个元素 题解

## 1. 题目概述

- **标题 / 题号**：是否所有 1 都至少相隔 k 个元素（#1437，easy）
- **链接**：https://leetcode.cn/problems/check-if-all-1s-are-at-least-length-k-places-away/
- **来源**：LeetCode 第 187 场周赛 Q2
- **难度**：简单
- **标签**：数组

**题意**：给定只含 `0` 和 `1` 的数组 `nums` 与整数 `k`，判断是否任意两个 `1` 之间都至少夹着 `k` 个元素。把 `1` 的下标按序取出为 $p_1 < p_2 < \dots < p_m$，等价于要求每个相邻下标对满足 $p_{t+1} - p_t - 1 \ge k$；若 $m \le 1$ 则不存在任何一对，答案为 `true`。

**约束**：

- $1 \le \text{nums.length} \le 10^5$
- $0 \le k \le \text{nums.length}$
- $\text{nums}[i] \in \{0, 1\}$

> 💡 一句话定位：签到题。全部难点只有两处——把「相隔 $k$ 个元素」准确翻译成下标不等式 $p_{t+1} - p_t - 1 \ge k$（而不是 $p_{t+1} - p_t \ge k$），以及意识到**只需检查相邻的两个 `1`**。

## 2. 示例

**示例 1**

```text
输入：nums = [1,0,0,0,1,0,0,1]，k = 2
输出：true
解释：每个 1 都至少相隔 2 个元素。
      1 的下标为 0、4、7：
      4 − 0 − 1 = 3 ≥ 2 ✓
      7 − 4 − 1 = 2 ≥ 2 ✓
```

**示例 2**

```text
输入：nums = [1,0,0,1,0,1]，k = 2
输出：false
解释：第二个 1 和第三个 1 之间只隔了 1 个元素。
      1 的下标为 0、3、5：
      3 − 0 − 1 = 2 ≥ 2 ✓
      5 − 3 − 1 = 1 < 2 ✗  → 返回 false
```

**示例 3（补充，非官方）**

```text
输入：nums = [1,0,1]，k = 2
输出：false
解释：中间只夹着 1 个 0，1 < 2。
      注意下标差 2 − 0 = 2 恰好等于 k，若误用「下标差 ≥ k」会错判成 true。
```

## 3. 解题思路

### 3.1 暴力思路

按题面直译有三种写法，逐一看它们的代价（记 `1` 的个数为 $m$）：

1. **两两配对**：先收集所有 `1` 的下标，再对每一对 $(p_i, p_j)$ 检查 $p_j - p_i - 1 \ge k$，共 $\binom{m}{2}$ 对。全 `1` 数组时 $m = n = 10^5$，约 $5 \times 10^9$ 次比较，超时。
2. **向后探测 $k+1$ 格**：对每个 `1` 检查它后面 $k+1$ 个位置里是否还有 `1`。单次 $O(k)$，最坏 $O(nk)$，当 $k$ 与 $n$ 同阶时同样是 $10^{10}$ 量级。
3. **枚举所有位置对**：对每个 $i < j$ 判断是否同为 `1` 再数中间元素，$O(n^2)$，更差。

> ⚠️ 三种暴力犯的是同一个错：**同一段 `0` 被反复清点**。相邻两个 `1` 之间的间隙其实只依赖「上一个 `1` 在哪」，信息量只有 $O(1)$，却被重复扫描了成百上千次。

### 3.2 核心观察：只需检查相邻的 1

![核心观察：间隙 = 下标差 − 1，只需检查相邻的 1](images/wc187_q2_gap_rule.svg)

**关键洞察一（语义）**：「两个 `1` 相隔至少 $k$ 个元素」数的是**中间**的元素个数。下标 $i < j$ 之间的元素是 $i+1, \dots, j-1$，共 $j - i - 1$ 个，故要求

$$j - i - 1 \ge k \quad\Longleftrightarrow\quad j - i \ge k + 1$$

**关键洞察二（降维）**：设相邻间隙 $g_t = p_{t+1} - p_t - 1$。对任意非相邻对 $i < j$：

$$p_j - p_i - 1 = \sum_{t=i}^{j-1} g_t + (j - i - 1)$$

后一项 $(j-i-1)$ 是中间夹着的 `1` 的个数，恒 $\ge 1$；每个 $g_t$ 也 $\ge 0$。因此非相邻对的间隙**严格大于**路径上每一个 $g_t$——只要所有相邻对都满足 $g_t \ge k$，非相邻对自动满足。检查对数从 $\binom{m}{2}$ 降到 $m-1$。

**关键洞察三（常数空间）**：既然只关心相邻对，就不必存下标数组。扫描时只需记住**上一个 `1` 的下标** `prev`，遇到新 `1` 立即算间隙并判定，判定后刷新 `prev`。一趟 $O(n)$、额外 $O(1)$。

> 💡 这三步是「两两距离」型判定题的标准降维链：**先翻译语义 → 再用「相邻对充分」把 $\binom{m}{2}$ 对压成 $m-1$ 对 → 最后把「存下来再配对」改成「边扫边配对」**。

### 3.3 算法流程

![算法流程：一趟扫描，用 prev 哨兵记住上一个 1 的下标](images/wc187_q2_algorithm_flow.svg)

```text
prev ← −1                                   // 哨兵：还没遇到过 1
for i ← 0 to n−1:
    if nums[i] == 1:
        if prev ≠ −1 and i − prev − 1 < k:  // 与上一个 1 的间隙不足
            return false                    // 提前退出
        prev ← i                            // 首个 1、或通过判定的 1：刷新 prev
return true                                 // 没有 1 / 只有一个 1 / 全部通过
```

**`prev = −1` 哨兵的作用**：首个 `1` 没有前驱，本不该参与判定。哨兵让代码用同一个 `if` 同时表达「尚未见过 `1`」与「间隙不足」两种状态，省掉单独的特判分支；代价是判定条件多一个 `prev ≠ −1`。

> 💡 若嫌哨兵啰嗦，可换成「零计数法」：用 `zeros` 累计两个 `1` 之间 `0` 的个数，**初始化为 `k`**，遇 `1` 时检查 `zeros >= k` 再归零，遇 `0` 时自增。初始值 `k` 使首个 `1` 天然通过，等价于消掉哨兵（见 §4 第 5 条）。

### 3.4 示例演算

![示例演算：两个示例的 prev 与间隙逐行对照](images/wc187_q2_walkthrough.svg)

**示例 1**（`nums = [1,0,0,0,1,0,0,1]`，$k = 2$，`1` 在下标 0、4、7）：

| 遇到 `1` 于 `i` | `prev` | $i - \text{prev} - 1$ | 判定与动作 |
|-----------------|--------|------------------------|------------|
| 0 | — | — | 首个 `1`，直接通过，`prev ← 0` |
| 4 | 0 | 3 | $3 \ge 2$ ✓，`prev ← 4` |
| 7 | 4 | 2 | $2 \ge 2$ ✓，`prev ← 7` |

两对相邻间隙均达标，扫描正常结束，返回 `true`。

**示例 2**（`nums = [1,0,0,1,0,1]`，$k = 2$，`1` 在下标 0、3、5）：

| 遇到 `1` 于 `i` | `prev` | $i - \text{prev} - 1$ | 判定与动作 |
|-----------------|--------|------------------------|------------|
| 0 | — | — | 首个 `1`，直接通过，`prev ← 0` |
| 3 | 0 | 2 | $2 \ge 2$ ✓，`prev ← 3` |
| 5 | 3 | 1 | $1 < 2$ ✗，立即返回 `false` |

> 再验两个极端：$k = 0$ 时 `i - prev - 1 < 0` 永不成立（因 $i > \text{prev}$，间隙非负），任意排布都返回 `true`；全 `0` 数组遇不到 `1`，`prev` 始终为 $-1$，循环结束返回 `true`。两者都与题意一致。

## 4. 算法细节

1. **哨兵的取值**：`prev` 用 $-1$ 而不是 $0$——$0$ 是合法下标，无法区分「上一个 `1` 在下标 0」与「还没有 `1`」。判定条件写成 `prev != -1 && i - prev - 1 < k`，短路求值保证首个 `1` 不会用假前驱算间隙。
2. **间隙公式与等价变形**：$i - \text{prev} - 1$；也可整体移项写成 `i - prev < k + 1` 或 `i - prev >= k + 1`，三者在整数上完全等价。**不要**化简成 `i - prev >= k`，那会把要求放松一档（示例 3 的 `[1,0,1]`、$k=2$ 就会误判成 `true`）。
3. **更新 `prev` 的时机必须是判定之后**：若先 `prev = i` 再算间隙，间隙永远是 $-1$，判定恒通过，答案恒为 `true`。违规分支直接 `return false`，无需再更新 `prev`。
4. **提前返回**：一旦发现违规立即 `return false`，最坏扫完一趟 $O(n)$，最好 $O(1)$（如 `nums = [1,1]`、$k \ge 1$，第 2 个元素即返回）。不要用布尔累加器扫完整数组，会白丢剪枝。
5. **零计数法（等价实现）**：`zeros` 初始化为 `k`；遍历中遇 `0` 则 `zeros += 1`，遇 `1` 则先判 `zeros >= k`（不满足即返回 `false`），再把 `zeros` 归零。初始化取 `k` 使首个 `1` 必通过，从而消去 `prev != -1` 分支；两种写法逐元素等价（见 §5 引理 3）。
6. **不需要下标数组**：先收集 `m` 个下标再配对会多花 $O(m)$ 空间与一次完整遍历。只有需要**返回违规位置**时才值得存 `prev` 之外的信息，本题只返回布尔值。
7. **数值范围**：$n, k \le 10^5$，`int` 足够；且 $i > \text{prev}$ 保证 $i - \text{prev} - 1 \ge 0$，C++ 中不存在负数下溢问题，Python 更无此虑。
8. **循环外的返回值**：只有「从未返回 `false`」才会走到函数末尾，此处必须显式 `return true`；漏写会让函数在无返回值路径上产生未定义行为（C++）或返回 `None`（Python）。

## 5. 正确性证明

**引理 1（相邻对充分性）**：设 `1` 的下标为 $p_1 < p_2 < \dots < p_m$。若对每个 $1 \le t < m$ 都有 $p_{t+1} - p_t - 1 \ge k$，则对任意 $i < j$ 都有 $p_j - p_i - 1 \ge k$。

**证明**：把区间 $[p_i, p_j]$ 按中间的 `1` 分段，每段长度即为相邻间隙：

$$p_j - p_i - 1 = \sum_{t=i}^{j-1}\bigl(p_{t+1} - p_t - 1\bigr) + (j - i - 1) \ \ge\ (j-i)\,k + (j-i-1) \ \ge\ k$$

最后一个不等号用了 $j - i \ge 1$ 与 $j - i - 1 \ge 0$（$j \ge i+1$ 时后者非负）。故任意对的间隙都不小于 $k$。∎

**引理 2（扫描不变量）**：设算法在第 $i$ 轮循环结束后仍未返回。则：(a) 若 `nums[0..i]` 中有 `1`，`prev` 恰为其中最后一个 `1` 的下标，否则 `prev = -1`；(b) `nums[0..i]` 内所有相邻 `1` 的间隙都 $\ge k$。

**证明**：对 $i$ 归纳。$i = 0$ 时：若 `nums[0] == 1`，`prev` 被置为 $0$，正是最后一个 `1`，且区间内没有相邻对，(b) 空真；否则 `prev` 保持 $-1$，区间内无 `1`，(a)(b) 均成立。

设处理完 $i-1$ 后成立，考察第 $i$ 轮：若 `nums[i] == 0`，`prev` 不变，仍是 `[0, i-1]` 内最后一个 `1`，而 `[0, i]` 与 `[0, i-1]` 的 `1` 集合相同，(a)(b) 保持。若 `nums[i] == 1`，此前的 `prev` 是 `[0, i-1]` 内最后一个 `1`（或 $-1$）：当 `prev ≠ -1` 时，唯一新增的相邻对是 $(\text{prev}, i)$，其间隙 $i - \text{prev} - 1$ 恰为本轮检查值，未返回意味着它 $\ge k$，旧的相邻对不受影响，(b) 成立；当 `prev = -1` 时 `[0, i-1]` 内没有 `1`，本轮无新增相邻对。随后 `prev ← i` 使 (a) 成立。∎

**引理 3（零计数法与下标法等价）**：对任意 `nums` 与 `k`，零计数法返回 `true` 当且仅当下标法返回 `true`。

**证明**：两种写法都在「遇到 `1`」时做同一次判定、在判定通过后把状态重置。下标法的检查值 $i - \text{prev} - 1$ 与零计数法的 `zeros` 在每轮遇到 `1` 时取值相同：两者都从「上一个 `1` 之后」开始累加 `0` 的个数，且首个 `1` 前分别由 `prev = -1`（跳过判定）与 `zeros = k`（判定必通过）保证一致。故每次判定的真值相同，返回值相同。∎

**定理**：算法返回 `true` 当且仅当所有 `1` 两两至少相隔 $k$ 个元素。

**证明**：

- （⇐）设条件成立。由题意，每个相邻对都满足 $p_{t+1} - p_t - 1 \ge k$，于是算法在遇到 $p_{t+1}$ 时判定通过，扫描全程不返回 `false`，最终返回 `true`。
- （⇒）设算法返回 `true`，则扫描中从未触发 `return false`。由引理 2(b)，所有相邻 `1` 的间隙都 $\ge k$；再由引理 1，任意两个 `1` 的间隙也 $\ge k$，即条件成立。∎

**边界一致性**：当 `1` 的个数 $m \le 1$ 时不存在相邻对，引理 2(b) 空真，算法返回 `true`，与「没有两个 `1` 就没有违规」的语义一致。

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。每个元素恰好被访问一次，判定与赋值都是 $O(1)$；最坏扫完整个数组 $O(n)$，最好情形（如 `[1,1]`、$k \ge 1$）在第 2 个元素就返回，为 $O(1)$。
- **空间复杂度**：$O(1)$。只用到 `prev`、`i`（零计数法下是 `zeros`、当前元素）等常数个变量，不随 $n$ 增长；没有递归栈，也没有下标数组或哈希表。
- **下界说明**：最坏情况必须读完数组才能确认无违规（例如全 `0`，或所有间隙恰好等于 $k$），故 $O(n)$ 已是时间下界；额外空间 $O(1)$ 也是判定类问题的最优。

## 7. 参考代码

### C++

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    bool kLengthApart(vector<int>& nums, int k) {
        int prev = -1;                                // 哨兵：还没有遇到过 1
        for (int i = 0; i < (int)nums.size(); ++i) {
            if (nums[i] == 1) {
                if (prev != -1 && i - prev - 1 < k)   // 与上一个 1 的间隙不足 k 个元素
                    return false;                     // 提前剪枝
                prev = i;                             // 判定通过（或是首个 1）后刷新
            }
        }
        return true;                                  // 没有 1 / 只有一个 1 / 全部通过
    }
};
```

### Python

```python
from typing import List


class Solution:
    def kLengthApart(self, nums: List[int], k: int) -> bool:
        prev = -1                        # 哨兵：还没有遇到过 1
        for i, x in enumerate(nums):
            if x == 1:
                if prev != -1 and i - prev - 1 < k:
                    return False         # 提前剪枝
                prev = i                 # 判定通过（或是首个 1）后刷新
        return True                      # 没有 1 / 只有一个 1 / 全部通过
```

> 💡 两份代码是同一骨架：**维护 `prev` → 遇 `1` 算间隙 → 判定通过后刷新**。注意 `prev` 的赋值在 `if` 之内、判定之后，这是本题唯一容易写反的地方。

## 8. 边界情况与易错点

1. **$k = 0$**：要求退化为「间隙 $\ge 0$」，恒成立，任意数组都返回 `true`。代码中 $i - \text{prev} - 1 \ge 0 > -1$，故 `i - prev - 1 < 0` 永不成立，无需特判。
2. **全 `0` 或只有一个 `1`**：不存在相邻对，返回 `true`。此时 `prev` 保持 $-1$，`prev != -1` 分支从不进入——这也是哨兵必须用 $-1$ 的原因。
3. **两个 `1` 紧邻**（如 `nums = [1,1]`，$k \ge 1$）：间隙 $1 - 0 - 1 = 0 < k$，必须返回 `false`。这是最容易被「下标差」写法放过的一类数据。
4. **语义差一错误（头号 WA）**：把判定写成 $j - i \ge k$ 会少减 1。`nums = [1,0,1]`、$k = 2$ 时正确间隙是 1（$< 2$，`false`），而 $j - i = 2 \ge 2$ 会误判为 `true`。牢记：**间隙是中间元素个数，不含两端**。
5. **先刷新 `prev` 再判定**：顺序写反会让每次间隙都是 $-1$；而 $-1 < k$ 对一切 $k \ge 0$ 恒成立，于是判定永远放行，答案恒为 `true`——比漏掉边界更隐蔽，因为示例 1 照样能过。
6. **忘记循环外 `return true`**：只写了 `return false` 分支时会漏掉「全部通过」的返回值；C++ 中函数末尾没有 `return` 是未定义行为，Python 中会返回 `None`（判题按 `False` 处理）。
7. **$k$ 接近 $n$**：题面允许 $k$ 取到 $n$。两个 `1` 的间隙最大只能到 $n - 2$（`1` 分别落在下标 $0$ 与 $n-1$），所以只要 $k > n - 2$ 且数组里至少有两个 `1`，答案必为 `false`；只有一个 `1` 时仍返回 `true`。公式天然覆盖，无需额外判断。
8. **不要为「优化」先收集下标**：$O(m)$ 数组既增加空间又多做一次遍历；本题只返回布尔值，边扫边判即可。若题目改成「返回第一个违规对」，才需要在返回时把 `prev` 与 `i` 一起带出。
