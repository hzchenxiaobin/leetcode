# LeetCode 神奇字符串 题解

## 1. 题目概述

- **标题 / 题号**：神奇字符串（#481，medium）
- **链接**：https://leetcode.cn/problems/magical-string/
- **来源**：LeetCode 第 14 场周赛 Q2
- **难度**：中等
- **标签**：双指针、字符串

**题意**：只由 `1`、`2` 组成的字符串 `s` 满足「自描述」——把 `s` 切成极大的连续同字符段，把各段长度依次写出来拼成的数字串，恰好等于 `s` 本身。已知 `s = "1221121221221121122…"`，给定 `n`，求 `s` 前 `n` 位中 `1` 出现的次数。

**约束**：

- $1 \le n \le 10^5$
- `s` 只含 `1` 与 `2`，且首字符为 `1`

## 2. 示例

**示例 1**

```text
输入：n = 6
输出：3
解释：s 的前 6 位是 "122112"，其中 1 出现 3 次。
```

**示例 2**

```text
输入：n = 1
输出：1
解释：s[0] = '1'。
```

**示例 3（补充，用来看整串形态）**

```text
输入：n = 9
输出：4
解释：前 9 位 "122112122" 含 4 个 1；
      切段 1 | 22 | 11 | 2 | 1 | 22 | 1 | 22 ⇒ 段长 1 2 2 1 1 2 1 2，正是 s 的前缀。
```

## 3. 解题思路

### 3.1 暴力思路

朴素想法是「搜」一个满足自描述性质的串：枚举前 $n$ 位的所有 $2^n$ 种 `1/2` 组合，逐一求游程编码（RLE）看是否等于自身。$n = 10^5$ 时毫无希望，即便 $n = 30$ 也要检查约 $10^9$ 个候选。

另一条朴素路线是「不动点迭代」：从 `"1"` 出发，反复把当前串替换成它的 RLE。问题是不动点迭代并不保证收敛：从随手挑的种子出发可能来回震荡，也可能收敛到以 `2` 开头的另一支 Kolakoski 变体（`2, 2, 1, 1, 2, …`），拿不到题目指定的 `s`。

**关键困难**：`s` 的定义是自指的 —— 描述 `s` 的段长序列又是 `s` 自己。必须找到一种「边生成边读取、且读到的位一定已生成」的顺序。

### 3.2 核心观察：s[k] 同时是「第 k 个字符」和「第 k 段的长度」

![自描述：段长序列正好是 s 本身](images/wc14_q2_self_describing.svg)

把 `s` 切成极大段：`1 | 22 | 11 | 2 | 1 | 22 | 1 | 22 | …`，段长依次为 $1,2,2,1,1,2,1,2,\dots$。上图把两个序列逐位对齐：第二行（段长）与第一行（字符）完全相同 —— 这就是「自描述」。

由此得到两条硬约束：

1. **段长只能是 1 或 2**：段长序列就是 `s` 本身，而 `s` 只含 `1`、`2`，所以每段长度 $\in \{1,2\}$。
2. **相邻段的字符必然不同**：段是极大的，同字符相邻就会被合并；字母表只有 $\{1,2\}$，若上一段字符为 $c$，则下一段字符必为 $3-c$。

两条合起来意味着：知道「第 $k$ 段的长度」就决定了第 $k$ 段的全部内容，而第 $k$ 段的长度正是 $s[k]$。**只要 $s[k]$ 已经写在前面，第 $k$ 段就立刻确定。**

顺序上有天然保证：每段长度 $\ge 1$，所以第 $k$ 段的起点 $\sum_{j<k} s[j] \ge k$，即起点不早于下标 $k$。于是**从左往右逐段生成时，读 $s[k]$ 的那一刻，第 $k$ 位必定已经生成好了**。自指结构就此变成可以顺序执行的双指针扫描。

### 3.3 算法流程：读指针 i 追逐写指针

![双指针流程：读段长、定字符、追加](images/wc14_q2_two_pointers_flow.svg)

维护数组 `s`（写指针就是 `len(s)`）和读指针 `i`：

1. **种子**：`s = [1, 2, 2]`，`i = 2`。为什么至少要三位？第 1 段是两个 `2`，其长度 $s[1]$ 需要串已有第 2 位，而形成这段又需要这个长度，互为前提；`"122"` 是能自我展开的最短前缀。
2. **循环**（当 `len(s) < n`）：
   - 读段长 $L = s[i]$；
   - 新段字符 $c = 3 - s[-1]$（与上一段交替）；
   - 在末尾追加 $L$ 个 $c$；
   - `i += 1`。
3. **收尾**：统计 `s[0..n)` 中 `1` 的个数。

**不变量**：循环任意时刻都有 $i < \lvert s\rvert$。

- 初始：$i = 2 < 3 = \lvert s\rvert$；
- 每轮：$\lvert s\rvert$ 至少增加 1（因 $s[i] \ge 1$），而 $i$ 只加 1，差值 $\lvert s\rvert - i$ 不减。

因此读指针永远追不上写指针，**不存在越界读**；反过来每轮至少写 1 个字符，循环最多 $n$ 轮必然终止。

### 3.4 示例演算（n = 6）

![n = 6 的逐轮走查](images/wc14_q2_walkthrough.svg)

| 步骤 | `i` | `s[i]`（段长） | 新段字符 | 追加后 `s` | `len(s)` |
|---|---|---|---|---|---|
| 初始 | 2 | — | — | `122` | 3 |
| ① | 2 | 2 | 1 | `12211` | 5 |
| ② | 3 | 1 | 2 | `122112` | 6 |

第 ② 轮后 $\lvert s\rvert = 6 \ge n$，停止。`s[:6] = "122112"` 含 3 个 `1`，返回 3，与官方示例一致。

## 4. 算法细节

1. **种子必须是 `"122"`**：只用 `"1"` 时 `len(s) = 1`，`i = 2` 直接越界；用 `"12"` 则 $s[2]$ 未定义，无法给出第 2 段长度。`"122"` 让 $i = 2$ 时恰好有 $\lvert s\rvert = 3$，读得到 `s[2]`。
2. **用 `3 - s[-1]` 完成交替**：本质是 $1 \leftrightarrow 2$。C++ 若用 `std::string` 存字符，写成 `s.push_back(3 - s.back())` 会把整数 `1/2` 当 **ASCII 控制字符**写入，后面 `count` 永远数不到 `'1'`；必须写 `'3' - s.back()`（`'3' - '2' = 1`）或三目 `s.back() == '1' ? '2' : '1'`。本解用 `vector<int>` 存 `1/2`，从根上避开该坑。
3. **整段追加而非逐字符**：C++ 用 `s.insert(s.end(), s[i], nxt)`，Python 用 `s.extend([nxt] * s[i])`，一次成型，代码结构与「第 $k$ 段」的定义一一对应，可读性更好。
4. **计数必须截断到 $n$**：最后一轮追加可能把长度顶到 $n+1$，用整个数组计数就会多算一位。务必写 `s[:n].count(1)` 或循环 `k < n`。
5. **`n ≤ 3` 不需要特判**：种子已含 3 位，循环不进入，`s[:n]` 自然给出 `1`、`12`、`122`，答案都是 1。很多题解写 `if (n <= 3) return 1;`，那是在绕开「从 `"1"` 起步」的实现缺陷；用 `"122"` 打底即可省掉特判（保留也无害）。
6. **容量预留**：$\lvert s\rvert$ 最多涨到 $n+1$（每轮至少 +1，最后一次最多超 1 位），`reserve(n + 2)` 避免反复扩容。
7. **增量计数（可选）**：若在追加时只统计落在 $[0,n)$ 内的 `1`，可省掉收尾遍历；代价是要在追加时处理截断判断，可读性下降，而一次 $O(n)$ 遍历已经足够快。

## 5. 正确性证明

**引理 1（读指针安全）**：循环每轮开始时恒有 $i < \lvert s\rvert$，故 `s[i]` 可读。

**证明**：对轮数归纳。初始 $i = 2$、$\lvert s\rvert = 3$，成立。设某轮开始时 $i < \lvert s\rvert$，则能成功读出 $s[i] \ge 1$，该轮结束时 $\lvert s'\rvert = \lvert s\rvert + s[i] \ge \lvert s\rvert + 1 > i + 1 = i'$，不变量对下一轮仍成立。∎

**引理 2（段字符交替、段仍极大）**：设追加前最后一个已生成段的字符为 $c$，则新段的字符必为 $3 - c$；追加不会破坏已有各段的极大性。

**证明**：`s` 只含 `1`、`2`，相邻两个极大段的字符必然不同，故新段字符 $\ne c$，只能是 $3 - c$。已有各段的极大性只依赖「段内同字符、与前后相邻段字符不同」，而追加只发生在末尾，不改变前面任何字符，故前面各段仍是极大段；新段字符全为 $3 - c$，与前一段末字符不同，起点处断开正确。∎

**引理 3（段长与串自洽）**：第 $k$ 轮结束后，已生成串 `t` 中前 $k+1$ 个完整段的长度序列恰为 $t[0..k]$。

**证明**：对 $k$ 归纳。初始 `t = "122"` 的完整段长度为 $(1, 2)$，与 $t[0..1] = (1, 2)$ 一致。设 $k-1$ 轮后前 $k$ 段长度恰为 $t[0..k-1]$；第 $k$ 轮由引理 1 可读 $s[k]$，并以它作为长度追加第 $k$ 段，故第 $k$ 段长度 $= t[k]$，与前缀 $t[0..k]$ 一致。∎

**定理**：循环结束（$\lvert s\rvert \ge n$）时，`s[:n]` 就是神奇字符串的前 $n$ 位，返回值是其中 `1` 的个数。

**证明**：由引理 1 循环可执行；由引理 2、3，生成过程中「段长序列 = 串自身前缀」这一自描述性质始终成立，且每段长度只能取 1 或 2。再证唯一性：首段字符固定为 `1`，之后每段的字符由前一段唯一确定（引理 2），长度由 $s[k]$ 唯一确定，而 $s[k]$ 在生成第 $k$ 段时已确定，故按 $k = 0,1,2,\dots$ 归纳，整串逐位唯一。因此生成的前缀与题目给定的神奇字符串逐位相同，`s[:n]` 中 `1` 的计数即为所求。∎

**终止性**：每轮 $\lvert s\rvert$ 至少 +1，故至多 $n$ 轮后退出循环。

## 6. 复杂度分析

- **时间**：$O(n)$。读指针每轮 +1、写指针每轮至少 +1，故轮数 $\le n$；总共写入的字符数 $\le n+1$；收尾统计 $O(n)$。常数极小，$n = 10^5$ 时约 0.01 秒。
- **空间**：$O(n)$。只保存生成出的前缀（长度 $\le n+1$），无额外表结构；若在追加时增量计数，除整串外只需 $O(1)$ 额外空间 —— 但整串必须保留，因为段长要从串里读取。

## 7. 参考代码

### C++

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    int magicalString(int n) {
        vector<int> s = {1, 2, 2};         // 种子：神奇字符串的前三位
        s.reserve(n + 2);                  // |s| 最多涨到 n + 1
        int i = 2;                         // 读指针：s[i] 是下一段的长度
        while ((int)s.size() < n) {
            int nxt = 3 - s.back();        // 相邻两段字符必然不同：1 与 2 交替
            s.insert(s.end(), s[i], nxt);  // 追加一整段，长度由 s[i] 决定
            ++i;
        }
        int ans = 0;
        for (int k = 0; k < n; ++k) ans += (s[k] == 1);   // 只统计前 n 位
        return ans;
    }
};
```

### Python

```python
class Solution:
    def magicalString(self, n: int) -> int:
        s = [1, 2, 2]          # 种子：前三位
        i = 2                  # 读指针：s[i] 就是下一段的长度
        while len(s) < n:
            nxt = 3 - s[-1]    # 相邻两段字符必然不同，只能是 1 / 2 交替
            s.extend([nxt] * s[i])
            i += 1
        return s[:n].count(1)  # 截断到前 n 位再统计
```

## 8. 边界情况与易错点

1. **`n = 1` 必须返回 1 而不是 0**：若模仿某些题解把 `ans` 初始化为 0、又在循环里累加，忘记种子里那个 `1`，就会输出 0。
2. **`n ≤ 3` 循环体一次都不执行**：种子已含 3 位，代码要保证「不进循环」时仍能正确统计前 $n$ 位。
3. **最后一段会越过 $n$**：$n = 4$ 时第一轮就把长度顶到 5，$n = 5$ 时恰好到 5。多出来的那一位绝不能计入答案。
4. **种子别写成 `"1"`**：会让 $i = 2$ 越界（$\lvert s\rvert = 1$），是本题最常见的 RE / WA 来源。
5. **C++ 字符与数字混用**：`push_back(3 - s.back())` 写入的是 ASCII 码 1/2（不可见控制字符），`count` 数不到 `'1'`；必须 `'3' - s.back()`。
6. **Python 视图统一**：全程用 `list[int]` 存 `1/2`，避免 `int` 与 `str` 反复转换；若用 `str`，交替要写 `'2' if s[-1] == '1' else '1'`。
7. **多组询问**：本题单次调用；若同一进程内反复询问不同 $n$，应生成到最大的 $n$ 并缓存，否则每次都退化成 $O(n)$。
