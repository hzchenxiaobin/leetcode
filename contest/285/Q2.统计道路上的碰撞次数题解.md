# LeetCode 统计道路上的碰撞次数 题解

## 1. 题目概述

- **标题 / 题号**：统计道路上的碰撞次数（#2211，medium）
- **链接**：https://leetcode.cn/problems/count-collisions-on-a-road/
- **来源**：LeetCode 第 285 场周赛 Q2
- **难度**：中等
- **标签**：字符串、模拟、双指针、计数

**题意**：一条无限长的公路上有 $n$ 辆车，从左到右编号 $0 \sim n-1$，每辆车占据互不相同的位置。`directions[i]` 为 `'L'`、`'R'` 或 `'S'`，分别表示第 $i$ 辆车向左行驶、向右行驶、原地停留；所有移动的车**速度相同**。碰撞计分：两辆**方向相反**的移动车相撞 $+2$；一辆移动车撞上**静止**的车 $+1$。碰撞后涉事车辆停在碰撞位置、不再移动，且车不能改变状态或方向。返回碰撞总次数。

**约束**：

- $1 \le \text{directions.length} \le 10^5$
- `directions[i]` 的取值为 `'L'`、`'R'` 或 `'S'`

> 📚 本题在本仓库另有[每日题解 2211](../../solution/2201-2300/2211_统计道路上的碰撞次数.md)：以「剥离逃逸车 + 不变量计数」的**整体**视角展开，附栈模拟扩展与面试问答；本篇改从「**逐车命运判定**」的**个体**视角切入，补全引理-定理化的正确性证明与赛时边界复盘，两篇刻意互补。

> ⚠️ **读题信号**：两个题面短语直接决定解法形态——「**速度相同**」意味着同向车永不追尾（间距恒定），「**碰撞后停下**」意味着停车会变成墙、但墙被撞时**不再计分**。把计分规则翻译成"每辆车"的语言：**一次碰撞的得分 = 当时还在移动的涉事车辆数**。于是本题根本不必关心"谁先撞谁、在哪撞、何时撞"——只需判定每辆车**是否以移动状态参与过碰撞**，这恰好是一个纯静态的字符串问题。

## 2. 示例

**示例 1**

```text
输入：directions = "RLRSLL"
输出：5
解释：
  车 0 (R) 与车 1 (L) 反向对撞 → +2，两车停在原车 1 位置
  车 2 (R) 撞静止的车 3 (S) → +1
  车 4 (L) 撞已停下的车 2/3 残骸 → +1
  车 5 (L) 撞已停下的车 4 残骸 → +1
  合计 2 + 1 + 1 + 1 = 5
```

**示例 2**

```text
输入：directions = "LLRR"
输出：0
解释：前缀两辆 L 向左驶向 −∞，后缀两辆 R 向右驶向 +∞，
      同向同速互不追尾，整条路无人碰撞。
```

**示例 3（自造，覆盖同向追尾链）**

```text
输入：directions = "RRSLL"
输出：4
解释：车 1 (R) 撞车 2 (S) → +1；车 0 (R) 撞刚停下的车 1 → +1；
      车 3 (L) 撞车 2 (S) → +1；车 4 (L) 撞刚停下的车 3 → +1。
      注意：同向不追尾 ≠ 同向不碰撞——前方车一旦撞停，就成了后车的"墙"。
```

**示例 4（自造，覆盖双向逃逸）**

```text
输入：directions = "LLRSRR"
输出：1
解释：前缀 "LL" 与后缀 "RR" 全部逃逸；中间段 "RS" 里，
      车 2 (R) 撞车 3 (S) → +1。
```

## 3. 解题思路

### 3.1 暴力思路：逐事件物理模拟

最直观的做法是真正"演一遍"：维护每辆车的状态（方向 / 是否已停），反复找最先发生碰撞的相邻活动车对，结算（$+2$ 或 $+1$），把涉事车标记为停下，重复直到没有可碰撞的车对。

问题有两个：其一，链式场景（如 `"RRRR...S"`）会触发 $O(n)$ 次碰撞事件——最右的 R 先撞 S 停下，次右的 R 再撞这堵墙停下，逐个传递——每次找事件 $O(n)$，总计 $O(n^2)$，$n = 10^5$ 下不可行；其二，位置只是互异的实数（题目并未保证整数），按碰撞时刻排序、维护事件队列，实现繁琐且极易写错。

> ⚠️ 暴力法的病灶在「逐事件结算」——它把每条碰撞链展开成一串事件。突破口是发现**计数与顺序无关**：把计分口径换算到每辆车上，答案只依赖每辆车的最终命运。

### 3.2 核心观察：每辆车只有三种命运

先把计分规则翻译成"每辆车"的语言：

| 碰撞类型 | 涉事车状态 | 计分 | 当时在移动的车数 |
|----------|-----------|------|----------------|
| `R` ↔ `L` 反向对撞 | 两辆都在移动 | $+2$ | 2 |
| 移动撞静止（初始 `S` 或已停车） | 一动一静 | $+1$ | 1 |
| 同向行驶（都未停） | 两辆都在移动 | 不碰撞 | — |

**每辆以移动状态参与碰撞的车恰好贡献 $1$，静止方贡献 $0$**（对撞的两辆车各贡献 $1$，合计 $2$；撞静止墙的只有自己贡献 $1$）。于是：

$$\text{碰撞总次数} = \#\{\, i : \text{车 } i \text{ 以移动状态参与过碰撞}\,\}$$

再对每辆车逐一问"你会撞上谁"：

- **`S` 车**：永远静止，被撞时是静止方 → 贡献 $0$。
- **`L` 车**：向左行驶，只关心**左侧**——若左侧存在非 `L` 的车（`R` 或 `S`），最近的那个要么挡路（`S`）、要么迎面开来（`R`），途中形成的停车堆也只是新的墙，它**终将撞上** → 贡献 $1$；若左侧**全是 `L`**，同向同速、间距恒定，它属于**前缀 `L` 段**，整段向左逃逸 → 贡献 $0$。
- **`R` 车**：对称地只关心**右侧**——右侧存在非 `R`（`L` 或 `S`）→ 贡献 $1$；右侧全是 `R`（**后缀 `R` 段**）→ 向右逃逸，贡献 $0$。

![核心观察：前缀L逃逸、后缀R逃逸、中间段全部停下](images/wc285_q2_escape_concept.svg)

### 3.3 算法流程：逐车判定 → 剥壳一次扫描

逐车判定看上去要"回看"整条左侧 / 右侧，但两个等价性让它坍缩成双指针：

- "车 $i$ 左侧存在非 `L`" $\iff i \ge l$，其中 $l$ = 前缀 `L` 段的长度（首个非 `L` 下标）；
- "车 $i$ 右侧存在非 `R`" $\iff i \le r$，其中 $r$ = 末个非 `R` 下标。

于是算法只有三步：

1. 从左扫描跳过所有 `'L'`，得 $l$；从右扫描跳过所有 `'R'`，得 $r$；
2. 若 $l > r$（整串被前缀 `L` 与后缀 `R` 覆盖，如 `"LLRR"`、`"LLL"`、`"RRR"`），返回 $0$；
3. 统计中间段 $[l, r]$ 内 `directions[i] != 'S'` 的个数，即为答案。

![算法流程：逐车命运判定与剥壳等价](images/wc285_q2_car_fate_flow.svg)

### 3.4 示例演算

对示例 1 `"RLRSLL"`：前缀 `L` 0 辆（`l = 0`）、后缀 `R` 0 辆（`r = 5`），中间段 = 整串。逐车判定：车 0/1/2/4/5 各贡献 $1$（车 0 右侧有 `L`、车 1 左侧有 `R`、车 2 右侧有 `S`、车 4 左侧有 `R`、车 5 左侧有非 `L`），车 3 是 `S` 贡献 $0$，合计 $5$。

再用碰撞链反向印证——每结算一个事件，"累计计分"与"累计被停下的移动车数"始终相等：

| 事件 | 碰撞 | 计分 | 停下的移动车 | 累计计分 | 累计停下车 |
|------|------|------|-------------|---------|-----------|
| ① | 车 0 ↔ 车 1（对撞） | $+2$ | 车 0、车 1 | 2 | 2 |
| ② | 车 2 → 车 3（撞 `S`） | $+1$ | 车 2 | 3 | 3 |
| ③ | 车 4 → 停墙 | $+1$ | 车 4 | 4 | 4 |
| ④ | 车 5 → 停墙 | $+1$ | 车 5 | 5 | 5 |

![示例演算：RLRSLL 两种口径对照](images/wc285_q2_example_walkthrough.svg)

## 4. 算法细节

1. **$l$、$r$ 的定义与哨兵**：$l$ 为首个非 `'L'` 下标，整串全 `L` 时扫到 $l = n$；$r$ 为末个非 `'R'` 下标，全 `R` 时 $r = -1$。两个 `while` 的短路顺序（先判 `l < n` / `r >= 0` 再取下标）保证不越界；$l > r$ 自然涵盖所有"中间段为空"的情形，不需要特判。
2. **计数即答案**：中间段内 `ans += (directions[i] != 'S')`。`S` 车既可能被撞（贡献 $0$）也可能无人问津，但对答案无影响，无需区分。
3. **为什么无需关心碰撞顺序与时刻**：§5 引理 1 把每次计分绑定到"当时在移动的涉事车"，引理 2 保证每车至多以移动状态参与一次，二者都与事件的时间顺序无关——这是能把动态过程折叠成静态计数的关键。
4. **Python 一行版**：`directions.lstrip('L').rstrip('R')` 恰好得到中间段——`lstrip('L')` 去掉前缀所有 `L`（下标 $0..l-1$），`rstrip('R')` 去掉后缀所有 `R`（下标 $r+1..n-1$）。
5. **数据范围**：答案上界 $n \le 10^5$，32 位 `int` 足够，无需 `long long`。

## 5. 正确性证明

**引理 1（计分口径）**：任一次碰撞事件的计分等于该事件中**以移动状态参与**的车辆数。

**证明**：碰撞只发生在"移动车撞上某辆车"时。若被撞方也在移动，两车方向必相反（同向同速永不相遇，见引理 3 的 (⇒) 部分），按规则计 $+2$，涉事移动车恰 2 辆；若被撞方静止（初始 `S`，或此前碰撞后已停），计 $+1$，涉事移动车恰 1 辆。∎

**引理 2（一次贡献）**：每辆车至多以移动状态参与一次碰撞。

**证明**：车一旦以移动状态参与碰撞即被停下；此后它若再被撞，身份是静止方，由引理 1 不产生计分。∎

**推论（车辆计数口径）**：碰撞总次数 $= \#\{i : \text{车 } i \text{ 以移动状态参与过碰撞}\}$。

**证明**：把所有碰撞事件的计分求和。由引理 1，总和 $= \sum_{\text{事件}} (\text{该事件的移动涉事车数})$；由引理 2，每辆车跨事件至多被计一次，故该和恰等于以移动状态参与过碰撞的车辆总数。∎

**引理 3（`L` 车命运刻画）**：设 $d = \text{directions}$。`L` 车 $i$ 以移动状态参与碰撞 $\iff$ 存在下标 $j < i$ 使 $d[j] \in \{R, S\}$（即 $i$ 不在前缀 `L` 段内）。

**证明**：

- (⇐) 取满足条件的**最小** $j$，则 $d[j] \in \{R, S\}$ 且 $(j, i)$ 内全是 `L`。若 $d[j] = S$：$S$ 车静止于 $i$ 的行进路上；$(j,i)$ 内的 `L` 车要么先撞上它、要么互相之间同速不撞——无论谁先撞停，$i$ 前方有限距离内必然存在一个静止障碍（原 `S` 车或先停的车），$i$ 匀速向左终将撞上。若 $d[j] = R$：$j$ 车向右、$i$ 车向左，相向而行，即便它们中途各自撞上别的车停下，停车位置仍落在两者初始位置之间的有限区间内，即 $i$ 的行进路上；故 $i$ 前方有限距离内必有障碍，$i$ 终将以移动状态撞上。
- (⇒) 逆否：若 $i$ 左侧全是 `L`（$i$ 在前缀 `L` 段内），左侧所有车与 $i$ 同向同速，间距恒定，永不相遇；右侧的车或向右远离（`R`）、或静止但被 $i$ 逐渐远离（`S`）、或同向同速（`L`），均无法与 $i$ 相遇。故 $i$ 永不碰撞。∎

**引理 4（`R` 车命运刻画）**：`R` 车 $i$ 以移动状态参与碰撞 $\iff$ 存在下标 $j > i$ 使 $d[j] \in \{L, S\}$（即 $i$ 不在后缀 `R` 段内）。

**证明**：与引理 3 左右对称。∎

**定理**：设 $l = \min\{i : d[i] \neq L\}$（不存在则 $l = n$），$r = \max\{i : d[i] \neq R\}$（不存在则 $r = -1$）。若 $l > r$，答案为 $0$；否则答案 $= \#\{i \in [l, r] : d[i] \neq S\}$。

**证明**：由推论，答案 = 以移动状态参与过碰撞的车辆数。`S` 车恒贡献 $0$（引理 1）。对 `L` 车，由引理 3，其左侧存在非 `L` $\iff i \ge l$，故贡献 $1$ 恰为那些满足 $i \ge l$ 的 `L` 车；对 `R` 车，由引理 4，贡献 $1$ 恰为满足 $i \le r$ 的 `R` 车。

若 $l \le r$：前缀 `L` 段 $[0, l-1]$ 与后缀 `R` 段 $[r+1, n-1]$ 不相交（$l - 1 < r + 1$），贡献 $1$ 的车恰是中间段 $[l, r]$ 内的 `L`/`R` 车，求和即得。

若 $l > r$：每个下标要么属于前缀 `L` 段（左侧无非 `L`）、要么属于后缀 `R` 段（右侧无非 `R`）。若不然，存在 $i$ 满足 $d[i] \neq L$（故 $i \ge l$）且 $d[i] \neq R$（故 $i \le r$），与 $l > r$ 矛盾。于是由引理 3、4，所有 `L`/`R` 车均逃逸，加上 `S` 车贡献 $0$，答案为 $0$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。左指针扫前缀、右指针扫后缀、中间段计数，每个字符至多被访问 $3$ 次；`lstrip`/`rstrip` 版本同为线性。
- **空间复杂度**：$O(1)$。仅 `l`、`r`、`ans` 三个变量（Python `strip` 版本会产生中间字符串，为 $O(n)$，可改用下标版规避）。

## 7. 参考代码

### C++（双指针剥壳）

```cpp
class Solution {
  public:
    int countCollisions(string directions) {
        int n = directions.size();
        int l = 0, r = n - 1, ans = 0;
        while (l < n && directions[l] == 'L') ++l;   // 前缀 L：向左逃逸
        while (r >= 0 && directions[r] == 'R') --r;  // 后缀 R：向右逃逸
        for (int i = l; i <= r; ++i) {
            if (directions[i] != 'S') ++ans;         // 中间段每辆移动车贡献 1
        }
        return ans;
    }
};
```

### Python（一行剥壳版）

```python
class Solution:
    def countCollisions(self, directions: str) -> int:
        return sum(c != 'S' for c in directions.lstrip('L').rstrip('R'))
```

### Python（下标版，$O(1)$ 额外空间）

```python
class Solution:
    def countCollisions(self, directions: str) -> int:
        n = len(directions)
        l, r = 0, n - 1
        while l < n and directions[l] == 'L':
            l += 1
        while r >= 0 and directions[r] == 'R':
            r -= 1
        return sum(1 for i in range(l, r + 1) if directions[i] != 'S')
```

## 8. 边界情况与易错点

1. **整串逃逸（`l` 与 `r` 交叉）**：`"LLLL"`（$l = n$）、`"RRRR"`（$r = -1$）、`"LLRR"`（$l = 2 > r = 1$）都应返回 $0$。两个 `while` 的短路顺序写反（先取下标再判字符）会数组越界；交叉情形靠 `l > r` 自然处理，别再单独写特判。

2. **中间段全 `S`**：`"LSR"` 剥壳后中间段为 `"S"`，答案 $0$——`S` 车从不计分，别把它数进答案，也别因为"它被夹在中间"就误以为有碰撞。

3. **同向追尾链是最大的直觉陷阱**：`"RRRRS"` 答案是 $4$ 而不是 $1$。同向车**都在移动**时确实永不追尾，但最右的 `R` 撞停 `S` 后就成了墙，后方每辆 `R` 依次撞墙各 $+1$。判定口径下它们都不是后缀 `R`（右侧存在非 `R`），逐个贡献 $1$。

4. **对撞计 $+2$ 不是 $+1$**：`"RL"` 答案是 $2$——两辆移动车各贡献 $1$。若把"一次碰撞"当 $1$ 计，会把所有含对撞的用例算少。

5. **已停的车被再撞不重复计分**：示例 1 中车 3 被撞了两次（事件 ② ③ 各一次涉事），但它两次都是静止方，贡献恒 $0$；只有"以移动状态撞别人"才算分。

6. **前缀 `L` ≠ 任意 `L`**：`"LLRLL"` 中前缀两辆 `L` 逃逸，但中间段的 `L`（车 3、4）逃不掉——车 2 `R` 与车 3 对撞 $+2$，车 4 撞残骸 $+1$，加上车 2 共 $3$。"看到 `L` 就以为逃逸"是最常见的错误脑补。

7. **$n = 1$**：`"L"`、`"R"` 均无碰撞对象返回 $0$，`"S"` 返回 $0$，剥壳逻辑天然覆盖。

8. **无需 `long long`**：答案 $\le n \le 10^5$，`int` 裸算即可。

- 若允许**不同速度**（同向可追尾），碰撞时刻与顺序变得本质重要，需用事件堆按时间逐个结算，$O(n \log n)$。
- 若道路改为**环形**（无逃逸出口），前缀/后缀逃逸论证失效：只要环上同时存在 `R` 与 `L`（或存在 `S`），所有移动车终将停下，答案需按弧段重新推导——一个好的自测变体。
