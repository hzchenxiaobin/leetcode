# LeetCode 和为目标值的最大乘积对 题解

## 1. 题目概述

- **标题 / 题号**：和为目标值的最大乘积对（#4074，easy）
- **链接**：https://leetcode.cn/problems/maximum-product-pair-with-target-sum/
- **来源**：LeetCode 第 193 场双周赛 Q1
- **难度**：简单
- **标签**：数组、枚举、哈希表、数学

**题意**：给定整数数组 `nums` 和整数 `target`。下标不同的二元组 $(i, j)$ 满足 `nums[i] + nums[j] == target` 且 `nums[i] > nums[j]`（**严格**大于）时称为**有效**的。返回一个有效二元组 $[i, j]$，使乘积 $nums[i] \times nums[j]$ 在所有有效二元组中**最大**；不存在有效二元组时返回 `[-1, -1]`；有多个达到最大乘积的可返回任意一个。

**约束**：

- $2 \le \text{nums.length} \le 100$
- $-100 \le \text{nums[i]}, \text{target} \le 100$

## 2. 示例

**示例 1**

```text
输入：nums = [1,2,3,4], target = 5
输出：[2,1]
解释：有效二元组有 (3,0)：4+1=5、4>1、积 4；(2,1)：3+2=5、3>2、积 6。
乘积最大为 6，返回 [2,1]（注意大值的下标排在前面）。
```

**示例 2**

```text
输入：nums = [-3,-1,4,2], target = 1
输出：[3,1]
解释：有效二元组有 (2,0)：4×(−3) = −12；(3,1)：2×(−1) = −2。
乘积全是负数，最大的是 −2，返回 [3,1]。
```

**示例 3**

```text
输入：nums = [3,3,5], target = 6
输出：[-1,-1]
解释：3+3=6 但 3 不严格大于 3；5 又找不到 1 配对，无有效二元组。
```

## 3. 解题思路

### 3.1 直接做法：双重循环枚举所有下标对

签到题的最短路径：$n \le 100$，下标对至多 $\binom{100}{2} = 4950$ 个，双重循环逐一检查「和为 $T$」与「两值不等」，维护最大乘积即可。$O(n^2)$ 完全够用，不需要任何优化——这题比拼的是**读题仔细度**而不是算法。

### 3.2 核心观察：定和抛物线——和固定时，两数越接近乘积越大

![定和抛物线：P(x)=x(T−x) 关于 x=T/2 对称，右半支递减](images/bw193_q1_parabola.svg)

所有有效二元组的两数之和都等于 $T = \text{target}$。设较大数为 $x$、较小数为 $y$，则 $x + y = T$，乘积是 $x$ 的二次函数：

$$P(x) = x(T - x) = -\left(x - \frac{T}{2}\right)^2 + \frac{T^2}{4}$$

开口向下、对称轴为 $x = T/2$。由 $x > y$ 知 $x > T/2$，即 $x$ 落在**右半支的递减段**——$x$ 越靠近 $T/2$（两数之差越小），乘积越大。例如 $T = 5$ 时 $(3,2) \to 6$ 胜过 $(4,1) \to 4$；顶点值 $T^2/4$ 对应 $x = y$，被「严格大于」排除，永远取不到。

这给出两点启示：

1. **直接比较乘积大小即可**，无需借助差值等中间量；
2. 用哈希表维护「值 → 下标」，对每个元素 $O(1)$ 查补数 $T - x$，可把整体优化到 $O(n)$（见延伸思考）。

### 3.3 算法流程

1. 初始化 $\text{best} = -\infty$，$\text{ans} = [-1, -1]$。
2. 枚举所有下标对 $0 \le a < b < n$：
   - 若两数之和不等于 $T$，跳过；
   - 若两值相等（不满足严格大于），跳过；
   - 令 $p$ 为两数乘积，若 $p > \text{best}$，更新 $\text{best} = p$，并把**大值下标排在前面**记入答案。
3. 返回 $\text{ans}$。

### 3.4 示例演算

![示例 1：枚举下标对，两个和为 5 的对里选乘积大的](images/bw193_q1_valid_pairs.svg)

示例 1 中 6 个下标对里只有 $(3,0)$ 与 $(2,1)$ 的和为 5，乘积分别为 4 与 6，取后者返回 $[2,1]$。

![示例 2：乘积全为负数，best 必须从 −∞ 起步](images/bw193_q1_negative_product.svg)

示例 2 是本题最大的坑：两个有效对的乘积 $-12$、$-2$ **全是负数**，若 `best` 从 0 起步将一个都记不下，误返回 `[-1,-1]`。

## 4. 算法细节

- 枚举时固定 $a < b$，命中后按**值**定向输出：`nums[a] > nums[b]` 输出 $[a, b]$，否则输出 $[b, a]$；两值不相等保证二者恰居其一。
- `best` 初始化为 $-\infty$（C++ 用 `INT_MIN` 即可，本题乘积 $\ge -10^4$），用严格大于 `p > best` 更新，天然保留首个最大对，符合「任意返回一个」的约定。
- 乘积范围：$|\,\text{nums[a]} \times \text{nums[b]}\,| \le 100 \times 100 = 10^4$，`int` 无溢出风险。

## 5. 正确性证明

**引理**：若 $x > y$ 且 $x + y = T$，则 $x > T/2$，且 $P(x) = x(T - x)$ 在 $(T/2, +\infty)$ 上严格递减。

**证明**：$x > y$ 与 $x + y = T$ 联立得 $2x > T$，即 $x > T/2$。又 $P'(x) = T - 2x < 0$ 在 $x > T/2$ 时恒成立，故 $P$ 在右半支严格递减。∎

**定理**：双重循环枚举所有下标对、维护最大乘积并按「大值在前」输出，算法返回某个乘积最大的有效二元组；无有效对时返回 $[-1, -1]$。

**证明**：每个无序下标对 $\{a, b\}$ 恰被枚举一次；它是有效对当且仅当和为 $T$ 且两值不等，此时按值定向后与题面定义的 $(i, j)$（$nums[i] > nums[j]$）一一对应，故枚举完整覆盖全部有效二元组。`best` 初值为 $-\infty$，任何整数乘积都严格大于它，因此只要存在有效对就必被记录；`p > best` 的严格比较保留首个达到最大值的对，符合「任意返回」的约定。若无有效对，`best` 保持 $-\infty$，返回初始值 $[-1, -1]$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n^2)$。$n \le 100$，至多 4950 次常数时间的判断。
- **空间复杂度**：$O(1)$。仅常数个变量（不含返回值）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> maxProductPair(vector<int>& nums, int target) {
        int n = nums.size();
        int best = INT_MIN;
        vector<int> ans = {-1, -1};
        for (int a = 0; a < n; ++a) {
            for (int b = a + 1; b < n; ++b) {
                if (nums[a] + nums[b] != target || nums[a] == nums[b]) continue;
                int p = nums[a] * nums[b];
                if (p > best) {
                    best = p;
                    if (nums[a] > nums[b]) ans = {a, b};
                    else ans = {b, a};
                }
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maxProductPair(self, nums: list[int], target: int) -> list[int]:
        n = len(nums)
        best = -inf
        ans = [-1, -1]
        for a in range(n):
            for b in range(a + 1, n):
                if nums[a] + nums[b] != target or nums[a] == nums[b]:
                    continue
                p = nums[a] * nums[b]
                if p > best:
                    best = p
                    ans = [a, b] if nums[a] > nums[b] else [b, a]
        return ans
```

## 8. 边界情况与易错点

1. **乘积为负**（本场最大坑）：示例 2 的最佳乘积是 $-2$，`best` 必须初始化为 $-\infty$；初始化为 0 会把所有负乘积对全部漏掉，误返回 `[-1,-1]`。
2. **严格大于**：`nums[i] > nums[j]` 是严格不等式，两值相等（如 $[3,3]$ 和为 6）不构成有效对，对应示例 3。
3. **返回顺序**：返回 `[大值下标, 小值下标]`，不是下标小的在前；枚举 $a < b$ 时记得按值定向输出。
4. **无解返回值**：两个分量都是 $-1$。
5. **溢出**：$|\text{乘积}| \le 10^4$，`int` 安全，无需 `long long`。
