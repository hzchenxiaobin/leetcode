# LeetCode 一个小组的最大实力值 题解

## 1. 题目概述

- **标题 / 题号**：一个小组的最大实力值（#2708，medium）
- **链接**：https://leetcode.cn/problems/maximum-strength-of-a-group/
- **来源**：LeetCode 第 105 场双周赛 Q3
- **难度**：中等
- **标签**：贪心、数组、排序、动态规划、枚举

**题意**：整数数组 `nums` 表示学生成绩。选一个**非空**下标子集组成小组，小组的**实力值**等于组内所有 `nums[i]` 的乘积。求能取得的最大实力值。

**约束**：

- $1 \le nums.length \le 13$
- $-9 \le nums[i] \le 9$

## 2. 示例

**示例 1**

```text
输入：nums = [3,-1,-5,2,5,-9]
输出：1350
解释：选下标 [0,2,3,4,5]，实力值 = 3 × (−5) × 2 × 5 × (−9) = 1350。
```

**示例 2**

```text
输入：nums = [-4,-5,-4]
输出：20
解释：选下标 [0,1]，实力值 = (−4) × (−5) = 20；三个全选是 −80，两个 −4 相乘只有 16。
```

**示例 3（边界补充）**

```text
输入：nums = [-9]
输出：-9
解释：小组必须非空，唯一的元素再差也得选，答案是负数。
```

## 3. 解题思路

### 3.1 暴力思路

$n \le 13$，枚举全部 $2^{13} - 1 = 8191$ 个非空子集、逐个求乘积取最大，$O(n \cdot 2^n)$ 毫秒级通过。这是本题的保底解法，比赛时先写暴力再想贪心是稳妥策略；但 $n$ 一旦放到几十，指数解法立刻失效，需要看清楚乘积的结构。

### 3.2 核心观察：按绝对值分桶，负数管符号，−1 免费纠错，0 是毒药

![元素分桶：大元素决定量级，−1 是免费的翻号工具，0 与 1 各有分工](images/bw105_q3_sign_cases.svg)

乘积的**绝对值**只由 $|x| \ge 2$ 的"大元素"决定——每多乘一个，绝对值至少翻倍；$1$ 不改变乘积，$0$ 会把一切清零，$-1$ 绝对值为 1、专门用来**翻符号**。于是把元素分三类讨论：

- **大元素**（$|x| \ge 2$）：能选尽选。选出的大元素乘积记为 $P$（带符号）。
- **负号个数**：若 $P$ 的负号个数为**偶**，直接取 $|P|$；为**奇**，想办法翻回正号——**借一个 $-1$ 乘进去是免费的**（绝对值不变、只翻符号）；没有 $-1$ 可借时，**弃掉绝对值最小的那个负大数**（损失最小的因子换取正号）。
- **无大元素的小世界**：元素全在 $\{-1, 0, 1\}$ 里。有 $1$（或至少两个 $-1$ 相乘）则答案为 $1$；否则有 $0$ 选 $0$；再否则只剩一个孤零零的 $-1$，答案为 $-1$。

### 3.3 算法流程（分类决策）

![决策流程：五步分类讨论，覆盖所有符号组合](images/bw105_q3_decision_flow.svg)

```text
1. 扫描一遍：大元素（|x| ≥ 2）累乘得 P，统计其中负数个数 bigNeg，
   记录绝对值最小的负大数 minAbsNeg；另记 negOne（−1 的个数）、hasOne、hasZero
2. 若没有大元素：
       有 1 或 negOne ≥ 2 → 1；有 0 → 0；否则 → −1（此时 nums 必为 [−1]）
3. 若 bigNeg 为偶数 → |P|
4. 若 bigNeg 为奇数：
       有 −1 → |P|（借一个翻正，绝对值不损）
       无 −1 且大元素 ≥ 2 个 → |P| / minAbsNeg（弃最小绝对值负大数）
       无 −1 且唯一大元素是负数 → 有 1 取 1，有 0 取 0，否则返回该负数本身
```

### 3.4 示例演算

![示例演算：偶负号直取、奇负号弃最小](images/bw105_q3_walkthrough.svg)

| 示例 | 大元素 | $P$ | 负号数 | 决策 | 答案 |
|------|--------|-----|--------|------|------|
| 1 | $3,-5,2,5,-9$ | $1350$ | 2（偶）| 直取 $|P|$；$-1$ 不选（选了变 $-1350$） | 1350 |
| 2 | $-4,-5,-4$ | $-80$ | 3（奇）| 无 $-1$ 可借，弃一个 $-4$：$|-5 \times -4| = 80/4$ | 20 |

示例 2 中弃 $-5$ 只会得到 $|-4 \times -4| = 16 < 20$——**弃掉的一定是绝对值最小的负数**，损失因子最小。

## 4. 算法细节

1. **"借 $-1$" 优先于 "弃负数"**：借 $-1$ 绝对值零损失（$|{-1}| = 1$），弃负大数至少损失因子 2，顺序不能颠倒。如 `[2, -3, -1]`：$P = -6$ 奇负，借 $-1$ 得 $6$，优于弃 $-3$ 得 $2$。
2. **弃负数时取绝对值最小者**：若弃出多个负数（奇数个），损失因子为各绝对值之积 $\ge 2$，而弃一个最小者只损失 $\min$；详细比较见证明引理 3。
3. **$0$ 的角色**：含 $0$ 时任何包含 $0$ 的组实力为 $0$，所以 $0$ 只在"没有更好的选择"时兜底——如 $[0, -1]$ 的最优是 $\{0\} \to 0$ 而不是 $\{-1\} \to -1$。
4. **$1$ 的角色**：不改变乘积，但能保证小组**非空**：如 $[1, -9]$ 中弃掉唯一的负大数后，靠 $\{1\}$ 拿到 $1 > 0 > -9$。
5. **唯一大数是负数且无 $-1$ 无 $1$ 无 $0$**：说明 `nums` 里只有这一个元素，答案就是它本身（负数）——这是答案为负的唯一情形。
6. **乘积量级**：$|P| \le 9^{13} \approx 2.5 \times 10^{12}$，超出 `int` 范围，C++ 必须用 `long long`（metaData 返回类型也是 `long`）。
7. **暴力对拍**：$n \le 13$ 恰好让 $O(2^n)$ 暴力可用——写完贪心后拿暴力对拍是这类"分类讨论易漏"题的救命稻草。

## 5. 正确性证明

**引理 1（量级上界）**：任意非空子集乘积的绝对值 $\le \prod_{|x| \ge 2} |x|$，等号可在"选出全部大元素"时达到。

**证明**：子集乘积绝对值 $= \prod_{x \in S} |x|$。把 $S$ 中的 $1$ 与 $-1$ 贡献的因子 $1$ 删去不减小乘积；把 $S$ 中缺的大元素补进来，因子 $\ge 2$，乘积不减小；若 $S$ 含 $0$ 则乘积为 $0 \le$ 右端。故上界成立，且取全部大元素（不含 $0$）时恰取等。∎

**引理 2（符号修复的代价）**：设选出的大元素乘积 $P < 0$。则存在非空子集乘积为正，当且仅当（a）数组中存在 $-1$，或（b）大元素至少 2 个（弃一个负大数后仍非空可补），或（c）存在 $1$ 或 $0$。且正数乘积的最大值为：

- 情形 (a)：$|P|$；
- 情形 (b)：$\max_{\text{负大数 } x} |P| / |x| = |P| / \min|\text{负大数}|$；
- 情形 (c)：$\max(1 \text{（若有 } 1),\ 0) \ge 0$ 中的较大者。

**证明**：(a) 在全大元素组里添一个 $-1$，乘积翻为 $|P|$；由引理 1 它已是全体子集的正乘积上界，故最优。(b) 要得到正号且不借助 $-1$，选中的负数个数必为偶。设弃掉的负大数集合为 $D$（须含奇数个负数），乘积为 $|P| / \prod_{x \in D} |x|$。若 $|D| = 1$，取 $|x|$ 最小者最优；若 $|D| \ge 3$，注意 $\prod_{x \in D} |x| \ge 2 \cdot 2 \cdot 2 = 8$，而 $\min|{\text{负大数}}| \le 9$：若最小绝对值 $m \le 8$ 则 $8 \ge m$，弃单最小更优；若 $m = 9$ 则所有负大数均为 $9$，$|D| \ge 3$ 时分母 $\ge 9^3 > 9 = m$，弃单最小仍更优。故弃一个绝对值最小的负大数全局最优。弃完后剩余大元素个数 $\ge 1$（大元素 $\ge 2$ 且只弃一个），非空保证成立。(c) 无 $-1$ 时若大元素仅 1 个且为负，任何含它的子集乘积为负，正解只能来自 $\{1\}$（乘积 1）或 $\{0\}$（乘积 0），取较大者；两者皆无则不存在正数（或零）子集，见定理中对负数情形的讨论。∎

**定理**：按 §3.3 分类返回的值等于最大实力值。

**证明**：**存在大元素时**：候选最优值不外乎——$|P|$（需偶负号或借到 $-1$）、$|P|/\min|\text{负大数}|$（奇负号、无 $-1$、弃一换正）、$1$、$0$、单个负大数、或含负号的负乘积。由引理 1，任何子集 $|\text{乘积}| \le |P|$，故正的最优解若可达必为引理 2 列出的三档；分类逻辑恰好按此优先级返回：偶负号（或借 $-1$）时 $|P| \ge 2$；奇负号无 $-1$ 且多大大元素时 $|P|/\min \ge 2$（剩余大元素仍至少一个、因子 $\ge 2$）；唯一负大元素时比较 $1 > 0 > \text{负数}$ 返回最大可行者。负乘积候选恒小于上述非负候选，不影响最大值。**无大元素时**：所有子集乘积绝对值 $\le 1$，可能取值为 $1$（全 $1$ 或偶数个 $-1$）、$0$、$-1$，按 $1 > 0 > -1$ 的优先序返回首个可达者即最大值；三者皆不可达仅当 `nums = [-1]`，返回 $-1$ 正确。∎

## 6. 复杂度分析

- **时间**：$O(n)$，一次扫描完成分桶统计与分类决策（若先排序再讨论则为 $O(n \log n)$，非必需）。
- **空间**：$O(1)$，仅若干计数器与乘积累加器。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long maxStrength(vector<int>& nums) {
        long long p = 1;                    // 所有 |x| >= 2 的元素之积（带符号）
        int bigCnt = 0, bigNeg = 0, negOne = 0;
        bool hasOne = false, hasZero = false;
        int minAbsNeg = 10;                 // 大元素中绝对值最小的负数
        for (int x : nums) {
            if (x == 1) hasOne = true;
            else if (x == 0) hasZero = true;
            else if (x == -1) ++negOne;
            else {                          // |x| >= 2
                ++bigCnt;
                p *= x;
                if (x < 0) { ++bigNeg; minAbsNeg = min(minAbsNeg, -x); }
            }
        }
        if (bigCnt == 0) {                  // 元素全部落在 {-1, 0, 1}
            if (hasOne || negOne >= 2) return 1;
            if (hasZero) return 0;
            return -1;                      // 此刻 nums 必为 [-1]
        }
        if (bigNeg % 2 == 0) return llabs(p);
        if (negOne > 0) return llabs(p);    // 再乘一个 -1 翻回正号，乘积不变
        if (bigCnt >= 2) return llabs(p) / minAbsNeg;  // 弃绝对值最小的负数
        // 唯一的 big 是个负数且没有 -1 可借：只能靠 1 / 0 / 它自己
        if (hasOne) return 1;
        if (hasZero) return 0;
        return p;                           // nums 恰为 {该负数}
    }
};
```

### Python

```python
class Solution:
    def maxStrength(self, nums: List[int]) -> int:
        p, big_cnt, big_neg, neg_one = 1, 0, 0, 0
        has_one = has_zero = False
        min_abs_neg = 10                   # 大元素中绝对值最小的负数
        for x in nums:
            if x == 1:
                has_one = True
            elif x == 0:
                has_zero = True
            elif x == -1:
                neg_one += 1
            else:                          # |x| >= 2
                big_cnt += 1
                p *= x
                if x < 0:
                    big_neg += 1
                    min_abs_neg = min(min_abs_neg, -x)
        if big_cnt == 0:                   # 元素全部落在 {-1, 0, 1}
            if has_one or neg_one >= 2:
                return 1
            if has_zero:
                return 0
            return -1                      # 此刻 nums 必为 [-1]
        if big_neg % 2 == 0:
            return abs(p)
        if neg_one:                        # 再乘一个 -1 翻回正号
            return abs(p)
        if big_cnt >= 2:
            return abs(p) // min_abs_neg   # 弃绝对值最小的负数
        # 唯一的 big 是个负数且没有 -1 可借：只能靠 1 / 0 / 它自己
        if has_one:
            return 1
        if has_zero:
            return 0
        return p                           # nums 恰为 {该负数}
```

## 8. 边界情况与易错点

1. **小组必须非空**：这是本题最大的坑。全零数组 `[0,0]` 答案是 $0$（选一个 0），`[-9]` 答案是 $-9$——"乘积最大"不等于"可以为正"。
2. **答案为负的唯一情形**：`nums = [x]`（单个负数）。分类里"唯一大元素是负数且无 $1$/$0$/$-1$"分支要兜住它。
3. **借 $-1$ 分支**：`[-9, -1]` 答案是 $9$ 而不是 $-9$——看到负号个数为奇，先查有没有 $-1$，再考虑弃数。
4. **弃多个负数不一定更好**：$[-9, -2, -2]$ 中 $P = -36$，弃一个 $-2$ 得 $18$；若误以为"弃三个负数更好"就错了——弃的因子越多损失越大，只需保证负号变偶。
5. **溢出**：$9^{13} \approx 2.5 \times 10^{12}$，C++ `int` 会溢出，务必 `long long`；Python 无碍但除法要用整除 `//` 保持整数。
6. **`minAbsNeg` 初值**：设 10（大于值域上界 9）即可当 $+\infty$；只要 `bigNeg > 0` 它必被真实值更新。
7. **与"子序列最大乘积"DP 的关系**：$n$ 更大时标准做法是维护"以 $i$ 结尾的最大/最小乘积"双 DP（负数会让最大最小互换），$O(n)$ 无需分类——但本题 $n \le 13$ 且值域含 $0$，分类讨论版更短更快，双 DP 版则更通用，值得都写一遍。
