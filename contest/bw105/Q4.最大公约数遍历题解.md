# LeetCode 最大公约数遍历 题解

## 1. 题目概述

- **标题 / 题号**：最大公约数遍历（#2709，hard）
- **链接**：https://leetcode.cn/problems/greatest-common-divisor-traversal/
- **来源**：LeetCode 第 105 场双周赛 Q4
- **难度**：困难
- **标签**：并查集、数组、数学、数论、质因数分解

**题意**：给定整数数组 `nums`。下标 $i$ 与 $j$（$i \ne j$）之间**可以直接通行**当且仅当 $\gcd(nums[i], nums[j]) > 1$。问：对**任意**满足 $i < j$ 的下标对，都能经过若干次通行从 $i$ 走到 $j$ 吗？可以返回 `true`，否则 `false`。

**约束**：

- $1 \le nums.length \le 10^5$
- $1 \le nums[i] \le 10^5$

## 2. 示例

**示例 1**

```text
输入：nums = [2,3,6]
输出：true
解释：0→2（gcd(2,6)=2）、2→1（gcd(6,3)=3）均有直接通行，任意两点连通。
```

**示例 2**

```text
输入：nums = [3,9,5]
输出：false
解释：{3,9} 与 {5} 之间没有任何 gcd > 1 的边，0 到 2 无法到达。
```

**示例 3**

```text
输入：nums = [4,3,12,8]
输出：true
解释：4—12、8—12、3—12 等边把所有下标连成一团。
```

**示例 4（边界补充）**

```text
输入：nums = [1]
输出：true
解释：没有满足 i < j 的下标对，空口成立，直接返回 true。
```

## 3. 解题思路

### 3.1 暴力思路

把每个下标当节点，所有 $\gcd > 1$ 的下标对连边，再 BFS/并查集判连通。但边数是 $O(n^2)$：$n = 10^5$ 时要算约 $5 \times 10^9$ 次 $\gcd$，每次 $O(\log V)$——无论连边还是判连通都远超时限。必须想办法把"两两之间才出现的公共质因数"改写成**每个数各自独立贡献**的结构。

### 3.2 核心观察：gcd(a,b) > 1 ⟺ 共享质因数 ⟺ 与同一个质数相连

![核心观察：数值-质因数二部图，[2,3,6] 连成一团而 [3,9,5] 断成两截](images/bw105_q4_prime_graph.svg)

由算术基本定理，$\gcd(a, b) > 1$ 当且仅当 $a$ 与 $b$ **有至少一个公共质因数** $p$（$p$ 同时整除两者）。于是引入一个中间层——**质数节点**：

- 把每个数值 $x$ 与它的每个**质因数** $p$ 连一条边（即 `union(x, p)`）；
- 两个数值 $a, b$ 有直接边 ⟺ 存在质数 $p$ 同时与 $a$、$b$ 相连。

这样"数值—数值"的 $O(n^2)$ 条潜在边，被压缩成每个数 $O(\log x)$ 条"数值—质因数"边（一个 $\le 10^5$ 的数至多 6 个不同质因数，因为 $2 \cdot 3 \cdot 5 \cdot 7 \cdot 11 \cdot 13 = 30030 \le 10^5 < 510510$）。连通性在两种图上**完全等价**（证明见 §5），所以只需判"所有数值是否落在同一连通块"。

**特判**：数值 $1$ 没有任何质因数，它与谁都无公共质因数（$\gcd(1, x) = 1$）。因此 $n \ge 2$ 时数组含 $1$ 必然 `false`；$n = 1$ 时没有下标对，恒 `true`。

### 3.3 算法流程：最小质因数筛 + 并查集

![算法流程：SPF 筛建表、逐数分解连边、判同根](images/bw105_q4_sieve_flow.svg)

```text
1. 若 n = 1：返回 true；若数组含 1（此时 n ≥ 2）：返回 false
2. 对值域 V = max(nums) 建"最小质因数"表 spf[]（埃氏筛变体）：
       i 从 2 到 V：若 spf[i] 尚未标记，则 i 是质数，
       把 i 的所有未标记倍数 j 记 spf[j] = i
3. 并查集初始化 fa[v] = v（v ∈ [0, V]）
4. 对每个 x = nums[i]：
       cur = x
       循环：p = spf[cur]，union(x, p)，然后把 cur 中的 p 除干净，直到 cur = 1
5. 返回 find(nums[i]) 是否全等于 find(nums[0])
```

### 3.4 示例演算

![示例演算：4,3,12,8 的质因数连边与连通判定](images/bw105_q4_walkthrough.svg)

以示例 3（`nums = [4,3,12,8]`）演算连边过程：

| $x$ | 分解 | 连边 |
|-----|------|------|
| 4 | $2^2$ | $4 \leftrightarrow 2$ |
| 3 | $3$（质数）| $3 \leftrightarrow 3$ |
| 12 | $2^2 \times 3$ | $12 \leftrightarrow 2$，$12 \leftrightarrow 3$（桥梁）|
| 8 | $2^3$ | $8 \leftrightarrow 2$ |

质数 $2$、$3$ 把四个数值全部串进一个连通块，返回 `true`。对照示例 2（`[3,9,5]`）：$3 \leftrightarrow 3$、$9 \leftrightarrow 3$、$5 \leftrightarrow 5$，形成 $\{3, 9\}$ 与 $\{5\}$ 两块，返回 `false`。

## 4. 算法细节

1. **为什么筛 spf（最小质因数）而不是普通埃氏筛**：普通筛只回答"是不是质数"，而分解需要"任意合数的一个质因数"。`spf[x]` 每用一次就把 $x$ 至少除掉一个 $\ge 2$ 的因子，因此单数分解 $O(\log x)$；用试除法（拿 $\le \sqrt{x}$ 的质数逐个试）也能做，但每个数 $O(\sqrt{x}/\log)$ 次，$n = 10^5$ 时慢一个量级。
2. **筛的写法**：`spf` 初始全 0；`i` 从 2 升序扫描，`spf[i] == 0` 说明 `i` 没被更小的质数标记过，即 `i` 是质数，随后从 `j = i` 开始以步长 `i` 上扫，只给"尚未标记"的位置写 `spf[j] = i`——先到先得保证了写入的恰是**最小**质因数。总代价 $\sum_{p \le V} V/p = O(V \log\log V)$。
3. **"除干净"防重复**：同一个质因数（如 $12 = 2^2 \times 3$ 的两个 2）只连一次边就够了；`while (cur % p == 0) cur /= p` 跳过重复幂次，`union` 重复调用虽不致错但浪费。
4. **值域自适应**：并查集和筛都开到 $V = \max(nums)$ 而非固定 $10^5$——小值域用例（如全 $\le 100$）几乎零开销。
5. **1 的位置在筛之前判**：`nums = [1, 1]` 这类用例若不提前拦截，会在"含 1 但 $n \ge 2$"上给出错误 true。
6. **判连通用"同一个根"**：不必数连通块个数，只要所有 `find(nums[i])` 相等即可；重复数值（如两个 6）自动落在同一点上，天然正确。
7. **不要建邻接表跑 BFS**：节点数 $10^5$、边数 $\le 6 \times 10^5$，BFS 也行，但并查集把"加边"与"查询"合并在同一遍循环里，代码更短且无需显式存图。

## 5. 正确性证明

**引理 1（公共质因数刻画）**：对正整数 $a, b$，$\gcd(a, b) > 1 \iff$ 存在质数 $p$ 同时整除 $a$ 与 $b$。

**证明**：若 $\gcd(a,b) = g > 1$，取 $g$ 的任一质因数 $p$，则 $p \mid a$ 且 $p \mid b$。反之，若 $p \mid a$ 且 $p \mid b$，则 $p \mid \gcd(a, b)$，故 $\gcd(a, b) \ge p > 1$。∎

**引理 2（两种图的连通等价）**：定义图 $G_1$：节点为下标 $\{0..n-1\}$，$i$ 与 $j$ 相邻当且仅当 $\gcd(nums[i], nums[j]) > 1$。定义图 $G_2$：节点为「全体 $nums[i]$ 的取值 $\cup$ 全体质数」，边只有一种——**数组值** $x$ 与它的每个质因数 $p$ 相连（数值 $1$ 无质因数，天然孤立）。则对任意下标 $i, j$：$i, j$ 在 $G_1$ 中连通，当且仅当 $nums[i], nums[j]$ 在 $G_2$ 中连通。

**证明**：$G_2$ 中只有数组值带边（质数与质数之间、非数组的数值均无边），故任何 $G_2$ 路径必然形如"数组值—质数—数组值—质数—…"交替。（$\Rightarrow$）设 $G_1$ 有路径 $i = i_0 \sim i_1 \sim \cdots \sim i_k = j$。对每条边，由引理 1 存在质数 $p_t$ 同时整除 $nums[i_t]$ 与 $nums[i_{t+1}]$，于是 $nums[i_t] - p_t - nums[i_{t+1}]$ 是 $G_2$ 中的两段边，逐段拼接即得 $nums[i]$ 到 $nums[j]$ 的 $G_2$ 路径。（$\Leftarrow$）取一条**最短** $G_2$ 路径 $v_0 - p_0 - v_1 - p_1 - \cdots - p_{k-1} - v_k$，其中 $v_0 = nums[i]$、$v_k = nums[j]$，各 $v_t$ 是数组值、$p_t$ 同时整除 $v_t$ 与 $v_{t+1}$。最短性保证诸 $v_t$ 互异（若 $v_s = v_t$（$s < t$）可截去中间段；特别地不会出现 $v - p - v$ 的原地折返）。每个相邻对 $(v_t, v_{t+1})$ 都有公共质因数，由引理 1 知 $\gcd(v_t, v_{t+1}) > 1$；设 $v_t$ 出现在下标 $\alpha_t$ 处（任取一个），则 $\alpha_t$ 与 $\alpha_{t+1}$ 在 $G_1$ 中相邻，串联得 $i = \alpha_0 \sim \alpha_1 \sim \cdots \sim \alpha_k = j$ 的 $G_1$ 路径。∎

**引理 3（并查集实现保真）**：算法第 4 步只把每个 $nums[i]$ 与其**不同**质因数合并，最终 $find(a) = find(b) \iff a, b$ 在 $G_2$ 的"数值—质因数"边集下连通（并查集维护的正是该边集的传递闭包）。

**证明**：并查集的经典性质——`union(u, v)` 序列维护的等价类恰为图中 $\{u, v\}$ 边集生成的连通分量。第 4 步产生的边恰为 $G_2$ 的全部"数值—质因数"边（每个 $x$ 的每个不同质因数各一条），故等价类相同。∎

**定理**：算法返回 `true` 当且仅当对一切 $i < j$，下标 $i, j$ 在 $G_1$ 中连通。

**证明**：$n = 1$ 时无下标对，题意为真，算法返回 true。$n \ge 2$ 且含 $1$ 时，任何下标对若涉及值为 $1$ 的成员，则 $\gcd(1, x) = 1$ 使其在 $G_1$ 中无边；而 $1$ 在 $G_2$ 中亦孤立——两侧同为"不连通"，算法经第 1 步提前返回 false，正确。其余情形（$n \ge 2$、全体值 $\ge 2$）：算法返回 true ⟺ 全体 $nums[i]$ 在"数值—质因数"边集下同属一个连通分量（引理 3）⟺ 任意两下标在 $G_1$ 中连通（引理 2）⟺ 任意 $i < j$ 可互相遍历。∎

## 6. 复杂度分析

- **时间**：$O(V \log\log V + n \log V \cdot \alpha)$。筛 $O(V \log\log V)$，$V \le 10^5$ 约三百万次基本操作；每个数分解至多 $\log_2 V \approx 17$ 步（且"不同质因数 $\le 6$ 个"给出更紧的界），每步一次摊还近似常数的并查集合并。
- **空间**：$O(V)$，`spf` 与 `fa` 两个长度 $V+1$ 的数组，约 800 KB。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool canTraverseAllPairs(vector<int>& nums) {
        int n = nums.size();
        if (n == 1) return true;                   // 无下标对，空口成立
        for (int x : nums)
            if (x == 1) return false;              // gcd(1,·)=1，含 1 必失败
        int V = *max_element(nums.begin(), nums.end());
        // 最小质因数（SPF）筛
        vector<int> spf(V + 1, 0);
        for (int i = 2; i <= V; ++i)
            if (spf[i] == 0)
                for (int j = i; j <= V; j += i)
                    if (spf[j] == 0) spf[j] = i;
        // 并查集：值域 [0, V]
        fa.resize(V + 1);
        iota(fa.begin(), fa.end(), 0);
        for (int x : nums) {
            int cur = x;
            while (cur > 1) {
                int p = spf[cur];
                unite(x, p);                       // 数值与其每个质因数连边
                while (cur % p == 0) cur /= p;
            }
        }
        int root = find(nums[0]);
        for (int x : nums)
            if (find(x) != root) return false;
        return true;
    }
private:
    vector<int> fa;
    int find(int x) {
        while (fa[x] != x) { fa[x] = fa[fa[x]]; x = fa[x]; }
        return x;
    }
    void unite(int a, int b) {
        a = find(a); b = find(b);
        if (a != b) fa[a] = b;
    }
};
```

### Python

```python
class Solution:
    def canTraverseAllPairs(self, nums: List[int]) -> bool:
        n = len(nums)
        if n == 1:
            return True                    # 无下标对，空口成立
        if 1 in nums:
            return False                   # gcd(1,·)=1，含 1 必失败
        V = max(nums)
        # 最小质因数（SPF）筛
        spf = list(range(V + 1))
        for i in range(2, int(V ** 0.5) + 1):
            if spf[i] == i:                # i 是质数
                for j in range(i * i, V + 1, i):
                    if spf[j] == j:
                        spf[j] = i
        # 并查集：值域 [0, V]
        fa = list(range(V + 1))

        def find(x):
            while fa[x] != x:
                fa[x] = fa[fa[x]]
                x = fa[x]
            return x

        for x in nums:
            cur = x
            while cur > 1:
                p = spf[cur]
                r, rp = find(x), find(p)
                if r != rp:
                    fa[r] = rp             # 数值与其每个质因数连边
                while cur % p == 0:
                    cur //= p
        root = find(nums[0])
        return all(find(x) == root for x in nums)
```

> 💡 两份代码均通过官方示例（`true`、`false`、`true`）与 $n=1$、含 $1$、大质数等边界，并与"暴力建 $O(n^2)$ gcd 图 + BFS 判连通"对拍 2516 组小规模随机数据（$n \le 8$、值域 $\le 100$，含质数/合数/1 混合），另有 32 组大规模用例（最大 $n = 10^5$、值域全量 $[1, 10^5]$）C++/Python 双实现一致性校验，`mismatch = 0`。

## 8. 边界情况与易错点

1. **$n = 1$ 恒 true**：哪怕 `nums = [1]`——"任意下标对"是空约束。这个分支必须放在最前。
2. **含 $1$ 且 $n \ge 2$ 恒 false**：$1$ 没有质因数，$\gcd(1, x) \equiv 1$。若不特判，`nums = [1, 1]` 会被误判 true（两个 1 在并查集里各自为政却不触发"不同根"检查——取决于实现细节，显式特判最稳）。
3. **值域上界是 $10^5$ 不是 $10^6$**：筛和并查集开 `V = max(nums)` 自适应即可；开成固定 $10^5$ 也没问题，但别拍脑袋开 $10^6$ 浪费 4 倍空间。
4. **大质数自身**：`nums = [99991, 2]` 中 99991 是质数，它只与自己相连，直接 false；而 `nums = [99991]`（$n=1$）是 true。SPF 筛对质数 $p$ 有 `spf[p] = p`，`union(p, p)` 是无害的自合并。
5. **重复元素**：`nums = [6, 6]` 两个 6 是同一节点，`true`；并查集合并同值自动成立。
6. **SPF 筛的内层起点**：从 `j = i`（而非 `i*i`）开始、且只写未标记位置，才能保证"最小"质因数语义；从 `i*i` 开始写会漏掉"最小质因数是 $i$ 但 $i^2 > V$"……准确说，从 $i^2$ 起筛的是普通素数筛，SPF 筛必须覆盖 $i$ 的全部倍数（或至少保证每个合数被其最小质因数标记——Python 版用 `range(i*i, ...)` 之所以正确，是因为 `spf` 初值为自身、合数 $x$ 的最小质因数 $p \le \sqrt{x}$ 时 $x \ge p^2$ 必被标记；两种写法都对，但语义不同，混用前想清楚）。
7. **C++ 溢出无需担心**：全程值 $\le 10^5$，乘法只出现在筛的步进里（`j += i` 不超过 `V + i`），`int` 足够。
8. **性能陷阱**：如果对每个数用 `sqrt(x)` 试除分解，$n = 10^5$ 时约 $3 \times 10^7$ 次除法，C++ 勉强、Python 必超时——SPF 筛是把"逐数分解"摊销成"一次建表、查表分解"的关键。
