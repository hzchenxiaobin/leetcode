# LeetCode 跳过交替单元格的之字形遍历 题解

## 1. 题目概述

- **标题 / 题号**：跳过交替单元格的之字形遍历（#3417，easy）
- **链接**：https://leetcode.cn/problems/zigzag-grid-traversal-with-skip/
- **来源**：LeetCode 第 432 场周赛 Q1
- **难度**：简单
- **标签**：数组、矩阵、模拟

**题意**：给定 $m \times n$ 的正整数矩阵 `grid`，按**之字形（行间蛇形）**顺序遍历：偶数行从左到右、奇数行从右到左。遍历过程中**跳过每个交替的单元格**——从 $(0,0)$ 开始「取、跳、取、跳……」交替进行。返回按顺序记录到的单元格值组成的数组。

**约束**：

- 行数与列数均在 $[2, 50]$ 内（即矩阵最小 $2 \times 2$，无空矩阵）
- $1 \le grid[i][j] \le 2500$

## 2. 示例

**示例 1**

```text
输入：grid = [[1,2],[3,4]]
输出：[1,4]
解释：之字形序列为 1, 2, 4, 3；取第 0、2 位（1、4），跳过 2 和 3。
```

**示例 2**

```text
输入：grid = [[2,1],[2,1],[2,1]]
输出：[2,1,2]
解释：之字形序列为 2, 1, 1, 2, 2, 1；取第 0、2、4 位得 2, 1, 2。
```

**示例 3**

```text
输入：grid = [[1,2,3],[4,5,6],[7,8,9]]
输出：[1,3,5,7,9]
解释：之字形序列为 1, 2, 3, 6, 5, 4, 7, 8, 9；取全部偶数位得 1, 3, 5, 7, 9。
```

**示例 4（自造，覆盖 $n$ 为偶数的情形）**

```text
输入：grid = [[1,2,3,4],[5,6,7,8]]
输出：[1,3,8,6]
解释：之字形序列为 1, 2, 3, 4, 8, 7, 6, 5；取第 0、2、4、6 位得 1, 3, 8, 6。
```

## 3. 解题思路

### 3.1 快速切入：直译模拟 + 全局计数器

签到题的最短路径是把题面两条规则直接翻译成代码：

- 「之字形」= 行级交替：偶数行正序、奇数行倒序；
- 「跳过交替」= 对遍历位置做奇偶判断。

维护一个**全局计数器** `cnt`，沿之字形逐格行走：`cnt` 为偶则收集、为奇则跳过，并且**每走一格 `cnt` 都 +1（被跳过的格子也计数）**。两重循环写完，$O(mn)$ 时间，$50 \times 50$ 的规模毫无压力。

> ⚠️ 唯一的坑：计数器**跨行连续，不随行重置**。示例 3 中 $n = 3$ 为奇数，第 1 行从右端先进来的 6（全局位置 3，奇）被跳过——若误以为每行都从「取」开始，会错收 6、4（详见 §8）。

### 3.2 核心观察：保留格恰好构成棋盘格

![核心观察：保留格恰为棋盘格 i+j 为偶](images/zigzag_grid_checkerboard.svg)

把「之字形 + 全局隔位跳过」合并起来，有一个干净的刻画：

**保留 $(i,j)$ 当且仅当 $i+j$ 为偶数**——与列数 $n$ 的奇偶无关，也与行的方向无关。等价地说：**偶数行保留偶数列、奇数行保留奇数列**（奇数行按从右到左的顺序输出）。

证明只需两行 mod 2（见 §5）：奇数行的位置公式里 $n$ 出现两次、恰好相消。于是每行根本不必逐格判断，直接**步长 2 跳着取**：偶数行从列 0 正序、奇数行从最右的奇数列倒序——被跳过的格子一个都不用碰。

### 3.3 示例演算

![示例 3 演算：全局计数器取跳交替](images/zigzag_grid_skip_counter.svg)

以示例 3（$n = 3$，奇数）走一遍全局计数器：

| 行 $i$ | 方向 | 依次经过（值@全局位置 $p$） | 本行收集 |
|---|---|---|---|
| 0 | → | 1@0 ✓、2@1 ✗、3@2 ✓ | 1, 3 |
| 1 | ← | 6@3 ✗、5@4 ✓、4@5 ✗ | 5 |
| 2 | → | 7@6 ✓、8@7 ✗、9@8 ✓ | 7, 9 |

result = $[1, 3, 5, 7, 9]$，与棋盘格 $(i+j)$ 为偶的格子 $\{1, 3, 5, 7, 9\}$ 完全一致 ✓。再对照自造示例 4（$n = 4$，偶数）：保留 $(0,0)=1$、$(0,2)=3$、$(1,1)=6$、$(1,3)=8$，按之字形顺序读出仍是 $[1, 3, 8, 6]$ ✓。

## 4. 算法细节

1. **行方向**：$i$ 偶 → 正序遍历列；$i$ 奇 → 从列 $n-1$ 倒序遍历（第一个走到的格子是 $(i, n-1)$）。
2. **计数器语义**：对**所有**格子（含被跳过的）递增；用 `cnt++ % 2 == 0` 把「判断 + 前进」合并成一行。
3. **闭式写法的起点**：偶数行收集列 $0, 2, 4, \dots$；奇数行收集**奇数列**、从右往左——最右的奇数列下标为 $n-1$（$n$ 为偶）或 $n-2$（$n$ 为奇）。起点写错会整行错位。
4. **输出长度**恰为 $\lceil mn/2 \rceil$（全局位置 $0 \dots mn-1$ 中的偶数个数），可用作 C++ 的 `reserve` 预分配与赛后自检。

## 5. 正确性证明

**引理 1（遍历位置公式）**：完整之字形序列中，单元格 $(i,j)$ 的位置下标为

$$p(i,j) = i\cdot n + \begin{cases} j & i \text{ 为偶数（向右）} \\ n-1-j & i \text{ 为奇数（向左）} \end{cases}$$

**证明**：行 $i$ 之前恰有 $i \cdot n$ 个格子被遍历。$i$ 为偶时行内从左到右走，列 $j$ 是行内第 $j$ 个（0 开始）；$i$ 为奇时从右到左走，列 $j$ 是行内第 $n-1-j$ 个。∎

**引理 2（奇偶刻画）**：$p(i,j)$ 为偶数 $\iff$ $i+j$ 为偶数。

**证明**：对 mod 2 讨论：

- $i$ 偶：$p \equiv i\cdot n + j \equiv j \pmod 2$，故 $p$ 偶 $\iff j$ 偶 $\iff i+j$ 偶；
- $i$ 奇：$p \equiv i\cdot n + (n-1-j) \equiv n + n - 1 - j \equiv 2n - 1 - j \equiv j + 1 \pmod 2$，故 $p$ 偶 $\iff j$ 奇 $\iff i+j$ 偶（$i$ 为奇）。

注意 $i$ 奇的情形中 $n$ 出现了两次、在 mod 2 下相消，因此结论**与 $n$ 的奇偶无关**。∎

**定理**：所求结果等于所有满足 $i+j$ 为偶数的格子按之字形顺序读出的序列；等价地，偶数行保留偶数列、奇数行保留奇数列。

**证明**：「跳过交替」即从位置 0 起取、跳、取、跳……即**保留位置下标 $p$ 为偶数**的格子（$p$ 由引理 1 给出）。由引理 2，保留集合恰为 $\{(i,j) : i + j \text{ 为偶}\}$，输出顺序即之字形遍历顺序。∎

**推论**：输出长度为 $\lceil mn/2 \rceil$（位置 $0 \dots mn-1$ 中偶数个数）。

## 6. 复杂度分析

- **时间复杂度**：直译模拟 $O(mn)$；闭式步长 2 写法 $O(\lceil mn/2 \rceil)$，被跳过的格子不进入循环体。规模 $50 \times 50 = 2500$，任何写法都轻松通过。
- **空间复杂度**：$O(1)$ 额外空间（输出数组不计）。相比「先拍平完整序列再 `order[::2]`」的两步写法，省掉了 $O(mn)$ 的中间数组。

## 7. 参考代码

### C++（直译模拟）

```cpp
class Solution {
  public:
    vector<int> zigzagTraversal(vector<vector<int>>& grid) {
        int m = grid.size(), n = grid[0].size();
        vector<int> ans;
        int cnt = 0;                          // 全局计数器：被跳过的格子也 +1
        for (int i = 0; i < m; i++) {
            if (i % 2 == 0) {                 // 偶数行：向右
                for (int j = 0; j < n; j++)
                    if (cnt++ % 2 == 0) ans.push_back(grid[i][j]);
            } else {                          // 奇数行：向左
                for (int j = n - 1; j >= 0; j--)
                    if (cnt++ % 2 == 0) ans.push_back(grid[i][j]);
            }
        }
        return ans;
    }
};
```

### Python（直译模拟）

```python
class Solution:
    def zigzagTraversal(self, grid: List[List[int]]) -> List[int]:
        ans = []
        cnt = 0                              # 全局计数器：被跳过的格子也 +1
        for i, row in enumerate(grid):
            cols = range(len(row)) if i % 2 == 0 else range(len(row) - 1, -1, -1)
            for j in cols:
                if cnt % 2 == 0:
                    ans.append(grid[i][j])
                cnt += 1
        return ans
```

### Python（闭式写法：步长 2 直取，跳过格不进循环）

```python
class Solution:
    def zigzagTraversal(self, grid: List[List[int]]) -> List[int]:
        n = len(grid[0])
        ans = []
        for i, row in enumerate(grid):
            if i % 2 == 0:                        # 偶数行：偶数列，正序
                ans += row[0::2]
            else:                                 # 奇数行：奇数列，倒序
                ans += row[n - 1 if n % 2 == 0 else n - 2::-2]
        return ans
```

## 8. 边界情况与易错点

1. **计数器不随行重置**（本题唯一的坑）：「交替」是全程连续的取、跳、取、跳。$n$ 为偶数时每行首格位置 $i \cdot n$ 恒为偶，「每行从取开始」的错误写法恰好也能得到正确结果，坑被**完全掩盖**；只有 $n$ 为奇数时才暴露——错收奇数行两端的 $grid[i][n-1]$ 与 $grid[i][0]$（示例 3 中即 6、4）。自测必须带上奇数宽度的用例。
2. **奇数行的起点是列 $n-1$**：向左走第一个格子是 $(i, n-1)$，写成 `for (j = n-1; j >= 0; --j)`；方向反了整行乱序。
3. **闭式写法的奇数行起始列**依赖 $n$ 的奇偶：$n$ 偶取 $n-1$、$n$ 奇取 $n-2$（都是最右的奇数列），起点错则整行错位。
4. **最小规模 $2 \times 2$ 也有跳过发生**（示例 1），不存在空矩阵或单格矩阵的特判；返回一维数组。
5. **输出长度恰为 $\lceil mn/2 \rceil$**：$mn$ 为奇（$m$、$n$ 均奇）时比「一半」多一个，可用它校验结果规模。
6. 数据范围极小（$\le 2500$ 格、值 $\le 2500$），无溢出与超时风险；本题比拼的是**一次写对**。

- **跳过周期推广**：若规则改为「每 $K+1$ 格取 1 格」（本题 $K=1$），保留条件变为 $p \bmod (K+1) = 0$，仍可按行推导「起点 + 步长」的直取写法——棋盘格只是 $K=1$ 的特例。
