# LeetCode 统计范围内的逗号 题解

## 1. 题目概述

- **标题 / 题号**：统计范围内的逗号（#3870，easy）
- **链接**：https://leetcode.cn/problems/count-commas-in-range/
- **来源**：LeetCode 第 493 场周赛 Q1
- **难度**：简单
- **标签**：数学

**题意**：给定整数 $n$，把 $[1, n]$ 内所有整数按**标准格式**书写——从右起每三位插入一个逗号，位数不足四位的数不含逗号——求总共用到的逗号个数。

**约束**：

- $1 \le n \le 10^5$

## 2. 示例

**示例 1**

```text
输入：n = 1002
输出：3
解释："1,000"、"1,001"、"1,002" 各含 1 个逗号，共 3 个。
```

**示例 2**

```text
输入：n = 998
输出：0
解释：1 到 998 的所有数位数都少于四位，不含逗号。
```

**示例 3（边界自测）**

```text
输入：n = 100000
输出：99001
解释：1000 ~ 99999 共 99000 个数各 1 个逗号；100000 写作 "100,000"，也是 1 个逗号。
```

## 3. 解题思路

### 3.1 暴力思路

遍历 $1 \sim n$，把每个数格式化成带逗号的字符串再数逗号：

```python
ans = sum(f"{i:,}".count(",") for i in range(1, n + 1))
```

时间复杂度 $O(n \log n)$。由于 $n \le 10^5$，暴力也能通过，但签到题应当追求 $O(1)$ 的公式解。

### 3.2 核心观察：逗号数只由位数决定

![位数与逗号数的关系](images/count_commas_digit_length.svg)

一个 $L$ 位数的逗号数为 $\left\lfloor \frac{L-1}{3} \right\rfloor$：

| 位数 $L$ | 数值范围 | 逗号数 |
|---------|---------|--------|
| 1 ~ 3 | 1 ~ 999 | 0 |
| 4 ~ 6 | 1,000 ~ 999,999 | 1 |
| 7 ~ 9 | 1,000,000 ~ 999,999,999 | 2 |

由于 $n \le 10^5 = 100000$（6 位），范围内**所有 $\ge 1000$ 的数恰好含 1 个逗号**，$< 1000$ 的数不含逗号。于是答案就是 $[1000, n]$ 内的整数个数：

$$\text{ans} = \max(0,\ n - 999)$$

### 3.3 算法流程

1. 比较 $n$ 与 $1000$ 的大小。
2. 若 $n \ge 1000$，答案为 $n - 1000 + 1 = n - 999$；否则答案为 $0$。合并为 $\max(0, n - 999)$。

### 3.4 示例演算

![示例演算 n=1002 与 n=998](images/count_commas_example.svg)

- $n = 1002$：含逗号的数为 $1000, 1001, 1002$，共 $1002 - 999 = 3$ 个 ✓
- $n = 998$：$[1000, 998]$ 为空区间，答案 $0$ ✓
- $n = 100000$：$100000 - 999 = 99001$ ✓

## 4. 算法细节

1. **位数 → 逗号数**：$L$ 位数从右起每 3 位一组、组间插逗号，共 $\left\lfloor \frac{L-1}{3} \right\rfloor$ 个。
2. **区间计数**：$[1000, n]$ 的整数个数为 $n - 1000 + 1 = n - 999$，两端均包含。
3. **通式（按位数分段统计）**：设 $f(n)$ 为 $[1, n]$ 的逗号总数，则

$$f(n) = \sum_{L \ge 1} \max\!\Bigl(0,\ \min\bigl(n,\ 10^L - 1\bigr) - 10^{L-1} + 1\Bigr) \cdot \left\lfloor \frac{L-1}{3} \right\rfloor$$

   本题 $n \le 10^5$，只有 $L = 4, 5, 6$ 三段可能非零且系数均为 $1$，三段并起来恰是 $[1000, n]$，公式退化为 $\max(0, n - 999)$。这个通式正是同场 Q2（数值扩大到 $10^{15}$）需要的做法。

## 5. 正确性证明

**引理 1**：$L$ 位数的标准格式恰含 $\left\lfloor \frac{L-1}{3} \right\rfloor$ 个逗号。

**证明**：标准格式从右起每 3 位插一个逗号，第 $k$ 个逗号（从右数）位于第 $3k$ 位与第 $3k+1$ 位数字之间，存在当且仅当 $3k \le L - 1$，即 $k \le \frac{L-1}{3}$。满足条件的正整数 $k$ 共 $\left\lfloor \frac{L-1}{3} \right\rfloor$ 个。∎

**引理 2**：当 $n \le 10^5$ 时，$[1, n]$ 中每个 $\ge 1000$ 的数恰含 1 个逗号，每个 $< 1000$ 的数不含逗号。

**证明**：$1000 \le x \le 100000$ 的位数为 4 ~ 6，由引理 1，逗号数分别为 $\lfloor 3/3 \rfloor = \lfloor 4/3 \rfloor = \lfloor 5/3 \rfloor = 1$；$1 \le x \le 999$ 的位数为 1 ~ 3，逗号数为 $\lfloor 0/3 \rfloor = \lfloor 1/3 \rfloor = \lfloor 2/3 \rfloor = 0$。∎

**定理**：答案为 $\max(0, n - 999)$。

**证明**：由引理 2，$[1, n]$ 中含逗号的数恰为 $[1000, n]$ 中的数，且每个恰贡献 1 个逗号。若 $n \ge 1000$，其个数为 $n - 999$；若 $n < 1000$，该区间为空，答案为 $0$。两种情形合并即 $\max(0, n - 999)$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(1)$，仅一次比较与一次减法。
- **空间复杂度**：$O(1)$。

## 8. 边界情况与易错点

1. **$n < 1000$**：直接 $n - 999$ 会得到负数，必须与 $0$ 取最大值。
2. **$10^5$ 本身只有 1 个逗号**：100000 写作 "100,000"（6 位，$\lfloor 5/3 \rfloor = 1$），不要误以为 $10^5$ 要 2 个逗号。
3. **区间端点**：$[1000, n]$ 的个数是 $n - 999$ 而非 $n - 1000$，1000 本身就含逗号。
4. **数据范围陷阱**：把本题做法直接搬到同场 Q2（数值到 $10^{15}$）会出错——4 ~ 6 位与 7 ~ 9 位的每数逗号数不同，必须按位数分段统计。
