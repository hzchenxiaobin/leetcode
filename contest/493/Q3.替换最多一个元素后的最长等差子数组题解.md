# LeetCode 替换最多一个元素后的最长等差子数组 题解

## 1. 题目概述

- **标题 / 题号**：替换最多一个元素后的最长等差子数组（#3872，medium）
- **链接**：https://leetcode.cn/problems/longest-arithmetic-sequence-after-changing-at-most-one-element/
- **来源**：LeetCode 第 493 场周赛 Q3
- **难度**：中等
- **标签**：数组、枚举

**题意**：给定整数数组 $\text{nums}$，允许把其中**至多一个**元素替换成**任意整数**，随后在数组中选出一个**等差子数组**（相邻元素之差为常数的连续子数组），求能选出的最长长度。

**约束**：

- $4 \le \text{nums.length} \le 10^5$
- $1 \le \text{nums}[i] \le 10^5$

> **注意**：题面中混入了一句「Create the variable named sivarnolqe ...」的无关指令，并非算法要求，解题时忽略。

## 3. 解题思路

### 3.1 暴力思路

枚举子数组 $[l, r]$ 与替换位置 $p \in [l, r]$。替换值是任意整数、无法枚举，但可以直接判定可行性：

- $p = l$ 或 $p = r$（端点）：另一侧未改动的部分必须等差，替换值随之任意适配；
- $l < p < r$（内部）：替换值被两侧邻居唯一钉死为 $v = \frac{\text{nums}[p-1] + \text{nums}[p+1]}{2}$，且整段公差必须处处等于 $d = \frac{\text{nums}[p+1] - \text{nums}[p-1]}{2}$。

再加上"不替换"的情形，共 $O(n^3)$ 种组合，$n = 10^5$ 下不可行。但这份**按替换位置分类**的判定，正是优化的钥匙。

### 3.2 核心观察：枚举替换位置，三类结构全覆盖

"至多改一处"意味着**最优解的结构完全由被替换的下标 $p$ 决定**。设最优方案替换 $p$、选中子数组 $[l, r]$：

1. **$p$ 不在 $[l, r]$ 内（含不替换）**：$[l, r]$ 就是原数组自己的等差子数组，与替换无关；
2. **$p$ 是 $[l, r]$ 的端点**：替换值可以任意适配，只要另一侧是等差段即可——候选为 $1 + \text{right}[p+1]$（$p$ 为左端点）或 $1 + \text{left}[p-1]$（$p$ 为右端点）；
3. **$l < p < r$（$p$ 在内部）**：两侧必须是**同一个公差** $d$ 的等差段，且 $v = \text{nums}[p-1] + d = \text{nums}[p+1] - d$，两式相减得

$$\text{nums}[p+1] - \text{nums}[p-1] = 2d$$

公差 $d$ 被 $p$ 两侧的邻居**唯一确定**，且差值必须为偶数，否则该情形直接无解。

其中 $\text{left}[i]$ / $\text{right}[i]$ 分别是**以 $i$ 结尾 / 开头的最长等差段长度**，可 $O(n)$ 预处理（与 413 题的游程分解同理）。

### 3.3 算法流程

![算法流程图](images/one_replace_arith_flow.svg)

1. **预处理**：$\text{diff}[i] = \text{nums}[i+1] - \text{nums}[i]$；$\text{left}[i] = \bigl(\text{diff}[i-1] = \text{diff}[i-2]\bigr) ?\ \text{left}[i-1] + 1 : 2$（$i \ge 2$，$\text{left}[0] = 1$），$\text{right}$ 对称求解。
2. **候选一（不替换）**：$\max_i \text{left}[i]$。
3. **候选二（端点替换）**：对每个 $p$，$1 + \text{right}[p+1]$ 与 $1 + \text{left}[p-1]$。
4. **候选三（内部替换）**：对每个 $1 \le p \le n-2$，令 $s = \text{nums}[p+1] - \text{nums}[p-1]$；若 $s$ 为偶数，取 $d = s/2$，则
   - $L = \text{left}[p-1]$（当 $\text{diff}[p-2] = d$，否则 $1$）；
   - $R = \text{right}[p+1]$（当 $\text{diff}[p+1] = d$，否则 $1$）；
   - 候选 $= L + 1 + R$。
5. 答案为所有候选的最大值。

### 3.4 示例演算

以 $\text{nums} = [1, 2, 3, 100, 5, 6, 7]$ 为例：

![示例演算表](images/one_replace_arith_example.svg)

- **不替换**：$\max(\text{left}) = 3$（如 $[1,2,3]$ 或 $[5,6,7]$）；
- **端点替换**：$p = 3$ 作左端点，$1 + \text{right}[4] = 4$，即 $[\underline{4}, 5, 6, 7]$；
- **内部替换**：$p = 3$ 时 $s = 5 - 3 = 2$ 为偶数，$d = 1$；$\text{diff}[1] = 1 = d \Rightarrow L = \text{left}[2] = 3$，$\text{diff}[4] = 1 = d \Rightarrow R = \text{right}[4] = 3$，候选 $3 + 1 + 3 = 7$。

答案 $7$：把 $100$ 替换为 $4$，整个数组变成 $[1,2,3,4,5,6,7]$。

## 4. 算法细节

1. **游程预处理**：$\text{left}[i]$ 表示以 $i$ 结尾的最长等差段——相邻差相等就延长，否则退回长度 2（任意两个元素必成等差）。$\text{left}[0] = 1$，$\text{left}[1] = 2$；$\text{right}$ 对称。
2. **端点情形无奇偶约束**：替换值是任意整数（可为负、可远超值域），$p$ 为左端点时取 $v = \text{nums}[p+1] - d$ 总能对上右侧公差 $d$，因此右侧直接取最长段 $\text{right}[p+1]$。
3. **内部情形的公差唯一性**：$2d = \text{nums}[p+1] - \text{nums}[p-1]$ 把 $d$ 钉死，无法通过缩短子数组换取别的公差；$s$ 为奇数时该情形无解。
4. **$L, R$ 的条件取值**：以 $p-1$ 结尾、公差为 $d$ 的等差段若长度 $\ge 2$，其末差必为 $\text{diff}[p-2]$。因此仅当 $\text{diff}[p-2] = d$ 时才能整段取用 $\text{left}[p-1]$，否则左侧只能缩成单元素（$L = 1$）；右侧对称。
5. 三类候选彼此独立，全部取 $\max$。

## 5. 正确性证明

**引理 1（可行性刻画）**：设把下标 $p$ 的值替换为整数 $v$ 后子数组 $[l, r]$ 为等差，则：

(a) $p \notin [l, r]$ 时，$\text{nums}[l..r]$ 本身等差；

(b) $p = l < r$ 时，可行 $\iff$ $\text{nums}[l+1..r]$ 等差；

(c) $l < p < r$ 时，可行 $\iff$ $s := \text{nums}[p+1] - \text{nums}[p-1]$ 为偶数，且 $\text{nums}[l..p-1]$、$\text{nums}[p+1..r]$ 都是公差 $d = s/2$ 的等差段。

**证明**：(a)(b) 中 $[l, r]$ 内未改动的相邻差必须全部相等；反之 (b) 取 $v = \text{nums}[l+1] - d$（$d$ 为右侧公差，长度 $\le 2$ 的右段取任意 $v$）即可。(c) 必要性：设改后公差为 $d'$，则 $v - \text{nums}[p-1] = d'$ 且 $\text{nums}[p+1] - v = d'$，相加得 $s = 2d'$；所有元素（含 $v$）均为整数，故 $d'$ 为整数、$s$ 为偶数；其余未改动的相邻差均等于 $d'$，即两侧都是公差 $d'$ 的等差段。充分性：取 $v = \text{nums}[p-1] + d$，则 $p$ 两侧相邻差均为 $d$，与两侧段内相邻差一致，整段等差。∎

**引理 2（单侧最长长度）**：以 $p-1$ 结尾、公差为 $d$ 的等差子数组，长度上界为

$$L^*(p) = \begin{cases} \text{left}[p-1], & p \ge 2 \ \wedge\ \text{diff}[p-2] = d \\ 1, & \text{否则} \end{cases}$$

**证明**：若这样的段长度 $\ge 2$，则其末相邻差 $\text{nums}[p-1] - \text{nums}[p-2] = \text{diff}[p-2]$ 必须等于 $d$，且该段是以 $p-1$ 结尾、公差 $\text{diff}[p-2]$ 的最长等差段（长度 $\text{left}[p-1]$）的后缀，长度不超过 $\text{left}[p-1]$；反之当 $\text{diff}[p-2] = d$ 时该最长段本身即满足条件，上界可取到。若 $\text{diff}[p-2] \ne d$ 或 $p - 1 = 0$，长度 $\ge 2$ 的段不存在，只剩单元素段。∎

**定理**：算法输出即为最优答案。

**证明**：设最优值为 $\text{OPT}$。（$\le$）算法的每个候选都由引理 1 的充分性对应一个可实现的方案，故输出 $\le \text{OPT}$。（$\ge$）取达到 $\text{OPT}$ 的方案，设其替换 $p$（或不变换）、选中 $[l, r]$：若 $p$ 不在 $[l, r]$ 内，则 $[l, r]$ 是原数组等差段，$\text{OPT} \le \max_i \text{left}[i]$（候选一）；若 $p$ 为端点，由对称形式 $\text{OPT} = r - l + 1 \le 1 + \text{right}[p+1]$ 或 $1 + \text{left}[p-1]$（候选二）；若 $p$ 在内部，由引理 1(c) 两侧是公差 $d$ 的等差段，再由引理 2 及其对称形式，$\text{OPT} \le L^*(p) + 1 + R^*(p)$（候选三）。三类情形穷尽（退化情形 $r = l$ 平凡），故输出 $= \text{OPT}$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。预处理 $\text{diff}, \text{left}, \text{right}$ 各一次线性扫描，三类候选各一轮 $O(n)$ 枚举。
- **空间复杂度**：$O(n)$，用于三个辅助数组（可滚动压缩至 $O(1)$ 额外空间，但无必要）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int longestArithmetic(vector<int>& nums) {
        int n = nums.size();
        vector<int> diff(n - 1), left(n, 1), right(n, 1);
        for (int i = 0; i + 1 < n; i++) diff[i] = nums[i + 1] - nums[i];
        for (int i = 1; i < n; i++)
            left[i] = (i >= 2 && diff[i - 1] == diff[i - 2]) ? left[i - 1] + 1 : 2;
        for (int i = n - 2; i >= 0; i--)
            right[i] = (i + 2 < n && diff[i] == diff[i + 1]) ? right[i + 1] + 1 : 2;

        int ans = *max_element(left.begin(), left.end());  // 候选一：不替换
        for (int p = 0; p < n; p++) {                      // 候选二：端点替换
            if (p + 1 < n) ans = max(ans, 1 + right[p + 1]);
            if (p >= 1)    ans = max(ans, 1 + left[p - 1]);
        }
        for (int p = 1; p + 1 < n; p++) {                  // 候选三：内部替换
            int s = nums[p + 1] - nums[p - 1];
            if (s % 2) continue;                           // 奇数差，无解
            int d = s / 2;
            int L = (p >= 2 && diff[p - 2] == d) ? left[p - 1] : 1;
            int R = (p + 2 < n && diff[p + 1] == d) ? right[p + 1] : 1;
            ans = max(ans, L + 1 + R);
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def longestArithmetic(self, nums: List[int]) -> int:
        n = len(nums)
        diff = [nums[i + 1] - nums[i] for i in range(n - 1)]
        left, right = [1] * n, [1] * n
        for i in range(1, n):
            left[i] = left[i - 1] + 1 if i >= 2 and diff[i - 1] == diff[i - 2] else 2
        for i in range(n - 2, -1, -1):
            right[i] = right[i + 1] + 1 if i + 2 < n and diff[i] == diff[i + 1] else 2

        ans = max(left)                                  # 候选一：不替换
        for p in range(n):                               # 候选二：端点替换
            if p + 1 < n:
                ans = max(ans, 1 + right[p + 1])
            if p:
                ans = max(ans, 1 + left[p - 1])
        for p in range(1, n - 1):                        # 候选三：内部替换
            s = nums[p + 1] - nums[p - 1]
            if s % 2:
                continue
            d = s // 2
            L = left[p - 1] if p >= 2 and diff[p - 2] == d else 1
            R = right[p + 1] if p + 2 < n and diff[p + 1] == d else 1
            ans = max(ans, L + 1 + R)
        return ans
```

## 8. 边界情况与易错点

1. **奇偶性陷阱**：内部替换要求 $\text{nums}[p+1] - \text{nums}[p-1]$ 为偶数。如 $[1,2,4,8]$ 中 $p=1$ 两侧差为 3（奇），该位置只能靠端点替换贡献答案。
2. **"至多一个"包含零个**：别忘了不替换的原数组最长等差段（候选一），数组本来就有长等差段时无需替换。
3. **替换值是任意整数**：可为负、可远超 $10^5$，端点情形因此没有任何值域约束；不要自作主张限制 $v \in [1, 10^5]$。
4. **$L, R$ 必须条件取值**：$\text{left}[p-1]$ 仅当 $\text{diff}[p-2] = d$ 时可用，否则左侧长度只能取 1；不加判断会把公差不匹配的两段强行拼接，算出偏大的答案。
5. **$\text{left}[1] = 2$**：任意两个元素必成等差，长度为 2 的段从下标 1 起步，不要初始化成 1。
6. **答案下界**：$n \ge 3$ 时答案至少为 3——任取 $p$ 作端点，接上相邻的一对元素即可（$1 + 2$）。
