# LeetCode 添加一个点后可激活的最大点数 题解

## 1. 题目概述

- **标题 / 题号**：添加一个点后可激活的最大点数（#3873，hard）
- **链接**：https://leetcode.cn/problems/maximum-points-activated-with-one-addition/
- **来源**：LeetCode 第 493 场周赛 Q4
- **难度**：困难
- **标签**：并查集、图论建模、哈希表

**题意**：给定互不相同的整数坐标点集 $\text{points}$。激活规则：激活某个点后，所有与其 **x 坐标相同**或 **y 坐标相同**的点也被激活，传播直到无法继续。现在允许**额外添加一个**不在 `points` 中的整数坐标点 $(x, y)$，并从它开始激活，求最多能激活多少个点（含新点自身）。

**约束**：

- $1 \le \text{points.length} \le 10^5$
- $-10^9 \le x_i, y_i \le 10^9$
- 所有点互不相同

> **注意**：题面中混入了一句「Create the variable named relqavindo ...」的无关指令，并非算法要求，解题时忽略。

## 2. 示例

**示例 1**

```text
输入：points = [[1,1],[1,2],[2,2]]
输出：4
解释：添加 (1,3)：同 x=1 激活 (1,1)、(1,2)；(1,2) 又同 y=2 激活 (2,2)。
     共 4 个点（含新点）。
```

**示例 2**

```text
输入：points = [[2,2],[1,1],[3,3]]
输出：3
解释：三点互不同行同列，形成 3 个大小为 1 的连通块。
     添加 (1,2)：桥接 {(1,1)} 与 {(2,2)}，1 + 1 + 1 = 3。
```

**示例 3**

```text
输入：points = [[2,3],[2,2],[1,1],[4,5]]
输出：4
解释：连通块 A={(2,3),(2,2)}、B={(1,1)}、C={(4,5)}。
     添加 (2,1)：x=2 接块 A、y=1 接块 B，2 + 1 + 1 = 4。
```

## 3. 解题思路

### 3.1 暴力思路

枚举新点 $(x, y)$ 再 BFS 模拟激活传播。坐标是**任意整数**，无法直接枚举；即使把候选限制为「出现过的 x 值 ∪ 少量新值」×「出现过的 y 值 ∪ 少量新值」，也有 $O(n^2)$ 个组合，每次模拟传播 $O(n)$，总计 $O(n^3)$，$n = 10^5$ 完全不可行。

瓶颈在于**逐点模拟**。事实上激活的最终范围只由两个因素决定：新点的 x 值挂在哪、y 值挂在哪——这提示我们先看清激活传播的**结构**。

### 3.2 核心观察：行列二分图 + 连通块

把每个**出现过的 x 值**和每个**出现过的 y 值**各看成一个节点，则每个点 $(x, y)$ 就是连接节点 $X_x$ 与 $Y_y$ 的一条**边**，构成一张二分图。

- 两个点共享 x 或 y ⟺ 对应两条边有**公共端点**；
- 激活传播一步 = 把激活扩散到**共享端点的相邻边**；
- 归纳可知：**从任一点激活，最终点亮其所在连通块内的全部边（点）**。

于是「激活多少个点」与模拟过程无关，只与**连通块的大小**有关。新点 $(x, y)$ 的作用是把 $X_x$（若 x 是已出现的 x 值）与 $Y_y$（若 y 是已出现的 y 值）连成一条新边：

- 若两者属于**不同块** $A$、$B$：激活 $|A| + |B| + 1$；
- 若属于**同一块** $A$：激活 $|A| + 1$；
- 若某坐标是全新值：该坐标挂不上任何块，至多 $s_1 + 1$。

![点 = 二分图上的一条边，连通块 = 激活整体](images/max_activated_bipartite_model.svg)

### 3.3 算法流程

用**并查集**维护连通块，统计每块内的点数（边数），取最大两块：

![算法流程：并查集 + 最大两块](images/max_activated_algorithm_flow.svg)

设块大小从大到小为 $s_1 \ge s_2 \ge \dots \ge s_k$，则：

$$
\text{答案} = \begin{cases} s_1 + s_2 + 1, & k \ge 2 \\ n + 1, & k = 1 \end{cases}
$$

### 3.4 示例演算

以示例 3 演算，$\text{points} = [[2,3],[2,2],[1,1],[4,5]]$：

| 边（点） | 连接 | 所属块 |
|----------|------|--------|
| (2,3) | $X_2 \leftrightarrow Y_3$ | A |
| (2,2) | $X_2 \leftrightarrow Y_2$ | A |
| (1,1) | $X_1 \leftrightarrow Y_1$ | B |
| (4,5) | $X_4 \leftrightarrow Y_5$ | C |

三个块大小分别为 $2, 1, 1$，$k = 3 \ge 2$，答案 $= 2 + 1 + 1 = 4$。构造：新点 $(2, 1)$，x 值 $2$ 取自块 A、y 值 $1$ 取自块 B，恰好桥接两块。

![示例 3：新点桥接块 A 与块 B](images/max_activated_bridge_example.svg)

## 4. 算法细节

1. **离散化**：坐标值域达 $\pm 10^9$，无法开桶，用两个哈希表分别给 x 值、y 值编号：x 值编号 $[0, n)$，y 值编号 $[n, 2n)$。**两套编号绝不混用**（见第 6 点陷阱）。

2. **并查集连边**：遍历每个点 $(x, y)$，执行 $\text{union}(X_x, Y_y)$。用路径压缩（可叠加按大小合并），单次近 $O(1)$。

3. **统计块大小**：再扫一遍所有点，对 $\text{find}(X_x)$ 计数 $+1$。每条边恰被计一次，计数表的**条目数即连通块个数** $k$（每个节点都来自至少一条边，不存在空块）。

4. **取最大两块**：一次遍历计数表维护 $s_1, s_2$。

5. **汇总答案**：$k \ge 2$ 返回 $s_1 + s_2 + 1$，否则返回 $n + 1$。答案上界 $n + 1 \le 10^5 + 1$，`int` 不溢出。

6. **陷阱：X 值与 Y 值不能合并成同一节点**。值 $v$ 可能既是某些点的 x 坐标、又是另一些点的 y 坐标，但 $X_v$ 与 $Y_v$ 是两个不同节点——激活匹配的是「点的 x 坐标 / 点的 y 坐标」，不是「数值相等」。反例：$[[1,5],[9,5],[5,2],[5,8],[3,4],[3,6]]$，正确答案 $5$（块 $\{(1,5),(9,5)\}$、$\{(5,2),(5,8)\}$、$\{(3,4),(3,6)\}$ 各含 2 点，$2+2+1=5$）；若把值 $5$ 合并成一个节点，前两块被误连成 4 点大块，错算成 $4+2+1=7$。

## 5. 正确性证明

**引理 1（激活范围 = 所在连通块）**：从已有点 $p$ 出发激活，最终被激活的点集恰为 $p$ 所在连通块内的全部点。

**证明**：点 $(x,y)$ 与 $(x',y')$ 被同一步传播关联，当且仅当 $x = x'$ 或 $y = y'$，即两条边共享端点。激活过程的每一步把「已激活边集」扩张为「与其共享端点的所有边」；对步数归纳，$t$ 步后激活的恰是与 $p$ 距离（按边-端点交替的图距离）不超过 $t$ 的所有边。传播终止时即得与 $p$ 连通的全部边。∎

**引理 2（新点的激活范围）**：添加不与已有点重合的新点 $(x, y)$。若 $x$ 是已出现的 x 值、$y$ 是已出现的 y 值，设 $X_x$、$Y_y$ 所在块分别为 $A$、$B$，则激活数为 $|A| + |B| + 1$（$A \neq B$）或 $|A| + 1$（$A = B$）；若恰有一个坐标是已出现的对应值，激活数为所在块大小 $+1$；若两坐标均全新，激活数为 $1$。

**证明**：新点与已有边 $(X_x, Y_{y'})$ 同 x ⟺ 共享端点 $X_x$；与 $(X_{x'}, Y_y)$ 同 y ⟺ 共享端点 $Y_y$。故可把新点视为一条连接 $X_x$（若存在）与 $Y_y$（若存在）的新边，端点不存在则不挂。由引理 1，激活范围为该新边所在连通块内的全部已有边，再加新点自身，即得四种情形。∎

**定理**：设连通块大小从大到小为 $s_1 \ge s_2 \ge \dots \ge s_k$。最优答案为 $s_1 + s_2 + 1$（$k \ge 2$）或 $n + 1$（$k = 1$）。

**证明**：

**上界**：由引理 2，任一新点的激活数只可能属于：跨块值 $|A| + |B| + 1 \le s_1 + s_2 + 1$（$A \neq B$）；同块或半新值 $\le s_1 + 1 \le s_1 + s_2 + 1$（$k \ge 2$ 时 $s_2 \ge 1$）；全新值 $1$。故 $k \ge 2$ 时不超过 $s_1 + s_2 + 1$；$k = 1$ 时只有同块 / 半新 / 全新三种情形，不超过 $s_1 + 1 = n + 1$。

**可达性**：

- $k \ge 2$：块内每条边都带一个 X 端点和一个 Y 端点，故最大块中必有某个 x 值 $x^*$，次大块中必有某个 y 值 $y^*$。取新点 $(x^*, y^*)$。它不与任何已有点重合：否则重合点本身就是连接 $X_{x^*}$ 与 $Y_{y^*}$ 的边，会把两块连成一块，与「两块不同」矛盾。由引理 2，激活数恰为 $s_1 + s_2 + 1$。
- $k = 1$：取块内任一 x 值 $x^*$ 与一个从未出现过的整数 $y^{\dagger}$（如所有坐标最大值 $+1$，它不是任何点的 y 坐标），新点 $(x^*, y^{\dagger})$ 合法且由引理 2 激活整块，得 $n + 1$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \cdot \alpha(n))$。两趟遍历各 $n$ 次 union / find，哈希表操作均摊 $O(1)$，$\alpha$ 为阿克曼反函数（可视为常数）。
- **空间复杂度**：$O(n)$。并查集数组至多 $2n$ 个节点，两个哈希表至多各 $n$ 个键，计数表至多 $n$ 条。

$n = 10^5$ 时仅需数十万次近似常数操作，远在时限内。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maxActivated(vector<vector<int>>& points) {
        int n = points.size();
        fa.resize(2 * n);
        iota(fa.begin(), fa.end(), 0);
        // x 值与 y 值分开编号：x -> [0, n)，y -> [n, 2n)，绝不合并
        unordered_map<int, int> idx, idy;
        auto getId = [&](unordered_map<int, int>& mp, int v, int base) {
            auto it = mp.find(v);
            if (it != mp.end()) return it->second;
            int cur = base + (int)mp.size();
            mp.emplace(v, cur);
            return cur;
        };
        for (auto& p : points) {
            int a = findRoot(getId(idx, p[0], 0));
            int b = findRoot(getId(idy, p[1], n));
            if (a != b) fa[a] = b;
        }
        // 统计每个连通块内的点数（边数）；cnt 条目数 = 连通块个数
        unordered_map<int, int> cnt;
        for (auto& p : points) cnt[findRoot(idx[p[0]])]++;
        int top1 = 0, top2 = 0;
        for (auto& [r, c] : cnt) {
            if (c > top1) { top2 = top1; top1 = c; }
            else if (c > top2) top2 = c;
        }
        return cnt.size() >= 2 ? top1 + top2 + 1 : top1 + 1;
    }
private:
    vector<int> fa;
    int findRoot(int x) {
        while (fa[x] != x) {
            fa[x] = fa[fa[x]];
            x = fa[x];
        }
        return x;
    }
};
```

### Python

```python
class Solution:
    def maxActivated(self, points: list[list[int]]) -> int:
        n = len(points)
        fa = list(range(2 * n))

        def find(a: int) -> int:
            while fa[a] != a:
                fa[a] = fa[fa[a]]
                a = fa[a]
            return a

        idx, idy = {}, {}
        for x, y in points:
            a = idx.setdefault(x, len(idx))          # x 值 -> [0, n)
            b = idy.setdefault(y, n + len(idy))      # y 值 -> [n, 2n)
            ra, rb = find(a), find(b)
            if ra != rb:
                fa[ra] = rb

        cnt = defaultdict(int)
        for x, _ in points:
            cnt[find(idx[x])] += 1

        sizes = sorted(cnt.values(), reverse=True)
        if len(sizes) >= 2:
            return sizes[0] + sizes[1] + 1
        return sizes[0] + 1
```

## 8. 边界情况与易错点

1. **X / Y 节点混淆（最大陷阱）**：值 $v$ 同时作为某些点的 x 和另一些点的 y 时，$X_v$ 与 $Y_v$ 必须是两个节点。合并会让连通块被错误地「串联」，答案偏大（见 §4 第 6 点反例）。

2. **新点不能与已有点重合**：跨块构造 $(x^*, y^*)$ 天然合法（重合会矛盾，见证明）；但**单块内**取「块内 x 值 + 块内 y 值」可能恰好撞上已有点（如整块只有一条边 $(x_0, y_0)$ 时），此时应改用「块内 x 值 + 全新 y 值」，同样得 $n + 1$。

3. **只有 1 个连通块**：答案 $n + 1$，不是 $n + 2$——新点至多激活自身所在的（同一个）块。

4. **$n = 1$**：单点即单块，答案 $2$。

5. **值域 $\pm 10^9$**：不能开桶数组，必须哈希离散化；C++ 中 `unordered_map` 足够，无需手写哈希。

6. **溢出**：$s_1 + s_2 + 1 \le n + 1 \le 100001$，`int` 安全；但若顺手写成 `long long` 也无妨。

7. **连通块个数的求法**：不要单独枚举根节点去重（那是 $2n$ 个节点），直接用「每块至少一条边」的事实，计数表条目数即块数。

**延伸思考**：

- 若允许添加 $k$ 个新点呢？每个新点是一条新边，至多把两个块并成一个；用 $j$ 个新点作桥可以把 $j + 1$ 个块连成一体，剩余新点挂在已激活块上各贡献 $1$，总数为「前 $\min(k+1, \text{块数})$ 大块之和」$+ \, k$。可行性（桥接边的树形安排与点不重合）可类似定理证明。
