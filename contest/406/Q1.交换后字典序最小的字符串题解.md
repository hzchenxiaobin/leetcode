# LeetCode 交换后字典序最小的字符串 题解

## 1. 题目概述

- **标题 / 题号**：交换后字典序最小的字符串（#3216，easy）
- **链接**：https://leetcode.cn/problems/lexicographically-smallest-string-after-a-swap/
- **来源**：LeetCode 第 406 场周赛 Q1
- **难度**：简单
- **标签**：贪心、字符串

**题意**：给定仅由数字组成的字符串 `s`，你可以**至多一次**交换两个**相邻**且**奇偶性相同**的数字（同为奇数或同为偶数），返回能得到的**字典序最小**的字符串。

**约束**：

- $2 \le s.length \le 100$
- `s` 仅由数字组成。

## 2. 示例

**示例 1**

```text
输入：s = "45320"
输出："43520"
解释：s[1]='5' 与 s[2]='3' 同为奇数且 5 > 3，交换它们使字典序变小。
```

**示例 2**

```text
输入：s = "001"
输出："001"
解释：(0,0) 同偶但相等，交换后串不变；(0,1) 奇偶不同不可换。原串已是最小。
```

**示例 3**

```text
输入：s = "13"
输出："13"
解释：1 与 3 同为奇数、可以交换，但 1 < 3，交换只会让串变大，不如不换。
```

## 3. 解题思路

### 3.1 暴力思路：枚举所有相邻对

从左到右枚举每个位置 $i$（$0 \le i < n-1$）：若 $s_i$ 与 $s_{i+1}$ 奇偶相同就交换一次、生成候选串，把所有候选与原串放在一起取字典序最小。候选至多 $n-1$ 个，每个的拷贝与比较各 $O(n)$，总计 $O(n^2)$；$n \le 100$ 轻松可过。但字典序比较**天生从左往右定胜负**——最左的改动永远优先级最高，暴力把每个位置一视同仁地试一遍，白白丢掉了这个结构。

### 3.2 核心观察：最左的「同奇偶降序对」一换即得

![核心观察：可换 = 相邻 + 同奇偶；有收益 = 前面更大](images/lexico_swap_scan_concept.svg)

**观察 1（什么交换有收益）**：交换相邻对 $(i, i+1)$ 后其余位置原样不动，位置 $i$ 变成 $s_{i+1}$——新旧两串的**第一个不同位置就是 $i$**，字典序大小由它一锤定音：

$$s' < s \iff s_{i+1} < s_i$$

即**前面更大才值得换**：相等则串不变（白费唯一的机会），前面更小则越换越大。

**观察 2（合法性门槛）**：题目只允许交换**同奇偶**的相邻数字。把两条合起来，**命中**位置 $i$ 满足：

$$s_i \equiv s_{i+1} \pmod 2 \;\; \text{且} \;\; s_i > s_{i+1}$$

**观察 3（最左命中完胜——交换论证）**：设 $i$ 为最左命中位置，则「换 $i$」就是全局最优：

- 对 $j < i$：由 $i$ 的最左性，$j$ 要么奇偶不同（**不可换**），要么 $s_j \le s_{j+1}$（换了**不变或变大**）——都不可能变小；
- 对 $j > i$：「换 $i$」与「换 $j$」的结果前缀 $s_0 \cdots s_{i-1}$ 完全相同，但位置 $i$ 上前者是 $s_{i+1}$、后者仍是 $s_i$；由 $s_{i+1} < s_i$ 知换 $i$ 的结果**严格更小**。

于是算法无比简短：**从左到右扫一遍，遇到第一个命中对就交换、立即收工**；一路扫完都没命中，说明任何合法交换都只会不变或变大，原串已最小，原样返回。

### 3.3 算法流程

![交换论证：最左命中 i 完胜更右的命中 j](images/lexico_swap_exchange_argument.svg)

```text
1. 从左到右扫描 i = 0 .. n-2
2. 若 s[i] 与 s[i+1] 奇偶相同 且 s[i] > s[i+1]：
3.     交换 s[i] 与 s[i+1]，立即 break   ←「至多一次」直接翻译成「换完就停」
4. 扫描结束仍无命中 → 原样返回 s
```

单趟 `for` 循环承担全部逻辑：一个 `if` 同时判「同奇偶」与「前面更大」，命中即 `swap` + `break`。

### 3.4 示例演算

![示例演算："45320" 与 "001" 的完整走查](images/lexico_swap_walkthrough.svg)

以 `"45320"` 为例：$i=0$ 的 $(4,5)$ 奇偶不同被拒；$i=1$ 的 $(5,3)$ 同为奇数且 $5>3$，**首个命中**——交换得 `"43520"`，立即 `break`。注意 $i=3$ 的 $(2,0)$ 其实也命中（换出 `"45302"`），但它更靠右、结果更大——这正是观察 3 的现场演示。

`"001"` 则一路扫不到任何命中：$(0,0)$ 同偶但**相等**（换了不变，白费机会），$(0,1)$ 奇偶不同——原样返回 `"001"`。

## 4. 算法细节

1. **奇偶判定 $O(1)$**：`(s[i] - '0') % 2` 或 `s[i] & 1`——'0' 的 ASCII 码 48 是偶数，减不减 '0' 奇偶性不变，只看最低二进制位即可。
2. **严格大于**：条件写 `s[i] > s[i+1]` 而非 `>=`。同奇偶且相等（如 `"001"` 的 $(0,0)$）交换后串完全不变，却烧掉唯一一次机会，应当跳过。
3. **命中即 `break`**：由观察 3，最左命中已严格最优，继续扫描没有任何收益；漏写 `break` 会做多次交换，直接违反题意。
4. **Python 的不可变字符串**：先 `list(s)` 转成字符数组原地交换，最后 `"".join(t)` 拼回。
5. **数据范围**：$n \le 100$，无溢出、无性能压力，是纯逻辑正确性题。

## 5. 正确性证明

**引理 1（交换的收益判定）**：设 $s'$ 为交换相邻对 $(i, i+1)$ 后的串，则 $s' < s \iff s_{i+1} < s_i$；且 $s' = s \iff s_{i+1} = s_i$。

**证明**：交换只改动位置 $i$ 与 $i+1$，故 $s'$ 与 $s$ 的首个不同位置（若存在）恰为 $i$，且 $s'[i] = s_{i+1}$。字典序由首个不同位置一锤定音：$s' < s \iff s_{i+1} < s_i$。若 $s_{i+1} = s_i$，则交换后所有位置字符不变，$s' = s$。∎

**引理 2（左交换压倒右交换）**：设 $i < j$ 且两处均为命中位置，$A$ 为仅在 $i$ 交换的结果，$B$ 为仅在 $j$ 交换的结果，则 $A < B$。

**证明**：在 $j$ 交换不影响位置 $0..j-1$，由 $i < j$ 知 $B$ 在位置 $0..i$ 上保持原值；在 $i$ 交换不影响位置 $0..i-1$。故 $A$ 与 $B$ 的前 $i$ 个位置均为 $s_0 \cdots s_{i-1}$，完全相同。而 $A[i] = s_{i+1}$，$B[i] = s_i$，由命中条件 $s_{i+1} < s_i$ 得 $A[i] < B[i]$——两串首个不同位置为 $i$ 且 $A$ 更小。∎

**定理**：返回「最左命中交换一次（若存在），否则原串」即为字典序最小的可行结果。

**证明**：可行结果集 = {原串（不换）} ∪ {在位置 $k$ 交换：$s_k$ 与 $s_{k+1}$ 同奇偶}。分三类比较：

- **非命中的合法交换**（$s_k \le s_{k+1}$）：由引理 1 其结果 $\ge$ 原串，不可能严格优于「不换」；
- **命中交换之间**：由引理 2，最左命中 $i$ 的结果严格小于任何更右命中的结果；
- **命中 vs 其余**：由引理 1，换 $i$ 的结果严格小于原串，而原串又 $\le$ 所有非命中交换的结果。

故命中存在时换最左者即全局最小；命中不存在时所有合法交换结果 $\ge$ 原串，原串即最小。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。单趟扫描，每个位置两次 $O(1)$ 判定（奇偶 + 大小），命中即停；$n \le 100$ 下近似常数。
- **空间复杂度**：$O(1)$。C++ 原地交换；Python 因字符串不可变需 $O(n)$ 的辅助 `list`。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    string getSmallestString(string s) {
        for (int i = 0; i + 1 < (int)s.size(); i++) {
            if ((s[i] - '0') % 2 == (s[i + 1] - '0') % 2 && s[i] > s[i + 1]) {
                swap(s[i], s[i + 1]);
                break;   // 至多一次交换，命中即收工
            }
        }
        return s;
    }
};
```

### Python

```python
class Solution:
    def getSmallestString(self, s: str) -> str:
        t = list(s)  # 字符串不可变，转 list 原地交换
        for i in range(len(t) - 1):
            if (int(t[i]) & 1) == (int(t[i + 1]) & 1) and t[i] > t[i + 1]:
                t[i], t[i + 1] = t[i + 1], t[i]
                break
        return "".join(t)
```

## 8. 边界情况与易错点

1. **相等对别换**：同奇偶且相等不满足严格大于，换了串不变还烧掉唯一机会；条件必须写 `>` 而非 `>=`。
2. **忘了 `break`**：命中后继续循环甚至再次交换是最典型的 WA——题目只允许**一次**交换。
3. **奇偶判定别绕晕**：稳妥写 `(s[i]-'0') % 2 == (s[i+1]-'0') % 2`。若想用 `(s[i] - s[i+1]) % 2 == 0` 判同奇偶，注意 C++ 负数取模：差为奇数时结果是 `-1` 而非 `1`，判 `== 0` 恰好不受影响，但判 `== 1` 必错。
4. **无命中返回原串**：整趟没换就原样返回，不要返回空串或硬造一次交换。
5. **$n = 2$**：最小规模只有一个候选对，循环逻辑自然覆盖，无需特判。
6. **Python 记得转 `list`**：直接对 `str` 下标赋值会抛 `TypeError`。
