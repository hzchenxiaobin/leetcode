# LeetCode 跳跃游戏 VII 题解

## 1. 题目概述

- **标题 / 题号**：跳跃游戏 VII（#1871，medium）
- **链接**：https://leetcode.cn/problems/jump-game-vii/
- **来源**：LeetCode 第 242 场周赛 Q3
- **难度**：中等
- **标签**：字符串、动态规划、前缀和、差分

**题意**：给定二进制字符串 $s$（下标从 0 开始）与整数 $\text{minJump}$、$\text{maxJump}$。起初站在下标 0 处（题目保证 $s[0] = \text{'0'}$）。从下标 $i$ 可以一步跳到下标 $j$，当且仅当 $i + \text{minJump} \le j \le \min(i + \text{maxJump},\ n-1)$ 且 $s[j] = \text{'0'}$。问能否经过若干步到达下标 $n-1$，能则返回 `true`。

**约束**：

- $2 \le n \le 10^5$
- $s[i] \in \{\text{'0'}, \text{'1'}\}$，且 $s[0] = \text{'0'}$
- $1 \le \text{minJump} \le \text{maxJump} < n$

> 💡 **读题三个信号**：① 问「能否到达」而非「最少几步」——是**可达性判定**，想到布尔 DP 或 BFS；② 一步的落点是一**段区间** $[i+\text{minJump},\ i+\text{maxJump}]$ 而非单个位置——「区间转移 DP」；③ 落点必须 $s[j] = \text{'0'}$，'1' 是障碍格。三者叠加即经典「**区间转移 + 存在性查询**」模型：dp 值只有 0/1 两态，前缀和 / 滑动窗口计数 / 差分任取其一，都能把 $O(n^2)$ 的暴力压到 $O(n)$。

## 2. 示例

**示例 1**

```text
输入：s = "011010", minJump = 2, maxJump = 3
输出：true
解释：0 —跳 3→ 3 —跳 2→ 5，两步到达末尾。
```

**示例 2**

```text
输入：s = "01101110", minJump = 2, maxJump = 3
输出：false
解释：全程可达的落脚点只有 0 和 3；从 3 出发能落 [5, 6]，但 s[5]、s[6] 均为 '1'，到不了 7。
```

**示例 3（补充：同串不同参数，结果翻转）**

```text
输入：s = "011010", minJump = 1, maxJump = 1
输出：false
解释：每步只能恰好跳 1 格，s[1] = '1' 直接堵死，寸步难行。
```

> 💡 示例 1 与示例 3 字符串相同、答案相反——**步长下界 minJump 是本题的灵魂约束**：步长太小可能被 '1' 一步一步卡死，步长大反而可能「跨过」障碍。这也是本题与 55. 跳跃游戏（步长上界内任跳、无障碍）最大的结构差异。

## 3. 解题思路

### 3.1 暴力思路：枚举来源，逐个检查

定义 $dp[i]$ 表示「位置 $i$ 是否可达」，$dp[0] = \text{true}$。把一步转移条件**反解**成「谁能跳到我」（推导见 §5 引理 1）：

$$dp[i] \;=\; \big(s[i] = \text{'0'}\big) \wedge \Big( \exists\, j \in \big[\max(0,\, i-\text{maxJump}),\; i-\text{minJump}\big] :\; dp[j] = \text{true} \Big)$$

朴素实现就是对每个 $i$ 把这个「来源窗口」扫一遍：

```python
dp = [False] * n
dp[0] = True
for i in range(1, n):
    if s[i] == '1':
        continue
    for j in range(max(0, i - maxJump), i - minJump + 1):
        if dp[j]:
            dp[i] = True
            break
```

窗口宽度 $w = \text{maxJump} - \text{minJump} + 1$ 最坏接近 $n$，总时间 $O(n \cdot w) \approx O(n^2)$，$n = 10^5$ 时约 $10^{10}$ 次操作，必然超时。正向暴力（对每个可达 $i$ 去标记 $[i+\text{minJump},\ i+\text{maxJump}]$ 内所有 '0' 位置）同病相怜，也是 $O(n \cdot w)$。

> ⚠️ 瓶颈在于：判定窗口内「**是否存在**一个 true」却付出了「**遍历全部**」的代价。dp 值域只有 $\{0, 1\}$——布尔量的区间存在性查询，正是**前缀和**的拿手好戏。

### 3.2 核心观察：反向来源窗口 + 前缀和 O(1) 判定

![核心观察：反向来源窗口 [i−maxJump, i−minJump] 与前缀和判定](images/wc242_q3_source_window.svg)

按 $i$ 从左到右填 $dp$，计算 $dp[i]$ 时来源窗口 $[\max(0,\, i-\text{maxJump}),\; i-\text{minJump}]$ **完全落在已填好的前缀里**（右端 $i - \text{minJump} \le i - 1$）。维护「dp 的前缀和」：

$$pre[i+1] = pre[i] + dp[i] \quad\Longleftrightarrow\quad pre[t] = \big|\{\, j < t : dp[j] = \text{true} \,\}\big|$$

则「窗口 $[lo, hi]$ 内存在可达位置」等价于**一次减法**：

$$pre[hi+1] - pre[lo] > 0$$

每个位置的判定从 $O(w)$ 降到 $O(1)$，总时间 $O(n)$。

三个配套细节：

1. **窗口为空**：$i < \text{minJump}$ 时 $hi = i - \text{minJump} < 0$，无合法来源，$dp[i] = \text{false}$（起点第一跳至少跨 $\text{minJump}$ 格，下标 $1 \sim \text{minJump}-1$ 天然不可达）。
2. **左端钳制**：$lo = \max(0,\ i - \text{maxJump})$，防负下标。
3. **终点剪枝**：$s[n-1] = \text{'1'}$ 直接返回 `false`——终点必须能落脚，这一刀在 DP 之前砍掉。

### 3.3 对偶视角：差分正向「泼漆」

![对偶视角：可达位置向右泼漆，差分数组 O(1) 区间 +1](images/wc242_q3_diff_forward.svg)

前缀和是「**向左看**」：问我的来源窗口里有没有可达位置。反过来「**向右看**」同样成立：每个确认可达的位置 $i$，向区间 $[i+\text{minJump},\; \min(i+\text{maxJump},\, n-1)]$ 泼一桶油漆；位置 $j$ 可达 $\iff$ $s[j] = \text{'0'}$ 且**被泼到至少一次**。

「泼漆 = 区间整体 +1」用**差分数组** $O(1)$ 完成：$diff[l] \mathrel{+}= 1$、$diff[r+1] \mathrel{-}= 1$；扫描到 $j$ 时用 $covered \mathrel{+}= diff[j]$ 边走边恢复覆盖数。起点 0 先泼 $[\text{minJump},\ \text{maxJump}]$ 一桶，之后每发现一个可达位置就补一桶。

两种视角是**同一转移边集的两种读法**（反向窗口查询 $\Leftrightarrow$ 正向区间覆盖），复杂度都是 $O(n)$。比赛中哪个顺手写哪个——前缀和版更「DP」，差分版更「BFS/传播」，本文参考代码两版都给。

### 3.4 算法流程

前缀和版共四步：

1. **剪枝**：若 $s[n-1] \ne \text{'0'}$，返回 `false`。
2. **初始化**：$dp[0] = \text{true}$，$pre[1] = 1$（其余 $pre$ 值为 0）。
3. **扫描**：$i$ 从 1 到 $n-1$：
   - 若 $s[i] = \text{'0'}$ 且 $i \ge \text{minJump}$：令 $lo = \max(0,\ i-\text{maxJump})$、$hi = i - \text{minJump}$，判定 $dp[i] = (pre[hi+1] - pre[lo] > 0)$；
   - 更新 $pre[i+1] = pre[i] + dp[i]$。
4. **返回** $dp[n-1]$。

差分版把第 3 步换成：先给 $[\text{minJump},\ \text{maxJump}]$ 打差分；$i$ 从 1 到 $n-1$ 恢复 $covered$，若 $s[i] = \text{'0'}$ 且 $covered > 0$，再给 $[i+\text{minJump},\ \min(i+\text{maxJump}, n-1)]$ 打差分（$i + \text{minJump} \ge n$ 时无需泼漆）；循环结束时的 $covered$ 即位置 $n-1$ 的覆盖数。

### 3.5 示例演算

![示例演算：s="011010" 的前缀和版逐步走查](images/wc242_q3_example_walkthrough.svg)

以示例 1（$s = \text{"011010"}$，$\text{minJump}=2$，$\text{maxJump}=3$）走查：

| $i$ | $s[i]$ | 来源窗口 $[lo, hi]$ | 查询 $pre[hi{+}1]-pre[lo]$ | $dp[i]$ | 说明 |
|:---:|:---:|:---:|:---:|:---:|------|
| 0 | 0 | —（起点） | — | **T** | 基例 |
| 1 | 1 | 空（$i < \text{minJump}$） | — | F | 无合法来源 |
| 2 | 1 | $[0, 0]$ | $pre[1]-pre[0] = 1$ | F | 查询为正但 $s[2]=\text{'1'}$ 挡住 |
| 3 | 0 | $[0, 1]$ | $pre[2]-pre[0] = 1$ | **T** | 下标 0 可达，一跳到 3 |
| 4 | 1 | $[1, 2]$ | $pre[3]-pre[1] = 1$ | F | 同样被 '1' 挡住 |
| 5 | 0 | $[2, 3]$ | $pre[4]-pre[2] = 1$ | **T** | 窗口内 $dp[3]=T$，收官 |

最终 $dp[5] = \text{true}$，返回 `true`，路径 $0 \to 3 \to 5$。

> 💡 **i=2 行是精髓**：前缀和查询 $1 > 0$ 说明「来源够了」，但 $s[2] = \text{'1'}$ 让这一格仍不可达——**可达 = 有可达前驱 ∧ 自己能落脚**，两个条件缺一不可。而示例 2 的失败定格在 $i=7$：窗口 $[4, 5]$ 内 $dp$ 全为 F，$pre[6]-pre[4] = 2-2 = 0$，差分版对应「7 从未被泼到」。

## 4. 算法细节

1. **pre 的下标约定**：$pre[t] = \sum_{j<t} dp[j]$，闭区间 $[lo, hi]$ 的计数写成 $pre[hi+1] - pre[lo]$——与「长度最小的子数组」等前缀和题保持同一肌肉记忆，左开右闭减法永不失手。
2. **判定与更新的顺序**：$\text{minJump} \ge 1$ 保证位置 $i$ 不在自己的来源窗口内（$i - \text{minJump} < i$），故「先判 $dp[i]$ 再更新 $pre[i+1]$」与「先更新再判」等价；按前者写语义更清晰。
3. **类型与溢出**：$pre$ 值域 $\le n \le 10^5$，`int` 绰绰有余——对比本场 Q2 的 `long long` 判定式，本题全程无溢出风险，C++ 用 `vector<int>` + `vector<char>` 即可。
4. **按查询语义选数据结构**：布尔 dp 的「区间存在性」→ 前缀和 / 滑窗计数；数值 dp 的「区间取 max」（如 1696 跳跃游戏 VI）→ 单调队列；任意区间查询 → 线段树/树状数组。同一「区间转移 DP」骨架，优化手段跟着**查询语义**走。
5. **差分版的两处钳制**：右端 $\min(i+\text{maxJump},\ n-1)$ 使 $r+1 \le n$ 不越界；$i + \text{minJump} \ge n$ 时区间整体出界，无需泼漆。
6. **为什么不用 BFS**：转移只能向右（$j \ge i + \text{minJump} > i$），状态天然构成按**下标序排列的 DAG**，拓扑序就是下标序——BFS 的队列在这里退化为一个 for 循环。若同一位置被多个前驱重复入队还不去重，复杂度反而退化。

## 5. 正确性证明

**引理 1（一步转移的改写）**：对 $1 \le i \le n-1$，从 $j$ 一步跳到 $i$ 合法 $\iff$ $s[i] = \text{'0'}$ 且 $j \in [\max(0,\, i-\text{maxJump}),\; i-\text{minJump}]$。

**证明**：一步合法需同时满足 $j + \text{minJump} \le i$、$i \le \min(j + \text{maxJump},\ n-1)$、$s[i] = \text{'0'}$。由 $i \le n-1$ 知 $i \le \min(j+\text{maxJump},\ n-1) \iff i \le j + \text{maxJump}$；两个不等式分别反解为 $j \le i - \text{minJump}$ 与 $j \ge i - \text{maxJump}$；再与 $j \ge 0$ 取交即得。∎

**引理 2（可达性的归纳刻画）**：位置 $i$ 可达 $\iff$ $i = 0$；或 $s[i] = \text{'0'}$ 且来源窗口 $[\max(0,\, i-\text{maxJump}),\; i-\text{minJump}]$（$i \ge \text{minJump}$ 时非空）内存在可达位置。

**证明**：（$\Rightarrow$）设 $i \ge 1$ 可达，取一条从 0 到 $i$ 的跳跃路径，其倒数第二个位置 $j$ 可达且 $j \to i$ 是合法一步，由引理 1 即得两条件。（$\Leftarrow$）窗口内存在可达 $j$，从 0 走到 $j$ 后再跳一步到 $i$（引理 1 保证该步合法），故 $i$ 可达。∎

**引理 3（前缀和计数等价）**：若 $dp[0..i-1]$ 均已正确，则对 $0 \le lo \le hi \le i-1$ 有 $pre[hi+1] - pre[lo] = \big|\{\, j \in [lo, hi] : dp[j] = \text{true} \,\}\big|$。

**证明**：由 $pre$ 的递推 $pre[t] = \sum_{j=0}^{t-1} dp[j]$，相减得 $pre[hi+1] - pre[lo] = \sum_{j=lo}^{hi} dp[j]$，恰为窗口内 true 的个数。∎

**定理（算法正确性）**：算法终止时对所有 $0 \le i \le n-1$ 有 $dp[i] = [\,i\ \text{可达}\,]$，故返回值正确。

**证明**：对 $i$ 强归纳。$i = 0$：$dp[0] = \text{true}$，且 $s[0] = \text{'0'}$ 保证起点可达，成立。设 $dp[0..i-1]$ 均正确，考察 $i \ge 1$：

- 若 $s[i] = \text{'1'}$：引理 2 的必要条件 $s[i] = \text{'0'}$ 不满足，$i$ 不可达，算法中 $dp[i]$ 保持 `false` ✓。
- 若 $i < \text{minJump}$：来源窗口为空（$i - \text{minJump} < 0$ 时区间内没有任何 $j \ge 0$ 能同时满足引理 1 的界），引理 2 的存在性条件不可能成立，$i$ 不可达，算法跳过判定、$dp[i] = \text{false}$ ✓。
- 否则 $s[i] = \text{'0'}$ 且 $i \ge \text{minJump}$：由引理 3，$pre[hi+1] - pre[lo] > 0 \iff$ 窗口内存在 $j$ 使 $dp[j] = \text{true}$；由归纳假设，后者 $\iff$ 窗口内存在**可达** $j$。结合引理 2，$dp[i]$ 恰为 $[\,i\ \text{可达}\,]$ ✓。

归纳完成；返回 $dp[n-1]$ 即「$n-1$ 可达」的判定。∎

> 💡 **差分版的正确性**可由引理 2 直接读出：$covered_j > 0 \iff$ 至少一个可达位置 $i$ 的泼漆区间覆盖 $j$ $\iff$（引理 1 的对称形式）$j$ 的来源窗口内存在可达位置。差分数组按定义精确恢复覆盖数，不多不少；「被泼到」与「窗口内有前驱」是同一关系在不同方向上的投影。

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。前缀和版每个下标的循环体只有一次减法、一次比较、一次加法，均为 $O(1)$；差分版同理（每步一次恢复 + 至多一次泼漆，每个位置至多泼一桶）。
- **空间复杂度**：$O(n)$。前缀和版需 $dp$ 与 $pre$ 两个数组（把 $dp$ 压进 $pre$ 的增量可省一个）；差分版需 $diff$ 数组。两版都**无法降到 $O(1)$**：判定 $dp[i]$ 要回看最多 $\text{maxJump}$ 之前的 dp 值（等价地，出窗/差分恢复需要历史信息），历史必须留档。

## 7. 参考代码

### C++（前缀和版）

```cpp
class Solution {
  public:
    bool canReach(string s, int minJump, int maxJump) {
        int n = s.size();
        if (s[n - 1] != '0') return false;      // 终点必须能落脚

        vector<char> dp(n, 0);
        dp[0] = 1;
        vector<int> pre(n + 1, 0);              // pre[i+1] = dp[0..i] 中 true 的个数
        pre[1] = 1;

        for (int i = 1; i < n; ++i) {
            if (s[i] == '0' && i >= minJump) {  // i < minJump 时窗口为空
                int lo = max(0, i - maxJump);   // 来源窗口 [lo, i-minJump]
                int hi = i - minJump;
                dp[i] = pre[hi + 1] - pre[lo] > 0;
            }
            pre[i + 1] = pre[i] + dp[i];
        }
        return dp[n - 1];
    }
};
```

### Python（前缀和版）

```python
class Solution:
    def canReach(self, s: str, minJump: int, maxJump: int) -> bool:
        n = len(s)
        if s[-1] != '0':
            return False

        dp = [False] * n
        dp[0] = True
        pre = [0] * (n + 1)                     # pre[i+1] = dp[0..i] 中 True 的个数
        pre[1] = 1

        for i in range(1, n):
            if s[i] == '0' and i >= minJump:    # i < minJump 时窗口为空
                lo = max(0, i - maxJump)        # 来源窗口 [lo, i-minJump]
                hi = i - minJump
                dp[i] = pre[hi + 1] - pre[lo] > 0
            pre[i + 1] = pre[i] + dp[i]

        return dp[-1]
```

### Python（差分正向传播版）

```python
class Solution:
    def canReach(self, s: str, minJump: int, maxJump: int) -> bool:
        n = len(s)
        if s[-1] != '0':
            return False

        diff = [0] * (n + 1)                    # 覆盖计数的差分数组
        diff[minJump] += 1                      # 起点 0 先泼 [minJump, maxJump]
        diff[maxJump + 1] -= 1
        covered = 0

        for i in range(1, n):
            covered += diff[i]                  # 恢复：当前被几个可达区间覆盖
            if s[i] == '0' and covered > 0 and i + minJump < n:
                diff[i + minJump] += 1          # i 可达 ⇒ 向右泼一桶
                diff[min(i + maxJump, n - 1) + 1] -= 1

        return covered > 0                      # 循环结束时 covered 即位置 n-1 的覆盖数
```

> ⚠️ 差分版的 `return covered > 0` 之所以成立，前提是开头已剪枝 $s[n-1] = \text{'0'}$：循环最后一次迭代把 `covered` 更新为位置 $n-1$ 的覆盖数，而「泼漆」只影响 $i$ 之后的位置（$i + \text{minJump} > i$），不干扰当前值。两版代码均已对拍验证：官方两例 + 自造边界（`"00"`/`"011010"` 配 $\text{minJump}{=}\text{maxJump}{=}1$ 等）+ 3000 组随机串与 BFS 暴力互验，全部一致。

## 8. 边界情况与易错点

1. **终点是 '1'**：必须返回 `false`。先剪枝 `s[n-1] != '0'`，既正确又省一趟 DP；差分版还**依赖**这个剪枝保证末尾 `covered > 0` 语义完整。
2. **去掉 `i >= minJump` 守卫会越界**：$i < \text{minJump}$ 时 $hi + 1 = i - \text{minJump} + 1 \le 0$，Python 里 `pre[负数]` 会静默取到数组**尾部**的垃圾值（不报错、更隐蔽），C++ 直接未定义行为。窗口为空的判定必须在查询之前。
3. **左端不钳制 `max(0, i - maxJump)`**：$i < \text{maxJump}$ 时 `pre[lo]` 负下标，同上越界。
4. **minJump == maxJump 的「定长跳」退化**：只能踩固定间隔的格子（如 $s = \text{"0000000"}$、步长恒为 2 时只能踩 0/2/4/6），某格为 '1' 即断链——窗口逻辑天然覆盖，无需特判，但脑内要有这个模型，示例 3 就是它的极端形态。
5. **差分版忘记「出界不泼漆」**：$i + \text{minJump} \ge n$ 仍执行 `diff[i+minJump] += 1` 会越界；右端不钳制 $\min(i+\text{maxJump},\ n-1)$ 则 $r+1$ 可达 $n+1$ 越界。
6. **别用裸 BFS**：同一位置会被多个前驱重复入队，不去重复杂度退化到 $O(n \cdot w)$；去了重的 BFS 本质就是本 DP（visited 数组 = dp 数组），多绕一圈。
7. **pre 更新遗漏**：即使 $s[i] = \text{'1'}$（$dp[i]$ 为假），$pre[i+1] = pre[i]$ 这一步也必须执行，否则后续所有查询下标错位——前缀和的「每格必填」纪律。
8. **约束的边界取值**：允许 $\text{maxJump} = n-1$（初始泼漆区间 $[\text{minJump},\ n-1]$ 恰好贴边不越界），也允许 $n = 2$（如 `"00"`、步长 1 一步直达），两版代码均自然覆盖。
