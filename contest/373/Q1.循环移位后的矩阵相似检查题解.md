# LeetCode 循环移位后的矩阵相似检查 题解

## 1. 题目概述

- **标题 / 题号**：循环移位后的矩阵相似检查（#2946，easy）
- **链接**：https://leetcode.cn/problems/matrix-similarity-after-cyclic-shifts/
- **来源**：LeetCode 第 373 场周赛 Q1
- **难度**：简单
- **标签**：数组、矩阵、数学、模拟

**题意**：给定 $m \times n$ 的下标从 0 开始的整数矩阵 `mat` 与整数 $k$。重复执行 $k$ 次操作：**偶数行**（下标 $0, 2, 4, \dots$）循环**左移**一位，**奇数行**（下标 $1, 3, 5, \dots$）循环**右移**一位。若 $k$ 次操作后的最终矩阵与原矩阵**完全相同**，返回 `true`，否则返回 `false`。

**约束**：

- $1 \le m = mat.length \le 25$
- $1 \le n = mat[i].length \le 25$
- $1 \le mat[i][j] \le 25$
- $1 \le k \le 50$

> 💡 读题抓形态：**整体判定型模拟**——只问"最终是否复原"，不问中间过程。循环移位天然带**周期 $n$**（连移 $n$ 位回到自身），所以 $k$ 次操作可以合并；"新旧相同"逐位展开后，每行只和自己比较。签到题要抠的三个细节：**$k$ 可以大于 $n$，取模是正确性必需**；**奇偶行方向相反但判据可以统一**；**不需要构造移位后的矩阵**。

## 2. 示例

**示例 1**

```text
输入：mat = [[1,2,3],[4,5,6],[7,8,9]], k = 4
输出：false
解释：每一步中，行 0 和行 2（偶数下标）左移，行 1（奇数下标）右移。
4 步后矩阵不再与原矩阵相同。
```

**示例 2**

```text
输入：mat = [[1,2,1,2],[5,5,5,5],[6,3,6,3]], k = 2
输出：true
解释：每行都是「长度 2 的块重复 2 次」的形态，左移 / 右移 2 位后恰好复原。
```

**示例 3**

```text
输入：mat = [[2,2],[2,2]], k = 3
输出：true
解释：矩阵中的所有值都相等，任何循环移位都不改变矩阵。
```

**补充示例：k 是 n 的倍数**

```text
输入：mat = [[1,2],[3,4]], k = 2
输出：true
解释：k mod n = 0，所有行等价于移 0 位，矩阵原样不动——与内容无关恒 true。
```

## 3. 解题思路

### 3.1 暴力思路

按题意老实模拟 $k$ 轮：每轮把偶数行整体左移一位、奇数行右移一位（用 $(j \pm 1) \bmod n$ 的下标映射或库函数 `rotate`），$k$ 轮结束后与原矩阵逐格比较。时间 $O(k \cdot m \cdot n) \le 50 \times 25 \times 25 = 31250$ 次元素操作，本约束下轻松通过。但这条路线埋着三个坑：**方向写反**（左移是 $new[j] = old[(j+1) \bmod n]$，不是 $j-1$）、**取模遗漏**（$k$ 可大于 $n$）、**白白维护 $k$ 个中间状态**。更好的做法是让数学替我们干活。

### 3.2 核心观察：移位合并 + 奇偶判据统一

![核心概念：k 次移位合并与奇偶判据统一](images/wc373_q1_shift_merge_concept.svg)

1. **移位合并（周期性）**：行长为 $n$，向任一方向连移 $n$ 位回到自身，因此 $k$ 次同向单位移位等价于**一次**移 $k \bmod n$ 位。本约束 $n \le 25 < k \le 50$，$k$ 完全可能超过 $n$——**取模不是优化，是正确性必需**。
2. **终态逐位表达**：偶行左移 $k$ 位后 $new[j] = old[(j+k) \bmod n]$；奇行右移 $k$ 位后 $new[j] = old[(j-k) \bmod n]$。
3. **判据统一**：复原即 $\forall j$ 逐位相等。对奇行条件 $\forall j:\ old[j] = old[(j-k) \bmod n]$ 做换元 $j \to (j+k) \bmod n$（$\{0,\dots,n-1\}$ 上的双射，全称量词下换元合法），得到 $\forall j:\ old[j] = old[(j+k) \bmod n]$——与偶行**完全一致**。奇偶只影响移位方向，不影响"复原"的判定条件。

于是整道题收敛为一行判据：

$$\text{返回 true} \iff \forall\, i, j:\quad mat[i][j] = mat[i][(j+k) \bmod n]$$

连方向都不用管，一次双重循环原地逐格比较即可。

**推论（周期结构）**：上述条件等价于每行在旋转 $g = \gcd(n, k)$ 步下不变，即**每行是长度为 $g$ 的块重复 $n/g$ 次**。示例 2 中 $g = \gcd(4,2) = 2$，三行恰是 $[1,2]$、$[5,5]$、$[6,3]$ 各重复两次；示例 1 中 $g = \gcd(3,4) = 1$，要求每行全等，立刻 `false`。

### 3.3 算法流程

![算法流程：双重循环逐格判定](images/wc373_q1_algorithm_flow.svg)

1. **初始化**：读入列数 $n$，行指针 $i = 0$；
2. **外层**：若 $i \ge m$，说明所有行通过检查，返回 `true`；
3. **内层**：$j$ 从 $0$ 到 $n-1$，检查 `row[j] == row[(j+k) % n]`，任一格不等**立即**返回 `false`（短路）；
4. **推进**：内层走完 $i{+}{+}$ 换下一行，回到第 2 步。

### 3.4 示例演算

![示例 2 演算：同色格必须相等](images/wc373_q1_example_walkthrough.svg)

以示例 2（$k = 2$，$n = 4$）为例，每行只需检查 $j$ 与 $(j+2) \bmod 4$ 这两对格子：

| 行 | 配对检查（$j \leftrightarrow (j+2) \bmod 4$） | 结果 |
|----|---------------------------------------------|------|
| 行 0（偶·左移） | $1 = 1$ ✓（$0 \leftrightarrow 2$），$2 = 2$ ✓（$1 \leftrightarrow 3$） | ✓ |
| 行 1（奇·右移） | $5 = 5$ ✓，$5 = 5$ ✓ | ✓ |
| 行 2（偶·左移） | $6 = 6$ ✓，$3 = 3$ ✓ | ✓ |

三行全部通过，返回 `true`。对照示例 1（$n = 3$，$k = 4$，$s = k \bmod n = 1$）：行 0 的首个比较是 $mat[0][0] = 1$ 与 $mat[0][(0+4) \bmod 3] = mat[0][1] = 2$，不相等，**第一格就短路返回 `false`**。

## 4. 算法细节

1. **取模写进下标里**：直接写 `row[j] != row[(j + k) % n]`，连预处理 $s = k \bmod n$ 都可以省——$j + k \le 24 + 50 = 74$，`int` 毫无溢出风险，`%` 天然吸收 $k \ge n$ 与 $k$ 为 $n$ 倍数的所有情况。
2. **奇偶行零分支**：核心观察 3 已证明两个方向的条件在 $\forall j$ 量化下等价，代码里**根本不出现行奇偶判断**——少一个分支就少一个把左移右移符号写反的机会。
3. **零拷贝**：不构造移位后的矩阵，逐格原地比较，只返回布尔值；对比模拟法需要 $O(mn)$ 的矩阵副本或原地 `rotate`。
4. **短路返回**：发现第一处不等立即 `false`；最坏情况（全等矩阵或最后一格才失配）仍是 $O(m \cdot n)$。

## 5. 正确性证明

**引理 1（移位合并）**：长度为 $n$ 的行 $a$ 左移 $t$ 位所得 $b$ 满足 $b[j] = a[(j+t) \bmod n]$；右移 $t$ 位满足 $b[j] = a[(j-t) \bmod n]$。且结果只依赖 $t \bmod n$。

**证明**：对 $t$ 归纳。$t = 0$ 平凡。左移一位的定义为 $b[j] = a[(j+1) \bmod n]$；若左移 $t$ 位得 $c[j] = a[(j+t) \bmod n]$，则再左移一位得 $d[j] = c[(j+1) \bmod n] = a[(j+t+1) \bmod n]$，归纳成立。右移将 $+t$ 换成 $-t$ 同理。又 $(j+t) \bmod n$ 只依赖 $t \bmod n$，得周期性。∎

**引理 2（偶行判定）**：偶行 $a$ 经 $k$ 次左移后与原行相等 $\iff \forall j:\ a[j] = a[(j+k) \bmod n]$。

**证明**：由引理 1，$k$ 次左移的终态为 $b[j] = a[(j+k) \bmod n]$；"行相同"即逐元素相等 $b[j] = a[j]$，代入即得。∎

**引理 3（奇行判定统一）**：$\forall j:\ a[j] = a[(j-k) \bmod n] \iff \forall j:\ a[j] = a[(j+k) \bmod n]$。

**证明**：记 $\sigma(j) = (j+k) \bmod n$，它是 $\{0, \dots, n-1\}$ 上的双射，且 $\sigma^{-1}(j) = (j-k) \bmod n$。左式为 $\forall j:\ a[j] = a[\sigma^{-1}(j)]$，作换元 $j = \sigma(j')$（双射 + 全称量词，换元合法）得 $\forall j':\ a[\sigma(j')] = a[j']$，即右式；反之对称。直观解释：若行在"旋转 $k$ 步"下不变，则连续施两次也不变，归纳知对 $k$ 的任何倍数移位都不变，而 $-k \equiv (n-1)k \pmod n$ 是 $k$ 的倍数。∎

**定理**：算法返回 `true` $\iff$ $k$ 次操作后的矩阵与原矩阵相同。

**证明**：操作只做行内循环移位、行间不交换元素，故矩阵相同 $\iff$ 每行各自相同。偶行由引理 1 + 2、奇行由引理 1 + 3，均得 $\forall j:\ mat[i][j] = mat[i][(j+k) \bmod n]$。算法枚举全部 $(i, j)$ 检查的正是该条件，逐格等价。∎

**推论（周期结构）**：返回 `true` $\iff$ 每行是以 $g = \gcd(n, k)$ 为循环周期的序列（前 $g$ 个元素重复 $n/g$ 次）。

**证明**：保持行不变的旋转构成 $\mathbb{Z}_n$ 的子群；含"旋转 $k$ 步"就含其生成的子群 $\langle k \rangle$（由 Bézout，$g = \gcd(n,k) \equiv vk \pmod n$，故 $g \in \langle k \rangle$）。因此不变 $\iff$ 在旋转 $g$ 步下不变 $\iff a[j] = a[(j+g) \bmod n]$ 对 $\forall j$ 成立 $\iff$ 长度 $g$ 的块重复 $n/g$ 次。∎

## 6. 复杂度分析

- **时间复杂度**：$O(m \cdot n)$。双重循环每格一次比较、一次取模；最坏情况（如全等矩阵）必须确认所有格子才能返回 `true`，$\Omega(m \cdot n)$ 是读取下界，一趟判定已最优。模拟 $k$ 轮的 $O(k \cdot m \cdot n)$（本约束下 $\le 31250$ 次操作）也能过，但纯属浪费。
- **空间复杂度**：$O(1)$。仅下标与常数个变量，原地判定，不构造任何中间矩阵（模拟法需 $O(m \cdot n)$ 副本或原地轮转）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool areSimilar(vector<vector<int>>& mat, int k) {
        int n = mat[0].size();
        for (const auto& row : mat) {
            for (int j = 0; j < n; j++) {
                if (row[j] != row[(j + k) % n]) {
                    return false;
                }
            }
        }
        return true;
    }
};
```

### Python

```python
class Solution:
    def areSimilar(self, mat: List[List[int]], k: int) -> bool:
        n = len(mat[0])
        return all(row[j] == row[(j + k) % n]
                   for row in mat for j in range(n))
```

## 8. 边界情况与易错点

1. **忘取模**：$k \le 50$ 可以大于 $n$（$n$ 最小为 1），`row[j + k]` 直接下标越界；必须写 `row[(j + k) % n]`。
2. **k 是 n 的倍数**：等价于移 0 位，恒返回 `true`，无需特判，判据自然成立。
3. **n = 1 单列矩阵**：$(j+k) \bmod 1 = 0 = j$，恒 `true`。
4. **方向写反（模拟路线专属坑）**：左移是 $new[j] = old[(j+1) \bmod n]$，不是 $j-1$；且奇偶行方向相反。判据法连方向都不出现，从根上免疫。
5. **画蛇添足的奇偶分支**：判据已统一，代码里加 `if (i % 2)` 分支不会错（两个方向条件等价），但多一处手滑空间，属于负优化。
6. **构造新矩阵再比较**：能对，但多 $O(mn)$ 空间与一轮拷贝；原地逐格比较即可。
