# LeetCode 统计美丽子字符串 II 题解

## 1. 题目概述

- **标题 / 题号**：统计美丽子字符串 II（#2949，hard）
- **链接**：https://leetcode.cn/problems/count-beautiful-substrings-ii/
- **来源**：LeetCode 第 373 场周赛 Q4
- **难度**：困难
- **标签**：哈希表、数学、字符串、数论、前缀和

**题意**：与 Q2（#2947）完全同一题面：给定字符串 `s` 与正整数 $k$，统计 `s` 中同时满足 ① 元音数与辅音数**相等**、② 两者数量的**乘积**能被 $k$ 整除的**非空美丽子字符串**个数。唯一区别是数据范围——$n$ 上限从 $10^3$ 抬到 $5 \times 10^4$。

**约束**：

- $1 \le n = s.length \le 5 \times 10^4$
- $1 \le k \le 1000$
- `s` 仅由小写英文字母组成

> 💡 读题抓形态：**同一题面换数据范围 = 逼你换算法**。Q2 的 $O(n^2)$ 增量枚举在 $5 \times 10^4$ 下要做约 $1.25 \times 10^9$ 次判定——C++ 开 O2 勉强、裸奔大概率超时，Python 必挂。线性化的路径有两条并行：**数论**上把平方整除 $k \mid v^2$ 压成线性整除 $m \mid v$；**结构**上把两条「区间整体判定」改写为「前缀量的差分约束」，合并成单一等值键后哈希配对，$O(n)$ 收工。

## 2. 示例

**示例 1**

```text
输入：s = "baeyh", k = 2
输出：2
解释：美丽子串只有 "aeyh" 与 "baey"：
- "aeyh"：元音 {a, e}，辅音 {y, h}，v = 2，v·c = 4，4 % 2 == 0；
- "baey"：元音 {a, e}，辅音 {b, y}，v = 2，v·c = 4，4 % 2 == 0。
"ba" 虽平衡（v = 1），但 v·c = 1 为奇数，被 k = 2 拒绝。
```

**示例 2**

```text
输入：s = "abba", k = 1
输出：3
解释：k = 1 时整除条件恒成立，退化为纯平衡计数：
平衡子串为 "ab"、"ba"、"abba"，共 3 个。
```

**示例 3**

```text
输入：s = "bcdf", k = 1
输出：0
解释：全辅音，任何非空子串元音数 v = 0 ≠ 辅音数，无美丽子串。
```

## 3. 解题思路

### 3.1 暴力思路

直接沿用 Q2 的 $O(n^2)$ 增量枚举：固定左端点 $i$、右移右端点 $j$，增量维护元音数 $v$，每个右端点 $O(1)$ 判定 $2v == L$ 与 $v^2 \bmod k$。子串共 $\binom{n+1}{2} \approx 1.25 \times 10^9$ 个，逐个判定的成本结构没有问题，问题在**数量级**：这是超时的。

症结在于：判定以「区间」为单位逐个进行，而 $n^2$ 个区间的判定信息高度冗余——**平衡与否只取决于两个前缀量之差，乘积整除与否（化简后）也只取决于两个前缀量之差**。线性化的方向是把判定对象从「区间」换成「前缀对」，让所有区间共享前缀上的哈希分组。

### 3.2 核心观察一：数论化简——$k \mid v^2 \iff m \mid v$

由 Q2 已证：平衡时辅音数 $= v$，条件②化为 $k \mid v^2$。这是关于**平方**的整除，无法直接进入前缀差分（前缀差 $V(j) - V(i)$ 只能表达线性整除）。设 $k$ 的质因数分解为 $k = \prod_p p^{e_p}$（$v_p(\cdot)$ 记素数 $p$ 的指数），则

$$
k \mid v^2 \iff \forall p:\ 2\,v_p(v) \ge e_p \iff \forall p:\ v_p(v) \ge \lceil e_p / 2 \rceil \iff m \mid v,\qquad m = \prod_p p^{\lceil e_p / 2 \rceil}
$$

$m$ 称为 $k$ 的**平方根核**——恰是使 $k \mid m^2$ 成立的最小正整数。几个速查值：

| $k$ | 质因数分解 | $m$ | 备注 |
|------|-----------|-----|------|
| $1$ | — | $1$ | 整除条件恒真，键的第二维退化 |
| $4$ | $2^2$ | $2$ | $k$ 为完全平方 ⟹ $m = \sqrt{k}$ |
| $8$ | $2^3$ | $4$ | $\lceil 3/2 \rceil = 2$，**并非** $\sqrt 8 \approx 2.83$ |
| $12$ | $2^2 \cdot 3$ | $6$ | 各素因子分别取 $\lceil e/2 \rceil$ |
| $1000$ | $2^3 5^3$ | $100$ | $m \le k$ 恒成立 |

于是「$v^2 \equiv 0 \pmod k$」这个非线性条件坍缩为**线性整除** $m \mid v$，且 $1 \le m \le k \le 1000$，小到可以放进取模哈希键。

### 3.3 核心观察二：判定改写为前缀双键等值配对

![核心观察：平方整除化简与前缀双键配对](images/wc373_q4_core_simplify.svg)

定义前缀量（$p$ 为前缀长度，$V(p)$、$C(p)$ 分别是前 $p$ 个字符的元音、辅音数）：

$$
D(p) = V(p) - C(p) = 2V(p) - p
$$

对子串 $(i, j]$（长度 $L = j - i$、元音数 $v = V(j) - V(i)$）：

1. **平衡 $\iff D(i) = D(j)$**：$D(j) - D(i) = 2v - L$，为零恰是平衡的定义（$2v = L$）——这是 525「连续数组」的差分套路。
2. **$m \mid v \iff V(i) \equiv V(j) \pmod m$**：差的整除就是余数的相等——这是 974「和可被 K 整除」的前缀模套路。

两条判定合并成**单一等值约束**：

$$
\operatorname{key}(p) = \bigl(D(p),\ V(p) \bmod m\bigr)
$$

> 💡 子串 $(i, j]$ 美丽 $\iff i < j$ 且 $\operatorname{key}(i) = \operatorname{key}(j)$。计数问题就此变成：**同键前缀两两配对**——每组 $c$ 个前缀贡献 $\binom{c}{2}$。配对套路本身是老朋友，新意只在键是**二维**的：一维管平衡、一维管整除，缺一不可。

### 3.4 算法流程

![算法流程：分解 k 求模数，单趟扫描哈希配对](images/wc373_q4_algorithm_flow.svg)

1. **预处理**：试除法分解 $k$（$k \le 1000$，试除到 $\sqrt k$ 即可），求 $m = \prod_p p^{\lceil e_p/2 \rceil}$；
2. **初始化**：$D = V = 0$，哈希表放入空前缀键 $(0, 0)$、计数 $1$；
3. **扫描**：依次读入字符 $c$——元音则 $V{+}{+}$、$D{+}{+}$，辅音则 $D{-}{-}$；
4. **配对**：算出 $\operatorname{key} = (D,\ V \bmod m)$，先 `ans += cnt[key]` 再 `cnt[key]++`（先查后插，天然保证 $i < j$）；
5. **收尾**：返回 `ans`。

### 3.5 示例演算

![示例 1 演算：baeyh 与 k=2 的前缀双键走查](images/wc373_q4_example_walkthrough.svg)

以示例 1（`s = "baeyh"`，$k = 2$）走查。$k = 2 = 2^1$，$m = 2$，双键为 $(D,\ V \bmod 2)$：

| $p$ | 字符 | $V$ | $D = 2V - p$ | $V \bmod 2$ | key |
|-----|------|-----|--------------|-------------|-----|
| 0 | — | 0 | $0$ | 0 | $(0,0)$ |
| 1 | b | 0 | $-1$ | 0 | $(-1,0)$ |
| 2 | a | 1 | $0$ | 1 | $(0,1)$ |
| 3 | e | 2 | $1$ | 0 | $(1,0)$ |
| 4 | y | 2 | $0$ | 0 | $(0,0)$ |
| 5 | h | 2 | $-1$ | 0 | $(-1,0)$ |

同键配对：$(0,0)$ 组 $\{0, 4\}$ → 子串 $(0,4] = $ `baey`（$v = 2$，$v^2 = 4$，$4 \bmod 2 = 0$）✓；$(-1,0)$ 组 $\{1, 5\}$ → `aeyh` ✓；$(0,1)$、$(1,0)$ 各自孤身，贡献 0。答案 $1 + 1 = 2$。

对照示例 2（`s = "abba"`，$k = 1$）：$m = 1$，键退化为单值 $D$；$D$ 序列 $0, 1, 0, -1, 0$，$D = 0$ 组 $\{0, 2, 4\}$ 贡献 $\binom{3}{2} = 3$，正是 `ab`、`ba`、`abba`。

## 4. 算法细节

1. **求 $m$ 的实现**：试除法 $p = 2, 3, \dots$，只要 $p \cdot p \le kk$ 就循环；每遇 $p \mid kk$ 就除干净并记指数 $e$，累乘 $p^{(e+1)/2}$（整数除法 $(e+1)/2$ 即 $\lceil e/2 \rceil$）。循环结束后若剩余 $kk > 1$，它是指数为 $1$ 的大素因子，直接 $m \mathrel{\times}= kk$。
2. **键编码**：$D \in [-n, n]$、$V \bmod m \in [0, m)$。Python 用元组键最省心；C++ 的 `unordered_map` 不认 `pair`，把键压成单个整数 $(D + n) \cdot m + (V \bmod m) \le 2 \times 10^5 \times 10^3 = 2 \times 10^8$，`long long` 富余。
3. **先查后插**：处理到第 $p$ 个前缀时表中只装有下标更小的同键前缀，`ans += cnt[key]` 的增量恰是以 $p$ 为右端点的美丽子串数；全过程与「每组求 $\binom{c}{2}$ 再求和」恒等，但免去二次遍历，也免去显式算组合数。
4. **空前缀入表**：$(D, V) = (0, 0)$ 的 $p = 0$ 必须先行入表，否则所有以 $s[0]$ 开头的子串（如示例 1 的 `baey`）全部漏计。
5. **无前缀数组**：$D$、$V$ 均为单变量增量维护，$O(1)$ 标量附加空间（不计哈希表）。
6. **溢出核查**：答案上界 $\binom{n+1}{2} \approx 1.25 \times 10^9$（实测 `abab…` 满串、$k = 1$ 时为 $6.25 \times 10^8$），已逼近 `int` 上限的一半以上，官方签名即 `long long`；先查后插的写法全程 `long long` 累加，无单点溢出风险。

## 5. 正确性证明

**引理 1（平衡的差分刻画）**：子串 $(i, j]$ 平衡 $\iff D(i) = D(j)$。

**证明**：$D(j) - D(i) = 2(V(j) - V(i)) - (j - i) = 2v - L$；又每字符非元音即辅音，辅音数 $= L - v$，平衡即 $v = L - v \iff 2v = L \iff D(j) - D(i) = 0$。∎

**引理 2（平方整除化简）**：设 $k = \prod_p p^{e_p}$，$m = \prod_p p^{\lceil e_p / 2 \rceil}$，则对任意非负整数 $v$：$k \mid v^2 \iff m \mid v$。

**证明**：$v_p(v^2) = 2 v_p(v)$，故 $k \mid v^2 \iff \forall p: e_p \le 2 v_p(v) \iff \forall p: v_p(v) \ge e_p / 2$。由 $v_p(v)$ 为整数，$v_p(v) \ge e_p / 2 \iff v_p(v) \ge \lceil e_p / 2 \rceil$。后者对一切 $p$ 成立 $\iff \forall p: v_p(m) = \lceil e_p / 2 \rceil \le v_p(v) \iff m \mid v$。∎

**定理（配对等价）**：对 $0 \le i < j \le n$：子串 $(i, j]$ 美丽 $\iff \operatorname{key}(i) = \operatorname{key}(j)$。

**证明**：（⇒）美丽即平衡且乘积被 $k$ 整除。由引理 1 得 $D(i) = D(j)$；平衡时辅音数 $= v$，乘积 $= v^2$，由引理 2 得 $m \mid v = V(j) - V(i)$，即 $V(i) \equiv V(j) \pmod m$。两分量都相等，故键相等。（⇐）键相等给出 $D(i) = D(j)$，由引理 1 子串平衡；又给出 $V(i) \equiv V(j) \pmod m$，即 $m \mid v$，由引理 2 得 $k \mid v^2$，而平衡时乘积恰为 $v^2$。两条件齐备，子串美丽。∎

**定理（计数正确性）**：算法返回值恰为美丽子字符串的个数。

**证明**：**一一对应**：二元组 $(i, j)$（$0 \le i < j \le n$）与非空子串 $(i, j]$ 一一对应。**不重**：每对同键 $(i, j)$ 恰在处理第 $j$ 个前缀时被计入一次（此刻表中只装有 $i < j$ 的同键前缀，`ans` 的增量即表中该键计数）。**不漏**：对任意美丽子串 $(i, j]$，由配对等价定理 $\operatorname{key}(i) = \operatorname{key}(j)$，处理第 $j$ 个前缀时 $\operatorname{cnt}[\operatorname{key}(i)] \ge 1$，该配对必被累计。又对扫描过程归纳：每步按字符的元音性更新 $V$、$D$，与定义 $V(p) = V(p-1) + [s_p \text{ 为元音}]$、$D = 2V - p$ 一致。∎

**推论（组计数视角）**：答案 $= \sum_{\operatorname{key}} \binom{c_{\operatorname{key}}}{2}$，其中 $c_{\operatorname{key}}$ 为同键前缀个数——与先查后插的累计结果恒等（每组 $c$ 个元素，每个元素入组时恰与先前 $c-1$ 个同键元素各计一次）。

## 6. 复杂度分析

- **时间复杂度**：$O(n + \sqrt{k})$。分解 $k$ 试除至多到 $\sqrt{1000} < 32$；主循环单趟扫描，每个字符做一次元音判定、一次取模、一次哈希查询与插入，均摊 $O(1)$——$n = 5 \times 10^4$ 毫秒级通过。对照 Q2 的 $O(n^2) \approx 1.25 \times 10^9$ 次判定，快三个数量级。
- **空间复杂度**：$O(n)$。哈希表至多存 $n + 1$ 个键（实际键数不超过 $(2n+1) \cdot m$ 的组合上界，但也封顶 $n+1$）；$D$、$V$ 与答案均为 $O(1)$ 标量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long beautifulSubstrings(string s, int k) {
        long long m = 1;
        int kk = k;
        for (int p = 2; p * p <= kk; ++p) {
            if (kk % p == 0) {
                int e = 0;
                while (kk % p == 0) { kk /= p; ++e; }
                for (int t = 0; t < (e + 1) / 2; ++t) m *= p;   // p^⌈e/2⌉
            }
        }
        m *= kk;                        // 剩余大素因子，指数为 1

        int n = s.size();
        unordered_map<long long, long long> cnt;
        cnt.reserve(n * 2);
        auto isVowel = [](char c) {
            return c == 'a' || c == 'e' || c == 'i' || c == 'o' || c == 'u';
        };
        int D = 0, V = 0;               // 前缀 p 的 D、V，增量维护
        cnt[(long long)n * m] = 1;      // 空前缀 p = 0：D = 0, V = 0
        long long ans = 0;
        for (char c : s) {
            if (isVowel(c)) { ++V; ++D; }
            else              { --D; }
            long long key = (long long)(D + n) * m + V % m;      // (D, V mod m)
            long long &slot = cnt[key];
            ans += slot;                // 先查：与此前同键前缀配对
            ++slot;                     // 后插：成为未来前缀的配对对象
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def beautifulSubstrings(self, s: str, k: int) -> int:
        m, kk, p = 1, k, 2
        while p * p <= kk:                    # 试除法分解 k
            if kk % p == 0:
                e = 0
                while kk % p == 0:
                    kk //= p
                    e += 1
                m *= p ** ((e + 1) // 2)     # p^⌈e/2⌉
            p += 1
        m *= kk                               # 剩余大素因子，指数为 1

        cnt = {(0, 0): 1}                     # 空前缀键 (D, V mod m)
        D = V = ans = 0
        for c in s:
            if c in 'aeiou':
                V += 1
                D += 1
            else:
                D -= 1
            key = (D, V % m)
            same = cnt.get(key, 0)
            ans += same                       # 先查：配对此前同键前缀
            cnt[key] = same + 1               # 后插
        return ans
```

两版逻辑逐行对应：分解求 $m$ → 空前缀入表 → 单趟扫描 → 先查后插配对。均通过 3000 组随机对拍与满规模 `abab…`（$6.25 \times 10^8$）压力测试。

## 8. 边界情况与易错点

1. **空前缀必须入表**：漏放 $(0,0)$ 则所有以 $s[0]$ 开头的美丽子串（示例 1 的 `baey`）全部漏计——小样例（如 `abba`，$k=1$）恰好测不出，大样例才暴露，是本题最阴的坑。
2. **$m$ 不是 $\sqrt k$ 的四舍五入**：$m = \prod p^{\lceil e/2 \rceil}$，仅当 $k$ 为完全平方数时 $m = \sqrt k$。最易错的是 $k = 8$：$m = 4$，不是 $2$ 也不是 $3$。可靠校验式：$m$ 是使 $k \mid m^2$ 成立的最小正整数。
3. **误用 `v % k == 0` 替代 `v² % k == 0`**：Q2 已踩过的坑（$k=4, v=2$ 反例），化简后的正确线性形式是 $v \bmod m == 0$，别再错一层。
4. **双键缺一不可**：只按 $D$ 配对会把「平衡但乘积不整除」的子串算进来（`baeyh` 的 `ba`，$k=2$）；只按 $V \bmod m$ 配对会混入不平衡子串。二维键必须整体相等。
5. **C++ `pair` 无默认哈希**：`unordered_map<pair<int,int>, …>` 编译不过，须编码成整型键或手写哈希；`map<pair<int,int>, …>` 能用但平添一个 $\log$。
6. **答案规模**：上界 $\binom{n+1}{2} \approx 1.25 \times 10^9$，逼近 `int` 上限，官方签名即 `long long`；若显式计算 $\binom{c}{2}$，$c \le 50001$ 时 $c(c-1)$ 已近 $2.5 \times 10^9$，必须先转 `long long`——先查后插写法则天然规避此步。
7. **试除法的收尾**：循环结束后 $kk > 1$ 是指数为 $1$ 的剩余素因子，勿忘 $m \mathrel{\times}= kk$（如 $k = 998 = 2 \times 499$，漏乘则 $m = 2$，素因子 $499$ 丢失，判定全线失真）。
8. **`y` 是辅音、$k = 1$ 退化**：与 Q2 相同的老坑；$k = 1$ 时 $m = 1$，$V \bmod 1 = 0$，键自动退化为单值 $D$（即 525 题形态），无需特判。
