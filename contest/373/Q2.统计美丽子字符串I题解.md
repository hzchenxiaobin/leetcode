# LeetCode 统计美丽子字符串 I 题解

## 1. 题目概述

- **标题 / 题号**：统计美丽子字符串 I（#2947，medium）
- **链接**：https://leetcode.cn/problems/count-beautiful-substrings-i/
- **来源**：LeetCode 第 373 场周赛 Q2
- **难度**：中等
- **标签**：字符串、枚举、前缀和、数学

**题意**：给定字符串 `s` 与正整数 $k$。一个子串若同时满足：① 元音数与辅音数**相等**（平衡）；② 两者数量的**乘积**能被 $k$ 整除，则称为**美丽子字符串**。返回 `s` 中非空美丽子字符串的个数。

**约束**：

- $1 \le n = s.length \le 1000$
- $1 \le k \le 1000$
- `s` 仅由小写英文字母组成

> 💡 读题抓形态：**双条件子串计数**。两条判定看似都要"数完整段"，实则可代数化简——平衡把辅音数钉死为 $L - v$，乘积条件随之收敛为 $v^2 \bmod k$，全部判定只依赖 $(v, L)$ 这对标量。$n \le 1000$ 明示 $O(n^2)$ 增量枚举够用；同一题面的 $n \le 5 \times 10^4$ 版正是本场 Q4（#2949），届时需换成前缀哈希 + 数论。

## 2. 示例

**示例 1**

```text
输入：s = "baeyh", k = 2
输出：2
解释：平衡且 v² % 2 == 0 的子串只有 "aeyh" 与 "baey"：
- "aeyh"：元音 {a, e}，辅音 {y, h}，v = 2，v² = 4，4 % 2 == 0；
- "baey"：元音 {a, e}，辅音 {b, y}，v = 2，v² = 4，4 % 2 == 0。
"ba" 虽平衡（v = 1），但 v² = 1 为奇数，被 k = 2 拒绝。
```

**示例 2**

```text
输入：s = "abba", k = 1
输出：3
解释：k = 1 时整除条件恒成立，退化为纯平衡计数：
平衡子串为 "ab"、"ba"、"abba"，共 3 个。
```

**示例 3**

```text
输入：s = "bcdf", k = 1
输出：0
解释：全辅音，任何非空子串元音数 v = 0 ≠ 辅音数，无美丽子串。
```

## 3. 解题思路

### 3.1 暴力思路

枚举全部 $O(n^2)$ 个子串区间 $(i, j)$，每个子串从头扫一遍统计元音、辅音，再照抄题面做两条判定。单次统计 $O(n)$，总计 $O(n^3) \approx 10^9$（$n = 1000$），远超周赛 1s 预算。症结在于：**判定信息（元音数）没有随枚举增量携带**，每个新子串都"从零再数一遍"；且判定直接以 `vowels`、`consonants` 两个量书写，既绕又藏着一个不易察觉的坑（见 §8 易错点 1）。

### 3.2 核心观察：判定收敛为标量对 $(v, L)$

![核心观察：两条判定收敛为标量对 (v, L)](images/wc373_q2_core_simplify.svg)

记子串长度为 $L$、元音数为 $v$，则辅音数恒为 $L - v$（每字符非元音即辅音）。

1. **观察 1（平衡 = 长度刻画）**：$vowels == consonants$ 即 $v == L - v$，等价于 $2v == L$。推论：**奇数长度的子串直接出局**，为枚举提供廉价剪枝。
2. **观察 2（乘积收敛）**：平衡前提下 $consonants = v$，于是乘积 $vowels \times consonants = v \cdot v = v^2$——整除条件与辅音数彻底脱钩，只依赖元音数：$v^2 \equiv 0 \pmod k$。
3. **观察 3（判定标量化）**：两条判定都只吃 $(v, L)$ 两个标量。固定左端点 $i$、右端点 $j$ 逐步右移时，$L = j - i + 1$ 每次 $+1$，$v$ 每次至多 $+1$（新字符是元音则 $+1$）——**每个右端点的判定成本 $O(1)$**。

于是 $O(n^3)$ 的"每个子串重数一遍"坍缩为 $O(n^2)$ 的"右端点右移一步、增量维护 $v$"。

### 3.3 算法流程

![算法流程：固定左端点增量扫描右端点](images/wc373_q2_algorithm_flow.svg)

1. **外层**：枚举左端点 $i = 0, \dots, n-1$，进入时把元音计数 $v$ 清零；
2. **内层**：右端点 $j$ 从 $i$ 走到 $n-1$，每步先 $v \mathrel{+}= is\_vowel(s[j])$，并记 $L = j - i + 1$；
3. **判定**：若 $2v == L$ 且 $v^2 \bmod k == 0$，答案 $+1$；
4. **收尾**：内层自然结束换下一个 $i$，全部结束返回答案。

### 3.4 示例演算

![示例 1 演算：baeyh 与 k=2 的完整走查](images/wc373_q2_example_walkthrough.svg)

以示例 1（`s = "baeyh"`，$k = 2$）走查。先用 $2v == L$ 筛平衡子串（奇数长度、元音辅音不配的全部出局），只剩 3 个候选：

| 子串 | 区间 | $v$ | $L$ | $2v == L$ | $v^2 \bmod 2$ | 美丽 |
|------|------|-----|-----|-----------|---------------|------|
| `ba` | $[0,1]$ | 1 | 2 | ✓ | $1 \ne 0$ ✗ | ✗ |
| `baey` | $[0,3]$ | 2 | 4 | ✓ | $0$ ✓ | ✓ |
| `aeyh` | $[1,4]$ | 2 | 4 | ✓ | $0$ ✓ | ✓ |

答案为 2。对照示例 2（`s = "abba"`，$k = 1$）：平衡子串 `ab`、`ba`、`abba`，而 $v^2 \bmod 1 \equiv 0$ 恒成立，3 个全部美丽——**$k = 1$ 时第二条件自动退化**。

## 4. 算法细节

1. **元音判定**：C++ 用五连等 `c=='a'||c=='e'||c=='i'||c=='o'||c=='u'`，Python 直接 `c in 'aeiou'`。切记 `y` 是**辅音**（示例 1 的 `"aeyh"` 中 `y` 计入辅音）。
2. **判定顺序**：先 $2v == L$ 再 $v^2 \bmod k$。前者一次比较即可淘汰大部分子串（所有奇数长度与不平衡的），后者含乘法取模，靠后放让短路收益最大。
3. **两种等价实现**：增量版（上文，空间 $O(1)$）与前缀和版——`pre[p]` 为前 $p$ 个字符的元音数，子串 $s[i..j]$ 的 $v = pre[j+1] - pre[i]$，双循环直接查表。前缀和版为 Q4（#2949）的**前缀量配对**视角埋下伏笔：平衡即前缀差相等，那是线性化的入口。
4. **溢出核查**：$v \le L/2 \le 500$，$v^2 \le 2.5 \times 10^5$，`int` 毫无压力；Python 无此虑。
5. **不做额外剪枝**：用 `L & 1` 跳过奇数长度与直接判 $2v == L$ 成本同为 $O(1)$，另加分支纯属画蛇添足。

## 5. 正确性证明

**引理 1（平衡刻画）**：子串（长度 $L$、元音数 $v$）平衡 $\iff 2v = L$。

**证明**：每字符非元音即辅音，故辅音数 $= L - v$。平衡即 $v = L - v$，移项得 $2v = L$。∎

**引理 2（乘积收敛）**：子串平衡时 $vowels \times consonants = v^2$；从而"平衡且乘积被 $k$ 整除" $\iff$ "平衡且 $v^2 \equiv 0 \pmod k$"。

**证明**：平衡时由引理 1 有 $consonants = L - v = v$，乘积 $= v \cdot v = v^2$；在"平衡"这一前提下，"$v^2 \equiv 0 \pmod k$"与"乘积 $\equiv 0 \pmod k$"是同一陈述。∎

**定理（判定等价）**：非空子串是美丽子字符串 $\iff$ $2v = L$ 且 $v^2 \equiv 0 \pmod k$。

**证明**：美丽定义为"平衡 ∧ 乘积整除"。由引理 1 等价替换前一合取项，再由引理 2 在平衡前提下等价替换后一合取项，逻辑等值变换保持充要性。∎

**定理（计数正确性）**：算法返回值恰为美丽子字符串的个数。

**证明**：**不重不漏**：二元组 $(i, j)$（$i \le j$）与非空子串 $s[i..j]$ 一一对应，双重循环遍历每对恰一次。**判定正确**：对固定 $i$ 归纳证明循环不变量"进入 $j$ 的判定前 $v = |\{p \in [i, j] : s[p] \text{ 为元音}\}|$"：$j = i$ 时刚执行 $v \mathrel{+}= is\_vowel(s[i])$ 且初值为 $0$，成立；设 $j$ 时成立，则 $j+1$ 时 $v$ 恰多计入 $s[j+1]$ 的元音性，仍成立。又 $L = j - i + 1$ 即子串长度，由判定等价定理，每个子串按美丽与否恰好增计一次。∎

**推论（结构）**：美丽子字符串长度必为偶数；其元音数 $v$ 满足 $v^2 \equiv 0 \pmod k$，等价于 $m \mid v$（$m = \prod_p p^{\lceil e_p / 2 \rceil}$，$k = \prod_p p^{e_p}$ 为质因数分解）——这一数论结构正是 Q4（#2949）线性化的钥匙。

## 6. 复杂度分析

- **时间复杂度**：$O(n^2)$。子串（左右端点对）共 $n(n+1)/2 = 500500$ 个，每个做一次加法与两次 $O(1)$ 判定；对照暴力重算的 $O(n^3) \approx 10^9$ 快三个数量级，$n \le 1000$ 下毫秒级通过。
- **空间复杂度**：增量版 $O(1)$（仅计数器 $v$、答案与下标）；前缀和版 $O(n)$。

## 7. 参考代码

### C++（增量枚举）

```cpp
class Solution {
public:
    int beautifulSubstrings(string s, int k) {
        int n = s.size(), ans = 0;
        auto isVowel = [](char c) {
            return c == 'a' || c == 'e' || c == 'i' || c == 'o' || c == 'u';
        };
        for (int i = 0; i < n; i++) {
            int v = 0;                        // 子串 s[i..j] 的元音数
            for (int j = i; j < n; j++) {
                v += isVowel(s[j]);
                if (2 * v == j - i + 1 && v * v % k == 0) {
                    ans++;
                }
            }
        }
        return ans;
    }
};
```

### Python（前缀和视角）

```python
class Solution:
    def beautifulSubstrings(self, s: str, k: int) -> int:
        n = len(s)
        pre = [0] * (n + 1)                   # pre[p] = s[:p] 中元音个数
        for p, c in enumerate(s):
            pre[p + 1] = pre[p] + (c in 'aeiou')
        ans = 0
        for i in range(n):
            for j in range(i + 1, n + 1):     # 子串 s[i:j]
                v = pre[j] - pre[i]           # 元音数，辅音数 = (j-i) - v
                if 2 * v == j - i and v * v % k == 0:
                    ans += 1
        return ans
```

两版判定逻辑逐字相同：$2v$ 等于长度、且 $v^2$ 被 $k$ 整除。

## 8. 边界情况与易错点

1. **把整除条件误写成 `v % k == 0`**：与 `v * v % k == 0` **不等价**！反例 $k = 4, v = 2$：$v^2 = 4$ 被 4 整除，但 $v = 2$ 不被 4 整除。乘积条件必须以平方面目出现（或经数论化简后以 $m \mid v$ 面目出现，见推论）。
2. **$O(n^3)$ 陷阱**：每个子串重扫一遍数元音，$10^9$ 级操作超时；增量维护或前缀和把统计降到每子串 $O(1)$。
3. **`y` 是辅音**：元音只有 `aeiou` 五个，别把 `y` 当元音。
4. **$k = 1$ 退化**：$v^2 \bmod 1 \equiv 0$ 恒真，第二条件消失，退化为纯平衡计数（示例 2）。
5. **非空子串**：增量版 $j$ 从 $i$ 起步；前缀和版 $j > i$ 严格大于，勿把空串计入。
6. **官方示例 2 译文展示有误**：三个子串实为 `"ab"`、`"ba"`、`"abba"`（译文中前两条展示成了 `"abba"`），按判定逐个核对勿被带偏。
7. **全辅音 / 全元音串**：任何子串都无法平衡（$v = 0$ 或 $v = L$ 且 $L > 0$），答案为 0，无需特判，判据自然覆盖。
