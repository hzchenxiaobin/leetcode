# LeetCode 交换得到字典序最小的数组 题解

## 1. 题目概述

- **标题 / 题号**：交换得到字典序最小的数组（#2948，medium）
- **链接**：https://leetcode.cn/problems/make-lexicographically-smallest-array-by-swapping-elements/
- **来源**：LeetCode 第 373 场周赛 Q3
- **难度**：中等
- **标签**：排序、贪心、并查集思想

**题意**：给定正整数数组 `nums` 与正整数 `limit`。一次操作可选任意两个下标 $i, j$，只要 $|nums[i] - nums[j]| \le limit$ 就可交换这两个数。可执行**任意多次**操作，返回能得到的**字典序最小**的数组。

**约束**：

- $1 \le n = nums.length \le 10^5$
- $1 \le nums[i] \le 10^9$
- $1 \le limit \le 10^9$

> 💡 读题抓形态：交换条件挂在**值**上（值差不超过 `limit`），优化目标挂在**下标序**上（字典序最小）。条件与目标错位，正是「排序重构连通性」的信号：把值排序后，「可交换」关系在数轴上形成一条条**链**——链内可任意重排、链间彻底隔离。另外 $n \le 10^5$ 提前宣告：对所有数对建并查集的 $O(n^2)$ 做法必然超时，必须从排序结构里找连通性。

## 2. 示例

**示例 1**

```text
输入：nums = [1,5,3,9,8], limit = 2
输出：[1,3,5,8,9]
解释：|5−3| = 2 ≤ 2，交换得 [1,3,5,9,8]；再 |9−8| = 1 ≤ 2，交换得 [1,3,5,8,9]。
而 1 与 9 差 8 > 2，无法直接换，也不存在把它们连起来的中转链。
```

**示例 2**

```text
输入：nums = [1,7,6,18,2,1], limit = 3
输出：[1,6,7,18,1,2]
解释：{1,1,2}、{6,7}、{18} 各成一组。
组内排序回填：下标 4、5 原来的 {2,1} 排成 [1,2]；下标 3 的 18 独居一组，原地不动。
```

**示例 3**

```text
输入：nums = [1,7,28,19,10], limit = 3
输出：[1,7,28,19,10]
解释：排序后相邻差为 6、3、9、9，全部大于 3——五个数各自成组，一个合法操作也做不了。
```

## 3. 解题思路

### 3.1 暴力思路

「能换就换」的朴素贪心：反复扫描数组，对每个下标寻找能换来的更小值。问题是交换相互纠缠，局部贪心未必收敛到全局字典序最小，且每轮扫描 $O(n)$、轮数不可控。

更结构化的暴力是把「可交换」建成图：对所有数对判 $|nums[i] - nums[j]| \le limit$，满足则并查集 `union(i, j)`，最后每个**连通块**内排序回填。这个做法方向正确（块内可任意重排、块间隔离，见 §5），但判边要 $O(n^2)$ 对——$n = 10^5$ 时约 $5 \times 10^9$ 次，直接超时。症结在于：**可交换性其实藏在值的排序结构里，却被当成了无结构的完全图**。

### 3.2 核心观察：排序后「相邻差 ≤ limit」的链就是连通块

![核心观察：排序后按相邻差分组](images/wc373_q3_sort_group_concept.svg)

把 $(值, 原下标)$ 按值升序排列，再按**相邻差**切分：相邻两值差 $\le limit$ 归入同组，差 $> limit$ 处断开。两个关键结论：

1. **组间隔绝**：不同组的任意两值之差必 $> limit$（两组之间被一个 $> limit$ 的裂缝隔开，裂缝两侧的值只会离得更远）。因此**任何时刻都不会发生跨组交换**——每组的值多重集、占据的下标集合永远不变。
2. **组内全排列可达**：组内按值排序后**相邻**的两值 $w_i, w_{i+1}$ 差 $\le limit$，无论它们当前落在组内哪两个位置，都**可以直接交换**；而「相邻对换」能生成 $k$ 个元素的一切排列（冒泡排序原理），所以组内的值可以重排成**任意**目标摆法。

于是原问题被分解为彼此独立的**组内子问题**：每组内部，把升序的值配给升序的原下标（第 $t$ 小的值放到第 $t$ 小的下标），即该组能达到的字典序最小摆法；组间互不干扰，拼起来就是全局答案。示例 1 中 $1$ 与 $5$ 差 $4 > 2$ 虽不能直接换，但可经 $3$ 中转（$1 \leftrightarrow 3 \leftrightarrow 5$），照样重排。

### 3.3 算法流程

![算法流程：附下标排序、扫描分组、组内配对回填](images/wc373_q3_algorithm_flow.svg)

1. **附下标排序**：构造 $a[i] = (nums[i],\ i)$，按值升序，$O(n \log n)$；
2. **扫描分组**：一遍线性扫描，遇到 $a[k+1].值 - a[k].值 > limit$ 就断开新组，$O(n)$；
3. **组内配对回填**：对每组取出原下标并升序排列为 $idx$（组内值本已升序），令 $ans[idx[t]] = $ 组内第 $t$ 小的值；
4. **返回** $ans$。

### 3.4 示例演算

![示例 1 演算：排序分组与组内配对](images/wc373_q3_example_walkthrough.svg)

以示例 1（`nums = [1,5,3,9,8]`，`limit = 2`）走查。排序后（值，原下标）序列与相邻差：

| 排序后 | (1,0) | (3,2) | (5,1) | (8,4) | (9,3) |
|--------|-------|-------|-------|-------|-------|
| 相邻差 | — | $2 \le 2$ ✓ | $2 \le 2$ ✓ | $3 > 2$ ✂ | $1 \le 2$ ✓ |

在差 $3 > 2$ 处剪断，得组 A = 值 $\{1,3,5\}$（原下标 $\{0,2,1\}$）、组 B = 值 $\{8,9\}$（原下标 $\{4,3\}$）。

- **组 A**：原下标排序 $[0,1,2]$，值升序 $[1,3,5]$，配对 $1 \to 0,\ 3 \to 1,\ 5 \to 2$；
- **组 B**：原下标排序 $[3,4]$，值升序 $[8,9]$，配对 $8 \to 3,\ 9 \to 4$。

拼回原下标得 `ans = [1,3,5,8,9]`，与预期一致。再对照示例 2（`limit = 3`）：排序后 $1,1,2 \,|\, 6,7 \,|\, 18$ 共三组。组 $\{1,1,2\}$ 原下标 $\{0,5,4\}$ → 排序 $[0,4,5]$ 配 $[1,1,2]$；组 $\{6,7\}$ 原下标 $\{2,1\}$ → 排序 $[1,2]$ 配 $[6,7]$；$18$ 独居下标 $3$。结果 `[1,6,7,18,1,2]` ✓。

## 4. 算法细节

1. **排序必须携带原下标**：只排值会丢失「值从哪来」的回填信息；用 `pair` / 元组一并排序即可。
2. **分组判据的方向**：断开条件是**严格大于** $a[k+1].值 - a[k].值 > limit$；差恰好**等于** `limit` 时必须留在同组（示例 1 的 $3-1=2$ 正是 `limit` 本尊）。
3. **组内配对的实现**：取出组内所有原下标排序得 `idx`，组内值天然升序，直接双序列按下标配对：`ans[idx[t]] = a[组起点 + t].值`。
4. **并查集视角的等价性**：本做法与「并查集 + 块内排序」完全等价——排序后只需对 **相邻对** 做 $n-1$ 次合并，而非 $O(n^2)$ 次两两判边。连通性沿排序链传递，这正是把 $O(n^2)$ 降到 $O(n \log n)$ 的全部秘密。
5. **溢出核查**：值域 $[1, 10^9]$，排序后做差非负且 $\le 10^9 - 1 < 2^{31} - 1$，`int` 险过；C++ 求稳可对差值用 `long long`（Python 无此虑）。
6. **重复元素**：相等值差为 $0 \le limit$，必落同组；同值配到哪个下标结果一样，无需特判，但下标仍须参与排序。

## 5. 正确性证明

**引理 1（组间隔绝）**：按上述规则分组后，不同组的任意两值 $x, y$ 满足 $|x - y| > limit$。

**证明**：不妨设 $x$ 在靠前的组、$y$ 在靠后的组。分组由排序序列上某个 $> limit$ 的相邻裂缝切开：设前组最大值 $u$、后组最小值 $v$，则 $v - u > limit$。而 $x \le u,\ y \ge v$，故 $y - x \ge v - u > limit$。∎

**推论 1（组不变量）**：任何操作序列都不改变每组的值多重集，且每组始终恰好占据其**原下标集合**。

**证明**：一次操作只交换差 $\le limit$ 的两值；由引理 1，这两值必属同组，故每次操作都是组内交换，组间永不发生交换。对操作次数归纳即得。∎

**引理 2（组内全排列可达）**：设组内值为 $w_1 \le w_2 \le \dots \le w_k$，原下标集合为 $P$，则这 $k$ 个值在 $P$ 上的**任意**摆放均可经有限次合法交换到达（重复值不影响结论）。

**证明**：由推论 1，任何时刻组内的值恰好是 $w_1, \dots, w_k$ 且都落在 $P$ 上。对任意 $1 \le i < k$：无论 $w_i, w_{i+1}$ 当前位于 $P$ 中哪两个位置，二者之差 $\le limit$（组内排序相邻，正是分组规则保证的），故这两个位置**总可以直接交换**。即「值序列上相邻元素的对换」始终可用，而相邻对换生成 $k$ 元素的全部排列（冒泡排序原理：任意目标排列可分解为一系列相邻对换），故任意目标摆放可达。∎

**定理（算法输出可达且字典序最小）**：算法输出 $ans$（每组内第 $t$ 小值配第 $t$ 小原下标）是所有可达配置中字典序最小者。

**证明**：**可达性**：由引理 2，每组的「升序值 → 升序下标」摆放均可独立实现；组间互不干扰，逐组实现后组合即得 $ans$。**最优性**：设 $B$ 为任意可达配置且 $B \ne ans$，取二者第一个不同的下标 $p$，记 $p$ 所在组为 $G$、组内秩为 $r$（即 $p$ 是 $G$ 中第 $r$ 小的下标）。在 $p$ 之前 $ans$ 与 $B$ 完全一致，故两组在 $G \cap [0, p)$ 的诸位置上取值相同，设该值集为 $S$；由算法的配对规则，$S$ 恰为 $G$ 中前 $r-1$ 小的值，于是 $ans[p]$ 是剩余值集 $G \setminus S$ 的最小值。又由推论 1，$B[p]$ 只能取 $G \setminus S$ 中的值且 $B[p] \ne ans[p]$，故 $B[p] > ans[p]$。即任何其他可达配置在第一个差异处都严格更大，$ans$ 字典序最小。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \log n)$。附下标排序 $O(n \log n)$；分组扫描 $O(n)$；各组下标排序的总元素数为 $n$，合计不超过整体排序的 $O(n \log n)$；配对回填 $O(n)$。对照 $O(n^2)$ 建图做法快两个数量级，$n = 10^5$ 下毫秒级通过。
- **空间复杂度**：$O(n)$。存储 $(值, 下标)$ 对、组内下标临时数组与答案数组（C++ 原地写回 `nums` 可省一份）。

## 7. 参考代码

### C++（排序 + 分段配对）

```cpp
class Solution {
public:
    vector<int> lexicographicallySmallestArray(vector<int>& nums, int limit) {
        int n = nums.size();
        vector<pair<int, int>> a(n);              // (值, 原下标)
        for (int i = 0; i < n; i++) a[i] = {nums[i], i};
        sort(a.begin(), a.end());

        vector<int> ans(n);
        for (int i = 0; i < n; ) {
            int j = i;                            // [i, j] 为一个组
            while (j + 1 < n && (long long)a[j + 1].first - a[j].first <= limit) j++;

            vector<int> idx;                      // 组内原下标
            for (int k = i; k <= j; k++) idx.push_back(a[k].second);
            sort(idx.begin(), idx.end());

            for (int t = 0; t < (int)idx.size(); t++)
                ans[idx[t]] = a[i + t].first;     // 第 t 小值 → 第 t 小下标
            i = j + 1;
        }
        return ans;
    }
};
```

### Python（同思路）

```python
class Solution:
    def lexicographicallySmallestArray(self, nums: List[int], limit: int) -> List[int]:
        a = sorted((v, i) for i, v in enumerate(nums))   # (值, 原下标) 按值升序
        n = len(a)
        ans = [0] * n
        i = 0
        while i < n:
            j = i                                       # [i, j] 为一个组
            while j + 1 < n and a[j + 1][0] - a[j][0] <= limit:
                j += 1
            idx = sorted(p[1] for p in a[i:j + 1])      # 组内原下标升序
            for t, p in enumerate(idx):
                ans[p] = a[i + t][0]                    # 第 t 小值 → 第 t 小下标
            i = j + 1
        return ans
```

两版逻辑逐字对应：排序分组后，组内「第 $t$ 小值 ↔ 第 $t$ 小下标」。

## 8. 边界情况与易错点

1. **分组条件写反**：断开判据是**严格 `> limit`**。误写成 `>= limit` 会把差恰好等于 `limit` 的对错误切组——示例 1 的 $(1,3)$ 差正好是 2，切错会输出 `[1,3,5,9,8]`。
2. **忘带原下标**：只对值排序，回填时不知道每个值该去哪；务必排 $(值, 下标)$ 二元组。
3. **组内配对方向搞反**：必须「小值配小下标」；若把值降序配下标升序，得到的是组内字典序**最大**的摆法。
4. **$O(n^2)$ 并查集超时**：对 $10^5$ 个数两两判边约 $5 \times 10^9$ 次；排序后只看 $n - 1$ 个相邻差即可覆盖全部连通信息。
5. **直接模拟「每轮给最左位置换更小值」**：忽略了交换的**传递性**——两值差 $> limit$ 不能直接换，却可能经链上中转间接换位（如示例 1 的 $1$ 与 $5$），必须用组结构一次性看穿。
6. **溢出**：值差上界 $10^9 - 1$，`int` 恰好装得下；排序后大减小保证非负，求稳可用 `long long`。
7. **$n = 1$**：单元素自成一组，原样返回。
8. **整体一组**：所有相邻差 $\le limit$（如 `limit` 极大）时，输出就是完全排序数组——可当作快速自测用例。
