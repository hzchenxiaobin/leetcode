# LeetCode 完美矩形 题解

## 1. 题目概述

- **标题 / 题号**：完美矩形（#391，hard）
- **链接**：https://leetcode.cn/problems/perfect-rectangle/
- **来源**：LeetCode 第 2 场周赛 Q3
- **难度**：困难
- **标签**：几何、数组、哈希表、数学、扫描线

**题意**：给定 $n$ 个与坐标轴平行的矩形，第 $i$ 个用 `[xi, yi, ai, bi]` 表示，`(xi, yi)` 是左下角、`(ai, bi)` 是右上角。判断这 $n$ 个矩形是否能**恰好**拼成一个大矩形——既不能有**重叠**（某个点被覆盖 $\ge 2$ 次），也不能有**空洞**（某个点被覆盖 $0$ 次），且拼出来的整体轮廓必须是一个矩形。

**约束**：

- $1 \le n \le 2 \times 10^4$
- `rectangles[i].length == 4`
- $-10^5 \le x_i < a_i \le 10^5$，$-10^5 \le y_i < b_i \le 10^5$
- 由此单个矩形面积可达 $4 \times 10^{10}$，$n$ 个之和可达 $8 \times 10^{14}$，**必须用 64 位整数**

## 2. 示例

**示例 1**

```text
输入：rectangles = [[1,1,3,3],[3,1,4,2],[3,2,4,4],[1,3,2,4],[2,3,3,4]]
输出：true
解释：5 个矩形面积 4+1+2+1+1 = 9，外接矩形 (1,1)-(4,4) 面积 3×3 = 9，恰好铺满。
      角点两两抵消后只剩 (1,1)、(4,1)、(1,4)、(4,4) 四个外接角。
```

**示例 2**

```text
输入：rectangles = [[1,1,2,3],[1,3,2,4],[3,1,4,2],[3,2,4,4]]
输出：false
解释：面积 2+1+1+2 = 6 < 9，中间那条 x∈[2,3]、y∈[1,4] 的竖条是空洞。
```

**示例 3**

```text
输入：rectangles = [[1,1,3,3],[3,1,4,2],[1,3,2,4],[2,2,4,4]]
输出：false
解释：面积 4+1+1+4 = 10 > 9，[2,3]×[2,3] 这一块被两个矩形同时覆盖，
      虽然整体轮廓仍是 3×3，但不是"精确"覆盖。
```

**示例 4（补充，非官方，用来区分两个判据）**

```text
输入：rectangles = [[0,0,2,2],[1,0,3,1]]
输出：false
解释：面积 4+2 = 6 = 外接矩形 3×2，面积判据通过；
      但 [1,2]×[0,1] 重叠 1 与 [2,3]×[1,2] 空洞 1 恰好互相抵消，
      角点异或后留下 8 个点而不是 4 个，被角点判据拦下。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的做法是**把平面离散化**：取出所有出现过的 $x$、$y$ 坐标做压缩，得到最多 $(4n) \times (4n)$ 个格子，逐格统计覆盖次数，最后检查"外接矩形内每格恰好 1 次、外接矩形外 0 次"。坐标压缩后格子数 $O(n^2)$，$n = 2\times10^4$ 时约 $6.4\times10^9$ 格；不做压缩而按单位长度枚举，坐标跨度 $2\times 10^5$，格子数 $4\times10^{10}$——**两条路都爆炸**。

可行的"正统一维化"方案是**扫描线 + 线段树**：沿 $x$ 扫描，线段树维护每个 $y$ 区间被覆盖的次数，要求全程"最小值 = 最大值 = 1"，复杂度 $O(n\log n)$。它是对的，但代码长、常数大。本题存在一个**只需要哈希表、期望 $O(n)$** 的漂亮判据。

### 3.2 核心观察：面积守恒 + 角点奇偶异或

![面积守恒与角点奇偶两个判据](images/wc2_q3_area_and_corner_parity.svg)

精确覆盖必须同时满足两条**必要条件**：

**判据 1（面积守恒）**：所有小矩形面积之和等于外接矩形面积。

$$\sum_{i=1}^{n}(a_i - x_i)(b_i - y_i) = (X_{\max}-X_{\min})(Y_{\max}-Y_{\min})$$

**判据 2（角点奇偶）**：把每个矩形的 4 个角点放进一个集合做**异或**（同一个点出现两次就删掉、出现一次就留下），最终剩下的点必须**恰好是外接矩形的 4 个角**。

为什么是这两条？面积只管"总量"：相等只说明**总重叠面积 = 总空洞面积**，两者可以互相抵消（示例 4 就是重叠 1 抵掉空洞 1）；角点只管"骨架"：内部网格点上的角点会成对抵消，只有**边界转折处**才可能残留，覆盖精确时恰为外接四角。

关键在于——**这两条合起来就是充分的**：面积相等保证"没有净亏损"，角点奇偶保证"没有重叠"，于是只能是精确覆盖。严格证明见第 5 节。

> ⚠️ 两条判据缺一不可。只查面积会被示例 4 骗过；只查角点会被"3 个完全相同的矩形叠加"骗过（角点异或恰好剩 4 个外接角，但面积 $3 \ne 1$）。

### 3.3 算法流程

![一遍扫描加两次判定的流程图](images/wc2_q3_algorithm_flow.svg)

1. **一次遍历**同时完成三件事：
   - 求外接矩形 $(x_{\min}, y_{\min}) - (x_{\max}, y_{\max})$；
   - 累加面积 `area += (a - x) * (b - y)`；
   - 把 $(x,y),(x,b),(a,y),(a,b)$ 四个角点依次"异或"进哈希集合（在集合里就删、不在就插；集合语义 = 该点出现次数的奇偶）。
2. 判定 `area == (xmax - xmin) * (ymax - ymin)`，不等直接 `false`。
3. 判定集合大小恰为 4，且正好是外接四角，否则 `false`；全部通过返回 `true`。

### 3.4 示例演算

![示例 1 的角点奇偶走查表](images/wc2_q3_example1_walkthrough.svg)

对示例 1 的 5 个矩形，逐个角点统计"贡献者"，再按奇偶筛出残留点：

| 角点 | 贡献矩形 | 奇偶 | 角点 | 贡献矩形 | 奇偶 |
|------|----------|------|------|----------|------|
| (1,1) | A | 奇 ✓ | (4,2) | B, C | 偶 |
| (1,3) | A, D | 偶 | (3,4) | C, E | 偶 |
| (3,1) | A, B | 偶 | (1,4) | D | 奇 ✓ |
| (3,3) | A, E | 偶 | (2,3) | D, E | 偶 |
| (3,2) | B, C | 偶 | (2,4) | D, E | 偶 |
| (4,1) | B | 奇 ✓ | (4,4) | C | 奇 ✓ |

面积 $4+1+2+1+1 = 9 = 3\times3$ 通过，残留奇点 $\{(1,1),(4,1),(1,4),(4,4)\}$ 正是外接四角，返回 `true`。

对照示例 3：面积 $10 \ne 9$，第一步就被拦下；再对照示例 4：面积 $6 = 6$ 通过，但残留 8 个奇点，第二步被拦下。

## 4. 算法细节

1. **外接矩形必须一次遍历求出**：$x_{\min}$ 取所有左边界最小、$x_{\max}$ 取所有右边界最大，$y$ 同理。四个角点顺序不能混：$(x_{\min},y_{\min})$ 与 $(x_{\max},y_{\max})$ 是对角。
2. **面积用 64 位**：单个矩形最多 $(2\times10^5)^2 = 4\times10^{10}$，$2\times10^4$ 个最多 $8\times10^{14}$，`int` 必然溢出，C++ 要 `long long`。
3. **角点键编码**：坐标范围 $[-10^5, 10^5]$，平移到 $[0, 2\times10^5]$ 后令 $\text{key} = (x + 10^5) \times 200001 + (y + 10^5)$，压成一个 64 位整数，比 `set<pair<int,int>>` 少一层比较；Python 直接用 `(x, y)` 元组即可。
4. **异或用"查—删/插"实现**：`find` 命中就 `erase(it)`（一次哈希），否则 `insert`；不要写成 `count` + `erase(key)`，那是两次哈希。
5. **终局判定要判"内容"而不只是"数量"**：`size() == 4` 之外还必须确认这四点就是外接四角。虽然配合面积判据时错误的 4 点很少见，但直接比较四角更稳、也更好解释。
6. **预留桶、免特判**：`corners.reserve(4*n)` 避免反复 rehash；$n=1$ 时角点集天然是四角、面积天然相等，无需特判。

## 5. 正确性证明

**引理 1（面积必要性）**：若 $n$ 个矩形精确覆盖外接矩形 $R$，则 $\sum_i (a_i-x_i)(b_i-y_i) = \operatorname{area}(R)$。

**证明**：精确覆盖意味着 $R$ 被划分成 $n$ 个内部互不相交的小矩形，面积可加，故总和等于 $\operatorname{area}(R)$。∎

**引理 2（角点—覆盖奇偶恒等式）**：设 $p$ 是任一网格顶点，取 $p$ 周围足够小的四个象限 $Q_1,\dots,Q_4$（不跨越任何矩形边），记 $m_j$ 为覆盖 $Q_j$ 的矩形数，$c(p)$ 为以 $p$ 为角点的矩形数，则

$$c(p) \equiv \sum_{j=1}^{4} m_j \pmod 2 .$$

**证明**：看单个矩形对 $\sum_j m_j$ 的贡献：$p$ 是它的角点时恰好覆盖 1 个象限；$p$ 落在它某条边的内部时覆盖 2 个；$p$ 在它内部时覆盖 4 个；其余 0 个。于是

$$\sum_{j=1}^{4} m_j = c(p) + 2e(p) + 4i(p),$$

其中 $e(p)$、$i(p)$ 分别是"$p$ 在其边内部"和"$p$ 在其内部"的矩形数。模 2 即得。∎

**引理 3（精确覆盖时奇角点必为四角）**：若精确覆盖，则 $c(p)$ 为奇数当且仅当 $p$ 是 $R$ 的四个角之一。

**证明**：$p$ 在 $R$ 内部（不在任何边上）时四个象限都在 $R$ 内且各被覆盖一次，$\sum m_j = 4$ 为偶；$p$ 在 $R$ 的边上但非角点时只有两个象限在 $R$ 内，$\sum m_j = 2$ 为偶；$p$ 是 $R$ 的角时只有一个象限在内，$\sum m_j = 1$ 为奇。由引理 2 得证。∎

**引理 4（奇区域的角点）**：令 $O = \{p : m(p) \text{ 为奇数}\}$ 为被奇数个矩形覆盖的点集，则 $p$ 是 $O$ 的"奇角点"（$p$ 周围被 $O$ 占据的象限数为奇数）当且仅当 $c(p)$ 为奇数。

**证明**：$O$ 在 $Q_j$ 中的指示函数就是 $m_j \bmod 2$，故 $p$ 周围被 $O$ 占据的象限数 $\equiv \sum_j m_j \equiv c(p) \pmod 2$。∎

**定理 1（充分性）**：若面积和 $=\operatorname{area}(R)$，且角点异或的残留点恰为 $R$ 的四个角，则这 $n$ 个矩形精确覆盖 $R$。

**证明**：由引理 4，奇区域 $O$ 的所有奇角点恰是 $R$ 的四角。直角多边形区域的任一连通分支至少含 4 个角点，且分支内部"凸角数 $-$ 凹角数 $=4$"；既然全部奇角点只有 4 个，$O$ 只能含一个分支，且该分支正是以 $R$ 的四角为顶点、没有凹角的矩形。又每个小矩形都含于 $R$（$R$ 由全体坐标的极值定义），故 $O \subseteq R$，于是 $O = R$：$R$ 内几乎处处被**奇数**个矩形覆盖，特别地覆盖数 $\ge 1$，没有空洞。

再由引理 1 的反向记账：$\int_R \bigl(m-1\bigr)\,dA = \sum_i \operatorname{area}_i - \operatorname{area}(R) = 0$，而上面已得 $m - 1 \ge 0$ 处处成立，故 $m \equiv 1$，即精确覆盖。∎

**定理 2（算法正确性）**：`isRectangleCover` 返回 `true` 当且仅当这些矩形精确覆盖某个矩形区域。

**证明**：

- （$\Leftarrow$）若精确覆盖，由引理 1 面积判据通过，由引理 3 角点判据通过，算法返回 `true`。
- （$\Rightarrow$）若算法返回 `true`，两个判据都成立，由定理 1 得精确覆盖；而精确覆盖的整体轮廓必然是外接矩形（$R$ 内每点覆盖 1 次、$R$ 外 0 次）。∎

## 6. 复杂度分析

- **时间**：期望 $O(n)$。一次遍历处理 $n$ 个矩形，每个矩形做 4 次哈希集合的查找/插入/删除，期望 $O(1)$ 每次；最后比较 4 个角点也是 $O(1)$。C++ 的 `unordered_set` 在极端构造下最坏 $O(n)$ 每次，但本题键是规整的整数编码，实际表现接近线性。
- **空间**：$O(n)$。哈希集合最多保存 $4n$ 个候选角点（通常远少于 $4n$，内部点会成对抵消），外加 4 个边界变量与常数空间。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <unordered_set>
#include <climits>
#include <algorithm>
using namespace std;

class Solution {
public:
    bool isRectangleCover(vector<vector<int>>& rectangles) {
        int x1 = INT_MAX, y1 = INT_MAX, x2 = INT_MIN, y2 = INT_MIN;
        for (auto& r : rectangles) {
            x1 = min(x1, r[0]);
            y1 = min(y1, r[1]);
            x2 = max(x2, r[2]);
            y2 = max(y2, r[3]);
        }

        long long area = 0;                 // 面积最大 8e14，必须 64 位
        unordered_set<long long> corners;
        corners.reserve(rectangles.size() * 4 + 8);

        auto key = [](int x, int y) -> long long {          // 坐标平移后压成 64 位键
            return (long long)(x + 100000) * 200001LL + (y + 100000);
        };

        for (auto& r : rectangles) {
            area += (long long)(r[2] - r[0]) * (r[3] - r[1]);
            int xs[2] = {r[0], r[2]}, ys[2] = {r[1], r[3]};
            for (int i = 0; i < 2; i++) {
                for (int j = 0; j < 2; j++) {
                    long long k = key(xs[i], ys[j]);
                    auto it = corners.find(k);              // 异或：有一次就抵消
                    if (it == corners.end()) corners.insert(k);
                    else corners.erase(it);
                }
            }
        }

        if (area != (long long)(x2 - x1) * (y2 - y1)) return false;
        if (corners.size() != 4) return false;
        return corners.count(key(x1, y1)) && corners.count(key(x1, y2)) &&
               corners.count(key(x2, y1)) && corners.count(key(x2, y2));
    }
};
```

### Python

```python
class Solution:
    def isRectangleCover(self, rectangles: list[list[int]]) -> bool:
        x1 = min(r[0] for r in rectangles)
        y1 = min(r[1] for r in rectangles)
        x2 = max(r[2] for r in rectangles)
        y2 = max(r[3] for r in rectangles)

        area = 0
        corners = set()

        for xa, ya, xb, yb in rectangles:
            area += (xb - xa) * (yb - ya)
            for p in ((xa, ya), (xa, yb), (xb, ya), (xb, yb)):
                if p in corners:          # 异或：出现两次就抵消
                    corners.remove(p)
                else:
                    corners.add(p)

        if area != (x2 - x1) * (y2 - y1):
            return False
        return corners == {(x1, y1), (x1, y2), (x2, y1), (x2, y2)}
```

## 8. 边界情况与易错点

1. **面积溢出**：$8\times10^{14}$ 远超 `int`，C++ 里面积累加与乘积都必须先转 `long long`，写成 `(long long)(r[2]-r[0]) * (r[3]-r[1])`，不要写成 `int` 相乘后再转。
2. **只查面积会漏判**：`[[0,0,2,2],[1,0,3,1]]` 重叠 1 与空洞 1 抵消，面积 6 = 6，但答案是 `false`。
3. **只查角点会误判**：三个完全相同的矩形叠加时角点异或恰好剩 4 个外接角，但面积 $3 \ne 1$，答案仍是 `false`。所以两条必须都判。
4. **`size() == 4` 不等于正确**：还要核对这 4 个点就是外接四角，否则把"4 个错误角点"当成合法结果。
5. **单矩形 / 完全重叠**：$n=1$ 返回 `true`；两个相同矩形返回 `false`（面积翻倍）。两者都能被现有判据自然处理，无需特判。
6. **共享边、共享顶点不算重叠**：示例 1 里大量内部网格点被两个矩形共用，它们在角点奇偶里出现两次自动抵消，这正是"相邻合法"的体现。
7. **负坐标**：题面允许 $-10^5$，C++ 编码键时先 `+100000` 平移，避免负数乘法带来的符号问题；Python 直接存元组，天然安全。
