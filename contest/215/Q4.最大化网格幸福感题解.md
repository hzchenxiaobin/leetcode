# LeetCode 最大化网格幸福感 题解

## 1. 题目概述

- **标题 / 题号**：最大化网格幸福感（#1659，hard）
- **链接**：https://leetcode.cn/problems/maximize-grid-happiness/
- **来源**：LeetCode 第 215 场周赛 Q4
- **难度**：困难
- **标签**：状态压缩、动态规划、记忆化搜索、位运算

**题意**：给定 $m \times n$ 网格，以及**至多** `introvertsCount` 个内向的人和 `extrovertsCount` 个外向的人（不必全部放入网格）。每个人占一个格子，幸福感规则：

- **内向**：初始 $120$ 分，每有一个邻居（上下左右四联通）损失 $30$ 分；
- **外向**：初始 $40$ 分，每有一个邻居获得 $20$ 分。

网格幸福感是所有人幸福感之和，求最大可能值。

**约束**：

- $1 \le m, n \le 5$，$1 \le m \cdot n \le 25$
- $0 \le \text{introvertsCount}, \text{extrovertsCount} \le \min(m \cdot n, 6)$

## 2. 示例

**示例 1**

```text
输入：m = 2, n = 3, introvertsCount = 1, extrovertsCount = 2
输出：240

解释：内向的人放 (1,1)，外向的人放 (1,3) 和 (2,3)。
- (1,1) 内向：120 - 0 * 30 = 120
- (1,3) 外向：40 + 1 * 20 = 60
- (2,3) 外向：40 + 1 * 20 = 60
合计 120 + 60 + 60 = 240
```

**示例 2**

```text
输入：m = 3, n = 1, introvertsCount = 2, extrovertsCount = 1
输出：260

解释：内向放 (1,1)、(3,1)，外向放 (2,1)，形成「内-外-内」竖排。
- (1,1) 内向：120 - 30 = 90
- (2,1) 外向：40 + 2 * 20 = 80
- (3,1) 内向：120 - 30 = 90
合计 90 + 80 + 90 = 260
```

**示例 3**

```text
输入：m = 2, n = 2, introvertsCount = 4, extrovertsCount = 0
输出：240

解释：全部放入：每人恰好 2 个邻居，每人 120 - 60 = 60，共 240；
只放对角两个内向同样得 240。
```

## 3. 解题思路

### 3.1 暴力思路

每个格子有「空 / 内向 / 外向」三种状态，共 $3^{mn} \le 3^{25} \approx 8.5 \times 10^{11}$ 种放置方案，直接枚举完全不可行。

即使加上「人数上限」剪枝（内向至多 6 个、外向至多 6 个），方案数仍有 $\sum_{i \le 6, e \le 6} \binom{25}{i}\binom{25-i}{e}$ 的量级（$10^{10}$ 以上），依然爆炸。必须利用**网格宽度极小**（$n \le 5$）这一关键条件做状态压缩。

### 3.2 核心观察一：幸福感可以按「点 + 边」分解

每个人的幸福感 = 初始分 + 对**每个邻居**的调整。把「对邻居的调整」分摊到两人之间的那条边上：

- 内向的人：每条邻接边为自己带来 $-30$；
- 外向的人：每条邻接边为自己带来 $+20$。

于是**总分 = Σ 所有点的点权 + Σ 所有相邻对的边权**：

| 相邻对 | 两端各结算 | 边权合计 |
|--------|-----------|---------|
| 内 - 内 | $-30$ 和 $-30$ | $-60$ |
| 内 - 外 | $-30$ 和 $+20$ | $-10$ |
| 外 - 外 | $+20$ 和 $+20$ | $+40$ |

![核心观察：总分分解为点权加边权](images/gh215_edge_decompose.svg)

这个分解的意义在于：**一条边的贡献只依赖两端格子的人格，与全局其余部分无关**。于是把网格按行切开时：

- **行内水平边**：只依赖本行状态，可以按行状态预处理；
- **行间垂直边**：只依赖相邻两行的状态，可以在行间转移时 $O(1)$（查表）结算。

> 💡 若不做这个分解，「每个人的邻居数」会同时依赖上下两行，行间转移无法 $O(1)$ 完成。

### 3.3 核心观察二：一行 = 一个三进制状态

每格三种取值（$0$=空、$1$=内向、$2$=外向），天然用**三进制数**编码一行。$n \le 5$ 时每行只有 $3^5 = 243$ 种状态。对每个行状态 `mask` 预处理：

- `cntI[mask]` / `cntE[mask]`：该行内向 / 外向人数；
- `rowScore[mask]`：该行全部点权 + 行内水平边边权。

![三进制行状态编码与派生量](images/gh215_ternary_row_mask.svg)

再预处理 `cross[prev][cur]`：上一行 `prev` 与当前行 `cur` 之间所有垂直边的边权之和（同列都非空才算）。

### 3.4 算法流程：按行转移的状压 DP

状态定义：$f[r][\text{prev}][i][e]$ 表示前 $r$ 行已放置、第 $r$ 行状态为 `prev`、还剩 $i$ 个内向与 $e$ 个外向未放置时的最大得分。转移枚举第 $r+1$ 行状态 `cur`：

$$f[r+1][\text{cur}][i - \text{cntI}(\text{cur})][e - \text{cntE}(\text{cur})] = \max\big(f[r][\text{prev}][i][e] + \text{rowScore}(\text{cur}) + \text{cross}[\text{prev}][\text{cur}]\big)$$

初始：虚拟第 $0$ 行全空，$f[0][0][I][E] = 0$；答案是所有终态的最大值（全空方案保证答案 $\ge 0$，对应「一个人都不放」）。

![按行DP转移：rowScore与cross分工](images/gh215_row_dp_transition.svg)

### 3.5 示例演算

![示例1演算：2×3网格最优放置](images/gh215_example_walkthrough.svg)

对示例 1（$m=2, n=3$，内向 1 个、外向 2 个），最优方案的两行状态分别是 `[内, 空, 外]` 与 `[空, 空, 外]`：

- $\text{rowScore}(\text{行1}) = 120 + 40 = 160$（内向与外向隔一格，不相邻）；
- $\text{rowScore}(\text{行2}) = 40$；
- $\text{cross} = $ 第 3 列外-外边 $+40$；
- 总分 $= 160 + 40 + 40 = 240$。∎（与逐人计算 $120 + 60 + 60$ 一致）

## 4. 算法细节

1. **行列交换**：行状态数为 $3^n$，故让 $n = \min(m, n)$（`swap` 后列数更小）。例如 $m=1, n=5$ 交换后变为 5 行 1 列，状态数从 $3^5 = 243$ 降到 $3$。
2. **行状态解码**：三进制低位对应第 $0$ 列，`mask % 3` 取第 0 列、`mask / 3` 右移一列。
3. **rowScore 计算**：先加每个非空格的初始分；再对每对相邻非空格 $(j-1, j)$ 加上 $\text{ADJ}[r_{j-1}] + \text{ADJ}[r_j]$（其中 $\text{ADJ} = \{0, -30, +20\}$）。
4. **cross 计算**：对同列且两行都非空的格子 $j$，加 $\text{ADJ}[\text{prev}_j] + \text{ADJ}[\text{cur}_j]$。**注意双向结算**——两个人都要调整，易错点是只算当前行的人。
5. **DP 组织**：可用滚动数组迭代，也可记忆化搜索 $\text{dfs}(r, \text{prev}, i, e)$；后者只访问可达状态，实际常数更小。
6. **哨兵值**：不可达状态用足够小的 `NEG` 标记；由于全空方案始终可行，最终答案初始化为 $0$ 即可。

## 5. 正确性证明

**引理 1（分解引理）**：任意放置方案的总幸福感等于 $\sum_{p} \text{init}(p) + \sum_{(u,v) \text{ 相邻}} \big(\text{adj}(u) + \text{adj}(v)\big)$，其中 $\text{init}(\text{内})=120$，$\text{init}(\text{外})=40$，$\text{adj}(\text{内})=-30$，$\text{adj}(\text{外})=+20$。

**证明**：按定义，总幸福感 $= \sum_p \big(\text{init}(p) + \sum_{v \in N(p)} \text{adj}(p)\big)$。其中第二项对每条有序对 $(p, v)$ 各计一次 $\text{adj}(p)$；由于相邻关系对称，每条无向边 $(u,v)$ 恰好被 $(u,v)$ 与 $(v,u)$ 各覆盖一次，故第二项等于 $\sum_{(u,v)} (\text{adj}(u) + \text{adj}(v))$。∎

**引理 2（行分解覆盖性）**：把网格的边集划分为「行内水平边」与「行间垂直边」，则 `rowScore(cur)` 恰好结算了 `cur` 行的所有点权和行内水平边，`cross[prev][cur]` 恰好结算了 `prev` 行与 `cur` 行之间的所有垂直边。

**证明**：水平边两端都在同一行内，由 `rowScore` 的构造逐对累加；垂直边两端分属相邻两行且同列，由 `cross` 的构造对「同列双非空」逐列累加。两类边不相交且覆盖全部边，且每条边在 DP 的整个过程中只在其对应位置被结算一次（水平边属于唯一一行，垂直边属于唯一的相邻行对）。∎

**定理**：DP 结束后，$f[m][\text{prev}][i][e]$ 等于「第 $m$ 行状态为 `prev`、剩余 $i$ 内向 $e$ 外向」的所有合法方案的最大总幸福感，因而答案 $\max f$ 为全局最优。

**证明**：对行数 $r$ 归纳。$r=0$ 时只有全空虚拟行，$f[0][0][I][E]=0$ 成立。归纳步：任何 $r+1$ 行方案可唯一拆成「前 $r$ 行方案 + 第 $r+1$ 行状态 `cur`」，由引理 1 其总分为前 $r$ 行总分 + 第 $r+1$ 行点权与水平边（`rowScore[cur]`）+ 行间垂直边（`cross[prev][cur]`），由引理 2 该分解无重无漏；转移枚举了所有满足人数约束的 `cur`，完备。人数维度 $(i,e)$ 精确跟踪两人格的剩余量，保证所有方案合法。∎

## 6. 复杂度分析

- **时间复杂度**：$O(9^n \cdot n + m \cdot 9^n \cdot I \cdot E)$
  - 预处理 `cross` 表：$3^n \times 3^n \times n \approx 3 \times 10^5$；
  - DP 转移：$m \times 3^n \times 3^n \times (I{+}1) \times (E{+}1) \le 5 \times 243^2 \times 49 \approx 1.5 \times 10^7$，轻松通过。
- **空间复杂度**：$O(9^n + 3^n \cdot I \cdot E)$
  - `cross` 表约 $5.9 \times 10^4$ 个整数；
  - 滚动 DP 两层各 $3^n \times 7 \times 7 \approx 1.2 \times 10^4$。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int getMaxGridHappiness(int m, int n, int introvertsCount, int extrovertsCount) {
        if (n > m) swap(m, n);  // 让列数更小，行状态数 3^n 更少

        int tot = 1;
        for (int i = 0; i < n; ++i) tot *= 3;  // 3^n <= 243

        const int INIT[3] = {0, 120, 40};   // 点权
        const int ADJ[3] = {0, -30, 20};    // 每条邻接边对一端的调整

        vector<array<int, 5>> rows(tot);
        vector<int> cntI(tot), cntE(tot), rowScore(tot);
        for (int mask = 0; mask < tot; ++mask) {
            int s = mask;
            auto& r = rows[mask];
            for (int j = 0; j < n; ++j) { r[j] = s % 3; s /= 3; }
            for (int j = 0; j < n; ++j) {
                if (r[j] == 0) continue;
                if (r[j] == 1) ++cntI[mask]; else ++cntE[mask];
                rowScore[mask] += INIT[r[j]];
                if (j > 0 && r[j - 1] != 0)
                    rowScore[mask] += ADJ[r[j]] + ADJ[r[j - 1]];  // 行内水平边
            }
        }

        // cross[p][c]：p 行与 c 行之间全部垂直边的边权之和
        vector<vector<int>> cross(tot, vector<int>(tot));
        for (int p = 0; p < tot; ++p)
            for (int c = 0; c < tot; ++c) {
                int s = 0;
                for (int j = 0; j < n; ++j)
                    if (rows[p][j] && rows[c][j])
                        s += ADJ[rows[p][j]] + ADJ[rows[c][j]];
                cross[p][c] = s;
            }

        const int I = introvertsCount, E = extrovertsCount;
        const int NEG = -1000000000;
        vector f(tot, vector(I + 1, vector<int>(E + 1, NEG)));
        f[0][I][E] = 0;  // 虚拟第 0 行全空

        for (int row = 1; row <= m; ++row) {
            vector g(tot, vector(I + 1, vector<int>(E + 1, NEG)));
            for (int prev = 0; prev < tot; ++prev)
                for (int ic = 0; ic <= I; ++ic)
                    for (int ec = 0; ec <= E; ++ec) {
                        int base = f[prev][ic][ec];
                        if (base == NEG) continue;
                        for (int cur = 0; cur < tot; ++cur) {
                            int ni = ic - cntI[cur], ne = ec - cntE[cur];
                            if (ni < 0 || ne < 0) continue;
                            int v = base + rowScore[cur] + cross[prev][cur];
                            g[cur][ni][ne] = max(g[cur][ni][ne], v);
                        }
                    }
            f.swap(g);
        }

        int ans = 0;  // 全空方案保底为 0
        for (int p = 0; p < tot; ++p)
            for (int ic = 0; ic <= I; ++ic)
                for (int ec = 0; ec <= E; ++ec)
                    if (f[p][ic][ec] != NEG)
                        ans = max(ans, f[p][ic][ec]);
        return ans;
    }
};
```

### Python

```python
from functools import lru_cache

class Solution:
    def getMaxGridHappiness(self, m: int, n: int, introvertsCount: int, extrovertsCount: int) -> int:
        if n > m:                       # 让列数更小，行状态数 3^n 更少
            m, n = n, m
        tot = 3 ** n

        INIT = (0, 120, 40)             # 点权
        ADJ = (0, -30, 20)              # 每条邻接边对一端的调整

        rows, cnt_i, cnt_e, row_score = [], [0] * tot, [0] * tot, [0] * tot
        for mask in range(tot):
            s, row = mask, []
            for _ in range(n):
                row.append(s % 3)
                s //= 3
            rows.append(row)
            cnt_i[mask] = row.count(1)
            cnt_e[mask] = row.count(2)
            sc = sum(INIT[v] for v in row)
            for j in range(1, n):
                if row[j] and row[j - 1]:           # 行内水平边
                    sc += ADJ[row[j]] + ADJ[row[j - 1]]
            row_score[mask] = sc

        cross = [[0] * tot for _ in range(tot)]
        for p in range(tot):
            rp = rows[p]
            for c in range(tot):
                rc = rows[c]
                cross[p][c] = sum(ADJ[rp[j]] + ADJ[rc[j]]
                                  for j in range(n) if rp[j] and rc[j])

        @lru_cache(None)
        def dfs(r: int, prev: int, ic: int, ec: int) -> int:
            if r == m:
                return 0
            best = 0
            for cur in range(tot):
                ni, ne = ic - cnt_i[cur], ec - cnt_e[cur]
                if ni < 0 or ne < 0:
                    continue
                cand = row_score[cur] + cross[prev][cur] + dfs(r + 1, cur, ni, ne)
                if cand > best:
                    best = cand
            return best

        return dfs(0, 0, introvertsCount, extrovertsCount)
```

## 8. 边界情况与易错点

1. **「不必全部放入」是实质性约束，不能贪心全放**
   - 一个内向的人若被 4 个内向邻居包围：自己 $120 - 120 = 0$，还让 4 个邻居各 $-30$，**净贡献 $-120$**。DP 的 $(i, e)$ 维度天然允许「剩余的人不用完」。
2. **cross 要双向结算**
   - 垂直边 `adj(prev) + adj(cur)` 两个人都要调整，漏掉一半是高频 bug（例如内-外边只算了 $-30$ 漏了 $+20$）。
3. **swap 方向**
   - 是让**列数** $n$ 变小（行状态 $3^n$），不是让行数变小；$m=1, n=5$ 应转成 $m=5, n=1$。
4. **三进制解码顺序**
   - 低位对应第 0 列；`row[j] = mask % 3` 后 `mask //= 3`，顺序反了会导致水平边与垂直边配对错位（对称状态下不易发现）。
5. **哨兵与答案初始化**
   - 不可达状态用足够小的 `NEG`；由于「全空」总是可行，答案从 $0$ 起取最大值，$I=E=0$ 时自然返回 $0$。
6. **分数范围**
   - 最大总分为 $25 \times 40 + 40 \times 40 = 2600$（全外向），最小可到负数但答案非负，`int` 足够，无溢出风险。

**延伸思考**：

- **逐格轮廓线 DP**：把状态改为「上一行 mask + 当前行已填部分 mask」，逐格转移可省去一个 $3^n$ 因子，转移更细但代码更长；本题 $n \le 5$ 两种写法都轻松通过。
- **人数上限增大**（如 $\min(mn, 100)$）：$(i, e)$ 维度爆炸，需要观察「最优解中人只会聚在少数连通块」之类的结构性质，难度陡增。
- **变体**：若要求「必须全部放入」，只需把答案改为 $f[m][\cdot][0][0]$ 的最大值；若加入第三种人格（如「中向」），三进制扩成四进制即可，框架不变。
