# LeetCode 每个字符最多出现两次的最长子字符串 题解

## 1. 题目概述

- **标题 / 题号**：每个字符最多出现两次的最长子字符串（#3090，easy）
- **链接**：https://leetcode.cn/problems/maximum-length-substring-with-two-occurrences/
- **来源**：LeetCode 第 390 场周赛 Q1
- **难度**：简单
- **标签**：哈希表、字符串、滑动窗口

**题意**：给定字符串 `s`，找出一个最长的**子字符串**（连续），使得其中**每个字符最多出现两次**，返回该子字符串的最大长度。

**约束**：

- `2 <= s.length <= 100`
- `s` 仅由小写英文字母组成

## 2. 示例

**示例 1**

```text
输入：s = "bcbbbcba"
输出：4

解释：子字符串 "bcba"（下标 4~7）长度为 4，
其中 b 出现 2 次、c 出现 1 次、a 出现 1 次，每个字符都不超过 2 次。
```

**示例 2**

```text
输入：s = "aaaa"
输出：2

解释：任何长度 3 以上的子串都含 3 个 'a'，"aa" 是最长的合法子串。
```

**示例 3（补充）**

```text
输入：s = "abcdef"
输出：6

解释：所有字符互不相同，整串即答案。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有 $O(n^2)$ 个子串，再花 $O(n)$ 逐个统计字符出现次数，总复杂度 $O(n^3)$。本题 $n \le 100$，约 $10^6$ 次操作也能通过，但没有沉淀价值。

稍加改进：固定左端点、右端点递增时**增量维护**计数数组，可降到 $O(n^2 \cdot |\Sigma|)$。这已经离最优只差一步——注意到合法窗口的左端点有单调性，就得到滑动窗口。

### 3.2 核心观察：滑动窗口

![滑动窗口：违规即收缩](images/max_two_occurrences_sliding_window.svg)

**关键性质**：

1. **子窗口继承合法性**：若窗口 `[l, r]` 合法（每字符 ≤ 2 次），则它的任意子窗口也合法——子窗口里每个字符的计数只会更少。
2. **左端点单调不减**：设 `L(r)` 为使 `[l, r]` 合法的最小 `l`，则 `L(r) <= L(r+1)`。

于是可以用**双指针**：右端点 `r` 逐步右移，一旦新字符导致某字符出现 3 次，就右移左端点 `l` 直到重新合法。`l` 和 `r` 各自只前进不后退，总共移动 `O(n)` 步。

### 3.3 算法流程

```text
cnt[26] ← 0, l ← 0, ans ← 0
for r = 0 .. n-1:
    c = s[r]
    cnt[c]++
    while cnt[c] > 2:          # 只有新字符 c 可能违规
        cnt[s[l]]--, l++       # 移出左端字符
    ans = max(ans, r - l + 1)  # 收缩完再更新
return ans
```

**收缩条件为什么只查 `cnt[c]`**：收缩前窗口是合法的（循环不变式），加入 `s[r]` 后**只有** `c = s[r]` 的计数可能从 2 变成 3，其余字符计数不变；而收缩过程中其他字符的计数只减不增。因此 `cnt[c] > 2` 与"窗口非法"**等价**，无需遍历 26 个字母。

### 3.4 示例演算

以 `s = "bcbbbcba"` 为例，逐步走查双指针（完整表格见下图）：

- `r = 0..2`：窗口扩为 `[0,2] "bcb"`，`b:2, c:1` 合法，`ans = 3`。
- `r = 3`：再进一个 `b`，`b` 计数变 3，移出 `s[0]='b'`，窗口 `[1,3] "cbb"`，`ans` 保持 3。
- `r = 4`：又进一个 `b`，连续移出 `s[1]='c'`、`s[2]='b'`，窗口缩到 `[3,4] "bb"`。
- `r = 5..6`：窗口恢复到 `[4,6] "bcb"`，长度 3。
- `r = 7`：进入 `a` 无需收缩，窗口 `[4,7] "bcba"`，长度 4，即最终答案。

![示例走查：bcbbbcba 双指针演算](images/max_two_occurrences_walkthrough.svg)

## 4. 算法细节

1. **计数数组**：`s` 全为小写字母，开 `cnt[26]` 即可（`c = s[i] - 'a'`）。
2. **指针推进顺序**：先把 `s[r]` 计数加一，再 `while` 收缩，最后更新答案——三步顺序不能乱。
3. **只检查新字符**：收缩循环条件是 `cnt[s[r]] > 2`，由 §3.3 的论证与"窗口非法"等价，均摊每步 `O(1)`。
4. **不变式**：每轮 `for` 结束时，窗口 `[l, r]` 必然合法，且 `ans` 等于所有已处理右端点中最长合法窗口的长度。

## 5. 正确性证明

**引理 1（子窗口继承合法性）**：若 `[l, r]` 合法，则任意 `[l', r']`（`l <= l' <= r' <= r`）也合法。

**证明**：`[l', r']` 中每个字符的计数不超过它在 `[l, r]` 中的计数，而后者 ≤ 2。∎

**推论**：对固定 `r`，合法左端点的集合向上封闭（`l` 合法 ⇒ `l+1` 合法），因此存在最小合法左端点 `L(r)`。

**引理 2（左端点单调）**：`L(r) <= L(r+1)`。

**证明**：`[L(r+1), r+1]` 合法，其子窗口 `[L(r+1), r]` 由引理 1 也合法，而 `L(r)` 是使 `[l, r]` 合法的**最小** `l`，故 `L(r) <= L(r+1)`。∎

**定理**：算法对每个 `r` 恰好把窗口收缩到 `[L(r), r]`，返回值 `max(r - L(r) + 1)` 即最长合法子串长度。

**证明**：对 `r` 归纳。设处理完 `r-1` 时 `l = L(r-1)`。处理 `r` 时加入 `s[r]`，由 §3.3 的等价性，`while` 循环当且仅当窗口非法时执行。由 `L(r)` 的最小性，所有 `l < L(r)` 的窗口 `[l, r]` 非法；由引理 2 有 `L(r) >= L(r-1) =` 当前 `l`。于是 `l` 从 `L(r-1)` 逐格右移，途经的位置全部非法，直到 `l = L(r)` 时窗口首次合法、循环终止，且此后不再移动。因此该轮记录的长度恰为以 `r` 结尾的最长合法子串长度；对所有 `r` 取 `max` 即全局最优。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n + |\Sigma|) = O(n)$。
  - `r` 右移 `n` 次；`l` 全程只前进，累计至多 `n` 次；每次移动仅做常数次数组读写。
  - 初始化计数数组 `O(26)`。
- **空间复杂度**：$O(|\Sigma|) = O(26) = O(1)$，仅一个计数数组与两个指针。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int maximumLengthSubstring(string s) {
        int cnt[26] = {0};
        int ans = 0;
        for (int l = 0, r = 0; r < (int)s.size(); ++r) {
            int c = s[r] - 'a';
            ++cnt[c];
            while (cnt[c] > 2) {
                --cnt[s[l] - 'a'];
                ++l;
            }
            ans = max(ans, r - l + 1);
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maximumLengthSubstring(self, s: str) -> int:
        cnt = [0] * 26
        ans = l = 0
        for r, ch in enumerate(s):
            c = ord(ch) - ord('a')
            cnt[c] += 1
            while cnt[c] > 2:
                cnt[ord(s[l]) - ord('a')] -= 1
                l += 1
            ans = max(ans, r - l + 1)
        return ans
```

## 8. 边界情况与易错点

1. **三步顺序不能乱**：必须"计数加一 → 收缩 → 更新答案"。若先更新再收缩，会把违规窗口计入 `ans`。
2. **收缩条件写错**：应写 `cnt[s[r]] > 2`（只查新字符），不要写成 `cnt[s[l]] > 2`，也不必遍历整个计数数组（虽等价但浪费）。
3. **最小输入**：`n = 2` 时任意长度 2 的子串必然合法，答案恒 ≥ 2（`"ab"` → 2，`"aa"` → 2），不存在答案为 0 或 1 的输入。
4. **全同字符**：`"aaaa"` → 2，窗口最多容纳两个相同字符。
5. **字符集**：题目保证小写字母，开 26 即可；若面向通用 ASCII 输入，把数组开到 128 更稳妥。
