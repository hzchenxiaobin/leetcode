# LeetCode 任意子数组和的绝对值的最大值 题解

## 1. 题目概述

- **标题 / 题号**：任意子数组和的绝对值的最大值（#1749，medium）
- **链接**：https://leetcode.cn/problems/maximum-absolute-sum-of-any-subarray/
- **来源**：LeetCode 第 45 场双周赛 Q2
- **难度**：中等
- **标签**：数组、动态规划

**题意**：给定整数数组 `nums`。子数组 $[nums_l, \dots, nums_r]$ 的**和的绝对值**为 $\left|nums_l + \dots + nums_r\right|$。允许选**空子数组**（和为 $0$）。返回任意子数组的**和的绝对值的最大值**。

**约束**：

- $1 \le nums.length \le 10^5$
- $-10^4 \le nums[i] \le 10^4$

## 2. 示例

**示例 1**

```text
输入：nums = [1,-3,2,3,-4]
输出：5
解释：子数组 [2,3] 和的绝对值最大，abs(2+3) = 5。
```

**示例 2**

```text
输入：nums = [2,-5,1,-4,3,-2]
输出：8
解释：子数组 [-5,1,-4] 和的绝对值最大，abs(-5+1-4) = 8。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有 $O(n^2)$ 个子数组，边枚举右边端点边累加和，取绝对值最大。$n = 10^5$ 时约 $5 \times 10^9$ 次操作，超时；即使是 $O(n^2)$ 无优化的 Kadane「枚举起点」版本同样过不去，必须线性或 $O(n \log n)$。

### 3.2 核心观察：绝对值最大 =「最大子段和」与「最小子段和」二选一

![前缀和折线：最大上升落差与最大下降落差取其大](images/bw45_q2_prefix_concept.svg)

设**前缀和** $pre_i = nums_1 + \dots + nums_i$，约定 $pre_0 = 0$。任一子数组 $[l..r]$ 的和为：

$$sum(l..r) = pre_r - pre_{l-1}$$

于是「和的绝对值最大」等价于：在前缀和序列 $\{pre_0, pre_1, \dots, pre_n\}$ 中，找**先后两个点**，使它们差的绝对值最大——也就是折线图上**最大上升落差**（$pre$ 从低到高）与**最大下降落差**（$pre$ 从高到低）二选一：

$$\text{答案} = \max\Big(\max_r (pre_r - \min_{j < r} pre_j),\ \max_r (\max_{j < r} pre_j - pre_r)\Big)$$

前一项正是**最大子段和**（Kadane），后一项是**最小子段和**取负。一句话：**跑两遍 Kadane，一遍求最大子段和、一遍求最小子段和，答案取 $\max(\text{maxSum}, -\text{minSum})$**。

> 💡 由于空子数组允许（贡献 $0$），答案天然非负；对全负数组如 $[-3,-5]$，最大子段和是 $-3$，但最小子段和是 $-8$，答案 $8 = |{-3-5}|$——两遍 Kadane 一个都不能少。

### 3.3 算法流程：一遍扫维护前缀最小 / 最大

![一遍扫同时维护前缀最小与最大的流程](images/bw45_q2_kadane_two_tracks.svg)

```text
pre = mx = mn = ans = 0          # mx/mn 初值为 0，代表 pre_0 = 0（空前缀）
for x in nums:
    pre += x                     # 当前前缀和
    ans = max(ans, pre - mn, mx - pre)
        # pre - mn ：以当前为右端点的最大上升（最大子段和候选）
        # mx - pre ：以当前为右端点的最大下降（最小子段和取负）
    mx = max(mx, pre)            # 更新「历史最小/最大前缀」（供后续右端点使用）
    mn = min(mn, pre)
返回 ans
```

更新 `mx / mn` 放在计算 `ans` **之后**，保证作差的两个前缀点一前一后（$j < r$），不会拿 $pre_r$ 与自己作差。

### 3.4 示例演算

![示例 [2,-5,1,-4,3,-2] 的一遍扫演算](images/bw45_q2_walkthrough.svg)

以示例 2 `nums = [2,-5,1,-4,3,-2]` 走查（$pre$ 序列含 $pre_0=0$ 为 $0,2,-3,-2,-6,-3,-5$）：

| 步骤 | $x$ | $pre$ | $pre - mn$ | $mx - pre$ | $ans$ | $mx$ | $mn$ |
|------|-----|-------|------------|------------|-------|------|------|
| 1 | 2 | 2 | 2 | 0 | 2 | 2 | 0 |
| 2 | −5 | −3 | −3 | 5 | **5** | 2 | −3 |
| 3 | 1 | −2 | 1 | 4 | 5 | 2 | −3 |
| 4 | −4 | −6 | −3 | 8 | **8** | 2 | −6 |
| 5 | 3 | −3 | 3 | 5 | 8 | 2 | −6 |
| 6 | −2 | −5 | 1 | 7 | 8 | 2 | −6 |

第 4 步达到 $mx - pre = 2 - (-6) = 8$，对应「前缀最高点 $pre_1 = 2$ 落到 $pre_4 = -6$」，即子数组 $[-5, 1, -4]$，与示例解释一致。最终返回 $8$。

## 4. 算法细节

1. **初值即空前缀**：`mx = mn = 0` 表示 $pre_0 = 0$ 已在候选集合里，从数组最左端开始的子数组自动被覆盖；`ans = 0` 覆盖空子数组。三者都不要初始化成第一个元素。
2. **更新顺序**：先算 `ans` 再更新 `mx / mn`。若先更新再作差，$pre_r$ 会与自己比较（差恒 $0$），单元素子数组永远拿不到——示例 1 的答案 $5$ 恰是单元素做不到时靠「先减后更」才正确。
3. **Kadane 写法的等价形态**：维护「以当前位置结尾的最大子段和」$f = \max(f, 0) + x$ 与最小子段和 $g = \min(g, 0) + x$，答案 $\max(\max f, -\min g)$。两种写法一一对应，本文选前缀版本是因为它把「上升 / 下降」的几何意义摆得更清楚。
4. **溢出**：$|pre| \le 10^5 \times 10^4 = 10^9$，差值上界 $2 \times 10^9$，贴着 `int` 上界（$2^{31}-1 \approx 2.1 \times 10^9$）。C++ 里用 `long long` 累加最稳，返回前转 `int`；本题答案本身 $\le 10^9$，`int` 装得下。
5. **为什么不用线段树**：维护前缀和 + 区间最大最小可做，但本题是静态数组一遍扫，线段树纯属杀鸡用牛刀（$O(n \log n)$ 还更慢）。

## 5. 正确性证明

**引理 1（前缀和分解）**：对任意 $1 \le l \le r$，$sum(l..r) = pre_r - pre_{l-1}$，且 $0 \le l - 1 < r \le n$；反之任意满足 $j < r$ 的前缀点对 $(j, r)$ 都对应一个（可能为空的）子数组。

**证明**：由定义 $pre_r - pre_{l-1} = \sum_{i=l}^{r} nums_i$。$l \ge 1$ 保证 $l - 1 \ge 0$，$l \le r$ 保证 $l - 1 < r$。反向：给定 $j < r$，取 $l = j + 1$ 即得子数组 $[j+1..r]$（$j = 0$ 时是空前缀到 $r$，即整个前缀）。∎

**引理 2（一遍扫的覆盖性）**：处理第 $r$ 个元素时，`mx` 与 `mn` 的值恰为 $\max_{0 \le j \le r-1} pre_j$ 与 $\min_{0 \le j \le r-1} pre_j$。

**证明**：对 $r$ 归纳。初始（处理第 1 个元素前）`mx = mn = 0`，候选集只含 $pre_0 = 0$，成立。归纳步：处理第 $r$ 个元素时先计算 `ans`（此刻 `mx/mn` 由归纳假设覆盖 $pre_0..pre_{r-1}$），随后才并入 $pre_r$——故处理第 $r+1$ 个元素时 `mx/mn` 覆盖 $pre_0..pre_r$。∎

**定理（算法正确性）**：算法返回的 $ans = \max_{0 \le j < r \le n} |pre_r - pre_j|$，等于所有子数组（含空）和的绝对值的最大值。

**证明**：先证「不小于任何候选」。任取合法点对 $j < r$：若 $pre_r \ge pre_j$，则 $|pre_r - pre_j| = pre_r - pre_j \le pre_r - mn \le ans$；若 $pre_r < pre_j$，则 $|pre_r - pre_j| = pre_j - pre_r \le mx - pre_r \le ans$。两式中 `mn/mx` 覆盖 $pre_j$ 由引理 2 保证，而 `ans` 的每轮更新只取这两种形式之一。再证「不大于最优」：`ans` 的每次更新值 $pre_r - mn$（或 $mx - pre_r$）都由引理 1 对应某个真实子数组和的绝对值，故 `ans` 从不超出真实可达的最大值。两个方向夹逼，得证。最后，空子数组对应差 $0$，`ans` 初值 $0$ 已覆盖，与点对最大值取 max 语义一致。∎

**推论（Kadane 两遍的等价性）**：$\max_{j<r}(pre_r - pre_j)$ 就是最大子段和，$\max_{j<r}(pre_j - pre_r)$ 是最小子段和的相反数，故「两遍 Kadane 取大」与上述一遍扫等价。

## 6. 复杂度分析

- **时间**：$O(n)$。每个元素处理常数次：一次前缀累加、两次作差比较、两次历史值更新。
- **空间**：$O(1)$。只维护 `pre / mx / mn / ans` 四个标量；不需要保存整个前缀和数组。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maxAbsoluteSum(vector<int>& nums) {
        long long pre = 0, mx = 0, mn = 0, ans = 0;
        for (int x : nums) {
            pre += x;
            ans = max({ans, pre - mn, mx - pre});
            mx = max(mx, pre);
            mn = min(mn, pre);
        }
        return (int)ans;
    }
};
```

### Python

```python
class Solution:
    def maxAbsoluteSum(self, nums: list[int]) -> int:
        pre = mx = mn = ans = 0
        for x in nums:
            pre += x
            ans = max(ans, pre - mn, mx - pre)
            mx = max(mx, pre)
            mn = min(mn, pre)
        return ans
```

> 💡 两份代码均通过官方 2 组示例，并与 $O(n^2)$ 全子数组枚举的暴力实现随机对拍 200 组（含正负交错、全正、全负、小值域密集重复），结果全部一致。

## 8. 边界情况与易错点

1. **空子数组**：答案至少为 $0$。`ans` 初值取 $0$ 已覆盖；若刻意初始化成 $-\infty$，全正数组里「最小子段和取负」全为负、只能靠最大子段和兜底尚能对，但空数组退化情形会漏掉 $0$ 下界。记住一条：**答案非负**。
2. **全负 / 全正数组**：全负时答案来自最小子段和（整个数组的和），全正时来自最大子段和；两遍逻辑缺一即错。
3. **更新顺序**：先算 `ans` 再更新 `mx / mn`，否则单元素子数组的差恒为 $0$（自己减自己）。
4. **溢出**：前缀和极值达 $\pm 10^9$，中间量 $mx - pre$ 可达 $2 \times 10^9$，超出 `int` 上界（约 $2.1 \times 10^9$）——虽然本题答案本身 $\le 10^9$ 放得下，中间比较仍会溢出，C++ 用 `long long` 稳妥。
5. **别把「最大子段和的绝对值」写成「子段和绝对值的最大值」的贪心**：逐元素取 $|f|$ 的 Kadane 变体是错的——绝对值不满足最优子结构（负和段后接大正数可能更优），必须从「两遍 Kadane」或「前缀 min/max」入手。
6. **$n = 1$**：答案 $|nums_0|$，一遍扫第 1 轮即得（$pre - mn$ 与 $mx - pre$ 恰好一个等于它）。
