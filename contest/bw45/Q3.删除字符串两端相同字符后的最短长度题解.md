# LeetCode 删除字符串两端相同字符后的最短长度 题解

## 1. 题目概述

- **标题 / 题号**：删除字符串两端相同字符后的最短长度（#1750，medium）
- **链接**：https://leetcode.cn/problems/minimum-length-of-string-after-deleting-similar-ends/
- **来源**：LeetCode 第 45 场双周赛 Q3
- **难度**：中等
- **标签**：双指针、字符串

**题意**：给定只含 `'a'`、`'b'`、`'c'` 的字符串 $s$。一次操作为：选择一个**非空**且字符全相同的前缀、一个**非空**且字符全相同的后缀，两者**不相交**、字符**相同**（长度可以不等！），同时删除。求操作任意多次（可为 0 次）后能得到的**最短长度**。

**约束**：

- $1 \le s.length \le 10^5$
- $s$ 只包含字符 `'a'`、`'b'`、`'c'`

## 2. 示例

**示例 1**

```text
输入：s = "ca"
输出：2
解释：两端字符不同，无法执行任何操作。
```

**示例 2**

```text
输入：s = "cabaabac"
输出：0
解释：c + c → "abaaba" → a + a → "baab" → b + b → "aa" → a + a → ""。
```

**示例 3**

```text
输入：s = "aabccabba"
输出：3
解释：删除前缀 "aa" 与后缀 "a" 得 "bccabb"；再删除前缀 "b" 与后缀 "bb" 得 "cca"。
```

## 3. 解题思路

### 3.1 暴力思路

按题意模拟：当前串若两端字符相同，枚举删除的前缀长度 $p$（不超过左端同字符段长）与后缀长度 $q$（不超过右端同字符段长，$p + q \le$ 当前长度），递归搜索所有分支取最短。状态是「剩余串 = 原串的一个连续子段 $s[i..j]$」，记忆化后仍有 $O(n^2)$ 个状态、每状态 $O(n^2)$ 种转移，$n = 10^5$ 完全不可行。必须找到「每一步怎么删不影响最终结果」的贪心结构。

### 3.2 核心观察：剥洋葱——两端字符相同时，把两端整段一起剥掉

![剥洋葱：两端同字符成对剥，中间剩余无法再动的部分](images/bw45_q3_peel_onion.svg)

两个关键事实：

1. **两端字符不同 ⇒ 永久卡死**。操作要求前缀和后缀字符相同，两端字符不同时一步也做不了，最终长度就是当前长度。
2. **两端字符相同（设为 $c$）⇒ 一次剥光两端整段 $c$ 不会吃亏**。设左端连续 $c$ 段长为 $L$、右端为 $R$。任何操作序列在「两端都是 $c$」的阶段里，每次删除的 $p \le L$、$q \le R$；要么把两边都剥到头进入下一阶段，要么中途一端剥完另一端剩着 $c$——后者两端字符变成「$c$ 与非 $c$」，立刻卡死，且剩余长度**严格大于**整段剥光后再继续的任何结果（见 §5 引理 3）。

于是算法就是**剥洋葱**：双指针 $i, j$ 从两端出发，只要 $s[i] = s[j]$ 就把两端的同字符段整段删除，再看新的两端；某一步两端字符不同即停，剩余长度 $j - i + 1$ 即答案。

> ⚠️ **本题最大的坑**：前缀和后缀的长度**可以不相等**。比如 $"aaa"$ 可以一次删除前缀 $"aa"$ 与后缀 $"a"$ 直接变空串，答案是 $0$ 而不是「左右配对删剩 1 个」的 $1$。反过来 $"aba"$ 剥掉两端 $a$ 后只剩孤零零的 $b$，无法再删，答案是 $1$。停机规则见 3.3。

### 3.3 算法流程与停机规则

```text
i = 0, j = n-1
while i < j 且 s[i] == s[j]:
    c = s[i]
    while i <= j 且 s[i] == c:  i++     # 删掉左端整段 c
    while i <= j 且 s[j] == c:  j--     # 删掉右端整段 c
返回 j - i + 1
```

![停机规则：整段同字符可删空，孤立单字符保留](images/bw45_q3_parity_stop.svg)

停机时的三种情况（内层 `while` 的 `i <= j` 边界是灵魂）：

| 循环停止时的状态 | 含义 | 返回值 |
|------------------|------|--------|
| $s[i] \ne s[j]$（且 $i < j$） | 两端不同，卡死 | $j - i + 1 \ge 2$ |
| $i = j$ | 只剩 1 个字符，前后缀必然相交，删不了 | $1$ |
| $i = j + 1$（左段跨过了右段） | 整段都是同一字符，被左右两刀删光 | $0$ |

由不变量「每轮内层循环至多让 $i$ 越过 $j$ 一次」，$i \le j + 1$ 恒成立，`j - i + 1` 不会出现负数。

### 3.4 示例演算

![示例 "aabccabba" 的剥洋葱走查](images/bw45_q3_walkthrough.svg)

以示例 3 `s = "aabccabba"`（$n = 9$）走查：

| 轮次 | 两端字符 | 左段 $c$ | 右段 $c$ | 操作后剩余 |
|------|----------|-----------|-----------|------------|
| 1 | `a` = `a` | `aa`（$i$：$0 \to 2$） | `a`（$j$：$8 \to 7$） | `bccabb` |
| 2 | `b` = `b` | `b`（$i$：$2 \to 3$） | `bb`（$j$：$7 \to 5$） | `cca` |
| 3 | `c` ≠ `a` | — | — | 卡死，长度 $3$ |

返回 $3$，与示例一致。注意第 1 轮删除的左右两段长度不等（$2$ 与 $1$），这正是「前后缀长度可不同」的直接体现。

## 4. 算法细节

1. **内层边界必须是 `i <= j` 而不是 `i < j`**：当剩余部分整段都是 $c$ 时（如 $"aaa"$、$"aa"$），左段扫描需要「越过」$j$ 才能表达「删光」；若写成 `i < j`，最后会剩 1 个 $c$ 被误报为答案 $1$（$"aa"$ 会返回 $1$ 而非 $0$）。
2. **外层条件 `i < j` 且 `s[i] == s[j]`**：$i = j$ 时单个字符的两端必然相交，不能删；两端字符不同时立即退出，返回当前长度。
3. **返回值不需要取 `max(0, j-i+1)`**：如上所述，$i$ 至多到 $j + 1$，$j - i + 1 \ge 0$ 自动成立。
4. **每轮把两端整段剥光而不是只删一对**：如果每轮只删左右各 1 个字符，$"abaa"$ 这类串会提前卡死（删 `a`+`a` 得 `"ba"` 卡死，长度 2；而整段剥光直接得 `"b"`，长度 1）。
5. **字符集无关**：代码没有用到「只有 abc」这一条件，任意字符集都成立；该条件只是降低了读题时对「更多字符」的想象力成本。

## 5. 正确性证明

**引理 1（剩余总是连续子段）**：任何操作序列执行过程中，剩余字符串始终是原串的连续子段 $s[i..j]$。

**证明**：操作只删除当前串的一个前缀和一个后缀，中间部分原样保留且相对顺序不变；对操作次数归纳，剩余部分始终由原串某个连续区间构成。反之，删除量 $p, q$ 满足 $p + q \le$ 当前长度时操作合法。∎

**引理 2（卡死条件）**：当且仅当当前段为空、或长度为 $1$、或两端字符不同时，无操作可用。

**证明**：操作需要非空同字符前缀与非空同字符后缀且不相交。空串与单字符（前缀后缀必相交）不可操作。长度 $\ge 2$ 且 $s[i] = s[j] = c$ 时，取 $p = q = 1$ 即为合法操作。若 $s[i] \ne s[j]$，任何前缀以 $s[i]$ 开头、任何后缀以 $s[j]$ 结尾，字符相同的条件不满足，无操作。∎

**引理 3（整段剥离占优）**：设当前段 $s[i..j]$ 两端字符均为 $c$，左端 $c$ 段长 $L$、右端 $c$ 段长 $R$。则任何操作序列从该状态出发能达到的最短长度，不小于「先删尽两端 $c$（剩余段 $s[i+L..j-R]$，可能为空）再任意操作」的结果。

**证明**：考察任意操作序列。它在两端仍为 $c$ 的期间（称为「$c$ 阶段」）只能从两端删 $c$（前缀若含非 $c$ 字符则不满足全同；后缀同理），累计删除量 $p \le L$、$q \le R$。阶段退出只有三种方式：

- **删空**（$p + q$ 覆盖整段）：最终长度 $0$，而整段剥离同样能删空（分段多次删，或一次 $p = L$、$q = $ 剩余长度），不劣；
- **左右同时剥尽**（$p = L, q = R$）：到达的状态恰是 $s[i+L..j-R]$，与整段剥离后的状态完全相同，后续完全一样；
- **恰好一端剥尽**（设 $p = L$，$q < R$）：新段左端为非 $c$ 字符 $d$、右端仍为 $c$，两端不同，由引理 2 永久卡死，最终长度 $= (j - q) - (i + L) + 1 > (j - R) - (i + L) + 1 = $ 剥离后的段长 $\ge$ 剥离后再任意操作的最短长度。

三种情况目标序列的最终长度都不小于整段剥离策略，得证。∎

**定理（算法正确性）**：剥洋葱算法返回的 $j - i + 1$ 是可达的最短长度。

**证明**：对剩余段长度归纳应用引理 3：算法在两端相同时执行整段剥离（引理 3 中不劣的选择），在两端不同 / 长度 $\le 1$ 时停止（引理 2：此时任何序列都无法再动）。由引理 1，一切可达状态都是子段，而算法在每个决策点都选择了一个「后续不劣于任何其他选择」的动作，归纳可得算法的最终长度 $\le$ 任何操作序列的最终长度；又算法本身每步都是合法操作（或停止），其结果是可达的。故为最短。∎

## 6. 复杂度分析

- **时间**：$O(n)$。$i$ 只增、$j$ 只减，内外层循环的每一步都让 $i + j$ 严格变化，总移动量不超过 $2n$。
- **空间**：$O(1)$。只有两个下标与一个暂存字符，原地处理。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minimumLength(string s) {
        int i = 0, j = (int)s.size() - 1;
        while (i < j && s[i] == s[j]) {
            char c = s[i];
            while (i <= j && s[i] == c) ++i;   // 删掉左端整段 c
            while (i <= j && s[j] == c) --j;   // 删掉右端整段 c
        }
        return j - i + 1;   // i==j → 1；i==j+1 → 0（整段被删光）
    }
};
```

### Python

```python
class Solution:
    def minimumLength(self, s: str) -> int:
        i, j = 0, len(s) - 1
        while i < j and s[i] == s[j]:
            c = s[i]
            while i <= j and s[i] == c:
                i += 1
            while i <= j and s[j] == c:
                j -= 1
        return j - i + 1
```

> 💡 两份代码均通过官方 3 组示例，并与「枚举每步 $(p, q)$ 全部转移 + 记忆化」的暴力递归实现随机对拍 250 组（含整段同字符、回文、长同字符段等对抗用例，长度 $\le 24$），结果全部一致。

## 8. 边界情况与易错点

1. **前后缀长度可以不等**（本题第一坑）：$"aaa"$ 答案是 $0$（删前缀 `"aa"` + 后缀 `"a"`），不是 $1$；想当然地「左右配对删」会把所有奇数长度的整段同字符串删剩一个字符。
2. **中间孤立的奇数单字符**：$"aba"$、$"aabaa"$ 剥完两端后剩下单个 `b`，无法再删，答案是 $1$——这就是「两端字符不同 ⇒ 卡死」的直接推论。
3. **内层 `while` 用 `i <= j`**：写成 `i < j` 会让 `"aa"` 返回 $1$、`"aaa"` 返回 $1$，而正确答案都是 $0$。
4. **单字符输入**：$n = 1$ 时外层条件 $i < j$ 直接不成立，返回 $1$。
5. **两端一开始就不同**：如 `"ca"`，一步不删直接返回原长度 $2$，不要误把「操作次数为 0」当作非法。
6. **别建子串**：每轮真实地 `substring` / 切片会退化到 $O(n^2)$（Python 尤其），双指针在原串上下标即可。
