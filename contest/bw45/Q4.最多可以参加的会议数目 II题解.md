# LeetCode 最多可以参加的会议数目 II 题解

## 1. 题目概述

- **标题 / 题号**：最多可以参加的会议数目 II（#1751，hard）
- **链接**：https://leetcode.cn/problems/maximum-number-of-events-that-can-be-attended-ii/
- **来源**：LeetCode 第 45 场双周赛 Q4
- **难度**：困难
- **标签**：数组、二分查找、动态规划、排序

**题意**：给定会议数组 $events[i] = [startDay_i, endDay_i, value_i]$：第 $i$ 个会议在第 $startDay_i$ 天开始、第 $endDay_i$ 天结束（**结束日当天也算在会期内**），参加可获得价值 $value_i$。再给整数 $k$：最多参加 $k$ 个会议。同一时间只能参加一个会议，且必须**完整**参加（不能既参加一个会议又参加一个与其结束日 = 另一个开始日重叠的会议）。返回能获得的最大价值和。不需要参加满 $k$ 个。

**约束**：

- $1 \le k \le events.length$
- $1 \le k \times events.length \le 10^6$
- $1 \le startDay_i \le endDay_i \le 10^9$
- $1 \le value_i \le 10^6$

## 2. 示例

**示例 1**

```text
输入：events = [[1,2,4],[3,4,3],[2,3,1]], k = 2
输出：7
解释：参加会议 0 和会议 1，总价值 4 + 3 = 7。
```

**示例 2**

```text
输入：events = [[1,2,4],[3,4,3],[2,3,10]], k = 2
输出：10
解释：只参加会议 2。其余会议与它重叠，不需要参加满 k 个。
```

**示例 3**

```text
输入：events = [[1,1,1],[2,2,2],[3,3,3],[4,4,4]], k = 3
输出：9
解释：会议互不重叠，但只能参加 3 个，选价值最大的 3 个，得 1+2+3 = 9。
```

## 3. 解题思路

### 3.1 暴力思路

枚举会议集合的子集 $2^n$ 种，检查所选会议两两不重叠（两区间 $[s_1,e_1], [s_2,e_2]$ 冲突当且仅当 $s_1 \le e_2$ 且 $s_2 \le e_1$，注意**端点相等也算冲突**）且数量 $\le k$，取最大价值和。$n$ 稍大即爆炸。问题的结构本质是：**带权区间调度（最多选 $k$ 条互不相交线段，权和最大）**——是经典「活动选择 / 线段不交」的带权计数约束版，必须动规。

### 3.2 核心观察：按结束时间排序后，「兼容会议集合」是前缀

![按 end 排序：兼容会议恰为某个前缀，二分定位](images/bw45_q4_dp_model.svg)

把会议按**结束时间**升序排序，考察第 $i$ 个（排序后的）会议。选它时，与它兼容（不冲突）的会议只有两类：**结束早于它开始**的，或**开始晚于它结束**的。关键在于：若我们把「可选范围」限定为「前 $i$ 个会议」（结束时间都不晚于 $end_i$），那么**后面那一类根本不存在**——开始晚于 $end_i$ 的会议其结束时间 $> end_i$，不在前缀里。于是：

$$\text{前 } i \text{ 个会议中与会议 } i \text{ 兼容的} = \text{结束时间} < start_i \text{ 的会议} = \text{排序后前 } p_i \text{ 个}$$

$p_i$ 用**二分查找**在结束时间数组上找（严格小于 $start_i$ 的个数，端点相等即冲突，故必须严格）。这给出了无后效性的转移。

### 3.3 状态设计与转移

$$dp[j][i] = \text{在按 end 升序的前 } i \text{ 个会议中，至多参加 } j \text{ 个的最大价值和}$$

边界：$dp[j][0] = dp[0][i] = 0$。转移（对第 $i$ 个会议二选一）：

$$dp[j][i] = \max\Big(dp[j][i-1],\ \ dp\big[j-1\big]\big[p_i\big] + value_i\Big)$$

- **不选第 $i$ 个**：$dp[j][i-1]$；
- **选第 $i$ 个**：剩余名额 $j - 1$ 只能花在与它兼容的前 $p_i$ 个会议上，得 $dp[j-1][p_i] + value_i$。

答案 $dp[k][n]$。约束 $k \times n \le 10^6$ 恰好为 $O(kn)$ 的 DP 量身定做。实现上**滚动数组**：$dp[j][\cdot]$ 只依赖上一行 $dp[j-1][\cdot]$，保留两行即可，空间 $O(n)$。

> 💡 等价写法：按**开始时间**排序 + 记忆化搜索 $f(i, j) = \max(f(i+1,j),\ value_i + f(nxt_i, j-1))$，$nxt_i$ 是第一个开始时间 $> end_i$ 的会议。两者互为镜像；递归版在 $n$ 达 $10^6$ 时有爆栈风险（Python 尤甚），本文采用按 end 排序的迭代写法。

### 3.4 示例演算

![示例 1 的 dp 演算表](images/bw45_q4_walkthrough.svg)

示例 1：`events = [[1,2,4],[3,4,3],[2,3,1]]`，$k = 2$。按 end 排序后：

| 序号 | 会议 | end | $p_i$（end 严格小于 $start$ 的个数） |
|------|------|-----|------|
| 1 | $[1,2,4]$ | 2 | 0 |
| 2 | $[2,3,1]$ | 3 | 0 |
| 3 | $[3,4,3]$ | 4 | 1（只有 end=2 < 3 的会议 1） |

$j = 1$ 行：$dp[1][1] = 4$；$dp[1][2] = \max(4, 1) = 4$；$dp[1][3] = \max(4, dp[0][1] + 3 = 3) = 4$。
$j = 2$ 行：$dp[2][1] = 4$；$dp[2][2] = 4$；$dp[2][3] = \max(4,\ dp[1][p_3] + 3) = \max(4,\ dp[1][1] + 3) = \max(4, 4 + 3) = 7$。

选「会议 1 + 会议 3」（即原会议 0 与会议 1），$4 + 3 = 7$ ✓。

## 4. 算法细节

1. **排序关键字**：只按 $endDay$ 升序；结束时间相同的会议任意排列皆可（它们彼此冲突，但 $p$ 的计算不受影响，见 §5 引理 1）。
2. **二分方向**：$p_i$ = `lower_bound(ends, start_i)`——**第一个 $\ge start_i$ 的位置**即「严格小于 $start_i$ 的个数」。用 `upper_bound` 会把「end 恰等于 start」的会议也划进兼容集合，而它们与会议 $i$ **冲突**（结束日当天在会期内），必须排除。
3. **滚动数组**：`prev` 保存 $dp[j-1][\cdot]$，`cur` 计算 $dp[j][\cdot]$，每轮结束后 `swap`。内层顺序 $i = 1 \to n$ 递增，`cur[i]` 依赖同行的 `cur[i-1]` 与上一行的 `prev[p]`，顺序天然正确。
4. **$k$ 与 $n$ 的关系**：$dp$ 的行数实际是 $\min(k, n)$——参加数不可能超过会议总数，多出的行是浪费。
5. **溢出**：价值和上界 $\min(k, n) \times 10^6 \le 10^9$（由 $kn \le 10^6$ 与 $k \le n$ 得 $k \le 10^3$），`int` 放得下但已贴边；C++ 中间累加用 `long long` 更稳。
6. **天数范围 $10^9$**：说明不能按「天」开数组做 $O(k \cdot 10^9)$ 的占坑 DP，必须按「会议」为状态离散化——这正是此题与 1353 题（按天贪心）的分野。

## 5. 正确性证明

**引理 1（兼容前缀刻画）**：会议按 end 升序排序后，对前 $i$ 个会议中的任一会议 $e$，$e$ 与会议 $i$ 兼容 $\iff$ $end_e < start_i$；且这类会议恰为排序后的前 $p_i$ 个。

**证明**：区间冲突当且仅当 $s_e \le e_i$ 且 $s_i \le e_e$（含端点相等）。先证 $\Leftarrow$ 方向的逆否：若 $end_e \ge start_i$，又 $e$ 在前 $i$ 个中故 $end_e \le end_i$，而 $s_e \le end_e$，于是 $s_e \le end_i$ 且 $s_i \le end_e$（后者由 $start_i \le end_i$ 与 $end_e \ge start_i$），两会议冲突。故兼容必须 $end_e < start_i$；此时 $s_e \le end_e < start_i$，第一类冲突条件不成立，确实兼容。再证计数：排序后「$end < start_i$」的会议是 `ends` 数组中一段**前缀**（ends 递增，判断阈值与下标无关），其长度即 $p_i$。∎

**引理 2（兼容子集的封闭性）**：设 $S$ 是前 $i$ 个会议中两两兼容的集合且 $i \in S$，则 $S \setminus \{i\}$ 是前 $p_i$ 个会议中两两兼容的集合；反之，前 $p_i$ 个会议中任一两两兼容集合 $T$ 加上 $i$ 仍两两兼容。

**证明**：$S \setminus \{i\}$ 内部兼容性继承自 $S$；其中每个 $e \in S$ 与 $i$ 兼容，由引理 1 得 $end_e < start_i$，故 $e$ 在前 $p_i$ 个中。反向：$T$ 内部兼容，$T$ 中每个会议 end $< start_i$ 与 $i$ 兼容（引理 1）。∎

**定理（DP 正确性）**：$dp[j][i]$ 等于「前 $i$ 个会议中选至多 $j$ 个两两兼容会议」的最大价值和。

**证明**：对 $(i, j)$（按 $i$ 为主序、$j$ 为辅序）做强归纳。边界 $i = 0$ 或 $j = 0$ 时空集唯一可行，值为 $0$，成立。设 $i, j \ge 1$，令 $OPT$ 为该子问题的某个最优解集合，$V(\cdot)$ 为价值和。

- 若 $i \notin OPT$：$OPT$ 是前 $i - 1$ 个会议的合法解，$V(OPT) \le dp[j][i-1] \le dp[j][i]$；同时 $dp[j][i-1]$ 的任何实现（归纳假设它是某可行解的值）在前 $i$ 个中同样可行，故 $dp[j][i-1] \le V(OPT)$... 即 $dp[j][i-1] = V(OPT)$ 也不超过，于是转移第一项正确。
- 若 $i \in OPT$：由引理 2，$OPT \setminus \{i\}$ 是前 $p_i$ 个会议中 $\le j - 1$ 个兼容会议的解，故 $V(OPT \setminus \{i\}) \le dp[j-1][p_i]$（归纳假设），即 $V(OPT) \le dp[j-1][p_i] + value_i \le dp[j][i]$。反过来，取 $dp[j-1][p_i]$ 的最优实现 $T$（归纳假设存在），由引理 2，$T \cup \{i\}$ 是前 $i$ 个会议中 $\le j$ 个的兼容解，价值 $dp[j-1][p_i] + value_i$，故 $OPT$ 的最优值 $V(OPT) \ge dp[j-1][p_i] + value_i$。

两个不等式夹逼得 $dp[j][i]$ 两项转移恰好覆盖「$i$ 不选 / $i$ 选」两种情形且都不超过可行上界，故递推值既可达又不超最优，等于最优。全体会议即前 $n$ 个，答案 $dp[k][n]$。∎

**推论（复杂度可行性）**：定理的转移每项 $O(1)$（$p_i$ 预先二分算好），总时间 $O(n \log n + kn) \le O(n \log n + 10^6)$，在约束 $kn \le 10^6$ 下线性可过。

## 6. 复杂度分析

- **时间**：$O(n \log n + k n)$。排序 $O(n \log n)$；二分 $n$ 次每次 $O(\log n)$；DP 共 $k \times n \le 10^6$ 个状态、每状态 $O(1)$。
- **空间**：$O(n)$。滚动后只存两行长度 $n + 1$ 的数组；另存 `ends` 与 `p` 各 $O(n)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maxValue(vector<vector<int>>& events, int k) {
        int n = (int)events.size();
        sort(events.begin(), events.end(),
             [](const vector<int>& a, const vector<int>& b) { return a[1] < b[1]; });
        vector<int> ends(n), p(n);
        for (int i = 0; i < n; ++i) ends[i] = events[i][1];
        for (int i = 0; i < n; ++i)                     // p[i]：end < start_i 的会议数
            p[i] = (int)(lower_bound(ends.begin(), ends.end(), events[i][0]) - ends.begin());
        vector<long long> prev(n + 1, 0), cur(n + 1, 0); // prev = dp[j-1][*]
        int K = min(k, n);
        for (int j = 1; j <= K; ++j) {
            for (int i = 1; i <= n; ++i) {
                long long take = prev[p[i - 1]] + events[i - 1][2];
                cur[i] = max(cur[i - 1], take);
            }
            swap(prev, cur);
        }
        return (int)prev[n];
    }
};
```

### Python

```python
from bisect import bisect_left


class Solution:
    def maxValue(self, events: list[list[int]], k: int) -> int:
        events.sort(key=lambda e: e[1])          # 按结束时间升序
        ends = [e[1] for e in events]
        n = len(events)
        p = [bisect_left(ends, e[0]) for e in events]   # p[i]：end < start_i 的会议数
        prev = [0] * (n + 1)                     # prev = dp[j-1][*]
        for _ in range(min(k, n)):
            cur = [0] * (n + 1)
            for i in range(1, n + 1):
                cur[i] = max(cur[i - 1], prev[p[i - 1]] + events[i - 1][2])
            prev = cur
        return prev[n]
```

> 💡 两份代码均通过官方 3 组示例，并与「枚举会议子集检查重叠」的暴力实现随机对拍 200 组（$n \le 10$，含同日会议、完全包含区间、$k = 1$ 等），结果全部一致；另在 $n = 10^6, k = 1$ 与 $n = k = 10^3$ 的极限规模下运行通过。

## 8. 边界情况与易错点

1. **端点相接即冲突**：一个会议结束日 = 另一个会议开始日，二者**不能同时参加**（结束日包含在会期内）。二分必须用「严格小于」，`upper_bound` / `bisect_right` 是错的。
2. **不要求参加满 $k$ 个**：转移取 max 而不是「恰好 $j$ 个」；若定义成恰好 $j$ 个，还得对「不足 $j$ 个」的不可行状态取 $-\infty$，平添易错点。
3. **$k > n$**：由约束 $k \le n$ 一般不会发生，但 `min(k, n)` 的保护几乎零成本，防御性写上更稳。
4. **滚动数组的依赖方向**：新行依赖旧行的**任意位置** `prev[p]`（$p$ 可以远小于 $i - 1$），所以必须整行算完再交换，不能在同一条数组上原地滚动。
5. **同 end 会议的顺序**：不影响正确性（引理 1 的刻画只看 end 与阈值的大小关系），无需次级关键字。
6. **数值范围**：$endDay$ 到 $10^9$，警惕任何「按天开桶」的野路子；价值和上界约 $10^9$，`long long` 累加保险。
7. **记忆化版的爆栈风险**：按 start 排序 + 递归写法在 $n = 10^6, k = 1$ 时递归深度可达 $10^6$，C++ 默认栈会溢出，Python 必爆——迭代写法是硬需求，不是风格偏好。
