# LeetCode 最大异或乘积 题解

## 1. 题目概述

- **标题 / 题号**：最大异或乘积（#2939，medium）
- **链接**：https://leetcode.cn/problems/maximum-xor-product/
- **来源**：LeetCode 第 372 场周赛 Q3
- **难度**：中等
- **标签**：贪心、位运算、数学

**题意**：给定三个整数 $a$、$b$ 和 $n$，在所有满足 $0 \le x < 2^n$ 的整数 $x$ 中选一个，使 $(a \oplus x) \cdot (b \oplus x)$ 最大（$\oplus$ 为按位异或）。答案可能很大，返回其对 $10^9 + 7$ 取模后的结果。

**约束**：

- $0 \le a, b < 2^{50}$
- $0 \le n \le 50$

> 💡 读题先抓**结构**：$x < 2^n$ 意味着 $x$ 只能触碰 $a$、$b$ 的**低 $n$ 位**，$\ge n$ 的位一律原样保留。记 $A = a \oplus x$、$B = b \oplus x$，它们在低 $n$ 位上每一位如何取值是**逐位独立**的决策——总共 $n \le 50$ 个布尔自由度。约束给的是 $n \le 50$ 而非 $10^5$ 量级，正是逐位贪心的明示。

## 3. 解题思路

### 3.1 暴力思路

枚举 $x \in [0, 2^n)$ 逐个计算 $(a \oplus x)(b \oplus x)$ 取最大。$n \le 50$ 时候选集大小可达 $2^{50} \approx 10^{15}$，铁定超时。

退一步看：$x$ 的低 $n$ 位每一位才是真正的自由度，共 $n \le 50$ 个，每个只有 0/1 两种选择——问题其实是**在 50 个布尔变量上做优化**。于是自然设问：能否从高位到低位，每一位**单独**定下来？

### 3.2 核心观察：逐位贪心——同位双取 1，异位补给小者

记 $A = a \oplus x$，$B = b \oplus x$。逐位考察第 $i$ 位（$i < n$），只有两种情况：

**情况①（同位）$a_i = b_i$**：$A_i$ 与 $B_i$ 永远同值（一起等于 $a_i$ 或一起翻转）。若当前双双为 0，把 $x_i$ 翻成 1，则 $A$、$B$ 各增加 $2^i$，乘积变化

$$(A + 2^i)(B + 2^i) - AB = 2^i(A + B) + 2^{2i} > 0$$

**严格变大**——不管其他位怎么选都成立，所以最优解中所有同位必为双双 1，无脑取满。顺带一个关键副产物：两人同时 $+2^i$，差 $D = A - B$ 纹丝不动，同位决策完全不影响后续的大小比较。

**情况②（异位）$a_i \ne b_i$**：$A_i$、$B_i$ **恰好一个为 1**，与 $x_i$ 无关（$x_i$ 只是决定这份 1 落在谁头上）。所以这一份 $2^i$ 只有一份，给谁都行？不——直接作差比较两种给法：

$$(A + 2^i) \cdot B - A \cdot (B + 2^i) = 2^i(B - A)$$

$A < B$ 时给 $A$ 严格更优；$A = B$ 时两种给法乘积相同。更深的视角是：异位上 $A + B$ **恒定不变**（恰有一人拿 $2^i$），于是

$$AB = \frac{(A+B)^2 - (A-B)^2}{4} = \frac{S^2 - D^2}{4}$$

$S$ 是常数，最大化乘积 $\Leftrightarrow$ **最小化 $|D|$**——把每一份 $2^i$ 给较小者，正是在把两人往"一样大"拉。

![核心观察：同位与异位的两种决策](images/max_xor_product_bit_cases.svg)

**贪心顺序**：必须**从高位往低位**处理（$i$ 从 $n-1$ 到 $0$）。当前位的权值 $2^i$ 大于剩余所有低位权值之和（$\le 2^i - 1$，超递增），高位先定、每步向"平衡"走，低位之后无论怎么补都翻不了案；反过来先定低位，高位的决策可能把辛苦拉平的差距重新拉开。整套规则浓缩为：

$$\text{for } i = n-1, \dots, 0: \quad \begin{cases} a_i = b_i & \Rightarrow A_i = B_i = 1 \\ a_i \ne b_i & \Rightarrow 2^i \text{ to the smaller of } A, B \end{cases}$$

> ⚠️ 比较大小必须用**完整当前值** $A$、$B$（含 $\ge n$ 的固定高位）。反例：$a = 2^{49}$，$b = 1$，$n = 1$——异位 $2^0$ 上 $A$ 高位压倒性大，这份 $2^0$ 必须给 $B$，否则 $B = 0$ 乘积归零；若只比较低 $n$ 位会误以为"给谁都行"。严格说明见 §5 引理 4。

### 3.3 算法流程

![算法流程：一趟从高位到低位的逐位决策](images/max_xor_product_greedy_flow.svg)

**完整步骤**：

1. **初始化**：`A = a`，`B = b`（真值，含 $\ge n$ 的固定高位，**全程不取模**）；
2. **循环** $i$ 从 $n-1$ 降到 $0$，令 `bit = 2^i`：
   - 若 $(a \gg i) \,\&\, 1 == (b \gg i) \,\&\, 1$（同位）：`A |= bit`，`B |= bit`（双双置 1）；
   - 否则（异位）：若 `A < B` 则 `A |= bit, B &= ~bit`；否则 `B |= bit, A &= ~bit`（把这份 $2^i$ 挪到较小者）；
3. **收尾**：返回 `(A % MOD) * (B % MOD) % MOD`。

> ⚠️ **取模时机**是本题的第二陷阱：循环里要比较 $A$、$B$ 的真实大小，**过程中绝不能取模**。$A, B < 2^{50}$，`long long` 装得下；最后一步再取模，$(10^9+6)^2 < 2^{63}$ 也不溢出。

### 3.4 示例演算

![示例 1 演算：逐位决策表](images/max_xor_product_walkthrough.svg)

以示例 1（$a = 12 = 1100_2$，$b = 5 = 0101_2$，$n = 4$）为例，四个低位依次是异、同、同、异：

| $i$ | $a_i / b_i$ | 判定 | 动作 | $A$ | $B$ |
|-----|------------|------|------|-----|-----|
| 3 | 1 / 0 异位 | $A = 12 > B = 5$ → 补给 $B$ | $A$ 摘走 $2^3$，$B$ 得 $2^3$ | 0100 (4) | 1101 (13) |
| 2 | 1 / 1 同位 | 双双置 1（原本是 1，幂等不变） | — | 0100 (4) | 1101 (13) |
| 1 | 0 / 0 同位 | 双双置 1 | 各 $+2$ | 0110 (6) | 1111 (15) |
| 0 | 0 / 1 异位 | $A = 6 < B = 15$ → 补给 $A$ | $B$ 摘走 $2^0$，$A$ 得 $2^0$ | 0111 (7) | 1110 (14) |

最终 $A = 7$，$B = 14$，乘积 $98$ ✓。反解 $x = a \oplus A = 1100_2 \oplus 0111_2 = 1011_2 = 11$，验证 $12 \oplus 11 = 7$、$5 \oplus 11 = 14$。另一最优解 $x = 2$（对应 $A = 14$、$B = 7$），两者 $|A - B|$ 同为 7——恰是一对"镜像"（见 §5 引理 3）。

示例 2（$a = 6$，$b = 7$，$n = 5$）：低 5 位前四位全是同位（双双置 1 后 $A = B = 30$），末位异位且真值相等 → 给谁都行，得 $31 \times 30 = 930$ ✓。示例 3（$a = 1$，$b = 6$，$n = 3$）：三个异位依次补给 $A$、$B$、$B$，得 $4 \times 3 = 12$ ✓。

## 4. 算法细节

1. **比较用完整当前值**：循环里比较的 $A$、$B$ 必须包含 $\ge n$ 的固定高位与已处理的高位，从 $a$、$b$ 初值出发天然如此；不要自作聪明先 `& ((1<<n)-1)` 把高位掩掉（反例见 §3.2）。

2. **"挪一份 $2^i$"的一步到位写法**：异位分支的 `A |= bit; B &= ~bit` 同时完成置一与清零——这份 $2^i$ 此刻必在其中一人头上（$a_i \ne b_i$），两句合起来即"把它挪到较小者"，无需先判断 bit 现在在谁那里。

3. **同位分支零判断**：`A |= bit; B |= bit` 对已是 1 的位是幂等操作，$a_i = b_i = 0$ 与 $a_i = b_i = 1$ 两种同位统一处理，不用分支讨论。

4. **取模时机**：过程中不取模（比较需要真值）；$A, B < 2^{50}$，C++ `long long` 安全。最后 `(A % MOD) * (B % MOD) % MOD`，两个 $\le 10^9 + 6$ 的数相乘约 $10^{18} < 2^{63}$，同样安全。Python 无溢出之忧，但提前取模同样会破坏比较，一样要留在最后。

5. **为什么从高位往低位**：$2^i$ 大于剩余全部低位权值之和（超递增），先定高位后低位只能微调；顺序反了，高位的后续决策会把低位辛苦拉平的差距重新拉开（严格论证见 §5 引理 3）。

6. **$n = 0$ 与 $a = b$ 无需特判**：$n = 0$ 时 $x$ 只能取 0，循环体不执行，直接返回 $a \cdot b \bmod p$；$a = b$ 时低 $n$ 位全同位，最终 $A = B$，代码自然覆盖。

## 5. 正确性证明

**约定**：记 $\Delta = \{ i < n : a_i \ne b_i \}$（异位集合），$C = \sum_{j \ge n} (a_j - b_j)\, 2^j$（固定高位之差，是与 $x$ 无关的常数），$p = 10^9 + 7$。

**引理 1（同位必双取 1）**：任何最优的 $x$，在所有同位 $i < n$（$a_i = b_i$）处都满足 $a_i \oplus x_i = 1$（即 $A_i = B_i = 1$）。

**证明**：反设某最优 $x$ 在某个同位 $i$ 处 $A_i = B_i = 0$。构造 $x'$ 仅把第 $i$ 位改成 $x_i \oplus 1$，其余位不变，则 $A' = A + 2^i$、$B' = B + 2^i$（$a, b \ge 0$ 且 $x \ge 0$ 保证 $A, B \ge 0$），于是

$$(A + 2^i)(B + 2^i) - AB = 2^i(A + B) + 2^{2i} > 0$$

乘积严格变大，与 $x$ 最优矛盾。∎

**引理 2（化归：最大化乘积 $\Leftrightarrow$ 最小化 $|A - B|$）**：在"所有同位双取 1"的取法类中，$S = A + B$ 为定值 $S^*$；且 $D = A - B$ 的可达值集恰为

$$\{\, C + \sum_{i \in \Delta} \varepsilon_i 2^i : \varepsilon_i \in \{+1, -1\} \,\}$$

在此类中，最大化 $AB$ 等价于最小化 $|D|$。

**证明**：逐位核算。$j \ge n$ 的位：对 $S$、$D$ 的贡献均为 $(a_j \pm b_j)2^j$，与 $x$ 无关。$i < n$ 同位：由前提两位均置 1，对 $S$ 贡献 $2^{i+1}$，对 $D$ 贡献 $0$。$i < n$ 异位：$A_i + B_i = 1$ 恒成立（$a_i \ne b_i$ 时两式恰一真），对 $S$ 贡献 $2^i$；对 $D$ 贡献 $\varepsilon_i 2^i$，符号可任选——要 $\varepsilon_i = +1$ 取 $x_i = a_i \oplus 1$ 即可，各位互不干扰，故可达集如上。综上 $S \equiv S^*$。又

$$4AB = (A+B)^2 - (A-B)^2 = S^{*2} - D^2$$

$S^* > 0$ 时 $AB$ 随 $|D|$ 严格减小；$S^* = 0$ 时 $A = B = 0$，一切取法同优，结论平凡成立。∎

**引理 3（异位贪心：超递增符号和的向零贪心）**：把 $\Delta$ 从大到小排成 $i_1 > i_2 > \cdots > i_k$，记 $w_t = 2^{i_t}$，则 $w_t > \sum_{s > t} w_s$（2 的不同幂天然超递增）。对任意整数初值，按 $t$ 从小到大累加：部分和 $P_{t-1} \ge 0$ 时取 $\varepsilon_t = -1$，$P_{t-1} < 0$ 时取 $+1$（$= 0$ 时任取）。则 $|P_k|$ 在所有符号取法中最小。

**证明**：对 $k$ 归纳，$k = 0$ 平凡。归纳步：把初值记作 $C$（对 $k \ge 2$ 即 $P_1$ 之类的部分和，论证不依赖其来源）。由"把 $C$ 与全部 $\varepsilon$ 同时反号，可达值集合不变"，不妨 $C \ge 0$。记 $T = \sum_{s \ge 2} w_s < w_1$。

断言：存在最优取法使 $\varepsilon_1 = -1$。任取一个取法 $(\varepsilon_1, R)$，其中 $R = \sum_{s \ge 2} \varepsilon_s w_s$，$|R| \le T$。若 $\varepsilon_1 = +1$，其终值 $V = C + w_1 + R \ge C + w_1 - T > 0$。考察**镜像取法** $(-1, -R)$（第一位连同整个后缀符号全部翻转），终值 $V' = C - w_1 - R$：

- 若 $C \ge w_1 + R$：则 $V' = V - 2(w_1 + R) \ge 0$，而 $w_1 + R > 0$（因 $R \ge -T > -w_1$），故 $|V'| < |V|$；
- 若 $C < w_1 + R$：则 $V' < 0$，$|V'| = w_1 + R - C \le w_1 + R + C = |V|$，等号当且仅当 $C = 0$。

故 $\varepsilon_1 = +1$ 的任何取法都不优于某个 $\varepsilon_1 = -1$ 的取法，断言成立；且 $C = 0$ 时两向不等式同时成立，说明**部分和为零处两种取法都能延拓到最优**。在 $\varepsilon_1 = -1$ 的前提下，问题化为从 $P_1 = C - w_1$ 出发、关于 $(w_2, \dots, w_k)$ 的同型子问题，由归纳假设贪心后缀已最优，故整体贪心最优。∎

**引理 4（算法比较与贪心部分和一致）**：算法第 $i$ 步（设 $i \in \Delta$）比较的 $A$、$B$ 中，高于 $i$ 的位已定值，$\le i$ 的位仍是 $a$、$b$ 的原值。记 $P_i$ 为已定部分对差的贡献（固定高位 + 已定同位（贡献 0）+ 已定异位），则 $P_i$ 是 $2^{i+1}$ 的倍数，而未定部分 $\sum_{j \le i}(a_j - b_j)2^j$ 的绝对值 $\le 2^{i+1} - 1$。于是 $P_i \ne 0$ 时 $\mathrm{sign}(A - B) = \mathrm{sign}(P_i)$，算法"把 $2^i$ 给较小者"恰是引理 3 贪心的"部分和向零靠"；$P_i = 0$ 时由引理 3 的等号情形，两种给法都存在最优延拓。

**证明**：$P_i = \sum_{j > i}(A_j - B_j)2^j$，每项含因子 $2^j$（$j > i$），故被 $2^{i+1}$ 整除。未定部分中同位贡献 0，异位贡献 $\pm 2^j$，绝对值 $\le \sum_{j=0}^{i} 2^j = 2^{i+1} - 1 < |P_i|$（当 $P_i \ne 0$），故 $A - B = P_i + (\text{未定})$ 的符号由 $P_i$ 决定。∎

**定理**：算法输出的 $(A, B)$ 满足 $AB = \max_{0 \le x < 2^n} (a \oplus x)(b \oplus x)$，返回值为其模 $p$ 结果。

**证明**：由引理 1，最优解必落在"同位双取 1"的取法类中，算法同位分支亦如此；由引理 2，该类中最大化乘积等价于在可达集 $\{C + \sum_{i \in \Delta} \varepsilon_i 2^i\}$ 上最小化 $|D|$；由引理 4，算法从高位到低位在异位上"给较小者"，每步与引理 3 的向零贪心一致（含 $P_i = 0$ 的任意平局处理）；由引理 3，该贪心达到 $|D|$ 的最小值。故算法终止时 $AB$ 即最大乘积。全程未取模，大小比较均基于真值；末尾的模乘不改变最优性，返回值正确。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。从第 $n-1$ 位到第 $0$ 位一趟扫描，每位 $O(1)$ 的判位与置位；$n \le 50$，总计常数级操作，远低于暴力的 $O(2^n)$。
- **空间复杂度**：$O(1)$。仅 `A`、`B`、`bit` 等常数个变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maximumXorProduct(long long a, long long b, int n) {
        const long long MOD = 1'000'000'007;
        long long A = a, B = b;                 // 真值参与比较，全程不取模
        for (int i = n - 1; i >= 0; i--) {
            long long bit = 1LL << i;           // i 可达 49，必须 1LL
            if (((a >> i) & 1) == ((b >> i) & 1)) {
                A |= bit;                       // 同位：双双置 1（幂等）
                B |= bit;
            } else if (A < B) {
                A |= bit;                       // 异位：把 2^i 挪到较小者
                B &= ~bit;
            } else {
                B |= bit;
                A &= ~bit;
            }
        }
        return (A % MOD) * (B % MOD) % MOD;     // 最后一步才取模
    }
};
```

### Python

```python
class Solution:
    def maximumXorProduct(self, a: int, b: int, n: int) -> int:
        MOD = 10**9 + 7
        A, B = a, b                     # 真值参与比较，全程不取模
        for i in range(n - 1, -1, -1):
            bit = 1 << i
            if (a >> i) & 1 == (b >> i) & 1:
                A |= bit                # 同位：双双置 1（幂等）
                B |= bit
            elif A < B:
                A |= bit                # 异位：把 2^i 挪到较小者
                B &= ~bit
            else:
                B |= bit
                A &= ~bit
        return A % MOD * (B % MOD) % MOD
```

## 8. 边界情况与易错点

1. **过程中取模**：比较 $A$、$B$ 需要真值，循环内取模会把大小关系打乱（模后相等 $\ne$ 真值相等）。$A, B < 2^{50}$，`long long` 直接装得下，最后一步再 `(A % p) * (B % p) % p`。

2. **只比较低 $n$ 位**：反例 $a = 2^{49}$，$b = 1$，$n = 1$——第 0 位是异位，真值上 $A$ 压倒性大，$2^0$ 必须给 $B$；只看低位会误判"给谁都行"。正确姿势是比较完整当前值，引理 4 保证了这恰好等价于比较"已定部分之差"的符号。

3. **从低位往高位处理**：低位先"拉平"会被高位的决策重新拉开，$2^i$ 一枚压过全部剩余低位（超递增），顺序反了必错。

4. **异位补给较大者**：方向写反则差被越拉越大、乘积变小。"给谁都行"只在**真值相等**（引理 3 部分和为零）时成立，不是"低位相等"时成立。

5. **$n = 0$**：$x$ 只能取 0，循环体不执行，直接返回 $a \cdot b \bmod p$，无需特判；测试时常被当隐藏用例。

6. **C++ 位移溢出**：$i$ 最大可到 49，`1 << i` 会在 32 位 `int` 上溢出（触碰符号位是 UB），必须写 `1LL << i`。

7. **$a = b$（含 $a = b = 0$）**：低 $n$ 位全同位，最终 $A = B$；$a = b = 0, n = 5$ 时答案 $31 \times 31 = 961$。

8. **别用浮点直接比乘积**：$A \cdot B$ 可达 $2^{100}$，超出 `double` 的 53 位尾数精度；任何"直接比乘积"的写法都应换成 128 位整数或本解的差值比较。

**延伸思考**：

- **改成最大化 $A + B$**：同位规则不变（双取 1 各赚 $2^i$），异位上 $A + B$ 恒定、怎么给都一样——答案与异位决策无关，可见"平衡补给"完全是**乘积目标**逼出来的。
- **改成最小化 $AB$**（$A, B \ge 0$）：贪心方向反转——同位双取 0、异位补给较大者把差拉开，或干脆把一人按到最小，仍是同一套逐位分析换单调方向。
- **三个数 $(a \oplus x)(b \oplus x)(c \oplus x)$**："和定积最大"的平方差结构不复存在，异位决策三方联动，逐位贪心不再直接可用。
- **镜像对称性**：由引理 3，最优解总成对出现——把全部异位符号翻转得到的 $x'$ 与原解 $|D|$ 相同、乘积相同（示例 1 的 $x = 2$ 与 $x = 11$ 即是一对）。调试时发现多解，多半源于此。
