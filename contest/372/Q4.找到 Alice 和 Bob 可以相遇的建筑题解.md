# LeetCode 找到 Alice 和 Bob 可以相遇的建筑 题解

## 1. 题目概述

- **标题 / 题号**：找到 Alice 和 Bob 可以相遇的建筑（#2940，hard）
- **链接**：https://leetcode.cn/problems/find-building-where-alice-and-bob-can-meet/
- **来源**：LeetCode 第 372 场周赛 Q4
- **难度**：困难
- **标签**：单调栈、二分查找、离线查询、数组

**题意**：给定正整数数组 $\mathrm{heights}$，$\mathrm{heights}[i]$ 表示第 $i$ 栋建筑的高度。人在建筑 $i$，若存在 $i < j$ 且 $\mathrm{heights}[i] < \mathrm{heights}[j]$，则可以移动到建筑 $j$（原地不动也可以）。另有查询数组 $\mathrm{queries}$，$\mathrm{queries}[i] = [a_i, b_i]$ 表示 Alice 在 $a_i$、Bob 在 $b_i$。对每个查询返回两人可相遇的**最左边**建筑下标；不能相遇返回 $-1$。

**约束**：

- $1 \le \mathrm{heights.length} \le 5 \times 10^4$
- $1 \le \mathrm{heights}[i] \le 10^9$
- $1 \le \mathrm{queries.length} \le 5 \times 10^4$
- $0 \le a_i, b_i \le n - 1$

> 💡 读题抓形态：**单向跳跃型**——只能原地不动或向右跳到严格更高的楼。两个关键读题点：其一，一跳可以到右侧**任意**更高的楼，不是一步一格，所以"中转"不会带来新的可达位置（见引理 1）；其二，两人都只能向右，故**相遇位置不可能早于 $\max(a, b)$**——这句话直接把每个查询砍成 O(1) 的三分支判定加一个统一的"右侧第一个更大值"子问题，是本题的胜负手。

## 2. 示例

**示例 1**

```text
输入：heights = [6,4,8,5,2,7], queries = [[0,1],[0,3],[2,4],[3,4],[2,2]]
输出：[2,5,-1,5,2]
解释：
- 查询 [0,1]：6 ≥ 4，两人同去右侧第一个 > 6 的楼 → 建筑 2；
- 查询 [0,3]：6 ≥ 5，右侧第一个 > 6 的楼是建筑 5；
- 查询 [2,4]：8 ≥ 2，右侧没有 > 8 的楼 → -1；
- 查询 [3,4]：5 ≥ 2，右侧第一个 > 5 的楼是建筑 5；
- 查询 [2,2]：两人在同一栋楼，原地相遇 → 2。
```

**示例 2**

```text
输入：heights = [5,3,8,2,6,1,4,6], queries = [[0,7],[3,5],[5,2],[3,0],[1,6]]
输出：[7,6,-1,4,6]
解释：
- 查询 [0,7]：heights[0]=5 < heights[7]=6，Alice 一跳直达 Bob → 7；
- 查询 [5,2]：lo=2, hi=5，heights[2]=8 ≥ 1，右侧没有 > 8 的楼 → -1。
```

**补充示例：等高也不直达（严格性陷阱）**

```text
输入：heights = [3,3], queries = [[0,1]]
输出：[-1]
解释：heights[0] = heights[1]，移动要求"严格更高"，Alice 到不了 Bob 的楼，
      右侧也没有更高的楼 → -1。
```

## 3. 解题思路

### 3.1 暴力思路

每个查询单独处理：设 $\mathrm{lo} = \min(a, b)$、$\mathrm{hi} = \max(a, b)$。先花 $O(1)$ 判定 $a = b$ 与 $\mathrm{heights}[\mathrm{lo}] < \mathrm{heights}[\mathrm{hi}]$ 两种直达情况（见 3.2）；否则从 $\mathrm{hi}+1$ 向右线性扫描，找到第一个 $\mathrm{heights}[j] > \mathrm{heights}[\mathrm{lo}]$ 的下标。单次查询 $O(n)$，总计 $O(nq) \approx 2.5 \times 10^9$，$5 \times 10^4$ 规模下必然超时。

> 💡 注意到 $\mathrm{queries}$ 只读、与处理顺序无关——典型的**离线**信号：把查询按某种次序分组挂载，配合一次扫描统一回答。

### 3.2 核心观察：每个查询都能 O(1) 归一化

先刻画可达性。定义 $\mathrm{reach}(u)$ 为从 $u$ 出发能到达（含原地）的位置集合。由于一跳可到任意右侧更高的楼，可达性没有"中转加成"：

$$\mathrm{reach}(u) = \{u\} \cup \{j > u : \mathrm{heights}[j] > \mathrm{heights}[u]\}$$

（严格证明见引理 1。）于是 $\mathrm{reach}(u)$ 中所有位置都 $\ge u$，这是三分支判定的基石：

设 $\mathrm{lo} = \min(a, b)$、$\mathrm{hi} = \max(a, b)$，且 $a \ne b$：

1. **情况①** $a = b$：两人已在同一栋，答案就是 $a$；
2. **情况②** $\mathrm{heights}[\mathrm{lo}] < \mathrm{heights}[\mathrm{hi}]$：矮的一方一跳直达 $\mathrm{hi}$；而另一人可达位置全 $\ge \mathrm{hi}$，$\mathrm{hi}$ 已是最左可能，答案就是 $\mathrm{hi}$；
3. **情况③** $\mathrm{heights}[\mathrm{lo}] \ge \mathrm{heights}[\mathrm{hi}]$：矮的一方连 $\mathrm{hi}$ 都站不上（需严格更高），两人只能一起向右找更高的楼。此时 $\mathrm{heights}[\mathrm{lo}]$ 是**瓶颈**——$j$ 要同时满足 $\mathrm{heights}[j] > \mathrm{heights}[\mathrm{lo}]$ 和 $\mathrm{heights}[j] > \mathrm{heights}[\mathrm{hi}]$，而前者蕴含后者。答案即：

$$\min\{\, j > \mathrm{hi} : \mathrm{heights}[j] > \mathrm{heights}[\mathrm{lo}] \,\}，不存在则 -1$$

情况①② $O(1)$ 直接出答案；情况③ 全部归结为同一个子问题：**给定位置 $\mathrm{hi}$ 与阈值 $x = \mathrm{heights}[\mathrm{lo}]$，求 $\mathrm{hi}$ 右侧第一个高度大于 $x$ 的下标**。这正是单调栈的主场。

![查询归一化：三种情况一击判完](images/meet_building_case_analysis.svg)

### 3.3 算法流程：从右往左扫 + 单调栈 + 栈上二分

对子问题「$\mathrm{hi}$ 右侧第一个 $> x$ 的下标」用经典离线套路：让扫描指针与查询同步。

1. **预处理**：所有查询归一化；情况③ 的查询挂到 $\mathrm{qs}[\mathrm{hi}]$，记录 $(x, \mathrm{id})$；
2. **扫描**：$i$ 从 $n-1$ 递减到 $0$，维护单调栈 $\mathrm{st}$（存下标；栈底→栈顶**下标递减、高度严格递减**）：
   - **回答**：处理挂在 $\mathrm{qs}[i]$ 上的每个 $(x, \mathrm{id})$——在栈数组中**二分**找最靠栈顶的满足 $\mathrm{heights}[\mathrm{st}[t]] > x$ 的位置 $t$，则 $\mathrm{ans}[\mathrm{id}] = \mathrm{st}[t]$；栈中没有比 $x$ 高的则保持 $-1$；
   - **维护**：不断弹出 $\mathrm{heights}[\mathrm{st}[\mathrm{top}]] \le \mathrm{heights}[i]$ 的栈顶，再把 $i$ 入栈。

直观理解栈的内容：**站在 $i$ 处抬头能看见的楼**——$j$ 在栈中当且仅当 $j > i$ 且 $\mathrm{heights}[j]$ 比 $(i, j)$ 中所有楼都高；中间挡视线的楼，早在它更高的楼入栈时就被弹掉了。查询 $(\mathrm{hi}, x)$ 要找的最左更高楼必然"可见"（它比 $(\mathrm{hi}, j^*)$ 中一切楼都高），所以**一定在栈里**；又因栈内高度从栈底到栈顶严格递减，满足 $> x$ 的元素恰是栈数组的一段前缀，**最靠栈顶的满足者下标最小**，二分一次即可定位。

### 3.4 示例演算

以示例 1 $\mathrm{heights} = [6,4,8,5,2,7]$ 演算全程。5 个查询归一化后：$[0,1] \to (\mathrm{hi}=1, x=6)$，$[0,3] \to (\mathrm{hi}=3, x=6)$，$[2,4] \to (\mathrm{hi}=4, x=8)$，$[3,4] \to (\mathrm{hi}=4, x=5)$，$[2,2]$ 直接答 $2$。扫描各步：

| $i$（高度） | 回答挂在此步的查询 | 本步弹出 | $i$ 入栈后的栈（底→顶） |
|------------|--------------------|---------|------------------------|
| 5（7） | — | — | $[5]$ |
| 4（2） | $(x{=}8)$：栈中最高 $7 \le 8$ → $-1$；$(x{=}5)$：$7 > 5$ → **5** | — | $[5, 4]$ |
| 3（5） | $(x{=}6)$：$h2 \le 6$ 跳过，$h7 > 6$ → **5** | $4$（$2 \le 5$） | $[5, 3]$ |
| 2（8） | — | $3$（$5 \le 8$）、$5$（$7 \le 8$） | $[2]$ |
| 1（4） | $(x{=}6)$：$h8 > 6$ → **2** | — | $[2, 1]$ |
| 0（6） | — | $1$（$4 \le 6$） | $[2, 0]$ |

五个答案全部收网：$\mathrm{ans} = [2, 5, -1, 5, 2]$，与官方一致。

## 4. 算法细节

1. **判定顺序**：先特判 $a = b$（直接 $a$，不看高度），再比较 $\mathrm{heights}[\mathrm{lo}]$ 与 $\mathrm{heights}[\mathrm{hi}]$。若把 $a = b$ 也拿去比高度，$\mathrm{heights}[a] = \mathrm{heights}[b]$ 时会误入情况③。

2. **挂载点是 $\mathrm{hi}$ 而非 $\mathrm{lo}$**：查询要在"扫描指针到达 $\mathrm{hi}$、$\mathrm{hi}$ 尚未入栈"的时刻回答，此时栈中恰好只有 $j > \mathrm{hi}$ 的可见楼；阈值才是 $\mathrm{lo}$ 的高度。位置与阈值一左一右，别挂反。

3. **弹栈条件是 $\le$，不是 $<$**：查询要求严格 $> x$，等高的楼对 $\mathrm{heights}[j] > x$ 的判定毫无贡献，必须弹掉；这也保证了栈内高度**严格**递减，是二分谓词单调性的来源。否则如 $\mathrm{heights} = [3, 3]$ 的栈会残留等高元素，被误当成答案。

4. **二分的目标**：栈数组 $\mathrm{st}$ 底→顶高度严格递减，故谓词"$\mathrm{heights}[\mathrm{st}[t]] > x$"关于 $t$ 呈**前缀真、后缀假**；要找的是**最后一个真**（最靠栈顶的满足者），它才是下标最小者。写二分时找"第一个假再回退"也行，但直接"找最后一个真"最不易错。

5. **数据结构选择**：栈用支持随机访问的 `vector`（C++）/ `list`（Python）模拟，因为回答查询需要对栈做二分，而只支持 `push/pop` 的抽象栈做不到。

6. **挂载表**：$\mathrm{qs}$ 是长度 $n$ 的桶数组，桶 $\mathrm{qs}[\mathrm{hi}]$ 存 $(x, \mathrm{id})$ 对；多个查询共享同一 $\mathrm{hi}$（如示例 1 的两个 $\mathrm{hi}=4$）在同一时刻顺次回答，互不干扰。

## 5. 正确性证明

**引理 1（可达性刻画）**：$\mathrm{reach}(u) = \{u\} \cup \{j > u : \mathrm{heights}[j] > \mathrm{heights}[u]\}$。

**证明**：右 $\subseteq$ 左显然（原地合法；一跳规则直接给出）。反之设经链 $u = m_0 < m_1 < \cdots < m_k = j$ 逐步可达，每步满足 $\mathrm{heights}[m_{t+1}] > \mathrm{heights}[m_t]$，链上高度严格递增，故 $\mathrm{heights}[j] > \mathrm{heights}[u]$ 且 $j > u$，即 $j$ 属于右侧集合。∎

**引理 2（归一化正确）**：设 $\mathrm{lo} = \min(a,b)$、$\mathrm{hi} = \max(a,b)$，$a \ne b$。

（i）若 $\mathrm{heights}[\mathrm{lo}] < \mathrm{heights}[\mathrm{hi}]$，则最左相遇点为 $\mathrm{hi}$；

（ii）否则最左相遇点为 $\min\{j > \mathrm{hi} : \mathrm{heights}[j] > \mathrm{heights}[\mathrm{lo}]\}$，不存在则 $-1$。

**证明**：由引理 1，$\mathrm{reach}(\mathrm{hi}) \subseteq \{\mathrm{hi}, \mathrm{hi}+1, \dots\}$，任何相遇点 $\ge \mathrm{hi}$。

（i）此时 $\mathrm{hi} \in \mathrm{reach}(\mathrm{lo})$（直接一跳），又 $\mathrm{hi} \in \mathrm{reach}(\mathrm{hi})$，故 $\mathrm{hi}$ 可行且已是最左。

（ii）候选点只能是 $j > \mathrm{hi}$：$j = \mathrm{hi}$ 需要 $\mathrm{heights}[\mathrm{lo}] < \mathrm{heights}[\mathrm{hi}]$，与前提矛盾；$j < \mathrm{hi}$ 不在 $\mathrm{reach}(\mathrm{hi})$ 中。对 $j > \mathrm{hi} > \mathrm{lo}$：$j \in \mathrm{reach}(\mathrm{lo}) \Leftrightarrow \mathrm{heights}[j] > \mathrm{heights}[\mathrm{lo}]$，$j \in \mathrm{reach}(\mathrm{hi}) \Leftrightarrow \mathrm{heights}[j] > \mathrm{heights}[\mathrm{hi}]$。由 $\mathrm{heights}[\mathrm{lo}] \ge \mathrm{heights}[\mathrm{hi}]$，前者蕴含后者，故相遇点集合恰为 $\{j > \mathrm{hi} : \mathrm{heights}[j] > \mathrm{heights}[\mathrm{lo}]\}$，取最小元即得。∎

**引理 3（栈不变量）**：在扫描指针到达 $i$、回答 $\mathrm{qs}[i]$ 的时刻，栈中元素恰为

$$S_i = \{\, j > i : \mathrm{heights}[j] > \mathrm{heights}[m],\ \forall\, m \in (i, j) \,\}$$

且从栈底到栈顶下标严格递减、高度严格递减。

**证明**（对 $i$ 从 $n-1$ 到 $0$ 归纳）：$i = n-1$ 时栈空，$S_{n-1} = \varnothing$，成立。设指针到达 $i$ 时栈 $= S_i$。回答查询后进入维护：弹出 $\mathrm{heights} \le \mathrm{heights}[i]$ 的栈顶——因栈内高度严格递减，这类元素恰为顶部连续一段，全部弹出后栈为 $\{j \in S_i : \mathrm{heights}[j] > \mathrm{heights}[i]\}$；再压入 $i$。逐个验证新栈元素都属于 $S_{i-1}$：$j = i$ 时 $(i-1, i)$ 为空，平凡成立；$j \in S_i$ 且 $\mathrm{heights}[j] > \mathrm{heights}[i]$ 时，$(i-1, j) = \{i\} \cup (i, j)$ 中一切 $m$ 都有 $\mathrm{heights}[m] < \mathrm{heights}[j]$，故 $j \in S_{i-1}$。反之设 $j \in S_{i-1}, j \ne i$：则 $j > i$ 且对 $m \in (i, j)$ 有 $\mathrm{heights}[m] < \mathrm{heights}[j]$（因 $(i, j) \subset (i-1, j)$），即 $j \in S_i$；又有 $\mathrm{heights}[i] < \mathrm{heights}[j]$，故 $j$ 未被弹出、仍在栈中。单调性：栈内任两元素 $j_1$（更靠底）与 $j_2$（更靠顶），都有 $j_2 \in (i, j_1)$ 区间约束之内（$j_2 > i$ 且 $j_2 < j_1$），故 $\mathrm{heights}[j_2] < \mathrm{heights}[j_1]$，即底→顶严格递减；下标按入栈顺序自然递减。∎

**定理**：算法对每个查询输出的即最左相遇建筑。

**证明**：情况①② 由引理 2 直接保证。情况③ 设 $x = \mathrm{heights}[\mathrm{lo}]$，$j^* = \min\{j > \mathrm{hi} : \mathrm{heights}[j] > x\}$（若存在）。

- **$j^*$ 在栈中**：一切 $m \in (\mathrm{hi}, j^*)$ 满足 $\mathrm{heights}[m] \le x < \mathrm{heights}[j^*]$，故 $j^* \in S_{\mathrm{hi}}$，由引理 3 它此刻在栈中；
- **二分找到的恰是 $j^*$**：栈中高度 $> x$ 的元素（含 $j^*$）都是 $> \mathrm{hi}$ 且高度 $> x$ 的下标，故均 $\ge j^*$；由栈内高度严格递减，这些元素构成栈数组的底部前缀，其中**最靠栈顶者下标最小**，而 $j^*$ 是其中一员，故该元素下标 $\le j^*$。二者夹逼即二分返回 $\mathrm{st}[t] = j^*$；
- **无解情形**：若二分未命中（栈底高度都 $\le x$），则 $S_{\mathrm{hi}}$ 中没有高度 $> x$ 的元素；而任何满足条件的 $j^*$ 必属 $S_{\mathrm{hi}}$，故不存在这样的 $j$，输出 $-1$ 正确。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n + q \log n)$。预处理归一化 $O(q)$；扫描中每个下标至多入栈一次、出栈一次，栈维护总计 $O(n)$；每个查询恰好做一次栈上二分 $O(\log n)$。$n, q \le 5 \times 10^4$ 时约 $10^6$ 量级基本运算，远低于暴力。
- **空间复杂度**：$O(n + q)$。栈最深 $n$，挂载表与答案各 $O(q)$，另有归一化暂存 $O(q)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> leftmostBuilding(vector<int>& heights, vector<vector<int>>& queries) {
        int n = heights.size(), q = queries.size();
        vector<int> ans(q, -1);
        vector<vector<pair<int, int>>> qs(n);
        for (int i = 0; i < q; i++) {
            int a = queries[i][0], b = queries[i][1];
            if (a == b) {
                ans[i] = a;
                continue;
            }
            int lo = min(a, b), hi = max(a, b);
            if (heights[lo] < heights[hi]) {
                ans[i] = hi;
            } else {
                qs[hi].push_back({heights[lo], i});
            }
        }
        vector<int> st;
        for (int i = n - 1; i >= 0; i--) {
            for (auto& [x, id] : qs[i]) {
                int l = 0, r = (int)st.size() - 1, pos = -1;
                while (l <= r) {
                    int mid = (l + r) / 2;
                    if (heights[st[mid]] > x) {
                        pos = mid;
                        l = mid + 1;
                    } else {
                        r = mid - 1;
                    }
                }
                if (pos != -1) {
                    ans[id] = st[pos];
                }
            }
            while (!st.empty() && heights[st.back()] <= heights[i]) {
                st.pop_back();
            }
            st.push_back(i);
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def leftmostBuilding(self, heights: List[int], queries: List[List[int]]) -> List[int]:
        n, q = len(heights), len(queries)
        ans = [-1] * q
        qs = [[] for _ in range(n)]
        for i, (a, b) in enumerate(queries):
            if a == b:
                ans[i] = a
                continue
            lo, hi = min(a, b), max(a, b)
            if heights[lo] < heights[hi]:
                ans[i] = hi
            else:
                qs[hi].append((heights[lo], i))
        st = []
        for i in range(n - 1, -1, -1):
            for x, idx in qs[i]:
                l, r, pos = 0, len(st) - 1, -1
                while l <= r:
                    mid = (l + r) // 2
                    if heights[st[mid]] > x:
                        pos = mid
                        l = mid + 1
                    else:
                        r = mid - 1
                if pos != -1:
                    ans[idx] = st[pos]
            while st and heights[st[-1]] <= heights[i]:
                st.pop()
            st.append(i)
        return ans
```

## 8. 边界情况与易错点

1. **$a = b$ 必须最先特判**，返回 $a$ 本身；若拿去比高度，相等时会误走情况③ 得到错误答案。

2. **等高不直达**：$\mathrm{heights}[\mathrm{lo}] = \mathrm{heights}[\mathrm{hi}]$ 属于情况③。移动要求"严格更高"，用 $\le$ 判直达会把 $\mathrm{heights} = [3,3]$ 的查询 $[0,1]$ 错答成 $1$（正确为 $-1$）。

3. **弹栈条件是 $\le$**：等高元素留在栈里会破坏"高度严格递减"，二分谓词失去前缀单调性，还可能把等高楼当答案返回。

4. **二分找"最后一个真"**：即最靠栈顶的满足者（下标最小）。误写成"第一个满足者"会返回栈底（最右端）的答案。

5. **查询挂在 $\mathrm{hi}$、阈值用 $\mathrm{heights}[\mathrm{lo}]$**：两者来自不同端点，反了则栈内全是 $j > \mathrm{lo}$ 的楼，可能返回 $\mathrm{lo}$ 与 $\mathrm{hi}$ 之间的错误下标。

6. **无解保持 $-1$**：栈空（如 $\mathrm{hi} = n-1$）或栈中全 $\le x$ 时不要覆盖初值；答案数组初始化为 $-1$、仅在二分命中时写入即可。

7. **值域无坑**：$\mathrm{heights}[i] \le 10^9$，`int` 足够，无溢出风险。

8. **别在查询里线性扫栈**：单次从栈顶扫到栈底最坏 $O(n)$，$q$ 次即 $O(nq)$ 退化回暴力；必须二分。同理不要对每个查询重新建栈。

**延伸思考**：

- **在线版怎么做**？若查询必须即时回答：建高度最大值线段树，查询"位置 $\mathrm{hi}$ 之后第一个值 $> x$ 的下标"用线段树二分下降，单次 $O(\log n)$；或预处理 ST 表后对前缀最大值做外层二分，复杂度同阶。
- **能否去掉二分、做到 $O(n + q)$**？可以：把同一 $\mathrm{hi}$ 的查询按 $x$ **降序**排序，扫描指针从栈顶向下走的路径单调不回退，组内双指针即可；或采用"查询挂到栈元素上、弹出时结算"的懒删除姿势。
- **NGE 链 + 倍增**：预处理每个位置的"下一个更大元素"构成森林，答案必在 $\mathrm{hi}$ 的祖先链上（链上高度严格递增），倍增跳链同样 $O(\log n)$ 查询，可与单调栈解法互证。
- 若把规则改为**双向移动**或"不高于也可走"，可达结构完全不同（后者一点就连通到后缀最大值），三分支归一化即失效——可见本题的精巧正在"单向 + 严格更高"这两个约束上。
