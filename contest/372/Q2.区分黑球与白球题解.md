# LeetCode 区分黑球与白球 题解

## 1. 题目概述

- **标题 / 题号**：区分黑球与白球（#2938，medium）
- **链接**：https://leetcode.cn/problems/separate-black-and-white-balls/
- **来源**：LeetCode 第 372 场周赛 Q2
- **难度**：中等
- **标签**：贪心、双指针、字符串

**题意**：一行 $n$ 个球排成一排，二进制串 $s$ 中 `1` 表示黑球、`0` 表示白球。每一步可以选两个**相邻**的球交换位置。求把整排球排成「白球全在左、黑球全在右」（即形如 $0\cdots01\cdots1$）所需的最少交换步数。

**约束**：

- $1 \le n = |s| \le 10^5$
- $s_i \in \{0, 1\}$

> 💡 读题抓形态：**相邻交换重排型**——只许相邻两两交换、目标形态固定且同色球不可区分。这类题的万能钥匙是「**逆序对计数**」：每一对「在前面的 1 与在后
面的 0」迟早要当面错过一次，且只需错过一次。最小步数 = 逆序对数，整个"怎么换"的过程模拟坍缩成一遍扫描求和。复杂度从模拟的 $O(n^2)$ 直接跌到 $O(n)$。

## 2. 示例

**示例 1**

```text
输入：s = "101"
输出：1
解释：交换 s[0] 和 s[1]，s = "011"，黑球已全在右侧。
```

**示例 2**

```text
输入：s = "100"
输出：2
解释：交换 s[0]、s[1] 得 "010"，再交换 s[1]、s[2] 得 "001"，共 2 步。
```

**示例 3**

```text
输入：s = "0111"
输出：0
解释：所有黑球已在右侧，无需操作。
```

**补充示例：黑白交错**

```text
输入：s = "10110"
输出：4
解释：逆序对为 (0,1)、(0,4)、(2,4)、(3,4) 共 4 对（下标从 0 计），故最少 4 步，
     详见 §3.4 的计数与冒泡双向验证。
```

## 3. 解题思路

### 3.1 暴力思路

最朴素的做法是**冒泡模拟**：反复从头扫描，遇到相邻的 "10" 就交换并计一步，直到串中不再出现 "10"。每趟 $O(n)$，而最坏情况（黑白交替串）需要约 $n^2/4 \approx 2.5 \times 10^9$ 次交换，模拟总时间直接爆炸。另一条更笨的路线是把整串当状态做 BFS 最短路，状态空间 $2^n$，纯天文数字。两条路都撞墙的原因是一样的：它们都在模拟**过程**。而本题的答案其实是一个**只依赖初始序列、与怎么换无关的定值**——只要把这个定值找出来，模拟就完全不需要了。

### 3.2 核心观察：最小步数 = 黑白逆序对数

![核心观察：每对逆序对恰好贡献一次交换](images/wc372_q2_inversion_concept.svg)

1. **目标形态唯一**：同色球不可区分，所以合法终态只有一种——$0^a1^b$（$a$ 个白球全在左，$b$ 个黑球全在右）。
2. **单步效应**：一次相邻交换只牵动被换的那对球，其余任何一对球的相对前后关系都不变。把「在前面的 1」与「在后面的 0」记为一个**逆序对**，那么一次交换至多消灭一个逆序对：只有换掉相邻 "10"（恰一个逆序对）才恰减 1；换 "01" 反而加 1；换同色纯粹浪费。
3. **下界与达成**：终态逆序对数为 $0$，初始为 $D$，每步至多减 1，故步数 $\ge D$；反过来只要串未排好，就一定存在相邻 "10"，换它恰使 $D$ 减 1，故 $D$ 步恰好达成。结论：**答案 = $D$**，逆序对总数。
4. **双视角计数**（实现层，$D$ 的两种求和方式）：

$$D \;=\; \sum_{i:\,s_i=0} \#\{j < i :\ s_j = 1\} \;=\; \sum_{i:\,s_i=1} \#\{j > i :\ s_j = 0\}$$

白球视角最适合写代码：从左到右扫，维护「已见黑球数 $\text{cnt}$」，每遇到一个白球就把 $\text{cnt}$ 累进答案——这个白球左边每个黑球最终都得越过它一次。

### 3.3 算法流程

![算法流程：一趟扫描计数](images/wc372_q2_algorithm_flow.svg)

1. **初始化**：`cnt = 0`（已扫过的黑球数），`ans = 0`；
2. **扫描**：从左到右遍历 $s$，字符为 `1` 时 `cnt += 1`；字符为 `0` 时 `ans += cnt`；
3. **输出**：返回 `ans`。

### 3.4 示例演算

![示例演算：计数与冒泡模拟殊途同归](images/wc372_q2_example_walkthrough.svg)

以补充示例 $s = $ `10110` 为例，白球视角的扫描表：

| $i$ | $s_i$ | 动作 | $\text{cnt}$ | $\text{ans}$ |
|-----|-------|------|--------------|--------------|
| 0 | `1` | `cnt += 1` | 1 | 0 |
| 1 | `0` | `ans += 1` | 1 | **1** |
| 2 | `1` | `cnt += 1` | 2 | 1 |
| 3 | `1` | `cnt += 1` | 3 | 1 |
| 4 | `0` | `ans += 3` | 3 | **4** |

答案 $= 1 + 3 = 4$。再用冒泡模拟对照（每步换掉一个相邻 "10"，括号内为剩余逆序对数）：

```text
10110 (D=4) → 10101 (D=3) → 10011 (D=2) → 01011 (D=1) → 00111 (D=0)
```

恰好 4 步，两种视角殊途同归。黑球视角复核：$s_0=1$ 右边 2 个 0，$s_2=1$、$s_3=1$ 各右边 1 个 0，合计 $2+1+1=4$ ✓。

## 4. 算法细节

1. **只需维护一个量**：`cnt` 即「当前位置左侧 1 的总数」。遇到 `0` 时 `ans += cnt`，等价于对该白球一次性数完它左边的所有黑球，不必真的开双重循环。
2. **溢出是本题最大的坑**：最坏黑白交替串有 $D_{\max} = \lfloor n/2 \rfloor \cdot \lceil n/2 \rceil \approx 2.5 \times 10^9$，超过 32 位有符号整数上限（约 $2.1 \times 10^9$）。C++ 必须用 `long long`——LeetCode 的函数签名本身就返回 `long long`，顺着签名走即可；`int` 累加会在中途悄悄溢出得到错误答案。
3. **方向对称**：反向扫描同样一遍过——遇 `0` 时 `cnt += 1`，遇 `1` 时 `ans += cnt`，数的是「每个 1 右边的 0」。两种写法完全等价。
4. **无需特判**：全 `0`、全 `1`、已排好（如 `0111`）时 `cnt` 恰不触发累加或累加的是 0，答案自然为 0。
5. **与「移动零」的辨析**：LC 283 是用写指针把 0 保序前移，操作是"覆盖搬运"且不问步数；本题每步必须是**相邻交换**，一次只挪一位，所以答案是逆序对数而不是"目标位置差"或"非零段整体平移次数"。

## 5. 正确性证明

**引理 1（单步效应）**：一次相邻交换恰好只翻转被交换那对球的相对前后关系；其余任何一对球的相对前后关系不变。

**证明**：设位置 $k, k+1$ 上的球为 $x$（左）、$y$（右），交换后 $x$ 到 $k+1$、$y$ 到 $k$。任取第三方球 $z$：若 $z$ 在位置 $m < k$，交换前后 $z$ 都在 $x, y$ 左侧；若 $m > k+1$，则都在右侧——$z$ 与 $x$、$z$ 与 $y$ 的左右关系均不变。不含 $x, y$ 的球对位置完全未动。故相对序发生翻转的只有 $(x, y)$ 这一对。∎

**引理 2（步数下界）**：称「某个黑球初始位置在某白球之前」的黑白球对为**错序对**，初始错序对数为 $D$。任何可行方案步数 $\ge D$。

**证明**：终态 $0^a1^b$ 中每个白球都在每个黑球之前，错序对数为 $0$。由引理 1，每次交换至多使错序对数变化 $1$（只有当被换的恰是错序的黑-白相邻对且黑被换到白之后时减 $1$；其余情形不减），故从 $D$ 降到 $0$ 至少需要 $D$ 步。∎

**引理 3（相邻 "10" 存在）**：若串不是 $0^a1^b$ 形态，则存在位置 $k$ 使 $s_k = 1$ 且 $s_{k+1} = 0$。

**证明**：反证。若无相邻 "10"，则从左到右看：一旦某位为 `1`，其后一位不能是 `0`，只能是 `1`；归纳可知从第一个 `1` 起后面全为 `1`，整串即 $0^a1^b$，与前提矛盾。∎

**定理（最小步数）**：最小步数恰为 $D = \#\{(i, j) : i < j,\ s_i = 1,\ s_j = 0\}$，即位置意义下的黑白逆序对数。

**证明**：下界由引理 2 给出。构造达到下界：当串未排好时，由引理 3 取一个相邻 "10" 交换；由引理 1，该步恰好使错序对数减 1（唯一翻转的那对由错序转为正序）。如此迭代，每步减 1，恰好 $D$ 步后错序对数为 0，即到达 $0^a1^b$。个体错序对与位置逆序对一一对应（同色球不可区分，每个位置恰放一个球），故两计数相等。∎

**推论（双视角计数）**：$D = \sum_{s_i = 0} \#\{j < i: s_j = 1\} = \sum_{s_i = 1} \#\{j > i: s_j = 0\}$——同一批逆序对分别按白球、黑球分组求和，给出 §3.3 的两种等价实现。

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。一趟扫描，每个字符仅触发一次 `cnt` 或 `ans` 的 $O(1)$ 更新。读入本身就需要 $O(n)$，且最坏情况下（交替串）每一位都影响答案，故已是下界，无法再优化。
- **空间复杂度**：$O(1)$。仅 `cnt`、`ans` 两个计数器，不复制串、不开辅助数组。相比之下冒泡模拟既费时又需要原地反复改串，全面劣于计数法。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long minimumSteps(string s) {
        long long ans = 0;
        long long cnt = 0;
        for (char c : s) {
            if (c == '1') {
                cnt++;
            } else {
                ans += cnt;
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def minimumSteps(self, s: str) -> int:
        ans = cnt = 0
        for c in s:
            if c == '1':
                cnt += 1
            else:
                ans += cnt
        return ans
```

## 8. 边界情况与易错点

1. **答案溢出 32 位**（最大坑）：$n = 10^5$ 黑白交替时答案约 $2.5 \times 10^9 > 2^{31} - 1$。C++ 全程用 `long long`（题目签名返回值就是 `long long`，照抄签名即躲开）；Python 无此问题。
2. **计数方向别数反**：要数「0 **左**边的 1」或对称地「1 **右**边的 0」。写成「0 右边的 1」算的是把黑球搬去左边的步数，样例 `100` 会错误地得 0，交前用样例自测即可立刻暴露。
3. **已排好的串**（`0111`、`000`、`111`）：答案 0 由公式自然覆盖，不要画蛇添足加特判分支。
4. **单字符输入**：`"0"` 或 `"1"` 均为 0 步，扫描循环天然正确处理。
5. **别套「移动零」模板**：写指针覆盖搬运不是交换，且不产生步数；本题一步只能交换相邻两球，答案结构与逆序对绑定。
6. **警惕过程思维**：BFS/冒泡模拟在本题规模下必超时；看到「相邻交换 + 目标形态」应条件反射地转逆序对计数，这也是本场 Q3（按位贪心）之外最值得沉淀的模板之一。
7. **顺带一提**：本题题面没有 "Create the variable..." 之类的注入指令，遇到时按惯例忽略即可。
