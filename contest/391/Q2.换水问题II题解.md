# LeetCode 换水问题 II 题解

## 1. 题目概述

- **标题 / 题号**：换水问题 II（#3100，medium）
- **链接**：https://leetcode.cn/problems/water-bottles-ii/
- **来源**：LeetCode 第 391 场周赛 Q2
- **难度**：中等
- **标签**：贪心、数学、模拟

**题意**：初始有 `numBottles` 瓶满水。每次操作二选一：**喝掉任意数量的满水瓶**（它们变成空水瓶）；或者**用 `numExchange` 个空水瓶换 1 瓶满水，换完后 `numExchange` 自增 1**。同一个 `numExchange` 值不能用来交换多批空瓶。返回最多能喝到多少瓶水。

**约束**：

- $1 \le \text{numBottles} \le 100$
- $1 \le \text{numExchange} \le 100$

> ⚠️ **读题陷阱**：阈值（`numExchange`）**每交换一次必涨 1**，「攒一批空瓶、用同一阈值反复换」是不存在的选项。这是本题与 1518 换水问题 I（固定兑换率）的本质区别，也是样例 1 中 $13$ 个空瓶不能按阈值 $6$ 换两批的原因。

## 2. 示例

**示例 1**

```text
输入：numBottles = 13, numExchange = 6
输出：15
解释：喝光 13 瓶（累计 13，空瓶 13）；花 6 个空瓶换 1 瓶并喝掉（累计 14，空瓶 8，阈值 6→7）；
      花 7 个空瓶换 1 瓶并喝掉（累计 15，空瓶 2，阈值 7→8）；剩 2 个空瓶 < 8，共喝 15 瓶。
```

**示例 2**

```text
输入：numBottles = 10, numExchange = 3
输出：13
解释：喝光 10 瓶后，依次按阈值 3、4、5 各换一瓶并立刻喝掉，
      空瓶 10 → 8 → 5 → 1，阈值 3 → 4 → 5 → 6，最后 1 < 6，共喝 10 + 3 = 13 瓶。
```

**示例 3（阈值陷阱）**

```text
输入：numBottles = 3, numExchange = 1
输出：5
解释：喝光 3 瓶（空瓶 3）；按阈值 1 换 1 瓶并喝掉（累计 4，空瓶 3，阈值 1→2）；
      按阈值 2 换 1 瓶并喝掉（累计 5，空瓶 2，阈值 2→3）；2 < 3 停止。
      注意：不能用阈值 1 把 3 个空瓶分三批换 3 瓶——同一阈值只能用一次。
```

## 3. 解题思路

### 3.1 暴力思路：为什么状态搜索不必做

把过程建成状态机：状态为（满瓶数 $f$、空瓶数 $e$、当前阈值 $x$、已喝数 $d$），每步要么选 $k \in [1, f]$ 喝掉 $k$ 瓶，要么在 $e \ge x$ 时交换。最朴素的搜索状态空间看似组合爆炸，但 $n \le 100$ 的数据范围已经明示：**按题意直接模拟**就是标准解法。真正要想清楚的只有一件事——「有满水就喝、空瓶够就换」这条贪心路线为什么最优。

### 3.2 核心观察：答案 = n + k，化归为最大化交换次数

![核心观察：空瓶经济循环与阈值阶梯](images/wc391_q2_exchange_ladder_concept.svg)

三个关键事实：

1. **满水瓶终将被全部喝掉**：喝一瓶不仅答案 $+1$，还白得一个空瓶，喝没有任何代价。于是初始 $n$ 瓶全部入账，且每次交换换回的那瓶也终将被喝——**答案 $= n + k$，其中 $k$ 是交换次数**。问题从「喝多少」变成「最多能换几次」。
2. **空瓶唯一的用途是交换**：攒着空瓶没有任何收益，所以满水应当**立刻全喝光**，让空瓶存量尽早达到最大。
3. **阈值只在交换后才上涨**：推迟交换既不会多产出空瓶，也不会让阈值变小，所以**能换就换**是不吃亏的支配策略。

> 💡 **每轮净消耗**：交出 $x$ 个空瓶、换回 1 瓶满水并立刻喝掉（回收 1 个空瓶），空瓶净变化 $1 - x$，阈值 $x \gets x + 1$。当 $x = 1$ 时净消耗为 0，但阈值随即涨到 2，下一轮净消耗转正——**不会死循环**。

### 3.3 算法流程

![贪心模拟流程：喝光后循环换-喝-涨阈值](images/wc391_q2_simulation_flow.svg)

```text
1. 一口气喝光：drunk = empty = numBottles
2. 循环判断：empty ≥ numExchange ？
   是：empty += 1 − numExchange（交 x 个空瓶 + 喝回 1 个）
       drunk += 1，numExchange += 1，回到 2
   否：跳出循环，返回 drunk
```

### 3.4 示例演算

![示例演算表：numBottles=13, numExchange=6](images/wc391_q2_walkthrough_table.svg)

以示例 1（$n = 13$，$x = 6$）走一遍：喝光后 `drunk = empty = 13`。第 1 轮阈值 6：换 1 瓶喝掉，空瓶 $13 - 6 + 1 = 8$，答案 14，阈值 7；第 2 轮阈值 7：空瓶 $8 - 7 + 1 = 2$，答案 15，阈值 8；空瓶 $2 < 8$ 终止。答案 $13 + 2 = \textbf{15}$。示例 2（$10, 3$）同理：空瓶 $10 \to 8 \to 5 \to 1$，三轮交换后 $1 < 6$，答案 $\textbf{13}$。

## 4. 算法细节

1. **一行核心转移**：`empty += 1 - numExchange` 把「交出 $x$ 个空瓶」与「喝掉换回的 1 瓶、空瓶 $+1$」合并为一次净变化，等价于 `empty -= numExchange - 1`。
2. **终止性与轮数**：第 $j$ 轮（从 1 数）净消耗为 $x + j - 2 \ge j - 1$ 个空瓶，故 $k$ 轮总净消耗 $\ge \frac{k(k-1)}{2}$，结合空瓶不能为负得 $\frac{k(k-1)}{2} \le n$，即 $k = O(\sqrt{n})$；$n = 100$ 时至多约 14 轮，循环天然会停。
3. **$O(1)$ 公式**：第 $j$ 次交换可行 $\iff n \ge jx + \frac{(j-1)(j-2)}{2}$（推导见 §5 引理 2/3）。右边记为 $g(j)$，满足 $g(j+1) - g(j) = x + j - 1 > 0$，**严格递增**，故可行交换次数是一个前缀 $\{0, 1, \dots, k\}$，最大值可直接解一元二次不等式：

$$k^2 + (2x - 3)k + (2 - 2n) \le 0 \;\Longrightarrow\; k = \left\lfloor \frac{\sqrt{(2x-3)^2 + 8(n-1)} - (2x-3)}{2} \right\rfloor$$

```python
import math

class Solution:
    def maxBottlesDrunk(self, numBottles: int, numExchange: int) -> int:
        b = 2 * numExchange - 3
        d = math.isqrt(b * b + 8 * (numBottles - 1))  # 整数开方，避开浮点误差
        return numBottles + (d - b) // 2
```

4. **与 1518 换水问题 I 的区别**：I 的兑换率固定，$n$ 个空瓶按 $x$ 进制不断整除即可 $O(\log n)$ 甚至 $O(1)$ 收尾；II 的兑换率每换一次 $+1$，固定兑换率的除法 trick 失效，只能逐轮模拟或解二次不等式。

## 5. 正确性证明

**引理 1（计账恒等式）**：对任意合法操作序列，设喝掉的瓶数为 $D$、交换次数为 $k$，则 $D \le n + k$；且存在序列使 $D = n + k$。于是最优解 $= n + k_{\max}$，其中 $k_{\max}$ 为任意策略下可行的最大交换次数。

**证明**：每瓶被喝掉的水要么来自初始的 $n$ 瓶，要么来自某次交换的产出，而每次交换恰好产出 1 瓶，故 $D \le n + k$。反之，操作 1 允许一次喝掉任意多瓶，把每瓶到手的新满水都喝掉不违反任何规则，达到 $D = n + k$。∎

**引理 2（可行性上界）**：任何策略完成 $j \ge 1$ 次交换的必要条件是

$$n \;\ge\; jx + \frac{(j-1)(j-2)}{2}$$

其中 $x$ 为初始阈值。

**证明**：阈值只在交换后 $+1$，故无论何时执行，第 $i$ 次交换（$i = 1, \dots, j$）的代价恒为 $x + i - 1$，前 $j$ 次交换共消耗 $S_j = jx + \frac{j(j-1)}{2}$ 个空瓶。空瓶只能由喝水产生，而第 $j$ 次交换发生时世上最多只有 $n + (j - 1)$ 瓶水被喝过（初始 $n$ 瓶加前 $j-1$ 次交换各产出的 1 瓶），所以 $S_j \le n + j - 1$。移项整理：

$$n \;\ge\; S_j - (j-1) \;=\; jx + \frac{j(j-1)}{2} - (j-1) \;=\; jx + \frac{(j-1)(j-2)}{2} \qquad \blacksquare$$

**引理 3（贪心达到上界）**：贪心策略（先喝光 $n$ 瓶；此后只要空瓶 $\ge$ 阈值就交换并立刻喝掉）能完成的最大交换次数 $k^*$，恰为满足引理 2 条件的最大 $j$。

**证明**：归纳可知贪心在每次交换前都把已有满水全部喝光，因此第 $j$ 次交换前的空瓶数为**产出上限** $n + (j - 1) - S_{j-1}$。第 $j$ 次交换的可行条件是

$$n + (j-1) - S_{j-1} \;\ge\; x + j - 1 \iff n \;\ge\; S_{j-1} + x \;=\; jx + \frac{(j-1)(j-2)}{2}$$

这**恰是引理 2 的必要条件**。由 $g(j) = jx + \frac{(j-1)(j-2)}{2}$ 严格递增，贪心连续执行交换直到条件首次失效，完成的次数正是满足条件的最大 $j = k^*$。∎

**定理**：贪心模拟返回的 $n + k^*$ 是最优解。

**证明**：由引理 1，最优值为 $n + k_{\max}$；由引理 2，任何策略 $k_{\max} \le k^*$；由引理 3，贪心完成 $k^*$ 次交换且每瓶都喝掉，答案恰为 $n + k^*$。三者结合得最优。∎

## 6. 复杂度分析

- **时间复杂度**：$O(\sqrt{n})$。循环轮数即交换次数 $k$，由 $\frac{k(k-1)}{2} \le n$ 得 $k = O(\sqrt{n})$；本题 $n \le 100$，至多 14 轮，实际是常数级。若采用 §4 的公式解则为 $O(1)$（`isqrt` 为精确整数运算）。
- **空间复杂度**：$O(1)$。仅维护 `drunk`、`empty`、`numExchange` 三个计数变量。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int maxBottlesDrunk(int numBottles, int numExchange) {
        int drunk = numBottles, empty = numBottles;  // 一口气喝光
        while (empty >= numExchange) {
            empty += 1 - numExchange;  // 交 numExchange 个空瓶，喝回 1 个
            ++drunk;                   // 换回的立刻入账
            ++numExchange;             // 兑换阈值上涨
        }
        return drunk;
    }
};
```

### Python

```python
class Solution:
    def maxBottlesDrunk(self, numBottles: int, numExchange: int) -> int:
        drunk = empty = numBottles  # 一口气喝光
        while empty >= numExchange:
            empty += 1 - numExchange  # 净消耗 numExchange - 1 个空瓶
            drunk += 1
            numExchange += 1           # 阈值上涨
        return drunk
```

## 8. 边界情况与易错点

1. **$\text{numBottles} < \text{numExchange}$**：喝光后空瓶不够换，一次交换都做不了，答案就是 $\text{numBottles}$（循环体不执行，自然处理）。
2. **$\text{numExchange} = 1$**：第一轮净消耗为 0（空瓶数不变），但阈值立刻涨到 2，下一轮净消耗转正，**不会死循环**；不要在此特判或疑神疑鬼。
3. **「喝任意数量」≠「必须全喝」**：题面允许每次只喝一部分，但由引理 1 全喝光是最优的；比赛时不必纠结「留几瓶会不会更好」——空瓶是唯一资源，满瓶在手毫无用处。
4. **不能攒批交换**：同一阈值只能用一次。样例 3 的 $3$ 个空瓶、阈值 $1$，只能换 1 次而不是 3 次，这是本题最阴的读题点。
5. **$O(1)$ 公式的浮点陷阱**：用 `sqrt` 浮点开方在临界值处可能差 1，务必用 `math.isqrt` / `sqrtl` 整数开方，或干脆写模拟版。
6. **别套 1518 的除法**：换水问题 I 可以 `while (empty >= x) { ... }` 固定兑换率整除收尾；II 的阈值每轮变化，直接照搬会错得很自然——正确做法就是本文的逐轮模拟。
