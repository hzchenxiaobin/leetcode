# LeetCode 交替子数组计数 题解

## 1. 题目概述

- **标题 / 题号**：交替子数组计数（#3101，medium）
- **链接**：https://leetcode.cn/problems/count-alternating-subarrays/
- **来源**：LeetCode 第 391 场周赛 Q3
- **难度**：中等
- **标签**：数组、数学、动态规划

**题意**：给定二进制数组 `nums`，统计其中**交替子数组**的数目。交替子数组的定义：**不存在两个相邻元素的值相同**的连续子数组；单个元素也算交替子数组。

**约束**：

- $1 \le \text{nums.length} \le 10^5$
- $\text{nums}[i] \in \{0, 1\}$

> 💡 两个读题要点：子数组必须**连续**（不是子序列）；由于数组只含 0/1，「相邻不同」等价于「相邻元素恰好一个 0 一个 1」。实际上本题解法对任意值域都成立，「二进制」是个烟雾弹。

## 2. 示例

**示例 1**

```text
输入：nums = [0,1,1,1]
输出：5
解释：交替子数组为 [0]、[1]、[1]、[1]、[0,1]，共 5 个。
      注意 [1,1] 含相邻相等对不合法，[0,1,1] 同理。
```

**示例 2**

```text
输入：nums = [1,0,1,0]
输出：10
解释：整个数组都在交替，任意连续子数组都合法，
      长度 1~4 的子数组分别有 4、3、2、1 个，共 10 个。
```

**示例 3（全相同元素）**

```text
输入：nums = [1,1,1,1]
输出：4
解释：只有 4 个单元素子数组交替，任何长度 ≥ 2 的子数组都含相邻相等对。
```

## 3. 解题思路

### 3.1 暴力思路

枚举全部 $O(n^2)$ 个子数组并逐一检查是否交替，朴素检查是 $O(n)$，总计 $O(n^3)$；固定左端点向右扩展、利用「子数组交替 ⇒ 去掉首元素仍交替」把检查摊还成 $O(1)$，也仍是 $O(n^2)$。$n = 10^5$ 时约 $10^{10}$ 次操作，必然超时。突破口在于：**合法子数组的分布不是零散的，而是成段聚集的**——应当按结构批量计数，而非逐个判断。

### 3.2 核心观察：极大交替段分解，每段贡献 $\frac{L(L+1)}{2}$

![核心观察：极大交替段分解与每段贡献](images/wc391_q3_run_decomposition.svg)

在所有「相邻相等对」的位置各切一刀，数组被分成若干**极大交替段**：每段内部相邻元素全不相等，段与段之间被一个相等对隔开。两个事实：

1. **段内任意子数组都交替**：交替性只取决于子数组内部的相邻对，而段内所有相邻对都不相等。于是长度为 $L$ 的段内，任意子数组都合法，贡献 $\frac{L(L+1)}{2}$ 个。
2. **跨段必不合法**：跨过刀口的子数组必然包含那个相邻相等对，直接出局。

于是**答案 $= \sum_{\text{段}} \frac{L(L+1)}{2}$**。如 $[1,0,1,1,0]$：切成 $[1,0,1]$ 与 $[1,0]$ 两段，贡献 $\frac{3 \times 4}{2} + \frac{2 \times 3}{2} = 6 + 3 = 9$。

### 3.3 算法流程：一次扫描的 DP（按右端点计数）

![算法流程：一次扫描 DP](images/wc391_q3_dp_flow.svg)

换一个等价且更好写的视角：设 $cur_i$ 为**以 $i$ 结尾**的交替子数组个数（它恰等于以 $i$ 结尾的最长交替子数组长度），则答案 $= \sum_i cur_i$。转移只看相邻两个元素：

$$cur_i = \begin{cases} cur_{i-1} + 1, & i \ge 1 \text{ 且 } \text{nums}[i] \ne \text{nums}[i-1] \\ 1, & i = 0 \text{ 或 } \text{nums}[i] = \text{nums}[i-1] \end{cases}$$

一次扫描即可，无需显式找断点、分段结算，也无需 DP 数组（滚动变量足矣）。两种写法完全等价：段内 $cur_i$ 恰好依次取 $1, 2, \dots, L$，求和正是 $\frac{L(L+1)}{2}$。

### 3.4 示例演算

![示例演算表：cur 依次为 1,2,1,1](images/wc391_q3_walkthrough.svg)

以 $[0,1,1,1]$ 走一遍：$cur$ 依次为 $1, 2, 1, 1$，累加得 $1 + 2 + 1 + 1 = 5$。$i = 1$ 处相邻不同，$cur$ 从 1 接力到 2——以它结尾的两个交替子数组 $[1]$ 与 $[0,1]$ 正是 $cur_1 = 2$；$i = 2, 3$ 处相邻相等，$cur$ 被重置为 1，另起新段。分段视角验证：$[0,1]$ 与两个 $[1]$ 三段，$\frac{2 \times 3}{2} + 1 + 1 = 5$，两种视角一致。

## 4. 算法细节

1. **滚动变量**：只需 `cur` 与 `ans` 两个变量，空间 $O(1)$；不建 DP 数组，避免 $10^5$ 的额外分配。
2. **比较对象是前一个元素**：`nums[i] != nums[i-1]`，二进制下等价于 `nums[i] ^ nums[i-1] == 1`；写成与「段首」比较会在段长 $> 2$ 时出错。
3. **两种实现等价**：显式分段（遇断点结算 $\frac{L(L+1)}{2}$，段长清零重数）与逐位累加 $\sum cur_i$ 结果一致，比赛时写后者更短、更不易错。
4. **返回类型是 64 位**：$n = 10^5$ 全交替时答案 $= \frac{10^5 \times (10^5 + 1)}{2} \approx 5 \times 10^9 > 2^{31} - 1$，C++ 必须用 `long long` 累加与返回（题目接口已定为 `long long`，中途也别用 `int`）。

## 5. 正确性证明

**引理 1（子数组封闭性）**：交替子数组的任意连续子数组仍交替。

**证明**：子数组的相邻对集合是原子数组相邻对集合的子集，而后者全部不相等。∎

**引理 2（右端点计数的显式表达）**：设 $s_i$ 为使 $[s_i..i]$ 交替的最小起点（即以 $i$ 结尾的最长交替子数组），$L_i = i - s_i + 1$。则以 $i$ 结尾的交替子数组恰为 $[s_i..i], [s_i+1..i], \dots, [i..i]$ 这 $L_i$ 个。

**证明**：由引理 1，上述 $L_i$ 个后缀全部交替。反设另有 $[j..i]$（$j < s_i$）交替，则它是比 $[s_i..i]$ 更长的、以 $i$ 结尾的交替子数组，与 $s_i$ 的最小性矛盾。∎

**引理 3（转移方程）**：若 $i \ge 1$ 且 $\text{nums}[i] \ne \text{nums}[i-1]$，则 $L_i = L_{i-1} + 1$；否则 $L_i = 1$。

**证明**：相邻不同时：$[s_{i-1}..i-1]$ 交替且新尾部对不等，故 $[s_{i-1}..i]$ 交替，得 $L_i \ge L_{i-1} + 1$；反之任一交替的 $[j..i]$（$j < i$）去掉末元素后 $[j..i-1]$ 仍交替，故 $j \ge s_{i-1}$，即 $L_i \le L_{i-1} + 1$，两边夹逼得等号。相邻相等（或 $i = 0$）时：任何 $[j..i]$（$j < i$）都包含相邻对 $(i-1, i)$ 且其相等，不交替；仅 $[i..i]$ 合法，故 $L_i = 1$。∎

**定理**：算法返回的 $\sum_{i=0}^{n-1} L_i$ 恰为数组中交替子数组的总数，且等于极大交替段分解下各段 $\frac{L(L+1)}{2}$ 之和。

**证明**：每个交替子数组有唯一右端点，按右端点分类不重不漏；由引理 2，右端点 $i$ 处的贡献恰为 $L_i$；由引理 3，算法逐位求出的正是各 $L_i$，故返回值即总数。对分段视角：极大交替段本身交替，由引理 1 段内全部 $\frac{L(L+1)}{2}$ 个子数组合法；跨段子数组必含刀口处的相等对故不合法；两类合计即总数。又段内 $L_i$ 依次为 $1, 2, \dots, L$，两种表达给出同一个数。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。单趟扫描，每个位置一次比较、一次累加。
- **空间复杂度**：$O(1)$。仅 `cur`、`ans` 两个变量（不计输入数组）。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    long long countAlternatingSubarrays(vector<int>& nums) {
        long long ans = 0, cur = 0;  // cur = 以 i 结尾的交替子数组个数
        for (int i = 0; i < (int)nums.size(); ++i) {
            cur = (i > 0 && nums[i] != nums[i - 1]) ? cur + 1 : 1;
            ans += cur;
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def countAlternatingSubarrays(self, nums: List[int]) -> int:
        ans = cur = 0
        for i, x in enumerate(nums):
            cur = cur + 1 if i > 0 and x != nums[i - 1] else 1
            ans += cur
        return ans
```

## 8. 边界情况与易错点

1. **答案溢出 32 位**：全交替、$n = 10^5$ 时约 $5 \times 10^9$，C++ 用 `long long`；Python 无此问题。这是本题最主流的 WA 原因。
2. **$n = 1$**：答案为 1，循环里 $i = 0$ 分支自然给出 `cur = 1`，无需特判。
3. **全相同元素**：答案为 $n$（只有单元素子数组），「重置为 1」分支覆盖。
4. **别把「子数组」读成「子序列」**：若统计交替**子序列**，问题是完全不同的组合计数（每个长度 $\ge 2$ 的 0/1 交替子序列由选 0/1 的位置决定），套路天差地别。
5. **不要和 2765 最长交替子数组混淆**：那题的「交替」要求相邻差在 $+1 / -1$ 间跳动（如 $[2,3,2,3]$），定义更苛刻；本题只要求相邻不等。
6. **比较写成与段首比较**：$[0,1,0]$ 中 $i = 2$ 处若写成 `nums[i] != nums[段首]` 会误判重置，必须是与**前一个**元素比较。
