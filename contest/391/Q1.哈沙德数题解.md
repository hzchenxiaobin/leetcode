# LeetCode 哈沙德数 题解

## 1. 题目概述

- **标题 / 题号**：哈沙德数（#3099，easy）
- **链接**：https://leetcode.cn/problems/harshad-number/
- **来源**：LeetCode 第 391 场周赛 Q1
- **难度**：简单
- **标签**：数学、模拟

**题意**：给定整数 `x`。记 $s$ 为 `x` 各个数位上的数字之和。若 `x` 能被 $s$ 整除（即 `x` 是**哈沙德数**），返回 $s$；否则返回 `-1`。

**约束**：

- `1 <= x <= 100`

## 2. 示例

**示例 1**

```text
输入：x = 18
输出：9
解释：数位和 s = 1 + 8 = 9，18 % 9 == 0，18 是哈沙德数，返回 9。
```

**示例 2**

```text
输入：x = 23
输出：-1
解释：数位和 s = 2 + 3 = 5，23 % 5 == 3 ≠ 0，23 不是哈沙德数，返回 -1。
```

**示例 3（边界）**

```text
输入：x = 7
输出：7
解释：个位数 s = x = 7，x % x == 0 恒成立，任何个位数都是哈沙德数。
```

## 3. 解题思路

### 3.1 暴力思路

题面本身就是算法流程：**求数位和 → 判断整除**。签到题，直接模拟即可。数据范围 $x \le 100$，最多三位数，任何按定义模拟的做法都是常数时间，不存在"暴力不可行"的问题，重点放在**最短路径**和**边界处理**上。

### 3.2 核心观察：两步模拟 + 两个不变量

![哈沙德数判定流程](images/wc391_q1_harshad_concept.svg)

本题由两个独立的小模块组成：

1. **数位分解**：`t % 10` 取末位，`t /= 10` 前进，循环至 `t == 0`，累加得到 $s$；
2. **整除判定**：`x % s == 0` 则返回 $s$，否则返回 `-1`。

两个保证正确性的不变量：

- **无除零风险**：$x \ge 1$ 的十进制表示中至少有一位非零，故 $s \ge 1$，取模运算安全；
- **个位数全是哈沙德数**：当 $1 \le x \le 9$ 时 $s = x$，$x \bmod x = 0$ 恒成立，答案就是 $x$ 本身。

> 💡 **读题注意**：返回值是**数位和 $s$**（一个正整数），不是布尔值。比赛时读错返回值定义是最常见的罚时来源。

### 3.3 算法流程

1. 另存副本 `t = x`，初始化 `s = 0`；
2. 循环：`s += t % 10`，`t /= 10`，直到 `t == 0`；
3. 判断：若 `x % s == 0` 返回 `s`，否则返回 `-1`。

### 3.4 示例演算：1 ~ 100 的哈沙德数分布

![1到100哈沙德数网格](images/wc391_q1_harshad_grid.svg)

把整个取值范围 $[1, 100]$ 跑一遍，可以直观看到几个规律：

| x | 数位和 s | x mod s | 结果 |
|---|---------|---------|------|
| 7 | 7 | 0 | 7（个位数返回自身） |
| 10 | 1 | 0 | 1 |
| 11 | 2 | 1 | -1 |
| 12 | 3 | 0 | 3 |
| 18 | 9 | 0 | 9 |
| 23 | 5 | 3 | -1 |
| 100 | 1 | 0 | 1（边界：三位数） |

- $1 \sim 9$ 全部命中（$s = x$）；
- **整十数全部命中**：$10a$ 的数位和恰为 $a$（100 的数位和为 1），必被整除；
- $[1, 100]$ 中哈沙德数共 **33** 个。

## 4. 算法细节

1. **数位提取的两种写法**：
   - 算术写法：`while (t) { s += t % 10; t /= 10; }`（C++ 惯用）；
   - 字符串写法：Python 一行 `s = sum(map(int, str(x)))`，签到题追求手速时更快。
2. **保留原始 x**：数位提取会破坏循环变量，必须用副本 `t` 做，最后整除判定还要用原值 `x`。
3. **无溢出**：$x \le 100$ 时 $s \le 9+9+1=19$（100），`int` 绰绰有余；即使推广到 $x \le 10^{18}$，$s \le 162$ 也不会溢出。
4. **返回值语义**：是哈沙德数返回 $s$，不是返回 `true`/下标。

## 5. 正确性证明

**引理 1**：对任意 $x \ge 1$，其数位和 $s \ge 1$。

**证明**：$x \ge 1$ 的十进制表示不含前导零，最高位至少为 1，故至少存在一位非零数字，数位和 $s \ge 1$。∎

**引理 2**：数位提取循环结束后，$s$ 恰为 $x$ 的各位数字之和。

**证明**：设 $x = \sum_{i=0}^{k} d_i \cdot 10^i$（$d_i \in [0,9]$，$d_k \ge 1$）。第 $j$ 轮循环时 $t = \lfloor x / 10^{j} \rfloor$，故 `t % 10` 恰取出 $d_j$。循环执行 $k+1$ 轮后 $t = 0$ 终止，每位数字恰好被累加一次，即 $s = \sum_{i=0}^{k} d_i$。∎

**定理**：算法当且仅当 $s \mid x$ 时返回 $s$，否则返回 `-1`，与哈沙德数定义一致。

**证明**：由引理 2，$s$ 为 $x$ 的数位和；由引理 1，$x \bmod s$ 无除零风险。`x % s == 0` 等价于 $s$ 整除 $x$，即 $x$ 是哈沙德数，此时按题意返回 $s$；否则 $x \bmod s \ge 1$，返回 `-1`。两种分支与定义完全对应。∎

## 6. 复杂度分析

- **时间复杂度**：$O(\log_{10} x)$。数位提取循环次数等于 $x$ 的十进制位数；本题 $x \le 100$ 至多 3 位，实际为常数时间。
- **空间复杂度**：$O(1)$。仅使用常数个整型变量 `t`、`s`。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int sumOfTheDigitsOfHarshadNumber(int x) {
        int s = 0;
        for (int t = x; t > 0; t /= 10) {
            s += t % 10;
        }
        return x % s == 0 ? s : -1;
    }
};
```

### Python

```python
class Solution:
    def sumOfTheDigitsOfHarshadNumber(self, x: int) -> int:
        s = sum(map(int, str(x)))
        return s if x % s == 0 else -1
```

## 8. 边界情况与易错点

1. **个位数 1~9**：$s = x$，必为哈沙德数，返回 $x$ **本身**（例如 `x = 7` 返回 7，不是 1 也不是 `x % s`）。
2. **边界 x = 100**：$s = 1$，任何数都被 1 整除，返回 1；不要以为"数位多就不是"。
3. **除零**：由 $s \ge 1$ 知不可能发生，但如果题目改成 `x` 可以为 0（$s = 0$），就必须特判——比赛时想清楚这一条再动手。
4. **破坏原值**：直接对 `x` 做数位提取后无法再做 `x % s`，务必用副本。
5. **相邻两位数大多不是哈沙德数**（11、13、14、…），手玩样例时不要被 12、18 的"高密度"误导。
6. **返回值定义**：哈沙德数返回数位和，不是 `true`，也不是 `x`。
