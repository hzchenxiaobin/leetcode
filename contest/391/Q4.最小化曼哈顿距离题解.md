# LeetCode 最小化曼哈顿距离 题解

## 1. 题目概述

- **标题 / 题号**：最小化曼哈顿距离（#3102，hard）
- **链接**：https://leetcode.cn/problems/minimize-manhattan-distances/
- **来源**：LeetCode 第 391 场周赛 Q4
- **难度**：困难
- **标签**：几何、数组、数学、有序集合、排序

**题意**：给定平面上 $n$ 个整点 `points[i] = [x_i, y_i]`，两点间距离取**曼哈顿距离** $|x_i - x_j| + |y_i - y_j|$。要求**恰好移除一个点**，使剩余点集中任意两点的**最大距离**（即点集直径）尽可能小，返回该最小值。

**约束**：

- $3 \le points.length \le 10^5$
- $points[i].length == 2$
- $1 \le points[i][0], points[i][1] \le 10^8$

> 💡 读题定位：$n$ 到 $10^5$，两两枚举距离的 $O(n^2)$ 必超时。「删一个点求直径最小值」的问法暗示：先把**点集直径**写成只依赖少数极值的封闭形式，再证明最优删除点只出现在极少数候选中，把「删除」的影响局部化。

## 2. 示例

**示例 1**

```text
输入：points = [[3,10],[5,15],[10,2],[4,4]]
输出：12
解释：移除每个点后的最大距离：
- 移除 (3,10) 后：最大距离在 (5,15)-(10,2)，为 18
- 移除 (5,15) 后：最大距离在 (3,10)-(10,2)，为 15
- 移除 (10,2) 后：最大距离在 (5,15)-(4,4)，为 12 ← 最优
- 移除 (4,4)  后：最大距离在 (5,15)-(10,2)，为 18
```

**示例 2（全部重合）**

```text
输入：points = [[1,1],[1,1],[1,1]]
输出：0
解释：所有点重合，删谁都一样，直径为 0。
```

**示例 3（一点独占两维极值，自造用例）**

```text
输入：points = [[9,1],[1,5],[3,1],[3,3]]
输出：6
解释：u = x+y 依次为 10, 6, 4, 6；v = x−y 依次为 8, −4, 2, 0。
      点 (9,1) 同时是 max u（10）与 max v（8）的达成者，候选只剩 3 个：
- 删 (9,1)：Δu′ = 6−4 = 2，Δv′ = 2−(−4) = 6 → 6 ← 最优
- 删 (3,1)（min u）：Δu′ = 10−6 = 4，Δv′ = 8−(−4) = 12 → 12
- 删 (1,5)（min v）：Δu′ = 10−4 = 6，Δv′ = 8−0 = 8 → 8
```

## 3. 解题思路

### 3.1 暴力思路

枚举删掉第 $i$ 个点，再对剩余 $n-1$ 个点两两枚举曼哈顿距离取最大：$n$ 种删法 $\times$ $O(n^2)$ 求直径 $= O(n^3) \approx 10^{15}$，不可行。即使把「单个点集求直径」优化到 $O(n)$（思路见下），外层还要枚举 $n$ 种删法，总共 $O(n^2) = 10^{10}$，同样超时。

卡壳的根源是**每次删除都从头重算**。要突破，必须先回答两个问题：点集直径到底由哪些点决定？删除一个点时，直径会怎样变化？

### 3.2 核心观察：45° 旋转变换，直径只由 4 个极值决定

![核心观察：45° 旋转变换，曼哈顿距离变切比雪夫距离](images/wc391_q4_rotation_transform.svg)

**观察一：曼哈顿距离可以「去绝对值」。** 对任意实数 $a, b$ 有恒等式

$$|a| + |b| = \max\big(|a+b|,\ |a-b|\big)$$

把每个点变换为 $u_i = x_i + y_i$、$v_i = x_i - y_i$（几何上是把坐标轴旋转 45° 再放缩 $\sqrt{2}$），取 $a = x_i - x_j$、$b = y_i - y_j$，得到

$$d(i, j) = |x_i - x_j| + |y_i - y_j| = \max\big(|u_i - u_j|,\ |v_i - v_j|\big)$$

即**曼哈顿距离（$L_1$）变成切比雪夫距离（$L_\infty$）**——菱形的 $L_1$ 球恰好变成正方形的 $L_\infty$ 球。

**观察二：点集直径只依赖 4 个数。** 切比雪夫距离下，任两点距离 $\le \max(\Delta u, \Delta v)$（$\Delta u = \max u - \min u$，$\Delta v$ 同理），且「$\max u$ 与 $\min u$ 的达成点对」恰好取到 $\Delta u$。于是

$$D(S) = \max_{i \ne j} d(i,j) = \max\big(\Delta u,\ \Delta v\big)$$

**观察三：最优删除点必是极值点。** 删掉一个**非极值点**（$u_i$、$v_i$ 都不顶着四个极值），四个极值全部有别的点保持着，直径**原封不动**；而删掉**任意点**后点对只会变少，直径**单调不增**。两条合起来：若最优解删的是非极值点，直径没变；换成删任何一个极值点都不会更差。因此候选集收缩到

$$C = \{\arg\max u,\ \arg\min u,\ \arg\max v,\ \arg\min v\} \quad (\le 4\ \text{个点})$$

### 3.3 算法流程：top-2 预处理 + 四候选 O(1) 重算

![算法流程：top-2 预处理与四候选枚举](images/wc391_q4_top2_flow.svg)

删掉一个极值点后，新的极值由「**次大 / 次小**」顶上。因此预处理 $u$、$v$ 各自的（最大, 次大）与（最小, 次小）**及对应下标**，共 8 个量；对每个候选 $i \in C$，被删下标命中的极值换用次值、其余不动，即可 $O(1)$ 算出删除后的直径。**并列极值天然正确**：两个点并列最大时次大 = 最大，删掉其中一个，另一个仍把极值顶住。

**完整步骤**：

1. **变换**：$u_i = x_i + y_i$，$v_i = x_i - y_i$；
2. **预处理**：一遍扫描求出 $u$、$v$ 各自的 top-2 最大 / 最小（值 + 下标）；
3. **候选集**：$C = \{i_{\max u},\ i_{\min u},\ i_{\max v},\ i_{\min v}\}$（至多 4 个下标，可能重复）；
4. **枚举**：对每个 $i \in C$，命中的极值下标换用次值，计算 $\max(\Delta u',\ \Delta v')$；
5. **返回**这些值的最小值。

> ⚠️ 别只试「当前最远点对」的两端。当两维极差相等、或一个点同时占据两维极值时，最远点对不止一对；与其纠结「找全所有最远点对」，不如老老实实把 4 个极值候选都试一遍——反正只有 $O(1)$ 个。

### 3.4 示例演算

![示例 1 演算：极值、候选与删点对比](images/wc391_q4_walkthrough.svg)

以示例 1 走一遍：$u = \{13, 20, 12, 8\}$，$v = \{-7, -10, 8, 0\}$，四个极值分别是 $\max u = 20$（点 1）、$\min u = 8$（点 3）、$\max v = 8$（点 2）、$\min v = -10$（点 1）。原始直径 $D = \max(12, 18) = 18$，候选 $C = \{1, 2, 3\}$：

| 删除 | $\Delta u'$ | $\Delta v'$ | $\max$ |
|------|------------|------------|--------|
| $i=2$（max v） | $20 - 8 = 12$ | $-7 - (-10) = 10$ | **12** ✓ |
| $i=1$（max u 且 min v） | $13 - 8 = 5$ | $8 - (-7) = 15$ | 15 |
| $i=3$（min u） | $20 - 12 = 8$ | $8 - (-10) = 18$ | 18 |
| $i=0$（非极值点） | $12$ | $18$ | 18（不试也知道不变） |

答案 $= \min(12, 15, 18) = \boxed{12}$——删 $(10,2)$ 后最远点对变为 $(5,15)$ 与 $(4,4)$，与官方解释一致。注意点 1 一个点占住两个极值，删它时 $\max u$、$\min v$ **同时**换次值。

## 4. 算法细节

1. **变换方向**：$(u, v) = (x+y,\ x-y)$ 与 $(x-y,\ x+y)$ 完全对称，任选其一即可，但两维别混用（$u$ 用 $x+y$、$v$ 也用 $x+y$ 会直接全错）。
2. **top-2 的并列处理**：更新最大时用严格大于 `a[i] > m1`，并列元素落入次值分支 `else if (a[i] > m2)`，保证**并列最值时次值 = 最值**。若写成跳过相等元素，删掉一个并列点后会把极差误算成缩小。
3. **命中判断按下标**：`i == iMxU` 才换次值。按「值相等」判断在并列时行为依赖次值恰好等于最值这一事实，一改动 tie 处理就连环出错，不推荐。
4. **候选可重复**：一个点占多个极值（示例 3 的 $(9,1)$、示例 1 的点 1）时候选自然去重，4 次循环重复计算同一个候选也无害，无需显式去重。
5. **次值的存在性**：$n \ge 3$ 保证删除后至少剩 2 个点，次大 / 次小总有定义；top-2 扫描时 `m2` 在第一轮就被赋成真实元素值。
6. **替代实现（官方标签里的「有序集合」）**：把 $u$、$v$ 各放进 `multiset`，枚举候选时 `erase(find(key))` 后查询首尾，$O(n \log n)$。top-2 做法 $O(n)$、代码更短，比赛首选。注意 `multiset::erase(key)` 会删掉**所有**等值元素，必须先 `find` 再迭代器删除。
7. **值域与溢出**：$1 \le x, y \le 10^8$ 时 $u \in [2, 2 \times 10^8]$、$v \in [-10^8 + 1, 10^8 - 1]$，极差 $\le 2 \times 10^8 < 2^{31} - 1$，`int` 足够；但若坐标上界放大到 $10^9$ 就必须换 `long long`——变换题的通用习惯是变换后直接上 64 位图安心。

## 5. 正确性证明

**引理 1（符号恒等式）**：对任意实数 $a, b$，$|a| + |b| = \max(|a+b|,\ |a-b|)$。

**证明**：若 $ab \ge 0$，则 $|a| + |b| = |a+b| \ge |a-b|$；若 $ab < 0$，则 $|a| + |b| = |a-b| \ge |a+b|$。两种情形都取到 $\max$。∎

**引理 2（距离变换）**：对任意两点 $p, q$，$d(p, q) = \max(|u_p - u_q|,\ |v_p - v_q|)$。

**证明**：取 $a = x_p - x_q$、$b = y_p - y_q$，则 $a + b = u_p - u_q$、$a - b = v_p - v_q$，代入引理 1 即得。∎

**引理 3（直径的极值表达）**：$\max_{p \ne q \in S} d(p, q) = \max(\Delta u, \Delta v)$，其中 $\Delta u = \max_S u - \min_S u$，$\Delta v$ 同理。

**证明**：「≥」：取 $p$ 为 $\max u$ 的任一达成点、$q$ 为 $\min u$ 的任一达成点（若 $\Delta u = 0$ 则该侧平凡），$d(p, q) \ge |u_p - u_q| = \Delta u$；$v$ 维同理。「≤」：对任意 $p, q$，由引理 2，$d(p, q) = \max(|u_p - u_q|, |v_p - v_q|) \le \max(\Delta u, \Delta v)$。两边合即得等式。∎

**引理 4（删除的单调性）**：对任意点 $i$，$D(S \setminus \{i\}) \le D(S)$。

**证明**：$S \setminus \{i\}$ 的点对集合是 $S$ 的真子集，对子集取最大不超过对全集取最大；由引理 3 两边都是「两两距离的最大值」。∎

**定理（四候选充分性）**：设 $i_{\max u}, i_{\min u}, i_{\max v}, i_{\min v}$ 为四个极值的任一达成下标（代码取首个），$C$ 为它们组成的集合，则

$$\min_{i \in C} D(S \setminus \{i\}) = \min_{\text{所有}\ i} D(S \setminus \{i\})$$

**证明**：记 $A = \min_i D(S \setminus \{i\})$（最优答案），$D = D(S)$。分两种情况。

（1）$A = D$：由引理 4，任意删除（含 $C$ 中候选）都满足 $D(S \setminus \{i\}) \le D = A$；又 $A$ 是所有删除结果的最小值，必有 $D(S \setminus \{i\}) \ge A$。故每个删除结果都恰为 $A$，等式成立。

（2）$A < D$：取最优删除 $i^*$，$D(S \setminus \{i^*\}) = A < D$。由引理 3，删除后 $\max(\Delta u', \Delta v') < \max(\Delta u, \Delta v)$，故 $\Delta u' < \Delta u$ 或 $\Delta v' < \Delta v$（否则 max 不减）。不妨设 $\Delta u' < \Delta u$，即 $\max u$ 严格下降或 $\min u$ 严格上升。若 $\max u$ 下降，说明 $i^*$ 顶着 $\max u$，**且是唯一达成者**（若另有并列点存活则极值不变）。「唯一达成者」意味着代码取的首个达成下标 $i_{\max u} = i^*$，即 $i^* \in C$。$\min u$ 上升、以及 $v$ 维的情形完全对称。于是最优删除点落在 $C$ 中，等式成立。∎

**推论（重算的正确性）**：对候选 $i$，top-2 换值法算出的恰是 $D(S \setminus \{i\})$。

**证明**：$S \setminus \{i\}$ 上的 $\max u$ 等于：$i = i_{\max u}$ 时「除 $i$ 外的最大值」即次大 $m_2$，否则 $i_{\max u}$ 仍存活，$\max u$ 不变即 $m_1$。其余三个极值逐一同理，四个判断相互独立，一个点占多个极值时逐条命中。由引理 3，用新极值算出的 $\max(\Delta u', \Delta v')$ 即删除后直径。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。变换一遍扫描；top-2 预处理对 $u$、$v$ 各做两趟（或合并成一趟）线性扫描；候选至多 4 个，每个 $O(1)$ 重算。
- **空间复杂度**：$O(n)$。存放 $u$、$v$ 两个数组（若直接在循环里即时计算并维护 top-2，可降到 $O(1)$，但可读性变差，没必要）。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int minimumDistance(vector<vector<int>>& points) {
        int n = points.size();
        vector<int> u(n), v(n);
        for (int i = 0; i < n; ++i) {
            u[i] = points[i][0] + points[i][1];
            v[i] = points[i][0] - points[i][1];
        }
        // 求（最值, 首个达成下标, 次值）；n >= 3 保证次值存在
        auto top2 = [](const vector<int>& a, bool wantMax) {
            int m1 = wantMax ? INT_MIN : INT_MAX, m2 = m1, i1 = -1;
            for (int i = 0; i < (int)a.size(); ++i) {
                if ((wantMax && a[i] > m1) || (!wantMax && a[i] < m1)) {
                    m2 = m1; m1 = a[i]; i1 = i;
                } else if ((wantMax && a[i] > m2) || (!wantMax && a[i] < m2)) {
                    m2 = a[i];  // 并列最值落在这里：m2 == m1
                }
            }
            return make_tuple(m1, i1, m2);
        };
        auto [mxU, iMxU, mxU2] = top2(u, true);
        auto [mnU, iMnU, mnU2] = top2(u, false);
        auto [mxV, iMxV, mxV2] = top2(v, true);
        auto [mnV, iMnV, mnV2] = top2(v, false);

        int ans = INT_MAX;
        for (int i : {iMxU, iMnU, iMxV, iMnV}) {  // 至多 4 个候选
            int hiU = (i == iMxU) ? mxU2 : mxU;    // 下标命中 → 换次值
            int loU = (i == iMnU) ? mnU2 : mnU;
            int hiV = (i == iMxV) ? mxV2 : mxV;
            int loV = (i == iMnV) ? mnV2 : mnV;
            ans = min(ans, max(hiU - loU, hiV - loV));
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def minimumDistance(self, points: List[List[int]]) -> int:
        n = len(points)
        u = [x + y for x, y in points]
        v = [x - y for x, y in points]

        def top2(a, want_max):
            m1 = m2 = float('-inf') if want_max else float('inf')
            i1 = -1
            for i, x in enumerate(a):
                if (x > m1) if want_max else (x < m1):
                    m1, m2, i1 = x, m1, i
                elif (x > m2) if want_max else (x < m2):
                    m2 = x  # 并列最值落在这里：m2 == m1
            return m1, i1, m2

        mxU, iMxU, mxU2 = top2(u, True)
        mnU, iMnU, mnU2 = top2(u, False)
        mxV, iMxV, mxV2 = top2(v, True)
        mnV, iMnV, mnV2 = top2(v, False)

        ans = float('inf')
        for i in (iMxU, iMnU, iMxV, iMnV):  # 至多 4 个候选
            hiU = mxU2 if i == iMxU else mxU
            loU = mnU2 if i == iMnU else mnU
            hiV = mxV2 if i == iMxV else mxV
            loV = mnV2 if i == iMnV else mnV
            ans = min(ans, max(hiU - loU, hiV - loV))
        return ans
```

## 8. 边界情况与易错点

1. **并列极值**：top-2 更新必须让并列元素进入次值分支（次值 = 最值）。若按「相等则跳过」处理，删掉一个并列极值点后会把极差误算成缩小，是本题最隐蔽的 WA 点。
2. **一点占两维极值**：示例 1 的点 1 同时是 $\max u$ 与 $\min v$，删除时**两处同时换次值**。四个命中判断必须相互独立、逐条执行，不能命中一个就 `continue`。
3. **候选集大小不固定**：去重后可能只有 1~4 个候选（全部点重合时 4 个极值可能由同一点达成），别假设恰好 4 个。
4. **溢出**：$x, y \le 10^8$ 时 $u \le 2 \times 10^8 < 2^{31} - 1$，`int` 安全；坐标上界放大到 $10^9$ 则 $u$ 达 $2 \times 10^9$ 溢出，需换 64 位。
5. **$n = 3$**：删一个剩两个，答案即剩下两点的距离；算法自然覆盖（次值来自幸存点），无需特判。
6. **全部点重合**：$\Delta u = \Delta v = 0$，答案 0，算法自然覆盖。
7. **「删非极值点直径不变」**：这一性质可当对拍断言——任删一个非候选点，检查答案是否恰好等于原始直径 $D$，能快速暴露 top-2 或命中判断的 bug。
8. **别用 `multiset::erase(key)`**：有序集合实现里它会删掉全部等值元素，必须 `erase(find(key))` 只删一个。
