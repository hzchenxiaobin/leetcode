# LeetCode 统计强大整数的数目 题解

## 1. 题目概述

- **标题 / 题号**：统计强大整数的数目（#2999，hard）
- **链接**：https://leetcode.cn/problems/count-the-number-of-powerful-integers/
- **来源**：LeetCode 第 121 场双周赛 Q4
- **难度**：困难
- **标签**：数学、字符串、动态规划（数位 DP）

**题意**：给定整数 `start`、`finish`、`limit` 和一个表示正整数的字符串 `s`。若正整数 $x$ 同时满足：

1. `s` 是 $x$ 十进制表示的**后缀**；
2. $x$ 的**每一个数位**都不超过 `limit`；

则称 $x$ 是**强大整数**。求区间 $[\textit{start}, \textit{finish}]$ 内强大整数的个数。

**约束**：

- $1 \le \textit{start} \le \textit{finish} \le 10^{15}$
- $1 \le \textit{limit} \le 9$
- $1 \le |s| \le \lfloor \log_{10} \textit{finish} \rfloor + 1$
- `s` 中每个数位都 $\le \textit{limit}$，且 `s` 不含前导 $0$

## 2. 示例

**示例 1**

```text
输入：start = 1, finish = 6000, limit = 4, s = "124"
输出：5
解释：区间内的强大整数为 124、1124、2124、3124、4124。
      5124 的首位 5 > limit = 4，不合格。
```

**示例 2**

```text
输入：start = 15, finish = 215, limit = 6, s = "10"
输出：2
解释：110 与 210。注意 10 本身也以 "10" 结尾，但它小于 start = 15。
```

**示例 3**

```text
输入：start = 1000, finish = 2000, limit = 4, s = "3000"
输出：0
解释：区间内所有数都 ≤ 2000 < 3000，而 4 位数若以 "3000" 结尾只能等于 3000，故一个都没有。
```

## 3. 解题思路

### 3.1 暴力思路

区间上界 $10^{15}$，逐个数检查后缀与数位显然不可行。即便「只枚举合法数位组合」也可能爆炸：$\textit{limit} = 9$ 时 $10^{16}$ 种组合。

唯一可行的方向是**按位计数**：把「数」拆成「可以自由选择的部分」与「被题目钉死的部分」，用乘法原理一次性算出数量。这也正是数位 DP 的闭式写法——由于本题约束（后缀固定、每位独立）非常规整，不需要真的写记忆化搜索，可以直接算出答案。

### 3.2 核心观察：自由前缀 + 固定后缀

![强大整数的结构：自由前缀 + 固定后缀 s](images/bw121_q4_structure.svg)

设 $m = |s|$，$x$ 的十进制表示共 $L$ 位，则 $L \ge m$，且 $x$ 唯一地写成

$$x = \underbrace{\overline{p_0 p_1 \cdots p_{L-m-1}}}_{\text{自由前缀，} p = L - m \text{ 位}} \;\Big\|\; \underbrace{s}_{\text{固定 }} .$$

约束翻译成对前缀的要求：

- $p = 0$ 时，$x$ 就是 $s$ 本身，只有一个候选；
- $p \ge 1$ 时，首位 $p_0 \in [1, \textit{limit}]$（**不能为 $0$**，否则总位数缩水，会与更短的 $L$ 重复计数），其余 $p - 1$ 位各自独立地取 $[0, \textit{limit}]$。

于是「给定 $L$，记 $f(L)$ 为所有 $L$ 位强大整数的个数」，有闭式

$$
f(L) =
\begin{cases}
1, & L = m,\\[2pt]
\textit{limit}\cdot(\textit{limit}+1)^{\,L-m-1}, & L > m.
\end{cases}
$$

再把麻烦的「区间」用**差分**化掉：记 $C(N)$ 为 $[1, N]$ 内强大整数的个数，则

$$\text{答案} = C(\textit{finish}) - C(\textit{start} - 1).$$

剩下唯一有技术含量的部分是 $C(N)$：位数 $L < \operatorname{len}(N)$ 的部分可以直接用 $f(L)$ 求和（这些数必然 $\le N$），只有 $L = \operatorname{len}(N)$ 的那一批需要**卡上界**。

### 3.3 算法流程：等位数时按「第一个不同的前缀位」分类

![等位数时按第一个不同的前缀位分类](images/bw121_q4_digit_dp.svg)

设 $N$ 的十进制串为 $t$，长度 $nd$，$p = nd - m$。

- **$p = 0$**（$nd = m$）：唯一的候选就是 $s$ 本身，判断字符串 $s \le t$ 即可（等长，字典序即数值序）。
- **$p \ge 1$**：枚举候选前缀 $P$ 与 $t$ 的**第一个不同位置** $i \in [0, p-1]$。在 $i$ 之前 $P$ 与 $t$ 完全相同，在 $i$ 处 $P[i] < t[i]$，于是后面 $p-1-i$ 位可以任意取。位置 $i$ 能取的数字个数为

$$c_i = \Big|[\,\textit{lo}_i,\ \min(\textit{limit},\ t_i - 1)\,]\Big|, \qquad \textit{lo}_i = \begin{cases} 1, & i = 0\\ 0, & i > 0\end{cases}$$

贡献 $c_i \cdot (\textit{limit}+1)^{p-1-i}$。累加时若发现 $t_i$ 本身不在 $[\textit{lo}_i, \textit{limit}]$ 内，说明「前缀与 $t$ 完全相同」这一支已经不可能延续，直接返回已累计值。

最后补上**前缀与 $t$ 完全相同**的那一支：此时 $x \le N \iff s \le t[p:]$（两者等长 $m$，直接比较字符串）。

### 3.4 示例演算

![示例 1 演算：位数 3 只有 124，位数 4 有 4 个合法前缀](images/bw121_q4_walkthrough.svg)

以示例 1（$[\textit{start}, \textit{finish}] = [1, 6000]$，$\textit{limit} = 4$，$s = \texttt{"124"}$）为例，$nd = 4$，$m = 3$。

**位数 $L = 3$**：$p = 0$，只有 $s = 124$ 一个，贡献 $1$。

**位数 $L = 4$**：$p = 1$，自由前缀只有 1 位。与 $t = \texttt{"6000"}$ 比较：

- $i = 0$ 处，$c_0 = |[1, \min(4, 6-1)]| = |[1,4]| = 4$，贡献 $4 \times (\textit{limit}+1)^0 = 4$，对应前缀 $1,2,3,4$；
- 检查 $t_0 = 6 \notin [1, 4]$ → 截断，「前缀与 $t$ 相同」这一支不存在。

合计 $1 + 4 = 5$，与输出一致。若 $\textit{finish}$ 更大（比如 $9000$），$c_0 = 4$ 不变但 $t_0 = 9 > 4$ 依然截断，答案还是 5——因为 5124 这类数的首位已经超过 `limit`。

再看示例 3（$s = \texttt{"3000"}$，$N = 2000$）：$nd = m = 4$，$p = 0$，比较 $\texttt{"3000"} \le \texttt{"2000"}$ 为假 → $C(2000) = 0$；而 $C(999) = 0$（$999$ 只有 3 位，放不下 4 位后缀），故答案为 $0$。

## 4. 算法细节

1. **按位数分段求和**：$L$ 从 $m$ 到 $nd-1$ 全部可用闭式 $f(L)$；注意 $L = m$ 时 $p = 0$（没有自由前缀），此时不能套乘法式，直接记 $1$ 即可。
2. **首位下界 `lo` 的区分**：$i = 0$ 时下界是 $1$，其余位置是 $0$。这是防止重复计数与前导零的关键。
3. **上界截断**：若 $t_i > \textit{limit}$，则该位取不到 $t_i$，「与 $N$ 前缀相同」的分支立即失效，此时必须 `return`（继续累加后面各位只会重复计数）。
4. **字符串比较代替数值比较**：`s <= t.substr(p)` 中两边长度都是 $m$，字典序与数值序一致；这样既避免了 `stoll` 的溢出隐患，也省去了补零对齐。
5. **幂次计算**：$\textit{limit} + 1 \le 10$，指数 $p - 1 \le 15$，用循环乘的整数幂即可；结果 $\le 10^{15}$ 落在 `long long` 内。若把指数写成浮点 `pow`，在 $\ge 2^{53}$ 附近会丢精度。
6. **差分边界**：`start = 1` 时 $C(0)$ 必须返回 $0$（函数入口 `n <= 0` 直接返回）。
7. **位数不匹配**：$nd < m$ 时直接返回 $0$（$N$ 太短，放不下后缀 $s$）。
8. **一般数位 DP 的对照**：写成记忆化搜索时状态是 `(pos, tight, started)`，本题因为「后缀固定」等价于「前 $p$ 位自由、后 $m$ 位锁定」，`started` 与 `tight` 的相互作用被消解成上面的闭式。

## 5. 正确性证明

**引理 1（表示唯一）**：以 $s$ 结尾、位数为 $L \ge m$ 的正整数 $x$，与「长度 $p = L - m$ 的前缀串 $P$」一一对应。在此对应下：$x$ 的每个数位都 $\le \textit{limit}$ 当且仅当 $P$ 的每个数位都 $\le \textit{limit}$（$s$ 的每位都 $\le \textit{limit}$ 由题面保证）；且 $P$ 非空时必有 $P_0 \ne 0$。

**证明**：$x$ 的十进制串是 $P$ 与 $s$ 的拼接，给定 $x$ 则前 $L - m$ 位唯一确定 $P$；给定 $P$ 则拼接结果唯一确定 $x$。数位约束逐位对应；$x$ 有 $L$ 位当且仅当 $P$ 为空或首位非 $0$。∎

**引理 2（$f(L)$ 的闭式正确）**：对 $L \ge m$，$L$ 位强大整数的个数为 $f(L)$，其中 $f(m) = 1$，$f(L) = \textit{limit}\cdot(\textit{limit}+1)^{L-m-1}$（$L > m$）。

**证明**：由引理 1，$P$ 为空时唯一解为 $s$，故 $f(m) = 1$。$P$ 非空时，$P_0$ 可取 $1, \dots, \textit{limit}$ 共 $\textit{limit}$ 种，其余 $L - m - 1$ 位各可取 $0, \dots, \textit{limit}$ 共 $\textit{limit}+1$ 种，各位独立，由乘法原理得 $f(L) = \textit{limit}\cdot(\textit{limit}+1)^{L-m-1}$。∎

**引理 3（短位数部分无需卡界）**：若 $L < \operatorname{len}(N)$，则所有 $L$ 位数都 $\le N$。

**证明**：$L$ 位数 $< 10^{L} \le 10^{nd-1} \le N$（$N$ 是 $nd$ 位数，故 $N \ge 10^{nd-1}$）。∎

**引理 4（等位数部分的分类不重不漏）**：设 $p = nd - m \ge 1$，则 $[1, N]$ 中 $nd$ 位的强大整数个数等于

$$\sum_{i=0}^{p-1} c_i \cdot (\textit{limit}+1)^{p-1-i} \;+\; [\,P^* \text{ 合法且 } s \le t[p:]\,],$$

其中 $P^* = t[0..p-1]$，且在某个 $t_i \notin [\textit{lo}_i, \textit{limit}]$ 时求和提前终止。

**证明**：设 $x$ 是 $nd$ 位强大整数，对应前缀 $P$。

- 若 $P \ne P^*$，令 $i$ 为 $P$ 与 $t$ 的第一个不同位置。由于两者在 $i$ 之前完全相同且同为 $p$ 位，$x \le N \iff P[i] < t[i]$（更靠前的位相同，比较落在第 $i$ 位）。对固定 $i$，合法的 $P[i]$ 取值为 $[\textit{lo}_i, \min(\textit{limit}, t_i - 1)]$，共 $c_i$ 个；$P$ 剩下 $p-1-i$ 位各自独立地取 $[0, \textit{limit}]$，共 $(\textit{limit}+1)^{p-1-i}$ 种。不同的 $i$ 对应互不相交的 $P$ 集合（第一个不同位置唯一），故不重不漏。
- 若 $P = P^*$，则 $x \le N$ 归结为比较后缀，即 $s \le t[p:]$（等长，字典序 $=$ 数值序）；同时 $P^*$ 本身要合法（每位在范围内、首位非 $0$）。若某位 $t_i$ 越界，则 $P^*$ 不合法，该支贡献为 $0$，且后续位置无需再考虑（前缀已不可能与 $t$ 相同）。∎

**定理**：`numberOfPowerfulInt` 返回 $[\textit{start}, \textit{finish}]$ 内强大整数的个数。

**证明**：由引理 3、4，$C(N)$ 精确统计 $[1, N]$ 内的强大整数个数。$C(\textit{finish}) - C(\textit{start}-1)$ 统计的是 $\{1, \dots, \textit{finish}\} \setminus \{1, \dots, \textit{start}-1\} = [\textit{start}, \textit{finish}]$ 内的个数，正是所求。∎

## 6. 复杂度分析

- **时间**：$O(D^2)$，其中 $D = \operatorname{len}(\textit{finish}) \le 16$。外层对 $L$ 求和 $O(D)$ 次、每次一次幂运算 $O(D)$；等位数部分 $O(D)$ 个位置、每个位置一次幂运算 $O(D)$。实际运算量在千次量级，可视为常数。
- **空间**：$O(D)$，只存 $N$ 的十进制串与 $s$，无 DP 表。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long numberOfPowerfulInt(long long start, long long finish, int limit, string s) {
        return countUpTo(finish, limit, s) - countUpTo(start - 1, limit, s);
    }
private:
    long long ipow(long long b, int e) {
        long long r = 1;
        while (e-- > 0) r *= b;
        return r;
    }
    // 统计 [1, n] 内强大整数的个数
    long long countUpTo(long long n, int limit, const string& s) {
        if (n <= 0) return 0;
        string t = to_string(n);
        int nd = (int)t.size(), m = (int)s.size();
        if (nd < m) return 0;                       // 位数都不够放下后缀 s
        long long total = 0;
        // 1) 位数 L 严格小于 nd：前缀各位完全自由
        for (int L = m; L < nd; ++L) {
            int p = L - m;
            if (p == 0) total += 1;                 // 只有 s 本身
            else total += (long long)limit * ipow(limit + 1, p - 1);
        }
        // 2) 位数恰好为 nd：按与 n 的第一个不同位分类
        int p = nd - m;
        if (p == 0) {
            if (s <= t) total += 1;
        } else {
            for (int i = 0; i < p; ++i) {
                int lo = (i == 0 ? 1 : 0), hi = limit, cur = t[i] - '0';
                long long c = min(hi, cur - 1) - lo + 1;   // 该位取严格更小的合法数字个数
                if (c > 0) total += c * ipow(limit + 1, p - 1 - i);
                if (cur < lo || cur > hi) return total;    // 与 n 前缀相同已不可能
            }
            if (s <= t.substr(p)) total += 1;              // 前缀与 n 完全一致，比后缀
        }
        return total;
    }
};
```

### Python

```python
class Solution:
    def numberOfPowerfulInt(self, start: int, finish: int, limit: int, s: str) -> int:
        # 统计 [1, n] 内强大整数的个数
        def count_up_to(n: int) -> int:
            if n <= 0:
                return 0
            t = str(n)
            nd, m = len(t), len(s)
            if nd < m:                             # 位数都放不下后缀 s
                return 0
            total = 0
            # 1) 位数 L 严格小于 nd：前缀各位完全自由
            for L in range(m, nd):
                p = L - m
                if p == 0:
                    total += 1                     # 只有 s 本身
                else:
                    total += limit * (limit + 1) ** (p - 1)
            # 2) 位数恰好为 nd：按「第一个不同的前缀位」分类
            p = nd - m
            if p == 0:
                if s <= t:                         # 同长度，字典序即数值序
                    total += 1
            else:
                for i in range(p):
                    lo = 1 if i == 0 else 0        # 首位不能为 0
                    hi = limit
                    cur = int(t[i])
                    c = min(hi, cur - 1) - lo + 1  # 该位取严格更小的合法数字个数
                    if c > 0:
                        total += c * (limit + 1) ** (p - 1 - i)
                    if cur < lo or cur > hi:       # 与 n 前缀相同已不可能
                        return total
                if s <= t[p:]:                     # 前缀与 n 完全一致，比后缀
                    total += 1
            return total

        return count_up_to(finish) - count_up_to(start - 1)
```

> 💡 两份代码均通过官方示例（`5`、`2`、`0`），并与两种独立暴力对拍：一是直接枚举区间逐个检查（3000 组随机用例，上界 $3\times10^4$）；二是**生成式**暴力（递归枚举所有位数 $\le 9$、数位 $\le \textit{limit}$ 的数，再判断后缀与区间，30 组随机用例，上界 $10^8$）。另验证了 $[\textit{start}, \textit{finish}] = [1, 10^{15}]$、$s = \texttt{"1"}$ 时答案为 $10^{14}$ 这一闭式结论。

## 8. 边界情况与易错点

1. **`start = 1`**：`countUpTo(0)` 必须返回 $0$，否则会把 $1$ 之前的数算进去。
2. **后缀比 $N$ 还长**：$|s| > \operatorname{len}(N)$ 时直接返回 $0$（示例 3 中若 $\textit{finish}$ 只有 3 位就属于这种情形）。
3. **$|s| = \operatorname{len}(N)$ 且 $s > N$**：$p = 0$ 分支要用字符串比较得出 $0$（示例 3 正是如此）。
4. **`limit` 限制的是每一位，不是整个数**：示例 1 里 5124 的数值远小于 `limit = 4` 之外的任何界，但首位 5 超限就非法。不要把「每位 $\le$ limit」误实现成「数值 $\le$ limit」。
5. **前导零**：$s$ 无前导零（题面保证），但**前缀首位**也不能取 $0$。若把 $p \ge 1$ 的首位下界写成 $0$，同一个数会被更短的位数分支重复计数。
6. **截断时机**：一旦某位 $t_i > \textit{limit}$，必须立刻 `return total`，不能继续循环——后面的位虽然还有「更小数字」可选，但那些组合对应的前缀在第 $i$ 位上已经与 $t$ 不同，重复计入会翻倍。
7. **等长字符串比较**：`s <= t[p:]` 两侧长度必须都是 $m$；若用 `stoll` 转数值，在 $10^{15}$ 附近的串虽然放得下，但一旦约束放宽到 $10^{18}$ 就会溢出，字符串比较更稳。
8. **幂运算的精度**：用整数幂（循环乘或 `**`），不要用 `pow` 的浮点版本；$(\textit{limit}+1)^{15}$ 已达 $10^{15}$ 量级，浮点会丢精度。
9. **返回值类型**：答案最大 $10^{15}$，`long long` / Python `int` 都安全；但中间量 $c_i \times (\textit{limit}+1)^{p-1-i}$ 必须用 `long long` 累加（C++ 中若写成 `int` 会溢出）。
10. **$m = 1$ 的退化**：$s$ 只有 1 位时，$L = m$ 分支就是 $s$ 本身（可能 $\le \textit{limit}$ 也可能不），$L > m$ 分支的通式照常工作。
