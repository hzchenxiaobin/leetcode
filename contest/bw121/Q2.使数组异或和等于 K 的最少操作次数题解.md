# LeetCode 使数组异或和等于 K 的最少操作次数 题解

## 1. 题目概述

- **标题 / 题号**：使数组异或和等于 K 的最少操作次数（#2997，medium）
- **链接**：https://leetcode.cn/problems/minimum-number-of-operations-to-make-array-xor-equal-to-k/
- **来源**：LeetCode 第 121 场双周赛 Q2
- **难度**：中等
- **标签**：位运算、数组

**题意**：每次操作可以任选数组中的一个元素，把它二进制表示的**某一位取反**（$0 \to 1$ 或 $1 \to 0$，**前导 0 也允许翻转**，例如 $(101)_2$ 翻第 4 位得到 $(1101)_2$）。求使整个数组的按位异或和等于 $k$ 所需的**最少操作次数**。

**约束**：

- $1 \le \textit{nums.length} \le 10^5$
- $0 \le \textit{nums}[i] \le 10^6$
- $0 \le k \le 10^6$

## 2. 示例

**示例 1**

```text
输入：nums = [2,1,3,4], k = 1
输出：2
解释：先翻转下标 2 的元素 3 = (011)₂ 的第 0 位 → (010)₂ = 2，数组变为 [2,1,2,4]；
      再翻转下标 0 的元素 2 = (010)₂ 的第 2 位 → (110)₂ = 6，数组变为 [6,1,2,4]；
      6 XOR 1 XOR 2 XOR 4 = 1 = k。少于 2 次做不到。
```

**示例 2**

```text
输入：nums = [2,0,2,0], k = 0
输出：0
解释：2 XOR 0 XOR 2 XOR 0 = 0 = k，已经是目标，无需操作。
```

**示例 3（补充）**

```text
输入：nums = [10], k = 3
输出：2
解释：10 = (1010)₂，k = (0011)₂，差异位是第 0 位与第 3 位，
      翻转这两位即得 10 → (0011)₂ = 3，共 2 次。
```

## 3. 解题思路

### 3.1 暴力思路

「操作任意次、求最少次数」天然让人想搜索状态空间，但每个元素有 20 个可翻的位、数组长度 $10^5$，状态数是指数级的，完全不可行。退一步想：每次操作对**整体异或和**的影响其实极其有限，抓住这一点就能直接算出闭式答案。

### 3.2 核心观察：每一位互相独立，代价只能是 0 或 1

![逐位分析：整体异或和的第 b 位等于所有元素第 b 位的奇偶性](images/bw121_q2_bit_model.svg)

先把「一次操作」对答案的影响写清楚。设 $X = \textit{nums}[0] \oplus \cdots \oplus \textit{nums}[n-1]$ 为当前的整体异或和，其二进制第 $b$ 位为

$$X_b = \bigoplus_{i} \textit{nums}[i]_b ,$$

即**所有元素第 $b$ 位的异或**（也就是这些位里 $1$ 的个数的奇偶性）。翻转某个元素的第 $b$ 位，只是把这一个加数取反，于是

$$X_b \leftarrow X_b \oplus 1, \qquad X_{b'} \leftarrow X_{b'}\ (b' \ne b).$$

也就是说：**一次操作恰好把整体异或和的某一位取反，且只影响那一位**。

于是问题拆成若干互不干扰的独立子问题。记目标差值

$$d = X \oplus k .$$

- 若 $d$ 的第 $b$ 位为 $0$，说明 $X_b = k_b$，第 $b$ 位已经被「配平」，不需要再动它（动两次等于没动，纯属浪费）。
- 若 $d$ 的第 $b$ 位为 $1$，说明 $X_b \ne k_b$，第 $b$ 位必须被翻转**奇数次**，至少 $1$ 次。

因此第 $b$ 位的代价必然落在 $\{0, 1\}$ 里：不匹配就要付 $1$，匹配就付 $0$。又因为题面允许翻**前导 0**（任何元素的任意高位都能翻），每个不匹配位都真的能只花 $1$ 次搞定——不存在「某位没有 1 可以翻」的阻碍。

$$ \text{答案} = \sum_{b} [\,d_b = 1\,] = \operatorname{popcount}(X \oplus k). $$

> 💡 注意这里**不需要**「$1$ 的个数与 $0$ 的个数取较小者」之类的额外权衡：一次操作只能翻转一位，翻转奇数次才改变奇偶性，所以一个不匹配位的下界就是 $1$，而 $1$ 次即可达，取不到更小。

### 3.3 算法流程

![两步走：先求整体异或和，再数它与 k 的不同位](images/bw121_q2_xor_flow.svg)

```text
1. X = 0
   for v in nums: X ^= v
2. d = X ^ k
3. 返回 popcount(d)        # d 的二进制中 1 的个数
```

整个算法只扫一遍数组，没有任何搜索。

### 3.4 示例演算

![示例 1 演算：整体异或和为 4，与 k = 1 相差两位](images/bw121_q2_walkthrough.svg)

以示例 1（`nums = [2,1,3,4]`，`k = 1`）为例：

| 步骤 | 计算 | 结果 |
|------|------|------|
| 求整体异或和 | $010_2 \oplus 001_2 \oplus 011_2 \oplus 100_2$ | $X = 100_2 = 4$ |
| 求差值 | $d = X \oplus k = 100_2 \oplus 001_2$ | $101_2$ |
| 数不同的位 | 第 2 位、第 0 位为 1 | $\operatorname{popcount}(101_2) = 2$ |

与逐位分析对照：第 2 位（$4$ 的 $1$ 位）和第 0 位（$1$ 的 $1$ 位）必须各翻一次，其余位不动，恰好 $2$ 次。题面给出的两次操作正是「翻第 0 位」和「翻第 2 位」的一种具体落法。

## 4. 算法细节

1. **位宽**：$\textit{nums}[i], k \le 10^6 < 2^{20}$，故 $X$ 与 $d$ 都在 $[0, 2^{20})$ 内，`int` 足够；`popcount` 只需统计低 20 位，用 32 位版本即可。
2. **`popcount` 的写法**：C++ 用 `__builtin_popcount(x ^ k)`，Python 用 `bin(x ^ k).count("1")`（或 `int.bit_count()`，Python 3.10+）。两者都是常数时间。
3. **不需要真的选元素**：构造时总可以「挑任意一个元素翻这一位」——同一位在一个元素上翻一次即可，不同位之间互不干扰，因此永远不会出现冲突。
4. **前导 0 的意义**：若不允许翻前导 0，当某位在所有元素里都是 $0$ 而又需要它变成 $1$ 时就会无解。题面明确允许，这条约束保证了「答案 = 不同位个数」始终可达。
5. **不要用「$1$ 的个数 vs $0$ 的个数取小」**：那是「把某一位全部统一」这类题的思路。本题操作数按「谁需要被翻」计费，与某位原本有多少个 $1$ 无关。
6. **常数**：$n = 10^5$ 时一趟异或 + 一次 `popcount`，几乎零开销。

## 5. 正确性证明

**引理 1（单次操作的效果）**：一次「翻转 `nums[i]` 的第 $b$ 位」的操作，恰好使整体异或和 $X$ 的第 $b$ 位取反，其余位不变。

**证明**：设操作前整体异或和为 $X$，翻转后为 $X'$。对任意位 $b' \ne b$，所有元素第 $b'$ 位均未改变，故 $X'_{b'} = X_{b'}$。对第 $b$ 位，只有 $\textit{nums}[i]_b$ 取了反，而异或的每一位是各元素对应位的异或，某个加数取反会使结果取反：$X'_b = \bigoplus_{j \ne i} \textit{nums}[j]_b \oplus (1 - \textit{nums}[i]_b) = X_b \oplus 1$。∎

**引理 2（下界）**：对任意合法操作序列，记 $c_b$ 为「翻转第 $b$ 位的操作次数」，则 $c_b$ 为奇数当且仅当 $d_b = 1$，其中 $d = X \oplus k$。因此总操作数 $\sum_b c_b \ge \operatorname{popcount}(d)$。

**证明**：由引理 1，操作完成后第 $b$ 位为 $X_b \oplus (c_b \bmod 2)$。目标要求它等于 $k_b$，故 $c_b \bmod 2 = X_b \oplus k_b = d_b$。于是 $d_b = 1$ 时 $c_b \ge 1$（奇数），$d_b = 0$ 时 $c_b \ge 0$。对所有位求和即得 $\sum_b c_b \ge \#\{b : d_b = 1\} = \operatorname{popcount}(d)$。∎

**引理 3（可达性）**：存在恰好 $\operatorname{popcount}(d)$ 次操作的序列达成目标。

**证明**：对每个满足 $d_b = 1$ 的位 $b$，取任意一个元素（例如 `nums[0]`）翻转它的第 $b$ 位。题面允许翻转前导 $0$，所以只要该元素存在，第 $b$ 位总能被翻转；不同位作用在不同位上，互不覆盖。共执行 $\operatorname{popcount}(d)$ 次操作后，每位 $b$ 被翻转的次数恰为 $d_b \in \{0,1\}$，由引理 1，最终第 $b$ 位为 $X_b \oplus d_b = k_b$，故整体异或和等于 $k$。∎

**定理**：算法返回最少操作次数。

**证明**：算法返回 $\operatorname{popcount}(d)$。由引理 2，任何合法序列的操作数都不小于它；由引理 3，存在操作数恰为它的合法序列。故它既是下界又可达到，即最少操作次数。∎

## 6. 复杂度分析

- **时间**：$O(n)$。一趟求异或和；`popcount` 为 $O(1)$（位宽固定为 20，与 $n$ 无关）。
- **空间**：$O(1)$，只用常数个整型变量，不复制数组。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minOperations(vector<int>& nums, int k) {
        int x = 0;
        for (int v : nums) x ^= v;          // 整体异或和
        return __builtin_popcount(x ^ k);   // 只有不同的位需要各翻转一次
    }
};
```

### Python

```python
class Solution:
    def minOperations(self, nums: list[int], k: int) -> int:
        x = 0
        for v in nums:                 # 整体异或和
            x ^= v
        return bin(x ^ k).count("1")   # 只有不同的位需要各翻转一次
```

> 💡 两份代码均通过官方示例（`2`、`0`）与补充示例（`[10], k = 3` → `2`），并与「对元素元组做 BFS、每次翻转一位」的暴力搜索在 400 组小规模随机用例（$n \le 3$、值 $< 16$、$k < 16$）上对拍，`mismatch = 0`；另在 $n = 10^5$、全体元素为 $10^6$ 的大用例上验证了线性耗时与 `int` 不溢出的结论。

## 8. 边界情况与易错点

1. **已经相等**：$X = k$ 时 $d = 0$，返回 $0$（示例 2）。不要漏掉这个分支。
2. **$n = 1$**：只有一个元素时结论不变，答案是 $\operatorname{popcount}(\textit{nums}[0] \oplus k)$——这其实就是 [2220. 转换数字的最少位翻转次数](https://leetcode.cn/problems/minimum-bit-flips-to-convert-number/)。
3. **$k = 0$**：目标是把整体异或和清成 $0$，答案仍是 $\operatorname{popcount}(X)$，无需特判。
4. **全 0 数组**：`nums = [0,0]`、`k = 0` → $0$。若 $k = 5$，答案是 $\operatorname{popcount}(5) = 2$，靠翻前导 $0$ 实现，这正是题面那句「可以翻转前导 0」的用处。
5. **高位差异**：$X = 0$、$k = 10^6$（第 19 位为 $1$）时答案要数到第 19 位，`popcount` 在 32 位整型上天然覆盖，不需要手动限位。
6. **不要真的模拟翻转**：模拟单次操作是 $O(1)$，但搜索最优序列不是；本题的价值就在于发现闭式解。
7. **不要误用「$0$ 与 $1$ 的个数取小」**：某些「按位构造最小代价」的题（如把某一位统一成 $0$ 或 $1$）才需要比较 $1$ 的个数与 $0$ 的个数；本题每位独立计费，下界恒为 $1$。
8. **类型**：$\textit{nums}[i], k \le 10^6$，异或结果仍在 `int` 范围，无溢出风险；若值域放大到 $10^{18}$ 需改用 `long long` 与 `__builtin_popcountll`。
