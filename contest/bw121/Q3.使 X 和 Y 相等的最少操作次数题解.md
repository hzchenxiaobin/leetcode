# LeetCode 使 X 和 Y 相等的最少操作次数 题解

## 1. 题目概述

- **标题 / 题号**：使 X 和 Y 相等的最少操作次数（#2998，medium）
- **链接**：https://leetcode.cn/problems/minimum-number-of-operations-to-make-x-and-y-equal/
- **来源**：LeetCode 第 121 场双周赛 Q3
- **难度**：中等
- **标签**：广度优先搜索、记忆化、动态规划

**题意**：给定两个正整数 $x$ 和 $y$，每次可以执行下列四种操作之一：

1. 若 $x$ 是 $11$ 的倍数，令 $x \leftarrow x / 11$；
2. 若 $x$ 是 $5$ 的倍数，令 $x \leftarrow x / 5$；
3. 令 $x \leftarrow x - 1$；
4. 令 $x \leftarrow x + 1$。

求使 $x = y$ 的最少操作次数。

**约束**：

- $1 \le x, y \le 10^4$

## 2. 示例

**示例 1**

```text
输入：x = 26, y = 1
输出：3
解释：26 → 25（−1）→ 5（÷5）→ 1（÷5），共 3 步。
```

**示例 2**

```text
输入：x = 54, y = 2
输出：4
解释：54 → 55（+1）→ 5（÷11）→ 1（÷5）→ 2（+1），共 4 步。
```

**示例 3**

```text
输入：x = 25, y = 30
输出：5
解释：只能连续 +1 五次：25 → 30。
```

**示例 4（补充）**

```text
输入：x = 9, y = 1
输出：3
解释：9 → 11（+2 两次）→ 1（÷11），共 3 步。
      最优路径跑到了 x 的右边（11 > 9），所以搜索上界不能只取到 x。
```

## 3. 解题思路

### 3.1 暴力思路

最自然的想法是 DFS：从 $x$ 出发尝试四种操作，递归到 $y$。但 $+1$ 与 $-1$ 互为逆运算，搜索会在两个相邻数值之间来回震荡，**不加「已访问」标记就会死循环，加了标记又要考虑「先变大再变小」是否有意义**，边界很难拍脑袋定。更麻烦的是，$+1$ 可以把数值推到任意大，状态空间本身是无穷的。

所以真正的问题不是「怎么搜」，而是**「搜索范围该定多大才不会漏掉最优解」**。这个上界一旦确定，问题就退化成一张有限图上的无权最短路。

### 3.2 核心观察：这是单位边权图上的最短路，且数值有安全上界

![把数值看成节点，四种操作就是四类单位代价的有向边](images/bw121_q3_graph_model.svg)

把每个正整数看成一个节点，四种操作看成边权为 $1$ 的有向边：$u \to u/11$（当 $11 \mid u$）、$u \to u/5$（当 $5 \mid u$）、$u \to u-1$、$u \to u+1$。于是「最少操作次数」= 从 $x$ 到 $y$ 的最短路径长度。

两个关键结论把这张无限图切成有限图：

- **若 $x \le y$，答案是 $y - x$**。因为只有 $+1$ 能让数值变大，除法与减法都使数值严格减小，任何路径中 $+1$ 的次数至少是 $y - x$，而全用 $+1$ 恰好 $y - x$ 步可达（见 §5 引理 1）。
- **若 $x > y$，最优路径上的数值不会超过 $x + (x - y) \le 2x$**。因为「一路 $-1$」已经给出了 $x - y$ 步的上界；若某条路径走到 $v > x + (x - y)$，光是爬到 $v$ 就花了超过 $x - y$ 步，已经比这个上界差，不可能最优（见 §5 引理 2）。

![搜索区间的上界：超过 x + (x − y) 的数值不可能出现在最优解里](images/bw121_q3_bound.svg)

于是只需在 $[1,\,2x]$ 上做 BFS。由于边权全为 $1$，**BFS 第一次访问某个数值时的层数就是它到 $x$ 的最短距离**，第一次弹出 $y$ 即可返回。

### 3.3 算法流程

![BFS 分层：从 26 出发，第 3 层首次出现 1](images/bw121_q3_bfs_layers.svg)

```text
1. 若 x <= y：返回 y − x
2. hi = 2x + 12，dist[0..hi] 全部置 −1，dist[x] = 0，队列 ← {x}
3. while 队列非空：
       u = 队首出队
       若 u == y：返回 dist[u]
       候选集合 = { u − 1 } ∪ { u/11 若 11 | u } ∪ { u/5 若 5 | u } ∪ { u + 1 若 u + 1 ≤ hi }
       for v in 候选集合：
           若 v ≥ 0 且 dist[v] == −1：dist[v] = dist[u] + 1，v 入队
4. 返回 dist[y]
```

`dist` 数组同时承担「访问标记」与「距离」两个职责，每个数值至多入队一次，整个 BFS 是线性的。

### 3.4 示例演算

以示例 1（$x = 26$，$y = 1$）为例，BFS 逐层扩展（同一层内顺序不影响结论）：

| 层 | 新入队的数值 | 说明 |
|----|--------------|------|
| 0 | 26 | 起点 |
| 1 | 25，27 | $26-1$、$26+1$（$26$ 不能被 $5$ 或 $11$ 整除） |
| 2 | 5，24，28 | $25/5 = 5$、$25-1 = 24$、$27+1 = 28$（$26$ 已访问，跳过） |
| 3 | **1**，4，6，… | 由 $5$ 扩展出 $5/5 = 1$，命中所求 |

第 3 层首次出现 $1$，故答案为 $3$，对应路径 $26 \to 25 \to 5 \to 1$。

对补充示例（$x = 9$，$y = 1$）：第 1 层是 $8, 10$（$9$ 不是 $5$ 或 $11$ 的倍数）；第 2 层是 $7, 5, 11$（$10/5 = 5$、$10+1 = 11$）；第 3 层由 $11/11 = 1$ 命中，答案 $3$。**注意路径经过了 $11 > x = 9$：如果上界只取到 $x$，就只剩 $9 \to 8 \to 7 \to 6 \to 5 \to 1$ 这条 5 步的路，答案会算错**——这正是上界必须留出余量的原因。

## 4. 算法细节

1. **早退分支 `x <= y`**：不加这个分支，BFS 也能算出正确答案，但要白白搜一遍 $[1, 2x]$；加上它既快又能避免「$y > 2x$ 时数组越界」的坑。
2. **上界取 `2x + 12`**：理论上 $x + (x-y) \le 2x - 1$ 就够，多给 12 的余量是为了让「先 $+1$ 探到最近的 $5$ 或 $11$ 的倍数」这类动作不被误截（最近的 $11$ 的倍数至多需要 $+10$）。
3. **`dist` 初始化成 `-1`**：一举两得——既是「未访问」标记，又能在访问时写入层数，不必额外开 `visited`。
4. **候选集顺序无关**：除法边只在整除时存在；$u$ 同时是 $55$ 的倍数时两条除法边都加入，BFS 自己会选更优的那条。
5. **$u+1$ 的上界检查**：只有 $u + 1 \le hi$ 才允许入队，避免数组越界；$u - 1$ 只需检查 $v \ge 0$。
6. **复杂度直觉**：每个数值最多入队一次，单次扩展 $O(1)$，总状态数 $O(x)$。$x \le 10^4$ 时最多约 $2 \times 10^4$ 个状态，毫无压力。
7. **为什么不用 Dijkstra**：边权全是 $1$，堆是多余的；用普通队列即可保证按层（按距离）出队。
8. **为什么不用记忆化 DFS**：$+1 / -1$ 构成环（$u \to u+1 \to u$），朴素记忆化会遇到「状态互相依赖」的问题；BFS 天然免疫。

## 5. 正确性证明

**引理 1**：若 $x \le y$，则最少操作次数恰为 $y - x$。

**证明**：考察任意一条从 $x$ 到 $y$ 的操作序列。设其中 $+1$ 执行了 $a$ 次、$-1$ 执行了 $b$ 次、除以 $11$ 与除以 $5$ 各 $c, d$ 次。除法只在数值为对应倍数时发生，故每次除法都把当前值 $u$ 变成 $u/11$ 或 $u/5$，减少量分别为 $u - u/11 \ge 0$ 与 $u - u/5 \ge 0$。于是

$$y - x = a - b - (\text{各次除法的减少量之和}) \le a,$$

即 $a \ge y - x$，而总操作次数 $\ge a \ge y - x$。另一方面，连续执行 $y - x$ 次 $+1$ 即可从 $x$ 到达 $y$，故上界也是 $y - x$，两者相等。∎

**引理 2**：若 $x > y$，则存在一条最优操作序列，其路径上出现的所有数值都不超过 $x + (x - y)$。

**证明**：先注意「连续 $x - y$ 次 $-1$」是一条合法序列，故最优值 $\mathrm{OPT} \le x - y$。反设某条最优序列经过了数值 $v > x + (x - y)$。在这条序列中，从 $x$ 走到 $v$ 的这段里，每一步至多让数值增加 $1$（$+1$ 增加 $1$，其余操作都不增加），因此这一段至少需要 $v - x > x - y \ge \mathrm{OPT}$ 步，与「该序列最优」矛盾。∎

**引理 3（BFS 正确性）**：在边权均为 $1$ 的图上，BFS 首次访问节点 $v$ 时记录的层数等于 $x$ 到 $v$ 的最短距离。

**证明**：BFS 按层扩展，第 $k$ 层的节点到 $x$ 的距离恰为 $k$（对 $k$ 归纳：第 $0$ 层只有 $x$；第 $k+1$ 层是从第 $k$ 层经一条边可达且未被前 $k$ 层访问的节点，其距离 $\le k+1$，又不可能是 $\le k$，故 $= k+1$）。既然距离严格随层数递增，首次访问必然是最短距离。∎

**定理**：算法返回 $x$ 到 $y$ 的最少操作次数。

**证明**：分两种情形。若 $x \le y$，引理 1 直接给出答案 $y - x$。若 $x > y$，由引理 2 最优路径完全落在 $[1, 2x]$ 内（因 $x + (x-y) \le 2x - 1 < hi$），而算法在该区间上完整地建图并做 BFS（所有合法边都被枚举：整除性检查覆盖两条除法边，$u \pm 1$ 覆盖加减边，越界仅裁掉不可能更优的部分），故由引理 3，算法在 $y$ 处记录的距离就是最少操作次数。∎

## 6. 复杂度分析

- **时间**：$O(x)$。状态空间为 $[1, 2x]$ 共 $O(x)$ 个节点，每个节点至多入队、出队一次，每次扩展检查常数条边。$x = 10^4$ 时约 $2 \times 10^4$ 个状态。
- **空间**：$O(x)$。`dist` 数组长度 $2x + 13$，队列最多同时容纳 $O(x)$ 个节点。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minimumOperationsToMakeEqual(int x, int y) {
        if (x <= y) return y - x;              // 只能 +1 才能变大
        int hi = 2 * x + 12;                   // 安全上界：超过 2x 的路径一定不如全用 -1
        vector<int> dist(hi + 1, -1);
        queue<int> q;
        dist[x] = 0;
        q.push(x);
        while (!q.empty()) {
            int u = q.front(); q.pop();
            if (u == y) return dist[u];
            int nxt[4], cnt = 0;
            if (u % 11 == 0) nxt[cnt++] = u / 11;
            if (u % 5 == 0)  nxt[cnt++] = u / 5;
            nxt[cnt++] = u - 1;
            if (u + 1 <= hi) nxt[cnt++] = u + 1;
            for (int t = 0; t < cnt; ++t) {
                int v = nxt[t];
                if (v >= 0 && dist[v] == -1) {  // 每个数值只入队一次
                    dist[v] = dist[u] + 1;
                    q.push(v);
                }
            }
        }
        return dist[y];
    }
};
```

### Python

```python
from collections import deque

class Solution:
    def minimumOperationsToMakeEqual(self, x: int, y: int) -> int:
        if x <= y:                     # 只有 +1 能把 x 变大
            return y - x
        hi = 2 * x + 12                # 安全上界：超过 2x 的数值不可能在最优路径上
        dist = [-1] * (hi + 1)
        dist[x] = 0
        q = deque([x])
        while q:
            u = q.popleft()
            if u == y:
                return dist[u]
            nxt = [u - 1]
            if u % 11 == 0:
                nxt.append(u // 11)
            if u % 5 == 0:
                nxt.append(u // 5)
            if u + 1 <= hi:
                nxt.append(u + 1)
            for v in nxt:              # 单位边权 → 首次访问即最短路
                if v >= 0 and dist[v] == -1:
                    dist[v] = dist[u] + 1
                    q.append(v)
        return dist[y]
```

> 💡 两份代码均通过官方示例（`3`、`4`、`5`）与补充示例（$x=10, y=1$ → `2`），并与「在 $[0, 6\max(x,y)+200]$ 上跑 Dijkstra」的宽区间独立实现在 $x, y \le 200$ 的 3000 组随机用例、以及 $x, y \in [1,120]$ 的全枚举（14400 组）上对拍，`mismatch = 0`；边界 $x = y = 10^4$（→ `0`）、$x = 10^4, y = 1$（→ `8`）也已验证。

## 8. 边界情况与易错点

1. **$x = y$**：答案为 $0$。走 `x <= y` 分支时返回 $y - x = 0$，天然正确。
2. **$x < y$**：直接返回 $y - x$，不要试图「先加再除再减」——除法只会让数值更小，绕路可证不会更优（引理 1）。
3. **上界必须大于 $x$**：$x = 9, y = 1$ 的最优路径经过 $11$（先 $+1$ 到最近的高倍数再除）。若上界只取到 $x$，答案会从 $3$ 错算成 $5$。取 $2x$ 有充分余量。
4. **$+1$ 的越界保护**：只有 $u + 1 \le hi$ 时才入队，否则数组越界（C++ 会段错误，Python 会静默错位）。
5. **$u - 1$ 的下界保护**：$u - 1$ 可能为 $0$。允许 $0$ 不影响正确性（$0$ 只能 $+1$ 回到 $1$，属于绕路），但必须避免负数下标。
6. **不要把 BFS 写成 DFS**：$+1$ 与 $-1$ 互为逆运算，DFS 不加访问标记必然死循环；记忆化 DFS 也要小心「状态互相依赖」。
7. **不要用堆**：边权全为 $1$，`priority_queue` 只会拖慢常数；BFS 队列才是对的。
8. **`dist` 的初值**：必须初始化为 $-1$（或一个不可能的距离值），不能用 $0$，否则「未访问」与「距离 0」无法区分。
9. **整除判断方向**：`u % 11 == 0` 才能除，不要用 `11 % u == 0`；两条除法互不排斥（$55$ 两条都能走）。
10. **数组大小**：`hi + 1`，别写成 `hi`——当 $u = hi$ 时 `dist[hi]` 是合法下标。
