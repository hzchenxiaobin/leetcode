# LeetCode 判断一个点是否可以到达 题解

## 1. 题目概述

- **标题 / 题号**：判断一个点是否可以到达（#2543，hard）
- **链接**：https://leetcode.cn/problems/check-if-point-is-reachable/
- **来源**：LeetCode 第 96 场双周赛 Q4
- **难度**：困难
- **标签**：数学、数论、最大公约数、欧几里得算法

**题意**：无穷网格上从 $(1, 1)$ 出发，每一步可以从 $(x, y)$ 走到以下四点之一：

$$(x, y - x), \quad (x - y, y), \quad (2x, y), \quad (x, 2y)$$

（前两个是"辗转相减"，后两个是坐标翻倍。）问能否经过**有限步**到达 $(targetX, targetY)$，能返回 `true`，否则 `false`。

**约束**：$1 \le targetX, targetY \le 10^9$。

## 2. 示例

**示例 1（官方）**

```text
输入：targetX = 6, targetY = 9
输出：false
解释：无法从 (1,1) 到达 (6,9)。
```

**示例 2（官方）**

```text
输入：targetX = 4, targetY = 7
输出：true
解释：(1,1) → (1,2) → (1,4) → (1,8) → (1,7) → (2,7) → (4,7)。
      (依次使用：y 翻倍、y 翻倍、y 翻倍、x−y 减、x 翻倍、x 翻倍)
```

**示例 3（边界补充）**

```text
输入：targetX = 1, targetY = 1
输出：true
解释：起点即终点，0 步可达。
```

## 3. 解题思路

### 3.1 暴力思路

从 $(1, 1)$ 正向 BFS：坐标会指数膨胀（每步翻倍），在 $10^9$ 的目标尺度上搜索空间不可控；反着从 $(targetX, targetY)$ 往回搜同样没有好的收敛界。正解必须找到**判据**而不是搜索。

### 3.2 核心观察：gcd 是"不变量 + 2 的幂"

![核心观察：四步操作与它们的逆操作](images/bw96_q4_inverse_operations.svg)

关键在于看四种操作对 $\gcd(x, y)$ 做了什么：

- **减法步**：$\gcd(x, y - x) = \gcd(x - y, y) = \gcd(x, y)$，**完全不变**（这就是欧几里得辗转相除法的基础）；
- **翻倍步**：$\gcd(2x, y) \in \{\gcd(x, y),\ 2\gcd(x, y)\}$，**至多翻一倍**（乘了一个 2）。

从 $\gcd(1, 1) = 1$ 出发，无论怎么走，$\gcd$ 永远是 $2^a$ 的形状。于是有**必要条件**：$\gcd(targetX, targetY)$ 必须是 2 的幂。

### 3.3 核心观察二：反向归约——必要性也是充分的

![反向归约：从目标一路走回 (1,1)](images/bw96_q4_gcd_invariant.svg)

四个操作都是**可逆**的：把方向反过来，等价的操作集是

$$(x, y) \to (x + y, y),\quad (x, x + y),\quad (x/2, y)\ (x\ 偶),\quad (x, y/2)\ (y\ 偶)$$

于是"$(1,1)$ 可达目标" ⟺ "目标可反向走回 $(1,1)$"。设 $g = \gcd(targetX, targetY) = 2^a$。反向策略：

1. **除尽 2**：只要某坐标是偶数就把**它**减半。$\gcd$ 的奇数部分始终保持为 1（见引理 2），最终停在两个**奇数** $(u, v)$ 且 $\gcd(u, v) = 1$；
2. **双奇归约**：$u \ne v$ 时不妨 $u < v$，执行 $(u, v) \to (u, u + v) \to (u, (u+v)/2)$（先反向加、再减半；$u + v$ 是偶数）。新点 $\big(u, (u+v)/2\big)$ 的 $\gcd$ 仍为 1，且最大坐标从 $v$ 降到 $(u+v)/2 < v$，**严格变小**；
3. $u = v$ 时由 $\gcd = 1$ 得 $u = v = 1$，到达终点。

最大坐标每轮严格下降，有限轮后必然归约到 $(1, 1)$。因此 $\gcd$ 是 2 的幂不光是必要的，还是**充分的**——答案就是判断 $g \And (g - 1) = 0$。

### 3.4 示例演算

![示例演算：(4,7) 的反向归约与正向路径](images/bw96_q4_example_walkthrough.svg)

**示例 2（可达）**：$\gcd(4, 7) = 1 = 2^0$ → `true`。反向走一遍验证：$(4,7) \xrightarrow{x \text{ 偶}} (2,7) \xrightarrow{x \text{ 偶}} (1,7)$；双奇、$1 < 7$：$(1,7) \to (1,8) \to (1,4) \to (1,2) \to (1,1)$。把这条反向路径**倒过来**读，恰好就是官方给的路径 $(1,1) \to (1,2) \to (1,4) \to (1,8) \to (1,7) \to (2,7) \to (4,7)$——一一对应，互为逆操作。

**示例 1（不可达）**：$\gcd(6, 9) = 3$，含奇素因子 3，不是 2 的幂 → `false`。无论怎么操作，$\gcd$ 的奇数部分永远是 1，永远变不出 3。

## 4. 算法细节

1. **一步求 gcd**：欧几里得算法 $O(\log \max(x, y))$；C++17 也可用 `<numeric>` 的 `std::gcd`，本文手写以保持代码自包含。
2. **判断 2 的幂**：$g \ge 1$ 时 $g$ 是 2 的幂 ⟺ 二进制只有一个 1 ⟺ $g \And (g-1) = 0$。$g = 1$（$2^0$）也满足，正确覆盖"互质"情形。
3. **不需要真的构造路径**：判定与构造是两回事，本题只要判定；§3.3 的反向归约其实是构造性证明，把它写成算法同样轻松——每轮"双奇归约"让最大坐标严格下降、随后减半只降不升，有限轮必到 $(1,1)$，实测 $10^9$ 级目标百来轮内收敛（本质是二元 GCD 型过程）。
4. **为什么不怕坐标越界**：判定只用 $\gcd \le 10^9$，`int` 足够。
5. **正难则反**：四操作的正向组合难以刻画，但每个操作的**逆**依然落在同一操作族内（减法 ⟺ 加法互逆、翻倍 ⟺ 减半互逆），这是"可达性 ⟺ 反向可达性"成立的前提，也是本题技巧的核心。

## 5. 正确性证明

**引理 1（gcd 的操作不变量，正向）**：设 $g = \gcd(x, y)$，则 $\gcd(x, y - x) = \gcd(x - y, y) = g$，且 $\gcd(2x, y), \gcd(x, 2y) \in \{g, 2g\}$。

**证明**：辗转相减：$d \mid x, d \mid y \iff d \mid x, d \mid y - x$，故 $x, y$ 与 $x, y-x$ 有完全相同的公因子集合，gcd 相等。翻倍：一方面 $g \mid 2x$ 且 $g \mid y$，故 $g \mid \gcd(2x, y)$；另一方面 $\gcd(2x, y) \mid 2x$ 且 $\mid y$，故 $\gcd(2x,y) \mid \gcd(2x, 2y) = 2g$。既是 $g$ 的倍数又是 $2g$ 的约数，只能是 $g$ 或 $2g$。∎

**引理 2（奇数部分守恒）**：定义 $\operatorname{odd}(m)$ 为 $m$ 中剔除所有因子 2 后的奇数部分。从 $(1,1)$ 出发任意正向走到 $(x, y)$，有 $\operatorname{odd}(\gcd(x, y)) = 1$；等价地，反向操作（加法与减半）同样保持 $\operatorname{odd}(\gcd)$ 不变。

**证明**：对步数归纳。$\gcd(1,1) = 1$，奇数部分为 1。归纳步只需验证三种操作都不改变 $\gcd$ 的奇数部分：设 $d = \gcd(x, y)$，奇素数 $p \mid \gcd(x', y')$（操作后）。减法步 $y' = y - x$：$p \mid x, p \mid y - x \Rightarrow p \mid y$，故 $p \mid d$。加法步（反向）$y' = x + y$ 同理。减半步 $x' = x/2$（$x$ 偶）：若奇素数 $p \mid x'$ 且 $p \mid y'$（$y' = y$），则 $p \mid 2x' = x$ 且 $p \mid y$，故 $p \mid d$。三个方向合并：操作后 gcd 的任何奇素因子都已属于操作前 gcd 的奇素因子集合。反之操作可逆（减法 ⟺ 加法互逆、翻倍 ⟺ 减半互逆），奇素因子也不会凭空消失——但这一点本证明不需要，只需"不新增"。初始奇数部分为 1（无奇素因子），故任意时刻 gcd 无奇素因子，即 $\operatorname{odd}(\gcd) = 1$。∎

**定理（判定准则）**：$(targetX, targetY)$ 可从 $(1, 1)$ 到达 ⟺ $g = \gcd(targetX, targetY)$ 是 2 的幂（含 $g = 1$）。

**证明**：（⟹）由引理 2，可达点的 gcd 无奇素因子，只能形如 $2^a$，必要性成立。（⟸）设 $g = 2^a$，用反向操作 $(x,y) \to (x+y, y)$、$(x, x+y)$、偶数减半构造一条回到 $(1,1)$ 的路径；由于每个反向操作恰是某个正向操作的逆，把该路径倒序即得正向可达路径，故只需证反向路径存在。过程：不断对偶坐标减半，由引理 2 的"不新增"论证（反向操作同样不新增 gcd 的奇素因子；更直接地：$g$ 形如 $2^a$，减半后 gcd 的奇数部分仍为 1）最终得到两个奇数 $(u, v)$，且 $\gcd(u, v)$ 是奇数、奇数部分为 1，即 $\gcd(u, v) = 1$。若 $u = v$ 则 $u = v = 1$，完成。否则不妨 $u < v$（$(u, v)$ 与 $(v, u)$ 操作对称），执行 $(u, v) \to (u, u + v)$（$u + v$ 为偶数）$\to \big(u, (u+v)/2\big)$。验证：$\gcd\big(u, (u+v)/2\big) = 1$——设 $d$ 为公因子，由 $u$ 奇知 $d$ 奇，则 $d \mid u$ 且 $d \mid (u+v)/2 \Rightarrow d \mid u + v$ 且 $d \mid u \Rightarrow d \mid v$，故 $d \mid \gcd(u, v) = 1$。且 $(u+v)/2 < v$，最大坐标严格下降；随后继续对偶者减半，两种操作都不增加最大坐标。由于每轮"双奇归约"使最大坐标至少减 1 且坐标恒 $\ge 1$，过程有限步内终止；终止时必然处于 $u = v$（两奇、互质），即 $(1, 1)$。反向路径存在，充分性成立。∎

> ⚠️ 注意"反向操作不新增奇素因子"与"正向不新增"是同一件事的两面——引理 2 的论证对加减、减半全部操作成立，与方向无关；这正是"操作集合可逆"带来的对称性。

## 6. 复杂度分析

- **时间**：$O(\log \max(targetX, targetY))$，即一次欧几里得 gcd 的开销；判断 2 的幂是 $O(1)$。若真要输出反向归约路径，其长度也与坐标规模相称（二元 GCD 型过程，随机实测 $10^9$ 级目标最坏约 140 轮收敛）。
- **空间**：$O(1)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool isReachable(int targetX, int targetY) {
        int g = gcd(targetX, targetY);       // g 只含 2 的幂 <=> (1,1) 可达
        return (g & (g - 1)) == 0;
    }

private:
    int gcd(int a, int b) {
        while (b) { int t = a % b; a = b; b = t; }
        return a;
    }
};
```

### Python

```python
class Solution:
    def isReachable(self, targetX: int, targetY: int) -> bool:
        from math import gcd
        g = gcd(targetX, targetY)    # g 只含 2 的幂 <=> (1,1) 可达
        return g & (g - 1) == 0
```

> 💡 两份代码均通过官方示例（`false`、`true`）、$(1,1)$、$2^{29}$ 级大数、$\gcd$ 为大奇数等边界，并与"从 $(1,1)$ 正向 BFS（只走正坐标）"的暴力在 $[1, 40]^2$ 全部 $1600$ 个点上一致（C++ 与 Python 双跑，BFS 搜索界取 100，可证明目标 $\le 40$ 的可达点必有全程 $\le 80$ 的路径，见 §3.3 归约过程的上界），`mismatch = 0`。

## 8. 边界情况与易错点

1. **$g = 1$ 是 2 的幂（$2^0$）**：互质的点全部可达，别把判断写成 $g > 1 \And g$ 是 2 的幂。
2. **$targetX = targetY = 1$**：gcd 为 1，返回 `true`（零步可达）。
3. **两坐标相等但不互质**：如 $(6, 6)$，$\gcd = 6 = 2 \times 3$ 含奇素因子，返回 `false`。
4. **判断 2 的幂的位技巧**：$g \And (g - 1) == 0$ 对 $g \ge 1$ 恒等价于"$g$ 是 2 的幂"；先取 gcd 再判断，顺序别反。
5. **操作数巨大也不用怕**：$10^9$ 级目标，正向路径可能要"翻倍—减法"交替几十步，但判定只需 $O(\log)$，无需担心步数上界。
6. **别去正向 BFS/DFS**：坐标每步可翻倍，$10^9$ 尺度下状态空间无法收束；也别对每个坐标预处理 2 的幂集合，直接 gcd 即可。
7. **"有限步"三个字**：题目允许 0 步（起点即终点），路径长度上不封顶；判据与步数无关。
