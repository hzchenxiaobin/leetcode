# LeetCode 找出满足差值条件的下标 I 题解

## 1. 题目概述

- **标题 / 题号**：找出满足差值条件的下标 I（#2903，easy）
- **链接**：https://leetcode.cn/problems/find-indices-with-index-and-value-difference-i/
- **来源**：LeetCode 第 367 场周赛 Q1
- **难度**：简单
- **标签**：数组、枚举、双指针

**题意**：给定下标从 0 开始、长度为 $n$ 的整数数组 `nums`，以及整数 `indexDifference`（下标差门槛，记 $D$）和 `valueDifference`（值差门槛，记 $V$）。在 $[0, n-1]$ 中找两个下标 $i$ 和 $j$（**可以相等**），满足：

- $\text{abs}(i - j) \ge D$，且
- $\text{abs}(\text{nums}[i] - \text{nums}[j]) \ge V$。

返回任意一组 $[i, j]$；不存在则返回 $[-1, -1]$。

**约束**：

- $1 \le n = \text{nums.length} \le 100$
- $0 \le \text{nums}[i] \le 50$
- $0 \le D \le 100$，$0 \le V \le 50$

> 💡 **赛场排布彩蛋**：本场 Q3（#2905）与本题**题面完全相同**，仅把 $n$ 从 $100$ 放大到 $10^5$——周赛少见的「Q1/Q3 双版本同题」排布。$n \le 100$ 时 $O(n^2)$ 暴力稳过签到；但**直接按 $O(n)$ 前缀最值写，一份代码通吃两题**（见第 3.5 节与 [Q3 题解](Q3.找出满足差值条件的下标 II题解.md)）。
>
> 本题另有[每日题解 2903](../../solution/2901-3000/2903_找出满足差值条件的下标I.md)：以前缀最值 $O(n)$ 为主解的面试向展开。本文是**赛场复盘**视角：签到题从题面到代码的最短路径、边界处理，以及双版本排布下的赛时策略。

## 2. 示例

**示例 1**

```text
输入：nums = [5,1,4,1], indexDifference = 2, valueDifference = 4
输出：[0,3]
解释：选择 i = 0 和 j = 3：abs(0 - 3) = 3 >= 2 且 abs(5 - 1) = 4 >= 4（压线达标）。
      [3,0] 也是符合题目要求的答案。
```

**示例 2**

```text
输入：nums = [2,1], indexDifference = 0, valueDifference = 0
输出：[0,0]
解释：选择 i = j = 0：abs(0 - 0) >= 0 且 abs(2 - 2) >= 0。
      注意 i 和 j 可以相等。[0,1]、[1,0]、[1,1] 同样合法。
```

**示例 3**

```text
输入：nums = [1,2,3], indexDifference = 2, valueDifference = 4
输出：[-1,-1]
解释：下标差 >= 2 的数对只有 (0,2)，但 |1-3| = 2 < 4，无解。
```

## 3. 解题思路

### 3.1 签到最短路径：枚举所有数对

$1 \le n \le 100$，满足条件的数对**判定**没有任何结构门槛——双重循环枚举全部 $(i, j)$ 对，逐对检查两条约束，命中即返回，$O(n^2)$ 至多约 $5 \times 10^3$ 次检查，任何语言都能瞬间通过。这正是签到题的预期解法：**别想复杂了，先交再优化**。

### 3.2 核心观察：abs 对称——只查「半个三角形」

![核心观察：对称化简，只枚举 j ≥ i + D 的半个三角形](images/index_value_diff_i_pair_matrix.svg)

两条约束里藏着一次免费优化：

1. **对称免检一半**：$\text{abs}(i - j)$ 与 $\text{abs}(\text{nums}[i] - \text{nums}[j])$ 都关于 $i, j$ 对称——数对 $(i, j)$ 与 $(j, i)$ **同生共死**，不妨只枚举 $j \ge i$ 的一半。
2. **内层起点直接对齐 $i + D$**：令 $j$ 从 $i + D$ 起步，则 $j - i \ge D$ **自动成立**，下标条件在循环结构里被「结构性满足」，循环体内只剩**一次值差比较**。
3. **$i = j$ 天然覆盖**：$D = 0$ 时 $j$ 从 $i$ 起步，数对 $(i, i)$ 也在枚举范围内——题面明示 $i, j$ 可以相等，无需任何特判。

> 💡 **从题面到代码的最短路径**：读题 → 看到 $\text{abs}$ 对称 → 内层从 $i + D$ 起步 → 命中即返回。三行观察，两个 `for`，一个 `if`，签到完成。

### 3.3 算法流程

![算法流程：双重循环，命中即返回](images/index_value_diff_i_algorithm_flow.svg)

1. **外层**：$i$ 从 $0$ 到 $n - 1$。
2. **内层**：$j$ 从 $i + D$ 到 $n - 1$（$D = 0$ 时含 $j = i$）。
3. **检查**：若 $\text{abs}(\text{nums}[i] - \text{nums}[j]) \ge V$，立即返回 $[i, j]$——题目只要任意一组解，无需最小字典序。
4. **扫完未命中**：返回 $[-1, -1]$。

### 3.4 示例演算

![示例演算：命中即返回 vs 全程无解 vs i=j 边界](images/index_value_diff_i_walkthrough.svg)

**示例 1**（$\text{nums} = [5, 1, 4, 1]$，$D = 2$，$V = 4$），按字典序枚举 $j \ge i + 2$ 的数对：

| 序 | 数对 $(i, j)$ | $\text{abs}(\text{nums}[i] - \text{nums}[j])$ | 判定 |
|----|---------------|---------------------------------------------|------|
| 1 | $(0, 2)$ | $\lvert 5 - 4 \rvert = 1 < 4$ | ✗ 继续 |
| 2 | $(0, 3)$ | $\lvert 5 - 1 \rvert = 4 \ge 4$ | ✓ 命中，返回 $[0, 3]$ |

$(1, 3)$ 也在检查范围内，但按字典序排在 $(0, 3)$ 之后——提前返回后永远不会轮到它。

**示例 3**（$\text{nums} = [1, 2, 3]$，$D = 2$，$V = 4$）：唯一需检查的数对 $(0, 2)$ 差值 $2 < 4$；此后 $i = 1, 2$ 时 $i + D \ge n$，内层区间为空——全程无命中，返回 $[-1, -1]$。

**示例 2**（$D = V = 0$）：内层从 $j = i$ 起步，首个检查 $(0, 0)$：$\lvert 2 - 2 \rvert = 0 \ge 0$ 立即命中，返回 $[0, 0]$。

### 3.5 赛场策略：双版本同题，直接写 $O(n)$ 通吃 Q3

本场 Q3（#2905）与本题题面完全相同、仅 $n$ 放大到 $10^5$，$O(n^2)$ 必然超时。线性做法只需一个观察：**对每个 $j$，合法的 $i$ 组成前缀 $[0, j - D]$——一个随 $j$ 右移只增不减的候选集**；想让值差拉满，候选集中只有**前缀最小值**和**前缀最大值**两个代表值得检查。边扫边增量维护这两个量，$O(n)$ 一趟出解，**同一份代码提交本题与 Q3 均 AC**。

## 4. 算法细节

1. **内层起点 $i + D$ 的统一性**：$D = 0$ 时覆盖 $i = j$（题面明示合法）；$D \ge 1$ 时 $j - i \ge D \ge 1$ 自动保证 $i \ne j$。一个起点表达式通吃两种边界，无需分支。
2. **命中即返回**：题目明确「任意一组即可」，首个命中的数对就是答案——这也让 $O(n^2)$ 的**均摊**开销极小：绝大多数有解用例在扫描早期就返回。
3. **检查次数上界**：$\sum_{i=0}^{n-1} (n - i - D)^+$，$D = 0$ 时取最大 $n(n+1)/2 \approx 5 \times 10^3$（$n = 100$），量级远低于任何时限。
4. **无需溢出防护**：值域 $[0, 50]$，差的绝对值 $\le 50$，`int` 与 `abs` 全程安全。
5. **$D \ge n$ 时无解**：如 $n = 1, D = 1$，内层区间恒为空，自然落到 `return {-1,-1}`，无需特判「下标差门槛高于整个数组」。

## 5. 正确性证明

**引理 1（对称化简）**：原问题有解 $\iff$ 存在数对 $(i, j)$ 满足 $j \ge i + D$ 且 $\text{abs}(\text{nums}[i] - \text{nums}[j]) \ge V$。

**证明**：（$\Leftarrow$）$j \ge i + D$ 蕴含 $\text{abs}(i - j) = j - i \ge D$，故 $(i, j)$ 就是原问题的解。（$\Rightarrow$）设 $(i, j)$ 为任意解，由 $\text{abs}(i - j) \ge D$ 知 $i \le j - D$ 或 $j \le i - D$；后者交换 $i, j$ 的记号即化为前者，且两条 $\text{abs}$ 约束均不因交换而改变。∎

**引理 2（枚举完备）**：双重循环恰好无重复地枚举了全部满足 $j \ge i + D$ 的数对。

**证明**：每对 $(i, j)$ 由 $(i, j)$ 唯一确定，至多被访问一次；固定 $i$ 时 $j$ 的遍历区间 $[i + D, n - 1]$ 恰为所有满足 $j \ge i + D$ 的取值。∎

**定理**：算法返回的下标对满足两条约束；原问题有解时算法不会返回 $[-1, -1]$。

**证明**：**返回值合法**：算法仅在 $\text{abs}(\text{nums}[i] - \text{nums}[j]) \ge V$ 命中时返回 $[i, j]$，且内层结构保证 $j \ge i + D$ 即 $\text{abs}(i - j) \ge D$，两条约束均显式或结构性成立。**不漏报**：设原问题有解，由引理 1 存在满足 $j \ge i + D$ 的解 $(i^*, j^*)$；由引理 2 该数对必被枚举，且枚举按字典序进行、命中即返回——若在 $(i^*, j^*)$ 之前返回，由前一段知返回的同样是合法解；若走到 $(i^*, j^*)$ 则当场命中。故有解时必返回合法解，无解时所有检查均不命中，返回 $[-1, -1]$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n^2)$。外层 $n$ 轮，内层至多 $n - i - D$ 次值差比较；$n \le 100$ 时至多约 $5 \times 10^3$ 次检查，签到无压力（$O(n)$ 版为单趟扫描 $O(n)$，见第 3.5 节）。
- **空间复杂度**：$O(1)$。仅循环下标与返回数组，不随 $n$ 增长。

## 7. 参考代码

### C++（暴力签到版）

```cpp
class Solution {
  public:
    vector<int> findIndices(vector<int>& nums, int indexDifference, int valueDifference) {
        int n = nums.size();
        for (int i = 0; i < n; i++) {
            for (int j = i + indexDifference; j < n; j++) {  // j 从 i+D 起步：下标条件自动成立
                if (abs(nums[i] - nums[j]) >= valueDifference) {
                    return {i, j};                           // 命中即返回，任意一组解即可
                }
            }
        }
        return {-1, -1};
    }
};
```

### Python（暴力签到版）

```python
class Solution:
    def findIndices(self, nums: List[int], indexDifference: int, valueDifference: int) -> List[int]:
        n = len(nums)
        for i in range(n):
            for j in range(i + indexDifference, n):   # D=0 时 j 从 i 起，覆盖 i=j
                if abs(nums[i] - nums[j]) >= valueDifference:
                    return [i, j]
        return [-1, -1]
```

### C++（前缀最值 $O(n)$ 版：一份代码通吃 Q3）

```cpp
class Solution {
  public:
    vector<int> findIndices(vector<int>& nums, int indexDifference, int valueDifference) {
        int n = nums.size();
        int minIdx = 0, maxIdx = 0;            // 恰为 [0, j - indexDifference] 的最值下标
        for (int j = indexDifference; j < n; j++) {
            int r = j - indexDifference;        // 先纳入新解锁的候选 r = j - D
            if (nums[r] < nums[minIdx]) minIdx = r;
            if (nums[r] > nums[maxIdx]) maxIdx = r;
            if (abs(nums[j] - nums[minIdx]) >= valueDifference) return {minIdx, j};
            if (abs(nums[j] - nums[maxIdx]) >= valueDifference) return {maxIdx, j};
        }
        return {-1, -1};
    }
};
```

> 💡 这份 $O(n)$ 代码原样提交 Q3（#2905，$n \le 10^5$）同样 AC——双版本排布下最划算的赛时策略。完整推导与 Python 版见 [Q3 题解](Q3.找出满足差值条件的下标 II题解.md)。

## 8. 边界情况与易错点

1. **$i$ 可以等于 $j$**（题面明示）：$D = V = 0$ 时任何 $[k, k]$ 都合法；$D = 0$、$V > 0$ 时 $(i, i)$ 差恒为 $0 < V$ 必不达标——两种情形都被「内层从 $i + D$ 起步」天然覆盖，无需特判。
2. **内层别写成从 $i + 1$ 起步**：$D = 0$ 时会漏掉所有 $(i, i)$。反例：$n = 1$、$D = V = 0$——唯一合法答案就是 $[0, 0]$，起点写 $i + 1$ 将误返回 $[-1, -1]$。
3. **$D \ge n$ 时无解**：如 $n = 1$、$D = 1$，内层区间恒为空，直接返回 $[-1, -1]$，无需显式特判。
4. **比较是 $\ge$ 含等于**：示例 1 中 $\lvert 5 - 1 \rvert = 4$ 恰好压线 $V = 4$ 即达标；误写成 $>$ 会漏掉压线解。
5. **别混淆 $D$ 与 $V$ 的约束对象**：$D$ 约束**下标距离**、$V$ 约束**值差**，两者独立，无联动关系。
6. **溢出**：值域 $[0, 50]$，`int` 全程安全（Q3 版值域抬到 $10^9$ 仍在 `int` 范围内）。
7. **「命中即返回」依赖任意解可接受**：本题不要求字典序最小；若题目变形为「返回字典序最小的解」，提前返回不再正确，需完整扫描取最优。
