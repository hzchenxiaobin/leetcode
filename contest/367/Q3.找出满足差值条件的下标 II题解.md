# LeetCode 找出满足差值条件的下标 II 题解

## 1. 题目概述

- **标题 / 题号**：找出满足差值条件的下标 II（#2905，medium）
- **链接**：https://leetcode.cn/problems/find-indices-with-index-and-value-difference-ii/
- **来源**：LeetCode 第 367 场周赛 Q3
- **难度**：中等
- **标签**：数组、前缀最值、一次遍历

**题意**：给定下标从 0 开始、长度为 $n$ 的整数数组 `nums`，以及整数 `indexDifference`（下标差门槛，记 $D$）和 `valueDifference`（值差门槛，记 $V$）。在 $[0, n-1]$ 中找两个下标 $i$ 和 $j$（**可以相等**），满足：

- $\text{abs}(i - j) \ge D$，且
- $\text{abs}(\text{nums}[i] - \text{nums}[j]) \ge V$。

返回任意一组 $[i, j]$；不存在则返回 $[-1, -1]$。

**约束**：

- $1 \le n = \text{nums.length} \le 10^5$
- $0 \le \text{nums}[i] \le 10^9$
- $0 \le D \le 10^5$，$0 \le V \le 10^9$

> 💡 **赛场排布彩蛋**：本场 Q1（#2903）与本题**题面完全相同**，仅 $n$ 从 $100$ 放大到 $10^5$——周赛少见的「Q1/Q3 双版本同题」排布。Q1 用暴力过签的人，Q3 必须现场识别出「候选集单调扩张」的信号并升级为线性做法；直接按 $O(n)$ 写，一份代码通吃两题。
>
> 本题另有[每日题解 2905](../../solution/2901-3000/2905_找出满足差值条件的下标 II.md)：同一算法的面试向展开（「找最远 vs 找最近」的信息量对比、2817/239 对照表）。本文是**赛场复盘**视角：平移升级的思路路径、循环不变式与完整证明，两篇互为印证。

## 2. 示例

**示例 1**

```text
输入：nums = [5,1,4,1], indexDifference = 2, valueDifference = 4
输出：[0,3]
解释：选择 i = 0 和 j = 3：abs(0 - 3) = 3 >= 2 且 abs(5 - 1) = 4 >= 4。
      [3,0] 也是符合题目要求的答案。
```

**示例 2**

```text
输入：nums = [2,1], indexDifference = 0, valueDifference = 0
输出：[0,0]
解释：选择 i = j = 0：abs(0 - 0) >= 0 且 abs(2 - 2) >= 0。
      注意 i 和 j 可以相等。[0,1]、[1,0]、[1,1] 同样合法。
```

**示例 3**

```text
输入：nums = [1,2,3], indexDifference = 2, valueDifference = 4
输出：[-1,-1]
解释：下标差 >= 2 的数对只有 (0,2)，但 |1-3| = 2 < 4，无解。
```

## 3. 解题思路

### 3.1 暴力思路：枚举所有数对

双重循环枚举全部 $(i, j)$ 对，逐一检查两条约束，命中即返回，$O(n^2)$。

这正是 Q1（$n \le 100$，至多 $10^4$ 次检查）的过签写法。但本题 $n = 10^5$，$O(n^2) = 10^{10}$ 次检查**必然超时**。赛时从 Q1 平移过来的正确反射不是换语言卡常数，而是观察结构：**对每个 $j$，合法的 $i$ 落在 $[0, j - D]$ 中——一个随 $j$ 右移只增不减的候选集**。这是「前缀最值」的信号弹。

### 3.2 核心观察：前缀最值——两个极端代表就是充分证人

![核心观察：候选集单调扩张与数轴夹逼判定](images/index_value_diff_prefix_minmax.svg)

三步把 $O(n^2)$ 压到 $O(n)$：

1. **对称化简**：$\text{abs}(i - j) \ge D$ 关于 $i, j$ 对称，不妨只枚举 $j$、要求 $i \le j - D$——另一半数对交换记号后完全对称。

2. **候选集单调扩张**：$j$ 每右移一格，候选集 $[0, j - D]$ 恰好新增一个元素 $\text{nums}[j - D]$，**只增不减**。于是候选集的最小值、最大值可以用两个变量 $O(1)$ 增量维护，无需任何数据结构。

3. **数轴夹逼判定**：对候选值 $x$，

   $$\text{abs}(\text{nums}[j] - x) \ge V \iff x \le \text{nums}[j] - V \ \text{或}\ x \ge \text{nums}[j] + V$$

   达标的值只能落在数轴上 $\text{nums}[j]$ 左右两侧的「绿区」。候选集的最小值 $mn$ 探向左侧最远、最大值 $mx$ 探向右侧最远——**若存在达标候选，$mn$ 或 $mx$ 必然达标（极端代表走得更远）；若 $mn$、$mx$ 都不达标，全体候选被夹在中间粉区，无一达标**。检查全部候选 $\iff$ 只检查两个代表。

> 💡 **直觉**：「是否存在足够远的值」是存在性问题——两个极端代表就是充分证人。对比 [2817](https://leetcode.cn/problems/minimum-absolute-difference-between-elements-with-constraint/)「找**最近**的值」需要有序集合 + 二分 $O(n \log n)$：「找最远」的信息需求远小于「找最近」。

### 3.3 算法流程

![算法流程：单趟扫描，先纳入后检查两个极端代表](images/index_value_diff_flow.svg)

1. **初始化**：`minIdx = maxIdx = 0`。
2. **遍历** $j$ **从** $D$ **到** $n - 1$：
   - **先纳入**：令 $r = j - D$；若 $\text{nums}[r] < \text{nums}[\text{minIdx}]$ 则 `minIdx = r`，若 $\text{nums}[r] > \text{nums}[\text{maxIdx}]$ 则 `maxIdx = r`；
   - **后检查**：若 $\text{abs}(\text{nums}[j] - \text{nums}[\text{minIdx}]) \ge V$，返回 $[\text{minIdx}, j]$；若 $\text{abs}(\text{nums}[j] - \text{nums}[\text{maxIdx}]) \ge V$，返回 $[\text{maxIdx}, j]$。
3. **遍历结束**：返回 $[-1, -1]$。

> ⚠️ **循环不变式**：检查 $j$ 之前，`minIdx` / `maxIdx` 恰为区间 $[0, j - D]$ 的最值下标。因此必须**先纳入 $r = j - D$、再检查**——顺序反了会漏掉刚解锁的候选（反例见第 8 节第 2 条）。

### 3.4 示例演算

![示例演算：两轮扫描命中答案对](images/index_value_diff_walkthrough.svg)

以示例 1 为例，$\text{nums} = [5, 1, 4, 1]$，$D = 2$，$V = 4$：

| $j$ | 纳入 $r = j - D$ | 候选集 $[0, j-2]$ | minIdx（值） | maxIdx（值） | 检查 min | 检查 max | 动作 |
|-----|-----------------|-------------------|--------------|--------------|----------|----------|------|
| 2 | $r = 0$（值 5） | $\{5\}$ | 0（5） | 0（5） | $\lvert 4 - 5 \rvert = 1 < 4$ ✗ | $\lvert 4 - 5 \rvert = 1 < 4$ ✗ | 继续 |
| 3 | $r = 1$（值 1） | $\{5, 1\}$ | **1（1）** ← 更新 | 0（5） | $\lvert 1 - 1 \rvert = 0 < 4$ ✗ | $\lvert 1 - 5 \rvert = 4 \ge 4$ ✓ | 返回 $[0, 3]$ |

第 2 轮命中 max 代表：$\lvert 1 - 5 \rvert = 4$ **恰好压线** $V = 4$（$\ge$ 含等于），返回 $[0, 3]$，与示例一致。

## 4. 算法细节

1. **为什么 min/max 两个代表就够**：判定「存在差值 $\ge V$ 的候选」是存在性问题。$mn \le \text{nums}[j] - V$ 或 $mx \ge \text{nums}[j] + V$ 与「存在达标候选」互为充要（证明见第 5 节引理 2），且 $mn$、$mx$ 本身就是候选集中的真实元素，检查它们不会误报。

2. **「先纳入后检查」的不变式**：处理 $j$ 时候选集必须是 $[0, j - D]$ 而非 $[0, j - D - 1]$——刚解锁的下标 $j - D$ 恰好是最可能改写最值的新人。这在实现上是唯一容易翻车的顺序问题。

3. **两种等价写法**：① 本文主解——边扫边维护两个下标变量，$O(1)$ 空间；② 官方 hints 的 `pre-compute`——先预处理前缀 min/max 下标数组再扫描，$O(n)$ 空间。思想同源（前缀最值），赛时写 ① 更短更快。

4. **$D \ge n$ 时无解**：循环从 $j = D$ 开始，$D \ge n$ 则循环体一次不执行，自然落到 `return {-1, -1}`，无需特判「下标差门槛高于整个数组」。

5. **无溢出风险**：$\text{nums}[i] \in [0, 10^9]$，差的绝对值 $\le 10^9 < 2^{31} - 1$，`int` 与 `abs` 全程安全。

## 5. 正确性证明

**引理 1（对称化简）**：原问题有解 $\iff$ 存在 $j$ 及 $i \le j - D$ 满足两条约束。

**证明**：（$\Leftarrow$）$i \le j - D$ 蕴含 $\text{abs}(i - j) \ge D$，故 $(i, j)$ 就是原问题的解。（$\Rightarrow$）设 $(i, j)$ 为任意解，由 $\text{abs}(i - j) \ge D$ 知 $i \le j - D$ 或 $j \le i - D$；后者交换 $i, j$ 的记号即化为前者。∎

**引理 2（极端代表判定）**：固定 $j$，记候选集 $S = \{\text{nums}[t] : 0 \le t \le j - D\}$，$mn = \min S$，$mx = \max S$。则

$$\exists\, x \in S,\ \text{abs}(\text{nums}[j] - x) \ge V \iff mn \le \text{nums}[j] - V\ \text{或}\ mx \ge \text{nums}[j] + V$$

**证明**：（$\Leftarrow$）$mn$、$mx$ 均为 $S$ 中的真实元素。若 $mn \le \text{nums}[j] - V$，则 $\text{nums}[j] - mn \ge V$；若 $mx \ge \text{nums}[j] + V$，则 $mx - \text{nums}[j] \ge V$。（$\Rightarrow$）设 $x \in S$ 达标。若 $\text{nums}[j] - x \ge V$ 即 $x \le \text{nums}[j] - V$，则 $mn \le x \le \text{nums}[j] - V$；若 $x - \text{nums}[j] \ge V$ 即 $x \ge \text{nums}[j] + V$，则 $mx \ge x \ge \text{nums}[j] + V$。∎

**定理**：算法返回的下标对满足两条约束；原问题无解时返回 $[-1, -1]$。

**证明**：先证**循环不变式**：每轮检查 $j$ 之前，`minIdx` / `maxIdx` 恰为 $[0, j - D]$ 的最小 / 最大值下标。归纳：首轮 $j = D$，先纳入 $r = 0$ 后集合为 $\{\text{nums}[0]\}$，最值下标均为 0，成立；设某轮成立，下一轮先纳入 $r' = j + 1 - D$，覆盖范围扩张为 $[0, j + 1 - D]$，且两个 `if` 保证最值下标被正确更新，不变式保持。

再证**正确性**。一方面，算法仅在 $\text{abs}(\text{nums}[j] - \text{nums}[\text{minIdx}]) \ge V$（或 max 版）命中时返回，此时 $i = \text{minIdx} \le j - D$ 保证 $\text{abs}(i - j) \ge D$，值差条件即检查条件本身，故**返回值必合法**。另一方面，设原问题有解，由引理 1 存在 $(i, j)$ 且 $i \le j - D$；对该 $j$，由引理 2，$mn \le \text{nums}[j] - V$ 或 $mx \ge \text{nums}[j] + V$ 必居其一，即该轮的两条检查至少一条命中，算法不会走到 `return [-1, -1]`。无解时所有检查均不命中（否则与上一段矛盾），循环结束返回 $[-1, -1]$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。$j$ 从 $D$ 到 $n - 1$ 单趟遍历，每轮「纳入 + 更新最值 + 两次绝对值比较」均为 $O(1)$；$n = 10^5$ 时约 $3 \times 10^5$ 次整数比较，对比暴力的 $10^{10}$ 次检查。
- **空间复杂度**：$O(1)$。仅 `minIdx` / `maxIdx` 两个下标变量（预处理前缀最值数组的写法需 $O(n)$ 空间）。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    vector<int> findIndices(vector<int>& nums, int indexDifference, int valueDifference) {
        int n = nums.size();
        int minIdx = 0, maxIdx = 0;            // 恰为 [0, j - indexDifference] 的最值下标
        for (int j = indexDifference; j < n; j++) {
            int r = j - indexDifference;        // 先纳入新解锁的候选 r = j - D
            if (nums[r] < nums[minIdx]) minIdx = r;
            if (nums[r] > nums[maxIdx]) maxIdx = r;
            if (abs(nums[j] - nums[minIdx]) >= valueDifference) return {minIdx, j};
            if (abs(nums[j] - nums[maxIdx]) >= valueDifference) return {maxIdx, j};
        }
        return {-1, -1};
    }
};
```

### C++（预处理前缀最值版：官方 hints 的静态写法）

```cpp
class Solution {
  public:
    vector<int> findIndices(vector<int>& nums, int indexDifference, int valueDifference) {
        int n = nums.size();
        vector<int> preMin(n), preMax(n);      // preMin[t] / preMax[t] = [0, t] 的最值下标
        preMin[0] = preMax[0] = 0;
        for (int t = 1; t < n; t++) {
            preMin[t] = nums[t] < nums[preMin[t - 1]] ? t : preMin[t - 1];
            preMax[t] = nums[t] > nums[preMax[t - 1]] ? t : preMax[t - 1];
        }
        for (int j = indexDifference; j < n; j++) {
            int r = j - indexDifference;        // r >= 0 恒成立，无需判空
            if (abs(nums[j] - nums[preMin[r]]) >= valueDifference) return {preMin[r], j};
            if (abs(nums[j] - nums[preMax[r]]) >= valueDifference) return {preMax[r], j};
        }
        return {-1, -1};
    }
};
```

```python
            if abs(nums[j] - nums[max_idx]) >= valueDifference:
                return [max_idx, j]
        return [-1, -1]
```

## 8. 边界情况与易错点

1. **$i$ 可以等于 $j$**（题面明示）：$D = V = 0$ 时任何 $[k, k]$ 都合法。算法首轮 $j = 0$、$r = 0$ 纳入自身后 $\text{abs}(0) \ge 0$ 命中，自然返回 $[0, 0]$（示例 2），无需特判。$D \ge 1$ 时 $\text{abs}(i - j) \ge D$ 自动保证 $i \ne j$。
2. **「先纳入后检查」顺序不能反**：反例 `nums = [5, 10, 0]`，$D = 1$，$V = 10$——唯一解是 $[1, 2]$（$\lvert 10 - 0 \rvert = 10 \ge 10$）。若先检查后纳入，处理 $j = 2$ 时候选集只覆盖 $[0, 0]$，漏掉刚解锁的 $r = 1$（值 10），误返回 $[-1, -1]$。
3. **$D \ge n$ 时无解**：如 $n = 1, D = 1$，循环体不执行，直接返回 $[-1, -1]$，无需显式特判。
4. **溢出**：值域 $[0, 10^9]$，差的绝对值 $\le 10^9 < 2^{31} - 1$，`int` 安全；若值域抬到 $2^{31}$ 量级需换 `long long`。
5. **最值更新的比较符号**：用严格 `<` / `>` 保留**更早**的最值下标；改成 `<=` / `>=` 也正确（答案任意一组即可），只是返回的下标可能不同。
6. **返回顺序**：按「$i$ 在前、$j$ 在后」返回 $[\text{minIdx}, j]$；题目不要求字典序最小，$[j, \text{minIdx}]$ 同样合法。
7. **别混淆 $D$ 与 $V$ 的约束对象**：$D$ 约束**下标距离**、$V$ 约束**值差**。$D = 0$、$V > 0$ 时 $i = j$ 的差恒为 0 必不达标，等价于要求 $i \ne j$——算法此时把 $\text{nums}[j]$ 自己也纳入候选，但 $0 < V$ 的检查天然滤掉它，依然正确。

**延伸思考**：

- 若要求 $i \ne j$ **严格成立**：$D = 0$ 时 $[k, k]$ 不再合法——把候选集换成 $[0, j - 1]$（即 $D' = \max(D, 1)$），其余一字不改。
- 若值约束改为「差**恰好**等于 $V$」：达标值不再连成两侧区间，min/max 代表失效，需哈希表逐个查询 $\text{nums}[j] \pm V$ 是否出现在候选集中，仍可 $O(n)$。
- 若下标约束改为 $\text{abs}(i - j) \le D$（窗口而非前缀）：候选集有进有出，两个变量的增量维护失效，换单调队列 $O(n)$——正是 239 的舞台。
- 若要求返回**所有**满足条件的数对：输出规模本身可达 $O(n^2)$（如全 0 数组、$D = V = 0$），不可能低于平方复杂度；但「判定存在 + 输出一组」始终是本题的 $O(n)$。
