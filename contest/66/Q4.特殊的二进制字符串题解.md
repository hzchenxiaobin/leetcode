# LeetCode 特殊的二进制字符串 题解

## 1. 题目概述

- **标题 / 题号**：特殊的二进制字符串（#761，hard）
- **链接**：https://leetcode.cn/problems/special-binary-string/
- **来源**：LeetCode 第 66 场周赛 Q4
- **难度**：困难
- **标签**：字符串，分治，排序，括号匹配（官方标签：String、Divide and Conquer、Sorting）

**题意**：若二进制串中 `0` 与 `1` 的数量相等，且**每个前缀**都满足 `1` 的个数不少于 `0` 的个数，则称它为**特殊串**。给定特殊串 `s`，一次操作可以选择 `s` 中两个**相邻**的非空特殊子串并交换（相邻指前者末字符与后者首字符下标相差 1）。求任意次操作后能得到的**字典序最大**串。

**约束**：

- $1 \le \lvert s \rvert \le 50$
- `s[i]` 为 `'0'` 或 `'1'`
- 输入保证 `s` 是特殊串，因此 $\lvert s \rvert$ 必为偶数

> 💡 把 `1` 看成左括号、`0` 看成右括号，两条性质恰好是**合法括号串**的定义（括号等量 + 任意前缀左括号不少于右括号）。于是本题可以改写成：**只允许交换相邻的完整括号块，把括号串变成字典序最大**。整个解法都建立在这个视角上。

## 2. 示例

**示例 1**

```text
输入：s = "11011000"
输出："11100100"
解释：把 s[1] 处的 "10" 与 s[3] 处的 "1100" 交换，得到 "11100100"，这是若干次操作后字典序最大的结果。
```

**示例 2**

```text
输入：s = "10"
输出："10"
解释：串中只有一个特殊子串（它自己），任何操作都无法执行，答案即原串。
```

**补充示例（非官方，用来说明"顶层块可以任意换序"）**

```text
输入：s = "101100"
输出："110010"
解释："101100" 可切成两个顶层块 "10" 与 "1100"，交换后得 "110010"；
      注意块 "1100" 自身 = 1·(10)·0，内层 "10" 已是最优，无法再变大。
```

## 3. 解题思路

### 3.1 暴力思路

最直白的做法是**搜索**：以当前串为状态，枚举所有满足"两个相邻非空特殊子串"的交换（起点 $i$、切点 $j$、终点 $k$，共 $O(n^3)$ 种三元组），做 BFS 收集全部可达串，取字典序最大者。

状态数是什么量级？仅考虑"把 $k$ 个顶层块任意排列"这一层，就有 $k!$ 种，而嵌套结构还会叠加乘性爆炸。$n = 50$ 时可达串数量远超天文数字，BFS 必然超时——但它恰好可以写成**对拍用的小数据暴力**：$n \le 14$ 时状态有限，用来验证正解非常方便（本文验证脚本正是这么做的）。

> 💡 暴力的病根不是"枚举得不够聪明"，而是**没看出嵌套结构**：特殊子串之间的交换只可能发生在"同一层的相邻块"上，不同层的块永远无法跨越。

### 3.2 核心观察：括号视角下的唯一"块分解"

![1 记 +1、0 记 −1 的山脉视角](images/wc66_q4_mountain_model.svg)

定义**前缀高度** $h(i)$ 为 $s[0..i]$ 中 `1` 的个数减去 `0` 的个数，把 `1` 当上坡、`0` 当下坡。特殊串就是"全程高度非负、末位回到 0"的折线，也就是一座（可能带多个山峰的）山脉。三个关键事实：

1. **首尾固定**：非空特殊串必以 `1` 开头、以 `0` 结尾（否则第一个前缀或倒数第二个前缀就会突破高度 0，见 §5 引理 1）。
2. **块分解唯一**：沿折线走，每当高度**回到 0** 就切一刀，得到 $s = M_1 M_2 \cdots M_k$。每个 $M_i$ 内部高度严格为正，称为**本原块**（对应括号语言里的本原 Dyck 词）。切点由"高度为 0 的下标集合"唯一确定，不依赖任何选择。
3. **块形如 $1 \cdot A_i \cdot 0$**：$M_i$ 首 `1` 末 `0`，剥掉这一层外壳后，中段 $A_i$ 仍然是一个特殊串（可以理解为这座山的"内部地形"），且可以是空串（此时 $M_i = $ `"10"`）。

于是问题被压成**两层**：

- **同层重排（块与块之间）**：$M_1, \dots, M_k$ 是**相邻**的特殊子串，一次交换可以重排它们，而相邻对换能生成**任意排列**；
- **块内递归（块内部）**：只有中段 $A_i$ 里的东西能动，外壳 `1` 与 `0` 只是被固定在两端，所以对 $M_i$ 的最优化等价于对 $A_i$ 的最优化。

> ⚠️ 关键结论：**跨块的交换只能整体搬运"连续的若干完整块"**。因为两个相邻特殊子串的分界若落在块内部，则二者各自都无法延伸到块外（块内高度为正，越界就把高度压到 0 以下）。这条性质是 §5 引理 3 的内容，也是"递归 + 排序"能成立的根据。

### 3.3 算法流程

![切块、递归、包回、降序拼接的流程](images/wc66_q4_algorithm_flow.svg)

**递归函数 `dfs(s)`**：

1. **扫描切块**：`bal` 从 0 开始，遇 `1` 加一、遇 `0` 减一；`bal` 每次归 0 就切出 `s[start..i]`，并令 `start = i + 1`。
2. **剥壳递归**：对每个块，取中段 `middle = s[start+1 .. i-1]`，递归求 `dfs(middle)`，再包回外壳，得到 `"1" + dfs(middle) + "0"`，存入 `parts`。
3. **降序排序**：把 `parts` 按字典序**降序**排序。
4. **拼接返回**：`parts` 顺序拼接即为 `dfs(s)` 的答案；外层调用拿到返回值后再包回自己的外壳，逐层向上。

递归出口：`s` 为空串或 `s == "10"` 时直接返回 `s`（此时不存在两个相邻非空特殊子串，无操作可做）。

> 💡 为什么排序用**普通字典序降序**就够，不需要 [179. 最大数](https://leetcode.cn/problems/largest-number/) 里 $a+b$ 与 $b+a$ 的自定义比较器？因为本原块**互不为前缀**（若有 $M_i$ 是 $M_j$ 的真前缀，则 $M_j$ 在 $\lvert M_i \rvert$ 处高度已归 0，就不再本原），而对互不为前缀的串，$a < b$ 与 $a+b < b+a$ 同真同假，普通 `sort` 即最优。

### 3.4 示例演算

![11011000 的递归走查](images/wc66_q4_walkthrough.svg)

| 步骤 | 观察 | 结果 |
|------|------|------|
| ① 最高层扫描 | 高度序列 $1,2,1,2,3,2,1,0$，只在末位归 0 | 整串是一个块：`1 · (101100) · 0` |
| ② 递归中段 `101100` | 高度序列 $1,0,1,2,1,0$，第 2、6 位归 0 | 切成 `10` 与 `1100` |
| ③ 处理块 `10` | 中段为空，`dfs("") = ""` | 包回得 `1 + "" + 0 = 10` |
| ④ 处理块 `1100` | 中段 `10`，`dfs("10") = "10"` | 包回得 `1 + 10 + 0 = 1100` |
| ⑤ 本层降序排序 | `"1100" > "10"` | 中段拼成 `110010` |
| ⑥ 包回最外层 | `1 + 110010 + 0` | 答案 `11100100` ✓ |

官方解释的那次交换恰好对应第 ⑤ 步：把 `s[1]` 起的 `"10"` 与 `s[3]` 起的 `"1100"` 换位。注意原中段是 `101100`，最大形态是 `110010`——**第 2 位从 `0` 变成 `1`，字典序立刻变大**。

## 4. 算法细节

1. **`bal` 必须按块独立计数**。代码用 `start` 指针隐式复位：块首字符必为 `1`，`bal` 自然从 1 起、在块末回到 0，切片后 `start = i + 1` 即可，无需显式清零。
2. **递归的是中段，不是整段**：`parts.append("1" + dfs(middle) + "0")`。若把整个块 `chunk` 丢进递归，会把刚剥掉的外壳又剥一次（甚至切片错位），结构立刻被破坏。
3. **切片下标**：C++ 用 `s.substr(start + 1, i - start - 1)`（第二参数是**长度**）；Python 用 `s[start + 1:i]`（右端开区间）。写成 `s[start + 1:i + 1]` 会把块尾的 `0` 带进中段，中段就不再平衡。
4. **降序排序**：C++ 用 `greater<string>()`，Python 用 `parts.sort(reverse=True)`。块数 $k = 1$ 时排序是空操作，无需特判。
5. **递归出口**：`len(s) <= 2` 直接返回。空串只会来自"中段为空"，`"10"` 是最小特殊串；这两个输入进循环也不会执行任何一次切块，结果相同，但显式出口更清晰，也省掉函数内的循环开销。
6. **保持"块长度不变"这个不变量**：交换只改变块的相对位置与内部顺序，任何块的字符数、`1`/`0` 的个数都不变。因此"同层排序"只需比较固定长度的串，比较在第一个相异位就决出胜负。
7. **不依赖特殊串以外的输入**：题面保证 `s` 是特殊串，所以第一层切分必然恰好走完整串；若把函数用于非特殊串，`bal` 可能在中途变负或末尾不归 0，此时应额外判非法（本题不需要）。

## 5. 正确性证明

**引理 1（首尾固定）**：任何非空特殊串 $s$（长度 $n$）满足 $s_0 = 1$ 且 $s_{n-1} = 0$。

**证明**：若 $s_0 = 0$，则长度为 1 的前缀里 `1` 的个数为 $0 < 1$，违反「前缀中 `1` 不少于 `0`」。若 $s_{n-1} = 1$，由 `0` 与 `1` 等量可知前 $n-1$ 个字符里 `0` 比 `1` 多 1，这个前缀本身就不满足「`1` 不少于 `0`」，同样矛盾。∎

**引理 2（块分解存在且唯一）**：非空特殊串 $s$ 可唯一地写成 $s = M_1 M_2 \cdots M_k$（$k \ge 1$），其中每个 $M_i$ 的首字符为 `1`、末字符为 `0`，去掉这两个字符得到中段 $A_i$（可为空串）仍是特殊串，并且 $M_i$ 内部各位置（相对 $M_i$ 起点）的高度除两端外严格为正。

**证明**：**存在性**：设高度序列 $h$，取所有满足 $h(i) = 0$ 的下标 $i$（$s$ 末尾必在其中，因 $s$ 特殊），相邻两个零点之间切出一段 $M_i$。段内相对高度严格为正，故块内没有别的零点，即不可再切。由引理 1，$M_i$ 首 `1` 末 `0`，剥壳得 $A_i$：$A_i$ 中 `1` 与 `0` 等量（$M_i$ 等量且首末恰好一 `1` 一 `0`），前缀非负（段内相对高度处处 $\ge 0$），故 $A_i$ 特殊。**唯一性**：零点集合 $\{i : h(i) = 0\}$ 由 $s$ 唯一确定，切法随之唯一。∎

**引理 3（特殊子串的结构）**：设 $s = M_1 \cdots M_k$ 为块分解，$T = s[p..q]$ 是特殊子串。若 $p$ 严格位于某个 $M_i$ 内部，则 $T$ 整体落在 $M_i$ 内；若 $p$ 是块边界（某个块的起点），则 $q$ 也是块边界，$T$ 恰为若干**连续完整块**的拼接。

**证明**：记 $L = h(p)$。$T$ 特殊意味着对所有 $p \le j \le q$ 有 $h(j) \ge L$，且 $h(q) = L$。

- 若 $p$ 严格位于 $M_i$ 内部，则 $L > 0$（块内相对高度为正，而块起点高度为 0）。$M_i$ 右端点的高度是 $0 < L$，若 $T$ 越过它就会被破坏，故 $T \subseteq M_i$。
- 若 $p$ 恰是某块起点，则 $L = 0$（每个块自身平衡，故所有块边界的高度都是 0）。若 $q$ 落在某块内部且不是块右端点，则该处相对高度严格为正，绝对高度也 $> 0 = L$，不可能成立；故 $q$ 必是块边界，$T = M_i M_{i+1} \cdots M_j$。∎

**推论（操作只有两种形态）**：(a) 交换完全发生在某个 $M_i$ 内部，等价于对 $A_i$ 做一次操作；(b) 交换两段连续完整块，即对块序列做一次「相邻段对换」。此外 $\mathcal{R}(M_i) = \{\, 1 \cdot c \cdot 0 : c \in \mathcal{R}(A_i) \,\}$——$M_i$ 内可执行的交换恰好是 $A_i$ 内的交换，外壳 `1`、`0` 永远被固定在首末。于是可达集为
$$\mathcal{R}(s) = \bigl\{\, \sigma(b_1, \dots, b_k) : b_i \in \mathcal{R}(M_i),\ \sigma \in S_k \,\bigr\}.$$

**定理**：`dfs(s)`（按 §3.3 的递归定义）返回 $\mathcal{R}(s)$ 中字典序最大的串。

**证明**：对 $n = \lvert s \rvert$ 归纳。$n \le 2$ 时 $s$ 是空串或 `"10"`，唯一的特殊子串就是它自己，凑不出「两个相邻的非空特殊子串」，无操作可做，答案即 $s$，成立。

设 $n > 2$，取块分解 $s = M_1 \cdots M_k$，记 $c_i = 1 \cdot \mathrm{dfs}(A_i) \cdot 0$。由归纳假设，$c_i$ 是 $\mathcal{R}(M_i)$ 的最大元。

*第一步：固定排列时逐块取最大不劣。* 任取排列 $\sigma$ 与 $b_i \in \mathcal{R}(M_i)$，把 $\sigma(b_1, \dots, b_k)$ 中每块原位换成 $c_i$。由推论 $\lvert b_i \rvert = \lvert c_i \rvert = \lvert M_i \rvert$，替换不改变任何块的起止下标；取第一个满足 $b_i \ne c_i$ 的块，两串在该块内的第一处差异来自 $b_i < c_i$，故替换后的串 $\ge$ 原串。因此只需在「排列」上求最优。

*第二步：降序排列最优。* 由引理 2，各块内部零点只有两端，故任意两块互不为前缀：若 $M_i$ 是 $M_j$ 的真前缀，则 $M_j$ 在 $\lvert M_i \rvert$ 处的相对高度已归 0，与「内部除两端外严格为正」矛盾。对互不为前缀的 $a, b$，设首个相异位为 $t$：$a+b$ 与 $b+a$ 的前 $t$ 位相同，第 $t$ 位分别是 $a_t$ 与 $b_t$，故 $a \le b \iff a + b \le b + a$。于是排列中只要有相邻两块满足 $a < b$，交换后串严格变大；每次严格变大且状态有限，过程必然终止，终止时不存在相邻逆序，即块序列按字典序降序。因此降序拼接是 $\{\sigma(c_1, \dots, c_k)\}$ 的最大元。

两步合并：`dfs(s)` 输出的降序拼接等于 $\mathcal{R}(s)$ 的最大元。∎

## 6. 复杂度分析

- **时间**：最坏 $O(n^2 \log n)$。**扫描**：每个字符会被它的所有祖先节点各扫一次，嵌套深度最多 $n/2$，故扫描总代价 $O(n^2)$。**排序**：所有节点合计的「块比较」次数为 $O(n \log n)$——各节点块数总和与节点数同阶（$O(n)$），单个节点的比较次数 $O(k_v \log k_v) \le O(k_v \log n)$；每次比较最坏扫 $O(n)$ 个字符，于是总代价 $O(n^2 \log n)$。$n \le 50$ 时真正执行的字符操作只有几千次。
- **空间**：递归栈 $O(n)$；各层同时存活的中段切片规模为 $O(n^2)$ 最坏（形如 `111…000` 的完全嵌套时，切片长度 $n-2, n-4, \dots$ 累加约 $n^2/4$），$n \le 50$ 时不足 1 KB。若不计切片复制，则辅助空间为 $O(n)$。

> 💡 由于 $n \le 50$，几乎任何正确实现都能通过。本题的分数全在**识别括号结构 + 想清"块能换序、外壳不能动"**这两点上。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    string makeLargestSpecial(string s) {
        vector<string> parts;
        int bal = 0, start = 0;
        for (int i = 0; i < (int)s.size(); ++i) {
            bal += (s[i] == '1') ? 1 : -1;
            if (bal == 0) {                                  // 顶层块 [start, i]
                string middle = s.substr(start + 1, i - start - 1);   // 剥掉首 1 末 0
                parts.push_back("1" + makeLargestSpecial(middle) + "0");
                start = i + 1;
            }
        }
        sort(parts.begin(), parts.end(), greater<string>());  // 本原块互不为前缀
        string res;
        for (const string& p : parts) res += p;
        return res;
    }
};
```

### Python

```python
class Solution:
    def makeLargestSpecial(self, s: str) -> str:
        parts, bal, start = [], 0, 0
        for i, ch in enumerate(s):
            bal += 1 if ch == '1' else -1
            if bal == 0:                       # 顶层块 [start, i]
                middle = s[start + 1:i]        # 剥掉首 1 末 0
                parts.append('1' + self.makeLargestSpecial(middle) + '0')
                start = i + 1
        parts.sort(reverse=True)               # 本原块互不为前缀，普通降序即最优
        return ''.join(parts)
```

## 8. 边界情况与易错点

1. **`"10"` 与空串**：最小特殊串没有任何可交换对象，必须原样返回；中段为空时 `dfs("")` 返回空串，外壳包回得 `"10"`，逻辑自然闭合。
2. **完全嵌套**：形如 `1` 重复 $m$ 次接 `0` 重复 $m$ 次（如 25 个 `1` 后接 25 个 `0`）。每层只有一个块，排序无效，答案就是原串本身——不要误以为"总能变大"。
3. **同层块全部相等**：如 `"101010"`，排序结果不变；用 `greater<string>()` 稳定与否都不影响答案，但不要依赖"交换一定会变优"。
4. **`start` 忘记前移**：切块后必须 `start = i + 1`，否则下一轮会把两个块连在一起切片，中段不再平衡、甚至越界。
5. **中段切片差一**：C++ 的 `substr(start + 1, i - start - 1)` 第二参数是长度；Python 的 `s[start + 1:i]` 是右开区间。写成 `s[start + 1:i + 1]` 会把块尾 `0` 带进中段。
6. **误用"最大数"比较器**：`a+b` 与 `b+a` 的比较在本题虽不致命，但会掩盖"本原块互不为前缀"这一关键性质，且让每次比较从「首处相异位即止」退化成一次 $O(\lvert a \rvert + \lvert b \rvert)$ 的拼接。

**延伸思考**：

1. **最小字典序版本**：把降序改成升序即可，证明只需把 §5 定理第二步的交换论证反向（相邻逆序换成升序逆序）；"外壳包回"的顺序不受影响，仍是先递归中段再排序。
2. **数一数有多少个不同的可达串**：由推论，可达串 = 各层块的排列，若同层各不同块的出现次数为 $c_1, c_2, \dots$（$\sum c_j = k$），则该层贡献 $\dfrac{k!}{\prod_j c_j!}$ 种，各层互不影响（块内最优形态唯一确定），答案是对各层取乘积累乘。
3. **若允许交换任意两个（不相邻）特殊子串**：答案不变。因为相邻对换已能生成任意排列，放宽限制不会增强表达能力；反之若**只允许**交换单个顶层块（不允许整段搬运），仍能生成全部排列，答案同样不变。
4. **推广到 $k$ 种符号**：把"1 比 0 优先"换成任意两两比较的字符序，只要保持"前缀偏序 + 等量"的结构，"本原块 + 降序拼接"的框架仍然适用，这就是广义 Dyck 词上的重排问题。
