# LeetCode 第K大的完美二叉子树的大小 题解

## 1. 题目概述

- **标题 / 题号**：第K大的完美二叉子树的大小（#3319，medium）
- **链接**：https://leetcode.cn/problems/k-th-largest-perfect-subtree-size-in-binary-tree/
- **来源**：LeetCode 第 419 场周赛 Q2
- **难度**：中等
- **标签**：树、深度优先搜索、二叉树、排序

**题意**：给出一棵二叉树的根节点 `root` 和整数 `k`。统计树中所有**完美二叉子树**的大小（节点数），返回第 $k$ 大的；若完美子树不足 $k$ 个，返回 $-1$。**完美二叉树**指所有叶子都在同一层级、且每个父节点**恰好有两个**子节点的树。

**约束**：

- 树中节点数目 $n \in [1, 2000]$
- $1 \le \text{Node.val} \le 2000$
- $1 \le k \le 1024$

> 💡 **读题关键**：四个决定思路走向的细节——① 「子树」指**以某节点为根的完整子结构**（该节点连同其全部后代），不是任意连通子图；② 完美子树**可以嵌套**——完美树的每个节点各自是一棵完美子树的根，统计对象是「每个节点为根的子树是否完美」，个数可达 $n$（示例 2 的大小序列有 7 项）；③ 「第 $k$ 大」按**非递增**排序取第 $k$ 个，**相同大小重复计数**（示例 1 的两个 3）；④ $n \le 2000 < 2047 = 2^{11} - 1$ 把完美子树高度压到 $\le 10$——大小只有约 10 种取值，这个「值域极窄」的观察藏着 $O(n)$ 的桶计数优化（见 §4）。

## 3. 解题思路

### 3.1 暴力思路：逐节点整棵复查

最直白的翻译：遍历每个节点 $u$，调用一次 `isPerfect(u)` 完整扫描 $\text{subtree}(u)$——递归检查「每个内部节点是否恰有两孩子」并比较「左右子树高度是否相等」。单次检查代价为 $O(|\text{subtree}(u)|)$，最坏（链状树）总代价 $O(n^2)$，$n = 2000$ 时约 $4 \times 10^6$ 次节点访问，**能过但全是浪费**。

浪费在哪？检查节点 $u$ 时已经把它的子树完整扫过、**左右子树的高度都算出来了**；轮到检查 $u$ 的孩子时又把同样的子树再扫一遍。父问题的判定材料（孩子的高度与完美性）在递归回溯时**天然经过父节点手里**，白白丢掉——这正是后序遍历的用武之地，也是周赛树题的最高频套路：**一次 DFS，自底向上把子结构结论「上传」**。

### 3.2 核心观察：完美性自底向上可分解，后序传高度

![核心观察：完美性递归分解为「左右子树完美 ∧ 等高」](images/kth_perfect_recursive_definition.svg)

完美二叉树的定义天然是**递归的**：

$$\text{subtree}(u) \text{ 完美} \iff \text{左子树完美} \wedge \text{右子树完美} \wedge h_L = h_R$$

三个条款逐一看：

- **叶子**：左右皆空，$h_L = h_R = 0$，两个「空树完美」自动成立 → 叶子完美，高度 1，大小 1；
- **单孩子节点**：一空一非空，空侧高度 0、非空侧高度 $\ge 1$，$h_L \ne h_R$ → 不完美，**无需特判**；
- **双子节点**：两孩子都完美且高度相等 → 完美，高度 $h_L + 1$，大小 $2^{h_L + 1} - 1$。

于是设计 `dfs(node)` 返回**该子树的高度**，用 $-1$ 作哨兵表示「不完美」：空节点返回 $0$；`hl < 0` 或 `hr < 0` 或 `hl != hr` 返回 $-1$；否则 $h = h_L + 1$，**记录大小 $2^h - 1$**，返回 $h$。

两个设计决策值得咀嚼：

> 💡 **为什么传高度而不是大小？** 完美二叉树的大小被高度唯一决定：高度 $h$ 的完美树恰有 $2^h - 1$ 个节点（高度 1 的叶 + 「根 + 两棵等高完美子树」逐层翻倍）。判「左右等高」与判「左右等大」在两边都完美时等价，但高度是递归比较中**直接可得**的量，且把「大小」留到判定成功后一次算出，职责更清晰。

> ⚠️ **`-1` 只向上传播，不影响横向**：某节点判为不完美后，它**左右子树里已记录的完美子树全部有效**——示例 1 中节点 `3` 因左右高度不等（2 vs 1）不完美，但它的左孩子（大小 3）和右孩子（大小 1）早已各自入列。后序顺序保证「先孩子后父亲」，父亲判负绝不回滚孩子的功劳。

### 3.3 算法流程

![算法流程：后序 DFS 收集大小，降序取第 k 大](images/kth_perfect_dfs_flow.svg)

**`dfs(node)` 完整步骤**（返回 `int` 高度）：

1. **空节点**：返回 `0`（空树高度约定为 0，不拖累父节点）；
2. **递归左右**：`hl = dfs(node.left)`，`hr = dfs(node.right)`（后序：先算孩子）；
3. **判定**：`hl < 0 || hr < 0 || hl != hr` → 返回 `-1`；
4. **记录**：`h = hl + 1`，把 $2^h - 1$ 追加进 `sizes`，返回 `h`。

**主流程**：

1. `dfs(root)` 收集全部完美子树大小（每个节点至多贡献一项，共 $\le n$ 个）；
2. `sizes` **降序排序**；
3. 若 `len(sizes) >= k` 返回 `sizes[k-1]`，否则返回 `-1`。

### 3.4 示例演算

![示例 1 演算：后序逐步判定，收集 8 个大小后降序取第 2 大](images/kth_perfect_example_walkthrough.svg)

以示例 1 完整走一遍（后序序列 `1, 8, 5, 2, 3, 6, 8, 5, 7, 6, 5`）：

- 叶子 `1`、`8`：`hl = hr = 0` → 高度 1，各记一个大小 1；
- 节点 `5`（3 的左子）：两叶等高 → 高度 2，记 $2^2 - 1 = 3$；
- 叶 `2`：记 1；
- 节点 `3`：$h_L = 2 \ne h_R = 1$ → 返回 $-1$，不记录；
- 叶 `6`、`8`：各记 1；节点 `5`（6 的左子）：记 3；叶 `7`：记 1；
- 节点 `6`：$h_L = 2 \ne h_R = 1$ → $-1$；根 `5`：左子树已 $-1$ → $-1$。

共收集 $[1, 1, 3, 1, 1, 1, 3, 1]$ 八个大小，降序 $[3, 3, 1, 1, 1, 1, 1, 1]$，$k = 2$ → 答案 $3$，与题面解释的序列逐项一致。

## 4. 算法细节

1. **返回值设计**：`dfs` 返回高度而非大小或布尔。高度同时服务两个判定条款——「等高比较」与「$-1$ 哨兵传播」；大小留到判定成功后由公式 $2^h - 1$ 一次算出。
2. **空节点返回 0**：空树约定高度 0，与叶子的 1 **错开一格**——单孩子节点空侧 0、实侧 $\ge 1$，被 `hl != hr` 自然淘汰，省掉一整段「孩子存在性」特判。
3. **判定次序**：`hl < 0 || hr < 0 || hl != hr` 三条件**必须先查负再查不等**。若漏掉 `< 0` 检查，两个孩子都返回 $-1$ 时 `hl == hr` 成立，会把「孩子都不完美」误判成「等高完美」——这是本题最隐蔽的 WA 点。
4. **记录口径**：`sizes` 每项对应**一个节点为根的完美子树**，嵌套完美子树由内部节点各自贡献（示例 2 的 7 项 = 每个节点一项）；相同大小不去重。
5. **主流程**：降序排序后 `sizes[k-1]` 即第 $k$ 大（含重复），`len(sizes) < k` 时返回 $-1$（示例 3）。
6. **值域观察（可选优化）**：$n \le 2000 < 2^{11} - 1$ 限制高度 $h \in [1, 10]$，大小只有 $\{1, 3, 7, \ldots, 1023\}$ 共 10 种取值——开高度桶 `cnt[h]` 计数，从高到低逐桶扣减 $k$，命中即返回 $2^h - 1$，排序的 $O(n \log n)$ 被压成 $O(n + \log n)$。$n = 2000$ 下两者都瞬时通过，桶版胜在思想：「第 $k$ 大」类问题第一步先问**值域**。

## 5. 正确性证明

**引理 1（递归刻画）**：对任意节点 $u$，约定空树高度为 0，则

$$\text{subtree}(u) \text{ 完美} \iff \text{（} u \text{ 为叶子）} \vee \text{（} u \text{ 有两孩子} \wedge \text{两孩子子树均完美} \wedge h_L = h_R \text{）}$$

**证明**：（$\Rightarrow$）设 $\text{subtree}(u)$ 完美，即所有叶子同层且每个内部节点恰有两孩子。若 $u$ 为叶，得证。否则 $u$ 恰有两孩子 $L, R$；$L$ 的内部节点在 $u$ 树中仍是内部节点，故各有两孩子，且 $L$ 的叶子就是 $u$ 树的叶，全部同层——所以 $L$ 完美，同理 $R$ 完美。任取 $L$ 的叶与 $R$ 的叶，都是 $u$ 树的叶故同层，而两子树内叶层各自唯一，得 $h_L = h_R$。（$\Leftarrow$）若 $u$ 为叶，单节点平凡完美。若 $u$ 有两孩子且两子树完美、等高 $h$：$u$ 树的内部节点 = $u$ ∪ 两子树的内部节点，每个都恰有两孩子；$u$ 树的叶 = $L$ 的叶 ∪ $R$ 的叶，前者相对 $u$ 的深度为 $h + 1$，后者亦然——所有叶同在第 $h+1$ 层，故完美。∎

**推论**：只有一个孩子的节点 $u$ 是内部节点却不满足「恰有两孩子」，故 $\text{subtree}(u)$ 不完美；算法中其空侧高度 0、实侧高度 $\ge 1$，`hl != hr` 恰好判负。

**引理 2（大小公式）**：高度 $h$ 的完美二叉树恰有 $2^h - 1$ 个节点。

**证明**：对 $h$ 归纳。$h = 1$：单节点，$2^1 - 1 = 1$。设高度 $h$ 时成立；高度 $h+1$ 的完美树 = 根 + 两棵高度 $h$ 的完美子树（由引理 1 的 $\Leftarrow$ 方向，其结构恰为如此），节点数 $1 + 2(2^h - 1) = 2^{h+1} - 1$。∎

**引理 3（无遗漏无重复）**：算法记录的多重集恰为 $\{ \text{size}(\text{subtree}(u)) : u \text{ 的子树完美} \}$（相同大小重复保留）。

**证明**：`dfs` 自根出发、每节点递归左右各一次，访问每个节点恰一次。在节点 $u$ 处，递归调用的返回值正确给出 $h_L, h_R$ 与孩子的完美性（对子树高度归纳：归纳基础是空节点返回 0 与引理 1 的叶子情形）。由引理 1，`hl < 0 || hr < 0 || hl != hr` 与「$\text{subtree}(u)$ 不完美」互为否定，判定精确；判定通过时由引理 2，记录的 $2^{h_L + 1} - 1$ 即该完美子树的大小。故每个完美子树根 $u$ 恰贡献一项，非完美节点零贡献。∎

**定理**：算法返回第 $k$ 大的完美子树大小；完美子树少于 $k$ 个时返回 $-1$。

**证明**：由引理 3，`sizes` 是全部完美子树大小构成的多重集（$m \le n$ 项）。「第 $k$ 大（相同大小重复计数）」即该多重集降序排列后的第 $k$ 项：$m \ge k$ 时排序后取 `sizes[k-1]` 正确；$m < k$ 时第 $k$ 大不存在，返回 $-1$，与题意一致。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \log n)$。DFS 部分：每个节点做 $O(1)$ 的比较、记录与一次递归返回，合计 $O(n)$；排序部分：对 $m \le n \le 2000$ 个大小排序 $O(m \log m)$。若采用 §4 的高度桶计数，降为 $O(n + \log n)$。
- **空间复杂度**：$O(n)$。递归栈最坏为链状树的深度 $O(n)$（$n = 2000$），`sizes` 至多 $n$ 项。
- **对照暴力**：逐节点整棵复查为 $O(n^2)$（链状树最坏，每次检查白扫一整段子树），$n = 2000$ 时约 $4 \times 10^6$ 次节点访问——能过，但一次后序 DFS 才是这题的「正确姿势」。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int kthLargestPerfectSubtree(TreeNode* root, int k) {
        vector<int> sizes;
        dfs(root, sizes);
        sort(sizes.begin(), sizes.end(), greater<int>());   // 降序取第 k 大
        return (int)sizes.size() >= k ? sizes[k - 1] : -1;
    }

  private:
    // 返回该子树的高度；-1 表示不是完美二叉树。空树约定高度 0
    int dfs(TreeNode* node, vector<int>& sizes) {
        if (!node) return 0;
        int hl = dfs(node->left, sizes);
        int hr = dfs(node->right, sizes);
        if (hl < 0 || hr < 0 || hl != hr) return -1;        // 孩子不完美 / 高度不等
        sizes.push_back((1 << (hl + 1)) - 1);               // 高度 h = hl+1 → 大小 2^h − 1
        return hl + 1;
    }
};
```

### Python

```python
class Solution:
    def kthLargestPerfectSubtree(self, root: Optional[TreeNode], k: int) -> int:
        sizes = []

        def dfs(node: Optional[TreeNode]) -> int:      # 返回高度；-1 表示不完美
            if not node:
                return 0                               # 空树约定高度 0，不拖累父节点
            hl = dfs(node.left)
            hr = dfs(node.right)
            if hl < 0 or hr < 0 or hl != hr:
                return -1                              # 孩子不完美 / 高度不等
            sizes.append((1 << (hl + 1)) - 1)          # 高度 h = hl+1 → 大小 2^h − 1
            return hl + 1

        dfs(root)
        sizes.sort(reverse=True)                       # 降序取第 k 大
        return sizes[k - 1] if len(sizes) >= k else -1
```

## 8. 边界情况与易错点

1. **判定次序**：`hl < 0 || hr < 0` 必须排在 `hl != hr` 之前——两个孩子都返回 $-1$ 时 `hl == hr` 成立，漏查负号会把「双不完美」误判成「等高完美」（§4 第 3 点，本题最隐蔽的 WA）。
2. **空节点返回 0 而非 −1**：空树高度 0 与叶子高度 1 错开一格，单孩子情形被高度不等自然淘汰；若空节点返回 $-1$，「孩子为空」与「孩子不完美」两种语义搅在一起，叶子反而要特判。
3. **相同大小重复计数**：示例 1 的两个 3 占据第 1、2 名；若题面改成「第 $k$ 大的**不同**大小」需先去重——语义差异是这类题最常见的澄清点。
4. **总数不足返回 −1**：`len(sizes) < k` 时输出 $-1$（示例 3 序列仅 `[1, 1]`）；C++ 取 `sizes[k-1]` 前必须查 `size() >= k`，否则越界。
5. **「子树」语义**：统计单位是「每个节点为根的完整子结构」，嵌套完美子树全部入列（示例 2 的 7 项）——别只统计「极大完美块」。
6. **移位不溢出**：$h \le 10$（$n \le 2000 < 2^{11} - 1$），`1 << 11` 远在 `int` 范围内；本题无溢出风险。
7. **Python 递归深度**：链状树递归深度最坏 $n = 2000$，逼近默认限制；评测环境栈紧时加 `sys.setrecursionlimit(5000)`，或改为显式栈迭代后序。C++ 无此顾虑。
8. **值域提示别浪费**：$k \le 1024 = 2^{10}$ 与 $n \le 2000 < 2^{11} - 1$ 相互印证「高度 $\le 10$」——数据范围本身就是「桶计数可行」的暗示。
