# LeetCode 最小差值平方和 题解

## 1. 题目概述

- **标题 / 题号**：最小差值平方和（#2333，medium）
- **链接**：https://leetcode.cn/problems/minimum-sum-of-squared-difference/
- **来源**：LeetCode 第 82 场双周赛 Q3
- **难度**：中等
- **标签**：贪心、数组、二分查找、排序、堆（优先队列）

**题意**：给定长度均为 $n$ 的数组 `nums1`、`nums2`。可以把 `nums1` 的任意元素 $+1$ 或 $-1$ **至多 $k_1$ 次**、`nums2` 的任意元素 $+1$ 或 $-1$ **至多 $k_2$ 次**（每次操作独立选择元素与方向，元素可变负）。求最终的**最小差值平方和** $\sum_{i=0}^{n-1} (nums1[i] - nums2[i])^2$。

**约束**：

- $1 \le n \le 10^5$
- $0 \le nums1[i], nums2[i] \le 10^5$
- $0 \le k_1, k_2 \le 10^9$

## 2. 示例

**示例 1**

```text
输入：nums1 = [1,2,3,4], nums2 = [2,10,20,19], k1 = 0, k2 = 0
输出：579
解释：不能修改。平方和 = 1 + 64 + 289 + 225 = 579。
```

**示例 2**

```text
输入：nums1 = [1,4,10,12], nums2 = [5,8,6,9], k1 = 1, k2 = 1
输出：43
解释：nums1[0]+1（差 4→3）、nums2[2]+1（差 4→3），
最终平方和 = 9 + 16 + 9 + 9 = 43。
```

**示例 3（边界补充）**

```text
输入：nums1 = [5], nums2 = [3], k1 = 0, k2 = 3
输出：0
解释：nums2[0] 连加 2 次（或连减），差值清零，剩 1 次操作不用。
```

## 3. 解题思路

### 3.1 暴力思路

小规模下可以逐位置枚举操作次数与方向（本文对拍就是这么做的），$n = 10^5$、$k = 10^9$ 时完全不可行。朴素的「贪心 + 堆」思路（每次取当前最大差值 $-1$）正确但复杂度 $O(k \log n)$，$k = 10^9$ 直接超时——必须发现操作总量与差值分布的**宏观结构**。

### 3.2 核心观察一：两类操作合流，只看总预算与差值

![核心观察：k1 与 k2 合流](images/bw82_q3_greedy_model.svg)

设 $d[i] = nums1[i] - nums2[i]$（带符号）。一次对 `nums1[i]` 的 $\pm 1$ 等价于 $d[i] \pm 1$；一次对 `nums2[i]` 的 $\pm 1$ 等价于 $d[i] \mp 1$——**方向自由选择**，所以：

- $k_1$、$k_2$ 的**用途完全对称**，有效信息只有总数 $k = k_1 + k_2$；
- 每次操作的效果 = 「把某个 $|d[i]|$ 减 1」或「加 1」（后者从不更优，弃用）；
- 目标函数只含 $d[i]^2$，与符号无关 → 直接研究 $|d|$ 数组。

### 3.3 核心观察二：凸性 → 最优解是「削平 + 均摊」

![削平到水平 h](images/bw82_q3_level_cut.svg)

在 $|d[i]| = h$ 的位置用一次操作降到 $h - 1$，平方和下降

$$
h^2 - (h-1)^2 = 2h - 1
$$

是关于 $h$ 的**严格递增**函数——差值越高，单位操作的收益越大（平方函数的凸性）。于是最优策略必然是**把操作全部花在最高的差值上**，宏观形态等价于：

> 选一个**水平线** $h$，把所有高于 $h$ 的差值**削平到 $h$**（消耗 $\text{cost}(h) = \sum_i \max(0, |d[i]| - h)$ 次操作）；若预算有剩余（$k > \text{cost}(h)$ 但不够再降一档），把剩余的 `left = k − cost(h)` 次操作分给 `left` 个仍等于 $h$ 的位置，各降到 $h - 1$。

$\text{cost}(h)$ 关于 $h$ **单调不增**（$h$ 越低削得越多、花得越多），因此「$\text{cost}(h) \le k$ 的最小 $h$」可以**二分**求得，也可以用**从高到低的差分数组**逐层下探。本文采用二分（配合排序）实现。

### 3.4 示例演算

![示例演算](images/bw82_q3_example_walkthrough.svg)

**示例 2**：$d = [4, 4, 4, 3]$（绝对值），$k = 2$。

1. $\text{cost}(3) = 1 + 1 + 1 + 0 = 3 > 2$；$\text{cost}(4) = 0 \le 2$ → $h = 4$；
2. $\text{left} = 2 - 0 = 2$：两个 $4$ 各降到 $3$，最终形态 $[3, 3, 4, 3]$；
3. 平方和 $= 9 + 9 + 16 + 9 = 43$ ✓。

**示例 1**：$k = 0$，$h = \max(d) = 17$，一步不动，$579$ ✓。**边界**：$k \ge \sum_i |d[i]|$ 时所有差值可清零，答案 $0$。

## 4. 算法细节

1. **先判「削平全零」**：$k \ge \sum |d|$ 时直接返回 0（此时二分的 $h$ 会到 0 且 $\text{left} = k - \sum|d|$ 无处可用——剩余操作只能把某些 0 加 1，绝不更优，故答案就是 0；显式判断可简化边界）。
2. **二分区间**：$lo = 0$、$hi = \max |d|$。$\text{cost}(\max|d|) = 0 \le k$ 必可行，区间非空；找最小可行 $h$。
3. **$\text{cost}(h)$ 的计算**：排序后（降序）前缀和可 $O(\log n)$ 求出「大于 $h$ 的部分之和」，再减去「个数 × $h$」；本文代码用线性扫描（$O(n)$ 每次判定，总 $O(n \log \max d)$），$n = 10^5$、值 $\le 10^5$ 时约 $34 \times 10^5$ 次操作，足够快。若值域更大可换前缀和版本。
4. **剩余操作的均摊公式**：设 $\text{cnt}_h$ = 削平后等于 $h$ 的差值个数（含原本就等于 $h$ 的与削到 $h$ 的），$\text{left} < \text{cnt}_h$（否则 $h - 1$ 也可行，与 $h$ 最小矛盾——二分保证）。把 $\text{left}$ 个 $h$ 降到 $h-1$，每个省 $2h - 1$：
   $$ \text{ans} = \sum_{v < h} v^2 + (\text{cnt}_h - \text{left}) \cdot h^2 + \text{left} \cdot (h-1)^2 $$
   实现上更简洁的等价写法：先算「全削到 $h$」的平方和，再减去 $\text{left} \cdot (2h - 1)$（把 $\text{left}$ 个 $h^2$ 换成 $(h-1)^2$ 差 $2h-1$）。注意 $h = 0$ 时不会进入此分支（已被步骤 1 截住）。
5. **溢出**：单差值 $\le 10^5$，$v^2 \le 10^{10}$，总和最坏 $10^{15}$——**必须 `long long`**（题目返回类型也是 `long`）。$k_1 + k_2$ 至 $2 \times 10^9$ 也超 `int`，先转 `long long` 再相加。
6. **排序方向**：降序排序后「大于 $h$ 的都在前缀」，`cost` 扫描可以在首个 $\le h$ 处提前终止。

## 5. 正确性证明

**引理 1（操作的合流等价）**：任何「至多 $k_1$ 次 nums1 操作 + 至多 $k_2$ 次 nums2 操作」的方案，其可达的差值数组集合，恰等于「对 $d$ 至多 $k = k_1 + k_2$ 次单位平移」的可达集合（每次平移任选一个 $d[i]$ 加 1 或减 1）。

**证明**：nums1[i] +1 使 $d[i]$ +1、nums1[i] −1 使 $d[i]$ −1、nums2[i] +1 使 $d[i]$ −1、nums2[i] −1 使 $d[i]$ +1。正反两个方向都是逐操作对应：给定原方案逐操作映射到 $d$ 的平移序列；反之给定平移序列，每个「$d[i]$ +1」可由 nums1[i]+1 或 nums2[i]−1 实现（任选），「−1」同理。次数一一对应，故两集合相等。∎

**引理 2（方向的单向最优）**：最优解中每次操作都不会使任何 $|d[i]|$ 增大。

**证明**：考察一次使某 $|d[i]|$ 从 $h$ 变 $h+1$ 的操作（$h \ge 0$）。若该位置后来再无操作，去掉该操作平方和严格下降（$(h+1)^2 > h^2$），矛盾于最优。若后来有操作把它变回 $h$ 或更低，则「先加后减」的连续两次操作可同时去掉（净效果 0 或等价于单次减），得到操作数更少、平方和不增的方案，再补任意无用操作（原地 ±1 对称两次，或对已为 0 的位置 +1 后 −1）不改变结果——仍最优但无「增大」步骤，反复交换论证可消除全部增大步骤。∎

**引理 3（削平结构）**：设最优方案最终差值绝对值多重集合为 $T$（由 $|d|$ 经总量 $\le k$ 次的「某元素减 1（不低于 0）」得到）。则 $T$ 恰为：把 $|d|$ 削到水平 $h$（$h$ 为 $\text{cost}(h) \le k$ 的最小值），再把 $\text{left} = k - \text{cost}(h)$ 个 $h$ 削到 $h - 1$。

**证明**：由引理 2，最优方案是 $k' \le k$ 次「元素减 1」。若 $k' < k$ 且存在某元素 $> 0$，再减一次平方和严格下降，矛盾——故要么全为 0（被 $k \ge \sum|d|$ 情形覆盖），要么 $k' = k$ 用满。把 $|d|$ 降序排列为 $b_1 \ge b_2 \ge \dots \ge b_n$，一次操作的效果是「令某 $b_i$ 减 1 后重新降序」。收益 $2b_i - 1$ 随 $b_i$ 减小而减小（凸性），经典交换论证：任何方案中若某次操作作用在 $b_i < b_j$（当前值）且 $b_j > $ 该方案中随后某次操作前的值，交换操作次序使高者先降不劣——形式化地，$k$ 次操作后的多重集合在「总是操作当前最大者」策略下取到逐元素最优（对操作次数归纳：一次操作的最优目标显然是最大元素；多次情形由凸函数的**分离格上的最优传输**性质 / 直接对「高度直方图」分析：总下降量 $k$ 分配到直方图各列，最小化 $\sum (\text{列高})^2$ 的分配是「水位线」式的——拉格朗日 / 逐层填充论证）。水位线恰为：存在 $h$ 使得所有 $> h$ 的列被削到 $h$、再往下削 $\text{left}$ 个 $h$。∎

**定理**：算法返回最小差值平方和。

**证明**：由引理 1 问题化为「对 $|d|$ 至多 $k$ 次减 1，最小化平方和」；由引理 3 最优终态结构由水平 $h$ 与剩余量 $\text{left}$ 刻画；由引理 2 与凸性，该结构达到下界。算法二分出的 $h$ 是 $\text{cost}(h) \le k$ 的最小值（$\text{cost}$ 单调不增 + 区间端点可行），$\text{left} = k - \text{cost}(h) < \text{cnt}_h$（若 $\ge$ 则 $h - 1$ 亦可行，矛盾），按该结构计算平方和，正确。∎

## 6. 复杂度分析

- **时间**：$O(n \log n + n \log \max|d|)$——排序 $O(n \log n)$；二分 $\log(10^5) \approx 17$ 轮，每轮线性算 $\text{cost}$ 共 $O(n \log V)$；收尾一次线性求和。
- **空间**：$O(n)$ 存差值数组（排序原地则 $O(1)$ 额外，Python 排序新表 $O(n)$）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long minSumSquareDiff(vector<int>& nums1, vector<int>& nums2, int k1, int k2) {
        int n = nums1.size();
        vector<long long> d(n);
        long long k = (long long)k1 + k2;
        for (int i = 0; i < n; ++i) d[i] = llabs((long long)nums1[i] - nums2[i]);
        sort(d.begin(), d.end(), greater<long long>());
        long long sum = 0;
        for (long long v : d) sum += v;
        if (k >= sum) return 0;                     // 预算足以把所有差值削到 0
        int lo = 0, hi = (int)d[0];                 // C(hi)=0 必可行
        while (lo < hi) {                           // 二分最小可行水平 h
            int mid = lo + (hi - lo) / 2;
            if (cost(d, mid) <= k) hi = mid;
            else lo = mid + 1;
        }
        int h = lo;
        long long left = k - cost(d, h);            // 削平后剩余的操作数
        long long ans = 0;
        for (long long v : d) ans += (v < h ? v * v : (long long)h * h);
        ans -= left * (2LL * h - 1);                // left 个 h 再降到 h-1，每个省 2h-1
        return ans;
    }
private:
    long long cost(vector<long long>& d, int h) {   // 把所有大于 h 的差值削到 h 的操作数
        long long c = 0;
        for (long long v : d) c += max(0LL, v - h);
        return c;
    }
};
```

### Python

```python
class Solution:
    def minSumSquareDiff(self, nums1: list[int], nums2: list[int], k1: int, k2: int) -> int:
        d = sorted((abs(a - b) for a, b in zip(nums1, nums2)), reverse=True)
        k = k1 + k2
        if k >= sum(d):                             # 预算足以把所有差值削到 0
            return 0

        def cost(h: int) -> int:                    # 把所有大于 h 的差值削到 h 的操作数
            return sum(v - h for v in d if v > h)

        lo, hi = 0, d[0]                            # cost(d[0])=0 必可行
        while lo < hi:                              # 二分最小可行水平 h
            mid = (lo + hi) // 2
            if cost(mid) <= k:
                hi = mid
            else:
                lo = mid + 1
        h = lo
        left = k - cost(h)                          # 削平后剩余的操作数
        ans = sum(v * v for v in d if v < h) + h * h * sum(1 for v in d if v >= h)
        ans -= left * (2 * h - 1)                   # left 个 h 再降到 h-1，每个省 2h-1
        return ans
```

> 💡 两份代码均通过官方 2 个示例；并与「逐位置枚举操作次数与方向」的暴力实现做了 **3000 组随机对拍**（$n \le 4$、$k \le 6$），另有 400 组大 $k$（至 $10^9$）跨语言一致性验证与 $n = 10^5$ 双端性能测试，`mismatch = 0`。

## 8. 边界情况与易错点

1. **溢出三连**：$k_1 + k_2$ 至 $2\times 10^9$ 超 `int`；单个 $v^2 \le 10^{10}$、总和至 $10^{15}$ 超 `int`。C++ 全程 `long long`（`k`、`sum`、`ans`、`cost` 返回值），`(long long)` 强转要在乘法前。
2. **$k \ge \sum|d|$ 的截断判断**：不判的话二分 $h = 0$、$\text{left} = k - \sum|d|$ 很大，`ans -= left * (2h-1)` 会算出 `left * (-1)` **负数**答案——务必先判 0 或在公式里特判 $h = 0$。
3. **`left < cnt_h` 的隐式保证**：二分取的是最小可行 $h$，所以剩余量一定小于「高度为 $h$ 的列数」，不会出现「再削一整层」的越界；若二分写错（如 `hi = mid` 与 `lo = mid + 1` 弄反）这个不变量破坏，公式立刻错。
4. **负差值**：$d[i]$ 带符号但平方与操作都对称，直接取绝对值；忘记 `abs` 会让排序与水位线全乱。
5. **「至多」而非「恰好」**：$k$ 次操作可以不用满（全零情形剩的操作浪费即可）；引理 2 保证了多用的操作不劣，因此按「恰好用满直到全零」计算安全。
6. **堆解法的复杂度陷阱**：`priority_queue` 每次弹最大、减一、压回，$k = 10^9$ 时 $O(k \log n)$ 必超时；正确做法正是本题的「整体水位线」视角（二分或从高到低的差分下探）。
7. **Python `sum(1 for v in d if v >= h)`**：收尾统计 cnt 的写法可以换成一次循环同时累加，减少两次遍历——对正确性无影响，性能差别在本题规模可忽略。
