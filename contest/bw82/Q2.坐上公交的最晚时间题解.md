# LeetCode 坐上公交的最晚时间 题解

## 1. 题目概述

- **标题 / 题号**：坐上公交的最晚时间（#2332，medium）
- **链接**：https://leetcode.cn/problems/the-latest-time-to-catch-a-bus/
- **来源**：LeetCode 第 82 场双周赛 Q2
- **难度**：中等
- **标签**：数组、双指针、二分查找、排序

**题意**：`buses[i]` 为第 $i$ 辆公交的出发时间，`passengers[j]` 为第 $j$ 位乘客的到达时间（公交出发时间互不相同、乘客到达时间互不相同，但两个数组**均无序**）。每辆车容量 `capacity`，乘客按到达顺序排队上「下一辆有空位的车」（到达时刻 $y$ 可上出发时刻 $x \ge y$ 且未满的车）。求**你**能上车的**最晚到达时刻**，要求不能与任何乘客同一时刻到达。

**约束**：

- $1 \le n, m, capacity \le 10^5$
- $2 \le buses[i], passengers[i] \le 10^9$
- `buses` 内互不相同，`passengers` 内互不相同

## 2. 示例

**示例 1**

```text
输入：buses = [10,20], passengers = [2,17,18,19], capacity = 2
输出：16
解释：车①(10)载乘客 2；车②(20)载乘客 17、18（满载），
乘客 19 上不去。你必须早于 18 到达（挤掉它的位置），
且避开所有乘客时刻，最晚是 16。
```

**示例 2**

```text
输入：buses = [20,30,10], passengers = [19,13,26,4,25,11,21], capacity = 2
输出：20
解释：排序后 buses = [10,20,30]，passengers = [4,11,13,19,21,25,26]。
车①(10) 载乘客 4；车②(20) 载乘客 11、13（满载，19 ≤ 20 但没位置了）；
车③(30) 载乘客 19、21（满载，25、26 上不去）。
末班车满载 → 我必须早于最后上车的乘客 21 到达，t = 21 − 1 = 20，
20 不是任何乘客的到达时刻 → 答案 20。
```

## 3. 解题思路

### 3.1 暴力思路

枚举每个候选时刻 $t \in [1, \max(bus)]$（避开乘客时刻），对每个 $t$ 完整模拟一遍上车过程判断能否上车——$O(\max(bus) \cdot (n + m))$，时刻上限 $10^9$ 直接不可行；即便二分时刻（可行性关于 $t$ 并不单调，不能直接二分！）也得先想清楚模拟本身。

> ⚠️ 注意「能否上车」关于 $t$ **不是单调的**：晚到可能上末班车、早到也可能被前面的人流挤掉逻辑不同，直接二分答案是错误方向。正确切入点是先把「别人怎么上车」模拟清楚。

### 3.2 核心观察：排序 + 双指针模拟出「末班车结束态」

![双指针模拟流程](images/bw82_q2_simulate_flow.svg)

把 `buses`、`passengers` 排序后，用**双指针** $j$（下一个待上车的乘客）逐车模拟：对每辆车 $b$，把到达时刻 $\le b$ 且还有容量的乘客依次「装车」（`++j, ++cnt`）。$O(n + m)$ 完成后，得到两个关键信息：

- $j$：已上车的乘客总数；
- `cnt`：**末班车**实际装载人数（每辆车开始时重置）。

模拟的正确性来自贪心：乘客按时刻先后排队，每辆车只会带走「时刻 ≤ 发车且未满」的最前面若干人。

### 3.3 收尾决策：末班车满载与否 + 回避冲突

![两种收尾情形与回退](images/bw82_q2_fallback.svg)

模拟结束后分两种情形确定**初始候选** $t$：

- **情形 A（末班车未满，`cnt < capacity`）**：我排最后一个也能上——只要 $t \le$ 末班车发车时刻。取 $t = \max(bus)$（最晚发车那辆）。
- **情形 B（末班车满载，`cnt == capacity`）**：我必须**挤掉一个已上车的人**——排在「末班车最后一个上车者」之前即可。最后一个上车者是 `passengers[j-1]`（$j$ 已越过它），取 $t = passengers[j-1] - 1$。

无论哪种情形，$t$ 可能撞上已有乘客时刻（我不能与他人同时到达），于是**逐个 $-1$ 回退**直到空档。由于乘客时刻互不相同且初始 $t$ 已是该情形的上界，回退途中第一个空档即最优。

### 3.4 示例演算：时间线

![示例 1 时间线](images/bw82_q2_timeline.svg)

**示例 1**（`buses=[10,20]`, `passengers=[2,17,18,19]`, `cap=2`）：

1. 车①(10)：乘客 2 上车（cnt=1/2）；17 > 10 停止；
2. 车②(20)：乘客 17、18 上车（cnt=2/2 满载）；19 被挤下；
3. 满载 → $t = 18 - 1 = 17$；17 已有乘客 → 回退 16；16 空档 → **答案 16** ✓。

**示例 2**（排序后 `buses=[10,20,30]`, `passengers=[4,11,13,19,21,25,26]`, `cap=2`）：

1. 车①(10)：载 4（cnt=1/2）；
2. 车②(20)：载 11、13（cnt=2/2 满载）；19 ≤ 20 但车已满，19 留在队首等下一辆；
3. 车③(30)：载 19、21（cnt=2/2 满载）；25、26 上不去；
4. 满载 → $t = 21 - 1 = 20$；20 无乘客到达 → **答案 20** ✓。

## 4. 算法细节

1. **条件顺序**：装车循环 `while (j < m && passengers[j] <= b && cnt < capacity)` —— 三个条件缺一不可：乘客耗尽、乘客赶不上本车、车满，任一出现即停止本车。特别注意「乘客赶不上本车」**不是**「永远上不了车」（还能等下一辆），所以 $j$ 不动、直接换下一辆车。
2. **`cnt` 按车重置**：每辆车开始时 `cnt = 0`；循环结束后保留的是**末班车**的装载量——收尾决策要用。
3. **情形 B 取 `passengers[j-1] - 1` 的原因**：$j-1$ 是全局最后一个上车的人（它在末班车上）。我若与其同时到达则违反「不同时刻」；比它晚（仍 ≤ 发车时刻）则排在它后面——但车已满，轮不到我。比它早任意小都行，最晚就是 $t = 时刻 - 1$。
4. **回退用集合加速**：C++ 里排序数组上 `binary_search`（$O(\log m)$ 每步）；Python 直接 `set(passengers)` 判 `in`（$O(1)$ 每步）。回退步数最坏 $O(m)$（连续时刻被占满），总计 $O(m \log m)$ 或 $O(m)$，可控。
5. **情形 A 的边界**：$t = \max(bus)$ 时若该时刻恰有乘客到达，回退同样适用；注意情形 A 下「比发车时刻晚」绝不可行（车已走）。
6. **别忘 `buses` 也要排序**：题目明确两个数组无序；漏排序示例 2 会直接算错。
7. **数据范围**：时刻至 $10^9$，`int` 装得下（$< 2^{31}-1$）；但 C++ 中 `passengers[j-1] - 1` 在 $j = 0$ 时未定义——情形 B 必然 $j \ge 1$（满载意味着至少上了 `capacity` ≥ 1 人），逻辑上安全。

## 5. 正确性证明

**引理 1（模拟的忠实性）**：排序后双指针模拟得到的「每辆车装载的乘客集合」与题意的排队规则一致。

**证明**：归纳于车序。乘客按到达时刻升序被考察（$j$ 单调不减），每辆车 $b$ 取走的是「尚未上车、到达 $\le b$」的最前 `capacity` 个乘客——恰是排队语义：先到先上、上「下一辆有空位的车」。已上车的乘客不再考察（$j$ 已越过）；赶不上当前车的乘客保留在队首等下一辆（$j$ 不动）。∎

**引理 2（上车可行性的刻画）**：我以时刻 $t$ 到达（$t$ 不与任何乘客重合）能上车，当且仅当存在某辆车 $b$：$t \le b$，且「时刻 $< t$（严格早于我，或同刻不可能）的乘客」在该车占位后仍有空位给我。

**证明**：排队顺序由到达时刻决定；时刻互不相同，故我之前的人恰是「时刻 $< t$」的全部乘客。我上某辆车 $b$ 的条件是：轮到我时（即时刻 $< t$ 的乘客都被处理完）车 $b$ 尚未满且未发走（$t \le b$）。若存在这样的车我必然上其中**最早**的一辆；反之所有满足 $t \le b$ 的车都被前面的人填满则我上不去。∎

**引理 3（两种情形的候选上界）**：设模拟结束时末班车为 $b^* = \max(bus)$（排序后最后一辆）、装载 `cnt`。

- 若 `cnt < capacity`：对任意 $t \le b^*$ 且不与乘客重合的时刻，我都能上车；故最晚候选 $t = b^*$（若被占则回退）。
- 若 `cnt == capacity`：我能上车当且仅当 $t <$ 末班车最后一名乘客的时刻 $p^* = passengers[j-1]$（且 $t \le b^*$ 自动满足，因 $p^* \le b^*$），故最晚候选 $t = p^* - 1$（若被占则回退）。

**证明**：情形一：时刻 $< t \le b^*$ 的乘客在模拟中已全部被前面各车消化或本车消化后仍有空位（末班车未满，且时刻 $< t$ 的乘客数不超过已模拟上车数）……严格地说：设 $t \le b^*$。所有时刻 $< t$ 的乘客按模拟会被某些车带走；到末班车时，装载的就是模拟所得集合（$t$ 的存在不改变他们的行为，因为他们时刻均 $< t$ 或……注意可能有乘客时刻 $\in (t, b^*]$，他们排我后面，不影响我）。末班车装载中时刻 $> t$ 的乘客实际上车与我先到矛盾吗？排队按时刻，时刻 $> t$ 者在我之后，我优先。因此「我到达前的世界」= 模拟结果中时刻 $< t$ 的部分；末班车容量减去这些占位还剩 $\ge 1$（由 `cnt < capacity` 且占位数 $\le cnt$），我能上。$t = b^*$ 取到上界。情形二：末班车满载。时刻 $< t$ 的乘客若**少于** $j$（即 $t \le p^*$），则末班车占位中至少有一个人（$p^*$ 或更晚者）时刻 $\ge t$，被我插队顶掉一个名额，我能上——最晚即 $t = p^*$，但禁止同刻，取 $p^* - 1$；若 $t > p^*$，时刻 $< t$ 的乘客 $\ge j$ 个，末班车占位不减少，仍满载，我上不去。∎

**定理（回退的正确性）**：从候选初值 $t_0$（情形对应的上界）出发逐个递减找到的第一个「无乘客到达」的时刻 $t$ 是全局最晚可行时刻。

**证明**：可行性：$t < t_0 \le$ 情形上界，由引理 3 的单调部分（$t$ 更小只会让「先于我的乘客」更少，可行性不降）依然可行。最优性：反设存在可行时刻 $t' > t$。$t' \le t_0$（引理 3 给出的上界），而 $t$ 是 $[t, t_0]$ 中**最靠右**的空档，故 $t' \in (t, t_0]$ 必是某个乘客时刻，与「$t'$ 不与乘客重合」矛盾。∎

## 6. 复杂度分析

- **时间**：$O(n \log n + m \log m)$——两个排序主导；模拟 $O(n + m)$（$j$ 与车指针都单调）；回退最坏 $O(m)$（C++ 二分判存则 $O(m \log m)$）。$n, m \le 10^5$ 下毫秒级。
- **空间**：$O(1)$ 额外（C++ 原地排序 + 二分）；Python 若建 `set` 判重则 $O(m)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int latestTimeCatchTheBus(vector<int>& buses, vector<int>& passengers, int capacity) {
        sort(buses.begin(), buses.end());
        sort(passengers.begin(), passengers.end());
        int m = passengers.size(), j = 0, cnt = 0;
        for (int b : buses) {                       // 依次模拟每辆车的上车过程
            cnt = 0;
            while (j < m && passengers[j] <= b && cnt < capacity) {
                ++j;
                ++cnt;
            }
        }
        int t;
        if (cnt < capacity) t = buses.back();       // 末班车仍有空位：最晚等于发车时刻
        else t = passengers[j - 1] - 1;             // 满载：抢末班车最后一名乘客之前的时刻
        while (binary_search(passengers.begin(), passengers.end(), t)) --t;
        return t;                                   // 回避所有已存在的到达时刻
    }
};
```

### Python

```python
class Solution:
    def latestTimeCatchTheBus(self, buses: list[int], passengers: list[int], capacity: int) -> int:
        buses.sort()
        passengers.sort()
        m, j, cnt = len(passengers), 0, 0
        for b in buses:                             # 依次模拟每辆车的上车过程
            cnt = 0
            while j < m and passengers[j] <= b and cnt < capacity:
                j += 1
                cnt += 1
        if cnt < capacity:
            t = buses[-1]                           # 末班车仍有空位：最晚等于发车时刻
        else:
            t = passengers[j - 1] - 1               # 满载：抢末班车最后一名乘客之前的时刻
        ps = set(passengers)
        while t in ps:                              # 回避所有已存在的到达时刻
            t -= 1
        return t
```

> 💡 两份代码均通过官方 2 个示例；并与「枚举每个时刻 $t$ 完整重模拟」的暴力实现做了 **3000 组随机对拍**（时刻 $\le 25$、小容量），另有 400 组中等规模与 $n = m = 10^5$ 的 C++/Python 跨语言一致性验证，`mismatch = 0`。

## 8. 边界情况与易错点

1. **忘记排序**：题面特意注明两数组无序；漏排 `buses` 或 `passengers` 都会在示例 2 上翻车。
2. **`cnt` 没按车重置**：把所有车的装载累计到一起会把「末班车是否满载」判错——每辆车开始时 `cnt = 0`。
3. **情形 B 的 $-1$ 忘写或写错位置**：`passengers[j-1]` 本身是乘客时刻，直接返回会违反「不同时刻」；且这个 $-1$ 与后面的冲突回退是**串联**的（先减一再查冲突），不要合并逻辑。
4. **「乘客赶不上当前车」≠「丢弃」**：内层 `while` 停止时该乘客仍在队首等下一辆；不要 `++j`。
5. **回退的复杂度意识**：最坏情况乘客占满 $[1, 10^9]$ 的某长段（$m = 10^5$ 连续时刻），回退 $10^5$ 步可控；但若误把回退写在循环外层套上别的 $O(m)$ 逻辑会平方爆炸。
6. **$j = 0$ 时的越界担忧**：情形 B 要求至少上一人（`capacity ≥ 1` 且 `cnt == capacity ≥ 1`），故 `j ≥ 1`，`passengers[j-1]` 安全；若把 `cnt < capacity` 判反会在空车情形错误访问 `passengers[-1]`。
7. **答案可能早于所有乘客**：若乘客恰好占满 $[p^*-k, p^*-1]$ 连续段，回退会一路走到 $p^*-k-1$——正确但容易让直觉意外；这正是「避开已有时刻」的意义。
