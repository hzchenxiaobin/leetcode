# LeetCode 计算布尔二叉树的值 题解

## 1. 题目概述

- **标题 / 题号**：计算布尔二叉树的值（#2331，easy）
- **链接**：https://leetcode.cn/problems/evaluate-boolean-binary-tree/
- **来源**：LeetCode 第 82 场双周赛 Q1
- **难度**：简单
- **标签**：树、深度优先搜索、二叉树

**题意**：给定一棵**完整二叉树**（每个节点有 0 个或 2 个孩子）：叶子节点值为 0（False）或 1（True）；非叶节点值为 2（OR）或 3（AND），表示对两个孩子值做逻辑或 / 逻辑与。返回根节点的布尔运算值。

**约束**：

- 树中节点数目在 $[1, 1000]$ 之间
- $0 \le Node.val \le 3$
- 每个节点孩子数为 0 或 2
- 叶子节点值为 0 或 1，非叶节点值为 2 或 3

## 2. 示例

**示例 1**

```text
输入：root = [2,1,3,null,null,0,1]
输出：true
解释：AND 节点（值为 3）计算 False AND True = False；
OR 根节点计算 True OR False = True，返回 true。
```

**示例 2**

```text
输入：root = [0]
输出：false
解释：根节点是值为 0 的叶子，直接返回 false。
```

**示例 3（边界补充）**

```text
输入：root = [3,1,0]
输出：false
解释：AND 根节点计算 True AND False = False。
```

## 3. 解题思路

### 3.1 暴力思路

本题数据量（$\le 1000$ 节点）下「暴力」与「最优」并无差别——任何遍历都是 $O(n)$。值得区分的是写法层次：把层序数组转成树再迭代求值（需要显式栈或队列，维护「节点值是否已就绪」的状态），远不如直接利用**递归结构 = 表达式结构**来得自然。这题的本质是**表达式树求值**（expression tree evaluation），后序遍历天然对应「先算操作数、再算操作符」。

### 3.2 核心观察：完整二叉树的叶子判定与运算符分发

![核心观察：后序求值与树形](images/bw82_q1_postorder_eval.svg)

- **叶子判定只需看一个孩子指针**：完整二叉树保证非叶节点**必有两个**孩子，因此 `root->left == nullptr` ⇔ 是叶子（不存在只有一个孩子的节点）。无需检查 `val` 是否在 $\{0, 1\}$。
- **叶子返回 `val == 1`**：0 → false，1 → true。
- **非叶节点按 `val` 分发**：2 → 左右值取 OR；3 → 取 AND。递归调用即「先求两个孩子（后序）」。

### 3.3 算法流程：递归后序

```text
evaluateTree(root):
    若 root->left 为空：              # 完整二叉树 → 无左孩子即叶子
        返回 (root->val == 1)
    l = evaluateTree(root->left)      # 后序：先左
    r = evaluateTree(root->right)     #       再右
    若 root->val == 2：返回 l || r    #       最后根（OR）
    否则：            返回 l && r     #                 （AND）
```

### 3.4 示例演算：递归栈展开

![递归调用栈展开](images/bw82_q1_recursion_stack.svg)

对示例 1（`[2,1,3,null,null,0,1]`）：

| 步骤 | 调用 | 动作 | 结果 |
|------|------|------|------|
| ① | evaluateTree(2) | 非叶，先递归左 | — |
| ② | evaluateTree(1) | 叶子 | true |
| ③ | evaluateTree(3) | 非叶，先递归其左 | — |
| ④ | evaluateTree(0) | 叶子 | false |
| ⑤ | evaluateTree(1) | 叶子 | true |
| ⑥ | 回到 ③ | false AND true | false |
| ⑦ | 回到 ① | true OR false | **true** |

值自底向上逐层汇合——这正是后序遍历的「左右根」次序。

## 4. 算法细节

1. **递归即答案**：表达式树的「结构」就是运算的「顺序」，递归体与题意一一对应，不需要任何额外数据结构。
2. **用 `left` 判叶**：比「`val <= 1` 判叶」更稳——题面已由完整二叉树性质背书；即便某些环境传入 `val` 异常，指针判空仍是结构性的判定。
3. **短路求值不生效也无妨**：`l || r`、`l && r` 在两个子树都已递归求值**之后**才组合，即使 C++ 的 `||` 短路也不会跳过子树计算（子树在参数里已求值）。如果追求「短路剪枝」，可以在算完 `l` 后：OR 时 `l` 为 true 就直接返回、AND 时 `l` 为 false 直接返回，省一次递归——对本题规模无必要，但值得知道。
4. **返回类型**：LeetCode 接口是 `bool`（Python `bool`）；C++ 中 `root->val == 1` 已是 `bool`。
5. **空树防御**：约束保证至少 1 个节点，`root` 非空；若要防御 `nullptr` 可在开头加 `if (!root) return false;`（非必需）。
6. **深度上界**：$1000$ 个节点的完整二叉树最深层约 $\log_2 1001 \approx 10$（完整二叉树深度平衡），实际最坏（链状不可能是完整二叉树，叶必须成对）仍远小于递归栈限制，无爆栈风险。

## 5. 正确性证明

**引理 1（叶子判定的充要性）**：在完整二叉树中，节点 $u$ 是叶子 ⇔ $u$ 无左孩子。

**证明**：叶子的定义是无孩子。若 $u$ 无左孩子：由「孩子数为 0 或 2」性质，$u$ 不可能有右孩子（否则孩子数为 1），故 $u$ 是叶子。反之叶子无左孩子显然。∎

**引理 2（子问题结构）**：非叶节点 $u$ 的值定义为 $op_u(l, r)$，其中 $l, r$ 是其左右子树（都是完整二叉树）的值，$op_u$ 为 OR（$val = 2$）或 AND（$val = 3$）。

**证明**：即题面的计算规则。左右子树是完整二叉树：完整二叉树删去根后，左右子树各自仍是完整二叉树（每个节点的孩子数不变），归纳可用。∎

**定理（算法正确性）**：`evaluateTree(u)` 返回节点 $u$ 按题意计算的布尔值，且终止。

**证明**：对子树大小归纳。基例（大小 1，即叶子）：由引理 1 算法走 `left == nullptr` 分支返回 `val == 1`，与叶子定义一致。归纳步（大小 $> 1$）：算法递归调用左右子树，其大小严格更小，由归纳假设返回值正确（$l$、$r$）；再按 `val` 分发为 `l || r` 或 `l && r`，由引理 2 恰为 $u$ 的定义值。递归深度受树高限制（有限），必然终止。∎

## 6. 复杂度分析

- **时间**：$O(n)$——每个节点恰好被访问一次，每次访问做常数次比较与一次布尔运算；$n \le 1000$。
- **空间**：$O(h)$ 递归栈，$h$ 为树高；完整二叉树 $h \le \lfloor \log_2 n \rfloor + 1 \approx 10$（实际上界），最坏一般二叉树为 $O(n)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool evaluateTree(TreeNode* root) {
        if (!root->left) return root->val == 1;        // 完整二叉树：无左孩子即叶子
        bool l = evaluateTree(root->left);             // 后序：先算两个孩子
        bool r = evaluateTree(root->right);
        return root->val == 2 ? (l || r) : (l && r);   // 2 → OR，3 → AND
    }
};
```

### Python

```python
class Solution:
    def evaluateTree(self, root: Optional[TreeNode]) -> bool:
        if root.left is None:                    # 完整二叉树：无左孩子即叶子
            return root.val == 1
        l = self.evaluateTree(root.left)         # 后序：先算两个孩子
        r = self.evaluateTree(root.right)
        return (l or r) if root.val == 2 else (l and r)   # 2 → OR，3 → AND
```

> 💡 两份代码均通过官方 2 个示例与 `[3,1,0]` 边界；并与「独立层序数组递归求值」实现做了 **400 组随机完整二叉树**对拍（随机生成叶子 0/1、内部 2/3），`mismatch = 0`。

## 8. 边界情况与易错点

1. **单节点树**：根即叶子，`[0]` → false、`[1]` → true；判叶分支必须先于任何对孩子指针的访问。
2. **不要用 `val` 判叶子**：`val <= 1` 在本题数据下可行，但一旦树的语义扩展（如允许单孩子节点）就会出错；指针判空 + 完整二叉树性质是最稳的判定。
3. **Python 判空写法**：用 `root.left is None` 而非 `not root.left`——后者在 TreeNode 定义了 `__bool__` 的环境下有隐患（LeetCode 标准定义无此问题，但习惯上 `is None` 更精确）。
4. **运算符映射别写反**：2 是 OR、3 是 AND（题面顺序）；写反在「示例 1」上会得到 `false AND true` 路径的错误答案，可作快速自检。
5. **不要修改树**：无需建新树或改 `val`，纯函数式递归即可；修改 `val` 缓存结果（记忆化）对本题规模是过度设计。
6. **迭代写法的选择**：若必须避免递归（某些面试场景），用显式栈做后序遍历（节点第一次弹出先压右再压左，第二次弹出求值）或用两个栈的「按运算优先级分层」法——都比递归长不少。
