# LeetCode 划分数字的方案数 题解

## 1. 题目概述

- **标题 / 题号**：划分数字的方案数（#1977，hard）
- **链接**：https://leetcode.cn/problems/number-of-ways-to-separate-numbers/
- **来源**：LeetCode 第 59 场双周赛 Q4
- **难度**：困难
- **标签**：字符串、动态规划、前缀和

**题意**：把若干正整数连写得到字符串 `num`（原逗号丢失）。这些数满足：整列数**非递减**，且每个数**无前导零**。问有多少种不同的正整数数组能拼出 `num`，答案对 $10^9 + 7$ 取模。注意：数组长度（即划分段数）任意，每段必须非空。

**约束**：

- $1 \le num.length \le 3500$
- `num` 只含数字 '0' ~ '9'。

## 2. 示例

**示例 1**

```text
输入：num = "327"
输出：2
解释：可能的数组为 [3, 27] 与 [327]。
```

**示例 2**

```text
输入：num = "094"
输出：0
解释：任何划分的第一段都以 '0' 开头，有前导零，全部非法。
```

**示例 3**

```text
输入：num = "0"
输出：0
解释：同上，"0" 不是合法正整数（前导零）。
```

**示例 4**

```text
输入：num = "9999999999999"
输出：101
解释：全 '9' 串的划分方案数等于 13 的整数分划数 p(13) = 101。
```

## 3. 解题思路

### 3.1 暴力思路

枚举 $n - 1$ 个切分点中的每个子集（$2^{n-1}$ 种），对每种切分逐段检查「首字符非 0」且「相邻段数值非递减」，$O(n)$ 验证。总复杂度 $O(2^{n-1} n)$，$n = 3500$ 下天文数字；即便 $n \le 20$ 也只能覆盖对拍。需要把「切分位置枚举」改造成「逐段决策的 DP」。

### 3.2 核心观察：以「最后一段的长度」做状态，比较可以被 O(1) 判定

![状态设计与三种前段长度关系](images/bw59_q4_dp_model.svg)

**状态定义**：$dp[i][L]$ 表示「前 $i$ 个字符已划分完毕，且最后一段是子串 $num[i-L..i)$（长度 $L$）」的方案数。答案是 $\sum_{L=1}^{n} dp[n][L]$。

**转移的关键**：设最后一段长 $L$、倒数第二段长 $P$，则倒数第二段是 $num[i-L-P..i-L)$。合法性由三个量完全决定：

1. **当前段首字符非零**：$num[i-L] \ne '0'$（否则该段非法，$dp$ 值为 0）；
2. **前一段首字符非零**：$num[i-L-P] \ne '0'$（由 $dp[i-L][P]$ 本身为 0 自动保证，无需重复判断）；
3. **非递减**：
   - $P < L$：前段位数少，**数值必小于**当前段（一个 $P$ 位数 $\le 10^P - 1 < 10^{L-1} \le$ 任意 $L$ 位数），无需比较——这是本题最容易被忽略的「免费」结论；
   - $P = L$：位数相同，等长字符串的**字典序比较 = 数值比较**，需要 $O(L)$ 逐位比较（暂记为瓶颈）；
   - $P > L$：前段位数多，数值必大于当前段，违反非递减，跳过。

于是转移为：

$$dp[i][L] = \underbrace{\sum_{P=1}^{L-1} dp[i-L][P]}_{\text{更短前段，全部合法}} + \underbrace{[cmp(i-2L,\ i-L,\ L) \le 0] \cdot dp[i-L][L]}_{\text{等长前段，需比较}}$$

其中 $cmp(a, b, L)$ 比较两个长度为 $L$ 的段 $num[a..a+L)$ 与 $num[b..b+L)$。

**前缀和消掉求和**：令 $pre[i][L] = \sum_{P=1}^{L} dp[i][P]$，则

$$dp[i][L] = pre[i-L][L-1] + [\text{等长段} \le] \cdot \big(pre[i-L][L] - pre[i-L][L-1]\big)$$

每步 $O(1)$。

### 3.3 瓶颈消除：LCP 预处理让等长比较降到 O(1)

![LCP 预处理：等长段比较的 O(1) 判定](images/bw59_q4_lcp_compare.svg)

等长比较若逐位做是 $O(L)$，总复杂度 $O(n^3) \approx 4 \times 10^{10}$，不可行。定义

$$lcp[i][j] = \text{后缀 } num[i..] \text{ 与 } num[j..] \text{ 的最长公共前缀长度} \quad (i < j)$$

用倒序二维递推 $O(1)$ 求出全部 $lcp$：$num[i] = num[j]$ 时 $lcp[i][j] = lcp[i+1][j+1] + 1$，否则为 0。比较等长段 $A = num[a..a+L)$、$B = num[b..b+L)$（$b = a + L$，恰好拼接）时：

- 若 $lcp[a][b] \ge L$：两段完全相同，$A = B$，合法（非递减允许相等）；
- 否则 $k = lcp[a][b] < L$，前 $k$ 位相同，第 $k$ 位决定大小：$num[a+k] < num[b+k] \Leftrightarrow A < B$（合法），$num[a+k] > num[b+k] \Leftrightarrow A > B$（非法）。

空间上 $lcp$ 是 $n^2$ 个 `unsigned short`（$n \le 3500$，$lcp \le n < 2^{16}$，约 24 MB 用 2 字节类型，Python 用 `array('H')`），加上 $pre$ 的 $n^2$ 个 int，本题卡的就是这个二维表——$3500^2 \times (2 + 4) \approx 73$ MB，`pre` 与 `lcp` 都必须用最省的类型（`pre` 存模后值 `int` 足够）。

### 3.4 示例演算

![示例演算：num = "327" 的 dp 表](images/bw59_q4_walkthrough_327.svg)

以 `num = "327"` 为例（下标从 1 计的前缀）：$dp[1][1] = 1$（段 "3"，整串一个数）；$dp[2][1] = 0$（段 "2"，唯一前段 "3" 数值更大）；$dp[2][2] = 1$（段 "32"）；$dp[3][1] = 0$（段 "7" 的前段只能是 "32"，$32 > 7$）；$dp[3][2] = 1$（段 "27"，前段 "3" 位数少必小，合法）；$dp[3][3] = 1$（整串 "327"）。答案 $= dp[3][1] + dp[3][2] + dp[3][3] = 0 + 1 + 1 = 2$，对应 $[3, 27]$ 与 $[327]$。

对照示例 4：全 '9' 串没有前导零问题、等长段比较全部相等、更短段必更小，任何「段长非递增」的划分都合法——方案数恰为段长集合的整数分划数。$n = 13$ 时 $p(13) = 101$ 与官方一致；顺带验证 $n = 3500$ 全 '9' 时答案 $= p(3500) \bmod (10^9+7) = 755568658$（用独立分划 DP 复核通过）。

## 4. 算法细节

1. **遍历顺序**：外层 $i = 1 \to n$（前缀长度），内层 $L = 1 \to n$；`pre[i][L]` 在内层循环结束时顺手做前缀和（`pre[i][L] = pre[i][L-1] + dp[i][L]`），不需要单独一维循环。
2. **`L == i` 的整串分支**：前缀本身就是一段（无前段），$dp[i][i] = [num[0] \ne '0']$，放在循环内 `L == i` 分支处理，避免数组越界访问 $i - L = 0$ 前的行。
3. **`L > i` 的分支**：段长超过前缀长度，非法，`cur = 0`（由 else 分支兜底），`pre` 照常累加 0 即可，无需 break——`pre[i][L]` 对 $L > i$ 恒等于 $pre[i][i]$，后续引用 $pre[i-L][\cdot]$ 时 $L \le i/2 < i$，永远只用有效部分。
4. **等长比较的下标**：段起点 $a = i - 2L$、$b = i - L$；条件 `2*L <= i` 保证 $a \ge 0$。判断式 `lcp[a][b] >= L || num[a+k] < num[b+k]`（$k = lcp[a][b]$）覆盖「相等或更小」。
5. **取模与负数**：`pre[i-L][L] - pre[i-L][L-1]` 是两个模数之差，可能为负，C++ 中 `(cur + same + MOD) % MOD` 规范化；Python 的 `%` 天然非负。
6. **首字符为 '0' 的整体剪枝**：`num[0] == '0'` 时任何划分第一段必含前导零，答案 0，可在入口直接返回（也天然被 $dp$ 值 0 覆盖，剪枝只是省时间）。
7. **内存布局**：C++ `vector<vector<unsigned short>>` 存 `lcp`、`vector<vector<int>>` 存 `pre`；Python 用 `array('H')` / `array('i')` 的行列表，纯 list-of-list 会超内存。
8. **`lcp` 只需上三角**：$i < j$ 才有意义，实现中开满 $(n+1)^2$ 但只用 $i < j$ 部分（$j = i$ 的行恒 0 不读），空间换简单。

## 5. 正确性证明

**引理 1（位数优势）**：对正整数 $x$（$P$ 位、无前导零）与 $y$（$L$ 位、无前导零），若 $P < L$ 则 $x < y$。

**证明**：$P$ 位无前导零正整数 $x \ge 10^{P-1}$ 且 $x \le 10^P - 1 < 10^{P} \le 10^{L-1} \le y$（后者因 $y$ 为 $L$ 位无前导零正整数，首位 $\ge 1$）。故 $x < y$。∎

**引理 2（等长字典序 = 数值序）**：两个长度同为 $L$、均无前导零的数字串 $A$、$B$，$A \le B$（字典序）当且仅当 $\mathrm{val}(A) \le \mathrm{val}(B)$。

**证明**：等长数字串的字典序即逐位比较首个不同位的大小；数值比较时高位权重 $10^{L-1-k}$ 严格大于其后所有位权重之和 $10^{L-1-k} - 1$，故首个不同位即决定数值大小关系，与字典序一致。∎

**引理 3（LCP 判定的正确性）**：设 $k = lcp[a][b] < L$，则段 $A = num[a..a+L)$ 与 $B = num[b..b+L)$ 的大小关系由 $num[a+k]$ 与 $num[b+k]$ 决定。

**证明**：$lcp$ 定义保证 $num[a+t] = num[b+t]$（$t < k$）且 $num[a+k] \ne num[b+k]$（否则 $lcp \ge k+1$）。前 $k$ 位相同，第 $k$ 位不同：若 $num[a+k] < num[b+k]$，则存在下标 $t^* = k$ 使 $A$ 在该位严格小且之前位全等，故 $A < B$（字典序与数值序由引理 2 一致）；反之 $A > B$。∎

**定理（DP 的完备性与正确性）**：$\sum_{L=1}^{n} dp[n][L]$ 恰为合法数组的个数（模 $10^9+7$）。

**证明**：**（双射）** 一个合法数组 $a_1 \le a_2 \le \dots \le a_k$（各段无前导零）与其切分位置序列一一对应：段 $a_j$ 的十进制串长 $L_j$ 满足 $\sum_j L_j = n$，且串拼接等于 `num`。**（无重复计数）** 切分位置序列不同则数组不同（串长序列或起点不同），DP 按「最后一段长度 $L$ + 其前缀的状态 $dp[i-L][P]$」分解，同一数组只被计数一次。**（无遗漏）** 对任意合法数组，取其最后一段（长 $L$，$num[n-L] \ne '0'$）与前缀数组（最后一段长 $P$）：若 $P < L$，由引理 1 前段合法地 $\le$ 末段，转移第一项覆盖；若 $P = L$，由引理 2、3 比较项正确判定 $\le$，成立时转移第二项覆盖；若 $P > L$，数组本身违反非递减，不存在该数组。归纳于 $i$：$dp[i][L]$ 等于「前 $i$ 位、末段恰为 $num[i-L..i)$ 的合法数组数」——基础 $i = L$（整串一段）由 $num[0] \ne '0'$ 给 1；归纳步骤由上述分解完备。求和遍历所有末段长度即覆盖全部合法数组。∎

**推论（复杂度）**：$lcp$ 表 $O(n^2)$ 时间 / $O(n^2)$ 空间；DP 双层循环 $O(n^2)$ 个状态、每状态 $O(1)$ 转移，总 $O(n^2)$ 时间、$O(n^2)$ 空间。

## 6. 复杂度分析

- **时间**：$O(n^2)$。`lcp` 倒序双循环 $n^2/2$ 次；DP 外层 $n$、内层 $n$，每步仅算术与一次 `lcp` 查表。$n = 3500$ 时约 $1.2 \times 10^7$ 量级操作，C++ 数十毫秒，Python 约 3~4 秒（用 `array` 行缓存优化后可过）。
- **空间**：$O(n^2)$。`lcp` 表 $n^2$ 个 2 字节项约 24 MB，`pre` 表 $n^2$ 个 4 字节项约 47 MB；`dp` 不显式存（由 `pre` 差分恢复）。若进一步滚动可省 `pre` 的行维，但 `lcp` 不可省（随机访问全表）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int numberOfCombinations(string num) {
        const int MOD = 1000000007;
        const int n = (int)num.size();
        // lcp[i][j]（i < j）：后缀 num[i..] 与 num[j..] 的最长公共前缀长度
        vector<vector<unsigned short>> lcp(n + 1, vector<unsigned short>(n + 1, 0));
        for (int i = n - 2; i >= 0; --i)
            for (int j = n - 1; j > i; --j)
                if (num[i] == num[j])
                    lcp[i][j] = lcp[i + 1][j + 1] + 1;
        // pre[i][L] = Σ_{P=1..L} dp[i][P]；dp[i][L]：把前 i 位分段、最后一段
        // 是 num[i-L..i)（长 L、无前导零、整段非递减）的方案数
        vector<vector<int>> pre(n + 1, vector<int>(n + 1, 0));
        for (int i = 1; i <= n; ++i) {
            for (int L = 1; L <= n; ++L) {
                int cur = 0;
                if (L == i) {
                    cur = (num[0] != '0');              // 整个前缀单独作为一个数
                } else if (L < i && num[i - L] != '0') {
                    cur = pre[i - L][L - 1];            // 前一段更短 ⇒ 数值必更小
                    if (2 * L <= i) {                   // 前一段等长：字符串比较
                        int a = i - 2 * L, b = i - L;
                        int k = lcp[a][b];
                        if (k >= L || num[a + k] < num[b + k]) {
                            int same = pre[i - L][L] - pre[i - L][L - 1];
                            cur = (cur + same + MOD) % MOD;
                        }
                    }
                }
                pre[i][L] = (pre[i][L - 1] + cur) % MOD;
            }
        }
        return pre[n][n];
    }
};
```

### Python

```python
class Solution:
    def numberOfCombinations(self, num: str) -> int:
        n = len(num)
        if num[0] == "0":
            return 0
        # lcp[i][j]（i < j）：后缀 num[i:] 与 num[j:] 的最长公共前缀长度
        lcp = [array("H", [0]) * (n + 1) for _ in range(n)]
        for i in range(n - 2, -1, -1):
            li, ln, ci = lcp[i], lcp[i + 1], num[i]
            for j in range(n - 1, i, -1):
                if ci == num[j]:
                    li[j] = ln[j + 1] + 1
        # pre[i][L] = Σ_{P≤L} dp[i][P]；dp[i][L]：前 i 位分段、最后一段长 L 的方案数
        pre = [array("i", [0]) * (n + 1) for _ in range(n + 1)]
        for i in range(1, n + 1):
            row, tail = pre[i], num[i - 1]
            for L in range(1, n + 1):
                if L == i:
                    cur = 1                       # 整个前缀单独作为一个数
                elif L < i and num[i - L] != "0":
                    pr = pre[i - L]
                    cur = pr[L - 1]               # 前一段更短 ⇒ 数值必更小
                    if 2 * L <= i:                # 前一段等长：字符串比较
                        a, b = i - 2 * L, i - L
                        k = lcp[a][b]
                        if k >= L or num[a + k] < num[b + k]:
                            cur += pr[L] - pr[L - 1]
                else:
                    cur = 0
                row[L] = (row[L - 1] + cur) % MOD
        return pre[n][n]
```

> ⚠️ Python 参考代码需在文件头部 `from array import array` 与 `MOD = 10 ** 9 + 7`（LeetCode 平台提交时补上这两行即可）。`array("H", [0]) * (n + 1)` 生成 2 字节无符号短整型数组，`array("i", ...)` 为 4 字节整型，均比纯 list 省内存。

> 💡 两份代码均通过官方示例（`2`、`0`、`0`、`101`），与**切分枚举暴力**对拍 400 组随机串（含全同数字、前导零高发、随机混合）全部一致；另以 $n = 3500$ 全 '9' 串对照独立计算的整数分划数 $p(3500) \bmod (10^9+7) = 755568658$ 复核通过，并对 3 组 $n = 3500$ 随机串做 C++/Python 双实现互验，结果一致。

## 8. 边界情况与易错点

1. **前导零**：`num[0] == '0'` 整体无解（首段必非法）；段中间的 '0' 开头同样非法，判断条件是 `num[i-L] != '0'`（当前段首字符）。注意 `"0"` 与 `"094"` 都返回 0。
2. **等长比较的下标**：$a = i - 2L$、$b = i - L$，前提 $2L \le i$；漏判 $2L \le i$ 会数组越界（负下标）。
3. **`lcp[a][b] >= L` 的含义**：两段完全相等（公共前缀覆盖整段），相等**合法**（非递减含等号）；写成 `>` 会漏掉相等情形。
4. **前缀和差分的负数**：`pre[..][L] - pre[..][L-1]` 在模意义下可能为负，C++ 必须补 `+ MOD` 再取模。
5. **`L == i` 与 `L > i` 分支**：整串一段单独给 1；$L > i$ 一律 0 但**不能 break**（`pre` 行要填满，后续行会引用本行的任意列）。
6. **内存类型**：`lcp` 用 `unsigned short`（C++）/ `array('H')`（Python），`pre` 用 `int` / `array('i')`；全用 32 位以上类型会在 $n = 3500$ 时超内存（LeetCode 本题内存卡得紧）。
7. **比较的是「段」不是「后缀」**：`lcp` 是后缀的公共前缀，判段相等时阈值是 $L$（段长）不是 $n$；混淆会把「后缀相等」误当「段相等」。
8. **全同字符串的退化**：全 '9' 时 `lcp` 全满（$lcp[i][j] = n - j$），是空间与分支的最坏压力源，可用于性能自测。

**延伸思考**：本题的技术骨架是「**分段计数 DP + 二维 LCP 表 O(1) 比较 + 前缀和优化**」，三件套可整体迁移到任何「把串切成非降/非升可比较段」的计数题。比较维度若从数值换成任意有序字典序对象，只需替换引理 2 的等长比较。进一步：若允许前导零（比较变为纯长度优先）本题会退化成整数分划计数（全 '9' 串的对照实验正揭示了这一联系）；若要求**严格递增**，等长相等的分支改为非法即可；若 $n$ 放大到 $10^5$，$O(n^2)$ 的 `lcp` 表不可行，需换后缀数组 + RMQ 在线求 LCP（复杂度 $O(n \log n)$ 预处理，DP 部分不变）。
