# LeetCode 最大方阵和 题解

## 1. 题目概述

- **标题 / 题号**：最大方阵和（#1975，medium）
- **链接**：https://leetcode.cn/problems/maximum-matrix-sum/
- **来源**：LeetCode 第 59 场双周赛 Q2
- **难度**：中等
- **标签**：贪心、数组、矩阵

**题意**：给定 $n \times n$ 整数方阵 `matrix`。每次操作可以任选**相邻**（有公共边）的两个元素同时乘以 $-1$，操作次数不限。目标是最大化方阵所有元素之和，返回能达到的最大和。

**约束**：

- $n = matrix.length = matrix[i].length$，$2 \le n \le 250$
- $-10^5 \le matrix[i][j] \le 10^5$

## 2. 示例

**示例 1**

```text
输入：matrix = [[1,-1],[-1,1]]
输出：4
解释：第一行两元素同乘 -1 得 [[-1,1],[-1,1]]，再第一列两元素同乘 -1 得 [[1,1],[1,1]]，和为 4。
```

**示例 2**

```text
输入：matrix = [[1,2,3],[-1,-2,-3],[1,2,3]]
输出：16
解释：把第二行最后两个元素（-2,-3）同乘 -1 得 [[1,2,3],[-1,2,3],[1,2,3]]，
再把 (1,0) 与 (2,0) 即 -1 与 1 同乘 -1 … 实际最优为翻转后 |1|+|2|+|3|+|1|+|2|+|3|+|1|+|2|+|3| − 2×1 = 16。
```

**示例 3（边界补充）**

```text
输入：matrix = [[-1,0],[0,0]]
输出：1
解释：负号只有 1 个（奇数），但 0 可以「吸收」负号：翻转 (-1,0) 后和为 1 = Σ|x|。
```

## 3. 解题思路

### 3.1 暴力思路

每次操作翻转相邻两格符号，状态空间是「每个格子是否被翻转过」共 $2^{n^2}$ 种符号形态（$n = 250$ 时天文数字）。正确但不可行的做法是 BFS 所有可达形态取最大和。规模稍小时可以观察到一个规律：**翻转标记本身的奇偶性才是本质**——这正是下面贪心的起点。

### 3.2 核心观察：负号可以沿网格自由「搬运」，绝对值多重集不变

![核心观察：负号沿网格搬运与湮灭](images/bw59_q2_sign_shuttle.svg)

一次操作 = 同时翻转相邻两格的符号，等价于把一个「负号」从其中一格搬到另一格（异或视角：负号个数的**奇偶分布**按相邻格转移）。关键推论：

1. **不变量**：全体元素的绝对值多重集永远不变——操作只改符号不改绝对值。
2. **搬运**：反复对相邻格操作，可以把任意一个负号移到任意位置（网格连通）。
3. **湮灭**：两个负号相遇（搬到同一格）后该格被翻两次回原状，等效于**两个负号同时消失**。
4. **吸收**：负号移到值为 0 的格子上，和不变，等效于**单独消灭一个负号**。

于是问题退化为：**负号个数（初始负数个数）的奇偶性决定命运**——偶数个全消；奇数个时若存在 0 则塞给 0，否则必须剩一个，让它落在绝对值最小的格子上损失最小。

### 3.3 算法流程

![示例演算：负号个数奇偶性三分决策](images/bw59_q2_example_walkthrough.svg)

```text
1. 一趟扫描统计：
       total  = Σ |x|                  # 绝对值总和（不变量的上限）
       minAbs = min |x|                # 绝对值最小者
       negCnt = 负数个数
       hasZero = 是否存在 0
2. 若 negCnt 为偶数，或 hasZero 为真：返回 total
3. 否则（奇数个负号且无 0）：返回 total − 2 × minAbs
```

### 3.4 示例演算

以示例 2（$3\times 3$）为例：绝对值总和 $total = 18$，负数有 3 个（奇数），无 0，$minAbs = 1$。答案 $18 - 2 \times 1 = 16$。具体操作：先把第二行的 $-1, -2$ 翻转成 $1, 2$（负号从这两格「搬走」），把两个负号叠到 $-3$ 上湮灭，剩一个负号从 $-3$ 一路搬到值为 $1$ 的格子，最终只剩一个 $-1$，和为 $1+2+3+1+2+3+1+2+3-2 = 16$。若错把负号留给 $3$，和只有 $18 - 6 = 12$。

## 4. 算法细节

1. **只用四个统计量**：$total$、$minAbs$、$negCnt$、$hasZero$，一趟双循环全部拿到，无需修改矩阵、无需实际模拟操作。
2. **扣 $2 \times minAbs$ 的由来**：把 $x$（$x > 0$）变负，和从 $+|x|$ 变 $-|x|$，损失 $2|x|$；负号留在原负数上等价，故选绝对值最小者损失最小。
3. **0 的角色**：$-0 = 0$，翻转含 0 的对不改变和，因此 0 是负号的「免费垃圾桶」。注意判断顺序：`negCnt % 2 == 1 && !hasZero` 才扣分。
4. **溢出**：$n \le 250$，$|x| \le 10^5$，$total \le 250^2 \times 10^5 = 6.25 \times 10^{12}$，超出 32 位 `int` 上界，C++ 必须用 `long long` 累加（LeetCode 返回类型也已是 64 位）。
5. **负数计数别把 0 算进去**：`x < 0` 才计负数；`x == 0` 单独标记 `hasZero`。若把 0 当负数（如用 `x <= 0`），奇偶性判断会被带偏。

## 5. 正确性证明

**引理 1（不变量）**：任意操作序列执行后，矩阵元素的绝对值多重集不变。

**证明**：操作将相邻两元素 $a, b$ 同时变为 $-a, -b$，而 $|-a| = |a|$、$|-b| = |b|$，逐次操作仅替换多重集中的元素为相同绝对值，故多重集恒定。∎

**引理 2（负号总数奇偶不变）**：设 $P(t)$ 为 $t$ 次操作后负数（严格小于 0 的元素）个数与「负号需求」的联合奇偶性，准确地说：定义 $s(t)$ 为全体元素符号乘积的符号（0 视为使乘积为 0 的特殊情况另行处理），则每次操作后 $s$ 不变。

**证明**：操作翻转两个元素符号，全体符号乘积变化因子为 $(-1)^2 = 1$，故乘积符号不变。若矩阵无 0，负数个数的奇偶性恰由符号乘积决定（负号奇偶 = 乘积符号），故负数个数奇偶性不变；若有 0，乘积恒为 0，但 0 元素在操作中仍为 0（$-0 = 0$），非零元素的符号乘积同样不变，同理非零负数个数奇偶不变。∎

**引理 3（可达性）**：设矩阵无 0 且初始有 $k$ 个负数。对任意满足「负数个数 $\equiv k \pmod 2$」的符号分布（绝对值固定），均可达；特别地，$k$ 为偶数时可达全正；$k$ 为奇数时可达「恰某一指定格为负」。

**证明**：把负号视作放置在格子上的棋子。对相邻格 $(u, v)$ 操作等价于把 $u$ 上一个负号移到 $v$（或反向），当且仅当两格负号状态不同时；若两格状态相同则各翻转偶数次等于不动（可跳过）。网格图连通，棋子（负号）可沿路径移动到任意格；两个负号移到同格即同时湮灭（该格被翻两次）。于是：$k$ 偶数时两两配对湮灭得全正；$k$ 奇数时先湮灭 $k-1$ 个，剩一个负号可移到任意指定格。∎

**定理**：设 $T = \sum |x|$，$m = \min |x|$，$k$ 为负数个数，$z$ 为是否含 0。可达的最大和为 $T$（$k$ 偶或 $z$ 真），否则 $T - 2m$。

**证明**：**上界**：和 $= T - 2 \times (\text{当前负数绝对值之和}) \le T$，故 $T$ 是绝对上界。**可达性**：$k$ 偶且无 0 时由引理 3 全正可达 $T$；含 0 时把奇数个负号中的多余者移入 0 格（和不变，因 $|0|$ 翻转仍贡献 0），归约为偶数情形，仍可达 $T$。**不可达性**：$k$ 奇且无 0 时由引理 2，负数个数奇偶恒为奇，至少剩一个负数，和 $\le T - 2m$（损失至少 $2 \times$ 最小绝对值）；由引理 3 可把唯一负号放到绝对值最小的格上，恰好取到 $T - 2m$。故三段决策即最优。∎

## 6. 复杂度分析

- **时间**：$O(n^2)$。单趟扫描统计四个量，每格 $O(1)$；$n \le 250$ 共至多 62500 格。
- **空间**：$O(1)$。仅常数个统计变量，不复制矩阵、不建访问标记。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long maxMatrixSum(vector<vector<int>>& matrix) {
        long long total = 0;               // 全体绝对值之和
        long long minAbs = LLONG_MAX;      // 绝对值最小的元素
        int negCnt = 0;                    // 负数个数
        bool hasZero = false;              // 是否存在 0
        for (const auto& row : matrix)
            for (int x : row) {
                long long a = x < 0 ? -(long long)x : (long long)x;
                total += a;
                minAbs = min(minAbs, a);
                if (x < 0) ++negCnt;
                else if (x == 0) hasZero = true;
            }
        // 负号个数为奇数且没有 0 能「吸收」负号时，最小绝对值处必须留一个负号
        if (negCnt % 2 == 1 && !hasZero) total -= 2 * minAbs;
        return total;
    }
};
```

### Python

```python
class Solution:
    def maxMatrixSum(self, matrix: list[list[int]]) -> int:
        total = 0                # 全体绝对值之和
        min_abs = None           # 绝对值最小的元素
        neg_cnt = 0              # 负数个数
        has_zero = False         # 是否存在 0
        for row in matrix:
            for x in row:
                a = abs(x)
                total += a
                if min_abs is None or a < min_abs:
                    min_abs = a
                if x < 0:
                    neg_cnt += 1
                elif x == 0:
                    has_zero = True
        # 负号个数为奇数且没有 0 能「吸收」负号时，最小绝对值处必须留一个负号
        if neg_cnt % 2 == 1 and not has_zero:
            total -= 2 * min_abs
        return total
```

> 💡 两份代码均通过官方示例（`4`、`16`）、含 0 边界（`[[-1,0],[0,0]] → 1`），并与 **BFS 符号形态暴力**（在「每格翻转标记」空间广搜所有可达形态取最大和）对拍 300 组随机矩阵（$n \in \{2,3\}$、值域含 0 与负数），全部一致。

## 8. 边界情况与易错点

1. **奇数个负数 + 有 0**：负号可以塞给 0，答案仍是 $\sum |x|$。漏判 `hasZero` 会错误地扣 $2 \times minAbs$。
2. **溢出**：$total$ 最大 $6.25 \times 10^{12}$，C++ `int` 直接爆；Python 无此虑但 C++ 必须 `long long`。
3. **0 不算负数**：计数条件是 `x < 0` 而非 `x <= 0`。把 0 计入负数会让奇偶判断出错的场景：如 $[[-1, 0]]$ 应为 1 而非 $-1$。
4. **全负矩阵**：$n^2$ 个负数，偶数个全消；$n^2$ 为奇（$n$ 奇）时剩一个给 $minAbs$。公式自动覆盖，无需特判。
5. **minAbs 初值**：C++ 用 `LLONG_MAX` 起步；Python 用 `None` 起步（矩阵至少 $2\times2$ 非空，不会未更新）。
6. **想当然「成对消除」位置**：负号不是只能和**物理上相邻**的负数消——它可以先搬过去再消。理解「搬运自由」是避免写复杂模拟的关键。
