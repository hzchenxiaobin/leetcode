# LeetCode 乘积为正数的最长子数组长度 题解

## 1. 题目概述

- **标题 / 题号**：乘积为正数的最长子数组长度（#1567，medium）
- **链接**：https://leetcode.cn/problems/maximum-length-of-subarray-with-positive-product/
- **来源**：LeetCode 第 204 场周赛 Q2
- **难度**：中等
- **标签**：数组、动态规划、贪心

**题意**：给定整数数组 `nums`，求**乘积为正数**的**最长非空连续子数组**的长度。乘积具体多大无关紧要，我们只关心它的**符号**；若不存在这样的子数组，返回 0。

**约束**：

- $1 \le nums.length \le 10^5$
- $-10^9 \le nums[i] \le 10^9$

> 💡 本题是 [152. 乘积最大子数组](https://leetcode.cn/problems/maximum-product-subarray/) 的「计数变体」：152 求乘积的最大**数值**，本题求乘积为正的最长**长度**。两者共享同一条核心洞察——**负数会让「正 / 负」两种状态互换**，所以必须同时维护两个状态。另有按零分段、数负数个数的贪心解法，见文末延伸。

## 2. 示例

**示例 1**

```text
输入：nums = [1,-2,-3,4]
输出：4
解释：整个数组乘积 1×(−2)×(−3)×4 = 24 > 0——负数恰好 2 个（偶数个）。
```

**示例 2**

```text
输入：nums = [0,1,-2,-3,-4]
输出：3
解释：最长的是 [1,-2,-3]，乘积 6 > 0；包含 0 的子数组乘积为 0，必须断开。
```

**示例 3**

```text
输入：nums = [-1,-2,-3,0,1]
输出：2
解释：[-1,-2] 与 [-2,-3] 乘积均为正；0 之后只剩 [1]，长度 1。
```

**补充示例**

```text
输入：nums = [-1]
输出：0
解释：唯一的非空子数组 [-1] 乘积为负，不存在乘积为正的子数组。
```

## 3. 解题思路

### 3.1 暴力思路：枚举起点 + 累乘

枚举每个子数组并累乘判断符号：

```text
ans = 0
for i in 0 .. n-1:            # 枚举左端点
    prod = 1
    for j in i .. n-1:        # 延伸右端点
        prod *= nums[j]       # 溢出风险！
        if prod > 0:
            ans = max(ans, j - i + 1)
```

- 时间 $O(n^2)$，在 $n = 10^5$ 下约 $5 \times 10^9$ 次内层操作，**必然超时**；
- 更致命的是累乘本身：$10^5$ 个绝对值可达 $10^9$ 的数连乘，**远超 64 位整数范围**。

> ⚠️ 两个瓶颈指向同一个**关键转念**：乘积为正当且仅当「不含 0 且负数个数为偶数」——符号只由**负数个数的奇偶**与**是否遇 0** 决定。既然只关心符号，就不必携带数值，只需数长度。

### 3.2 核心观察：正 / 负长度双状态，遇负互换、遇零清零

![核心观察：pos/neg 双状态在正数、负数、零三类元素下的转移](images/wc204_q2_state_swap.svg)

仿照 152 的双状态设计，把状态从「乘积值」换成「长度」。定义**以当前下标 $i$ 结尾**的两个状态：

- `pos`：乘积为**正**的最长子数组长度（不存在则为 $0$）；
- `neg`：乘积为**负**的最长子数组长度（不存在则为 $0$）。

按 $nums[i]$ 的符号三路转移：

| $nums[i]$ | 新 `pos` | 新 `neg` | 直觉 |
|-----------|----------|----------|------|
| $> 0$ | $pos + 1$ | $neg > 0\ ?\ neg + 1 : 0$ | 正数不改符号，两状态各自延伸 |
| $< 0$ | $neg > 0\ ?\ neg + 1 : 0$ | $pos + 1$ | 负数翻转符号，正负身份**互换** |
| $= 0$ | $0$ | $0$ | 乘积归零，**硬分隔符** |

表格里藏着一处不对称，恰是本题最精妙也最容易写错的地方：

1. **`pos + 1` 可以无条件写**：若 $pos = 0$（以 $i-1$ 结尾凑不出正乘积子数组），则 $pos + 1 = 1$ 恰好对应单元素子数组 $[nums[i]]$——正数自身就是正乘积，长度 1 天然合法。两种情形被同一个式子统一。
2. **`neg` 的更新必须带条件**：若 $neg = 0$，单靠一个正数 $nums[i]$ 凑不出负乘积，新 `neg` 只能是 0；盲目写 $neg + 1$ 会得到 1，等于宣称「$[nums[i]]$ 的乘积为负」（详见 §8 易错点 1）。

### 3.3 算法流程：单趟扫描 + 滚动变量

![算法流程：单趟扫描三路分支，O(n) 时间 O(1) 空间](images/wc204_q2_dp_flow.svg)

一遍扫描：读入 $x = nums[i]$，按符号走三路分支之一更新 `(pos, neg)`，随后立即 `ans = max(ans, pos)`。全程只有三个整数变量滚动，无需 DP 数组。

### 3.4 示例演算

![示例演算：示例 2 的 pos/neg 逐步互换过程](images/wc204_q2_walkthrough.svg)

对示例 2 `nums = [0,1,-2,-3,-4]` 手玩一遍状态机（见上图）：开局遇 0 双清零；`1` 把 `pos` 立起来；随后三个负数让 `pos / neg` 每步互换，`pos` 依次取值 $1 \to 0 \to 3 \to 2$，峰值 3 恰为答案（子数组 $[1,-2,-3]$）。注意最后一步 `pos` 从 3 **回落**到 2——`pos` 只描述「以当前下标结尾」的局部最优，全局答案必须靠 `ans` 边扫边记峰值。

## 4. 算法细节

1. **状态定义**：`pos` / `neg` 都是「以当前下标结尾」的**后缀型**状态，转移只依赖上一步的值，因此两个滚动变量即可，空间 $O(1)$。
2. **三路分支**：按 $x > 0$、$x < 0$、$x = 0$ 分类，`else` 分支恰好捕获零，无需额外判断。
3. **互换的实现**：$x < 0$ 时新 `neg` 依赖旧 `pos`，C++ 需临时变量留档，Python 用元组同时赋值一步完成。
4. **答案收集时机**：`ans = max(ans, pos)` 必须放在**每步转移之后**——`pos` 是局部量，扫描中会起落，循环结束后再取只能拿到最后一格的值。
5. **只比符号不碰数值**：全程没有一次乘法，天然免疫溢出，$|nums[i]| \le 10^9$ 完全无感。

## 5. 正确性证明

**引理 1（符号刻画）**：非空子数组的乘积为正，当且仅当它不含 0 且含有偶数个负数。

**证明**：实数乘积的符号由负因子的个数决定：偶数个负数相乘为正，奇数个为负；只要有一个因子为 0，乘积即为 0，非正。∎

**引理 2（转移方程）**：设 $pos_i$、$neg_i$ 为以 $i$ 结尾的乘积为正 / 负的最长子数组长度（不存在记 $0$），约定 $pos_{-1} = neg_{-1} = 0$，则 §3.2 表格中的三组公式成立。

**证明**：对 $i$ 归纳。以 $i$ 结尾的非空子数组，要么是单元素 $[nums[i]]$，要么由某个以 $i-1$ 结尾的子数组接上 $nums[i]$ 得到。逐 case 讨论：

- **$nums[i] > 0$**：正乘积子数组若为单元素则长 1；若由延伸得到，则前缀部分必为正乘积，长 $pos_{i-1}+1$。当 $pos_{i-1} = 0$ 时两式归并为 $pos_i = 1 = pos_{i-1}+1$。负乘积子数组不可能是单元素（正数自乘为正），只能由负乘积后缀延伸而来：$neg_{i-1} \ge 1$ 时 $neg_i = neg_{i-1}+1$，否则不存在（$neg_i = 0$）。
- **$nums[i] < 0$**：正乘积子数组不可能是单元素（负数自乘为负），只能由**负**乘积后缀乘负数翻转而来：$neg_{i-1} \ge 1$ 时 $pos_i = neg_{i-1}+1$，否则 $pos_i = 0$。负乘积子数组若为单元素则长 1；若由延伸得到，前缀必为正乘积，长 $pos_{i-1}+1$；两式归并为 $neg_i = pos_{i-1}+1$。
- **$nums[i] = 0$**：任何以 $i$ 结尾的子数组都含 0，由引理 1 乘积为 0，两类子数组均不存在，$pos_i = neg_i = 0$。∎

**定理（算法正确性）**：扫描结束后，`ans` 等于乘积为正的最长子数组长度。

**证明**：算法中滚动变量与 $(pos_i, neg_i)$ 逐项相同（初始值与三路转移和引理 2 一一对应）。一方面，任何正乘积子数组以其右端点 $i$ 结尾，长度不超过 $pos_i$，也不超过 `ans`，故 `ans` 不小于最优值；另一方面，每次刷新 `ans` 用到的 $pos_i$ 本身就是某个合法正乘积子数组的长度，故 `ans` 可达成。两者结合，`ans` 恰为最优值。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。每个元素只做一次符号判断和常数次比较 / 加法，相比暴力的 $O(n^2)$ 消除了起点间的重复计算。
- **空间复杂度**：$O(1)$。仅 `pos`、`neg`、`ans` 三个整数变量滚动，无需 DP 数组。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int getMaxLen(vector<int>& nums) {
        int pos = 0, neg = 0, ans = 0;
        for (int x : nums) {
            if (x > 0) {
                pos = pos + 1;
                neg = neg > 0 ? neg + 1 : 0;
            } else if (x < 0) {
                int oldPos = pos;                  // 互换前留档旧 pos
                pos = neg > 0 ? neg + 1 : 0;
                neg = oldPos + 1;
            } else {
                pos = neg = 0;                     // 0 是硬分隔符
            }
            ans = max(ans, pos);
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def getMaxLen(self, nums: List[int]) -> int:
        pos = neg = ans = 0
        for x in nums:
            if x > 0:
                pos, neg = pos + 1, (neg + 1 if neg else 0)
            elif x < 0:
                pos, neg = (neg + 1 if neg else 0), pos + 1  # 元组同时赋值完成互换
            else:
                pos = neg = 0
            ans = max(ans, pos)
        return ans
```

## 8. 边界情况与易错点

1. **`neg` 的条件更新（最高频错误）**：`x > 0` 且 `neg == 0` 时新 `neg` 必须为 0；写成 `neg + 1` 会凭空造出长度 1 的「负乘积子数组」，一步错、步步错。与之对称，`pos + 1` 的无条件写法是**安全**的（$pos = 0$ 时退化为单元素）。
2. **互换时覆盖旧值**：`x < 0` 分支里新 `neg` 依赖旧 `pos`，C++ 若先把新值写进 `pos` 再拿来算 `neg`，用的已是新值。用临时变量或 Python 元组同时赋值。
3. **遇 0 忘记清零**：0 不是普通元素——乘积一旦归零，任何跨越它的子数组都不合法，两状态必须同时归零。
4. **只在循环结束后取 `ans`**：`pos` 是后缀局部量，扫描中会起落（§3.4 中 3 → 2），峰值必须边扫边记。
5. **答案可以为 0**：如 `nums = [-1]` 或 `[-1, 0]`，不存在任何正乘积子数组，应返回 0 而不是 1。
6. **不要真去累乘**：不仅慢，还会溢出；本题从头到尾不需要一次乘法。
7. **比赛策略**：本题是 152 的模板迁移题，认出「双状态 + 遇负互换」后 5 分钟内可写完；若卡壳，先手玩示例 2 观察互换规律再动笔。
