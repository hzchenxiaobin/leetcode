# LeetCode 将子数组重新排列得到同一个二叉搜索树的方案数 题解

## 1. 题目概述

- **标题 / 题号**：将子数组重新排列得到同一个二叉搜索树的方案数（#1569，hard）
- **链接**：https://leetcode.cn/problems/number-of-ways-to-reorder-array-to-get-same-bst/
- **来源**：LeetCode 第 204 场周赛 Q4
- **难度**：困难
- **标签**：二叉搜索树、分治、组合数学、动态规划、乘法逆元

**题意**：给定数组 `nums`，它是 $1$ 到 $n$ 的一个排列。把 `nums` 的元素**依次**插入一棵初始为空的二叉搜索树（BST）。统计 `nums` 的多少种**重排**，插入后能得到与原顺序**完全相同**的 BST。答案对 $10^9 + 7$ 取模。

**约束**：

- $1 \le n \le 1000$；
- `nums` 是 $1 \sim n$ 的排列，元素互不相同。

> 💡 本题是「计数 + 组合数取模」的经典压轴题：不枚举排列，而是**自顶向下分治**——每个子问题的自由度只来自「左子序列 / 右子序列」的交错方式，答案是一串组合数的乘积。识别出「根 + 保序分区 + 交错组合数」三件套后，剩下的就是乘法逆元模板。

## 2. 示例

**示例 1**

```text
输入：nums = [2,1,3]
输出：1
解释：[2,3,1] 插入后同为「2 为根，1 在左、3 在右」；
      [3,2,1] 则以 3 为根，BST 不同。
```

**示例 2**

```text
输入：nums = [3,4,5,1,2]
输出：5
解释：以下 5 个排列得到相同的 BST：
      [3,1,2,4,5]  [3,1,4,2,5]  [3,1,4,5,2]  [3,4,1,2,5]  [3,4,1,5,2]
```

**示例 3**

```text
输入：nums = [1,2,3]
输出：0
解释：BST 退化为右链，插入顺序唯一，除原排列外再无其他方案。
```

## 3. 解题思路

### 3.1 暴力思路：枚举排列再建树比对

`nums` 是 $1 \sim n$ 的排列，重排共 $n!$ 种，每种还要 $O(n)$ 建树与比对。$n = 1000$ 时 $n!$ 是天文数字；即便 $n = 10$ 也有 $3.6 \times 10^6$ 种排列，毫无扩展余地。

> ⚠️ 方向错了：不该「枚举 + 验证」，而应**直接计数**——先刻画「什么样的排列能长出同一棵 BST」，再用组合数学一次算清。

### 3.2 核心观察：根固定 + 左右子序列保序交错

![核心观察：根固定，左右子序列各自保序、相互任意交错](images/wc204_q4_root_interleave_concept.svg)

BST 从空树起插，**首元素必为根**——它没有比较对象，直接落根。设首元素为 $a$（即根值），后续元素按与 $a$ 的大小分流：小于 $a$ 的最终都落在左子树，大于 $a$ 的都落在右子树。于是得到三条「铁律」：

1. **根不能变**：两棵 BST 相同则根相同，重排的首元素必须仍是 `nums[0]`；
2. **左子序列保序**：小于 $a$ 的元素在重排中的相对顺序，必须与原数组一致——左子树的形态完全由「这些元素谁先谁后插入」决定；
3. **右子序列保序**：同上，大于 $a$ 的元素相对顺序不变。

铁律之外的部分**完全自由**：左、右子序列在时间轴上可以任意**交错**。某个左子树元素插入时，无论右子树已插入了多少元素，它从根一路向左下行走的路径只由左子树中已插入的元素决定——比较只发生在值都小于 $a$ 的节点之间，与右子树元素何时出现毫不相干，反之亦然。

> 💡 **交错数 = 组合数**：左子序列长 $l$、右子序列长 $r$，保持各自内部顺序将两者交错排列，等价于从 $l + r$ 个位置中选 $l$ 个放左元素、其余放右元素，方案数 $\binom{l+r}{l}$。

于是得到分治递推（$f(S)$ 表示「$S$ 的、能长出同一棵 BST 的重排个数」）：

$$f(S) = \binom{l+r}{l} \times f(L) \times f(R)$$

其中 $L$、$R$ 是 $S[1:]$ 中按原序抽出的小于 / 大于根的子序列。递归基：$|S| \le 1$ 时排列唯一，$f = 1$。**答案**为 $f(\text{nums}) - 1$——因为 $f$ 把原排列自己也数了进去。

### 3.3 算法流程：预计算组合数 + 递归分治

![算法流程：组合数取模预计算与递归分治计数](images/wc204_q4_algorithm_flow.svg)

算法分两阶段。**阶段一**预计算阶乘 `fact[]` 与逆阶乘 `invFact[]`：模数 $p = 10^9 + 7$ 是质数，由费马小定理 $a^{p-2} \equiv a^{-1} \pmod{p}$，用一次快速幂求出 $\text{invFact}[n]$，再线性回推 $\text{invFact}[i] = \text{invFact}[i+1] \times (i+1)$，此后任意 $\binom{a}{b} \bmod p$ 均可 $O(1)$ 查表。**阶段二**按递推式递归：每层以首元素为根、保序分区出 `left` / `right`，返回 $\binom{l+r}{l} \cdot f(L) \cdot f(R) \bmod p$；主入口最后减 1 取模。

### 3.4 示例演算

![示例演算：递归分治与全部六种交错排列](images/wc204_q4_walkthrough.svg)

以示例 2 `nums = [3,4,5,1,2]` 走一遍（见上图）：第一层根为 $3$，$L = [1,2]$，$R = [4,5]$，$\binom{4}{2} = 6$；两个子问题各自是「右链」——$f([1,2]) = f([4,5]) = 1$。故 $f = 6 \times 1 \times 1 = 6$，答案 $6 - 1 = 5$，与示例一致。六种交错中恰好包含原排列 `[3,4,5,1,2]` 本身，正是「减 1」的来由。

> 💡 **示例 3 为何是 0**：`[1,2,3]` 每层的根都是当前最小值，左子序列恒为空，$\binom{r}{0} = 1$ 层层相乘仍得 $f = 1$，答案 $1 - 1 = 0$。凡是**链状 BST**（升序、降序排列）答案必为 0，可作对拍自检用例。

## 4. 算法细节

1. **保序分区**：`left = [x for x in S[1:] if x < root]`，`right` 同理。filter 天然保持相对顺序，**不需要排序**。
2. **组合数取模三件套**：`fact[0..n]` 递推 $O(n)$；`invFact[n] = fact[n]^(p−2) mod p`（快速幂 + 费马小定理）；`invFact[i] = invFact[i+1]·(i+1) mod p` 线性回推——避免做 $n$ 次快速幂。
3. **查询**：$\binom{a}{b} = \text{fact}[a] \times \text{invFact}[b] \times \text{invFact}[a-b] \bmod p$。本题查询上限是 $\binom{n-1}{\cdot}$，组合数表只需预计算到 $n$。
4. **防溢出**：C++ 用 `long long`，两两相乘后立即取模，中间积 $\le (p-1)^2 < 9 \times 10^{17} < 2^{63}$。
5. **递归基**：`len(S) <= 1` 返回 1（空序列与单元素各只有一种排列）。
6. **减 1 的取模时机**：`dfs` 返回的是 $f \bmod p$，可能为 $0$；`f − 1` 要先 `+MOD` 再取模，避免 C++ 出现负数。

## 5. 正确性证明

**引理 1（子树分解）**：设序列 $\sigma$ 的首元素为 $a$，$L_\sigma$、$R_\sigma$ 分别是 $\sigma[1:]$ 中按出现顺序抽出的「小于 $a$」「大于 $a$」子序列。记 $T(\sigma)$ 为按 $\sigma$ 顺序插入空树所得的 BST，则 $T(\sigma)$ 以 $a$ 为根，且左子树 $= T(L_\sigma)$，右子树 $= T(R_\sigma)$。

**证明**：对 $|\sigma|$ 归纳，$|\sigma| = 1$ 时左右子树皆空，成立。设 $|\sigma| > 1$：插入 $\sigma[1:]$ 的任意前缀后，树中根的左子树恰好由该前缀里 $< a$ 的元素构成、右子树由 $> a$ 的元素构成（每个元素先与 $a$ 比较分流，此后不再跨过根）。考虑插入某个 $x < a$：它与 $a$ 比较后转左，**此后遇到的节点全是左子树节点**，行走路径只由左子树当前形态决定，与右子树元素何时插入无关。因此左子树的演化与「把 $L_\sigma$ 依次插入空树」逐步一致，由归纳假设终态为 $T(L_\sigma)$；右子树对称同理。∎

**引理 2（判据）**：$T(\pi) = T(S)$ 当且仅当 $\pi[0] = S[0]$、$T(L_\pi) = T(L_S)$ 且 $T(R_\pi) = T(R_S)$。

**证明**：键互不相同的两棵 BST 相同，当且仅当根相同且左、右子树分别相同。对 $\pi$ 与 $S$ 分别应用引理 1，$T(\pi)$ 的根是 $\pi[0]$、左右子树是 $T(L_\pi), T(R_\pi)$；$T(S)$ 同理。逐项对应即得。∎

**定理（计数递推）**：记 $f(S) = \lvert \{\pi : \pi \text{ 是 } S \text{ 的重排且 } T(\pi) = T(S)\} \rvert$，则 $|S| \le 1$ 时 $f(S) = 1$；$|S| \ge 2$ 时

$$f(S) = \binom{|L_S|+|R_S|}{|L_S|} \cdot f(L_S) \cdot f(R_S).$$

**证明**：$|S| \le 1$ 时重排唯一，$f = 1$。设 $|S| \ge 2$，根值 $a = S[0]$。由引理 2（根相同部分），合法 $\pi$ 必有 $\pi[0] = a$。对满足 $\pi[0] = a$ 的重排建立映射

$$\Phi:\ \pi \mapsto (I,\ \pi_L,\ \pi_R),$$

其中 $\pi_L = L_\pi$（$\pi$ 中 $< a$ 的子序列）、$\pi_R = R_\pi$、$I$ 为 $\pi[1:]$ 共 $n-1$ 个位置中「左元素」所占的位置集合。$\Phi$ 是双射：给定 $(I, \pi_L, \pi_R)$，首位置填 $a$、$I$ 中位置按序填 $\pi_L$、其余位置按序填 $\pi_R$，唯一还原 $\pi$；逆向显然。再由引理 2，

$$T(\pi) = T(S) \iff T(\pi_L) = T(L_S) \ \text{且}\ T(\pi_R) = T(R_S),$$

即 $\pi_L$ 是 $L_S$ 的合法重排、$\pi_R$ 是 $R_S$ 的合法重排。三者（位置集合、$\pi_L$、$\pi_R$）的取法相互独立，故

$$f(S) = \binom{n-1}{|L_S|} \cdot f(L_S) \cdot f(R_S) = \binom{|L_S|+|R_S|}{|L_S|} \cdot f(L_S) \cdot f(R_S). \ \blacksquare$$

**推论**：所求答案 $= f(\text{nums}) - 1$。恒等重排总合法（$f \ge 1$），而题目统计的是「重排」出的其他方案数。∎

**注（取模正确性）**：$p = 10^9 + 7$ 为质数，且 $p \nmid i!$ 对所有 $i \le n$ 成立，故每个 $\text{fact}[i]$ 在模 $p$ 下可逆；费马小定理保证 $\text{fact}[n]^{p-2} \equiv (\text{fact}[n])^{-1} \pmod{p}$。递推只涉及乘法，模运算与整数计数逐步同构。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n^2)$。预计算 $O(n)$；递归树同一深度的各层分区扫描合计 $O(n)$，最坏（链状输入）深度 $n$，总计 $\sum_{i \le n} i = O(n^2)$。$n = 1000$ 时约 $5 \times 10^5$ 次比较，瞬间完成。
- **空间复杂度**：切片实现最坏 $O(n^2)$（链状时递归路径上每层各持一份子数组）；递归栈深最坏 $O(n)$。改为传索引区间 + 原地分区可降至 $O(n)$（见延伸思考）。

## 7. 参考代码

### C++

```cpp
class Solution {
    static constexpr long long MOD = 1000000007;
    vector<long long> fact, invFact;

    long long power(long long b, long long e) {          // 快速幂：费马小定理求逆元
        long long r = 1;
        b %= MOD;
        while (e > 0) {
            if (e & 1) r = r * b % MOD;
            b = b * b % MOD;
            e >>= 1;
        }
        return r;
    }

    void precompute(int n) {
        fact.assign(n + 1, 1);
        for (int i = 1; i <= n; i++) fact[i] = fact[i - 1] * i % MOD;
        invFact.assign(n + 1, 1);
        invFact[n] = power(fact[n], MOD - 2);            // 一次快速幂
        for (int i = n - 1; i >= 0; i--)                 // 线性回推逆阶乘
            invFact[i] = invFact[i + 1] * (i + 1) % MOD;
    }

    long long C(int a, int b) {
        if (b < 0 || b > a) return 0;
        return fact[a] * invFact[b] % MOD * invFact[a - b] % MOD;
    }

    long long dfs(vector<int>& s) {
        if (s.size() <= 1) return 1;                     // 递归基：排列唯一
        int root = s[0];
        vector<int> left, right;                         // filter 天然保序
        for (int i = 1; i < (int)s.size(); i++) {
            if (s[i] < root) left.push_back(s[i]);
            else right.push_back(s[i]);
        }
        long long ways = C((int)left.size() + (int)right.size(), (int)left.size());
        return ways * dfs(left) % MOD * dfs(right) % MOD;
    }

public:
    int numOfWays(vector<int>& nums) {
        precompute((int)nums.size());
        return (int)((dfs(nums) - 1 + MOD) % MOD);       // 排除原排列本身
    }
};
```

### Python

```python
class Solution:
    def numOfWays(self, nums: List[int]) -> int:
        MOD = 10**9 + 7
        n = len(nums)

        fact = [1] * (n + 1)
        for i in range(1, n + 1):
            fact[i] = fact[i - 1] * i % MOD
        inv_fact = [1] * (n + 1)
        inv_fact[n] = pow(fact[n], MOD - 2, MOD)         # 费马小定理
        for i in range(n - 1, -1, -1):
            inv_fact[i] = inv_fact[i + 1] * (i + 1) % MOD

        def comb(a: int, b: int) -> int:
            if b < 0 or b > a:
                return 0
            return fact[a] * inv_fact[b] % MOD * inv_fact[a - b] % MOD

        def dfs(arr: List[int]) -> int:
            if len(arr) <= 1:
                return 1
            root = arr[0]
            left = [x for x in arr[1:] if x < root]      # 保序分区
            right = [x for x in arr[1:] if x > root]
            ways = comb(len(left) + len(right), len(left))
            return ways * dfs(left) % MOD * dfs(right) % MOD

        return (dfs(nums) - 1) % MOD
```

## 8. 边界情况与易错点

1. **别忘了减 1**：$f$ 计入了原排列；且 `dfs` 返回的是 $f \bmod p$，可能为 $0$，C++ 中须写 `(dfs − 1 + MOD) % MOD` 防负数（Python 的 `%` 对负数天然友好）。
2. **$n = 1$**：$f = 1$，答案 0。
3. **链状输入答案为 0**：升序 / 降序数组每层 $l = 0$，$\binom{r}{0} = 1$，$f = 1$ → 答案 0。可用 `[1,2,3]` 等用例对拍自检。
4. **组合数表只需预计算到 $n$**：查询上限是 $\binom{n-1}{\cdot}$，惯性开到 $2n$ 属于浪费（虽不错但没必要）。
5. **中间乘法立即取模**：两个 $< p$ 的数相乘已达约 $10^{18}$，C++ 必须用 `long long` 且逐次取模，`int` 直接溢出。
6. **Python 递归深度**：链状输入递归深达 $n - 1 \approx 1000$，逼近默认上限；本地运行需 `sys.setrecursionlimit`，LeetCode 环境一般已调高。
7. **分区必须保序**：若手滑先排序再分区，等于抹掉了「相对顺序」这一唯一约束，答案会系统性偏大（示例 2 将得不到 5）。
8. **比赛策略**：本题思考重点全在「交错 = 组合数」这步转化上；想通之后就是组合数取模模板 + 15 行递归，赛时直接写 $O(n^2)$ 切片版即可，不必优化空间。
