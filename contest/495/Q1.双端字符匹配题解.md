# LeetCode 双端字符匹配 题解

## 1. 题目概述

- **标题 / 题号**：双端字符匹配（#3884，easy）
- **链接**：https://leetcode.cn/problems/first-matching-character-from-both-ends/
- **来源**：LeetCode 第 495 场周赛 Q1
- **难度**：简单
- **标签**：双指针、字符串

**题意**：给定长度为 `n` 的小写字母串 `s`，返回**最小**的下标 `i`，使得 `s[i] == s[n - i - 1]`（即左数第 `i` 个字符与右数第 `i` 个字符相同）；若不存在这样的下标，返回 `-1`。

**约束**：

- `1 <= n == s.length <= 100`
- `s` 仅包含小写英文字母

## 2. 示例

**示例 1**

```text
输入：s = "abcacbd"
输出：1
解释：i=1 时 s[1]='b' 与 s[5]='b' 相等；不存在更小的合法下标。
```

**示例 2**

```text
输入：s = "abc"
输出：1
解释：i=1 恰为中点（n-1-i == i），左右位置重合，字符自然相等。
```

**示例 3**

```text
输入：s = "abcdab"
输出：-1
解释：每个 i 都有 s[i] != s[n-i-1]，不存在合法下标。
```

## 3. 解题思路

### 3.1 暴力思路

按定义枚举所有下标 `i ∈ [0, n)`，逐一判断 `s[i] == s[n-1-i]`，返回第一个满足的下标。`n ≤ 100`，`O(n)` 直接通过——本题暴力即正解，关键在于**把循环范围和边界想清楚**。

### 3.2 核心观察：对撞双指针 + 对称性剪枝

![核心观察：对撞双指针逐层向内](images/first_matching_char_concept.svg)

把 `i` 和 `n-1-i` 看成**从两端同步内移的对撞双指针**：

1. **对称性**：条件 `s[i] == s[n-1-i]` 关于 `i` 与 `n-1-i` 对称。若某个 `i > n/2` 满足条件，则 `j = n-1-i < n/2` 也满足，且 `j < i`。因此**最小匹配下标（若存在）一定落在前半段** `[0, ⌊(n-1)/2⌋]`，枚举后半段是纯浪费。
2. **中点自匹配**：`n` 为奇数时，`i = (n-1)/2` 满足 `i == n-1-i`，即指针指向同一位置，`s[i] == s[n-1-i]` **恒成立**。所以奇数长度必有答案且不超过 `(n-1)/2`；`-1` 只可能出现在**偶数长度**且所有对称对均不相等时。

### 3.3 算法流程

```text
i 从 0 开始，L = i, R = n-1-i 同步内移：
while L <= R:
    if s[L] == s[R]: return L      # 首次相等，L 即最小下标
    L++, R--（即 i++）
return -1                          # 前半段扫完无匹配
```

### 3.4 示例演算

![示例演算：三个关键情形](images/first_matching_char_walkthrough.svg)

`s = "abcacbd"`：`(0,6)` 中 `a≠d`，`(1,5)` 中 `b==b`，返回 `1` ✓
`s = "abc"`：`(0,2)` 中 `a≠c`，`i=1` 为中点自匹配，返回 `1` ✓
`s = "abcdab"`：三组对称对全不等，返回 `-1` ✓

## 4. 算法细节

1. **循环上界**：等价写法有三种——`for i in range((n+1)//2)`、`while i <= n-1-i`、`for L, R in zip(s, reversed(s))`（Python 直接同时取正序/逆序字符）。上界取 `⌊(n-1)/2⌋`（含中点）即可。
2. **为何不用枚举后半段**：见 3.2 对称性论证，最小匹配下标不会超过中点；后半段的匹配下标都有更小的对称影子。
3. **数据结构**：无需任何额外结构，一次线性扫描 + 两个"虚拟指针"（实际只需下标 `i`）。
4. **提前返回**：首个命中立即返回，最坏情况（偶数长度全不等）也只扫半串。

## 5. 正确性证明

**引理 1（对称性）**：对任意 `i`，`s[i] == s[n-1-i]` 当且仅当 `s[n-1-i] == s[i]`。故匹配下标关于 `m = (n-1)/2` 对称成对出现；若存在匹配下标 `i > m`，则 `j = n-1-i` 也是匹配下标且 `j < m < i`。

**证明**：条件两侧字符互换后完全相同，等式与 `i`、`n-1-i` 的书写顺序无关。∎

**引理 2（中点自匹配）**：若 `n` 为奇数，取 `i = (n-1)/2`，则 `n-1-i = i`，`s[i] == s[i]` 恒真，故 `i` 是合法下标。

**证明**：`n-1-(n-1)/2 = (2(n-1) - (n-1))/2 = (n-1)/2 = i`（`n-1` 为偶数）。字符与自身相等。∎

**定理**：算法枚举 `i = 0, 1, …, ⌊(n-1)/2⌋` 并返回首个满足 `s[i] == s[n-1-i]` 的 `i`（无则 `-1`），返回值恰为最小匹配下标。

**证明**：由引理 1，若存在任何匹配下标，则必存在不超过 `⌊(n-1)/2⌋` 的匹配下标（比中点大的都有更小的对称者），故枚举范围覆盖了可能的最小值。算法按升序检查该范围内全部候选，首个命中者即范围内最小、由引理 1 亦为全局最小。若范围内无命中，由引理 1 后半段也不会有，由引理 2 奇数长度不可能出现此情形（中点必命中），返回 `-1` 正确。∎

## 6. 复杂度分析

- **时间复杂度**：`O(n)`。最坏扫描前半段约 `n/2 + 1` 个下标，每个 `O(1)` 比较；`n ≤ 100` 远低于限制。
- **空间复杂度**：`O(1)`。仅下标 `i`（及隐含的 `n-1-i`），无额外数据结构。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int firstMatchingIndex(string s) {
        int n = s.size();
        for (int i = 0; i <= n - 1 - i; i++) {
            if (s[i] == s[n - 1 - i]) {
                return i;
            }
        }
        return -1;
    }
};
```

### Python

```python
class Solution:
    def firstMatchingIndex(self, s: str) -> int:
        n = len(s)
        for i in range((n + 1) // 2):
            if s[i] == s[n - 1 - i]:
                return i
        return -1
```

## 8. 边界情况与易错点

1. **`n = 1`**：`i = 0` 即中点，自匹配，直接返回 `0`，不会走到 `-1`。
2. **奇数长度必有答案**：中点 `i == n-1-i` 恒匹配（示例 2）；因此只有**偶数长度**才可能返回 `-1`（示例 3）。若比赛时对此没把握，直接枚举全范围 `[0, n)` 也正确，只是多扫一半。
3. **循环上界差一错误**：`range((n+1)//2)` 含中点；写成 `range(n // 2)` 会漏掉奇数中点，导致 `"abc"` 错误地返回 `-1`。
4. **返回的是下标不是字符**，也别把 `i` 与 `n-1-i` 混着返回（取更小者即 `i`，因为枚举范围内 `i <= n-1-i`）。
5. **顺序敏感**：题目要**最小**下标，必须从 `i = 0` 升序枚举并首次命中即返回。
