# LeetCode 两地调度 题解

## 1. 题目概述

- **标题 / 题号**：两地调度（#1029，medium）
- **链接**：https://leetcode.cn/problems/two-city-scheduling/
- **来源**：LeetCode 第 133 场周赛 Q1
- **难度**：中等
- **标签**：贪心、数组、排序

**题意**：公司要面试 $2n$ 个人，其中 $n$ 人飞往 $A$ 市、$n$ 人飞往 $B$ 市。给定数组 `costs`，`costs[i] = [aCost_i, bCost_i]` 表示第 $i$ 人飞 $A$、飞 $B$ 的费用。求满足「每城恰好 $n$ 人」的最小总费用。

**约束**：

- $2 \cdot n == costs.length$，`costs.length` 为偶数
- $2 \le costs.length \le 100$
- $1 \le aCost_i, bCost_i \le 1000$

> 💡 这是一个**带基数约束的选择问题**：不能简单地把每个人派到更便宜的城市，因为每城必须恰好 $n$ 人。

## 2. 示例

**示例 1**

```text
输入：costs = [[10,20],[30,200],[400,50],[30,20]]
输出：110
解释：1、2 号去 A（10 + 30），3、4 号去 B（50 + 20），总计 110。
```

**示例 2**

```text
输入：costs = [[259,770],[448,54],[926,667],[184,139],[840,118],[577,469]]
输出：1859
```

**示例 3**

```text
输入：costs = [[515,563],[451,713],[537,709],[343,819],[855,779],[457,60],[650,359],[631,42]]
输出：3086
```

## 3. 解题思路

### 3.1 暴力思路

从 $2n$ 个人里选 $n$ 个去 $A$（其余去 $B$），枚举所有组合：

$$\binom{2n}{n} = \binom{100}{50} \approx 10^{29}$$

完全不可行。即使用 DP（$O(n^2)$ 背包）也能做，但本题有更简单的贪心结构。

### 3.2 核心观察：先全部派 B，再挑 n 个人「改派」

![基准 + 改派：把问题化成「选 n 个最小的差额」](images/wc133_q1_delta_concept.svg)

**第一步：设基准**。假设所有人都去 $B$，总费用为

$$S_B = \sum_i bCost_i$$

**第二步：看改派代价**。把第 $i$ 个人改派到 $A$，总费用变化为

$$\Delta_i = aCost_i - bCost_i$$

于是「选一个恰好 $n$ 人的集合 $T$ 去 $A$」的总费用是

$$S_B + \sum_{i \in T} \Delta_i$$

要最小化它，只需让 $\sum_{i \in T}\Delta_i$ 最小——**选出 $\Delta_i$ 最小的 $n$ 个人**。

**第三步：排序**。按 $\Delta_i = aCost_i - bCost_i$ **升序**排序，前 $n$ 个人去 $A$、后 $n$ 个人去 $B$。

等价说法：$\Delta_i$ 越小说明「去 $A$ 相对去 $B$ 越划算」，最划算的 $n$ 个人当然应该去 $A$。

> 💡 与「把便宜的优先」的朴素贪心区别：朴素贪心可能让所有人都去同一个便宜的城市，违反「每城 $n$ 人」；而「选 $n$ 个最小差额」天然满足基数约束。

### 3.3 算法流程

![算法流程：排序 → 前半去 A、后半去 B](images/wc133_q1_algorithm_flow.svg)

```text
1. 把 costs 按 (aCost - bCost) 升序排序
2. n = len(costs) / 2
3. ans = sum(costs[0..n-1] 的 aCost) + sum(costs[n..2n-1] 的 bCost)
4. 返回 ans
```

### 3.4 示例演算

![示例演算：差额排序后的切分](images/wc133_q1_walkthrough.svg)

对 `costs = [[10,20],[30,200],[400,50],[30,20]]`：

| 人 | $aCost$ | $bCost$ | $\Delta = a - b$ | 排序后位置 | 去向 |
|---|---|---|---|---|---|
| 1 | 10 | 20 | −10 | 2 | A |
| 2 | 30 | 200 | −170 | 1 | A |
| 3 | 400 | 50 | 350 | 4 | B |
| 4 | 30 | 20 | 10 | 3 | B |

排序后顺序：$[2, 1, 4, 3]$。前 $n = 2$ 个（人 2、1）去 $A$：$30 + 10 = 40$；后两个（人 4、3）去 $B$：$20 + 50 = 70$。总费用 $110$ ✓，与人 1、2 去 A、3、4 去 B 的方案一致。

## 4. 算法细节

1. **排序键**：`aCost - bCost`，升序；C++ 用 `sort` + lambda，Python 用 `key=lambda c: c[0] - c[1]`。
2. **切分点**：`n = len(costs) / 2`，前 $n$ 个去 $A$、后 $n$ 个去 $B$。
3. **不要修改输入时可拷贝**：LeetCode 允许原地排序，若需保留输入则先 `copy`。
4. **数值范围**：最大总费用 $100 \times 1000 = 10^5$，`int` 足够。
5. **相等差额**：$\Delta_i$ 相同时顺序任意，结论不变（交换论证对相等情形也成立）。
6. **另一种写法**：也可以算 $\min(\sum_{i<n} a + \sum_{i \ge n} b)$，形式上更短；注意不要漏掉 `n` 的计算。

## 5. 正确性证明

**引理 1（方案 ↔ 集合）**：任一合法方案与「恰好含 $n$ 个人的集合 $T$（去 $A$）」一一对应。

**证明**：合法方案要求恰好 $n$ 人去 $A$、$n$ 人去 $B$，故「去 $A$ 的人的集合」恰有 $n$ 个元素；反之任给 $n$ 元集合 $T$，令 $T$ 去 $A$、其余去 $B$，即得合法方案。∎

**引理 2（目标函数化简）**：方案 $T$ 的总费用为 $S_B + \sum_{i \in T}\Delta_i$。

**证明**：总费用 $=\sum_{i \in T} aCost_i + \sum_{i \notin T} bCost_i = \sum_i bCost_i + \sum_{i\in T}(aCost_i - bCost_i) = S_B + \sum_{i \in T}\Delta_i$。∎

**引理 3（选最小的 $n$ 个差额最优）**：设 $\Delta$ 升序排列为 $\delta_1 \le \delta_2 \le \cdots \le \delta_{2n}$，则对任意 $n$ 元下标集合 $T$，有 $\sum_{i \in T}\Delta_i \ge \sum_{k=1}^{n}\delta_k$。

**证明**：设 $T$ 对应的差额为 $t_1 \le \cdots \le t_n$（排序后），则第 $k$ 小的 $t_k \ge \delta_k$（因为 $t_k$ 至少是全体中第 $k$ 小的，即不小于全局第 $k$ 小）。故 $\sum t_k \ge \sum \delta_k$。∎

**定理**：算法返回最小总费用。

**证明**：算法取的 $T^*$ 恰为 $\Delta$ 最小的 $n$ 个人（升序排序后的前 $n$ 个），由引理 3 它使 $\sum_{T}\Delta$ 取最小，再由引理 2 总费用也最小。由引理 1，$T^*$ 对应合法方案。故算法结果等于最优值。∎

## 6. 复杂度分析

- **时间**：$O(n \log n)$，排序占主导（$n$ 为人数，$\le 100$）；求和 $O(n)$。
- **空间**：$O(1)$ 额外空间（原地排序）；若不允许修改输入，则 $O(n)$ 拷贝。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int twoCitySchedCost(vector<vector<int>>& costs) {
        sort(costs.begin(), costs.end(), [](const vector<int>& x, const vector<int>& y) {
            return x[0] - x[1] < y[0] - y[1];      // 按「去 A 相对去 B 的差额」升序
        });
        int n = (int)costs.size() / 2, ans = 0;
        for (int i = 0; i < n; i++) ans += costs[i][0];              // 前 n 个去 A
        for (int i = n; i < (int)costs.size(); i++) ans += costs[i][1]; // 后 n 个去 B
        return ans;
    }
};
```

### Python

```python
class Solution:
    def twoCitySchedCost(self, costs: list[list[int]]) -> int:
        costs.sort(key=lambda c: c[0] - c[1])   # 按差额升序
        n = len(costs) // 2
        return sum(c[0] for c in costs[:n]) + sum(c[1] for c in costs[n:])
```

## 8. 边界情况与易错点

1. **$n = 1$**：`costs` 只有 2 人，各去一处，答案是 `min(a0+b1, a1+b0)`；排序后取前 1 去 A、后 1 去 B，正好是这个 min。
2. **差额相等**：多个 $\Delta$ 相同时切分位置任意，答案不变。
3. **差额为负**：负差额表示去 A 更便宜，排序后它们自然排在最前面。
4. **朴素贪心会错**：如果只按「每人选便宜的城市」，可能出现某一城市人数超标，必须用差额排序。
5. **排序方向**：升序！写成降序会把最不划算的 $n$ 个人派去 $A$。
6. **不要用 `aCost` 或 `bCost` 单独排序**：决定性的是**差额**，不是两列中的任何一列。
7. **总费用溢出**：$100 \times 1000 = 10^5$，`int` 安全。
