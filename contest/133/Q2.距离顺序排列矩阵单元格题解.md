# LeetCode 距离顺序排列矩阵单元格 题解

## 1. 题目概述

- **标题 / 题号**：距离顺序排列矩阵单元格（#1030，easy）
- **链接**：https://leetcode.cn/problems/matrix-cells-in-distance-order/
- **来源**：LeetCode 第 133 场周赛 Q2
- **难度**：简单
- **标签**：数组、数学、矩阵、排序、几何

**题意**：给定 $rows \times cols$ 的矩阵与其中的坐标 $(rCenter, cCenter)$。把**所有**单元格按「到中心点的曼哈顿距离」从小到大排列，返回坐标列表。

单元格 $(r_1, c_1)$ 与 $(r_2, c_2)$ 的距离定义为

$$d = |r_1 - r_2| + |c_1 - c_2|$$

距离相同的单元格之间**顺序任意**。

**约束**：

- $1 \le rows, cols \le 100$
- $0 \le rCenter < rows$，$0 \le cCenter < cols$

> 💡 这是一道「排序键是几何量」的签到题：把 $rows \times cols$ 个格子全列出来，按距离排序即可；也可以按距离桶排序做到线性。

## 2. 示例

**示例 1**

```text
输入：rows = 1, cols = 2, rCenter = 0, cCenter = 0
输出：[[0,0],[0,1]]
解释：中心是 (0,0)；到 (0,0) 距离 0，到 (0,1) 距离 1。
```

**示例 2**

```text
输入：rows = 2, cols = 2, rCenter = 0, cCenter = 1
输出：[[0,1],[0,0],[1,1],[1,0]]
解释：距离依次为 0、1、1、2；距离为 1 的两个格子顺序任意。
```

**示例 3**

```text
输入：rows = 2, cols = 3, rCenter = 1, cCenter = 2
输出：[[1,2],[0,2],[1,1],[0,1],[1,0],[0,0]]
解释：距离依次为 0、1、1、2、2、3。
```

## 3. 解题思路

### 3.1 暴力思路

没有任何「暴力优化」的空间：直接生成全部 $rows \times cols$ 个坐标，算距离，按距离排序。这就是一个 $O(rc \log(rc))$ 的排序问题，$100 \times 100 = 10^4$ 个元素，$10^4 \log 10^4 \approx 1.3 \times 10^5$ 次比较，绰绰有余。

唯一需要注意的是「距离要算对」：曼哈顿距离是行列差绝对值之和，不是欧氏距离，也不是切比雪夫距离（max）。

### 3.2 核心观察：距离的取值只有 $O(rows + cols)$ 种

![距离分层：同一距离的格子构成一圈“菱形”](images/wc133_q2_distance_layers.svg)

中心到任意格子的距离 $d = |r - rCenter| + |c - cCenter|$，取值范围是

$$0 \le d \le (rows - 1) + (cols - 1) \le 198$$

也就是说**只有 $\le 199$ 种不同的键**。于是可以不用比较排序，而是**按距离分桶**：

1. 开 $rows + cols - 1$ 个桶（下标为距离）；
2. 遍历所有格子，把它放进 `bucket[d]`；
3. 从 $d = 0$ 开始依次输出各桶内容。

复杂度降到 $O(rows \cdot cols + \text{距离范围})$，即线性。这是「键值域小 → 桶排序」的典型应用。

> 💡 两种写法都对。排序版更短、更不容易写错；桶排序版在 $rows, cols$ 很大时更快。本题数据范围下两者都能过，题解给出排序版为主、桶排序为对照。

### 3.3 算法流程

![算法流程：枚举全部格子 → 计算距离 → 排序输出](images/wc133_q2_algorithm_flow.svg)

```text
1. ans = []
2. for r = 0 .. rows-1:
       for c = 0 .. cols-1:
           ans.push([r, c])
3. ans 按 |r - rCenter| + |c - cCenter| 升序排序
4. 返回 ans
```

### 3.4 示例演算

![示例演算：2×3 矩阵的距离分层](images/wc133_q2_walkthrough.svg)

对 $rows = 2, cols = 3$，中心 $(1, 2)$：

| 格子 | $\lvert r-1 \rvert$ | $\lvert c-2 \rvert$ | 距离 | 桶 |
|---|---|---|---|---|
| (1,2) | 0 | 0 | 0 | 第 0 桶 |
| (0,2) | 1 | 0 | 1 | 第 1 桶 |
| (1,1) | 0 | 1 | 1 | 第 1 桶 |
| (0,1) | 1 | 1 | 2 | 第 2 桶 |
| (1,0) | 0 | 2 | 2 | 第 2 桶 |
| (0,0) | 1 | 2 | 3 | 第 3 桶 |

按桶依次输出：`[[1,2],[0,2],[1,1],[0,1],[1,0],[0,0]]`，与示例 3 一致（同桶内顺序任意）✓。

## 4. 算法细节

1. **距离公式**：`abs(r - rCenter) + abs(c - cCenter)`，别写成 `abs((r - rCenter) + (c - cCenter))`。
2. **输出顺序**：题目允许多解，评测一般做集合 + 距离单调性检查；排序版自然满足「距离非降」。
3. **桶的数量**：最大距离为 $(rows-1) + (cols-1)$，桶数组长度取 `rows + cols - 1` 即可（下标 0 到 $rows+cols-2$）。
4. **C++ 排序 lambda**：捕获 `rCenter, cCenter`（按值捕获），或用 `[&]`。
5. **坐标编码**：桶排序时可以直接存 `{r, c}` 对，也可以把格子编码为 `r * cols + c` 再解码，省空间。
6. **返回类型**：`vector<vector<int>>` / `list[list[int]]`，必须是所有格子的一个排列（每个恰好出现一次）。

## 5. 正确性证明

**引理 1（距离函数合法）**：$d(r, c) = |r - rCenter| + |c - cCenter|$ 是非负整数，且 $d(rCenter, cCenter) = 0$。

**证明**：绝对值非负，故 $d \ge 0$；代入中心点两项均为 0。∎

**引理 2（排序版输出正确）**：把全部格子按 $d$ 升序排列，得到的序列满足「距离非降」，且包含每个格子恰好一次。

**证明**：枚举双重循环生成 $rows \cdot cols$ 个互不相同的 $(r,c)$，恰好覆盖全部格子一次；排序不增删元素，故仍是全部格子的一次排列；按 $d$ 升序排序保证相邻两项的 $d$ 值非降。∎

**引理 3（桶排序版输出正确）**：按距离分桶后从 $d = 0$ 递增输出，得到的序列距离非降，且包含全部格子一次。

**证明**：每个格子被放入且仅放入距离对应的桶；按 $d$ 递增遍历桶，桶内元素距离都等于 $d$，故整体距离非降，元素不重不漏。∎

**定理**：算法返回的序列满足题目要求（全部格子、按距离从小到大，同距离顺序任意）。

**证明**：由引理 1 距离计算正确，由引理 2（或引理 3）输出是全部格子的一个排列且距离非降，正是题目要求的顺序。∎

## 6. 复杂度分析

- **排序版**：时间 $O(rc \log(rc))$，空间 $O(rc)$。$rc \le 10^4$，实际运行极快。
- **桶排序版**：时间 $O(rc + (rows + cols))$，空间 $O(rc)$。
- 两者都远优于任何指数级做法（本题也不存在指数级陷阱）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<vector<int>> allCellsDistOrder(int rows, int cols, int rCenter, int cCenter) {
        vector<vector<int>> ans;
        ans.reserve(rows * cols);
        for (int r = 0; r < rows; r++)
            for (int c = 0; c < cols; c++)
                ans.push_back({r, c});

        sort(ans.begin(), ans.end(), [&](const vector<int>& x, const vector<int>& y) {
            int dx = abs(x[0] - rCenter) + abs(x[1] - cCenter);
            int dy = abs(y[0] - rCenter) + abs(y[1] - cCenter);
            return dx < dy;
        });
        return ans;
    }
};
```

### Python

```python
class Solution:
    def allCellsDistOrder(self, rows: int, cols: int, rCenter: int, cCenter: int) -> list[list[int]]:
        cells = [[r, c] for r in range(rows) for c in range(cols)]
        cells.sort(key=lambda p: abs(p[0] - rCenter) + abs(p[1] - cCenter))
        return cells
```

## 8. 边界情况与易错点

1. **$1 \times 1$ 矩阵**：只有中心一个格子，返回 `[[0,0]]`，排序与桶排序都能正确处理。
2. **单行 / 单列**：$rows = 1$ 时距离退化为 $|c - cCenter|$，排序结果就是「向两侧扩散」。
3. **距离公式写错**：曼哈顿距离必须是两个绝对值之和；写成 `abs(r + c - rCenter - cCenter)` 会把对角线距离算错。
4. **中心在角上**：如 $(0,0)$，距离最大值为 $(rows-1)+(cols-1)$，桶数组长度要够。
5. **同一距离的顺序**：题目明确允许多解，不要为了「字典序」额外排序——那会多花时间且没有必要。
6. **返回的是坐标而不是距离**：不要返回距离数组。
7. **C++ `abs` 的重载**：对 `int` 用 `std::abs`（`<cstdlib>`/`<cmath>` 均可），传浮点会得到不同结果。
