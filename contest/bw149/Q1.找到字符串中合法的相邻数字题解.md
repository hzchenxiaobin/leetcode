# LeetCode 找到字符串中合法的相邻数字 题解

## 1. 题目概述

- **标题 / 题号**：找到字符串中合法的相邻数字（#3438，easy）
- **链接**：https://leetcode.cn/problems/find-valid-pair-of-adjacent-digits-in-string/
- **来源**：LeetCode 第 149 场双周赛 Q1
- **难度**：简单
- **标签**：哈希表、字符串、计数

**题意**：给定只含 `'1'~'9'` 的字符串 `s`。一对**相邻**字符 `s[i], s[i+1]` 称为**合法**的，当且仅当：

1. 两个数字**不相等**；
2. 在**整个字符串** `s` 中，这两个数字各自的**出现次数恰好等于它本身的数值**，即 `cnt[s[i]] = s[i]` 且 `cnt[s[i+1]] = s[i+1]`。

从左到右扫描，返回**最先**出现的合法相邻对（返回这两字符构成的长为 2 的字符串）；不存在则返回空字符串 `""`。

**约束**：

- $2 \le |s| \le 100$
- `s` 只包含 `'1'` 到 `'9'` 的数字，不含 `'0'`

## 2. 示例

**示例 1**

```text
输入：s = "2523533"
输出："23"
解释：'2' 出现 2 次，'3' 出现 3 次，恰好都等于自身；
      i = 2 处的 "23" 是第一个合法的相邻对。
```

**示例 2**

```text
输入：s = "221"
输出："21"
解释：'2' 出现 2 次，'1' 出现 1 次；i = 0 的 "22" 两数字相同，
      i = 1 的 "21" 合法，故返回 "21"。
```

**示例 3**

```text
输入：s = "22"
输出：""
解释：唯一的相邻对 "22" 两数字相同，不合法。
```

## 3. 解题思路

### 3.1 暴力思路

对每个相邻对 `(i, i+1)`，重新扫一遍 `s` 数出这两个数字各出现几次，再判定是否合法，复杂度 $O(n^2)$。$n \le 100$ 时确实能过，但每次判定都重扫整串毫无必要：**频次是整串的全局属性**，与在哪一对上判定无关，先一次性算好就能把每次判定降到 $O(1)$。

### 3.2 核心观察：全局频次表 + 左侧优先扫描

![先统计全局频次，再从 i = 2 处命中第一个合法对 "23"](images/bw149_q1_pair_scan.svg)

两个关键点：

- **频次表是全局的**：用长度 10 的桶数组 `cnt[0..9]` 扫一遍 `s` 即可得到全部数字的出现次数，之后每对相邻数字的判定都是两次数组查询，$O(1)$。
- **"最先找到"由扫描顺序保证**：题目要的是**最左**的合法对，那么从 $i=0$ 开始自左向右检查，第一个通过判定的一对天然就是答案，无需比较下标。

判定写成一行即可：

$$s[i] \ne s[i+1] \;\wedge\; cnt[s[i]] = s[i] \;\wedge\; cnt[s[i+1]] = s[i+1]$$

注意这里的 `cnt[...] = ...` 比较的是**数值**：`cnt[a]` 是次数，右边的 `a` 是数字 $1\sim 9$。例如字符 `'5'` 必须出现恰好 5 次，出现 2 次或 6 次都不行。

### 3.3 算法流程

![算法流程：一次计数，一次线性扫描，命中即返回](images/bw149_q1_algorithm_flow.svg)

```text
1. cnt[0..9] 全部置 0
2. for ch in s:  cnt[ch - '0'] += 1
3. for i = 0 .. n-2:
       a = s[i] - '0',  b = s[i+1] - '0'
       若 a != b 且 cnt[a] == a 且 cnt[b] == b:  返回 s[i..i+1]
4. 返回 ""
```

### 3.4 示例演算

![示例 1 逐对判定表：只有 i = 2 的 "23" 三个条件全过](images/bw149_q1_example_walkthrough.svg)

对示例 1 的 `s = "2523533"`，统计得 `cnt[2] = 2`、`cnt[3] = 3`、`cnt[5] = 2`，其余数字为 0。逐对检查：

| i | 相邻对 | 两数字不同 | cnt[a] = a | cnt[b] = b | 结论 |
|---|--------|-----------|------------|------------|------|
| 0 | "25" | ✓ | 2 = 2 ✓ | 2 ≠ 5 ✗ | 淘汰 |
| 1 | "52" | ✓ | 2 ≠ 5 ✗ | 2 = 2 ✓ | 淘汰 |
| 2 | "23" | ✓ | 2 = 2 ✓ | 3 = 3 ✓ | **命中** |
| 3 | "35" | ✓ | 3 = 3 ✓ | 2 ≠ 5 ✗ | 不合法 |
| 4 | "53" | ✓ | 2 ≠ 5 ✗ | 3 = 3 ✓ | 不合法 |
| 5 | "33" | ✗ | — | — | 不合法 |

下标 2 是第一个三个条件全过的地方，故返回 `"23"`。示例 2、3 分别踩中"靠左的 `"22"` 相同"和"整串只有一对且相同"两种情形。

## 4. 算法细节

1. **桶数组大小为 10**：字符是 `'1'~'9'`，但用 `cnt[10]` 同时容纳下标 0 的占位，避免 `-1` 偏移，代码更好读。
2. **一次计数、一次扫描**：两趟独立的线性遍历，互不干扰；不要在扫描时边读边改 `cnt`，否则后半段的次数还没统计完，判定就会错。
3. **字符要转成数值**：C++ 用 `ch - '0'`，Python 用 `ord(ch) - 48`；`'5'` 的 ASCII 是 53，直接和 5 比较必然不等。
4. **判定顺序**：先判 `a != b`（严格不相等），再查两个计数。三条件是**与**关系，任一不满足即淘汰。
5. **返回 `s.substr(i, 2)` / `s[i:i+2]`**：返回的是**原串中这对字符**，不是拼接数字。
6. **`"最先"` 不做额外处理**：正序扫描 + 命中即返回，天然满足"最先"。如果反过来从右往左扫，就要额外记录并比较。

## 5. 正确性证明

**引理 1（频次表正确）**：第 2 步结束后，对任意 $d \in \{1,\dots,9\}$，`cnt[d]` 等于字符 `'d'` 在 `s` 中的出现次数。

**证明**：初始全 0；遍历 `s` 时，每个字符 `ch` 恰好让其对应的桶 `cnt[ch - '0']` 加 1。由加法交换律与遍历的完备性（每个位置被访问且仅被访问一次），最终 `cnt[d]` 就是从 0 到 $n-1$ 中满足 `s[j] = 'd'` 的下标个数。∎

**引理 2（判定等价）**：在第 2 步之后，对任意下标 $i$，`cnt[s[i]] = s[i]` 当且仅当字符 `s[i]` 在 `s` 中的出现次数等于它代表的数字。

**证明**：由引理 1，`cnt[s[i]]` 即出现次数；`s[i]` 作为数值就是它代表的数字（例如字符 `'7'` 代表 7）。两者相等即"出现次数 = 数字本身"。∎

**定理**：算法返回值等于 `s` 中最先出现的合法相邻对；若不存在则返回 `""`。

**证明**：分两点。

1. **正确性**：若算法在第 $i$ 步返回，则由引理 2，`cnt[a] = a`、`cnt[b] = b` 分别是"出现次数 = 数字本身"，且循环内已判 `a ≠ b`，故 `(i, i+1)` 是合法对，返回值取自原字符串，形式正确。
2. **最先性**：若存在合法对，设其最小下标为 $i^\*$，则由该对合法性，上述三个条件在 $i^\*$ 处全部成立。循环按 $0,1,\dots$ 递增，所有 $i < i^\*$ 均不合法（否则与最小性矛盾），故循环第一次返回必发生在 $i^\*$，与"最左合法对"一致。若循环走完仍未返回，说明不存在任何合法对，返回 `""` 也正确。∎

## 6. 复杂度分析

- **时间**：$O(n)$。第一趟计数 $O(n)$；第二趟至多 $n-1$ 次、每次 $O(1)$ 判定，共 $O(n)$。合计 $O(n)$，$n \le 100$ 时远低于时限。
- **空间**：$O(1)$。只有大小 10 的计数数组与常数个临时变量，与 $n$ 无关。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    string findValidPair(string s) {
        int cnt[10] = {0};
        for (char ch : s) cnt[ch - '0']++;
        for (int i = 0; i + 1 < (int)s.size(); i++) {
            int a = s[i] - '0', b = s[i + 1] - '0';
            if (a != b && cnt[a] == a && cnt[b] == b) return s.substr(i, 2);
        }
        return "";
    }
};
```

### Python

```python
class Solution:
    def findValidPair(self, s: str) -> str:
        cnt = [0] * 10
        for ch in s:
            cnt[ord(ch) - 48] += 1
        for i in range(len(s) - 1):
            a, b = ord(s[i]) - 48, ord(s[i + 1]) - 48
            if a != b and cnt[a] == a and cnt[b] == b:
                return s[i:i + 2]
        return ""
```

## 8. 边界情况与易错点

1. **"恰好"不是"至少"**：`'5'` 出现 5 次才合法，出现 6 次同样淘汰。这是本题唯一的思维陷阱，也是与"频次至少"类题目的关键区别。
2. **两数字必须不同**：`"33"`、`"22"` 这类相同对即使频次都对也不合法（示例 3 正是这个反例）。
3. **字符与数值混淆**：`cnt[ch]` 用字符索引在 C++ 里也能编译（隐式转 `int`，如 `'5'` → 53），数组越界且结果必然错误，务必 `ch - '0'`。
4. **先统计后判定**：把计数和扫描合在一趟里（边扫边加边判定）会用到不完整的频次，属于隐蔽 WA。
5. **`n = 2` 时只有一对**：循环上界是 `i + 1 < n`，不要越界访问 `s[i+1]`。
6. **没有解时返回空串而非 `"0"` 或 `null`**：题目明确要求 `""`，直接 `return ""`。
7. **不要在扫描时排序或去重**：题目要求的是**子串中相邻的两个字符**，排序会破坏相邻关系，输出也会错。
