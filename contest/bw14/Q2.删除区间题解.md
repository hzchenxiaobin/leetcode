# LeetCode 删除区间 题解

## 1. 题目概述

- **标题 / 题号**：删除区间（#1272，medium）
- **链接**：https://leetcode.cn/problems/remove-interval/
- **来源**：LeetCode 第 14 场双周赛 Q2
- **难度**：中等
- **标签**：数组、区间

**题意**：给定一个**有序、互不相交**的半开区间列表 `intervals`，每个 `intervals[i] = [a, b]` 表示实数集合 $\{x : a \le x < b\}$。再给定一个区间 `toBeRemoved = [rs, re)`。从每个 `intervals[i]` 中**挖掉**它与 `toBeRemoved` 的交集，返回处理后的区间列表（保持有序、相邻不合并也正确）。

**约束**：

- $1 \le intervals.length \le 10^4$
- $-10^9 \le a < b \le 10^9$，列表按左端点有序且互不相交
- $toBeRemoved$ 是任意区间（与原列表可以任意相交）

## 2. 示例

**示例 1**

```text
输入：intervals = [[0,2],[3,4],[5,7]], toBeRemoved = [1,6]
输出：[[0,1],[6,7]]
解释：[0,2) 挖掉 [1,2) 剩 [0,1)；[3,4) 整段被挖掉；[5,7) 挖掉 [5,6) 剩 [6,7)。
```

**示例 2**

```text
输入：intervals = [[0,5]], toBeRemoved = [2,3]
输出：[[0,2],[3,5]]
解释：被挖区间严格落在原区间内部，剩余被一分为二。
```

**示例 3**

```text
输入：intervals = [[-5,-4],[-3,-2],[1,2],[3,5],[8,9]], toBeRemoved = [-1,4]
输出：[[-5,-4],[-3,-2],[4,5],[8,9]]
解释：[1,2) 整段被挖；[3,5) 挖掉 [3,4) 剩 [4,5)；负数区间不受影响。
```

## 3. 解题思路

### 3.1 暴力思路

对每个区间与 `toBeRemoved` 的相对位置做**分类讨论**：不相交（左/右）、左端相交、右端相交、完全包含、严格内部——共 5 种情形，每种写一个分支处理。这样写正确性没问题（提示也是这么引导的），但 5 个分支里"挖左留右""挖右留左"的边界很容易写错（半开区间的端点归属），而且分支之间可以合并。复杂度已经是 $O(n)$，问题只在于**代码形态的简洁与稳妥**。

### 3.2 核心观察：差集至多剩"左段 + 右段"两截

![五种位置关系统一成左右两段](images/bw14_q2_position_cases.svg)

关键观察：半开区间 $[s, e)$ 与被挖区间 $[rs, re)$ 作差，剩余部分**至多两段**，而且两段有**统一公式**：

- **左段** $=[\,s,\ \min(e, rs)\,)$ —— 从 $s$ 起到"被挖区间的左端"为止；
- **右段** $=[\,\max(s, re),\ e\,)$ —— 从"被挖区间的右端"起到 $e$ 为止。

两段**只在非空时保留**（半开区间 $[a,b)$ 非空 $\iff a < b$）。这四则 `min/max` 把上述 5 种情形**全部**覆盖：完全包含时两段皆空、区间消失；严格内部时两段都保留；其余情形恰保留一段。于是 5 个 `if` 分支坍缩成 2 个。

### 3.3 算法流程

![算法流程：逐区间输出非空的左右剩余段](images/bw14_q2_algorithm_flow.svg)

```text
对 intervals 中的每个 [s, e)：
    若 s < rs：输出左段 [s, min(e, rs))
    若 re < e：输出右段 [max(s, re), e)
```

由于输入本身有序，输出按扫描顺序拼接自然有序，**无需排序或合并**。

### 3.4 示例演算

![示例演算：数轴上挖去 [1,6)](images/bw14_q2_example_walkthrough.svg)

以示例 1 为例：`toBeRemoved = [1,6)`。

- $[0,2)$：左段 $[0, \min(2,1)) = [0,1)$ 非空 ✓；右段 $[\max(0,6), 2)$ 为空 ✗。剩 $[0,1)$。
- $[3,4)$：左段 $[3, \min(4,1))$ 为空（$3 \ge 1$）；右段 $[\max(3,6),4)$ 为空（$6 \ge 4$）。整段消失。
- $[5,7)$：左段 $[5,1)$ 空；右段 $[\max(5,6), 7) = [6,7)$ ✓。剩 $[6,7)$。

输出 `[[0,1],[6,7]]`。示例 2 中 $[0,5)$ 与 $[2,3)$：左段 $[0,2)$、右段 $[3,5)$，一分为二 ✓。

## 4. 算法细节

1. **统一的左右段公式**：`left = [s, min(e, rs))`、`right = [max(s, re), e)`，配两个非空条件 `s < rs` 与 `re < e`。注意左段的非空条件是 $s < rs$（由于 $s < e$，此时 $\min(e,rs) > s$ 自动成立）；右段的非空条件是 $re < e$（此时 $\max(s,re) < e$ 自动成立）。
2. **半开语义自动处理端点重合**：$[0,1)$ 与 $[1,6)$ 相邻但不相交——$e = rs$ 时左段为 $[0, \min(1,1)) = [0,1)$ 整段保留，正确。闭区间语义就得纠结端点归属，半开不需要。
3. **不需要特判"完全包含"**：包含时两段皆空，两个 `if` 自然跳过。
4. **数据范围**：$|坐标| \le 10^9 < 2^{31}-1$，`int` 足够，无溢出风险。
5. **输出顺序**：左段先于右段、输入顺序保持——结果自然有序，题目要求的排序免费获得。

## 5. 正确性证明

**引理 1（差集结构）**：$[s,e) \setminus [rs,re) = [\,s,\min(e,rs)\,) \;\cup\; [\,\max(s,re),\,e\,)$，其中空段（$a \ge b$ 的 $[a,b)$）视为不存在。

**证明**：任取实数 $x$。$x \in [s,e) \setminus [rs,re)$ $\iff$ $s \le x < e$ 且（$x < rs$ 或 $x \ge re$）。按两种情况展开：

- 若 $x < rs$：条件为 $s \le x < \min(e, rs)$（$x < e$ 与 $x < rs$ 合并），即 $x \in [\,s,\min(e,rs)\,)$；
- 若 $x \ge re$：条件为 $\max(s, re) \le x < e$（$x \ge s$ 与 $x \ge re$ 合并），即 $x \in [\,\max(s,re),\,e\,)$。

两个集合之并恰为所求差集，且二者至多隔开、不重叠。∎

**引理 2（非空等价）**：左段 $[s, \min(e,rs))$ 非空 $\iff s < rs$；右段 $[\max(s,re), e)$ 非空 $\iff re < e$。

**证明**：左段非空 $\iff s < \min(e, rs) \iff s < e$ 且 $s < rs$；因输入保证 $s < e$，故等价于 $s < rs$。右段同理：$\max(s,re) < e \iff s < e$ 且 $re < e$，等价于 $re < e$。∎

**定理**：算法输出的区间列表恰为 $\big(\bigcup_i [s_i, e_i)\big) \setminus [rs, re)$ 的区间表示，且有序。

**证明**：由引理 1、引理 2，对每个输入区间，算法恰好输出其差集的全部非空段；不同输入区间互不相交，其差集（各自为原区间的子集）也互不相交，故输出列表的并为 $\bigcup_i [s_i,e_i) \setminus [rs,re)$。有序性：段与段之间，按输入顺序先左后右输出；由于输入区间互不相交且有序，任意输出的两段要么来自同一区间（左段在右段左侧且不交），要么来自先后两个区间（前者的所有点都小于后者的所有点，或同样小于被挖空后的剩余段），故输出整体按左端点有序。∎

## 6. 复杂度分析

- **时间**：$O(n)$。单趟扫描，每个区间 $O(1)$ 处理（输出总量不超过 $2n$ 段）。
- **空间**：$O(1)$ 额外空间（不计返回的答案列表；答案至多 $2n$ 段）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<vector<int>> removeInterval(vector<vector<int>>& intervals, vector<int>& toBeRemoved) {
        int rs = toBeRemoved[0], re = toBeRemoved[1];
        vector<vector<int>> ans;
        for (auto& iv : intervals) {
            int s = iv[0], e = iv[1];
            if (s < rs) ans.push_back({s, min(e, rs)});   // 剩下的左段 [s, min(e,rs))
            if (re < e) ans.push_back({max(s, re), e});   // 剩下的右段 [max(s,re), e)
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def removeInterval(self, intervals: List[List[int]], toBeRemoved: List[int]) -> List[List[int]]:
        rs, re = toBeRemoved
        ans = []
        for s, e in intervals:
            if s < rs:
                ans.append([s, min(e, rs)])    # 剩下的左段 [s, min(e,rs))
            if re < e:
                ans.append([max(s, re), e])    # 剩下的右段 [max(s,re), e)
        return ans
```

> 💡 两份代码均通过官方 3 组示例（`[[0,1],[6,7]]`、`[[0,2],[3,5]]`、`[[-5,-4],[-3,-2],[4,5],[8,9]]`）以及 304 组测试：其中 300 组随机小坐标用例与**独立的整数点集合模拟**（把半开区间展开成整数点集合作差再压缩回区间）对拍，另含 $[-10^9, 10^9]$ 大坐标切分边界，结果全部一致。

## 8. 边界情况与易错点

1. **别写五分支硬分类**：用"左段 + 右段"统一公式，5 种位置关系一网打尽；硬分类最容易在"左端相交 vs 完全包含"的端点条件上写反（半开区间的 $e \le rs$ 才是不相交）。
2. **半开区间的相邻不交**：$[0,1)$ 与 $[1,6)$ **没有**交集。判断"左不相交"用 $e \le rs$，写成 $e < rs$ 会把恰好相接的情况误判成相交。
3. **空段必须丢弃**：左段 $[s, \min(e,rs))$ 在 $s \ge rs$ 时为空，直接不输出；若把空段塞进答案，LeetCode 会判错（区间要求 $a < b$）。
4. **一分为二的顺序**：严格内部情形输出两段时，左段在前、右段在后，别搞反。
5. **toBeRemoved 可能不与任何区间相交**：所有区间原样保留。
6. **负坐标**：题目允许 $-10^9$，`min/max` 与比较运算对负数无特殊性，无需额外处理，但手写分类时容易下意识按非负数假设画数轴。
