# LeetCode 十六进制魔术数字 题解

## 1. 题目概述

- **标题 / 题号**：十六进制魔术数字（#1271，easy）
- **链接**：https://leetcode.cn/problems/hexspeak/
- **来源**：LeetCode 第 14 场双周赛 Q1
- **难度**：简单
- **标签**：数学、字符串

**题意**：把十进制整数 $N$ 转换成**大写十六进制串**，再把其中的数字 `0` 替换成字母 `O`、数字 `1` 替换成字母 `I`，得到的结果称为 **Hexspeak** 表示。如果替换后的串只由集合 $\{A,B,C,D,E,F,I,O\}$ 中的字母构成，它就是**合法**的；只要十六进制表示里出现了 $2 \sim 9$ 中的某个数字，替换后必然残留数字，返回 `"ERROR"`。给定表示 $N$ 的十进制字符串 `num`，返回 $N$ 的 Hexspeak 表示（非法则返回 `"ERROR"`）。

**约束**：

- $1 \le N \le 10^{12}$
- `num` 无前导零
- 答案全部大写

## 2. 示例

**示例 1**

```text
输入：num = "257"
输出："IOI"
解释：257 的十六进制是 101，把 1→I、0→O 得 "IOI"。
```

**示例 2**

```text
输入：num = "3"
输出："ERROR"
解释：3 的十六进制就是 "3"，出现数字 3，非法。
```

**补充示例**

```text
输入：num = "16"
输出："IO"
解释：16 = 0x10 → "10" → "IO"，合法。

输入：num = "100"
输出："ERROR"
解释：100 = 0x64，含数字 6 与 4，非法。

输入：num = "65536"
输出："IOOOO"
解释：65536 = 0x10000 → "IOOOO"，合法。
```

## 3. 解题思路

### 3.1 暴力思路

本题不存在什么"暴力"——按题意模拟本身就是正解。唯一要做的决策是**进制转换怎么写**：把 `num` 逐字符解析成整数（或直接 `stoll` / `int(num)`），再用**短除法**不断对 16 取余得到每一位。整个过程 $O(\log_{16} N)$，$N \le 10^{12}$ 时最多约 10 位十六进制，量级完全可以忽略。若非要挑刺，"先转 2 进制再转 16 进制"或调用 `printf("%X")` 也行，但手写 4 位一组的短除法最直接，也不依赖平台格式化行为。

### 3.2 核心观察：合法性 ⟺ 十六进制中不出现 2~9

![转换流程：短除法取余再逐位映射](images/bw14_q1_conversion_flow.svg)

映射 $0 \to O$、$1 \to I$ 是**逐字符替换**且两类字符（数字 vs 字母）互不混淆，所以替换后串里是否残留数字，完全由**原始十六进制表示**决定：十六进制位取值 $0 \sim 15$，其中

- $d = 0$：映成 `O`；
- $d = 1$：映成 `I`；
- $d \in [2, 9]$：会残留**数字**，直接 `"ERROR"`；
- $d \in [10, 15]$：映成 `A`~`F`。

因此判定与转换可以**在同一趟短除法里完成**：遇到 $2 \le d \le 9$ 立即返回 `"ERROR"`，不必先构出完整十六进制串再做第二趟替换。

### 3.3 算法流程

1. 把 `num` 解析成 64 位整数 $n$（$10^{12} > 2^{31}$，必须用 `long long` / Python 大整数）。
2. 循环：$d = n \bmod 16$，$n \gets \lfloor n/16 \rfloor$，按上面四类处理 $d$，把对应字符**尾插**进结果串。
3. 短除法得到的余数是**低位在前**，最后把结果串整体反转。
4. $N \ge 1$ 保证循环至少执行一次，结果非空。

### 3.4 示例演算

![示例演算：257 到 IOI 与 3 到 ERROR](images/bw14_q1_example_walkthrough.svg)

以 `num = "257"` 为例：$257 = 16 \times 16 + 1$，短除过程依次得余数 $1, 0, 1$（低位在前），逆序后十六进制为 $101$；逐位映射 $1 \to I,\ 0 \to O,\ 1 \to I$，得 `"IOI"`。而 `num = "3"`：余数为 $3$，落在 $[2,9]$ 内，立即返回 `"ERROR"`。再看上界 $N = 10^{12}$：十六进制为 `E8D4A51000`，含数字 $8,4,5,1,0$（$1,0$ 可映射但 $8,4,5$ 不行），返回 `"ERROR"`。

## 4. 算法细节

1. **整数范围**：$10^{12} \approx 2^{39.86}$，超出 32 位 `int`（上限约 $2.1 \times 10^9$），C++ 用 `long long` + `stoll`；Python 的 `int` 无限精度天然安全。
2. **短除法方向**：余数先产生的是**最低位**，所以边除边尾插、最后 `reverse`，与"除基取余、逆序排列"的手算流程一致。
3. **四类分支的顺序**：先判 $d=0$、$d=1$，再判 $d<10$（即 $2 \sim 9$，非法），剩下的必然是 $10 \sim 15$，用 `'A' + d - 10` 映射。分支互斥且完整，无遗漏。
4. **为什么可以边转换边判**：映射是逐位独立的，某一位非法即可整体判非法，提前返回不影响正确性。
5. **复杂度**：$O(\log_{16} N)$ 时间与空间（结果串长度）。

## 5. 正确性证明

**引理 1（十六进制表示唯一）**：任意正整数 $N$ 的不带前导零的十六进制表示唯一，且恰为短除法余数序列的逆序。

**证明**：对 $N$ 归纳。$N \in [1,15]$ 时余数序列长度为 1，即 $N$ 本身，显然唯一。设 $N \ge 16$，其最低位 $d_0 = N \bmod 16$ 由 $N$ 唯一决定；高位部分 $N' = \lfloor N/16 \rfloor \ge 1$ 且 $N' < N$，由归纳假设 $N'$ 的表示唯一，故 $N$ 的表示唯一且为 $d_0$ 附加在 $N'$ 表示之后（逆序拼接即得）。∎

**引理 2（合法性等价）**：$N$ 的 Hexspeak 表示合法 $\iff$ $N$ 的十六进制表示的每一位都取值于 $\{0, 1\} \cup [10, 15]$。

**证明**：替换 $0 \to O$、$1 \to I$ 只作用于字符 `0`、`1`，其余字符不变。位 $d \in [10,15]$ 本就是字母 `A`~`F`；位 $d \in [2,9]$ 是数字且不被任何替换规则覆盖，替换后仍是数字，落入非法集合。故替换结果只含 $\{A,\dots,F,I,O\}$ 当且仅当没有 $d \in [2,9]$。∎

**定理**：算法返回值恰为 $N$ 的 Hexspeak 表示（非法时为 `"ERROR"`）。

**证明**：由引理 1，短除法逆序得到的就是 $N$ 唯一的十六进制表示；算法在扫描每一位时按引理 2 的四类逐一映射，一旦遇到 $d \in [2,9]$ 即提前返回 `"ERROR"`，由引理 2 此判定正确；若无任何非法位，全部位被映射为 $\{O,I,A,\dots,F\}$ 中的字符，且映射方向（低位在前）经 `reverse` 后与原表示同序，返回值即合法 Hexspeak。∎

## 6. 复杂度分析

- **时间**：$O(\log_{16} N)$。$N \le 10^{12}$ 时不超过 10 次循环；解析 `num` 为整数另需 $O(|num|) \le O(13)$。
- **空间**：$O(\log_{16} N)$。结果串长度，同样不超过 10 个字符。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    string toHexspeak(string num) {
        long long n = stoll(num);                 // N <= 10^12，long long 足够
        string s;
        while (n > 0) {
            int d = n % 16;
            n /= 16;
            if (d == 0) s.push_back('O');             // 0 -> O
            else if (d == 1) s.push_back('I');        // 1 -> I
            else if (d < 10) return "ERROR";          // 2..9 -> 出现数字，非法
            else s.push_back(char('A' + d - 10));     // 10..15 -> A..F
        }
        reverse(s.begin(), s.end());                  // 余数序列是逆序的
        return s;
    }
};
```

### Python

```python
class Solution:
    def toHexspeak(self, num: str) -> str:
        n = int(num)                            # N <= 10^12
        s = []
        while n > 0:
            d = n % 16
            n //= 16
            if d == 0:
                s.append('O')                   # 0 -> O
            elif d == 1:
                s.append('I')                   # 1 -> I
            elif d <= 9:
                return "ERROR"                  # 2..9 -> 出现数字，非法
            else:
                s.append(chr(ord('A') + d - 10))
        return ''.join(reversed(s))             # 余数序列是逆序的
```

> 💡 两份代码均通过官方示例（`"IOI"`、`"ERROR"`）与 413 组测试（含由合法字母表构造的 Hexspeak 数、随机数、$10^{12}$ 边界），并与独立参考实现（Python 内置 `format(n,'X')` + 替换检查）对拍，结果一致。

## 8. 边界情况与易错点

1. **溢出是本题唯一的坑**：$10^{12} > 2^{31}-1$，C++ 中 `int` 必然溢出，必须 `stoll`/`long long`；如果 $N$ 上界再大（比如 $10^{18}$ 以上），就要对**十进制字符串**直接做短除法，不能先转整数。
2. **0 和 1 都要映射**：别只想着 $2 \sim 9$ 判非法，`0→O`、`1→I` 是题目要求的输出字符；同时 $2 \sim 9$ **不能**被映射成字母，只能报错。
3. **逆序别忘了**：短除法余数从低位到高位产生，输出前必须反转，否则 `"IOI"` 会写成 `"IOI"` 的镜像（对回文样例看不出来，随机数据立刻暴露）。
4. **$N \ge 1$**：约束保证至少一位十六进制；若数据被放宽到 $N=0$，`while` 循环一次都不执行会返回空串——此时应特判返回 `"O"`（$0 \to$ `O`），本题无需处理但值得知道。
5. **大小写**：`A~F` 必须大写，`I`、`O` 也是大写字母；用 `%x`（小写）格式化再忘记转大写是常见笔误。
