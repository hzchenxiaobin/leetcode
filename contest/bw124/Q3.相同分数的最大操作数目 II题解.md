# LeetCode 相同分数的最大操作数目 II 题解

## 1. 题目概述

- **标题 / 题号**：相同分数的最大操作数目 II（#3040，medium）
- **链接**：https://leetcode.cn/problems/maximum-number-of-operations-with-the-same-score-ii/
- **来源**：LeetCode 第 124 场双周赛 Q3
- **难度**：中等
- **标签**：记忆化、数组、动态规划

**题意**：给定整数数组 nums，只要还剩至少 $2$ 个元素，就可以从下面三种删法中**任选一种**：删最前面两个、删最后面两个、删第一个和最后一个。一次操作的分数是被删两元素之和。要求所有操作的分数相同，求最多能操作多少次。

**约束**：

- $2 \le nums.length \le 2000$
- $1 \le nums[i] \le 1000$

## 2. 示例

**示例 1**

```text
输入：nums = [3,2,1,2,3,4]
输出：3
解释：删前两个（3+2=5）→ [1,2,3,4]；
      删首尾（1+4=5）→ [2,3]；
      删首尾（2+3=5）→ []。共 3 次。
```

**示例 2**

```text
输入：nums = [3,2,6,1,4]
输出：2
解释：删前两个（3+2=5）→ [6,1,4]；
      删后两个（1+4=5）→ [6]；只剩一个元素，停止。共 2 次。
```

**示例 3（边界补充）**

```text
输入：nums = [5,5]
输出：1
解释：无论选哪种删法都会把两个元素一次删光，共 1 次。
```

## 3. 解题思路

### 3.1 暴力思路

每次最多有 $3$ 种删法，最多删 $\lfloor n/2 \rfloor = 1000$ 次，搜索树的规模是 $3^{1000}$ 级别，指数爆炸。

即便加上「首步定死分数」这一剪枝，状态仍然是「当前剩余哪些元素」——而剩下的元素其实总是**一段连续区间**，这正是把指数搜索变成多项式 DP 的关键。

### 3.2 核心观察：剩余元素永远是连续子数组，首步只有三种

![状态是「一段还在的区间」，一步只砍两头](images/bw124_q3_interval_state.svg)

**观察一：任何时刻剩下的都是原数组的连续子数组。** 初始是整个数组；三种删法分别从左边砍两个、从右边砍两个、两边各砍一个，都不会在中间挖洞。所以状态可以用一对下标 $(l, r)$ 完全描述。

**观察二：第一次操作只有三种可能**，它把分数定死：

- 删 `nums[0]`、`nums[1]`，分数 $score = nums[0] + nums[1]$，剩余区间 $[2, n-1]$；
- 删 `nums[n-2]`、`nums[n-1]`，分数 $score = nums[n-2] + nums[n-1]$，剩余区间 $[0, n-2]$；
- 删 `nums[0]`、`nums[n-1]`，分数 $score = nums[0] + nums[n-1]$，剩余区间 $[1, n-2]$。

分数一旦确定，后面每一步只需判断「这种删法的两数之和是否等于 $score$」。于是对每个固定的 $score$，都可以用区间 DP 求该分数下的最大操作数，最后三种首步取最大。

![首步只有三种选择，分数就此定死](images/bw124_q3_three_starts.svg)

### 3.3 状态转移

定义 $dp[l][r]$：在固定分数 $score$ 下，区间 $nums[l..r]$ 上最多还能做的操作数。长度小于 $2$ 时 $dp[l][r] = 0$。转移时枚举三种删法，只接受「两数之和等于 $score$」的那些：

$$dp[l][r] = 1 + \max\begin{cases}
dp[l+2][r], & nums[l] + nums[l+1] = score,\\
dp[l][r-2], & nums[r-1] + nums[r] = score,\\
dp[l+1][r-1], & nums[l] + nums[r] = score.
\end{cases}$$

三者都不满足时 $dp[l][r] = 0$。所有转移都指向长度为 $len - 2$ 的子区间，因此按**区间长度递增**计算即可，不需要递归。

**空间优化**：由于只依赖 $len - 2$ 层，而 $len$ 与 $len - 2$ 奇偶性相同，可以只保留两个层（按长度奇偶分桶），把空间从 $O(n^2)$ 降到 $O(n)$。

```text
整体流程：
ans = 1
对三种首步 (两数之和 s, 剩余区间 [L, R]):
    ans = max(ans, 1 + solve(s, L, R))
返回 ans
其中 solve(score, L, R) 用上面的区间 DP 返回 dp[L][R]
```

### 3.4 示例演算

![示例 1 三次操作都是 5](images/bw124_q3_example_walkthrough.svg)

以示例 1 `[3,2,1,2,3,4]` 为例，首步删前两个得 $score = 5$：

| 步骤 | 区间 | 删法 | 分数 | 剩余 |
|------|------|------|------|------|
| 1 | [3,2,1,2,3,4] | 前两个 3+2 | 5 | [1,2,3,4] |
| 2 | [1,2,3,4] | 首尾 1+4 | 5 | [2,3] |
| 3 | [2,3] | 首尾 2+3 | 5 | [] |

共 3 次。另两种首步的分数都是 $7$（$3+4$），剩余区间里再也凑不出 $7$，各只能做 $1$ 次。故答案 $3$。

## 4. 算法细节

1. **首步必做**：$n \ge 2$ 时至少能做一次，所以 `ans` 初值为 $1$；若剩余区间长度不足 $2$，子问题的 $dp$ 返回 $0$。
2. **三种首步各跑一遍 DP**：即便②③的分数相同，剩余区间也不同（$[0,n-2]$ 与 $[1,n-2]$），不能按分数去重。
3. **按长度递增递推**：$dp[l][r]$ 依赖更短的区间，从 $len = 2$ 递推到 $len = m$ 即可，无环。
4. **滚动数组按奇偶分桶**：`layer[len & 1]` 里存的正是长度 $len - 2$ 的那一层，写完再覆盖。注意要保留长度为 $0$ 与 $1$ 的两个全零层作为初值。
5. **层内下标偏移**：层数组以「区间左端点相对 $L$ 的偏移」为下标，长度 $m + 2$ 足够，因为最多访问到 $l + 2$。
6. **三种删法的下标**：删前两个用 `nums[l] + nums[l+1]`，删后两个用 `nums[r-1] + nums[r]`，删首尾用 `nums[l] + nums[r]`；三者都可能与其它情形重合（如长度 $2$ 时三种删法等价），重复计算不影响正确性。
7. **不用递归**：$n = 2000$ 时递归深度可达 $1000$，C++ 尚可，Python 默认递归上限会直接报错，递推更稳。
8. **整数范围**：$nums[i] \le 1000$，两数之和 $\le 2000$，`int` 足够。

## 5. 正确性证明

**引理 1（区间不变式）**：任意时刻，数组中剩余的元素恰为原数组的一个连续子数组 $nums[l..r]$。

**证明**：初始时剩余全体即 $nums[0..n-1]$，是连续子数组。设某时刻剩余 $nums[l..r]$，三种删法分别得到 $nums[l+2..r]$、$nums[l..r-2]$、$nums[l+1..r-1]$，仍是连续子数组。由归纳法，任意时刻都成立。∎

**引理 2（首步穷尽）**：第一次操作必然是上述三种之一，且此后分数固定为这次操作的两数之和。

**证明**：第一次操作时可选的删法只有「最前两个」「最后两个」「第一个和最后一个」三种（题面给定），分别对应引理 1 中的三个新区间；题意要求所有操作分数相同，故第一次的分数即为后续所有操作的分数。∎

**引理 3（转移穷尽且最优）**：固定 $score$ 后，对任意区间 $[l, r]$（长度 $\ge 2$），$dp[l][r]$ 的递推式给出该区间上最多可做的操作数。

**证明**：对区间长度 $len$ 归纳。$len < 2$ 时无法操作，$dp = 0$ 正确。设对长度 $len - 2$ 成立。区间 $[l,r]$ 长度 $len \ge 2$ 时，第一步只能从三种删法中选（引理 2 同理），删法合法当且仅当对应两数之和等于 $score$。若三种都不合法，则一步也做不了，$dp = 0$ 正确；否则对每种合法删法，做完这一步后剩余区间长度为 $len - 2$，之后最多还能做 $dp[\cdot][\cdot]$ 次（归纳假设），故该删法给出 $1 + dp[\cdot][\cdot]$ 次。取最大值即为「先选最优删法」的最优解。∎

**定理**：算法返回的值等于最多可执行的操作次数。

**证明**：由引理 2，任意合法操作序列的第一步必为三种首步之一，设其分数为 $s$、剩余区间为 $[L, R]$，则该序列的总长度恰为 $1 + (\text{在 } [L,R] \text{ 上以 } s \text{ 为分数的最多操作数}) = 1 + dp[L][R]$（引理 3）。算法枚举三种首步并取最大值，故结果不小于任何合法序列的长度；另一方面每个候选值都对应一条真实可执行的操作序列（按 DP 的取最大分支回溯即得），故结果也不大于最优值。两者相等。∎

## 6. 复杂度分析

- **时间**：$O(n^2)$。固定分数后，区间状态共约 $n^2/2$ 个，每个状态常数次比较与取最大；三种首步各跑一遍，常数因子为 $3$，总量仍是 $O(n^2)$。$n = 2000$ 时约 $6 \times 10^6$ 次状态计算。
- **空间**：$O(n)$。滚动数组只保留两个长度为 $O(n)$ 的层；若不滚动则为 $O(n^2)$（$n = 2000$ 时约 $4 \times 10^6$ 个 `int`，也可接受）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maxOperations(vector<int>& nums) {
        int n = nums.size();
        // 固定分数 score 后，区间 DP：nums[L..R] 最多还能做几次
        auto solve = [&](int score, int L, int R) -> int {
            int m = R - L + 1;
            if (m < 2) return 0;
            vector<int> layer[2];                      // 按长度奇偶滚动，只保留 len-2 层
            layer[0].assign(m + 2, 0);
            layer[1].assign(m + 2, 0);
            for (int len = 2; len <= m; ++len) {
                vector<int>& prev = layer[len & 1];    // 同奇偶 → 长度 len-2 的层
                vector<int> cur(m + 2, 0);
                for (int l = 0; l + len - 1 < m; ++l) {
                    int r = l + len - 1, best = 0;
                    if (nums[L + l] + nums[L + l + 1] == score) best = max(best, prev[l + 2] + 1);
                    if (nums[L + r - 1] + nums[L + r] == score) best = max(best, prev[l] + 1);
                    if (nums[L + l] + nums[L + r] == score)     best = max(best, prev[l + 1] + 1);
                    cur[l] = best;
                }
                layer[len & 1] = move(cur);
            }
            return layer[m & 1][0];
        };
        int ans = 1;
        ans = max(ans, 1 + solve(nums[0] + nums[1], 2, n - 1));            // 删最前两个
        ans = max(ans, 1 + solve(nums[n - 2] + nums[n - 1], 0, n - 2));    // 删最后两个
        ans = max(ans, 1 + solve(nums[0] + nums[n - 1], 1, n - 2));        // 删首尾
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maxOperations(self, nums: list[int]) -> int:
        n = len(nums)

        def solve(score: int, L: int, R: int) -> int:
            # 固定分数 score 后：区间 nums[L..R] 最多还能做几次操作
            m = R - L + 1
            if m < 2:
                return 0
            layers = [[0] * (m + 2), [0] * (m + 2)]   # 长度 0 / 1 的层，全为 0
            for length in range(2, m + 1):
                prev = layers[length & 1]              # 同奇偶 → 长度 length-2 的层
                cur = [0] * (m + 2)
                last = length - 1
                for l in range(m - length + 1):
                    best = 0
                    if nums[L + l] + nums[L + l + 1] == score:
                        best = prev[l + 2] + 1          # 删最前两个
                    if nums[L + l + last - 1] + nums[L + l + last] == score:
                        v = prev[l] + 1                 # 删最后两个
                        if v > best:
                            best = v
                    if nums[L + l] + nums[L + l + last] == score:
                        v = prev[l + 1] + 1             # 删第一个和最后一个
                        if v > best:
                            best = v
                    cur[l] = best
                layers[length & 1] = cur
            return layers[m & 1][0]

        ans = 1
        for (i, j, l, r) in ((0, 1, 2, n - 1), (n - 2, n - 1, 0, n - 2), (0, n - 1, 1, n - 2)):
            ans = max(ans, 1 + solve(nums[i] + nums[j], l, r))
        return ans
```

> 💡 两份代码通过官方示例（`3`、`2`）与 `[5,5]`、`[1,1,1,1,1,1]`（答案 3）等边界，并与无记忆化的纯递归暴力在 3000 组 $n \le 11$ 的随机数组上对拍，`mismatch = 0`；$n = 2000$ 的全相同数据（答案 1000）在 C++ 下瞬时完成。

## 8. 边界情况与易错点

1. **$n = 2$**：三种首步删除的都是同一对元素，答案必为 $1$；子区间为空，`solve` 应返回 $0$。
2. **②③ 分数相同但区间不同**：`[0,n-2]` 与 `[1,n-2]` 是两个不同的子问题，不能因为分数相同就只算一次。
3. **区间长度可能是奇数**：删两个不改变奇偶之外的约束，但 DP 表要覆盖所有长度，别只按偶数长度递推。
4. **滚动数组的奇偶分桶**：$len$ 的依赖是 $len - 2$（同奇偶），用 `len & 1` 分桶；若用单层 `prev = cur` 会错位一层（改成减 1 的依赖才成立）。
5. **层数组要留 $+2$ 的余量**：转移里会访问 `prev[l + 2]`，长度开 $m + 2$ 才不会越界。
6. **递归会爆栈**：Python 默认递归深度约 1000，$n = 2000$ 时递归实现会 `RecursionError`，务必用递推。
7. **首步不能跳过**：不能为了「以后能多删几次」而放弃第一次操作——第一次是强制的，`ans` 从 $1$ 起算。
8. **分数比较用整数**：$nums[i] \le 1000$，直接比较即可，无需考虑溢出。
