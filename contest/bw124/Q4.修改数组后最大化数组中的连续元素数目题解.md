# LeetCode 修改数组后最大化数组中的连续元素数目 题解

## 1. 题目概述

- **标题 / 题号**：修改数组后最大化数组中的连续元素数目（#3041，hard）
- **链接**：https://leetcode.cn/problems/maximize-consecutive-elements-in-an-array-after-modification/
- **来源**：LeetCode 第 124 场双周赛 Q4
- **难度**：困难
- **标签**：数组、动态规划、排序

**题意**：给定只含正整数的数组 nums。先做一次批量修改：**任意选一些元素，每个被选中的元素最多加 1**（也可以不加）。修改后，从数组中挑出一个或多个元素，要求它们升序排列后是**连续**的（步长恰好为 1，如 $[3,4,5]$ 合法，$[3,4,6]$ 与 $[1,1,2,3]$ 不合法）。求最多能挑出多少个元素。

**约束**：

- $1 \le nums.length \le 10^5$
- $1 \le nums[i] \le 10^6$

## 2. 示例

**示例 1**

```text
输入：nums = [2,1,5,1,1]
输出：3
解释：把两个 1 中的一个加 1 变成 2，再把 2 加 1 变成 3，
      可选出 [1,2,3]（长度 3）。5 接不上任何链，只能弃用。
```

**示例 2**

```text
输入：nums = [1,4,7,10]
输出：1
解释：相邻元素差 3，加 1 也填不平，最多只能选 1 个。
```

**示例 3（边界补充）**

```text
输入：nums = [1,1]
输出：2
解释：一个保持 1，另一个加 1 变成 2，得到 [1,2]，长度 2。
```

## 3. 解题思路

### 3.1 暴力思路

先枚举「选哪些元素」（$2^n$ 种），再枚举「每个选中的元素是否 +1」（又是 $2^m$ 种），逐组检查是否连续。$n = 10^5$ 时完全不可行；即便 $n = 20$ 也会爆。

暴力里唯一有价值的信息是：**每个元素只有两种归宿（$x$ 或 $x+1$）**，这提示我们把「选择」变成「状态转移」，而不是枚举。

### 3.2 核心观察：只关心「以某个值结尾的链有多长」

![每个元素只有两个去处：原地不动，或 +1](images/bw124_q4_x_or_x1.svg)

先把数组排序。连续链的本质是：链上的值恰好是 $c, c+1, c+2, \dots$。于是把一条链刻画成「**结尾值**」和「**长度**」，延长链时只需要知道结尾值是多少——这就是一维的状态。

处理到元素 $x$ 时，它只有两种用法：

- **保持 $x$**：接在「以 $x-1$ 结尾的链」后面；
- **加 1 变成 $x+1$**：接在「以 $x$ 结尾的链」后面。

于是维护一张表 $dp[v]$ = 以值 $v$ 结尾的最长链长度，处理 $x$ 时做两次更新：

$$dp[x] \leftarrow dp[x-1] + 1, \qquad dp[x+1] \leftarrow dp[x] + 1.$$

注意第二条用的是**旧的** $dp[x]$（处理 $x$ 之前的值），所以**必须先算 $dp[x+1]$ 再算 $dp[x]$**，否则同一个元素会被当成「既是 $x$ 又是 $x+1$」用两次。

![处理元素 x 时的两次写入](images/bw124_q4_dp_transition.svg)

答案就是所有 $dp[v]$ 的最大值。

### 3.3 算法流程

```text
1. 把 nums 升序排序
2. dp ← 空哈希表（值 → 以该值结尾的最长链长）
3. ans ← 1
4. 对每个 x ∈ nums（按升序）：
       up   = dp[x] + 1        # 本元素 +1 变成 x+1，接在以 x 结尾的链后
       keep = dp[x-1] + 1      # 本元素保持 x，接在以 x-1 结尾的链后
       dp[x+1] = up
       dp[x]   = keep
       ans = max(ans, up, keep)
5. 返回 ans
```

两行赋值的顺序是「先 `dp[x+1]`，后 `dp[x]`」，与上面推导一致。

### 3.4 示例演算

![示例 1 走查：排序后 [1,1,1,2,5]](images/bw124_q4_example_walkthrough.svg)

排序后为 $[1,1,1,2,5]$：

| $x$ | $dp[x]$（旧） | $dp[x-1]$ | 写 $dp[x+1] = dp[x]+1$ | 写 $dp[x] = dp[x-1]+1$ | ans |
|-----|---------------|-----------|------------------------|------------------------|-----|
| 1 | 0 | 0 | $dp[2] = 1$ | $dp[1] = 1$ | 1 |
| 1 | 1 | 0 | $dp[2] = 2$ | $dp[1] = 1$ | 2 |
| 1 | 1 | 0 | $dp[2] = 2$ | $dp[1] = 1$ | 2 |
| 2 | 2 | 1 | $dp[3] = 3$ | $dp[2] = 2$ | 3 |
| 5 | 0 | 0 | $dp[6] = 1$ | $dp[5] = 1$ | 3 |

前两个 $1$ 把 $dp[2]$ 顶到 $2$；轮到 $2$ 时借 $dp[2] = 2$ 造出 $dp[3] = 3$，对应链 $1 \to 2 \to 3$。第三个 $1$ 无法再延长（$dp[1]$ 仍是 $1$），$5$ 与前面断档只能自成一条长度 $1$ 的链。最终 $dp$ 中最大值是 $3$。

## 4. 算法细节

1. **必须先排序**：按值升序处理，保证「延长链所需的前驱值」都已经算过；乱序处理会让 $dp[x-1]$ 拿到过时的值。
2. **两行赋值的顺序不能反**：先 `dp[x+1] = dp[x] + 1` 用的是旧 $dp[x]$；若先写 `dp[x] = dp[x-1] + 1`，`dp[x]` 变成新值，再算 $dp[x+1]$ 就相当于让同一个元素既当 $x$ 又当 $x+1$。
3. **不需要取 max**：$dp$ 的每个值只会被赋成「某个时刻的 $dp[v-1] + 1」，而 $dp[v-1]$ 单调不减（见 §5 引理 2），所以后来写入的值一定不小于旧值，直接赋值即可。
4. **哈希表 vs 数组**：值域 $10^6$，开长度 $10^6 + 2$ 的数组也可行；哈希表在 $n$ 较小、值较分散时更省内存，C++ 用 `unordered_map` 并预留 $2n$ 桶避免 rehash。
5. **答案至少为 1**：$n \ge 1$，单个元素自己就是长度 $1$ 的连续序列，所以 `ans` 初值取 $1$。
6. **重复元素**：同一个值的多个副本会依次改写 $dp[x+1]$，这正是「多个副本可以占据相邻位置」的体现；但 $dp[x]$ 只能接在 $dp[x-1]$ 后，第三个重复值无法继续延长，所以重复元素不会让链长凭空膨胀。
7. **值域边界**：$dp[x+1]$ 最大访问到 $10^6 + 1$，用哈希表无需担心；若用数组要开到 $10^6 + 2$。
8. **记录答案的时机**：每处理完一个元素就用 `up`、`keep` 更新 `ans`，这样即使后面出现断档也不会漏掉已有最优。

## 5. 正确性证明

记 $P_t$ 为排序后的前 $t$ 个元素构成的集合（$P_0 = \emptyset$）。定义 $L_t(v)$ 为：只用 $P_t$ 中的元素、每个元素至多用一次、每个元素取 $x$ 或 $x+1$，能得到的最长连续链中「以值 $v$ 结尾」的最大长度（不存在则为 $0$）。

**引理 1（元素只有两种归宿）**：设元素值为 $x$，它在任何方案中只能变成 $x$ 或 $x+1$。因此若它出现在一条连续链中，则该链在它之后的下一个值只能是 $x+1$ 或 $x+2$，在它之前的前一个值只能是 $x-1$ 或 $x$；特别地，$x$ 只能接在「以 $x-1$ 结尾的链」后（保持 $x$）或接在「以 $x$ 结尾的链」后（变成 $x+1$）。

**证明**：修改规则限定每个元素至多加 $1$，故取值只有两种。连续链要求相邻值差恰好为 $1$，把 $x$ 或 $x+1$ 代入即得结论。∎

**引理 2（$dp$ 单调）**：对任意值 $v$，$dp[v]$ 在处理过程中单调不减；且 $L_t(v) \le L_t(v-1) + 1$ 对一切 $t, v$ 成立。

**证明**：先证第二个不等式。设链 $C$ 以 $v$ 结尾、长度 $L_t(v) \ge 1$，其最后一个元素来自 $P_t$。删去该元素后剩下的部分是一条以 $v-1$ 结尾的链（长度 $L_t(v) - 1$，若长度为 $1$ 则为空链），且它使用的元素仍属于 $P_t$，故 $L_t(v-1) \ge L_t(v) - 1$，即 $L_t(v) \le L_t(v-1) + 1$。再证单调性：对 $v$ 归纳。$dp[0] \equiv 0$（元素值 $\ge 1$，代码中不会写入 $dp[0]$ 之外的值；$x-1 \ge 0$ 且只在 $x \ge 1$ 时使用，$x+1 \ge 2$，故 $dp[0]$ 恒为 $0$）。设 $dp[v-1]$ 单调不减，则 $dp[v]$ 的每次赋值都形如「当时的 $dp[v-1] + 1」（在处理元素 $v$ 时由 $dp[x-1]$ 赋值，或在处理元素 $v-1$ 时由 $dp[x]$ 赋值），由归纳假设它单调不减。∎

**引理 3（不变式）**：处理完前 $t$ 个元素后，对任意值 $v$ 有 $dp[v] = L_t(v)$。

**证明**：对 $t$ 归纳。$t = 0$ 时 $dp$ 全为 $0$，与 $L_0 \equiv 0$ 一致。设处理完前 $t$ 个后成立，考察第 $t+1$ 个元素 $x$（由排序知它是当前最大值）。

对 $v \notin \{x, x+1\}$：由引理 1，$x$ 无法出现在以 $v$ 结尾的链中（它的取值只会是 $x$ 或 $x+1$），故 $L_{t+1}(v) = L_t(v) = dp[v]$，未被修改，成立。

对 $v = x$：以 $x$ 结尾的链要么不用 $x$（长度至多 $L_t(x)$），要么以 $x$（保持）收尾，此时前一段是以 $x-1$ 结尾的链，长度至多 $L_t(x-1) + 1$。故 $L_{t+1}(x) = \max(L_t(x),\ L_t(x-1)+1)$。由引理 2 的不等式 $L_t(x) \le L_t(x-1)+1$，得 $L_{t+1}(x) = L_t(x-1)+1$，而代码正是 `dp[x] = dp[x-1] + 1`，由归纳假设 $dp[x-1] = L_t(x-1)$，故赋值正确。

对 $v = x+1$：同理 $L_{t+1}(x+1) = \max(L_t(x+1),\ L_t(x)+1)$，由引理 2 得 $= L_t(x)+1$，代码写 `dp[x+1] = dp[x] + 1`；此处 `dp[x]` 尚未被本元素覆盖，仍是 $L_t(x)$（代码先算 $dp[x+1]$ 再算 $dp[x]$），故正确。

其余值不受影响。综上不变式对 $t+1$ 成立。∎

**定理**：算法返回的值等于最多可挑出的元素数目。

**证明**：设排序后共 $n$ 个元素。由引理 3，处理完全部元素后 $dp[v] = L_n(v)$，即「以 $v$ 结尾的最长合法链长度」。任一合法选择方案对应的链必以某个值 $v$ 结尾，其长度不超过 $L_n(v)$，故不超过 $\max_v dp[v]$；反之 $\max_v dp[v]$ 对应的链是一条真实的合法选择（由 $L_n$ 的定义），其长度可达该上界。故 $\max_v dp[v]$ 恰为答案，而算法在过程中用 `up`、`keep` 记录了所有被写入的 $dp$ 值，`ans` 的初值 $1$ 覆盖 $n \ge 1$ 的单元素情形，因此返回值等于 $\max_v dp[v]$。∎

## 6. 复杂度分析

- **时间**：$O(n \log n)$。排序 $O(n \log n)$ 主导；随后每个元素做常数次哈希读写，期望 $O(1)$，共 $O(n)$。
- **空间**：$O(n)$。哈希表最多存 $2n$ 个不同的键；若改用数组则为 $O(\max nums)$（此处 $10^6$）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maxSelectedElements(vector<int>& nums) {
        sort(nums.begin(), nums.end());
        unordered_map<int, int> dp;   // dp[v]：以值 v 结尾的最长连续链长度
        dp.reserve(nums.size() * 2 + 1);
        int ans = 1;
        for (int x : nums) {
            int up = dp[x] + 1;            // 本元素 +1 变成 x+1，接在「结尾为 x」的链后
            int keep = dp[x - 1] + 1;      // 本元素保持 x，接在「结尾为 x-1」的链后
            dp[x + 1] = up;
            dp[x] = keep;
            ans = max(ans, max(up, keep));
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maxSelectedElements(self, nums: list[int]) -> int:
        nums = sorted(nums)
        dp = {}                        # 值 → 以该值结尾的最长连续链长度
        ans = 1
        for x in nums:
            up = dp.get(x, 0) + 1      # 本元素 +1 变成 x+1，接在「结尾为 x」的链后
            keep = dp.get(x - 1, 0) + 1  # 本元素保持 x，接在「结尾为 x-1」的链后
            dp[x + 1] = up
            dp[x] = keep
            ans = max(ans, up, keep)
        return ans
```

> 💡 两份代码通过官方示例（`3`、`1`）与 `[1]`、`[1,1]`、`[1,1,1]`（答案 2）、`[3,3,4,4,5]`（答案 4）等边界，并与「枚举子集 + 枚举每个元素是否 +1」的暴力在 2000 组 $n \le 8$ 的随机数组上对拍，`mismatch = 0`；$n = 10^5$ 的随机数据在 C++ 下耗时约 $10$ 毫秒。

## 8. 边界情况与易错点

1. **两行赋值的顺序**：先 `dp[x+1]`、后 `dp[x]`。写反会让同一个元素被用两次，答案虚高（例如 `[1,1,1]` 会算出 3 而不是 2）。
2. **必须先排序**：按值升序处理，才能保证用到的 $dp[x-1]$、$dp[x]$ 都是「已处理元素」的最优值。
3. **`ans` 初值为 1**：$n \ge 1$，单元素即可成链；若初值取 0，$n = 1$ 时会返回 0。
4. **重复元素不会无限制延长**：三个 $1$ 最多撑出 $1,2$ 两个位置（$dp[2] = 2$），第三个 $1$ 无法再延；不要误以为重复值能凑出更长的链。
5. **断档要重置**：$5$ 从 $dp[4] = 0$ 起算，长度回到 1，这与「链必须连续」一致，无需显式清零。
6. **不要用 `dp[x] = max(dp[x], dp[x-1]+1)` 加保险**：虽然加上也不会错（引理 2 说明两者相等），但若顺序写错，`max` 会掩盖错误、让对拍也难发现；保持形式简洁更利于证明。
7. **值域与空间**：$nums[i] \le 10^6$，数组实现要开到 $10^6 + 2$（因为要访问 $x+1$）；哈希表则无此顾虑。
8. **$n = 10^5$ 的性能**：排序 $O(n \log n)$ 是瓶颈；哈希表记得 `reserve`，Python 用 `dict.get` 避免 `KeyError`。
