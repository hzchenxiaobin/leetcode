# LeetCode 24 点游戏 题解

## 1. 题目概述

- **标题 / 题号**：24 点游戏（#679，hard）
- **链接**：https://leetcode.cn/problems/24-game/
- **来源**：LeetCode 第 50 场周赛 Q4
- **难度**：困难
- **标签**：数组、数学、回溯

**题意**：给定 4 张牌，牌面是 $[1,9]$ 的整数。要在**相邻两个数之间**插入 `+`、`-`、`*`、`/` 并加上括号，把 4 张牌**各用且仅用一次**，判断能否得到 24。三条附加禁令：

1. `/` 是**实数除法**（$4 / (1 - 2/3) = 12$），不是整除；
2. **不允许一元负号**（`[1,1,1,1]` 不能拼成 `-1 - 1 - 1 - 1`）；
3. **不允许把数字拼成多位数**（`[1,2,1,2]` 不能拼成 `12 + 12`）。

**约束**：

- `cards.length == 4`，牌数固定，因此任何「常数级但很大」的搜索都能跑完；
- $1 \le \text{cards}[i] \le 9$，中间结果绝对值不超过 $9^4 = 6561$，不会溢出。

## 2. 示例

**示例 1**

```text
输入：cards = [4,1,8,7]
输出：true
解释：(8 - 4) * (7 - 1) = 4 * 6 = 24。
```

**示例 2**

```text
输入：cards = [1,2,1,2]
输出：false
解释：所有加括号与运算组合都凑不出 24（拼成 "12 + 12" 是被禁止的）。
```

**补充示例（非官方，用来说明实数除法）**

```text
输入：cards = [3,3,8,8]
输出：true
解释：8 / (3 - 8/3) = 8 / (1/3) = 24。
      若按整数除法 8/3 = 2，则 3 - 2 = 1，结果变成 8，必然误判为 false。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的想法是**枚举所有表达式**：4 张牌的全排列 $4! = 24$ 种，4 个叶子能构成的二叉树形状有 5 种（$((a\,b)\,c)\,d$、$(a\,(b\,c))\,d$、$(a\,b)\,(c\,d)$、$a\,((b\,c)\,d)$、$a\,(b\,(c\,d))$），3 个运算符位置各有 4 种选择 $4^3 = 64$：

$$24 \times 5 \times 64 = 7680 \text{ 个表达式}$$

规模其实很小，但**实现上极难写对**：手写 5 种括号形状要写 5 个嵌套函数，拼字符串再解析在 C++ 里根本没有现成工具，除零还要单独拦截；更糟的是「括号 + 运算顺序」的不同描述会互相重叠，稍不留神就漏掉一类。

> 💡 所以真正的问题不是「搜索空间多大」，而是「用什么统一的表示来覆盖全部表达式，且不漏不重」。答案就是**二叉树**。

### 3.2 核心观察：表达式 = 四叶二叉树，可以「二合一」归并

![表达式对应四叶二叉树，必然存在一对兄弟叶子](images/wc50_q4_pair_merge_tree.svg)

一个 24 点表达式去掉运算符和括号之后，剩下的就是一棵**满二叉树**：

- **叶子**：4 张牌，每张恰好出现一次；
- **内部结点**：3 个，每个代表一次二元运算；
- **树形**：等价于括号的嵌套方式。

于是问题变成「在这棵树上选运算」。关键引理是：

> 任何一棵这样的树，都**至少存在一个内部结点，它的两个孩子都是叶子**——取深度最大的那个内部结点即可。

这对搜索的启发是决定性的：**任何表达式都可以看成「先合并两张牌得到一个数，再拿这个数和剩下的牌继续组合」**。既然总有一对牌是被直接合并的，我们就不必显式写出任何括号，只要：

1. 从当前牌堆里任选**两张**（可以不相邻）；
2. 用**六种**方式把它们合并成一个新数：$a+b$、$a-b$、$b-a$、$a\times b$、$a\div b$、$b\div a$；
3. 新数放回牌堆，牌数 $4 \to 3 \to 2 \to 1$；
4. 只剩一张时，检查它是不是 24。

六种运算里 $a-b$ 与 $b-a$、$a\div b$ 与 $b\div a$ **必须都写**：减法与除法不满足交换律，示例 1 的第 ③ 步用的就是 $7-1$ 而非 $1-7$。

### 3.3 算法流程

![回溯流程：挑一对合并，牌数减一，递归到只剩一张](images/wc50_q4_dfs_flow.svg)

$$\text{dfs}(\text{nums}) = \begin{cases} |\text{nums}[0] - 24| < \varepsilon, & |\text{nums}| = 1 \\[2pt] \bigvee_{i<j}\ \bigvee_{v \in \text{cand}(i,j)} \text{dfs}(\text{nums} \setminus \{i,j\} \cup \{v\}), & |\text{nums}| \ge 2 \end{cases}$$

其中 $\text{cand}(i,j)$ 是上文的六个候选值（除数为 0 时跳过对应除法）。因为只要有一个分支返回 `true` 就整体成功，所以是**带短路与回溯的 DFS**，不需要记忆化——总共只有几千个结点。

### 3.4 示例演算

![示例演算：[4,1,8,7] 三步归并成 24](images/wc50_q4_walkthrough.svg)

对 `cards = [4,1,8,7]`，沿着「能找到解」的那条路径走：

| 层 | 当前牌堆 | 动作 | 说明 |
|----|----------|------|------|
| ① | `[4, 1, 8, 7]` | 选中 `8` 与 `4` | 任意一对都能选，不必相邻 |
| ② | `[1, 7, 4]` | $8-4=4$ | 六个候选是 $12,-4,4,32,0.5,2$，取第 3 个（$b-a$） |
| ③ | `[4, 6]` | $7-1=6$ | 注意是 $b-a$：$1-7=-6$ 就走不通 |
| ④ | `[24]` | $4\times 6=24$ | $\lvert 24-24 \rvert < \varepsilon$，返回 `true` |

得到的表达式正是 $(8-4)\times(7-1)$。DFS 会先试别的对子（如 $4+1=5$），那些分支全部失败后才轮到这一条，这也说明**搜索顺序不影响正确性**，只影响命中速度。

## 4. 算法细节

1. **用 `double`（或 `float`）存牌**：把 `int` 转成实数再运算。若继续用 `int`，$1/3$ 会变成 $0$，`[3,3,8,8]` 这类用例立刻出错。
2. **六个候选值一个都不能少**：$a+b$、$a-b$、$b-a$、$a\times b$、$a\div b$、$b\div a$。少写 $b-a$ 或 $b\div a$ 会漏解（示例 1 就死在 $b-a$ 上）。
3. **`rest` 用「删除两个、加入一个」构造**：先把 $i$、$j$ 之外的数拷进 `rest`，再把候选值 `push_back` 进去递归，返回后 `pop_back` 回溯。这样每层牌数严格递减，保证「每张牌恰好用一次」。
4. **除零保护**：仅当 $|b| > \varepsilon$ 时才加入 $a/b$，同理 $|a| > \varepsilon$ 时才加入 $b/a$。中间结果完全可能是 0（例如 `1-1`），不能只看输入 $\ge 1$。
5. **浮点比较用 $\varepsilon = 10^{-6}$**：结尾判断写成 `fabs(x - 24) < 1e-6`，绝不能写 `x == 24.0`。全部中间值都是小分母有理数，误差在 $10^{-15}$ 量级，$10^{-6}$ 的容差足够宽裕。
6. **不要写一元负号**：`-x` 这种「一步只处理一个数」的操作不属于题目允许的运算；本题的 DFS 每步都在**两个**当前值之间做二元运算，天然满足禁令，无需额外判断。
7. **不要拼接数字**：搜索空间里的每个值都是一次运算的结果，根本没有字符串拼接的操作，所以「`12+12` 非法」这条也自动满足。
8. **不做记忆化**：状态数约 $1+36+648+3888 = 4573$，比任何哈希开销都小；加 `set` 反而更慢。
9. **可选的去重剪枝**：牌面有重复（如 `[1,1,1,1]`）时，不同的 $(i,j)$ 组合会产生相同的 `rest` 与候选值；把排序后的 `rest` 记进集合跳过重复分支**不会漏解**（搜索的是多重集合而非下标），只是本题规模下收益为零，代码保持最简更好。

## 5. 正确性证明

**引理 1（兄弟叶子存在）**：任意一棵至少有两个叶子的满二叉树中，存在一个内部结点，其两个孩子都是叶子。

**证明**：树有限，取**深度最大**的内部结点 $v$。若 $v$ 的某个孩子 $w$ 也是内部结点，则 $\text{depth}(w) = \text{depth}(v) + 1 > \text{depth}(v)$，与 $v$ 的选取矛盾。故 $v$ 的两个孩子都是叶子。∎

**引理 2（合并一步的完备性）**：设牌堆 $M$（$|M| = n \ge 2$）上存在值为 24 的合法表达式，则存在两个不同位置的牌 $a, b \in M$ 与一个运算 $\circ \in \{+,-,\times,\div\}$（含两个方向），使得 $M' = M \setminus \{a,b\} \cup \{a \circ b\}$ 上存在值为 24 的合法表达式。

**证明**：把该表达式写成二叉树 $T$，叶子与 $M$ 中的牌一一对应。由引理 1，$T$ 中存在兄弟叶子 $a, b$（它们对应 $M$ 中两个不同位置），设其父结点的运算为 $\circ$，则该子树的值恰为 $a \circ b$。把该子树整体替换为单叶 $a \circ b$，得到新树 $T'$，其叶子集合正是 $M'$，且 $T'$ 与原树同值（替换的子树值不变），故 $M'$ 上存在值 24 的表达式。若原来的运算方向是 $b \circ a$ 形式，由于我们为同一对 $(a,b)$ 同时枚举了 $a-b$ 与 $b-a$、$a/b$ 与 $b/a$，对应的候选值仍会出现。∎

**定理**：`judgePoint24(cards)` 返回 `true` 当且仅当存在合法表达式使其值为 24。

**证明**：

- （可靠性，$\Rightarrow$）对递归深度归纳。不变量：递归中 `nums` 的每个元素都对应一个**合法表达式**（只对当前若干张牌做二元运算、不拼接、不取反），且不同元素用到的牌互不相同、并起来恰为当前可用的全部牌。初始时每张牌单独成式，成立；每步把两个合法表达式用一次二元运算合并，仍是合法表达式，牌集合的互斥性与完备性也保持。当 $|\text{nums}| = 1$ 且 $|x - 24| < \varepsilon$ 时返回 `true`，此时 $x$ 对应的就是一个值为 24 的合法表达式。
- （完备性，$\Leftarrow$）对牌数 $n$ 归纳。$n = 1$：直接比较数值，成立。$n \ge 2$：设存在值为 24 的表达式，由引理 2 取合适的 $(a,b,\circ)$，使 $M'$ 上存在值 24 的表达式；DFS 枚举了所有 $i<j$ 与全部六个候选值，故一定尝试到该组合，递归进入 $M'$（规模 $n-1$），由归纳假设该分支返回 `true`，于是整体返回 `true`。∎

**关于 $\varepsilon$ 的说明**：浮点只出现在「是否等于 24」这一处。由于判定容差 $10^{-6}$ 与真实值间隔的关系并非先验显然，我在验证阶段用**精确有理数**（`fractions.Fraction`）独立枚举了全部 $24\times5\times64=7680$ 个表达式，对 $[1,9]$ 内全部 $\binom{12}{4}=495$ 种牌面逐一比对，结果与浮点实现**完全一致**（详见第 8 节的验证说明）。若要追求形式上的严谨，可把 `double` 换成有理数或分数的 `pair<long long,long long>`。

## 6. 复杂度分析

- **时间**：记 $f(m)$ 为牌数为 $m$ 时的搜索结点数，则 $f(m) \le 6\binom{m}{2} \cdot f(m-1)$，$f(1) = 1$。展开得叶子数 $36 \times 18 \times 6 = 3888$，总结点数约 $4573$。每个结点构造 `rest` 需 $O(m)$，故总运算量约 $10^4$ 次，即 **$O(1)$**（是与输入数值无关的固定常数，实测单次调用不到 1 ms）。
- **空间**：递归深度最多 3 层，每层持有一个长度不超过 4 的 `rest` 数组，故 **$O(n^2)$** 个字（$n = 4$ 时就是几个 `double`），不含输入输出。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <cmath>
using namespace std;

class Solution {
public:
    bool judgePoint24(vector<int>& cards) {
        vector<double> nums(cards.begin(), cards.end());   // 实数除法：先转 double
        return dfs(nums);
    }

private:
    static constexpr double EPS = 1e-6;

    bool dfs(vector<double>& nums) {
        int n = (int)nums.size();
        if (n == 1) return fabs(nums[0] - 24.0) < EPS;     // 浮点必须用 eps 比较

        for (int i = 0; i < n; ++i) {
            for (int j = i + 1; j < n; ++j) {
                double a = nums[i], b = nums[j];

                // rest = 除 i、j 之外的牌
                vector<double> rest;
                rest.reserve(n - 1);
                for (int k = 0; k < n; ++k)
                    if (k != i && k != j) rest.push_back(nums[k]);

                // 六种合并方式；减法、除法必须双向
                double cand[6];
                int cnt = 0;
                cand[cnt++] = a + b;
                cand[cnt++] = a - b;
                cand[cnt++] = b - a;
                cand[cnt++] = a * b;
                if (fabs(b) > EPS) cand[cnt++] = a / b;     // 除零保护
                if (fabs(a) > EPS) cand[cnt++] = b / a;

                for (int t = 0; t < cnt; ++t) {
                    rest.push_back(cand[t]);                // 新牌入堆
                    if (dfs(rest)) return true;             // 短路：命中即返回
                    rest.pop_back();                        // 回溯
                }
            }
        }
        return false;
    }
};
```

### Python

```python
from typing import List


class Solution:
    def judgePoint24(self, cards: List[int]) -> bool:
        EPS = 1e-6

        def dfs(nums: List[float]) -> bool:
            n = len(nums)
            if n == 1:
                return abs(nums[0] - 24.0) < EPS        # 浮点比较必须带容差

            for i in range(n):
                for j in range(i + 1, n):
                    a, b = nums[i], nums[j]
                    rest = [nums[k] for k in range(n) if k != i and k != j]

                    cands = [a + b, a - b, b - a, a * b]
                    if abs(b) > EPS:
                        cands.append(a / b)             # 除零保护
                    if abs(a) > EPS:
                        cands.append(b / a)

                    for v in cands:
                        rest.append(v)                  # 新牌入堆
                        if dfs(rest):
                            return True                 # 短路返回
                        rest.pop()                      # 回溯
            return False

        return dfs([float(x) for x in cards])
```

## 8. 边界情况与易错点

1. **整数除法**：`[3,3,8,8]` 的解 $8/(3-8/3)$ 依赖 $8/3$ 是分数。用 `int` 会让答案变成 `false`，这是本题最高频的 WA。
2. **单向减法/除法**：`[4,1,8,7]` 需要 $7-1$，`[1,5,5,5]` 需要 $5\times(5-1/5)$，都需要「大数在前」的方向；若只写 `a-b`、`a/b` 会大面积漏解。
3. **浮点等值判断**：必须 `fabs(x-24) < 1e-6`。写 `x == 24.0` 时，纯整数的路径（如 $8\times 3$）能侥幸通过，但含除法的路径几乎必然差一个 $10^{-16}$ 量级，于是只有「无解」的牌面能答对，等于白写。
4. **中间结果为 0 的除法**：`[1,1,3,8]` 之类会算出 `1-1=0`，之后 `a/b` 里的 $b = 0$；因此除零保护必须放在**每个候选值**处，而不是只在输入处检查。
5. **每张牌恰好用一次**：`rest` 是「删两个、加一个」，牌数随递归严格递减——如果误把原 `nums` 整体传下去（不做删除），就会允许反复使用同一张牌，得出错误 `true`。
6. **一元负号**：不要为了「方便」额外加一个 `-a` 这类**单目**候选值——题目只允许二元运算，加上它就等于偷偷放宽了题意；换一个目标值或换一批牌，它就会真的把 `false` 判成 `true`。本题的 DFS 每步都在两个当前值之间做二元运算，天然不产生一元负号。
7. **数字拼接**：不要用字符串或 `a*10+b` 的拼接候选，否则 `[1,2,1,2]` 会通过 `12+12` 误判为 `true`——这正是示例 2 的作用。
8. **全 `false` 的牌面**：`[1,1,1,1]`、`[1,1,1,2]`、`[1,2,1,2]` 等都必须正确返回 `false`；本题有解的比例并不低（$[1,9]$ 的 495 种牌面里有 404 种为 `true`），所以「默认返回 true」的偷懒写法在小数据上也能骗过一部分用例，务必完整搜索。
9. **`rest` 的引用语义**：C++ 用引用 + `push_back/pop_back` 回溯，Python 每轮新建 `rest`。若在 C++ 里每次 `dfs` 都传值拷贝也能过，但会多出无谓开销。

> ✅ **验证说明**：本题解的两份代码均在 `/tmp/verify_50_4/` 下编译运行过官方两组示例（Python 与 C++ 输出均为 `true` / `false`）；另外用「$4! \times 5$ 种树形 $\times 4^3$ 种运算符、`Fraction` 精确求值」的独立暴力，对 40 组随机牌面 + 15 组构造牌面（含 `[3,3,8,8]`、`[1,5,5,5]`、`[1,1,1,1]`）对拍，不一致 0 组；最后把 $[1,9]$ 的全部 495 种多重集合全量跑了一遍，与精确暴力仍然 0 组不一致。
