# LeetCode 抛掷硬币 题解

## 1. 题目概述

- **标题 / 题号**：抛掷硬币（#1230，medium）
- **链接**：https://leetcode.cn/problems/toss-strange-coins/
- **来源**：LeetCode 第 11 场双周赛 Q3
- **难度**：中等
- **标签**：数组、数学、动态规划、概率与统计

**题意**：有 $n$ 枚「奇怪的硬币」，第 $i$ 枚抛出正面朝上的概率为 $prob[i]$。把每枚硬币**恰好抛一次**，求正面朝上的硬币总数恰好等于 $target$ 的概率。

**约束**：

- $1 \le prob.length \le 1000$
- $0 \le prob[i] \le 1$
- $0 \le target \le prob.length$
- 答案误差在 $10^{-5}$ 以内即视为正确

> 💡 「每枚恰好一次 + 各枚概率不同」说明这是**独立但不同分布**的伯努利试验——不是二项分布（那是同概率场景），不能套 $C_n^{target} p^{target} (1-p)^{n-target}$，必须老老实实做概率的卷积累加。

## 2. 示例

**示例 1**

```text
输入：prob = [0.4], target = 1
输出：0.40000
解释：唯一的硬币要以正面计数，概率即 0.4。
```

**示例 2**

```text
输入：prob = [0.5,0.5,0.5,0.5,0.5], target = 0
输出：0.03125
解释：五枚全为反面，概率 0.5^5 = 0.03125。
```

**补充示例（混合概率）**

```text
输入：prob = [1.0, 0.5, 0.0], target = 1
输出：0.50000
解释：第 1 枚必正面、第 3 枚必反面，真正自由的是第 2 枚（概率 0.5）。
```

补充示例展示了 $prob[i] \in \{0, 1\}$ 的退化情形：确定性硬币既不该贡献概率分支，也不会让 DP 失效——转移式自然处理。

## 3. 解题思路

### 3.1 暴力思路

枚举每枚硬币正/反的全部 $2^n$ 种组合，对正面数恰为 $target$ 的组合累加概率之积。$n \le 1000$ 时 $2^{1000}$ 完全不可行；即使把「组合枚举」改造成「枚举正面的下标集合」也只对 $n \le 20$ 左右可用（$C_{20}^{10} \approx 18$ 万）。它真正的用途是**对拍基准**：$n \le 10$ 时可以精确到 $10^{-15}$ 级别地校验 DP 的实现。

### 3.2 核心观察：正面计数是逐枚累加的——按硬币顺序做概率 DP

![核心观察：每枚硬币把概率质量在「正面数」轴上平移或留守](images/bw11_q3_dp_model.svg)

把「已处理前 $i$ 枚硬币、其中正面数为 $j$」的概率记为状态。处理第 $i$ 枚（正面率 $p$）时，这个状态只发生两种迁移：

- 反面（概率 $1-p$）：正面数不变，$j \to j$；
- 正面（概率 $p$）：正面数加一，$j \to j+1$。

$$dp_i[j] = dp_{i-1}[j] \cdot (1 - p_i) + dp_{i-1}[j-1] \cdot p_i$$

这正是**一维卷积**逐层累乘的过程：每枚硬币的作用是把当前概率分布「乘 $(1-p)$ 留在原地，再把整体右移一格乘 $p$ 叠加上去」。初始 $dp_0[0] = 1$（零枚硬币零正面），最终答案 $dp_n[target]$。

顺带一提等价的**逆序视角**：从最后一枚硬币往前算，状态含义改成「剩余硬币中还需凑出的正面数」，转移形式完全对称（先处理完右侧硬币再决定左侧）。两种写法殊途同归，本文按正序实现。

> 💡 $target > n$ 或 $target < 0$ 不在约束内（$0 \le target \le n$），但把 dp 数组开成 $target+1$ 长度、下标越界即概率为 0 的写法，天然把「不可能」编码掉了。

### 3.3 算法流程：滚动数组 + 倒序扫描

![算法流程：滚动数组一维化，j 必须倒序更新避免本枚概率重复使用](images/bw11_q3_rolling_array.svg)

```text
1. dp = [0] * (target + 1)；dp[0] = 1
2. for p in prob:
3.     for j = target downto 0:            # 倒序！
4.         dp[j] = dp[j] * (1 - p)         # 本枚反面
5.                + (dp[j-1] * p if j > 0 else 0)   # 本枚正面
6. 返回 dp[target]
```

为什么 $j$ 必须**倒序**：一维滚动复用同一数组时，$dp[j]$ 的新值要用**旧**的 $dp[j-1]$（上一枚硬币的概率）。若正序更新，$dp[j-1]$ 已被本枚硬币的转移污染，等于同一枚硬币被算了两次——这正是 01 背包一维化的同款坑。

### 3.4 示例演算

![示例演算：[0.4] 与 [0.5,0.5,0.5,0.5,0.5] 的 DP 表](images/bw11_q3_example_walkthrough.svg)

**示例 2（$prob = [0.5 \times 5]$，$target = 0$）**：只需盯住 $dp[0]$，每枚硬币执行 $dp[0] \mathrel{\times}= 0.5$：

| 处理第几枚 | $dp[0]$ |
|-----------|---------|
| 0（初始） | 1 |
| 1 | 0.5 |
| 2 | 0.25 |
| 3 | 0.125 |
| 4 | 0.0625 |
| 5 | **0.03125** ✓ |

**补充示例（$[1.0, 0.5, 0.0]$，$target = 1$）**：

| 处理 | $dp[0]$ | $dp[1]$ | 说明 |
|------|---------|---------|------|
| 初始 | 1 | 0 | |
| $p=1.0$ | 0 | 1 | 必正面：质量整体右移 |
| $p=0.5$ | 0 | 0.5 | $dp[1] = 0\times 0.5 + 1\times 0.5$ |
| $p=0.0$ | 0 | 0.5 | $dp[1] = 0.5 \times 1 + 0 \times 0$ |

返回 $dp[1] = 0.5$ ✓。可以看到 $p=1$ 与 $p=0$ 的硬币分别表现为「纯右移」与「纯留守」，无需任何特判。

## 4. 算法细节

1. **状态定义**：$dp[i][j]$ = 前 $i$ 枚硬币恰有 $j$ 枚正面的概率；转移为独立事件概率的乘积之和（全概率公式按第 $i$ 枚的正/反分解）。滚动后只留 $dp[j]$。
2. **倒序更新的正确性**：新 $dp[j]$ 依赖旧 $dp[j]$ 与旧 $dp[j-1]$；倒序保证读取 $dp[j-1]$ 时它尚未被本轮覆盖（同 01 背包）。
3. **数组长度取 $target+1$ 而非 $n+1$**：正面数超过 $target$ 的状态对答案无贡献，直接截断，空间从 $O(n)$ 降为 $O(target)$，且转移里 `j > 0` 的判断天然处理了边界。
4. **精度**：$n \le 1000$、每步乘加两次，`double`（约 15–16 位有效数字）累计误差远小于 $10^{-5}$ 的判定阈值；无需 `long double` 或分数运算。
5. **验证口径**：对拍时不要用「四舍五入后相等」比较，应使用绝对误差 $10^{-9}$ 级别的阈值，避免掩盖实现错误。

## 5. 正确性证明

**引理 1（状态独立性）**：各硬币抛掷结果相互独立，故任意一个「正/反模式」$\sigma \in \{0,1\}^n$ 发生的概率为 $\prod_i (p_i)^{\sigma_i}(1-p_i)^{1-\sigma_i}$。

**证明**：题目设定每枚硬币被抛一次且互不影响，是 $n$ 个独立伯努利试验；由独立性，联合概率等于边缘概率之积。∎

**引理 2（DP 状态的正确含义）**：处理完前 $i$ 枚硬币后，$dp_i[j] = \Pr[\text{前 } i \text{ 枚中恰 } j \text{ 枚正面}]$。

**证明**：对 $i$ 归纳。$i = 0$ 时 $dp_0[0] = 1$，零枚硬币零正面概率为 1，成立。设 $i-1$ 时成立。事件「前 $i$ 枚恰 $j$ 正面」按第 $i$ 枚的结果划分为两个不相容事件：「前 $i-1$ 枚恰 $j$ 正面且第 $i$ 枚反面」与「前 $i-1$ 枚恰 $j-1$ 正面且第 $i$ 枚正面」。由全概率公式与引理 1 的独立性，
$$dp_i[j] = dp_{i-1}[j]\,(1 - p_i) + dp_{i-1}[j-1]\,p_i,$$
其中 $j-1 < 0$ 时第二项为 0。与算法转移一致。∎

**定理**：算法返回 $\Pr[\text{$n$ 枚硬币中恰 $target$ 枚正面}]$。

**证明**：由引理 2（取 $i = n$），二维 DP 的 $dp_n[target]$ 即所求概率。一维滚动实现中，倒序扫描保证每个 $dp[j]$ 的更新读取的是上一层的 $dp[j]$ 与 $dp[j-1]$（见 4.2），故一维数组在第 $i$ 轮扫描结束时与二维的 $dp_i[\cdot]$（$0 \le j \le target$）完全一致，归纳即得返回值 $= dp_n[target]$，即所求概率。∎

## 6. 复杂度分析

- **时间**：$O(n \cdot target)$。每枚硬币对 $dp[0..target]$ 各做一次 $O(1)$ 转移；最坏 $1000 \times 1000 = 10^6$ 次浮点乘加，毫秒级完成。
- **空间**：$O(target)$。滚动数组只保留当前一层的 $target + 1$ 个概率值（二维写法为 $O(n \cdot target)$，滚动化是标准优化）。

对照暴力 $O(2^n)$：$n = 1000$ 时是天文数字；DP 用「按正面数聚合状态」把指数条路径压成 $n \cdot target$ 个概率质量桶，这正是概率 DP 的普遍收益。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    double probabilityOfHeads(vector<double>& prob, int target) {
        vector<double> dp(target + 1, 0.0);
        dp[0] = 1.0;                                  // 0 枚硬币 0 正面
        for (double p : prob) {
            for (int j = target; j >= 0; --j) {       // 倒序：读旧的 dp[j-1]
                dp[j] = dp[j] * (1.0 - p)
                       + (j > 0 ? dp[j - 1] * p : 0.0);
            }
        }
        return dp[target];
    }
};
```

### Python

```python
class Solution:
    def probabilityOfHeads(self, prob: list[float], target: int) -> float:
        dp = [0.0] * (target + 1)
        dp[0] = 1.0
        for p in prob:
            for j in range(target, -1, -1):           # 倒序更新
                dp[j] = dp[j] * (1 - p) + (dp[j - 1] * p if j > 0 else 0.0)
        return dp[target]
```

**验证记录**：两份代码均通过官方双示例（0.40000、0.03125）；与「枚举 $2^n$ 全部正/反模式精确求和」的暴力器对拍 **3007 组**（$n \le 10$ 随机概率 + 全 0/全 1/半确定等特殊用例），绝对误差全部 $< 10^{-9}$；另以 $n = 1000$ 的随机大例验证 C++ 与 Python 输出一致（六位小数）。

## 8. 边界情况与易错点

1. **别套二项分布公式**：各枚概率不同，$C_n^{target} p^{target}(1-p)^{n-target}$ 仅当所有 $p_i$ 相同时成立；示例 2 的 $0.5$ 均匀情形恰好骗过公式，混合概率立刻露馅。
2. **倒序更新是硬约束**：一维滚动时正序扫描会让同一枚硬币的概率被重复使用（读到了本轮刚写入的 $dp[j-1]$），结果系统性偏大——这是从 01 背包迁移过来最容易踩的坑。
3. **$target = 0$ 与 $target = n$**：分别是「全反面」与「全正面」的极端情形，转移式自然覆盖；测试时应显式包含。
4. **$p_i \in \{0, 1\}$ 的确定性硬币**：转移退化为纯移位/纯留守，无需特判，但值得在测试集中单列（容易暴露初始化错误）。
5. **数组只开到 $target$**：省空间的同时要小心 $j-1$ 的下界（`j > 0` 判断）与「$target$ 截断丢弃的高正面数状态」——后者对答案无贡献，截断安全。
6. **浮点比较**：判题容差 $10^{-5}$，但本地对拍建议用 $10^{-9}$ 阈值，把实现 bug 与浮点噪声区分开。
