# LeetCode 分享巧克力 题解

## 1. 题目概述

- **标题 / 题号**：分享巧克力（#1231，hard）
- **链接**：https://leetcode.cn/problems/divide-chocolate/
- **来源**：LeetCode 第 11 场双周赛 Q4
- **难度**：困难
- **标签**：数组、二分查找

**题意**：一根巧克力由若干**连续小块**组成，第 $i$ 块甜度为 $sweetness[i]$。你要与 $K$ 位朋友分享：用**恰好 $K$ 刀**把整条巧克力切成 $K+1$ 段（每段由连续小块组成、非空），朋友们各拿一段，**自己拿走总甜度最小的那段**。求最优切法下「自己那段」总甜度的最大值。

**约束**：

- $0 \le K < sweetness.length \le 10^4$
- $1 \le sweetness[i] \le 10^5$

> 💡 题眼的转化：最大化「各段甜度最小值」——「最大化最小值」是**二分答案**的标准信号：把「答案能否 $\ge x$」变成一个可行性判定，而可行性对 $x$ 单调。

## 2. 示例

**示例 1**

```text
输入：sweetness = [1,2,3,4,5,6,7,8,9], K = 5
输出：6
解释：切成 [1,2,3],[4,5],[6],[7],[8],[9]，各段和为 6,9,6,7,8,9，
     最小段为 6。
```

**示例 2**

```text
输入：sweetness = [5,6,7,8,9,1,2,3,4], K = 8
输出：1
解释：8 刀切 9 段，每段只能是单独一块，最小段即数组最小值 1。
```

**示例 3**

```text
输入：sweetness = [1,2,2,1,2,2,1,2,2], K = 2
输出：5
解释：切成 [1,2,2],[1,2,2],[1,2,2]，三段甜度均为 5。
```

示例 2 是 $K = n-1$ 的极端：切法唯一，答案就是 $\min(sweetness)$——这也给出了二分下界的直觉。

## 3. 解题思路

### 3.1 暴力思路

枚举所有切法：从 $n-1$ 个间隙中选 $K$ 个下刀位置，共 $\binom{n-1}{K}$ 种，每种 $O(n)$ 计算最小段和。$K$ 居中时组合数是天文数字（$n = 10^4$ 时 $\binom{9999}{5000}$ 有数千位），完全不可行。换一个多项式的「DP 暴力」：$g[i][j]$ 表示前 $i$ 块分成 $j$ 段时最小段和的最大值，转移 $g[i][j] = \max_{t<i} \min(g[t][j-1],\ \mathrm{sum}(t{+}1..i))$，$O(n^2 K)$——$n, K \sim 10^4$ 时约 $10^{12}$，同样超时，但它既揭示了「最小段和关于切法呈凹性」的直觉（这正是可二分的结构），又是本文对拍的参照解。

### 3.2 核心观察：判定「每段甜度都 ≥ x」可以贪心，且判定对 x 单调

![核心观察：二分阈值 x，贪心检查能否切出 K+1 段都 ≥ x](images/bw11_q4_binary_search_model.svg)

把问题反过来问：**给定阈值 $x$，能否把巧克力切成 $K+1$ 段、每段总甜度 $\ge x$？** 记判定结果为 $feasible(x)$，则：

- **单调性**：$feasible(x) \Rightarrow feasible(x-1)$（同一组切法在更低的阈值下依然合法）。于是 $feasible$ 呈「真…真 假…假」布局，答案即**最大的可行 $x$**，可二分。
- **贪心判定**：从左到右累加，一旦当前段和 $\ge x$ 立刻切一刀、清零重来；数一数总共切出多少段，$\ge K+1$ 即可行。这是「在每段和 $\ge x$ 的约束下**最大化段数**」的经典贪心——刀落得越早，留给后面的余量越大。

两件事拼起来：二分 $x$ + 贪心 $check(x)$，即为答案。示例 1 中 $x=6$ 可行（贪心切出 6 段：$1{+}2{+}3,\ 4{+}5,\ 6,\ 7,\ 8,\ 9$，段和 $6,9,6,7,8,9$ 全 $\ge 6$），$x=7$ 不可行（只能切 5 段），故答案 6。

> ⚠️ 「至少 $K+1$ 段」与「恰好 $K+1$ 段」的等价性需要说明（见 §5 引理 2）：贪心切出的段数若超过 $K+1$，把相邻段两两合并即可减到恰好 $K+1$ 段，而合并只会让每段的和更大、约束依然满足。这一步是「贪心段数 $\ge K+1$ ⟺ 存在合法的 $K+1$ 段切法」的桥梁。

### 3.3 算法流程

![算法流程：二分上中位 + 贪心切段](images/bw11_q4_greedy_check.svg)

```text
1. lo = min(sweetness), hi = sum(sweetness) / (K+1)     # 闭区间二分
2. while lo < hi:
3.     mid = (lo + hi + 1) / 2                           # 上中位，防死循环
4.     cnt = 0, cur = 0
5.     for s in sweetness:
6.         cur += s
7.         if cur >= mid: cnt += 1; cur = 0              # 尽早落刀
8.     if cnt >= K + 1: lo = mid                         # mid 可行，答案 ≥ mid
9.     else:            hi = mid - 1                     # mid 不可行
10. 返回 lo
```

初始下界 $lo = \min(sweetness)$ 必然可行：每个小块都 $\ge lo$，逐块切段可得 $n \ge K+1$ 段、每段 $\ge lo$；初始上界 $hi = \lfloor \mathrm{sum}/(K+1) \rfloor$ 满足 $hi+1$ 必不可行（$(K+1)(hi+1) > \mathrm{sum}$，鸽巢保证必有段 $< hi+1$），故答案落在闭区间 $[lo, hi]$ 内，二分完备。

### 3.4 示例演算

![示例演算：示例 1 的二分轨迹与贪心切法](images/bw11_q4_example_walkthrough.svg)

**示例 1（$[1..9]$，$K=5$）**：$\min = 1$，$\lfloor 45/6 \rfloor = 7$，二分区间 $[1, 7]$。贪心的落刀规则是「段和**首次**达到阈值立刻切」，演算如下：

| 区间 | mid | 贪心切段（∥ 为刀） | 段数 | $\ge 6$？ | 动作 |
|------|-----|---------------------|------|-----------|------|
| [1,7] | 4 | 1+2+3=6 ∥ 4+5=9 ∥ 6 ∥ 7 ∥ 8 ∥ 9 | 6 | 是 | lo=4 |
| [4,7] | 6 | 1+2+3=6 ∥ 4+5=9 ∥ 6 ∥ 7 ∥ 8 ∥ 9 | 6 | 是 | lo=6 |
| [6,7] | 7 | 1+2+3+4=10 ∥ 5+6=11 ∥ 7 ∥ 8 ∥ 9 | 5 | 否 | hi=6 |
| [6,6] | — | 收敛 | — | — | 返回 **6** ✓ |

注意 $x=6$ 与 $x=4$ 的贪心切法恰好相同——段和 $6,9,6,7,8,9$ 全都 $\ge 6$，阈值继续压低并不会「解锁」新的切法，只会让同一批切法在更松的约束下重复成立；二分找的正是「贪心还能挤出 $K+1$ 段」的**最大**阈值。

**示例 3（$[1,2,2,1,2,2,1,2,2]$，$K=2$）**：$\lfloor 15/3 \rfloor = 5$。$x=5$：$1{+}2{+}2=5$ 切、$1{+}2{+}2=5$ 切、$1{+}2{+}2=5$ 切，3 段 $\ge 3$ ✓；$x=6$：$1{+}2{+}2{+}1=6$ 切、$2{+}2{+}1{+}2=7$ 切、末尾只剩 $2$，共 2 段 $<3$ ✗。二分收敛到 5 ✓。

## 4. 算法细节

1. **二分对象与方向**：求「最大可行 $x$」用上中位数 $mid = (lo + hi + 1)/2$，可行时 $lo = mid$、不可行时 $hi = mid - 1$；若误用下中位，在 $hi = lo + 1$ 且该 $mid$ 可行时会陷入 $lo$ 永不推进的死循环。
2. **贪心 check 的语义**：数的是「每段和 $\ge x$ 时最多能切多少段」，与「恰好 $K$ 刀」之间靠引理 2 的合并论证衔接；check 本身 $O(n)$，全程 $O(n \log S)$，$S \le 10^9$，约 30 轮。
3. **边界值预置**：$lo$ 取 $\min(sweetness)$（恒可行），$hi$ 取 $\lfloor \mathrm{sum}/(K+1) \rfloor$（$hi+1$ 恒不可行）；由 $\mathrm{sum} \ge n \cdot \min \ge (K+1)\min$ 保证 $lo \le hi$，闭区间二分无需越界特判。
4. **$K = 0$ 的退化**：一刀不切、整条归自己，答案 $sum$；上界 $hi = sum/1 = sum$，$check(sum)$ 因「整段和 $\ge sum$」得 1 段 $\ge 1$ 成立，二分自然收敛到 $sum$，无需特判。
5. **数值类型**：$sum \le 10^4 \times 10^5 = 10^9$，贴 `int` 上限（$2^{31}-1 \approx 2.1\times 10^9$），C++ 中 `total`、`x`、`mid` 一律 `long long`；Python 原生大整数无虞。
6. **为什么不直接 DP**：$O(n^2 K)$ 的最小值最大化 DP 在 $10^4$ 规模下超时；二分把「最小值约束」变成判定后，DP 里的段数维度被贪心吸收——这是「最小值最大化 → 二分 + 贪心」的标准降维。

## 5. 正确性证明

记 $n = |sweetness|$，一段为下标区间 $[l, r]$ 的连续小块，$w(l, r) = \sum_{i=l}^{r} sweetness[i]$。称一个切成 $K+1$ 段的方案合法，若 $K+1$ 段两两相邻不重叠、并为全集、每段非空；方案的最小段和记为方案价值。

**引理 1（贪心最大化段数）**：固定 $x \ge 1$。设贪心切法（累加至 $\ge x$ 立即落刀）得到 $p$ 段，则任何「每段和 $\ge x$」的 $q$ 段切法（段两两相邻、并为全集、非空）都满足 $q \le p$。

**证明**：设贪心的切点为 $c_1 < c_2 < \dots < c_p$（第 $t$ 段覆盖 $(c_{t-1}, c_t]$，$c_0 = 0$），任取每段和 $\ge x$ 的 $q$ 段切法，切点 $d_1 < \dots < d_q$（第 $t$ 段覆盖 $(d_{t-1}, d_t]$，$d_0 = 0$）。对 $t = 1, \dots, q$ 归纳证明 $c_t \le d_t$：$t = 1$ 时，切法第 1 段 $w(1, d_1) \ge x$，而 $c_1$ 是**首个**使前缀和 $\ge x$ 的切点，故 $c_1 \le d_1$。设 $c_{t-1} \le d_{t-1}$：切法第 $t$ 段 $w(d_{t-1}+1, d_t) \ge x$，由 $c_{t-1} \le d_{t-1}$ 知区间 $(c_{t-1}, d_t] \supseteq (d_{t-1}, d_t]$，故从贪心第 $t$ 段的起点累加到 $d_t$ 的和 $\ge x$，于是贪心至迟在 $d_t$ 处已落第 $t$ 刀，即 $c_t \le d_t$。特别地若 $q > p$，取 $t = p+1 \le q$ 得 $c_{p+1} \le d_{p+1}$，与贪心只有 $p$ 个切点矛盾；故 $q \le p$。∎

**引理 2（「至少」与「恰好」等价）**：存在每段和 $\ge x$ 的合法 $K+1$ 段切法 $\iff$ 存在每段和 $\ge x$、段数为 $q \ge K+1$ 的切法（段两两相邻、并为全集、每段非空）。

**证明**：（⇒）取 $q = K+1$ 即可。（⇐）对 $q$ 归纳：$q = K+1$ 时即结论；$q > K+1$ 时任取相邻两段合并为一段，段数减一，新段和为两段之和只会更大，每段非空保持，并为全集保持，得到 $q - 1$ 段的同类切法，归纳即得。∎

**引理 3（可行性的贪心刻画）**：$feasible(x)$（存在每段和 $\ge x$ 的合法 $K+1$ 段切法）$\iff$ 贪心 $check(x)$ 的段数 $p(x) \ge K+1$。

**证明**：（⇒）合法 $K+1$ 段切法是「每段和 $\ge x$」的切法，由引理 1 得 $p(x) \ge K+1$。（⇐）设 $p(x) \ge K+1$。贪心切出的 $p$ 段各自非空、互不相交、按序相邻，且段和 $\ge x$；把它们与「尾部不足 $x$ 的残余块」依次拼接（残余并入最后一段，或不并），得到一个「并为全集、每段非空、每段和 $\ge x$」的 $p$ 段切法（残余并入只会增大段和；若残余为空则无需处理）。由引理 2，存在合法的 $K+1$ 段切法。∎

**定理**：二分返回的 $lo$ 等于最优方案价值 $A = \max_{\text{合法切法}} \min_{\text{段}} w$。

**证明**：第一步，证明对任意整数 $x$：$x \le A \iff feasible(x)$。若 $x \le A$，取价值为 $A$ 的合法切法，其每段和 $\ge A \ge x$，可行；若 $x > A$ 反设 $feasible(x)$，则该切法的最小段和 $\ge x > A$，与 $A$ 的最大性矛盾。第二步，由引理 3，$check$ 与 $feasible$ 逐点等价，故 $check$ 的真值集合为 $\{x : x \le A\}$，且 $check(x) \Rightarrow check(x-1)$（同一贪心切法在更低阈值下每段和依然 $\ge x - 1$），呈「真…真 假…假」单调布局。第三步，证 $A$ 落在初始区间内：$A \ge \min(sweetness)$，因为任一合法切法的每段含至少一块，最小段 $\ge \min(sweetness)$，而「逐块切」在 $K = n - 1$ 时恰能达到（每段一块、最小段为最小块；一般地取 $A$ 的定义即得 $A \ge$ 某个切法的最小段 $\ge \min$）；$A \le \lfloor \mathrm{sum}/(K+1) \rfloor$，因为 $K+1$ 段之和恰为 $\mathrm{sum}$，最小段 $\le \mathrm{sum}/(K+1)$。于是标准「找最大真值」二分在闭区间 $[\min, \lfloor \mathrm{sum}/(K+1) \rfloor]$ 内维护不变量「$lo$ 可行或 $lo = \min$ 初始可行、$hi + 1$ 不可行」，终止时 $lo = hi = A$。∎

## 6. 复杂度分析

- **时间**：$O(n \log S)$，$S = \sum sweetness \le 10^9$：二分约 30 轮，每轮贪心一次线性扫描；$n = 10^4$ 时总计约 $3 \times 10^5$ 次加法与比较，毫秒级。
- **空间**：$O(1)$。只使用常数个计数与累加变量（贪心不存储段）。

对照两个参照解：组合暴力指数级；最小值最大化 DP $O(n^2 K)$ 在 $10^4$ 规模超时。二分答案把「段数」这一维从状态里挤压成判定条件，是本题从 hard 降到「线性 × 30」的关键一步。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maximizeSweetness(vector<int>& sweetness, int k) {
        long long total = 0;
        int mn = INT_MAX;
        for (int s : sweetness) { total += s; mn = min(mn, s); }
        long long lo = mn, hi = total / (k + 1);        // 闭区间，两端分别为可行/不可行边界
        while (lo < hi) {
            long long mid = lo + (hi - lo + 1) / 2;     // 上中位：找最大可行值
            if (feasible(sweetness, k, mid)) lo = mid;
            else hi = mid - 1;
        }
        return (int)lo;
    }
private:
    bool feasible(vector<int>& sw, int k, long long x) { // 每段 ≥ x 时最多能切多少段
        int cnt = 0;
        long long cur = 0;
        for (int s : sw) {
            cur += s;
            if (cur >= x) { ++cnt; cur = 0; }           // 尽早落刀
        }
        return cnt >= k + 1;
    }
};
```

### Python

```python
class Solution:
    def maximizeSweetness(self, sweetness: list[int], k: int) -> int:
        def feasible(x: int) -> bool:
            cnt, cur = 0, 0
            for s in sweetness:
                cur += s
                if cur >= x:
                    cnt += 1
                    cur = 0
            return cnt >= k + 1

        lo, hi = min(sweetness), sum(sweetness) // (k + 1)
        while lo < hi:
            mid = (lo + hi + 1) // 2                    # 上中位，防死循环
            if feasible(mid):
                lo = mid
            else:
                hi = mid - 1
        return lo
```

**验证记录**：两份代码均通过官方三示例（6、1、5）；与两种独立参照对拍——「枚举全部 $\binom{n-1}{K}$ 切法」的组合暴力（$n \le 9$）与「$O(n^2K)$ 最小值最大化 DP」（$n \le 40$），合计 **22000 组 0 失配**；另以 $n = 10^4$ 的 50 个随机大例验证 C++ 与 Python 一致、C++ 总耗时 0.27 秒。

## 8. 边界情况与易错点

1. **贪心段数「至少」与题目「恰好 $K$ 刀」**：$check$ 数的是最大段数，超过 $K+1$ 时靠合并相邻段回到恰好 $K+1$ 段（引理 2）；漏掉这一论证会把「cnt > K+1」误判为不可行。
2. **二分用上中位**：求「最大可行值」时 `mid = (lo+hi+1)/2`；用下中位在两端点相邻且可行时会死循环。这是本题最高频的翻车点。
3. **末尾残余段**：贪心扫完后不足 $x$ 的尾巴不计入段数——它不影响判定（见引理 3 的（⇐）方向：残余并入最后一段只会增大段和），但若手误把「cur > 0 则 cnt++」写进 check，会把不可行误判为可行。
4. **$K = 0$**：整条不切，答案为总和；确认二分上下界与 check 在此退化下依然收敛（$hi = sum$，$check(sum)$ 为真）。
5. **溢出**：$sum$ 上界 $10^9$，贴 `int` 上限；C++ 中 `total`、`x` 一律 `long long`。
6. **下界别取 0**：取 $\min(sweetness)$ 作为初始 `lo` 既能缩小二分范围，又天然覆盖 $K = n-1$ 的退化情形（答案恰为最小块）。
7. **目标是「最小段」的最大化**：不是总甜度、也不是平均——示例 3 里三段相等纯属巧合；用 $K=1$ 试同一数组（$[1,2,2,1,2]{=}8$ 与 $[2,1,2,2]{=}7$，答案 7）即可与「平均」区分。
