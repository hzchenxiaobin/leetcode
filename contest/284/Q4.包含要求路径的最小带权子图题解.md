# LeetCode 包含要求路径的最小带权子图 题解

## 1. 题目概述

- **标题 / 题号**：包含要求路径的最小带权子图（#2203，hard）
- **链接**：https://leetcode.cn/problems/minimum-weighted-subgraph-with-the-required-paths/
- **来源**：LeetCode 第 284 场周赛 Q4
- **难度**：困难
- **标签**：图、最短路、Dijkstra、堆（优先队列）、枚举汇合点

**题意**：给定 $n$ 个点的**带权有向图**（边权为正），再给三个互不相同的点 $src1$、$src2$、$dest$。选出**边权和最小**的子图，使得子图中 $src1$ 与 $src2$ 都能到达 $dest$；不存在则返回 `-1`。子图的边权和对其中的每条边**只计一次**——哪怕这条边同时服务两条路径。

**约束**：

- $3 \le n \le 10^5$，$0 \le edges.length \le 10^5$
- $1 \le weight_i \le 10^5$，且 $from_i \ne to_i$（无自环，但**允许重边**）
- $src1$、$src2$、$dest$ 两两不同

## 2. 示例

**示例 1**

```text
输入：n = 6, edges = [[0,2,2],[0,5,6],[1,0,3],[1,4,5],[2,1,1],[2,3,3],[2,3,4],[3,4,2],[4,5,1]],
      src1 = 0, src2 = 1, dest = 5
输出：9
解释：取 {1→0 (3), 0→5 (6)}：0 直接沿 0→5 到 5，1 先走 1→0 再同一条 0→5 到 5。
      边 0→5 同时服务两条路径但只计一次，总代价 3 + 6 = 9。
```

**示例 2**

```text
输入：n = 3, edges = [[0,1,1],[2,1,1]], src1 = 0, src2 = 1, dest = 2
输出：-1
解释：节点 1 没有任何出边，1 号点永远到不了 2，无解。
```

**示例 3**（自造，突出「$src2$ 借道 $src1$ 的路径」）

```text
输入：n = 3, edges = [[0,1,1],[1,2,1],[0,2,3]], src1 = 0, src2 = 1, dest = 2
输出：2
解释：直接边 0→2 代价 3 反而是陷阱；取 {0→1 (1), 1→2 (1)}，
      0 借道 1 号点、src2=1 本身出发，两条路径共用全部边，总代价 2。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的做法是枚举**边子集**：$2^m$ 个子集，对每个子图做两遍 BFS 检查 $src1$、$src2$ 是否都能到达 $dest$，取最小权。$m \le 10^5$ 时 $2^m$ 直接爆炸。

再往深一层看：这题长得像 **Steiner 树**（在图中找连接一组终端点的最小权子图），一般形式是 NP-hard。但本题只有**两个源点**、方向固定为「都流向 $dest$」——这个结构允许我们把「整体最优子图」拆成「三个单源最短路的拼接」，多项式时间可解。突破点在于：**合法子图 = 两条路径的并**，而两条路径必有公共点。

### 3.2 核心观察：两条路径必有汇合点，枚举它！

![核心观察：汇合点结构与共享边](images/wc284_q4_merge_point_concept.svg)

设子图 $S$ 合法，则 $S$ 中存在路径 $P_1$（$src1 \to dest$）与 $P_2$（$src2 \to dest$）。$P_1$ 与 $P_2$ **至少共享 $dest$**，因此可以描述为：**两路各自走到某个汇合点 $x$，再共用一段 $x \to dest$ 的尾巴**。

于是按 $x$ 拆解代价：

$$F = \min_{x \in [0,\,n)} \big[\, d(src1,\,x) + d(src2,\,x) + d(x,\,dest) \,\big]$$

三个分量恰好都是**单源最短路**：

- $d(src1, x)$：正图上从 $src1$ 跑一次 Dijkstra；
- $d(src2, x)$：正图上从 $src2$ 跑一次 Dijkstra；
- $d(x, dest)$：**把所有边反向**，在反图上从 $dest$ 跑一次 Dijkstra（「每个点到 $dest$」的常规套路）。

> 💡 **为什么不能直接 $d(src1,dest) + d(src2,dest)$？** 因为两条最短路可能共享一段尾巴（示例 1 中两路都爱走 $0 \to 5$），共享段在子图里**只计一次**，简单相加会把共享边算成两次：$6 + 6 = 12 > 9$。而枚举汇合点 $x$ 后，共享尾巴 $d(x,dest)$ 天然只计一次；$x$ 走遍所有点时，「各自独立到达 $dest$」（$x = dest$）与「先汇合再同路」两种形态都被覆盖。
>
> ⚠️ 注意 $x$ **可以是任何点**，包括 $src1$、$src2$ 本身（$src2$ 先走到 $src1$ 再同行，示例 3）或 $dest$（两路完全独立，仅终点重合）。人为限制 $x$ 的范围会漏解。

### 3.3 算法流程：三次 Dijkstra + 一重枚举

![算法流程图](images/wc284_q4_three_dijkstra_flow.svg)

1. **建图**：邻接表建正图 $g$；同时把每条边 $(u, v, w)$ 反向加进 $rg$（$v \to u$），重边照常保留；
2. **三次堆优化 Dijkstra**（边权全为正，Dijkstra 前提成立）：
   - $d_1 \leftarrow$ dist$(g, src1)$
   - $d_2 \leftarrow$ dist$(g, src2)$
   - $d_3 \leftarrow$ dist$(rg, dest)$，此时 $d_3[x]$ 即 $d(x, dest)$；
3. **枚举汇合点**：$ans = \min\{d_1[x] + d_2[x] + d_3[x] : 三段均可达\}$；
4. 三段全不可达（$ans$ 仍为 $INF$）则返回 `-1`。

### 3.4 示例演算

![示例 1 演算：三次最短路逐点求和](images/wc284_q4_walkthrough.svg)

以**示例 1** 走查（$src1=0$，$src2=1$，$dest=5$）：

- $d_1 = [0, 3, 2, 5, 7, 6]$（如 $d_1[4] = 7$：$0 \to 2 \to 3 \to 4$）；
- $d_2 = [3, 0, 5, 8, 5, 6]$（如 $d_2[2] = 5$：$1 \to 0 \to 2$）；
- $d_3 = [6, 6, 6, 3, 1, 0]$（反图上从 5 出发，如 $d_3[3] = 3$：$3 \to 4 \to 5$）；
- 逐点求和：$x=0$ 得 $0+3+6=9$；$x=1$ 得 $3+0+6=9$；$x=5$ 得 $6+6+0=12$（两路独立）；其余更大。

最小值 $9$ ✓，对应两个最优子图：$\{1\to0,\ 0\to5\}$（$x=0$）与 $\{0\to2,\ 2\to1,\ 1\to4,\ 4\to5\}$（$x=1$，即官方蓝色边）。可以看到 **$x=5$（不相交）与 $x=0$（尽早汇合）都被枚举覆盖**，这正是枚举汇合点不失一般性的直观体现。

## 4. 算法细节

1. **反图是第三个 Dijkstra 的关键**：$d(x, dest)$ 是「以 $x$ 为源的入边方向最短路」，直接在正图上从 $dest$ 跑得到的是 $d(dest, x)$，方向完全反了；必须把边全部反向后再从 $dest$ 跑。
2. **邻接表存图**：$n, m \le 10^5$ 且允许重边（示例 1 中 $2 \to 3$ 有权 3 与 4 两条），用 `vector<vector<pair<int,int>>>`，邻接矩阵既爆内存又合并重边。
3. **堆优化 Dijkstra**：`(dist, node)` 入小根堆，弹出时 `if (d > dist[u]) continue;` 做惰性删除，均摊 $O((n+m)\log n)$。
4. **溢出**：一条最短路最长 $(n-1) \cdot 10^5 \approx 10^{10}$，三段和约 $3 \times 10^{10}$，超出 `int32`；C++ 距离数组和返回值用 `long long`，`INF` 取 `LLONG_MAX / 4` 留出加法余量。判断可达要**逐段** `d[x] < INF` 再相加，避免 `INF + INF` 溢出。
5. **可达性判断的顺序无关**：$ans$ 的初值取 $INF$，枚举中只接受三段全可达的 $x$；最后 `ans == INF` 即无解——它一次性覆盖了「$src1$ 不可达」「$src2$ 不可达」「汇合点无法连通 $dest$」三种失败形态。

## 5. 正确性证明

约定：**路径**均指简单路径（点不重复）。任何通路去掉环后仍是端点相同的路径且权不增，故合法子图中的通路总可换成简单路径而不破坏合法性。

**引理 1（下界）**：设 $S$ 为任意合法子图，$P_1 \subseteq S$ 为 $src1 \to dest$ 的简单路径，$P_2 \subseteq S$ 为 $src2 \to dest$ 的简单路径。沿 $P_2$ 自 $src2$ 向 $dest$ 行进，设 $x$ 为**第一个**落在 $P_1$ 上的顶点，$B$ 为 $P_2$ 的 $src2 \to x$ 段。则

$$w(S) \ge d(src1, x) + d(src2, x) + d(x, dest).$$

**证明**：$dest$ 是 $P_1$ 的终点且在 $P_2$ 上，故 $x$ 存在。先证 $B$ 与 $P_1$ **无公共边**：若 $B$ 中有边 $(u, v)$ 同时属于 $P_1$，则 $u$ 是 $P_1$ 的顶点且 $u$ 在 $P_2$ 上严格先于 $x$ 出现，与 $x$ 的「第一个」性矛盾。于是（$P_1 \cup B \subseteq S$，且并集无重叠边时权可加）

$$w(S) \ge w(P_1) + w(B).$$

再把 $P_1$ 在 $x$ 处拆成 $A$（$src1 \to x$ 段）与 $C$（$x \to dest$ 段）——$P_1$ 是简单路径，$A$、$C$ 边不重复，故 $w(P_1) = w(A) + w(C)$。三段 $A$、$B$、$C$ 都是 $S$ 中的简单路径，由最短路的定义：

$$w(S) \ge w(A) + w(B) + w(C) \ge d(src1, x) + d(src2, x) + d(x, dest). \quad \blacksquare$$

**引理 2（上界 / 构造）**：若某个 $x$ 使 $d(src1,x)$、$d(src2,x)$、$d(x,dest)$ 均有限，取对应三条最短路 $P_A$、$P_B$、$P_C$，令 $S_x$ 为三者的边并集。则 $S_x$ 合法，且 $w(S_x) \le d(src1,x) + d(src2,x) + d(x,dest)$。

**证明**：$S_x$ 含路径 $P_A \cdot P_C$（$src1 \to x \to dest$）与 $P_B \cdot P_C$（$src2 \to x \to dest$），故 $src1$、$src2$ 在 $S_x$ 中均可到达 $dest$，合法。并集权不超过各路径权之和——重叠边只被计一次，而边权非负。∎

**定理**：记 $F = \min_x \{d_1(x) + d_2(x) + d_3(x)\}$（无可行 $x$ 时 $F = +\infty$）。则：存在合法子图时最优边权和恰为 $F$；返回 `-1` 当且仅当 $F = +\infty$。

**证明**：若 $F$ 有限：引理 2 给出权 $\le F$ 的合法子图，故最优权 $OPT \le F$；对最优子图 $S^\ast$ 应用引理 1，得 $OPT = w(S^\ast) \ge F$，故 $OPT = F$。若 $F = +\infty$：反设存在合法子图 $S$，由引理 1 存在 $x$ 使三段距离均有限，则 $F$ 有限，矛盾；反之 $F$ 有限时引理 2 已给出合法子图。故「$-1$」与「$F = +\infty$」等价。∎

**推论**（`-1` 的直观刻画）：返回 `-1` 当且仅当 $src1$ **或** $src2$ 到不了 $dest$。

**证明**：若 $src1$ 不可达 $dest$：任一 $x$ 若 $d(src1,x)$、$d(x,dest)$ 均有限，则拼出 $src1 \to dest$ 的路径，矛盾；故每个 $x$ 至少一段为 $\infty$，$F = \infty$。$src2$ 同理。反之若 $src1$、$src2$ 均可达 $dest$，取各自最短路 $P_1$、$P_2$ 的并（合法、权有限），由定理存在性即得 $F$ 有限。∎

## 6. 复杂度分析

- **时间复杂度**：$O\big((n+m)\log n\big)$。三次堆优化 Dijkstra 各 $O\big((n+m)\log n\big)$，枚举汇合点 $O(n)$；$n, m \le 10^5$ 时毫无压力。
- **空间复杂度**：$O(n + m)$。正图、反图两个邻接表共 $2m$ 条边，三个距离数组各 $n$ 个 `long long`，堆中至多 $O(m)$ 个元素。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long minimumWeight(int n, vector<vector<int>>& edges,
                            int src1, int src2, int dest) {
        const long long INF = LLONG_MAX / 4;
        vector<vector<pair<int, int>>> g(n), rg(n);
        for (auto& e : edges) {              // 正图 + 反图，重边照存
            g[e[0]].push_back({e[1], e[2]});
            rg[e[1]].push_back({e[0], e[2]});
        }

        auto dijkstra = [&](vector<vector<pair<int, int>>>& adj, int s) {
            vector<long long> dist(n, INF);
            priority_queue<pair<long long, int>,
                           vector<pair<long long, int>>, greater<>> pq;
            dist[s] = 0;
            pq.push({0, s});
            while (!pq.empty()) {
                auto [d, u] = pq.top(); pq.pop();
                if (d > dist[u]) continue;   // 惰性删除过期条目
                for (auto [v, w] : adj[u])
                    if (dist[v] > d + w) {
                        dist[v] = d + w;
                        pq.push({dist[v], v});
                    }
            }
            return dist;
        };

        auto d1 = dijkstra(g, src1);         // src1 → x
        auto d2 = dijkstra(g, src2);         // src2 → x
        auto d3 = dijkstra(rg, dest);        // 反图上 dest 出发 ⇒ d3[x] = x → dest

        long long ans = INF;
        for (int x = 0; x < n; x++)          // 汇合点枚举遍所有点
            if (d1[x] < INF && d2[x] < INF && d3[x] < INF)
                ans = min(ans, d1[x] + d2[x] + d3[x]);
        return ans == INF ? -1 : ans;
    }
};
```

### Python

```python
import heapq
from typing import List

class Solution:
    def minimumWeight(self, n: int, edges: List[List[int]],
                      src1: int, src2: int, dest: int) -> int:
        g = [[] for _ in range(n)]
        rg = [[] for _ in range(n)]
        for u, v, w in edges:                 # 正图 + 反图，重边照存
            g[u].append((v, w))
            rg[v].append((u, w))

        def dijkstra(adj: List[List[tuple]], s: int) -> List[int]:
            dist = [float('inf')] * n
            dist[s] = 0
            pq = [(0, s)]
            while pq:
                d, u = heapq.heappop(pq)
                if d > dist[u]:               # 惰性删除过期条目
                    continue
                for v, w in adj[u]:
                    if dist[v] > d + w:
                        dist[v] = d + w
                        heapq.heappush(pq, (dist[v], v))
            return dist

        d1 = dijkstra(g, src1)                # src1 → x
        d2 = dijkstra(g, src2)                # src2 → x
        d3 = dijkstra(rg, dest)               # 反图上 dest 出发 ⇒ d3[x] = x → dest

        # 汇合点枚举遍所有点：过滤三段任一不可达的 x
        return min((a + b + c for a, b, c in zip(d1, d2, d3)
                    if a < float('inf') and b < float('inf') and c < float('inf')),
                   default=-1)
```

> 💡 上面 Python 的 `min(..., default=-1)` 一行完成了「过滤不可达 + 取最小 + 无解给 -1」。生成器里对三段逐个判 `inf` 再相加，`float('inf')` 的加法也不会有溢出问题（若模仿 C++ 用大整数 `INF`，则必须先判后加）。

## 8. 边界情况与易错点

1. **溢出是本题头号陷阱**：三段和可达 $3 \times 10^{10}$，C++ 全程 `long long`；`INF` 别取 `LLONG_MAX`（相加会溢出），取 `LLONG_MAX / 4` 并**逐段判可达**后再相加。
2. **反图方向别搞反**：$d_3$ 是「每个点**到** $dest$」，反图上从 $dest$ 跑；在正图上从 $dest$ 跑得到的是 $dest$ 到各点，两码事。
3. **`-1` 的条件是「或」不是「且」**：$src1$、$src2$ **任一**到不了 $dest$ 就无解；写成「两个都到不了才 `-1`」会错放行。
4. **汇合点 $x$ 不要人为收窄范围**：$x \in$ 全体 $[0, n)$，包括 $src1$、$src2$、$dest$ 本身——漏掉 $x = src1$（$src2$ 借道路过 $src1$）这类形态就会 WA，示例 3 正是这种「整条路共享」的解。
5. **重边必须保留**：题面允许 $u \to v$ 多条边（示例 1 的 $2 \to 3$ 有权 3 与 4），邻接表天然支持；用「去重 / 邻接矩阵」存图会丢边。
6. **`m = 0` 空边表**：三点互异必然不可达，直接 `-1`，Dijkstra 空跑后三段全 `INF`，逻辑自洽无需特判。
7. **Dijkstra 惰性删除别忘**：弹出 `d > dist[u]` 的过期条目要 `continue`，否则可能用旧距离松弛，复杂度也会劣化。
8. **正权是 Dijkstra 的前提**：本题 $weight \ge 1$ 恒成立；若题目变体出现负权，需换 Bellman-Ford / SPFA。
