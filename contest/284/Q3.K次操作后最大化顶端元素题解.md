# LeetCode K 次操作后最大化顶端元素 题解

## 1. 题目概述

- **标题 / 题号**：K 次操作后最大化顶端元素（#2202，medium）
- **链接**：https://leetcode.cn/problems/maximize-the-topmost-element-after-k-moves/
- **来源**：LeetCode 第 284 场周赛 Q3
- **难度**：中等
- **标签**：贪心、数组、分类讨论、计数

**题意**：`nums` 表示一个堆（`nums[0]` 为堆顶），每次操作二选一：**删除**堆顶（若堆非空）；或从**已删除元素**中任取一个**推回**堆顶（若已删集合非空）。给定操作总数 `k`，求**恰好** `k` 次操作后堆顶元素的**最大值**；若堆一定为空，返回 `-1`。

**约束**：

- `1 <= nums.length <= 10^5`
- `0 <= nums[i], k <= 10^9`

> ⚠️ 本题在本仓库另有[每日题解 2202](../../solution/2201-2300/2202_K次操作后最大化顶端元素.md)。经暴力对拍验证，每日版「$k > n+1$ 且 $k-n$ 为偶 ⇒ 答案只能是 $\max(nums[0..n-2])$」这一分支**有误**：它假设空转步数只能靠周期为 2 的「推-删对」消磨，漏掉了**推回不要求堆为空、可以连续推回叠多层**这一操作语义（反例 `nums=[1,3], k=6`，正确答案 3，每日版代码返回 1）。本篇按修正后的分类展开，全部结论已通过 BFS 对拍与穷举验证。

## 2. 示例

**示例 1**

```text
输入：nums = [5,2,2,4,0,6], k = 4
输出：5
解释：删 5 → 删 2 → 删 2 → 推回 5，堆变为 [5,4,0,6]，堆顶 5。
```

**示例 2**

```text
输入：nums = [2], k = 1
输出：-1
解释：唯一的选择是弹出堆顶 2，堆为空。
```

**示例 3**（自造，$k = n$ 时间隙恰好落在最后一个下标上）

```text
输入：nums = [7,9], k = 2
输出：7
解释：第 1 步只能删 7 → [9]；第 2 步删 9（堆空）或推回 7 → [7,9]。
     堆顶只能是 7——最大值 9 恰好落在间隙 k−1 = 1 上，取不到。
```

**示例 4**（自造，$k \ge n+1$ 且 $k - n$ 为偶，最大值在末尾）

```text
输入：nums = [1,3], k = 6
输出：3
解释：删 1 → 删 3 → 推 1 → 删 1 → 推 1（垫层） → 推 3，堆为 [3,1]，堆顶 3。
     连续两次推回把奇数空转步「垫」掉了——这正是每日版漏掉的情形。
```

## 3. 解题思路

### 3.1 暴力思路

从初始堆出发 BFS 枚举所有 $k$ 步操作序列：每步分支为 $1 + |\text{已删集合}|$，状态空间指数膨胀；更致命的是 $k \le 10^9$，即使每步 $O(1)$ 决策也远超时限。

瓶颈在于「过程太长、分支太多」。突破口：**不模拟过程，直接刻画哪些 `nums[i]` 有资格成为最终堆顶**，把 $O(k)$ 的过程问题压缩成 $O(n)$ 的集合判定。

### 3.2 核心观察：终态刻画——堆顶只能是前 min(k, n−1) 个位置（挖掉 k−1）中某一个

![核心观察：堆 = 推回叠放区 + 原数组连续后缀](images/wc284_q3_pile_structure.svg)

**观察 1（结构不变量）**：任何时刻，堆自上而下 = 「若干已推回元素叠成的**叠放区**」+「原数组的**连续后缀** $nums[j..n-1]$」。删除永远拿走顶层（叠放区空则后缀头前移），推回永远压在最高处。**推回不要求堆为空**，所以叠放区可以有多层。

**观察 2（双计数）**：设整个过程后缀被删推进 $j$ 格、推回共 $Q$ 次、再删叠放区元素共 $R$ 次，则 $k = j + Q + R$。看最终堆顶来自哪里：

- **来自后缀**（叠放区空）：每次推回的元素最终都被再删 ⇒ $R = Q$ ⇒ $k - j = 2Q$ 为**偶数**；
- **来自叠放区**：$nums[i]$ 必须先被删过一次（要先删掉 $nums[0..i]$ 才能「释放」它）⇒ $j \ge i+1$，且它被推回 ⇒ $Q \ge 1$ ⇒ $k \ge i + 2$。

**观察 3（合并）**：堆顶为 $nums[i]$ 需要——后缀型：$i \le k$ 且 $k-i$ 为偶；叠放型：$i \le k-2$。两者取并，恰好覆盖 $i \in [0, \min(k, n-1)]$ **除了 $k-1$**：$i = k$ 由后缀型覆盖（$k-i=0$），$i \le k-2$ 由叠放型覆盖，唯独 $i = k-1$ 两头都差一步——这就是本题著名的「**k−1 间隙**」。

![可达索引集合：挖掉 k−1](images/wc284_q3_reachable_indices.svg)

> 💡 一句话：候选集 = 前 $\min(k+1, n)$ 个位置挖掉第 $k-1$ 个，答案就是候选集的 $\max$；唯一需要单独处理的是 $n=1$（操作被强制交替，看 $k$ 的奇偶）。

### 3.3 算法流程：三个小特判 + 一个通用式

![算法流程图](images/wc284_q3_decision_flow.svg)

1. $k = 0$：堆没动过，返回 `nums[0]`；
2. $n = 1$：操作被迫「删、推、删、推……」交替，$k$ 为奇返回 `-1`，为偶返回 `nums[0]`；
3. $k = 1$（$n \ge 2$）：第 1 步只能删，堆顶变 `nums[1]`；
4. 否则（$k \ge 2$）：`best = max(nums[0 .. min(k-2, n-1)])`；若 $k < n$，再和 `nums[k]` 取 $\max$。

注意第 4 步的上界要 **clamp 到 $n$**：$k$ 可达 $10^9$，而 $k \ge n+1$ 时整个数组都可达（间隙 $k-1$ 已越界），上式自动退化为 $\max(nums)$。

### 3.4 示例演算

![示例演算：候选集取 max 与垫层构造](images/wc284_q3_walkthrough.svg)

以**示例 1** `nums = [5,2,2,4,0,6], k = 4`（$2 \le k \le n-1$）走查：

- $i \le k-2 = 2$：`nums[0..2] = {5,2,2}` 可达（叠放型）；
- $i = k-1 = 3$：`nums[3] = 4` 间隙，不可达；
- $i = k = 4$：`nums[4] = 0` 可达（恰好删 4 个）；
- $i = 5 > k$：够不着。

候选 $= \{5,2,2,0\}$，答案 $5$ ✓。

再看**示例 4** `nums = [1,3], k = 6`（$k \ge n+1$，$k-n = 4$ 为偶）：删光两个后剩 4 步，其中「推 1、删 1」对消 2 步、垫推 1 步、最后推回 3——**连续两次推回叠出两层**，堆顶 3。若以为空转只能两两对消，就会错判成只能取 1（每日版即栽在这里）。

## 4. 算法细节

1. **切片 / 循环上界 clamp**：C++ 中 `i < k-1` 必须写成 `i < min(k-1, n)`，否则 $k \gg n$ 时越界；Python 的 `nums[:k-1]` 会自动截断到整个数组，这恰好与「$k \ge n+1$ 时全数组可达」的正确结论吻合，但**不要依赖这种巧合**，显式 clamp 才能表达意图。
2. **奇偶吸收**：叠放型构造里删 $i+1$ 个后余量 $k-i-2$ 若为奇，**垫删 1 个**即可变偶（$i \le n-2$ 保证删得出）；$i = n-1$ 且 $k \ge n+1$ 时垫删不可用（已到数组底），改用**垫推一层**吸收奇数步（引理 4(c)）。
3. **$k = n$ 的特殊性**：间隙 $k-1 = n-1$ 恰好落在最后一个下标上，候选只剩前 $n-1$ 个——示例 3。
4. **$-1$ 的判定只看 $n = 1$**：$n \ge 2$ 时任何 $k$ 都存在非空终态（引理 3 给出显式构造），无需在通用分支里考虑 `-1`。
5. **$k \le 10^9 < 2^{31}-1$**：`int` 不溢出；但 $k-2$ 在 $k \in \{0,1\}$ 时为负，三个特判全部前置即可避免负界循环/负下标切片。

## 5. 正确性证明

**引理 1**（结构不变量）：任意时刻，堆 = 若干已推回元素按被推回顺序叠成的叠放区 + 连续后缀 $nums[j..n-1]$（$0 \le j \le n$），且 $j$ 单调不减。

**证明**：对操作次数归纳。初始 $j=0$、叠放区空。删除作用于顶层：叠放区非空则弹叠放区（$j$ 不变），否则删后缀头（$j$ 加一）；推回把元素压入叠放区顶层（$j$ 不变）。归纳保持。∎

**引理 2**（可达必要条件）：$k \ge 1$ 时，若恰 $k$ 步后堆顶为 $nums[i]$，则 $i \le k$ 且 $i \ne k-1$。

**证明**：由引理 1 分两种情形（记推回 $Q$ 次、再删 $R$ 次、后缀推进 $j$ 格，$k = j + Q + R$）。

- **堆顶为后缀头** $nums[j]$：叠放区空 ⇒ 每次推回的元素最终都被再删 ⇒ $R = Q$ ⇒ $k - j = 2Q$ 为偶且 $j \le k$。若 $i = j = k-1$，则 $k - i = 1$ 为奇，矛盾。
- **堆顶为叠放区顶** $nums[i]$：$nums[i]$ 曾位于后缀头且被删（否则不可能进入已删集合、更不可能被推回），而 $j$ 单调不减 ⇒ 最终 $j \ge i+1$；又 $nums[i]$ 至少被推回一次 ⇒ $Q \ge 1$。于是 $k = j + Q + R \ge (i+1) + 1 = i+2$。若 $i = k-1$，则 $k \ge k+1$，矛盾。∎

**引理 3**（$-1$ 刻画）：恰 $k$ 步后堆必空 $\iff$ $n = 1$ 且 $k$ 为奇数。

**证明**：$n=1$ 时堆中唯一元素 $x$，初始已删集空 ⇒ 第 1 步只能删；此后任意时刻「堆非空 $\iff$ 已删集空」（$x$ 只可能在两处之一），操作被强制为删、推、删、推……严格交替，第 $t$ 步后堆非空 $\iff t$ 为偶，$k$ 奇则空。反之 $n \ge 2, k \ge 1$：若 $k \le n-1$，连删 $k$ 次堆顶为 $nums[k]$；若 $k \ge n$，删 $n-1$ 次后堆顶 $nums[n-1]$，剩 $k-n+1 \ge 1$ 步全用「推 $y$、删 $y$」对消（偶数步），奇数步则先垫推一次再对消，堆始终非空。∎

**引理 4**（可达充分性）：$k \ge 2, n \ge 2$ 时，每个满足 $0 \le i \le \min(k, n-1)$ 且 $i \ne k-1$ 的 $i$ 都可成为最终堆顶。

**证明**（显式构造）：

- (a) $i = k$（此时 $k \le n-1$）：连删 $k$ 次，堆顶 $nums[k]$，恰好用尽；
- (b) $i \le \min(k-2,\, n-2)$：连删 $i+1$ 个，余量 $m = k-i-2 \ge 0$；$m$ 为奇则垫删 1 个（$i+2 \le n$ 删得出）使余量变偶，推回 $nums[i]$，剩余偶数步全部「推 $y$、删 $y$」对消（已删集非空恒可取 $y$）；
- (c) $i = n-1$ 且 $k \ge n+1$：删光 $n$ 个，余量 $m = k-n \ge 1$；$m$ 奇：对消 $m-1$ 步后推回 $nums[n-1]$；$m$ 偶（$\ge 2$）：对消 $m-2$ 步、垫推任意已删元素 1 步、再推回 $nums[n-1]$（连续两次推回、叠放两层）。

覆盖检查：$2 \le k \le n-1$ 时目标集 $[0,k] \setminus \{k-1\}$ 由 (a)(b) 覆盖；$k = n$ 时 $[0, n-2]$ 由 (b) 覆盖（$\min(k-2, n-2) = n-2$）；$k \ge n+1$ 时 $[0, n-1]$ 由 (b)(c) 覆盖（此时 $k-1 \ge n$ 已越界，无间隙）。∎

**定理**：$k \ge 2$ 时答案为 $\max\{\,nums[i] : 0 \le i \le \min(k, n-1),\ i \ne k-1\,\}$；$k = 0$ 时为 $nums[0]$；$n \ge 2, k = 1$ 时为 $nums[1]$；返回 $-1$ 当且仅当 $n = 1$ 且 $k$ 为奇数。实现上等价于 $\max(nums[0..\min(k-2,\,n-1)] \cup \{nums[k] : k < n\})$。

**证明**：候选上界由引理 2 给出（$k = 1$ 时引理 2 给 $i \in \{1\}$，构造即「删一次」）；界内每个值可由引理 4 达到；$-1$ 情形由引理 3 完全刻画。两条通用实现式与集合刻画逐一对应：$nums[0..\min(k-2, n-1)]$ 即 $i \le \min(k, n-1) \wedge i \le k-2$，$nums[k]$（$k < n$）即后缀型仅有的 $i = k$ 项。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。三个特判 $O(1)$；通用分支只扫数组前 $\min(k-1, n) \le n$ 个元素并做一次 $O(1)$ 的 `nums[k]` 比较，与 $k$ 的大小无关——这正是把 $O(k)$ 过程模拟压缩为 $O(n)$ 终态判定的收益（$k = 10^9$ 时也只做 $\le 10^5$ 次比较）。
- **空间复杂度**：$O(1)$。仅常数个变量（Python 的切片拷贝至多 $n$ 个元素，可用 `max(nums[i] for i in range(...))` 规避为 $O(1)$）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maximumTop(vector<int>& nums, int k) {
        int n = nums.size();
        if (k == 0) return nums[0];
        if (n == 1) return (k % 2 == 0) ? nums[0] : -1;
        if (k == 1) return nums[1];

        int best = -1;
        for (int i = 0; i < min(k - 1, n); i++)   // nums[0 .. min(k-2, n-1)]
            best = max(best, nums[i]);
        if (k < n) best = max(best, nums[k]);     // 恰好删 k 个露头的那个
        return best;
    }
};
```

### Python

```python
class Solution:
    def maximumTop(self, nums: List[int], k: int) -> int:
        n = len(nums)
        if k == 0:
            return nums[0]
        if n == 1:
            return nums[0] if k % 2 == 0 else -1
        if k == 1:
            return nums[1]

        best = max(nums[:min(k - 1, n)])   # nums[0 .. min(k-2, n-1)]
        if k < n:
            best = max(best, nums[k])
        return best
```

> 💡 写完这类分类讨论题，建议花 3 分钟做一个**小数据对拍**：用 BFS 枚举全部操作序列求真值（$n \le 4$、$k \le 8$、值域 $\{0,1,2\}$ 穷举即可），与公式逐例比对。本篇的引理 2/4 与上面两份代码正是通过了 3000 组随机 + 全量穷举对拍——顺带揪出了每日版的 $k-n$ 偶数分支 bug。

## 8. 边界情况与易错点

1. **三个特判的顺序**：$k=0$、$n=1$、$k=1$ 必须在通用式之前，否则 $k-2$ 为负、`nums[1]` 越界、$n=1$ 的奇偶强制交替全部失控。
2. **别假设「推回要求堆为空」**：题面明说推回只是「添加回堆顶」，堆非空照推不误，可连续叠多层。漏掉这一点就会把空转步数错误地限制成偶数，在「$k \ge n+1$ 且 $k-n$ 为偶、最大值在末尾」时 WA——每日题解 2202 的实错（反例 `[1,3], k=6` 应输出 3 而非 1）。
3. **上界 clamp 到 $n$**：C++ 循环 `i < k-1` 在 $k \gg n$ 时直接越界；Python 切片虽自动截断且恰好正确，也建议显式写 `min(k-1, n)` 表达意图。
4. **$k = n$ 时取不到末尾元素**：间隙 $k-1$ 恰好压在下标 $n-1$ 上，候选只有前 $n-1$ 个（示例 3 的 `[7,9], k=2` → 7）。
5. **$-1$ 只属于 $n=1$ 且 $k$ 奇**：$n \ge 2$ 时永远存在非空终态（引理 3 的显式构造），不要在通用分支里再判空。
6. **间隙规则不覆盖 $n=1$**：「挖掉 $k-1$」的统一规则对 $k = 0$（挖掉 $-1$，即不挖）和 $k=1$（挖掉 $0$）都自然成立，唯独 $n=1$ 且 $k$ 奇时会错误地给出 $nums[0]$——这是必须特判 $n=1$ 的本质原因。
7. **溢出**：$k \le 10^9$ 在 `int32` 内，无溢出；但 $k - 2$、$k - n$ 一类表达式要在特判之后使用，避免负值参与无符号/切片语义。
