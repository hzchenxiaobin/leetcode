# LeetCode 分割回文串 IV 题解

## 1. 题目概述

- **标题 / 题号**：分割回文串 IV（#1745，hard）
- **链接**：https://leetcode.cn/problems/palindrome-partitioning-iv/
- **来源**：LeetCode 第 226 场周赛 Q4
- **难度**：困难
- **标签**：字符串、动态规划、区间预处理

**题意**：给定字符串 `s`，判断能否恰好切**两刀**，把它分成**三个非空**子串，且每段都是**回文串**。能分割返回 `true`，否则返回 `false`。

**约束**：

- $3 \le s.\text{length} \le 2000$
- `s` 只包含小写英文字母

> 💡 **一句话建模**：段数固定为 3 ⇒ 合法划分由「两刀的位置」唯一决定，方案总数只有 $O(n^2)$ 组。问题 = 枚举切点组合 + 快速判定三段是否回文，而「子串是否回文」是会被重复查询 $O(n^2)$ 次的同一类信息 → **先建回文表，再 $O(1)$ 查询**。

## 2. 示例

**示例 1**

```text
输入：s = "abcbdd"
输出：true
解释："abcbdd" = "a" + "bcb" + "dd"，三个子字符串都是回文的。
```

**示例 2**

```text
输入：s = "bcbddxy"
输出：false
解释：s 没办法被分割成 3 个回文子字符串。
```

**示例 3（边界）**

```text
输入：s = "abc"
输出：true
解释：任何长度为 3 的字符串都能切成 3 个单字符，单字符必为回文。
```

## 3. 解题思路

### 3.1 暴力思路

长度为 $n$ 的字符串有 $n-1$ 个间隙，任选其中 2 个作为切点，共 $\binom{n-1}{2} = O(n^2)$ 种方案。对每种方案，逐段用双指针判定回文，最坏各花 $O(n)$，总计 $O(n^3)$。$n = 2000$ 时约 $4 \times 10^9$ 次字符比较，必然超时。

> ⚠️ 瓶颈剖析：所有判定对象都是 `s` 的子串，本质是同一份「回文性」信息被反复重算——**子串 $s[i..j]$ 是否回文**这一询问会被不同切点方案问到 $O(n^2)$ 次，每次却都花 $O(n)$ 从头扫。

### 3.2 核心观察：回文表预处理 + 双重枚举切点

![核心观察：两刀切三段，回文判定交给O(1)查表](images/wc226_q4_two_cuts_concept.svg)

两刀 $(i, j)$ 把 `s` 切成三段，各自独立判定：

| 段 | 区间 | 判定条件 |
|----|------|----------|
| 第一段 | $s[0..i]$ | `isPal[0][i]` |
| 第二段 | $s[i+1..j]$ | `isPal[i+1][j]` |
| 第三段 | $s[j+1..n-1]$ | `isPal[j+1][n-1]` |

其中 `isPal[i][j]` 表示子串 $s[i..j]$ 是否为回文串，用**区间 DP** 一次性预处理：

$$
isPal[i][j] = (s[i] = s[j]) \land \bigl(j - i < 2 \ \lor\ isPal[i+1][j-1]\bigr)
$$

- $j - i < 2$ 覆盖长度 1（单字符）与长度 2（两端即全部）的 base case；
- 长度 $\ge 3$ 时：两端相等 **且** 去掉两端后仍是回文。

> 💡 **关键洞察**：把「重复 $O(n^2)$ 次的 $O(n)$ 判定」压成「一次 $O(n^2)$ 建表 + 每次 $O(1)$ 查表」，总复杂度从 $O(n^3)$ 降到 $O(n^2)$。这与 131/132/1278 一脉相承，是回文 DP 家族的「**表先行**」范式。

### 3.3 算法流程：建表 → 枚举两刀 → 三段查表

![算法流程：Phase 1 建回文表，Phase 2 枚举切点并查表](images/wc226_q4_palindrome_table_flow.svg)

1. **Phase 1 建表**：`i` 从 $n-1$ 递减、`j` 从 $i$ 递增填 `isPal`（等价于按子串长度递增），保证查 `isPal[i+1][j-1]` 时该格已填好。
2. **Phase 2 枚举**：外层枚举第一刀 $i \in [0, n-3]$，先查 `isPal[0][i]`，非回文直接 `continue`（**剪枝**）；回文则内层枚举第二刀 $j \in [i+1, n-2]$。
3. **命中短路**：某组 $(i,j)$ 使三段全回文，立即 `return true`；全部枚举完无命中则 `return false`。

### 3.4 示例演算

![示例演算：abcbdd 命中 (i,j)=(0,3)，bcbddxy 无解](images/wc226_q4_walkthrough.svg)

以 `s = "abcbdd"`（$n=6$）为例，$i \in [0, 3]$，$j \in [i+1, 4]$：

| $i$ | $j$ | 第一段 $s[0..i]$ | 第二段 $s[i+1..j]$ | 第三段 $s[j+1..5]$ | 结果 |
|-----|-----|------------------|---------------------|---------------------|------|
| 0 | 1 | `"a"` ✓ | `"b"` ✓ | `"cbdd"` ✗ | false |
| 0 | 2 | `"a"` ✓ | `"bc"` ✗ | — | false |
| **0** | **3** | **`"a"` ✓** | **`"bcb"` ✓** | **`"dd"` ✓** | **true ⭐** |
| 1 | — | `"ab"` ✗ | 第一段剪枝，内层全跳过 | — | ✗ |
| 2 | — | `"abc"` ✗ | 第一段剪枝 | — | ✗ |
| 3 | — | `"abcb"` ✗ | 第一段剪枝 | — | ✗ |

- $(i, j) = (0, 3)$ 命中即**短路返回** true，$i \ge 1$ 各行列出仅为展示剪枝效果——第一段非回文时内层循环一次都不进。
- 反例 `s = "bcbddxy"`：回文**前缀**只有 `"b"`（$i=0$）和 `"bcb"`（$i=2$），回文**后缀**只有 `"y"`（$j=5$）。若 $i=0$ 则中段 `s[1..5] = "cbddx"` 非回文；若 $i=2$ 则中段 `"ddx"` 非回文——所有组合失败，返回 `false`。

## 4. 算法细节

1. **填表顺序**：`isPal[i][j]`（长度 $L$）依赖 `isPal[i+1][j-1]`（长度 $L-2$），必须先填短再填长。代码里 `i` 从 $n-1$ 递减、`j` 从 $i$ 递增：行 $i+1$ 整行先于行 $i$ 填完，因此 $j$ 的内层顺序其实无关紧要，自然安全。
2. **base case 靠短路**：递推中 `j - i < 2` 先于 `isPal[i+1][j-1]` 判断，`j == i` 时不会访问越界的 `j-1 = i-1` 格。
3. **枚举范围的推导**：三段非空 ⟺ $i \ge 0$（自动满足）、$j \ge i+1$（第二段非空）、$j \le n-2$（第三段非空）；第一段非空还要求第一刀后仍剩两个字符，即 $i \le n-3$。合起来 $i \in [0, n-3]$，$j \in [i+1, n-2]$。
4. **剪枝与短路**：外层 `isPal[0][i]` 为 false 直接跳过整个内层——最坏情形（无解）也只退化回完整 $O(n^2)$ 枚举，不损正确性；命中即返回，通常远早于最坏。
5. **存储选择**：`vector<vector<char>>` / `bytearray` 布尔表，$2000^2 = 4 \times 10^6$ 字节 ≈ 4MB，完全可接受；用 `int` 表 16MB 也能过但无必要。
6. **为什么不上「最小分割」DP**：132 题的 $f[i]$（前缀最少刀数）解决的是**段数不固定**的最优化；本题段数恰好为 3，双重枚举切点更直接，套 DP 反而多写一层状态、易错。

## 5. 正确性证明

**引理 1（回文表正确性）**：按 §3.2 递推填表后，`isPal[i][j]` 为真当且仅当 $s[i..j]$ 是回文串。

**证明**：对长度 $L = j - i + 1$ 强归纳。$L = 1$：$j - i = 0 < 2$ 短路，`isPal[i][i] = (s[i]==s[i])` 为真，单字符是回文。$L = 2$：`isPal[i][j] = (s[i]==s[j])`，两端相等 ⟺ 该两字符串回文。$L \ge 3$：由回文定义，$s[i..j]$ 回文 ⟺ $s[i] = s[j]$ 且 $s[i+1..j-1]$ 回文（回文条件 $s[i+k] = s[j-k]$ 对 $k=0$ 即首尾、对 $1 \le k \le L-2$ 即内部子串的回文条件）。递推式恰好编码此等价，且 `isPal[i+1][j-1]` 长度 $L-2 < L$，由填表顺序保证已填好，归纳成立。∎

**引理 2（切点与三段划分一一对应）**：三段非空的划分 $\{s[0..i],\ s[i+1..j],\ s[j+1..n-1]\}$ 与满足 $0 \le i \le n-3$、$i+1 \le j \le n-2$ 的切点对 $(i, j)$ 构成双射。

**证明**：划分由两刀位置唯一决定，反之每组范围内的 $(i,j)$ 给出的三段长度分别为 $i+1 \ge 1$、$j - i \ge 1$、$n - 1 - j \ge 1$，均非空；两条互逆的映射显式给出。∎

**定理（算法正确性）**：算法返回 `true` 当且仅当 `s` 可分割成三个非空回文子串。

**证明**：（⇐ 完备性）设存在合法划分，由引理 2 其切点 $(i^*, j^*)$ 落在枚举范围内；由引理 1，三段对应的查表均为真。枚举按 $i$ 递增、$j$ 递增的顺序完整覆盖该范围，剪枝只跳过第一段非回文的 $i$（这些 $i$ 不属于任何解），故 $(i^*, j^*)$ 必被访问，算法返回 `true`。（⇒ 正确性）算法返回 `true` 时，命中的 $(i, j)$ 使三次查表全真，由引理 1 三段皆回文，由枚举范围三段皆非空，构成合法划分。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n^2)$。Phase 1 填表 $\frac{n(n+1)}{2}$ 项，每项 $O(1)$；Phase 2 至多 $\binom{n-1}{2}$ 组切点，每组 $O(1)$ 查表（剪枝与短路只会更少）。$n = 2000$ 时合计约 $4 \times 10^6$ 步，毫秒级。
- **空间复杂度**：$O(n^2)$。回文表占 $n^2$ 格（`char` 版约 4MB）；其余变量 $O(1)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool checkPartitioning(string s) {
        int n = s.size();
        // Phase 1: 预处理回文表（等价于按长度递增填表）
        vector<vector<char>> isPal(n, vector<char>(n, 0));
        for (int i = n - 1; i >= 0; --i) {
            for (int j = i; j < n; ++j) {
                isPal[i][j] = (s[i] == s[j]) &&
                              (j - i < 2 || isPal[i + 1][j - 1]);
            }
        }
        // Phase 2: 枚举两刀 (i, j)
        // 第一段 s[0..i]，第二段 s[i+1..j]，第三段 s[j+1..n-1]
        for (int i = 0; i <= n - 3; ++i) {
            if (!isPal[0][i]) continue;          // 第一段非回文，剪枝
            for (int j = i + 1; j <= n - 2; ++j) {
                if (isPal[i + 1][j] && isPal[j + 1][n - 1]) {
                    return true;                 // 三段皆回文
                }
            }
        }
        return false;
    }
};
```

### Python

```python
class Solution:
    def checkPartitioning(self, s: str) -> bool:
        n = len(s)
        # Phase 1: 预处理回文表
        isPal = [[False] * n for _ in range(n)]
        for i in range(n - 1, -1, -1):
            for j in range(i, n):
                isPal[i][j] = (s[i] == s[j]) and \
                              (j - i < 2 or isPal[i + 1][j - 1])
        # Phase 2: 枚举两刀 (i, j)
        for i in range(n - 2):                   # i ∈ [0, n-3]
            if not isPal[0][i]:
                continue                         # 第一段非回文，剪枝
            for j in range(i + 1, n - 1):        # j ∈ [i+1, n-2]
                if isPal[i + 1][j] and isPal[j + 1][n - 1]:
                    return True
        return False
```

> 💡 C++ 的 `i <= n - 3` 与 Python 的 `range(n - 2)`（上界不含）等价：$n = 3$ 时都只让 $i = 0$、$j = 1$ 这一组通过，三个单字符必回文，返回 `true`。

## 8. 边界情况与易错点

1. **n = 3**：唯一切点组 $(0, 1)$，答案恒 `true`。C++ 若把外层误写成 `i < n - 3`，$n=3$ 时循环体一次不执行，错返 `false`——必须是 `<=`。
2. **空段陷阱**：`j` 上界是 $n-2$ 而非 $n-1$（第三段非空），下界是 $i+1$（第二段非空）；`j` 取到 $n-1$ 会让第三段为空，直接越界访问 `isPal[j+1][n-1] = isPal[n][n-1]`。
3. **填表顺序写反**：若 `i` 递增填表，计算 `isPal[i][j]` 时 `isPal[i+1][j-1]` 尚未初始化（读到 0），全表几乎恒 false——这是本模板最常见的一发 WA。
4. **递推短路防越界**：`j - i < 2` 必须写在 `isPal[i+1][j-1]` 之前（短路求值），否则 `j == i` 时访问负下标。
5. **表内存**：$n=2000$ 的二维表用 `char`/`bool` 约 4MB；Python 的 `[[False]*n for _ in range(n)]` 约 4×10⁶ 元素，注意别写成 `[[False]*n]*n`（行共享引用）。
6. **不要滥用 DP**：段数恰为 3 时枚举两刀最直接；套 132 的「最少分割」DP 属于杀鸡用牛刀，多一层状态反而引入新错误面。
7. **剪枝不影响最坏复杂度**：外层 `continue` 只砍掉第一段非回文的分支，无解输入仍走满 $O(n^2)$，复杂度分析按最坏计。
