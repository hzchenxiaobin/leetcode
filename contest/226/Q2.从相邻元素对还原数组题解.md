# LeetCode 从相邻元素对还原数组 题解

## 1. 题目概述

- **标题 / 题号**：从相邻元素对还原数组（#1743，medium）
- **链接**：https://leetcode.cn/problems/restore-the-array-from-adjacent-pairs/
- **来源**：LeetCode 第 226 场周赛 Q2
- **难度**：中等
- **标签**：数组、哈希表、深度优先搜索

**题意**：存在一个由 $n$ 个**互不相同**的整数组成的数组 `nums`，但你已经记不清内容，只记得其中每一对**相邻元素**。给定大小为 $n-1$ 的二维数组 `adjacentPairs`，每个 `adjacentPairs[i] = [ui, vi]` 表示 `ui` 与 `vi` 在 `nums` 中相邻；这些对**顺序任意、方向任意**（`[a,b]` 与 `[b,a]` 等价）。返回**任意一个**满足全部相邻关系的原始数组。

**约束**：

- $\text{nums.length} = n$，$\text{adjacentPairs.length} = n - 1$，$\text{adjacentPairs}[i].\text{length} = 2$
- $2 \le n \le 10^5$
- $-10^5 \le \text{nums}[i],\ u_i,\ v_i \le 10^5$
- 题目数据保证存在一些以 `adjacentPairs` 作为元素对的数组 `nums`

> 💡 **一句话建模**：$n$ 个互异元素、$n-1$ 对相邻关系 → 把每对看作**无向边**，整张图恰好是一条**链**（path）。本题就是「找端点 + 沿链走」。

## 2. 示例

**示例 1**

```text
输入：adjacentPairs = [[2,1],[3,4],[3,2]]
输出：[1,2,3,4]
解释：数组的所有相邻元素对都在 adjacentPairs 中。
特别注意 [2,1] 只表示 2 与 1 相邻，并不保证左-右顺序。
```

**示例 2**

```text
输入：adjacentPairs = [[4,-2],[1,4],[-3,1]]
输出：[-2,4,1,-3]
解释：数组中可能存在负数；[-3,1,4,-2] 也是合法答案。
```

**示例 3**

```text
输入：adjacentPairs = [[100000,-100000]]
输出：[100000,-100000]
```

## 3. 解题思路

### 3.1 暴力思路

最朴素的做法是枚举所有出现元素的全排列并逐一验证相邻关系，复杂度 $O(n \cdot n!)$，$n \le 10^5$ 下完全不可行。退一步，即便想到「选一个元素当起点、不断向右拼接」，若不利用结构信息，每次拼接都要在 $n-1$ 对中线性扫描匹配，还可能因选错方向而回溯，最坏 $O(n^2)$ 且实现繁琐。事实上，「在一般图上找哈密顿路径」是 NP-Hard 的——本题能线性解决，全靠相邻对背后隐藏的**链结构**。

### 3.2 核心观察：n−1 条无向边拼成一条链，端点度数为 1

![核心观察：相邻对构成无向链，端点度数=1](images/wc226_q2_adjacency_chain_concept.svg)

把每个 `adjacentPairs[i] = [u, v]` 视为一条**无向边**，所有元素构成一张图。由于原数组是线性排列，每个元素至多与左右两个元素相邻：

| 元素位置 | 度数（出现的相邻对数） | 说明 |
|----------|----------------------|------|
| 数组**端点**（下标 $0$ 或 $n-1$） | $1$ | 只有一侧有邻居 |
| 数组**内部** | $2$ | 左右各一个 |

> 💡 **关键洞察**：元素互异 + 恰好 $n-1$ 对相邻关系 ⇒ 图**连通**且度数分布为 $1, 2, \dots, 2, 1$，即一条**链**。只要找到任一度数为 1 的节点作起点，沿链一步步走到底，就能还原整个数组（得到原数组或其逆序，均合法）。

### 3.3 算法流程：建邻接表 → 找端点 → prev/curr 沿链迭代

![算法流程：建图、找端点、哨兵prev沿链迭代](images/wc226_q2_restore_array_flow.svg)

1. **建邻接表**：哈希表 `adj`，对每对 `[u, v]` 双向加边（`adj[u]` 加 `v`，`adj[v]` 加 `u`），与输入顺序和方向无关。
2. **找端点**：扫描 `adj`，找到只有 1 个邻居的元素 `s`（链恰有两个端点，找到任意一个即可）。
3. **沿链迭代**：`prev` 初始化为**哨兵**（一个永不出现在值域的数，Python 用 `None`、C++ 用 `INT_MIN`），`curr = s`；循环 $n$ 次——把 `curr` 追加进答案，然后在 `adj[curr]` 中挑出 $\ne prev$ 的邻居作为下一节点。
4. **返回**长度为 $n$ 的答案数组。

> ⚠️ 用 `prev` 记住「来路」后，内部节点的两个邻居中恰有一个等于 `prev`，另一个就是**唯一去向**——全程**无需 visited 集合**。起点的唯一邻居天然 $\ne$ 哨兵、末端挑不到新邻居不再前进，这两种边界都被同一句「找 $\ne prev$ 的邻居」统一覆盖。

### 3.4 示例演算

![示例演算：建表、找端点、沿链走查](images/wc226_q2_example_walkthrough.svg)

**示例 1**：`adjacentPairs = [[2,1],[3,4],[3,2]]`，建图后的邻接表：

| 元素 | 邻居 | 度数 |
|------|------|------|
| 1 | [2] | 1 ← 端点 |
| 2 | [1, 3] | 2 |
| 3 | [4, 2] | 2 |
| 4 | [3] | 1 ← 端点 |

- **找端点**：`1` 度数为 1，作为起点 `s`；`prev = 哨兵`，`curr = 2`。
- **走链**：追加 `1` → `2` 的邻居 `{1,3}` 排除 `prev=1` 得 `next=3`，追加 `2` → `3` 的邻居 `{4,2}` 排除 `prev=2` 得 `next=4`，追加 `3` → `4` 只剩邻居 `{3}=prev`，追加 `4` 后停止。
- **答案**：`[1, 2, 3, 4]` ✓

**示例 2**：`adjacentPairs = [[4,-2],[1,4],[-3,1]]` 建出链 `−2 — 4 — 1 — −3`，从 `−2` 出发得 `[-2,4,1,-3]`，从 `−3` 出发得逆序 `[-3,1,4,-2]`，两者都正确。

## 4. 算法细节

1. **邻接表容器**：元素值含负数且实际只有 $n$ 个（值域 $[-10^5, 10^5]$ 共 $2\times10^5+1$ 个槽位），`unordered_map<int, vector<int>>` / `defaultdict(list)` 最省心；追求常数可用「值 $+10^5$」偏移后的定长数组。
2. **找端点**：链恰有两个度 1 节点，扫描到第一个即 `break`；从哪个出发都行——答案只差一个 reverse。
3. **哨兵 prev**：值域是 $[-10^5, 10^5]$，任何域外值都可作为初始 `prev`，让「起点的唯一邻居 $\ne prev$」天然成立，省去对起点的特判。
4. **为什么迭代而不是递归 DFS**：链长可达 $10^5$，递归深度同步达到 $10^5$，Python 默认递归上限 1000 直接溢出，C++ 也有栈溢出风险；迭代版只多用 `prev/curr` 两个变量。
5. **为什么不用 visited**：一般图 DFS 需要 visited 是因为一个节点可能有多个未访问邻居、方向不唯一；链上每个节点的邻居至多 2 个，「刚来的路」`prev` 唯一标识，剩余邻居（若有）就是唯一去向。这是利用链结构特性的关键优化。

## 5. 正确性证明

**引理 1（度数分布）**：图恰有两个度数为 1 的节点（数组的两个端点元素），其余 $n-2$ 个节点度数均为 2。

**证明**：元素互异，故每个元素对应图中唯一节点。数组下标 $0$ 与 $n-1$ 的元素各只出现在一对相邻关系 $(a_0,a_1)$、$(a_{n-2},a_{n-1})$ 中，度数为 1；下标 $1 \le i \le n-2$ 的元素出现在 $(a_{i-1},a_i)$ 与 $(a_i,a_{i+1})$ 两对中，度数为 2。题设保证 `adjacentPairs` 恰由这 $n-1$ 对构成（顺序、方向任意不影响无向边集合），故度数分布如上。$n \ge 2$ 时两个端点元素存在且互异。∎

**引理 2（连通性）**：图连通。

**证明**：对任意 $0 \le i < n-1$，$(a_i, a_{i+1})$ 是一条边，于是 $a_0 - a_1 - \cdots - a_{n-1}$ 本身就是一条经过全部节点的路径，任意两节点沿此路径可达。∎

**推论（图是链）**：连通且所有节点度数 $\le 2$、存在度数为 1 的节点，则图是一条简单路径（若所有度数均为 2 则为环，此处被度 1 节点排除）。∎

**引理 3（合法答案即链的走向）**：任何满足全部相邻对的数组，必是链 $v_0 - v_1 - \cdots - v_{n-1}$ 的两个走向 $[v_0,\dots,v_{n-1}]$ 或 $[v_{n-1},\dots,v_0]$ 之一。

**证明**：满足条件的数组构成图中一条哈密顿路径。在链上，哈密顿路径只能从某节点出发沿链不回头地走：链无分支，每步去向唯一，任何「回头」都会立即访问重复节点，违反哈密顿路径每点恰访问一次的性质。故哈密顿路径恰为从某一端点走到另一端点的序列，只有两个方向。∎

**定理（算法正确性）**：算法输出的是合法答案。

**证明**：记链为 $v_0 - \cdots - v_{n-1}$，不妨设算法选中的端点 $s = v_0$（另一情形对称）。归纳断言：第 $i$ 轮循环开始时 $curr = v_i$ 且 $prev = v_{i-1}$（$i = 0$ 时 $prev$ 为哨兵，而 $v_0$ 的唯一邻居 $v_1 \ne$ 哨兵）。当 $i \le n-2$ 时 $v_i$ 的邻居集为 $\{v_{i-1}, v_{i+1}\}$，内层扫描挑出 $\ne prev$ 的唯一邻居 $v_{i+1}$，断言对 $i+1$ 成立；$i = n-1$ 时 $v_{n-1}$ 的唯一邻居等于 $prev$，无邻居可挑，`curr` 不再更新。因此 $n$ 轮循环依次追加 $v_0, v_1, \dots, v_{n-1}$，由引理 3 这是合法答案。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。建邻接表处理 $n-1$ 对、写入 $2(n-1)$ 条记录；找端点至多扫 $n$ 个键；沿链迭代 $n$ 轮，每轮内层扫描至多 2 个邻居，均为常数开销。
- **空间复杂度**：$O(n)$。邻接表存 $n$ 个键、$2(n-1)$ 条邻居记录，另加输出数组 $O(n)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> restoreArray(vector<vector<int>>& adjacentPairs) {
        int n = adjacentPairs.size() + 1;
        unordered_map<int, vector<int>> adj;
        for (auto& p : adjacentPairs) {
            adj[p[0]].push_back(p[1]);
            adj[p[1]].push_back(p[0]);
        }

        int start = 0;
        for (auto& [val, nb] : adj) {
            if (nb.size() == 1) {
                start = val;
                break;
            }
        }

        vector<int> ans;
        ans.reserve(n);
        int prev = INT_MIN;
        int curr = start;
        for (int i = 0; i < n; ++i) {
            ans.push_back(curr);
            for (int nb : adj[curr]) {
                if (nb != prev) {
                    prev = curr;
                    curr = nb;
                    break;
                }
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def restoreArray(self, adjacentPairs: List[List[int]]) -> List[int]:
        adj = collections.defaultdict(list)
        for u, v in adjacentPairs:
            adj[u].append(v)
            adj[v].append(u)

        start = next(x for x, nb in adj.items() if len(nb) == 1)

        n = len(adjacentPairs) + 1
        ans = []
        prev, curr = None, start
        for _ in range(n):
            ans.append(curr)
            for nb in adj[curr]:
                if nb != prev:
                    prev, curr = curr, nb
                    break
        return ans
```

## 8. 边界情况与易错点

1. **n = 2（只有一对）**：两个元素都是端点，输出任一顺序均可；上述写法无特判自然正确。
2. **负数**：不能拿元素值直接做数组下标；哈希表天然支持，或用 $+10^5$ 偏移映射。
3. **答案不唯一**：从两个端点出发分别得到原序与逆序；哈希表遍历顺序不确定导致起点可能不同，**评测按任意合法解判定**，本地调试时不要与固定输出逐位比对。
4. **「取第二个邻居」越界**：若写成每轮「追加 `curr` 后立刻从 `adj[curr]` 里按下标取 $\ne prev$ 的邻居（如 `nb[0] == prev ? nb[1] : nb[0]` 或解包 `a, b = adj[curr]`）」，最后一轮 `curr` 已是末端节点、邻居表只有 1 个元素，取下标 1 / 解包两个值会**越界**。哨兵 + 内层 `break` 扫描的写法把末端「挑不到邻居」自然吞掉，规避该坑。
5. **递归爆栈**：链长 $10^5$ 时 DFS 递归深度同阶，Python 默认上限 1000；务必迭代。
6. **建图方向**：`[u,v]` 与 `[v,u]` 等价，双向加边即可，与输入对的顺序无关。
7. **C++ 细节**：找到度 1 节点立即 `break`；`ans.reserve(n)` 预分配避免反复扩容。
