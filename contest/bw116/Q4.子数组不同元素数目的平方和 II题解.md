# LeetCode 子数组不同元素数目的平方和 II 题解

## 1. 题目概述

- **标题 / 题号**：子数组不同元素数目的平方和 II（#2916，hard）
- **链接**：https://leetcode.cn/problems/subarrays-distinct-element-sum-of-squares-ii/
- **来源**：LeetCode 第 116 场双周赛 Q4
- **难度**：困难
- **标签**：树状数组、线段树、数组、哈希表

**题意**：定义子数组 `nums[i..j]` 的**不同计数** $d(i,j)$ 为其中互不相同值的个数。求所有子数组的 $d(i,j)^2$ 之和，对 $10^9 + 7$ 取模返回。

**约束**：

- $1 \le \texttt{nums.length} \le 10^5$
- $1 \le \texttt{nums}[i] \le 10^5$

## 2. 示例

**示例 1**

```text
输入：nums = [1,2,1]
输出：15
解释：六个子数组的不同计数为 1,1,1,2,2,2，平方和 = 3×1 + 3×4 = 15。
```

**示例 2**

```text
输入：nums = [2,2]
输出：3
解释：三个子数组的不同计数均为 1，平方和 = 3。
```

## 3. 解题思路

### 3.1 暴力思路

同场 Q1（#2913）的 $O(n^2)$ 做法：固定右端、左端左移、set 维护不同数。$n = 10^5$ 时 $10^{10}$ 次操作，超时 4 个数量级。必须把「逐子数组求 $d^2$」改造成「**增量递推** + **区间数据结构**」。

### 3.2 核心观察一：按右端点分行，平方和的增量公式

把总和按**右端点**分组：

$$\texttt{ans} = \sum_{i=0}^{n-1} S_i, \qquad S_i = \sum_{l=0}^{i} d(l, i)^2$$

右端从 $i-1$ 扩到 $i$（新元素 $x = \texttt{nums}[i]$，其上次出现为 $j = \texttt{last}[x]$，不存在记 $-1$）时，哪些 $d(l,i)$ 相比 $d(l, i-1)$ 变化？

- $l \in (j, i]$：$x$ 在 `nums[l..i]` 中**首次**出现，$d(l, i) = d(l, i-1) + 1$（$l = i$ 时 $d(i,i) = 1$，与 $d(i, i-1)$ 无关，单独看待也可统一为「从 0 起 +1」）；
- $l \le j$：$x$ 已在 `nums[l..i-1]` 里，$d$ 不变。

对变化的 $l$，$(d+1)^2 - d^2 = 2d + 1$，于是

$$S_i = S_{i-1} + \sum_{l=j+1}^{i} \bigl(2\,d(l, i-1) + 1\bigr) = S_{i-1} + 2\underbrace{\sum_{l=j+1}^{i-1} d(l,i-1)}_{T} + (i - j)$$

（$T$ 为区间 $(j, i)$ 上**旧 $d$ 值之和**；$l=i$ 项贡献 $2\cdot0+1 = 1$，与 $l\in(j,i)$ 的各 $+1$ 合计 $i-j$。）**只要能快速查询「某段左端区间上 $d$ 的和」，就能 $O(1)$ 递推出 $S_i$**。而区间上 $d(l,i-1) \to d(l,i)$ 的批量 +1 恰是一次**区间加**——需要支持**区间加 + 区间求和**的数据结构。

### 3.3 核心观察二：双树状数组实现区间加、区间和

![D 数组与增量公式](images/bw116_q4_D_array.svg)

维护数组 $D[l] = d(l, i)$（当前右端 $i$ 下的整行不同计数）。每步：

1. **查询** $T = \sum_{l=j+1}^{i} D[l]$（查询必须在更新前做，拿到的是旧值 $d(\cdot, i-1)$，其中 $D[i]$ 尚为 0）；
2. **递推** $S_i = S_{i-1} + 2T + (i-j)$，累加进答案；
3. **区间加**：$D[l] \mathrel{+}= 1$ 对 $l \in (j, i]$。

区间加/区间和用**两棵 BIT**（$b_1$ 维护差分，$b_2$ 维护差分加权 $i$）实现，单次 $O(\log n)$；也可用带懒标记线段树。总体 $O(n \log n)$。

### 3.4 换个视角：贡献法（$d^2$ = 有序对计数）

![贡献法：平方拆成有序对](images/bw116_q4_pair_contribution.svg)

$$d(l,r)^2 = \bigl|\{(p,q) :\ l \le p \le r,\ l \le q \le r,\ \max(\texttt{prev}[p], \texttt{prev}[q]) < l\}\bigr|$$

其中 $\texttt{prev}[p]$ 为 $p$ 的前一次出现下标（无则 $-\infty$）。直观地说：位置对 $(p, q)$（含 $p=q$，**有序**）被子数组 $[l, r]$ 计数，当且仅当 $l \le p, q \le r$ 且 $l$ 大于两者的前次出现——即 $p, q$ 处的值在 $[l,r]$ 内都「以本次出现为准」。对固定的有序对，合法 $l$ 有 $p - \max(\texttt{prev}[p], \texttt{prev}[q])$ 种、合法 $r$ 有 $n - q$ 种（设 $p \le q$；$p=q$ 时对角项为 $(p - \texttt{prev}[p])(n-p)$）。两种求和次序——静态双循环（$O(n^2)$，用于对拍验证）与按右端递推（$O(n \log n)$，正解）——数的是同一批有序对，这是理解本题最坚固的抓手。

### 3.5 算法流程

```text
1. last ← 空哈希表（值 → 上次下标）
2. b1, b2 ← 双 BIT（1 基）；S ← 0；ans ← 0；D 全 0（隐式）
3. for i = 0..n−1:
       x ← nums[i]；j ← last.get(x, −1)
       T ← 区间和 D[j+1 .. i]（1 基即 [j+2, i+1]）
       S ← S + 2T + (i − j)
       ans ← (ans + S) mod p
       区间加：D[j+1 .. i] 全体 +1
       last[x] ← i
4. 返回 ans
```

### 3.6 示例演算

![示例 1 走查](images/bw116_q4_walkthrough.svg)

**示例 1**（`nums = [1,2,1]`）：

| i | x | j | T = D[j+1..i] | ΔS = 2T+(i−j) | S | D（更新后） | ans |
|---|---|---|----------------|----------------|---|--------------|-----|
| 0 | 1 | −1 | D[0..0] = 0 | 2·0+1 = 1 | 1 | [1, 0, 0] | 1 |
| 1 | 2 | −1 | D[0..1] = 1+0 = 1 | 2·1+1 = 3 | 4 | [2, 1, 0] | 5 |
| 2 | 1 | 0 | D[1..2] = 1+0 = 1 | 2·1+2 = 4 | 9 | [2, 2, 1] | 15 |

注意第 3 步：$j=0$ 意味着左端 $l = 0$ 的 $d$ 不变（1 重复出现），只有 $l \in \{1, 2\}$ 的 $d$ 加 1。最终 `ans = 15` ✓。同表也给出各步行内校验：$S_2 = 1 + 4 + 4 = 9$ 恰为右端 2 的三个子数组 $[1]、[2,1]、[1,2,1]$ 的平方和。

## 4. 算法细节

1. **下标体系**：`last` 存 0 基下标；BIT 用 1 基，0 基区间 $[j+1, i]$ 对应 1 基 $[j+2, i+1]$。当 $j = -1$ 时区间为 $[1, i+1]$，自然覆盖全部左端。**先查询后更新**：查询时 $D[i]$（新左端）尚为 0，公式中的 $T$ 只含旧 $d$ 值，与推导一致。
2. **双 BIT 的区间加/区间和**：区间 $[l, r]$ 加 $v$：`b1.add(l, v); b1.add(r+1, −v); b2.add(l, v(l−1)); b2.add(r+1, −v·r)`；前缀和 $\texttt{sum}(x) = \texttt{query}(b_1, x) \cdot x - \texttt{query}(b_2, x)$；区间和 = $\texttt{sum}(r) - \texttt{sum}(l-1)$。也可替换为懒标记线段树，等价。
3. **$S$ 的维护两种写法**：(a) $S$ 用 `long long` 精确维护（上界见 §8.6 的估算，$\approx 3\times10^{14} < 2^{63}$），每步 `ans += S` 后取模；(b) $S$ 本身在模意义下递推（$2T$ 与 $i-j$ 都取模后累加）。两种都对，**不能混**（精确 $S$ 配模意义 $T$ 会把「减法出负」的坑放大）。本文代码用 (b)（全程模意义），推导用精确值便于理解。
4. **`last` 用数组还是哈希**：值域 $10^5$，直接 `vector<int> last(100001, -1)` 数组最快；哈希表也可。
5. **答案取模时机**：`ans` 每步加 $S$ 后立即 `% MOD`；BIT 内部差分值可能很大（前缀 $2T \cdot r$ 量级），C++ 全程 `long long` 且每步取模。
6. **为何不用「每步重算 $S_i$」**：$S_i$ 需要整行 $d$ 的平方和，$O(n)$ 重算是 $O(n^2)$ 的另一形态；增量公式的意义正是把「平方」降为「一次」的查询。

## 5. 正确性证明

**引理 1（增量公式）**：设 $j$ 为 $\texttt{nums}[i]$ 的前一次出现（无则 $j = -1$）。则 $d(l, i) = d(l, i-1) + 1$ 对 $l \in (j, i]$ 成立（约定 $d(i, i-1) = 0$），$d(l, i) = d(l, i-1)$ 对 $0 \le l \le j$ 成立。

**证明**：子数组 `nums[l..i]` 的值集合 = `nums[l..i-1]` 的值集合 $\cup \{x\}$。若 $l \le j$，则 $x = \texttt{nums}[j]$ 已含于 `nums[l..i-1]`（$l \le j \le i-1$），集合不变，$d$ 不变。若 $j < l \le i$：当 $l \le i-1$ 时 $x$ 不在 `nums[l..i-1]`（其出现都不落在 $[l, i-1]$——上一次在 $j < l$，下一次就是 $i$），集合恰多一个 $x$，$d$ 加 1；当 $l = i$ 时 $d(i,i) = 1 = 0 + 1$，与约定一致。∎

**引理 2（行递推）**：$S_i = \sum_{l=0}^{i} d(l,i)^2$ 满足 $S_i = S_{i-1} + 2\sum_{l=j+1}^{i-1} d(l, i-1) + (i - j)$。

**证明**：拆分 $S_i$ 中变化与不变的左端：

$$S_i - S_{i-1} = \sum_{l=j+1}^{i} \bigl(d(l,i)^2 - d(l,i-1)^2\bigr) = \sum_{l=j+1}^{i} \bigl((d(l,i-1)+1)^2 - d(l,i-1)^2\bigr) = \sum_{l=j+1}^{i} (2\,d(l,i-1) + 1)$$

（$l \le j$ 的项差为 0，已消去；$l = i$ 项用约定 $d(i,i-1)=0$。）后一个和式 $= 2\sum_{l=j+1}^{i-1} d(l,i-1) + 2\cdot 0 + (i - j)$，其中 $i - j$ 是区间 $(j, i]$ 的长度，含 $l=i$ 的那个 $1$。∎

**定理**：算法返回 $\sum_{i} S_i \bmod (10^9+7) = \sum_{0 \le l \le r < n} d(l, r)^2 \bmod (10^9+7)$。

**证明**：对 $i$ 归纳：算法中数组 $D$ 在第 $i$ 轮更新后等于 $(d(l, i))_{l=0}^{i}$（由引理 1，查询得的 $T$ 为旧值 $\sum_{l=j+1}^{i-1} d(l,i-1)$，随后区间加实现引理 1 的增量）；$S$ 由引理 2 递推等于 $S_i$。答案逐项累加 $S_i$，而 $\sum_i S_i$ 恰把每个子数组按右端归组求和，即所求总和。所有运算模 $10^9 + 7$ 封闭。∎

**补充（贡献法一致性）**：$\sum_{l \le r} d(l,r)^2 = \sum_{(p,q)\ \text{有序}} \#\{[l,r] : l \le p, q \le r,\ l > \max(\texttt{prev}[p], \texttt{prev}[q])\}$，因为 $d(l,r)^2 = \left(\sum_{p} [p \in [l,r], \texttt{prev}[p] < l]\right)^2$ 展开即为有序对求和。两条路线（增量 / 贡献）互为验证，本文对拍即据此实现。

## 6. 复杂度分析

- **时间**：$O(n \log n)$。每步一次区间查询（两次前缀和，各 $O(\log n)$）与一次区间加（4 次单点改，各 $O(\log n)$），共 $n$ 步。$n = 10^5$ 时约 $10^5 \times 34$ 次 BIT 操作，C++ 实测 12 ms、Python 约 1 s。
- **空间**：$O(n + U)$。两棵 BIT 各 $n+2$；`last` 表 $O(U)$（$U$ 为值域，可用哈希压到 $O(\min(n, U))$）。

## 7. 参考代码

### C++

```cpp
class Solution {
    static constexpr long long MOD = 1'000'000'007LL;
    int n;
    vector<long long> b1, b2;                       // 双 BIT：区间加 + 区间和

    void bitAdd(vector<long long>& b, int i, long long v) {
        for (; i <= n; i += i & -i) b[i] = (b[i] + v) % MOD;
    }
    long long bitSum(const vector<long long>& b, int i) {   // 前缀和 [1..i]
        long long s = 0;
        for (; i > 0; i -= i & -i) s += b[i];
        return s;
    }
    void rangeAdd(int l, int r, long long v) {      // [l, r]（1 基）整体 +v
        bitAdd(b1, l, v);        bitAdd(b1, r + 1, -v);
        bitAdd(b2, l, v * (l - 1)); bitAdd(b2, r + 1, -v * r);
    }
    long long rangeSum(int l, int r) {              // [l, r]（1 基）区间和
        return (bitSum(b1, r) * r - bitSum(b2, r))
             - (bitSum(b1, l - 1) * (l - 1) - bitSum(b2, l - 1));
    }
public:
    int sumCounts(vector<int>& nums) {
        n = (int)nums.size();
        b1.assign(n + 2, 0);
        b2.assign(n + 2, 0);
        unordered_map<int, int> last;               // 值 → 上次出现（0 基）
        long long S = 0, ans = 0;                   // S = Σ_{l≤i} d(l,i)²（模意义）
        for (int i = 0; i < n; ++i) {
            auto it = last.find(nums[i]);
            int j = (it == last.end()) ? -1 : it->second;
            long long T = rangeSum(j + 2, i + 1);   // 0 基 [j+1, i] → 1 基 [j+2, i+1]
            S = (S + 2 * T + (i - j)) % MOD;
            ans = (ans + S) % MOD;
            rangeAdd(j + 2, i + 1, 1);
            last[nums[i]] = i;
        }
        return (int)ans;
    }
};
```

### Python

```python
class Solution:
    def sumCounts(self, nums: list[int]) -> int:
        MOD = 10 ** 9 + 7
        n = len(nums)
        b1 = [0] * (n + 2)               # 双 BIT：区间加 + 区间和
        b2 = [0] * (n + 2)

        def add(b, i, v):
            while i <= n + 1:
                b[i] = (b[i] + v) % MOD
                i += i & -i

        def psum(b, i):
            s = 0
            while i > 0:
                s += b[i]
                i -= i & -i
            return s

        def range_add(l, r, v):          # [l, r] 1 基
            add(b1, l, v); add(b1, r + 1, -v)
            add(b2, l, v * (l - 1)); add(b2, r + 1, -v * r)

        def range_sum(l, r):
            return (psum(b1, r) * r - psum(b2, r)) \
                 - (psum(b1, l - 1) * (l - 1) - psum(b2, l - 1))

        last = {}                        # 值 → 上次出现（0 基）
        S = 0                            # S = Σ_{l≤i} d(l,i)²（模意义）
        ans = 0
        for i, x in enumerate(nums):
            j = last.get(x, -1)
            T = range_sum(j + 2, i + 1)  # 0 基 [j+1, i] → 1 基 [j+2, i+1]
            S = (S + 2 * T + (i - j)) % MOD
            ans = (ans + S) % MOD
            range_add(j + 2, i + 1, 1)
            last[x] = i
        return ans
```

> 💡 两份代码均通过官方示例（`15`、`3`），并与两种独立实现三方对拍：$O(n^2)$ 逐子数组枚举、$O(n^2)$ 有序对贡献公式，共 1000 组随机数据，`mismatch = 0`；C++ 在 $n = 10^5$（随机值域 $10^5$ / 全同值 / 小值域三种）下 5–12 ms，Python 约 1 s。

## 8. 边界情况与易错点

1. **先查询后更新**：$T$ 必须取**旧** $d$ 值（区间加之前的），否则增量公式失效。顺序颠倒是最隐蔽的 bug。
2. **$l = i$ 的项**：新左端的 $d(i,i) = 1$，公式中由「$2 \cdot 0 + 1$」并入 $i - j$（区间长度）。若在 $T$ 里误把 $D[i]$ 更新后再查，会把该项算成 $2\cdot1+1$。
3. **下标换算差一**：0 基 $[j+1, i]$ ↔ 1 基 $[j+2, i+1]$；$j = -1$ 时是 $[1, i+1]$。BIT 大小开 $n+2$ 防 $r+1 = n+2$ 越界（本实现 `bitAdd` 上界用 `<= n`，数组开 $n+2$ 已含缓冲，改用 `<= n+1` 时同样安全）。
4. **减法取模**：区间加的 `−v`、区间和的两次相减都可能出负；C++ 各处 `+ MOD` 或全程用 `long long` 后统一取模，Python 负索引取模虽非负但乘法后数值会膨胀，建议每步 `% MOD`。
5. **全同值数组**：每步 $j = i-1$，区间只有单点 $l=i$，$\Delta S = 1$，$S_i = i+1$，答案 $\sum (i+1) = n(n+1)/2 \bmod p$——快速自检用例。
6. **溢出估算**：精确 $S$ 上界 $\max_i \sum_{l \le i} d(l,i)^2 \le \sum_{k=1}^{n} k^2 \approx n^3/3 \approx 3.3\times 10^{14}$（$n = 10^5$），`long long` 装得下但**逼近** $2^{63}$ 的十万分之一，安全；若 $n$ 再大 10 倍必须全程模意义。
7. **别忘取模**：与 I 版（#2913）不同，本题必须 `% (10^9+7)`；两题函数同名 `sumCounts`，提交时留意选对版本。
8. **线段树替代**：带懒标记线段树同样 $O(n\log n)$，常数略大；双 BIT 代码短、缓存友好，是首选。
