# LeetCode 子数组不同元素数目的平方和 I 题解

## 1. 题目概述

- **标题 / 题号**：子数组不同元素数目的平方和 I（#2913，easy）
- **链接**：https://leetcode.cn/problems/subarrays-distinct-element-sum-of-squares-i/
- **来源**：LeetCode 第 116 场双周赛 Q1
- **难度**：简单
- **标签**：数组、哈希表、暴力枚举

**题意**：定义子数组 `nums[i..j]` 的**不同计数**为其中互不相同值的个数。求 `nums` **所有子数组**的不同计数的**平方和**。

**约束**：

- $1 \le \texttt{nums.length} \le 100$
- $1 \le \texttt{nums}[i] \le 100$

## 2. 示例

**示例 1**

```text
输入：nums = [1,2,1]
输出：15
解释：六个子数组 [1] [2] [1] [1,2] [2,1] [1,2,1] 的
不同计数分别为 1,1,1,2,2,2，平方和 = 3×1 + 3×4 = 15。
```

**示例 2**

```text
输入：nums = [2,2]
输出：3
解释：[2] [2] [2,2] 的不同计数都是 1，平方和 = 3。
```

**示例 3（边界补充）**

```text
输入：nums = [1,2,3,4]
输出：50
解释：4 个单元素（各 1）+ 3 个长 2（各 4）+ 2 个长 3（各 9）+ 1 个长 4（16）
= 4 + 12 + 18 + 16 = 50（元素互异时长度 k 的子数组有 n−k+1 个，不同计数都是 k）。
```

## 3. 解题思路

### 3.1 暴力思路：固定右端、向左扩张，set 动态维护

本题数据范围把「暴力」扶正：$n \le 100$，子数组共 $\frac{n(n+1)}{2} \le 5050$ 个，每个用 $O(1)$ 均摊更新哈希集合即可。

```text
1. ans ← 0
2. for j = 0..n−1:                # 右端
       st ← 空集合
       for i = j..0:              # 左端从 j 向左扩
           st.insert(nums[i])     # 新元素进入
           ans += |st|²           # [i, j] 的不同计数²
3. 返回 ans
```

内层循环里**左端每左移一位只新增一个元素**，`set` 增删 $O(1)$ 均摊，`size` $O(1)$，总量约 $10^5$ 级别操作。

### 3.2 核心观察：增量维护避免每个子数组重扫

![子数组三角与右端点视角](images/bw116_q1_subarray_grid.svg)

关键在于**换枚举次序**：不是「对每个子数组 $[i, j]$ 各自从头数不同值」（那是 $O(n^3)$），而是**固定右端 $j$、左端从 $j$ 向 0 移动**。往集合里加入 `nums[i]` 后集合内容恰好是 `nums[i..j]` 的值集合——因为子数组是**连续**的，左端收缩时前面的元素一直在场。于是每个子数组的 `|set|` 都是均摊 $O(1)$ 得到，总体 $O(n^2)$。

### 3.3 算法流程

同 §3.1 伪代码。要点只有两个：外层右端、内层左端向左；插入后立即累加平方。

### 3.4 示例演算

![示例 1 走查三角](images/bw116_q1_walkthrough.svg)

**示例 1**（`nums = [1,2,1]`）：

| j | 依次扩展 i=2→0 | 各步 \|st\| | 本行贡献 |
|---|----------------|------------|----------|
| 0 | [1] | 1 | 1 |
| 1 | [2]→[1,2] | 1, 2 | 1 + 4 |
| 2 | [1]→[2,1]→[1,2,1] | 1, 2, 2 | 1 + 4 + 4 |

总计 $1 + 5 + 9 = 15$ ✓。注意 $j=2$ 时左端扫到 `nums[0]=1`，集合里已有 1（来自 `nums[2]`），`size` 保持 2——重复值的去重由 set 自动完成。

## 4. 算法细节

1. **枚举方向**：必须「右端固定、左端左移」才能增量维护（新进来的是 `nums[i]`，其余不变）。若「左端固定、右端右移」同样可行（对称地，集合里加入 `nums[j]`），两种写法等价，别在同一次循环里混用。
2. **平方用整数乘法**：$|st| \le n \le 100$，平方 $\le 10^4$，总和 $\le 5050 \times 10^4 \approx 5\times 10^7$，`int` 装得下，但 C++ 仍建议 `long long` 习惯性防身（本题 I 不取模，II 取模）。
3. **每个 j 重建 set**：外层循环开始时清空集合，千万别复用上一次的（元素会串味）。
4. **值域只有 1..100**：可以用 `bool seen[101]` 数组代替哈希 set，配合计数器 `distinct`，常数更小——插入时 `if (!seen[x]) { seen[x]=true; ++distinct; }`。
5. **不取模**：本题返回精确值（与 II 的差异之一），最终直接返回累加和。

## 5. 正确性证明

**引理 1（集合内容）**：内层循环处理到左端 $i$ 时，集合恰为 $\{\texttt{nums}[i], \texttt{nums}[i+1], \dots, \texttt{nums}[j]\}$，即子数组 `nums[i..j]` 的值集合。

**证明**：对固定的 $j$，内层从 $i = j$ 开始：初始集合为空，先插入 `nums[j]`，集合为 $\{\texttt{nums}[j]\}$，成立。归纳：设左端为 $i+1$ 时集合为 `nums[i+1..j]` 的值集合；左移到 $i$ 时插入 `nums[i]`，集合变为旧集合 $\cup \{\texttt{nums}[i]\} = $ `nums[i..j]` 的值集合。∎

**定理**：算法返回 $\sum_{0 \le i \le j < n} d(i, j)^2$，其中 $d(i,j)$ 为子数组 `nums[i..j]` 的不同计数。

**证明**：二重循环枚举了每一对 $i \le j$ 各恰一次，覆盖全部子数组且不重不漏。由引理 1，每步的 $|st| = d(i, j)$，累加项为 $d(i,j)^2$；求和交换律下总和即所求。∎

## 6. 复杂度分析

- **时间**：$O(n^2)$。共 $\frac{n(n+1)}{2}$ 个子数组，每个 $O(1)$ 均摊（哈希插入）或 $O(1)$ 严格（数组版 seen）。$n = 100$ 时约 5050 步。
- **空间**：$O(U)$，$U$ 为值域（$\le 100$）。集合任意时刻至多存 $n$ 个值，即 $O(\min(n, U))$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int sumCounts(vector<int>& nums) {
        int n = (int)nums.size();
        long long ans = 0;
        for (int j = 0; j < n; ++j) {           // 右端固定
            unordered_set<int> st;               // 每个 j 重建
            for (int i = j; i >= 0; --i) {       // 左端向左扩
                st.insert(nums[i]);
                long long d = (long long)st.size();
                ans += d * d;                    // [i, j] 的不同计数²
            }
        }
        return (int)ans;
    }
};
```

### Python

```python
class Solution:
    def sumCounts(self, nums: list[int]) -> int:
        n = len(nums)
        ans = 0
        for j in range(n):                       # 右端固定
            st = set()                           # 每个 j 重建
            for i in range(j, -1, -1):           # 左端向左扩
                st.add(nums[i])
                ans += len(st) ** 2              # [i, j] 的不同计数²
        return ans
```

> 💡 两份代码均通过官方示例（`15`、`3`）并另测 `[1,2,3,4] → 50`、全相同元素等用例；另与「逐子数组重扫 set」的 $O(n^3)$ 参照实现对拍随机数据一致。

## 8. 边界情况与易错点

1. **$n = 1$**：唯一子数组，返回 1。
2. **重复元素跨子数组**：`[1,2,1]` 的 $[1,2,1]$ 不同计数是 2 不是 3——set 去重正确处理；若手写计数器忘记判 `seen` 会算成 3。
3. **别把「子数组」当「子序列」**：本题只统计连续段；若误用子序列（$2^n$ 个）既超时也不符合定义。
4. **溢出评估**：上界 $5050 \times 10^4 \approx 5\times 10^7$，`int` 安全；但同场 Q4（II 版）$n = 10^5$ 需取模，别把两题的返回约定搞混——I 返回精确值。
5. **外层/内层次序写反**：写成「左端固定、右端右移 + 集合不重建」依然正确（对称方向增量），但若两个方向混着写（例如右端固定却向右扩集合），集合内容与当前子数组不再对应，会得到错误答案——改方向前想清楚集合里该装谁。
