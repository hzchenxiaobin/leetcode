# LeetCode 使二进制字符串变美丽的最少修改次数 题解

## 1. 题目概述

- **标题 / 题号**：使二进制字符串变美丽的最少修改次数（#2914，medium）
- **链接**：https://leetcode.cn/problems/minimum-number-of-changes-to-make-binary-string-beautiful/
- **来源**：LeetCode 第 116 场双周赛 Q2
- **难度**：中等
- **标签**：字符串、贪心

**题意**：二进制字符串 $s$（长度为偶数）称为**美丽的**，当且仅当它能被分割成一个或多个子串，每个子串长度为**偶数**且**只含一种字符**（全 0 或全 1）。每次修改可把任一字符改成 0 或 1，求让 $s$ 变美丽的最少修改次数。

**约束**：

- $2 \le s.\texttt{length} \le 10^5$
- $s$ 的长度为偶数
- $s[i]$ 为 `'0'` 或 `'1'`

## 2. 示例

**示例 1**

```text
输入：s = "1001"
输出：2
解释：改 s[1]→1、s[3]→0 得 "1100" = "11|00"，2 次修改。
```

**示例 2**

```text
输入：s = "10"
输出：1
解释：改 s[1]→1 得 "11"。
```

**示例 3**

```text
输入：s = "0000"
输出：0
解释：本身美丽（"0000" 或 "00|00" 均可）。
```

## 3. 解题思路

### 3.1 暴力思路

枚举分割方案：在偶数位置切或不切（$2^{n/2-1}$ 种），对每种分割把每块统一成较多数的字符并统计修改数，取最小——指数级。也可以做 $O(n^2)$ DP：$f[i]$ 表示前 $i$ 个字符变美丽的最少修改，$f[i] = \min_{j} f[j] + \text{cost}(j+1, i)$（$j$ 与 $i$ 同奇偶），$n = 10^5$ 时 $O(n^2)$ 会超。需要更强的结构观察。

### 3.2 核心观察：划分可以统一看成定长 2 的块

![配对观察](images/bw116_q2_pairing.svg)

**两条观察**把任意划分「标准化」：

1. **块长总是偶数 → 块总能对半切**：长度 $2k$ 的同色块切成两个长度 $k$ 的同色块，仍是合法划分。递归切下去，任何合法划分都 refine 成**长度为 2** 的块划分。
2. **定长 2 划分是「最细」的合法划分**：$s$ 美丽 ⇔ 按 $(s_0s_1)(s_2s_3)\dots(s_{n-2}s_{n-1})$ 分块后**每块两个字符相同**。一方面，若每对都相同，这本身就是合法划分（$n/2$ 个长 2 同色块）；另一方面，若 $s$ 美丽，任何合法划分的块边界都落在偶数位置（块长为偶数且从 0 起），于是每个长 2 对要么整个落进某块（同色），要么恰是某块的一部分（同色）——两种情况对内字符都相同。

于是问题变为：**把每一对 $(s_{2i}, s_{2i+1})$ 变成相同字符的最少修改数之和**。每对不同时改 1 次（任改一个跟另一个一致）即可，相同则 0 次。各对互不干扰，答案就是：

$$\texttt{ans} = \#\{\, i : s_{2i} \ne s_{2i+1} \,\}$$

### 3.3 算法流程

```text
1. ans ← 0
2. for i = 0, 2, 4, …, n−2:
       若 s[i] ≠ s[i+1]：ans ← ans + 1
3. 返回 ans
```

一次线性扫描，$O(n)$ 时间 $O(1)$ 空间。

### 3.4 示例演算

**示例 1**（`s = "1001"`）：

| 对 | 字符 | 相同？ | 改动 |
|----|------|--------|------|
| (0,1) | 1,0 | ✗ | 1 |
| (2,3) | 0,1 | ✗ | 1 |

答案 2，改后 `11|00` ✓。

**再举 `s = "0101"`**：两对 (0,1)、(0,1) 都不同，答案 2，改成 `00|11` 或 `11|00`。

**`s = "11000111"`**：对 (1,1)✓、(0,0)✓、(0,1)✗、(1,1)✓ → 答案 1。

## 4. 算法细节

1. **对内改谁无所谓**：把 `10` 改成 `11` 或 `00` 都花 1 次，且**不影响其他对**（相邻块的边界已在偶数处切好，块内字符取 0 还是 1 与下一块无关）。这是「逐对独立」的关键——块与块之间没有耦合。
2. **为什么不担心「跨对」更优**：有人会想 `1001` 里改 s[1] 与 s[2] 两次得 `1101"`？不美丽。或者改一次 s[3] 得 `1000` = `10|00`？第一块 `10` 不合法。**任何美丽串的所有偶数位置对必须内部相同**（§3.2 观察二的逆否），所以跨对修修补补逃不掉「每对不同至少改一次」的下界。
3. **下界即上界**：不同的对至少改 1 次（下界）；逐对改 1 次即达美丽（上界）。两者相等，贪心最优，不需要 DP。
4. **实现**：`for (i = 0; i + 1 < n; i += 2) ans += (s[i] != s[i+1]);`，注意循环条件用 `i + 1 < n` 防御奇数长度（本题保证偶数，防御无害）。
5. **数据范围宽裕**：$n \le 10^5$，$O(n)$ 轻松；答案上界 $n/2 \le 5\times 10^4$，无溢出。

## 5. 正确性证明

**引理 1（划分的边界都在偶数下标处）**：若 $s$ 美丽，则存在一种合法划分，其每块起点下标都是偶数。

**证明**：划分从下标 0 开始依次排列，每块长度为偶数，偶数个偶数相加仍为偶数，归纳得每块起点为偶数、终点为奇数。∎

**引理 2（美丽 ⇔ 每对内部相同）**：$s$ 美丽当且仅当对所有 $i$，$s_{2i} = s_{2i+1}$。

**证明**：（⇐）若每对相同，按对划分即得 $n/2$ 个长度 2 的同色块，合法。（⇒）设 $s$ 有合法划分，由引理 1 各块边界在偶数下标处，于是每个下标对 $(2i, 2i+1)$ 包含于同一块内（块长为偶数，起点偶数，不可能「一半在前块一半在后块」），而块内同色，故 $s_{2i} = s_{2i+1}$。∎

**定理（最优性）**：最少修改次数等于 $\#\{i : s_{2i} \ne s_{2i+1}\}$。

**证明**：设 $B = \#\{i : s_{2i} \ne s_{2i+1}\}$。**下界**：修改后串必须美丽，由引理 2 每对应相同；一个位置对在原串中不同，至少要改动其中一个字符（1 次修改只影响一个位置），故总修改数 $\ge B$。**上界**：对每个不同的对，把 $s_{2i+1}$ 改成 $s_{2i}$（1 次修改），共 $B$ 次，改后每对都相同，由引理 2 美丽。二者相等，即最优。∎

## 6. 复杂度分析

- **时间**：$O(n)$。单趟扫描，每对 $O(1)$ 比较累加。
- **空间**：$O(1)$。只有计数器，不随输入规模增长（不计输入字符串本身）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minChanges(string s) {
        int ans = 0;
        for (size_t i = 0; i + 1 < s.size(); i += 2)  // 每对 (2i, 2i+1)
            ans += (s[i] != s[i + 1]);                 // 不同则至少改一次、也只需一次
        return ans;
    }
};
```

### Python

```python
class Solution:
    def minChanges(self, s: str) -> int:
        return sum(s[i] != s[i + 1] for i in range(0, len(s) - 1, 2))
```

> 💡 两份代码均通过官方示例（`2`、`1`、`0`）及 `"11000111"→1`、`"0101"→2` 等补充用例；另与「$2^n$ 枚举每个字符改/不改再判美丽」的暴力对拍 400 组随机串（长度 $\le 12$），`mismatch = 0`。

## 8. 边界情况与易错点

1. **$n = 2$**：只有一对，不同改 1、相同改 0；`"10"→1` 是官方示例 2。
2. **已经美丽**：`"0000"`、`"1111"`、`"0011"` 等全对相同，返回 0，别手滑给「已美丽」加初始 1。
3. **误用「最长交替段」等套路**：本题块长**任意偶数**都可，不是定长 2 的 `00/11` 交替拼接；但因引理 2 的等价性，只需逐对检查。别把它做成「使串成为 0^a1^b 形」——那是不必要的强约束（例如 `11|00|11` 三块合法）。
4. **对齐起点**：必须从下标 0 开始按 (0,1)(2,3)… 配对。从下标 1 开始配对是常见笔误，`"1001"` 会算成 0 对不同而错误输出 0。
5. **答案与值无关**：不需要统计 0/1 个数、不需要关心改成 0 还是 1，只看「对内是否相等」。
6. **奇数长度防御**：题目保证偶数；若循环写成 `i < n` 且访问 `s[i+1]` 在 $i = n-1$ 处越界（C++ 未定义行为），用 `i + 1 < n` 或步进 2 的正确边界。

**延伸思考**：本题的本质是「**把划分自由度归一化**」：块长任意偶数看似搜索空间巨大，但所有合法划分 refine 到长度 2 后判据不变，于是自由度坍缩成逐对的局部条件。同族技巧见「每组块长为 $k$ 的倍数」变体（按 $\bmod k$ 同余类配对检查）以及括号匹配类问题（任何合法匹配 refine 为相邻配对）。看到一个带「任意划分」的问题时，先问一句：**最细的合法划分是什么？** 它往往就是答案的全部信息。
