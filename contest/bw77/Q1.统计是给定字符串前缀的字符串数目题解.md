# LeetCode 统计是给定字符串前缀的字符串数目 题解

## 1. 题目概述

- **标题 / 题号**：统计是给定字符串前缀的字符串数目（#2255，easy）
- **链接**：https://leetcode.cn/problems/count-prefixes-of-a-given-string/
- **来源**：LeetCode 第 77 场双周赛 Q1
- **难度**：简单
- **标签**：数组、字符串

**题意**：给定字符串数组 `words` 和字符串 `s`（均只含小写字母），统计 `words` 中**是 `s` 的前缀**的字符串数目。前缀指出现在字符串开头的连续子串；相同的字符串出现多次要计多次。

**约束**：

- $1 \le words.length \le 1000$
- $1 \le words[i].length,\ s.length \le 10$
- `words[i]` 与 `s` 只包含小写英文字母

## 2. 示例

**示例 1**

```text
输入：words = ["a","b","c","ab","bc","abc"], s = "abc"
输出：3
解释："a"、"ab"、"abc" 是 s = "abc" 的前缀；"b"、"c"、"bc" 不是。
```

**示例 2**

```text
输入：words = ["a","a"], s = "aa"
输出：2
解释：两个 "a" 都是 "aa" 的前缀，重复出现的字符串分别计数。
```

**示例 3（边界补充）**

```text
输入：words = ["abcd","abcde"], s = "abc"
输出：0
解释：words[i] 比 s 更长时必然不是 s 的前缀——长度判断不可省略。
```

## 3. 解题思路

### 3.1 暴力思路

对每个 `words[i]`，逐字符与 `s` 的前 $\lvert words[i] \rvert$ 个字符比较：长度超出 `s` 直接排除，否则比较 $O(\lvert words[i] \rvert)$ 次。总复杂度 $O\left(\sum_i \lvert words[i] \rvert\right) \le 1000 \times 10 = 10^4$，本题数据下完全够用——**签到题直接模拟即可**，不需要任何优化。

另一条等价路线：把 `s` 的所有前缀（至多 10 个）放进哈希集合，再对每个 `words[i]` 查一次集合，$O(1)$ 判定。总复杂度同为 $O(\lvert s \rvert + \sum_i \lvert words[i] \rvert)$，数据规模小时两者无差别。

### 3.2 核心观察：前缀判定 = 长度合法 + 首段逐字符相等

![前缀判定模型：s 的前缀集合与 words 匹配](images/bw77_q1_prefix_model.svg)

**关键事实**：字符串 $w$ 是 $s$ 的前缀，当且仅当

$$\lvert w \rvert \le \lvert s \rvert \quad\text{且}\quad s[0..\lvert w \rvert - 1] = w。$$

两条缺一不可：长度判断防止越界与误判（$w$ 比 $s$ 长必非前缀）；逐字符相等保证 $w$ 恰好出现在 $s$ 的开头，而不是中间或末尾。工程上直接调用库函数即可：C++ 的 `s.compare(0, w.size(), w) == 0` 或 `s.substr(0, w.size()) == w`，Python 的 `s.startswith(w)`（`startswith` 自带长度语义，无需先判长度）。

### 3.3 算法流程

```text
1. ans = 0
2. 对 words 中每个字符串 w：
       若 len(w) <= len(s) 且 s 的前 len(w) 个字符与 w 相等：
           ans += 1
3. 返回 ans
```

### 3.4 示例演算

![示例演算：逐词判定表](images/bw77_q1_walkthrough.svg)

以示例 1（`s = "abc"`）为例：

| words[i] | 长度合法？ | 与 s 前缀比对 | 是否前缀 |
|----------|-----------|---------------|----------|
| `"a"` | $\checkmark$（1 ≤ 3） | `"a"` == `"a"` | ✅ |
| `"b"` | $\checkmark$ | `"b"` != `"a"` | ❌ |
| `"c"` | $\checkmark$ | `"c"` != `"a"` | ❌ |
| `"ab"` | $\checkmark$ | `"ab"` == `"ab"` | ✅ |
| `"bc"` | $\checkmark$ | `"bc"` != `"ab"` | ❌ |
| `"abc"` | $\checkmark$ | `"abc"` == `"abc"` | ✅ |

共 3 个 ✅，返回 $3$，与官方输出一致。

## 4. 算法细节

1. **判定的短路顺序**：先判长度再比对内容。长度不合法时跳过比对，既省时也避免 `substr` 越界语义歧义（C++ 的 `substr(pos, len)` 越界会截断，比较结果恰好为 false，但显式判长度更清晰）。
2. **`compare` 的三段式用法**：`s.compare(0, w.size(), w)` 把 `s` 从下标 0 起、长 `w.size()` 的子串与 `w` 比较，返回 0 表示相等。它不构造临时子串，比 `substr` 比较少一次拷贝。
3. **重复字符串**：题目明确重复出现要计多次（示例 2），遍历计数天然满足，**不要**先对 `words` 去重。
4. **哈希集合版**：`s` 至多 10 个前缀，`unordered_set<string>` 或 Python `set` 存入后逐词 `in` 查询；两条路线复杂度同阶，本题无优劣之分。
5. **数据规模意识**：$\lvert words \rvert \le 1000$、长度 $\le 10$，任何 $O(n \cdot L)$ 的做法都在 $10^4$ 量级；若把范围放大到 $10^5 \times 10^5$，则应改为哈希集合版（比对成本转移到哈希）。

## 5. 正确性证明

**引理 1（前缀判定准则）**：字符串 $w$ 是 $s$ 的前缀 $\iff$ $\lvert w \rvert \le \lvert s \rvert$ 且对所有 $0 \le k < \lvert w \rvert$ 有 $w[k] = s[k]$。

**证明**：（$\Rightarrow$）设 $w$ 是 $s$ 的前缀，即存在 $s$ 的子串从下标 0 开始恰为 $w$。该子串占据 $s[0..\lvert w \rvert - 1]$，故 $\lvert w \rvert \le \lvert s \rvert$ 且逐位相等。（$\Leftarrow$）若两条件成立，则 $s$ 的开头 $\lvert w \rvert$ 个字符依序与 $w$ 相同，按前缀定义 $w$ 出现在 $s$ 开头，是 $s$ 的前缀。∎

**定理（算法正确性）**：遍历 `words` 对每个元素按引理 1 判定并计数，返回值等于 `words` 中是 `s` 的前缀的字符串数目（含重复）。

**证明**：算法对每个下标 $i$ 独立判定 `words[i]`，由引理 1 该判定结果与「`words[i]` 是 $s$ 的前缀」这一命题真值一致；计数器对每个真命题加一，且遍历不重不漏地覆盖所有下标（重复字符串在不同下标各计一次）。故计数器的终值恰为所求数目。∎

## 6. 复杂度分析

- **时间**：$O\left(\lvert s \rvert + \sum_i \lvert words[i] \rvert\right)$。每个字符串一次长度判断 + 至多 $\lvert words[i] \rvert$ 次字符比较；本题规模下上界 $10^4$。
- **空间**：$O(1)$ 额外空间（逐个判定，不建哈希表）；若采用哈希集合版则为 $O(\lvert s \rvert^2)$（存所有前缀，长度 $1..10$ 总字符数 $\le 55$，仍可视为常数级）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int countPrefixes(vector<string>& words, string s) {
        int ans = 0;
        for (const string& w : words)
            if (w.size() <= s.size() && s.compare(0, w.size(), w) == 0)
                ++ans;
        return ans;
    }
};
```

### Python

```python
class Solution:
    def countPrefixes(self, words: list[str], s: str) -> int:
        return sum(1 for w in words if s.startswith(w))
```

> 💡 两份代码均通过官方示例（`3`、`2`），并与「重实现 `startswith` 的逐字符暴力」对拍 1500 组随机数据（含 `words[i]` 长于 `s`、重复词、整串相等边界），`mismatch = 0`。

## 8. 边界情况与易错点

1. **长度判断不可省略**：`words[i]` 长于 `s` 时不是前缀。手写逐字符比较若不先判长度会越界或误判；`startswith` / `compare` 自带该语义，但自造轮子时最易踩坑。
2. **重复字符串计多次**：示例 2 明确要求，先去重会直接输出错误答案。
3. **整串相等**：`words[i] == s` 时是前缀（任何字符串是自身的前缀），`w.size() <= s.size()` 的等号方向要写对。
4. **空串陷阱**：本题约束长度 $\ge 1$，不存在空串；若放宽约束，空串是任何字符串的前缀，需按题意单独确认。
5. **单字符串**：`s = "a"` 时只有 `"a"`（以及更短的，不存在）是前缀，长度为 1 的比对退化成单字符相等，无需特判。
