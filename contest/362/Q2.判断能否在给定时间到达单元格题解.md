# LeetCode 判断能否在给定时间到达单元格 题解

## 1. 题目概述

- **标题 / 题号**：判断能否在给定时间到达单元格（#2849，medium）
- **链接**：https://leetcode.cn/problems/determine-if-a-cell-is-reachable-at-a-given-time/
- **来源**：LeetCode 第 362 场周赛 Q2
- **难度**：中等
- **标签**：数学、几何

**题意**：在无限的二维网格中，你从单元格 $(sx, sy)$ 出发。每一秒，你**必须**移动到一个与当前格**相邻**的单元格（相邻指共享至少一个角——横、竖、斜 8 个方向都算），同一格可以反复经过。问能否在**恰好** $t$ 秒后位于 $(fx, fy)$：能返回 `true`，否则返回 `false`。

**约束**：

- $1 \le sx, sy, fx, fy \le 10^9$
- $0 \le t \le 10^9$

> 💡 读题抓三个词：「**必须移动**」——不能原地等待；「**恰好** $t$ **秒**」——不是至多，多一秒少一秒都不行；「**共享角即可**」——8 邻接、可以斜走。再看数据范围：坐标与 $t$ 都到 $10^9$，任何逐格 BFS / DP 必然爆炸，答案只能是 $O(1)$ 的数学判定。

## 2. 示例

**示例 1**

```text
输入：sx = 2, sy = 4, fx = 7, fy = 7, t = 6
输出：true
解释：从 (2, 4) 到 (7, 7) 最短 5 秒；把路径中的一个斜走拆成两步直走，
恰好 6 秒到达。
```

**示例 2**

```text
输入：sx = 3, sy = 1, fx = 7, fy = 3, t = 3
输出：false
解释：x 方向差 4，每秒 x 至多推进 1，3 秒后 x 最多到 6，够不到 7。
```

**示例 3（同格陷阱，自构造）**

```text
输入：sx = 1, sy = 1, fx = 1, fy = 1, t = 1
输出：false
解释：起点终点同格，但每秒必须移动：第 1 秒被迫迈到邻格，
1 秒末必然不在 (1, 1)。
```

## 3. 解题思路

### 3.1 暴力思路：逐秒 BFS 扩散

最直觉的做法是 BFS：从 $(sx, sy)$ 出发逐秒枚举可达集合，看 $(fx, fy)$ 是否恰好出现在第 $t$ 层。第 $k$ 秒的可达区域是以起点为中心、切比雪夫半径为 $k$ 的正方形，面积约 $(2k+1)^2$；$t$ 达 $10^9$ 时状态数 $10^{18}$ 量级，彻底不可行。DP 同样无从下手——网格无限、无障碍、无结构可记。

正确的方向是**反过来刻画**：不模拟走法，直接回答两个数学问题：

1. 从 S 到 F **至少**要多少秒？（最短时间）
2. 比「至少」多出来的时间，能不能**精确凑整**到恰好 $t$ 秒？（凑时间）

### 3.2 核心观察：最短时间 = 切比雪夫距离，多余时间随便凑

![核心观察：斜走一步两轴同时推进，最短时间 = max(dx, dy) = 5](images/wc362_q2_chebyshev_concept.svg)

**观察 1（最短时间）**：记 $dx = |sx - fx|$，$dy = |sy - fy|$，则从 S 到 F 的最短时间恰为 $d = \max(dx, dy)$——这正是**切比雪夫距离**（Chebyshev distance），国际象棋里「王」的走法距离。

- **下界**：每一步中 $x$ 坐标至多变化 $\pm 1$，故至少要走 $dx$ 步；$y$ 同理至少 $dy$ 步；两者须同时满足，所以至少 $\max(dx, dy)$ 步。
- **构造**：先沿对角线走 $\min(dx, dy)$ 步（两轴同时向 F 推进），再沿较长的一轴直走 $|dx - dy|$ 步，恰好 $\max(dx, dy)$ 步到达。

**观察 2（凑时间自由）**：「恰好」二字并不卡奇偶——只要路径**非空**，多出来的秒数想加几加几：

- **+1（拆步）**：把任意一步拆成两步——斜走 $(1,1)$ 拆成 $(1,0)+(0,1)$；直走 $(1,0)$ 拆成 $(1,1)+(0,-1)$（先斜走再竖回）。一步变两步，时长 +1，起终点不变。
- **+2（踱步）**：任意时刻去邻格打个转再回来，+2。

![凑时间两板斧：拆步 +1、踱步 +2；同格 t=1 唯一例外](images/wc362_q2_padding_tricks.svg)

于是一旦 $F \ne S$（最短路径长度 $d \ge 1$），反复「拆步 / 踱步」就能把时长精确调成**任何** $t \ge d$ 的值：**异格时答案就是 $t \ge \max(dx, dy)$，与奇偶无关**。

（对比：若只许上下左右 4 方向移动，斜走不存在，+1 凑不出来，奇偶性被锁死——同场 Q3 的石头搬运正是「共享边」的 4 邻接 + 曼哈顿距离世界，两题挨着做极易串味。）

**观察 3（同格例外）**：$dx = dy = 0$ 时最短路径是**空路径**，+1 拆步无从下手，「必须移动」开始反咬一口：

- $t = 0$：原地不动即达 → `true`；
- $t = 1$：被迫迈出一步，1 秒末必在某个邻格 → **`false`**（全题唯一反例）；
- $t \ge 2$：去邻格再回来（+2）、走「斜 + 横 + 竖」三角形回原点（+3），再叠加 +2 → `true`。

同格时答案为 $t \ne 1$。

### 3.3 算法流程

![算法流程：两次绝对值 + 同格判断 + 切比雪夫距离与 t 比较](images/wc362_q2_algorithm_flow.svg)

整个算法就是「两次绝对值 + 两个分支」：

1. 计算 $dx = |sx - fx|$、$dy = |sy - fy|$；
2. 若 $dx = dy = 0$（同格）：返回 $t \ne 1$；
3. 否则（异格）：返回 $\max(dx, dy) \le t$。

### 3.4 示例演算

![示例演算：示例 1 拆步凑出第 6 秒；示例 2 长轴差 4 步、3 秒够不着](images/wc362_q2_example_walkthrough.svg)

- **示例 1**：$dx = 5$，$dy = 3$，$d = \max(5, 3) = 5 \le 6$ → `true`。恰好 6 秒的走法：斜、斜、横、横、横、竖——相当于把最短路径（3 斜 + 2 横）里的一个斜走拆成「横 + 竖」，5 步变 6 步。
- **示例 2**：$dx = 4$，$dy = 2$，$d = 4 > 3$ → `false`。每秒 $x$ 至多 $+1$，3 秒后 $x \le 6 < 7$，物理上够不着。
- **示例 3**：$dx = dy = 0$，同格，$t = 1$ → `false`。

## 4. 算法细节

1. **先特判同格，再比较距离**：`dx == 0 && dy == 0` 走 `t != 1` 分支，其余走 `max(dx, dy) <= t`。两个分支的先后无所谓，但**同格特判绝不能省**。
2. **切比雪夫距离 $O(1)$ 计算**：$d = \max(|\Delta x|, |\Delta y|)$，无需任何预处理。在 45° 旋转坐标系（$u = x + y$，$v = x - y$）下它等于曼哈顿距离——两套度量可互相转化（见 1131 题）。
3. **无溢出风险**：坐标 $\le 10^9$，$dx, dy < 2^{31}$，32 位 `int` 装得下。
4. **为什么 8 邻接没有奇偶限制**：+1 拆步的本质是「同一起终点下，一步与两步的走法都存在」——斜步可拆成两个直步、直步可拆成斜步 + 回步。4 邻接下这两族走法不互通，奇偶才被锁死。
5. **为什么同格 $t = 1$ 是唯一反例**：一步的位移是 8 个非零向量之一，必不为 $(0,0)$；而 $t \ge 2$ 的所有值都有回到起点的回路（2 步往返、3 步三角形，再叠加 +2）。

## 5. 正确性证明

**引理 1（步数下界）**：从 $S = (sx, sy)$ 到 $F = (fx, fy)$ 的任意合法移动序列长度 $L \ge d = \max(dx, dy)$。

**证明**：每步移到相邻格，横、纵坐标各自的变化量绝对值 $\le 1$。$L$ 步的横向总变化量绝对值至多为 $L$，而它必须等于 $dx$，故 $L \ge dx$；同理 $L \ge dy$。合并得 $L \ge \max(dx, dy) = d$ ∎

**引理 2（最短路径可达）**：存在长度恰为 $d$ 的合法移动序列。

**证明**：不妨设 $dx \ge dy$（另一侧对称）。先连走 $dy$ 步斜步，每步位移 $\bigl(\operatorname{sgn}(fx - sx),\ \operatorname{sgn}(fy - sy)\bigr)$，两轴同时向 F 推进；再沿 $x$ 轴直走 $dx - dy$ 步。总步数 $dy + (dx - dy) = dx = d$，且每步都是合法的 8 邻接移动 ∎

**引理 3（拆步凑 1）**：任何长度 $L \ge 1$ 的合法移动序列，都可改写为长度 $L + 1$ 的、起终点不变的合法移动序列。

**证明**：取序列中任意一步，设其位移为 $v = (a, b)$（$|a|, |b| \le 1$，$v \ne (0,0)$），按情形把这步一拆二：

- $a \ne 0$ 且 $b \ne 0$（斜步）：替换为 $(a, 0)$ 与 $(0, b)$ 两步；
- $b = 0$（横步，$a \ne 0$）：替换为 $(a, a)$ 与 $(0, -a)$ 两步；
- $a = 0$（竖步，$b \ne 0$）：替换为 $(b, b)$ 与 $(-b, 0)$ 两步。

三种情形的两个新位移各自都落在 8 邻接向量集内，且位移和恰为 $v$；序列其余步不动，总位移不变、长度 $+1$ ∎

**引理 4（同格判定）**：$S = F$ 时，恰好 $t$ 秒后位于 $S$ 当且仅当 $t \ne 1$。

**证明**：$t = 0$：空序列即达。$t = 1$：唯一一步的位移 $v \ne (0, 0)$，1 秒末位置 $\ne S$。$t \ge 2$：若 $t$ 为偶数，交替执行 $(1,0)$ 与 $(-1,0)$ 共 $t$ 步，位移和为零；若 $t \ge 3$ 为奇数，先走三角形三步 $(1,1), (-1,0), (0, -1)$（和为零），再补 $(t-3)/2$ 组往返。两种情形都恰好 $t$ 秒回到 $S$ ∎

**定理**：恰好 $t$ 秒后能位于 $F$ $\iff$（$S = F$ 且 $t \ne 1$）或（$S \ne F$ 且 $t \ge d$）。

**证明**：同格情形即引理 4。异格情形：**必要性**——存在长度为 $t$ 的序列，由引理 1 得 $t \ge d$；**充分性**——由引理 2 取长度 $d \ge 1$ 的最短序列，若 $t > d$，因序列始终非空，可反复应用引理 3 共 $t - d$ 次把长度逐步抬到 $t$，起终点不变 ∎

算法返回值与定理的判定条件逐字对应，故算法正确。

## 6. 复杂度分析

- **时间复杂度**：$O(1)$——两次减法取绝对值、一次 $\max$、一至两次比较，与坐标和 $t$ 的大小无关。
- **空间复杂度**：$O(1)$——常数个变量。

> 💡 对比：BFS 需要 $O(t^2)$ 级别的状态且 $t \le 10^9$ 完全不可行。「坐标与时间同阶巨大 + 无障碍无限网格」是「别搜索、找公式」的标准信号。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    bool isReachableAtTime(int sx, int sy, int fx, int fy, int t) {
        int dx = abs(sx - fx), dy = abs(sy - fy);
        if (dx == 0 && dy == 0) return t != 1;  // 同格：被迫走 1 步，回不来
        return max(dx, dy) <= t;                // 切比雪夫距离 ≤ t 即可达
    }
};
```

### Python

```python
class Solution:
    def isReachableAtTime(self, sx: int, sy: int, fx: int, fy: int, t: int) -> bool:
        dx, dy = abs(sx - fx), abs(sy - fy)
        if dx == 0 and dy == 0:
            return t != 1        # 同格：被迫走 1 步，回不来
        return max(dx, dy) <= t  # 切比雪夫距离 ≤ t 即可达
```

## 8. 边界情况与易错点

1. **同格 + $t = 1$（头号易错）**：朴素公式 $\max(0,0) = 0 \le 1$ 会误判 `true`，正确答案是 `false`——本题绝大多数 WA 源于此。同格时正确判定是 $t \ne 1$，注意 $t = 0$ 是 `true`。
2. **$t = 0$**：同格 `true`；异格 `false`（$d \ge 1 > 0$）。
3. **「恰好」不是「至多」**：多数网格题问「至多 $t$ 秒」，本题问精确相等；幸好 8 邻接下「能至多就能恰好」，差别只剩同格 $t = 1$ 这一个洞。
4. **别把 4 邻接的结论搬过来**：8 邻接可斜走，最短时间是切比雪夫距离、凑时间不卡奇偶；若误按「曼哈顿距离 + 奇偶」判定会双错。同场 Q3 是「共享边」的 4 邻接搬运题，距离用曼哈顿——动笔前先看清「共享边」还是「共享角」。
5. **坐标与 $t$ 均到 $10^9$**：`int` 不溢出（差值 $< 2^{31}$），但 BFS / DFS / DP 全部不可行，复杂度必须 $O(1)$。
6. **「必须移动」是同格陷阱的根源**：审题看到「必须」二字，要立刻检查「原地等待」是否被禁止——它往往就是特判分支的藏身之处。
