# LeetCode 与车相交的点 题解

## 1. 题目概述

- **标题 / 题号**：与车相交的点（#2848，easy）
- **链接**：https://leetcode.cn/problems/points-that-intersect-with-cars/
- **来源**：LeetCode 第 362 场周赛 Q1
- **难度**：简单
- **标签**：数组、哈希表、前缀和

**题意**：数轴上停着 $n$ 辆车，第 $i$ 辆占据闭区间 $[start_i, end_i]$ 上的所有整数点。返回数轴上被**任意一辆车**覆盖的整数点数目——重叠的部分只数一次，本质是求区间**并集**覆盖的点数。

**约束**：

- `1 <= nums.length <= 100`
- `nums[i].length == 2`
- `1 <= start_i <= end_i <= 100`

> 💡 读题关键：「被任意部分覆盖」翻译成集合语言就是**区间并集**——示例 2 中 $[1,3]$ 与 $[5,8]$ 不相连，中间的点 4 没被任何车盖住，不计入答案；而示例 1 的三辆车互相咬合，重叠点也只能数一次。值域只有 $[1,100]$，这个「小值域」正是签到切入的突破口。

## 2. 示例

**示例 1**

```text
输入：nums = [[3,6],[1,5],[4,7]]
输出：7
解释：三辆车互相咬合，并集为 [1,7]，1 到 7 的每个点都至少被一辆车覆盖。
```

**示例 2**

```text
输入：nums = [[1,3],[5,8]]
输出：7
解释：1、2、3 与 5、6、7、8 被覆盖；点 4 夹在两车之间的空洞里，不计入。
```

**示例 3（单点车边界）**

```text
输入：nums = [[1,1],[100,100]]
输出：2
解释：start = end 时车仍占据 1 个整数点，闭区间端点都算被覆盖。
```

## 3. 解题思路

### 3.1 快速切入：值域 ≤ 100，「涂格子」即正解

签到题先看数据范围：坐标 $\le 100$、车 $\le 100$ 辆。开一个长度 101 的布尔数组（或哈希集合），每辆车把 $[start_i, end_i]$ 内的整数点逐个标记，最后数被标记的点——总操作至多 $100 \times 100 = 10^4$，怎么写都能过。Python 甚至一行：`len({p for s, e in nums for p in range(s, e + 1)})`。

比赛到这一步就可以提交了。唯一值得花 10 秒确认的边界：**区间是闭的，`end` 本身也要标记**——`range(s, e + 1)` 里那个 `+1` 别丢。

### 3.2 核心观察：区间加 → 差分数组，一次涂色只改两格

![核心观察：三辆车叠在数轴上，并集覆盖 1 到 7 共 7 个点](images/wc362_q1_coverage_concept.svg)

逐点涂色把「区间」当成「一堆点」对待，单次涂色代价 $O(\text{区间长})$。更有转移价值的写法是**差分数组**：把「点 $p$ 是否被覆盖」升级为「点 $p$ 的**覆盖层数**」，每辆车 $[s, e]$ 的入桩只需改两格：

$$\text{diff}[s] \mathrel{+}= 1, \qquad \text{diff}[e+1] \mathrel{-}= 1$$

从左到右做一遍前缀和 $\text{cover}[p] = \sum_{j \le p} \text{diff}[j]$，就还原出每个点的覆盖层数：$s$ 处起 $+1$，$e+1$ 处被 $-1$ 抵消，恰好覆盖 $[s, e]$；多辆车叠加时层数相加。**被覆盖 ⇔ cover > 0**，重叠去重由「层数判正」自动完成。

### 3.3 算法流程

![算法流程：第一趟打桩 O(n)，第二趟前缀和拉线 O(C)](images/wc362_q1_diff_flow.svg)

```text
1. diff = [0] * 102
2. 第一趟（打桩）：遍历每辆车 [s, e]：
   a. diff[s] += 1
   b. diff[e+1] -= 1
3. 第二趟（拉线）：cover = 0，p 从 1 扫到 100：
   a. cover += diff[p]
   b. 若 cover > 0：ans += 1
4. 返回 ans
```

### 3.4 示例演算

![示例 1 演算：diff 打桩与前缀和还原覆盖层数](images/wc362_q1_diff_walkthrough.svg)

以示例 1 `nums = [[3,6],[1,5],[4,7]]` 走一遍：三辆车各打一对桩——$[3,6]$ 打在 3 和 7，$[1,5]$ 打在 1 和 6，$[4,7]$ 打在 4 和 8。从左到右拉前缀和：点 1 处升到 1 层，点 4 处叠到 3 层（三车同时盖住），点 7 处回落到 1 层，点 8 处三个 $-1$ 全部抵消归零。`cover > 0` 的位置恰为 $1 \sim 7$，答案 **7**。

顺带还能读出重叠信息：点 4 被盖 3 层、点 7 只剩 1 层——「层数」比「布尔标记」多出来的信息是差分白送的：若改问「恰好被 $k$ 辆车覆盖的点数」，把判正改成判 `cover == k` 即可。

## 4. 算法细节

1. **数组开 102 格**：$e + 1$ 最大到 101，`diff` 下标需覆盖 $0 \sim 101$；多出的第 101 格只承接 $e = 100$ 的减桩，不参与计数。
2. **减桩位置是 $e+1$**：区间是闭的，点 $e$ 本身要被覆盖，前缀和走到 $e+1$ 时才把 $+1$ 抵消归零；写成 `diff[e]--` 会把点 $e$ 漏掉。
3. **判正不判一**：多辆车重叠时层数累加（示例 1 的点 4 达到 3 层），被覆盖的判据是 `cover > 0`，与层数是 1 还是 3 无关。
4. **两趟不可合并**：必须先把所有车打完桩、再统一拉前缀和；若边读区间边还原，会漏掉尚未入桩的车。

## 5. 正确性证明

**引理 1**：对单个区间 $[s, e]$ 只做 `diff[s] += 1`、`diff[e+1] -= 1` 两次修改，则任意位置 $p$ 的前缀和 $\text{cover}[p] = \sum_{j \le p} \text{diff}[j]$ 满足：$s \le p \le e$ 时为 1，否则为 0。

**证明**：按 $p$ 与区间的位置关系分三段。$p < s$：前缀和里不含任何桩，$\text{cover}[p] = 0$；$s \le p \le e$：$s$ 处的 $+1$ 已累加、$e+1$ 处的 $-1$ 尚未累加（因 $e + 1 > p$），$\text{cover}[p] = 1$；$p \ge e+1$：$+1$ 与 $-1$ 均已累加，互相抵消，$\text{cover}[p] = 0$ ∎

**引理 2**：$n$ 辆车全部打桩后，$\text{cover}[p] = \#\{\, i : s_i \le p \le e_i \,\}$，即恰好盖住点 $p$ 的车的辆数。

**证明**：前缀和是线性的——全部桩的前缀和等于各车的桩的前缀和之和。由引理 1，第 $i$ 辆车对 $\text{cover}[p]$ 恰好贡献 1 当且仅当 $s_i \le p \le e_i$，对所有车求和即得 ∎

**定理**：算法返回值等于数轴上被至少一辆车覆盖的整数点数目。

**证明**：点 $p$ 被覆盖 ⇔ 存在 $i$ 使 $s_i \le p \le e_i$ ⇔ $\text{cover}[p] \ge 1$（引理 2）。又由值域约束 $1 \le s_i \le e_i \le 100$，被覆盖的点只能落在 $[1, 100]$ 内，第二趟恰好无重无漏地枚举该区间并统计 `cover > 0` 的位置 ∎

## 6. 复杂度分析

- **时间复杂度**：$O(n + C)$——第一趟 $n$ 辆车各改两格；第二趟扫值域 $C = 100$ 个位置。本题 $n, C \le 100$，总量 $O(10^2)$ 级别。
- **空间复杂度**：$O(C)$——差分数组 102 个整数，与车数 $n$ 无关。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int numberOfPoints(vector<vector<int>>& nums) {
        int diff[102] = {0};
        for (auto& car : nums) {
            diff[car[0]]++;
            diff[car[1] + 1]--;
        }
        int ans = 0, cover = 0;
        for (int p = 1; p <= 100; p++) {
            cover += diff[p];
            ans += cover > 0;
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def numberOfPoints(self, nums: List[List[int]]) -> int:
        diff = [0] * 102
        for s, e in nums:
            diff[s] += 1
            diff[e + 1] -= 1
        ans = cover = 0
        for p in range(1, 101):
            cover += diff[p]
            ans += cover > 0
        return ans
```

## 8. 边界情况与易错点

1. **off-by-one（头号易错）**：减桩打在 `e+1` 而非 `e`——闭区间含端点，点 `e` 必须被盖住。
2. **数组越界**：`e = 100` 时 `e + 1 = 101`，`diff` 至少开 102 格。
3. **判 `cover > 0` 而非 `== 1`**：重叠层数可以到 2、3，只要非零就算覆盖。
4. **单点车**：`start == end` 时车仍占据 1 个点，不是 0 个。
5. **区间之间的空洞**：示例 2 的点 4 不被任何车盖住，前缀和在此处为 0，天然不计入；逐点涂色法靠集合去重、差分法靠层数归零，两者殊途同归。
6. **值域扩大时失效**：若 $end_i$ 放大到 $10^9$，差分数组开不下，应改用**排序 + 区间合并**（56 题模板，$O(n \log n)$ 与值域无关）。
