# LeetCode 字符串转换 题解

## 1. 题目概述

- **标题 / 题号**：字符串转换（#2851，hard）
- **链接**：https://leetcode.cn/problems/string-transformation/
- **来源**：LeetCode 第 362 场周赛 Q4
- **难度**：困难
- **标签**：数学、字符串、动态规划、字符串匹配

**题意**：给定长度均为 $n$ 的字符串 $s$ 和 $t$。一次操作：取出 $s$ 长度为 $l$（$0 < l < n$）的**后缀**搬到开头，得到 $s[n-l:] + s[:n-l]$——本质是一次**循环移位**。求**恰好** $k$ 次操作把 $s$ 变成 $t$ 的方案数，对 $10^9+7$ 取模。注意「方案」按**每步选择的 $l$ 组成的序列**计数：即使两个序列产生完全相同的字符串轨迹，也各算一种（示例 2 输出 2 正是此意）。

**约束**：

- $2 \le n = s.length = t.length \le 5 \times 10^5$
- $1 \le k \le 10^{15}$
- $s$、$t$ 只含小写字母

> 💡 **三个数字各定一件事**：$n \le 5\times10^5$ ⇒ 「哪些移位能变成 $t$」必须**线性**求出（KMP / Z 函数）；$k \le 10^{15}$ ⇒ 计数绝不能逐轮递推，必须**闭式或矩阵快速幂**；单步 $l \in [1, n-1]$ **不含 0** ⇒ 单步不能原地不动，但多步净位移可以是 $0$——这一点是全部非平凡性的来源。

## 2. 示例

**示例 1**（题面）

```text
输入：s = "abcd", t = "cdab", k = 2
输出：2
解释：方案一：两次都取 index=3 起始的后缀（l=1），abcd → dabc → cdab；
      方案二：两次都取 index=1 起始的后缀（l=3），abcd → bcda → cdab。
```

**示例 2**（题面）

```text
输入：s = "ababab", t = "ababab", k = 1
输出：2
解释：取 index=2 起始的后缀（l=4）或 index=4 起始的后缀（l=2），
      两种操作都得到 "ababab" 本身——字符串相同仍计 2 种方案。
```

**示例 3**（自构造，奇数 $k$ 走 $+1$ 分支）

```text
输入：s = "aabb", t = "bbaa", k = 3
输出：7
解释：t 在 s+s 中仅起点 p=2 命中 → 好位移 L=(4−2) mod 4=2，m=1，m₀=0，m₁=1；
      p=(n−1)^k=27，k 为奇数 sign=−1，y₃=(27+1)/4=7。
```

**示例 4**（自构造，$t$ 不是 $s$ 的旋转）

```text
输入：s = "ab", t = "cd", k = 5
输出：0
解释："cd" 不在 "abab" 中出现 → 好位移集合为空，直接返回 0。
```

## 3. 解题思路

### 3.1 暴力思路：三级阶梯，全被数据范围否决

**暴力一（字符串当状态）**：任何时刻 $s$ 都是原串的某个旋转，字符串状态至多 $n$ 个。每轮对每个状态枚举 $n-1$ 种 $l$ 生成新串、哈希合并，$O(k \cdot n^2)$——$k = 10^{15}$，死。

**暴力二（位移当状态）**：先看出「旋转可加」（下文观察一），把状态压成**净位移 $r \bmod n$**：$f[i][r]$ 表示 $i$ 步、净位移 $\equiv r$ 的序列数，转移用「总和减自己」$O(1)$ 完成，总 $O(k \cdot n) \approx 5 \times 10^{20}$——$k$ 是天文数字，一切**逐轮递推**都死。

**暴力三（矩阵快速幂）**：转移是线性映射，写成 $n \times n$ 矩阵用快速幂，$O(n^3 \log k)$——$n = 5\times10^5$，立方项直接爆炸。

> ⚠️ 三级暴力其实是通向正解的阶梯：**状态抽象（字符串 → 位移）→ 线性转移 → 降维**。缺的最后一步是：位移维有 $n$ 个值，但「从每个值出发能到哪、各几条路」的结构**对所有状态完全相同**——利用这份对称性，$n$ 维可以压到 $2$ 维。

### 3.2 核心观察一：操作是循环移位，$k$ 步只看位移之和

![核心观察一：圆环上的循环移位与位移可加性](images/wc362_q4_rotation_ring.svg)

记 $R_l(s) = s[n-l:] + s[:n-l]$（把长 $l$ 的后缀搬到开头）。把 $s$ 想成写在圆环上，直接验证复合律：

$$R_a(R_b(s)) = R_{(a+b) \bmod n}(s)$$

于是 $k$ 步操作后 $s = R_L(s)$，其中 $L = (l_1 + \cdots + l_k) \bmod n$，**与操作顺序无关**。问题从「字符串演变」坍缩为纯计数：

> 数序列 $(l_1, \dots, l_k)$：每项 $l_i \in [1, n-1]$，且 $\sum l_i \equiv L \pmod n$。

两个易错点提前钉死：**单步不能不动**（$l$ 不含 $0$ 与 $n$），但多步合成的净位移可以为 $0$；**不同 $l$ 序列即使中间字符串完全相同也计不同方案**（示例 2 的答案 2 来自 $l=2$ 与 $l=4$）。

### 3.3 核心观察二：好位移集合 = KMP 在 $s+s$ 里数匹配

满足 $R_L(s) = t$ 的 $L$ 称为**好位移**。注意到 $R_L(s) = s[p:] + s[:p]$（其中 $p = (n-L) \bmod n \in [0, n-1]$），而 $(s+s)[p:p+n] = s[p:] + s[:p]$，于是

$$R_L(s) = t \iff t \text{ 在 } s+s \text{ 的起点 } p = (n-L) \bmod n \text{ 处匹配}$$

用 KMP 在长度 $2n$ 的文本 $s+s$ 里匹配 $t$，统计**起点 $\le n-1$** 的完整匹配数 $m$（$s+s$ 中起点 $p$ 与 $p+n$ 是同一个旋转，只数一圈）。若 $m = 0$，$t$ 根本不是 $s$ 的旋转，答案为 $0$。再按「是否为零」分桶：

- $m_0 = [s = t]$：好位移 $L = 0$（即起点 $p=0$）是否存在，至多 $1$ 个；
- $m_1 = m - m_0$：其余好位移个数——闭式只区分「零 / 非零」两桶，桶内同价，无需显式存集合。

> 💡 直觉版：若 $s$ 的最小周期为 $d$（$d \mid n$），则 $m = n/d$，命中起点等距排成 $p_0, p_0+d, p_0+2d, \dots$。示例 2 中 $d=2$、$m=3$。周期不必真的求，理解即可。

### 3.4 核心观察三：平移对称性把 $n$ 个状态压成 2 个

![对称性降维：n 个位移状态 → 两状态递推 → 闭式](images/wc362_q4_dp_closed_form.svg)

设 $W_k(r) = \#$「$k$ 步、净位移 $\equiv r \pmod n$」的序列数。枚举最后一步 $l$：

$$W_{k+1}(r) = \sum_{l=1}^{n-1} W_k\big((r - l) \bmod n\big)$$

$l$ 取遍 $[1, n-1]$ 时，$(r-l) \bmod n$ 恰好取遍**除 $r$ 以外**的全部剩余类，于是

$$W_{k+1}(r) = \Big(\sum_{d=0}^{n-1} W_k(d)\Big) - W_k(r)$$

这一行「总和减自己」同时送出两份礼物：

1. **对称性归纳**：右端只依赖「全体之和」与「$W_k(r)$ 自身」。基态 $W_0(0) = 1$（空序列）、$W_0(r \ne 0) = 0$ 满足「非零同值」；归纳可知全程 $W_k(r)$ 在所有 $r \ne 0$ 上取同一值。于是只剩两个数：$x_k = W_k(0)$，$y_k = W_k(\text{非零})$。
2. **两状态转移**：

$$x_{k+1} = (n-1)\, y_k, \qquad y_{k+1} = x_k + (n-2)\, y_k$$

写成矩阵 $\begin{pmatrix} x \\ y \end{pmatrix}_{k+1} = \begin{pmatrix} 0 & n-1 \\ 1 & n-2 \end{pmatrix}\begin{pmatrix} x \\ y \end{pmatrix}_k$，特征方程 $\lambda^2 - (n-2)\lambda - (n-1) = 0$ 的判别式 $(n-2)^2 + 4(n-1) = n^2$ 恰为**完全平方**，两根 $\lambda = n-1$ 与 $-1$。通解 $x_k = \alpha(n-1)^k + \beta(-1)^k$，代入 $x_0 = 1$（空序列）、$x_1 = 0$（单步禁 0）得 $\alpha = 1/n,\ \beta = (n-1)/n$；同理由 $y_0 = 0,\ y_1 = 1$ 定系数。**闭式**：

$$x_k = \frac{(n-1)^k + (n-1)(-1)^k}{n}, \qquad y_k = \frac{(n-1)^k - (-1)^k}{n}$$

验证：$k=1$ 时 $x_1 = 0$（一步转不回 $0$）、$y_1 = 1$（到每个非零位移恰 $1$ 条路）✓；$k=2, n=4$ 时 $x_2 = 3, y_2 = 2$，总数 $3 + 3 \times 2 = 9 = 3^2$ ✓。$(n-1)^k$ 用快速幂扛住 $k = 10^{15}$。最终对好位移求和（引理 3 保证桶内同价）：

$$\text{ans} = m_0 \cdot x_k + m_1 \cdot y_k \pmod{10^9+7}$$

### 3.5 算法流程

![算法流程：KMP 数好位移 → 分桶 → 快速幂 → 闭式拼答案](images/wc362_q4_algorithm_flow.svg)

1. `text = s + s`，以 $t$ 为模式建 KMP `fail` 数组，在 `text` 上扫描；
2. 统计起点 $\le n-1$ 的完整匹配数 $m$；$m = 0$ 返回 $0$；
3. $m_0 = [s = t]$，$m_1 = m - m_0$；
4. 快速幂求 $p = (n-1)^k \bmod (10^9+7)$、$\mathit{invN} = n^{10^9+5} \bmod (10^9+7)$（费马小定理），$\mathit{sign} = (-1)^k$；
5. $x = (p + \mathit{sign}\cdot(n-1)) \cdot \mathit{invN}$，$y = (p - \mathit{sign}) \cdot \mathit{invN}$，答案 $= (m_0 x + m_1 y) \bmod (10^9+7)$。

### 3.6 示例演算

![示例演算：两个官方示例与自构造示例的闭式计算全过程](images/wc362_q4_example_walkthrough.svg)

- **示例 1**（$n=4, k=2$）：`"cdab"` 在 `"abcdabcd"` 中命中于 $p=2$ → 好位移 $L=2$，$m=1,\ m_0=0,\ m_1=1$；$p = 3^2 = 9$，$\mathit{sign}=+1$；$x_2 = (9+3)/4 = 3$，$y_2 = (9-1)/4 = 2$；答案 $= 0 \times 3 + 1 \times 2 = \mathbf{2}$ ✓。$9$ 条序列按净位移分布为 $3/2/2/2$（$\equiv 0,1,2,3$），净位移 $\equiv 2$ 的 $(1,1)$ 与 $(3,3)$ 正是官方解释的两种方案。
- **示例 2**（$n=6, k=1$）：`s` 周期 2 且 $s = t$，命中起点 $\{0,2,4\}$ → 好位移 $L \in \{0,4,2\}$，$m=3,\ m_0=1,\ m_1=2$；$p = 5$，$\mathit{sign}=-1$；$x_1 = (5-5)/6 = 0$（一步转不回自身），$y_1 = (5+1)/6 = 1$；答案 $= 1 \times 0 + 2 \times 1 = \mathbf{2}$ ✓——两个答案全部来自 $m_1$ 桶。
- **示例 3**（$n=4, k=3$）：$p = 27$，$\mathit{sign}=-1$，$y_3 = (27+1)/4 = 7$；$27$ 条序列中净位移 $\equiv 2$ 的恰 $7$ 条，答案 $\mathbf{7}$ ✓。

## 4. 算法细节

1. **KMP 匹配计数**：`fail` 建在模式 $t$ 上；扫 `text = s+s` 时若 `j == n` 表示完整命中，先按 `i - n + 1 <= n - 1` 判断是否计入 $m$，再 `j = fail[j-1]` 继续扫描。失配跳转保证总比较次数线性。
2. **只数一圈的原因**：$s+s$ 长 $2n$，匹配起点范围是 $[0, n]$；起点 $p$ 与 $p+n$ 对应同一个旋转（只有 $p=0$ 与 $p=n$ 这一对会同时出现），不截断会把 $s=t$ 情形数重复。
3. **为什么只要 $(m_0, m_1)$ 两个数**：闭式对好位移只区分「$L = 0$」与「$L \ne 0$」两档（引理 3），而 $L = 0$ 的好位移至多一个（$p = 0 \iff s = t$），其余全部共用 $y_k$——无需显式存好位移集合，更无需枚举周期。
4. **闭式的待定系数法**：由特征方程 $\lambda^2 - (n-2)\lambda - (n-1) = 0$（判别式 $n^2$）得两根 $n-1, -1$；$x_k = \alpha(n-1)^k + \beta(-1)^k$，用两个初值 $x_0 = 1$（空序列净位移为 0）、$x_1 = 0$（单步禁 0）解出 $\alpha, \beta$。初值的组合意义正是公式的记忆锚点。
5. **模意义除以 $n$**：$n < 10^9+7$ 且均为质数域元素，逆元存在，$\mathit{invN} = n^{\text{MOD}-2}$。整除性由 $n - 1 \equiv -1 \pmod n \Rightarrow (n-1)^k \equiv (-1)^k \pmod n$ 保证——两个分子都 $\equiv 0 \pmod n$，闭式在整数意义下本就整除，模逆算出的就是真值取模。
6. **负数与溢出**：C++ 中把 $\mathit{sign}$ 用 $\text{MOD}-1$ 表示 $-1$，或在运算后 `+MOD` 再取模；Python 的 `%` 对负数天然非负。$k \le 10^{15} < 2^{63}$ 用 `long long`；中间乘法先 `%` 再乘，最长链 $m_1 \cdot y \le 5\times10^5 \times 10^9 \approx 5\times10^{14}$ 也在 `long long` 安全域内。

## 5. 正确性证明

**引理 1（移位复合律）**：对任意 $a, b \in [1, n-1]$，$R_a(R_b(s)) = R_{(a+b) \bmod n}(s)$。

**证明**：设 $s' = R_b(s)$，则 $s'[i] = s[(i+b) \bmod n]$（长 $b$ 后缀前置 = 下标整体平移 $b$）。再作用 $R_a$ 后结果的第 $j$ 个字符为 $s'[(j+a) \bmod n] = s[(j+a+b) \bmod n]$；而 $R_{(a+b) \bmod n}(s)$ 的第 $j$ 个字符为 $s[(j+a+b) \bmod n]$，两者逐位相同。∎

**推论**：$k$ 次操作 $(l_1, \dots, l_k)$ 的结果串为 $R_L(s)$，$L = (\sum l_i) \bmod n$，与顺序无关；且操作方案与 $l$ 序列一一对应（$l \in [1, n-1]$ 内两个不同的 $l$ 即是两种不同选择）。

**引理 2（好位移与匹配起点双射）**：对 $L \in [0, n-1]$，$R_L(s) = t \iff t$ 在 $s+s$ 中起点 $p = (n - L) \bmod n \ge 0$ 处匹配，且只统计起点 $p \in [0, n-1]$ 时每个好位移恰被计数一次。

**证明**：$R_L(s) = s[n-L:] + s[:n-L]$（下标按 $\bmod n$ 理解），令 $p = (n-L) \bmod n \in [0, n-1]$，则 $R_L(s) = s[p:] + s[:p] = (s+s)[p : p+n]$，故 $R_L(s) = t \iff (s+s)[p:p+n] = t$。$p \mapsto L = (n-p) \bmod n$ 是 $[0, n-1]$ 上的双射，且 $L = 0 \iff p = 0$。$s+s$ 中匹配起点至多为 $n$，若 $p$ 与 $p+n$ 同时产生匹配仅当 $p = 0$（此时 $p + n = n$），二者对应同一 $L$，故限定 $p \le n-1$ 恰计数一次。∎

**引理 3（平移对称与两桶转移）**：记 $W_k(r)$ 为 $k$ 步、净位移 $\equiv r \pmod n$ 的序列数，则 $W_{k+1}(r) = \sum_{d \not\equiv r} W_k(d)$；且 $W_k(r)$ 对所有 $r \ne 0$ 取值相同，满足 $x_{k+1} = (n-1)\,y_k$、$y_{k+1} = x_k + (n-2)\,y_k$，初值 $(x_0, y_0) = (1, 0)$。

**证明**：序列 $(l_1, \dots, l_{k+1})$ 落在 $r$ 当且仅当前 $k$ 步净位移 $d$ 满足 $l_{k+1} \equiv r - d \pmod n$；该方程在 $[1, n-1]$ 中有解当且仅当 $d \not\equiv r$，有解时**恰一解**。求和即得转移式。归纳「非零同值」：基态 $W_0$ 满足；若 $W_k$ 满足，则 $W_{k+1}(r) = \big(x_k + (n-1)y_k\big) - W_k(r)$ 只依赖「$W_k(r)$ 是否为零桶」，故 $W_{k+1}$ 对一切 $r \ne 0$ 取同一值 $x_k + (n-2)y_k$，而 $W_{k+1}(0) = (n-1)y_k$。∎

**定理 1（闭式）**：$x_k = \dfrac{(n-1)^k + (n-1)(-1)^k}{n}$，$y_k = \dfrac{(n-1)^k - (-1)^k}{n}$，且两个分子均被 $n$ 整除。

**证明**：由引理 3，$(x_{k+1}, y_{k+1}) = M (x_k, y_k)$，$M = \begin{pmatrix} 0 & n-1 \\ 1 & n-2 \end{pmatrix}$。$M$ 的特征多项式 $\lambda^2 - (n-2)\lambda - (n-1) = (\lambda - (n-1))(\lambda + 1)$，两相异特征根 $n-1, -1$，故 $x_k = \alpha(n-1)^k + \beta(-1)^k$。代入 $x_0 = 1, x_1 = 0$ 解得 $\alpha = 1/n, \beta = (n-1)/n$；代入 $y_0 = 0, y_1 = 1$ 得 $y_k = \big((n-1)^k - (-1)^k\big)/n$。整除性：$n - 1 \equiv -1 \pmod n \Rightarrow (n-1)^k \equiv (-1)^k \pmod n$，故两个分子均 $\equiv 0 \pmod n$，闭式为整数。∎

**定理 2（答案公式）**：恰好 $k$ 次操作把 $s$ 变为 $t$ 的方案数为 $m_0 \cdot x_k + m_1 \cdot y_k$，其中 $m_0 = [s = t]$，$m_1 = m - m_0$，$m$ 为 $t$ 在 $s+s$ 中起点 $\le n-1$ 的匹配数（$m = 0$ 时答案为 $0$）。

**证明**：由引理 1 的推论，每个方案（$l$ 序列）恰有一个净位移 $L$，其结果串为 $R_L(s)$；由引理 2，$R_L(s) = t$ 当且仅当 $L$ 是好位移，且好位移与「起点 $\le n-1$ 的匹配」一一对应。不同好位移对应的序列集合两两不交（净位移互异），全体之并为所求方案集。于是答案 $= \sum_{\text{好位移 } L} W_k(L)$。由引理 3，好位移中 $L = 0$ 者贡献 $x_k$、其余每个贡献 $y_k$；而 $L = 0$ 是好位移 $\iff p = 0 \iff s = t$，至多一个，故求和即 $m_0 x_k + m_1 y_k$。∎

> 💡 上述模型与闭式已用**操作序列全枚举暴力**对拍验证：字母表 $\{a, b\}$、$n \in [2, 5]$ 的全部 $(s, t)$ 组合 × $k \in [1, 4]$ 共 **5440 组**，暴力模拟与闭式 / 取模实现输出全部一致；文中示例 3、4 的答案同样经暴力复核。

## 6. 复杂度分析

- **时间复杂度**：$O(n + \log k)$。KMP 建表加扫描共处理长度 $2n$ 的文本，约 $2 \times 10^6$ 次字符比较；快速幂两次（$(n-1)^k$ 与 $n^{\text{MOD}-2}$）各约 $50$ 次乘法。相比之下：暴力二 $O(kn)$ 是 $5 \times 10^{20}$，暴力三 $O(n^3 \log k)$ 约 $10^{22}$——**对称性降维**把指数级直接压到线性。
- **空间复杂度**：$O(n)$。`fail` 数组 $n$ 个 `int`，拼接文本 `s+s` 共 $2n$ 字符；闭式部分仅 $O(1)$。

```cpp
class Solution {
    static constexpr long long MOD = 1'000'000'007;

    long long qpow(long long a, long long e) {
        long long r = 1;
        a %= MOD;
        while (e) {
            if (e & 1) r = r * a % MOD;
            a = a * a % MOD;
            e >>= 1;
        }
        return r;
    }

public:
    int numberOfWays(string s, string t, long long k) {
        int n = s.size();
        string text = s + s;                     // t 是 s 的旋转 ⟺ t 在 s+s 中出现

        vector<int> fail(n);                     // KMP 失配数组（建在模式 t 上）
        for (int i = 1, j = 0; i < n; i++) {
            while (j && t[i] != t[j]) j = fail[j - 1];
            if (t[i] == t[j]) j++;
            fail[i] = j;
        }

        long long m = 0;                         // 好位移个数 = 起点 <= n-1 的匹配数
        for (int i = 0, j = 0; i < 2 * n; i++) {
            while (j && text[i] != t[j]) j = fail[j - 1];
            if (text[i] == t[j]) j++;
            if (j == n) {
                if (i - n + 1 <= n - 1) m++;     // 起点 n 与起点 0 是同一旋转，只数一圈
                j = fail[j - 1];
            }
        }
        if (m == 0) return 0;                    // t 不是 s 的任何旋转

        long long m0 = (s == t) ? 1 : 0;         // L = 0 的好位移（至多 1 个）
        long long m1 = m - m0;                   // 其余好位移共用 y_k

        long long p = qpow(n - 1, k);            // (n-1)^k
        long long sign = (k & 1) ? MOD - 1 : 1;  // (-1)^k 的模表示
        long long invN = qpow(n, MOD - 2);      // n 的逆元（n < MOD 保证存在）

        long long x = (p + sign * (n - 1) % MOD) % MOD * invN % MOD;  // W_k(0)
        long long y = (p - sign + MOD) % MOD * invN % MOD;             // W_k(L != 0)
        return (m0 * x + m1 % MOD * y) % MOD;
    }
};
```

### Python

```python
class Solution:
    def numberOfWays(self, s: str, t: str, k: int) -> int:
        MOD = 10 ** 9 + 7
        n = len(s)
        text = s + s                          # t 是 s 的旋转 ⟺ t 在 s+s 中出现

        fail = [0] * n                        # KMP 失配数组（建在模式 t 上）
        j = 0
        for i in range(1, n):
            while j and t[i] != t[j]:
                j = fail[j - 1]
            if t[i] == t[j]:
                j += 1
            fail[i] = j

        m = 0                                 # 好位移个数 = 起点 <= n-1 的匹配数
        j = 0
        for i, ch in enumerate(text):
            while j and ch != t[j]:
                j = fail[j - 1]
            if ch == t[j]:
                j += 1
            if j == n:
                if i - n + 1 <= n - 1:        # 起点 n 与起点 0 是同一旋转，只数一圈
                    m += 1
                j = fail[j - 1]
        if m == 0:
            return 0                          # t 不是 s 的任何旋转

        m0 = 1 if s == t else 0               # L = 0 的好位移（至多 1 个）
        m1 = m - m0                           # 其余好位移共用 y_k

        sign = -1 if k % 2 else 1             # (-1)^k
        inv_n = pow(n, MOD - 2, MOD)          # n 的逆元（n < MOD 保证存在）
        p = pow(n - 1, k, MOD)                # (n-1)^k
        x = (p + sign * (n - 1)) * inv_n % MOD  # W_k(0)，负数 % 天然非负
        y = (p - sign) * inv_n % MOD            # W_k(L != 0)
        return (m0 * x + m1 * y) % MOD
```

> 💡 两版结构一致：**KMP 数好位移 + 分桶 + 闭式**。C++ 把 $-1$ 表示成 `MOD-1`，让 `sign * (n-1)` 与 `p - sign` 走同一套非负取模；Python 的 `%` 对负数天然返回非负，直接写即可。除以 $n$ 一律用费马小定理逆元——定理 1 已证分子被 $n$ 整除，模逆结果即真值取模。

## 8. 边界情况与易错点

1. **$t$ 不是 $s$ 的旋转**：$m = 0$ 直接返回 $0$（此时 $m_0 = m_1 = 0$，公式本身也给出 0，但显式早退更清晰，也省去后续幂运算）。
2. **只数一圈**：匹配起点必须限制在 $[0, n-1]$。$s = t$ 时 `s+s` 会在起点 $0$ 与起点 $n$ 各命中一次，不截断会把偏移 $0$ 数两次，$m$ 虚增、$m_0/m_1$ 关系错乱。
3. **$s = t$ 且有小周期（本题最大的坑）**：答案未必来自「转回自身」。示例 2 的答案 2 **全部来自 $m_1$ 桶**（$x_1 = 0$，$y_1 = 1$）——只算「最近的那个位移」或只算 $x_k$ 会得 0，漏掉一半以上。
4. **单步禁 0**：转移矩阵是 $J - I$（无自环的完全图邻接矩阵），不是全 1 矩阵 $J$。若误把「每步可以不动」纳入，转移塌缩成平凡形式（所有位移 $n^{k-1}$），观察三的 $\pm(-1)^k$ 修正项全部消失。
5. **$k$ 的奇偶决定符号**：$y_k$ 分子在 $k$ 偶时是 $(n-1)^k - 1$、$k$ 奇时是 $(n-1)^k + 1$。写反了示例 1（$k=2$）会得到 $(9+1)/4$ 这类非整数，务必用 $k=1$、$k=2$ 两组小值回验。
6. **C++ 负数取模**：`p - sign`、`sign * (n-1)` 都可能产生负数，要 `+ MOD` 再 `% MOD`（或用 `MOD-1` 表示 $-1$）；Python 的 `%` 天然非负，无此坑。
7. **溢出**：$k \le 10^{15}$ 必须 `long long`；$(n-1)^k$ 必须快速幂；乘法链中先取模再乘。最长的单步乘法 $m_1 \cdot y \le 5\times10^5 \times (10^9+6) \approx 5\times10^{14}$，仍在 `long long` 内，但取模是防呆的好习惯。
8. **别赌 `find` 的最坏复杂度**：$n = 5\times10^5$ 时朴素匹配最坏 $O(n^2) = 2.5\times10^{11}$ 会 TLE，比赛里老老实实手写 KMP / Z 函数。
9. **「方案」按 $l$ 序列计数**：两个不同的 $l$（如示例 2 的 2 与 4）即使产生相同字符串也算两种；反过来同一个序列只计一次——计数对象是操作序列，不是字符串轨迹。
10. **$n = 2$ 退化自检**：$n - 1 = 1$，闭式给出 $x_k = (1+(-1)^k)/2$——每步被迫交换，「ab」经偶数步回到自身、奇数步变成「ba」，可作快速 sanity check。
