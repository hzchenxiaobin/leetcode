# LeetCode 老鼠和奶酪 题解

## 1. 题目概述

- **标题 / 题号**：老鼠和奶酪（#2611，medium）
- **链接**：https://leetcode.cn/problems/mice-and-cheese/
- **来源**：LeetCode 第 339 场周赛 Q3
- **难度**：中等
- **标签**：贪心、数组、排序、堆（优先队列）

**题意**：有两只老鼠和 `n` 块奶酪，每块奶酪**恰被其中一只**吃掉：第 `i` 块若被第一只老鼠吃掉得 `reward1[i]` 分，被第二只老鼠吃掉得 `reward2[i]` 分。要求**第一只老鼠恰好吃掉 `k` 块**，返回最大总得分。

**约束**：

- $1 \le n = \text{reward1.length} = \text{reward2.length} \le 10^5$
- $1 \le \text{reward1}[i], \text{reward2}[i] \le 1000$
- $0 \le k \le n$

> 💡 关键信号：「每块二选一 + 恰好选 k 个」是标准的**基线 + 增量**结构——先固定一个默认归属，问题就化成「按增量 $\Delta$ 排序取前 k」。$n \le 10^5$ 说明 $O(n \log n)$ 稳过，任何 $O(n^2)$ 级暴力都不可行。

## 2. 示例

**示例 1**

```text
输入：reward1 = [1,1,3,4], reward2 = [4,4,1,1], k = 2
输出：15
解释：第一只老鼠吃掉第 2、3 块奶酪（得 3 + 4），第二只老鼠吃掉第 0、1 块（得 4 + 4）。
      总得分 = 3 + 4 + 4 + 4 = 15，为最大得分。
```

**示例 2**

```text
输入：reward1 = [1,1], reward2 = [1,1], k = 2
输出：2
解释：第一只老鼠吃掉全部两块奶酪，第二只老鼠不吃任何奶酪，总得分 = 1 + 1 = 2。
```

**示例 3（补充：Δ 全为负也要凑满 k 块）**

```text
输入：reward1 = [1,2], reward2 = [5,6], k = 1
输出：7
解释：两块奶酪的 Δ 均为 −4（换给老鼠1 都亏），但「恰好 1 块」必须满足：
      老鼠1 吃第 0 块得 1 + 6 = 7，或吃第 1 块得 2 + 5 = 7，怎么选都是 7。
```

## 3. 解题思路

### 3.1 暴力思路

朴素做法是枚举大小为 $k$ 的子集 $S$ 作为老鼠1 的食谱，得分为 $\sum_{i \in S} \text{reward1}[i] + \sum_{i \notin S} \text{reward2}[i]$。组合数 $\binom{10^5}{5 \times 10^4}$ 是天文数字，不可行。

还有两个「直觉贪心」陷阱：

- **每块独立取 $\max(\text{reward1}[i], \text{reward2}[i])$**：完全忽略「恰好 k 块」的配额约束，必然错误；
- **按 $\text{reward1}$ 降序取前 k 块给老鼠1**：反例 `reward1 = [5,6]`，`reward2 = [0,4]`，`k = 1`——按 reward1 最大选第 1 块得 $6 + 0 = 6$，而最优是选第 0 块得 $5 + 4 = 9$。

两个陷阱的共同病灶：**缺少一个把「给谁吃」统一起来的可比度量**。下面的增量 $\Delta$ 正是这个度量。

### 3.2 核心观察：基线 + 增量 Δ，取前 k 大

![基线全给老鼠2 + 换食增量Δ的贪心观察](images/wc339_q3_delta_concept.svg)

先假定**所有奶酪都归老鼠2**，得到基线分 $\text{base} = \sum_i \text{reward2}[i]$。由于老鼠1 必须恰好吃 $k$ 块，等价于要从基线中**换出 $k$ 块**给老鼠1。把第 $i$ 块换给老鼠1，得分变化量为

$$
\Delta_i = \text{reward1}[i] - \text{reward2}[i].
$$

- $\Delta_i > 0$：换给老鼠1 赚（这块老鼠1 吃分更高）；
- $\Delta_i < 0$：换给老鼠1 亏，但配额必须凑满 $k$ 个，只能挑亏得最少的。

**为什么能直接排序取前 k**？总得分是各块得分之和，**每块奶酪的选择相互独立、没有交叉项**。于是任意换入集 $S$（$|S| = k$）的总分为

$$
T(S) = \underbrace{\sum_i \text{reward2}[i]}_{\text{base}} + \sum_{i \in S} \Delta_i,
$$

最大化总分 ⇔ 最大化 $\sum_{i \in S} \Delta_i$ ⇔ **取 $\Delta$ 最大的 $k$ 块**。「选哪 k 块」这个组合问题被彻底化成一次排序。

### 3.3 算法流程

![流程：求和→求Δ→降序排序→取前k→相加](images/wc339_q3_algorithm_flow.svg)

1. 一遍扫描求 $\text{base} = \sum \text{reward2}$；
2. 同时构造增量数组 $\Delta_i = \text{reward1}[i] - \text{reward2}[i]$；
3. 将 $\Delta$ 从大到小排序；
4. 前 $k$ 个 $\Delta$ 求和得 gain（负的也要取满）；
5. 返回 $\text{base} + \text{gain}$。

> 💡 排序并非唯一选择：只需「前 k 大之和」时，C++ 可用 `nth_element`（平均 $O(n)$）或大小为 $k$ 的小根堆（$O(n \log k)$），见 §4。

### 3.4 示例演算

![示例1的逐步演算：求base、求Δ、排序取前k、汇总](images/wc339_q3_example_walkthrough.svg)

以**示例 1**（`reward1=[1,1,3,4]`，`reward2=[4,4,1,1]`，`k=2`）为例：

| 步骤 | 计算 | 结果 |
|:----:|------|:----:|
| ① 基线 | base = 4 + 4 + 1 + 1 | 10 |
| ② 增量 | Δ = [1−4, 1−4, 3−1, 4−1] | [−3, −3, +2, +3] |
| ③ 降序 | [−3, −3, +2, +3] → 排序 | [+3, +2, −3, −3] |
| ④ 前 k=2 个 | gain = 3 + 2 | 5 |
| ⑤ 汇总 | 10 + 5 | **15** ✓ |

对应分配：$\Delta$ 最大的两块是第 3、2 块，给老鼠1；其余第 0、1 块留给老鼠2 → $\text{reward1}[3] + \text{reward1}[2] + \text{reward2}[0] + \text{reward2}[1] = 4 + 3 + 4 + 4 = 15$，与公式一致。

## 4. 算法细节

1. **Δ 可正可负可为零**：排序后**无条件取前 k 个**。「恰好 k 块」是硬约束，不是「至多」，负增量也必须凑满（见示例 3）。
2. **求和与构造一趟完成**：`base` 累加与 `delta[i]` 计算可合并在同一个循环里，常数更小。
3. **排序方向**：从大到小取前 k（等价于从小到大取后 k）。方向写反会拿到**最差**的 k 个——样例 1 会算出 $10 + (-3) + (-3) = 4$。
4. **只要前 k 大的「和」**：不必真正排好序。C++ 用 `nth_element` 平均 $O(n)$ 把前 k 大挪到数组前段；或维护一个大小为 k 的小根堆，扫描一遍，$O(n \log k)$。Python 的 `sorted` / `heapq.nlargest` 皆可。
5. **决策只取决于差值**：第 $i$ 块给谁，与 $\text{reward1}[i]$、$\text{reward2}[i]$ 的绝对大小无关，只由 $\Delta_i$ 是否进入前 k 大决定。
6. **溢出**：总分上界 $10^5 \times 1000 = 10^8 < 2^{31} - 1$，`int` 恰好安全；但若值域放大到 $10^9$，必须 `long long`（Python 无此忧）。比赛时默认上 `long long` 是更稳的习惯。

## 5. 正确性证明

**引理 1（分解）**：设 $S \subseteq \{0, 1, \dots, n-1\}$，$|S| = k$，为老鼠1 吃的奶酪下标集，则总得分

$$
T(S) = \sum_{i} \text{reward2}[i] + \sum_{i \in S} \Delta_i.
$$

**证明**：每块奶酪恰被一只老鼠吃掉：$i \in S$ 得 $\text{reward1}[i]$，$i \notin S$ 得 $\text{reward2}[i]$。于是

$$
T(S) = \sum_{i \in S} \text{reward1}[i] + \sum_{i \notin S} \text{reward2}[i] = \sum_{i} \text{reward2}[i] + \sum_{i \in S} \bigl(\text{reward1}[i] - \text{reward2}[i]\bigr). \;\blacksquare
$$

**引理 2（上界）**：对任意 $|S| = k$，有 $\sum_{i \in S} \Delta_i \le \sum_{t=1}^{k} \delta_t$，其中 $\delta_1 \ge \delta_2 \ge \dots \ge \delta_n$ 是全体 $\Delta$ 值的降序排列。

**证明**：把 $S$ 中 $k$ 个 $\Delta$ 值降序排列为 $s_1 \ge s_2 \ge \dots \ge s_k$。$s_t$ 是**子集** $S$ 的第 $t$ 大，$\delta_t$ 是**全体**的第 $t$ 大，而 $S$ 的元素取自全体，故对每个 $t$ 都有 $s_t \le \delta_t$（子集的第 $t$ 大不超过全体的第 $t$ 大）。逐位求和即得。∎

**定理**：把 $\Delta$ 最大的 $k$ 块给老鼠1，总得分最大，且最大值为 $\sum_i \text{reward2}[i] + \sum_{t=1}^{k} \delta_t$。

**证明**：贪心集 $G$ 恰由 $\delta_1, \dots, \delta_k$ 对应的下标组成，故 $\sum_{i \in G} \Delta_i = \sum_{t=1}^{k} \delta_t$，达到引理 2 的上界；结合引理 1，任意可行方案 $T(S) \le T(G)$，贪心最优。∎

> 💡 亦可**交换论证**：若方案 $S$ 漏掉某个 $\Delta_j > \Delta_i$（$j \notin S$，$i \in S$），则 $S' = S - \{i\} + \{j\}$ 得分严格更优；反复交换说明最优解必含 top-k。两种证法殊途同归。

## 6. 复杂度分析

- **时间复杂度**：$O(n \log n)$，排序主导；求和与取前 k 求和均为 $O(n)$。若用 `nth_element` 平均可降到 $O(n)$，大小为 $k$ 的小根堆为 $O(n \log k)$——$n \le 10^5$ 时三者都能通过，排序写法最不易错。
- **空间复杂度**：$O(n)$，增量数组 $\Delta$。堆写法可压到 $O(k)$；C++ 中若追求极致也可把 $\Delta$ 就地写回 `reward1` 复用内存。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int miceAndCheese(vector<int>& reward1, vector<int>& reward2, int k) {
        int n = reward1.size();
        long long base = 0;
        vector<int> delta(n);
        for (int i = 0; i < n; ++i) {          // 一趟：基线求和 + 增量构造
            base += reward2[i];
            delta[i] = reward1[i] - reward2[i];
        }
        sort(delta.begin(), delta.end(), greater<int>());
        for (int i = 0; i < k; ++i)            // 恰好 k 块：负 Δ 也要取满
            base += delta[i];
        return base;
    }
};
```

### Python

```python
class Solution:
    def miceAndCheese(self, reward1: List[int], reward2: List[int], k: int) -> int:
        base = sum(reward2)
        delta = sorted((a - b for a, b in zip(reward1, reward2)), reverse=True)
        return base + sum(delta[:k])
```

## 8. 边界情况与易错点

1. **k = 0**：答案 = $\sum \text{reward2}$，取前 k 的循环不执行，自然处理。
2. **k = n**：答案 = $\sum \text{reward1}$，$\Delta$ 全部取入。
3. **「恰好」不是「至多」**：$\Delta$ 为负也必须凑满 k 块，只能挑负得最少的（示例 3 中两块 Δ 都是 −4，取哪块都行）。
4. **排序方向写反**：拿到最差的 k 个，样例 1 输出 $10 + (-3) + (-3) = 4$ 而非 15。
5. **别按单个数组排序**：决策只看差值 $\Delta_i$。按 reward1 降序取前 k 的反例见 §3.1（`[5,6]/[0,4]`，得 6 而最优 9）；按 reward2 的大小分配同理可构造反例。
6. **并列 Δ**：任取其一，总得分相同，无需去重或特殊处理。
7. **溢出**：本题 $10^8$ 上界 `int` 安全；值域加强到 $10^9$ 时 C++ 必须 `long long`（$10^{14}$ 超 int32），比赛默认 `long long` 更稳。
8. **读清归属规则**：每块奶酪**恰被一只**吃掉（不许两鼠分食、也不许空置）——引理 1 的分解正是建立在这条上；若规则改成「可以都不吃」，基线建模需相应调整。
