# LeetCode 最少翻转操作数 题解

## 1. 题目概述

- **标题 / 题号**：最少翻转操作数（#2612，hard）
- **链接**：https://leetcode.cn/problems/minimum-reverse-operations/
- **来源**：LeetCode 第 339 场周赛 Q4
- **难度**：困难
- **标签**：广度优先搜索、并查集、有序集合、数组、哈希表

**题意**：给定长度为 $n$ 的数组，除位置 $p$ 是 1 外其余全是 0。每次操作可以任选一个**大小为 $k$ 的子数组**反转，但 1 不能落在 `banned` 中的位置上。对每个位置 $i$ 输出：把 1 送到 $i$ 的最少操作次数；无法送达输出 $-1$（banned 中的位置天然为 $-1$）。

**约束**：

- $1 \le n \le 10^5$
- $0 \le p \le n-1$
- $0 \le \text{banned.length} \le n-1$，$0 \le \text{banned}[i] \le n-1$，值互不相同且均不为 $p$
- $1 \le k \le n$

> 💡 关键信号：「最少操作次数 + 每步代价相同」= **无权图单源最短路 = BFS**。真正的难点在规模：每个位置的邻居有 $O(n)$ 个，朴素 BFS 总边数 $O(n^2)$，在 $n \le 10^5$ 下必超时。突破口是发现「一步可达位置构成**同一奇偶类内公差 2 的连续段**」，再用并查集把邻居枚举摊还到近线性。

## 2. 示例

**示例 1**

```text
输入：n = 4, p = 0, banned = [1,2], k = 4
输出：[0,-1,-1,1]
解释：1 起始在位置 0，ans[0] = 0；位置 1、2 在 banned 中，为 -1。
      反转整个长度为 4 的数组，1 从 0 镜像到位置 3（落点 3 不在 banned 中，合法），
      ans[3] = 1。
```

**示例 2**

```text
输入：n = 5, p = 0, banned = [2,4], k = 3
输出：[0,-1,-1,-1,-1]
解释：唯一能覆盖 1（在位置 0）的窗口是 [0,2]，反转后 1 会落到位置 2，
      而 2 在 banned 中，操作被禁止——1 一步也动不了，其余位置全部 -1。
```

**示例 3**

```text
输入：n = 4, p = 2, banned = [0,1,3], k = 1
输出：[-1,-1,0,-1]
解释：k = 1 时窗口就是单点，反转不改变任何位置，1 永远停在 2。
```

## 3. 解题思路

### 3.1 暴力思路

把每个非 banned 位置看成一个节点：若存在一次合法翻转把 1 从 $i$ 挪到 $t$（$t$ 非 banned），就连边 $i \to t$；所求即从 $p$ 出发的 BFS 最短路。

问题在边数：位置 $i$ 的合法窗口起点 $s$ 最多有 $\min(i, n-k) - \max(0, i-k+1) + 1 = O(\min(k, n-k))$ 个，$n = 10^5$ 时总边数约 $10^9 \sim 10^{10}$ 级别——显式建图连内存都放不下，边枚举边 BFS 也一样超时。优化必须落在「**邻居集合的结构**」上，而不是换搜索方式。

### 3.2 核心观察：翻转即镜像，落点是公差 2 的等差数列

![翻转=窗口内镜像，落点集是公差2的等差数列](images/wc339_q4_reverse_target_concept.svg)

反转起点为 $s$、长度为 $k$ 的窗口 $[s, s+k-1]$，本质是窗口内位置的**镜像**：位置 $x$ 被翻到 $s + (s+k-1) - x$（首尾互换、向中心配对）。设 1 位于 $i$，则窗口必须同时满足 $s \le i \le s+k-1$（覆盖 1）与 $0 \le s \le n-k$（不越界），翻转后 1 落到

$$
t = s + (s + k - 1) - i = 2s + k - 1 - i.
$$

合法起点构成连续区间 $[s_{lo}, s_{hi}] = [\max(0,\, i-k+1),\ \min(i,\, n-k)]$，而 $s$ 每 $+1$，$t$ 恰好 $+2$，于是**一步可达集**是

$$
\{\, t \mid t_{\min} \le t \le t_{\max},\ t \equiv k-1-i \pmod 2 \,\},\qquad
t_{\min} = 2s_{lo} + k - 1 - i,\quad t_{\max} = 2s_{hi} + k - 1 - i,
$$

再剔除 banned。奇偶性由公式直接读出，与 $s$ 无关：

- **$k$ 为奇数**：$t \equiv i \pmod 2$，奇偶**不变**——1 永远只能待在与 $p$ 同奇偶的位置类里；
- **$k$ 为偶数**：$t \not\equiv i \pmod 2$，每步**翻转**奇偶——BFS 第 $d$ 层的位置奇偶恰为 $(p + d) \bmod 2$。

> 💡 一句话：**邻居 = 一个奇偶类内的连续段（步长 2）减去 banned 与已访问**。「区间 + 删除」正是并查集「下一个未访问」的招牌场景。

### 3.3 优化：BFS + 双奇偶类并查集「下一个未访问」

![算法流程：BFS + 并查集摊还枚举邻居](images/wc339_q4_bfs_dsu_flow.svg)

BFS 中每个位置至多入队一次，于是把「枚举邻居」改造成「枚举后即删除」：

1. 按**奇偶**把 $0 \sim n-1$ 分成两个类。位置 $x$ 写成 $x = 2j + c$（$c = x \bmod 2$ 为类号，$j = x \gg 1$ 为类内压缩下标），两个类各配一个「候选集」；
2. **预删除**所有 banned 位置与 $p$ 本身，$ans[p] = 0$，$p$ 入队；
3. 出队 $i$ 时算出落点区间 $[t_{\min}, t_{\max}]$ 与目标类 $c$，在类 $c$ 的候选集里从 $\ge t_{\min}$ 的第一个存活点扫到 $t_{\max}$：每个存活点赋 $ans = d+1$、入队、**从候选集删除**；
4. 队列空即结束，未赋值的位置保持 $-1$。

候选集用「**下一个未访问**」并查集实现：数组 `nxt[c]` 初始 `nxt[c][j] = j`，`find(c, j)` 沿链找到 $\ge j$ 的第一个未被删除的压缩下标（路径减半压缩）；删除 $j$ 就是 `nxt[c][j] = j + 1`。**每个位置至多被删除一次**，所以所有 find 的总代价是近线性的 $O(n\,\alpha(n))$。

> ⚠️ 若不用并查集、出队时线性扫区间，最坏每次 $O(n)$、总计 $O(n^2)$，一样超时；摊还的来源正是「删过的点永远不再碰」。替代实现：每个奇偶类一个 `std::set`（或 Python `SortedList`），`lower_bound(t_min)` 起边查边 `erase`，总复杂度 $O(n \log n)$，思路相同、常数更大。

### 3.4 示例演算

![示例演算：n=8, p=1, banned=[4], k=4 的 BFS 全过程](images/wc339_q4_example_walkthrough.svg)

官方三个示例规模太小，补一个同时覆盖「k 偶的奇偶翻转、banned 跳过、边界不可达」三个现象的例子：$n = 8$，$p = 1$，$\text{banned} = [4]$，$k = 4$。

| 出队 $i$ | $s \in [s_{lo}, s_{hi}]$ | 一步落点集 | 新入队 |
|:--------:|:------------------------:|:-------------------:|:----------------------|
| 1 | $[0, 1]$ | $\{2, 4\}$ | 2（4 是 banned） |
| 2 | $[0, 2]$ | $\{1, 3, 5\}$ | 3, 5 |
| 3 | $[0, 3]$ | $\{0, 2, 4, 6\}$ | 0, 6（2 已访问） |
| 5 | $[2, 4]$ | $\{2, 4, 6\}$ | —（均已处理） |
| 0 | $[0, 0]$ | $\{3\}$ | — |
| 6 | $[3, 4]$ | $\{3, 5\}$ | — |

- $k = 4$ 为偶数 ⇒ 奇偶逐层翻转：$d=0$ 奇 $\{1\}$ → $d=1$ 偶 $\{2\}$ → $d=2$ 奇 $\{3,5\}$ → $d=3$ 偶 $\{0,6\}$；
- 位置 4 在 banned 中，开局即从候选集删除，永远为 $-1$；
- 位置 7 不可达：要落到 7 只能从偶数源点出发，而 $0/2$ 的镜像窗口根本不含自己、$6$ 的窗口越界、$4$ 被 banned，故 $ans[7] = -1$。

最终 $ans = [3, 0, 1, 2, -1, 2, 3, -1]$。

## 4. 算法细节

1. **压缩下标与哨兵**：位置 $x = 2j + c$，类号 $c = x \bmod 2$，压缩下标 $j = x \gg 1$。两个类各一个 `nxt` 数组，大小取 $n/2 + 2$——多出的 1 格是**哨兵**：哨兵永不被删除，`find` 一定能落在固定点上终止；若按 $n/2 + 1$ 开数组，删除最大压缩下标时 `nxt[j] = j + 1` 就越界了。
2. **find 用路径减半**（path halving）：`while nxt[j] != j: nxt[j] = nxt[nxt[j]]; j = nxt[j]`。两趟指针跳跃即可把长链压短，摊还近 $O(1)$，且是纯迭代实现，无递归栈风险。
3. **remove 的语义是「跳过我」**：`nxt[c][j] = j + 1` 之后，任何 `find` 撞上 $j$ 都会顺着链滑到 $j+1$ 及以后，等价于把 $j$ 从候选集删除，无需真正清空内存。
4. **预删除 banned 与 $p$**：banned 位置永远不可达、$p$ 是深度 0 的起点，都在 BFS 前移出候选集，主循环内就不再需要任何合法性特判。题目保证 $p \notin \text{banned}$，$ans[p] = 0$ 无冲突。
5. **区间公式的三个边界**（引理 2 可证，实现时无需特判）：$k \le n$ 保证 $s_{lo} \le s_{hi}$ 恒成立；$t_{\min} \ge 0$；$t_{\max} \le n-1$。压缩下标自然落在数组界内。
6. **深度就地传递**：出队时 $d = ans[i] + 1$，`ans` 本身就是距离数组，不必另存。
7. **同层区间重叠无害**：多个前驱的落点区间可以互相覆盖，每个位置只会被**第一个**扫到它的前驱删除并赋值，之后的 `find` 自动跳过——这正是「每个点至多处理一次」的摊还来源；先到者的距离不小于后到者，跳过不丢解。
8. **替代实现**：每个奇偶类一个有序集合（C++ `std::set`，Python `sortedcontainers.SortedList`，LeetCode 环境已内置），从 `lower_bound(t_min)` 起边查边删，$O(n \log n)$，正确性论证完全相同；并查集版无 STL 依赖、常数更小。

## 5. 正确性证明

**引理 1（镜像公式）**：反转窗口 $[s, s+k-1]$ 把位于 $i$（$s \le i \le s+k-1$）的 1 送到 $t = 2s + k - 1 - i$。

**证明**：反转即窗口内的对换 $\sigma(x) = s + (s+k-1) - x$：首尾配对 $\sigma(s) = s+k-1$、$\sigma(s+1) = s+k-2$、……向中心对称，且 $\sigma$ 是对合（$\sigma(\sigma(x)) = x$），故恰为反转。代入 $x = i$ 即得。∎

**引理 2（一步可达集）**：设 $s_{lo} = \max(0, i-k+1)$，$s_{hi} = \min(i, n-k)$。从 $i$ 出发经一次合法操作可达的位置恰为

$$
N(i) = \{\, t \mid t_{\min} \le t \le t_{\max},\ t \equiv k-1-i \pmod 2,\ t \notin \text{banned} \,\},
$$

其中 $t_{\min} = 2s_{lo} + k - 1 - i$，$t_{\max} = 2s_{hi} + k - 1 - i$；且 $s_{lo} \le s_{hi}$、$0 \le t_{\min} \le t_{\max} \le n-1$。

**证明**：一次操作 = 选一个窗口 $[s, s+k-1]$，合法当且仅当（a）窗口在界内：$0 \le s \le n-k$；（b）窗口覆盖 1：$s \le i \le s+k-1$；（c）落点非 banned。前两条即 $s \in [s_{lo}, s_{hi}]$，由引理 1 落点 $t = 2s + k - 1 - i$。映射 $s \mapsto t$ 是 $[s_{lo}, s_{hi}]$ 到 $\{t_{\min}, t_{\min}+2, \dots, t_{\max}\}$ 的双射（$s$ 每加 1，$t$ 加 2），故可达集恰为该等差数列去掉 banned。界的验证：若 $s_{lo} = i-k+1 > 0$ 则 $t_{\min} = i-k+1 \ge 0$，否则 $s_{lo}=0$ 时 $i \le k-1$，$t_{\min} = k-1-i \ge 0$；若 $s_{hi} = i \le n-k$ 则 $t_{\max} = i+k-1 \le n-1$，否则 $s_{hi} = n-k$ 时 $i \ge n-k+1$，$t_{\max} = 2n-k-1-i \le n-2$。$s_{lo} \le s_{hi}$：若 $i \le n-k$，则 $s_{hi} = i \ge \max(0, i-k+1) = s_{lo}$；若 $i > n-k$，则 $s_{hi} = n-k \ge i-k+1 \ge \max(0, i-k+1)$ 中的 $i-k+1$，且 $n-k \ge 0$。∎

**引理 3（奇偶不变量）**：$k$ 奇时任意操作序列保持 1 的位置奇偶不变；$k$ 偶时每次操作翻转奇偶，故经 $d$ 步后位置奇偶为 $(p+d) \bmod 2$。

**证明**：由引理 1，$t = 2s + (k-1) - i \equiv k-1-i \pmod 2$。$k$ 奇时 $k-1$ 为偶，$t \equiv i$；$k$ 偶时 $k-1$ 为奇，$t \equiv i+1$。对操作步数归纳即得。∎

**定理**：算法输出的 `ans[i]` 恰为把 1 送到 $i$ 的最少操作次数；不可达（含 banned）为 $-1$。

**证明**：构造状态图 $G$：节点为非 banned 位置，边 $i \to t$ 当且仅当 $t \in N(i)$（引理 2）。所求即 $G$ 上从 $p$ 到各点的最短路长。分两个方向证：

（可行性，$dist(i) \le ans[i]$）对 $ans[i]$ 的赋值过程归纳：$ans[p] = 0$ 对应空路径；每个被赋值的位置 $x$ 都是在某个 $i$ 出队时从候选集中取出（即 $x \in N(i)$，边真实存在），且 $ans[x] = ans[i] + 1$。沿 BFS 的赋值父链回溯到 $p$，得到一条长度恰为 $ans[x]$ 的合法操作序列，故真实最短路 $dist(x) \le ans[x]$。banned 位置从未入候选集，保持 $-1$，与题意一致。

（最优性，$ans[i] \le dist(i)$）对 $dist$ 归纳：$dist(p) = 0 = ans[p]$。设 $x$ 满足 $ans[x] \le dist(x)$ 且 $x$ 已被赋值（则会入队）。任取 $x$ 的最短路上最后一步 $y \to x$（$dist(x) = dist(y) + 1$，$x \in N(y)$）：当 $y$ 出队时扫描 $y$ 的落点区间，若 $x$ 仍在候选集中则被赋值 $ans[x] \le ans[y] + 1 \le dist(y) + 1 = dist(x)$；若 $x$ 已被更早出队的 $y'$ 删除，则 $ans[x] = ans[y'] + 1$，而队列距离单调不减（出队按 $ans$ 非降，新赋值恰为当前层 $+1$），$ans[y'] \le ans[y]$，同样得 $ans[x] \le dist(x)$。∎

> 💡 引理 3 也能单独用来 $O(1)$ 排除一半位置：$k$ 奇时与 $p$ 异奇偶的位置全部 $-1$，可作为输出的快速自查。

## 6. 复杂度分析

- **时间复杂度**：$O\bigl((n + |\text{banned}|) \cdot \alpha(n)\bigr) \approx O(n)$。初始化为 $O(n)$；主循环中每个位置至多出队一次，每次出队做一次初始 `find` 与一次越界 `find`；每个位置至多被 `remove` 一次，每次成功入队伴随一次 `find(j+1)`——所有 `find` 的总次数为 $O(n)$ 量级，路径减半使其摊还近常数。有序集合版本为 $O(n \log n)$。
- **空间复杂度**：$O(n)$。两个并查集数组共 $n + O(1)$ 个 int、答案数组与队列各 $O(n)$。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    vector<int> minReverseOperations(int n, int p, vector<int>& banned, int k) {
        vector<int> ans(n, -1);
        int m = n / 2 + 2;                            // 每个奇偶类的并查集大小（末位哨兵）
        vector<vector<int>> nxt(2, vector<int>(m));
        for (int c = 0; c < 2; ++c)
            for (int j = 0; j < m; ++j) nxt[c][j] = j;

        auto find = [&](int c, int j) {               // 类 c 中 >= j 的首个未访问压缩下标
            while (nxt[c][j] != j) {
                nxt[c][j] = nxt[c][nxt[c][j]];        // 路径减半
                j = nxt[c][j];
            }
            return j;
        };
        auto remove = [&](int c, int j) { nxt[c][j] = j + 1; };

        for (int b : banned) remove(b & 1, b >> 1);   // banned 预删除，永不可达
        ans[p] = 0;
        remove(p & 1, p >> 1);

        queue<int> q;
        q.push(p);
        while (!q.empty()) {
            int i = q.front(); q.pop();
            int d = ans[i] + 1;
            int sLo = max(0, i - k + 1), sHi = min(i, n - k);
            int tMin = 2 * sLo + k - 1 - i;
            int tMax = 2 * sHi + k - 1 - i;
            int c = tMin & 1;                         // 落点与 k-1-i 同奇偶
            for (int j = find(c, tMin >> 1), end = tMax >> 1; j <= end;
                 j = find(c, j + 1)) {
                ans[2 * j + c] = d;
                q.push(2 * j + c);
                remove(c, j);                         // 删过的点永远不再碰
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def minReverseOperations(self, n: int, p: int, banned: List[int], k: int) -> List[int]:
        ans = [-1] * n
        m = n // 2 + 2                        # 末位哨兵，保证 find 必终止
        nxt = [list(range(m)), list(range(m))]

        def find(c: int, j: int) -> int:      # 类 c 中 >= j 的首个未访问压缩下标
            while nxt[c][j] != j:
                nxt[c][j] = nxt[c][nxt[c][j]]  # 路径减半
                j = nxt[c][j]
            return j

        def remove(c: int, j: int) -> None:
            nxt[c][j] = j + 1

        for b in banned:                       # banned 预删除，永不可达
            remove(b & 1, b >> 1)
        ans[p] = 0
        remove(p & 1, p >> 1)

        q = deque([p])
        while q:
            i = q.popleft()
            d = ans[i] + 1
            s_lo, s_hi = max(0, i - k + 1), min(i, n - k)
            t_min = 2 * s_lo + k - 1 - i
            t_max = 2 * s_hi + k - 1 - i
            c = t_min & 1                      # 落点与 k-1-i 同奇偶
            j, end = find(c, t_min >> 1), t_max >> 1
            while j <= end:
                x = 2 * j + c
                ans[x] = d
                q.append(x)
                remove(c, j)                   # 删过的点永远不再碰
                j = find(c, j + 1)
        return ans
```

## 8. 边界情况与易错点

1. **$k = 1$**：窗口是单点，1 永远不动，只有 $ans[p] = 0$（示例 3）。此时 $t_{\min} = t_{\max} = i$，扫描因 $i$ 已删除而立即结束，代码自然处理。
2. **$k = n$**：唯一合法窗口是整个数组，$i$ 一步只能到 $n-1-i$。
3. **操作语义是「落点不能是 banned」**，不是「窗口不能覆盖 banned」：示例 1 中窗口 $[0,3]$ 覆盖了 banned 的 1、2，操作依然合法（落点 3 干净）；示例 2 中落点 2 在 banned 里，窗口 $[0,2]$ 才被禁止。理解反了会把合法边删掉。
4. **按奇偶类扫描，步长是 2 不是 1**：$t_{\min}$ 与 $t_{\max}$ 必与 $k-1-i$ 同奇偶。压缩下标 $j = x \gg 1$ 天然实现「同类内连续」；若在同一条数组链上按步 1 扫，会混进另一奇偶类的点。
5. **并查集数组必须留哨兵**：开 $n/2 + 2$ 而非 $n/2 + 1$，否则删除最大压缩下标时 `nxt[j] = j + 1` 越界；哨兵永不被删，`find` 一定停在固定点。
6. **别忘了把 banned 移出候选集**：只「标记不合法」而不删除，扫描会反复撞上 banned 点，最坏退化 $O(n^2)$；删除后 `find` 一步跳过整段。
7. **奇偶不变量是最快的自查工具**：$k$ 奇 ⇒ 与 $p$ 异奇偶的位置必须为 $-1$；$k$ 偶 ⇒ 深度 $d$ 的位置奇偶 $= (p+d) \bmod 2$。输出违反这两条必有 bug。
8. **$n = 1$**：banned 必为空，$k = 1$，返回 `[0]`。
9. **溢出**：全程 int 安全（$t_{\max} \le 2n \le 2\times 10^5$），无需 long long。
