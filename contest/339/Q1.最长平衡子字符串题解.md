# LeetCode 最长平衡子字符串 题解

## 1. 题目概述

- **标题 / 题号**：最长平衡子字符串（#2609，easy）
- **链接**：https://leetcode.cn/problems/find-the-longest-balanced-substring-of-a-binary-string/
- **来源**：LeetCode 第 339 场周赛 Q1
- **难度**：简单
- **标签**：字符串、游程（连续段）计数

**题意**：给定仅由 `0` 和 `1` 组成的二进制字符串 `s`。若子字符串中**所有的 `0` 都在 `1` 之前**，且 **`0` 与 `1` 的数量相等**，则称其为**平衡子字符串**（空子字符串也算平衡）。返回 `s` 中最长平衡子字符串的长度。

**约束**：

- $1 \le s.length \le 50$
- `s[i]` 为 `'0'` 或 `'1'`

> 💡 关键信号：「0 全在 1 前」+「数量相等」⇒ 合法子串形态固定为 $0^x 1^x$，即**某两个相邻连续段**的拼接。这是标准的**游程（run）配对**结构，一遍扫描即可求解。

## 2. 示例

**示例 1**

```text
输入：s = "01000111"
输出：6
解释：最长的平衡子字符串是 "000111"，长度为 6。
```

**示例 2**

```text
输入：s = "00111"
输出：4
解释：最长的平衡子字符串是 "0011"，长度为 4。
```

**示例 3**

```text
输入：s = "111"
输出：0
解释：除空子字符串外不存在其他平衡子字符串，答案为 0。
```

**示例 4（补充：0 段与 1 段不相邻）**

```text
输入：s = "001011"
输出：2
解释：游程切分为 00 | 1 | 0 | 11。相邻配对 (00, 1) 贡献 2·min(2,1)=2，
      (0, 11) 贡献 2·min(1,2)=2。更长的 0 段与 1 段被中间的 "10" 隔开、
      无法拼接，答案为 2（如 s[1..2]="01"）。
```

## 3. 解题思路

### 3.1 暴力思路：枚举子串逐个检查

枚举所有 $O(n^2)$ 个子串 $s[l..r]$，每个花 $O(n)$ 检查「前缀全 0、后缀全 1、两段等长」，取最长，总复杂度 $O(n^3)$。$n \le 50$ 时约 $1.25 \times 10^5$ 次操作，稳过。

但签到题的正确打开方式是**从结构切入**：合法子串形态固定为 $0^x 1^x$，只与**相邻两个连续段**有关。识别出这一点后，$O(n)$ 解法的代码量与三重循环相当，还省去检查函数，比赛时敲得更快、更不易错。

### 3.2 核心观察：平衡子串 = 相邻 (0 段, 1 段) 配对

![游程配对：相邻的 (0段, 1段) 贡献 2·min(a,b)](images/wc339_q1_runs_pairing_concept.svg)

把 `s` 按连续相同字符切成**游程**（run）。两个观察：

1. **形态固定**：平衡子串必形如 $0^x 1^x$。其中 $x$ 个 `0` 连续构成前缀，只能取自**同一个 0 段**；$x$ 个 `1` 连续构成后缀，只能取自紧随其后的**同一个 1 段**——所以每个平衡子串恰好嵌在**一对相邻的 (0 段, 1 段)** 里。
2. **取满较短段最优**：设相邻 0 段长 $a$、1 段长 $b$，受「数量相等」约束，能配对的 $x \le \min(a, b)$；取 $x = \min(a, b)$ 时，从 0 段**末尾**取 $x$ 个 `0`、从 1 段**开头**取 $x$ 个 `1`，二者恰好相邻，拼成合法子串，长度 $2 \cdot \min(a, b)$。

> ⚠️ 只有「0 段在前、1 段在后」的相邻对有效——反方向的 (1 段, 0 段)（如 `"10"`）不满足「所有 0 在 1 之前」。

于是答案就是：

$$\text{ans} = \max_{\text{相邻 } (0\text{ 段},\, 1\text{ 段})} \; 2 \cdot \min(a, b)$$

### 3.3 算法流程：双计数器一遍扫描

![双计数器一遍扫描流程：zero 在 1 段中冻结，one 遇 0 清零](images/wc339_q1_counter_scan_flow.svg)

不必显式存下游程，只维护两个计数器：

- `zero`：当前 0 段的累计长度。进入 1 段后**冻结**——它保存的就是「当前 1 段紧邻的前置 0 段长度」；
- `one`：当前 1 段中**以 $i$ 结尾**的连续 `1` 个数；遇到任何 `0` 立即清零。

每个位置用 $2 \cdot \min(zero, one)$ 更新答案——这正是**以 $i$ 结尾的最长平衡子串长度** $f(i)$：`s[i]='0'` 时 `one=0`，贡献自然为 0；`s[i]='1'` 时它是「前置 0 段能给的 `0` 数」与「以 $i$ 结尾的 `1` 后缀能给的 `1` 数」的短板组合。

### 3.4 示例演算

![示例 "01000111" 的逐步演算表](images/wc339_q1_example_walkthrough.svg)

以 `s = "01000111"` 为例，游程切分为 `0 | 1 | 000 | 111`：

| $i$ | $s_i$ | 段事件 | `zero` | `one` | $f(i)=2\cdot\min$ | `ans` |
|:---:|:-----:|--------|:------:|:-----:|:-----------------:|:-----:|
| 0 | 0 | 新 0 段 | 1 | 0 | 0 | 0 |
| 1 | 1 | 新 1 段（zero 冻结 1） | 1 | 1 | 2 | 2 |
| 2 | 0 | 新 0 段（one 清 0） | 1 | 0 | 0 | 2 |
| 3 | 0 | 延长 0 段 | 2 | 0 | 0 | 2 |
| 4 | 0 | 延长 0 段 | 3 | 0 | 0 | 2 |
| 5 | 1 | 新 1 段（zero 冻结 3） | 3 | 1 | 2 | 2 |
| 6 | 1 | 延长 1 段 | 3 | 2 | 4 | 4 |
| 7 | 1 | 延长 1 段 | 3 | 3 | **6** | **6** |

最终 `ans = 6`，对应子串 $s[2..7]=$ `"000111"`（0 段末尾 3 个 `0` + 1 段开头 3 个 `1`）⭐。
## 4. 算法细节

1. **跨段检测**：比较 `s[i]` 与 `s[i-1]`，不同则跨段，把新起段的计数器清零后自增。注意 `i > 0` 短路——`i = 0` 视为新段开始，两个计数器都从 0 起步，天然正确。
2. **`zero` 的冻结语义**：进入 1 段后 `zero` 不再变动，保存「前置 0 段长度」；只有跨进**新的 0 段**时才重置为 0 再自增。这是本题最核心的状态设计。
3. **`one` 的清零语义**：遇到任何 `0`，`one` 立即清 0——`0` 把 1 段切断了。
4. **更新位置统一**：`ans ← max(ans, 2·min(zero, one))` 放在循环体末尾、对两种字符统一执行即可：`s[i]='0'` 分支里 `one` 已清零，贡献自动为 0，无需再包一层 `if (s[i]=='1')`。
5. **等价写法**：① prev/cur 滚动变量（上一段长 + 当前段长，仅在 `s[i]=='1'` 时更新答案）；② 先把游程收集成 `(字符, 长度)` 列表再扫相邻配对。三者同构，见「相关题目」中同题的每日题解。

## 5. 正确性证明

**引理 1（形态结构）**：非空子串 $s[l..r]$ 是平衡子串，当且仅当存在 $x \ge 1$ 使 $s[l..r] = 0^x 1^x$（前 $x$ 个字符全为 `0`，后 $x$ 个全为 `1`）。

**证明**：(⇒) 子串只含 `0`/`1` 且所有 `0` 在所有 `1` 之前，故由连续的 `0` 前缀与 `1` 后缀组成；两段数量相等，设各 $x$ 个。(⇐) $0^x 1^x$ 显然满足两个条件。∎

**引理 2（右端点刻画）**：非空平衡子串的末字符必为 `1`。设 $s_i = 1$，记 $o_i$ 为以 $i$ 结尾的连续 `1` 段长度，$z_i$ 为紧邻该 `1` 段之前的 `0` 段长度（该 `1` 段位于串首时 $z_i = 0$），则以 $i$ 结尾的最长平衡子串长度为 $2 \cdot \min(z_i, o_i)$。

**证明**：由引理 1，以 $i$ 结尾的平衡子串形如 $0^x 1^x$ 且末字符为 `1`。其 $1^x$ 部分是以 $i$ 结尾的 `1` 连续后缀，故 $x \le o_i$；其 $0^x$ 部分紧贴 $1^x$ 之前，而 $1^x$ 又落在以 $i$ 结尾的 1 段内，故 $0^x$ 只能取自该 1 段紧邻的前一个 0 段，$x \le z_i$。反之取 $x' = \min(z_i, o_i)$：0 段的最后 $x'$ 个 `0` 与以 $i$ 结尾的 $x'$ 个 `1` 相邻拼接成 $0^{x'}1^{x'}$，长度 $2x'$。两个方向夹逼即得。∎

**定理**：算法返回 $s$ 中最长平衡子字符串的长度；不存在非空平衡子字符串时返回 $0$。

**证明**：记 $f(i)$ 为以 $i$ 结尾的最长平衡子串长度（不存在记 $0$）。由引理 2：$s_i = 0$ 时 $f(i) = 0$；$s_i = 1$ 时 $f(i) = 2\min(z_i, o_i)$。任何非空平衡子串以其右端点结尾，故全局答案 $= \max_{0 \le i < n} f(i)$。对 $i$ 归纳证明循环不变量「处理完位置 $i$ 后：`one` 为以 $i$ 结尾的连续 `1` 段长度（$s_i=0$ 时为 $0$）；`zero` 在 $s_i=0$ 时为以 $i$ 结尾的连续 `0` 段长度，在 $s_i=1$ 时为紧邻前置 `0` 段长度」：初始两计数器为 0，对应空前缀；每次跨段（$s_i \ne s_{i-1}$）恰好把新起段的计数器清零后自增，`0` 分支同时清零 `one`，不变量保持。于是循环内每次更新用的 $2\min(zero, one)$ 恰等于 $f(i)$（$s_i=0$ 时 `one`=0 亦真），`ans` 取遍所有 $f(i)$ 的最大值，初值 $0$ 兜底全空情形。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。单趟扫描，每个字符 $O(1)$ 处理。$n \le 50$ 远未触及瓶颈，即使 $n = 10^6$ 也一遍而过。
- **空间复杂度**：$O(1)$。仅 `zero` / `one` / `ans` 三个整型变量，游程信息被压进了滚动状态。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int findTheLongestBalancedSubstring(string s) {
        int ans = 0, zero = 0, one = 0;
        for (int i = 0; i < (int)s.size(); ++i) {
            if (s[i] == '0') {
                if (i > 0 && s[i - 1] == '1') zero = 0; // 跨进新 0 段
                ++zero;
                one = 0;                                // 0 切断 1 段
            } else {
                if (i > 0 && s[i - 1] == '0') one = 0;  // 跨进新 1 段
                ++one;                                  // zero 冻结为前置 0 段长
            }
            ans = max(ans, 2 * min(zero, one));         // 以 i 结尾的最长平衡串
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def findTheLongestBalancedSubstring(self, s: str) -> int:
        ans = zero = one = 0
        for i, c in enumerate(s):
            if c == '0':
                if i > 0 and s[i - 1] == '1':
                    zero = 0            # 跨进新 0 段
                zero += 1
                one = 0                 # 0 切断 1 段
            else:
                if i > 0 and s[i - 1] == '0':
                    one = 0             # 跨进新 1 段
                one += 1                # zero 冻结为前置 0 段长
            ans = max(ans, 2 * min(zero, one))
        return ans
```

## 8. 边界情况与易错点

1. **全 `1` / 全 `0`**：不存在 (0 段, 1 段) 相邻配对，返回 0（示例 3）。`ans` 初值 0 兜底，无需特判。
2. **串首即 `1`**：前置 0 段不存在，`zero` 保持 0，$2 \cdot \min(0, one) = 0$ 自然不计入——依赖 `zero` 初值为 0 且从未被赋值。
3. **`one` 忘清零**（最高频 WA）：如 `s = "1110001"`，正确答案 2（`"01"`）；若遇 `0` 不清 `one`，扫到末尾 `1` 时 `one = 4`、`zero = 3`，得 $2\min = 6$——把不相邻的 `111` 与 `0001` 错误拼接。
4. **`zero` 在 1 段中被清零**（对称 bug）：`"000111"` 会被算成 0。`zero` 必须跨越整个 1 段保持冻结。
5. **忘记 ×2**：贡献是 $2 \cdot \min(a, b)$——`0` 与 `1` 都计入长度，只写 $\min(a,b)$ 会少一半。
6. **(1 段, 0 段) 方向无效**：如 `"10"`，`1` 在 `0` 前，不满足定义；配对只在 `0 → 1` 方向发生。
7. **`s[i-1]` 越界**：跨段判断需 `i > 0` 守卫，或改为先单独处理首字符再从 $i = 1$ 起循环。
8. **暴力能过但要忍住**：$O(n^3) \approx 1.25 \times 10^5$ 在 $n \le 50$ 下完全够用；但一遍扫描代码同样短、复杂度最优、不怕数据加强——周赛应养成直接写结构解的习惯。
