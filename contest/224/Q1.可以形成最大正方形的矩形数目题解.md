# LeetCode 可以形成最大正方形的矩形数目 题解

## 1. 题目概述

- **标题 / 题号**：可以形成最大正方形的矩形数目（#1725，easy）
- **链接**：https://leetcode.cn/problems/number-of-rectangles-that-can-form-the-largest-square/
- **来源**：LeetCode 第 224 场周赛 Q1
- **难度**：简单
- **标签**：数组

**题意**：给你数组 `rectangles`，其中 `rectangles[i] = [l_i, w_i]` 表示第 $i$ 个矩形长 $l_i$、宽 $w_i$。若存在 $k$ 同时满足 $k \le l_i$ 且 $k \le w_i$，就能把该矩形切成边长为 $k$ 的正方形。设 `maxLen` 为所有矩形能切出的**最大正方形边长**，统计有多少个矩形能切出边长为 `maxLen` 的正方形，返回其数目。

**约束**：

- $1 \le \text{rectangles.length} \le 1000$
- $\text{rectangles[i].length} = 2$
- $1 \le l_i, w_i \le 10^9$
- $l_i \ne w_i$

## 3. 解题思路

### 3.1 暴力思路：先求 maxLen 再计数（两遍扫描）

最直白的做法分两步：

1. **第一遍**：遍历所有矩形，算出每个 $k_i = \min(l_i, w_i)$，记录最大值 `maxLen`。
2. **第二遍**：再数一遍有多少个 $k_i$ 等于 `maxLen`。

时间 $O(n)$、空间 $O(n)$（若存下列表）。$n \le 1000$，赛时怎么写都能过，甚至 Python 一行 `ks.count(max(ks))` 即可。但签到题的价值在于沉淀**最短路径**：把「求最大」和「计数」合并到**同一遍扫描**里，只维护两个变量，空间降到 $O(1)$。

### 3.2 核心观察：瓶颈在短边

![核心概念：正方形卡在较短边上，k = min(l, w)](images/wc224_q1_min_side_concept.svg)

边长 $k$ 的正方形要放进（切出）$l \times w$ 的矩形，必须同时满足 $k \le l$ 且 $k \le w$，即 $k \le \min(l, w)$——**正方形卡在较短的那条边上**。于是：

- 每个矩形能切出的最大正方形边长恰为 $k_i = \min(l_i, w_i)$；
- 矩形 $i$ 能切出边长 `maxLen` 的正方形 $\iff k_i \ge \text{maxLen} \iff k_i = \text{maxLen}$（`maxLen` 是所有 $k_i$ 的上界）。

问题就此**归约**为：在序列 $\{\min(l_i, w_i)\}$ 中求最大值并统计其出现次数——标准的「求最大 + 计数」，一遍扫描足矣。

### 3.3 算法流程：一遍扫描维护 (maxLen, count)

![算法流程：一遍扫描同步维护 maxLen 与 count](images/wc224_q1_one_pass_flow.svg)

遍历每个矩形，计算 $k = \min(l, w)$ 后按三分支处理：

- **$k > \text{maxLen}$**：发现更大的值，之前累计的计数全部作废——更新 $\text{maxLen} \leftarrow k$，**重置** $\text{count} \leftarrow 1$；
- **$k = \text{maxLen}$**：并列最大，$\text{count} \mathrel{+}= 1$；
- **$k < \text{maxLen}$**：跳过，不影响任何状态。

遍历结束后 `count` 即答案。注意两个分支必须用 `if / elif` 串联（先判 $>$ 再判 $=$），与「先比较再行动」的决策顺序一致。

### 3.4 示例演算

以示例 1 `rectangles = [[5,8],[3,9],[5,12],[16,5]]` 为例逐状态走查：

![示例演算：一遍扫描逐步状态表](images/wc224_q1_walkthrough.svg)

| 步骤 | 矩形 $[l, w]$ | $k=\min(l,w)$ | 判断 | maxLen | count |
|------|---------------|---------------|------|--------|-------|
| 初始 | — | — | — | $0$ | $0$ |
| ① | $[5, 8]$ | $5$ | $5 > 0$ → 更新 | $5$ | $1$ |
| ② | $[3, 9]$ | $3$ | $3 < 5$ → 跳过 | $5$ | $1$ |
| ③ | $[5, 12]$ | $5$ | $5 = 5$ → count++ | $5$ | $2$ |
| ④ | $[16, 5]$ | $5$ | $5 = 5$ → count++ | $5$ | $3$ |

最终 $\text{maxLen} = 5$、$\text{count} = 3$，返回 $3$ ✓。

> 💡 **示例 2 的关键一步**：$[[2,3],[3,7],[4,3],[3,7]]$ 的 $k$ 序列为 $[2,3,3,3]$。处理第二个矩形时 $k = 3 > \text{maxLen} = 2$，触发**重置**：`count` 从 1 归 1（而非累加到 2）。这是本算法唯一容易写错的地方——「发现更大值时旧计数全部作废」。

## 4. 算法细节

1. **单矩形贡献**：每个矩形独立计算 $k = \min(l, w)$，矩形之间互不影响，无顺序依赖。
2. **状态仅两个变量**：`maxLen`（当前已扫描部分的 $k$ 最大值）与 `count`（等于该最大值的元素个数），无需哈希表或排序。
3. **分支顺序**：先判 `k > maxLen`（更新 + 重置），`elif` 再判 `k == maxLen`（计数）。若写成两个独立 `if`，更新后的 `k == maxLen` 会再成立一次，首个矩形 `count` 会变成 2。
4. **初始化**：`maxLen = 0, count = 0`。由约束 $l_i, w_i \ge 1$ 知 $k \ge 1 > 0$，首个矩形必走更新分支，`count` 被正确置 1，无需特判 $n = 1$ 或空数组（约束保证 $n \ge 1$）。
5. **数据范围**：$k \le 10^9 < 2^{31} - 1$，C++ 用 `int` 即可，无需 `long long`；`count` 至多 1000。
6. **赛时最短写法**（Python）：先列表推导出 $k$ 序列，`ks.count(max(ks))` 一行解决，$O(n)$ 时间、$O(n)$ 空间；追求 $O(1)$ 空间再写一遍扫描版。

## 5. 正确性证明

**引理 1（短边瓶颈）**：矩形 $[l, w]$（$l, w \ge 1$）能切出的最大正方形边长恰为 $\min(l, w)$。

**证明**：边长 $k$ 的正方形可切出 $\iff k \le l$ 且 $k \le w \iff k \le \min(l, w)$。可行 $k$ 的上界为 $\min(l, w)$，且 $k = \min(l, w)$ 时两个不等式均成立（取 $k$ 为整数，$\min(l, w) \ge 1$），故最大可行边长为 $\min(l, w)$。∎

**引理 2（循环不变式）**：遍历完任意前缀 $P_i = \{k_1, \dots, k_i\}$ 后，`maxLen` $= \max_{j \le i} k_j$，`count` $= \#\{j \le i : k_j = \text{maxLen}\}$。

**证明**：对 $i$ 归纳。$i = 0$（空前缀）时 `maxLen = 0, count = 0`，约定空集最大值为 $0$ 且出现 $0$ 次；由 $k_j \ge 1$ 知该约定与后续不冲突，基底成立。设处理 $k_i$ 前不变式成立，考察三分支：

- $k_i > \text{maxLen}$：则 $k_i$ 严格大于前缀 $P_{i-1}$ 中所有元素，新前缀最大值为 $k_i$ 且仅出现 $1$ 次。算法置 $\text{maxLen} = k_i$、$\text{count} = 1$，不变式保持；
- $k_i = \text{maxLen}$：前缀最大值不变，等于最大值的元素多一个。算法执行 `count += 1`，不变式保持；
- $k_i < \text{maxLen}$：最大值及其出现次数均不变，算法不修改状态，不变式保持。

三种情况均保持不变式，归纳完成。∎

**定理**：算法返回能切出边长为 `maxLen` 的正方形的矩形数目。

**证明**：由引理 1，每个矩形 $i$ 能切出的最大正方形边长为 $k_i = \min(l_i, w_i)$，且能切出边长 $k$ 的正方形 $\iff k \le k_i$。全局 $\text{maxLen} = \max_i k_i$，故矩形 $i$ 能切出边长 `maxLen` 的正方形 $\iff k_i \ge \text{maxLen} \iff k_i = \text{maxLen}$。由引理 2，遍历结束（前缀 = 全序列）时 `count` 恰为 $k_i = \text{maxLen}$ 的下标个数，即所求矩形数目。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。每个矩形做一次 `min` 与至多两次比较，均为常数开销。
- **空间复杂度**：$O(1)$。只维护 `maxLen`、`count` 两个变量。（两遍扫描的列表版为 $O(n)$ 空间；先排序再数末尾相同值的做法为 $O(n \log n)$ 时间，无必要——求最值及其计数不需要全局序。）

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int countGoodRectangles(vector<vector<int>>& rectangles) {
        int maxLen = 0, count = 0;
        for (const auto& r : rectangles) {
            int k = min(r[0], r[1]);
            if (k > maxLen) {
                maxLen = k;
                count = 1;      // 发现更大值，重置计数
            } else if (k == maxLen) {
                count++;
            }
        }
        return count;
    }
};
```

### Python

```python
class Solution:
    def countGoodRectangles(self, rectangles: List[List[int]]) -> int:
        max_len, count = 0, 0
        for l, w in rectangles:
            k = min(l, w)
            if k > max_len:
                max_len, count = k, 1   # 发现更大值，重置计数
            elif k == max_len:
                count += 1
        return count
```

赛时追求手速可用一行版（$O(n)$ 时间 / $O(n)$ 空间）：

```python
class Solution:
    def countGoodRectangles(self, rectangles: List[List[int]]) -> int:
        ks = [min(l, w) for l, w in rectangles]
        return ks.count(max(ks))
```

## 8. 边界情况与易错点

1. **$n = 1$**：唯一矩形即答案 1。初始化 `maxLen = 0` 保证首个矩形必触发更新分支，无需特判。
2. **重置写成累加**：`k > maxLen` 时必须 `count = 1` 而非 `count += 1`——新最大值出现后，旧的并列计数全部作废（示例 2 步骤②即此情形）。
3. **`if / elif` 顺序**：若拆成两个独立 `if`，首个矩形更新 `maxLen = k` 后紧接着 `k == maxLen` 又成立，`count` 会被错误地加到 2。
4. **初始化为 0 的安全性**：依赖 $l_i, w_i \ge 1$ 这一约束；若边长可为 0 或负（本题不会），应改用第一个元素或 $-\infty$ 初始化。
5. **读题坑**：求的是「能切出边长为 `maxLen` 的**矩形数目**」，不是切法数、不是最大面积、也不是能切出的正方形总数。
6. **$l_i \ne w_i$ 用不上**：该约束只保证矩形非正方形，$\min$ 对相等边同样成立，算法无需区分。
7. **数值范围**：$l_i, w_i \le 10^9$ 在 32 位 `int` 内，C++ 无溢出风险。
