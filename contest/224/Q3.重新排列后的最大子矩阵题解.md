# LeetCode 重新排列后的最大子矩阵 题解

## 1. 题目概述

- **标题 / 题号**：重新排列后的最大子矩阵（#1727，medium）
- **链接**：https://leetcode.cn/problems/largest-submatrix-with-rearrangements/
- **来源**：LeetCode 第 224 场周赛 Q3
- **难度**：中等
- **标签**：贪心、数组、矩阵、排序

**题意**：给定 $m \times n$ 的二进制矩阵 `matrix`（元素为 `0` 或 `1`）。允许将**列**按任意顺序**整体重排**（同一个列排列对所有行统一生效），求重排后**全为 1** 的子矩阵的最大面积。

**约束**：

- $1 \le m \times n \le 10^5$
- $\text{matrix}[i][j] \in \{0, 1\}$

> ⚠️ **只能整列重排**：列的顺序对所有行统一改变，不能单独重排某一行内部的元素，也不能交换行。示例 3 正是卡这一点——按行内重排能拼出更大的块，但那不允许。

> 💡 本题在本仓库另有[每日题解 1727](../../solution/1701-1800/1727_重新排列后的最大子矩阵.md)：以「与 85 题的柱状图对比、$O(m \cdot n)$ 计数排序优化与面试问答」展开。本篇按**周赛复盘视角**重写：侧重**赛时最短切入路径**（识破「列可重排 = 位置约束消失」）、**排序替代单调栈的结构解释**与「**候选可达 + 最优封顶**」的双向证明链，两篇互为印证。

## 2. 示例

**示例 1**

```text
输入：matrix = [[0,0,1],
               [1,1,1],
               [1,0,1]]
输出：4
解释：把第 2 列换到最左，按 [2, 0, 1] 重排：
      [[1,0,0],
       [1,1,1],
       [1,1,0]]
      第 1、2 行与前两列构成 2×2 全 1 子矩阵，面积 4。
```

**示例 2**

```text
输入：matrix = [[1,0,1,0,1]]
输出：3
解释：单行矩阵，三个全 1 列并到一起 → 1×3 = 3。
```

**示例 3**

```text
输入：matrix = [[1,1,0],
               [1,0,1]]
输出：2
解释：只能整列重排：高 2 的列（第 0 列）与任何高 1 的列并排
      只能拼出高 1 的矩形；按行内重排才拼得出更大的，但禁止。
      最大面积 2。
```

**示例 4**

```text
输入：matrix = [[0,0],[0,0]]
输出：0
解释：矩阵中没有 1，面积为 0。
```

## 3. 解题思路

### 3.1 暴力思路：枚举列排列

枚举全部 $n!$ 种列排列，对每个排列求「全 1 最大子矩阵」（经典 85 题套路：按行高度 + 单调栈，$O(m \cdot n)$）。$n = 10$ 时 $n! \approx 3.6 \times 10^6$，$n = 15$ 时已超 $10^{12}$，完全不可行。

> ⚠️ **症结**：陷入了「必须先确定一个具体排列」的思维定势。但题目只问**面积**——不需要构造排列，只需要知道「以某行为底时，哪些高度组合能并排出现」。

### 3.2 核心观察：位置约束消失，排序取代单调栈

![核心观察：按底行求列高，列可重排时降序排序即最优并排](images/wc224_q3_rearrange_sort_concept.svg)

**第一步：把矩阵压成「每行的直方图」**。任何全 1 子矩阵都以**某一行**为底。固定底行 $i$，维护每列向上连续 1 的高度：

$$\text{heights}[j] = \begin{cases} \text{heights}[j] + 1, & \text{matrix}[i][j] = 1 \\ 0, & \text{matrix}[i][j] = 0 \end{cases}$$

一个以第 $i$ 行为底、高 $h$、宽 $w$ 的全 1 子矩阵，当且仅当底行处**至少有 $w$ 列的** $\text{heights} \ge h$——至于这些列原来站在哪里，无关紧要。

**第二步：用排序代替单调栈**。85 题（列固定）的困难全在「哪几列能**相邻**」——位置约束使得必须用单调栈维护左右边界。本题**列可任意重排**，「高度 $\ge h$ 的列」无论原本在哪都能被搬到一起相邻，**位置约束彻底消失**。于是对当前行的 `heights` **降序排序**即可：排在位置 $j$ 的高度 $h_j$ 满足前 $j+1$ 列的高度都不小于 $h_j$，把它们并排即得高 $h_j$、宽 $j+1$ 的全 1 矩阵：

$$\text{answer} \;=\; \max_{i=0}^{m-1}\ \max_{j=0}^{n-1}\ \text{sorted}(\text{heights}_i)[j] \times (j+1)$$

> 💡 **赛时识别**：看到「列可任意重排」应立刻反应到**位置约束消失**——85 题的预处理（按行累加高度）逐字照搬，单调栈换成一次降序排序，中等题体量。

> ⚠️ **按行独立处理为何正确**：列重排虽是全局操作，但题目只要**面积**。候选 $(i, j)$ 对应的子矩阵只以第 $i$ 行为底——把「高度 $\ge h_j$ 的那 $j+1$ 列」搬到一起就能实现它，其余行排在哪不影响这一块。故每行独立取最大、再取全局最大即可（严格证明见 §5）。

### 3.3 算法流程

![算法流程：逐行更新高度、降序排序、扫描取最大](images/wc224_q3_row_scan_flow.svg)

1. 初始化 `heights = [0] * n`，`ans = 0`。
2. 逐行 $i = 0 \dots m-1$：
   - **更新高度**：`matrix[i][j] == 1` 则 `heights[j] += 1`，否则归零；
   - **拷贝**出 `sorted_h` 并降序排序（`heights` 本体保持原列序，留给下一行用）；
   - **扫描** $j = 0 \dots n-1$：`sorted_h[j] == 0` 直接 `break`（后面全 0）；否则 `ans = max(ans, sorted_h[j] * (j + 1))`。
3. 返回 `ans`。

### 3.4 示例演算

![示例演算：三行各自的高度更新、排序与候选面积](images/wc224_q3_walkthrough.svg)

以示例 1 为例（见上图）：第 0 行扫出 $1 \times 1 = 1$；第 1 行排序后 $[2,1,1]$，扫出 $1 \times 3 = 3$；第 2 行 heights $= [2,0,3]$、排序后 $[3,2,0]$，位置 $j=1$ 处 $2 \times 2 = 4$ 成为最终答案——高 3 列与高 2 列在原矩阵中**并不相邻**，正是「重排 + 排序」拼出的组合。

## 4. 算法细节

1. **高度递推的含义**：`heights[j]` 是「以当前行为底」的向上连续 1 长度；遇 0 归零保证任何向上穿过 0 的矩形自动被排除——与 85 题预处理完全一致。
2. **必须拷贝再排序**：`heights` 要跨行复用，第 $i+1$ 行的更新发生在**原列序**上（`heights[j]` 与 `matrix[i+1][j]` 按列对齐）；就地排序会打乱列对应关系，从第二行起全部算错。
3. **候选面积公式**：宽度取 $j+1$（降序时的前缀长度）。若改用升序排序，则从右往左扫、宽度取 $n - j$，两者等价；降序写法更直观。
4. **`h == 0` 提前终止**：降序后 0 全在尾部，遇到即 `break`。这是纯性能优化——$h_j = 0$ 时候选面积为 0，跳过不影响正确性。
5. **数据结构**：仅需一个 $O(n)$ 的 `heights` 数组与每行一次排序，无需单调栈、无需哈希表。

## 5. 正确性证明

**引理 1（候选可达）**：对任意行 $i$ 与位置 $j$，记 $h_j = \text{sorted}(\text{heights}_i)[j]$。若 $h_j > 0$，则存在一个列排列，使重排后的矩阵中存在面积为 $h_j \times (j+1)$ 的全 1 子矩阵。

**证明**：设排序后前 $j+1$ 个高度对应的列构成集合 $S$（$|S| = j+1$，各列互不相同）。构造排列：$S$ 中任意次序放最前，其余列任意放后面。由降序性，$S$ 中每列在底行 $i$ 处的高度都 $\ge h_j$，即这些列从第 $i$ 行向上的 $h_j$ 行（第 $i - h_j + 1$ 行到第 $i$ 行）全为 1。重排后这 $j+1$ 列相邻，且各自底部 $h_j$ 层全 1，故围成 $h_j \times (j+1)$ 的全 1 子矩阵。∎

**引理 2（最优封顶）**：对任意列排列 $\pi$，重排后矩阵中任意全 1 子矩阵的面积不超过算法输出的 $\text{ans}$。

**证明**：设该子矩阵以第 $i$ 行为底（取其最底行），宽 $w$、高 $h$，则其覆盖的 $w$ 列（重排后相邻）各自在原矩阵中以第 $i$ 行为底的向上连续 1 高度都 $\ge h$——即至少有 $w$ 列的 $\text{heights}_i \ge h$。于是第 $w$ 大的高度 $\text{sorted}(\text{heights}_i)[w-1] \ge h$（且 $\ge h \ge 1 > 0$，扫描在 $j = w-1$ 处不会提前 `break`），算法在行 $i$、位置 $j = w-1$ 处考察的候选满足

$$\text{sorted}(\text{heights}_i)[w-1] \times w \;\ge\; h \times w,$$

故 $\text{ans} \ge h \times w$。∎

**定理**：算法返回值等于最优解。

**证明**：由引理 1，算法输出的每个候选面积都可在某个列排列下真实取得，故返回值 $\le$ 最优解；由引理 2，任意排列下的任意全 1 子矩阵面积都 $\le$ 返回值，故最优解 $\le$ 返回值。二者相等。∎

## 6. 复杂度分析

- **时间复杂度**：$O(m \cdot n \log n)$。每行三步：高度更新 $O(n)$、排序 $O(n \log n)$、扫描 $O(n)$。由 $m \cdot n \le 10^5$ 且 $\log n \le 17$，总运算量约 $1.7 \times 10^6$，远在时限内。
- **空间复杂度**：$O(n)$。`heights` 数组与每行的排序拷贝 `sorted_h`；不计输入矩阵。

> 💡 高度取值是 $[0, m]$ 内的整数，每行排序可换**计数排序**做到 $O(n + m)$、总量 $O(m \cdot n)$，详见每日题解的优化章节；赛时无此必要。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int largestSubmatrix(vector<vector<int>>& matrix) {
        int m = matrix.size(), n = matrix[0].size();
        vector<int> heights(n, 0);
        int ans = 0;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++)
                heights[j] = matrix[i][j] ? heights[j] + 1 : 0;
            vector<int> sorted_h = heights;                  // 拷贝！heights 保留原列序
            sort(sorted_h.begin(), sorted_h.end(), greater<int>());
            for (int j = 0; j < n && sorted_h[j] > 0; j++)   // h = 0 提前终止
                ans = max(ans, sorted_h[j] * (j + 1));
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def largestSubmatrix(self, matrix: List[List[int]]) -> int:
        n = len(matrix[0])
        heights = [0] * n
        ans = 0
        for row in matrix:
            for j, v in enumerate(row):
                heights[j] = heights[j] + 1 if v else 0
            for j, h in enumerate(sorted(heights, reverse=True)):
                if h == 0:
                    break
                ans = max(ans, h * (j + 1))
        return ans
```

## 8. 边界情况与易错点

1. **全 0 矩阵**：所有候选为 0，`ans` 初始为 0 直接返回，无需特判（示例 4）。
2. **就地排序陷阱**（最常见错误）：对 `heights` 本体排序后，下一行的高度更新就与列错位，从第二行起全错。必须拷贝一份排序。
3. **宽度用 $j+1$**：降序扫描时位置 $j$ 的宽度是前缀长度 $j+1$；误写成 $n - j$ 会系统性偏小（升序 + 从右往左扫才是 $n - j$）。
4. **「整列重排」的语义**：不能行内重排、不能交换行。示例 3 按行内重排可得 4，但整列重排只能得 2——把题意读宽是本题最大的坑。
5. **溢出**：$h_j \le m$、$j + 1 \le n$，候选面积 $\le m \cdot n \le 10^5$，`int` 完全安全。
6. **极端形状**：$n = 1$（每行排序退化为单元素）与 $m = 1$（高度只有 0/1，排序后 1 的个数即答案）都被通用逻辑自动覆盖。
7. **别照搬 85 题单调栈**：在原列序上跑单调栈只能得到**原排列**下的最大矩形，会漏掉「不相邻列拼矩形」的组合（本题答案是它的超集）——赛时卡住多数源于此。
