# LeetCode 猫和老鼠 II 题解

## 1. 题目概述

- **标题 / 题号**：猫和老鼠 II（#1728，hard）
- **链接**：https://leetcode.cn/problems/cat-and-mouse-ii/
- **来源**：LeetCode 第 224 场周赛 Q4
- **难度**：困难
- **标签**：广度优先搜索、拓扑排序、动态规划、博弈、记忆化搜索、极小化极大、矩阵

**题意**：一只猫和一只老鼠在 `rows × cols` 的方格 `grid` 上追逐。格子为墙 `#`（不可通过）、地板 `.`、猫 `C`、老鼠 `M` 或食物 `F`（`C` / `M` / `F` 各出现一次）。老鼠**先手**，双方轮流操作：每次向上下左右之一跳跃 $1 \sim \text{jump}$ 格（可以跳更短、也可以原地不动），不能跳过墙、不能出界；**老鼠可以跳过猫的位置**。游戏结束条件与胜者：

| 条件 | 胜者 |
|------|------|
| 猫鼠同格 | 猫 |
| 猫先到达食物 | 猫 |
| 老鼠先到达食物 | 老鼠 |
| 老鼠 1000 次操作内没到食物 | 猫 |

双方都采取**最优策略**，问老鼠是否获胜。

**约束**：

- $1 \le \text{rows}, \text{cols} \le 8$（至多 64 格）
- `grid[i][j]` 只含 `'C'`、`'M'`、`'F'`、`'.'`、`'#'`，且 `C` / `M` / `F` 各恰好一次
- $1 \le \text{catJump}, \text{mouseJump} \le 8$

> 💡 本题在本仓库另有[每日题解 1728](../../solution/1701-1800/1728_猫和老鼠II.md)：以「逆向归纳框架的通用化（何时可用）、前驱传播规则与面试问答」展开。本篇按**周赛复盘视角**重写：侧重**赛时最短切入**（从 913 识别套路）、**平局语义换元**（1000 步规则 → 值域二值化）、**猫越顶走法的支配论证**与**守域式证明链**，两篇互为印证。

## 3. 解题思路

### 3.1 暴力思路：minimax DFS + 步数维度

最直觉的做法是把博弈写成 minimax：老鼠在自己回合选**最大化**自己胜率的走法，猫选**最小化**老鼠胜率的走法，记忆化搜索。麻烦在**平局**：双方原地不动或来回踱步会让对局无限循环。

- 若给状态加上步数维度 $(m, c, t, \text{steps})$ 并限制 $\text{steps} \le 1000$：状态数 $64 \times 64 \times 2 \times 1000 \approx 8.2 \times 10^6$，每个状态至多 $4 \times 8 + 1 = 33$ 条转移边，总边数约 $2.7 \times 10^8$——递归深、常数大，Python 必超时，C++ 也很悬。
- 若不加步数维度，朴素记忆化 DFS 会**死循环**：示例 3 正是这种局面——老鼠困在 0，猫守在 2，谁都不动，递归在 $(0, 2, 0)$ 上无限展开（记忆化只缓存「算完」的状态，算不完就永远没有缓存）。

> ⚠️ **症结**：循环 / 平局。1000 步规则把「无限对峙」判给猫——这既是 DFS 的坑，也是优化的钥匙。

### 3.2 核心观察：平局判猫赢 → 去掉步数维度 → 逆向归纳

![核心观察：状态 (m, c, t) 博弈图与逆向归纳](images/wc224_q4_state_graph_concept.svg)

**观察一（状态空间极小）**：棋盘至多 64 格，状态 $(m, c, t)$ 至多 $64 \times 64 \times 2 = 8192$ 个。1000 步规则的唯一作用是把「平局」**定义**成猫赢——它根本不需要被模拟。

**观察二（值域二值化）**：把结果定义成二值：$\text{result}[m][c][t] \in \{1\ \text{鼠胜},\ 2\ \text{猫胜}\}$。老鼠若无法强制到达食物（对局循环），1000 步后猫胜——「平局」这个第三种结果被**合并**进猫胜，步数维度彻底消失。这是与 913（猫和老鼠）最大的差异：913 里平局是真实的第三种返回值（0），必须三分值域；本题反而因为规则更"残酷"而更简单。

**观察三（逆向归纳 / retrograde analysis）**：有限完美信息零和博弈的胜负可以从**终止态倒着推**：

- **终止态**（结果已知，直接入队）：$m = c$ → 猫胜；$m = \text{food}$ → 鼠胜；$c = \text{food}$ → 猫胜。
- **传播**：设已解析状态 $S$ 的结果为 $r$，看它的**前驱** $P$（能一步走到 $S$ 的状态）：
  - $r$ 的赢家 == $P$ 的当前玩家 → $P$ 也赢（当前玩家会选这步）→ 标记入队；
  - $r$ 的赢家 == $P$ 的当前玩家的对手 → 这是 $P$ 当前玩家的一条「送死」走法 → $\text{loss}[P] \mathrel{+}= 1$；当 $\text{loss}[P] = \text{degree}[P]$（**所有**走法都送死）→ $P$ 判负入队。
- BFS 结束仍未解析的状态 = 双方都无强制胜负 = 平局 = **猫胜**。

> 💡 **为什么「赢」走捷径而「输」要计数**：轮到的玩家是选择方——**赢只需要一条路**；**不输**则至少要有一条不送死的路（哪怕通向平局）。这正是 `loss / degree` 计数的语义。

**前驱怎么找？——跳跃的对称性**：$A$ 能跳到 $B$ 当且仅当 $B$ 能跳到 $A$（同方向反跳同样距离，中间无墙）。所以预计算的可达表 `reach[p]` 既是「从 $p$ 能到哪」（后继），也是「谁能一步到 $p$」（前驱），无需显式建图、无需反向边。具体地：$(m, c, 1)$（猫回合，老鼠刚跳完）的前驱是 $(m', c, 0)$，$m' \in \text{mouseReach}[m]$；$(m, c, 0)$（鼠回合，猫刚走完）的前驱是 $(m, c', 1)$，$c' \in \text{catReach}[c]$。

> ⚠️ **猫能不能「跳过」老鼠？** 题面明说老鼠可以跳过猫；猫这一侧其实**无需纠结**——两种读法答案恒相同。若猫的某次跳跃路径**穿过**老鼠所在格，把这跳缩短一截、直接落在老鼠身上即可：跳跃路径的前缀仍是合法跳跃（中间格全非墙），而落上去就是「同格 → 猫胜」这条立即获胜的走法，它支配一切越顶走法。向选择集里添加被支配的走法不改变博弈价值。因此可达表只需以墙为唯一障碍，猫鼠两侧完全对称。

### 3.3 算法流程

![算法流程：逆向归纳 BFS](images/wc224_q4_retrograde_flow.svg)

1. **解析棋盘**：一维编码 $pos = r \cdot \text{cols} + c$，记录老鼠 / 猫 / 食物起点与墙集合。$O(n)$，$n = \text{rows} \times \text{cols}$。
2. **预计算可达表** `mouseReach` / `catReach`：对每个非墙格，四方向各跳 $1 \sim \text{jump}$ 格，遇墙或出界即截断，含原地。$O(n \cdot J)$。
3. **初始化**：枚举所有 $(m, c, t)$（$m$、$c$ 均为非墙格）：终止态按规则标记并入队；非终止态记录 $\text{degree}$ = 当前玩家的走法数（含原地）。$O(n^2)$。
4. **BFS 逆向传播**：弹出 $(m, c, t, r)$，枚举前驱（复用可达表）：同侧捷径标记；异侧 $\text{loss}{+}{+}$，计满 $\text{degree}$ 判负。每个状态至多入队一次。$O(n^2 \cdot J)$。
5. **返回** $\text{result}[\text{mStart}][\text{cStart}][0] == 1$；未解析（0）按猫胜处理。

### 3.4 示例演算：守卫区与逃逸（示例 2 vs 示例 3）

![示例演算：守卫区 —— jump=3 无路可逃，jump=4 一跃脱网](images/wc224_q4_guard_zone_walkthrough.svg)

同一棋盘 `"M.C...F"`、`catJump = 1`，猫的**守卫区**是 $\{1, 2, 3\}$（猫从 2 一步可达的格子）：

- **`mouseJump = 3`（示例 3，false）**：老鼠从 0 出发一步能到 $\{0, 1, 2, 3\}$。跳到 $1 / 2 / 3$ 都落进守卫区——下一步即被猫抓住（如 $(0,2,0) \to (3,2,1) \to$ 猫跟到 3 同格）；原地不动则与猫僵持，1000 步超时。$(0,2,0)$ 的 $\text{degree} = 4$（原地 + 跳 $1/2/3$），四条走法全部送死，$\text{loss}$ 计满 4 → 判猫胜。
- **`mouseJump = 4`（示例 2，true）**：老鼠一步能到 $\{0, \dots, 4\}$，第 4 格在守卫区**外**。老鼠 $0 \to 4$ 得到 $(4, 2, 1)$；猫一步只能到 $\{1, 2, 3\}$，摸不到 4；轮到老鼠 $4 \to 6$ 直达食物。逆向归纳把 $(4, \{1,2,3\}, 0)$ 全部解析为鼠胜 → $(4,2,1)$ 判鼠胜 → $(0,2,0)$ 选「跳到 4」这步 → `true`。

> 💡 **守卫区是本题的赛时直觉**：猫不必「抓」，蹲住通往食物的咽喉即可——平局规则天然站在猫这边。逆向归纳把「守而不攻」自动算进「未解析 = 猫胜」，无需手工推理。一格格之差（jump 3 → 4），胜负翻转。

## 4. 算法细节

1. **一维编码**：$pos = r \cdot \text{cols} + c$，三张 $n \times n \times 2$ 的表 `result` / `degree` / `loss` 用嵌套数组索引 $[m][c][t]$，比四维数组更省也更清晰。
2. **可达表一表两用**：对称性（能跳到 ⟺ 能跳回）使同一张 `reach` 表既当**后继表**（初始化时求 `degree`）又当**前驱表**（BFS 时枚举前驱），省掉显式建图与反向边。
3. **`degree` 的语义**：非终止态 $(m, c, t)$ 的**当前玩家**走法总数，**含原地不动**。$\text{loss}$ 计到 $\text{degree}$ 才判负——差一条没送死的路（含通向平局的路）就保持未解析。
4. **前驱方向别搞反**：$(m, c, 0)$ 是鼠回合，说明**刚走完的是猫**，前驱是猫换位的 $(m, c', 1)$；$(m, c, 1)$ 是猫回合，前驱是鼠换位的 $(m', c, 0)$。传播时判断「前驱的当前玩家」与弹出结果 $r$ 的赢家是否同侧。
5. **墙的截断**：跳跃沿方向逐格延伸，遇墙或出界立即 `break`（该方向更远的格全部不可达）。
6. **终止态优先级**：`m == c` 的判断放在 `m == food` 之前——老鼠跳上被猫占据的食物格属于「同格被抓」，猫胜（猫已经在食物上，也满足「猫先到食物」）。
7. **每个状态至多入队一次**：`result` 已非 0 的状态在传播时直接跳过；标记只在入队时写一次，保证 $O(\text{状态数} \times \text{走法数})$ 的总工作量。

## 5. 正确性证明

**约定**：博弈状态图 $G$：节点 $(m, c, t)$，边为合法走法（由可达表给出）。$W$ 为 BFS 结束时被标记为 1（鼠胜）的状态集。

**引理 1（标 1 即真胜）**：任意 $P \in W$，老鼠从 $P$ 出发有制胜策略，且可保证整局**无状态重复**。

**证明**：对 $P$ 的标记时刻（`result` 被写入的先后）作强归纳。

- 基例：终止态 $P = (\text{food}, c, t)$ 在初始化时标记，老鼠已在食物上，结论成立。
- 鼠回合态 $P = (m, c, 0)$ 被标 1，当且仅当某个后继 $S = (m', c, 1) \in W$（$m' \in \text{mouseReach}[m]$）出队（$r = 1$）时由捷径规则写入，而 $S$ 的标记时刻严格早于 $P$。策略：老鼠跳到 $m'$，随后沿用 $S$ 处的归纳策略。
- 猫回合态 $P = (m, c, 1)$ 被标 1，仅当 $\text{loss} = \text{degree}$，即猫在 $P$ 的**全部**走法对应的后继 $(m, c'', 0)$ 都 $\in W$ 且标记时刻更早。无论猫怎么走，对局落入某个已完成归纳的状态，沿用其策略即可。

归纳链上标记时刻严格递减，故依此策略的对局每走一步标记时刻都在下降，至多 $|W| \le 8192$ 步内触底——只能是标记时刻最小的一类状态，即终止态 $(\text{food}, c, t)$，老鼠到达食物。∎

**引理 2（守域：未标 1 则猫不输）**：从任意 $P \notin W$ 出发，猫有策略使对局永不进入 $W$，从而老鼠永远到不了食物。

**证明**：往证 $W$ 的补集是老鼠的陷阱。

- 设 $P = (m, c, 0)$（鼠回合）且 $P \notin W$，则它的每个后继 $S = (m', c, 1) \notin W$。反设某后继 $S \in W$：$S$ 出队（$r = 1$）那一刻会经捷径把 $P$ 标成 1；若担心 $P$ 更早被标成 2——标 2 要求 $\text{loss} = \text{degree}$，即**全部**后继都已出队且 $r = 2$，而每个状态只出队一次、$W$ 中状态出队时 $r = 1$，矛盾。故老鼠的每一步都被迫留在 $W$ 之外。
- 设 $P = (m, c, 1)$（猫回合）且 $P \notin W$，则至少有一个后继 $(m, c'', 0) \notin W$。反设全部后继 $\in W$：它们出队时的 $r = 1$ 事件逐次累加 $\text{loss}[P]$ 直至计满 $\text{degree}[P]$，把 $P$ 标成 1，矛盾。猫总是选择这样的后继。

于是猫可把整局锁死在 $W$ 之外；又因全部 $m = \text{food}$ 的终止态初始即 $\in W$，对局永远不会以老鼠到达食物告终。∎

**定理**：算法返回 `true` 当且仅当老鼠在题面语义下获胜。

**证明**：返回 `true` 即初始态 $\in W$，由引理 1，老鼠有有限步内到达食物的制胜策略。返回 `false` 即初始态 $\notin W$，由引理 2，猫可锁死对局：要么中途抓住老鼠或自己先到食物（猫胜），要么无限僵持——无论哪种，老鼠都未在 1000 次操作内到达食物，按第 4 条结束规则同样判猫胜。∎

**推论（1000 步上限为何可以不模拟）**：引理 1 的策略沿标记时刻严格下降，保证制胜对局无状态重复、至多 $64 \times 64 \times 2 = 8192$ 次操作内结束。该上界大于 1000，「能赢但需要超过 1000 步」的状态在理论上未被排除——但构造这种局面需要猫在至多 $8 \times 8$ 的棋盘上摆出极端拖延阵型。实测（官方 5 个示例与随机棋盘，与「字面模拟 1000 步上限」的暴力 minimax 双向比对）从未出现分歧；官方题解同样省略步数维度。**1000 在本题的作用是消灭「平局」这个第三种结果，而不是一个需要跟踪的约束。**

## 6. 复杂度分析

- **时间复杂度**：$O(n^2 \cdot J)$，其中 $n = \text{rows} \times \text{cols} \le 64$，$J = \max(\text{catJump}, \text{mouseJump}) \le 8$。状态数 $2n^2 \le 8192$；每个状态出队时枚举的前驱数 $\le 4J + 1 \le 33$；总量 $\le 8192 \times 33 \approx 2.7 \times 10^5$，常数极小。对比带步数暴力的 $O(n^2 \cdot 1000 \cdot J) \approx 2.7 \times 10^8$，快约一千倍。
- **空间复杂度**：$O(n^2)$。`result` / `degree` / `loss` 三张 $n \times n \times 2$ 表（$n = 64$ 时约 $2.4 \times 10^4$ 个整数）与两张 $O(n \cdot J)$ 的可达表。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool canMouseWin(vector<string>& grid, int catJump, int mouseJump) {
        int rows = grid.size(), cols = grid[0].size();
        int n = rows * cols;
        int mStart = 0, cStart = 0, food = 0;
        vector<bool> wall(n, false);
        for (int r = 0; r < rows; r++)
            for (int c = 0; c < cols; c++) {
                int p = r * cols + c;
                if (grid[r][c] == 'M') mStart = p;
                else if (grid[r][c] == 'C') cStart = p;
                else if (grid[r][c] == 'F') food = p;
                else wall[p] = (grid[r][c] == '#');
            }

        auto build = [&](int jump) {          // 唯一的障碍是墙
            vector<vector<int>> reach(n);
            const int dr[4] = {1, -1, 0, 0}, dc[4] = {0, 0, 1, -1};
            for (int p = 0; p < n; p++) {
                if (wall[p]) continue;
                reach[p].push_back(p);        // 原地不动也是合法走法
                int r = p / cols, c = p % cols;
                for (int d = 0; d < 4; d++)
                    for (int k = 1; k <= jump; k++) {
                        int nr = r + dr[d] * k, nc = c + dc[d] * k;
                        if (nr < 0 || nr >= rows || nc < 0 || nc >= cols) break;
                        if (wall[nr * cols + nc]) break;   // 遇墙截断
                        reach[p].push_back(nr * cols + nc);
                    }
            }
            return reach;
        };
        auto mouseReach = build(mouseJump);
        auto catReach = build(catJump);

        // result[m][c][t]：0 未解析(=平局=猫胜) 1 鼠胜 2 猫胜
        vector<vector<array<int, 2>>> result(n, vector<array<int, 2>>(n, {0, 0}));
        vector<vector<array<int, 2>>> degree(n, vector<array<int, 2>>(n, {0, 0}));
        vector<vector<array<int, 2>>> loss(n, vector<array<int, 2>>(n, {0, 0}));
        queue<array<int, 4>> q;

        for (int m = 0; m < n; m++) {
            if (wall[m]) continue;
            for (int c = 0; c < n; c++) {
                if (wall[c]) continue;
                for (int t = 0; t < 2; t++) {
                    if (m == c)          { result[m][c][t] = 2; q.push({m, c, t, 2}); }
                    else if (m == food)  { result[m][c][t] = 1; q.push({m, c, t, 1}); }
                    else if (c == food)  { result[m][c][t] = 2; q.push({m, c, t, 2}); }
                    else degree[m][c][t] = (t == 0 ? mouseReach[m] : catReach[c]).size();
                }
            }
        }

        while (!q.empty()) {
            auto [m, c, t, r] = q.front(); q.pop();
            if (t == 0) {   // 鼠回合态：前驱是猫换位的 (m, c', 1)
                for (int cp : catReach[c]) {
                    if (result[m][cp][1]) continue;
                    if (r == 2) { result[m][cp][1] = 2; q.push({m, cp, 1, 2}); }
                    else if (++loss[m][cp][1] == degree[m][cp][1])
                        { result[m][cp][1] = 1; q.push({m, cp, 1, 1}); }
                }
            } else {        // 猫回合态：前驱是鼠换位的 (m', c, 0)
                for (int mp : mouseReach[m]) {
                    if (result[mp][c][0]) continue;
                    if (r == 1) { result[mp][c][0] = 1; q.push({mp, c, 0, 1}); }
                    else if (++loss[mp][c][0] == degree[mp][c][0])
                        { result[mp][c][0] = 2; q.push({mp, c, 0, 2}); }
                }
            }
        }
        return result[mStart][cStart][0] == 1;
    }
};
```

### Python

```python
class Solution:
    def canMouseWin(self, grid: List[str], catJump: int, mouseJump: int) -> bool:
        rows, cols = len(grid), len(grid[0])
        n = rows * cols
        m_start = c_start = food = -1
        wall = [False] * n
        for r in range(rows):
            for c in range(cols):
                p, ch = r * cols + c, grid[r][c]
                if ch == 'M': m_start = p
                elif ch == 'C': c_start = p
                elif ch == 'F': food = p
                elif ch == '#': wall[p] = True

        def build(jump):                      # 唯一的障碍是墙
            reach = [[] for _ in range(n)]
            for p in range(n):
                if wall[p]: continue
                r, c = divmod(p, cols)
                reach[p].append(p)            # 原地不动
                for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):
                    for k in range(1, jump + 1):
                        nr, nc = r + dr * k, c + dc * k
                        if not (0 <= nr < rows and 0 <= nc < cols): break
                        if wall[nr * cols + nc]: break   # 遇墙截断
                        reach[p].append(nr * cols + nc)
            return reach

        mouse_reach, cat_reach = build(mouseJump), build(catJump)

        # result[m][c][t]：0 未解析(=平局=猫胜) 1 鼠胜 2 猫胜
        result = [[[0, 0] for _ in range(n)] for _ in range(n)]
        degree = [[[0, 0] for _ in range(n)] for _ in range(n)]
        loss = [[[0, 0] for _ in range(n)] for _ in range(n)]
        q = deque()
        for m in range(n):
            if wall[m]: continue
            for c in range(n):
                if wall[c]: continue
                for t in range(2):
                    if m == c:
                        result[m][c][t] = 2; q.append((m, c, t, 2))
                    elif m == food:
                        result[m][c][t] = 1; q.append((m, c, t, 1))
                    elif c == food:
                        result[m][c][t] = 2; q.append((m, c, t, 2))
                    else:
                        degree[m][c][t] = len(mouse_reach[m] if t == 0 else cat_reach[c])

        while q:
            m, c, t, r = q.popleft()
            if t == 0:    # 鼠回合态：前驱是猫换位的 (m, c', 1)
                for cp in cat_reach[c]:
                    if result[m][cp][1]: continue
                    if r == 2:
                        result[m][cp][1] = 2; q.append((m, cp, 1, 2))
                    else:
                        loss[m][cp][1] += 1
                        if loss[m][cp][1] == degree[m][cp][1]:
                            result[m][cp][1] = 1; q.append((m, cp, 1, 1))
            else:         # 猫回合态：前驱是鼠换位的 (m', c, 0)
                for mp in mouse_reach[m]:
                    if result[mp][c][0]: continue
                    if r == 1:
                        result[mp][c][0] = 1; q.append((mp, c, 0, 1))
                    else:
                        loss[mp][c][0] += 1
                        if loss[mp][c][0] == degree[mp][c][0]:
                            result[mp][c][0] = 2; q.append((mp, c, 0, 2))

        return result[m_start][c_start][0] == 1
```

## 8. 边界情况与易错点

1. **平局必须判猫**：BFS 结束后 `result == 0`（未解析）就是猫胜。最常见的错误是把它当成第三种返回值单独处理，或者死磕步数维度把状态空间放大一千倍。
2. **`degree` 必须含「原地不动」**：双方都可以停留。漏掉它既会漏后继（守卫型走法消失），又会让 `loss` 提前计满、把「可僵持」的状态错判为必败。
3. **墙是 `break` 不是 `continue`**：某方向遇到墙后，该方向更远的格全部不可达；`continue` 会算出穿墙跳跃。
4. **前驱方向别搞反**：$(m, c, 0)$ 是鼠回合 → 刚走完的是猫 → 前驱动**猫**的位置得 $(m, c', 1)$；$(m, c, 1)$ 的前驱动**鼠**的位置得 $(m', c, 0)$。搞反一侧，传播整体错误。
5. **跳跃语义**：只有墙是障碍。老鼠跳过猫是题面明示；猫能否跳过老鼠不影响答案——越顶走法被「缩短跳距、落上去抓」的立即获胜走法支配（见 §3.2）。不要在可达表里对猫的位置做任何特殊处理。
6. **`m == c` 的判断先于 `m == food`**：老鼠跳上被猫占据的食物格是「同格被抓」，猫胜。
7. **食物不可达**（示例 4）：整张 `result` 表标不出任何 1，初始态未解析 → 猫胜。算法自动覆盖，无需连通性特判。
8. **别把 1000 步带回状态**：它的语义作用是「平局归猫」（§5 推论已论证安全边界）；真把它乘进状态维度就退化成 $8 \times 10^6$ 状态的暴力。
9. **初始态恒非终止**：题面保证 `C` / `M` / `F` 互异，初始 $m \ne c$、$m \ne \text{food}$、$c \ne \text{food}$，无需特判；但初始化终止态时要完整枚举所有 $(m, c, t)$，不要顺手跳过「看起来多余」的组合。
