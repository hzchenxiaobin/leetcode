# LeetCode 同积元组 题解

## 1. 题目概述

- **标题 / 题号**：同积元组（#1726，medium）
- **链接**：https://leetcode.cn/problems/tuple-with-same-product/
- **来源**：LeetCode 第 224 场周赛 Q2
- **难度**：中等
- **标签**：数组、哈希表、计数

**题意**：给你一个由**互不相同**的正整数组成的数组 `nums`，返回满足 $a \times b = c \times d$ 的元组 $(a, b, c, d)$ 的数目，其中 $a, b, c, d$ 都是 `nums` 中的元素，且四个数**互不相同**。

**约束**：

- $1 \le \text{nums.length} \le 1000$
- $1 \le \text{nums[i]} \le 10^4$
- `nums` 中所有元素**互不相同**

> ⚠️ 题面里 `a != b != c != d` 是链式简写，实际含义是 $a, b, c, d$ **两两互不相同**（即四个不同的数组元素），并非只要求相邻不等。「元素互异 + 正整数」这两个条件是全题简化的根基（见 §5 引理 1）。

> 💡 本题在本仓库另有[每日题解 1726](../../solution/1701-1800/1726_同积元组.md)：以「乘积分组的两种等价计数推导、元素可重复时的退化分析与面试问答」展开。本篇按**周赛复盘视角**重写：侧重**赛时最短切入路径**、**$8 = 2 \times 2 \times 2$ 倍数的结构拆解**与**引理—定理证明链**，两篇互为印证。

## 3. 解题思路

### 3.1 暴力思路：枚举四元组

最直接的做法是枚举所有由四个不同元素组成的有序四元组 $(a, b, c, d)$ 并检验 $a \times b = c \times d$，时间 $O(n^4)$。$n = 1000$ 时约 $10^{12}$ 次检验，必然超时。

退一步观察：元组本来就被等式**沿中间切成两半**——前两格是一个数对，后两格是另一个数对。于是只枚举**无序数对**：$i < j$ 的双循环产生 $O(n^2) \approx 5 \times 10^5$ 个数对，问题变成「每个数对有多少个**其他**数对与它乘积相同」。若两层循环互相配对验证仍是 $O(n^4)$；而把「查询同积数对个数」交给**哈希表**，一边枚举一边计数，每次查询降为均摊 $O(1)$——这就是正解的形态。

### 3.2 核心观察：以「无序数对」为计数单位

![核心概念：元组拆成两个同积无序数对，恰好对应 8 种排列](images/wc224_q2_pair_product_concept.svg)

把元组 $(a, b, c, d)$ 沿中间拆开：**前两个位置**组成无序数对 $P = \{a, b\}$，**后两个位置**组成无序数对 $Q = \{c, d\}$，方程 $a \times b = c \times d$ 说明 $P$、$Q$ **乘积相同**。于是自然以「乘积相同的无序数对」为计数单位，有两条关键性质：

- **性质一（自动不交）**：两个**相异**的同积数对必然**不共享元素**。若 $\{x, y\}$ 与 $\{x, v\}$ 共享 $x$ 且 $x \cdot y = x \cdot v$，由 $x \ge 1$ 约去 $x$ 得 $y = v$，两数对相同，矛盾。所以「四个数互不相同」这一合法性条件**免费成立**，无需任何判交或去重。
- **性质二（恰好 8 倍）**：固定一对同积数对 $\{a,b\}$ 与 $\{c,d\}$，能排出的合法元组恰有 $2 \times 2 \times 2 = 8$ 个：$\{a,b\}$ 内部顺序（2）× $\{c,d\}$ 内部顺序（2）× 两组前后交换（2）。

> 💡 示例 1 的 8 个元组全部来自 $\{2,6\}$ 与 $\{3,4\}$ 这一对组合——8 不是巧合，而是计数结构固有的倍数。

于是问题归约为**两步计数**：

1. 用哈希表统计每个乘积 $p$ 的**无序数对个数** $\text{cnt}[p]$；
2. 从 $k = \text{cnt}[p]$ 个同积数对中任选两个，有 $\binom{k}{2}$ 种组合，每种组合贡献 8 个元组：

$$\text{ans} \;=\; \sum_{p} 8 \times \binom{\text{cnt}[p]}{2} \;=\; \sum_{p} 4 \times \text{cnt}[p] \times (\text{cnt}[p] - 1)$$

### 3.3 算法流程：数对乘积哈希计数

![算法流程：阶段一枚举数对建乘积频次表，阶段二按乘积聚合求和](images/wc224_q2_hash_count_flow.svg)

算法分两个阶段：

- **阶段一（枚举计数）**：双循环枚举 $i < j$，计算 $p = \text{nums}[i] \times \text{nums}[j]$，执行 $\text{cnt}[p] \mathrel{+}= 1$；
- **阶段二（聚合求和）**：遍历哈希表，对每个 $k = \text{cnt}[p] \ge 2$ 的乘积累加 $4 \times k \times (k - 1)$；$k \le 1$ 的乘积贡献为 0，可跳过。

### 3.4 示例演算

![示例演算：[1,2,4,5,10] 的数对枚举、乘积聚合与答案计算](images/wc224_q2_walkthrough.svg)

以示例 2 `nums = [1,2,4,5,10]` 为例。$C(5,2) = 10$ 个无序数对的乘积依次为 $2, 4, 5, 10, 8, 10, 20, 20, 40, 50$，聚合得 $\text{cnt}[10] = \text{cnt}[20] = 2$，其余乘积均为 1：

| 乘积 $p$ | 数对 | $k = \text{cnt}[p]$ | 贡献 $4k(k-1)$ |
|----------|------|---------------------|----------------|
| $10$ | $\{1,10\}, \{2,5\}$ | $2$ | $8$ |
| $20$ | $\{2,10\}, \{4,5\}$ | $2$ | $8$ |
| 其余 | 各 1 对 | $1$ | $0$ |

$\text{ans} = 8 + 8 = 16$ ✓。

> 💡 **示例 3 的关键一步**：$\text{cnt}[12] = 3$ 时，三个数对 $\{1,12\}, \{2,6\}, \{3,4\}$ 两两组合有 $\binom{3}{2} = 3$ 种（由引理 1，任意两个都自动不交），贡献 $3 \times 8 = 24 = 4 \times 3 \times 2$ 个元组——这正是公式中 $\binom{k}{2}$ 的来源，也说明 $k$ 再大时公式依然只需一行。

## 4. 算法细节

1. **只枚举 $i < j$**：无序数对 $\{x, y\}$ 与 $\{y, x\}$ 是同一个计数单位，内层循环从 $i + 1$ 开始，保证每个数对恰入表一次；若枚举全部有序对，$\text{cnt}$ 翻倍且「共享元素的数对」混入，公式直接失效。
2. **乘积用 `int` 存即可**：$10^4 \times 10^4 = 10^8 < 2^{31} - 1$，C++ 中 `nums[i] * nums[j]` 不溢出，可直接作哈希键。
3. **计数公式的两种等价写法**：无序视角 $8\binom{k}{2}$（先选无序两对，再乘 8 种排列）与有序视角 $4k(k-1)$（先选有序两对 $k(k-1)$，再乘每对内部 4 种交换）数值相同。三个因子分别对应两个数对的内部顺序与两组前后交换，漏掉任何一个都会得到 4、2 等错误倍数——用示例 1 的 8 个元组逐一对照验证。
4. **无需判交、无需去重**：由引理 1，相异的同积数对自动不交，$\binom{k}{2}$ 种组合全部合法；也不存在同一元组被两组数对重复计数——元组的前两格、后两格唯一确定它所属的数对组合（见 §5 引理 2）。
5. **$k = 1$ 无需特判**：$4 \times 1 \times 0 = 0$，直接套公式即可；加 `if (k >= 2)` 只是省一点循环开销。
6. **数据结构选择**：哈希表（`unordered_map` / `dict`）总体 $O(n^2)$；若想避开哈希，可把 $O(n^2)$ 个乘积存入数组**排序**后扫描连续相等段，$O(n^2 \log n)$，略慢但无哈希常数，同样能过。

## 5. 正确性证明

**引理 1（同积相异数对必不交）**：设 $\{x, y\}$ 与 $\{u, v\}$ 是两个由 `nums` 中元素组成的无序数对（数对内两元素不同），且 $x \cdot y = u \cdot v$。若两数对相异，则它们不共享任何元素。

**证明**：反证。若共享某元素，由无序性不妨设 $x = u$，则 $x \cdot y = x \cdot v$。因 $x \ge 1$ 非零，约去 $x$ 得 $y = v$，于是 $\{x, y\} = \{u, v\}$，与两数对相异矛盾。∎

**引理 2（8:1 对应）**：设映射 $\varphi$ 把每个由四个不同值组成的有序四元组 $(a, b, c, d)$ 映到无序数对组合 $\big\{\{a, b\}, \{c, d\}\big\}$。则每个**同积数对组合** $\{P, Q\}$（$P \neq Q$ 且 $\mathrm{prod}(P) = \mathrm{prod}(Q)$）的原像 $\varphi^{-1}(\{P, Q\})$ 恰含 8 个四元组，且全部是合法元组；全体合法元组恰被所有原像**不重不漏**地划分。

**证明**：先算原像大小。设 $P = \{a, b\}$、$Q = \{c, d\}$，则原像中的四元组前两格恰为 $P$ 的一个排列、后两格恰为 $Q$ 的一个排列（$2 \times 2 = 4$ 个），或前 $Q$ 后 $P$（再 4 个），共 8 个；凡满足该位置结构的四元组显然都在原像中。由引理 1，$P \cap Q = \emptyset$，故这 8 个四元组四数互异，且前两数之积与后两数之积都等于同一 $p$，均为合法元组。

再证划分。任取合法元组 $t = (a, b, c, d)$：由四数互异知 $\{a, b\} \neq \{c, d\}$，由 $a \cdot b = c \cdot d$ 知二者是相异同积数对，故 $t \in \varphi^{-1}\big(\{\{a,b\}, \{c,d\}\}\big)$，落在某个同积数对组合的原像中。同一映射的不同原像两两不交，故「合法元组集合 = 所有同积数对组合的原像之并」，不重不漏。∎

**定理**：$\displaystyle \text{ans} = \sum_{p} 4 \times \text{cnt}[p] \times (\text{cnt}[p] - 1)$，其中 $\text{cnt}[p]$ 是乘积等于 $p$ 的无序数对个数。

**证明**：对每个乘积 $p$，共有 $\text{cnt}[p]$ 个数对，任取两个相异数对的方法数为 $\binom{\text{cnt}[p]}{2}$。由引理 1，任一这样的组合都是同积数对组合；由引理 2，每个组合恰对应 8 个合法元组，不同组合（无论是否同一 $p$）对应的元组互不相同，且全体合法元组都被覆盖。故

$$\text{ans} = \sum_{p} 8 \binom{\text{cnt}[p]}{2} = \sum_{p} 4\, \text{cnt}[p]\, (\text{cnt}[p] - 1). \;\; \blacksquare$$

## 6. 复杂度分析

- **时间复杂度**：$O(n^2)$。阶段一双循环枚举 $C(n, 2) \le 499500$ 个数对，每次一次乘法加一次均摊 $O(1)$ 的哈希插入；阶段二遍历哈希表至多 $O(n^2)$ 个键。$n = 1000$ 时约 $5 \times 10^5$ 次哈希操作，远在时限内。
- **空间复杂度**：$O(n^2)$。最坏情形所有数对乘积互异，哈希表需存下全部 $C(n, 2) \approx 5 \times 10^5$ 个键值对（几 MB 量级，可接受）。排序替代方案同样需要 $O(n^2)$ 空间存乘积数组。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int tupleSameProduct(vector<int>& nums) {
        int n = nums.size();
        unordered_map<int, int> cnt;
        for (int i = 0; i < n; ++i)
            for (int j = i + 1; j < n; ++j)
                ++cnt[nums[i] * nums[j]];          // 乘积 ≤ 1e8，int 键足够
        int ans = 0;
        for (auto& [p, k] : cnt)
            ans += 4 * k * (k - 1);                // 8 * C(k, 2)，k = 1 时为 0
        return ans;
    }
};
```

### Python

```python
class Solution:
    def tupleSameProduct(self, nums: List[int]) -> int:
        cnt = {}
        n = len(nums)
        for i in range(n):
            for j in range(i + 1, n):
                p = nums[i] * nums[j]
                cnt[p] = cnt.get(p, 0) + 1
        return sum(4 * k * (k - 1) for k in cnt.values())
```

赛时追求手速可用标准库一行聚合（$O(n^2)$ 时间 / $O(n^2)$ 空间）：

```python
from itertools import combinations
from collections import Counter

class Solution:
    def tupleSameProduct(self, nums: List[int]) -> int:
        cnt = Counter(a * b for a, b in combinations(nums, 2))
        return sum(4 * k * (k - 1) for k in cnt.values())
```

## 8. 边界情况与易错点

1. **$n < 4$ 时答案为 0**：凑不出四个互异元素；公式自动给出 0（$n \le 3$ 时任意两个数对必共享元素，由引理 1 所有乘积必互异），无需特判。
2. **8 倍系数**：最常见错误是只乘 4（漏掉两组前后交换）或只乘 2（再漏数对内部顺序）。对照示例 1 的 8 个元组逐个验证倍数来源。
3. **重复枚举数对**：内层循环必须从 `i + 1` 开始；若枚举全部有序对，$\text{cnt}$ 翻倍，公式结果错误。
4. **溢出**：乘积 $\le 10^8$ 在 `int` 内；答案上界也可控——$k = \text{cnt}[p]$ 不超过 $p$ 的约数个数的一半，而 $p \le 10^8$ 的约数个数纪录为 768，故 $k \le 384$，$\text{ans} \le 4 \times 383 \times \binom{1000}{2} \approx 7.6 \times 10^8 < 2^{31}$，`int` 累加安全。但这是依赖值域 $10^4$ 的精细结论，赛时不想推就直接用 `long long` 更省心；Python 无溢出问题。
5. **读题坑**：`a != b != c != d` 意为四数两两不同；「元素互不相同」也是前提——元素可重复时引理 1 失效（见延伸思考）。
6. **不必判交**：无需检查两个数对是否共享元素，引理 1 保证同积的相异数对自动不交；多写判重逻辑反而引入出错空间。
