# LeetCode 范围内最接近的两个质数 题解

## 1. 题目概述

- **标题 / 题号**：范围内最接近的两个质数（#2523，medium）
- **链接**：https://leetcode.cn/problems/closest-prime-numbers-in-range/
- **来源**：LeetCode 第 326 场周赛 Q4
- **难度**：中等
- **标签**：数学、数论、埃拉托斯特尼筛法

**题意**：给定正整数 $\text{left}$、$\text{right}$，在闭区间 $[\text{left}, \text{right}]$ 内找两个质数 $\text{num1} < \text{num2}$，使 $\text{num2} - \text{num1}$ 是所有合法质数对中的**最小值**；有多个差值相同的最优对时返回 $\text{num1}$ 最小的一对；区间内质数不足两个时返回 $[-1, -1]$。

**约束**：

- $1 \le \text{left} \le \text{right} \le 10^6$——值域只有一百万且**单组查询**，一次性把 $[0, \text{right}]$ 的质数标记全建出来毫无压力
- 区间是**闭**区间：$\text{right}$ 本身也可能入选答案，筛表必须开到下标 $\text{right}$

> 💡 **赛时最短路径**：本场 Q4 标橙（medium），是罕见的"温柔压轴"。两个信号直指解法——①值域 $10^6$ 的批量判素，想**埃氏筛**而非逐个试除；②"取两数最小化差值"且数据天然升序，最优对必然**相邻**（中间夹着谁，谁就更近），两两枚举塌缩成单趟扫描。实现只剩三个坑要防：比较必须**严格小于**（并列取 $\text{num1}$ 最小）、筛表开 $\text{right}+1$ 并预置 $0/1$ 为合数、别忘了区间里可能一个质数都没有。

## 2. 示例

**示例 1**

```text
输入：left = 10, right = 19
输出：[11, 13]
解释：10 到 19 之间的质数为 11、13、17、19。
      质数对的最小差值是 2，[11,13] 和 [17,19] 都取得最小差值；
      由于 11 比 17 小，返回第一个质数对 [11,13]。
```

**示例 2**

```text
输入：left = 4, right = 6
输出：[-1, -1]
解释：给定范围内只有质数 5 一个，凑不出一对。
```

**示例 3（自造，展示 gap = 1 的唯一特例）**

```text
输入：left = 2, right = 10
输出：[2, 3]
解释：范围内质数为 2、3、5、7，相邻差依次为 1、2、2。
      (2, 3) 是唯一一对"相邻整数都是质数"，gap = 1 必为全局最小。
```

## 3. 解题思路

### 3.1 暴力思路：试除判素 + 两两枚举

最朴素的做法分两步：对 $[\text{left}, \text{right}]$ 内每个数用试除法判素（除到 $\sqrt n$），收集出 $m$ 个质数；再两两枚举 $\binom{m}{2}$ 个质数对维护最小差。两个**独立**的瓶颈：

- **判素**：单数 $O(\sqrt R)$，整段 $O(R\sqrt R) \approx 10^9$ 次除法——实测 CPython 判 $[1, 10^6]$ 全部数约 2.3 s，撞时限边缘；
- **配对**：$m = \pi(10^6) = 78498$，$\binom{m}{2} \approx 3.1 \times 10^9$ 对，即使每对 $O(1)$ 也必然超时。

拆掉第一个瓶颈靠**筛法**（逐个验证 → 批量标记），拆掉第二个靠**相邻性**（两两枚举 → 只看相邻对）。这正是下文的两个观察。

### 3.2 核心观察：最优对必相邻

![核心观察：非相邻对被自己的相邻前缀严格压过，并列对也必相邻](images/wc326_q4_adjacent_concept.svg)

三个环环相扣的观察：

- **观察 1（批量判素）**：与其对每个数问"你是质数吗"（$O(\sqrt R)$/个），不如用**埃氏筛**主动划掉合数：从 2 起，每遇到未划掉的数 $i$ 即为质数，划掉 $i^2, i^2+i, \ldots$。外层只需跑到 $\sqrt R$，总代价 $O(R \log\log R)$，$R = 10^6$ 时实测只划约 $2.1 \times 10^6$ 格。
- **观察 2（最优对相邻）**：把范围内质数升序排成 $p_1 < p_2 < \cdots < p_m$。任取合法对 $(p_i, p_j)$：若 $j \ge i + 2$（中间还夹着 $p_{i+1}$），则 $(p_i, p_{i+1})$ 也是合法对，且其 gap $p_{i+1} - p_i < p_j - p_i$。**非相邻对被自己的相邻前缀严格压过**——最小 gap 只能在相邻对中取得，且取得最小 gap 的对（含并列的）也必是相邻对。于是 $\binom{m}{2}$ 次枚举塌缩成 $m - 1$ 次相邻比较。
- **观察 3（gap 的奇偶结构）**：除 2 外质数全是奇数，两奇数之差为偶数 $\ge 2$；而 $(2, 3)$ 是唯一的"相邻整数都是质数"。所以**相邻质数 gap $= 1 \iff$ 这对就是 $(2, 3)$，其余 gap 全为偶数**。这既是扫描中"命中 gap $\le 2$ 即可早停"的依据，也是对拍时最顺手的 sanity check（见 §8 第 7 条）。

> ⚠️ **并列规则别读错**：题面要求"多个最优对时返回 $\text{num1}$ 最小的一对"，不是任意一组。观察 2 已保证并列候选全是相邻对，而升序扫描 + **严格小于**更新天然保留**首次**出现的最小对——首次出现即 $\text{num1}$ 最小，一行特判都不用加。

### 3.3 算法流程：筛 + 单趟扫描

![算法流程：埃氏筛建表，升序单趟扫描，严格小于更新](images/wc326_q4_sieve_scan_flow.svg)

伪代码（`prev` 为已扫到的最后一个质数）：

```text
sieve = 埃氏筛 [0..right]               # 观察 1：批量判素
prev = -1, best = +inf, ans = [-1, -1]
for x in [left, right]:                  # 升序
    if not sieve[x]: continue
    if prev >= 0 and x - prev < best:    # 严格 <：并列保住先出现的
        best = x - prev
        ans = [prev, x]
    prev = x
return ans                               # 质数不足两个时 ans 从未更新
```

两条**循环不变式**贯穿扫描：① `prev` 恒等于 $[\text{left}, x)$ 内最大的质数（$-1$ 表示尚未遇到质数）；② `best` / `ans` 恒为"已见相邻对中的最小 gap 及其首次出现的对"。严格小于的更新只放宽 `best`、绝不覆盖并列，不变式②由此保持。

### 3.4 示例演算

![示例演算：left=10、right=19 的相邻对扫描表与并列处理](images/wc326_q4_walkthrough.svg)

以例 1 走查（表格见上图）：

| 相邻对 | gap | 与 best | 动作 |
|---|---|---|---|
| $(11, 13)$ | 2 | $2 < +\infty$ ✓ | best = 2，ans = [11,13] |
| $(13, 17)$ | 4 | $4 \not< 2$ ✗ | 不更新 |
| $(17, 19)$ | 2 | $2 \not< 2$ ✗（并列） | 不更新，保住 [11,13] |

扫描结束返回 $[11, 13]$ ✓。第三行是全场最险的一步：$(17,19)$ 与 $(11,13)$ 同为 gap 2，若比较误写成 $\le$，答案会被覆盖成 $[17,19]$，示例 1 当场 WA。

- **例 2**（$[4, 6]$）：只有质数 5，循环里 `prev ≥ 0` 与"当前数质数"凑不齐第二次，ans 保持 $[-1,-1]$ ✓。
- **例 3**（$[2, 10]$）：质数 2、3、5、7，首对 $(2,3)$ gap 1 立即锁定 best = 1；此后任何 gap 都是偶数 $\ge 2$，不可能再严格小于，返回 $[2,3]$ ✓。

## 4. 算法细节

1. **筛表开 `right + 1`，预置 0/1 为合数**：区间闭、$\text{right}$ 本身待判定，差一会越界。$\text{left}$ 可为 1，`sieve[1] = 0` 正好挡住"1 被当质数"的经典错误（$[1, 2]$ 应返回 $[-1,-1]$）。
2. **外层只到 $\sqrt{\text{right}}$，内层从 $i^2$ 起步**：更小的倍数 $k \cdot i$（$k < i$）早在筛 $\mathrm{spf}(k) \le k < i$ 时就被划过（$k \cdot i \ge \mathrm{spf}(k)^2$ 恒成立）。$R = 10^6$ 时 $i \le 10^3$、$i^2 \le 10^6$，`int` 不溢出；但养成 `i <= right / i` 写法可免疫范围升级后的溢出。
3. **比较必须严格小于**：并列规则 = 首次出现 = $\text{num1}$ 最小。`<=` 会用 $[17,19]$ 覆盖 $[11,13]$，见 §8 第 1 条。
4. **`prev ≥ 0` 守卫**：范围内第一个质数没有前驱，只置 `prev` 不参与比较。丢掉守卫或把 `prev` 初值设成非 $-1$ 的数，会在区间头部对出假对。
5. **单趟扫描 vs 先收集再扫**：两变量版省掉 $O(m)$ 的质数数组，"质数不足两个"自然归约为"ans 从未更新"；先收集质数再扫（站内每日题解的写法）带显式 `len(primes) < 2` 守卫，逻辑更直白。两者完全等价，按手感选。
6. **常数工程**：C++ 用 `vector<char>` 而非 `vector<bool>`（位压缩的间接寻址慢约 2~3 倍）；Python 必须用 `bytearray` + 切片赋值 `sieve[i*i::i] = bytes(n)`，比逐元素循环标记快一个量级，切片长度公式 $(\text{right} - i^2) \,//\, i + 1$ 别代错（见 §8 第 6 条）。
7. **早停（可选）**：由观察 3，命中 gap $\le 2$ 即可 `break`——gap $= 1$ 只可能是首对 $(2, 3)$，其余 gap 为偶数不可能小于 2。纯常数优化，不改变最坏复杂度。

## 5. 正确性证明

**引理 1（埃氏筛正确性）**：筛法结束后，$\text{sieve}[x] = 1 \iff 2 \le x \le \text{right}$ 且 $x$ 是质数。

**证明**：初始时 $\text{sieve}[0] = \text{sieve}[1] = 0$、其余为 1；标记只把某些下标从 1 改成 0。先看"不会被标 0"的方向：若 $x$ 是质数且 $2 \le x \le \text{right}$，任何标记步都形如"$j$ 是某个 $i \in [2, \lfloor\sqrt{\text{right}}\rfloor]$ 的倍数"，一旦命中 $x$ 便有 $i \mid x$ 且 $2 \le i \le \sqrt{\text{right}}$，则 $i \le \sqrt{x} < x$ 与 $x$ 无真因子矛盾——故 $x$ 全程保持 1。再看"必被标 0"的方向：设 $x \le \text{right}$ 是合数，取最小质因子 $p$，写 $x = p \cdot m$。$m$ 的质因子全 $\ge p$（否则与 $p$ 最小矛盾），故 $m \ge p$，从而 $x \ge p^2$；又 $p \le \sqrt{x} \le \sqrt{\text{right}}$，外层会以 $i = p$ 进入，且 $\text{sieve}[p]$ 此时仍为 1（$p$ 是质数，由上一方向知其永不被标），内层从 $p^2$ 步长 $p$ 覆盖 $[p^2, \text{right}]$ 中全部 $p$ 的倍数——$x$ 命中，被标 0。∎

**引理 2（最优对与并列对都必相邻）**：设 $m \ge 2$，范围内质数升序 $p_1 < \cdots < p_m$，$\delta^*$ 为全部合法对的最小 gap。则 (a) 每个 gap $= \delta^*$ 的合法对都是相邻对 $(p_i, p_{i+1})$；(b) $\delta^* = \min_{1 \le i < m} (p_{i+1} - p_i)$。

**证明**：合法对形如 $(p_i, p_j)$，$i < j$。若 $j \ge i + 2$，则 $p_{i+1}$ 仍在范围内且 $(p_i, p_{i+1})$ 合法，其 gap 满足 $p_{i+1} - p_i < p_j - p_i$——即**每个非相邻对都被以其左端为起点的相邻对严格压过**。于是 (b)：全局最小值不可能落在非相邻对上（否则被严格更小的相邻对取代），故 $\delta^*$ 在相邻对中取得；(a)：若某非相邻对 gap 恰为 $\delta^*$，则相应相邻对 gap 严格小于 $\delta^*$，与 $\delta^*$ 的最小性矛盾，故并列的最小对也全是相邻对。∎

**定理（算法正确性）**：返回的 `ans` 恰为题意所求——gap 最小的合法对中 $\text{num1}$ 最小的一对；不存在合法对时返回 $[-1, -1]$。

**证明**：分两种情形。

(i) $m \le 1$（含 $m = 0$）：循环中"当前数是质数"至多发生一次，只置 `prev`；`prev ≥ 0` 与"当前数质数"无法同时成立第二次，更新永不触发，`ans` 保持初值 $[-1, -1]$，与"合法对不存在"一致 ✓。

(ii) $m \ge 2$：由引理 2，候选答案集恰为全部 $m - 1$ 个相邻对。扫描升序进行：每遇到一个质数 $x$，`prev` 由不变式①恰为序列中 $x$ 的前一项，故产生的对正是 $(p_i, p_{i+1})$，且按 $i$ 递增的顺序不重不漏地遍历。设取到 $\delta^*$ 的相邻对按扫描序为 $(q_1, r_1), \ldots, (q_t, r_t)$（$q_1 < q_2 < \cdots < q_t$）。首个 $\delta^*$ 对出现之前，已见各对 gap 均 $> \delta^*$（若有 $= \delta^*$ 者它才是首个），故此刻 best $> \delta^*$，严格小于判断成立，`ans ← (q_1, r_1)`、best $\gets \delta^*$。此后任何对 gap $\ge \delta^*$，不满足严格小于，`ans` 不再变动。最终答案 gap $= \delta^*$ 为最小 ✓；其余并列对满足 $q_k \ge q_2 > q_1$，故 $\text{num1} = q_1$ 为并列中最小 ✓。∎

> 💡 **另一视角（望远镜求和）**：非相邻对的 gap $p_j - p_i = \sum_{t=i}^{j-1}(p_{t+1} - p_t)$ 是若干相邻差之和，故不小于最小相邻差——这同样给出 (b)。但"夹逼"论证更强：它还给出了**严格**不等号，从而排除非相邻对并列，这正是定理中并列情形所需要的。两套论证合起来看，"有序集合上取两数最小差 ⇒ 只看相邻"这条范式的适用边界也就清楚了：它要求并列规则也只依赖"扫描序首个"，一旦题目并列规则改成"$\text{num2}$ 最小"之类的**非**首序规则，就不能再裸用严格小于，得显式比较 $(\text{gap}, \text{num1})$ 字典序。

## 6. 复杂度分析

- **时间复杂度**：$O(R \log\log R)$，$R = \text{right}$。埃氏筛代价 $\sum_{p \le \sqrt R}(\lfloor R/p \rfloor - p + 1)$，$R = 10^6$ 时实测划掉约 $2.1 \times 10^6$ 格；扫描 $O(R)$，其中有效比较仅 $m - 1 = 78497$ 次。CPython 实测筛 + 全区间扫描合计约 0.1 s。
- **空间复杂度**：$O(R)$。`bytearray` / `vector<char>` 的筛表恰约 1 MB；不收集质数数组则额外空间 $O(1)$。
- **对照（试除判素版）**：$O(R\sqrt R) \approx 10^9$ 次除法，实测约 2.3 s——同一语言慢 20 倍以上；$R$ 提到 $10^7$ 时试除按 $R^{1.5}$ 放大约 30 倍、筛法只按 $R$ 放大 10 倍，差距继续拉开。
- **对照（两两枚举版）**：判素改用筛也救不了配对这一层，$\binom{m}{2} \approx 3.1 \times 10^9$ 对照样超时——相邻性观察拆的是第二个瓶颈。

## 7. 参考代码

### C++（埃氏筛 + 单趟扫描）

```cpp
class Solution {
public:
    vector<int> closestPrimes(int left, int right) {
        vector<char> sieve(right + 1, 1);
        sieve[0] = sieve[1] = 0;                     // 0、1 不是质数
        for (int i = 2; i * i <= right; ++i)         // 只筛到 √right
            if (sieve[i])
                for (int j = i * i; j <= right; j += i)  // 从 i² 起划倍数
                    sieve[j] = 0;

        int prev = -1, best = INT_MAX;
        vector<int> ans = {-1, -1};
        for (int x = left; x <= right; ++x) {        // 升序单趟扫描
            if (!sieve[x]) continue;
            if (prev >= 0 && x - prev < best) {      // 严格 <：并列保住先出现的
                best = x - prev;
                ans = {prev, x};
            }
            prev = x;
        }
        return ans;
    }
};
```

> 💡 `vector<char>` 换 `vector<bool>` 在本题规模下都能过，但位寻址的常数差在更大筛表上会显形；$i \cdot i \le 10^6$ 不溢出 `int`，保守可写 `i <= right / i`。

### Python（bytearray 切片筛）

```python
class Solution:
    def closestPrimes(self, left: int, right: int) -> List[int]:
        sieve = bytearray([1]) * (right + 1)
        sieve[0] = sieve[1] = 0
        i = 2
        while i * i <= right:                      # 只筛到 √right
            if sieve[i]:
                n = (right - i * i) // i + 1       # 内层要划掉的格数
                sieve[i * i :: i] = bytes(n)       # 切片批量清零
            i += 1

        prev, best, ans = -1, float("inf"), [-1, -1]
        for x in range(left, right + 1):           # 升序单趟扫描
            if not sieve[x]:
                continue
            if prev >= 0 and x - prev < best:      # 严格 <：并列保住先出现的
                best, ans = x - prev, [prev, x]
            prev = x
        return ans
```

> 💡 `sieve[i*i::i] = bytes(n)` 是 Python 筛法的核心常数技巧：整段切片在 C 层一次清零，等价于内层循环但快一个量级；长度 `n` 必须精确等于该切片的元素个数，否则 `ValueError`（见 §8 第 6 条）。

### 对照：试除判素（能过但慢 20 倍以上）

```python
class Solution:
    def closestPrimes(self, left: int, right: int) -> List[int]:
        def is_prime(n: int) -> bool:
            if n < 2: return False
            if n % 2 == 0: return n == 2
            d = 3
            while d * d <= n:
                if n % d == 0: return False
                d += 2
            return True

        prev, best, ans = -1, float("inf"), [-1, -1]
        for x in range(left, right + 1):
            if not is_prime(x):
                continue
            if prev >= 0 and x - prev < best:
                best, ans = x - prev, [prev, x]
            prev = x
        return ans
```

> 💡 试除版结构上与主解法只差判素函数，实测约 2.3 s（主解法 0.1 s）。它在 C++ 下稳过、Python 下贴着线过；一旦范围升到 $10^7$ 或时限收紧就先死。数论题的选型口诀：**点查询用试除，区间批量用筛**——本场 Q2（2521 质因数分解）恰好是"点查询"一侧的练习，两题连起来正好凑成一对。

## 8. 边界情况与易错点

1. **比较误写成 $\le$**：并列的最小 gap 对会被后出现的覆盖。反例就是示例 1——正确 $[11,13]$，误写后返回 $[17,19]$。本题全场最大的坑，一行的事。
2. **1 不是质数**：$\text{left} = 1$ 时（如 $[1,2]$ 应返回 $[-1,-1]$）若筛表忘了预置 `sieve[1] = 0`，会产出形如 $[1, x]$ 的假答案。
3. **筛表差一**：开成 `right` 而非 `right + 1`，访问 `sieve[right]` 越界（Python `IndexError`，C++ 直接 UB）。
4. **质数不足两个**：$[4,6]$（单质数）、$[14,16]$（零质数）、$[19,19]$（单点）都应返回 $[-1,-1]$；单趟扫描版靠"ans 从未更新"兜底，收集版靠 `len(primes) < 2` 守卫，别两套守卫都忘。
5. **外层边界写成严格小于**：`i * i < right` 会在 $\text{right}$ 为完全平方数时漏筛。反例 $\text{right} = 25$：$25 = 5^2$ 的最小质因子恰是 5，只有 $i = 5$ 这一趟（内层起点 $25$）能划掉它，外层写成 $<$ 则 $25$ 被当成质数，$[20, 25]$ 会错误输出 $[23, 25]$。
6. **Python 切片长度代错**：`sieve[i*i::i]` 的元素个数是 $(\text{right} - i^2) // i + 1$；扩展切片赋值要求两侧长度严格相等，写错直接 `ValueError: bytes length mismatch`（报错还算友好，怕就怕在某些写法下静默截断）。
7. **gap 奇偶性当 sanity check**：除 $(2,3)$ 外相邻质数 gap 全为偶数——对拍时若输出 gap 为 $3, 5$ 这类奇数，代码必有 bug；反之区间覆盖 $\{2, 3\}$ 时答案必是 $[2,3]$。
8. **早停的两种小失误**：先 `break` 后更新会把答案丢掉（顺序必须先更新再判）；判 `g == 2` 而非 `g <= 2` 时，$(2,3)$ 这对 gap $=1$ 不触发早停——不影响正确性，只白扫了尾巴。

**延伸思考**：① **多组查询版**（如 $10^4$ 组 $[\text{left}, \text{right}]$）：每组重筛必超时——预计算质数数组与相邻 gap 数组 $g_i = p_{i+1} - p_i$，把"对完全落在 $[L, R]$ 内"翻译成下标区间 $i \in [\text{first}(p_i \ge L),\ \text{last}(p_{i+1} \le R)]$，建稀疏表做"区间最小 gap 及最左出现位置"，单组查询降到 $O(1)$。② **$\text{right}$ 大到 $10^{14}$（区间长仍 $\le 10^6$）**：整段筛不可行，改**分段筛**——先筛出 $\sqrt{R} \le 10^7$ 内的全部质数（$\pi(10^7) = 664579$ 个），再用它们标记 $[L, R]$，空间 $O(\sqrt R + \text{区间长})$，扫描逻辑一字不改。③ **孪生质数**：gap $= 2$ 的相邻对即孪生质数，$10^6$ 内共 8169 对；孪生质数猜想（无穷多对）至今未证，目前最好的结果是"无穷多对 gap $\le 246$"（张益唐 2013 开创、Polymath 改进）。$10^6$ 内最大相邻 gap $= 114$（$492113 \to 492227$），素数定理给出的平均 gap 约 $\ln R \approx 13.8$——短区间落在"质数荒漠"时答案 gap 可能远大于 2，这正是早停只是常数优化的原因。④ **对偶问法**"范围内相邻质数 gap **最大**的一对"：同一趟扫描取 max 即可，并列规则按题意另行处理。
