# LeetCode 数组乘积中的不同质因数数目 题解

## 1. 题目概述

- **标题 / 题号**：数组乘积中的不同质因数数目（#2521，medium）
- **链接**：https://leetcode.cn/problems/distinct-prime-factors-of-product-of-array/
- **来源**：LeetCode 第 326 场周赛 Q2
- **难度**：中等
- **标签**：数组、哈希表、数学、数论、质因数分解

**题意**：给定正整数数组 $\text{nums}$，把所有元素相乘得到 $P = \prod_i \text{nums}[i]$，返回 $P$ 的**不同质因数**个数——只问**种类**，不问每个质因数出现几次（重数）。

**约束**：

- $1 \le \text{nums.length} \le 10^4$
- $2 \le \text{nums}[i] \le 1000$

> 💡 **赛时最短路径**：两个信号直指解法——①「乘积的质因数」由唯一分解定理等于**各元素质因数的并集**，根本不必算出乘积；②约束 $\text{nums}[i] \le 1000$ 意味着每个元素试除只枚举到 $\sqrt{1000} \approx 32$。于是「分解 $10^{30000}$ 位大数」被降为「分解 $10^4$ 个不超过 3 位的小数」，套路代码（试除 + `set`）两分钟可交。

## 2. 示例

**示例 1**

```text
输入：nums = [2,4,3,7,10,6]
输出：4
解释：乘积 = 2 * 4 * 3 * 7 * 10 * 6 = 10080 = 2⁵ * 3² * 5 * 7
      共 4 个不同质因数（2、3、5、7），返回 4。
```

**示例 2**

```text
输入：nums = [2,4,8,16]
输出：1
解释：乘积 = 2 * 4 * 8 * 16 = 1024 = 2¹⁰，只有 1 个不同质因数，返回 1。
```

## 3. 解题思路

### 3.1 暴力思路：先算乘积再分解

照题面字面执行：先把 $10^4$ 个数乘成 $P$，再对 $P$ 分解质因数、数不同质因子。

死穴在 $P$ 的规模：$n = 10^4$、$\text{nums}[i] \le 1000$ 时 $P \le 1000^{10^4} = 10^{30000}$，是一个**约 3 万位**的大数。C++/Java 的 64 位整数只装得下 $9.2 \times 10^{18}$（19 位），累乘过程第二十几步就溢出；即便 Python 大整数硬扛，对 $10^{30000}$ 位的数做质因数分解也是天文开销。这条路既慢又**毫无必要**——题目要的是「不同质因数的数目」，不是乘积本身。

### 3.2 核心观察：乘积的质因数 = 各元素质因数的并集

![核心观察：乘积的不同质因数 = 各元素不同质因数的并集](images/wc326_q2_union_concept.svg)

由**算术基本定理（唯一分解定理）**，每个 $\text{nums}[i]$ 唯一分解为质数之积，乘积 $P$ 的分解就是把各元素的分解「拼接」：

$$\{\,p : p \mid P\,\} \;=\; \bigcup_{i}\;\{\,p : p \mid \text{nums}[i]\,\}$$

某个质数 $p$ 只要出现在**任一**元素的分解里，就整除 $P$；它在多少个元素里出现、各出现几次（重数）对「种类数」毫无影响。于是算法一句话：**逐元素试除分解，质因子丢进哈希集合，返回集合大小**——`set` 的去重语义恰好就是「不同」二字的语义，全程不碰大数乘法。

### 3.3 算法流程：试除法逐元素分解

![算法流程：试除法逐元素分解，质因子入集合](images/wc326_q2_trial_division_flow.svg)

对每个元素 $x$：

1. 令 $d$ 从 $2$ 起，只要 $d^2 \le x$（注意 $x$ 是**被除后不断缩小**的剩余值）：
   - 当 $x \bmod d = 0$：把 $d$ 加入集合，$x \leftarrow x / d$，**重复除到不能整除**（除尽 $d$ 的全部重数）；
   - $d \leftarrow d + 1$；
2. 循环结束后若剩余 $x > 1$，剩余值本身必是质数（最大质因子），加入集合；
3. 所有元素处理完，返回集合大小。

> 💡 **两个「为什么」**：(1) 为什么枚举到 $\sqrt{x}$ 就够？若 $x$ 还有 $> \sqrt{x}$ 的质因子，至多一个（两个这种因子相乘已超过 $x$），它被步骤 2 的「剩余 $>1$」兜底。(2) 为什么 $d$ 步进 $1$、不跳过合数也正确？轮到 $d$ 时，比 $d$ 小的因子已被除尽；若 $d$ 是合数，其质因子早已被除掉，$d$ 不可能整除剩余值——合数 $d$ 自动空转，正确性无损（$d \le 32$，浪费可忽略）。

### 3.4 示例演算

![示例演算：nums=[2,4,3,7,10,6]，集合逐步并大为 {2,3,5,7}](images/wc326_q2_walkthrough_10080.svg)

以例 1 `nums = [2,4,3,7,10,6]` 走查，观察集合如何「只增种类、不记重数」：

| 元素 | 分解 | 并入后集合 | 新增 |
|------|------|-----------|------|
| $2$ | $2$（质数） | $\{2\}$ | $+2$ |
| $4$ | $2 \times 2$ | $\{2\}$ | —（重数被丢弃） |
| $3$ | $3$（质数） | $\{2, 3\}$ | $+3$ |
| $7$ | $7$（质数） | $\{2, 3, 7\}$ | $+7$ |
| $10$ | $2 \times 5$ | $\{2, 3, 5, 7\}$ | $+5$ |
| $6$ | $2 \times 3$ | $\{2, 3, 5, 7\}$ | — |

最终集合 $\{2,3,5,7\}$，返回 $4$ ✓。校验：$P = 2^5 \cdot 3^2 \cdot 5 \cdot 7 = 10080$，不同质因数恰为 4 个。

- **例 2**（`[2,4,8,16]`）：四个元素全是 $2$ 的幂，分解出的质因子全是 $2$，集合恒为 $\{2\}$，返回 $1$ ✓。
- **单个大质数**（如 `nums = [997]`）：$d$ 从 $2$ 试到 $31$（$31^2 = 961 \le 997 < 32^2$）无一整除，剩余 $997 > 1$ 兜底入集合，返回 $1$ ✓——这一步覆盖「残余兜底」分支。

## 4. 算法细节

1. **试除上界动态收紧**：条件 $d^2 \le x$ 用的是**被除后的剩余值**而非原始值。每除尽一个因子 $x$ 就缩小，上界同步收紧，是天然的剪枝；$x \le 1000$ 时 $d$ 至多试到 $31$。
2. **内层必须 `while` 除尽**：把内层 `while` 误写成 `if`（只除一次）是高频翻车点——见 §8 第 2 条的反例 $x = 8$。除尽重数不是「为了种类数」的仪式，而是保证「剩余值无小因子」这一不变式的关键。
3. **残余兜底行不可省**：`if (x > 1) 加入 x`。每个元素至多贡献一个 $> \sqrt{x}$ 的质因子，全靠这行收账；漏写则 $997$ 这类质数元素的因子丢失。
4. **值域去重再分解（小优化）**：值域只有 $[2, 1000]$（999 种取值），先 `seen = set(nums)` 把 $n = 10^4$ 压到 $\le 999$ 个**不同值**，再对每个不同值分解一次。复杂度从 $O(n\sqrt{M})$ 降为 $O(n + \min(n, 999)\sqrt{M})$，本题不卡常则可不做。
5. **集合容量的上界**：入集合的质数都 $\le 1000$，而 $\pi(1000) = 168$（1000 内恰 168 个质数），答案 $\le 168$——这也是验证代码时的先验上界。

## 5. 正确性证明

**引理 1（并集引理）**：设 $a_1, \dots, a_n$ 均为大于 $1$ 的正整数，$P = \prod_i a_i$，则整除 $P$ 的质数集合等于各 $a_i$ 质因子集合的并集。

**证明**：若质数 $p$ 整除某个 $a_i$，则由 $a_i \mid P$ 得 $p \mid P$，故并集 $\subseteq$ 质因子集合($P$)。反之设 $p \mid P$：若 $p$ 不整除任何 $a_i$，则每个 $a_i$ 与 $p$ 互素，由**欧几里得引理**（$p$ 质数且 $p \mid ab \Rightarrow p \mid a$ 或 $p \mid b$）的逆否形式对 $n$ 个因子归纳，$p \nmid P$，矛盾。故两个集合相等。∎

**引理 2（试除不变式）**：对某个元素做试除时，记当前外层判定值为 $d$（$d \ge 2$）、剩余值为 $x'$，则不变式成立：$x'$ 不含 $[2, d-1]$ 中任何因数。从而若 $x' \bmod d = 0$，则 $d$ 必为质数。

**证明**：归纳。初始 $d = 2$，区间 $[2, 1]$ 为空，成立。设某轮开始时成立：若 $x' \bmod d \ne 0$，则 $d \leftarrow d+1$ 后 $x'$ 不变、新增进区间的恰是刚验证不整除的 $d$，不变式保持；若 $x' \bmod d = 0$，内层除尽后新剩余值是旧 $x'$ 的因数，仍不含 $[2, d-1]$ 的因数（除法只会去掉因子、不会引入），且此时 $x' \bmod d \ne 0$，$d \leftarrow d+1$ 后不变式保持。对于「$d$ 必质」：若 $d$ 为合数，取其质因子 $q < d$，则 $q \in [2, d-1]$，由不变式 $q \nmid x'$；但 $q \mid d$、$d \mid x'$ 推出 $q \mid x'$，矛盾。∎

**引理 3（残余是质数）**：外层循环因 $d^2 > x'$ 终止时，若 $x' > 1$ 则 $x'$ 是质数。

**证明**：反设 $x' > 1$ 是合数，取其最小质因子 $q$，则 $q \le \sqrt{x'}$（合数的最小质因子不超过其平方根）。由 $d^2 > x'$ 得 $q \le \sqrt{x'} < d$，故 $q \in [2, d-1]$；但 $q \mid x'$ 与引理 2 的不变式矛盾。∎

**定理**：算法返回值等于乘积 $P$ 的不同质因数个数。

**证明**：先看单元素 $x$。（**乘积不变式**）整个过程中「已收集因子之积 × 当前剩余值 = 原 $x$」始终成立，每步除法两端同除一个 $d$ 即可保持。由引理 2 及其推论、引理 3，算法对 $x$ 加入集合的每个数都是质数且整除 $x$——无假阳性；结束时剩余值或为 $1$（质因子已全部以 $d$ 的形式收集）或为质数（由引理 3 兜底入集合），再由乘积不变式与算术基本定理，$x$ 的每个质因子必在集合中——无假阴性。故单元素贡献恰为其质因子集合。哈希集合逐步并入不改变这一点，最终集合 $= \bigcup_i \{\,\text{质因子}(\text{nums}[i])\,\}$；由引理 1，这正是 $P$ 的质因子集合，其大小即所求。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \cdot \sqrt{M})$，$M = \max \text{nums}[i] \le 1000$。每个元素外层至多试除到 $\sqrt{M} \le 32$（$d \in [2, 31]$），内层除法总次数受 $O(\log_2 M) \approx 10$ 封顶（每除一次剩余值至少折半）；总计 $\le 10^4 \times 32 \approx 3.2 \times 10^5$ 次整数运算，远低于周赛时限。若做值域去重（§4 第 4 条），降为 $O(n + 999 \sqrt{M})$。
- **空间复杂度**：$O(\pi(M))$。集合至多容纳 $1000$ 内全部 $168$ 个质数，加上 $O(1)$ 个临时变量，可视为 $O(1)$ 级别。
- **对照（暴力）**：先乘积再分解需处理 $10^{30000}$ 位大数，构造乘积 $O(n \cdot \text{位数})$、分解更是不可行——复杂度差出「指数级位数」的鸿沟，这是本题「观察优于实现」的典型体现。

## 7. 参考代码

### C++（试除 + 哈希集合）

```cpp
class Solution {
public:
    int distinctPrimeFactors(vector<int>& nums) {
        unordered_set<int> primes;
        for (int x : nums) {
            for (int d = 2; (long long)d * d <= x; ++d) {  // 上界随剩余值收紧
                while (x % d == 0) {                        // 除尽 d 的重数
                    primes.insert(d);                       // d 必为质因子
                    x /= d;
                }
            }
            if (x > 1) primes.insert(x);                     // 残余 = 最大质因子
        }
        return primes.size();
    }
};
```

> 💡 `(long long)d * d` 是防 32 位溢出的稳妥写法（本题 $x \le 1000$ 实际不触发，值域放大后必用）。注意 $x$ 是循环内被不断缩小的**副本**，`nums` 本身只读。

### Python（试除 + 哈希集合）

```python
class Solution:
    def distinctPrimeFactors(self, nums: List[int]) -> int:
        primes = set()
        for x in nums:
            d = 2
            while d * d <= x:            # 上界随剩余值收紧
                while x % d == 0:        # 除尽 d 的重数
                    primes.add(d)
                    x //= d
                d += 1
            if x > 1:                    # 残余 = 最大质因子
                primes.add(x)
        return len(primes)
```

### 对照：值域去重版（压掉重复分解）

```python
class Solution:
    def distinctPrimeFactors(self, nums: List[int]) -> int:
        primes = set()
        for x in set(nums):              # 值域 [2,1000]，不同值至多 999 个
            d = 2
            while d * d <= x:
                while x % d == 0:
                    primes.add(d)
                    x //= d
                d += 1
            if x > 1:
                primes.add(x)
        return len(primes)
```

> 💡 只改一行 `for x in set(nums)`：$n = 10^4$ 个元素最多 $999$ 种取值，重复值只分解一次。答案只依赖「哪些值出现过」，与出现次数无关——这与引理 1 中「重数不影响种类」一脉相承。

## 8. 边界情况与易错点

1. **真的去算乘积**：$10^4$ 个 $\le 1000$ 的数累乘，第 20 多步即超出 `long long`；正确姿势是分解**小元素**、合并**质因子集合**，乘积从头到尾不需要存在。
2. **内层 `while` 写成 `if`**：只除一次会破坏「剩余值无小因子」的不变式。反例 $x = 8$：`if` 版 $d=2$ 时加入 $2$、$x \leftarrow 4$，随后 $d^2 = 9 > 4$ 循环停，残余 $4$ 被当质数入集合，得 $\{2, 4\}$ 错算 $2$（正确答案 $1$）。
3. **漏掉残余兜底**：忘记 `if (x > 1)` 这行，`[997]` 输出 $0$ 而非 $1$。质数元素（含单个大质数、以及 $2p$ 型元素的大质数半边）全靠它兜底。
4. **上界写成原始值的 $\sqrt{\,}$**：用原始 `num` 固定上界虽仍正确（更大上界包含更小），但放弃了「剩余值缩小 → 上界收紧」的剪枝；更糟的是写反成 `d <= 1000` 之类会退化成全量枚举。条件恒写 `d * d <= x`（$x$ 为当前剩余值）。
5. **`d * d` 溢出习惯**：本题 $d \le 1000$、`int` 无恙；但把此题模板搬到 $x \le 10^{18}$ 的题时，`d * d` 在 `d > 46340` 处溢出 32 位 `int`，须写 `(long long)d * d` 或 `d <= x / d`。
6. **约束免特判**：$\text{nums}[i] \ge 2$ 保证无 $1$（无质因子）、无 $0$（除零），代码无需守卫；若放宽到允许 $1$，`while (d * d <= 1)` 与 `if (x > 1)` 自然跳过，模板依然正确。
7. **跨元素重复质因子**：$4$ 与 $6$ 共享质因子 $2$，$set$ 去重即「不同」语义；若误用 `vector` + 排重忘记 `unique`，或对每个元素独立计数后**求和**，会把例 2 错算成 $4$。
