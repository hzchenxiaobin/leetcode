# LeetCode 统计能整除数字的位数 题解

## 1. 题目概述

- **标题 / 题号**：统计能整除数字的位数（#2520，easy）
- **链接**：https://leetcode.cn/problems/count-the-digits-that-divide-a-number/
- **来源**：LeetCode 第 326 场周赛 Q1
- **难度**：简单
- **标签**：数学、数位操作、枚举

**题意**：给定整数 $\text{num}$，统计其十进制表示中**能整除 $\text{num}$ 本身**的数位个数。判定式为 $\text{num} \bmod d = 0$（$d$ 是某一数位，作除数）；同值数位**各自计入**（如 $121$ 的两个 $1$ 都算）。

**约束**：

- $1 \le \text{num} \le 10^9$
- $\text{num}$ 的数位中不含 $0$

> 💡 **签到题最短路径**：读题抓两个信号——①整除的对象是**整个 $\text{num}$**（判定式 $\text{num} \bmod d = 0$，别写反成 $d \bmod \text{num}$）；②约束明示**无 $0$ 数位**（$d \in \{1,\dots,9\}$，免除零守卫）。实现就是三行骨架：`t = num; while t: cnt += (num % (t % 10) == 0); t //= 10`，两分钟内可交。

## 2. 示例

**示例 1**

```text
输入：num = 7
输出：1
解释：7 被自己整除，因此答案是 1。
```

**示例 2**

```text
输入：num = 121
输出：2
解释：121 可以被 1 整除，但无法被 2 整除。由于 1 出现两次，所以返回 2。
```

**示例 3**

```text
输入：num = 1248
输出：4
解释：1248 可以被它每一位上的数字整除，因此答案是 4。
```

## 3. 解题思路

### 3.1 保底思路：转字符串逐字符判定

```python
return sum(num % int(c) == 0 for c in str(num))
```

把 $\text{num}$ 转成字符串后逐字符取数位、判定、求和，时间 $O(D)$（$D$ 为位数），空间 $O(D)$，在签到语境下稳过。它的「浪费」只在**取数位的方式**：引入了字符串构造与类型转换，而拆位本可用纯整数运算 `%10` / `//10` 完成，省掉 $O(D)$ 额外空间。两种实现的判定逻辑完全一致，差别只在「如何拿到每一位」。

### 3.2 核心观察：拆位用副本 t，试除用原值 num

![核心观察：拆位副本 t 前进，判定原值 num 全程只读](images/wc326_q1_split_test_concept.svg)

**关键直觉**：判定式 $\text{num} \bmod d = 0$ 中，$\text{num}$ 是**被除数**且必须始终是**完整原值**；而拆位需要一个不断 $\div 10$「向前走」的量。二者必须分离：

- **$t$（拆位副本）**：初值 $= \text{num}$，每轮取 $d = t \bmod 10$ 后 $t \leftarrow \lfloor t/10 \rfloor$，负责从个位到最高位**逐位前进**；
- **$\text{num}$（判定原值）**：全程**只读**，专司被除数。

若贪图省事直接 `num /= 10` 推进，后续位的判定就变成「被截断的部分值 $\bmod d$」，语义全错——这是本题唯一的实现陷阱。另外两点观察：

- **判定按位独立 ⇒ 同值数位不去重**：$121$ 的两个 $1$ 各自问一遍 $121 \bmod 1 = 0$，各命中一次，计 $2$；
- **无可优化的代数结构**：答案取决于 $\text{num}$ 与每个数位的整除关系，任何解法都至少要读全所有数位，一趟扫描即达此界。

### 3.3 算法流程

![算法流程：一趟 while 循环，取位、判定、推进](images/wc326_q1_digit_scan_flow.svg)

1. 初始化 $t = \text{num}$、$\text{cnt} = 0$；
2. 当 $t > 0$：取 $d = t \bmod 10$；若 $\text{num} \bmod d = 0$ 则 $\text{cnt} \leftarrow \text{cnt} + 1$；随后 $t \leftarrow \lfloor t/10 \rfloor$；
3. 循环结束返回 $\text{cnt}$。

> 💡 循环次数 $=$ 位数 $D$。$\text{num} \le 10^9$ 至多 10 位，且「无 $0$ 数位」把实际上界压到 $999999999$（9 位），故 $D \le 9$，至多 9 次取余。

### 3.4 示例演算

![示例演算：num=121 逐轮拆位判定，两个 1 各计一次](images/wc326_q1_walkthrough_121.svg)

以 $\text{num} = 121$（例 2，同时覆盖 ✗ 与重复数位两种情况）走查：

| 轮次 | $t$（轮初） | $d = t \bmod 10$ | $121 \bmod d$ | 命中 | $\text{cnt}$ |
|------|------------|------------------|---------------|------|--------------|
| 1 | $121$ | $1$（个位） | $0$ | ✓ | $1$ |
| 2 | $12$ | $2$（十位） | $1$ | ✗ | $1$ |
| 3 | $1$ | $1$（百位） | $0$ | ✓ | $2$ |
| — | $0$ | — | — | 循环结束 | 返回 $2$ |

- **例 1**（$\text{num} = 7$）：唯一数位 $7$，$7 \bmod 7 = 0$ ✓，返回 $1$；
- **例 3**（$\text{num} = 1248$）：$1248 = 2^5 \times 3 \times 13$，含因子 $2^5$，故被 $2,4,8$ 整除，又被 $1$ 整除，四位全中，返回 $4$。

## 4. 算法细节

1. **副本与原值职责分离**：`t` 只做 `%10` 取位与 `//10` 推进；`num` 只出现在被除数位置，循环内不写任何对 `num` 的赋值。
2. **取位顺序无关正确性**：从个位到最高位取出，命中判定与顺序无关，结果只依赖「每位恰判定一次」（§5 引理 2）。
3. **同值数位独立计数**：判定按「位」而非「值」进行，重复值不去重；若误对数位去重（如转 `set`），$121$ 会错算成 $1$。
4. **免除零守卫的条件**：约束保证 $d \in \{1,\dots,9\}$，`num % d` 无除零风险。若题面放宽允许 $0$ 数位，需在取余前加 `d != 0` 守卫（$0$ 不能整除任何数，天然不计入）。
5. **终止性**：每轮 $t \leftarrow \lfloor t/10 \rfloor$ 使 $t$ 非负且严格变小，至多 $D$ 轮后 $t = 0$，循环必然终止。

## 5. 正确性证明

**引理 1（拆位不变式）**：第 $k$ 轮循环开始时（$k = 1, 2, \dots$），$t = \lfloor \text{num} / 10^{k-1} \rfloor$。

**证明**：对 $k$ 归纳。$k = 1$ 时 $t = \text{num}$，成立。设第 $k$ 轮开始时命题成立，则该轮结束时 $t' = \lfloor t/10 \rfloor = \lfloor \lfloor \text{num}/10^{k-1} \rfloor / 10 \rfloor = \lfloor \text{num}/10^{k} \rfloor$（对正整数 $a,b$ 有嵌套下取整合并律 $\lfloor \lfloor x/a \rfloor / b \rfloor = \lfloor x/(ab) \rfloor$），即第 $k+1$ 轮开始时命题成立。∎

**引理 2（每数位恰访问一次）**：循环体第 $k$ 次执行时取出的 $d = t \bmod 10$ 恰为 $\text{num}$ 十进制表示自低到高的第 $k$ 个数位；循环共执行 $D$ 次（$D$ 为 $\text{num}$ 的位数）。

**证明**：由引理 1，$d = \lfloor \text{num}/10^{k-1} \rfloor \bmod 10$，此即十进制第 $k$ 低位数的标准取位公式。循环继续当且仅当 $t > 0$，即 $\lfloor \text{num}/10^{k-1} \rfloor > 0$，当且仅当 $\text{num} \ge 10^{k-1}$，当且仅当 $k \le D$（$D$ 位数满足 $10^{D-1} \le \text{num} < 10^{D}$）。故每个 $k \in [1, D]$ 恰执行一次。∎

**定理**：算法返回 $\text{cnt} = \left| \{\, k \in [1, D] : \text{num} \bmod d_k = 0 \,\} \right|$（$d_k$ 为第 $k$ 个数位），即能整除 $\text{num}$ 的数位个数（按出现次数计）。

**证明**：循环中 `num` 从未被赋值，每次判定 $\text{num} \bmod d_k = 0$ 用的都是原始值。由引理 2，每个数位恰被判定一次，命中一次则 $\text{cnt}$ 增一，故 $\text{cnt}$ 与目标集合按位一一对应。同值数位对应不同的 $k$、各自计入，与题意「重复计入」一致。∎

## 6. 复杂度分析

- **时间复杂度**：$O(D) = O(\log_{10} \text{num})$。每轮一次取位（$\bmod 10$）、至多一次取余（$\text{num} \bmod d$）、一次整除推进（$\lfloor t/10 \rfloor$）；$D \le 9$，常数极小。
- **空间复杂度**：$O(1)$。仅 $t, d, \text{cnt}$ 三个整型变量；对照字符串版需 $O(D)$ 存放字符串。

## 7. 参考代码

### C++（取余拆位，$O(1)$ 空间）

```cpp
class Solution {
public:
    int countDigits(int num) {
        int cnt = 0;
        for (int t = num; t > 0; t /= 10) {
            int d = t % 10;
            if (num % d == 0) ++cnt;
        }
        return cnt;
    }
};
```

> 💡 `for (int t = num; t > 0; t /= 10)` 把「初始化副本 / 循环条件 / 推进」压进一行；`num` 原值不动专司取余。约束保证无 $0$ 位故免守卫；若需兼容含 $0$ 位，改成 `if (d != 0 && num % d == 0)`。

### Python（取余拆位，$O(1)$ 空间）

```python
class Solution:
    def countDigits(self, num: int) -> int:
        cnt = 0
        t = num
        while t > 0:
            d = t % 10
            if num % d == 0:
                cnt += 1
            t //= 10
        return cnt
```

> 💡 `num % 1` 恒为 $0$，含 $1$ 的位天然计入，无需特判。

### 对照：字符串版（签到保底）

```python
class Solution:
    def countDigits(self, num: int) -> int:
        return sum(num % int(c) == 0 for c in str(num))
```

## 8. 边界情况与易错点

1. **判定式方向写反**：是 $\text{num} \bmod d = 0$（数位整除原数），不是 $d \bmod \text{num} = 0$。后者仅当 $\text{num} \le d \le 9$ 时才可能成立，语义完全不同。
2. **副本与原值混用**：直接 `num /= 10` 推进会让后续判定用「截断值」取余，结果失真。必须设独立副本 $t$。
3. **误去重**：对数位集合去重（如 `set(str(num))`）后再判定，$121$ 会错得 $1$ 而非 $2$——判定按位独立、重复计入。
4. **除零**：本题约束内无 $0$ 位；若变体允许 $0$ 位，`num % 0` 是未定义行为 / 运行时错误，需 `d != 0` 守卫，且 $0$ 不整除任何数、不计入。
5. **上界与位数**：$10^9$ 本身含 $0$ 数位，被约束排除；实际最大输入 $999999999$ 共 9 位，$D \le 9$。$\text{num} \le 10^9 < 2^{31} - 1$，C++ `int` 足够，无溢出点。
6. **单数位输入**：$\text{num} \in [1, 9]$ 时自己整除自己，答案恒为 $1$，算法无需特判自动覆盖。
