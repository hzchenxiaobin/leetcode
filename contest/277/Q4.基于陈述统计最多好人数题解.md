# LeetCode 基于陈述统计最多好人数 题解

## 1. 题目概述

- **标题 / 题号**：基于陈述统计最多好人数（#2151，hard）
- **链接**：https://leetcode.cn/problems/maximum-good-people-based-on-statements/
- **来源**：LeetCode 第 277 场周赛 Q4
- **难度**：困难
- **标签**：位运算、枚举、回溯、数组

**题意**：$n$ 个玩家分两种角色：**好人**句句真话，**坏人**可能说真话也可能说假话。给 $n \times n$ 矩阵 `statements`：`statements[i][j] = 1` 表示 $i$ 称 $j$ 是好人，`0` 表示 $i$ 称 $j$ 是坏人，`2` 表示 $i$ 未评价 $j$（对角线恒为 2）。求一种角色指派，使**所有好人的陈述都为真**，返回该指派下好人数目的**最大值**。

**约束**：

- $2 \le n \le 15$
- `statements[i][j]` 的值为 `0`、`1` 或 `2`，且 `statements[i][i] == 2`

> 💡 本题在本仓库另有[每日题解 2151](../../solution/2101-2200/2151_基于陈述的最大善良人数.md)：主线同为「位掩码枚举 + 好人陈述校验」，含回溯剪枝扩展与面试问答。本篇按**周赛复盘视角**展开：给出「坏人陈述是噪声」的引理-定理化证明、`good` / `bad` 掩码把单次判定从 $O(n^2)$ 压到 $O(n)$ 的位运算形态、可行性**无单调性**（不能贪心扩展）的论证、「答案可以为 0」的三人互卡构造、「坏人必说谎」错误模型直接无解的四人反例，两篇互为印证。同场 Q1（#2148）、Q2（#2149）、Q3（#2150）全是「条件直译 / 模拟」型，本题是全场唯一需要「搜索空间建模 + 严谨证明」的压轴。

## 2. 示例

**示例 1**

```text
输入：statements = [[2,1,2],[1,2,2],[2,0,2]]
输出：2
解释：0 说 1 好；1 说 0 好；2 说 1 坏。
      最优：0、1 为好人（互证清白），2 为坏人在说谎 → 2 个好人。
      次优：{2} 单独为好人也自洽——0、1 都是坏人，0 那句「1 是好人」
      出自坏人之口，真假无所谓 → 只有 1 个好人。
```

**示例 2**

```text
输入：statements = [[2,0],[0,2]]
输出：1
解释：0 说 1 坏；1 说 0 坏，两人互指对方是坏人。
      {0} 可行：0 是好人说真话，1 确是坏人；1 的指认出自坏人，不构成约束。
      {0,1} 不可行：0 若是好人则 1 必是坏人，与 1∈S 矛盾。
```

**示例 3（答案为 0 的构造，自编）**

```text
输入：statements = [[2,1,2],[2,2,1],[1,0,2]]
输出：0
解释：0 说 1 好；1 说 2 好；2 说 0 好、且说 1 坏。
      任何非空 S 都会沿「点名链」被迫扩张：0∈S 拉进 1，1∈S 拉进 2，
      而 2∈S 又咬定 1 是坏人 → 所有非空集合全部矛盾，
      只剩「全体坏人」（空集）这一保底指派。
```

## 3. 解题思路

### 3.1 暴力思路：两个诱人的错误方向

题面最唬人的地方是「坏人**可能**说真话，**也可能**说假话」。顺着字面走会撞上两条歧路：

- **方向一（状态爆炸）**：先枚举每个人的角色（$2^n$ 种），再枚举坏人每句话的真假（最多 $n(n-1)$ 句话，$2^{\Theta(n^2)}$ 种组合），逐一核对总陈述数——$n = 15$ 时谎话模式已是 $10^{63}$ 量级，彻底不可行。
- **方向二（错误模型）**：把「坏人」误读成「必说谎的骗子」。这个模型会**错杀合法指派**：示例 2 的「全体坏人」指派下，两人互指对方是坏人、句句属实，却被错误模型直接否决（§8 给出一个更极端的四人反例：错误模型下**无解**，正解是 2）。

两条歧路的共同根源：**把精力花在了坏人身上**。真正可行的暴力是：枚举好人集合 $S \subseteq \{0,\dots,n-1\}$（$2^n$ 个），对每个 $S$ 只核对 $S$ 内成员的陈述、直接扫矩阵 $O(n^2)$ 判定——$2^{15} \times 225 \approx 7.4 \times 10^6$，已经能过。接下来的观察把这个判定再压掉一个 $n$。

### 3.2 核心观察：合法性只由好人的陈述决定

![核心观察：好人陈述是硬约束，坏人陈述是噪声](images/2151_good_only_constraints.svg)

好人的定义是「句句真话」，所以**一旦假定好人集合 $S$，$S$ 内每个人的陈述都变成必须兑现的硬约束**（上图左 panel）：

- $i \in S$ 说 $j$ 好（值 `1`）⟹ $j$ 必须也在 $S$ 里；
- $i \in S$ 说 $j$ 坏（值 `0`）⟹ $j$ 必须不在 $S$ 里。

而 $i \notin S$ 是坏人，说真说假都合法——**坏人的陈述对合法性零贡献，是纯噪声**（上图右 panel）。定义两个掩码：$\text{good}(i)$ = $i$ 所有 `1` 语句指向的 $j$ 的位集合，$\text{bad}(i)$ = $i$ 所有 `0` 语句指向的 $j$ 的位集合，则可行性与「谁在说谎」彻底解耦（上图下方公式）：

$$S \text{ 可行} \iff \forall i \in S:\ \text{good}(i) \subseteq S \ \wedge\ \text{bad}(i) \cap S = \varnothing$$

> 💡 搜索空间就此塌缩：从「角色 × 谎话模式」的双重枚举，变成**只枚举好人集合 $S$**——共 $2^n$ 个候选（$n \le 15$，至多 32768 个），每个候选用位运算 $O(n)$ 验证。逻辑谜题变身枚举签到。

### 3.3 算法流程：子集枚举 + 位运算判定

![算法流程：预处理掩码、枚举 S、位运算验证、维护最大 popcount](images/2151_bitmask_flow.svg)

1. **预处理**（$O(n^2)$）：对每个 $i$ 构造 $\text{good}[i]$、$\text{bad}[i]$ 两个掩码。
2. **枚举**：$S$ 从 $0$ 到 $2^n - 1$，视第 $i$ 位为「$i$ 是好人」。
3. **验证**：对每个 $i \in S$（`(S >> i) & 1`）做两个位运算：`(good[i] & S) == good[i]`（点名的好人全在 $S$ 内，即子集）且 `(bad[i] & S) == 0`（点名的坏人全在 $S$ 外，即不相交）。任一失败立即弃 $S$。
4. **计分**：可行则用 `popcount(S)` 更新答案；全部枚举完返回最大值（空集恒可行，答案至少为 $0$）。

> ⚠️ **为什么必须全枚举、不能贪心扩展**（上图底部警示）：可行性**既不上闭也不下闭**——例 1 里 $\{2\}$ 可行而其超集 $\{0,2\}$ 不可行，$\{0,1\}$ 可行而其子集 $\{0\}$ 不可行。「当前可行的 $S$」对往哪扩张不提供任何保证，DFS 贪心 / 单向剪枝都会漏解；$n \le 15$ 本来就是出题人递的「放心全枚举」信号。

### 3.4 示例演算

![示例演算：例 1 的 8 个好人集合逐一判定](images/2151_mask_walkthrough.svg)

以示例 1（`statements = [[2,1,2],[1,2,2],[2,0,2]]`）全量走查（插图含 8 个 $S$ 的判定表，红字为击杀理由）：

| $S$（二进制） | 好人集合 | 击杀理由 / 备注 | 可行 | $\lvert S \rvert$ |
|------|------|------|:--:|:--:|
| 000 | $\varnothing$ | 空集：无好人，无真话需要兑现 | ✓ | 0 |
| 001 | {0} | 0 说 1 好，但 $1 \notin S$ | ✗ | 1 |
| 010 | {1} | 1 说 0 好，但 $0 \notin S$ | ✗ | 1 |
| 011 | {0,1} | 无违反：0、1 互证清白 | ✓ | **2** |
| 100 | {2} | 无违反：2 说 1 坏，$1 \notin S$ ✓ | ✓ | 1 |
| 101 | {0,2} | 0 说 1 好，但 $1 \notin S$ | ✗ | 2 |
| 110 | {1,2} | 1 说 0 好，但 $0 \notin S$ | ✗ | 2 |
| 111 | {0,1,2} | 2 说 1 坏，但 $1 \in S$ | ✗ | 3 |

最大 $\text{popcount} = 2$（$S = \{0,1\}$）→ 返回 2。注意 8 个集合里可行者有三个：$\varnothing$、$\{2\}$、$\{0,1\}$——分别对应「全员恶人」「只有 2 是好人」「2 在说谎」三种互不相同的世界观，它们**都**与陈述矩阵自洽，题目要的只是其中好人最多的那个。再快速过一遍示例 2（$n=2$）：`good = [00, 00]`、`bad = [10, 01]`；$S=01$（{0}）与 $S=10$（{1}）均可行（各自 1 人），$S=11$ 被 `bad[0] & S ≠ 0` 击杀 → 答案 1。

## 4. 算法细节

1. **掩码预处理**：把 $O(n^2)$ 的语句信息压缩成每人两个 $n$ 位掩码。`statements[i][j] == 1` 时 `good[i] |= 1 << j`，`== 0` 时 `bad[i] |= 1 << j`；值 `2` 与对角线（恒为 2）自动落不进任何掩码，**无需特判**。
2. **判定的位运算形态**：子集关系写成 `(good[i] & S) == good[i]`，比 `good[i] & ~S == 0` 更稳——C++ 的 `~S` 高位全 1（碰巧被 `good[i]` 的低位掩掉）、Python 的 `~S` 是负数（无限位补码，结果碰巧也对），子集式在两种语言里都直白无歧义。
3. **只查 $S$ 内成员**：循环里 `if ((S >> i) & 1)` 先筛掉坏人——坏人的 `good/bad` 掩码是噪声，多查只会错杀：例 1 的 $S=\{0,1\}$ 若顺手查了 2 的 `bad[2]` 就会被误判不可行（实际后果见 §8 第 5 条）。
4. **popcount**：C++ 用 `__builtin_popcount`；Python 3.10+ 用 `S.bit_count()`，旧版本用 `bin(S).count("1")`。
5. **短路**：`for (int i = 0; i < n && ok; i++)` 一旦违反立即跳出该 $S$ 的验证循环，违反越早弃得越快。
6. **可选剪枝**：按 popcount 从大到小的顺序枚举，首个可行即返回。$n = 15$ 时主循环约 $32768 \times 15 \approx 5 \times 10^5$ 次位运算，**不剪也绰绰有余**——赛场优先写对，不追求写快。
7. **对照直查版**：不预处理掩码、对每个 $S$ 直接双重循环扫 `statements` 的 $O(2^n \cdot n^2)$ 版本（$\approx 7.4 \times 10^6$）同样能过（见 §7）——位掩码是优雅加速，不是救命稻草。

## 5. 正确性证明

**引理 1（可行性刻画）**：对任意 $S \subseteq \{0,1,\dots,n-1\}$，$S$ 可以作为某个合法指派的好人集合，当且仅当

$$\forall i \in S,\ \forall j \ne i:\quad \text{statements}[i][j] = 1 \Rightarrow j \in S,\qquad \text{statements}[i][j] = 0 \Rightarrow j \notin S.$$

**证明**：（⇒）设存在合法指派且其好人集合恰为 $S$。任取 $i \in S$：$i$ 是好人，句句真话。若 $i$ 说 $j$ 好（值 1），此话为真，故 $j$ 是好人，$j \in S$；若 $i$ 说 $j$ 坏（值 0），此话为真，故 $j$ 是坏人，$j \notin S$。（⇐）设条件成立。构造指派：$S$ 内为好人、$S$ 外为坏人。核对唯一约束「好人句句真话」：对 $i \in S$，其值 1 的语句说 $j$ 好而 $j \in S$，为真；其值 0 的语句说 $j$ 坏而 $j \notin S$，为真；值 2 无内容。坏人 $i \notin S$ 的每句话在该指派下非真即假，两种情况都被「可能说真话也可能说假话」覆盖，天然合法。故该指派合法，其好人集合为 $S$。∎

> 💡 引理 1 的 (⇐) 方向正是「坏人陈述是噪声」的形式化：合法指派的**存在性**只取决于 $S$ 内部的陈述是否自洽，$S$ 外的陈述无论说什么都无法否决 $S$——这也是为什么不需要枚举谎话模式。

**引理 2（空集恒可行 / 答案下界）**：$S = \varnothing$ 满足引理 1 的条件，故「全体坏人」永远是合法指派，答案 $\ge 0$；且答案确实可以取到 $0$（§2 示例 3 的三人在点名链上互卡）。

**证明**：$S = \varnothing$ 时引理 1 的全称量词作用于空集，条件空虚成立（vacuous truth）；此时无好人，无任何「真话约束」需要兑现。∎

**引理 3（指派与好人集合一一对应）**：合法指派与其好人集合之间存在双射，且指派的好人数 $= |S| = \text{popcount}(S)$。

**证明**：指派是 $\{0,\dots,n-1\} \to \{\text{好},\text{坏}\}$ 的映射，由好人集合（取值为「好」的原像集）唯一确定，反之亦然，故为双射；好人数即原像集大小 $|S|$。∎

**定理**：枚举全部 $2^n$ 个 $S$、按引理 1 的条件（位运算实现）筛选、取可行者的最大 $|S|$，返回值即最多好人数。

**证明**：由引理 3，「最多好人数」$= \max\{|S| : S \text{ 为某合法指派的好人集合}\}$；由引理 1，$S$ 进入此候选集当且仅当引理条件成立，而位运算判定与之逐条等价：`(good[i] & S) == good[i]` ⟺ 「值 1 的语句都指向 $S$ 内」（掩码按位展开即得），`(bad[i] & S) == 0` ⟺ 「值 0 的语句都指向 $S$ 外」。算法遍历所有 $2^n$ 个 $S$，不重不漏，故最大值正确；由引理 2 该最大值有定义且 $\ge 0$。∎

**推论（无单调性）**：可行集族既非上闭也非下闭。例 1 中 $\{2\}$ 可行但其超集 $\{0,2\}$ 不可行；$\{0,1\}$ 可行但其子集 $\{0\}$ 不可行。

**证明**：$S=\{2\}$：2 说 1 坏且 $1 \notin S$，可行。$S=\{0,2\}$：0 说 1 好但 $1 \notin S$，违反引理 1。$S=\{0,1\}$：0、1 互指对方为好且均在 $S$，可行。$S=\{0\}$：0 说 1 好但 $1 \notin S$，违反引理 1。∎

> 💡 推论说明「从可行集出发贪心扩张 / 收缩」没有正确性依据，全枚举是本题的必要姿势；引理 1~3 合起来则把「枚举 + 位运算判定」的每个环节都钉死——这也是周赛压轴题复盘的价值：不仅知道能过，还知道为什么一定对。

## 6. 复杂度分析

- **时间复杂度**：$O(2^n \cdot n)$。预处理 $O(n^2)$；枚举 $2^n$ 个集合，每个至多 $n$ 次成员检查、每次常数个位运算。$n = 15$ 时约 $32768 \times 15 \approx 4.9 \times 10^5$，毫秒级。
- **空间复杂度**：$O(n)$，即 `good` / `bad` 两个掩码数组，另有 $O(1)$ 计数器。
- **对照**：直查版 $O(2^n \cdot n^2) \approx 7.4 \times 10^6$，同样轻松通过；字面模拟「枚举谎话模式」为 $2^{\Theta(n^2)}$（不可行）；「坏人必说谎」错误模型虽快但答案错误（甚至无解）。

## 7. 参考代码

### C++（位掩码 + 子集判定，主推）

```cpp
class Solution {
public:
    int maximumGood(vector<vector<int>>& statements) {
        int n = statements.size();
        vector<int> good(n, 0), bad(n, 0);              // 预处理：i 认作好/坏人的掩码
        for (int i = 0; i < n; i++)
            for (int j = 0; j < n; j++) {
                if (statements[i][j] == 1) good[i] |= 1 << j;
                else if (statements[i][j] == 0) bad[i] |= 1 << j;
            }

        int ans = 0;                                    // 空集恒可行，答案至少 0
        for (int S = 0; S < (1 << n); S++) {            // 枚举好人集合
            bool ok = true;
            for (int i = 0; i < n && ok; i++)
                if ((S >> i) & 1)                       // 只检查 S 内的好人
                    ok = ((good[i] & S) == good[i])     // 点名的好人全在内（子集）
                      && ((bad[i] & S) == 0);           // 点名的坏人全在外（不相交）
            if (ok) ans = max(ans, __builtin_popcount(S));
        }
        return ans;
    }
};
```

### Python（位掩码）

```python
class Solution:
    def maximumGood(self, statements: List[List[int]]) -> int:
        n = len(statements)
        good = [0] * n
        bad = [0] * n
        for i in range(n):
            for j in range(n):
                if statements[i][j] == 1:
                    good[i] |= 1 << j
                elif statements[i][j] == 0:
                    bad[i] |= 1 << j

        ans = 0
        for S in range(1 << n):
            if all((good[i] & S) == good[i] and (bad[i] & S) == 0
                   for i in range(n) if (S >> i) & 1):  # 只检查 S 内的好人
                ans = max(ans, bin(S).count("1"))       # 3.10+ 可用 S.bit_count()
        return ans
```

### Python（直查对照版，O(2ⁿ·n²)）

```python
class Solution:
    def maximumGood(self, statements: List[List[int]]) -> int:
        n = len(statements)
        ans = 0
        for S in range(1 << n):                          # 枚举好人集合
            ok = True
            for i in range(n):
                if not (S >> i) & 1:
                    continue                             # 坏人的陈述一律不查
                for j in range(n):
                    if statements[i][j] == 1 and not (S >> j) & 1:
                        ok = False                       # 好人点名 j 好，j 却不在 S
                    elif statements[i][j] == 0 and (S >> j) & 1:
                        ok = False                       # 好人点名 j 坏，j 却在 S
                if not ok:
                    break
            if ok:
                ans = max(ans, bin(S).count("1"))
        return ans
```

## 8. 边界情况与易错点

1. **头号坑：把坏人当骗子**。坏人是「可能说真话也可能说假话」，不是必说谎。示例 2 的「全体坏人」指派下两句话都是真话，错误模型直接否决；更极端的构造 `[[2,2,2,2],[2,2,2,2],[0,2,2,0],[0,2,2,2]]`（2、3 都说 0 坏，2 还说 3 坏）在错误模型下**无任何可行指派**，而正解是 2（$S=\{0,1\}$，2、3 为说真话的坏人）。一切判定必须只建立在 $S$ 内成员的陈述上（引理 1）。
2. **答案可以为 0**：不要想当然 `return max(ans, 1)`。§2 示例 3 的三方互卡输入输出 0——「全体坏人」只是保底可行解，但可能就是最优解。
3. **全 2 矩阵 → 答案 $n$**：无任何陈述时所有集合可行，最大即全体（常用 sanity check）。
4. **对角线无需特判**：`statements[i][i] == 2` 保证自身不进任何掩码，内层循环包含 `j == i` 也安全。
5. **漏写「只查 $S$ 内成员」的筛子**：把坏人的陈述也纳入判定后，例 1 的 8 个集合会全军覆没、输出 0，样例即挂——但若数据里坏人恰好句句说谎，则样例过了、大点 WA，极难肉眼定位。
6. **位运算形态**：子集判定用 `(good[i] & S) == good[i]`；`good[i] & ~S == 0` 在 C++（`~S` 高位为 1）与 Python（`~S` 为负）里结果碰巧都对，但可读性差、 review 时容易心虚，统一推荐子集式。
7. **`S >> i & 1` 的优先级**：实际按 `(S >> i) & 1` 结合，正确但建议加括号；写成 `S & (1 << i)` 更直白。
8. **popcount API 差异**：C++ `__builtin_popcount`（或 C++20 `std::popcount`）；Python 3.10 前没有 `bit_count`，用 `bin(S).count("1")`。
9. **别枚举谎话**：任何「枚举每句话真假」的思路都是 $2^{\Theta(n^2)}$ 起步，$n = 15$ 时天文数字；合法性判定根本不消费谎言信息（引理 1 的 (⇐) 方向）。
10. **溢出审计**：全程只有 $n \le 15$ 位的掩码与 popcount，`int` 富余，无溢出风险。

**延伸思考**：① **n 放大怎么办**：本题一般化后是「最大化满足指派」，属 Max-SAT（NP-hard）——$n \le 15$ 正是可全枚举的边界信号，更大规模需分支限界或 SAT 求解器思路。② **要求输出具体指派**：记录取得最大值的 $S$（及一个Witness 解释：$S$ 外全是坏人），回溯输出即可。③ **计数变体**：统计可行集合个数（把 `max` 换 `sum`），框架原样成立。④ **与 2-SAT 的边界**：约束可写成蕴含式 $i \in S \wedge \text{stmt}=1 \Rightarrow j \in S$，但「坏人不约束」使子句不完整，标准的 2-SAT 连通分量判法并不直接适用——这正好解释了为何正解是暴力枚举。⑤ **批量判定加速**：把 $n$ 个玩家的逐个检查压进 `uint64` 的按位与 / 或，可降到 $O(n/64)$ 级别位操作，对 $n = 15$ 属屠龙刀，对大规模变体才是刚需。
