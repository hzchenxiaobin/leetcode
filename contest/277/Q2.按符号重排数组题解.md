# LeetCode 按符号重排数组 题解

## 1. 题目概述

- **标题 / 题号**：按符号重排数组（#2149，medium）
- **链接**：https://leetcode.cn/problems/rearrange-array-elements-by-sign/
- **来源**：LeetCode 第 277 场周赛 Q2
- **难度**：中等
- **标签**：数组、双指针、模拟

**题意**：给定下标从 0 开始、长度为**偶数**的整数数组 `nums`，其中正整数与负整数**数目相等**。重排并返回新数组，满足三条：① 任意**连续**两个整数**符号相反**；② 符号相同的整数**保留**它们在 `nums` 中的**相对顺序**；③ 重排后**以正整数开头**。

**约束**：

- $2 \le \text{nums.length} \le 2 \times 10^5$，且为偶数
- $1 \le |\text{nums[i]}| \le 10^5$（**不存在 0**）
- `nums` 由相等数量的正整数和负整数组成

> 💡 本题在本仓库另有[每日题解 2149](../../solution/2101-2200/2149_按符号重排数组.md)：主线同为「奇偶落位 + 双游标一趟写入」。本篇按**周赛复盘视角**展开：先论证本题是「输出唯一」的**结论题**（引理-定理化证明），再对比逐位取数的 $O(n^2)$ 暴力、分组两趟与双游标一趟三种写法，最后以极端分布用例验证越界免疫，附赛场易错清单，两篇互为印证。同场 Q1（#2148 元素计数）是极值开区间签到题，Q4（#2151 基于陈述统计最多好人数）才是本场的主菜。

## 2. 示例

**示例 1**

```text
输入：nums = [3,1,-2,-5,2,-4]
输出：[3,-2,1,-5,2,-4]
解释：正整数保序流为 [3,1,2]，负整数保序流为 [-2,-5,-4]，
      交错后唯一可行方案是 [3,-2,1,-5,2,-4]。
      [3,1,2,-2,-5,-4] 违反「连续符号相反」，[-2,3,-5,1,-4,2] 违反「以正开头」，
      [1,-2,3,-5,2,-4] 违反「同号保序」。
```

**示例 2**

```text
输入：nums = [-1,1]
输出：[1,-1]
解释：即使负数在前，「以正整数开头」强制 1 打头——
      开头符号由规则决定，与输入首个元素无关。
```

**示例 3（极端分布）**

```text
输入：nums = [1,2,3,-1,-2,-3]
输出：[1,-1,2,-2,3,-3]
解释：正数连成整块在前：前 3 步 posIdx 一路跑满 0→2→4→6，negIdx 始终停在 1；
      后 3 步负数才依序填入 1,3,5。因正数恰有 n/2 = 3 个，游标全程不越界（§5 引理 2）。
```

## 3. 解题思路

### 3.1 暴力思路：逐位回原数组取数

按输出位置逐格填：填偶下标时，从上次取用位置向后线性扫描找**下一个正数**；填奇下标时同理找**下一个负数**。取数顺序天然保序，正确性显然；但每个落点都可能重扫长段——极端分布「正数全在前」下，填每个奇下标都要扫过整个正数块，总代价 $O(n^2)$，$n = 2 \times 10^5$ 时约 $4 \times 10^{10}$ 次比较，必然超时。

- **根因**：「下一个正数/负数在哪」被反复询问，却每次都从头线性回答。
- **修法**：两个游标各自**记住**自己的进度，使每次落位 $O(1)$——这正是双指针的通用动机。

> ⚠️ 赛场上更快的朴素替代是「先分组再交错」两趟写法（§3.3 对照版），已经 $O(n)$ 通过；真正值得沉淀的是下面这条把整题变成**结论题**的观察。

### 3.2 核心观察：三条要求锁定唯一输出，落点由下标奇偶性决定

![核心观察：正数流落偶下标、负数流落奇下标](images/sign_parity_slots_concept.svg)

把三条要求联立起来读：

1. **以正开头 + 相邻符号相反** ⟹ 对位置**归纳**：位置 $0$ 为正，则位置 $1$ 必负、位置 $2$ 必正……即**偶下标必正、奇下标必负**，整个输出的符号格局被唯一确定；
2. **同号保序** ⟹ 第 $k$ 个正数（按原数组出现顺序）必须落在第 $k$ 个正数落点——偶下标 $2(k-1)$；负数同理落 $2k-1$；
3. **正负等量**（各 $n/2$ 个）⟹ 偶落点 $0,2,\dots,n-2$ 与奇落点 $1,3,\dots,n-1$ **恰好同时填满**，无空位、无剩余。

三条合起来：**合法输出唯一存在**（§5 引理 1），本题没有任何「选择」，是彻头彻尾的模拟题。于是只需从左到右扫一遍 `nums`，维护两个步长为 2 的游标：

$$\text{posIdx 从 } 0 \text{ 起}，\quad \text{negIdx 从 } 1 \text{ 起}，\qquad
\begin{cases}
x > 0 \Rightarrow \text{ans}[\text{posIdx}] = x,\ \text{posIdx} \mathrel{+}= 2 \\
x < 0 \Rightarrow \text{ans}[\text{negIdx}] = x,\ \text{negIdx} \mathrel{+}= 2
\end{cases}$$

> 💡 **为什么天然保序？** 扫描顺序即原数组顺序，同号元素按扫描先后写入**单调递增**的偶（或奇）下标序列，相对次序自动保持。两个游标独立步进、互不干扰——这是「两条队列保序归并」的退化版：无需比较大小，符号即路由。

### 3.3 算法流程：双游标一趟写入

![算法流程：逢正落偶位、逢负落奇位](images/sign_two_cursor_flow.svg)

1. **初始化**：创建长度 $n$ 的结果数组 `ans`；`posIdx = 0`，`negIdx = 1`。
2. **扫描**：对每个 $x \in \text{nums}$（从左到右）：$x > 0$ 则写入 `ans[posIdx]` 并令 `posIdx += 2`；否则写入 `ans[negIdx]` 并令 `negIdx += 2`。
3. **返回 `ans`**：输出形如 `正,负,正,负,…`。

**对照：分组两趟版**。先收集 `pos = [所有正数]`、`neg = [所有负数]`（扫描顺序天然保序），再交错 `ans[2k] = pos[k]`、`ans[2k+1] = neg[k]`。同样 $O(n)$、可读性极佳；双游标版把「分组」与「交错」合并成一趟，少两个中间数组、访问更连续，是赛场主流写法。

### 3.4 示例演算

![示例演算：双游标逐步走查](images/sign_interleave_walkthrough.svg)

以示例 1（`nums = [3,1,-2,-5,2,-4]`）逐步走查（插图逐格快照，红框为当步写入格）：

| 步 | $x$ | 写入 | posIdx | negIdx | ans 状态 |
|----|-----|------|---------|---------|-----------|
| 1 | 3 | ans[0]=3 | 0→2 | 1 | `[3,_,_,_,_,_]` |
| 2 | 1 | ans[2]=1 | 2→4 | 1 | `[3,_,1,_,_,_]` |
| 3 | −2 | ans[1]=−2 | 4 | 1→3 | `[3,−2,1,_,_,_]` |
| 4 | −5 | ans[3]=−5 | 4 | 3→5 | `[3,−2,1,−5,_,_]` |
| 5 | 2 | ans[4]=2 | 4→6 | 5 | `[3,−2,1,−5,2,_]` |
| 6 | −4 | ans[5]=−4 | 6 | 5→7 | `[3,−2,1,−5,2,−4]` |

**收尾口径**：扫描结束后 `posIdx = 6 = n`、`negIdx = 7 = n+1`——两个游标各自停在「出界哨兵位」上，但**不再被访问**；真正的不变量是「所有写入都在界内」（§5 引理 2）。正数流写入顺序 idx `0→2→4` 对应值 `3,1,2`，与原数组正数出现顺序一致；负数流 `1→3→5` 对应 `−2,−5,−4`，同样保序。

**极端分布自检** `[1,2,3,-1,-2,-3]`（正数连成整块在前）：前 3 步只有 `posIdx` 在动（0→2→4→6），`negIdx` 原地等待；后 3 步负数才依序填 1,3,5。因正数**恰有** $n/2 = 3$ 个，`posIdx` 止步于 6，全程不越界。

## 4. 算法细节

1. **判正条件写 `x > 0`**：约束 $|\text{nums[i]}| \ge 1$ 保证无零，`if/else` 二分即可，不存在第三类元素。`x > 0` 比 `x >= 0` 语义更严（零不合法），虽在本题等价，但迁移时更安全。
2. **游标步长 2 的意义**：把「该元素去哪个符号的队列」与「队列内第几个位置」两步决策合成一次 $O(1)$ 落位。等价写法是维护计数器 `pc/nc`：`ans[2*pc] = x; pc++`——与双游标完全同构。
3. **结果数组预分配**：C++ `vector<int> ans(n)` 定长后按下标直写；Python `[0] * n`。不要 `push_back` 式追加（那需要自己维护交错下标，多此一举且易错）。
4. **无需越界检查**：正负等量是**题面保证**。第 $k$ 个正数写入 $2(k-1) \le n-2$、第 $k$ 个负数写入 $2k-1 \le n-1$，全程在界内（§5 引理 2），一个边界判断都不用写。
5. **不要原地修改 `nums`**：一边扫描读 `nums` 一边覆写，会把尚未读到的元素冲掉；题面明说「不需要原地进行修改」，独立 `ans` 最稳。
6. **分组交错 twin**：`for k in range(n//2)` 依次写 `ans[2k] = pos[k]`、`ans[2k+1] = neg[k]`——语义与双游标版逐位一致，§5 定理一并覆盖两者。
7. **能否 $O(1)$ 额外空间？** 不保序可以（922 式对撞交换）；**保序**的 in-place 需要 stable partition 的循环置换 / 块旋转技巧，实现复杂、常数大，赛场上 $O(n)$ 辅助数组就是公认最优解（详见延伸思考）。

## 5. 正确性证明

**引理 1（结构唯一性）**：满足题面三条要求的重排数组**存在且唯一**：其偶下标依次存放 `nums` 中的正数（按出现顺序），奇下标依次存放负数（按出现顺序）。

**证明**：先证任何合法输出必有此结构。设输出为 $a_0, a_1, \dots, a_{n-1}$。由条件③，$a_0$ 为正；由条件①（相邻符号相反）对 $i$ 归纳：$a_i$ 为正当且仅当 $i$ 为偶数——符号格局唯一。再由条件②（同号保序）：偶下标序列 $0 < 2 < \cdots < n-2$ 与奇下标序列 $1 < 3 < \cdots < n-1$ 各自严格升序，故第 $k$ 个正数必落在第 $k$ 个偶下标 $2(k-1)$，第 $k$ 个负数必落在 $2k-1$——每类内部的排布也唯一。反之，该结构确为合法输出：相邻下标奇偶异号即正负交替 ✓；同号元素按扫描顺序写入升下标序列，保序 ✓；$a_0$ 为正 ✓。存在性由构造保证，唯一性得证。∎

**引理 2（恰好填满 / 越界免疫）**：算法扫描过程中每次写入都在界内；扫描结束时 `ans` 的每个位置恰被写入一次。

**证明**：`nums` 恰含 $n/2$ 个正数与 $n/2$ 个负数（题面约束）。第 $k$ 次遇到正数时 `posIdx` 的值为 $2(k-1) \le n-2 < n$，写入合法；第 $k$ 次遇到负数时 `negIdx` 的值为 $2k-1 \le n-1 < n$，写入合法——所有写入在界内。正数写入的下标集合为 $\{0,2,\dots,n-2\}$（$n/2$ 个互异值），负数为 $\{1,3,\dots,n-1\}$（$n/2$ 个互异值），两集合并集恰为 $\{0,1,\dots,n-1\}$ 且不相交，故 $n$ 个位置每格恰写一次：无空位、无覆盖、无越界。∎

**定理**：双游标算法返回的数组等于题面要求的重排（即引理 1 中的唯一合法结构）。

**证明**：算法从左到右读 `nums`，遇到第 $k$ 个正数时写入偶下标 $2(k-1)$、第 $k$ 个负数写入奇下标 $2k-1$（游标初值 $0/1$ 与步长 2 保证），恰好复现引理 1 的唯一结构；由引理 2，该结构被完整填满、且过程中不越界。故输出即唯一合法重排。∎

> 💡 引理 1 是本题的「结论题」本质：三条要求把每个元素的位置**全部锁死**，不存在搜索空间，比赛时应把时间花在「快速确信唯一性」而非枚举方案。引理 2 则解释了为什么代码里**一个越界判断都不用写**——等量前提把「填满」与「不越界」一起包办。

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。单趟扫描，每个元素一次符号判断、一次写入，合计约 $2n$ 次操作；渐近最优（输出本身有 $n$ 个数，$\Omega(n)$ 不可回避）。
- **空间复杂度**：$O(n)$，即结果数组。按 LeetCode 惯例返回值不计入额外空间，则双游标版**额外空间 $O(1)$**——这是它优于分组两趟版之处（后者还需 `pos`、`neg` 两个中间数组）。
- **对照**：逐位取数暴力 $O(n^2)$（$4 \times 10^{10}$，超时）；分组两趟 $O(n)$ / 额外 $O(n)$；双游标一趟 $O(n)$ / 额外 $O(1)$。

## 7. 参考代码

### C++（双游标一趟，主推）

```cpp
class Solution {
public:
    vector<int> rearrangeArray(vector<int>& nums) {
        int n = nums.size();
        vector<int> ans(n);
        int posIdx = 0, negIdx = 1;
        for (int x : nums) {
            if (x > 0) {
                ans[posIdx] = x;
                posIdx += 2;
            } else {
                ans[negIdx] = x;
                negIdx += 2;
            }
        }
        return ans;
    }
};
```

### C++（分组交错对照版）

```cpp
class Solution {
public:
    vector<int> rearrangeArray(vector<int>& nums) {
        vector<int> pos, neg;
        for (int x : nums) (x > 0 ? pos : neg).push_back(x);
        vector<int> ans;
        ans.reserve(nums.size());
        for (int k = 0; k < (int)pos.size(); ++k) {
            ans.push_back(pos[k]);
            ans.push_back(neg[k]);
        }
        return ans;
    }
};
```

### Python（双游标）

```python
class Solution:
    def rearrangeArray(self, nums: List[int]) -> List[int]:
        n = len(nums)
        ans = [0] * n
        pos_idx, neg_idx = 0, 1
        for x in nums:
            if x > 0:
                ans[pos_idx] = x
                pos_idx += 2
            else:
                ans[neg_idx] = x
                neg_idx += 2
        return ans
```

### Python（zip 交错版）

```python
class Solution:
    def rearrangeArray(self, nums: List[int]) -> List[int]:
        pos = [x for x in nums if x > 0]
        neg = [x for x in nums if x < 0]
        return [v for p, q in zip(pos, neg) for v in (p, q)]
```

> 💡 `zip(pos, neg)` 依赖两流等长（题面保证）。正数先用尽时 `zip` 会**静默截断**——恰好对应「不等量则无合法解」的退化情形，属于输入违约，本题无需处理。

## 8. 边界情况与易错点

1. **开头必须是正**：输入 `[-1,1]` 输出 `[1,-1]`——开头符号由规则③决定，与输入首个元素无关；把「保留顺序」误读成「保持首元素」会 WA。
2. **不要原地修改 `nums`**：边扫边写会冲掉未读元素；题面明示无需原地。
3. **游标三处细节**：首正落 0、首负落 1、步长 2。`negIdx` 起始误写 0 或步长误写 1，都是「想当然交错」的手滑，且小样例未必暴露（如 `[1,-1]` 步长 1 时恰好不撞车）。
4. **判正写 `x > 0` 而非 `x >= 0`**：本题无零两者等价；若约束放宽出现 0，`>=` 会把 0 当正数塞进偶位，违反「符号相反」——严写语义更稳。
5. **正负数量不等（题面已排除）**：正多用尽偶位后 `posIdx` 越界（C++ 未定义行为 / RE）。若拿此模板改题，须先校验 `count(+) == count(-)`。
6. **极端分布**：正数连成整块在前（`[1,2,3,-1,-2,-3]`），`posIdx` 先跑满、`negIdx` 长时间闲置——自检越界免疫与「游标可以长时间不动」的直觉（引理 2）。
7. **`ans` 必须预分配定长**：`vector<int> ans(n)` / `[0]*n`；空 `vector` 直接 `ans[posIdx]` 是越界 RE。
8. **保序 ≠ 可任意重排同号**：示例 1 中合法解**唯一**（引理 1），`[1,-2,3,-5,2,-4]` 违反保序——调试时别指望「另一个输出也对」。
9. **溢出审计**：全程只搬运无算术，值域 $\pm 10^5$，无溢出风险。
