# LeetCode 尽量减少恶意软件的传播 题解

## 1. 题目概述

- **标题 / 题号**：尽量减少恶意软件的传播（#924，hard）
- **链接**：https://leetcode.cn/problems/minimize-malware-spread/
- **来源**：LeetCode 第 106 场周赛 Q4
- **难度**：困难
- **标签**：深度优先搜索、广度优先搜索、并查集、图、数组、哈希表

**题意**：给定 $n$ 个节点的无向图，用 $n \times n$ 邻接矩阵 `graph` 表示（`graph[i][j] = 1` 表示 $i$ 与 $j$ 直接相连，主对角线恒为 1、矩阵对称）。`initial` 中的节点最初被恶意软件感染，感染沿边无限扩散：只要一条边的一端被感染，另一端也会被感染，直到稳定。

记 $M(\text{initial})$ 为扩散结束后的感染节点总数。现在**从 `initial` 中移除恰好一个节点**（只取消它的「初始感染」身份，节点本身仍留在图中），使得 $M$ 最小。返回该节点；若有多个，返回**下标最小**者。

**约束**：

- $2 \le n \le 300$，$n = \text{graph.length} = \text{graph}[i].\text{length}$
- `graph[i][j]` 为 0 或 1，`graph[i][j] = graph[j][i]`，`graph[i][i] = 1`
- $1 \le \text{initial.length} \le n$，`initial` 内元素互不相同
- $0 \le \text{initial}[i] \le n - 1$

> ⚠️ 本题与紧随其后的 `#928`（第 107 场周赛 Q4，II 版）只差一句：I 版只是**取消初始感染**，节点与边都还在；II 版是把节点**连同所有边一起删除**。两者的最优策略完全不同，切勿混用。

## 2. 示例

**示例 1**

```text
输入：graph = [[1,1,0],[1,1,0],[0,0,1]], initial = [0,1]
输出：0
解释：0 与 1 连通成一块（大小 2），2 独立（大小 1）。
     移除 0：块 {0,1} 仍由 1 感染 → 感染数 2；
     移除 1：同理仍为 2。收益并列，取下标最小的 0。
```

**示例 2**

```text
输入：graph = [[1,0,0],[0,1,0],[0,0,1]], initial = [0,2]
输出：0
解释：三个孤立点，各自成块（块规模都是 1）。
     移除 0 后 initial = {2}，最终感染数 1；移除 2 后 initial = {0}，最终感染数 1。
     两种选择都把 M 从 2 降到 1（收益相同），取下标最小的 0。
```

**示例 3**

```text
输入：graph = [[1,1,1],[1,1,1],[1,1,1]], initial = [1,2]
输出：1
解释：全图是一个大小 3 的连通块，块内有 2 个感染源。
     移除 1 后块内仍剩 2 号感染源，最终 3 个节点全被感染；移除 2 同理。
     收益都是 0，取下标最小的 1。
```

## 3. 解题思路

### 3.1 暴力思路

按定义直接模拟：对 `initial` 中每个候选 $u$，从 `initial \ {u}` 出发做一次 BFS/DFS 求出最终感染数，取最小者。单次扩散 $O(n^2)$，共 $|initial| \le n$ 个候选，总复杂度 $O(n^3)$，$n = 300$ 时约 $2.7 \times 10^7$，**能过**。

但这条路没有抓住题目的结构：它把「图」当成了需要反复模拟的动力学过程，而实际上感染范围和「谁被移除」之间有一个非常干净的组合关系。看清这一点后，可以做到 $O(n^2)$，且代码短得多。

### 3.2 核心观察：感染只在连通块内部发生

![关键：感染只在连通块内部扩散](images/wc106_q4_component_concept.svg)

**第一层观察**：感染沿边扩散，因此**连通块之间互不影响**。把图分成若干连通块 $C_1, C_2, \dots$，则

- 若某块内**至少有一个**初始感染源，整块最终全部被感染；
- 若某块内**没有**初始感染源，整块永远安全。

于是 $M = \sum_{\text{含感染源的块}} |C|$，这个式子直接把「动力学」变成了「静态计数」。

**第二层观察**：移除 $u$ 之后，唯一可能变化的块就是 $u$ 所在的块 $C(u)$：

- 若 $C(u)$ 内原本只有 $u$ 一个感染源，移除后该块变成「零感染源」，整块获救，收益 $= |C(u)|$；
- 若 $C(u)$ 内原本有 $\ge 2$ 个感染源，移除 $u$ 后仍剩至少一个，该块照样全灭，**收益 $= 0$**。

所以每个候选的收益只有两种取值，问题退化为「找 $|C(u)|$ 最大的、且块内感染源唯一的节点 $u$」，并列取最小下标。这就是本题的全部内容。

### 3.3 算法流程

![收益与并列规则](images/wc106_q4_saving_case.svg)

```text
1. DFS/BFS 给每个节点染上连通块编号 color[u]，同时统计每个块的规模 compSize
2. 累加 compMal[cid] = 块 cid 内的初始感染源个数
3. 将 initial 升序排序
4. best = initial[0], bestSave = -1
5. for u in initial（升序）:
       cid = color[u]
       save = compSize[cid]  若 compMal[cid] == 1
              0              否则
       if save > bestSave:   # 严格大于 → 并列时保留更小下标
           bestSave = save; best = u
6. 返回 best
```

复杂度 $O(n^2)$：染色阶段遍历邻接矩阵一次（$O(n^2)$），之后每个候选 $O(1)$。

### 3.4 示例演算

![示例演算：示例 1 与示例 3](images/wc106_q4_walkthrough.svg)

**示例 1**：`graph = [[1,1,0],[1,1,0],[0,0,1]]`，`initial = [0,1]`。

| 连通块 | 规模 | 感染源个数 | 移除 0 的收益 | 移除 1 的收益 |
|--------|------|------------|---------------|---------------|
| {0,1} | 2 | 2 | 0 | 0 |
| {2} | 1 | 0 | —（不是候选） | — |

收益都为 0，`bestSave` 初始为 $-1$，遍历升序 `[0,1]`：先处理 0（`save = 0 > -1`，取 0），再处理 1（`save = 0`，不大于 0，不更新）→ 返回 **0**。

**示例 2**：三个孤立点，块规模都是 1、各自只有 1 个感染源，收益都是 1。升序遍历 `[0,2]`，先取 0，处理 2 时 `save = 1` 不严格大于 1 → 返回 **0**。

**示例 3**：单块规模 3、感染源 2 个，收益都是 0 → 返回 **1**（`initial` 最小下标）。

## 4. 算法细节

1. **染色用迭代 DFS**：`n = 300` 时递归深度最多 300，C++ 不会爆栈，但迭代写法更稳妥；Python 请务必用显式栈或 BFS，避免递归深度问题。
2. **`compMal` 只统计 `initial` 中的节点**：普通节点不增加感染源计数，别把「被感染的」和「初始感染的」搞混。
3. **排序 `initial` 的作用**：让升序遍历与「并列取最小下标」的规则一致，配合 `save > bestSave` 的**严格大于**即可自动实现 tie-break，无需额外比较。
4. **`best` 的初值**：取 `initial` 的最小值，`bestSave = -1` 保证第一个候选一定被采纳。不要初始化成 `bestSave = 0`，否则当所有收益都是 0 时 `best` 会停留在初值——虽然初值恰好也是最小下标，但逻辑上容易被人为修改而埋雷。
5. **对角线恒为 1**：DFS 时不会因 `graph[u][u] = 1` 而把自身再次入队，因为染色时已把 `color[u]` 置为当前块编号。
6. **只移除「初始感染身份」**：题面特别强调「被移除的节点之后仍可能被传染」，因此本解法**不删边、不删点**，只改计数——这正是与 #928 的分水岭。

## 5. 正确性证明

**引理 1（感染闭包 = 含源连通块）**：扩散结束后，被感染的节点集合恰为「所有包含至少一个 `initial` 节点的连通块的并集」。

**证明**：设 $u$ 与 $v$ 在同一连通块，则存在路径 $u = x_0, x_1, \dots, x_m = v$。若 $u$ 被感染，则 $x_1$ 与 $x_0$ 相邻且 $x_0$ 已感染，故 $x_1$ 被感染；归纳得整条路径上的点都被感染，特别地 $v$ 被感染。因此每个「含源连通块」整体被感染。反之，若某连通块内没有初始感染源，感染不可能跨越块边界传入（块内与外界无边），故永远安全。∎

**推论 1**：$M(\text{initial}) = \sum_{C:\,C \cap \text{initial} \ne \varnothing} |C|$。

**引理 2（单点移除的收益）**：设 $u \in \text{initial}$、$C = C(u)$ 为其所在连通块。移除 $u$ 后

$$M(\text{initial} \setminus \{u\}) - M(\text{initial}) = \begin{cases} -|C|, & \text{若 } C \cap \text{initial} = \{u\}\\ 0, & \text{否则}\end{cases}$$

**证明**：移除 $u$ 只改变 $C$ 的「源集合」，其他块的源集合不变，由推论 1 只需看 $C$。

- 若 $C$ 内原本只有 $u$ 一个源：移除后 $C$ 内零源，由引理 1，$C$ 不再被感染，$M$ 减少 $|C|$。这里 $u$ 自身也不会被感染——$C$ 内没有别的源，$C$ 外与 $C$ 无边，没有能传染它的来源，所以减少量确实是整块 $|C|$。
- 若 $C$ 内还有别的源 $w \ne u$：移除后 $w$ 仍在，由引理 1，$C$ 整体仍被感染，$M$ 不变。∎

**引理 3（比较规则的正确性）**：设候选 $u$ 的收益为 $\text{save}(u)$（引理 2 中的减少量）。则「$\text{save}$ 最大者，并列取下标最小」恰好是题目要求的节点。

**证明**：$M(\text{initial} \setminus \{u\}) = M(\text{initial}) - \text{save}(u)$，其中 $M(\text{initial})$ 是与 $u$ 无关的常数。故 **最小化 $M$ 等价于最大化 $\text{save}$**。并列时题目要求返回下标最小者，而算法按升序遍历、仅在 `save` **严格大于**当前最优时才更新，故并列时先遇到的（即下标更小的）被保留。∎

**定理**：算法返回的节点是使 $M(\text{initial} \setminus \{u\})$ 最小、并列取最小下标的那个节点。

**证明**：由引理 1 与推论 1，染色阶段得到的 `compSize`、`compMal` 精确刻画了每个块的规模与源数；由引理 2，第 5 步算出的 `save` 恰为该候选的收益；所有候选都被遍历一次，取到收益最大值并由引理 3 完成 tie-break。故返回值满足题意。∎

## 6. 复杂度分析

- **时间**：$O(n^2)$。染色阶段每个节点出栈一次，每次扫描 $n$ 个邻接项，合计 $O(n^2)$；统计与选优各 $O(|initial|) \le O(n)$，排序 $O(n \log n)$。总计 $O(n^2)$，$n = 300$ 时约 $9 \times 10^4$ 次基本操作。
- **空间**：$O(n)$，`color`、`compSize`、`compMal`、显式栈各占 $O(n)$；邻接矩阵是输入本身，不计入额外空间。
- **对比暴力**：逐候选 BFS 为 $O(n^3)$，本解法把「模拟」换成「按块计数」，降了一个数量级，且常数极小。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minMalwareSpread(vector<vector<int>>& graph, vector<int>& initial) {
        int n = (int)graph.size();
        // 1) 连通块划分
        vector<int> color(n, -1);
        vector<int> compSize;
        for (int s = 0; s < n; ++s) {
            if (color[s] != -1) continue;
            int cid = (int)compSize.size();
            compSize.push_back(0);
            vector<int> st{s};
            color[s] = cid;
            while (!st.empty()) {
                int u = st.back();
                st.pop_back();
                compSize[cid]++;
                for (int v = 0; v < n; ++v) {
                    if (graph[u][v] == 1 && color[v] == -1) {
                        color[v] = cid;
                        st.push_back(v);
                    }
                }
            }
        }
        // 2) 每个连通块里的初始感染节点数
        vector<int> compMal(compSize.size(), 0);
        for (int u : initial) compMal[color[u]]++;

        // 3) 只有「块内感染源恰好为 1」的节点被移除才真正减少感染数
        sort(initial.begin(), initial.end());
        int best = initial[0], bestSave = -1;
        for (int u : initial) {
            int cid = color[u];
            int save = (compMal[cid] == 1) ? compSize[cid] : 0;
            if (save > bestSave) {   // 严格大于 → 相同收益下保留更小的下标
                bestSave = save;
                best = u;
            }
        }
        return best;
    }
};
```

### Python

```python
from collections import deque


class Solution:
    def minMalwareSpread(self, graph: list[list[int]], initial: list[int]) -> int:
        n = len(graph)
        color = [-1] * n
        comp_size = []
        for s in range(n):
            if color[s] != -1:
                continue
            cid = len(comp_size)
            comp_size.append(0)
            color[s] = cid
            q = deque([s])
            while q:
                u = q.popleft()
                comp_size[cid] += 1
                for v in range(n):
                    if graph[u][v] == 1 and color[v] == -1:
                        color[v] = cid
                        q.append(v)

        comp_mal = [0] * len(comp_size)
        for u in initial:
            comp_mal[color[u]] += 1

        best, best_save = min(initial), -1
        for u in sorted(initial):
            cid = color[u]
            save = comp_size[cid] if comp_mal[cid] == 1 else 0
            if save > best_save:
                best_save, best = save, u
        return best
```

## 8. 边界情况与易错点

1. **「移除」的含义**：I 版**不删点、不删边**，只是不再把它当初始感染源。写成「删除节点」会得到 II 版的答案（如示例 2 会变成 0 也恰好对，但别的用例立刻分道扬镳）。
2. **收益为 0 也要比较**：所有候选收益都是 0 时，仍要返回 `initial` 中最小下标；把 `best` 初始化为 `-1` 或直接返回 `initial[0]` 都是对的，但需保证遍历逻辑一致。
3. **tie-break 必须是严格大于**：写成 `>=` 会让升序遍历中的**最后一个**候选胜出，得到最大下标，与题意相反。
4. **`initial` 未排序**：若直接按输入顺序遍历，`best` 的并列规则就失效了；排序是必须的（或显式比较下标）。
5. **连通块内感染源计数**：只数 `initial` 里的节点，不要数「所有被感染的节点」。
6. **`n = 2` 的最小图**：`graph = [[1,1],[1,1]]`、`initial = [0,1]` → 单块 2 个源，收益均为 0 → 返回 0。
7. **单元素 `initial`**：只剩一个源时，移除它后整块获救（若该块只有它），答案就是它本身。
8. **图不保证连通**：$n$ 个节点可能有 $n$ 个连通块，`color` 必须初始化为 $-1$，不能假设全连通。
