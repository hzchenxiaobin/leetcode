# LeetCode 下降路径最小和 II 题解

## 1. 题目概述

- **标题 / 题号**：下降路径最小和 II（#1289，hard）
- **链接**：https://leetcode.cn/problems/minimum-falling-path-sum-ii/
- **来源**：LeetCode 第 15 场双周赛 Q4
- **难度**：困难
- **标签**：数组、动态规划、矩阵

**题意**：给定 $n \times n$ 整数矩阵 `grid`。**非零偏移下降路径**定义为：从每一行各选一个数字，且**相邻两行所选的数字不在同一列**。返回所有合法下降路径的数字和的最小值。

**约束**：

- $n == grid.length == grid[i].length$
- $1 \le n \le 200$
- $-99 \le grid[i][j] \le 99$

## 2. 示例

**示例 1**

```text
输入：grid = [[1,2,3],[4,5,6],[7,8,9]]
输出：13
解释：12 条路径中数字和最小的是 [1,5,7]，和为 13。
     列序列 (0,1,0) 满足相邻不同列。
```

**示例 2**

```text
输入：grid = [[7]]
输出：7
解释：1×1 矩阵，唯一路径就是 [7]。
```

**补充示例**

```text
输入：grid = [[-73,61,69,-16,96,12],[-10,17,10,63,-90,74],[-64,63,63,-37,47,-58],[38,-65,-43,71,77,85],
             [64,-72,37,-17,-67,-87],[74,-77,-17,47,60,-7]]
输出：-456
解释：存在负数时路径和可以为负，最优列序列为 (0,4,0,1,5,1)；
     动态规划初始化不能默认为 0。
```

## 3. 解题思路

### 3.1 暴力思路

枚举每一行选哪一列——共 $n^n$ 条路径（$n=200$ 时是天文数字），显然不可行。自然的改进是**动态规划**：

$$dp[i][j] = grid[i][j] + \min_{c \ne j} dp[i-1][c]$$

$dp[i][j]$ 表示"前 $i+1$ 行、第 $i$ 行选第 $j$ 列"的最小路径和。按此转移每行每列要扫一遍上一行（$O(n)$），总复杂度 $O(n^3) = 8 \times 10^6$（$n=200$），能过但浪费——$\min_{c \ne j}$ 对所有 $j$ 只有两种取值，值得继续压。

### 3.2 核心观察：上一行只需要"最小 + 次小"

![转移只需要上一行的最小值与次小值](images/bw15_q4_min1_min2_concept.svg)

$\min_{c \ne j} dp[i-1][c]$ 里唯一被"排除"的竞争者是 $j$ 自己那一列。把上一行的 $dp$ 值排序看：设最小值为 $min1$（在列 $c1$ 取得）、**不同列**上的次小值为 $min2$。那么对任意 $j$：

$$\min_{c \ne j} dp[i-1][c] = \begin{cases} min2, & j = c1 \\ min1, & j \ne c1 \end{cases}$$

——只有落在"冠军列"上时才被迫用次小值，其余位置人人都能用全局最小。于是**每行的转移不再需要看整行**，先花 $O(n)$ 扫出 $min1, c1, min2$，再花 $O(n)$ 整行转移，总复杂度从 $O(n^3)$ 降到 $O(n^2)$。这个技巧的经典出处是「265. 粉刷房子 II」。

### 3.3 算法流程

![滚动数组逐行推进的转移流程](images/bw15_q4_dp_transition_model.svg)

1. 初始化滚动数组 $dp[j] = grid[0][j]$（第 0 行无约束）；
2. 对 $i = 1 \dots n-1$：
   - 一趟扫描上一行的 $dp$，求出 $min1$、其所在列 $c1$、以及**来自不同列**的次小值 $min2$；
   - 整行转移：$dp[j] = grid[i][j] + (j = c1\ ?\ min2 : min1)$；
3. 答案为 $\min_j dp[j]$。

先算好 $min1/min2$ 再整行覆写，滚动数组才安全（边写边读会污染上一行）。

### 3.4 示例演算

![示例演算：3×3 矩阵逐行 DP](images/bw15_q4_example_walkthrough.svg)

以示例 1 演算（$n = 3$）：

- 第 0 行：$dp = [1, 2, 3]$；
- 处理第 1 行 $[4,5,6]$：上一行最小 $min1 = 1$（列 $c1 = 0$），次小 $min2 = 2$。转移：$dp[0] = 4 + min2 = 6$（第 0 列被迫避开冠军列），$dp[1] = 5 + min1 = 6$，$dp[2] = 6 + min1 = 7$。得 $[6, 6, 7]$；
- 处理第 2 行 $[7,8,9]$：$min1 = 6$（取列 0），$min2 = 6$（列 1，同值不同列）。转移：$dp[0] = 7 + 6 = 13$，$dp[1] = 8 + 6 = 14$，$dp[2] = 9 + 6 = 15$；
- 答案 $\min(13,14,15) = 13$ ✓（对应路径 $[1,5,7]$，列序列 $0 \to 1 \to 0$）。

注意第 2 行出现了 $min1 = min2 = 6$ 的**并列最小**：只要两者来自**不同列**，规则依然正确——第 0 列避开"列 0 的 6"还有"列 1 的 6"可用。

## 4. 算法细节

1. **滚动数组**：$dp$ 只保留一行，空间 $O(n)$。转移必须**先**求 $min1/min2$ **再**覆写整行——若边读边写，第 $j$ 列会读到已被新值污染的"上一行"。
2. **$min2$ 必须来自不同列**：求次小时排除 $c1$ 那一列，允许 $min2 = min1$（并列最小时），只要求列不同。否则 $j = c1$ 时会用一个并不存在的"可避开值"。
3. **并列最小时 $c1$ 任取其一**：多个列同为最小值时，$c1$ 选哪个都不影响正确性——落在被选中的 $c1$ 上用 $min2$（并列的另一个最小，来自别的列），落在未被选中的最小列上用 $min1$，两种取值都合法且都是"避开自身列的最小"。代码中用严格小于 `<` 更新 $min1$，先到者当选，实现最简。
4. **负数无害**：$dp$ 的初值直接取第 0 行的原始值（可正可负），全程无 `0` 之类假设；$min1/min2$ 的初值用 `LLONG_MAX`/`INT_MAX` 语义上的 $+\infty$。
5. **$n = 1$**：外层循环不执行，答案即 $\min grid[0]$，无需特判（示例 2）。
6. **求和范围**：$|dp| \le n \times 99 \le 19800$，`int` 完全够用；C++ 中用 `long long` 是防御性习惯，非必需。

## 5. 正确性证明

**引理 1（最优子结构）**：设 $dp[i][j]$ 为"从第 $0$ 行到第 $i$ 行、每行各取一数、相邻行不同列、且第 $i$ 行取第 $j$ 列"的最小和。则

$$dp[0][j] = grid[0][j],\qquad dp[i][j] = grid[i][j] + \min_{c \ne j} dp[i-1][c]$$

**证明**：归纳。$i=0$ 平凡。对 $i \ge 1$：任何以 $(i,j)$ 结尾的合法路径，其前缀是"到第 $i-1$ 行、结尾不在第 $j$ 列"的合法路径，前缀和 $\ge \min_{c \ne j} dp[i-1][c]$（归纳假设下该 min 就是所有这种前缀的最小值），故路径和 $\ge grid[i][j] + \min_{c \ne j} dp[i-1][c]$；反之，取达到该 $\min$ 的前缀（结尾列 $c^\ast \ne j$）接上 $(i,j)$，得到合法路径且和恰为右端。两端夹逼即得等式。∎

**引理 2（min1/min2 等价替换）**：设上一行 $dp$ 值的全局最小为 $min1$、取得最小值的某一列为 $c1$、$min2 = \min_{c \ne c1} dp[i-1][c]$。则对任意 $j$：$\min_{c \ne j} dp[i-1][c] = min2$ 若 $j = c1$，否则 $= min1$。

**证明**：若 $j \ne c1$：列 $c1$ 是合法候选且其值为 $min1$，故 $\min_{c \ne j} \le min1$；又任意候选 $c \ne j$ 满足 $dp[i-1][c] \ge min1$（全局最小），故 $\min_{c \ne j} \ge min1$。两者相等。若 $j = c1$：候选集恰为"除 $c1$ 外所有列"，其最小值按定义就是 $min2$。∎

**定理**：算法返回 $\min_j dp[n-1][j]$，即所有非零偏移下降路径的最小和；总时间 $O(n^2)$。

**证明**：最优路径必然在第 $n-1$ 行的某一列结束，其和 $= \min_j dp[n-1][j]$（引理 1）；算法按引理 2 的两分支计算每个 $dp[i][j]$，与引理 1 的转移一致（数学归纳于行号），滚动数组因"先汇总后覆写"（4 节第 1 点）逐行保持正确值。每行两趟 $O(n)$，共 $O(n^2)$。∎

## 6. 复杂度分析

- **时间**：$O(n^2)$。每行两趟线性扫描（求 $min1/min2$ 一趟 + 整行转移一趟），$n = 200$ 时约 $8 \times 10^4$ 次基本运算，比朴素 $O(n^3) = 8 \times 10^6$ 快两个数量级。
- **空间**：$O(n)$ 滚动数组（另有输入 $O(n^2)$ 不可省略；若允许原地修改 `grid` 可做到 $O(1)$ 额外空间）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minFallingPathSum(vector<vector<int>>& grid) {
        int n = grid.size();
        vector<long long> dp(grid[0].begin(), grid[0].end());   // 第 0 行
        for (int i = 1; i < n; ++i) {
            // 求上一行 dp 的最小值 min1（所在列 c1）与次小值 min2
            long long min1 = LLONG_MAX, min2 = LLONG_MAX;
            int c1 = -1;
            for (int j = 0; j < n; ++j) {
                if (dp[j] < min1) { min2 = min1; min1 = dp[j]; c1 = j; }
                else if (dp[j] < min2) min2 = dp[j];
            }
            // 转移：非同列用 min1，恰好在 c1 列只能用次小 min2
            for (int j = 0; j < n; ++j)
                dp[j] = grid[i][j] + (j == c1 ? min2 : min1);
        }
        return *min_element(dp.begin(), dp.end());
    }
};
```

### Python

```python
class Solution:
    def minFallingPathSum(self, grid: List[List[int]]) -> int:
        n = len(grid)
        dp = list(grid[0])                          # 第 0 行
        for i in range(1, n):
            # 求上一行 dp 的最小值 min1（所在列 c1）与次小值 min2
            c1 = min(range(n), key=lambda j: dp[j])
            min1 = dp[c1]
            min2 = min(dp[j] for j in range(n) if j != c1)
            # 转移：非同列用 min1，恰好在 c1 列只能用次小 min2
            dp = [grid[i][j] + (min2 if j == c1 else min1) for j in range(n)]
        return min(dp)
```

> 💡 两份代码均通过官方 2 组示例（输出 `13`、`7`）以及 297 组测试：$n \le 6$ 的 250 组与**穷举所有合法列序列**的参考对拍、$7 \le n \le 40$ 的 40 组与朴素 $O(n^3)$ DP 对拍、$n = 200$ 性能边界一组，`mismatch = 0`（含全负矩阵等极端值域）。

## 8. 边界情况与易错点

1. **负数矩阵**：$-99 \le grid[i][j]$ 允许全负，路径和可为负（补充示例输出 $-456$）。任何把 `dp` 初始化为 0、或用 `ans = 0` 起步的写法都会错；正确做法是直接以第 0 行为初值、以 $\min dp$ 收尾。
2. **$min2$ 必须避开 $c1$ 列**：若把次小实现成"排序取第二个"或"遍历时 `<=` 也更新 $min2$"，并列最小（如第 2 行的 $[6,6,7]$）会把 $min2$ 算成同一列的值——$j = c1$ 时转移就用了一个不存在的候选。正确实现：`dp[j] < min1` 时旧 $min1$ 降级为 $min2$；其余情况 `dp[j] < min2` 时更新（同一列被 `<` 的分支挡住，天然避开）。
3. **$n = 1$ 不特判也能对**：循环体不执行，`min(dp) = grid[0][0]`。但如果把求 $min2$ 的代码放在循环**外**（第 0 行也做转移），$n = 1$ 时 $min2$ 无定义——这也是"先汇总后覆写"流程顺带规避的坑。
4. **滚动数组的覆写时机**：转移必须整行一次性完成。若写成"单趟边求 $min$ 边更新 $dp[j]$"，后半行读到的是新值，前半行读到的是旧值，结果四不像。
5. **与 931 题的区别**：「931. 下降路径最小和」限制相邻列差 $\le 1$（上下相邻列），转移要访问三个特定列；本题是"任意**不同**列"，约束反而更松、更规整——$\min_{c \ne j}$ 的两值化技巧只在"排除一个集合极小"时可用，931 里并不适用。
6. **溢出**：和最大约 $200 \times 99 < 2 \times 10^4$，`int` 级别；C++ 用 `long long` 仅为习惯性防御。

**延伸思考**：本题的通用形态是"**行间转移 + 禁用自身列**"：转移 $\min_{c \ne j}$ 之所以能两值化，是因为禁用集只有一个元素，而"避开单点禁用的最小"永远 ∈ {全局最小, 次小}。若禁用集是任意集合 $S$，则需要维护"前 $|S|+1$ 小值及其列"（比如禁用相邻 $d$ 列就维护前 $d+1$ 小，思路可扩展到带状约束）。另一个方向：若允许"跳过某些行"或"每行选多个数"，模型变成分段 DP 或费用流——本题的 $O(n^2)$ 已经是这条线上最实用的模板。
