# LeetCode 比较字符串最小字母出现频次 题解

## 1. 题目概述

- **标题 / 题号**：比较字符串最小字母出现频次（#1170，medium）
- **链接**：https://leetcode.cn/problems/compare-strings-by-frequency-of-the-smallest-character/
- **来源**：LeetCode 第 151 场周赛 Q2
- **难度**：中等
- **标签**：数组，哈希表，字符串，二分查找，排序

**题意**：定义 $f(s)$ 为字符串 $s$ 中**字典序最小字母的出现次数**（$s$ 非空）。例如 $s = \text{"dcce"}$，最小字母是 `'c'`，出现 2 次，所以 $f(s) = 2$。

给定待查表 `queries` 与词汇表 `words`，对每个 $i$ 统计 `words` 中满足 $f(\text{queries}[i]) < f(W)$ 的词的**个数**，按 `queries` 的原顺序返回数组 `answer`。

两点容易被读漏：**「字典序最小」不是「频率最高」**；比较是**严格大于**，$f(W) = f(Q)$ 时不计入。

**约束**：

- $1 \le \text{queries.length} \le 2000$
- $1 \le \text{words.length} \le 2000$
- $1 \le \text{queries}[i].\text{length},\ \text{words}[i].\text{length} \le 10$
- 所有字符均为小写英文字母

> 💡 串长上限 10 是本题的暗线：它把 $f(s)$ 压进 $[1, 10]$，值域只有 10 个整数。「排序 + 二分」与「值域计数 + 后缀和」两条路线都成立，本节主推前者（不依赖串长，赛中最稳），后者在 §4 第 6 点说明。

## 2. 示例

**示例 1**

```text
输入：queries = ["cbd"], words = ["zaaaz"]
输出：[1]
解释：f("cbd") = 1（最小字母 'b' 出现 1 次），f("zaaaz") = 3（最小字母 'a' 出现 3 次）。
      1 < 3，所以 words 中有 1 个词满足条件。
```

**示例 2**

```text
输入：queries = ["bbb","cc"], words = ["a","aa","aaa","aaaa"]
输出：[1,2]
解释：f("bbb") = 3，words 中 f > 3 的只有 "aaaa"（f = 4）→ 1；
      f("cc") = 2，f > 2 的有 "aaa"（3）、"aaaa"（4）→ 2。
```

**补充示例（边界，非官方）**

```text
输入：queries = ["a","aaaa"], words = ["aaaa"]
输出：[1,0]
解释："a" 的 f = 1 < f("aaaa") = 4，贡献 1；"aaaa" 的 f = 4，与唯一候选相等，
      不满足严格大于，贡献 0。两端边界各有一次。
```

## 3. 解题思路

### 3.1 暴力思路

对每个查询 `queries[i]`：先算 $t = f(\text{queries}[i])$，再遍历整个 `words`，对每个词算 $f(W)$ 并比较，累加计数。

时间复杂度 $O(n \cdot m \cdot L)$，取上界 $2000 \times 2000 \times 10 = 4\times 10^7$ 次字符操作，勉强能过。但它浪费在**重复劳动**上：$f(W)$ 只取决于串 $W$ 自己，与查询方是谁毫无关系，却为每个查询重算了一遍。

如果能先把 $m$ 个 $f(W)$ 一次算好并排好序，那么每次查询就退化成「在有序数组里数一数有多少个元素严格大于 $t$」——这是二分查找的标准形态。

### 3.2 核心观察：f 是词的固有属性，把 words 压成一个有序数组

![核心观察：words 只预处理一次（求 f、排序），每次查询在有序 freq 上二分](images/wc151_q2_freq_concept.svg)

三个事实拼出最优解：

1. **$f$ 与查询无关**。$f(W)$ 是词 $W$ 的固有属性，可以**预计算**并复用。
2. **$f$ 与顺序无关**。$f(W)$ 只依赖「最小字母是谁、它出现几次」，与字母排列无关，因此 $f(W)$ 是一个可排序的整数。
3. **问题可归约**。把 $m$ 个 $f(W)$ 放进升序数组 `freq` 后，设 `pos` 为第一个满足 $\text{freq}[\text{pos}] > t$ 的下标（不存在则取 $m$），查询的答案就是
   $$\text{answer}[i] = \bigl|\{\,j : \text{freq}[j] > t\,\}\bigr| = m - \text{pos}$$

第 3 点的关键在于**严格大于**：`upper_bound` 返回第一个 $> t$ 的下标 `pos`，而升序数组里「下标 $\ge$ `pos`」的元素恰好全部 $> t$、「下标 $<$ `pos`」的恰好全部 $\le t$，所以个数就是后缀长度 $m - \text{pos}$。若误用 `lower_bound`（第一个 $\ge t$），等于 $t$ 的元素会被算进答案，示例 2 的 `"aaa"` 就会被 `"bbb"` 错误计入。

> 💡 一句话：把「两两比较」降维成「在一维有序数组上定位」。$n \times m$ 的比较被拆成 $O(m \log m)$ 的一次排序 + $n$ 次 $O(\log m)$ 的二分。

### 3.3 算法流程：排序 + 二分

![二分定位：维护 lo ≤ pos ≤ hi 的不变式，收缩到 pos 即答案](images/wc151_q2_binary_search.svg)

1. **求 f 值**：对每个 $W \in \text{words}$ 计算 $f(W)$，收集成长度 $m$ 的数组 `freq`。
2. **排序**：`freq` 升序排列，一次性 $O(m \log m)$。
3. **逐查询二分**：对每个 $Q \in \text{queries}$，令 $t = f(Q)$，在 `freq` 上求第一个 $> t$ 的下标 `pos`。
4. **计数**：`answer` 追加 $m - \text{pos}$。
5. **返回**：保持 `queries` 的原顺序输出（**不要排序 `queries`**，否则答案错位）。

手写二分时用「闭区间不变式」最不容易写错：

$$\text{lo} = 0,\quad \text{hi} = m,\qquad \text{循环条件 } \text{lo} < \text{hi}$$

$$\text{mid} = \left\lfloor \frac{\text{lo}+\text{hi}}{2} \right\rfloor,\qquad
\begin{cases}
\text{freq}[\text{mid}] \le t & \Rightarrow \text{lo} = \text{mid} + 1\\
\text{freq}[\text{mid}] > t & \Rightarrow \text{hi} = \text{mid}
\end{cases}$$

循环结束时 $\text{lo} = \text{hi} = \text{pos}$。第一条分支能放心取 `mid + 1`，因为 $\text{freq}[\text{mid}] \le t$ 时 `mid` 自己绝不可能是 `pos`；第二条只能取 `mid`，因为 `mid` 可能就是答案。

### 3.4 示例演算

![示例 2 演算：四个词的 f 值为 1、2、3、4，两次查询分别定位 pos = 3 与 pos = 2](images/wc151_q2_walkthrough.svg)

以示例 2 为例，`words = ["a","aa","aaa","aaaa"]` 全是单字母串，$f$ 就等于串长：

| 词 $W$ | 最小字母 | 出现次数 | $f(W)$ |
|---|---|---|---|
| `a` | `a` | 1 | 1 |
| `aa` | `a` | 2 | 2 |
| `aaa` | `a` | 3 | 3 |
| `aaaa` | `a` | 4 | 4 |

`freq = [1, 2, 3, 4]`（原本已升序），$m = 4$。逐查询：

| 查询 $Q$ | $t = f(Q)$ | 第一个 $> t$ 的下标 `pos` | 答案 $m - \text{pos}$ |
|---|---|---|---|
| `bbb` | 3 | 3（`freq[3] = 4 > 3`） | $4 - 3 = 1$ |
| `cc` | 2 | 2（`freq[2] = 3 > 2`） | $4 - 2 = 2$ |

得到 `answer = [1, 2]`，与官方输出一致。注意 `bbb` 的 $t = 3$ 与 `freq[2] = 3` 相等，被 `upper_bound` 正确地留在「$\le t$ 的前缀」里，不计入答案。

## 4. 算法细节

1. **$f(s)$ 的三种写法**：① 先 `min(s)` 再 `count`，Python 一行；② 26 桶计数后取最左非零桶；③ 一遍扫描维护 `minCh` 与 `cnt`，遇更小字母就 `cnt = 1`、遇相同就 `cnt++`。三者都是 $O(L)$，串长只有 10 时差别可忽略；② 最直白，③ 额外空间最省。下方 C++ 用 ②，Python 用 ①。
2. **必须用 `upper_bound` / `bisect_right`**：题目是严格大于。用 `lower_bound` 会把 $f(W) = t$ 的词多算进去，恰好错在「存在相等」的数据上。
3. **只排序 `freq`，不排序 `queries`**：答案要与 `queries` 下标一一对应。若要离线双指针，必须把 `(f(Q), index)` 一起排序再回填，不能直接排原数组。
4. **二分的区间写法**：`lo = 0, hi = m`，循环 `while (lo < hi)`，`mid = (lo + hi) >> 1`。`hi` 取 `m`（不是 `m - 1`）让「所有元素都 $\le t$」时 `pos = m` 自然成立，答案 $m - m = 0$。
5. **`pos` 的两个极端都合法**：全部 $> t$ 时 `pos = 0`，答案 $m$；全部 $\le t$ 时 `pos = m`，答案 0。不必特判，也不要写 `pos == m` 的越界访问。
6. **值域只有 10，可以换计数数组**：`cnt[v]` 记 $f(W) = v$ 的词数，再算后缀和 $\text{suf}[v] = \sum_{k>v} \text{cnt}[k]$，查询直接查 `suf[t]`，$O(1)$ 出答案。代价是依赖「串长 $\le 10$」这一条件，且数组要开到 $12$ 以免 $t = 10$ 时越界。
7. **常数估算**：$m \le 2000$，排序约 $2000 \times 11 \approx 2.2\times 10^4$ 次比较；$n$ 次二分共约 $2000 \times 11 = 2.2\times 10^4$ 次比较；字符扫描总量 $\le 4\times 10^4$。整题不到 $10^5$ 次操作。

## 5. 正确性证明

**引理 1**（$f$ 的计算）：按「维护当前最小字母 `minCh` 及其计数 `cnt`」的一遍扫描，结束时 `cnt` 恰为 $s$ 中字典序最小字母的出现次数。

**证明**：对已扫描前缀长度归纳。初始 `minCh` 为哨兵、`cnt = 0`。设前缀的当前最小字母为 $c$、出现次数 $k$，读入新字符 $x$：若 $x < c$，则 $x$ 是新的最小字母且此前未出现过，故 `cnt = 1` 正确；若 $x = c$，计数加一正确；若 $x > c$，最小字母不变、计数不变，同样正确。扫描完整个串即得 $f(s)$。∎

**引理 2**（计数公式）：设 `freq` 升序、长度 $m$，`pos` 为第一个满足 $\text{freq}[\text{pos}] > t$ 的下标（若不存在则 `pos = m`），则 $\bigl|\{j : \text{freq}[j] > t\}\bigr| = m - \text{pos}$。

**证明**：由升序与 `pos` 的最小性，对 $j < \text{pos}$ 有 $\text{freq}[j] \le t$；对 $j \ge \text{pos}$（`pos < m` 时）有 $\text{freq}[j] \ge \text{freq}[\text{pos}] > t$。于是大于 $t$ 的下标集合恰为 $\{\text{pos}, \text{pos}+1, \dots, m-1\}$，元素个数 $m - \text{pos}$；当 `pos = m` 时该集合为空，个数 $0 = m - m$，公式同样成立。∎

**引理 3**（二分不变式）：循环 `while (lo < hi)` 每次迭代后仍有 $\text{lo} \le \text{pos} \le \text{hi}$；初始 $\text{lo} = 0 \le \text{pos} \le m = \text{hi}$ 成立。

**证明**：取 $\text{mid} = \lfloor (\text{lo}+\text{hi})/2 \rfloor$，有 $\text{lo} \le \text{mid} < \text{hi}$。若 $\text{freq}[\text{mid}] \le t$，由引理 2 的论证 `mid` 及其左侧都 $\le t$，必有 $\text{pos} > \text{mid}$，令 $\text{lo} = \text{mid}+1$ 后不变式保持；若 $\text{freq}[\text{mid}] > t$，则 $\text{pos} \le \text{mid}$，令 $\text{hi} = \text{mid}$ 后不变式保持。每轮区间长度严格减小，故必终止于 $\text{lo} = \text{hi} = \text{pos}$。∎

**定理**：算法返回的数组满足 $\text{answer}[i] = \bigl|\{W \in \text{words} : f(W) > f(\text{queries}[i])\}\bigr|$。

**证明**：由引理 1，`freq` 中每个元素都等于对应词的 $f$ 值（排序只改变位置，不改变多重集）。对查询 $i$，第 3.3 节令 $t = f(\text{queries}[i])$，引理 3 保证二分终点就是第一个 $> t$ 的下标，引理 2 给出满足 $f(W) > t$ 的词数恰为 $m - \text{pos}$，这就是题目要求的计数。输出按 `queries` 原顺序追加，故下标对应关系正确。∎

## 6. 复杂度分析

- **时间**：算 $f$ 需扫描全部字符，$O\bigl(\sum L_W + \sum L_Q\bigr)$；排序 `freq` 为 $O(m \log m)$；$n$ 次二分共 $O(n \log m)$。合计 $O\bigl(\sum L_W + \sum L_Q + m\log m + n\log m\bigr)$，上界约 $4\times 10^4 + 2.2\times 10^4 + 2.2\times 10^4 < 10^5$。
- **空间**：`freq` 数组 $O(m)$，输出数组 $O(n)$；$f$ 的 26 桶与二分指针都是 $O(1)$ 额外空间。若改用值域计数法，则额外只需 $O(1)$（固定 12 个槽）。
- **对比暴力**：暴力为 $O\bigl(\sum L_W + \sum L_Q + n \cdot m \cdot L\bigr)$，最坏 $4\times 10^7$；本解把 $n \cdot m$ 项彻底消掉。
- **换用值域计数 + 后缀和**：时间降到 $O\bigl(\sum L_W + \sum L_Q + m + n\bigr)$，空间 $O(1)$，但依赖串长 $\le 10$。

## 7. 参考代码

### C++

```cpp
#include <algorithm>
#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> numSmallerByFrequency(vector<string>& queries, vector<string>& words) {
        // f(s)：字典序最小字母的出现次数（26 桶，取最左非零桶）
        auto f = [](const string& s) {
            int cnt[26] = {0};
            for (char ch : s) cnt[ch - 'a']++;
            for (int i = 0; i < 26; ++i)
                if (cnt[i]) return cnt[i];
            return 0;
        };

        vector<int> freq;
        freq.reserve(words.size());
        for (const auto& w : words) freq.push_back(f(w));
        sort(freq.begin(), freq.end());            // 升序

        vector<int> ans;
        ans.reserve(queries.size());
        for (const auto& q : queries) {
            int t = f(q);
            // 第一个 > t 的位置，其右侧元素个数即为答案
            int pos = (int)(upper_bound(freq.begin(), freq.end(), t) - freq.begin());
            ans.push_back((int)freq.size() - pos);
        }
        return ans;
    }
};
```

### Python

```python
from typing import List
from bisect import bisect_right


class Solution:
    def numSmallerByFrequency(self, queries: List[str], words: List[str]) -> List[int]:
        def f(s: str) -> int:
            smallest = min(s)
            return s.count(smallest)          # 最小字母的出现次数

        freq = sorted(f(w) for w in words)    # 升序
        m = len(freq)
        # bisect_right(freq, t) 返回第一个 > t 的下标，等价于 C++ 的 upper_bound
        return [m - bisect_right(freq, f(q)) for q in queries]
```

## 8. 边界情况与易错点

1. **相等不算**：$f(W) = f(Q)$ 时不计数。必须 `upper_bound`；写成 `lower_bound` 后 `m - pos` 会把相等元素算进去，示例 2 的 `"bbb"` 会错答 2。
2. **答案顺序**：`answer[i]` 对应 `queries[i]`。若为了双指针而排序 `queries`，必须连带存下标回填，否则张冠李戴。
3. **全部 $\le t$**：`pos = m` 时答案 0，说明 `hi` 初值要取 `m` 而非 `m - 1`，并且不要访问 `freq[m]`。
4. **全部 $> t$**：`pos = 0` 时答案 $m$，例如 `queries = ["a"]`、`words = ["zz"]`（$f = 2$）。
5. **单字符词**：$f$ 恒为 1，这是 $f$ 的下界；$f$ 的上界是 10（串长上限），远小于字母表大小 26，别把 $f$ 当成「字母种类数」。
6. **`min(s)` 的语义**：`min` 按字符编码比较，小写字母的字典序与编码序一致，所以直接 `min(s)` 即可，不必自定义比较器。
7. **值域计数法的越界**：若写 `cnt[f(w)]++` 且数组只开 10，$f = 10$（十个相同字母）时会越界，开到 12 更安全。
8. **空串**：题面保证词非空，`min(s)` 不会抛异常；若自行扩展接口需补判空。

**延伸思考**：

- **若 `words` 动态增删**：排序数组失效，可换成按 $f$ 值域建立树状数组（Fenwick），单次插入 $O(\log V)$、查询后缀和 $O(\log V)$。
- **若把严格大于改成 $\ge$**：只需把 `upper_bound` 换成 `lower_bound`，答案变为 $m - \text{lb}(t)$；后缀和版本则为 `suf[v] = suf[v+1] + cnt[v]`，差正好一个位置。
- **离线双指针**：把 $f(Q)$ 排序后，`pos` 随 $t$ 单调不减，可一遍扫过 `freq`，做到 $O(n\log n + m\log m)$（排序主导），适合 $n$ 远大于 $m$ 的场景。
- **若串长放宽到 $10^5$**：$f$ 仍是 $O(L)$，值域变成 $O(L)$，计数数组不再便宜，排序 + 二分重新成为首选；若 $L$ 与查询数都很大，可考虑按 $f$ 值分桶 + 前缀和离线回答。
