# LeetCode 两个键的键盘 题解

## 1. 题目概述

- **标题 / 题号**：两个键的键盘（#650，medium）
- **链接**：https://leetcode.cn/problems/2-keys-keyboard/
- **来源**：LeetCode 第 43 场周赛 Q2
- **难度**：中等
- **标签**：数学、动态规划

**题意**：记事本最初只有 **一个** `'A'`。每次可以执行两种操作之一：

- **Copy All**：把记事本中的**全部**字符复制到剪贴板（不允许只复制一部分）；
- **Paste**：把剪贴板上**上一次复制的内容**追加到记事本末尾。

求恰好得到 $n$ 个 `'A'` 所需的**最少操作次数**。注意剪贴板初始为空，因此第一次有效操作只能是 Copy All。

**约束**：

- $1 \le n \le 1000$
- 复制只能「全选复制」，粘贴只能粘贴上一次的完整剪贴板

> 💡 本题与 Q4「四个键的键盘」是同一系列：本题只有 Copy All 与 Paste 两个键，一旦加上「选中后部分覆盖」的第四个键，贪心的因子分解就不再成立，必须改用 DP。

## 2. 示例

**示例 1**

```text
输入：n = 3
输出：3
解释：初始 1 个 'A'
      第 1 步 Copy All  → 剪贴板 = 1 个 'A'
      第 2 步 Paste     → 2 个 'A'
      第 3 步 Paste     → 3 个 'A'
```

**示例 2**

```text
输入：n = 1
输出：0
解释：初始就已经是 1 个 'A'，无需任何操作。
```

**示例 3（补充，便于对照演算）**

```text
输入：n = 12
输出：7
解释：Copy Paste | Copy Paste | Copy Paste Paste
      Copy(1) Paste → 2 | Copy(2) Paste → 4 | Copy(4) Paste Paste → 8 → 12
      段代价 2 + 2 + 3 = 7。
```

## 3. 解题思路

### 3.1 暴力思路

最直白的做法是把「屏幕长度 + 剪贴板长度」当作状态做 BFS：起点 $(1, 0)$，每个状态有 Copy All 与 Paste 两条出边，第一次到达屏幕长度 $n$ 时的层数就是答案。状态数 $O(n^2)$、边数 $2n^2$，$n = 1000$ 时约 $10^6$ 个状态，能过但很笨。

也可以直接按「最后一段复制了多长」做 DP：$dp[i]$ 表示得到 $i$ 个 `'A'` 的最少步数，枚举 $i$ 的因子 $j$，则

$$dp[i] = \min_{j \mid i,\ j \ge 2}\Bigl(dp[i/j] + j\Bigr),\qquad dp[1] = 0$$

即先用 $dp[i/j]$ 步做出 $i/j$ 个 `'A'`，再 Copy 一次、Paste $j-1$ 次，共 $j$ 步把它放大 $j$ 倍。这是 $O(n\sqrt{n})$ 的解法，已经足够。但本题其实有一个**不用 DP** 的闭式答案。

### 3.2 核心观察：把操作序列切段，得到乘法分拆

![操作序列切段与乘法分拆](images/wc43_q2_block_factorization.svg)

在一段连续操作里，只要剪贴板不变，每次 Paste 加进来的字符数就是**固定的** $c$。而在每个 Copy All 的瞬间，剪贴板被改写成**当时的屏幕长度** $s$。于是相邻两次 Copy All 之间（含后一次 Copy 之前）的结构必然是：

$$\underbrace{\text{Copy All}}_{c \leftarrow s}\ \underbrace{\text{Paste}\ \text{Paste}\ \cdots\ \text{Paste}}_{k\ \text{次}}$$

屏幕从 $s$ 变成 $s + k\cdot s = s\,(k+1)$，这一段的代价是 $1 + k = k+1$ 步。

**令段因子 $f = k+1$**，则段代价恰好等于 $f$，屏幕长度乘以 $f$。若整条序列共 $m$ 段、段因子为 $f_1, \dots, f_m$，从 $1$ 出发连乘就得到

$$n = f_1 f_2 \cdots f_m,\qquad \text{总代价} = \sum_{i=1}^{m} f_i,\qquad f_i \ge 2$$

反过来，任给一个这样的分拆，按「Copy All + $(f_i-1)$ 次 Paste」逐段执行，就能用 $\sum f_i$ 步得到 $n$。所以问题等价于：

$$\boxed{\ \min \sum f_i \quad \text{s.t.}\quad \prod f_i = n,\ f_i \ge 2\ }$$

即求 $n$ 的**乘法分拆的最小元素和**。

### 3.3 算法流程：拆得越细越省，答案就是素因子和

![试除流程：反复剥离素因子](images/wc43_q2_factor_flow.svg)

关键的不等式：对任意整数 $a, b \ge 2$，

$$a + b \le a\,b \iff a\,b - a - b = (a-1)(b-1) - 1 \ge 0$$

也就是说，把一个因子 $f = ab$ **拆成** $a \cdot b$ 绝不会让总代价变大（仅当 $a = b = 2$ 时不变）。于是从任意分拆出发不断往下拆，代价单调不增，最终一定停在**全部是素数**的分拆上。由唯一分解定理，这个分拆正是 $n$ 的素因子分解，因此

$$\text{minSteps}(n) = \sum_{p \text{ 是 } n \text{ 的素因子（含重数）}} p$$

素因子和可以**不排序、不分段**地直接算出来：从小到大枚举 $d$，只要 $d \mid$ 当前的 $n$ 就不断剥离并把 $d$ 累加到答案。

> 💡 为什么不需要考虑因子的顺序？因为乘法可交换，交换 $f_i$ 只是把两段的先后次序对调，而每段的内部结构、每段代价 $f_i$ 都不变，总和自然不变。

### 3.4 示例演算

![n = 12 的逐步演算](images/wc43_q2_example_walkthrough.svg)

对 $n = 12 = 2 \times 2 \times 3$：逐段执行 **Copy Paste**（$f=2$，值 $1 \to 2$）、**Copy Paste**（$f=2$，$2 \to 4$）、**Copy Paste Paste**（$f=3$，$4 \to 12$），共 $2+2+3 = 7$ 步。

再对照其它分拆：$12 = 3 \times 4 \to 3 + 4 = 7$（同样最优，因为拆 $4$ 成 $2+2$ 不改变和）；$12 = 2 \times 6 \to 2+6 = 8$；$12 = 12 \to 12$。最小值确实是 $7$。

其它几组：$24 = 2^3 \times 3 \to 2+2+2+3 = 9$；$1000 = 2^3 \times 5^3 \to 2 \times 3 + 5 \times 3 = 21$；$97$ 是素数 $\to 97$；$n = 1 \to 0$。

## 4. 算法细节

1. **循环条件**：`d * d <= n`（等价于 $d \le \lfloor\sqrt{n}\rfloor$）。一旦 $d^2$ 超过**当前剩余**的 $n$，剩余部分就不存在更小的因子，必为素数；所以条件要对被除小之后的 $n$ 判断。
2. **内层必须是 while**：$1000 = 2^3 \cdot 5^3$，若写成 `if`，每轮只剥掉一个因子，会算出 $36$（正确值 $21$）。
3. **循环后收尾**：`if (n > 1) ans += n;`。漏掉这一步会丢失最大的那个素因子（$n = 6$ 会算成 $2$ 而不是 $5$）。
4. **顺序无关**：从小到大试除可以保证每次命中的 $d$ 必是素数——比 $d$ 小的数已经全部除干净了，所以不需要额外的素数判定。
5. **两种写法**：直接试除 $O(\sqrt{n})$、$O(1)$ 空间；若更喜欢 DP，则 `dp[1] = 0`，`for i in 2..n: dp[i] = i`，再对每个真因子 $j$ 做 `dp[i] = min(dp[i], dp[j] + i/j)`，时间 $O(n\sqrt{n})$、空间 $O(n)$，结果与素因子和完全一致。
6. **DP 的初值易错**：`dp[i]` 初值必须是 $i$（Copy 一次 + Paste $i-1$ 次），若初始化为 $0$ 或 `INF` 不更新会出错。
7. **`n = 1` 无需特判**：答案累加为 $0$，与「初值已满足」一致，但阅读时值得注意循环体一次都不执行。

## 5. 正确性证明

**引理 1（段结构）**：任意把 $1$ 个 `'A'` 变成 $n$ 个 `'A'` 的操作序列，都可以按 Copy All 切成 $m$ 段，使得每段是「$1$ 次 Copy All + $k_i$ 次 Paste」（允许 $k_i = 0$，此时 $f_i = 1$、这一段纯属浪费，删掉更优），且

$$n = \prod_{i=1}^{m}(1+k_i),\qquad \text{操作次数} = \sum_{i=1}^{m}(1+k_i)$$

**证明**：设第 $i$ 次 Copy All 时屏幕长度为 $s_i$，执行后剪贴板长度变为 $c_i = s_i$；在第 $i$ 段内（第 $i$ 次 Copy 之后、第 $i+1$ 次 Copy 之前）共粘贴 $k_i$ 次，每次加的都是同一个 $c_i = s_i$，于是下一段起点 $s_{i+1} = s_i + k_i s_i = s_i (1+k_i)$。第一次 Copy 之前剪贴板为空、无法 Paste，故 $s_1 = 1$；归纳得 $n = s_{m+1} = \prod (1+k_i)$，代价为 $m$ 次 Copy 加 $\sum k_i$ 次 Paste，即 $\sum (1+k_i)$。∎

**引理 2（拆分不等式）**：对整数 $a, b \ge 2$ 有 $a + b \le ab$，且等号成立当且仅当 $a = b = 2$。

**证明**：$ab - a - b = (a-1)(b-1) - 1$。因为 $a, b \ge 2$，所以 $(a-1)(b-1) \ge 1$，故差 $\ge 0$；等号要求 $(a-1)(b-1) = 1$，只能 $a-1 = b-1 = 1$，即 $a = b = 2$。∎

**引理 3（素因子和是最小值）**：设 $n > 1$ 的素因子（含重数）为 $p_1, p_2, \dots, p_r$，则对 $n$ 的任意乘法分拆 $n = \prod f_i$（$f_i \ge 2$）都有 $\sum f_i \ge \sum p_j$。

**证明**：由唯一分解定理，每个 $f_i$ 可唯一分解为素数之积，全部乘起来正好给出多重集 $\{p_1, \dots, p_r\}$。对每个复合的 $f_i = a b$ 反复套用引理 2：把 $f_i$ 替换成 $a, b$ 后总和变化为 $(a+b) - ab \le 0$，即总和单调不增。不断拆分直到所有因子都是素数，得到的分拆正是 $\{p_1,\dots,p_r\}$，故 $\sum p_j \le \sum f_i$。∎

**定理**：算法输出的 `ans` 等于最少操作次数。

**证明**：

- **可达（上界）**：由引理 1 的构造，按素因子逐个执行「Copy All + $(p-1)$ 次 Paste」，$n = \prod p_j$ 可达，代价恰为 $\sum p_j$，故最优值 $\le \sum p_j$。
- **下界**：任意合法序列由引理 1 对应一个乘法分拆且代价等于该分拆的元素和，由引理 3 该和 $\ge \sum p_j$，故最优值 $\ge \sum p_j$。

两侧合并得最优值 $= \sum p_j$。试除法通过「剥离全部最小因子 → 剩余部分必为素数」正确枚举了每个素因子，故 `ans` 即所求；$n = 1$ 时和为空集、值为 $0$，与「初值已满足」一致。∎

## 6. 复杂度分析

- **时间**：$O(\sqrt{n})$。外层 $d$ 从 $2$ 到 $\lfloor\sqrt{n}\rfloor$，每次 $O(1)$；内层总执行次数等于素因子个数（含重数），不超过 $\log_2 n$。$n \le 1000$ 时最多约 $31$ 次外层迭代。
- **空间**：$O(1)$，只用了 `ans`、`d` 与就地修改的 `n`。
- **对比 DP**：枚举因子的 DP 为 $O(n\sqrt{n})$ 时间、$O(n)$ 空间；BFS 为 $O(n^2)$ 时间空间。三者答案一致，本题数据范围下都可行，但素因子和写法最短最快。

## 7. 参考代码

### C++

```cpp
#include <iostream>
using namespace std;

class Solution {
public:
    int minSteps(int n) {
        int ans = 0;
        for (int d = 2; (long long)d * d <= n; ++d) {
            while (n % d == 0) {   // 剥离全部重复的素因子
                ans += d;
                n /= d;
            }
        }
        if (n > 1) ans += n;       // 剩下的最大素因子
        return ans;
    }
};
```

### Python

```python
class Solution:
    def minSteps(self, n: int) -> int:
        ans = 0
        d = 2
        while d * d <= n:          # 注意这里用的是被除小之后的 n
            while n % d == 0:
                ans += d
                n //= d
            d += 1
        if n > 1:                  # 剩余部分必为素数
            ans += n
        return ans
```

## 8. 边界情况与易错点

1. **`n = 1`**：返回 `0`，不是 `1`。循环体一次都不执行、`n > 1` 不成立，天然正确，不需要额外特判。
2. **`n` 为素数**（如 `97`）：返回 `n`，即 Copy 一次 + Paste $n-1$ 次；不要误以为能更快。
3. **内层写成 `if`**：`1000 = 2³·5³` 会算成 `36`（正确 `21`）；凡指数 $>1$ 的素因子都会漏乘，必须用 `while`。
4. **漏掉收尾**：`n = 6` 不累加剩余的 `3` 会得到 `2` 而非 `5`；`n = 5` 会得到 `0`。
5. **循环条件用原始 `n`**：若把 `n` 缓存成 `m` 并用 `d*d <= m` 判断，会在 `m` 已经除尽小因子后仍无谓地试除到底（结果仍对，但做了无用功，且容易在别处误用）。
6. **`d` 的步进**：从 `2` 开始逐个数枚举即可；命中的 `d` 一定是素数，不必预筛，也不必跳过偶数（数据范围小，跳过的收益可忽略）。
7. **DP 初值**：若改用 DP，`dp[i] = i` 的初值不能漏；`dp[1] = 0`。
8. **溢出意识**：本题 $n \le 1000$，`d * d` 不会溢出；若推广到 $n$ 接近 `INT_MAX`，应写 `d <= n / d` 或 `(long long)d * d <= n`。
