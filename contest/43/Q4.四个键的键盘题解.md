# LeetCode 四个键的键盘 题解

## 1. 题目概述

- **标题 / 题号**：四个键的键盘（#651，medium）
- **链接**：https://leetcode.cn/problems/4-keys-keyboard/
- **来源**：LeetCode 第 43 场周赛 Q4
- **难度**：中等
- **标签**：数学、动态规划

**题意**：键盘上只有四个键：`A`（在屏幕上打印一个 A）、`Ctrl-A`（全选屏幕上的内容）、`Ctrl-C`（把选区复制进剪贴板）、`Ctrl-V`（把剪贴板内容**追加**到屏幕末尾）。总共只能按 $N$ 次键，每次按一个键，求屏幕上最多能有多少个 `A`。

**约束**：

- $1 \le N \le 50$
- 答案在 32 位有符号整数范围内（$N = 50$ 时答案为 $1327104$）

## 2. 示例

**示例 1**

```text
输入：N = 3
输出：3
解释：最多只能连按 3 次 A：A, A, A → 3 个 A。
      （全选 + 复制已经吃掉 2 次键，只剩 1 次不足以形成有效乘法）
```

**示例 2**

```text
输入：N = 7
输出：9
解释：按 A, A, A, Ctrl-A, Ctrl-C, Ctrl-V, Ctrl-V
      前 3 次得到 3 个 A；全选复制后连续粘贴 2 次，屏幕变成 3 + 3 + 3 = 9。
      对照：一路按 A 只能得到 7，可见 N = 7 是复制粘贴首次跑赢的临界点。
```

> 💡 示例 2 说明：**复制粘贴要成块使用**。单独按 `Ctrl-A` 或 `Ctrl-C` 不产出任何 A，它们必须被「先攒基数、再乘一次」的块结构包住才划算。

## 3. 解题思路

### 3.1 暴力思路

直接枚举所有按键序列：每步 4 种选择，$N = 50$ 时共有 $4^{50} \approx 1.3 \times 10^{30}$ 条路径，不可能枚举。若把「屏幕长度 + 剪贴板长度 + 是否处于全选态」作为状态做 BFS，状态数同样随数值指数爆炸（剪贴板长度可以取到 $10^6$ 量级），依旧不可行。

暴力唯一的价值是验证小数据：$N \le 11$ 时 $4^{11} \approx 4.2 \times 10^{6}$ 条序列还可以用 DFS 全部跑完，正好用来对拍。

### 3.2 核心观察：最优序列的「规范形」

![最优按键序列的规范形：基数 + 若干乘法块](images/wc43_q4_phase_structure.svg)

先做三件事，把看似自由的 4 键序列压成固定骨架：

1. **`Ctrl-A` 与 `Ctrl-C` 必须相邻使用**：`Ctrl-A` 本身不改变屏幕，它唯一的用途是让随后的 `Ctrl-C` 有内容可复制；而 `Ctrl-C` 复制的永远是**整屏**，所以中间插不进任何有意义的键。
2. **一块连续粘贴 = 一次乘法**：设进入某块时屏幕上有 $S$ 个 A、剪贴板为空，则 `Ctrl-A, Ctrl-C` 之后剪贴板里是 $S$；再连续按 $v$ 次 `Ctrl-V`，屏幕变成 $(v+1)S$。记乘数 $f = v+1$（$f \ge 2$），这一块花费的键数是

$$2 + v = f + 1$$

3. **所有 `A` 键都提前**：若某个 `A` 按在某个乘法块之后，把它挪到所有块之前，它乘上的乘数就从「后面那些块」变成「全部块」，而每个乘数都 $\ge 2$，所以它的贡献只增不减。

于是最优序列一定形如：先按 $k$ 次 `A` 得到基数 $k$，随后串上若干个乘法块，乘数分别为 $f_1, f_2, \dots, f_m \ge 2$。屏幕最终是

$$k \cdot \prod_{i=1}^{m} f_i, \qquad \text{总键数} = k + \sum_{i=1}^{m}(f_i + 1) = N$$

每个乘数的「单位键收益」是 $f^{\frac{1}{f+1}}$：$f=2$ 时 $1.26$，$f=3$ 时 $1.316$，$f=4$ 时 $1.319$，$f=5$ 时 $1.308$。**收益在 $f = 3, 4$ 处最大**，这就是「$N$ 较大时答案基本是 $3^{a}4^{b}$ 形状」的原因。

### 3.3 状态转移

![dp 转移：最后一次按 A 或最后一段乘法块](images/wc43_q4_dp_transition.svg)

把「干净状态」（没有待用的选区，剪贴板内容无关紧要）作为阶段。设 $dp[i]$ 为用**恰好** $i$ 次按键能得到的最多 A 数，则最后一步只有两种可能：

- **最后一次是 `A`**：$dp[i-1] + 1$。
- **最后一段是一个乘法块**：块开始前用了 $k$ 次键，得到 $dp[k]$；块本身占 $2 + (i-k-2) = i-k$ 次键，其中粘贴 $i-k-2$ 次，乘数 $f = i-k-1$。转移为

$$dp[i] = \max_{1 \le k \le i-2} dp[k] \cdot (i - k - 1)$$

合并两式：

$$dp[i] = \max\Bigl(dp[i-1] + 1,\ \max_{1 \le k \le i-2} dp[k] \cdot (i-k-1)\Bigr), \qquad dp[0] = 0$$

注意 $k \le i-2$ 是硬约束：至少要留 2 次键给 `Ctrl-A` 与 `Ctrl-C`，否则连剪贴板都填不上。

### 3.4 示例演算

![N = 1..11 的 dp 走查表](images/wc43_q4_walkthrough.svg)

| $i$ | $dp[i]$ | 最优来源 | 说明 |
|-----|---------|----------|------|
| 1–6 | $i$ | 全按 `A` | 复制粘贴的 2 键开销还赚不回来 |
| 7 | 9 | $k=3$，$f=3$ | `A A A` + `Ctrl-A Ctrl-C` + 2 次粘贴 → $3 \times 3$ |
| 8 | 12 | $k=3$，$f=4$ | 同上但粘贴 3 次 → $3 \times 4$ |
| 9 | 16 | $k=4$，$f=4$ | `A A A A` + 2 键 + 3 次粘贴 → $4 \times 4$ |
| 10 | 20 | $k=4$，$f=5$ | $4 \times 5$（$k=5, f=4$ 同样得 20） |
| 11 | 27 | $k=7$，$f=3$ | 用 $dp[7]=9$ 再乘 3 → $9 \times 3$，**第二段乘法** |

$N=7$ 的例子走查：$k=3$ 时 $dp[7] = dp[3]\cdot(7-3-1) = 3 \times 3 = 9$，对应按键 `A, A, A, Ctrl-A, Ctrl-C, Ctrl-V, Ctrl-V`；$N=14$ 更能说明问题——只允许「一段乘法」的公式 $k(N-k-1)$ 最多给 $6 \times 7 = 42$，而 $dp[14] = 64 = 4 \times 4 \times 4$，**必须允许乘法链**，这也是本题不能只用一条公式的原因。

## 4. 算法细节

1. **状态只记「干净状态」**：$dp[i]$ 描述的是「屏幕上 $dp[i]$ 个 A、没有待用选区」的最好情况。剪贴板内容对后续没有影响（下一块的 `Ctrl-A` 会整体覆盖它），因此不必进入状态，问题从「字符串状态」降成「一维数值 DP」。
2. **转移的上界 $k \le i-2$**：至少留 2 次键做 `Ctrl-A` 与 `Ctrl-C`；$k = i-2$ 时乘数为 $i-k-1 = 1$，是一个「白按两次键」的废块，取不取都不影响答案。不要为了省一次循环把上界收成 $k \le i-3$：本题 $N \le 50$ 内 $f = 2$ 的块确实从不最优，但那是数据巧合，不是可依赖的结论。
3. **乘数与粘贴次数的换算**：粘贴 $v$ 次 → 乘数 $v+1 = i-k-1$。实现时直接写 `i - k - 1`，不要先算 $v$ 再 $+1$，否则容易把边界写歪。
4. **初值与单调性**：$dp[0] = 0$，且恒有 $dp[i] \ge dp[i-1] + 1 \ge i$（一路按 A 的策略成立），所以答案单调递增，$N \le 6$ 时自然退化为 $N$。
5. **可剪枝的枚举范围**：因为单位键收益在 $f = 3, 4$ 处最大，$i \ge 7$ 时只需比较 $k = i-4$（$\times 3$）与 $k = i-5$（$\times 4$）两个候选，内层循环退化成常数，整体 $O(N)$。这一步对 $N \le 50$ 逐项验证与完整 DP 一致，但严格说明「末段乘数不会超过 4」需要更细的交换论证；比赛中直接写 $O(N^2)$ 最稳妥，把剪枝当验算手段用。
6. **等价的闭式写法**：由规范形，答案也可写成「枚举基数 $b$、乘 $4$ 的次数 $a$、乘 $3$ 的次数 $c$」，满足 $b + 5a + 4c = N$，取 $b \cdot 4^a 3^c$ 的最大值。它与 DP 在 $N \le 50$ 上逐项一致，可用于交叉验证。
7. **数值范围**：$N = 50$ 时答案为 $1327104$，`int` 足够；若把 $N$ 放宽到 $10^3$ 量级，$4^{N/5}$ 会溢出 64 位，需要取模或高精度——那时问题性质也变了。

## 5. 正确性证明

**引理 1（规范形）**：对任意合法按键序列，都存在一个「$k$ 次 `A` 后接若干乘法块」的序列，按键次数相同且屏幕上的 A 数不减少。

**证明**：分三步整理序列。① 删除所有后面不跟 `Ctrl-C` 的 `Ctrl-A`，以及所有不在 `Ctrl-A` 之后的 `Ctrl-C`：它们不改变屏幕，删除后屏幕数不变、键数减少（缺少的键补按 `A`，屏幕数不减）。② 把每个 `Ctrl-C` 与其后紧邻的一串 `Ctrl-V` 收拢为一个块：块内粘贴共用同一份剪贴板内容 $S$，故块把屏幕从 $S$ 变为 $(v+1)S$；块外不再出现 `Ctrl-V`。③ 把每个 `A` 向左交换到所有块之前：它原先只乘上「后面那些块」的乘数，交换后乘上全部乘数，每个乘数 $\ge 2$，贡献不减；$A$ 之间互不影响。整理完毕即得规范形，且总键数不变。∎

**引理 2（块的作用）**：在干净状态下，一次 `Ctrl-A, Ctrl-C` 与随后 $v$ 次 `Ctrl-V` 把屏幕从 $S$ 变为 $(v+1)S$，消耗 $v+2$ 次按键。

**证明**：`Ctrl-A` 选中整屏 $S$，`Ctrl-C` 使剪贴板为 $S$；每次 `Ctrl-V` 追加 $S$，$v$ 次后屏幕为 $S + vS = (v+1)S$；键数为 $1+1+v = v+2$。∎

**引理 3（转移覆盖最优解的末端）**：对 $i \ge 1$，最优规范形序列的最后一键若是 `A`，则 $dp[i] = dp[i-1]+1$ 可达；若最后一键属于某个乘法块且该块开始时已用 $k$ 次键，则 $dp[i] \ge dp[k] \cdot (i-k-1)$。

**证明**：前一种情况去掉最后一键即得 $i-1$ 键的可行序列。后一种情况：该块之前的 $k$ 次按键构成一个合法前缀，屏幕数为 $dp[k]$ 的上界；块内粘贴次数为 $i-k-2$，由引理 2 乘数为 $i-k-1$，故整段可达 $dp[k]\cdot(i-k-1)$。∎

**定理**：递推 $dp[i] = \max\bigl(dp[i-1]+1,\ \max_{1\le k\le i-2} dp[k](i-k-1)\bigr)$ 给出的 $dp[N]$ 等于 $N$ 次按键能得到的最多 A 数。

**证明**：对 $i$ 归纳。**下界**：两个候选都对应真实按键序列（一路按 `A`；或先取 $i-1$ 键最优序列再按 `A`；或取 $k$ 键最优序列后接 `Ctrl-A, Ctrl-C` 与 $i-k-2$ 次 `Ctrl-V`），故 $dp[i]$ 不超过真实最优值。**上界**：任取一个 $i$ 键最优序列，由引理 1 可设其为规范形且不退化。若它没有乘法块，则全按 `A`，值为 $i = dp[i-1]+1$，被第一项覆盖；若末块从第 $k+1$ 键开始，则前 $k$ 键是合法前缀、由归纳假设其屏幕数 $\le dp[k]$，再由引理 2 末块乘数为 $i-k-1$，整条序列的值 $\le dp[k](i-k-1)$，被第二项覆盖。两种情形都不超过递推值，故 $dp[i]$ 恰为最优值。∎

## 6. 复杂度分析

- **时间**：$O(N^2)$。外层枚举 $i = 1..N$，内层枚举 $k = 1..i-2$，每次 $O(1)$ 乘法与比较；$N \le 50$ 时约 $1.2 \times 10^3$ 次运算。采用 §4.5 的剪枝可降为 $O(N)$。
- **空间**：$O(N)$，只存一维 $dp$ 数组；若只保留最近 5 项还可压到 $O(1)$（完整写法没必要为此牺牲可读性）。

## 7. 参考代码

### C++

```cpp
#include <algorithm>
#include <vector>
using namespace std;

class Solution {
public:
    int maxA(int n) {
        vector<int> dp(n + 1, 0);
        for (int i = 1; i <= n; i++) {
            dp[i] = dp[i - 1] + 1;                 // 第 i 键是 A
            // 最后一段为乘法块：前 k 键得到 dp[k]，块内粘贴 i-k-2 次，乘数 i-k-1
            for (int k = 1; k <= i - 2; k++) {
                dp[i] = max(dp[i], dp[k] * (i - k - 1));
            }
        }
        return dp[n];
    }
};
```

### Python

```python
class Solution:
    def maxA(self, n: int) -> int:
        dp = [0] * (n + 1)
        for i in range(1, n + 1):
            dp[i] = dp[i - 1] + 1           # 第 i 键是 A
            # 最后一段为乘法块：前 k 键得到 dp[k]，粘贴 i-k-2 次，乘数 i-k-1
            for k in range(1, i - 1):
                dp[i] = max(dp[i], dp[k] * (i - k - 1))
        return dp[n]
```

## 8. 边界情况与易错点

1. **$N \le 6$**：复制粘贴块必须先花 2 键做全选与复制，再加至少 1 键粘贴才有 2 倍收益，预算根本摊不平，此时一路按 `A` 就是最优（答案即 $N$）。不要把「乘 4」写死成通式，必须由 `dp[i-1]+1` 兜住前 6 项。
2. **$k$ 的上界**：循环写到 $k \le i-2$（至少留 2 键）。写小成 $k \le i-3$ 在本题 $N \le 50$ 内凑巧不出错，但会依赖「$f=2$ 从不最优」这一未证明的性质；写大成 $k \le i-1$ 时乘数 $i-k-1$ 会变成 0，虽然不会算大答案，却多出一堆无意义项。
3. **乘数公式差一**：粘贴 $v$ 次对应乘数 $v+1$，而 $v = i-k-2$，所以乘数是 $i-k-1$。写成 $i-k-2$ 会把 $N=7$ 算成 6。
4. **`dp[i-1]+1` 不能省**：它同时承担「$i$ 较小时无块可用」和「最后补按一个 A 收尾」两种情形，省掉后 $dp$ 会在小 $i$ 处取到 0。
5. **$N=1$**：返回 1（`dp[0]=0`，`dp[1]=1`），内层循环不执行，直接走第一项。
6. **溢出与范围**：本题 $N \le 50$、答案 $1327104$，`int` 足够；若题目把 $N$ 提到 $10^2$ 以上，需改用 `long long` 并留意答案上界。
