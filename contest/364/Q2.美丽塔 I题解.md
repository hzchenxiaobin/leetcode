# LeetCode 美丽塔 I 题解

## 1. 题目概述

- **标题 / 题号**：美丽塔 I（#2865，medium）
- **链接**：https://leetcode.cn/problems/beautiful-towers-i/
- **来源**：LeetCode 第 364 场周赛 Q2
- **难度**：中等
- **标签**：栈、数组、单调栈

**题意**：给定 $n$ 座**连续**的塔，$heights[i]$ 为第 $i$ 座塔现有的砖块数。允许**移除**砖块（等价于把任意塔压低到不超过原高度），使最终塔排列呈**山脉状**：高度先**非递减**，中间一段连续塔达到**最大峰值**，随后**非递增**。求所有山脉状方案中**高度和的最大值**。

**约束**：

- $1 \le n = heights.length \le 10^3$
- $1 \le heights[i] \le 10^9$

> 💡 赛场视角：本题与同场 Q3（[2866. 美丽塔 II](https://leetcode.cn/problems/beautiful-towers-ii/)）**题面一字不差**，唯一区别是 $n$ 从 $10^3$ 放大到 $10^5$——与第 365 场 Q1/Q2（有序三元组）如出一辙的「I/II 姊妹题」编排：**Q2 给 $O(n^2)$ 留活路，Q3 逼出 $O(n)$**。赛时最优策略是先扫一眼 Q3 确认只差数据范围：求稳就 Q2 交 $O(n^2)$ 立刻拿分、Q3 再上单调栈；手熟则直接写单调栈版，一份代码通吃两题。本题另有[每日题解 2865](../../solution/2801-2900/2865_美丽塔I.md)：与本文互为印证，其单调栈推导与面试问答式展开更详细；本文侧重**赛场决策、逐塔支配式的严谨证明与边界复盘**。

## 3. 解题思路

### 3.1 暴力思路：先数清楚「自由度」

最朴素的做法是对每座塔独立枚举最终高度，组合空间是 $\prod_k heights[k]$，指数级，$n = 10^3$ 下连边都摸不着。

但山脉状约束让自由度骤减：**整条形态由「峰」完全刻画**。枚举峰下标 $i$（仅 $n$ 个候选）后，剩下的问题只是「左侧 $[0..i]$ 非递减、右侧 $[i..n{-}1]$ 非递增、且每塔不超上限时，每座塔垫多高」。这一步若再逐塔搜索仍是指数级——正确姿势是下面的贪心。

### 3.2 核心观察：固定峰后，「尽量高」逐塔最优

![核心概念：固定峰后每座塔尽量高，min 从峰向两侧传播](images/wc364_q2_mountain_concept.svg)

- **观察 1（峰是唯一的形态自由度）**：山脉状 $\iff$ 存在下标 $i$ 使 $t[0..i]$ 非递减、$t[i..n{-}1]$ 非递增（$t$ 为最终塔高）。可行方案按「峰在谁家」恰好分成 $n$ 类，逐类求最大再取总最大即可。
- **观察 2（固定峰后最优形态唯一）**：峰取 $i$ 时，最优方案是把每座塔**垫到约束允许的最高**：$t[i] = heights[i]$，左半 $t[k] = \min(heights[k..i])$，右半 $t[k] = \min(heights[i..k])$。直觉：砖块是白给的，单座塔压低只会让和变小；而「垫到最高」恰好仍满足山脉约束——区间 $\min$ 随 $k$ 靠近峰单调不降（右半对称）。
- **观察 3（传播式计算）**：由 $\min(heights[k..i]) = \min\big(heights[k],\ \min(heights[k{+}1..i])\big)$，最优塔高可**从峰向两侧逐格传播**求得：$t[k] = \min(t[k{+}1],\ heights[k])$（左半），右半对称。每个峰一趟线性扫描。

三个观察合起来，每个峰的最优和 $O(n)$ 可求，总复杂度 $O(n^2)$。

### 3.3 算法流程：枚举 $n$ 个峰 + 双向传播

![算法流程：枚举峰加双向传播，O(n²) 即本题赛时正解](images/wc364_q2_algorithm_flow.svg)

1. 外层枚举峰 $i = 0, 1, \dots, n-1$；
2. 初始化 $sum = cur = heights[i]$；
3. $j$ 从 $i-1$ 递减到 $0$：$cur \leftarrow \min(cur,\ heights[j])$，$sum \mathrel{+}= cur$（向左传播）；
4. 重置 $cur = heights[i]$，$j$ 从 $i+1$ 递增到 $n-1$：同样传播累加（向右传播）；
5. $ans \leftarrow \max(ans,\ sum)$，进入下一个峰。

$n \le 10^3$ 时总工作量 $\approx 10^6$ 次 `min`，毫秒级通过——**这就是本题的赛时正解**。

**升级预告（Q3 #2866 的正解）**：$O(n^2)$ 的浪费在于「峰从 $i{-}1$ 移到 $i$ 时，左侧塔高只有被压平的一段发生变化，却整段重算」。记 $left[i]$ 为峰取 $i$ 时 $[0..i]$ 的最优和，设 $j$ 为 $i$ 左侧第一个满足 $heights[j] \le heights[i]$ 的下标，则 $(j, i]$ 全被压平到 $heights[i]$、$[0..j]$ 与峰取 $j$ 时完全一致：

$$left[i] = left[j] + heights[i] \times (i - j)$$

「左侧第一个 $\le$」正是**单调栈**的经典工作：两遍扫描 $O(n)$ 预处理 $left$ / $right$，合并时减去重复计入的峰。完整推导、配图与递推证明见[每日题解 2865](../../solution/2801-2900/2865_美丽塔I.md)与[每日题解 2866](../../solution/2801-2900/2866_美丽塔II.md)，本文 §5 引理 3 亦给出递推式的证明，§7 附可直接提交的 $O(n)$ 代码。

## 4. 算法细节

1. **两类等价写法**：传播式（滚动维护 $cur = \min(cur, h[j])$）与区间式（$t[k] = \min(h[k..i])$）完全等价；赛时写传播式——一趟扫描、无重复取 $\min$，最不易错。
2. **全程 64 位**：和的上界 $\approx n \times \max(heights) \approx 10^3 \times 10^9 = 10^{12}$，超出 `int32`（$\approx 2.1 \times 10^9$）三个数量级。C++ 中 $sum$ 从第一次累加起就必须是 `long long`；单调栈版 $heights[i] \times (i-j)$ 要先乘 `1LL`。官方函数签名返回 `long long`，照抄即可。Python 原生大整数无此顾虑。
3. **「峰」的语义**：代码里「峰取 $i$」实为「以 $i$ 为非递减终点 & 非递增起点」，即 $i$ 只需落在最大峰值段内，不要求严格单峰——连续相等峰（示例 3）自动兼容。
4. **单调栈弹栈条件用严格大于**：`heights[stk.top()] > heights[i]` 才弹、相等保留，使 $j$ 停在最近的相等位置；由 §5 引理 3，只要 $heights[j] \le heights[i]$（含相等）递推式就成立。
5. **对拍建议**：$O(n^2)$ 版与单调栈版互拍，再用小数据真暴力（$n \le 5$、$h \le 5$ 时枚举所有塔高组合）兜底，随机几百组即可放心提交（本文代码已按此验证，见 §7 末尾）。
6. **赛时决策**：$n \le 10^3$ 时 $O(n^2)$ 稳过且 5 分钟写完；除非已确认 Q3 只差数据范围，否则不必在 Q2 上抢写单调栈。

## 5. 正确性证明

约定 $h = heights$，$t$ 表示最终塔高方案，并定义
$$C_i = \{\, t : t[0..i]\ \text{非递减},\ t[i..n{-}1]\ \text{非递增},\ \forall k,\ t[k] \le h[k] \,\}.$$

**引理 1（峰的刻画）**：$t$ 是山脉状方案，当且仅当存在 $i$ 使 $t \in C_i$。

**证明**：（⇐）$t \in C_i$ 时左段非递减终于 $t[i]$、右段非递增始于 $t[i]$，故 $t[i]$ 是全局最大值且最大值段包含 $i$，是山脉状。（⇒）设山脉状方案的最大峰值段为连续区间 $[p, q]$，取 $i \in [p, q]$：$[0..i]$ 非递减、$[i..n{-}1]$ 非递增，且每塔不超上限，故 $t \in C_i$。∎

**引理 2（固定峰的逐塔支配解）**：固定 $i$，定义 $t^*[k] = \min(h[k..i])$（$k < i$）、$t^*[i] = h[i]$、$t^*[k] = \min(h[i..k])$（$k > i$）。则 $t^* \in C_i$，且对任意 $t \in C_i$ 与**每个** $k$ 都有 $t[k] \le t^*[k]$；从而 $t^*$ 是 $C_i$ 中唯一的和最大者。

**证明**：先证 $t^* \in C_i$。左半：$t^*[k] = \min(h[k..i]) \le \min(h[k{+}1..i]) = t^*[k{+}1]$，非递减；$t^*[k] \le h[k]$ 显然；右半对称。再证逐塔支配：设 $t \in C_i$，对 $k < i$ 与任意 $j \in [k, i]$，非递减给出 $t[k] \le t[j]$，上限给出 $t[j] \le h[j]$，故 $t[k] \le \min_{j \in [k,i]} h[j] = t^*[k]$；$k = i$ 时 $t[i] \le h[i] = t^*[i]$；$k > i$ 对称。逐塔求和得 $\sum_k t[k] \le \sum_k t^*[k]$，等号当且仅当 $t = t^*$。∎

**引理 3（left 递推）**：设 $L_i = \sum_{k=0}^{i} \min(h[k..i])$（约定 $L_{-1} = 0$），$j$ 为 $i$ 左侧第一个满足 $h[j] \le h[i]$ 的下标（不存在则 $j = -1$），则
$$L_i = L_j + h[i] \times (i - j).$$

**证明**：对 $k \in (j, i]$：区间 $[k..i] \subseteq (j..i]$，其中除 $h[i]$ 外的元素全部 $> h[i]$，故 $\min(h[k..i]) = h[i]$，共 $(i - j)$ 项、合计 $h[i] \times (i-j)$。对 $k \le j$：$[k..i]$ 的最小值 $= \min\big(\min(h[k..j]),\ \min(h[j{+}1..i])\big) = \min\big(\min(h[k..j]),\ h[i]\big) = \min(h[k..j])$（末步因 $\min(h[k..j]) \le h[j] \le h[i]$），恰为 $L_j$ 的第 $k$ 项。两段相加即得。∎

**定理**：算法返回 $\max_{0 \le i < n} \big(L_i + R_i - h[i]\big)$，即题目所求的最大高度和（$R_i$ 按右侧对称定义）。

**证明**：由引理 1，可行方案集 $= \bigcup_i C_i$；由引理 2，每个 $C_i$ 的最大和为 $\sum_k t^*[k] = L_i + R_i - h[i]$（峰 $t^*[i] = h[i]$ 在 $L_i$、$R_i$ 中各计一次，须减去一份）。故全局最大 $= \max_i (L_i + R_i - h[i])$。枚举传播版按 $t^*[k] = \min(t^*[k{+}1], h[k])$ 从峰向两侧逐格算出与 $t^*$ 逐项相同的值；单调栈版由引理 3 的递推计算同一组 $L_i, R_i$。两者都恰好返回该最大值。∎

> 💡 引理 2 的「**逐塔支配**」比交换论证更干脆：不论证交换是否破坏可行性，而是直接给出每座塔的高度上界，再验证同时取等的方案存在。这是「固定断点 + 两侧独立」类问题的通用证明姿势。

## 6. 复杂度分析

- **时间复杂度**：$O(n^2)$。外层 $n$ 个峰，每峰向两侧各一趟线性传播；$n = 10^3$ 时约 $10^6$ 次 `min`/加法，毫秒级。单调栈版 $O(n)$：每个下标进栈、出栈各一次，正反两遍扫描均为线性。
- **空间复杂度**：$O(1)$ 额外（枚举版仅滚动 `sum` / `cur` / `ans`）；单调栈版 $O(n)$（`left` / `right` 数组与栈）。
- **对 Q3 的意义**：$n = 10^5$ 时 $O(n^2) \approx 10^{10}$ 次运算必然超时，单调栈 $O(n)$ 是唯一活路——本题先用 $O(n^2)$ 拿分、把 $O(n)$ 留给 Q3，正是姊妹题编排下的正确复杂度分工。

## 7. 参考代码

### C++（赛时主推：枚举峰 + 双向传播，$O(n^2)$）

```cpp
class Solution {
  public:
    long long maximumSumOfHeights(vector<int>& heights) {
        int n = heights.size();
        long long ans = 0;
        for (int i = 0; i < n; i++) {           // 枚举峰：i 落在最大峰值段内即可
            long long sum = heights[i];
            int cur = heights[i];
            for (int j = i - 1; j >= 0; j--) {  // 向左传播 min
                cur = min(cur, heights[j]);
                sum += cur;
            }
            cur = heights[i];
            for (int j = i + 1; j < n; j++) {   // 向右传播 min
                cur = min(cur, heights[j]);
                sum += cur;
            }
            ans = max(ans, sum);
        }
        return ans;
    }
};
```

### C++（单调栈 $O(n)$，Q3 #2866 原样通用）

```cpp
class Solution {
  public:
    long long maximumSumOfHeights(vector<int>& heights) {
        int n = heights.size();
        vector<long long> left(n), right(n);
        vector<int> stk;                              // 存下标，栈内 heights 递增
        for (int i = 0; i < n; i++) {
            while (!stk.empty() && heights[stk.back()] > heights[i])
                stk.pop_back();
            int j = stk.empty() ? -1 : stk.back();     // 左侧第一个 <= h[i]
            left[i] = (j < 0 ? 0 : left[j]) + 1LL * heights[i] * (i - j);
            stk.push_back(i);
        }
        stk.clear();
        for (int i = n - 1; i >= 0; i--) {
            while (!stk.empty() && heights[stk.back()] > heights[i])
                stk.pop_back();
            int j = stk.empty() ? n : stk.back();     // 右侧第一个 <= h[i]
            right[i] = (j == n ? 0 : right[j]) + 1LL * heights[i] * (j - i);
            stk.push_back(i);
        }
        long long ans = 0;
        for (int i = 0; i < n; i++)
            ans = max(ans, left[i] + right[i] - heights[i]);  // 峰被 L、R 各计一次
        return ans;
    }
};
```

### Python（枚举峰 + 双向传播，$O(n^2)$）

```python
class Solution:
    def maximumSumOfHeights(self, heights: List[int]) -> int:
        n = len(heights)
        ans = 0
        for i in range(n):                    # 枚举峰
            cur = sum_ = heights[i]
            for j in range(i - 1, -1, -1):     # 向左传播 min
                cur = min(cur, heights[j])
                sum_ += cur
            cur = heights[i]
            for j in range(i + 1, n):          # 向右传播 min
                cur = min(cur, heights[j])
                sum_ += cur
            ans = max(ans, sum_)
        return ans
```

### Python（单调栈 $O(n)$）

```python
class Solution:
    def maximumSumOfHeights(self, heights: List[int]) -> int:
        n = len(heights)
        left, right = [0] * n, [0] * n
        stk = []                                    # 存下标，栈内 heights 递增
        for i in range(n):
            while stk and heights[stk[-1]] > heights[i]:
                stk.pop()
            j = stk[-1] if stk else -1              # 左侧第一个 <= h[i]
            left[i] = (left[j] if j >= 0 else 0) + heights[i] * (i - j)
            stk.append(i)
        stk = []
        for i in range(n - 1, -1, -1):
            while stk and heights[stk[-1]] > heights[i]:
                stk.pop()
            j = stk[-1] if stk else n               # 右侧第一个 <= h[i]
            right[i] = (right[j] if j < n else 0) + heights[i] * (j - i)
            stk.append(i)
        return max(l + r - h for l, r, h in zip(left, right, heights))
```

> 💡 两版实现已在 $n \le 5$、$h \le 5$ 的全枚举真暴力与 300 组随机数据（$n \le 10^3$、$h \le 10^9$）下对拍一致，三个官方示例全部通过；$O(n)$ 版在 $n = 10^5$ 下（Q3 数据范围）同样毫秒级。

## 8. 边界情况与易错点

1. **32 位溢出（本题最大的坑）**：$10^3 \times 10^9 = 10^{12}$，`int` 直接爆；C++ 全程 `long long`（含 `1LL *` 乘法），Python 无此问题。
2. **连续相等峰值**（示例 3）：最优峰可以是一段（`[2,2,5,5,2,2]` 的峰段为下标 2、3）。枚举法天然覆盖；单调栈弹栈条件必须**严格大于**（相等保留），否则 $j$ 越过相等位置、递推式错位。
3. **峰在两端**（示例 1 峰在下标 0）：一侧传播循环不进入，无需特判；$n = 1$ 时唯一塔自身即峰，答案 $heights[0]$。
4. **全局最小值当峰**（示例 2 的 $i=4$）：整段被压平到全局最小值，说明「峰越高越好」是错觉——答案取决于两侧被压低的总量，别急着把峰定在最大值处。
5. **传播方向别写反**：左侧必须**从峰向左**传播（$t[k] = \min(t[k{+}1], h[k])$），写成从左向峰会漏掉「远处的矮塔」对内侧的压制。
6. **合并时忘减峰值**：单调栈版 $left[i] + right[i] - h[i]$，峰被左右各算一次；忘记减会把答案抬高 $h[i]$（枚举传播版无此坑）。
7. **姊妹题赛时策略**：Q2/Q3 同题面只差 $n$——先读 Q3 再决定投入；若 Q2 已用 $O(n^2)$ 过了，Q3 只需换上单调栈版，两题共享 §5 的全部证明。
