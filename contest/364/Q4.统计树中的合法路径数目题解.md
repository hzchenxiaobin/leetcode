# LeetCode 统计树中的合法路径数目 题解

## 1. 题目概述

- **标题 / 题号**：统计树中的合法路径数目（#2867，hard）
- **链接**：https://leetcode.cn/problems/count-valid-paths-in-a-tree/
- **来源**：LeetCode 第 364 场周赛 Q4
- **难度**：困难
- **标签**：树、深度优先搜索、数学、数论（埃氏筛）、贡献法

**题意**：给一棵 $n$ 个节点的无向树，节点编号 $1 \sim n$。路径 $(a,b)$ 指从 $a$ 到 $b$ 的节点序列，序列中节点互不相同；$(a,b)$ 与 $(b,a)$ 算同一条路径。若路径上**恰好有一个**节点的编号是质数，则称该路径合法。求合法路径总数。

**约束**：

- $1 \le n \le 10^5$
- `edges.length == n − 1`，保证输入构成一棵合法的树

> 💡 赛场视角：本场 Q1–Q3 全是数组题（贪心 / 单调栈），Q4 切到树上计数，第一反应"枚举点对"会立刻被 $n = 10^5$ 劝退。破局点在于**换视角**：合法路径的定义自带一个分类锚点——"路径上那个唯一的质数"。每条合法路径恰属于一个质数，按质数分类后不重不漏，整道题坍缩成每个质数邻域上的**组合计数**。

输出：4
解释：合法路径 (1,2)、(1,3)、(1,4)、(2,4)，
      每条恰好含一个质数编号节点（2 或 3）。
```

**示例 2**

解释：合法路径 (1,2)、(1,4)、(2,4)（唯一质数 2），
      (1,3)、(1,6)、(3,6)（唯一质数 3）。
```

**示例 3（相邻质数）**

```text
输入：n = 3, edges = [[1,2],[2,3]]
输出：1
解释：仅 (1,2) 合法；(1,3) 与 (2,3) 都同时经过质数 2 和 3。
```

## 3. 解题思路

### 3.1 暴力思路：枚举点对，逐条检查

最朴素的做法：枚举所有点对 $(a,b)$（$a<b$），BFS 找到路径后数一遍质数个数。$n = 10^5$ 时点对约 $5 \times 10^9$ 个，仅枚举就不可行。即便用「根到节点的质数前缀计数 + LCA」把单次判断压到 $O(\log n)$：

$$\mathrm{cnt}_P(a,b) = c_a + c_b - 2\,c_{\mathrm{lca}} + \mathrm{isPrime}(\mathrm{lca})$$

总复杂度仍是 $O(n^2 \log n) \approx 10^{10}$ 量级，必然超时。瓶颈在于**把"质数个数"当成每条路径各自的属性、逐条验证**——必须反过来，让路径按质数**分类聚合**。

### 3.2 核心观察：按「路径上唯一的质数」分类

- **观察 1（分类不重不漏）**：每条合法路径上恰有一个质数 $p$，以 $p$ 为键分类，全体合法路径被划分成互不相交的类。
- **观察 2（删质数 → 孤岛）**：把所有质数节点从树上删掉，剩下的非质数节点裂成若干**连通块（孤岛）**。同一孤岛内任意两点间的路径不含任何质数；路径想碰到质数，必须"出岛"。
- **观察 3（合法路径的刻画）**：路径 $(a,b)$ 恰含一个质数 $p$，当且仅当 $a,b$ 落在组集合 $\{p\} \cup \{p \text{ 的邻接孤岛}\}$ 中**两个不同的组**（一组是 $p$ 自己，其余组是各个邻接孤岛）。于是每个质数的贡献就是纯粹的组合计数。

![核心概念：删掉质数节点，非质数节点裂成孤岛，合法路径按唯一质数分类](images/wc364_q4_prime_split_concept.svg)

设质数 $p$ 的邻接孤岛大小为 $s_1, s_2, \dots, s_k$，记 $S = \sum_i s_i$，则

$$\underbrace{S}_{(p,x)\text{ 对， } x \text{ 在某邻接孤岛}} \;+\; \underbrace{\sum_{i<j} s_i s_j}_{\text{两端在不同邻接孤岛}} \;=\; S + \frac{S^2 - \sum_i s_i^2}{2}$$

![星形分组计数：以质数 p 为中心的组合公式](images/wc364_q4_star_arms_counting.svg)

> ⚠️ 为什么枚举 $p$ 的邻居时**不用去重孤岛**？树无环保证每个孤岛与每个质数至多一条邻接边（否则成环，见 §5 引理 3），因此同一个孤岛在 $p$ 的邻居表里至多出现一次。

### 3.3 算法流程

![算法流程：筛质数 → 染孤岛 → 逐质数累加贡献](images/wc364_q4_algorithm_flow.svg)

1. **埃氏筛**：节点编号恰是 $1 \sim n$，一次筛出 `is_prime[1..n]`，$O(n \log\log n)$；注意 $1$ 不是质数。
2. **建邻接表**。
3. **孤岛染色**：在非质数节点上做 BFS（迭代），给每个连通块编号 `comp` 并统计大小 `sz`。
4. **逐质数累加**：对每个质数 $p$ 扫一遍邻居，跳过质数邻居；对非质数邻居 $w$ 累计 $S \mathrel{+}= sz[\mathrm{comp}[w]]$、$sq \mathrel{+}= sz^2$，然后答案累加 $S + (S^2 - sq)/2$。

### 3.4 示例演算

![示例 2 演算：三个质数各自邻接的孤岛与贡献](images/wc364_q4_example_walkthrough.svg)

对示例 2（$n=6$，质数 $2,3,5$，非质数 $1,4,6$ 各自成孤岛）逐质数计算：

| 质数 $p$ | 邻接孤岛（大小） | $S$ | 跨孤岛对 $\sum_{i<j} s_i s_j$ | $(p,x)$ 对 | 小计 |
|---|---|---|---|---|---|
| 2 | $\{1\},\{4\}$（1, 1） | 2 | $1$ | $2$ | $3$ |
| 3 | $\{1\},\{6\}$（1, 1） | 2 | $1$ | $2$ | $3$ |
| 5 | 邻居 3 是质数，无孤岛 | 0 | $0$ | $0$ | $0$ |

合计 $3+3+0 = 6$，对应路径 $(1,2),(2,4),(1,4)$（唯一质数 2）与 $(1,3),(3,6),(1,6)$（唯一质数 3）✓。注意质数 5 虽在树中，但唯一的邻居是质数 3——"两质数相接"的路径至少含两个质数，天然不合法。

## 4. 算法细节

1. **判定质数用筛、不用逐个试除**：编号范围恰为 $1 \sim n$，埃氏筛一次出全表 $O(n\log\log n)$；逐点试除是 $O(n\sqrt n) \approx 3 \times 10^7$，虽也能过但没有理由。
2. **孤岛染色必须迭代**：$n = 10^5$ 的链状树递归深度 $10^5$——Python 直接 `RecursionError`，C++ 默认栈也有溢出风险，用显式栈或 BFS。
3. **贡献公式的两种等价写法**：$S + (S^2 - \sum_i s_i^2)/2 = \sum_i s_i + \sum_{i<j} s_i s_j$。前者一边扫邻居一边累计 $S$ 与 $\sum_i s_i^2$ 即可，免两两配对；后者语义直白便于校验。由 $S^2 - \sum_i s_i^2 = 2\sum_{i<j}s_is_j$ 知整除恒无余数。
4. **64 位**：$S \le n = 10^5$，$S^2 \le 10^{10}$；答案上界约 $4.1 \times 10^9$（质数居中的菊花图，见 §8），超 `int32`。C++ 全程 `long long`，Python 原生大整数无忧。
5. **枚举量分析**：第 4 步只遍历**质数点**的邻接边，而全树的有向边共 $2(n-1)$ 条，故该步 $O(n)$；孤岛染色同样每点每边常数次。除筛法外全流程线性。

## 5. 正确性证明

约定 $\mathcal{P}$ 为 $[1,n]$ 内的质数集合。从树上删去 $\mathcal{P}$ 的所有节点后，剩余图的连通块称为**孤岛**；与孤岛 $B$ 有边相邻的质数称为 $B$ 的**门户质数**。先叙述一个树的基本事实：**树上两点间的路径唯一，且必含于任何包含这两点的连通子图中**（连通子图自身含有一条连接路径，而树中连接路径唯一）。

**引理 1（同岛 ⟺ 路径无质数）**：非质数节点 $a \ne b$ 属于同一孤岛，当且仅当路径 $(a,b)$ 不含任何质数。

**证明**：（⇒）孤岛是同时包含 $a,b$ 的连通子图，由基本事实，路径 $(a,b)$ 整体落在孤岛内，而孤岛内无质数。（⇐）若路径不含质数，则路径本身就是"删质数图"中连接 $a,b$ 的连通证据，故 $a,b$ 同属一个连通块。∎

**引理 2（合法路径的刻画）**：路径 $(a,b)$ 恰含一个质数 $p$，当且仅当 $a,b$ 属于组集合 $\{p\} \cup \mathcal{B}_p$ 中**两个不同的组**，其中 $\mathcal{B}_p$ 是 $p$ 的邻接孤岛全体。

**证明**：（⇒）路径上除 $p$ 外全是非质数。若 $a = p$（$b=p$ 对称）：$b$ 到 $p$ 的路径去掉 $p$ 后是一条全非质数的连通段，它把 $b$ 连到 $p$ 的某个邻居，故 $b$ 所在孤岛 $\in \mathcal{B}_p$，即 $a,b$ 分属 $\{p\}$ 与该孤岛两组。若 $a,b \ne p$：把路径去掉 $p$，得两段全非质数的连通段，同理 $a$ 所在孤岛与 $b$ 所在孤岛均 $\in \mathcal{B}_p$；两孤岛不同——若相同，该孤岛同时含 $a,b$，由引理 1 其间路径无质数，与树上路径唯一性矛盾（该路径本应经过 $p$）。（⇐）设 $a,b$ 属不同组。若一组为 $\{p\}$，设 $a = p$，$b \in B \in \mathcal{B}_p$：$B$ 与 $p$ 有邻接边 $p\!-\!v$（$v \in B$），$B$ 是含 $b,v$ 的连通子图，由基本事实 $b \rightsquigarrow v$ 全在 $B$ 内，拼上边 $v\!-\!p$ 得一条 $b$ 到 $p$ 的路径，由路径唯一性它**就是** $(b,p)$，其中仅 $p$ 一个质数。若两组均为孤岛 $B_i \ne B_j$：同理 $a \rightsquigarrow v_i \to p \to v_j \rightsquigarrow b$ 就是 $(a,b)$，仅含 $p$。∎

**引理 3（一岛一门）**：每个孤岛与每个质数至多有一条邻接边。

**证明**：若孤岛 $B$ 与质数 $p$ 之间有两条边 $p\!-\!u$ 与 $p\!-\!v$（$u,v \in B$），则 $B$ 内 $u$ 到 $v$ 的路径（由 $B$ 连通必存在）与边 $v\!-\!p$、$p\!-\!u$ 拼成环，与树无环矛盾。∎

**定理**：算法的返回值等于合法路径总数。

**证明**：每条合法路径恰含一个质数，以其为键，全体合法路径划分为互不相交的类 $C_p$，答案 $= \sum_p |C_p|$。由引理 2，$C_p$ 与"从 $\{p\} \cup \mathcal{B}_p$ 中选两个不同组、再各组内任取一点"的选取方式一一对应（两点确定唯一路径；不同组保证不退化为同一点）。组大小依次为 $1, s_1, \dots, s_k$，故

$$|C_p| = \sum_{i<j} t_i t_j = \frac{\Big(1+S\Big)^2 - \Big(1 + \sum_i s_i^2\Big)}{2} = S + \frac{S^2 - \sum_i s_i^2}{2},\qquad t = (1, s_1, \dots, s_k)$$

正是代码累加的式子。由引理 3，枚举 $p$ 的邻居时每个邻接孤岛恰被统计一次，$S$ 与 $\sum_i s_i^2$ 不重不漏；BFS 染色给出孤岛的正确划分（连通块定义使然）。故算法输出 $= \sum_p |C_p|$，即合法路径总数。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \log\log n)$。埃氏筛 $O(n\log\log n)$；建邻接表、孤岛染色（每点每边常数次）、质数邻居扫描（全体质点的邻接边之和 $\le 2(n-1)$）均为 $O(n)$。瓶颈在筛法，$n = 10^5$ 下毫秒级。
- **空间复杂度**：$O(n)$。邻接表 $2(n-1)$ 条有向边 + `is_prime` / `comp` / `sz` 三个线性数组 + 迭代栈。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    long long countPaths(int n, vector<vector<int>>& edges) {
        if (n == 1) return 0;

        vector<bool> isPrime(n + 1, true);          // 埃氏筛：编号恰是 1..n
        isPrime[0] = isPrime[1] = false;
        for (int i = 2; 1LL * i * i <= n; i++)
            if (isPrime[i])
                for (int j = i * i; j <= n; j += i) isPrime[j] = false;

        vector<vector<int>> adj(n + 1);
        for (auto& e : edges) {
            adj[e[0]].push_back(e[1]);
            adj[e[1]].push_back(e[0]);
        }

        vector<int> comp(n + 1, -1);                // 非质数节点 → 孤岛编号
        vector<long long> sz;                       // 每个孤岛的大小
        vector<int> stk;                            // 显式栈，防链状树递归爆栈
        for (int s = 1; s <= n; s++) {
            if (isPrime[s] || comp[s] != -1) continue;
            int cid = sz.size();
            stk.push_back(s);
            comp[s] = cid;
            long long cnt = 0;
            while (!stk.empty()) {
                int u = stk.back(); stk.pop_back();
                cnt++;
                for (int w : adj[u])
                    if (!isPrime[w] && comp[w] == -1) {
                        comp[w] = cid;
                        stk.push_back(w);
                    }
            }
            sz.push_back(cnt);
        }

        long long ans = 0;
        for (int p = 2; p <= n; p++) {
            if (!isPrime[p]) continue;
            long long S = 0, sq = 0;                // S = Σsᵢ，sq = Σsᵢ²
            for (int w : adj[p])
                if (!isPrime[w]) {
                    S += sz[comp[w]];
                    sq += sz[comp[w]] * sz[comp[w]];
                }
            ans += S + (S * S - sq) / 2;            // (p,x) 对 + 跨孤岛对
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def countPaths(self, n: int, edges: List[List[int]]) -> int:
        if n == 1:
            return 0

        is_prime = [False, False] + [True] * (n - 1)   # 埃氏筛，注意 1 非质数
        for i in range(2, int(n ** 0.5) + 1):
            if is_prime[i]:
                for j in range(i * i, n + 1, i):
                    is_prime[j] = False

        adj = [[] for _ in range(n + 1)]
        for u, v in edges:
            adj[u].append(v)
            adj[v].append(u)

        comp = [-1] * (n + 1)                          # 非质数节点 → 孤岛编号
        sz = []                                        # 每个孤岛的大小
        for s in range(1, n + 1):
            if is_prime[s] or comp[s] != -1:
                continue
            cid = len(sz)
            stack = [s]                                # 显式栈，防递归爆栈
            comp[s] = cid
            cnt = 0
            while stack:
                u = stack.pop()
                cnt += 1
                for w in adj[u]:
                    if not is_prime[w] and comp[w] == -1:
                        comp[w] = cid
                        stack.append(w)
            sz.append(cnt)

        ans = 0
        for p in range(2, n + 1):                      # 每个质数独立累加贡献
            if not is_prime[p]:
                continue
            S = sq = 0
            for w in adj[p]:
                if not is_prime[w]:
                    S += sz[comp[w]]
                    sq += sz[comp[w]] * sz[comp[w]]
            ans += S + (S * S - sq) // 2
        return ans
```

> 💡 两版已与「枚举全点对 + BFS 找路径数质数」的 $O(n^3)$ 暴力在 600 组随机树（$n \le 40$）、链 / 菊花 / 相邻质数等结构化用例及官方示例下对拍一致；$n = 10^5$ 的链与菊花实测 Python 约 0.2 s。

## 8. 边界情况与易错点

1. **64 位溢出**：$S^2$ 最大 $10^{10}$；答案上界约 $4.1 \times 10^9$（质数 2 居中的菊花图：约 $9 \times 10^4$ 个非质数叶子，$\binom{9\times10^4}{2} \approx 4 \times 10^9$），超 `int32` 上限 $2.1 \times 10^9$。C++ 中 `S`、`sq`、`sz`、`ans` 全用 `long long`。
2. **1 不是质数**：埃氏筛显式置 `is_prime[1] = false`。误判会凭空多出"以 1 为唯一质数"的整类假路径。
3. **单点路径不计数**：$(a,a)$ 不算合法路径——示例 1 中若把质数 2、3、5 的单点计入，答案会从 4 变成 7。组合公式里"选两个不同组、组内取**不同**点"天然排除了它。
4. **递归爆栈**：$n = 10^5$ 的链上递归 DFS 深度 $10^5$，Python 报 `RecursionError`，C++ 默认栈同样危险——孤岛染色必须迭代。
5. **相邻质数**：边两端都是质数（示例 3 的 2–3、示例 2 的 3–5）时，跨过这条边的路径至少含两个质数；算法中"跳过质数邻居"自动处理，无需特判。
6. **别把无序对算成有序对**：$(a,b)$ 与 $(b,a)$ 同一条；公式 $\sum_{i<j}$ / $(S^2 - \sum s_i^2)/2$ 天然无序。若改用有序对思路记得除 2。
7. **除法整除性**：$S^2 - \sum_i s_i^2 = 2\sum_{i<j} s_i s_j$ 恒为偶数，C++ 整数除法无余数风险；Python 用 `//` 防浮点误差。
8. **不用对邻接孤岛去重**：树无环保证一岛一门（§5 引理 3），直接累加即可；加 `set` 去重不出错但纯属多余。
9. **$n = 1$**：无边，节点 1 非质数且单点不计，答案 0（代码直接返回）。

**延伸思考**：

- **一般化到"恰好 $k$ 个特殊节点"**：$k=1$ 时"删点成岛"的分组计数是独占红利——路径上只有一个特殊点，才能把它当"锚"分类。$k \ge 2$ 时应改用**树形 DP**：`dfs(u)` 返回向量 $(c_0, c_1, \dots, c_k)$（自 $u$ 向下延伸、含 $j$ 个特殊点的路径条数），逐个子树合并时按"左边 $i$ 个 × 右边 $k-i$ 个"配对累加，$u$ 自身是特殊点则整体右移一位，复杂度 $O(nk)$。$k=1$ 时它在特殊点处合并出的正是本文的 $S + \sum_{i<j} s_i s_j$——两种解法是同一公式的两种推导路径。
- **若改问"合法路径的总长度"**：分组结构不变，把"点对计数"升级为"点对距离和"——对每个孤岛额外维护"到门户边的距离和"（自底向上子树和 + 换根），即经典的 up/down 双向分解。
