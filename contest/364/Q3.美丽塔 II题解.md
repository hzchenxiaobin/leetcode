# LeetCode 美丽塔 II 题解

## 1. 题目概述

- **标题 / 题号**：美丽塔 II（#2866，medium）
- **链接**：https://leetcode.cn/problems/beautiful-towers-ii/
- **来源**：LeetCode 第 364 场周赛 Q3
- **难度**：中等
- **标签**：单调栈、栈、数组、动态规划

**题意**：给定长度为 $n$ 的数组 $maxHeights$，为下标 $i$ 的塔选定高度 $heights[i]$，需满足 $1 \le heights[i] \le maxHeights[i]$，且 $heights$ 呈**山脉状**——存在某个下标，使左侧非递减、右侧非递增（峰可在任意位置，也允许是一段连续相等的塔）。求所有合法方案中 $heights$ **总和的最大值**。

**约束**：

- $1 \le n = maxHeights.length \le 10^5$
- $1 \le maxHeights[i] \le 10^9$

> 💡 赛场视角：与同场 Q2（[2865. 美丽塔 I](https://leetcode.cn/problems/beautiful-towers-i/)，$n \le 10^3$）**题面一字不差**，唯一区别是 $n$ 放大到 $10^5$——Q2 的 $O(n^2)$「枚举峰 + 双向传播」在此约 $10^{10}$ 次运算必然超时，必须把「逐格传播」升级为「分段压平」的**单调栈 $O(n)$**。赛时最短路径有两条：Q2 已用 $O(n^2)$ 拿分后，本题给同一骨架换上单调栈引擎；或直接写单调栈版，一份代码通吃两题。本题另有[每日题解 2866](../../solution/2801-2900/2866_美丽塔II.md)：与本文互为印证，其表格演算与面试问答式展开更详细；本文侧重**优化路径的发现（增量视角）、压平递推的严谨证明、弹栈条件两种写法的辨析与赛场决策**。

## 3. 解题思路

### 3.1 起点：Q2 的 O(n²) 骨架在本题撞墙

[Q2 题解](Q2.美丽塔%20I题解.md)已确立「**枚举峰 $i$ + 两侧独立**」骨架：峰固定后，最优形态唯一——每座塔垫到约束允许的最高（$h = maxHeights$）：

$$t[i] = h[i],\qquad t[k] = \min(h[k..i])\ (k < i),\qquad t[k] = \min(h[i..k])\ (k > i)$$

每峰向两侧各传播一趟 $\min$，总计 $O(n^2)$。$n = 10^3$ 时约 $10^6$ 次 `min` 毫秒级通过；$n = 10^5$ 时约 $10^{10}$ 次——常数再小也救不回来，**必须结构性消除重复计算**。

### 3.2 核心观察：峰移动时的「增量」—— 分段压平 + 形态继承

![核心概念：分段压平与形态继承，left 递推](images/wc364_q3_flatten_segment_recurrence.svg)

- **观察 1（浪费在哪）**：比较峰 $i$ 与峰 $i{+}1$ 的左侧形态：$t_{i+1}[k] = \min(h[k..i{+}1]) = \min\big(t_i[k],\ h[i{+}1]\big)$。新形态只是旧形态被 $h[i{+}1]$ 整体夹了一次——由于 $t_i$ 向峰非递减，被压低的位置是一段**连续后缀**，其余位置**一字不动**。$O(n^2)$ 却把整段重算，浪费正在于此。
- **观察 2（继承 + 压平）**：设 $j$ 为 $i$ 左侧第一个满足 $h[j] \le h[i]$ 的下标，则峰取 $i$ 时：$(j, i]$ 内所有塔被压平成 $h[i]$（这些位置的上限全部 $> h[i]$，区间 $\min$ 被 $h[i]$ 卡死）；$[0..j]$ 内的形态与**峰取 $j$ 时完全一致**（$h[j] \le h[i]$ 挡住了峰的压制）。记 $L_i$ 为峰取 $i$ 时前缀 $[0..i]$ 的最优和，则
  $$L_i = L_j + h[i] \times (i - j)$$
  $j$ 不存在（左侧全部 $> h[i]$）时整段压平：$L_i = h[i] \times (i{+}1)$。
- **观察 3（$j$ 的求取是单调栈本职）**：所有还有机会被继承的「子峰」下标，其 $h$ 值构成**非递减序列**——处理 $i$ 时，栈顶所有 $h > h[i]$ 的下标从此再无被继承的机会，弹出；栈顶剩下的就是 $j$。每个下标至多进栈、出栈一次，求 $j$ 摊还 $O(1)$。

### 3.3 算法流程：两遍单调栈 + 一次合并

![算法流程：两遍单调栈扫描与合并](images/wc364_q3_algorithm_flow.svg)

1. **正向扫描** $i = 0 \to n{-}1$：弹掉栈顶所有 $h[\cdot] > h[i]$ 的下标，取 $j = $ 栈顶（空则哨兵 $-1$），$left[i] = left[j] + h[i] \times (i - j)$，然后 $i$ 入栈；
2. **反向扫描** $i = n{-}1 \to 0$：完全对称地求 $right[i]$（$j$ 为右侧第一个 $\le$，空则哨兵 $n$，段长为 $j - i$）；
3. **合并**：$ans = \max_i \big(left[i] + right[i] - h[i]\big)$——峰 $h[i]$ 在左右两侧各被计一次，须减去一份。

### 3.4 示例演算

![示例 2 的单调栈演算：栈状态演化与 left 递推](images/wc364_q3_example_walkthrough.svg)

以示例 2 $h = [6,5,3,9,2,7]$ 演算 $left$（栈存下标、栈内 $h$ 值非递减）：

| $i$ | $h[i]$ | 弹栈动作 | $j$ | $left[i]$ |
|-----|--------|----------|-----|-----------|
| 0 | 6 | （栈空） | $-1$ | $6 \times 1 = 6$ |
| 1 | 5 | 弹 6 | $-1$ | $5 \times 2 = 10$ |
| 2 | 3 | 弹 5 | $-1$ | $3 \times 3 = 9$ |
| 3 | 9 | $3 < 9$ 不弹 | 2 | $9 + 9 \times 1 = 18$ |
| 4 | 2 | 弹 9、3 | $-1$ | $2 \times 5 = 10$ |
| 5 | 7 | $2 < 7$ 不弹 | 4 | $10 + 7 \times 1 = 17$ |

反向对称得 $right = [21, 15, 10, 13, 4, 7]$，合并 $left[i] + right[i] - h[i]$：

| $i$ | 0 | 1 | 2 | 3 | 4 | 5 |
|-----|---|---|---|---|---|---|
| 合并值 | 21 | 20 | 16 | **22** | 12 | 17 |

最大值 $22$ 在 $i = 3$，对应塔形 $[3,3,3,9,2,2]$ ✓。注意 $i = 4$：左侧没有任何 $h \le 2$，触发哨兵整段压平——「峰越高越好」是错觉，答案取决于两侧被压低的**牺牲总量**。

## 4. 算法细节

1. **只存和、不存形态**：递推只需 $left[j]$ 一个历史数值，「形态继承」落实为 $O(1)$ 的数值复用，无需显式保存每座塔高；赛后要重建方案时，从 $\arg\max$ 的峰向两侧传播一遍即可（见「延伸思考」）。
2. **栈存下标而非高度**：递推需要 $j$ 的**位置**（算段长 $i - j$）与 $left[j]$（查表），高度只是弹栈判据——存高度会同时丢掉这两样。
3. **哨兵统一公式**：$j$ 不存在时取 $-1$（左）/$ n$（右），此时 $left[j]$ 项取 $0$、段长恰好覆盖整个前缀/后缀，递推无需分支特判。
4. **弹栈条件两种写法都对，但语义不同**：本文用**严格大于**弹栈（$j$ = 左侧第一个 $h \le h[i]$），与 [Q2 题解](Q2.美丽塔%20I题解.md) §5 引理 3 配套；[每日题解 2866](../../solution/2801-2900/2866_美丽塔II.md) 用 $\ge$ 弹栈（$j$ = 左侧第一个 $h < h[i]$），分段方式不同、各自「不重不漏」（§5 引理 2 与引理 3 分别给出配套证明）。**关键是自己写的弹栈条件必须与证明里的 $j$ 语义配套**，调试时两套混改是常见翻车点。
5. **全程 64 位**：$10^5 \times 10^9 = 10^{14}$，超 `int32` 七个数量级；C++ 中 `left` / `right` 直接声明 `long long`，乘法前 `1LL *` 转型（官方签名返回 `long long`）。Python 原生大整数无此顾虑。
6. **对拍验证**：用 Q2 的 $O(n^2)$ 传播版做基准，随机 $n \le 10^3$、$h \le 10^9$ 对拍数百组；再补全相等、单调、单谷等结构化用例，专门打相等链（本文代码已按此验证，见 §7 末尾）。

## 5. 正确性证明

约定 $h = maxHeights$，$t$ 为最终塔高方案，并定义
$$L_i = \sum_{k=0}^{i} \min(h[k..i])\ (L_{-1} = 0),\qquad R_i = \sum_{k=i}^{n-1} \min(h[i..k])\ (R_n = 0).$$

**引理 1（固定峰的最优形态）**：峰取 $i$ 时，唯一最优方案为 $t^*[i] = h[i]$、$t^*[k] = \min(h[k..i])$（$k < i$）、$t^*[k] = \min(h[i..k])$（$k > i$），其和为 $L_i + R_i - h[i]$。

**证明**：$t^*$ 对「左非递减、右非递增、逐塔不超上限」的任一可行方案**逐塔支配**：$k < i$ 时非递减与上限夹出 $t[k] \le \min_{j \in [k,i]} h[j] = t^*[k]$，$k = i$、$k > i$ 同理；且 $t^*$ 自身可行（区间 $\min$ 随靠近峰单调不降）。逐塔求和即得，等号仅当 $t = t^*$。完整叙述见 [Q2 题解](Q2.美丽塔%20I题解.md) §5 引理 1–2。∎

**引理 2（分段压平递推，$>$ 弹栈配套）**：设 $j$ 为 $i$ 左侧第一个满足 $h[j] \le h[i]$ 的下标（不存在则 $j = -1$），则 $L_i = L_j + h[i] \times (i - j)$。

**证明**：$j = -1$ 时 $[0..i)$ 内元素全部 $> h[i]$，故每项 $\min(h[k..i]) = h[i]$，共 $i{+}1$ 项，$L_i = h[i] \times (i{+}1) = L_{-1} + h[i] \times (i{+}1)$，公式成立。$j \ge 0$ 时分两段：(a) $k \in (j, i]$：$[k..i] \subseteq (j..i]$，其中除 $h[i]$ 外的元素全部 $> h[i]$（$j$ 是**第一个** $\le$），故 $\min(h[k..i]) = h[i]$，共 $i - j$ 项、合计 $h[i] \times (i - j)$；(b) $k \le j$：
$$\min(h[k..i]) = \min\big(\min(h[k..j]),\ \min(h[j{+}1..i])\big) = \min\big(\min(h[k..j]),\ h[i]\big) = \min(h[k..j])$$
末步因 $\min(h[k..j]) \le h[j] \le h[i]$——恰为 $L_j$ 的第 $k$ 项。两段相加即得。∎

**引理 3（弹栈条件 $\ge$ 亦正确）**：若改弹所有 $h[\cdot] \ge h[i]$（$j'$ 为左侧第一个 $h[j'] < h[i]$），递推 $L_i = L_{j'} + h[i] \times (i - j')$ 同样成立。

**证明**：仿引理 2。(a) $k \in (j', i]$：$(j', i)$ 内元素全部 $\ge h[i]$ 且峰为 $h[i]$，故 $\min(h[k..i]) = h[i]$，共 $i - j'$ 项；(b) $k \le j'$：$\min(h[k..i]) = \min\big(\min(h[k..j']),\ h[i]\big) = \min(h[k..j'])$，末步因 $\min(h[k..j']) \le h[j'] < h[i]$。∎

> 💡 两种分段对同一 $L_i$ 给出**相同数值、不同划分**：$>$ 弹栈把相等链整体留给最长压平段，$\ge$ 弹栈把相等者各自成段。正如「按 $\le$ 继承」与「按 $<$ 继承」都能不重不漏地覆盖全段——这是单调栈 DP 的常见自由度（907、1944 同款），写代码前固定一种 $j$ 语义即可。

**定理**：单调栈算法返回 $\max_{0 \le i < n} \big(L_i + R_i - h[i]\big)$，即题目所求的最大高度和，且总时间为 $O(n)$。

**证明**：山脉方案集按「峰在谁家」划分为 $n$ 类 $C_i$（[Q2 题解](Q2.美丽塔%20I题解.md) §5 引理 1）；由引理 1，第 $i$ 类的最大和为 $L_i + R_i - h[i]$，故全局最优即其最大值。再证算法确实算出每个 $L_i$：对 $i$ 归纳——处理 $i$ 时 $left[j]$ 已算出（$j < i$）；栈中下标按处理顺序排列、$h$ 值非递减（入栈前弹掉了所有更大者），且 $i$ 左侧第一个 $h \le h[i]$ 的下标 $k$ 必在栈中（中间元素 $h$ 均 $> h[i] \ge h[k]$，弹不掉它），其上方的栈元素全部落在 $(k, i)$ 内且 $h > h[i]$，被本次尽数弹出，故弹栈后栈顶恰为 $k$；由引理 2，$left[i] = L_i$。$right$ 对称。合并即返回最大值。每个下标至多入栈、出栈一次，三趟扫描均为线性。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。三趟线性扫描；单调栈部分由势能法，总弹出次数不超过总入栈次数 $n$，单次 `while` 摊还 $O(1)$。实测 $n = 10^5$ 毫秒级（见 §7 末尾）。
- **空间复杂度**：$O(n)$。`left` / `right` 两个 64 位数组 + 下标栈。Q2 的传播版只用 $O(1)$ 额外空间但时间是 $O(n^2)$——本题用空间换时间，是姊妹题数据范围倒逼的标准交换。
- **对比 Q2**：同一骨架在 $n \le 10^3$ 用 $O(n^2)$ / $O(1)$ 最快写完，在 $n \le 10^5$ 必须换 $O(n)$ / $O(n)$——「复杂度预算」由数据范围唯一决定，这正是 I/II 姊妹题编排的训练价值。

## 7. 参考代码

### C++（单调栈 $O(n)$，赛时主推）

```cpp
class Solution {
  public:
    long long maximumSumOfHeights(vector<int>& maxHeights) {
        int n = maxHeights.size();
        vector<long long> left(n), right(n);
        vector<int> stk;                              // 存下标，栈内 h 非递减
        for (int i = 0; i < n; i++) {                  // left[i]：以 i 为峰的前缀最优和
            while (!stk.empty() && maxHeights[stk.back()] > maxHeights[i])
                stk.pop_back();                        // 弹掉所有 > h[i]，栈顶 = 左侧第一个 <= h[i]
            int j = stk.empty() ? -1 : stk.back();
            left[i] = (j < 0 ? 0 : left[j]) + 1LL * maxHeights[i] * (i - j);
            stk.push_back(i);
        }
        stk.clear();
        for (int i = n - 1; i >= 0; i--) {             // right[i]：以 i 为峰的后缀最优和
            while (!stk.empty() && maxHeights[stk.back()] > maxHeights[i])
                stk.pop_back();
            int j = stk.empty() ? n : stk.back();      // 右侧第一个 <= h[i]
            right[i] = (j == n ? 0 : right[j]) + 1LL * maxHeights[i] * (j - i);
            stk.push_back(i);
        }
        long long ans = 0;
        for (int i = 0; i < n; i++)
            ans = max(ans, left[i] + right[i] - maxHeights[i]);  // 峰被 L、R 各计一次
        return ans;
    }
};
```

### Python（单调栈 $O(n)$）

```python
class Solution:
    def maximumSumOfHeights(self, maxHeights: List[int]) -> int:
        n = len(maxHeights)
        left, right = [0] * n, [0] * n
        stk = []                                       # 存下标，栈内 h 非递减
        for i, h in enumerate(maxHeights):             # left[i]：以 i 为峰的前缀最优和
            while stk and maxHeights[stk[-1]] > h:
                stk.pop()                              # 栈顶 = 左侧第一个 <= h[i]
            j = stk[-1] if stk else -1
            left[i] = (left[j] if j >= 0 else 0) + h * (i - j)
            stk.append(i)
        stk = []
        for i in range(n - 1, -1, -1):                 # right[i]：以 i 为峰的后缀最优和
            h = maxHeights[i]
            while stk and maxHeights[stk[-1]] > h:
                stk.pop()
            j = stk[-1] if stk else n                  # 右侧第一个 <= h[i]
            right[i] = (right[j] if j < n else 0) + h * (j - i)
            stk.append(i)
        return max(l + r - h for l, r, h in zip(left, right, maxHeights))
```

> 💡 两版已与 Q2 的 $O(n^2)$ 传播版在 500 组随机数据（$n \le 10^3$、$h \le 10^9$）、300 组 $n \le 5$ 真暴力（全枚举每座塔高度）及全相等 / 单调 / 单谷结构用例下对拍一致，`>` 与 `>=` 两种弹栈写法亦互拍一致，三个官方示例全部通过；$n = 10^5$ 实测约 74 ms（Python）。本代码原样可交 Q2。

## 8. 边界情况与易错点

1. **64 位溢出**：$10^5 \times 10^9 = 10^{14}$，`int` 必爆；C++ 乘法前 `1LL *` 转型、和数组声明 `long long`。
2. **合并忘减峰值**：$left[i] + right[i] - h[i]$；峰被左右各计一次，忘减会把每个候选答案整体抬高 $h[i]$。
3. **弹栈条件与 $j$ 语义不配套**：`>` 弹栈 → $j$ 是左侧首个 $h \le h[i]$；`>=` 弹栈 → 首个 $h < h[i]$。两套各自正确（§5 引理 2/3），混着改必错；相等链（示例 3 的 `[5,5]`）是最敏感的检错用例。
4. **栈存下标**：存高度会丢掉段长 $i - j$ 与 $left[j]$ 的查询能力。
5. **反向扫描段长方向**：右侧递推段长是 $j - i$（$j$ 在右边），照抄正向的 $i - j$ 会得到负数；两遍扫描里 $j$ 的哨兵也不同（$-1$ vs $n$）。
6. **峰在两端 / $n = 1$**：一侧栈空触发哨兵，公式自然成立，无需特判；$n=1$ 时答案是 $h[0]$。
7. **连续相等峰**（示例 3）：$i = 2$ 与 $i = 3$ 都达到最优 $18$，`max` 天然覆盖，无需去重——这也是弹栈条件敢保留相等元素的原因（引理 2 的 $h[j] \le h[i]$ 含相等）。
8. **别把 Q2 的 $O(n^2)$ 直接交上来**：$n = 10^5$ 约 $10^{10}$ 次运算必超时——姊妹题先确认只差数据范围，再决定复用哪一版代码。

**延伸思考**：若要**输出方案本身**，只需记录 $\arg\max$ 的峰 $i^*$，再从 $i^*$ 向两侧逐格传播 $\min$（Q2 的传播式）即可 $O(n)$ 重建塔形——「数值递推求答案、传播式重建方案」是此类前后缀分解 DP 的标准分工。更进一步，把 $L_i$ 放到 907 的视角下看：$L_i$ 恰是「所有以 $i$ 为右端点的子数组最小值之和」，本题本质是在这个量上再取 $\max$——两题共享同一副单调栈递推骨架，只是统计的目标不同，掌握其一即可横扫另一。
