# LeetCode 交替位二进制数 题解

## 1. 题目概述

- **标题 / 题号**：交替位二进制数（#693，easy）
- **链接**：https://leetcode.cn/problems/binary-number-with-alternating-bits/
- **来源**：LeetCode 第 53 场周赛 Q1
- **难度**：简单
- **标签**：位运算

**题意**：给定正整数 $n$，判断它的二进制表示中**是否每一对相邻位都不同**。若整串二进制形如 `1`、`10`、`101`、`1010`、`10101`，返回 `true`；只要存在一处相邻两位相同（`11` 或 `00`）就返回 `false`。对首位、末位的具体取值没有额外要求。

**约束**：

- $1 \le n \le 2^{31} - 1$，即二进制位长 $k \in [1, 31]$
- 单次调用，只有一个参数 $n$，无多组数据、无取模

> 💡 数据极小（最多 31 位），逐位扫描也能过；本题真正的价值是提炼出「用异或把相邻位折叠成一位」这条 $O(1)$ 位运算模板。

## 2. 示例

**示例 1**

```text
输入：n = 5
输出：true
解释：5 的二进制是 101，相邻的 (1,0)、(0,1) 都不同。
```

**示例 2**

```text
输入：n = 7
输出：false
解释：7 的二进制是 111，最高两位都是 1。
```

**示例 3**

```text
输入：n = 11
输出：false
解释：11 的二进制是 1011，末两位都是 1。
```

## 3. 解题思路

### 3.1 暴力思路

把 $n$ 转成二进制串（`bin(n)[2:]` 或手写取位），从头到尾比较每对相邻字符，一旦相同立即返回 `false`。时间 $O(\log n)$、空间 $O(\log n)$；位长最多 31，常数开销可以忽略，**完全能过**。

另一种「暴力」是枚举所有交替数：位长 $k$ 的交替数唯一（以 1 开头的 `1010…`），一共只有 31 个，预处理成哈希集后 $O(1)$ 查询。这条路同样正确，但要硬编码或预生成 31 个常数，且对「$n$ 是否恰好等于其中某个值」的判断依赖枚举范围，不如直接推导公式优雅。

真正值得复盘的是：把「相邻位是否不同」这个**逐位条件整体压成一次整数运算**，写法只有两行，而且完全不依赖位长 $k$。

### 3.2 核心观察：异或折叠相邻位

![把相邻位折叠成异或：交替位变全 1](images/wc53_q1_xor_fold_concept.svg)

设 $n$ 的位长为 $k$，写成 $n = (n_{k-1}n_{k-2}\cdots n_0)_2$，最高位 $n_{k-1} = 1$。令

$$x = n \oplus (n \gg 1)$$

右移一位后，第 $i$ 位变成了 $n_{i+1}$（越界的高位补 $0$），所以

$$x_i = n_i \oplus n_{i+1}\ (0 \le i \le k-2), \qquad x_{k-1} = n_{k-1} \oplus 0 = 1$$

也就是说，**$x$ 的第 $i$ 位恰好回答「原数第 $i$ 位与第 $i+1$ 位是否不同」**：不同则 $x_i = 1$，相同则 $x_i = 0$。

于是得到本题的核心等价关系：

$$\text{二进制交替} \iff x \text{ 的低 } k \text{ 位全为 } 1 \iff x = 2^k - 1$$

以 $n = 21 = 10101_2$ 为例：$n \gg 1 = 01010_2$，异或得 $11111_2 = 2^5 - 1$，判定为交替；而 $n = 11 = 1011_2$ 异或得 $1110_2$，末位还是 $0$，不是全 $1$，判定失败。

### 3.3 算法流程：全 1 判定

![两行判定流程与溢出陷阱](images/wc53_q1_algorithm_flow.svg)

剩下的问题是「$x$ 是否全 $1$」。不必求位长 $k$ 再和 $2^k-1$ 比较，用一条经典恒等式即可：

$$x \text{ 全 } 1 \iff x \,\&\, (x+1) = 0$$

直觉：$2^k-1$ 加一会一路进位变成 $10\cdots0_2$，与原数没有任何公共的 $1$ 位；反之只要 $x$ 中某个 $0$ 位之上还留着 $1$，与运算就必然残留非零位。

流程只有三步：

1. $x \leftarrow n \oplus (n \gg 1)$，用 64 位整数保存；
2. 计算 $x \,\&\, (x+1)$；
3. 结果为 $0$ 返回 `true`，否则返回 `false`。

### 3.4 示例演算

![演算表：x 是否全 1](images/wc53_q1_walkthrough_table.svg)

| $n$ | 二进制 | $x = n \oplus (n\gg1)$ | $x+1$ | $x \,\&\, (x+1)$ | 返回 |
|----:|:------:|:----------------------:|:-----:|:----------------:|:----:|
| 1 | `1` | `1` | 2 | 0 | true |
| 5 | `101` | `111` | 8 | 0 | true |
| 10 | `1010` | `1111` | 16 | 0 | true |
| 21 | `10101` | `11111` | 32 | 0 | true |
| 7 | `111` | `100` | 5 | 4 | false |
| 11 | `1011` | `1110` | 15 | 14 | false |

前四行 $x$ 恰好是 $2^k-1$，$x+1$ 是 2 的幂，与运算清零；后两行 $x$ 中含 $0$，$x+1$ 只是把最低的 $0$ 变成 $1$，与运算仍残留非零位。

## 4. 算法细节

1. **必须用 64 位整型**。$n \le 2^{31}-1$ 时 $n \oplus (n\gg1) \le 2^{31}-1$；当 $n = \texttt{0x55555555}$（最大的交替数）时 $x = \texttt{0x7FFFFFFF}$，$x+1 = 2^{31}$ 超出 `int` 表示范围，在 C++ 中是**有符号溢出（UB）**。写成 `long long x = (long long)n ^ ((long long)n >> 1);` 最稳妥。
2. **`>>` 在正数上无歧义**。题目保证 $n \ge 1$，算术右移与逻辑右移结果一致，不必先转 `unsigned` 再移位。
3. **`unsigned int` 也能救场**。无符号溢出是定义良好的回绕：`0x7FFFFFFF + 1` 变成 `0x80000000`，两者相与仍为 $0$，结论正确；但可读性不如 64 位，面试/比赛中推荐 64 位。
4. **不要用 $n \,\&\, (n \gg 1) = 0$ 判定**。它只说明「没有相邻的两个 1」，对连续 0 无能为力：$n = 4 = 100_2$ 满足该式，却显然不是交替数。
5. **不必求位长**。用 `__builtin_clz` / `bit_length` 求 $k$ 再比 $2^k-1$ 也正确，但多一次分支和边界（$k = 31$ 时 $1 \ll 31$ 在 `int` 上越界），`x & (x+1)` 没有这些问题。
6. **Python 无需担心溢出**。大整数天然任意精度，两行即可；`bin()` 字符串法只是可读性偏好，不是必需。
7. **接口只有 $n$ 一个参数**。按 `metaData`，函数签名为 `bool hasAlternatingBits(int n)`，不要额外引入输入缓冲或全局状态变量。

## 5. 正确性证明

**引理 1（折叠引理）**：设 $n \ge 1$ 位长为 $k$，$x = n \oplus (n \gg 1)$，则对 $0 \le i \le k-2$ 有 $x_i = n_i \oplus n_{i+1}$；且 $x_{k-1} = 1$，而当 $i \ge k$ 时 $x_i = 0$。

**证明**：$(n \gg 1)$ 的第 $i$ 位定义为 $n_{i+1}$，其中 $i+1 \ge k$ 时该位为 $0$（右移补零）。异或按位独立，故 $x_i = n_i \oplus n_{i+1}$。取 $i = k-1$，因最高位 $n_{k-1} = 1$，得 $x_{k-1} = 1 \oplus 0 = 1$。取 $i \ge k$，有 $n_i = n_{i+1} = 0$，故 $x_i = 0$。∎

**引理 2（交替 $\iff$ 全 1）**：$n$ 的二进制表示相邻位互不相同 $\iff$ $x = 2^k - 1$。

**证明**：
($\Rightarrow$) 若相邻位互不相同，则每个 $0 \le i \le k-2$ 都有 $n_i \ne n_{i+1}$，即 $x_i = 1$；加上引理 1 给出的 $x_{k-1} = 1$，低 $k$ 位全为 $1$、高位全为 $0$，故 $x = 2^k-1$。
($\Leftarrow$) 若 $x = 2^k-1$，则 $x_i = 1$ 对所有 $0 \le i \le k-1$ 成立。特别地，$i \le k-2$ 时 $n_i \oplus n_{i+1} = 1$，即 $n_i \ne n_{i+1}$，相邻位互不相同。∎

**引理 3（全 1 判定）**：对任意非负整数 $x$，$x \,\&\, (x+1) = 0 \iff$ 存在 $j \ge 0$ 使 $x = 2^j - 1$。

**证明**：
($\Leftarrow$) $x = 2^j-1$ 的第 $0 \sim j-1$ 位全为 $1$、其余为 $0$；$x+1 = 2^j$ 只有第 $j$ 位为 $1$。两者没有公共的 $1$ 位，与为 $0$。
($\Rightarrow$) 若 $x = 0$，取 $j = 0$ 即 $x = 2^0-1$；若 $x$ 的二进制全为 $1$，则 $x = 2^w-1$（$w$ 为位长），结论成立。否则令 $j$ 为 $x$ 中最低的 $0$ 位下标，此时 $x$ 的低 $j$ 位全为 $1$、第 $j$ 位为 $0$。加 $1$ 后低 $j$ 位进位清零、第 $j$ 位置 $1$、$j$ 以上各位不变。于是 $x \,\&\, (x+1)$ 在低 $j$ 位为 $1 \& 0 = 0$，在第 $j$ 位为 $0 \& 1 = 0$，在 $j$ 以上等于 $x$ 的对应位。若整个与为 $0$，则 $x$ 在 $j$ 以上全为 $0$，故 $x = 2^j-1$。∎

**定理**：`hasAlternatingBits(n)` 返回 `true` 当且仅当 $n$ 的二进制表示相邻位互不相同。

**证明**：算法返回 `true` $\iff x \,\&\, (x+1) = 0$。由引理 3，这等价于 $x = 2^j-1$；由引理 1，$x$ 的最高置位是第 $k-1$ 位且更高位全为 $0$，故只能 $j = k$，即 $x = 2^k-1$；再由引理 2，这等价于「相邻位互不相同」。∎

## 6. 复杂度分析

- **时间**：$O(1)$。一次右移、一次异或、一次加法、一次与运算，全部在不超过 64 位的机器字上完成；若按位长计为 $O(\log n)$，但 $\log n \le 31$ 是常数。
- **空间**：$O(1)$。只用常数个整型变量，不申请字符串、哈希集合或数组。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool hasAlternatingBits(int n) {
        // 用 64 位：n = 0x55555555 时 x = 0x7FFFFFFF，x + 1 = 2^31 会让 int 溢出
        long long x = (long long)n ^ ((long long)n >> 1);
        return (x & (x + 1)) == 0;   // x 全 1 ⇔ x + 1 是 2 的幂
    }
};
```

### Python

```python
class Solution:
    def hasAlternatingBits(self, n: int) -> bool:
        x = n ^ (n >> 1)           # 第 i 位 = 原第 i 位与第 i+1 位是否不同
        return (x & (x + 1)) == 0  # x 全 1 ⇔ x + 1 是 2 的幂
```

> 💡 若更习惯逐位扫描，`while n > 1: if (n & 1) == ((n >> 1) & 1): return False; n >>= 1` 同样正确，只是常数更大，且要小心循环终止条件（`n` 降到 1 时 `n >> 1 = 0`，最后一位与补零比较仍成立）。

## 8. 边界情况与易错点

1. **$n = 1$**：二进制只有一位，不存在「相邻位」，按语义视为交替，返回 `true`。算法给出 $x = 1$，$1 \,\&\, 2 = 0$ ✓。
2. **$n = 2^{31}-1$**：31 个 $1$，返回 `false`。此时 $x = \texttt{0x40000000}$，$x+1 = \texttt{0x40000001}$，与运算仍非零，不会误判。
3. **$n = \texttt{0x55555555} = 1431655765$**：最大的交替数，返回 `true`；但 $x = 2^{31}-1$，`x + 1` 用 `int` 会溢出（UBSan 直接报 `signed integer overflow`），必须 64 位。
4. **误用 `n & (n >> 1) == 0`**：$n = 4 = 100_2$ 会得到 `true`，正确答案是 `false`。该式只排除「11」，不排除「00」。
5. **字符串法漏掉 `0b` 前缀**：`bin(n)` 返回 `'0b101'`，务必 `[2:]`；虽然 `'b'` 与相邻字符都不同、本例不会因此误判，但写法脆弱。
6. **把「交替」误读成「回文」或「以 0 结尾」**：题目只要求相邻位不同，`1`、`10`、`101`、`1010` 都合法，例如 $n = 2 = 10_2$ 返回 `true`。
7. **多组输入忘记重置**：本题单次调用无状态；若改成多组模板，注意每组重新读入 $n$，不要复用上一组的 $x$。

**延伸思考**：

1. **判断周期 $p$ 的重复 / 反相重复**：若要求 $n_i = n_{i+p}$ 对所有 $0 \le i \le k-1-p$ 成立，令 $y = n \oplus (n \gg p)$ 后检查其低 $k-p$ 位是否为 $0$：`y & ((1 << (k - p)) - 1) == 0`；若要求 $n_i \ne n_{i+p}$，则检查这 $k-p$ 位是否全为 $1$。本题正是 $p = 1$ 的**反相**版本：$y$ 的低 $k-1$ 位全为 $1$，而第 $k-1$ 位由「最高位与补零异或」恒为 $1$，合起来恰好是全 $1$，于是一条与运算就能收尾。
2. **$k$ 位交替数的闭式**：$k$ 位二进制中以 $1$ 开头的交替串唯一，其值为 $\left\lfloor \dfrac{2^{k+1}}{3} \right\rfloor$（$k=3$ 得 $5$，$k=5$ 得 $21$）。等价地，$n$ 是交替数 $\iff$ $3n+1$ 或 $3n+2$ 是 $2$ 的幂。
3. **求「下一个更大的交替数」**：先算位长 $k$ 的候选 $\left\lfloor 2^{k+1}/3 \right\rfloor$，若它不大于 $n$ 就取 $k+1$ 位的候选，$O(1)$ 完成，注意 $k = 31$ 时用 64 位。
