# LeetCode 贴纸拼词 题解

## 1. 题目概述

- **标题 / 题号**：贴纸拼词（#691，hard）
- **链接**：https://leetcode.cn/problems/stickers-to-spell-word/
- **来源**：LeetCode 第 53 场周赛 Q4
- **难度**：困难
- **标签**：位运算、记忆化搜索、数组、哈希表、字符串、动态规划、回溯、状态压缩

**题意**：有 $n$ 种贴纸，第 $i$ 种印着小写单词 `stickers[i]`。把贴纸上的字母**剪成单个字母**再重新排列，去拼出 `target`；每种贴纸都有**无限张**。求最少需要多少张贴纸，拼不出则返回 $-1$。

关键点在于：**字母是可拆散重排的**，所以贴纸只是一袋字母，`target` 只是另一袋字母，位置完全无关；再叠加「每种贴纸无限张」，问题就变成「用最少的字母袋覆盖一个需求向量」。

**约束**：

- $1 \le n \le 50$
- $1 \le \lvert \text{stickers}[i] \rvert \le 10$
- $1 \le \lvert \text{target} \rvert \le 15$
- 所有单词只含小写英文字母

> 💡 $\lvert\text{target}\rvert \le 15$ 是本题唯一的「小」信号：它保证了任何按 `target` 派生的状态空间都不超过 $2^{15}$ 量级。

## 2. 示例

**示例 1**

```text
输入：stickers = ["with","example","science"], target = "thehat"
输出：3
解释：2 张 "with" 提供 t×2、h×2；1 张 "example" 提供 e×1、a×1，恰好拼出 "thehat"。
      任意 2 张贴纸的字母都凑不齐（"with" 缺 a/e，"example" 缺 t/h），故答案为 3。
```

**示例 2**

```text
输入：stickers = ["notice","possible"], target = "basicbasic"
输出：-1
解释：target 需要字母 a 与 b，但两张贴纸都不含 a、b，永远拼不出，返回 -1。
```

**补充示例**（自测用，非官方）

```text
输入：stickers = ["ab","bc","cd"], target = "abcd"
输出：2
解释："ab" 给 a、b，"cd" 给 c、d，两张即可；1 张贴纸最多 2 个字母，必然不够。
```

## 3. 解题思路

### 3.1 暴力思路

三种「顺着直觉走」的写法，各有各的坑：

1. **枚举贴纸序列**：从 $n$ 种贴纸里选 $k$ 张（可重复），枚举量 $n^k$。答案最大可到 15（`target` 全不重复、每张贴纸只给一个字母），$50^{15}$ 不可行。
2. **以「已拼出的位置集合」为状态**：$2^{15} = 32768$ 个状态看似可行，但同一份「剩余需求」会被大量位集重复表示。`target = "aaaaa"` 时 5 个 `a` 的位置有 $2^5 = 32$ 种填法，**完全等价**却各占一个状态。
3. **按位置贪心填充的状压 BFS**：用「从左往右填」把等价位集压成唯一代表，能过题，但「为什么可以规定顺序」需额外论证，状态里仍带位置信息。

> ⚠️ 真正的浪费来自**位置对称性**：`target` 里两个 `t` 先填哪个都无所谓。把状态从「哪些位置已拼出」换成「每种字母还差几个」，冗余立刻消失，转移也变成纯向量减法。

### 3.2 核心观察：剩余需求向量是充分状态

![状态 = 剩余字母需求向量](images/wc53_q4_sticker_state_model.svg)

设 `target` 中出现的不同字母为 $c_1,\dots,c_k$（$k \le 15$），需求 $need_j$ 为字母 $c_j$ 的出现次数。状态定义为**剩余需求向量**：

$$S = (r_1, r_2, \dots, r_k), \qquad 0 \le r_j \le need_j$$

初始 $S_0 = (need_1,\dots,need_k)$，目标 $S = \mathbf{0}$。用一张贴纸（其计数向量为 $s$）后：

$$r_j \leftarrow \max\bigl(0,\; r_j - s_j\bigr)$$

**为什么这是充分状态**：拼词只依赖「每种字母还缺多少个」，与它们原本位于 `target` 的哪几个下标无关——字母可以任意重排。于是同一个 $S$ 出发的最优后续代价是唯一的，可以记忆化。

**状态数上界**：因为 $need_j + 1 \le 2^{need_j}$（$need_j \ge 1$ 时等号仅在 $need_j = 1$），所以

$$\prod_{j=1}^{k}(need_j+1) \;\le\; 2^{\sum_j need_j} \;=\; 2^{\lvert \text{target}\rvert} \;\le\; 2^{15} = 32768$$

状态数不超过 32768，且转移只会让 $\sum_j r_j$ **严格变小**，所以状态图是 **DAG**：可以直接记忆化 DFS（或按剩余总量递增做 DP），每个状态只算一次。

### 3.3 算法流程与三道剪枝

![记忆化搜索流程](images/wc53_q4_memo_search_flow.svg)

1. **统计需求**：`need[c]` 为 `target` 中字母 $c$ 的数量，只保留 $need[c] > 0$ 的 $k$ 个字母。
2. **贴纸归一化**：每张贴纸同样按 $k$ 个字母计数，**逐位截断到 $need$**；丢掉全零（对 `target` 无贡献）的贴纸，再排序去重。
3. **支配剪枝**：若存在另一张贴纸 $B$ 满足 $\forall j,\; B_j \ge A_j$ 且 $B \ne A$，则称 $B$ **支配** $A$，删除 $A$——用 $B$ 顶替 $A$ 只会更宽松。这一步常把 $n=50$ 压到十几张。
4. **混合进制编码**：令 $mult_1 = 1$，$mult_j = \prod_{i<j}(need_i+1)$，则

$$state = \sum_{j=1}^{k} r_j \cdot mult_j, \qquad 0 \le state < \prod_j (need_j+1)$$

满状态（初始状态）恰为 $\prod_j(need_j+1) - 1$，因为每一位都取到最大值。
5. **选关键缺口字母 $c^\ast$**：在所有 $r_j > 0$ 的字母中，取「能提供它的贴纸数量最少」的那个。任何最优方案的下一张贴纸**必然包含 $c^\ast$**（否则 $c^\ast$ 永远补不上），于是只需枚举含 $c^\ast$ 的贴纸，分支数骤降。
6. **记忆化递推**：`memo[state] = 1 + min(memo[next])`；$state = 0$ 时为 0；没有合法转移时置 $\infty$。
7. **收尾**：答案为 `memo[满状态]`，若为 $\infty$ 返回 $-1$。

> 💡 第 5 步的正确性与「选哪个字母」无关，选「供给最少」的只是让枚举更快；这也是本题最常见的超时点——不剪枝时 $50 \times 32768$ 次向量运算在 Python 里很危险。

### 3.4 示例演算

![thehat 的走查](images/wc53_q4_walkthrough.svg)

以 `stickers = ["with","example","science"]`、`target = "thehat"` 为例。需求为 $t{:}2,\ h{:}2,\ e{:}1,\ a{:}1$，贴纸归一化后：

| 贴纸 | 归一化向量 $(t,h,e,a)$ | 说明 |
|------|------------------------|------|
| `with` | $(1,1,0,0)$ | 提供 t、h |
| `example` | $(0,0,1,1)$ | 原 e×2、a×1，截断到 $need$ 后为 e×1、a×1 |
| `science` | $(0,0,1,0)$ | 只提供 e，被 `example` 支配，剪掉 |

DFS 从 $(2,2,1,1)$ 出发（混合进制下满状态 $state = 35$）：缺口字母中 `a` 只有 `example` 能供，故第一张必选 `example`；此后 $t,h$ 各剩 2，`with` 供给最多，需 2 张。总计 $1 + 2 = 3$。

反观示例 2：`target = "basicbasic"` 中 `a`、`b` 无人供给，第 5 步的 $bc = 0$ 直接判定 $\infty$，返回 $-1$。

## 4. 算法细节

1. **截断到 $need$ 是安全的**：贴纸里超出需求的字母永远用不上，计数大于 $need_j$ 与等于 $need_j$ 等价，截断后向量更小、支配关系更干净。
2. **先排序去重，再做支配剪枝**：向量完全相同的贴纸若在去重前比较，会互相删除；`cnts[b] != cnts[a]` 是兜底，去重还能省掉大量比较。
3. **支配剪枝是严格版**：只允许「每一位都不少，且至少一位更多」才删；否则两张互相支配的贴纸会把对方都删掉，该字母彻底失去供给。
4. **满状态就是 `total - 1`**：初始向量每位取最大值（`total = ∏(need_j+1)`），不必单独编码；解码用 `state / mult[j] % (need_j+1)`。
5. **$c^\ast$ 取「供给贴纸数最少」的缺口字母**：若为 0，说明该字母无人能供给，直接返回 $\infty$（本题唯一的不可行原因）。
6. **memo 双哨兵 + 递归深度**：`-1` 表示未计算、$\infty$ 表示已算但无解，两者必须分开；每次转移至少消掉一个字母，深度 $\le \lvert\text{target}\rvert \le 15$，不会爆栈。

## 5. 正确性证明

**引理 1（状态充分性）**：若两个部分解在 $k$ 个字母上的剩余需求向量相同，则从它们出发能达成目标的最小贴纸数相同。

**证明**：拼词只取决于「每种字母还需要多少个」。剩余向量相同意味着两者的可用字母池与缺口完全一致；由于字母可任意重排，任何能补全其中之一的贴纸多重集，同样能补全另一个，且所需张数相同。∎

**引理 2（单张贴纸取满最优）**：给定剩余向量 $r$ 与贴纸计数 $s$，转移 $r_j' = \max(0, r_j - s_j)$ 不劣于只取用一部分字母的任何转移。

**证明**：设另一种取法得到 $r''$，因为少取字母只会让剩余更多，故 $r''_j \ge r'_j$ 对每个坐标成立（逐点更大）。任何能补全 $r''$ 的贴纸多重集，也一定能补全 $r'$（剩余更少只会更容易满足），所以 $r'$ 的最优代价不超过 $r''$ 的。取满不劣。∎

**引理 3（关键字母剪枝）**：设 $r \ne \mathbf{0}$，$c^\ast$ 是任一满足 $r_{c^\ast} > 0$ 的字母，则存在一个最优方案，其使用的第一张贴纸包含 $c^\ast$。

**证明**：取任一最优贴纸多重集 $\mathcal{M}$。因为 $\mathcal{M}$ 补全了 $r$，其中必有一张贴纸 $X$ 含字母 $c^\ast$（$c^\ast$ 的缺口只能由含它的贴纸补上）。多重集的使用顺序不影响最终剩余向量（逐坐标取 $\max(0,\cdot)$ 的减法可交换），故可令 $X$ 排在第一位，方案张数不变。∎

**引理 4（支配剪枝）**：若 $B$ 支配 $A$，则删除 $A$ 不改变最优值。

**证明**：任一使用 $A$ 的方案，把该处的 $A$ 换成 $B$：由于 $B_j \ge A_j$ 对每个坐标成立，替换后每一步的剩余向量逐点不超过原方案，张数不变仍能补全，故最优值不变；而删除 $A$ 后 $B$ 仍在集合中（$B \ne A$ 保证不会连带删除），这些方案仍可达。∎

**定理**：`dfs(满状态)` 返回拼出 `target` 所需的最少贴纸数，无解时为 $\infty$。

**证明**：对剩余字母总数 $m = \sum_j r_j$ 归纳。$m = 0$ 时无需贴纸，返回 0 正确。设 $m \ge 1$，由引理 3 存在最优方案以含 $c^\ast$ 的贴纸 $X$ 开头；由引理 2 该步取满最优；由引理 1，进入新状态后的最优代价只依赖于新向量，正是递归所求。故 `1 + min dfs(next)` 等于最优值。转移严格减少 $m$，归纳成立。∎

**推论**：若某个 $need_j > 0$ 的字母不出现在任何贴纸中，$c^\ast$ 的 $bc = 0$，返回 $\infty$，最终输出 $-1$，与「不可行」等价。

## 6. 复杂度分析

- **时间**：状态数 $S = \prod_j (need_j+1) \le 2^{\lvert\text{target}\rvert} \le 32768$，每个状态做一次 $O(nk)$ 的转移枚举（$k \le 15$），总上界 $O(S \cdot n \cdot k) \approx 2.5\times10^7$；预处理（统计 + 去重 + 支配剪枝）为 $O(n^2 k)$。支配剪枝与关键字母剪枝把 $n$ 和分支数都大幅压低，实测最坏用例在毫秒级。
- **空间**：记忆化数组 $O(S)$，每张贴纸计数 $O(nk)$，递归栈深度 $O(\lvert\text{target}\rvert)$；合计 $O(S + nk)$。

## 7. 参考代码

### C++

```cpp
#include <string>
#include <vector>
#include <algorithm>
#include <functional>
using namespace std;

class Solution {
public:
    int minStickers(vector<string>& stickers, string target) {
        int need[26] = {0}, pos[26];
        for (char ch : target) need[ch - 'a']++;
        vector<int> letters;
        for (int i = 0; i < 26; i++) { pos[i] = -1; if (need[i]) letters.push_back(i); }
        int k = letters.size();
        for (int j = 0; j < k; j++) pos[letters[j]] = j;

        vector<vector<int>> cnts;                    // 归一化：截断到 need，丢弃无贡献贴纸
        for (const string& s : stickers) {
            vector<int> c(k, 0);
            for (char ch : s) {
                int i = ch - 'a';
                if (need[i] && c[pos[i]] < need[i]) c[pos[i]]++;
            }
            if (*max_element(c.begin(), c.end()) > 0) cnts.push_back(c);
        }
        sort(cnts.begin(), cnts.end());
        cnts.erase(unique(cnts.begin(), cnts.end()), cnts.end());

        vector<vector<int>> keep;                    // 支配剪枝：B 每位 ≥ A 且 B ≠ A ⇒ 删 A
        for (int a = 0; a < (int)cnts.size(); a++) {
            bool dom = false;
            for (int b = 0; b < (int)cnts.size() && !dom; b++) {
                if (a == b) continue;
                bool ge = true;
                for (int j = 0; j < k; j++) if (cnts[b][j] < cnts[a][j]) { ge = false; break; }
                if (ge && cnts[b] != cnts[a]) dom = true;
            }
            if (!dom) keep.push_back(cnts[a]);
        }
        cnts = keep;

        vector<int> mult(k);                         // 混合进制：state = Σ rem[j]·mult[j]
        int total = 1;
        for (int j = 0; j < k; j++) { mult[j] = total; total *= need[letters[j]] + 1; }

        const int INF = 1000000000;
        vector<int> memo(total, -1);
        function<int(int)> dfs = [&](int state) -> int {
            if (state == 0) return 0;
            int& res = memo[state];
            if (res != -1) return res;
            vector<int> rem(k);                      // 每个栈帧独立，切勿共享
            for (int j = 0; j < k; j++) rem[j] = state / mult[j] % (need[letters[j]] + 1);
            int bi = -1, bc = INF;                   // 选「供给贴纸最少」的缺口字母
            for (int j = 0; j < k; j++) {
                if (rem[j] == 0) continue;
                int c = 0;
                for (const auto& s : cnts) if (s[j] > 0) c++;
                if (c < bc) { bc = c; bi = j; }
            }
            if (bc == 0) return res = INF;
            long long best = INF;
            for (const auto& s : cnts) {
                if (s[bi] == 0) continue;            // 必须覆盖关键缺口
                int ns = state, gain = 0;
                for (int j = 0; j < k; j++) {
                    int t = min(rem[j], s[j]);
                    if (t) { ns -= t * mult[j]; gain += t; }
                }
                if (gain) best = min(best, (long long)dfs(ns) + 1);
            }
            return res = (int)best;
        };
        int ans = dfs(total - 1);
        return ans >= INF ? -1 : ans;
    }
};
```

### Python

```python
from functools import lru_cache


class Solution:
    def minStickers(self, stickers, target):
        need = [0] * 26
        for ch in target:
            need[ord(ch) - 97] += 1
        letters = [i for i in range(26) if need[i]]
        k = len(letters)
        pos = {c: j for j, c in enumerate(letters)}

        cnts = []                                    # 归一化：只留 target 字母，截断到 need
        for s in stickers:
            c = [0] * k
            for ch in s:
                i = ord(ch) - 97
                if need[i] and c[pos[i]] < need[i]:
                    c[pos[i]] += 1
            if any(c):
                cnts.append(tuple(c))
        cnts = sorted(set(cnts))

        keep = []                                    # 支配剪枝
        for ai, a in enumerate(cnts):
            dom = any(ai != bi and b != a and all(b[j] >= a[j] for j in range(k))
                      for bi, b in enumerate(cnts))
            if not dom:
                keep.append(a)
        cnts = keep

        INF = 10 ** 9

        @lru_cache(maxsize=None)
        def dfs(rem):
            if not any(rem):
                return 0
            bi, bc = -1, 10 ** 9                     # 供给最少的缺口字母
            for j in range(k):
                if rem[j] > 0:
                    c = sum(1 for s in cnts if s[j] > 0)
                    if c < bc:
                        bc, bi = c, j
            if bc == 0:
                return INF
            best = INF
            for s in cnts:
                if s[bi] == 0:
                    continue
                nr = tuple(max(0, rem[j] - s[j]) for j in range(k))
                if nr != rem:
                    best = min(best, dfs(nr) + 1)
            return best

        ans = dfs(tuple(need[c] for c in letters))
        return -1 if ans >= INF else ans
```

## 8. 边界情况与易错点

1. **某字母无人供给**：`target = "basicbasic"` 需要 `a`、`b`，两张贴纸都没有 → 必须返回 $-1$，不能因为递归「走不动」就返回 0 或大数。
2. **C++ 里 `rem` 向量不能跨栈帧共享**：若把 `rem` 定义在 lambda 外，递归返回后外层循环仍在使用被内层覆盖的 `rem`，结果偏大（真实踩坑）。每个栈帧必须各自 `vector<int> rem(k)`。
3. **`memo` 的哨兵冲突**：用 `-1` 表示未计算时，无解状态必须写 $\infty$（如 `1e9`），否则会被当成「没算过」反复重算；返回时用 `ans >= INF` 判不可行，而不是 `== INF`。
4. **支配剪枝必须严格**：只删「被严格支配」的贴纸；相等向量先去重，否则两张相同贴纸会互相删除，可能导致某字母失去全部供给。
5. **单字母 `target`**：`["x"]` + `"x"` → 1；`"xx"` 且只有 `"x"` → 2。截断后状态数只有 2，递推仍要能正确处理。
6. **答案上界**：最多 $\sum_j need_j \le 15$ 张（每张至少消掉一个字母），$\infty$ 取 `1e9` 足够安全，也不会与合法答案混淆。

**延伸思考**：若给每张贴纸加上价格、要求**总价最小**，状态不变但转移权值不是 1，需要用 Dijkstra 或按拓扑序做最短路；若每张贴纸**只能用一次**，就退化成 638 那样的 0/1 背包式记忆化，状态需额外记录已用贴纸集合（$2^n$），复杂度不可接受，此时应转向整数规划或 DLX。另一个方向是**下界剪枝 + IDA\***：以 $\max_j \lceil r_j / \max_i s_{i,j} \rceil$ 作为剩余步数下界，可以在 `target` 更长（例如 100）时把搜索压到可接受范围。
