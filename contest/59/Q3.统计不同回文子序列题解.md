# LeetCode 统计不同回文子序列 题解

## 1. 题目概述

- **标题 / 题号**：统计不同回文子序列（#730，hard）
- **链接**：https://leetcode.cn/problems/count-different-palindromic-subsequences/
- **来源**：LeetCode 第 59 场周赛 Q3
- **难度**：困难
- **标签**：字符串，动态规划

**题意**：给定只含 `a`、`b`、`c`、`d` 四种字符的字符串 $s$，统计**本质不同**的非空回文子序列的个数，答案对 $10^9+7$ 取余。子序列通过删除若干字符得到；两个子序列只要字符序列相同就算同一个，**不看下标**，「`bcb` 出现两次也只计一次」正是本题的全部难点。

**约束**：

- $1 \le \lvert s \rvert \le 1000$
- $s[i] \in \{\texttt{a},\texttt{b},\texttt{c},\texttt{d}\}$

## 2. 示例

**示例 1**

```text
输入：s = "bccb"
输出：6
解释：6 个不同的非空回文子序列是 "b"、"c"、"bb"、"cc"、"bcb"、"bccb"。
      "bcb" 可由下标 (0,1,3) 或 (0,2,3) 得到，字符相同只计一次。
```

**示例 2**

```text
输入：s = "abcdabcdabcdabcdabcdabcdabcdabcddcbadcbadcbadcbadcbadcbadcbadcba"（长度 64，a~d 各 16 个）
输出：104860361
解释：不同非空回文子序列共 3104860382 个，对 10^9+7 取余后为 104860361。
```

## 3. 解题思路

### 3.1 暴力思路

枚举全部 $2^n$ 个子序列、逐个判回文、用集合去重：$O(n \cdot 2^n)$，$n=1000$ 时完全不可行。即使是「按位置计数」的区间 DP 也不对——同一个字符串会有多种取法，直接累加会重复计数。所以这题的关键不是「怎么数」，而是「怎么保证不重不漏」。

### 3.2 核心观察：按最外层字母把候选划分成三块

![三种来源恰好划分全部回文子序列](images/wc59_q3_dedup_partition.svg)

设 $f(i,j)$ 为 $s[i..j]$ 的不同非空回文子序列个数。盯住两个端点：

**情形一：$s[i]\ne s[j]$。** 任何回文都不可能同时用到 $i$ 和 $j$——否则它的首字符是 $s[i]$、末字符是 $s[j]$，而回文首末字符必须相同，直接逼出 $s[i]=s[j]$。所以每个回文至少落在 $s[i+1..j]$ 或 $s[i..j-1]$ 之一里，容斥得

$$f(i,j)=f(i+1,j)+f(i,j-1)-f(i+1,j-1)$$

**情形二：$s[i]=s[j]=c$。** 记内部区间 $[i+1,j-1]$ 的全部不同回文集合为 $A$，$|A|=f(i+1,j-1)$。此时 $s[i..j]$ 的回文恰好分成三块：$A$ 本身（$|A|$ 个）；包裹 $c+q+c$，其中 $q\in A\cup\{\varepsilon\}$，共 $|A|+1$ 个（$q$ 取空串给出 `"cc"`）；以及单字符 `"c"`（1 个）。

三块之间唯一的重复是：某些包裹其实在内部就已经出现了。设 $a$ 为 $i$ 之后第一个 $c$ 的下标、$b$ 为 $j$ 之前最后一个 $c$ 的下标（字母表只有 4 个字符，用 next/prev 表 $O(1)$ 查）。包裹 $c+q+c$ 能出现在 $s[i+1..j-1]$ 中，当且仅当内部存在两个 $c$ 把 $q$ 夹住，即 $a<b$ 且 $q$ 是 $s[a+1..b-1]$ 的回文（或空串），重复个数为 $f(a+1,b-1)+1$。按 $c$ 在内部出现的次数分三支：

$$f(i,j)=\begin{cases}2f(i+1,j-1)+2, & a>b\ (\text{内部没有 } c)\\ 2f(i+1,j-1)+1, & a=b\ (\text{内部恰有一个 } c)\\ 2f(i+1,j-1)-f(a+1,b-1), & a<b\ (\text{内部至少两个 } c)\end{cases}$$

> 💡 直觉：$a>b$ 时 `"c"` 和 `"cc"` 都是新面孔，各贡献 $+1$，所以 $+2$；$a=b$ 时 `"c"` 已经在 $A$ 里，只剩 `"cc"` 是新的，所以 $+1$；$a<b$ 时连 `"cc"` 都能在内部找到，必须减去内部那一段的答案。

### 3.3 算法流程 / 状态转移

![区间 DP 状态转移](images/wc59_q3_dp_transition.svg)

1. **预处理 next/prev**：`nxt[i][c]` 表示 $i$ 之后第一个字符 $c$ 的下标（没有则为 $n$），`prv[i][c]` 表示 $j$ 之前最后一个字符 $c$ 的下标（没有则为 $-1$）。倒序扫一遍、正序扫一遍即可，$O(4n)$。
2. **初始化**：$f(i,i)=1$；空区间约定为 $0$，代码里用 $i+1\le j-1$ 判断，避免访问非法区间。
3. **按长度递推**：对 $\text{len}=2,3,\dots,n$，令 $j=i+\text{len}-1$。转移只用到 $[i+1,j]$、$[i,j-1]$、$[i+1,j-1]$、$[a+1,b-1]$ 四个**更短**的区间，全部已算好。
4. **取模**：出现减法的位置统一写 `(val % MOD + MOD) % MOD`，C++ 中负数取模仍为负。
5. **答案**：$f(0,n-1)$。

### 3.4 示例演算

![示例 bccb 的填表过程](images/wc59_q3_walkthrough.svg)

对字符串 `"bccb"`（$n=4$），按长度从小到大：

| 区间 | 子串 | 端点关系 | 转移式 | $f$ |
|------|------|----------|--------|-----|
| $[0,1]$ | `bc` | 不同 | $1+1-0=2$ | 2 |
| $[1,2]$ | `cc` | 相同，内部无 `c` | $2\cdot 0+2=2$ | 2 |
| $[2,3]$ | `cb` | 不同 | $1+1-0=2$ | 2 |
| $[0,2]$ | `bcc` | 不同 | $2+2-1=3$ | 3 |
| $[1,3]$ | `ccb` | 不同 | $2+2-1=3$ | 3 |
| $[0,3]$ | `bccb` | 相同，内部无 `b` | $2\cdot f(1,2)+2=6$ | 6 |

长度 1 的四个区间各自贡献 1 个单字符回文，作为基态。最后一格的 6 正好对应 $\{\texttt{b},\texttt{c},\texttt{bb},\texttt{cc},\texttt{bcb},\texttt{bccb}\}$，与示例一致。

## 4. 算法细节

1. **next 表的构造顺序**：倒序循环里先把 `nxt[i]` 整体赋成当前的 `last`，再更新 `last[s[i]] = i`，这样得到的一定是**严格大于** $i$ 的位置；`prv` 正序同法，保证**严格小于** $j$。顺序写反会把自己算进去，答案偏大。
2. **三支的判定顺序**：必须先判 $a>b$（内部没有 $c$），再判 $a=b$。若写成「$a\ne b$ 就减去 $f(a+1,b-1)$」，在 $a>b$ 时会读到非法区间，值是不可预期的脏数据。
3. **非法区间视为 0**：$u>v$ 时 $f(u,v)=0$。实现上要么显式判断（本文代码），要么只填 $u\le v$ 的表项、让其余位置保持初始 0，两者等价。
4. **定长数组比哈希表快**：字母表是 `abcd`，C++ 用 `array<int,4>`、Python 用长度 4 的 list，比 `map<char,int>` / `unordered_map` 快一个量级，且缓存友好。
5. **循环顺序不能反**：外层必须是区间长度、内层是左端点，因为 $[a+1,b-1]$ 是严格内含的区间，长度必然更短；如果按左端点降序、右端点升序枚举，也能满足依赖，但按长度写最不容易错。
6. **空间不必滚动**：$n=1000$ 时 $f$ 为 $10^6$ 个 `int`，约 4MB，完全够用；硬压成一维反而要处理跨层访问，得不偿失。

## 5. 正确性证明

**引理 1**：若 $s[i]\ne s[j]$，则 $f(i,j)=f(i+1,j)+f(i,j-1)-f(i+1,j-1)$。

**证明**：记 $P(i,j)$ 为 $s[i..j]$ 的不同非空回文子序列构成的集合。

先证 $P(i,j)=P(i+1,j)\cup P(i,j-1)$。取 $P\in P(i,j)$。若 $P\notin P(i+1,j)$，说明 $P$ 的任何实现都必须用到位置 $i$（$i$ 是最左端，用到它就意味着 $P$ 以 $s[i]$ 开头）；若同时 $P\notin P(i,j-1)$，同理 $P$ 的任何实现都必须用到位置 $j$，即 $P$ 以 $s[j]$ 结尾。于是 $P$ 的首字符是 $s[i]$、末字符是 $s[j]$，而 $P$ 是回文要求首末字符相同，得 $s[i]=s[j]$，矛盾。故每个 $P$ 至少属于一侧。

再证交集为 $P(i+1,j-1)$。一个方向显然：$P(i+1,j-1)$ 中的回文在两侧都能实现。另一个方向，设 $P$ 同时属于两侧。取 $P$ 在 $s[i..j-1]$ 中的一次实现：若它不含 $i$，则 $P\in P(i+1,j-1)$；若含 $i$，则 $P$ 以 $s[i]$ 开头。再取 $P$ 在 $s[i+1..j]$ 中的一次实现：若它不含 $j$，则 $P\in P(i+1,j-1)$；若含 $j$，则 $P$ 以 $s[j]$ 结尾。后一种情形同样推出 $s[i]=s[j]$，与假设矛盾。故交集只能是 $P(i+1,j-1)$，由容斥即得引理。∎

**引理 2**：若 $s[i]=s[j]=c$，则 $P(i,j)=A\cup W\cup\{C\}$，其中 $A=P(i+1,j-1)$、$W=\{c+q+c:q\in A\cup\{\varepsilon\}\}$，$C$ 表示只含一个字符 $c$ 的串。

**证明**：任取 $P\in P(i,j)$ 且 $P\notin A$，即 $P$ 无法完全在 $s[i+1..j-1]$ 中实现，于是它的每次实现都要用到 $i$ 或 $j$。

- 用到 $i$ 就必须以 $s[i]=c$ 开头（$i$ 是区间最左端）；用到 $j$ 就必须以 $s[j]=c$ 结尾。
- 回文的末字符等于首字符，故 $P$ 是长度 1 的 `"c"`，或是首末字符都为 $c$、长度 $\ge 2$ 的串，即形如 $c+q+c$。
- 中间的 $q$ 是 $P$ 去掉首末字符的结果，仍是回文；它由 $s[i+1..j-1]$ 中位于两个 $c$ 之间的字符实现，故 $q\in A\cup\{\varepsilon\}$。

又 $W$ 中的串长度都 $\ge 2$、`"c"` 长度为 1，二者不相交；$W$ 内部因 $q$ 不同而互不相同。故 $P(i,j)$ 被这三块覆盖，且只可能在这些块之间重复。∎

**引理 3**：$a<b$ 时 $|W\cap A|=f(a+1,b-1)+1$；$a\ge b$ 时 $W\cap A=\varnothing$。

**证明**：$c+q+c\in A$ 等价于 $s[i+1..j-1]$ 中存在两个 $c$ 夹住 $q$ 的一次实现。$a$ 是内部最左的 $c$、$b$ 是最右的 $c$，因此这件事等价于「$a<b$ 且 $q$ 可由 $s[a+1..b-1]$ 实现」，也就是 $q\in P(a+1,b-1)\cup\{\varepsilon\}$（$\varepsilon$ 对应 `"cc"`）。该集合含 $f(a+1,b-1)+1$ 个元素，与 $W\cap A$ 一一对应；若 $a\ge b$，内部凑不出两个 $c$，交集为空。∎

**定理**：上述递推按区间长度归纳，正确算出每个 $f(i,j)$，故算法输出 $f(0,n-1)$ 即为答案。

**证明**：对长度归纳。长度为 1 时 $f(i,i)=1$，正确。设长度小于 $L$ 的区间都正确，取长度 $L$ 的 $[i,j]$：

- 若 $s[i]\ne s[j]$：由引理 1，$f(i,j)$ 只由三个更短区间决定，归纳假设保证它们正确。
- 若 $s[i]=s[j]=c$：由引理 2，$|P(i,j)|=|A\cup W|+[C\notin A\cup W]$，而 $|A\cup W|=|A|+|W|-|W\cap A|=2|A|+1-|W\cap A|$。
  - $a>b$：引理 3 给出交集为空，且内部无 $c$ 故 `"c"` 不在 $A$ 中，得 $2|A|+1+1=2f(i+1,j-1)+2$。
  - $a=b$：交集为空，内部有 $c$ 故 `"c"` 已在 $A$ 中，得 $2|A|+1=2f(i+1,j-1)+1$。
  - $a<b$：交集大小为 $f(a+1,b-1)+1$，且 `"c"` 已在 $A$ 中，得 $2|A|+1-\bigl(f(a+1,b-1)+1\bigr)=2f(i+1,j-1)-f(a+1,b-1)$。

  三种情况都与代码一致；而 $f(a+1,b-1)$ 对应严格更短的区间，可用归纳假设。∎

## 6. 复杂度分析

- **时间**：$O(n^2)$。预处理 next/prev 为 $O(4n)$；DP 共 $\frac{n(n+1)}{2}$ 个区间，每个区间 $O(1)$ 次查表与四则运算，总计 $O(n^2)$。$n=1000$ 时约 $5\times10^5$ 个状态，实测 Python 也在 0.2s 内跑完。
- **空间**：$O(n^2)$。DP 表 $n\times n$ 个 `int`（约 4MB），next/prev 各 $4n$ 个 `int`。题目只要 $n\le 1000$，无需滚动优化。

## 7. 参考代码

### C++

```cpp
#include <array>
#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    int countPalindromicSubsequences(string s) {
        const int MOD = 1000000007;
        int n = (int)s.size();
        if (n == 0) return 0;
        // nxt[i][c] / prv[i][c]：i 之后 / 之前最近的字符 c 的下标
        vector<array<int, 4>> nxt(n), prv(n);
        array<int, 4> last = {n, n, n, n};
        for (int i = n - 1; i >= 0; --i) {
            nxt[i] = last;
            last[s[i] - 'a'] = i;
        }
        array<int, 4> first = {-1, -1, -1, -1};
        for (int i = 0; i < n; ++i) {
            prv[i] = first;
            first[s[i] - 'a'] = i;
        }
        vector<vector<int>> f(n, vector<int>(n, 0));
        for (int i = 0; i < n; ++i) f[i][i] = 1;
        for (int len = 2; len <= n; ++len) {
            for (int i = 0; i + len - 1 < n; ++i) {
                int j = i + len - 1;
                long long val;
                if (s[i] != s[j]) {
                    val = (long long)f[i + 1][j] + f[i][j - 1] - f[i + 1][j - 1];
                } else {
                    int c = s[i] - 'a';
                    int a = nxt[i][c], b = prv[j][c];
                    long long inner = (i + 1 <= j - 1) ? f[i + 1][j - 1] : 0;
                    if (a > b)        val = 2 * inner + 2;   // 内部没有 c
                    else if (a == b)  val = 2 * inner + 1;   // 内部恰有一个 c
                    else {
                        long long sub = (a + 1 <= b - 1) ? f[a + 1][b - 1] : 0;
                        val = 2 * inner - sub;               // 减掉内部重复的包裹
                    }
                }
                val %= MOD;
                if (val < 0) val += MOD;
                f[i][j] = (int)val;
            }
        }
        return f[0][n - 1];
    }
};
```

### Python

```python
class Solution:
    def countPalindromicSubsequences(self, s: str) -> int:
        MOD = 10**9 + 7
        n = len(s)
        if n == 0:
            return 0

        # nxt[i][c]：i 之后第一个 c 的下标（没有为 n）
        nxt = [[n] * 4 for _ in range(n)]
        last = [n] * 4
        for i in range(n - 1, -1, -1):
            nxt[i] = last[:]
            last[ord(s[i]) - 97] = i
        # prv[i][c]：i 之前最后一个 c 的下标（没有为 -1）
        prv = [[-1] * 4 for _ in range(n)]
        first = [-1] * 4
        for i in range(n):
            prv[i] = first[:]
            first[ord(s[i]) - 97] = i

        f = [[0] * n for _ in range(n)]
        for i in range(n):
            f[i][i] = 1
        for length in range(2, n + 1):
            for i in range(n - length + 1):
                j = i + length - 1
                if s[i] != s[j]:
                    f[i][j] = (f[i + 1][j] + f[i][j - 1] - f[i + 1][j - 1]) % MOD
                else:
                    c = ord(s[i]) - 97
                    a, b = nxt[i][c], prv[j][c]
                    inner = f[i + 1][j - 1] if i + 1 <= j - 1 else 0
                    if a > b:
                        val = 2 * inner + 2        # 内部没有 c
                    elif a == b:
                        val = 2 * inner + 1        # 内部恰有一个 c
                    else:
                        sub = f[a + 1][b - 1] if a + 1 <= b - 1 else 0
                        val = 2 * inner - sub      # 减掉内部重复的包裹
                    f[i][j] = val % MOD
        return f[0][n - 1]
```

## 8. 边界情况与易错点

1. **$n=1$**：返回 1，只有字符本身。
2. **全部字符相同**（如 `"aaaa"`）：答案是 $n$——每个长度恰好一种回文。递推里每层都走 $a>b$ 分支，`+2` 的写法必须正确，写成 `+1` 会让答案整体偏小。
3. **长度 2 的区间**：$i+1>j-1$，内部答案必须按 0 处理。若用长度为 $n$ 的表且只填 $i\le j$，非法位置天然是 0；若改用字典或滚动数组，就必须显式判断，否则会取到脏值。
4. **三支的判定顺序**：先判 $a>b$、再判 $a=b$；顺序反了会在「内部没有 $c$」时访问 $[a+1,b-1]$ 这种 $a>b$ 的非法区间。
5. **负数取模**：C++ 的 `%` 保留符号，减法后必须 `(v % MOD + MOD) % MOD`；Python 的 `%` 天然返回非负，可直接取模。
6. **漏掉 `"c"` 这一项**：$a>b$ 时的 $+2$ 里，一份是 `"cc"`、一份是 `"c"`，少加任何一份结果都会系统性偏小。
7. **字符映射**：`s[i]-'a'` 落在 $0..3$，数组开 4；Python 用 `ord(s[i]) - 97` 保持与 C++ 一致，别误写成 `ord(s[i]) - ord('a') + 1` 导致越界。
8. **答案口径**：只统计**非空**回文，空串不算；答案取 $f(0,n-1)$，不是所有区间之和。
