# LeetCode 转化为全零矩阵的最少反转次数 题解

## 1. 题目概述

- **标题 / 题号**：转化为全零矩阵的最少反转次数（#1284，hard）
- **链接**：https://leetcode.cn/problems/minimum-number-of-flips-to-convert-binary-matrix-to-zero-matrix/
- **来源**：LeetCode 第 166 场周赛 Q4
- **难度**：困难
- **标签**：位运算、广度优先搜索、数组、哈希表、矩阵

**题意**：给定一个 $m \times n$ 的 01 矩阵 `mat`。一步操作是选中某个格子，把它自己以及**上下左右四个相邻格子**（存在的那些）一起取反。求把整张矩阵变成全零矩阵所需的**最少操作步数**；若不可能做到，返回 `-1`。

**约束**：

- $m = \text{mat.length}$，$n = \text{mat}[0].\text{length}$
- $1 \le m, n \le 3$，故格子总数 $N = mn \le 9$
- $\text{mat}[i][j]$ 只能取 $0$ 或 $1$
- 状态总数至多 $2^9 = 512$，这是本题一切解法的复杂度上界来源

## 2. 示例

**示例 1**

```text
输入：mat = [[0,0],[0,1]]
输出：3
解释：一种可行顺序是依次反转 (1,0)、(0,1)、(1,1)，共 3 步。
```

**示例 2**

```text
输入：mat = [[0]]
输出：0
解释：已经是全零矩阵，不需要任何操作。
```

**示例 3**

```text
输入：mat = [[1,0,0],[1,0,0]]
输出：-1
解释：所有可能的状态都无法到达全零矩阵。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的想法是把「操作序列」整体当作搜索对象：每层有 $N$ 种选法，深度不设上限时同一个格子可能被按很多次，分支数 $N^d$；即使限制深度不超过 $N$，也有 $N^N = 9^9 \approx 3.9 \times 10^8$ 条序列，而且其中绝大多数互为**重排**（按下 (1,0) 再按 (0,1)，与反过来完全等价），造成海量重复搜索。

若只枚举「按哪些格子」的子集，则是 $2^N$ 个子集、每个子集套用 $N$ 个掩码，$O(2^N \cdot N)$，$N = 9$ 时约 $4608$ 次异或——这其实已经够快。**关键不是「怎么搜得更快」，而是「搜什么」**：把操作序列折叠成状态，同一状态只访问一次，搜索树就坍缩成一张不超过 512 个点的图，答案就是图上的最短路。

另一个常见误区是贪心：每次按「能让 1 变少」的格子。以示例 1 为例，从 1 个 1 出发，任何一步之后 1 的个数至少是 2（按 (0,0) 会变成 4 个 1，按 (1,1) 变成 2 个），贪心会在此直接卡死，而正解恰好是 3 步。

### 3.2 核心观察：异或掩码 + 状态压缩

![状态压缩与十字掩码](images/wc166_q4_bitmask_state.svg)

**第一步：把矩阵压成一个整数。** 给格子 $(i,j)$ 编号 $k = i \cdot n + j$，令

$$
\text{state} = \sum_{i=0}^{m-1}\sum_{j=0}^{n-1} \text{mat}[i][j] \cdot 2^{i n + j}
$$

$N \le 9$，所以 `state` 装得进一个 `int`，所有 $2^N$ 个状态可以开一个数组直接索引。

**第二步：把一次操作写成异或。** 对格子 $(i,j)$ 定义掩码 $\text{mask}(i,j) = \sum_{(x,y)} 2^{x n + y}$，其中 $(x,y)$ 取遍 $(i,j)$ 自身与四个相邻格子（越界的跳过）；由于「翻转」就是二进制位的取反，一次操作恰好是

$$
\text{state}' = \text{state} \oplus \text{mask}(i,j)
$$

**第三步：序列可以折叠成子集。** 异或满足交换律、结合律，且自逆（$x \oplus x = 0$）。于是任何操作序列的总效果只取决于「每个格子被按了奇数次还是偶数次」，同一格按两次等于没按，答案因此等于 $\min\{|T| : T \subseteq \text{cells},\ \bigoplus_{c \in T} \text{mask}(c) = \text{start}\}$。

**第四步：求最小步数 = 无权图最短路。** 以 $2^N$ 个状态为点、每个状态连出 $N$ 条边（异或第 $k$ 个掩码），从 `start` 出发做 BFS，第一次遇到状态 $0$ 时的距离就是答案。$N \le 9$ 时图至多 512 个点、4608 条边，常数极小。

> 💡 **一句话本质**：本题是「Lights Out」类翻灯游戏的极小版本，状态空间只有 512，BFS 是标准答案；而 $m, n \le 3$ 这个约束本身就是出题人给的提示。

### 3.3 算法流程

![BFS 求最短反转次数](images/wc166_q4_bfs_flow.svg)

1. 读入矩阵，按 $k = i \cdot n + j$ 编码出 `start`；`start == 0` 时答案为 0，BFS 首轮弹出即可返回。
2. 预计算 $N$ 个掩码：对每个格子遍历自身与四邻居，越界的跳过，把合法格子的位或起来。
3. 开 `dist[0 .. 2^N-1]` 并全部置 $-1$，`dist[start] = 0`，把 `start` 入队。
4. 循环弹出队首 $s$：若 $s = 0$，返回 `dist[s]`；否则枚举 $N$ 个掩码得到 $t = s \oplus \text{mask}[k]$，若 `dist[t] == -1` 则令 `dist[t] = dist[s] + 1` 并入队。
5. 队列耗尽仍未遇到 $0$，说明 $0$ 与 `start` 不在同一连通分量，返回 $-1$。

### 3.4 示例演算

![示例 1 的三步走查](images/wc166_q4_walkthrough.svg)

对示例 1 的 $2 \times 2$ 矩阵 `[[0,0],[0,1]]`，按 bit0 = (0,0)、bit1 = (0,1)、bit2 = (1,0)、bit3 = (1,1) 编码，初始状态为 $8$：

| 步骤 | 按下格子 | 掩码 | 状态变化 | 二进制 |
|------|----------|------|----------|--------|
| 初始 | — | — | 8 | 1000 |
| 第 1 步 | (1,0) | 13 | $8 \oplus 13 = 5$ | 0101 |
| 第 2 步 | (0,1) | 11 | $5 \oplus 11 = 14$ | 1110 |
| 第 3 步 | (1,1) | 14 | $14 \oplus 14 = 0$ | 0000 |

BFS 的第 1、2 层都不含状态 $0$，第 3 层才出现，故 `dist[0] = 3`。示例 3 的初始状态是 $9$（bit0 与 bit3 为 1），但 $2 \times 3$ 的反转矩阵秩只有 4，64 个状态里只有 16 个与 $0$ 连通，BFS 队列耗尽也不会遇到 $0$，返回 $-1$。

## 4. 算法细节

1. **位编号必须用列数**：$k = i \cdot n + j$。写成 $i \cdot m + j$ 在非方阵（$2 \times 3$）上会直接错位，而本题恰好允许非方阵。
2. **掩码用「自身 + 四邻居」的 5 个方向**：写成 `(0,0),(1,0),(-1,0),(0,1),(0,-1)` 循环，配 `0 <= x < m && 0 <= y < n` 的越界判断，比手写 5 个 `if` 更不容易漏。
3. **距离数组而不是哈希表**：状态数固定为 $2^N \le 512$，`vector<int> dist(1 << N, -1)` 既快又省，也能用 `-1` 同时表达「未访问」；用 `unordered_map` 反而慢。
4. **先判 0 再扩展**：弹出时判断 $s = 0$，可让全零矩阵在第一次循环就返回 0，也保证返回的是「步数」而不是「点数」。
5. **BFS 也可以从 0 反向出发**：异或掩码自逆，图是无向图，从 $0$ 出发得到同样的距离；距离统一记在 `dist` 数组里，队列元素就是状态本身，不必把 `(state, d)` 打包。
6. **等价写法是枚举子集**：`for T in 0..2^N-1` 计算 $\bigoplus_{k \in T} \text{mask}_k$，若等于 `start` 就用 `popcount(T)` 更新答案。它与 BFS 复杂度同阶（都是 $O(2^N \cdot N)$），但 BFS 一旦命中就停，通常更快。
7. **无解判定只需要一次遍历**：BFS 队列耗尽仍未弹出 $0$，说明二者不连通，返回 $-1$；不需要额外做可解性判断。

## 5. 正确性证明

**引理 1（序列可折叠为子集）**：对任意格子序列 $c_1, c_2, \dots, c_t$，令 $T$ 为其中出现奇数次的格子集合，则该序列对状态的作用等于 $\text{state} \oplus \bigoplus_{c \in T}\text{mask}(c)$，且 $|T| \le t$。

**证明**：每次操作都是异或一个掩码，故 $t$ 步之后的状态为 $\text{state} \oplus \bigoplus_{k=1}^{t}\text{mask}(c_k)$（归纳可得）。异或满足交换律、结合律，且同一个量异或偶数次相互抵消，因此和式中只剩出现奇数次的掩码，它们对应的格子恰好组成 $T$。每个加入 $T$ 的格子至少在序列中出现一次，故 $|T| \le t$。∎

**引理 2（最少步数 = 最短路长度）**：在以全部 $N$ 位状态为点、$s$ 与 $s \oplus \text{mask}(k)$ 之间连边的无向图 $G$ 中，从 `start` 到 $0$ 的最少操作次数等于二者的最短路径长度。

**证明**：任取一个 $t$ 步操作序列，由引理 1 它等价于某个 $|T| \le t$ 的子集操作，对应一条长度不超过 $t$ 的路径，故最短路径长度不超过最少操作次数。反过来，$G$ 中任一长度为 $d$ 的路径逐边对应 $d$ 次操作（每条边就是异或某个掩码），把这些操作依次执行可把 `start` 变成 $0$，故最少操作次数不超过 $d$。两边夹逼即得相等。∎

**引理 3（可达状态恰为一个仿射子空间）**：设 $V = \text{span}\{\text{mask}(k)\}$ 是 $N$ 个掩码在 $\mathbb{F}_2$ 上张成的线性空间，维数为 $r$。则 `start` 的可达状态集合恰为 $\{\text{start} \oplus v : v \in V\}$，共有 $2^r$ 个；BFS 会不重不漏地访问它们。

**证明**：任何操作序列的净效果是若干掩码的异或，必属于 $V$；反之 $V$ 中每个向量都是掩码的某个子集的异或（由张成的定义），用引理 1 用该子集操作即可实现。故可达集合就是该仿射空间。BFS 从 `start` 出发沿所有边遍历；由于每条边可双向通行，BFS 访问的正是 `start` 所在的整个连通分量，而该分量已由上述集合刻画。∎

**定理**：算法返回的值等于最少反转次数；当且仅当 $0$ 不在 `start` 的连通分量中时返回 $-1$。

**证明**：若 $0$ 可达，由引理 2 与引理 3，BFS 第一次弹出 $0$ 时 `dist[0]` 就是最短路径长度，也就是最少反转次数，算法返回它。若 $0$ 不可达，由引理 3 的刻画，BFS 会遍历完整个连通分量（至多 $2^r$ 个状态）后队列为空，此时返回 $-1$，与「无法转化」一致。∎

**推论**：$3 \times 3$ 时掩码组满秩（$r = 9$），任意输入都可达、一定有解；$2 \times 3$ 与 $3 \times 2$ 只有 $r = 4$，$64$ 个状态中仅 $16$ 个可达，因此大量输入返回 $-1$；$1 \times 2$ 与 $2 \times 1$ 的秩为 $1$，同样经常无解。

## 6. 复杂度分析

- **时间**：$O(2^N \cdot N)$。编码 $O(N)$，预计算掩码 $O(N)$；BFS 至多访问 $2^N \le 512$ 个状态，每个状态枚举 $N \le 9$ 条出边，合计不超过 $4608$ 次异或与比较。这个上界与输入的具体形态无关。
- **空间**：$O(2^N + N)$。`dist` 数组 $2^N \le 512$ 个 `int`，队列最坏存 $2^N$ 个状态，掩码数组 $N$ 个 `int`。均为百字节量级。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <queue>
using namespace std;

class Solution {
public:
    int minFlips(vector<vector<int>>& mat) {
        int m = mat.size(), n = mat[0].size(), total = m * n;

        // 1. 编码：bit(i*n + j) 表示格子 (i, j) 的值
        int start = 0;
        for (int i = 0; i < m; ++i)
            for (int j = 0; j < n; ++j)
                if (mat[i][j]) start |= 1 << (i * n + j);

        // 2. 预计算每个格子的「十字」掩码（自身 + 上下左右，越界跳过）
        vector<int> mask(total, 0);
        const int dir[5][2] = {{0, 0}, {1, 0}, {-1, 0}, {0, 1}, {0, -1}};
        for (int i = 0; i < m; ++i) {
            for (int j = 0; j < n; ++j) {
                int bits = 0;
                for (int d = 0; d < 5; ++d) {
                    int x = i + dir[d][0], y = j + dir[d][1];
                    if (x >= 0 && x < m && y >= 0 && y < n)
                        bits |= 1 << (x * n + y);
                }
                mask[i * n + j] = bits;
            }
        }

        // 3. 在 2^N 个状态上做 BFS，求 start 到 0 的最短距离
        vector<int> dist(1 << total, -1);
        queue<int> q;
        dist[start] = 0;
        q.push(start);
        while (!q.empty()) {
            int s = q.front();
            q.pop();
            if (s == 0) return dist[s];        // 第一次弹出 0 即为最短步数
            for (int k = 0; k < total; ++k) {
                int t = s ^ mask[k];
                if (dist[t] == -1) {
                    dist[t] = dist[s] + 1;
                    q.push(t);
                }
            }
        }
        return -1;                             // 0 与 start 不连通
    }
};
```

### Python

```python
from collections import deque
from typing import List


class Solution:
    def minFlips(self, mat: List[List[int]]) -> int:
        m, n = len(mat), len(mat[0])
        total = m * n

        # 1. 编码：bit(i*n + j) 表示格子 (i, j) 的值
        start = 0
        for i in range(m):
            for j in range(n):
                if mat[i][j]:
                    start |= 1 << (i * n + j)

        # 2. 预计算每个格子的「十字」掩码
        mask = [0] * total
        for i in range(m):
            for j in range(n):
                bits = 0
                for di, dj in ((0, 0), (1, 0), (-1, 0), (0, 1), (0, -1)):
                    x, y = i + di, j + dj
                    if 0 <= x < m and 0 <= y < n:
                        bits |= 1 << (x * n + y)
                mask[i * n + j] = bits

        # 3. BFS：状态数 2^N <= 512，dist 数组代替哈希表
        dist = [-1] * (1 << total)
        dist[start] = 0
        q = deque([start])
        while q:
            s = q.popleft()
            if s == 0:
                return dist[s]                 # 第一次弹出 0 即为最短步数
            for bits in mask:
                t = s ^ bits
                if dist[t] == -1:
                    dist[t] = dist[s] + 1
                    q.append(t)
        return -1                              # 0 与 start 不连通
```

## 8. 边界情况与易错点

1. **已经全零**：`start = 0`，第一次弹出就返回 `dist[0] = 0`，不需要任何特判；注意别把 `start` 漏掉入队，否则会误判成 -1。
2. **无解矩阵必须返回 -1**：`2 x 3`、`3 x 2` 秩只有 4，`1 x 2`、`2 x 1` 秩只有 1，都会出现无解；不要把「队列空」错写成返回 0 或返回 `dist` 的初值。
3. **`3 x 3` 一定可解**：掩码组满秩 9，512 个状态全连通，因此 `3 x 3` 输入永远不会返回 -1，写特判时不要给 `3 x 3` 加「无解」分支。
4. **单格输入**：`[[0]] -> 0`，`[[1]] -> 1`；此时越界判断会把掩码退化成只有自己一位，逻辑不需要特判。
5. **位编号与界内判断**：位号用 `i * n + j`，写成 `i * m + j` 在 `2 x 3` 上会把两个不同格子编到同一位；越界判断要分别对照行与列，`0 <= x < m` 不要写成 `x < n`。
6. **`dist` 初值与 0 的冲突**：距离 0 是合法值，所以未访问必须用 $-1$ 而不是 0；若用 `vector<bool> visited` 则要另开一个距离数组，反而更啰嗦。
7. **Python 的队列**：用 `collections.deque`，不要用 `list.pop(0)`（$O(n)$ 拷贝）；本题规模下两者都能过，但习惯要正确。
