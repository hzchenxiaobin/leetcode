# LeetCode 找出峰值 题解

## 1. 题目概述

- **标题 / 题号**：找出峰值（#2951，easy）
- **链接**：https://leetcode.cn/problems/find-the-peaks/
- **来源**：LeetCode 第 374 场周赛 Q1
- **难度**：简单
- **标签**：数组、枚举

**题意**：给定下标从 0 开始的数组 `mountain`，找出其中所有**峰值**的下标，以数组形式返回，**顺序不限**。

- **峰值**：**严格大于**其相邻元素的元素。
- 数组的**第一个和最后一个元素不可能是峰值**（只有一侧邻居）。

**约束**：

- $3 \le mountain.length \le 100$
- $1 \le mountain[i] \le 100$

> 💡 读题抓形态：**局部判定型枚举**——位置 $i$ 是否为峰只由自身和左右邻居共 3 个元素决定，与数组其余部分无关。$n \le 100$ 规模极小，怎么写都能过；签到题真正要抠的是三个细节：**首尾天然排除**、**严格大于排除等值平台**、**各判定相互独立**。

## 2. 示例

**示例 1**

```text
输入：mountain = [2,4,4]
输出：[]
解释：mountain[0] 和 mountain[2] 不可能是峰值，因为它们是数组的第一个和最后一个元素。
mountain[1] 也不可能是峰值，因为它不严格大于 mountain[2]。
因此，答案为 []。
```

**示例 2**

```text
输入：mountain = [1,4,3,8,5]
输出：[1,3]
解释：mountain[0] 和 mountain[4] 不可能是峰值，因为它们是数组的第一个和最后一个元素。
mountain[2] 也不可能是峰值，因为它不严格大于 mountain[3] 和 mountain[1]。
但是 mountain[1] 和 mountain[3] 严格大于它们的相邻元素。
因此，答案是 [1,3]。
```

**补充示例：等值平台**

```text
输入：mountain = [1,2,2,1]
输出：[]
解释：中间两个 2 互相相等，都不满足「严格大于两侧」，不是峰值。
这是「严格」二字埋的坑，用 >= 判定会误输出 [1,2]。
```

## 3. 解题思路

### 3.1 暴力思路

枚举每个下标 $i$，检查它是否严格大于左右邻居，是则收进答案。由于题目明文规定首尾不算峰，「暴力」与「正解」几乎重合——唯一的打磨空间是**把边界检查从循环体挪到循环范围上**：枚举范围直接从 $[0, n-1]$ 收缩为 $[1, n-2]$，循环体内只剩两次比较，连越界特判都省了。

规模 $n \le 100$，$O(n)$ 扫描毫无压力。

### 3.2 核心观察：3 格判定窗口 + 严格大于

![核心概念：3 格判定窗口与严格大于](images/wc374_q1_peak_window_concept.svg)

1. **判定窗口只有 3 格**：位置 $i$ 是否为峰，只取决于 $mountain[i-1] < mountain[i]$ 且 $mountain[i] > mountain[i+1]$ 这一个布尔表达式，与数组其他部分无关——各下标判定**相互独立**，天然一趟遍历。
2. **严格大于，等值不算**：示例 1 的 $[2,4,4]$ 是官方埋的坑——中间的 $4$ 与右邻相等，不满足**严格**大于。比较必须用严格不等号，写成 $\ge$ 就会在等值平台上翻车。
3. **首尾排除做进循环边界**：首尾只有一侧邻居，题目直接规定不算峰。与其在循环体里判边界，不如让枚举范围本身就是 $[1, n-2]$。

$$\mathrm{ans} = \{\, i \mid 1 \le i \le n-2,\ \ mountain[i-1] < mountain[i] > mountain[i+1] \,\}$$

顺带一个输出侧性质：**相邻两个峰的下标至少相差 2**——若 $i$ 与 $i+1$ 同时为峰，则 $mountain[i] > mountain[i+1]$ 与 $mountain[i+1] > mountain[i]$ 同时成立，矛盾。故 $n$ 个元素最多 $\lfloor (n-1)/2 \rfloor$ 个峰（如 $[1,2,1,2,1]$）。

### 3.3 算法流程

![算法流程：一趟扫描 [1, n-2]](images/wc374_q1_algorithm_flow.svg)

1. **初始化**：答案数组 `ans` 置空，枚举下标 `i = 1`；
2. **判定**：若 `mountain[i-1] < mountain[i] && mountain[i] > mountain[i+1]`，把 `i` 追加进 `ans`（`&&` 短路，左侧失败即跳过右侧）；
3. **推进**：`i++`，只要 `i <= n-2` 回到第 2 步；
4. **收尾**：遍历结束返回 `ans`（无峰则返回空数组）。

### 3.4 示例演算

![示例 2 演算：逐下标判定收集峰](images/wc374_q1_example_walkthrough.svg)

以示例 2（`mountain = [1,4,3,8,5]`，$n = 5$）为例，枚举范围 $[1, 3]$：

| $i$ | $m[i-1] < m[i]$ ? | $m[i] > m[i+1]$ ? | 峰？ | `ans` |
|-----|------------------|------------------|------|-------|
| 1 | $1 < 4$ ✓ | $4 > 3$ ✓ | ✓ | `[1]` |
| 2 | $4 < 3$ ✗ | 短路，不再比较 | ✗ | `[1]` |
| 3 | $3 < 8$ ✓ | $8 > 5$ ✓ | ✓ | `[1, 3]` |

遍历结束返回 `[1, 3]` ✓。示例 1（`[2,4,4]`）中唯一候选 $i = 1$ 因 $4 > 4$ 不成立被剔除，返回 `[]`——正是「等值平台不算峰」的落点。

## 4. 算法细节

1. **枚举范围收缩**：答案只可能出现在 $[1, n-2]$，把首尾排除直接编码进循环边界，循环体内不再判 `i > 0 && i < n-1`，也杜绝了 $mountain[-1]$ / $mountain[n]$ 越界。
2. **谓词与短路**：C++ 写成 `mountain[i-1] < mountain[i] && mountain[i] > mountain[i+1]`，两个条件都要严格不等号；Python 用链式比较 `mountain[i-1] < mountain[i] > mountain[i+1]` 一行表达「严格高于两侧」，等价于 `a < b and b > c` 且短路求值。
3. **数据结构选择**：只需返回下标列表，`vector<int>` / `list[int]` 顺序收集即可；题目允许任意顺序，按升序自然产出最省事。
4. **无后处理**：各位置判定独立，收集完直接返回，不存在跨位置状态。

## 5. 正确性证明

**引理 1**：对 $1 \le i \le n-2$，位置 $i$ 是峰值当且仅当 $mountain[i-1] < mountain[i]$ 且 $mountain[i] > mountain[i+1]$。

**证明**：由题面定义，峰值 = 严格大于其**相邻元素**的元素。当 $1 \le i \le n-2$ 时位置 $i$ 恰有两个相邻元素 $i-1$、$i+1$，「严格大于所有相邻元素」逐条展开即两个严格不等式同时成立，二者等价。∎

**引理 2**：下标 $0$ 与 $n-1$ 永不为峰；且各位置的峰判定相互独立。

**证明**：首尾各只有一个相邻元素，题目明文规定其不算峰值。而位置 $i$ 的判定只读取下标 $i-1, i, i+1$ 三格，不依赖任何判定结果或外部状态，故各判定彼此独立，一趟遍历可完备完成。∎

**定理**：算法返回的集合恰为 `mountain` 的全部峰值下标。

**证明**：由引理 2，候选集为 $[1, n-2]$，算法枚举的正是该全集，无遗漏。对每个候选 $i$，由引理 1，算法采用的谓词与峰值定义逐字等价，故收进 `ans` 的皆为峰、未收的皆非峰，即返回集合 = 全部峰值下标。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。一次扫描 $[1, n-2]$，每个位置至多两次比较（短路后可能只做一次）；且要输出**全部**峰，最坏情况（如严格递增数组）必须读完每个元素才能确认答案为空，$\Omega(n)$ 是读取下界，一趟扫描已最优。
- **空间复杂度**：$O(1)$。仅循环下标与临时比较；不计返回数组（若计入，由峰间距性质至多 $\lfloor (n-1)/2 \rfloor$ 个元素）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> findPeaks(vector<int>& mountain) {
        vector<int> ans;
        int n = mountain.size();
        for (int i = 1; i < n - 1; i++) {
            if (mountain[i - 1] < mountain[i] && mountain[i] > mountain[i + 1]) {
                ans.push_back(i);
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def findPeaks(self, mountain: List[int]) -> List[int]:
        return [i for i in range(1, len(mountain) - 1)
                if mountain[i - 1] < mountain[i] > mountain[i + 1]]
```

## 8. 边界情况与易错点

1. **循环边界写成 `i < n`**：访问 `mountain[i+1]` 在 $i = n-1$ 处越界。C++ 中 `i < n - 1` 等价于 `i <= n - 2`；Python `range(1, n-1)` 右开区间恰好枚举到 $n-2$。
2. **等值平台误判**：`[2,4,4]` 中间元素与右邻相等，用 `>=` 会误判为峰。两个比较都必须是**严格**不等号。
3. **最小规模 $n = 3$**：候选只有 $i = 1$ 一个位置，如 `[1,2,1]` 输出 `[1]`；循环范围 $[1,1]$ 正常工作。
4. **无峰输入**：单调递增 / 递减 / 全等数组均返回 `[]`，无需特判，空 `ans` 自然返回。
5. **返回顺序**：题目允许任意顺序，但按升序枚举天然输出升序，不必额外说明。
