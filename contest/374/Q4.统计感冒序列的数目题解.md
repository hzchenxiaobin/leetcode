# LeetCode 统计感冒序列的数目 题解

## 1. 题目概述

- **标题 / 题号**：统计感冒序列的数目（#2954，hard）
- **链接**：https://leetcode.cn/problems/count-the-number-of-infection-sequences/
- **来源**：LeetCode 第 374 场周赛 Q4
- **难度**：困难
- **标签**：数组、数学、组合数学、费马小定理

**题意**：$n$ 位小朋友站成一排，编号 $0$ 到 $n-1$；升序数组 `sick` 给出一开始就感冒的小朋友。感冒者会把病传染给**相邻**（$i-1$ 或 $i+1$）的、存在且尚未感冒的小朋友；**每一秒至多一位**健康小朋友被传染。最终全员感冒，**感冒序列**定义为所有初始健康者被传染的先后顺序序列。求所有可能的感冒序列数目，对 $10^9 + 7$ 取模。

**约束**：

- $2 \le n \le 10^5$
- $1 \le sick.length \le n - 1$（至少一人初始感冒，且永远有人健康）
- `sick` 按升序排列

> 💡 传染只能沿相邻位置发生，初始 `sick` 把队列切成若干**独立的健康段**——每段内部的传染顺序只取决于段本身。于是答案天然分解为「段内方案数 × 段间穿插数」两个乘积，前者是 $2$ 的幂，后者是**多重集排列**，最后用**费马小定理**求逆元取模。全题没有 DP，是一道纯组合计数。

## 2. 示例

**示例 1**

```text
输入：n = 5, sick = [0, 4]
输出：4
解释：初始只有 1、2、3 健康，它们构成夹在 sick[0]=0 与 sick[4]=4 之间的中间段。
      4 种感冒序列：[1,2,3]、[1,3,2]、[3,1,2]、[3,2,1]。
```

**示例 2**

```text
输入：n = 4, sick = [1]
输出：3
解释：两段：左开放段 [0]（顺序被迫为 0）、右开放段 [2,3]（顺序被迫为 2,3）。
      穿插方式：[0,2,3]、[2,0,3]、[2,3,0]，共 3 种。
```

**示例 3**（自拟，混合三类段）

```text
输入：n = 8, sick = [1, 4, 6]
输出：120
解释：四段——左开放 [0]（m=1）、中间 [2,3]（m=2）、中间 [5]（m=1）、右开放 [7]（m=1），M = 5。
      答案 = 5!/(1!·2!·1!·1!) × 2^(2−1) × 2^(1−1) = 60 × 2 = 120（DFS 暴力对拍一致）。
```

## 3. 解题思路

### 3.1 暴力思路：DFS 枚举传染过程

把传染过程建成搜索树：状态为「已感冒集合」，每步从**当前可被传染者**（紧邻 sick 的健康小朋友）中任选一人，递归到底统计完整序列。分支数每步至多为段数 × 2，路径总数最坏是 $M!$ 量级（$M$ 为健康人数），$M \ge 20$ 就完全不可行。$n \le 10^5$ 下无望，只能退居二线当**对拍工具**（本文公式正是用它验证的：$n \le 9$ 的全部 `sick` 组合，公式与暴力输出完全一致）。

死结在于把「过程」当成整体模拟。突破口：**传染不跨段**——初始 `sick` 是静态的墙，把计数问题切成互不相干的独立子问题。

### 3.2 核心观察一：切段与段独立性

![核心观察一：初始 sick 把健康小朋友切成独立段](images/wc374_q4_segment_concept.svg)

把健康小朋友按**极大连续区间**切成段。段分三类：

- **左开放段**：$[0, sick[0]-1]$，只右端贴 sick（当 $sick[0] > 0$ 时存在）；
- **中间段**：两个相邻 sick 之间的区间，**两端都贴 sick**；
- **右开放段**：$[sick.back()+1, n-1]$，只左端贴 sick（当 $sick.back() < n-1$ 时存在）。

由传染只发生在相邻位置：任一健康小朋友的邻居 = 同段邻居 ＋ 段边界的 sick（或数组边界）。**任何一段的传染进度都不改变其它段「下一个可被传染者」是谁**——各段的内部传染顺序完全独立。于是：

$$\text{全局序列} = \text{各段内部序列的穿插}$$

### 3.3 核心观察二：段内计数——开放段 $1$ 种，中间段 $2^{m-1}$ 种

![中间段计数：首步二选一，f(m) = 2 × f(m−1)](images/wc374_q4_two_front_recursion.svg)

设段长为 $m$，段内合法传染顺序数为 $f$：

- **开放段**：只有贴 sick 的那一端能发起感染。第一个被传染的必然是紧贴 sick 的小朋友，此后它成为新的 sick，剩余部分还是开放段。归纳得顺序**完全被迫**（如 $[2,3]$ 只能 $2 \to 3$）：$f = 1$。
- **中间段**（$m \ge 2$）：第一个被传染的只能是最左或最右——只有这两端紧贴 sick，内部小朋友只挨着健康者。二选一之后（比如最左者 $a$ 先病），剩余 $m-1$ 人夹在 sick(a) 与右端 sick 之间，**还是同型的中间段**。于是
  $$f(m) = 2 \times f(m-1), \quad f(1) = 1 \implies f(m) = 2^{m-1}$$
  验证：$m=2 \to 2$ 种，$m=3 \to 4$ 种（正是示例 1）。

> 💡 直觉版本：任意时刻段内已感染者 = **左前缀 ∪ 右后缀**，每步选一端推进；最后剩一人时两条路合流，不产生新选择，故是 $2^{m-1}$ 而非 $2^m$。递推 $f(m) = 2f(m-1)$ 则自动处理了这个合流。

### 3.4 核心观察三：段间穿插 = 多重集排列

![全局序列 = 各段内部序列的穿插](images/wc374_q4_interleave_multinomial.svg)

段内顺序各自确定后，全局序列只差「各段元素谁排在前」的**穿插**方式。把 $M = n - |sick|$ 个时间槽分给各段（段 $i$ 占 $m_i$ 个、槽内顺序已由段内序列锁定），穿插数即**多重集排列**：

$$\binom{M}{m_1}\binom{M-m_1}{m_2}\cdots = \frac{M!}{m_1!\, m_2! \cdots m_p!}$$

**总公式**：

$$\boxed{\;\text{ans} = \frac{M!}{\prod_i m_i!} \times \prod_{\text{中间段 } i} 2^{m_i - 1}\;}$$

其中 $M = n - |sick|$ 为健康总人数（即 $\sum_i m_i$），$p$ 为非空段数；开放段只贡献分母的 $m_i!$，中间段额外乘 $2^{m_i-1}$。

> ⚠️ 「每秒**至多**一人」不会额外约束序列：只要还有健康者，就一定有人紧贴 sick 可被传染，穿插中的每一步都能落到某个时间秒上（空秒跳过即可），序列计数与时间无关。

### 3.5 示例演算

![示例演算：两个官方样例与一个自拟混合样例](images/wc374_q4_example_walkthrough.svg)

- **例 1**（$n=5$，`sick=[0,4]`）：唯一段是中间段 $[1,2,3]$（$m=3$）。段内 $2^{3-1}=4$ 种，穿插 $\frac{3!}{3!}=1$，答案 $4$ ✓。
- **例 2**（$n=4$，`sick=[1]`）：左开放 $[0]$、右开放 $[2,3]$，段内均 $1$ 种；穿插 $\frac{3!}{1!\,2!}=3$，答案 $3$ ✓。
- **自拟**（$n=8$，`sick=[1,4,6]`）：$\frac{5!}{1!\,2!\,1!\,1!} \times 2^1 \times 2^0 = 120$，与暴力枚举一致 ✓。

## 4. 算法细节

1. **段的划分**（`sick` 已升序，无需排序）：左开放段长 $sick[0]$；中间段长 $sick[i] - sick[i-1] - 1$（相邻 `sick` 间的 gap）；右开放段长 $n - 1 - sick.back()$。长度为 $0$ 的段**直接跳过**。
2. **阶乘与逆元表**：预计算 $fact[0..M]$；由费马小定理（$p = 10^9+7$ 为质数，$a^{p-2} \equiv a^{-1} \pmod p$）先求 $invfact[M] = fact[M]^{p-2}$，再线性回推 $invfact[i-1] = invfact[i] \cdot i$。
3. **$2$ 的幂**：每个非空中间段乘一次 $\text{pow}(2, m_i-1)$。因 $\log m_i \le m_i$，各段快速幂总耗时 $\le O(M)$；也可直接预处理 $[0, M]$ 的 $2$ 的幂表。
4. **组装公式**：$ans = fact[M] \times \prod invfact[m_i] \times \prod_{\text{中间段}} 2^{m_i-1}$，每乘一步立即取模。
5. **自检**：各段长度之和应等于 $M = n - |sick|$，可作为实现的断言条件。

## 5. 正确性证明

**引理 1（段独立引理）**：任一时刻，某段内一个健康小朋友可被传染，当且仅当它紧邻段内已传染者或段边界 sick；该条件与其它段的传染进度无关。

**证明**：传染只发生在相邻位置之间。段是极大连续健康区间，段内成员的邻居仅有：同段成员、段边界的 sick（恒为 sick）、数组边界（无小朋友）。故「段内已感冒集合」完全决定本段的可传染集合。∎

**引理 2（穿插双射引理）**：全局合法感冒序列与「（各段合法段内序列，穿插方案）」一一对应；从而全局序列数 = $\prod_i f_i \times \frac{M!}{\prod m_i!}$，其中 $f_i$ 为段 $i$ 的段内序列数。

**证明**：（正向）取全局序列 $S$，把每段元素按出现顺序抽出得 $S_i$。$S$ 中段 $i$ 的元素 $x$ 被传染时，其传染源是紧邻的 sick——要么是段边界 sick，要么是同段更早者 $y$；两种情况都保证 $S_i$ 中 $x$ 的紧邻前驱（或边界）已满足传染条件，故 $S_i$ 是段 $i$ 的合法序列。穿插方案由 $S$ 中各段元素的下标位置唯一确定。
（反向）给定各段合法序列 $S_i$ 与穿插方案 $T$，按 $T$ 逐个传染：轮到段 $i$ 的下一个元素 $x$ 时，由 $S_i$ 合法性，$x$ 紧邻段边界 sick 或 $S_i$ 中更早的 $y$；$y$ 在 $T$ 中更靠前故已 sick，传染合法。「至多一人/秒」不影响——把 $M$ 次传染放到任意 $M$ 个时刻即可。
两构造互逆，且穿插方案数为多重集排列 $\frac{M!}{\prod m_i!}$。∎

**引理 3（开放段计数）**：长度 $m \ge 1$ 的开放段内部合法序列唯一。

**证明**：不妨设段为 $[s-m, s-1]$、右端贴 sick $s$。第一个被传染者只能是紧贴 $s$ 的 $s-1$（其余成员只紧邻同段健康者与数组边界）。此后 $s-1$ 为新 sick，剩余部分是同型开放段。归纳得唯一顺序 $s-1, s-2, \dots, s-m$。∎

**引理 4（中间段计数）**：长度 $m$ 的中间段内部合法序列数 $f(m) = 2^{m-1}$。

**证明**：对 $m$ 归纳。$m=1$：唯一成员紧贴 sick，恰 $1 = 2^0$ 种。$m \ge 2$：第一个被传染者必须紧贴某端 sick，即最左或最右成员（中间成员只紧邻健康者，不可选），恰 $2$ 个候选。设最左者 $a$ 先病：由引理 1，其后的段内过程与外界无关，且剩余 $m-1$ 人夹在 sick(a) 与右端 sick 之间，是规模 $m-1$ 的中间段——（首步选择，剩余合法序列）与完整合法序列显然双射。故 $f(m) = 2 f(m-1)$，展开即 $2^{m-1}$。∎

**定理（主公式）**：$\text{ans} = \frac{M!}{\prod_i m_i!} \times \prod_{\text{中间段}} 2^{m_i - 1}$。

**证明**：由引理 2，答案 = $\prod_i f_i \times \frac{M!}{\prod m_i!}$；由引理 3、4，开放段 $f_i = 1$、中间段 $f_i = 2^{m_i-1}$。代入即得。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。段划分 $O(|sick|)$；阶乘与逆元表 $O(M)$（$M \le n$）；主循环至多 $|sick|+1$ 个段，每段一次逆元乘法 $O(1)$、中间段一次快速幂 $O(\log m_i)$，而 $\sum \log m_i \le \sum m_i = M$，总计仍为 $O(n)$。
- **空间复杂度**：$O(M)$，两张阶乘表（$M = n - |sick| \le n - 1$）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int numberOfSequence(int n, vector<int>& sick) {
        const long long MOD = 1e9 + 7;
        int m = n - (int)sick.size();
        vector<long long> fact(m + 1), invFact(m + 1);
        fact[0] = 1;
        for (int i = 1; i <= m; i++) fact[i] = fact[i - 1] * i % MOD;
        auto mpow = [&](long long b, long long e) {
            long long r = 1;
            for (; e; e >>= 1, b = b * b % MOD)
                if (e & 1) r = r * b % MOD;
            return r;
        };
        invFact[m] = mpow(fact[m], MOD - 2);
        for (int i = m; i >= 1; i--) invFact[i - 1] = invFact[i] * i % MOD;

        long long ans = fact[m];
        if (sick[0] > 0) ans = ans * invFact[sick[0]] % MOD;
        if (sick.back() < n - 1) ans = ans * invFact[n - 1 - sick.back()] % MOD;
        for (int i = 1; i < (int)sick.size(); i++) {
            int gap = sick[i] - sick[i - 1] - 1;
            if (gap > 0) ans = ans * invFact[gap] % MOD * mpow(2, gap - 1) % MOD;
        }
        return (int)ans;
    }
};
```

### Python

```python
class Solution:
    def numberOfSequence(self, n: int, sick: List[int]) -> int:
        MOD = 10 ** 9 + 7
        m = n - len(sick)
        fact = [1] * (m + 1)
        for i in range(1, m + 1):
            fact[i] = fact[i - 1] * i % MOD
        inv_fact = [1] * (m + 1)
        inv_fact[m] = pow(fact[m], MOD - 2, MOD)
        for i in range(m, 0, -1):
            inv_fact[i - 1] = inv_fact[i] * i % MOD

        ans = fact[m]
        if sick[0] > 0:
            ans = ans * inv_fact[sick[0]] % MOD
        if sick[-1] < n - 1:
            ans = ans * inv_fact[n - 1 - sick[-1]] % MOD
        for a, b in zip(sick, sick[1:]):
            gap = b - a - 1
            if gap > 0:
                ans = ans * inv_fact[gap] % MOD * pow(2, gap - 1, MOD) % MOD
        return ans
```

## 8. 边界情况与易错点

1. **空段必须跳过**：相邻 `sick`（如 `sick=[3,4]`）的 gap 为 $0$，若不 `if (gap > 0)` 就会算出 $2^{-1}$——Python 的 `pow(2, -1, MOD)` 会悄悄返回 $2$ 的逆元（错值），C++ 的快速幂传负指数则直接死循环/错果。这是本题最常见的实现 bug。
2. **指数是 $m-1$ 不是 $m$**：单成员中间段贡献 $2^0 = 1$；把 $m=1$ 段也算成 $2$ 倍是最典型的手滑。
3. **除法必须走逆元**：$fact[M]$ 已取模，直接整除再取模是错的；MOD $= 10^9+7$ 为质数才能用费马小定理。
4. **开放段别忘乘 $1/m_i!$**：开放段虽无 $2$ 的幂因子，但它占用穿插槽位，分母里的 $m_i!$ 一个都不能少。
5. **sick 已升序**：题目保证升序，直接 `zip(sick, sick[1:])`；但不要顺手假设它「恰好一个元素」等特例。
6. **端点段的判断**：左开放段存在当且仅当 `sick[0] > 0`，右开放段当且仅当 `sick.back() < n - 1`；两者都可能在 `sick = [0]` 或 `sick = [n-1]` 时缺席。
7. **M 的范围**：由 $1 \le |sick| \le n-1$ 得 $1 \le M \le n-1$，阶乘表从 $fact[0]$ 起步即可，无需 $M=0$ 特判。
8. **溢出**：C++ 用 `long long` 且每步乘完立即取模（单次乘法 $< 10^{18}$ 安全）；累乘到底再取模必然溢出。
