# LeetCode 位计数深度为 K 的整数数目 I 题解

## 1. 题目概述

- **标题 / 题号**：位计数深度为 K 的整数数目 I（#3621，hard）
- **链接**：https://leetcode.cn/problems/number-of-integers-with-popcount-depth-equal-to-k-i/
- **来源**：LeetCode 第 161 场双周赛 Q4
- **难度**：困难
- **标签**：位运算、数学、动态规划、组合数学

**题意**：对正整数 $x$ 定义序列 $p_0 = x$，$p_{i+1} = \operatorname{popcount}(p_i)$（二进制中 $1$ 的个数）。序列最终到达 $1$。$x$ 的 **popcount-depth** 为使 $p_d = 1$ 的**最小** $d \ge 0$。给定 $n, k$，返回 $[1, n]$ 中 popcount-depth **恰好等于** $k$ 的整数个数。

注意 $x = 1$ 的深度是 $0$（$p_0 = 1$ 已经满足）。

**约束**：

- $1 \le n \le 10^{15}$
- $0 \le k \le 5$

$n$ 的二进制位数不超过 $50$，这是本题一切优化的基础；$n$ 太大以至于不可能逐个枚举。

## 2. 示例

**示例 1**

```text
输入：n = 4, k = 1
输出：2
解释：x = 2（10 → 1）与 x = 4（100 → 1）深度为 1；
      x = 1 深度 0，x = 3（11 → 2 → 1）深度 2。答案 2。
```

**示例 2**

```text
输入：n = 7, k = 2
输出：3
解释：x = 3、5、6 的深度都是 2（例如 5 → 2 → 1）。答案 3。
```

**示例 3（自造，检查 k = 0）**

```text
输入：n = 100, k = 0
输出：1
解释：只有 x = 1 的深度为 0，故答案为 1。
```

## 3. 解题思路

### 3.1 暴力思路

对 $x = 1, 2, \dots, n$ 逐个模拟 popcount 链，累加步数。每一步至少把数「压」到 $\le 60$，之后最多再走 $4 \sim 5$ 步，所以单个数 $O(\log x)$。总复杂度 $O(n \log n)$，当 $n = 10^{15}$ 时完全不可行。

### 3.2 核心观察：深度只取决于 popcount 的值

![popcount 链：每走一步把 x 换成它的 1 的个数](images/bw161_q4_popcount_chain.svg)

关键递推：

$$\operatorname{depth}(x) = 1 + \operatorname{depth}\big(\operatorname{popcount}(x)\big) \quad (x > 1), \qquad \operatorname{depth}(1) = 0$$

因为第一步之后数就变成 $\operatorname{popcount}(x)$，而 $\operatorname{popcount}(x) \le 50 \ll x$（$x > 1$ 时严格变小），所以**后续链与 $x$ 的具体数值无关，只与 popcount 的值 $j$ 有关**。

于是把问题拆成两层：

1. **内层（很小的表）**：预处理 $\text{dep}[j] = \operatorname{depth}(j)$，$j \le 64$，直接暴力递归即可。
2. **外层（计数）**：统计 $[1, n]$ 中有多少个数的 popcount **恰好等于** $j$，记作 $\text{cnt}[j]$，则

$$\text{answer} = \sum_{j \ge 1,\ 1 + \text{dep}[j] = k} \text{cnt}[j]$$

（$x = 1$ 需要单独从 $\text{cnt}[1]$ 里扣掉，见 §4。）

### 3.3 算法流程：按二进制位做数位统计

![按 popcount 分类：先数「恰好 j 个 1」的整数，再看 depth(j)](images/bw161_q4_digit_split.svg)

数 $\text{cnt}[j]$ 用经典的「数位 + 组合数」方法。设 $n$ 的二进制有 $L$ 位（最高位权重 $2^{L-1}$）。把所有 $\le n$ 的正整数按「**第一个与 $n$ 不同的位**」分成互不相交的若干类：

- 从高位到低位扫描，设当前已经固定了若干个 $1$（记作 `ones`），扫到第 $p$ 位（权重 $2^p$）且 $n$ 的该位为 $1$：
  - 把这一位取 $0$（此时前缀已经严格小于 $n$），低 $p$ 位可以任意取。若低 $p$ 位里放 `add` 个 $1$，则这个数的 popcount 为 $\text{ones} + \text{add}$，方案数 $\binom{p}{\text{add}}$；
  - 把这一位取 $1$ 继续与 $n$ 的前缀相同，`ones += 1`。
- 扫描结束后，`ones` 就是 $n$ 自己的 popcount，把 $n$ 本身补计一次。
- 注意「全部取 $0$」的那一类会数到 $x = 0$，最后统计时只累加 $j \ge 1$ 即可排除。

组合数 $\binom{p}{add}$ 预先打表（$p \le 50$），每次枚举是 $O(L^2)$，$L \le 50$，非常快。

### 3.4 示例演算

![示例演算：n = 4 时按「1 的个数」分桶，n = 7 同理](images/bw161_q4_example_walkthrough.svg)

**示例 1（$n = 4 = 100_2$，$k = 1$）**

逐个数验证：$1 \to 1$（深度 $0$）、$2 \to 1$（$1$）、$3 \to 2 \to 1$（$2$）、$4 \to 1$（$1$）。

按 popcount 分桶：$j = 1$ 的有 $\{1, 2, 4\}$（3 个），$j = 2$ 的有 $\{3\}$（1 个）。
$\text{dep}[1] = 0 \Rightarrow 1 + 0 = 1 = k$，$\text{dep}[2] = 1 \Rightarrow 1 + 1 = 2 \ne k$。
故答案 $= \text{cnt}[1] - 1 = 3 - 1 = 2$（减去 $x = 1$）。

**示例 2（$n = 7$，$k = 2$）**

分桶：$j = 1:\{1,2,4\}$，$j = 2:\{3,5,6\}$，$j = 3:\{7\}$。
$\text{dep}[2] = 1$，所以 $1 + 1 = 2 = k$，答案 $= \text{cnt}[2] = 3$。✓

## 4. 算法细节

1. **$x = 1$ 是唯一的例外**：它的深度是 $0$，但按递推 $1 + \text{dep}[\operatorname{popcount}(1)] = 1 + 0 = 1$ 会把它算成深度 $1$。因此 `k == 1` 时要从结果里减去 $1$。
2. **`k == 0` 直接返回 $1$**：只有 $x = 1$ 满足（$n \ge 1$ 恒成立）。
3. **组合数表必须清零**：$\binom{i}{j}$ 的递推会访问 $\binom{i-1}{j}$，当 $j > i-1$ 时应视为 $0$。C++ 中写 `long long C[MAXB + 1][MAXB + 1] = {};` 才能保证这一点（这是本题最容易踩的实现坑）。
4. **位数上界**：$n \le 10^{15} < 2^{50}$，所以 `bits ≤ 50`，`cnt` 只需 66 个槽位；但仍按 $64$ 打表，留足余量。
5. **`popcount` 的实现**：C++ 用 `__builtin_popcount((unsigned)j)`（$j \le 65$，安全）；Python 用 `bin(j).count("1")`。
6. **组合数不会溢出**：$\binom{50}{25} \approx 1.26\times10^{14}$，`long long` 足够；但若把上界误设成 $64$，$\binom{64}{32} \approx 1.83\times10^{18}$ 已逼近 `long long` 上限，因此**不要为了「通用」把 MAXB 开到 70 以上**。
7. **答案范围**：不超过 $n$，`long long` 安全。
8. **为什么 $j$ 只到 `bits`**：popcount 不可能超过位数，统计循环写 `j <= bits` 即可。

## 5. 正确性证明

**引理 1（链良定义）**：对任意 $x \ge 1$，序列 $p_0 = x$，$p_{i+1} = \operatorname{popcount}(p_i)$ 必在有限步内到达 $1$，故深度定义良好。

**证明**：$x = 1$ 时 $p_0 = 1$ 已达。$x \ge 2$ 时 $\operatorname{popcount}(x) \le \lfloor \log_2 x\rfloor + 1 < x$（因 $2^{t} > t + 1$ 对 $t \ge 2$ 成立，且 $x \ge 2$ 时 $\log_2 x \ge 1$），故序列严格递减，必然降到 $1$（$1$ 是不动点）。∎

**引理 2（递推式）**：对 $x \ge 2$，$\operatorname{depth}(x) = 1 + \operatorname{depth}(\operatorname{popcount}(x))$。

**证明**：设 $j = \operatorname{popcount}(x)$，$x \ge 2$ 故 $j \ge 1$。若 $j = 1$，则 $p_1 = 1$，深度为 $1$，右式为 $1 + 0 = 1$ ✓。若 $j \ge 2$，则 $x$ 的链从第 $1$ 项起就是 $j$ 的链，故 $\operatorname{depth}(x) = 1 + \operatorname{depth}(j)$。∎

**引理 3（分桶计数不重不漏）**：上述按「首个与 $n$ 不同的二进制位」分类，恰好把 $[0, n]$ 的每个整数计入一次，且计入的桶下标等于其 popcount。

**证明**：对任意 $0 \le x \le n$，若 $x = n$ 归入最后补计的一次；否则设 $p$ 是 $x$ 与 $n$ 最高不同的位，则 $n$ 的第 $p$ 位为 $1$、$x$ 的该位为 $0$（否则 $x > n$），更高位完全相同。算法在扫到 $p$ 时恰好把「高位与 $n$ 相同、第 $p$ 位取 $0$、低位任意」的全部数枚举一遍，$x$ 属于且仅属于这一批。该批中每个数的 popcount 都是「已固定的 `ones` 个 $1$」加上「低 $p$ 位中的 `add` 个 $1$」，方案数正是从 $p$ 个位置里选 `add` 个的 $\binom{p}{add}$。∎

**定理**：算法返回值等于 $[1, n]$ 中 popcount-depth 恰为 $k$ 的整数个数。

**证明**：由引理 3，$\text{cnt}[j]$ 恰好统计了 $[0, n]$ 中 popcount 为 $j$ 的整数个数。由引理 2，对 $x \ge 2$ 有 $\operatorname{depth}(x) = 1 + \text{dep}[\operatorname{popcount}(x)]$，故 $x$ 的深度为 $k$ 当且仅当 $1 + \text{dep}[j] = k$（$j = \operatorname{popcount}(x)$）。累加时只取 $j \ge 1$，排除了 $x = 0$（$x = 0$ 的 popcount 为 $0$，本就不在 $[1,n]$ 内）。最后对 $k = 1$ 减去 $x = 1$ 这一次误计（$x = 1$ 的真实深度是 $0$），对 $k = 0$ 单独返回唯一的 $x = 1$。因此统计结果精确等于所求个数。∎

## 6. 复杂度分析

- **时间**：组合数打表 $O(M^2)$（$M = 64$）；预处理 $\text{dep}$ 为 $O(M\log M)$；数位枚举为 $O(L^2)$（$L \le 50$，因为每个为 $1$ 的位要枚举一次 `add`）。整体 $O(M^2 + L^2)$，即常数级。
- **空间**：$O(M^2)$ 存组合数表（$65 \times 65 \times 8$ 字节约 $34$ KB），$O(M)$ 存 $\text{dep}$ 与 $\text{cnt}$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long popcountDepth(long long n, int k) {
        if (k == 0) return n >= 1 ? 1 : 0;   // 只有 x = 1 的深度为 0
        const int MAXB = 64;
        int dep[MAXB + 2];
        dep[1] = 0;
        for (int j = 2; j <= MAXB + 1; j++) {
            int c = __builtin_popcount((unsigned)j);
            dep[j] = 1 + dep[c];
        }
        long long C[MAXB + 1][MAXB + 1] = {};   // 必须清零：C[i-1][j] 在 j > i-1 处为 0
        for (int i = 0; i <= MAXB; i++) {
            C[i][0] = 1;
            for (int j = 1; j <= i; j++) C[i][j] = C[i - 1][j - 1] + C[i - 1][j];
        }
        int bits = 0;
        while ((1LL << bits) <= n) bits++;      // n 的二进制位数
        long long cnt[MAXB + 2] = {0};          // cnt[j] = [1, n] 中 popcount 为 j 的个数
        int ones = 0;
        for (int p = bits - 1; p >= 0; p--) {
            if ((n >> p) & 1LL) {
                for (int add = 0; add <= p; add++) cnt[ones + add] += C[p][add];
                ones++;
            }
        }
        cnt[ones] += 1;                          // n 本身
        long long ans = 0;
        for (int j = 1; j <= bits; j++) {
            if (1 + dep[j] == k) ans += cnt[j];
        }
        if (k == 1) ans -= 1;                    // 去掉 x = 1（深度 0）
        return ans;
    }
};
```

### Python

```python
class Solution:
    def popcountDepth(self, n: int, k: int) -> int:
        if k == 0:
            return 1 if n >= 1 else 0   # 只有 x = 1 的深度为 0
        MAXB = 64
        dep = [0] * (MAXB + 2)
        dep[1] = 0
        for j in range(2, MAXB + 2):
            dep[j] = 1 + dep[bin(j).count("1")]
        # 组合数
        C = [[0] * (MAXB + 1) for _ in range(MAXB + 1)]
        for i in range(MAXB + 1):
            C[i][0] = 1
            for j in range(1, i + 1):
                C[i][j] = C[i - 1][j - 1] + C[i - 1][j]
        bits = n.bit_length()
        cnt = [0] * (MAXB + 2)      # cnt[j] = [1, n] 中 popcount 为 j 的个数
        ones = 0
        for p in range(bits - 1, -1, -1):
            if (n >> p) & 1:
                for add in range(p + 1):
                    cnt[ones + add] += C[p][add]
                ones += 1
        cnt[ones] += 1              # n 本身
        ans = sum(cnt[j] for j in range(1, bits + 1) if 1 + dep[j] == k)
        if k == 1:
            ans -= 1                # 去掉 x = 1（深度 0）
        return ans
```

## 8. 边界情况与易错点

1. **$x = 1$ 的深度是 $0$ 而不是 $1$**：这是本题第一大坑。若不做减法，$k = 1$ 的答案会多 $1$。
2. **$k = 0$**：只有 $x = 1$，答案 $1$（$n \ge 1$）；不要让它走主逻辑。
3. **组合数表未清零**：C++ 的 `long long C[65][65];` 若不初始化，$\binom{i-1}{j}$（$j > i-1$）读到的就是垃圾值，答案会出现 $10^{18}$ 级别的错误。必须 `= {}`。
4. **$n$ 本身要补计**：数位枚举只覆盖「严格小于 $n$ 的数」，最后 `cnt[ones] += 1` 补上 $n$。
5. **$x = 0$ 不能被计入**：枚举中会数到 $0$，靠「只累加 $j \ge 1$」排除。
6. **`1LL << bits` 的边界**：用 `while ((1LL << bits) <= n) bits++` 求位数，$n \le 10^{15}$ 时 `bits ≤ 50`，不会移位越界；但若 $n$ 接近 $2^{63}$ 则要小心。
7. **`popcount` 的有符号性**：`__builtin_popcount` 接收 `unsigned int`，传负数会出错；这里只传 $\le 65$ 的正数，安全。
8. **`int` 与 `long long`**：`cnt` 与答案都用 `long long`（单个桶可达 $10^{14}$）。
9. **上界不要贪多**：把 MAXB 开到 $70$ 会让组合数逼近 `long long` 上限，反而有溢出风险。
