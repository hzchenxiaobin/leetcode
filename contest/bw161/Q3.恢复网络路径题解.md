# LeetCode 恢复网络路径 题解

## 1. 题目概述

- **标题 / 题号**：恢复网络路径（#3620，hard）
- **链接**：https://leetcode.cn/problems/network-recovery-pathways/
- **来源**：LeetCode 第 161 场双周赛 Q3
- **难度**：困难
- **标签**：图、拓扑排序、二分查找、动态规划、最短路、堆（优先队列）

**题意**：给定 $n$ 个节点（编号 $0 \sim n-1$）的**有向无环图**，`edges[i] = [u, v, cost]` 表示 $u \to v$ 的通信恢复成本。`online[i]` 表示节点 $i$ 是否在线，且 $0$ 与 $n-1$ 恒在线。

一条 $0 \to n-1$ 的路径**有效**当且仅当：

1. 路径上所有**中间节点**都在线；
2. 路径所有边的成本之和 $\le k$。

每条有效路径的**分数** = 该路径上**最小边成本**。返回所有有效路径中的最大分数；不存在有效路径则返回 $-1$。

**约束**：

- $2 \le n \le 5 \times 10^4$
- $0 \le m \le \min(10^5, n(n-1)/2)$
- $0 \le \text{cost}_i \le 10^9$，注意成本**可以为 $0$**
- $0 \le k \le 5 \times 10^{13}$
- 输入保证是有向无环图

成本之和最大 $10^5 \times 10^9 = 10^{14}$，$k$ 也有 $5 \times 10^{13}$ 量级，所有距离必须用 64 位整数。

## 2. 示例

**示例 1**

```text
输入：edges = [[0,1,5],[1,3,10],[0,2,3],[2,3,4]], online = [true,true,true,true], k = 10
输出：3
解释：路径 0→1→3 总成本 15 > 10，无效；
      路径 0→2→3 总成本 7 ≤ 10，有效，分数 min(3,4) = 3；
      因此答案是 3。
```

**示例 2**

```text
输入：edges = [[0,1,7],[1,4,5],[0,2,6],[2,3,6],[3,4,2],[2,4,6]],
      online = [true,true,true,false,true], k = 12
输出：6
解释：节点 3 离线，凡经过 3 的路径都无效；
      0→1→4 成本 12 ≤ 12，分数 5；
      0→2→4 成本 12 ≤ 12，分数 6；
      最大分数为 6。
```

**示例 3（自造，检查成本为 0）**

```text
输入：edges = [[0,1,0],[1,2,0]], online = [true,true,true], k = 0
输出：0
解释：唯一路径成本 0 ≤ 0，分数 min(0,0) = 0。
```

## 3. 解题思路

### 3.1 暴力思路

直接枚举 $0 \to n-1$ 的所有路径，逐一检查「中间节点在线、总成本 $\le k$」，再取分数最大值。DAG 上路径条数可以指数级（例如分层完全二部图），$n = 5\times10^4$ 完全不可行。

退一步：能否枚举「分数」，即枚举路径上的最小边？如果固定阈值 $x$，只允许走成本 $\ge x$ 的边，问题就退化为「在子图上求 $0 \to n-1$ 的最短（总成本）路径，判断是否 $\le k$」。这正是暴力的可用骨架，但枚举 $x$ 的取值太多。

### 3.2 核心观察：对阈值二分，判定退化为 DAG 上的 DP

![二分「最小边成本阈值」：阈值越大，可用边越少](images/bw161_q3_binary_search.svg)

定义判定函数

$$\text{check}(x) = \big[\text{只保留 cost} \ge x \text{ 的边时，} 0 \to n-1 \text{ 的最短总成本} \le k\big]$$

它有两个关键性质：

- **单调性**：$x$ 增大只会**删掉**边，不新增边，因此最短总成本**单调不减**。于是 $\text{check}(x)$ 形如「前面一段为真、后面一段为假」。
- **答案必是某条边的成本**：设最优路径 $P^*$ 的分数为 $s = \min_{e \in P^*} c_e$，则 $s$ 恰等于 $P^*$ 上某条边的成本。而对所有 $x \le s$，$P^*$ 的边全部可用，故 $\text{check}(x)$ 为真；对 $x > s$，分数 $\ge x$ 的路径都不存在，$\text{check}(x)$ 为假。

两点合起来：$\text{check}$ 的最大可行 $x$ 就是答案，可以在 $[0, \max \text{cost}]$ 上二分，共 $O(\log 10^9) \approx 30$ 轮。

由于图是 DAG，$\text{check}$ 不需要 Dijkstra：按**拓扑序**做一遍 DP 即可，$O(n + m)$：

$$\text{dist}[v] = \min_{(u,v,c),\, c \ge x}\big(\text{dist}[u] + c\big)$$

再叠加「中间节点必须在线」：只要在松弛时跳过**离线节点**的出边即可（$0$ 与 $n-1$ 恒在线，无需特判）。

![示例演算：二分阈值后只需在 DAG 上跑一次 DP](images/bw161_q3_check_dp.svg)

### 3.3 算法流程

```text
1. 建邻接表 g[u] = [(v, c)]，统计入度；记录 maxCost = max c
2. Kahn 拓扑排序得到 order（输入保证是 DAG，order 长度为 n）
3. 若 check(0) 为假 → 没有总成本 ≤ k 的路径（所有边都允许走）→ 返回 -1
4. 在 [0, maxCost] 上二分最大的 x 使 check(x) 为真：
       lo = 0, hi = maxCost
       while lo < hi:
           mid = ⌈(lo + hi) / 2⌉
           若 check(mid): lo = mid，否则 hi = mid − 1
5. 返回 lo
```

其中 `check(x)`：

```text
dist[0] = 0，其余为 INF
for u in order:
    若 dist[u] 为 INF 或 u 离线: 跳过
    for (v, c) in g[u]:
        若 c < x: 跳过
        dist[v] = min(dist[v], dist[u] + c)
返回 dist[n−1] ≤ k
```

### 3.4 示例演算

以示例 1 为例（$k = 10$，边成本为 $5, 10, 3, 4$）：

| 阈值 $x$ | 保留的边 | 最短总成本 | $\le 10$？ |
|---|---|---|---|
| 10 | 1→3 (10) | 不可达（0 无出边） | ✗ |
| 6 | 1→3 (10) | 不可达 | ✗ |
| 5 | 0→1 (5)、1→3 (10) | $5 + 10 = 15$ | ✗ |
| 4 | 上面两条 + 2→3 (4) | $15$（0→2 被删） | ✗ |
| 3 | 全部四条 | $0 \to 2 \to 3 = 7$ | ✓ |

二分最终停在 $x = 3$，即答案 $3$，与题面一致。

再以示例 2 为例：节点 3 离线，所以 $2 \to 3$、$1 \to 3$（若有）都被掐断，只剩 $0\to1\to4$ 与 $0\to2\to4$ 两条，分数分别 $5$ 与 $6$；阈值取 $6$ 时前者被删、后者仍可行，答案为 $6$。

## 4. 算法细节

1. **拓扑序只算一次**：二分有 30 轮，每轮都重新拓扑排序会多花 $30 \times O(n+m)$；入度是静态的，拓扑序可以复用。
2. **离线节点的处理位置**：在**出边端**过滤（`if (!online[u]) continue;`）。若在入边端过滤（只允许 $v$ 在线），会漏掉「$v$ 离线但路径本可以绕过它」的判断；实际上只要保证路径不**经过**离线节点，两种过滤等价，但出边端更省事。
3. **成本为 0 的边**：因此答案可能是 $0$，二分下界必须是 $0$ 而不是 $1$；同时 `check(0)` 用全部边，是「是否存在任何有效路径」的判定，必须先跑一次，否则二进制搜索会误返回 $0$ 而不是 $-1$。
4. **`mid` 向上取整**：找「最大的可行值」时用 `mid = lo + (hi - lo + 1) / 2`，否则 $lo = mid$ 会死循环。
5. **INF 的选取**：`LLONG_MAX / 4`，避免 `dist[u] + c` 溢出；Python 用 `float('inf')` 即可。
6. **重边**：同一对 $(u,v)$ 可以有多条不同成本的边，`g` 用邻接表天然支持；DP 会取其中最优者。
7. **`check(0)` 的返回值与 $k$ 的关系**：$k$ 可以等于 $0$，此时只有全零成本的路径可行，`dist[n-1] <= k` 依然正确。
8. **复杂度常数**：每轮 `check` 都要 `vector` 初始化为 INF（$O(n)$），30 轮共 $3 \times 10^6$ 次写，可接受。

## 5. 正确性证明

**引理 1（`check` 单调）**：若 $x_1 \le x_2$，则 $\text{check}(x_2) \Rightarrow \text{check}(x_1)$。

**证明**：阈值 $x_2$ 允许的边集 $E_{\ge x_2} \subseteq E_{\ge x_1}$。任何在 $E_{\ge x_2}$ 中成立的 $0 \to n-1$ 路径同样在 $E_{\ge x_1}$ 中成立，且总成本相同，故 $E_{\ge x_1}$ 下的最短总成本不超过 $E_{\ge x_2}$ 下的最短总成本。若后者 $\le k$，前者也 $\le k$。∎

**引理 2（拓扑 DP 正确）**：对固定阈值 $x$，算法算出的 $\text{dist}[v]$ 等于「只走成本 $\ge x$ 的边、不经过离线节点」时 $0 \to v$ 的最小总成本。

**证明**：对拓扑序归纳。$\text{dist}[0] = 0$ 是空路径的成本。设处理到 $u$ 时，所有拓扑序在 $u$ 之前的节点 $w$ 都已有正确的 $\text{dist}[w]$。若存在到 $u$ 的最优路径，其最后一条边是 $(w, u, c)$，$w$ 必在 $u$ 之前被处理，且 $c \ge x$、$w$ 在线（否则该路径非法），于是松弛 $\text{dist}[u] \le \text{dist}[w] + c$ 取到该路径成本；又每次松弛都对应一条真实合法的路径（拼接），故 $\text{dist}[u]$ 不会小于真实最优值。两者相等。∎

**引理 3（最优分数是某条边的成本）**：若存在有效路径，则最大分数 $s^*$ 等于某条边的成本。

**证明**：任取一条分数最大的有效路径 $P$，$s^* = \min_{e\in P} c_e$，最小值必在 $P$ 的某条边上取到（有限非空集合），该边的成本即 $s^*$。∎

**定理**：算法返回值为所有有效路径分数的最大值；无有效路径时返回 $-1$。

**证明**：

*存在性*：若不存在有效路径，则 $E_{\ge 0}$（即全部边）下 $0 \to n-1$ 的最短总成本 $> k$，由引理 2，`check(0)` 为假，算法返回 $-1$，正确。

*最优性*：设最大分数为 $s^*$。由引理 3，$s^*$ 是某条边的成本，且 $\text{check}(s^*)$ 为真（取到 $s^*$ 的那条路径的所有边成本 $\ge s^*$，总成本 $\le k$）。对任意 $x > s^*$，若 $\text{check}(x)$ 为真，则存在一条所有边成本 $\ge x$、总成本 $\le k$ 的路径，其分数 $\ge x > s^*$，与 $s^*$ 的最大性矛盾。所以 $\text{check}(x)$ 对所有 $x > s^*$ 为假。由引理 1 的单调性，二分会收敛到满足 $\text{check}$ 的最大整数，即 $s^*$。∎

## 6. 复杂度分析

- **时间**：
  - 建图与拓扑排序 $O(n + m)$；
  - 二分共 $\lceil \log_2(\max\text{cost} + 1)\rceil \le 30$ 轮，每轮 `check` 为 $O(n + m)$；
  - 合计 $O\big((n + m)\log C\big)$，其中 $C = \max \text{cost} \le 10^9$。按 $n = 5\times10^4$、$m = 10^5$ 估计约 $30 \times 1.5\times10^5 = 4.5\times10^6$ 次操作。
- **空间**：$O(n + m)$，邻接表 $2m$ 个整数对、拓扑队列与 `dist` 各 $O(n)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int findMaxPathScore(std::vector<std::vector<int>>& edges, std::vector<bool>& online, long long k) {
        int n = (int)online.size();
        std::vector<std::vector<std::pair<int, long long>>> g(n);
        std::vector<int> indeg(n, 0);
        int maxCost = 0;
        for (const std::vector<int>& e : edges) {
            int u = e[0], v = e[1], c = e[2];
            g[u].push_back({v, c});
            indeg[v]++;
            if (c > maxCost) maxCost = c;
        }
        // 拓扑序（DAG）
        std::vector<int> order;
        order.reserve(n);
        {
            std::vector<int> deg = indeg;
            std::vector<int> q;
            for (int i = 0; i < n; i++) if (deg[i] == 0) q.push_back(i);
            for (size_t h = 0; h < q.size(); h++) {
                int u = q[h];
                order.push_back(u);
                for (const auto& pr : g[u]) {
                    if (--deg[pr.first] == 0) q.push_back(pr.first);
                }
            }
        }
        const long long INF = std::numeric_limits<long long>::max() / 4;
        auto feasible = [&](int low) -> bool {
            std::vector<long long> dist(n, INF);
            dist[0] = 0;
            for (int u : order) {
                if (dist[u] >= INF || !online[u]) continue;
                for (const auto& pr : g[u]) {
                    int v = pr.first;
                    long long c = pr.second;
                    if (c < low) continue;
                    if (dist[u] + c < dist[v]) dist[v] = dist[u] + c;
                }
            }
            return dist[n - 1] <= k;
        };
        if (!feasible(0)) return -1;
        int lo = 0, hi = maxCost;
        while (lo < hi) {
            int mid = lo + (hi - lo + 1) / 2;
            if (feasible(mid)) lo = mid;
            else hi = mid - 1;
        }
        return lo;
    }
};
```

### Python

```python
class Solution:
    def findMaxPathScore(self, edges: list[list[int]], online: list[bool], k: int) -> int:
        n = len(online)
        g = [[] for _ in range(n)]
        indeg = [0] * n
        max_cost = 0
        for u, v, c in edges:
            g[u].append((v, c))
            indeg[v] += 1
            max_cost = max(max_cost, c)
        # 拓扑序（Kahn）
        order = []
        deg = indeg[:]
        q = [i for i in range(n) if deg[i] == 0]
        for u in q:
            order.append(u)
            for v, _ in g[u]:
                deg[v] -= 1
                if deg[v] == 0:
                    q.append(v)
        INF = float('inf')

        def feasible(low: int) -> bool:
            dist = [INF] * n
            dist[0] = 0
            for u in order:
                if dist[u] == INF or not online[u]:
                    continue
                du = dist[u]
                for v, c in g[u]:
                    if c < low:
                        continue
                    if du + c < dist[v]:
                        dist[v] = du + c
            return dist[n - 1] <= k

        if not feasible(0):
            return -1
        lo, hi = 0, max_cost
        while lo < hi:
            mid = (lo + hi + 1) // 2
            if feasible(mid):
                lo = mid
            else:
                hi = mid - 1
        return lo
```

## 8. 边界情况与易错点

1. **答案可能为 $0$**：因为边成本可以为 $0$。二分下界必须取 $0$，且 `feasible(0)` 要先单独判定，用于区分「答案是 $0$」和「无解」。
2. **无解返回 $-1$**：漏掉 `feasible(0)` 的预判会把无解错误地输出成 $0$。
3. **离线节点的过滤方向**：必须在**出发节点**处过滤（`!online[u]` 就跳过），否则会允许路径穿过离线节点。$0$ 与 $n-1$ 恒在线，不必特判。
4. **`mid` 取整方向**：求最大可行值要向上取整，否则死循环。
5. **`dist` 溢出**：`INF = LLONG_MAX / 4`，且 `dist[u] + c` 只在 `dist[u] < INF` 时计算。
6. **`k` 很大**：$k$ 可达 $5\times10^{13}$，`int` 装不下，函数签名里就是 `long long`。
7. **图是 DAG 但节点编号未必拓扑有序**：必须真正做拓扑排序，不能直接用编号顺序。
8. **$m = 0$**：没有边，`maxCost = 0`，`feasible(0)` 为假，返回 $-1$；此时二分区间退化为单点，注意不要在 `lo == hi` 时再进循环。
9. **多条同向边**：邻接表保留全部，DP 自然取最优，不要用邻接矩阵（$n = 5\times10^4$ 存不下）。
