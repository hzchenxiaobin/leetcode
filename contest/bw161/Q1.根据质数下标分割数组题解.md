# LeetCode 根据质数下标分割数组 题解

## 1. 题目概述

- **标题 / 题号**：根据质数下标分割数组（#3618，medium）
- **链接**：https://leetcode.cn/problems/split-array-by-prime-indices/
- **来源**：LeetCode 第 161 场双周赛 Q1
- **难度**：中等
- **标签**：数组、数学、数论

**题意**：给定整数数组 `nums`，按**下标**（不是元素值）把元素分成两组：下标是**质数**的元素放进数组 $A$，其余元素放进数组 $B$。返回两数组之和的绝对差 $\lvert \text{sum}(A) - \text{sum}(B) \rvert$。空数组的和记为 $0$。

注意下标从 $0$ 开始，因此 $0$ 和 $1$ 都**不是**质数，只有 $2, 3, 5, 7, 11, \dots$ 算质数。

**约束**：

- $1 \le \text{nums.length} \le 10^5$
- $-10^9 \le \text{nums}[i] \le 10^9$

元素可以是负数，求和结果最大约 $10^{14}$，必须用 64 位整数。

## 2. 示例

**示例 1**

```text
输入：nums = [2,3,4]
输出：1
解释：唯一的质数下标是 2，nums[2] = 4 进 A；
      nums[0] = 2、nums[1] = 3 进 B。
      sum(A) = 4，sum(B) = 5，|4 − 5| = 1。
```

**示例 2**

```text
输入：nums = [-1,5,7,0]
输出：3
解释：质数下标是 2、3，nums[2] = 7、nums[3] = 0 进 A，sum(A) = 7；
      nums[0] = -1、nums[1] = 5 进 B，sum(B) = 4；
      |7 − 4| = 3。
```

**示例 3（自造，用于检查边界）**

```text
输入：nums = [7]
输出：7
解释：下标 0 不是质数，A 为空（和为 0），B = [7]，|0 − 7| = 7。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的做法：对每个下标 $i$ 写一个试除法判断 $i$ 是否质数，然后决定放进 $A$ 还是 $B$。单次判定 $O(\sqrt{i})$，总体 $O(n\sqrt{n})$。当 $n = 10^5$ 时约 $3 \times 10^7$ 次取模，勉强能过，但完全是浪费——所有下标是**同一批**数字 $0, 1, \dots, n-1$，它们的质性只需要算一次。

### 3.2 核心观察：把「逐个判定」换成「一次筛」

![质数下标进 A，其余进 B，最后取绝对差](images/bw161_q1_prime_index_split.svg)

质数判定具有**批量结构**：只要求出 $[0, n-1]$ 上的质数标记表，每个下标 $O(1)$ 查表即可。用**埃氏筛**：

1. 初始全部标记为质数；
2. 把 $0$ 和 $1$ 标记为合数（$1$ 只有一个因子，按定义不是质数）；
3. 从 $i = 2$ 开始，若 $i$ 仍是质数，就把 $i^2, i^2 + i, i^2 + 2i, \dots$ 全部标记为合数。

![埃氏筛：先划掉 0、1，再把每个质数的倍数划掉](images/bw161_q1_sieve.svg)

筛法总代价 $O(n \log\log n)$，比分桶判定快一个量级。

另一个容易忽略的点是**符号**：元素可以为负，所以不能想当然地写 `sumA - sumB`，必须取绝对值。同时在 C++ 中求和要用 `long long`（$10^5 \times 10^9 = 10^{14}$ 已超出 `int`）。

### 3.3 算法流程

```text
1. n = len(nums)
2. isPrime[0..n] 全部置 true；isPrime[0] = isPrime[1] = false
3. for i = 2 .. ⌊√n⌋:
       若 isPrime[i]:
           for j = i², i²+i, ... ≤ n: isPrime[j] = false
4. sumA = sumA + nums[i]（isPrime[i] 为真时）
   sumB = sumB + nums[i]（isPrime[i] 为假时）
5. 返回 |sumA − sumB|
```

筛的上界取 $n$ 而不是 $n-1$，仅仅是为了少写一个特判：多筛一个数不影响结果。

### 3.4 示例演算

以示例 2 的 `nums = [-1,5,7,0]` 为例：

| 下标 $i$ | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| `nums[i]` | −1 | 5 | 7 | 0 |
| 质数？ | ✗ | ✗ | ✓ | ✓ |
| 去向 | B | B | A | A |

于是 $\text{sum}(A) = 7 + 0 = 7$，$\text{sum}(B) = -1 + 5 = 4$，答案为 $\lvert 7 - 4 \rvert = 3$。

示例 1 中只有下标 $2$ 是质数，$A = \{4\}$、$B = \{2, 3\}$，答案为 $1$。

## 4. 算法细节

1. **筛的边界**：`isPrime` 开 $n + 1$ 大小；$n = 1$ 时只用到下标 $0$，需要单独把 `isPrime[1]` 的写入包在条件里，避免越界。
2. **循环上界**：外层只需枚举到 $\lfloor\sqrt{n}\rfloor$。C++ 中写 `i * i <= n` 时若 $i$ 用 `int` 且 $n$ 很大可能溢出，这里 $n \le 10^5$ 安全，但写成 `(long long)i * i <= n` 更稳妥。
3. **内层起点是 $i^2$**：比 $i^2$ 小的 $i$ 的倍数已经被更小的质因子筛掉了，从 $i^2$ 起可以省掉一半无效写入。
4. **求和类型**：C++ 用 `long long sumA, sumB`；Python 无溢出问题。最终取差值时用 `sumA >= sumB ? sumA - sumB : sumB - sumA`（或 `abs`），避免 `llabs` 的符号陷阱。
5. **不要真的开辟两个数组**：题目只说「分割成两个数组」，本质只需要两个累加器，$O(1)$ 额外空间即可。

## 5. 正确性证明

**引理 1（筛法正确性）**：算法结束后 `isPrime[i]` 为真当且仅当 $i$ 是质数（$0 \le i \le n$）。

**证明**：$0$ 与 $1$ 被显式置假，符合质数定义（大于 $1$ 且只有 $1$ 和自身两个因子）。

若 $i \ge 2$ 是合数，设 $p$ 是 $i$ 的最小质因子，则 $p \le \sqrt{i} \le \sqrt{n}$，且 $i = p \cdot q$ 中 $q \ge p$，故 $i \ge p^2$ 且 $i$ 是 $p$ 的倍数。外层循环枚举到 $p$ 时（$p \le \lfloor\sqrt{n}\rfloor$），内层会从 $p^2$ 起把所有 $p$ 的倍数置假，其中包含 $i$。所以合数一定被置假。

反之，若 $i \ge 2$ 是质数，它只有 $1$ 与自身的因子，不可能等于任何 $p^2 + kp$（$p \ge 2$）形式的数，因此从未被置假，保持为真。∎

**引理 2（划分唯一性）**：每个下标 $i$ 恰好属于 $A$ 或 $B$ 之一，且归属只由 $i$ 是否为质数决定。

**证明**：题目规则对下标做二分：是质数进 $A$，否则进 $B$。两个条件互斥且穷尽全部下标，故每个元素恰好被累加一次。∎

**定理**：算法返回值等于 $\lvert \text{sum}(A) - \text{sum}(B) \rvert$。

**证明**：由引理 1，循环中 `isPrime[i]` 的取值与「$i$ 是质数」等价；由引理 2，每个 `nums[i]` 被且仅被累加到它应属的那一组，所以 `sumA`、`sumB` 分别等于 $A$、$B$ 的元素和。最后一步按大小关系取非负差值，即绝对差。∎

## 6. 复杂度分析

- **时间**：$O(n \log\log n)$。筛法的主项是 $\sum_{p \le \sqrt{n}} \frac{n}{p} = O(n \log\log n)$，累加部分 $O(n)$。
- **空间**：$O(n)$，即长度 $n + 1$ 的布尔标记数组（用 `vector<bool>` 时实际约 $n/8$ 字节）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long splitArray(std::vector<int>& nums) {
        int n = (int)nums.size();
        std::vector<bool> isPrime(n + 1, true);
        if (n >= 0) isPrime[0] = false;
        if (n >= 1) isPrime[1] = false;
        for (int i = 2; (long long)i * i <= n; i++) {
            if (!isPrime[i]) continue;
            for (int j = i * i; j <= n; j += i) isPrime[j] = false;
        }
        long long sumA = 0, sumB = 0;
        for (int i = 0; i < n; i++) {
            if (isPrime[i]) sumA += nums[i];
            else sumB += nums[i];
        }
        return sumA >= sumB ? sumA - sumB : sumB - sumA;
    }
};
```

### Python

```python
class Solution:
    def splitArray(self, nums: list[int]) -> int:
        n = len(nums)
        is_prime = [True] * (n + 1)
        if n >= 0:
            is_prime[0] = False
        if n >= 1:
            is_prime[1] = False
        for i in range(2, int(n ** 0.5) + 1):
            if is_prime[i]:
                for j in range(i * i, n + 1, i):
                    is_prime[j] = False
        sum_a = sum(nums[i] for i in range(n) if is_prime[i])
        sum_b = sum(nums[i] for i in range(n) if not is_prime[i])
        return abs(sum_a - sum_b)
```

## 8. 边界情况与易错点

1. **$0$ 和 $1$ 不是质数**：这是本题第一大坑。`nums[0]`、`nums[1]` 永远属于 $B$。
2. **下标与元素值混淆**：判断的是**下标**的质性，不是 `nums[i]` 的质性。示例 1 的 `nums[1] = 3` 是质数，但下标 $1$ 不是，所以它进 $B$。
3. **负数与求和溢出**：元素可负，`sumA - sumB` 可能为负，必须取绝对值；$n \cdot 10^9 = 10^{14}$ 必须 64 位。
4. **$n = 1$**：只有下标 $0$，$A$ 为空（和为 $0$），答案就是 $\lvert \text{nums}[0] \rvert$。此时对 `isPrime[1]` 的写入要防越界。
5. **$n = 2$**：下标 $2$ 不存在，`isPrime` 只有两个有效位，筛法一次都不需要跑。
6. **空数组的和**：题目明确约定空数组和为 $0$，代码里不要去特判「$A$ 为空则返回什么」，累加器初值 $0$ 已经满足。
7. **`i * i` 溢出**：虽然本题 $n \le 10^5$ 不会溢出，养成 `(long long)i * i <= n` 的习惯可以避免在更大值域上翻车。
