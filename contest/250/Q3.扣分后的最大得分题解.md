# LeetCode 扣分后的最大得分 题解

## 1. 题目概述

- **标题 / 题号**：扣分后的最大得分（#1937，medium）
- **链接**：https://leetcode.cn/problems/maximum-number-of-points-with-cost/
- **来源**：LeetCode 第 250 场周赛 Q3
- **难度**：中等
- **标签**：动态规划、数组、矩阵、前后缀最值

**题意**：给定 $m \times n$ 整数矩阵 `points`（下标从 0 开始）。需要**每行恰选一个格子**：选 $(r, c)$ 使总分**增加** $\text{points}[r][c]$；但相邻两行 $r$ 与 $r+1$ 所选列分别为 $c_1, c_2$ 时，总分**减少** $|c_1 - c_2|$。求能得到的**最大**总分。

**约束**：

- $m = \text{len(points)}$，$n = \text{len(points}[r])$
- $1 \le m, n \le 10^5$ 且 $1 \le m \cdot n \le 10^5$
- $0 \le \text{points}[r][c] \le 10^5$

> 💡 本题在本仓库另有[每日题解 1937](../../solution/1901-2000/1937_扣分后的最大得分.md)，两篇为姊妹篇：每日篇侧重**前后缀 max 数组**的讲法、原地合并写法与面试问答。本篇按周赛复盘视角，聚焦**从「行间耦合的绝对值」到「两趟扩散」的赛场最短推理路径**、**免哨兵免辅助数组的原地实现**（与图像处理的 L1 距离变换同构），并补全**最优子结构 → 拆解恒等式 → 扩散等价性**的完整证明链（§5）。

## 2. 示例

**示例 1**

```text
输入：points = [[1,2,3],[1,5,1],[3,1,1]]
输出：9
解释：选 (0,2)、(1,1)、(2,0)。增分 3+5+3 = 11，扣分 |2−1|+|1−0| = 2，
      最终 11 − 2 = 9。
```

**示例 2**

```text
输入：points = [[1,5],[2,3],[4,2]]
输出：11
解释：选 (0,1)、(1,1)、(2,0)。增分 5+3+4 = 12，扣分 |1−1|+|1−0| = 1，
      最终 12 − 1 = 11。
```

**自造边界样例**

```text
输入：points = [[7]]
输出：7
解释：m = n = 1，只有一种选法，无扣分。

输入：points = [[5],[2],[9]]
输出：16
解释：n = 1，每行只能选第 0 列，|0−0| = 0 恒无扣分，答案 = 5+2+9。
      （注意反之 m = 1 时答案是 max(points[0])，两者语义不同。）

输入：points = [[1,3],[5,1]]
输出：7
解释：选 (0,1)、(1,0)：3+5−|1−0| = 7。此时第 0 行的最优源在 c=0 的「右侧」——
      只跑单向扫描的写法会得 6，专照「漏一趟」这个坑（§8.3）。

输入：points = 10⁵ 行 × 1 列，每格 10⁵
输出：10¹⁰
解释：答案上界照妖镜——超出 int32（约 2.1×10⁹），C++ 必须 long long（§8.1）。
```

## 3. 解题思路

### 3.1 暴力思路：逐行 DP，内层枚举上一行所有列

定义 $f(r, c)$ = 前 $r+1$ 行、第 $r$ 行选 $(r, c)$ 时的最大得分。扣分只耦合**相邻两行**，这正是无后效性的入口，转移为：

$$f(r, c) = \text{points}[r][c] + \max_{c'} \big( f(r-1, c') - |c - c'| \big), \qquad f(0, c) = \text{points}[0][c]$$

答案是 $\max_c f(m-1, c)$。转移本身已经正确（§5 引理 1），问题是**每个 $c$ 都要重扫一遍上一行**：每行 $O(n^2)$，总共 $O(m n^2)$。$m \cdot n \le 10^5$ 但 $n$ 单独可达 $10^5$（单行矩阵），$n^2$ 高达 $10^{10}$——**必 TLE**。

> ⚠️ 瓶颈精确地落在 $\max_{c'}(\,f(r-1,c') - |c-c'|\,)$ 这一坨：绝对值把「上一行任意列」与「当前列 $c$」焊在一起。能不能把耦合拆开，让与 $c'$ 有关的部分**预先**算好？能，而且有两种等价拆法——前后缀 max（§3.2）与两趟扩散（§3.3），后者就是本篇的主推实现。

### 3.2 核心观察：拆掉绝对值，前后缀 max 各管半边

![核心观察：拆掉绝对值，左半边交给前缀 max，右半边交给后缀 max](images/wc250_q3_abs_split.svg)

按 $c'$ 与 $c$ 的大小关系把候选源分成两半，绝对值在每一半里都能**去掉分段符号**：

- **左源 $c' \le c$**：$|c - c'| = c - c'$，于是 $f(r-1,c') - |c-c'| = \big(f(r-1,c') + c'\big) - c$。括号内**只与 $c'$ 有关**，对 $c' \le c$ 取 max 就是**前缀最大值** $L[c] = \max_{c' \le c}(f(r-1,c') + c')$。
- **右源 $c' \ge c$**：$|c - c'| = c' - c$，于是 $f(r-1,c') - |c-c'| = \big(f(r-1,c') - c'\big) + c$。同理是**后缀最大值** $R[c] = \max_{c' \ge c}(f(r-1,c') - c')$。

于是转移被压成 $O(1)$ 查询：

$$\boxed{\;f(r, c) = \text{points}[r][c] + \max\big( L[c] - c,\; R[c] + c \big)\;}$$

$L$ 一趟从左到右、$R$ 一趟从右到左即可递推出（每行 $O(n)$）。这是「拆贡献 + 前后缀最值预计算」的经典套路，与 [1014. 最佳观光组合](https://leetcode.cn/problems/best-sightseeing-pair/)（$\text{values}[i]+i$ 与 $\text{values}[j]-j$ 的拆法）完全同构——那题是一维两点的特例，本题把它做成了**逐行滚动**的版本。

### 3.3 等价视角：两趟「扩散」，价值每传一格衰减 1

![等价实现：两趟扩散，价值每传一格衰减 1](images/wc250_q3_diffusion_passes.svg)

前后缀版还要显式建出 $L$、$R$ 两个数组。换个角度看 $\max_{c'}(\,v[c'] - |c - c'|\,)$（$v$ 为上一行 dp）：它等价于让每个格子的值向两侧**传播**，**每传一格衰减 1**，每个位置取所有传到者与自身原值的最大。这个语义有一段极简的递推实现——**两趟原地扩散**：

```text
左趟（c 从 1 到 n−1）：v[c] = max(v[c], v[c−1] − 1)
右趟（c 从 n−2 到 0）：v[c] = max(v[c], v[c+1] − 1)
```

两趟跑完，$v[c]$ 恰好变成 $\max_{c'}(\text{旧 } v[c'] - |c - c'|)$（§5 引理 3，关键一步是直线上**三角不等式**「绕路不赚」）。**原地、免哨兵、免辅助数组**——max 里天然有 $v[c]$ 自身兜底，不存在「空区间」问题。

> 💡 这正是图像处理里 **L1 距离变换**（distance transform）的两趟扫描算法：把「初值集合 + 每步距离代价」沿正反两个方向各扫一遍即得全局最近距离。本题把「min + 距离」换成了「max − 距离」，骨架一模一样。识别出这个同构，实现和证明（引理 3）都可以直接平移。

### 3.4 算法流程

![算法流程：逐行滚动，每行两趟扩散加累加](images/wc250_q3_algorithm_flow.svg)

1. **初始化**：`dp ← points[0]`（第 0 行没有上一行，选哪格得哪格，无扣分）。
2. 对每一行 $r = 1 \dots m-1$：
   - **左趟扩散**：`for c = 1 … n−1: dp[c] = max(dp[c], dp[c−1] − 1)`；
   - **右趟扩散**：`for c = n−2 … 0: dp[c] = max(dp[c], dp[c+1] − 1)`；
   - **累加当前行**：`for c = 0 … n−1: dp[c] += points[r][c]`。
3. **返回** $\max_c\ \text{dp}[c]$。

三条注意：**先扩散后累加**（顺序反了语义就错，§8.2）；左趟读的左邻是**已更新值**（这正是衰减链一格格传递的机制，不是脏读 bug）；两趟**方向不能反、不能省**（§8.3）。

### 3.5 示例演算

![示例演算：points=[[1,2,3],[1,5,1],[3,1,1]]，答案 9](images/wc250_q3_example_walkthrough.svg)

以示例 1 逐步推演（`dp` 只保留上一行）：

| r | 上一行 dp | 扩散后 g（即 $\max_{c'}(\cdot)$） | 新 dp（= points[r] + g） |
|---|-----------|-----------------------------------|--------------------------|
| 0 | —         | —                                 | $[1, 2, 3]$              |
| 1 | $[1,2,3]$ | $[1, 2, 3]$（相邻差恰为 1，两趟都追平而不超过） | $[1{+}1,\ 5{+}2,\ 1{+}3] = [2, 7, 4]$ |
| 2 | $[2,7,4]$ | $[6, 7, 6]$（7 向左右各传一步，$7-1=6$ 改写两端） | $[3{+}6,\ 1{+}7,\ 1{+}6] = [9, 8, 7]$ |

最终 $\max(\text{dp}_2) = 9$ ✓，对应最优路径 $(0,2) \to (1,1) \to (2,0)$：增分 $3+5+3=11$，扣分 $|2-1|+|1-0|=2$，$11-2=9$。

抽查一个转移验证（$r=2, c=0$）：扩散后的 $g[0] = 6$ 来自 $\max(2-0,\ 7-1,\ 4-2) = 6$（源是 $c'=1$ 的 7，衰减 1）；$\text{dp}_2[0] = 3 + 6 = 9$。若只跑左趟，$g[0]$ 只能是 $2$（$c'=0$ 自身），$\text{dp}_2[0] = 5$——当场漏掉最优解，这就是 §8.3 的照妖镜。

## 4. 算法细节

1. **滚动数组**：转移只依赖上一行，`dp` 用一维数组原地滚动，空间 $O(n)$。初值是 `points[0]` 本身（不是 0，也不是该行最大值）。
2. **扩散版的「免哨兵」**：前后缀版若用 `cur` 从 $-\infty$ 起算要小心下溢（每日篇用 `LLONG_MIN/2` / `-10**18`）；但其实**两个半区都含 $c' = c$ 自身**，前缀/后缀区间永不为空，从端点直接起算即可免哨兵。扩散版更彻底——递推式的 max 里天然有 $v[c]$ 兜底，全程不碰哨兵。
3. **顺序契约**：先两趟扩散、再累加 `points[r]`。若先累加再扩散，等于把**当前行**也当成扩散源参与「对自身的传播」，样例 1 即错（§8.2）。
4. **读改同一数组的语义**：左趟 `dp[c] = max(dp[c], dp[c−1] − 1)` 读的是**已更新的左邻**——这让衰减链 $v_0[c''] \to v_1[c''+1] \to \cdots \to v_1[c]$ 一格格接力传递，正是引理 3 第一步归纳所依赖的性质；若错抄成读「旧左邻」（先存副本再扫），只会传递一步衰减，答案错。
5. **两种实现对照**：

   | 版本 | 每行趟数 | 额外数组 | 哨兵 | 备注 |
   |------|---------|----------|------|------|
   | 前后缀 max（每日篇主推） | 2 趟扫描 + 1 趟合并 | $L$、$R$（可省其一） | 可免（区间含自身） | 与 1014 拆法同构，面试好讲 |
   | 两趟扩散（本篇主推） | 3 趟（左、右、加） | 0 | 完全免 | = L1 距离变换，最短代码 |
6. **溢出核算**：$f$ 值上界 $\sum_r \max_c \text{points}[r] \le m \cdot 10^5 \le 10^{10}$（$m \le 10^5$），**超出 int32**（$\approx 2.1 \times 10^9$）——C++ 的 dp 数组与返回值都必须 `long long`（接口返回类型本身就是 `long long`，但内部数组手滑写成 `vector<int>` 照样 WA）。又由 $g[c] \ge \text{dp}[c] \ge 0$（取 $c'=c$、代价 0）归纳可知 dp 逐行非负，扩散中的 $-1$ 无下溢风险；Python 整数任意精度无此虑。
7. **复杂度即数据范围**：$m \cdot n \le 10^5$，每行至多 3 趟线性扫，总操作约 $3 \times 10^5$ 次——$O(mn)$ 正是出题人给的通过线，暴力 $O(mn^2)$ 与线段树 $O(mn\log n)$（把转移看成区间加 + 区间 max 的另一个做法）都不必要。

## 5. 正确性证明

把「合法方案」形式化：从每行各选一列得到的序列 $(c_0, c_1, \dots, c_{m-1})$，其得分

$$\text{val}(c_\cdot) = \sum_{r=0}^{m-1} \text{points}[r][c_r] \; - \sum_{r=0}^{m-2} |c_{r+1} - c_r|.$$

**引理 1（最优子结构 / 转移正确）**：$f(0, c) = \text{points}[0][c]$；对 $r \ge 1$，

$$f(r, c) = \text{points}[r][c] + \max_{c'} \big( f(r-1, c') - |c - c'| \big).$$

**证明**：$r = 0$ 时无扣分项，得分即 $\text{points}[0][c]$。对 $r \ge 1$：任取末行选 $c$ 的部分方案 $(c_0, \dots, c_{r-1}, c)$，其得分可拆为

$$\underbrace{\Big( \sum_{t=0}^{r-1} \text{points}[t][c_t] - \sum_{t=0}^{r-2} |c_{t+1} - c_t| \Big)}_{\text{前 } r \text{ 行部分方案的得分}} + \; \text{points}[r][c] \; - \; |c - c_{r-1}|,$$

括号内是某个末行选 $c_{r-1}$ 的 $(r-1)$ 行部分方案得分 $\le f(r-1, c_{r-1})$，故整体 $\le \text{points}[r][c] + \max_{c'}(f(r-1,c') - |c-c'|)$，对 $c_{r-1}$ 取上界仍成立。反之设 $c^*$ 取到 max，取达到 $f(r-1, c^*)$ 的方案再接上第 $r$ 行选 $c$，是合法部分方案且得分恰为右端。两向夹逼得等式。∎

**引理 2（绝对值拆解恒等式）**：对任意数组 $v$ 与下标 $c$，

$$\max_{c'} \big( v[c'] - |c - c'| \big) = \max\big( L[c] - c,\; R[c] + c \big), \quad L[c] = \max_{c' \le c}(v[c'] + c'),\;\; R[c] = \max_{c' \ge c}(v[c'] - c').$$

**证明**：把下标全集划分为 $A = \{c' \le c\}$ 与 $B = \{c' \ge c\}$（$c$ 同属两者，不影响 max）。$c' \in A$ 时 $|c - c'| = c - c'$，故 $v[c'] - |c-c'| = (v[c'] + c') - c$，该半边最大值 $= L[c] - c$；$c' \in B$ 时同理该半边最大值 $= R[c] + c$。全集 max 等于两半较大者。∎

**引理 3（两趟扩散等价）**：设 $v_0$ 为初始数组。左趟定义 $v_1[c] = \max(v_0[c],\, v_1[c-1] - 1)$（$c$ 自左向右，$v_1[0] = v_0[0]$），右趟定义 $w[c] = \max(v_1[c],\, w[c+1] - 1)$（自右向左，$w[n-1] = v_1[n-1]$）。则对每个 $c$：

$$w[c] = \max_{c'} \big( v_0[c'] - |c - c'| \big).$$

**证明**：**第一步**（左趟显式解）：对 $c$ 归纳证明 $v_1[c] = \max_{c' \le c}\big(v_0[c'] - (c - c')\big)$。$c = 0$ 显然；若对 $c-1$ 成立，则

$$v_1[c] = \max\big(v_0[c],\, v_1[c-1] - 1\big) = \max\Big(v_0[c] - 0,\; \max_{c' \le c-1}\big(v_0[c'] - (c\!-\!1 - c')\big) - 1\Big) = \max_{c' \le c}\big(v_0[c'] - (c - c')\big).$$

**第二步**（右趟显式解）：同理归纳得 $w[c] = \max_{c'' \ge c}\big(v_1[c''] - (c'' - c)\big)$。

**（≥）** 一方面 $w[c] \ge v_1[c] = \max_{c' \le c}(v_0[c'] - (c - c'))$，覆盖所有左源 $c' \le c$；另一方面对每个 $c'' \ge c$，$w[c] \ge v_1[c''] - (c'' - c) \ge v_0[c''] - (c'' - c)$（右趟不动值，$v_1 \ge v_0$ 逐点成立），覆盖所有右源。故 $w[c] \ge \max_{c'}(v_0[c'] - |c - c'|)$。

**（≤）** 由第二步，存在 $c_0 \ge c$ 使 $w[c] = v_1[c_0] - (c_0 - c)$；由第一步，存在 $c_1 \le c_0$ 使 $v_1[c_0] = v_0[c_1] - (c_0 - c_1)$。于是

$$w[c] = v_0[c_1] - \big( |c_0 - c_1| + |c_0 - c| \big) \;\le\; v_0[c_1] - |c - c_1| \;\le\; \max_{c'} \big( v_0[c'] - |c - c'| \big),$$

其中第一个不等号用直线上**三角不等式** $|c_0 - c_1| + |c_0 - c| \ge |c_1 - c|$——「先经过中转站 $c_0$ 再到 $c$」的总衰减不小于直达。∎

**定理（算法正确性）**：按 §3.4 流程（初值 $\text{dp} = \text{points}[0]$；每行先两趟扩散、再累加该行点数）滚动计算，处理完第 $r$ 行后 $\text{dp}[c] = f(r, c)$ 对所有 $c$ 成立；算法返回 $\max_c f(m-1, c)$，即全局最优得分。

**证明**：对 $r$ 归纳。$r = 0$ 即初值，显然。设处理完 $r - 1$ 后 $\text{dp} = (f(r-1, c))_c$；处理第 $r$ 行时，引理 3 保证两趟扩散后 $\text{dp}[c] = \max_{c'}(f(r-1, c') - |c - c'|)$，累加 $\text{points}[r][c]$ 后由引理 1 恰得 $(f(r, c))_c$，归纳完成。扣分只依赖相邻两行（引理 1 的拆分正说明了这一点），滚动只保留一行不丢信息。最后，任何合法方案的得分都被其末行的 $f$ 值覆盖（把方案截断到前 $m-1$ 行即得下界），故 $\max_c f(m-1, c)$ 是最优值。∎

**推论（值域与工程安全性）**：归纳可知 $0 \le f(r, c) \le (r+1) \cdot 10^5$，答案上界 $m \cdot 10^5 \le 10^{10}$ 超 int32（C++ 必须 `long long`）；又 $g[c] \ge f(r-1, c) \ge 0$（源取 $c' = c$、代价 0）保证 dp 逐行非负、扩散中 $-1$ 无下溢。∎

> 💡 **证明的关键一步**是引理 3（≤）方向的三角不等式：扩散语义允许「值接力传递」（7 向右传成 6、6 再向左传成 5），看似可能编出比直达更优的路径，但直线上绕路总长度只会更长，衰减只会更多——接力链恰好不会超过任何直达源。「拆解恒等式（引理 2）」与「扩散等价（引理 3）」是同一件事的代数版与算法版，两条路在 $\max_{c'}(v[c'] - |c-c'|)$ 处会师。

## 6. 复杂度分析

- **时间复杂度**：$O(m \cdot n)$。每行左趟 $n-1$ 次、右趟 $n-1$ 次、累加 $n$ 次，均为 $O(1)$ 操作；$m \cdot n \le 10^5$，总量约 $3 \times 10^5$ 次，瞬时通过。对照暴力 $O(m \cdot n^2)$：把「每个 $c$ 重扫上一行」替换为「整行两趟扩散」，内层 $n$ 被消掉。
- **空间复杂度**：$O(n)$。仅一个滚动 dp 数组，无辅助数组、无哨兵（不计输入矩阵本身）。

## 7. 参考代码

### C++（两趟扩散，原地滚动）

```cpp
class Solution {
public:
    long long maxPoints(vector<vector<int>>& points) {
        int m = points.size(), n = points[0].size();
        vector<long long> dp(points[0].begin(), points[0].end());

        for (int r = 1; r < m; ++r) {
            for (int c = 1; c < n; ++c)
                dp[c] = max(dp[c], dp[c - 1] - 1);   // 左趟：左源衰减传播
            for (int c = n - 2; c >= 0; --c)
                dp[c] = max(dp[c], dp[c + 1] - 1);   // 右趟：右源衰减传播
            for (int c = 0; c < n; ++c)
                dp[c] += points[r][c];               // 累加当前行（顺序不能反）
        }
        return *max_element(dp.begin(), dp.end());
    }
};
```

### Python（两趟扩散，同构直译）

```python
class Solution:
    def maxPoints(self, points: List[List[int]]) -> int:
        dp = points[0][:]                            # 拷贝，防与输入别名
        for row in points[1:]:

            for c in range(len(dp) - 2, -1, -1):
                dp[c] = max(dp[c], dp[c + 1] - 1)    # 右趟
            dp = [d + p for d, p in zip(dp, row)]    # 累加当前行
        return max(dp)
```

### Python（前后缀版，与每日篇对照）

```python
class Solution:
    def maxPoints(self, points: List[List[int]]) -> int:
        n = len(points[0])
        dp = points[0][:]
        for row in points[1:]:
            L = [0] * n                              # L[c] = max_{c'<=c}(dp[c']+c')
            L[0] = dp[0]
            for c in range(1, n):
                L[c] = max(L[c - 1], dp[c] + c)
            R = [0] * n                              # R[c] = max_{c'>=c}(dp[c']-c')
            R[n - 1] = dp[n - 1] - (n - 1)
            for c in range(n - 2, -1, -1):
                R[c] = max(R[c + 1], dp[c] - c)
            dp = [row[c] + max(L[c] - c, R[c] + c) for c in range(n)]
        return max(dp)
```

> 💡 **写法对照**：① 三个版本共享同一条转移（引理 1），扩散版与前后缀版由引理 2/3 保证等价；② 前后缀版从端点起算、区间永含自身（$c' = c$），**连哨兵都不用**——每日篇的 $-10^{18}$ / `LLONG_MIN/2` 写法是防御式习惯，并非必需；③ C++ 版 dp 声明为 `vector<long long>` 是硬要求（§4.6：答案上界 $10^{10}$）。以上实现均已通过官方样例 1–2 及 $m=n=1$、单列累加、[[1,3],[5,1]]（右源关键样例）、$10^5 \times 1$ 极值等自造边界，并与暴力 $O(mn^2)$ 枚举版互拍随机小矩阵验证一致。

## 8. 边界情况与易错点

1. **C++ 内部数组用 `int`（本题第一大 WA）**：答案上界 $\sum \text{points} \le m \cdot 10^5 = 10^{10}$，超 int32。不用很大就爆：$n = 1$、$m = 3 \times 10^4$、全 $10^5$ 时总分 $3 \times 10^9$ 已越界。接口返回类型 `long long` 只是台阶，dp 数组必须同步 `long long`。
2. **先累加后扩散（顺序反了）**：变成「当前行参与对自身的扩散传播」，语义完全不同。正确契约：**扩散（消费上一行）→ 累加（写入当前行）**。记不住就记「先把旧账结清，再记新账」。
3. **只跑一趟 / 方向跑反（本题第二大 WA）**：只跑左趟则永远学不到右侧更优的源。照妖镜 `points = [[1,3],[5,1]]`：正确答案 $3+5-1=7$（第 1 行 $c=0$ 的最优源是右边的 $c'=1$），只跑左趟得 $6$。方向跑反同理。两趟**都要跑、各沿各的方向**。
4. **内层枚举 $c'$ 带 `abs`（TLE）**：$O(m n^2)$，$n = 10^5$ 时单行转移就 $10^{10}$ 次。见到「绝对值 + 区间上取 max/min」先想拆解或扩散。
5. **dp 初值**：`points[0]` 整行（每列各自起跑），不是 0、不是 `max(points[0])`、也不是全 $-\infty$。
6. **哨兵下溢（前后缀版专属）**：若坚持用 $-\infty$ 起算 `cur`，C++ 别用 `LLONG_MIN`（后续 $\pm c$ 会下溢 UB），用 `LLONG_MIN/2`；更好的做法是从端点起算或改扩散版，压根不碰哨兵。
7. **$m = 1$ / $n = 1$ 自动正确**：$m=1$ 时行循环不执行，答案 `max(points[0])`；$n=1$ 时扩散循环不执行、扣分恒 0，答案为该列之和。无需特判，但可作 sanity check（§2 自造样例）。
8. **`points` 含 0**：dp 可能整行为 0，max 语义照常，无影响。题目**强制每行选一格**，且 $\text{points} \ge 0$，不存在「想跳过某行」的歧义。
9. **Python 细节**：右趟 `range(n - 2, -1, -1)` 别写成 `range(n - 2, 0, -1)`（漏掉 $c=0$）；`dp = points[0][:]` 要拷贝，防止原地修改与输入别名（LeetCode 上无碍，本地对拍时是坑）。
10. **读改同一数组不是 bug**：左趟读「已更新的左邻」是衰减链接力的机制（引理 3 第一步归纳依赖它）；若抄成「先快照副本再扫描」，衰减只传一步，答案错。这与「先累加后扩散」一样，都是把**语义顺序**写错的典型位置。

**延伸思考**：

- **距离变换的一般化**：两趟扩散 = 一维 L1 距离变换。把「$-|c-c'|$」换成「$-\text{dist}(c, c')$」对任何**链上度量**（每步代价一致地衰减传递）都成立；二维网格上的曼哈顿距离变换则要正反两趟各合并两个方向（左上 → 右下）。识别出「max-min 与距离的可分离结构」是这类题的通用钥匙。
- **凹包络 / 斜率技巧视角**：$g(x) = \max_{c'}(v[c'] - |x - c'|)$ 是一族「帐篷函数」的**上包络**——凹、分段线性、斜率 $\pm 1$。若扣分推广为凸函数 $h(|c - c'|)$（如平方），两趟 $\pm 1$ 衰减失效，需转 **slope trick**（可并堆维护折线）或决策单调性。从「衰减传递」到「斜率维护」，是这族问题从 Medium 通往 Hard 的那条路。
- **环形列**：若第 $0$ 列与第 $n-1$ 列视为相邻（扣分取 $\min(|c-c'|, n - |c-c'|)$），扩散的两趟扫描不再直接适用——环上破链、或前后缀拆两段拼接，值得动手推一推。
- **输出具体方案**：转移时另存 `argmax` 来源列，末行从最优格回溯，空间退化为整表 $O(mn)$，时间不变。
- **min 版镜像**：把全部 max 换成 min（配合可负的点数）即「最小化总分」——转移结构照搬，前后缀 min / 反向扩散同理可写，可用于对拍检验对偶理解。
