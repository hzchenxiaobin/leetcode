# LeetCode 新增的最少台阶数 题解

## 1. 题目概述

- **标题 / 题号**：新增的最少台阶数（#1936，medium）
- **链接**：https://leetcode.cn/problems/add-minimum-number-of-rungs/
- **来源**：LeetCode 第 250 场周赛 Q2
- **难度**：中等
- **标签**：贪心、数组、数学

**题意**：梯子的台阶高度由**严格递增**数组 `rungs` 给出，你站在高度为 $0$ 的地板上要爬到最后一级。每次移动只能到达比当前位置**高不超过 `dist`** 的台阶；可以在任意**正整数**高度处插入新台阶。求爬到最后一级必须添加的**最少**台阶数。

**约束**：

- $1 \le \text{rungs.length} \le 10^5$
- $1 \le \text{rungs}[i] \le 10^9$
- $1 \le \text{dist} \le 10^9$
- `rungs` 严格递增

> 💡 本题在本仓库另有[每日题解 1936](../../solution/1901-2000/1936_新增的最少台阶数.md)，两篇为姊妹篇：那边侧重贪心直觉、闭式推导，以及 ceiling-division 与「二分答案」家族（875/1011）的对照和面试问答。本篇按周赛复盘视角，聚焦**从「逐级模拟」到「一次整除」的最短推理路径**、**差 1 的三副面孔**（`gap/dist`、`gap/dist-1`、浮点 `ceil` 各自翻车的精确位置），并补全「间隔独立」的完整**下界—构造**证明链（路径穿越论证）。两篇互为印证。

## 3. 解题思路

### 3.1 赛场直觉：逐级模拟填补（暴力）

最直观的做法：从地板出发，面对下一个目标台阶，若当前高度 $+\ \text{dist}$ 还够不到，就在「当前高度 $+\ \text{dist}$」处补一根台阶并站上去，循环直到够得着，再转向下一个目标台阶。

```text
cur = 0, ans = 0
对每个目标台阶 r：
    while cur + dist < r:     # 还够不到
        cur += dist           # 在 cur+dist 处补台阶并站上去
        ans += 1
    cur = r                   # 跳上已有台阶
```

- **正确性**：每步尽量跳满 `dist`，铺满间隔显然最省（§5 给出严格证明）。
- **效率**：最坏单个间隔 $\text{gap} = 10^9$、$\text{dist} = 1$ 时 `while` 要循环 $10^9$ 次，总时间 $O(\sum \text{gap}/\text{dist})$——**TLE**。

> ⚠️ 瓶颈在于「一个间隔要补多少根」其实是个**纯数学问题**：间隔固定、步长固定，根数有闭式解，根本不用一步步模拟。把内层循环压成一次整除，就是本题作为 Q2 的全部考点。

### 3.2 核心观察：间隔独立 + 闭式解 (gap−1)//dist

![核心观察：各间隔独立求解，单段补 (gap−1)//dist 根](images/wc250_q2_gap_independence.svg)

两条观察叠加：

**① 间隔之间相互独立。**「严格递增」意味着**原台阶只出现在间隔端点**，每个间隔内部空无一物。于是任何一根新增台阶都落在唯一一个间隔内部，只能为「从该间隔下端爬到上端」服务；站在某个已有台阶上时，下方已铺好、上方从该台阶重新起跳。**全局最少 = 各间隔独立求解之和**（§5 用路径穿越论证严格化）。

**② 单个间隔的补法有闭式解。** 设间隔 $\text{gap} = r - \text{prev}$。从下端爬到上端、每步至多 `dist`，至少需要 $\lceil \text{gap}/\text{dist} \rceil$ 步；这串步子的**中间落脚点**必须自己补，而**终点台阶已存在**——所以要补的根数是「步数 $-1$」：

$$\text{add} = \left\lceil \frac{\text{gap}}{\text{dist}} \right\rceil - 1 = \frac{\text{gap} - 1}{\text{dist}} \;\;\text{（整除）}$$

最后一步等号是整数向上取整恒等式 $\lceil a/b \rceil = (a + b - 1)\,/\,b$ 的直接推论（§5 引理 1）。

$$\boxed{\text{ans} = \sum_{i} \frac{\text{gap}_i - 1}{\text{dist}} \;\; \text{（每个间隔整除后求和）}}$$

> ⚠️ **差 1 照妖镜**：当 $\text{gap} = \text{dist}$（一步直达）时，$\text{gap}/\text{dist}$ 会给出 $1$（多补一根），而 $(\text{gap}-1)/\text{dist}$ 给出 $0$ ✓。更隐蔽的陷阱是 $\text{gap}/\text{dist} - 1$：它在 $\text{gap} = \text{dist}$ 时恰好正确，却在 $\text{gap} < \text{dist}$ 时给出 $-1$——两个错误写法各翻车在不同的半区，只有 $(\text{gap}-1)//\text{dist}$ 全域正确，且对 $\text{gap} \le \text{dist}$ **自动归零、无需特判**（详见 §8）。

### 3.3 算法流程

![算法流程：单趟扫描，每个间隔一次整除](images/wc250_q2_algorithm_flow.svg)

1. **初始化**：`prev = 0`（**地板高度**，不是 `rungs[0]`），`ans = 0`。
2. **扫描**：对每个台阶 $r$（从左到右）：计算 $\text{gap} = r - \text{prev}$，执行 `ans += (gap - 1) // dist`，再更新 `prev = r`。
3. **返回** `ans`。

整个算法是一条没有 `if` 分支的直链：$\text{gap} \le \text{dist}$ 的段整除自动得 $0$，不需要任何特判——这正是闭式解相对暴力模拟的最大工程价值。

### 3.4 示例演算

![示例演算：rungs=[1,3,5,10], dist=2 与示例 3 的对照](images/wc250_q2_example_walkthrough.svg)

以示例 1（`rungs = [1,3,5,10]`，`dist = 2`）逐间隔套公式：

| 步骤 | prev | r | gap | (gap−1)//2 | ans |
|------|------|------|-----|-----------|-----|
| 1 | 0（地板） | 1 | 1 | 0 | 0 |
| 2 | 1 | 3 | 2 | 0 | 0 |
| 3 | 3 | 5 | 2 | 0 | 0 |
| 4 | 5 | 10 | 5 | **2** | **2** |

前三个间隔 $\le 2$ 自动贡献 $0$；只有 $5 \to 10$ 这段 $\text{gap} = 5$ 需补 $(5-1)//2 = 2$ 根（落在高度 $7$、$8$，恰为每步跳满 $2$ 的构造位置）。最终 `ans = 2` ✓。

示例 3（`rungs = [3,4,6,7]`，`dist = 2`）专照「起点」这个坑：第一段是 $\text{rungs}[0] - 0 = 3 > 2$，补 $(3-1)//2 = 1$ 根（高度 $1$）；若误把 `prev` 初始化成 `rungs[0]`，第一段变成 $0$，直接漏掉这 $1$ 根。

## 4. 算法细节

1. **`prev` 滚动变量**：初始为 $0$ 表示地板；第一个间隔是 $\text{rungs}[0] - 0$。这是「链式起跳点」的标准写法——上一个台阶永远是下一段的起跳点，无需额外数组存差分。
2. **整数实现的直译**：`(gap - 1) / dist` 即 $(\text{gap}-1)\,//\,\text{dist}$；代码里直接写 `(r - prev - 1) / dist`。**严格递增保证 $\text{gap} \ge 1$**，故 `gap - 1 ≥ 0`，不存在 C++ 负数整除（向零取整）与 Python `//`（向下取整）语义分叉的歧义。
3. **别用浮点 `ceil`**：`ceil((double)gap / dist)` 在 $10^9$ 量级有精度风险——商的 double 表示可能略小于/略大于真值，让恰好整除的情形被 `ceil` 多进一位。整数恒等式 $(\text{gap}-1)//\text{dist}$ 无此问题，且少一次类型转换。
4. **构造位置**（对拍/可视化时用）：间隔内最省的补法是「每步跳满 `dist`」，即新台阶放在 $r_{i-1} + j \cdot \text{dist}$（$j = 1, \dots, \lceil \text{gap}/\text{dist} \rceil - 1$）。注意「跳满」只是一种达到最优的构造，**答案只关心根数不关心位置**。
5. **溢出核算**：全程只有减法与整除、无乘法；$\text{gap} \le 10^9 < 2^{31}-1$，`int` 可容纳；$\text{ans} \le \sum \text{gap}_i / \text{dist} \le \text{rungs}[n-1] \le 10^9$ 也在 `int` 内——但 C++ 用 `long long` 累加是零成本的防御性习惯（防改约束、防手滑写错中间量）。

## 5. 正确性证明

先把「合法攀爬」形式化：它是一个立足点序列 $0 = p_0 < p_1 < \dots < p_m = \text{rungs}[n-1]$（每次移动只能到达**更高**的台阶，故序列严格递增），满足相邻差 $p_{t+1} - p_t \le \text{dist}$，且每个 $p_t\ (t \ge 1)$ 是原有台阶或新增台阶。目标是最小化新增台阶数。记 $r_{-1} := 0$（地板），间隔 $\text{gap}_i = \text{rungs}[i] - \text{rungs}[i-1] > 0$（$i = 0, \dots, n-1$）。

**引理 1（整数恒等式）**：对正整数 $g \ge 1$、$d \ge 1$，$\lceil g/d \rceil - 1 = \lfloor (g-1)/d \rfloor$。

**证明**：带余除法 $g = qd + r$，$0 \le r < d$。若 $r = 0$：左边 $= q - 1$；右边 $qd - 1 = (q-1)d + (d-1)$ 整除得 $q - 1$ ✓。若 $r \ge 1$：左边 $= (q+1) - 1 = q$；右边 $qd + r - 1 = qd + (r - 1)$ 且 $0 \le r - 1 < d$，整除得 $q$ ✓。∎

**引理 2（单间隔下界）**：设 $a < b$，$g = b - a$。任何起点 $\le a$、终点 $\ge b$、严格递增、相邻差 $\le \text{dist}$ 的立足点序列，落在开区间 $(a, b)$ 内的立足点**至少** $\lceil g/\text{dist} \rceil - 1$ 个。

**证明**：设序列为 $q_0 \le a$、$q_k \ge b$。取 $u$ 为最后一个满足 $q_u \le a$ 的下标、$v$ 为第一个满足 $q_v \ge b$ 的下标；由严格递增，$\le a$ 的项全部先于 $\ge b$ 的项，故 $u < v$ 且两者均存在。由 $u$ 的最后性与 $v$ 的最先性，中间项 $q_{u+1}, \dots, q_{v-1}$ 全部严格落在 $(a, b)$ 内。这段共 $v - u$ 步，总爬升 $q_v - q_u \ge b - a = g$，而每步 $\le \text{dist}$，故 $(v - u) \cdot \text{dist} \ge g$，即 $v - u \ge \lceil g/\text{dist} \rceil$。中间项个数 $= v - u - 1 \ge \lceil g/\text{dist} \rceil - 1$。∎

**引理 3（下界对全体间隔求和）**：对任何合法攀爬，新增台阶总数 $\ge \sum_{i=0}^{n-1} \left( \lceil \text{gap}_i/\text{dist} \rceil - 1 \right)$。

**证明**：对每个间隔 $(\text{rungs}[i-1], \text{rungs}[i])$，攀爬序列满足引理 2 的前提（起点 $p_0 = 0 \le \text{rungs}[i-1]$，终点 $p_m = \text{rungs}[n-1] \ge \text{rungs}[i]$），故至少有 $\lceil \text{gap}_i/\text{dist} \rceil - 1$ 个立足点落在该间隔**内部**。这些立足点只能是**新增**台阶——原台阶的高度恰为各间隔端点，严格递增保证任何间隔内部没有原台阶。又不同间隔的内部两两不交，同一新增台阶不会被两个间隔重复计数。把 $n$ 个间隔的不等式相加即得。∎

**引理 4（构造达到下界）**：在每个间隔内部按 $r_{i-1} + j \cdot \text{dist}$（$j = 1, \dots, \lceil \text{gap}_i/\text{dist} \rceil - 1$）插入新台阶，则存在合法攀爬且新增数恰为 $\sum_i \left( \lceil \text{gap}_i/\text{dist} \rceil - 1 \right)$。

**证明**：逐条验证构造的合法性。**① 内部性**：$j \le \lceil \text{gap}_i/\text{dist} \rceil - 1$ 故 $j \cdot \text{dist} \le (\lceil \text{gap}_i/\text{dist} \rceil - 1) \cdot \text{dist} < \text{gap}_i$（因 $\lceil x \rceil < x + 1$），新台阶严格落在间隔内部，不与原台阶重合；**② 可达性**：相邻新台阶相距恰 $\text{dist}$，首个距下端 $r_{i-1}$ 恰 $\text{dist}$，末个距上端 $r_i$ 为 $\text{gap}_i - (\lceil \text{gap}_i/\text{dist} \rceil - 1)\,\text{dist} \le \text{dist}$（因 $\lceil \text{gap}_i/\text{dist} \rceil \cdot \text{dist} \ge \text{gap}_i$）；**③ 正整数高度**：各 $r_{i-1} \ge 0$、$\text{dist} \ge 1$ 均为整数，故 $r_{i-1} + j \cdot \text{dist} \ge 1$ 是正整数，满足题面「正整数高度」的限制。按 $0 \to \dots \to r_0 \to \dots \to r_1 \to \dots \to \text{rungs}[n-1]$ 依次踩过即为合法攀爬。∎

**定理（算法正确性）**：最少新增台阶数

$$\text{ans} = \sum_{i=0}^{n-1} \left( \left\lceil \frac{\text{gap}_i}{\text{dist}} \right\rceil - 1 \right) = \sum_{i=0}^{n-1} \left\lfloor \frac{\text{gap}_i - 1}{\text{dist}} \right\rfloor$$

算法（§3.3 一趟扫描逐段整除累加）返回该值。

**证明**：下界由引理 3 给出，引理 4 构造出达到该下界的方案，故最小值等于该和；再由引理 1 把每个 $\lceil \text{gap}/\text{dist} \rceil - 1$ 换为 $(\text{gap}-1)\,//\,\text{dist}$，即算法所算的表达式。∎

**推论（免特判）**：$\text{gap}_i \le \text{dist}$ 的间隔贡献为 $0$：此时 $0 \le \text{gap}_i - 1 < \text{dist}$，整除为 $0$。特别地 $\text{gap}_i = \text{dist}$ 时贡献 $0$ 而非 $1$。∎

> 💡 **证明的关键一步**是引理 2 的「穿越段」：不管攀爬路径如何曲折（事实上每步向上、路径必然严格递增），从 $\le a$ 到 $\ge b$ 的总爬升摆在那儿，步长受限就逼出步数下界，而每一步的中间落脚点都必须是**该间隔内部**的新增台阶。下界与构造相会，闭式解即为最优——这是「贪心 = 交换论证 / 下界构造」范式在一维数轴上的最干净样例。

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。一趟遍历 `rungs`，每个台阶一次减法、一次整除、一次累加，均为 $O(1)$。对照暴力模拟的 $O(\sum \text{gap}/\text{dist})$（最坏 $10^9$ 次循环）：把「按步模拟」替换为「一次整除」，内层循环被数学消除。$n \le 10^5$ 下瞬时通过。
- **空间复杂度**：$O(1)$。仅 `prev`、`ans` 两个标量，不建立差分数组、不拷贝输入。

## 7. 参考代码

### C++（prev 滚动 + 整数整除）

```cpp
class Solution {
public:
    int addRungs(vector<int>& rungs, int dist) {
        long long ans = 0;
        int prev = 0;
        for (int r : rungs) {
            ans += (r - prev - 1) / dist;
            prev = r;
        }
        return ans;
    }
};
```

### Python（同构直译）

```python
class Solution:
    def addRungs(self, rungs: List[int], dist: int) -> int:
        ans = 0
        prev = 0
        for r in rungs:
            ans += (r - prev - 1) // dist
            prev = r
        return ans
```

### Python（赛场一行流：zip 拼出起跳点）

```python
class Solution:
    def addRungs(self, rungs: List[int], dist: int) -> int:
        return sum((r - p - 1) // dist for r, p in zip(rungs, [0] + rungs[:-1]))
```

> 💡 **写法对照**：① 三个版本核心都是 `(gap − 1) // dist`，公式对了怎么写都对；② `prev` 初始为 $0$（地板），第一个间隔是 `rungs[0] − 0`——一行流里 `[0] + rungs[:-1]` 正是「起跳点序列」：地板拼上去掉末项；③ C++ 累加用 `long long` 防御（§4.5 核算过 `int` 其实够），Python 整数任意精度无虑。以上实现均已通过官方样例 1–4 及 `gap = dist`、`gap < dist`、单台阶、$10^9$ 极值等自造边界，并与暴力 `while` 模拟版互拍随机数据（小值域下）验证一致。

## 8. 边界情况与易错点

1. **差 1 的三副面孔（本题第一大 WA 来源）**：
   - `gap // dist`：当 $\text{gap} = \text{dist}$ 时得 $1$，多补一根。自造样例 `rungs=[5], dist=5`：正确 $0$，此写法得 $1$。
   - `gap / dist - 1`：当 $\text{gap} < \text{dist}$ 时得 $-1$，累加后答案偏小甚至为负；且它在 $\text{gap} = \text{dist}$ 时恰好正确（$1-1=0$），官方样例若只覆盖这种情形就照不出来。自造样例 `rungs=[1], dist=2`：正确 $0$，此写法得 $-1$。
   - `(gap - 1) // dist`：全域正确，且 $\text{gap} \le \text{dist}$ 时**自动归零**，代码里没有任何 `if`。
2. **起点是地板，不是第一级台阶**：`prev` 初始为 $0$，第一段间隔是 $\text{rungs}[0] - 0$。示例 3（`rungs=[3,4,6,7]`）的第一段 $\text{gap}=3$ 贡献 $1$；若误把 `prev` 初始化成 `rungs[0]`，第一段变 $0$，直接漏 $1$。
3. **别用浮点 `ceil`**：$10^9$ 量级的商在 `double` 下可能有微小误差，恰整除的情形被 `ceil` 错误进位。坚持整数恒等式 $(\text{gap}-1)//\text{dist}$。
4. **「步数」与「根数」相差 $1$**：跨一段需 $\lceil \text{gap}/\text{dist} \rceil$ **步**，但终点台阶已存在，要补的是**中间落脚点**数 $\lceil \text{gap}/\text{dist} \rceil - 1$。这个「$-1$」是差 1 陷阱的根源——想清楚「步数 $-1 =$ 中间点数」就不会错。
5. **C++ 负数整除的语义坑**：`gap/dist - 1` 的错误在 C++ 与 Python 中表现一致（先整除后减法，无整除歧义），但若写成 `(gap - dist) / dist` 之类含负数参与的整除，C++ 向零取整与 Python 向下取整在负数上分叉——本题 `gap ≥ 1` 使正确写法恒非负，天然避开这个坑。
6. **新增台阶必须落在正整数高度**：无需特判——构造位置 $r_{i-1} + j \cdot \text{dist}$ 由非负整数相加而来且 $\ge 1$（引理 4③），且答案只依赖根数不依赖具体位置。
7. **插入的台阶可以不被踩**：题目只要求「能到达最后一级」。下界证明（引理 3）只统计**被踩的**新增台阶，闲置的新增台阶只会让总数更大，最优方案不会放废台阶——无需考虑「插了不踩能否省根数」这种伪优化。
8. **单台阶输入（$n = 1$）**：只有「地板 $\to \text{rungs}[0]$」一段，公式照常工作（示例 4），无空数组（约束 $n \ge 1$）。
9. **溢出核算**：全程无乘法，`gap ≤ 10^9` 在 `int` 内；$\text{ans} \le \text{rungs}[n-1] \le 10^9$ 也在 `int` 内。C++ 仍建议 `long long` 累加做防御，Python 无此顾虑。

**延伸思考**：

- **允许向下移动会怎样**：若每次移动改为「与当前位置高度差 $\le \text{dist}$」（双向），答案不变——下界论证（引理 2 的穿越段）只依赖「从 $\le a$ 到达 $\ge b$」的爬升总量，向下绕路只会多要落脚点；而构造本身是单调路径。把这条想清楚，能加深对「下界证明为何只看穿越」的理解。
- **改问「最少移动步数」**：答案变为 $\sum_i \lceil \text{gap}_i/\text{dist} \rceil$，与本题答案恰差 $n$（路径上每级原台阶贡献一步）。这个关系也可以反着用来对拍两问的答案。
- **流式版**：若 `rungs` 逐个到来且需随时回答「当前前缀的最少补梯数」，维护 `(prev, 前缀和)` 即可 $O(1)$ 摊还响应——闭式解天然支持在线化，暴力模拟则要重跑。
- **加权变体**：若移动一步代价 $1$、新增一个台阶代价 $c$，段内仍独立（段间不借贷不变），但「跳满 dist」未必最优——段内是「步数与新增数的凸权衡」，退化为一个小型极值问题，值得动手推一推。
