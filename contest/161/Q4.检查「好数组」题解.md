# LeetCode 检查「好数组」 题解

## 1. 题目概述

- **标题 / 题号**：检查「好数组」（#1250，hard）
- **链接**：https://leetcode.cn/problems/check-if-it-is-a-good-array/
- **来源**：LeetCode 第 161 场周赛 Q4
- **难度**：困难
- **标签**：数组、数学、最大公约数、数论、欧几里得算法、扩展欧几里得算法、裴蜀定理

**题意**：给定正整数数组 `nums`，允许任选一个**非空子集**，给子集里的每个数乘上一个**任意整数**（可以为 0，也可以为负），再把乘积累加。如果存在某个子集与某组系数使和恰好为 $1$，就称 `nums` 是「好数组」，返回 `true`；否则返回 `false`。

换个说法：问是否存在若干下标 $i_1, \dots, i_k$ 与整数 $c_1, \dots, c_k$，使

$$c_1 \cdot \text{nums}[i_1] + c_2 \cdot \text{nums}[i_2] + \dots + c_k \cdot \text{nums}[i_k] = 1$$

注意系数**不要求非负、不要求非零、也没有上界**——这一点是本题能被秒杀的关键。

**约束**：

- $1 \le \text{nums.length} \le 10^5$
- $1 \le \text{nums}[i] \le 10^9$
- 元素全部为正整数（不含 $0$，因此子集 gcd 不会退化为 $0$）

## 2. 示例

**示例 1**

```text
输入：nums = [12,5,7,23]
输出：true
解释：挑选 5 和 7：5*3 + 7*(-2) = 15 - 14 = 1。
      其实挑 12 和 5 也行：12*3 + 5*(-7) = 36 - 35 = 1。
```

**示例 2**

```text
输入：nums = [29,6,10]
输出：true
解释：挑选 29、6、10：29*1 + 6*(-3) + 10*(-1) = 29 - 18 - 10 = 1。
      只挑 29 和 6 也够：29*(-1) + 6*5 = -29 + 30 = 1。
```

**示例 3**

```text
输入：nums = [3,6]
输出：false
解释：任何子集的任何整数系数组合都是 3 的倍数：
      3x + 6y = 3(x + 2y)，永远凑不出 1。
```

## 3. 解题思路

### 3.1 暴力思路

最直白的做法是「枚举子集 + 枚举系数」：子集有 $2^{n}-1$ 个，而系数在全整数范围内取值，是**无穷**的，根本枚举不完；即使人为截断到 $[-K, K]$，正确性也无法保证（裴蜀定理给出的系数可以大到 $O(\max/\gcd)$ 量级）。

退一步的「半暴力」是只枚举子集并计算子集 gcd，看是否有子集 gcd 为 $1$，复杂度 $O(2^n \cdot n)$。$n = 10^5$ 时这是天文数字。

关键的问题是：**「能否凑出 1」和「子集长什么样」其实无关**，它只取决于一个数论量——gcd。找出这个量，题目就退化成一次线性扫描。

### 3.2 核心观察：裴蜀定理，可达和恰好是 gcd 的倍数

![裴蜀定理：可达和恰是 gcd 的倍数](images/wc161_q4_bezout_model.svg)

**观察**：固定一个非空子集 $S$，给每个元素配任意整数系数，能得到的所有和构成集合

$$\Sigma(S) = \Bigl\{\textstyle\sum_{a \in S} c_a \cdot a \;:\; c_a \in \mathbb{Z}\Bigr\}$$

这个集合**恰好是** $g = \gcd(S)$ 的全部倍数，即 $\Sigma(S) = g\mathbb{Z}$：

- 每个 $a \in S$ 都是 $g$ 的倍数，所以任意整数组合也是 $g$ 的倍数（$\Sigma(S) \subseteq g\mathbb{Z}$）；
- 反过来，由**裴蜀定理（Bézout's lemma）**，$g$ 本身可以写成 $S$ 中元素的整数系数组合，于是 $g\mathbb{Z}$ 里每个数都能被表示（$g\mathbb{Z} \subseteq \Sigma(S)$）。

于是「某个子集能凑出 $1$」等价于「某个子集的 $\gcd = 1$」。

再补一步：全体元素的 $\gcd$ 记为 $G$。因为 $G$ 整除每个 $\text{nums}[i]$，它当然也是任意子集 $S$ 的公约数（$G \mid \gcd(S)$）。所以

$$G = 1 \;\Longrightarrow\; \text{取 } S = \text{全体有 } g_S = 1 \;\Longrightarrow\; 1 \in \Sigma(S)$$

反过来若存在子集 $\gcd(S) = 1$，由 $G \mid \gcd(S) = 1$ 得 $G = 1$。两边合起来：

$$\text{好数组} \iff \gcd(\text{nums}[0], \text{nums}[1], \dots, \text{nums}[n-1]) = 1$$

**答案就是全体元素的 gcd 是否为 1**，不需要真的构造系数，也不需要知道是哪个子集。

### 3.3 算法流程：一次扫描维护全局 gcd

![一次扫描：g 单调不增，碰到 1 立刻返回](images/wc161_q4_gcd_scan_flow.svg)

1. 令 $g \leftarrow 0$（$0$ 是 gcd 的单位元：$\gcd(0, x) = x$，省掉首元素特判）。
2. 依次读入 $x = \text{nums}[i]$，更新 $g \leftarrow \gcd(g, x)$。
3. 若此时 $g = 1$，说明前 $i+1$ 个元素已经构成一组「gcd 为 1 的子集」，**立刻返回 `true`**，后面的元素不必再看。
4. 全部读完仍没有出现 $1$，说明 $G > 1$，返回 `false`。

**为什么可以提前退出**：$g$ 是不断与新的数取 gcd 得到的，所以 $g$ 只会**单调不增**（每次取 gcd 都是原来的约数）；一旦降到 $1$ 就再也降不下去，也不会有任何元素把它抬高。因此「第一次出现 1」就是判定成立的时刻。

### 3.4 示例演算

![三条 gcd 链：两次提前退出，一次失败](images/wc161_q4_gcd_walkthrough.svg)

| 数组 | gcd 链 | 结论 |
|------|--------|------|
| `[12,5,7,23]` | $12 \to \gcd(12,5)=1$（第 2 步退出） | `true`，子集 $\{12,5\}$ 即可 |
| `[29,6,10]` | $29 \to \gcd(29,6)=1$（第 2 步退出） | `true`，子集 $\{29,6\}$ 即可 |
| `[3,6]` | $3 \to \gcd(3,6)=3$（读完仍未到 1） | `false`，所有和都是 3 的倍数 |

三组都能用裴蜀证书验证：$12\cdot 3 + 5\cdot(-7) = 1$、$29\cdot(-1) + 6\cdot 5 = 1$、$5\cdot 3 + 7\cdot(-2) = 1$；而 $3x + 6y = 3(x + 2y)$ 恒为 3 的倍数，$1$ 永远缺席。

> 💡 注意示例 1 与示例 2 的官方解释都挑了「三个数」，但按本题逻辑，只要 gcd 链在某个前缀上降到 1，那个前缀就够用——系数存在性由裴蜀定理保证，不需要与官方示例挑同一个子集。

## 4. 算法细节

1. **初值取 $g = 0$**：$\gcd(0, x) = x$，这样循环体不需要为 $i = 0$ 特判，也不会误把 `nums[0]` 当成答案来源。
2. **提前退出必须放在更新之后**：先 `g = gcd(g, x)` 再判 `g == 1`。如果放在更新之前，单元素数组 `[1]` 会漏判。
3. **用库函数**：C++ 用 `std::gcd`（`<numeric>`，C++17），Python 用 `math.gcd`。两者都处理 $0$，都返回非负值，不需要自己写欧几里得。
4. **不需要扩展欧几里得**：本题只问「是否存在」整数系数，不要求输出系数。扩展欧几里得只在需要**构造**那组 $c_i$ 时才必需（见延伸思考）。
5. **系数允许为负是本解成立的前提**：若把「乘以任意整数」误读成「乘以正整数」，[2, 3] 这类数组会从 `true` 变成 `false`，本题就退化成一个不好做的硬币问题。
6. **位宽安全**：全程只做 gcd，不对元素做乘法，所以 $10^9$ 的数值不会溢出；C++ 用 `int` 足够，但把 $g$ 写成 `long long` 也无害。
7. **收尾写法**：循环结束后若没有提前返回，则必有 $g > 1$，因此 `return g == 1` 与 `return false` 等价；写成前者还能顺带兜住「空数组」这种题面之外的输入。
8. **$n$ 很大时也只需一遍**：$10^5$ 个元素、每个一次 gcd，实测 Python 约 6 ms，C++ 更快。

## 5. 正确性证明

**引理 1（子集 gcd 被全体 gcd 整除）**：设 $G = \gcd(\text{nums}[0..n-1])$，$S$ 为任意非空子集，$g_S = \gcd(S)$，则 $G \mid g_S$。

**证明**：$G$ 整除每个 $\text{nums}[i]$，故 $G$ 整除 $S$ 中每个元素，即 $G$ 是 $S$ 的一个公约数；而 $g_S$ 是 $S$ 的最大公约数，最大公约数被任何公约数整除，故 $G \mid g_S$。∎

**引理 2（可达集 $=$ 倍数集）**：对任意非空子集 $S$，$\Sigma(S) = \{ \sum_{a\in S} c_a a : c_a \in \mathbb{Z}\} = g_S \mathbb{Z}$。

**证明**：

- $\Sigma(S) \subseteq g_S\mathbb{Z}$：$g_S$ 整除每个 $a \in S$，设 $a = g_S \cdot a'$，则 $\sum c_a a = g_S \sum c_a a' \in g_S\mathbb{Z}$。
- $g_S\mathbb{Z} \subseteq \Sigma(S)$：只需证 $g_S \in \Sigma(S)$，其余倍数乘以整数即可。对 $|S|$ 归纳：$|S| = 1$ 时 $g_S = a = 1 \cdot a$；设对 $|S| - 1$ 成立，记 $S' = S \setminus \{a_k\}$，$g' = g_{S'} = \sum_{a \in S'} c_a a$，由两个数的裴蜀定理存在 $u, v \in \mathbb{Z}$ 使 $g_S = \gcd(g', a_k) = u g' + v a_k = \sum_{a\in S'} (u c_a) a + v a_k$，仍在 $\Sigma(S)$ 中。∎

**引理 3（$G = 1 \iff$ 存在 gcd 为 1 的子集）**：

**证明**：

- ($\Rightarrow$) 取 $S = $ 全体，$g_S = G = 1$。
- ($\Leftarrow$) 若某 $S$ 满足 $g_S = 1$，由引理 1 得 $G \mid 1$，而 $G \ge 1$，故 $G = 1$。∎

**定理**：`isGoodArray(nums)` 返回 `true` 当且仅当 `nums` 是好数组。

**证明**：

- ($\Leftarrow$) 设 `nums` 是好数组，则存在非空子集 $S$ 与整数系数使和为 $1$，即 $1 \in \Sigma(S)$。由引理 2，$\Sigma(S) = g_S\mathbb{Z}$，而 $1 \in g_S\mathbb{Z}$ 迫使 $g_S = 1$；再由引理 3 得 $G = 1$。算法在扫描到 $S$ 中最后一个元素时（最迟读完整个数组）必使 $g$ 降到 $1$，从而返回 `true`。
- ($\Rightarrow$) 设算法返回 `true`，则存在某个前缀 $P$ 使 $\gcd(P) = 1$。由引理 2，$\Sigma(P) = 1\cdot\mathbb{Z}$ 包含 $1$，即该前缀（一个非空子集）能凑出 $1$，故 `nums` 是好数组。
- 若算法返回 `false`，则 $G > 1$。对任意非空子集 $S$，由引理 1 有 $G \mid g_S$，由引理 2 其可达和全是 $g_S$ 的倍数，从而是 $G \ge 2$ 的倍数，不可能等于 $1$，故不是好数组。∎

## 6. 复杂度分析

- **时间**：$O(n \log V)$，其中 $V = \max(\text{nums}) \le 10^9$。单次 $\gcd$ 是欧几里得算法，$O(\log V)$；总共至多 $n$ 次。由于 $g$ 单调不增且一旦为 $1$ 就提前返回，实际常数远小于上界。判定本身是 $\Omega(n)$ 的（最坏情况要读完全部输入，如 `[3,6]`）。
- **空间**：$O(1)$。只维护一个整数 $g$，不建任何辅助数组；输入数组本身不算额外空间。

## 7. 参考代码

### C++

```cpp
#include <numeric>
#include <vector>
using namespace std;

class Solution {
public:
    bool isGoodArray(vector<int>& nums) {
        int g = 0;                       // gcd 的单位元：gcd(0, x) = x
        for (int x : nums) {
            g = std::gcd(g, x);
            if (g == 1) return true;     // 触到 1 就可以提前退出
        }
        return g == 1;                   // 读完仍未到 1 ⇒ false
    }
};
```

### Python

```python
from math import gcd
from typing import List


class Solution:
    def isGoodArray(self, nums: List[int]) -> bool:
        g = 0                            # gcd 的单位元：gcd(0, x) = x
        for x in nums:
            g = gcd(g, x)
            if g == 1:                   # 触到 1 就可以提前退出
                return True
        return g == 1                    # 读完仍未到 1 ⇒ False
```

## 8. 边界情况与易错点

1. **单元素数组**：`[1]` → `true`（$1 \cdot 1 = 1$）；`[2]` → `false`。初值取 $0$ 且「先更新后判断」才不会漏掉 `[1]`。
2. **所有元素同为一个数 $d \ge 2$ 的倍数**：如 `[6, 10, 14]`，$G = 2$，任何组合都是偶数，返回 `false`。这是最容易在构造数据上暴露的错误（误以为「最小值是 1 就行」）。
3. **提前退出不能跳过判断**：把 `if (g == 1)` 写在循环外，答案仍然对，但会白跑满 $10^5$ 次；写在更新之前则会漏判。
4. **不要用 lcm**：判定过程若想着「所有数的 lcm 是否……」会立刻溢出（$n$ 个数连乘早就爆 `long long`），而且和题意无关。
5. **不要把系数当成非负**：题面说「乘以任意整数」，负系数合法，这正是裴蜀定理适用的条件；[2, 3] 用 $2\cdot(-1) + 3\cdot 1 = 1$ 成立，若限非负则连 $2$ 和 $3$ 都凑不出 $1$。
6. **子集必须非空**：空集的和恒为 $0$，与判定无关；因为元素都是正整数，只要非空子集的 gcd 为 1 就必能取到，不会出现「空集凑出 1」的退化。
7. **返回值类型**：Python 里 `return g == 1` 本身就是 `bool`，不要写成 `return g`（返回 `int`）；C++ 的 `bool` 返回也只会是 `true`/`false`。
8. **不要真的去构造系数**：即便用扩展欧几里得求出 $c_i$，也可能出现 $O(10^9)$ 量级的系数，中间乘积超出 64 位；本题只需要布尔判定，不必承担这个风险。

**延伸思考**：

1. **系数限非负**会怎样？此时问题变成「硬币问题」：$\gcd = 1$ 只是**必要**条件，`[2,3]` 仍凑不出 $1$（最小可用和为 $2$）；一般情形要用 Frobenius 数（两枚硬币时为 $ab - a - b$）或完全背包来判定。
2. **目标从 $1$ 换成 $k$**：结论立刻推广为 $\gcd(\text{nums}) \mid k$——这正是水壶问题的形式。
3. **要求输出一组系数**：需要对子集元素依次做扩展欧几里得，用归纳把两个数的解组合成 $k$ 个数的解；注意系数可能很大，要用 128 位或高精度。
4. **要求最小规模的子集**：问题变难，需要求「gcd 为 1 的最短子数组/子序列」，可用约数筛 + 状压/DP 或枚举约数做 $O(n \sqrt{V})$ 的处理，不再是一次扫描能解决的。
5. **数组允许含 $0$ 与负数**：$\gcd(0, x) = |x|$，$0$ 不改变 gcd，负数取绝对值，结论仍然成立——这解释了为什么用 $g = 0$ 作为初值是安全且优雅的。
