# LeetCode 交换字符使得字符串相同 题解

## 1. 题目概述

- **标题 / 题号**：交换字符使得字符串相同（#1247，medium）
- **链接**：https://leetcode.cn/problems/minimum-swaps-to-make-strings-equal/
- **来源**：LeetCode 第 161 场周赛 Q1
- **难度**：中等
- **标签**：贪心、数学、字符串

**题意**：给定两个等长字符串 `s1`、`s2`，二者只含 `'x'` 与 `'y'`。每次操作可以在**两个串之间**各选一个字符交换，即交换 `s1[i]` 与 `s2[j]`（$i = j$ 也允许），但**绝不允许**在同一个串内部交换。求使 `s1 == s2` 的**最少交换次数**；若无法做到，返回 `-1`。

**约束**：

- $1 \le \lvert s_1 \rvert, \lvert s_2 \rvert \le 1000$
- $\lvert s_1 \rvert = \lvert s_2 \rvert$
- `s1`、`s2` 只包含字符 `'x'` 或 `'y'`

> 💡 这是一道「签到题藏模板」：**答案只取决于两类失配各自的个数，与它们出现的位置完全无关**。想清楚这一点，代码只有五六行。

## 2. 示例

**示例 1**

```text
输入：s1 = "xx", s2 = "yy"
输出：1
解释：交换 s1[0] 与 s2[1]，得到 s1 = "yx"，s2 = "yx"。
      两个失配位置都是 A 型（s1 上是 x、s2 上是 y），一次交换同时修好两处。
```

**示例 2**

```text
输入：s1 = "xy", s2 = "yx"
输出：2
解释：交换 s1[0] 与 s2[0]，得到 s1 = "yy"，s2 = "xx"（A 型被翻成 B 型）；
      再交换 s1[0] 与 s2[1]，得到 s1 = "xy"，s2 = "xy"。
      不能直接交换 s1[0] 与 s1[1] 把 s1 变成 "yx"——交换只能跨两个串进行。
```

**示例 3**

```text
输入：s1 = "xx", s2 = "xy"
输出：-1
解释：只有下标 1 失配，a = 1、b = 0，失配总数为奇数；
      两串 x 的总数是 3（奇数），任何交换都只是搬运字符，总数不变，
      最终两串相等就必须各拿 3/2 个 x，矛盾，故无解。
```

三组示例正好对应三种结局：**同类配对 → 1 次**、**异类零头 → 2 次**、**奇偶挡死 → -1**。

## 3. 解题思路

### 3.1 暴力思路

把状态记成有序对 $(s_1, s_2)$，从初始状态做 BFS，每次枚举 $O(n^2)$ 个交换，状态总数 $4^n$；$n = 1000$ 时连存都存不下。即便只盯每个位置的对齐状态（「已对齐 / A 型 / B 型」三选一，共 $3^n$ 种），指数级也毫无希望。所以这题必须找**结构性结论**，而不是搜索。

### 3.2 核心观察：失配只有两类，同类可以一次两清

![失配位置只有两类](images/wc161_q1_mismatch_types.svg)

只看失配位置，按「方向」分类：

- **A 型**：`s1[i] = 'x'`、`s2[i] = 'y'`，个数记为 $a$；
- **B 型**：`s1[i] = 'y'`、`s2[i] = 'x'`，个数记为 $b$。

已对齐的位置（`s1[i] == s2[i]`）不需要、也不应该再动。下面三条是全部机理：

1. **两个 A 型位置 $i, j$**：交换 `s1[i]` 与 `s2[j]`。因为 `s2[j] = 'y'`，交换后 `s1[i] = 'y' = s2[i]`，位置 $i$ 对齐；同时 `s2[j] = 'x' = s1[j]`，位置 $j$ 也对齐。**一次修好两处**。两个 B 型同理。
2. **1 个 A 型 + 1 个 B 型**：直接交换会互相抵消成空操作（`s1[i] = 'x'` 换 `s2[j] = 'x'`，什么都没变）。正确做法是先做一次**同位置自交换** `s1[i] ↔ s2[i]`，把 A 型翻成 B 型（$i = j$ 是允许的，且不改动任何其它位置），于是变成两个 B 型，再按第 1 条花 1 次修好。合计 **2 次**。
3. **$a + b$ 为奇数**：两串 x 的总数是 $2\cdot(\text{双方都是 x 的位置数}) + a + b$，与 $a+b$ 同奇偶；而最终两串相等必须各含总数的一半个 x，故总数为奇数时**必然无解**。

因此贪心策略极其简单：**能同类配对就同类配对，剩下的零头只可能是「1 个 A + 1 个 B」，再补 2 次**。

### 3.3 算法流程

![贪心流程](images/wc161_q1_greedy_flow.svg)

1. 一次遍历统计 $a$、$b$（对齐位置直接跳过）。
2. 若 $(a + b)$ 为奇数，返回 `-1`。
3. 否则返回

$$\text{ans} = \left\lfloor \frac{a}{2} \right\rfloor + \left\lfloor \frac{b}{2} \right\rfloor + 2 \cdot (a \bmod 2)$$

因为 $a + b$ 是偶数，$a$ 与 $b$ 必然**同奇偶**，所以 $a \bmod 2$ 与 $b \bmod 2$ 相等，只看 $a$ 的奇偶即可。当 $a, b$ 都偶时答案是 $(a+b)/2$；都奇时是 $(a+b)/2 + 1$。

### 3.4 示例演算

![演算走查](images/wc161_q1_walkthrough.svg)

取 $s_1 = \text{"xxyxyy"}$、$s_2 = \text{"yyxyxx"}$，逐位比较得 $a = 3$（下标 0、1、3）、$b = 3$（下标 2、4、5），$a+b = 6$ 为偶数，有解。

| 步骤 | 操作 | 交换后 $s_1$ | 交换后 $s_2$ | 累计 |
|------|------|--------------|--------------|------|
| 初始 | — | `xxyxyy` | `yyxyxx` | 0 |
| 1 | 交换 `s1[0]` 与 `s2[1]`：A 型配对 | `yxyxyy` | `yxxyxx` | 1 |
| 2 | 交换 `s1[2]` 与 `s2[4]`：B 型配对 | `yxxxyy` | `yxxyyx` | 2 |
| 3 | 交换 `s1[3]` 与 `s2[3]`：把 A3 翻成 B 型 | `yxxyyy` | `yxxxyx` | 3 |
| 4 | 交换 `s1[3]` 与 `s2[5]`：B 型配对收尾 | `yxxxyy` | `yxxxyy` | 4 |

对照公式：$\lfloor 3/2 \rfloor + \lfloor 3/2 \rfloor + 2 = 1 + 1 + 2 = 4$，与走查一致。若在第 2 步后直接想「一次交换修掉剩下的 A3、B5」，会发现无解——这正是最后那 $+2$ 的来源。

## 4. 算法细节

1. **不要去模拟交换**。这道题的交换次数只与 $a$、$b$ 有关，模拟只会引入无关复杂度；把题面转成「数两种失配的个数」这一步就是全部建模工作。
2. **一次遍历同时数两类**：`if s1[i] == s2[i]: continue`，再按 `s1[i]` 是 `x` 还是 `y` 决定累加到 $a$ 还是 $b$。
3. **无解判据写成奇偶性**：`(a + b) % 2 == 1 → -1`。等价说法是「两串 x 的总数为奇数」。**不要**写成 `a != b`——示例 1 中 $a = 2, b = 0$ 明明有解，这是一个高频错误。
4. **公式统一**：`a // 2 + b // 2 + 2 * (a % 2)`。因为 $a+b$ 偶数蕴含 $a, b$ 同奇偶，所以 $2 \cdot (a \bmod 2)$ 同时覆盖了「都奇加 2」和「都偶加 0」两种情况，无需分叉。
5. **注意 Python 的整除与取模**：`//` 与 `%` 对非负整数就是下取整与余数，可以直接用；若写成 `/` 会得到浮点数，`//` 也不要换成 `int(a/2)` 这种绕路写法。
6. **接口按官方签名**：`int minimumSwap(string s1, string s2)` / `def minimumSwap(self, s1: str, s2: str) -> int`，参数按值传入即可，无需引用或额外数组。
7. **返回值范围**：最坏 $a = n$、$b = 0$（$n$ 为偶数），答案是 $n/2 \le 500$，`int` 足够，不必担心溢出。

## 5. 正确性证明

**引理 1（一次交换只影响两个位置）**：一次交换 `s1[i] ↔ s2[j]` 只可能改变位置 $i$ 与位置 $j$ 的对齐状态（当 $i = j$ 时只涉及位置 $i$ 一个），其余位置的对齐状态不变。

**证明**：交换只修改 `s1[i]` 和 `s2[j]` 两个字符；对齐状态 `s1[k] == s2[k]` 只依赖位置 $k$ 上的这两个字符，故除 $k \in \{i, j\}$ 外全部不变。∎

**引理 2（失配数减少 2 的充要条件）**：一次交换使失配位置总数 $m$ 减少 2，当且仅当它交换的是两个**同类型**的失配位置；其余任何交换都不会让 $m$ 减少（$m$ 不变或变大）。

**证明**：设交换 `s1[i]` 与 `s2[j]`。

- **$i = j$**：由引理 1 只涉及一个位置。失配位置交换后仍然失配（A 型变 B 型、B 型变 A 型），对齐位置交换后仍然对齐，故 $m$ 不变。
- **$i \ne j$，两者都失配**：位置 $i$ 对齐需交换后 `s1[i] = s2[j]` 等于 `s2[i]`；位置 $j$ 对齐需 `s2[j] = s1[i]` 等于 `s1[j]`。前者要求 `s2[j] = s2[i]`，后者要求 `s1[i] = s1[j]`，合起来即 $i, j$ 的失配方向相同（同为 A 型或同为 B 型）；反向代入可验证同型时两处确实同时对齐，故此时 $m$ 恰减少 2。
- **$i \ne j$，其中一个是已对齐位置**：不妨设位置 $j$ 已对齐，`s1[j] = s2[j] = c`。若交换后两处都对齐，则需 `s1[i] = c`（位置 $j$ 对齐）与 `s2[j] = c = s2[i]`（位置 $i$ 对齐），即 `s1[i] = s2[i] = c`，与 $i$ 失配矛盾。故 $m$ 不减少。∎

**引理 3（可行的充要条件）**：存在合法交换序列使 $s_1 = s_2$，当且仅当 $a + b$ 为偶数。

**证明**：交换只是把字符在**两个串之间搬运**，所有 $2n$ 个字符的多重集合不变，因此 `s1`、`s2` 中 x 的总数 $X$ 是不变量。最终两串相等意味着每串各含 $X/2$ 个 x，故 $X$ 必须为偶数。又设两串同时为 x 的位置有 $c$ 个，则 $X = 2c + a + b$，于是 $X$ 与 $a + b$ 同奇偶：$a+b$ 为奇数时无解。反之，当 $a+b$ 为偶数时，按 §3.3 的构造（同类两两配对，剩余 1 个 A + 1 个 B 时先自交换再配对）可以在有限步内让 $m$ 归零，故有解。∎

**定理（答案公式）**：当 $a + b$ 为偶数时，最少交换次数恰为

$$\left\lfloor \frac{a}{2} \right\rfloor + \left\lfloor \frac{b}{2} \right\rfloor + 2 \cdot (a \bmod 2)$$

当 $a + b$ 为奇数时无解，返回 $-1$。

**证明**：设 $T$ 为任意可行方案的交换次数。

**下界。** 由引理 2，每次交换使 $m$ 减少至多 2，而 $m$ 要从 $a+b$ 降到 $0$，故 $T \ge (a+b)/2$。

- 若 $a, b$ 均偶：$(a+b)/2 = \lfloor a/2 \rfloor + \lfloor b/2 \rfloor$，于是 $T \ge \lfloor a/2 \rfloor + \lfloor b/2 \rfloor$。
- 若 $a, b$ 均奇：反设 $T = (a+b)/2$。由于每步减少量不超过 2，$T$ 步的总减少量最多为 $2T = a+b$，要恰好清空就必须**每一步都把 $m$ 减 2**。由引理 2，这样的每一步都是同型配对，即把 $a$ 减 2 或把 $b$ 减 2——两种操作都**保持 $a$、$b$ 的奇偶性**。起始 $a, b$ 均为奇数，于是途中 $a, b$ 恒为奇数，永远不可能同时等于 $0$（$0$ 是偶数），矛盾。故 $T \ge (a+b)/2 + 1 = \lfloor a/2 \rfloor + \lfloor b/2 \rfloor + 2$。

**上界。** 按 §3.3 的构造：先做 $\lfloor a/2 \rfloor + \lfloor b/2 \rfloor$ 次同类配对，若还剩 1 个 A 与 1 个 B，再花 2 次（自交换翻型 + 配对），总步数恰为公式值，且每步都合法（自交换允许 $i = j$，配对只跨两串）。

上下界相等，故公式即最少交换次数。∎

## 6. 复杂度分析

- **时间**：$O(n)$。只需一次遍历，对每个下标做常数次比较与自增；随后的判奇偶与公式计算是 $O(1)$。$n \le 1000$ 时几乎零开销。
- **空间**：$O(1)$。只用了 $a$、$b$ 两个计数器，没有额外数组或哈希表；输入字符串本身不计入。

## 7. 参考代码

### C++

```cpp
#include <string>
using namespace std;

class Solution {
public:
    int minimumSwap(string s1, string s2) {
        int a = 0, b = 0;                       // a: (x,y) 型，b: (y,x) 型
        for (int i = 0; i < (int)s1.size(); ++i) {
            if (s1[i] == s2[i]) continue;       // 已对齐，完全忽略
            if (s1[i] == 'x') ++a;
            else ++b;
        }
        if ((a + b) % 2 == 1) return -1;        // 两串 x 总数为奇数，不可行
        return a / 2 + b / 2 + 2 * (a % 2);     // 同类配对 + 零头的 2 次
    }
};
```

### Python

```python
class Solution:
    def minimumSwap(self, s1: str, s2: str) -> int:
        a = b = 0                               # a: (x,y) 型，b: (y,x) 型
        for c1, c2 in zip(s1, s2):
            if c1 == c2:                        # 已对齐，完全忽略
                continue
            if c1 == 'x':
                a += 1
            else:
                b += 1
        if (a + b) % 2:                         # 两串 x 总数为奇数，不可行
            return -1
        return a // 2 + b // 2 + 2 * (a % 2)    # 同类配对 + 零头的 2 次
```

## 8. 边界情况与易错点

1. **两串本来就相同**：$a = b = 0$，公式给出 $0$，正确；不要写成至少 1 次。
2. **失配总数为奇数**：如 `s1 = "xx"`、`s2 = "xy"`（$a=1, b=0$）返回 `-1`；`s1 = "x"`、`s2 = "y"` 同样返回 `-1`。
3. **奇数零头必须补 2 而不是 1**：`s1 = "xy"`、`s2 = "yx"` 的答案是 2。很多错误解法直接返回 $(a+b)/2 = 1$，忽略了「异类失配无法一次修好」。
4. **别用 `a != b` 判无解**：示例 1 里 $a = 2, b = 0$ 却有解，正确判据是奇偶性。
5. **自交换合法但无效**：`s1[3] ↔ s2[3]` 这类同位置交换本身不解决任何失配，只有在「翻转类型、凑成同型配对」时才值得花这 1 次，不要误以为它总能省步数。
6. **大输入的计数**：$n = 1000$、`s1` 全 `x`、`s2` 全 `y` 时 $a = 1000$，答案 $500$；计数不要用 `int` 之外的奇怪类型，也不要在循环里做字符串拼接。
7. **越界与长度**：题面保证两串等长，但按 `zip`/同一下标遍历最稳；C++ 里 `s1.size()` 是 `size_t`，比较时转 `int` 可避开有符号/无符号警告。
