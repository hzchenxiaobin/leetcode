# LeetCode 移除无效的括号 题解

## 1. 题目概述

- **标题 / 题号**：移除无效的括号（#1249，medium）
- **链接**：https://leetcode.cn/problems/minimum-remove-to-make-valid-parentheses/
- **来源**：LeetCode 第 161 场周赛 Q3
- **难度**：中等
- **标签**：栈、字符串、贪心、括号匹配

**题意**：给定只含 `'('`、`')'` 和小写英文字母的字符串 `s`，删掉**最少个数**的括号（字母一个都不能删，剩余字符保持原相对顺序），使剩下的括号串合法，返回**任意一个**最优结果。

题面用递归方式定义「合法」：空串/纯字母串合法；`AB` 合法当且仅当 `A`、`B` 都合法；`(A)` 合法当且仅当 `A` 合法。这个递归定义其实等价于一条**计数判据**：把 `'('` 记 $+1$、`')'` 记 $-1$、字母记 $0$，则合法 $\iff$ 每个前缀和都 $\ge 0$ 且总和为 $0$。本题的全部推导都建立在这条判据上。

**约束**：

- $1 \le \lvert s \rvert \le 10^5$
- `s[i]` 只会是 `'('`、`')'` 或小写英文字母

## 2. 示例

**示例 1**

```text
输入：s = "lee(t(c)o)de)"
输出："lee(t(c)o)de"
解释：末尾多出一个 ')'，删掉它即可；"lee(t(co)de)"、"lee(t(c)ode)" 也算正确。
```

**示例 2**

```text
输入：s = "a)b(c)d"
输出："ab(c)d"
解释：下标 1 的 ')' 左边没有任何 '('，必删；下标 3、4 的 "()" 成对保留。
```

**示例 3**

```text
输入：s = "))(("
输出：""
解释：两个 ')' 都无左括号可配，两个 '(' 也无右括号可配，四个全删，空串合法。
```

## 3. 解题思路

### 3.1 暴力思路

先想「枚举删除集合」：若括号有 $k$ 个，检查所有 $2^k$ 个子集，对每个子集判合法性（$O(n)$），取删除数最小的——$k$ 可以到 $10^5$，不可能。

再想「逐轮贪心修补」：每轮找出一个导致非法的括号删掉，删一次判一次，最坏要删 $O(n)$ 个、每轮 $O(n)$，总计 $O(n^2)$。$n = 10^5$ 时约 $10^{10}$ 次操作，超时。

两条路的共同问题是：把「删谁」当成一道需要搜索的题。实际上合法性的判据是**逐前缀的局部条件**，扫描一遍就能知道每个位置「此刻是否已经出了问题」，完全不需要搜索。

### 3.2 核心观察：前缀平衡值刻画合法性

![前缀平衡值与两类无效括号](images/wc161_q3_balance_validity.svg)

定义 $b(i)$ 为**前 $i$ 个字符**（$0 \le i \le n$）里 `'('` 的个数减 `')'` 的个数。合法判据（引理 1）是：

$$b(i) \ge 0 \quad (0 \le i \le n), \qquad b(n) = 0$$

于是**只有两类字符会破坏合法性**：

- **坏右括号**：读到 `')'` 时 $b$ 已经是 $0$，再减就变负。这个 `')'` 必须删（想保它就只能删它前面某个 `'('`，代价同样是 1，见 3.3）。
- **多余左括号**：全文扫完仍有 $b(n) = B > 0$，还得再删 $B$ 个 `'('`。

两类互不干扰：坏右括号在扫描时立刻暴露，可以顺手丢弃；多余左括号只能等扫描结束后才知道「欠了 $B$ 个右括号」，需要回头补删。这就把问题拆成了**方向相反的两趟**。

关键的数量关系是：第一趟结束后剩余的 $b(n) = B$ 恰好等于「必须再删的左括号个数」，因此删除总数 $= r + B$（$r$ 为坏右括号个数），**不需要任何尝试**。

### 3.3 算法流程：两趟相向扫描

![两趟扫描流程：先删坏右括号，再删最右的 B 个左括号](images/wc161_q3_two_pass_flow.svg)

**第一趟：左 → 右，只删 `')'`**

维护 `balance`，把字符逐个写入新串 `t`：

- `'('`：`balance += 1`，写入；
- `')'`：若 `balance > 0` 则 `balance -= 1` 并写入（配对成功）；否则**丢弃**（坏右括号）；
- 字母：原样写入。

扫描结束时 `balance = B` 就是剩余串里多出的 `'('` 个数。

**第二趟：右 → 左，只删 `'('`**

令 `excess = B`，从 `t` 的末尾往前扫，倒序写入结果：遇到 `'('` 且 `excess > 0` 时丢弃并 `excess -= 1`，其余保留。最后把结果反转回来。

> 💡 **为什么删最右边的 $B$ 个 `'('` 是安全的？** 删除一个 `'('` 会让它**之后**的所有前缀平衡都减 1，因此从右边删，受影响的前缀最少、且这些前缀的平衡值最大。严格证明见引理 3：对任意前缀，需要删除的 `'('` 个数不超过该前缀的平衡值。

### 3.4 示例演算

![示例演算：s = ")(a(b)c(" 的两趟扫描](images/wc161_q3_walkthrough.svg)

取一个两趟都用得上的例子：`s = ")(a(b)c("`。

**第一趟**（左 → 右）：

| $i$ | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| `s[i]` | `)` | a | `(` | b | `(` | c | `)` | `(` |
| `balance` | 0 → 丢弃 | 0 | 1 | 1 | 2 | 2 | 1 | 2 |
| 动作 | 删 | 留 | 留 | 留 | 留 | 留 | 留 | 留 |

第一趟结果 $t = $ `"a(b(c)("`，`balance = B = 2`。

**第二趟**（右 → 左，`excess = 2`）：

| 位置（从右） | 7 | 6 | 5 | 4 | 3 | 2 | 1 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 字符 | `(` | `)` | c | `(` | b | `(` | a |
| `excess` | 2→1 | 1 | 1 | 1→0 | 0 | 0 | 0 |
| 动作 | 删 | 留 | 留 | 删（最右的左括号） | 留 | 留 | 留 |

反转后得 `"a(bc)"`：前缀平衡依次为 $0,1,1,2,2,1,0$，处处非负、末尾归零，合法；共删除 3 个括号，等于 $r + B = 1 + 2$。

## 4. 算法细节

1. **字母完全不参与状态**：既不进 `balance` 也不参与删除判断，直接透传；把字母当成「透明字符」是这类括号题的标准处理。
2. **第一趟用追加写而不是原地删除**：每次 `erase` 都是 $O(n)$，$n$ 次就退化成 $O(n^2)$。C++ 用 `string::push_back`（先 `reserve(s.size())` 避免扩容），Python 用 `list.append`。
3. **`B` 必须在第一趟结束后取值**：`balance` 在第一趟里不断变化，只有当所有字符都处理完，它才等于「多出的左括号个数」。中途读它会得到错误的 `excess`。
4. **第二趟只处理 `'('`**：此时串里所有 `')'` 都已经能和某个 `'('` 配对（第一趟保证了每个 `)` 都对应一次 `balance--`），再删 `)` 只会让前缀平衡变得更小、把合法串改坏。
5. **倒序写 + 反转**：第二趟从右往左扫，直接把字符 `push_back` 到结果串会得到逆序串，最后要 `reverse`（Python 用 `''.join(reversed(ans))`）。也可以先开一个长度已知的数组，从尾部往前填空位，省掉反转。
6. **栈变体（等价结论）**：用栈存 `'('` 的下标，扫描时把「栈空时遇到的 `')'`」标记删除，扫完把栈里剩余下标一并标记，再拼接。它和两趟法**删除数量相同**（都是 $r+B$），但保留的具体括号可能不同——两种结果都合法，题目接受任意一个。栈法多一个 $O(n)$ 的 `vector`，两趟法只用两个指针。
7. **原地优化**：两趟都可以在 `s` 上原地做（第一趟用写指针覆盖，第二趟从尾部读、从头写），除返回串外额外空间 $O(1)$。

## 5. 正确性证明

**引理 1（合法判据）**：括号串 $w$ 合法 $\iff$ 对它的每个前缀 $b \ge 0$，且 $b(\lvert w \rvert) = 0$。

**证明**：记 $w$ 的平衡函数为 $b$。

（$\Rightarrow$）对合法串的结构做归纳。空串与纯字母串：$b$ 恒为 $0$，成立。$w = AB$：由归纳假设 $A$、$B$ 各自满足条件，$w$ 的前缀要么落在 $A$ 内（$\ge 0$），要么等于「$A$ 的总平衡值 $+$ 在 $B$ 中的前缀和」$= 0 + (\ge 0) \ge 0$，末尾为 $0 + 0 = 0$，成立。$w = (A)$：前缀为 $1$ 时 $\ge 0$；落在 $A$ 内时为 $1 + (\ge 0) \ge 0$；闭括号处为 $1 + 0 - 1 = 0$，成立。

（$\Leftarrow$）对 $\lvert w \rvert$ 归纳。剥掉开头连续的字母（它们合法且不影响括号平衡），余下若为空，则 $w$ 为纯字母串，合法；否则不妨设 $w[0] = $ `'('`。令 $j \ge 1$ 为第一个使 $b(j) = 0$ 的位置（存在：$b(0) = 0$、$b(1) = 1$、$b(\lvert w\rvert) = 0$，且 $b$ 每步只变 $\pm 1$）。对 $1 \le t < j$ 有 $b(t) \ge 1$，故中间部分 $w[1..j)$ 的前缀和为 $b(t) - 1 \ge 0$、总和为 $b(j-1) - 1 = 0$；后缀 $w[j..\lvert w\rvert)$ 的前缀和为 $b(j+t) - b(j) = b(j+t) \ge 0$、总和为 $0$。两段长度都小于 $\lvert w\rvert$，由归纳假设合法，故 $w = (A)B$ 合法。∎

**引理 2（第一趟的保证）**：设第一趟输出为 $t$，丢弃了 $r$ 个 `')'`，则 $t$ 的每个前缀平衡 $b_t \ge 0$，且 $b_t(\lvert t \rvert) = B \ge 0$，其中 $B$ 为多出的 `'('` 个数；同时 $t$ 中 `')'` 的个数恰为「可与某个 `'('` 配对的 `')'` 个数」。

**证明**：`balance` 只在 `')'` 且 `balance > 0` 时自减，故始终 $\ge 0$，而 `balance` 就是 $t$ 当前前缀的平衡值，得第一句；扫描结束时 `balance` 即 $b_t(\lvert t \rvert) = B$。每个被保留的 `')'` 都伴随一次成功的 `balance--`，即与一个已保留的 `'('` 配对；被丢弃的 `')'` 到达时 $b_t$ 为 $0$，说明前面没有可配的左括号。∎

**引理 3（第二趟不破坏前缀非负）**：设 $t$ 满足 $b_t \ge 0$、$b_t(\lvert t \rvert) = B$，则删掉 $t$ 中最右边的 $B$ 个 `'('` 后，所得串 $u$ 的每个前缀平衡 $\ge 0$，且末尾为 $0$。

**证明**：末尾平衡为 $B - B = 0$，显然。设 $p$ 为 $u$ 的任一前缀对应的位置，$c(p)$、$o(p)$ 为 $t$ 在该前缀内 `')'`、`'('` 的个数，$O$、$C$ 为 $t$ 的总数，则 $O - C = B$，$b_t(p) = o(p) - c(p)$。记 $d(p)$ 为该前缀中被删掉的 `'('` 个数。因为删除的是**最右**的 $B$ 个 `'('`，前缀内的 `'('` 只有在「它右侧的左括号不足 $B$ 个」时才会被删，即

$$d(p) = \max\bigl(0,\; B - (O - o(p))\bigr) = \max\bigl(0,\; o(p) - C\bigr) \le o(p) - c(p) = b_t(p)$$

（第二步用了 $B = O - C$；最后一步用了 $c(p) \le C$。）于是 $u$ 在该前缀的平衡为 $b_t(p) - d(p) \ge 0$。∎

**引理 4（下界）**：任何合法结果至少删除 $r + B$ 个括号。

**证明**：把 $s$ 中的每个 `'('` 与它右侧最近的、尚未配对的 `')'` 做一次贪心配对，得到 $P$ 对。合法串中的括号必然两两配对（引理 1），而合法串是 $s$ 的子序列，其中每一对配对在 $s$ 中也是「左在前、右在后」的可配关系，故配对数不超过 $P$，长度不超过 $2P$。于是删除数 $\ge n_{\text{par}} - 2P$。另一方面，第一趟和第二趟恰好删掉 $r + B$ 个，剩下 $2P$ 个（全部成对），即 $n_{\text{par}} - 2P = r + B$。∎

**定理**：算法输出的串合法，且删除数等于最小值 $r + B$。

**证明**：由引理 2、3，输出的串前缀平衡处处非负、末尾为 $0$，由引理 1 合法；算法删除了 $r$ 个 `')'` 与 $B$ 个 `'('`，总数 $r + B$ 达到引理 4 的下界，故最优。∎

## 6. 复杂度分析

- **时间**：$O(n)$。第一趟遍历 $n$ 个字符，每个字符 $O(1)$；第二趟倒序遍历 $|t| \le n$ 个字符，每个 $O(1)$；最后反转 $O(n)$。常数约为 $3n$ 次简单操作，$n = 10^5$ 时远低于时限。
- **空间**：$O(n)$，用于中间串 $t$ 与结果串。若采用 §4 第 7 条的原地写法，除返回串外只用到两个下标与两个计数变量，额外空间 $O(1)$；栈变体需要 $O(n)$ 的下标栈，最坏（全为 `'('`）存 $n$ 个下标。

## 7. 参考代码

### C++

```cpp
#include <string>
#include <algorithm>

class Solution {
public:
    string minRemoveToMakeValid(string s) {
        // 第一趟：左 -> 右，丢弃所有「到场时 balance 已经为 0」的右括号
        string t;
        t.reserve(s.size());
        int balance = 0;
        for (char c : s) {
            if (c == '(') {
                ++balance;
                t.push_back(c);
            } else if (c == ')') {
                if (balance > 0) {          // 有左括号可配，保留
                    --balance;
                    t.push_back(c);
                }                        // 否则丢弃：坏右括号
            } else {
                t.push_back(c);             // 字母原样保留
            }
        }

        // 第二趟：右 -> 左，丢弃最右边的 balance 个左括号
        int excess = balance;
        string ans;
        ans.reserve(t.size());
        for (int i = (int)t.size() - 1; i >= 0; --i) {
            if (t[i] == '(' && excess > 0) {
                --excess;
            } else {
                ans.push_back(t[i]);
            }
        }
        reverse(ans.begin(), ans.end());
        return ans;
    }
};
```

### Python

```python
class Solution:
    def minRemoveToMakeValid(self, s: str) -> str:
        # 第一趟：左 -> 右，丢弃「到场时 balance 已经为 0」的右括号
        first = []
        balance = 0
        for c in s:
            if c == '(':
                balance += 1
                first.append(c)
            elif c == ')':
                if balance > 0:
                    balance -= 1
                    first.append(c)
                # 否则丢弃：坏右括号
            else:
                first.append(c)

        # 第二趟：右 -> 左，丢弃最右边的 balance 个左括号
        excess = balance
        ans = []
        for c in reversed(first):
            if c == '(' and excess > 0:
                excess -= 1
            else:
                ans.append(c)
        return ''.join(reversed(ans))
```

## 8. 边界情况与易错点

1. **全是字母**：$b$ 恒为 $0$，两趟都不删任何字符，返回原串。注意不要因为「结果串和原串长度相等」而误判成空串处理。
2. **结果可以是空串**：`"))))(("`、`")(("`、`"((("` 这类输入返回 `""`，空串合法。函数返回类型是 `string` 而不是指针，不存在空指针问题，但拼接时不要对空结果做 `ans[0]` 之类的访问。
3. **只有多余左括号**：如 `"((("`，第一趟全保留（每个 `)` 都没出现），`B = 3`，第二趟把三个全删掉。若忘记第二趟，会返回 `"((("`。
4. **只有多余右括号**：如 `")))"`，全部在第一趟被丢弃，`B = 0`，第二趟空转。此时 `t` 为空串，倒序循环一次都不执行，不能写成 `for (int i = t.size() - 1; ...)` 中让 `t.size()` 参与有符号/无符号混算——`t.size() - 1` 在 `size_t` 下会回绕成极大值，必须先转 `int`。
5. **`balance` / `excess` 用有符号整型**：若用 `unsigned`，`balance > 0` 的判断没有问题，但任何 `--balance` 在下溢时会静默回绕，之后一路错到底。
6. **不要用递归实现匹配**：括号嵌套深度可达 $10^5$（如 $5\times10^4$ 个 `'('` 后接 $5\times10^4$ 个 `')'`），递归配对会爆栈。
7. **字母不能被删**：题面要求只删括号。若为了「凑最小长度」把字母当噪声删掉，答案无效。
8. **第二趟别删右括号**：第一趟之后每个 `')'` 都有配对，删它会立刻让末尾平衡小于 $0$，破坏合法性。
