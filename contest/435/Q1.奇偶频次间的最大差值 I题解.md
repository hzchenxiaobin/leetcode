# LeetCode 奇偶频次间的最大差值 I 题解

## 1. 题目概述

- **标题 / 题号**：奇偶频次间的最大差值 I（#3442，easy）
- **链接**：https://leetcode.cn/problems/maximum-difference-between-even-and-odd-frequency-i/
- **来源**：LeetCode 第 435 场周赛 Q1
- **难度**：简单
- **标签**：哈希表、字符串、计数

**题意**：给定一个由小写英文字母组成的字符串 `s`。找出两个字符 `a1` 和 `a2` 的出现频次之间的**最大**差值 `diff = freq(a1) - freq(a2)`，要求 `a1` 在串中出现**奇数次**、`a2` 出现**偶数次**。返回最大差值。

**约束**：

- `3 <= s.length <= 100`
- `s` 仅由小写英文字母组成
- `s` 至少由一个出现奇数次的字符和一个出现偶数次的字符组成

## 2. 示例

**示例 1**

```text
输入：s = "aaaaabbc"
输出：3
解释：'a' 出现奇数次，频次 5；'b' 出现偶数次，频次 2。最大差值为 5 - 2 = 3。
```

**示例 2**

```text
输入：s = "abcabcab"
输出：1
解释：'a' 出现奇数次，频次 3；'c' 出现偶数次，频次 2。最大差值为 3 - 2 = 1。
```

**示例 3（自造，覆盖负数答案）**

```text
输入：s = "aabbc"
输出：-1
解释：'c' 出现奇数次，频次 1；'a'、'b' 均出现偶数次，频次 2。最大差值为 1 - 2 = -1。
```

## 3. 解题思路

### 3.1 暴力思路

统计 26 个字母的频次后，枚举所有有序字母对 $(a_1, a_2)$：若 $\mathrm{freq}(a_1)$ 为奇数、$\mathrm{freq}(a_2)$ 为偶数，就用 $\mathrm{freq}(a_1) - \mathrm{freq}(a_2)$ 更新答案。检查 $O(26^2)$ 对，$n \le 100$ 下轻松通过，但这层两两配对的循环完全是多余的。

### 3.2 核心观察：差值拆成两个独立极值

![奇偶频次拆分：各取极值再相减](images/evenodd_freq_concept.svg)

`diff = freq(a1) - freq(a2)` 中被减项与减项**独立选取**：让被减项尽量大（奇频次中取**最大**），让减项尽量小（偶频次中取**最小**），两者互不干扰。因此

$$\text{答案} = \max_{\text{奇频 } f}\, f \;-\; \min_{\text{偶频 } f,\, f>0}\, f$$

一遍扫描 26 个频次即可，无需两两枚举。

### 3.3 算法流程

![算法流程：一趟扫描 26 个频次](images/evenodd_freq_flow.svg)

1. 遍历 `s` 统计每个字母的出现次数 `cnt[26]`。
2. 遍历 `cnt`：频次为 `0`（字母未出现）直接跳过；否则按奇偶分别更新 `maxOdd` 与 `minEven`。
3. 返回 `maxOdd - minEven`。

### 3.4 示例演算

![示例演算：答案可能为负](images/evenodd_freq_example.svg)

| 输入 | 频次表 | maxOdd | minEven | 答案 |
|------|--------|--------|---------|------|
| `"aaaaabbc"` | a:5, b:2, c:1 | 5（a） | 2（b） | 5 − 2 = 3 |
| `"abcabcab"` | a:3, b:3, c:2 | 3（a 或 b） | 2（c） | 3 − 2 = 1 |
| `"aabbc"` | a:2, b:2, c:1 | 1（c） | 2（a 或 b） | 1 − 2 = −1 |

注意第三个例子：**答案可以为负**，不能加绝对值，也不能对负数特判返回 0。

## 4. 算法细节

1. **计数**：`n ≤ 100`，用长度 26 的数组（C++）或 `Counter`（Python）统计频次。
2. **跳过频次 0**：未出现的字母频次为 0，虽然 0 是偶数，但 `a2` 必须是**在字符串中出现过**偶数次的字符；若不跳过，`minEven` 恒为 0，答案直接错。
3. **极值初始化**：`maxOdd` 初始化为极小值、`minEven` 初始化为极大值；由于题目保证至少存在一个奇频字符和一个偶频字符，两者一定会被更新，无需判空。
4. **奇偶判定**：`f & 1` 或 `f % 2` 判断奇偶即可。

## 5. 正确性证明

**引理 1**：合法字符对 $(a_1, a_2)$ 中必然有 $a_1 \ne a_2$。

**证明**：同一字符在 `s` 中的频次是唯一确定的整数，不可能既是奇数又是偶数，故出现奇数次的字符集合与出现偶数次的字符集合不相交。∎

**引理 2**：最大差值 $= \max_{\text{奇频}} f - \min_{\text{偶频}, f>0} f$。

**证明**：对任意合法对 $(a_1, a_2)$，有 $\mathrm{freq}(a_1) \le \max_{\text{奇频}} f$ 且 $\mathrm{freq}(a_2) \ge \min_{\text{偶频}, f>0} f$，故 $\mathrm{freq}(a_1) - \mathrm{freq}(a_2) \le \max_{\text{奇频}} f - \min_{\text{偶频}, f>0} f$，即右边是上界。另一方面，设 $a_1^*$ 为取到最大奇频的字符、$a_2^*$ 为取到最小非零偶频的字符，由引理 1 两者不同，且 $(a_1^*, a_2^*)$ 是合法对，恰好达到该上界。∎

**定理**：算法返回字符串中奇频字符与偶频字符频次间的最大差值。

**证明**：算法先精确统计每个字符的频次，再按引理 2 分别维护最大奇频与最小非零偶频并作差，即引理 2 中的最优值。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n + 26) = O(n)$。一趟遍历 `s` 计数，再常数次遍历 26 个频次。
- **空间复杂度**：$O(26) = O(1)$。仅频次数组。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maxDifference(string s) {
        int cnt[26] = {0};
        for (char c : s) cnt[c - 'a']++;
        int maxOdd = INT_MIN, minEven = INT_MAX;
        for (int f : cnt) {
            if (f == 0) continue;
            if (f & 1) maxOdd = max(maxOdd, f);
            else minEven = min(minEven, f);
        }
        return maxOdd - minEven;
    }
};
```

### Python

```python
class Solution:
    def maxDifference(self, s: str) -> int:
        cnt = Counter(s)
        max_odd = max(f for f in cnt.values() if f % 2 == 1)
        min_even = min(f for f in cnt.values() if f % 2 == 0)
        return max_odd - min_even
```

## 8. 边界情况与易错点

1. **频次 0 不能算偶频**：`minEven` 只在 `f > 0` 的偶频里取，否则答案恒被 0 干扰（本题最大坑点）。
2. **答案可以为负**：如 `"aabbc"` 输出 `-1`，不要加绝对值、不要对负数特判。
3. **`a1` 与 `a2` 必然不同**：同一频次不能既奇又偶，无需额外去重判断。
4. **无需判空**：题目保证同时存在奇频与偶频字符，`maxOdd`/`minEven` 必被赋值；若不放心可断言非初始值。
5. **最小偶频至少为 2**：正偶数从 2 起，不会出现 `minEven == 0` 之外的退化情形（前提是已跳过 0）。
