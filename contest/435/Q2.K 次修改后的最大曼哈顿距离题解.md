# LeetCode K 次修改后的最大曼哈顿距离 题解

## 1. 题目概述

- **标题 / 题号**：K 次修改后的最大曼哈顿距离（#3443，medium）
- **链接**：https://leetcode.cn/problems/maximum-manhattan-distance-after-k-changes/
- **来源**：LeetCode 第 435 场周赛 Q2
- **难度**：中等
- **标签**：哈希表、数学、字符串、计数

**题意**：给定仅由 `'N'`、`'S'`、`'E'`、`'W'` 组成的字符串 `s`，从原点 `(0, 0)` 出发按顺序逐字符移动（每步在无限网格上移动 1 个单位）。**执行前**最多可以把 `k` 个字符改成任意方向。求执行过程中**任意时刻**（而非仅终点）能达到的、离原点的最大曼哈顿距离 $|x| + |y|$。

**约束**：

- $1 \le s.length \le 10^5$
- $0 \le k \le s.length$
- `s` 仅由 `'N'`、`'S'`、`'E'`、`'W'` 组成

> 💡 **审题关键**：① 问的是「过程中任意时刻」的最大值，不是终点——必须**逐前缀**考察；② 修改在执行前一次性定死，同一组修改要服务所有时刻，但「取 max」意味着只需让**某一个**时刻达到最优；③ $n \le 10^5$ 要求 $O(n)$ 级做法。

## 2. 示例

**示例 1**

```text
输入：s = "NWSE", k = 1
输出：3
解释：把 s[2] 从 'S' 改成 'N'，s 变为 "NWNE"。
走到第 3 步时位于 (-1, 2)，曼哈顿距离 |−1| + |2| = 3。
注意：终点 (0, 2) 的距离只有 2 —— 最大值出现在中间时刻。
```

**示例 2**

```text
输入：s = "NSWWEW", k = 3
输出：6
解释：把 s[1] 的 'S' 改成 'N'、s[4] 的 'E' 改成 'W'，s 变为 "NNWWWW"。
终点为 (-4, 2)，距离 |−4| + |2| = 6。
```

**示例 3（自造，覆盖单轴翻转）**

```text
输入：s = "NSSS", k = 1
输出：4
解释：把唯一的 'N' 改成 'S'，s 变为 "SSSS"，终点 (0, -4)，距离 4。
```

## 3. 解题思路

### 3.1 暴力思路

每个字符有 4 种方向选择，`n` 个字符共 $4^n$ 种修改后的串；对每种串模拟一遍取全程最大距离，复杂度 $O(4^n \cdot n)$，天文数字。即使把「选哪些位置改、改成什么」压成 DP，状态也得带上 $(位置, x, y, 已用次数)$，坐标范围 $[-n, n]$，总量 $O(n^3 k)$，同样不可行。瓶颈在于把「方向序列」当成不可压缩的对象——而**位置只由四个方向的计数决定**，必须先做这步降维。

### 3.2 核心观察：按轴拆分 + 抵消对，一次修改救回 2 步

![核心观察：抵消对浪费 2 步，改一个少数方向字符恰赚 2](images/kchange_cancel_pair_concept.svg)

设某前缀长度为 $L$，其中 `'N'`、`'S'`、`'E'`、`'W'` 的个数分别为 $c_N, c_S, c_E, c_W$，则该时刻位置为 $(c_E - c_W,\; c_N - c_S)$。利用恒等式 $|a - b| = a + b - 2\min(a, b)$：

$$\text{dist} = |c_E - c_W| + |c_N - c_S| = L - 2\big(\underbrace{\min(c_N, c_S)}_{w_1} + \underbrace{\min(c_E, c_W)}_{w_2}\big) = L - 2w$$

直觉解读：**同一轴上方向相反的两步互相抵消**——1 个 `'N'` 配 1 个 `'S'` 走了 2 步却回到原地。$w = w_1 + w_2$ 就是「抵消对」的个数，每对浪费 2 步。

再看修改的威力：把某个**少数方向**的字符改成**同轴多数方向**（例如 $c_N \ge c_S$ 时把一个 `'S'` 改成 `'N'`），该轴净位移从 $c_N - c_S$ 变为 $(c_N + 1) - (c_S - 1)$，恰好 $+2$——一次修改**救回一整对抵消**。而任何单次修改对 $|x| + |y|$ 的增益都不超过 2（新位移向量与旧位移向量的 $L_1$ 差至多 2，三角不等式）。所以：

$$f(L) = L - 2w + 2 \cdot \min(k, w) = L - 2\max(0,\, w - k)$$

即每个前缀能改到的最大距离。抵消对用完（$k \ge w$）后距离封顶为 $L$——每步最多贡献 1，物理上不可能更多。

> ⚠️ **为什么前缀可以独立优化**：修改虽是全局一次性定好的，但我们只需要**一个**时刻达到全局最大值。取最优前缀 $L^*$，把 $\min(k, w)$ 次修改全部放在前 $L^*$ 个字符内的少数方向上，$L^*$ 之后的字符原样保留——时刻 $L^*$ 的位置只依赖前 $L^*$ 个字符的方向计数，后面的修改与否不影响它。

### 3.3 算法流程

![算法流程：一趟扫描维护四个计数器](images/kchange_algorithm_flow.svg)

1. 初始化四个计数器 $c_N, c_S, c_E, c_W = 0$，答案 `ans = 0`。
2. 从左到右扫描 `s`：每读一个字符，对应计数器 `+1`。
3. 计算 $w = \min(c_N, c_S) + \min(c_E, c_W)$，用 $f(L) = L - 2w + 2\min(k, w)$ 更新 `ans`。
4. 扫描结束返回 `ans`。

### 3.4 示例演算

![示例演算：NSWWEW 逐前缀表格与轨迹](images/kchange_example_walkthrough.svg)

以 `s = "NSWWEW", k = 3` 为例：

| L | 前缀 | $c_N$ | $c_S$ | $c_E$ | $c_W$ | $w_1$ | $w_2$ | $w$ | $f(L) = L - 2w + 2\min(k, w)$ |
|---|------|----|----|----|----|----|----|---|------|
| 1 | `N` | 1 | 0 | 0 | 0 | 0 | 0 | 0 | 1 |
| 2 | `NS` | 1 | 1 | 0 | 0 | 1 | 0 | 1 | 2 − 2 + 2 = 2 |
| 3 | `NSW` | 1 | 1 | 0 | 1 | 1 | 0 | 1 | 3 − 2 + 2 = 3 |
| 4 | `NSWW` | 1 | 1 | 0 | 2 | 1 | 0 | 1 | 4 − 2 + 2 = 4 |
| 5 | `NSWWE` | 1 | 1 | 1 | 2 | 1 | 1 | 2 | 5 − 4 + 4 = 5 |
| 6 | `NSWWEW` | 1 | 1 | 1 | 3 | 1 | 1 | 2 | 6 − 4 + 4 = **6** ← 答案 |

最优时刻是终点 $L = 6$：$w = 2 \le k = 3$，$f = 6 = L$。对应构造：`'S'→'N'`（救回 y 轴抵消对）、`'E'→'W'`（救回 x 轴抵消对），改后 `NNWWWW`，终点 $(-4, 2)$。注意 $k=3$ 只用掉 2 次——多余的修改无处增益。

## 4. 算法细节

1. **计数降维**：位置只由 $(c_N, c_S, c_E, c_W)$ 决定，与字符顺序无关；每个前缀的计数可在扫描中 $O(1)$ 增量维护，无需前缀和数组。
2. **抵消对公式**：$w = \min(c_N, c_S) + \min(c_E, c_W)$，恒等式 $|a - b| = a + b - 2\min(a,b)$ 同时给出上界刻画与构造方案。
3. **修改收益恰为 2 的构造**：少数方向 → 同轴多数方向。多数 ≥ 少数保证该轴净位移非负、翻转后绝对值严格 $+2$；两轴各自独立执行，互不干扰。
4. **预算封顶**：有效修改次数为 $\min(k, w)$；$k > w$ 时多余预算作废（距离已达上界 $L$）。
5. **上界兜底**：$f(L) \le L$ 恒成立，避免「改了 $k$ 次就一定能加 $2k$」的错觉——没有抵消对可救时，一次修改的收益可能是 0（把 `'N'` 改成 `'E'` 只是把 1 步换了个轴）。
6. **单次修改收益 ≤ 2 的原因**：位置增量是新旧位移向量之差，其 $L_1$ 范数 $\le 1 + 1 = 2$。

## 5. 正确性证明

**引理 1（恒等式）**：任意前缀 $L$，$\text{dist} = |c_E - c_W| + |c_N - c_S| = L - 2\big(\min(c_N, c_S) + \min(c_E, c_W)\big)$。

**证明**：$|a - b| = a + b - 2\min(a, b)$ 对非负整数恒成立，对两个轴分别应用并相加，$c_N + c_S + c_E + c_W = L$。∎

**引理 2（可达性）**：对任意前缀 $L$，存在使用 $\min(k, w)$ 次修改的方案，使时刻 $L$ 的距离恰为 $f(L) = L - 2w + 2\min(k, w)$。

**证明**：不妨设 $c_N \ge c_S$（否则对称）。把前 $L$ 个字符中的一个 `'S'` 改成 `'N'`：y 轴计数变为 $(c_N + 1, c_S - 1)$，净位移由 $c_N - c_S \ge 0$ 增加 2，绝对值严格 $+2$；$x$ 轴不变。y 轴上可执行此操作 $\min(c_N, c_S) = w_1$ 次，x 轴同理 $w_2$ 次，两轴合计 $w$ 次、每次 $+2$，且互不冲突（改的是不同字符）。执行 $\min(k, w)$ 次后距离为 $L - 2w + 2\min(k, w)$；$L$ 之后的字符不修改，不影响时刻 $L$ 的位置。∎

**引理 3（上界）**：对**任意**修改方案与任意时刻 $t$，距离 $\le L_t - 2w_t + 2\min(k, w_t)$，其中 $L_t, w_t$ 按**原串**前缀计算。

**证明**：设前 $L_t$ 个字符中被实际修改的有 $k_t \le k$ 个，修改后计数为 $c'_d$。每次修改使一个方向计数 $-1$、另一个 $+1$；检验所有改动类型可知 $\min(c'_N, c'_S) + \min(c'_E, c'_W)$ 每次修改至多下降 $1$（改动同轴反方向时恰好降 1，异轴时一降一升或不降），故修改后该和 $\ge w_t - k_t$。对 $c'$ 用引理 1：距离 $= L_t - 2\big(\min(c'_N, c'_S) + \min(c'_E, c'_W)\big) \le L_t - 2w_t + 2k_t$。另一方面每个位移向量 $L_1$ 范数为 1，三角不等式给距离 $\le L_t$。两上界取 $\min$：

$$\text{dist} \le \min\big(L_t,\; L_t - 2w_t + 2k_t\big) = L_t - 2w_t + 2\min(k_t, w_t) \le L_t - 2w_t + 2\min(k, w_t) \qquad \blacksquare$$

**定理**：算法返回的 $\max_{1 \le L \le n} f(L)$ 即为所求答案。

**证明**：取 $L^*$ 为取到最大值的前缀。由引理 2，存在一组全局合法修改（改动全部位于前 $L^*$ 内，共 $\min(k, w_{L^*}) \le k$ 次）使时刻 $L^*$ 的距离为 $f(L^*)$，故答案 $\ge f(L^*)$。反之，任意修改方案在任意时刻 $t$ 的距离由引理 3 不超过 $f(L_t) \le f(L^*)$，故答案 $\le f(L^*)$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。一趟扫描，每个字符更新计数器 $O(1)$、计算 $w$ 与候选值 $O(1)$。
- **空间复杂度**：$O(1)$。仅 4 个计数器与常数个标量，无需前缀数组。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maxDistance(string s, int k) {
        int cN = 0, cS = 0, cE = 0, cW = 0;
        int ans = 0;
        for (int i = 0; i < (int)s.size(); i++) {
            if (s[i] == 'N') cN++;
            else if (s[i] == 'S') cS++;
            else if (s[i] == 'E') cE++;
            else cW++;
            int w = min(cN, cS) + min(cE, cW);
            ans = max(ans, i + 1 - 2 * w + 2 * min(k, w));
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maxDistance(self, s: str, k: int) -> int:
        cN = cS = cE = cW = 0
        ans = 0
        for i, ch in enumerate(s):
            if ch == 'N': cN += 1
            elif ch == 'S': cS += 1
            elif ch == 'E': cE += 1
            else: cW += 1
            w = min(cN, cS) + min(cE, cW)
            ans = max(ans, i + 1 - 2 * w + 2 * min(k, w))
        return ans
```

## 8. 边界情况与易错点

1. **「任意时刻」不是只看终点**：示例 1 终点最优只有 2，答案 3 出现在第 3 步——漏掉逐前缀取 max 直接错。
2. **不要因为「修改全局定死」而去做全局 DP**：取 max 的语义允许只为最优前缀服务，改后缀字符不影响更早时刻的位置。
3. **一次修改的收益是 2 不是 1**：救回的是一整对抵消（少数方向翻转后，净位移跨 2 格）。低估成 1 会得到 $L - 2w + \min(k, w)$ 的错误公式。
4. **收益封顶 $\min(k, w)$**：抵消对耗尽后再多改无增益；$k \ge w$ 时 $f(L) = L$ 触及「前缀长度」这一物理上界，防止答案超过 $L$。
5. **$k = 0$ 退化**：公式退化为 $\max_L (L - 2w_L)$，即原串全程最大距离，无需特判。
6. **多数方向也可能只有 0 个**：如前缀 `"SS"`，$\min(c_N, c_S) = 0$，无可救的抵消对，$w$ 正确地为 0——不要把「少数方向的个数」误当成「抵消对之外的字符」。
7. **数值范围**：$n \le 10^5$，$f(L) \le L \le 10^5$，中间量 $2w \le 2 \times 10^5$，`int` 绰绰有余，无溢出风险。
