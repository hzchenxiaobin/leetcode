# LeetCode 合法分组的最少组数 题解

## 1. 题目概述

- **标题 / 题号**：合法分组的最少组数（#2910，medium）
- **链接**：https://leetcode.cn/problems/minimum-number-of-groups-to-create-a-valid-assignment/
- **来源**：LeetCode 第 368 场周赛 Q3
- **难度**：中等
- **标签**：贪心、数组、哈希表、数学

**题意**：给定数组 `balls` 表示一堆带编号的球，要把它们全部装进若干盒子，满足两条规则：

1. **同盒同编号**：同一个盒子里的球编号必须相同；但同编号的球可以拆开放进多个盒子；
2. **均衡性**：最大的盒子只能比最小的盒子**多一个球**（即所有盒子的大小至多两档，且两档相差恰为 1；全部同大小也合法）。

求满足规则时**盒子的最少数目**。

**约束**：

- $1 \le \text{balls.length} \le 10^5$
- $1 \le \text{balls[i]} \le 10^9$

> 💡 本题是 368 场的分水岭题（Q1/Q2 手速题之后、Q4 困难题之前），赛时现场通过率明显掉档。全题只有三个环环相扣的观察：**规则 1 ⟹ 各编号独立拆分**、**规则 2 ⟹ 全局盒大小只有 $\{x, x+1\}$ 两档**、**$g$ 个盒的容量恰是连续区间 $[gx, g(x+1)]$**——每一步都只是一行数学，拼起来却能把「模拟装盒」的实现负担整个抹掉。两个经典坑：对 $x$ **二分**（可行集有洞，根本不单调）和**逐盒模拟装球**（边界回拆极易写挂）。另见[每日题解](../../solution/2901-3000/2910_合法分组的最少组数.md)（面试问答视角），互为印证。

## 3. 解题思路

### 3.1 暴力思路：划分枚举指数级，逐盒模拟坑连坑

最naive的想法是枚举「球的划分」：把每个编号的 $f$ 个球写成有序拆分再组合，方案数是指数级的，$n \le 10^5$ 下无从谈起。

退一步的正确暴力：先用哈希表统计每个编号的频率 $f$，再**枚举小档尺寸 $x$**，对每个 $(f, x)$ **逐盒模拟装球**——每盒尽量装 $x+1$ 个、装不下再装 $x$ 个……问题出在收尾：最后剩下的 $r$ 个球若 $0 \lt r \lt x$，既不能单独成盒，也不能直接丢进已装 $x+1$ 的盒子（会变成 $x+2$），必须**回头把若干盒子从 $x+1$ 档拆成 $x$ 档**腾容量。这个回拆逻辑分支多、边界绕，赛时极易写挂；复杂度虽可接受（每轮 $O(n/x)$），但正确性风险远大于收益。

我们的目标是：对每个 $(f, x)$ 用**一次算术**直接回答「能不能拆、最少几盒」——把模拟彻底变成数学判定。

### 3.2 核心观察：独立拆分 + 两档尺寸 + 容量区间

![两条规则坍缩成可枚举结构](images/valid_groups_two_tiers.svg)

**观察 1（规则 1 ⟹ 各编号独立拆分）**：盒子不能混编号，所以每个编号的球只在自家盒子之间分配，编号之间互不影响——**总盒数 = 各编号盒数之和**。全局唯一要协调的是：所有编号共用同一组盒大小档位。

**观察 2（规则 2 ⟹ 尺寸只有两档）**：设合法方案中最小盒大小为 $x$，则最大盒 $\le x+1$，即**所有盒大小 $\in \{x, x+1\}$**。反过来，只要全部盒大小都落在 $\{x, x+1\}$ 里，最大减最小至多是 1，自动合法（全部同大小则差为 0，也合法）。于是**唯一的决策变量就是小档 $x$**——把「均衡分配」这个连续的语义压缩成了一个可枚举的整数。

**观察 3（容量区间判定）**：固定 $x$，某编号有 $f$ 个球。设用 $g$ 个盒子，其中 $q$ 个装 $x+1$ 个、其余 $g - q$ 个装 $x$ 个，则

$$
\text{总球数} = (g - q) \cdot x + q \cdot (x + 1) = gx + q,\qquad 0 \le q \le g
$$

$q$ 从 $0$ 到 $g$ 连续取值，所以 **$g$ 个盒子恰好能装下闭区间 $[gx,\ g(x+1)]$ 中的每一个整数**（不多不少）。于是对固定的 $x$：

- **可行 ⟺** 存在 $g$ 使 $gx \le f \le g(x+1)$；
- **最少盒数** $g_{\min} = \left\lceil f / (x+1) \right\rceil$（让「上限」够得着 $f$ 的最小 $g$），此时可行性只需再验**下限**：$g_{\min} \cdot x \le f$。

![容量区间与一次乘法判定](images/valid_groups_capacity_interval.svg)

注意判定的方向性：$g_{\min}$ 本来就是按上界 $g(x+1) \ge f$ 取的，**上界条件自动成立**，真正可能挂掉的只有下界 $gx \le f$——即「$g_{\min}$ 个盒子就算全装小档也超出了 $f$」。右图中 $x=4$、$f=7$：$g_{\min} = 2$，两个盒全装小档也要 $8$ 个球，装不下，故 $x=4$ 整体不可行。

**枚举范围与存在性**：任何盒子至少装 $x$ 个球，而每个编号至少占一个盒子，故 $x \le f$ 对所有编号成立 ⟹ $x \le \text{minFreq}$（最小频率）。而 $x = 1$（盒大小 $\{1,2\}$）时 $g_{\min} = \lceil f/2 \rceil \le f$ 恒成立，**任何频率都可拆**——答案必然存在，枚举 $x \in [1, \text{minFreq}]$ 完备且必有命中。

### 3.3 算法流程

1. 遍历 `balls`，哈希表统计每个编号的频率 `freq`，同时求出 `minFreq`；
2. 枚举小档尺寸 $x = 1 \ldots \text{minFreq}$（大档自动为 $x+1$）；
3. 对每个频率 $f$：整数写法计算 $g = (f + x) / (x + 1)$（即 $\lceil f/(x+1) \rceil$）；
4. 若 $g \cdot x \gt f$：该 $x$ 不可行，`break` 跳出本轮回合；
5. 否则累加 `total += g`；本轮回合全部频率通过后，用 `total` 更新答案；
6. 枚举结束返回最小 `total`（$x=1$ 恒可行，`ans` 必被更新过）。

### 3.4 示例演算

![示例 1 逐档演算与可行集的洞](images/valid_groups_walkthrough.svg)

以示例 1 `balls = [3,2,3,2,3]` 为例：频率 $\{3{:}3,\ 2{:}2\}$，$\text{minFreq} = 2$，只需检查 $x = 1, 2$：

| $x$ | 盒大小 | $f=3$：$g=\lceil 3/(x{+}1)\rceil$，验 $gx \le 3$ | $f=2$：$g=\lceil 2/(x{+}1)\rceil$，验 $gx \le 2$ | total |
|-----|--------|--------------------------------------------------|--------------------------------------------------|-------|
| 1 | $\{1,2\}$ | $g=2$，$2 \times 1 = 2 \le 3$ ✓（装法 $1{+}2$） | $g=1$，$1 \le 2$ ✓ | 3 |
| **2** | $\{2,3\}$ | $g=1$，$1 \times 2 = 2 \le 3$ ✓（装法 $3$） | $g=1$，$2 \le 2$ ✓（装法 $2$） | **2 ← 答案** |

返回 2 ✓。示例 2 频率 $\{10{:}3,\ 3{:}1,\ 1{:}2\}$，$\text{minFreq} = 1$，只能 $x = 1$：$g$ 分别为 $2, 1, 1$，共 4 盒 ✓。示例 3 单一频率 $f = 7$，$\text{minFreq} = 7$：$x = 7$ 时 $g = \lceil 7/8 \rceil = 1$ 且 $1 \times 7 = 7 \le 7$ ✓，一盒装下，答案 1 ✓——**最优档位可以正好顶在 `minFreq` 上**，枚举上界别少写一格。

> ⚠️ 同一频率 $f = 7$ 的可行集是 $\{1,2,3,6,7\}$：$x{=}4$ 时 $g_{\min}=2$、$2 \times 4 = 8 \gt 7$ ✗，$x{=}5$ 同理 ✗，但 $x{=}6$ 又活了（一盒装 7）。**可行集中间有洞 ⟹ 可行性关于 $x$ 不单调 ⟹ 不能二分**，只能线性枚举。不过 $\text{total}(x) = \sum_f \lceil f/(x+1) \rceil$ 的每项都随 $x$ 增大单调不增，所以从 $\text{minFreq}$ **向下**枚举、首个可行即返回，是一个安全的常数优化（见延伸思考）。

## 4. 算法细节

1. **上取整的整数写法**：$g = \lceil f/(x+1) \rceil = (f + x) / (x + 1)$（分子加「分母减一」）。写成 `f / (x+1)` 是下取整，会把盒数算少、把不可行的档位误判成可行。
2. **只验下界，别验上界**：判定写 `g * x > f` 即不可行。若误写成 `g * (x+1) < f`，由于 $g$ 本身就是按 $g(x+1) \ge f$ 取的下界，该式**恒为假**——所有 $x$ 都会被当成可行，答案直接算错。
3. **枚举上界必须是 `minFreq`**：每盒 $\ge x$ 个球、每编号 $\ge 1$ 盒 ⟹ $f \ge x$ 对所有编号成立。写成 `maxFreq` 不会错答案（更大的 $x$ 必然在第一个 `f < x` 的编号处失败），但白白浪费轮次；漏掉 `minFreq` 本身则会丢解（示例 3）。
4. **答案必有，无无解分支**：$x = 1$ 时 $g = \lceil f/2 \rceil \le f$ 对一切 $f \ge 1$ 成立。`ans` 用足够大的初值即可，循环结束直接返回。
5. **值域无关**：$\text{balls[i]} \le 10^9$ 只是哈希 key，算法只看频率集合，无需离散化。
6. **要输出具体方案也不难**（本题只要个数）：$g_{\min}$ 个盒子里，令 $q = f - g_{\min} \cdot x$ 个盒装 $x+1$、其余装 $x$。由 $g_{\min}x \le f \le g_{\min}(x+1)$ 知 $0 \le q \le g_{\min}$，构造天然合法。
7. **溢出评估**：$g \cdot x \le f + x \le 2 \times 10^5 \lt 2^{31}$，C++ `int` 安全；`1LL` 只是防御性习惯。

## 5. 正确性证明

**引理 1（两档表示）**：一个分组方案合法 ⟺ 存在正整数 $x$，使方案中所有盒大小 $\in \{x, x+1\}$；且该 $x$（取方案的最小盒大小时）必满足 $1 \le x \le \text{minFreq}$。

**证明**：（⟸）盒大小都在 $\{x, x+1\}$ 内时，最大减最小 $\in \{0, 1\}$，规则 2 成立；同盒同编号是方案自身的属性，与 $x$ 无关，规则 1 不受影响。（⟹）合法方案中盒大小均为正整数，设最小者为 $x \ge 1$，由规则 2 最大者 $\le x + 1$，故全部落在 $\{x, x+1\}$。又每个编号至少占一个盒、每盒 $\ge x$ 个球，故每个频率 $f \ge x$，即 $x \le \text{minFreq}$。∎

**引理 2（单编号的区间定理）**：固定 $x \ge 1$ 与 $f \ge 1$。$f$ 恰能被 $g$ 个大小 $\in \{x, x+1\}$ 的非空盒装下 ⟺ $gx \le f \le g(x+1)$；且满足此条件的 $g$ 的最小值为 $g_{\min} = \lceil f/(x+1) \rceil$，故「$f$ 可拆」⟺ $g_{\min} \cdot x \le f$，可拆时最少盒数即 $g_{\min}$。

**证明**：设 $g$ 个盒中 $q$ 个装 $x+1$ 个、$g - q$ 个装 $x$ 个（$0 \le q \le g$），总球数 $= (g-q)x + q(x+1) = gx + q$。当 $q$ 遍取 $0, 1, \ldots, g$ 时 $gx + q$ 恰遍取闭区间 $[gx,\ g(x+1)]$ 中的全部整数，故「$f$ 可拆成 $g$ 盒」⟺ $f \in [gx, g(x+1)]$ ⟺ $gx \le f \le g(x+1)$。区间右端 $g(x+1)$ 随 $g$ 递增，使 $g(x+1) \ge f$ 的最小 $g$ 即 $\lceil f/(x+1) \rceil = g_{\min}$；任何 $g \lt g_{\min}$ 都有 $g(x+1) \lt f$ 不可行，因此可行 $g$（若存在）中最小者就是 $g_{\min}$，且其可行 ⟺ 左端条件 $g_{\min} x \le f$。∎

**引理 3（独立可加）**：固定 $x$。若每个频率 $f_i$ 都满足 $\lceil f_i/(x+1) \rceil \cdot x \le f_i$，则「小档为 $x$」的合法方案的最少总盒数为 $\sum_i \lceil f_i/(x+1) \rceil$；只要有一个频率不满足，则小档为 $x$ 的合法方案不存在。

**证明**：规则 1 使各编号不共享盒子，一个方案按编号切成互不干扰的子方案；规则 2 只约束盒大小的全局档位一致性，而这里所有盒子都被限制在 $\{x, x+1\}$，一致性自动满足。于是总方案合法 ⟺ 每个编号的子方案各自合法（引理 1 的 ⟸ 方向），且总盒数 = 各子方案盒数之和。由引理 2，各子方案最少盒数为 $\lceil f_i/(x+1) \rceil$，且子方案存在 ⟺ 可行条件成立；对和式求最小，各分量独立取最小即得总和最小。∎

**定理**：算法返回合法分组的最少盒数。

**证明**：由引理 1，任意合法方案对应某个 $x \in [1, \text{minFreq}]$（取其最小盒大小），算法的枚举范围覆盖了全部候选 $x$。固定 $x$ 后，由引理 3，该档位下的最优总盒数为 $\sum_i \lceil f_i/(x+1) \rceil$（可行时）或不存在（不可行时），算法第 3–5 步逐一验证每个频率的可行性并在可行时精确累加出该值。对全体可行 $x$ 取最小，即对全体合法方案按档位分类后取各类最优的最小值，故为全局最少。又 $x = 1$ 时每个频率 $f$ 满足 $\lceil f/2 \rceil \cdot 1 \le f$，算法至少命中一轮，返回值必为有限值。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。哈希统计 $O(n)$。设不同编号数为 $k$、最小频率为 $m$，枚举与检查的总轮次为 $k \cdot m$；每个频率 $\ge m$，故 $k \cdot m \le \sum_i f_i = n$，枚举部分总量不超过 $n$，与统计合并仍为线性。「编号多 ⟹ 最小频率小、最小频率大 ⟹ 编号少」二者此消彼长，把双重枚举封顶在 $n$——与计数排序的桶论证同款套路，是本题复杂度的精髓。
- **空间复杂度**：$O(k)$。哈希表存 $k$ 个编号的频率（$k \le n$），枚举过程只用常数个变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minGroupsForValidAssignment(vector<int>& balls) {
        unordered_map<int, int> freq;
        for (int b : balls) freq[b]++;

        int minFreq = INT_MAX;
        for (auto& [num, f] : freq) minFreq = min(minFreq, f);

        int ans = INT_MAX;
        for (int x = 1; x <= minFreq; x++) {      // 小档 x / 大档 x+1
            int total = 0;
            bool ok = true;
            for (auto& [num, f] : freq) {
                int g = (f + x) / (x + 1);        // g = ceil(f/(x+1))，该编号最少盒数
                if (1LL * g * x > f) {            // g 盒全装小档也超出 f → x 不可行
                    ok = false;
                    break;
                }
                total += g;
            }
            if (ok) ans = min(ans, total);
        }
        return ans;                               // x=1 恒可行，ans 必被更新
    }
};
```

### Python

```python
class Solution:
    def minGroupsForValidAssignment(self, balls: List[int]) -> int:
        freq = Counter(balls)
        min_freq = min(freq.values())

        ans = inf
        for x in range(1, min_freq + 1):          # 小档 x / 大档 x+1
            total, ok = 0, True
            for f in freq.values():
                g = (f + x) // (x + 1)            # g = ceil(f/(x+1))，该编号最少盒数
                if g * x > f:                     # g 盒全装小档也超出 f → x 不可行
                    ok = False
                    break
                total += g
            if ok:
                ans = min(ans, total)
        return ans                                 # x=1 恒可行，ans 必被更新
```

> 💡 两版逻辑一致。三个易错点回看：`(f + x) // (x + 1)` 是上取整写法；判定只看下界 `g * x > f`；`break` 只跳出内层频率循环、`ok` 标记负责让本轮 `total` 作废。

## 8. 边界情况与易错点

1. **上取整别写成下取整**：`f / (x+1)` 会把 $g$ 算小，进而在本不可行的档位上让 `g * x > f` 也不触发，输出偏小的错答案。
2. **判定方向别写反**：`g * (x+1) < f` 恒为假（$g$ 按上界取的），等于没判；真正的约束在下界 `g * x > f`。
3. **不能二分**：单一频率 $f = 7$ 的可行集 $\{1,2,3,6,7\}$ 中间有洞，可行性关于 $x$ 不单调。缓解办法是自 $\text{minFreq}$ 向下线性枚举、首个可行即返回（$\text{total}$ 单调不增保证正确）。
4. **枚举上界含 `minFreq` 本身**：`[1,1,1,1,1,1,1]` 的答案是 1（$x = 7$ 一盒装下），上界写成 `minFreq - 1` 或随手写 `maxFreq/2` 之类都会丢解。
5. **单元素 / 全互异**：`balls = [1]` → 1 盒；全互异时每频率为 1、$\text{minFreq} = 1$、只能 $x = 1$，每编号一盒，答案 = 编号数 = $n$。两处都被 `x=1` 分支自然覆盖。
6. **「至多两档」≠「两档都得出现」**：全部盒子同大小（差为 0）同样合法，别在判定里强求 $x$ 与 $x+1$ 都被用上。
7. **答案必有**：$x = 1$ 恒可行，无需返回 $-1$ 的分支；但 `ans` 初值要足够大，且别把「初值 0」当答案返回。
8. **溢出安全**：$g \cdot x \le f + x \le 2 \times 10^5$，`int` 足够；C++ 写 `1LL` 属防御性习惯，非必需。
9. **别被值域带偏**：$\text{balls[i]} \le 10^9$ 只影响哈希 key 的存储（用 `unordered_map` / `Counter` 即可），不影响任何算法环节。

- 本题另有[每日题解](../../solution/2901-3000/2910_合法分组的最少组数.md)：面试问答展开（枚举范围推导、为何不能二分等）。

**延伸思考**：① **从大到小枚举**：$\text{total}(x) = \sum_f \lceil f/(x+1) \rceil$ 关于 $x$ 单调不增，故所有可行 $x$ 中**最大者**的 `total` 最小——从 $\text{minFreq}$ 向下枚举、首个可行即返回，最坏复杂度不变、平均常数更优；还可加下界剪枝 $\text{total} \ge \lceil n/(x+1) \rceil$。② **为什么不能二分**：可行集有洞（$f=7$ 的 $\{1,2,3,6,7\}$），二分的单调前提被破坏；「值单调、可行不单调」时用线性扫描 + 首个可行即停是标准替代。③ **泛化到 $d$ 档**：若规则改为「最大 − 最小 $\le d$」，则盒大小 $\in \{x, \ldots, x+d\}$，$g$ 个盒容量恰为区间 $[gx,\ g(x+d)]$（$q_1 + 2q_2 + \cdots$ 可凑出 $0..gd$ 的每个整数），同一骨架给出 $g_{\min} = \lceil f/(x+d) \rceil$、可行 ⟺ $g_{\min} x \le f$。④ **输出方案**：取 $q = f - g_{\min} \cdot x$ 个盒装 $x+1$、其余装 $x$，一次构造即得合法分组。
