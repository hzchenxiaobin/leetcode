# LeetCode 得到 K 个半回文串的最少修改次数 题解

## 1. 题目概述

- **标题 / 题号**：得到 K 个半回文串的最少修改次数（#2911，hard）
- **链接**：https://leetcode.cn/problems/minimum-changes-to-make-k-semi-palindromes/
- **来源**：LeetCode 第 368 场周赛 Q4
- **难度**：困难
- **标签**：动态规划、字符串、枚举、因数

**题意**：给定字符串 `s` 与整数 `k`，把 `s` 切成 `k` 个非空子串，对每段独立地做若干次**字符替换**使它成为**半回文串**，求总替换次数的最小值。

**半回文串**的判定：设段长为 $L$，取 $L$ 的一个**真因数** $d$（$1 \le d \lt L$），把段内下标 $\bmod d$ 相同的位置归为一组（共 $d$ 组，每组恰 $L/d$ 个字符），若**每一组各自是回文串**，则该段是半回文串。两个定义细节：$d = 1$ 时只有一组即整段本身，条件退化为「整段是回文」；长度为 $1$ 的段没有任何真因数，**永远不是**半回文串。

**约束**：

- $2 \le s.length \le 200$
- $1 \le k \le s.length / 2$
- `s` 仅由小写英文字母组成

> 💡 本题是 368 场的收官困难题，赛时通过率断崖，但拆开看是「三件熟悉的小事」的拼装：**段代价可以脱离划分单独预计算**（一张 $cost$ 表）、**固定 $d$ 后代价就是数不匹配对称对**（每对改一个字符）、**选切点交给划分型 DP**。三步单拎出来都是模板级知识，真正的门槛全在「半回文」这个陌生定义的第一次翻译——尤其是「长度 1 的段不合法」与「$d$ 必须是真因数」两处暗桩，属于 wa 一发才能体会的类型。另见[每日题解](../../solution/2901-3000/2911_得到 K 个半回文串的最少修改次数.md)（面试问答视角），互为印证。

## 2. 示例

**示例 1**

```text
输入：s = "abcac", k = 2
输出：1
解释：划分成 "ab" 与 "cac"。"cac" 在 d = 1 时整段回文，已是半回文；
     "ab" 在 d = 1 时改一处（"aa"）成为半回文。
```

**示例 2**

```text
输入：s = "abcdef", k = 2
输出：2
解释：划分成 "abc" 与 "def"，各改 1 个字符（如 "aba" / "ded"）。
```

**示例 3**

```text
输入：s = "aabbaa", k = 3
输出：0
解释：划分成 "aa"、"bb"、"aa"，三段在 d = 1 下都是回文，零修改。
```

## 3. 解题思路

### 3.1 暴力思路：指数级划分 + 逐段按定义判定

最朴素的做法：枚举 $s$ 的所有 $k$ 段划分（$\binom{n-1}{k-1}$ 种），对每段枚举真因数 $d$、按定义检查每组是否回文、再数修改次数。$n = 200$ 时划分数是天文数字，不可行。

但这个暴力里藏着两个**可以彻底解耦的子问题**：

1. **段代价**：任意子串变成半回文的最少修改次数 $cost[l][r]$——只依赖子串自身；
2. **划分选择**：选哪些切点使各段代价之和最小——只依赖 $cost$ 表。

把 1 预计算成表，2 就是一维划分 DP，复杂度立刻落回多项式。

### 3.2 核心观察：代价 = 不匹配对称对数，各段独立可加

![半回文的分组配对结构](images/semipalin_groups_concept.svg)

**观察 1（配对计数）**：固定段 $s[l..r]$ 与因数 $d$ 后，第 $g$ 组（$0 \le g \lt d$）的元素位于偏移 $g,\ g+d,\ \ldots,\ g+(m-1)d$（$m = L/d$）。组内回文要求第 $t$ 个与第 $m-1-t$ 个字符相等——这构成组内位置（除 $m$ 为奇数时的中心外）的一个**完美匹配**。因此把该组改成回文的最少修改次数恰是**不匹配对的个数**：每对两端若不同，改其中一端即可、恰好 1 次。各组位置互不相交、修改互不干扰，直接求和。

**观察 2（回文是半回文的特例）**：$d = 1$ 是一切 $L \ge 2$ 的真因数，此时一组即整段、条件退化为回文。所以**回文串都是半回文串**（代价 0），而 `"abcabc"` 这类非回文串也能以 $d = 3$、代价 0 成为半回文——半回文是严格更弱的约束，这正是本题比「划分回文串」多出的自由度。

**观察 3（段间独立）**：字符替换只发生在段内，切点一旦确定，各段代价互相独立，**总代价 = 各段代价之和**。于是「选划分」是标准的划分型 DP：$f[i][j]$ = 前 $i$ 个字符切成 $j$ 段的最小总代价。

![两阶段解耦：段代价查表 + 划分 DP](images/semipalin_dp_model.svg)

> ⚠️ **定义里的两处暗桩**：① 长度为 1 的段没有真因数，**不是半回文串**，且修改不改变长度、无药可救——划分中不允许出现；好在 $k \le n/2$ 保证「每段都取至少 2 个字符」的划分必然存在（如均分），答案必定有限。② $d$ 必须严格小于 $L$：若允许 $d = L$，每组只含 1 个字符、自动回文，任何串都成了零代价半回文——题目特意封死这个退化解。

### 3.3 算法流程

1. **真因数表**：倍数筛求 $divs[L]$（$L \in [2, n]$ 的全部真因数）：外层 $d = 1 \ldots n-1$，内层 $L = 2d, 3d, \ldots \le n$，总量为调和级数 $O(n \log n)$；
2. **代价表**：枚举全部 $O(n^2)$ 个子串 $[l, r]$，对每个真因数 $d$ 按观察 1 累计不匹配对称对数，对 $d$ 取最小，存入 $cost[l][r]$；
3. **划分 DP**：$f[0][0] = 0$，其余初始化为 $\infty$，

$$
f[i][j] = \min_{t \le i-2} \; f[t][j-1] + cost[t][i-1]
$$

   其中末段为 $s[t..i-1]$（长度 $i - t \ge 2$，天然排除长度 1 的段），且 $j \le i/2$；
4. 答案为 $f[n][k]$。

### 3.4 示例演算

![示例 1 的候选划分与 DP 演算](images/semipalin_walkthrough.svg)

以示例 1 `s = "abcac", k = 2` 为例，先算代价表里用得到的条目：

| 子串 | $L$ | 真因数 | 各 $d$ 的不匹配对数 | $cost$ |
|------|-----|--------|---------------------|--------|
| `ab` | 2 | 1 | $d{=}1$：$(a,b)$✗ → 1 | 1 |
| `ac` | 2 | 1 | $d{=}1$：$(a,c)$✗ → 1 | 1 |
| `abc` | 3 | 1 | $d{=}1$：$(a,c)$✗ → 1 | 1 |
| `cac` | 3 | 1 | $d{=}1$：$(c,c)$✓ → 0 | **0** |
| `abca` | 4 | 1, 2 | $d{=}1$：1；$d{=}2$：组 $(a,c)$✗、$(b,a)$✗ → 2 | 1 |
| `bcac` | 4 | 1, 2 | $d{=}1$：2；$d{=}2$：组 $(b,a)$✗、$(c,c)$✓ → 1 | 1 |
| `abcac` | 5 | 1 | $d{=}1$：$(a,c)$✗、$(b,a)$✗ → 2 | 2 |

DP 表（`—` 表示不可达，即必然出现长度 1 的段）：

| $i$ | 2 | 3 | 4 | 5 |
|-----|---|---|---|---|
| $f[i][1]$ | 1 | 1 | 1 | 2 |
| $f[i][2]$ | — | — | 2 | **1** |

$f[5][2] = \min(f[2][1] + cost(\text{"cac"}),\; f[3][1] + cost(\text{"ac"})) = \min(1+0,\, 1+1) = 1$，对应划分 `"ab" | "cac"` ✓。四个候选切分里两个含长度 1 段直接非法，剩下两个中 `"ab"|"cac"` 胜出。

## 4. 算法细节

1. **真因数用倍数筛而非试除**：`for d in 1..n-1: for L in 2d, 3d, ..., n: divs[L].append(d)`，比每个 $L$ 做 $O(\sqrt L)$ 试除更短，总量 $\sum_d n/d = O(n \log n)$；从 $2d$ 起填 $L$，$d = L$ 永远进不了表，天然排除假因数。
2. **组内对称对的索引公式**：段 $[l, r]$、长度 $L$、$d \mid L$、$m = L/d$，第 $g$ 组比较

$$
s[l+g+t\cdot d] \;\neq\; s[l+g+(m-1-t)\cdot d] \qquad (0 \le g \lt d,\; 0 \le t \lt m/2)
$$

   两个下标都是「从 $l$ 起偏移 $g + k\cdot d$」的形状。忘加 $l$、或把 $m-1-t$ 写成 $m-t$，是最高频的两处手滑。
3. **比较次数的账本**：每个（子串, $d$）恰做 $d \cdot \lfloor m/2 \rfloor \le L/2$ 次比较；$L \le 200$ 时真因数个数 $\le 17$（$\tau(180) = 18$ 为最大因数个数），全部子串累计约 $3 \times 10^6$ 次比较（$n = 200$ 实测 2 973 993 次），完全跑得动。
4. **DP 的两重界限**：`j ≤ i/2`（每段至少 2 个字符）与 `t ≤ i-2`（末段长度 $i - t \ge 2$），都在防止长度 1 的段混进来；$f$ 初始化为 $\infty$、转移前判可达，天然屏蔽非法状态。
5. **为什么没有循环依赖**：替换不改变长度，$d$ 的候选集合与「改成什么字符」无关；引理 1 又把固定 $d$ 的最优修改数直接按配对数了出来，无需先知道最终串。「先算代价、再做 DP」的顺序因此是安全的。
6. **值域**：每段代价 $\le \lfloor L/2 \rfloor \le 99$，总和 $< 10^4$，`int` 足够；Python 用 `inf` 表示不可达，C++ 用 `0x3f3f3f3f` 且转移前判 `< INF`，防止两个「无穷」相加破坏哨兵值。

## 5. 正确性证明

**引理 1（单组代价）**：设某组按顺序取出为 $c_0, c_1, \ldots, c_{m-1}$，把它变成回文串的最少修改次数为 $\#\{\,t \lt m/2 : c_t \ne c_{m-1-t}\,\}$。

**证明**：回文要求终态字符满足 $c'_t = c'_{m-1-t}$ 对一切 $t$ 成立。配对 $\{t,\, m-1-t\}$（$t \lt m/2$）构成对非中心位置（$m$ 为奇数时的中心位不受约束）的完美匹配，各对位置互不重叠。若 $c_t \ne c_{m-1-t}$，则该对至少一端必须被修改，贡献 $\ge 1$；反之把其中一端改成另一端的字符，恰好贡献 $1$。各对独立、贡献可加，故最小值恰为不匹配对数。∎

**引理 2（段代价）**：子串 $s[l..r]$（$L \ge 2$）变成半回文串的最少修改次数为 $\min_{d \mid L,\, d \lt L} \sum_{g=0}^{d-1} \#\{\text{第 } g \text{ 组的不匹配对称对}\}$；长度为 1 的子串不存在合法 $d$，代价为 $\infty$。

**证明**：半回文的定义为存在一个合法 $d$ 使全部 $d$ 组各自回文。替换只改字符、不改长度，故 $d$ 的候选集合不因替换而变化。固定任一合法 $d$，由引理 1，该 $d$ 下每组的最优修改数即其不匹配对数、组间独立可加；对所有合法 $d$ 取最小即得段最优。$L = 1$ 时 $1 \le d \lt 1$ 无解，候选集为空。∎

**定理**：上述 DP 返回的 $f[n][k]$ 等于所求最少总修改次数。

**证明**：对 $(i, j)$ 归纳断言：$f[i][j]$ 等于「把 $s[0..i-1]$ 划分成 $j$ 个长度 $\ge 2$ 的段的最小代价和」，不存在此类划分时为 $\infty$。奠基 $f[0][0] = 0$ 显然。归纳步：任一合法划分的末段形如 $s[t..i-1]$（$t \le i-2$），去掉末段后前缀是 $j-1$ 段的合法划分；由引理 2，末段的最优代价为 $cost[t][i-1]$，且前后两部分的修改发生在不相交的位置区间、代价可加。由归纳假设与交换论证（若某最优方案的前缀非最优，将其替换为最优前缀得严格更优方案，矛盾），$f[i][j]$ 恰取遍所有 $t$ 的 $f[t][j-1] + cost[t][i-1]$ 之最小值。又 $k \le n/2$ 时存在每段长度 $\ge 2$ 的划分（每段先分 2 个字符、余数逐段加 1），故 $f[n][k] \lt \infty$。∎

## 6. 复杂度分析

- **时间复杂度**：真因数表 $O(n \log n)$；代价表共 $O(n^2)$ 个子串、每个子串做 $\sum_{d} d\lfloor (L/d)/2 \rfloor \le L \cdot \tau(L) / 2$ 次比较，$n = 200$ 实测约 $3 \times 10^6$ 次比较（宽松上界 $O(n^3 \log n)$，常数极小）；划分 DP $O(n^2 k) \le 2 \times 10^6$ 次转移。合计百万量级：C++ 毫秒级，Python 数秒内可通过。
- **空间复杂度**：$O(n^2)$ 存 $cost$ 表（$n = 200$ 即约 4 万项），加 $O(nk)$ 的 DP 数组。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int minimumChanges(string s, int k) {
        int n = s.size();

        // divs[L]：长度 L 的全部真因数（1 <= d < L 且 d | L）
        vector<vector<int>> divs(n + 1);
        for (int d = 1; d < n; d++)
            for (int L = d * 2; L <= n; L += d)
                divs[L].push_back(d);

        const int INF = 0x3f3f3f3f;
        // cost[l][r]：s[l..r] 变成半回文的最少修改次数
        vector<vector<int>> cost(n, vector<int>(n, INF));
        for (int l = 0; l < n; l++)
            for (int r = l + 1; r < n; r++) {
                int L = r - l + 1, best = INF;
                for (int d : divs[L]) {
                    int m = L / d, c = 0;
                    for (int g = 0; g < d; g++)           // 第 g 组
                        for (int t = 0; t < m / 2; t++)    // 组内对称对 t <-> m-1-t
                            c += s[l + g + t * d] != s[l + g + (m - 1 - t) * d];
                    best = min(best, c);
                }
                cost[l][r] = best;
            }

        // f[i][j]：前 i 个字符切成 j 段的最小总代价
        vector<vector<int>> f(n + 1, vector<int>(k + 1, INF));
        f[0][0] = 0;
        for (int i = 2; i <= n; i++)
            for (int j = 1; j <= min(k, i / 2); j++)
                for (int t = j - 1; t <= i - 2; t++)       // 末段 s[t..i-1]，长度 >= 2
                    if (f[t][j - 1] < INF)
                        f[i][j] = min(f[i][j], f[t][j - 1] + cost[t][i - 1]);
        return f[n][k];
    }
};
```

### Python

```python
class Solution:
    def minimumChanges(self, s: str, k: int) -> int:
        n = len(s)
        divs = [[] for _ in range(n + 1)]        # divs[L]：L 的全部真因数
        for d in range(1, n):
            for L in range(d * 2, n + 1, d):
                divs[L].append(d)

        INF = inf
        cost = [[INF] * n for _ in range(n)]     # cost[l][r]：s[l..r] 的半回文代价
        for l in range(n):
            for r in range(l + 1, n):
                L = r - l + 1
                best = INF
                for d in divs[L]:
                    m = L // d
                    c = 0
                    for g in range(d):           # 第 g 组
                        for t in range(m // 2):  # 组内对称对 t <-> m-1-t
                            if s[l + g + t * d] != s[l + g + (m - 1 - t) * d]:
                                c += 1
                    if c < best:
                        best = c
                cost[l][r] = best

        f = [[INF] * (k + 1) for _ in range(n + 1)]
        f[0][0] = 0
        for i in range(2, n + 1):
            for j in range(1, min(k, i // 2) + 1):
                best = INF
                for t in range(j - 1, i - 1):    # 末段 s[t..i-1]，长度 >= 2
                    if f[t][j - 1] < INF:
                        c = f[t][j - 1] + cost[t][i - 1]
                        if c < best:
                            best = c
                f[i][j] = best
        return f[n][k]
```

> 💡 两版逻辑一致。三个易错点回看：`divs` 只装**真因数**（从 $2d$ 起填 $L$，$d = L$ 永远进不了表）；DP 双重界限 `j ≤ i/2`、`t ≤ i-2` 排除长度 1 的段；`cost[t][i-1]` 的两端下标都要落在 `s` 内。

## 8. 边界情况与易错点

1. **长度 1 的段非法**：没有真因数、不是半回文，修改救不了（不改长度）。DP 若不禁止（把单字符当代价 0）会 WA。$k \le n/2$ 保证存在每段 $\ge 2$ 的划分，答案必有限。
2. **$d$ 必须是真因数（$d \lt L$）**：放进 $d = L$ 会出现「每组单字符、自动回文」的退化解，任何串代价都变 0。倍数筛从 $L = 2d$ 开始填表，天然排除。
3. **$d = 1$ 别漏**：它是所有 $L \ge 2$ 的真因数（整段回文）。若从 $d = 2$ 开始枚举，`"aa"` 会被误判成无解、代价虚高。
4. **组内配对索引**：$s[l+g+t\cdot d]$ 对 $s[l+g+(m-1-t)\cdot d]$。忘加 $l$、步长乘错位置、$m-1-t$ 差一，都会悄悄算错——建议拿 `"abcabc"`（$d=3$ 应得 0）和 `"abcac"` 做单元自测。
5. **min 是对 $d$ 取**：先枚举 $d$ 数不匹配对、再取最小；不存在「先定终态串再挑 $d$」的循环依赖（见 §4 第 5 点）。
6. **DP 状态的可达性**：`f` 用 $\infty$ 初始化、转移前判可达；`f[i][j]` 仅在 $i \ge 2j$ 有意义。Python 的 `inf` 参与加法不会坏，C++ 两个 `INF` 相加会破哨兵值，必须先判。
7. **答案量级**：$\le \sum_i \lfloor L_i/2 \rfloor \lt 10^4$，`int` 安全；无取模、无负数。
8. **「代价 0」不等于「回文」**：非回文的 `"abcabc"` 代价也是 0（$d = 3$）；调试时别只按回文剪枝，大因数 $d$ 常常才是代价 0 的来源。

**延伸思考**：① **代价表能否更快**：固定 $d$，把 $s$ 按下标 $\bmod d$ 抽成 $d$ 条子列，则子串 $[l, r]$ 关于 $d$ 的代价恰是各子列对应**连续区间**的回文代价之和；每条子列用 $g[a][b] = g[a+1][b-1] + (c_a \ne c_b)$ 预处理全部区间，单个 $d$ 耗时 $O(n^2/d)$，合计 $\sum_{d=1}^{n} O(n^2/d) = O(n^2 \log n)$——比朴素上界降一个 $n$，$n = 200$ 时属杀鸡用牛刀。② **若去掉 $k \le n/2$**：$k \gt n/2$ 时任何划分必含长度 1 段，问题无解（应返回 $-1$），DP 的 $\infty$ 会如实报告。③ **泛化「每组回文」为「每组 $k$-近似回文」**：单组代价从「不匹配对数」换成「至多容忍 $k$ 对不匹配」的判定，引理 1 的配对计数改为阈值比较即可，整体骨架不变。
