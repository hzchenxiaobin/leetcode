# LeetCode 切割后面积最大的蛋糕 题解

## 1. 题目概述

- **标题 / 题号**：切割后面积最大的蛋糕（#1465，medium）
- **链接**：https://leetcode.cn/problems/maximum-area-of-a-piece-of-cake-after-horizontal-and-vertical-cuts/
- **来源**：LeetCode 第 191 场周赛 Q2
- **难度**：中等
- **标签**：贪心、数组、排序

**题意**：一块高为 $h$、宽为 $w$ 的矩形蛋糕。`horizontalCuts[i]` 表示第 $i$ 条**水平**切口到蛋糕顶部的距离，`verticalCuts[j]` 表示第 $j$ 条**竖直**切口到蛋糕左侧的距离。沿这些贯穿整块蛋糕的切口切开后，蛋糕被分成若干个小矩形，求其中**面积最大**的一块，并把面积对 $10^9 + 7$ 取模后返回。

**约束**：

- $2 \le h, w \le 10^9$
- $1 \le \lvert \text{horizontalCuts} \rvert \le \min(h-1, 10^5)$，$1 \le \lvert \text{verticalCuts} \rvert \le \min(w-1, 10^5)$
- $1 \le \text{horizontalCuts}[i] < h$，$1 \le \text{verticalCuts}[j] < w$，同一数组内元素互不相同
- 答案对 $10^9 + 7$ 取模

> 💡 切口一定贯穿整块蛋糕，所以切完之后**每一块都是一条水平带与一条竖直带的交集**，这是本题所有结论的几何基础。

## 2. 示例

**示例 1**

```text
输入：h = 5, w = 4, horizontalCuts = [1,2,4], verticalCuts = [1,3]
输出：4
解释：水平带依次长 1,1,2,1，竖直带依次长 1,2,1，最大块面积 = 2 × 2 = 4。
```

**示例 2**

```text
输入：h = 5, w = 4, horizontalCuts = [3,1], verticalCuts = [1]
输出：6
解释：水平切口乱序，排序后为 [1,3]，带长 1,2,2；竖直带长 1,3；最大块面积 = 2 × 3 = 6。
```

**示例 3**

```text
输入：h = 5, w = 4, horizontalCuts = [3], verticalCuts = [3]
输出：9
解释：水平带长 3,2，竖直带长 3,1，最大块面积 = 3 × 3 = 9。
```

## 3. 解题思路

### 3.1 暴力思路

最直白的做法是「先把蛋糕切开，再逐块量面积」：枚举一个水平带和一个竖直带，组合出 $(n+1)(m+1)$ 块，取面积最大者。而 $n, m$ 都可以达到 $10^5$，枚举量是 $10^{10}$ 量级，必然超时。

退一步，「只求最大间隔」也有暴力写法：对每个切口与其他切口两两相减求最大差，或对每个水平间隔与每个竖直间隔求乘积的最大值，同样是 $O(nm)$，依旧过不去。瓶颈其实不在数据规模，而在于**我们把两个方向耦合在一起考虑了**。

### 3.2 核心观察：两个方向互相独立

![面积 = 最高的水平间隔 × 最宽的竖直间隔](images/wc191_q2_max_gap_model.svg)

把所有水平切口坐标连同上下边界 0 与 $h$ 一起排序，得到

$$0 = H_0 < H_1 < \cdots < H_{n+1} = h$$

把所有竖直切口坐标连同左右边界 0 与 $w$ 一起排序，得到

$$0 = W_0 < W_1 < \cdots < W_{m+1} = w$$

由于切口贯穿整块蛋糕，切出来的每一块都恰好是

$$\bigl[H_i,\ H_{i+1}\bigr] \times \bigl[W_j,\ W_{j+1}\bigr], \qquad 0 \le i \le n,\ 0 \le j \le m$$

它的面积为 $\Delta H_i \cdot \Delta W_j$，其中 $\Delta H_i = H_{i+1} - H_i$、$\Delta W_j = W_{j+1} - W_j$ 就是同一方向上相邻两条切口之间的距离。于是问题变成

$$\text{ans} = \max_{i,\,j} \bigl(\Delta H_i \cdot \Delta W_j\bigr) = \Bigl(\max_i \Delta H_i\Bigr) \cdot \Bigl(\max_j \Delta W_j\Bigr)$$

最后一步之所以成立，是因为**两个因子互不影响**：挑出最大的水平间隔与最大的竖直间隔，它们的交集就是一块真实存在的蛋糕，面积恰好是两个最大值之积；而任何其他块的面积都不会超过它。二维的「最大矩形」因此被降成了两个一维的「最大间隔」。

### 3.3 算法流程

![排序 → 补边界 → 扫最大间隔 → 相乘取模](images/wc191_q2_algorithm_flow.svg)

1. 分别把 `horizontalCuts` 与 `verticalCuts` 升序排序。
2. 求水平方向的最大相邻间隔：从 `prev = 0` 出发依次扫描排序后的切口 $c$，用 $c - \text{prev}$ 更新答案，扫完后**再用 $h - \text{prev}$ 更新一次**（收尾的那条带）。
3. 竖直方向同理，收尾用 $w - \text{prev}$。
4. 两个最大间隔相乘（用 64 位整型），再对 $10^9 + 7$ 取模。

### 3.4 示例演算

![示例 2 的数轴演算](images/wc191_q2_walkthrough.svg)

以示例 2（$h = 5$、$w = 4$、`horizontalCuts = [3,1]`、`verticalCuts = [1]`）为例：

| 方向 | 排序后的切口（含边界） | 相邻间隔 | 最大值 |
|------|------------------------|----------|--------|
| 水平 | 0, 1, 3, 5 | 1, 2, 2 | 2 |
| 竖直 | 0, 1, 4 | 1, 3 | 3 |

答案为 $2 \times 3 = 6$，$6 \bmod (10^9+7) = 6$，与官方输出一致。注意水平方向的最大间隔并不唯一（两条长度都是 2），取哪一条都不影响乘积。

## 4. 算法细节

1. **必须补上两条边界**。$n$ 条水平切口只切出 $n+1$ 条水平带，最上面一条是 $H_1 - 0$、最下面一条是 $h - H_n$；漏掉边界就会少算两条带。示例 3 的最大间隔恰好就是边界带 $3 - 0 = 3$。
2. **必须排序，不能依赖输入顺序**。示例 2 的 `horizontalCuts` 就是 `[3,1]`：不排序时扫描会得到 $3-0=3$（把切口 1 的左侧也算了进去）、$1-3=-2$、$5-1=4$，最大值 4 完全错误。
3. **用一次线性扫描求最大间隔**，而不是两两相减。排序后相邻元素之差才是候选间隔，非相邻元素之差一定由若干个相邻间隔拼成，不可能更大。
4. **取模的位置与溢出**。最大间隔可达 $10^9$，乘积可达 $10^{18}$，超过 32 位 `int` 上限（约 $2.1 \times 10^9$），必须用 `long long`。数学上 $(a \cdot b) \bmod M = \bigl((a \bmod M)\cdot(b \bmod M)\bigr) \bmod M$，所以先取模再乘**结果相同**；但无论哪种写法，中间乘积都必须在 64 位里算，否则会溢出成错值。
5. **用游标省掉额外数组**。只需 `prev` 一个变量跟随扫描，不必真的把 0 与 $h$ 插进数组；若想保留原数组，先拷贝一份再排序即可。
6. **排序可以直接原地修改入参**。LeetCode 不检查入参是否被改动，C++ 用 `vector<int>&` 直接 `sort` 即可；若在工程代码中使用，建议传值或先拷贝，避免副作用。
7. **两个方向共用同一段逻辑**。把「求最大间隔」抽成一个函数，参数是「上限 limit + 切口数组」，比复制粘贴两遍更不容易漏写收尾那一行。

## 5. 正确性证明

**引理 1（块的几何刻画）**：记 $H = \{0, h\} \cup \text{horizontalCuts}$ 排序后为 $H_0 < H_1 < \cdots < H_{n+1}$，$W = \{0, w\} \cup \text{verticalCuts}$ 排序后为 $W_0 < W_1 < \cdots < W_{m+1}$。切分得到的块集合恰为 $\bigl\{\,[H_i, H_{i+1}] \times [W_j, W_{j+1}]\,\bigr\}$，共 $(n+1)(m+1)$ 块，第 $(i,j)$ 块面积为 $(H_{i+1}-H_i)(W_{j+1}-W_j)$。

**证明**：每条水平切口都是平行于宽边、贯穿整块蛋糕的直线 $y = H_i$，每条竖直切口都是贯穿整块蛋糕的直线 $x = W_j$。这些直线把矩形 $[0,h] \times [0,w]$ 划分成若干区域的并集，且区域之间的边界就是这些直线，故每个区域都是矩形；两条相邻水平直线与两条相邻竖直直线围出的矩形就是 $[H_i, H_{i+1}] \times [W_j, W_{j+1}]$，其面积为长乘宽。区域总数为相邻区间配对数 $(n+1)(m+1)$。∎

**引理 2（两个方向可分离）**：设 $A = \max_i \Delta H_i$、$B = \max_j \Delta W_j$，则 $\max_{i,j} \bigl(\Delta H_i \cdot \Delta W_j\bigr) = A \cdot B$。

**证明**：先注意所有 $\Delta H_i, \Delta W_j > 0$——切口互不相同且都严格落在开区间内，故每个间隔都为正。

- **上界**：对任意 $(i,j)$，有 $\Delta H_i \cdot \Delta W_j \le A \cdot \Delta W_j \le A \cdot B$。
- **可达**：取 $i^* = \arg\max_i \Delta H_i$、$j^* = \arg\max_j \Delta W_j$，由引理 1，块 $[H_{i^*}, H_{i^*+1}] \times [W_{j^*}, W_{j^*+1}]$ 真实存在，其面积恰为 $A \cdot B$。

故最大值等于 $A \cdot B$。∎

**引理 3（扫描正确）**：设排序后的切口为 $c_1 < c_2 < \cdots < c_n$，均落在 $(0, \text{limit})$ 内。以 `prev = 0` 依次处理 $c_1, \ldots, c_n$，循环结束后再补算 $\text{limit} - c_n$，所得最大值等于 $\max\{c_1 - 0,\ c_2 - c_1,\ \ldots,\ c_n - c_{n-1},\ \text{limit} - c_n\}$。

**证明**：对扫描过程归纳：处理 $c_k$ 时 `prev` 恰为 $c_{k-1}$（$k = 1$ 时为 0），故此时比较的值正是 $c_k - c_{k-1}$；循环结束后 `prev = c_n`，补算的是 $\text{limit} - c_n$。集合中的每个元素都被逐一比较过一次，取最大值即为所求。∎

**定理**：算法返回 $\Bigl(\bigl(\max_i \Delta H_i\bigr)\bigl(\max_j \Delta W_j\bigr)\Bigr) \bmod (10^9+7)$，即题面要求的最大的那块蛋糕面积对 $10^9+7$ 取模的结果。

**证明**：由引理 3，`maxGap` 返回的正是该方向上所有相邻间隔（含边界带）的最大值；由引理 2，二者乘积就是所有块中的最大面积；最后按题意对 $10^9+7$ 取模。故输出正确。∎

## 6. 复杂度分析

- **时间**：$O(n \log n + m \log m)$，其中 $n, m$ 分别是两个切口数组的长度。两次排序各占 $O(n \log n)$ 与 $O(m \log m)$；两次线性扫描为 $O(n + m)$；乘法与取模为 $O(1)$。在 $n, m \le 10^5$ 时约 $3 \times 10^6$ 次比较级别，远低于时限。
- **空间**：$O(1)$（不计排序内部开销）。若原地排序入参，额外空间只有常数个 `long long` 变量；若拷贝后再排序，则为 $O(n + m)$。Python 的 `sorted` 返回新列表，额外占用 $O(n + m)$。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int maxArea(int h, int w, vector<int>& horizontalCuts, vector<int>& verticalCuts) {
        const long long MOD = 1000000007LL;

        // 排序后线性扫描，返回该方向上的最大相邻间隔（含两条边界带）
        auto maxGap = [](int limit, vector<int>& cuts) -> long long {
            sort(cuts.begin(), cuts.end());
            long long best = 0, prev = 0;
            for (int c : cuts) {
                best = max(best, (long long)c - prev);
                prev = c;
            }
            best = max(best, (long long)limit - prev);   // 收尾的边界带
            return best;
        };

        long long rh = maxGap(h, horizontalCuts);
        long long rw = maxGap(w, verticalCuts);
        return (int)(rh * rw % MOD);                     // 在 long long 中相乘后再取模
    }
};
```

### Python

```python
class Solution:
    def maxArea(self, h: int, w: int, horizontalCuts: list[int], verticalCuts: list[int]) -> int:
        MOD = 10**9 + 7

        def max_gap(limit: int, cuts: list[int]) -> int:
            best = 0
            prev = 0
            for c in sorted(cuts):
                best = max(best, c - prev)
                prev = c
            return max(best, limit - prev)      # 收尾的边界带

        return max_gap(h, horizontalCuts) * max_gap(w, verticalCuts) % MOD
```

## 8. 边界情况与易错点

1. **最大带贴着边界**：如 $h = 5$、`horizontalCuts = [1]`，最大间隔是 $5 - 1 = 4$ 而不是 $1 - 0 = 1$。收尾那一行 `limit - prev` 漏写是最常见的 bug。
2. **32 位溢出**：$h = w = 10^9$、只有一条切口时，答案是 $5 \times 10^8 \times 5 \times 10^8 = 2.5 \times 10^{17}$，`int` 必然溢出。必须先转 `long long` 再乘；官方示例全是小数据，本地根本测不出来。
3. **取模的结果不会为 0**：两个间隔都在 $[1, 10^9]$ 内，而 $10^9+7$ 是大于二者的素数，不可能整除乘积，所以返回值必定非零；若跑出 0，说明中间乘积溢出或逻辑写错。
4. **乱序输入**：题目只保证同一数组内元素互不相同，**不保证有序**（示例 2 就是 `[3,1]`），必须排序后再扫描。
5. **重复取模仍要 64 位**：写成 `(a % MOD) * (b % MOD) % MOD` 结果正确，但若把 `a % MOD` 存进 `int` 后再与 `b` 相乘，依然可能在 32 位里溢出，全程 64 位最稳妥。
6. **Python 无溢出**：任意精度整数，直接相乘再 `% MOD` 即可，别漏掉取模。
7. **只有一条切口也算合法边界**：$n = m = 1$ 时每方向只有两条带（如示例 3），算法不需要任何 $n = 0$ 的特判，反而是特判容易写错。

**延伸思考**：

- 若要求返回最大块的**具体位置**（由哪两条切口围成），只需在扫描时多记一个下标，复杂度不变。
- 若要求**最小**面积块，分离性质依然成立：$\min_{i,j} \Delta H_i \Delta W_j = (\min_i \Delta H_i)(\min_j \Delta W_j)$，正数条件下最小值同样可分离。
- 若切口不是贯穿直线，而是一条条任意线段（现实中的切蛋糕），块就不再是网格矩形，最大面积问题会变成平面剖分 + 扫描线的计算几何题。
- 若把「最大的块」换成「第 $k$ 大的块」，可以对两个方向的所有间隔排序后用堆或二分答案求解，分离性质仍然有用。
