# LeetCode 两个盒子中球的颜色数相同的概率 题解

## 1. 题目概述

- **标题 / 题号**：两个盒子中球的颜色数相同的概率（#1467，hard）
- **链接**：https://leetcode.cn/problems/probability-of-a-two-boxes-having-the-same-number-of-distinct-balls/
- **来源**：LeetCode 第 191 场周赛 Q4
- **难度**：困难
- **标签**：数组、数学、动态规划、回溯、组合数学、概率与统计

**题意**：桌面上共有 $2n$ 个球，分属 $k$ 种颜色，`balls[i]` 是颜色 $i$ 的球数。所有球被**均匀随机打乱**，然后前 $n$ 个球放入第一个盒子，后 $n$ 个球放入第二个盒子；两个盒子**可区分**。求「两个盒子里出现的颜色种数恰好相同」的概率。

注意「颜色种数」只看出现了哪些颜色，不看每种颜色有几个；两个盒子交换内容算**不同**的分配。

**约束**：

- $1 \le k = \lvert \text{balls} \rvert \le 8$
- $1 \le \text{balls}[i] \le 6$，故球总数 $2n \le 48$
- $\sum \text{balls}$ 为偶数，保证一定能均分
- 答案与真实值误差在 $10^{-5}$ 内即算正确

## 2. 示例

**示例 1**

```text
输入：balls = [1,1]
输出：1.00000
解释：只有两种均分方式——颜色 1 的球进盒 1、颜色 2 的球进盒 2，或反之。
      两种方式下两盒颜色种数都是 1，概率 = 2/2 = 1。
```

**示例 2**

```text
输入：balls = [2,1,1]
输出：0.66667
解释：球列表为 [1,1,2,3]，随机打乱共 12 种等概率方案，每种 1/12：
      [1,1|2,3], [1,1|3,2], [1,2|1,3], [1,2|3,1], [1,3|1,2], [1,3|2,1],
      [2,1|1,3], [2,1|3,1], [2,3|1,1], [3,1|1,2], [3,1|2,1], [3,2|1,1]
      其中 8 种两盒颜色种数相同，概率 = 8/12 = 0.66667。
```

**示例 3**

```text
输入：balls = [1,2,1,2]
输出：0.60000
解释：球列表为 [1,2,2,3,4,4]，共 180 种随机打乱方案，其中 108 种满足条件，
      概率 = 108/180 = 0.6。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的做法是把「打乱」枚举出来：$2n$ 个球的全排列有 $(2n)!$ 种，但同色球不可区分，等价的样本是「选哪 $n$ 个球进盒 1」，共 $\binom{2n}{n}$ 种。当 $2n = 48$ 时 $\binom{48}{24} \approx 3.2 \times 10^{13}$，逐个枚举必然超时。

退一步想：颜色种数只依赖「每种颜色分别有多少个球进了盒 1」。于是可以对每个颜色枚举 $x_i \in [0, \text{balls}[i]]$，用回溯遍历所有分配向量，状态数 $\prod_i (\text{balls}[i]+1) \le 7^8 \approx 5.8 \times 10^6$。这个量级在剪枝后**可以过**，但每个向量都要算一次多项组合数乘积，常数偏大；而且它把一个天然有重叠子问题的过程写成了枚举。下面把它换成 $O(k^2 n B)$（$B \le 6$ 为单色球数上界）的计数 DP。

### 3.2 核心观察：把「随机打乱」折算成「按颜色的分配向量」

![随机打乱折算成按颜色的分配向量](images/wc191_q4_prob_model.svg)

关键有三点：

1. **样本空间可以换一种描述**。打乱后取前 $n$ 个，等价于「从 $2n$ 个编号球里**均匀随机地**挑 $n$ 个放进盒 1」，样本总数为 $\binom{2n}{n}$。盒内顺序不影响颜色分布，所以这个更粗的样本空间上概率依然是均匀的。
2. **按颜色独立分解**。设颜色 $i$ 有 $x_i$ 个球进盒 1，则从 $b_i = \text{balls}[i]$ 个球里挑 $x_i$ 个的方法数是 $\binom{b_i}{x_i}$，各颜色互不干扰。于是分配向量 $x = (x_1, \dots, x_k)$ 出现的概率为

$$P(x) = \frac{\prod_{i=1}^{k} \binom{b_i}{x_i}}{\binom{2n}{n}}, \qquad \sum_{i=1}^{k} x_i = n$$

3. **判据化成「差值」**。盒 1 的颜色种数是 $\#\{i : x_i > 0\}$，盒 2 的颜色种数是 $\#\{i : x_i < b_i\}$。定义

$$d(x) = \#\{i : x_i > 0\} - \#\{i : x_i < b_i\}$$

则「两盒颜色种数相同」$\iff d(x) = 0$。答案就是所有 $d(x) = 0$ 且 $\sum x_i = n$ 的向量概率之和。

每个颜色对 $d$ 的贡献只有三种取值：$x_i = 0$ 时贡献 $-1$，$0 < x_i < b_i$ 时贡献 $0$，$x_i = b_i$ 时贡献 $+1$。这就是 DP 的转移素材。

### 3.3 算法流程 / 状态转移

![按颜色推进的 DP 状态转移](images/wc191_q4_dp_state.svg)

**状态**：$dp[s][d]$ 表示已处理完前若干个颜色、其中一共 $s$ 个球被分到盒 1、两盒**颜色种数差为 $d - k$** 的方案数。这里下标 $d \in [0, 2k]$ 由真实差值 $[-k, k]$ 平移 $+k$ 得到，于是「差值 0」恰好落在下标 $k$。初值 $dp[0][k] = 1$。

**转移**：枚举下一个颜色 $b = \text{balls}[i]$ 与它分给盒 1 的个数 $x \in [0, b]$，令 $\delta = [x > 0] - [x < b] \in \{-1, 0, 1\}$，则

$$ndp[s + x][\,d + \delta\,] \mathrel{+}= dp[s][d] \cdot \binom{b}{x}$$

**剪枝**：只保留 $s + x \le n$ 的状态（$x_i \ge 0$，一旦超过 $n$ 就再也回不到 $n$）。

**答案**：处理完 $k$ 个颜色后，$\text{answer} = dp[n][k] \big/ \binom{2n}{n}$。

算法的流程图可以概括为：建组合数表 → 初始化 $dp[0][k]=1$ → 对每个颜色做一次「按 $x$ 展开」的卷积式转移 → 取 $dp[n][k]$ 除以 $\binom{2n}{n}$。

### 3.4 示例演算

![balls=[2,1,1] 的分配向量走查](images/wc191_q4_walkthrough.svg)

对 `balls = [2,1,1]`：$2n = 4$，$n = 2$，$\binom{4}{2} = 6$。枚举 $x_1 \in [0,2]$、$x_2, x_3 \in [0,1]$，并要求 $x_1 + x_2 + x_3 = 2$：

| $x_1$ | $x_2$ | $x_3$ | 方案数 $\prod \binom{b_i}{x_i}$ | 盒 1 种数 | 盒 2 种数 | $d$ | 计入 |
|-------|-------|-------|--------------------------------|-----------|-----------|-----|------|
| 0 | 1 | 1 | $1 \cdot 1 \cdot 1 = 1$ | 0 | 3 | $-3$ | 否 |
| 1 | 1 | 0 | $2 \cdot 1 \cdot 1 = 2$ | 2 | 2 | $0$ | **是** |
| 1 | 0 | 1 | $2 \cdot 1 \cdot 1 = 2$ | 2 | 2 | $0$ | **是** |
| 2 | 0 | 0 | $1 \cdot 1 \cdot 1 = 1$ | 1 | 2 | $-1$ | 否 |

合计数（分母）为 $1 + 2 + 2 + 1 = 6 = \binom{4}{2}$，满足 $d = 0$ 的有 $4$ 种，概率 $4/6 = 0.66667$，与示例 2 一致。

分母为什么是 $6$ 而不是题面里的 $12$：题面的 $12 = 4!/(2!\,1!\,1!)$ 数的是**颜色序列**（同色球不可区分），这里的 $6 = \binom{4}{2}$ 数的是「哪 $n$ 个编号球进盒 1」。两种样本空间都把样本均匀铺开，而事件「两盒颜色种数相同」只依赖颜色分布，因此比值一致：$8/12 = 4/6$。**只要分子分母用同一套样本空间，结果就一样**，而 $\binom{2n}{n}$ 的量级安全得多。

## 4. 算法细节

1. **组合数表**：用 Pascal 递推 $\binom{i}{j} = \binom{i-1}{j-1} + \binom{i-1}{j}$ 预处理到 $\binom{2n}{2n}$，即表的大小为 $(2n+1) \times (2n+1)$。上界写成 `total` 而不是 `n`，否则 $\binom{2n}{n}$ 取不到。
2. **一维压平的下标**：`d` 的真实取值范围是 $[-k, k]$，统一加偏移 $k$ 映射到 $0..2k$。处理第 $i$ 个颜色时必有 $\lvert d \rvert \le i$，所以 `d + delta` 一定落在 $[0, 2k]$ 内，无需额外越界判断；但遍历仍按 $0..2k$ 全量走，代码更简单。
3. **剪枝方向**：内层写 `for (int x = 0; x <= b && s + x <= n; x++)`，即「条件不满足立即停」；$x$ 单调递增，一旦 $s + x > n$ 就不存在后续合法的 $x$，所以语义是 `break` 而非 `continue`。
4. **精度**：DP 里存的始终是**整数**（组合数乘积之和），其最大值不超过 $\binom{48}{24} \approx 3.2\times 10^{13}$，远小于 double 能精确表示的整数上界 $2^{53} \approx 9\times 10^{15}$。所以全过程**没有任何舍入误差**，只在最后一步除法产生一次舍入，绝对误差在 $10^{-16}$ 量级，远优于 $10^{-5}$ 的要求。用 `long double` 或 `long long` 也可以。
5. **只累加终态**：答案是 $dp[n][k]$，即「恰好分完 $n$ 个球」且「差值归零」的那一格；不要写成对 $d$ 求和。
6. **对称性自检**：交换两个盒子等价于把所有 $x_i$ 换成 $b_i - x_i$，此时 $s \to 2n - s$、$d \to -d$。所以**不做** $s \le n$ 剪枝的完整 DP 应满足 $dp[s][d+k] = dp[2n-s][k-d]$，可用它快速检查转移是否写对；$dp[n][k]$ 在该变换下不变，说明答案本身确实是对称的。
7. **回溯版等价写法**：用 DFS 遍历 $\prod (b_i+1)$ 个向量，在叶子处判断 $\sum x_i = n$ 与 $d = 0$，累加 $\prod \binom{b_i}{x_i}$。状态数最多约 $5.8\times 10^6$，配合「剩余球数不足以补到 $n$」的剪枝也能通过；DP 版更稳、更短。

## 5. 正确性证明

**引理 1（单向量概率）**：对任意满足 $\sum_i x_i = n$ 的向量 $x$（$0 \le x_i \le b_i$），随机打乱后盒 1 中颜色 $i$ 恰有 $x_i$ 个球的概率为 $\prod_i \binom{b_i}{x_i} \big/ \binom{2n}{n}$。

**证明**：「打乱后取前 $n$ 个」等价于从 $2n$ 个球中均匀选 $n$ 个放入盒 1，样本空间大小 $\binom{2n}{n}$ 且每个样本等概率。盒 1 中颜色 $i$ 恰有 $x_i$ 个，意味着从颜色 $i$ 的 $b_i$ 个球中选出指定的 $x_i$ 个，方法数 $\binom{b_i}{x_i}$；各颜色的选取互相独立，由乘法原理总方法数为 $\prod_i \binom{b_i}{x_i}$。等可能样本中有利样本占比即为所述概率。∎

**引理 2（判据等价）**：两个盒子的颜色种数相同 $\iff d(x) = \#\{i : x_i > 0\} - \#\{i : x_i < b_i\} = 0$。

**证明**：盒 1 含颜色 $i$ 当且仅当 $x_i > 0$，故盒 1 的颜色种数为 $\#\{i : x_i > 0\}$；盒 2 含颜色 $i$ 当且仅当盒 2 分到至少一个该色球，即 $b_i - x_i > 0 \iff x_i < b_i$，故盒 2 的颜色种数为 $\#\{i : x_i < b_i\}$。两者相等即 $d(x) = 0$。∎

**引理 3（DP 无重不漏）**：按颜色顺序做完前 $j$ 个颜色后，$dp[s][d]$ 恰等于「前 $j$ 个颜色共分出 $s$ 个球给盒 1 且颜色种数差为 $d$」的所有部分向量的 $\prod_{i \le j} \binom{b_i}{x_i}$ 之和。

**证明**：对 $j$ 归纳。$j = 0$ 时只有空向量，$s = 0$、$d = 0$，$dp[0][k] = 1$，成立。设对 $j-1$ 成立，考虑第 $j$ 个颜色取 $x$ 个球：任一前 $j$ 个颜色的合法部分向量唯一位于「前 $j-1$ 个颜色的部分向量 + 第 $j$ 个颜色的 $x$」这一分解中，且转移按 $x$ 逐一枚举、互不重复，权重由 $\binom{b_j}{x}$ 相乘累加。因此每个部分向量恰被统计一次，权重正确。剪枝只丢弃 $s > n$ 的状态，而这类状态不可能再通过非负的 $x$ 回到 $s = n$，不影响终态 $dp[n][\cdot]$。∎

**定理**：算法输出的 $dp[n][k] \big/ \binom{2n}{n}$ 等于「两盒颜色种数相同」的概率。

**证明**：由引理 3，$dp[n][k]$ 是所有满足 $\sum_i x_i = n$、$d(x) = 0$ 的向量 $x$ 的 $\prod_i \binom{b_i}{x_i}$ 之和；由引理 2，这些向量恰好对应「两盒颜色种数相同」的事件；由引理 1，每个向量的概率为 $\prod_i \binom{b_i}{x_i} \big/ \binom{2n}{n}$。事件概率等于其中各互斥基本事件概率之和，故所求概率为 $dp[n][k] \big/ \binom{2n}{n}$。∎

## 6. 复杂度分析

- **时间**：$O(k \cdot n \cdot k \cdot B)$，其中 $B = \max_i \text{balls}[i] \le 6$。具体为每个颜色扫一遍 $(n+1)(2k+1)$ 个状态、每状态最多 $B+1$ 个转移；代入 $k \le 8$、$n \le 24$ 约 $2\times 10^4$ 次运算，可忽略。组合数表预处理 $O((2n)^2)$，最大也只要约 $2401$ 次加法。
- **空间**：$O(n \cdot k)$ 存两层 DP 表（滚动数组），外加 $O((2n)^2)$ 的组合数表；实际是几百个 double，常数极小。

## 7. 参考代码

### C++

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    double getProbability(vector<int>& balls) {
        int k = balls.size();
        int total = 0;
        for (int b : balls) total += b;
        int n = total / 2;

        // 组合数表 C[i][j]，i 最大到 2n
        vector<vector<double>> C(total + 1, vector<double>(total + 1, 0.0));
        for (int i = 0; i <= total; i++) {
            C[i][0] = 1.0;
            for (int j = 1; j <= i; j++)
                C[i][j] = C[i - 1][j - 1] + (j <= i - 1 ? C[i - 1][j] : 0.0);
        }

        // dp[s][d]：已给盒1 分配 s 个球，两盒颜色种数差为 d-k 的方案数
        vector<vector<double>> dp(n + 1, vector<double>(2 * k + 1, 0.0));
        dp[0][k] = 1.0;

        for (int b : balls) {
            vector<vector<double>> ndp(n + 1, vector<double>(2 * k + 1, 0.0));
            for (int s = 0; s <= n; s++) {
                for (int d = 0; d <= 2 * k; d++) {
                    double cur = dp[s][d];
                    if (cur == 0.0) continue;
                    for (int x = 0; x <= b && s + x <= n; x++) {
                        // x=0：该色只在盒2 -> 盒2 多一种；x=b：只在盒1 -> 盒1 多一种
                        int nd = d + (x > 0 ? 1 : 0) - (x < b ? 1 : 0);
                        ndp[s + x][nd] += cur * C[b][x];
                    }
                }
            }
            dp.swap(ndp);   // 滚动：上一层已被完全消耗
        }
        return dp[n][k] / C[total][n];
    }
};
```

### Python

```python
from math import comb


class Solution:
    def getProbability(self, balls: list[int]) -> float:
        k = len(balls)
        total = sum(balls)
        n = total // 2

        # dp[s][d + k]：从已处理颜色给盒1 共分 s 个球、颜色种数差为 d 的方案数
        dp = [[0] * (2 * k + 1) for _ in range(n + 1)]
        dp[0][k] = 1

        for b in balls:
            ndp = [[0] * (2 * k + 1) for _ in range(n + 1)]
            for s in range(n + 1):
                row = dp[s]
                for d in range(2 * k + 1):
                    cur = row[d]
                    if cur == 0:
                        continue
                    for x in range(b + 1):
                        if s + x > n:
                            break
                        # x == 0：颜色 b 只在盒2；x == b：只在盒1
                        nd = d + (1 if x > 0 else 0) - (1 if x < b else 0)
                        ndp[s + x][nd] += cur * comb(b, x)
            dp = ndp

        return dp[n][k] / comb(total, n)
```

## 8. 边界情况与易错点

1. **只有一种颜色**（如 `balls = [6]`）：$n = 3$，唯一能落到 $s = n$ 的向量是 $x_1 = 3$，此时 $\delta = (3>0) - (3<6) = 0$，两盒各 1 种颜色，概率为 $1$。若把 $d$ 直接当下标（不偏移 $k$）而不加 `+k`，$x_1 = 0$ 等分支会产生负下标越界，这是 $k = 1$ 时最容易踩的坑。
2. **$x_i$ 取中间值时 $\delta = 0$**：此时该颜色两盒都有，既不加也不减，是唯一「不改变差值」的转移，容易漏写或写成 $+1$。三个分支一定要用 `(x > 0) - (x < b)` 一次算清，别拆成两个 if 造成重复计数。
3. **下标平移遗漏**：初值必须写 `dp[0][k] = 1`（而不是 `dp[0][0]`），答案取 `dp[n][k]`。写成 `dp[0][0]` 等于把「差值为 0」这个零点错放到下标 0 上，任何负差值都会越界。
4. **剪枝用 `break` 而不是 `continue`**：$x$ 单调递增，$s + x > n$ 之后所有更大的 $x$ 都不合法，`break` 才能保证内层是 $O(b)$ 而不是带上无效遍历；C++ 里写成 `x <= b && s + x <= n` 的三段式最稳。
5. **组合数表上界**：分母是 $\binom{2n}{n}$，其中上标为 $2n$；表只开到 $n$ 会越界或读到 0，导致除零得到 `inf`/`nan`。
6. **精度与类型**：不要用 `float`（只有约 7 位有效数字，分子量级 $10^{13}$ 会直接失真）；DP 用 `double`/`long double` 存整数、最后一步做除法即可，绝对不要中途提前除。
7. **分母不要写成排列数**：若用 $(2n)!/(\prod b_i!)$ 当分母，数值可达 $10^{40}$ 量级，double 溢出且必然丢精度；用 $\binom{2n}{n}$ 不但量级安全，还天然把「盒内顺序」约掉了。

**延伸思考**：若问「盒 1 的颜色种数**严格大于**盒 2」的概率，只需把终态从 $dp[n][k]$ 换成 $\sum_{d > k} dp[n][d]$，DP 结构完全不动；若两盒**不可区分**，样本空间减半但判据不变，概率也不变（交换是一个对合双射，保持事件）。若把 `balls[i]` 的量级放大到 $10^5$，逐颜色枚举 $x$ 就不再可行，此时 $\prod_i \binom{b_i}{x_i}$ 关于 $s$ 的卷积可以用生成函数 + NTT 加速，复杂度降到 $O(k n \log n)$。
