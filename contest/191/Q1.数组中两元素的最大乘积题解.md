# LeetCode 数组中两元素的最大乘积 题解

## 1. 题目概述

- **标题 / 题号**：数组中两元素的最大乘积（#1464，easy）
- **链接**：https://leetcode.cn/problems/maximum-product-of-two-elements-in-an-array/
- **来源**：LeetCode 第 191 场周赛 Q1
- **难度**：简单
- **标签**：数组，排序，堆（优先队列）

**题意**：给定一个正整数数组 `nums`，选出两个**不同**的下标 $i \ne j$，返回

$$(\text{nums}[i]-1)\times(\text{nums}[j]-1)$$

的**最大值**。因为 $i$ 与 $j$ 必须不同，即使数组里有两个相等的最大值，也必须占用两个位置。

**约束**：

- $2 \le \text{nums.length} \le 500$
- $1 \le \text{nums}[i] \le 10^{3}$

> 💡 约束里最关键的一条是 $\text{nums}[i] \ge 1$：它保证**每个因子都非负**，于是「乘积最大」退化为「两个因子各自最大」。这条签到题的全部套路就在这一点上。

## 2. 示例

**示例 1**

```text
输入：nums = [3,4,5,2]
输出：12
解释：取 i=1, j=2（下标从 0 开始），(4-1)*(5-1) = 3*4 = 12。
      其余数对中最接近的是 (5,3) 的 4*2 = 8，都更小。
```

**示例 2**

```text
输入：nums = [1,5,4,5]
输出：16
解释：取 i=1, j=3，两个 5 来自不同下标，(5-1)*(5-1) = 4*4 = 16。
      注意不能只取一个 5，题目要求两个不同下标。
```

**示例 3**

```text
输入：nums = [3,7]
输出：12
解释：只有唯一的数对，(3-1)*(7-1) = 2*6 = 12。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有下标对 $(i,j)$（$i<j$），逐个计算乘积取最大：

```text
ans = -inf
for i in 0..n-1:
    for j in i+1..n-1:
        ans = max(ans, (nums[i]-1) * (nums[j]-1))
return ans
```

数对总数 $\frac{n(n-1)}{2}$，$n = 500$ 时约 $1.25\times10^{5}$ 个，时间 $O(n^2)$ 在本题完全跑得动，官方提示给的也正是这种写法。

> ⚠️ 但暴力只是「能过」，不是「会了」：它把每个元素都和所有其他元素配对，完全没有利用「乘积由谁决定」的结构。一旦 $n$ 放宽到 $10^{5}$ 甚至 $10^{6}$，$O(n^2)$ 立刻爆炸。周赛 Q1 的价值恰恰在于**三分钟内看出结构并写出 $O(n)$**。

### 3.2 核心观察：因子非负 ⇒ 只需前两大

![核心观察：两个因子都非负，取最大的两个数](images/wc191_q1_top_two.svg)

把目标写成二元函数 $f(a,b) = (a-1)(b-1)$，其中 $a,b$ 是数组里两个不同位置上的值。约束 $\text{nums}[i] \ge 1$ 给出 $a - 1 \ge 0$、$b - 1 \ge 0$，于是：

- **因子非负 ⇒ 关于每个因子单调不减**：固定 $b$，函数 $f(\cdot,b)$ 在 $a \ge 1$ 上单调不减；对 $b$ 同理。
- **单调 ⇒ 最优解必由最大、次大贡献**：设数组最大值 $m_1$、次大值 $m_2$（按多重集合计，两者可以相等，只要是两个不同位置）。任取一对值，把它「抬」到 $(m_1,m_2)$ 只会让乘积变大：

$$\max_{i \ne j}\ (\text{nums}[i]-1)(\text{nums}[j]-1) = (m_1-1)(m_2-1)$$

于是问题被彻底改写为：**一趟扫描求数组的最大值与次大值**。不需要排序，不需要枚举数对。

> 💡 **一句话**：非负因子让「乘积最大」变成「两个因子各自最大」，于是 $O(n^2)$ 枚举 → $O(n)$ 求前两大。这是「最值驱动」最朴素的一次降维。

> ⚠️ 若元素允许为负（例如 [LeetCode 628. 三个数的最大乘积](https://leetcode.cn/problems/maximum-product-of-three-numbers/) 的场景），减 1 后因子可负，单调性失效，最大乘积可能来自「两最小 × 一最大」。本题的 $\ge 1$ 是推导的**前提**，读题时必须确认范围。

### 3.3 算法流程

![算法流程：一趟扫描维护前两大](images/wc191_q1_scan_flow.svg)

维护两个变量，始终保证 $\text{mx1} \ge \text{mx2}$，依次扫描每个 $x = \text{nums}[k]$：

1. 初始化 `mx1 = mx2 = -1`（哨兵，小于任何 $\text{nums}[i]$）；
2. 若 $x \ge \text{mx1}$：出现新的最大值，**旧最大值降级为次大**，即 `mx2 = mx1; mx1 = x`；
3. 否则若 $x > \text{mx2}$：最大值不变，只把次大值抬高，即 `mx2 = x`；
4. 否则跳过，`mx1`、`mx2` 都不动；
5. 扫描结束返回 $(\text{mx1}-1)\times(\text{mx2}-1)$。

降级这一步是整段代码的灵魂：新最大值出现时，被挤下的旧 `mx1` 必然大于此前所有元素，它天然就是新的次大值，**不需要再和 `mx2` 比较**。

### 3.4 示例演算

以示例 2 `nums = [1,5,4,5]` 为例（比示例 1 更能暴露并列最大值的处理）：

![示例演算：nums = [1, 5, 4, 5]](images/wc191_q1_walkthrough.svg)

| 步 | $x$ | 判断 | `mx1` | `mx2` | 说明 |
|----|-----|------|-------|-------|------|
| $i=0$ | 1 | $x \ge \text{mx1}$ | 1 | −1 | 首元素成为最大，次大仍是哨兵 |
| $i=1$ | 5 | $x \ge \text{mx1}$ | 5 | 1 | 新最大，旧最大 1 降级为次大 |
| $i=2$ | 4 | $x > \text{mx2}$ | 5 | 4 | 最大值不变，次大抬到 4 |
| $i=3$ | 5 | $x \ge \text{mx1}$ | 5 | 5 | 并列最大：旧最大 5 降级为次大 |

最终 $(\text{mx1},\text{mx2}) = (5,5)$，对应下标 $1$ 与 $3$，答案 $(5-1)(5-1)=16$。

再走查示例 1 `[3,4,5,2]`：`3` → `(3,−1)`；`4` → `(4,3)`；`5` → `(5,4)`；`2` 既不 $\ge 5$ 也不 $> 4$，跳过。答案 $(5-1)(4-1)=12$，与官方输出一致。

## 4. 算法细节

1. **哨兵取值**：哨兵必须**不大于数组最小元素**，本题 $\text{nums}[i] \ge 1$，取 $-1$（或 `INT_MIN`）皆可，首元素必然走降级分支。若数据允许负数，就必须换成 `INT_MIN`，否则哨兵会「冒充」成最大值，答案直接错。
2. **先降级再更新**：`mx2 = mx1; mx1 = x` 两行的**顺序不能反**。反写成 `mx1 = x; mx2 = mx1` 会把刚写入的新最大值复制进 `mx2`，真正的次大（旧 `mx1`）被覆盖丢失。
3. **`≥` 与 `>` 都能对，但语义不同**：写 `x >= mx1` 时并列最大值也走降级分支，`mx2` 自动获得同样的值（如 `[1,5,4,5]` 的第二个 5）；写 `x > mx1` 时并列值落入 `else if (x > mx2)` 分支，结果相同。前者把「并列」统一进「降级」语义，代码更短，建议采用。
4. **`else if` 不可写成两个独立 `if`**：若第一个分支已经执行（`mx1 = x`），第二个条件 `x > mx2` 可能再次成立，从而把同一个 $x$ 同时写进 `mx1` 和 `mx2`——这就违反了「两个下标必须不同」的要求。
5. **替代写法**：排序后取末两位 `(nums[n-1]-1)*(nums[n-2]-1)`，$O(n\log n)$、$O(\log n)$ 栈空间；或用大小为 2 的小顶堆，$O(n\log 2)=O(n)$ 但常数更大。$n \le 500$ 时都能过，一趟扫描法最优。
6. **值域计数**：$\text{nums}[i] \le 10^{3}$，也能开一个长度 $1001$ 的桶从大到小找前两个非空桶，$O(n + V)$；这是「值域小」时的另一条路，但没必要。
7. **返回值类型**：最大值为 $(10^{3}-1)^2 = 998001$，远小于 $2^{31}-1$，`int` 足够；若题目把 $\text{nums}[i]$ 放大到 $10^{9}$ 级别，乘积会溢出 32 位，需改用 `long long`。

## 5. 正确性证明

**引理 1（单调性）**：对任意 $a, b \ge 1$ 与 $c \le b$，有 $f(a,b) \ge f(a,c)$；对 $c \le a$，有 $f(a,b) \ge f(c,b)$。

**证明**：由 $f(a,b) - f(a,c) = (a-1)(b-c)$，其中 $a - 1 \ge 0$、$b - c \ge 0$，故差非负。同理 $f(a,b) - f(c,b) = (a-c)(b-1) \ge 0$。∎

**引理 2（前两大是上界）**：设 $m_1 \ge m_2$ 分别是 `nums` 的最大值与次大值（取自两个不同下标），则对任意 $i \ne j$ 都有 $f(\text{nums}[i], \text{nums}[j]) \le f(m_1, m_2)$。

**证明**：任取一对下标，把两个值记为 $a, b$ 且不妨 $a \ge b$。

- 因为 $a$ 是数组中某个元素，$a \le m_1$。
- 因为 $b$ 是数组中**除 $a$ 所在位置之外**的某个元素，而 $m_2$ 是「去掉一个 $m_1$ 后剩余元素的最大值」，故 $b \le m_2$。

由引理 1 连续使用两次单调性：$f(a,b) \le f(m_1,b) \le f(m_1,m_2)$。∎

**引理 3（扫描不变式）**：扫描完前 $k$ 个元素后，`mx1`、`mx2` 恰为这 $k$ 个元素的最大值与次大值（$k = 0$ 时二者为哨兵 $-1$，视为 $-\infty$）。

**证明**：对 $k$ 归纳。$k=0$ 时成立（哨兵不超过任何元素，等价于空集）。设前 $k$ 个元素处理后不变式成立，处理 $x = \text{nums}[k]$：

- 若 $x \ge \text{mx1}$：新集合的最大值显然是 $x$；次大值则是旧最大值（旧 `mx1` 不小于前 $k$ 个元素的任何值），代码正是 `mx2 = mx1; mx1 = x`。
- 若 $x < \text{mx1}$：最大值仍是 `mx1`；次大值变为 $\max(\text{旧 mx2}, x)$，代码的 `else if (x > mx2) mx2 = x` 恰好实现这一取大。

两种情形都保持不变式。∎

**定理**：算法返回值等于 $\max_{i \ne j} f(\text{nums}[i], \text{nums}[j])$。

**证明**：由引理 3，扫描结束时 `mx1 = m1`、`mx2 = m2`，算法返回 $f(m_1,m_2)$。由引理 2 它是所有数对的上界，而取到 $m_1$、$m_2$ 的两个下标不同、构成合法数对，故该上界可达，即为最大值。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。每个元素至多触发两次比较与两次赋值，均为 $O(1)$ 操作，总代价 $\Theta(n)$；这是本题的理论下界（至少要读一遍输入）。
- **空间复杂度**：$O(1)$。只使用 `mx1`、`mx2` 两个整型变量与循环变量，与 $n$ 无关。
- **对比**：排序法 $O(n\log n)$ 时间、$O(\log n)$ 栈空间；小顶堆 $O(n\log 2)=O(n)$ 时间、$O(1)$ 空间但常数更大；暴力 $O(n^2)$ 时间、$O(1)$ 空间。题目 $n \le 500$，四者均可通过，但只有前两大法对 $n \le 10^{6}$ 也依然稳健。

## 7. 参考代码

### C++

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    int maxProduct(vector<int>& nums) {
        int mx1 = -1, mx2 = -1;      // 最大值、次大值（哨兵小于任何 nums[i]）
        for (int x : nums) {
            if (x >= mx1) {         // 新的最大值出现：旧最大值降级为次大
                mx2 = mx1;
                mx1 = x;
            } else if (x > mx2) {   // 只抬高次大值
                mx2 = x;
            }
        }
        return (mx1 - 1) * (mx2 - 1);
    }
};
```

### Python

```python
from typing import List

class Solution:
    def maxProduct(self, nums: List[int]) -> int:
        mx1 = mx2 = -1              # 最大值、次大值
        for x in nums:
            if x >= mx1:            # 新最大：旧最大降级为次大
                mx2, mx1 = mx1, x
            elif x > mx2:           # 只更新次大
                mx2 = x
        return (mx1 - 1) * (mx2 - 1)
```

> 💡 Python 里 `mx2, mx1 = mx1, x` 一步完成降级与更新，天然避免了「顺序写反」的坑。

## 8. 边界情况与易错点

1. **$n = 2$**：只有唯一数对 $(0,1)$，算法第一轮 `mx1 = nums[0]`、`mx2` 为哨兵，第二轮 `x >= mx1` 或 `x > mx2` 必成立，最终两值都填入，结果正确。
2. **并列最大值**：`[1,5,4,5]` 中两个 5 值相等但下标不同，是合法数对（返回 16）。若误判成「只能取一个 5、另一个必须是 4」，会得到 12。
3. **`nums[i] = 1`**：因子为 0，乘积也是 0；全 1 数组 `[1,1]` 的答案是 $(1-1)(1-1)=0$。不要用 0 作为答案初值再 `max`（本题下界恰好是 0，容易掩盖「没更新」的 bug），更稳妥的是直接用两个哨兵算出结果。
4. **哨兵方向搞反**：用 `INT_MAX` 这类大哨兵时，首元素进不了降级分支，`mx2` 会一直停在 `INT_MAX`，答案荒谬；本题应取 $-1$ 或 `INT_MIN`。
5. **两个独立 `if` 的陷阱**：`if (x >= mx1) {...} if (x > mx2) {...}` 会让同一个元素同时占用两个槽位，对 `[3,7]` 会算出 $(7-1)(7-1)=36$ 这种非法答案。
6. **降级顺序**：`mx2 = mx1` 必须在 `mx1 = x` 之前；反过来写会丢掉真正的次大值。
7. **返回类型与溢出**：$(10^{3}-1)^{2}$ 在 `int` 内安全；若数据范围放大，先转 `long long` 再乘。
