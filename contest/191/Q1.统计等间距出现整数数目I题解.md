# LeetCode 统计等间距出现整数数目 I 题解

## 1. 题目概述

- **标题 / 题号**：统计等间距出现整数数目 I（#4048，easy）
- **链接**：https://leetcode.cn/problems/count-values-with-equally-spaced-occurrences-i/
- **来源**：LeetCode 第 191 场双周赛 Q1
- **难度**：简单
- **标签**：数组、哈希表

**题意**：给定整数数组 `nums`。整数 $x$ 称为**特别**的，当且仅当：

1. $x$ 在 `nums` 中**恰好出现三次**；
2. 这三次出现的下标 $i_1 < i_2 < i_3$ 满足 $i_2 - i_1 = i_3 - i_2$，即三个下标**等间距**（构成等差数列）。

返回 `nums` 中**不同**特别整数的数量。

**约束**：

- $3 \le nums.length \le 100$
- $1 \le nums[i] \le 100$

## 2. 示例

**示例 1**

```text
输入：nums = [1,8,1,5,1,5,8,5]
输出：2
解释：1 出现于下标 0、2、4，等间距 ✓；5 出现于下标 3、5、7，等间距 ✓；
     8 只出现两次。特别整数共有 2 个（1 和 5）。
```

**示例 2**

```text
输入：nums = [8,8,8,8]
输出：0
解释：8 出现了 4 次，不满足「恰好三次」，直接淘汰。
```

**示例 3**

```text
输入：nums = [8,6,6,8,8]
输出：0
解释：8 出现于下标 0、3、4，间隔为 3 和 1，不等间距；6 只出现两次。
```

## 3. 解题思路

### 3.1 暴力思路

值域 $[1,100]$、长度 $\le 100$，最朴素的写法：枚举每个候选值 $x \in [1,100]$，再扫一遍 `nums` 收集 $x$ 的全部下标，判定次数与间距，总复杂度 $O(100 \cdot n)$ 也能过。但对每个候选值重复扫数组完全没必要——一遍顺序遍历就能把**所有值**的下标同时收集齐。

### 3.2 核心观察：按值分组 + 两次 O(1) 判定

![等间距出现：按值收集下标，再做两次 O(1) 判定](images/bw191_q1_index_groups.svg)

- **分组**：用哈希表 `pos` 维护「值 → 出现下标列表」。从左到右扫描并追加，每个 `pos[x]` **天然严格递增**，无需排序。
- **判定一（次数）**：$\lvert \text{pos}[x] \rvert = 3$。注意是**恰好**三次——出现 4 次及以上同样一票否决。
- **判定二（间距）**：三个下标等间距 $\iff i_2$ 是 $i_1, i_3$ 的**等差中项**：

$$i_2 - i_1 = i_3 - i_2 \iff 2 \cdot i_2 = i_1 + i_3$$

两个判定均为 O(1)，每个不同的值只检查一次，天然去重。

### 3.3 算法流程

![算法流程：哈希分组 + 两次 O(1) 判定](images/bw191_q1_algorithm_flow.svg)

```text
1. pos = 空哈希表
2. for i = 0 .. n-1:        pos[nums[i]] 追加 i
3. ans = 0
4. for (x, p) in pos:
       若 len(p) == 3 且 2*p[1] == p[0] + p[2]:    ans += 1
5. 返回 ans
```

### 3.4 示例演算

![示例演算：一张表覆盖三类判定结果](images/bw191_q1_example_walkthrough.svg)

对示例 1 的 `nums = [1,8,1,5,1,5,8,5]`：

| 值 x | pos[x] | 恰好 3 次？ | 等差？ | 结论 |
|------|--------|------------|--------|------|
| 1 | [0, 2, 4] | ✓ | 2−0 = 4−2 = 2 ✓ | 特别 |
| 8 | [1, 6] | ✗（2 次） | — | 淘汰 |
| 5 | [3, 5, 7] | ✓ | 5−3 = 7−5 = 2 ✓ | 特别 |

答案为 2。示例 2、3 的两个反例分别踩中「次数超过 3」与「次数恰好但下标不等差」两类陷阱（见上图）。

## 4. 算法细节

1. **数据结构**：C++ 用 `unordered_map<int, vector<int>>`，Python 用 `defaultdict(list)`。值域 $\le 100$ 时也可开 `vector<vector<int>> pos(101)` 桶数组，但哈希表写法可直接迁移到 II 版的大值域。
2. **下标无需排序**：遍历顺序保证 `pos[x]` 递增，`p[0] < p[1] < p[2]` 恰为 $x$ 的全部三次出现。
3. **判定顺序**：先判 `len(p) == 3`，再访问 `p[2]`，避免列表长度为 1/2 时越界（C++）或抛异常（Python）。
4. **中点条件**：`2 * p[1] == p[0] + p[2]` 与 `p[1] - p[0] == p[2] - p[1]` 完全等价，前者一次乘加即可，且不易写反减法顺序。
5. **去重免费**：按哈希表的键遍历，每个不同整数天然只统计一次，无需额外集合。

## 5. 正确性证明

**引理 1（有序性）**：按下标递增顺序遍历并追加，每个 `pos[x]` 严格递增。

**证明**：设 $x$ 在 `nums` 中出现的下标依次为 $j_1 < j_2 < \cdots < j_m$（下标互不相同）。只有遍历到 $j_k$ 时才会追加 $j_k$，故 `pos[x]` 恰为 $[j_1, j_2, \cdots, j_m]$，严格递增。∎

**引理 2（判定等价）**：$x$ 特别 $\iff \lvert \text{pos}[x] \rvert = 3$ 且 $2 \cdot \text{pos}[x][1] = \text{pos}[x][0] + \text{pos}[x][2]$。

**证明**：由引理 1，`pos[x]` 按升序记录 $x$ 的全部出现位置。「恰好出现三次」即 $\lvert \text{pos}[x] \rvert = 3$；「等间距」即 $j_2 - j_1 = j_3 - j_2$，移项得 $2 j_2 = j_1 + j_3$，正是中点条件。二者皆为对定义的直接转写。∎

**定理**：算法返回值等于 `nums` 中不同特别整数的个数。

**证明**：哈希表的键集合恰为 `nums` 中出现的全部不同值，每个键被检查恰好一次；由引理 2，检查条件与「特别」定义等价。故 `ans` 恰好对每个特别整数计数一次，不多不少。∎

## 6. 复杂度分析

- **时间**：$O(n)$。建表一遍扫描 $O(n)$；随后每个不同值做 $O(1)$ 判定，不同值个数不超过 $n$，合计仍为 $O(n)$。
- **空间**：$O(n)$。哈希表共存储 $n$ 个下标，键数不超过 $\min(n, 100)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int countSpecialIntegers(vector<int>& nums) {
        unordered_map<int, vector<int>> pos;
        for (int i = 0; i < (int)nums.size(); i++) {
            pos[nums[i]].push_back(i);
        }
        int ans = 0;
        for (auto& [x, p] : pos) {
            if (p.size() == 3 && 2 * p[1] == p[0] + p[2]) {
                ans++;
            }
        }
        return ans;
    }
};
```

### Python

```python
from collections import defaultdict

class Solution:
    def countSpecialIntegers(self, nums: list[int]) -> int:
        pos = defaultdict(list)
        for i, x in enumerate(nums):
            pos[x].append(i)
        return sum(
            1
            for p in pos.values()
            if len(p) == 3 and 2 * p[1] == p[0] + p[2]
        )
```

## 8. 边界情况与易错点

1. **「恰好三次」不是「至少三次」**：出现 4 次及以上的值直接淘汰（示例 2 的 `[8,8,8,8]`），这是本题最常见的 WA 点，也是与同场 Q2（II 版）题意的关键差异。
2. **次数判定在前**：`len(p) != 3` 时不能访问 `p[2]`，否则长度不足的列表会越界（C++）或抛 `IndexError`（Python）。
3. **次数对但间距不对**：如示例 3 的 8（下标 0、3、4，间隔 3 与 1），两个条件是**独立的一票否决**，缺一不可。
4. **别被小值域带偏**：$1 \le nums[i] \le 100$ 允许开桶数组，但哈希表写法可无缝迁移到 II 版的 $10^9$ 值域。
5. **无需排序**：按扫描顺序追加即有序；先收集再排序是多余的 $O(D \log D)$。
6. **去重免费**：按哈希表的键遍历，同值只判一次，不会重复计数。
