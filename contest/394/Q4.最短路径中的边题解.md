# LeetCode 最短路径中的边 题解

## 1. 题目概述

- **标题 / 题号**：最短路径中的边（#3123，hard）
- **链接**：https://leetcode.cn/problems/find-edges-in-shortest-paths/
- **来源**：LeetCode 第 394 场周赛 Q4
- **难度**：困难
- **标签**：图、最短路、Dijkstra、堆（优先队列）、广度优先搜索

**题意**：给定一个 $n$ 个节点的**无向带权图**（节点编号 $0 \sim n-1$，共 $m$ 条边），`edges[i] = [a_i, b_i, w_i]` 表示 $a_i$、$b_i$ 之间有一条权为 $w_i$ 的边。对于**所有**从节点 $0$ 出发、到节点 $n-1$ 结束的最短路，返回长度为 $m$ 的布尔数组 `answer`：若 `edges[i]` **至少**出现在其中一条最短路上，则 `answer[i]` 为 `true`，否则为 `false`。

**约束**：

- $2 \le n \le 5 \times 10^4$
- $m = \text{edges.length}$，$1 \le m \le \min(5 \times 10^4,\ n(n-1)/2)$
- $0 \le a_i, b_i < n$，$a_i \ne b_i$
- $1 \le w_i \le 10^5$
- 图中没有重边，且**图可能不连通**

> ⚠️ 三个易漏点：一是最短路的**条数**可能是指数级的，「枚举每条最短路再标记边」走不通；二是路径总长上界 $(n-1) \times w_{\max} \approx 5 \times 10^9$，超出 32 位整数范围，C++ 必须用 `long long`；三是图可能不连通，$0$ 到 $n-1$ 不通时不存在任何最短路，`answer` 应全为 `false`。

## 2. 示例

**示例 1**

```text
输入：n = 6, edges = [[0,1,4],[0,2,1],[1,3,2],[1,4,3],[1,5,1],[2,3,1],[3,5,3],[4,5,2]]
输出：[true,true,true,false,true,true,true,false]

解释：节点 0 出发到达节点 5 的所有最短路（总长均为 5）：
      0→1→5（4+1）
      0→2→3→5（1+1+3）
      0→2→3→1→5（1+1+2+1）
      边 [1,4,3] 与 [4,5,2] 不在任何一条最短路上。
```

**示例 2**

```text
输入：n = 4, edges = [[2,0,1],[0,1,1],[0,3,4],[3,2,2]]
输出：[true,false,false,true]

解释：唯一的最短路是 0→2→3（1+2=3），只用到边 [2,0,1] 与 [3,2,2]。
```

**示例 3（不连通）**

```text
输入：n = 4, edges = [[0,1,5],[2,3,7]]
输出：[false,false]

解释：图分成 {0,1} 与 {2,3} 两个连通分量，节点 0 到节点 3 不连通，
      不存在任何最短路，全部 false。
```

## 3. 解题思路

### 3.1 暴力思路

- **删边验证**：对每条边，暂时删掉它重跑一遍 Dijkstra，看 $0 \to n-1$ 的距离是否变大或不可达——$m$ 次完整最短路，$O(m \cdot (n+m)\log n) \approx 2.5 \times 10^{10}$ 次操作，必然超时。
- **枚举最短路**：从 $0$ 出发 DFS 收集所有总长为 $D$ 的路径——条数可达指数级（想象一张分层图，每层二选一都能拼出最短路），既存不下也数不完。

两条暴力路的共同盲区：它们都把「每条边」当成独立问题从头算一遍最短路。而「$0$ 到每个点的距离」本是可以**一次预处理、处处查询**的全局信息——这正是下面的切入点。

### 3.2 核心观察：双向 Dijkstra + 三段拼接判定

![核心概念：三段拼接判定](images/shortest_path_edges_dual_dijkstra.svg)

设 $d_0[\cdot]$ 为从 $0$ 出发的单源最短路（一遍 Dijkstra），$d_1[\cdot]$ 为从 $n-1$ 出发的单源最短路（无向图中等价于「到 $n-1$ 的距离」，再跑一遍即可），$D = d_0[n-1]$ 为全程最短距离。

**观察 1（经过 $e$ 的路径有三段下界）**：若边 $e=(a,b,w)$ 以 $a \to b$ 方向出现在某条 $0 \to n-1$ 的路径上，这条路径被 $e$ 切成三段：$0 \to a$ 的前段、边 $e$、$b \to n-1$ 的后段。前段长度 $\ge d_0[a]$，后段长度 $\ge d_1[b]$，于是

$$\text{路径总长} \ \ge\ d_0[a] + w + d_1[b]$$

**观察 2（拼接通道给出上界）**：反过来，把「$0 \to a$ 的最短路 + 边 $e$ + $b \to n-1$ 的最短路」首尾相接，得到一条 $0$ 到 $n-1$ 的**通道**（允许重复经过点的 walk），长度恰为 $d_0[a]+w+d_1[b]$；而任何通道的长度都 $\ge D$，所以 $d_0[a]+w+d_1[b] \ge D$ **恒成立**——这个和只可能「恰好等于 $D$」或「严格大于 $D$」。

**观察 3（等值 ⟹ 真最短路）**：若拼接和恰为 $D$，则该通道**无环**——否则删掉一个权为正的环会得到更短的通道，与 $D$ 最小矛盾——因此它是一条货真价实的最短路，$e$ 正好在其中。正权在这里干了双份活：既保证 Dijkstra 正确，又保证「等值通道」无环。

**观察 4（无向边正反各判一次）**：$e$ 也可能以 $b \to a$ 方向被经过，最终判定为

$$\text{answer}[i] = \big(d_0[a]+w+d_1[b] = D\big)\ \lor\ \big(d_0[b]+w+d_1[a] = D\big)$$

一句话：**两遍 Dijkstra 把「这条边在不在最短路上」从一次全程计算压缩成一次 $O(1)$ 的加法比较**——与前缀和「一次预处理、区间 $O(1)$ 查询」是同一类「预处理换查询」思想。

### 3.3 算法流程

![算法流程图](images/shortest_path_edges_flow.svg)

1. 建邻接表，无向边 $(a,b,w)$ 在 $a$、$b$ 的表里各挂一条；
2. 分别以 $0$ 和 $n-1$ 为源跑两遍堆优化 Dijkstra，得 $d_0$、$d_1$；
3. 取 $D = d_0[n-1]$，若 $D = \infty$（不连通）直接返回全 `false`；
4. 逐边套用观察 4 的公式，$O(1)$ 定真假；
5. 返回 `answer`。

### 3.4 示例演算

![示例演算：逐边三段拼接判定](images/shortest_path_edges_example.svg)

以示例 1 为例：$d_0 = [0,4,1,2,7,5]$，$d_1 = [5,1,4,3,2,0]$，$D = 5$。看点有三：

- **e₂ = [1,3,2]**：正向 $4+2+3=9$ 落空，反向 $2+2+1=5$ 命中——对应最短路 $0\to2\to3\to1\to5$，**反向判定不可省**；
- **e₃ = [1,4,3] 与 e₇ = [4,5,2]**：两个方向的最优拼接是 9 和 11，都拼不出 5——节点 4 距离两端太「亏」（$d_0[4]+d_1[4] = 9 > 5$），挂在它身上的边全军覆没；
- 其余 5 条边都能恰好拼出 5，与三条最短路覆盖的边集完全吻合。

示例 2 同法：$d_0 = [0,1,1,3]$，$d_1 = [3,4,2,0]$，$D=3$，仅 e0（$0+1+2=3$）与 e3（$1+2+0=3$）判真。

## 4. 算法细节

1. **邻接表**：`g[a]` 挂 `(b, w)`、`g[b]` 挂 `(a, w)`，两遍 Dijkstra 共用一张表（无向图对称性）。
2. **堆优化 Dijkstra**：小根堆存 `(距离, 节点)`，弹出时若 `d > dist[u]` 说明是**过期记录**（懒删除），直接跳过；每条边至多入堆一次，单遍复杂度 $O((n+m)\log n)$。
3. **INF 哨兵**：C++ 取 `LLONG_MAX/4`——即使 $\infty + w + \infty$ 相加也不溢出，且结果必然远大于 $D$，自动判 `false`，无需对不可达端点逐项特判；Python 用 `float('inf')` 天然安全。
4. **不连通特判**：`D == INF` 时提前返回全 `false`。无向图连通性对称：一条边的两个端点要么都在 $0$ 的连通分量里（$d_0, d_1$ 都有限），要么都在别的分量里，不存在「一端可达一端不可达」的边。
5. **判定循环**：直接按下标遍历 `edges`，对每条边做两次「加两次、比一次」，与答案下标一一对应，不会串位。

## 5. 正确性证明

**引理 1（三段下界）**：设 $P$ 是任意一条从 $0$ 到 $n-1$、且以 $a \to b$ 方向经过边 $e=(a,b,w)$ 的**路径**，则 $\mathrm{len}(P) \ge d_0[a] + w + d_1[b]$。

**证明**：把 $P$ 在边 $e$ 处切开，得到前段 $P_1$（$0 \to a$）、边 $e$、后段 $P_2$（$b \to n-1$）。$P_1$ 是 $0 \to a$ 的一条路径，长度 $\ge d_0[a]$；$P_2$ 是 $b \to n-1$ 的一条路径，长度 $\ge d_1[b]$。三部分相加即得。∎

**引理 2（拼接和不小于 $D$）**：对图中任意边 $e=(a,b,w)$，恒有 $d_0[a] + w + d_1[b] \ge D$。

**证明**：把「$0 \to a$ 的最短路 + 边 $e$ + $b \to n-1$ 的最短路」首尾相接，得到一条 $0 \to n-1$ 的通道 $W$，$\mathrm{len}(W) = d_0[a] + w + d_1[b]$。任何通道删去重复经过的点后可提炼出一条 $0 \to n-1$ 的简单路径，长度不增，而简单路径长度 $\ge D$，故 $\mathrm{len}(W) \ge D$。∎

**引理 3（等值通道无环）**：若一条 $0 \to n-1$ 的通道长度恰为 $D$，则它是一条简单路径（无重复节点）。

**证明**：反设通道重复经过某节点，则它含一个环；边权全为正数，环权 $> 0$，删去该环得到长度 $< D$ 的通道，再引理 2 同法提炼出长度 $< D$ 的简单路径，与 $D$ 是最短距离矛盾。∎

**定理（判定准则）**：边 $e=(a,b,w)$ 以 $a \to b$ 方向出现在某条最短路上 $\iff d_0[a] + w + d_1[b] = D$。

**证明**：

- **必要性**：设最短路 $P$ 以 $a \to b$ 方向经过 $e$，则 $\mathrm{len}(P) = D$。由引理 1，$D \ge d_0[a] + w + d_1[b]$；由引理 2，$d_0[a] + w + d_1[b] \ge D$。两者夹逼，得 $d_0[a] + w + d_1[b] = D$。
- **充分性**：设 $d_0[a] + w + d_1[b] = D$。取「$0 \to a$ 最短路 + 边 $e$ + $b \to n-1$ 最短路」拼成的通道 $W$，由引理 3，$W$ 无环，是一条简单路径且长度为 $D$，即 $e$ 确实出现在一条最短路上。∎

**推论**：无向边可能被正向或反向经过，结合两个方向得

$$\text{answer}[i] = \big(d_0[a]+w+d_1[b]=D\big) \lor \big(d_0[b]+w+d_1[a]=D\big)$$

由定理，两个方向任一取等即「$e$ 在某条最短路上」，否则两边都严格大于 $D$、不在任何最短路上。∎

## 6. 复杂度分析

- **时间复杂度**：$O((n+m)\log n)$。主体是两遍堆优化 Dijkstra，各 $O((n+m)\log n)$；逐边判定仅 $m$ 次加法与比较，$O(m)$。$n, m \le 5\times10^4$，轻松通过。
- **空间复杂度**：$O(n+m)$。邻接表 $O(n+m)$，两个距离数组 $O(n)$，堆中至多 $O(m)$ 个记录。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    vector<bool> findAnswer(int n, vector<vector<int>>& edges) {
        int m = edges.size();
        vector<vector<pair<int, int>>> g(n);
        for (auto& e : edges) {              // 无向边双向入表
            g[e[0]].push_back({e[1], e[2]});
            g[e[1]].push_back({e[0], e[2]});
        }

        const long long INF = LLONG_MAX / 4; // 路径和上界 ~5e9，必须 64 位
        auto dijkstra = [&](int s) {
            vector<long long> dist(n, INF);
            priority_queue<pair<long long, int>,
                           vector<pair<long long, int>>, greater<>> pq;
            dist[s] = 0;
            pq.push({0, s});
            while (!pq.empty()) {
                auto [d, u] = pq.top();
                pq.pop();
                if (d > dist[u]) continue;   // 懒删除：过期记录
                for (auto [v, w] : g[u]) {
                    if (d + w < dist[v]) {
                        dist[v] = d + w;
                        pq.push({dist[v], v});
                    }
                }
            }
            return dist;
        };

        vector<long long> d0 = dijkstra(0);      // 0 出发
        vector<long long> d1 = dijkstra(n - 1);   // n-1 出发
        long long D = d0[n - 1];

        vector<bool> ans(m, false);
        if (D == INF) return ans;             // 不连通：无最短路，全 false
        for (int i = 0; i < m; i++) {
            int a = edges[i][0], b = edges[i][1];
            long long w = edges[i][2];
            ans[i] = d0[a] + w + d1[b] == D || d0[b] + w + d1[a] == D;
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def findAnswer(self, n: int, edges: List[List[int]]) -> List[bool]:
        g = [[] for _ in range(n)]
        for u, v, w in edges:                # 无向边双向入表
            g[u].append((v, w))
            g[v].append((u, w))

        INF = float('inf')

        def dijkstra(s: int) -> List[int]:
            dist = [INF] * n
            dist[s] = 0
            pq = [(0, s)]                     # 小根堆：(距离, 节点)
            while pq:
                d, u = heapq.heappop(pq)
                if d > dist[u]:              # 懒删除：过期记录
                    continue
                for v, w in g[u]:
                    if d + w < dist[v]:
                        dist[v] = d + w
                        heapq.heappush(pq, (dist[v], v))
            return dist

        d0 = dijkstra(0)                     # 0 出发
        d1 = dijkstra(n - 1)                 # n-1 出发
        D = d0[n - 1]

        if D == INF:                         # 不连通：无最短路
            return [False] * len(edges)
        return [d0[a] + w + d1[b] == D or d0[b] + w + d1[a] == D
                for a, b, w in edges]
```

## 8. 边界情况与易错点

1. **图不连通**：$D = \infty$ 时不存在任何最短路，直接返回全 `false`，千万别拿 $\infty$ 参与判定后误判相等（Python 中 `inf == inf` 为 `True`，若恰好两边都不可达会错判，所以先特判最稳）。
2. **整数溢出**：路径总长上界约 $(n-1) \times 10^5 \approx 5 \times 10^9$，超出 `int`；C++ 距离、$D$、拼接和都必须用 `long long`。
3. **INF 哨兵的选取**：取 `LLONG_MAX/4` 保证 $\infty + w + \infty$ 不溢出；且不可达端点的拼接和必然 $\ne D$，无需逐项特判。取 `LLONG_MAX` 或 `INT_MAX` 都会溢出出错。
4. **无向边两个方向都要判**：示例 1 的 e₂ 正向拼出 9、反向才拼出 5，漏判反向就漏掉最短路 $0\to2\to3\to1\to5$。
5. **懒删除**：堆里允许残留过期记录，弹出时用 `d > dist[u]` 跳过即可；不要试图在入堆时删除旧记录（朴素 Dijkstra 用 `st` 数组标记亦可，但懒删除写法最省事）。
6. **答案下标对齐**：判定时按 `edges` 的原始下标遍历，不要在排序/去重后打乱对应关系。
7. **$n = 2$**：起点终点直接相邻，$D$ 就是两点间边权，该边（若存在多条更短绕路则可能不选它）由公式自动判定，无需特判。

**延伸思考**：

- **只跑一遍 Dijkstra 行不行？** 行。跑出 $d_0$ 后，称满足 $d_0[u] + w = d_0[v]$ 的有向边 $(u,v,w)$ 为**紧边**，所有最短路恰好由紧边组成，它们构成按 $d_0$ 分层、无环的**最短路 DAG**；从 $n-1$ 沿紧边反向 DFS/BFS，能走到的紧边即是答案——题目标签里的 BFS/DFS 即指此法，与双 Dijkstra 等价。
- **若问「边在多少条最短路上」**：在最短路 DAG 上做计数 DP，$f_0[v]$ 为 $0\to v$ 最短路条数、$f_1[v]$ 为 $v\to n-1$ 条数，则经过边 $e$（$a\to b$ 方向）的最短路条数为 $f_0[a]\times f_1[b]$；它等于总数当且仅当 $e$ 在**每一条**最短路上。
- **若边权可为负（无负环）**：Dijkstra 失效，$d_0, d_1$ 改用 Bellman-Ford/SPFA；但判定公式依然成立——引理 3 的删环论证只需环权 $\ge 0$。
