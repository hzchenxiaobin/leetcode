# LeetCode 使矩阵满足条件的最少操作次数 题解

## 1. 题目概述

- **标题 / 题号**：使矩阵满足条件的最少操作次数（#3122，medium）
- **链接**：https://leetcode.cn/problems/minimum-number-of-operations-to-satisfy-conditions/
- **来源**：LeetCode 第 394 场周赛 Q3
- **难度**：中等
- **标签**：数组、动态规划、矩阵

**题意**：给定 $m \times n$ 的矩阵 `grid`。每次操作可把**任意一个**格子改成**任意非负整数**。要求最终矩阵满足：同一列上下相邻的格子**相等**（$grid[i][j] = grid[i+1][j]$），同一行左右相邻的格子**不相等**（$grid[i][j] \ne grid[i][j+1]$）。返回最少操作次数。

**约束**：

- $1 \le m, n \le 1000$
- $0 \le grid[i][j] \le 9$

> 💡 读题关键：两条约束方向不同——**竖直是相等、水平是不等**。相等约束沿列「链式传递」：$grid[0][j] = grid[1][j] = grid[2][j] = \cdots$，整列被迫同值；而格子值域只有 $0 \sim 9$，这意味着候选列值只有 10 个。$m, n$ 同时到 $10^3$（$10^6$ 个格子）堵死了指数枚举，而值域 10 又把状态空间压得极小——「大网格 + 小值域」正是列级 DP 的招牌信号。

## 2. 示例

**示例 1**

```text
输入：grid = [[1,0,2],[1,0,2]]
输出：0
解释：矩阵中所有格子已经满足要求。
```

**示例 2**

```text
输入：grid = [[1,1,1],[0,0,0]]
输出：3
解释：变成 [[1,0,1],[1,0,1]]，改 grid[1][0]、grid[0][1]、grid[1][2]，共 3 次。
```

**示例 3**

```text
输入：grid = [[1],[2],[3]]
输出：2
解释：只有一列，全部变成 1 即可（改 2 个格子）。
```

## 3. 解题思路

### 3.1 暴力思路

任何最终方案都等价于「给每列定一个目标值 $v_j$，再把列内不等于 $v_j$ 的格子全改掉」（为何每列必须同值，见 3.2 的观察一）。于是朴素枚举：

- 每列从 $0 \sim 9$ 中挑一个值，共 $10^n$ 种序列；
- 检查相邻列值互异，取总代价 $\sum_j (m - cnt[j][v_j])$ 的最小值。

$10^{1000}$ 种组合天文数字，必须放弃。但这个暴力已经把问题的结构榨出来了：**决策单位是「列」而不是「格子」**，且合法性与代价都只和「本列取值 + 左邻取值」有关——这是标准的一维 DP 骨架。

### 3.2 核心观察：竖直约束「绑列」，水平约束「染色」

![核心概念：两条约束压缩成一维列值序列](images/min_ops_column_uniform.svg)

三个层层递进的观察：

- **观察一（列同值）**：竖直约束 $grid[i][j] = grid[i+1][j]$ 沿列链式传递，等价于**每列所有格子取同一个值**。$m \times n$ 的矩阵就此塌缩成长度 $n$ 的「列值序列」——一次决策定一整列。
- **观察二（相邻异值）**：每列同值之后，水平约束 $grid[i][j] \ne grid[i][j+1]$ 自动简化为「**相邻两列的列值不同**」。这恰是路径图（$n$ 个点排成一排）上的**涂色**模型。
- **观察三（值域 10）**：格子值 $0 \le grid[i][j] \le 9$，而把一列改成域外新值（$\ge 10$）的代价恒为 $m$（所有格子都要动），不比任何域内值更便宜——域外值被**支配**。因此每列只需考虑 $10$ 个候选值。

把第 $j$ 列整体赋值为 $v$ 的代价一目了然：$cost(j, v) = m - cnt[j][v]$，其中 $cnt[j][v]$ 是第 $j$ 列中**原本就等于** $v$ 的格子数——它们恰好是免于修改的幸运儿。

> 💡 这一步是全题的「降维打击」：$10^6$ 个格子的修改自由度被压缩成 $n$ 个「十选一」的决策。识别信号是**约束的结构**（沿列传递的相等 + 只看相邻的不等）而非数据范围本身。

### 3.3 算法流程：$dp[j][v]$ 与「最小 + 次小」转移

![DP 转移：最小加次小的 O(1) 前驱查询](images/min_ops_dp_transition.svg)

定义 $dp[j][v]$：前 $j+1$ 列已全部合法、且第 $j$ 列取值 $v$ 的最少操作数。转移时唯一的约束是**不能与左邻同色**：

$$dp[j][v] = cost(j, v) + \min_{u \ne v} dp[j-1][u]$$

初始化 $dp[0][v] = cost(0, v)$，答案为 $\min_v dp[n-1][v]$。

若对每个 $v$ 都扫一遍 10 个前驱，单列转移 $O(10^2)$；注意到 $\min_{u \ne v} dp[j-1][u]$ 对 9 个 $v$ 取的都是**同一个最小值** $v_1$，只有当 $v$ 恰好等于最小值位置 $b_1$ 时才要用**次小值** $v_2$。于是每列先花 $O(10)$ 记下两笔账（最小 + 次小），再 $O(1)$ 回答每个 $v$：

$$dp_{new}[v] = cost(j, v) + \begin{cases} v_2 & v = b_1 \\ v_1 & v \ne b_1 \end{cases}$$

流程总结：

1. 统计每列计数 $cnt[j][v]$（$O(mn)$）；
2. 用第 0 列代价初始化 $dp$；
3. 逐列转移：求 $dp$ 的最小值 $v_1$（位置 $b_1$）与次小值 $v_2$，按上式更新；
4. 返回最终 $dp$ 的最小值。

### 3.4 示例演算

![示例 2 逐列 dp 表演算与回溯](images/min_ops_example_walkthrough.svg)

以示例 2 `grid = [[1,1,1],[0,0,0]]`（$m=2, n=3$）走一遍。每列 $cnt$：$0 \to 1$、$1 \to 1$、其余 $\to 0$，三列完全相同：

| 值 $v$ | $dp[0][v]$ | $dp[1][v]$ | $dp[2][v]$ |
|--------|-----------|-----------|-----------|
| 0 | 1 | **2** | 3 |
| 1 | **1** | 2 | **3** |
| 2 ~ 9 | 2 | 3 | 4 |

- 第 0 列只付自身代价：$dp[0][0] = dp[0][1] = 1$，其余为 2；
- 第 1 列转移（$v_1 = 1$ 在 $b_1 = 0$，$v_2 = 1$）：$dp[1][0] = 1 + v_2 = 2$，$dp[1][1] = 1 + v_1 = 2$，$v \ge 2$ 时 $2 + 1 = 3$；
- 第 2 列同理：$dp[2][0] = dp[2][1] = 3$，其余 4。

答案 $\min_v dp[2][v] = 3$。回溯路径 $1 \to 0 \to 1$：三列各改 1 个格子，共 3 次，与官方解释（变成 `[[1,0,1],[1,0,1]]`）完全吻合。

## 4. 算法细节

1. **计数方式**：`cnt[j][v]` 按「外层遍历列、内层遍历行」统计；C++ 中 `cnt` 开成 `vector<array<int,10>>`，Python 开成 `n × 10` 的列表。也可只滚动当前列的计数，把额外空间从 $O(10n)$ 降到 $O(10)$。
2. **次小的求法**：先扫一遍找最小值位置 $b_1$，再在 $u \ne b_1$ 中取最小即次小 $v_2$（注意次小与最小**可以相等**，只要它们位于不同的值上）。Python 用 `min(range(10), key=dp.__getitem__)` 取 $b_1$ 最简洁。
3. **就地滚动**：先算好 $v_1, v_2$ 再覆写 `dp[v]`，旧值只通过这两笔账参与计算，无需额外数组。
4. **写法容忍度**：$n \le 1000$，即便写成朴素的 $O(10^2 n)$ 双重循环（约 $10^5$ 次比较）也轻松通过；min/次小是「顺手做对」的锦上添花，面试里值得口头点出。
5. **域外值为何不考虑**：把某列赋成 $w \ge 10$ 代价恰为 $m$；换成任一避开左右邻列取值的域内 $v$，代价 $m - cnt[j][v] \le m$ 不增，且约束仍满足——任何使用域外值的最优解都能改写成纯域内方案（证明见引理 3）。
6. **与「粉刷房子」的同构**：把每列看作一栋房子、10 个候选值看作 10 种油漆、$cost(j,v)$ 是刷漆价格、相邻房子颜色须不同——本题就是 256/265 系列的矩阵变装，265 的 min/次小优化原封不动可用。

## 5. 正确性证明

**引理 1**（列同值刻画）：修改后的网格满足竖直约束 $\iff$ 每列所有格子取同一值。

**证明**：（$\Leftarrow$）同列任取相邻两格，值相同，约束成立。（$\Rightarrow$）对固定的列 $j$，约束给出链 $grid[0][j] = grid[1][j],\ grid[1][j] = grid[2][j],\ \cdots$，由相等关系的传递性，$grid[i][j] = grid[i'][j]$ 对一切 $i, i'$ 成立。∎

**引理 2**（列代价刻画）：把第 $j$ 列整体变成值 $v$ 的最少操作数为 $m - cnt[j][v]$。

**证明**：只需修改不等于 $v$ 的格子，它们恰有 $m - cnt[j][v]$ 个，故该代价可取到。反之若操作数少于 $m - cnt[j][v]$，由鸽笼原理至少有一个原值 $\ne v$ 的格子未被修改，该格子的值不等于 $v$，与引理 1 的「整列同值」矛盾。∎

**引理 3**（值域缩减）：存在最优方案，使每列取值都在 $0 \sim 9$ 中。

**证明**：设某最优方案中第 $j$ 列取值 $w \ge 10$，由引理 2 其代价为 $m$。取域内值 $v \in \{0,\cdots,9\} \setminus \{v_{j-1}, v_{j+1}\}$（左邻、右邻的取值），该集合至多排除 2 个值，仍有至少 8 个候选，故非空。把第 $j$ 列改为 $v$：代价变为 $m - cnt[j][v] \le m$，不增；且 $v$ 异于左右邻列取值，水平约束仍满足；其他列未动，其余约束不受影响。故总代价不增，仍为最优。对域外取值的列逐个执行上述替换（每次替换可能改变邻列的「禁忌集」，但不影响替换的合法性），有限步后得到全部取值在 $0 \sim 9$ 的最优方案。∎

**引理 4**（DP 最优子结构）：$dp[j][v]$ 满足转移 $dp[j][v] = cost(j,v) + \min_{u \ne v} dp[j-1][u]$。

**证明**：对 $j$ 归纳。$j = 0$ 时无左邻，$dp[0][v] = cost(0,v)$，即初始条件。设对 $j-1$ 成立。考虑「前 $j+1$ 列合法且第 $j$ 列取值 $v$」的任一方案，设其第 $j-1$ 列取值 $u$，则由约束 $u \ne v$；该方案在前 $j$ 列上的限制是一个「第 $j-1$ 列取值 $u$」的合法方案（前 $j$ 列的约束不涉及第 $j$ 列），由引理 2 两段代价可加，故方案代价 $\ge dp[j-1][u] + cost(j,v) \ge \min_{u' \ne v} dp[j-1][u'] + cost(j,v)$。反之，取达到 $dp[j-1][u^\ast]$ 的方案（$u^\ast \ne v$ 为最优前驱），将第 $j$ 列赋值为 $v$，由 $u^\ast \ne v$ 水平约束成立，得代价恰为 $cost(j,v) + dp[j-1][u^\ast]$ 的合法方案。两方向夹逼即得转移式。∎

**定理**：算法返回值等于最少操作数。

**证明**：由引理 1，任何合法终态对应一个列值序列 $(v_0, \cdots, v_{n-1})$ 且相邻互异；由引理 3，只需在 $v_j \in \{0,\cdots,9\}$ 中考察；由引理 2，其总操作数为 $\sum_j cost(j, v_j)$。反之，任何相邻互异的列值序列都可通过「逐列赋值」实现，代价相同。于是原问题等价于

$$\min \left\{ \sum_{j=0}^{n-1} cost(j, v_j) : v_j \in \{0,\cdots,9\},\ v_j \ne v_{j+1} \right\}$$

这是路径图上的最小费用涂色，由引理 4 的转移逐列递推即可精确求解；min/次小的替换只是把 $\min_{u \ne v}$ 的计算从 $O(10)$ 降到 $O(1)$，取值不变（当 $v \ne b_1$ 时最小值可达，当 $v = b_1$ 时最小值被禁止、次小值恰为剩余 9 个中的最小）。算法最终取 $\min_v dp[n-1][v]$，即为上式的最优值。∎

## 6. 复杂度分析

- **时间复杂度**：$O(mn + 10n)$。统计每列计数需读完 $m n$ 个格子，是不可避免的下界；DP 部分 $n$ 列各做 $O(10)$ 的记账与转移。即便朴素 $O(10^2 n)$ 也仅 $10^5$ 量级。
- **空间复杂度**：$O(10n)$ 存全部列计数；若逐列滚动统计可降至 $O(10)$（dp 一维数组随列滚动）。答案上限 $mn \le 10^6$，`int` 足够。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int minimumOperations(vector<vector<int>>& grid) {
        int m = grid.size(), n = grid[0].size();
        vector cnt(n, array<int, 10>{});
        for (int i = 0; i < m; i++)
            for (int j = 0; j < n; j++)
                cnt[j][grid[i][j]]++;

        array<int, 10> dp{};
        for (int v = 0; v < 10; v++) dp[v] = m - cnt[0][v];
        for (int j = 1; j < n; j++) {
            int b1 = 0;                       // 最小值所在的颜色
            for (int v = 1; v < 10; v++)
                if (dp[v] < dp[b1]) b1 = v;
            int v1 = dp[b1], v2 = INT_MAX;    // 最小与次小（允许相等）
            for (int v = 0; v < 10; v++)
                if (v != b1) v2 = min(v2, dp[v]);
            for (int v = 0; v < 10; v++)
                dp[v] = m - cnt[j][v] + (v == b1 ? v2 : v1);
        }
        return *min_element(dp.begin(), dp.end());
    }
};
```

### Python

```python
class Solution:
    def minimumOperations(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        cnt = [[0] * 10 for _ in range(n)]
        for i in range(m):
            row = grid[i]
            for j in range(n):
                cnt[j][row[j]] += 1

        dp = [m - c for c in cnt[0]]
        for j in range(1, n):
            b1 = min(range(10), key=dp.__getitem__)   # 最小值所在的颜色
            v1 = dp[b1]
            v2 = min(dp[:b1] + dp[b1 + 1:])           # 次小（允许与最小相等）
            dp = [m - cnt[j][v] + (v2 if v == b1 else v1) for v in range(10)]
        return min(dp)
```

## 8. 边界情况与易错点

1. **单列 $n = 1$**：无水平约束，答案就是 $m - \max_v cnt[0][v]$。DP 循环不进入，初始化后直接取 min，自动覆盖（示例 3 正是此情形）。
2. **单行 $m = 1$**：每个「列」只有一个格子，$cost(j,v) \in \{0,1\}$，DP 照常工作；若同时 $n = 1$，答案为 0。
3. **min/次小的撞色判定**：必须判 $v == b_1$（最小值所在的颜色）而非判 $dp$ 值相等——若最小值有并列，用「值相等」判断会把所有并列位置都错换成次小。次小 $v_2$ 与最小 $v_1$ **可以相等**。
4. **别把行列搞反**：竖直相等约束作用于**同一列**，压缩的是列、转移沿列下标推进；若误按行压缩（把每行绑成一个值），样例 1 都过不了。矩阵转置后本题约束并**不**对称（转置会交换两条约束的角色）。
5. **域外值的诱惑**：「整列改成 10、11 交替」看似规避撞色，实则每列代价都是 $m$，绝不优于在 $0 \sim 9$ 里挑（引理 3）；千万别把候选值域扩大。
6. **代价只看本列计数**：$cost(j,v)$ 与其他列无关，可以放心预计算；转移里加的才是前驱的 $dp$。
7. **C++ 次小初值**：$v_2$ 初始化为 `INT_MAX` 后要在 $u \ne b_1$ 中取 min，$10$ 个值保证它必被更新；`cnt` 用 `array<int,10>` 值初始化 `{}` 防止脏数据。
