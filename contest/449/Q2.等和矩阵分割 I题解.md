# LeetCode 等和矩阵分割 I 题解

## 1. 题目概述

- **标题 / 题号**：等和矩阵分割 I（#3546，medium）
- **链接**：https://leetcode.cn/problems/equal-sum-grid-partition-i/
- **来源**：LeetCode 第 449 场周赛 Q2
- **难度**：中等
- **标签**：数组、矩阵、前缀和、枚举

**题意**：给定一个 $m \times n$ 的正整数矩阵 `grid`，判断能否用**一条水平或一条垂直分割线**将矩阵分成两部分，使得每部分都**非空**，且两部分所有元素之和**相等**。存在返回 `true`，否则返回 `false`。

**约束**：

- `1 <= m == grid.length <= 10^5`
- `1 <= n == grid[i].length <= 10^5`
- `2 <= m * n <= 10^5`
- `1 <= grid[i][j] <= 10^5`

> 💡 关键约束是 $m \cdot n \le 10^5$：矩阵"长宽都可以很大但总面积小"，所以任何 $O(mn)$ 的做法都安全，$O(m^2 n)$、$O(mn \cdot (m+n))$ 之类则不行。另外元素全为正、总和可达 $10^{10}$（C++ 需 64 位整数）。

## 2. 示例

**示例 1**

```text
输入：grid = [[1,4],[2,3]]
输出：true
解释：在第 0 行和第 1 行之间水平分割，两部分和分别为 1+4=5 与 2+3=5，相等。
```

**示例 2**

```text
输入：grid = [[1,3],[2,4]]
输出：false
解释：水平分割：4 与 6；垂直分割：3 与 7。都无法相等。
```

**示例 3**（单行矩阵，只能垂直切）

```text
输入：grid = [[10,1,5]]
输出：false
解释：total=16 为偶数，target=8；但列前缀只有 10（切点仅 1 个），10 > 8 且严格递增，越过 target → false。
```

## 3. 解题思路

### 3.1 暴力思路：逐条分割线重算和

枚举全部 $m-1$ 个水平切点与 $n-1$ 个垂直切点，每个切点 $O(mn)$ 重新累加两部分之和。总复杂度 $O(mn \cdot (m+n))$，最坏约 $10^5 \times 10^5$ 量级，必然超时。

### 3.2 核心观察：前缀和 + 总和减半

一条分割线把矩阵分成**互补**的两部分。设矩阵总和为 $S$，两部分和相等当且仅当**其中一部分恰好是 $S/2$**。于是问题转化为：

- 水平分割 ⟺ 存在切点 $i \in [1, m-1]$，使**行前缀和** $\sum_{k=0}^{i-1} R_k = S/2$（$R_k$ 为第 $k$ 行的行和）；
- 垂直分割 ⟺ 存在切点 $j \in [1, n-1]$，使**列前缀和** $\sum_{l=0}^{j-1} C_l = S/2$（$C_l$ 为第 $l$ 列的列和）。

两个立即可得的加速：

1. **奇偶特判**：$S$ 为奇数时 $S/2$ 不是整数，直接 `false`；
2. **单调性提前终止**：元素全为正 $\Rightarrow$ $R_k \ge n \ge 1$、$C_l \ge m \ge 1$，前缀随切点**严格递增**，每个方向至多一个可行切点，扫描中一旦超过 $S/2$ 即可停止该方向。

![核心观察：水平/垂直分割与前缀和](images/egp1_partition_concept.svg)

### 3.3 算法流程

![算法流程：奇偶特判 + 行列前缀扫描](images/egp1_decision_flow.svg)

1. 一次遍历矩阵，同时累加 `total`、每行和 `rowSum[]`、每列和 `colSum[]`；
2. 若 `total` 为奇数，返回 `false`；
3. 令 `target = total / 2`，扫描行前缀（切点 $i = 1 \dots m-1$）：命中 `target` 返回 `true`，超过即 `break`；
4. 扫描列前缀（切点 $j = 1 \dots n-1$）：同样判定；
5. 两方向都未命中，返回 `false`。

### 3.4 示例演算

![示例演算：命中 target 与越过 target](images/egp1_example_walkthrough.svg)

- 示例 1：$S = 10$，`target = 5`；行前缀 $R_0 = 1+4 = 5$ 命中 → 第 0 行后水平切分，返回 `true`；
- 示例 2：$S = 10$，`target = 5`；水平唯一切点前缀为 4，垂直唯一切点前缀为 3，补上下一行/列直接跳到 10，**越过** 5 → 返回 `false`。

## 4. 算法细节

1. **一次遍历求三个量**：遍历 `grid[i][j]` 时同步执行 `total += v; rowSum[i] += v; colSum[j] += v;`，避免多次 $O(mn)$ 遍历。
2. **切点与循环边界**：水平切点 $i$ 表示"上半为前 $i$ 行"，合法范围 $i \in [1, m-1]$（切满 $m$ 行会使下半为空）。代码里写成 `for (int i = 0; i + 1 < m; i++)`，累加 `rowSum[i]` 后判断，等价于枚举 $i \in [1, m-1]$。垂直方向同理。
3. **提前终止的正确写法**：先判 `pref == target` 再判 `pref > target`；由于严格递增，`break` 不会错过唯一可能的命中（见 §5 引理 3）。
4. **溢出**：$S \le m \cdot n \cdot 10^5 \le 10^{10}$，超过 32 位 int 范围，C++ 中 `total`、`rowSum`、`colSum`、`pref` 都用 `long long`；Python 无此问题。
5. **单行 / 单列矩阵**：$m = 1$ 时行前缀循环不执行（`m - 1 = 0`），自动只查垂直方向；$n = 1$ 同理。约束 $m \cdot n \ge 2$ 保证至少一个方向存在切点。

## 5. 正确性证明

**引理 1（等价转化）**：一条分割合法，当且仅当两部分中某一部分的元素和为 $S/2$（$S$ 为矩阵总和）。

**证明**：两部分互补不重叠，设各自和为 $x$ 与 $S - x$。相等即 $x = S - x$，即 $2x = S$、$x = S/2$；此时 $S$ 必为偶数。反之若某部分和为 $S/2$，则另一部分为 $S - S/2 = S/2$，相等。∎

**引理 2（切点刻画）**：水平分割线只能落在相邻两行之间，共 $m - 1$ 个位置；切在第 $i$ 行之后（上半为前 $i$ 行，$1 \le i \le m - 1$）时，上半和为 $\sum_{k=0}^{i-1} R_k$。垂直方向对称：切在第 $j$ 列之后（左半为前 $j$ 列，$1 \le j \le n - 1$），左半和为 $\sum_{l=0}^{j-1} C_l$。切点范围保证两部分非空。

**证明**：水平线切矩阵，上方部分恰是若干完整的行；"上半非空"要求 $i \ge 1$，"下半非空"要求 $i \le m-1$。列方向同理。∎

**引理 3（单调性与提前终止）**：所有元素 $\ge 1$，故每个行和 $R_k \ge n \ge 1$、每个列和 $C_l \ge m \ge 1$。因此行/列前缀和关于切点**严格递增**：每个方向至多一个切点满足前缀 $= S/2$，且扫描中一旦前缀 $> S/2$，其后所有切点的前缀也 $> S/2$，可安全 `break`。

**证明**：前缀从切点 $i$ 推进到 $i+1$ 恰好增加 $R_i \ge 1$（列方向增加 $C_j \ge 1$），严格递增。严格递增的整数序列中，值 $S/2$ 至多出现一次；且若某项 $> S/2$，后续项只增不减，均 $> S/2$，不可能再等于 $S/2$。∎

**定理**：算法返回 `true` 当且仅当存在合法分割。

**证明**：

- （充分性）算法返回 `true` 只发生在某方向扫描中 `pref == target`，对应引理 2 中一个合法切点，且该侧和为 $S/2$；由引理 1，该分割两侧相等。
- （必要性）设存在合法分割。由引理 1，$S$ 为偶数（奇偶检查通过），且某一侧和为 $S/2$；由引理 2，该侧是行方向或列方向某个合法切点的前缀。扫描按切点从小到大访问前缀，由引理 3 的严格递增性，命中之前的所有前缀都 $< S/2$，不会触发提前 `break`，故扫描必然命中并返回 `true`。∎

## 6. 复杂度分析

- **时间复杂度**：$O(mn + m + n) = O(mn)$。一次遍历求 `total / rowSum / colSum` 占 $O(mn)$；两个方向的切点扫描各 $O(m)$、$O(n)$。由 $mn \le 10^5$，总量极小。
- **空间复杂度**：$O(m + n)$，存 `rowSum` 与 `colSum` 两个数组。若追求极致，可改为三趟在线累加（第一趟求 `total`，第二趟逐行累加判水平切点，第三趟逐列累加判垂直切点），额外空间降到 $O(1)$。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    bool canPartitionGrid(vector<vector<int>>& grid) {
        int m = grid.size(), n = grid[0].size();
        long long total = 0;
        vector<long long> rowSum(m, 0), colSum(n, 0);
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                long long v = grid[i][j];
                total += v;
                rowSum[i] += v;
                colSum[j] += v;
            }
        }
        if (total % 2 != 0) return false; // S 为奇数，S/2 非整数
        long long target = total / 2;

        // 水平切点 i = 1..m-1：上半为前 i 行
        long long pref = 0;
        for (int i = 0; i + 1 < m; i++) {
            pref += rowSum[i];
            if (pref == target) return true;
            if (pref > target) break; // 正元素 ⇒ 严格递增，可提前终止
        }

        // 垂直切点 j = 1..n-1：左半为前 j 列
        pref = 0;
        for (int j = 0; j + 1 < n; j++) {
            pref += colSum[j];
            if (pref == target) return true;
            if (pref > target) break;
        }
        return false;
    }
};
```

### Python

```python
class Solution:
    def canPartitionGrid(self, grid: List[List[int]]) -> bool:
        m, n = len(grid), len(grid[0])
        total = 0
        row_sum = [0] * m
        col_sum = [0] * n
        for i in range(m):
            for j in range(n):
                v = grid[i][j]
                total += v
                row_sum[i] += v
                col_sum[j] += v

        if total % 2:
            return False
        target = total // 2

        # 水平切点 i = 1..m-1：上半为前 i 行
        pref = 0
        for i in range(m - 1):
            pref += row_sum[i]
            if pref == target:
                return True
            if pref > target:
                break

        # 垂直切点 j = 1..n-1：左半为前 j 列
        pref = 0
        for j in range(n - 1):
            pref += col_sum[j]
            if pref == target:
                return True
            if pref > target:
                break
        return False
```

## 8. 边界情况与易错点

1. **总和为奇数**：必须最先特判返回 `false`，避免无意义扫描，也避免"前缀永远凑不出 $S/2$"的隐性错误。
2. **切点范围**：水平合法切点是 $[1, m-1]$ 而非 $[1, m]$——切满 $m$ 行会让下半为空。循环写成 `i + 1 < m` / `j + 1 < n`（Python `range(m-1)` / `range(n-1)`），不要多扫一个非法切点。
3. **单行 / 单列**：$m = 1$ 只能垂直切、$n = 1$ 只能水平切；上述循环边界天然处理（另一个方向的循环体不执行），无需 if 分支。
4. **C++ 溢出**：$S$ 可达 $10^{10}$，`total`、前缀和必须 `long long`；只把 `target` 设成 `long long` 而累加用 `int` 仍会溢出。
5. **提前终止依赖正元素**：`break` 的正确性来自"元素 $\ge 1$ ⇒ 前缀严格递增"。若题目改为允许 $0$ 或负数（本题不允许），必须去掉 `break`，否则会漏解。
6. **先判等再判大于**：循环内 `== target` 的判断必须放在 `> target` 之前——虽然对当前项两者顺序其实无碍（同一项不可能既等于又大于），但养成固定顺序可避免在"≥ 终止"变体中出错。

**延伸思考**：
