# LeetCode 不同字符数量最多为 K 时的最少删除数 题解

## 1. 题目概述

- **标题 / 题号**：不同字符数量最多为 K 时的最少删除数（#3545，easy）
- **链接**：https://leetcode.cn/problems/minimum-deletions-for-at-most-k-distinct-characters/
- **来源**：LeetCode 第 449 场周赛 Q1
- **难度**：简单
- **标签**：贪心、哈希表、字符串、计数、排序

**题意**：给定小写字母字符串 `s` 和整数 `k`，删除其中若干字符（可以不删），使得剩余字符串的**不同字符数量**最多为 `k`，返回最少需要删除的字符数。

**约束**：

- `1 <= s.length <= 16`
- `1 <= k <= 16`
- `s` 仅由小写英文字母组成

## 2. 示例

**示例 1**

```text
输入：s = "abc", k = 2
输出：1
解释：三个不同字符 'a'、'b'、'c' 频率均为 1，需删光某一个字符的全部出现，如删 'c'，答案 1。
```

**示例 2**

```text
输入：s = "aabb", k = 2
输出：0
解释：不同字符数 m = 2 ≤ k = 2，无需删除。
```

**示例 3**

```text
输入：s = "yyyzz", k = 1
输出：2
解释：'y' 出现 3 次、'z' 出现 2 次，只能保留 1 种，删光频率较小的 'z'，答案 2。
```

## 3. 解题思路

### 3.1 暴力思路

`n ≤ 16` 极小，可以枚举每个位置"删/不删"（$2^{16} = 65536$ 种方案），对每种方案统计剩余字符串的不同字符数，在合法方案中取删除数最小值。可行但完全没必要——如此小的数据范围只是为了不卡语言，正解是一个对 `n` 线性的**贪心**。

### 3.2 核心观察：要删就删光，保留频率最大的 k 个

![核心观察：要删就删光，保留频率最大的k个](images/wc449_q1_greedy_concept.svg)

**关键洞察**（两步）：

1. **部分删除是无用功**：一个字符只要还剩至少一次出现，它就仍然贡献 1 个"不同字符"。因此任何最优解中，每个字符要么完全不动、要么**删光全部出现**——问题从"删哪些位置"坍缩为"删光哪些字符"。
2. **删哪几个**：设不同字符数为 $m$。删光 $j$ 种字符后不同字符数为 $m - j$，合法需 $j \ge m - k$；而每多删光一种字符，代价至少增加其全部出现次数（$> 0$），所以恰好删光 $m - k$ 种最优，且应选**出现次数最少**的那些。

于是答案 = 频率最小的 $m - k$ 个字符的出现次数之和。

### 3.3 算法流程

![算法流程：计数、特判、排序求和](images/wc449_q1_algorithm_flow.svg)

1. 统计每个字符出现次数 `cnt[26]`；
2. 取出所有非零频率，记个数为 $m$（即不同字符数）；
3. 若 $m \le k$，直接返回 `0`（特判分支）；
4. 否则将频率**升序排序**，返回前 $m - k$ 个频率之和。

### 3.4 示例演算

![示例演算：三个分支各走一遍](images/wc449_q1_example_walkthrough.svg)

| 示例 | 频率 | $m$ 与 $k$ 比较 | 操作 | 答案 |
|------|------|----------------|------|------|
| `s="abc", k=2` | `a:1, b:1, c:1` | $m=3>2$ | 删 $3-2=1$ 个最小频率（并列任选） | 1 |
| `s="aabb", k=2` | `a:2, b:2` | $m=2\le 2$ | 无需删除 | 0 |
| `s="yyyzz", k=1` | `y:3, z:2` | $m=2>1$ | 删频率最小的 `z`，删光 2 个 | 2 |

## 4. 算法细节

1. **计数**：长度 26 的数组或哈希表统计频率，`O(n)`。
2. **特判**：`m = 非零频率个数 ≤ k` 时返回 0，避免排序后计算负数个数的求和。
3. **排序方向**：**升序**排序后取**前** $m-k$ 个——删的是频率**最小**的字符（易错点：与"保留 Top-k"等价，但别取成后 $m-k$ 个）。
4. **求和**：`freq[0..m-k-1]` 之和即答案，最大不超过 `n`，`int` 足够。

## 5. 正确性证明

**引理 1（删光的等价性）**：任何可行方案都可调整为"若干字符完全不动、其余字符删光"的形式，且删除次数不增。

**证明**：设某方案删除了字符 $c$ 的部分出现但未删光。将 $c$ 的这些删除全部恢复：$c$ 仍出现 $\ge 1$ 次，它对"不同字符数"的贡献不变（仍贡献 1 种），方案保持合法，而删除次数严格减少。对每个被部分删除的字符依次调整即得。∎

**引理 2（删除数量）**：存在最优解恰好删光 $m - k$ 种字符。

**证明**：删光 $j$ 种后不同字符数为 $m - j \le k$ 当且仅当 $j \ge m - k$（$m > k$ 时）。由引理 1，只需考虑"删光集合"型方案。若 $j > m - k$，从集合中去掉任意一种字符，方案仍合法且代价减少（该字符出现次数 $> 0$），故 $j = m - k$ 时不劣。∎

**定理（贪心最优性）**：保留频率最大的 $k$ 种字符（即删光频率最小的 $m - k$ 种）的代价最小。

**证明**：由引理 1、2，问题化为：在所有大小为 $m - k$ 的字符子集中最小化频率之和。这是经典的"选最小的 $m - k$ 个数"问题：若某最优集合 $D$ 含字符 $y$ 但不含字符 $x$ 且 $f_x < f_y$，则以 $x$ 替换 $y$ 后代价变化量为 $f_x - f_y < 0$，与最优性矛盾。故最优集合恰由频率最小的 $m - k$ 种字符组成。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n + \Sigma \log \Sigma)$，其中 $\Sigma \le 26$ 为字符集大小。计数 $O(n)$，排序 $O(\Sigma \log \Sigma)$；对 $n \le 16$ 而言约等于 $O(n)$，即使 $n$ 放大到 $10^5$ 也轻松通过。
- **空间复杂度**：$O(\Sigma)$，仅频率数组与排序后的列表。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minDeletion(string s, int k) {
        int cnt[26] = {0};
        for (char c : s) cnt[c - 'a']++;
        vector<int> freq;
        for (int i = 0; i < 26; i++)
            if (cnt[i] > 0) freq.push_back(cnt[i]);
        int m = freq.size();
        if (m <= k) return 0;
        sort(freq.begin(), freq.end());
        int ans = 0;
        for (int i = 0; i < m - k; i++) ans += freq[i];
        return ans;
    }
};
```

### Python

```python
class Solution:
    def minDeletion(self, s: str, k: int) -> int:
        cnt = Counter(s)
        if len(cnt) <= k:
            return 0
        freq = sorted(cnt.values())
        return sum(freq[:len(freq) - k])
```

## 8. 边界情况与易错点

1. **忘记特判 `m ≤ k`**：此时答案为 0；若直接排序求和会错误地删字符（Python 切片 `freq[:-k]` 在 `len(freq) == k` 时为空恰好不出错，但逻辑上应显式特判；C++ 中 `m - k` 为负会导致循环不执行，同样掩盖问题——显式写出更清晰）。
2. **"删光"而非"删一次"**：题目删除的是字符的**每次出现**，答案按出现次数累加。
3. **排序方向反了**：要删的是频率**最小**的 $m - k$ 种，不是最大的（保留最大的 $k$ 种）。
4. **频率并列**：最小频率并列时任选其一，代价相同（示例 1）。
5. **溢出**：答案上界为 $n \le 16$，`int` 足够，无溢出风险。
6. **`k` 很大**：约束 $k \le 16$，但即使 $k \ge 26$ 也被 `m ≤ k` 特判覆盖。
