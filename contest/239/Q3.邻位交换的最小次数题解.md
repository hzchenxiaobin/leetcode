# LeetCode 邻位交换的最小次数 题解

## 1. 题目概述

- **标题 / 题号**：邻位交换的最小次数（#1850，medium）
- **链接**：https://leetcode.cn/problems/minimum-adjacent-swaps-to-reach-the-kth-smallest-number/
- **来源**：LeetCode 第 239 场周赛 Q3
- **难度**：中等
- **标签**：贪心、双指针、字符串、排列

**题意**：给定表示大整数的字符串 `num` 与整数 $k$。若某整数是 `num` 各位数字的一个**排列**且**值大于** `num`，称之为**妙数**。妙数可能很多，只需关注**值最小**的那些。求把 `num` 变成**第 $k$ 个最小妙数**所需执行的**相邻位数字交换的最小次数**。

**约束**：

- $2 \le \text{num.length} \le 1000$
- $1 \le k \le 1000$
- `num` 仅由数字组成
- 测试用例按存在第 $k$ 个最小妙数生成

> 💡 **审题关键**：① 所有排列**等长**，故「按数值比较」与「按字典序比较」完全一致，前导零不影响大小关系（示例 3 的 `"00123"` 与 `"00132"`）；② 问的不是第 $k$ 个妙数本身，而是**从 `num` 变过去的代价**——两件事可以解耦；③ 只允许交换**相邻两位**，这是「逆序对」模型的标志性信号。

## 2. 示例

**示例 1**

```text
输入：num = "5489355142", k = 4
输出：2

解释：第 4 个最小妙数是 "5489355421"：
- 交换下标 7 和 8："5489355142" -> "5489355412"
- 交换下标 8 和 9："5489355412" -> "5489355421"
```

**示例 2**

```text
输入：num = "11112", k = 4
输出：4

解释：第 4 个最小妙数是 "21111"，'2' 从队尾一路冒泡到队首，共 4 次相邻交换。
```

**示例 3**

```text
输入：num = "00123", k = 1
输出：1

解释：第 1 个最小妙数是 "00132"，交换下标 3 和 4 即可。
```

## 3. 解题思路

### 3.1 暴力思路

两件事各自都有暴力做法：枚举 `num` 的全部排列（$n!$ 级，$n = 1000$ 时是天文数字）筛出大于 `num` 的第 $k$ 小；再从 `num` 出发对排列状态做 BFS 逐层找最短交换路径——状态空间同样是排列级。双双不可行。

> 💡 暴力不可行的根源是**把两件事搅在一起**。正确姿势是分开问：第 $k$ 个妙数**是什么**（纯排列问题）？变成它的**最小代价**是多少（纯计数问题）？

### 3.2 核心观察：两阶段解耦

![核心观察：两阶段解耦，求第 k 个后继排列 + 数逆序对](images/wc239_q3_two_phase_concept.svg)

**观察 1（妙数 = 字典序后继链）**：等长数字串的数值比较就是字典序比较，所以「大于 `num` 的最小妙数」就是 `num` 的**下一个排列**——[31. 下一个排列](https://leetcode.cn/problems/next-permutation/) 的经典四步法：从右找首个升序对、从右找首个更大数字、交换、反转后缀。从 `num` 出发**连续调用 $k$ 次**，恰好走到第 $k$ 个最小妙数 `target`，单次 $O(n)$，共 $O(nk)$。

**观察 2（相邻交换的代价 = 逆序对数）**：一次相邻交换**恰好翻转一对元素的先后关系**，至多消除一个逆序对；而「不断交换相邻的逆序对」（冒泡排序）恰好用逆序对数次完成变换。因此把 `num` 变成 `target` 的最少相邻交换次数，就是两者元素对应关系下的**逆序对数**（Kendall tau 距离）。

**观察 3（重复数字要保序匹配）**：`num` 含重复数字时（示例 1 有三个 `5`、两个 `4`），`target` 的每一位对应 `num` 的哪个同值位可以任选——**按出现顺序依次配对**（保序匹配）使逆序对最少，错位配对会凭空制造逆序对（§5 引理 3 严格证明）。

### 3.3 算法流程

![算法流程图](images/wc239_q3_simulation_flow.svg)

1. **阶段①**：`target ← num` 的副本，循环 $k$ 次对 `target` 执行「下一个排列」四步法。
2. **阶段②**：`s ← num` 的副本，$i$ 从左到右扫描：
   - 若 $s[i] = \text{target}[i]$：已就位，直接跳过；
   - 否则从 $i+1$ 起找**最左侧**的 $j$ 使 $s[j] = \text{target}[i]$（保序匹配），把 $s[j]$ **冒泡左移**到位置 $i$，代价累加 $j - i$。
3. 返回累计的交换次数。

### 3.4 示例演算

![示例演算：num = 5489355142, k = 4](images/wc239_q3_walkthrough.svg)

以 `num = "5489355142", k = 4` 为例。**阶段①**连续 4 次「下一个排列」：

| 步骤 | $(i, j)$ | 结果 | 变动后缀 |
|------|----------|------|----------|
| num | — | `5489355142` | — |
| ① | $(7, 9)$ | `5489355214` | `142` → `214` |
| ② | $(8, 9)$ | `5489355241` | `14` → `41` |
| ③ | $(7, 8)$ | `5489355412` | `241` → `412` |
| ④ | $(8, 9)$ | `5489355421` | `12` → `21` |

得 `target = "5489355421"`。**阶段②**从左扫描：前 7 位 `5489355` 本已相同；$i=7$ 需要 `4`，最左的 `4` 在 $j=8$，左移 1 次；$i=8$ 需要 `2`，$j=9$，再左移 1 次。共 **2** 次交换 ✓。

> 💡 若把 `target[7]` 的 `4` 错配到 `num` 下标 1 的那个 `4`（同时 `target[1]` 配下标 8），逆序对会从 2 涨到 13——**保序匹配**是重复数字不翻车的关键。

## 4. 算法细节

1. **「下一个排列」四步法**（C++ 可直接调用 `std::next_permutation`）：
   - 从右向左找**首个**升序对，即最大的 $i$ 使 $s[i] < s[i{+}1]$（其后缀必然非升）；
   - 从右向左找**首个**大于 $s[i]$ 的 $s[j]$——后缀非升，最右的「大于」就是大于 $s[i]$ 的**最小值**；
   - 交换 $s[i]$ 与 $s[j]$；
   - 反转后缀 $s[i{+}1..]$（由 $s[j{+}1] \le s[i] < s[j] \le s[j{-}1]$ 知交换后后缀仍非升，反转即得升序的最小后缀）。
2. **找 $j$ 必须取最左同值**：从 $i+1$ 向右扫到的第一个 $s[j] = \text{target}[i]$。由于每轮把选中数字提到 $i$ 后**其余数字相对顺序不变**（§5 定理证明中的关键断言），窗口里「最左同值」恰是保序匹配指定的那一个。
3. **冒泡左移**：`while (j > i) { swap(s[j], s[j-1]); j--; ans++; }`——每步交换恰消除一个逆序对，绝不做无用功。
4. **进阶（$n$ 更大时）**：阶段② 可用树状数组降到 $O(n \log n)$：为每个数字维护下标队列，遍历 `target` 取队首 $j$，累加 $i - \text{query}(j)$（$\text{query}(j)$ 为已消费下标中小于 $j$ 的个数），再把 $j$ 标记为已用。本题 $n \le 1000$ 无此必要。
5. **复杂度为何够用**：$nk \le 10^6$、$n^2 \le 10^6$，总操作量约 $2 \times 10^6$。

## 5. 正确性证明

约定：把 `num` 每个位置看作带编号的**令牌**（可见值为该位数字），相邻交换即相邻令牌互换。**匹配** $M$ 指把 `target` 每个位置分配给一个同值令牌的双射；$M$ 的**逆序对数** $\mathrm{inv}(M)$ 为满足 $p < q$ 且 $M(p) > M(q)$ 的位置对数（即相对顺序需要翻转的令牌对数）。

**引理 1（后继性）**：四步法返回 $s$ 的字典序后继——所有由 $s$ 重排得到且大于 $s$ 的串中最小的一个；从而从 `num` 连续调用 $k$ 次得到第 $k$ 个最小妙数。

**证明**：设 $i$ 为最大的下标使 $s[i] < s[i{+}1]$，则后缀 $s[i{+}1..]$ 非升，是这些字符能组成的**最大**排列；故任何大于 $s$ 的重排必须改动下标 $\le i$ 的某位，而保留前缀越长结果越小，最优方案保留 $s[0..i{-}1]$ 并仅在位置 $i$ 换入更大字符。为使结果最小，应换入后缀中大于 $s[i]$ 的**最小字符**——后缀非升保证它位于最右端的大于 $s[i]$ 处，即四步法的 $j$。换入后，剩余字符（含原 $s[i]$）组成的后缀应取最小排列即**升序**；交换后后缀仍非升，一次反转即得。四步法逐条实现上述最优选择。「$k$ 次调用得第 $k$ 个」：后继关系构成一条链，对 $k$ 归纳即得。∎

**引理 2（代价 = 最优匹配的逆序对数）**：对固定匹配 $M$，任何把 `num` 变成 `target` 的相邻交换序列长度 $\ge \mathrm{inv}(M)$，且存在恰好 $\mathrm{inv}(M)$ 次的序列。从而最少交换次数 $= \min_M \mathrm{inv}(M)$。

**证明**：每做一次相邻交换，恰有一对令牌的相对顺序被翻转，其余不变。把「相对顺序与 $M$ 所规定终点不一致的令牌对数」看作势能：初始为 $\mathrm{inv}(M)$，终态为 $0$，每次交换至多使势能减 1，故长度 $\ge \mathrm{inv}(M)$。另一方面，若当前排列尚未到位但不存在任何「相邻且先后颠倒」的令牌对，则沿序列传递可知所有令牌对的先后都与 $M$ 一致，排列已到位——矛盾。故势能 $> 0$ 时必可交换一对相邻颠倒的令牌，使势能恰减 1，$\mathrm{inv}(M)$ 次即可完成。∎

**引理 3（保序匹配最优）**：在所有合法匹配中，「同值按出现顺序配对」的保序匹配 $M^\*$ 唯一最小化 $\mathrm{inv}$。

**证明**：设匹配 $M$ 含一对**同值交叉**：$p < q$，$\text{target}[p] = \text{target}[q]$，而 $M(p) = j' > j = M(q)$。构造 $M'$：交换这两处的分配（仍为合法匹配）。只有涉及 $p$、$q$ 的对变化：

- 对 $(p, q)$：原为逆序（$j' > j$），交换后不再是，**减 1**；
- 第三位置 $r < p$（或 $r > q$）：两对的贡献只是 $j, j'$ 互换位置，与 $M(r)$ 的大小比较结果总数**不变**；
- $p < r < q$：原贡献 $[j' > M(r)] + [M(r) > j]$，新贡献 $[j > M(r)] + [M(r) > j']$，当 $M(r) \in (j, j')$ 时由 2 变 0，其余情况**不变**。

故 $\mathrm{inv}(M') \le \mathrm{inv}(M) - 1 < \mathrm{inv}(M)$。这说明最优匹配（存在，因为匹配总数有限）不含同值交叉，即每个数字的各次出现按 `target` 中位置顺序对应 `num` 中下标顺序——正是保序匹配，且这样的匹配唯一。∎

**定理**：算法返回把 `num` 变成第 $k$ 个最小妙数所需相邻交换的最少次数。

**证明**：由引理 1，阶段① 得到的 `target` 是第 $k$ 个最小妙数。由引理 2、3，最少交换次数为保序匹配 $M^\*$ 的逆序对数，只需证明阶段② 的模拟恰好执行 $\mathrm{inv}(M^\*)$ 次交换。

**断言**：每轮开始时，`s` 的前 $i$ 位恰为令牌 $M^\*(0), \dots, M^\*(i{-}1)$（已就位），且窗口 $s[i..]$ 中令牌的相对顺序仍是**初始顺序**。归纳：初始显然。设第 $i$ 轮成立；由保序性，窗口内尚未提取的同值令牌中**下标最小**者恰为 $M^\*(i)$，而窗口相对顺序即初始顺序，故「最左同值」就是它；把它冒泡提到位置 $i$，其余令牌仅整体右移一格、相对顺序不变，归纳保持。

于是第 $i$ 轮的交换次数 = 窗口中位于 $M^\*(i)$ 之前的令牌数。对任意令牌对 $(M^\*(p), M^\*(q))$，$p < q$：交换只涉及「被提取的令牌」及其左邻，故该对唯一可能的发生时刻是第 $p$ 轮（第 $q$ 轮时 $M^\*(p)$ 已就位于窗口之外）；发生当且仅当 $M^\*(q)$ 当时在窗口中位于 $M^\*(p)$ 之前，由断言即 $M^\*(q) < M^\*(p)$——恰为逆序对。故每对令牌至多交叉一次，且交叉的恰是逆序对，总交换数 $= \mathrm{inv}(M^\*)$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(nk + n^2)$
  - 阶段① $k$ 次「下一个排列」，每次至多扫描一遍串，$O(nk) \le 10^6$；
  - 阶段② 每轮「找 $j$ + 冒泡」合计至多 $O(n)$，共 $n$ 轮，$O(n^2) \le 10^6$。
- **空间复杂度**：$O(n)$——`target` 与 `s` 两个串副本，其余为常数变量。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int getMinSwaps(string num, int k) {
        int n = num.size();

        // 阶段①：连续 k 次「下一个排列」= 第 k 个最小妙数
        string target = num;
        for (int t = 0; t < k; ++t)
            next_permutation(target.begin(), target.end());

        // 阶段②：贪心冒泡，数 num -> target 的最少相邻交换
        string s = num;
        int ans = 0;
        for (int i = 0; i < n; ++i) {
            if (s[i] == target[i]) continue;       // 已就位
            int j = i + 1;
            while (s[j] != target[i]) ++j;         // 最左侧同值（保序匹配）
            for (; j > i; --j) {                   // 冒泡左移到 i
                swap(s[j], s[j - 1]);
                ++ans;
            }
        }
        return ans;
    }
};
```

> 💡 `std::next_permutation` 就是四步法的标准库实现，对重复字符同样正确（内部用严格不等号判定，自动跳过相等）。

### Python

```python
class Solution:
    def getMinSwaps(self, num: str, k: int) -> int:
        target = list(num)
        for _ in range(k):
            self._next_permutation(target)

        s = list(num)
        ans = 0
        for i, ch in enumerate(target):
            if s[i] == ch:
                continue
            j = i + 1
            while s[j] != ch:                      # 最左侧同值（保序匹配）
                j += 1
            while j > i:                           # 冒泡左移到 i
                s[j], s[j - 1] = s[j - 1], s[j]
                j -= 1
                ans += 1
        return ans

    def _next_permutation(self, a: list) -> None:
        n = len(a)
        i = n - 2
        while i >= 0 and a[i] >= a[i + 1]:         # 从右找首个升序对
            i -= 1
        if i >= 0:
            j = n - 1
            while a[j] <= a[i]:                    # 从右找首个更大数字
                j -= 1
            a[i], a[j] = a[j], a[i]
        a[i + 1:] = reversed(a[i + 1:])            # 反转后缀
```

## 8. 边界情况与易错点

1. **别把「第 $k$ 个妙数」当「第 $k$ 个排列」**：妙数必须**严格大于** `num`，从 `num` 的后继链数起，不是从全排列的最小者数起。
2. **`target` 必须用副本**：阶段① 若直接在 `num` 上原地推进，原串被破坏，阶段② 无从比较。`target` 与 `s` 都要独立复制。
3. **找 $j$ 从 $i+1$ 开始**：能走到找 $j$ 说明 $s[i] \ne \text{target}[i]$，同值令牌必在右侧；从 0 开始扫会匹配到已就位的前缀。
4. **同值必须取最左**：取「最右同值」或任意一个都会破坏保序性、制造虚假逆序对（示例 1 错配方案算出 13 而非 2）。
5. **冒泡的是 $s[j]$ 向左**：把它逐位换到 $i$，代价 $j - i$；写成旋转式右移 $s[i]$ 得到的是另一个串。
6. **前导零无需处理**：等长串的数值比较 = 字典序比较，`"00132"` 是合法妙数（示例 3）。
7. **溢出**：答案上界 $\binom{n}{2} \approx 5 \times 10^5$，`int` 足够。
8. **$k$ 次后继不会中途失败**：题目保证第 $k$ 个妙数存在，即后继链长度 $\ge k$。
