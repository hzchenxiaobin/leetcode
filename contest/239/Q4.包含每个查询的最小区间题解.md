# LeetCode 包含每个查询的最小区间 题解

## 1. 题目概述

- **标题 / 题号**：包含每个查询的最小区间（#1851，hard）
- **链接**：https://leetcode.cn/problems/minimum-interval-to-include-each-query/
- **来源**：LeetCode 第 239 场周赛 Q4
- **难度**：困难
- **标签**：数组、排序、堆（优先队列）、扫描线、离线处理

**题意**：给定 $n$ 个闭区间 `intervals[i] = [left_i, right_i]`，区间的**长度**定义为 $r_i - l_i + 1$。再给定 $q$ 个查询 `queries[j]`。对每个查询，在所有满足 $l_i \le queries[j] \le r_i$（即完全包含该查询点）的区间中，求**长度最小**的那个区间的长度；若不存在任何覆盖它的区间，答案为 $-1$。返回所有查询的答案数组。

**约束**：

- $1 \le n \le 10^5$
- $1 \le q \le 10^5$
- $1 \le l_i \le r_i \le 10^7$
- $1 \le queries[j] \le 10^7$

## 2. 示例

**示例 1**

输入：intervals = [[1,4],[2,4],[3,6],[4,4]], queries = [2,3,4,5]
输出：[3,3,1,4]

解释：
- 查询 2：覆盖它的区间有 [1,4]（长 4）、[2,4]（长 3），最短为 3。
- 查询 3：覆盖它的区间有 [1,4]、[2,4]、[3,6]，最短为 3。
- 查询 4：覆盖它的区间有 [1,4]、[2,4]、[3,6]、[4,4]（长 1），最短为 1。
- 查询 5：只剩 [3,6] 覆盖它，长度 4。
```

**示例 2**

- 查询 5：[2,5] 覆盖（[1,8] 也覆盖但更长），长度 4。

```

## 3. 解题思路

### 3.1 暴力思路

对每个查询 $q_j$，线性扫描全部 $n$ 个区间，检查 $l_i \le q_j \le r_i$ 并维护长度最小值。

时间复杂度 $O(nq)$，本题 $n = q = 10^5$，约 $10^{10}$ 次比较，必然超时。

> 💡 暴力慢在**每个查询都从零开始**重新筛选区间。突破口是让所有查询**共享**一次筛选过程——这正是**离线处理**的动机。

### 3.2 核心观察：离线升序扫描 + 小根堆

![核心观察：查询升序扫描下的三类区间](images/wc239_q4_offline_heap_concept.svg)

**观察 1（可以离线）**：每个查询的答案只取决于查询**数值**本身，与查询的先后顺序无关。因此可以把 `queries` 任意重排处理，最后按原下标写回答案。

**观察 2（入场是一次性的）**：把查询**升序**处理后，把区间按左端点 $l_i$ 升序排序，用指针 $i$ 扫描：当前查询为 $q$ 时，所有 $l_i \le q$ 的区间都已"入场"，$l_i > q$ 的区间一个都不用管。由于 $q$ 只增不减、指针只前进，**每个区间恰好入场一次**。

**观察 3（失效是永久的）**：若某区间 $r_i < q$，则它对当前查询不覆盖；又因为后续查询 $q' \ge q$，它对后续查询也永远不覆盖。失效的区间可以**直接丢弃**，不必保留。

于是维护一个"已入场且未失效"的候选集合——这正是**覆盖当前查询的全体区间**。查询的是其中**长度最小值**，用按长度的小根堆维护即可：堆顶就是答案。

### 3.3 算法流程

![算法流程图](images/wc239_q4_sweep_flow.svg)

1. **预处理**：`queries` 升序排序（记录原下标 `idx`）；`intervals` 按左端点升序排序，指针 $i = 0$。
2. **对每个查询 $q$（升序）**：
   - **入场循环**：只要 $i < n$ 且 $l_i \le q$，把 $(r_i - l_i + 1,\ r_i)$ 入堆，$i{+}{+}$。
   - **弹出循环**：只要堆非空且堆顶的 $r < q$，弹出堆顶（永久失效）。
   - **取答案**：堆非空则 $ans[idx] = $ 堆顶长度；否则 $ans[idx] = -1$。
3. 所有查询处理完后返回 `ans`。

### 3.4 示例演算

![示例演算过程](images/wc239_q4_walkthrough.svg)

以示例 1 为例（区间已按 $l$ 排序为 `[1,4], [2,4], [3,6], [4,4]`，查询升序 `2,3,4,5`）：

- $q=2$：`[1,4]`、`[2,4]` 入堆；堆顶 $(3, [2,4])$，$r=4 \ge 2$ → 答案 3。
- $q=3$：`[3,6]` 入堆；堆顶仍 $(3, [2,4])$，$r=4 \ge 3$ → 答案 3。
- $q=4$：`[4,4]` 入堆；新堆顶 $(1, [4,4])$，$r=4 \ge 4$ → 答案 1。
- $q=5$：无新入场；$(1,r{=}4)$、$(3,r{=}4)$、$(4,r{=}4)$ 依次弹出（$r < 5$ 永久失效）；堆顶 $(4, [3,6])$，$r=6 \ge 5$ → 答案 4。

最终按原下标拼回 `[3,3,1,4]`，与期望一致。

## 4. 算法细节

1. **离线排序的两种顺序**：
   - 查询排序后需还原：排序时保存 `(q, idx)` 二元组（或对下标数组按查询值排序），答案写入 `ans[idx]`。
   - 区间按 $l_i$ 升序即可（$l_i$ 相同时顺序无关紧要，反正都会入堆）。
2. **堆元素设计**：堆中存 $(len, right)$ 二元组，**比较键是 `len`**，`right` 只用于失效判断。C++ 用 `priority_queue<pair<int,int>, vector<pair<int,int>>, greater<>>`；Python 用元组直接进 `heapq`。
3. **两个循环的顺序**：先入场、后弹出。弹出条件是 `堆顶.right < q`；由于弹出的判断对象始终是当前堆顶，每个失效区间都会被正确清理。
4. **为什么弹出的堆顶一定永久失效**：查询升序保证后续 $q' \ge q$，而堆顶 $r < q \le q'$，后续也不可能覆盖，删除无损。
5. **均摊计数**：每个区间入堆一次、至多弹出一次；指针 $i$ 只前进。全部堆操作总量 $O(n)$ 次，每次 $O(\log n)$。

## 5. 正确性证明

**引理 1（失效的永久性）**：设查询按升序处理，当前查询为 $q$。若区间 $[l, r]$ 满足 $r < q$，则它不覆盖任何后续查询 $q' \ge q$。

**证明**：覆盖 $q'$ 需要 $l \le q' \le r$。由 $q' \ge q > r$ 得 $q' > r$，与 $q' \le r$ 矛盾。故该区间从此永远无效，弹出丢弃不影响任何后续答案。∎

**引理 2（入堆的完备性）**：处理查询 $q$ 的入场循环结束后，所有满足 $l \le q$ 的区间都已在堆中或已被弹出，且被弹出的必然满足 $r < q$（即不属于覆盖 $q$ 的区间）。

**证明**：对查询序号归纳。初始堆空、$i = 0$。处理 $q$ 时，入场循环把排序后前缀中所有 $l \le q$ 的区间推入堆——因为区间按 $l$ 升序，该前缀是连续的，指针 $i$ 停在第一个 $l > q$ 的位置。后续查询 $q'' \ge q$ 时，满足 $q < l \le q''$ 的区间位于 $i$ 之后，会被该轮入场循环推入；先前已入堆的区间不会丢失（堆只增加或按引理 1 的条件弹出）。∎

**引理 3（堆中恰为活跃集）**：入场、弹出两个循环结束后，堆中元素恰为活跃集 $S(q) = \{\, [l, r] : l \le q \le r \,\}$。

**证明**：由引理 2，所有 $l \le q$ 的区间都被堆持有过；弹出只移除 $r < q$ 的区间。于是堆中 = $\{l \le q\} \setminus \{r < q\} = \{l \le q \le r\} = S(q)$。∎

**定理**：算法对每个查询 $q$ 返回 $\min\{\, r_i - l_i + 1 : l_i \le q \le r_i \,\}$；活跃集为空时返回 $-1$。

**证明**：由引理 3，两个循环结束后堆中恰为覆盖 $q$ 的全体区间。小根堆以长度为键，堆顶即活跃集中长度最小者，即所求最小值。堆空 $\iff S(q) = \varnothing$，此时无区间覆盖 $q$，输出 $-1$。∎

## 6. 复杂度分析

- **时间复杂度**：$O((n + q) \log(n + q))$
  - 区间排序 $O(n \log n)$，查询（下标）排序 $O(q \log q)$。
  - 每个区间入堆一次、至多弹出一次，堆操作共 $O(n)$ 次、每次 $O(\log n)$。
  - 指针 $i$ 与每个查询的主循环均为均摊 $O(1)$ 的推进。
- **空间复杂度**：$O(n + q)$
  - 堆最坏存全部 $n$ 个区间；查询下标数组与答案数组 $O(q)$。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    vector<int> minInterval(vector<vector<int>>& intervals, vector<int>& queries) {
        int n = intervals.size(), m = queries.size();
        sort(intervals.begin(), intervals.end());  // 按左端点升序

        vector<int> order(m);
        iota(order.begin(), order.end(), 0);
        sort(order.begin(), order.end(),
             [&](int a, int b) { return queries[a] < queries[b]; });

        priority_queue<pair<int, int>, vector<pair<int, int>>, greater<>> pq;  // (len, right)
        vector<int> ans(m, -1);
        int i = 0;
        for (int idx : order) {
            int q = queries[idx];
            while (i < n && intervals[i][0] <= q) {
                pq.emplace(intervals[i][1] - intervals[i][0] + 1, intervals[i][1]);
                ++i;
            }
            while (!pq.empty() && pq.top().second < q) {
                pq.pop();
            }
            if (!pq.empty()) {
                ans[idx] = pq.top().first;
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def minInterval(self, intervals: List[List[int]], queries: List[int]) -> List[int]:
        intervals.sort(key=lambda x: x[0])

        order = sorted(range(len(queries)), key=lambda i: queries[i])

        heap = []  # (len, right)
        ans = [-1] * len(queries)
        i = 0
        for idx in order:
            q = queries[idx]
            while i < len(intervals) and intervals[i][0] <= q:
                l, r = intervals[i]
                heapq.heappush(heap, (r - l + 1, r))
                i += 1
            while heap and heap[0][1] < q:
                heapq.heappop(heap)
            if heap:
                ans[idx] = heap[0][0]
        return ans
```

## 8. 边界情况与易错点

1. **必须离线**：逐个在线处理无法利用"查询升序"的单调性，退化为 $O(nq) = 10^{10}$ 超时。重排查询后记得**按原下标写回** `ans[idx]`，直接按排序后顺序输出是最常见的错误。
2. **堆的两个维度别混淆**：排序键是**长度**，失效判断是**右端点**。若按 `right` 建小根堆，堆顶不保证长度最小，答案会错。
3. **弹出循环不可省略**：不弹出失效区间时，堆顶可能是"长度很短但早已不覆盖 $q$"的区间（如示例 1 的 `[4,4]` 对 $q=5$），导致答案偏小。
4. **溢出**：$r_i - l_i + 1 \le 10^7$、坐标 $\le 10^7$，`int` 完全够用，无需 `long long`。
5. **相同查询值重复出现**：升序后相邻处理，第二次入场循环不推进（区间已全部入堆）、弹出条件同样成立，逻辑天然正确。
6. **完全相同的重复区间**：会重复入堆，堆顶取最小不受影响，无需去重。
7. **单点区间**：$l = r$（长度 1）与"所有区间都不覆盖"（输出 $-1$）都要在脑内过一遍（见示例 3）。
