# LeetCode 具有所有最深节点的最小子树 题解

## 1. 题目概述

- **标题 / 题号**：具有所有最深节点的最小子树（#865，medium）
- **链接**：https://leetcode.cn/problems/smallest-subtree-with-all-the-deepest-nodes/
- **来源**：LeetCode 第 92 场周赛 Q2
- **难度**：中等
- **标签**：树、深度优先搜索、广度优先搜索、最近公共祖先、树形 DP

**题意**：给定根为 `root` 的二叉树，结点的**深度**是它到根的距离（根深度为 0）。找出整个树中深度最大的那些结点（**最深结点**），返回**包含所有这些最深结点的最小子树**的根。

一个结点的子树 = 它自身加上它的全部后代。所以「最小子树」的根，本质上是所有最深结点的**最近公共祖先**（LCA）——要求根尽可能深，自然就最小。

**约束**：

- 结点数在 $[1, 500]$ 范围内
- $0 \le \text{Node.val} \le 500$，每个结点的值互不相同
- 返回的是结点（判题器按层序序列化比较）

## 2. 示例

**示例 1**

```text
输入：root = [3,5,1,6,2,0,8,null,null,7,4]
输出：[2,7,4]
解释：最深结点是 7 和 4（深度均为 3）。结点 3、5、2 的子树都包含它们，
     但 2 的子树最小（只有 2、7、4），所以返回结点 2。
```

**示例 2**

```text
输入：root = [1]
输出：[1]
解释：根结点本身就是唯一的最深结点，答案是它自己。
```

**示例 3**

```text
输入：root = [0,1,3,null,2]
输出：[2]
解释：树中唯一最深结点是 2（路径 0 → 1 → 2），最小子树就是叶子 2 本身。
```

## 3. 解题思路

### 3.1 暴力思路

最直白的分两步：先遍历一次求出每个结点的深度，收集所有最深结点集合 $S$；再求 $S$ 中所有结点的 LCA（可以任取一个最深结点 $u$，把 $u$ 到根的路径标出来，然后让其他最深结点依次「向上爬直到落在已标路径上」）。单次求 LCA 是 $O(h)$，整体 $O(n \cdot |S|)$ 最坏 $O(n^2)$。$n \le 500$ 时能过，但既不优雅也容易写错（向上爬的边界、深度对齐都容易出 bug）。

### 3.2 核心观察：一次后序遍历同时带回「高度」和「答案」

![递归契约：dfs(v) 返回（子树高度, 该子树内的答案结点）](images/wc92_q2_pair_dfs.svg)

把「子树高度」定义为：空子树高度 0，叶子高度 1，即

$$h(v) = 1 + \max(h(v.\text{left}),\, h(v.\text{right}))$$

对每个结点 $v$，让递归返回一个二元组 $(h, cand)$，其中 $cand$ 是「包含 $v$ 子树内全部最深结点的最小子树」的根。合并左右两份结果时只有三种情况：

- $h_L > h_R$：最深结点全在左子树，答案继承左边，返回 $(h_L + 1,\ cand_L)$；
- $h_R > h_L$：对称，返回 $(h_R + 1,\ cand_R)$；
- $h_L = h_R$：最深结点**同时出现在两侧**，任何包含它们的子树都必须以 $v$ 为根，返回 $(h_L + 1,\ v)$。

其中第三种情况是关键：左右两侧的最高点一样高，说明两侧各存在至少一个最深结点，而跨两侧的最近公共祖先只能是 $v$ 自己。

### 3.3 算法流程

```text
dfs(v):
    若 v 为空：返回 (0, null)
    (hL, candL) = dfs(v.left)
    (hR, candR) = dfs(v.right)
    若 hL > hR：返回 (hL + 1, candL)
    若 hR > hL：返回 (hR + 1, candR)
    否则：返回 (hL + 1, v)

主函数：返回 dfs(root).cand
```

一次遍历、无回溯、无额外数据结构。

### 3.4 示例演算

![示例：最深结点是 7 和 4，它们的最小公共祖先是结点 2](images/wc92_q2_example_result.svg)

| 7 | (0, null) | (0, null) | (1, 7) |

## 4. 算法细节

1. **高度的基准要统一**：空树 0、叶子 1 是最省事的一套；即使改成「空树 −1、叶子 0」，比较逻辑不变、答案也不变，只要前后一致。
2. **返回类型的顺序**：C++ 用 `pair<int, TreeNode*>`，Python 用元组 `(h, node)`；解构赋值（structured binding）能让代码非常干净。
3. **空结点返回 `(0, nullptr)`**：这样叶子结点会走「两侧相等」分支，返回自己，天然正确。
4. **只比较高度，不比较结点值**：题目与结点的值无关，值仅用于判题器序列化。
5. **答案唯一性**：如果左右同高，两侧都存在最深结点，$v$ 是不二之选；不存在「两个不同的最小子树」的歧义。
6. **不需要求深度**：全程只用到子树高度，深度信息完全省略，这也是比暴力做法更省的原因。

## 5. 正确性证明

记 $h(v)$ 为 $v$ 子树的高度（空为 0），记 $D(v)$ 为 $v$ 子树中**最深结点**的集合（即子树内高度最大的那些结点；空子树时为空集）。记 $\text{best}(v)$ 为「包含 $D(v)$ 全部结点的最小子树」的根。

**引理 1（高度递推）**：$h(v) = 1 + \max(h(v_L), h(v_R))$；且当 $h(v_L) > h(v_R)$ 时 $D(v) = D(v_L)$，当 $h(v_R) > h(v_L)$ 时 $D(v) = D(v_R)$，当 $h(v_L) = h(v_R)$ 时 $D(v) = D(v_L) \cup D(v_R)$。

**证明**：$v$ 子树中任一点到 $v$ 的路径必经过某个孩子，故高度为两侧较大者加 1。最深结点到 $v$ 的距离等于 $h(v) - 1$：若某侧高度严格更大，则只有该侧能提供这个最大距离，另一侧所有结点到 $v$ 的距离都更小，故 $D(v)$ 等于较深那侧的集合；若两侧相等，则两侧各自的最高层结点到 $v$ 的距离都等于 $h(v) - 1$，故并集。∎

**引理 2（$h_L = h_R$ 时答案就是 $v$）**：若 $h(v_L) = h(v_R) = t$，则 $\text{best}(v) = v$。

**证明**：由引理 1，$D(v) = D(v_L) \cup D(v_R)$，两部分都非空（$t \ge 0$ 时每侧至少有一个最深结点：$t = 0$ 表示该侧为空，此时两侧都空，即 $v$ 是叶子，$D(v) = \{v\}$）。任何以 $v$ 子树内某结点 $u$ 为根的子树若包含某个 $D(v_L)$ 中的结点，则 $u$ 必须是它的祖先；同理对 $D(v_R)$。若 $u \ne v$，则 $u$ 必属于左子树或右子树之一，无法同时是另一侧结点的祖先，矛盾。故 $u = v$，最小性显然。∎

**引理 3（$h_L > h_R$ 时答案继承左侧）**：若 $h(v_L) > h(v_R)$，则 $\text{best}(v) = \text{best}(v_L)$。

**证明**：由引理 1，$D(v) = D(v_L)$。任何包含 $D(v)$ 的子树都以 $D(v_L)$ 中某结点的祖先为根；在 $v$ 子树范围内，这样的根要么是 $v$ 本身，要么在左子树内且是 $D(v_L)$ 全部结点的祖先。后者中最小的正是 $\text{best}(v_L)$（归纳假设），它比 $v$ 更深，故更小。∎

**定理**：算法对根返回的 `cand` 等于包含整棵树全部最深结点的最小子树的根。

**证明**：对树高归纳。叶子情形，算法返回 $(1, v)$，$D(v)=\{v\}$，最小子树根为 $v$，成立。设左右子树结论均成立。三种情形由引理 2、3 及其对称情形分别给出 $\text{best}(v)$，与算法返回值一致。故根结点处返回的 `cand` 即为答案。∎

## 6. 复杂度分析

- **时间**：$O(n)$。每个结点被访问一次，合并左右结果只做常数次比较与赋值。
- **空间**：$O(h)$ 的递归栈（$h$ 为树高，最坏 $O(n)$）；除返回值外无额外容器，若不计递归栈则为 $O(1)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    TreeNode* subtreeWithAllDeepest(TreeNode* root) {
        return dfs(root).second;
    }

private:
    pair<int, TreeNode*> dfs(TreeNode* node) {
        if (!node) return {0, nullptr};
        auto [ld, left] = dfs(node->left);
        auto [rd, right] = dfs(node->right);
        if (ld > rd) return {ld + 1, left};
        if (rd > ld) return {rd + 1, right};
        return {ld + 1, node};
    }
};
```

### Python

```python
class Solution:
    def subtreeWithAllDeepest(self, root: TreeNode) -> TreeNode:
        def dfs(node):
            if node is None:
                return 0, None
            ld, left = dfs(node.left)
            rd, right = dfs(node.right)
            if ld > rd:
                return ld + 1, left
            if rd > ld:
                return rd + 1, right
            return ld + 1, node

        return dfs(root)[1]
```

## 8. 边界情况与易错点

1. **单结点树**：`root` 是叶子，返回它自己（示例 2）。若误把空树高度写成 1，会对单结点返回 `(2, null)`，出现空指针。
2. **只有一侧有最深结点**：必须是「继承更深那侧的答案」，而不是「返回当前结点」；示例 3 的链条 `0 → 1 → 2` 专门考这一点。
3. **所有叶子同深度**：例如满二叉树，答案应是**根**（两侧同高一路向上），不要返回某个叶子。
4. **误把「深度」与「高度」混用**：全程只需要子树高度（自底向上），不要把根的深度、结点的层号混进来。
5. **返回值顺序**：`(h, node)` 与 `(node, h)` 不要写反，解构赋值时最容易错位。
6. **返回的是结点而非值**：判题器会序列化整棵子树，返回 `node.val` 会直接类型错误。
