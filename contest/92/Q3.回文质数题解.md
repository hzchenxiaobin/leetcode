# LeetCode 回文质数 题解

## 1. 题目概述

- **标题 / 题号**：回文质数（#866，medium）
- **链接**：https://leetcode.cn/problems/prime-palindrome/
- **来源**：LeetCode 第 92 场周赛 Q3
- **难度**：中等
- **标签**：数学、数论、素性测试

**题意**：给定整数 $n$，返回**大于或等于 $n$ 的最小回文质数**。回文数指正着读与倒着读相同的数；质数指恰好有两个除数 $1$ 与自身的数（$1$ 不是质数）。题目保证答案存在，且落在 $[2,\,2\times 10^8]$ 内。

**约束**：

- $1 \le n \le 10^8$
- 答案 $\le 2 \times 10^8$

## 2. 示例

**示例 1**

```text
输入：n = 6
输出：7
解释：6 不是质数；7 既是回文数又是质数，且 ≥ 6。
```

**示例 2**

```text
输入：n = 8
输出：11
解释：8 不是质数，9 不是质数，10 不是回文；11 是回文质数。
```

**示例 3**

```text
输入：n = 13
输出：101
解释：14..99 中的回文数只有 22、33、…、99，全是 11 的倍数；
     三位数里最小的回文质数是 101。
```

**示例 4（补充）**

```text
输入：n = 9999999
输出：100030001
解释：9999999 之后的所有 8 位回文数都不是质数（全是 11 的倍数），
     答案直接跳到 9 位数 100030001，中间隔着约 9 × 10^7 个整数。
     这个例子说明「从 n 开始逐个整数试」有多危险。
```

## 3. 解题思路

### 3.1 暴力思路

最直白的做法是从 $x = n$ 开始逐个整数判断「是回文且是质数」。质数判定用试除法到 $\sqrt{x}$，单次约 $1.4\times 10^4$ 次取模。

问题出在**间隔**上。示例 4 中 $n = 9\,999\,999$，答案是 $100030001$，需要跨过约 $9\times 10^7$ 个整数；即使只用 $O(\log x)$ 的代价判回文，也要 $7\times 10^8$ 量级的操作，质数判定更是天文数字。暴力法必然超时。

所以要换的不是「怎么判」，而是「枚举什么」：**回文数的数量远少于整数的数量**，直接枚举回文数即可。

### 3.2 核心观察：只枚举回文数，且只枚举奇数位

![构造回文数：只枚举「前半段」，后半段照镜子补齐](images/wc92_q3_half_build.svg)

**观察一：回文数由前半段唯一确定。** 长度为 $L$ 的回文数，只要定下前 $\lceil L/2 \rceil$ 位，后一半就是它的镜像。于是候选集从 $10^8$ 个整数缩到约 $10^5$ 个回文数（位数 1、3、5、7、9 合计约 $10^5$ 个）。

**观察二：偶数位回文数必是 11 的倍数。**

![偶数位回文数一定是 11 的倍数，只有 11 本身是质数](images/wc92_q3_even_11.svg)

以四位回文 $\overline{abba}$ 为例：

$$\overline{abba} = 1000a + 100b + 10b + a = 1001a + 110b = 11\,(91a + 10b)$$

所以除 $11$ 本身外，所有偶数位回文数都是合数，可以直接整段跳过。这条结论把候选量再砍掉一大半（偶数位长度 2、4、6、8 全部不枚举）。

### 3.3 算法流程

![搜索顺序：按位数从小到大，只走奇数位（长度 2 特判）](images/wc92_q3_length_order.svg)

```text
1. 若 n <= 11：在 [max(n,2), 11] 中找第一个「回文且质数」的数并返回
   （2、3、5、7、11 都是回文质数，一定命中）
2. s = str(n)，L = 若 len(s) 为奇数则 len(s)，否则 len(s) + 1
3. while L <= 9:
       half_len = (L + 1) // 2
       low = 10^(half_len - 1)
       若 L 等于 len(s)：low = max(low, n 的前 half_len 位)
       for half in [low, 10^half_len):
           pal = 由 half 构造长度为 L 的回文数
           若 pal >= n 且 pal 是质数：返回 pal
       L += 2
4. 返回 -1（题目保证不会走到）
```

要点：**位数递增 + 同位数内 half 递增**，因此生成的 `pal` 严格递增，第一个质数就是答案。

### 3.4 示例演算

以 $n = 13$ 为例：

| 阶段 | 候选 | 判定 | 结果 |
|------|------|------|------|
| $n \le 11$？ | — | 13 > 11，跳过特判 | 继续 |
| 长度 2（偶数位） | 22, 33, …, 99 | 全是 11 的倍数，**整段跳过** | 跳过 |
| 长度 3，half = 10 | 101 | $101 \ge 13$ 且 101 是质数 | 返回 101 |

再看 $n = 6$：走特判分支，$6, 7$ 中 7 既是回文又是质数，返回 7。$n = 8$ 时依次检查 $8, 9, 10, 11$，只有 11 合格，返回 11。

对 $n = 9\,999\,999$：8 位全部跳过，9 位从 $half = 10000$ 开始构造出 $100000001$，逐个数试到 $100030001$（对应 $half = 10003$）才命中质数。

## 4. 算法细节

1. **$n \le 11$ 特判**：此时答案必在 $\{2,3,5,7,11\}$ 中，直接小范围枚举最省事；否则长度计算的边界会出现「长度 1 的 half 从 1 开始」之类的琐碎讨论。
2. **回文构造公式**：长度为奇数的回文 $= half + \text{reverse}(half[:-1])$。注意去掉末尾字符，否则中间位会重复。Python 里 `hs + hs[:-1][::-1]` 最简洁；C++ 用「乘 10 取模」逐位补。
3. **起始 half**：本位数（$L = \text{len}(s)$）时取 $\max(10^{half\_len-1},\ n \text{ 的前 } half\_len \text{ 位})$，保证不漏掉刚好落在 $n$ 附近的候选；更长的位数从 $10^{half\_len-1}$ 起。
4. **`pal >= n` 过滤**：起始 half 由 $n$ 截断得到时，构造出的回文可能略小于 $n$（例如 $n$ 前几位相同但低位更大），需要显式过滤。
5. **质数判定**：先排除 $< 2$ 与偶数，再从 3 开始只试奇数因子，循环条件 $d \cdot d \le x$，用 `long long` 防溢出。
6. **上界 9 位**：题目保证答案 $\le 2\times 10^8$，9 位回文里只有首位为 1 的不超过该上界，所以枚举到长度 9 足够。

## 5. 正确性证明

**引理 1（偶数位回文被 11 整除）**：设 $x$ 是位数为偶数 $2L$（$L \ge 1$）的回文数，则 $11 \mid x$。

**证明**：设 $x$ 的前 $L$ 位依次为 $a_1, a_2, \ldots, a_L$（$a_1 \ne 0$），由回文性，其十进制展开为

$$x = \sum_{i=1}^{L} a_i\left(10^{\,2L-i} + 10^{\,i-1}\right)$$

因为 $10 \equiv -1 \pmod{11}$，故 $10^k \equiv (-1)^k \pmod{11}$。于是

$$10^{\,2L-i} + 10^{\,i-1} \equiv (-1)^{2L-i} + (-1)^{i-1} = (-1)^{i} + (-1)^{i-1} = 0 \pmod{11}$$

每一项都被 11 整除，故 $11 \mid x$。∎

**推论 1**：位数 $\ge 2$ 的偶数位回文数都是合数；偶数位回文质数只有 $11$（此时 $L = 1$、$x = 11$，且 11 是质数）。

**引理 2（构造是双射）**：固定长度 $L$，令 $h$ 取遍所有 $L$ 位数（$10^{L-1} \le h < 10^{L}$）时，按「奇偶分别镜像」构造出的 $\text{pal}(h)$ 恰好是全部 $2L$ 位与 $2L-1$ 位回文数，一一对应。

**证明**：回文数的后半段完全由前半段决定，故给定前 $L$ 位只有唯一回文数；反之每个这样的回文数由它的前 $L$ 位唯一确定。构造式正是把前 $L$ 位按逆序补到右侧（奇数长度时去掉已作为中间位的最后一位），故为双射。∎

**引理 3（构造保持单调）**：同长度下 $h_1 < h_2 \Rightarrow \text{pal}(h_1) < \text{pal}(h_2)$。

**证明**：设补 $k$ 位镜像，则 $\text{pal}(h) = h \cdot 10^{k} + r(h)$，其中 $0 \le r(h) < 10^{k}$。于是

$$\text{pal}(h_1) \le h_1 \cdot 10^k + 10^k - 1 < (h_1 + 1)\cdot 10^k \le h_2 \cdot 10^k \le \text{pal}(h_2)$$

严格单调。∎

**引理 4（试除判定正确）**：函数 `is_prime(x)` 返回 `true` 当且仅当 $x$ 是质数。

**证明**：若 $x$ 合数，则存在因子 $d$ 满足 $2 \le d \le \sqrt{x}$，循环必然命中并返回 `false`；若 $x$ 质数，则 $[2,\sqrt{x}]$ 内无因子，循环结束返回 `true`。∎

**定理**：算法返回不小于 $n$ 的最小回文质数。

**证明**：由推论 1，所有回文质数要么是 $11$，要么位数是奇数；算法对 $n \le 11$ 直接扫描 $[n, 11]$，覆盖了前者。对 $n > 11$，算法从 $\ge n$ 的最小可能位数开始，按长度递增、同长度按 `half` 递增枚举（引理 2 保证不重不漏，引理 3 保证递增），因此生成的候选序列正是「所有 $\ge n$ 的奇数位回文数」的递增序列；对每个候选先过滤 $<n$ 者，再用引理 4 判定质数，返回的第一个质数必是全体回文质数中 $\ge n$ 的最小者。∎

## 6. 复杂度分析

- **时间**：设枚举的候选个数为 $C$、探测到的最大值为 $P$，则 $O(C\sqrt{P})$。奇数位长度 1、3、5、7、9 的回文总数上界约 $10^5$，$\sqrt{2\times10^8} \approx 1.4\times10^4$，理论最坏 $O(10^9)$；但绝大多数候选会在试除的最初几步被 2、3、5、7 等小素数淘汰，且答案通常落在起始位置附近几个候选内。实测最坏输入（如 $n = 9\,999\,999$）在本机约 10 ms 量级。
- **空间**：$O(1)$。只用常数个整数变量与定长字符串，与 $n$ 无关。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int primePalindrome(int n) {
        if (n <= 11) {
            for (int x = max(n, 2); x <= 11; x++) {
                if (isPrime(x)) return x;
            }
        }

        int len = (int)to_string(n).size();
        if (len % 2 == 0) len++;

        for (; len <= 9; len += 2) {
            int half = (len + 1) / 2;
            long long base = 1;
            for (int i = 0; i < half - 1; i++) base *= 10;
            long long low = base;
            if (len == (int)to_string(n).size()) low = max(low, (long long)n / base);
            long long high = base * 10;

            for (long long h = low; h < high; h++) {
                long long pal = h;
                for (long long t = h / 10; t > 0; t /= 10) pal = pal * 10 + t % 10;
                if (pal >= n && isPrime(pal)) return (int)pal;
            }
        }
        return -1;
    }

private:
    bool isPrime(long long x) {
        if (x < 2) return false;
        if (x % 2 == 0) return x == 2;
        for (long long d = 3; d * d <= x; d += 2) {
            if (x % d == 0) return false;
        }
        return true;
    }
};
```

### Python

```python
class Solution:
    def primePalindrome(self, n: int) -> int:
        def is_prime(x: int) -> bool:
            if x < 2:
                return False
            d = 2
            while d * d <= x:
                if x % d == 0:
                    return False
                d += 1
            return True

        if n <= 11:
            for x in range(max(n, 2), 12):
                if str(x) == str(x)[::-1] and is_prime(x):
                    return x

        s = str(n)
        length = len(s) if len(s) % 2 == 1 else len(s) + 1
        while length <= 9:
            half_len = (length + 1) // 2
            low = 10 ** (half_len - 1)
            if length == len(s):
                low = max(low, int(s[:half_len]))
            for half in range(low, 10 ** half_len):
                hs = str(half)
                pal = int(hs + hs[:-1][::-1])
                if pal >= n and is_prime(pal):
                    return pal
            length += 2
        return -1
```

## 8. 边界情况与易错点

1. **$n \le 11$**：$n = 1$ 时答案是 2（质数但不是奇数位回文，走特判分支才不会漏）；$n = 8$ 时答案是 11。
2. **$n = 12$**：长度 2 被整段跳过，正确进入 3 位枚举，答案是 101，不要返回 22 之类的合数。
3. **不要逐个整数试**：示例 4 的间隔达 $9\times10^7$，会直接超时；必须按「枚举回文」的思路。
4. **镜像时重复中间位**：奇数长度构造要用 `half[:-1]` 去掉末位再反转，写成 `half[::-1]` 会得到 `123321` 这类偶数位结果，位数就错了。
5. **起始 half 截断**：由 $n$ 截取前几位时，构造出的回文可能小于 $n$，必须保留 `pal >= n` 的显式判断。
6. **质数判定的平方根上界用乘法**：写成 `d * d <= x` 而不是 `sqrt(x)`，既避免浮点误差也更快；$x$ 接近 $10^9$ 时 `d * d` 请用 `long long`。
7. **返回值类型**：答案可达 $10^8$ 以上，C++ 用 `int` 足够（$<2.1\times10^9$），但中间的 `pal` 构造建议用 `long long` 防溢出后再转回。
