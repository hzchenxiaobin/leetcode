# LeetCode 赢得比赛需要的最少训练时长 题解

## 1. 题目概述

- **标题 / 题号**：赢得比赛需要的最少训练时长（#2383，easy）
- **链接**：https://leetcode.cn/problems/minimum-hours-of-training-to-win-a-competition/
- **来源**：LeetCode 第 307 场周赛 Q1
- **难度**：简单
- **标签**：贪心、数组、模拟

**题意**：
你有初始精力 $initialEnergy$ 与初始经验 $initialExperience$，需**依次**对战 $n$ 个对手，第 $i$ 个对手的精力和经验为 $energy[i]$、$experience[i]$。对战第 $i$ 个对手时，你的精力和经验必须**都严格超过**对手才能获胜；获胜后经验**增加** $experience[i]$、精力**减少** $energy[i]$。赛前可以训练若干小时，每训练 1 小时可任选精力 +1 或经验 +1。求击败全部 $n$ 个对手所需的最少训练小时数。

**约束**：

- $n = energy.length = experience.length$
- $1 \le n \le 100$
- $1 \le initialEnergy, initialExperience, energy[i], experience[i] \le 100$

> 💡 **审题关键**：两条对称却方向相反的动态规则——**精力只减不增**（每场净耗 $energy[i]$），**经验只增不减**（每场净赚 $experience[i]$）。两条规则一个"看总账"、一个"看逐场"，分别决定了两种完全不同的贪心口径；另外"严格超过"意味着相等即败，差 1 也要补。

## 2. 示例

**示例 1**

```text
输入：initialEnergy = 5, initialExperience = 3, energy = [1,4,3,2], experience = [2,6,3,1]
输出：8
解释：先训练 6 小时精力（5 → 11），再训练 2 小时经验（3 → 5）。
     逐场：11>1,5>2 → 10,7；10>4,7>6 → 6,13；6>3,13>3 → 3,16；3>2,16>1 → 1,17。
     共 8 小时，可证明不存在更小答案。
```

**示例 2**

```text
输入：initialEnergy = 2, initialExperience = 4, energy = [1], experience = [3]
输出：0
解释：精力 2>1、经验 4>3，无需任何训练。
```

**示例 3**（覆盖"相等即败"的边界）

```text
输入：initialEnergy = 1, initialExperience = 1, energy = [1], experience = [1]
输出：2
解释：精力 1 不严格大于 1，需补 1 小时到 2；经验同理补 1 小时到 2，共 2 小时。
```

## 3. 解题思路

### 3.1 暴力思路

数据范围极小（$n \le 100$，值域 $\le 100$），答案上界约 $2 \times 10^4$。可以二分/枚举训练总时长再暴力模拟对局验证，甚至枚举"分给精力 $t_E$ 小时、分给经验 $t - t_E$ 小时"的所有组合——$O(T \cdot n)$ 或 $O(T^2 \cdot n)$ 都能过。**比赛时作为签到题这样写完全没问题，但毫无沉淀**；真正的价值在于看清两条规则各自的"记账方式"，把答案直接算出来。

### 3.2 核心观察：精力看总账，经验看逐场

![核心观察：精力只减不增看总账，经验只增不减看逐场](images/min_training_concept.svg)

两条规则的对称性被方向打破：

**观察一（精力 ⇒ 只需看总和）**：精力单调递减，打完前 $i$ 场后精力恰为 $(E_0 + t_E) - \sum_{j<i} energy[j]$（$E_0$ 为初始精力，$t_E$ 为分给精力的训练小时）。第 $i$ 场开打前的约束

$$E_0 + t_E - \sum_{j<i} energy[j] > energy[i] \iff E_0 + t_E > \sum_{j \le i} energy[j]$$

右端是**前缀和**，随 $i$ 单调不减，故最紧的约束在最后一场：$E_0 + t_E > S$（$S = \sum_i energy[i]$）。于是精力训练小时**一锤定音**：

$$t_E = \max(0,\; S + 1 - E_0)$$

**观察二（经验 ⇒ 逐场补差恰好够用）**：经验单调递增，赢下第 $j$ 场会"滚雪球"式地抬高后续场次的底子。设打到第 $i$ 场前的经验为 $cur$：若 $cur > experience[i]$ 直接白嫖通过；否则恰补 $experience[i] - cur + 1$ 小时把经验抬到 $experience[i] + 1$。**多补不必要**——补到"刚好严格超过"后，后面每场的门槛要么已够、要么由本场胜利的滚雪球自动垫高（详见 §5 引理 4 的下界证明：逐场补差之和恰等于全局下界）。

> 💡 **一句话**：精力是"一次性充值"，充值额 = 总消费 + 1 − 余额；经验是"随用随充"，每场只补到刚好压线。两者独立，答案直接相加。

### 3.3 算法流程

![算法流程：精力一步公式，经验逐场贪心补差](images/min_training_flow.svg)

| 步骤 | 操作 | 说明 |
|------|------|------|
| ① 算总消耗 | $S \leftarrow \sum_i energy[i]$ | 精力总账 |
| ② 精力充值 | 若 $E_0 \le S$，训练 $t_E = S + 1 - E_0$ 小时 | 保证 $E_0 + t_E > S$，一场公式收工 |
| ③ 逐场判定 | 对第 $i$ 场：若 $cur \le experience[i]$，补 $experience[i] - cur + 1$ 小时，$cur \leftarrow experience[i] + 1$ | 恰好严格超过 |
| ④ 经验入账 | $cur \leftarrow cur + experience[i]$ | 赢下本场，滚雪球 |
| ⑤ 终止 | $i$ 走完 $n$ 场，返回 $t_E + \sum$ 逐场补差 | 精力与经验独立相加 |

### 3.4 示例演算

![示例演算：6 小时充精力 + 第 1 场前补 2 小时经验](images/min_training_walkthrough.svg)

以**示例 1**（$E_0 = 5$，初始经验 $3$，$energy = [1,4,3,2]$，$experience = [2,6,3,1]$）演算。精力：$S = 10$，$5 \le 10$ → 充 $10 + 1 - 5 = 6$ 小时，开打精力 $11$。经验逐场：

| $i$ | 对手经验 | 战前经验 | 判定 | 补训练 | 战后经验 |
|-----|---------|---------|------|--------|---------|
| 0 | 2 | 3 | $3 > 2$ ✓ | 0 | $3 + 2 = 5$ |
| 1 | 6 | 5 | $5 \le 6$ ✗ | $6-5+1=2$ | $7 + 6 = 13$ |
| 2 | 3 | 13 | $13 > 3$ ✓ | 0 | $13 + 3 = 16$ |
| 3 | 1 | 16 | $16 > 1$ ✓ | 0 | $16 + 1 = 17$ |

精力轨迹 $11 \to 10 \to 6 \to 3 \to 1$，每场战前均严格大于对手精力 ✓。总训练 $6 + 2 = 8$ ✓。**示例 2**：$S = 1 < 2$，精力免充；经验 $4 > 3$ 直接过 → $0$ ✓。

## 4. 算法细节

1. **精力为何不用逐场模拟**：训练只能发生在**赛前**，精力训练必然全部叠进初始值；而前缀和约束单调收紧到最后一场，所以 $E_0 + t_E > S$ 一步等价于全部 $n$ 条约束。逐场模拟（减掉 $energy[i]$ 再判）结果相同，但公式版一眼看出无循环。
2. **经验训练的"时间平移"**：训练物理上都在赛前完成，但把"第 $i$ 场前才补的差"视为赛前已补，总量不变、每场判定不变——因为经验单调增，提前补只会让更早的场次判定更容易（更早场次本就通过时无影响）。这正是逐场贪心合法的语义基础。
3. **两统计量独立**：每 1 训练小时只能给精力或经验其一，且精力判定从不依赖经验、经验判定从不依赖精力，故总训练 = 两个独立子问题最优解之和，无权衡空间。
4. **补差公式**：$cur \le experience[i]$ 时补 $experience[i] - cur + 1$（注意 $+1$，严格超过），并把 $cur$ 直接置为 $experience[i] + 1$ 再加 $experience[i]$，避免先加后判的顺序错误。

## 5. 正确性证明

**引理 1（精力下界）**：任意可行方案中，$E_0 + t_E \ge S + 1$（$t_E$ 为分给精力的训练小时数，$S = \sum_i energy[i]$）。

**证明**：考虑最后一场（第 $n-1$ 场）开打前，精力为 $E_0 + t_E - \sum_{j<n-1} energy[j]$，严格超过对手需满足
$$E_0 + t_E - \sum_{j<n-1} energy[j] > energy[n-1] \iff E_0 + t_E > S,$$
整数值即 $E_0 + t_E \ge S + 1$。∎

**引理 2（精力下界充分）**：若 $E_0 + t_E \ge S + 1$，则每场开打前精力均严格超过对手。

**证明**：第 $i$ 场开打前精力为 $E_0 + t_E - \sum_{j<i} energy[j] \ge S + 1 - \sum_{j<i} energy[j] = energy[i] + \sum_{j>i} energy[j] + 1 > energy[i]$。∎

**引理 3（经验下界）**：设 $prefix(i) = \sum_{j<i} experience[j]$，$g_i = experience[i] + 1 - E_x - prefix(i)$（$E_x$ 为初始经验）。任意可行方案的经验训练小时数 $x \ge \max(0,\; \max_i g_i)$。

**证明**：第 $i$ 场开打前经验为 $E_x + x + prefix(i)$（训练全部赛前完成），严格超过对手需 $E_x + x + prefix(i) > experience[i]$，即 $x \ge g_i$ 对每个 $i$ 成立；又 $x \ge 0$，取最大即得。∎

**引理 4（贪心达到下界）**：逐场贪心（不足则恰补到 $experience[i] + 1$）的总补差 $X$ 满足：处理完前 $i$ 场后，$X = \max(0, \max_{j \le i} g_j)$；特别地最终 $X = \max(0, \max_i g_i)$。

**证明**：对 $i$ 归纳。基例 $i$ 为首场前 $X = 0$ 成立。归纳步：贪心在第 $i$ 场的补差为 $d_i = \max(0,\; experience[i] + 1 - cur_i)$，其中 $cur_i = E_x + X + prefix(i)$，故 $d_i = \max(0,\; g_i - X)$，于是新累计 $X' = X + d_i = \max(X, g_i) = \max(0, \max_{j \le i} g_j)$。∎

**定理**：算法返回值 $t_E + X = \max(0, S + 1 - E_0) + \max(0, \max_i g_i)$ 为最少训练小时数。

**证明**：训练小时可任意分配给精力 / 经验，且两组判定约束互不牵连（精力判定只含精力量，经验判定只含经验量），故可行当且仅当两个子方案分别可行，总时长 = 两者之和。由引理 1、2，$\max(0, S + 1 - E_0)$ 是精力子问题的最小解；由引理 3、4，$\max(0, \max_i g_i)$ 是经验子问题的最小解。两者之和即全局最小。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。一次求和（精力总账）+ 一趟扫描（经验逐场判定），每场 $O(1)$。
- **空间复杂度**：$O(1)$。仅若干标量（$S$、$cur$、答案累计），不随 $n$ 增长。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minNumberOfHours(int initialEnergy, int initialExperience,
                         vector<int>& energy, vector<int>& experience) {
        int ans = 0;
        int s = accumulate(energy.begin(), energy.end(), 0);
        if (initialEnergy <= s) ans += s + 1 - initialEnergy;   // 精力：一次性充值
        int cur = initialExperience;
        for (int e : experience) {
            if (cur <= e) {                                     // 经验：不足则恰补压线
                ans += e - cur + 1;
                cur = e + 1;
            }
            cur += e;                                           // 赢下本场，滚雪球
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def minNumberOfHours(self, initialEnergy: int, initialExperience: int,
                         energy: List[int], experience: List[int]) -> int:
        ans = 0
        s = sum(energy)
        if initialEnergy <= s:                    # 精力：一次性充值
            ans += s + 1 - initialEnergy
        cur = initialExperience
        for e in experience:
            if cur <= e:                          # 经验：不足则恰补压线
                ans += e - cur + 1
                cur = e + 1
            cur += e                              # 赢下本场，滚雪球
        return ans
```

## 8. 边界情况与易错点

1. **"严格超过"的 off-by-one**：精力相等（如 $E_0 = 1$，$energy = [1]$）需补 1 小时，判定必须用 `<=`（不严格大于即需补），公式是 $S + 1 - E_0$ 而非 $S - E_0$；经验补差同理带 $+1$，补后 $cur$ 置为 $experience[i] + 1$。
2. **精力训练不能"中途充"**：训练只发生在赛前，精力训练必须整体计入初始值。用逐场模拟写法时若在循环里临时加精力，语义上等价（总量一致），但要清楚它对应的都是"赛前已充"。
3. **经验先判后加**：必须先判定 / 补差，再加 $experience[i]$；顺序写反会把本场胜利的收益错算进战前判定。
4. **单对手**（$n = 1$）：两条公式退化为 $E_0 > energy[0]$、$E_x > experience[0]$，逐一检查即可（示例 2、3）。
5. **数据规模无溢出风险**：$n \le 100$、值域 $\le 100$，$S \le 10^4$，答案上界约 $2 \times 10^4$，`int` / Python 均安全。
6. **精力已充足时不要多充**：$E_0 > S$ 时 $t_E = 0$，`max(0, ·)`（或等价的 `if`）不可省。
