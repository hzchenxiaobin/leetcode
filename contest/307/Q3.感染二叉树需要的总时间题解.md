# LeetCode 感染二叉树需要的总时间 题解

## 1. 题目概述

- **标题 / 题号**：感染二叉树需要的总时间（#2385，medium）
- **链接**：https://leetcode.cn/problems/amount-of-time-for-binary-tree-to-be-infected/
- **来源**：LeetCode 第 307 场周赛 Q3
- **难度**：中等
- **标签**：树、深度优先搜索、广度优先搜索、哈希表、二叉树

**题意**：
给定节点值**互不相同**的二叉树 `root` 与整数 `start`。第 0 分钟，值为 `start` 的节点开始感染；此后**每分钟**，所有「尚未感染」且「与某个已感染节点**相邻**」的节点同时被感染。相邻指有一条边直连——**父子双向**。返回感染整棵树所需的分钟数。

**约束**：

- 节点数 $1 \le n \le 10^5$
- $1 \le \text{Node.val} \le 10^5$，且**互不相同**
- 树中**必存在**值为 `start` 的节点

> 💡 **审题关键**：「相邻」是**对称关系**——子能感染父，父也能感染子。于是这棵「二叉树」在感染规则下就是一张**无向图**；「每分钟感染一层」= 从 `start` 出发的 **BFS 逐层扩张**。谜面是树，谜底是图上的**单源最远点**（离心率）。此题是本场的分水岭：看到「父指针」就稳了，死盯「子树高度」就 WA。

## 2. 示例

**示例 1**

```text
输入：root = [1,5,3,null,4,10,6,9,2], start = 3
输出：4
解释：树形为 1(5,3)、5(∅,4)、3(10,6)、4(9,2)。
     第 0 分钟：3；第 1 分钟：1、10、6；第 2 分钟：5；
     第 3 分钟：4；第 4 分钟：9、2 —— 第 4 分钟整棵树感染完毕。
```

**示例 2**

```text
输入：root = [1], start = 1
输出：0
解释：第 0 分钟唯一节点已被感染，无需再等。
```

**示例 3**（自拟：把感染源换成 `start = 5`，让上行边现形）

```text
输入：root = [1,5,3,null,4,10,6,9,2], start = 5
输出：3
解释：第 0 分钟：5；第 1 分钟：4（右子）与 1（父）同时感染——父边首次登场；
     第 2 分钟：9、2、3；第 3 分钟：10、6。最远点 10/6 距离 5 为 3 条边。
     若误以为感染只往孩子方向走，会答 start 子树高度 h(5) = 2，WA。
```

## 3. 解题思路

### 3.1 暴力思路

逐分钟模拟：维护已感染集合，每分钟**扫描全部节点**，把与感染集相邻且未感染的节点全部标记，直到感染完毕。链形树每分钟恰好只推进一个节点，共 $n$ 分钟、每分钟 $O(n)$ 扫描，总计 $O(n^2) \approx 10^{10}$，$n = 10^5$ 直接超时。瓶颈在「按时间组织」的重复扫描；而每个节点的感染时刻其实是**确定值**——它到 `start` 的边数。改为「按距离组织」，一次遍历即可全部求出。

### 3.2 核心观察：感染时刻 = 无向距离，答案 = start 的离心率

![核心观察：父子边双向可达，感染 = 从 start 出发的 BFS 分层](images/wc307_q3_tree_graph_concept.svg)

三步建模：

1. **边无向化**：每个节点除了左右孩子，还有**父节点**这个邻居。遍历时补上「父指针」，二叉树就补全成一张 $n$ 点 $n-1$ 边的**无向树**（连通、无环）。
2. **时刻 = 距离**：感染每分钟恰沿一条边扩散一格（归纳证明见 §5 引理 1），故节点 $v$ 的感染时刻 $t(v) = \text{dist}(start, v)$。
3. **答案 = 离心率**：整棵树感染完毕的时刻 $= \max_v \text{dist}(start, v)$，即 `start` 在无向树上的**离心率**——也正是**以 `start` 为根重新悬挂**后的树高（换根视角）。

> ⚠️ **读题陷阱**：若把「相邻」悄悄降级成「父亲传孩子」，答案会退化成 `start` 的子树高度。示例 1 的 `start=3` 便能戳穿（子树高度 1，正确答案 4）；但若恰好拿 `start =` 根自测，两种口径给出相同结果，假 AC 极具迷惑性——自测样例必须含 `start ≠` 根的情形。

### 3.3 解法一流程：迭代建图 + BFS

![算法流程：层序遍历建无向邻接表，再从 start 逐层 BFS](images/wc307_q3_iterative_bfs_flow.svg)

| 步骤 | 操作 | 说明 |
|------|------|------|
| ① 层序建图 | 队列存 `(node, 父值)`，根的父值记 $-1$ | 迭代遍历，链深 $10^5$ 也不爆栈 |
| ② 双向连边 | 每出队一个节点：若父值 $\ne -1$，向邻接表加 `pval ↔ node.val` | 每个节点的邻居至多 3 个（父 + 两子） |
| ③ 单源 BFS | `vis = {start}`，从 `start` 逐层向外扩张 | 第 $d$ 层 = 第 $d$ 分钟感染集 |
| ④ 输出最大层 | 每轮 `ans + 1`，队列清空时返回 `ans` | `ans` 初值 $-1$，首层即第 0 分钟 |

两个实现要点：**值作键**——节点值互不相同且 $\le 10^5$，`unordered_map` / `dict` 即可，也可开 $10^5+1$ 的数组直接寻址省哈希常数；**全程无递归**——建图用队列层序、BFS 天然迭代，这是赛场上 Python 存活的关键（见 §8 第 2 条）。

### 3.4 示例演算

![示例演算：start=3 逐分钟感染表与距离标注](images/wc307_q3_bfs_walkthrough.svg)

对示例 1（`start=3`），BFS 各层即各分钟：

| 分钟（距离 $d$） | 新感染 | 感染来源 |
|------|------|------|
| 0 | `3` | 起点 |
| 1 | `1`、`10`、`6` | `3` 的父 + 左右子 |
| 2 | `5` | `1` 的未感染邻居（`3` 已染） |
| 3 | `4` | `5` 的右子 |
| 4 | `9`、`2` | `4` 的左右子 |

最大层 $4$ 即答案。自拟变体 `start=5`（§2 示例 3）中，第 1 分钟**孩子 4 与父 1 同时感染**——上行边与下行边并肩出现，正是无向化的题眼。

### 3.5 解法二：一次 DFS 的「转折点」合并（不建图，$O(h)$ 额外空间）

![解法二：路径 = 上行到转折点 A，再下钻 A 的另一棵子树](images/wc307_q3_tree_dp_turnaround.svg)

建图版要把整棵树物化成邻接表，空间 $O(n)$。其实从 `start` 出发的每条路径都形如「**先沿父链上行**到某个祖先 $A$，**再下钻** $A$ 的另一棵子树」——$A$ 正是 $\mathrm{LCA}(start, v)$（§5 引理 3）。于是只需在每个**转折点**合并「上行距离 + 兄弟臂长」：

$$\text{候选}(A) = \text{dist}(start, A) + 1 + h(c')$$

其中 $c'$ 是 $A$ 的**不含** `start` 的那个孩子，$h$ 为子树高度；约定 $h(\varnothing) = -1$，使「没有兄弟臂」时退化为 $\text{dist}(start, A)$（终点就是 $A$ 自己，依然合法）。再加上转折点就是 `start` 本身的候选 $h(start)$（一路向下），全体取 max 即离心率。这正是 [543. 二叉树的直径](https://leetcode.cn/problems/diameter-of-binary-tree/) 的后序合并——直径合并**两条下行臂**，本题合并「**上行**距离 + **一条**兄弟臂」。

**实现**：后序 DFS 返回二元组 $(h, d)$——$h$ 为子树高度（空树 $-1$，叶子 $0$）；$d$ 为 `start` 到本节点的距离，`start` 不在子树内时取 $-1$ 哨兵。逐节点合并见 §4 第 5 条；以示例 1 走查：`3` 即 `start` 时 $\text{ans} = h(3) = 1$；回溯到 `1` 时 `start` 在右子树、$d_R = 0$、左臂 $h_L = 2$，候选 $0 + 2 + 2 = 4$，对应路径 $3\to1\to5\to4\to9$，终值 $4$ ✓。

## 4. 算法细节

1. **迭代建图的二元组**：队列存 `(节点, 父值)`。根的父值用 $-1$ 标记（值域 $\ge 1$，不会撞车），「加父边」只需一个 `if (pval != -1)`；层序遍历按深度推进，与第二阶段的 BFS 形成结构呼应。全程零递归，是链深 $10^5$ 下的安全写法。
2. **值域直接寻址 vs 哈希**：值互不相同且 $\le 10^5$，两种键皆可。C++ 的 `unordered_map<int, vector<int>>` 通用性最好；追求常数可改 `vector<vector<int>> adj(100001)`——$n = 10^5$ 时两者都能 AC，本题无需卡常。
3. **BFS 的「层 = 分钟」计数**：外层每轮 `++ans` 对应新的一分钟；内层先快照 `sz = q.size()` 再逐个弹出，严格分层——否则层与层粘连，`ans` 会多计。首层是 `start` 自己，`ans` 从 $-1$ 起数恰好计为第 0 分钟，单节点输入自然返回 0。
4. **判重不可省**：无向图每条边会被两侧各走一次，不维护 `vis` 会重复入队甚至来回震荡。树连通且无环，BFS「首次到达即最短」（§5 引理 2），标记即可；若要输出各点感染时刻，把 `vis` 换成 `dist` 数组即可。
5. **解法二的四个合并点**（后序递归，$(h, d)$ 上传）：

   | 当前节点情形 | 候选更新 | 返回值 |
   |------|------|------|
   | `node.val == start` | $\max(\text{ans},\ h)$（一路向下） | $(h,\ 0)$ |
   | `start` 在左子树（$d_L \ge 0$） | $\max(\text{ans},\ d_L + 2 + h_R)$（折返进右子树） | $(h,\ d_L + 1)$ |
   | `start` 在右子树（$d_R \ge 0$） | $\max(\text{ans},\ d_R + 2 + h_L)$（折返进左子树） | $(h,\ d_R + 1)$ |
   | 两边都不在 | 不更新 | $(h,\ -1)$ |

6. **换根视角统一两条解法**：答案 = 以 `start` 为根重挂后的**树高**。解法一把「重挂」物化为邻接表再跑 BFS；解法二不物化，用 $(h, d)$ 沿递归栈上传，把树高拆成「上行段 + 下行段」在转折点拼接。

## 5. 正确性证明

**引理 1（感染时刻 = 无向距离）**：设 $d(v)$ 为无向树中 `start` 到 $v$ 的边数距离，$v$ 被感染的时刻为 $t(v)$，则对所有节点 $t(v) = d(v)$。

**证明**：对时刻 $k$ 归纳断言 $S(k)$：「时刻 $k$ 结束时的感染集合恰为 $I_k = \{v : d(v) \le k\}$」。$k=0$：初始感染集合为 $\{\text{start}\}$，而 $d(v) = 0 \iff v = \text{start}$（值互不相同，起点唯一），即 $I_0$。设 $S(k)$ 成立，考察第 $k+1$ 分钟。（⇒）$v$ 于该分钟感染 $\Rightarrow$ $v \notin I_k$ 且 $v$ 有邻居 $u \in I_k$ $\Rightarrow$ $d(v) > k$ 且 $d(v) \le d(u) + 1 \le k+1$（`start` 到 $u$ 的路径再接一条边即到 $v$ 的通道），整数值故 $d(v) = k+1$。（⇐）若 $d(v) = k+1$：树中 `start` 到 $v$ 的路径唯一，取路径上 $v$ 的前一节点 $u$，则 $d(u) = k$ 即 $u \in I_k$；$u$ 与 $v$ 相邻且 $v \notin I_k$，故 $v$ 恰于第 $k+1$ 分钟感染。两向合并得 $S(k+1)$，归纳完成。∎

**引理 2（BFS 分层 = 最短路）**：无权无向图中，从 `start` 出发的 BFS 把节点首次被发现时的层号记为 $d'(v)$，则 $d'(v) = d(v)$，且第 $k$ 层恰为 $\{v : d(v) = k\}$。

**证明**：对出队次序归纳「$d'$ 非降且 $d' = d$」：队列先弹尽低层再弹高层，故层号非降。设出队节点 $u$ 时 $d'(u) = d(u)$（归纳假设），其未访问邻居 $v$ 被发现并记 $d'(v) = d'(u) + 1$。一方面 $d(v) \le d(u) + 1 = d'(v)$；另一方面若 $d(v) < d'(v)$，取 $v$ 最短路上前一节点 $w$，则 $d(w) = d(v) - 1 < d'(u)$，由层号非降 $w$ 先于 $u$ 出队，$v$ 应在那轮已被发现——与「首次」矛盾。故 $d'(v) = d(v)$，同层聚集即得层集合刻画。∎

**定理 1（解法一正确）**：感染整棵树所需分钟数 $= \max_v d(v)$，且建图 BFS 算法返回该值。

**证明**：由引理 1，时刻 $k$ 的感染集为 $\{v : d(v) \le k\}$；树连通，故「全体感染」$\iff \max_v d(v) \le k$，所需分钟数即 $\max_v d(v)$。算法建出的邻接表与无向树逐边一致（每条父边两侧各加一条有向记录），BFS 最大层 $= \max_v d(v)$（引理 2），`ans` 恰计到最大层。∎

**引理 3（转折点分解）**：对任意 $v \ne \text{start}$：若 $v$ 在 `start` 的子树内（以原根为根），则 `start` 到 $v$ 的路径全在该子树内；否则记 $A = \mathrm{LCA}(\text{start}, v)$（`start` 的真祖先），路径 = 「`start` 沿父链上行 $d(\text{start}, A)$ 条边到 $A$」+「$A$ 下行至 $v$」，且 $v \ne A$ 时 $v$ 位于 $A$ 的某个**不含** `start` 的孩子 $c'$ 的子树内。

**证明**：树中任意两点间路径唯一。LCA 的标准性质：$A$ 的两个孩子子树分别容纳 `start` 侧与 $v$ 侧（或 $v = A$），两段恰在 $A$ 交汇；上行段必沿 `start` 的父链，长度即 $d(\text{start}, A)$。∎

**定理 2（解法二正确）**：$\text{ans}^* = \max\Big(h(\text{start}),\ \max_{A \in \text{start 的真祖先}} \big[\, d(\text{start}, A) + 1 + h(c'(A))\,\big]\Big)$，其中 $c'(A)$ 为 $A$ 的不含 `start` 的孩子（不存在时取 $h(\varnothing) = -1$，项退化为 $d(\text{start}, A)$）；解法二的递归恰好计算此 max。

**证明**：（每项 $\le \text{ans}^*$）$h(\text{start})$ 是 `start` 子树内最远点的距离（引理 3 情形一：子树内路径长度即子树意义下的深度差，最大者为其高度）；$d(\text{start}, A) + 1 + h(c')$ 是「上行到 $A$、下钻 $c'$ 子树最深叶」的距离，由引理 3 情形二知这正是该叶的真实无向距离。（$\text{ans}^* \le$ 右端）任取 $v$：在 `start` 子树内则 $\text{dist} \le h(\text{start})$；否则 $A = \mathrm{LCA}$ 是真祖先——$v = A$ 时 $\text{dist} = d(\text{start}, A)$ 恰等于退化项；$v \ne A$ 时 $v$ 在 $c'(A)$ 子树内，$\text{dist}(start, v) = d(\text{start}, A) + \text{dist}(A, v) \le d(\text{start}, A) + 1 + h(c'(A))$。递归实现中，候选恰好出现在该出现的节点上：`start` 自身（§4 情形表第 1 行）与其每个真祖先（第 2、3 行沿回溯路径逐个触发），二元组 $(h, d)$ 传递的正是定理所需量。∎

## 6. 复杂度分析

- **时间复杂度（两解法皆 $O(n)$)**：解法一——层序建图每节点入队出队各一次、每条无向边加两次记录，$O(n)$；BFS 同阶，合计 $O(n)$。解法二——后序 DFS 每节点访问一次、每步 $O(1)$ 合并，$O(n)$。
- **空间复杂度**：解法一 $O(n)$——邻接表 $2(n-1)$ 条记录、`vis` 集合与队列；解法二不建图，额外仅 $O(h)$ 递归栈（平衡树 $O(\log n)$，链形树 $O(n)$——这正是它赛场上须谨慎使用的理由）。

## 7. 参考代码

### C++

**解法一：迭代建图 + BFS（推荐，零递归）**

```cpp
class Solution {
public:
    int amountOfTime(TreeNode* root, int start) {
        // ① 层序遍历建无向邻接表：值 -> 邻居值（父边 + 子边），全程无递归
        unordered_map<int, vector<int>> adj;
        queue<pair<TreeNode*, int>> q;                 // (节点, 父节点值)，根的父值 -1
        q.emplace(root, -1);
        while (!q.empty()) {
            auto [node, pval] = q.front(); q.pop();
            if (pval != -1) {
                adj[node->val].push_back(pval);        // 子 -> 父
                adj[pval].push_back(node->val);         // 父 -> 子
            }
            if (node->left)  q.emplace(node->left,  node->val);
            if (node->right) q.emplace(node->right, node->val);
        }

        // ② 从 start 逐层 BFS：一轮 = 一分钟，最大层即答案
        int ans = -1;
        queue<int> bq;
        unordered_set<int> vis{start};
        bq.push(start);
        while (!bq.empty()) {
            ++ans;
            for (int sz = bq.size(); sz-- > 0;) {
                int u = bq.front(); bq.pop();
                for (int v : adj[u])
                    if (vis.insert(v).second) bq.push(v);
            }
        }
        return ans;
    }
};
```

**解法二：一次 DFS，转折点合并（不建图，$O(h)$ 额外空间）**

```cpp
class Solution {
    int start_, ans_ = 0;
    // 返回 {子树高度(边), start 到本节点的距离; start 不在子树内为 -1}
    pair<int, int> dfs(TreeNode* node) {
        if (!node) return {-1, -1};
        auto [hl, dl] = dfs(node->left);
        auto [hr, dr] = dfs(node->right);
        int h = max(hl, hr) + 1;
        if (node->val == start_) {                     // 转折点 = start：一路向下
            ans_ = max(ans_, h);
            return {h, 0};
        }
        if (dl >= 0) {                                 // start 在左子树：折返下钻右子树
            ans_ = max(ans_, dl + 2 + hr);             // 到本节点 1 边 + 进右臂 1 边 + 右臂高度
            return {h, dl + 1};
        }
        if (dr >= 0) {                                 // start 在右子树：对称
            ans_ = max(ans_, dr + 2 + hl);
            return {h, dr + 1};
        }
        return {h, -1};                                // start 不在本子树
    }
public:
    int amountOfTime(TreeNode* root, int start) {
        start_ = start;
        dfs(root);
        return ans_;
    }
};
```

### Python

**解法一：迭代建图 + BFS（零递归，链形树安全）**

```python
from collections import defaultdict, deque


class Solution:
    def amountOfTime(self, root: Optional[TreeNode], start: int) -> int:
        # ① 层序建无向邻接表：值 -> [邻居值]，全程无递归
        adj = defaultdict(list)
        q = deque([(root, -1)])                        # (节点, 父值)，根的父值 -1
        while q:
            node, pval = q.popleft()
            if pval != -1:
                adj[node.val].append(pval)             # 子 -> 父
                adj[pval].append(node.val)             # 父 -> 子
            if node.left:
                q.append((node.left, node.val))
            if node.right:
                q.append((node.right, node.val))

        # ② 从 start 逐层 BFS：一轮 = 一分钟
        vis = {start}
        bq = deque([start])
        ans = -1
        while bq:
            ans += 1
            for _ in range(len(bq)):
                u = bq.popleft()
                for v in adj[u]:
                    if v not in vis:
                        vis.add(v)
                        bq.append(v)
        return ans
```

**解法二：一次 DFS（递归版，需放宽递归上限，见 §8 第 2 条）**

```python
import sys


class Solution:
    def amountOfTime(self, root: Optional[TreeNode], start: int) -> int:
        sys.setrecursionlimit(300000)
        ans = 0

        def dfs(node: Optional[TreeNode]) -> tuple[int, int]:
            # 返回 (子树高度, start 到本节点距离; 不在子树内为 -1)
            nonlocal ans
            if node is None:
                return -1, -1
            hl, dl = dfs(node.left)
            hr, dr = dfs(node.right)
            h = max(hl, hr) + 1
            if node.val == start:                      # 转折点 = start：一路向下
                ans = max(ans, h)
                return h, 0
            if dl >= 0:                                # start 在左：折返下钻右子树
                ans = max(ans, dl + 2 + hr)
                return h, dl + 1
            if dr >= 0:                                # start 在右：对称
                ans = max(ans, dr + 2 + hl)
                return h, dr + 1
            return h, -1

        dfs(root)
        return ans
```

## 8. 边界情况与易错点

1. **「相邻」读成单向**：WA 头号坑。只往孩子方向感染 = 只算 `start` 子树高度：示例 1 会答 1（正确 4）。更阴险的是 `start =` 根时两种口径同答案——自测必须含 `start ≠` 根的用例（如自拟示例 3）。
2. **递归爆栈**：$n = 10^5$、链形树深 $10^5$。Python 默认递归上限约 1000，递归建图必炸 `RecursionError`；解法二须 `sys.setrecursionlimit(300000)`（CPython 在 $10^5$ 深度通常可过，但 C 栈余量视平台而定，生产环境建议显式栈化）。C++ 一般无虞但并非保证。**解法一全程迭代，链形树零风险**——赛场上 Python 首选。
3. **解法二的「+2」拼装**：折返候选 $= d_{\text{child}} + 2 + h_{\text{另一侧}}$，三段各是「到本节点 1 边、进另一侧 1 边、侧内高度 $h$」，少加任何一个 $+1$ 即 WA。空子树哨兵 $h(\varnothing) = -1$ 让「没有另一侧」时公式自动退化为「到本节点的距离」——终点就是转折点自己，依然合法。
4. **哨兵不能用 0**：空树高度 $-1$、「`start` 不在子树」$d = -1$；而叶子高度 0、`start` 自身距离 0 都是**合法值**。用 0 当哨兵会把「叶子」「起点」误判成「不存在」。
5. **值作键的前提**：值互不相同才可直接拿值当键；若值可重复（面试变体常见），须改用节点指针或 DFS 时重编号 $1..n$。
6. **BFS 不判重**：无向边两侧各遍历一次，无 `vis` 会重复入队甚至震荡；树连通、首达即最短，标记即可，无需优先队列。
7. **单节点与 `start` 为根**：$n=1$ 返回 0（`ans` 从 $-1$ 起数，首层计 0 分钟，自然覆盖）；`start` 为根时答案恰为树高，两解法均无需特判。
8. **溢出与规模**：答案上界 $n - 1 < 10^5$，`int` 绰绰有余；两解法均 $O(n)$，$n = 10^5$ 毫无压力。
