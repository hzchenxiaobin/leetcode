# LeetCode 找出数组的第 K 大和 题解

## 1. 题目概述

- **标题 / 题号**：找出数组的第 K 大和（#2386，hard）
- **链接**：https://leetcode.cn/problems/find-the-k-sum-of-an-array/
- **来源**：LeetCode 第 307 场周赛 Q4
- **难度**：困难
- **标签**：数组、排序、堆（优先队列）

**题意**：
给定整数数组 `nums` 与**正**整数 `k`。任选 `nums` 的一个**子序列**并对全部元素求和（**空子序列的和视作 0**，子序列和允许重复）。把全部 $2^n$ 个子序列和**从大到小**排成一列，返回其中**第 $k$ 个**的值。

**约束**：

- $1 \le n \le 10^5$
- $-10^9 \le \text{nums}[i] \le 10^9$
- $1 \le k \le \min(2000,\; 2^n)$

> 💡 **审题关键**：约束呈现罕见的「**n 大 k 小**」不对称——$n$ 达 $10^5$，$2^n$ 个子序列和绝无可能全算（连折半枚举都过不了 $n \le 40$ 的门槛）；而 $k \le 2000$ 极小，暗示**只需按序生成前 $k$ 个**。另一半钥匙是「**最大子序列和不用搜索**」：全选正数即得 $\text{total}$。把每个子序列和写成「$\text{total} -$ 某个扣减量」，第 $k$ 大就翻转成「**第 $k$ 小扣减量**」——即绝对值数组 $|\text{nums}|$ 的**第 $k$ 小子集和**，最小堆逐个吐出前 $k$ 小即可。转化 + 堆枚举，是这道压轴题的完整考点。

## 2. 示例

**示例 1**

```text
输入：nums = [2,4,-2], k = 5
输出：2

解释：全部子序列和从大到小排列为
6、4、4、2、2、0、0、-2
（两个 0 分别来自空子序列与 {2,-2}；两个 2 来自 {2} 与 {4,-2}）
第 5 大和为 2。
```

**示例 2**

```text
输入：nums = [1,-2,3,4,-10,12], k = 16
输出：10

解释：正数和 total = 1+3+4+12 = 20，第 16 小的 |nums| 子集和为 10，
答案 = 20 - 10 = 10。
```

**示例 3**（自拟：$k$ 取到上界 $2^n$）

```text
输入：nums = [2,4,-2], k = 8
输出：-2

解释：8 = 2^3，第 8 大即最小的子序列和——只选 -2 得 -2。
k 取满时堆枚举量恰为 2^n ≤ 2000，依然轻松；答案也可以为负。
```

## 3. 解题思路

### 3.1 暴力思路

枚举每个元素选 / 不选，得 $2^n$ 个和，排序取第 $k$ 大：$n \le 20$ 勉强可行，$n = 10^5$ 是天文数字；即便折半枚举（meet in the middle）也要求 $n \le 40$。死路的根源是「**无序地全量枚举**」，而 $k \le 2000$ 说明只需要**最小的那一小撮**。突破口藏在两个显眼的事实里：其一，**最大子序列和一眼可得**——全选正数、不选负数即得 $\text{total}$（引理 1）；其二，任何子序列和都能写成「$\text{total}$ 减去若干个 $|\text{nums}[i]|$」。把「求第 $k$ 大」换成「从最大值出发做**最小的 $k$ 次扣减**」，问题立刻有了有序结构。

### 3.2 核心观察：第 k 大子序列和 = total − 第 k 小子集和

![核心观察：子序列和 = total − 子集和，大小关系翻转](images/wc307_q4_total_subset_concept.svg)

记 $\text{total} = \sum_{\text{nums}[i] > 0} \text{nums}[i]$（全部正数之和），这是**最大**子序列和。对每个下标 $i$，按元素正负建立子序列（下标集 $S$）与**扣减子集** $T$ 的对应：

| 元素 | 选入子序列 $S$ | 不选入 $S$ |
|------|------|------|
| 正数 $p$（已在 total 中） | 贡献 $+p$，**不扣** | 从 total **扣 $p$** |
| 负数 $-x$（不在 total 中） | **再扣 $x$**（贡献 $-x$） | 贡献 $0$，不扣 |

即 $i \in T \iff$ 「$\text{nums}[i] > 0$ 且 $i \notin S$」或「$\text{nums}[i] \le 0$ 且 $i \in S$」，于是

$$\text{sum}(S) = \text{total} - \sum_{i \in T} |\text{nums}[i]|$$

且 $S \mapsto T$ 是下标子集间的**双射**（同一规则把 $\in / \notin$ 互换即得逆映射）。减法把大小关系**翻转**：$\text{total}$（第 1 大子序列和）对应空集 $T$（第 1 小子集和 $0$）；双射**保重数**（重复的子序列和对应重复的子集和），因此

$$\text{第 } k \text{ 大子序列和} = \text{total} - \text{第 } k \text{ 小子集和}(a), \qquad a = |\text{nums}|$$

转化后只剩一个干净的小问题：**非负数组 $a$ 的第 $k$ 小子集和**（子集和的多重集在排序置换下不变，故可直接对升序后的 $a$ 求解）。$k \le 2000$ 意味着只需生成前 $k$ 小，与 $2^n$ 彻底解耦。

### 3.3 算法流程：最小堆 add / replace 双分支

![算法流程：最小堆按升序生成前 k 小子集和](images/wc307_q4_heap_flow.svg)

把 $a$ **升序排序**后，用最小堆按非降次序生成子集和。堆中状态为二元组 $(s, i)$：$s$ 是某个子集的和，该子集的**最大下标为 $i-1$**，下一个待处理下标为 $i$。每次弹出堆顶（当前全局最小）后，分裂出至多两个后继：

| 分支 | 新状态 | 子集动作 | 和的增量 |
|------|--------|---------|---------|
| **add** | $(s + a[i],\; i+1)$ | 末尾追加 $a[i]$ | $a[i] \ge 0$ |
| **replace**（$i>0$） | $(s + a[i] - a[i-1],\; i+1)$ | 把 $a[i-1]$ 换成 $a[i]$ | $a[i]-a[i-1] \ge 0$（升序） |

两个增量都非负，配合最小堆「每次弹全局最小」，弹出序列就是子集和的升序排列（引理 3、4）。整体流程：

1. **预处理**：$\text{total} \leftarrow$ 正数和；$a \leftarrow |\text{nums}|$ 升序排序；
2. **初始化**：堆中放入 $(0, 0)$——空子集，即第 1 小子集和 $0$；
3. **循环 $k-1$ 次**：弹堆顶 $(s,i)$；若 $i < n$ 压入 add 后继 $(s+a[i],\, i+1)$；若 $i > 0$ 再压入 replace 后继 $(s+a[i]-a[i-1],\, i+1)$；
4. **输出**：此时堆顶即第 $k$ 小子集和，答案 $= \text{total} - \text{堆顶}.s$。

> 💡 **add/replace 的来历**：它等价于给所有子集建一棵**二叉生成树**——从「上一个子集」出发，要么在末尾**追加**更大的 $a[i]$，要么把末尾的 $a[i-1]$ **换成** $a[i]$，不重不漏地遍历（引理 3）。这套「加 / 换」堆归并与 [373. 查找和最小的 K 对数字](https://leetcode.cn/problems/find-k-pairs-with-smallest-sums/)、[1439. 有序矩阵中的第 k 个最小数组和](https://leetcode.cn/problems/find-the-kth-smallest-sum-with-k-numbers/) 完全同源，是「有序集合求第 $k$ 小」的通用武器。

### 3.4 示例演算

![示例演算：nums=[2,4,−2], k=5 的堆操作与翻转对应](images/wc307_q4_walkthrough.svg)

以示例 1 演算：$\text{total} = 2 + 4 = 6$，$a = [2, 2, 4]$（子集以下标 $a_0, a_1, a_2$ 表示）。

| 步 | 弹出 $(s,i)$ | 对应子集 | 压入后继 | 弹出后的堆 |
|----|------|------|------|------|
| 1 | $(0,0)$ | $\varnothing$ | add $(2,1)$ | $(2,1)$ |
| 2 | $(2,1)$ | $\{a_0\}$ | add $(4,2)$、repl $(2,2)$ | $(2,2),(4,2)$ |
| 3 | $(2,2)$ | $\{a_1\}$ | add $(6,3)$、repl $(4,3)$ | $(4,2),(4,3),(6,3)$ |
| 4 | $(4,2)$ | $\{a_0,a_1\}$ | add $(8,3)$、repl $(6,3)$ | $(4,3),(6,3),(6,3),(8,3)$ |

弹完 $k-1 = 4$ 次后堆顶为 $(4,3)$（子集 $\{a_2\}$）：第 5 小子集和 $= 4$，答案 $= 6 - 4 = 2$ ✓。升序子集和全体为 $0,2,2,4,4,6,6,8$，经 $\text{total}-s$ 翻转恰得题面的降序子序列和 $6,4,4,2,2,0,0,-2$；两个 $0$ 分别来自 $\varnothing$ 与 $\{2,-2\}$、两个 $2$ 来自 $\{2\}$ 与 $\{4,-2\}$——**重复按重数计入**，正是「子序列和允许重复」的体现。

## 4. 算法细节

1. **状态语义保证 replace 合法**：不变量——$i \ge 1$ 的状态 $(s,i)$ 所代表的子集**必含** $a[i-1]$。归纳可证：add 给子集缀上 $a[i]$、replace 把 $a[i-1]$ 换成 $a[i]$，新状态的最大下标都变为 $i$，不变量逐层传递。根 $(0,0)$ 是唯一的例外（代表空集），故 replace 必须判 $i > 0$。
2. **升序排序是两分支单调的前提**：add 增量 $a[i] \ge 0$ 恒成立（绝对值非负）；replace 增量 $a[i] - a[i-1] \ge 0$ **依赖升序**。若忘记排序，replace 可能产生更小的和，「弹出即升序」即被破坏。
3. **堆内比较只看 $s$**：`pair<long long,int>` 的默认字典序先比 $s$；$s$ 相同时无论弹出哪个都是当前最小，$i$ 的次序不影响正确性。
4. **弹 $k-1$ 次、再取堆顶**：初始堆顶 $(0,0)$ 本身就是第 1 小（空集）。循环 $k-1$ 次弹掉第 $1 \sim k-1$ 小，余下堆顶才是第 $k$ 小；误弹 $k$ 次会取到第 $k+1$ 小（示例 1 将错答 $0$）。
5. **堆不会弹空**：约束 $k \le 2^n$ 保证子集总数不少于 $k$，弹 $k-1$ 次后至少剩一个状态；$k = 2^n$ 时恰剩唯一的全集状态，第 $2^n$ 小即「全选」的和。
6. **堆大小 $O(k)$**：每次弹出至多压入 $2$ 个状态，$k-1$ 轮后堆中至多 $2(k-1)$ 个元素——这正是 $k \le 2000$ 养得起的规模，也是本题不用二分答案的根本原因（见 §8 第 9 条）。

## 5. 正确性证明

**引理 1（最大子序列和）**：全部正数组成的子序列之和 $\text{total}$ 是最大子序列和。

**证明**：从任一子序列中删去一个负元素，结果仍是合法子序列且和严格变大；删尽负元素后，再并入任何尚未选入的正数也使和严格变大。故最大者必「含全部正数、不含全部负数」，其和为 $\text{total}$。若无正数，则 $\text{total} = 0$，由空子序列取到；此时任何非空子序列和为负，$0$ 仍是最大。∎

**引理 2（双射表示）**：按 §3.2 的规则定义 $S \mapsto T(S)$，则它是下标子集间的双射，且 $\text{sum}(S) = \text{total} - \sum_{i \in T(S)} |\text{nums}[i]|$。

**证明**：规则对每个下标 $i$ 独立取值（$\text{nums}[i] > 0$：$i \in T \iff i \notin S$；$\text{nums}[i] \le 0$：$i \in T \iff i \in S$），把两处 $\in / \notin$ 互换即得逆映射，故为双射。对和式按正负分解（记 $P = \{i : \text{nums}[i] > 0\}$）：

$$
\begin{aligned}
\text{sum}(S) &= \sum_{i \in S \cap P} \text{nums}[i] + \sum_{i \in S \setminus P} \text{nums}[i] \\
&= \text{total} - \sum_{i \in P \setminus S} \text{nums}[i] + \sum_{i \in S \setminus P} \text{nums}[i] \\
&= \text{total} - \sum_{i \in P \setminus S} |\text{nums}[i]| - \sum_{i \in S \setminus P} |\text{nums}[i]| \\
&= \text{total} - \sum_{i \in T(S)} |\text{nums}[i]|.
\end{aligned}
$$

∎

**推论（翻转）**：第 $k$ 大子序列和 $= \text{total} -$ 第 $k$ 小子集和（$a = |\text{nums}|$）。

**证明**：子集和的多重集在排序置换下不变，故只需考察 $a$。设 $a$ 的子集和带重数升序排列为 $s_1 \le s_2 \le \cdots \le s_{2^n}$。由引理 2，子序列和的多重集恰为 $\{\text{total} - s_j\}$；由 $s_j$ 非降知 $\text{total} - s_1 \ge \text{total} - s_2 \ge \cdots$ 即为降序排列，其第 $k$ 项为 $\text{total} - s_k$。∎

**引理 3（生成树不重不漏）**：以空集为根、按 add / replace 分裂，每个子集恰被生成一次（每个状态只入堆一次）。

**证明**：先证**至多一个父辈**。设子集 $X \ne \varnothing$ 的最大下标为 $m$。注意两个事实：add 的结果形如 $Y \cup \{i\}$（必含 $i$，且 $Y = X \smallsetminus \{i\}$ 的最大下标为 $i-1$，故含 $i-1$）；replace 的结果形如 $(Y \smallsetminus \{i-1\}) \cup \{i\}$（含 $i$ 且**不含** $i-1$）。分类：

- $m = 0$：$X = \{0\}$。replace 的结果必含某个 $i \ge 1$，故 $X$ 只能由 add 生成，父辈唯一为 $\varnothing$（根）。
- $m \ge 1$ 且 $m-1 \in X$：$X$ 不能由 replace 生成（replace 结果不含被换掉的 $i-1$），只能由 add 生成，父辈唯一为 $X \smallsetminus \{m\}$。
- $m \ge 1$ 且 $m-1 \notin X$：$X$ 不能由 add 生成（否则 $X \smallsetminus \{m\}$ 的最大下标为 $m-1$，即 $m-1 \in X$，矛盾），只能由 replace 生成，父辈唯一为 $(X \smallsetminus \{m\}) \cup \{m-1\}$。

再证**可达**：对 $m$ 归纳。$m = 0$ 即根的 add 孩子。$m \ge 1$ 时，上述唯一父辈的最大下标严格小于 $m$（第二类中为 $X$ 的次大下标，第三类中为 $m-1$；$X = \{m\}$ 落入第三类，父辈为 $\{m-1\}$），由归纳假设父辈可达，故 $X$ 可达。两向合并，不重不漏。∎

**引理 4（弹出即升序）**：堆过程的第 $t$ 次弹出，其状态之和为全体子集和（带重数）的第 $t$ 小。

**证明**：先看**路径单调**：生成树中子状态的和不小于父状态——add 增量 $a[i] \ge 0$，replace 增量 $a[i] - a[i-1] \ge 0$（$a$ 升序），沿任一根到叶路径逐边累加即得。

对 $t$ 归纳。$t = 1$：初始堆仅 $(0,0)$，其和 $0$ 是最小子集和（$a$ 非负，任何子集和 $\ge 0$）。设前 $t$ 次弹出恰为前 $t$ 小。考察第 $t+1$ 次弹出前：堆中元素恰为「已弹状态的尚未弹出的儿子」。对任一未弹状态 $X$：根在第 1 步已弹出，故 $X$ 到根的路径上存在**最深的已弹祖先** $A$；$A$ 弹出时压入了全部儿子，路径上 $A$ 的儿子 $B$ 若已弹出则与 $A$ 最深矛盾，故 $B$ 在堆中，且由路径单调 $\text{sum}(B) \le \text{sum}(X)$。于是每个未弹状态都有一个堆中元素不超过它，得 $\min(\text{堆}) \le \min_{\text{未弹}} \text{sum}$；又堆 ⊆ 未弹，反向不等式显然。故堆顶即全体未弹状态的最小者，弹出它恰为第 $t+1$ 小，归纳成立。∎

**定理**：算法返回 `nums` 的第 $k$ 大子序列和。

**证明**：由引理 3，堆过程逐一生成全部子集和且无重复状态；由引理 4，前 $k-1$ 次弹出恰为前 $k-1$ 小子集和，随后堆顶为第 $k$ 小；由引理 2 推论，$\text{total} -$ 第 $k$ 小子集和即第 $k$ 大子序列和。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \log n + k \log k)$。排序 $O(n \log n)$；堆阶段共 $k-1$ 次弹出、至多 $2(k-1)$ 次压入，堆大小 $O(k)$，每次堆操作 $O(\log k)$。
- **空间复杂度**：$O(n + k)$。绝对值数组 $O(n)$，堆 $O(k)$。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    long long kSum(vector<int>& nums, int k) {
        long long total = 0;
        for (int x : nums)
            if (x > 0) total += x;                 // ① 正数和 = 最大子序列和

        vector<int> a;
        for (int x : nums) a.push_back(abs(x));
        sort(a.begin(), a.end());                  // ② 升序是 replace 单调的前提
        int n = a.size();

        using P = pair<long long, int>;            // (子集和, 下一个待处理下标)
        priority_queue<P, vector<P>, greater<P>> pq;
        pq.push({0, 0});                           //    空子集 = 第 1 小
        for (int step = 1; step < k; ++step) {     // ③ 弹 k-1 次
            auto [s, i] = pq.top(); pq.pop();
            if (i < n) {
                pq.push({s + a[i], i + 1});                 // add：追加 a[i]
                if (i > 0)
                    pq.push({s + a[i] - a[i - 1], i + 1});  // replace：换尾
            }
        }
        return total - pq.top().first;             // ④ total − 第 k 小子集和
    }
};
```

### Python

```python
import heapq
from typing import List

class Solution:
    def kSum(self, nums: List[int], k: int) -> int:
        total = sum(x for x in nums if x > 0)      # ① 正数和
        a = sorted(abs(x) for x in nums)           # ② 升序
        n = len(a)

        pq = [(0, 0)]                              # (子集和, 下一个待处理下标)
        for _ in range(k - 1):                     # ③ 弹 k-1 次
            s, i = heapq.heappop(pq)
            if i < n:
                heapq.heappush(pq, (s + a[i], i + 1))                 # add
                if i:
                    heapq.heappush(pq, (s + a[i] - a[i - 1], i + 1))  # replace
        return total - pq[0][0]                    # ④ 翻转回第 k 大
```

## 8. 边界情况与易错点

1. **`total` 与堆中和必须用 64 位**：$n = 10^5$、$|\text{nums}[i]| \le 10^9$，正数和上界 $\approx 10^{14}$，C++ `int` 必溢出（堆中的 $s$ 同理可达 $10^{14}$）；Python 整数无上限，无此虑。
2. **replace 必须判 `i > 0`**：$i = 0$ 的状态是根（空集），没有 $a[i-1]$ 可换，越界且语义错误；add 只需 $i < n$。
3. **循环 $k-1$ 次而非 $k$ 次**：初始堆顶 $(0,0)$ 本身就是第 1 小；多弹一次会取到第 $k+1$ 小，示例 1 将错答 $0$。
4. **忘记升序排序**：replace 增量 $a[i] - a[i-1]$ 可能为负，「弹出即升序」失效，输出的不再是第 $k$ 小。
5. **$k = 1$**：不进循环，堆顶 $(0,0)$，答案 $= \text{total}$——「全选正数」直接返回，无需特判。
6. **$k = 2^n$**（$n \le 10$ 时可达上界）：枚举量 $\le 2000$ 依旧轻松；第 $2^n$ 小即「全选」的和，堆中恰剩全集状态，不会弹空（见 §4 第 5 条）。
7. **重复值与零元素**：$a$ 中相等的值（如 $+2$ 与 $-2$ 的绝对值）来自不同下标，是**不同子集、相同和**——必须按重数计入，切勿对 $a$ 去重；$0$ 的选 / 不选同样产生两个同和子序列（对应空子序列与 $\{0\}$）。
8. **答案可为负**：$k$ 接近 $2^n$ 时第 $k$ 大可能为负（示例 3 的 $-2$），不要想当然把答案截断到 $0$。
9. **为什么不用二分答案**：「子集和 $\le \text{mid}$ 的个数」是 0-1 背包计数，值域高达 $10^{14}$ 无法 DP，剪枝 DFS 最坏仍指数；而 $k \le 2000$ 让堆枚举只需 $O(k \log k)$——**$k$ 小用堆枚举、计数容易才用二分**（对照 [719. 找出第 K 小的数对距离](https://leetcode.cn/problems/find-k-th-smallest-pair-distance/)）。
