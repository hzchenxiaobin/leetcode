# LeetCode 船上可以装载的最大集装箱数量 题解

## 1. 题目概述

- **标题 / 题号**：船上可以装载的最大集装箱数量（#3492，easy）
- **链接**：https://leetcode.cn/problems/maximum-containers-on-a-ship/
- **来源**：LeetCode 第 442 场周赛 Q1
- **难度**：简单
- **标签**：数学

**题意**：船上有一个 $n \times n$ 的货物甲板，每个单元格**至多**装载一个重量**恰好**为 $w$ 的集装箱。所有装上船的集装箱总重量不能超过船的最大承载量 $\text{maxWeight}$。求最多能装载的集装箱数量。

**约束**：

- $1 \le n \le 1000$
- $1 \le w \le 1000$
- $1 \le \text{maxWeight} \le 10^9$

> 💡 **读题关键**：每个集装箱重量完全相同（恰为 $w$）、每个格子完全等价（无位置差异），因此格子数与总重量这两条限制**互不耦合**，答案可以一步算出。

## 2. 示例

**示例 1**

```text
输入：n = 2, w = 3, maxWeight = 15
输出：4
解释：甲板有 4 个单元格，全部装上后总重 4 × 3 = 12 ≤ 15。
```

**示例 2**

```text
输入：n = 3, w = 5, maxWeight = 20
输出：4
解释：甲板有 9 个单元格，但预算只够装 4 个（4 × 5 = 20）。
```

**补充边界**

```text
输入：n = 1000, w = 1000, maxWeight = 999
输出：0
解释：预算连一个整箱都装不下，⌊999/1000⌋ = 0。
```

## 3. 解题思路

### 3.1 暴力思路：逐格模拟装箱

从任意格子开始逐个装箱，每装一个，已用格子数加一、累计重量加 $w$，直到「格子用完」或「再装一个就超重」：

```text
count = 0, total = 0
while count < n * n and total + w <= maxWeight:
    count += 1
    total += w
return count
```

循环次数为 $\min(n^2, \lfloor \text{maxWeight}/w \rfloor) \le 10^6$，提交也能过，但完全没必要：第 $k$ 个箱子能否装下，与前面的箱子装在**哪些格子**毫无关系，逐个模拟是对「集装箱同质」这一性质的浪费。中间档还可以二分答案（可行性关于 $k$ 单调），但判定条件本身是线性的，直接解不等式即可。

### 3.2 核心观察：两条独立上界，取短板

![两条独立上界取min](images/max_containers_bottlenecks.svg)

把「装 $k$ 个集装箱可行」翻译成数学语言：

$$\text{feasible}(k) \iff k \le n^2 \;\;\text{且}\;\; k \cdot w \le \text{maxWeight}$$

- **空间侧**：格子只有 $n^2$ 个、每格至多一箱 → $k \le n^2$；
- **重量侧**：每箱恰重 $w$，装 $k$ 个总重恰为 $k \cdot w$ → $k \le \lfloor \text{maxWeight}/w \rfloor$（$k$ 为整数）。

两条约束各自给出一个线性上界且**互不影响**——数学形态的木桶效应，同时满足即取 min：

$$\text{ans} = \min\left(n^2,\ \left\lfloor \frac{\text{maxWeight}}{w} \right\rfloor\right)$$

示例 1 空间先卡住（$4 < 5$），示例 2 重量先卡住（$4 < 9$）——谁短谁说了算。

> ⚠️ 「**恰好**为 $w$」是公式成立的题眼：总重 $= k \cdot w$ 只依赖个数、与摆在哪些格子无关，因此任意 $k \le n^2$ 的装载方案总存在，无需搜索。

### 3.3 算法流程

```text
读入 n, w, maxWeight
  → 空间上界 n * n
  → 重量上界 maxWeight / w（整除）
  → 取 min 返回
```

没有循环、没有分支——一行公式就是全部算法。

### 3.4 示例演算

![示例演算：谁先卡住](images/max_containers_walkthrough.svg)

| 场景 | 空间上界 $n^2$ | 重量上界 $\lfloor \text{maxWeight}/w \rfloor$ | 答案 | 卡在哪 |
|------|------|------|------|------|
| 示例 1：$n=2, w=3, \text{mx}=15$ | $4$ | $5$ | $\min(4,5)=4$ | 空间 |
| 示例 2：$n=3, w=5, \text{mx}=20$ | $9$ | $4$ | $\min(9,4)=4$ | 重量 |
| 边界：$n=1000, w=1000, \text{mx}=999$ | $10^6$ | $0$ | $0$ | 重量 |

> 💡 两个官方示例恰好一人卡一个瓶颈，完整展示了「短板决定」；边界行说明答案可以为 0——预算不足一整箱时一个也装不了。

## 4. 算法细节

1. **空间上界**：`n * n` 计算。$n \le 1000$ 时不超过 $10^6$。
2. **重量上界**：`maxWeight / w`。C++ 中两个正整数相除即向下取整，与 Python 的 `//` 语义一致。
3. **合并**：`min(n * n, maxWeight / w)` 一步得到答案，无需循环或特判。
4. **溢出核对**：$n^2 \le 10^6$，$\text{maxWeight}/w \le 10^9$，均小于 $2^{31}-1 \approx 2.1 \times 10^9$，32 位 `int` 全程安全（详见 §8）。

## 5. 正确性证明

**引理 1（可行性刻画）**：装 $k$ 个集装箱可行 $\iff$ $k \le n^2$ 且 $k \cdot w \le \text{maxWeight}$。

**证明**：（必要性）每格至多一箱、共 $n^2$ 格，故 $k \le n^2$；每箱恰重 $w$，总重为 $k \cdot w$，不超载即 $k \cdot w \le \text{maxWeight}$。（充分性）任取 $k \le n^2$ 个格子各放一箱——格子无差异，方案总存在；此时总重 $k \cdot w \le \text{maxWeight}$，满足承载约束。∎

**引理 2（可行域结构）**：可行的装箱数 $k$ 恰为闭区间 $\left[0,\ M\right]$ 内的全部整数，其中 $M = \min\left(n^2,\ \lfloor \text{maxWeight}/w \rfloor\right)$。

**证明**：$k$ 为非负整数时，$k \cdot w \le \text{maxWeight} \iff k \le \text{maxWeight}/w \iff k \le \lfloor \text{maxWeight}/w \rfloor$。于是引理 1 的两个条件联立等价于 $k \le \min\left(n^2,\ \lfloor \text{maxWeight}/w \rfloor\right) = M$。∎

**定理**：最大装箱数为 $\min\left(n^2,\ \lfloor \text{maxWeight}/w \rfloor\right)$。

**证明**：由引理 2，可行集是 $\left[0, M\right]$ 中的全部整数，非空（含 0）且存在最大元 $M$，故答案为 $M$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(1)$。一次乘法、一次整除、一次取小；对照逐格模拟的 $O\!\left(\min(n^2, \lfloor \text{maxWeight}/w \rfloor)\right) \le 10^6$。
- **空间复杂度**：$O(1)$。无任何辅助数据结构。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maxContainers(int n, int w, int maxWeight) {
        return min(n * n, maxWeight / w);
    }
};
```

### Python

```python
class Solution:
    def maxContainers(self, n: int, w: int, maxWeight: int) -> int:
        return min(n * n, maxWeight // w)
```

## 8. 边界情况与易错点

1. **整除必须向下取整**：剩余预算不足一整箱时只能闲置，如 $\text{maxWeight}=22, w=5$ 仍只能装 4 个。本题三参数均为正，C++ `/` 与 Python `//` 行为一致，无「向零取整」的方向歧义。
2. **答案为 0**：$\text{maxWeight} < w$ 时连一个整箱都装不下，公式自然返回 0，无需特判。
3. **溢出**：本题各值上界（$10^6$、$10^9$）均在 `int` 范围内；若约束放宽（如 $n \le 10^5$ 或 $\text{maxWeight} \le 10^{18}$），`n * n` 与中间计算须换 `long long`（Python 天然大数无碍）。
4. **语义混淆**：$w$ 是**每个**集装箱的重量，不是总重也不是数量；返回值是集装箱**个数**而非最大总重。
5. **不要过度设计**：本题无需 DP、贪心或二分——识别「约束解耦 ⇒ 一行公式」，正是签到题要训练的判断力。
