# LeetCode 属性图 题解

## 1. 题目概述

- **标题 / 题号**：属性图（#3493，medium）
- **链接**：https://leetcode.cn/problems/properties-graph/
- **来源**：LeetCode 第 442 场周赛 Q2
- **难度**：中等
- **标签**：并查集、深度优先搜索、广度优先搜索、图、数组、哈希表

**题意**：给定 $n \times m$ 的二维整数数组 `properties` 和整数 $k$。定义 $\text{intersect}(a, b)$ 为数组 $a$、$b$ 中**共有的不同整数**的个数。构造无向图：节点 $i$ 对应 `properties[i]`，当且仅当 $\text{intersect}(\text{properties}[i], \text{properties}[j]) \ge k$（$i \ne j$）时节点 $i$、$j$ 之间连一条边。返回图中**连通分量**的个数。

**约束**：

- $1 \le n = \text{properties.length} \le 100$
- $1 \le m = \text{properties}[i].\text{length} \le 100$
- $1 \le \text{properties}[i][j] \le 100$
- $1 \le k \le m$

> 💡 **读题三个关键点**：① intersect 按「**不同**值」计数——先去重再数个数；② 建边是「相似度 $\ge k$」的阈值判定；③ 值域被刻意压到 $[1, 100]$。三者合起来几乎明示了「位掩码 + 并查集」的标准套路。

## 2. 示例

**示例 1**

```text
输入：properties = [[1,2],[1,1],[3,4],[4,5],[5,6],[7,7]], k = 1
输出：3
解释：共享 ≥ 1 即连边：0–1 共享 {1}，2–3 共享 {4}，3–4 共享 {5}；
      5 号点不与任何人共享，自成孤点。三个分量：{0,1}、{2,3,4}、{5}。
```

**示例 2**

```text
输入：properties = [[1,2,3],[2,3,4],[4,3,5]], k = 2
输出：1
解释：0–1 共享 {2,3}（2 个 ≥ 2 ✓），1–2 共享 {3,4}（2 个 ≥ 2 ✓），
      0–2 只共享 {3}（1 个 < 2 ✗）。0 和 2 虽无直接边，但经 1 中转仍同属一个分量。
```

**示例 3**

```text
输入：properties = [[1,1],[1,1]], k = 2
输出：2
解释：两行去重后都只剩 {1}，intersect = 1 < 2，无边 → 各自成一个分量。
```

**补充边界**

```text
输入：properties = [[5]], k = 1
输出：1
解释：n = 1 时不存在任何配对，单点即一个分量。
```

## 3. 解题思路

### 3.1 暴力思路：哈希集合两两求交

把每行塞进 `set`，对每对 $(i, j)$ 求一次集合交集的大小。配对共 $\binom{100}{2} = 4950$ 个，每次 $O(m)$，总计约 $5 \times 10^5$ 次哈希操作——本题数据规模下**完全能过**。它的问题不在超时，而在于：① 浪费了「值域 $\le 100$」这个题眼，代码更长、常数更大；② 周赛里「值域受限 → 位掩码」应当是条件反射，一眼看出就不该再写哈希版。

### 3.2 核心观察：值域 ≤ 100，一行压成一个位掩码

![位掩码核心观察](images/prop_graph_bitmask_concept.svg)

- **去重免费**：值 $v$ 对应掩码第 $v$ 位，同一值重复出现也只置一次位——位掩码天然完成去重，直接对上 intersect 的「不同值」语义（示例 3 的陷阱被顺手化解）。
- **交集 = 按位与 + popcount**：$\text{mask}_a \wedge \text{mask}_b$ 中值为 1 的位与公共值一一对应，于是

$$\text{intersect}(\text{properties}[i],\ \text{properties}[j]) = \text{popcount}(\text{mask}_i \,\&\, \text{mask}_j)$$

- 每对判定从「哈希集合求交」降到**一次按位与 + 一次 popcount**（101 位 ≈ 2 个机器字）。图中用示例 2 的前两行演示：$\{1,2,3\} \wedge \{2,3,4\} = \{2,3\}$，popcount $= 2 \ge k = 2$，连边。

### 3.3 算法流程：并查集顺手数分量

![并查集流程](images/prop_graph_dsu_flow.svg)

判定出边之后要数连通分量，三个候选：

| 方案 | 需要什么 | 评价 |
|------|----------|------|
| DFS / BFS | 邻接表 + visited 数组 | 要先建表，多一轮代码 |
| 并查集 | 一个 `fa` 数组 | **边判定边合并，不建表，计数顺手** ✓ |

并查集计数套路：`comps` 从 $n$ 起步，每发生一次**异根合并**就减 1，最终 `comps` 即分量数（见 §5 定理）。

> 💡 **隐藏剪枝**：若某行不同值个数 $< k$，则它与任何行的交集 $\le$ 自身不同值数 $< k$，**必为孤立分量**（§5 引理 2），枚举时可直接跳过。$k$ 较大、重复值多时能砍掉大量无效配对。

### 3.4 示例演算

![示例1演算](images/prop_graph_walkthrough.svg)

对示例 1（$n = 6, k = 1$）按 $i < j$ 顺序枚举，只列出触发合并的事件：

| 配对 | 共享值集 | intersect | $\ge k=1$？ | 动作 | comps |
|------|----------|-----------|-------------|------|-------|
| (0, 1) | {1} | 1 | ✓ | union | 6 → 5 |
| (2, 3) | {4} | 1 | ✓ | union | 5 → 4 |
| (3, 4) | {5} | 1 | ✓ | union | 4 → 3 |
| 其余 12 对 | ∅ | 0 | ✗ | 跳过 | 3 |

枚举完毕，`comps = 3`，与图中三个分量 $\{0,1\}$、$\{2,3,4\}$、$\{5\}$ 吻合。

## 4. 算法细节

1. **压位**：C++ 用 `bitset<101>`（值域含 100，必须开 101 位）；Python 直接用大整数 `mask[i] |= 1 << v`。
2. **判定**：`(mask[i] & mask[j]).count() >= k`；Python 3.10+ 用 `.bit_count()`，旧版本 `bin(x).count("1")`。
3. **并查集**：`fa` 初始化为自身；`find` 用隔代路径压缩 `fa[x] = fa[fa[x]]`，本题 $n \le 100$，无需按秩合并。
4. **计数**：仅当 `find(i) != find(j)` 才执行 `fa[find(i)] = find(j)` 且 `comps -= 1`；同一分量内的重复连边**不再减**。
5. **枚举顺序**：只枚举 $i < j$，无向边判定一次即可；无自环（题面 $i \ne j$）。

## 5. 正确性证明

**引理 1（掩码刻画交集）**：设 $S_i$ 为 `properties[i]` 去重后的值集，$\text{mask}_i = \sum_{v \in S_i} 2^v$。则对任意 $i \ne j$：$\text{mask}_i \,\&\, \text{mask}_j$ 中值为 1 的位数恰等于 $\left| S_i \cap S_j \right| = \text{intersect}(\text{properties}[i], \text{properties}[j])$。

**证明**：第 $v$ 位在按位与结果中为 1 $\iff$ 两个掩码的第 $v$ 位均为 1 $\iff$ $v \in S_i$ 且 $v \in S_j$ $\iff$ $v \in S_i \cap S_j$。即结果的每个 1 位恰好对应一个公共值，1 的位数与公共值个数相等。∎

**引理 2（必孤立判定）**：若 $\left| S_i \right| < k$，则节点 $i$ 在图中度为 0。

**证明**：对任意 $j \ne i$，$\text{intersect}(i, j) = \left| S_i \cap S_j \right| \le \left| S_i \right| < k$，不满足建边阈值，故 $i$ 没有任何邻边。∎

**定理（分量计数）**：按 §3.3 流程执行（`comps` 初值为 $n$，对每个满足 popcount $\ge k$ 的配对执行「异根则合并并减一」），最终 `comps` 等于图的连通分量数。

**证明**：由引理 1，算法连边的条件与题意 $\text{intersect} \ge k$ 严格一致，故判定阶段无遗漏、无多连。对边的处理顺序做归纳：并查集维护的等价类始终等于「已处理边集」导出的连通关系——初始无边时每点自成一类，共 $n$ 类；处理一条两端异根的边时，它恰好把两个此前互不连通的分量缝合成一个，分量数减 1；两端同根则该边两端已连通，分量数不变。所有 $\binom{n}{2}$ 个配对处理完后，等价类即图 $G$ 的连通分量，其个数恰为 `comps` $= n - $ 有效合并次数。∎

## 6. 复杂度分析

- **时间复杂度**：$O\!\left(nm + n^2 \cdot \lceil V/64 \rceil\right)$，$V = 101$。建掩码 $O(nm) \le 10^4$；两两判定 $\binom{100}{2} \approx 5 \times 10^3$ 对，每对约 2 个机器字的按位与加一次 popcount；并查集 `find` 近乎 $O(1)$（反阿克曼函数 $\alpha$）。总计约 $2 \times 10^4$ 量级，瞬间完成。
- **空间复杂度**：$O\!\left(n \cdot \lceil V/64 \rceil + n\right)$——掩码数组加并查集 `fa`，合计不超过几百字。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int numberOfComponents(vector<vector<int>>& properties, int k) {
        int n = properties.size();
        vector<bitset<101>> mask(n);
        for (int i = 0; i < n; i++) {
            for (int v : properties[i]) mask[i][v] = 1;
        }

        vector<int> fa(n);
        iota(fa.begin(), fa.end(), 0);
        auto find = [&](int x) {
            while (fa[x] != x) x = fa[x] = fa[fa[x]];
            return x;
        };

        int comps = n;
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                if ((mask[i] & mask[j]).count() >= k) {
                    int a = find(i), b = find(j);
                    if (a != b) {
                        fa[a] = b;
                        comps--;
                    }
                }
            }
        }
        return comps;
    }
};
```

### Python

```python
class Solution:
    def numberOfComponents(self, properties: List[List[int]], k: int) -> int:
        n = len(properties)
        mask = [0] * n
        for i, row in enumerate(properties):
            for v in row:
                mask[i] |= 1 << v

        fa = list(range(n))

        def find(x: int) -> int:
            while fa[x] != x:
                fa[x] = fa[fa[x]]
                x = fa[x]
            return x

        comps = n
        for i in range(n):
            for j in range(i + 1, n):
                if (mask[i] & mask[j]).bit_count() >= k:
                    a, b = find(i), find(j)
                    if a != b:
                        fa[a] = b
                        comps -= 1
        return comps
```

## 8. 边界情况与易错点

1. **「不同整数」是头号陷阱**：示例 3 中 $[1,1]$ 与 $[1,1]$ 的 intersect 是 1 而不是 2。不去重时 $k = 2$ 会错误连边，把答案 2 判成 1。位掩码按位存值天然去重；若写哈希集合版，务必先对每行去重。
2. **不同值不足 $k$ 的行必孤立**：$k \le m$ 只约束到列数，某行去重后可能连 $k$ 个不同值都凑不齐（如 $[7,7], k = 2$），此时该点自成分量——直接枚举也能算对，但可作为剪枝跳过（引理 2）。
3. **同根不再减**：同一分量内出现第 2、3 条边时 `find(i) == find(j)`，`comps` 不能再减——三角形三个点三条边，分量数只减 2。
4. **$n = 1$**：不存在任何配对，答案 1，算法自然成立无需特判。
5. **C++ `bitset` 要开 101 位**：值 100 需要下标 100；Python 无此顾虑（大整数），但 3.10 之前没有 `bit_count()`，需用 `bin(x).count("1")`。
6. **只枚举 $i < j$**：无向图边对称，判两次纯属浪费；自环不存在（题面 $i \ne j$）。
