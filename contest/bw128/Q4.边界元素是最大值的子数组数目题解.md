# LeetCode 边界元素是最大值的子数组数目 题解

## 1. 题目概述

- **标题 / 题号**：边界元素是最大值的子数组数目（#3113，hard）
- **链接**：https://leetcode.cn/problems/find-the-number-of-subarrays-where-boundary-elements-are-maximum/
- **来源**：LeetCode 第 128 场双周赛 Q4
- **难度**：困难
- **标签**：栈，数组，二分查找，单调栈

**题意**：给定正整数数组 `nums`，统计有多少个子数组满足：**第一个元素和最后一个元素都是该子数组中的最大值**（即 $nums[l] = nums[r] = \max(nums[l..r])$）。

**约束**：

- $1 \le nums.length \le 10^5$
- $1 \le nums[i] \le 10^9$
- 返回值类型为 `long`（答案可达 $n(n+1)/2 \approx 5 \times 10^9$）

> 💡 子数组的第一个元素就是 $nums[l]$、最后一个是 $nums[r]$，所以条件等价于：$nums[l] = nums[r]$ 且区间内**没有**严格大于它的元素。

## 2. 示例

**示例 1**

```text
输入：nums = [1,4,3,3,2]
输出：6
解释：合法的是 [1]（下标 0）、[4]（下标 1）、[3]（下标 2）、[3]（下标 3）、[2]（下标 4）以及 [3,3]（下标 2..3）。
```

**示例 2**

```text
输入：nums = [3,3,3]
输出：6
解释：任意子数组的首尾都是 3，也是最大值；共 3 + 2 + 1 = 6 个。
```

**示例 3**

```text
输入：nums = [1]
输出：1
解释：单元素子数组必然满足条件。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有 $l \le r$，求区间最大值并判断首尾是否等于它。用 ST 表或前缀最大值可以做到 $O(1)$ 查询，但枚举子数组本身是 $O(n^2)$，$n = 10^5$ 时约 $5 \times 10^9$ 次检查，超时。需要一种「增量维护候选左端点」的办法。

### 3.2 核心观察：固定右端点，合法左端点只能是某些「同值」位置

![合法与不合法：中间是否出现更大的元素](images/bw128_q4_pairing.svg)

固定右端点 $r$，考虑哪些 $l \le r$ 能让 $[l, r]$ 合法。条件有两部分：

1. $nums[l] = nums[r]$（首尾相等且等于最大值）；
2. $l$ 到 $r$ 之间没有比 $nums[r]$ 更大的元素（否则最大值就不是它了）。

于是天然想到：把所有「可能成为左端点」的位置，按它们的值分组维护。当处理到 $r$ 时：

- 所有**值小于** $nums[r]$ 的候选位置，此后都不可能再作为任何区间的最大值（因为 $nums[r]$ 比它们大，且 $r$ 会一直留在区间里）——可以整体丢弃；
- 值**等于** $nums[r]$ 的候选位置，恰好全部满足条件 2（它们与 $r$ 之间没有更大的元素，否则早被丢弃了），于是与 $r$ 一一配对，贡献等于这些候选的个数；
- $r$ 自身也是一个新的候选（对应单元素区间 $[r,r]$，必然合法）。

这正好对应一个**单调栈**：栈中保存 $(值, 该值当前可用的候选个数)$，值**严格递减**。

### 3.3 算法流程

![单调栈在示例数组上的逐步演化](images/bw128_q4_stack_model.svg)

```text
1. ans = 0，栈 st 为空（栈底到栈顶的值严格递减）
2. for x in nums:
       while st 非空 and st.top().value < x:
           st.pop()                       # 比 x 小的值被 x 永久淘汰
       if st 非空 and st.top().value == x:
           ans += st.top().count          # 与每个候选左端点各构成一个合法区间
           st.top().count += 1            # x 自己也可作为未来的左端点
       else:
           st.push((x, 1))
       ans += 1                           # 单元素区间 [i, i]
3. return ans
```

### 3.4 示例演算

![逐步累加 ans 的演算表](images/bw128_q4_walkthrough.svg)

以 `nums = [1,4,3,3,2]` 为例：

| $i$ | $x$ | 处理后的栈（值, 计数） | 新增区间数 | `ans` |
|-----|-----|--------------------------|------------|-------|
| 0 | 1 | $(1,1)$ | 1 | 1 |
| 1 | 4 | $(4,1)$（弹出 1） | 1 | 2 |
| 2 | 3 | $(4,1),\ (3,1)$ | 1 | 3 |
| 3 | 3 | $(4,1),\ (3,2)$ | 2 | 5 |
| 4 | 2 | $(4,1),\ (3,2),\ (2,1)$ | 1 | 6 |

最终 6，与题面一致。注意 $i = 3$ 时一次新增 2 个：$[3]$（下标 2..3 的 `[3,3]`）与 $[3]$（下标 3 的单元素）。

## 4. 算法细节

1. **弹出条件是 `<` 而不是 `<=`**：相等的值必须保留在栈里，它们是能配对的候选。写成 `<=` 会把候选全部弹光，示例 2 立刻出错。
2. **计数的含义**：栈顶 $(v, c)$ 的 $c$ 等于「满足 $nums[l] = v$ 且 $l$ 与当前位置之间没有比 $v$ 大的元素的 $l$ 的个数」。因此新增合法区间数恰为 $c$。
3. **相等时先累加再自增**：`ans += c; c += 1`。顺序不能反，否则会把「$x$ 与自身配对」多算一次（那个由最后统一 `+1` 负责）。
4. **单元素区间**：每次循环都 `+1`，不要忘记；它对应「$x$ 自己作为左端点与右端点」的情形。
5. **$long long$**：答案为 $n(n+1)/2 \approx 5 \times 10^9$，超过 32 位，C++ 必须用 `long long`（Python 无此问题）。
6. **栈的空间**：可能保存 $n$ 个元素（数组严格递减时），$O(n)$。
7. **等价写法**：也可以先按值分组、记录每组的位置列表，再用单调栈/二分计算每个位置右侧第一个更大元素，逐组累加贡献——本质相同，但常数与代码量都更大。

## 5. 正确性证明

**引理 1（栈不变式）**：设处理完下标 $i$ 后栈为 $(v_1, c_1), \dots, (v_t, c_t)$，则

1. $v_1 > v_2 > \dots > v_t$；
2. 对每个 $j$，$c_j = \#\{\,l \le i : nums[l] = v_j \text{ 且 } \max(nums[l..i]) = v_j\,\}$。

**证明**：对 $i$ 归纳。$i = 0$ 时栈为 $(nums[0], 1)$，条件 2 中只有 $l = 0$ 满足，成立。

设处理 $i$ 前（即处理完 $i-1$ 后）不变式成立，当前元素为 $x = nums[i]$。

- 弹出所有 $v_j < x$ 的项：这些项对应的 $l$ 满足 $\max(nums[l..i-1]) = v_j < x$，故 $\max(nums[l..i]) = x \ne v_j$，计数应变为 0，弹出正确。
- 保留下来的项满足 $v_j > x$（严格递减栈中只剩 $> x$ 的值）：对这些 $l$，$\max(nums[l..i]) = \max(v_j, x) = v_j$，计数不变，正确。
- 若栈顶 $v_t = x$：其计数 $c_t$ 统计的是 $\max(nums[l..i-1]) = x$ 的 $l$，加上 $x$ 后 $\max(nums[l..i]) = x$ 仍成立；再加上 $l = i$（新候选，$\max(nums[i..i]) = x$），故计数应为 $c_t + 1$。代码正是先累加 $c_t$ 再把计数 $+1$。
- 若弹出后栈顶 $\ne x$（或栈为空）：以 $x$ 为最大值的左端点只剩 $l = i$，压入 $(x, 1)$，正确。

条件 1（严格递减）由「弹出所有更小值、只在栈顶不等于 $x$ 时压栈」保证。∎

**引理 2（单步贡献）**：设处理 $i$ 之前栈非空、栈顶为 $(v, c)$，则以下标 $i$ 结尾的合法子数组恰有 $[v = nums[i]] \cdot c + 1$ 个。

**证明**：合法子数组 $[l, i]$ 需要 $nums[l] = nums[i]$，且 $[l, i]$ 内没有大于 $nums[i]$ 的元素（等于它的元素无妨）。

先看 $l < i$ 的情形。由引理 1 的不变式，处理 $i-1$ 后，栈中值为 $v$ 的那一项的计数，正是「满足 $nums[l] = v$ 且 $[l, i-1]$ 内最大值仍为 $v$」的 $l$ 的个数——这正是 $nums[i] = v$ 时所需的候选。处理 $i$ 时算法先弹出所有**小于** $nums[i]$ 的项，因此：若栈中原本存在值为 $nums[i]$ 的项，它上方的项值都更小、已被弹出，此刻它必为栈顶，`st.top().value == x` 恰好识别出这种情况，累加的 $c$ 就是候选数；若不存在这样的项，说明所有同值位置都已被更大的元素隔断，这样的 $l$ 一个也没有，贡献为 0。最后加上 $l = i$ 的单元素区间，即得 $[v = nums[i]] \cdot c + 1$。∎

**定理**：算法输出的 `ans` 等于满足条件的子数组总数。

**证明**：每个合法子数组有唯一的右端点 $i$，故总数 $=$ 对每个 $i$ 求「以 $i$ 结尾的合法子数组数」之和。由引理 2，算法在每轮恰好累加该数量（`ans += c`（若相等）+ `ans += 1`）。因此总和正确。∎

## 6. 复杂度分析

- **时间**：$O(n)$。每个元素至多入栈一次、出栈一次，均摊 $O(1)$。
- **空间**：$O(n)$，栈最深 $n$（数组严格递减时）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long numberOfSubarrays(vector<int>& nums) {
        long long ans = 0;
        vector<pair<int, int>> st;   // (值, 该值当前可当左端点的个数)，值严格递减
        for (int x : nums) {
            while (!st.empty() && st.back().first < x)
                st.pop_back();       // 比 x 小的值不可能再成为任何区间的最大值
            if (!st.empty() && st.back().first == x) {
                ans += st.back().second;   // 与之前每个同值左端点各构成一个合法区间
                ++st.back().second;        // x 自己也能当未来的左端点
            } else {
                st.push_back({x, 1});
            }
            ++ans;                   // 单元素区间 [i, i]
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def numberOfSubarrays(self, nums: list[int]) -> int:
        ans = 0
        st = []                      # [(值, 该值当前可当左端点的个数)]，值严格递减
        for x in nums:
            while st and st[-1][0] < x:
                st.pop()             # 比 x 小的值不可能再成为任何区间的最大值
            if st and st[-1][0] == x:
                ans += st[-1][1]     # 与之前每个同值左端点各构成一个合法区间
                st[-1][1] += 1
            else:
                st.append([x, 1])
            ans += 1                 # 单元素区间 [i, i]
        return ans
```

> 💡 两份代码均通过官方三个示例（`6`、`6`、`1`），并与 $O(n^2)$ 暴力（枚举所有子数组求最大值）对拍了 500 组随机数据（$n \le 12$，值域 $[1,5]$ 制造大量重复），结果完全一致；$n = 10^5$ 全等数组的极限数据输出 $5000050000$，验证了 64 位必要性。

## 8. 边界情况与易错点

1. **$n = 1$**：答案 1。
2. **全部元素相等**：答案是 $n(n+1)/2$，必须用 64 位整数（示例 2 是 $n = 3$ 的小情形）。
3. **严格递增**：如 `[1,2,3]`，每个元素都会把前一个弹出，答案恰为 $n$（只有单元素区间）。
4. **严格递减**：如 `[3,2,1]`，栈一直增长，但从不相等，答案同样是 $n$；不要误以为递减数组有很多合法区间。
5. **弹出条件**：必须 `st.back().first < x`，写成 `<=` 会破坏「相等可配对」。
6. **相等时计数顺序**：先 `ans += count` 再 `count += 1`；若先自增会多算「自己配自己」。
7. **单元素区间别漏**：每次循环无条件 `+1`，这是很多人少算的来源。
8. **返回值类型**：题目要求 `long`，C++ 用 `long long` 返回（LeetCode 的 `long` 在 C++ 中即 `long long` 语义）。

**延伸思考**：把「最大值」换成「最小值」，得到的是对称问题——只需把单调栈的比较方向反过来（栈内递增、弹出更大的值）。若把条件放宽为「首尾相等」而不要求是最大值，问题就变成统计「相同元素对且区间内无更大约束」的组合，用哈希表按值分组 + 记录未被更大值隔断的位置数即可，思路与本题一致。另一个方向是**离线按值分组**：从大到小枚举值，用并查集把「大于当前值」的位置隔开，逐组统计连续段内的同值位置对——这条路线复杂度 $O(n \alpha(n))$，与单调栈等价但更好扩展到「统计所有满足条件的区间长度之和」等变体。
