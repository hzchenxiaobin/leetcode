# LeetCode 访问消失节点的最少时间 题解

## 1. 题目概述

- **标题 / 题号**：访问消失节点的最少时间（#3112，medium）
- **链接**：https://leetcode.cn/problems/minimum-time-to-visit-disappearing-nodes/
- **来源**：LeetCode 第 128 场双周赛 Q3
- **难度**：中等
- **标签**：图，数组，最短路，堆（优先队列）

**题意**：给定 $n$ 个点的无向带权图（边权为通过时间）与数组 `disappear`，`disappear[i]` 表示节点 $i$ 在时刻 `disappear[i]` **及以后**不可访问。求从节点 0 出发到每个节点的最少耗时；若无法在节点消失前到达，则该点答案为 $-1$。

**约束**：

- $1 \le n \le 5 \times 10^4$
- $0 \le edges.length \le 10^5$
- $1 \le length_i \le 10^5$
- $1 \le disappear[i] \le 10^5$
- 图可能不连通，可能存在重边

> 💡 与朴素最短路唯一的差别：松弛前要判断「到达时刻是否仍早于该节点的消失时刻」，且必须是**严格**小于。

## 2. 示例

**示例 1**

```text
输入：n = 3，edges = [[0,1,2],[1,2,1],[0,2,4]]，disappear = [1,1,5]
输出：[0,-1,4]
解释：到 1 需 2，但 2 ≥ disappear[1] = 1，不可达；到 2 直接走 4 < 5，可达。
```

**示例 2**

```text
输入：n = 3，edges = [[0,1,2],[1,2,1],[0,2,4]]，disappear = [1,3,5]
输出：[0,2,3]
解释：到 1 只需 2 < 3；到 2 经 1 中转只需 2 + 1 = 3 < 5，比直达的 4 更快。
```

**示例 3**

```text
输入：n = 2，edges = [[0,1,1]]，disappear = [1,1]
输出：[0,-1]
解释：到达节点 1 的时刻恰好是 1，等于 disappear[1]，在「那一刻及以后」不可访问，故失败。
```

## 3. 解题思路

### 3.1 暴力思路

枚举从 0 出发的所有路径并检查沿途每个节点的到达时刻——路径数量指数级，不可行。用 BFS 也不行：边权不同，BFS 只能处理无权图。所以基本框架只能是**带权最短路（Dijkstra）**，问题在于如何把「节点会消失」这一约束嵌进去。

### 3.2 核心观察：越早到达越有利

![带权图与消失时刻：到达时间必须严格早于 disappear](images/bw128_q3_graph_model.svg)

关键性质是**单调性/支配性**：如果我们能在一个时刻 $t$ 到达节点 $v$，那么以 $v$ 为跳板继续前进时，所有后续到达时刻都是 $t$ 加上若干正边权。到达 $v$ 越早，后续每个节点的到达时刻都**不晚**，而所有约束都是「到达时刻 < 消失时刻」这种**上界**约束。因此：

> 对每个节点，只需要保留「最早可行到达时间」这一个标号，晚到的方案永远不会更优。

这正是 Dijkstra 的使用前提。于是算法与标准 Dijkstra 几乎相同，只在**松弛边时**多加一个条件：

$$nd = d + w, \qquad \text{仅当 } nd < disappear[v] \text{ 时才更新 } dist[v]$$

### 3.3 算法流程

![Dijkstra 流程与唯一的改动](images/bw128_q3_dijkstra_flow.svg)

```text
1. dist[0] = 0，其余为 INF；堆 = [(0, 0)]
2. while 堆非空:
       弹出 (d, u)；若 d > dist[u] 则跳过（过期堆项）
       for (v, w) in adj[u]:
           nd = d + w
           if nd >= disappear[v]: continue      # 到达时已消失，这条路作废
           if nd < dist[v]:
               dist[v] = nd
               入堆 (nd, v)
3. answer[i] = dist[i] < INF ? dist[i] : -1
```

注意：起点 0 的时间是 0，而 $disappear[0] \ge 1$，所以 $0 < disappear[0]$ 恒成立，起点永远可用（无需特判）。

## 4. 算法细节

1. **必须严格小于**：题意是「在那一刻及以后无法访问」，所以 `nd >= disappear[v]` 一律丢弃。示例 3 就是恰好相等于消失时刻的反例。
2. **只在松弛时判断**：因为进入堆的所有 `dist` 都满足 `< disappear`，出堆时无需再判一次；再判也不会错，只是多余。
3. **过期堆项**：同一节点可能被多次入堆，出堆时用 `if (d > dist[u]) continue;` 剪掉旧标号，这是 Dijkstra 的标准写法。
4. **起点不判消失**：$disappear[0] \ge 1 > 0$，天然可用；如果强行写 `if (0 >= disappear[0])` 会多此一举。
5. **重边与自环**：重边保留最小值即可（代码不特判，Dijkstra 会自动取较优者）；自环 `u == v` 不影响正确性。
6. **非连通**：`dist` 保持 `INF` 的节点输出 $-1$。
7. **数值类型**：所有可行的 `dist` 都 $< 10^5$，`int` 足够；但 `d + w` 与 `INF` 的选取建议用 `long long`，避免把 `INT_MAX` 当 `INF` 后加法溢出。
8. **复杂度**：邻接表 + 二叉堆，$O((n + m) \log n)$，$n = 5 \times 10^4$、$m = 10^5$ 时轻松通过。

## 5. 正确性证明

**引理 1（严格早于约束的传递性）**：设路径 $0 = v_0, v_1, \dots, v_t = v$ 的到达时刻依次为 $0 = T_0 < T_1 < \dots < T_t$（边权为正）。该路径**可行**当且仅当对每个 $j \ge 1$ 有 $T_j < disappear[v_j]$。

**证明**：由定义，节点 $v_j$ 在 $T_j$ 时刻被访问，需 $T_j < disappear[v_j]$；各节点条件相互独立，故合取即为可行。∎

**引理 2（支配性）**：若节点 $u$ 存在可行路径到达（时刻 $t$），且 $t' \le t$ 也是某条可行路径的到达时刻，则对任何以 $u$ 为中间点的可行路径，把前缀替换为 $t'$ 那条路径后仍然可行，且后续每个节点的到达时刻都不晚于原来。

**证明**：设原路径自 $u$ 起的后缀边权为 $w_1, w_2, \dots$，原到达时刻为 $T_j = t + \sum_{i \le j} w_i$，替换后为 $T'_j = t' + \sum_{i\le j} w_i \le T_j$。而可行性条件是 $T_j < disappear[\cdot]$，由 $T'_j \le T_j < disappear[\cdot]$ 知替换后仍可行，且到达不晚。∎

**引理 3（标号的可靠性）**：算法每次把 `dist[v] = nd` 时，都存在一条真实路径，其到达 $v$ 的时刻为 $nd$ 且沿途各节点均满足消失约束。

**证明**：`nd = d + w`，其中 $d = dist[u]$ 且 $u$ 的标号由归纳假设对应一条可行路径（基：`dist[0] = 0` 对应空路径，$0 < disappear[0]$）。把边 $(u, v)$ 接在其后，中间节点的到达时刻不变，仍满足约束；终点 $v$ 的判定条件 `nd < disappear[v]` 已通过。故新标号对应真实可行路径。∎

**引理 4（出堆即最优）**：设算法以标号 $d = dist[u]$ 弹出节点 $u$，则不存在到达 $u$ 且时刻 $< d$ 的可行路径，即 $d$ 就是 $u$ 的最早可行到达时间。

**证明**：反设存在可行路径 $P: v_0 = 0, v_1, \dots, v_s = u$，到达时刻 $T_0 = 0 < T_1 < \dots < T_s = t < d$（边权为正，故时刻严格递增）。

先用归纳建立一个小结论：对 $P$ 上任一**已确定**（以等于 `dist` 的值出过堆）的节点 $v_j$，有 $dist[v_j] \le T_j$。$j = 0$ 时 $dist[0] = 0 = T_0$。设 $v_j$ 已确定且 $dist[v_j] \le T_j$，则它出堆时会松弛边 $(v_j, v_{j+1})$，得到

$$nd = dist[v_j] + w \le T_j + w = T_{j+1} < disappear[v_{j+1}]$$

因此 $dist[v_{j+1}]$ 被写成 $\le T_{j+1}$ 的值（或原本更小），$v_{j+1}$ 带着该值入堆。

取 $P$ 上最后一个已确定的节点 $v_j$：$v_0$ 已确定故存在，而 $v_s = u$ 此刻才出堆、尚未确定，故 $j < s$。由小结论 $dist[v_j] \le T_j$，于是松弛 $(v_j, v_{j+1})$ 时写入堆的值 $\le T_{j+1} < d$。而 $v_{j+1}$ 尚未确定，其标号项仍在堆中，这说明堆里存在 $< d$ 的元素，与「$(d, u)$ 是当前堆中最小元素」矛盾。故不存在这样的路径。∎

**定理**：算法输出的 `dist[i]` 等于从 0 到 $i$ 的、满足所有消失约束的最早到达时刻；若不存在这样的路径则输出 $-1$。

**证明**：由引理 3，每个非 `INF` 的 `dist[i]` 都对应真实可行路径，故 `dist[i]` $\ge$ 真实最早到达时间 $t^*$。反之，沿最优可行路径逐点归纳：设其到达时刻为 $T_0 = 0, T_1, \dots$，假设算法确定到 $v_{j-1}$ 时已有 $dist[v_{j-1}] \le T_{j-1}$（基：$dist[0] = 0 = T_0$），则该边被松弛时 $nd \le T_j < disappear[v_j]$，于是 $dist[v_j] \le T_j$ 被写入（可能更早）。归纳得 $dist[i] \le t^*$。两向夹逼得 `dist[i] = t^*`；`INF` 的情形对应不存在可行路径，输出 $-1$。∎

## 6. 复杂度分析

- **时间**：$O((n + m) \log n)$。每条边至多触发一次成功的松弛（实际上每次成功松弛还会入堆，总入堆次数 $\le m + 1$），堆操作 $O(\log n)$。
- **空间**：$O(n + m)$。邻接表 $2m$ 条有向边、`dist` 数组 $O(n)$、堆 $O(m)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> minimumTime(int n, vector<vector<int>>& edges, vector<int>& disappear) {
        const long long INF = LLONG_MAX / 4;
        vector<vector<pair<int, int>>> g(n);
        for (const auto& e : edges) {
            g[e[0]].push_back({e[1], e[2]});    // 无向图双向建边
            g[e[1]].push_back({e[0], e[2]});
        }
        vector<long long> dist(n, INF);
        priority_queue<pair<long long, int>, vector<pair<long long, int>>,
                       greater<pair<long long, int>>> pq;
        dist[0] = 0;
        pq.push({0, 0});
        while (!pq.empty()) {
            auto [d, u] = pq.top();
            pq.pop();
            if (d > dist[u]) continue;          // 过期堆项
            for (const auto& [v, w] : g[u]) {
                long long nd = d + w;
                if (nd >= disappear[v]) continue;   // 到达时 v 已消失
                if (nd < dist[v]) {
                    dist[v] = nd;
                    pq.push({nd, v});
                }
            }
        }
        vector<int> ans(n, -1);
        for (int i = 0; i < n; ++i)
            if (dist[i] < INF) ans[i] = (int)dist[i];
        return ans;
    }
};
```

### Python

```python
class Solution:
    def minimumTime(self, n: int, edges: list[list[int]], disappear: list[int]) -> list[int]:
        import heapq
        INF = float('inf')
        g = [[] for _ in range(n)]
        for u, v, w in edges:
            g[u].append((v, w))                 # 无向图双向建边
            g[v].append((u, w))
        dist = [INF] * n
        dist[0] = 0
        pq = [(0, 0)]
        while pq:
            d, u = heapq.heappop(pq)
            if d > dist[u]:                     # 过期堆项
                continue
            for v, w in g[u]:
                nd = d + w
                if nd >= disappear[v]:          # 到达时 v 已消失
                    continue
                if nd < dist[v]:
                    dist[v] = nd
                    heapq.heappush(pq, (nd, v))
        return [-1 if d == INF else d for d in dist]
```

> 💡 两份代码均通过官方三个示例（`[0,-1,4]`、`[0,2,3]`、`[0,-1]`），并与「DFS 枚举所有简单路径」的暴力对拍了 400 组随机数据（$n \le 6$，含重边、自环、不连通），结果完全一致；$n = 5 \times 10^4$、$m = 10^5$ 的极限数据运行约 0.36 秒（含 I/O）。

## 8. 边界情况与易错点

1. **恰好等于消失时刻**：必须判为不可达（示例 3），条件写成 `nd >= disappear[v]` 就丢弃；写成 `>` 会错。
2. **$n = 1$、无边**：答案就是 `[0]`；起点无需任何时间。
3. **起点自身消失时刻很小**：$disappear[0] = 1$ 时 $0 < 1$ 仍成立，起点始终可用；不要错误地在起点上也做一次判定。
4. **不可达**：图不连通、或必须经过已消失的节点，都输出 $-1$。
5. **重边**：不必预处理去重，保留全部边即可（Dijkstra 自然取优）；但若自己写邻接矩阵就会踩内存坑。
6. **`INF` 溢出**：C++ 中不要把 `INT_MAX` 直接用来做加法，用 `LLONG_MAX / 4` 之类的值更安全。
7. **节点消失后仍可能被「发现」**：算法丢弃的是「到达时刻不早于消失时刻」的边，不会删除节点本身，因此其他路径仍可绕过它——这正是我们想要的行为。
8. **负权不存在**：边权 $\ge 1$，Dijkstra 的前提成立；若边权为 0 或负，需要改算法。
