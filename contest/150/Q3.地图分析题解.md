# LeetCode 地图分析 题解

## 1. 题目概述

- **标题 / 题号**：地图分析（#1162，medium）
- **链接**：https://leetcode.cn/problems/as-far-from-land-as-possible/
- **来源**：LeetCode 第 150 场周赛 Q3
- **难度**：中等
- **标签**：广度优先搜索，数组，动态规划，矩阵

**题意**：给一个 $n \times n$ 的网格，`1` 表示陆地、`0` 表示海洋。对**每个海洋格**求出它到**最近的陆地格**的曼哈顿距离，返回这些距离中的**最大值**。若网格里全是陆地或全是海洋（没有海洋格可挑，或没有陆地可量），返回 $-1$。

**约束**：

- $n = \text{grid.length} = \text{grid}[i]\text{.length}$
- $1 \le n \le 100$
- `grid[i][j]` 只能是 `0` 或 `1`
- 曼哈顿距离：$d\big((x_0,y_0),(x_1,y_1)\big) = |x_0 - x_1| + |y_0 - y_1|$

> 💡 网格规模只有 $100 \times 100$，状压、线段树之类都无需考虑，关键是把「每个海洋格各自找最近陆地」的**重复劳动**消掉。

## 2. 示例

**示例 1**

```text
输入：grid = [[1,0,1],[0,0,0],[1,0,1]]
输出：2
解释：四角是陆地。海洋格 (1,1) 到四块陆地的距离都是 2，是所有海洋格中最大的。
```

**示例 2**

```text
输入：grid = [[1,0,0],[0,0,0],[0,0,0]]
输出：4
解释：唯一的陆地是左上角 (0,0)。海洋格 (2,2) 到它的曼哈顿距离是 2 + 2 = 4，为最大。
```

**示例 3（边界）**

```text
输入：grid = [[1]]
输出：-1
解释：网格里没有海洋格；同理 grid = [[0]] 返回 -1（没有陆地）。
```

## 3. 解题思路

### 3.1 暴力思路

对每个海洋格单独跑一次 BFS（或直接枚举所有陆地格算曼哈顿距离），求出它的最近陆地距离，再取最大值。

- 枚举法：$O(n^4)$。$n = 100$ 时约有 $10^8$ 次距离计算，C++ 勉强能过，Python 必超时。
- 逐格 BFS：同样是 $O(n^4)$，而且**每个海洋格都把整张图重新扫一遍**，其中绝大多数工作是重复的。

瓶颈在于：最近陆地这一个信息，对每个海洋格都**重新计算了一次**，而它其实可以由邻居「接力」得到。

### 3.2 核心观察：多源 BFS

![多源 BFS：陆地同时出发，一次扩散出全部距离](images/wc150_q3_multisource_bfs.svg)

**关键转化**：构造一个虚拟的**超级源点** $S$，把它到每块陆地的距离看成 $0$。于是「海洋格到最近陆地的距离」就等于「该格到 $S$ 的最短距离」——问题从 $n^2$ 个源点的最短路，变成**单源最短路**，而所有边权都是 $1$，用 BFS 即可。

实现上根本不需要真的建出 $S$：**把所有陆地格在第 $0$ 层一次性全部入队**，然后照常做 BFS。波纹从所有陆地同时向外扩散，一个海洋格**第一次**被波前碰到时，碰它的必然是与它最近的那块陆地的波前，此刻记录的层号就是答案。

由此得到一条极强的性质：**每个格子只会入队一次**，总工作量 $O(n^2)$，比暴力的 $O(n^4)$ 快了两个数量级。

> 💡 反向思考：不要问「这个海洋格离哪块陆地最近」，而要问「这一层波前能同时覆盖哪些海洋格」。多源 BFS 的第 $k$ 层，就是全部「距最近陆地恰好 $k$」的格子集合。

### 3.3 算法流程

![多源 BFS 主流程图](images/wc150_q3_bfs_flow.svg)

1. 扫一遍网格，统计陆地数 `cnt`；同时把每个陆地格的距离置 $0$ 并入队，海洋格距离置 $-1$（兼作「未访问」标记）。
2. 若 `cnt == 0`（全海洋）或 `cnt == n * n`（全陆地），直接返回 $-1$。
3. 队列非空时反复弹出队首 $(x,y)$，枚举**上下左右**四个邻居：
   - 越界则跳过；
   - 距离不等于 $-1$ 说明已被更早（或同样早）的波前访问过，跳过；
   - 否则令 `dist[nx][ny] = dist[x][y] + 1`，用它更新答案 `ans`，再把 $(nx,ny)$ 入队。
4. 队列空时，`ans` 就是最大的层号，即答案。

**状态转移**（多源 BFS 的距离递推）：

$$\text{dist}[nx][ny] = \text{dist}[x][y] + 1, \qquad \text{dist}[\text{陆地}] = 0$$

**等价的 DP 写法**（标签里的「动态规划」）：把网格距离场拆成两次方向扫描，第一次用上、左两个方向松弛，第二次用下、右两个方向松弛：

$$d[i][j] = \min\Big(d[i][j],\ \min\big(d[i-1][j],\ d[i][j-1]\big) + 1\Big)$$

$$d[i][j] = \min\Big(d[i][j],\ \min\big(d[i+1][j],\ d[i][j+1]\big) + 1\Big)$$

初值 $d[i][j] = 0$（陆地）或 $+\infty$（海洋）。因为曼哈顿距离的最短路径一定可以拆成「先向上/向左走，再向下/向右走」，两遍相反方向的松弛就覆盖了全部 4 个方向。两种写法复杂度相同，BFS 版本更好写也更好证，本文以 BFS 为主。

### 3.4 示例演算

![两个官方示例的分层演算](images/wc150_q3_walkthrough.svg)

以示例 1 的 `grid = [[1,0,1],[0,0,0],[1,0,1]]` 为例，四角是陆地：

| 阶段 | 队列内容（层号） | 本轮新染色的海洋格 | `ans` |
|------|------------------|--------------------|-------|
| 初始 | (0,0)、(0,2)、(2,0)、(2,2)（层 0） | 无 | −1 |
| 弹出层 0 | 4 个边格 (0,1)、(1,0)、(1,2)、(2,1)，层号 1 | 4 个 | 1 |
| 弹出层 1 | 中心 (1,1)，层号 2 | 1 个 | 2 |
| 队列空 | — | — | 返回 2 |

第 0 层是 4 块陆地，第 1 层是四条边的中点，第 2 层才轮到中心——中心到最近陆地的距离确实是 $2$，且它是最后被染色的格子，因此返回 $2$。

示例 2 中只有一个源点 (0,0)，层号就是从左上向右下递增的曼哈顿距离，右下角 (2,2) 在第 4 层才被覆盖，返回 $4$。

## 4. 算法细节

1. **用 $-1$ 同时表示「未访问」**：陆地写 $0$、海洋写 $-1$，于是 BFS 里判 `dist[nx][ny] == -1` 就同时完成了「还没被任何波前碰到」的判重，不需要额外的 `visited` 数组（越界仍需单独用下标范围判断）。
2. **先数陆地再改网格**：若想省掉 `dist` 矩阵、直接在 `grid` 上原地打层号，必须**先**统计 `cnt` 并提前判掉「全陆地/全海洋」，否则 `1` 被改写成 $0$ 之后就无法再区分陆地与第 $0$ 层。本文代码为可读性另开 `dist`。
3. **入队即标记**：距离赋值必须发生在入队的那一刻（而不是出队时），否则同一个格子会被多个邻居重复入队，队列最坏膨胀到 $4n^2$。
4. **队列的选型**：C++ 用 `vector` 加 `head` 下标（比 `std::queue` 少一次内存分配）；Python 用 `collections.deque`，**不要**用 `list.pop(0)`，那是 $O(n)$ 的搬移。
5. **答案只在「第一次访问」时更新**：`ans = max(ans, dist[nx][ny])`，陆地自身距离 $0$ 不参与更新；`ans` 初值取 $-1$ 正好覆盖「已提前返回」之外的所有情况。
6. **层号与距离等价**：BFS 的 FIFO 保证出队顺序按层号非降，因此 `dist[x][y] + 1` 不会出现「先给大值、后来才发现更小值」的情况，无需任何回退修正。
7. **四个方向用常量数组**：`dx[4] = {1,-1,0,0}`、`dy[4] = {0,0,1,-1}`，写成循环比手写四份 `if` 更短且不易漏方向。

## 5. 正确性证明

**引理 1（多源 BFS 等价于单源最短路）**：把全部陆地格的距离初始化为 $0$ 并一起入队后，BFS 赋予每个格子的 `dist` 值，等于它到「陆地集合」的最短曼哈顿距离。

**证明**：引入虚拟源点 $S$，令 $S$ 到每块陆地的边权为 $0$、相邻格子之间的边权为 $1$，则「海洋格到最近陆地的曼哈顿距离」正是 $S$ 到该格的最短路长度。把 $S$ 的 $0$ 权出边塌缩掉，正等价于「所有陆地初始距离为 $0$ 且同时入队」的多源 BFS。塌缩之后所有边权都是 $1$，BFS 按层扩展、出队序列的 `dist` 单调不减，因此每个顶点第一次被赋值时拿到的就是最短路长度。∎

**引理 2（每个格子至多入队一次，且 `ans` 恰为最大距离）**：BFS 过程中每个格子最多入队一次；结束时 `ans` 等于所有海洋格 `dist` 的最大值。

**证明**：格子只在 `dist == -1` 时被赋值并入队，赋值后 `dist` 非负，故不可能再次入队，第一部分成立。`ans` 的每次更新都发生在某个海洋格第一次被赋值的瞬间，取 `max` 后不再减小；又每个海洋格都会在有限步内被某个陆地的波前覆盖（网格连通，路径长度有界），所以所有海洋格的 `dist` 都参与过比较。故 `ans` 为最大值。∎

**定理**：算法返回值即为题目所求的最大距离；当网格全为陆地或全为海洋时返回 $-1$。

**证明**：由引理 1，每个海洋格的 `dist` 就是它到最近陆地的曼哈顿距离；由引理 2，`ans` 是这些距离的最大值，即所要答案。全陆地时 `cnt == n * n`、全海洋时 `cnt == 0`，两种情况都在 BFS 之前被判定并返回 $-1$，与题意一致。∎

## 6. 复杂度分析

- **时间**：$O(n^2)$。初始化扫一遍 $O(n^2)$；BFS 中每个格子入队、出队各一次，每格检查 4 个邻居，共 $O(n^2)$ 次常数操作。相比暴力的 $O(n^4)$ 快了两个数量级。
- **空间**：$O(n^2)$。`dist` 矩阵 $O(n^2)$；队列里每个格子至多出现一次，故队列长度也不超过 $n^2$（多源时大量格子同层入队，实际长度与最外层波前的规模同阶）。若原地复用 `grid` 存层号，矩阵部分可压到 $O(1)$ 额外空间，只剩队列开销。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int maxDistance(vector<vector<int>>& grid) {
        int n = grid.size();
        vector<vector<int>> dist(n, vector<int>(n, -1));
        vector<pair<int, int>> q;              // 数组 + head 指针，比 queue 更快
        q.reserve(n * n);
        for (int i = 0; i < n; i++)
            for (int j = 0; j < n; j++)
                if (grid[i][j] == 1) {
                    dist[i][j] = 0;            // 所有陆地都是第 0 层
                    q.push_back({i, j});
                }
        if (q.empty() || (int)q.size() == n * n) return -1;   // 全海洋 / 全陆地

        int ans = -1;
        const int dx[4] = {1, -1, 0, 0}, dy[4] = {0, 0, 1, -1};
        for (size_t head = 0; head < q.size(); head++) {
            auto [x, y] = q[head];
            for (int d = 0; d < 4; d++) {
                int nx = x + dx[d], ny = y + dy[d];
                if (nx < 0 || nx >= n || ny < 0 || ny >= n) continue;
                if (dist[nx][ny] != -1) continue;              // 已经入队过
                dist[nx][ny] = dist[x][y] + 1;                 // 入队瞬间即标记
                ans = max(ans, dist[nx][ny]);
                q.push_back({nx, ny});
            }
        }
        return ans;
    }
};
```

### Python

```python
from typing import List
from collections import deque


class Solution:
    def maxDistance(self, grid: List[List[int]]) -> int:
        n = len(grid)
        dist = [[-1] * n for _ in range(n)]
        q = deque()
        for i in range(n):
            for j in range(n):
                if grid[i][j] == 1:
                    dist[i][j] = 0          # 所有陆地同时作为源点
                    q.append((i, j))
        if not q or len(q) == n * n:        # 全海洋 / 全陆地
            return -1

        ans = -1
        while q:
            x, y = q.popleft()
            for dx, dy in ((1, 0), (-1, 0), (0, 1), (0, -1)):
                nx, ny = x + dx, y + dy
                if 0 <= nx < n and 0 <= ny < n and dist[nx][ny] == -1:
                    dist[nx][ny] = dist[x][y] + 1
                    ans = max(ans, dist[nx][ny])
                    q.append((nx, ny))
        return ans
```

## 8. 边界情况与易错点

1. **全陆地 / 全海洋**：`[[1,1],[1,1]]` 与 `[[0,0],[0,0]]` 都必须返回 $-1$。只看「队列是否为空」会漏掉全陆地的情况，必须同时判 `cnt == n * n`。
2. **$n = 1$**：`[[1]]` 与 `[[0]]` 都返回 $-1$，这是最容易漏的最小规模；此时 `n * n == 1`，`cnt == 1` 会触发全陆地分支。
3. **答案初值不能取 $0$**：若取 $0$，全陆地时会错误返回 $0$；用 $-1$ 作初值，并且只对海洋格更新 `ans`，语义最干净。
4. **入队与标记的顺序**：若等到出队时才标记已访问，同一个格子会被它的多个邻居各入队一次，队列里同一格可能出现多份副本（最坏 4 份以上），Python 下这种常数膨胀足以把运行时间推过限制。
5. **原地修改 `grid` 的副作用**：若把层号写回 `grid`，必须**先**统计陆地数并判掉全陆地/全海洋，此后 `grid` 里再也读不到原始的 `0/1`；本地对拍时若在同一个对象上重复调用同一个函数，第二次拿到的就是被改写过的网格，会得到莫名其妙的错误结果。
6. **只走四连通**：题目是曼哈顿距离，只能上下左右；写成八方向（含对角）会得到切比雪夫距离，示例 1 会错答 $1$。
7. **Python 的队列操作**：`list.pop(0)` 是 $O(n)$，循环里用它会退化成 $O(n^3)$，务必用 `deque`。

**延伸思考**：如果距离改成**欧氏距离**，多源 BFS 立刻失效——此时要么对每个点做最近点查询（Voronoi 图 / KD 树），要么对答案二分半径再用「圆覆盖并查集」判定，复杂度都会高一个档次。如果改成允许障碍物的网格最短路，那么多源 BFS 依然成立，只需在扩展时跳过障碍格，这正说明它的本质是「源点集合上的单源最短路」而非某种几何技巧。另一条延伸是**两遍扫描的 DP**：它不需要队列，适合在只允许 $O(1)$ 额外空间的嵌入式场景下做距离变换。
