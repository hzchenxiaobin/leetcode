# LeetCode 数组的均值分割 题解

## 1. 题目概述

- **标题 / 题号**：数组的均值分割（#805，hard）
- **链接**：https://leetcode.cn/problems/split-array-with-same-average/
- **来源**：LeetCode 第 77 场周赛 Q4
- **难度**：困难
- **标签**：位运算、数组、哈希表、数学、动态规划、状态压缩、中途相遇

**题意**：把 `nums` 的每个元素分到 `A` 或 `B`（两边都非空，相当于取一个**非空真子集** `A`，其余归 `B`），问能否让 `average(A) == average(B)`。

**约束**：

- $1 \le \text{nums.length} \le 30$
- $0 \le \text{nums}[i] \le 10^4$

**关键点**：元素必须**全部用上**，所以 `A` 是下标子集；`n` 只有 30，但 $2^{30} \approx 10^9$ 不能直接枚举，而元素之和 $S \le 3\times 10^5$ 又小到可以做「和」维度的 DP。

## 2. 示例

**示例 1**

```text
输入：nums = [1,2,3,4,5,6,7,8]
输出：true
解释：[1,4,5,8] 与 [2,3,6,7] 的和都是 18、长度都是 4，平均值都是 4.5。
```

**示例 2**

```text
输入：nums = [3,1]
输出：false
解释：可能的切法只有 {3} / {1}，平均值 3 与 1 不同，无法相等。
```

**补充示例（用于检验边界，非官方）**

```text
输入：nums = [2,3,4]
输出：true
解释：{3} 的均值是 3，{2,4} 的均值也是 3，两边都非空。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有子集 `mask`（从 $1$ 到 $2^n-2$），累加子集和与元素个数，判断 $\frac{s}{c} = \frac{S}{n}$：单次判断 $O(n)$，总计 $O(n2^n)$。$n=30$ 时是 $3\times 10^{10}$ 量级，彻底超时。

换成「枚举大小 $k$ 再枚举组合」也救不回来：$\binom{30}{15} \approx 1.55\times 10^{8}$ 已经不小，而枚举组合本身的常数比子集枚举更高，Python 更是直接没戏。所以必须换维度：**不要枚举「选哪些」，而是枚举「和是多少」**。

### 3.2 核心观察：均值相等 ⇔ 某个子集和命中目标

![均值相等等价于子集和命中](images/wc77_q4_average_equivalence.svg)

设 $S = \sum \text{nums}$、$n = \lvert \text{nums} \rvert$，并令 $k = \lvert A \rvert$、$m = \lvert B \rvert = n-k$。

**第一步：两边均值都等于总均值**。记 $a = \operatorname{avg}(A)$、$b = \operatorname{avg}(B)$，若 $a = b = t$，则

$$S = a\cdot k + b\cdot m = t\,(k+m) = t\,n \;\Longrightarrow\; t = \frac{S}{n}$$

所以问题等价于：**是否存在大小 $k$、和恰为 $\dfrac{S\cdot k}{n}$ 的子集**。

**第二步：对称性把 $k$ 砍掉一半**。若 $A$ 可行，那么它的补集 $B$ 也满足 $\lvert B\rvert = n-k$ 且 $\operatorname{avg}(B) = \operatorname{avg}(A) = S/n$，因此 `A` 与 `B` 互为答案。于是只需检查

$$1 \le k \le \left\lfloor \frac{n}{2} \right\rfloor$$

这不仅砍掉一半工作量，还顺手排除了 $k=n$（全集）这种「把整个数组当成 `A`、`B` 为空」的伪解。

**第三步：先过整数关**。目标 $\dfrac{S\cdot k}{n}$ 必须是整数，否则直接跳过这个 $k$——这一步把候选 $k$ 从 15 个压到通常 2~4 个。

### 3.3 算法流程：按大小分层的 bitset 背包

![bitset 0/1 背包的转移与查询](images/wc77_q4_bitset_dp.svg)

定义 `dp[k]` 为**一个二进制整数**，它的第 $s$ 位为 1 表示「存在恰好 $k$ 个元素、和恰好为 $s$ 的子集」。那么「加入元素 $v$」的转移是一次**整行平移 + 按位或**：

$$\text{dp}[k] \;|\!=\! \text{dp}[k-1] \ll v$$

- 平移 $v$ 位 = 把「$k-1$ 元的和」整体变成「$k$ 元的和」；
- 按位或 = 保留「不选 $v$」的旧方案；
- **$k$ 必须倒序**（从 $\lfloor n/2 \rfloor$ 到 1），这样 `dp[k-1]` 还是「没考虑 $v$」的旧值，才是 0/1 背包而不是完全背包。

初始化 `dp[0] = 1`（只有空集和为 0）。所有元素扫完后，对每个满足 $S\cdot k \bmod n = 0$ 的 $k$ 检查 $\text{dp}[k]$ 的第 $t = S\cdot k/n$ 位：置位就返回 `true`，全部落空返回 `false`。

用整数位运算的好处：C++ 里 `std::bitset<300001>` 的 `<<` 与 `|` 由编译器展开成机器字循环，Python 里 `int` 的 `<<` / `|` 走大整数实现，都远比「两层循环扫布尔数组」快，且代码只有三行。

### 3.4 示例演算

![示例走查：k 从 1 试到 4](images/wc77_q4_walkthrough.svg)

以 `nums = [1,2,3,4,5,6,7,8]` 为例，$S = 36$、$n = 8$、$\lfloor n/2 \rfloor = 4$：

| $k$ | 目标 $S\cdot k/n$ | 整数？ | `dp[k]` 命中？ | 结论 |
|-----|-------------------|--------|----------------|------|
| 1 | 4.5 | 否 | — | 跳过 |
| 2 | 9 | 是 | `{1,8}` 和为 9 | **返回 true** |
| 3 | 13.5 | 否 | — | 跳过 |
| 4 | 18 | 是 | `{1,4,5,8}` 和为 18 | 也会命中 |

$k=2$ 时就已经命中：`A = {1,8}`（和 9，均值 4.5）、`B = {2,3,4,5,6,7}`（和 27，均值 4.5），程序直接返回。$k=4$ 那行只是复核官方示例给出的切法。

再看反例 `nums = [3,1]`：$S = 4$、$n = 2$、$\lfloor n/2 \rfloor = 1$，$k=1$ 的目标是 2，但单元素的可能和只有 3 和 1，第 2 位是 0，故返回 `false`。

## 4. 算法细节

1. **整数关用乘法判**：写 `S * k % n == 0`，不要写 `S * k / n` 再比较浮点。C++ 中 $S\cdot k \le 3\times 10^5 \times 15 = 4.5\times 10^6$，`int` 都放得下，但习惯上仍用 `long long` 更稳。
2. **`half = n // 2` 是上界**：`n = 1` 时 `half = 0`，`dp` 只有 `dp[0]`，查询循环 `k in 1..0` 为空，自然返回 `false`——「两边非空」的约束被自动满足，不会把全集当子集。
3. **倒序更新 $k$**：`for k in range(half, 0, -1)`。若写成正序，`dp[k-1]` 已被当前元素污染，等价于元素可重复使用（完全背包），会把 `[3,1]` 这种反例判成 `true`。
4. **位宽取 $S+1$**：`dp[k]` 要能表示 $0 \le s \le S$ 的所有和，所以 C++ 用 `bitset<300001>`（$S$ 的上界 $30\times 10^4 = 3\times 10^5$）刚好够；若把数据范围改大，就得换成按 `total + 1` 开动态位图（如 `vector<vector<char>>`）。Python 的 `int` 长度自适应，无需关心位宽。
5. **只保留 $k \le \text{half}$ 的行**：转移时 `dp[k]` 只依赖 `dp[k-1]`，超过一半的行永远不会被查询，`dp` 数组开 `half + 1` 就够。
6. **命中即返回**：$k$ 从小到大试，一旦某行置位就 `return true`；平均只需检查一两个 $k$。
7. **元素含 0 不影响**：`0` 对应「平移 0 位」，会让同一行的某些位被重复置位，但按位或天然幂等，不产生错误。
8. **别忘 `n < 2`**：虽然 `half = 0` 已能兜住 `n = 1`，但显式 `if n < 2: return false` 让意图更清楚（`A`、`B` 都非空，至少需要两个元素）。

## 5. 正确性证明

**引理 1（均值回归总均值）**：若 `A ∪ B` 是 `nums` 的一个划分且 $\operatorname{avg}(A) = \operatorname{avg}(B)$，则二者都等于 $S/n$。

**证明**：设公共均值为 $t$，$k = \lvert A\rvert$、$m = \lvert B\rvert$，则 $k + m = n$ 且 $S = kt + mt = (k+m)t = nt$，故 $t = S/n$。∎

**引理 2（对称性）**：存在大小为 $k$ 的可行子集 $\iff$ 存在大小为 $n-k$ 的可行子集；因此只需在 $1 \le k \le \lfloor n/2\rfloor$ 中查找。

**证明**：设 $A$ 大小为 $k$ 且和为 $S\cdot k/n$，取 $B = \text{nums}\setminus A$，则 $\lvert B\rvert = n-k$，且由引理 1 有 $\operatorname{avg}(B) = (S - S\cdot k/n)/(n-k) = S/n$。反向同理。于是 $k$ 与 $n-k$ 的可行性等价，任取两者中较小者检查即可。∎

**引理 3（DP 不变式）**：扫描完前 $t$ 个元素后，`dp[k]` 的第 $s$ 位为 1 $\iff$ 存在由前 $t$ 个元素构成的、大小恰为 $k$、和恰为 $s$ 的子集。

**证明**：对 $t$ 归纳。$t=0$ 时只有空集，`dp[0]=1` 的第 0 位为 1，其余为 0，成立。设扫描第 $t$ 个元素（值 $v$）前不变式成立。一个新子集要么不含 $v$（沿用 `dp[k]` 的旧值），要么含 $v$（去掉 $v$ 后是前 $t-1$ 个元素的 $k-1$ 元子集，和减 $v$，即 `dp[k-1] << v` 的第 $s$ 位），两者之并正是 `dp[k] | (dp[k-1] << v)`。倒序枚举 $k$ 保证读到的是未被本次扫描改写的 `dp[k-1]`，所以并集恰好覆盖「用前 $t$ 个元素」的所有情形，不变式保持。∎

**定理**：算法返回 `true` $\iff$ 存在满足条件的划分。

**证明**：

- （$\Leftarrow$）若存在合法划分，设 $A$ 大小为 $k$，由引理 2 不妨设 $k \le \lfloor n/2\rfloor$，由引理 1 其和为整数 $S\cdot k/n$，故 $S\cdot k \bmod n = 0$ 成立，且由引理 3 该位在 `dp[k]` 中为 1，算法必返回 `true`。
- （$\Rightarrow$）算法只在某个 $k$ 的 `dp[k]` 第 $t = S\cdot k/n$ 位为 1 时返回 `true`；由引理 3，存在大小 $k \in [1, n/2]$ 的集合 $A$ 满足和为 $S\cdot k/n$、均值 $S/n$，其补集 $B$ 非空（$n-k \ge n/2 \ge k \ge 1$），均值为 $(S - S\cdot k/n)/(n-k) = S/n$，即是一个合法划分。∎

## 6. 复杂度分析

- **时间**：转移是 $n$ 个元素 × $\lfloor n/2\rfloor$ 行，每行一次长度为 $S+1$ 位的平移与按位或，按机器字 $w=64$ 计为 $O\!\left(\dfrac{n\cdot \lfloor n/2\rfloor \cdot S}{w}\right)$。代入上限约 $30 \times 15 \times 300001 / 64 \approx 2.1\times 10^{6}$ 次字操作；查询只有 $\lfloor n/2\rfloor$ 次取位，$O(n)$ 可忽略。
- **空间**：$O\!\left(\dfrac{\lfloor n/2\rfloor \cdot S}{w}\right)$，即约 $16 \times 300001$ 位 $= 4.8\times 10^6$ 位 $\approx 600$ KB；Python 的大整数每个约 37 KB，合计同量级。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <bitset>
#include <numeric>
using namespace std;

class Solution {
public:
    bool splitArraySameAverage(vector<int>& nums) {
        int n = nums.size();
        if (n < 2) return false;
        int total = accumulate(nums.begin(), nums.end(), 0);
        int half = n / 2;
        // dp[k] 的第 s 位为 1 <=> 存在恰好 k 个元素、和为 s 的子集
        vector<bitset<300001>> dp(half + 1);
        dp[0][0] = 1;
        for (int v : nums) {
            for (int k = half; k >= 1; --k) {      // 倒序：每个元素最多用一次
                dp[k] |= dp[k - 1] << v;
            }
        }
        for (int k = 1; k <= half; ++k) {
            if ((long long)total * k % n != 0) continue;   // 目标必须是整数
            int target = total * k / n;
            if (dp[k][target]) return true;
        }
        return false;
    }
};
```

### Python

```python
class Solution:
    def splitArraySameAverage(self, nums: list[int]) -> bool:
        n = len(nums)
        if n < 2:
            return False
        total = sum(nums)
        half = n // 2
        # dp[k] 的第 s 位为 1 <=> 存在恰好 k 个元素、和为 s 的子集
        dp = [0] * (half + 1)
        dp[0] = 1
        for v in nums:
            for k in range(half, 0, -1):          # 倒序：每个元素最多用一次
                dp[k] |= dp[k - 1] << v
        for k in range(1, half + 1):
            if total * k % n:                     # 目标必须是整数
                continue
            target = total * k // n
            if (dp[k] >> target) & 1:
                return True
        return False
```

## 8. 边界情况与易错点

1. **`n = 1`**：无法分成两个非空数组，必须返回 `false`。`half = 0` 时查询循环为空，代码天然正确，但显式特判更直观。
2. **全相等 / 全 0**：如 `[5,5,5,5]`、`[0,0]`，`k=1` 时目标就是该值，第一位即命中，返回 `true`；`[0]` 则因为 `n<2` 返回 `false`。
3. **上界写成 `n` 会误判**：若把 `k` 取到 `n`，`k=n` 时目标是 $S$，`dp[n]` 必然置位，任何输入都会返回 `true`。用 `n // 2` 才能排除全集。
4. **倒序写成正序**：元素会被重复使用（完全背包），`[3,1]` 这类反例会误判为 `true`。
5. **浮点比较**：不要用 `sum(A)/k == total/n` 判等，`double` 在 $10^4$ 量级上会有舍入误差；一律用交叉相乘 $s\cdot n = S\cdot k$ 或整数除法加整除性检查。
6. **`total * k % n` 的优先级**：C++ 里 `total * k % n != 0` 是 `(total*k) % n != 0`，但如果写成 `total * (k % n)` 就完全错了；另外 `int` 上界 $4.5\times10^6$ 虽然安全，仍建议 `long long` 防手滑改数据范围。
7. **`bitset` 尺寸**：写死 `300001` 时必须保证 $\ge$ 最大可能的 `total + 1`；若把题面数据范围改大（比如 $10^5$）就会越界，动态定长更稳。
8. **提前返回的时机**：命中即 `return true`，但不要在处理元素的过程中就返回——`dp` 必须扫完全部元素才完整。
