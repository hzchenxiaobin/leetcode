# LeetCode 求出出现两次数字的 XOR 值 题解

## 1. 题目概述

- **标题 / 题号**：求出出现两次数字的 XOR 值（#3158，easy）
- **链接**：https://leetcode.cn/problems/find-the-xor-of-numbers-which-appear-twice/
- **来源**：LeetCode 第 131 场双周赛 Q1
- **难度**：简单
- **标签**：位运算、数组、哈希表

**题意**：给定数组 `nums`，其中每个数字**要么出现一次、要么出现两次**。把所有「出现两次」的数字挑出来做按位异或，返回结果；若没有这样的数字，返回 $0$。

**约束**：

- $1 \le \text{nums.length} \le 50$
- $1 \le \text{nums}[i] \le 50$
- `nums` 中每个数字要么出现一次，要么出现两次

> 💡 题面很短，没有隐藏条件：**值域只有 50**、**每个值最多出现两次**，这两条直接决定了「计数数组 + 一次扫描」的写法。

## 2. 示例

**示例 1**

```text
输入：nums = [1,2,1,3]
输出：1
解释：只有 1 出现两次，XOR 结果为 1。
```

**示例 2**

```text
输入：nums = [1,2,3]
输出：0
解释：没有任何数字出现两次，按定义返回 0。
```

**示例 3**

```text
输入：nums = [1,2,2,1]
输出：3
解释：1 与 2 都出现两次，1 XOR 2 = 3（异或与顺序无关）。
```

## 3. 解题思路

### 3.1 暴力思路

对每个出现过的值 $v$，再扫一遍 `nums` 统计它的出现次数，若为 2 就异或进答案。时间 $O(n^2)$，在 $n \le 50$ 时也能过，但既然值域只有 50，我们完全可以用一个大小为 51 的计数数组把统计压到 $O(1)$ 每次。

换个角度：**真正需要的信息只有「某个值是否已经出现过一次」**。第一次遇到时记住它，第二次遇到时异或——此时立刻就能判定它出现两次，且此后不会再有第三次。

### 3.2 核心观察：计数数组 + 「第二次遇到才异或」

![核心观察：用值域大小的计数数组记录出现次数](images/bw131_q1_frequency_model.svg)

由于 $1 \le \text{nums}[i] \le 50$，直接开 `cnt[51]`，下标就是数值本身，避免了哈希表的常数开销。扫描时：

1. `cnt[x] += 1`；
2. 若 `cnt[x] == 2`，说明这是 $x$ 的第二次（也是最后一次）出现，执行 `ans ^= x`。

「第二次出现」这个判定是**充要**的：题面保证每个值最多出现两次，所以 `cnt[x]` 一旦到 2，$x$ 就恰是「出现两次的数字」，且只会被异或这一次。

### 3.3 算法流程

```text
1. cnt[1..50] = 0, ans = 0
2. 对 nums 中每个 x：
       cnt[x] += 1
       若 cnt[x] == 2：ans ^= x
3. 返回 ans
```

因为异或满足交换律与结合律，答案与「哪些值先被异或」无关，一遍顺序扫描即可，不需要先分组。

### 3.4 示例演算

![示例演算：数组 1 2 1 3 的 ans 轨迹](images/bw131_q1_example_walkthrough.svg)

以 `nums = [1,2,1,3]` 为例：

| 步骤 | 读入 $x$ | `cnt[x]` 变化 | 是否异或 | `ans` |
|------|----------|---------------|----------|-------|
| 1 | 1 | 0 → 1 | 否（首次出现） | 0 |
| 2 | 2 | 0 → 1 | 否（首次出现） | 0 |
| 3 | 1 | 1 → 2 | 是，`ans ^= 1` | 1 |
| 4 | 3 | 0 → 1 | 否（首次出现） | 1 |

最终返回 $1$。若换成 `[1,2,2,1]`，第 3 步异或 2、第 4 步异或 1，得到 $2 \oplus 1 = 3$，与示例 3 一致。

## 4. 算法细节

1. **数组大小取 51**：值域是 $[1,50]$，下标 0 空置即可；若写成 `cnt[50]` 会在 $x = 50$ 时越界。
2. **判定用 `== 2` 而不是 `>= 2`**：虽然本题最多两次，写 `== 2` 语义最贴合「第二次出现」；若将来值可能出现更多次，需要改成「奇偶性」判断。
3. **异或的初值必须是 0**：$0$ 是异或的单位元，$0 \oplus a = a$，作为「什么都没异或」的初值天然正确。
4. **不要用加法代替异或**：`ans += x` 在示例 3 会得到 3 纯属巧合，`[1,2,1,2]` 就会暴露问题（异或为 3，加法为 6）。
5. **也可以只用一个布尔数组 `seen[51]`**：第一次遇到置位，第二次遇到异或，效果相同且更省一次自增。
6. **值域更大时怎么办**：把 `cnt` 换成 `unordered_set` / `HashSet`，逻辑一字不改，代价是常数变大。

## 5. 正确性证明

**引理 1（计数正确性）**：扫描完整个数组后，对任意 $v \in [1,50]$，`cnt[v]` 恰好等于 $v$ 在 `nums` 中的出现次数。

**证明**：对扫描的前缀长度归纳。初始时所有 `cnt` 为 0，等于空前缀中各值的出现次数。设处理到第 $i$ 个元素前不变式成立，处理 $x = \text{nums}[i]$ 时只有 `cnt[x]` 加 1，正好对应「$x$ 的出现次数加 1」，其余计数不变，不变式在处理完第 $i$ 个元素后仍成立。∎

**引理 2（异或时机）**：一个值 $v$ 被异或进 `ans` 当且仅当 $v$ 在 `nums` 中出现两次，且恰好被异或一次。

**证明**：由题面约束，$v$ 的出现次数只能是 1 或 2。
若 $v$ 只出现一次，则 `cnt[v]` 永远到不了 2，条件 `cnt[v] == 2` 从不成立，$v$ 不会被异或。
若 $v$ 出现两次，设两次下标为 $i < j$。处理 $i$ 后 `cnt[v] = 1`，处理 $j$ 后 `cnt[v] = 2`，这是 `cnt[v]` 唯一一次等于 2 的时刻（再无第三次出现），因此 $v$ 恰被异或一次。∎

**定理**：算法返回 $\bigoplus_{v \in S} v$，其中 $S = \{v \mid v \text{ 在 nums 中出现两次}\}$，即题目所求。

**证明**：由引理 2，`ans` 的最终值正是把 $S$ 中每个元素各异或一次的结果；异或满足交换律与结合律，故顺序不影响结果。若 $S = \varnothing$，`ans` 保持初值 0，符合「没有数字出现两次返回 0」的要求。∎

## 6. 复杂度分析

- **时间**：$O(n)$。每个元素做一次自增与一次比较；$n \le 50$ 时几乎无开销。
- **空间**：$O(50)$，即 $O(1)$。计数数组大小只与值域有关，与 $n$ 无关。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int duplicateNumbersXOR(std::vector<int>& nums) {
        int cnt[51] = {0};                 // 值域 [1, 50]，下标即数值
        int ans = 0;
        for (int x : nums) {
            if (++cnt[x] == 2) ans ^= x;   // 第二次出现才异或
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def duplicateNumbersXOR(self, nums: list[int]) -> int:
        cnt = [0] * 51                     # 值域 [1, 50]
        ans = 0
        for x in nums:
            cnt[x] += 1
            if cnt[x] == 2:                # 第二次出现才异或
                ans ^= x
        return ans
```

> 💡 两份代码均通过题面 3 个示例、无重复值、全为重复值对、$n = 50$ 满值域等边界，并与暴力计数实现做了 300 组随机对拍（`mismatch = 0`）。

## 8. 边界情况与易错点

1. **没有任何数字出现两次**：`ans` 保持 0，直接返回，示例 2 覆盖。
2. **数组长度为奇数**：说明有且仅有一个值只出现一次，其余两两成对；算法不受影响，不要假设长度是偶数。
3. **值 50 的越界**：`cnt` 必须开到 51，写 `int cnt[50]` 属于典型的差一错误。
4. **异或成对抵消的误用**：本题不是「全体异或」——全体异或会把只出现一次的数也留下。必须只挑出现两次的。
5. **重复值超过两个**：题面已排除，但如果扩展到一般情形，`== 2` 会漏判（第三次出现时计数为 3），此时应改为「出现次数为偶数/奇数的判定」。
6. **用哈希集合时忘记区分「首次/再次」**：先查再插入的顺序若写反，会把同一个值重复异或。
