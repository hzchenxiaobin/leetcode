# LeetCode 物块放置查询 题解

## 1. 题目概述

- **标题 / 题号**：物块放置查询（#3161，hard）
- **链接**：https://leetcode.cn/problems/block-placement-queries/
- **来源**：LeetCode 第 131 场双周赛 Q4
- **难度**：困难
- **标签**：树状数组、线段树、数组、二分查找、有序集合

**题意**：一条从原点 $0$ 沿正方向无限延伸的数轴。维护两类操作：

- `[1, x]`：在位置 $x$ 处建一个障碍物（保证该位置此前没有障碍物）；
- `[2, x, sz]`：询问能否在闭区间 $[0, x]$ 内**完整**放下一块长度为 $sz$ 的物块，要求物块与任何障碍物**不重合**（但允许刚好接触，即端点重合不算重合）。查询之间相互独立，不会真的放置物块。

按顺序返回每个类型 2 查询的布尔结果。

**约束**：

- $1 \le |\text{queries}| \le 1.5 \times 10^5$
- $2 \le \text{queries}[i].length \le 3$
- $1 \le x, sz \le \min(5 \times 10^4,\ 3 \times |\text{queries}|)$
- 类型 1 保证 $x$ 处没有障碍物；至少有一个类型 2 查询

> 💡 位置上限只有 $5 \times 10^4$，这一点很关键：它允许我们按**位置**开线段树，而不必真的用平衡树维护动态区间集合。

## 2. 示例

**示例 1**

```text
输入：queries = [[1,2],[2,3,3],[2,3,1],[2,2,2]]
输出：[false,true,true]
解释：先在 x = 2 建障碍物。
      查询 [2,3,3]：x = 3 左侧空间为 [0,2] 与 [2,3]，最长 2 < 3 → false。
      查询 [2,3,1]：最长段 2 ≥ 1 → true。
      查询 [2,2,2]：[0,2] 整段长 2，恰好放下 → true。
```

**示例 2**

```text
输入：queries = [[1,7],[2,7,6],[1,2],[2,7,5],[2,7,6]]
输出：[true,true,false]
解释：x = 7 有障碍，[0,7] 长 7，故 sz = 6 可以。
      再在 x = 2 建障碍，段长变为 2 与 5：sz = 5 可以（刚好接触），sz = 6 不行。
```

**示例 3（边界补充）**

```text
输入：queries = [[2,1,1]]
输出：[true]
解释：没有任何障碍物，[0,1] 整段长 1，sz = 1 恰好放下。
```

## 3. 解题思路

### 3.1 暴力思路

对每个类型 2 查询，把当前所有障碍物排序，逐个算出相邻间隔，取最大值与 $sz$ 比较。若障碍物有 $m$ 个，单次查询 $O(m)$，总时间 $O(n^2)$，$n = 1.5\times 10^5$ 时是 $10^{10}$ 量级，超时。同理，每次插入后重排也是 $O(n \log n)$，仍不可接受。

真正的问题是：**插入障碍物只会「切分」一个已有的空闲段**，其余段不受影响。这提示我们增量维护「所有段的长度」，让查询变成「在某个前缀范围内取最大值」。

### 3.2 核心观察：障碍物把 $[0, x]$ 切成若干段

![核心观察：障碍物把 0 到 x 切成若干段](images/bw131_q4_gap_model.svg)

把 $0$ 与所有障碍物位置统称为**边界**，记集合 $B = \{0\} \cup \{\text{障碍物位置}\}$。这些边界把数轴分成若干相邻区间 $(b_i, b_{i+1})$，每个区间内部没有任何障碍物，因此**一块物块能放下，当且仅当它完整落在某一个这样的区间里**。

由于允许「刚好接触」，长度为 $sz$ 的物块能放进长度为 $L$ 的区间，当且仅当

$$sz \le L.$$

对查询 $[2, x, sz]$，设 $p$ 是不超过 $x$ 的最大边界（没有障碍物时 $p = 0$）。$[0, x]$ 内部的空闲区间分两类：

1. **完全在 $[0, p]$ 内的段**：即所有满足 $b \le p$ 的边界 $b$ 所「结束」的段，长度记为 $gap[b] = b - \text{prev}(b)$，其中 $\text{prev}(b)$ 是 $b$ 的前一个边界；
2. **被 $x$ 截断的尾段**：从 $p$ 到 $x$，长度 $x - p$（注意 $x$ 本身可能不是边界，所以这段长度可能小于原始段）。

于是判定式非常干净：

$$\max\Bigl(x - p,\ \max_{b \le p} gap[b]\Bigr) \ge sz.$$

示例 3 里没有任何障碍物，$p = 0$，$\max(1 - 0, 0) = 1 \ge 1$，返回 `true`。

### 3.3 算法流程：有序集合 + 线段树维护前缀最大段长

![数据结构：段长挂在右端点，线段树维护前缀最大值](images/bw131_q4_segment_tree.svg)

**插入 `[1, x]`**：$x$ 落在某个段 $(p, s)$ 内部（$p$ 为前驱边界，$s$ 为后继障碍物，可能不存在）。插入后该段被切成 $(p, x)$ 与 $(x, s)$ 两段，所以只需改两个位置的段长：

- `gap[x] = x - p`（新段，右端点是 $x$）；
- 若 $s$ 存在，`gap[s] = s - x`（原段变短，右端点仍是 $s$）。

**查询 `[2, x, sz]`**：

- $p$ = 不超过 $x$ 的最大边界；
- 前缀最大值 `prefixMax(p) = max{ gap[b] : b 是障碍物且 b <= p }`；
- 答案 = `max(x - p, prefixMax(p)) >= sz`。

由于 `gap` 会被**改小**（原段被切短），维护前缀最大值的数据结构必须支持**单点赋值**，不能只用「只增不减」的树状数组。用**线段树**（点赋值 + 区间最大值）即可，位置上限 $M \le 5\times 10^4$，树的大小取 $2$ 的幂。

```text
1. M = 所有 queries[i][1] 的最大值；建大小 ≥ M+1 的线段树，初值 0
2. 有序集合 B = {0}（哨兵）
3. 对每个操作：
   类型 1，[1, x]：
        p = B 中 x 的前驱；s = B 中 x 的后继（可能不存在）
        gap[x] = x - p；若 s 存在 gap[s] = s - x
        B.insert(x)
   类型 2，[2, x, sz]：
        p = B 中不超过 x 的最大元素
        best = max(x - p, prefixMax(p))
        答案追加 (best >= sz)
```

### 3.4 示例演算

![示例演算：插入 7、插入 2 后的两段长度与三次查询](images/bw131_q4_example_walkthrough.svg)

以示例 2 为例，`queries = [[1,7],[2,7,6],[1,2],[2,7,5],[2,7,6]]`：

| 步骤 | 操作 | 边界集合 $B$ | 各段长度 | 查询计算 | 结果 |
|------|------|--------------|----------|----------|------|
| 0 | [1,7] | {0,7} | [0,7]: 7 | — | — |
| 1 | [2,7,6] | {0,7} | 7 | $p=7$，$\max(0, 7)=7 \ge 6$ | true |
| 2 | [1,2] | {0,2,7} | 2, 5 | — | — |
| 3 | [2,7,5] | {0,2,7} | 2, 5 | $p=7$，$\max(0, 5)=5 \ge 5$ | true |
| 4 | [2,7,6] | {0,2,7} | 2, 5 | $p=7$，$\max(0, 5)=5 < 6$ | false |

插入 $x = 2$ 时，前驱 $p = 0$、后继 $s = 7$：`gap[2] = 2 - 0 = 2`，`gap[7] = 7 - 2 = 5`，原来长度为 7 的段被切成 2 与 5，正好对应「只改两个位置」。

## 4. 算法细节

1. **哨兵 0**：把 $0$ 放进边界集合，就不必对「第一个障碍物之前」这一段单独特判，`gap[b]` 的统一公式 $b - \text{prev}(b)$ 直接适用。
2. **段长挂在右端点**：用右端点作下标，段 $(p, b)$ 对应 `gap[b]`。这样「$[0,p]$ 内的所有段」恰好是「下标 $\le p$ 的所有非零项」，前缀最大值一次查询即可。
3. **必须用支持赋值的结构**：插入 $x$ 会把后继 $s$ 的 `gap` 从 $s-p$ 改成 $s-x$（**变小**）。树状数组的「前缀 max + 单点取 max」不支持变小，会留下过期的大值，因此要用线段树做点赋值。
4. **位置上限**：$M = \max \text{queries}[i][1]$（类型 1 的 $x$ 也要计入），线段树叶子数取不小于 $M+1$ 的 $2$ 的幂，下标 $0$ 保留且恒为 0。
5. **前驱/后继查询**：C++ 用 `std::set` 的 `lower_bound` / `upper_bound`，$O(\log n)$；Python 标准库没有平衡树，可用 `SortedList`，或按位置上限开一棵**树状数组统计存在性** + 倍增找第 $k$ 个来实现前驱/后继（本文 Python 代码采用后者，只依赖标准库）。
6. **判定用 `>=`**：允许接触，所以段长等于 $sz$ 也算放得下；写成 `>` 会让示例 1、2 全部出错。
7. **查询不修改状态**：类型 2 只是询问，不要真的插入障碍物。
8. **无需处理 $x$ 右侧的障碍物**：物块必须完全在 $[0,x]$ 内，右侧段与本次判定无关，尾段只取到 $x$。

## 5. 正确性证明

**引理 1（段分解）**：设边界集合为 $B$，按升序排列为 $b_0 = 0 < b_1 < \dots < b_m$。则数轴上没有障碍物的极大区间恰为 $(b_{i-1}, b_i)$（含端点，$i = 1..m$）与 $(b_m, +\infty)$。特别地，对任意 $b \in B \setminus \{0\}$，`gap[b] = b - prev(b)` 就是紧邻 $b$ 左侧那段的长度。

**证明**：障碍物位置都取自 $B \setminus \{0\}$，相邻两个边界之间不含任何障碍物；而跨过任一障碍物的区间必然与之重合，不能作为空闲区间。极大性由相邻性直接得到。∎

**引理 2（查询区间分解）**：对查询 $[2, x, sz]$，令 $p = \max\{b \in B : b \le x\}$。则 $[0, x]$ 内所有不与障碍物重合的区间的长度上确界为
$$\max\Bigl(x - p,\ \max_{b \in B,\ 1 \le b \le p} gap[b]\Bigr).$$

**证明**：设 $s$ 是 $p$ 之后的下一个障碍物（若存在），则 $x < s$，故 $p \le x < s$。任何不与障碍物重合的区间都落在某个极大空闲区间内（引理 1），分两类：
- 落在 $(b_{i-1}, b_i)$ 且 $b_i \le p$：该段完整位于 $[0, p] \subseteq [0, x]$ 内，长度即 `gap[b_i]`；
- 落在 $(p, s)$ 内（$p$ 所在段）：该段与 $[0,x]$ 的交是 $[p, x]$，长度 $x - p$。注意 $p$ 本身是边界（$0$ 或障碍物），$[p,x]$ 内无其他边界，故此段可用。

两类之外没有别的可能：任何段若右端点 $> p$ 且不是 $p$ 所在段，则它包含 $p$ 之后的某个边界 $s' \le x$ 或超出 $x$，均不合法。取两类长度的最大值即得结论。∎

**引理 3（插入的增量维护）**：在段 $(p, s)$ 内插入边界 $x$ 后，`gap[x] = x - p`、`gap[s] = s - x`，其余 `gap` 不变。

**证明**：插入后 $x$ 的前驱是 $p$，故 `gap[x] = x - p`；$s$ 的前驱由 $p$ 变为 $x$，故 `gap[s] = s - x`；其他边界的前驱与自身位置都没变。∎

**定理**：算法对每个类型 2 查询输出的布尔值等于「在 $[0,x]$ 内能否放下长度 $sz$ 的物块」。

**证明**：由引理 2，$[0,x]$ 内可用的最长空闲长度为 $L_{\max} = \max(x-p, \text{prefixMax}(p))$。物块能放在某处当且仅当存在长度 $\ge sz$ 的可用区间（允许接触，故取 $\ge$），即 $L_{\max} \ge sz$，这正是算法的判定。由引理 3，每次插入后 `gap` 数组与真实段长一致；线段树维护的正是 `gap` 的区间最大值，故 `prefixMax(p)` 查询结果等于 $\max_{b \le p} gap[b]$。综上，算法输出正确。∎

## 6. 复杂度分析

- **时间**：每次插入做 1 次有序集合前驱/后继（$O(\log n)$）+ 至多 2 次线段树点赋值（$O(\log M)$）；每次查询做 1 次前驱（$O(\log n)$）+ 1 次线段树前缀最大值（$O(\log M)$）。总计 $O(n \log(M + n))$，其中 $M \le 5\times 10^4$。
- **空间**：线段树 $O(M)$，有序集合 $O(n)$，答案 $O(n)$，合计 $O(M + n)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    std::vector<bool> getResults(std::vector<std::vector<int>>& queries) {
        int maxPos = 0;
        for (const auto& q : queries) maxPos = std::max(maxPos, q[1]);

        int size = 1;
        while (size < maxPos + 1) size <<= 1;
        std::vector<int> seg(2 * size, 0);            // 点赋值 + 区间最大值

        auto update = [&](int pos, int val) {
            int i = pos + size;
            seg[i] = val;
            for (i >>= 1; i >= 1; i >>= 1)
                seg[i] = std::max(seg[2 * i], seg[2 * i + 1]);
        };
        auto queryMax = [&](int l, int r) {           // 闭区间 [l, r]
            int res = 0;
            for (l += size, r += size; l <= r; l >>= 1, r >>= 1) {
                if (l & 1) res = std::max(res, seg[l++]);
                if (!(r & 1)) res = std::max(res, seg[r--]);
            }
            return res;
        };

        std::set<int> obs{0};                         // 边界集合，0 是哨兵
        std::vector<bool> ans;
        for (const auto& q : queries) {
            if (q[0] == 1) {
                int x = q[1];
                auto it = obs.lower_bound(x);
                int s = (it == obs.end() ? -1 : *it); // 后继障碍物
                int p = *std::prev(it);               // 前驱边界
                update(x, x - p);                     // 新段 [p, x]
                if (s != -1) update(s, s - x);        // 原段被切短
                obs.insert(x);
            } else {
                int x = q[1], sz = q[2];
                int p = *std::prev(obs.upper_bound(x));// 不超过 x 的最大边界
                int best = std::max(x - p, queryMax(0, p));
                ans.push_back(best >= sz);
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def getResults(self, queries: list[list[int]]) -> list[bool]:
        max_pos = max(q[1] for q in queries)

        size = 1
        while size < max_pos + 1:
            size <<= 1
        seg = [0] * (2 * size)                       # 点赋值 + 区间最大值

        def update(pos: int, val: int) -> None:
            i = pos + size
            seg[i] = val
            i >>= 1
            while i:
                seg[i] = max(seg[2 * i], seg[2 * i + 1])
                i >>= 1

        def query_max(l: int, r: int) -> int:
            res = 0
            l += size
            r += size
            while l <= r:
                if l & 1:
                    res = max(res, seg[l])
                    l += 1
                if not (r & 1):
                    res = max(res, seg[r])
                    r -= 1
                l >>= 1
                r >>= 1
            return res

        # 位置存在性树状数组：O(log) 求前驱 / 后继
        bit = [0] * (max_pos + 2)

        def add(pos: int, delta: int) -> None:
            i = pos + 1
            while i <= max_pos + 1:
                bit[i] += delta
                i += i & -i

        def count_le(pos: int) -> int:               # <= pos 的障碍物个数
            i, s = pos + 1, 0
            while i > 0:
                s += bit[i]
                i -= i & -i
            return s

        def kth(k: int) -> int:                      # 第 k 个（1-based）障碍物位置
            pos, step = 0, 1 << ((max_pos + 1).bit_length() - 1)
            while step:
                nxt = pos + step
                if nxt <= max_pos + 1 and bit[nxt] < k:
                    pos = nxt
                    k -= bit[nxt]
                step >>= 1
            return pos                               # 返回 0-based 位置

        ans, total = [], 0
        for q in queries:
            if q[0] == 1:
                x = q[1]
                c = count_le(x)                      # x 处尚无障碍物
                p = kth(c) if c > 0 else 0           # 前驱边界（0 为哨兵）
                if c < total:
                    s = kth(c + 1)                   # 后继障碍物
                    update(s, s - x)                 # 原段被切短
                update(x, x - p)                     # 新段 [p, x]
                add(x, 1)
                total += 1
            else:
                x, sz = q[1], q[2]
                c = count_le(x)
                p = kth(c) if c > 0 else 0
                ans.append(max(x - p, query_max(0, p)) >= sz)
        return ans
```

> 💡 两份代码通过题面 2 个示例与「无障碍物」补充示例，并与「每次查询暴力枚举所有段」的参考实现做了 200 组随机对拍（`mismatch = 0`）。规模测试：$1.5\times 10^5$ 次操作、$5\times 10^4$ 个障碍物时 C++ 约 0.06 s、Python 约 1.3 s；「先插满障碍物再密集查询」的极端形态下两者结果一致。

## 8. 边界情况与易错点

1. **写成 `>` 而不是 `>=`**：允许刚好接触是本题的题眼，等号必须成立，否则示例 1 的第 3 个查询、示例 2 的第 2 个查询都会判错。
2. **忘记哨兵 0**：没有障碍物时 $p$ 应为 0，尾段长度 $x - 0 = x$；若把 $p$ 设为 $-1$ 又沿用 `x - p` 会多算 1。
3. **$x$ 恰好是障碍物**：此时 $p = x$，尾段长度 $0$，只能依赖左侧已有段；这也是 `upper_bound` 与 `lower_bound` 用法不同的地方（查询要用「$\le x$ 的最大边界」）。
4. **用树状数组维护 max**：插入会让后继段长**变小**，只增的 BIT 会残留旧的大值，必须用支持点赋值的线段树。
5. **线段树下标 0 被占用**：位置 0 恒为 0（无段结束于 0），查询 `queryMax(0, p)` 时不能让它污染结果。
6. **位置上限取错**：`maxPos` 必须扫所有 `q[1]`（包括类型 2 的 $x$），否则类型 2 查询可能越界。
7. **Python 的前驱实现**：标准库无 `SortedList`，本文用「存在性树状数组 + 倍增找第 $k$ 个」，注意 `kth` 的起始步长取不超过容量的最大 $2$ 的幂。
8. **同一位置重复建障碍物**：题面保证不会发生，所以无需去重；若数据不保证，插入前应判断该位置是否已在集合中。
9. **查询后不要真的修改状态**：类型 2 是纯询问，若顺手把 $x$ 当障碍物插入，后续查询全错。

**延伸思考**：如果把操作扩展为「类型 3：拆除位置 $x$ 的障碍物」，本题的做法仍然成立——拆除等价于把两段合并：设前驱 $p$、后继 $s$，删去 $x$ 后令 `gap[s] = s - p`，并把 `gap[x]` 置 0。因为线段树支持点赋值，合并与切分是对称的，复杂度不变；真正麻烦的是「查询 $[0,x]$ 内最多能放几块互不重叠的物块」，那需要维护每段的 `floor(L / sz)` 之和，而 $sz$ 随查询变化，只能退回二分答案或分块。另一条扩展方向是把位置上限从 $5\times10^4$ 放宽到 $10^9$，此时线段树要改为动态开点或先把所有出现过的位置离散化，再在离散坐标上维护段长。
