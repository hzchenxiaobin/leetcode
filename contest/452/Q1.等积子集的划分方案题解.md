# LeetCode 等积子集的划分方案 题解

## 1. 题目概述

- **标题 / 题号**：等积子集的划分方案（#3566，medium）
- **链接**：https://leetcode.cn/problems/partition-array-into-two-equal-product-subsets/
- **来源**：LeetCode 第 452 场周赛 Q1
- **难度**：中等
- **标签**：位运算、枚举、数组、递归

**题意**：给定一个由**互不相同**的正整数组成的数组 `nums` 和整数 `target`，判断能否把**全部**元素划分成两个**非空、互不相交**的子集 A、B（每个元素恰好属于其中一个），使得 $\prod_{x \in A} x = \prod_{x \in B} x = target$。

**约束**：

- $3 \le nums.length \le 12$
- $1 \le target \le 10^{15}$
- $1 \le nums[i] \le 100$，且元素互不相同

> 💡 **读题关键**：① 每个元素**必须**归入某一侧，不能弃权；② 两侧乘积都要**恰好等于** target，不是「相等即可」；③ $n \le 12$ 是「子集枚举」的明示信号，但 $target \le 10^{15}$、$nums[i] \le 100$ 暗藏 **64 位溢出**陷阱——全积上界 $100^{12} = 10^{24}$ 已超过 `long long`。

## 2. 示例

**示例 1**

```text
输入：nums = [3,1,6,8,4], target = 24
输出：true
解释：A = {3, 8}（积 24），B = {1, 6, 4}（积 24），每个元素恰好属于一侧，划分合法。
```

**示例 2**

```text
输入：nums = [2,5,3,7], target = 15
输出：false
解释：全积 210 ≠ 225 = 15²，且 2 不整除 15——两道 O(n) 必要检查任一即可否决。
```

**示例 3（自拟，覆盖「两关全过但无解」）**

```text
输入：nums = [8,16,32], target = 64
输出：false
解释：8|64、16|64、32|64，且全积 4096 = 64²，两道必要检查全部通过；
     但 6 个非空真子集的积为 8、16、32、128、256、512，无一等于 64。
```

## 3. 解题思路

### 3.1 暴力思路：枚举每个元素的归属

把「划分」看成给每个元素染 A/B 两种颜色，共 $2^n$ 种染色方案，逐种验证两侧乘积是否都等于 `target`。$n \le 12$ 时 $2^{12} = 4096$，每种验证 $O(n)$，总量约 $5 \times 10^4$——**搜索规模本身就在正解范围内**，暴力并不超时。

真正的坑不在搜索而在**算术**：全积上界 $100^{12} = 10^{24} > 2^{63} \approx 9.2 \times 10^{18}$，C++ 里直接用 `long long` 累乘三个「全积」会**静默溢出**，输出看似合理的错误答案。所以「暴力」必须配两样东西：**必要条件预检**（让大量输入根本轮不到枚举）与**防溢出的累乘方式**。

### 3.2 核心观察：全积守恒 × 因子过滤

![核心观察概念图](images/wc452_q1_partition_concept.svg)

**观察 1（全积守恒）**：A、B 不相交且并为全集，故

$$\prod_{x \in nums} x = \Big(\prod_{x \in A} x\Big) \times \Big(\prod_{x \in B} x\Big) = target^2$$

合法划分存在 ⟹ 全积必须**恰好**等于 $target^2$。一次 $O(n)$ 检查即可否决一大批输入，如示例 2（$210 \ne 225$）。

**观察 2（因子过滤）**：元素 $x$ 必落在某一侧，设为 A，则 $x \times (\text{A 中其余元素之积}) = target$，而其余元素之积是正整数，故 **每个 $x$ 都必须整除 $target$**（从而 $x \le target$）。示例 2 还能被更早否决：$2 \nmid 15$。

**观察 3（只需枚举一侧）**：过了两关后，只需找到**一个非空真子集** $A$ 使 $\prod_{x \in A} x = target$；由守恒，补集积自动 $= target^2 / target = target$，且「真子集」保证补集非空。于是 $2^n$ 枚举只查一侧即可。

> ⚠️ **别把必要条件当充分条件**：观察 1、2 只是「合法划分存在」的必要条件。自拟示例 3（`[8,16,32]`, `target = 64`）两关全过、答案却是 false——最终裁决必须靠枚举。反方向倒有个捷径：若守恒成立且 $target \in nums$，取 $A = \{target\}$、$B$ 为其余元素即得合法划分（$B$ 的积被守恒强制等于 $target$），可直接返回 true。

### 3.3 算法流程

![算法流程图](images/wc452_q1_filter_flow.svg)

三道关卡，逐级否决：

1. **关卡一（因子过滤）**：任一 $x$ 不整除 $target$ → `false`；
2. **关卡二（全积守恒）**：全积（`__int128` 累乘）$\ne target^2$ → `false`；
3. **关卡三（子集枚举）**：枚举 $mask \in [1,\ 2^n - 2]$（非空真子集），按位累乘、**中途一旦超过 $target$ 立即放弃该 mask**；某 mask 的积恰为 $target$ → `true`；
4. 枚举耗尽 → `false`。

剪枝同时也是**溢出防护**：进入累乘的中间值恒 $\le target \le 10^{15}$，再乘上 $nums[i] \le 100$ 后至多 $10^{17}$，`long long` 全程安全。

### 3.4 示例演算

![示例演算走查](images/wc452_q1_walkthrough.svg)

示例 1 在关卡三的走查：`{3}`、`{3,1}` 积为 3 不中；`{6,8}` 累乘到 48 超过 24 被剪枝；`{3,8}` 积恰为 24 命中，补集 `{1,6,4}` 的积由守恒同样是 24 → `true`。示例 3 则 6 个 mask 全部耗尽 → `false`。

## 4. 算法细节

1. **枚举范围**：`mask` 从 $1$ 到 $2^n - 2$。下界排除**空集**——空集积约定为 1，当 $target = 1$ 时会把「一侧全空」误判成解；上界排除**全集**——补集为空，不满足两侧非空。
2. **全积的溢出防护**：$100^{12} = 10^{24}$ 溢出 `long long`。C++ 用 `__int128` 累乘，再与 `(__int128)target * target`（$\le 10^{30}$，同样在 `__int128` 范围内）比较；Python 整数天然无此问题。
3. **剪枝即防护**：关卡三中，中间积 $\le target$ 才继续乘，故中间值上界 $target \times 100 = 10^{17} < 2^{63}$，`long long` 不会溢出。
4. **等价写法（DFS 双桶）**：递归地给每个元素分配到 A/B 两个桶，维护两桶当前积，任一桶积超过 $target$ 即回溯——与子集枚举同构（官方标签中的「递归」即此写法），复杂度同为 $O(2^n)$。
5. **捷径（可选）**：守恒成立且 $target \in nums$ 时可直接返回 true（见 3.2 末尾注记）；代码中不做也不影响正确性与复杂度，本题主打最稳的三关卡写法。

## 5. 正确性证明

**引理 1（必要性）**：若存在合法划分 $(A, B)$，则每个 $x \in nums$ 整除 $target$，且 $\prod_{x \in nums} x = target^2$。

**证明**：任取 $x$，不妨设 $x \in A$。令 $r = \prod_{y \in A \setminus \{x\}} y$，A 中元素皆为 $\ge 1$ 的整数，故 $r$ 是正整数，且 $x \cdot r = \prod_{y \in A} y = target$，于是 $x \mid target$。又 $A \cap B = \varnothing$、$A \cup B = nums$，正整数乘法在互不相交的分组上可分解，故 $\prod nums = \prod A \cdot \prod B = target \cdot target = target^2$。∎

**引理 2（充分性）**：若 $\prod nums = target^2$，且存在非空真子集 $A$ 使 $\prod_{x \in A} x = target$，则 $(A,\ nums \setminus A)$ 是合法划分。

**证明**：$A$ 非空；$A$ 为真子集，故 $B = nums \setminus A$ 非空；$A$ 中元素积整除全积（$A \subseteq nums$，商即 $B$ 中元素之积），故 $\prod B = \prod nums \big/ \prod A = target^2 / target = target$。两子积均为 $target$，每个元素恰属一侧，是合法划分。∎

**引理 3（剪枝不丢解）**：对固定 mask，累乘过程中间积一旦超过 $target$，该子集的积必 $\ne target$，可安全放弃。

**证明**：元素均 $\ge 1$，向子集追加元素只使积不减。中途积 $p > target$ 时，最终积 $\ge p > target$，不可能等于 $target$。∎

**定理**：算法返回 `true` 当且仅当存在合法划分。

**证明**：（⇐）设合法划分 $(A, B)$ 存在。由引理 1，关卡一、二均放行（算法不会提前误杀）；$A$ 是非空真子集且积为 $target$，落在关卡三的枚举范围内，由引理 3 剪枝不会放弃它，枚举到 `mask` = $A$ 时返回 `true`。（⇒）算法返回 `true` 时已通过关卡一、二，且找到了积为 $target$ 的非空真子集 $A$，由引理 2，存在合法划分。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \cdot 2^n)$。关卡一、二各 $O(n)$；关卡三枚举 $2^n - 2$ 个 mask，每个至多累乘 $n$ 次（剪枝后通常更少）。$n = 12$ 时约 $5 \times 10^4$ 次乘法，远低于时限。
- **空间复杂度**：$O(1)$。仅若干计数变量，`__int128` 也只是常数大小（16 字节）。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    bool checkEqualPartitions(vector<int>& nums, long long target) {
        int n = nums.size();
        __int128 all = 1;
        for (int x : nums) {
            if (target % x != 0) return false;               // 关卡一：因子过滤
            all *= x;
        }
        if (all != (__int128)target * target) return false;  // 关卡二：全积守恒

        for (int mask = 1; mask < (1 << n) - 1; mask++) {    // 关卡三：非空真子集
            long long pa = 1;
            for (int i = 0; i < n && pa <= target; i++)      // 剪枝：超 target 即弃
                if (mask >> i & 1) pa *= nums[i];
            if (pa == target) return true;
        }
        return false;
    }
};
```

### Python

```python
class Solution:
    def checkEqualPartitions(self, nums: List[int], target: int) -> bool:
        n = len(nums)
        total = 1
        for x in nums:
            if target % x:                    # 关卡一：因子过滤
                return False
            total *= x
        if total != target * target:          # 关卡二：全积守恒（大数无溢出）
            return False
        for mask in range(1, (1 << n) - 1):   # 关卡三：非空真子集
            p = 1
            for i in range(n):
                if mask >> i & 1:
                    p *= nums[i]
                    if p > target:            # 剪枝：超 target 即弃
                        break
            if p == target:
                return True
        return False
```

## 8. 边界情况与易错点

1. **64 位溢出（本题最大的坑）**：全积上界 $100^{12} = 10^{24}$、$target^2$ 上界 $10^{30}$，双双溢出 `long long`。C++ 必须用 `__int128` 做守恒检查；关卡三若**不剪枝**直接累乘同样可能溢出，务必带上「超 $target$ 即弃」。
2. **mask 上下界**：$[1,\ 2^n - 2]$。放进空集会在 $target = 1$ 时把「空 A + 全量 B」误判成解；放进全集会让补集为空，违反两侧非空。
3. **$target = 1$ 恒为 false**：元素互不相同且 $n \ge 3$，至多一个 1，其余 $\ge 2$ 的元素无处安放。无需特判——关卡一（$target \% x \ne 0$）自动否决，但要能想明白为什么不用特判。
4. **别用两道 O(n) 检查代替枚举**：`[8,16,32], target = 64` 全过两关却无解（见 3.2 警告框），枚举才是最终裁决。
5. **元素 1 的处理**：1 整除任何 target、乘进去积不变，放哪侧都行——枚举框架自动处理，无需单独摘出。
6. **剪枝别写成 `pa >= target`**：积**恰好等于** $target$ 的子集正是要找的目标，只有**超过**才放弃；该剪枝顺带把中间值压在 $10^{17}$ 以内，一石二鸟。
