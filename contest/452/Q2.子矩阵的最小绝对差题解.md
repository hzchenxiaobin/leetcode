# LeetCode 子矩阵的最小绝对差 题解

## 1. 题目概述

- **标题 / 题号**：子矩阵的最小绝对差（#3567，medium）
- **链接**：https://leetcode.cn/problems/minimum-absolute-difference-in-sliding-submatrix/
- **来源**：LeetCode 第 452 场周赛 Q2
- **难度**：中等
- **标签**：数组、矩阵、排序、滑动窗口

**题意**：给定 $m \times n$ 整数矩阵 `grid` 和整数 $k$。对每个以 $(i, j)$ 为左上角的连续 $k \times k$ 子矩阵，求其中**任意两个不同值**之间的最小绝对差；若子矩阵内所有元素都相同，则该处答案为 $0$。返回大小为 $(m-k+1) \times (n-k+1)$ 的矩阵 `ans`。

**约束**：

- $1 \le m, n \le 30$
- $-10^5 \le grid[i][j] \le 10^5$
- $1 \le k \le \min(m, n)$
- 每个窗口内值个数 $k^2 \le 900$，窗口总数 $(m-k+1)(n-k+1) \le 900$

> 💡 **读题关键**：① 题眼是「**不同值**」三个字——两个相等的元素**不构成**合法数对，重复元素必须先去重；② $m, n \le 30$ 明示**暴力逐窗口重算**即可，不需要任何增量维护；③ 全相同时答案规定为 $0$，这正好被「去重后只剩一个值」的分支自然覆盖。

## 2. 示例

**示例 1**

```text
输入：grid = [[1,8],[3,-2]], k = 2
输出：[[2]]
解释：唯一的 2×2 子矩阵中不同值为 [1, 8, 3, -2]，最小绝对差为 |1 - 3| = 2。
```

**示例 2**

```text
输入：grid = [[3,-1]], k = 1
输出：[[0,0]]
解释：每个 1×1 子矩阵只有一个值，无从配对，答案全为 0。
```

**示例 3（关键示例：窗口内有重复值）**

```text
输入：grid = [[1,-2,3],[2,3,5]], k = 2
输出：[[1,2]]
解释：窗口 (0,0) 值为 {1,-2,2,3}，最小差 |1-2| = 1；
     窗口 (0,1) 值为 {-2,3,3,5}，两个 3 不是「不同值」，去重后最小差 |3-5| = 2。
```

## 3. 解题思路

### 3.1 暴力思路：逐窗口收集 + 两两枚举

最朴素的做法：枚举全部 $(m-k+1)(n-k+1)$ 个窗口，每个窗口把 $k^2$ 个值收进数组，然后**两两枚举值对**、跳过相等的对、取最小差。单个窗口代价 $O(k^4)$，总量在 $m = n = 30$、$k \approx 20$ 时约 $10^7$，C++ 勉强能过，但 Python 相当危险。

好在本题有一个立刻能用的优化：**排序之后，最小差必然出现在相邻的两个值之间**（见 3.2），两两枚举可以完全省掉，换成「排序 + 一遍扫描相邻差」。这也是官方标签给出 `Sorting` 的指向。

### 3.2 核心观察：排序后最小差必相邻 ×「不同值」必须去重

![核心观察概念图](images/wc452_q2_adjacent_gap_concept.svg)

**观察 1（相邻最优）**：把窗口内的值排序后，任意一对「跳着比」的值 $a < b$（中间还隔着别的值），设 $a$ 右边紧邻的值是 $a'$（$a < a' \le b$），则

$$b - a \;\ge\; a' - a$$

即任何非相邻对的差都不小于某个相邻差，而相邻对本身也是合法数对。于是**最小差 = 排序后相邻差的最小值**，$O(t^2)$ 的配对枚举降为 $O(t \log t)$ 的排序加线性扫描。

**观察 2（去重陷阱，本题唯一的坑）**：题目要求的是两个「**不同值**」的最小差。若窗口内有重复值（如 $[-2, 3, 3, 5]$），排序后两个相等的 3 紧挨着产生相邻差 $0$，但它们**不是不同值**，这个 $0$ 是假答案。必须先**去重**再查相邻差：去重后得 $[-2, 3, 5]$，正确答案是 $2$。若去重后只剩 $1$ 个值（窗口全相同或 $k = 1$），答案为 $0$，与题面规定一致。

**观察 3（窗口彼此独立）**：每个窗口的答案只依赖自己的 $k^2$ 个值，窗口之间没有任何转移关系。数据规模下（见复杂度分析的 AM–GM 上界）逐窗口重算的总代价约 $5.8 \times 10^4$，**完全不需要**滑动窗口的增量维护（multiset 增删、前驱后继查询等），重算反而是最简单、最不易错的写法。

### 3.3 算法流程

![算法流程图](images/wc452_q2_window_flow.svg)

对每个左上角 $(i, j)$，$0 \le i \le m-k$、$0 \le j \le n-k$：

1. **收集**：把满足 $i \le x < i+k$、$j \le y < j+k$ 的 $k^2$ 个值 `grid[x][y]` 放入临时数组；
2. **排序 + 去重**：`sort` 后接 `unique`（C++ 惯用的 erase–unique 写法；Python 直接 `sorted(set(...))`），得到 $T$ 个互异值；
3. **单值分支**：$T = 1$ → `ans[i][j] = 0`（$k = 1$ 或窗口全相同）；
4. **扫描相邻差**：否则取 $\min_{1 \le t < T}(v_t - v_{t-1})$ 写入 `ans[i][j]`。

### 3.4 示例演算

![示例演算走查](images/wc452_q2_example_walkthrough.svg)

以示例 3 走查两个窗口：

- **窗口 (0, 0)**：收集 $\{1, -2, 2, 3\}$，排序得 $[-2, 1, 2, 3]$（无重复），相邻差 $3, 1, 1$，最小差 $\mathbf{1}$；
- **窗口 (0, 1)**：收集 $\{-2, 3, 3, 5\}$，排序得 $[-2, 3, 3, 5]$，**直接查相邻差会得到假 $0$**（两个 3 不是不同值）；去重后 $[-2, 3, 5]$，相邻差 $5, 2$，最小差 $\mathbf{2}$。

最终 `ans = [[1, 2]]`。

## 4. 算法细节

1. **窗口枚举边界**：$i \in [0, m-k]$、$j \in [0, n-k]$（闭区间），输出尺寸 $(m-k+1) \times (n-k+1)$；上界写成 $m-k+1$ 会越界。
2. **收集范围**：行 $x \in [i, i+k)$、列 $y \in [j, j+k)$，恰好 $k^2$ 个值，与「连续子矩阵」的定义逐格对应。
3. **排序去重的实现**：C++ 用 `sort` + `erase(unique(...))`；Python 一行 `sorted(set(...))` 同时完成两步，最不易错。
4. **单值分支不可省**：$k = 1$ 时每个窗口只有 1 个值，$T = 1$，没有相邻对可扫；窗口全相同同理。该分支正好落实题面「全相同 → 0」的规定。
5. **负数无需特殊处理**：排序后 $v_t \ge v_{t-1}$，相邻差 $v_t - v_{t-1}$ 天然非负，不用再套 `abs`，更不能对无序数组直接求差。
6. **为什么不搞滑动增量维护**：逐窗口重算的总搬运量有 AM–GM 上界 $(m-k+1)k \le \frac{(m+1)^2}{4}$（行列各一次相乘），见复杂度分析；规模小到增量维护纯属负优化。

## 5. 正确性证明

**引理 1（相邻最优）**：设 $v_1 < v_2 < \cdots < v_T$ 为严格递增序列，$T \ge 2$，则

$$\min_{i < j}\,(v_j - v_i) \;=\; \min_{1 \le t < T}\,(v_{t+1} - v_t).$$

**证明**：记 $g = \min_t (v_{t+1} - v_t)$。一方面，每个相邻对 $(v_t, v_{t+1})$ 本身就是下标对 $i < j$，故左边 $\le g$。另一方面，任取 $i < j$：若 $j = i+1$，则 $v_j - v_i$ 就是某个相邻差，$\ge g$；若 $j > i+1$，由 $v_j \ge v_{i+1}$ 得 $v_j - v_i \ge v_{i+1} - v_i \ge g$。故左边 $\ge g$。两向合并即得等号。∎

**引理 2（去重等价）**：设某窗口内全部互异值构成集合 $S$，$|S| = T$。若 $T \le 1$，窗口答案为 $0$；若 $T \ge 2$，窗口答案等于 $S$ 升序排列后相邻差的最小值。

**证明**：「窗口内两个不同值组成的数对」与「$S$ 中两个互异元素组成的数对」一一对应：窗口元素的取值都属于 $S$，且两元素值不同当且仅当对应的 $S$ 中元素不同；反之 $S$ 中任取两个互异值，窗口内必存在取这两个值的元素（$S$ 就是窗口取值集合）。$T \le 1$ 时（即窗口所有元素同值，含 $k = 1$）不存在不同值数对，按题面规定答案为 $0$；$T \ge 2$ 时对 $S$ 的升序序列应用引理 1 即得。∎

**定理**：算法输出的 `ans[i][j]` 等于以 $(i, j)$ 为左上角的 $k \times k$ 子矩阵中两个不同值的最小绝对差（全相同时为 $0$）。

**证明**：算法收集的范围与子矩阵定义完全一致，故收集到的 $k^2$ 个值恰为该子矩阵的全部元素；排序去重后得到的升序序列恰为引理 2 中的 $S$。由引理 2，$T = 1$ 分支返回 $0$ 正确，多值分支返回的相邻差最小值正确。枚举的 $(i, j)$ 恰好覆盖且仅覆盖所有合法左上角，故整个 `ans` 正确。∎

## 6. 复杂度分析

- **时间复杂度**：$O\big((m-k+1)(n-k+1) \cdot k^2 \log k\big)$。由 AM–GM 不等式，$(m-k+1) \cdot k \le \frac{(m+1)^2}{4}$，同理 $(n-k+1) \cdot k \le \frac{(n+1)^2}{4}$，故总搬运量

$$(m-k+1)(n-k+1)\,k^2 \;\le\; \frac{(m+1)^2 (n+1)^2}{16} \;\approx\; 5.8 \times 10^4 \quad (m = n = 30),$$

  排序与扫描开销同量级，毫秒级完成。若坚持两两枚举则为 $O(k^4)$ 每窗，总量约 $10^7$，C++ 可过但已是危险边缘。
- **空间复杂度**：$O(k^2)$，即临时数组的开销（$\le 900$ 个 `int`）；输出数组不计入。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    vector<vector<int>> minAbsDiff(vector<vector<int>>& grid, int k) {
        int m = grid.size(), n = grid[0].size();
        int r = m - k + 1, c = n - k + 1;
        vector<vector<int>> ans(r, vector<int>(c));
        vector<int> vals;
        vals.reserve((size_t)k * k);
        for (int i = 0; i < r; i++) {
            for (int j = 0; j < c; j++) {
                vals.clear();                              // 收集窗口内 k² 个值
                for (int x = i; x < i + k; x++)
                    for (int y = j; y < j + k; y++)
                        vals.push_back(grid[x][y]);
                sort(vals.begin(), vals.end());
                vals.erase(unique(vals.begin(), vals.end()), vals.end());  // 去重！
                if (vals.size() == 1) {
                    ans[i][j] = 0;                        // k=1 或全相同
                } else {
                    int best = INT_MAX;                   // 扫描相邻差
                    for (int t = 1; t < (int)vals.size(); t++)
                        best = min(best, vals[t] - vals[t - 1]);
                    ans[i][j] = best;
                }
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def minAbsDiff(self, grid: List[List[int]], k: int) -> List[List[int]]:
        m, n = len(grid), len(grid[0])
        r, c = m - k + 1, n - k + 1
        ans = [[0] * c for _ in range(r)]
        for i in range(r):
            for j in range(c):
                vals = sorted({                      # set 一步完成去重
                    grid[x][y]
                    for x in range(i, i + k)
                    for y in range(j, j + k)
                })
                if len(vals) == 1:
                    ans[i][j] = 0                    # k=1 或全相同
                else:
                    ans[i][j] = min(b - a for a, b in zip(vals, vals[1:]))
        return ans
```

## 8. 边界情况与易错点

1. **不去重（本题最大的坑）**：窗口内有重复值时，排序后相等的值相邻产生假 $0$。示例 3 的窗口 $(0,1)$：$[-2, 3, 3, 5]$ 直接扫相邻差得 $0$，去重后才是正确答案 $2$。
2. **单值分支漏写**：$k = 1$ 或窗口全相同时只剩 $1$ 个值，若不单独处理，对长度 1 的序列扫相邻差会得到无意义结果（甚至越界）。
3. **输出尺寸**：`ans` 是 $(m-k+1) \times (n-k+1)$，$i$、$j$ 的枚举上界是 $m-k$、$n-k$（闭区间），别多开一行一列。
4. **负数处理**：排序后 $v_t - v_{t-1} \ge 0$ 恒成立，无需 `abs`；反过来「不排序直接对无序数组求相邻差」则必然出错。
5. **无溢出风险**：值域 $[-10^5, 10^5]$，差不超过 $2 \times 10^5$，`int` 足够，本题不考溢出。
6. **别急着上滑动窗口**：multiset 增量维护（滑一格删左列加右列）在本题规模下是负优化——代码更长、坑更多（删除时迭代器失效等），重算又短又稳。

**延伸思考**：

- 若 $m, n \le 10^3$、$k \le 10^3$：逐窗重排的总搬运量达 $10^{12}$ 量级，必须改为增量维护——窗口右移一格时删去左列 $k$ 个值、加入右列 $k$ 个值，用 `multiset` 维护窗口内值；最小差不能现算，需在每次插入/删除时用前驱（`prev(it)`）与后继（`next(it)`）更新候选差集合，整体 $O(mnk \log k)$。
- 值域只有 $2 \times 10^5 + 1$ 种，还能用桶 + 树状数组维护「值是否存在」并查询前驱后继，把单次更新降到 $O(\log V)$；若还要求在线区间询问，可进一步考虑二维莫队或可持久化结构。
