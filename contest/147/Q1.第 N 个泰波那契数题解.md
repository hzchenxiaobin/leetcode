# LeetCode 第 N 个泰波那契数 题解

## 1. 题目概述

- **标题 / 题号**：第 N 个泰波那契数（#1137，easy）
- **链接**：https://leetcode.cn/problems/n-th-tribonacci-number/
- **来源**：LeetCode 第 147 场周赛 Q1
- **难度**：简单
- **标签**：记忆化搜索、数学、动态规划

**题意**：泰波那契序列由三个初值和一个三阶线性递推确定：

$$T_0 = 0,\quad T_1 = 1,\quad T_2 = 1,\qquad T_{n+3} = T_n + T_{n+1} + T_{n+2}\ (n \ge 0)$$

给定整数 `n`，返回 $T_n$。换句话说，从第 3 项起，每一项都是**前 3 项之和**。

**约束**：

- $0 \le n \le 37$
- 答案保证落在 32 位有符号整数范围内，即 $T_n \le 2^{31} - 1$

> 💡 签到题定位：只需把「前两项之和」（斐波那契）换成「前三项之和」，递推骨架完全一样。真正要写对的只有两件事——**初值**与**循环边界**。

## 2. 示例

**示例 1**

```text
输入：n = 4
输出：4
解释：
T_3 = T_0 + T_1 + T_2 = 0 + 1 + 1 = 2
T_4 = T_1 + T_2 + T_3 = 1 + 1 + 2 = 4
```

**示例 2**

```text
输入：n = 25
输出：1389537
解释：一路递推到 T_25 = 1389537，仍在 int 范围内。
```

**示例 3（边界自测）**

```text
输入：n = 0     输出：0     解释：直接返回初值 T_0。
输入：n = 1     输出：1     解释：直接返回初值 T_1。
输入：n = 2     输出：1     解释：直接返回初值 T_2，不做任何加法。
输入：n = 3     输出：2     解释：0 + 1 + 1 = 2，只跑一轮循环。
```

## 3. 解题思路

### 3.1 暴力思路

最直白的写法是把定义抄成递归：

$$T(n) = T(n-1) + T(n-2) + T(n-3)$$

问题在于同一个状态会被展开很多次：算 $T(6)$ 需要 $T(5),T(4),T(3)$，而 $T(5)$ 又要再算一遍 $T(4),T(3),T(2)$，如此反复。节点数按 $\lambda^n$ 增长，其中 $\lambda$ 是 $x^3 = x^2 + x + 1$ 的最大实根，$\lambda \approx 1.8393$，于是 $1.8393^{37} \approx 6 \times 10^{9}$——远超 1 秒能承受的调用量，必然超时。

把「算过的答案存起来」就得到记忆化搜索（$O(n)$ 时间、$O(n)$ 空间）；再把「自顶向下」翻成「自底向上」，就是 DP 数组；最后发现状态只依赖**前 3 项**，数组也可以省掉。

### 3.2 核心观察：无后效性 + 滑动三格

![朴素递归的重复子问题与三条优化路线](images/wc147_q1_recursion_tree.svg)

递推式 $T_i = T_{i-1} + T_{i-2} + T_{i-3}$ 有两个关键性质：

1. **无后效性**：$T_i$ 只由 $T_{i-1}, T_{i-2}, T_{i-3}$ 决定，与更早的项、与「怎么算出来的」都无关。因此按 $i$ 递增的顺序逐个算，不会回头改已经算好的值。
2. **依赖窗口固定为 3**：任何时候只有最近的 3 个值会被用到，更早的值算完就再也用不上。于是**不需要数组**，三个变量 $a, b, c$ 就够，滚动覆盖即可。

这就是本题的最优解：**三变量滚动递推**，时间 $O(n)$、空间 $O(1)$。

### 3.3 算法流程 / 状态转移

![三变量滚动的状态转移流程](images/wc147_q1_rolling_state.svg)

**状态定义**：进入第 $i$ 轮（$i \ge 3$）时，令

$$a = T_{i-3},\qquad b = T_{i-2},\qquad c = T_{i-1}$$

**转移**：

$$d \leftarrow a + b + c = T_i,\qquad (a,b,c) \leftarrow (b,\,c,\,d)$$

**流程**：

1. 特判 $n < 2$，直接返回 $n$（也就是 $n=0 \to 0$，$n=1 \to 1$）。
2. 初始化 $a = 0,\ b = 1,\ c = 1$。此时 $n \le 2$ 的答案已经在 $c$ 里了。
3. 对 $i = 3, 4, \dots, n$ 依次执行一次转移。
4. 返回 $c$。

循环结束后 $c$ 恰好是 $T_n$：最后一轮 $i = n$ 算出的 $d = T_n$ 被移进了 $c$。

### 3.4 示例演算

![从 T(0..2) 滚动到 T(8) 的演算表](images/wc147_q1_walkthrough.svg)

对 $n = 4$：

| 轮次 $i$ | $a = T_{i-3}$ | $b = T_{i-2}$ | $c = T_{i-1}$ | $d = a+b+c$ | 更新后 $(a,b,c)$ |
|---|---|---|---|---|---|
| 初始 | 0 | 1 | 1 | — | $(0,1,1)$ |
| 3 | 0 | 1 | 1 | **2** | $(1,1,2)$ |
| 4 | 1 | 1 | 2 | **4** | $(1,2,4)$ |

循环结束，返回 $c = 4$，与示例 1 一致。

对 $n = 25$，只需把上表继续滚到 $i = 25$（共 23 轮），末轮得到 $T_{25} = 1389537$；再往后滚到 $i = 37$ 得 $T_{37} = 2082876103$，仍然不超过 $2^{31}-1$，这正是「答案保证在 int 范围内」的含义。

## 4. 算法细节

1. **特判的写法**：`if (n < 2) return n;` 一行同时覆盖 $n=0$（返回 0）与 $n=1$（返回 1）；不要写成 `if (n <= 2) return 1;`（那会让 $n=0$ 错报成 1），$n=2$ 交给初值 $c = 1$ 自然处理即可。
2. **初值三元组必须是 $(0,1,1)$**：顺序是 $T_0, T_1, T_2$。常见错误是写成 $(0,1,2)$（那是斐波那契的初值习惯）或 $(1,1,1)$。
3. **循环区间是 $[3, n]$ 闭区间**：`for (int i = 3; i <= n; ++i)`。写成 `i < n` 会少滚一轮，$n=3$ 时直接返回初值 1。
4. **更新顺序不能错**：必须先算出 $d = a+b+c$，再整体左移。若写成 `a = b; b = c; c = a + b + c;`，此时 $a$ 已经被覆盖，加出来的是 $T_{i-2} + T_{i-1} + (T_{i-2}+T_{i-1})$，完全错误。
5. **利用语言的并行赋值**：Python 写 `a, b, c = b, c, a + b + c`，右侧三项在赋值前一次性求值，天然满足「先算后用」，无需临时变量；C++ 则需要显式的 `long long d`。
6. **防止溢出**：$T_{37} = 2082876103 < 2^{31}-1 = 2147483647$，`int` 刚好够；但只要 $n$ 放宽到 38，$T_{38} = 3831006429$ 就溢出 32 位有符号整数了，所以 C++ 里用 `long long` 存中间量、最后转回 `int` 更稳妥。**本题不允许取模**，答案必须是精确值。
7. **不要用递归**：$n \le 37$ 时递归加记忆化也能过，但栈深 37 且要额外哈希表；自底向上三变量既短又快，是这类题的默认模板。

## 5. 正确性证明

**引理 1（递推封闭）**：对任意 $i \ge 3$，$T_i$ 由 $T_{i-1}, T_{i-2}, T_{i-3}$ 唯一确定，且等于三者之和。

**证明**：题面定义 $T_{n+3} = T_n + T_{n+1} + T_{n+2}$ 对所有 $n \ge 0$ 成立。令 $n = i-3$（$i \ge 3$ 时 $n \ge 0$），即得 $T_i = T_{i-3} + T_{i-2} + T_{i-1}$。右端三项均已由序列定义确定，故 $T_i$ 唯一确定。∎

**引理 2（循环不变量）**：记第 $i$ 轮（$i \ge 3$）开始前三个变量的值为 $(a_i, b_i, c_i)$，则

$$(a_i,\, b_i,\, c_i) = (T_{i-3},\, T_{i-2},\, T_{i-1})$$

**证明**：对 $i$ 归纳。

- **基础**：$i = 3$ 时初始化为 $(0, 1, 1) = (T_0, T_1, T_2)$，成立。
- **归纳**：设第 $i$ 轮开始前不变量成立。本轮先算出 $d = a_i + b_i + c_i = T_{i-3} + T_{i-2} + T_{i-1} = T_i$（引理 1）；随后按 $(a,b,c) \leftarrow (b,c,d)$ 更新，得到 $(T_{i-2}, T_{i-1}, T_i)$，正是第 $i+1$ 轮开始前应有的三元组。∎

**定理**：`tribonacci(n)` 返回 $T_n$。

**证明**：分三种情况。

- $n = 0$：函数返回 `n`，即 0 $= T_0$。
- $n = 1$：函数返回 `n`，即 1 $= T_1$。
- $n \ge 2$：初始化后 $c = 1 = T_2$，若 $n = 2$ 则循环体不执行，返回 $c = T_2$，正确；若 $n \ge 3$，循环执行到 $i = n$ 结束。由引理 2，最后一轮开始前 $c = T_{n-1}$，该轮算出 $d = T_n$ 并把它赋给 $c$，循环结束时的 $c$ 即 $T_n$，返回值正确。

三种情况穷尽，故算法对约束内所有 $n$ 都返回 $T_n$。∎

## 6. 复杂度分析

- **时间**：$O(n)$。初始化 $O(1)$；循环恰好执行 $\max(0, n-2)$ 轮，每轮一次加法与三次赋值，均 $O(1)$。总加法次数为 $n-2$，$n \le 37$ 时最多 35 次，可视为常数级。
- **空间**：$O(1)$。只用 $a, b, c$（以及 C++ 中的中间量 $d$）四个整数，与 $n$ 无关；没有数组、没有递归栈、没有哈希表。
- **对比**：朴素递归时间 $O(1.84^n)$、空间 $O(n)$（递归深度）；记忆化 / DP 数组时间 $O(n)$、空间 $O(n)$；本题解在时间不变的前提下把空间压到 $O(1)$。若把 $n$ 放大到 $10^{18}$，则应改用 $3 \times 3$ 矩阵快速幂，时间 $O(\log n)$、空间 $O(1)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int tribonacci(int n) {
        if (n < 2) return n;             // n = 0 -> 0, n = 1 -> 1
        long long a = 0, b = 1, c = 1;   // T(0), T(1), T(2)
        for (int i = 3; i <= n; ++i) {
            long long d = a + b + c;     // d = T(i)，用 long long 兜住中间量
            a = b;                       // 整体左移：a <- b
            b = c;                       //           b <- c
            c = d;                       //           c <- d
        }
        return (int)c;
    }
};
```

### Python

```python
class Solution:
    def tribonacci(self, n: int) -> int:
        if n < 2:
            return n                     # n = 0 -> 0, n = 1 -> 1
        a, b, c = 0, 1, 1                # T(0), T(1), T(2)
        for _ in range(3, n + 1):
            a, b, c = b, c, a + b + c    # 右侧先求值，等价于先算 d 再左移
        return c
```

## 8. 边界情况与易错点

1. **$n = 0$**：答案 0 而不是 1。若把特判写成 `if (n <= 2) return 1`，$n=0$ 就会错报成 1。
2. **$n = 1$ 与 $n = 2$**：两者答案都是 1，但来源不同——$T_1$ 是初值，$T_2$ 也是初值，循环一次都不该进。`range(3, n + 1)` 在 $n=2$ 时为空，`for (i = 3; i <= 2; ...)` 也不执行，天然安全。
3. **更新顺序**：先算 $d$ 再左移。若先写 `a = b`，后续 `a + b + c` 用的就是被污染的值，$n=4$ 会算错。Python 的元组赋值是唯一可以「省掉临时变量」的写法。
4. **溢出**：$T_{37} = 2082876103$ 已非常接近 `int` 上界 $2147483647$。若把题目改成 $n \le 50$，`int` 立刻溢出，必须换 `long long`；同时注意本题**不能取模**，取模会直接错答案。
5. **返回 `c` 而不是 `d`**：`d` 是循环体内的局部变量，循环结束后已不可见；语义上「最近一项」永远在 `c` 里。
6. **别把三项写成两项**：如果照着斐波那契写成 $T_i = T_{i-1} + T_{i-2}$，$n=4$ 会得到 3 而不是 4，这是本题最常见的整题翻车点。

**延伸思考**：若把 $n$ 放大到 $10^{18}$（$O(n)$ 递推必然超时），标准做法是构造 $3 \times 3$ 转移矩阵

$$\begin{pmatrix} T_{i} \\ T_{i-1} \\ T_{i-2} \end{pmatrix} = \begin{pmatrix} 1 & 1 & 1 \\ 1 & 0 & 0 \\ 0 & 1 & 0 \end{pmatrix}\begin{pmatrix} T_{i-1} \\ T_{i-2} \\ T_{i-3} \end{pmatrix}$$

再用快速幂把它乘到 $n-2$ 次方，时间 $O(\log n)$；若要求取模或模数是质数，还可以用特征方程 $\lambda^3 - \lambda^2 - \lambda - 1 = 0$ 配合多项式快速幂（Kitamasa 法）做到同样的复杂度，且常数更小。
