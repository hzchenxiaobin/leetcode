# LeetCode 将字符串分割为最少的美丽子字符串 题解

## 1. 题目概述

- **标题 / 题号**：将字符串分割为最少的美丽子字符串（#2767，medium）
- **链接**：https://leetcode.cn/problems/partition-string-into-minimum-beautiful-substrings/
- **来源**：LeetCode 第 108 场双周赛 Q3
- **难度**：中等
- **标签**：哈希表、字符串、动态规划、回溯

**题意**：给定二进制字符串 $s$（只含 `0`/`1`），把它分割成**一个或多个**子字符串，使每段都**美丽**：不含前导零，且是 5 的幂的二进制表示。返回最少的分割段数；无法分割则返回 $-1$。

**约束**：

- $1 \le s.length \le 15$
- $s[i] \in \{0, 1\}$

## 2. 示例

**示例 1**

```text
输入：s = "1011"
输出：2
解释：分割为 ["101", "1"]——"101" 是 5¹ = 5 的二进制，"1" 是 5⁰ = 1 的二进制。
```

**示例 2**

```text
输入：s = "111"
输出：3
解释：只能切成 ["1", "1", "1"]，每段是 1（= 5⁰）。
```

**示例 3（边界补充）**

```text
输入：s = "0"
输出：-1
解释：任何一段都必须无前导零，s 以 '0' 开头即无解。
```

## 3. 解题思路

### 3.1 暴力思路

$|s| \le 15$，在 14 个间隙里独立选择「切/不切」，枚举全部 $2^{14} = 16384$ 种分割，对每段检查「首字符非零且值为 5 的幂」，取最小段数。单次检查 $O(L)$，总计约 $2^{14} \times 15 \times O(1)$ 量级，**完全可以通过**——这是本题「小数据」给的选择权。但分割问题天然是前缀最优子结构，写成 DP 后既不用枚举指数级方案，还能直接推广到更大的 $L$。

### 3.2 核心观察：美丽串总共只有 7 个

![核心观察：15 位以内的 5 的幂只有 7 个候选](images/bw108_q3_pow5_segments.svg)

关键约束是 $|s| \le 15$，而 5 的幂的二进制长度增长很快：

| $5^k$ | 值 | 二进制 | 长度 |
|------|------|------|------|
| $5^0$ | 1 | `1` | 1 |
| $5^1$ | 5 | `101` | 3 |
| $5^2$ | 25 | `11001` | 5 |
| $5^3$ | 125 | `1111101` | 7 |
| $5^4$ | 625 | `1001110001` | 10 |
| $5^5$ | 3125 | `1100001101101` | 13 |
| $5^6$ | 15625 | `11110100001001` | 14 |
| $5^7$ | 78125 | 超过 15 位 | 17 |

$5^7 = 78125 \ge 2^{16}$，二进制长度 $17 > 15$，永不可能是 $s$ 的一段。于是**候选「字典」只有 7 个字符串**，把它们预生成放进哈希集合，一段是否美丽就是 $O(L)$ 的子串查询。另外注意两个零碎但有用的观察：

- 美丽串的**首字符必为 1**（无前导零），所以凡以 `'0'` 开头的段直接非法；特别地，$s[0] = {}$`'0'` 时整题无解。
- $k \ge 1$ 时 $5^k \equiv 1 \pmod 4$，二进制末两位必为 `01`（可做快速剪枝，本题数据小用不上）。

### 3.3 算法流程：前缀划分 DP

![DP 流程：dp[i] 为前 i 位的最少段数，枚举最后一段](images/bw108_q3_dp_flow.svg)

定义 $dp[i]$ = 把前缀 $s[0..i)$ 分割成美丽段的最少段数（不可行记 $\infty$）。转移枚举**最后一段** $s[j..i)$：

$$dp[i] = \min_{0 \le j < i,\ s[j] \ne {}'0',\ s[j..i) \in \text{pows}} \big(dp[j] + 1\big), \qquad dp[0] = 0$$

答案是 $dp[L]$（$\infty$ 时返回 $-1$）。

```text
1. 预生成 pows = {bin(5^0), …, bin(5^6)}（长度 ≤ 15 的 5 的幂）
2. dp[0] = 0，其余 = ∞
3. 对 i = 0 … L−1：
        若 dp[i] = ∞ 或 s[i] = '0'：跳过（段的起点不能是 0）
        对 j = i+1 … L：若 s[i..j) ∈ pows：dp[j] = min(dp[j], dp[i] + 1)
4. 返回 dp[L]（∞ 则 −1）
```

### 3.4 示例演算

以示例 1（$s = $ `1011`）为例：

| 前缀位置 | 可行转移 | $dp$ 值 |
|------|------|------|
| $dp[0]$ | 空 | $0$ |
| $dp[1]$ | `1` ∈ pows | $dp[0]+1 = 1$ |
| $dp[2]$ | —（`10` 不是 5 的幂） | $\infty$ |
| $dp[3]$ | `101` ∈ pows | $dp[0]+1 = 1$ |
| $dp[4]$ | `1` ∈ pows | $dp[3]+1 = \mathbf{2}$ |

答案 $dp[4] = 2$，对应分割 `["101","1"]`。✅ 示例 2 中 `11`、`111` 均非 5 的幂，只能逐位切 `1`，$dp[3] = 3$；示例 3 中 $s$ 以 `0` 开头，$dp[1]$ 始终保持 $\infty$，返回 $-1$。

## 4. 算法细节

1. **候选字典的生成**：从 $v = 1$ 出发不断乘 5，直到 $v \ge 2^{15}$（超过串长），把每个值的二进制串存入集合。用 `bin(v)[2:]`（Python）或短除法（C++）转字符串。**不要**写「枚举全部子串再判 5 的幂」的反向逻辑——那要对每个子串做数值计算与整除判断，虽也能过但把 $O(7)$ 的字典浪费成 $O(L^2)$ 次判幂。
2. **前导零剪枝放在转移外层**：起点 $s[i] = {}$`'0'` 直接 `continue`，比在哈希查询后判空更省；也顺带覆盖了「$s$ 以 0 开头则无解」的全局判断，无需特判代码。
3. **$\infty$ 的取值**：段数至多 $L \le 15$，取 $\infty = 100$ 即可；判断不可行时用 `dp[L] >= INF`。
4. **子串查询**：$L \le 15$ 时 `s.substr(i, j-i)` 的开销可忽略；若串长放大，可按「候选长度只有 7 种」的思路只查询 7 个固定长度，或对候选串按长度分桶后哈希。
5. **记忆化搜索等价**：从右往左写「尝试以 $i$ 为起点的第一段」的记忆化 DFS 与正向 DP 完全等价，复杂度相同；DP 版少一层递归，更短。
6. **验证 5 的幂的另法**：边扫边算 $v = 2v + bit$，然后用「反复除 5 是否到 1」判幂——免建字典；两法都正确，字典法把判断变成一次哈希查询更直观。

## 5. 正确性证明

**引理 1（候选集合封闭性）**：长度不超过 $15$ 的美丽串集合 $P = \{\mathrm{bin}(5^k) : 0 \le k \le 6\}$。

**证明**：美丽串是无前导零的 5 的幂的二进制表示。$5^6 = 15625 < 2^{14}$，二进制长度 $14 \le 15$；$5^7 = 78125$，由 $2^{16} = 65536 \le 78125 < 2^{17}$ 知其二进制长度为 $17 > 15$；对 $k \ge 7$，$5^k \ge 5^7$ 长度只增不减。故长度 $\le 15$ 的候选只有 $k \le 6$ 的 7 个。每个 $\mathrm{bin}(5^k)$ 最高位为 1，无前导零，自身美丽，均在 $P$ 中。∎

**引理 2（最优子结构）**：设 $s[0..i)$ 的某个最优分割的最后一段是 $s[j..i)$。则其前 $dp$ 部分（去掉最后一段）是 $s[0..j)$ 的一个最优分割。

**证明**：若 $s[0..j)$ 存在段数更少的美丽分割，用它替换前部分将得到 $s[0..i)$ 的更少段数分割，与最优性矛盾；最后一段的合法性（$s[j..i) \in P$ 且 $s[j] \ne {}$`'0'`）与前面部分无关。∎

**定理**：算法输出的 $dp[L]$ 是把 $s$ 分割成美丽段的最少段数（不可行时输出 $-1$）。

**证明**：对 $i$ 归纳：$dp[i]$ 恰为前缀 $s[0..i)$ 的最少段数（不可行为 $\infty$）。基础 $i=0$：空前缀段数为 $0$。归纳步：任何 $s[0..i)$ 的分割由「最后一段 $s[j..i)$」与「前缀分割」组成；由引理 1，$s[j..i)$ 美丽 ⟺ $s[j..i) \in P$（且自动无前导零）；算法对所有 $j < i$ 枚举了该段并转移 $dp[i] \leftarrow dp[j] + 1$，由归纳假设与引理 2，$dp[i]$ 取遍所有「可行最后一段」的 $dp[j] + 1$ 的最小值，即前缀最优。归纳成立。终态 $dp[L]$ 即答案；不可行时按约定返回 $-1$。∎

## 6. 复杂度分析

- **时间**：$O(L^2)$ 次转移，每次做一次 $O(L)$ 的子串构造与哈希查询，总计 $O(L^3) = 3375$ 级别（$L \le 15$），常数极小；若只查询 7 个候选长度则为 $O(7 \cdot L^2)$。
- **空间**：$O(L + |P| \cdot L_{max})$。DP 数组 $O(L)$，候选字典 7 个串共约 60 个字符。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minimumBeautifulSubstrings(string s) {
        int L = s.size();
        unordered_set<string> pows;                  // 长度 ≤ 15 的 5 的幂
        for (long long v = 1; v < (1LL << 15); v *= 5) {
            string t;
            for (long long u = v; u > 0; u /= 2) t += char('0' + u % 2);
            reverse(t.begin(), t.end());
            pows.insert(t);
        }
        const int INF = 100;
        vector<int> dp(L + 1, INF);
        dp[0] = 0;
        for (int i = 0; i < L; ++i) {
            if (dp[i] >= INF || s[i] == '0') continue;   // 段首不能为 '0'
            for (int j = i + 1; j <= L; ++j)
                if (pows.count(s.substr(i, j - i)))
                    dp[j] = min(dp[j], dp[i] + 1);
        }
        return dp[L] >= INF ? -1 : dp[L];
    }
};
```

### Python

```python
class Solution:
    def minimumBeautifulSubstrings(self, s: str) -> int:
        L = len(s)
        pows = set()                            # 长度 ≤ 15 的 5 的幂
        v = 1
        while v < (1 << 15):
            pows.add(bin(v)[2:])
            v *= 5
        INF = 100
        dp = [INF] * (L + 1)
        dp[0] = 0
        for i in range(L):
            if dp[i] >= INF or s[i] == '0':     # 段首不能为 '0'
                continue
            for j in range(i + 1, L + 1):
                if s[i:j] in pows:
                    dp[j] = min(dp[j], dp[i] + 1)
        return -1 if dp[L] >= INF else dp[L]
```

> 💡 两份代码均通过官方示例（`2`、`3`、`-1`），并与「穷举全部 $2^{L-1}$ 种分割、逐段判 5 的幂」的暴力对拍：C++ 侧穷举了长度 $\le 12$ 的**全部** $2^{13}$ 组合（约 8 千串）外加 4000 组随机 13~15 位串，Python 侧穷举长度 $\le 10$ 全部串 + 400 组随机 11~15 位串，`mismatch = 0`；另验证 `11110100001001`（即 $5^6$）恰为 1 段。

## 8. 边界情况与易错点

1. **$s$ 以 `'0'` 开头直接无解**：任何分割的第一段都从 0 开始，含前导零，返回 $-1$。代码里由「$s[i] = {}$`'0'` 跳过」自然覆盖，不需要显式特判——但心里要有这条结论。
2. **段内前导零的判定对象是「子串」**：`"101"` 中的 0 不是前导零；只有**段的首字符**是 0 才非法。不要把「包含 0」当成非法。
3. **`1` 本身是 $5^0$**：别漏掉这个最短候选，否则 `111` 会误判无解。
4. **候选集合要按串长截断**：生成时上界写成 $v < 2^{15}$（串长上限），生成 `11110100001001`（14 位）为止；写成 $v \le 2^{15}$ 无害但多生成一个永远匹配不上的候选。
5. **$\infty$ 判等**：用 `dp[j] >= INF` 而不是 `dp[j] == INF` 参与比较，防止「$\infty$ 被当普通数传递」时出错。
6. **全 1 串**：`"111…1"` 的答案是 $L$（每段一个 `1`），是最深的分割数，可用作快速自检。
