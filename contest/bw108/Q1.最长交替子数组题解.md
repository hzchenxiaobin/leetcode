# LeetCode 最长交替子数组 题解

## 1. 题目概述

- **标题 / 题号**：最长交替子数组（#2765，easy）
- **链接**：https://leetcode.cn/problems/longest-alternating-subarray/
- **来源**：LeetCode 第 108 场双周赛 Q1
- **难度**：简单
- **标签**：数组、枚举

**题意**：给定整数数组 `nums`。若长度 $m > 1$ 的子数组 $s$ 满足：$s_1 = s_0 + 1$，且差分依次交替为 $+1, -1, +1, -1, \dots$（即子数组形如 $[v,\ v+1,\ v,\ v+1,\ \dots]$，在 $v$ 与 $v+1$ 之间来回跳动），则称它为**交替子数组**。返回最长交替子数组的长度；不存在则返回 $-1$。

**约束**：

- $2 \le nums.length \le 100$
- $1 \le nums[i] \le 10^4$

## 2. 示例

**示例 1**

```text
输入：nums = [2,3,4,3,4]
输出：4
解释：交替子数组有 [2,3]、[3,4]、[3,4,3]、[3,4,3,4]，最长为 [3,4,3,4]，长度 4。
```

**示例 2**

```text
输入：nums = [4,5,6]
输出：2
解释：只有 [4,5]、[5,6] 两个交替子数组，长度均为 2。
```

**示例 3（边界补充）**

```text
输入：nums = [7,7,7]
输出：-1
解释：任何相邻两数都不满足 +1，不存在交替子数组。
```

## 3. 解题思路

### 3.1 暴力思路

枚举全部 $O(n^2)$ 个子数组 $[i, j]$，再花 $O(n)$ 逐位检查「差分交替且首步为 $+1$」，总计 $O(n^3)$。$n \le 100$ 时不过 $10^6$ 次操作，必然能过。但检查完全可以增量进行：固定起点向右延伸，遇到第一个不满足的位置立即停止——这就是下面的枚举起点法，最坏 $O(n^2)$，写起来反而更短。

### 3.2 核心观察：交替模式只有一种形状

![核心观察：交替子数组在 v 与 v+1 之间来回跳动](images/bw108_q1_pattern_concept.svg)

把差分条件展开：$s_1 - s_0 = +1$，$s_2 - s_1 = -1$，$s_3 - s_2 = +1$……于是**偶数下标处恒为 $v$、奇数下标处恒为 $v+1$**，其中 $v = s_0$。换言之，从起点 $i$ 出发，位置 $j$ 的期望值是

$$\text{期望}(j) = nums[i] + \big((j - i) \bmod 2\big)$$

两个直接推论：

1. 起点合法的必要条件是 $nums[i+1] = nums[i] + 1$（模式第一步必须成立），不满足的起点直接跳过；
2. 从起点 $i$ 延伸到第一个 $\text{期望}(j) \ne nums[j]$ 的位置 $j$ 为止，这段长度 $j - i$ 就是以 $i$ 为起点的最长交替子数组长度。

### 3.3 算法流程

```text
1. ans = −1
2. 对每个 i（0 ≤ i < n−1）：
        若 nums[i+1] ≠ nums[i] + 1：跳过
        j = i + 2
        while j < n 且 nums[j] == nums[i] + ((j−i) mod 2)：j++
        ans = max(ans, j − i)
3. 返回 ans
```

注意延伸失败后**不能**把失败位置当作相邻起点的共享信息直接复用——期望值依赖起点处的基准 $v$，换起点后基准变了；$n \le 100$ 也无需这类优化。

### 3.4 示例演算

![示例演算：nums = 2,3,4,3,4 的两个合法起点](images/bw108_q1_walkthrough.svg)

以示例 1（$nums = [2,3,4,3,4]$）为例：

| 起点 $i$ | 首步检查 | 延伸过程 | 长度 |
|------|------|------|------|
| $i=0$（$v=2$） | $nums[1]=3=2+1$ ✓ | 期望 $2$，但 $nums[2]=4 \ne 2$ ✗，止于 $j=2$ | 2 |
| $i=1$（$v=3$） | $nums[2]=4=3+1$ ✓ | $nums[3]=3=3+0$ ✓，$nums[4]=4=3+1$ ✓，到末尾 | **4** |
| $i=2$（$v=4$） | $nums[3]=3 \ne 5$ ✗ | 跳过 | — |
| $i=3$（$v=3$） | $nums[4]=4=3+1$ ✓ | 延伸到末尾 | 2 |

最长为 $4$，即子数组 $[3,4,3,4]$。✅

## 4. 算法细节

1. **期望值公式**：$(j-i) \bmod 2$ 为 0 期望 $v$、为 1 期望 $v+1$，比维护「上一步差分符号」的写法少一个状态变量，不易错。
2. **答案初值 $-1$**：题目规定 $m > 1$ 才算交替子数组，单个元素不算；找不到合法子数组时返回 $-1$，不要初始化成 1 或 0。
3. **跳过条件的等价写法**：`if (nums[i+1] != nums[i] + 1) continue;` 与「j 从 i+1 起延伸」的写法等价，但前者让主循环更干净。
4. **溢出无虞**：$nums[i] \le 10^4$，加 1、比较都在 `int` 范围内。
5. **延伸循环别写成单次 `if`**：只检查一位会漏掉 $[3,4,3,4]$ 这种长度 $\ge 3$ 的情况。
6. **$O(n)$ 做法存在但没必要**：延伸失败于位置 $j$ 时，可以证明区间 $(i, j)$ 内的任何起点其模式也必然在 $j$ 处或更早失败（它们在 $j$ 处的期望值与从 $i$ 出发完全相同，见延伸思考），于是下个候选起点只有 $j-1$ 与 $j$；整体可摊还 $O(n)$。$n \le 100$ 用朴素枚举即可，少写一行是一行。

## 5. 正确性证明

**引理（模式的封闭刻画）**：子数组 $nums[i..j]$（$j > i$）是交替子数组，当且仅当 $nums[i+1] = nums[i] + 1$，且对所有 $k \in [i+2, j]$ 有 $nums[k] = nums[i] + ((k-i) \bmod 2)$。

**证明**：**必要性**：差分条件归纳给出 $s_t = s_0 + (t \bmod 2)$——$s_1 = s_0 + 1$ 是基础；若 $s_{t-1} = s_0 + ((t-1) \bmod 2)$，则 $s_t = s_{t-1} + (-1)^{t+1}$……具体地，$t$ 为偶数时前一步 $s_{t-1} = s_0 + 1$ 且差分为 $-1$，得 $s_t = s_0$；$t$ 为奇数时 $s_{t-1} = s_0$ 且差分为 $+1$，得 $s_t = s_0 + 1$。归纳成立。**充分性**：若各位置均满足 $nums[k] = nums[i] + ((k-i) \bmod 2)$，则相邻差分交替为 $+1, -1, +1, \dots$ 且首差分 $nums[i+1] - nums[i] = +1$，逐项验证即得。∎

**定理**：枚举所有起点 $i$ 并延伸至最远，取长度最大值即为答案（不存在时为 $-1$）。

**证明**：设最优交替子数组为 $nums[i^*..j^*]$。算法枚举到 $i = i^*$ 时，由引理，$[i^*, j^*]$ 内每个位置都满足期望值条件，故延伸不会在 $j^*$ 之前停止，得到长度 $\ge j^* - i^* + 1 \ge 2$；任何起点延伸出的长度若为 $len$，则由引理的充分性，$nums[i..i+len-1]$ 确为交替子数组，算法不会高估。所有 $len \ge 2$ 的候选中最大者即全局最长；若所有起点延伸长度均 $< 2$（即无合法首步），`ans` 保持 $-1$。∎

## 6. 复杂度分析

- **时间**：$O(n^2)$ 最坏。每个起点至多延伸 $n$ 步（如 $[1,2,1,2,\dots]$ 全合法），$n \le 100$ 时约 $10^4$ 次比较；摊还版（见 §4 第 6 点）为 $O(n)$。
- **空间**：$O(1)$。只有常数个下标与答案变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int alternatingSubarray(vector<int>& nums) {
        int n = nums.size(), ans = -1;
        for (int i = 0; i + 1 < n; ++i) {
            if (nums[i + 1] != nums[i] + 1) continue;        // 首步必须 +1
            int j = i + 2;
            while (j < n && nums[j] == nums[i] + ((j - i) % 2)) ++j;  // 期望 v, v+1 交替
            ans = max(ans, j - i);
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def alternatingSubarray(self, nums: list[int]) -> int:
        n, ans = len(nums), -1
        for i in range(n - 1):
            if nums[i + 1] != nums[i] + 1:                  # 首步必须 +1
                continue
            j = i + 2
            while j < n and nums[j] == nums[i] + (j - i) % 2:
                j += 1
            ans = max(ans, j - i)
        return ans
```

> 💡 两份代码均通过官方示例（`4`、`2`）与无解边界（`[7,7,7] → -1`），并与「枚举全部子数组逐位检查」的 $O(n^3)$ 暴力对拍：C++ 侧 30000 组、Python 侧 2000 组随机数据（值域压缩到 $[1,6]$ 制造密集的伪模式），`mismatch = 0`。

## 8. 边界情况与易错点

1. **返回 $-1$ 的语义**：不存在**长度 $\ge 2$** 的交替子数组时返回 $-1$；别把答案初值设为 0 或 1。
2. **模式必须 $+1$ 开头**：$[v+1, v, v+1, v]$ 这种「先减后增」的锯齿**不合法**——$s_1 = s_0 + 1$ 是硬性条件。这是本题与「湍流子数组」（任意大小关系交替）的本质区别。
3. **期望值随起点变化**：$[2,3,4]$ 中 $[3,4]$ 合法而 $[2,3,4]$ 不合法（第 3 位期望 $2$ 实际 $4$），延伸判定必须用「以当前起点的基准值」计算。
4. **首步条件的位置**：判 `nums[i+1] != nums[i]+1` 时 $i$ 的上界是 $n-2$（保证 $i+1$ 合法），`for` 条件写成 `i + 1 < n`。
5. **重复元素**：相邻相等（如 $[7,7]$）首步即失败，注意别让 `+1` 写成 `+0` 或 `abs`。

**延伸思考**：把本题做快的 $O(n)$ 版本有个漂亮的引理：若从起点 $i$ 出发的模式在位置 $j$ 失败，则任何起点 $t \in (i, j)$ 的模式要么更早失败，要么在 $j$ 处的期望值与从 $i$ 出发完全相同（同样失败）。理由是在 $[i, j)$ 内合法的模式把该段钉死成「某两个相邻值的抖动」，起点的选择只决定抖动的相位，不改变 $j$ 处的期望值。因此失败后下一个值得尝试的起点只有 $j-1$（当 $nums[j] = nums[j-1]+1$）或 $j$，指针总跳跃前进，总代价 $O(n)$。若把模式推广成「差分 $\pm k$ 交替」或「周期为 $p$ 的循环模式」，同样的「期望值函数 + 起点跳跃」分析依然适用。
