# LeetCode 给小朋友们分糖果 I 题解

## 1. 题目概述

- **标题 / 题号**：给小朋友们分糖果 I（#2928，easy）
- **链接**：https://leetcode.cn/problems/distribute-candies-among-children-i/
- **来源**：LeetCode 第 117 场双周赛 Q1
- **难度**：简单
- **标签**：数学、组合数学、枚举

**题意**：给定正整数 $n$ 和 $limit$，把 $n$ 颗**完全相同**的糖果分给 $3$ 位小朋友，要求每位小朋友分到的糖果数都不超过 $limit$，返回总方案数。两种方案不同当且仅当某位小朋友拿到的糖果数不同（小朋友可区分，糖果不可区分）。

**约束**：

- $1 \le n \le 50$
- $1 \le limit \le 50$

## 2. 示例

**示例 1**

```text
输入：n = 5, limit = 2
输出：3
解释：满足条件的分配只有 (1,2,2)、(2,1,2)、(2,2,1)。
```

**示例 2**

```text
输入：n = 3, limit = 3
输出：10
解释：(0,0,3),(0,1,2),(0,2,1),(0,3,0),(1,0,2),(1,1,1),(1,2,0),(2,0,1),(2,1,0),(3,0,0) 共 10 种。
```

**示例 3（边界补充）**

```text
输入：n = 50, limit = 1
输出：0
解释：3 个人每人至多 1 颗，总共至多 3 颗 < 50，无法分完，方案数为 0。
```

## 3. 解题思路

### 3.1 暴力思路

数据范围极小（$n, limit \le 50$），最直接的做法是**三重循环枚举**前两个人的糖果数 $a, b$，第三个人拿 $c = n - a - b$，检查 $0 \le a, b, c \le limit$ 即可，$O(n^2)$。这也是本题官方提示给出的做法（`Use three nested for loops`），完全够用。但既然 Q2 会把 $n$ 放大到 $10^6$，不妨在 Q1 就把 $O(1)$ 的组合公式练熟，两题共用一份代码。

### 3.2 核心观察：容斥原理去掉上界约束

![核心观察：容斥原理去掉上界约束](images/bw117_q1_inclusion_exclusion.svg)

没有上界限制时，「$a + b + c = n$（$a,b,c \ge 0$）」的解数由**隔板法**直接给出：把 $n$ 颗糖果排成一行，插 $2$ 块隔板分成 $3$ 段，方案数为

$$\binom{n+2}{2}$$

现在要求每人 $\le limit$。设事件 $A_k$ =「第 $k$ 个人拿超过 $limit$ 颗（即 $\ge limit+1$ 颗）」。所求为

$$\binom{n+2}{2} - |A_1 \cup A_2 \cup A_3|$$

对**三个事件的并**用容斥：

$$|A_1 \cup A_2 \cup A_3| = \sum_k |A_k| - \sum_{k<l} |A_k \cap A_l| + |A_1 \cap A_2 \cap A_3|$$

由对称性，$|A_1| = |A_2| = |A_3|$，两两交、三交同理，只需各算一次：

- **单个事件** $|A_1|$：先给第 1 个人预发 $limit+1$ 颗，剩下 $n - (limit+1)$ 颗任意分（隔板法），即 $\binom{n - limit + 1}{2}$；
- **两个事件** $|A_1 \cap A_2|$：各预发 $limit+1$ 颗，剩下 $n - 2(limit+1)$ 颗任意分，即 $\binom{n - 2\mathit{limit}}{2}$；
- **三个事件** $|A_1 \cap A_2 \cap A_3|$：各预发 $limit+1$ 颗，剩下 $n - 3(limit+1)$ 颗，即 $\binom{n - 3\mathit{limit} - 1}{2}$。

> ⚠️ 上面公式里的 $n - 2\mathit{limit}$ 是 $n - 2(\mathit{limit}+1) + 2$ 的化简结果，与「先发后插板」的标准化简一致；推导详见 §4。

于是答案为一条 $O(1)$ 公式：

$$\mathrm{ans} = \binom{n+2}{2} - 3\binom{n-\mathit{limit}+1}{2} + 3\binom{n-2\mathit{limit}}{2} - \binom{n-3\mathit{limit}-1}{2}$$

其中约定 $\binom{v}{2} = 0$（当 $v < 2$）。**组合数取负下标时一律记 0**，正好对应「预发糖果不够发、事件不可能发生」的情形。

### 3.3 算法流程

![算法流程：一条公式与四个取值](images/bw117_q1_formula_terms.svg)

```text
1. 定义 C2(v) = v < 2 ? 0 : v*(v-1)/2
2. ans = C2(n+2) - 3*C2(n-limit+1) + 3*C2(n-2*limit) - C2(n-3*limit-1)
3. 返回 ans
```

### 3.4 示例演算

以 $n = 5,\ limit = 2$ 为例：

| 项 | 表达式 | 值 |
|----|--------|-----|
| 总方案（无上界） | $\binom{7}{2}$ | $21$ |
| 某人超限（×3） | $3\binom{4}{2}$ | $3 \times 6 = 18$ |
| 两人超限（×3） | $3\binom{1}{2}$ | $0$ |
| 三人超限 | $\binom{-2}{2}$ | $0$ |

$$\mathrm{ans} = 21 - 18 + 0 - 0 = 3$$

与示例一致。再验 $n = 3,\ limit = 3$：$\binom{5}{2} - 3\binom{1}{2} = 10 - 0 = 10$ ✓（每人上限 3、总数 3，超限不可能发生）。

## 4. 算法细节

1. **隔板法**：$x_1 + \cdots + x_k = n$（$x_i \ge 0$）的非负整数解数为 $\binom{n + k - 1}{k - 1}$。本题 $k = 3$，即 $\binom{n+2}{2}$。
2. **「预发」变换（多退少补）**：事件「$x_1 \ge limit+1$」做变量代换 $x_1' = x_1 - (limit+1) \ge 0$，方程变为 $x_1' + x_2 + x_3 = n - limit - 1$，解数 $\binom{n - limit + 1}{2}$。两人同时超限时代换两次，得 $\binom{n - 2\mathit{limit}}{2}$（因为 $n - 2(limit+1) + 2 = n - 2\mathit{limit}$）；三人同时超限得 $\binom{n - 3\mathit{limit} - 1}{2}$。
3. **负值截断**：当 $n$ 小于预发总量时，剩余糖果数为负，对应的 $\binom{v}{2}$ 按 $v < 2$ 记 0。这个约定不能省——它保证了公式在「上界约束根本不会触发」时自动退化成 $\binom{n+2}{2}$。
4. **整数类型**：本题 $n \le 50$，`int` 足够；但同一份代码要搬到 Q2（$n \le 10^6$，$\binom{n+2}{2} \approx 5 \times 10^{11}$），所以用 `long long` 更稳，一次写对。
5. **为什么三个事件容斥系数是 $1, 3, 3, 1$**：$\sum|A_k|$ 有 3 个对称单项、$\sum|A_k \cap A_l|$ 有 $\binom{3}{2} = 3$ 个、三交有 1 个，正好是容斥的二项式系数。

## 5. 正确性证明

**引理 1（隔板法）**：方程 $x_1 + x_2 + x_3 = n$（$x_i \ge 0$）的非负整数解数为 $\binom{n+2}{2}$。

**证明**：把 $n$ 个相同小球排成一行，在其中与末尾共 $n + 2$ 个空隙里选 2 个位置插入隔板，隔板把球序列切成 3 段，第 $i$ 段长度即 $x_i$。每个解与「$n$ 球 + 2 板」的排列一一对应，而球彼此相同、板彼此相同，排列数即从 $n + 2$ 个位置中选 2 个放板，为 $\binom{n+2}{2}$。∎

**引理 2（超限事件的计数）**：设 $t \ge 0$，事件「$x_1 \ge t$」的解数为 $\binom{n - t + 2}{2}$（当 $n \ge t$），否则为 $0$。

**证明**：令 $x_1' = x_1 - t \ge 0$，方程等价于 $x_1' + x_2 + x_3 = n - t$（$x_i' , x_2, x_3 \ge 0$）。由引理 1，解数为 $\binom{n - t + 2}{2}$；当 $n < t$ 时无解，且此时 $n - t + 2 < 2$，与截断约定 $\binom{v}{2} = 0\ (v < 2)$ 完全一致。∎

**定理**：$\mathrm{ans} = \binom{n+2}{2} - 3\binom{n-\mathit{limit}+1}{2} + 3\binom{n-2\mathit{limit}}{2} - \binom{n-3\mathit{limit}-1}{2}$ 给出「每人 $\le limit$」的分配方案数。

**证明**：所计数的是全集 $U = \{x_1+x_2+x_3 = n,\ x_i \ge 0\}$ 中不落入任何 $A_k$（$A_k$ = 第 $k$ 人 $> limit$）的元素数，即 $|U \setminus (A_1 \cup A_2 \cup A_3)|$。由三集合容斥，

$$|U| - |A_1 \cup A_2 \cup A_3| = |U| - \sum_k |A_k| + \sum_{k<l} |A_k \cap A_l| - |A_1 \cap A_2 \cap A_3|.$$

由对称性与引理 2（取 $t = limit + 1$）：$|A_k| = \binom{n-\mathit{limit}+1}{2}$；$|A_k \cap A_l|$ 对两个变量同时代换 $t$，得 $\binom{n - 2\mathit{limit}}{2}$；三交为 $\binom{n - 3\mathit{limit} - 1}{2}$。代入即得公式。截断约定保证所有项在剩余量为负时自动为 0，公式对一切 $n, limit \ge 1$ 成立。∎

## 6. 复杂度分析

- **时间**：$O(1)$。四个组合数各常数次乘除。
- **空间**：$O(1)$。若采用三重循环暴力则为 $O(n^2)$ 时间，在 $n \le 50$ 下同样通过，但无法迁移到 Q2。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int distributeCandies(int n, int limit) {
        // 容斥：无上界方案 - 3*单人超限 + 3*双人超限 - 三人超限
        auto C2 = [](long long v) -> long long {   // C(v,2)，v<2 视为 0
            return v < 2 ? 0 : v * (v - 1) / 2;
        };
        long long ans = C2(n + 2)
                      - 3 * C2(n - limit + 1)
                      + 3 * C2(n - 2 * limit)
                      - C2(n - 3 * limit - 1);
        return (int)ans;
    }
};
```

### Python

```python
class Solution:
    def distributeCandies(self, n: int, limit: int) -> int:
        def C2(v: int) -> int:          # C(v,2)，v<2 视为 0
            return v * (v - 1) // 2 if v >= 2 else 0
        return (C2(n + 2) - 3 * C2(n - limit + 1)
                + 3 * C2(n - 2 * limit) - C2(n - 3 * limit - 1))
```

> 💡 两份代码均通过官方示例（`3`、`10`）以及 20 万组随机数据与三重循环暴力的对拍（`mismatch = 0`）；同一公式直接适用于 Q2（#2929）的 $n \le 10^6$ 规模。

## 8. 边界情况与易错点

1. **$n > 3 \times limit$ 时答案为 0**：糖果太多根本分不出去。公式自动给出 0（四个组合数相消），无需特判。
2. **负下标组合数必须截断为 0**：如 $n = 3, limit = 3$ 时 $n - 2\mathit{limit} = -3$，若不截断会算出奇怪的负值项。
3. **「超过 limit」是 $\ge limit + 1$**：预发时发 $limit + 1$ 颗而不是 $limit$ 颗，符号错一位结果是系统性偏差。
4. **糖果相同、小朋友不同**：$(1,2,2)$ 与 $(2,1,2)$ 是不同方案；不要误用 $\binom{n + 2}{2}$ 之外的无序计数。
5. **中间乘法溢出**：`3 * C2(...)` 在 $n = 10^6$ 时约 $1.5 \times 10^{12}$，必须用 64 位整数（Q1 范围虽小，养成习惯）。
