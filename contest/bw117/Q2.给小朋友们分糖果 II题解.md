# LeetCode 给小朋友们分糖果 II 题解

## 1. 题目概述

- **标题 / 题号**：给小朋友们分糖果 II（#2929，medium）
- **链接**：https://leetcode.cn/problems/distribute-candies-among-children-ii/
- **来源**：LeetCode 第 117 场双周赛 Q2
- **难度**：中等
- **标签**：数学、组合数学、枚举

**题意**：与 Q1（#2928）完全同模型，只是数据范围放大：给定正整数 $n$ 和 $limit$，把 $n$ 颗相同糖果分给 $3$ 位小朋友，每位不超过 $limit$ 颗，返回总方案数。

**约束**：

- $1 \le n \le 10^6$
- $1 \le \mathit{limit} \le 10^6$

## 2. 示例

**示例 1**

```text
输入：n = 5, limit = 2
输出：3
解释：满足条件的分配只有 (1,2,2)、(2,1,2)、(2,2,1)。
```

**示例 2**

```text
输入：n = 3, limit = 3
输出：10
解释：(0,0,3),(0,1,2),(0,2,1),(0,3,0),(1,0,2),(1,1,1),(1,2,0),(2,0,1),(2,1,0),(3,0,0) 共 10 种。
```

**示例 3（边界补充）**

```text
输入：n = 1000000, limit = 1000000
输出：500001500001
解释：上界约束完全不触发（n ≤ limit），答案退化为隔板法 C(n+2,2)。
```

## 3. 解题思路

### 3.1 暴力思路

Q1 的三重循环枚举在此失效：$n = 10^6$ 时 $O(n^2)$ 约 $10^{12}$ 次操作。即使只枚举一个人 $a \in [0, \min(n, limit)]$、对每个 $a$ 用区间长度 $O(1)$ 算第二个人的合法范围（官方提示的做法），也是 $O(n)$——能过，但 $n = 10^6$ 时已接近 $10^6$ 次循环，Python 下要小心。真正优雅的做法是把 Q1 的容斥公式原封不动搬过来：**三个对称事件的容斥，答案是一条 $O(1)$ 闭式**。

### 3.2 核心观察：对称事件的容斥闭式

![核心观察：容斥四项的对称结构](images/bw117_q2_inclusion_terms.svg)

设全集 $U$ 为 $x_1 + x_2 + x_3 = n$（$x_i \ge 0$）的全部非负整数解，$A_k$ 为「$x_k \ge \mathit{limit} + 1$」。所求为 $|U \setminus (A_1 \cup A_2 \cup A_3)|$。三集合容斥展开后，由对称性只余四种单项：

$$\mathrm{ans} = \underbrace{\binom{n+2}{2}}_{|U|} - \underbrace{3\binom{n-\mathit{limit}+1}{2}}_{\text{单人超限}} + \underbrace{3\binom{n-2\mathit{limit}}{2}}_{\text{双人超限}} - \underbrace{\binom{n-3\mathit{limit}-1}{2}}_{\text{三人超限}}$$

推导链条（每一步都是「先预发 $\mathit{limit}+1$ 颗，再隔板」）：

- $|U| = \binom{n+2}{2}$（隔板法）；
- $|A_k|$：$x_k$ 预发 $t = \mathit{limit}+1$ 颗后剩余 $n - t$ 任意分，$\binom{n-t+2}{2} = \binom{n-\mathit{limit}+1}{2}$；
- $|A_k \cap A_l|$：两人各预发 $t$，剩余 $n - 2t$，$\binom{n-2t+2}{2} = \binom{n-2\mathit{limit}}{2}$；
- $|A_1 \cap A_2 \cap A_3|$：三人各预发 $t$，剩余 $n - 3t$，$\binom{n-3t+2}{2} = \binom{n-3\mathit{limit}-1}{2}$。

所有 $\binom{v}{2}$ 在 $v < 2$ 时记 $0$。**注意 $n \le 3 \times \mathit{limit}$ 不一定无解**（恰好等于仍有 1 种），而 $n > 3\mathit{limit}$ 时公式自动给出 $0$。

### 3.3 算法流程

![算法流程：公式计算与截断约定](images/bw117_q2_algorithm_flow.svg)

```text
1. C2(v) = (v < 2) ? 0 : v*(v-1)/2      # 负值/小值自动截断为 0
2. ans = C2(n+2) - 3*C2(n-limit+1) + 3*C2(n-2*limit) - C2(n-3*limit-1)
3. 返回 ans（long long / Python int 均天然不溢出）
```

### 3.4 示例演算

以 $n = 10^6,\ \mathit{limit} = 10^6$ 验证「退化情形」：

| 项 | 表达式 | 值 |
|----|--------|-----|
| $|U|$ | $\binom{10^6+2}{2}$ | $500001500001$ |
| 单人超限 | $n - \mathit{limit} + 1 = 1 < 2$ | $0$ |
| 双人 / 三人超限 | 更小 | $0$ |

$$\mathrm{ans} = 500001500001 - 0 + 0 - 0 = 500001500001$$

与实测一致。再验 $n = 5,\ \mathit{limit} = 2$：$\binom{7}{2} - 3\binom{4}{2} = 21 - 18 = 3$ ✓。

## 4. 算法细节

1. **预发变换的代数核对**：$\binom{n - kt + 2}{2}$ 中 $t = \mathit{limit}+1$。$k=1$：$n - \mathit{limit} - 1 + 2 = n - \mathit{limit} + 1$；$k=2$：$n - 2\mathit{limit} - 2 + 2 = n - 2\mathit{limit}$；$k=3$：$n - 3\mathit{limit} - 3 + 2 = n - 3\mathit{limit} - 1$。四个下标逐一对上，写代码时**照抄这四个下标**即可，不必现场再推。
2. **截断函数是正确性的一部分**：$C2(v) = 0\ (v < 2)$ 处理了「预发超总额、事件不可能」的全部情形，不需要任何 `if` 特判。
3. **溢出**：$n = 10^6$ 时 $\binom{n+2}{2} \approx 5 \times 10^{11}$，乘 $3$ 后约 $1.5 \times 10^{12}$，超出 32 位 `int`（约 $2.1 \times 10^9$）三个数量级，C++ 必须 `long long`。返回类型恰好是 `long`（LeetCode 的 `long` 即 64 位）。
4. **另一种 $O(n)$ 思路（对拍用）**：枚举 $a \in [0, \min(n, \mathit{limit})]$，对每个 $a$ 第二人合法个数是 $\max(0, \min(\mathit{limit}, n-a) - \max(0, n-a-\mathit{limit}) + 1)$，求和即答案。它与闭式互为独立的验证手段。
5. **为什么不能直接 $\binom{n+2}{2}$ 减 $\binom{n-\mathit{limit}}{2}$ 之类**：单人超限的事件互相重叠（两人可以同时超限），漏掉交叉项会多数/少数。容斥的 $+3\binom{n-2\mathit{limit}}{2} - \binom{n-3\mathit{limit}-1}{2}$ 正是把重叠部分加回、再扣掉多加的。

## 5. 正确性证明

**引理 1（隔板法）**：$x_1 + x_2 + x_3 = n$（$x_i \ge 0$）的非负整数解数为 $\binom{n+2}{2}$。

**证明**：将 $n$ 个相同球与 $2$ 个相同隔板混合排列，隔板切出的 3 段长度对应 $(x_1, x_2, x_3)$，排列数即从 $n + 2$ 个位置选 2 个放隔板。∎

**引理 2（预发变换）**：对固定 $t \ge 1$ 与下标集合 $S \subseteq \{1,2,3\}$，事件 $B_S = \bigcap_{k \in S}\{x_k \ge t\}$ 的解数为 $\binom{n - |S| \cdot t + 2}{2}$（若 $n \ge |S| \cdot t$），否则 $0$；该值恰为截断约定下的 $\binom{n - |S|t + 2}{2}$。

**证明**：对每个 $k \in S$ 令 $x_k' = x_k - t \ge 0$，方程化为 $x' + x_{\bar S} = n - |S|t$ 的非负解计数，由引理 1 即 $\binom{n - |S|t + 2}{2}$。当 $n < |S|t$ 时剩余为负、无解，而 $n - |S|t + 2 < 2$，截断约定同样给出 $0$。∎

**定理**：记 $t = \mathit{limit} + 1$，则

$$\mathrm{ans} = \sum_{s=0}^{3} (-1)^s \binom{3}{s}\binom{n - s\,t + 2}{2}$$

（即 $|U| - 3|A_1| + 3|A_1 \cap A_2| - |A_1 \cap A_2 \cap A_3|$ 的展开）给出每人 $\le \mathit{limit}$ 的方案数。

**证明**：目标集合为 $U \setminus \bigcup_k A_k$，其中 $A_k = \{x_k \ge t\}$。由容斥原理，

$$\left| U \setminus \bigcup_{k=1}^{3} A_k \right| = \sum_{S \subseteq \{1,2,3\}} (-1)^{|S|} |B_S|,$$

按 $|S| = s$ 分组，同组内各 $B_S$ 大小相同（变量对称），组贡献为 $(-1)^s \binom{3}{s}|B_{\{1,\dots,s\}}|$。代入引理 2（$|B_S| = \binom{n - st + 2}{2}$）即得公式；截断约定覆盖 $n < st$ 的所有情形，故对一切 $n, \mathit{limit} \ge 1$ 成立。∎

## 6. 复杂度分析

- **时间**：$O(1)$。四次组合数计算。
- **空间**：$O(1)$。对比 $O(n)$ 枚举法：在 $n = 10^6$ 时二者都能通过，但闭式对任意 $n$（哪怕 $10^{18}$，换 `__int128` 或 Python 大整数）仍然成立，是真正的「数论级」解法。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long distributeCandies(int n, int limit) {
        // 容斥闭式：C(n+2,2) - 3*C(n-limit+1,2) + 3*C(n-2*limit,2) - C(n-3*limit-1,2)
        auto C2 = [](long long v) -> long long {    // C(v,2)，v<2 视为 0
            return v < 2 ? 0 : v * (v - 1) / 2;
        };
        return C2(n + 2)
             - 3 * C2(n - (long long)limit + 1)
             + 3 * C2(n - 2LL * limit)
             - C2(n - 3LL * limit - 1);
    }
};
```

### Python

```python
class Solution:
    def distributeCandies(self, n: int, limit: int) -> int:
        def C2(v: int) -> int:          # C(v,2)，v<2 视为 0
            return v * (v - 1) // 2 if v >= 2 else 0
        return (C2(n + 2) - 3 * C2(n - limit + 1)
                + 3 * C2(n - 2 * limit) - C2(n - 3 * limit - 1))
```

> 💡 两份代码均通过官方示例（`3`、`10`）、边界 $n = 10^6 = \mathit{limit}$（`500001500001`），以及 20 万组随机数据与三重循环暴力的对拍（`mismatch = 0`）。C++ 大规模单次调用 0ms。

## 8. 边界情况与易错点

1. **`int` 溢出是本题最大坑**：$\binom{n+2}{2}$ 在 $n = 10^6$ 时约 $5 \times 10^{11}$，32 位整型直接爆。C++ 中间量全部 `long long`，包括 `2LL * limit` 这种字面量提升。
2. **$n > 3\mathit{limit}$**：答案为 0，公式自动成立（四项相消），无需特判。例如 $n = 50, \mathit{limit} = 1$。
3. **$n \le \mathit{limit}$**：上界完全不触发，答案即 $\binom{n+2}{2}$，公式自动退化。
4. **函数签名**：本题返回 `long`（64 位），与 Q1 的 `int` 不同；抄 Q1 代码时记得改返回类型，否则强转截断。
5. **截断 vs 取绝对值**：$v < 2$ 必须返回 0 而不是「取模为正」之类的花活——这里的负值代表「事件不可能」，语义就是 0。
6. **别把 $t$ 写成 $\mathit{limit}$**：超限是「严格大于 $\mathit{limit}$」，预发 $t = \mathit{limit} + 1$ 颗。错一位会导致例如 $n = \mathit{limit} \cdot 3$ 时错误地多减。
