# LeetCode 和为奇数的子数组数目 题解

## 1. 题目概述

- **标题 / 题号**：和为奇数的子数组数目（#1524，medium）
- **链接**：https://leetcode.cn/problems/number-of-sub-arrays-with-odd-sum/
- **来源**：LeetCode 第 31 场双周赛 Q2
- **难度**：中等
- **标签**：数组、数学、动态规划、前缀和

**题意**：给定整数数组 $\textit{arr}$，统计**和为奇数**的子数组（连续区间）数目。答案可能很大，对 $10^9 + 7$ 取模后返回。

**约束**：

- $1 \le \textit{arr.length} \le 10^5$
- $1 \le \textit{arr}[i] \le 100$

## 2. 示例

**示例 1**

```text
输入：arr = [1, 3, 5]
输出：4
解释：所有子数组的和为 [1, 4, 9, 3, 8, 5]，其中奇数和为 [1, 9, 3, 5]，共 4 个。
```

**示例 2**

```text
输入：arr = [2, 4, 6]
输出：0
解释：全为偶数，任何子数组之和都是偶数。
```

**示例 3**

```text
输入：arr = [1, 2, 3, 4, 5, 6, 7]
输出：16
```

**示例 4（边界补充）**

```text
输入：arr = [7]
输出：1
解释：唯一子数组 [7] 的和就是奇数。
```

## 3. 解题思路

### 3.1 暴力思路

枚举全部 $O(n^2)$ 个子数组 $(l, r]$，对每个子数组求和判奇偶，总时间 $O(n^3)$；若用固定左端点向右累加的增量法，可降到 $O(n^2)$。但 $n = 10^5$ 时 $O(n^2) = 10^{10}$ 次操作仍然不可行，必须把「求和判奇偶」这一步压缩成 $O(1)$ 的**奇偶判断**。

### 3.2 核心观察：前缀和的奇偶配对

![前缀奇偶配对](images/bw31_q2_prefix_parity_pairs.svg)

记前缀和 $S_i = \textit{arr}[0] + \dots + \textit{arr}[i-1]$（$S_0 = 0$）。子数组 $\textit{arr}[l..r]$ 的和等于 $S_{r+1} - S_l$，而**差的奇偶只取决于两项奇偶是否不同**：

$$S_{r+1} - S_l \equiv 1 \pmod 2 \iff S_{r+1} \not\equiv S_l \pmod 2.$$

于是一次线性扫描即可：扫到右端点 $r$ 时，维护**此前出现过的奇前缀个数 $\textit{odd}$ 与偶前缀个数 $\textit{even}$**（空前缀 $S_0 = 0$ 初始计入 $\textit{even} = 1$）：

- 当前前缀和为奇：与此前每个**偶**前缀配对成奇和子数组，$\textit{ans} \mathrel{+}= \textit{even}$；
- 当前前缀和为偶：与此前每个**奇**前缀配对，$\textit{ans} \mathrel{+}= \textit{odd}$。

这等价于一个 $O(1)$ 转移的 DP：设 $f(i)$ 为**以 $i$ 结尾**的和为奇的子数组个数，则 $f(i) = \textit{even}$（当前前缀奇）或 $\textit{odd}$（当前前缀偶），答案为 $\sum f(i)$；而 $\textit{odd}/\textit{even}$ 的增量更新正是 DP 的滚动状态。

### 3.3 算法流程

![逐位累加流程与演算](images/bw31_q2_dp_flow_table.svg)

```text
1. odd = 0, even = 1（空前缀和 0 计入偶），ans = 0, pre = 0
2. 对每个 x = arr[i]：
       pre += x
       若 pre 为奇：ans += even；odd  += 1
       若 pre 为偶：ans += odd ；even += 1
       （ans 全程对 1e9+7 取模）
3. 返回 ans
```

### 3.4 示例演算

以 $\textit{arr} = [1, 3, 5]$ 为例（见上图右下表格）：

| $i$ | $\textit{arr}[i]$ | 前缀和 $\textit{pre}$ | 奇偶 | 累加 | $\textit{ans}$ | $\textit{odd}$ / $\textit{even}$ |
|-----|-----|-----|-----|-----|-----|-----|
| — | — | $0$ | 偶 | — | $0$ | $0$ / $1$ |
| $0$ | $1$ | $1$ | 奇 | $+1$（配空前缀） | $1$ | $1$ / $1$ |
| $1$ | $3$ | $4$ | 偶 | $+1$（配 $S_1=1$） | $2$ | $1$ / $2$ |
| $2$ | $5$ | $9$ | 奇 | $+2$（配 $S_0, S_2$） | $4$ | $2$ / $2$ |

最终 $\textit{ans} = 4$，对应奇和子数组 $[1], [1,3,5], [3], [5]$，与官方示例一致。

## 4. 算法细节

1. **空前缀必须计入 $\textit{even}$**：子数组可以从下标 0 开始（即 $l = 0$，$S_l = S_0 = 0$），漏掉初始 $\textit{even} = 1$ 会少算所有「从头部开始的奇和子数组」。
2. **只关心奇偶，不关心数值**：前缀和最大 $10^5 \times 100 = 10^7$，`int` 足够；但取模后的 $\textit{ans}$ 与计数都不受影响，因为奇偶性由 $\textit{pre} \bmod 2$ 决定，**取模前判断奇偶即可**，无需对 $\textit{pre}$ 取模（对 $2$ 取模与对 $10^9+7$ 取模互不干扰）。
3. **DP 视角的转移方程**：设 $f(i)$、$g(i)$ 分别为**以 $i$ 结尾**的和为奇 / 偶的子数组个数，记 $\textit{pre}_i = S_{i+1} \bmod 2$（含 $\textit{arr}[i]$ 的前缀和奇偶），则
   $$f(i) = \begin{cases} g(i-1) + 1, & \textit{pre}_i = 1 \\ 0, & \textit{pre}_i = 0 \end{cases},\qquad g(i) = \begin{cases} f(i-1) + 1, & \textit{pre}_i = 0 \\ 0, & \textit{pre}_i = 1 \end{cases}$$
   （$+1$ 项对应「子数组恰从 $i$ 开始」，即与前缀 $S_i$ 配对）。滚动后：$g(i-1)+1 = \textit{even}$（当前前缀为奇时），$f(i-1)+1 = \textit{odd}$（当前前缀为偶时），恰与「计数器」写法一致——两个视角互相印证。
4. **取模时机**：`ans += ...` 之后立即 `% MOD`，`odd/even` 计数最大 $10^5 + 1$ 不取模也不溢出；C++ 中 `ans` 用 `long long` 防止中间加法越界更稳。
5. **为什么不能只数奇数元素**：奇和子数组未必含奇数个奇元素——不对，恰相反，**和为奇 ⟺ 子数组内奇数元素个数为奇**。这个「元素奇偶」视角同样可做：前缀「奇元素计数」的奇偶配对与前缀和奇偶配对完全同构（$S \bmod 2 = $ 奇元素个数 $\bmod 2$），两种推导殊途同归。

## 5. 正确性证明

**引理 1（奇偶判别）**：子数组 $\textit{arr}[l..r]$ 的和为奇数，当且仅当前缀和 $S_l$ 与 $S_{r+1}$ 奇偶性不同。

**证明**：和 $= S_{r+1} - S_l$。若 $S_{r+1} \equiv S_l \pmod 2$，则差为偶；若奇偶不同，则差为奇。这正是模 2 意义下的减法：$S_{r+1} - S_l \equiv S_{r+1} + S_l \pmod 2$（因为 $-1 \equiv 1 \pmod 2$）。∎

**引理 2（计数完备）**：固定右端点 $r$，和为奇的子数组 $\textit{arr}[l..r]$ 的个数恰等于「下标 $\le r$ 且与 $S_{r+1}$ 奇偶不同的前缀和 $S_l$（$0 \le l \le r$）」的个数。

**证明**：映射 $l \mapsto S_l$ 在 $l \in [0, r]$ 上是双射到「扫描到 $r$ 为止出现过的所有前缀和」（每个下标对应唯一前缀和值），由引理 1，满足条件的 $l$ 与和为奇的子数组一一对应。∎

**定理**：算法返回值等于和为奇的子数组总数（模 $10^9+7$）。

**证明**：对 $r$ 归纳。扫描处理完 $\textit{arr}[0..r-1]$ 后，不变量为：$\textit{odd}$ = $\{S_l : 0 \le l \le r-1,\ S_l \text{ 为奇}\}$ 的基数，$\textit{even}$ = $\{S_l : 0 \le l \le r-1,\ S_l \text{ 为偶}\}$ 的基数（初始 $r=0$ 时仅 $S_0 = 0$，$\textit{even} = 1$ 成立），且 $\textit{ans} = \sum_{r' < r} f(r')$。处理 $\textit{arr}[r]$ 时算法先更新 $\textit{pre} = S_{r+1}$，按其奇偶把 $\textit{ans}$ 加上对面计数器——由引理 2，这个增量恰是 $f(r)$（以 $r$ 结尾的奇和子数组个数）；随后把 $S_{r+1}$ 计入对应计数器，不变量对 $r+1$ 成立。归纳完成，$\textit{ans} = \sum_{r=0}^{n-1} f(r)$ 恰为全部奇和子数组数。取模只作用于答案的累加，计数不取模，不影响正确性。∎

## 6. 复杂度分析

- **时间**：$O(n)$。每个元素一次加法、一次奇偶判断、一次累加取模。
- **空间**：$O(1)$。只维护 $\textit{pre}, \textit{odd}, \textit{even}, \textit{ans}$ 四个变量（若不用增量法而先算整个前缀和数组则为 $O(n)$，没必要）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int numOfSubarrays(vector<int>& arr) {
        const long long MOD = 1000000007LL;
        long long odd = 0, even = 1;   // 已出现的前缀和：奇数个 / 偶数个（空前缀和 0 计入 even）
        long long ans = 0, pre = 0;
        for (int x : arr) {
            pre += x;
            if (pre & 1LL) { ans = (ans + even) % MOD; odd++; }   // 奇前缀配偶前缀
            else           { ans = (ans + odd)  % MOD; even++; }  // 偶前缀配奇前缀
        }
        return (int)ans;
    }
};
```

### Python

```python
class Solution:
    def numOfSubarrays(self, arr: list[int]) -> int:
        MOD = 10**9 + 7
        odd, even = 0, 1          # 前缀和为奇 / 偶的个数，空前缀(和0)计入 even
        ans, pre = 0, 0
        for x in arr:
            pre += x
            if pre % 2:
                ans = (ans + even) % MOD
                odd += 1
            else:
                ans = (ans + odd) % MOD
                even += 1
        return ans
```

> 💡 两份代码均通过官方全部示例（`4`、`0`、`16`、`4`、`1`），并与 500 组随机数据（含 $n$ 最多 300 的全奇/全偶对抗样例）上的 $O(n^2)$ 增量暴力对拍，`mismatch = 0`。

## 8. 边界情况与易错点

1. **忘记初始 `even = 1`**：最常见的错法。空前缀 $S_0 = 0$ 是偶数，它对应「从下标 0 开始的所有子数组」；漏掉后 `[1,3,5]` 会输出 3 而不是 4。
2. **取模的位置**：只对 `ans` 取模；`odd/even` 是计数器（$\le n+1$）不必取模。反过来若对 `pre` 取模，注意要取 $10^9+7$ 的模之前先判奇偶，或直接对 `pre & 1` 判断——本题 `pre` 不取模最省心。
3. **`int` 溢出**：`ans` 每次累加前 $< \textit{MOD} \approx 10^9$，加上的计数 $\le n+1 \approx 10^5$，瞬时值 $< 1.1 \times 10^9 < \textit{INT\_MAX} \approx 2.1 \times 10^9$，`int` 理论上够用但贴边；C++ 用 `long long` 累加再转 `int` 返回最稳，Python 无此顾虑。
4. **全偶数组**：前缀和恒为偶，`ans` 恒加 `odd = 0`，自然返回 0，无需特判。
5. **「子数组」是连续的**：不要误算成子序列（子序列版本是另一道计数 DP，复杂度完全不同）。
