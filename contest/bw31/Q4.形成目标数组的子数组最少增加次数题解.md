# LeetCode 形成目标数组的子数组最少增加次数 题解

## 1. 题目概述

- **标题 / 题号**：形成目标数组的子数组最少增加次数（#1526，hard）
- **链接**：https://leetcode.cn/problems/minimum-number-of-increments-on-subarrays-to-form-a-target-array/
- **来源**：LeetCode 第 31 场双周赛 Q4
- **难度**：困难
- **标签**：栈、贪心、数组、动态规划、单调栈

**题意**：给定目标数组 $\textit{target}$（长度 $n$）与同长度的全零数组 $\textit{initial}$。一次操作可任选 $\textit{initial}$ 的一个**连续子数组**并将其中每个值加 1。返回把 $\textit{initial}$ 变成 $\textit{target}$ 的最少操作次数。答案保证在 32 位整数范围内。

**约束**：

- $1 \le n \le 10^5$
- $1 \le \textit{target}[i] \le 10^5$
- 输入保证答案在 32 位整数范围内

## 2. 示例

**示例 1**

```text
输入：target = [1, 2, 3, 2, 1]
输出：3
解释：[0,0,0,0,0] → 全段+1 → [1,1,1,1,1] → [1,2,2,2,1]（下标 1..3 加 1）
      → [1,2,3,2,1]（下标 2 加 1）。
```

**示例 2**

```text
输入：target = [3, 1, 1, 2]
输出：4
解释：全段+1 得 [1,1,1,1]，下标 0 加 2 次得 [3,1,1,1]，下标 3 加 1 次得 [3,1,1,2]。
```

**示例 3**

```text
输入：target = [3, 1, 5, 4, 2]
输出：7
```

**示例 4（边界补充）**

```text
输入：target = [1, 1, 1, 1]
输出：1
解释：全段加 1 一次即可。
```

## 3. 解题思路

### 3.1 暴力思路

把每次操作看作「选一个区间整体抬高一层」。暴力可对每个值从 0 逐层构造：找到当前全局最小值的极大连续平台，对每个平台做一次操作、平台内各值减 1，重复直到全 0——这是「按层剥皮」的模拟，最坏 $O(n \cdot \max)$（$10^5 \times 10^5 = 10^{10}$）超时。另一条暴力路是状态搜索（BFS），只对 $n \le 4$、值 $\le 3$ 的玩具规模可用。正确做法是找到操作次数的**不变量下界**并给出匹配的构造。

### 3.2 核心观察：答案 = 正台阶增量之和

![台阶贪心](images/bw31_q4_stairs_greedy.svg)

把 $\textit{target}$ 画成台阶轮廓，想象「每次操作铺一层连续的地板」：

- 第 $0$ 列必须从 0 抬到 $\textit{target}[0]$，这些层每一层都**必须**有一次操作覆盖下标 0；
- 从左往右看相邻两列 $i-1 \to i$：若 $\textit{target}[i] > \textit{target}[i-1]$，多出来的 $\textit{target}[i] - \textit{target}[i-1]$ 层是**新开的层**，每层至少一次操作；若 $\textit{target}[i] \le \textit{target}[i-1]$，则 $i$ 处需要的高度不超过左侧，左侧已铺的层可以「免费滑下来」盖住 $i$。

于是猜想：

$$\textit{ans} = \textit{target}[0] + \sum_{i=1}^{n-1} \max(0,\ \textit{target}[i] - \textit{target}[i-1]).$$

这就是**差分**视角：$\textit{diff}[i] = \textit{target}[i] - \textit{target}[i-1]$（约定 $\textit{target}[-1] = 0$），答案为所有**正差分之和**。等价地，答案 $= \sum_i \textit{diff}^+[i] = \frac{1}{2}\left(\textit{target}[0] + \textit{target}[n-1] + \sum_i |\textit{diff}[i]|\right)$（由差分和为 0 的恒等式推出，两种写法均可）。

### 3.3 算法流程

```text
1. ans = target[0]
2. 对 i = 1 .. n-1：
       ans += max(0, target[i] - target[i-1])
3. 返回 ans
```

（构造具体方案：把每个正差分 $\textit{diff}[i]$ 视为「从下标 $i$ 开始、向右延伸到其匹配负差分处结束」的层，可用单调栈求出每层的结束位置——但题目只要次数，无需输出方案。）

### 3.4 示例演算

![分层覆盖构造](images/bw31_q4_layer_decomposition.svg)

以 $\textit{target} = [3, 1, 5, 4, 2]$ 为例：

| $i$ | $\textit{target}[i]$ | $\textit{diff}[i]$ | $\max(0, \textit{diff})$ | 累计 |
|-----|-----|-----|-----|-----|
| 0 | 3 | $+3$ | 3 | 3 |
| 1 | 1 | $-2$ | 0 | 3 |
| 2 | 5 | $+4$ | 4 | 7 |
| 3 | 4 | $-1$ | 0 | 7 |
| 4 | 2 | $-2$ | 0 | 7 |

答案 $7$，与官方示例一致。上图的「分层地板」给出 7 次操作的具体构造：第 1 次铺 $[0,4]$ 的高 1 层，第 2、3 次铺 $[0,0]$ 的第 2、3 层，第 4 次铺 $[2,4]$ 的第 2 层，第 5、6 次铺 $[2,3]$ 的第 3、4 层，第 7 次铺 $[2,2]$ 的第 5 层。

## 4. 算法细节

1. **差分的意义**：$\max(0, \textit{target}[i] - \textit{target}[i-1])$ 数的是「以 $i$ 为**左端点**的新开层数」。正差分必开新层（左侧盖不到这么高），负差分只是让层提前结束，不花次数。
2. **不需要分段或特判**：把序列按「谷」切开逐段独立计算再相加是多余的——差分求和天然处理了所有边界，跨谷与不跨谷的层在公式中自动归位。
3. **单调栈备选**：若要输出操作方案，维护一个存下标的单调递增栈，遇到更矮的列时弹栈结算若干层的右端点；统计层面等价于正差分求和（弹栈时累加的高度差之和恰为正差分和）。
4. **数据规模与溢出**：$n \le 10^5$、$\textit{target}[i] \le 10^5$，理论上正差分之和最坏可达 $10^{10}$ 量级，但题目明确「输入保证答案在 32 位整数范围内」，实际数据下 `int` 足够；稳妥写法用 `long long` 累加再转 `int` 返回。
5. **一次遍历、无需额外数组**：只依赖相邻两个元素，$O(1)$ 空间。

## 5. 正确性证明

**引理 1（下界：逐点覆盖计数）**：任何合法操作序列中，覆盖下标 $i$ 的操作次数恰为 $\textit{target}[i]$（每覆盖一次加 1，最终要恰好达到目标）。因此对每个 $i \ge 1$，**新开于下标 $i$ 或更左、且覆盖 $i$** 的操作（即左端点 $\le i - 1 < $ 右端点的延续操作之外的、左端点恰为 $i$ 的操作）至少有 $\max(0, \textit{target}[i] - \textit{target}[i-1])$ 次。

**证明**：覆盖 $i-1$ 的操作次数为 $\textit{target}[i-1]$；覆盖 $i$ 的操作中，左端点 $< i$ 者**必定同时覆盖 $i-1$**（操作是连续区间，左端点 $\le i-1$ 且覆盖 $i$ ⟹ 覆盖 $[i-1, i]$ 整段），故此类操作至多 $\textit{target}[i-1]$ 个。于是左端点恰为 $i$（新开于 $i$）的操作数 $\ge \textit{target}[i] - \textit{target}[i-1]$，且自然非负，即 $\ge \max(0, \textit{target}[i] - \textit{target}[i-1])$。同理下标 0 处所有操作都是新开的，共 $\textit{target}[0]$ 次。各下标的新开操作互不相同（一个操作的左端点唯一），操作总数 $\ge \textit{target}[0] + \sum_{i \ge 1} \max(0, \textit{target}[i] - \textit{target}[i-1])$。∎

**引理 2（构造：贪心铺层达到下界）**：存在恰好 $M = \textit{target}[0] + \sum_{i \ge 1} \max(0, \textit{target}[i] - \textit{target}[i-1])$ 次操作的合法序列。

**证明**（构造）：对 $h = 1, 2, \dots, \max_i \textit{target}[i]$ 逐层铺地板。第 $h$ 层需要覆盖的位置集合是 $\{i : \textit{target}[i] \ge h\}$，它是若干个极大连续区间（高度 $\ge h$ 的位置可能被谷分开）；对每个极大区间做一次操作。这样每列 $i$ 恰被 $\textit{target}[i]$ 次操作覆盖，结果正确。下面数操作总次数：第 $h$ 层的极大区间数等于「$h$ 层的段数」，而一个段当且仅当其最左列 $i$ 满足 $\textit{target}[i] \ge h > \textit{target}[i-1]$（约定 $\textit{target}[-1] = 0$），即 $h \le \textit{target}[i] - \textit{target}[i-1]$ 且 $h \le \textit{target}[i]$。对每个 $i$，作为「某层最左列」被计数的次数恰为 $\max(0, \textit{target}[i] - \textit{target}[i-1])$（当 $\textit{target}[i] > \textit{target}[i-1]$ 时 $h \in (\textit{target}[i-1], \textit{target}[i]]$ 共 $\textit{target}[i]-\textit{target}[i-1]$ 个；否则 0 个，$i = 0$ 时即 $\textit{target}[0]$ 个）。逐层求和，总操作数 $= M$。∎

**定理**：最少操作次数为 $\textit{target}[0] + \sum_{i=1}^{n-1} \max(0, \textit{target}[i] - \textit{target}[i-1])$。

**证明**：引理 1 给出任何方案的操作数 $\ge M$（下界），引理 2 给出操作数恰为 $M$ 的可行方案（可达），两者夹逼即得最小值为 $M$。∎

**交换论证视角**（另一种下界论证）：任取最优方案，若某操作的左端点 $l$ 落在 $\textit{target}[l] \le \textit{target}[l-1]$ 处（即该处不需要新层），可把该操作左端点右移一位：右移后下标 $l-1$ 处覆盖次数减 1，若仍 $\ge \textit{target}[l-1]$ 则方案保持可行而次数不变；反复右移所有「冗余左端点」直至每个操作的左端点 $l$ 都满足 $\textit{target}[l] > \textit{target}[l-1]$（或 $l = 0$）。此时操作数恰为 $\sum_l \max(0, \textit{target}[l]-\textit{target}[l-1])$（每个合法左端点 $l$ 处的操作数被其高度需求 $\textit{target}[l] - \textit{target}[l-1]$ 封顶），说明任何最优值不超过该式——与引理 1 合并同样完成证明。∎

## 6. 复杂度分析

- **时间**：$O(n)$。一次线性扫描求正差分之和。
- **空间**：$O(1)$。只维护答案与前一个值（差分数组都无需显式存）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minNumberOperations(vector<int>& target) {
        int ans = target[0];                       // 第一个台阶从 0 抬上来
        for (size_t i = 1; i < target.size(); ++i)
            ans += max(0, target[i] - target[i - 1]);   // 只累加正增量
        return ans;
    }
};
```

### Python

```python
class Solution:
    def minNumberOperations(self, target: list[int]) -> int:
        ans = target[0]
        for i in range(1, len(target)):
            ans += max(0, target[i] - target[i-1])
        return ans
```

> 💡 两份代码均通过官方全部示例（`3`、`4`、`7`、`1`）及单元素边界。此外做了两层对拍：250 组小规模（$n \le 4$、值 $\le 3$）与 **BFS 状态空间搜索**的暴力最优解对比，405 组中大规模（$n \le 40$，含单调、山谷、平台、$10^5$ 值域极端）与独立的「谷底分层递归」实现对比，`mismatch = 0`。

## 8. 边界情况与易错点

1. **$n = 1$**：答案是 $\textit{target}[0]$，公式中求和项为空，天然正确；不要误把单元素特判成 1。
2. **全相同值**（如 $[1,1,1,1]$）：差分全 0，答案 $= \textit{target}[0] = 1$，对应「一次全段操作」。
3. **严格递增 / 严格递减**：递增时正差分逐项累加（裂项相消），答案 $= \textit{target}[n-1]$；递减时除首项外差分全负，答案 $= \textit{target}[0]$。可作公式自检。
4. **不要把负差分也累加**：$\max(0, \cdot)$ 不可省。若累加带符号差分，$[3,1,1,2]$ 会得到 $3-2+0+1=2$ 而非 4。
5. **答案上界**：最坏 $\textit{target}$ 形如锯齿且峰值 $10^5$ 时答案约 $5 \times 10^9$，超出 `int`——但题目明确「输入保证答案在 32 位整数范围内」，故 `int` 可行；不放心可用 `long long` 累加（题目数据下不会溢出）。
6. **区间是「子数组」不是「子序列」**：操作必须连续，这正是「左端点 $< i$ 的覆盖必延伸到 $i-1$」、从而引理 1 成立的前提。
