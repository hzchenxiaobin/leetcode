# LeetCode 在区间范围内统计奇数数目 题解

## 1. 题目概述

- **标题 / 题号**：在区间范围内统计奇数数目（#1523，easy）
- **链接**：https://leetcode.cn/problems/count-odd-numbers-in-an-interval-range/
- **来源**：LeetCode 第 31 场双周赛 Q1
- **难度**：简单
- **标签**：数学

**题意**：给定两个非负整数 $\textit{low}$ 和 $\textit{high}$，返回闭区间 $[\textit{low}, \textit{high}]$ 内奇数的个数。

**约束**：

- $0 \le \textit{low} \le \textit{high} \le 10^9$

## 2. 示例

**示例 1**

```text
输入：low = 3, high = 7
输出：3
解释：3 到 7 之间的奇数为 [3, 5, 7]。
```

**示例 2**

```text
输入：low = 8, high = 10
输出：1
解释：8 到 10 之间的奇数为 [9]。
```

**示例 3（边界补充）**

```text
输入：low = 0, high = 0
输出：0
解释：区间里只有偶数 0。
```

## 3. 解题思路

### 3.1 暴力思路

从 $\textit{low}$ 遍历到 $\textit{high}$，逐个判断奇偶并计数，时间 $O(\textit{high} - \textit{low} + 1)$。$10^9$ 的范围下最坏要循环十亿次，必然超时。签到题的正确姿势是把「逐个数」换成一个**前缀计数公式**，让复杂度与区间长度无关。

### 3.2 核心观察：前缀奇数计数 $f(x) = \lfloor (x+1)/2 \rfloor$

![前缀奇数计数公式](images/bw31_q1_prefix_odd_count.svg)

定义 $f(x)$ 为 $[0, x]$ 内奇数的个数。自然数从 0 开始**两两成对** $(0,1), (2,3), (4,5), \dots$，每对恰好贡献一个奇数，于是

$$f(x) = \left\lfloor \frac{x+1}{2} \right\rfloor.$$

闭区间 $[\textit{low}, \textit{high}]$ 的奇数个数可以用**容斥**直接相减：

$$\textit{ans} = f(\textit{high}) - f(\textit{low} - 1) = \left\lfloor \frac{\textit{high}+1}{2} \right\rfloor - \left\lfloor \frac{\textit{low}}{2} \right\rfloor.$$

注意整数除法自带下取整，且 $\lfloor \textit{low}/2 \rfloor = f(\textit{low}-1)$（对 $\textit{low} = 0$ 也成立：$f(-1) = 0$），所以公式不需要任何特判。

### 3.3 算法流程

```text
1. 计算 a = (high + 1) / 2   // [0, high] 内奇数个数（下整除）
2. 计算 b = low / 2           // [0, low-1] 内奇数个数（下整除）
3. 返回 a - b
```

### 3.4 示例演算

![奇偶两类边界情况](images/bw31_q1_two_cases.svg)

| 输入 | $f(\textit{high})$ | $f(\textit{low}-1)$ | 答案 | 验证 |
|------|------|------|------|------|
| $3, 7$ | $\lfloor 8/2 \rfloor = 4$ | $\lfloor 3/2 \rfloor = 1$ | $3$ | $3,5,7$ |
| $8, 10$ | $\lfloor 11/2 \rfloor = 5$ | $\lfloor 8/2 \rfloor = 4$ | $1$ | $9$ |
| $0, 0$ | $\lfloor 1/2 \rfloor = 0$ | $0$ | $0$ | 无奇数 |
| $1, 1$ | $\lfloor 2/2 \rfloor = 1$ | $\lfloor 1/2 \rfloor = 0$ | $1$ | $1$ |

也可以按区间长度的奇偶分类记忆：长度为偶数时奇偶各半；长度为奇数时看两端奇偶是否相同（相同则该奇偶多一个）。但**容斥公式一视同仁**，比赛时直接写公式最不容易错。

## 4. 算法细节

1. **整数下整除的实现**：C++ / Python 的 `/`（Python）与 `/`（C++ 整数除法）对非负数都是下取整，直接用即可；本题 $\textit{low}, \textit{high} \ge 0$，不存在负数取整方向的坑。
2. **为什么 $\lfloor \textit{low}/2 \rfloor = f(\textit{low}-1)$**：$f(\textit{low}-1) = \lfloor \textit{low}/2 \rfloor$ 由定义直接代入即得，$\textit{low} = 0$ 时两者都为 $0$，无需特判。
3. **数据范围**：$\textit{high} \le 10^9$，$(\textit{high}+1)/2 \le 5 \times 10^8 + 1$，在 `int` 范围内（`INT_MAX ≈ 2.1 × 10^9`），不会溢出。
4. **另一种等价写法**：$\textit{ans} = \lfloor (\textit{high}+1)/2 \rfloor - \lfloor \textit{low}/2 \rfloor$ 也可以写成 $\lfloor (\textit{high} - \textit{low} + 1 + [\textit{low} \text{ 为奇}]) / 2 \rfloor$ 的分类形式，前者更简洁。

## 5. 正确性证明

**引理 1（前缀计数）**：对任意整数 $x \ge 0$，$[0, x]$ 内奇数的个数为 $f(x) = \lfloor (x+1)/2 \rfloor$。

**证明**：把 $[0, x]$ 从 0 开始按相邻两数分组：$\{0,1\}, \{2,3\}, \dots$。每组恰含一个偶数与一个奇数，且奇数是组内较大者。若 $x = 2m+1$ 为奇数，则恰好分满 $m+1$ 组，奇数个数 $m+1 = (x+1)/2$；若 $x = 2m$ 为偶数，则前 $m$ 组完整、余下单独一个偶数 $2m$，奇数个数 $m = \lfloor (x+1)/2 \rfloor$。两种情形统一为 $\lfloor (x+1)/2 \rfloor$。∎

**引理 2（容斥）**：$[\textit{low}, \textit{high}]$ 内奇数的个数等于 $f(\textit{high}) - f(\textit{low} - 1)$。

**证明**：$[0, \textit{high}]$ 的奇数集合是不相交并 $[0, \textit{low}-1] \cup [\textit{low}, \textit{high}]$（当 $\textit{low} = 0$ 时前者为空集），两个区间内的奇数个数分别为 $f(\textit{low}-1)$ 与所求值，相加即 $f(\textit{high})$，移项即得。∎

**定理**：算法返回的 $\lfloor (\textit{high}+1)/2 \rfloor - \lfloor \textit{low}/2 \rfloor$ 恰为 $[\textit{low}, \textit{high}]$ 内奇数的个数。

**证明**：由引理 2，答案为 $f(\textit{high}) - f(\textit{low}-1)$。由引理 1，$f(\textit{high}) = \lfloor (\textit{high}+1)/2 \rfloor$；又 $f(\textit{low}-1) = \lfloor \textit{low}/2 \rfloor$（在引理 1 中令 $x = \textit{low}-1$，$\lfloor ((\textit{low}-1)+1)/2 \rfloor = \lfloor \textit{low}/2 \rfloor$；$\textit{low}=0$ 时 $f(-1)$ 定义为 $0$，与 $\lfloor 0/2 \rfloor$ 相等）。代入即得。∎

## 6. 复杂度分析

- **时间**：$O(1)$。只有两次整数除法与一次减法，与 $\textit{high} - \textit{low}$ 的大小无关。
- **空间**：$O(1)$。只用了常数个变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int countOdds(int low, int high) {
        // f(x) = [0, x] 内奇数个数 = (x + 1) / 2（下取整）
        // 容斥：[low, high] = f(high) - f(low - 1)
        return (high + 1) / 2 - low / 2;
    }
};
```

### Python

```python
class Solution:
    def countOdds(self, low: int, high: int) -> int:
        return (high + 1) // 2 - low // 2
```

> 💡 两份代码均通过官方示例（`3`、`1`）与边界用例（`low = high = 0`、`low = high = 1`、`low = 0, high = 10^9` 共 $5 \times 10^8$ 个奇数）。

## 8. 边界情况与易错点

1. **$\textit{low} = \textit{high}$**：单元素区间，公式退化为 $f(x) - f(x-1)$，恰好是「$x$ 是否为奇数」的指示函数，天然正确。
2. **$\textit{low} = 0$**：$\lfloor 0/2 \rfloor = 0 = f(-1)$，无需为「负数前缀」特判——这正是采用 $\lfloor \textit{low}/2 \rfloor$ 写法的好处。
3. **不要写 $\lfloor (\textit{high}-\textit{low}+1)/2 \rfloor$**：区间长度为奇数且两端同为奇数时（如 $[3,7]$ 长度 5，奇数 3 个而非 2 个）会算错。长度奇偶分类的记忆方式见 §3.4 配图。
4. **溢出**：$\textit{high} + 1 \le 10^9 + 1$ 在 `int` 内安全；若题目范围升到 $2^{31}$ 量级，C++ 需换 `long long`。
5. **逐位遍历的诱惑**：看到签到题先想公式，$O(1)$ 解法与 $O(n)$ 遍历在 $10^9$ 范围下是天壤之别。
