# LeetCode 删除后的最大子数组元素和 题解

## 1. 题目概述

- **标题 / 题号**：删除后的最大子数组元素和（#3487）
- **链接**：https://leetcode.cn/problems/maximum-unique-subarray-sum-after-deletion/
- **来源**：LeetCode 第 441 场周赛 Q1
- **难度**：简单
- **标签**：贪心、数组、哈希表

**题意**：
给定整数数组 `nums`。你可以先删除**任意数量**的元素，但删除后数组不能为空；然后从剩余数组中选出一段**连续、非空**的子数组，要求子数组内所有元素**互不相同**，并最大化该子数组的元素和。返回这个最大元素和。

**约束**：

- $1 \le nums.length \le 100$
- $-100 \le nums[i] \le 100$

> 💡 本题的"删除任意个元素"是极强的自由度：它让"连续子数组"这个限制**名存实亡**——任何子序列都能通过删光其余元素变成连续段。这是本题最大的陷阱，也是最快的切入点。

## 2. 示例

**示例 1**

```text
输入：nums = [1,2,3,4,5]
输出：15
解释：不删除任何元素，选中整个数组，元素互不相同，和最大。
```

**示例 2**

```text
输入：nums = [1,1,0,1,1]
输出：1
解释：删除三个 1 和一个 0，剩下 [1]，只能得到 1。
重复的 1 无论如何只能保留一个进入子数组。
```

**示例 3**

```text
输入：nums = [1,2,-1,-2,1,0,-1]
输出：3
解释：删除 -1、-2 后从 [1,2,1,0,-1] 中选子数组 [2,1]，
即取正数 2 和 1 各一次，总和为 3。
```

## 3. 解题思路

### 3.1 暴力思路

最朴素的做法是枚举删除哪些元素、再枚举删除后数组的所有子数组并检查元素互不相同，复杂度为 $O(2^n \cdot n^2)$，$n = 100$ 时完全不可行。

另一种"看似有道理"的路线是套经典模板：滑动窗口求"无重复元素的最大和子数组"，或者 Kadane 求最大子数组和。但这条路从一开始就错了——**删除是全局自由的**，连续性约束根本不构成限制，滑窗/Kadane 都在解一个比原问题难得多的假想问题。

### 3.2 核心观察：删除自由度 ⇒ 任意子序列 + 每值至多取一次

> 💡 **关键 insight**：既然可以删除任意个元素，那么"删除后选连续子数组"得到的元素集合，**就是原数组的一个非空子序列（保序）**——想留下哪几个元素，把其余的全删掉，它们自然连成一段。

于是问题一步转化为：**从 `nums` 中选一个非空子序列，元素互不相同，最大化元素和**。再叠加"互不相同"这一约束，每个**值**至多被取一次，且一个值 $v$ 无论取哪个出现位置、贡献都是 $v$ 本身，**与位置无关**。因此贪心策略浮出水面：

- 值 $v > 0$：必取（每个不同的正值取一次）；
- 值 $v \le 0$：不取；
- 特例：若数组里没有任何正数，子序列必须非空，此时退化为**只取单个最大元素**。

![删除任意元素后选连续子数组，等价于在原数组中选子序列](images/mssd_delete_to_subsequence.svg)

### 3.3 算法流程

1. 一遍扫描 `nums`，同时维护：
   - **正数集合** `pos`：所有互不相同的正数（可用 `set`，值域小也可用桶）；
   - **全局最大值** `mx`。
2. 若 `pos` 非空，返回 $\sum_{v \in pos} v$；否则返回 `mx`。

### 3.4 示例演算

以示例 3 `nums = [1, 2, -1, -2, 1, 0, -1]` 走查：互不相同的值为 $\{1, 2, 0, -1, -2\}$，其中正数只有 $1$ 和 $2$，各取一次；重复出现的 $1$ 只算一次，$0$ 取否对和无影响，负数全部不取：

![示例三的取值决策演算表](images/mssd_example_walkthrough.svg)

答案 $= 1 + 2 = 3$，与官方一致。

## 4. 算法细节

1. **等价转化的实现意义**：不需要真正枚举删除方案，"保留所选子序列、删除其余全部元素"就是合法的删除方式，且删除后数组非空，天然满足"不能删成空数组"的限制。
2. **去重的数据结构**：值域 $|nums[i]| \le 100$，既可用 `set`/哈希表，也可以开一个长度 201（或只对正值开 101）的布尔数组 $O(1)$ 判重。对本题的数据规模两者皆可，桶版更省常数。
3. **`0` 的处理**：$0$ 不是正数，进不了 `pos`；即使取它，对元素和也没有影响。因此无需特判。
4. **退化分支的统一写法**：让"正数之和"与"全局最大值"在扫描中同时维护，最后 `sum(pos) > 0` 则返回之和，否则返回 `mx`。注意用 `ans > 0` 而不是 `pos 非空` 来判断亦可，两者在本题语义等价（`pos` 非空则和至少为 1）。
5. **公式化表达**：
   $$ans = \begin{cases} \sum\limits_{v \in P} v, & P = \{v \in nums : v > 0\} \ne \varnothing \\ \max(nums), & \text{otherwise} \end{cases}$$

## 5. 正确性证明

**引理 1（子序列等价）**：经过"删除任意个元素、再选一个连续子数组"能得到的元素序列，恰是原数组的全体非空子序列。

**证明**：删除只移除元素、不改变剩余元素的相对顺序，因此删除后数组的任何连续段按原顺序读出，都是原数组的一个非空子序列。反之，对原数组的任意非空子序列 $S$，保留 $S$ 中的元素、删除其余所有元素，则 $S$ 恰好构成删除后数组的全部——是一段连续子数组，且数组非空。两个方向的方案集合相同。∎

**引理 2（取值上界）**：设 $P$ 为 `nums` 中互不相同的正数集合，则任何合法方案的元素和不超过 $\max\left(\sum_{v \in P} v,\ \max(nums)\right)$。

**证明**：任取一个合法方案，其取到的值互不相同，设取值集合为 $T$。一方面 $T$ 中的正数互不相同且均属于 $P$，故 $\sum_{x \in T} x \le \sum_{x \in T,\ x > 0} x \le \sum_{v \in P} v$（非正数贡献非正）。另一方面，若 $P = \varnothing$，则 $T$ 中所有元素非正，于是 $\sum_{x \in T} x \le \max_{x \in T} x \le \max(nums)$。两个界中较大者即为所求上界。∎

**定理**：记 $P$ 为 `nums` 中互不相同的正数集合，则最优值等于 $\sum_{v \in P} v$（当 $P \ne \varnothing$），否则等于 $\max(nums)$。

**证明**：由引理 1，问题等价于选一个非空、互不相同的子序列。由引理 2，上述两个候选值分别是两种情形的上界。再证可达：

- 若 $P \ne \varnothing$：对 $P$ 中每个值 $v$ 任取一个出现位置，这些位置构成的子序列非空、保序、互不相同，元素和恰为 $\sum_{v \in P} v$，达到上界。
- 若 $P = \varnothing$：取单个元素 $[\max(nums)]$ 构成的子序列，非空且自动互不相同，元素和恰为 $\max(nums)$，达到上界。

上界与构造匹配，故最优。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。一遍扫描维护正数集合与最大值，随后至多再扫一遍值域（$O(D)$，$D$ 为不同正数个数，$D \le 100$）求和。
- **空间复杂度**：$O(D)$。`set` 或长度 101 的布尔桶，用于去重不同正数。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maxSum(vector<int>& nums) {
        int ans = 0;
        int mx = INT_MIN;
        bool seen[101] = {false};
        for (int x : nums) {
            mx = max(mx, x);
            if (x > 0) seen[x] = true;
        }
        for (int v = 1; v <= 100; v++) {
            if (seen[v]) ans += v;
        }
        return ans > 0 ? ans : mx;
    }
};
```

### Python

```python
class Solution:
    def maxSum(self, nums: List[int]) -> int:
        pos = {x for x in nums if x > 0}
        return sum(pos) if pos else max(nums)
```

## 8. 边界情况与易错点

1. **全负数组**：子数组必须非空，答案是最小负担的单个最大元素（负数），**不能返回 0**。写成 `max(ans, 0)` 之类的兜底会在这里出错。
2. **有 0 无正**：例如 `[0, -1]`，答案是 $0$（选子数组 `[0]`）。`pos` 为空时走 `max(nums)` 分支自然得到 0，无需特判。
3. **重复正数只计一次**：`[1, 1, 1]` 的答案是 1 而不是 3——"互不相同"按值去重，必须用集合/桶。
4. **误套经典模板**：看到"连续子数组 + 互不相同"就条件反射滑窗（LC 2461），或看到"最大和子数组"就上 Kadane（LC 53），都会把简单题做复杂甚至做错——"删除任意个元素"已让连续性失效。
5. **"不能删成空数组"不构成额外限制**：最优方案对应的子序列本身就非空，保留它、删掉其余元素即可，无需针对该条件写任何特判。
6. **单元素数组**：`n = 1` 时，正数走集合求和、非正走 `max`，两条分支都直接返回该元素。
7. **数值范围**：$n \le 100$、$|nums[i]| \le 100$，和不超过 $10^4$，任何整型都不会溢出。
