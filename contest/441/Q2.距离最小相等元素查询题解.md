# LeetCode 距离最小相等元素查询 题解

## 1. 题目概述

- **标题 / 题号**：距离最小相等元素查询（#3488，medium）
- **链接**：https://leetcode.cn/problems/closest-equal-element-queries/
- **来源**：LeetCode 第 441 场周赛 Q2
- **难度**：中等
- **标签**：数组、哈希表、二分查找

**题意**：
给定一个**环形**数组 `nums` 和查询数组 `queries`。对每个查询 $q = queries[i]$，求下标 $q$ 处的元素与**任意其他**同值下标 $j$（$nums[j] = nums[q]$ 且 $j \ne q$）之间的**最小环上距离**；若不存在这样的 $j$，答案为 $-1$。环上下标 $i, j$ 之间的距离为 $\min\big(|i-j|,\ n-|i-j|\big)$——沿环两个方向各有一条路径，取较短者。

**约束**：

- $1 \le queries.length \le nums.length \le 10^5$
- $1 \le nums[i] \le 10^6$
- $0 \le queries[i] < nums.length$

> 💡 两个关键词各指向一个套路：**"环形"** 意味着距离要双方向取 $\min$（环绕取模）；**"最近同值"** 意味着按值分组后只需看"邻居"。数据范围 $10^5$ 容许 $O(n \log n)$，排除 $O(nq)$ 暴力。

## 2. 示例

**示例 1**

```text
输入：nums = [1,3,1,4,1,3,2], queries = [0,3,5]
输出：[2,-1,3]
解释：
查询 0：nums[0] = 1，最近的同值下标为 2，距离 2。
查询 1：nums[3] = 4，值 4 只出现一次，答案 -1。
查询 2：nums[5] = 3，最近的同值下标为 1，沿环 5→6→0→1 距离 3。
```

**示例 2**

```text
输入：nums = [1,2,3,4], queries = [0,1,2,3]
输出：[-1,-1,-1,-1]
解释：所有值互不相同，不存在其他同值下标。
```

**示例 3**（补充：全相同元素）

```text
输入：nums = [7,7,7,7], queries = [0,2]
输出：[1,1]
解释：任何下标的相邻位置都是同值，最近距离恒为 1。
```

## 3. 解题思路

### 3.1 暴力思路

对每个查询 $q$，从 $q$ 出发沿环的两个方向各逐格扩散，最先撞到的同值下标即为答案：

```python
for q in queries:
    for d in range(1, n // 2 + 1):
        if nums[(q + d) % n] == nums[q] or nums[(q - d) % n] == nums[q]:
            answer.append(d)   # 找到
            break
```

单次查询最坏 $O(n)$，总体 $O(nq)$，在 $n, q \le 10^5$ 时达 $10^{10}$ 量级，必然超时。问题出在：每个查询都从零开始"找邻居"，而同一批同值下标之间的邻居关系被重复计算了成百上千次。

### 3.2 核心观察：同值下标排成有序表，最近必是环形前驱 / 后继

![按值分组与环形前驱后继](images/ceeq_value_group_prev_next.svg)

**第一步：按值分组。** 用哈希表把每个值映射到下标列表：$pos[x] = [\,i : nums[i] = x\,]$。由于建表时按下标 $0 \dots n-1$ 顺序录入，每个列表**天然升序**，无需排序。

**第二步：最近者必是前驱 / 后继。** 固定查询 $q$，设 $v = pos[nums[q]]$（长度 $m$），$q = v[\text{idx}]$。从 $q$ 沿环出发：

- 沿**顺时针**方向遇到的第一个同值下标，就是 $v$ 中 $q$ 的**后继** $next = v[(\text{idx}+1) \bmod m]$（若 $q$ 是表中最后一个，环绕到表头 $v[0]$）；
- 沿**逆时针**方向的第一个同值下标，就是**前驱** $prev = v[(\text{idx}-1+m) \bmod m]$（若 $q$ 是表头，环绕到表尾）。

环上其余同值下标都排在这两个"第一名"**之后**，弧长只会更长；而环上距离恰为两个方向最短弧长之 $\min$，所以：

$$answer[i] = \min\Big(\text{rd}\big(q,\ prev\big),\ \text{rd}\big(q,\ next\big)\Big), \qquad \text{rd}(a,b) = \min\big(|a-b|,\ n-|a-b|\big)$$

在有序表 $v$ 中定位 $idx$ 只需**二分查找**——"哈希分组 + 二分"正是本题的标签组合。唯一需要特判的是 $m = 1$（该值只出现一次），直接返回 $-1$。

### 3.3 算法流程

![算法流程图](images/ceeq_algorithm_flow.svg)

1. 一遍扫描 `nums`，建哈希表 `pos`：值 → 有序下标列表；
2. 依次处理每个查询 `q`，取 `v = pos[nums[q]]`；
3. 若 `|v| = 1`：该查询答案为 `-1`；
4. 否则二分定位 `idx`（`v[idx] = q`），用取模公式求前驱 `prev` 与后继 `next`；
5. 用环距公式 $\min(|a-b|, n-|a-b|)$ 分别计算 `q` 到二者的距离，取较小者为该查询答案；
6. 所有查询处理完毕后返回 `answer`。

### 3.4 示例演算

![示例一的三次查询演算](images/ceeq_example_walkthrough.svg)

以**示例 1**（`nums = [1,3,1,4,1,3,2]`，$n = 7$）走一遍。建表得 `pos[1] = [0,2,4]`、`pos[3] = [1,5]`、`pos[4] = [3]`、`pos[2] = [6]`。

| 查询 | $q$ | 值 | $v$ | idx | prev / next | 环距计算 | answer |
|---|---|---|---|---|---|---|---|
| 0 | 0 | 1 | $[0,2,4]$ | 0 | 4（环绕）/ 2 | $\text{rd}(0,4)=\min(4,3)=3$，$\text{rd}(0,2)=\min(2,5)=2$ | **2** |
| 1 | 3 | 4 | $[3]$ | — | —（m=1） | 无其他同值下标 | **-1** |
| 2 | 5 | 3 | $[1,5]$ | 1 | 1 / 1（m=2 同一元素） | $\text{rd}(5,1)=\min(4,3)=3$ | **3** |

- **查询 0**：`idx = 0`，前驱环绕到表尾 `v[2] = 4`，后继 `v[1] = 2`。$2 < 3$，答案 2 ✓
- **查询 1**：值 4 只出现一次，直接 `-1` ✓
- **查询 2**：`idx = 1`，前驱 `v[0] = 1`；后继 `v[(1+1) \bmod 2] = v[0] = 1`（$m = 2$ 时前驱后继是同一个元素）。$\text{rd}(5,1) = \min(4, 3) = 3$——正是"沿环 5→6→0→1 走 3 步"的绕行路径 ✓

## 4. 算法细节

1. **建表即有序**：按下标 $0 \dots n-1$ 扫描、`push_back`，同值下标按录入顺序天然升序，二分前提免费成立。哈希表**键**的遍历顺序无序不影响正确性——二分只作用于每个**组内列表**。
2. **二分是"精确命中"**：$q$ 必然属于 $pos[nums[q]]$，`lower_bound` / `bisect_left` 返回的位置恰是 $q$ 本身，不存在"找不到"分支。
3. **前驱 / 后继的取模公式**：$prev = v[(\text{idx}-1+m) \bmod m]$、$next = v[(\text{idx}+1) \bmod m]$。`idx = 0` 时前驱绕到表尾、`idx = m-1` 时后继绕到表头——这是"环"在组内有序表上的投影。C++ 必须写 `(idx - 1 + m) % m` 防负数下标；Python 的 `v[idx - 1]` 在 `idx = 0` 时自动取 `v[-1]`（表尾），与环绕语义恰好一致。
4. **环距两个分支都要算**：`rd = min(|a-b|, n-|a-b|)`。当候选来自"环绕"（如前驱绕到表尾）时，`n - |a-b|` 分支才会生效，漏掉它就是典型 WA。
5. **消二分的两种写法**（均把总复杂度做到 $O(n+q)$，本题非必需，属于常数优化）：
   - **建表记名次**：扫描时顺手记录每个下标在其组内的名次 `rank[i] = len(pos[x])`（`i` 加入前组内已有元素数），查询时直接 `idx = rank[q]`，免去二分；
   - **相邻对松弛**：对每个 $m \ge 2$ 的组，枚举环形相邻对 $\big(v[k],\ v[(k+1) \bmod m]\big)$ 互相松弛环距，预处理出每个下标的 `best`；未被松弛过的下标（值唯一）答案为 $-1$。

## 5. 正确性证明

**引理 1（环距公式）**：在长度为 $n$ 的环形数组上，从下标 $i \ne j$ 出发每步移动到下标 $\pm 1 \pmod n$，走到 $j$ 的最短步数为 $\text{rd}(i,j) = \min\big(|i-j|,\ n-|i-j|\big)$。

**证明**：把所有"每步 $\pm 1$"的路线按净方向分类。整段沿下标递增方向走的步数为 $(j-i) \bmod n$，整段递减方向为 $(i-j) \bmod n$，且当 $i \ne j$ 时二者恰为 $|i-j|$ 与 $n-|i-j|$（互补，和为 $n$）。任何中途折返的路线，其折返段来回相互抵消、只会更长，故最短步数不小于 $\min\big((j-i) \bmod n,\ (i-j) \bmod n\big) = \min\big(|i-j|,\ n-|i-j|\big)$；而两个纯方向路线恰好达到该下界。∎

**引理 2（最近者必为前驱 / 后继）**：设值 $x$ 的升序下标列表为 $v$，$m = |v| \ge 2$，$q = v[\text{idx}]$，$p = v[(\text{idx}-1+m) \bmod m]$，$s = v[(\text{idx}+1) \bmod m]$。则

$$\min_{j \in v,\, j \ne q} \text{rd}(q, j) \;=\; \min\big(\text{rd}(q, p),\ \text{rd}(q, s)\big)$$

**证明**：记 $\text{cw}(q,j) = (j - q) \bmod n$ 为从 $q$ **顺时针**（下标递增方向）走到 $j$ 的步数，$\text{ccw}(q,j) = (q - j) \bmod n$ 为逆时针步数。由引理 1，$\text{rd}(q,j) = \min\big(\text{cw}(q,j),\ \text{ccw}(q,j)\big)$。

**（a）$s$ 是顺时针方向第一个撞到的组内元素**：从 $q$ 顺时针扫过 $q+1, q+2, \dots, n-1, 0, \dots, q-1$。因 $v$ 升序，大于 $q$ 的组内元素按 $v[\text{idx}+1], \dots, v[m-1]$ 顺序出现（若存在）；若不存在（$q$ 是表中最大下标，即 $\text{idx} = m-1$），则环绕经过 $n-1 \to 0$ 后第一个遇到的是 $v[0]$。两种情况统一为 $v[(\text{idx}+1) \bmod m] = s$，且对任意 $j \in v \setminus \{q\}$ 有 $\text{cw}(q, j) \ge \text{cw}(q, s)$。对称地，$p$ 是逆时针方向第一个撞到的组内元素，对任意 $j \ne q$ 有 $\text{ccw}(q, j) \ge \text{ccw}(q, p)$。

**（b）夹逼**：对任意 $j \in v, j \ne q$，

$$\text{rd}(q,j) = \min\big(\text{cw}(q,j),\ \text{ccw}(q,j)\big) \ge \min\big(\text{cw}(q,s),\ \text{ccw}(q,p)\big) \ge \min\big(\text{rd}(q,s),\ \text{rd}(q,p)\big)$$

（最后一步因 $\text{cw}(q,s) \ge \text{rd}(q,s) \ge \min(\text{rd}(q,s), \text{rd}(q,p))$，$\text{ccw}$ 同理）。而 $m \ge 2$ 时取模保证 $(\text{idx}+1) \bmod m \ne \text{idx} \ne (\text{idx}-1+m) \bmod m$，故 $s, p$ 都是组内异于 $q$ 的合法候选，右边可以取到。两边夹逼即得等式。∎

**定理（算法正确性）**：算法对每个查询 $q$ 输出的值等于其最优环上距离（不存在其他同值下标时为 $-1$）。

**证明**：若 $m = 1$，组内无其他下标，任何满足 $nums[j] = nums[q]$ 的 $j$ 都等于 $q$，违反 $j \ne q$，答案为 $-1$，算法的特判正确。若 $m \ge 2$，二分定位准确（算法细节第 2 点），由引理 2，最近距离恰在 $prev$、$next$ 二者之一取到；算法按引理 1 的公式计算 $\text{rd}(q, prev)$、$\text{rd}(q, next)$ 并取 $\min$，与距离定义一致。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n + q \log n)$。建哈希表一遍 $O(n)$（均摊）；每次查询在长度 $m \le n$ 的有序表上二分定位 $O(\log m)$，共 $q$ 次。$n, q \le 10^5$ 时约 $10^5 \times 17 \approx 1.7 \times 10^6$ 次比较，轻松通过。若采用算法细节第 5 点的名次记录，可降到 $O(n + q)$。
- **空间复杂度**：$O(n)$。哈希表中所有下标列表长度之和恰为 $n$；输出数组 $O(q)$ 按惯例不计。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    vector<int> solveQueries(vector<int>& nums, vector<int>& queries) {
        int n = nums.size();
        unordered_map<int, vector<int>> pos;
        for (int i = 0; i < n; ++i) {
            pos[nums[i]].push_back(i);        // 按下标顺序录入，天然有序
        }

        auto ringDist = [&](int a, int b) {
            int d = abs(a - b);
            return min(d, n - d);              // 环上距离：两个方向取短
        };

        vector<int> answer;
        answer.reserve(queries.size());
        for (int q : queries) {
            vector<int>& v = pos[nums[q]];
            if (v.size() == 1) {                // 该值只出现一次
                answer.push_back(-1);
                continue;
            }
            int m = v.size();
            int idx = lower_bound(v.begin(), v.end(), q) - v.begin();
            int prev = v[(idx - 1 + m) % m];    // idx=0 时环绕到表尾
            int next = v[(idx + 1) % m];        // idx=m-1 时环绕回表头
            answer.push_back(min(ringDist(q, prev), ringDist(q, next)));
        }
        return answer;
    }
};
```

### Python

```python
class Solution:
    def solveQueries(self, nums: List[int], queries: List[int]) -> List[int]:
        n = len(nums)
        pos = defaultdict(list)
        for i, x in enumerate(nums):
            pos[x].append(i)                    # 按下标顺序录入，天然有序

        def rd(a: int, b: int) -> int:
            d = abs(a - b)
            return min(d, n - d)                # 环上距离：两个方向取短

        answer = []
        for q in queries:
            v = pos[nums[q]]
            if len(v) == 1:                     # 该值只出现一次
                answer.append(-1)
                continue
            idx = bisect_left(v, q)
            prev = v[idx - 1]                   # idx=0 时取 v[-1] 恰为表尾，天然环绕
            nxt = v[(idx + 1) % len(v)]         # 表尾环绕回表头
            answer.append(min(rd(q, prev), rd(q, nxt)))
        return answer
```

## 8. 边界情况与易错点

1. **忘算环绕方向**：最典型的 WA。查询 2（$q = 5$，目标 $1$）中 $|5-1| = 4$，但沿环 $5 \to 6 \to 0 \to 1$ 只要 3 步。环距必须 $\min(d,\ n-d)$ 双方向取短。
2. **$m = 1$ 特判**：值只出现一次时返回 $-1$；注意不要把"组里只有 $q$ 自己"误算成"距离 0"——题目要求 $j \ne q$，答案永远**不会是 0**（$m \ge 2$ 时 $n \ge 2$，环距至少为 1）。
3. **$m = 2$ 无需特判**：前驱与后继都指向仅剩的另一个元素，取模公式天然正确；$m = n$（全相同）时最近距离恒为 1，同样被公式覆盖。
4. **C++ 负数取模**：`v[(idx - 1) % m]` 在 `idx = 0` 时是 `v[-1]` 越界，必须写 `(idx - 1 + m) % m`。Python 负下标自动环绕是巧合，可读性优先时也可显式写 `(idx - 1 + m) % m`。
5. **二分的前提是有序**：组内列表有序来自"按下标顺序录入"这一实现细节，若用 unordered_set / 乱序收集再二分就是错的。
6. **$n = 1$**：唯一下标必然 $m = 1$，走 `-1` 分支，无需单独处理。
7. **queries 重复 / 乱序**：每个查询独立幂等，不受影响；$queries[i] < n$ 保证下标合法。
8. **溢出**：环距 $\le n/2 \le 5 \times 10^4$，`int` 足够；`n - d` 在 $d = 0$ 时为 $n$ 也不越界（且 $d = 0$ 意味 $j = q$，已被 $m = 1$ 特判与候选选取排除）。
