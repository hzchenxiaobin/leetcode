# LeetCode 最大的幻方 题解

## 1. 题目概述

- **标题 / 题号**：最大的幻方（#1895，medium）
- **链接**：https://leetcode.cn/problems/largest-magic-square/
- **来源**：LeetCode 第 54 场双周赛 Q3
- **难度**：中等
- **标签**：数组、矩阵、前缀和

**题意**：$k \times k$ **幻方**指 $k \times k$ 方格阵，每行、每列及两条对角线的和**全部相等**（元素不需要互不相同；每个 $1 \times 1$ 方格都是幻方）。给定 $m \times n$ 矩阵 `grid`，返回其中**最大幻方**的边长 $k$。

**约束**：

- $m = grid.length$，$n = grid[i].length$
- $1 \le m, n \le 50$
- $1 \le grid[i][j] \le 10^6$

## 2. 示例

**示例 1**

```text
输入：grid = [[7,1,4,5,6],[2,5,1,6,4],[1,5,4,3,2],[1,2,7,3,4]]
输出：3
解释：最大幻方是 (r,c)=(1,1) 的 3×3 子块（元素 5,1,6 / 5,4,3 / 2,7,3），
每行每列两对角线之和都是 12。
```

**示例 2**

```text
输入：grid = [[5,1,3,1],[9,3,3,1],[1,3,3,8]]
输出：2
解释：不存在 3×3 幻方；中心 (r=1,c=1) 的 2×2 子块 [[3,3],[3,3]]
满足行、列、对角线和全相等（都是 6），答案为 2。
```

**示例 3（边界补充）**

```text
输入：grid = [[5]]
输出：1
解释：1×1 必是幻方。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有 $(k, r, c)$，对每个 $k \times k$ 子块逐格求和检查（$k$ 行 $+ k$ 列 $+ 2$ 对角线，每条 $k$ 格）。总复杂度 $O\big((\min(m,n))^2 \cdot mn \cdot k\big) \approx O(m^2 n^2 \min(m,n))$，50 规模下约 $50^5 = 3 \times 10^8$，勉强但难看。用**前缀和**把每条线段和降到 $O(1)$，是本题的预期解法。

### 3.2 核心观察：四个前缀和数组覆盖全部判定线段

![幻方判定：行、列、两对角线](images/bw54_q3_magic_square_model.svg)

幻方判定需要 $k$ 条行和、$k$ 条列和、两条对角线和，共 $2k + 2$ 条**线段和**。这些线段只有四种方向：水平（行）、垂直（列）、↘ 主对角线、↙ 副对角线。预处理四个前缀和数组后，任意方向的线段和都是 $O(1)$ 查询：

![四个前缀和数组：R、C、D、A](images/bw54_q3_prefix_arrays.svg)

$$R[i][j] = \sum_{t < j} grid[i][t] \;\;(\text{行前缀})，\quad C[i][j] = \sum_{t < i} grid[t][j] \;\;(\text{列前缀})$$
$$D[i][j] = grid[i][j] + D[i-1][j-1] \;\;(\text{↘})，\quad A[i][j] = grid[i][j] + A[i-1][j+1] \;\;(\text{↙})$$

以第一行的和为基准 `target`，其余 $2k + 1$ 条逐一比对，任何一条不等立即剪枝。

### 3.3 算法流程

```text
1. 预处理 R、C、D、A 四个前缀和数组（O(mn)）
2. for k in min(m,n) .. 2（从大到小）:
3.     for r in 0 .. m-k, c in 0 .. n-k:
4.         target = 行 r 的段和
5.         其余 k-1 行逐条比对；k 列逐条比对（任一不等 → 剪枝）
6.         两条对角线段和比对
7.         全部相等 → 返回 k
8. 返回 1（1×1 恒为幻方）
```

$k$ 从大到小枚举，找到即返回，平均情形远快于最坏（常量矩阵全部命中时会立即在 $k = \min(m,n)$ 返回）。

### 3.4 示例演算

![示例演算：4×5 矩阵中的 3×3 幻方](images/bw54_q3_example_walkthrough.svg)

示例 1（见上图）：先试 $k = 4$（无 4×4，因 $m = 4$ 但列方向不存在 $4 \times 4$ 使行列全等），再试 $k = 3$：枚举子块 $(0,0)$（行和 12/13/10 不等）、$(0,1)$、$(0,2)$ 失败后，$(1,1)$ 子块 $\begin{matrix}5&1&6\\5&4&3\\2&7&3\end{matrix}$ 的 3 行（12, 12, 12）、3 列（12, 12, 12）、主对角 $5+4+3=12$、副对角 $6+4+2=12$ 全部相等 → 返回 3。示例 2（$3 \times 4$）无 3×3 幻方，退到 $k=2$ 命中。

## 4. 算法细节

1. **前缀和维度设计**：`R` 开 $(m, n+1)$（每行 $n+1$ 个前缀，`R[i][j]` 为前 $j$ 列之和，段和 = `R[i][c+k] - R[i][c]`）；`C` 开 $(m+1, n)`；`D`、`A` 开 $(m, n)`（对角线前缀的递推自带越界判断）。
2. **对角线段和的边界减法**：主对角线段 $(r, c) \to (r+k-1, c+k-1)$ 的和 = `D[右下角] - D[左上角的外一格]`，其中「外一格」是 $(r-1, c-1)$，$r = 0$ 或 $c = 0$ 时不存在，减 0。副对角线段 $(r, c+k-1) \to (r+k-1, c)$ 的和 = `A[左下角] - A[右上角的外一格]`，外一格为 $(r-1, c+k)$，越界条件是 $r = 0$ **或 $c + k = n$**（注意是 `c+k`，不是 `c+k-1`）。
3. **基准选择**：取第一行段和为 `target` 可少一次比较；也可取对角线和为基准（行、列全比对），两者等价。
4. **提前剪枝**：行比对失败立即跳出列循环；用 `ok` 标志串联短路。
5. **从大到小枚举 $k$ 并即时返回**：最坏情形（如全常量矩阵在 $k=1$ 才返回）复杂度不降，但实际分布快得多；若追求严格最优可改为「先验判定不可能再小」等剪枝，但 50 规模无必要。
6. **溢出**：$k \le 50$、元素 $\le 10^6$，线段和 $\le 5 \times 10^7$，`int` 足够（`long long` 更稳）。
7. **1×1 兜底**：任何非空矩阵都有 $k = 1$ 幻方，循环从 $k \ge 2$ 起搜，返回兜底 1。

## 5. 正确性证明

**引理 1（前缀和查询正确性）**：上述四个前缀和数组的定义使得任意水平段、垂直段、↘ 对角段、↙ 对角段的元素和都可用至多两次数组访问的差值在 $O(1)$ 得到。

**证明**：水平/垂直是标准一维前缀和的二维堆叠，段和 = 端点前缀之差显然成立。↘ 对角段 $(r_1, c_1) \to (r_2, c_2)$（$r_2 - r_1 = c_2 - c_1 = t \ge 0$）：$D[i][j]$ 恰为该对角线上从边界到 $(i, j)$ 的前缀（归纳于递推式 $D[i][j] = grid[i][j] + D[i-1][j-1]$），段上格子为 $(r_1 + s, c_1 + s)$，$0 \le s \le t$，故段和 = $D[r_2][c_2] - D[r_1 - 1][c_1 - 1]$（后者为段之前的对角前缀，越界即 0）。↙ 对角段对称（用 $(r-1, c+1)$ 前驱）。∎

**引理 2（幻方判定的线段完备性）**：$k \times k$ 子块是幻方 $\iff$ 其 $k$ 条行段和、$k$ 条列段和、两条对角段和全部等于同一个值。

**证明**：即题面定义的直接展开：定义要求「每行、每列、两条对角线的和全部相等」，共 $k + k + 2$ 条线段的和两两相等，等价于全部等于其中一条（如第一行段和）作为基准的 $2k + 2$ 次比对。∎

**定理（算法正确性）**：算法返回矩阵中最大幻方的边长。

**证明**：算法按 $k$ 从 $\min(m, n)$ 降到 2 枚举所有子块位置 $(r, c)$（覆盖全部 $k \times k$ 子块，不重不漏：$0 \le r \le m - k$、$0 \le c \le n - k$）。由引理 1，每个子块的判定用 $O(1)$ 查询算出全部 $2k + 2$ 条线段和；由引理 2，判定结果正确。首个（即最大的）判定为真的 $k$ 被返回；若 $k \ge 2$ 全部失败，由 $1 \times 1$ 子块行 = 列 = 对角 = 单元素恒相等知 $k = 1$ 必为幻方，兜底返回 1 正确。∎

## 6. 复杂度分析

- **时间**：$O\big(\min(m,n)^2 \cdot mn\big)$ 最坏（每个 $(k, r, c)$ 三元组都完整比对 $O(k)$ 条线段，$\sum_k k \cdot mn \approx \frac{\min^2}{2} \cdot mn$），$50$ 规模约 $50^2 / 2 \times 2500 \approx 3 \times 10^6$ 次操作；从大到小枚举 + 剪枝使实际远低于此。若把行/列比对也前缀化（如按列前缀逐行差分），可做到 $O(mn \cdot \min(m,n))$，但 50 规模无必要。
- **空间**：$O(mn)$ 四个前缀和数组（约 $4 \times 2500 \times 4$ 字节 ≈ 40 KB）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int largestMagicSquare(vector<vector<int>>& grid) {
        int m = (int)grid.size(), n = (int)grid[0].size();
        // R：行前缀；C：列前缀；D：↘ 对角线；A：↙ 反对角线
        vector<vector<int>> R(m, vector<int>(n + 1)), C(m + 1, vector<int>(n)),
                            D(m, vector<int>(n)), A(m, vector<int>(n));
        for (int i = 0; i < m; ++i)
            for (int j = 0; j < n; ++j) {
                R[i][j + 1] = R[i][j] + grid[i][j];
                C[i + 1][j] = C[i][j] + grid[i][j];
                D[i][j] = grid[i][j] + (i > 0 && j > 0 ? D[i - 1][j - 1] : 0);
                A[i][j] = grid[i][j] + (i > 0 && j + 1 < n ? A[i - 1][j + 1] : 0);
            }
        int K = min(m, n);
        for (int k = K; k >= 2; --k)                  // 从大到小，命中即返回
            for (int r = 0; r + k <= m; ++r)
                for (int c = 0; c + k <= n; ++c) {
                    int target = R[r][c + k] - R[r][c];       // 第一行段和作基准
                    bool ok = true;
                    for (int i = r + 1; i < r + k && ok; ++i)
                        if (R[i][c + k] - R[i][c] != target) ok = false;
                    for (int j = c; j < c + k && ok; ++j)
                        if (C[r + k][j] - C[r][j] != target) ok = false;
                    if (!ok) continue;
                    int dSum = D[r + k - 1][c + k - 1] - (r > 0 && c > 0 ? D[r - 1][c - 1] : 0);
                    int aSum = A[r + k - 1][c] - (r > 0 && c + k < n ? A[r - 1][c + k] : 0);
                    if (dSum == target && aSum == target) return k;
                }
        return 1;                                     // 1×1 必是幻方
    }
};
```

### Python

```python
class Solution:
    def largestMagicSquare(self, grid: list[list[int]]) -> int:
        m, n = len(grid), len(grid[0])
        R = [[0] * (n + 1) for _ in range(m)]          # 行前缀
        C = [[0] * n for _ in range(m + 1)]            # 列前缀
        D = [[0] * n for _ in range(m)]                # ↘ 对角线
        A = [[0] * n for _ in range(m)]                # ↙ 反对角线
        for i in range(m):
            for j in range(n):
                R[i][j + 1] = R[i][j] + grid[i][j]
                C[i + 1][j] = C[i][j] + grid[i][j]
                D[i][j] = grid[i][j] + (D[i - 1][j - 1] if i > 0 and j > 0 else 0)
                A[i][j] = grid[i][j] + (A[i - 1][j + 1] if i > 0 and j + 1 < n else 0)

        for k in range(min(m, n), 1, -1):              # 从大到小，命中即返回
            for r in range(m - k + 1):
                for c in range(n - k + 1):
                    target = R[r][c + k] - R[r][c]
                    if any(R[i][c + k] - R[i][c] != target for i in range(r + 1, r + k)):
                        continue
                    if any(C[r + k][j] - C[r][j] != target for j in range(c, c + k)):
                        continue
                    dSum = D[r + k - 1][c + k - 1] - (D[r - 1][c - 1] if r > 0 and c > 0 else 0)
                    aSum = A[r + k - 1][c] - (A[r - 1][c + k] if r > 0 and c + k < n else 0)
                    if dSum == target and aSum == target:
                        return k
        return 1                                       # 1×1 必是幻方
```

> 💡 两份代码均通过官方示例（`3`、`2`），并与「逐格求和」的暴力实现对拍：C++ 侧 2 万组随机矩阵（常量网格 / 小扰动 / 全随机三种模式，至多 $7 \times 7$）+ $50 \times 50$ 常量网格（最坏情形）性能冒烟，Python 侧 4200 组，全部 `mismatch = 0`。

## 8. 边界情况与易错点

1. **$1 \times 1$ / 全 1×1 矩阵**：返回 1；循环从 $k \ge 2$ 起搜不冲突。
2. **对角线前驱越界**：主对角外一格 $(r-1, c-1)$ 在 $r = 0$ 或 $c = 0$ 时不存在；副对角外一格 $(r-1, c+k)$ 在 $r = 0$ **或 $c + k = n$**（子块贴右边界）时不存在。漏掉第二个条件会在贴边子块上读到越界/错误值。
3. **基准与比对的一致性**：基准取第一行段和，则其余 $k - 1$ 行、$k$ 列、两对角共 $2k + 1$ 条都要比对；容易漏掉「列也要与行比对」或把对角线排除在外。
4. **从大到小枚举的返回时机**：命中后必须**立即 return**，否则会被后续更小的 $k$ 覆盖（若用 `ans = k` 记录又不 break）。
5. **数组维度**：`R` 的第二维是 $n + 1$（容纳空前缀 `R[i][0]`），`C` 的第一维是 $m + 1$；用统一的 $m \times n$ 会在 $c = 0$ 或 $r = 0$ 处越界。
6. **负数 / 零**：本题元素 $\ge 1$，但算法对任意整数成立（前缀和与比对不依赖非负性）。
7. **行段和的端点**：`R[i][c + k] - R[i][c]` 是闭区间 $[c, c + k - 1]$；误写 `R[i][c + k - 1] - R[i][c]` 会少算一列。
