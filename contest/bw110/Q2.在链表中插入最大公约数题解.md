# LeetCode 在链表中插入最大公约数 题解

## 1. 题目概述

- **标题 / 题号**：在链表中插入最大公约数（#2807，medium）
- **链接**：https://leetcode.cn/problems/insert-greatest-common-divisors-in-linked-list/
- **来源**：LeetCode 第 110 场双周赛 Q2
- **难度**：中等
- **标签**：链表、数学、数论

**题意**：给定单链表头结点 `head`，在**每两个相邻结点之间**插入一个新结点，其值为这两个相邻结点值的**最大公约数**（GCD）。返回插入后的链表。

**约束**：

- 链表结点数在 $[1, 5000]$ 范围内
- $1 \le \mathrm{Node.val} \le 1000$

## 2. 示例

**示例 1**

```text
输入：head = [18, 6, 10, 3]
输出：[18, 6, 6, 2, 10, 1, 3]
解释：gcd(18,6)=6 插在第一对之间；gcd(6,10)=2 插在第二对之间；
gcd(10,3)=1 插在第三对之间。
```

**示例 2**

```text
输入：head = [7]
输出：[7]
解释：没有相邻结点，原样返回。
```

## 3. 解题思路

### 3.1 暴力思路

把链表值读进数组，对每对相邻值算 gcd，拼出新数组再重建一条链表——正确但绕远路：两次遍历加一次重建，空间 $O(n)$，还要小心头结点处理。其实"相邻插入"天生适合**就地单指针遍历**，边走边插，一次扫描完成，$O(1)$ 额外空间。

### 3.2 核心观察：新结点不参与"下一对"配对

![相邻插入 gcd 结点的结构](images/bw110_q2_insert_gcd_concept.svg)

设指针 `cur` 指向某个**原始**结点。它的右邻 `cur->next` 也是原始结点，两者构成"当前待处理的一对"；插入 `gcd` 结点后，**下一个待处理对是 `(cur->next, cur->next->next)`**——刚插入的 gcd 结点永远不会成为配对的一员。因此指针每次**跨两步**前进，遍历的对象始终是原链表的结点序列，互不干扰。

### 3.3 GCD 用辗转相除

![辗转相除求 gcd 的三个实例](images/bw110_q2_euclid_gcd.svg)

$\gcd(a, b) = \gcd(b, a \bmod b)$，余数为 0 时答案取除数。C++17 直接用 `std::gcd`（`<numeric>`，LeetCode 环境内置）；Python 可 `from math import gcd` 或手写三行循环。相邻值相等时 $\gcd(a, a) = a$；互质时为 1——都不需要特判。

### 3.4 指针走查

![指针走查：cur 跨两步前进](images/bw110_q2_pointer_walk.svg)

以 `[18, 6, 10, 3]` 为例：

```text
cur = 18：gcd(18, 6) = 6 → 18 → [6*] → 6 → 10 → 3，cur 跨到原结点 6
cur = 6 ：gcd(6, 10) = 2 → 6 → [2*] → 10 → 3，cur 跨到原结点 10
cur = 10：gcd(10, 3) = 1 → 10 → [1*] → 3，cur 跨到原结点 3
cur = 3 ：cur->next 为空，结束，返回 head
```

结果 `[18, 6, 6, 2, 10, 1, 3]` ✓。

## 4. 算法细节

1. **插入写法**：`new ListNode(g, cur->next)` 让新结点先挂好右指针，再 `cur->next = mid` 完成左挂——两步顺序颠倒也不出错（先用局部变量 `nxt` 暂存原右邻更稳妥）。
2. **指针推进两步**：`cur = mid->next`（跳过刚插入的结点）。若误写 `cur = cur->next`，下一轮就会对"原始结点与 gcd 结点"求 gcd，把链表越插越长（死循环或错误结果）。
3. **`std::gcd` 头文件**：C++ 记 `<numeric>`；值域 $\le 1000$，`int` 足够。
4. **复杂度无压力**：结点 5000 个、gcd 每次 $O(\log V)$，总计约 $5000 \times 10 = 5 \times 10^4$ 量级运算。
5. **就地修改的合法性**：`head` 本身不会变（插入都发生在 head 之后），直接返回 `head` 即可，不需要 dummy 结点。

## 5. 正确性证明

**引理 1（配对序列）**：设原链表结点值为 $a_1, a_2, \dots, a_n$。算法产生的结果链表为 $a_1, g_1, a_2, g_2, \dots, g_{n-1}, a_n$，其中 $g_i = \gcd(a_i, a_{i+1})$。

**证明**：对"cur 停留在原结点 $a_i$"归纳。$i = 1$ 时 `cur = head` ✓。设某轮 `cur` 在 $a_i$（$i < n$）：插入新结点 $g_i$ 于 $a_i$ 与 $a_{i+1}$ 之间，随后 `cur` 跨到 $a_{i+1}$（归纳结构保持：cur 始终指向原结点）。逐轮执行至 `cur = a_n`，其 `next` 为空终止。每对 $(a_i, a_{i+1})$ 恰被处理一次且插入恰在其间。$n = 1$ 时循环不执行，链表不变。∎

**定理**：返回链表满足题意——每两个相邻**原始**结点之间都恰插入一个值为二者 gcd 的结点，且无多余插入。

**证明**："相邻"在题意中指原链表的相邻（示例解释按原始序列逐对描述）。由引理 1，结果恰为原序列每对相邻处插入一个 gcd 结点，共 $n - 1$ 个新结点；插入结点之间不相邻（中间必隔着原结点），故不存在"对新结点再求 gcd"的多余插入。∎

## 6. 复杂度分析

- **时间**：$O(n \log V)$，$n$ 为链表长度，$V \le 1000$ 为值域上界；每对相邻结点一次 gcd，单次 gcd 由辗转相除的"两步减半"性质为 $O(\log V)$。本题规模下可视为 $O(n)$。
- **空间**：$O(1)$ 指针与临时变量；新链表占用 $O(n)$ 结点（输出本身所需，通常不计入额外空间）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    ListNode* insertGreatestCommonDivisors(ListNode* head) {
        for (ListNode* cur = head; cur->next != nullptr; ) {
            ListNode* mid = new ListNode(std::gcd(cur->val, cur->next->val), cur->next);
            cur->next = mid;                     // 插在 cur 与 cur->next 之间
            cur = mid->next;                     // 跳过新结点，处理下一对
        }
        return head;
    }
};
```

### Python

```python
class Solution:
    def insertGreatestCommonDivisors(self, head: Optional[ListNode]) -> Optional[ListNode]:
        def gcd(a: int, b: int) -> int:     # 辗转相除
            while b:
                a, b = b, a % b
            return a

        cur = head
        while cur.next:
            nxt = cur.next
            cur.next = ListNode(gcd(cur.val, nxt.val), nxt)
            cur = nxt                       # 跳过新结点，处理下一对
        return head
```

> 💡 两份代码均通过全部官方示例（`[18,6,6,2,10,1,3]`、`[7]`）；另做 2000 组随机链表（长度 $1\sim8$、值 $1\sim1000$）性质校验：结果长度 $2n-1$、奇数下标处与原值逐一相等、偶数下标处恰为相邻原值的 gcd，`mismatch = 0`。

## 8. 边界情况与易错点

1. **单结点链表**：`cur->next` 为空直接跳过循环，原样返回（示例 2）。
2. **指针只跨一步的 bug**：插入后 `cur = cur->next` 会停在新 gcd 结点上，下一对变成 `(gcd, 原结点)`，链表被反复插长。必须跨到原结点。
3. **丢失右邻**：先改 `cur->next` 再读 `cur->next->val` 会读到新结点。C++ 版先构造新结点（内部读旧 `cur->next`）再挂接，顺序安全；Python 版用 `nxt` 暂存。
4. **gcd(a, a) = a**：相邻两值相等（如 `[6, 6]`）插入的还是 6，不要特判跳过。
5. **无需 dummy 头结点**：head 永不被替换；若坚持用 dummy 也正确，只是多余。
6. **内存**：$n \le 5000$ 个 `new` 结点，无泄漏检查要求（LeetCode 不检查），本地长期运行可用 `unique_ptr` 管理。
