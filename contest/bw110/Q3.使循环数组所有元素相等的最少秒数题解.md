# LeetCode 使循环数组所有元素相等的最少秒数 题解

## 1. 题目概述

- **标题 / 题号**：使循环数组所有元素相等的最少秒数（#2808，medium）
- **链接**：https://leetcode.cn/problems/minimum-seconds-to-equalize-a-circular-array/
- **来源**：LeetCode 第 110 场双周赛 Q3
- **难度**：中等
- **标签**：数组、哈希表

**题意**：给定长度为 $n$ 的数组 `nums`（首尾相邻成环）。每一秒，**所有位置同时**把 $\mathrm{nums}[i]$ 替换成三者之一：$\mathrm{nums}[i]$、$\mathrm{nums}[(i-1+n) \bmod n]$、$\mathrm{nums}[(i+1) \bmod n]$（即自身、左邻、右邻，环上下标）。返回使所有元素相等所需的最少秒数。

**约束**：

- $1 \le n = \mathrm{nums.length} \le 10^5$
- $1 \le \mathrm{nums}[i] \le 10^9$

## 2. 示例

**示例 1**

```text
输入：nums = [1, 2, 1, 2]
输出：1
解释：第 1 秒每个位置各取 [nums[3], nums[1], nums[3], nums[3]]
（即位置 0、2 取右邻的 2），得 [2,2,2,2]。
```

**示例 2**

```text
输入：nums = [2, 1, 3, 3, 2]
输出：2
解释：两秒后可全部变成 3（题面给出了逐秒变换过程）。
```

**示例 3**

```text
输入：nums = [5, 5, 5, 5]
输出：0
解释：初始已全部相等。
```

## 3. 解题思路

### 3.1 暴力思路

把"每一秒 $3^n$ 种取值组合"全部枚举做 BFS——状态是整个数组，状态空间上界 $\prod(\text{值域})^n$，$n \ge 7$ 就爆炸；即使 $n$ 小到可以 BFS，也毫无推广性。正确的暴力视角是反过来问：**第 $t$ 秒时，位置 $q$ 的值可能来自哪里？**——这正是扩散模型。

### 3.2 核心观察：值以每秒 1 格的速度在环上扩散

![值在环上以每秒一格向两侧扩散](images/bw110_q3_spread_speed.svg)

**上界方向（值能到达哪）**：每个位置每秒只能"拉取"左邻、右邻或自身，因此 $t$ 秒后 $\mathrm{nums}[q]$ 的值必然来自某个初始环距 $\le t$ 的位置（对 $t$ 归纳：$t$ 秒的值来自 $t-1$ 秒时 $q$ 及其邻位，递归展开成以 $q$ 为中心、半径 $t$ 的环上圆盘）。

**下界方向（值怎样到达）**：某个值 $v$ 若在位置 $p$ 出现，则可以让 $v$ 像"感染"一样每秒向两侧各传播一格：距离 $p$ 为 $d$ 的位置，$d$ 秒后可以变成 $v$（该位置每秒向 $p$ 的方向拉取邻居即可，归纳构造）。**同时性无冲突**：不同位置的拉取互不干扰。

于是"全体变成 $v$" ⇔ 每个位置离**某个** $v$ 的初始出现处的环距 $\le t$，最短耗时由**离 $v$ 最远的位置**决定。又因操作只会复制已存在的值（上界方向），**最终相等值必然是数组中出现过的某个值**——只需枚举出现过的值。

### 3.3 聚合间隙：每个值只需看相邻出现的最大间隔

![相邻出现间隔 g 与 ⌊g/2⌋ 的关系](images/bw110_q3_gap_formula.svg)

设值 $v$ 的出现位置（升序）为 $p_1 < p_2 < \dots < p_k$，含**环绕间隔** $p_1 + n - p_k$，共 $k$ 个间隔 $g_1, \dots, g_k$。某个落在间隔 $g$ 正中间的位置，离两侧的 $v$ 都约 $\lfloor g/2 \rfloor$ 格，是最后被感染的位置，故：

$$\mathrm{time}(v) = \max_i \left\lfloor \frac{g_i}{2} \right\rfloor, \qquad \text{答案} = \min_v \mathrm{time}(v)$$

值只出现一次时唯一间隔为 $n$（绕一整圈）。用哈希表把每个值的下标配成升序列，一次线性扫描即可算完所有值。

### 3.4 示例演算

![两个官方示例的逐值间隔计算](images/bw110_q3_walkthrough.svg)

**示例 1** $[1,2,1,2]$：值 1 出现于 $\{0,2\}$，间隔 $2$ 与环绕 $0+4-2=2$，$\mathrm{time}(1)=1$；值 2 同理 $\mathrm{time}(2)=1$。答案 1。

**示例 2** $[2,1,3,3,2]$：值 2 出现于 $\{0,4\}$，间隔 $4$ 与环绕 $1$，$\mathrm{time}(2)=2$；值 1 出现于 $\{1\}$，间隔 $5$，$\mathrm{time}(1)=2$；值 3 出现于 $\{2,3\}$，间隔 $1$ 与环绕 $4$，$\mathrm{time}(3)=2$。答案 2。

## 4. 算法细节

1. **哈希表聚合下标**：`unordered_map<int, vector<int>>`（或 Python `dict` + `setdefault`）；下标按扫描顺序天然升序，无需排序。
2. **环绕间隔**：`ps[0] + n - ps.back()`——从最后一个出现位置绕过环尾回到第一个出现位置的距离，**最容易漏掉**；漏算会把"值聚在数组一端"的情况（如示例 2 的值 2）判松。
3. **答案初始化为 $n$**：任何值的最大间隔 $\le n$，故 $\lfloor g/2 \rfloor \le \lfloor n/2 \rfloor < n$（$n \ge 1$），用 $n$ 当上界必然被覆盖。
4. **整数除法**：`mx / 2` 在非负数上就是 $\lfloor \cdot / 2 \rfloor$。
5. **为什么枚举出现过的值就够**：$t$ 秒时任何位置的值都来自环距 $\le t$ 的初始位置（§3.2 上界方向），全体相等为 $v$ 时每个位置都需在半径 $t$ 内有 $v$ 的初始出现——不存在的值无法成为终值。
6. **哈希的键值范围**：$\mathrm{nums}[i] \le 10^9$，用哈希表而非数组计数。

## 5. 正确性证明

**引理 1（值的来源半径）**：$t$ 秒后任意位置 $q$ 的值，等于某个初始环距 $\mathrm{dist}(q, p) \le t$ 的位置 $p$ 的初始值。

**证明**：对 $t$ 归纳。$t=0$ 显然。设对 $t-1$ 成立。第 $t$ 秒时 $q$ 的值取自 $t-1$ 秒的 $q' \in \{q-1, q, q+1\}$（环上下标），而 $q'$ 的值来自初始环距 $\le t-1$ 的某位置 $p$；由三角不等式 $\mathrm{dist}(q, p) \le \mathrm{dist}(q, q') + \mathrm{dist}(q', p) \le 1 + (t-1) = t$。∎

**引理 2（扩散可达）**：若值 $v$ 初始出现于位置集 $S$，$d(q, S) = \min_{p \in S} \mathrm{dist}(q, p)$，则存在操作序列使 $t = d(q, S)$ 秒时 $q$ 处的值为 $v$；且该结论对所有 $q$ 同时成立。

**证明**：对 $t$ 归纳构造。$t = 0$：$q \in S$，保持自身值即可。设 $t-1$ 秒时所有 $d(\cdot, S) \le t-1$ 的位置均为 $v$。对 $d(q, S) = t$ 的位置：取 $S$ 的最近点 $p$（任一），沿 $q$ 到 $p$ 的最短环弧方向取邻居 $q'$，则 $d(q', S) \le t - 1$（最短路上一格更近），由归纳假设 $q'$ 处为 $v$，令 $q$ 拉取 $q'$。$d(q,S) < t$ 的位置拉取自身保持 $v$。各位置选取互不影响（值同时替换），故 $t$ 秒时结论成立。∎

**引理 3（最坏位置在中点）**：设 $v$ 的相邻出现（含环绕）间隔为 $g_1, \dots, g_k$，则 $\max_q d(q, S_v) = \max_i \lfloor g_i / 2 \rfloor$。

**证明**：环被 $S_v$ 的相邻出现切成长度 $g_i$ 的弧（两端端点是出现位置）。弧内非端点位置 $q$ 距两端分别为 $a$ 与 $g_i - a$（沿弧计），$d(q, S_v) = \min(a, g_i - a) \le \lfloor g_i / 2 \rfloor$（$a$ 与 $g_i - a$ 之一 $\le \lfloor g_i/2 \rfloor$）；取 $a = \lceil g_i / 2 \rceil$ 时取等。端点处距离为 0。而弧外的路径必经过端点，距离不小于沿本弧到端点的距离，故全局最大恰为 $\max_i \lfloor g_i / 2 \rfloor$。∎

**定理**：题意答案 $= \min_v \max_i \lfloor g_i(v) / 2 \rfloor$，其中 $v$ 取遍数组中出现过的值。

**证明**：全体在某时刻 $t$ 相等为值 $v$，由引理 1 每个位置 $q$ 都需 $d(q, S_v) \le t$（$q$ 处的 $v$ 必来自初始出现处），故 $t \ge \max_q d(q, S_v) = \mathrm{time}(v)$（引理 3）；由引理 2，取 $t = \mathrm{time}(v)$ 即可全体变 $v$。故 $\mathrm{time}(v)$ 是"全体变 $v$"的精确最短耗时，答案为全体候选值取 min。候选集恰为出现过的值（引理 1 亦排除未出现值）。∎

## 6. 复杂度分析

- **时间**：$O(n)$。一次扫描建哈希表；每个值遍历其下标列表一次，所有列表长度之和为 $n$。
- **空间**：$O(n)$。哈希表存全部下标（最坏所有值互不相同，退化为 $n$ 个单元素列表）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minimumSeconds(vector<int>& nums) {
        int n = (int)nums.size();
        unordered_map<int, vector<int>> pos;      // 每个值出现的所有下标（升序）
        for (int i = 0; i < n; ++i) pos[nums[i]].push_back(i);
        int ans = n;                              // 答案上界 ⌊n/2⌋ < n
        for (auto& [v, ps] : pos) {
            int mx = ps[0] + n - ps.back();       // 环绕间隔（最后一个回到第一个）
            for (int i = 1; i < (int)ps.size(); ++i)
                mx = max(mx, ps[i] - ps[i - 1]);  // 相邻出现位置的间隔
            ans = min(ans, mx / 2);               // 该值扩散耗时 = ⌊最大间隔/2⌋
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def minimumSeconds(self, nums: list[int]) -> int:
        n = len(nums)
        pos = {}
        for i, v in enumerate(nums):
            pos.setdefault(v, []).append(i)   # 每个值出现的下标（升序）
        ans = n
        for ps in pos.values():
            mx = ps[0] + n - ps[-1]           # 环绕间隔
            for a, b in zip(ps, ps[1:]):
                mx = max(mx, b - a)
            ans = min(ans, mx // 2)           # ⌊最大间隔/2⌋
        return ans
```

> 💡 两份代码均通过全部官方示例（`1`、`2`、`0`）；另与"逐秒枚举全部 $3^n$ 种取值组合、BFS 求最先全等时刻"的独立暴力做了 600 组随机对拍（$n \in [1,6]$、值域 $[1,3]$ 及 $n \in [1,8]$、值域 $[1,2]$），`mismatch = 0`；$n = 10^5$、值域 $10^9$ 的满规模实测约 10ms。

## 8. 边界情况与易错点

1. **环绕间隔必算**：`ps[0] + n - ps.back()`。它是"最后一个出现位置绕过环尾回到第一个出现位置"的距离，**最容易漏掉**。漏算的后果在出现位置聚在数组两端时最致命：如 $n=10$、某值仅出现于 $\{4,5\}$，内部间隔只有 1，环绕间隔却是 $4+10-5=9$，正确耗时 $\lfloor 9/2 \rfloor = 4$ 秒；漏掉环绕间隔会误得 0 秒。（示例 2 中值 2 的出现位置 $\{0,4\}$ 内部间隔 4 恰为主导，漏算侥幸不出错——这正是它容易被漏测的原因。）
2. **只出现一次的值**：唯一间隔为 $n$，耗时 $\lfloor n/2 \rfloor$；全部值都只出现一次时答案是 $\lfloor n/2 \rfloor$（如 $n = 10^5$ 全互异 → 49999/50000 量级）。
3. **$n = 1$**：单元素数组已经全等，环绕间隔 $0 + 1 - 0 = 1$，$\lfloor 1/2 \rfloor = 0$ ✓。
4. **"同时替换"不是"依次替换"**：不要按顺序一个一个改（那是链式传播，1 秒能传整条链，与题意不符）；本题操作是全并行快照式替换。
5. **答案上界初始化**：用 `ans = n` 而非 `INT_MAX` 无妨（必被覆盖），但别初始化成 0。
6. **值域大**：$\mathrm{nums}[i]$ 到 $10^9$，不能用计数数组，用哈希表。
