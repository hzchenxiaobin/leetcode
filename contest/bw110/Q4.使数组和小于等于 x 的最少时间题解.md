# LeetCode 使数组和小于等于 x 的最少时间 题解

## 1. 题目概述

- **标题 / 题号**：使数组和小于等于 x 的最少时间（#2809，hard）
- **链接**：https://leetcode.cn/problems/minimum-time-to-make-array-sum-at-most-x/
- **来源**：LeetCode 第 110 场双周赛 Q4
- **难度**：困难
- **标签**：数组、动态规划、排序

**题意**：给定等长数组 `nums1`、`nums2` 与整数 $x$。每一秒：先对所有下标 $i$ 执行 $\mathrm{nums1}[i] \mathrel{+}= \mathrm{nums2}[i]$；然后**可以选择**一个下标 $i$ 把 $\mathrm{nums1}[i]$ 置为 $0$（每秒至多一次，可不选）。返回使 $\mathrm{nums1}$ 的**元素和** $\le x$ 的最少秒数；无法实现返回 $-1$。

**约束**：

- $1 \le \mathrm{nums1.length} = \mathrm{nums2.length} \le 10^3$
- $1 \le \mathrm{nums1}[i] \le 10^3$
- $0 \le \mathrm{nums2}[i] \le 10^3$
- $0 \le x \le 10^6$

## 2. 示例

**示例 1**

```text
输入：nums1 = [1,2,3], nums2 = [1,2,3], x = 4
输出：3
解释：第 1/2/3 秒分别清零下标 0/1/2，末态 [2,2,0]，和为 4 ≤ 4。
不存在更短的方案。
```

**示例 2**

```text
输入：nums1 = [1,2,3], nums2 = [3,3,3], x = 4
输出：-1
解释：无论如何操作，和始终超过 x。
```

## 3. 解题思路

### 3.1 暴力思路

枚举每秒"不清零 / 清零哪个下标"，共 $(n+1)^t$ 条长度 $t$ 的操作序列——指数爆炸。哪怕只是回答"第 $t$ 秒末最小可能的和"也需要把操作的全部自由度压掉，这正是本题作为 Hard 的分水岭：需要三层观察逐级压缩——(1) 每个下标至多清零一次；(2) 清零时刻如何分配；(3) 选哪些下标交给 DP。

### 3.2 观察一：清零收益的公式，与"每下标至多一次"

![第 s 秒清零下标 i 的收益推导](images/bw110_q4_reset_saving.svg)

若下标 $i$ 在第 $s$ 秒末被清零且之后不再清零，则第 $t$ 秒末它的值为 $(t - s) \cdot \mathrm{nums2}[i]$（清零后每秒仍增长）。不清零则为 $\mathrm{nums1}[i] + t \cdot \mathrm{nums2}[i]$。两者之差即这一操作的**折抵**：

$$\mathrm{save}(i, s) = \mathrm{nums1}[i] + s \cdot \mathrm{nums2}[i]$$

**清得越晚省得越多**（勾掉的累积更多）。若同一下标清零两次，只有最后一次生效、第一次纯属浪费——故**最优解中每个下标至多清零一次**，且各次清零发生在**互不相同的秒**。

于是第 $t$ 秒末的总和可以写成：

$$S(t) = S_1 + t \cdot S_2 - \sum_{i \text{ 被清零于第 } s_i \text{ 秒}} \big(\mathrm{nums1}[i] + s_i \cdot \mathrm{nums2}[i]\big)$$

其中 $S_1 = \sum \mathrm{nums1}$、$S_2 = \sum \mathrm{nums2}$。**最小化 $S(t)$ ⇔ 最大化折抵和**。

### 3.3 观察二、三：按 nums2 排序分配时刻，"t 秒 = 清零 t 次"

![按 nums2 排序 + dp 模型](images/bw110_q4_sort_dp_model.svg)

给定清零下标集合 $I = \{i_1, \dots, i_k\}$（互不相同）与互异时刻集合 $A \subseteq \{1, \dots, t\}$（$|A| = k$），折抵和 $\sum (\mathrm{nums1}[i] + s_i \cdot \mathrm{nums2}[i])$ 如何最大化？

- **时刻集合取最大的 $k$ 个**（$t-k+1, \dots, t$）：折抵随 $s$ 递增，小时刻只会吃亏；
- **大时刻配大 nums2**（重排不等式）：若 $s_1 < s_2$ 分给 $b_1 > b_2$，交换二者使折抵增加 $(s_2 - s_1)(b_1 - b_2) > 0$。

再看"**用满 $t$ 秒**"：若 $t$ 秒内只清零 $k < t$ 次（挪到最后 $k$ 秒），则 $S(t) - S(k) = (t - k)\big(S_2 - \sum_{i \in I} \mathrm{nums2}[i]\big) \ge 0$——多等的那 $t - k$ 秒里，未被清零的下标也在涨，不会更省。所以**最优解里每秒都清零且互不重复，即 $t$ 秒 = 恰清零 $t$ 个下标**，$t \le n$；于是只需对每个 $t \in [0, n]$ 判定 $S_1 + t S_2 - D(t) \le x$，$D(t)$ 为"恰选 $t$ 个下标、按 nums2 升序依次安排在第 $1 \dots t$ 秒"的最大折抵。若存在可行方案，最小的可行 $t$ 必 $\le n$（否则取其清零集合缩减到 $k \le n$ 的方案更早可行）。

### 3.4 DP：$D(t)$ 的计算与示例演算

把下标按 $\mathrm{nums2}$ **升序**排列后，"第 $j$ 个被选中的"恰安排在第 $j$ 秒（保证大 nums2 吃大系数 $j$）：

$$\mathrm{dp}[i][j] = \max\big(\mathrm{dp}[i-1][j],\ \mathrm{dp}[i-1][j-1] + \mathrm{nums1}[i] + j \cdot \mathrm{nums2}[i]\big)$$

$D(t) = \mathrm{dp}[n][t]$。一维滚动（$j$ 倒序）即得全部 $D(0 \dots n)$。

![示例演算：dp 值与逐 t 判定](images/bw110_q4_walkthrough.svg)

以示例 1（$\mathrm{nums1} = \mathrm{nums2} = [1,2,3]$，$x=4$）演算：$S_1 = S_2 = 6$；$\mathrm{dp}$ 逐层算得 $D(1) = 6$、$D(2) = 13$、$D(3) = 20$。逐 $t$ 判定 $6 + 6t - D(t) \le 4$：$t=0$ 得 $6$、$t=1$ 得 $6$、$t=2$ 得 $5$、$t=3$ 得 $4$ ✓。答案 3。

## 4. 算法细节

1. **排序稳定性无关紧要**：$\mathrm{nums2}$ 相等时谁吃哪个系数 $j$ 不影响该组折抵总和（$\sum j \cdot b$ 对同 $b$ 的分组置换不变），tie 随意。
2. **滚动方向**：转移用到 $\mathrm{dp}[i-1][j-1]$，故 $j$ 必须从 $i$ **倒序**到 1，防止本层新值被当作上层值使用；`dp[0] = 0` 恒定（一个都不选）。
3. **"恰选 $j$ 个"的可达性**：$\mathrm{dp}[j]$ 首次在 $i = j$ 层被真正填入（此前保持 0 也无害：$j \le i$ 时转移链上每层的 $\mathrm{dp}[j-1]$ 都是可达真值），最终 $\mathrm{dp}[t]$ 即 $D(t)$。
4. **答案枚举顺序**：$t$ 从 0 到 $n$ 升序，首个满足者即答案（可行性不随 $t$ 单调，但"最小可行时刻"的定义就是首个）；全不满足返回 $-1$。
5. **长整型**：$t \cdot S_2 \le 10^3 \cdot 10^6 = 10^9$，加 $S_1$ 后贴着 `int` 上限；$D(t) \le \sum (\mathrm{nums1} + n \cdot \mathrm{nums2}) \approx 10^9$ 同级。C++ 用 `long long` 稳妥（Python 天然大整数）。
6. **别忘 $t = 0$**：初始和 $S_1 \le x$ 时答案为 0（$x = 0$ 且全清场景外最常见边界）。

## 5. 正确性证明

**引理 1（重复清零可消除）**：任一操作序列都存在另一序列：每个下标恰在其**最后一次**清零时刻清零一次，且第 $t$ 秒末每个下标的值不变。

**证明**：第 $t$ 秒末下标 $i$ 的值只取决于其最后一次清零时刻 $s_i$（之后线性增长 $(t-s_i) b_i$）或"从未清零"。删去所有非最后一次的清零（该秒改为不操作），各下标末值不变。∎

**引理 2（时刻与配对的重排最优）**：设清零集合 $I$（$|I| = k$）固定，折抵和的最大值在"时刻取 $\{t-k+1, \dots, t\}$、按 $\mathrm{nums2}$ 升序依次分配"时取到。

**证明**：折抵 $\mathrm{nums1}[i] + s_i b_i$ 中 $s_i$ 系数为正，故时刻集合任一元素换为更大值不减少折抵，最优必取可用时刻中最大的 $k$ 个。固定时刻集合后，$\sum s_i b_i$ 的配对由重排不等式：若 $s_1 < s_2$ 配 $b_1 > b_2$，交换得变化量 $(s_2 - s_1)(b_1 - b_2) > 0$，故最优配对为同序。∎

**引理 3（用满每秒）**：对任意 $t$ 与 $k < t$ 的方案，存在 $k$ 秒的方案使末和不增：$S(t) \ge S(k)$ 对最优折抵成立。

**证明**：取 $t$ 秒最优方案，由引理 1、2 设其清零集合 $I$（$|I| = k$）折抵为 $\sum_{j} (\mathrm{nums1}[i_j] + (t - k + j) b_{i_j})$（$i_j$ 按 $b$ 升序）。构造 $k$ 秒方案：同一 $I$、第 $j$ 个清零于第 $j$ 秒，折抵 $\sum_j (\mathrm{nums1}[i_j] + j\, b_{i_j})$，差恰为 $(t - k) \sum_{i \in I} b_i$。于是 $S(t) - S(k) = (t-k)\big(S_2 - \sum_{i \in I} b_i\big) \ge 0$（$I$ 的 nums2 之和不超过全体和 $S_2$）。∎

**推论**：若存在某 $t > n$（或任意 $t$）使 $S(t) \le x$，则存在 $k \le n$ 使 $S(k) \le x$；故答案要么是 $[0, n]$ 中最小可行 $t$，要么为 $-1$。∎

**引理 4（DP 正确）**：$\mathrm{dp}[i][j]$ = 从前 $i$ 个（按 nums2 升序）下标中恰选 $j$ 个、按序安排在第 $1 \dots j$ 秒的最大折抵。

**证明**：对 $i$ 归纳。$i = 0$：仅 $j = 0$ 取 0 ✓。设前 $i-1$ 层成立。第 $i$ 个下标（升序中最大）若被选，它在选中集合中排位**恰为第 $j$**（后面没有更大元素，前面恰有 $j-1$ 个更小的选中元素），贡献 $\mathrm{nums1}[i] + j \cdot \mathrm{nums2}[i]$；不选则继承 $\mathrm{dp}[i-1][j]$。转移取 max 覆盖两种情况，且由引理 2，"选中的都按升序吃系数 $1..j$"正是最优配对结构。∎

**定理**：算法返回值即题意答案。

**证明**：由引理 4，$D(t) = \mathrm{dp}[n][t]$ 是"恰清零 $t$ 个下标"的最大折抵；由引理 2，$S_1 + t S_2 - D(t)$ 是恰用 $t$ 秒（每秒一清）可达的最小末和。可行时刻的最小值 $t^*$：由引理 3 推论 $t^* \le n$（若可行），故升序枚举 $t \in [0, n]$ 首个满足 $S_1 + t S_2 - D(t) \le x$ 者即 $t^*$；全不满足则不可行，返回 $-1$。∎

## 6. 复杂度分析

- **时间**：$O(n^2)$。排序 $O(n \log n)$，DP 双层循环 $\sum_{i=1}^{n} i = O(n^2) \approx 5 \times 10^5$（$n \le 10^3$），最后线性枚举 $t$。
- **空间**：$O(n)$。一维滚动 dp（排序下标数组另占 $O(n)$）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minimumTime(vector<int>& nums1, vector<int>& nums2, int x) {
        int n = (int)nums1.size();
        vector<int> idx(n);
        iota(idx.begin(), idx.end(), 0);
        sort(idx.begin(), idx.end(), [&](int a, int b) { return nums2[a] < nums2[b]; });

        long long s1 = accumulate(nums1.begin(), nums1.end(), 0LL);
        long long s2 = accumulate(nums2.begin(), nums2.end(), 0LL);

        // dp[j]：按 nums2 升序考察前 i 个位置、恰选 j 个清零的最大折抵
        vector<long long> dp(n + 1, 0);
        for (int i = 1; i <= n; ++i) {
            int id = idx[i - 1];
            long long a = nums1[id], b = nums2[id];
            for (int j = i; j >= 1; --j)          // 滚动数组：j 倒序
                dp[j] = max(dp[j], dp[j - 1] + a + (long long)j * b);
        }
        for (int t = 0; t <= n; ++t)              // t 秒 = 恰好清零 t 个
            if (s1 + (long long)t * s2 - dp[t] <= x) return t;
        return -1;
    }
};
```

### Python

```python
class Solution:
    def minimumTime(self, nums1: list[int], nums2: list[int], x: int) -> int:
        n = len(nums1)
        idx = sorted(range(n), key=lambda i: nums2[i])   # 按 nums2 升序
        s1, s2 = sum(nums1), sum(nums2)

        dp = [0] * (n + 1)     # dp[j]: 前 i 个位置恰选 j 个清零的最大折抵
        for i in range(1, n + 1):
            a, b = nums1[idx[i - 1]], nums2[idx[i - 1]]
            for j in range(i, 0, -1):        # 滚动数组：j 倒序
                dp[j] = max(dp[j], dp[j - 1] + a + j * b)

        for t in range(n + 1):               # t 秒 = 恰好清零 t 个
            if s1 + t * s2 - dp[t] <= x:
                return t
        return -1
```

> 💡 两份代码均通过全部官方示例（`3`、`-1`）；另与"枚举每秒 清零/不操作/清零哪个下标 的全部操作序列、逐 $t$ 判定"的独立暴力做了 600 组随机对拍（$n \in [1,4]$、含 $\mathrm{nums2}[i] = 0$、$x \in [0,40]$，暴力枚举到 $t = n+2$ 以验证"答案 $\le n$ 或 $-1$"），`mismatch = 0`；$n = 1000$ 满规模实测 $O(n^2)$ 仅数毫秒。

## 8. 边界情况与易错点

1. **$t = 0$ 别漏**：初始和已 $\le x$ 时答案 0；dp 循环前直接先判，或统一放进末尾的 $t$ 枚举（本文代码即后者）。
2. **int 溢出**：$t \cdot S_2$ 可达 $10^9$，$S_1 + t S_2$、$D(t)$ 同为 $10^9$ 量级，C++ 全程 `long long`（`accumulate` 初值写 `0LL`，否则按 `int` 累加会溢出）。
3. **nums2 可为 0**：清零这种下标收益恒为 $\mathrm{nums1}[i]$、不随时刻变化；排序后它们排最前吃系数 1，DP 自然处理，无需特判。
4. **滚动方向错了变"完全背包"**：$j$ 正序会让 $\mathrm{dp}[j-1]$ 读到本层新值，等于允许"同一时刻系数被重复吃"，答案偏大。
5. **$\mathrm{nums2}$ 相等时的顺序**：谁先谁后不影响折抵总和（§4.1），不要为 tie 写复杂比较器。
6. **"答案可能超过 $n$"是错觉**：引理 3 说明等更久不会更省；若担心，可用 $t > n$ 的暴力对拍验证（本文对拍即如此）。
7. **-1 的判定**：必须把 $t = 0 \dots n$ **全部**判完才能返回 $-1$；中途 `break` 只用于已找到答案。
