# LeetCode K 条边路径的最大边权和 题解

## 1. 题目概述

- **标题 / 题号**：K 条边路径的最大边权和（#3543，medium）
- **链接**：https://leetcode.cn/problems/maximum-weighted-k-edge-path/
- **来源**：LeetCode 第 156 场双周赛 Q3
- **难度**：中等
- **标签**：图、哈希表、动态规划

**题意**：给定 $n$ 个节点的 DAG，边 `edges[i] = [u_i, v_i, w_i]`。再给整数 `k` 与 `t`。求一条满足下面两个条件的路径的最大边权和：

1. 路径**恰好包含 $k$ 条边**；
2. 路径的边权和**严格小于 $t$**。

不存在这样的路径时返回 $-1$。路径的起点与终点可以是任意节点。

**约束**：

- $1 \le n \le 300$，$0 \le \text{edges.length} \le 300$
- $0 \le k \le 300$，$1 \le t \le 600$，$1 \le w_i \le 10$
- 输入是 DAG，无重边

注意 $t \le 600$ 这个数字很关键：**任何可行的路径边权和都小于 600**，而 $w_i\ge 1$，所以可行路径的边数也不会超过 599——搜索空间被 $t$ 卡住了。

## 2. 示例

**示例 1**

```text
输入：n = 3, edges = [[0,1,1],[1,2,2]], k = 2, t = 4
输出：3
解释：唯一 2 条边的路径是 0→1→2，权和 1+2=3 < 4。
```

**示例 2**

```text
输入：n = 3, edges = [[0,1,2],[0,2,3]], k = 1, t = 3
输出：2
解释：0→1 权和 2 < 3 可行；0→2 权和 3 = t 不满足严格小于，被排除。
```

**示例 3**

```text
输入：n = 3, edges = [[0,1,6],[1,2,8]], k = 1, t = 6
输出：-1
解释：0→1 权和 6 = t 不合格，1→2 权和 8 > t，没有可行路径。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有路径：从每个节点出发 DFS，每走一条边记录当前权和，走到恰好 $k$ 条边时判断权值和是否 $<t$。DAG 中路径总数可以是指数级的（例如分层完全图），$n=300$ 时完全不可行。

另一种「看起来聪明」的暴力是：只记录每个节点「当前最小权值和」或「最大权值和」，但那会丢掉「恰好 $k$ 条边」的信息，也无法处理「和必须 $<t$」的剪枝——同一个节点用不同的和到达，后续能扩展出的结果不同，必须把**和**作为状态的一部分。

### 3.2 核心观察：把「可达的和」当作状态，并用位掩码压缩

![按边数分层：dp[e][v] = 恰好 e 条边、终点 v 的可行边权和集合](images/bw156_q3_layer_dp.svg)

由于 $t\le 600$，可行的边权和只可能是 $0,1,\dots,t-1$ 这至多 600 种整数。定义

$$\text{dp}[e][v] = \{\, s : \text{存在一条恰含 } e \text{ 条边、终点为 } v \text{ 的路径，权和为 } s \,\}$$

初始时（$0$ 条边）任何节点都可以作为起点，故 $\text{dp}[0][v]=\{0\}$ 对所有 $v$ 成立。转移就是「走一条边」：

$$\text{dp}[e+1][v] \supseteq \{\, s + w : s\in \text{dp}[e][u],\ (u,v,w)\in E \,\}$$

并且立刻丢弃 $\ge t$ 的和（它们永远不可能再变小）。

因为状态集合始终是 $[0,t)$ 的子集，可以用一个整数当**位集**：第 $s$ 位为 1 表示和 $s$ 可达。于是「整体加上 $w$」就是左移 $w$ 位，「丢弃 $\ge t$」就是与 $(1\ll t)-1$ 做按位与。一次边转移 $O(t/64)$（Python 的大整数按字并行，更快）。

### 3.3 算法流程

```text
1. 若 k == 0：返回 0（空路径，权和 0 < t 恒成立）
2. allow = (1 << t) - 1                      // 只保留 [0, t) 的位
3. cur[v] = 1 对所有权 v                      // 0 条边、和为 0
4. 重复 k 轮：
       nxt[v] = 0
       for (u, v, w) in edges:
           nxt[v] |= (cur[u] << w) & allow
       cur = nxt
5. best = max{ s : cur[v] 的第 s 位为 1 }，若全空返回 -1
6. 返回 best
```

只需要两层（`cur` 与 `nxt`），因为第 $e+1$ 层只依赖第 $e$ 层；DAG 保证不会出现「同一条边被反复利用」的环状依赖。

### 3.4 示例演算

![示例 1：0→1(1)、1→2(2)，k = 2，t = 4](images/bw156_q3_example_walkthrough.svg)

以示例 1 为例（$k=2,\ t=4$，位集只保留 $0,1,2,3$）：

| 层 $e$ | 节点 0 | 节点 1 | 节点 2 |
|--------|--------|--------|--------|
| 0 条边 | `{0}` | `{0}` | `{0}` |
| 1 条边 | `∅` | `{0+1}={1}` | `∅` |
| 2 条边 | `∅` | `∅` | `{1+2}={3}` |

最终所有集合中最大的可达和是 3，且 $3<4$，故返回 3。注意第 1 层节点 2 为空：没有哪条边以 2 为终点且走一条边可达。

## 4. 算法细节

1. **初始化的含义**：`dp[0][v] = {0}` 对所有 $v$ 成立，表示「以 $v$ 为起点、走 0 条边」是合法的。这正好对应示例 2 中 0 条边与 1 条边路径各自计数，起点不受限制。
2. **位集实现**：C++ 用 `bitset<601>`（$t\le 600$，留一位余量），`(cur[u] << w) & allow` 一步完成「加 $w$ + 截断」；Python 用整数位掩码，`(cur[u] << w) & allow` 完全对应。
3. **`allow` 的作用**：`(1<<t)-1` 恰好保留第 $0\sim t-1$ 位，即所有 $<t$ 的和；不移除的话，超界和被当作可达会导致答案错误（示例 2 的 3、示例 3 的 6 都会被误判）。
4. **严格小于**：是 $<t$ 不是 $\le t$，所以 `allow` 只到 $t-1$ 位。
5. **轮数**：外层固定循环 $k$ 次，每轮遍历所有边；$k$ 可能为 0，需提前返回。
6. **答案提取**：对每个节点的位集取最高位（`bit_length()-1` 或从 $t-1$ 向下找第一个置位），再对所有节点取最大。

## 5. 正确性证明

**引理 1（状态精确）**：对任意 $e\ge 0$ 与节点 $v$，第 $e$ 轮结束时 $\text{dp}[e][v]$ 恰好等于「所有恰含 $e$ 条边、终点为 $v$、且权和 $<t$ 的路径的权和」构成的集合。

**证明**：对 $e$ 归纳。$e=0$ 时只有空路径，权和 0，$\text{dp}[0][v]=\{0\}$ 正确。设对 $e$ 成立，任取一条恰含 $e+1$ 条边、终点 $v$ 的路径 $P$，设其最后一条边为 $(u,v,w)$，则 $P$ 去掉该边是恰含 $e$ 条边、终点 $u$、权和 $s'$ 的路径，且 $s' = s - w \le s < t$，由归纳假设 $s'\in\text{dp}[e][u]$，故 $s = s'+w$ 通过转移进入 $\text{dp}[e+1][v]$（因为 $s<t$，未被 `allow` 截掉）。反过来，任何被加入 $\text{dp}[e+1][v]$ 的 $s$ 都来自某条边 $(u,v,w)$ 与某个 $s'\in\text{dp}[e][u]$，由归纳假设存在对应路径，接上这条边即得权和 $s$、$e+1$ 条边的路径。∎

**引理 2（位集运算等价）**：设整数 $B$ 的第 $s$ 位表示 $s\in S$，则 `(B << w) & allow` 的第 $s$ 位为 1 当且仅当 $s\ge w$ 且 $s-w\in S$ 且 $s<t$，即恰好表示 $\{s+w : s\in S,\ s+w<t\}$ 的位集。

**证明**：左移 $w$ 位把第 $s-w$ 位移到第 $s$ 位；`allow = (1<<t)-1` 把第 $t$ 位及以上的位清零，只保留 $s<t$。两者都是逐位操作，故等价。∎

**定理**：算法返回的值等于满足条件的最大边权和，若不存在则返回 $-1$。

**证明**：由引理 1（归纳到第 $k$ 轮），$\bigcup_v \text{dp}[k][v]$ 恰为所有「恰含 $k$ 条边且权和 $<t$」的路径权和集合；由引理 2，位集实现与集合转移等价。答案就是该集合的最大元素：非空时取最大即得，为空时返回 $-1$，与题意一致。$k=0$ 时空路径权和为 0，$0<t$ 恒成立，返回 0 正确。∎

## 6. 复杂度分析

- **时间**：$k$ 轮，每轮遍历 $|E|$ 条边，每条边做一次「左移 + 与 + 或」，位集长度 $t$ 位，故 $O\big(k\cdot|E|\cdot t/64\big)$。取上限 $300\times300\times600/64\approx 8.4\times10^5$ 次字操作，非常快；即使按集合实现也是 $O(k\cdot|E|\cdot t)$ 的 $5.4\times10^7$ 量级（Python 下偏慢，故用位集）。
- **空间**：两层位集，每层 $n$ 个长度为 $t$ 的位集，$O(n\cdot t/64)$；边的存储 $O(|E|)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maxWeight(int n, vector<vector<int>>& edges, int k, int t) {
        if (k == 0) return 0;
        bitset<601> allow;
        for (int s = 0; s < t; s++) allow.set(s);

        vector<bitset<601>> cur(n), nxt(n);
        for (int v = 0; v < n; v++) cur[v].set(0);

        for (int step = 0; step < k; step++) {
            for (int v = 0; v < n; v++) nxt[v].reset();
            for (auto& e : edges) {
                int u = e[0], v = e[1], w = e[2];
                nxt[v] |= (cur[u] << w) & allow;
            }
            cur.swap(nxt);
        }

        int best = -1;
        for (int v = 0; v < n; v++) {
            for (int s = t - 1; s >= 0; s--) {
                if (cur[v].test(s)) {
                    if (s > best) best = s;
                    break;
                }
            }
        }
        return best;
    }
};
```

### Python

```python
class Solution:
    def maxWeight(self, n: int, edges: list[list[int]], k: int, t: int) -> int:
        if k == 0:
            return 0
        allow = (1 << t) - 1          # 只保留和 < t 的位
        cur = [1] * n                 # 0 条边、和为 0：任何节点都可作为起点

        for _ in range(k):
            nxt = [0] * n
            for u, v, w in edges:
                nxt[v] |= (cur[u] << w) & allow
            cur = nxt

        best = -1
        for bits in cur:
            if bits:
                best = max(best, bits.bit_length() - 1)
        return best
```

## 8. 边界情况与易错点

1. **`k = 0`**：空路径权和为 0，且 $t\ge 1>0$ 恒成立，答案 0。忘了特判会让位集从 $\{0\}$ 出发、最后一层仍是 $\{0\}$，其实也能得到 0，但代码里多一轮循环；显式特判更清晰。
2. **`t` 与严格小于**：必须 `< t`。示例 2 中权和恰为 $t$ 的 0→2 必须排除，若写成 `<= t`（`allow` 开到第 $t$ 位）就会错答 3。
3. **路径起点不固定**：`dp[0][v] = {0}` 对所有 $v$ 成立，别只初始化节点 0，否则「从中间节点出发的路径」全被漏掉。
4. **边权和不降**：$w\ge1$，所以和单调递增，一旦超过 $t$ 就永远无法回头，`allow` 的截断就是合法的剪枝；若边权可为负，这套剪枝会失效。
5. **图是 DAG 才能分层**：若存在环，「恰好 $k$ 条边」仍可定义（允许重复走），但本做法的转移依然成立（因为它按边数分层、不依赖拓扑序）；不过题面保证 DAG，无需考虑。
6. **`bitset` 大小**：C++ 中 `bitset<601>` 的位移会丢弃高位，配合 `allow` 已足够；若把 $t$ 上限放大，记得同步放大模板参数。
7. **答案不存在**：所有位集为空时返回 $-1$（示例 3）。
