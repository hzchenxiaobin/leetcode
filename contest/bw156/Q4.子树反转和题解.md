# LeetCode 子树反转和 题解

## 1. 题目概述

- **标题 / 题号**：子树反转和（#3544，hard）
- **链接**：https://leetcode.cn/problems/subtree-inversion-sum/
- **来源**：LeetCode 第 156 场双周赛 Q4
- **难度**：困难
- **标签**：树、深度优先搜索、数组、动态规划

**题意**：给定一棵以 0 为根、$n$ 个节点的树，节点 $i$ 的值为 `nums[i]`。你可以选择一些节点执行**反转操作**：反转节点 $v$ 时，以 $v$ 为根的**整棵子树**内所有值乘以 $-1$。约束是：

> 若被反转的两个节点 $a,b$ 中一个是另一个的祖先，则它们之间的**距离（路径边数）必须至少为 $k$**。

不同分支之间（互不为祖先）没有约束。求操作后树上所有节点值的**最大可能总和**。

**约束**：

- $2 \le n \le 5\times 10^4$，`edges` 是合法的树
- $-5\times 10^4 \le \text{nums}[i] \le 5\times 10^4$
- $1 \le k \le 50$

注意答案量级：$n\cdot\lvert\text{nums}\rvert = 2.5\times 10^9$，**超过 32 位整数**，必须用 64 位。

     nums = [4,-8,-6,3,7,-2,5], k = 2
输出：27
解释：反转 0、3、4、6。0 反转使全部变号 → [-4,8,6,-3,-7,2,-5]；
     再反转 3、4、6 各自把 -3、-7、-5 翻回正 → [-4,8,6,3,7,2,5]，和 27。
     检查距离：0-3、0-4、0-6 的距离都是 2 ≥ k = 2。
```

```

## 3. 解题思路

### 3.1 暴力思路

反转方案共 $2^n$ 种，$n=5\times10^4$ 时不可能枚举。即使只枚举「合法」的方案，数量依然指数级。

还有两个观察可以化简问题：

1. 同一节点反转两次等于没反转（子树内符号翻转两次回到原值），而「两个反转节点距离 0 < k」本来也不合法，所以每个节点只需考虑**反转 / 不反转**两种状态——这是一个 0/1 选择问题；
2. 一个节点的最终值只取决于**根到它的路径上**有多少个被反转的节点（含它自己），与别的分支无关。

### 3.2 核心观察：只记住「最近的反转祖先」与奇偶

![状态：(奇偶 p, 到最近已反转祖先的距离 d，封顶 k)](images/bw156_q4_state_design.svg)

**观察一（值的形态）**：对节点 $v$，最终值 $= \text{nums}[v]\cdot(-1)^{c(v)}$，其中 $c(v)$ 是根到 $v$ 路径上（含 $v$）被反转节点的个数。所以只关心 $c(v)$ 的**奇偶** $p$。

**观察二（约束的等价形式）**：设 $v$ 的所有已反转祖先为 $a_1,\dots,a_m$，约束要求对每个 $a_i$ 都有 $\text{dist}(a_i,v)\ge k$，这等价于

$$\min_i \text{dist}(a_i,v) \ \ge\ k$$

也就是**离 $v$ 最近的那个已反转祖先**满足距离 $\ge k$。所以我们只需要携带一个量：$d=$ 到最近已反转（真）祖先的距离，并把它**封顶在 $k$**（$d=k$ 表示「至少 $k$」，此时允许反转 $v$）。

由此定义树形 DP：

$$\text{dp}[v][p][d] = \text{在「$v$ 的祖先中已反转个数奇偶为 } p\text{、到最近已反转祖先距离封顶为 } d\text{」的前提下，}v\text{ 的子树能贡献的最大值和}$$

其中 $d\in\{0,1,\dots,k\}$，$d=k$ 含义是「距离 $\ge k$ 或不存在已反转祖先」。

![每个状态只有两种选择](images/bw156_q4_transition.svg)

**转移**：对 $v$ 的两种选择取较大者，两个分支里每个儿子 $c$ 的贡献都查表得到：

- **不反转 $v$**：$v$ 自身贡献 $\text{nums}[v]\cdot(-1)^p$；儿子的状态是 $(p,\ \min(d+1,k))$；
- **反转 $v$**（仅当 $d=k$）：$v$ 自身贡献 $-\text{nums}[v]\cdot(-1)^p$；儿子的状态是 $(p\oplus1,\ 1)$。

$$\text{dp}[v][p][d]=\max\begin{cases}\text{nums}[v](-1)^p+\sum_{c}\text{dp}[c][p][\min(d+1,k)]\\[2pt] -\text{nums}[v](-1)^p+\sum_{c}\text{dp}[c][p\oplus1][1]\quad(d=k)\end{cases}$$

根节点没有祖先，取 $(p,d)=(0,k)$，答案即 $\text{dp}[0][0][k]$。

### 3.3 算法流程

```text
1. 建邻接表，从 0 出发 BFS 得到 parent[] 与 BFS 序 order[]（父在子之前）
2. 令 D = k+1；用 S[u][p*D+d] 累计「u 的所有儿子在状态 (p,d) 下的 dp 之和」，初值 0
3. 按 order 的逆序（子先父后）处理每个节点 v：
       a. dp[v][p][d] = max( 不反转分支, 反转分支（若 d == k） )，两个分支都用 S[v] 求和
       b. 若 v 不是根：把 dp[v][*] 逐项加到 S[parent[v]][*] 上
4. 根节点处返回 dp[0][0*D + k]
```

用「逆 BFS 序 + 累加到父节点」代替递归，既能避开 $5\times10^4$ 深度的递归爆栈，也能在处理完一个节点后立刻释放它的状态。

### 3.4 示例演算

![示例 1：反转 0、3、4、6，总和 27](images/bw156_q4_example_walkthrough.svg)

对示例 1（$k=2$，树为 0 的两个孩子 1、2；1 的孩子 3、4；2 的孩子 5、6），选择 $\{0,3,4,6\}$：

| 节点 | 原值 | 反转祖先（含自身）个数 | 最终值 |
|------|------|------------------------|--------|
| 0 | 4 | 1（0） | −4 |
| 1 | −8 | 1（0） | 8 |
| 2 | −6 | 1（0） | 6 |
| 3 | 3 | 2（0,3） | 3 |
| 4 | 7 | 2（0,4） | 7 |
| 5 | −2 | 1（0） | 2 |
| 6 | 5 | 2（0,6） | 5 |

总和 $-4+8+6+3+7+2+5=27$。所有「祖先-后代」反转对的距离都是 2，满足 $k=2$；而 3 与 4、5 与 6 等互不为祖先，不受约束。

## 4. 算法细节

1. **距离封顶**：$d$ 只需 $0\sim k$ 共 $k+1$ 个取值。封顶后「$d+1$」写作 `min(d+1,k)`，保证下标不越界，同时语义仍是「至少 $k$」。
2. **反转条件**：`d == k`。因为 $d<k$ 表示最近已反转祖先距离不足 $k$，此时反转 $v$ 会违反约束；$d=k$ 涵盖「没有已反转祖先」与「距离 $\ge k$」两种情况。
3. **儿子求和表 $S$**：$S[u][p\cdot D+d]=\sum_{c}\text{dp}[c][p][d]$。这样计算 $\text{dp}[u]$ 时只需两次查表（不反转分支查 $S[u][p][\min(d+1,k)]$，反转分支查 $S[u][p\oplus1][1]$），避免对每个状态重新遍历儿子，把总代价压到 $O(nk)$。
4. **奇偶的含义**：$p$ 统计的是**真祖先**（不含 $v$）的反转次数奇偶；$v$ 自身的翻转在转移里用「取负」体现。写代码时不要重复计算 $v$ 自己。
5. **逆序处理**：BFS 序保证父先于子，逆序遍历即子先于父；每个节点算完就并入父节点的 $S$，因此不需要保存所有 $n$ 个节点的完整 DP 表（Python 版用一个 `dict` 只保留尚未处理完的父节点）。
6. **负数与初值**：`dp` 值可能为负，不能用 0 当初值；实现里每个状态都显式由分支计算得出，或把初值设为 $-\infty$ 再取 max。
7. **64 位**：$n\cdot\lvert\text{nums}\rvert$ 可达 $2.5\times10^9$，C++ 必须 `long long`，Python 无此问题。

## 5. 正确性证明

**引理 1（值的形态）**：设 $S$ 为被反转的节点集合，则节点 $v$ 的最终值为 $\text{nums}[v]\cdot(-1)^{\lvert S\cap \text{path}(0,v)\rvert}$，其中 $\text{path}(0,v)$ 是根到 $v$ 的节点集合。

**证明**：反转 $u$ 会把 $u$ 子树内所有节点的值乘 $-1$，而 $v$ 属于 $u$ 的子树当且仅当 $u$ 是 $v$ 的祖先或 $u=v$，即 $u\in\text{path}(0,v)$。各次反转的影响相乘，符号为 $(-1)^{\lvert S\cap\text{path}(0,v)\rvert}$。∎

**引理 2（约束等价）**：一组选择 $S$ 合法，当且仅当对每个 $v\in S$，设 $a$ 是 $v$ 的**最近**已反转祖先（存在时），则 $\text{dist}(a,v)\ge k$。

**证明**：必要性：$a$ 是已反转祖先之一，题面要求所有已反转祖先对的距离都 $\ge k$，故 $\text{dist}(a,v)\ge k$。充分性：任取已反转祖先 $a'$ 与 $v\in S$，由「最近」的定义 $\text{dist}(a,v)\le\text{dist}(a',v)$，故 $\text{dist}(a',v)\ge k$；互不为祖先的节点对题面不施加约束，因此所有约束满足。∎

**引理 3（状态充分）**：给定 $(p,d)$ 与节点 $v$，$v$ 子树内可达到的最优总和只依赖 $(p,d)$，即 $\text{dp}[v][p][d]$ 的定义是良定义且完备的。

**证明**：由引理 1，$v$ 自身及子树的符号翻转只由「$v$ 的祖先中已反转个数奇偶」决定，与祖先的具体身份无关；由引理 2，$v$ 及其后代能否再反转只由「到最近已反转祖先的距离」决定，而该距离可由 $d$ 与后续选择递推得到（每下一层 $+1$，封顶 $k$）。不同分支的约束互不交叉（互不为祖先），因此子树之间可以独立取最优。∎

**引理 4（转移正确）**：对树的高度归纳，$\text{dp}[v][p][d]$ 等于「在 $(p,d)$ 前提下 $v$ 子树的最大贡献」。

**证明**：叶节点：两个分支的「儿子贡献和」为空（0），故 $\text{dp}[v][p][d]=\max$ 取到自身的两种贡献，正确。设对所有儿子成立。任一合法方案在 $v$ 处只有两种可能：不反转（$v$ 贡献 $\text{nums}[v](-1)^p$，儿子状态 $(p,\min(d+1,k))$）或反转（仅 $d=k$ 时合法，$v$ 贡献 $-\text{nums}[v](-1)^p$，儿子状态 $(p\oplus1,1)$）。由归纳假设，儿子的最优贡献恰为对应 $S$ 项；方案在各子树间独立，故总和即为「自身贡献 + 儿子最优和」。算法对两种可能取 max，恰好枚举了全部合法方案，故取到最大值。∎

**定理**：$\text{dp}[0][0][k]$ 等于题目要求的最大总和。

**证明**：根没有祖先，故 $p=0$、$d=k$（「距离 $\ge k$」视为满足，可以反转根）。由引理 3、4，$\text{dp}[0][0][k]$ 覆盖所有合法选择下的最大总和；由引理 2，合法选择恰好是满足约束的选择。故它就是答案。∎

## 6. 复杂度分析

- **时间**：状态数 $n\cdot 2\cdot(k+1)$；每个状态计算需 $O(1)$ 次查表（因为儿子贡献已预先累加到 $S$），而把 $2(k+1)$ 个值并入父节点的总开销为 $\sum_v O(k)=O(nk)$。合计 $O(nk)$，$n=5\times10^4,\ k=50$ 时约 $5\times10^6$ 次运算。
- **空间**：C++ 实现用长度 $n\cdot 2(k+1)$ 的 `long long` 数组，约 $41$ MB；Python 实现按需创建并释放，峰值约为 $O(k\cdot\text{树的宽度})$。均远小于题目限制。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long subtreeInversionSum(vector<vector<int>>& edges, vector<int>& nums, int k) {
        int n = (int)nums.size();
        vector<vector<int>> adj(n);
        for (auto& e : edges) {
            adj[e[0]].push_back(e[1]);
            adj[e[1]].push_back(e[0]);
        }

        // 以 0 为根建树，得到 BFS 序（父在子之前）
        vector<int> par(n, -1), order;
        order.reserve(n);
        vector<char> vis(n, 0);
        order.push_back(0);
        vis[0] = 1;
        for (int i = 0; i < (int)order.size(); i++) {
            int u = order[i];
            for (int v : adj[u]) {
                if (!vis[v]) {
                    vis[v] = 1;
                    par[v] = u;
                    order.push_back(v);
                }
            }
        }

        int D = k + 1;   // 距离 0..k，其中 k 表示“>= k”
        // S[u][p * D + d] = 所有儿子 c 的 dp[c][p][d] 之和
        vector<long long> S((size_t)n * 2 * D, 0);
        vector<long long> dp(2 * D, 0);
        long long answer = 0;

        for (int idx = n - 1; idx >= 0; idx--) {
            int v = order[idx];
            long long* sv = &S[(size_t)v * 2 * D];
            for (int p = 0; p < 2; p++) {
                long long base = (p == 0) ? nums[v] : -nums[v];
                int off = p * D;
                for (int d = 0; d <= k; d++) {
                    // 不反转 v
                    long long val = base + sv[off + min(d + 1, k)];
                    // 反转 v：要求 up 到最近的已反转祖先距离 >= k
                    if (d == k) {
                        long long cand = -base + sv[(1 - p) * D + 1];
                        if (cand > val) val = cand;
                    }
                    dp[off + d] = val;
                }
            }
            if (v == 0) {
                answer = dp[k];   // p = 0, d = k
            } else {
                long long* sp = &S[(size_t)par[v] * 2 * D];
                for (int j = 0; j < 2 * D; j++) sp[j] += dp[j];
            }
        }
        return answer;
    }
};
```

### Python

```python
class Solution:
    def subtreeInversionSum(self, edges: list[list[int]], nums: list[int], k: int) -> int:
        n = len(nums)
        adj = [[] for _ in range(n)]
        for u, v in edges:
            adj[u].append(v)
            adj[v].append(u)

        # 以 0 为根建树，得到 BFS 序（父在子之前）
        par = [-1] * n
        order = [0]
        for u in order:
            for v in adj[u]:
                if v != par[u]:
                    par[v] = u
                    order.append(v)

        D = k + 1                     # 距离 0..k，k 表示“>= k”
        S = {}                        # S[u][p*D+d] = 所有儿子 dp[*][p][d] 之和

        for v in reversed(order):
            sv = S.pop(v, None) or [0] * (2 * D)
            dp = [0] * (2 * D)
            nv = nums[v]
            for p in range(2):
                base = nv if p == 0 else -nv
                off = p * D
                for d in range(D):
                    val = base + sv[off + min(d + 1, k)]
                    if d == k:        # 可以反转 v
                        cand = -base + sv[(1 - p) * D + 1]
                        if cand > val:
                            val = cand
                    dp[off + d] = val
            if v == 0:
                return dp[k]          # p = 0, d = k
            pv = par[v]
            if pv not in S:
                S[pv] = [0] * (2 * D)
            tgt = S[pv]
            for j in range(2 * D):
                tgt[j] += dp[j]
        return 0
```

## 8. 边界情况与易错点

1. **`k = 1`**：任意祖先-后代距离都 $\ge1$，约束自动满足，等价于「每个节点可独立决定是否反转它和它的子树」的宽松版本；$d$ 只有 $0,1$ 两个取值，代码无需特判。
2. **链状树**：深度可达 $5\times10^4$，**不能写递归 DFS**，必须用迭代（本题解用 BFS 序 + 逆序处理）。
3. **64 位溢出**：总和可达 $2.5\times10^9$，C++ 用 `int` 会溢出，必须 `long long`；Python 无此问题。
4. **`d` 忘记封顶**：写 `d+1` 而不做 `min(d+1,k)` 会数组越界；封顶后 $d=k$ 依然表示「$\ge k$」，不影响合法性判定。
5. **就绪条件写错**：反转条件是 `d == k`，不是 `d >= k`（$d$ 已封顶，等价），也不是 `d > k`（永远不会成立）。
6. **奇偶含义混淆**：$p$ 只统计**真祖先**；若把 $v$ 自身也算进 $p$，反转分支会双重取负，答案系统性错误。
7. **对称分支漏算**：互不为祖先的两个节点可以同时反转（示例 3），所以不能用「某个全局计数器」限制总反转次数，约束只在祖先-后代之间。
8. **初值选 0**：`dp` 值可以为负（`nums` 全负时），不要用 0 当「不可达」的哨兵；本题解每个状态都由公式显式计算，天然规避。
9. **根的状态**：根的 $d$ 必须取 $k$（等价于 $\infty$），否则反转根会被错误禁止。
