# LeetCode 将所有元素变为 0 的最少操作次数 题解

## 1. 题目概述

- **标题 / 题号**：将所有元素变为 0 的最少操作次数（#3542，medium）
- **链接**：https://leetcode.cn/problems/minimum-operations-to-convert-all-elements-to-zero/
- **来源**：LeetCode 第 156 场双周赛 Q2
- **难度**：中等
- **标签**：栈、贪心、数组、哈希表、单调栈

**题意**：给定非负整数数组 `nums`。一次操作是：任选子数组 $[i,j]$，令 $m$ 为该子数组中**最小的非负整数**，把子数组中**所有等于 $m$ 的元素**设为 0。求把所有元素变成 0 所需的**最少**操作次数。

注意两点语义细节：

- 「最小的非负整数」：若子数组里含 0，则 $m=0$，操作为**空操作**（0 变成 0）——因此有效操作必然作用在**全为正数**的区间上；
- 一次操作会一次性把该区间内**所有**等于 $m$ 的位置清零，而不是逐个减 1。

**约束**：

- $1 \le n = \text{nums.length} \le 10^5$
- $0 \le \text{nums}[i] \le 10^5$

## 2. 示例

**示例 1**

```text
输入：nums = [0,2]
输出：1
解释：选 [1,1]，m = 2，清 0 → [0,0]。
```

**示例 2**

```text
输入：nums = [3,1,2,1]
输出：3
解释：选 [1,3]（m=1）→ [3,0,2,0]；选 [2,2]（m=2）→ [3,0,0,0]；
     选 [0,0]（m=3）→ [0,0,0,0]。
```

**示例 3**

```text
输入：nums = [1,2,1,2,1,2]
输出：4
解释：选 [0,5]（m=1）→ [0,2,0,2,0,2]；再对三个 2 各做一次 → 共 4 次。
```

## 3. 解题思路

### 3.1 暴力思路

每次操作有 $O(n^2)$ 种选法（区间），且操作序列的长度也不定，直接搜索状态空间是「区间 DP + 最短路」的量级，$n=10^5$ 完全不可行。

换个角度：**值相同的元素能不能合并成一次操作**？示例 3 中三个 2 都被 1 隔开，只能各做一次；而示例 1 的 2 只有一个，一次搞定。关键在于「中间有没有更小的值把它们隔断」。

### 3.2 核心观察：按「层」切分，一段一层一次操作

![同一个值的每个连续段，各自需要一次操作](images/bw156_q2_stack_levels.svg)

固定一个高度 $v>0$，考察集合

$$S_v = \{\, i : \text{nums}[i] \ge v \,\}$$

把它按原数组的连续性切成若干**极大连续段**（即被 $\text{nums}[i]<v$ 的位置隔开）。观察：

- 一次 $m=v$ 的操作，其区间内所有元素的值都 $\ge v$（否则最小值会更小），所以区间必然**落在某个 $S_v$ 的极大连续段内部**；
- 反过来，任意包含「值恰好为 $v$ 的位置」的极大连续段 $C$，只要在其中做一次 $m=v$ 的操作，就能把 $C$ 内所有值等于 $v$ 的元素**一次性清零**。

于是自然得到候选答案

$$\text{ans} = \sum_{v>0} \#\{\, S_v \text{ 的极大连续段中，包含至少一个值恰为 } v \text{ 的位置} \,\}$$

这个量既给出下界（每个这样的段都必须消耗一次 $m=v$ 的操作），也能由「按 $v$ 从小到大逐段操作」的构造达到。剩下的问题就是：怎么在 $O(n)$ 内把它数出来？——用**单调栈**。

### 3.3 算法流程：单调栈数「层的左端点」

从左到右扫描，维护一个**严格递增**的栈（栈里存「当前还有效的值层级」）：

```text
1. st = 空栈，ans = 0
2. for x in nums:
       while st 非空 且 st.back() > x:  st.pop_back()   // 更大的层被 x 截断
       if x == 0: continue                            // 0 是天然的隔断
       if st 为空 或 st.back() < x:
           st.push_back(x)
           ans += 1                                   // 新开一层的一段
3. 返回 ans
```

直观理解：栈顶是「当前所在的最小层」。若新的 $x$ 比栈顶大，说明进入了一个**更高层的新段**，必须多一次操作；若栈顶恰好等于 $x$，说明这个值的当前段还在延续，直接复用；若 $x$ 更小，则比它高的层都被截断，弹掉。

![示例 2：单调栈模拟 [3,1,2,1]](images/bw156_q2_example_walkthrough.svg)

### 3.4 示例演算

以示例 2 `nums = [3,1,2,1]` 为例：

| 读入 $x$ | 弹栈后栈内容 | 动作 | `ans` |
|----------|--------------|------|-------|
| 3 | `[]` | push 3（新段） | 1 |
| 1 | `[]` | 3 被弹掉，push 1（新段） | 2 |
| 2 | `[1]` | 1 < 2，push 2（新段） | 3 |
| 1 | `[1]` | 2 被弹掉，栈顶等于 1 → 复用 | 3 |

答案 3。对照 §3.2 的计数：$v=1$ 时 $S_1$ 是整段（含值 1）→ 1 次；$v=2$ 时 $S_2$ 的段为 $\{0\}$、$\{2\}$，其中含值 2 的只有 $\{2\}$ → 1 次；$v=3$ 时 $S_3 = \{0\}$ 含值 3 → 1 次。合计 $1+1+1=3$，与示例输出一致。

## 4. 算法细节

1. **栈的单调性**：每次先弹掉所有 $>x$ 的元素，再判断栈顶与 $x$ 的关系，因此栈内始终**严格递增**。严格递增是「栈顶等于 $x$ 即复用」这个判定的前提。
2. **`x == 0` 的处理**：0 是最小值，任何含 0 的区间其 $m=0$、操作无效，所以 0 只起「隔断」作用。先把 `>` 0 的层弹掉，再直接 `continue`（不 push、不计数）。
3. **为什么用 `while` 而不是 `if`**：$x$ 可能一次性截断多个更高的层，例如 `[5,4,3,2,1]` 中读入 1 需要连续弹 4 次。
4. **栈的容量**：栈内是严格递增的不同数值，长度不超过 $n$，用 `vector<int>` 即可，无需哈希。
5. **计数时机**：只在「真正 push」时 `ans++`；栈顶等于 $x$ 的复用情形不加。
6. **不修改原数组**：整个算法只读一遍数组，符合「操作次数」的分析语义。

## 5. 正确性证明

先给出两个结构性的定义与引理。

**定义**：对 $v>0$，称 $S_v=\{i:\text{nums}[i]\ge v\}$ 的一个极大连续段为「$v$-段」；若该段内存在 $i$ 使 $\text{nums}[i]=v$，则称它为「**有效 $v$-段**」。记有效 $v$-段的个数总和为 $T$。

**引理 1（操作不能跨段）**：任何一次 $m=v>0$ 的操作所选的区间 $[a,b]$ 必包含在某个 $v$-段内部。

**证明**：操作要求 $m$ 是区间内最小非负整数。若区间内含 0，则 $m=0$，与 $m=v>0$ 矛盾，故区间内元素均 $>0$。又被清零的位置当前值就是 $v$，而其他位置当前值 $\ge v$（否则最小值 $<v$），所以区间内每个位置的原值都 $\ge v$（值只会从原值变成 0，不会取中间值）。因此 $[a,b]\subseteq S_v$，且连续，故落在 $S_v$ 的某个极大连续段内。∎

**引理 2（下界）**：任意合法操作序列的长度 $\ge T$。

**证明**：考察任一原值为 $v>0$ 的位置 $i$。由于操作只会把元素置 0、不会改变成其他非零值，位置 $i$ 从 $v$ 变 0 的那一刻，必然是被某次 $m=v$ 的操作覆盖（它的当前值恰为 $v$，且它必须等于区间最小值才会被清零）。由引理 1，该操作落在 $i$ 所属的 $v$-段内。于是每个有效 $v$-段都至少对应一次 $m=v$ 的操作；不同 $v$ 的操作互不相同，不同段的 $m=v$ 操作也不能是同一次（引理 1），故总操作数 $\ge T$。∎

**引理 3（构造达到下界）**：按 $v=1,2,3,\dots$ 递增的顺序，对每个有效 $v$-段 $C$ 在其整段上做一次操作，可在恰好 $T$ 次操作内清空数组。

**证明**：对 $v$ 归纳证明「做完第 $v$ 步后，所有原值 $\le v$ 的位置均为 0，且原值 $>v$ 的位置值不变」。设此前各步只清掉了原值 $<v$ 的位置，那么对有效 $v$-段 $C$：$C$ 内原值均 $\ge v$；原值 $<v$ 的位置不在 $C$ 内（$C\subseteq S_v$），故 $C$ 内没有已被清零的位置；于是 $C$ 内所有位置仍保持原值，最小值恰为 $v$（因为 $C$ 含原值 $v$ 的位置）。在该段上做一次操作，只把值 $v$ 清零，其余 $>v$ 的位置不变。归纳成立。$v$ 取到最大值后所有位置被清零，操作数恰为 $T$。∎

**引理 4（栈计数等于 $T$）**：算法中 `ans` 的累加次数等于 $T$。

**证明**：先刻画 push 条件。对下标 $i$，记 $p(i)$ 为 $i$ 左侧最近的满足 $\text{nums}[p]\le \text{nums}[i]$ 的下标（不存在则 $p=-1$）。由栈的构造可归纳证明：弹出所有 $>$ `nums[i]` 的值之后，栈顶恰为「前缀 $[0,i-1]$ 中所有 $\le \text{nums}[i]$ 的层里最大的那个」。于是 push 发生当且仅当 $\text{nums}[i]>0$ 且 $p(i)=-1$ 或 $\text{nums}[p(i)]<\text{nums}[i]$。

再证「每个有效 $v$-段恰贡献一次 push」。设 $C$ 是有效 $v$-段，$i_0$ 是 $C$ 内**最左**的值为 $v$ 的位置；$C$ 左端之外（或数组开头）没有值 $\le v$ 的元素，$C$ 内 $i_0$ 左侧的值都 $>v$，故 $p(i_0)=-1$ 或 $\text{nums}[p(i_0)]<v$，$i_0$ 被计数。而 $C$ 内其他值为 $v$ 的位置 $i>i_0$，其左侧最近的 $\le v$ 元素就是某个值为 $v$ 的位置（$C$ 内没有 $<v$ 的元素），故 $\text{nums}[p(i)]=v$，不被计数。于是每个有效 $v$-段恰好贡献 1 次。∎

**定理**：算法返回的值等于最少操作次数。

**证明**：由引理 2 得下界 $T$，由引理 3 得上界 $T$，故最少操作次数 $=T$；由引理 4，算法输出恰为 $T$。∎

## 6. 复杂度分析

- **时间**：每个下标至多被 push 一次、pop 一次，`while` 的总迭代次数不超过 $n$，故整个过程 $O(n)$。
- **空间**：栈长度不超过 $n$，$O(n)$；不修改原数组，无额外开销。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minOperations(vector<int>& nums) {
        vector<int> st;
        int ans = 0;
        for (int x : nums) {
            while (!st.empty() && st.back() > x) st.pop_back();
            if (x == 0) continue;
            if (st.empty() || st.back() < x) {
                st.push_back(x);
                ans++;
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def minOperations(self, nums: list[int]) -> int:
        st = []          # 单调递增栈：尚未被“清零领导”覆盖的层
        ans = 0
        for x in nums:
            while st and st[-1] > x:
                st.pop()
            if x == 0:
                continue
            if not st or st[-1] < x:
                st.append(x)
                ans += 1
        return ans
```

## 8. 边界情况与易错点

1. **全是 0**：栈始终为空，`ans = 0`，符合「可能 0 次操作」的题意。
2. **`x == 0` 必须跳过**：0 不能入栈，否则会污染「层」的含义；同时 0 会截断所有更高的层，所以要先弹掉 $>0$ 的层再 `continue`。
3. **栈顶等于 $x$ 时不能计数**：这正代表「同一个值的段被延续」，重复计数是最常见的 WA。
4. **`while` 写成 `if`**：`[5,4,3,2,1]` 之类递减序列需要连续弹出，写 `if` 会让栈失去单调性，后续判断全错。
5. **把操作理解成「减 1」**：本题是一次性置 0，所以答案与「数组和」无关；若误按「每次减 1」的模型，示例 2 会算成 $3+1+2+1=7$。
6. **答案范围**：最多 $n$ 次（每个位置单独清零上界），`int` 足够。
