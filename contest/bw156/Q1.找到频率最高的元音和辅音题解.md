# LeetCode 找到频率最高的元音和辅音 题解

## 1. 题目概述

- **标题 / 题号**：找到频率最高的元音和辅音（#3541，easy）
- **链接**：https://leetcode.cn/problems/find-most-frequent-vowel-and-consonant/
- **来源**：LeetCode 第 156 场双周赛 Q1
- **难度**：简单
- **标签**：哈希表、字符串、计数

**题意**：给定只含小写字母的字符串 `s`。在元音 `a、e、i、o、u` 中找出**出现次数最多**的那个元音的频率，再在辅音（其余 21 个字母）中找出出现次数最多者的频率，返回两个频率之和。若某一类字母在串中完全没出现，则该类频率记为 0；同类多个字母并列最高时任选一个即可。

**约束**：

- $1 \le \lvert s\rvert \le 100$
- `s` 只包含小写英文字母

## 2. 示例

**示例 1**

```text
输入：s = "successes"
输出：6
解释：元音 u 出现 1 次、e 出现 2 次 → 最大元音频率 2；
     辅音 s 出现 4 次、c 出现 2 次 → 最大辅音频率 4；
     返回 2 + 4 = 6。
```

**示例 2**

```text
输入：s = "aeiaeia"
输出：3
解释：元音 a 出现 3 次、e 与 i 各 2 次 → 最大元音频率 3；
     s 中没有辅音 → 最大辅音频率 0；
     返回 3 + 0 = 3。
```

## 3. 解题思路

### 3.1 暴力思路

串长只有 100，最直接的办法是：对 26 个字母逐个统计它在 `s` 中的出现次数，成本 $O(26n)$；或者更朴素地，对每个字母用一次 `count` 扫描全串，同样是 $O(26n)$。常数很小，实测都很快。真正的浪费在于对每个字母都重新扫一遍字符串。

### 3.2 核心观察：一次计数 + 分两类取最大

![successes：元音、辅音各取最高频，再相加](images/bw156_q1_vowel_consonant_split.svg)

只需要：

1. 用长度 26 的计数数组把 `s` 扫**一遍**，得到每个字母的频率 $c_0,\dots,c_{25}$；
2. 把 26 个字母按「是否属于 `{a,e,i,o,u}`」分成两组，分别取最大值；
3. 两个最大值相加即为答案。

两个关键细节：

- **初值取 0**：某一类没有字母出现时，最大值自然保持 0，无需特判「找不到」；
- **并列取谁都一样**：题目只要频率之和，不关心具体是哪个字母，所以只维护最大值即可，不用记录字母。

### 3.3 算法流程

```text
1. cnt[26] 全部置 0
2. for ch in s: cnt[ch - 'a'] += 1
3. bestVowel = 0，bestConsonant = 0
4. for i = 0 .. 25:
       若 chr(i+'a') 属于 {a,e,i,o,u}: bestVowel = max(bestVowel, cnt[i])
       否则:                          bestConsonant = max(bestConsonant, cnt[i])
5. 返回 bestVowel + bestConsonant
```

### 3.4 示例演算

![示例 2：aeiaeia 没有辅音 → 辅音频率按 0 计](images/bw156_q1_example_walkthrough.svg)

对示例 2 `s = "aeiaeia"`：

| 字母 | 次数 | 类别 |
|------|------|------|
| a | 3 | 元音 |
| e | 2 | 元音 |
| i | 2 | 元音 |
| 其余 | 0 | — |

最大元音频率 $3$，辅音组为空故为 $0$，答案 $3$。示例 1 的 `"successes"` 则给出元音 $\{u:1, e:2\}$、辅音 $\{s:4, c:2\}$，答案 $2+4=6$。

## 4. 算法细节

1. **判定元音**：用字符串 `"aeiou"` 查找（C++ 可写 `ch=='a'||ch=='e'||ch=='i'||ch=='o'||ch=='u'`，或用 26 长度的布尔表）。判定成本 $O(1)$。
2. **计数数组 vs 哈希表**：字母表只有 26 个，定长数组比哈希表更快也更省内存；Python 用 `[0]*26` 同样合适，不必用 `Counter`。
3. **两类最大值的初值**：都取 0。这样「没有元音」或「没有辅音」的输入自动得到贡献 0，不需要额外分支。
4. **不记录具体字母**：题目只要求频率之和，省掉「并列时选谁」的分支。
5. **字符偏移**：`ch - 'a'` 得到 $0\sim25$ 的下标；判断元音时比较的是**字母**而不是下标，别把 `i` 是否等于 0/4/8/14/20 写错（`a,e,i,o,u` 的下标分别是 0、4、8、14、20）。

## 5. 正确性证明

**引理 1（计数正确）**：扫描结束后 $\text{cnt}[i]$ 等于第 $i$ 个字母在 `s` 中出现的次数。

**证明**：对 `s` 中每个字符恰好执行一次 `cnt[ch-'a'] += 1`，故每个字母被累加的次数等于它的出现次数。∎

**引理 2（分组最大值正确）**：$\text{bestVowel}$ 与 $\text{bestConsonant}$ 分别等于元音字母与辅音字母中频率的最大值；若对应组为空，则值为 0。

**证明**：循环遍历了全部 26 个字母，每个字母按定义被归入唯一的一组，并与该组当前最大值取 `max`，故每组最终值是该组所有字母频率的最大值（初值 0 只会在组为空时保留，恰好符合题设「缺失记 0」）。∎

**定理**：算法返回值等于题面定义的「最大元音频率 + 最大辅音频率」。

**证明**：由引理 1、2，算法返回的两个量恰为题面所要求的两类最大频率，其和即为答案。∎

## 6. 复杂度分析

- **时间**：计数一遍 $O(n)$；遍历 26 个字母 $O(26)=O(1)$。合计 $O(n)$，$n\le 100$ 时是几十次哈希/数组访问。
- **空间**：计数数组固定 26 个整数，$O(1)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maxFreqSum(string s) {
        int cnt[26] = {0};
        for (char c : s) cnt[c - 'a']++;
        int bestVowel = 0, bestConsonant = 0;
        for (int i = 0; i < 26; i++) {
            bool isVowel = (i == 0 || i == 4 || i == 8 || i == 14 || i == 20);
            if (isVowel) {
                if (cnt[i] > bestVowel) bestVowel = cnt[i];
            } else {
                if (cnt[i] > bestConsonant) bestConsonant = cnt[i];
            }
        }
        return bestVowel + bestConsonant;
    }
};
```

### Python

```python
class Solution:
    def maxFreqSum(self, s: str) -> int:
        vowels = set('aeiou')
        best = {'vowel': 0, 'consonant': 0}
        cnt = [0] * 26
        for ch in s:
            cnt[ord(ch) - ord('a')] += 1
        for i, c in enumerate(cnt):
            kind = 'vowel' if chr(i + ord('a')) in vowels else 'consonant'
            if c > best[kind]:
                best[kind] = c
        return best['vowel'] + best['consonant']
```

## 8. 边界情况与易错点

1. **没有元音**：例如 `s = "bcdfg"`，答案应为最大辅音频率 + 0；初值 0 保证正确。
2. **没有辅音**：示例 2 就是这种情况，辅音贡献 0。
3. **单字符**：`"a"` → 1，`"z"` → 1。
4. **元音下标写错**：`a,e,i,o,u` 对应 $0,4,8,14,20$，漏掉或写错一个会让某个字母被错分到另一组，示例 1（`u` 与 `e` 都是元音）就能暴露。
5. **误把 `y` 当元音**：题面明确元音只有 `a、e、i、o、u`，`y` 属于辅音。
6. **并列处理**：并列时「任选一个」意味着只需频率，不要引入「字典序」之类的额外规则，否则可能画蛇添足。
7. **返回类型**：频率之和最大为 $n\le100$，`int` 足够。
