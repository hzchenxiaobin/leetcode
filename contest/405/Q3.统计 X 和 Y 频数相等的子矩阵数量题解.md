# LeetCode 统计 X 和 Y 频数相等的子矩阵数量 题解

## 1. 题目概述

- **标题 / 题号**：统计 X 和 Y 频数相等的子矩阵数量（#3212，medium）
- **链接**：https://leetcode.cn/problems/count-submatrices-with-equal-frequency-of-x-and-y/
- **来源**：LeetCode 第 405 场周赛 Q3
- **难度**：中等
- **标签**：数组、矩阵、前缀和

**题意**：给定 $n \times m$ 字符矩阵 `grid`，元素只可能是 `'X'`、`'Y'`、`'.'`。统计同时满足以下条件的**子矩阵**（连续矩形区域）个数：

1. 包含左上角格子 `grid[0][0]`；
2. `'X'` 与 `'Y'` 的出现频数相等；
3. 至少包含一个 `'X'`。

**约束**：

- $1 \le n, m \le 1000$，格子数至多 $10^6$；
- `grid[i][j]` 的取值只可能是 `'X'`、`'Y'`、`'.'` 三种字符。

> 💡 读题关键：①「子矩阵」是**连续矩形**，不是任意格子集合；②「包含 `grid[0][0]`」是降维的钥匙——候选从 $O(n^2m^2)$ 个锐减到 $n \cdot m$ 个；③ 条件 ③ 不能丢：全 `'.'` 的矩形满足 ② 但不满足 ③。

## 2. 示例

**示例 1**

```text
输入：grid = [["X","Y","."],
              ["Y",".","."]]
输出：3
解释：合法子矩阵的右下角分别为 (0,1)、(0,2)、(1,0)，均恰有 1 个 X、1 个 Y。
```

**示例 2**

```text
输入：grid = [["X","X"],
              ["X","Y"]]
输出：0
解释：X 处处多于 Y（最多 3:1），不存在频数相等的候选。
```

**示例 3**

```text
输入：grid = [[".","."],
              [".","."]]
输出：0
解释：所有候选 X=Y=0，相等但「至少一个 X」不满足——条件 ③ 的存在感。
```

**补充示例（1×1 矩阵）**

```text
输入：grid = [["X"]]（或 [["Y"]]、[["."]]）
输出：0
解释：唯一候选 (0,0) 的 (X,Y) 计数分别为 (1,0)、(0,1)、(0,0 且无 X)，均不合法。
```

## 3. 解题思路

### 3.1 暴力思路

最朴素：枚举全部子矩阵（上下左右边界 $r_1 \le r_2$、$c_1 \le c_2$，共 $O(n^2m^2) \approx 2.5 \times 10^{11}$ 个），每个再花 $O(nm)$ 统计频数——总计 $O(n^3m^3)$，天文数字。

退一步：利用条件 ① 只枚举含 `(0,0)` 的候选（即右下角 $(i,j)$，共 $O(nm)$ 个），但若每个候选仍**重新扫描**统计 X/Y 个数，单次 $O(nm)$，总计 $O(n^2m^2) = 10^{12}$，在 $n = m = 1000$ 下依然不可行。瓶颈在于「**高度重叠的矩形被重复统计**」。

### 3.2 核心观察：锚定 (0,0) + 前缀和 O(1) 计数

![核心观察：包含左上角的子矩阵由右下角唯一确定](images/w405_xy_matrix_concept.svg)

**观察 1（候选降维）**：连续矩形包含 `(0,0)` ⟺ 其行区间为 $[0, i]$、列区间为 $[0, j]$。于是**候选子矩阵与右下角 $(i,j)$ 一一对应**，只有 $n \cdot m \le 10^6$ 个——四维枚举 $(r_1, r_2, c_1, c_2)$ 塌缩成二维。

**观察 2（前缀和 O(1) 计数）**：一个区域内 `'X'` 的个数是**二维可减量**。预处理两张 $(n{+}1) \times (m{+}1)$ 前缀和表 $p_X, p_Y$ 后，任意矩形的计数都能 $O(1)$ 取得。更进一步：本题查询的矩形**永远从 $(0,0)$ 出发**，容斥式

$$\#X_{[0..i]\times[0..j]} = p_X[i{+}1][j{+}1] - p_X[0][j{+}1] - p_X[i{+}1][0] + p_X[0][0]$$

的后三项全为 $0$——$p_X[i{+}1][j{+}1]$ **本身就是**所求计数，连减法都省了。

**观察 3（判定合一）**：锚定之后三条件只剩两个布尔判断：$c_X = c_Y$ 且 $c_X \ge 1$（条件 ① 已由枚举方式保证）。每个候选 $O(1)$ 判定，总体 $O(nm)$。

### 3.3 算法流程：前缀和 + 枚举右下角

![算法流程：双计数二维前缀和 + 枚举右下角](images/w405_xy_prefix_flow.svg)

```text
预处理 px, py（(n+1)×(m+1)，分别统计 'X' / 'Y'）
枚举右下角 (i, j)：
    cx = px[i+1][j+1]          # 即 [0..i]×[0..j] 内 'X' 数
    cy = py[i+1][j+1]
    若 cx == cy 且 cx >= 1：    ans += 1
返回 ans
```

构建用的递推式（$w_X(i,j) = [\text{grid}[i][j] = \text{'X'}]$，$p_Y$ 同理）：

$$p_X[i{+}1][j{+}1] = p_X[i][j{+}1] + p_X[i{+}1][j] - p_X[i][j] + w_X(i,j)$$

### 3.4 示例演算

![示例 1 演算：六个候选右下角逐个判定](images/w405_xy_matrix_walkthrough.svg)

以示例 1 走一遍：$2 \times 3$ 矩阵共 6 个候选右下角。$(0,0)$ 只有 1 个 X；$(0,1)$、$(0,2)$、$(1,0)$ 都是 $c_X = c_Y = 1$，计入；$(1,1)$、$(1,2)$ 因第二行的 `Y` 使 $c_Y = 2 > 1 = c_X$，淘汰。答案 3，与示例一致。

## 4. 算法细节

1. **哨兵行列**：前缀和表开 $(n{+}1) \times (m{+}1)$，第 0 行/列全 0。递推中访问 $p[i][j]$（$i, j \ge 0$，对应原矩阵下标 $-1$）天然不越界，**无需特判**。
2. **构建与判定同趟完成**：双循环里先更新 $p_X[i{+}1][j{+}1]$、$p_Y[i{+}1][j{+}1]$，随后立刻取值判定——连第二遍遍历都省了。
3. **判定的两个条件缺一不可**：`cx == cy && cx >= 1`。只写前者会把全 `'.'` 的候选（$c_X = c_Y = 0$）误计入，示例 3 正是为此存在。
4. **字符即权值**：$w_X(i,j)$ 是 0/1 权。C++ 里 `grid[i][j] == 'X'` 的 `bool` 隐式转 `int` 直接参与加减；Python 里 `True` 即 1。
5. **空间化简（可选）**：因查询区域总从 $(0,0)$ 出发，不必存完整二维表——按行滚动维护「每列至今的 X/Y 计数」`colX`/`colY`，再从左到右累加出 $c_X, c_Y$，空间降到 $O(m)$（见 Python 代码）；按列滚动同理可得 $O(n)$，取小者。
6. **数值范围**：计数上限 $n \cdot m = 10^6$，答案上限同为 $10^6$，`int` 足够，无溢出风险。

## 5. 正确性证明

**引理 1（候选一一对应）**：含 `grid[0][0]` 的子矩阵与二元组 $(i, j) \in [0, n) \times [0, m)$ 一一对应。

**证明**：子矩阵是连续矩形 $[r_1, r_2] \times [c_1, c_2]$（$0 \le r_1 \le r_2 < n$，$0 \le c_1 \le c_2 < m$）。「包含 $(0,0)$」即 $r_1 \le 0 \le r_2$ 且 $c_1 \le 0 \le c_2$，结合下界非负得 $r_1 = c_1 = 0$。于是子矩阵形如 $[0, i] \times [0, j]$，由 $(i, j) = (r_2, c_2)$ 唯一确定；反过来每个 $(i,j)$ 都给出一个含 $(0,0)$ 的子矩阵。两个方向的映射互逆，故为双射。∎

**引理 2（前缀和计数正确）**：按递推式构建的 $p_X$ 满足 $p_X[i{+}1][j{+}1] = \#\{(a, b) : 0 \le a \le i,\ 0 \le b \le j,\ \text{grid}[a][b] = \text{'X'}\}$，$p_Y$ 同理。

**证明**：对 $i + j$ 归纳。基础：$p_X[0][*] = p_X[*][0] = 0$ 对应空区域，成立。归纳步：区域 $[0..i] \times [0..j]$ 不重不漏地分解为 $[0..i{-}1] \times [0..j]$（由归纳假设贡献 $p_X[i][j{+}1]$）与 $[0..i] \times [0..j{-}1]$（贡献 $p_X[i{+}1][j]$）；二者重叠部分 $[0..i{-}1] \times [0..j{-}1]$ 被算了两次，需减去 $p_X[i][j]$；最后补上既不属于前者（缺行 $i$）也不属于后者（缺列 $j$）的唯一格子 $(i, j)$ 的权 $w_X(i, j)$。这正是递推式。∎

**定理**：算法返回值等于满足全部三条件的子矩阵个数。

**证明**：由引理 1，对 $(i,j)$ 的双重循环**不重不漏**地遍历了所有满足条件 ① 的子矩阵，每个恰一次。由引理 2，循环中取得的 $c_X = p_X[i{+}1][j{+}1]$、$c_Y = p_Y[i{+}1][j{+}1]$ 即当前子矩阵内 `'X'`/`'Y'` 的真实频数，故布尔式 $c_X = c_Y \wedge c_X \ge 1$ 与条件 ②∧③ 逐候选等价。于是每个合法子矩阵恰使 `ans` 增加 1，非法者增加 0，求和即得答案。∎

## 6. 复杂度分析

- **时间复杂度**：$O(nm)$。一趟双循环同时完成前缀和构建与判定，每格 $O(1)$；$n = m = 1000$ 时约 $10^6$ 次基本操作，远低于周赛常规的 $10^8$ 量级预算。
- **空间复杂度**：$O(nm)$——两张 $(n{+}1) \times (m{+}1)$ 的 `int` 表（约 $2 \times 4\,\mathrm{MB}$）；按行/列滚动可降到 $O(\min(n, m))$（§4 第 5 点），本题 $O(nm)$ 已足够。
- **对照**：暴力 $O(n^3m^3)$、锚定后重扫 $O(n^2m^2) = 10^{12}$（超时约 6 个数量级）→ 前缀和把「重叠区域的重复统计」一次性摊销进预处理。

## 7. 参考代码

### C++（标准二维前缀和，一趟完成）

```cpp
class Solution {
public:
    int numberOfSubmatrices(vector<vector<char>>& grid) {
        int n = grid.size(), m = grid[0].size();
        vector<vector<int>> px(n + 1, vector<int>(m + 1)), py = px;
        int ans = 0;
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < m; j++) {
                px[i + 1][j + 1] = px[i][j + 1] + px[i + 1][j] - px[i][j]
                                 + (grid[i][j] == 'X');   // bool 转 0/1
                py[i + 1][j + 1] = py[i][j + 1] + py[i + 1][j] - py[i][j]
                                 + (grid[i][j] == 'Y');
                ans += (px[i + 1][j + 1] == py[i + 1][j + 1] &&
                        px[i + 1][j + 1] >= 1);           // X=Y 且至少一个 X
            }
        }
        return ans;
    }
};
```

### Python（按列滚动，O(m) 空间）

```python
class Solution:
    def numberOfSubmatrices(self, grid: List[List[str]]) -> int:
        n, m = len(grid), len(grid[0])
        col_x = [0] * m        # col_x[j]：前 i+1 行中第 j 列的 'X' 数
        col_y = [0] * m
        ans = 0
        for row in grid:
            sx = sy = 0        # sx：[0..i]×[0..j] 内 'X' 数（随 j 前缀累计）
            for j, c in enumerate(row):
                col_x[j] += c == 'X'
                col_y[j] += c == 'Y'
                sx += col_x[j]
                sy += col_y[j]
                ans += sx == sy and sx >= 1
        return ans
```

## 8. 边界情况与易错点

1. **漏写条件 ③（最常见 WA）**：只判 `cx == cy` 会把全 `'.'` 的候选计入——$c_X = c_Y = 0$ 相等但不含 X（示例 3 专门构造了这一情形）。
2. **没利用「包含 (0,0)」**：去枚举任意子矩阵，复杂度直接失控；读题时要把「锚定左上角」翻译成「只枚举右下角」。
3. **前缀和不开哨兵行列**：若表只开 $n \times m$，递推访问 $p[i][j]$ 在 $i = 0$ 或 $j = 0$ 时下标 $-1$ 越界，需额外特判；开 $(n{+}1) \times (m{+}1)$ 一劳永逸。
4. **容斥项写错**：构建端是「加左、加上、减左上、加当前权」。查询端虽因左上角固定而无需容斥，但**构建端**的 $-p[i][j]$ 不能省——省掉会重复计数重叠区。
5. **1×1 矩阵**：唯一候选 $(0,0)$，无论 `'X'`/`'Y'`/`'.'` 均不合法，答案恒 0，可作提交前的 sanity check。
6. **Python 的 `ans += sx == sy and sx >= 1`**：`and` 短路求值返回 `False`/`True`，参与加法即 0/1，正确；但若顺手写成 `sx == sy and sx`，当 `sx == sy == 0` 时返回 `0`、否则返回 `sy`——碰巧也对，但语义晦涩，不推荐。
