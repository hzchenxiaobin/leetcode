# LeetCode 最小代价构造字符串 题解

## 1. 题目概述

- **标题 / 题号**：最小代价构造字符串（#3213，hard）
- **链接**：https://leetcode.cn/problems/construct-string-with-minimum-cost/
- **来源**：LeetCode 第 405 场周赛 Q4
- **难度**：困难
- **标签**：字符串、动态规划、字符串哈希、AC 自动机

**题意**：给定字符串 `target`、字符串数组 `words` 与等长的整数数组 `costs`。从空串 `s` 出发，每次操作任选下标 $i$，把 `words[i]` 追加到 `s` 末尾，支付 `costs[i]`（同一单词**可以重复使用**）。求使 `s` 恰好等于 `target` 的最小总成本；无法构造时返回 `-1`。

**约束**：

- $1 \le n = |\textit{target}| \le 5\times10^4$
- $1 \le m = |\textit{words}| = |\textit{costs}| \le 5\times10^4$
- $1 \le |\textit{words}[i]| \le n$
- $\sum_i |\textit{words}[i]| \le 5\times10^4$    ← 全题的题眼
- 字符集为小写字母；$1 \le \textit{costs}[i] \le 10^4$

> 💡 读题关键：① 这是「单词拆分」（LC 139）的**带权版**——把 `target` 切成若干段，每段必须恰好是某个 `words[i]`，最小化段成本之和；② 单词可重复使用，说明是「无限供给」的转移，按前缀 DP 即可，无需状压；③ 真正的难度不在 DP 本身，而在**转移如何加速**——而钥匙藏在最不起眼的 $\sum|\textit{words}[i]| \le 5\times10^4$ 里。

## 2. 示例

**示例 1**

```text
输入：target = "abcdef", words = ["abdef","abc","d","def","ef"], costs = [100,1,1,10,5]
输出：7
解释："abc"(1) + "d"(1) + "ef"(5) = 7；用 "abdef"+"..." 则首段就要花 100。
```

**示例 2**

```text
输入：target = "aaaa", words = ["z","zz","zzz"], costs = [1,10,100]
输出：-1
解释：没有任何单词能拼出 target。
```

**补充示例（重复单词取最便宜的）**

```text
输入：target = "aa", words = ["a","a","aa"], costs = [5,3,9]
输出：6
解释：两个 "a" 都能追加，应取 cost=3 的那个：3 + 3 = 6（而非 5+5 或 9）。
```

## 3. 解题思路

### 3.1 暴力思路

定义 $f[i]$ 为「拼出 `target` 长为 $i$ 的前缀」的最小成本，$f[0]=0$。按「枚举最后一段」思考：若最后一段 `target[j:i]` 等于某个 `words[k]`，则

$$f[i] = f[j] + \textit{costs}[k]$$

对全部来源取 min。问题在于 $j$ 有 $i$ 种取值：

- 逐字符判等：$O(n^2\cdot m\cdot|\text{word}|)$，天文数字；
- 就算用哈希把判等压到 $O(1)$，枚举所有 $j$ 仍是 $O(n^2) = 2.5\times10^9$，超时；
- 建 Trie 后从每个起点沿树匹配：单起点最深可走 $\min(\text{树高},\,n)$，`target` 与单词全为 `'a'` 时仍是 $\Theta(n^2)$。

瓶颈看得清楚：**枚举的「长度」太多了**。而 `words` 里真实出现的长度，远远没有 $n$ 种。

### 3.2 核心观察：长度种类只有 $O(\sqrt L)$ 个

![核心观察：总长约束推出长度种类上界，按长度分桶去重](images/w405_min_cost_length_groups.svg)

**观察一（长度三角形）**：设 $L=\sum_i|\textit{words}[i]| \le 5\times10^4$。若 `words` 中出现 $K$ 个**互不相同**的长度，则每个长度至少对应一个该长度的单词，且不同长度对应不同单词，于是

$$L \;\ge\; 1+2+\cdots+K = \frac{K(K+1)}{2} \quad\Longrightarrow\quad K \le 315$$

（$315\times316/2 = 49890 \le 5\times10^4 < 316\times317/2$。）也就是说，转移不必枚举 $n$ 个 $j$，只需枚举至多 $315$ 个**真实出现的长度** $\ell$：查 `target[i-ℓ:i]` 是不是某个长度为 $\ell$ 的单词。用前缀哈希把判等压到 $O(1)$、按 $(\ell, \text{哈希})$ 分桶去重取最小成本，转移量 $n\cdot K \le 5\times10^4\times315 \approx 1.6\times10^7$，一次模乘 + 一次哈希表查询，稳稳当当。

**观察二（匹配总数同级）**：固定长度 $\ell$ 时，每个结束位置 $i$ 至多匹配**一个**长度为 $\ell$ 的单词——子串 `target[i-ℓ:i]` 是唯一确定的字符串。因此全部「(位置, 单词) 匹配对」至多 $n\cdot K \approx 1.6\times10^7$ 对。这同时解释了「按单词枚举出现位置」的后缀数组 / AC 自动机做法为什么也是 $O(n\sqrt L)$：**$O(n\sqrt L)$ 就是本题的本质复杂度**，三个 $5\times10^4$ 的数据范围正是为此配套设计的。

### 3.3 算法流程：前缀哈希 + 按长度分组 DP

![算法流程：预处理两个前缀哈希与长度分桶，位置外层长度内层做 DP](images/w405_min_cost_dp_flow.svg)

```text
预处理：
  1. 对 target 做双哈希前缀 pre1/pre2 与幂表 pw1/pw2
     hash(s) = s[0]·B^{|s|-1} + s[1]·B^{|s|-2} + … + s[|s|-1]（两个独立模数）
     子串哈希：hash(target[j:i]) = pre[i] − pre[j]·B^(i−j)  （模意义下 O(1)）
  2. words 分桶：桶键 = 长度 ℓ（ℓ > n 的直接丢弃）
     桶内键 = 哈希，值 = min(cost)（重复单词自动合并为最小成本）
DP（位置为外层、长度为内层——顺序不能反，见 §8）：
  f[0] = 0，其余 = +∞
  for i = 1..n:
      for ℓ in 升序长度表（ℓ > i 即 break）:
          j = i − ℓ
          c = 桶[ℓ].get(hash(target[j:i]))     # 查不到则跳过
          f[i] = min(f[i], f[j] + c)
答案：f[n] 仍为 +∞ 则返回 −1，否则返回 f[n]
```

### 3.4 示例演算

![示例 1 演算：逐位置查长度表，最优路径 abc|d|ef](images/w405_min_cost_example_walkthrough.svg)

以示例 1 走一遍。分桶结果：$\ell{=}1$: {d:1}；$\ell{=}2$: {ef:5}；$\ell{=}3$: {abc:1, def:10}；$\ell{=}5$: {abdef:100}——注意 $\ell=4$ 没有任何单词，**这个长度根本不进入枚举**。长度表 = [1, 2, 3, 5]。

| $i$ | $\ell{=}1$ | $\ell{=}2$ | $\ell{=}3$ | $\ell{=}5$ | $f[i]$ |
|:---:|:---:|:---:|:---:|:---:|:---:|
| 1 | `a`✗ | — | — | — | ∞ |
| 2 | `b`✗ | `ab`✗ | — | — | ∞ |
| 3 | `c`✗ | `bc`✗ | `abc`✓ $f_0{+}1$ | — | **1** |
| 4 | `d`✓ $f_3{+}1{=}2$ | `cd`✗ | `bcd`✗ | — | **2** |
| 5 | `e`✗ | `de`✗ | `cde`✗ | `abcde`✗ | ∞ |
| 6 | `f`✗ | `ef`✓ $f_4{+}5{=}7$ | `def`✓ $f_3{+}10{=}11$ | `bcdef`✗ | **7** |

两处细节值得咀嚼：① $f[5]=\infty$ 并不导致 $-1$——中间前缀不可达完全正常，只要 $f[n]$ 可达即可，最优方案 `abc|d|ef` 正是「跳过」了 $f[5]$；② 位置 6 同时命中 `ef` 与 `def` 两个不同长度的单词，必须都试——这正是「枚举长度」而不是「贪心取最长/最短」的原因。

## 4. 算法细节

1. **为什么是双哈希**：本题哈希查询约 $nK \approx 1.6\times10^7$ 次、去重后词典至多 $m \le 5\times10^4$ 个键。同长度的 (窗口, 单词) 对约 $\sum_\ell n\cdot m_\ell \le nm = 2.5\times10^9$ 个，单模 $10^9$ 级哈希的期望假命中 $\approx 2.5\times10^9 / 10^9 > 1$——**不是理论洁癖，是真能错**。取两个独立模数 $M_1, M_2$（或单个梅森素数 $2^{61}-1$ 配 `__int128`），期望假命中降到 $\approx 10^{-9}$ 量级。两组哈希拼成单一键 $h_1\cdot M_2 + h_2 < 2^{63}$，方便塞进一张哈希表。
2. **负数取模**：`pre[i] − pre[j]·pw[ℓ]` 在 C++ 中 `%` 后可能为负，必须 `((x % M) + M) % M`；Python 的 `%` 恒非负，无此坑。
3. **按长度分桶，而不是全局词典**：查询只在同长度单词内比对，天然杜绝「不同长度的哈希互相撞车」这类额外风险，也让「长度枚举」与「词典查询」一一对应。
4. **循环顺序**：必须**位置外层、长度内层**。长度做外层时，后续长度对 $f[j]$ 的更优值无法传播给先前长度已写下的 $f[i]$，会系统性漏解（反例见 §8 第 2 条）。
5. **数值范围**：段数 $\le n = 5\times10^4$、单价 $\le 10^4$，答案上界 $5\times10^8$，`int` 恰好装得下，但中途加法建议 `long long`；$+\infty$ 取 `LLONG_MAX/2`，加 `cost` 不溢出。
6. **方法二：AC 自动机（免哈希的标准姿势）**：

   ![AC 自动机：fail 链与 last 单词跳转，位置 6 一链枚举三个后缀单词](images/w405_min_cost_ac_last_chain.svg)

   把 `words` 建 Trie（节点存该处单词的最小成本），BFS 建 fail 指针并做**确定化**（空儿子直接补成 fail 的儿子，扫描时一步到位）。`target` 逐字符在自动机上走，读完第 $i$ 个字符停在节点 $u$，则 **$u$ 的 fail 链上的所有单词节点 = 「`target[0..i]` 的全部单词后缀」**，逐个做转移 $f[i] = \min(f[i],\, f[i-|\text{word}|] + \text{cost})$。关键优化：**不能裸跳 fail 链**——链上大量是非单词节点，`target` 与单个长单词全为 `'a'` 时链长 $\Theta(n)$、总计 $\Theta(n^2)\approx1.25\times10^9$ 步，必超时。预处理 `last[u]`：$u$ 的 fail 链上（含 $u$）最近的**单词**节点，沿 `last` 链一步一跳，访问的全是单词节点。由观察二，其总数 ≤ 匹配总数 $\le nK$，加上建树 $O(26L)$、扫描 $O(n)$，总复杂度仍是 $O(L + n\sqrt L)$，且**完全确定、无哈希风险**。

## 5. 正确性证明

**引理 1（最优子结构）**：$f[i]$ 由上述转移计算时，恰等于「拼接结果等于 `target[0:i]` 的单词序列」的成本最小值（无解时为 $+\infty$）。

**证明**：对 $i$ 归纳。$i=0$：空序列成本 $0$。$i\ge1$：任一可行序列非空，设末段为单词 $w = \textit{target}[j:i]$（$j=i-|w|$），其前缀部分是 `target[0:j]` 的可行序列，由归纳假设成本 $\ge f[j]$，故该序列成本 $\ge f[j]+\textit{cost}(w)$；对一切可行序列取下界即得 $f[i]\ge\min_j\{f[j]+\textit{cost}\}$。反向，取达到 $f[j]$ 的序列（由归纳假设存在）并追加 $w$，得成本 $f[j]+\textit{cost}(w)$ 的可行序列，故 $f[i]$ 不超过该 min。两向合一即证。∎

**引理 2（长度种类）**：`words` 中互不相同的长度个数 $K$ 满足 $K(K+1)/2 \le L$，故 $K = O(\sqrt L)$。

**证明**：设相异长度 $\ell_1<\cdots<\ell_K$。每个 $\ell_t$ 至少对应一个长度为 $\ell_t$ 的单词，且不同长度对应**不同**的单词（一个单词只有一个长度），这些单词的长度之和为 $\ell_1+\cdots+\ell_K \ge 1+2+\cdots+K$，而它不超过 $L$。∎

**引理 3（匹配总数）**：固定长度 $\ell$，每个结束位置 $i$ 至多匹配一个长度为 $\ell$ 的单词；故所有 (位置, 长度) 中「子串恰为单词」的对数至多 $nK \le n\sqrt{2L}$。

**证明**：子串 `target[i-ℓ:i]` 是唯一确定的字符串，它要么恰为某个长度 $\ell$ 的（去重后）单词——匹配且仅匹配这一个，要么不是——零匹配。对 $\ell\in\mathcal{L}$ 求和即得。∎

**引理 4（fail 链枚举的完备性）**：读入 `target[0..i]` 后自动机状态为 $u$，则「是 `target[0..i]` 后缀的单词」全体恰为 $u$ 的 fail 链（含 $u$）上的单词节点全体。

**证明**：AC 自动机基本性质：$v$ 在 $u$ 的 fail 链上 $\iff$ $v$ 对应的串是 $u$ 对应串的后缀且 $v$ 是 Trie 节点。单词被插入 Trie 故其终止节点是 Trie 节点，反之 Trie 上的单词节点对应被插入的单词。于是「单词 $w$ 是 `target[0..i]`（即状态 $u$ 对应的最长匹配串）的后缀」$\iff$「$w$ 的节点在 $u$ 的 fail 链上」。`last` 的定义保证链上访问严格沿 fail 方向且不跳过任何单词节点，不重不漏。∎

**定理**：方法一与方法二均返回正确答案；时间复杂度 $O\big(L + n\sqrt L\big)$，空间复杂度 $O(n+L)$。

**证明**：正确性：由引理 1，只需转移枚举覆盖「所有可能的末段单词」。方法一枚举全部 $K$ 个长度（引理 2 保证覆盖一切单词长度，分桶词典给出该长度下的最小成本）；方法二枚举全部单词后缀（引理 4）。两者都不重不漏，故 $f$ 与定义一致，$f[n]$ 即答案、$+\infty$ 时返回 $-1$。复杂度：方法一每对 $(i,\ell)$ 一次 $O(1)$ 哈希计算与查询，共 $nK$；方法二建树与确定化 $O(26L)$，扫描均摊 $O(n)$，`last` 链访问均为单词节点，总数由引理 3 限制在 $nK$。方法一另需哈希不碰撞，由 §4 第 1 条的生日论证，双哈希下错误概率 $\approx 10^{-9}$ 量级；方法二完全确定。∎

> 💡 一句话复盘：**DP 负责「怎么拆」，$O(\sqrt L)$ 的长度种类负责「拆多快」**。$\sum|\textit{words}[i]| \le 5\times10^4$ 这个约束不是白给的——它就是出题人递给你的复杂度预算表。

## 6. 复杂度分析

- **时间复杂度**：$O(L + n\sqrt L)$。预处理（前缀哈希、分桶、建自动机）$O(L)$；DP 转移 $nK \le 5\times10^4 \times 315 \approx 1.6\times10^7$ 次。实测（`target` 与 `words` 全为 `'a'` 的最坏构造，长度 $1\sim315$ 齐全）：C++ 哈希版约 0.4 s、C++ 自动机版约 0.1 s、Python 自动机版约 2 s。
- **空间复杂度**：$O(n + L)$。前缀哈希与 DP 数组 $O(n)$；分桶词典或 AC 自动机 $O(L)$（自动机 26 叉数组约 $26L$ 个 `int`，$\sim 5$ MB）。
- **对照**：暴力 $O(n^2) = 2.5\times10^9$ 超时约两个数量级；「长度枚举」把它砍到 $1.6\times10^7$，是本题唯一需要的那一刀。

## 7. 参考代码

### C++（方法一：双哈希 + 按长度分组 DP）

```cpp
class Solution {
public:
    int minimumCost(string target, vector<string>& words, vector<int>& costs) {
        int n = target.size();
        const long long M1 = 1'000'000'007, M2 = 1'000'000'009;  // 双哈希
        const long long B1 = 131, B2 = 137;
        // 前缀哈希与幂表
        vector<long long> h1(n + 1), h2(n + 1), p1(n + 1, 1), p2(n + 1, 1);
        h1[0] = h2[0] = 0;
        for (int i = 0; i < n; i++) {
            long long v = target[i] - 'a' + 1;
            h1[i + 1] = (h1[i] * B1 + v) % M1;
            h2[i + 1] = (h2[i] * B2 + v) % M2;
            p1[i + 1] = p1[i] * B1 % M1;
            p2[i + 1] = p2[i] * B2 % M2;
        }
        // 按长度分桶：长度 -> (哈希 -> 最小成本)
        unordered_map<int, unordered_map<long long, int>> group;
        for (int k = 0; k < (int)words.size(); k++) {
            int l = words[k].size();
            if (l > n) continue;                       // 长于 target，永不匹配
            long long a = 0, b = 0;
            for (char c : words[k]) {
                long long v = c - 'a' + 1;
                a = (a * B1 + v) % M1;
                b = (b * B2 + v) % M2;
            }
            long long key = a * M2 + b;                // 两组合一键，< 2^63
            auto [it, ok] = group[l].emplace(key, costs[k]);
            if (!ok) it->second = min(it->second, costs[k]);
        }
        vector<int> lens;                              // 升序长度表
        for (auto& kv : group) lens.push_back(kv.first);
        sort(lens.begin(), lens.end());

        const long long INF = LLONG_MAX / 2;
        vector<long long> f(n + 1, INF);
        f[0] = 0;
        for (int i = 1; i <= n; i++) {                 // 位置外层
            for (int l : lens) {                       // 长度内层（升序可 break）
                if (l > i) break;
                int j = i - l;
                long long a = ((h1[i] - h1[j] * p1[l]) % M1 + M1) % M1;
                long long b = ((h2[i] - h2[j] * p2[l]) % M2 + M2) % M2;
                auto it = group[l].find(a * M2 + b);
                if (it != group[l].end())
                    f[i] = min(f[i], f[j] + it->second);
            }
        }
        return f[n] >= INF ? -1 : (int)f[n];
    }
};
```

### C++（方法二：AC 自动机，`last` 链只跳单词节点）

```cpp
class Solution {
public:
    int minimumCost(string target, vector<string>& words, vector<int>& costs) {
        int n = target.size();
        // 1. Trie，0 号为根
        vector<array<int, 26>> ch(1);
        vector<int> wlen(1, 0), wcost(1, -1);
        for (int k = 0; k < (int)words.size(); k++) {
            int cur = 0;
            for (char c : words[k]) {
                int x = c - 'a';
                if (!ch[cur][x]) {
                    ch.push_back({});
                    wlen.push_back(0);
                    wcost.push_back(-1);
                    ch[cur][x] = (int)ch.size() - 1;
                }
                cur = ch[cur][x];
            }
            wlen[cur] = (int)words[k].size();
            wcost[cur] = wcost[cur] < 0 ? costs[k] : min(wcost[cur], costs[k]);
        }
        // 2. BFS 建 fail 并确定化：空儿子直接补成 fail 的儿子
        int sz = ch.size();
        vector<int> fail(sz, 0), last(sz, 0);  // last[u]：u 的 fail 链上（含 u）最近的单词节点
        queue<int> q;
        for (int x = 0; x < 26; x++)
            if (ch[0][x]) q.push(ch[0][x]);
        while (!q.empty()) {
            int u = q.front(); q.pop();
            last[u] = wlen[u] ? u : last[fail[u]];
            for (int x = 0; x < 26; x++) {
                int v = ch[u][x];
                if (v) { fail[v] = ch[fail[u]][x]; q.push(v); }
                else    ch[u][x] = ch[fail[u]][x];
            }
        }
        // 3. 扫 target，沿 last 链枚举「是当前后缀的单词」
        const long long INF = LLONG_MAX / 2;
        vector<long long> f(n + 1, INF);
        f[0] = 0;
        int cur = 0;
        for (int i = 1; i <= n; i++) {
            cur = ch[cur][target[i - 1] - 'a'];
            for (int v = last[cur]; v; v = last[fail[v]])
                f[i] = min(f[i], f[i - wlen[v]] + wcost[v]);
        }
        return f[n] >= INF ? -1 : (int)f[n];
    }
};
```

### Python（方法二：AC 自动机；Python 下方法一约 8 s 有超时风险，不推荐）

```python
class Solution:
    def minimumCost(self, target: str, words: List[str], costs: List[int]) -> int:
        n = len(target)
        # 1. Trie，0 号为根
        ch = [[0] * 26]          # 儿子表（BFS 时同步确定化）
        wlen = [0]               # 该节点单词的长度（0 表示非单词）
        wcost = [-1]             # 该节点单词的最小成本
        for w, c in zip(words, costs):
            cur = 0
            for b in w:
                x = ord(b) - 97
                if ch[cur][x] == 0:
                    ch.append([0] * 26)
                    wlen.append(0)
                    wcost.append(-1)
                    ch[cur][x] = len(ch) - 1
                cur = ch[cur][x]
            wlen[cur] = len(w)
            wcost[cur] = c if wcost[cur] < 0 else min(wcost[cur], c)

        # 2. BFS 建 fail 并确定化
        sz = len(ch)
        fail = [0] * sz
        last = [0] * sz          # last[u]：u 的 fail 链上（含 u）最近的单词节点
        q = deque(ch[0][x] for x in range(26) if ch[0][x])
        while q:
            u = q.popleft()
            last[u] = u if wlen[u] else last[fail[u]]
            fu = ch[fail[u]]
            for x in range(26):
                v = ch[u][x]
                if v:
                    fail[v] = fu[x]
                    q.append(v)
                else:
                    ch[u][x] = fu[x]

        # 3. 扫 target，沿 last 链枚举「是当前后缀的单词」
        f = [inf] * (n + 1)
        f[0] = 0
        cur = 0
        for i in range(1, n + 1):
            cur = ch[cur][ord(target[i - 1]) - 97]
            best = f[i]
            v = last[cur]
            while v:
                t = f[i - wlen[v]] + wcost[v]
                if t < best:
                    best = t
                v = last[fail[v]]
            f[i] = best
        return -1 if f[n] == inf else f[n]
```

## 8. 边界情况与易错点

1. **重复单词不合并**：`words` 中同一字符串可出现多次，必须取最小成本（分桶 `min` / Trie 节点 `min`），否则补充示例会答 10 而非 6。
2. **循环顺序写反（最隐蔽的 WA）**：长度做外层时，短长度对 $f[j]$ 的更新无法传播给长长度已写下的 $f[i]$。反例：`target="abc"`，`words=["abc"/10, "a"/1, "bc"/1]`——正确答案 2（`a`+`bc`），长度外层无论升序降序都得不到 2；必须位置外层、长度内层。
3. **单模 $10^9$ 哈希**：期望假命中 $>1$，真能错（§4 第 1 条的账）；要双哈希或 $2^{61}-1$。
4. **C++ 负模**：`(a - b*p) % M` 可能为负，`+M` 再 `%M`。
5. **$\infty$ 参与加法**：`f[j] = ∞` 时 `f[j] + cost` 若用 `INT_MAX` 会溢出；用 `LLONG_MAX/2`，或先判可达。
6. **AC 自动机裸跳 fail 链**：链上大量非单词节点，`target` 全 `'a'` + 单个长单词 `$a^{50000}$` 时为 $\Theta(n^2)$ 步，必超时；`last` 指针只跳单词节点后降为 $O(n\sqrt L)$。
7. **中途 $+\infty$ 误判 $-1$**：只有 $f[n]$ 为 $+\infty$ 才返回 $-1$；示例 1 中 $f[1]=f[2]=f[5]=\infty$ 毫不妨碍 $f[6]=7$。
8. **长度大于 $n$ 的单词**：永不匹配，分桶时跳过（省时间）；建 Trie 不跳也只是浪费空间，不影响正确性。
9. **答案上界**：$5\times10^4\times10^4 = 5\times10^8$，`int` 恰好装下，但保险起见全程 `long long`（Python 无此虑）。
