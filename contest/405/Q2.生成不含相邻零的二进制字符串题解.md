# LeetCode 生成不含相邻零的二进制字符串 题解

## 1. 题目概述

- **标题 / 题号**：生成不含相邻零的二进制字符串（#3211，medium）
- **链接**：https://leetcode.cn/problems/generate-binary-strings-without-adjacent-zeros/
- **来源**：LeetCode 第 405 场周赛 Q2
- **难度**：中等
- **标签**：位运算、字符串、回溯

**题意**：给定正整数 $n$，一个长度为 $n$ 的二进制串 $x$ 称为**有效**，当且仅当它的**每个长度为 2 的子串**都**至少含一个 `'1'`**。返回所有长度为 $n$ 的有效串，顺序不限。

**约束**：

- $1 \le n \le 18$

> 💡 读题关键：①「所有长度为 2 的子串」就是全部 $n-1$ 个**相邻对** $x_ix_{i+1}$；②「至少一个 1」⟺ 该对**不是 `"00"`**；③ $n \le 18$ 暗示 $2^{18} = 262144$ 的指数枚举完全可行；④ $n = 1$ 时不存在长度 2 的子串，条件**空真**，`"0"` 也有效。

## 2. 示例

**示例 1**

```text
输入：n = 3
输出：["010","011","101","110","111"]
解释：长度为 3 的有效串恰为这 5 个。
      "000"、"001" 含子串 "00"（窗口 [0,1]），"100" 含子串 "00"（窗口 [1,2]），均无效。
```

**示例 2**

```text
输入：n = 1
输出：["0","1"]
解释：没有长度为 2 的子串，条件空真，两个串都有效。
```

**补充示例（n = 2）**

```text
输入：n = 2
输出：["01","10","11"]
解释：四个 2 位串中只有 "00" 无效；合法个数 3 = F(4)。
```

## 3. 解题思路

### 3.1 暴力思路

枚举 $0 \sim 2^n - 1$ 的每个整数，转成 $n$ 位二进制串（**补齐前导零**），逐对检查相邻字符是否出现 `"00"`。复杂度 $O(2^n \cdot n)$，$n = 18$ 时约 $4.7 \times 10^6$，**能过**。但答案只有 6765 个（见 3.2），**97% 以上的检查都花在注定非法的串上**——枚举生成的是「全集」，而要的只是一小簇。

### 3.2 核心观察：条件 ⟺ 无相邻零

![核心观察：每个长度 2 的子串至少一个 1 等价于无相邻零](images/w405_no_adj_zeros_concept.svg)

**观察 1（条件转化）**：长度为 2 的子串恰为 $x_ix_{i+1}$（$i = 0..n-2$）。「每个子串至少一个 1」⟺「不存在相邻两位**都是 0**」——这正是题名「不含相邻零」的来历，也是全题唯一需要的一步转化。

**观察 2（答案个数是 Fibonacci）**：设 $a(n)$ 为长度 $n$ 的合法串个数，按**末位**分类：末位 `1` ← 任意长度 $n-1$ 合法串；末位 `0` ← 倒数第二位必为 `1`，即长度 $n-2$ 合法串后接 `"10"`。故

$$a(n) = a(n-1) + a(n-2), \quad a(1) = 2,\ a(2) = 3$$

即 $a(n) = F(n+2)$（Fibonacci）：$a(18) = F(20) = 6765$，只占全集 $2^{18} = 262144$ 的约 $2.6\%$。

**观察 3（剪枝方向）**：与其「生成全集再过滤」，不如**在构造时就拒绝产生 `"00"`**——当前缀末位是 `'1'`（或前缀为空）才允许选 `'0'`，选 `'1'` 永远安全。这就是回溯剪枝：只走合法分支，检查成本转化为不生成非法前缀。

### 3.3 算法流程：回溯剪枝生成

![回溯决策树与剪枝](images/w405_no_adj_zeros_flow.svg)

```text
dfs(path):
  1. if |path| == n：收集 path，返回
  2. 若 path 为空 或 path 末位 == '1'：
        append '0' → dfs → 回退        ← 选 0 有前置条件
  3. append '1' → dfs → 回退            ← 选 1 永远允许
```

按「先 `'0'` 后 `'1'`」的顺序展开，输出天然是**字典序**。

### 3.4 示例演算

![枚举与位技巧演算](images/w405_no_adj_zeros_walkthrough.svg)

对照枚举视角（$n = 3$）：令 $x = \mathrm{num} \,|\, (\mathrm{num} \gg 1)$，则 $x$ 的第 $i$ 位是「$b_i$ 或 $b_{i+1}$」。判据「低 $n-1$ 位全 1」即 `(x & mask) == mask`（`mask = (1 << (n-1)) - 1`）——一次位运算替代整趟扫描：

| num | 串 | x = num\|(num>>1) | x & mask | 判定 |
|-----|------|-------------------|----------|------|
| 0 | `000` | `000` | $0 \ne 3$ | ✗ |
| 1 | `001` | `001` | $1 \ne 3$ | ✗ |
| 2 | `010` | `011` | $3$ | ✓ |
| 3 | `011` | `011` | $3$ | ✓ |
| 4 | `100` | `110` | $2 \ne 3$ | ✗ |
| 5 | `101` | `111` | $3$ | ✓ |
| 6 | `110` | `111` | $3$ | ✓ |
| 7 | `111` | `111` | $3$ | ✓ |

5 个合法串与示例 1 一致；两行 ✗（`000`、`001`）卡在窗口 $[0,1]$，一行 ✗（`100`）卡在窗口 $[1,2]$。

## 4. 算法细节

1. **条件转化的逐字映射**：「长度为 2 的子串」→ 相邻对 $x_ix_{i+1}$；「至少一个 1」→ $\ne$ `"00"`；对所有 $i$ 取合取即得「无相邻零」。$n = 1$ 时 $i$ 的取值范围为空，条件**空真**。
2. **剪枝条件**：`append '0'` 当且仅当 `path.empty() || path.back() == '1'`。等价地：每个 `'0'` 的右邻居（若存在）必是 `'1'`。
3. **位技巧判据**：$\mathrm{num} \,|\, (\mathrm{num} \gg 1)$ 的第 $i$ 位为 $b_i \lor b_{i+1}$，于是「无相邻零」⟺ 该值低 $n-1$ 位全 1 ⟺ `(x & mask) == mask`。**方向不能反**：右移把窗口 $[i, i+1]$ 对齐到第 $i$ 位，写 `num << 1` 会引入第 $n$ 位的窗口且把最高位顶出去。
4. **前导零**：枚举 `num` 转串必须补齐 $n$ 位（`format(x, f"0{n}b")`），否则 `"010"` 退化成 `"10"`，连长度都不对。
5. **输出顺序**：题目允许任意顺序（判题器按集合比较）；回溯按「先 `0` 后 `1`」展开即得字典序，与示例一致。

## 5. 正确性证明

**引理 1（条件等价）**：当 $n \ge 2$ 时，$x$ 有效 ⟺ 不存在 $i \in [0, n-2]$ 使 $x_i = x_{i+1} = 0$。

**证明**：长度恰为 2 的子串恰为 $x_ix_{i+1}$（$i = 0, \dots, n-2$），共 $n-1$ 个；而「该子串含至少一个 1」⟺「该子串 $\ne$ `00`」。对所有 $i$ 逐条取合取即得。∎

**引理 2（Fibonacci 计数）**：记 $a(n)$ 为长度 $n$ 的合法串个数，约定 $a(0) = 1$（空串），则 $n \ge 2$ 时 $a(n) = a(n-1) + a(n-2)$。

**证明**：按末位把长度 $n$ 的合法串划分为不交的两类。① 末位为 `1`：去掉末位得长度 $n-1$ 的合法串，且此对应是双射——新串的全部相邻对 = 去尾串的相邻对 ∪ 最后的对 $(x_{n-2}, 1)$，后者以 `1` 结尾必含 1；反之给合法串添 `1` 不会产生新的 `"00"`。② 末位为 `0`：由引理 1 必有 $x_{n-2} = 1$，故 $x = x' + $ `10`，$x'$ 是长度 $n-2$ 的合法串，同样构成双射。两类不交且穷尽，故 $a(n) = a(n-1) + a(n-2)$（$n = 2$ 时 $3 = 2 + 1$ 亦验）。∎

**定理**：回溯算法输出的列表恰为全体长度 $n$ 的合法串，且无重复。

**证明**：算法每条完整执行路径 append 的字符顺次连接即为其输出，不同路径产出不同串，故**无重复**。①（不漏）设 $x$ 合法，对其前缀逐步归纳：若 $x_i = 0$，由引理 1 有 $x_{i-1} = 1$（或 $i = 0$），剪枝条件成立，`'0'` 分支存在；`'1'` 分支恒存在。故 $x$ 对应的路径完整走到底、被收集。②（不错）反设某输出 $y$ 含相邻零 $y_j = y_{j+1} = 0$，则 append $y_{j+1}$ 时前缀非空且末位为 $y_j = 0$，剪枝条件不成立，该分支根本不存在，矛盾。综上输出集 = 合法串集。∎

## 6. 复杂度分析

- **时间复杂度（回溯）**：$O(a(n) \cdot n) = O(F(n+2) \cdot n)$。每条根到叶路径长 $n$、每步 $O(1)$；树中节点全是合法前缀，总数 $\sum_{k=0}^{n} a(k) = a(n+2) - 1$。$n = 18$ 时约 $6765 \times 18 \approx 1.2 \times 10^5$。
- **时间复杂度（枚举 + 位技巧）**：$O(2^n)$——每个 `num` 一次 $O(1)$ 位判据，仅对合法者付出 $O(n)$ 的转串成本。$n = 18$ 时约 $2.6 \times 10^5$ 次判定。
- **空间复杂度**：递归深度与路径缓冲 $O(n)$（不计输出）；输出本身 $O(a(n) \cdot n)$，$n = 18$ 时为 6765 串 × 18 字符。
- **对照**：朴素枚举检查 $O(2^n \cdot n) \approx 4.7 \times 10^6$ 也能过——本题范围放得宽，考的是「条件转化 + 只生成合法分支」的意识。

## 7. 参考代码

### C++（回溯剪枝生成）

```cpp
class Solution {
public:
    vector<string> validStrings(int n) {
        vector<string> ans;
        string path;
        auto dfs = [&](auto&& dfs) {
            if ((int) path.size() == n) {
                ans.push_back(path);
                return;
            }
            if (path.empty() || path.back() == '1') {  // 选 '0'：前一位须为 '1'
                path.push_back('0');
                dfs(dfs);
                path.pop_back();
            }
            path.push_back('1');                        // 选 '1'：无前置条件
            dfs(dfs);
            path.pop_back();
        };
        dfs(dfs);
        return ans;
    }
};
```

### Python（枚举 + 位技巧一行流）

```python
class Solution:
    def validStrings(self, n: int) -> List[str]:
        mask = (1 << (n - 1)) - 1                     # 低 n-1 位全 1
        return [format(x, f"0{n}b") for x in range(1 << n)
                if (x | (x >> 1)) & mask == mask]     # 无相邻零 ⟺ 各窗口含 1
```

## 8. 边界情况与易错点

1. **条件误读（最大坑）**：「每个长度 2 的子串至少一个 1」**不是**「整串至少一个 1」。`"001"` 含 `1`，但子串 `"00"` 违规，**无效**；误读者会错误收下所有含 `1` 的串。
2. **$n = 1$ 空真**：无长度 2 子串，`"0"`、`"1"` 均有效。位技巧此时 `mask = 0`，判据 `(x & 0) == 0` 恒真——与「空真」是同一件事（0 个约束的合取），**无需特判**。
3. **前导零丢失**：`bin(num)[2:]` 不补零会把 `"010"` 变 `"10"`；必须 `zfill(n)` 或 `format(x, f"0{n}b")`。
4. **朴素检查的循环范围**：窗口右端点须满足 $i + 1 \le n - 1$，即 `for i in range(n - 1)`；写成 `range(n)` 则访问 `s[n]`——Python 抛 IndexError，C++ 读 `std::string` 的 `s[n]` 返回 `'\0'` 但比较逻辑已错。
5. **位技巧方向**：必须 `num >> 1`（把 $b_{i+1}$ 挪到第 $i$ 位与 $b_i$ 会合）；写 `num << 1` 窗口错位且把第 $n-1$ 位顶出范围。
6. **`mask` 是低 $n-1$ 位**：对应 $n-1$ 个相邻对；误写 `(1 << n) - 1` 会要求低 $n$ 位全 1，把最高位为 `0` 的合法串（如 `"010"`，$x = $ `011`）误杀。
