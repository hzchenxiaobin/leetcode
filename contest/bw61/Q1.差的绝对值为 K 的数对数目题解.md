# LeetCode 差的绝对值为 K 的数对数目 题解

## 1. 题目概述

- **标题 / 题号**：差的绝对值为 K 的数对数目（#2006，easy）
- **链接**：https://leetcode.cn/problems/count-number-of-pairs-with-absolute-difference-k/
- **来源**：LeetCode 第 61 场双周赛 Q1（2021-09-18）
- **难度**：简单
- **标签**：数组、哈希表、计数

**题意**：给定整数数组 `nums` 与整数 $k$，统计满足 $i < j$ 且 $|nums[i] - nums[j]| = k$ 的下标对 $(i, j)$ 的数目。

**约束**：

- $1 \le nums.length \le 200$
- $1 \le nums[i] \le 100$
- $1 \le k \le 99$

> 💡 签到题的要点不在「能不能做出来」，而在于能否在 2 分钟内把「值域极小」这个条件翻译成 $O(n + V)$ 的桶计数，绕开 $O(n^2)$ 的默认写法。

## 2. 示例

**示例 1**

```text
输入：nums = [1,2,2,1], k = 1
输出：4
解释：差的绝对值为 1 的数对为 (0,1)、(0,2)、(1,3)、(2,3)。
```

**示例 2**

```text
输入：nums = [1,3], k = 3
输出：0
解释：|1 - 3| = 2 ≠ 3，没有任何满足条件的数对。
```

**示例 3**

```text
输入：nums = [3,2,1,5,4], k = 2
输出：3
解释：数对 (3,1)、(3,5)、(2,4)，即值对 {3,1}、{3,5}、{2,4}。
```

## 3. 解题思路

### 3.1 暴力思路

双重循环枚举所有 $i < j$，逐对判断 $|nums[i] - nums[j]| = k$。$n \le 200$ 时至多 $\frac{200 \times 199}{2} = 19900$ 对，$O(n^2)$ 完全可以通过。但在值域 $V \le 100$ 的条件下，这一做法没有利用任何结构信息：相同数值的下标在桶里本质等价，逐对判断做了大量重复工作。比赛时可以直接写暴力抢时间，但赛后值得沉淀桶计数写法——它把复杂度降到 $O(n + V)$，并且在 $n$ 放大到 $10^5$ 级别时依然成立。

### 3.2 核心观察：值域计数桶，按「值对」而非「下标对」统计

![核心观察：值域计数桶，差为 k 的值对连线](images/bw61_q1_bucket_counting.svg)

设 $cnt[v]$ 表示值 $v$ 在 `nums` 中的出现次数。由于 $k \ge 1$，一个无序数对 $\{i, j\}$ 满足 $|nums[i] - nums[j]| = k$ 当且仅当这两个下标的值恰好是某个值对 $(v, v + k)$：较小的值是 $v$，较大的值是 $v + k$。这样的值对个数就是

$$
ans = \sum_{v=1}^{100-k} cnt[v] \times cnt[v+k]
$$

值 $v$ 的任一个出现位置与值 $v+k$ 的任一个出现位置配对，都构成一个合法的 $i < j$ 数对；值不同保证了两桶之间不会选到同一个下标，也保证每个无序数对只被唯一一个 $v$ 统计。

### 3.3 算法流程

```text
1. 开桶 cnt[1..100]，扫描 nums 一遍计数：cnt[x]++
2. ans = 0
3. for v = 1 to 100 - k:
4.     ans += cnt[v] * cnt[v + k]
5. 返回 ans
```

整个过程一次线性计数 + 一趟值域枚举，与 $n$ 的平方无关。

### 3.4 示例演算

![示例演算：nums=[3,2,1,5,4]，k=2 的桶配对](images/bw61_q1_example_pairs.svg)

以示例 3（$nums = [3,2,1,5,4]$，$k = 2$）为例，五个值各出现一次：

| $v$ | 值对 $(v, v+2)$ | 贡献 $cnt[v] \cdot cnt[v+2]$ |
|-----|-----------------|------------------------------|
| 1 | (1, 3) | $1 \times 1 = 1$ |
| 2 | (2, 4) | $1 \times 1 = 1$ |
| 3 | (3, 5) | $1 \times 1 = 1$ |
| 4 | (4, 6)，$cnt[6] = 0$ | $0$ |

合计 $ans = 3$，与示例一致。示例 1 中 $cnt[1] = 2$、$cnt[2] = 2$，$k = 1$ 时 $ans = 2 \times 2 = 4$，正是四个数对。

## 4. 算法细节

1. **桶大小开 101**：值域 $[1, 100]$，`cnt[v+k]` 的最大下标是 $100$，数组开 $101$ 即可；循环上界 $100 - k$ 保证不越界。
2. **$k \ge 1$ 是「不除以 2」的根据**：两桶值 $v$ 与 $v+k$ 不同，任意有序选取都对应不同的下标对，$cnt[v] \cdot cnt[v+k]$ 恰是无序下标对的个数。若题目允许 $k = 0$（本题约束排除），则同一桶内的组合数是 $\binom{cnt[v]}{2}$，公式需要单独分支。
3. **乘积用宽类型更稳**：单桶最多 $200$，单项乘积至多 $10^4$，总和上界 $\binom{200}{2} = 19900$，`int` 足够；但用 `long long` 累加可以免疫值域放大后的溢出，是更可迁移的习惯。
4. **值域更大时换哈希表**：若值域没有上界，把桶换成哈希表，一次遍历中执行 $ans \mathrel{+}= cnt[x-k] + cnt[x+k]$（仅对 $k > 0$ 成立，此时两个方向不重复），再 $cnt[x]\mathrel{+}=1$，复杂度 $O(n)$。
5. **先计数后枚举 vs 边扫边查**：前者代码更短且天然无重复；后者不需要预知道值域上界。两者本题等价，按口味选择。

## 5. 正确性证明

**引理 1（无序化）**：条件 $i < j$ 且 $|nums[i] - nums[j]| = k$ 的下标对集合，与全体无序下标对 $\{i, j\}$（$i \ne j$）中满足 $|nums[i] - nums[j]| = k$ 的集合一一对应。

**证明**：任意有序对 $(i, j)$（$i < j$）对应无序对 $\{i, j\}$，反之任意无序对 $\{i, j\}$ 排序后得到唯一的有序对。绝对值条件只依赖下标集合，与顺序无关，故对应保持条件成立。∎

**引理 2（值对计数）**：设 $0 < k$，则满足 $|nums[i] - nums[j]| = k$ 的无序对 $\{i, j\}$ 中，两值构成 $(v, v + k)$（$nums$ 较小值为 $v$）的对数恰为 $cnt[v] \cdot cnt[v + k]$。

**证明**：$|a - b| = k$ 且 $a \ne b$ 等价于 $\{a, b\} = \{v, v + k\}$ 对某个 $v \ge 1$ 成立（较小值为 $v$，较大值为 $v+k$；两值不等保证较小值唯一确定 $v$）。枚举较小值所在桶的下标 $i$（共 $cnt[v]$ 种）与较大值所在桶的下标 $j$（共 $cnt[v+k]$ 种），两个不同桶保证 $i \ne j$，且每个无序对被唯一分解为「较小值下标 × 较大值下标」，故恰为 $cnt[v] \cdot cnt[v+k]$ 个。∎

**定理**：$ans = \sum_{v=1}^{100-k} cnt[v] \cdot cnt[v+k]$ 等于所求下标对数目。

**证明**：由引理 1，只需数无序对。由引理 2，把无序对按较小值 $v$ 分类：$v$ 的可能取值是 $1, \dots, 100 - k$（因为较大值 $v + k \le 100$ 需在值域内），不同 $v$ 对应的值对 $(v, v+k)$ 两两不同（较小值不同），故分类不重不漏；每类贡献 $cnt[v] \cdot cnt[v+k]$。求和即得。∎

## 6. 复杂度分析

- **时间**：$O(n + V)$。一趟计数 $O(n)$，一趟值域枚举 $O(V)$，其中 $V = 101$ 为常数；当 $n$ 与 $V$ 同阶时即线性。
- **空间**：$O(V)$。仅一个长度 $101$ 的计数数组。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int countKDifference(vector<int>& nums, int k) {
        int cnt[101] = {0};
        for (int x : nums) ++cnt[x];                  // 值域桶计数
        long long ans = 0;
        for (int v = 1; v + k <= 100; ++v)            // 枚举较小值 v
            ans += (long long)cnt[v] * cnt[v + k];    // 值对 (v, v+k) 的组合数
        return (int)ans;
    }
};
```

### Python

```python
class Solution:
    def countKDifference(self, nums: list[int], k: int) -> int:
        cnt = [0] * 101
        for x in nums:
            cnt[x] += 1
        return sum(cnt[v] * cnt[v + k] for v in range(1, 101 - k))
```

> 💡 两份代码均通过官方三个示例（`4`、`0`、`3`），并与 $O(n^2)$ 暴力做了 3000 组随机对拍（$n \le 200$，值域 $[1,100]$，含 $k = 1$ 与 $k = 99$ 边界），`mismatch = 0`。

## 8. 边界情况与易错点

1. **$k$ 可能大于值域直径**：如 $nums = [1, 3]$、$k = 3$，循环范围 $[1, 100 - k]$ 内所有乘积为 0，自然返回 0，无需特判，但要保证循环上界写成 $100 - k$ 而非固定 100，否则 `cnt[v+k]` 越界。
2. **不要除以 2**：$k \ge 1$ 时 $cnt[v] \cdot cnt[v+k]$ 已经是无序对个数，再除 2 会错；只有 $k = 0$（同桶配对）才需要 $\binom{cnt[v]}{2}$，而本题约束 $k \ge 1$。
3. **桶下标从值域出发**：`cnt` 数组长度取 $101$（下标 $0 \sim 100$），既容纳值 100，也让「下标即值」的写法成立。
4. **暴力写法的循环边界**：$j$ 从 $i + 1$ 开始，避免重复计数与自配对。
5. **哈希表版本的方向去重**：边扫边查时对每个 $x$ 累加 $cnt[x-k] + cnt[x+k]$ 只在 $k > 0$ 时正确；$k = 0$ 会把同一桶算两遍。
