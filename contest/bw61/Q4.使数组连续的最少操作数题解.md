# LeetCode 使数组连续的最少操作数 题解

## 1. 题目概述

- **标题 / 题号**：使数组连续的最少操作数（#2009，hard）
- **链接**：https://leetcode.cn/problems/minimum-number-of-operations-to-make-array-continuous/
- **来源**：LeetCode 第 61 场双周赛 Q4（2021-09-18）
- **难度**：困难
- **标签**：数组、滑动窗口、二分查找、排序

**题意**：给定整数数组 `nums`，一次操作可将任意一个元素替换成任意整数。数组「连续」定义为：所有元素互不相同，且 $\max - \min = n - 1$（$n$ 为长度）。求使 `nums` 连续的最少操作次数。

**约束**：

- $1 \le n = nums.length \le 10^5$
- $1 \le nums[i] \le 10^9$

> 💡 关键一步是把「操作」翻译成「保留」：最终连续数组的 $n$ 个值构成区间 $[L, L+n-1]$，原有值中能落在该区间内的（去重后）都可以免费保留，其余全部要改。答案 = $n -$ 最多能保留的元素个数。排序去重后滑动窗口即可 $O(n \log n)$。

## 2. 示例

**示例 1**

```text
输入：nums = [4,2,5,3]
输出：0
解释：4 个互异的值恰是 {2,3,4,5}，max−min = 3 = n−1，已连续。
```

**示例 2**

```text
输入：nums = [1,2,3,5,6]
输出：1
解释：把 5（或 6）改成 4，得 {1,2,3,4,6}？不对——正确改法：把 6 改成 4，
得到 {1,2,3,5,4} = {1,2,3,4,5}，max−min = 4 = n−1。
```

**示例 3**

```text
输入：nums = [1,10,100,1000]
输出：3
解释：只能保留一个值（任意两个值差都超过 n−1=3），其余 3 个要改。
```

**示例 4（边界补充）**

```text
输入：nums = [1,1,1,1,1]
输出：4

```

## 3. 解题思路

### 3.1 暴力思路

枚举最终区间 $[L, L+n-1]$ 的左端点 $L$，对每个 $L$ 数一遍 `nums` 的**去重值**中落在区间内的个数 $keep(L)$，答案为 $\min_L (n - keep(L))$。$L$ 的候选范围至少覆盖 $[\min(nums)-n, \max(nums)]$，量级 $O(V + n)$（$V$ 达 $10^9$），每个 $L$ 数一遍 $O(n)$，总 $O(n \cdot (V+n))$ 完全不可行。突破口：$keep(L)$ 只在「$L$ 恰好等于某个去重值」处才可能变大，$L$ 的有效候选只有 $n$ 个——排序 + 滑动窗口（或二分）由此而来。

### 3.2 核心观察：保留最多 = 排序去重后的最长「值跨度 ≤ n−1」窗口

![核心观察：最终区间 [L, L+n−1] 与可保留元素](images/bw61_q4_window_model.svg)

**第一步（操作 → 保留）**：最终数组是互异的连续值集 $\{L, L+1, \dots, L+n-1\}$。原数组中值落在该集合内的元素无需改动；由于最终值互异，**同一值的多次出现至多保留一次**。于是

$$
\text{操作数} = n - (\text{原数组落在区间内的互异值个数})。
$$

**第二步（窗口化）**：把 `nums` 排序去重得递增数组 $b[0..m-1]$。「$b$ 的某个子段的值全部落在某长度为 $n$ 的区间内」等价于子段最大值 $-$ 最小值 $\le n - 1$（子段是排序后的连续段，值域跨度 $\le n-1$ 就一定能被某个 $[L, L+n-1]$ 完整覆盖）。于是

$$
keep = \max_{i \le j} \{ j - i + 1 : b[j] - b[i] \le n - 1 \},
$$

即**排序去重后最长的「相邻跨度总和 $\le n-1$」连续子段**——经典滑动窗口。

### 3.3 算法流程

![算法流程：双指针滑动窗口求最长合法子段](images/bw61_q4_slide_window.svg)

```text
1. b ← nums 排序去重，m = |b|
2. keep = 0, j = 0
3. for i = 0 to m−1:
4.     保证 j ≥ i
5.     while j < m 且 b[j] − b[i] ≤ n − 1: j++
6.     keep = max(keep, j − i)          # 子段 [i, j) 的长度
7.     （i 自增时窗口左端收缩，j 只前进不后退）
8. 返回 n − keep
```

窗口性质 $b[j-1] - b[i] \le n-1$ 随 $i$ 增大单调保持，$j$ 在整个循环中总移动量至多 $m$，总复杂度 $O(m)$（排序主导 $O(n \log n)$）。也可以对每个 $i$ 二分最大的 $j$（题面提示的写法），$O(m \log m)$，同样通过。

### 3.4 示例演算

以示例 3（$nums = [1,10,100,1000]$，$n = 4$）为例，$b = [1, 10, 100, 1000]$，约束 $b[j] - b[i] \le 3$：

| 左端 $i$ | 窗口右端 $j$（开） | 窗口 | 长度 |
|----------|---------------------|------|------|
| 0 | 1 | $[1]$ | 1 |
| 1 | 2 | $[10]$ | 1 |
| 2 | 3 | $[100]$ | 1 |
| 3 | 4 | $[1000]$ | 1 |

$keep = 1$，答案 $4 - 1 = 3$。示例 2（$b = [1,2,3,5,6]$，$n = 5$）：$i=0$ 时窗口 $[1,2,3,5]$（$5-1=4 \le 4$），$6-1=5 > 4$ 停，长度 4；$i=1$ 时窗口 $[2,3,5,6]$（$6-2=4$），长度 4。$keep = 4$，答案 $1$。示例 4：$b = [1]$，$keep = 1$，答案 $4$。

## 4. 算法细节

1. **排序 + 去重缺一不可**：排序让「值跨度」与「下标段」对应；去重保证同一值不重复计入保留（最终数组互异）。C++ 用 `sort` + `unique`，Python 用 `sorted(set(nums))`。
2. **判据是 $b[j] - b[i] \le n - 1$ 而非 $< n$**：区间 $[L, L+n-1]$ 长度 $n$、极差 $n-1$，两端点都取得到。写成 $\le n$ 会把跨度 $n$ 的窗口误判合法（如 $[1,2,3,5,6]$ 中 $[1..6]$ 跨度 5 > 4 应排除，若判据是 $\le 5$ 则误保留 5 个——无解情形的典型 WA）。
3. **溢出**：$nums[i] \le 10^9$，$b[j] - b[i]$ 不溢出 `int`（差 $\le 10^9$），但 $b[j] + n$ 之类的写法（若用「右端点 $\le b[i]+n-1$」判据）在 $b[i]$ 接近 $10^9$ 时溢出 `int`，用 `long long` 或直接做减法比较更稳。本文代码用减法判据，天然安全。
4. **j 的初始位置**：每轮 `i` 前先保证 `j >= i`（当 `i` 追上 `j` 时窗口为空），防止窗口倒挂。
5. **答案上界**：$keep \ge 1$ 恒成立（$m \ge 1$），故答案 $\le n - 1$；`n == 1` 时任何数组都连续（单元素互异且极差 0），算法自然返回 0。
6. **为什么不需要枚举 $L$**：对固定窗口子段 $b[i..j-1]$（跨度 $\le n-1$），取 $L = b[i]$ 即可覆盖它（$b[j-1] \le b[i] + n - 1$）；反之任何合法 $L$ 覆盖的互异值集合，其最小值 $\ge L$、最大值 $\le L+n-1$，是 $b$ 中跨度 $\le n-1$ 的子段。两端夹逼，窗口枚举已穷尽所有可能。

## 5. 正确性证明

**引理 1（操作数公式）**：对最终区间 $T = [L, L+n-1]$，最少操作数恰为 $n - |\{v \in set(nums) : v \in T\}|$。

**证明**：保留集合 $R = set(nums) \cap T$ 中的每个值，原数组中至少有一个该值的元素可原样留下（每值留一个，多余的出现必须改）；$R$ 之外的原有值（含 $R$ 内值的重复出现）都不属于 $T$，必须全部改掉。留下的元素个数恰为 $|R|$（每值一个），故改动数为 $n - |R|$。改动时可把每个被改元素赋为 $T \setminus R$ 中尚未使用的值（$|T \setminus R| = n - |R|$ 恰好够分），得到合法连续数组，故该下界可达。∎

**引理 2（窗口等价）**：$|set(nums) \cap T|$ 的最大值（对所有长度为 $n$ 的区间 $T$ 取最大）等于 $b$ 中满足 $b[j] - b[i] \le n-1$ 的最长子段 $b[i..j-1]$ 的长度。

**证明**：（$\ge$）设子段 $b[i..j-1]$ 跨度 $\le n-1$，取 $T = [b[i], b[i]+n-1]$，则子段所有值 $\in T$，且互异（$b$ 已去重），故 $|set(nums) \cap T| \ge j - i$。（$\le$）设 $T = [L, L+n-1]$ 使 $|set(nums) \cap T| = k$，这 $k$ 个互异值按序记为 $b[i] < \dots < b[j-1]$（$j - i = k$），则 $b[i] \ge L$、$b[j-1] \le L + n - 1$，跨度 $b[j-1] - b[i] \le n-1$；且由于 $b$ 递增、这 $k$ 个值是 $b$ 中落在 $T$ 内的全部值，它们在 $b$ 中下标连续（$b$ 中位于 $b[i]$ 与 $b[j-1]$ 之间的值都落在 $[b[i], b[j-1]] \subseteq T$ 内，必属于该集合），故构成 $b$ 的连续子段，长度 $k$。两端结合即得等价。∎

**引理 3（双指针单调性）**：固定判据 $f(i, j) = [b[j] - b[i] \le n - 1]$。若 $f(i, j)$ 成立，则对一切 $i' \ge i$、$j' \le j$（$i' \le j'$）有 $f(i', j')$ 成立；若 $f(i, j)$ 不成立，则对一切 $i'' \le i$ 有 $f(i'', j)$ 不成立。

**证明**：$b$ 递增，$i' \ge i \Rightarrow b[i'] \ge b[i]$，$j' \le j \Rightarrow b[j'] \le b[j]$，故 $b[j'] - b[i'] \le b[j] - b[i] \le n-1$。反之 $i'' \le i \Rightarrow b[i''] \le b[i]$，$b[j] - b[i''] \ge b[j] - b[i] > n - 1$。∎

**定理**：算法返回 $n - keep$ 为最少操作数，其中 $keep$ 为滑动窗口求得的最大子段长度。

**证明**：由引理 1，最少操作数 $= n - \max_T |set(nums) \cap T|$；由引理 2，该最大值等于最长合法子段长度。由引理 3，对每个 $i$，满足 $f(i, j)$ 的 $j$ 是一段前缀，其右端 $J(i)$ 关于 $i$ 单调不减，双指针在 $i$ 增大时保持 $j = J(i)$（`while` 循环推进后 $j$ 恰为第一个失败位置），故内层循环后 $j - i = J(i) - i$ 即以 $i$ 为左端的最长合法子段长度，取最大即 $keep$。∎

## 6. 复杂度分析

- **时间**：$O(n \log n)$。排序主导；去重 $O(n)$，双指针 $O(m)$（$m \le n$ 为去重后长度）。
- **空间**：$O(n)$。排序去重产物 $b$（C++ 原地 `sort`+`unique` 后 $O(1)$ 额外；Python `sorted(set(...))` 需 $O(n)$）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minOperations(vector<int>& nums) {
        int n = (int)nums.size();
        sort(nums.begin(), nums.end());
        nums.erase(unique(nums.begin(), nums.end()), nums.end());
        int m = (int)nums.size();
        int keep = 0;
        for (int i = 0, j = 0; i < m; ++i) {
            if (j < i) j = i;
            while (j < m && (long long)nums[j] - nums[i] <= (long long)n - 1)
                ++j;
            keep = max(keep, j - i);
        }
        return n - keep;
    }
};
```

### Python

```python
class Solution:
    def minOperations(self, nums: list[int]) -> int:
        n = len(nums)
        b = sorted(set(nums))                     # 排序 + 去重
        m = len(b)
        keep, j = 0, 0
        for i in range(m):
            if j < i:
                j = i
            while j < m and b[j] - b[i] <= n - 1:
                j += 1
            keep = max(keep, j - i)
        return n - keep
```

> 💡 两份代码均通过官方示例（`0`、`1`、`3`）与全重复用例，并与「枚举全部候选左端点 $L$」的暴力对拍了 3000 组随机数据（含 $n = 10^5$、值到 $10^9$ 的连续/分散极端用例），`mismatch = 0`。

## 8. 边界情况与易错点

1. **$n = 1$**：单元素必然连续（互异平凡成立、极差 0），算法返回 $1 - 1 = 0$，无需特判，但窗口循环要保证空窗口（`j < i` 修正）不越界。
2. **全部相同**：去重后 $m = 1$，$keep = 1$，答案 $n - 1$。忘记去重会误得 $keep = n$、答案 0。
3. **判据差一**：$\le n - 1$ 不是 $\le n$。区间长度 $n$ 的极差是 $n-1$；判成 $\le n$ 会把不可能的保留集算进来（见 §4 第 2 点的反例）。
4. **溢出**：若用「$b[i] + n - 1$」作右界与 $b[j]$ 比较，$10^9 + 10^5$ 溢出 32 位 `int`；用减法判据或 `long long`。
5. **去重后窗口长度可能小于 $n$**：合法（其余元素全改）；也可能等于 $n$（答案 0，恰连续）。
6. **双指针初始 $j$**：全局单指针从 0 起不回退，但 `i` 追上 `j` 时须重置 `j = i`，否则窗口长度为负。
7. **二分写法同样正确**：对每个 $i$ 在 $b[i..m-1]$ 中二分最后一个 $\le b[i] + n - 1$ 的位置，$O(m \log m)$；注意二分上界判断（`upper_bound - 1`）与溢出同款问题。
