# LeetCode 找到最高海拔 题解

## 1. 题目概述

- **标题 / 题号**：找到最高海拔（#1732，easy）
- **链接**：https://leetcode.cn/problems/find-the-highest-altitude/
- **来源**：LeetCode 第 44 场双周赛 Q1
- **难度**：简单
- **标签**：数组、前缀和

**题意**：自行车手从海拔 $0$ 的点 $0$ 出发，`gain[i]` 是点 $i$ 与点 $i+1$ 之间的**净海拔差**。整条路线共 $n+1$ 个点，求骑行过程中到达过的**最高点的海拔**。

**约束**：

- $n = gain.length$，$1 \le n \le 100$
- $-100 \le gain[i] \le 100$

## 2. 示例

**示例 1**

```text
输入：gain = [-5,1,5,0,-7]
输出：1
解释：海拔依次为 [0,-5,-4,1,1,-6]，最高海拔 1。
```

**示例 2**

```text
输入：gain = [-4,-3,-2,-1,4,3,2]
输出：0
解释：海拔依次为 [0,-4,-7,-9,-10,-6,-3,-1]，最高海拔是起点的 0。
```

## 3. 解题思路

### 3.1 暴力思路

先建出整个海拔数组：`alt[0] = 0`，`alt[i+1] = alt[i] + gain[i]`，再取最大值。$O(n)$ 时间、$O(n)$ 空间，对本题完全够用；但海拔只依赖「当前前缀和」，可以边扫边比，把空间降到 $O(1)$。

### 3.2 核心观察：海拔就是前缀和

![海拔折线：gain 转换成海拔并标记最高点](images/bw44_q1_altitude_curve.svg)

点 $i$ 的海拔是**前缀和**：

$$h(i) = gain[0] + gain[1] + \cdots + gain[i-1], \qquad h(0) = 0.$$

要求的是 $\max_{0 \le i \le n} h(i)$。这是一个「滚动前缀和」——不需要保存整个数组，一个变量 `cur` 扫一遍即可。

### 3.3 算法流程

![一遍扫描的滚动状态：cur 与 best 同步更新](images/bw44_q1_prefix_scan.svg)

```text
cur = 0, best = 0        # 出发点海拔 0 必须参与比较
for g in gain:
    cur += g             # 前缀和推进
    best = max(best, cur)
return best
```

### 3.4 示例演算

以 `gain = [-5,1,5,0,-7]` 为例：`cur` 依次为 $-5, -4, 1, 1, -6$；`best` 依次为 $0, 0, 1, 1, 1$，返回 $1$ ✓。注意 `best` 的初值是 $0$（起点海拔），全程没被超过时返回 $0$（示例 2）。

## 4. 算法细节

1. **best 初值必须是 0**（起点海拔），不能是 $-\infty$——最高点可能是出发点本身。
2. **每次累加后立刻比较**，无需先算完所有前缀和。
3. **无需 long long**：海拔范围 $\pm 10^4$，`int` 充足。
4. **前缀和方向**：`gain[i]` 是「点 $i$ → 点 $i+1$」的差，从左到右累加即可，不要反向。

## 5. 正确性证明

**引理 1（海拔的闭式）**：点 $i$ 的海拔 $h(i) = \sum_{j<i} gain[j]$。

**证明**：$h(0) = 0$；$h(i+1) - h(i) = gain[i]$ 是题设，逐项累加即得。∎

**定理**：算法返回 $\max_{0 \le i \le n} h(i)$。

**证明**：循环不变量：处理完 `gain[0..k-1]` 后，`cur` = $h(k)$，`best` = $\max_{0 \le i \le k} h(i)$。初始 $k=0$：`cur = 0 = h(0)`，`best = 0 = h(0)` ✓。每一步 `cur += g` 保持第一式；`best = max(best, cur)` 把新的 $h(k+1)$ 纳入比较，保持第二式。循环结束 $k = n$，`best` 即全点最大海拔。∎

## 6. 复杂度分析

- **时间**：$O(n)$，一次线性扫描。
- **空间**：$O(1)$，只维护两个变量（建数组版本为 $O(n)$）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int largestAltitude(vector<int>& gain) {
        int cur = 0, best = 0;   // 出发点海拔为 0，答案至少为 0
        for (int g : gain) {
            cur += g;
            if (cur > best) best = cur;
        }
        return best;
    }
};
```

### Python

```python
class Solution:
    def largestAltitude(self, gain: list[int]) -> int:
        cur = best = 0          # 出发点海拔 0，答案至少为 0
        for g in gain:
            cur += g
            if cur > best:
                best = cur
        return best
```

> 💡 两份代码均通过官方示例（`1`、`0`），并与「先建海拔数组再取 max」的暴力在 10 万组随机数据上比对一致。

## 8. 边界情况与易错点

1. **全为负数**：最高海拔就是出发点的 $0$——`best` 初值给 $-\infty$ 或忘了起点会错（示例 2 即考点）。
2. **全为正数**：最高海拔是最后一点。
3. **`n = 1`**：只有起点和第二个点，循环只执行一次。
4. **海拔可以为负**：中间下探不要把 `best` 拉低——`best` 只升不降。
5. **读题**：$n+1$ 个点、`gain` 长度 $n$，海拔序列长度是 `n+1`；起点也算「到达过」。
