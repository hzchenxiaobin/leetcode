# LeetCode 解码异或后的排列 题解

## 1. 题目概述

- **标题 / 题号**：解码异或后的排列（#1734，medium）
- **链接**：https://leetcode.cn/problems/decode-xored-permutation/
- **来源**：LeetCode 第 44 场双周赛 Q3
- **难度**：中等
- **标签**：位运算、数组

**题意**：`perm` 是前 $n$ 个正整数的排列，且 **$n$ 为奇数**。加密规则为 `encoded[i] = perm[i] XOR perm[i+1]`，得到长 $n-1$ 的数组 `encoded`。给定 `encoded`，还原 `perm`（题目保证答案存在且唯一）。

**约束**：

- $3 \le n < 10^5$，$n$ 为奇数
- `encoded.length == n - 1`

## 2. 示例

**示例 1**

```text
输入：encoded = [3,1]
输出：[1,2,3]
解释：perm = [1,2,3]，encoded = [1⊕2, 2⊕3] = [3,1]。
```

**示例 2**

```text
输入：encoded = [6,5,4,6]
输出：[2,4,1,5,3]
```

## 3. 解题思路

### 3.1 为什么"逐段还原"失败

若直接从 `perm[0]` 出发：`perm[i+1] = perm[i] ⊕ encoded[i]`，只要知道任意一个 `perm[k]` 就能推出全部。难点只有一个：**求出任何一个 `perm[k]`**。`encoded` 里相邻两两异或，所有元素各出现两次、成对抵消，初看拿不到任何单独的 `perm[k]`——突破口藏在「perm 是 1..n 的排列」这一条件里。

### 3.2 核心观察：全体异或已知，隔项异或"差一个"

![隔项异或的望远镜结构与 n 必须为奇数的原因](images/bw44_q3_xor_telescope.svg)

两个事实：

1. **`perm` 的全体异或可以离线算出**：因为 `perm` 是 $1 \sim n$ 的排列，

$$\text{total} = perm[0] \oplus perm[1] \oplus \cdots \oplus perm[n-1] = 1 \oplus 2 \oplus \cdots \oplus n.$$

2. **`encoded` 的偶数下标异或恰好等于 `perm[0..n-2]` 的异或**：

$$\text{even} = encoded[0] \oplus encoded[2] \oplus \cdots \oplus encoded[n-3] = perm[0] \oplus perm[1] \oplus \cdots \oplus perm[n-2],$$

因为相邻两项配对相消：$encoded[0] = perm[0] \oplus perm[1]$、$encoded[2] = perm[2] \oplus perm[3]$、……这像一节节望远镜，把 $perm[0..n-2]$ **每个元素恰好覆盖一次**，唯独漏掉了 $perm[n-1]$。

两者一差，就把落单者揪出来：

$$perm[n-1] = \text{total} \oplus \text{even}.$$

> ⚠️ **$n$ 为奇数是前提**：$n-1$ 是偶数，偶数下标 $0, 2, \dots, n-3$ 恰好配对覆盖 $perm[0..n-2]$。若 $n$ 为偶数，偶数下标会覆盖 $perm[0..n-1]$ 全体，`total ⊕ even = 0`，什么都还原不出来。

### 3.3 从右往左逐项回推

![从末位向左回推 perm 的链条](images/bw44_q3_chain_recover.svg)

拿到 $perm[n-1]$ 后，用相邻异或的自反性（$a = b \oplus (a \oplus b)$）从右往左推：

$$perm[i] = perm[i+1] \oplus encoded[i], \qquad i = n-2, \dots, 0.$$

每步 $O(1)$，整条链一次线性扫完。

### 3.4 示例演算

![示例 2 的数字演算全流程](images/bw44_q3_walkthrough.svg)

以 `encoded = [6,5,4,6]`（$n=5$）为例：

| 步骤 | 计算 | 结果 |
|------|------|------|
| total | $1⊕2⊕3⊕4⊕5$ | $1$ |
| even | $encoded[0] ⊕ encoded[2] = 6 ⊕ 4$ | $2$ |
| perm[4] | $1 ⊕ 2$ | $3$ |
| perm[3] | $3 ⊕ 6$ | $5$ |
| perm[2] | $5 ⊕ 4$ | $1$ |
| perm[1] | $1 ⊕ 5$ | $4$ |
| perm[0] | $4 ⊕ 6$ | $2$ |

得到 `perm = [2,4,1,5,3]` ✓。

## 4. 算法细节

1. **total 的两种求法**：直接循环 $1..n$ 异或，$O(n)$，最直观；也可用异或前缀的 $O(1)$ 闭式（$n \bmod 4$ 的四值规律），但没必要。
2. **even 的下标边界**：`i` 取 $0, 2, \dots$ 且 `i + 1 < n`，即 `i ≤ n-3`——写循环时用 `i + 1 < n` 判断，避免 `encoded` 越界（`encoded` 只有 $n-1$ 个元素，最大下标 $n-2$ 是奇数下标，不参与）。
3. **回推方向**：必须**从右往左**（先有 $perm[n-1]$）；从左往右需要 $perm[0]$，而 $perm[0]$ 没有直接的求解式。
4. **异或满足交换结合律**，`total ⊕ even` 的顺序无关紧要。
5. **无需 long long**：$n < 10^5$，元素 $\le n$，异或结果也在 `int` 范围。

## 5. 正确性证明

**引理 1（异或消去）**：对任意 $a$，$a \oplus a = 0$ 且 $a \oplus 0 = a$；异或满足交换律与结合律。

**证明**：按位验证：同为 0、异为 1，$a \oplus a$ 逐位为 0；与 0 异或保持原值。∎

**引理 2（隔项覆盖）**：$n$ 为奇数时，$\bigoplus_{k=0}^{(n-3)/2} encoded[2k] = \bigoplus_{j=0}^{n-2} perm[j]$。

**证明**：$encoded[2k] = perm[2k] \oplus perm[2k+1]$，把这些式子全部异或起来，右边每个 $perm[j]$（$0 \le j \le n-2$）恰好出现一次（$n$ 奇 ⟹ $n-2$ 奇 ⟹ 配对 $(0,1), (2,3), \dots, (n-3, n-2)$ 完整无剩余）。∎

**定理（还原正确）**：`total ⊕ even` 等于 $perm[n-1]$；从它出发按 $perm[i] = perm[i+1] \oplus encoded[i]$ 回推得到的数组就是原排列。

**证明**：由题设 `total` $= \bigoplus_{j=0}^{n-1} perm[j]$（排列与 $1..n$ 逐元素对应）。于是

$$\text{total} \oplus \text{even} = \left(\bigoplus_{j=0}^{n-1} perm[j]\right) \oplus \left(\bigoplus_{j=0}^{n-2} perm[j]\right) = perm[n-1],$$

中间各项两两抵消（引理 1）。回推式由 $encoded[i] = perm[i] \oplus perm[i+1]$ 两边同异或 $perm[i+1]$ 即得。归纳可得每个 `perm[i]` 正确。唯一性由「给定 `perm[n-1]` 后回推是确定过程」保证。∎

## 6. 复杂度分析

- **时间**：$O(n)$——三段线性扫描（求 total、求 even、回推）。
- **空间**：$O(1)$ 额外（输出数组不计）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> decode(vector<int>& encoded) {
        int n = (int)encoded.size() + 1;        // n 为奇数
        int total = 0;                          // perm 全体异或 = 1..n 的异或
        for (int i = 1; i <= n; ++i) total ^= i;
        int even = 0;                           // 偶数下标异或 = perm[0..n-2] 的异或
        for (int i = 0; i + 1 < n; i += 2) even ^= encoded[i];
        vector<int> perm(n);
        perm[n - 1] = total ^ even;             // 差一个 perm[n-1]，异或即得
        for (int i = n - 2; i >= 0; --i)
            perm[i] = perm[i + 1] ^ encoded[i]; // 由相邻异或逐个回推
        return perm;
    }
};
```

### Python

```python
class Solution:
    def decode(self, encoded: list[int]) -> list[int]:
        n = len(encoded) + 1          # n 为奇数
        total = 0
        for i in range(1, n + 1):     # 1..n 的异或 = perm 全体的异或
            total ^= i
        even = 0                      # 偶数下标异或 = perm[0..n-2] 的异或
        for i in range(0, n - 1, 2):
            even ^= encoded[i]
        perm = [0] * n
        perm[-1] = total ^ even       # 二者只差 perm[n-1]
        for i in range(n - 2, -1, -1):
            perm[i] = perm[i + 1] ^ encoded[i]   # 相邻异或逐个回推
        return perm
```

> 💡 两份代码均通过官方示例（`[1,2,3]`、`[2,4,1,5,3]`），并在 3000 组随机奇数长度排列（含 $n = 99999$）上做「生成 → 加密 → 解码 → 比对」往返测试全部一致。

## 8. 边界情况与易错点

1. **even 的循环上界**：条件 `i + 1 < n` 等价于 `i <= n - 3`；若误写成 `i < n - 1`，由于步进 `i += 2`、且 $n$ 为奇数时 $n-2$ 是奇数，实际恰好读不到 `encoded[n-2]`——但边界条件应写严，避免改动步进时埋雷。
2. **回推必须从 $perm[n-1]$ 开始向左**；从 $perm[0]$ 开始没有已知初值。
3. **不要把 `total` 算成 `encoded` 全体的异或**——那是 $perm[0] \oplus perm[n-1]$（每项出现两次消掉中间），不是全体。
4. **`n` 为奇数是必要假设**：偶数时此法失效（见 3.2 的 ⚠️），题目恰好把它写进了约束。
5. **输出长度是 $n$**，别把 `encoded` 原地改写当成答案。
