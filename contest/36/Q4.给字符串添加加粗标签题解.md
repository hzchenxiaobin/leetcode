# LeetCode 给字符串添加加粗标签 题解

## 1. 题目概述

- **标题 / 题号**：给字符串添加加粗标签（#616，medium）
- **链接**：https://leetcode.cn/problems/add-bold-tag-in-string/
- **来源**：LeetCode 第 36 场周赛 Q4
- **难度**：中等
- **标签**：字典树，数组，哈希表，字符串，字符串匹配，AC 自动机

**题意**：给定字符串 $s$ 与词典 $words$（无重复单词）。凡是 $s$ 中**出现在** $words$ 里的子串，都要用一对 `<b>` … `</b>` 包起来。规则有两条：

1. 两个待加粗子串若**重叠**，只保留一对标签；
2. 两个待加粗子串若**首尾相接**（前一段右端点 $+1$ 等于后一段左端点），也只保留一对标签。

返回处理后的字符串。

**约束**：

- $1 \le \lvert s \rvert \le 1000$
- $0 \le \lvert words \rvert \le 100$
- $1 \le \lvert words[i] \rvert \le 1000$
- $s$ 与 $words[i]$ 只含英文字母，$words$ 内不含重复单词

> 💡 两条规则其实是同一句话：把「所有匹配区间」取并集后，每一块**极大连续覆盖段**套一对标签。相邻为什么能合并？因为两段之间没有任何未加粗的字符把它们隔开。

## 2. 示例

**示例 1**

```text
输入：s = "abcxyz123", words = ["abc","123"]
输出："<b>abc</b>xyz<b>123</b>"
解释：两段匹配 [0,2] 与 [6,8] 之间隔着 "xyz"，互不相邻，所以保留两对标签。
```

**示例 2**

```text
输入：s = "aaabbb", words = ["aa","b"]
输出："<b>aaabbb</b>"
解释："aa" 在下标 0、1 各出现一次（重叠），"b" 在 3、4、5；并集是连续的 [0,5]。
```

**示例 3**

```text
输入：s = "aaabbcc", words = ["aaa","aab","bc"]
输出："<b>aaabbc</b>c"
解释："aaa" 覆盖 [0,2]、"aab" 覆盖 [1,3]、"bc" 覆盖 [4,5]，并集 [0,5]；下标 6 的 'c' 未被覆盖。
```

## 3. 解题思路

### 3.1 暴力思路

最朴素的做法：枚举 $s$ 的每个起点 $i$，再枚举 `words` 里的每个词 $w$，逐字符比较（或对每个 $w$ 用一次 `find` 轮询全部出现），命中就把区间 $[i,\,i+\lvert w\rvert-1]$ 记成「已覆盖」，最后从左到右扫一遍、把连续覆盖段套上标签。代价 $O(\lvert s\rvert \cdot \sum\lvert w\rvert)$，代进去约 $10^8$：C++ 勉强能过、Python 会超时。

更麻烦的是**不能边匹配边拼字符串**。按「命中一次套一对标签」的直觉写，示例 2 会输出 `<b>aaa</b><b>b</b><b>b</b><b>b</b>` 这样的碎片，重叠与相邻两种情况都没处理。所以要先想清楚的不是「怎么找匹配」，而是「匹配结果怎么合并」：前者用字典树压到 $O(\lvert s\rvert \cdot L_{\max})$，后者需要一条正确的判据。

### 3.2 核心观察：加粗 = 匹配区间的并集

![匹配区间求并集](images/wc36_q4_interval_union.svg)

每个匹配都贡献一个下标区间 $[i,\, i+\lvert w\rvert - 1]$，位置 $p$ 最终是否加粗，只取决于**是否存在某个匹配区间包含 $p$**，与是哪个词、匹配了几次完全无关。因此：

- 覆盖状态是一个**布尔集合**，与 `words` 的枚举顺序无关；同一个词的不同出现之间也可以重叠（`"aaa"` 里 `"aa"` 就出现两次）；
- 输出时只需要求覆盖集合的**极大连续段**，每段一对标签，段与段之间的空隙原样输出。

于是整个问题被拆成两步：**求覆盖集合** + **求极大连续段**。第二步不需要布尔数组，只用一个「每个起点的最远右端点」数组即可。

### 3.3 算法流程：字典树扫描 + 贪心合并

![字典树扫描与贪心合并](images/wc36_q4_trie_scan.svg)

第一步，把所有 `words` 插进一棵字典树，词尾节点打上 `terminal` 标记。第二步，对每个起点 $i$ 沿树向后走，把「能匹配到的最远右端点」记下来：

$$\text{endAt}[i] = \max\{\, j \mid \exists w \in words,\ s[i\,..\,j] = w \,\}$$

若从 $i$ 出发没有任何匹配，则 $\text{endAt}[i] = -1$。因为扫描时 $j$ 单调递增，**遇到 `terminal` 就覆盖赋值**，最后一次赋值自然就是最大值，不需要额外的 $\max$。

第三步贪心合并。设当前段起点为 $i$、右端点初值 $end = \text{endAt}[i]$，令 $j$ 从 $i+1$ 开始逐个右移：

只要 $j \le end + 1$ 且 $\text{endAt}[j] > end$，就说明从 $j$ 开始的匹配与当前段**相接或重叠**，把 $end$ 扩到 $\text{endAt}[j]$；否则 $j$ 继续右移。

这里的 $end+1$ 是本题的题眼：写 $j \le end$ 只能吃到重叠，示例 2 的 `[0,2]` 与 `[3,5]` 会被拆成两段，输出错误。第四步，把 $[i, end]$ 整段包进 `<b>` … `</b>`，然后令 $i \leftarrow end + 1$ 继续。

### 3.4 示例演算

![示例 2 演算表](images/wc36_q4_walkthrough.svg)

以 `s = "aaabbb"`、`words = ["aa","b"]` 为例，字典树只有 `root→a→a`（词尾）和 `root→b`（词尾）两条链：

| $i$ | $s[i]$ | 从 $i$ 出发命中的词 | $\text{endAt}[i]$ |
|-----|--------|--------------------|-------------------|
| 0 | a | `"aa"`（覆盖 0..1） | 1 |
| 1 | a | `"aa"`（覆盖 1..2） | 2 |
| 2 | a | —（`"ab"` 不在树里，中断） | $-1$ |
| 3 | b | `"b"`（覆盖 3..3） | 3 |
| 4 | b | `"b"`（覆盖 4..4） | 4 |
| 5 | b | `"b"`（覆盖 5..5） | 5 |

合并过程：$i = 0$，$end = 1$；$j=1 \le end+1$ 且 $\text{endAt}[1] = 2 > 1$，扩到 $end = 2$；$j=3 \le 3$ 且 $\text{endAt}[3] = 3 > 2$，扩到 $3$；$j=4$、$5$ 一路扩到 $end = 5$；$j=6$ 越界，段落定格在 $[0,5]$，输出 `<b>aaabbb</b>`。

对照示例 1：$\text{endAt} = [2,-1,-1,-1,-1,6,-1,-1,-1]$，第一段 $[0,2]$ 扫到 $j=3$ 时 $\text{endAt}[3] = -1$，扩展停止；第二段从 $i = 3$ 起跳过三个空格到达 $i = 6$，得到 $[6,8]$，于是输出 `<b>abc</b>xyz<b>123</b>`。

## 4. 算法细节

1. **为什么存「最远右端点」而不是布尔覆盖**：布尔数组标记时，一个长度为 $L$ 的匹配要写 $L$ 次，最坏 $O(\lvert s\rvert^2)$；而 $\text{endAt}$ 每个起点只存一个整数，扫描时 $O(1)$ 更新，合并时也只需比较端点。两者刻画的是同一个覆盖集合，但后者更省。
2. **字典树的表示**：C++ 用 `vector<array<int,26>>`，节点上限是 $\sum\lvert w\rvert + 1 \le 10^5$，每个节点 104 字节、总计约 10 MB，可以接受；Python 用「每个节点一个 `dict`」，只存实际出现的孩子，内存更省。
3. **扫描上界**：从 $i$ 出发最多走 $\min(\lvert s\rvert - i,\ L_{\max})$ 步；若某个词比 $s$ 还长，扫描会在越界前自然中断，不需要特判。
4. **命中 `terminal` 后必须继续走，相邻判据必须是 $j \le end+1$**：前者防止 `"aa"` 与 `"aaa"` 同时在词典里时 $\text{endAt}$ 偏小；后者对应题面第二句「首尾相接的也要合并」，写成 $j \le end$ 就是本场最容易 WA 的点。
5. **拼接方式**：C++ 用 `res +=` 并 `reserve(n + 16)`；Python 用列表 `append` 收集片段再 `"".join()`，避免字符串 `+=` 退化为 $O(n^2)$。走完一段要用 `i = end + 1` 推进，而不是 `i = j`——$j$ 已被推到 $end+2$ 附近，用它推进会漏字符。
6. **匹配总数的量级**：$\text{endAt}$ 把「所有匹配」压成「每个起点一个值」，最坏只需 $O(\lvert s\rvert)$ 个整数，比显式收集全部区间更稳（同一位置可被多个词重复命中，区间数最坏 $O(\lvert s\rvert \cdot \lvert words\rvert)$）。

## 5. 正确性证明

**引理 1（$\text{endAt}$ 精确）**：对任意起点 $i$，$\text{endAt}[i]$ 恰为所有满足 $s[i\,..\,j] \in words$ 的 $j$ 的最大值；若不存在这样的 $j$，则 $\text{endAt}[i] = -1$。

**证明**：沿树行走 $j = i, i+1, \dots$，若处理到 $j$ 后仍停留在某个节点 $\text{cur}$，则该节点正是串 $s[i\,..\,j]$ 对应的节点，且 $s[i\,..\,j]$ 是某个词的前缀；反之若某步取不到孩子则 $s[i\,..\,j]$ 不是任何词的前缀，其后缀更长也都不可能是词，`break` 不会漏解。因此 $\text{cur}$ 上有 `terminal` 标记当且仅当 $s[i\,..\,j] \in words$。赋值按 $j$ 递增发生且每次覆盖写，故最终保留的是最大 $j$。∎

**引理 2（段内全被覆盖）**：设算法在起点 $i$ 处围绕 $[i, end]$ 输出了一段，则该段内每个位置都被某个匹配区间覆盖。

**证明**：初始 $[i, \text{endAt}[i]]$ 被以 $i$ 为起点的匹配覆盖，由引理 1 成立。归纳地设 $[i, end]$ 已被覆盖，若某次扩展把 $end$ 提到 $\text{endAt}[j]$（$j \le end+1$），则 $[j, \text{endAt}[j]]$ 被覆盖；又 $j \le end + 1$ 说明这两段在位置上相接或重叠，其并仍是一个连续区间 $[i, \text{endAt}[j]]$，结论保持。∎

**引理 3（段落极大）**：算法输出的每一段 $[l, r]$ 都极大，即 $r+1$ 一定未被覆盖（或 $r = \lvert s\rvert - 1$）。

**证明**：反设 $r < \lvert s\rvert - 1$ 且位置 $r+1$ 被某个匹配覆盖。该匹配的起点 $i'$ 必满足 $i' \le r+1$，否则它覆盖不到 $r+1$；而合并循环终止时已检查过所有 $j \le r+1$，故 $\text{endAt}[i'] \le r$，与「覆盖 $r+1$」矛盾。所以 $r+1$ 未被覆盖，段落不能继续向右延伸。∎

**定理**：算法输出与题意要求的结果一致。

**证明**：记覆盖集合 $C = \{p \mid \exists \text{匹配区间包含 } p\}$。题面两条规则等价于「$C$ 的每个极大连续段套一对标签，其余字符原样输出」。引理 2 与引理 3 说明算法每段恰是 $C$ 的一个极大连续段，且不同段落互不相接（否则会被合并），因此区间划分与题面要求一一对应；段外字符自 $i$ 开始逐个原样输出且都不在 $C$ 中（否则该位置会被某段吸收），故输出字符串唯一确定，与标准答案相同。∎

## 6. 复杂度分析

- **时间**：建树 $O(\sum\lvert w\rvert)$；扫描阶段共 $\lvert s\rvert$ 个起点，每个起点最多走 $L_{\max}$ 步，$O(\lvert s\rvert \cdot L_{\max})$；合并与拼接各扫一遍 $O(\lvert s\rvert)$。总计 $O(\sum\lvert w\rvert + \lvert s\rvert \cdot L_{\max})$，在给定范围下不超过约 $10^6$ 次操作。
- **空间**：字典树节点数不超过 $\sum\lvert w\rvert + 1$，$O(\sum\lvert w\rvert)$；$\text{endAt}$ 数组与输出缓冲 $O(\lvert s\rvert)$。合计 $O(\sum\lvert w\rvert + \lvert s\rvert)$。

## 7. 参考代码

### C++

```cpp
#include <string>
#include <vector>
#include <array>
using namespace std;

class Solution {
public:
    string addBoldTag(string s, vector<string>& words) {
        int n = s.size();
        vector<array<int, 26>> nxt(1);
        nxt[0].fill(-1);
        vector<char> terminal(1, 0);
        for (const string& w : words) {          // ① 建字典树
            int cur = 0;
            for (char c : w) {
                int k = c - 'a';
                if (nxt[cur][k] == -1) {
                    nxt[cur][k] = (int)nxt.size(); nxt.emplace_back();
                    nxt.back().fill(-1); terminal.push_back(0);
                }
                cur = nxt[cur][k];
            }
            terminal[cur] = 1;
        }
        vector<int> endAt(n, -1);                // ② 每个起点的最远右端点
        for (int i = 0; i < n; i++) {
            int cur = 0;
            for (int j = i; j < n; j++) {
                cur = nxt[cur][s[j] - 'a'];
                if (cur == -1) break;            // 不是任何词的前缀，后面更不可能
                if (terminal[cur]) endAt[i] = j; // j 递增，最后一次即最远
            }
        }
        string res;
        res.reserve(n + 16);
        int i = 0;
        while (i < n) {
            if (endAt[i] == -1) { res += s[i]; i++; continue; }   // 未覆盖，原样输出
            int end = endAt[i], j = i + 1;
            while (j <= end + 1 && j < n) {      // ③ end+1：相邻区间也要并进来
                if (endAt[j] > end) end = endAt[j];
                j++;
            }
            res += "<b>";
            res += s.substr(i, end - i + 1);
            res += "</b>";
            i = end + 1;                         // ④ 从段尾之后继续
        }
        return res;
    }
};
```

### Python

```python
class Solution:
    def addBoldTag(self, s: str, words: list[str]) -> str:
        n = len(s)
        trie = [dict()]          # ① 建字典树：节点 0 是根
        terminal = [False]
        for w in words:
            cur = 0
            for ch in w:
                nxt = trie[cur].get(ch)
                if nxt is None:
                    trie.append(dict())
                    terminal.append(False)
                    nxt = len(trie) - 1
                    trie[cur][ch] = nxt
                cur = nxt
            terminal[cur] = True
        end_at = [-1] * n        # ② end_at[i] = 从 i 出发能覆盖到的最远下标
        for i in range(n):
            cur = 0
            for j in range(i, n):
                cur = trie[cur].get(s[j], -1)
                if cur == -1:
                    break
                if terminal[cur]:
                    end_at[i] = j        # j 递增，最后一次赋值即最远
        res = []
        i = 0
        while i < n:
            if end_at[i] == -1:          # 未覆盖，原样输出
                res.append(s[i])
                i += 1
                continue
            end = end_at[i]
            j = i + 1
            while j <= end + 1 and j < n:   # ③ end+1：相邻区间也要并进来
                if end_at[j] > end: end = end_at[j]
                j += 1
            res.append("<b>" + s[i:end + 1] + "</b>")
            i = end + 1                      # ④ 从段尾之后继续
        return "".join(res)
```

## 8. 边界情况与易错点

1. **相邻必须合并**：`s = "aaabbb"`、`words = ["aa","b"]` 的答案是一对标签。判据写成 $j \le end$ 会把 `[0,2]` 与 `[3,5]` 拆成两段，这是本题最典型的 WA。
2. **`words` 为空、全不匹配、或单词比 `s` 还长**：返回原串。`endAt` 全为 $-1$ 时逐字符输出，不会产生空的 `<b></b>`；`s = "abc"`、`words = ["abcd"]` 这类扫描第一步就中断，无需提前过滤。
3. **重叠出现不能被去重**：`s = "aaaa"`、`words = ["aa"]` 中 `"aa"` 在下标 0、1、2 各出现一次，覆盖并集为 $[0,3]$，答案是整串加粗而不是只加粗前两个字符。
4. **`terminal` 后继续走**：同时有 `"aa"` 与 `"aaa"` 时，不能在短词的 `terminal` 处停下，否则 $\text{endAt}$ 偏小，长词覆盖的尾部会被漏掉。
5. **段落跳转用 `end + 1`**：内层 `j` 在扩展过程中可能已经跑到 `end + 2`，用它作为新的 $i$ 会漏字符。
6. **输出内容本身包含尖括号**：结果里的 `<b>` / `</b>` 是答案的一部分，不要当成 HTML 做转义或清洗；Python 端则用列表 `append` + `"".join()` 拼接。
