# LeetCode 统计下标的相反奇偶性得分 题解

## 1. 题目概述

- **标题 / 题号**：统计下标的相反奇偶性得分（#3917，easy）
- **链接**：https://leetcode.cn/problems/count-indices-with-opposite-parity/
- **来源**：LeetCode 第 500 场周赛 Q1
- **难度**：简单
- **标签**：数组

**题意**：
给定长度为 $n$ 的整数数组 $nums$。下标 $i$ 的**分数**定义为满足以下条件的下标 $j$ 的数量：$i < j < n$（$j$ 位于 $i$ 严格右侧），且 $nums[i]$ 与 $nums[j]$ **奇偶性不同**（一奇一偶）。返回长度为 $n$ 的数组 $answer$，其中 $answer[i]$ 为下标 $i$ 的分数。

**约束**：

- $1 \le n \le 100$
- $1 \le nums[i] \le 100$

> 💡 **审题关键**：只问"右侧有多少个奇偶相反的"，**完全不关心** $nums[j]$ 与 $nums[i]$ 的大小关系。$n \le 100$ 暴力双循环稳过；但这题真正的教学点是：**去掉值域约束后连树状数组都不需要，两个计数器倒序一趟就是理论最优**。

## 2. 示例

**示例 1**

```text
输入：nums = [1,2,3,4]
输出：[2,1,1,0]
解释：i=0（1 奇）：右侧偶数有 2、4 → 2；
     i=1（2 偶）：右侧奇数有 3 → 1；
     i=2（3 奇）：右侧偶数有 4 → 1；
     i=3：右侧无元素 → 0。
```

**示例 2**

```text
输入：nums = [1]
输出：[0]
解释：只有一个元素，任何下标的右侧都为空，分数为 0。
```

**示例 3**（覆盖"右侧同奇偶不计数"）

```text
输入：nums = [2,4,5,7]
输出：[2,2,0,0]
解释：i=0（2 偶）：右侧奇数有 5、7 → 2；
     i=1（4 偶）：右侧奇数有 5、7 → 2；
     i=2（5 奇）：右侧只有 7（奇），奇偶相同不计 → 0；
     i=3：无右侧 → 0。
```

## 3. 解题思路

### 3.1 暴力思路

对每个 $i$ 枚举所有 $j > i$，逐一判定 $nums[i] \bmod 2 \ne nums[j] \bmod 2$，累计即为 $answer[i]$。总复杂度 $O(n^2)$，$n = 100$ 时至多约 $5 \times 10^3$ 次判定，**比赛时作为签到题直接写完全没问题**。

但换个角度看：指针从 $i+1$ 移到 $i$ 时，"右侧元素的奇偶分布"只变化一个元素（右侧集合恰好新增 $nums[i+1]$）。暴力却为每个 $i$ 把整个右侧从头重扫一遍——**同一份奇偶分布被重复统计了 $n$ 遍**。信息几乎不变，就该**增量维护**，而不是反复全量计算。

### 3.2 核心观察：后缀奇偶双计数器（倒序一趟 O(n)）

![核心观察：右侧奇偶分布压缩为两个计数器](images/opposite_parity_concept.svg)

**观察一（奇偶二分 ⇒ 两个标量足够）**：$answer[i]$ 的取值只依赖右侧奇数个数 $\text{cntOdd}$ 与右侧偶数个数 $\text{cntEven}$ 两个数：

$$answer[i] = \begin{cases} \text{cntOdd}, & nums[i] \text{ 为偶数} \\[2pt] \text{cntEven}, & nums[i] \text{ 为奇数} \end{cases}$$

"奇偶相反"就此坍缩成一次 **O(1) 选对面计数器**的动作：偶数问奇、奇数问偶。约束越少，结构越轻——没有值域约束，就不需要任何值域数据结构。

**观察二（「右侧」⇒ 倒序增量维护）**：从 $n-1$ 向左扫。处理 $i$ 时，两个计数器装的恰好是**下标 $> i$ 的全体**——这就是不变式。作答后把 $nums[i]$ 计入**本方**计数器，指针左移；此时右侧集合恰好新增一个元素，计数器只做一次 $+1$。

**先查后插**：查询打**对面**计数器、插入打**本方**计数器，两条腿互不相交。

> 💡 **一句话**：右侧信息 = 两个标量；奇偶相反 = 选对面计数器；倒序一趟先查后插，$O(n)$ 收工。

### 3.3 算法流程

![算法流程：倒序一趟，先查后插](images/opposite_parity_flow.svg)

| 步骤 | 操作 | 说明 |
|------|------|------|
| ① 初始化 | $\text{cntOdd} = \text{cntEven} = 0$，$i = n-1$ | 初始右侧为空，计数器为 0 |
| ② 先查 | $nums[i]$ 偶 → $ans[i] = \text{cntOdd}$；奇 → $ans[i] = \text{cntEven}$ | 选**对面**计数器，O(1) |
| ③ 后插 | $nums[i]$ 偶 → $\text{cntEven}{+}{+}$；奇 → $\text{cntOdd}{+}{+}$ | 把自己计入**本方** |
| ④ 左移 | $i \leftarrow i - 1$ | 右侧集合恰好多一个元素 |
| ⑤ 终止 | $i < 0$ 时返回 $ans$ | $n$ 个位置全部作答 |

### 3.4 示例演算

![示例演算：倒序四步，先查后插](images/opposite_parity_walkthrough.svg)

以**示例 1**（$nums = [1,2,3,4]$）倒序演算，$(\text{奇}, \text{偶})$ 表示两计数器状态：

| $i$ | $nums[i]$ | 奇偶 | 查前 (奇, 偶) | 查对面计数器 | $ans[i]$ | 插后 (奇, 偶) |
|-----|-----------|------|---------------|--------------|----------|---------------|
| 3 | 4 | 偶 | $(0, 0)$ | $\text{cntOdd} = 0$ | 0 | $(0, 1)$ |
| 2 | 3 | 奇 | $(0, 1)$ | $\text{cntEven} = 1$ | 1 | $(1, 1)$ |
| 1 | 2 | 偶 | $(1, 1)$ | $\text{cntOdd} = 1$ | 1 | $(1, 2)$ |
| 0 | 1 | 奇 | $(1, 2)$ | $\text{cntEven} = 2$ | 2 | $(2, 2)$ |

得 $ans = [2,1,1,0]$ ✓。**示例 2** 单元素：$i=0$ 时两计数器均为 0 → $[0]$ ✓。

## 4. 算法细节

1. **计数器语义（不变式）**：处理 $i$ 之前，$\text{cntOdd} / \text{cntEven}$ 恰等于下标 $> i$ 的元素中奇 / 偶的个数——这是正确性的锚点，写代码时心里要默念这条口径。
2. **先查后插**：作答必须发生在把 $nums[i]$ 计入计数器**之前**，保证计数器口径是"严格右侧"、不含自己。
3. **奇偶判定**：本题值域 $1 \le nums[i] \le 100$ 全为正，`nums[i] % 2` 与 `nums[i] & 1` 等价；若值域含负数，C++ 的 `%` 可能返回负值，应改用 `& 1`。
4. **遍历方向**：倒序 `for (int i = n - 1; i >= 0; --i)`；不习惯倒序可写正序"先扣后查"等价版（见延伸思考），同为 $O(n)/O(1)$。

## 5. 正确性证明

**引理 1（计数器不变式）**：在第 ② 步作答时刻，$\text{cntOdd}$ 与 $\text{cntEven}$ 分别等于 $\{\, j : i < j < n \,\}$ 中奇数与偶数的个数。

**证明**：对 $i$ 从 $n-1$ 到 $0$ 归纳。
- **基例**：$i = n-1$ 时右侧集合为空，两计数器初始化为 $0$，命题成立。
- **归纳步**：设处理 $i+1$ 时命题成立。处理完 $i+1$（作答后执行一次本方计数器 $+1$），指针移到 $i$，此时右侧集合为 $\{\, j : j > i \,\} = \{\, j : j > i+1 \,\} \cup \{ i+1 \}$，相对上一状态恰好新增元素 $nums[i+1]$，而它恰被计入本方计数器一次，故命题对 $i$ 成立。∎

**定理**：算法对每个 $i$ 输出 $ans[i] = \#\{\, j > i : nums[j] \not\equiv nums[i] \pmod 2 \,\}$。

**证明**：由引理 1，作答时刻计数器恰为严格右侧全体。若 $nums[i]$ 为偶数，则右侧与之奇偶相反的 $j$ 恰为右侧全体奇数，个数为 $\text{cntOdd}$；若为奇数，则恰为右侧全体偶数，个数为 $\text{cntEven}$。先查后插保证作答先于 $nums[i]$ 入计数器，自身不会被误数。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。倒序一趟，每步 1 次查询 + 1 次插入，均为 $O(1)$。$n \le 100$ 时暴力 $O(n^2) = 10^4$ 同样通过；本解对 $n = 10^6$ 甚至更大依然线性，而读入本身是 $\Omega(n)$，**已触及下界**。
- **空间复杂度**：$O(1)$。仅两个整型计数器（输出数组不计入）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> countOppositeParity(vector<int>& nums) {
        int n = nums.size();
        vector<int> ans(n);
        int cntOdd = 0, cntEven = 0;          // 不变式：恰为下标 > i 的奇/偶个数
        for (int i = n - 1; i >= 0; --i) {
            if (nums[i] % 2 == 0) {
                ans[i] = cntOdd;              // 先查：偶数问奇数个数
                ++cntEven;                    // 后插：计入本方
            } else {
                ans[i] = cntEven;
                ++cntOdd;
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def countOppositeParity(self, nums: list[int]) -> list[int]:
        cnt_odd = cnt_even = 0                # 不变式：恰为下标 > i 的奇/偶个数
        ans = [0] * len(nums)
        for i in range(len(nums) - 1, -1, -1):
            if nums[i] % 2 == 0:
                ans[i] = cnt_odd              # 先查：偶数问奇数个数
                cnt_even += 1                 # 后插：计入本方
            else:
                ans[i] = cnt_even
                cnt_odd += 1
        return ans
```

## 8. 边界情况与易错点

1. **单元素**（$n = 1$）：右侧为空，两计数器均为 0，输出 `[0]`（示例 2）。
2. **全同奇偶**：如 `[2,4,6]`，任何 $i$ 查到的对面计数器恒为 0，输出全 0。
3. **先查后插次序**：本题查询打对面、插入打本方，两腿不相交，即使先插后查结果也对；但一旦口径改成"同奇偶计数"（如 1512 正序版），先插就会把自己数进去。**默认先查后插最稳**。
4. **负数奇偶判定**：本题值域为正无影响；推广到含负数时 C++ 的 `-3 % 2 == -1`（非 0 即真但符号为负），应改用 `& 1` 判定。
5. **"严格右侧"口径**：$j$ 的范围是 $i < j < n$，不含 $i$ 自身；写正序版时最容易把"先扣后查"写成"先查后扣"，导致把自己数进去。
