# LeetCode 相邻字符不同的最长路径 题解

## 1. 题目概述

- **标题 / 题号**：相邻字符不同的最长路径（#2246，hard）
- **链接**：https://leetcode.cn/problems/longest-path-with-different-adjacent-characters/
- **来源**：LeetCode 第 289 场周赛 Q4
- **难度**：困难
- **标签**：树、深度优先搜索、树形动态规划、拓扑排序

**题意**：给定一棵以节点 $0$ 为根的 $n$ 节点树，用 `parent` 数组描述：`parent[i]` 是节点 $i$ 的父节点（`parent[0] == -1`）。每个节点 $i$ 上有一个字符 $s[i]$。求一条**最长路径**，使路径上**任意一对相邻节点的字符不同**，返回路径长度（路径上的**节点数**）。

**约束**：

- $n = \text{parent.length} = \text{s.length}$
- $1 \le n \le 10^5$
- 对所有 $i \ge 1$：$0 \le \text{parent}[i] \le n - 1$；`parent[0] == -1`
- `parent` 表示一棵有效的树
- $s$ 仅由小写英文字母组成

> 💡 三个赛场信号：① 「相邻节点字符不同」是**边的局部约束**——一条边合法当且仅当两端字符相异，这预示子树信息可以自底向上拼合（对比「路径上字符互不相同」的全局约束，难度立刻上一档）；② $n \le 10^5$ 锁定 $O(n)$ 或 $O(n \log n)$；③ 树上「最长路径」= **直径类问题**，套路是后序 DFS 传递「以我为端点向下延伸的单边最优」，在节点处拼「拐弯路径」打擂台——与 543 / 124 / 687 / 1522 同一副骨架，本题是 **N 叉 + 异字延伸** 版。

> 💡 本题在本仓库另有[每日题解 2246](../../solution/2201-2300/2246_相邻字符不同的最长路径.md)：主线同为「后序 + top-2 拼路径」，附面试问答与迭代后序的对照展开。本篇按**周赛复盘视角**展开，补齐引理-定理化的正确性证明（最高点分解定理）、$n = 10^5$ 下 Python 递归爆栈的两种工程解法（含官方拓扑排序标签的由来）与赛场易错清单，两篇互为印证。

## 3. 解题思路

### 3.1 暴力思路

枚举所有点对 $(u, v)$：树上两点间路径唯一，逐边检查相邻字符是否相异，取合法路径长度的最大值。点对共 $O(n^2)$ 个，每条路径验证 $O(n)$，总计 $O(n^3)$；即使从每个点出发各做一次 $O(n)$ 的 DFS（只沿「下一节点字符不同」的边走），也是 $O(n^2)$。$n = 10^5$ 时约 $10^{10}$ 次操作，不可行。

> ⚠️ 暴力的浪费在于**子树信息没有复用**：以节点 $u$ 为端点向下的最长合法链一旦算出，$u$ 的父节点直接拿来用即可，无需重复扫描整棵子树。

### 3.2 核心观察：按「最高点」分类路径 + 后序传递最长异字链

![示例 1 的树：同字边被阻断，最长路径 3→1→0](images/wc289_q4_block_edges.svg)

**观察一（约束的局部性）**：合法路径的判定只逐边进行——边 $(u,v)$ 可用当且仅当 $s[u] \ne s[v]$。因此「一条从上到下的链合法」等价于「链上每条边两端字符相异」，链可以**从叶子开始逐边向上拼合**，这是树形 DP 可行性的根源。

**观察二（路径的最高点分解）**：树中任何简单路径 $P$ 都有一个**最高点** $u$（$P$ 上离根最近的节点，即 $P$ 中所有点的最近公共祖先）。$P$ 去掉 $u$ 后至多剩下两段，分别落在 $u$ 的**两棵不同子树**里（或只剩一段 / 为空）。于是：

$$\text{全树最长合法路径} = \max_{u}\ \big(\text{以 } u \text{ 为最高点的最长合法路径}\big)$$

问题从「枚举路径」转为「对每个节点 $u$，求两条从 $u$ 向下、首边异字的最长链，拼成穿过 $u$ 的路径」。

**定义**：

$$\text{chain}(u) = \text{以 } u \text{ 为端点、向下伸入 } u \text{ 子树的最长合法链的节点数（含 } u \text{ 自身）}$$

**最优子结构**（孩子链只在异字边下可用）：

$$\text{chain}(u) = 1 + \max_{\substack{c \in \text{children}(u) \\ s[c] \ne s[u]}} \text{chain}(c) \quad (\text{无可用孩子时 } \text{chain}(u) = 1)$$

**路径聚合**：设 $u$ 的可用孩子链（$s[c] \ne s[u]$）中最长与次长分别为 $\text{max1}, \text{max2}$（不足两条则取 $0$，$0$ 表示空链），则

$$\text{path}(u) = 1 + \text{max1} + \text{max2}$$

> ⚠️ **为什么只取 top-2？** 一条简单路径在最高点处至多分两叉（一左一右），第三条子链必然与某一条共享节点，无法构成简单路径。这与 124（top-2 贡献和）、543（top-2 深度）、1522（N 叉直径）完全同理。
>
> ⚠️ **同字孩子仍需递归**：$s[c] = s[u]$ 只说明边 $(u,c)$ 断了、链不能穿过 $u$ 向上延伸，但 $c$ 的子树**内部**仍可能藏着更长的合法路径（如 $c$ 的其他孩子方向的长链），递归不能省，只是**不使用其返回值**更新 top-2。

### 3.3 算法流程：后序 DFS + O(1) 维护 top-2

![节点 u 处的 top-2 拼接：同字孩子断链，异字孩子链参与拼接](images/wc289_q4_top2_merge.svg)

**`dfs(u)` 的完整步骤**：

1. 初始化 `max1 = max2 = 0`（top-2 可用子链长，`0` 表示无可用子链）；
2. 遍历每个孩子 $c$：
   - 递归 `chain = dfs(c)`（**无条件**，子树内部的答案在此过程中更新）；
   - 若 $s[c] \ne s[u]$：用 `chain` 更新 top-2——`chain > max1` 则 `max2=max1, max1=chain`，否则 `chain > max2` 则 `max2=chain`；
   - 若 $s[c] = s[u]$：丢弃返回值（链被边 $(u,c)$ 阻断）；
3. 聚合：`ans = max(ans, 1 + max1 + max2)`（穿过 $u$ 的最优路径候选）；
4. 返回 `1 + max1`（$u$ 向下的最长链，供父节点拼路径）。

`ans` 初始化为 $1$（单节点路径），主调用 `dfs(0)`，返回 `ans`。

### 3.4 示例演算

以示例 1 `parent = [-1,0,0,1,1,2], s = "abacbe"` 为例，后序遍历顺序为 $3 \to 4 \to 1 \to 5 \to 2 \to 0$：

![示例 1 的逐步后序演算：链长、top-2 与穿过路径](images/wc289_q4_walkthrough.svg)

| 步 | 节点(字符) | 可用子链 | max1 | max2 | 穿过路径 | 返回 chain |
|----|-----------|---------|------|------|---------|-----------|
| ① | 3 (c) | 叶子 | 0 | 0 | 1 | 1 |
| ② | 4 (b) | 叶子 | 0 | 0 | 1 | 1 |
| ③ | 1 (b) | 3(c≠b)→1；4(b=b)✗ | 1 | 0 | 2 | 2 |
| ④ | 5 (e) | 叶子 | 0 | 0 | 1 | 1 |
| ⑤ | 2 (a) | 5(e≠a)→1 | 1 | 0 | 2 | 2 |
| ⑥ | 0 (a) | 1(b≠a)→2；2(a=a)✗ | 2 | 0 | **3** ★ | 3 |

**关键一步**：节点 $0(a)$ 的孩子 $2(a)$ 返回链长 $2$（路径 $5 \to 2$），但 $s[2] = s[0] = \text{a}$，这条链**不能**经过边 $(0,2)$ 延伸——若忽略字符检查直接拼路径，会错误地算出 $1 + 2 + 2 = 5$。阻断检查是本题与裸直径题的唯一区别所在。

最终 `ans = 3` ✓

## 4. 算法细节

1. **建图**：由 `parent` 数组建孩子邻接表 `children`。注意**从 $i = 1$ 开始**（`parent[0] == -1` 不是合法下标，见 §8 易错点 5）。

2. **返回值与副作用分工**：`dfs` 一肩挑两职——**返回值** `1 + max1` 驱动父节点的 top-2 更新，**副作用** `ans = max(ans, 1 + max1 + max2)` 记录全局最优。这是树形路径最值题的通用模板。

3. **top-2 的 O(1) 维护**：不打擂台排序。某节点哪怕有 $O(n)$ 个孩子（星形树），总更新次数也是 $O(n)$；若对每个节点的孩子链排序，总时间退化为 $O(n \log n)$，虽能过但无必要。

4. **筛选在收集之前**：top-2 只收**异字孩子**的链。若先收集全部孩子链再排序取前二，同字孩子的链会混入——必须先判 $s[c] \ne s[u]$ 再进 top-2。

5. **深度问题的两种工程解法**：$n = 10^5$ 且树可退化为**深度 $10^5$ 的链**：
   - **C++**：递归版在 LeetCode 上可通过（评测栈较大）；本地小栈环境需留意。
   - **Python**：默认递归上限约 $1000$，链状树必然 `RecursionError`；`sys.setrecursionlimit` 只是解除计数限制，CPython 深递归仍有 C 栈溢出风险。**推荐改写为迭代**。本题官方标签里的「拓扑排序」正是迭代解法的由来：把 `parent` 视作 $i \to \text{parent}[i]$ 的有向边，每个节点统计**未处理孩子数** `deg`，`deg == 0` 的叶子先行入队；节点出队时它的所有孩子必已处理完毕（等价于后序），做 top-2 聚合、算出 `chain[u]`，再令 `deg[parent] -= 1`，归零则父节点入队。队列跑空即全程结束，天然无爆栈。

## 5. 正确性证明

**引理 1（路径的最高点分解）**：树 $T$ 中任何简单路径 $P$ 存在唯一节点 $u$（$P$ 中深度最小者，即 $P$ 中全部节点的最近公共祖先），使得 $P \setminus \{u\}$ 的每个连通分量都完全落在 $u$ 的某个孩子的子树内，且分量个数至多为 $2$。

**证明**：取 $u$ 为 $P$ 中深度最小的节点。$P$ 是简单路径，$P \setminus \{u\}$ 至多分成两段（路径去掉一点至多裂为两段）。每段中与 $u$ 相邻的点 $w$ 满足 $\text{dep}(w) = \text{dep}(u) + 1$，且由深度最小性，段中其余点深度 $\ge \text{dep}(u)$。设该段从 $u$ 的孩子 $c$ 出发：若段中存在离开 $c$ 子树的点 $x$，则 $x$ 到 $u$ 的树路径必经过 $c$ 到 $u$ 的父亲方向，即与 $P$ 中 $u$ 到该段的初始边形成环路或迫使 $P$ 重复经过某点，与 $P$ 是简单路径矛盾。故每段整体落在某个孩子子树内，且两段（若都存在）落在不同孩子子树（同一子树内两点间的树路径不经过 $u$，与两段均邻接 $u$ 矛盾）。唯一性：若 $P$ 中有两个深度最小的节点 $u_1 \ne u_2$，则 $P$ 上 $u_1$ 与 $u_2$ 之间的部分加上树中 $u_1 \to u_2$ 的路径构成两条不同的 $u_1$-$u_2$ 路径，成环，与树无环矛盾。∎

**引理 2（链的递推正确性）**：$\text{chain}(u) = 1 + \max_{c:\, s[c] \ne s[u]} \text{chain}(c)$（最大值不存在时取 $1$）恰为以 $u$ 为端点向下伸入子树的最长合法链长。

**证明**：对子树大小归纳。叶子处链只能取 $\{u\}$，长为 $1$，成立。设 $u$ 非叶，其向下链要么只含 $u$（长 $1$），要么下一节点是某个孩子 $c$ 且经过边 $(u,c)$，后者合法当且仅当 $s[c] \ne s[u]$；链的剩余部分恰是 $c$ 向下的合法链，由归纳假设其最长为 $\text{chain}(c)$。因此

$$\text{chain}(u) = \max\Big(1,\ 1 + \max_{c:\, s[c] \ne s[u]} \text{chain}(c)\Big)$$

而最大值不存在时右边即 $1$，与递推式一致。∎

**引理 3（穿过 $u$ 的最优路径）**：以 $u$ 为最高点的合法路径的最长长度为 $1 + \text{max1} + \text{max2}$，其中 $\text{max1}, \text{max2}$ 是 $u$ 的异字孩子链中最长与次长（不足则补 $0$，且二者来自**不同孩子**）。

**证明**：

- **上界**：设 $P$ 以 $u$ 为最高点。由引理 1，$P \setminus \{u\}$ 至多两段，落在不同孩子 $c_1, c_2$ 的子树内，每段是 $c_i$ 向下的合法链，且首边 $(u, c_i)$ 合法即 $s[c_i] \ne s[u]$。故每段长度 $\le \text{chain}(c_i) \le$ 异字孩子链的最大值（$\text{max1}$），两段合计 $\le \text{max1} + \text{max2}$（次大值 $\le \text{max1}$，且 $c_1 \ne c_2$ 保证两链来自不同孩子，两条链长之和不超前两大值之和）。故 $|P| \le 1 + \text{max1} + \text{max2}$。
- **可达**：取 $\text{max1}$ 对应的孩子 $c_1$ 的最长链与 $\text{max2}$ 对应的孩子 $c_2 \ne c_1$ 的最长链，加上 $u$ 拼接。链内部相邻字符相异（引理 2 保证），$u$ 与两链首节点 $c_1, c_2$ 之间由 $s[c_i] \ne s[u]$ 保证，故拼接结果是合法路径，长为 $1 + \text{max1} + \text{max2}$。∎

**定理**：算法返回全树最长合法路径的节点数。

**证明**：设最优路径为 $P^\ast$，其最高点为 $u^\ast$（引理 1）。算法在 $u^\ast$ 处的聚合候选为 $1 + \text{max1} + \text{max2} \ge |P^\ast|$（引理 3 上界以 $P^\ast$ 为目标），而每个聚合候选都对应一条真实合法路径（引理 3 可达），故 $\text{ans} \le |P^\ast|$。又 $\text{ans} \ge$ 在 $u^\ast$ 处的候选 $\ge |P^\ast|$，故 $\text{ans} = |P^\ast|$。$n = 1$ 时路径即单节点，`ans` 初始化为 $1$ 恰好覆盖。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。
  - 建邻接表：$O(n)$。
  - DFS / 拓扑队列：每个节点恰好处理一次，每条父子边恰好触发一次 top-2 更新（$O(1)$ 比较，无排序），合计 $O(n)$。
  - 递归版每层 $O(1)$ 额外工作，迭代版队列操作摊还 $O(1)$。
- **空间复杂度**：$O(n)$。
  - 邻接表 `children`：$O(n)$。
  - 递归版调用栈最深 $O(n)$（链状树）；迭代版 `chain` / `deg` 数组 + 队列共 $O(n)$。

## 7. 参考代码

### C++：后序 DFS + top-2（递归版）

```cpp
class Solution {
public:
    int longestPath(vector<int>& parent, string s) {
        int n = parent.size();
        vector<vector<int>> children(n);
        for (int i = 1; i < n; i++) {
            children[parent[i]].push_back(i);
        }
        int ans = 1;
        dfs(0, children, s, ans);
        return ans;
    }

private:
    int dfs(int u, vector<vector<int>>& children, string& s, int& ans) {
        int max1 = 0, max2 = 0;
        for (int v : children[u]) {
            int chain = dfs(v, children, s, ans);
            if (s[v] != s[u]) {
                if (chain > max1) {
                    max2 = max1;
                    max1 = chain;
                } else if (chain > max2) {
                    max2 = chain;
                }
            }
        }
        ans = max(ans, 1 + max1 + max2);
        return 1 + max1;
    }
};
```

### Python：度数计数拓扑（迭代版，防爆栈）

```python
class Solution:
    def longestPath(self, parent: List[int], s: str) -> int:
        from collections import deque

        n = len(parent)
        children = [[] for _ in range(n)]
        for i in range(1, n):
            children[parent[i]].append(i)

        deg = [len(ch) for ch in children]   # 每个节点剩余未处理的孩子数
        chain = [1] * n                      # chain[u] = 以 u 为端点向下的最长异字链
        ans = 1
        queue = deque(i for i in range(n) if deg[i] == 0)

        while queue:
            u = queue.popleft()              # u 出队 <=> u 的孩子已全部处理完（后序时机）
            max1 = max2 = 0
            for v in children[u]:
                if s[v] != s[u]:
                    c = chain[v]
                    if c > max1:
                        max1, max2 = c, max1
                    elif c > max2:
                        max2 = c
            ans = max(ans, 1 + max1 + max2)
            chain[u] = 1 + max1

            p = parent[u]
            if p >= 0:
                deg[p] -= 1
                if deg[p] == 0:
                    queue.append(p)

        return ans
```

> 💡 迭代版的正确性关键：**出队时机即后序时机**——`deg[u] == 0` 意味着 `children[u]` 里的每个 `v` 都已出队并写好终值 `chain[v]`，此时做 top-2 聚合与递归版逐层返回完全等价。根节点 `parent[0] = -1` 处理完毕后队列自然排空，整棵树每个节点恰好处理一次。

## 8. 边界情况与易错点

1. **`ans` 初始化为 1 而非 0**：路径至少含一个节点。全同字符（补充示例 3）或 $n = 1$ 时答案都是 $1$，初始为 $0$ 会错。

2. **同字孩子不能跳过递归**：$s[c] = s[u]$ 只是边 $(u,c)$ 不可用，子树内部的最优路径仍须经过 $c$ 的处理才能进入 `ans`。跳过整棵子树会把内部答案一起丢掉。

3. **top-2 必须先筛选后收集**：同字孩子的 `chain` 不能进 `max1/max2`。示例 1 中节点 $0$ 若误收孩子 $2$ 的链，会算出 $5$ 而非 $3$——这是本题最容易错的单点。

4. **Python 递归爆栈**：$n = 10^5$ 的链状树递归深度 $10^5$，默认上限约 $1000$ 直接 `RecursionError`；`sys.setrecursionlimit(3 * 10^5)` 也只是解除计数限制，深递归仍有 C 栈崩溃风险。赛时 Python 直接写迭代版（§7 度数计数拓扑，或显式栈模拟后序）。

5. **建图从 $i = 1$ 开始**：`parent[0] == -1`。Python 中若写成 `for i in range(n): children[parent[i]].append(i)`，`children[-1]` **不报错**而指向 `children[n-1]`，把根错挂到最后一个节点下——隐蔽的 WA；C++ 中则是越界 UB。必须从 $i = 1$ 开始或显式跳过 $i = 0$。

6. **答案是节点数不是边数**：长度为 $k$ 个节点的路径有 $k - 1$ 条边；本题返回节点数（示例 1 的 `0 -> 1 -> 3` 返回 $3$）。

7. **链状树的深度**：C++ 递归深度可达 $10^5$，LeetCode 评测栈可通过，但本地默认 $8\,\text{MB}$ 栈的环境实测同样会段错误（每帧约百字节量级，$10^5$ 层叠加超限）；对拍调试时遇到无法复现的段错误优先怀疑爆栈，`ulimit -s` 加大后即可复现正常结果。

8. **多条 top-2 链必须来自不同孩子**：逐孩子遍历天然保证；若实现改为「所有可用链排序取前二」也没问题，但若把**同一孩子的两条子链**相加则违反引理 1（两段必须在不同子树）。

**延伸思考**：

- 若约束加强为「路径上**所有**字符互不相同」（不再是相邻局部约束）呢？子树链不再能无条件拼接（拼之前要保证字符集不相交），$O(n)$ 的一趟 top-2 失效。参考 [3425. 最长特殊路径](https://leetcode.cn/problems/longest-special-path/)：树上滑动窗口 + 每种字符最近出现位置的维护，是本题的进阶对照。
- 若再给每条边加边权，求「相邻字符不同」前提下权和最大的路径？`chain` 改为「以 $u$ 为端点的最大权和链」（边权可负时取 $\max(0, \cdot)$ 剪枝），聚合处 top-2 相加，模板不变。
- 若要求输出方案（具体路径）？在聚合点额外记录 top-2 链对应的孩子编号与链上端点，回溯还原即可，复杂度不变。
