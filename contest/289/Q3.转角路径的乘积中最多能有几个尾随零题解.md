# LeetCode 转角路径的乘积中最多能有几个尾随零 题解

## 1. 题目概述

- **标题 / 题号**：转角路径的乘积中最多能有几个尾随零（#2245，medium）
- **链接**：https://leetcode.cn/problems/maximum-trailing-zeros-in-a-cornered-path/
- **来源**：LeetCode 第 289 场周赛 Q3
- **难度**：中等
- **标签**：数组、矩阵、前缀和、数学

**题意**：给定 $m \times n$ 的正整数矩阵 `grid`。**转角路径**是至多含**一个弯**的一组相邻单元格：先沿水平（或竖直）方向移动一段，至多转一次弯后改为沿竖直（或水平）方向移动一段，途中不能重复访问格子。一条路径的**乘积**为路径上所有值之积。求所有转角路径中，乘积**尾随零最多**的那条有多少个尾随零。

**约束**：

- $1 \le m, n \le 10^5$，且 $1 \le m \cdot n \le 10^5$
- $1 \le \text{grid}[i][j] \le 1000$

> 💡 三个赛场信号：① 尾随零只由因子 $2$、$5$ 决定——乘积问题可转化为**因子计数**；② $m \cdot n \le 10^5$ 锁定 $O(m \cdot n)$ 解法；③「至多一个弯」= L 形 = 转角 + 两条一维臂 → **行/列前缀和**。

> 💡 本题在本仓库另有[每日题解 2245](../../solution/2201-2300/2245_转角路径的乘积中最多能有几个尾随零.md)：主线同为「$\min(v_2, v_5)$ + 行/列前缀和 + 满臂最优」，附面试问答与「前缀和端点极值」的等价视角。本篇按**周赛复盘视角**展开，补齐引理-定理化的完备性证明（含零弯直线的支配论证）与赛场易错清单，两篇互为印证。

## 2. 示例

**示例 1**

```text
输入：grid = [[23,17,15,3,20],[8,1,20,27,11],[9,4,6,2,21],[40,9,1,10,6],[22,7,4,5,3]]
输出：3
解释：转角路径 15 → 20 → 6 → 1 → 10 的乘积 15×20×6×1×10 = 18000，含 3 个尾随零。
```

**示例 2**

```text
输入：grid = [[4,3,2],[7,6,1],[8,8,8]]
输出：0
解释：矩阵里没有任何含因子 5 的格子，任何乘积都没有因子 10，尾随零为 0。
```

**补充示例 3（单行矩阵，零弯直线也是合法路径）**

```text
输入：grid = [[8,5,25]]
输出：3
解释：整行是一条零弯的转角路径：8×5×25 = 1000。
     v₂ = 3（来自 8），v₅ = 1 + 2 = 3（来自 5 与 25），min(3, 3) = 3。
```

## 3. 解题思路

### 3.1 暴力思路

枚举「转角位置 × 两臂长度」的全部 L 形：每个转角的水平臂有 $O(n)$ 种取法（沿左/右一侧的端点）、竖直臂有 $O(m)$ 种取法，路径总数 $O\big((m \cdot n)^2\big)$；每条还要 $O(\text{长度})$ 重新统计因子，$m \cdot n = 10^5$ 时约 $10^{10}$ 以上，必然超时。且乘积可达 $1000^{2 \times 10^5}$，任何整型都装不下。

另一个诱人的错误方向：维护行/列的**前缀乘积**并取模，试图从模值反推尾随零——模运算会彻底丢失因子 $2$、$5$ 的精确个数（模值相近的数尾随零可以差很多），此路不通。

### 3.2 核心观察：min(v₂, v₅) + 行/列前缀和 + 满臂最优

![核心观察：L 形 = 转角 + 两臂，尾随零 = min(v₂, v₅)](images/wc289_q3_l_shape_concept.svg)

三个层层递进的观察：

1. **尾随零 = $\min(v_2, v_5)$，乘积问题变求和问题**。乘积 $P = 2^a \cdot 5^b \cdot r$（$r$ 与 $10$ 互素），尾随零数 $= \min(a, b)$。因子个数对乘法**可加**：路径上 $v_2$、$v_5$ 就是各格贡献之和。于是「数乘积尾随零」变成「数路径上 $v_2$、$v_5$ 之和」——**和**可以用前缀和 $O(1)$ 求任意区间。
2. **L 形 = 转角 + 水平臂 + 竖直臂**。转角 $(i,j)$ 是两臂的唯一交点：水平臂是行 $i$ 上以 $(i,j)$ 为端点的一维区间，竖直臂是列 $j$ 上以 $(i,j)$ 为端点的一维区间 → **行前缀和**管水平臂、**列前缀和**管竖直臂。
3. **满臂延伸总是最优**。把臂向矩阵边缘再延伸，新增格子的贡献 $(\Delta v_2, \Delta v_5) \ge (0, 0)$，两个分量同时不减，故 $\min(v_2, v_5)$ **单调不降**。于是**不必枚举臂长**：每个转角只需算 4 种「满臂」方向组合，$O(m+n)$ 的臂长维度被直接消去。

> ⚠️ 观察 3 依赖「格值为**正**整数」这一前提——贡献恒非负。若格值可正可负，满臂单调性失效，$O(m \cdot n)$ 解法随之瓦解。

### 3.3 算法流程

![算法流程：行/列前缀和 + 转角 × 4 满臂组合](images/wc289_q3_prefix_arms.svg)

预处理（各多开一位，省去边界特判）：

- `row2[i][k]`：行 $i$ 前 $k$ 列（列 $0..k-1$）的 $v_2$ 之和；`row5` 同理。
- `col2[j][k]`：列 $j$ 前 $k$ 行（行 $0..k-1$）的 $v_2$ 之和；`col5` 同理。

对每个转角 $(i,j)$，四条**含转角**的满臂：

| 满臂 | 所在直线 | 区间 | $v_2$（$v_5$ 同理） |
|------|---------|------|---------------------|
| 左臂 | 行 $i$ | 列 $0..j$ | `row2[i][j+1]` |
| 右臂 | 行 $i$ | 列 $j..n-1$ | `row2[i][n] - row2[i][j]` |
| 上臂 | 列 $j$ | 行 $0..i$ | `col2[j][i+1]` |
| 下臂 | 列 $j$ | 行 $i..m-1$ | `col2[j][m] - col2[j][i]` |

两臂在转角处重叠一份，因此每种「(左|右) × (上|下)」组合：

$$
\text{total}_2 = H_2 + V_2 - c_2[i][j], \qquad \text{total}_5 = H_5 + V_5 - c_5[i][j]
$$

更新 $\text{ans} \gets \max(\text{ans},\; \min(\text{total}_2, \text{total}_5))$，共 $4mn$ 个组合。

### 3.4 示例演算

![示例演算：转角 (3,2) 的四个满臂组合](images/wc289_q3_walkthrough.svg)

对示例 1 取转角 $(3,2)$（值为 $1$，自身贡献 $(v_2, v_5) = (0,0)$）。四条满臂（均含转角）：左臂 $40,9,1$、右臂 $1,10,6$、上臂 $15,20,6,1$、下臂 $1,4$，因子和分别为 $(3,1)$、$(2,1)$、$(3,2)$、$(2,0)$。四个组合：

| 组合 | $(\text{total}_2,\ \text{total}_5)$ | $\min$ |
|------|--------------------------------------|--------|
| 左 + 上 | $(6,\ 3)$ | $3$ |
| 左 + 下 | $(5,\ 1)$ | $1$ |
| 右 + 上 | $(5,\ 3)$ | $\mathbf{3}$ |
| 右 + 下 | $(4,\ 1)$ | $1$ |

该转角最优为 $3$。题目解释里的路径 $15 \to 20 \to 6 \to 1 \to 10$ 正是「右 + 上」去掉最后一格 $(3,4)=6$ 的情形：满臂多带的这个 $6$ 让 $v_2$ 加 $1$、$v_5$ 不变，$\min$ 仍为 $3$——「满臂不降」的直接体现。全场答案即 $3$。

## 4. 算法细节

1. **因子预处理**：$\text{grid}[i][j] \le 1000$，故单格 $v_2 \le 9$（$2^9 = 512$）、$v_5 \le 4$（$5^4 = 625$），逐格试除 $O(\log V) \approx 10$ 步。全表前缀和上界约 $9 \times 10^5$，`int` 足够。
2. **前缀和多开一位**：`row2` 每行开 $n+1$、`col2` 每列开 $m+1$；`prefix[k]` 表「前 $k$ 个元素」，区间 $[l, r]$ 的和 $= \text{prefix}[r+1] - \text{prefix}[l]$，免特判 $l = 0$。
3. **四段均含转角**：左/上臂写作 `[j+1]`、`[i+1]`（端点含转角），右/下臂写作 `[n] - [j]`、`[m] - [i]`（区间 $[j, n-1]$、$[i, m-1]$）；随后**统一减去一份转角贡献** $c_2[i][j]$、$c_5[i][j]$ 去重。
4. **单行 / 单列自动退化**：$m = 1$ 时上/下臂退化为转角一格，$H + V - c$ 恰等于水平满臂本身——直线（零弯）路径无需特判即被覆盖。
5. **组合枚举写成 2×2 双循环**：`(左|右) × (上|下)` 收进两个小数组，避免复制四份相似代码、漏改其中一份。

## 5. 正确性证明

**引理 1（尾随零刻画）**：设正整数 $P = 2^a \cdot 5^b \cdot r$，其中 $r$ 与 $10$ 互素，则 $P$ 的尾随零数为 $\min(a, b)$；且对乘积有 $v_p\!\Big(\prod_t x_t\Big) = \sum_t v_p(x_t)$。

**证明**：$10^t \mid P \iff 2^t \mid P$ 且 $5^t \mid P \iff t \le a$ 且 $t \le b \iff t \le \min(a, b)$，故整除 $P$ 的 $10$ 的最高幂次为 $\min(a, b)$，即末尾恰有 $\min(a, b)$ 个零、第 $\min(a,b)+1$ 位非零。可加性来自唯一分解定理：乘积的质因子指数等于各因子指数之和。∎

**引理 2（满臂不降）**：设合法转角路径 $S$ 扩充为 $S' = S \cup D$（$D$ 为新增格子集合），则 $\min\big(v_2(S'),\, v_5(S')\big) \ge \min\big(v_2(S),\, v_5(S)\big)$。

**证明**：格值为正整数，$v_2(S') = v_2(S) + v_2(D) \ge v_2(S)$，$v_5$ 同理；设 $a \le a'$、$b \le b'$，则 $\min(a', b') \ge \min(a, b)$（两分量同增时 $\min$ 不减）。∎

**引理 3（候选合法）**：对任意 $(i,j)$ 与方向组合，两条满臂之并是一条合法转角路径；按 $H + V - c$ 计数时每个格子恰被计入一次。

**证明**：水平满臂是行 $i$ 从边缘到 $(i,j)$ 的连续段，竖直满臂是列 $j$ 从 $(i,j)$ 到边缘的连续段，二者仅在 $(i,j)$ 相交，无重复格子；行进为「沿水平臂 → 在 $(i,j)$ 至多转一次弯 → 沿竖直臂」，至多一个弯。当某一臂长度为 1（臂即转角）时退化为直线（零弯），仍合法。两臂前缀和各含转角一份，减去一份后恰计一次。∎

**定理**：算法枚举全部 $m \cdot n$ 个转角 $\times\ 4$ 种满臂组合并取 $\max\min$，返回值等于全局最优 $\mathrm{OPT}$。

**证明**：

- **（ans $\le$ OPT）**：由引理 3，每个被评估的满臂组合都是合法转角路径，其 $\min(v_2, v_5)$ 不超过所有合法路径的最优值 $\mathrm{OPT}$；取最大值亦然。
- **（ans $\ge$ OPT）**：设 $P$ 为取到 $\mathrm{OPT}$ 的合法路径。若 $P$ 恰有一个弯，设弯在 $(i,j)$，其水平臂沿某方向终止于 $(i,j)$、竖直臂沿某方向终止于 $(i,j)$；把两臂沿各自方向延长到矩阵边缘，得到满臂组合 $L \supseteq P$，由引理 2 得 $\text{val}(L) \ge \text{val}(P) = \mathrm{OPT}$。若 $P$ 为零弯直线（不妨设位于行 $i$、列区间 $[j_1, j_2]$），取端点 $(i, j_2)$ 为转角，取**覆盖线段一侧**的水平满臂（列 $0..j_2$，是 $[j_1, j_2]$ 的超集），再任取一条竖直满臂，同样得到 $L \supseteq P$ 且 $\text{val}(L) \ge \mathrm{OPT}$。两种情形的 $L$ 都在算法枚举的 $4mn$ 个候选之中，故 $\text{ans} \ge \text{val}(L) \ge \mathrm{OPT}$。

两条合并即 $\text{ans} = \mathrm{OPT}$。∎

> 💡 直线情形是初学时最容易被漏证的完备性缺口：转角要取**线段端点**、水平臂要取**线段所在的一侧**，满臂才包含整条线段。不补这条论证，「只枚举 L 形」对零弯路径的正确性就没有着落。

## 6. 复杂度分析

- **时间复杂度**：$O(m \cdot n)$。因子试除 $O(m \cdot n \log V)$（$V = 1000$，$\log V \le 10$，常数极小）；行/列前缀和各 $O(m \cdot n)$；枚举 $m \cdot n$ 个转角 × 4 组合、每组 $O(1)$。
- **空间复杂度**：$O(m \cdot n)$。`c2/c5` 因子表与 `row*/col*` 前缀和共 6 张表；如需压空间可按行/列滚动复用降至 $O(m + n)$，但 $m \cdot n \le 10^5$ 下无此必要。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int maxTrailingZeros(vector<vector<int>>& grid) {
        int m = grid.size(), n = grid[0].size();
        auto cnt = [](int x, int p) {
            int c = 0;
            while (x % p == 0) {
                ++c;
                x /= p;
            }
            return c;
        };
        vector<vector<int>> c2(m, vector<int>(n)), c5(m, vector<int>(n));
        for (int i = 0; i < m; ++i)
            for (int j = 0; j < n; ++j) {
                c2[i][j] = cnt(grid[i][j], 2);
                c5[i][j] = cnt(grid[i][j], 5);
            }
        // row2[i][k]：行 i 前 k 列的 v2 之和（v5 同理）
        vector<vector<int>> row2(m, vector<int>(n + 1)), row5(m, vector<int>(n + 1));
        for (int i = 0; i < m; ++i)
            for (int j = 0; j < n; ++j) {
                row2[i][j + 1] = row2[i][j] + c2[i][j];
                row5[i][j + 1] = row5[i][j] + c5[i][j];
            }
        // col2[j][k]：列 j 前 k 行的 v2 之和（v5 同理）
        vector<vector<int>> col2(n, vector<int>(m + 1)), col5(n, vector<int>(m + 1));
        for (int j = 0; j < n; ++j)
            for (int i = 0; i < m; ++i) {
                col2[j][i + 1] = col2[j][i] + c2[i][j];
                col5[j][i + 1] = col5[j][i] + c5[i][j];
            }
        int ans = 0;
        for (int i = 0; i < m; ++i)
            for (int j = 0; j < n; ++j) {
                int H2[2] = {row2[i][j + 1], row2[i][n] - row2[i][j]}; // 左臂 / 右臂
                int H5[2] = {row5[i][j + 1], row5[i][n] - row5[i][j]};
                int V2[2] = {col2[j][i + 1], col2[j][m] - col2[j][i]}; // 上臂 / 下臂
                int V5[2] = {col5[j][i + 1], col5[j][m] - col5[j][i]};
                for (int a = 0; a < 2; ++a)
                    for (int b = 0; b < 2; ++b)
                        ans = max(ans, min(H2[a] + V2[b] - c2[i][j],
                                           H5[a] + V5[b] - c5[i][j]));
            }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maxTrailingZeros(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])

        def cnt(x: int, p: int) -> int:
            c = 0
            while x % p == 0:
                c += 1
                x //= p
            return c

        c2 = [[cnt(grid[i][j], 2) for j in range(n)] for i in range(m)]
        c5 = [[cnt(grid[i][j], 5) for j in range(n)] for i in range(m)]

        row2 = [[0] * (n + 1) for _ in range(m)]
        row5 = [[0] * (n + 1) for _ in range(m)]
        for i in range(m):
            for j in range(n):
                row2[i][j + 1] = row2[i][j] + c2[i][j]
                row5[i][j + 1] = row5[i][j] + c5[i][j]

        col2 = [[0] * (m + 1) for _ in range(n)]
        col5 = [[0] * (m + 1) for _ in range(n)]
        for j in range(n):
            for i in range(m):
                col2[j][i + 1] = col2[j][i] + c2[i][j]
                col5[j][i + 1] = col5[j][i] + c5[i][j]

        ans = 0
        for i in range(m):
            for j in range(n):
                H2 = (row2[i][j + 1], row2[i][n] - row2[i][j])   # 左臂 / 右臂
                H5 = (row5[i][j + 1], row5[i][n] - row5[i][j])
                V2 = (col2[j][i + 1], col2[j][m] - col2[j][i])   # 上臂 / 下臂
                V5 = (col5[j][i + 1], col5[j][m] - col5[j][i])
                for a in range(2):
                    for b in range(2):
                        ans = max(ans, min(H2[a] + V2[b] - c2[i][j],
                                           H5[a] + V5[b] - c5[i][j]))
        return ans
```

## 8. 边界情况与易错点

1. **转角重复计数**：两臂前缀和都含转角，$H + V$ 把转角算了两次，必须减去一份 $c[i][j]$；忘减会让转角自身的因子被双计（如转角为 $10$ 时凭空多出一个「零」的原料），答案偏大。
2. **端点 off-by-one**：含转角的左/上臂是 `row[i][j+1]`、`col[j][i+1]`，写成 `row[i][j]` 会漏掉转角格；右/下臂 `row[i][n] - row[i][j]` 写成 `- row[i][j+1]` 同样漏格。
3. **行列维度用反**：`row*` 每行长 $n+1$、`col*` 每列长 $m+1$。方阵上测不出错，长条矩阵（如 $1 \times 10^5$）上直接越界或 WA——赛后要用长条用例自测。
4. **单行 / 单列**：合法路径只剩直线；公式中另一臂自动退化为转角一格，无需特判（正是定理证明里直线情形的落地）。
5. **答案初值 0**：全 $1$ 矩阵（无任何因子 $2/5$）答案为 $0$；所有组合的 $\min \ge 0$，`ans = 0` 起步安全。
6. **v₂、v₅ 缺一不可**：因子 $2$ 通常远多于 $5$，但全 $2^k$ 矩阵的答案卡在 $v_5 = 0$ 上；只统计一侧必错。
7. **别用取模维护乘积**：模值无法恢复 $2$、$5$ 因子的精确个数，前缀乘积思路从根上不可行。
8. **隐性收益：无大数**：路径可长达 $2 \times 10^5$ 格，真实乘积远超任何整型；算法只对 $v_2, v_5$ 求和（上界约 $9 \times 10^5$），`int` 即可——「乘积变求和」顺带解决了溢出。

**延伸思考**：

- **允许 $k$ 个弯**（折线而非 L 形）：满臂最优性依然成立（延伸仍非负），但需逐行/列维护「以当前格为端点、已用弯数的最优折线值」的 DP，复杂度升至 $O(k \cdot m \cdot n)$。
- **格值可正可负或含零**：零使「乘积为 $0$」的路径尾随零无定义，负贡献打破满臂单调性；两问都需重新建模（区间 DP 或双指标前缀极值），难度陡增——本题限定正整数正是为了让单调性成立。
