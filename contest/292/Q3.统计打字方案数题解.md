# LeetCode 统计打字方案数 题解

## 1. 题目概述

- **标题 / 题号**：统计打字方案数（#2266，medium）
- **链接**：https://leetcode.cn/problems/count-number-of-texts/
- **来源**：LeetCode 第 292 场周赛 Q3
- **难度**：中等
- **标签**：字符串、动态规划、计数、爬楼梯（斐波那契型递推）

**题意**：九键键盘上数字 $2\sim9$ 各映射一段字母（`2→abc, 3→def, 4→ghi, 5→jkl, 6→mno, 7→pqrs, 8→tuv, 9→wxyz`），其中 **7 和 9 映射 4 个字母，其余映射 3 个**。要打出某键上的第 $i$ 个字母，需连按该键 $i$ 次；一个字母的全部按键必然是**同一字符的连续段**。现在 Bob 收到的不是文字而是按键字符串 `pressedKeys`，求 Alice 原本可能发出的不同文字信息的总数，对 $10^9+7$ 取余。

**约束**：

- $1 \le \text{pressedKeys.length} \le 10^5$
- `pressedKeys` 只包含数字 `'2'` 到 `'9'`（不会出现不映射字母的 `'0'`/`'1'`）

> 💡 本题在本仓库另有[每日题解 2266](../../solution/2201-2300/2266_统计打字方案数.md)：以「分段 + 步长通用模板」主线、滚动数组优化与面试问答（91 题耦合对比、$f(0)$ 语义、取模溢出）展开。本篇按**周赛复盘视角**展开，侧重**两个观察的快速切入路径**、**k=3/k=4 从 $f(4)$ 才分化的隐蔽 WA 反例**、引理-定理化的严格证明（切分双射 + 笛卡尔积 + 末块分类递推）与边界清单，两篇互为印证。

## 3. 解题思路

### 3.1 暴力思路：枚举所有切分

最朴素的做法是对整条按键串做指数级 DFS：每个位置尝试让「下一个字母」占 1..k 个按键，递归到底计数。单个长为 $L$ 的 run 最坏有约 $4^{L/4}$ 量级的切分，$n = 10^5$ 时天文数字，必然超时；而且这种写法把所有位置一视同仁，完全没利用「**不同字符之间必然断开**」这一结构性约束。

### 3.2 核心观察：极大同字符段独立 + 段内就是爬楼梯

![核心观察：按极大同字符段切开，段内计数就是爬楼梯](images/2266_contest_run_concept.svg)

两个关键观察把问题直接打穿：

**观察一（跨段必断）**：一个字母的所有按键必须是同一数字字符（打字母 `s` 只能连按 `7`）。因此位置 $p$ 与 $p+1$ 字符不同时，**没有任何字母能横跨这条边界**——整条按键串在「极大同字符段（run）」边界处被天然切开。段与段之间互不影响，**乘法原理**：总方案数 = 各 run 方案数之积。

**观察二（段内双射）**：在一个长为 $L$ 的 run 内（字符映射 $k$ 个字母），一种文字 ↔ 一种把 run 切成若干块、每块长度 $\in[1,k]$ 的**有序切分**——因为长为 $j$ 的块恰好解码为该键第 $j$ 个字母，是**一一对应**（"22233" 中 "222" 有 $[1,1,1],[1,2],[2,1],[3]$ 共 4 种切分，正对应 aaa/ab/ba/c）。于是段内计数就是**爬楼梯（70 题）的直接泛化**：

$$f(0) = 1,\qquad f(i) = f(i-1) + f(i-2) + \cdots + f(i-k)$$

（最后一块长 $j$，剩下 $f(i-j)$ 种）。$k=3$ 时是**三阶斐波那契（tribonacci）**：$1,1,2,4,7,13,24,\dots$；$k=4$ 时是**四阶斐波那契（tetranacci）**：$1,1,2,4,8,15,29,\dots$——两列数直到 $f(3)$ 都相同，从 $f(4)$ 起才分化为 $7$ 与 $8$（见示例 3）。

### 3.3 算法流程

![算法流程：预处理 f3/f4，再单遍扫描结算](images/2266_contest_flow.svg)

1. **预处理**：递推两张表 `f3[0..n]`、`f4[0..n]`，每项至多 4 次加法后取模；
2. **扫描**：双指针取每个极大同字符段 `[i, j)`，长度 `L = j - i`；
3. **查表**：字符是 `'7'` 或 `'9'` 取 `f4[L]`，否则取 `f3[L]`；
4. **结算**：`ans = ans * f % MOD`，`i = j` 继续下一段；
5. 全段扫完返回 `ans`。

### 3.4 示例演算

![示例演算："22233" 与 f3/f4 分化](images/2266_contest_walkthrough.svg)

对 `"22233"`：run `"222"` 内递推 $f(1)=1,\ f(2)=1+1=2,\ f(3)=2+1+1=4$，段末结算 $ans = 4$；run `"33"` 重新从 $f(0)=1$ 起算得 $f(2)=2$，结算 $ans = 4\times2 = 8$，与示例 1 一致。演算图同时给出 `f3`/`f4` 前几项的对照，标出 $f(4)=7\ne 8$ 的分化点。

## 4. 算法细节

1. **k 的判定**：字符 `'7'`、`'9'` 映射 4 个字母（pqrs / wxyz），其余映射 3 个。只需 `c == '7' || c == '9'` 判定，无需建键盘映射表。
2. **递推边界**：`f3[i] = f3[i-1] + f3[i-2] + f3[i-3]`（不足的项按 0 处理，等价于求和上限 $\min(k, i)$），故 `f3[1]=1, f3[2]=2, f3[3]=4`；`f4` 同理多加一项 `f4[i-4]`。
3. **初值 $f(0)=1$ 的语义**：空段恰有 1 种方案（什么都不切）。它是整个递推的种子，取 0 则全线崩塌。
4. **新段必须重置**：每个 run 都从 $f(0)=1$ 重新起算，段与段的 $f$ 值不可复用（若写成整串位置 DP 则等价，由 run 边界自动切断）。
5. **O(1) 滚动变体**：预处理数组可换成 4 变量窗口 $(f(t{-}3),f(t{-}2),f(t{-}1),f(t))$，初值 $(0,0,0,1)$，每步 `new = d + c + b + (a if k==4 else 0)` 后平移，空间降到 $O(1)$（见 Python 参考代码的变体）。
6. **取模纪律**：`f` 与 `ans` 每步取模。C++ 中三项之和 $\le 3\times(10^9{+}7) < 2^{63}$，乘积 $\le (10^9{+}7)^2 \approx 10^{18} < 9.2\times10^{18}$，全程 `long long` 安全；`int` 必溢出。

## 5. 正确性证明

**引理 1（块-字母双射）**：设字符 $c$ 映射有序字母表 $\ell_1,\dots,\ell_k$（$k=3$ 或 $4$）。在 $c$ 的一个 run 内，「合法文字串」与「把 run 切成若干块长 $\in[1,k]$ 的有序切分」一一对应。

**证明**：映射 $\Phi$（文字 → 切分）：文字中每个字母 $\ell_j$ 的按键是长为 $j$ 的同字符块，按顺序拼接即得切分，且拼接结果的按键串恰为该 run（按键内容由 run 决定）。映射 $\Psi$（切分 → 文字）：对每块依长度 $j$ 解码为 $\ell_j$，顺序读出得文字。由「按 $i$ 次得第 $i$ 个字母」的定义，$\Psi \circ \Phi = \mathrm{id}$ 且 $\Phi \circ \Psi = \mathrm{id}$，故为双射。∎

**引理 2（跨段独立）**：若位置 $p$ 与 $p+1$ 处字符不同，则任何合法文字中没有字母同时覆盖这两个位置；从而每个字母完整落在唯一一个极大同字符 run 内，合法文字集合是各 run 局部文字选择的笛卡尔积。

**证明**：一个字母的按键全部来自同一字符 $c$（打它只能连按同一个键），若某字母覆盖 $p$ 与 $p+1$，则 $\text{s}[p] = \text{s}[p+1] = c$，与字符不同矛盾。故任意文字的切分在每个 run 边界处断开，各 run 内的块互不跨界；反之各 run 任取一个局部切分拼起来仍是合法文字。两个方向合起来即笛卡尔积结构。∎

**引理 3（段内递推）**：长为 $L$、字符映射 $k$ 个字母的 run，其方案数 $f$ 满足 $f(0)=1$，且对 $L \ge 1$：$f(L) = \sum_{j=1}^{\min(k,L)} f(L-j)$。

**证明**：$L=0$ 时空切分一种方案。$L\ge1$ 时按切分中**最后一块**的长度 $j$ 分类：$j$ 取遍 $1..\min(k,L)$（块非空、不超 $k$），各类互斥且完备。固定 $j$ 后，由引理 1 最后一块解码出唯一字母（长为 $j$ 的块对应 $\ell_j$，与前面怎么切无关），剩余前 $L-j$ 个按键是同一字符、同一 $k$ 的子问题，方案数 $f(L-j)$。由乘法与加法原理求和即得。∎

**定理**：设输入切成极大同字符段 $r_1,\dots,r_m$，段 $r_t$ 长 $L_t$、其字符映射 $k_t$ 个字母，则答案为 $\prod_{t=1}^{m} f_{k_t}(L_t) \bmod (10^9+7)$，算法输出恰为该值。

**证明**：由引理 2，合法文字总数等于各段方案数之积（笛卡尔积的基数）；由引理 3，各段方案数由递推 $f(0)=1,\ f(i)=\sum_{j=1}^{\min(k,i)} f(i-j)$ 正确计算。算法忠实实现该递推与逐段累乘，且只在加法、乘法后立即取模，全程与真值在模 $10^9+7$ 下同余，故输出正确。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。预处理每个 $i$ 至多 4 次加法一次取模共 $O(n)$；扫描阶段每段结算 $O(1)$ 查表，段长之和为 $n$，总计线性。瓶颈在整串一次遍历，$n = 10^5$ 轻松通过。
- **空间复杂度**：$O(n)$，两张预处理 `long long` 数组；改用四值滚动窗口可降到 $O(1)$（本例 $n\le10^5$，$O(n)$ 空间约 $2 \times 8 \times 10^5$ 字节，完全无压力）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int countTexts(string s) {
        const long long MOD = 1e9 + 7;
        int n = s.size();
        vector<long long> f3(n + 1), f4(n + 1);
        f3[0] = f4[0] = 1;                       // 空段恰 1 种方案
        for (int i = 1; i <= n; ++i) {
            f3[i] = f3[i - 1];
            f4[i] = f4[i - 1];
            if (i >= 2) { f3[i] += f3[i - 2]; f4[i] += f4[i - 2]; }
            if (i >= 3) { f3[i] += f3[i - 3]; f4[i] += f4[i - 3]; }
            if (i >= 4) f4[i] += f4[i - 4];      // 7/9 独有的一项
            f3[i] %= MOD;
            f4[i] %= MOD;
        }
        long long ans = 1;
        int i = 0;
        while (i < n) {
            int j = i;
            while (j < n && s[j] == s[i]) ++j;   // 极大同字符段 [i, j)
            long long f = (s[i] == '7' || s[i] == '9') ? f4[j - i] : f3[j - i];
            ans = ans * f % MOD;                 // 段间独立，乘法原理
            i = j;
        }
        return (int)ans;
    }
};
```

### Python

```python
class Solution:
    def countTexts(self, s: str) -> int:
        MOD = 10 ** 9 + 7
        n = len(s)
        f3 = [0] * (n + 1)
        f4 = [0] * (n + 1)
        f3[0] = f4[0] = 1
        for i in range(1, n + 1):
            f3[i] = f3[i-1] + (f3[i-2] if i >= 2 else 0) + (f3[i-3] if i >= 3 else 0)
            f4[i] = (f4[i-1] + (f4[i-2] if i >= 2 else 0)
                     + (f4[i-3] if i >= 3 else 0) + (f4[i-4] if i >= 4 else 0))
            f3[i] %= MOD
            f4[i] %= MOD

        ans, i = 1, 0
        while i < n:
            j = i
            while j < n and s[j] == s[i]:
                j += 1
            f = f4[j - i] if s[i] in '79' else f3[j - i]
            ans = ans * f % MOD
            i = j
        return ans
```

**变体：四值滚动，O(1) 空间**

```python
class Solution:
    def countTexts(self, s: str) -> int:
        MOD = 10 ** 9 + 7
        ans, i, n = 1, 0, len(s)
        while i < n:
            j = i
            while j < n and s[j] == s[i]:
                j += 1
            k = 4 if s[i] in '79' else 3
            a, b, c, d = 0, 0, 0, 1               # f(t-3), f(t-2), f(t-1), f(t)
            for _ in range(j - i):
                a, b, c, d = b, c, d, (d + c + b + (a if k == 4 else 0)) % MOD
            ans = ans * d % MOD
            i = j
        return ans
```

## 8. 边界情况与易错点

1. **初值 $f(0)=1$ 不能写成 0**：它是「空段一种方案」的种子；错成 0 会让所有 $f$ 归零、答案恒 0。
2. **7 和 9 是四字母键**：漏判成 $k=3$ 时，`"7777"` 会答 7 而正确答案是 8。特别注意 $f(1)..f(3)$ 两组数完全相同，**短样例测不出这个 bug**——错误从 $f(4)$ 才开始暴露（`"7777"`/`"2222"` 是最小反例对）。
3. **跨段不可复用 $f$**：每个 run 从 $f(0)=1$ 重起；把上一段的 $f$ 值带入下一段会串段出错。
4. **取模与溢出**：C++ 全程 `long long`（乘积约 $10^{18}$ 贴近上限）；`int` 存 $f$ 或 $ans$ 直接溢出。Python 无溢出问题，但也应每步取模防止大整数运算变慢。
5. **块长下界是 1**：字母至少按 1 次，没有「零按键字母」，递推求和从 $j=1$ 开始（这就是 $f(i)$ 不含 $f(i)$ 自身的原因，别写成滑窗自环）。
6. **无需处理 '0'/'1'**：题目保证只含 '2'~'9'；若变体允许出现，因其不映射字母，答案为 0，需显式特判返回。
7. **整体位置 DP 等价性**：若不显式分段而写 `g(i) = Σ g(i-j)`（要求 `s[i-j..i-1]` 同字符），复杂度同为 $O(n)$；漏掉「同字符检查」则是常见 WA 来源——分段写法从结构上杜绝了这一错误。
8. **别用浮点或通项公式**：tribonacci 通项含无理数幂，$n=10^5$ 精度必然崩；矩阵快速幂虽可 $O(k^3\log n)$ 求单项，但本题直接线性递推最稳。
