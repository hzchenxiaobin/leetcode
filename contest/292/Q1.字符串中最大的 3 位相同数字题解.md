# LeetCode 字符串中最大的 3 位相同数字 题解

## 1. 题目概述

- **标题 / 题号**：字符串中最大的 3 位相同数字（#2264，easy）
- **链接**：https://leetcode.cn/problems/largest-3-same-digit-number-in-string/
- **来源**：LeetCode 第 292 场周赛 Q1
- **难度**：简单
- **标签**：字符串、枚举

**题意**：给定数字字符串 `num`。称一个整数为**优质整数**，当且仅当它是 `num` 的一个长度为 3 的子字符串，且由同一个数字重复 3 次组成（如 `"777"`、`"000"`）。以字符串形式返回**最大**的优质整数；不存在则返回 `""`。

**约束**：

- $3 \le \text{num.length} \le 1000$
- `num` 仅由数字（`'0'`-`'9'`）组成
- 优质整数允许前导零，`"000"` 是合法答案

## 2. 示例

**示例 1**

```text
输入：num = "6777133339"
输出："777"
解释：优质整数有 "777"（下标 1-3）与 "333"（下标 5-7），最大的是 "777"。
```

**示例 2**

```text
输入：num = "2300019"
输出："000"
解释："000" 是唯一的优质整数。0 也是合法数字，不能因前导零而丢弃。
```

**示例 3**

```text
输入：num = "42352338"
输出：""
解释：不存在连续三个相同的数字。
```

## 3. 解题思路

### 3.1 暴力思路

枚举全部 $n-2$ 个长度为 3 的子串，把三字符相同的子串统统收进列表，最后取最大：

```text
candidates = []
for i in 0 .. n-3:
    if num[i..i+2] 三个字符相同:
        candidates.append(num[i..i+2])
return max(candidates)（若非空），否则 ""
```

时间 $O(n)$、空间 $O(n)$。$n \le 1000$ 完全能过，但属于"过度收集"——只需要一个极值，却保存了全部候选。

### 3.2 核心观察：优质整数形如 ddd，大小只看数字 d

![核心观察：优质整数形如 ddd，大小只看数字 d](images/2264_contest_scan_concept.svg)

**观察一（结构确定，比较归结）**：优质整数必然形如 `"ddd"`，其中 $d \in \{'0',\dots,'9'\}$，因此两个优质整数的大小比较**等价于单个数字 $d$ 的比较**——`"777"` 对应 7、`"333"` 对应 3，$7 > 3$。于是无需保存 3 字符子串，一个整数变量 `best` 足够。

**观察二（候选稀疏）**：所有可能的优质整数只有 **10 种**——`"999"`、`"888"`、…、`"000"`。正向做法是单趟扫描：对每个起点 $i \in [0, n-3]$ 用 $O(1)$ 判断 `num[i] == num[i+1] == num[i+2]`，命中则用该数字更新 `best`；也可以从大到小逐个试探（见第 4 节）。

**观察三（哨兵必须避开 0）**：`'0'` 是合法命中（示例 2 返回 `"000"`），所以"未找到"的哨兵**不能取 0**。取 `best = -1`（小于一切数字）即可干净区分"未命中"与"命中 0"两种状态。

### 3.3 算法流程

![算法流程：单趟扫描，滚动维护最大数字](images/2264_contest_flow.svg)

1. **初始化**：`best = -1`；
2. **遍历**：对每个起点 $i$ 从 $0$ 到 $n-3$，判断三字符是否相同；相同则 `best = max(best, d)`，其中 $d$ 为该数字；
3. **返回**：`best` 仍为 $-1$ 则返回 `""`，否则返回 `d` 重复 3 次构成的串。

### 3.4 示例演算

![示例演算：6777133339 与 2300019 的逐步走查](images/2264_contest_walkthrough.svg)

`num = "6777133339"`（$n = 10$，窗口起点 $i = 0..7$）：

| $i$ | 窗口 | 三字符相同？ | best |
|-----|------|------------|------|
| 0 | `677` | ✗ | $-1$ |
| 1 | `777` | ✓（$d=7$） | $7$ ★ |
| 2 | `771` | ✗ | $7$ |
| 3 | `713` | ✗ | $7$ |
| 4 | `133` | ✗ | $7$ |
| 5 | `333` | ✓（$d=3$） | $7$（$3 < 7$ 不换） |
| 6 | `333` | ✓（$d=3$） | $7$（不换） |
| 7 | `339` | ✗ | $7$ |

$i=1$ 命中 `"777"`，`best` 由 $-1$ 更新为 $7$；$i=5,6$ 虽命中 `"333"`，但 $3 < 7$ 不更新。最终 `best = 7`，返回 `"777"` ✓。

`num = "2300019"`：仅 $i=2$ 命中 `"000"`（$d=0$），`best` 由 $-1$ 更新为 $0$，返回 `"000"` ✓——这正是哨兵取 $-1$ 而非 $0$ 的价值。

## 4. 算法细节

1. **窗口边界**：起点 $i$ 的合法区间是 $[0, n-3]$；循环写成 `i + 2 < n`（C++）可避免 `n` 为无符号数时 `n - 3` 在 $n < 3$ 时下溢（本题 $n \ge 3$ 无实际风险，但习惯更稳）。
2. **三元判等的短路形式**：Python 直接链式比较 `num[i] == num[i+1] == num[i+2]`；C++ 写 `num[i] == num[i+1] && num[i+1] == num[i+2]`，两次比较均 $O(1)$。
3. **哨兵与还原**：`best = -1` 表示未命中；命中时 `best = max(best, num[i] - '0')`；返回时 `best < 0` 给 `""`，否则 `string(3, '0' + best)` / `str(best) * 3` 还原三连串。
4. **替代写法（从大到小试探）**：优质整数只有 10 种，从 `'9'` 到 `'0'` 逐个判断 `d*3 in num`，第一个命中的即答案——天然规避哨兵问题且可提前返回；至多 10 次子串查找，总时间 $O(10n) = O(n)$。

```python
class Solution:
    def largestGoodInteger(self, num: str) -> str:
        for d in '9876543210':
            if d * 3 in num:
                return d * 3
        return ''
```

## 5. 正确性证明

**引理 1**：子串 `num[i..i+2]` 是优质整数，当且仅当 `num[i] == num[i+1] == num[i+2]`。

**证明**：优质整数定义为"长度为 3 且由唯一数字重复 3 次组成的子串"。长度为 3 的子串三字符相同 $\iff$ 由唯一数字重复 3 次。∎

**引理 2**：设两个优质整数分别为 $d_1d_1d_1$ 与 $d_2d_2d_2$，则前者大于后者当且仅当 $d_1 > d_2$。

**证明**：三连串的数值为 $111 \cdot d$，$111 > 0$，故 $111d_1 > 111d_2 \iff d_1 > d_2$。∎

**定理**：上述算法返回 `num` 中最大的优质整数；不存在时返回 `""`。

**证明**：算法枚举全部 $n-2$ 个窗口起点。由引理 1，每个命中窗口的数字都参与了 `max` 比较，故 `best` 终值即"出现过连续 3 次的数字"中的最大值（从未命中则保持 $-1$）。由引理 2，`best` 对应的三连串即最大优质整数；`best = -1` 时不存在优质整数，返回 `""`。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。单趟扫描 $n-2$ 个窗口，每个窗口至多两次字符比较加一次 `max` 更新。
- **空间复杂度**：$O(1)$。仅维护哨兵变量 `best` 与循环变量，返回串长度恒为 3（或 0），不随 $n$ 增长。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    string largestGoodInteger(string num) {
        int best = -1;
        for (int i = 0; i + 2 < (int)num.size(); ++i) {
            if (num[i] == num[i + 1] && num[i + 1] == num[i + 2]) {
                best = max(best, num[i] - '0');
            }
        }
        return best < 0 ? "" : string(3, '0' + best);
    }
};
```

### Python

```python
class Solution:
    def largestGoodInteger(self, num: str) -> str:
        best = -1
        for i in range(len(num) - 2):
            if num[i] == num[i + 1] == num[i + 2]:
                best = max(best, int(num[i]))
        return '' if best < 0 else str(best) * 3
```

## 8. 边界情况与易错点

1. **前导零**：`"000"` 是合法答案（示例 2）。任何把 `'0'` 当作"未命中"标记的写法（如初值 `best = 0` 配 `if num[i] > best`）都依赖巧合而非不变式；哨兵应取 $-1$、空串或空格。
2. **Python 的 falsy 陷阱**：若用 `if best:` 判断"是否命中"，`best = 0`（即答案 `"000"`）会被误判为未命中；必须用 `best < 0` 显式比较。
3. **窗口越界**：`i` 上限为 $n-3$（含）。`range(len(num) - 2)` 恰好给出 $0..n-3$；C++ 写 `i + 2 < n` 防无符号下溢。
4. **返回类型是字符串**：应返回 `"777"` 而非 `777`；用重复构造（`string(3, c)` / `str * 3`），不要只返回单个字符。
5. **n = 3**：只有一个窗口，整个串要么三字符全同（返回它），要么返回 `""`。
6. **字符与数值**：`num[i]` 是字符，数字字符的 ASCII 序与数值序一致（`'0' < '9'`），直接比较字符也正确；但构造返回串时记得做 `'0' + best` / `int(num[i])` 的转换。
