# LeetCode 检查是否有合法括号字符串路径 题解

## 1. 题目概述

- **标题 / 题号**：检查是否有合法括号字符串路径（#2267，hard）
- **链接**：https://leetcode.cn/problems/check-if-there-is-a-valid-parentheses-string-path/
- **来源**：LeetCode 第 292 场周赛 Q4
- **难度**：困难
- **标签**：数组、动态规划、矩阵、括号序列、状态压缩（bitset）

**题意**：给定 $m \times n$ 的括号网格 `grid`（每格为 `'('` 或 `')'`）。一条**合法括号路径**需同时满足：从左上角 $(0,0)$ 出发、到右下角 $(m-1,n-1)$ 结束、每步只能向**右**或向**下**移动，且路径经过的格子按顺序拼出的字符串是**合法括号串**（即 `()`、合法串的连接、或 `(合法串)`）。问是否存在这样的路径，存在返回 `true`，否则返回 `false`。

**约束**：

- $1 \le m, n \le 100$
- `grid[i][j]` 是 `'('` 或 `')'`

> 💡 本题在本仓库另有[每日题解 2267](../../solution/2201-2300/2267_检查是否有合法括号字符串路径.md)：以「BFS + 三剪枝」为主线，附 DFS 记忆化与面试问答。本篇按**周赛复盘视角**展开，主线换成**行序逐格递推 + bitset 压位**（赛场上最稳最快的写法），并补上引理-定理化的严格证明（无后效性、剪枝安全性、DP 不变式）与赛场易错清单，两篇互为印证。

## 2. 示例

**示例 1**

```text
输入：grid = [["(","(","("],[")","(",")"],["(","(",")"],["(","(",")"]]
输出：true
解释：路径「右→右→下→下→下」拼出 "((()))"，
      路径「下→右→下→右→下」拼出 "()(())"，两条均合法。
```

**示例 2**

```text
输入：grid = [[")",")"],["(","("]]
输出：false
解释：仅有的两条路径拼出 "))(" 与 ")(("，均不合法。
```

**示例 3**（自构造，覆盖奇偶剪枝）

```text
输入：grid = [["(","("],[")",")"]]
输出：false
解释：m + n = 4 为偶数 → 路径长度 m+n−1 = 3 为奇数，
      而合法括号串长度必为偶数，无需任何搜索即可判定 false。
```

## 3. 解题思路

### 3.1 暴力思路：枚举全部路径

从 $(0,0)$ 出发每步「右/下」二选一，枚举全部 $\binom{m+n-2}{m-1}$ 条路径（$m=n=100$ 时约 $10^{58}$ 条），逐条拼串、用计数法校验合法性，每条校验 $O(m+n)$——天文数字，必然超时。但注意：**决定后续能否合法的只有「当前位置」和「已读括号的平衡程度」**，与具体怎么走到这里无关，存在海量重复子问题——这正是折叠成状态、做可达性 DP 的信号。

### 3.2 核心观察：balance 折叠 + 三剪枝

![核心观察：网格 + balance 走廊，状态 (i, j, bal)](images/2267_contest_state_concept.svg)

**观察一（长度固定，奇偶即判）**：只能右/下，从 $(0,0)$ 到 $(m-1,n-1)$ 必走 $m-1$ 步下、$n-1$ 步右，路径**恰好**含 $m+n-1$ 个格子。合法括号串长度必为偶数，故 $m+n-1$ 必偶 $\Leftrightarrow$ **$m+n$ 必为奇**；否则直接 `false`（示例 3）。

**观察二（balance 一维判定）**：设走到某格时已读 `(` 数为 $a$、`)` 数为 $b$，记 $\text{bal} = a - b$。则拼出的串合法 $\Leftrightarrow$ **任意时刻 $\text{bal} \ge 0$（下界）且到终点时 $\text{bal} = 0$（归零）**。由此立刻得到三个 $O(1)$ 必要条件：

1. $m+n$ 为奇（长度为偶）；
2. 首格必为 `(`（否则第一步 $\text{bal}=-1<0$，即示例 2）；
3. 末格必为 `)`（否则最后一步 $\text{bal}$ 从 $\ge 1$ 变成 $\ge 2$，或从 $0$ 变 $1$，总之归不了零）。

**观察三（状态折叠 + 平衡走廊）**：由引理 2（见 §5），同一格以相同 balance 到达的所有路径**前途完全相同**，可合并为一个状态 $(i,j,\text{bal})$。且 bal 天然被夹在**走廊**里：设 $(i,j)$ 之后还剩 $\text{rem} = (m-1-i)+(n-1-j)$ 个格子，则

$$0 \le \text{bal} \le \text{rem}$$

上界的含义：即使后面全是 `)`，bal 每格也只能降 1；要终点归零必须 $\text{bal} \le \text{rem}$。这条**上界剪枝**提前毙掉「`(` 堆太多回不来」的死分支（如全 `(` 网格几乎一路被剪光）。走廊随行进逐渐收窄，到终点只剩 bal $=0$ 一个出口——「能到终点」与「存在合法路径」合二为一。

### 3.3 算法流程：行序逐格递推 + bitset 压位

![算法流程：三剪枝 → 行序递推（bitset）→ 终点判 bit0](images/2267_contest_dp_flow.svg)

把每格「可达的 balance 集合」压成一个**位串** `dp[i][j]`：第 $b$ 位为 1 $\Leftrightarrow$ 存在路径以 balance $=b$ 到达 $(i,j)$。转移只需三步位运算：

1. **汇入**：`frm = dp[i-1][j] | dp[i][j-1]`（只能从上、从左来）；
2. **移位**：新格是 `(` 则 `cur = frm << 1`（全体 bal $+1$）；是 `)` 则 `cur = frm >> 1`（全体 bal $-1$，**bit0 自动丢弃**——这正是下界剪枝，bal $=0$ 再遇 `)` 变 $-1$ 的分支被无声删除）；
3. **掩码**：`cur &= (1 << (rem+1)) - 1`（上界剪枝，只留 bal $\le$ rem）。

行序遍历天然满足「先算上、左」的拓扑序。最终答案即 `dp[m-1][n-1]` 的 **bit0**：终点处 rem $=0$，能存活到 bit0 的只有 bal $=0$。

### 3.4 示例演算

![示例演算：两条合法路径的 balance 逐步走查](images/2267_contest_walkthrough.svg)

**示例 1**（$4\times 3$，$m+n=7$ 奇，首 `(` 末 `)`，三剪枝放行）：路径 A「右右下下下」的 bal 序列为 $1,2,3,2,1,0$，路径 B「下右下右下」为 $1,0,1,2,1,0$——两条都全程 $\ge 0$ 且终点归零（B 在第 2 步**贴到 0** 是允许的，只是不能穿到 0 以下），返回 `true`。**示例 2**：首格即 `)`，$O(1)$ 出局。**示例 3**：$m+n$ 为偶，$O(1)$ 出局。

## 4. 算法细节

1. **遍历顺序**：行序（先外层 $i$ 后内层 $j$）即可，因为 $(i,j)$ 的入邻只有 $(i-1,j)$ 与 $(i,j-1)$，均先于它被计算；按对角线 $i+j$ 递增序遍历同样正确。
2. **bitset 宽度**：bal $\le m+n-1 \le 199$，C++ 用 `bitset<200>`（内部约 4 个 64 位字）；**绝不能用 `uint64_t`**（bal 可达 199 > 63，高位会被悄悄截掉，WA 而非 RE，极难排查）。Python 大整数天然支持任意宽度。
3. **两个移位的语义**：`<<1` 超出宽度的位自动丢弃——由于宽度 200 > 199 $\ge$ bal 上界，被丢弃的位对应物理不可能的状态，无害；`>>1` 丢 bit0 是下界剪枝的**唯一**实现，朴素写法必须显式判 $nb \ge 0$。
4. **上界掩码**：$\text{rem} = (m-1-i)+(n-1-j)$，掩码 $(1 \ll (\text{rem}+1)) - 1$ 即低 rem+1 位全 1。注意它是**常数优化而非正确性必需**：漏掉时死状态到终点也变不成 0（每格 bal 至多变 $\pm 1$，撑不回 0），只是位串变脏、常数变大。
5. **起点初始化**：`dp[0][0] = bit 1`（首格必 `(`，起步 bal $=1$）；初始化成 bit 0 是典型笔误。
6. **跳过起点**：行序循环里 $(0,0)$ 必须 `continue`，否则空 `frm` 会把 `dp[0][0]` 覆盖成 0，后续全线熄灭。
7. **朴素等价写法**：把位串换成 `bool vis[m][n][m+n]` 或每格一个 `set<int>`，逻辑完全同构，复杂度 $O(mn(m+n))$；bitset 版把它除以机器字长 $w$，再快一个量级。
8. **滚动数组**：只保留上一行即可，空间从 $O(mn\cdot(m+n)/w)$ 降到 $O(n\cdot(m+n)/w)$；本题 $100\times100$ 无需滚动。
9. **提前出局**（可选）：若某行所有 `dp` 全为 0，可直接返回 `false`。

## 5. 正确性证明

**引理 1（balance 判定）**：设串 $s$ 长为偶数，定义 $\text{bal}(t) = \sum_{p \le t} \delta(s_p)$，其中 $\delta(\texttt{(}) = 1$、$\delta(\texttt{)}) = -1$。则 $s$ 合法 $\Leftrightarrow$ (a) 对一切 $1 \le t \le |s|$ 有 $\text{bal}(t) \ge 0$；(b) $\text{bal}(|s|) = 0$。

**证明**：($\Rightarrow$) 对合法结构归纳：`()` 显然满足 (a)(b)；$s = AB$ 时拼接串的 bal 是 $A$、$B$ 两段 bal 之和，两段各自非负且和为零，故整体满足；$s = (A)$ 时 bal 序列是「$+1$、$A$ 的序列整体抬升 1、$-1$」，全程 $\ge 0$ 且归零。($\Leftarrow$) 对长度归纳：设 $s$ 满足 (a)(b) 且非空，取**最小**的 $t$ 使 $\text{bal}(t) = 0$（$t = |s|$ 保证存在）。则 $s[1..t]$ 的每个真前缀 bal $> 0$，且 $\text{bal}(1) = +1$（为 $-1$ 则违反 (a)），故 $s[1] = \texttt{(}$、$s[t] = \texttt{)}$，$s[1..t] = (A)$，其中 $A$ 的前缀 bal $= s$ 的前缀 bal $- 1 \ge 0$ 且归零，由归纳假设 $A$ 合法；剩余 $s[t{+}1..]$ 全程非负且归零，同理合法。故 $s = (A)B$ 合法。∎

**引理 2（无后效性）**：设 $P_1, P_2$ 是两条从 $(0,0)$ 到 $(i,j)$ 的（右/下）路径，读出的 balance 同为 $b$。则对任一从 $(i,j)$ 到 $(m-1,n-1)$ 的后缀格序列 $Q$，$P_1 + Q$ 与 $P_2 + Q$ 同时合法或不合法。

**证明**：完整串任意前缀的 bal $= b +$（$Q$ 对应前缀的平衡增量），终点 bal $= b + Q$ 的总增量——两个量都只依赖 $b$ 与 $Q$，与取 $P_1$ 还是 $P_2$ 无关。故引理 1 的判定条件 (a)(b) 对两条完整路径同时成立或同时不成立。∎

**引理 3（剪枝安全性）**：记 $\text{rem}(i,j) = (m-1-i)+(n-1-j)$。(i) bal $< 0$ 的部分路径不能扩展成合法路径；(ii) 在 $(i,j)$ 处 bal $> \text{rem}(i,j)$ 的部分路径不能扩展成合法路径；(iii) 满足 $0 \le \text{bal} \le \text{rem}$ 的状态均被算法保留。

**证明**：(i) 违反引理 1(a)。(ii) 后续每格至多使 bal 降 1，共 rem 格，故终点 bal $\ge b - \text{rem} > 0$，违反引理 1(b)。(iii) `>>1` 只丢 bit0（对应 $-1$，属 (i)），掩码只删 $b > \text{rem}$ 的位（属 (ii)），其余位均保留。故剪枝**恰**删除不可行状态。∎

**定理**：算法返回 `true` $\Leftrightarrow$ 存在合法括号路径。

**证明**：先证 DP 不变式：对每格 $(i,j)$，`dp[i][j]` 的第 $b$ 位为 1 $\Leftrightarrow$ 存在从 $(0,0)$ 到 $(i,j)$ 的部分路径，其 bal $= b$ 且沿途（含自身）满足 $0 \le \text{bal} \le \text{rem}$。对行典序归纳。**基础**：三剪枝通过后首格为 `(`，bal $= 1 \in [0, \text{rem}(0,0)]$，且 $\text{rem}(0,0) + 1 \le 199 < 200$，bit1 置位。**归纳步**：$(i,j)$ 的入邻只有 $(i-1,j)$、$(i,j-1)$，均先被计算。由归纳假设，`frm` 第 $c$ 位为 1 $\Leftrightarrow$ 存在 bal $= c$ 的合规前缀到达某入邻；移位 $\pm 1$ 与该格字符的 $\delta$ 值精确对应；由引理 3(iii)，两个删除操作只删不可行分支、不删可行分支；宽度 200 保证合法 bal（$\le 199$）不会被 `<<1` 溢出丢弃。故不变式在 $(i,j)$ 成立。

由不变式，`dp[m-1][n-1]` 的 bit0 为 1 $\Leftrightarrow$ 存在到达终点、bal $= 0$、全程合规的路径。($\Rightarrow$) 该路径 bal 全程 $\ge 0$ 且终点 $= 0$，由引理 1 拼出的串合法。($\Leftarrow$) 合法路径的每个前缀都满足 $0 \le \text{bal} \le \text{rem}$（引理 1(a) 与引理 3(i)(ii) 的逆否命题），逐格传递使 bit0 被置位，算法返回 `true`。∎

## 6. 复杂度分析

- **时间复杂度**：$O\!\big(\tfrac{mn(m+n)}{w}\big)$，$w$ 为机器字长（64）。每格做一次 200 位 bitset 的「或 + 移位 + 与」，约 $200/64 \approx 3.1$ 个字操作，$m=n=100$ 时总量仅 $10^4 \times 3.1 \approx 3\times10^4$ 字操作，近乎免费；朴素 bool/set 版为 $O(mn(m+n)) \approx 2\times10^6$，同样轻松通过。
- **空间复杂度**：$O\!\big(\tfrac{mn(m+n)}{w}\big)$，即 $10^4$ 个 32 字节的 `bitset<200>` 约 320KB；按行滚动可降至 $O\!\big(\tfrac{n(m+n)}{w}\big)$（仅上一行）。

## 7. 参考代码

### C++（行序逐格递推 + bitset）

```cpp
class Solution {
public:
    bool hasValidPath(vector<vector<char>>& grid) {
        int m = grid.size(), n = grid[0].size();
        if ((m + n) % 2 == 0) return false;                 // 路径长 m+n-1 必为偶
        if (grid[0][0] == ')' || grid[m - 1][n - 1] == '(') return false;

        vector<vector<bitset<200>>> dp(m, vector<bitset<200>>(n));
        dp[0][0][1] = 1;                                     // 起点是 '(' → balance 1
        for (int i = 0; i < m; ++i)
            for (int j = 0; j < n; ++j) {
                if (i == 0 && j == 0) continue;
                bitset<200> frm;
                if (i > 0) frm |= dp[i - 1][j];              // 从上方来
                if (j > 0) frm |= dp[i][j - 1];              // 从左方来
                bitset<200> cur = (grid[i][j] == '(') ? (frm << 1) : (frm >> 1);
                int rem = (m - 1 - i) + (n - 1 - j);         // (i,j) 之后剩余格数
                cur &= ~(bitset<200>().set() << (rem + 1));  // 上界剪枝：只留 bal ≤ rem
                dp[i][j] = cur;
            }
        return dp[m - 1][n - 1][0];                          // 终点 balance 0 可达
    }
};
```

### Python（大整数位串，与 C++ 版逐行对应）

```python
class Solution:
    def hasValidPath(self, grid: List[List[str]]) -> bool:
        m, n = len(grid), len(grid[0])
        if (m + n) % 2 == 0 or grid[0][0] == ')' or grid[m - 1][n - 1] == '(':
            return False
        dp = [[0] * n for _ in range(m)]
        dp[0][0] = 1 << 1                                  # 起点是 '(' → balance 1（bit1）
        for i in range(m):
            for j in range(n):
                if i == 0 and j == 0:
                    continue
                frm = 0
                if i > 0:
                    frm |= dp[i - 1][j]
                if j > 0:
                    frm |= dp[i][j - 1]
                cur = (frm << 1) if grid[i][j] == '(' else (frm >> 1)
                rem = (m - 1 - i) + (n - 1 - j)             # (i,j) 之后剩余格数
                dp[i][j] = cur & ((1 << (rem + 1)) - 1)     # 上界剪枝：只留 bal ≤ rem
        return dp[m - 1][n - 1] & 1 == 1                   # 终点 balance 0 可达
```

**变体：朴素集合版（无位运算，逻辑同构）**

```python
class Solution:
    def hasValidPath(self, grid: List[List[str]]) -> bool:
        m, n = len(grid), len(grid[0])
        if (m + n) % 2 == 0 or grid[0][0] == ')' or grid[m - 1][n - 1] == '(':
            return False
        reach = [[set() for _ in range(n)] for _ in range(m)]
        reach[0][0].add(1)
        for i in range(m):
            for j in range(n):
                if i == 0 and j == 0:
                    continue
                frm = (reach[i - 1][j] if i else set()) | (reach[i][j - 1] if j else set())
                reach[i][j] = {
                    bal + (1 if grid[i][j] == '(' else -1)
                    for bal in frm
                    if 0 <= bal + (1 if grid[i][j] == '(' else -1)
                       <= (m - 1 - i) + (n - 1 - j)
                }
        return 0 in reach[m - 1][n - 1]
```

## 8. 边界情况与易错点

1. **奇偶剪枝别漏**：$m+n$ 为偶直接 `false`，$1\times1$（含 `grid=[["("]]`）、$2\times2$ 等小网格全靠它 $O(1)$ 出局；不漏也不影响正确性，但白跑搜索。
2. **首 `)` / 末 `(` 剪枝**：同理是必要条件；示例 2 即首格 `)`。
3. **C++ 位宽陷阱**：bal 上界 $m+n-1 \le 199$，必须 `bitset<200>`；用 `uint64_t` 做「位串」会**静默截断**高位 balance，输出错误答案而非崩溃，是最隐蔽的 WA 来源。Python 大整数无此问题。
4. **起点初始化 bit1 而非 bit0**：起步 bal 是 1（首格必 `(`），写成 0 则全程平衡差一，答案恰好整体反转一类。
5. **行序循环必须跳过 $(0,0)$**：否则空 `frm` 把 `dp[0][0]` 覆盖成 0，起点熄灭、整张 DP 归零。
6. **`>>1` 丢 bit0 是下界剪枝的全部**：朴素版漏判 $nb \ge 0$ 会把 bal $=-1$ 的状态放进来 → WA；bitset 版「免费」获得这一剪枝，但写朴素版时要自己补。
7. **上界掩码是优化不是正确性**：漏掉只变慢不变错（死状态到终点也变不成 0）；但在 BFS 写法里它还承担「到达终点即合法」的简化（终点 rem $=0$，入队即 bal $=0$），详见每日题解。
8. **记忆化 DFS 版的数组第三维**要开 $m+n$ 而非 $\max(m,n)$——bal 可到 199 而 $\max(m,n)$ 可能只有 100，开小直接越界 RE。
9. **常数意识**：每格 `unordered_set<int>` 的版本比 bitset 慢约一个量级，本题 $100\times100$ 无所谓，网格放大到 $10^3\times10^3$ 就必须位运算。
