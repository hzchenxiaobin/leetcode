# LeetCode 统计只含单一字母的子串 题解

## 1. 题目概述

- **标题 / 题号**：统计只含单一字母的子串（#1180，easy）
- **链接**：https://leetcode.cn/problems/count-substrings-with-only-one-distinct-letter/
- **来源**：LeetCode 第 8 场双周赛 Q1
- **难度**：简单
- **标签**：数学、字符串

**题意**：给定仅由小写字母组成的字符串 `s`，返回其中**只含一种字母**（所有字符都相同）的子串数目。子串按**位置**区分：内容相同但位置不同的子串分别计数。

**约束**：

- $1 \le s.length \le 1000$
- `s` 仅由小写英文字母组成

## 2. 示例

**示例 1**

```text
输入：s = "aaaba"
输出：8
解释：只含单一字母的子串为 "a","a","a","b","a","aa","aa","aaa"，共 8 个。
```

**示例 2**

```text
输入：s = "aaaaaaaaaa"
输出：55
```

> 💡 55 这个数字很「圆」：$10 \times 11 / 2 = 55$——一眼就能猜到这是一道**用等差数列求和**而不是逐个枚举的题。

## 3. 解题思路

### 3.1 暴力思路

枚举全部 $O(n^2)$ 个子串 $s[i..j]$，逐个检查内部字符是否全部相同。检查本身又是 $O(n)$，总计 $O(n^3)$；若改用「向右扩展时维护当前字符」的技巧可把单次检查降到 $O(1)$，总体 $O(n^2)$。$n \le 1000$ 时 $O(n^2) = 10^6$ 也能通过，但完全没必要——字符串里藏着一眼可见的**游程结构**，一次线性扫描就能拿到闭式答案。

### 3.2 核心观察：游程分解，每个游程贡献 $L(L+1)/2$

![核心观察：游程分解，每个游程独立计数](images/bw8_q1_run_decomposition.svg)

把字符串切成若干**极大同字母段**（游程，run）：例如 `"aaaba"` 的游程为 `aaa`（$L=3$）、`b`（$L=1$）、`a`（$L=1$）。

- 一个子串只含单一字母，当且仅当它**整段落在某个游程内部**（一旦跨越边界必然含两种字母）；
- 长度为 $L$ 的游程内部，合法子串就是「任选起点 + 终点」的对数：$1+2+\dots+L = \dfrac{L(L+1)}{2}$。

于是

$$\text{答案} = \sum_{\text{游程}} \frac{L(L+1)}{2}$$

> 💡 实现上甚至不必先显式切出游程：**逐位累加**即可。设 `run` 为「以 $i$ 结尾的游程长度」（$s[i] = s[i-1]$ 时 `run+1`，否则归 1），则 $\sum_i run_i$ 恰好等于 $\sum L(L+1)/2$——因为长度为 $L$ 的游程从左到右贡献 $1, 2, \dots, L$。

### 3.3 算法流程

```text
1. ans = 0, run = 0
2. for i = 0 .. n-1:
3.     run = (i > 0 且 s[i] == s[i-1]) ? run + 1 : 1
4.     ans += run
5. 返回 ans
```

### 3.4 示例演算

![示例演算：逐位累加 run 与两个官方样例](images/bw8_q1_example_walkthrough.svg)

以 `"aaaba"` 走一遍：`run` 依次为 $1,2,3,1,1$，累加得 $1+2+3+1+1 = 8$ ✓。游程视角复核：$3 \times 4/2 + 1 + 1 = 6+1+1 = 8$ ✓。示例 2 是单一游程 $L=10$，直接 $10 \times 11/2 = 55$ ✓。

## 4. 算法细节

1. **游程的两种等价实现**：显式分组（先扫描出所有 $(字母, 长度)$ 再套公式）与逐位累加（一行循环）。后者把「公式求和」折叠进扫描过程，更不容易写错边界。
2. **为什么 $\sum run = \sum L(L+1)/2$**：长度 $L$ 的游程内第 $p$ 个字符（$p$ 从 1 计）结尾的合法子串恰有 $p$ 个（起点可选它前面的 $p$ 个同字母位置），游程内贡献 $\sum_{p=1}^{L} p$。
3. **数据类型**：$n \le 1000$，答案上界 $\dfrac{1000 \times 1001}{2} = 500500$，`int` 绰绰有余。
4. **不需要特判**：$n \ge 1$ 保证循环至少执行一次，`run` 从 0 起步天然正确。

## 5. 正确性证明

**引理 1（刻画）**：子串 $s[i..j]$ 只含单一字母 $\iff$ $[i, j]$ 完整落在某个极大游程内。

**证明**：（⇐）游程内字符全部相同，其子串自然单一字母。（⇒）若子串内字符全部相同，则 $s[i] = s[i+1] = \dots = s[j]$，这 $j-i+1$ 个位置连续同字母，可向两侧扩展到极大游程，$[i,j]$ 含于其中。∎

**引理 2（游程计数）**：长度为 $L$ 的游程内部，合法子串恰有 $\dfrac{L(L+1)}{2}$ 个。

**证明**：合法子串与数对 $(p, q)$（$1 \le p \le q \le L$，起点为游程内第 $p$ 个字符、终点为第 $q$ 个字符）一一对应，故计数为 $\sum_{q=1}^{L} q = \dfrac{L(L+1)}{2}$。不同游程的子串位置不同，互不重复。∎

**定理**：算法返回只含单一字母的子串总数。

**证明**：由引理 1，合法子串按其所在游程划分为互不相交的若干组；由引理 2 每组恰贡献 $L(L+1)/2$；算法累加的 $\sum run$ 与该值相等（第 4 节第 2 点），故总数正确。∎

## 6. 复杂度分析

- **时间**：$O(n)$。一次线性扫描，每步 $O(1)$。
- **空间**：$O(1)$。只维护 `run` 与 `ans` 两个变量。

对照：暴力 $O(n^2)$ / $O(n^3)$ 在 $n \le 1000$ 下虽可过，但本题是「一次扫描 + 等差求和」的标准签到难度。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int countLetters(string s) {
        int n = (int)s.size(), ans = 0, run = 0;
        for (int i = 0; i < n; ++i) {
            run = (i > 0 && s[i] == s[i - 1]) ? run + 1 : 1;  // 以 i 结尾的游程长度
            ans += run;  // 长度 L 的游程共贡献 L(L+1)/2，逐位累加 run 恰为实现
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def countLetters(self, s: str) -> int:
        ans = run = 0
        for i, ch in enumerate(s):
            run = run + 1 if i > 0 and ch == s[i - 1] else 1  # 以 i 结尾的游程长度
            ans += run
        return ans
```

**验证记录**：两份代码均通过官方双示例（8 / 55）；另与「枚举全部子串逐一检查」的 $O(n^3)$ 暴力做了交叉对拍——C++ 3000 组、Python 1000 组随机串（长度 1–60、字母表 1–3），公式与暴力 0 失配；额外验证 `n=1000` 全同字母得 500500、单字符得 1，无溢出。

## 8. 边界情况与易错点

1. **别去重**：相同内容、不同位置的子串要分别计数（示例 1 里 `"a"` 出现 4 次计 4 个）。这是「子串计数」与「本质不同子串」题的本质区别。
2. **`run` 归 1 而不是归 0**：遇到新字母时当前位自己构成长度 1 的游程，`run` 应重置为 1。
3. **公式对单个游程同样成立**：$L=1$ 时贡献 $1$，无需为短游程写分支。
4. **$O(n^2)$ 暴力也能过，但别误写成 $O(n^2)$ 检查**：逐对枚举时若每次重新检查整个子串会退化到 $O(n^3)$，$n=1000$ 时约 $10^9$ 次字符比较，可能超时。
5. **类型与范围**：最大答案 500500，`int` 足够；若把 $n$ 放大到 $10^5$ 级别则需 `long long` / Python 无碍。
