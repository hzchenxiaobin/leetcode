# LeetCode 与目标颜色间的最短距离 题解

## 1. 题目概述

- **标题 / 题号**：与目标颜色间的最短距离（#1182，medium）
- **链接**：https://leetcode.cn/problems/shortest-distance-to-target-color/
- **来源**：LeetCode 第 8 场双周赛 Q3
- **难度**：中等
- **标签**：数组、二分查找、动态规划

**题意**：给定数组 `colors`，元素取值为 $1$、$2$、$3$（三种颜色）。再给一组查询 `queries`，每个查询为 $[index, color]$，求下标 `index` 到**最近的**颜色为 `color` 的元素的距离 $|index - j|$；若整个数组中不存在该颜色，返回 $-1$。

**约束**：

- $1 \le colors.length \le 5 \times 10^4$
- $1 \le colors[i] \le 3$
- $1 \le queries.length \le 5 \times 10^4$
- $0 \le queries[j][0] < colors.length$，$1 \le queries[j][1] \le 3$

> 💡 这是典型的**离线预处理型查询题**：$n, q$ 都是 $5 \times 10^4$，任何「逐查询扫描」的 $O(nq)$ 都会超时，必须先把三种颜色的结构信息压缩出来。

## 2. 示例

**示例 1**

```text
输入：colors = [1,1,2,1,3,2,2,3,3], queries = [[1,3],[2,2],[6,1]]
输出：[3,0,3]
解释：
queries[0]：下标 1 找颜色 3，最近的颜色 3 在下标 4，距离 |4-1| = 3
queries[1]：下标 2 本身就是颜色 2，距离 0
queries[2]：下标 6 找颜色 1，左侧最近的 1 在下标 3，距离 3
```

**示例 2**

```text
输入：colors = [1,2], queries = [[0,3]]
输出：[-1]
解释：数组中不存在颜色 3。
```

## 3. 解题思路

### 3.1 暴力思路

对每个查询从 `index` 出发向左右两侧逐格扩展，直到撞到目标颜色或同时越界，单次最坏 $O(n)$，总计 $O(nq) = 2.5 \times 10^9$——在 $n, q \le 5\times10^4$ 的范围下必然超时。瓶颈在于：**同一种颜色的「到哪里最近」被反复计算**。颜色只有 3 种，把每种颜色的出现位置一次性整理成有序表，查询就能二分。

### 3.2 核心观察：三种颜色各记一张升序下标表，查询 = 找前驱 / 后继

![核心观察：三种颜色各记下标，二分找前驱 / 后继](images/bw8_q3_binary_search_model.svg)

- 扫一遍 `colors`，把下标按颜色分进 `pos[1..3]` 三张表。**下标天然升序**，无需排序。
- 查询 $(i, c)$：最近的 $c$ 只可能是「$\le i$ 的最大出现位置」（**前驱**）或「$\ge i$ 的最小出现位置」（**后继**）——因为 `pos[c]` 有序，比前驱更左、比后继更右的候选都更远。
- 二分（`lower_bound`）定位 $i$ 在 `pos[c]` 中的插入点 `lo`：后继是 `v[lo]`（若存在），前驱是 `v[lo-1]`（若存在），答案取两侧距离的最小值；`pos[c]` 为空则 $-1$。

> 💡 「有序表 + 二分找前驱后继」是「最近 X 问题」的通用模板；本题颜色数只有 3，直接开 3 张表即可，连桶都省了。

### 3.3 算法流程

```text
1. 扫描 colors，构建 pos[1..3]（升序下标表）          O(n)
2. 对每个查询 (i, c)：
3.     v = pos[c]；若 v 为空 → 输出 -1
4.     在 v 中二分找第一个 >= i 的位置 lo              O(log n)
5.     best = +∞
6.     若 lo < |v|：best = min(best, v[lo] - i)        # 后继
7.     若 lo > 0：  best = min(best, i - v[lo-1])       # 前驱
8.     输出 best
```

另一种等价做法是**双向 DP 预处理**：从左到右扫一遍维护 `left[c][i]`（$i$ 及其左侧最近的 $c$），再从右到左维护 `right[c][i]`，查询 $O(1)$。时间总量相同（$O(n+q)$ 查询端更快），空间 $O(3n)$ 略大；二分版省空间、思路更通用，本文以其为主。

### 3.4 示例演算

![示例演算：三个查询逐一二分](images/bw8_q3_example_walkthrough.svg)

`colors = [1,1,2,1,3,2,2,3,3]`：`pos[1] = [0,1,3]`，`pos[2] = [2,5,6]`，`pos[3] = [4,7,8]`。

| 查询 | 二分结果 | 前驱 / 后继 | 答案 |
|------|----------|------------|------|
| $(1, 3)$ | `lo = 0`（4 ≥ 1） | 后继 4 | $4-1 = 3$ |
| $(2, 2)$ | `lo = 0`（命中 2） | 后继即自身 | $0$ |
| $(6, 1)$ | `lo = 3`（越界，无后继） | 前驱 3 | $6-3 = 3$ |

示例 2 中 `pos[3]` 为空，直接 $-1$。

## 4. 算法细节

1. **为什么只要看前驱与后继**：`pos[c]` 升序，任何出现位置要么 $\le$ 前驱（更远），要么 $\ge$ 后继（更远），二者必为全局最近。查询位置自身命中时后继距离为 0，公式无需特判。
2. **二分模板**：手写「第一个 $\ge i$」的左端点二分，或直接用 `std::lower_bound`；注意 `lo == 0` 时无前驱、`lo == |v|` 时无后继的两侧边界。
3. **`-1` 的判定放在二分之前**：`pos[c]` 为空直接短路，避免对空表二分。
4. **数组组织**：`pos` 用 `vector<int> pos[4]` 按 $1..3$ 下标直接寻址，比 `map<int, vector<int>>` 快且省事——颜色值域已知且极小，**值域小的键用数组不用哈希**。

## 5. 正确性证明

**引理 1（最近位置在前驱后继中）**：设 $P = pos[c]$（升序），$i$ 为查询下标，$p = \max\{x \in P : x \le i\}$（前驱，若存在），$q = \min\{x \in P : x \ge i\}$（后继，若存在）。则 $\min_{x \in P} |x - i| = \min\{i - p,\ q - i\}$（仅对存在的一侧取值）。

**证明**：任取 $x \in P$：若 $x \le i$，由 $p$ 的定义 $x \le p$，故 $i - x \ge i - p$；若 $x \ge i$，由 $q$ 的定义 $x \ge q$，故 $x - i \ge q - i$。两种情形都被前驱、后继支配，最小值只在二者处取到。∎

**引理 2（二分正确性）**：「找第一个 $\ge i$ 的位置」的左端点二分在升序表上返回 $q$ 所在下标 `lo`；于是 `v[lo]`（若 `lo < |v|`）是后继，`v[lo-1]`（若 `lo > 0`）是前驱。

**证明**：二分循环维护不变量「`v[0..lo)` 全部 $< i$，`v[hi..]` 全部 $\ge i$」，终止时 `lo == hi` 即分界点；两侧各取一个元素恰为 $p, q$。∎

**定理**：算法对每个查询返回正确的最短距离，不存在的颜色返回 $-1$。

**证明**：`pos[c]` 为空时数组无颜色 $c$，返回 $-1$ 正确；否则由引理 1、2，前驱后继被准确定位并取最小距离。∎

## 6. 复杂度分析

- **时间**：预处理 $O(n)$；每个查询一次二分 $O(\log n)$，总计 $O(n + q \log n)$。$n, q \le 5\times10^4$ 时约 $5\times10^4 \times 16$ 次比较，轻松通过。
- **空间**：$O(n)$ 存三张下标表（双向 DP 版需 $O(3n)$，查询降为 $O(1)$，总量同为 $O(n+q)$）。

对照：暴力 $O(nq) = 2.5 \times 10^9$ 超时；二分版 / DP 版把「重复的近邻搜索」压缩成了「一次有序结构上的定位」。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> shortestDistanceColor(vector<int>& colors, vector<vector<int>>& queries) {
        vector<int> pos[4];                            // pos[c]：颜色 c 的出现下标，天然升序
        for (int i = 0; i < (int)colors.size(); ++i)
            pos[colors[i]].push_back(i);

        vector<int> ans;
        ans.reserve(queries.size());
        for (auto& q : queries) {
            int i = q[0], c = q[1];
            const vector<int>& v = pos[c];
            if (v.empty()) {                           // 该颜色未出现
                ans.push_back(-1);
                continue;
            }
            int lo = 0, hi = (int)v.size();            // 二分：第一个 >= i 的下标
            while (lo < hi) {
                int mid = lo + (hi - lo) / 2;
                if (v[mid] < i) lo = mid + 1;
                else hi = mid;
            }
            int best = INT_MAX;
            if (lo < (int)v.size()) best = min(best, v[lo] - i);     // 后继
            if (lo > 0)             best = min(best, i - v[lo - 1]); // 前驱
            ans.push_back(best);
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def shortestDistanceColor(self, colors: list[int], queries: list[list[int]]) -> list[int]:
        pos = [[], [], [], []]                         # pos[c]：颜色 c 的出现下标
        for i, c in enumerate(colors):
            pos[c].append(i)
        ans = []
        for i, c in queries:
            v = pos[c]
            if not v:                                  # 该颜色未出现
                ans.append(-1)
                continue
            lo, hi = 0, len(v)                         # 二分：第一个 >= i 的下标
            while lo < hi:
                mid = (lo + hi) // 2
                if v[mid] < i:
                    lo = mid + 1
                else:
                    hi = mid
            best = len(colors)
            if lo < len(v):
                best = min(best, v[lo] - i)            # 后继
            if lo > 0:
                best = min(best, i - v[lo - 1])        # 前驱
            ans.append(best)
        return ans
```

**验证记录**：两份代码均通过官方双样例（`[3,0,3]` 与 `[-1]`）；另与「每个查询向两侧线性扫描」的暴力交叉对拍——C++ 2000 组、Python 1000 组随机数据（$n \le 80$、颜色数 1–3 故意让某些颜色缺失、随机查询含命中自身），0 失配；边界测试单元素数组查询自身颜色与缺失颜色分别为 `0`、`-1`。

## 8. 边界情况与易错点

1. **颜色整体缺失**：判空放在二分之前，返回 $-1$（示例 2）。
2. **查询位置自身就是目标颜色**：后继即自身、距离 0——二分命中后公式自然覆盖，不要写 `if v[lo] == i` 的特判分支。
3. **二分边界**：`lo == 0`（无前驱）与 `lo == |v|`（无后继）必须分别保护，漏一侧会在端点查询时读越界。
4. **初始值**：`best` 初始化为足够大（或 `INT_MAX`），两侧 `min` 之后再输出；若写成「先取后继再判空」容易在无后继时留下垃圾值。
5. **下标语义**：`queries[j][0]` 是 0 基下标、`queries[j][1]` 是 1..3 的颜色值，别混用。
6. **双向 DP 版的坑**：`left/right` 表初始化要用 $\mp\infty$ 之外的哨兵并区分「不存在」，实现细节比二分版多，容易写出「左侧不存在却取了 0」的错。
