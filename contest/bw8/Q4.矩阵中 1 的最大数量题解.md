# LeetCode 矩阵中 1 的最大数量 题解

## 1. 题目概述

- **标题 / 题号**：矩阵中 1 的最大数量（#1183，hard）
- **链接**：https://leetcode.cn/problems/maximum-number-of-ones/
- **来源**：LeetCode 第 8 场双周赛 Q4
- **难度**：困难
- **标签**：贪心、数学、排序、堆（优先队列）

**题意**：构造一个 `width × height` 的 0/1 矩阵 $M$，要求**任意** `sideLength × sideLength` 的正方形子矩阵中 1 的个数都不超过 `maxOnes`。返回整个矩阵中 1 的个数的最大值。

**约束**：

- $1 \le width, height \le 100$
- $1 \le sideLength \le width, height$
- $0 \le maxOnes \le sideLength^2$

> 💡 乍看像网格 DP 或状压搜索，但「任意子阵 1 数受限」的约束里藏着一个优美的**模运算余数类**结构：按 $(i \bmod s,\ j \bmod s)$ 给格子分类后，任何子阵都恰好「每类取一格」。困难题的难点不在代码——最终只有短短几行——而在把「为什么贪心取最大的 `maxOnes` 个类整类填满是最优」**证明清楚**。

## 2. 示例

**示例 1**

```text
输入：width = 3, height = 3, sideLength = 2, maxOnes = 1
输出：4
解释：任意 2×2 子阵的 1 不超过 1 个。最优方案（4 个 1）：
[1,0,1]
[0,0,0]
[1,0,1]
```

**示例 2**

```text
输入：width = 3, height = 3, sideLength = 2, maxOnes = 2
输出：6
解释：
[1,0,1]
[1,0,1]
[1,0,1]
```

## 3. 解题思路

### 3.1 暴力思路：枚举每格的 0/1

矩阵至多 $100 \times 100 = 10^4$ 个格子，每格独立取 0/1 有 $2^{10^4}$ 种组合，逐一检查所有子阵更是雪上加霜——指数爆炸，完全不可行。即便只对小规模（$W, H \le 4$，$2^{16} = 65536$ 种）穷举，也只是**对拍工具**而非解法。但这个穷举在本题里有特殊价值：它让我们在小例子里**猜出公式**（见 3.3），再回头严格证明——这正是本题的比赛复盘路径。

### 3.2 核心观察：余数类划分，「边角放 1」

![余数类划分：按 (i mod s, j mod s) 涂色](images/bw8_q4_residue_classes.svg)

记 $s = sideLength$。把每个格子 $(i, j)$ 按**余数对** $(i \bmod s,\ j \bmod s)$ 分类，共 $s^2$ 个**余数类**。行方向余数为 $r$ 的行有

$$R_r = \left\lfloor \frac{H-1-r}{s} \right\rfloor + 1 = \left\lceil \frac{H-r}{s} \right\rceil \text{ 行}$$

列方向同理有 $C_c$ 列。于是余数类 $(r, c)$ 的大小恰为 $z_{rc} = R_r \cdot C_c$（$H = height$，$W = width$）。

![关键性质：任意 s×s 子阵恰取每个余数类各一格](images/bw8_q4_window_transversal.svg)

三个观察把问题彻底改写：

- **观察一（穿越性）**：任意 $s \times s$ 子阵覆盖连续 $s$ 行、连续 $s$ 列，各是模 $s$ 的完全剩余系——因此**恰含每个余数类各一格**。
- **观察二（同类互斥）**：同类两格的行号差（或列号差）是 $s$ 的非零倍数，永远不可能同处一个 $s \times s$ 子阵。
- **观察三（整类填满 ⇒ 每窗 +1）**：把某余数类的**全部**格子填 1，由观察一每个子阵恰多 1 个 1。选 $\le maxOnes$ 个类整类填满，每个子阵恰有「类数」个 1，合法且总 1 数 = 所选类大小之和。

于是**答案的下界**是：把 $s^2$ 个类大小降序排列，**取前 $maxOnes$ 个求和**。余数小的类（$r, c$ 靠近 0）行列都更密、类更大——「**边角放 1**」的直觉正是「优先填满贴着边角对齐的那张周期网格」。

> ⚠️ **「整类填满不劣于部分填充」并不显然**。朴素论证会说「同类格子互不冲突，把没填满的类补满只会更好」，但补满一个类会让**所有**窗口的该类计数从「部分为 1」变成「全为 1」，可能直接爆掉预算。反例：$W=H=3$、$s=2$、$maxOnes=2$ 时，$M = \{(0,0),(0,1),(1,2),(2,0),(2,1)\}$（5 个 1）合法——每个 $2\times2$ 窗口恰 2 个 1——却**触碰了 3 个余数类**（多于 $maxOnes$）。上界需要真正的证明，见第 5 节的密度论证。

### 3.3 算法流程（含小规模枚举对拍推导）

比赛中的实际发现路径值得记录：先手算 $3\times3, s=2$ 得 $4/6$，再用 $W,H \le 4$ 的 $2^{WH}$ 穷举对拍猜测「答案 = 类大小前 $maxOnes$ 大之和」，最后补证明。最终算法只剩四步：

```text
1. 对 r = 0 .. s-1 算 R_r = (H-1-r)/s + 1（整数除法）
2. 对 c = 0 .. s-1 算 C_c = (W-1-c)/s + 1
3. 生成全部 s² 个乘积 z_rc = R_r × C_c，降序排序
4. 答案 = 前 maxOnes 个 z 之和
```

> 💡 排序可换成「大小为 maxOnes 的小顶堆」求 Top-$maxOnes$（呼应题目标签里的「堆」），复杂度 $O(s^2 \log maxOnes)$；$s \le 100$ 时两者都瞬开。

### 3.4 示例演算

![贪心选取：类大小降序取前 maxOnes 个求和](images/bw8_q4_topk_selection.svg)

$W=H=3,\ s=2$：$R_0 = C_0 = 2$（行 0、2 / 列 0、2），$R_1 = C_1 = 1$。四个类大小：

| 余数类 | 行数 × 列数 | 大小 | 格子 |
|--------|------------|------|------|
| $(0,0)$ | $2 \times 2$ | **4** | $(0,0),(0,2),(2,0),(2,2)$ |
| $(0,1)$ | $2 \times 1$ | **2** | $(0,1),(2,1)$ |
| $(1,0)$ | $1 \times 2$ | **2** | $(1,0),(1,2)$ |
| $(1,1)$ | $1 \times 1$ | **1** | $(1,1)$ |

降序为 $[4,2,2,1]$：$maxOnes=1$ 取 $4$（四角），$maxOnes=2$ 取 $4+2=6$（官方两例）✓。

非对称小例复核：$W=2, H=3, s=2, k=1$：$R_0=2, R_1=1$，$C_0=C_1=1$，类大小 $[2,2,1,1]$，公式给 $2$。手验：$2\times2$ 窗口分别覆盖行 $\{0,1\}$、$\{1,2\}$，各含 $\le 1$ 个 1，总 1 数确被压到 2 ✓。

## 4. 算法细节

1. **$R_r$ 公式**：余数为 $r$ 的行为 $r, r+s, r+2s, \dots$，要求 $< H$，最大 $k$ 满足 $r + ks \le H-1$，共 $k+1 = \lfloor (H-1-r)/s \rfloor + 1$ 行。约束 $s \le \min(W,H)$ 保证 $r < s \le H$，分子 $\ge 0$，**公式恒正、无需特判**。
2. **行用 $H$、列用 $W$，别接反**：$z_{rc} = R_r(H) \cdot C_c(W)$。官方样例 $W=H$ 是正方形看不出错；用上面 $W=2,H=3$ 的非对称例子即可自检。
3. **取前 $maxOnes$ 个不会越界**：约束 $maxOnes \le s^2$ 恰好等于类的总数，`cnt` 数组长度就是 $s^2$。
4. **数值范围**：$z_{rc} \le 100 \times 100$，总和 $\le W \cdot H = 10^4$，`int` 足够。
5. **无需构造矩阵**：答案只依赖类大小分布，与具体填法无关——这是余数类结构带来的「降维」：复杂度与 $W \times H$ 无关，只随 $s$ 增长。

## 5. 正确性证明

记 $H = height$，$W = width$，$s = sideLength$，$k = maxOnes$；$R_r$、$C_c$、$z_{rc} = R_r C_c$ 如前；**窗口**指左上角为 $(a,b)$（$0 \le a \le H-s$，$0 \le b \le W-s$）的 $s \times s$ 子阵，记作 $W(a,b)$；合法矩阵指每个窗口的 1 数 $\le k$。

**引理 1（穿越性）**：每个窗口恰含每个余数类各一格。

**证明**：窗口覆盖行 $\{a, \dots, a+s-1\}$，这是模 $s$ 的完全剩余系——每个余数 $r$ 恰出现一次；列同理。故窗口内 $s^2$ 格的余数对两两不同，恰覆盖全部 $s^2$ 个类各一次。∎

**引理 2（可达性，下界）**：任取至多 $k$ 个余数类 $T$，把这些类的**全部**格子置 1，得到合法矩阵，1 数为 $\sum_{K \in T} z_K$。

**证明**：由引理 1，每个窗口恰含每类一格，故每个窗口的 1 数 $= |T| \le k$，合法；总 1 数即各类大小之和。特别地，取**前 $k$ 大**的类，答案 $\ge z_{(1)} + \dots + z_{(k)}$。∎

上界是本题的真正难点。朴素做法是把最优解「调整」成整类填满的形态，但 3.2 的反例显示合法解可以触碰多于 $k$ 个类，简单的逐类交换论证失效。我们改用**密度论证**：给每个格子配一个「密度权重」$1/z_{\text{class}}$，先证所有合法矩阵的**加权 1 数** $\le k$（引理 4），再用重排把加权和不放大成原始计数（引理 5）。

**引理 3（一维覆盖权重）**：设 $m \ge s \ge 1$（行向 $m=H$、列向 $m=W$ 各取一次），记 $N_r = |\{i \in [0,m) : i \bmod s = r\}|$，$q = \lfloor m/s \rfloor$，$t = m \bmod s$。在窗口起点 $a \in [0, m-s]$ 上定义权重 $\alpha$：

- $t = 0$：$\alpha_{js} = 1/q$（$0 \le j \le q-1$），其余为 $0$；
- $t > 0$：$\alpha_{js} = \dfrac{q-j}{q(q+1)}$，$\alpha_{t+js} = \dfrac{j+1}{q(q+1)}$（均取 $0 \le j \le q-1$），其余为 $0$。

则（i）$\alpha \ge 0$ 且 $\sum_a \alpha_a = 1$；（ii）对每个位置 $i \in [0,m)$，覆盖和 $\sum_{a:\ i \in [a, a+s-1]} \alpha_a = 1 / N_{i \bmod s}$（求和范围天然截断在 $[0, m-s]$）。

**证明**：非负性由 $j \le q-1$ 直接可见；$\sum \alpha$ 在 $t=0$ 时为 $q \cdot \frac1q = 1$，在 $t>0$ 时为 $\frac{\sum_j (q-j) + \sum_j (j+1)}{q(q+1)} = \frac{q(q+1)/2 + q(q+1)/2}{q(q+1)} = 1$。

（ii）记位置 $i$ 的覆盖起点集 $A(i) = [\max(0, i-s+1),\ \min(i, m-s)]$，写 $i = ks + \sigma$。核心事实：**任意连续 $s$ 个整数中，$s$ 的倍数与 $\equiv t \pmod s$ 的数各恰有一个**。注意 $N_\sigma = q+1$（$\sigma < t$）或 $q$（$\sigma \ge t$）。

- $t = 0$：此时 $N_r \equiv q$，权重全在 $s$ 的倍数上，而 $A(i)$ 是长为 $s$ 的区间的截断，截断只会少不会多——完整窗口恰含一个倍数；左截断 $[0, i]$（$i \le s-2$）只含倍数 $0$；右截断 $[i-s+1, m-s]$（$i > m-s$，此时 $k$ 落在 $[1, q-1]$ 或退化为 $\{0\}$）恰含 $(q-1)s$ 或 $0$。三种情形覆盖和均为 $1/q = 1/N_\sigma$。
- $t > 0$，分四种位置情形：
  1. **完整窗口**（$s-1 \le i \le m-s$，$A = [i-s+1, i]$）：恰含倍数 $ks$ 与一个 $\equiv t$ 起点。若 $\sigma \ge t$，后者为 $t+ks$，覆盖和 $= \frac{(q-k)+(k+1)}{q(q+1)} = \frac1q = 1/N_\sigma$；若 $\sigma < t$，后者为 $t+(k-1)s$（$\sigma < t$ 保证它落在窗口内），覆盖和 $= \frac{(q-k)+k}{q(q+1)} = \frac{1}{q+1} = 1/N_\sigma$。
  2. **左截断**（$i \le s-2$，$A = [0, \min(i, m-s)]$）：含倍数 $0$（权 $\frac{q}{q(q+1)}$）；是否含 $\equiv t$ 起点（即 $t$ 本身）取决于 $t \le \min(i, m-s)$，恰等价于 $\sigma = i \ge t$。故覆盖和为 $\frac{1}{q+1} + [\sigma \ge t] \cdot \frac{1}{q(q+1)}$，两种取值 $\frac{1}{q+1}, \frac1q$ 分别匹配 $1/N_\sigma$。
  3. **右截断且 $\sigma < t$**（$i$ 在最后一个不完整块，$k=q$）：$A = [(q-1)s+\sigma+1,\ (q-1)s+t]$ 不含任何倍数、恰含 $\equiv t$ 的 $m-s$，覆盖和 $= \frac{q}{q(q+1)} = \frac{1}{q+1} = 1/N_\sigma$。
  4. **右截断且 $\sigma > t$**（由 $i > m-s$ 与 $i \le m-1$ 可解出 $k = q-1$）：$A = [(q-2)s+\sigma+1,\ (q-1)s+t]$ 恰含倍数 $(q-1)s$ 与 $m-s$，覆盖和 $= \frac{1}{q(q+1)} + \frac{1}{q+1} = \frac1q = 1/N_\sigma$。（$q=1$ 时两种右截断合并为 $A = [0, t]$，含 $0$ 与 $t$，覆盖和 $= 1/q$，且 $\sigma > t$ 一致。）

全部情形验证完毕，得（ii）。∎

**引理 4（密度不等式）**：对任意合法矩阵 $M$：

$$\sum_{(i,j) \in M} \frac{1}{R_{i \bmod s} \cdot C_{j \bmod s}} \le k$$

**证明**：取行方向（$m=H$）的 $\alpha$ 与列方向（$m=W$）的 $\beta$（引理 3），令窗口位权 $\lambda_{(a,b)} = \alpha_a \beta_b \ge 0$，则 $\sum_{(a,b)} \lambda_{(a,b)} = \big(\sum_a \alpha_a\big)\big(\sum_b \beta_b\big) = 1$。由引理 3(ii) 的**乘积结构**：

$$\sum_{(a,b) \ni (i,j)} \lambda_{(a,b)} = \Big(\sum_{a:\, i \in [a,a+s-1]} \alpha_a\Big)\Big(\sum_{b:\, j \in [b,b+s-1]} \beta_b\Big) = \frac{1}{R_{i \bmod s}} \cdot \frac{1}{C_{j \bmod s}}$$

于是（第二个等号交换求和次序，每个「格子 × 覆盖它的窗口」配对恰被两侧各计一次）：

$$\sum_{(i,j) \in M} \frac{1}{R C} = \sum_{(i,j) \in M} \sum_{(a,b) \ni (i,j)} \lambda_{(a,b)} = \sum_{(a,b)} \lambda_{(a,b)} \cdot \big|M \cap W(a,b)\big| \le k \sum_{(a,b)} \lambda_{(a,b)} = k \qquad \blacksquare$$

**引理 5（加权重排）**：把 $s^2$ 个类大小降序记为 $z_{(1)} \ge \dots \ge z_{(s^2)}$。对任意满足 $0 \le \rho_K \le 1$、$\sum_K \rho_K \le k$ 的系数，有 $\sum_K \rho_K z_K \le \sum_{t=1}^{k} z_{(t)}$。

**证明**：按 $z$ 降序排列后，若存在 $i < j$ 使 $\rho_i < 1$ 且 $\rho_j > 0$，把质量 $\delta = \min(1-\rho_i,\ \rho_j)$ 从 $j$ 移到 $i$，目标值变化 $\delta(z_i - z_j) \ge 0$。重复交换至无法进行：正质量集中在前缀 $[1, m]$ 且 $\rho_1 = \dots = \rho_{m-1} = 1$。此时 $\sum \rho = (m-1) + \rho_m \le k$ 强迫 $m \le k$，故目标值 $\le \sum_{i \le m} z_i \le \sum_{i \le k} z_{(i)}$（降序序列的前缀和不减、非负项）。∎

**定理**：答案 $= z_{(1)} + z_{(2)} + \dots + z_{(k)}$（前 $k$ 大类大小之和）。

**证明**：（$\ge$）引理 2 取前 $k$ 大的类整类填满。（$\le$）设 $M$ 为任意合法矩阵，令 $\rho_K = |M \cap K| / z_K \in [0, 1]$。诸类构成格子的划分，故 $|M| = \sum_K \rho_K z_K$；而 $\sum_K \rho_K = \sum_{(i,j) \in M} 1/(R_{i\bmod s} C_{j \bmod s}) \le k$（引理 4）。由引理 5，$|M| \le \sum_{t=1}^k z_{(t)}$。∎

> 💡 回看 3.2 的反例：$M = \{(0,0),(0,1),(1,2),(2,0),(2,1)\}$ 的密度恰为 $\frac{2}{4} + \frac{2}{2} + \frac{1}{2} = 2 = k$，**恰好取等**——密度不等式是紧的；而 $|M| = 5 \le 6 = z_{(1)} + z_{(2)}$ 也印证了上界。密度论证绕开了「触碰类数」这个错误抓手，把「每个窗口 $\le k$」这个真正的约束直接换算成「加权计数 $\le k$」。

## 6. 复杂度分析

- **时间**：枚举 $s^2$ 个类 $O(s^2)$，排序 $O(s^2 \log s)$——总 $O(s^2 \log s)$。$s \le 100$ 时约 $10^4 \log 10^4 \approx 1.3 \times 10^5$ 次比较，毫秒级。
- **空间**：$O(s^2)$ 存类大小数组。

注意复杂度**与 $W \times H$ 无关**：约束的全部信息被压缩进了 $s^2$ 个类大小。这是「洞察降维」型困难题的典型红利。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maximumNumberOfOnes(int width, int height, int sideLength, int maxOnes) {
        int s = sideLength;
        vector<int> cnt;
        cnt.reserve(s * s);
        for (int r = 0; r < s; ++r) {
            int rows = (height - 1 - r) / s + 1;        // 行号 ≡ r (mod s) 的行数
            for (int c = 0; c < s; ++c) {
                int cols = (width - 1 - c) / s + 1;     // 列号 ≡ c (mod s) 的列数
                cnt.push_back(rows * cols);             // 余数类 (r, c) 的格子数
            }
        }
        sort(cnt.rbegin(), cnt.rend());                 // 降序取前 maxOnes 个
        int ans = 0;
        for (int i = 0; i < maxOnes; ++i) ans += cnt[i];
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maximumNumberOfOnes(self, width: int, height: int,
                            sideLength: int, maxOnes: int) -> int:
        cnt = []
        for r in range(sideLength):
            rows = (height - 1 - r) // sideLength + 1   # 行号 ≡ r (mod s) 的行数
            for c in range(sideLength):
                cols = (width - 1 - c) // sideLength + 1  # 列号 ≡ c (mod s) 的列数
                cnt.append(rows * cols)                  # 余数类 (r, c) 的大小
        cnt.sort(reverse=True)
        return sum(cnt[:maxOnes])                        # 降序取前 maxOnes 个
```

**验证记录**：两份代码均通过官方双样例（4 / 6）。C++ 版额外做了四层交叉验证——① **穷举对拍**：$W,H \le 4$ 的全部 $2^{W \cdot H}$ 个矩阵枚举（覆盖 134 个 $(W,H,s,k)$ 配置），公式与穷举最优 0 失配；② **列 DP 精确解**：状态压缩「最后 $s-1$ 列」的位掩码 DP，再对 287 个中等规模配置（$H$ 至 12、$W$ 至 13、$s$ 至 4）对拍公式，0 失配；③ **密度引理实测**：穷举中每个合法矩阵上验证 $\sum 1/(R \cdot C) \le k$（精确整数算术），无一违反；④ **一维权重构造**：对全部 $m \le 30$、$s \le m$ 共 465 组 $(m,s)$ 验证引理 3 的 $\sum \alpha = 1$ 与逐位置精确覆盖。Python 版完成 $W,H \le 3$ 的 48 组穷举对拍，同样 0 失配。

## 8. 边界情况与易错点

1. **$maxOnes = 0$**：一个类都不选，答案 0（矩阵全 0），循环自然处理。
2. **$s = 1$**：只有类 $(0,0)$，大小 $W \times H$；此时 $k \le 1$：$k=0$ 得 0，$k=1$ 得全 1 矩阵。
3. **$k = s^2$**：所有类都选，答案 $W \times H$（全 1 矩阵，每个窗口恰 $s^2 = k$ 个 1）。
4. **行列别接反**：$R_r$ 用 $height$、$C_c$ 用 $width$。官方样例 $W=H$ 测不出这个 bug，务必用 $W \ne H$ 的用例自测（如 $W=2,H=3,s=2,k=1 \to 2$）。
5. **约束 $s \le \min(W,H)$ 是公式免特判的前提**：它保证 $R_r, C_c \ge 1$ 且每个格子都在至少一个窗口内；若输入违反（本题不会），$r \ge H$ 时公式 $(H-1-r)/s+1$ 会出 0 或负数。
6. **类大小上界**：$z \le \lceil H/s \rceil \cdot \lceil W/s \rceil \le 10^4$，答案 $\le W \cdot H = 10^4$，`int` 无溢出。
7. **贪心的「选哪些类」**：大小相同的类任选即可（示例 2 中 $(0,1)$ 与 $(1,0)$ 同为 2，官方选了后者），答案与选择无关。

**延伸思考**：其一，把约束从**正方形**推广到任意 $a \times b$ **矩形子阵**（每个 $a \times b$ 子阵 1 数 $\le k$）：按 $(i \bmod a,\ j \bmod b)$ 分类后，「每个窗口恰含每类一格」「同类互斥」「整类填满」三条观察逐字成立，答案 = 前 $k$ 大类大小之和，引理 3 的构造与密度论证对 $a \ne b$ 逐字平移——本题的结构本质是**一维性质的乘积**，而非正方形特有。其二，若再要求 1 的位置**输出构造**而非计数，按前 $k$ 大类整类填满即是显式方案。其三，若窗口约束只对**部分位置**（如不与边界相交的子阵）生效，边角类不再「免费」，余数类大小结构被破坏，需要重新建模。
