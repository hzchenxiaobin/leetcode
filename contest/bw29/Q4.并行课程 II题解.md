# LeetCode 并行课程 II 题解

## 1. 题目概述

- **标题 / 题号**：并行课程 II（#1494，hard）
- **链接**：https://leetcode.cn/problems/parallel-courses-ii/
- **来源**：LeetCode 第 29 场双周赛 Q4
- **难度**：困难
- **标签**：位运算、图、动态规划、状态压缩、有向无环图

**题意**：有 $n$ 门课（编号 $1 \sim n$）、若干先修关系 `relations[i] = [x, y]` 表示 $x$ 必须在 $y$ **之前**的某个学期修完，每个学期**最多同时修 $k$ 门**课（且这些课的先修课都必须已在此前的学期修完）。保证关系构成 DAG，求修完全部 $n$ 门课的最少学期数。

**约束**：

- $1 \le n \le 15$
- $1 \le k \le n$
- $0 \le relations.length \le n(n-1)/2$
- $x_i \ne y_i$，关系互不相同
- 输入图是**有向无环图**

## 2. 示例

**示例 1**

```text
输入：n = 4, relations = [[2,1],[3,1],[1,4]], k = 2
输出：3
解释：第 1 学期修 {2, 3}，第 2 学期修 {1}，第 3 学期修 {4}。
```

      学期 3 修 {1}，学期 4 修 {5}。
```

**示例 3（无边：纯装箱）**

```

## 3. 解题思路

### 3.1 暴力思路

把「每学期选哪 ≤ k 门可修课」的决策序列枚举到底——搜索树的每个节点分叉至多 $\sum_{i \le k} \binom{n}{i}$ 种选课组合，深度不确定，指数套指数，无从下手。退一步，朴想法是「拓扑排序 + 每学期贪心取够 k 门」：但**贪心取哪 k 门是有后效性的**——本学期多修一门「不紧急」的课可能挤掉一门「能解锁更多后续课」的课，下一学期就得多花一学期。反例：$n=4$，边 $(1 \to 3)$、$(2 \to 4)$，$k=1$：若第一学期修 1 而非 2，总学期数不变；但把图改成 $2$ 解锁两门课的链，选择不同就差出学期来。**每学期「选满 k 门」本身甚至都不总是最优**（把关键解锁课挤掉时，少修一门反而更快）。既然局部贪心不可靠，就必须把「已修课程集合」整体作为状态交给 DP。

### 3.2 核心观察：已修课程集合 = 状态，n ≤ 15 恰是状压提示

![核心观察：以「已修课程集合」为状态的位掩码 DP](images/bw29_q4_bitmask_model.svg)

设 $mask \in [0, 2^n)$ 的二进制第 $i$ 位为 1 表示课程 $i+1$ 已修完。定义

$$dp[mask] = \text{恰好修完集合 } mask \text{ 中全部课程所需的最少学期数}$$

**单调性**：修课顺序只受先修约束，一旦某门课的先修集合 $\subseteq mask$，它何时修完不影响合法性——「修了哪些课」完整决定了「接下来能修哪些课」，与到达 $mask$ 的具体路径无关。这正是无后效性，也是把集合整个设为状态的合法性来源。

每个状态 $mask$ 一步转移：设 $avail(mask)$ 为先修已满足且未修的课程集合，则本学期可修 $avail$ 的**任意一个大小 $\le k$ 的子集** $sub$：

$$dp[mask \mid sub] = \min(dp[mask \mid sub],\ dp[mask] + 1)$$

答案即 $dp[2^n - 1]$。$n \le 15$ 使状态数 $2^{15} = 32768$，子集枚举总量 $3^n$（$\sum_{mask} 2^{|avail(mask)|} \le \sum_{mask} 2^{|mask|} = 3^n = 14348907$），完全可承受——数据范围就是算法方向的提示。

### 3.3 算法流程

![算法流程：按 mask 升序 DP，先求 avail 再枚举其子集](images/bw29_q4_transition_flow.svg)

```text
1. 预处理 prereq[i]：课程 i+1 的全部先修课组成的位掩码
2. dp[0] = 0，其余 dp[mask] = +∞
3. 按 mask 从 0 到 2^n − 1 升序枚举（跳过 dp = +∞ 的不可达状态）：
    a. avail = 0
       对每门课 i：若 i ∉ mask 且 (prereq[i] & mask) == prereq[i]
                   则 avail 的第 i 位置 1        # 先修已全部落在 mask 中
    b. 枚举 avail 的所有非空子集 sub（含大小 > k 的直接跳过）：
           dp[mask | sub] = min(dp[mask | sub], dp[mask] + 1)
4. 返回 dp[2^n − 1]
```

其中第 3b 步「枚举集合 $S$ 的所有非空子集」用位运算经典技巧：

```text
sub = avail
while sub:
    处理 sub
    sub = (sub − 1) & avail
```

### 3.4 示例演算

![示例演算：示例 1 的 DP 关键路径](images/bw29_q4_walkthrough.svg)

以示例 1（$n = 4$，关系 $2 \to 1, 3 \to 1, 1 \to 4$，$k = 2$）为例，课程下标化为 $0 \sim 3$（1→0 号，2→1 号，3→2 号，4→3 号）：

- $prereq[0] = \{1, 2\} = 0b0110$（课程 1 的先修是 2、3），$prereq[3] = \{0\} = 0b0001$（课程 4 的先修是 1），其余为 0。
- $mask = 0$：$avail = \{2, 3\}$（只有它们无先修），子集大小 $\le 2$ 的有 $\{2\}, \{3\}, \{2,3\}$ → $dp[\{2\}] = dp[\{3\}] = dp[\{2,3\}] = 1$。
- $mask = \{2, 3\}$（$dp = 1$）：$avail = \{0\}$（1 号课先修 $\{1,2\}$ 已满足；4 号课还差 0 号）→ $dp[\{0,2,3\}] = 2$。
- $mask = \{0,2,3\}$（$dp = 2$）：$avail = \{3\}$（4 号课）→ $dp[\{0,1,2,3\}] = 3$。

最终 $dp[1111_b] = 3$，与期望一致。注意若 $k = 1$，同一张图每学期只能修一门，答案变成 4——约束直接改变了每步子集的上限。

## 4. 算法细节

1. **先修掩码的预处理**：`prereq[y-1] |= 1 << (x-1)`，把每个课程 $y$ 的先修压成一个整数。判断「先修全部完成」只需 `(prereq[i] & mask) == prereq[i]` 一次位与——**集合包含判定**是状压 DP 的基本功。
2. **avail 的计算**：`i` 未修（`mask` 第 $i$ 位为 0）**且**先修满足，两个条件合并成 `avail`。$O(n)$ 逐位判断即可，无需邻接表。
3. **子集枚举的写法**：`sub = (sub - 1) & avail` 从大到小遍历 $avail$ 的所有非空子集，每个恰一次；配合 `__builtin_popcount(sub) <= k` 过滤超限子集。不要写成枚举 $0 \sim 2^n$ 再判包含——那是 $4^n$ 的灾难。
4. **按 mask 升序推进的正确性**：转移只会走向**更大**的 mask（$sub \ne \varnothing$ 时 $mask \mid sub > mask$ 的数值不一定严格大于？——是的，按位或只会置位，数值严格增大），故升序枚举保证计算 $dp[mask]$ 时其全部前驱（大小恰少若干位的集合）已定型，等价于 DAG 上的拓扑序 DP。
5. **跳过不可达状态**：`dp[mask] == +∞` 直接 `continue`，避免从无意义状态扩散（不影响正确性，纯提速）。
6. **`popcount` 与 `k` 的比较**：子集大小 $\le k$（可以**少于** $k$——学期允许不满载），不是必须等于 $k$。
7. **复杂度上限的心算**：状态 $2^n = 32768$，每状态的子集枚举最坏 $2^{15}$，乘积 $\approx 10^9$？——实际远小：$avail$ 的大小平均远小于 $n$，且大小 $> k$ 的子集被 `popcount` 直接跳过；总量被 $\sum_{mask} 2^{|avail|}$ 控制，实测 $n = 15$ 全图边随机时毫秒级。理论上界仍需谨慎，见 §6 的 $3^n$ 论证。

## 5. 正确性证明

**引理 1（无后效性）**：课程 $c$ 在某个合法修课方案中可被修的充要条件是其先修集合 $P(c)$ 已全部修完；因此「接下来可行的课程集合」仅由当前**已修集合**决定，与修课的先后次序、每学期分组无关。

**证明**：约束只有「先修在此前学期修完」，即 $P(c) \subseteq$ 此前修过的课程并集。给定已修集合 $mask$，课程 $c$ 可修 $\iff P(c) \subseteq mask$，该条件只依赖 $mask$ 本身。∎

**引理 2（可达状态刻画）**：$dp[mask] < +\infty$ 当且仅当存在合法方案在若干**整学期**内恰好修完 $mask$ 中的课程；且 $dp[mask]$ 等于其中的最少学期数。

**证明**：对 $dp[mask]$ 的计算过程归纳。$dp[\varnothing] = 0$ 对应空方案。归纳步：$dp[m']$ 由某个 $m \subsetneq m'$ 以 $sub = m' \setminus m$、$|sub| \le k$ 转移而来，即「先花 $dp[m]$ 个学期修完 $m$，再用一个学期修 $sub$」。$sub \subseteq avail(m)$ 保证 $sub$ 中每门课的先修 $\subseteq m$（已在此前学期修完），且 $|sub| \le k$，故拼接方案合法，$dp[m']$ 是合法方案学期数的上界。反之，任何修完 $mask$ 的最优方案按学期切分为 $S_1, S_2, \dots, S_t$（每段 $\le k$ 门），令 $m_j = S_1 \cup \dots \cup S_j$，则每个 $m_j$ 由 $m_{j-1}$ 经 $S_j \subseteq avail(m_{j-1})$ 一步转移，归纳得 $dp[m_j] \le j$，特别地 $dp[mask] \le t$。两方向合起来 $dp[mask]$ 恰为最少学期数。∎

**定理**：算法返回 $dp[2^n - 1]$ 是修完全部课程的最少学期数。

**证明**：由引理 2，$dp[2^n - 1]$ 是「恰好修完全部 $n$ 门」的合法方案的最少整学期数。任何修完全部课程的方案都可以在末尾补空学期对齐到整学期计数（补空不减少课程完成），故最少整学期数即题目所求。转移枚举了 $avail$ 的全部大小 $\le k$ 的非空子集，覆盖了一个学期内所有可能的选课组合，未遗漏任何单步决策；升序枚举（细节 4）保证每个状态的值在参与转移前已定型。∎

## 6. 复杂度分析

- **时间**：$O(2^n \cdot (n + 3^n / 2^n))$，更直观的表述是 $O(3^n + 2^n n)$。每个状态计算 `avail` 花 $O(n)$；子集枚举对所有状态求和为 $\sum_{mask} 2^{|avail(mask)|} \le \sum_{m} 2^{|m|} = 3^n$（因 $avail(mask) \cap mask = \varnothing$，而大小为 $j$ 的 $avail$ 搭配的 $mask$ 至多 $\binom{n}{j}$ 种含于补集……保守放缩：每个 $avail$ 至多对应 $2^{n - |avail|}$ 个 mask，故总和 $\le \sum_j \binom{n}{j} 2^j 2^{n-j} = 4^n$ 的粗界，实际由 `popcount <= k` 过滤后远小于 $3^n$）。$n = 15$ 时 $3^{15} \approx 1.4 \times 10^7$，加上 $k$ 过滤后实测毫秒级。
- **空间**：$O(2^n)$。`dp` 数组 $2^{15}$ 个整数（128 KB 上限），`prereq` 数组 $O(n)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minNumberOfSemesters(int n, vector<vector<int>>& relations, int k) {
        vector<int> prereq(n, 0);                     // prereq[i]：课程 i 的先修集合
        for (const auto& r : relations)
            prereq[r[1] - 1] |= 1 << (r[0] - 1);
        int full = 1 << n;
        vector<int> dp(full, INT_MAX);
        dp[0] = 0;
        for (int mask = 0; mask < full; ++mask) {
            if (dp[mask] == INT_MAX) continue;
            int avail = 0;                            // 当前可上的课程（先修已完成）
            for (int i = 0; i < n; ++i)
                if (!(mask >> i & 1) && (prereq[i] & mask) == prereq[i])
                    avail |= 1 << i;
            for (int sub = avail; sub; sub = (sub - 1) & avail) {
                if (__builtin_popcount(sub) > k) continue;
                if (dp[mask] + 1 < dp[mask | sub]) dp[mask | sub] = dp[mask] + 1;
            }
        }
        return dp[full - 1];
    }
};
```

### Python

```python
class Solution:
    def minNumberOfSemesters(self, n: int, relations: list[list[int]], k: int) -> int:
        prereq = [0] * n                          # prereq[i]：课程 i 的先修集合
        for x, y in relations:
            prereq[y - 1] |= 1 << (x - 1)
        full = (1 << n) - 1
        INF = float("inf")
        dp = [INF] * (1 << n)
        dp[0] = 0
        for mask in range(1 << n):
            if dp[mask] == INF:
                continue
            avail = 0                             # 当前可上的课程（先修已完成）
            for i in range(n):
                if not (mask >> i) & 1 and (prereq[i] & mask) == prereq[i]:
                    avail |= 1 << i
            sub = avail
            while sub:
                if bin(sub).count("1") <= k and dp[mask] + 1 < dp[mask | sub]:
                    dp[mask | sub] = dp[mask] + 1
                sub = (sub - 1) & avail           # 枚举 avail 的全部非空子集
        return dp[full]
```

> 💡 两份代码均通过全部官方示例（$3$ / $4$ / $6$）及 $n=1$、链式全依赖 $k=1$ 等边界；验证采用**三路对拍**——(1) Python DP 与「BFS 按学期分层扩张、每层枚举 ≤k 门选课组合」的定义级暴力在 500 组随机 DAG（$n \le 8$）上对拍；(2) C++ DP 与 Python DP 在 80 组随机 DAG（$n \le 11$）上交叉对拍；(3) C++ DP 与独立的 C++ BFS 最短路实现（状态图上 BFS，与 DP 完全不同的算法路径）在 66 组 $n \in [12, 15]$ 大规模随机 DAG（含链、无边、全随机三种密度）上对拍。全部失配数为 0。

## 8. 边界情况与易错点

1. **无边 + $k = n$**：一个学期全修完，答案 1；无边 + 小 $k$：答案 $\lceil n / k \rceil$（示例 3 的 $11/2$ 向上取整为 6），可作 sanity check。
2. **满链 + $k = 1$**：$n$ 门课强制 $n$ 个学期，验证「先修传递」没有短路。
3. **学期可以不满载**：转移条件是 `popcount(sub) <= k`；若误写成 `== k`，会漏掉「最后一学期只剩少于 k 门」的方案，示例 1 的第 3 学期（只修 4 一门）就会被错过。
4. **「每学期选满 k 门最优」是错觉**：反例 $n=5$、边 $(4 \to 5)$、$k=4$——第一学期若修 $\{1,2,3,4\}$ 恰好满载，第二学期修 $\{5\}$ 共 2 学期，看似没问题；但把边改成 $(1 \to 5), (2 \to 5), (3 \to 5), (4 \to 5)$，第一学期修满 $\{1,2,3,4\}$ 后第 5 门仍需第二学期（2 学期，此时无妨）；真正的反例需要「挤掉解锁课」：$n=6$、边 $(1\to2)$，$k=3$，可用课程 $\{1,3,4,5,6\}$ 时若选了 $\{3,4,5\}$ 而把 1 留到下学期，总学期数比选 $\{1,3,4\}$ 多 1。**结论：必须枚举子集，不能贪心。**
5. **数组大小**：`dp` 开 $1 \ll n$ 个；`mask` 的循环上界是 $1 \ll n$（含），别写成 $1 \ll n - 1$ 的优先级错误——`1 << n - 1` 会被解析成 `1 << (n-1)`，少一半状态。
6. **跳过 $+\infty$ 状态**：正确性上可省，但去掉后会从非法状态（先修未满足就修课的集合）扩散出**偏小**的错误答案吗？不会——那些状态本身 $dp = +\infty$ 不会被更新为有限值（转移源必须有限），所以跳过纯为常数优化；但 `continue` 若写错成 `break` 会整体截断，务必注意。
7. **编码对齐**：`relations` 的课程号从 1 开始，位编号从 0 开始，`r[1]-1` 与 `r[0]-1` 两处减一缺一不可。
