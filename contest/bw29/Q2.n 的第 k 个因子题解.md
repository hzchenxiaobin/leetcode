# LeetCode n 的第 k 个因子 题解

## 1. 题目概述

- **标题 / 题号**：n 的第 k 个因子（#1492，medium）
- **链接**：https://leetcode.cn/problems/the-kth-factor-of-n/
- **来源**：LeetCode 第 29 场双周赛 Q2
- **难度**：中等
- **标签**：数学、数论、枚举

**题意**：正整数 $i$ 是 $n$ 的因子当且仅当 $n \bmod i = 0$。把 $n$ 的所有因子**升序**排列后，返回第 $k$ 个；若因子个数不足 $k$ 个，返回 $-1$。

**约束**：

- $1 \le k \le n \le 1000$

**进阶**：能否设计时间复杂度小于 $O(n)$ 的算法？

## 2. 示例

**示例 1**

```text
输入：n = 12, k = 3
输出：3
解释：12 的因子升序为 [1, 2, 3, 4, 6, 12]，第 3 个是 3。
```

**示例 2**

```text
输入：n = 7, k = 2
输出：7
解释：7 是质数，因子只有 [1, 7]，第 2 个是 7。
```

**示例 3（k 超出因子个数）**

```text
输入：n = 4, k = 4
输出：-1
解释：4 的因子为 [1, 2, 4]，只有 3 个，不足 4 个，返回 -1。
```

## 3. 解题思路

### 3.1 暴力思路

从 $1$ 到 $n$ 逐个试除，能整除就计数，计到第 $k$ 个直接返回；扫完仍未凑满则返回 $-1$。时间 $O(n)$，对 $n \le 1000$ 显然够用。但这没有利用因子的**配对结构**——题面特意给了进阶要求 $o(n)$，考点正是成对枚举。

### 3.2 核心观察：因子成对出现，枚举到 √n 即可

![核心观察：因子成对出现，d 与 n/d 关于 √n 对称](images/bw29_q2_factor_pairs_concept.svg)

若 $d \mid n$（$d$ 整除 $n$），则 $n/d$ 也整除 $n$：因子总是**成对**出现，且 $d \le \sqrt{n} \le n/d$ 或 $d \ge \sqrt{n} \ge n/d$，两者分居 $\sqrt{n}$ 两侧。因此：

- 所有 $\le \sqrt{n}$ 的因子（「小因子」）按 $d$ **升序**枚举：$d = 1, 2, \dots, \lfloor\sqrt{n}\rfloor$；
- 每个小因子 $d$ 对应一个大因子 $n/d$，$d$ 越小 $n/d$ 越大，所以大因子按 $d$ **降序**回看时恰好升序；
- 若 $n$ 是完全平方数，$d = \sqrt{n}$ 与自己配对，只算**一次**。

这样只需枚举到 $\sqrt{n}$，就能按升序「流式」消费前一半因子，再倒序消费后一半，整体 $O(\sqrt{n})$。

### 3.3 算法流程

![算法流程：先消耗小因子，再倒序消耗大因子](images/bw29_q2_algorithm_flow.svg)

```text
1. small = []                       # 记录已见过的小因子（升序）
2. d 从 1 递增，只要 d*d < n：
        若 n % d == 0：
            若 k == 1：返回 d       # 第 k 个因子恰是当前小因子
            k -= 1；small.push(d)
3. 若 d*d == n（n 为完全平方数）：
        若 k == 1：返回 d           # √n 恰在序列正中，只出现一次
        k -= 1
4. 从 small 末尾往前遍历 d：
        若 k == 1：返回 n / d       # 大因子随 d 降序而升序
        k -= 1
5. 返回 −1                          # 因子总数不足 k
```

### 3.4 示例演算

![示例演算：n=12 与 n=4 两例的因子序列消费过程](images/bw29_q2_walkthrough.svg)

**示例 1**（$n = 12$，$k = 3$）：小因子依次为 $1, 2, 3$（$4^2 = 16 > 12$ 停止），消费 $1$（$k: 3 \to 2$）、$2$（$k: 2 \to 1$）、$3$ 时 $k = 1$，返回 $3$。✓

**示例 3**（$n = 4$，$k = 4$）：$d = 1$ 时 $1 \cdot 1 < 4$，消费 $1$（$k \to 3$）；$d = 2$ 时 $d^2 = n$，$\sqrt{4} = 2$ 居中消费（$k \to 2$）；随后倒序看大因子：$4/1 = 4$ 消费（$k \to 1$），`small` 已空，$k$ 仍不为 0，返回 $-1$。完整序列 $[1, 2, 4]$ 只有 3 个因子。✓

## 4. 算法细节

1. **边界 $d \cdot d$ 与 $n$ 的关系要三分**：循环条件写 $d^2 < n$（严格小于），出循环后单独判断 $d^2 = n$ 的情形——完全平方数的 $\sqrt{n}$ 因子只出现一次，混进任何一侧都会重复计数。
2. **`long long` 防溢出**：$d \cdot d$ 在 $n = 10^{18}$ 级别的推广题中会溢出 `int`，本题 $n \le 1000$ 无虞，但写成 `(long long)d * d` 是可迁移的好习惯。
3. **两个「k == 1」的判断点**：小因子一边枚举一边消耗 $k$，命中立即返回，平均意义上比「先收集再合并」更快；大因子阶段倒序消耗。两个阶段的衔接（平方数居中）是最容易写错的地方。
4. **不用数组也行**：若只需求「是否存在第 $k$ 个因子」，可以先数出小因子个数 $c$（含 $\sqrt{n}$ 若为平方数），则总因子数 $= 2c - [\text{平方数}]$，先判 $k$ 是否超界，再决定向前取小因子还是向后换算大因子——$O(\sqrt{n})$ 时间、$O(1)$ 空间。
5. **升序保证**：小因子天然升序（$d$ 递增）；大因子 $n/d$ 在 $d$ 降序时严格升序（$n$ 固定，$d$ 减小则 $n/d$ 增大），两段拼接即全局升序。

## 5. 正确性证明

**引理 1（因子配对）**：$d$ 是 $n$ 的因子当且仅当 $n/d$ 是 $n$ 的因子；且除 $d = \sqrt{n}$（仅当 $n$ 为完全平方数）外，$d \ne n/d$。

**证明**：$n \bmod d = 0$ 时记 $n = d \cdot e$，则 $n \bmod e = 0$，故 $e = n/d$ 也是因子；对称地由 $e \mid n$ 得 $d \mid n$。若 $d = n/d$，则 $d^2 = n$，即 $d = \sqrt{n}$，只可能发生在 $n$ 为完全平方数时；反之若 $d \ne n/d$，两因子互异。∎

**引理 2（两段升序拼接）**：设 $n$ 的因子中 $\le \sqrt{n}$ 的为 $d_1 < d_2 < \dots < d_c$（若 $n$ 为完全平方数，$d_c = \sqrt{n}$），则 $n$ 的全部因子升序恰为

$$d_1, d_2, \dots, d_c, \ n/d_{c-1},\ n/d_{c-2},\ \dots,\ n/d_1$$

（$n$ 为完全平方数时中间的 $d_c = \sqrt{n}$ 只出现一次，紧随其后的是 $n / d_{c-1}$）。

**证明**：由引理 1，任何因子要么 $\le \sqrt{n}$（属于 $\{d_i\}$），要么 $> \sqrt{n}$（形如 $n / d_i$，且 $d_i < \sqrt{n}$）。前段 $d_1 < \dots < d_c$ 升序显然；后段中 $d_{c-1} > d_{c-2} > \dots > d_1$，而 $n / d$ 关于 $d$ 严格递减，故 $n/d_{c-1} < n/d_{c-2} < \dots < n/d_1$ 升序。衔接处：$d_c \le \sqrt{n} < n/d_{c-1}$（由 $d_{c-1} < \sqrt{n}$ 得 $n / d_{c-1} > \sqrt{n} \ge d_c$），故两段拼接整体升序且无遗漏、无重复。∎

**定理**：按 §3.3 流程返回的值恰为升序因子序列的第 $k$ 项（不存在时返回 $-1$）。

**证明**：流程按引理 2 的拼接顺序依次「消费」因子——第 2 步按升序消费 $d_1, \dots, d_{c-1}$（条件 $d^2 < n$ 保证不含 $\sqrt{n}$），第 3 步消费居中的 $d_c$（若存在），第 4 步倒序消费 $n / d_{c-1}, \dots, n / d_1$，与升序序列逐项对应。每消费一项令 $k$ 减一，恰在某项上 $k$ 到达 1 时该项即第 $k$ 个因子，返回正确；若全部消费完 $k$ 仍 $> 1$，说明因子总数 $< $ 原始 $k$，返回 $-1$ 正确。∎

## 6. 复杂度分析

- **时间**：$O(\sqrt{n})$。第 2 步 $d$ 从 1 枚举到 $\lceil\sqrt{n}\rceil$，每步一次取模；第 4 步至多再扫 $c \le \sqrt{n}$ 个小因子。对 $n \le 1000$ 约 32 次迭代。
- **空间**：$O(\sqrt{n})$ 存小因子列表；若采用 §4.4 的计数判界写法可降到 $O(1)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int kthFactor(int n, int k) {
        vector<int> small;                       // d <= sqrt(n) 的因子，升序
        int d = 1;
        for (; (long long)d * d < n; ++d) {
            if (n % d == 0) {
                if (--k == 0) return d;          // 小因子按升序直接消耗 k
                small.push_back(d);
            }
        }
        if (d * d == n && --k == 0) return d;    // 完全平方数：sqrt(n) 恰在正中
        for (int i = (int)small.size() - 1; i >= 0; --i) {
            if (--k == 0) return n / small[i];   // 大因子 = n/d，随 d 降序而升序
        }
        return -1;
    }
};
```

### Python

```python
class Solution:
    def kthFactor(self, n: int, k: int) -> int:
        small = []                                # d <= sqrt(n) 的因子，升序
        d = 1
        while d * d < n:
            if n % d == 0:
                if k == 1:
                    return d
                k -= 1
                small.append(d)
            d += 1
        if d * d == n:                            # 完全平方数：sqrt(n) 居中
            if k == 1:
                return d
            k -= 1
        for d in reversed(small):                 # 大因子 = n/d 随 d 降序而升序
            if k == 1:
                return n // d
            k -= 1
        return -1
```

> 💡 两份代码均通过全部官方示例（$3$ / $7$ / $-1$）及 $n = 1, k = 1$、$k = n$ 超界等边界；另与「$1 \sim n$ 逐个试除」的独立暴力实现进行了双重对拍——Python 侧 3000 组随机 + $n = 1 \dots 1000$ 全量（每个 $n$ 配随机 $k$），C++ 侧 3000 组随机，全部失配数为 0。

## 8. 边界情况与易错点

1. **完全平方数**：$n = 4, 9, 16, \dots$ 的 $\sqrt{n}$ 因子只能算一次。循环条件若是 `d * d <= n` 再在体内判 $d^2 = n$ 也能写对，但最易错的是「前后两段都把它算了一次」。
2. **$n = 1$**：唯一因子是 $1$（$1$ 也是完全平方数），$k = 1$ 返回 $1$；流程中第 2 步循环体不执行（$1 \cdot 1 = n$），直接落到平方数分支，正确。
3. **$k > $ 因子总数**：如 $n = 7, k = 7$，质数只有 2 个因子，必须返回 $-1$——别忘了流程末尾的兜底返回。
4. **质数输入**：因子只有 $[1, n]$，$k = 2$ 时答案就是 $n$ 本身（示例 2），验证大因子分支的衔接。
5. **溢出习惯**：本题 $n \le 1000$ 不会溢出，但 $d \cdot d$ 的类型提升写法在 $n$ 达到 `int` 上限时是必须的，建议养成。
6. **升序陷阱**：大因子阶段若**正序**遍历 `small`，得到的是 $n/d_1 > n/d_2 > \dots$ 降序序列，顺序就反了——必须倒序遍历。
