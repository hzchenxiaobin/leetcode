# LeetCode 去掉最低工资和最高工资后的工资平均值 题解

## 1. 题目概述

- **标题 / 题号**：去掉最低工资和最高工资后的工资平均值（#1491，easy）
- **链接**：https://leetcode.cn/problems/average-salary-excluding-the-minimum-and-maximum-salary/
- **来源**：LeetCode 第 29 场双周赛 Q1
- **难度**：简单
- **标签**：数组、排序

**题意**：给定整数数组 `salary`，元素**互不相同**，`salary[i]` 是第 $i$ 位员工的工资。去掉其中的最低工资与最高工资后，返回剩余 $n-2$ 个工资的**平均值**。

**约束**：

- $3 \le salary.length \le 100$
- $10^3 \le salary[i] \le 10^6$
- `salary[i]` 互不相同（保证最小值、最大值各只有一个）
- 与真实值误差在 $10^{-5}$ 以内的结果都视为正确

## 2. 示例

**示例 1**

```text
输入：salary = [4000,3000,1000,2000]
输出：2500.00000
解释：最低工资 1000、最高工资 4000，去掉后剩 [3000,2000]，
      平均值 (3000+2000)/2 = 2500。
```

**示例 2**

```text
输入：salary = [1000,2000,3000]
输出：2000.00000
解释：去掉 1000 与 3000 后只剩 [2000]，平均值即 2000。
```

**示例 3（边界：正好 3 个人）**

```text
输入：salary = [6000,5000,4000,3000,2000,1000]
输出：3500.00000
解释：去掉 1000 与 6000，剩下 (2000+3000+4000+5000)/4 = 3500。
```

## 3. 解题思路

### 3.1 暴力思路

复制一份数组、排序、去掉首尾两个元素再求平均——$O(n \log n)$ 时间、$O(n)$ 空间。对 $n \le 100$ 完全够用，但排序做了大量无关工作：我们只需要**总和、最小值、最大值**三个统计量，根本不需要知道其余元素的大小次序。这题作为签到题，值得沉淀的正是「从排序降维到一遍扫描」的意识。

### 3.2 核心观察：三个统计量可以一遍同求

![核心观察：一遍扫描同时维护 sum、min、max](images/bw29_q1_one_pass_concept.svg)

去掉最小值与最大值后的和等于「总和 − 最小值 − 最大值」，而**总和、最小值、最大值**都能在同一次遍历中用 $O(1)$ 额外空间维护。由元素互不相同（约束保证），最小值与最大值各只出现一次，直接减去即可，不会误伤其他元素。

$$\text{ans} = \frac{\sum_{i} salary[i] - \min(salary) - \max(salary)}{n - 2}$$

### 3.3 算法流程

```text
1. mn = +∞, mx = −∞, sum = 0
2. 遍历每个 s ∈ salary：
        sum += s
        mn = min(mn, s)
        mx = max(mx, s)
3. 返回 (sum − mn − mx) / (n − 2)
```

### 3.4 示例演算

![示例演算：4000,3000,1000,2000 的一遍扫描](images/bw29_q1_walkthrough.svg)

以示例 1（`[4000,3000,1000,2000]`）为例：

| 元素 | sum | mn | mx |
|------|-----|-----|-----|
| 4000 | 4000 | 4000 | 4000 |
| 3000 | 7000 | 3000 | 4000 |
| 1000 | 8000 | 1000 | 4000 |
| 2000 | 10000 | 1000 | 4000 |

遍历结束后 $sum = 10000$、$mn = 1000$、$mx = 4000$，故

$$\text{ans} = \frac{10000 - 1000 - 4000}{4 - 2} = \frac{5000}{2} = 2500.0$$

## 4. 算法细节

1. **整数累加、最后才转浮点**：先在整数域算出 `sum - mn - mx`（最大约 $98 \times 10^6 < 2^{31}$，`long long` 更稳），再做一次除法转 `double`，只引入一次浮点舍入误差，远小于 $10^{-5}$ 的容差。
2. **初始值选取**：`mn` 初始化为第一个元素（或 `INT_MAX`），`mx` 同理；用第一个元素初始化可避免忘记边界值。
3. **除法语义**：C++ 中 `(double)a / (n - 2)` 必须显式把至少一侧转成浮点，写成 `a / (n - 2)` 会做整数除法直接得 0 或整数部分。
4. **返回值精度**：题目容差 $10^{-5}$，`double` 足够；无需输出格式化，直接返回数值。
5. **为什么不担心重复的最值**：约束明确 `salary[i]` 唯一。若去掉唯一性（变体题），只需在遍历时**计数**最小/最大值出现次数，各减去相应份数。

## 5. 正确性证明

**引理 1（去最值的和）**：设数组互不相同，$S = \sum_i a_i$，$m$ 与 $M$ 分别为其最小值与最大值，则去掉最小值与最大值后剩余元素之和为 $S - m - M$。

**证明**：设最小值出现在下标 $p$、最大值出现在下标 $q$。由互不相同性 $p \ne q$，故被去掉的恰是两个不同位置的元素 $a_p = m$、$a_q = M$，剩余元素之和为 $S - a_p - a_q = S - m - M$。∎

**定理**：一遍扫描维护 `(sum, mn, mx)`，返回 $(sum - mn - mx)/(n-2)$，结果与去掉最值后的平均值之差不超过一次浮点除法的相对舍入误差（约 $10^{-16}$ 量级），在题目容差内。

**证明**：归纳可证遍历结束时 `sum/mn/mx` 分别等于全数组之和/最小值/最大值（初值取首个元素时，对前 $k$ 个元素成立，则对第 $k+1$ 个也成立）。由引理 1，分子恰为剩余元素之和；分母 $n - 2$ 为剩余元素个数（$n \ge 3$ 保证分母非零）。整数运算精确，唯一的浮点操作是最后一次除法，IEEE 754 `double` 的相对误差 $\le 2^{-53}$，绝对误差远小于 $10^{-5}$。∎

## 6. 复杂度分析

- **时间**：$O(n)$，单次遍历，每个元素做常数次比较与累加。
- **空间**：$O(1)$，只维护三个标量统计量，无需排序或复制数组。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    double average(vector<int>& salary) {
        int mn = INT_MAX, mx = INT_MIN;
        long long sum = 0;
        for (int s : salary) {
            mn = min(mn, s);
            mx = max(mx, s);
            sum += s;
        }
        return (double)(sum - mn - mx) / (double)(salary.size() - 2);
    }
};
```

### Python

```python
class Solution:
    def average(self, salary: list[int]) -> float:
        mn = mx = salary[0]
        total = 0
        for s in salary:
            if s < mn:
                mn = s
            elif s > mx:
                mx = s
            total += s
        return (total - mn - mx) / (len(salary) - 2)
```

> 💡 两份代码均通过全部 4 个官方示例（2500 / 2000 / 3500 / 4750）与「$n = 3$ 最小规模」「工资贴近 $10^6$ 上界」的边界测试；另与「排序去首尾求平均」的独立实现在 3000 组随机数组（$3 \le n \le 100$，值域 $[10^3, 10^6]$）上对拍，失配数为 0。

## 8. 边界情况与易错点

1. **$n = 3$**：去掉首尾后只剩 1 个元素，分母 $n - 2 = 1$；这是分母可能的最小值，题目约束 $n \ge 3$ 保证不为零。
2. **整数除法陷阱**：C++ 里 `(sum - mn - mx) / (n - 2)` 两个操作数都是整数会截断；必须先 cast 成 `double`。Python 的 `/` 天然是浮点除法，无此问题。
3. **`min`/`max` 初始化**：`mn` 用 `INT_MAX`、`mx` 用 `INT_MIN` 初始化是标准写法；若偷懒初始化为 0，由于工资 $\ge 1000 > 0$，`mn` 会出错。
4. **互异性是前提**：本题约束元素互不相同，直接减一个 min/max 即可；变体中若允许重复（如统计去掉所有最值），需要改为计数。
5. **无需真的「删除」**：题目说「去掉」，但物理删除（erase/切片）既慢又无必要——统计量相减即等价，这是本题最想传达的简化。
