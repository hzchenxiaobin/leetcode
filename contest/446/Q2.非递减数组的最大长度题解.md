# LeetCode 非递减数组的最大长度 题解

## 1. 题目概述

- **标题 / 题号**：非递减数组的最大长度（#3523，medium）
- **链接**：https://leetcode.cn/problems/make-array-non-decreasing/
- **来源**：LeetCode 第 446 场周赛 Q2
- **难度**：中等
- **标签**：栈、贪心、数组、单调栈

**题意**：给你一个整数数组 `nums`。一次操作可以选择一个**子数组**（连续非空段），把它替换成**一个**等于该子数组**最大值**的元素——整段"压缩"成一个数。返回经过零次或多次操作后，数组仍保持**非递减**的前提下，数组长度的**最大值**。

**约束**：

- $1 \le \text{nums.length} \le 2 \times 10^5$
- $1 \le \text{nums[i]} \le 2 \times 10^5$

> 💡 **读题关键**：① 操作只能**缩短**数组，且压出来的数是段内**最大值**——任何操作都造不出比原有值更大的数；② 方向别看反：同族题常问"最少几次操作使非递减"，本题反过来问"长度最多能保住多少"，是"保最大"而不是"花最少"；③ 抓住"最大值"三个字——每个块的**代言人**只能是块内最大值，谁来当代言人决定了块与块之间的秩序。

## 2. 示例

**示例 1**

```text
输入：nums = [4,2,5,3,5]
输出：3
解释：把子数组 nums[1..2] = [2,5] 压成 5 → [4,5,3,5]；
      再把子数组 nums[2..3] = [3,5] 压成 5 → [4,5,5]。
      最终数组 [4,5,5] 非递减，长度为 3。
```

**示例 2**

```text
输入：nums = [1,2,3]
输出：3
解释：数组本身已是非递减，一次操作都不用做，长度保持 3。
```

**示例 3**

```text
输入：nums = [3,1,2]
输出：1
解释：1 和 2 都被开头的 3 压制：任何不含 3 的块最大值都小于 3，
      放在含 3 的块之后必然破坏非递减。唯一出路是整段压成 [3]，长度 1。
```

## 3. 解题思路

### 3.1 暴力思路

最朴素的模拟：从原数组出发，每一步在 $O(n^2)$ 个子数组里任选其一压缩，BFS 所有可达状态，在非递减的状态里挑最长者。状态空间随操作组合指数膨胀，$n = 2\times10^5$ 下完全不可行。

先退一步，在草稿上把官方示例的两步操作画出来——$[4,2,5,3,5]$ 压成 $[4,5,5]$，本质是把原数组切成了 $[4]\,|\,[2,5]\,|\,[3,5]$ 三段、每段各自塌缩。会发现一个规律：**不管怎么压，最终数组的每个元素都恰好等于原数组某段连续区间的最大值，且这些区间首尾相接、铺满原数组**（§5 引理 1 证明）。于是问题脱离"操作模拟"，变成：

$$\text{把 nums 划分成尽可能多的连续块，使各块最大值从左到右非递减}$$

沿这个模型做 DP：状态得记"已划分到第 $i$ 个元素 + 最后一块的最大值"，转移还要枚举下一块的边界，至少 $O(n^2)$；$n = 2\times10^5$ 时约 $4\times10^{10}$，依旧超时。必须看穿块最大值的结构。

### 3.2 核心观察：块最大值的代言人只能是前缀最大值——答案是"数"出来的

![核心观察：任意操作序列等价于连续划分，每块收缩为块内最大值](images/c446_q2_partition_max.svg)

- **观察一（操作的封闭性）**：$\max$ 满足结合律——先压 $A$ 再压 $B$，与一次压掉 $A \cup B$ 结果相同。归纳可知：**任意操作序列的净效果 = 原数组的一个连续划分、每块收缩为块内最大值**；反过来，任何划分都能从左到右逐块压缩实现。操作序列与划分**一一对应**，两个世界可以随便切换（证明见 §5 引理 1）。
- **观察二（上界）**：在任一合法划分里，任取一块，其最大值在块内**首次出现**的位置 $t$ 必满足 $\text{nums}[t] \ge \max(\text{nums}[0..t-1])$——左侧所有元素都不超过它：左侧各块的元素 $\le$ 所在块最大值 $\le$ 本块最大值（块最大值非递减），本块内 $t$ 之前的元素 $<$ 本块最大值（$t$ 是首次出现）。**$t$ 正是"前缀最大值"位置**。各块互不重叠 ⇒ 各块的 $t$ 严格递增、互不相同 ⇒

$$\text{块数} \le \text{前缀最大值的个数 } L$$

- **观察三（构造取等）**：让每个前缀最大值位置单独成块，并"带走"它右侧直到下一个前缀最大值之间的所有元素。两个幸存者之间的元素都不是前缀最大值，都**严格小于**左侧最近的幸存者（前缀最大值水位没人抬升），所以每块的最大值恰好等于幸存者本人；而幸存者的值随下标非递减（定义使然）⇒ 块最大值序列非递减，**恰好 $L$ 块**。

**结论**：**答案 $= L$（前缀最大值的个数，首元素天然计入）**。问题从"构造方案"退化为"一遍数数"：

- 维护左侧历史最大值 $\text{cur}$；
- $\text{nums}[i] \ge \text{cur}$：顶得住左侧所有人 ⇒ **幸存**，$\text{ans}{+}{+}$，抬高 $\text{cur}$；
- 否则：左侧有人压着 ⇒ **被吸收**（并进左块，块最大值不变），跳过。

> 💡 幸存者恰是数组的"**天际线**"：从左向右看，只有前缀最大值能露出头来；天际线之下的元素谁也保不住，只能并进旁边的块里"消失"。

### 3.3 算法流程

![算法流程：单趟扫描维护前缀最大值 cur](images/c446_q2_scan_flow.svg)

| 步骤 | 动作 | 说明 |
|------|------|------|
| ① 初始化 | `cur = 0, ans = 0` | 值域 $\ge 1$，`cur = 0` 视作 $-\infty$，首元素必幸存 |
| ② 取元素 | `x = nums[i]` | 从左到右单趟扫描 |
| ③ 判定 | `x >= cur ?` | 与"左侧历史最大值"比较，不是与前一个元素比 |
| ④ 幸存分支 | `ans++, cur = x` | 前缀最大值，单独成块 |
| ⑤ 吸收分支 | 跳过 | 并入左侧某块，块最大值不变，无需模拟 |
| ⑥ 返回 | `ans` | 幸存者个数即最大长度 |

### 3.4 示例演算

![示例 1 演算：幸存者即天际线，被吸收者压在天际线之下](images/c446_q2_example_walkthrough.svg)

用**示例 1**（`nums = [4,2,5,3,5]`）逐步走一遍：

| $i$ | $\text{nums}[i]$ | 扫描前 cur | 判定 | 动作 | ans |
|-----|-----------------|------------|------|------|-----|
| 0 | 4 | 0（视作 $-\infty$） | $4 \ge 0$ ✓ | 幸存，cur = 4 | 1 |
| 1 | 2 | 4 | $2 < 4$ ✗ | 被吸收 | 1 |
| 2 | 5 | 4 | $5 \ge 4$ ✓ | 幸存，cur = 5 | 2 |
| 3 | 3 | 5 | $3 < 5$ ✗ | 被吸收 | 2 |
| 4 | 5 | 5 | $5 \ge 5$ ✓ | 相等也算，幸存，cur = 5 | 3 |

幸存者下标 $0, 2, 4$ ⇒ 划分 $[4]\,|\,[2,5]\,|\,[3,5]$，收缩成 $[4,5,5]$，与官方解释的两步操作完全一致，长度 $\boxed{3}$。

**示例 2**（`[1,2,3]`）：每个元素都是前缀最大值，全部幸存，答案 3，零操作。

**示例 3**（`[3,1,2]`）：只有 3 幸存（cur 一路保持 3，1 和 2 都过不了判定），答案 1——整段 $[3,1,2]$ 必须压成一个块 $[3]$。

## 4. 算法细节

1. **先建模，再写码**：比赛时的破冰动作是在小样例上把"操作"画成"划分"（$[4,2,5,3,5] \to [4]\,|\,[2,5]\,|\,[3,5]$）。"操作 ⟺ 划分"一经确认，问题就换了世界——这是本题最大的时间节省点。
2. **标签里的「单调栈」已退化为单变量**：把幸存者序列看作一个只进不出的栈——新元素 $\ge$ 栈顶则入栈（幸存），否则被吸收丢弃。由于只与栈顶比较、吸收又不改变栈，栈里有效信息只剩栈顶一个，退化成标量 `cur`，$O(1)$ 空间。
3. **判定必须是 `>=`**：非递减允许相等，连续相等的"平台段"应全部幸存；写 `>` 会在样例 1 末尾的 5 上翻车（误得 2）。
4. **`cur` 是左侧历史最大值，不是前一个元素**：反例 `[3,1,2]`——2 只比前一个 1 大，但历史最大 3 仍压着它；拿 `nums[i-1]` 比较会误得 2，正确答案 1。
5. **被吸收者零成本**：$x < \text{cur}$ 时把它并入任何左块，块最大值 $\max(\text{cur}, x) = \text{cur}$ 不变——连"并给哪一块"都不必知道，直接跳过。这正是贪心能退化成一次比较的原因。
6. **等价写法**：$\text{nums}[i] \ge \max(\text{nums}[0..i-1]) \iff \text{nums}[i] = \max(\text{nums}[0..i])$，故也可以数"逐位置前缀最大值"，见参考代码的 Python 变体。

## 5. 正确性证明

**引理 1（操作序列 ⟺ 连续划分）**：任意操作序列得到的最终数组，等于把原数组划分成 $k$ 个连续块后依次取各块最大值所得的序列；反之，任意连续划分都可经恰 $k$ 次操作实现。

**证明**：先证正向。对已执行的操作步数归纳，维护不变量：当前数组的元素与原数组的一组区间 $I_1, \dots, I_m$ 一一对应，诸区间互不相交、按序排列、并为 $[0, n)$，且每个元素的值等于对应区间上 $\text{nums}$ 的最大值。归纳基础（零步）取单点区间显然成立。设某步操作选中当前数组的连续段，它对应区间 $I_l, \dots, I_r$；诸区间按序排列，故其并为连续区间 $I'$，替换后的新元素对应 $I'$，值为诸区间最大值的最大——由 $\max$ 的结合律，即 $I'$ 上的最大值。不变量保持，终态即得命题前半。再证反向：给定划分 $B_1, \dots, B_k$，从左到右对每块做一次"整块压缩"。归纳可知任一时刻每块在当前数组中仍是一段连续区间（其它块的压缩不切断它），故 $k$ 次操作后每块恰剩一个等于其最大值的元素。∎

**引理 2（块最大值首次出现位置是前缀最大值）**：设某划分的块最大值序列非递减。任取一块 $B$，其最大值 $M$ 在 $B$ 内的首次出现为位置 $t$，则 $\text{nums}[t] = M \ge \max(\text{nums}[0..t-1])$。

**证明**：位置 $t$ 之前的元素分两类：① 位于 $B$ 左侧的块中，每个 $\le$ 所在块的最大值 $\le M$（块最大值非递减）；② 位于 $B$ 内 $t$ 之前，因 $t$ 是 $M$ 在块内的首次出现，均严格小于 $M$。两类均不超过 $\text{nums}[t]$，故 $\max(\text{nums}[0..t-1]) \le \text{nums}[t]$。∎

**定理（答案 = 前缀最大值个数）**：记 $L = \#\{\, i : \text{nums}[i] \ge \max(\text{nums}[0..i-1]) \,\}$（$i = 0$ 时前缀为空、约定计入 $L$）。任何合法划分的块数至多 $L$，且存在块数恰为 $L$ 的合法划分。

**证明**：上界：对合法划分的每块取其最大值的首次出现位置 $t$，由引理 2，诸 $t$ 均属于前缀最大值位置集合；块互不重叠 ⇒ 诸 $t$ 严格递增 ⇒ 互不相同。块与 $t$ 一一对应，故块数 $\le L$。构造：把全部前缀最大值位置按序记为 $l_1 < l_2 < \dots < l_L$，令第 $j$ 块为 $[l_j,\, l_{j+1} - 1]$（末块延伸到 $n - 1$）。先说明：两个相邻前缀最大值之间**水位不变**——对 $p \in (l_j, l_{j+1})$，归纳可知 $\max(\text{nums}[0..p-1]) = \text{nums}[l_j]$（中间无人抬升前缀最大值），而 $p$ 不是前缀最大值位置，故 $\text{nums}[p] < \text{nums}[l_j]$。于是第 $j$ 块内除 $l_j$ 外的元素全部严格小于 $\text{nums}[l_j]$，块最大值 $m_j = \text{nums}[l_j]$；又 $l_{j+1}$ 是前缀最大值位置，$m_{j+1} = \text{nums}[l_{j+1}] \ge \max(\text{nums}[0..l_{j+1}-1]) \ge \text{nums}[l_j] = m_j$，块最大值序列非递减。该划分合法且恰有 $L$ 块。∎

**推论（算法正确性）**：单趟扫描维护 $\text{cur}$，归纳可证：处理第 $i$ 个元素之前 $\text{cur} = \max(\text{nums}[0..i-1])$（初值 $0$ 为哨兵，因 $1 \le \text{nums}[i]$）。故判定 $x \ge \text{cur}$ 恰在前缀最大值位置为真，返回值即 $L$；由引理 1 与定理，$L$ 就是最大可能长度。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。单趟扫描，每个元素一次比较与至多两次赋值；$n = 2\times10^5$ 时毫秒级完成。
- **空间复杂度**：$O(1)$。仅 `cur` / `ans` 两个标量；"单调栈"退化为标量后无需任何数组。
- **范围验证**：$\text{ans} \le n \le 2\times10^5$、$\text{cur} \le 2\times10^5$，`int` 无溢出风险；值域下界 $1$ 与哨兵 $0$ 相容。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int maximumPossibleSize(vector<int>& nums) {
        int ans = 0, cur = 0;               // cur：左侧历史最大值，0 视作 -inf（值域 >= 1）
        for (int x : nums) {
            if (x >= cur) {                 // 前缀最大值 ⇒ 幸存（注意是 >=，平台段全活）
                ans++;
                cur = x;                    // 抬高天际线
            }                               // 否则被左块吸收：块最大值不变，直接跳过
        }
        return ans;                         // 幸存者个数 = 最大长度
    }
};
```

### Python

```python
class Solution:
    def maximumPossibleSize(self, nums: List[int]) -> int:
        ans, cur = 0, 0                   # cur：左侧历史最大值，0 视作 -inf（值域 >= 1）
        for x in nums:
            if x >= cur:                  # 前缀最大值 ⇒ 幸存（注意是 >=，平台段全活）
                ans += 1
                cur = x                   # 否则被左块吸收：块最大值不变，直接跳过
        return ans                        # 幸存者个数 = 最大长度
```

等价一行流：$\text{nums}[i] \ge \max(\text{nums}[0..i-1]) \iff \text{nums}[i] = \max(\text{nums}[0..i])$，直接数逐位置前缀最大值：

```python
from itertools import accumulate

class Solution:
    def maximumPossibleSize(self, nums: List[int]) -> int:
        return sum(x == m for x, m in zip(nums, accumulate(nums, max)))
```

## 8. 边界情况与易错点

1. **判定用 `>=` 别写 `>`**：非递减允许相等，平台段（连续相等元素）全部幸存；样例 1 末尾的 5 靠 `>=` 活下来，写 `>` 误得 2。
2. **`cur` 是历史前缀最大值**：严禁退化成 `nums[i-1]`——反例 `[3,1,2]`：2 大于前一个 1，但历史最大 3 仍压着它，正确答案 1，误用得 2。
3. **别当 LIS 做**：块必须**连续**且覆盖全部元素，中间的大数丢不掉。反例 `[1,5,2,3]`：最长非递减子序列长 3，但 5 无法消失，其后无论怎么分块都压不过 5，本题答案是 2。
4. **$n = 1$**：单元素必幸存，答案 1；`cur = 0` 哨兵天然处理，无需特判。
5. **全部相等**（如 `[7,7,7]`）：非严格前缀最大值包含所有元素 ⇒ 答案 $n$，零操作。
6. **已非递减**（示例 2）：全部幸存，答案 $n$；"零次操作"是合法选项。
7. **溢出**：$\text{ans} \le n \le 2\times10^5$、$\text{cur} \le 2\times10^5$，`int` 足够；Python 无此虑。
8. **不要死磕"怎么操作"**：由引理 1，操作序列与划分一一对应，在"划分世界"里思考即可；比赛时在"每步选哪个子数组"上反复模拟是本题最大的时间黑洞。
