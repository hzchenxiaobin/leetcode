# LeetCode 二叉搜索树的最小绝对差 题解

## 1. 题目概述

- **标题 / 题号**：二叉搜索树的最小绝对差（#530，easy）
- **链接**：https://leetcode.cn/problems/minimum-absolute-difference-in-bst/
- **来源**：LeetCode 第 21 场周赛 Q1
- **难度**：简单
- **标签**：树、深度优先搜索、广度优先搜索、二叉搜索树、二叉树

**题意**：给定一棵**二叉搜索树**的根 `root`，返回树中**任意两个不同节点**的值之差的绝对值的最小值。注意候选节点对**不要求相邻**（不要求是父子、也不要求在同一条边上），只要节点不同即可；节点数不少于 2，所以答案一定存在。

**约束**：

- 树中节点数目范围是 $[2, 10^4]$
- $0 \le \text{Node.val} \le 10^5$
- 输入保证是一棵合法的二叉搜索树
- 本题与 [783. 二叉搜索树节点最小距离](https://leetcode.cn/problems/minimum-distance-between-bst-nodes/) 完全相同

## 2. 示例

**示例 1**

```text
输入：root = [4,2,6,1,3]
输出：1
解释：中序遍历为 1, 2, 3, 4, 6，相邻差 1, 1, 1, 2，最小值为 1。
```

**示例 2**

```text
输入：root = [1,0,48,null,null,12,49]
输出：1
解释：中序遍历为 0, 1, 12, 48, 49，相邻差 1, 11, 36, 1，最小值为 1。
      取节点 0 与 1（或 48 与 49）即可。
```

**示例 3**

```text
输入：root = [236,104,701,null,227,null,911]
输出：9
解释：中序遍历为 104, 227, 236, 701, 911，相邻差 123, 9, 465, 210，最小值为 9。
      注意 9 来自祖孙节点 227 与 236，而所有父子边上的差最小也是 123
      （|236−104|=132、|104−227|=123、|236−701|=465、|701−911|=210），
      所以「只比较父子边」的直觉是错的。
```

## 3. 解题思路

### 3.1 暴力思路

把树里所有节点的值收集成一个数组，枚举所有 $\binom{n}{2}$ 个节点对求 $|a_i - a_j|$ 的最小值：时间 $O(n^2)$、空间 $O(n)$。$n = 10^4$ 时约 $5 \times 10^7$ 对比较，虽然勉强能过，但完全没有利用「这是一棵 **BST**」这一关键信息。

一个更常见但**错误**的贪心是「只比较每条父子边上的差」：示例 3 会得到 $123$ 而不是 $9$，因为最小差可以出现在**祖孙**甚至**跨层**的节点对之间。

### 3.2 核心观察：中序遍历 → 有序序列，答案落在相邻两项

![核心观察：中序遍历 BST 得到递增序列，最小差必在相邻两项](images/wc21_q1_bst_inorder_concept.svg)

BST 的中序遍历（左 → 根 → 右）恰好按**从小到大**输出全部节点值。设中序序列为

$$a_1 < a_2 < \cdots < a_n$$

对任意 $i < j$，把区间差拆成相邻间隙之和：

$$a_j - a_i = (a_{i+1} - a_i) + (a_{i+2} - a_{i+1}) + \cdots + (a_j - a_{j-1})$$

每一项都是正数（序列递增），所以

$$a_j - a_i \ \ge\ a_{i+1} - a_i \ \ge\ \min_{1 \le k < n}\bigl(a_{k+1} - a_k\bigr)$$

也就是说：**任何一对节点的差都不可能小于某个相邻间隙**，而相邻对本身也是合法候选，于是

$$\text{答案} = \min_{1 \le k < n} \bigl(a_{k+1} - a_k\bigr)$$

问题从 $O(n^2)$ 的「枚举点对」变成 $O(n)$ 的「一遍中序遍历 + 维护前驱」。

### 3.3 算法流程

![迭代中序遍历流程：栈 + 前驱变量 prev](images/wc21_q1_inorder_flow.svg)

```text
ans ← +∞，prev ← 无（无前驱）
stack ← 空，cur ← root
while cur ≠ 空 或 stack 非空:
    while cur ≠ 空:                 # 一路向左，左链全部入栈
        stack.push(cur)
        cur ← cur.left
    cur ← stack.pop()               # 弹出即「中序访问」当前节点
    if prev 存在:
        ans ← min(ans, cur.val − prev)
    prev ← cur.val
    cur ← cur.right
return ans
```

三个要点：

1. **访问顺序**由「左链入栈 + 弹出 + 转右」这一套动作保证，不需要把节点排序；
2. **前驱变量 `prev`** 让「相邻项」在流式遍历中自然可得，无需保存整个数组；
3. 中序序列递增，所以 $cur.val - prev$ 已是非负值，**不用再取绝对值**。

### 3.4 示例演算

![示例演算：root = [1,0,48,null,null,12,49] 的中序走查](images/wc21_q1_walkthrough.svg)

以 `root = [1,0,48,null,null,12,49]` 为例，中序遍历依次出栈 $0, 1, 12, 48, 49$：

| 出栈序 | `cur.val` | `prev` | `cur − prev` | `ans` | 说明 |
|--------|-----------|--------|--------------|-------|------|
| 1 | 0 | 无 | — | $\infty$ | 首个节点，无前驱 |
| 2 | 1 | 0 | **1** | **1** | 刷新 `ans` |
| 3 | 12 | 1 | 11 | 1 | 不更优 |
| 4 | 48 | 12 | 36 | 1 | 不更优 |
| 5 | 49 | 48 | **1** | **1** | 再次刷到 1 |

遍历结束返回 `ans = 1`，与示例输出一致。

## 4. 算法细节

1. **用迭代中序，不用递归**：$n$ 可达 $10^4$，退化成单链时递归深度也是 $10^4$，Python 默认递归上限 1000 会直接 `RecursionError`；显式栈没有这个问题（C++ 递归深度 $10^4$ 一般也能过，但没必要冒栈溢出的风险）。
2. **「有没有前驱」与「前驱是多少」分开处理**：用一个独立的 `hasPrev` 标记（Python 用 `prev = None`）。本题值域 $\ge 0$，写成 `prev == -1` 恰好也能过；但只要值域出现负数就会静默出错，不要赌这个巧合。
3. **`ans` 初值必须是无穷大**：取 `LLONG_MAX` / $10^{18}$。若误初始化为 `0`，`min(0, 任何正差)` 恒为 `0`，答案必错。
4. **不需要取绝对值**：中序序列递增，`cur.val - prev` 恒非负。若 BST 中存在重复值，该差为 `0`，也正是正确答案，代码无需改动。
5. **只保留一个前驱**：`prev` 在每次访问后覆盖为 `cur.val`，因此空间与节点数无关，只与树高有关。
6. **不要修改节点**：`ans` 与 `prev` 都用局部变量传递，节点值只读；这也是能反复调用 `Solution` 对象的前提。
7. **备选写法**：任意遍历（DFS/BFS）收集全部值后排序，再取相邻差最小值，时间 $O(n \log n)$、空间 $O(n)$。代码更短、也不依赖 BST 性质，作为兜底完全够用；但题目既然给的是 BST，中序既更快又更贴合考点。

## 5. 正确性证明

**引理 1（中序序列有序）**：设 $a_1, a_2, \dots, a_n$ 为 BST 的中序遍历结果，则 $a_1 < a_2 < \cdots < a_n$（允许重复值时非降）。

**证明**：对树高归纳。中序遍历先递归左子树、再访问根、最后递归右子树。由 BST 性质，左子树所有节点值 $<$ 根值 $<$ 右子树所有节点值；由归纳假设，左右子树各自的中序序列有序。三段拼接后整体有序，根恰好是其左、右两段的严格分界点。∎

**引理 2（相邻间隙支配所有点对）**：对任意 $1 \le i < j \le n$，有 $a_j - a_i \ge a_{i+1} - a_i$。

**证明**：$a_j - a_i = \sum_{k=i}^{j-1} (a_{k+1} - a_k)$。由引理 1 每项 $a_{k+1} - a_k > 0$，非负项之和必不小于其中任一项，取 $k = i$ 即得。∎

**引理 3（不变量）**：每次执行更新语句时，`prev` 恰为中序序列中 `cur` 的**前一个**值；且执行后 `ans` 等于「已访问过的相邻对」中的最小差。

**证明**：对访问次数归纳。第一次访问没有前驱，跳过更新，`ans` 仍为 $\infty$，对应空集的最小值。之后每次 `prev` 都在上一次访问末尾被置为当时的 `cur.val`，由归纳假设上一次访问的正是中序前一个节点，故 `prev` 正确；`ans` 取旧值与新相邻差的 `min`，正好扩充了「已访问相邻对」集合的最小值。∎

**定理**：算法返回树中任意两不同节点值的最小绝对差。

**证明**：引理 3 保证遍历结束后 `ans` 等于中序序列全部相邻差的 $\min$；引理 2 说明该值不超过任何节点对的差，而相邻对本身是合法节点对，故它正是全局最小绝对差。又 $n \ge 2$ 保证至少一次更新，`ans` 不会停留在 $\infty$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。每个节点恰好入栈一次、出栈一次，压栈/弹栈与比较均为 $O(1)$ 操作，没有排序、没有额外遍历。
- **空间复杂度**：$O(h)$，其中 $h$ 为树高。栈中存放的是「当前左链」上的节点，其长度不超过 $h$；另外只有 `ans`、`prev`、`cur` 三个 $O(1)$ 变量。平衡树时 $O(\log n)$，退化成链时 $O(n)$。

## 7. 参考代码

### C++

```cpp
#include <algorithm>
#include <climits>
#include <vector>
using namespace std;

class Solution {
public:
    int getMinimumDifference(TreeNode* root) {
        long long ans = LLONG_MAX;
        int prev = -1;                    // 值域 >= 0，-1 可作哨兵
        bool hasPrev = false;
        vector<TreeNode*> stk;
        TreeNode* cur = root;
        while (cur != nullptr || !stk.empty()) {
            while (cur != nullptr) {      // 左链全部入栈
                stk.push_back(cur);
                cur = cur->left;
            }
            cur = stk.back();
            stk.pop_back();               // 弹出即中序访问
            if (hasPrev) ans = min(ans, (long long)cur->val - prev);
            prev = cur->val;
            hasPrev = true;
            cur = cur->right;
        }
        return (int)ans;
    }
};
```

### Python

```python
class Solution:
    def getMinimumDifference(self, root: Optional[TreeNode]) -> int:
        INF = 10 ** 18
        ans = INF
        prev = None                        # 上一个中序节点的值
        stack, cur = [], root
        while cur or stack:
            while cur:                     # 一路向左，左链全部入栈
                stack.append(cur)
                cur = cur.left
            cur = stack.pop()              # 弹出即按中序访问
            if prev is not None:
                ans = min(ans, cur.val - prev)
            prev = cur.val
            cur = cur.right
        return ans
```

## 8. 边界情况与易错点

1. **`ans` 初值写成 0**：`min(0, 正差)` 恒为 0，示例 1 会输出 0。必须用无穷大。
2. **Python 递归深度**：用递归中序时，单链形态 $n = 10^4$ 会 `RecursionError`（默认上限 1000）；要么改迭代，要么 `sys.setrecursionlimit(20000+)`。
3. **只比父子边**：示例 3 的最小差 9 来自祖孙节点 227 与 236，父子边最小是 123。别把「树上的距离」和「值之差」混淆。
4. **`prev` 哨兵用值判断**：`if (prev != -1)` 在值域含负数时失效；应使用独立的 `hasPrev`（Python 用 `None`）。
5. **忘记推进 `cur = cur.right`**：会导致同一节点被反复弹出，死循环；`cur` 的更新必须放在更新 `prev` 之后。
6. **空树不必特判**：题目保证 $n \ge 2$，`root` 一定非空。若本地自测时传入空树，`ans` 会停在初值、返回一个巨大的数——造测试数据时不要用空树。
7. **重复值**：题面未显式声明节点值互不相同。若存在重复，中序序列非严格递增，相邻差可为 0，此时答案就是 0，本算法天然正确。

**延伸思考**：

- 若树**不是** BST，求任意两点值差的最小值就只能「收集 + 排序」，$O(n \log n)$；BST 的价值就在于把「排序」这一 $O(n \log n)$ 步骤变成免费的 $O(n)$ 中序。
- 若要求「BST 中任意两节点差**第 k 小**」，可以二分答案 + 中序双指针统计差 $\le x$ 的点对数，做到 $O(n \log V)$；这也说明「相邻性」只对**最小值**成立，对第 k 小并不成立。
- 若要求「值差最小的一对节点」而不仅是差值，只需在更新 `ans` 时同时记录 `(prev, cur.val)` 两个值，改动是一行。
