# LeetCode 树中可以形成回文的路径数 题解

## 1. 题目概述

- **标题 / 题号**：树中可以形成回文的路径数（#2791，hard）
- **链接**：https://leetcode.cn/problems/count-paths-that-can-form-a-palindrome-in-a-tree/
- **来源**：LeetCode 第 355 场周赛 Q4
- **难度**：困难
- **标签**：位运算、树、深度优先搜索、哈希表

**题意**：给一棵以 $0$ 为根、$n$ 个节点的树（`parent` 数组给出，$\text{parent}[0] = -1$），以及字符串 $s$，其中 $s[i]$ 是节点 $i$ 与 $\text{parent}[i]$ 之间边上的字符（$s[0]$ 无意义）。统计满足 $u < v$ 且 $u \to v$ **简单路径**上的字符**可以重新排列成回文串**的点对 $(u, v)$ 的数目。

**约束**：

- $n = |\text{parent}| = |s| \le 10^5$
- 对所有 $i \ge 1$：$0 \le \text{parent}[i] \le n-1$，`parent` 表示一棵有效树（注意父编号**可以大于**子编号）
- $s$ 仅含小写英文字母

> 💡 赛场切入三句话：① 「重排成回文」只看每个字符出现次数的**奇偶性**——26 个字母压成一个 26 位 mask；② 树上 $u \to v$ 路径的奇偶 mask 恰好等于 $m(u) \oplus m(v)$（$m(x)$ = 根到 $x$ 的路径 mask，公共前缀在 LCA 处成对抵消，**根本不用求 LCA**）；③ 于是问题变成「数 mask 至多差 1 个比特的点对」——哈希表一趟数完，$O(26n)$。

## 2. 示例

**示例 1**

```text
输入：parent = [-1,0,0,1,1,2], s = "acaabc"
输出：8

解释：
- (0,1)、(0,2)、(1,3)、(1,4)、(2,5)：路径上只有一个字符，天然回文；
- (2,3)：路径 "aca"；
- (1,5)：路径 "cac"；
- (3,5)：路径 "acac"，重排为 "acca"。
```

**示例 2**

```text
输入：parent = [-1,0,0,0,0], s = "aaaaa"
输出：10

解释：任意 u < v 的点对，路径上全是字符 'a'，总数 C(5,2) = 10。
```

**补充示例（单节点）**

```text
输入：parent = [-1], s = "a"
输出：0

解释：只有根节点自身，不存在点对。
```

## 3. 解题思路

### 3.1 暴力思路

朴素做法是**枚举所有点对**，再对每个点对求出路径字符并判定能否重排成回文：

- 求单条路径需要先找 LCA（树上倍增 $O(n \log n)$ 预处理后 $O(\log n)$ 查询），或者干脆从 $u$、$v$ 分别向根走 $O(n)$；
- 点对本身有 $\binom{n}{2} \approx 5 \times 10^9$ 个（$n = 10^5$），枚举就已经爆炸，路径判定再快也无济于事。

瓶颈在于：**「路径可回文」是一个二元的点对谓词，必须把它压缩成一元可哈希的量**，才能套「前缀 + 哈希计数」的经典套路（类比 437. 路径总和 III 的前缀和）。

### 3.2 核心观察：路径的奇偶 mask = $m(u) \oplus m(v)$

**观察 1（回文只看奇偶性）**：一个多重集能重排成回文，当且仅当出现**奇数次**的字符至多一种——全偶则本身已是回文，恰一个奇字符则放在正中间（§5 引理 1）。于是路径的全部相关信息就是 26 个「该字符出现次数是否为奇数」的布尔值，压成一个 26 位整数。

**观察 2（树上路径 = 两条根路径的异或）**：设 $m(x)$ 为**根到 $x$** 路径上字符的奇偶 mask。路径 $u \to v$ 必经 $\mathrm{LCA}(u,v)$，拆成 $u \to l$ 与 $l \to v$ 两段；而 $m(u)$、$m(v)$ 各自多出的「根到 $l$」公共前缀部分被**异或两次，自行抵消**：

![核心观察：树上路径的奇偶 mask 等于两节点根路径 mask 的异或，LCA 公共前缀抵消](images/wc355_q4_path_xor_concept.svg)

于是路径 $u \to v$ 的奇偶 mask $= m(u) \oplus m(v)$——**无需真的求出 LCA**，一遍 DFS/BFS 从根递推每个点的 mask 即可。

**定理（好对判定）**：$(u,v)$ 是好对 $\iff \mathrm{popcount}(m(u) \oplus m(v)) \le 1$（§5 定理 1）。

### 3.3 算法流程：一趟遍历 + 哈希计数

判定已化成「两个 mask 相等或恰差一个比特」，剩下的就是标准计数：

![判定与计数流程：mask 至多差 1 位即好对，先查后记一趟数完](images/wc355_q4_count_hashmap.svg)

1. 由 `parent` 建 children 邻接表，从根 $0$ 出发迭代遍历（显式栈或队列），根的 mask 为 $0$；进入子节点 $y$ 时递推 $m(y) = m(x) \oplus (1 \ll (s[y] - \text{'a'}))$；
2. 到达节点 $x$（设 $m = m(x)$）时**先查后记**：
   - $\text{ans} \mathrel{+}= \text{cnt}[m]$（差 0 位：路径本身回文）；
   - $\text{ans} \mathrel{+}= \sum_{b=0}^{25} \text{cnt}[m \oplus (1 \ll b)]$（差 1 位：恰一个奇数字符作中心）；
   - 然后 $\text{cnt}[m] \mathrel{+}= 1$；
3. 遍历结束，`ans` 即答案。**处理顺序任意**：每个点对恰在「后到达者」处被统计一次（§5 定理 2）。

### 3.4 示例演算

![示例 1 走查：各节点 mask 与逐步配对计数](images/wc355_q4_walkthrough.svg)

以示例 1 `parent = [-1,0,0,1,1,2]`，`s = "acaabc"` 走查（按编号 $0 \to 5$ 处理，任何顺序皆可）：

| 处理节点 $x$ | $m(x)$ | 本步配对（与已处理节点差 ≤ 1 位） | ans |
|------|--------|------|-----|
| 0 | $\varnothing$ | — | 0 |
| 1 | $\{c\}$ | (0,1) | 1 |
| 2 | $\{a\}$ | (0,2) | 2 |
| 3 | $\{a,c\}$ | (1,3)、(2,3) | 4 |
| 4 | $\{b,c\}$ | (1,4) | 5 |
| 5 | $\{a,c\}$ | (1,5)、(2,5)、(3,5) | **8** |

其中节点 5 到达时，哈希表中 $\{a,c\}$ 已有 1 个（节点 3）→ 配出 **(3,5)**（差 0 位，路径 "acac" 重排 "acca"）；翻转 $a$ 得 $\{c\}$ 命中节点 1 → **(1,5)**（差 1 位，路径 "cac"）；翻转 $c$ 得 $\{a\}$ 命中节点 2 → **(2,5)**；其余 24 个翻转目标未命中。共 8 对，与官方输出一致 ✓。

## 4. 算法细节

1. **mask 的定义与递推**：$m(\text{root}) = 0$（空路径）；从父到子 $m(y) = m(x) \oplus (1 \ll (s[y] - \text{'a'}))$。$s[0]$ 对应根的「入边」，不存在，天然不会被用到。
2. **必须建 children 邻接表**：约束只保证 $0 \le \text{parent}[i] \le n-1$，**不保证 $\text{parent}[i] < i$**，不能按下标 $1..n-1$ 顺序直接递推 mask，必须从根开始沿邻接表 BFS/DFS。
3. **「先查后记」**：当前节点只与**已遍历**的节点配对，保证每对恰好统计一次；这也是顺序无关的来源。查询用 `find`（C++）或 `get`（Python），不要顺手插入空键。
4. **26 个翻转目标互不相同且 $\ne m$**：$m \oplus (1 \ll b_1) = m \oplus (1 \ll b_2) \Rightarrow b_1 = b_2$（两边再异或 $m$ 消去），且翻转一个比特必然改变值——「差 0 位」与「差 1 位」天然互斥，**不重不漏**。
5. **哈希容器**：mask $< 2^{26}$，键用 `int` 即可；C++ `unordered_map` 提前 `reserve(2n)` 减少 rehash；Python 预生成 `bits = [1 << b for b in range(26)]` 省一点常数。
6. **遍历用显式栈/队列**：树退化成链时深度达 $10^5$，Python 递归默认上限 1000 必爆，C++ 深递归也有栈溢出风险，迭代版一劳永逸。

## 5. 正确性证明

**引理 1（重排回文刻画）**：字符多重集 $S$ 可重排成回文 $\iff$ $S$中出现奇数次的字符至多一种。

**证明**：（必要性）设重排结果 $t$ 是回文。$t$ 中位置 $i$ 与 $|t| - 1 - i$ 配对（关于中心对称），每个字符的出现次数被配对贡献偶数份；若 $|t|$ 为奇数，正中间那一格单独贡献 1，故至多一个字符出现奇数次。（充分性）设至多一个奇字符：把每个偶数字符的一半任意排在前半段，另一半按镜像放进后半段；若有奇字符则置于正中间。得到的串关于中心对称，是回文。∎

**引理 2（拼接即异或）**：若路径 $P$ 由 $P_1$、$P_2$ 顺次拼接而成，则 $\mathrm{mask}(P) = \mathrm{mask}(P_1) \oplus \mathrm{mask}(P_2)$。

**证明**：任一字符 $c$ 在 $P$ 中的出现次数 = 在 $P_1$ 中的次数 + 在 $P_2$ 中的次数；模 $2$ 的加法恰是异或。对 26 个比特逐一成立。∎

**引理 3（树上路径的 mask 分解）**：设 $l = \mathrm{LCA}(u, v)$，则 $\mathrm{mask}(u \to v) = m(u) \oplus m(v)$。

**证明**：根到 $u$ 的路径 = （根到 $l$）拼接（$l$ 到 $u$），由引理 2 得 $m(u) = m(l) \oplus \mathrm{mask}(l \to u)$；同理 $m(v) = m(l) \oplus \mathrm{mask}(l \to v)$。于是

$$m(u) \oplus m(v) = \mathrm{mask}(l \to u) \oplus \mathrm{mask}(l \to v)$$

（$m(l)$ 被异或两次自行抵消）。而路径 $u \to v$ 恰由 $u \to l$ 与 $l \to v$ 两段拼接（树中 $u \to v$ 唯一且必经 $l$，两段除 $l$ 外无公共边），由引理 2，其 mask 即上式右端。∎

**定理 1（判定等价）**：对任意 $u \ne v$：$(u,v)$ 是好对 $\iff \mathrm{popcount}(m(u) \oplus m(v)) \le 1$。

**证明**：由引理 3，$m(u) \oplus m(v)$ 就是 $u \to v$ 路径字符的奇偶 mask，其中为 1 的比特恰对应出现奇数次的字符。由引理 1，路径可重排成回文 $\iff$ 奇数字符至多一种 $\iff$ 该 mask 的 popcount $\le 1$。∎

**定理 2（计数不重不漏）**：按任意固定顺序遍历全部节点，维护已遍历节点 mask 的计数器 cnt；对当前节点 $x$（$m = m(x)$）累加 $\text{cnt}[m] + \sum_{b=0}^{25} \text{cnt}[m \oplus (1 \ll b)]$ 后再执行 $\text{cnt}[m] \mathrel{+}= 1$。则最终总和恰等于好对总数。

**证明**：令 $T(m) = \{m\} \cup \{m \oplus (1 \ll b) : 0 \le b < 26\}$，共 27 个值且两两不同（$m \oplus (1 \ll b_1) = m \oplus (1 \ll b_2)$ 两边异或 $m$ 得 $b_1 = b_2$；单比特翻转值 $\ne m$），故 cnt 按 27 个互异键分别累加，无重复。

对任一点对 $\{y, x\}$（设按遍历序 $y$ 先到、$x$ 后到）：$x$ 被处理时 $y$ 已计入 cnt。若 $\{y,x\}$ 是好对，由定理 1，$m(y) \in T(m(x))$，其贡献恰好被累加一次；反之，被累加的每个 $y$ 都满足 $m(y) \in T(m(x))$，由定理 1 知 $\{y,x\}$ 必为好对。因此总和 = 好对总数，且每对恰统计一次。∎

## 6. 复杂度分析

- **时间复杂度**：$O(26n)$。建邻接表与遍历 $O(n)$；每个节点做 $1 + 26 = 27$ 次哈希查询与一次插入，$n = 10^5$ 时约 $2.7 \times 10^6$ 次哈希操作。
- **空间复杂度**：$O(n)$。children 邻接表 $O(n)$，显式栈 $O(n)$，哈希表至多存 $n$ 个不同的 mask 键。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    long long countPalindromePaths(vector<int>& parent, string s) {
        int n = parent.size();
        // parent[i] 不保证 < i，必须建 children 邻接表从根遍历
        vector<vector<int>> children(n);
        for (int i = 1; i < n; ++i)
            children[parent[i]].push_back(i);

        unordered_map<int, int> cnt;   // mask -> 已遍历节点中出现次数
        cnt.reserve(2 * n);
        long long ans = 0;
        vector<pair<int, int>> stk{{0, 0}};  // (节点, 根到该节点的奇偶 mask)
        while (!stk.empty()) {
            auto [x, m] = stk.back();
            stk.pop_back();
            // 先查：差 0 位 + 差 1 位（26 种翻转目标互不相同，不重不漏）
            auto it = cnt.find(m);
            if (it != cnt.end()) ans += it->second;
            for (int b = 0; b < 26; ++b) {
                it = cnt.find(m ^ (1 << b));
                if (it != cnt.end()) ans += it->second;
            }
            // 后记
            ++cnt[m];
            for (int y : children[x])
                stk.emplace_back(y, m ^ (1 << (s[y] - 'a')));
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def countPalindromePaths(self, parent: List[int], s: str) -> int:
        n = len(parent)
        children = [[] for _ in range(n)]
        for i in range(1, n):
            children[parent[i]].append(i)

        cnt = {}
        bits = [1 << b for b in range(26)]
        ans = 0
        stack = [(0, 0)]  # (节点, 根到该节点的奇偶 mask)
        while stack:
            x, m = stack.pop()
            # 先查：差 0 位 + 差 1 位
            ans += cnt.get(m, 0)
            for bit in bits:
                ans += cnt.get(m ^ bit, 0)
            # 后记
            cnt[m] = cnt.get(m, 0) + 1
            for y in children[x]:
                stack.append((y, m ^ (1 << (ord(s[y]) - 97))))
        return ans
```

## 8. 边界情况与易错点

1. **单节点**（$n = 1$）：无点对，答案 0；算法只处理根、cnt 为空，天然返回 0，无需特判。
2. **父编号大于子编号**：`parent[i]` 取值范围是 $[0, n-1]$ 而非 $[0, i)$，按下标顺序递推 mask 是错的——必须建 children 邻接表从根开始遍历。
3. **深链爆栈**：链状树深度 $10^5$，Python 递归默认上限 1000 直接 `RecursionError`；C++ 深递归在受限栈环境也可能溢出——统一用显式栈/队列迭代。
4. **答案溢出**：全同字符时答案达 $\binom{10^5}{2} \approx 5 \times 10^9$，超 32 位 int 上限；接口返回 `long long`（Python 无此问题）。
5. **26 位要全遍历**：翻转目标 $b \in [0, 26)$ 一个都不能漏；「差 0 位」与「差 1 位」的目标值天然不同，不会重复计数。
6. **先查后记**：若先 `cnt[m] += 1` 再查，会把节点与自己配对（$m \oplus m = 0$，popcount 为 0）多算 $n$ 对。
7. **$s[0]$ 无意义**：根没有入边，代码从根出发向 children 递推、只用 $s[y]$（$y \ne 0$），天然规避。

**延伸思考**：

- 若字符集巨大（如 $10^5$ 种编号字符）：无法枚举 26 个单比特翻转目标，需改为**树上启发式合并 / 点分治**——在每个分治重心（或合并中的「大集合」）上维护子树奇偶多重集合，对每棵子树查询「与大集合至多差一个元素」的对数（集合大小可控时逐元素枚举差集）。

- 若要求路径**本身**（不可重排）是回文：与奇偶性无关，需树上正反哈希 + 点分治，复杂度与实现难度都上一个大台阶。
