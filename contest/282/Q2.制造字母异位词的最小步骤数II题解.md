# LeetCode 制造字母异位词的最小步骤数II 题解

## 1. 题目概述

- **标题 / 题号**：制造字母异位词的最小步骤数II（#2186，medium）
- **链接**：https://leetcode.cn/problems/minimum-number-of-steps-to-make-two-strings-anagram-ii/
- **来源**：LeetCode 第 282 场周赛 Q2
- **难度**：中等
- **标签**：哈希表、字符串、计数

**题意**：给定两个字符串 `s` 和 `t`，一步操作可以往 `s` **或** `t` 末尾**追加任意一个字符**。求使 `s` 与 `t` 互为**字母异位词**（每种字符的出现次数完全相同，顺序无关）所需的最少操作步数。

**约束**：

- $1 \le \text{s.length},\, \text{t.length} \le 2 \times 10^5$
- `s` 和 `t` 仅由小写英文字母组成

> 💡 **读题定位**：「字母异位词」是频率计数的最强信号——只比多重集合、不比顺序，问题立刻从字符串层面退化到 26 维频率向量层面；「**追加**任一字符」则说明操作是**单向只增**的，频率差没有任何捷径可走。两个信号合起来，答案呼之欲出：$\sum_c \lvert \text{cntS}[c] - \text{cntT}[c] \rvert$。本题是 1347 的续作，属于周赛 Q2 的标准「套路识别 + 公式一步到位」题，赛场上应在 3~5 分钟内 AC；真正的分差在于**别把前作的公式记串**（见 §8）。

## 2. 示例

**示例 1**（官方）

```text
输入：s = "leetcode", t = "coats"
输出：7
解释：
- 执行 2 步操作，将 "as" 追加到 s，得到 s = "leetcodeas"；
- 执行 5 步操作，将 "leede" 追加到 t，得到 t = "coatsleede"。
两串均为 {a1 c1 d1 e3 l1 o1 s1 t1}，互为字母异位词，共 2 + 5 = 7 步。
```

**示例 2**（官方）

```text
输入：s = "night", t = "thing"
输出：0
解释：两串的字符多重集合本就相同，无需任何操作。
```

**示例 3**（自造：隔离「两串无公共字符」这一变量）

```text
输入：s = "a", t = "bbbb"
输出：5
解释：a 的频率差 |1−0| = 1，b 的频率差 |0−4| = 4，合计 5。
构造：s' = "abbbb"（向 s 追加 4 个 b），t' = "bbbba"（向 t 追加 1 个 a），
两串均为 {a1, b4}。注意最终长度必须对齐到 L* = 5（见 §4 第 3 条）。
```

## 3. 解题思路

### 3.1 暴力思路

模拟：反复判断两串是否互为字母异位词，不是就试着追加一个字符。每一步有「26 个字符 × 2 个目标串 = 52 种选择」，最坏需要追加 $O(n + m)$ 步，搜索树规模达 $52^{n+m}$，完全不可行；而且**局部看不清该补哪个字符**——该补谁由全局频率差决定，逐字符模拟无法在局部做出最优决策。

不可行的根源与前作 1347 一样：没有先提炼「**顺序无关**」这一性质，把功夫浪费在字符串层面。正确姿势是直接在 26 维频率向量上做差。

### 3.2 核心观察：只能追加 ⇒ 每个频率差都要单独补一步

![核心观察：只能追加，每个字符的频率差都要单独补一步](images/wc282_q2_diff_concept.svg)

关键在于操作语义是「**追加**」——**只增不减**：

- 操作过程中，$\text{cntS}[c]$ 与 $\text{cntT}[c]$ 都只能变大，不能变小；
- 终态互为字母异位词 ⇒ 终态计数相等，记为 $m_c$，则必有 $m_c \ge \max(\text{cntS}[c],\, \text{cntT}[c])$；
- 取等即最优：$s$ 侧补 $m_c - \text{cntS}[c]$ 步、$t$ 侧补 $m_c - \text{cntT}[c]$ 步，两项相加恰为 $\lvert \text{cntS}[c] - \text{cntT}[c] \rvert$。

每个字符的缺口互相独立（追加 $c$ 不影响 $d$ 的计数），于是

$$\text{ans} = \sum_{c} \big| \text{cntS}[c] - \text{cntT}[c] \big|$$

> 💡 **与前作 1347 的本质差异**：1347 的操作是「替换」（一减一加），一步同时消去一个正差和一个负差，答案 $= \sum\text{正差} = \frac{1}{2}\sum \lvert \text{diff} \rvert$；本题的操作是「追加」（只增不减），一步只能补一个缺口，答案 $= \sum \lvert \text{diff} \rvert$。当 `s`、`t` 等长时，本题答案恰为 1347 的**两倍**——**操作语义决定公式**。

### 3.3 算法流程：一个 diff 数组，三遍扫描

![算法流程：一个 diff 数组承载两张频率表，三遍扫描](images/wc282_q2_algorithm_flow.svg)

用一个 `diff[26]` 数组同时承载两张频率表：

1. 遍历 `s`：`diff[c]++`；
2. 遍历 `t`：`diff[c]--`；
3. 遍历 26 格：`ans += abs(diff[i])`，返回 `ans`。

遍历结束后 `diff[c] = cntS[c] - cntT[c]`：正差是 `t` 的缺口（向 `t` 补），负差是 `s` 的缺口（向 `s` 补），绝对值求和即答案。

### 3.4 示例演算

![示例演算：频率差绝对值求和等于 7，等长视角复核](images/wc282_q2_walkthrough.svg)

以官方示例 1（`s = "leetcode"`，`t = "coats"`）为例，先统计频率再做差：

| 字符 | cntS | cntT | 差 S−T | 绝对差 | 补法 |
|------|------|------|--------|--------|------|
| a | 0 | 1 | −1 | 1 | 补 1 个 a → s |
| c | 1 | 1 | 0 | 0 | — |
| d | 1 | 0 | +1 | 1 | 补 1 个 d → t |
| e | 3 | 0 | +3 | 3 | 补 3 个 e → t |
| l | 1 | 0 | +1 | 1 | 补 1 个 l → t |
| o | 1 | 1 | 0 | 0 | — |
| s | 0 | 1 | −1 | 1 | 补 1 个 s → s |
| t | 1 | 1 | 0 | 0 | — |

$\text{ans} = 1+0+1+3+1+0+1+0 = 7$。

**追加方案**：向 `s` 追加 `a`、`s`（2 步）得 `"leetcodeas"`；向 `t` 追加 `d`、`e`、`e`、`e`、`l`（5 步）得 `"coatsleede"`。两串均为 $\{a_1\, c_1\, d_1\, e_3\, l_1\, o_1\, s_1\, t_1\}$ ✓。

**等长视角复核**：终态必等长，$L^* = \sum_c \max(\text{cntS}[c],\, \text{cntT}[c]) = 10$，$\text{ans} = 2L^* - \lvert s \rvert - \lvert t \rvert = 20 - 8 - 5 = 7$ ✓（见 §4 第 3 条）。

## 4. 算法细节

1. **diff 数组的「一表两用」**：只需一个 `diff[26]`——遍历 `s` 时 `diff[c]++`，遍历 `t` 时 `diff[c]--`，结束时 `diff[c] = cntS[c] - cntT[c]`。比维护两张独立频率表少一半内存和代码量，是字母异位词家族的通用小技巧。

2. **补的方向**：正差（`s` 多）→ 向 `t` 追加差额；负差（`t` 多）→ 向 `s` 追加差额。每个字符**只补少的一方**——往两边同时补会让终态计数超过 $\max$，纯浪费步数（这正是 §5 中等号成立的前提）。

3. **等长视角（另一条等价公式，可作校验）**：互为异位词 ⇒ 终态长度相等，设终长为 $L$，则总步数 $= (L - \lvert s \rvert) + (L - \lvert t \rvert) = 2L - \lvert s \rvert - \lvert t \rvert$。最小化它等价于取**最小可行终长**：每个字符的终计数不得低于双方初计数的较大者，故 $L \ge \sum_c \max(\text{cntS}[c], \text{cntT}[c]) =: L^*$，且取 $L^*$ 恰好可行（每字符终计数都取 $\max$）。于是 $\text{ans} = 2L^* - \lvert s \rvert - \lvert t \rvert = \sum_c \lvert \text{cntS}[c] - \text{cntT}[c] \rvert$，两条公式互为印证。

4. **与 1347 的公式口诀**：**替换一步消两差 → 半个 $\lvert\text{diff}\rvert$ 之和；追加一步补一差 → 整个 $\lvert\text{diff}\rvert$ 之和**。等长数据下两题答案恰差一倍，是记忆锚点。

5. **答案上界**：$\text{ans} \le \lvert s \rvert + \lvert t \rvert \le 4 \times 10^5$（两串无公共字符时取等）。本题是周赛里罕见的**完全不用考虑溢出**的题，`int` 从头用到尾。

## 5. 正确性证明

记初态计数为 $\text{cntS}[c]$、$\text{cntT}[c]$。一个合法方案是若干次追加操作，终态 $s'$、$t'$ 互为字母异位词；记终态计数 $\text{cntS}'[c] = \text{cntT}'[c] = m_c$。

**引理 1（操作的单向性）**：任意时刻都有 $\text{cntS}[c] \ge \text{cntS}[c]_{\text{初}}$、$\text{cntT}[c] \ge \text{cntT}[c]_{\text{初}}$；一次追加恰使某一串的某一个字符计数 $+1$，不影响其他字符、其他串。

**证明**：追加只在串尾添加一个字符，不删除、不重排，计数变化恰为 $+1$。∎

**引理 2（步数下界）**：任一合法方案的步数为

$$k = \sum_c \big( 2m_c - \text{cntS}[c] - \text{cntT}[c] \big) \ \ge\ \sum_c \big| \text{cntS}[c] - \text{cntT}[c] \big|.$$

**证明**：由引理 1，计数只能单向增长，故向 $s$ 追加字符 $c$ 的次数恰为 $m_c - \text{cntS}[c]$，向 $t$ 追加 $c$ 的次数恰为 $m_c - \text{cntT}[c]$。求和：

$$k = \sum_c (m_c - \text{cntS}[c]) + \sum_c (m_c - \text{cntT}[c]) = \sum_c \big( 2m_c - \text{cntS}[c] - \text{cntT}[c] \big).$$

又 $m_c \ge \text{cntS}[c]$ 且 $m_c \ge \text{cntT}[c]$，故 $m_c \ge \max(\text{cntS}[c], \text{cntT}[c])$，从而逐字符有

$$2m_c - \text{cntS}[c] - \text{cntT}[c] \ \ge\ 2\max(\text{cntS}[c], \text{cntT}[c]) - \text{cntS}[c] - \text{cntT}[c] = \big| \text{cntS}[c] - \text{cntT}[c] \big|,$$

求和即得下界。∎

**引理 3（下界可达）**：取 $m_c = \max(\text{cntS}[c], \text{cntT}[c])$，存在恰好 $\sum_c \lvert \text{cntS}[c] - \text{cntT}[c] \rvert$ 步的合法方案。

**证明**：对每个 $c$，向计数少的一串追加 $\lvert \text{cntS}[c] - \text{cntT}[c] \rvert$ 个 $c$。追加后两串对每个 $c$ 的计数均为 $\max(\text{cntS}[c], \text{cntT}[c])$，故互为字母异位词；总步数 $= \sum_c \lvert \text{cntS}[c] - \text{cntT}[c] \rvert$。∎

**定理**：最少步数为 $\displaystyle\sum_c \big| \text{cntS}[c] - \text{cntT}[c] \big|$。

**证明**：由引理 2，任何合法方案的步数不低于该值；由引理 3，该值可以取到。下界与可达匹配，故为最优。∎

> 💡 **证明结构复盘**：这是「**逐部件下界 + 构造达到下界**」的标准范式——引理 2 说明每个字符的频率差是不可压缩的成本（下界），引理 3 给出恰好支付这些成本的方案（可达）。等号成立条件 $m_c = \max$ 还顺带解释了 §4 第 2 条：往两边同时补会让 $m_c > \max$，白花步数。这套「下界 + 构造」骨架适用于绝大多数「最少操作次数」型问题。

## 6. 复杂度分析

- **时间复杂度**：$O(n + m + \lvert\Sigma\rvert) = O(n + m)$，其中 $\lvert\Sigma\rvert = 26$ 为字符集大小。两次线性扫描构建 `diff`，一次 26 格扫描求和；$n = m = 2 \times 10^5$ 时约 $4 \times 10^5$ 次加减。至少要读完两个串才能知道频率，$\Omega(n + m)$ 不可避开，已是理论最优。
- **空间复杂度**：$O(\lvert\Sigma\rvert) = O(1)$，仅一个 26 长度的 `diff` 数组，与输入规模无关。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int minSteps(string s, string t) {
        int diff[26] = {0};                  // diff[c] = cntS[c] - cntT[c]
        for (char c : s) diff[c - 'a']++;    // ① s 的字符记正
        for (char c : t) diff[c - 'a']--;    // ② t 的字符记负
        int ans = 0;
        for (int i = 0; i < 26; ++i)         // ③ 累加绝对差
            ans += abs(diff[i]);
        return ans;
    }
};
```

### Python

```python
class Solution:
    def minSteps(self, s: str, t: str) -> int:
        diff = [0] * 26
        for c in s:
            diff[ord(c) - 97] += 1     # ① s 的字符记正
        for c in t:
            diff[ord(c) - 97] -= 1     # ② t 的字符记负
        return sum(abs(x) for x in diff)
```

### Python（Counter 变体）

```python
from collections import Counter

class Solution:
    def minSteps(self, s: str, t: str) -> int:
        diff = Counter(s)
        diff.subtract(t)               # 必须用 subtract：保留负值
        return sum(abs(v) for v in diff.values())
```

> ⚠️ `Counter(s) - Counter(t)` 走的是 `__sub__`，会**丢弃非正项**，算出来是 $\sum\text{正差}$——那是 1347 的答案；`subtract` 方法**保留负值**，才是本题要的 $\sum \lvert \text{diff} \rvert$。一字之差，答案减半。

## 8. 边界情况与易错点

1. **公式记串成 1347（最高频 WA 点）**：1347 等长 + 可替换，答案是 $\sum\text{正差}$；本题不等长 + 只能追加，答案是 $\sum \lvert \text{diff} \rvert$。若误用正差和，`s = "a"`、`t = "b"` 会算出 0 而非 2。提交前用两个自造用例拦截：`"night"/"thing"` → 0，`"a"/"b"` → 2。

2. **`Counter` 的 `-` 运算符 vs `subtract` 方法**：见 §7 的警告框。前者丢非正项（1347 语义），后者保留负值（本题语义），不可混用。

3. **操作对象是两个串**：题目允许往 `s` **或** `t` 追加（1347 只能改 `t`）。本题中「只能改一边」的公式会变成 $\sum_c \max(0, \text{cntS}[c] - \text{cntT}[c])$，是另一个答案——读清操作对象再动笔。

4. **别往两边同时补**：对某个字符，把双方都追加到超过 $\max$ 的同一计数，每多 1 层白花 2 步。正确姿势是只补少的一方，补到 $\max$ 为止。

5. **C++ 下标转换**：`diff[c - 'a']`——直接用 `diff[c]` 会越界或读到脏数据（`char` 隐式转 `int` 可能为负，取决于平台 `char` 的符号性）。

6. **两端的 sanity check**：两串完全相同（且互为异位词）→ 答案 0；两串无任何公共字符 → 答案 $\lvert s \rvert + \lvert t \rvert$。用这两端心算一遍能拦截绝大多数公式错误。

7. **本题无溢出风险**：答案上界 $4 \times 10^5$，`int` 累加毫无压力。不过「先判断值域再选类型」的习惯不能省——本题只是恰好安全。

**延伸思考**：

- **若允许「追加或删除」**？每个字符的终计数可取 $[\min, \max]$ 中任意值，最优取 $\min$（多的一侧直接删，比少的一侧追上来得省），答案 $= \sum\lvert\text{diff}\rvert - 2\min(P, N)$（$P$、$N$ 分别为正差和与负差绝对值和）。等长时 $P = N$，退化为 1347 的 $\sum\text{正差}$。
- **若只能追加到 `t`**？`s` 不能动，`t` 的每个计数必须追平 $\text{cntS}[c]$，答案 $= \sum_c \max(0, \text{cntS}[c] - \text{cntT}[c]) = \sum\text{正差}$——形式上回到了 1347 的公式，但推导路径完全不同。
- **若给定终长 $L \ge L^*$**？答案 $= 2L - \lvert s \rvert - \lvert t \rvert$：多出的 $L - L^*$ 层每层向两串同步追加同一批字符即可，不破坏异位词性质。
- **若字符集是全体 Unicode**？把 `diff[26]` 换成哈希表，复杂度变为 $O(n + m + \lvert\Sigma\rvert)$，思路不变。
