# LeetCode 有限重边的最小阈值路径 题解

## 1. 题目概述

- **标题 / 题号**：有限重边的最小阈值路径（#3924，hard）
- **链接**：https://leetcode.cn/problems/minimum-threshold-path-with-limited-heavy-edges/
- **来源**：LeetCode 第 182 场双周赛 Q4
- **难度**：困难
- **标签**：图、最短路、二分查找、0-1 BFS

**题意**：给定 $n$ 个节点的无向带权图，边为 `edges[i] = [u, v, w]`。再给 `source`、`target`、`k`。

对阈值 $T$：边权 $\le T$ 的边称**轻边**，$> T$ 的边称**重边**。若一条从 `source` 到 `target` 的路径含**至多 $k$ 条重边**，称其**有效**。

求使「至少存在一条有效路径」的**最小整数阈值 $T$**；不存在则返回 $-1$。

**约束**：

- $1 \le n \le 10^3$，$0 \le edges.length \le 10^3$
- $1 \le w_i \le 10^9$
- $0 \le source, target \le n-1$，$0 \le k \le edges.length$

## 2. 示例

**示例 1**

```text
输入：n = 6, edges = [[0,1,5],[1,2,3],[3,4,4],[4,5,1],[1,4,2]], source = 0, target = 3, k = 1
输出：4
解释：T = 4 时轻边为 {1-2(3), 3-4(4), 4-5(1), 1-4(2)}，重边只有 {0-1(5)}；
     路径 0→1→4→3 只用 1 条重边，满足 k = 1。T = 3 时 3-4 也变成重边，任何路径都至少 2 条重边。
```

**示例 2**

```text
输入：n = 6, edges = [[0,1,3],[1,2,4],[3,4,5],[4,5,6]], source = 0, target = 4, k = 1
输出：-1
解释：0 与 4 之间根本没有路径（图不连通），无论阈值多大都不可达。
```

**示例 3**

```text
输入：n = 4, edges = [[0,1,2],[1,2,2],[2,3,2],[3,0,2]], source = 0, target = 0, k = 0
输出：0
解释：起点即终点，不需要经过任何边，最小的阈值是 0。
```

## 3. 解题思路

### 3.1 暴力思路

对每个可能的重边条数上限，或者对每个路径枚举「第 $k+1$ 大的边权」，都会退化成枚举路径（指数级）。另一条朴素路线是：对每个候选阈值 $T$ 做一次 BFS/DFS 判连通并统计重边数——单次 $O(n+m)$ 没问题，但候选 $T$ 有 $10^9$ 种取值，不能逐个试。

**关键压缩**：答案一定是 $0$ 或**某条边的权重**。因为把 $T$ 从 $w-1$ 提到 $w$ 只会让「恰好权重为 $w$ 的边」从重边变轻边，其它边的分类不变；所以在两个相邻边权之间，可行性是不变的。候选只有 $m+1 \le 1001$ 个。

### 3.2 核心观察：可行性关于 $T$ 单调 + 0-1 BFS 判重边数

![阈值把边分成轻/重两类，可行性关于阈值单调](images/bw182_q4_threshold_model.svg)

- **单调性**：$T$ 变大 $\Rightarrow$ 轻边集合变大、重边集合变小 $\Rightarrow$ 任何在 $T$ 下有效的路径在 $T' > T$ 下仍有效。所以「存在有效路径」是关于 $T$ 的**单调谓词**，可以二分。
- **判定子问题**：给定 $T$，求 `source` 到 `target` 的**最少重边数**。把每条边看成权 $0$（轻）或 $1$（重），就是**边权只有 0/1 的最短路**，用 **0-1 BFS**（双端队列）在 $O(n+m)$ 内解决。若最少重边数 $\le k$，则 $T$ 可行。
- **答案下界**：$T$ 可以小到 $0$（所有边都算重边，只要存在一条边数 $\le k$ 的路径就可行）；`source == target` 时路径长度为 0，答案为 0。

### 3.3 算法流程

![0-1 BFS：轻边权 0、重边权 1，用双端队列维护有序性](images/bw182_q4_01bfs.svg)

```text
1. 候选阈值 cand = 排序去重后的 {0} ∪ {所有边权}
2. 在 cand 上二分：
     mid = 中位数，T = cand[mid]
     若 feasible(T)：ans = T，向右半区间收缩（找更小的）
     否则：向左半区间不含地收缩
3. 返回 ans（都不行则 -1）

feasible(T):
     0-1 BFS：dist[source] = 0，其余 INF
     弹出 u，对每条边 (u,v,w)：c = (w > T ? 1 : 0)
     若 dist[u] + c < dist[v]：更新，c == 0 则 push_front，否则 push_back
     返回 dist[target] <= k
```

### 3.4 示例演算

![示例 1：T = 4 时存在 0 → 1 → 4 → 3 的有效路径](images/bw182_q4_walkthrough.svg)

示例 1 的边权排序后为 $\{1, 2, 3, 4, 5\}$，候选阈值为 $\{0, 1, 2, 3, 4, 5\}$：

| $T$ | 重边集合 | 最少重边数（0→3） | $\le k=1$？ |
|-----|----------|--------------------|--------------|
| 0 | 全部 5 条 | 3（如 0→1→4→3） | ✗ |
| 2 | {1-2(3), 3-4(4), 0-1(5)} | 2 | ✗ |
| 3 | {3-4(4), 0-1(5)} | 2 | ✗ |
| 4 | {0-1(5)} | 1（0→1→4→3） | ✓ |
| 5 | 空 | 0 | ✓ |

最小的可行阈值是 4，与题面一致。二分只需 $\lceil \log_2 6 \rceil = 3$ 次 `feasible` 调用即可定位。

## 4. 算法细节

1. **候选集合**：必须显式加入 $0$，否则「所有边都是重边也能走通」的情形（例如 $k \ge$ 最短路径边数）会漏掉答案 0。
2. **0-1 BFS 的实现**：用 `deque`，代价 0 的松弛 `push_front`、代价 1 的 `push_back`；每个点可能被多次入队，但只有在 `dist` 被改进时才入队，总复杂度仍是 $O(n+m)$。
3. **`dist` 初值**：用一个足够大的数（如 `1<<29`），不要用 `INT_MAX` 参与加法以免溢出。
4. **不可达**：`dist[target]` 保持 `INF`，`INF <= k` 为假，判定自动失败，无需特判。
5. **`source == target`**：`dist[source] = 0 <= k` 恒成立，二分会收敛到候选最小值 0，正好符合示例 3。
6. **重边定义**：`w > T` 才算重边（`w == T` 是轻边），这个等号方向直接决定示例 1 的答案是否正确。
7. **二分写法**：在有序候选数组上用「找第一个可行」的下标二分，最后返回 `cand[idx]`。

## 5. 正确性证明

**引理 1（可行性单调）**：若阈值 $T$ 可行，则任意 $T' \ge T$ 也可行。

**证明**：$T' \ge T$ 时，满足 $w \le T$ 的边一定满足 $w \le T'$，故轻边集合单调扩大、重边集合单调缩小。原来那条含 $\le k$ 条重边的有效路径在 $T'$ 下的重边数只会更少，仍然 $\le k$，故 $T'$ 可行。∎

**引理 2（0-1 BFS 正确）**：`feasible(T)` 中 0-1 BFS 算出的 `dist[v]` 等于从 `source` 到 $v$ 的所有路径中「重边条数」的最小值。

**证明**：把重边视作权 1、轻边视作权 0，`dist` 就是该 0/1 权图上的最短路。0-1 BFS 的正确性来自：队列中的距离值只有 $d$ 与 $d+1$ 两种且按非降序出队（`push_front` 保持同层在前、`push_back` 把 $d+1$ 放后面），因此每个点出队时其 `dist` 已是最小值，与 Dijkstra 的论证一致。∎

**引理 3（答案必是 0 或某条边权）**：设 $T^\*$ 是最小可行阈值，则 $T^\* = 0$ 或 $T^\*$ 等于某条边的权重。

**证明**：若 $T^\* > 0$ 且不等于任何边权，令 $w_{\max}$ 为最小的「大于 $T^\*$」的边权（不存在则说明所有边权都 $< T^\*$，此时 $T^\*-1$ 与 $T^\*$ 把边分成完全相同的轻/重两类，与 $T^\*$ 最小矛盾）。于是 $T^\*-1$ 与 $T^\*$ 之间没有边权，二者产生的轻/重划分相同，可行性相同，故 $T^\*-1$ 也最小可行，矛盾。∎

**定理**：算法返回使有效路径存在的最小阈值；若无解返回 $-1$。

**证明**：由引理 3，只需在候选集合 $C = \{0\} \cup \{w_i\}$ 中搜索；由引理 1，可行性在 $C$ 上单调，故「找最小的可行元素」可用二分。每次二分的判定由引理 2 保证正确（`dist[target] <= k` 当且仅当存在含 $\le k$ 条重边的路径）。二分结束时得到的 `ans` 即最小可行候选；若所有候选都不可行（含图不连通），返回 $-1$ 正确。∎

## 6. 复杂度分析

- **时间**：候选数 $O(m)$；二分 $O(\log m)$ 次判定，每次 0-1 BFS 为 $O(n + m)$；总计 $O((n+m)\log m)$。$n, m \le 10^3$ 时约 $10^4$ 量级操作。
- **空间**：邻接表 $O(n + m)$，`dist` 数组 $O(n)$，候选数组 $O(m)$，`deque` 最坏 $O(n + m)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minimumThreshold(int n, vector<vector<int>>& edges, int source, int target, int k) {
        vector<vector<pair<int, int>>> adj(n);
        vector<int> cand(1, 0);
        for (auto& e : edges) {
            adj[e[0]].push_back({e[1], e[2]});
            adj[e[1]].push_back({e[0], e[2]});
            cand.push_back(e[2]);
        }
        sort(cand.begin(), cand.end());
        cand.erase(unique(cand.begin(), cand.end()), cand.end());
        const int INF = 1 << 29;
        auto feasible = [&](int limit) {
            vector<int> dist(n, INF);
            deque<int> dq;
            dist[source] = 0;
            dq.push_back(source);
            while (!dq.empty()) {
                int u = dq.front();
                dq.pop_front();
                for (auto& nb : adj[u]) {
                    int v = nb.first, w = nb.second;
                    int c = (w > limit) ? 1 : 0;
                    if (dist[u] + c < dist[v]) {
                        dist[v] = dist[u] + c;
                        if (c == 0) dq.push_front(v);
                        else dq.push_back(v);
                    }
                }
            }
            return dist[target] <= k;
        };
        int lo = 0, hi = (int)cand.size() - 1, ans = -1;
        while (lo <= hi) {
            int mid = (lo + hi) / 2;
            if (feasible(cand[mid])) { ans = cand[mid]; hi = mid - 1; }
            else lo = mid + 1;
        }
        return ans;
    }
};
```

### Python

```python
from collections import deque


class Solution:
    def minimumThreshold(self, n: int, edges: list[list[int]], source: int,
                         target: int, k: int) -> int:
        adj = [[] for _ in range(n)]
        for u, v, w in edges:
            adj[u].append((v, w))
            adj[v].append((u, w))

        def feasible(limit: int) -> bool:
            INF = float("inf")
            dist = [INF] * n
            dist[source] = 0
            dq = deque([source])
            while dq:
                u = dq.popleft()
                du = dist[u]
                for v, w in adj[u]:
                    c = 1 if w > limit else 0
                    if du + c < dist[v]:
                        dist[v] = du + c
                        if c == 0:
                            dq.appendleft(v)
                        else:
                            dq.append(v)
            return dist[target] <= k

        cand = sorted({0} | {w for _, _, w in edges})
        lo, hi = 0, len(cand) - 1
        ans = -1
        while lo <= hi:
            mid = (lo + hi) // 2
            if feasible(cand[mid]):
                ans = cand[mid]
                hi = mid - 1
            else:
                lo = mid + 1
        return ans
```

## 8. 边界情况与易错点

1. **`source == target`**：答案为 0（示例 3）。候选集合必须包含 0，否则会返回 $1$ 或边权最小值。
2. **图不连通**：`dist[target]` 恒为 `INF`，所有候选都不可行，返回 $-1$（示例 2）。
3. **`k` 足够大**：当 $k \ge$ 最短路径的边数时，$T = 0$ 就可行（所有边都是重边也能走通），答案 0。
4. **重边的等号**：$w > T$ 才是重边，$w = T$ 是轻边。写成 `>=` 会让示例 1 的答案从 4 变成 5。
5. **`INF` 溢出**：用 `INT_MAX` 做 `dist[u] + c` 会溢出成负数，必须用一个「大但安全」的值。
6. **0-1 BFS 的入队方向**：轻边 `push_front`、重边 `push_back`，写反会退化成普通 BFS，得到的不是最少重边数。
7. **多重边**：题面允许多条不同权重的边连接同一对节点，邻接表天然支持，无需特判。
8. **候选去重**：边权可能大量重复，不去重不影响正确性但会拖慢二分。
