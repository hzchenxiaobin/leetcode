# LeetCode 使二进制字符串连贯的最少翻转次数 题解

## 1. 题目概述

- **标题 / 题号**：使二进制字符串连贯的最少翻转次数（#3922，medium）
- **链接**：https://leetcode.cn/problems/minimum-flips-to-make-binary-string-coherent/
- **来源**：LeetCode 第 182 场双周赛 Q2
- **难度**：中等
- **标签**：字符串、枚举、贪心

**题意**：给定二进制字符串 $s$。若一个字符串**不含** `"011"` 或 `"110"` 作为**子序列**，称其**连贯**。一次操作可以翻转任意一位。求使 $s$ 连贯所需的**最少**翻转次数。

**约束**：

- $1 \le s.length \le 10^5$
- $s[i] \in \{'0', '1'\}$

## 2. 示例

**示例 1**

```text
输入：s = "1010"
输出：1
解释：翻转 s[0] 得到 "0010"，不含 "011" 也不含 "110"。（也可翻转 s[2] 得到 "1000"。）
```

**示例 2**

```text
输入：s = "0110"
输出：1
解释：翻转 s[1] 得到 "0010"，所有禁止子序列消失。
```

**示例 3**

```text
输入：s = "1000"
输出：0
解释：只含一个 1，任何子序列都不可能是 "011" 或 "110"。
```

## 3. 解题思路

### 3.1 暴力思路

直接对每个候选目标串检查连贯性，再取 Hamming 距离最小者：目标串有 $2^n$ 个，$n = 10^5$ 时完全不可行。即便把检查优化到 $O(n)$，枚举部分仍是 $O(2^n)$。所以必须**刻画连贯串的结构**，把「$2^n$ 个候选」压缩成常数类候选。

### 3.2 核心观察：连贯串只有三类

![连贯 ⇔ 每个 0 的左右两侧各至多一个 1](images/bw182_q2_coherent_shapes.svg)

把禁止子序列翻译成「局部条件」：

- `"011"` 是子序列 $\iff$ 存在一个 `0`，它**后面**至少有两个 `1`；
- `"110"` 是子序列 $\iff$ 存在一个 `0`，它**前面**至少有两个 `1`。

于是**连贯 $\iff$ 每个 `0` 之前至多一个 1、之后至多一个 1**。

设整个串中 `1` 的个数为 $m$：

| $m$ | 允许的串 | 说明 |
|-----|----------|------|
| $m \le 1$ | 任意位置放这唯一（或零个）1 | 没有两个 1，禁止子序列无从谈起 |
| $m = 2$ | 必为 `1` + 若干 `0` + `1` | 0 若在第一个 1 之前，则它右边有两个 1（`011`）；0 若在第二个 1 之后，则它左边有两个 1（`110`）。所以 0 只能夹在两个 1 之间，两个 1 分居首尾 |
| $m \ge 3$ | 只能是**全 1** | 任取一个 0，它左侧、右侧的 1 的个数之和为 $m \ge 3$，故至少有一侧 $\ge 2$，立即违规；所以根本不能有 0 |

由此得到三类候选目标串，逐个算 Hamming 距离取最小：

1. **至多一个 1**：保留任意一个 1、其余 1 全翻成 0，代价 $m - 1$（$m \ge 1$；$m = 0$ 时代价 0）；
2. **全 1**：把所有 0 翻成 1，代价 $n - m$；
3. **`1` + 若干 0 + `1`**：要求 $s[0] = 1$、$s[n-1] = 1$、中间全 0，代价为

$$\big[s[0] \ne '1'\big] + \big[s[n-1] \ne '1'\big] + \#\{1 \le i \le n-2 : s[i] = '1'\}$$

三类各扫一遍或一遍统计即可，总复杂度 $O(n)$。

### 3.3 算法流程

![示例 1 演算：三类形态各算一次代价](images/bw182_q2_walkthrough.svg)

```text
1. ones = s 中 '1' 的个数
2. best = max(ones - 1, 0)                  // ① 至多一个 1
3. best = min(best, n - ones)               // ② 全 1
4. 若 n >= 2：                              // ③ 1 0…0 1
       cost = (s[0] != '1') + (s[n-1] != '1') + 中间 1 的个数
       best = min(best, cost)
5. 返回 best
```

### 3.4 示例演算

**示例 1**：`s = "1010"`，`ones = 2`，`zeros = 2`。

| 候选 | 计算 | 代价 |
|------|------|------|
| ① 至多一个 1 | $m - 1 = 2 - 1$ | 1 |
| ② 全 1 | $n - m = 4 - 2$ | 2 |
| ③ `1 0 0 1` | $s[0]='1'$ 不翻，$s[3]='0'$ 翻 1 次，中间 `"01"` 含 1 个 1 再翻 1 次 | 2 |

最小为 1，与题面一致。

**示例 2**：`s = "0110"`，`ones = 2` → ① 代价 1；② 代价 2；③ 需翻 $s[0]$、中间 `"11"` 两个 1 → 3。答案 1。

**示例 3**：`s = "1000"`，`ones = 1` → ① 代价 $\max(1-1,0) = 0$，已连贯，答案 0。

## 4. 算法细节

1. **只看个数与两端的字符**：三类候选的代价都只依赖 `ones`、`n`、`s[0]`、`s[n-1]` 与「中间 1 的个数」，可以一次遍历全算出来。
2. **`m = 0` 的处理**：`max(ones - 1, 0)` 使「全 0」串的代价为 0（它本来就连贯）；若写成 `ones - 1` 会得到 $-1$，是常见的实现 bug。
3. **`n = 1` 的处理**：第三类要求首尾都是 1，长度为 1 时它是同一个位置，需特判跳过（或允许它与②重复，代价相同也不影响答案，但语义上应跳过）。
4. **布尔转整数**：C++ 中 `(s[0] != '1')` 直接是 `int`；Python 中 `bool` 可以参与加法，`(s[0] != "1") + (s[-1] != "1")` 得到 0/1/2。
5. **中间 1 的个数**：`s[1:-1]` 在 Python 里对 $n = 1$ 会得到空串；C++ 用下标循环 `1 .. n-2`。
6. **无需构造目标串**：直接算 Hamming 距离，省内存也省时间。

## 5. 正确性证明

**引理 1（子序列条件的重述）**：字符串含 `"011"` 子序列 $\iff$ 存在某个 `0`，其**右侧**至少有两个 `1`；含 `"110"` 子序列 $\iff$ 存在某个 `0`，其**左侧**至少有两个 `1`。

**证明**：`"011"` 作为子序列出现，当且仅当存在下标 $i < j < k$ 使 $s_i = 0, s_j = s_k = 1$，即以 $i$ 处的 0 为界右侧至少两个 1；反之亦然。`"110"` 对称（取 $i < j < k$ 为 $1,1,0$，以 $k$ 处的 0 为界左侧两个 1）。∎

**引理 2（连贯串的分类）**：设串中 1 的个数为 $m$，则串连贯当且仅当属于以下三类之一：$m \le 1$；$m = 2$ 且形如 `1 0…0 1`；$m \ge 3$ 且全为 1。

**证明**：
- $m \le 1$：任何 0 的两侧 1 的个数之和不超过 1，由引理 1 不可能含禁止子序列。
- $m = 2$：设两个 1 在下标 $p < q$。若存在 0 于 $p$ 之前，则其右侧有两个 1 → `"011"`；若存在 0 于 $q$ 之后，则其左侧有两个 1 → `"110"`。故所有 0 必须位于 $(p, q)$ 之间，即 $p = 0$、$q = n-1$，串形如 `1 0…0 1`。反之这类串显然连贯。
- $m \ge 3$：若存在 0，则该 0 左侧与右侧的 1 的个数之和为 $m \ge 3$，至少一侧 $\ge 2$，由引理 1 立即出现禁止子序列。故不存在 0，即全 1；反之全 1 串连贯。

∎

**定理**：算法返回的 `best` 等于使 $s$ 连贯的最少翻转次数。

**证明**：由引理 2，任何连贯串必属三类之一，故最优解一定在下列三类中：

- 第一类（1 的个数 $\le 1$）：把 $s$ 变成「至多一个 1」的最省方式就是保留一个已有的 1、其余翻成 0，代价 $m-1$（$m \ge 1$）或 0（$m = 0$），即 `max(m-1, 0)`，这是该类的最小代价；
- 第二类（全 1）：唯一目标串，代价 $n - m$，即该类最小代价；
- 第三类：目标串唯一（`1 0…0 1`），代价按位统计，即该类最小代价。

算法取三类的最小值，故等于全局最小翻转次数。∎

## 6. 复杂度分析

- **时间**：$O(n)$。统计 `ones` 与中间 1 的个数各一遍线性扫描（可合并为一遍）。
- **空间**：$O(1)$，只用到若干计数器。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minFlips(string s) {
        int n = s.size();
        int ones = 0;
        for (char c : s) ones += (c == '1');
        int best = max(ones - 1, 0);
        best = min(best, n - ones);
        if (n >= 2) {
            int cost = (s[0] != '1') + (s[n - 1] != '1');
            for (int i = 1; i + 1 < n; i++) cost += (s[i] == '1');
            best = min(best, cost);
        }
        return best;
    }
};
```

### Python

```python
class Solution:
    def minFlips(self, s: str) -> int:
        n = len(s)
        ones = s.count("1")
        zeros = n - ones
        best = max(ones - 1, 0)          # 至多保留一个 1
        best = min(best, zeros)          # 全 1
        if n >= 2:                       # "1" + 若干个 0 + "1"
            best = min(best, (s[0] != "1") + (s[-1] != "1") + s[1:-1].count("1"))
        return best
```

## 8. 边界情况与易错点

1. **`ones = 0`**：全 0 串本来就连贯，`max(ones-1, 0)` 返回 0；若写成 `ones - 1` 会得到 $-1$ 并被 `min` 选中，答案错误。
2. **`n = 1`**：只有 `"0"`、`"1"` 两种串，都连贯，答案 0。第三类候选在 $n = 1$ 时没有意义，需跳过。
3. **`n = 2`**：`"11"` 属第三类（`1 0…0 1` 且中间为空），代价 0，答案 0——注意 `s[1:-1]` 为空串的写法在 Python 中安全。
4. **两个 1 必须分居首尾**：第三类不是「任意两个 1 之间可以放 0」，而是必须 $p = 0, q = n-1$；误以为可以任意摆放会漏算代价。
5. **`m ≥ 3` 时不可能是「全 1 以外」的形态**：别试图构造「三段 0」的候选，引理 2 已排除。
6. **子序列 ≠ 子串**：`"011"` 是**子序列**，字符可以不连续。若误当子串处理，会把 `"00110"` 之类判成连贯。
7. **翻转计数方向**：把 `1` 翻成 `0` 或反之，代价都是 1，只需统计不一致的位数。
