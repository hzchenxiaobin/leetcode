# LeetCode 摘樱桃 II 题解

## 1. 题目概述

- **标题 / 题号**：摘樱桃 II（#1463，hard）
- **链接**：https://leetcode.cn/problems/cherry-pickup-ii/
- **来源**：LeetCode 第 27 场双周赛 Q4
- **难度**：困难
- **标签**：数组、动态规划、矩阵

**题意**：给定 $rows \times cols$ 的矩阵 grid，grid[i][j] 是该格樱桃数。两个机器人：机器人 1 从 $(0,0)$ 出发，机器人 2 从 $(0, cols-1)$ 出发。每一步两者各从 $(i,j)$ 移动到 $(i+1, j-1)$、$(i+1, j)$ 或 $(i+1, j+1)$（三选一，可不同）。经过格子摘走其全部樱桃；**两者同时到达同一格时樱桃只算一份**；不能越界；最终都停在最后一行。求两机器人能摘到的樱桃总数最大值。

**约束**：

- $2 \le rows, cols \le 70$
- $0 \le grid[i][j] \le 100$

## 3. 解题思路

### 3.1 暴力思路

两个机器人各自有 3 种下移方向，从第 0 行到最后一行共 $rows$ 步，搜索空间 $3^{2 \cdot rows}$——$rows = 70$ 时约 $3^{140} \approx 10^{66}$，完全不可行。朴素的记忆化 DFS（状态 $(r, c_1, c_2)$）已经能把复杂度压到 $O(rows \cdot cols^2 \cdot 9)$，本质上与下面要写的 DP 相同；本题的正解就是把这条记忆化思路显式写成**自底向上的多阶段 DP**。

### 3.2 核心观察：两机器人永远同步，「行」是天然的阶段

![状态设计：列对 (c1,c2) 刻画同行局面](images/bw27_q4_state_design.svg)

规则规定两个机器人每步**同时**从第 $i$ 行移到第 $i+1$ 行——它们永远在同一行！于是整个联合状态只需要 $(r, c_1, c_2)$ 三个维度：$r$ 是阶段，$(c_1, c_2)$ 是行内位置对。不需要记录两个机器人各自的行号，这正是题面「同步移动」规则送出的最大红利。

定义：

$$dp[r][c_1][c_2] = \text{两机器人位于第 } r \text{ 行、列 } c_1 \text{ 与 } c_2 \text{ 时，从第 } r \text{ 行摘到底部的最大总数}$$

当前行的收获 $gain = grid[r][c_1] + grid[r][c_2]$，若 $c_1 = c_2$ 则只算一份。

### 3.3 状态转移：上一行 3×3 邻域取最大

![自底向上递推与 3×3 来源](images/bw27_q4_row_dp_flow.svg)

$$dp[r][c_1][c_2] = gain(r, c_1, c_2) + \max_{\substack{j_1 \in \{c_1-1, c_1, c_1+1\} \cap [0, cols) \\ j_2 \in \{c_2-1, c_2, c_2+1\} \cap [0, cols)}} dp[r-1][j_1][j_2]$$

初始 $dp[0][0][cols-1] = grid[0][0] + grid[0][cols-1]$（$cols \ge 2$ 保证两起点不同列）；其余状态初始化为 $-1$ 表示**不可达**——不是所有 $(c_1, c_2)$ 都在第 $r$ 行真的能出现（例如第 1 行最多只有 $3 \times 3 = 9$ 种位置对）。樱桃非负，真实值 $\ge 0$，所以 $-1$ 可以安全地充当「负无穷」。答案为 $\max_{c_1, c_2} dp[rows-1][c_1][c_2]$。

空间可用滚动数组压到 $O(cols^2)$：转移只依赖上一行。

### 3.4 示例演算

![示例演算：24 的逐行 dp 轨迹](images/bw27_q4_example_walkthrough.svg)

以示例 1 为例（$4 \times 3$ 网格）：$dp[0][0][2] = 3 + 1 = 4$；最优路径上 $dp[1][0][1] = 4 + 2 + 5 = 11$；$dp[2][1][2] = 11 + 5 + 5 = 21$；$dp[3][0][2] = 21 + 2 + 1 = 24$。最优方案让两个机器人在第 1 行分踞第 0、1 列，把 2 和 5 一网打尽，再在底部合围两个 5。

## 4. 算法细节

1. **维度顺序与初始化**：`dp[r][c1][c2]` 全部初始化为 $-1$（不可达哨兵），仅 $dp[0][0][cols-1]$ 赋初值。转移时跳过来源为 $-1$ 的项；若某状态所有来源都不可达，它自身保持 $-1$。
2. **gain 的分支**：$c_1 = c_2$ 时 `gain = grid[r][c1]`，否则 `grid[r][c1] + grid[r][c2]`。两机器人可以合法地走到同一格（规则只说樱桃算一份，没说禁止同格）。
3. **边界裁剪**：$j_1, j_2$ 的三选一循环里做 $0 \le j < cols$ 判断。cols $= 2$ 时起点 $(0, 0)$ 与 $(0, 1)$ 相邻且都只有两个合法去向，边界判断必须严谨。
4. **答案的位置**：最后一行任意 $(c_1, c_2)$ 都可能是终点（题目只要求到达最后一行，不指定列），对整个二维平面取 max。由于 $dp$ 值非负（可达者），从 0 起取 max 即可。
5. **滚动数组**：`ndp` 每行新建并整体置 $-1$，算完与 `dp` 交换。注意不能原地更新——同一行的 $(c_1, c_2)$ 之间不存在转移（机器人不能横移），但行内旧值会被上一行数据污染。
6. **为什么不怕「漏掉跨行交互」**：樱桃摘走发生在「经过」时，两机器人同步经过第 $r$ 行；任何一行的贡献只由该行的 $(c_1, c_2)$ 决定，与路径的其余部分无关——这是无后效性的直观来源（§5 有严格论证）。

## 5. 正确性证明

**引理 1（同步性与合法轨迹的刻画）**：一条合法的双机器人轨迹可唯一表示为序列 $\big((c_1^{(r)}, c_2^{(r)})\big)_{r=0}^{rows-1}$，其中 $c_1^{(0)} = 0$、$c_2^{(0)} = cols - 1$，且对每个 $r \ge 1$，$|c_1^{(r)} - c_1^{(r-1)}| \le 1$、$|c_2^{(r)} - c_2^{(r-1)}| \le 1$，各列号均在 $[0, cols)$ 内。

**证明**：两机器人从第 0 行出发、每步同步下移一行且列变化量为 $-1, 0, +1$ 之一，故任意时刻两者行号相同且等于已走步数；列的约束逐条对应规则。反之，任何满足上述约束的序列按 $r$ 逐行执行即得合法轨迹。两者互相构造，故为一一对应。∎

**引理 2（轨迹的收益分解）**：轨迹 $\big((c_1^{(r)}, c_2^{(r)})\big)$ 的总收获为

$$\sum_{r=0}^{rows-1} g(r, c_1^{(r)}, c_2^{(r)}), \qquad g(r, a, b) = grid[r][a] + \begin{cases} grid[r][b], & a \ne b \\ 0, & a = b \end{cases}$$

**证明**：机器人 1 经过且仅经过 $\{(r, c_1^{(r)})\}$，机器人 2 经过 $\{(r, c_2^{(r)})\}$；被经过的格子贡献其樱桃一次，被两者同时经过（即 $c_1^{(r)} = c_2^{(r)}$ 的行）的格子也只贡献一次（题意），恰为 $g$ 的定义。∎

**定理（DP 正确性）**：对一切 $r \ge 0$ 与可达状态 $(c_1, c_2)$，$dp[r][c_1][c_2]$ 等于「两机器人位于 $(r, c_1)$ 与 $(r, c_2)$ 的所有合法轨迹后缀」的最大收益；算法返回值是全局最大收益。

**证明**：对 $r$ 归纳。$r = 0$：可达状态仅 $(0, cols-1)$，唯一后缀是只含第 0 行的轨迹，收益 $g(0, 0, cols-1) = grid[0][0] + grid[0][cols-1]$（$cols \ge 2$ 两列不同），与初值一致；其余 $(c_1, c_2)$ 不可达，$dp = -1$ 哨兵正确。设第 $r - 1$ 行归纳成立。第 $r$ 行状态 $(c_1, c_2)$ 的任一后缀轨迹 $\tau$ 去掉第 $r$ 行一步，得第 $r - 1$ 行状态 $(j_1, j_2)$ 的后缀轨迹 $\tau'$（引理 1 保证 $j_1, j_2$ 落在三选一邻域内），且由引理 2，$\text{val}(\tau) = g(r, c_1, c_2) + \text{val}(\tau')$。反之任一 $\tau'$ 配上一步到达 $(c_1, c_2)$ 也构成合法 $\tau$。于是后缀最优值满足

$$opt(r, c_1, c_2) = g(r, c_1, c_2) + \max_{j_1, j_2} opt(r - 1, j_1, j_2)$$

最大值取遍可达的 $(j_1, j_2)$——不可达者 $dp = -1$ 被跳过，与 $opt$ 只在可达状态上定义一致（$g \ge 0$ 且所有可达 $opt \ge 0$，$-1$ 小于任何可达值，跳过不影响 max）。按此式更新的 $dp[r][c_1][c_2]$ 等于 $opt(r, c_1, c_2)$，归纳成立。最终，全局最优轨迹按第 $rows-1$ 行的终止位置 $(c_1, c_2)$ 分类，每类的最佳值即 $opt(rows-1, c_1, c_2)$，故 $\max_{c_1, c_2} dp[rows-1][c_1][c_2]$ 为全局最大收益；不可达状态为 $-1$ 不会胜过任何可达状态（$\ge 0$）。∎

## 6. 复杂度分析

- **时间**：$O(rows \cdot cols^2 \cdot 9)$。每行有 $cols^2$ 个状态，每个状态枚举 $3 \times 3 = 9$ 个来源。$70 \times 70^2 \times 9 \approx 3 \times 10^6$，C++ 约 2ms、CPython 约 0.3s。
- **空间**：$O(cols^2)$（滚动数组）或 $O(rows \cdot cols^2)$（保留全表以便重构路径）。$70^2 = 4900$，两个整型数组即可。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int cherryPickup(vector<vector<int>>& grid) {
        int rows = (int)grid.size(), cols = (int)grid[0].size();
        const int NEG = -1;                                  // 哨兵：状态不可达
        // dp[c1][c2]：两机器人同处某行、列 c1 / c2 时，从该行到底的最大总数（滚动）
        vector<vector<int>> dp(cols, vector<int>(cols, NEG));
        dp[0][cols - 1] = grid[0][0] + grid[0][cols - 1];    // cols >= 2，起点不同列
        for (int r = 1; r < rows; ++r) {
            vector<vector<int>> ndp(cols, vector<int>(cols, NEG));
            for (int c1 = 0; c1 < cols; ++c1) {
                for (int c2 = 0; c2 < cols; ++c2) {
                    int best = NEG;
                    for (int j1 = c1 - 1; j1 <= c1 + 1; ++j1) {
                        if (j1 < 0 || j1 >= cols) continue;
                        for (int j2 = c2 - 1; j2 <= c2 + 1; ++j2) {
                            if (j2 < 0 || j2 >= cols) continue;
                            if (dp[j1][j2] < 0) continue;
                            best = max(best, dp[j1][j2]);
                        }
                    }
                    if (best < 0) continue;                  // 来源全不可达 → 本状态不可达
                    int gain = grid[r][c1] + (c1 != c2 ? grid[r][c2] : 0);
                    ndp[c1][c2] = best + gain;
                }
            }
            dp.swap(ndp);
        }
        int ans = 0;
        for (int c1 = 0; c1 < cols; ++c1)
            for (int c2 = 0; c2 < cols; ++c2)
                ans = max(ans, dp[c1][c2]);
        return ans;
    }
};
```

### Python

```python
class Solution:
    def cherryPickup(self, grid: List[List[int]]) -> int:
        rows, cols = len(grid), len(grid[0])
        NEG = -1
        dp = [[NEG] * cols for _ in range(cols)]
        dp[0][cols - 1] = grid[0][0] + grid[0][cols - 1]
        for r in range(1, rows):
            ndp = [[NEG] * cols for _ in range(cols)]
            grow = grid[r]
            for c1 in range(cols):
                for c2 in range(cols):
                    best = NEG
                    for j1 in (c1 - 1, c1, c1 + 1):
                        if 0 <= j1 < cols:
                            for j2 in (c2 - 1, c2, c2 + 1):
                                if 0 <= j2 < cols and dp[j1][j2] > best:
                                    best = dp[j1][j2]
                    if best > NEG:
                        ndp[c1][c2] = best + grow[c1] + (grow[c2] if c1 != c2 else 0)
            dp = ndp
        return max(max(row) for row in dp)
```

> 💡 两份代码均通过全部官方示例（24 / 28 / 22 / 4）。C++ 版与「无记忆化纯 DFS 双机器人搜索」在 2 万组随机小网格（$rows, cols \le 5$）上对拍，失配数为 0；$70 \times 70$ 满规模随机网格下 C++ 约 2ms、Python 约 0.3s。

## 8. 边界情况与易错点

1. **cols = 2**：两起点 $(0,0)$ 与 $(0,1)$ 相邻，且每行只有两列可选；$c_1$ 与 $c_2$ 交叉甚至重合都可能出现，gain 分支与边界判断都要到位。
2. **重合格子只算一份**：gain 里 `c1 != c2` 的判断漏掉的话，重合格会被双倍计入（例如全 1 的 $2\times 2$ 网格会错输出 6 而不是 4）。
3. **不可达哨兵不能用 INT_MIN 直接加**：来源全为 $-1$ 时应保持 $-1$ 而不是 `INT_MIN + gain` 溢出；代码里先判 `best < 0` 再加 gain。
4. **答案在最后一行全平面取 max**：不要只取 $dp[rows-1][0][cols-1]$ 或某个特定列对——终点列不受限制。
5. **滚动数组要整行新建**：行内状态互不转移，但原地复用上一行数组会把「上一行值」误当「本行值」读入。
6. **rows = 2**：只有一次转移，初始状态外其余第 1 行状态只依赖 $dp[0][0][cols-1]$ 这一个来源，逻辑自然覆盖，无需特判。
7. **负值不存在**：$grid[i][j] \ge 0$ 使「最大收益非负」成立，$-1$ 哨兵才安全；若题目改为可负，哨兵得换成更小的值并小心比较逻辑。
