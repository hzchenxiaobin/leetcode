# LeetCode “气球” 的最大数量 题解

## 1. 题目概述

- **标题 / 题号**：“气球” 的最大数量（#1189，easy）
- **链接**：https://leetcode.cn/problems/maximum-number-of-balloons/
- **来源**：LeetCode 第 154 场周赛 Q1
- **难度**：简单
- **标签**：哈希表、字符串、计数

**题意**：给定字符串 `text`，用其中的字母拼单词 `"balloon"`。`text` 里每个字符最多使用一次，顺序任意（可以任意重排、可以丢弃不需要的字母）。返回最多能拼出多少个完整的 `"balloon"`。

**约束**：

- $1 \le \lvert \text{text} \rvert \le 10^4$
- `text` 仅由小写英文字母组成

> 💡 **一句话切入**：这是道「多维资源按比例分配」的签到题——每个单词对每个字母的消耗量是固定的，谁的库存最先见底，谁就是瓶颈。

## 2. 示例

**示例 1**

```text
输入：text = "nlaebolko"
输出：1
解释：字母重排后恰好凑出 1 个 "balloon"，库存只够一份：
      b×1, a×1, l×2, o×2, n×1。
```

**示例 2**

```text
输入：text = "loonbalxballpoon"
输出：2
解释：多出的 x 用不上；b/a/n 各 2 个，l/o 各 4 个，正好能拼 2 份。
```

**示例 3**

```text
输入：text = "leetcode"
输出：0
解释：整个串里没有字母 b（也没有 a），一个 "balloon" 都拼不出。
```

## 3. 解题思路

### 3.1 暴力思路

最直白的做法是**边找边删**：每一轮从左到右扫描字符串，依次找齐 `b`、`a`、`l`、`l`、`o`、`o`、`n` 并标记删除，凑满一轮答案加一，直到某一轮找不齐为止。

- 每一轮要扫描整串且需要标记/删除，最坏 $O(n)$；
- 最多 $O(n)$ 轮（每轮至少消耗 7 个字符），总复杂度 $O(n^2)$；
- 换成「枚举答案 $k$，再检查每轮是否可行」也是同一个量级，还要额外处理字符的删除与恢复。

$n = 10^4$ 时 $10^8$ 级别操作虽然不一定超时，但答案是**纯计数问题**：字母的位置完全不影响可行性，为什么要模拟删除？观察到这一点后，问题可以压到一次遍历。

### 3.2 核心观察：字母配额 → 逐字母求「能支撑几份」

![balloon 的字母配额与答案公式](images/wc154_q1_balloon_quota.svg)

把 `"balloon"` 拆开，得到每个字母的**单价** `need[x]`：

| 字母 | b | a | l | o | n |
|------|----|----|----|----|----|
| `need[x]` | 1 | 1 | 2 | 2 | 1 |

其余 21 个字母与目标单词无关，出现多少次都是噪声。

**关键等价**：能拼出 $k$ 个 `"balloon"`，当且仅当对每个有用字母 $x$ 都有

$$k \cdot \text{need}[x] \le \text{cnt}[x]$$

因为 $k$ 个单词一共需要 $k \cdot \text{need}[x]$ 个 $x$，而库存只有 $\text{cnt}[x]$ 个，且每个字符最多用一次。于是每个字母都给出了一个**独立上界**：

$$k \le \left\lfloor \frac{\text{cnt}[x]}{\text{need}[x]} \right\rfloor$$

答案就是这些上界的最小值（瓶颈维度）：

$$\text{ans} = \min\Bigl(\text{cnt}[b],\ \text{cnt}[a],\ \Bigl\lfloor\frac{\text{cnt}[l]}{2}\Bigr\rfloor,\ \Bigl\lfloor\frac{\text{cnt}[o]}{2}\Bigr\rfloor,\ \text{cnt}[n]\Bigr)$$

直觉：`l` 与 `o` 是「双份消耗」，天然比别的字母先耗尽；只有它们需要除以 2。

### 3.3 算法流程

![算法流程：计数 → 取五个字母 → 求 min](images/wc154_q1_balloon_flow.svg)

1. 开一个长度 26 的计数数组 `cnt[26]`，遍历 `text`，`cnt[c - 'a'] += 1`。
2. 取出 5 个有用字母的「份数」：`b`、`a`、`n` 直接取计数；`l`、`o` 取计数整除 2。
3. 五者取最小值返回。

整份代码只有一次遍历 + 常数次运算，不需要排序、不需要哈希表，也不需要真的去构造单词。

### 3.4 示例演算

对 `text = "loonbalxballpoon"`（长度 16）：

![示例演算：逐字母份数表](images/wc154_q1_balloon_walkthrough.svg)

| 字母 $x$ | $\text{cnt}[x]$ | $\text{need}[x]$ | $\lfloor \text{cnt}/\text{need} \rfloor$ |
|----------|-----------------|------------------|------------------------------------------|
| b | 2 | 1 | 2 |
| a | 2 | 1 | 2 |
| l | 4 | 2 | 2 |
| o | 4 | 2 | 2 |
| n | 2 | 1 | 2 |

$\min(2,2,2,2,2) = 2$，与官方输出一致。若字符串里混进 `x`、`p` 等无关字母，计数阶段直接跳过，不影响结果。

## 4. 算法细节

1. **只统计有用字母**：可以只对 `b/a/l/o/n` 累加（用 `switch` 或查表），也可以统计全部 26 个再取值。前者常数更小，后者代码更短，都符合 $O(n)$。
2. **整数除法即向下取整**：C++ / Python 中非负整数相除天然向下取整，`cnt[l] / 2`、`cnt[l] // 2` 即为 $\lfloor \cdot \rfloor$，**不要**写成浮点除法再转整型，避免精度与类型转换噪音。
3. **只有 `l`、`o` 除以 2**：把 5 个字母统一除以 2 是经典错误（`b` 的单价是 1，不是 2）。
4. **字符转下标**：`c - 'a'` 即可；若担心 `char` 有符号性问题，可先转 `unsigned char`，本题输入保证小写字母，直接相减是安全的。
5. **不必真的构造单词**：答案由计数决定，构造方案只是证明「上界可达」时的思想实验；代码里出现字符串拼接/删除反而会引入 $O(n^2)$。
6. **可选的剪枝/断言**：答案必然不超过 $\lfloor n / 7 \rfloor$（每个单词消耗 7 个字符），调试时可用它做断言，但正常解法不需要。
7. **Python 写法取舍**：`text.count(ch)` 五次是 $O(5n)$ 同样线性，代码最短；`collections.Counter` 或长度 26 的列表则可控制在一次遍历。

## 5. 正确性证明

**引理 1（上界）**：若能从 `text` 拼出 $k$ 个 `"balloon"`，则对每个有用字母 $x$ 有 $k \cdot \text{need}[x] \le \text{cnt}[x]$，从而 $k \le \min_x \lfloor \text{cnt}[x] / \text{need}[x] \rfloor$。

**证明**：$k$ 个单词中，字母 $x$ 共出现 $k \cdot \text{need}[x]$ 次。每个字符最多被使用一次，故这些位置必须由 `text` 中互不相同的字符填充，于是 $k \cdot \text{need}[x] \le \text{cnt}[x]$。两边同除以正整数 $\text{need}[x]$ 并取整，得 $k \le \lfloor \text{cnt}[x]/\text{need}[x] \rfloor$；对 5 个字母取最小值即得上界。∎

**引理 2（可达）**：令 $k^* = \min_x \lfloor \text{cnt}[x]/\text{need}[x] \rfloor$，则一定存在方案只用 `text` 中的字符拼出 $k^*$ 个 `"balloon"`（剩余字符直接丢弃）。

**证明**：由 $k^*$ 的定义，对每个有用字母 $x$ 都有 $k^* \le \lfloor \text{cnt}[x]/\text{need}[x] \rfloor$，故 $k^* \cdot \text{need}[x] \le \text{cnt}[x]$。构造如下：准备 $k^*$ 个空位，逐个字母 $x$ 从 `text` 中挑出 $k^*\cdot \text{need}[x]$ 个尚未使用的 $x$ 填入对应位置。由于该数量不超过库存 $\text{cnt}[x]$，且不同字母的取用互不干扰（每个字符只有一个字母身份），每一步取用都不会失败。填完后 $k^*$ 个位置全部齐备，即为 $k^*$ 个 `"balloon"`。∎

**定理**：算法返回的数值等于最多可拼出的 `"balloon"` 个数。

**证明**：设最优值为 $k_{\max}$。由引理 1，$k_{\max} \le k^*$；由引理 2，存在拼出 $k^*$ 个的方案，故 $k_{\max} \ge k^*$。两者合并得 $k_{\max} = k^*$，而算法正是返回 $k^*$，结论成立。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$，其中 $n = \lvert \text{text} \rvert$。一次线性遍历完成计数，之后是常数次取下标、整数除法与 5 路比较。字符集固定为 26，与 $n$ 无关。
- **空间复杂度**：$O(1)$。计数数组长度恒为 26（或只记 5 个计数器），不随输入规模增长；无需额外字符串、哈希表或递归栈。

## 7. 参考代码

### C++

```cpp
#include <string>
#include <algorithm>
using namespace std;

class Solution {
public:
    int maxNumberOfBalloons(string text) {
        int cnt[26] = {0};
        for (char c : text) cnt[c - 'a']++;

        // b, a, n 单价 1；l, o 单价 2
        int b = cnt['b' - 'a'];
        int a = cnt['a' - 'a'];
        int l = cnt['l' - 'a'] / 2;
        int o = cnt['o' - 'a'] / 2;
        int n = cnt['n' - 'a'];

        return min({b, a, l, o, n});
    }
};
```

### Python

```python
class Solution:
    def maxNumberOfBalloons(self, text: str) -> int:
        cnt = [0] * 26
        base = ord('a')
        for ch in text:
            cnt[ord(ch) - base] += 1

        # b, a, n 单价 1；l, o 单价 2
        return min(
            cnt[ord('b') - base],
            cnt[ord('a') - base],
            cnt[ord('l') - base] // 2,
            cnt[ord('o') - base] // 2,
            cnt[ord('n') - base],
        )
```

> 也可以写成更短的 `min(text.count(c) // k for c, k in [('b',1),('a',1),('l',2),('o',2),('n',1)])`，复杂度同为 $O(n)$。

## 8. 边界情况与易错点

1. **缺少任一字母 → 答案为 0**：如 `"leetcode"` 缺 `b`；`"ballon"`（少一个 `o`）中 `cnt[o] = 1`，`1 // 2 = 0`，公式自动给出 0，无需特判。
2. **长度不足 7**：任何长度 $< 7$ 的串都不可能拼出一个 `"balloon"`，公式因某个字母必然不足而返回 0；但注意输入长度可以只有 1 个字符。
3. **只除以 2 的两个字母**：把 5 个字母统一 `/2` 会把 `"balloon"`（$\text{cnt}=1,1,2,2,1$）误算成 0，属于最典型的错误。
4. **无关字母不参与计算**：`x`、`z`、`p` 等出现多少次都不影响答案，不要把它们计入 min。
5. **字符下标越界**：若题面允许大写字母或非字母字符，`c - 'a'` 会越界写内存，需要先转小写或加范围判断；本题保证全小写，可直接相减。
6. **整数除法方向**：必须向下取整（`//`、`/` 在非负整数上），不能四舍五入；`4 // 2 = 2` 与 `5 // 2 = 2` 都表示「够 2 份，第 3 份凑不齐」。
7. **别把答案写成「字符总数 / 7」**：$n/7$ 只是理论上界，`"aaaaaaa"` 长度是 7 但答案是 0，必须逐字母核对配额。
