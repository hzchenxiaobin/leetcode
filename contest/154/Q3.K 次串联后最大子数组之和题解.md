# LeetCode K 次串联后最大子数组之和 题解

## 1. 题目概述

- **标题 / 题号**：K 次串联后最大子数组之和（#1191，medium）
- **链接**：https://leetcode.cn/problems/k-concatenation-maximum-sum/
- **来源**：LeetCode 第 154 场周赛 Q3
- **难度**：中等
- **标签**：数组, 动态规划

**题意**：把数组 `arr` 原样首尾相接复制 $k$ 份，得到一个长度 $nk$ 的长数组，求它的**最大子数组和**。子数组允许为空，此时和为 $0$；结果需对 $10^9+7$ 取模。

**约束**：

- $1 \le n = \lvert arr \rvert \le 10^5$
- $1 \le k \le 10^5$
- $-10^4 \le arr[i] \le 10^4$
- 拼接后长度可达 $10^{10}$，**不可能真的构造**；答案最大约 $10^{14}$，超出 32 位整数

> 💡 **一句话切入**：子数组落在 $k$ 份副本里只有三种形态，随 $k$ 增长的只有「中间整份的个数」。抓住这一点，$O(nk)$ 的拼接暴力就被压成 $O(n)$ 的几次扫描。

## 2. 示例

**示例 1**

```text
输入：arr = [1,2], k = 3
输出：9
解释：拼接为 [1,2,1,2,1,2]，最大子数组是整个数组，和 = 9（整份和 3 > 0，吃满 k 份）。
```

**示例 2**

```text
输入：arr = [1,-2,1], k = 5
输出：2
解释：拼成 15 个元素，最大子数组是跨边界的 [1,1]（某份末尾的 1 接下一份的 1），和 = 2。
```

**示例 3**

```text
输入：arr = [-1,-2], k = 7
输出：0
解释：所有元素为负，任何非空子数组都为负，取空子数组，和为 0。
```

## 3. 解题思路

### 3.1 暴力思路

最直白的做法是**真的拼接**：把 `arr` 复制 $k$ 份，再跑一遍 Kadane 求最大子数组和。

- 时间 $O(nk)$，$n = k = 10^5$ 时有 $10^{10}$ 次操作，必然超时；
- 空间 $O(nk)$ 同样爆掉（$10^{10}$ 个整数）；也不能简单地「单份 Kadane 乘 $k$」：示例 2 中单份答案为 $1$，乘 $5$ 得 $5$，与正确答案 $2$ 不符。

所以必须换掉「按位置枚举」：数组被复制了 $k$ 次，真正随 $k$ 变化的量应该只有**整份的个数**。

### 3.2 核心观察：子数组在副本中的三种落法

记 $S = \sum arr$（单份和），$P$ 为**最大前缀和**、$Q$ 为**最大后缀和**（两者都允许取空，故 $\ge 0$）：

$$P = \max_{0 \le i \le n} \sum_{t=0}^{i-1} arr[t], \qquad Q = \max_{0 \le i \le n} \sum_{t=i}^{n-1} arr[t]$$

![k 份副本中最大子数组的三种落法](images/wc154_q3_three_shapes.svg)

拼接后的数组是**周期为 $n$** 的。一个连续子数组的边界落在第 $a$ 份与第 $b$ 份（$b \ge a$），只有三种可能：

| 落法 | 形态 | 是否随 $k$ 增长 | 上界 |
|------|------|------------------|------|
| ① 单份内部 | 长度 $\le n$ 的子数组 | 否 | best₁ |
| ② 跨 1 条边界 | 某份的后缀 + 下一份的前缀 | 否 | $P + Q$ |
| ③ 跨 $\ge 2$ 条边界 | 后缀 + $m$ 个整份 + 前缀 | **是**，$m \le k-2$ | $P + mS + Q$ |

形态 ① ② 合起来正是「两份拼接上的最大子数组和」，记作 **best₂**（它必然 $\ge$ best₁）。形态 ③ 里 $m$ 个整份贡献的是 $mS$：

- 若 $S \le 0$：多攒一个整份只会让和变小或不变，**删掉整份**后剩下的仍是合法连续区间，故最优一定不跨越 2 条以上边界，答案就是 best₂；
- 若 $S > 0$：整份越多越好，$m$ 取到上限 $k-2$（首尾两份留给前缀、后缀），答案至少是 $P + Q + (k-2)S$。

综上，对 $k \ge 2$：

$$\text{ans} = \begin{cases} P + Q + (k-2)S, & S > 0 \\[2pt] \text{best}_2, & S \le 0 \end{cases}$$

代码里写成 $\max(\text{best}_2,\ P + Q + (k-2)S)$（仅在 $S>0$ 时计入后一项）更稳；$k = 1$ 时没有第二份可用，必须直接返回 best₁。

### 3.3 算法流程

![算法流程：前缀和一次遍历、Kadane 两次、分支取 max](images/wc154_q3_flow.svg)

1. 一次遍历求出 $S$ 与 best₁（Kadane：`cur = max(0, cur + x)`，初值 0 表示允许空子数组）。
2. 若 $k = 1$，直接返回 best₁（取模）。
3. 否则在「两份拼接」上再跑一次 Kadane 得到 best₂，先令 $\text{ans} = \text{best}_2$。
4. 若 $S > 0$，再各扫一次求出 $P$、$Q$，用 $P + Q + (k-2)S$ 去更新 ans。
5. 返回 $\text{ans} \bmod (10^9+7)$。

整个过程只需 3～4 次线性扫描，与 $k$ 完全无关。

### 3.4 示例演算

![两条分支的演算：total ≤ 0 与 total > 0](images/wc154_q3_walkthrough.svg)

**演算 A**（示例 2，$arr=[1,-2,1]$，$k=5$，$S=0$）：

| 量 | 计算过程 | 结果 |
|----|----------|------|
| $S$ | $1-2+1$ | $0$ |
| best₁ | Kadane：$1 \to \max(0,1-2)=0 \to 1$ | $1$ |
| best₂ | 两份拼接后 cur：$1,0,1,2,0,1$，峰值 $2$ | $2$ |
| 结论 | $S \le 0$，不吃整份 | $\text{ans}=2$ ✓ |

**演算 B**（自造，$arr=[4,-5,4]$，$k=4$，$S=3>0$）：

| 量 | 计算过程 | 结果 |
|----|----------|------|
| $S$ | $4-5+4$ | $3$ |
| $P$ | 前缀和 $4,-1,3$ 的最大值（含空） | $4$ |
| $Q$ | 从右往左 $4,-1,3$ 的最大值（含空） | $4$ |
| best₂ | $[4,-5,4,4,-5,4]$ 的 Kadane 峰值 | $8$ |
| wrap | $4 + 4 + (4-2)\times 3$ | $14$ |
| 结论 | $\max(8,14)$ | $\text{ans}=14$ ✓ |

验算：四份共 12 个格子，最优区间是第 3 个到第 10 个格子，$4+4-5+4+4-5+4+4 = 14$，恰好是「后缀 + 2 个整份 + 前缀」，比整段的 $12$ 还大——因为丢掉了首尾的负贡献。

## 4. 算法细节

1. **「允许空子数组」靠初值实现**：Kadane 用 `cur = max(0, cur + x)`、`best = max(best, cur)`，`cur`、`best` 与最大前/后缀和 $P$、$Q$ 都从 0 开始。这样全负数组自然返回 0，$P$、$Q$ 也不会被负前缀拉低，无需任何特判。
2. **best₂ 只需在 2 份上算**：不用拼 $k$ 份；任何「跨 1 条边界」的窗口都能平移进前两份，两份拼接的 Kadane 已经覆盖所有形态 ①②。
3. **$k = 1$ 必须单独分支**：两份额公式会用到不存在的第二份，结果偏大。例如 $arr=[5]$、$k=1$，若按两份算会返回 5（看着对）但 $arr=[-1,5]$ 这类就会出错。
4. **$S>0$ 才计算 wrap**：$S=0$ 时 $P+Q$ 已经不超过 best₂，归入哪支结果都一样，但显式写成 `if S > 0` 更不容易在变体题里踩坑。
5. **比较必须用真实和**：$S$ 最大 $10^9$，乘 $k=10^5$ 后约 $10^{14}$，必须用 64 位整数（Python 天然安全）；C++ 中 `(k - 2) * total` 要先转 `long long`，否则 int×int 先溢出再赋值。
6. **取模只在最后一步**：中途取模会破坏 $\max$ 的大小关系（例如 $10^9+8 \bmod (10^9+7) = 1$，比较结果完全变样）。
7. **空间可以做到 $O(1)$**：两份拼接不必真的拷贝，用 `arr[i % n]` 遍历 $2n$ 个位置即可；显式拷贝也只是 $2\times 10^5$ 个元素，完全可以接受。

## 5. 正确性证明

**引理 1（形态完备）**：拼接数组中任一非空子数组，若其首元素在第 $a$ 份、末元素在第 $b$ 份且 $b - a \ge 2$，则它完整包含第 $a+1, \dots, b-1$ 份。

**证明**：第 $a+1$ 份的任意位置都严格位于「第 $a$ 份首元素」之后、「第 $b$ 份末元素」之前，而子数组是连续区间，故这些位置全部落在区间内，即这些整份被完整包含。∎

**引理 2（下界可达）**：当 $k \ge 2$ 且 $S > 0$ 时，存在和恰为 $P + Q + (k-2)S$ 的合法子数组；而 best₂ 本身就是某个合法子数组的和。

**证明**：取第 1 份中达到最大后缀和的那个后缀、第 2 至第 $k-1$ 份整份、第 $k$ 份中达到最大前缀和的那个前缀。三段首尾相接，构成一个连续区间（$k=2$ 时中间段为空），其和为 $Q + (k-2)S + P$。best₂ 由 Kadane 在真实的两份拼接上取得，自然对应某个合法子数组。故最大子数组和 $\ge \max(\text{best}_2, P+Q+(k-2)S)$。∎

**引理 3（上界）**：当 $k \ge 2$ 时，任一子数组的和不超过 $\max(\text{best}_2,\ P+Q+(k-2)S)$（第二项仅在 $S>0$ 时有效）。

**证明**：设子数组和分解为 $q + mS + p$，其中 $q$ 是首份的残缺后缀和、$p$ 是末份的残缺前缀和、$m \ge 0$ 是被完整包含的份数，且 $q \le Q$、$p \le P$。

- 若 $m = 0$，由引理 1 它落在至多两份相邻副本内，由周期性可平移进前两份，故和 $\le \text{best}_2$。
- 若 $m \ge 1$ 且 $S \le 0$，删去这 $m$ 个整份得到和 $q + p \ge q + mS + p$ 的、落在两份内的合法子数组，同样有原和 $\le \text{best}_2$。
- 若 $S > 0$，则 $m \le k - 2$（首尾至少各占一份来提供 $q$、$p$；若某端恰好对齐份边界则该端为空，$m$ 只会更小），故 $q + mS + p \le Q + (k-2)S + P$。

三种情形都被 $\max(\text{best}_2, P+Q+(k-2)S)$ 覆盖。∎

**定理**：算法返回的值等于拼接数组的最大子数组和（对 $10^9+7$ 取模）。

**证明**：$k \ge 2$ 时，引理 2 给出可达的下界、引理 3 给出上界，两者相等，故返回 $\max(\text{best}_2, P+Q+(k-2)S)$ 正确；$k=1$ 时整个数组就是 `arr`，best₁ 由 Kadane 保证正确。由于所有比较都在真实和（64 位）上完成，末尾统一取模不改变答案，仅改变表示。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。求 $S$、best₁ 一次扫描；求 best₂ 在 $2n$ 个位置上一次扫描；求 $P$、$Q$ 各一次扫描。总操作次数与 $k$ 无关，$n = 10^5$ 时约 $5 \times 10^5$ 次基本运算。
- **空间复杂度**：$O(1)$（用下标取模在原数组上走两圈）或 $O(n)$（显式拷贝两份，最多 $2 \times 10^5$ 个整数）。Kadane 与前后缀统计都只需常数个变量，没有递归栈。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int kConcatenationMaxSum(vector<int>& arr, int k) {
        const long long MOD = 1000000007LL;
        long long total = 0;
        for (int x : arr) total += x;

        // Kadane：允许空子数组，初值 0
        auto kadane = [](const vector<int>& v) -> long long {
            long long best = 0, cur = 0;
            for (int x : v) {
                cur = max(0LL, cur + x);
                best = max(best, cur);
            }
            return best;
        };

        long long ans;
        if (k == 1) {
            // 只有一份，直接 Kadane
            ans = kadane(arr);
        } else {
            // 形态 ① + ②：两份拼接上的最大子数组和
            vector<int> twice(arr);
            twice.insert(twice.end(), arr.begin(), arr.end());
            ans = kadane(twice);

            // 形态 ③：后缀 + (k-2) 个整份 + 前缀，仅当整份为正时才有意义
            if (total > 0) {
                long long pre = 0, cur = 0;
                for (int x : arr) { cur += x; pre = max(pre, cur); }

                long long suf = 0;
                cur = 0;
                for (int i = (int)arr.size() - 1; i >= 0; --i) { cur += arr[i]; suf = max(suf, cur); }
                // 注意先转 long long 再做乘法，避免 int 溢出
                long long wrap = pre + suf + (long long)(k - 2) * total;
                ans = max(ans, wrap);
            }
        }
        return (int)(ans % MOD);
    }
};
```

### Python

```python
class Solution:
    def kConcatenationMaxSum(self, arr: list[int], k: int) -> int:
        MOD = 10 ** 9 + 7

        def kadane(nums):
            """允许空子数组的最大子数组和。"""
            best = cur = 0
            for x in nums:
                cur = max(0, cur + x)
                best = max(best, cur)
            return best

        total = sum(arr)

        if k == 1:
            # 只有一份，直接 Kadane
            return kadane(arr) % MOD

        # 形态 ① + ②：两份拼接上的最大子数组和
        ans = kadane(arr + arr)

        # 形态 ③：后缀 + (k-2) 个整份 + 前缀
        if total > 0:
            pre = cur = 0
            for x in arr:
                cur += x
                pre = max(pre, cur)

            suf = cur = 0
            for x in reversed(arr):
                cur += x
                suf = max(suf, cur)

            ans = max(ans, pre + suf + (k - 2) * total)

        return ans % MOD
```

## 8. 边界情况与易错点

1. **全负数组**：Kadane 允许空子数组，best₁ = best₂ = 0，$S \le 0$ 分支返回 0，与示例 3 一致。若把 `cur` 初值写成 `arr[0]` 或忘记 `max(0, ...)`，就会返回负数。
2. **$k=1$**：必须提前返回，不能套「两份拼接 + wrap」的公式——此时第二份根本不存在，$P + Q$ 会把首尾接起来，凭空多算一段。
3. **$S=0$ 的归属**：示例 2 就是 $S=0$，既不能算「整份有收益」（否则 $P+Q+(k-2)\cdot 0 = 2$ 恰好也对，但逻辑脆弱），也不能用「$\text{ans} = S \times k$」这种想当然的写法（会得 0）。
4. **整数溢出**：$P+Q+(k-2)S$ 在极端数据下可达 $10^{14}$ 量级（$P,Q \le 10^9$，$(k-2)S \le 10^{14}$），`int` 必然溢出；C++ 里 `(long long)(k - 2) * total` 的强制转换要写在乘法之前。
5. **取模时机**：务必在比较结束、返回之前才取模。提前取模会让 $10^9+8$ 变成 $1$，导致 max 选错。
6. **$P$、$Q$ 要含空区间**：全负数组时 $P=Q=0$，wrap 才不会被拉成负数；若实现成「必须非空」，当最优首段/末段本应取空时（例如 $S>0$ 但数组只有靠尾部才转正）就会低估答案。
7. **`k` 很大但很快收敛**：$k \ge 3$ 且 $S>0$ 时答案关于 $k$ 是线性增长的，不存在「跑 $k$ 轮」的必要；任何带 $O(k)$ 循环的写法都会超时。
