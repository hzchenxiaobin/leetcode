# LeetCode 最好可到达的塔 题解

## 1. 题目概述

- **标题 / 题号**：最好可到达的塔（#3809，medium）
- **链接**：https://leetcode.cn/problems/best-reachable-tower/
- **来源**：LeetCode 第 174 场双周赛 Q1
- **难度**：中等
- **标签**：数组

**题意**：给出若干座塔 `towers[i] = [x, y, q]`（坐标与质量因子）、你的位置 `center = [cx, cy]` 以及可达半径 `radius`。若一座塔与 `center` 的**曼哈顿距离** $|x-cx| + |y-cy| \le radius$，称它**可到达**。在所有可到达的塔中：

1. 取质量因子 $q$ **最大**者；
2. $q$ 并列时取坐标 `[x, y]` **字典序最小**者；
3. 没有可到达的塔则返回 `[-1, -1]`。

**约束**：

- $1 \le towers.length \le 10^5$
- $0 \le x_i, y_i, q_i, cx, cy \le 10^5$，$0 \le radius \le 10^5$

> 💡 坐标为 $0$ 是合法的，所以"未找到"的哨兵不能用 `[0, 0]` 或 $q=0$，必须用 $q=-1$ 与 `[-1,-1]`。

## 2. 示例

**示例 1**

```text
输入：towers = [[1,2,5],[2,1,7],[3,1,9]], center = [1,1], radius = 2
输出：[3,1]
解释：三座塔距离分别为 1、1、2，全部可到达；最大 q = 9 对应 [3,1]。
```

**示例 2**

```text
输入：towers = [[1,3,4],[2,2,4],[4,4,7]], center = [0,0], radius = 5
输出：[1,3]
解释：[4,4] 距离 8 超半径；[1,3] 与 [2,2] 距离都是 4、q 都是 4，
      [1,3] 字典序更小。
```

**示例 3**

```text
输入：towers = [[5,6,8],[0,3,5]], center = [1,2], radius = 1
输出：[-1,-1]
解释：距离分别为 8 与 2，都超半径，返回哨兵。
```

## 3. 解题思路

### 3.1 暴力思路

题目本身就是"遍历 + 比较"，规模 $10^5$ 也只允许**一趟扫描**。真正的"暴力"陷阱是排序：把所有可到达的塔按 $(q \text{ 降序}, x \text{ 升序}, y \text{ 升序})$ 排序再取第一个，复杂度 $O(n \log n)$，虽然能过，但完全没有必要——最大值比较是 $O(1)$ 的在线操作。

### 3.2 核心观察：双关键字比较可以合并成一个标准序

![曼哈顿菱形：距离 ≤ radius 的格子构成菱形区域](images/bw174_q1_manhattan_diamond.svg)

字典序最小 $\iff$ 二元组 $(x, y)$ 按普通元组序最小。而"$q$ 最大优先、$q$ 相同看坐标"正好等价于**按如下键取最小**：

$$\text{key}(t) = (-q,\; x,\; y)$$

于是问题变成：在所有可到达的塔中取 $\text{key}$ 最小的那个。这样每一趟只需一次元组比较，无需排序、无需额外存列表。

**曼哈顿距离与欧氏距离的区别**：等距线是"菱形"（$|dx| + |dy| = r$）而不是圆。$radius$ 可以到 $10^5$，坐标差不会溢出 `int`，但两项相加后最大 $2 \times 10^5$，仍在 `int` 范围内。

### 3.3 算法流程

![算法流程：一次扫描 + 键比较](images/bw174_q1_algorithm_flow.svg)

```text
1. best = 无；ans = [-1, -1]
2. for 每座塔 (x, y, q):
       若 |x - cx| + |y - cy| > radius：跳过
       若 best 为空 或 (q, x, y) 与当前最优比较更优：
           记录为最优
3. 返回 ans
```

比较时用**降序 q + 升序 x + 升序 y** 三段式，或直接构造键 $(-q, x, y)$。

### 3.4 示例演算

![示例演算：示例 2 的两座并列塔](images/bw174_q1_walkthrough.svg)

以示例 2 为例（`center = [0,0]`、`radius = 5`）：

| 塔 | 曼哈顿距离 | 可到达 | 候选键 $(-q,x,y)$ | 当前最优 |
|----|-----------|--------|--------------------|----------|
| [1,3,4] | 4 | ✓ | $(-4, 1, 3)$ | [1,3,4] |
| [2,2,4] | 4 | ✓ | $(-4, 2, 2)$ | 保持不变（$1 < 2$） |
| [4,4,7] | 8 | ✗ | — | 保持不变 |

最终返回 `[1, 3]`。若把比较写成"$q$ 更大才替换"，就会漏掉并列时取字典序更小的分支。

## 4. 算法细节

1. **哨兵**：$q$ 初值用 $-1$（因为 $q_i \ge 0$），答案初值 `[-1,-1]`；不要用 $0$，否则 `q = 0` 的塔不会被选中。
2. **距离计算**：`abs(x - cx) + abs(y - cy)`，不要写反成欧氏距离；也不要开平方（会产生浮点误差）。
3. **比较写法**（C++）：
   ```text
   better = q > bestQ || (q == bestQ && (x < ansX || (x == ansX && y < ansY)))
   ```
   Python 可直接比较元组 `(-q, x, y)`。
4. **一趟扫描**：$n = 10^5$，$O(n)$ 足够；排序是多余开销。
5. **并列链**：可能有三座以上塔 $q$ 相同，三元比较必须一直生效，不能只在"第一次遇到最大 $q$"时比较坐标。
6. **`radius = 0`**：只有与 `center` 完全重合的塔可到达，属于合法情况，不能特判成空。

## 5. 正确性证明

**引理 1（键序等价）**：对任意两座可到达的塔 $A, B$，$A$ 优于 $B$（$q_A > q_B$，或 $q_A = q_B$ 且坐标字典序更小）当且仅当 $(-q_A, x_A, y_A) < (-q_B, x_B, y_B)$（元组字典序）。

**证明**：元组字典序先比较第一分量。$q_A > q_B \iff -q_A < -q_B$；若 $q$ 相等则第一分量相等，退化为比较 $(x, y)$，即坐标字典序。∎

**引理 2（扫描不变量）**：每一步结束时，`ans` 是"已扫描的塔中所有可到达塔里最优的那座"。

**证明**：对扫描步数归纳。基例：未扫描任何塔时 `ans` 为哨兵，约定它劣于一切真实塔。归纳步：新塔若不可达则集合不变；若可达，代码显式与当前最优比较并按引理 1 的键序保留更优者，故不变量保持。∎

**定理**：算法返回的坐标是题目要求的最优塔坐标；若无塔可到达则返回 `[-1,-1]`。

**证明**：由引理 2，扫描完全部 $n$ 座塔后 `ans` 是全体可到达塔中的最优者，正是题目所求。若没有任何塔可到达，`ans` 始终保持哨兵值 `[-1,-1]`，与题目要求一致。∎

## 6. 复杂度分析

- **时间**：$O(n)$。每座塔做一次距离计算与一次常数比较。
- **空间**：$O(1)$。只维护 `bestQ` 与 `ans` 两个状态。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> bestTower(vector<vector<int>>& towers, vector<int>& center, int radius) {
        vector<int> ans = {-1, -1};
        int best = -1;
        for (auto& t : towers) {
            int dist = abs(t[0] - center[0]) + abs(t[1] - center[1]);
            if (dist > radius) continue;
            bool better = t[2] > best ||
                          (t[2] == best && (t[0] < ans[0] || (t[0] == ans[0] && t[1] < ans[1])));
            if (better) {
                best = t[2];
                ans = {t[0], t[1]};
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def bestTower(self, towers: list[list[int]], center: list[int], radius: int) -> list[int]:
        ans = [-1, -1]
        best = -1
        for x, y, q in towers:
            if abs(x - center[0]) + abs(y - center[1]) > radius:
                continue
            if q > best or (q == best and (x, y) < (ans[0], ans[1])):
                best = q
                ans = [x, y]
        return ans
```

## 8. 边界情况与易错点

1. **`q` 可以为 0**：哨兵必须取 $-1$，否则 `q = 0` 的塔永远选不上。
2. **坐标全 0 合法**：`[0, 0]` 可能是正确答案，不能当"未找到"。
3. **并列的坐标比较方向**：题目要**字典序最小**，写成 `>` 就反了。
4. **距离用曼哈顿**：用欧氏距离会改变可到达集合（示例 2 里 $[2,2]$ 两者都为 4，但其它用例可能不同）。
5. **`radius` 与距离都为 `int`**：坐标差最大 $10^5$，相加 $2\times 10^5$，不会溢出，但别用 `unsigned`。
6. **不要提前 `break`**：最大 $q$ 可能出现在最后一棵，必须扫完。
