# LeetCode 变成目标数组的最少操作次数 题解

## 1. 题目概述

- **标题 / 题号**：变成目标数组的最少操作次数（#3810，medium）
- **链接**：https://leetcode.cn/problems/minimum-operations-to-reach-target-array/
- **来源**：LeetCode 第 174 场双周赛 Q2
- **难度**：中等
- **标签**：贪心、数组、哈希表

**题意**：给定等长数组 `nums` 与 `target`。一次操作：

1. 选择一个整数 $x$；
2. 找出 `nums` 中所有**极大连续段**（段内所有元素都等于 $x$，且左右都无法再延伸）；
3. 对**每个**这样的段 $[l, r]$ **同时**执行 `nums[l..r] = target[l..r]`。

求把 `nums` 变成 `target` 的最少操作次数。

**约束**：

- $1 \le n \le 10^5$
- $1 \le nums[i], target[i] \le 10^5$

> 💡 一次操作会同时命中**所有**该值的极大段，这正是"答案不是段数"的关键。

## 2. 示例

**示例 1**

```text
输入：nums = [1,2,3], target = [2,1,3]
输出：2
解释：选 x=1 → 段 [0,0] 被更新，nums = [2,2,3]；
      选 x=2 → 极大段 [0,1] 被更新为 target[0..1]，nums = [2,1,3]。
```

**示例 2**

```text
输入：nums = [4,1,4], target = [5,1,4]
输出：1
解释：选 x=4 时，两段 [0,0] 与 [2,2] 同时被更新：[0] 变 5，[2] 保持 4。
```

**示例 3**

```text
输入：nums = [7,3,7], target = [5,5,9]
输出：2
解释：选 x=7 同时修好两个 7 → [5,3,9]；再选 x=3 → [5,5,9]。
```

## 3. 解题思路

### 3.1 暴力思路

状态是整条数组，操作依赖当前数组中"值为 $x$ 的极大段"的位置，BFS 的状态空间可达 $\prod (\text{值域})$，完全不可行。需要换视角：**每个位置最终怎么被修好**。

### 3.2 核心观察：只需为每个"错位的值"各操作一次

![每个错位的值都必须在某一刻被选中](images/bw174_q2_misplaced_values.svg)

定义**错位位置** $i$：$nums[i] \ne target[i]$；**错位值**集合

$$S = \{\, nums[i] \;|\; nums[i] \ne target[i] \,\}$$

两个方向的事实：

- **必要性**：位置 $i$ 的值只有在"选中 $x = nums[i]$ 的操作"中才会改变（其它值的极大段不包含 $i$）。所以每个错位位置上的初始值都必须被至少选中一次，即 $S$ 中每个值至少操作一次。
- **充分性**：按任意顺序对每个 $x \in S$ 操作一次即可全部修好。因为一次操作写进位置的值**永远是它自己的 `target` 值**（对每个被覆盖的位置 $i$ 写 `target[i]`），所以：

  1. 一旦某个位置被写过一次，它就**永久正确**（之后即使再被同值段覆盖，写的还是 `target[i]`)；
  2. 对错位位置 $i$，若它还没被写过，则它的值仍是初始的 $nums[i] \in S$，而 $S$ 中的值都会被操作，轮到它时必被写下。

因此答案为 $|S|$，即 `nums[i] != target[i]` 的位置上**不同**的 `nums[i]` 的个数。

### 3.3 算法流程

![算法流程：一趟扫描收集错位值](images/bw174_q2_algorithm_flow.svg)

```text
1. S = 空集合
2. for i = 0 .. n-1:
       若 nums[i] != target[i]: S 插入 nums[i]
3. 返回 |S|
```

### 3.4 示例演算

![示例演算：三组数据的错位值集合](images/bw174_q2_walkthrough.svg)

| 输入 | 错位位置 | 错位值集合 $S$ | 答案 |
|------|----------|----------------|------|
| `[1,2,3]` → `[2,1,3]` | 0, 1 | $\{1, 2\}$ | 2 |
| `[4,1,4]` → `[5,1,4]` | 0 | $\{4\}$ | 1 |
| `[7,3,7]` → `[5,5,9]` | 0, 1, 2 | $\{7, 3\}$ | 2 |

示例 3 里位置 2 的 `nums[2] = 7` 与位置 0 同值，两次错位只贡献**一个**值 7，所以是 2 而不是 3——这正是"同时更新所有极大段"带来的合并收益。

## 4. 算法细节

1. **只收集 `nums[i]`**：错位位置写的是"当前值"，不是 `target[i]`；后者是写入结果，不影响操作集合。
2. **去重**：用哈希集合；值域 $\le 10^5$，也可以开 `vector<bool> seen(100001)` 做到 $O(1)$ 常数更小。
3. **`n = 1`**：错位则答案为 1，否则 0。
4. **已经正确的值不必操作**：若某个值 $v \notin S$，对它操作没有任何收益（它只能把已经正确的段再写一遍），故最优解不会包含它。
5. **顺序无关**：由上文的"永久正确"性质，任意顺序都能成功，因此不需要考虑操作顺序，直接计数。
6. **返回值是不同值个数**，不是"错位位置的个数"（示例 3 会错成 3）。

## 5. 正确性证明

**引理 1（值的改变只来源于同值操作）**：若某次操作选中 $x$，则只有当前值为 $x$ 的位置集合会被写入。

**证明**：操作定义为"对值为 $x$ 的每个极大段 $[l,r]$ 写 `target[l..r]`"，其它位置的当前值不是 $x$，不属于任何 $x$ 的极大段。∎

**引理 2（写入即永久正确）**：任何被某次操作覆盖的位置 $i$，其值在操作后等于 `target[i]`，且此后永远保持 `target[i]`。

**证明**：操作把 $i$ 写成 `target[i]`（第一句）。若之后再次覆盖 $i$，写的仍是 `target[i]`，值不变（第二句）。∎

**引理 3（下界）**：任何可行操作序列至少包含 $|S|$ 次操作。

**证明**：取任意 $v \in S$，存在错位位置 $i$ 使初始 `nums[i] = v`。由引理 1，位置 $i$ 的值只可能被"选中 $v$"的操作改变（在它改变之前，它的值一直是 $v$）。而它最终必须变成 `target[i] ≠ v`，故必须至少有一次选中 $v$ 的操作。不同的 $v$ 对应不同的操作取值，故总操作次数 $\ge |S|$。∎

**引理 4（可达性）**：对 $S$ 中每个值各操作一次（任意顺序）后 `nums` 等于 `target`。

**证明**：任取位置 $i$。若 $nums[i] = target[i]$ 初始成立，则它一开始就正确，由引理 2 永远正确。否则 `nums[i] ∈ S`，设其为 $v$：若在处理 $v$ 之前 $i$ 未被覆盖，则此时 `nums[i]` 仍为 $v$（引理 1，只有选中 $v$ 才改它），于是本次操作覆盖 $i$（$i$ 属于某个 $v$ 的极大段）并写入 `target[i]`；若在此之前 $i$ 已被覆盖，则由引理 2 它已是 `target[i]`。两种情形最终都是 `target[i]`。∎

**定理**：答案为 $|S|$。

**证明**：引理 3 给出下界 $|S|$，引理 4 给出达到下界的构造，两者夹逼即得。∎

## 6. 复杂度分析

- **时间**：$O(n)$。一趟扫描，每个位置一次比较与一次集合插入（哈希均摊 $O(1)$）。
- **空间**：$O(\min(n, V))$，$V \le 10^5$ 为值域；用桶数组则是定长 $O(V)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minOperations(vector<int>& nums, vector<int>& target) {
        unordered_set<int> need;
        for (int i = 0; i < (int)nums.size(); i++) {
            if (nums[i] != target[i]) need.insert(nums[i]);
        }
        return (int)need.size();
    }
};
```

### Python

```python
class Solution:
    def minOperations(self, nums: list[int], target: list[int]) -> int:
        return len({a for a, b in zip(nums, target) if a != b})
```

## 8. 边界情况与易错点

1. **数"值"而不是数"位置"**：`[7,3,7] → [5,5,9]` 的答案是 2（值 7、3），不是 3。
2. **收集的是 `nums[i]`**：写成 `target[i]` 会得到完全不同（且错误）的答案。
3. **已经是目标值的值不必进集合**：否则会多算。
4. **认为"每个极大段一次操作"**：那会得到段数，示例 2 会算成 2 而正确答案是 1（两段同值同时被更新）。
5. **考虑操作顺序的必要性**：不需要——注意"写入即永久正确"，顺序无关。
6. **空错位**：`nums == target` 时返回 0。
