# LeetCode 翻转树上最少边 题解

## 1. 题目概述

- **标题 / 题号**：翻转树上最少边（#3812，hard）
- **链接**：https://leetcode.cn/problems/minimum-edge-toggles-on-a-tree/
- **来源**：LeetCode 第 174 场双周赛 Q4
- **难度**：困难
- **标签**：树、深度优先搜索、图、拓扑排序、排序

**题意**：给定 $n$ 个节点的无向树（`edges[i] = [u, v]` 即下标 $i$ 的边）、两个长度 $n$ 的二进制串 `start` 与 `target`。一次操作：选一条边，把**它的两个端点**颜色同时翻转（`0 ↔ 1`）。求一个**最短**的边下标序列（升序返回），使 `start` 变成 `target`；不可能则返回 `[-1]`。

**约束**：

- $2 \le n \le 10^5$
- $edges.length = n-1$，构成一棵合法树
- `start[i]`, `target[i]` $\in \{0,1\}$

## 2. 示例

**示例 1**

```text
输入：n = 3, edges = [[0,1],[1,2]], start = "010", target = "100"
输出：[0]
解释：翻转边 0 同时改变节点 0 与 1：010 → 100。
```

**示例 2**

```text
输入：n = 7, edges = [[0,1],[1,2],[2,3],[3,4],[3,5],[1,6]],
     start = "0011000", target = "0010001"
输出：[1,2,5]
解释：坏节点是 3（1→0）与 6（0→1），沿路径 3-2-1-6 依次翻转边 2、1、5。
```

**示例 3**

```text
输入：n = 2, edges = [[0,1]], start = "00", target = "01"
输出：[-1]
解释：每次操作同时翻转两个端点，改变颜色不同的节点数永远是偶数，无法只改一个。
```

## 3. 解题思路

### 3.1 暴力思路

枚举边子集：$2^{n-1}$ 种，每种检验 $O(n)$，$n = 10^5$ 完全不可行。但从"子集"这个形态可以得到两个关键约束：**同一条边翻两次等于没翻**，因此最优解中每条边至多使用一次；问题变成"在树上选一个边子集，使得每个节点的奇偶性符合要求"——这是一个**模 2 线性方程组**。

### 3.2 核心观察：坏节点的奇偶性是唯一的判据

![坏节点集合：目标状态只取决于“每个节点被翻转次数的奇偶性”](images/bw174_q4_parity_concept.svg)

设 $B = \{\,i \mid start[i] \ne target[i]\,\}$ 为**坏节点**集合，$x_e \in \{0,1\}$ 表示边 $e$ 是否被选。则对每个节点 $u$：

$$\bigoplus_{e \ni u} x_e = [\,u \in B\,] \pmod 2$$

三个结论：

1. **存在性**：把所有方程相加，左边每条边被计入两次而抵消，得 $\sum_u [u \in B] \equiv 0$，故 $|B|$ 必须为**偶数**；
2. **唯一性**：树的边-点关联矩阵在 $\mathbb{F}_2$ 上秩为 $n-1$，方程组若有解则**唯一**；
3. **最短性**：解唯一 ⇒ 任何合法边子集都等于它，故它就是最短（也是唯一）答案。

### 3.3 算法流程：自底向上回推每条边

![自底向上：子树中坏节点数为奇数时，必须用连向父节点的边](images/bw174_q4_dfs_flow.svg)

唯一解可以**自底向上**构造。把树以 $0$ 为根，先求出 BFS/DFS 的访问序 `order`（父先于子），然后**逆序**处理每个非根节点 $u$：

```text
1. need[i] = (start[i] != target[i])，表示节点 i 还需要的翻转奇偶性
2. 从 0 开始做 BFS/DFS 得到 order（父先于子）与每个节点的父边下标 pedge
3. for u in reverse(order)，跳过根：
       若 need[u] == 1：
           选中边 pedge[u]（记入答案）
           need[parent[u]] ^= 1        # 这条边同时翻转了父节点
4. 若 need[0] != 0：无解，返回 [-1]
5. 答案排序后返回
```

**为什么是逆序**：处理到 $u$ 时，$u$ 的整棵子树已经处理完，所有"能影响 $u$ 的边"里只剩父边未定；若此时 $u$ 仍需要奇数次翻转，那么父边**必须**被选中，没有别的选择——这正是唯一性的体现。

### 3.4 示例演算

![演算：示例 2 中自底向上推出 [1,2,5]](images/bw174_q4_walkthrough.svg)

示例 2：`start = "0011000"`、`target = "0010001"`，逐位比较得 $B = \{3, 6\}$（$|B|=2$ 为偶数）。以 0 为根建树：

| 处理顺序（逆序） | 节点 | `need` | 是否选父边 | 父节点 need 变化 |
|------------------|------|--------|------------|------------------|
| 1 | 4 | 0 | 否 | — |
| 2 | 5 | 0 | 否 | — |
| 3 | 3 | 1 | 选边 2 (2–3) | need[2] ^= 1 |
| 4 | 2 | 1 | 选边 1 (1–2) | need[1] ^= 1 |
| 5 | 6 | 1 | 选边 5 (1–6) | need[1] ^= 1 → 0 |
| 6 | 1 | 0 | 否 | — |
| 根 | 0 | 0 | 完成 | — |

答案 `[1, 2, 5]`，与示例一致。注意节点 1 被两条子边各翻一次，奇偶抵消，正好回到 0。

## 4. 算法细节

1. **迭代代替递归**：$n = 10^5$ 的链在 C++ 递归里可能爆栈，Python 默认递归深度更小；统一用显式栈或"BFS 队列按层生成 order"。
2. **`order` 的生成**：用一个队列/栈，从 0 出发，跳过父节点即可。逆序遍历 `order[1..]` 保证子先于父。
3. **父边下标**：建邻接表时把边下标一起存（`adj[u]` 里放 `(v, edgeIdx)`），回溯时直接取。
4. **`need` 的异或传播**：`need[parent] ^= 1` 等价于"这条边翻转了父节点一次"。
5. **无解判定只有一个**：`need[0] != 0`，等价于 $|B|$ 为奇数。
6. **答案升序**：按处理顺序得到的是乱序，最后 `sort` 一次；$O(n \log n)$ 可接受（也可以用桶排序做到 $O(n)$）。
7. **返回值类型**：`vector<int>`，无解时返回单元素 `{-1}`（注意不是空数组）。

## 5. 正确性证明

**引理 1（0/1 归约）**：存在最优解，其中每条边至多被选一次；且任何合法解的"边使用次数奇偶向量"满足关联方程组。

**证明**：若某条边被用了偶数次，删掉这些使用不改变任何节点的翻转奇偶性，且操作次数减少（或不变），故可归约为每边 0/1 次。此时节点 $u$ 被翻转的次数为 $\bigoplus_{e \ni u} x_e$，必须等于 $[u \in B]$。∎

**引理 2（唯一性）**：若关联方程组 $\bigoplus_{e \ni u} x_e = [u \in B]$ 有解，则解唯一。

**证明**：两个解之差 $d$ 满足"每个节点的关联边中 $d_e = 1$ 的条数为偶数"。取使 $\sum d_e$ 最小的非零差向量，令 $S = \{e : d_e = 1\} \ne \varnothing$。由于 $d$ 满足条件，$S$ 中每个节点都被**偶数条** $S$ 中的边覆盖，故 $S$ 在树上诱导的子图每个点度数均为偶数。但它是一片森林（树的子图无环）且非空，必然存在度为 1 的叶子节点，矛盾。故 $d = 0$，解唯一。∎

**引理 3（逆序构造正确）**：算法选出的边集 $S$ 满足方程组。

**证明**：对子树大小归纳。处理 $u$ 时（$u \ne$ 根），其子树内所有非 $u$ 节点的边都已确定；$u$ 的翻转奇偶性来自"子边中被选中的条数"与（可能的）父边。若此时 `need[u] == 1`，说明子边贡献的奇偶性与要求不符，必须由父边补齐，故选中父边并把影响传给父节点；若为 0，父边必须不选（选了就破坏 $u$ 的奇偶性，且父边是 $u$ 唯一未定的边）。归纳可得每个节点的方程最终被满足，且根节点的 `need[0]` 恰为全部方程之和的余项。∎

**定理**：若 $|B|$ 为偶数，算法输出唯一最短解（升序边下标）；否则返回 `[-1]`。

**证明**：$|B|$ 为奇数时，由引理 1 的求和论证方程组无解，故无法转换，返回 `[-1]` 正确。$|B|$ 为偶数时，由引理 3 解存在；由引理 2 解唯一；由引理 1 任何可行方案都必须是该 0/1 解（否则奇偶不符），故它就是最短解。排序不改变集合。∎

## 6. 复杂度分析

- **时间**：$O(n \log n)$，瓶颈在答案排序；建树、求 `order`、逆序传播都是 $O(n)$。若要 $O(n)$，可对边下标做一次计数排序。
- **空间**：$O(n)$。邻接表 $2(n-1)$ 条弧、`order`、`need`、`par` 各 $O(n)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> minimumFlips(int n, vector<vector<int>>& edges, string start, string target) {
        vector<vector<pair<int, int>>> adj(n);
        for (int i = 0; i < n - 1; i++) {
            adj[edges[i][0]].push_back({edges[i][1], i});
            adj[edges[i][1]].push_back({edges[i][0], i});
        }
        vector<int> par(n, -1), pedge(n, -1), order;
        order.reserve(n);
        par[0] = 0;
        order.push_back(0);
        for (int i = 0; i < (int)order.size(); i++) {
            int u = order[i];
            for (auto& pr : adj[u]) {
                int v = pr.first;
                if (v == par[u]) continue;
                par[v] = u;
                pedge[v] = pr.second;
                order.push_back(v);
            }
        }
        vector<int> need(n);
        for (int i = 0; i < n; i++) need[i] = (start[i] != target[i]) ? 1 : 0;
        vector<int> res;
        for (int k = n - 1; k >= 1; k--) {
            int u = order[k];
            if (need[u]) {
                res.push_back(pedge[u]);
                need[par[u]] ^= 1;
            }
        }
        if (need[0]) return {-1};
        sort(res.begin(), res.end());
        return res;
    }
};
```

### Python

```python
class Solution:
    def minimumFlips(self, n: int, edges: list[list[int]], start: str, target: str) -> list[int]:
        adj = [[] for _ in range(n)]
        for i, (a, b) in enumerate(edges):
            adj[a].append((b, i))
            adj[b].append((a, i))
        par = [-1] * n
        pedge = [-1] * n
        order = [0]
        for u in order:
            for v, idx in adj[u]:
                if v == par[u]:
                    continue
                par[v] = u
                pedge[v] = idx
                order.append(v)
        need = [1 if start[i] != target[i] else 0 for i in range(n)]
        res = []
        for u in reversed(order[1:]):
            if need[u]:
                res.append(pedge[u])
                need[par[u]] ^= 1
        if need[0]:
            return [-1]
        return sorted(res)
```

## 8. 边界情况与易错点

1. **$|B|$ 为奇数**：直接无解，返回 `[-1]`；示例 3 就是这种情形（坏节点只有 1 个）。
2. **返回类型是数组**：无解时返回 `[-1]`（单元素），不是空数组、也不是 `-1`。
3. **同一条边只能用一次**：翻两次等价于没翻，最优解绝不会重复使用某条边。
4. **根的选择不影响结果**：换根只改变处理顺序，最终边集不变（解唯一）。
5. **`need` 传播方向**：是 `need[par[u]] ^= 1`（父节点被这条边翻转），不是 `need[u] ^= 1`。
6. **深链爆栈**：$n = 10^5$ 的链必须用迭代（本解法用 `for u in order` 的列表扩张，天然无递归）。
7. **答案要排序**：逆序处理的顺序与边下标无关。
8. **`par[0] = 0`**：允许根自指，配合 `if (v == par[u]) continue` 防止走回父节点；也可显式判断 `v != par[u]` 并单独处理根。
