# LeetCode 从字符串生成二叉树 题解

## 1. 题目概述

- **标题 / 题号**：从字符串生成二叉树（#536，medium）
- **链接**：https://leetcode.cn/problems/construct-binary-tree-from-string/
- **来源**：LeetCode 第 23 场周赛 Q3
- **难度**：中等
- **标签**：栈，树，深度优先搜索，字符串，二叉树

**题意**：字符串 `s` 用「整数 + 括号块」描述一棵二叉树：一个整数代表一个节点，紧跟其后的第一对括号内是它的**左子树**，第二对括号内是它的**右子树**，括号块内部递归地遵循同一格式。要求还原这棵树并返回根节点；空串代表空树。

**约束**：

- $0 \le \lvert s \rvert \le 3 \times 10^4$
- `s` 只包含 `(`、`)`、`-` 和 `0`~`9`；负号只出现在整数前，正值不写 `+`
- 空树由 `""` 表示，而**不是** `"()"`
- 有子结点时**先构建左子结点**，因此只有一对括号时它一定指向左孩子

## 2. 示例

**示例 1**

```text
输入：s = "4(2(3)(1))(6(5))"
输出：根节点 4，层序 [4, 2, 6, 3, 1, 5]
解释：4 的左子树是 2(3)(1)（2 的孩子为 3、1），右子树是 6(5)（6 的左孩子为 5）。
```

**示例 2**

```text
输入：s = "4(2(3)(1))(6(5)(7))"
输出：根节点 4，层序 [4, 2, 6, 3, 1, 5, 7]
解释：6 后面有两对括号，第二对 (7) 挂到 6 的右孩子上。
```

**示例 3**

```text
输入：s = "-4(2(3)(1))(6(5)(7))"
输出：根节点 -4，层序 [-4, 2, 6, 3, 1, 5, 7]
解释：负号与数字连读，根值为 -4；其余结构与示例 2 相同。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的做法是「先找配对括号，再切子串递归」：在位置 $i$ 读到数字后，用计数器找到与它后面那个 `(` 配对的 `)`，把括号内的内容 `substr` 出来递归，再去找第二对括号。每层都要把整段子串扫一遍、拷一遍，链状输入（如 `1(2(3(4…)))`）的总代价是

$$\sum_{k=0}^{\lfloor n/3 \rfloor} (n - 3k) = O(n^2)$$

$n = 3\times10^4$ 时约 $1.5\times10^8$ 次字符访问，Python 必然超时，C++ 也在超时边缘，反复切片还会带来大量内存分配。症结在于**同一段字符被反复读取**，而它其实只需要读一遍。

### 3.2 核心观察：括号块就是子树，扫描指针不必回退

![数字加紧随的括号块即一棵子树](images/wc23_q3_bracket_tree_concept.svg)

关键观察有两条：

1. **结构自相似**：一个节点的描述 = 整数 + 至多两对括号，括号里又是一棵完整的树。因此解析函数 `build(s, i)` 只需负责「从 `i` 开始的一棵子树」，就能递归复用。
2. **边界由配对括号唯一确定**：`build` 返回时，指针恰好停在这棵子树串的**末尾之后**。于是父节点处理完左孩子后，原地就能看有没有第二对括号 —— **指针只前进、从不回退**。

又因为第 1 对括号一定对应左孩子、第 2 对一定对应右孩子，「先左后右」的顺序无需额外判断，只要**按出现顺序各检查一次**即可。

### 3.3 算法流程 / 状态转移

![一次扫描的流程与栈不变量](images/wc23_q3_parse_flow.svg)

递归下降版本 `build(s, i)`：

1. 若 `i` 已到串尾或 `s[i] == ')'`，说明是空子树，返回 `nullptr`；
2. 读可选负号，再连续读数字累加成 `val`，新建节点；
3. 若 `s[i] == '('`：`++i` 跳过它，递归 `build` 得到**左孩子**，返回后 `++i` 跳过配对的 `)`；
4. 若此时 `s[i]` 又是 `(`：同样跳过、递归得到**右孩子**、跳过 `)`；
5. 返回当前节点，整棵树的答案就是 `build(s, 0)`。

**显式栈版本**与之等价：栈里保存「根 → 当前未闭合子树的根」这条路径。读到整数就建节点，挂到栈顶节点的第一个空位（左空挂左，否则挂右），再把自己压栈；读到 `)` 就弹栈。两种写法的扫描顺序与挂载时机完全一致，只是一个用函数调用栈、一个用显式栈。

### 3.4 示例演算

![示例 4(2(3)(1))(6(5)) 的扫描过程](images/wc23_q3_walkthrough.svg)

以 `s = "4(2(3)(1))(6(5))"` 为例，栈内元素按「栈底 → 栈顶」书写：

| 读入 | 动作 | 栈 |
|------|------|-----|
| `4` | 建根 4 并入栈 | `[4]` |
| `(` | 子树开始标记，指针后移 | `[4]` |
| `2` | 4 的左位为空 → 挂 4 左，入栈 | `[4,2]` |
| `3` | 2 的左位为空 → 挂 2 左，入栈 | `[4,2,3]` |
| `)(` | 弹出 3，跳过 `(` | `[4,2]` |
| `1` | 2 的左位已占 → 挂 2 右，入栈 | `[4,2,1]` |
| `))(` | 弹出 1、弹出 2，跳过 `(` | `[4]` |
| `6` | 4 的左位已占 → 挂 4 右，入栈 | `[4,6]` |
| `5` | 6 的左位为空 → 挂 6 左，入栈 | `[4,6,5]` |

剩下两个 `)` 依次把 5、6 弹出，栈空，扫描结束；根节点在第一次创建时就被记录，所以答案不受栈空影响。

## 4. 算法细节

1. **负数与多位数**：`-` 只是符号位而不是分隔符，必须「先判负号、再循环读数字」；数字累加在 C++ 里用 `long long`（最终转 `int`），Python 天然支持大整数，不必特判。
2. **指针必须「传引用」**：C++ 用 `int& i`；若用 Python 写递归版，则要靠 `nonlocal` 或把下标塞进列表/成员变量。若按值传递，父层拿到的是过期副本，会重复解析同一段字符。
3. **只有一对括号 = 左孩子**：题面保证「左孩子先建」，所以处理完左孩子后才检查第二对括号；不能因为「当前只有一个括号块」就把它当右孩子。
4. **返回后必须跳过配对的 `)`**：`build` 内部只消费自己的数字和子括号，配对的 `)` 留在原地，必须由**调用者** `++i` 跳过；漏掉这一步指针会停在 `)` 上，被误判为空子树。
5. **递归深度 vs 显式栈**：C++ 栈帧很小，深度 $10^4$ 级安全；Python 默认递归上限只有 1000，而链状输入 `1(2(3(…)))` 每层平均只占约 3 个字符，深度可达约 $10^4$（实测深度 2001 就抛 `RecursionError`）。故 Python 参考代码改用**显式栈**，既不依赖 `sys.setrecursionlimit`，也不会撞 C 栈。
6. **栈版的三个动作要分清**：`(` 不入栈也不建节点，只是跳过；`)` 只弹栈不建节点；只有读到数字才建节点、挂到栈顶、再入栈。把 `(` 也入栈会破坏「栈顶即父节点」的不变量。
7. **空串先返回**：Python 栈版在入口判空，避免主循环去读 `s[0]`；C++ 递归版靠 `build` 首行的 `i >= n` 也能兜住，但入口显式判空更直白。

## 5. 正确性证明

固定记号：把 `s` 中某个节点对应的那段文本（整数 + 至多两对括号）称为**子树串**；记 `end(i)` 为从位置 `i` 的整数开始、其子树串结束的下标（不含）。

**引理 1（括号块边界唯一）**：`s` 中任一位置的整数，其子树串由该整数后紧跟的括号结构唯一确定，且这段文本恰好描述一棵合法二叉树。

**证明**：题面保证括号串良构，故每个 `(` 都有唯一配对的 `)`，且配对关系是顺序嵌套、互不交叉的。位置 $i$ 的整数之后若紧跟 `(`，其配对位置 $j$ 即左子树串的结束；若该子树还有第二对括号，则第二对的配对位置是整棵子树串的结束，否则整棵子树串在左子树后即结束。由于配对位置由嵌套结构唯一决定，故边界唯一。「合法二叉树」由题面描述（整数 + 至多两对递归括号）对嵌套层数归纳即得。∎

**引理 2（`build` 的正确性）**：对任意合法起点 $i$，`build(s, i)` 恰好返回该处子树串所描述的树，且返回时指针值为 `end(i)`。

**证明**：对子树串长度 $L$ 归纳。

- 基始：$L$ 仅为一个整数（可带负号）时，函数读到串尾或 `)` 就停下（该字符不属于本子树），建出叶子并返回，指针恰在 `end(i)`；若起点越界或 `s[i] == ')'`，返回空指针，对应空子树。
- 归纳：设子树串为 `v(A)(B)` 或 `v(A)`。由引理 1，`A`、`B` 分别是左右子树串且都短于整体。函数读 `v` 建节点 → 跳过 `(` → 递归解析 `A`：由归纳假设返回值正是 `A` 描述的树，且指针停在 `A` 之后（即 `A` 的配对 `)`），故 `++i` 后指针落在 `B` 的 `(` 或本子树串末尾。前者再递归一次得到 `B`。于是左右孩子都正确，指针到达 `end(i)`。∎

**引理 3（栈不变量）**：栈版主循环中，栈内元素自底向上构成一条祖先链（栈顶最深），链上每个节点已填的孩子都遵循「先左后右」的次序，因此新节点的落点恰是栈顶节点的第一个空孩子位。

**证明**：初始栈空。读到数字时：栈空则它是整棵树的根（首个节点），否则由不变量，新节点正是栈顶节点尚未填充的第一个孩子位，挂上后压栈，链延长一格，不变量保持。`(` 只移动指针，不影响栈。`)` 表示栈顶子树闭合，弹出后栈顶回到其父亲，链式结构保持。∎

**定理**：`str2tree(s)` 返回 `s` 所描述的整棵树；空串返回空树。

**证明**：整串正是根节点的子树串。递归版由引理 2 直接得到；栈版由引理 3，每个节点都挂到了正确父亲的正确孩子位，且每个节点只创建一次，故两版结果都与串描述同构。空串时无字符可读，返回空树，符合题面约定。∎

## 6. 复杂度分析

- **时间**：$O(\lvert s \rvert)$。指针 `i` 单调递增，每个字符（数字位、负号、括号）只被检查常数次；所有数字位加起来不超过 $n$，每个节点建一次，无子串拷贝与二次扫描。
- **空间**：$O(n)$ 用于存放 $n$ 个节点（输出本身）；额外空间 $O(h)$，$h$ 为树高 —— 递归版是调用栈深度，栈版是显式栈大小。链状输入 $h$ 可达约 $10^4$，C++ 无压力，Python 需用显式栈（见 §4 第 5 条）。

## 7. 参考代码

> ⚠️ C++ 用递归下降（函数调用栈即栈）；Python 改写为**显式栈**，因为链状输入深度可达约 $10^4$，超过 CPython 默认递归上限 1000。两者是同一算法的两种栈实现，输出完全一致。

### C++

```cpp
/**
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    TreeNode* str2tree(string s) {
        int i = 0;
        return build(s, i);
    }

private:
    // 解析 s[i] 起的子树，返回其根；返回时 i 指向该子树串之后
    TreeNode* build(const string& s, int& i) {
        int n = s.size();
        if (i >= n || s[i] == ')') return nullptr;   // 空子树

        long long sign = 1;
        if (s[i] == '-') { sign = -1; ++i; }
        long long val = 0;
        while (i < n && isdigit(s[i])) val = val * 10 + (s[i++] - '0');
        TreeNode* node = new TreeNode((int)(sign * val));

        if (i < n && s[i] == '(') {                  // 第一对括号 = 左孩子
            ++i;                                      // 跨过 '('
            node->left = build(s, i);
            ++i;                                      // 跨过配对的 ')'
        }
        if (i < n && s[i] == '(') {                  // 第二对括号 = 右孩子
            ++i;
            node->right = build(s, i);
            ++i;
        }
        return node;
    }
};
```

### Python

```python
from typing import Optional

# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def str2tree(self, s: str) -> Optional['TreeNode']:
        if not s:
            return None
        stack, i, n = [], 0, len(s)
        root = None
        while i < n:
            c = s[i]
            if c == '(':                  # 子树开始标记，只移动指针
                i += 1
            elif c == ')':                # 子树闭合，弹出它的根
                stack.pop()
                i += 1
            else:
                sign = 1
                if c == '-':
                    sign = -1
                    i += 1
                val = 0
                while i < n and s[i].isdigit():
                    val = val * 10 + (ord(s[i]) - 48)
                    i += 1
                node = TreeNode(sign * val)
                if stack:                 # 左位空则挂左，否则挂右
                    parent = stack[-1]
                    if parent.left is None:
                        parent.left = node
                    else:
                        parent.right = node
                else:
                    root = node            # 第一个节点就是根
                stack.append(node)
        return root
```

## 8. 边界情况与易错点

1. **空串**：`""` → 返回 `nullptr` / `None`。题面明确空树写作 `""` 而不是 `"()"`，因此不必为 `"()"` 单独写分支。
2. **单节点**：`"1"`、`"-4"`、`"123"` 读完整数后直接结束，不能期待后面一定有括号。
3. **深链爆栈**：`"1" + "(2"*k + ")"*k`，取 $k = 9000$ 时串长 27001、树深 9001；Python 默认上限 1000，实测深度 2001 就 `RecursionError`，务必用显式栈。
4. **漏跳配对 `)`**：少写一次 `++i` 会让指针停在 `)` 上，后续把兄弟节点误判成空子树，结果直接丢掉一半节点。
5. **唯一孩子挂错边**：`"1(2)"` 的答案是 `1` 的左孩子为 `2`、右孩子为空；若按「先看右孩子」的逻辑就错了。
6. **栈版弹栈时机**：`")"` 必须立刻 `pop`，否则下一个数字会挂到已闭合的子树根上，树形整体错乱。
7. **负号处理**：读到 `-` 要 `++i` 再继续读数字，且 `sign` 必须参与最终取值；漏掉符号会得到相反数。
