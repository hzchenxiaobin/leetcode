# LeetCode 最小无法得到的或值 题解

## 1. 题目概述

- **标题 / 题号**：最小无法得到的或值（#2568，medium）
- **链接**：https://leetcode.cn/problems/minimum-impossible-or/
- **来源**：LeetCode 第 98 场双周赛 Q3
- **难度**：中等
- **标签**：位运算、脑筋急转弯、数组、哈希表

**题意**：给定整数数组 `nums`。若存在下标 $index_1 < index_2 < \dots < index_k$ 使 $nums[index_1] \mid nums[index_2] \mid \dots \mid nums[index_k] = x$，则称 $x$ **可表达**（即 $x$ 能由 `nums` 的某个**非空子序列**按位或得到）。返回 `nums` **不可表达的最小非零整数**。

**约束**：

- $1 \le nums.length \le 10^5$
- $1 \le nums[i] \le 10^9$

## 2. 示例

**示例 1**

```text
输入：nums = [2,1]
输出：4
解释：1、2 本身在数组中；2 | 1 = 3 也可表达。4 无法由任何子序列的或得到。
```

**示例 2**

```text
输入：nums = [5,3,2]
输出：1
解释：所有元素的二进制最低位都是 0（5=101, 3=11, 2=10），任何子序列的或最低位仍是 0，
      故 1 不可表达，它就是最小非零不可表达数。
```

**示例 3（边界补充）**

```text
输入：nums = [1,2,4,8,3,7]
输出：16
解释：前缀 1,2,4,8 全在数组中（且 3=1|2、7=1|2|4 均可表达），2^4 = 16 不在也无法拼出。
```

## 3. 解题思路

### 3.1 暴力思路

或运算的子序列结果至多 $2^n$ 种，但去重后不超过「所有元素或起来的位集合的子集数」$\le 2^{30}$（$nums[i] \le 10^9 < 2^{30}$）。把全部可达值放进集合（对每个元素 $x$，`reach |= {s | x : s ∈ reach}`，即子集和式的 OR-DP），再从 1 向上找第一个不在集合里的数。可达值个数可达 $2^{30} \approx 10^9$，时间与空间都爆炸——不可行。但这个 DP 揭示了结构：**可达集是「全体元素或 $T$」的子集，且包含每个元素本身**。

### 3.2 核心观察：答案必是 2 的幂——最小缺失的 $2^i$

![核心观察：最低缺失的 2 的幂就是答案](images/bw98_q3_power_of_two.svg)

**两个方向的事实**：

1. **若 $2^i$ 不在数组中，则 $2^i$ 不可表达**？——不对，$2^i$ 可以由多个数或出来吗？或运算只**置位不退位**：把若干数或起来，第 $i$ 位为 1 当且仅当**至少一个**参与数的第 $i$ 位为 1。但参与数可能在其他位也是 1，或出的结果就会带上多余的 1 位，变成别的数。于是「$x$ 可表达」当且仅当 $x$ 的**每个 1 位**都被某个参与数覆盖，且**没有任何参与数在 $x$ 的 0 位上是 1**——这第二半条件极强！
2. **关键引理（见 §5）**：$2^i$ 可表达 $\iff$ $2^i \in nums$（作为元素出现）。因为若子序列的或恰好等于 $2^i$，则每个参与数都必须是 $2^i$ 的子集（二进制下只有第 $i$ 位可能为 1），又因 $nums[j] \ge 1$，参与数恰为 $2^i$ 本身。

于是**答案 = 最小的 $2^i$ 不在数组中出现**。再结合覆盖性：若 $2^0, 2^1, \dots, 2^{i-1}$ 全在数组中，则 $1 \sim 2^i - 1$ 的所有数都可表达（任意 $< 2^i$ 的数是这些幂的子集，选对应元素或起来即可）；而 $2^i$ 不在数组就不可表达——**最小的缺失幂恰好卡在「全可表达前缀」的尽头**。若 $2^0 \dots 2^{29}$ 全在（$nums[i] \le 10^9 < 2^{30}$，最多到 $2^{29}$），则答案为 $2^{30}$（所有 $\le 10^9$ 的非零数都可表达，但答案必须存在——实际上 $nums[i] \le 10^9 < 2^{30}$ 使 $2^{30}$ 不可能在数组中，故答案 $\le 2^{30}$ 恒有解）。

### 3.3 算法流程

![算法流程：哈希集合 + 逐个检查 2 的幂](images/bw98_q3_algorithm_flow.svg)

```text
1. s ← nums 的哈希集合
2. for i = 0, 1, 2, ...:
       若 2^i ∉ s：返回 2^i
```

$i$ 至多枚举到 30（$2^{30} > 10^9 \ge nums[i]$，必然缺失），循环必然终止。

### 3.4 示例演算

**示例 1**（`nums = [2,1]`，$s = \{1, 2\}$）：

| $i$ | $2^i$ | 在 $s$ 中？ |
|-----|-------|------------|
| 0 | 1 | ✓ |
| 1 | 2 | ✓ |
| 2 | 4 | ✗ → 返回 **4** |

**示例 2**（`nums = [5,3,2]`，$s = \{5,3,2\}$）：$2^0 = 1 \notin s$ → 返回 **1**。

**示例 3**（`nums = [1,2,4,8,3,7]`）：$1, 2, 4, 8$ 依次命中，$2^4 = 16 \notin s$ → 返回 **16**。顺带验证 $15 = 1|2|4|8$ 可表达 ✓，与「前缀全可表达」一致。

## 4. 算法细节

1. **判存在用哈希集合**：`unordered_set` / `set(nums)` 一次构建 $O(n)$，查询 $O(1)$。
2. **也可以用位掩码代替集合**：`mask |= (x == (x & -x)) ? x : 0`——即「$x$ 是 2 的幂时把它并进掩码」；随后从低位找 mask 的第一个 0 位。一次遍历、$O(1)$ 额外空间，且免去哈希开销（`x & (x-1) == 0` 判 2 的幂）。注意 $x \ge 1$ 保证 $x = 0$ 的歧义不存在。
3. **枚举上界**：$nums[i] \le 10^9 < 2^{30}$，故 $i$ 只需枚举到 30（含）；$2^{30}$ 必不在数组中，循环至多 31 次必返回。防呆写法是 `while (true)`（数学上必停）。
4. **为什么不用管「3、7 等非幂可表达」**：非幂数的可表达性由幂的覆盖自动决定（引理 2），算法只需盯住幂。这是本题「脑筋急转弯」的精髓：**看似要研究全部整数，实则只需研究 30 个幂**。
5. **元素可重复、顺序无关**：子序列对顺序无要求（或满足交换律），重复元素与哈希去重兼容。
6. **复杂度对比**：哈希版 $O(n)$ 时间 $O(n)$ 空间；位掩码版 $O(n)$ 时间 $O(1)$ 空间。两者对本题规模都是瞬时完成。

## 5. 正确性证明

**引理 1（幂的可表达刻画）**：对任意 $i \ge 0$，$2^i$ 可表达 $\iff$ $2^i \in nums$。

**证明**：（⇐）单元素子序列 $\{2^i\}$ 的或即 $2^i$。（⇒）设子序列 $S$ 的或为 $2^i$。或运算逐位独立：结果的第 $j$ 位 $= \max_{x \in S} \text{bit}_j(x)$。结果第 $i$ 位为 1，故存在 $x \in S$ 使 $\text{bit}_i(x) = 1$；结果其余位为 0，故**每个** $x \in S$ 的所有 $j \ne i$ 位全为 0（只要有一个 $x$ 在某 $j \ne i$ 位是 1，结果第 $j$ 位就是 1）。于是每个 $x \in S$ 形如 $2^i$ 或 $0$；由 $nums[x] \ge 1$ 排除 0，故 $x = 2^i$，即 $2^i \in nums$。∎

**引理 2（前缀覆盖 ⇒ 全可表达）**：设 $t \ge 0$ 且 $2^0, 2^1, \dots, 2^{t-1}$ 都在 `nums` 中，则任意 $1 \le x < 2^t$ 都可表达。

**证明**：对 $x$ 的二进制表示，设其 1 位集合为 $B \subseteq \{0, 1, \dots, t-1\}$（因 $x < 2^t$，最高可能位是 $t-1$）。对每个 $i \in B$，从 `nums` 中取**一个**值为 $2^i$ 的元素（$B$ 中各位对应的元素互不相同——因为值不同；下标自然互异可排成递增序列构成子序列）。这些元素的或：第 $i \in B$ 位为 1（恰有该元素贡献），第 $j \notin B$ 位为 0（所有元素除自己那位外全是 0）。故或恰好为 $x$。∎

**定理（算法正确性）**：设 $i^*$ 为最小的使 $2^{i^*} \notin nums$ 的非负整数（由 $nums[j] < 2^{30}$ 知 $i^*$ 存在且 $\le 30$）。则 $2^{i^*}$ 是不可表达的最小非零整数。

**证明**：先证 $2^{i^*}$ 不可表达：由引理 1（⇒ 方向逆否），$2^{i^*} \notin nums$ ⇒ 不可表达。再证无更小者：任取 $1 \le x < 2^{i^*}$，$x$ 的二进制最高位 $< i^*$，其每个 1 位 $i < i^*$ 都满足 $2^i \in nums$（$i^*$ 最小），由引理 2 的论证（把 $t$ 换成 $i^*$），$x$ 可表达。故 $2^{i^*}$ 恰是最小不可表达非零整数。∎

## 6. 复杂度分析

- **时间**：$O(n)$。构建哈希集合一次线性扫描；幂检查至多 31 次、每次 $O(1)$。位掩码变体一次遍历 $O(n)$ + $O(31)$ 找零位。
- **空间**：哈希版 $O(n)$（存至多 $10^5$ 个整数）；位掩码版 $O(1)$（一个 32 位整数）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minImpossibleOR(vector<int>& nums) {
        unordered_set<int> s(nums.begin(), nums.end());
        for (int i = 0; i <= 30; ++i) {        // 2^30 > 1e9 >= nums[i]，必命中
            int p = 1 << i;
            if (!s.count(p)) return p;         // 第一个不在数组里的 2^i
        }
        return -1;                             // 不可达，占位
    }
};
```

### Python

```python
class Solution:
    def minImpossibleOR(self, nums: List[int]) -> int:
        s = set(nums)
        p = 1
        while p in s:                          # 2^30 > 1e9，循环至多 31 次
            p <<= 1
        return p
```

> 💡 两份代码均通过官方示例（`4`、`1`）、全覆盖前缀样例（`[1,2,4,8,3,7] → 16`），以及 C++ 侧 3000 组、Python 侧 800 组随机数组与「子序列或可达集」暴力（逐元素扩张 `reach |= {s | x}`）的对拍，`mismatch = 0`。

## 8. 边界情况与易错点

1. **不要试图 DP 全部可达值**：可达集大小可达 $2^{30}$，任何「显式建集合」的做法都会爆炸；必须利用幂的刻画。
2. **引理 1 的方向别记反**：是「$2^i$ 可表达 ⇒ $2^i$ 在数组中」这条不显眼的方向支撑了算法；反之「在数组中 ⇒ 可表达」是平凡的。两者合并才得「恰等」。
3. **非幂数不需要单独检查**：如 `nums = [3]`，答案不是 3 也不是 1？——$2^0 = 1 \notin \{3\}$，返回 1 ✓（3 的最低位是 1，但 1 本身不可表达：或出的任何结果若含第 0 位则必含第 1 位）。再如 `[3, 2]`：$1$ 仍不可表达（3 带着 2 位），答案 1 ✓。**「某位被某个元素覆盖」不等于「纯该位可表达」**，这是最常见的思维陷阱。
4. **枚举上界**：`for i in 0..30`（含 30）已足够；若写成 `0..29`，在数组恰好含 $2^{29}$（$= 536870912 \le 10^9$）且缺更小幂时不致命（更小幂先命中），但数组为 `[1,2,4,...,2^29]` 全幂覆盖时会漏判返回错误值。`while True` + 数学保证终止最稳。
5. **元素上界与 2 的幂**：$10^9$ 内最大的幂是 $2^{29} = 536870912$；$2^{30} = 1073741824 > 10^9$ 必不在数组。答案上界 $2^{30}$（当 $2^0 \dots 2^{29}$ 全在场时）。
6. **空子序列与零**：题目要求最小**非零**不可表达数；空或为 0，不参与比较。`nums[i] \ge 1` 也不含 0 元素，无需处理「0 在数组中」的分支（若有 0，它对或毫无贡献，可直接忽略）。
7. **位掩码变体的判幂**：`x & (x - 1) == 0` 判 2 的幂时依赖 $x \ge 1$（$x = 0$ 也满足该式但不是幂），本题 $nums[i] \ge 1$ 天然安全。
