# LeetCode 网络延迟时间 题解

## 1. 题目概述

- **标题 / 题号**：网络延迟时间（#743，medium）
- **链接**：https://leetcode.cn/problems/network-delay-time/
- **来源**：LeetCode 第 62 场周赛 Q2
- **难度**：中等
- **标签**：深度优先搜索、广度优先搜索、图、最短路、Dijkstra 算法、堆（优先队列）

**题意**：有 $n$ 个节点（编号 $1 \sim n$），`times` 中每个三元组 $(u_i, v_i, w_i)$ 表示一条**有向边**：信号从 $u_i$ 传到 $v_i$ 要花 $w_i$ 时间（注意是**单向**的，且 $w_i$ 可以为 $0$）。从节点 $k$ 发出一份信号，信号会沿所有出边继续转发。求「**所有**节点都收到信号」所需的最短时间；只要有节点永远收不到，返回 `-1`。

一句话：**求 $k$ 到每个点的最短路，答案是其中最大的那个；若有不可达点则返回 $-1$。**

**约束**：

- $1 \le k \le n \le 100$
- $1 \le \text{times.length} \le 6000$
- $1 \le u_i, v_i \le n$，$u_i \ne v_i$，$0 \le w_i \le 100$
- 所有 $(u_i, v_i)$ 互不相同（无重边，但代码里支持也无妨）

## 2. 示例

**示例 1**

```text
输入：times = [[2,1,1],[2,3,1],[3,4,1]], n = 4, k = 2
输出：2
解释：t=1 时 1 和 3 收到信号，t=2 时 3 把信号转给 4；最晚的节点 4 在 t=2 收到，故答案为 2。
```

**示例 2**

```text
输入：times = [[1,2,1]], n = 2, k = 1
输出：1
解释：唯一的边把信号从 1 送到 2，耗时 1，两个节点都收到。
```

**示例 3**

```text
输入：times = [[1,2,1]], n = 2, k = 2
输出：-1
解释：唯一的边方向是 1 → 2，源点 2 没有任何出边，节点 1 永远收不到信号。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的想法是 **DFS 枚举从 $k$ 出发的所有路径**，对每个节点保留「到达它的最小时间」。图中有环时路径数量是指数级的，虽然可以用「当前累计时间已经不小于已知最优值就剪枝」把多数分支砍掉，但最坏情况（大量 0 权边、稠密环）依然会爆炸，$m = 6000$ 时不可接受。

次一等的暴力是 **Bellman-Ford**：对所有边反复松弛 $n-1$ 轮，复杂度 $O(nm) = 100 \times 6000 = 6\times10^5$，本题完全够用，是最稳的兜底写法。但它没有利用「边权非负」这一额外条件——这正是 Dijkstra 可以做到更快的空间。

### 3.2 核心观察：答案是单源最短路的最大值

![信号传播等价于单源最短路](images/wc62_q2_signal_model.svg)

信号不需要「选一条路」，它会**同时**沿所有出边扩散。因此节点 $v$ 收到信号的时刻就是 $k \to v$ 的**最短路径长度** $\delta(v)$——因为信号总能挑最快的那条路走，而任何一条更慢的路都不会让结果更早。

于是问题变成两件事：

1. 求出 $k$ 到所有点的最短路 $\delta(v)$；
2. 若存在 $\delta(v) = \infty$，返回 $-1$；否则返回 $\max_v \delta(v)$。

**为什么是最大值**：所有节点都收到信号的时刻，等于「最后一个收到信号的节点」的时刻，即 $\max_v \delta(v)$。取最小值没有意义（那是最近的点），累加也不对（各条最短路会共用边，但时间是并行流逝的）。

**为什么能用 Dijkstra**：题目保证 $w_i \ge 0$。非负边权意味着「当前距离最小的未定节点，其最短路已经被确定」，贪心成立；一旦出现负权边，这个结论就崩了，必须换 Bellman-Ford。

### 3.3 算法流程：Dijkstra + 小根堆

![Dijkstra 流程：小根堆 + 惰性删除](images/wc62_q2_dijkstra_flow.svg)

用邻接表建图，堆里存 `(当前距离, 节点)`：

1. `dist[k] = 0`，其余为 $\infty$；堆初始为 `{(0, k)}`。
2. 反复弹出堆顶 `(d, u)`：
   - 若 `d > dist[u]`，说明这是同一节点被更新多次后残留的**过期项**，直接丢弃（惰性删除，省掉「修改堆中元素」的麻烦）；
   - 否则 $u$ 的最短路已确定。遍历 $u$ 的每条出边 $(u \to v, w)$，若 `dist[u] + w < dist[v]`，就更新 `dist[v]` 并把 `(dist[v], v)` 入堆。
3. 堆空后检查 $1 \sim n$ 的 `dist`：有 $\infty$ 就返回 $-1$，否则返回最大值。

每个节点可能被多次入堆，但每次入堆都由一次成功的松弛引起，所以总入堆次数不超过 $m+n$，堆操作代价 $O(\log m)$。

### 3.4 示例演算

![示例 1 的 Dijkstra 走查](images/wc62_q2_walkthrough.svg)

对示例 1（`times = [[2,1,1],[2,3,1],[3,4,1]]`，$n=4$，$k=2$，表中 `dist` 为该轮**出堆时刻**的值，动作列写本轮松弛的结果）：

| 轮次 | 出堆 | `dist[1..4]` | 动作 |
|------|------|--------------|------|
| 初始 | — | $[\infty, 0, \infty, \infty]$ | 只有源点已知 |
| 1 | $(0, 2)$ | $[\infty, 0, \infty, \infty]$ | 松弛 $2\to1$、$2\to3$，两者都变成 $1$ |
| 2 | $(1, 1)$ | $[1, 0, 1, \infty]$ | 节点 1 无出边，空转 |
| 3 | $(1, 3)$ | $[1, 0, 1, \infty]$ | 松弛 $3\to4$，`dist[4] = 2` |
| 4 | $(2, 4)$ | $[1, 0, 1, 2]$ | 无出边，堆空结束 |

最终 `dist = [1, 0, 1, 2]`，无 $\infty$，答案 $\max\{1,0,1,2\} = 2$。

> 💡 第 1 轮同时把 1、3 的距离更新成 1，堆中出现并列的 `(1,1)` 与 `(1,3)`。按节点号先弹出 1 纯属实现细节；先弹谁都不影响结果，因为 3 的距离已经是最优值，不会被 1 再改进。

## 4. 算法细节

1. **节点编号 1-indexed**：邻接表开 `n + 1` 个槽位，`dist[0]` 只作占位，统计答案时从 $1$ 遍历到 $n$，不要把占位的 `dist[0]` 算进最大值。
2. **惰性删除**：`if (d > dist[u]) continue;` 是性能与正确性的双保险——过期项被丢弃，而「弹出的 $d$ 等于 `dist[u]`」保证 $u$ 的最短路已确定，可以安全地用它松弛。
3. **INF 的取法**：C++ 用 `INT_MAX` 时 `d + w` 会溢出成负数，导致错误更新。要么取 `0x3f3f3f3f`（$\approx 1.06\times10^9$，加 $100$ 不溢出），要么显式判断 `dist[u] != INF`。Python 直接用 `float('inf')`。
4. **零权边不影响正确性**：Dijkstra 只要求边权非负，$w = 0$ 完全合法；但若把「出堆时标记 `visited`，入堆前检查 `visited`」写混，零权边容易漏松弛，用惰性删除的写法天然没有这个坑。
5. **`ans` 初值为 0**：源点自身 `dist[k] = 0`，当 $n = 1$ 或无出边但只有源点时答案应是 0，而不是 $-1$。
6. **可选写法**：$n \le 100$ 时 Floyd-Warshall（$O(n^3) = 10^6$）也很好写；Bellman-Ford（$O(nm)$）最稳。三种解法都能通过本题，Dijkstra 是通用性最好的模板。

## 5. 正确性证明

设 $\delta(v)$ 为 $k \to v$ 的真实最短路径长度（不可达记 $+\infty$），`dist[v]` 为算法维护的当前值。

**引理 1（路径性）**：算法任意时刻，若 `dist[v]` 有限，则存在一条 $k \to v$ 的真实路径，其长度恰为 `dist[v]`。

**证明**：初始时只有 `dist[k] = 0`，对应长度为 0 的空路径。每次更新 `dist[v] = dist[u] + w` 都以「一条长度为 `dist[u]` 的 $k \to u$ 路径」为基础再拼接边 $u \to v$，拼接后的总长仍是一条真实路径的长度。∎

**引理 2（下界性）**：算法任意时刻 `dist[v] >= δ(v)`。

**证明**：由引理 1，`dist[v]` 是某条真实路径的长度，而 $\delta(v)$ 是所有路径长度的最小值，故 `dist[v] >= δ(v)`。∎

**引理 3（贪心正确性）**：若某次弹出的 `(d, u)` 满足 $d = \text{dist}[u]$，则 $\text{dist}[u] = \delta(u)$，且此后不再改变。

**证明**：反设 $u$ 是**第一个**出堆时 `dist[u] > δ(u)` 的节点，记 $d = \text{dist}[u]$。取一条真实最短路 $k = p_0 \to p_1 \to \dots \to p_m = u$。先注意 $d = \text{dist}[u] > \delta(u) \ge 0$，而 $k$ 的堆键为 `dist[k] = 0`，堆顶取最小键，故 $p_0 = k$ 必已出堆。设 $p_i$ 是这条路径上**第一个尚未出堆**的节点（$i \ge 1$）。

于是 $p_{i-1}$ 已出堆且（由 $u$ 的极小性）$\text{dist}[p_{i-1}] = \delta(p_{i-1})$。当 $p_{i-1}$ 出堆时，算法松弛了边 $(p_{i-1}, p_i)$，得到

$$\text{dist}[p_i] \le \delta(p_{i-1}) + w(p_{i-1}, p_i) = \delta(p_i)$$

再由引理 2 得 $\text{dist}[p_i] \ge \delta(p_i)$，故 $\text{dist}[p_i] = \delta(p_i)$，且该值对应的堆元素已存在于堆中（键为 $\delta(p_i)$）。

因为 $p_i$ 在最短路上位于 $u$ 之前且不是 $u$（$p_i$ 尚未出堆，而 $u$ 正在出堆），有 $\delta(p_i) \le \delta(u) < \text{dist}[u] = d$。堆顶弹出的键 $d$ 是堆中最小键，而堆中存在键 $\delta(p_i) < d$，矛盾。故不存在这样的 $u$。∎

**定理**：算法终止时，对所有可达节点 $\text{dist}[v] = \delta(v)$；不可达节点保持 $\infty$。因此返回值「有 $\infty$ 则 $-1$，否则 $\max_v \delta(v)$」正确。

**证明**：

- **可达性**：沿最短路用归纳法证明每个可达节点都会入堆：$k$ 入堆；若 $p_{i-1}$ 入堆，它终将出堆（堆空才终止），出堆时会松弛 $(p_{i-1}, p_i)$ 使 $\text{dist}[p_i]$ 成为有限值并入堆。
- **取值**：每个可达节点都会出堆（堆空才终止），由引理 3 出堆时 `dist` 已等于 $\delta$，且之后不会再被改进，故终止时 `dist[v] = δ(v)`。
- **不可达**：不可达节点没有任何从 $k$ 出发的路径，由引理 1 的逆否命题其 `dist` 始终为 $\infty$，算法自然返回 $-1$。
- **答案**：信号以最短路速度传播，节点 $v$ 在 $\delta(v)$ 时刻收到；「全部收到」的时刻即 $\max_v \delta(v)$。∎

## 6. 复杂度分析

- **时间**：建图 $O(n + m)$。每条边最多引起一次成功松弛、一次入堆，故堆操作共 $O(m)$ 次，每次 $O(\log m)$；出堆总次数也是 $O(m)$，合计 $O((n + m)\log m)$。本题 $m \le 6000$，约 $10^5$ 量级，远低于限制（对比 Bellman-Ford 的 $O(nm)$ 与 Floyd 的 $O(n^3)$，本题数据下同样能过）。
- **空间**：邻接表 $O(n + m)$；`dist` 数组 $O(n)$；堆最坏存 $O(m)$ 个元素。总计 $O(n + m)$，常数很小。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <queue>
#include <functional>
#include <algorithm>
using namespace std;

class Solution {
public:
    int networkDelayTime(vector<vector<int>>& times, int n, int k) {
        vector<vector<pair<int, int>>> graph(n + 1);
        for (auto& e : times) {
            graph[e[0]].push_back({e[1], e[2]});   // 有向边 u -> v，权 w
        }

        const int INF = 0x3f3f3f3f;                // 加 100 也不会溢出 int
        vector<int> dist(n + 1, INF);
        // 小根堆：按距离升序弹出
        priority_queue<pair<int, int>, vector<pair<int, int>>, greater<>> pq;

        dist[k] = 0;
        pq.push({0, k});

        while (!pq.empty()) {
            auto [d, u] = pq.top();
            pq.pop();
            if (d > dist[u]) continue;             // 惰性删除：过期项直接丢弃

            for (auto [v, w] : graph[u]) {
                if (d + w < dist[v]) {
                    dist[v] = d + w;
                    pq.push({dist[v], v});
                }
            }
        }

        int ans = 0;
        for (int v = 1; v <= n; ++v) {
            if (dist[v] == INF) return -1;         // 有节点永远收不到信号
            ans = max(ans, dist[v]);
        }
        return ans;
    }
};
```

### Python

```python
import heapq
from typing import List


class Solution:
    def networkDelayTime(self, times: List[List[int]], n: int, k: int) -> int:
        graph = [[] for _ in range(n + 1)]
        for u, v, w in times:
            graph[u].append((v, w))          # 有向边 u -> v，权 w

        INF = float('inf')
        dist = [INF] * (n + 1)
        dist[k] = 0
        pq = [(0, k)]                        # 小根堆，元素 (距离, 节点)

        while pq:
            d, u = heapq.heappop(pq)
            if d > dist[u]:                  # 惰性删除：过期项跳过
                continue
            for v, w in graph[u]:
                nd = d + w
                if nd < dist[v]:
                    dist[v] = nd
                    heapq.heappush(pq, (nd, v))

        ans = 0
        for v in range(1, n + 1):
            if dist[v] == INF:               # 存在不可达节点
                return -1
            ans = max(ans, dist[v])
        return ans
```

## 8. 边界情况与易错点

1. **先判不可达，再取最大值**：如果先算 `max(dist[1..n])` 再判断，$\infty$ 会污染结果；正确顺序是「遍历时一旦遇到 $\infty$ 立刻返回 $-1$」。
2. **`dist[0]` 是占位**：从 $1$ 开始循环。若从 $0$ 开始，`dist[0] = INF` 会让所有用例都返回 $-1$（而 `0` 号位本不该被访问）。
3. **`d + w` 溢出**：`INF = INT_MAX` 时 `INT_MAX + 100` 回绕成负数，可能被当成更短距离写回 `dist`，产生错误答案。用 `0x3f3f3f3f` 或 `INT_MAX / 2`。
4. **`k` 自身**：`dist[k] = 0`，答案初值取 `0`。虽然本题 `times` 非空且 $u_i \ne v_i$，但 `n = 1`、或源点孤立（只有入边）时答案应为 `0` 而不是 `-1`。
5. **零权边的死循环风险**：$w = 0$ 时松弛条件必须写成严格小于 `nd < dist[v]`；若写成 `<=`，两个由 0 权边相连的点会不断把 `(0, v)` 重新入堆，`d > dist[u]` 拦不住（此时 `d == dist[u]`），程序死循环。
6. **不要用「入堆时即定稿」的 visited**：若在松弛前就标记 `visited[v] = true`，会拦住后续更优路径。要么出堆时标记，要么像本解一样用惰性删除。
7. **无重边假设不要当成算法依赖**：题面保证无重边，但把「重边取最小」交给松弛逻辑处理，代码更健壮。

**延伸思考**：

1. 若信号会**沿双向边**传播（无向图），只需把每条 `times[i]` 拆成两条有向边，算法完全不变。
2. 若要求「让所有节点收到信号的最早时刻」但允许**从多个源点**同时发信号，就是**多源最短路**：把所有源点初始 `dist = 0` 一起入堆即可（等价于加一个超级源点）。
3. 若 $w_i$ 可能为负但无负环，Dijkstra 失效，应改用 SPFA / Bellman-Ford；若存在负环且要求「所有点都收到」，则最短时间无定义（可无限变小），需要先判负环。
4. 本题也可以二分答案 + BFS 判定：二分时间 $T$，只保留 $w \le T$ 的「单边可行性」并不可行（路径是累加的），所以二分的正确做法是判定「存在一条总长 $\le T$ 的路径」，那又回到了最短路——可见最短路才是本题的本质结构。
