# LeetCode 二叉树最近的叶节点 题解

## 1. 题目概述

- **标题 / 题号**：二叉树最近的叶节点（#742，中等）
- **链接**：https://leetcode.cn/problems/closest-leaf-in-a-binary-tree/
- **来源**：LeetCode 第 62 场周赛 Q3
- **难度**：中等
- **标签**：树、深度优先搜索、广度优先搜索、二叉树

**题意**：给定一棵节点值互不相同的二叉树与一个目标值 `k`，返回离「值等于 `k` 的那个节点」**最近的叶节点**的值。这里「最近」指在树上走过的**边数最少**；「叶节点」指**没有任何孩子**的节点。若有多个叶节点并列最近，返回其中任意一个都可以。

**约束**：

- 树中节点数在 $[1, 1000]$ 之间
- 每个节点的值唯一，范围 $[1, 1000]$
- 保证树中一定存在某个节点的值等于 `k`

## 2. 示例

**示例 1**

```text
输入：root = [1,3,2]，k = 1
输出：2（或 3）
解释：1 有两个孩子 3（左）与 2（右），二者都是叶，都只需要走 1 条边，
      所以 2 和 3 都是正确答案，返回哪个都行。
```

**示例 2**

```text
输入：root = [1]，k = 1
输出：1
解释：全树只有一个节点，根就是叶，目标节点到自己的距离为 0。
```

**示例 3**

```text
输入：root = [1,2,3,4,null,null,null,5,null,6]，k = 2
输出：3
解释：树形为 1 的左孩子 2、右孩子 3；2 的左孩子 4；4 的左孩子 5；5 的左孩子 6。
      叶只有两个：3 与 6。2 到 3 的距离是 2（2 → 1 → 3），
      2 到 6 的距离是 4（2 → 4 → 5 → 6），故答案是 3 而不是 6。
```

## 3. 解题思路

### 3.1 暴力思路

最直白的做法是：先收集所有叶节点，再对每个叶节点求它到 `k` 的距离，取最小值。

难点在「求距离」：二叉树只有指向孩子的指针，没有指向父节点的指针。于是每种求法都很别扭——

- 对每个叶节点做一次 DFS，看能否走到 `k`，走到时用栈长当距离：单次 $O(n)$，总共 $O(n^2)$；
- 或者先 DFS 出父子关系，再对每对「目标、叶」用 LCA 算距离：$O(n^2)$ 甚至 $O(n^2 \log n)$。

$n \le 1000$ 时 $O(n^2)$ 确实能过，但它把「树上路径唯一」这个最好的性质浪费了——真正的问题是**信息只能单向流动**（父 → 子），而答案可能需要「先向上、再向下」，例如示例 3 的目标 2 必须先走到父节点 1 才能到叶 3。正确的破题方式是**把单向的树边补成双向**。

### 3.2 核心观察：树换成无向图，最近叶 = 图上离 k 最近的叶

![把二叉树变成无向图：向上走也合法](images/wc62_q3_tree_to_graph.svg)

**关键观察 1**：二叉树的边本来就表示「相邻」，把它当作**无向边**看待，就得到一张 $n$ 个点、$n-1$ 条边的无向连通图 $G$。

**关键观察 2**：在树上，任意两点之间的简单路径**唯一**，而且这条路径可能先向上经过若干祖先（LCA），再向下走到目标。把边对称化之后，「向上走」就是图上一条正常的边，不需要任何特判。

**关键观察 3**：$G$ 的所有边权都是 1，于是「最近」等价于**无权图上的最短距离**，而 BFS 按距离分层扩展，天然给出最短距离。

于是问题变形为：在无向图 $G$ 上，从节点 `k` 出发做 BFS，**最早出队的叶节点**就是答案。注意这里「叶」必须按原树的语义判定（左右孩子都为空），不能用「图中度数为 1」来代替——根节点只有一个孩子时度数是 1，但它不是叶。

### 3.3 算法流程

![BFS 从 k 出发按距离分层，第一个叶节点即答案](images/wc62_q3_bfs_layers.svg)

1. **一次 DFS 建图**：用显式栈遍历原树，对每个节点 $u$ 与它存在的每个孩子 $c$，在邻接表里加双向边 $u \leftrightarrow c$，同时把 $u$ 记入 `hasChild` 集合（表示「$u$ 有孩子」）。
2. **顺手定位目标**：遍历过程中若 `u->val == k`，记下这个节点指针 `target`，避免之后再花 $O(n)$ 找它。
3. **BFS**：把 `target` 入队并标记已访问。每次取队首 $u$：若 $u \notin$ `hasChild`（即左右孩子都为空），立刻返回 `u->val`；否则把 $u$ 所有未访问的邻居入队。
4. 因为题目保证 `k` 存在且树中至少有一个叶，BFS 一定会返回。

**为什么可以「一碰到叶就返回」**：BFS 出队的距离单调不减，所以第一个出队的叶节点，其距离不会大于任何其它叶节点，直接就是最优解。

### 3.4 示例演算

![示例 3 的 BFS 出队过程](images/wc62_q3_walkthrough.svg)

对示例 3（树形 `1(2(4(5(6))), 3)`，`k = 2`），各节点到 2 的距离与 BFS 出队过程：

| 出队顺序 | 节点 | 到 2 的距离 | 是否叶 | 新入队（距离 + 1） |
|----------|------|-------------|--------|--------------------|
| 1 | 2 | 0 | 否（有左孩子 4） | 1(1)、4(1) |
| 2 | 1 | 1 | 否（有右孩子 3） | 3(2) |
| 3 | 4 | 1 | 否（有左孩子 5） | 5(2) |
| 4 | 3 | 2 | **是 ✓** | — → 返回 3 |

叶 6 要到距离 3 才被访问到，比 3 更远，因此答案为 3。同层内部的出队先后由邻接表顺序决定，但**不影响结论**：第 2 层里只有 3 是叶，所以无论先处理 1 还是 4，叶 3 都一定早于层 3 的叶 6 出队。

再验示例 1：`root = [1,3,2]`、`k = 1`。1 的两个孩子 3 与 2 都是叶，距离都是 1，BFS 返回先入队的那一个，两者都合法。示例 2 中 `k` 本身就是叶，循环第一轮就返回。

## 4. 算法细节

1. **邻接表的键**：C++ 用 `unordered_map<TreeNode*, vector<TreeNode*>>`（指针可直接做哈希键），Python 用 `dict`（`TreeNode` 对象可哈希）。因为节点值唯一且不超过 1000，也可以先把值映射成 $[0,1000]$ 的下标，用数组 + 链式前向星，省掉哈希开销。
2. **叶的判定必须用「有没有孩子」**：维护 `hasChild` 集合，建图时只要给 $u$ 连了孩子就把 $u$ 加进去。千万不要写成 `adj[u].size() == 1`：根只有单侧孩子时度数是 1 却不是叶，而 `k` 本身是叶时度数可能也是 1。
3. **用迭代而非递归**：$n$ 最大 1000，退化成一条链时递归深度就是 1000，Python 默认递归上限 1000 会直接 `RecursionError`。建图与 BFS 都用显式栈/队列。
4. **`target` 在建图时定位**：BFS 前不要再用一次遍历按值查找，否则多花 $O(n)$；建树时顺手记录最省。
5. **提前返回的正确性依赖 BFS 性质**：出队时才检查叶，而不是入队时检查。入队检查也正确，但要注意「源点本身就是叶」的边界；统一在出队处检查更不容易漏。
6. **不建图的替代写法（两遍树形 DP）**：定义 $down[u]$ 为 $u$ 到其子树内最近叶的距离，$down[u]=0$（$u$ 为叶）或 $1+\min_{c} down[c]$；再自顶向下维护 $up[c]=1+\min\bigl(up[u],\ \min_{s \ne c}(1+down[s])\bigr)$，其中 $up[u]$ 表示从 $u$ 的父侧（子树外）到最近叶的距离。答案即 $\min(down[k], up[k])$。每个节点只需记录孩子 `down` 值的最小与次小，就能 $O(1)$ 算出「除 $c$ 以外兄弟的最优值」，总时间仍是 $O(n)$，且不需要邻接表。
7. **并列答案的处理**：题目明确「返回任一最近叶」，所以不要在实现里额外加「取最小值」之类的规则；反过来，自测/对拍时也**不能**写死期望值，只能比较距离是否等于最小距离、返回的是否是叶。
8. **值域**：`node.val` 在 $[1,1000]$ 内且唯一，可作为 `visited` 的天然键（用布尔数组），比 `unordered_set` 更快。

## 5. 正确性证明

**引理 1（图距离 = 树距离）**：在把树边对称化得到的无向图 $G$ 中，`k` 到任意节点 $x$ 的最短距离，等于原树中从 `k` 到 $x$ 的唯一路径上的边数。

**证明**：原树中 `k` 到 $x$ 的唯一路径在 $G$ 中依然存在（每条边都保留了），故 $dist_G(k,x) \le$ 树距离。反过来，$G$ 中任意一条 $k \to x$ 的路径，都可以删去其中的重复顶点（回路）而得到一条无重复顶点的简单路径，其边数不增；而树中两点间的简单路径唯一，故任何 $G$ 路径的长度都不小于树距离，即 $dist_G(k,x) \ge$ 树距离。两边夹得相等。∎

**引理 2（BFS 分层非降）**：BFS 中节点按 $dist_G(k,\cdot)$ 非降的顺序出队。

**证明**：对队列中的元素做归纳。初始只有 $k$（距离 0）。若队首距离为 $d$，则由它新入队的邻居距离为 $d+1$，都排在队尾，而队列中已有的元素距离 $\ge d$，故出队序列非降。∎

**引理 3（叶判定等价）**：`u` 不在 `hasChild` 中 $\iff$ `u` 在原树中是叶。

**证明**：建图时，对 $u$ 的每个存在的孩子 $c$ 都会把 $u$ 插入 `hasChild`；因此 $u \in$ `hasChild` 当且仅当 $u$ 至少有一个孩子，取反即得结论。∎

**定理**：算法返回的节点是叶，且它到 `k` 的距离在所有叶节点中最小。

**证明**：设算法返回 $u^{*}$，它是 BFS 中第一个出队的叶节点（算法正是在出队时做检查并返回）。由引理 3，$u^{*}$ 是叶。由引理 2，任意其它叶 $v$ 要么与 $u^{*}$ 同层（距离相等），要么在 $u^{*}$ 之后出队（距离更大），故 $dist_G(k,v) \ge dist_G(k,u^{*})$。再由引理 1，$dist_G$ 就是树上的边数距离，所以 $u^{*}$ 的树距离也是所有叶中最小的。∎

## 6. 复杂度分析

- **时间**：$O(n)$。建图 DFS 访问每个节点一次、每条边两次（双向），$O(n)$；BFS 中每个节点最多入队一次、每条无向边被检查两次，也是 $O(n)$。哈希表操作为均摊 $O(1)$。
- **空间**：$O(n)$。邻接表存 $2(n-1)$ 条边加 $n$ 个表头；`hasChild` 最多 $n-1$ 个元素；`visited` 与 BFS 队列各 $O(n)$；建图的显式栈 $O(n)$。递归版会有 $O(h)$ 的调用栈，迭代版把这部分也放进显式栈，本质仍是 $O(n)$。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <queue>
#include <unordered_map>
#include <unordered_set>
using namespace std;

class Solution {
public:
    int findClosestLeaf(TreeNode* root, int k) {
        unordered_map<TreeNode*, vector<TreeNode*>> adj;  // 树边对称化后的无向图
        unordered_set<TreeNode*> hasChild;                // 有孩子的节点
        TreeNode* target = nullptr;

        // 迭代 DFS 建图，同时定位目标节点
        vector<TreeNode*> st{root};
        while (!st.empty()) {
            TreeNode* u = st.back();
            st.pop_back();
            if (u->val == k) target = u;
            TreeNode* kids[2] = {u->left, u->right};
            for (TreeNode* c : kids) {
                if (!c) continue;
                adj[u].push_back(c);
                adj[c].push_back(u);
                hasChild.insert(u);
                st.push_back(c);
            }
        }

        // BFS：第一个出队的叶节点就是最近叶
        queue<TreeNode*> q;
        unordered_set<TreeNode*> visited;
        q.push(target);
        visited.insert(target);
        while (!q.empty()) {
            TreeNode* u = q.front();
            q.pop();
            if (!hasChild.count(u)) return u->val;        // 左右孩子都为空 => 叶
            for (TreeNode* v : adj[u]) {
                if (!visited.count(v)) {
                    visited.insert(v);
                    q.push(v);
                }
            }
        }
        return -1;                                        // 题意保证不会走到这里
    }
};
```

### Python

```python
from collections import deque

class Solution:
    def findClosestLeaf(self, root: 'TreeNode', k: int) -> int:
        adj = {}            # 无向图：节点 -> 邻居列表
        has_child = set()   # 有孩子的节点
        target = None

        stack = [root]
        while stack:                              # 迭代 DFS 建图
            u = stack.pop()
            adj.setdefault(u, [])
            if u.val == k:
                target = u
            for c in (u.left, u.right):
                if c is not None:
                    adj[u].append(c)
                    adj[c].append(u)
                    has_child.add(u)
                    stack.append(c)

        q = deque([target])
        visited = {target}
        while q:                                  # BFS：按距离非降地扩展
            u = q.popleft()
            if u not in has_child:                # 左右孩子都为空 => 叶
                return u.val
            for v in adj[u]:
                if v not in visited:
                    visited.add(v)
                    q.append(v)
        return -1                                 # 题意保证不会走到这里
```

## 8. 边界情况与易错点

1. **`k` 本身就是叶**（含单节点树）：答案就是 `k` 自己，距离 0。BFS 第一轮出队就要返回，不要漏掉这个「零步」情形。
2. **用度数判叶会错**：根节点只有一个孩子时在图中的度数为 1，但它不是叶；`k` 恰好是叶时度数也可能是 1。必须用「左右孩子均为空」判定。
3. **忘记「向上走」**：示例 3 就是典型陷阱——只搜 `k` 的子树会得到 6，正确答案是经父节点 1 到叶 3。对称化树边后这个错误自然不会发生。
4. **递归深度**：链状树有 1000 层，Python 递归默认上限约 1000，容易 `RecursionError`；C++ 一般能过但也没必要冒栈溢出的风险，统一写成迭代。
5. **并列最近叶**：示例 1 中 2 与 3 都是答案，返回谁都对；写测试时必须比较「距离是否为最小」而不是写死某个值。
6. **`target` 不要用值再查一遍**：若在 BFS 前遍历找 `k`，等于白白多扫一遍；建图时顺手记录即可。
7. **`hasChild` 只在孩子存在时才插入**：如果把 `hasChild.add(u)` 写在判断孩子是否存在之前（或对 `null` 也建边），所有节点都会变成「非叶」，BFS 会一路跑空并返回 `-1`。
