# LeetCode 下降路径最小和 题解

## 1. 题目概述

- **标题 / 题号**：下降路径最小和（#931，medium）
- **链接**：https://leetcode.cn/problems/minimum-falling-path-sum/
- **来源**：LeetCode 第 108 场周赛 Q3
- **难度**：中等
- **标签**：数组、动态规划、矩阵

**题意**：给定 $n \times n$ 的整数矩阵 `matrix`。一条**下降路径**从第一行的任意元素出发，每行恰好选一个元素，且相邻两行的列下标最多相差 1（即从 $(r,c)$ 只能走到 $(r+1,c-1)$、$(r+1,c)$、$(r+1,c+1)$）。求所有下降路径中元素和的**最小值**。

**约束**：

- $1 \le n \le 100$
- $-100 \le \text{matrix}[i][j] \le 100$
- $n = \text{matrix.length} = \text{matrix}[i].\text{length}$

> 💡 元素**可以为负**，所以不能像「最短路径 BFS」那样按步数剪枝，也不能贪心取每行最小值——必须老老实实做 DP。

## 2. 示例

**示例 1**

```text
输入：matrix = [[2,1,3],[6,5,4],[7,8,9]]
输出：13
解释：最优路径之一为 1 → 5 → 7，和为 13；另一条 1 → 4 → 8 也是 13。
```

**示例 2**

```text
输入：matrix = [[-19,57],[-40,-5]]
输出：-59
解释：路径 1 → -40（第一步走左下），和为 -19 + (-40) = -59。
```

**示例 3（补充）**

```text
输入：matrix = [[-100]]
输出：-100
解释：只有一行一列。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有下降路径：第一行 $n$ 种起点，之后每步至多 3 种选择，路径总数为 $O(n \cdot 3^n)$。$n = 100$ 时是天文数字，即使加记忆化也要先意识到「状态只有 $(r, c)$」。

另一些看似聪明但错误的做法：

- **每行取最小值**：示例 1 第一行最小值是 1（列 1），第二行最小值是 4（列 2，与列 1 相邻，合法），第三行最小值是 7（列 0）——但列 2 与列 0 相差 2，这一步不合法，于是贪心拼出的「12」根本不是一条合法路径。
- **只从最小元素出发做 BFS**：负权下「当前和最小」不保证后续最优。

### 3.2 核心观察：状态就是「落到某个格子的最小路径和」

![状态转移：每个格子只看上一行的三个邻居](images/wc108_q3_dp_concept.svg)

定义
$$\text{dp}[r][c] = \text{从第一行出发、落到 } (r, c) \text{ 的所有下降路径的最小和}$$
边界：$\text{dp}[0][c] = \text{matrix}[0][c]$（起点可以是第一行任意元素）。
转移：落到 $(r,c)$ 之前，上一步只能来自 $(r-1, c-1)$、$(r-1, c)$、$(r-1, c+1)$ 三者之一，故
$$\text{dp}[r][c] = \text{matrix}[r][c] + \min\bigl(\text{dp}[r-1][c-1],\ \text{dp}[r-1][c],\ \text{dp}[r-1][c+1]\bigr)$$
（越界的邻居直接忽略。）

答案是最后一行的最小值：$\min_c \text{dp}[n-1][c]$。

**最优子结构**：一旦确定了「路径经过 $(r,c)$」，那么它在这一段之前的部分必须是「落到 $(r,c)$ 的最优路径」——否则把前半段换成更优的，整条路径也会更优。这正是 DP 合法性的依据（见引理 1）。

### 3.3 算法流程

![算法流程：逐行滚动](images/wc108_q3_algorithm_flow.svg)

```text
1. dp = matrix[0]                     # 第一行
2. for r = 1 .. n-1:
       ndp = new array(n)
       for c = 0 .. n-1:
           best = dp[c]
           if c > 0:     best = min(best, dp[c-1])
           if c < n-1:   best = min(best, dp[c+1])
           ndp[c] = best + matrix[r][c]
       dp = ndp
3. 返回 min(dp)
```

由于第 $r$ 行只依赖第 $r-1$ 行，可以用两个一维数组滚动，空间降到 $O(n)$。

### 3.4 示例演算

![示例演算：3×3 矩阵](images/wc108_q3_walkthrough.svg)

`matrix = [[2,1,3],[6,5,4],[7,8,9]]`：

| 行 | dp 值 | 计算过程 |
|----|-------|----------|
| 0 | `[2, 1, 3]` | 初始行 |
| 1 | `[7, 6, 5]` | $7 = \min(2,1)+6$；$6 = \min(2,1,3)+5$；$5 = \min(1,3)+4$ |
| 2 | `[13, 13, 14]` | $13 = \min(7,6)+7$；$13 = \min(7,6,5)+8$；$14 = \min(6,5)+9$ |

最后一行最小值 13，对应路径 $1 \to 5 \to 7$（或 $1 \to 4 \to 8$），与官方输出一致。

示例 2：`dp = [-19, 57]`，第二行 $c=0$：$\min(-19,57) + (-40) = -59$；$c=1$：$\min(-19,57) + (-5) = -24$；取最小 $-59$。

## 4. 算法细节

1. **负权不影响 DP**：DP 求的是「所有路径」上的最小值，不依赖元素非负；但这也意味着**不能用「当前和已经很大就剪枝」**的搜索。
2. **边界列**：$c = 0$ 只有两个来源（$0$ 与 $1$），$c = n-1$ 同理；用 `if` 保护即可，不要给越界位置填 `0`——`0` 可能比真实值更小，会污染最小值。
3. **第一行的初值**：直接取 `matrix[0]`，不要初始化成 `0` 或 `INF`（否则 $n = 1$ 时答案错）。
4. **滚动数组**：`ndp` 必须单独分配，不能原地覆盖 `dp`，否则同一行的更新会互相污染（$c$ 依赖 $c-1$ 的**上一行**值）。
5. **`min` 的比较对象**：先取 `dp[c]` 作为初值，再逐个比较左右邻居，避免写三个嵌套 `min` 时括号错位。
6. **答案类型**：$n \le 100$、$|matrix[i][j]| \le 100$，路径和范围 $[-10^4, 10^4]$，`int` 足够。

## 5. 正确性证明

记 $P(r,c)$ 为「从第一行某元素出发、落到 $(r,c)$ 的全部下降路径」的集合，$\text{dp}[r][c] = \min_{p \in P(r,c)} \text{sum}(p)$。

**引理 1（最优子结构）**：设路径 $p \in P(r,c)$ 且 $r \ge 1$，其在第 $r-1$ 行的位置为 $(r-1, c')$，$c' \in \{c-1, c, c+1\}$。则 $p$ 的前缀 $p'$（从第一行到 $(r-1,c')$ 的部分）满足：若 $p$ 是 $P(r,c)$ 中的最优路径，则 $p'$ 是 $P(r-1,c')$ 中的最优路径。

**证明**：反设存在 $p'' \in P(r-1,c')$ 使 $\text{sum}(p'') < \text{sum}(p')$。则把 $p$ 的前缀替换为 $p''$ 得到一条新的下降路径 $q \in P(r,c)$（因为 $p''$ 的终点仍是 $(r-1,c')$，与 $(r,c)$ 相邻性不变），且
$$\text{sum}(q) = \text{sum}(p'') + \text{matrix}[r][c] < \text{sum}(p') + \text{matrix}[r][c] = \text{sum}(p)$$
与 $p$ 最优矛盾。∎

**引理 2（转移方程正确）**：对 $r \ge 1$，
$$\text{dp}[r][c] = \text{matrix}[r][c] + \min_{c' \in \{c-1,c,c+1\} \cap [0,n)} \text{dp}[r-1][c']$$

**证明**：任一 $p \in P(r,c)$ 由「前缀 $p' \in P(r-1,c')$」加「格子 $(r,c)$」组成，$c'$ 取遍合法邻居，且
$$\text{sum}(p) = \text{sum}(p') + \text{matrix}[r][c]$$
于是
$$\text{dp}[r][c] = \min_{c'} \min_{p' \in P(r-1,c')}\bigl(\text{sum}(p') + \text{matrix}[r][c]\bigr) = \text{matrix}[r][c] + \min_{c'} \text{dp}[r-1][c']$$
（第二个等号用到：对每个固定 $c'$，$\min_{p'}$ 就是 $\text{dp}[r-1][c']$；求和的常数可直接提出）。注意这里把「按最后一个格子分组」的划分是完备且不重叠的——每条路径的最后一步唯一确定 $c'$。∎

**引理 3（边界一致）**：$\text{dp}[0][c] = \text{matrix}[0][c]$ 与定义一致。

**证明**：$P(0,c)$ 中只有一条路径：仅含格子 $(0,c)$，和为 $\text{matrix}[0][c]$。∎

**定理**：算法返回值为所有下降路径和的最小值。

**证明**：由引理 3，第 0 行正确；由引理 2 归纳，每一行的 `dp` 都等于定义中的 $\text{dp}[r][c]$。一条合法的下降路径必然终于最后一行某列 $c$，故全体路径的最小和
$$\min_{p} \text{sum}(p) = \min_{c} \min_{p \in P(n-1,c)} \text{sum}(p) = \min_c \text{dp}[n-1][c]$$
正是算法的返回值。∎

## 6. 复杂度分析

- **时间**：$O(n^2)$。每行 $n$ 个格子、每格常数次比较，共 $n$ 行；$n = 100$ 时 $10^4$ 次操作。
- **空间**：$O(n)$。滚动数组只保留上一行（若保存整张表则为 $O(n^2)$）。
- **对比**：暴力枚举 $O(n \cdot 3^n)$ 完全不可行；记忆化搜索虽同为 $O(n^2)$，但递归与哈希开销更大。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minFallingPathSum(vector<vector<int>>& matrix) {
        int n = (int)matrix.size();
        vector<int> dp = matrix[0];          // dp[c]：落到当前行第 c 列的最小路径和
        for (int r = 1; r < n; ++r) {
            vector<int> ndp(n);
            for (int c = 0; c < n; ++c) {
                int best = dp[c];                       // 正上方
                if (c > 0) best = min(best, dp[c - 1]);  // 左上方
                if (c + 1 < n) best = min(best, dp[c + 1]);  // 右上方
                ndp[c] = best + matrix[r][c];
            }
            dp.swap(ndp);
        }
        return *min_element(dp.begin(), dp.end());
    }
};
```

### Python

```python
class Solution:
    def minFallingPathSum(self, matrix: list[list[int]]) -> int:
        n = len(matrix)
        dp = list(matrix[0])
        for r in range(1, n):
            ndp = [0] * n
            for c in range(n):
                best = dp[c]
                if c > 0:
                    best = min(best, dp[c - 1])
                if c + 1 < n:
                    best = min(best, dp[c + 1])
                ndp[c] = best + matrix[r][c]
            dp = ndp
        return min(dp)
```

## 8. 边界情况与易错点

1. **$n = 1$**：`dp = matrix[0]` 直接返回其唯一元素，不要写成「至少走两步」。
2. **越界位置填 0**：若把不存在的邻居当作 0，则在 $-100$ 的矩阵里会被误当成最小来源，答案偏小。
3. **原地覆盖 `dp`**：把 `ndp[c]` 写回 `dp[c]` 后，计算 `dp[c+1]` 时读到的就是新值，结果错乱。
4. **负权与剪枝**：用 DFS + 「当前和已超过已知最优」剪枝在负权下是**错的**（后续可能出现更负的值），必须用 DP。
5. **贪心取每行最小**：示例 1 中贪心会得到非法路径，务必用 DP 验证可达性。
6. **`min` 初值**：`best = dp[c]` 而非 `INT_MAX` 后直接比较，注意 `if` 分支里不能漏掉 `dp[c]` 本身。
7. **列下标偏移**：题目允许「左下、正下、右下」，即 $c-1, c, c+1$；不要写成 $c, c+1, c+2$。
