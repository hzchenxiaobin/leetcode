# LeetCode 漂亮数组 题解

## 1. 题目概述

- **标题 / 题号**：漂亮数组（#932，medium）
- **链接**：https://leetcode.cn/problems/beautiful-array/
- **来源**：LeetCode 第 108 场周赛 Q4
- **难度**：中等
- **标签**：数组、数学、分治

**题意**：长度为 $n$ 的数组若满足下面两条，则称为**漂亮数组**：

1. 它是 $[1, n]$ 的一个排列；
2. 对任意 $0 \le i < j < n$，都不存在 $i < k < j$ 使 $2 \cdot \text{nums}[k] = \text{nums}[i] + \text{nums}[j]$。

也就是：**任意两个元素的中点（等差中项）不能出现在它们中间的位置**。给定 $n$，返回任一漂亮数组。

**约束**：

- $1 \le n \le 1000$
- 题目保证对给定 $n$ 至少存在一个有效答案

> 💡 这是「构造题」而非「搜索题」：答案不唯一，关键是找到一个**可递归扩张**的构造方式。

## 2. 示例

**示例 1**

```text
输入：n = 4
输出：[2,1,4,3]
解释：一个合法构造。注意 k 只看「中间位置」，不是下标连续的三元组。
```

**示例 2**

```text
输入：n = 5
输出：[3,1,2,5,4]
解释：同样合法；其他漂亮排列也被接受。
```

**示例 3（补充）**

```text
输入：n = 1
输出：[1]
解释：没有三元组，自然合法。
```

## 3. 解题思路

### 3.1 暴力思路

$n \le 8$ 时可以回溯搜索：逐位放数，放完后检查是否出现「中间元素是两端点的等差中项」的三元组。但 $n = 1000$ 时搜索空间是 $n!$，完全不可行——而且这类构造题的回溯即使加剪枝也会在中途爆炸。

另一类错误方向是「随机洗牌 + 检查」：$n$ 较大时，随机排列几乎必然含有等差三元组，命中率趋近于 0。

### 3.2 核心观察：奇偶分治——把「中点」赶到另一边

![奇偶分治：为什么「奇数一半 + 偶数一半」一定合法](images/wc108_q4_parity_split_concept.svg)

命题的核心是**奇偶性**。假设我们构造的数组由两部分拼成：

- 左半部分全是**奇数**；
- 右半部分全是**偶数**。

考察任意三元组 $i < k < j$，看 $2\cdot \text{nums}[k] = \text{nums}[i] + \text{nums}[j]$ 是否可能成立：

- 左边 $2 \cdot \text{nums}[k]$ 永远是**偶数**；
- 若 $\text{nums}[i]$ 与 $\text{nums}[j]$ **一奇一偶**，右边是奇数，不可能等于偶数；
- 若三者**全奇**或**全偶**，等式两边奇偶性一致，需要进一步用子结构保证不成立。

而三者全奇或全偶时，这三个位置**全部落在同一半**（因为左半全奇、右半全偶）。于是只要「左半部分本身漂亮」「右半部分本身漂亮」，这两个子情形也自动成立。

**递归构造**：若 $A$ 是长度为 $m$ 的漂亮数组（取值 $[1,m]$），则

- $2A - 1 = (2a_1 - 1, \dots, 2a_m - 1)$ 是取值 $\{1, 3, \dots, 2m-1\}$ 的漂亮数组；
- $2A = (2a_1, \dots, 2a_m)$ 是取值 $\{2, 4, \dots, 2m\}$ 的漂亮数组。

因为「$x \mapsto 2x-1$」与「$x \mapsto 2x$」都是**仿射变换**，会把等差数列映射成等差数列（$2a_k = a_i + a_j \iff 2(2a_k-1) = (2a_i-1) + (2a_j-1)$），所以漂亮性被保持。

于是
$$B(n) = \bigl(2 \cdot B(\lceil n/2 \rceil) - 1\bigr) \ \Vert\ \bigl(2 \cdot B(\lfloor n/2 \rfloor)\bigr)$$
其中 $\Vert$ 表示拼接，$\lceil n/2 \rceil$ 个奇数恰好覆盖 $1, 3, \dots$ 中的前 $\lceil n/2 \rceil$ 个、$\lfloor n/2 \rfloor$ 个偶数覆盖前 $\lfloor n/2 \rfloor$ 个偶数，合起来正好是 $[1, n]$ 的一个排列。

> 💡 一句话总结：**奇数全放左边、偶数全放右边**，让「一奇一偶」的三元组直接失效，剩下的三元组都落在同一半、可以递归处理。

### 3.3 算法流程

![递归构建：n = 5](images/wc108_q4_recursion_tree.svg)

```text
B(n):
    if n == 1: return [1]
    odd  = B((n + 1) / 2)      # 上取整
    even = B(n / 2)            # 下取整
    ans = []
    for x in odd:  ans.push(2 * x - 1)    # 映射成奇数
    for x in even: ans.push(2 * x)        # 映射成偶数
    return ans
```

$n = 5$ 时：

- $B(3) = [1, 3, 2]$，映射成奇数得 $[1, 5, 3]$；
- $B(2) = [1, 2]$，映射成偶数得 $[2, 4]$；
- 拼接得 $[1, 5, 3, 2, 4]$。

### 3.4 示例演算

![结果校验：n = 4 与 n = 5](images/wc108_q4_walkthrough.svg)

$n = 4$：$B(2) = [1,2]$，奇数部分 $[1,3]$，偶数部分 $[2,4]$，拼接 $[1,3,2,4]$。
逐个检查「中间位置」：

- $k = 1$（值 3）：两端 $(1,2)$ 和为 3，$2 \times 3 = 6 \ne 3$ ✓；
- $k = 2$（值 2）：两端 $(1,4)$ 和为 5、$(3,4)$ 和为 7，都不等于 $2 \times 2 = 4$ ✓。

$n = 5$：$[1,5,3,2,4]$。$k = 1$（5）：$2\times5 = 10$，两端和为 $1+3 = 4$、$1+2=3$、$1+4=5$，均不等 ✓；其余 $k$ 同样通过。

题目接受任一合法答案，所以示例给出的 $[2,1,4,3]$ 与我们的 $[1,3,2,4]$ 都正确。

## 4. 算法细节

1. **上取整与下取整**：奇数个数是 $\lceil n/2 \rceil$、偶数个数是 $\lfloor n/2 \rfloor$。C++ 整数除法 `n/2` 天然下取整，`(n+1)/2` 即上取整。
2. **映射公式**：$x \mapsto 2x-1$ 把 $[1,m]$ 映成前 $m$ 个奇数；$x \mapsto 2x$ 把 $[1,m]$ 映成前 $m$ 个偶数。两者都不改「等差关系」。
3. **递归出口**：$n = 1$ 返回 $[1]$；注意 $n = 0$ 不会出现（$B(\lfloor n/2 \rfloor)$ 在 $n \ge 2$ 时 $\ge 1$）。
4. **数组大小**：递归深度 $O(\log n)$，元素总数恰为 $n$；`reserve(n)` 可减少扩容。
5. **返回的是排列**：奇数部分与偶数部分值域不重叠，且合起来覆盖 $[1,n]$，无需再去重。
6. **不要对结果排序**：排序会破坏构造出的顺序。

## 5. 正确性证明

先证一个引理，把「漂亮性」与整数集合的性质解耦。

**引理 1（仿射保持）**：设 $A = (a_1, \dots, a_m)$ 是漂亮数组。则

1. $A^{o} = (2a_1 - 1, \dots, 2a_m - 1)$ 是漂亮数组；
2. $A^{e} = (2a_1, \dots, 2a_m)$ 是漂亮数组。

**证明**：两者都是逐元素仿射变换 $x \mapsto 2x + b$（$b = -1$ 或 $0$），是单射，故元素互不相同，且满足「漂亮」只依赖下标之间的相对关系。对任意 $i < k < j$，
$$2 a_k = a_i + a_j \iff 2(2a_k + b) = (2a_i + b) + (2a_j + b)$$
（右边 $= 2a_i + 2a_j + 2b = 2(2a_k + b)$ 当且仅当 $2a_k = a_i + a_j$）。因此 $A$ 中不存在满足条件的三元组，当且仅当变换后也不存在。∎

**引理 2（拼接保持）**：设 $X$ 是全奇数的漂亮数组、$Y$ 是全偶数的漂亮数组，且 $X$ 的值两两不同、$Y$ 的值两两不同、$X$ 与 $Y$ 的值域不相交。则 $Z = X \Vert Y$（$X$ 在前、$Y$ 在后）是漂亮数组。

**证明**：设 $Z$ 的下标 $i < k < j$ 满足 $2 Z_k = Z_i + Z_j$。左边是偶数。

- 若 $Z_i$ 与 $Z_j$ 一奇一偶，右边是奇数，矛盾；
- 若 $Z_i, Z_j$ 同奇，则 $i, j$ 都在 $X$ 段（$Y$ 段全偶）。由 $i < k < j$，$k$ 也在 $X$ 段，于是三元组完全落在 $X$ 中，与 $X$ 漂亮矛盾；
- 若 $Z_i, Z_j$ 同偶，同理三元组完全落在 $Y$ 中，与 $Y$ 漂亮矛盾。

三种情形都矛盾，故不存在这样的三元组。∎

**引理 3（值域覆盖）**：对任意 $n \ge 1$，$B(n)$ 是 $[1,n]$ 的一个排列，且长度为 $n$。

**证明**：对 $n$ 归纳。$n = 1$ 时 $B(1) = [1]$，成立。设对 $< n$ 成立。$B(n)$ 由 $B(\lceil n/2\rceil)$ 映射成奇数、$B(\lfloor n/2\rfloor)$ 映射成偶数后拼接：

- 长度 $= \lceil n/2 \rceil + \lfloor n/2 \rfloor = n$；
- 由归纳假设，$B(\lceil n/2\rceil)$ 是 $[1, \lceil n/2\rceil]$ 的排列，映射 $2x-1$ 后得到 $\{1, 3, \dots, 2\lceil n/2\rceil - 1\}$，恰为 $[1,n]$ 中的全部奇数；
- 同理 $B(\lfloor n/2\rfloor)$ 经 $2x$ 映射得到 $[1,n]$ 中的全部偶数。

二者值域不相交、并集为 $[1,n]$ 且各元素出现一次，故 $B(n)$ 是排列。∎

**定理**：对任意 $n \ge 1$，$B(n)$ 是漂亮数组。

**证明**：对 $n$ 归纳。$n = 1$ 显然。设 $X = 2B(\lceil n/2\rceil) - 1$、$Y = 2B(\lfloor n/2\rfloor)$：

- 由归纳假设与引理 1，$X$、$Y$ 都是漂亮数组；
- 由引理 1 的构造，$X$ 全为奇数、$Y$ 全为偶数，值域由引理 3 知不相交，且各自内部元素互异；
- 由引理 2，$B(n) = X \Vert Y$ 是漂亮数组；
- 由引理 3，$B(n)$ 还是 $[1,n]$ 的排列。

两条定义都满足，故 $B(n)$ 是漂亮数组。∎

## 6. 复杂度分析

- **时间**：$O(n \log n)$。用主定理：$T(n) = T(\lceil n/2\rceil) + T(\lfloor n/2\rfloor) + O(n)$（映射与拼接），解得 $T(n) = O(n \log n)$。$n = 1000$ 时约 $10^4$ 次操作。
- **空间**：$O(n \log n)$（递归各层的数组总和）或 $O(n)$（若共享同一块输出缓冲区）；递归栈深度 $O(\log n)$。
- **注**：用「迭代按层构造」的写法可把额外空间降到 $O(n)$，时间不变。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> beautifulArray(int n) {
        if (n == 1) return {1};
        // 奇偶分治：左边放「1..(n+1)/2 的漂亮数组」映射成的奇数，右边放偶数
        vector<int> odd = beautifulArray((n + 1) / 2);
        vector<int> even = beautifulArray(n / 2);
        vector<int> ans;
        ans.reserve(n);
        for (int x : odd) ans.push_back(2 * x - 1);   // 奇数部分：1,3,5,...
        for (int x : even) ans.push_back(2 * x);      // 偶数部分：2,4,6,...
        return ans;
    }
};
```

### Python

```python
class Solution:
    def beautifulArray(self, n: int) -> list[int]:
        if n == 1:
            return [1]
        odd = self.beautifulArray((n + 1) // 2)
        even = self.beautifulArray(n // 2)
        return [2 * x - 1 for x in odd] + [2 * x for x in even]
```

## 8. 边界情况与易错点

1. **$n = 1$**：必须返回 $[1]$，递归出口漏写会导致无限递归（$(1+1)/2 = 1$）。
2. **奇偶个数写反**：奇数个数是 $\lceil n/2\rceil$，若写成 $\lfloor n/2\rfloor$ 会漏掉元素，返回长度不等于 $n$。
3. **映射公式写错**：$2x-1$ 与 $2x$ 是唯一正确的一对；写成 $2x+1$ 会得到 $\{3, 5, \dots\}$ 而缺 1。
4. **误以为要排序**：构造顺序本身就是答案，排序会破坏「中点不在中间」的性质。
5. **检查条件理解错**：题目只禁止「$k$ 位于 $i$ 与 $j$ 之间」的等差中项，不禁止数组中存在等差数列（如 $[1,3,2]$ 含 1 与 3 但中项 2 在 3 之后，合法）。
6. **返回类型**：`vector<int>` / `list`，判题器会检查是否为 $[1,n]$ 的排列，重复或越界都算错。
7. **$n = 1000$**：递归深度约 10 层，不会爆栈；输出长度必须恰为 1000。
