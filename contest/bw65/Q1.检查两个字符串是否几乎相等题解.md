# LeetCode 检查两个字符串是否几乎相等 题解

## 1. 题目概述

- **标题 / 题号**：检查两个字符串是否几乎相等（#2068，easy）
- **链接**：https://leetcode.cn/problems/check-whether-two-strings-are-almost-equivalent/
- **来源**：LeetCode 第 65 场双周赛 Q1
- **难度**：简单
- **标签**：哈希表、字符串、计数

**题意**：给定两个**等长**的小写字符串 word1 与 word2。若对 `'a'` 到 `'z'` 的每个字母，它在两个字符串中的**出现频率之差都不超过 3**，则称两串"几乎相等"。判断给定两串是否几乎相等，是则返回 `true`，否则 `false`。

**约束**：

- $n = word1.length = word2.length$，$1 \le n \le 100$
- 两串都只含小写英文字母

> 💡 频率之差是**绝对值**：$|cnt_1(c) - cnt_2(c)| \le 3$，单边差为 $-3$ 也合法。

## 2. 示例

**示例 1**

```text
输入：word1 = "aaaa", word2 = "bccb"
输出：false
解释：'a' 在 word1 出现 4 次、word2 出现 0 次，差为 4 > 3。
```

**示例 2**

```text
输入：word1 = "abcdeef", word2 = "abaaacc"
输出：true
解释：各字母频率差为 a:3, b:0, c:1, d:1, e:2, f:1，全部不超过 3。
```

**示例 3（压线边界）**

```text
输入：word1 = "cccddabba", word2 = "babababab"
输出：true
解释：'b' 差 3、'c' 差 3，恰好等于上限 3，"不超过"含等号，仍返回 true。
```

## 3. 解题思路

### 3.1 暴力思路

对每个字母 $c \in \{a, \dots, z\}$，分别线性扫描两个字符串数出 $cnt_1(c)$ 与 $cnt_2(c)$，比较 $|cnt_1(c) - cnt_2(c)| \le 3$。共扫 $26 \times 2$ 遍，时间 $O(52n)$，在 $n \le 100$ 下当然能过，但写法笨重；一次遍历同时计数更优雅。

### 3.2 核心观察：一个 26 桶计数数组足够

![核心观察：逐字母计数作差](images/bw65_q1_count_diff.svg)

两串**等长**这个条件其实无需使用：只需一个长度 26 的数组 `cnt`，扫 word1 时对应位置 `+1`，扫 word2 时对应位置 `-1`。扫完后 `cnt[c]` 就是字母 $c$ 的频率差 $cnt_1(c) - cnt_2(c)$。最后检查**是否存在** $|cnt[c]| > 3$——存在即返回 `false`，否则 `true`。

两个方向合并进同一个数组，天然得到带符号的差值，无需开两张表再相减。

### 3.3 算法流程

```text
1. cnt[26] 全 0
2. for c in word1: cnt[c-'a'] += 1
3. for c in word2: cnt[c-'a'] -= 1
4. for d in cnt:
       若 |d| > 3 → 返回 false
5. 返回 true
```

### 3.4 示例演算

![示例演算：逐字母查表](images/bw65_q1_walkthrough.svg)

以示例 2（`abcdeef` vs `abaaacc`）为例：word1 计数为 $a{:}1, b{:}1, c{:}1, d{:}1, e{:}2, f{:}1$；word2 计数为 $a{:}4, b{:}1, c{:}2$。逐字母作差得 $a{:}3, b{:}0, c{:}1, d{:}1, e{:}2, f{:}1$（其余字母差为 0），全部 $|\cdot| \le 3$，返回 `true`。其中 $a$ 的差恰好为 3，验证了"不超过"含等号。

## 4. 算法细节

1. **计数下标**：`c - 'a'` 归一到 $[0, 26)$；本题保证只含小写字母，无需防御其他字符。
2. **带符号差**：一次 `+1`/`-1` 合并计数，比开两个数组再逐位相减少一次循环且少一半空间。
3. **判定条件**：是 $|d| \le 3$ 而非 $d \le 3$——word2 中多出的字母同样可能超限（如示例 1 的反面：word1 无某字母而 word2 出现 4 次）。
4. **两串等长不必利用**：算法与长度是否相等无关，题面的等长只是设定。

## 5. 正确性证明

**引理 1**：设 $cnt_1(c)$、$cnt_2(c)$ 为字母 $c$ 在两串中的出现次数，则两遍扫描后数组满足 $cnt[c] = cnt_1(c) - cnt_2(c)$。

**证明**：初始 $cnt[c] = 0$。word1 中每个 $c$ 使 $cnt[c]$ 自增 1，共自增 $cnt_1(c)$ 次；word2 中每个 $c$ 使其自减 1，共自减 $cnt_2(c)$ 次。故终值 $cnt[c] = cnt_1(c) - cnt_2(c)$。∎

**定理**：算法返回 `true` 当且仅当对所有字母 $c$ 有 $|cnt_1(c) - cnt_2(c)| \le 3$，即两串几乎相等。

**证明**：由引理 1，第 4 步检查的恰是 $|cnt_1(c) - cnt_2(c)| > 3$ 是否对某个 $c$ 成立。若有字母超限，循环必在检查到该字母时返回 `false`；若全部不超限，循环走完返回 `true`。二者与"几乎相等"的定义逐字对应。∎

## 6. 复杂度分析

- **时间**：$O(n + 26)$。两遍线性扫描加一次常数长度的数组检查，即 $O(n)$。
- **空间**：$O(26)$，即 $O(1)$ 额外空间（计数数组大小与 $n$ 无关）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool checkAlmostEquivalent(string word1, string word2) {
        int cnt[26] = {0};
        for (char c : word1) ++cnt[c - 'a'];
        for (char c : word2) --cnt[c - 'a'];
        for (int d : cnt)
            if (d > 3 || d < -3) return false;
        return true;
    }
};
```

### Python

```python
class Solution:
    def checkAlmostEquivalent(self, word1: str, word2: str) -> bool:
        cnt = [0] * 26
        for c in word1:
            cnt[ord(c) - 97] += 1
        for c in word2:
            cnt[ord(c) - 97] -= 1
        return all(abs(d) <= 3 for d in cnt)
```

> 💡 两份代码均通过官方 3 组示例（`false` / `true` / `true`）、压线用例（差恰为 3 / 4）以及 C++ 20000 组、Python 3000 组随机串与独立暴力（`map` 逐字母计数）的对拍，`mismatch = 0`。

## 8. 边界情况与易错点

1. **"不超过 3"含等号**：$|差| = 3$ 合法、$= 4$ 才非法，条件写成 `> 3` 而非 `>= 3`。
2. **差是双向的**：必须比较绝对值；只查 `d > 3` 会漏掉 word2 多出的字母（如 word1=`"bccb"`、word2=`"aaaa"`）。
3. **单字母串**：$n = 1$ 时任意两串都几乎相等（差至多 1）。
4. **只出现在一串的字母**：另一边计 0，差即出现次数，超过 3 直接判负（示例 1 的 'a'）。
5. **Python 的 `all(...)` 短路**：写生成器表达式而非列表推导，可在首个超限字母处提前返回。
