# LeetCode 每一个查询的最大美丽值 题解

## 1. 题目概述

- **标题 / 题号**：每一个查询的最大美丽值（#2070，medium）
- **链接**：https://leetcode.cn/problems/most-beautiful-item-for-each-query/
- **来源**：LeetCode 第 65 场双周赛 Q3
- **难度**：中等
- **标签**：数组、排序、二分查找

**题意**：给定物品数组 `items`，`items[i] = [price_i, beauty_i]`。再给查询数组 `queries`。对每个查询 $q$，求**价格 $\le q$ 的物品中的最大美丽值**；若不存在这样的物品，答案为 0。返回与 `queries` 等长的答案数组。

**约束**：

- $1 \le items.length, queries.length \le 10^5$
- $1 \le price_i, beauty_i, queries[j] \le 10^9$

## 2. 示例

**示例 1**

```text
输入：items = [[1,2],[3,2],[2,4],[5,6],[3,5]], queries = [1,2,3,4,5,6]
输出：[2,4,5,5,6,6]
解释：q=1 只能买 [1,2]；q=2 可买 [1,2],[2,4] → 4；q=3、q=4 可买前四个 → 5；q=5、q=6 全部可买 → 6。
```

**示例 2（同价物品）**

```text
输入：items = [[1,2],[1,2],[1,3],[1,4]], queries = [1]
输出：[4]
解释：同价格的多个物品都可选，取美丽值最大的 4。
```

**示例 3（无可买物品）**

```text
输入：items = [[10,1000]], queries = [5]
输出：[0]
解释：没有任何物品价格 ≤ 5，答案为 0。
```

## 3. 解题思路

### 3.1 暴力思路

对每个查询线性扫全部物品，取价格满足条件的最大美丽值：$O(nq)$，最坏 $10^5 \times 10^5 = 10^{10}$，必然超时。需要预处理 + 快速查询。

### 3.2 核心观察：按价格排序后"可选集合"随 $q$ 单调扩张，前缀最大值 + 二分

![核心观察：排序 + 前缀最大 + 二分](images/bw65_q3_sort_prefix_model.svg)

把物品按价格升序排序后，"价格 $\le q$ 的物品集合"恰好是数组的一个**前缀**，且这个前缀长度随 $q$ 增大而单调不减。预先做**前缀最大美丽值** `best[i] = max(best[i-1], beauty[i])`，则查询化为：

1. 二分找最大的下标 $pos$ 使 $price[pos] \le q$（不存在则 $pos = -1$）；
2. 答案即 $pos = -1 ? 0 : best[pos]$。

两个关键点：**同价物品被前缀最大自动合并**（排序后相邻，max 抹平差异）；**答案随 $q$ 单调不减**（前缀只会变长，最大值不降）。

### 3.3 算法流程

```text
1. items 按 price 升序排序（同价任意序）
2. best[0] = beauty[0]；best[i] = max(best[i-1], beauty[i])
3. 对每个 q：
       pos = 最大的 i 使 price[i] <= q（二分；无则 -1）
       ans = pos == -1 ? 0 : best[pos]
```

### 3.4 示例演算

![示例演算：六个查询全流程](images/bw65_q3_query_walkthrough.svg)

示例 1 排序后 items 为 $[(1,2), (2,4), (3,2), (3,5), (5,6)]$，best 前缀为 $[2, 4, 4, 5, 6]$（两个价格 3 的物品合并后最大美丽值 5）。逐查询二分：

| q | 最后一个 price ≤ q 的下标 | 答案 |
|---|---|---|
| 1 | 0 | 2 |
| 2 | 1 | 4 |
| 3 | 3 | 5 |
| 4 | 3 | 5 |
| 5 | 4 | 6 |
| 6 | 4 | 6 |

得 `[2,4,5,5,6,6]`，与官方一致。

## 4. 算法细节

1. **排序键**：只按 `price` 升序即可；同价物品的相对顺序不影响前缀最大值。
2. **二分写法**：手写"最后一个 ≤ q"的二分（`lo <= hi` 收缩 `pos`），或 Python 直接 `bisect_right(prices, q) - 1`；下标 $-1$ 表示无可买物品，答案 0。
3. **前缀最大而非排序美丽值**：不能只对价格排序后在查询时扫前缀求 max（那是 $O(n)$ 每查询）；前缀数组把区间 max 预处理成 $O(1)$ 查询。
4. **值域**：价格与美丽值达 $10^9$，排序 + 下标二分天然避开值域离散化；`int` 足够（$10^9 < 2^{31}-1$）。
5. **离线替代**：把 queries 连同下标排序后双指针扫 items，同样 $O((n+q)\log(n+q))$，不需要保留在线性；本题查询互不依赖，两种写法均可。

## 5. 正确性证明

**引理 1（前缀性）**：items 按 price 升序排列后，集合 $S(q) = \{i : price_i \le q\}$ 是数组的一个前缀 $[0, pos(q)]$，且 $pos(\cdot)$ 单调不减。

**证明**：升序数组中若 $price_{pos} \le q$，则一切 $i \le pos$ 有 $price_i \le price_{pos} \le q$；若 $price_{pos+1} > q$，则一切 $i > pos$ 有 $price_i \ge price_{pos+1} > q$。故 $S(q)$ 恰为前缀。$q_1 \le q_2 \Rightarrow S(q_1) \subseteq S(q_2)$，故 $pos$ 单调不减。∎

**引理 2（前缀最大正确性）**：$best[i] = \max_{0 \le k \le i} beauty_k$，从而 $\max_{i \in S(q)} beauty_i = best[pos(q)]$。

**证明**：对 $i$ 归纳，$best[i]$ 的递推式 $max(best[i-1], beauty[i])$ 恰是前缀 max 的定义。当 $S(q)$ 非空时其元素恰为 $\{0, \dots, pos(q)\}$，最大值即 $best[pos(q)]$。∎

**定理**：算法对每个查询 $q$ 返回 $\max\{beauty_i : price_i \le q\}$（空集时 0）。

**证明**：由引理 1，二分找到的 $pos$ 是 $S(q)$ 的右端点；由引理 2，返回值即该集合的最大美丽值。$S(q) = \varnothing$ 时二分得 $pos = -1$，返回约定值 0。∎

## 6. 复杂度分析

- **时间**：排序 $O(n \log n)$ + 前缀 $O(n)$ + 每查询二分 $O(\log n)$，共 $O((n + q) \log n)$；$n, q \le 10^5$ 时约 $3.5 \times 10^6$ 次比较。
- **空间**：$O(n)$（排序副本与 best 数组；Python 还需 $O(q)$ 答案数组）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> maximumBeauty(vector<vector<int>>& items, vector<int>& queries) {
        sort(items.begin(), items.end());            // 按 price 升序
        int n = items.size();
        vector<int> best(n);                          // 前缀最大美丽值
        best[0] = items[0][1];
        for (int i = 1; i < n; ++i)
            best[i] = max(best[i - 1], items[i][1]);
        vector<int> ans;
        ans.reserve(queries.size());
        for (int q : queries) {
            int lo = 0, hi = n - 1, pos = -1;         // 最大的 i 使 price[i] <= q
            while (lo <= hi) {
                int mid = lo + (hi - lo) / 2;
                if (items[mid][0] <= q) { pos = mid; lo = mid + 1; }
                else hi = mid - 1;
            }
            ans.push_back(pos == -1 ? 0 : best[pos]);
        }
        return ans;
    }
};
```

### Python

```python
from bisect import bisect_right

class Solution:
    def maximumBeauty(self, items: list[list[int]], queries: list[int]) -> list[int]:
        items.sort()                              # 按 price 升序（同价任意序）
        prices = [it[0] for it in items]
        best = [0] * len(items)                   # 前缀最大美丽值
        cur = 0
        for i, (_, b) in enumerate(items):
            cur = max(cur, b)
            best[i] = cur
        return [best[bisect_right(prices, q) - 1]
                if bisect_right(prices, q) > 0 else 0
                for q in queries]
```

> 💡 两份代码均通过官方 3 组示例（`[2,4,5,5,6,6]` / `[4]` / `[0]`）、$10^9$ 极值用例，以及 C++ 4000 组、Python 2000 组随机数据与"逐查询全扫描"暴力的对拍，`mismatch = 0`。

## 8. 边界情况与易错点

1. **全部物品价格 > q**：二分得 $pos = -1$，必须返回 0，别让 `best[-1]` 越界访问（Python 的 `bisect_right(...) - 1` 为 $-1$ 时要显式判空）。
2. **同价物品**：多个物品价格相同，排序后相邻，前缀最大自然取到其中最大美丽值；不要试图按 `(price, beauty)` 双键排序后只查最后一个——前缀 max 已经覆盖。
3. **二分方向**：要找"最后一个 ≤ q"（右端），用 `bisect_right` 风格；`bisect_left` 会漏掉同价物品。
4. **答案非严格单调**：q 增大答案不减，但不相等也正常，别拿相邻查询的答案去剪枝。
5. **不要修改 queries 顺序**：答案必须按原下标返回；离线双指针写法要记录原下标。
6. **int 范围**：$10^9$ 价格在 `int` 内，但 C++ 累加 `long long` 判空逻辑前先确认 `pos` 的初值。

**延伸思考**：本题是"前缀最大 + 二分"的经典组合，等价于对**单调不减函数** $g(q) = best[pos(q)]$ 的求值。若强制在线（查询逐个到来且不可预知），此法天然支持；若带修改（物品增删），可升级为树状数组上"前缀最大"单点更新，或直接用值域线段树。另一个方向是把 $q$ 离散化后建**稀疏表**回答任意区间最值——但本题只需前缀，前缀 max 更简单。
