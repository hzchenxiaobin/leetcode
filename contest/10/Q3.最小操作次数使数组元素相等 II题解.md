# LeetCode 最小操作次数使数组元素相等 II 题解

## 1. 题目概述

- **标题 / 题号**：最小操作次数使数组元素相等 II（#462，medium）
- **链接**：https://leetcode.cn/problems/minimum-moves-to-equal-array-elements-ii/
- **来源**：LeetCode 第 10 场周赛 Q3
- **难度**：中等
- **标签**：数组、数学、排序

**题意**：给定长度为 $n$ 的整数数组 `nums`，每次操作可以把**任意一个**元素加 $1$ 或减 $1$。求让所有元素相等所需的**最少操作次数**。

把最终公共值记作 $t$，第 $i$ 个元素需要的操作数就是 $|nums[i] - t|$，各元素的操作互不影响，因此总代价为

$$f(t) = \sum_{i=0}^{n-1} |nums[i] - t|$$

问题转化为：**选一个目标值 $t$，使 $f(t)$ 最小**。

**约束**：

- $1 \le n \le 10^5$
- $-10^9 \le nums[i] \le 10^9$
- 答案保证在 32 位整数范围内

## 2. 示例

**示例 1**

```text
输入：nums = [1,2,3]
输出：2
解释：
[1,2,3] => [2,2,3] => [2,2,2]
两次操作（1 加 1、3 减 1），全部变成 2。
```

**示例 2**

```text
输入：nums = [1,10,2,9]
输出：16
解释：全部变成 2（或全部变成 9）都需要 16 次：
      |1−2| + |10−2| + |2−2| + |9−2| = 1 + 8 + 0 + 7 = 16。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的做法是枚举目标值 $t$，对每个 $t$ 花 $O(n)$ 求 $f(t)$。但值域是 $[-10^9, 10^9]$，约 $2\times10^9$ 个候选，每个再乘 $10^5$，总量 $2\times10^{14}$，完全不可行。

退一步：最优 $t$ 一定可以取数组中的某个元素（否则把 $t$ 朝最近的元素方向微调，$f(t)$ 不会变大）。于是枚举 $n$ 个候选、每个 $O(n)$ 计算，复杂度 $O(n^2) = 10^{10}$，仍然超时。

从 $O(n^2)$ 到 $O(n\log n)$ 的差距，来自一个能**一次性定位最优 $t$** 的结构性结论。

### 3.2 核心观察：最优目标是中位数

![排序后两头配对，L1 代价只由两端差值决定](images/wc10_q3_median_pairing.svg)

把数组升序排序，记为 $a_0 \le a_1 \le \cdots \le a_{n-1}$，目标值为 $t$。

**配对相消**：把最小与最大配成一对，它们的贡献满足

$$|a_0 - t| + |a_{n-1} - t| \ge a_{n-1} - a_0$$

等号成立当且仅当 $t \in [a_0, a_{n-1}]$。也就是说，**只要 $t$ 落在这对元素的区间内，这一对的距离之和就是常数**，与 $t$ 的具体取值无关。

把 $a_i$ 与 $a_{n-1-i}$ 全部配对，得到 $f(t)$ 的下界

$$f(t) \ge \sum_{i=0}^{\lfloor n/2 \rfloor - 1} \left(a_{n-1-i} - a_i\right)$$

这个下界能不能取到？取中位数 $m = a_{\lfloor n/2 \rfloor}$。对任意 $i < n/2$ 都有 $a_i \le m \le a_{n-1-i}$，所以**每一对**的等号条件同时成立：

$$f(m) = \sum_{i=0}^{\lfloor n/2 \rfloor - 1} \left(a_{n-1-i} - a_i\right)$$

下界被恰好取到，$m$ 就是最优目标值。

> 💡 **为什么不是平均值？** 平均值最小化的是平方损失 $\sum (a_i - t)^2$；本题是绝对值损失（$L_1$），最优点在中位数。反例 `nums = [1,2,3,100]`：取中位数 $3$ 代价 $2+1+0+97=100$，取均值 $26.5$ 代价约 $147$，均值明显更差。

> 💡 **偶数长度**：中位数是一个**区间** $[a_{n/2-1}, a_{n/2}]$，取区间内任意值（含两个端点）答案相同，工程上统一取 $a_{n/2}$ 即可，不必分类讨论。

### 3.3 算法流程

![算法流程：排序 → 取中位数 → 累加绝对差](images/wc10_q3_algorithm_flow.svg)

1. **排序**：`sort(nums)` 升序，$O(n\log n)$。
2. **取中位数**：`m = nums[n // 2]`。奇数长度是唯一中位数，偶数长度是右中位数，两者都最优。
3. **累加**：`ans = Σ |nums[i] - m|`，$O(n)$。
4. **返回** `ans`。

**等价写法（两头配对）**：排序后用双指针从两端向中间收拢，每次累加 `nums[r] - nums[l]`：

$$ans = \sum_{i=0}^{\lfloor n/2 \rfloor - 1} \left(a_{n-1-i} - a_i\right)$$

它不需要显式取中位数，也天然不会出现负数差值；由 3.2 的等式，结果与「到中位数的距离和」完全一致。

### 3.4 示例演算

![示例走查：排序后逐项累加 |nums[i] − m|](images/wc10_q3_walkthrough.svg)

以 `nums = [1,10,2,9]` 为例，排序得 $[1,2,9,10]$，$m = nums[2] = 9$：

| $i$ | $nums[i]$ | $\lvert nums[i] - 9 \rvert$ |
|-----|-----------|-----------------------------|
| 0 | 1 | 8 |
| 1 | 2 | 7 |
| 2 | 9 | 0 |
| 3 | 10 | 1 |
| 合计 | | **16** |

再看 `nums = [1,2,3]`：排序后 $m = 2$，$|1-2| + |2-2| + |3-2| = 1 + 0 + 1 = 2$。

若用配对写法：$(10-1) + (9-2) = 9 + 7 = 16$，与上表逐项结果一致。

## 4. 算法细节

1. **右中位数统一奇偶**：统一取 `nums[n / 2]`（下标向下取整）。$n$ 为奇数时它是唯一中位数；$n$ 为偶数时它是中位数区间的右端点，同样最优，不需要分类讨论。
2. **排序即可，无需去重或计数**：重复元素不影响结论，配对区间退化为一点时等号条件依然成立。
3. **中间量必须用 64 位**：单个差值最大 $2\times10^9$，累加最多约 $10^5 \times 2\times10^9 = 2\times10^{14}$，`int` 会溢出。C++ 用 `long long` 累加后再转回 `int`（题面保证最终答案在 32 位内），`abs` 的参数也要先转 `long long`。
4. **避免负数取绝对值的坑**：C++ 中 `abs(a - b)` 若 $a-b$ 超出 `int` 会溢出甚至 UB，应先 `(long long)a - b` 再 `llabs`；Python 整数无溢出问题。
5. **不要真的模拟操作**：逐次加减模拟需要 $O(\text{答案})$ 次操作，答案可达 $10^{14}$，必然超时；本题只需求总距离。
6. **双指针写法可以省掉中位数**：`for (int l = 0, r = n - 1; l < r; ++l, --r) ans += nums[r] - nums[l];`，与中位数写法等价，且每项非负。
7. **想要更快**：C++ 用 `nth_element(nums.begin(), nums.begin() + n / 2, nums.end())`（期望 $O(n)$）或手写 quickselect 找中位数；$n = 10^5$ 时排序已绰绰有余，但这是从 $O(n\log n)$ 降到 $O(n)$ 的通用套路。

## 5. 正确性证明

**引理 1（配对下界）**：设 $a_i \le a_j$。对任意实数 $t$，

$$|a_i - t| + |a_j - t| \ge a_j - a_i$$

且等号成立当且仅当 $t \in [a_i, a_j]$。

**证明**：由三角不等式 $|a_i - t| + |t - a_j| \ge |a_i - a_j| = a_j - a_i$。当 $t \in [a_i, a_j]$ 时，$|a_i - t| + |t - a_j| = (t - a_i) + (a_j - t) = a_j - a_i$，等号成立；当 $t$ 在区间外时两项同号叠加，严格大于。∎

**引理 2（中位数落在所有配对区间内）**：数组升序，$m = a_{\lfloor n/2 \rfloor}$。对任意整数 $0 \le i < n/2$，有

$$a_i \le m \le a_{n-1-i}$$

**证明**：由 $i < n/2$ 且 $i$ 为整数，得 $i \le \lfloor n/2 \rfloor = m$；又 $n-1-i \ge n-1-\left(\lceil n/2 \rceil - 1\right) = \lfloor n/2 \rfloor = m$。于是由排序的单调性 $a_i \le a_m = m \le a_{n-1-i}$。∎

**定理**：设 $m = a_{\lfloor n/2 \rfloor}$，则 $f(m) = \min_{t} f(t)$，且最小值为 $\sum_{i=0}^{\lfloor n/2 \rfloor - 1}\left(a_{n-1-i} - a_i\right)$。

**证明**：任取 $t$，把 $f(t)$ 按 $(a_i, a_{n-1-i})$ 配对，每对套用引理 1，得

$$f(t) \ge \sum_{i=0}^{\lfloor n/2 \rfloor - 1} \left(a_{n-1-i} - a_i\right)$$

由引理 2，$t = m$ 时每一对的等号条件都成立，于是

$$f(m) = \sum_{i=0}^{\lfloor n/2 \rfloor - 1} \left(a_{n-1-i} - a_i\right) \le f(t)$$

对任意 $t$ 成立，故 $m$ 是最优目标值。算法排序后逐个累加 $|a_i - m|$，算出的正是 $f(m)$，即最少操作次数。又因为 $m$ 本身是数组元素（整数），而操作只能 $\pm 1$ 也只在整数间移动，所以最优目标可以取到整数，不损失最优性。∎

## 6. 复杂度分析

- **时间**：$O(n\log n)$。排序是瓶颈 $O(n\log n)$；取中位数 $O(1)$；累加 $O(n)$。若用 `nth_element` / quickselect 找中位数，期望时间可降到 $O(n)$。
- **空间**：$O(\log n)$ 为排序递归栈（C++ 内省排序）；Python 的 Timsort 最坏需要 $O(n)$ 辅助空间。除输入与排序开销外，算法只使用常数个变量。

## 7. 参考代码

### C++

```cpp
#include <algorithm>
#include <cstdlib>
#include <vector>
using namespace std;

class Solution {
public:
    int minMoves2(vector<int>& nums) {
        sort(nums.begin(), nums.end());
        int n = (int)nums.size();
        int median = nums[n / 2];          // 右中位数，奇偶通用
        long long ans = 0;                 // 累加最大约 2e14，必须 64 位
        for (int x : nums) {
            ans += llabs((long long)x - median);
        }
        return (int)ans;                   // 题面保证答案在 32 位内
    }
};
```

### Python

```python
from typing import List


class Solution:
    def minMoves2(self, nums: List[int]) -> int:
        nums = sorted(nums)
        median = nums[len(nums) // 2]
        return sum(abs(x - median) for x in nums)
```

## 8. 边界情况与易错点

1. **$n = 1$**：唯一的元素已经满足「全部相等」，返回 $0$；代码无需特判，`nums[0]` 作中位数时差值自然为 $0$。
2. **全部元素相等**：如 `[5,5,5]`，$m = 5$，答案为 $0$。
3. **溢出**：`[-10^9, 10^9]` 的差值是 $2\times10^9$，已接近 `INT_MAX`；元素一多累加必然溢出。`ans` 与 `abs` 的参数都要用 64 位。
4. **偶数长度不要取平均**：`[1,2,3,100]` 取均值 $26.5$ 代价约 $147$，取中位数 $3$ 代价 $100$；均值既可能不是整数，也不是最优。
5. **原地排序的副作用**：`nums.sort()` / `sort(nums.begin(), nums.end())` 会修改入参；若调用方依赖原顺序，应先拷贝一份。
6. **不要按答案次数模拟**：答案可达 $10^{14}$ 量级，逐次加减模拟必然超时，必须直接用「距离和」公式。
