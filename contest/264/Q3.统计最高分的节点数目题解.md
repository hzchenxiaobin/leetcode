# LeetCode 统计最高分的节点数目 题解

## 1. 题目概述

- **标题 / 题号**：统计最高分的节点数目（#2049，medium）
- **链接**：https://leetcode.cn/problems/count-nodes-with-the-highest-score/
- **来源**：LeetCode 第 264 场周赛 Q3
- **难度**：中等
- **标签**：树、深度优先搜索、树形 DP、迭代遍历

**题意**：

给一棵以节点 $0$ 为根的**二叉树**，共 $n$ 个节点，用父指针数组 `parents` 表示（`parents[0] == -1`）。把节点 $v$ 及其所有连边**删除**后，剩余部分是若干个**非空**子树，$v$ 的**分数** = 这些子树大小的**乘积**。返回取得**最高分**的节点**数目**。

> 💡 换句话说：删掉 $v$ 把树劈成几块，每块节点数相乘就是 $v$ 的分数。分数只取决于「块的大小」，不取决于块的形状。

**约束**：

- $2 \leq n \leq 10^5$
- `parents[0] == -1`；对 $i \neq 0$ 有 $0 \leq$ `parents[i]` $\leq n-1$
- `parents` 表示一棵**二叉树**（每个节点至多 2 个孩子）

## 2. 示例

**示例 1**

```text
输入：parents = [-1,2,0,2,0]
输出：3
解释：树形为  0 ← 根，0 的孩子 2、4，2 的孩子 1、3
- 节点 0：剩子树{2,1,3}(3) 与 {4}(1)          → 3 × 1 = 3
- 节点 1：剩上方 {0,2,3,4}(4)                 → 4
- 节点 2：剩 {1}(1)、{3}(1)、上方 {0,4}(2)    → 1 × 1 × 2 = 2
- 节点 3：剩上方 (4)                          → 4
- 节点 4：剩上方 (4)                          → 4
最高分 4，节点 1、3、4 共 3 个达到。
```

**示例 2（链）**

```text
输入：parents = [-1,2,0]
输出：2
解释：链 0 → 2 → 1
- 节点 0：剩子树{2,1}(2)        → 2
- 节点 1：剩上方 {0,2}(2)       → 2
- 节点 2：剩 {1}(1) × 上方 {0}(1) → 1
最高分 2，节点 0、1 共 2 个达到。
```

**示例 3（最小规模边界）**

```text
输入：parents = [-1,0]
输出：2
解释：根 0 带一个孩子 1。
- 节点 0：删后剩子树 {1}(1) → score = 1
- 节点 1：删后剩上方 {0}(1) → score = 1
两节点并列最高分 1，答案 2 —— 分数的最小值就是 1。
```

## 3. 解题思路

### 3.1 暴力思路：逐节点模拟删除数连通块

对每个节点 $v$，真的把它从图里抠掉：从其余每个未访问节点出发 BFS/DFS，统计各连通块大小并相乘。单个节点 $O(n)$，全体 $O(n^2)$；$n = 10^5$ 时约 $10^{10}$ 次基本操作，必然超时。更本质的浪费在于：每个节点的答案都从零开始重新数一遍**大小完全相同的子树**——子树大小本可以算一次、全体复用。

### 3.2 核心观察：删点分裂 = 孩子子树 ∪ 上方剩余

![核心观察：删除节点后树裂成孩子子树与上方剩余，分数=各块大小乘积](images/highest_score_split_parts.svg)

删掉 $v$ 之后剩下的连通块，来源是**固定的**：

1. **$v$ 的每个孩子 $c$ 的子树**：删边后就地独立成块，大小恰为 `size[c]`；
2. **上方剩余**（仅当 $v$ 非根）：整棵树去掉 $v$ 的子树后的部分，大小为 $n - \text{size}[v]$，因含根而非空。

> 💡 上方剩余为什么是一整块？树上任意两点间路径唯一：$v$ 是「$v$ 的子树内」与「子树外」的唯一通道，删掉 $v$ 只切断这条通道；子树外的节点之间仍经由根方向互达，仍是单个连通块。

于是分数有了闭式（二叉树至多 2 个孩子，因子至多 3 个）：

$$\text{score}(v) \;=\; \Big(\prod_{c \,\in\, \text{children}(v)} \text{size}[c]\Big) \times \big(n - \text{size}[v]\big), \qquad v \neq \text{根}$$

根节点没有上方因子（$n - \text{size}[0] = 0$ 须跳过，不能乘进去）；叶子没有孩子因子，分数恒为 $n-1$。

> ⚠️ **溢出陷阱**：$n = 10^5$ 时三块各约 $n/3$，由 AM–GM，乘积上界 $\big(\frac{n-1}{3}\big)^3 \approx 3.7 \times 10^{13}$；连根节点的两因子乘积也有 $\big(\frac{n-1}{2}\big)^2 \approx 2.5 \times 10^9$，**双双超过 32 位 `int`**（$\approx 2.1 \times 10^9$）。`score` 必须用 `long long`（Python 大整数天然安全）；好在 $3.7 \times 10^{13}$ 远小于 $2^{63}-1$，64 位足够。

到此问题只剩一件事：**把所有 `size[v]` 求出来**。

### 3.3 算法流程：先序入表 + 逆序累加，全程无递归

![算法流程：栈式先序得到顺序，逆序执行 size 上传，两遍扫描完成](images/highest_score_reverse_accumulation.svg)

1. **建邻接表**：扫描 `parents`，得到 `children` 列表，$O(n)$。
2. **栈式先序**：从根 $0$ 出发，弹出一个节点就压入它的全部孩子，得到先序序列 `order`——**祖先必排在子孙前面**。
3. **逆序累加**：`size` 初值全 1，按 `order` 的**倒序**执行 `size[parents[v]] += size[v]`（$v = 0$ 跳过）。倒序保证**孩子先于父亲**被处理，每个节点把自己的子树总大小沿父边送上去。
4. **组装分数**：再扫一遍全体节点，按 §3.2 公式 $O(\text{度数})$ 直接算 `score`。
5. **在线维护** `best` 与 `cnt`：`score > best` 则重置计数，相等则加一。

> ⚠️ **为什么必须先跑一遍先序？** `parents[i]` 与 $i$ **没有大小关系**——示例 1 中 `parents[1] = 2 > 1`。不能按下标从 $n-1$ 递减直接累加，必须显式求出「孩子先于父亲」的合法顺序。（逆先序只是最方便的一种，逆 BFS 序同样可行。）

### 3.4 示例演算

![示例1演算：逐节点组装分数表，最高分4共3个](images/highest_score_scores_table.svg)

以示例 1 `parents = [-1,2,0,2,0]` 为例：先序 `order = [0,4,2,3,1]`，逆序累加后 `size = [5,1,3,1,1]`。逐节点组装：

| 节点 $v$ | $\text{size}[v]$ | 删除后的各部分 | score |
|---|---|---|---|
| 0（根） | 5 | 子树{2,1,3}(3)、子树{4}(1) | $3 \times 1 = 3$ |
| 1 | 1 | 上方剩余(4) | $4$ ★ |
| 2 | 3 | {1}(1)、{3}(1)、上方{0,4}(2) | $1 \times 1 \times 2 = 2$ |
| 3 | 1 | 上方剩余(4) | $4$ ★ |
| 4 | 1 | 上方剩余(4) | $4$ ★ |

`best = 4`，`cnt = 3`，返回 **3** ✓。

> 💡 三个叶子 1、3、4 的分数全是 $n - 1 = 4$——叶子分数恒为 $n-1$，这是写完代码后最快的自检锚点：树里叶子多时最高分常常就是 $n-1$。

## 4. 算法细节

1. **邻接表方向**：只存 `children`（父 → 孩子），不必存双向边；父指针本身已经在 `parents` 里，累加时直接 `size[parents[v]]` 即可。
2. **先序的实现**：显式栈 `stk`，弹出 $v$ 后**逆序无所谓**地把孩子全部压栈。每个节点恰进出栈一次，$O(n)$；得到的 `order` 只需满足「祖先在前」，孩子压栈顺序不影响正确性。
3. **逆序累加的等价说法**：它就是一次**自底向上**的树形 DP——`size[v] = 1 + Σ size[c]`，只是把「后序 DFS 回溯时合并」改写成「倒着走先序、沿父边送值」，省掉了递归。
4. **根的两处守卫**：
   - 累加处 `if (v != 0)`：`parents[0] == -1`，不守卫就是下标 $-1$ 的越界访问（C++ 未定义行为）；
   - 组装处用 `rest = n - size[v]; if (rest > 0)` 判断是否乘上方因子：$v$ 为根时 $\text{size}[v] = n$，`rest = 0` 自动跳过，比写 `if (v != 0)` 更不容易漏。
5. **空积初值**：`score` 从 $1$ 起乘。根的孩子乘积若只有一项就是一项；叶子的孩子乘积是空积 $1$，再乘上方 $n-1$。
6. **溢出控制**：`size` 用 `int` 就够（$\leq 10^5$），`score`、`best` 必须 `long long`；两处因子上界见 §3.2。
7. **不必收集全体分数**：`best/cnt` 在线维护即可，省一个 $O(n)$ 数组（虽然存下也无妨）。

## 5. 正确性证明

**引理 1（分裂引理）**：从树 $T$ 中删除节点 $v$ 及其所有连边后，剩余图的连通块恰为：$v$ 的每个孩子 $c$ 的子树 $\text{subtree}(c)$，以及（当 $v$ 非根时）集合 $T \setminus \text{subtree}(v)$；所有块均非空，且块数 $= v$ 的邻居数。

**证明**：树中删去顶点 $v$ 后，每个连通块与 $v$ 的一个邻居一一对应：任取块内节点 $x$，$x$ 到 $v$ 的路径的最后一条边 $(u, v)$ 给出该块的邻居 $u$；反之从 $u$ 出发不经过 $v$ 可达的点集是一个块。若 $u$ 是 $v$ 的孩子：$v$ 是 $\text{subtree}(u)$ 与树其余部分的唯一连接点（树上路径唯一），故该块恰为 $\text{subtree}(u)$，含 $u$ 非空。若 $u$ 是 $v$ 的父亲：由 $\text{subtree}(v) = \{v\} \cup \bigcup_{c} \text{subtree}(c)$，删去 $\text{subtree}(v)$ 后从 $u$ 可达的点集恰为 $T \setminus \text{subtree}(v)$，它包含根故非空，大小为 $n - \text{size}[v]$。二叉树至多 2 个孩子，故块数至多 3。∎

**引理 2（逆序累加正确性）**：先序序列的反转满足「任意节点的全部严格子孙都排在该节点之前」；`size` 初值全 1，按该倒序执行 `size[parents[v]] += size[v]`（$v = 0$ 除外）后，$\text{size}[v] = |\text{subtree}(v)|$ 对所有 $v$ 成立。

**证明**：先序访问中祖先必先于子孙出现，反转即得每个节点先于其所有祖先、特别地先于其父亲出现；$v$ 的孩子是 $v$ 的严格子孙，故轮到 $v$ 之前其全部孩子都已被处理，各自把当时的 `size` 加进了 `size[v]`。对倒序位置做强归纳：位置最早的节点必为叶子（其子孙集为空），`size` 保持初值 1，成立；设某节点 $v$ 被处理时其每个孩子 $c$ 均已处理完且由归纳假设 $\text{size}[c] = |\text{subtree}(c)|$ 已定型，则此后 `size[v]` 不再被修改且 $\text{size}[v] = 1 + \sum_{c} |\text{subtree}(c)| = |\text{subtree}(v)|$。∎

**定理**：上述算法返回得分最高节点的数目。

**证明**：由引理 2，组装阶段使用的 `size[]` 全部正确。由引理 1，删除 $v$ 后各连通块大小恰为多重集 $\{\text{size}[c] : c \in \text{children}(v)\} \cup \{n - \text{size}[v]\}$（$v$ 非根时含后者），算法计算的乘积正是这些数的乘积，即真实 $\text{score}(v)$。计数逻辑对节点序列做归纳：维护不变式「$(\text{best}, \text{cnt})$ = 已扫描前缀中最大分数及其出现次数」——首个节点时 $\text{score} \geq 1 > 0 = \text{best}$ 触发初始化，此后新分数严格大于则重置、相等则加一，均保持不变式。扫描完全体节点后即得全局答案。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。建邻接表一次 $O(n)$；栈式先序每个节点进出栈各一次 $O(n)$；逆序累加每条父边（共 $n-1$ 条）恰好触发一次 $O(n)$；组装阶段遍历所有节点的孩子列表，所有孩子总数为 $n-1$，合计 $O(n)$。
- **空间复杂度**：$O(n)$。`children` 邻接表与 `size`、`order` 数组各 $O(n)$；显式栈最坏 $O(n)$（链状树）。
- **最坏形态**：链状树（深度 $n$）。本做法全程迭代，无递归栈溢出风险；每个节点至多 1 个孩子，分数仅两因子（孩子子树 × 上方剩余），计算量不变。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int countHighestScoreNodes(vector<int>& parents) {
        int n = parents.size();
        vector<vector<int>> children(n);
        for (int v = 1; v < n; ++v)
            children[parents[v]].push_back(v);

        // 栈式先序：得到「祖先在前」的序列
        vector<int> order;
        order.reserve(n);
        vector<int> stk{0};
        while (!stk.empty()) {
            int v = stk.back();
            stk.pop_back();
            order.push_back(v);
            for (int c : children[v]) stk.push_back(c);
        }

        // 逆序累加：孩子先于父亲，子树大小沿父边上送
        vector<long long> size(n, 1);
        for (int i = n - 1; i >= 0; --i) {
            int v = order[i];
            if (v != 0) size[parents[v]] += size[v];  // parents[0] = -1，根必须跳过
        }

        long long best = 0;
        int cnt = 0;
        for (int v = 0; v < n; ++v) {
            long long score = 1;                       // 空积初值
            long long rest = n - size[v];              // 上方剩余；根时为 0，自动跳过
            if (rest > 0) score *= rest;
            for (int c : children[v]) score *= size[c];
            if (score > best) { best = score; cnt = 1; }
            else if (score == best) ++cnt;
        }
        return cnt;
    }
};
```

### Python

```python
class Solution:
    def countHighestScoreNodes(self, parents: List[int]) -> int:
        n = len(parents)
        children = [[] for _ in range(n)]
        for v in range(1, n):
            children[parents[v]].append(v)

        # 栈式先序：祖先在前
        order, stack = [], [0]
        while stack:
            v = stack.pop()
            order.append(v)
            stack.extend(children[v])

        # 逆序累加：孩子先于父亲
        size = [1] * n
        for v in reversed(order):
            if v:
                size[parents[v]] += size[v]   # 根跳过（parents[0] = -1）

        best = cnt = 0
        for v in range(n):
            score = 1
            rest = n - size[v]
            if rest > 0:
                score *= rest
            for c in children[v]:
                score *= size[c]
            if score > best:
                best, cnt = score, 1
            elif score == best:
                cnt += 1
        return cnt
```

> 💡 两份实现均已对拍验证：示例 1/2、$n=2$ 边界、$n = 10^5$ 的链（答案 2，中间两个节点 $v(n-1-v)$ 并列最大）与完全二叉树（答案 1）全部通过；另与「逐点模拟删除 + BFS 数连通块」的暴力在 3000 棵随机二叉树（$n \le 60$）上一致。

## 8. 边界情况与易错点

1. **乘积溢出（本题头号坑）**：最高分可达 $\approx 3.7 \times 10^{13}$，根节点两因子也有 $\approx 2.5 \times 10^9$，都超过 32 位 `int`。`score`/`best` 必须 `long long`；`size` 本身 $\le 10^5$ 用 `int` 没问题——别顺手把 `score` 也声明成 `int`。
2. **`parents[i]` 与 `i` 无大小关系**：示例 1 中 `parents[1] = 2 > 1`。若想当然「按下标从大到小累加 `size[parents[i]] += size[i]`」，会在父亲尚未定型时就送出错误的 size。必须先跑先序/BFS 拿到合法顺序。
3. **`parents[0] = -1` 的越界访问**：累加循环里 `size[parents[v]]` 在 $v = 0$ 时下标为 $-1$，C++ 是未定义行为，务必 `if (v != 0)` 守卫；组装处则用 `rest > 0` 自然规避。
4. **根的上方剩余是 0，不能乘**：题面要求「非空子树」的乘积，把 0 乘进去会让所有分数清零。用 `rest = n - size[v]; if (rest > 0)` 处理比 `if (v != 0)` 更不容易漏。
5. **链深 $10^5$ 的递归栈**：树可退化为链，递归 DFS 深度 $10^5$，Python 默认递归上限 1000 必崩，C++ 也有栈风险。先序 + 逆序累加全程迭代，天然免疫。
6. **$n = 2$ 最小规模**：两节点分数都是 1，答案 2；`best` 初值取 0 安全（$\text{score} \geq 1$ 恒成立）。
7. **叶子分数恒为 $n-1$**：实现完成后先看叶子的分数对不对，是最快的正确性自检。
8. **在线计数不要写成只记 `max` 的下标**：题目要**数目**，`score > best` 时记得把 `cnt` 重置为 1，而不是 `++cnt`。
