# LeetCode 并行课程 III 题解

## 1. 题目概述

- **标题 / 题号**：并行课程 III（#2050，hard）
- **链接**：https://leetcode.cn/problems/parallel-courses-iii/
- **来源**：LeetCode 第 264 场周赛 Q4
- **难度**：困难
- **标签**：图、拓扑排序、动态规划、DAG 带权最长路

**题意**：

$n$ 门课程编号 $1$ 到 $n$，`relations[j] = [prev, next]` 表示 `prev` 必须**修完才能开始** `next`（先修关系构成 **DAG**）。`time[i]` 是完成第 $i+1$ 门课所需的月份数。只要某门课的先修全部完成，它可以在**任意时刻**开始，且可以**同时修任意多门课**。求修完全部课程的**最少月份数**。

> 💡 一句话审题：并行不设上限、不额外收费——瓶颈不在「能同时修几门」，而在「最长的先修依赖链有多长」。这是与「每学期最多修 k 门」类题目（1136 / 1494）的本质区别。

**约束**：

- $1 \leq n \leq 5 \times 10^4$
- $0 \leq$ `relations.length` $\leq \min(n(n-1)/2,\ 5 \times 10^4)$，先修对互不相同，无自环
- `time.length == n`，$1 \leq \text{time}[i] \leq 10^4$
- 先修关系图**保证是 DAG**（一定可以修完全部课程）

## 2. 示例

**示例 1**（官方示例 1）

```text
输入：n = 3, relations = [[1,3],[2,3]], time = [3,2,5]
输出：8
解释：课程 1、2 无先修，第 0 月同时开始；
      课程 1 于第 3 月、课程 2 于第 2 月完成；
      课程 3 要等先修全部完成，最早第 3 月开始，3 + 5 = 8 月完成。
```

**示例 2**（官方示例 2）

```text
输入：n = 5, relations = [[1,5],[2,5],[3,5],[3,4],[4,5]], time = [1,2,3,4,5]
输出：12
解释：课程 1、2、3 并行开始，分别于 1 / 2 / 3 月完成；
      课程 4 等 3：第 3 月开始，3 + 4 = 7 月完成；
      课程 5 等 max(1, 2, 3, 7) = 第 7 月开始，7 + 5 = 12 月完成。
      关键路径 3 → 4 → 5：3 + 4 + 5 = 12。
```

**示例 3**（边界：完全无先修）

```text
输入：n = 4, relations = [], time = [5,3,8,2]
输出：8
解释：四门课第 0 月全部并行开始，总工期 = 最慢的那门 = 8。
      无任何先修时答案退化为 max(time)。
```

## 3. 解题思路

### 3.1 两条走不通的路：枚举拓扑序 与 「学期分层」

**枚举拓扑序**：把问题理解为「选一个修课顺序」——枚举所有拓扑序、逐个模拟取最优。DAG 的拓扑序数量是阶乘级的（空图有 $n!$ 个），$n = 5 \times 10^4$ 直接爆炸。浪费的根源在于：先修关系只约束**开始时刻**，不约束**顺序本身**——并行免费的世界里，「排顺序」是伪需求，该按「每门课各自何时完成」记账。

**学期分层（更隐蔽的坑）**：做过 1136「平行课程」很容易把那套 BFS 分层搬过来——每「学期」修掉所有已解锁课程、层内耗时取最大 `time`、学期数换成月份数。**这在带权时是错的**：分层把同层课程强行对齐到统一的学期边界，快的课白等慢的课。反例：

```text
n = 4, relations = [[1,3],[2,4]], time = [1,10,10,1]
两条独立链 1→3（1+10=11 个月）与 2→4（10+1=11 个月）互不干扰，真实答案 11；
分层模型：第 1 层 {1,2} 取 max(1,10) = 10，第 2 层 {3,4} 取 max(10,1) = 10，得 20 ✗
```

> ⚠️ 只有当所有 `time` 相等（无权图）时，「分层取 max」才与关键路径等价——1136 能成立恰恰因为它是无权的。带权之后必须逐点记账，不能按学期粗粒度对齐。

### 3.2 核心观察：并行免费 ⇒ 每门课的最早完成时间独立可算

![核心观察：并行免费时总工期等于 DAG 带权最长路（关键路径）](images/wc264_q4_critical_path.svg)

既然同时修多少门课都不额外花时间，课程 $v$ 何时能开始就**只**取决于它自己的先修课们谁最晚完成。定义 $\text{dist}[v]$ 为 $v$ 的**最早完成时刻**：

$$\text{dist}[v] \;=\; \text{time}[v] + \max_{u \to v} \text{dist}[u] \qquad (\text{无先修时 max 项为 } 0)$$

- 无先修的课第 0 月开始，$\text{dist}[v] = \text{time}[v]$；
- 有先修的课，开始时刻 = 先修中最晚的完成时刻，再加自身耗时。

全部修完的时刻就是最晚完成的那门课：

$$\text{答案} \;=\; \max_{v}\, \text{dist}[v]$$

两式合起来正是 **DAG 带权最长路**（节点权 = `time`），即工程管理中的**关键路径法（CPM）**：总工期由最长的依赖链决定，压缩非关键课程不缩短总工期。

> 💡 与 3.1 的分层模型对照：分层是「按层同步、层内取 max」，正确模型是「按点记账、逐点取 max」——同步化正是误差的来源。

### 3.3 算法流程：Kahn 拓扑排序 + dist 松弛

![算法流程：Kahn 拓扑排序逐点松弛 dist，一趟完成](images/wc264_q4_kahn_dp_flow.svg)

$\text{dist}[v]$ 依赖全部先修的 $\text{dist}$，必须**先修全部定型、再算后继**——这正是拓扑序。用 Kahn 算法（BFS 拓扑排序）一边剥零入度节点、一边松弛后继：

1. **建图**：邻接表 `adj[prev]` 存后继，`indeg[next]` 统计先修数，$O(n+m)$。
2. **初始化**：`dist[v] = time[v-1]`（自身耗时；注意课程 1 起编号、`time` 0 起下标的偏移）。
3. **入队**：所有 `indeg[v] == 0` 的课程入队——它们无先修，`dist` 已是终值。
4. **松弛**：弹出 $u$，对每个后继 $v$ 执行 `dist[v] = max(dist[v], dist[u] + time[v-1])`，`indeg[v]--`，减到 0 就入队。
5. **收尾**：返回 `max(dist)`。

关键机制：**入度归零 ⇔ 全部先修已松弛 ⇔ `dist[v]` 已定型**，此时才把 $v$ 入队，处理顺序天然是拓扑序。

### 3.4 示例演算

![示例 2 演算：Kahn 队列逐步松弛，关键松弛在 u=4 把 dist[5] 推到 12](images/wc264_q4_walkthrough.svg)

以示例 2 为例（完整表见插图）：初始 `dist = [1,2,3,4,5]`、队列 `[1,2,3]`。弹 1、2、3 依次把 `dist[5]` 推到 6、7、8；弹 3 时顺带把 `dist[4]` 从 4 松弛到 7 并让 4 入队；弹 4 时执行**关键松弛** `dist[5] = max(8, 7+5) = 12`。最终 `max(dist) = 12`。

> ⚠️ 注意 `dist[5] = 8` 这个「假答案」：只看先修 {1,2,3} 时 5 似乎 8 月完成，但 4 也是 5 的先修且完成得更晚——拓扑排序保证处理 5 之前它的**全部**先修都松弛过，这正是引理 3 的内容。

## 4. 算法细节

1. **邻接方向**：存「先修 → 后继」（`adj[prev]` 收 `next`），入度即先修数；也可反向存（后继 → 先修）配合记忆化 DFS，见 §8 第 6 条。
2. **`dist` 初值 = 自身耗时**：松弛公式把 `time[v]` 放在被松弛端累加（`dist[u] + time[v]`），每门课恰被加一次自身耗时；无先修的课永远不会被松弛，初值即终值。若初值误设为 0，无先修课程的完成时刻会算成 0。
3. **下标偏移**：课程编号 $1 \sim n$（1-indexed），`time` 数组 0-indexed，取耗时一律 `time[v-1]`——本题最高频的 WA 点。
4. **入队时机**：只在 `--indeg[v] == 0` 时入队。入队早了（比如松弛一次就入队）会破坏「出队时 dist 已定型」，松弛顺序错乱。
5. **答案取全体 max**：DAG 没有统一的「汇点」，最后一门完成的课可以是任何节点，必须 `max(dist[1..n])`，不能只看某个特定课程。
6. **值的范围**：$\text{dist} \leq n \times \max(\text{time}) = 5 \times 10^4 \times 10^4 = 5 \times 10^8 < 2^{31}-1 \approx 2.1 \times 10^9$，`int` 恰好安全（C++ 版已用 $5 \times 10^8$ 的链上界用例实测不溢出）；若担心数据变体，`long long` 一劳永逸。

## 5. 正确性证明

**引理 1（下界）**：设任一可行排课中课程 $v$ 的开始时刻为 $s[v] \geq 0$、完成时刻 $f[v] = s[v] + \text{time}[v]$，且对每条先修边 $u \to v$ 有 $s[v] \geq f[u]$。则对一切 $v$：$f[v] \geq \text{dist}[v]$。

**证明**：取任一拓扑序 $v_1, \dots, v_n$（先修必排在前）。对 $i$ 归纳：$v_i$ 的全部先修落在 $\{v_1, \dots, v_{i-1}\}$ 中，由归纳假设其 $f$ 值均不小于对应 $\text{dist}$。于是

$$f[v_i] = s[v_i] + \text{time}[v_i] \;\geq\; \max_{u \to v_i} f[u] + \text{time}[v_i] \;\geq\; \max_{u \to v_i} \text{dist}[u] + \text{time}[v_i] = \text{dist}[v_i]$$

其中第一个不等号用了先修约束与 $s[v_i] \geq 0$（无先修时 $\max$ 项由 $s[v_i] \geq 0$ 兜底）。∎

**引理 2（可达）**：定义 $s^{*}[v] = \max_{u \to v} \big(s^{*}[u] + \text{time}[u]\big)$（无先修时为 $0$）。该排课可行，且每门课恰在 $\text{dist}[v]$ 完成。

**证明**：图是 DAG，沿先修边的递归定义按拓扑序可逐一确定（良基）。$s^{*}$ 非负且满足全部先修约束，故可行；记 $f^{*}[v] = s^{*}[v] + \text{time}[v]$，则 $f^{*}[v] = \max_{u \to v} f^{*}[u] + \text{time}[v]$。再对拓扑序归纳：$f^{*}[v_i] = \max_{u \to v_i} \text{dist}[u] + \text{time}[v_i] = \text{dist}[v_i]$（先修的 $f^{*}$ 已由归纳假设等于 $\text{dist}$）。∎

**定理 1**：最少月份数 $= \max_v \text{dist}[v]$，且该值等于 DAG 的带权最长路长（路径权 = 沿途节点 `time` 之和）。

**证明**：任一可行方案的总工期 $T = \max_v f[v] \geq \max_v \text{dist}[v]$（引理 1）；引理 2 的方案达到 $\max_v f^{*}[v] = \max_v \text{dist}[v]$，两侧夹逼即得最优值。再证等于最长路：对「以 $v$ 结尾的路径」归纳可证 $\text{dist}[v]$ 恰为其最大节点权和——无先修时 $\text{dist}[v] = \text{time}[v]$ 即单节点路径；有先修时 $\text{dist}[v] = \text{time}[v] + \max_u \text{dist}[u]$，将取得最大值的先修 $u$ 的最优路径延长一步即得等值路径；反之任何以 $v$ 结尾的路径去掉 $v$ 后是以某先修 $u$ 结尾的路径，其权 $\leq \text{time}[v] + \text{dist}[u] \leq \text{dist}[v]$。对所有 $v$ 取最大即全图最长路。∎

**引理 3（Kahn 松弛定型）**：Kahn 算法中每条边恰被松弛一次（其起点出队时）；$v$ 入队当且仅当其全部入边已松弛；且 $v$ 被弹出时 `dist[v]` 已等于递归值。

**证明**：$v$ 的入度每在其一个先修出队、松弛边 $u \to v$ 时恰减一次，故归零 ⇔ 全部入边已松弛；出队顺序构成拓扑序（先修总在后继之前出队）。对出队顺序归纳：$v$ 出队时其全部先修已出队且 `dist` 已定型（归纳假设），$v$ 的每次松弛都以某个**已定型**的 `dist[u]` 为准；最后一次松弛发生在入度归零（入队）时，此后 `dist[v]` 不再被任何操作修改（能修改它的只有先修，均已处理完）。故出队时

$$\text{dist}[v] = \max\Big(\text{time}[v],\ \max_{u \to v}\big(\text{dist}[u] + \text{time}[v]\big)\Big) = \text{递归值}$$

（$v$ 有先修时任一 $\text{dist}[u] \geq \text{time}[u] \geq 1 > 0$，初值项被覆盖；无先修时恒为初值 $\text{time}[v]$）。∎

**定理 2（算法正确性）**：算法返回 $\max_v \text{dist}[v]$，由定理 1 即最少月份数。

**证明**：DAG 保证每个节点入度终会归零、Kahn 全体节点各出队一次；由引理 3，出队时的 `dist` 数组与递归定义逐点相等，程序返回其最大值，结合定理 1 得证。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n + m)$。建图遍历 `relations` 一次；Kahn 阶段每个节点入队、出队各一次，每条边恰在其起点出队时松弛一次。$n, m \leq 5 \times 10^4$，总量 $10^5$ 量级，远在时限内。
- **空间复杂度**：$O(n + m)$。邻接表 $O(n + m)$，`indeg`、`dist`、队列各 $O(n)$。
- **答案上界**：$5 \times 10^8$，`int` 可容纳（见 §4 第 6 条）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minimumTime(int n, vector<vector<int>>& relations, vector<int>& time) {
        vector<vector<int>> adj(n + 1);
        vector<int> indeg(n + 1, 0);
        for (auto& r : relations) {
            adj[r[0]].push_back(r[1]);
            indeg[r[1]]++;
        }

        // dist[v] = 课程 v 的最早完成时刻，初值 = 自身耗时
        vector<int> dist(n + 1);
        for (int v = 1; v <= n; ++v) dist[v] = time[v - 1];

        queue<int> q;
        for (int v = 1; v <= n; ++v)
            if (indeg[v] == 0) q.push(v);

        while (!q.empty()) {
            int u = q.front(); q.pop();
            for (int v : adj[u]) {
                // 松弛：先修 u 完成后，v 至少要到 dist[u] + time[v] 才能完成
                dist[v] = max(dist[v], dist[u] + time[v - 1]);
                if (--indeg[v] == 0) q.push(v);
            }
        }
        return *max_element(dist.begin() + 1, dist.end());
    }
};
```

### Python

```python
class Solution:
    def minimumTime(self, n: int, relations: List[List[int]], time: List[int]) -> int:
        adj = [[] for _ in range(n + 1)]
        indeg = [0] * (n + 1)
        for u, v in relations:
            adj[u].append(v)
            indeg[v] += 1

        # dist[v] = 课程 v 的最早完成时刻，初值 = 自身耗时
        dist = [0] + list(time)
        q = deque(v for v in range(1, n + 1) if indeg[v] == 0)

        while q:
            u = q.popleft()
            for v in adj[u]:
                if dist[u] + time[v - 1] > dist[v]:
                    dist[v] = dist[u] + time[v - 1]
                indeg[v] -= 1
                if indeg[v] == 0:
                    q.append(v)

        return max(dist[1:])
```

> 💡 两份实现均已验证：官方示例 1 / 2、$n = 1$ 与无先修边界、分层反例（答案 11）全部通过；另与「枚举 DAG 全部路径取最大节点权和」的暴力在 3000 张随机 DAG（$n \leq 8$）上一致；C++ 版另通过 $n = 5 \times 10^4$ 全链 + `time` 全 $10^4$ 的极端用例（答案恰为 $5 \times 10^8$，验证 `int` 不溢出）。

## 8. 边界情况与易错点

1. **下标偏移（头号坑）**：课程 1-indexed、`time` 0-indexed，耗时必须写 `time[v-1]`。写成 `time[v]` 轻则答案错、重则 $v = n$ 时越界。
2. **`dist` 初值设 0 而非 `time[v]`**：无先修的课程永远不会被松弛，初值 0 会让它们的完成时刻算成 0；若其他课程恰好更慢，样例全过、隐藏用例爆炸——典型的大小根之差。
3. **「学期分层」惯性（1136 后遗症）**：带权后按层同步必错（§3.1 反例：真值 11，分层 20）。识别信号：问的是「月份 / 时间」且 `time` 互不相同 → 逐点记账，不按层对齐。
4. **答案取全体 `max`**：没有统一的「最后一门课」，任何节点都可能是最晚完成的；`dist` 数组 0 号位是占位 0，取 max 时跳过（C++ 用 `begin() + 1`）。
5. **`relations` 为空 / $n = 1$**：全部课程初始入队后直接扫完，答案 `max(time)` / `time[0]`，无需特判。
6. **想用 DFS + 记忆化**：递归深度可达链长 $5 \times 10^4$，Python 默认递归上限 1000 必崩，C++ 也有爆栈风险；迭代 Kahn 是更稳的选择（每日姊妹篇 §5 有两种写法的对照表）。
7. **若不保证 DAG**：Kahn 结束时出队计数 $< n$ 即有环（本题保证无环，可不作检测，但值得在面试时提一句）。
8. **溢出核算**：上界 $n \cdot \max(\text{time}) = 5 \times 10^8$，`int` 安全但只余约 77% 余量；若数据范围放宽（如 `time` 到 $10^5$），立即改 `long long`。

1. **输出关键路径本身**：松弛时额外记下把 $v$ 推到当前值的先修 `from[v]`，结束时从取得全局 max 的节点沿前驱回溯，即得一条具体的最长依赖链。
2. **允许赶工**：每门课可花 $c_v$ 的钱把耗时从 $\text{time}[v]$ 压到 $\text{minT}[v]$，问预算 $B$ 内的最短工期——经典工期-成本权衡问题，贪心只压缩关键路径上的课还要处理压缩后关键路径的切换。
3. **每学期最多修 k 门**（1494 路线）：并行不再免费，需子集 DP；对比本题可看清「资源约束」这一维如何把线性问题变成状压问题。
4. **图可能带环**：先用 Kahn 判环（出队计数 $< n$），有环则永远修不完、返回 $-1$。
