# LeetCode 子集中元素的最大数量 题解

## 1. 题目概述

- **标题 / 题号**：子集中元素的最大数量（#3020，medium）
- **链接**：https://leetcode.cn/problems/find-the-maximum-number-of-elements-in-subset/
- **来源**：LeetCode 第 382 场周赛 Q2
- **难度**：中等
- **标签**：数组、哈希表、枚举

**题意**：给定正整数数组 `nums`，从中选出一个子集（每个元素最多用一次），把选出的元素排成下标从 0 开始的数组，使其遵循模式 $[x, x^2, x^4, \ldots, x^{k/2}, x^k, x^{k/2}, \ldots, x^4, x^2, x]$，其中 $k$ 是任意非负的 2 的幂。返回满足条件的子集中**元素数量的最大值**。

**约束**：

- $2 \le nums.length \le 10^5$
- $1 \le nums[i] \le 10^9$

> 💡 **关键转化**：合法数组是"平方链"上的回文山丘——指数是 $1, 2, 4, \ldots, 2^j, \ldots, 4, 2, 1$。整个模式由**底 $x$** 和**峰值档位 $j$**（$k = 2^j$）唯一确定，于是"枚举子集"可以降维成"枚举模式"。

## 2. 示例

**示例 1**

```text
输入：nums = [5,4,1,2,2]
输出：3
解释：选择子集 {4,2,2}，排成 [2,4,2]，满足 2² = 4。
```

**示例 2**

```text
输入：nums = [1,3,2,4]
输出：1
解释：选择子集 {1}，排成 [1]。任何单个元素都是合法模式（j = 0）。
```

**示例 3（自定义：中间元素份数不足，链被截断）**

```text
输入：nums = [2,2,4,16,16]
输出：3
解释：从 2 出发：cnt(2)=2 可作非峰值，但 cnt(4)=1，4 只能当峰值，得 [2,4,2]。
     多出来的两个 16 想用上需要 256（16²），不在数组中，帮不上忙。
```

**示例 4（自定义：全 1）**

```text
输入：nums = [1,1,1,1]
输出：3
解释：1 的任何幂都是 1，模式退化为任意奇数个 1。4 个 1 只能取 3 个。
```

## 3. 解题思路

### 3.1 暴力思路

最朴素的做法是枚举所有子多重集再逐一验证能否排成模式，复杂度 $O(2^n)$，在 $n \le 10^5$ 下完全不可行。

但换个角度：合法数组的形状只有"回文山丘"一种，**整个子集由底 $x$ 和峰值档位 $j$ 两个参数唯一决定**。真正要枚举的不是子集，而是模式 $(x, j)$——这就是优化的起点。

### 3.2 核心观察：模式由「底 x + 峰值档位」唯一确定

![合法模式：平方链上的回文山丘](images/wc382_q2_pattern_shape.svg)

1. **模式刻画**：合法数组形如 $[x, x^2, x^4, \ldots, x^{2^j}, \ldots, x^4, x^2, x]$。指数序列 $1, 2, 4, \ldots, 2^j, \ldots, 4, 2, 1$ 是不断翻倍的回文，长度 $2j+1$ **恒为奇数**；$j = 0$ 时模式就是单个元素 $[x]$。

2. **次数要求**：非峰值 $x^{2^i}$（$i < j$）在左右两侧各出现一次，需要**恰好 2 份**；峰值 $x^{2^j}$ 只出现一次，需要**至少 1 份**（多余份数无用）。

3. **平方链极短**：所有元素都落在链 $x \to x^2 \to x^4 \to x^8 \to \cdots$ 上。由 $x^{2^j} \le 10^9$ 得 $2^j \cdot \log_2 x \le 30$，即 $j \le 4$——**每条链至多 5 个不同值**（如 $x=2$：$2,4,16,256,65536$；$x=3$：$3,9,81,6561,43046721$）。沿链走查每步只需一次哈希查询，代价极低。

4. **$x = 1$ 是自环**：$1^2 = 1$，任何幂都是 1。模式退化为"任意奇数个 1"：$c_1$ 个 1 的最优贡献是 $c_1$（$c_1$ 为奇数）或 $c_1 - 1$（$c_1$ 为偶数）。走链前必须显式跳过 $x=1$，否则死循环。

5. **必须以每个出现过的值为起点**，不能只从"链根"（非完全平方数）出发：例如 $\{2{:}1,\ 4{:}2,\ 16{:}1\}$，从链根 2 出发因 $cnt(2)=1$ 只能得到 1，但从 4 出发可得 $[4,16,4]$，长度 3。详见 §4 的对比分析。

### 3.3 算法流程：沿平方链走查

![算法流程：从每个起点沿平方链走查](images/wc382_q2_chain_walk_flow.svg)

先哈希计数，特判 $x=1$；然后对表中每个 $x \ge 2$，从 $x$ 出发沿平方链走查，规则只有三条：

```text
cnt = 哈希计数(nums)
ans = c1 为奇数 ? c1 : c1-1        （若存在 1）

对表中每个键 x（x ≥ 2）:
    len = 0, cur = x
    循环:
        若 cur 不在表中:  len -= 1; 终止    # 链断：上一元素多算的 1 份改回峰值
        若 cnt[cur] == 1: len += 1; 终止    # 份数不够，只能当峰值
        len += 2                          # 左右各一份
        cur = cur × cur                   # 沿链上移一格
    ans = max(ans, len)
```

其中"链断回退 1"是最容易写错的一步：链上元素全部 $cnt \ge 2$ 而平方后不在表中时，最后那个元素其实该当**峰值**（只需 1 份），之前按 2 份累加多算了 1，要减回来。Python 可用 `while ... else` 优雅表达，C++ 用一个退出分支即可。

### 3.4 示例演算

![示例演算：nums = [5,4,1,2,2]](images/wc382_q2_example_walk.svg)

以 `nums = [5,4,1,2,2]` 为例，计数得 $\{5{:}1,\ 4{:}1,\ 1{:}1,\ 2{:}2\}$：

| 起点 | 走查过程 | 候选长度 |
|------|----------|----------|
| $x=1$ | 特判：$c_1 = 1$（奇数） | 1 |
| $x=2$ | $cnt(2)=2 \ge 2$ 计 2 份上移 → $cnt(4)=1$ 作峰值 | **3** |
| $x=4$ | $cnt(4)=1$ 只能当峰值（$16$ 不在表中，无法延伸） | 1 |
| $x=5$ | $cnt(5)=1$ 只能当峰值 | 1 |

答案为 3，对应子集 $\{2,2,4\}$ 排成 $[2,4,2]$。注意 $x=4$ 虽然是 $2^2$（链上非根位置），也必须走查——若只从链根 2 走查，本题恰好不丢解，但 §4 的反例说明一般情形会丢。

## 4. 算法细节

1. **数据结构**：`unordered_map`（C++）/ `Counter`（Python）做值 → 次数的哈希表；也可以排序后双指针，但哈希更直接。

2. **走查三分支**（每个起点 $x \ge 2$，维护 `cur` 与 `len`）：
   - `cur` 不在表中 → 链断：`len -= 1`（最后一步按 2 份算多了，峰值只要 1 份），终止；
   - `cnt[cur] == 1` → 只能当峰值：`len += 1`，终止；
   - `cnt[cur] >= 2` → 左右各一份：`len += 2`，`cur` 自乘上移。

3. **为什么枚举所有起点，而不是只从链根走**：直觉上像 128. 最长连续序列那样只从"链头"（非完全平方数）走一遍就能覆盖整条链，但本题不行——链头份数为 1 时它只能当峰值，**会把链上更高的位置"堵死"**，而更高的子链仍可能以中间元素为底构成合法模式。例如 $\{2{:}1, 4{:}2, 16{:}1\}$：从链根 2 出发只能得到 $[2]$，从 4 出发却能得到 $[4,16,4]$。由于链长 $\le 5$，对每个键都走一遍的总代价只是原来的常数倍，正确性却立住了。

4. **溢出（C++）**：只有 `cur` 在表中（$\le 10^9$）时才会平方，故 `cur * cur` 最大 $10^{18}$，`long long` 装得下；而 $10^{18} > 10^9$ 必然不在表中，循环随即终止，不会对 $10^{18}$ 再平方。若用 `int` 存 `cur` 会在平方时溢出，是典型的 WA 点。

5. **链长上界推导**：$x^{2^j} \le 10^9 \Rightarrow 2^j \le 30/\log_2 x \le 30 \Rightarrow j \le 4$，即链上至多 5 个不同值。走查总步数为 $O(U \cdot \log\log V)$，$U$ 为不同值个数。

6. **1 的自环**：$1 \to 1 \to 1 \to \cdots$ 永不终止，循环前用 `if (x == 1) continue;` 跳过，并单独按奇偶计算候选。

## 5. 正确性证明

**引理 1（模式刻画）**：多重集 $S$ 能排成合法模式，当且仅当存在 $x \ge 1$ 与 $j \ge 0$，使得 $S$ 由「$x^{2^i}$ 各 2 份（$0 \le i < j$）」与「$x^{2^j}$ 1 份」组成。$x = 1$ 时所有 $x^{2^i} = 1$，即 $S$ 是大小为奇数的全 1 多重集。

**证明**：模式数组下标 $0 \sim 2j$ 关于中心 $j$ 对称，位置 $i$ 与 $2j - i$ 上的值相同，均为 $x^{2^{\min(i,\,2j-i)}}$；其中 $\min(i, 2j-i) < j$ 的每个值恰出现两次，中心位置（值为 $x^{2^j}$）出现一次。反之，把满足上述次数条件的多重集按该对应关系排布即得合法数组。∎

**引理 2（固定底时的单调性）**：固定 $x \ge 2$，记 $v_i = x^{2^i}$。若峰值档位 $j$ 可行（即 $cnt(v_i) \ge 2$ 对所有 $i < j$，且 $cnt(v_j) \ge 1$），则任意 $0 \le j' < j$ 也可行，且对应长度 $2j'+1 < 2j+1$。

**证明**：$j'$ 的约束条件是 $j$ 的约束条件在更短前缀上的子集，自然满足；长度公式关于 $j$ 严格递增。∎

**引理 3（走查定位最大可行档位）**：设链上在表中的前缀为 $v_0, \ldots, v_{L-1}$（$v_L$ 不在表中）。走查得到的长度恰为 $\max_j (2j+1)$，其中 $j$ 取遍所有可行档位。

**证明**：分两种情形。

- 若存在最小的 $m < L$ 使 $cnt(v_m) = 1$：任何 $j \ge m+1$ 都要求 $cnt(v_m) \ge 2$，不可行；而 $j = m$ 可行，长度 $2m+1$。走查恰在 $v_0, \ldots, v_{m-1}$ 各计 2 份后，于 $v_m$ 处计 1 份（峰值）终止，得 $2m+1$。
- 若 $v_0, \ldots, v_{L-1}$ 全部 $cnt \ge 2$：最大可行档位为 $j = L-1$（$j = L$ 需要 $v_L$），长度 $2(L-1)+1 = 2L-1$。走查给每个元素计 2 份共 $2L$，在 $v_L$ 处发现不在表中，回退 1，恰得 $2L - 1$。

两种情形走查都给出最大可行档位对应的长度。∎

**定理**：算法返回合法子集大小的最大值。

**证明**：任一合法子集 $S$ 由引理 1 对应某个 $(x, j)$ 模式。$x = 1$ 时可行子集大小恰为不超过 $c_1$ 的全部奇数，最大值为 $c_1$（$c_1$ 奇）或 $c_1 - 1$（$c_1$ 偶），与算法特判一致。$x \ge 2$ 时，由引理 2，每个底 $x$ 只需考虑最大可行档位；由引理 3，走查恰好给出该值。算法对表中**所有** $x \ge 2$ 取最大，覆盖了全部可能的 $(x, j)$，故为全局最优。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n + U \log\log V)$，其中 $U$ 为不同值个数（$U \le n$），$V = 10^9$。哈希计数 $O(n)$；每个不同值走查一条链，链长 $\le \log_2\log_2 V \approx 5$，每步一次哈希查询。实践中 $\log\log V$ 是常数，总复杂度即 $O(n)$。
- **空间复杂度**：$O(U)$，哈希表存储不同值及其次数。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maximumLength(vector<int>& nums) {
        unordered_map<long long, int> cnt;
        for (int v : nums) cnt[v]++;

        int ans = 1;
        if (auto it = cnt.find(1); it != cnt.end()) {
            ans = it->second % 2 ? it->second : it->second - 1;
        }

        for (auto& kv : cnt) {
            long long x = kv.first;
            if (x == 1) continue;          // 1 是自环，走链前必须跳过
            int len = 0;
            long long cur = x;
            while (true) {
                auto it = cnt.find(cur);
                if (it == cnt.end()) {     // 链断：上一元素改作峰值
                    len -= 1;
                    break;
                }
                if (it->second == 1) {     // 份数不够，只能当峰值
                    len += 1;
                    break;
                }
                len += 2;                  // 左右各一份
                cur *= cur;                // 沿平方链上移（≤ 10^18，long long 安全）
            }
            ans = max(ans, len);
        }
        return ans;
    }
};
```

### Python

```python
from collections import Counter


class Solution:
    def maximumLength(self, nums: List[int]) -> int:
        cnt = Counter(nums)
        ans = 1
        if 1 in cnt:
            ans = cnt[1] if cnt[1] % 2 else cnt[1] - 1

        for x in cnt:
            if x == 1:
                continue
            length = 0
            cur = x
            while cur in cnt:
                if cnt[cur] >= 2:
                    length += 2
                    cur *= cur
                else:
                    length += 1
                    break
            else:
                length -= 1  # 循环因“不在表中”退出：峰值只需 1 份，回退
            ans = max(ans, length)
        return ans
```

## 8. 边界情况与易错点

1. **$x = 1$ 死循环**：1 的平方还是 1，不跳过会无限循环；1 的候选要按奇偶单独算。
2. **全 1 偶数个**：如 $[1,1,1,1]$，模式长度恒为奇数，答案为 $c_1 - 1 = 3$ 而不是 4。
3. **"链根"思维陷阱**：不能只从非完全平方数出发走链。$\{2{:}1, 4{:}2, 16{:}1\}$ 的最优解是 $[4,16,4]$（以 4 为底），只走链根会得到错误的 1。
4. **$cnt = 1$ 的截断语义**：链中间元素只有 1 份时，它只能当峰值（终止），不能"越过去"继续使用更高的幂——多余的更高元素与它无关。
5. **链尾回退 $-1$**：链上全部 $cnt \ge 2$ 且平方后不在表中时，最后累加的 2 份多算了 1 份（峰值只需 1 份）。这是本题最容易 WA 的地方，Python 的 `while-else` 恰好优雅覆盖该分支。
6. **C++ 溢出**：`cur * cur` 最大 $10^{18}$，`cur` 与哈希表的键都必须用 `long long`；用 `int` 必溢出。
7. **峰值多份无用**：峰值只贡献 1 份、非峰值最多 2 份，$cnt \ge 3$ 的多余副本不会带来收益，不要贪多。
8. **答案至少为 1**：任何单个元素 $[x]$ 都是合法模式（$j = 0$，$k = 1 = 2^0$）。
