# LeetCode Alice 和 Bob 玩鲜花游戏 题解

## 1. 题目概述

- **标题 / 题号**：Alice 和 Bob 玩鲜花游戏（#3021，medium）
- **链接**：https://leetcode.cn/problems/alice-and-bob-playing-flower-game/
- **来源**：LeetCode 第 382 场周赛 Q3
- **难度**：中等
- **标签**：数学、博弈、计数

**题意**：Alice 和 Bob 之间的田野上有两排鲜花，第一排 $x$ 朵、第二排 $y$ 朵。Alice 先手，双方轮流行动；每次行动必须选择**其中一排**，从这边摘**一朵**花。一次行动结束后，若**两排都**没有剩下鲜花，则**刚行动的**玩家抓住对手并获胜。给定 $n$ 和 $m$，统计满足 $1 \le x \le n$、$1 \le y \le m$ 且 **Alice 必胜**的数对 $(x, y)$ 的个数。

**约束**：

- $1 \le n, m \le 10^5$

> 💡 **关键转化**：每次行动恰好摘走一朵花，游戏**必然**在第 $x+y$ 步结束——双方的任何选择都改变不了总步数。于是这局"博弈"退化为**奇偶判定**：Alice 先手走奇数步，她获胜当且仅当 $x+y$ 为奇数；问题进一步退化为**计数**：$[1,n] \times [1,m]$ 中有多少对奇偶性互异的 $(x, y)$。

## 2. 示例

**示例 1**

```text
输入：n = 3, m = 2
输出：3
解释：满足条件的数对是 (1,2)、(3,2)、(2,1)，总和分别为 3、5、3，均为奇数。
```

**示例 2**

```text
输入：n = 1, m = 1
输出：0
解释：唯一数对 (1,1) 总数为 2：Alice 摘一朵后，Bob 摘走最后一朵，Bob 获胜。
```

**示例 3（自定义：验证闭式）**

```text
输入：n = 4, m = 5
输出：10
解释：x 奇 y 偶的有 2×2 = 4 对，x 偶 y 奇的有 2×3 = 6 对，共 10 = ⌊4×5/2⌋ 对。
```

## 3. 解题思路

### 3.1 暴力思路

最直接的做法：双重循环枚举所有 $(x, y)$，用 $O(1)$ 判断 $x+y$ 的奇偶。复杂度 $O(nm)$，在 $n, m \le 10^5$ 时高达 $10^{10}$，必然超时。

另一个方向的"暴力"更危险：把题目当成真博弈，对每个 $(x,y)$ 写 minimax / 记忆化搜索模拟摘花过程——单次 $O(x+y)$，总计 $O(nm \cdot (n+m))$，而且完全是浪费，因为这局棋**根本没有策略空间**（见下）。

### 3.2 核心观察：游戏长度恒为 $x+y$，胜负与策略无关

![游戏长度与胜负判定](images/wc382_q3_game_parity.svg)

1. **步数是定数**：规则强制"每次必须摘、且只能摘一朵"。无论双方怎么选，每一次行动都让总数恰好减 1，所以游戏**恰好**进行 $x+y$ 步，不多不少。
2. **胜者是收官者**：胜利条件是"自己行动后两排皆空"，即自己摘走了**最后一朵**花——也就是第 $x+y$ 步的行动者。
3. **先手走奇数步**：Alice 行动第 $1, 3, 5, \ldots$ 步（奇数步），Bob 行动偶数步。于是
   $$\text{Alice 获胜} \iff x + y \text{ 为奇数}.$$
4. **为什么没有策略**：与 Nim、292 题"可取 1~3 个"的博弈不同，本题所有合法着法**完全等价**（都让总数减 1，且不影响"谁走最后一步"）——博弈树是一条单链，不存在任何选择，胜负在 $(x,y)$ 给定的瞬间就已注定。识别"伪博弈"是本题的第一层考点。

### 3.3 算法流程：奇偶四象限计数

![奇偶四象限计数](images/wc382_q3_parity_grid.svg)

$x+y$ 为奇 $\iff$ $x$ 与 $y$ 奇偶性**互异**。两个维度独立，用乘法原理分成两类相加：

```text
奇x = [1,n] 中奇数个数 = ⌈n/2⌉          偶x = ⌊n/2⌋
奇y = [1,m] 中奇数个数 = ⌈m/2⌉          偶y = ⌊m/2⌋

ans = 奇x × 偶y  +  偶x × 奇y
```

其中 $[1, n]$ 中的奇数是 $1, 3, 5, \ldots$，共 $\lceil n/2 \rceil$ 个（代码里用 $(n+1)/2$ 的整数除法实现）。整个算法就是四则运算，$O(1)$ 完成。

### 3.4 示例演算

![示例演算：n=3, m=2](images/wc382_q3_example_walk.svg)

以 $n=3, m=2$ 为例：奇 $x \in \{1, 3\}$（2 个）、偶 $x = \{2\}$（1 个）、奇 $y = \{1\}$、偶 $y = \{2\}$，故 $ans = 2 \times 1 + 1 \times 1 = 3$，对应获胜对 $(1,2)$、$(2,1)$、$(3,2)$，与示例解释完全一致。再验证 $n = m = 1$：$ans = 1 \times 0 + 0 \times 1 = 0$，同样吻合。

## 4. 算法细节

1. **奇偶个数公式**：$[1, n]$ 中奇数有 $\lceil n/2 \rceil = \lfloor (n+1)/2 \rfloor$ 个，偶数有 $\lfloor n/2 \rfloor$ 个。整数除法即可，无需浮点。
2. **乘法原理的独立性**：$x$ 与 $y$ 的取值互不影响，"x 奇 y 偶"的对数 $=$ 奇 $x$ 个数 $\times$ 偶 $y$ 个数；"奇偶"与"偶奇"两类互斥且覆盖全部获胜对，直接相加。
3. **闭式**：$ans = \left\lfloor nm/2 \right\rfloor$，证明见 §5 定理。代码可以只写 `n * m / 2` 一行，但四象限式更直观、不易错，也方便推广（见延伸思考）。
4. **溢出（C++）**：$n \cdot m \le 10^{10}$，中间乘积 $\lceil n/2 \rceil \cdot \lfloor m/2 \rfloor \le 2.5 \times 10^9$，双双超过 `int` 上界 $2^{31}-1 \approx 2.1 \times 10^9$。所有中间变量与返回值都必须用 `long long`（本题签名已是 `long long`，注意别在中间步骤退回 `int`）。
5. **取整括号**：`n / 2 * ((m + 1) / 2)` 与 `n / 2 * (m + 1) / 2` 在 C++ 中结果**不同**——后者 `*` 与 `/` 同优先级左结合，先乘后除，$m$ 为奇数时丢精度。第二个因子必须加括号（撰写本篇题解时作者本人就被它坑过一次）。

## 5. 正确性证明

**引理 1（游戏长度与胜者）**：对任意 $x, y \ge 1$，游戏恰好进行 $x+y$ 步；第 $k$ 步的行动者是 Alice 当且仅当 $k$ 为奇数；获胜者是第 $x+y$ 步的行动者。特别地，Alice 获胜 $\iff x+y$ 为奇数。

**证明**：第 $k$ 步行动前的总数为 $x+y-(k-1)$。只要 $k \le x+y$，总数 $\ge 1$，当前玩家总存在合法行动，且任何合法行动使总数恰好减 1，故行动序列唯一确定长度为 $x+y$。行动者从 Alice 起交替轮转，第 $k$ 步为 Alice $\iff k$ 为奇数。"行动后两排皆空" $\iff$ 总数降为 0，首次且唯一发生在第 $x+y$ 步，故获胜者即该步行动者。∎

**引理 2（四象限计数）**：记 $odd_N = \lceil n/2 \rceil$、$even_N = \lfloor n/2 \rfloor$、$odd_M = \lceil m/2 \rceil$、$even_M = \lfloor m/2 \rfloor$，则 $[1,n] \times [1,m]$ 中满足 $x+y$ 为奇的数对个数为 $odd_N \cdot even_M + even_N \cdot odd_M$。

**证明**：$x+y$ 为奇 $\iff$ $x, y$ 一奇一偶（同奇或同偶均为偶）。按 $x$ 的奇偶分成"奇偶"与"偶奇"两类，互斥且覆盖全部获胜对；类内 $x$ 与 $y$ 独立取值，由乘法原理分别有 $odd_N \cdot even_M$ 与 $even_N \cdot odd_M$ 对，相加即得。∎

**定理（闭式）**：$odd_N \cdot even_M + even_N \cdot odd_M = \left\lfloor nm/2 \right\rfloor$。

**证明**：分三种情形。

- $n$ 为偶数：固定任意 $y$，$[1,n]$ 中与 $y$ 异奇的 $x$ 恰有 $n/2$ 个（奇偶各半），故 $ans = m \cdot (n/2) = nm/2$；此时 $nm$ 为偶，等于 $\lfloor nm/2 \rfloor$。
- $m$ 为偶数：对称地 $ans = nm/2 = \lfloor nm/2 \rfloor$。
- $n, m$ 均奇：$odd_N = \frac{n+1}{2}$、$even_N = \frac{n-1}{2}$、$odd_M = \frac{m+1}{2}$、$even_M = \frac{m-1}{2}$，于是
  $$ans = \frac{(n+1)(m-1) + (n-1)(m+1)}{4} = \frac{2nm - 2}{4} = \frac{nm-1}{2} = \left\lfloor \frac{nm}{2} \right\rfloor$$
  （$nm$ 为奇数）。∎

**推论**：按引理 2 计数的算法返回正确答案；由定理，亦可直接返回 $\lfloor nm/2 \rfloor$。

## 6. 复杂度分析

- **时间复杂度**：$O(1)$。只做常数次乘除加法，与 $n, m$ 的规模无关。
- **空间复杂度**：$O(1)$。仅常数个变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long flowerGame(int n, int m) {
        long long oddN = (n + 1) / 2, evenN = n / 2;
        long long oddM = (m + 1) / 2, evenM = m / 2;
        return oddN * evenM + evenN * oddM;   // 由定理亦等于 (long long)n * m / 2
    }
};
```

### Python

```python
class Solution:
    def flowerGame(self, n: int, m: int) -> int:
        odd_n = (n + 1) // 2
        odd_m = (m + 1) // 2
        return odd_n * (m // 2) + (n // 2) * odd_m
```

## 8. 边界情况与易错点

1. **`int` 溢出**：$ans$ 最大约 $5 \times 10^9$（$n = m = 10^5$ 时），`int` 必炸；C++ 全程 `long long`，闭式写法记得先转换 `(long long)n * m / 2`。
2. **取整括号**：`(n / 2) * (m + 1) / 2` 先乘后除会丢精度，必须写成 `(n / 2) * ((m + 1) / 2)`（见 §4 第 5 点）。
3. **误当真博弈**：写 SG 函数、minimax、记忆化搜索都是南辕北辙——所有着法等价，博弈树是一条链，胜负与走法无关。
4. **奇数个数数错**：$[1, n]$ 的奇数个数是 $\lceil n/2 \rceil$，$n$ 为奇时若误用 $n/2$ 会少 1（如 $n=3$ 时误得 1 个奇数）。
5. **胜利条件读偏**：是"自己行动后**两排同时**为空"才获胜（即摘到最后一朵），不是"先摘空某一排"也不是"让对手无花可摘"——本题里这些说法恰好同时发生，但条件改一个字就是另一道题。
6. **最小样例**：$n = m = 1$ 时答案为 0，可作 sanity check；$n = 1, m = 2$ 时答案为 1（仅 $(1,2)$）。
