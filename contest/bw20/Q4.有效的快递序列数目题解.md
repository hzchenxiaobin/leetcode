# LeetCode 有效的快递序列数目 题解

## 1. 题目概述

- **标题 / 题号**：有效的快递序列数目（#1359，hard）
- **链接**：https://leetcode.cn/problems/count-all-valid-pickup-and-delivery-options/
- **来源**：LeetCode 第 20 场双周赛 Q4
- **难度**：困难
- **标签**：数学、动态规划、组合数学

**题意**：有 $n$ 笔订单，第 $i$ 笔订单有取货 `P_i` 与交付 `D_i` 两个事件。把 $2n$ 个事件排成一个序列，要求对每个 $i$，`D_i` 都排在 `P_i` 之后。求满足条件的序列数目，对 $10^9 + 7$ 取余。

**约束**：

- $1 \le n \le 500$
- 答案对 $10^9+7$ 取模

## 2. 示例

**示例 1**

```text
输入：n = 1
输出：1
解释：唯一序列 (P₁, D₁)。
```

**示例 2**

```text
输入：n = 2
输出：6
解释：(P₁,P₂,D₁,D₂)，(P₁,P₂,D₂,D₁)，(P₁,D₁,P₂,D₂)，
      (P₂,P₁,D₁,D₂)，(P₂,P₁,D₂,D₁)，(P₂,D₂,P₁,D₁)。
      例如 (P₁,D₂,P₂,D₁) 无效：D₂ 排在了 P₂ 前面。
```

**示例 3**

```text
输入：n = 3
输出：90
```

## 3. 解题思路

### 3.1 暴力思路

枚举 $2n$ 个带标号事件的全排列 $(2n)!$ 个、逐个检查每对 $P_i \prec D_i$：$n = 3$ 时 720 个排列尚可，$n = 5$ 时 $10! = 3628800$ 已到极限，$n = 500$ 完全不可想象。有效序列只占全排列的 $1/2^n$，巨大的浪费提示我们**不要枚举再过滤，而要直接构造/计数**。

### 3.2 核心观察：插入法——每加一笔新订单，旧的合法序列之间有 $C(2n,2)$ 个空位可用

![插入法：给P_n、D_n挑两个位置](images/bw20_q4_insertion_derivation.svg)

按订单号 $1, 2, \dots, n$ **逐笔插入**。设 $f(k)$ 为 $k$ 笔订单的合法序列数。已知一个 $k$ 笔订单的合法序列（长 $2k$），把它扩充成 $k+1$ 笔订单（长 $2k+2$）时：在最终长 $2(k+1)$ 的序列中**选两个位置**，前面的放 $P_{k+1}$、后面的放 $D_{k+1}$，其余位置按原相对顺序保留旧序列——$P$ 在前 $D$ 在后天然满足新订单的约束，旧订单的相对顺序未变所以仍然合法。

选择数是

$$\binom{2k+2}{2} = \frac{(2k+2)(2k+1)}{2} = (k+1)(2k+1)$$

即对第 $k+1$ 笔订单（记 $i = k+1$）有 $i(2i-1)$ 种插入方式。于是

$$f(n) = f(n-1) \cdot n(2n-1),\qquad f(1) = 1$$

**这为什么数得不重不漏**：任何 $n$ 订单的合法序列删去 $P_n, D_n$ 后得到的仍是合法的 $(n-1)$ 订单序列，且由「哪两个位置放了 $P_n, D_n$」可完全还原——「(旧序列, 插入位置对)」与「新序列」双射。$n=1\to2$：$1 \times 2 \times 3 = 6$ ✓；$n=2\to3$：$6 \times 3 \times 5 = 90$ ✓。

### 3.3 闭式：连乘化简为 $(2n)! / 2^n$

![递推链条与闭式：(2n)!/2^n](images/bw20_q4_recurrence.svg)

把递推展开成连乘：

$$f(n) = \prod_{i=1}^{n} i \cdot (2i-1) = \Big(\prod_{i=1}^n i\Big)\Big(\prod_{i=1}^n (2i-1)\Big) = n! \cdot (2n-1)!!$$

其中 $(2n-1)!! = 1 \cdot 3 \cdot 5 \cdots (2n-1)$ 是奇双阶乘。由 $(2n)! = \underbrace{(2n)(2n-2)\cdots 2}_{2^n \cdot n!} \times (2n-1)!!$，即 $(2n-1)!! = \dfrac{(2n)!}{2^n \, n!}$，代入得

$$\boxed{f(n) = n! \cdot (2n-1)!! = \frac{(2n)!}{2^n}}$$

验证：$n=2$：$24/4 = 6$ ✓；$n=3$：$720/8 = 90$ ✓。

还有一条更短的路——**对称性**：在全部 $(2n)!$ 个排列中，对任意排列交换 $P_i \leftrightarrow D_i$ 是保持「其余约束不变」的对合，故「$P_i \prec D_i$ 对全部 $i$ 成立」的排列占比恰为 $\dfrac{1}{2^n}$，直接得 $f(n) = (2n)!/2^n$（见下图与 §5 引理 4）。

![n=2的24个排列中恰好6个合法](images/bw20_q4_n2_enumeration.svg)

### 3.4 实现取舍：取模下用递推最稳

$n = 500$ 时 $(2n)!$ 巨大，取模除法 $/2^n$ 需要乘法逆元；而递推 $f(i) = f(i-1)\cdot i \cdot (2i-1) \bmod p$ 每步只乘两个 $\le 10^6$ 的因子，`long long` 内两步取模即可，代码最短、最不容易错。

## 4. 算法细节

1. **递推式**：$f(1) = 1$；$f(i) = f(i-1) \cdot i \cdot (2i - 1) \bmod (10^9+7)$。乘法顺序先 $f(i-1)\cdot i$ 取模、再 $\cdot(2i-1)$ 取模，防止溢出：$f < 10^9$、$i \le 500$、$(2i-1) \le 999$，中间量 $< 10^{9+3} \times 10^3 = 10^{15}$，`long long`（上限 $\approx 9.2\times10^{18}$）绰绰有余。
2. **为什么插入位置是 $C(2n, 2)$**：最终序列长 $2n$，新订单占两个下标，**位置集合**（而非相邻空隙）决定序列——同一个旧序列、不同的位置集合给出不同的新序列；也可以数成「$P_n$ 放在 $2n-1$ 个空隙之一、$D_n$ 放在 $P_n$ 之后」，求和同样是 $\sum_{t=1}^{2n-1} t = n(2n-1)$。
3. **闭式 + 逆元版**（备选）：$(2n)! \bmod p$ 用循环连乘，$2^n$ 的逆元用费马小模 $x^{p-2} \bmod p$；结果与递推版完全一致（已对 $n \le 200$ 验证）。多两个易错点（负数取模、溢出），初学不推荐。
4. **取模细节**：每一步乘法后立刻取模；C++ 用 `long long`，Python 大整数天然安全但仍建议每步 `% MOD` 控制规模。
5. **别把「相对顺序」搞错**：插入法保留旧序列元素**彼此之间**的相对顺序，而不是它们的具体下标——位置集合一旦确定，剩余位置从左到右依次填入旧序列即可，这是双射成立的关键。

## 5. 正确性证明

**引理 1（删除保持合法）**：从合法的 $n$ 订单序列中删去 $P_n$ 与 $D_n$，得到的长度 $2(n-1)$ 的序列是合法的 $(n-1)$ 订单序列。

**证明**：删除只影响第 $n$ 笔订单的事件。对 $i < n$，$D_i$ 与 $P_i$ 在新序列中的相对前后关系与原序列相同（都删的是别的事件，不改变剩余元素的次序），故 $D_i \prec P_i$ 依然不成立的方式不存在，即约束全部保持。∎

**引理 2（插入构造合法）**：任取合法的 $(n-1)$ 订单序列 $S$ 与位置对 $1 \le p < q \le 2n$，把 $P_n$ 放在 $S$ 扩充后序列的第 $p$ 位、$D_n$ 放在第 $q$ 位、其余位置依原顺序填入 $S$，得到合法的 $n$ 订单序列。

**证明**：第 $n$ 笔订单满足 $P_n \prec D_n$（$p < q$）；对 $i < n$，$P_i, D_i$ 的相对顺序未被扰动（插入只把它们推开、不交换），合法性保持。∎

**引理 3（计数双射）**：所有「(合法 $(n-1)$ 序列, 位置对 $p<q$)」与所有「合法 $n$ 序列」之间存在双射。

**证明**：由引理 2，「(S, p, q) ↦ 新序列」是从前者到后者的映射；由引理 1，任一合法 $n$ 序列 $T$ 删去 $P_n, D_n$ 得到合法 $S$，记 $P_n, D_n$ 在 $T$ 中的位置为 $(p, q)$（$p < q$ 自动成立），且从 $S$ 与 $(p, q)$ 出发按引理 2 重构恰得到 $T$，故该映射满射且可逆，为双射。位置对 $(p, q)$ 的取法共 $\binom{2n}{2} = n(2n-1)$ 种。∎

**定理（递推）**：$f(1) = 1$，$f(n) = f(n-1) \cdot n(2n-1)$；从而 $f(n) = \dfrac{(2n)!}{2^n}$。

**证明**：由引理 3，合法 $n$ 序列集合被划分为 $f(n-1)$ 个「旧序列」组、每组恰 $n(2n-1)$ 个元素，得递推。展开连乘：$f(n) = \prod_{i\le n} i(2i-1) = n!\,(2n-1)!!$。再由 $(2n)! = (2^n n!)\,(2n-1)!!$（把偶因子 $2,4,\dots,2n$ 与奇因子分开），得 $(2n-1)!! = (2n)!/(2^n n!)$，代入化简即 $f(n) = (2n)!/2^n$。∎

**引理 4（对称性证明闭式）**：在 $(2n)!$ 个全排列中，满足全部 $2^n$ 个约束「$P_i \prec D_i$」的排列恰有 $(2n)!/2^n$ 个。

**证明**：对位置集合 $\{1,\dots,2n\}$ 的每个排列 $\pi$（事件到位置的分配），定义对合 $\sigma_T$：把子集 $T \subseteq \{1..n\}$ 中的每对 $P_i \leftrightarrow D_i$ 互换。$\sigma_T$ 是排列集合上的双射，共 $2^n$ 个。每个 $\sigma_T$ 轨道大小恰为 $2^n$（$T$ 取遍全部子集，且 $\sigma_{T_1} \ne \sigma_{T_2}$ 对不同 $T_1, T_2$ 作用不同），轨道内**恰有一个**排列满足全部 $P_i \prec D_i$（约束彼此独立：对每对 $i$ 各自恰好「一半」的翻转状态满足 $P_i \prec D_i$，即 $T$ 恰为「那些 $\sigma_T$ 交换后违反约束的对」之集）。故满足约束的排列数 $=$ 排列总数 $/ 2^n$。∎

**推论**：递推、闭式 $n!\,(2n-1)!!$、闭式 $(2n)!/2^n$ 三者一致，与 $n = 1\sim5$ 的全排列暴力枚举结果（$1, 6, 90, 2520, 113400$）完全吻合。∎

## 6. 复杂度分析

- **时间**：$O(n)$——一趟连乘，每步常数次模乘；$n = 500$ 时仅 499 次乘法。闭式 + 逆元版为 $O(n + \log p)$，同阶。
- **空间**：$O(1)$——只有当前值 $f$ 与模数。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int countOrders(int n) {
        const long long MOD = 1e9 + 7;
        long long f = 1;                       // f(1) = 1
        for (int i = 2; i <= n; ++i)
            f = f * i % MOD * (2 * i - 1) % MOD;   // f(n) = f(n-1) * n * (2n-1)
        return (int)f;
    }
};
```

闭式 $(2n)!/2^n$ 的取模实现要用**费马小逆元**把除法换成乘法（与递推版已对 $n = 1\sim500$ 全量对照一致）：

```cpp
class Solution {
public:
    int countOrders(int n) {
        const long long MOD = 1e9 + 7;
        long long fact = 1;
        for (int i = 2; i <= 2 * n; ++i) fact = fact * i % MOD;   // (2n)! mod p
        long long pow2 = 1;
        for (int i = 0; i < n; ++i) pow2 = pow2 * 2 % MOD;        // 2^n mod p
        long long inv2n = 1, base = pow2, e = MOD - 2;            // 费马小逆元：x^(p-2)
        while (e > 0) {
            if (e & 1) inv2n = inv2n * base % MOD;
            base = base * base % MOD;
            e >>= 1;
        }
        return (int)(fact * inv2n % MOD);
    }
};
```

> ⚠️ 写取模时最常见的优先级笔误是 `% (long long)1e9 + 7`：`%` 先于 `+` 结合，实际语义是「先取模再加 7」，悄无声息地全盘出错。务必先定义 `const long long MOD = 1e9 + 7;` 再统一 `% MOD`。

### Python

```python
class Solution:
    def countOrders(self, n: int) -> int:
        MOD = 10**9 + 7
        f = 1
        for i in range(2, n + 1):
            f = f * i * (2 * i - 1) % MOD    # f(n) = f(n-1) * n * (2n-1)
        return f
```

Python 大整数不溢出，闭式版可以直接**先精确整除再取模**（$2^n$ 整除 $(2n)!$ 恒成立，两者顺序不可颠倒）：

```python
import math

class Solution:
    def countOrders(self, n: int) -> int:
        return math.factorial(2 * n) // 2**n % (10**9 + 7)
```

> 💡 递推版与闭式版（C++ 逆元版、Python 整除版）均通过官方示例（`1`、`6`、`90`）；$n = 1\sim5$ 与「全排列逐个检查 $P_i \prec D_i$」的暴力枚举对拍结果 $1, 6, 90, 2520, 113400$ 全部吻合；$n \le 200$（Python）与 $n \le 500$（C++）范围内递推与闭式逐一对照一致。

## 8. 边界情况与易错点

1. **$n = 1$**：循环不进，直接返回 $1$；别让 $f(0) = 1$ 的语义（空序列）与「题目 $n \ge 1$」混淆。
2. **每步取模**：C++ 中 `f * i * (2*i-1)` 中间量约 $10^9 \times 500 \times 999 \approx 5\times10^{14}$，虽仍在 `long long` 内，但**连续乘再统一取模**接近极限时容易踩界，标准写法是「乘一个因子、立刻取模」。
3. **`% (long long)1e9 + 7` 优先级陷阱**：`%` 与 `+` 同时出现时先取模后加 7，结果完全错误——本题解第 7 节第二个代码块故意展示了这个真实笔误，务必用 `const long long MOD = 1e9 + 7;` 再 `% MOD`。
4. **逆元存在性**：$\gcd(2^n, 10^9+7) = 1$（模是奇素数），费马小定理保证逆元存在；若模数换成合数且与 2 不互素（如 $998244353$ 的因子）就要小心。
5. **先整除再取模（Python）**：`factorial(2n) // 2**n` 是精确整除（$2^n \mid (2n)!$ 恒成立），之后取模才正确；`% MOD` 放到整除**之前**会得到错误结果。
6. **插入法数的是位置不是空隙**：常见的错误答案是「$2n$ 个空隙放 $P$、$2n$ 个空隙放 $D$ 再减去 $D$ 在前」，边界一堆；「$C(2n,2)$ 个位置对」最干净。
7. **别把 $P_i$ 之间的顺序约束加戏**：不同订单的 $P$ 之间**没有**先后要求，允许任何交错。
