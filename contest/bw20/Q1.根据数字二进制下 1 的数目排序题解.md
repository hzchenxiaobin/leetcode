# LeetCode 根据数字二进制下 1 的数目排序 题解

## 1. 题目概述

- **标题 / 题号**：根据数字二进制下 1 的数目排序（#1356，easy）
- **链接**：https://leetcode.cn/problems/sort-integers-by-the-number-of-1-bits/
- **来源**：LeetCode 第 20 场双周赛 Q1
- **难度**：简单
- **标签**：位运算、数组、计数、排序

**题意**：给定整数数组 `arr`，把元素按其**二进制表示中 1 的个数升序**排序；1 的个数相同的，再按**数值升序**排序。返回排序后的数组。

**约束**：

- $1 \le arr.length \le 500$
- $0 \le arr[i] \le 10^4$

## 2. 示例

**示例 1**

```text
输入：arr = [0,1,2,3,4,5,6,7,8]
输出：[0,1,2,4,8,3,5,6,7]
解释：[0] 有 0 个 1；[1,2,4,8] 各有 1 个 1；[3,5,6] 各有 2 个 1；[7] 有 3 个 1。
```

**示例 2**

```text
输入：arr = [1024,512,256,128,64,32,16,8,4,2,1]
输出：[1,2,4,8,16,32,64,128,256,512,1024]
解释：全部都只有 1 个 1，于是按数值升序。
```

**示例 3**

```text
输入：arr = [10000,10000]
输出：[10000,10000]
```

## 3. 解题思路

### 3.1 暴力思路

对每个数用「逐位右移数 1」的方式计算 1 的个数（$\le 14$ 次），得到二元组 $(\text{1 的个数}, \text{数值})$ 后排序。$n \le 500$、值 $\le 10^4$，任何写法都在时限内——本题考的是**把排序条件翻译成正确的比较键**，以及顺手挑一个漂亮的 popcount 实现方式。

### 3.2 核心观察：排序条件就是双关键字——(popcount, 值)

![排序键：先按1的个数，再按数值](images/bw20_q1_popcount_key.svg)

题面给的序关系是一个**全序**：先比 1 的个数 $c(x) = \operatorname{popcount}(x)$，相等再比 $x$ 本身。因此直接以 $(c(x), x)$ 为排序键调用一次 `sort` 即可，无需真的建桶。把示例 1 的 9 个数按 $(c, x)$ 排开，正好得到输出 $[0,1,2,4,8,3,5,6,7]$。

若想展示桶排序视角：$x \le 10^4 < 2^{14}$，1 的个数只有 $0 \sim 14$ 共 15 种，可以按个数分 15 个桶、桶内排序再拼接——与统一排序殊途同归，但足以说明键空间极小。

### 3.3 算法流程

```text
1. 对每个 x 计算 c(x) = 二进制下 1 的个数
   （__builtin_popcount / x &= x−1 循环 / bin(x).count('1') 均可）
2. 以 (c(x), x) 为键升序排序
3. 返回排序结果
```

### 3.4 示例演算

![示例4走查：键(1的个数,值)的排序](images/bw20_q1_walkthrough.svg)

拿官方示例 4 `[2,3,5,7,11,13,17,19]` 走一遍：8 个数的键依次为 $(1,2),(2,3),(2,5),(3,7),(3,11),(3,13),(2,17),(3,19)$。按字典序排：$(1,2)$ 最小；$(2,3),(2,5),(2,17)$ 次之（同为 2 个 1，按值 $3<5<17$）；最后是 $(3,7),(3,11),(3,13),(3,19)$。得输出 `[2,3,5,17,7,11,13,19]`——注意 17 排在 7 前面，因为**个数优先于数值**，这是最容易看错的地方。

## 4. 算法细节

1. **popcount 的实现选择**：C++17 用 `__builtin_popcount((unsigned)x)`（GCC/Clang 内建，单指令级）；跨平台可写 `while (x) { x &= x - 1; ++cnt; }`——每次消去最低位的 1，循环次数就是 1 的个数。Python 用 `bin(x).count('1')` 最稳（3.10+ 也可 `x.bit_count()`）。
2. **0 的个数是 0**：$0$ 的二进制没有 1，$\operatorname{popcount}(0) = 0$，天然排最前，无需特判。
3. **比较器写法**：C++ 比较器先比 `cnt` 再比 `x`；不要用 `cnt * 100000 + x` 之类的「打包键」——虽然本题 $x \le 10^4$、$cnt \le 14$ 打包可行，但隐含假设一旦数值范围变化就会静默出错，`std::tie`/`pair` 是无风险写法。
4. **重复元素**：键含数值本身，相等的数键完全相同，稳定/不稳定排序结果一致（示例 3 的 `[10000,10000]` 原样保留）。
5. **原地 or 新数组**：C++ 直接 `sort(arr)` 原地排再返回即可；Python 用 `sorted` 返回新列表更符合题面「返回排序后的数组」。

## 5. 正确性证明

**引理 1（键的良定义）**：$K(x) = (\operatorname{popcount}(x), x)$ 定义了非负整数集上的全序：任意 $x \ne y$，$K(x) \ne K(y)$，且任意两个键可比较。

**证明**：$\operatorname{popcount}$ 是非负整数到非负整数的函数；二元组按字典序比较，第一分量（非负整数）可比，相等时第二分量（数本身）必不等且可比较。故 $K$ 是单射（$K(x)=K(y) \Rightarrow x=y$），且任意两键字典序可比较，构成全序。∎

**引理 2（题面要求与键序一致）**：按题面，「$x$ 排在 $y$ 前」当且仅当 $c(x) < c(y)$，或 $c(x) = c(y)$ 且 $x < y$——这正是 $K(x) <_{\text{lex}} K(y)$。

**证明**：逐字翻译题面：第一优先级是 1 的个数的升序（$c$ 严格小者优先，相同则看第二级）；第二优先级是数值升序。字典序定义即此。∎

**定理**：对 $K$ 升序排序的输出是唯一确定的，且满足题面要求的排序。

**证明**：由引理 1 键两两不同，排序结果唯一。由引理 2，该顺序与题面要求的顺序逐对一致，故输出正确。∎

## 6. 复杂度分析

- **时间**：$O(n \log n + nB)$，其中 $B \approx 14$ 是单次 popcount 的成本上限（$x < 2^{14}$）。$n = 500$ 时总操作量不过几千。
- **空间**：$O(n)$——排序缓冲与键数组；原地 `sort` 版为 $O(\log n)$ 递归栈（比较器内联计算 popcount 则免键数组）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> sortByBits(vector<int>& arr) {
        vector<int> a = arr;
        sort(a.begin(), a.end(), [](int x, int y) {
            int cx = __builtin_popcount((unsigned)x), cy = __builtin_popcount((unsigned)y);
            if (cx != cy) return cx < cy;      // 先按 1 的个数升序
            return x < y;                      // 再按数值升序
        });
        return a;
    }
};
```

若不使用内建函数，用「消最低位」手写 popcount（效果等价，已对拍验证）：

```cpp
class Solution {
public:
    int cntBits(int x) {
        int c = 0;
        while (x) { x &= x - 1; ++c; }         // 每次消去最低位的 1
        return c;
    }
    vector<int> sortByBits(vector<int>& arr) {
        vector<int> a = arr;
        sort(a.begin(), a.end(), [this](int x, int y) {
            int cx = cntBits(x), cy = cntBits(y);
            if (cx != cy) return cx < cy;
            return x < y;
        });
        return a;
    }
};
```

### Python

```python
class Solution:
    def sortByBits(self, arr: List[int]) -> List[int]:
        return sorted(arr, key=lambda x: (bin(x).count("1"), x))
```

> 💡 全部实现通过官方 5 组示例（含 `[2,3,5,17,7,11,13,19]` 这个「个数优先」的陷阱示例），并与手写 `x &= x - 1` popcount 的独立实现交叉对拍 2000 组随机数据，全部一致。

## 8. 边界情况与易错点

1. **0 的 popcount**：等于 0，自动排最前；别把 0 当成「1 个 1」处理。
2. **「个数优先于数值」**：17（2 个 1）排在 7（3 个 1）之前，比较器把 `cnt` 放在第一位绝不能颠倒。
3. **负数与有符号右移**：本题 $x \ge 0$ 不踩坑；但若值可负，`__builtin_popcount` 需转 `(unsigned)`，手写右移需用逻辑右移，此习惯值得提前养成。
4. **打包键的隐患**：`key = cnt * 100001 + x` 之类要求 $x < 100001$，题目约束一变即错；`pair`/元组键没有这种暗坑。
5. **返回新数组还是原数组**：C++ 题面允许原地；Python 的 `sorted` 返回新表，`arr.sort()` 原地——两者都可，别在 Python 里 `arr.sort()` 后忘记返回。
6. **稳定性无关紧要**：相同数值的元素彼此不可区分，稳定排序与否不影响输出。
