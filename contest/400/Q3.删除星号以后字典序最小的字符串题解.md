# LeetCode 删除星号以后字典序最小的字符串 题解

## 1. 题目概述

- **标题 / 题号**：删除星号以后字典序最小的字符串（#3170，medium）
- **链接**：https://leetcode.cn/problems/lexicographically-minimum-string-after-removing-stars/
- **来源**：LeetCode 第 400 场周赛 Q3
- **难度**：中等
- **标签**：栈、贪心、哈希表、字符串、堆（优先队列）

**题意**：给定字符串 `s`，只含小写字母和 `*`。只要还存在 `*` 就可执行操作：删除**最左边**的那个 `*`，同时删掉它**左边**一个字典序最小的字符（若最小字符有多个，删其中任意一个）。删除所有 `*` 后，剩余字符按原顺序连接，返回能得到的字典序最小的字符串。

**约束**：

- $1 \le s.length \le 10^5$
- `s` 只含小写英文字母与 `*`
- 输入保证操作可以删除所有的 `*`（即每个 `*` 处理时左侧总有字符可删）

> 💡 **审题关键**：操作的执行顺序没有自由度——**星号必须从左到右逐个消除**；唯一的自由度是「同一个最小字母有多个出现时，删哪一个」。整道题的全部优化空间就浓缩在这一个选择上。

## 2. 示例

**示例 1**

```text
输入：s = "aaba*"
输出："aab"
解释：星号左侧最小字母是 a（下标 0/1/3 各一个）。删最右边的 a（下标 3），保留 "aab"，字典序最小。
```

**示例 2**

```text
输入：s = "abc"
输出："abc"
解释：没有星号，原串即答案。
```

**示例 3**

```text
输入：s = "ab*a"
输出："ba"
解释：星号左侧只有 a(0)、b(1)，最小字母 a 仅一个出现，必须删它。注意：星号右边的 a(3) 不能被这个星号删掉。
```

## 3. 解题思路

### 3.1 暴力思路：每个星号线性扫描左侧（$O(n^2)$ 被卡死）

逐个模拟星号：对每个 `*`，从头扫描其左侧所有**尚未删除**的字符，找出最小字母并删掉其中一个出现，标记删除。最坏 $n/2$ 个星号、每次 $O(n)$ 扫描，总计 $O(n^2) \approx 10^{10}$ 量级，在 $n = 10^5$ 下必然超时。**瓶颈在于「反复在动态前缀中查询最小存活字母并删除」**——需要把存活字符组织成支持高效「查最小 + 删指定出现」的结构。

另一个更朴素的想法是枚举每个星号删哪个出现，但那是组合爆炸，更不可行。

### 3.2 核心观察：删「最小字母的最右出现」

两个观察把问题完全钉死：

**观察 1（删哪个字母是被逼定的）**：第 $t$ 个星号删除的字母 = 它左侧存活字符中的最小字母。由于每次删除只改变存活字符的**多重集**，对星号从左到右归纳可证：**每个星号删除的字母序列是唯一的**——所有合法方案删除/保留的字母多重集完全相同，方案之间只差在「删的是该字母的哪一个出现」（证明见 §5 引理 1）。

**观察 2（同字母删最右的出现）**：设某星号要删字母 $c$，其左侧存活的 $c$ 有两个出现，位置 $i < j$。由于 $c$ 是**存活**字符的最小字母，位置 $i, j$ 之间所有存活字符都 $\ge c$。保留靠前的 $i$（删 $j$）得到的串形如 $X \cdot c \cdot Y \cdot Z$，保留 $j$（删 $i$）得到 $X \cdot Y \cdot c \cdot Z$，其中 $Y$ 中字符均 $\ge c$，可证 $c \cdot Y \le Y \cdot c$（§5 引理 2）——**删靠后的出现永远不亏**。

![核心观察：星号删除左侧最小字母的最右出现](images/clear_stars_greedy_concept.svg)

> 💡 **一句话总结**：字母没得选（必须是最小字母），位置有得选（最右出现）——**每个 `*` 删掉它左侧最小字母的最后一次出现**，这就是完整的贪心策略。

### 3.3 算法流程：26 个「字母桶栈」，一趟扫描

「最右出现」天然对应**栈顶**：为 26 个字母各开一个存下标的栈，从左到右扫描：

- 遇到字母 `x`：把下标压入 `stack[x]`；
- 遇到 `*`：从 `'a'` 到 `'z'` 找第一个非空栈，**弹栈顶**下标并标记删除。

扫描时任何栈里只会出现已扫过的下标（< 当前位置），天然满足「只删星号左侧」；弹栈顶恰好 = 删该字母最右存活出现。最后按原顺序拼接所有未被删除的字母。

![算法流程：字母入桶、星号弹最小非空桶的栈顶](images/clear_stars_stacks_model.svg)

```text
1. stacks[0..25] 初始化为空栈；removed[0..n−1] = false
2. 从左到右扫描 i = 0 … n−1：
   若 s[i] 为字母 x：stacks[x−'a'].push(i)
   若 s[i] == '*'：取最小的使 stacks[c] 非空的 c
                   j = stacks[c].pop()；removed[j] = true
3. 答案 = 所有满足 !removed[i] 且 s[i] != '*' 的 s[i] 按原序拼接
```

## 4. 算法细节

1. **栈里存下标而不是字符**：最终答案要按原顺序拼接，必须记位置；同时「弹栈顶 = 删最右存活出现」正是贪心所需——一举两得。
2. **找最小非空桶**：`*` 处从 `'a'` 到 `'z'` 线性探测第一个非空栈，单次 $O(26)$；总计 $O(26n) \approx 2.6 \times 10^6$ 次基本操作，$n = 10^5$ 下毫无压力。若追求严格线性，可用一个 26 位整数掩码维护「非空桶集合」（桶空清位、压入置位），`lowbit` 一步定位最小非空字母。
3. **删除的表示**：不真的去字符串里「挖」元素——每次弹的都是栈顶，无需随机删除；用 `removed` 布尔数组打标记，最后一趟拼接时跳过被标记与 `*` 的位置即可。
4. **等价实现**：小根堆存 `(字母, −下标)`，`*` 时弹堆顶——堆序最小的元素恰好是「最小字母、同字母最右出现」，$O(n \log n)$；有序集合（`multiset<pair<char,int>>` 排 `begin()`）同理。桶栈版本零比较开销、代码最短，是最优选择。
5. **为什么不能用「单调栈」**：[402. 移掉 K 位数字](https://leetcode.cn/problems/remove-k-digits/) 式单调栈的前提是**任意字符都可删**，才能把每个逆序对削掉；本题每个 `*` 只能删**最小字母**，删除对象受限，单调栈的交换条件不成立——两道题形似而神不似，是很好的对照。

## 5. 正确性证明

**引理 1（删除字母序列唯一）**：设星号位置从左到右为 $p_1 < p_2 < \dots < p_k$。任何合法方案中，第 $t$ 个星号删除的字母仅由 $s$ 决定，与方案无关；从而所有方案保留的字母多重集相同。

**证明**：对 $t$ 归纳。$t = 0$ 平凡。设前 $t-1$ 个星号删除的字母（与方案无关地）为 $c_1, \dots, c_{t-1}$。第 $t$ 个星号删除的字母 = $s[0..p_t)$ 中存活字符的最小字母；因 $p_1 < \dots < p_{t-1} < p_t$，前 $t-1$ 次删除都发生在该前缀内，故存活字母多重集 $= \mathrm{mult}(s[0..p_t)) \setminus \{c_1, \dots, c_{t-1}\}$，由归纳假设它与方案无关，其最小字母——即第 $t$ 次删除的字母——随之确定。∎

**引理 2（前置比较）**：设 $c$ 为字母，$Y$ 是每个字符都 $\ge c$ 的字符串，则 $c \cdot Y \le_{\mathrm{lex}} Y \cdot c$。

**证明**：若 $Y$ 为空，两边相等。设 $Y$ 中第一个 $> c$ 的字符位于下标 $t$（若不存在则 $Y$ 全为 $c$，两边相等）。记 $A = c \cdot Y$，$B = Y \cdot c$。对 $p < t$：$A[0] = B[0] = c$；$p \ge 1$ 时 $A[p] = Y[p-1] = c$，$B[p] = Y[p] = c$，逐位打平。而第 $t$ 位：$A[t] = c < Y[t] = B[t]$（$t = 0$ 时即 $A[0] = c < Y[0] = B[0]$）。故 $A < B$。∎

**定理（贪心最优性）**：每个星号删除其左侧存活最小字母的**最右出现**，所得串在所有合法方案中字典序最小。

**证明**（交换论证）：设 $G$ 为贪心方案。断言：对每个 $t \in [0, k]$，存在**最优**方案 $O_t$，与 $G$ 在前 $t$ 个星号上的删除位置完全一致。$t = 0$ 取任意最优方案 $O_0$ 即可。

归纳步：由 $O_{t-1}$ 构造 $O_t$。由引理 1，第 $t$ 个星号两边删除的字母同为某个 $c$；设 $G$ 删位置 $j$（$c$ 的最右存活出现），$O_{t-1}$ 删位置 $i$。若 $i = j$，取 $O_t = O_{t-1}$；否则 $i < j$（$j$ 是最右），分两种情形：

- **情形一：$O_{t-1}$ 此后永不删 $j$**（$j$ 存活至其输出）。令 $O_t$：第 $t$ 个星号删 $j$，其余星号完全模仿 $O_{t-1}$。由引理 1，两方案每步删除的字母序列相同，任意时刻存活字母多重集相同；且被模仿的删除位置 $p_w \notin \{i, j\}$ 在 $O_t$ 中同样存活、字母同为当步最小字母，故 $O_t$ 合法。比较输出：两者只差「保留 $j$ 处的 $c$」还是「保留 $i$ 处的 $c$」。记输出中位于 $i, j$ 之间的保留字符为 $Y$——它们在第 $t$ 步时存活于星号左侧，故均 $\ge c$——$O_t$ 的输出为 $X \cdot c \cdot Y \cdot Z$，$O_{t-1}$ 的输出为 $X \cdot Y \cdot c \cdot Z$，由引理 2 得 $\mathrm{out}(O_t) \le \mathrm{out}(O_{t-1})$。
- **情形二：$O_{t-1}$ 在其后某星号 $u$（第一个）删 $j$**。令 $O_t$：第 $t$ 个星号删 $j$，星号 $t+1 \dots u-1$ 模仿 $O_{t-1}$，第 $u$ 个星号改删 $i$，之后完全模仿。区间 $[t, u)$ 内两方案存活字母多重集相同（互换的是同字母 $c$ 的 $i, j$），模仿合法；第 $u$ 步 $O_{t-1}$ 删 $j$ 说明当步最小字母 $= \mathrm{letter}(j) = c = \mathrm{letter}(i)$，而 $i$ 在 $O_t$ 中存活，是合法选择。此后两方案存活集合完全相同，输出相等：$\mathrm{out}(O_t) = \mathrm{out}(O_{t-1})$。

两种情形均有 $\mathrm{out}(O_t) \le \mathrm{out}(O_{t-1})$，故 $O_t$ 仍最优。取 $t = k$：$O_k$ 与 $G$ 在所有星号上一致，两方案输出相同，故 $G$ 的输出就是全局最小。∎

## 6. 复杂度分析

- **时间复杂度**：$O(26n)$。每个字符入栈一次 $O(1)$；每个 `*` 从 `'a'` 起探测非空桶至多 26 步；末尾拼接一趟 $O(n)$。$n \le 10^5$ 时约 $2.6 \times 10^6$ 次基本操作，位掩码优化后为 $O(n)$。
- **空间复杂度**：$O(n)$。26 个栈合计至多存 $n$ 个下标，`removed` 数组 $O(n)$；不计输出串。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    string clearStars(string s) {
        int n = s.size();
        vector<vector<int>> stacks(26);        // 每个字母一个「下标栈」
        vector<bool> removed(n, false);
        for (int i = 0; i < n; i++) {
            if (s[i] == '*') {                 // 找最小的非空桶，弹栈顶
                for (int c = 0; c < 26; c++) {
                    if (!stacks[c].empty()) {
                        removed[stacks[c].back()] = true;
                        stacks[c].pop_back();
                        break;
                    }
                }
            } else {
                stacks[s[i] - 'a'].push_back(i); // 字母入桶
            }
        }
        string ans;
        for (int i = 0; i < n; i++)
            if (s[i] != '*' && !removed[i]) ans += s[i];
        return ans;
    }
};
```

### Python

```python
class Solution:
    def clearStars(self, s: str) -> str:
        n = len(s)
        stacks = [[] for _ in range(26)]      # 每个字母一个「下标栈」
        removed = [False] * n
        for i, ch in enumerate(s):
            if ch == '*':                      # 找最小的非空桶，弹栈顶
                for c in range(26):
                    if stacks[c]:
                        removed[stacks[c].pop()] = True
                        break
            else:
                stacks[ord(ch) - 97].append(i) # 字母入桶
        return ''.join(s[i] for i in range(n)
                       if s[i] != '*' and not removed[i])
```

## 8. 边界情况与易错点

1. **删「最左」出现是错的**：`"aaba*"` 删最左的 `a` 得 `"aba"`，删最右得 `"aab"`，而 `"aab" < "aba"`。同字母必须删**最右**存活出现——正是弹栈顶的原因。
2. **懒删除「最后统一丢掉最靠右的若干个最小字母」是错的**：`"ab*a"` 的答案是 `"ba"` 而非 `"ab"`——星号只能删**左侧**字符，`a(3)` 在星号右边，不能被它删。逐星号在线弹栈（栈中天然只有已扫过的下标）才正确。
3. **输出必须过滤 `*`**：星号自身随操作消失，拼接时记得跳过 `s[i] == '*'`。
4. **答案可以是空串**：`"a*"` → `""`；`"abc***"` 三个星号依次删 `a`、`b`、`c` → `""`。
5. **被删字符可能压入晚于之前的星号**：`"cbca**b*"` 中 `b(6)` 在两个星号之后才压入，却被更右的 `*(7)` 删除——桶栈状态是动态的，不能在扫描开始前「预定」全部删除对象。
6. **连续星号**：如 `"abc***"`，桶从 `'a'` 开始被逐个清空，验证了「从 `'a'` 到 `'z'` 找非空桶」的顺序正确。
7. **无需判空防御**：题目保证每个 `*` 左侧有字符可删，探测循环必命中非空桶；防御性地判「未删任何字符」也不影响正确性。
