# LeetCode 候诊室中的最少椅子数 题解

## 1. 题目概述

- **标题 / 题号**：候诊室中的最少椅子数（#3168，easy）
- **链接**：https://leetcode.cn/problems/minimum-number-of-chairs-in-a-waiting-room/
- **来源**：LeetCode 第 400 场周赛 Q1
- **难度**：简单
- **标签**：模拟、字符串、计数、前缀和

**题意**：给定一个仅含 `'E'` 和 `'L'` 的字符串 `s`，按时间顺序模拟候诊室中顾客的进出：`s[i] == 'E'` 表示第 `i` 秒有一位顾客进入并占用一把椅子，`s[i] == 'L'` 表示有一位顾客离开并释放一把椅子。候诊室初始为空，求能让每位进入的顾客都有椅子坐的**最少椅子数**。

**约束**：

- `1 <= s.length <= 50`
- `s` 仅由字母 `'E'` 和 `'L'` 组成
- `s` 表示一个有效的进出序列（任意时刻离开人数不超过在场人数，前缀人数非负）

## 2. 示例

**示例 1**

```text
输入：s = "EEEEEEE"
输出：7
解释：每秒都有顾客进入、无人离开，7 人同时在场的时刻 → 至少需要 7 把椅子。
```

**示例 2**

```text
输入：s = "ELELEEL"
输出：2
解释：秒 5 时第 2 位顾客进入，与秒 4 进入的顾客同时在场的时刻 → 2 人 → 需要 2 把椅子。
```

**示例 3**

```text
输入：s = "ELEELEELLL"
输出：3
解释：秒 6 时第 3 位顾客进入，此刻 3 人同时在场的时刻 → 需要 3 把椅子；随后 3 次 'L' 使人数归零。
```

## 3. 解题思路

### 3.1 签到切入：椅子何时被占用？

签到题最快的切入方式是抓住一句话——**同一时刻在场的顾客必须一人一把椅子**。椅子是否够用，只取决于"最多有多少人**同时**在场"：

- 先离开的顾客释放的椅子，可以被后进入的顾客复用；
- 因此唯一要保证的是：**最大同时在场人数** $M$ 不超过椅子数 $k$。

朴素做法：枚举椅子数 $k = 0, 1, \dots, n$，对每个 $k$ 模拟一遍 `s` 检查是否够坐。由于 $n \leq 50$，$O(n^2)$ 也能过，但完全没必要。

### 3.2 核心观察：一次遍历 + 峰值统计

把 `'E'` 看作 $+1$、`'L'` 看作 $-1$，第 $i$ 秒处理完后的在场人数就是前缀和 $\mathrm{cur}_i$。答案就是：

$$\text{ans} = \max_{0 \leq i < n} \mathrm{cur}_i$$

![核心观察：E=+1、L=−1，答案为在场人数曲线的峰值](images/chairs_prefix_sum_concept.svg)

> 💡 **一句话总结**：椅子是"可复用资源"，需求峰值决定库存下限——答案就是人数前缀和的最大值。

### 3.3 算法流程

一次遍历，维护两个变量：当前在场人数 `cur` 与历史峰值 `ans`。

![一次遍历模拟算法流程](images/chairs_simulation_flow.svg)

```text
1. cur = 0, ans = 0
2. 依次扫描每个字符 c：
   c == 'E'：cur++，并更新 ans = max(ans, cur)
   c == 'L'：cur--
3. 扫描结束，返回 ans
```

## 4. 算法细节

1. **两个变量的分工**：`cur` 表示当前在场人数，`ans` 记录历史峰值。`ans` 单调不减，遍历结束时的 `ans` 即所求。
2. **更新时机**：`'E'` 后 `cur` 增大、可能刷新峰值，需要 `ans = max(ans, cur)`；`'L'` 后 `cur` 减小、峰值不可能变大，**无需更新** `ans`。实现上可以先 `++cur` 再取 `max`。
3. **无需显式模拟椅子编号**：题目只问数量，"谁坐哪把椅子"不重要——进入的人坐任意一把空椅即可（正确性见 §5）。
4. **有效序列的性质**：题面保证 `s` 是有效进出序列，因此任意前缀 `'E'` 的个数不少于 `'L'` 的个数，`cur` 不会为负，无需特判下溢。

## 5. 正确性证明

**引理 1（下界）**：设 $M = \max_i \mathrm{cur}_i$ 为整个过程中最大同时在场人数，则任何合法方案的椅子数 $k \geq M$。

**证明**：设在第 $t$ 秒后 $\mathrm{cur}_t = M$。这 $M$ 位顾客此刻都在场、每人占用一把**不同**的椅子（一把椅子同一时刻只能坐一人），故至少需要 $M$ 把椅子。若 $k < M$，第 $t$ 秒必有顾客无椅可坐，矛盾。∎

**引理 2（上界 / 充分性）**：$k = M$ 把椅子一定够用。

**证明**：采用贪心分配——每位进入的顾客坐任意一把空椅，离开时释放该椅子。由定义 $\mathrm{cur}_i \leq M$ 对所有 $i$ 成立，故任意时刻空椅数 $= M - \mathrm{cur}_i \geq 0$，每位进入者总有空椅可坐，不会出现无椅可坐的情况。∎

**定理**：最少椅子数恰为 $\max_i \mathrm{cur}_i$，即算法返回的 `ans`。

**证明**：由引理 1，$M$ 是必要下界；由引理 2，$M$ 把椅子可行。故最优解为 $M$，与一次遍历维护的 `ans = max(ans, cur)` 一致。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。单次扫描字符串，每个字符 $O(1)$ 处理（$n \leq 50$，远低于任何限制）。
- **空间复杂度**：$O(1)$。只使用 `cur`、`ans` 两个整数变量。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int minimumChairs(string s) {
        int cur = 0, ans = 0;
        for (char c : s) {
            if (c == 'E') ans = max(ans, ++cur);
            else --cur;
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def minimumChairs(self, s: str) -> int:
        cur = ans = 0
        for c in s:
            if c == 'E':
                cur += 1
                ans = max(ans, cur)
            else:
                cur -= 1
        return ans
```

## 8. 边界情况与易错点

1. **全 `'E'`**：`cur` 一路涨到 `n`，答案为 `n`（示例 1）。不要误以为椅子数与总进入人数无关——峰值就是总数。
2. **`ans` 必须在 `'E'` 之后更新**：先 `cur++` 再 `ans = max(ans, cur)`，顺序写反会漏掉刚进入的顾客。
3. **离开不需要动 `ans`**：`'L'` 只做 `cur--`；`ans` 是历史峰值，不随当前人数回落。
4. **`cur` 不会为负**：题面保证有效序列；即便如此，`ans` 初始化为 0 也保证结果非负。
5. **无需栈或队列**：本题与括号匹配同构（`'E'` ↔ `'('`、`'L'` ↔ `')'`），不需要配对追踪，一个计数器足矣——这正是签到题的最短路径。
