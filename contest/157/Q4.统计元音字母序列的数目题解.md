# LeetCode 统计元音字母序列的数目 题解

## 1. 题目概述

- **标题 / 题号**：统计元音字母序列的数目（#1220，hard）
- **链接**：https://leetcode.cn/problems/count-vowels-permutation/
- **来源**：LeetCode 第 157 场周赛 Q4
- **难度**：困难
- **标签**：动态规划

**题意**：统计长度为 $n$ 的字符串数目，字符串的每个字符都取自 5 个小写元音 $a,e,i,o,u$，且相邻两位必须满足：

- $a$ 后面只能跟 $e$；
- $e$ 后面只能跟 $a$ 或 $i$；
- $i$ 后面**不能**还是 $i$（即可以跟 $a,e,o,u$）；
- $o$ 后面只能跟 $i$ 或 $u$；
- $u$ 后面只能跟 $a$。

答案对 $10^9+7$ 取模。

**约束**：

- $1 \le n \le 2 \times 10^4$
- 字符集固定为 5 个元音，转移规则与位置无关

## 2. 示例

**示例 1**

```text
输入：n = 1
输出：5
解释：所有合法字符串为 "a"、"e"、"i"、"o"、"u"。
```

**示例 2**

```text
输入：n = 2
输出：10
解释："ae"、"ea"、"ei"、"ia"、"ie"、"io"、"iu"、"oi"、"ou"、"ua"。
```

**示例 3**

```text
输入：n = 5
输出：68
```

## 3. 解题思路

### 3.1 暴力思路

从空串出发 DFS，每步枚举当前末位允许的所有后继，走到长度 $n$ 时计数 +1。分支最多 4 个（末位为 $i$ 时），总搜索量 $O(4^n)$；$n = 2\times10^4$ 时天文数字，**不可行**。

不过暴力里藏着一个信号：状态其实只有「当前长度 + 当前末位」两维，共 $5n$ 个——大量分支**共享同一后果**。只要末位相同、剩余长度相同，后面能接的字符串数目完全一样，与前面具体怎么排无关。这正是 DP 的入口。

### 3.2 核心观察：5 节点有向图上的路径计数

把 5 个元音看成 5 个节点，「$x$ 后面可以接 $y$」看成一条有向边 $x \to y$，题目就变成：

> 在这张固定的小图上，数长度为 $n$ 的**路径条数**（起点任选）。

![后继规则：5 节点有向图](images/wc157_q4_transition_graph.svg)

图的出度分布很不均匀：$i$ 有 4 条出边（唯一不能接自己），$e$、$o$ 各 2 条，$a$、$u$ 各 1 条。长度 1 的路径有 5 条；长度 2 的路径恰好 10 条，与示例 2 枚举出的 10 个字符串一一对应。

更要紧的是这张图满足**无后效性**：下一步怎么走只看当前停在哪个节点，与之前走过的路径无关。所以可以按长度逐层推进，每层只需记住停在 5 个节点上各有多少条路径。

### 3.3 状态定义与反向转移

设 $dp_k(v)$ 为「长度 $k$、末位恰为元音 $v$」的合法字符串数目，$k = 1,2,\dots,n$，$v \in \{a,e,i,o,u\}$。初值

$$dp_1(a) = dp_1(e) = dp_1(i) = dp_1(o) = dp_1(u) = 1$$

转移时**反向汇总**比正向分发更省事——问「谁能接在我前面」，而不是「我能接谁」：

$$
\begin{aligned}
dp_k(a) &= dp_{k-1}(e) + dp_{k-1}(i) + dp_{k-1}(u)\\
dp_k(e) &= dp_{k-1}(a) + dp_{k-1}(i)\\
dp_k(i) &= dp_{k-1}(e) + dp_{k-1}(o)\\
dp_k(o) &= dp_{k-1}(i)\\
dp_k(u) &= dp_{k-1}(i) + dp_{k-1}(o)
\end{aligned}
$$

这 5 行正是图上 5 个节点的**入边**。若坚持正向视角，把每个 $v$ 的计数加给它的所有后继，结果完全等价，只是代码要 5 次分发、写起来更啰嗦。

![反向汇总：dp_k 由上一层能接自己的末位求和](images/wc157_q4_dp_flow.svg)

因为第 $k$ 层只读第 $k-1$ 层，可以用**滚动变量**把空间压到 $O(1)$：只留 5 个变量，每轮用旧值算出 5 个新值再整体覆盖。最终答案

$$\text{ans} = \Bigl(\sum_{v} dp_n(v)\Bigr) \bmod (10^9+7)$$

### 3.4 示例演算

![n = 1…5 的五状态走查表](images/wc157_q4_walkthrough.svg)

第 4 层得到 $(11,9,7,3,5)$，据此算第 5 层：

- $dp_5(a) = 9 + 7 + 5 = 21$
- $dp_5(e) = 11 + 7 = 18$
- $dp_5(i) = 9 + 3 = 12$
- $dp_5(o) = 7$
- $dp_5(u) = 7 + 3 = 10$

合计 $21 + 18 + 12 + 7 + 10 = 68$，与示例 3 的 $n=5$ 输出吻合；前两层 $5$、$10$ 分别对上示例 1、2，第 3、4 层的 $19$、$35$ 则是表中新算出的中间值。

## 4. 算法细节

1. **下标映射**：把 $a,e,i,o,u$ 对应到 $0 \sim 4$，或直接用 5 个具名变量。具名变量最直观，也便于和转移式逐行对照。
2. **循环范围**：初值是 $k=1$ 的五个 1，循环从 $k=2$ 跑到 $k=n$，共 $n-1$ 轮；$n=1$ 时不进循环，直接对所有初值求和得 5。
3. **必须并行更新**：C++ 写成 `a = e + i + u; e = a + i;` 是错的——第二行读到的是已被覆盖的 `a`。要先算 5 个临时值再一起赋值；Python 的元组赋值右值先整体求值，天然安全。
4. **取模时机**：每轮每个状态都取模。$3 \times (10^9+6) \approx 3\times10^9$ 已超出 32 位有符号整数上限 $2.1\times10^9$，C++ 的累加与求和都要用 `long long`，最后才转 `int`。
5. **只有加法**：全部转移都是非负整数相加，不会出现取模后的负数，也无需 `+MOD` 修正；但末次求和后仍要再取一次模。
6. **空间压缩**：二维表 `dp[k][5]` 需要 $O(n)$ 空间，滚动后只要 5 个变量；二者结果相同，滚动版还更缓存友好。

## 5. 正确性证明

**引理 1（无后效性）**：设 $s,t$ 是两个长度相同、末位相同的合法串，则对任意字母序列 $c_1c_2\cdots c_m$，$s$ 拼接该序列合法当且仅当 $t$ 拼接该序列合法。

**证明**：规则只约束相邻两位，且约束条件只取决于前一位的具体字母，而不取决于更早的字符。$s$ 与 $t$ 末位相同，故 $c_1$ 能否接在其后由同一个末位决定；此后每一步只看「当前末位」，而这一步的末位由 $c_1,\dots,c_j$ 唯一确定，与 $s,t$ 无关。逐位归纳即得。∎

**引理 2（转移方程正确）**：对 $k \ge 2$ 及每个元音 $v$，成立 $dp_k(v) = \sum_{u \in P(v)} dp_{k-1}(u)$，其中 $P(v)$ 是「后面能接 $v$」的元音集合：$P(a)=\{e,i,u\}$，$P(e)=\{a,i\}$，$P(i)=\{e,o\}$，$P(o)=\{i\}$，$P(u)=\{i,o\}$。

**证明**：把全体「长度 $k$、末位为 $v$」的合法串按倒数第二位 $u$ 分类。由规则，只有 $u \in P(v)$ 的串才有资格出现在某一类里，故 $u \notin P(v)$ 的类为空；反过来任取 $u \in P(v)$，取任一长度 $k-1$、末位为 $u$ 的合法串，在其后接 $v$ 得到的串仍合法（引理 1），故该类恰好有 $dp_{k-1}(u)$ 个元素。各类按倒数第二位互不相交、并集为全体，求和即得方程。∎

**定理**：算法返回值等于满足规则的长度为 $n$ 的字符串数目模 $10^9+7$ 的结果。

**证明**：$n=1$ 时五个状态各计 1，覆盖且仅覆盖 $a,e,i,o,u$ 五个串，正确。设 $dp_{k-1}$ 对每个末位都等于对应串数，则由引理 2 得 $dp_k$ 亦然，归纳成立。答案对 5 个末位求和，按末位分类不重不漏，故等于合法串总数。滚动实现中，每轮新值只依赖旧值且在覆盖前已全部算出（细节 3），与二维递推等价；取模是环同态，逐轮取模与最后取模同余，结果正确。∎

## 6. 复杂度分析

- **时间**：$O(n)$。共 $n-1$ 轮，每轮固定 5 次加法 + 5 次取模，与数据和字符集大小无关的常数开销；$n=2\times10^4$ 时不到 $10^5$ 次基本运算。
- **空间**：$O(1)$。仅需 5 个状态计数（C++ 另有 5 个 `long long` 临时变量），不随 $n$ 增长。若保留整张表则为 $O(n)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int countVowelPermutation(int n) {
        const long long MOD = 1000000007LL;
        // 长度 1：五种单字符串各 1 种
        long long a = 1, e = 1, i = 1, o = 1, u = 1;
        for (int k = 2; k <= n; ++k) {
            long long na = (e + i + u) % MOD;  // 能接 a 的前驱：e, i, u
            long long ne = (a + i) % MOD;      // 能接 e 的前驱：a, i
            long long ni = (e + o) % MOD;      // 能接 i 的前驱：e, o
            long long no = i % MOD;            // 能接 o 的前驱：i
            long long nu = (i + o) % MOD;      // 能接 u 的前驱：i, o
            a = na; e = ne; i = ni; o = no; u = nu;
        }
        return (int)((a + e + i + o + u) % MOD);
    }
};
```

### Python

```python
class Solution:
    def countVowelPermutation(self, n: int) -> int:
        MOD = 10 ** 9 + 7
        a = e = i = o = u = 1          # 长度 1 时五个状态各 1 种
        for _ in range(n - 1):
            a, e, i, o, u = (
                (e + i + u) % MOD,     # 末位 a：来自 e / i / u
                (a + i) % MOD,         # 末位 e：来自 a / i
                (e + o) % MOD,         # 末位 i：来自 e / o
                i,                     # 末位 o：只来自 i
                (i + o) % MOD,         # 末位 u：来自 i / o
            )
        return (a + e + i + o + u) % MOD
```

## 8. 边界情况与易错点

1. **$n=1$**：不进循环，返回初值之和 5。若把初值写成 0、再「跑 $n$ 轮」，会返回 0。
2. **串行赋值污染**：C++ 里 `a = e + i + u; e = a + i;` 用到了新的 `a`，必须借助临时变量；这是本题最高频的 WA。
3. **`int` 溢出**：三个接近 $10^9$ 的数相加约 $3\times10^9 > 2^{31}-1$，累加与最终求和都要 `long long`，否则 UB。
4. **转移方向写反**：$a$ 出度 1、入度 3，$i$ 出度 4、入度 2，正向与反向的系数完全不同。把入边写成出边后，$n=2$ 的小表会变成 $(2,1,3,1,1)$、合计 8，示例 2 立刻判错；正确的小表是 $(3,2,2,1,2)$、合计 10。
5. **漏掉「$i$ 不能接 $i$」**：$P(i)$ 必须是 $\{e,o\}$。若顺手写成 $\{e,o,i\}$，$n=2$ 会得 11（应为 10）、$n=5$ 会得 138（应为 68）；反之漏掉 $o$ 写成 $\{e,i\}$ 则会少算。
6. **忘记逐轮取模**：$n=2\times10^4$ 时计数指数级膨胀，只在最后取模早已溢出；每轮都必须取模，末次求和后补一次模。
