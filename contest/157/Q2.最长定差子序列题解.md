# LeetCode 最长定差子序列 题解

## 1. 题目概述

- **标题 / 题号**：最长定差子序列（#1218，medium）
- **链接**：https://leetcode.cn/problems/longest-arithmetic-subsequence-of-given-difference/
- **来源**：LeetCode 第 157 场周赛 Q2
- **难度**：中等
- **标签**：数组、哈希表、动态规划

**题意**：给定整数数组 `arr` 与整数 `difference`，求一个最长的**子序列**（保持原相对顺序，可以跳过任意多个元素），使得子序列中**任意相邻两项之差都等于** `difference`，返回这个长度的最大值。

**约束**：

- $1 \le \text{arr.length} \le 10^5$
- $-10^4 \le \text{arr}[i],\ \text{difference} \le 10^4$

## 2. 示例

**示例 1**

```text
输入：arr = [1,2,3,4], difference = 1
输出：4
解释：最长的等差子序列是 [1,2,3,4]，相邻差都是 1，长度 4。
```

**示例 2**

```text
输入：arr = [1,3,5,7], difference = 1
输出：1
解释：相邻两数之差都是 2 而不是 1，任何两项都不能拼接，
      只能退化成单个元素，答案为 1。
```

**示例 3**

```text
输入：arr = [1,5,7,8,5,3,4,2,1], difference = -2
输出：4
解释：最长等差子序列是 [7,5,3,1]，对应下标 2、4、5、8，
      相邻差依次为 −2、−2、−2（数字在下降，差为负）。
```

## 3. 解题思路

### 3.1 暴力思路

**做法一**：枚举所有子序列（$2^n$ 个），逐一检查相邻差是否等于 `difference`，复杂度 $O(n \cdot 2^n)$。

**做法二**：线性 DP，令 $dp[i]$ 为以第 $i$ 个元素结尾的最长合法长度，转移时枚举所有前驱下标 $j < i$ 且 $\text{arr}[j] = \text{arr}[i] - d$（记 $d = \text{difference}$）：

$$dp[i] = 1 + \max_{j < i,\ \text{arr}[j] = \text{arr}[i] - d} dp[j]$$

最坏情况 $O(n^2)$，$n = 10^5$ 时是 $10^{10}$ 次比较，必然超时。**瓶颈不在转移式子，而在「为每个 $i$ 重新扫一遍前面所有下标」**。

### 3.2 核心观察：差值固定，前驱由数值唯一确定

![dp 状态按数值索引](images/wc157_q2_dp_state.svg)

观察转移条件：前驱的**数值**被完全钉死了。若子序列的最后一项是 $a$，那么倒数第二项只可能是 $a - \text{difference}$，不可能是别的数，也与它出现在哪个下标无关。

于是把状态从「以下标结尾」换成「以**数值**结尾」：

$$dp[x] = \text{已扫描前缀中，以数值 } x \text{ 结尾的最长定差子序列长度}$$

那么遇到 $a$ 时只有一条转移：

$$dp[a] = dp[a - \text{difference}] + 1$$

（查不到 $a - \text{difference}$ 时视作 $0$，于是 $dp[a] = 1$，$a$ 自成长度为 1 的链。）因为状态按**值**索引，用哈希表可以在均摊 $O(1)$ 内找到前驱的答案，整体从 $O(n^2)$ 降到 $O(n)$。

> 💡 一句话：**定差让「枚举前驱」退化成「查一个键」**，哈希表把这次查找变成常数时间。

### 3.3 算法流程 / 状态转移

![算法流程图](images/wc157_q2_algorithm_flow.svg)

1. 建一个空哈希表 `dp`，`best = 0`；
2. 按原顺序遍历 `a = arr[i]`：
   - 查 `prev = dp[a - difference]`，不存在记 0；
   - `cur = prev + 1`；
   - 写回 `dp[a] = cur`，并 `best = max(best, cur)`；
3. 遍历结束返回 `best`。

> ⚠️ **先查后写**：一次迭代只写一次 `dp[a]`。当 $\text{difference} = 0$ 时 $a - \text{difference} = a$，先查到的必须是「上一次出现」的旧值，才能正确地把相同数值接成一条链（等价于统计出现次数）。若先写后查，这一步就会取到自己刚写进去的值，链会凭空变长。

### 3.4 示例演算

![示例 3 走查](images/wc157_q2_walkthrough.svg)

以示例 3（`arr = [1,5,7,8,5,3,4,2,1]`，`difference = -2`）为例，前驱是 $a - (-2) = a + 2$：

| $i$ | $a$ | 查 $a+2$ | $dp[a+2]$ | $dp[a]$ 更新为 | `best` |
|-----|-----|-----------|-----------|----------------|--------|
| 0 | 1 | 3 | 0 | 1 | 1 |
| 1 | 5 | 7 | 0 | 1 | 1 |
| 2 | 7 | 9 | 0 | 1 | 1 |
| 3 | 8 | 10 | 0 | 1 | 1 |
| 4 | 5 | 7 | 1 | 2 | 2 |
| 5 | 3 | 5 | 2 | 3 | 3 |
| 6 | 4 | 6 | 0 | 1 | 3 |
| 7 | 2 | 4 | 1 | 2 | 3 |
| 8 | 1 | 3 | 3 | 4 | 4 |

第 4 行把 5 接到 7 后面（$dp[5] = dp[7] + 1 = 2$），第 5 行把 3 接到 5 后面（$dp[3] = dp[5] + 1 = 3$），第 8 行把 1 接到 3 后面（$dp[1] = dp[3] + 1 = 4$），最终返回 4。注意 `dp[1]` 原本是 1，这里被覆盖成 4——值变大了，这正是下一节要证明的「覆盖安全」。

## 4. 算法细节

1. **状态键是数值而不是下标**：这是把 $O(n^2)$ 压到 $O(n)$ 的唯一改动。写下 `dp[x]` 时请时刻提醒自己「x 是值」，否则容易误写成 `dp[i]` 再去枚举前驱。
2. **每个元素一次查询、一次写入**：`dp[a]` 直接覆盖，不需要 `max`（引理 2 保证覆盖值不会更小）；如果为了心安写成 $dp[a] = \max(dp[a],\ \text{cur})$ 也完全等价，只是多一次比较。
3. **答案在循环内维护**：`best` 取所有 `dp[a]` 的最大值；也可以在结束后返回 `max(dp.values())`，但**不能**返回 `dp[arr[-1]]`——最长链未必以最后一个元素结尾。例：`arr = [1,2,0]`、`difference = 1`，答案是 2，而 $dp[arr[-1]] = dp[0] = 1$。
4. **`difference` 可以为负**：前驱是 $a - \text{difference}$，当 `difference = -2` 时它是 $a+2$；不要顺手写成 $a + \text{difference}$。代码里永远只用 `a - difference`，符号交给减法处理。
5. **容器选型**：C++ 用 `unordered_map<int,int>` 并 `reserve(2n)` 抑制 rehash；查询键 $a - \text{difference}$ 落在 $[-2\times10^4, 2\times10^4]$、写入键 $a$ 落在 $[-10^4, 10^4]$，`int` 足够，不必上 `long long`。用 `map`（红黑树）会把复杂度抬到 $O(n\log n)$，纯属浪费。
6. **值域小时可以换数组**：由约束 $a - \text{difference} \in [-2\times10^4, 2\times10^4]$，开一个 $40001$ 长的 `int` 数组、整体偏移 $20000$ 即可，`dp[a - difference + 20000]` 就是查找，常数比哈希表更小，空间是固定的 $O(4\times10^4)$。
7. **不要排序、不要离散化**：子序列的顺序约束决定了必须按原顺序扫描；排序会直接改变可选的子序列集合。离散化虽然不影响正确性，但多一次 $O(n\log n)$ 且毫无必要。
8. **只有求具体序列时才需要记录前驱**：若题目要求返回子序列本身，需要额外的 `parent[a]`，且覆盖 `dp[a]` 时同步覆盖 `parent[a]`；本题只要长度，保持一个标量即可。

## 5. 正确性证明

记 $f_i(x)$ 为**只使用前缀** $\text{arr}[0..i]$、以数值 $x$ 结尾的最长定差子序列长度（不存在这样的子序列时记为 $0$），$d = \text{difference}$。

**引理 1（转移方程与单调性）**：$f_i(x) \ge f_{i-1}(x)$ 对一切 $x$ 成立；且当 $\text{arr}[i] = x$ 时

$$f_i(x) = \max\bigl(f_{i-1}(x),\ f_{i-1}(x - d) + 1\bigr)$$

当 $\text{arr}[i] \ne x$ 时 $f_i(x) = f_{i-1}(x)$。

**证明**：前缀变长只会让可选子序列集合变大，故 $f$ 关于 $i$ 单调不减。设 $\text{arr}[i] = x$。一方面，任何在 $f_{i-1}$ 中已经合法的、以 $x$ 结尾的链仍然合法，故 $f_i(x) \ge f_{i-1}(x)$。另一方面，考察 $f_i(x)$ 对应的最优链：若它不含下标 $i$，长度不超过 $f_{i-1}(x)$；若它含下标 $i$，由于 $i$ 是前缀末尾、链中不可能有更靠后的元素，$i$ 必是链尾，链长若为 1 则不超过 $f_{i-1}(x - d) + 1$（后者至少为 1），链长若 $L \ge 2$ 则倒数第二项必须是 $x - d$ 且来自前缀 $i-1$，故 $L - 1 \le f_{i-1}(x - d)$，即 $L \le f_{i-1}(x - d) + 1$。所以 $f_i(x) \le \max(f_{i-1}(x), f_{i-1}(x - d) + 1)$。反之，取前缀 $i-1$ 中以 $x - d$ 结尾的最优链再接上 $\text{arr}[i] = x$，得到长度 $f_{i-1}(x - d) + 1$ 的合法链，故等号成立。$\text{arr}[i] \ne x$ 时任何以 $x$ 结尾的子序列都用不到下标 $i$，$f_i(x) = f_{i-1}(x)$。∎

**引理 2（覆盖安全）**：对任意 $i \ge 1$ 与任意 $x$，有 $f_{i-1}(x) \le f_{i-1}(x - d) + 1$。

**证明**：若 $x$ 在 $f_{i-1}$ 中无合法链，左边为 0，结论显然。否则取一条长度 $L = f_{i-1}(x)$ 的链，设其最后一项 $x$ 落在下标 $j \le i-1$。若 $L = 1$，则 $L \le f_{i-1}(x-d) + 1$ 显然成立。若 $L \ge 2$，该链去掉 $x$ 后是一条长度 $L - 1$、以 $x - d$ 结尾、全部落在前缀 $j-1$ 内的合法链，故 $L - 1 \le f_{j-1}(x - d) \le f_{i-1}(x - d)$（引理 1 的单调性），即 $L \le f_{i-1}(x - d) + 1$。∎

**引理 3（扫描不变量）**：处理完前 $i$ 个元素后，哈希表满足 $dp[y] = f_i(y)$ 对所有出现过或查询过的 $y$ 成立（未出现的 $y$ 按 0 处理）。

**证明**：对 $i$ 归纳。$i = 0$ 时表为空，$f_0 \equiv 0$，成立。设处理完前 $i-1$ 个元素后成立，记 $x = \text{arr}[i]$。代码把 `dp[x - d]` 的值（即 $f_{i-1}(x-d)$）加一记作 `cur` 并写入 `dp[x]`。由引理 1、引理 2，

$$\text{cur} = f_{i-1}(x-d) + 1 = \max\bigl(f_{i-1}(x),\ f_{i-1}(x-d) + 1\bigr) = f_i(x)$$

故 `dp[x]` 的更新结果恰为 $f_i(x)$；对 $y \ne x$，代码不改动 `dp[y]`，而引理 1 给出 $f_i(y) = f_{i-1}(y)$，不变式保持。∎

**定理**：算法返回的 `best` 等于整个数组上最长定差子序列的长度。

**证明**：由引理 3，遍历结束时 $dp[y] = f_n(y)$ 对每个出现过的 $y$ 成立。`best` 是每次更新中 `cur`（即 $dp[x]$）的最大值，即 $\max_y f_n(y)$。任一合法子序列都以某个数值 $y$ 结尾，其长度不超过 $f_n(y)$，故最长长度恰为 $\max_y f_n(y)$；又 $n \ge 1$，至少存在长度 1 的链，故 `best` 与真实答案相等。∎

## 6. 复杂度分析

- **时间**：期望 $O(n)$。每个元素做一次哈希查找与一次哈希写入，均摊 $O(1)$；$n = 10^5$ 时约 $2\times10^5$ 次操作。严格意义上哈希表最坏情况是 $O(n^2)$（大量键碰撞时），但对本题的整数键不会实际发生；改用第 4 节第 6 条的数组实现后是**确定性** $O(n)$。
- **空间**：$O(m)$，其中 $m$ 是不同取值的个数，由于 $\text{arr}[i] \in [-10^4, 10^4]$，有 $m \le \min(n,\ 20001)$。数组实现固定 $O(4\times 10^4)$，两者在同一量级，远小于 $n$ 的上界。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <unordered_map>
#include <algorithm>
using namespace std;

class Solution {
public:
    int longestSubsequence(vector<int>& arr, int difference) {
        unordered_map<int, int> dp;
        dp.reserve(arr.size() * 2 + 1);          // 预留桶数，避免反复 rehash
        int best = 0;
        for (int a : arr) {
            auto it = dp.find(a - difference);
            int cur = (it == dp.end() ? 0 : it->second) + 1;
            dp[a] = cur;                         // 覆盖是安全的：引理 2
            best = max(best, cur);
        }
        return best;
    }
};
```

### Python

```python
from typing import List


class Solution:
    def longestSubsequence(self, arr: List[int], difference: int) -> int:
        dp = {}
        best = 0
        for a in arr:
            cur = dp.get(a - difference, 0) + 1   # 先查：difference = 0 时也正确
            dp[a] = cur                           # 后写：覆盖为更大的链长
            best = max(best, cur)
        return best
```

## 8. 边界情况与易错点

1. **`difference = 0`**：此时前驱就是 $a$ 自己，$dp[a] \leftarrow dp[a] + 1$ 恰好统计同一数值出现的次数，答案等于最大频次。必须「先查后写」，否则每次都会读到自己刚写入的值，链长会算错。
2. **负的 `difference`**：前驱数值比 $a$ 大（示例 3），只有在代码里统一写 `a - difference` 才不会把方向弄反；不要手动改写成 `a + difference` 再按符号分支。
3. **答案为 1**：所有元素两两之差都不等于 `difference`（示例 2）时返回 1，而不是 0。`best` 初值取 0 也能得到正确结果，但若数组为空（本题不会出现）应返回 0，两者要分清。
4. **最长链不以最后一个元素结尾**：例如 `arr = [1,2,3,9]`、`difference = 1`，答案是 3；任何「只维护最后一个元素的状态」的写法都会错，答案必须在循环中取最大值。
5. **覆盖还是取 max**：$dp[a] = \text{cur}$ 与 $dp[a] = \max(dp[a],\ \text{cur})$ 等价（引理 2），但写成「只在 `cur` 更大时才更新」并顺手漏掉其他逻辑容易出错；保持覆盖写法最简。
6. **值域与键范围**：$a - \text{difference}$ 最小为 $-2\times10^4$、最大为 $2\times10^4$，若用数组实现偏移量取 $20000$、数组长 $40001$，不要取 $10^4$ 导致负下标越界。
7. **`unordered_map` 的性能**：不 `reserve` 时 $10^5$ 次插入会触发多次 rehash，常数明显变大；在周赛里这类细节常常决定能否卡进时限。
