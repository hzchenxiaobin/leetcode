# LeetCode 最大和查询 题解

## 1. 题目概述

- **标题 / 题号**：最大和查询（#2736，hard）
- **链接**：https://leetcode.cn/problems/maximum-sum-queries/
- **来源**：LeetCode 第 349 场周赛 Q4
- **难度**：困难
- **标签**：数组、排序、单调栈、二分查找、ST 表

**题意**：给定两个长度为 $n$ 的数组 `nums1`、`nums2` 与 $q$ 个查询，`queries[i] = [xi, yi]`。对每个查询，在所有满足 `nums1[j] >= xi` **且** `nums2[j] >= yi` 的下标 $j$ 中，求 `nums1[j] + nums2[j]` 的**最大值**；若不存在这样的下标则返回 $-1$。返回所有查询的答案数组。

**约束**：

- $1 \le n \le 10^5$
- $1 \le \text{nums1[i]}, \text{nums2[i]} \le 10^9$
- $1 \le q \le 10^5$
- $1 \le x_i, y_i \le 10^9$

> 💡 建模一句话：把每个下标 $j$ 看成平面上的点 $(\text{nums1}[j],\ \text{nums2}[j])$，权值 $w = x + y$；每个查询就是问「以 $(x_i, y_i)$ 为左下角的**右上角区域**内，权值最大的点是谁」——一个标准的**二维支配 + 区间最值**问题。

## 2. 示例

**示例 1**

```text
输入：nums1 = [4,3,1,2], nums2 = [2,4,9,5], queries = [[4,1],[1,3],[2,5]]
输出：[6,10,7]
解释：点集为 (4,2), (3,4), (1,9), (2,5)：
  - 查询 (4,1)：候选 {(4,2)}，最大和 6；
  - 查询 (1,3)：候选 {(4,2)?否(y=2<3), (3,4), (1,9), (2,5)}，最大和 9+1 = 10；
  - 查询 (2,5)：候选 {(2,5)}，最大和 7。
```

**示例 2**

```text
输入：nums1 = [3,2,5], nums2 = [2,3,4], queries = [[4,4],[3,2],[1,1]]
输出：[9,9,9]
解释：点 (5,4) 位于所有查询的右上角区域内，和恒为 9。
```

```text
输入：nums1 = [2,1], nums2 = [2,3], queries = [[3,3]]

```

## 3. 解题思路

### 3.1 暴力思路：逐查询全量扫描

对每个查询遍历全部 $n$ 个下标，检查两维门槛并维护最大和，单次 $O(n)$，总计 $O(nq)$。在 $n = q = 10^5$ 时约 $10^{10}$ 次操作，必然超时。数据范围明示：必须把每个查询的代价压到 $O(\log n)$ 级别，即需要**预处理出某种可二分、可快速求最值的结构**。

### 3.2 核心观察：支配淘汰，只留「阶梯」

![核心观察：支配淘汰，落在阶梯左下方的点永远不用看](images/2736_maxsum_pareto_stack.svg)

将点集画在平面上，关键洞察是**支配关系**：

1. **支配定义**：点 $B=(b_1, b_2)$ **支配**点 $A=(a_1, a_2)$，当且仅当 $b_1 \ge a_1$ 且 $b_2 \ge a_2$（$B$ 在 $A$ 的右上方）。
2. **被支配即可删**：若 $B$ 支配 $A$，则任何能选到 $A$ 的查询（$a_1 \ge x_i$ 且 $a_2 \ge y_i$）必然也能选到 $B$（$b_1 \ge a_1 \ge x_i$，$b_2 \ge a_2 \ge y_i$），且 $w_B = b_1 + b_2 \ge a_1 + a_2 = w_A$——**留着 $A$ 永远不会更优，直接删除**。
3. **权值恰为 $x+y$ 是关键**：上面第 2 步的 $w_B \ge w_A$ 完全由「两坐标都不小」推出，**无需额外比较权值**。若权值是独立的 $w_j$，被支配但更贵的点仍可能是某些查询的最优解，就不能无脑删了。

删完所有被支配点后，幸存点构成一条**阶梯**（Pareto 前沿）：按 $x$ 升序排列后 **$y$ 严格递减**——若 $x_1 < x_2$ 且 $y_1 \le y_2$，则点 2 支配点 1，矛盾。

这条阶梯用**单调栈** $O(n \log n)$ 一趟建出：把点按 $(x, y)$ 字典序升序排序后依次入栈，新点 $(x, y)$ 到来时，不断弹掉栈顶所有 $y' \le y$ 的点（它们排序在前面、$x' \le x$，被新点支配），再压入新点。

### 3.3 算法流程：两次二分 + ST 表区间最大

![查询流程：两次二分夹出候选段，ST表O(1)取最大](images/2736_maxsum_query_flow.svg)

阶梯上 $x$ 严格递增、$y$ 严格递减，于是每个查询 $(x_i, y_i)$ 的候选点是一段**连续区间 $[L, R]$**：

- **二分①**：$L \leftarrow$ 第一个满足 $x \ge x_i$ 的下标（$x$ 有序，砍掉左端）；
- **二分②**：$R \leftarrow$ $[L, m)$ 内最后一个满足 $y \ge y_i$ 的下标（该后缀上 $y$ 递减，砍掉右端）；
- **区间最值**：答案为 $\max_{L \le k \le R} w_k$。

> ⚠️ **$w = x + y$ 在阶梯上不单调**：例如阶梯 $(1,100), (50,99), (100,1)$ 的权值为 $101, 149, 101$，最大值藏在中间。所以不能只看区间端点，必须用 **ST 表**（稀疏表）做 $O(1)$ 静态区间最大查询。

```text
pts ← 按 (x, y) 字典序升序排序的点集
栈 S ← 空
for (x, y) in pts:                        # 单调栈建阶梯
    while S 非空 且 S.top.y <= y: pop      # 栈顶被新点支配
    push (x, y)
在 S 上构建 ST 表（w = x + y 的区间最大）
for (xi, yi) in queries:                  # 逐查询二分
    L ← 第一个 x >= xi 的下标；L == m → -1
    R ← [L, m) 内最后一个 y >= yi 的下标；R < L → -1
    answer ← ST.max(L, R)
```

### 3.4 示例演算

![示例演算：阶梯与三个查询的L/R及答案](images/2736_maxsum_walkthrough.svg)

以示例 1 为例：点集 $\{(4,2), (3,4), (1,9), (2,5)\}$，排序后为 $(1,9), (2,5), (3,4), (4,2)$，依次入栈时无人被弹（$y$ 恰好递减），得到四格阶梯 $x = [1,2,3,4]$，$y = [9,5,4,2]$，$w = [10,7,7,6]$：

- 查询 $(4,1)$：$L = 3$，$y \ge 1$ 直到末尾，$R = 3$，$\max w[3..3] = 6$；
- 查询 $(1,3)$：$L = 0$，$y \ge 3$ 止于下标 2（$y=4 \ge 3$，下一个 $y=2 < 3$），$R = 2$，$\max(10,7,7) = 10$；
- 查询 $(2,5)$：$L = 1$，$y \ge 5$ 止于下标 1（$y=5 \ge 5$，下一个 $y=4 < 5$），$R = 1$，$w = 7$。

答案 $[6, 10, 7]$，与示例一致。

## 4. 算法细节

1. **排序规则**：按 $(x, y)$ **字典序升序**（即 $x$ 相同时 $y$ 升序）。这保证同一 $x$ 的点中 $y$ 最大者最后到来、把同 $x$ 更小的全部弹掉，栈内 $x$ **严格**递增、$y$ **严格**递减，两次二分的有序性前提都成立。
2. **弹栈条件取 $\le$**：`while st and st.top.y <= y: pop`。写成严格 `<` 会在坐标完全相同的重复点处残留冗余（不影响正确性，但不干净）。
3. **二分①**：在 `xs` 数组上 `lower_bound(xs, xi)`——必须是「第一个 $\ge x_i$」，误用 `upper_bound` 会漏掉 $x$ 恰好等于 $x_i$ 的点。
4. **二分②**：在 $[L, m)$ 上找「最后一个 $y \ge y_i$」，等价于找「第一个 $y < y_i$ 的位置再减一」。手写整数二分：`ys[mid] >= yi` 则收缩左端，否则收缩右端。
5. **ST 表**：`st[j][i] = max(st[j-1][i], st[j-1][i + 2^(j-1)])`，查询 $[L, R]$ 时取 $k = \lfloor \log_2(R-L+1) \rfloor$，答案为 $\max(st[k][L], st[k][R - 2^k + 1])$。$m = 1$ 时只有第 0 层，注意不要越界建表。
6. **替代做法（离线 + 树状数组）**：把查询按 $x_i$ 降序、点按 $x$ 降序排序，用指针把 $x \ge x_i$ 的点逐个插入树状数组（按 $y$ 离散化，维护「$y \ge$ 某值的最大 $w$」后缀最大值），每个查询 $O(\log n)$ 查一次。两种做法复杂度同阶；单调栈版无需离散化、无需离线重排查询，代码更短。

## 5. 正确性证明

**引理 1**（支配淘汰的合法性）：设 $B$ 支配 $A$（$b_1 \ge a_1$ 且 $b_2 \ge a_2$）。则对任意查询 $(x_i, y_i)$：若 $A$ 满足约束则 $B$ 也满足，且 $w_B \ge w_A$。故从点集中删去 $A$ 不改变任何查询的答案。

**证明**：$A$ 满足约束即 $a_1 \ge x_i$ 且 $a_2 \ge y_i$，于是 $b_1 \ge a_1 \ge x_i$、$b_2 \ge a_2 \ge y_i$，$B$ 满足约束；$w_B = b_1 + b_2 \ge a_1 + a_2 = w_A$。删去 $A$ 后，任何原先以 $A$ 为最优的查询仍可在候选集中取到 $B$，答案不降；候选集只减不增，答案不升。∎

**引理 2**（栈的形态与覆盖）：算法结束后，栈自底向上 $x$ 严格递增、$y$ 严格递减；且**每个被弹出的点都被某个最终留在栈中的点支配**。

**证明**：形态：点按字典序升序处理。压入新点前，栈顶所有 $y' \le y$ 者已被弹出，故压入后栈内 $y$ 仍严格递减；同 $x$ 的点按 $y$ 升序先后到来，后到者弹出先到者，故栈内不会出现相同 $x$，结合处理顺序得 $x$ 严格递增。覆盖：点 $P$ 被点 $Q$ 弹出时，处理顺序保证 $x_Q \ge x_P$，弹栈条件给出 $y_Q \ge y_P$，即 $Q$ 支配 $P$。若 $Q$ 日后被 $Q'$ 弹出，由两分量各自取 $\ge$ 的复合可得支配关系**传递**：$Q'$ 支配 $P$。对弹出链归纳：每个被弹出的点都被某个最终栈中之点支配。∎

**定理**：对每个查询，算法输出值为该查询约束下原点集中 $x + y$ 的最大值（无解时输出 $-1$）。

**证明**：记最终栈集为 $S$（$|S| = m$），查询为 $(x_i, y_i)$。由引理 2 的形态，$S$ 中满足 $x \ge x_i$ 的点构成后缀 $[L, m)$，其中再满足 $y \ge y_i$ 的点因 $y$ 递减构成前缀 $[L, R]$——两次二分定位的正是这段连续区间，ST 表返回其 $w$ 最大值，故算法输出 $= \max\{x + y : (x,y) \in S,\ x \ge x_i,\ y \ge y_i\}$。
一方面 $S$ 是原点集的子集，输出 $\le$ 原答案。另一方面，对原候选集中任一点 $P$：若 $P \in S$，其 $w$ 已参与输出中的 $\max$；若 $P \notin S$，由引理 2 存在 $Q \in S$ 支配 $P$，于是 $Q$ 满足约束且 $w_Q \ge w_P$。故原候选集中每点的 $w$ 都不超过输出值，原答案 $\le$ 输出。两边夹得输出 = 原答案。
无解情形：输出 $-1$ 当且仅当 $S$ 中无点满足约束。此时原候选集必为空——否则取 $P$，同上可得 $S$ 中存在满足约束的点，矛盾。∎

## 6. 复杂度分析

- **时间复杂度**：$O((n + q) \log n)$——排序 $O(n \log n)$；单调栈每点至多入栈、出栈各一次，$O(n)$；ST 表构建 $O(m \log m)$（$m \le n$ 为阶梯长度）；每个查询两次二分加一次 $O(1)$ 区间最大，$O(\log m)$，共 $O(q \log n)$。
- **空间复杂度**：$O(n \log n)$——阶梯数组 $O(m)$，ST 表 $O(m \log m)$ 为主体。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> maximumSumQueries(vector<int>& nums1, vector<int>& nums2,
                                  vector<vector<int>>& queries) {
        int n = nums1.size();
        vector<pair<int, int>> pts(n);
        for (int i = 0; i < n; i++) pts[i] = {nums1[i], nums2[i]};
        sort(pts.begin(), pts.end());                    // 字典序：x 升序，同 x 时 y 升序

        vector<int> xs, ys;                              // 阶梯：x 严格递增、y 严格递减
        vector<long long> ws;
        for (auto& [x, y] : pts) {
            while (!ys.empty() && ys.back() <= y) {      // 栈顶被新点支配，弹掉
                xs.pop_back(); ys.pop_back(); ws.pop_back();
            }
            xs.push_back(x); ys.push_back(y); ws.push_back((long long)x + y);
        }
        int m = xs.size();

        int LOG = 1;                                     // ST 表：静态区间最大
        while ((1 << LOG) <= m) LOG++;
        vector<vector<long long>> st(LOG, vector<long long>(m));
        st[0] = ws;
        for (int j = 1; j < LOG; j++)
            for (int i = 0; i + (1 << j) <= m; i++)
                st[j][i] = max(st[j - 1][i], st[j - 1][i + (1 << (j - 1))]);

        vector<int> ans;
        ans.reserve(queries.size());
        for (auto& q : queries) {
            int xi = q[0], yi = q[1];
            int L = lower_bound(xs.begin(), xs.end(), xi) - xs.begin(); // 第一个 x >= xi
            if (L == m) { ans.push_back(-1); continue; }
            int lo = L, hi = m;                          // [L,m) 内找第一个 y < yi
            while (lo < hi) {
                int mid = (lo + hi) >> 1;
                if (ys[mid] >= yi) lo = mid + 1;
                else hi = mid;
            }
            int R = lo - 1;                              // 最后一个 y >= yi
            if (R < L) { ans.push_back(-1); continue; }
            int k = 31 - __builtin_clz(R - L + 1);
            ans.push_back((int)max(st[k][L], st[k][R - (1 << k) + 1]));
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maximumSumQueries(self, nums1: List[int], nums2: List[int],
                          queries: List[List[int]]) -> List[int]:
        xs, ys, ws = [], [], []                          # 阶梯：x 严格递增、y 严格递减
        for x, y in sorted(zip(nums1, nums2)):           # 字典序升序
            while ys and ys[-1] <= y:                    # 栈顶被新点支配，弹掉
                xs.pop(); ys.pop(); ws.pop()
            xs.append(x); ys.append(y); ws.append(x + y)
        m = len(xs)

        st = [ws]                                        # ST 表：静态区间最大
        j = 1
        while (1 << j) <= m:
            half = 1 << (j - 1)
            prev = st[j - 1]
            st.append([max(prev[i], prev[i + half]) for i in range(m - (1 << j) + 1)])
            j += 1

        ans = []
        for xi, yi in queries:
            L = bisect_left(xs, xi)                      # 第一个 x >= xi
            if L == m:
                ans.append(-1); continue
            lo, hi = L, m                                # [L,m) 内找第一个 y < yi
            while lo < hi:
                mid = (lo + hi) // 2
                if ys[mid] >= yi: lo = mid + 1
                else: hi = mid
            R = lo - 1                                   # 最后一个 y >= yi
            if R < L:
                ans.append(-1); continue
            k = (R - L + 1).bit_length() - 1
            ans.append(max(st[k][L], st[k][R - (1 << k) + 1]))
        return ans
```

## 8. 边界情况与易错点

1. **$w$ 贴近 `int` 上限**：$x + y \le 2 \times 10^9$，恰好低于 `INT_MAX`（约 $2.147 \times 10^9$）但只差约 $1.5$ 亿——C++ 中建议直接用 `long long` 存权值，防御性优先；Python 无此问题。
2. **同 $x$ 的排序次序**：必须 $y$ **升序**，同 $x$ 只留 $y$ 最大者，保证栈内 $x$ 严格递增（$y$ 降序虽只是残留冗余点、侥幸不出错，但破坏「严格」不变式，二分语义变脆）。
3. **二分① 用 `lower_bound` 不是 `upper_bound`**：后者会漏掉 $x$ 恰等于 $x_i$ 的阶梯点（示例 1 的查询 $(4,1)$、$(2,5)$ 都踩在等号上）。
4. **两处 $-1$ 判定缺一不可**：$L = m$（没有点的 $x$ 够大，示例 3）与 $R < L$（有 $x$ 够大的点但它们的 $y$ 全不够，此时常被遗漏——注意 $[L, m)$ 后缀里 $y$ 最小的是末尾，不是开头）。
5. **ST 表 $m = 1$**：只有第 0 层，建表循环与 `LOG` 计算都不应越界；查询长度 1 时 $k = 0$，两段拼盖同一段。
6. **弹栈条件带等号**：`y' <= y` 而非 `y' < y`，重复点只留一份（等号漏写不影响正确性但留冗余）。
7. **输入规模**：$n, q$ 均达 $10^5$，C++ 关同步流（`ios::sync_with_stdio(false)`）或用 `scanf`；Python 的 ST 表用列表推导逐层构建，避免逐元素 `append` 的双层循环。
