# LeetCode 执行子串操作后的字典序最小字符串 题解

## 1. 题目概述

- **标题 / 题号**：执行子串操作后的字典序最小字符串（#2734，medium）
- **链接**：https://leetcode.cn/problems/lexicographically-smallest-string-after-substring-operation/
- **来源**：LeetCode 第 349 场周赛 Q2
- **难度**：中等
- **标签**：贪心、字符串

**题意**：给定仅由小写字母组成的字符串 `s`，要求**恰好执行一次**如下操作：选一个非空子串（可以是整个字符串），把其中**每一个**字符替换为字母表中的**前一个**字母（`'b' → 'a'`，而 `'a'` 环绕到 `'z'`）。返回操作后**字典序最小**的字符串。

**约束**：

- $1 \le \mathrm{len}(s) \le 3 \times 10^5$
- `s` 仅由小写英文字母组成

> 💡 全部难度浓缩在一个字符上：`'a'`。非 `'a'` 字符减一是"变小"，唯独 `'a'` 减一环绕成 `'z'`、不降反升。贪心策略就是围绕"哪些位置敢减、延伸到哪里必须停"展开（见 3.2）。

## 2. 示例

**示例 1**

```text
输入：s = "cbabc"
输出："baabc"
解释：选择下标 [0,1] 的子串 "cb"，减一后得 "ba"，整体为 "baabc"。
```

**示例 2**

```text
输入：s = "acbbc"
输出："abaab"
解释：跳过前缀 'a'，选择下标 [1,4] 的子串 "cbbc"，减一后得 "baab"，整体为 "abaab"。
```

**示例 3**

```text
输入：s = "leetcode"
输出："kddsbncd"
解释：整串没有 'a'，直接把整个字符串减一。
```

**示例 4**（自拟，覆盖全 `'a'` 边界）

```text
输入：s = "aa"
输出："az"
解释：全是 'a'，怎么操作都必然产生 'z'；只把最后一个 'a' 单独变 'z' 最优。
```

## 3. 解题思路

### 3.1 暴力思路：枚举所有子串

最朴素的做法是枚举全部 $O(n^2)$ 个区间 $[l, r]$，对每个区间生成结果串（$O(n)$）再取字典序最小，总代价 $O(n^3)$。问题在于 $n = 3 \times 10^5$ 时光是区间个数就有 $\frac{n(n+1)}{2} \approx 4.5 \times 10^{10}$ 个，任何逐区间枚举的方案都直接出局——必须利用**字典序比较的结构性**，把"选哪个区间"一步推理出来。

### 3.2 核心观察：贪心——保住 'a' 前缀，非 'a' 极大段整体减一

![核心观察：保住a前缀，非a极大段整体减一](images/subop_lexmin_concept.svg)

三个观察层层递进：

1. **字典序由第一个不同位置决定**：想让结果更小，等价于让"第一个被改小的位置"尽量靠前，且在该位置改得尽量小。
2. **前驱运算的分裂性**：记 $\mathrm{pred}(c)$ 为 $c$ 的前一个字母，则 $\mathrm{pred}(c) < c$ 当且仅当 $c \ne 'a'$；而 $\mathrm{pred}('a') = 'z'$ 恰是**整个字母表中最大**的字符。也就是说，这次操作让每个字符"变小"还是"变大"，完全由它是否为 `'a'` 决定。
3. 由此拼出三段式贪心（设 $i$ 为第一个非 `'a'` 的下标）：
   - **开头的 `'a'` 前缀动不得**：它已是各自位置上可能的最小字符，任何覆盖它的区间都会在第一个被覆盖的 `'a'` 处产出 `'z'`，当场变大；
   - **区间必须从 $i$ 开始**：若区间不含 $i$，位置 $i$ 保持原值；含 $i$ 则减一变小——由观察 1，起点选 $i$ 严格更优；
   - **从 $i$ 向右能延伸就延伸，碰到 `'a'` 立即停**：延伸覆盖的每个非 `'a'` 字符都白赚一次减一；而一旦把 `'a'` 拉进区间，该位变 `'z'`，前面赚的全部白搭（第 5 节引理 2 的逐位置比较给出严格论证）。

### 3.3 算法流程

![算法流程：一遍线性扫描](images/subop_lexmin_flow.svg)

```text
1. i ← 0；while i < n 且 s[i] == 'a'：i++         # 跳过 'a' 前缀
2. if i == n：                                     # 整个串全是 'a'
       s[n-1] ← 'z'；返回 s                        # 只动最后一个
3. while i < n 且 s[i] != 'a'：s[i] 减一；i++       # 极大非 'a' 段整体减一
4. 返回 s
```

**全 `'a'` 特判的理由**：此时任何操作都必然产出 `'z'`，只能退而求其次——让第一个 `'z'` 出现得**尽量晚**（位置 $n-1$），且区间**尽量短**（只剩它自己），即单独把最后一个字符变 `'z'`。

### 3.4 示例演算

![示例演算：四种典型形态](images/subop_lexmin_walkthrough.svg)

四种典型形态一图打尽：`"cbabc"`（遇 `'a'` 停）、`"acbbc"`（延伸到串尾）、`"leetcode"`（整串无 `'a'`）、`"aa"`（全 `'a'` 特判）。

## 4. 算法细节

1. **找第一个非 `'a'`**：`while (i < n && s[i] == 'a') i++;`——循环条件是"等于 `'a'` 才跳过"，别与减一段的"不等于 `'a'` 才继续"写反。
2. **全 `'a'` 判定就是 `i == n`**：无需额外标志位；特判分支里 `s[n-1] = 'z'` 一步完成（$n \ge 1$ 保证下标合法）。
3. **减一无需环绕特判**：减一段内字符全部 $\ge 'b'$，`s[i]--`（或 `chr(ord(c)-1)`）不可能穿过 `'a'`；只有错误地让区间覆盖 `'a'` 时才会触发环绕。
4. **C++ 原地修改**：接口 `smallestString(string s)` 按值传入，直接在 `s` 上改完返回，无额外拷贝；Python 字符串不可变，先 `list(s)` 再 `''.join`。
5. 两个阶段共享同一个下标变量、都单调右移，整题就是**一遍扫描**。

## 5. 正确性证明

记 $\mathrm{pred}(c)$ 为 $c$ 的字母表前驱（`'a'` 的前驱为 `'z'`），$R(l, r)$ 表示对区间 $[l, r]$ 执行操作后的结果串。

**引理 1**（前驱的单调性）：对小写字母 $c$，$\mathrm{pred}(c) < c \iff c \ne 'a'$；且 $\mathrm{pred}('a') = 'z' > 'a'$。

**证明**：$c \in ['b', 'z']$ 时 $\mathrm{pred}(c)$ 的字符编码恰比 $c$ 小 $1$ 且仍 $\ge 'a'$，故 $\mathrm{pred}(c) < c$；$c = 'a'$ 时按题意 $\mathrm{pred}('a') = 'z'$，而 `'z'` 是字母表最大者。∎

**引理 2**（存在非 `'a'` 时的最优区间）：设 $i$ 为 $s$ 中第一个非 `'a'` 的下标，$j$ 为从 $i$ 出发的极大非 `'a'` 段右端点（$s[i..j]$ 均非 `'a'`，且 $j = n-1$ 或 $s[j+1] = 'a'$）。则对任何区间 $[l, r] \ne [i, j]$，有 $R(i, j) < R(l, r)$。

**证明**：记 $A = R(i,j)$，$B = R(l,r)$，逐类找到一个位置 $p$，使 $A$ 与 $B$ 在 $[0, p)$ 上相同且 $A[p] < B[p]$：

- **$l < i$**：由 $i$ 的最小性，$s[l] = 'a'$。取 $p = l$：位置 $l$ 之前两者均未改动；$A[l] = 'a'$（$A$ 只改 $[i, j]$），$B[l] = \mathrm{pred}('a') = 'z'$。由引理 1，$A < B$。
- **$l > i$**：取 $p = i$：位置 $i$ 之前两者相同；$A[i] = \mathrm{pred}(s[i]) < s[i]$（引理 1，$s[i] \ne 'a'$），而 $B[i] = s[i]$（区间 $[l, r]$ 未覆盖 $i$）。故 $A < B$。
- **$l = i$ 且 $r < j$**：取 $p = r+1 \le j$：位置 $[0, r]$ 上两者逐位相同；$A[p] = \mathrm{pred}(s[p]) < s[p] = B[p]$，因 $p$ 落在非 `'a'` 段内，$s[p] \ne 'a'$。故 $A < B$。
- **$l = i$ 且 $r > j$**：此时 $j + 1 \le r \le n - 1$，由 $j$ 的极大性 $s[j+1] = 'a'$。取 $p = j+1$：位置 $[0, j]$ 上两者相同；$A[p] = 'a'$（未改动），$B[p] = \mathrm{pred}('a') = 'z'$。故 $A < B$。∎

**引理 3**（全 `'a'` 时的最优区间）：若 $s$ 全为 `'a'`，则 $R(n-1, n-1) =$ `"a…az"` 严格小于任何其他区间的结果。

**证明**：对全 `'a'` 串操作 $[l, r]$ 的结果是：前 $l$ 位 `'a'`、中间 $r - l + 1$ 位 `'z'`、其余 `'a'`。设 $[l, r] \ne [n-1, n-1]$，则必有 $l \le n - 2$（若 $l = n-1$ 则 $r = n-1$，与假设矛盾）。取 $p = l$：位置 $[0, l)$ 上两个结果均为 `'a'`；$R(n-1, n-1)[p] = 'a'$（因 $l < n-1$，未被改动），而 $R(l, r)[p] = 'z'$。故 `a…az` 更小。∎

**定理**：算法返回恰好执行一次操作后字典序最小的字符串。

**证明**：所有可能的结果恰为 $\{R(l, r) : 0 \le l \le r \le n-1\}$（操作必须执行且只执行一次）。若 $s$ 含非 `'a'` 字符，由引理 2，$R(i, j)$ 是其中的严格最小元，算法输出之；若 $s$ 全为 `'a'`，由引理 3，$R(n-1, n-1)$ 是严格最小元，算法输出之。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。找 $i$ 与扩展减一两个阶段的下标均单调右移，每个字符至多被访问常数次。
- **空间复杂度**：C++ 在按值传入的 `s` 上原地修改，额外 $O(1)$（返回串即传入串）；Python 因字符串不可变需 `list` 副本，额外 $O(n)$。

## 7. 参考代码

### C++（一遍扫描，原地修改）

```cpp
class Solution {
public:
    string smallestString(string s) {
        int n = s.size(), i = 0;
        while (i < n && s[i] == 'a') i++;
        if (i == n) {
            s[n - 1] = 'z';
            return s;
        }
        while (i < n && s[i] != 'a') s[i]--;
        return s;
    }
};
```

### Python（list 中转，逻辑同构）

```python
class Solution:
    def smallestString(self, s: str) -> str:
        t = list(s)
        n = len(t)
        i = 0
        while i < n and t[i] == 'a':
            i += 1
        if i == n:
            t[n - 1] = 'z'
        else:
            while i < n and t[i] != 'a':
                t[i] = chr(ord(t[i]) - 1)
                i += 1
        return ''.join(t)
```

## 8. 边界情况与易错点

1. **全 `'a'` 串必须特判**："恰好一次"意味着**不能原样返回**——`"aa"` 的答案是 `"az"`。且必须动**最后一个**：动第一个得 `"za"`，动整段得 `"zz"`，都更大。
2. **遇 `'a'` 必停（本题最大陷阱）**：把 `'a'` 拉进区间会产出 `'z'`。反例 `"cbabc"`：若把 $[0,2]$ 整段减一得 `"bazbc"`，与正确答案 `"baabc"` 相比在第 2 位 `'z' > 'a'` 而落败。
3. **两个循环条件别写反**：跳前缀是 `s[i] == 'a'` 时右移，减一段是 `s[i] != 'a'` 时继续；写反会把非 `'a'` 段当成前缀跳过。
4. **$n = 1$**：`"a" → "z"`、`"b" → "a"`，两个分支天然覆盖，无需单独处理。
5. **别按"找子串"的思路做**：贪心完全由下标结构决定，先定位"第一个非 `'a'`"，再谈延伸。
6. **数据范围**：$n \le 3 \times 10^5$，任何 $O(n^2)$ 的区间枚举（约 $4.5 \times 10^{10}$ 个区间）都不可行，必须线性贪心。
7. **Python 字符串不可变**：直接 `s[i] = ...` 会抛 `TypeError`，先 `list(s)`，最后 `''.join(t)`。
