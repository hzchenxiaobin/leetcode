# LeetCode 最长理想子序列 题解

## 1. 题目概述

- **标题 / 题号**：最长理想子序列（#2370，medium）
- **链接**：https://leetcode.cn/problems/longest-ideal-subsequence/
- **来源**：LeetCode 第 305 场周赛 Q4
- **难度**：中等
- **标签**：动态规划、字符串、哈希表

**题意**：给定小写字母组成的字符串 `s` 和整数 `k`。字符串 `t` 称为**理想字符串**，当且仅当：

1. `t` 是 `s` 的**子序列**（可以跳着取字符，保持相对顺序）；
2. `t` 中任意两个**相邻**字母在字母表中的位次差绝对值不超过 $k$（`'a'` 记 0，…，`'z'` 记 25；**字母表不循环**，`'a'` 与 `'z'` 的差是 25 不是 1）。

返回最长理想字符串的长度。

**约束**：

- $1 \le \text{s.length} \le 10^5$
- $0 \le k \le 25$
- `s` 仅由小写英文字母组成

> 💡 本场 Q4 官方难度是中等（周赛压轴里少见的 medium 评级），真正的分水岭不在"想到 DP"，而在**把 $O(n^2)$ 的朴素子序列 DP 压到 $O\big(n(2k+1)\big)$**——一步"按末字符建状态"的压缩。

## 2. 示例

**示例 1**

```text
输入：s = "acfgbd", k = 2
输出：4
解释：最长理想字符串是 "acbd"（取下标 0, 1, 4, 5）。
     位次 0, 2, 1, 3：|0−2| = 2 ≤ 2，|2−1| = 1 ≤ 2，|1−3| = 2 ≤ 2，均合法。
     注意 "acfgbd" 本身不理想：'c' 与 'f' 的位次差为 3 > 2。
```

**示例 2**

```text
输入：s = "abcd", k = 3
输出：4
解释：整个串即为理想字符串，相邻位次差均为 1 ≤ 3。
```

**示例 3**（自构造：`k = 0` 退化与"字母表不循环"两个边界）

```text
输入：s = "abcdcba", k = 0
输出：2
解释：k=0 时相邻必须同字母，理想子序列只能由同一字母的多次出现构成，
     答案 = 出现次数最多的字母频次（这里 a/b/c 各 2 次）。

输入：s = "az", k = 24
输出：1
解释：|'a'−'z'| = 25 > 24，两个字符接不起来；
     若误以为字母表循环（把差算成 1）会错答 2。
```

## 3. 解题思路

### 3.1 暴力思路：指数枚举、$O(n^2)$ DP、单线贪心全部折戟

三层"最自然的想法"逐层翻车：

1. **枚举全部子序列**：$2^n$ 个，$n = 10^5$ 时是天文数字，不可行。
2. **经典子序列 DP（LIS 式）**：定义 $f[i]$ 为以 $s_i$ 结尾的最长理想子序列长度，则 $f[i] = 1 + \max\{f[j] : j < i,\ |s_j - s_i| \le k\}$。正确，但每步回扫前面全部下标，$O(n^2) \approx 10^{10}$，必然 TLE。
3. **单线贪心**：只维护"一条当前最长的理想子序列"，能接就接、不能接就跳过。用示例 1 即可推翻：扫到 `b` 之前，最长的线有两条——`"ac"` 与 `"fg"`（长度都是 2）。若手里攥的是 `"fg"`，则 $|g - b| = 5 > 2$ 接不上，只能跳过 `b`，随后止步于 `"fgd"`（长度 3）；而正确答案走的是 `"ac" → "acb" → "acbd"` 这条线（长度 4）。

第 3 条翻车的根因最有价值：**能否接住下一个字符，取决于子序列的末字符，而不是它的长度**。只攥一条"全局最长"会把其他末字符的线索全部丢掉——要想不漏，必须**按末字符分桶**，每桶各保留一条当前最长。第 2 条翻车则提示：桶不必按"下标"开 $n$ 个，因为**末字符的值域只有 26 个字母**。

### 3.2 核心观察：把"以下标结尾"压缩成"以字母结尾"

![核心观察：状态从按下标建 n 个压缩为按末字母建 26 槽，转移取邻域最大加一](images/2370_ideal_state_compression.svg)

两个性质支撑这次**无损压缩**：

- **无后效性**：理想性只校验**相邻两位**的位次差。一条子序列将来能否再接某个字符，只由它的**末字符**决定，更早的历史不起任何作用（即 §5 引理 1）。
- **支配性**：末字符相同的两条子序列，将来能接的字符集合完全相同，于是**长者支配短者**——每桶只需保留最长的一条。

据此定义状态：$dp[c]$ = **已扫描前缀**中、以字母 $c$ 结尾的最长理想子序列长度（$c \in [0, 25]$，不存在为 0）。从左到右处理字符 $s_i$（编码 $c_i = s_i - \text{'a'}$）时，把它接到"以 $c$ 结尾且 $|c - c_i| \le k$"的桶代表后面即可，故：

$$dp[c_i] \;=\; 1 \;+\; \max_{|c - c_i| \le k} dp[c]$$

邻域 $[\max(0,\, c_i-k),\ \min(25,\, c_i+k)]$ 在字母表两端**夹断**，长度至多 $2k+1 \le 51$。于是每个字符的转移只是一次**小区间取最大**：总复杂度 $O\big(n(2k+1)\big) \approx 5 \times 10^6$，轻松通过。

> 💡 **与 LIS 的关系**：[300. 最长递增子序列](https://leetcode.cn/problems/longest-increasing-subsequence/) 的骨架是"以 $x$ 结尾、后面只能接满足约束的字符"，本题把"严格更大"松弛成"位次差 $\le k$"，前驱集合从"右侧射线"变成"半径 $k$ 的邻域"；而值域缩到 26 之后，连"排序 + 树状数组"都省了，直接数组扫邻域。[1218. 最长定差子序列](https://leetcode.cn/problems/longest-arithmetic-subsequence-of-given-difference/) 则是"差恰为 $d$"的单点前驱版本——三题同属"**只关心末元素**"的按值建表家族。

> ⚠️ **读旧值是安全的，且覆盖即提升**：邻域包含 $c_i$ 自身（$|c_i - c_i| = 0 \le k$），候选里有"以 $s_i$ 之前的同字母结尾的旧子序列"——这正是"再接一个同字母"的合法分支。先取 max、再 $+1$、最后写回，$s_i$ 恰好被计入一次。又因为旧值 $dp[c_i]$ 也在邻域内，新值 $= \text{best} + 1 \ge dp_{\text{旧}}[c_i] + 1$ **恒严格大于旧值**——直接覆盖即可，无需与旧值再取 max，这同时说明**每个槽的值随其字母的出现严格递增**。

### 3.3 算法流程

![算法流程：一遍扫描，每字符夹断邻域、读旧值取最大、加一写回、更新全局答案](images/2370_ideal_algorithm_flow.svg)

1. **初始化**：`dp[0..25] = 0`，`ans = 0`；
2. **主循环**：从左到右对每个字符 `ch`：
   - 编码 `ci = ch - 'a'`；
   - 夹断出邻域 `lo = max(0, ci-k)`、`hi = min(25, ci+k)`；
   - `best = max(dp[lo..hi])`（**读写入前的旧值**）；
   - `dp[ci] = best + 1`，并 `ans = max(ans, dp[ci])`；
3. **返回** `ans`。

一遍扫描、无回溯、无复杂数据结构。

### 3.4 示例演算

![示例演算：s 等于 acfgbd，k 等于 2，逐字符看邻域、取最大、写回 dp 表](images/2370_ideal_example_walkthrough.svg)

以 $s =$ `"acfgbd"`、$k = 2$ 演算（编码 `a=0, c=2, f=5, g=6, b=1, d=3`）：

| 步 | 字符 | $c_i$ | 邻域（夹断后） | best 来源 | 写入 | 代表子序列 |
|----|------|-------|----------------|-----------|------|------------|
| ① | `a` | 0 | $[0,2]$：a,b,c | 全 0 | $dp[a]=1$ | `"a"`（单开新串） |
| ② | `c` | 2 | $[0,4]$：a..e | $dp[a]=1$ | $dp[c]=2$ | `"ac"` |
| ③ | `f` | 5 | $[3,7]$：d..h | 全 0 | $dp[f]=1$ | `"f"`（邻域全 0，单开） |
| ④ | `g` | 6 | $[4,8]$：e..i | $dp[f]=1$ | $dp[g]=2$ | `"fg"` |
| ⑤ | `b` | 1 | $[0,3]$：a..d | $dp[c]=2$ | $dp[b]=3$ | `"acb"`（绕开够不着的 `"fg"`） |
| ⑥ | `d` | 3 | $[1,5]$：b..f | $dp[b]=3$ | $dp[d]=4$ | `"acbd"` |

最终 `ans = dp[d] = 4`，对应位次序列 $0, 2, 1, 3$，相邻差 $2, 1, 2$ 均 $\le 2$。

> ⚠️ **第 ⑤ 步就是单线贪心的翻车点**：此刻全局最长为 2（`"ac"` 与 `"fg"` 并列），但 $|g - b| = 5 > 2$，`"fg"` 这条线接不住 `b`；邻域 $[0,3]$ 内的最大来自 $dp[c] = 2$（`"ac"`），于是 `"acb"` 在 `b` 桶诞生。**每桶各留一条最长**的 dp 状态，把这层"分线追踪"完全自动化了。

## 4. 算法细节

1. **状态语义绑定扫描顺序**：`dp[c]` 是"**已扫描前缀**中以 $c$ 结尾的最长长度"，因此必须**从左到右**单遍扫描——处理 $s_i$ 时读到的都是"只含 $s_i$ 之前字符"的旧值，这是转移正确性的前提（见 §5 定理）。
2. **邻域夹断**：$c_i - k$ 可为负、$c_i + k$ 可超过 25，必须 `max(0, ci-k)` / `min(25, ci+k)`。C++ 里不夹断直接当数组下标是未定义行为；Python 的 `dp[lo:hi+1]` 若 `lo` 为负，切片会从**尾部**数起，不报错但答案悄悄错掉。
3. **先读后写**：`best` 必须用**写入前**的 `dp`（含 `dp[ci]` 旧值）参与计算。若一边扫邻域一边就地更新 `dp[ci]`，可能把 $s_i$ 自己重复计入。
4. **覆盖即提升**：邻域含 $c_i$ 自身 ⇒ 新值 $\ge dp_{\text{旧}}[c_i] + 1$ 恒严格更大，`dp[ci] = best + 1` 直接覆盖即可（写成 `max(dp[ci], best+1)` 结果相同，只是多余）。
5. **答案的收集时机**：写完 `dp[ci]` 立即 `ans = max(ans, dp[ci])`。每个槽只在"其字母出现时"被写入且值只增不减，故终值一定在最后一次写入时被 `ans` 捕获，结尾无需再扫 `max(dp)`（扫了也不错）。
6. **常数账**：$n(2k+1) \le 10^5 \times 51 \approx 5.1 \times 10^6$ 次比较，C++ 十几毫秒；Python 把内层交给切片 `max(dp[lo:hi+1])` 的 C 实现，同样轻松。
7. **不必上更高级的结构**：值域 26、邻域至多 51，线性扫描已是常数级。若字符集推广到大值域（如 $[-10^9, 10^9]$ 的整数、$k$ 也大），才需要离散化 + 线段树/树状数组做"区间最大 + 单点写入"，转移 $O(\log U)$。

## 5. 正确性证明

对 $0 \le i \le n$，记 $D_i[c]$（$c \in [0,25]$）为 $s[0..i)$ 中以字母 $c$ 结尾的理想子序列的最大长度（不存在则为 0）。显然 $D_0[c] \equiv 0$。

**引理 1**（接尾判定 / 无后效性）：理想子序列 $t$ 与字符 $x$ 的拼接 $t \cdot x$ 是理想子序列，当且仅当 $t$ 为空或 $|t_{\text{末}} - x| \le k$。

**证明**：理想性是对**所有相邻对**的约束。拼接只新增一个相邻对 $(t_{\text{末}}, x)$，原有相邻对的合法性不变；$t$ 为空时没有相邻对，条件空真成立。∎

**引理 2**（转移公式）：设 $c_x$ 为 $s_i$ 的编码，则对一切 $c$：

$$D_{i+1}[c] = D_i[c] \quad (c \ne c_x); \qquad D_{i+1}[c_x] = 1 + \max_{|c - c_x| \le k} D_i[c]$$

**证明**：

- **$c \ne c_x$**：$s[0..i+1)$ 中以字母 $c$ 结尾的子序列，其末字符不能嵌在位置 $i$（该位置是字母 $c_x \ne c$），故整个子序列落在 $s[0..i)$ 内；反过来，$s[0..i)$ 的任何子序列也是 $s[0..i+1)$ 的子序列。两个集合相同，最大长度相等。
- **$c_x$，记 $M = \max_{|c - c_x| \le k} D_i[c]$**：
  - **$\ge$（构造）**：若 $M = 0$，单字符子序列 $s_i$ 给出下界 $1 = M + 1$。若 $M \ge 1$，取达到 $M$ 的字母 $c^*$ 及对应的理想子序列 $t^*$（$s[0..i)$ 中以 $c^*$ 结尾、长度 $M$），把 $s_i$ 嵌在位置 $i$ 接在其后：$t^* \cdot s_i$ 是 $s[0..i+1)$ 的子序列，由引理 1 及 $|c^* - c_x| \le k$ 知其理想，长度 $M + 1$。
  - **$\le$（剪枝，即"支配性"的严谨化）**：设 $t$ 是 $s[0..i+1)$ 中以字母 $c_x$ 结尾的最长理想子序列，$|t| = L$。若 $L = 1$，则 $L \le 1 + M$ 显然。若 $L \ge 2$，取 $t$ 的一个合法嵌入，其末字符（字母 $c_x$）位于某位置 $p \le i$；去掉末字符得 $t'$，它是理想子序列（理想性对子列保持），以某字母 $c'$ 结尾，且由引理 1 知 $|c' - c_x| \le k$。$t'$ 完整嵌在 $s[0..p) \subseteq s[0..i)$ 内，故 $D_i[c'] \ge L - 1$，于是 $L \le 1 + D_i[c'] \le 1 + M$。∎

**定理**（实现不变式）：算法从左到右处理每个字符，处理 $s_i$ 时先以**写入前**的 `dp` 数组计算邻域最大 `best`，再执行写回 `dp[c_i] = best + 1`；则处理完 $s[0..i)$ 后，对一切 $c$ 有 $dp[c] = D_i[c]$。

**证明**：对 $i$ 强归纳。$i = 0$：`dp` 全 0，等于 $D_0$。设处理完 $s[0..i)$ 后不变式成立。处理 $s_i$ 时代码读取的是**写入前**的数组，由归纳假设它等于 $D_i$，故 $\text{best} = \max_{|c - c_x| \le k} D_i[c] = M$；写回只改动槽 $c_x$，其余槽保持 $D_i[c] = D_{i+1}[c]$（引理 2 前半），槽 $c_x$ 的新值为 $M + 1 = D_{i+1}[c_x]$（引理 2 后半）。故处理完 $s[0..i+1)$ 后 `dp` $= D_{i+1}$。∎

**推论**：算法返回值 `ans` 等于全串最长理想子序列的长度。

**证明**：任何非空理想子序列以某个字母 $c$ 结尾，其长度 $\le D_n[c]$，而 $D_n[c]$ 本身可由某条子序列达到，故最优解 $= \max_c D_n[c]$。

- **上界**：`ans` 的每次取值都是某时刻的 $dp[c_i] = D_i[c_i]$，对应一条真实存在的理想子序列（也是全串的子序列），故 `ans` $\le$ 最优。
- **下界**：任一槽 $c$ 的终值 $D_n[c]$ 在字母 $c$ **最后一次出现**被处理时写入，随即被 `ans` 捕获，且 `ans` 单调不减，故最终 `ans` $\ge \max_c D_n[c]$。

两者夹逼，`ans` $= \max_c D_n[c] =$ 最优解。∎

## 6. 复杂度分析

- **时间复杂度**：$O\big(n \cdot (2k+1)\big)$，上界 $10^5 \times 51 \approx 5.1 \times 10^6$。每个字符做一次长度 $\le 2k+1$ 的邻域扫描；对比指数枚举的 $2^n$ 与下标 DP 的 $O(n^2) \approx 10^{10}$。
- **空间复杂度**：$O(|\Sigma|) = O(26)$，即 26 个整型槽加常数个变量，视作 $O(1)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int longestIdealString(string s, int k) {
        int dp[26]{};
        int ans = 0;
        for (char ch : s) {
            int ci = ch - 'a';
            int lo = max(0, ci - k), hi = min(25, ci + k);
            int best = 0;
            for (int c = lo; c <= hi; ++c)
                best = max(best, dp[c]);   // 读写入前的旧值
            dp[ci] = best + 1;              // 邻域含自身，覆盖即提升
            ans = max(ans, dp[ci]);
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def longestIdealString(self, s: str, k: int) -> int:
        dp = [0] * 26
        ans = 0
        for ch in s:
            ci = ord(ch) - 97
            lo, hi = max(0, ci - k), min(25, ci + k)
            best = max(dp[lo:hi + 1])       # 切片一步取邻域最大
            dp[ci] = best + 1
            ans = max(ans, dp[ci])
        return ans
```

> 💡 两份代码都遵循"**先读后写**"：`best` 用写入前的数组算出，$+1$ 之后才写回 `dp[ci]`。Python 的切片 `dp[lo:hi+1]` 长度恒在 $[1, 51]$（邻域总含 `ci` 自身，夹断后至少一个元素），`max` 不会作用在空切片上。

## 8. 边界情况与易错点

1. **子序列 ≠ 子串**：字符可以跳着选。若误按"连续子串"做（双指针/滑动窗口），示例 1 的 `"acbd"` 根本取不出来，全盘皆错。
2. **$O(n^2)$ 情结**：LIS 式下标 DP 正确但 $10^{10}$ 必 TLE；看见"值域只有 26"要立刻想到按值建桶。
3. **邻域夹断**：`ci-k` 可负、`ci+k` 可超 25。C++ 负下标是 UB；Python 负 `lo` 让切片从尾部数起，**静默**出错（不报错、答案错）。
4. **先读后写**：一边扫邻域一边就地更新 `dp[ci]`，会把当前字符重复计入。
5. **k = 0 退化**：只能接同字母，答案 = 出现最多的字母频次（可当对拍基准）。例：`"abcdcba", k=0 → 2`。
6. **k ≥ 25 全通**：任意两个小写字母位次差 $\le 25 \le k$，任何子序列都理想，答案 = $n$。
7. **字母表不循环**：`"az"` 的位次差是 25 不是 1；`k = 24` 时 `"az"` 的答案是 1。
8. **n = 1 最小输入**：答案 1，循环体执行一次、邻域夹断正确即自然通过。
9. **答案收集**：只在最后返回 `max(dp)` 也可以，但"直接返回 `dp[ci]`（最后一个字符的槽值）"是错的——最优子序列未必以 $s_{n-1}$ 结尾（示例 1 恰以 `d` 结尾纯属巧合，`"abz"` 型输入立即翻车）。

- [2369. 检查数组是否存在有效划分](https://leetcode.cn/problems/check-if-there-is-a-valid-partition-for-the-array/)：同场 Q3，同为"窗口形状由题面单元决定"的线性 DP（那边是段长集合 $\{2,3\}$，这边是邻域半径 $k$）。
- [每日题解 2370. 最长理想子序列](../../solution/2301-2400/2370_最长理想子序列.md)：同题的每日一题视角（面试向展开与"信息压缩"的马尔可夫性讨论）。

**延伸思考**：

- **输出具体方案**：给每个槽配一条父指针（写入时记录"来源槽 + 当前位置"），从终值最大的槽回溯即得一条具体的最长理想子序列，仍 $O(n)$。
- **值域放大**：若字符集换成 $[-10^9, 10^9]$ 的整数且 $k$ 很大，朴素邻域扫描退化为 $O(nU)$；离散化后用线段树做"区间最大 + 单点写入"，转移 $O(\log n)$，总 $O(n \log n)$。
- **相邻差恰为 $k$ / 恰为 $d$**：邻域从区间缩成至多两个点（$c-k$ 与 $c+k$），转移 $O(1)$，回到 1218 式单点前驱。
- **流式 / 在线版本**：算法天然单遍扫描、状态只有 26 个整数，可直接用于字符流——每到达一个字符就更新一次，随时能回答"到目前为止的最长理想子序列长度"。
