# LeetCode 受限条件下可到达节点的数目 题解

## 1. 题目概述

- **标题 / 题号**：受限条件下可到达节点的数目（#2368，medium）
- **链接**：https://leetcode.cn/problems/reachable-nodes-with-restrictions/
- **来源**：LeetCode 第 305 场周赛 Q2
- **难度**：中等
- **标签**：树、深度优先搜索、广度优先搜索、并查集、图、哈希表

**题意**：给定一棵 $n$ 个节点（编号 $0 \sim n-1$，$n-1$ 条边）的**无向树**，以及一组**受限节点** `restricted`。从节点 $0$ 出发走边，**不允许经过任何受限节点**，问最多能到达多少个**不同节点**（节点 $0$ 本身也算）。

**约束**：

- $2 \le n \le 10^5$
- `edges.length` $= n - 1$，且 `edges` 表示一棵**有效的树**（无环、连通）
- $1 \le \text{restricted.length} < n$，值互不相同，且**不含节点 $0$**

## 2. 示例

**示例 1**

```text
输入：n = 7, edges = [[0,1],[1,2],[3,1],[4,0],[0,5],[5,6]], restricted = [4,5]
输出：4
解释：从 0 出发，1/2/3 可达；4、5 受限不能进入，
     6 的唯一路径 0→5→6 必经受限点 5，也不可达。
     可达集合 {0,1,2,3}，共 4 个。
```

**示例 2**

```text
输入：n = 7, edges = [[0,1],[0,2],[0,5],[0,4],[3,2],[6,5]], restricted = [4,2,1]
输出：3
解释：0 的四个邻居中 1、2、4 受限，只有 5 可进；
     6 挂在 5 下，可达。可达集合 {0,5,6}，共 3 个。
```

**示例 3**（自构造：受限点全堵在起点旁）

```text
输入：n = 4, edges = [[0,1],[1,2],[1,3]], restricted = [1]
输出：1
解释：节点 1 是唯一的"出口"，被限制后 2、3 整体失联，
     只剩下起点 0 自己，答案保底为 1。
```

## 3. 解题思路

### 3.1 暴力思路：逐点找路径

最朴素的想法：对每个节点 $v$，在树上求出 $0 \to v$ 的路径，检查路径上是否含受限点，是则 $v$ 不可达。逐点判一次为 $O(n)$，总共 $O(n^2)$——$n = 10^5$ 时约 $10^{10}$ 次操作，必然超时。

它的问题在于把「连通性」当成了 $n$ 个**独立的**判定问题反复求解，而实际上所有节点的可达性共享同一套结构：**从 0 出发能走到的那一片连通区域**，一次遍历就能全部收割。

### 3.2 核心观察：受限点是"路障"，挡住的是整棵子树

![核心观察：受限节点是路障，挡住背后整棵子树](images/2368_restricted_subtree_concept.svg)

树有一个区别于一般图的本质性质：**任意两点之间的简单路径唯一**。于是受限点的作用就像公路上的路障——它挡住的不只是自己这个点，还有**它背后唯一一条路通向的所有节点**：若 $0 \to v$ 的唯一路径必经某个受限点 $x$，那么 $v$ 彻底不可达，**没有任何绕行的可能**。

等价地看：把所有受限点从树中**删掉**，树碎成若干个连通块，答案就是 **$0$ 所在连通块的大小**（节点 0 永不受限，该块非空）。求一个连通块的大小，一次 BFS / DFS 就够了：

$$\text{ans} = \big|\,\text{component}(0)\ \text{in}\ T - \text{restricted}\,\big|$$

> 💡 转化的收益：从「每个点独立判定路径」变成「一次遍历求连通块」，复杂度从 $O(n^2)$ 直接到 $O(n)$。树给出两个赠品：**无环**（不需 visited 也不会死循环，用父指针即可）与**路径唯一**（路障效应成立）。若输入是一般无向图，路障效应不成立（可绕行），但「删点后求 $0$ 所在连通块」的框架依然正确。

### 3.3 算法流程：BFS 一把梭

![算法流程：标记受限、建图、BFS 主循环、返回](images/2368_bfs_flow.svg)

1. **标记受限**：`restricted` 转成布尔数组 `ban[]`（或哈希集合），保证 $O(1)$ 查询；
2. **建邻接表**：`edges` 无向，`g[a]`、`g[b]` 双向加边；
3. **BFS**：队列初始化为 $[0]$，`vis[0] = true`；每次出队 `u` 计数 `ans++`，遍历 `u` 的邻居 `v`——若 `v` 未访问且不受限，则标记并入队；受限点**不入队、不计数、不扩展**；
4. **队空返回** `ans`。

受限点被"拦在门外"，其身后的子树自然无人递达，无需任何显式删除操作。

### 3.4 示例演算

![示例演算：restricted={4,5} 时从 0 出发的 BFS 过程](images/2368_example_walkthrough.svg)

对示例 1 逐步走查（`ban = {4,5}`）：$0$ 出队时邻居 $1$ 入队、$4/5$ 被拦截；$1$ 出队时邻居 $2,3$ 入队；此后 $2,3$ 的邻居都已访问，无新点入队。队列清空，`ans = 4` ✓。可以看到节点 $6$ **从未被检查**——它唯一的入口 $5$ 是路障，整条子树在遍历中根本没被触碰。

## 4. 算法细节

1. **受限标记必须 $O(1)$ 查询**：`restricted` 先转成 `bool ban[n]` 数组（C++）或 `set`（Python）。切忌遍历时对 `restricted` 列表做线性 `in` 判断——$n$ 个点 $\times$ $O(n)$ 查找 = $O(n^2)$，$n = 10^5$ 下直接 TLE。
2. **无向边双向建**：`g[a].push_back(b)` 与 `g[b].push_back(a)` 成对出现，漏写一半图直接断链。
3. **用 visited 判重**：BFS 中 $u$ 的邻居 $v$ 的邻居又包含 $u$，没有 `vis` 会反复入队。树中也可以只记父节点代替 `vis`，但 `vis` 数组写法更通用、更不易错。
4. **迭代而非递归**：$n \le 10^5$ 且树可能是链形，深度达 $10^5$ 层。Python 默认递归上限 1000，递归 DFS 必爆栈（`RecursionError`）；C++ 递归 $10^5$ 层也逼近默认栈限额。**BFS 或显式栈 DFS 最稳**。
5. **并查集替代方案**：遍历所有边，**两端都不受限**才 `union(a, b)`（受限点不与任何点合并，保持孤立）；最后答案为满足 $\text{find}(i) = \text{find}(0)$ 的 $i$ 的个数。注意不能只统计 $0$ 所在集合的 `size`——受限点也在并查集数组里但不在任何集合中，逐点 `find` 比较才正确。

## 5. 正确性证明

**引理 1**（路径唯一性）：树中任意两点 $u, v$ 之间的简单路径唯一。

**证明**：树是无环连通图。若存在两条不同的 $u \to v$ 简单路径 $P_1 \ne P_2$，取 $P_1 \cup P_2$ 中第一条分叉到最后一条重合的片段，得到一个环，与树无环矛盾。∎

**引理 2**（可达刻画）：节点 $v$ 从 $0$ 可达（存在不经过受限点的行走路线）$\iff$ $0 \to v$ 的唯一简单路径上不含受限点。

**证明**：

- **充分性**：该路径本身每个中间点都非受限，沿路径逐步走即是合法路线。
- **必要性**：设 $0 \to v$ 的唯一路径 $P$ 上有受限点 $x$。若 $x = v$，则 $v$ 自身受限，任何以 $v$ 为终点的路线都访问 $v$，不合法。若 $x$ 是 $P$ 的内点：删去 $x$ 后树分裂成 $\deg(x)$ 个连通块，$P$ 上 $x$ 的前驱与后继分属**不同**块（否则绕过 $x$ 仍有路径，与引理 1 矛盾），而 $0$ 与 $v$ 分别在这两个方向上，故 $T - x$ 中 $0$、$v$ 不连通。任何行走路线若避开 $x$，则其经过的点全落在 $T - x$ 的某个块内，无法从 $0$ 的块跨到 $v$ 的块；若经过 $x$ 则违反受限约束。故 $v$ 不可达。∎

**定理**：设 $R$ 为从树 $T$ 中删除全部受限点后，$0$ 所在连通块的节点集合，则 BFS 算法的返回值恰为 $|R|$。

**证明**：

- **不重**：`vis[v] = true` 与入队同时发生，每个节点至多入队一次；`ans` 仅在出队时自增，且每个节点至多出队一次，故每个被计数的节点恰好贡献 $1$。
- **不漏也不多**：对 BFS 访问集 $S$ 归纳。（i）$S \subseteq R$：起点 $0$ 非受限（题目保证）故 $0 \in R$；入队的邻居 $v$ 满足非受限且与已入队点相邻，归纳可知 $S$ 中任意点与 $0$ 在删点后的图中连通，即 $S \subseteq R$。（ii）$S = R$：反设 $S \ne R$，因 $R$ 连通且 $S$ 非空，必存在边 $(u, w)$，$u \in S$，$w \in R \setminus S$。$u$ 出队时会检查 $w$：$w$ 非受限（$w \in R$）、未被标记（$w \notin S$），于是 $w$ 被入队，$w \in S$，矛盾。故 $S = R$，返回值 $= |S| = |R|$。

又由引理 2，$R$ 恰为全部可达节点组成的集合（$R$ 内任意 $v$：$0 \to v$ 路径全在 $R$ 内故无受限点，可达；$R$ 外任意 $v$：其路径必经受限点，不可达）。算法正确。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。建标记与邻接表各遍历一次输入（$n-1$ 条边）；BFS 中每个节点至多入队、出队各一次，每条无向边至多被两端各检查一次，合计 $O(n + (n-1)) = O(n)$。
- **空间复杂度**：$O(n)$。邻接表存 $2(n-1)$ 条有向边，`ban`、`vis` 数组与队列各 $O(n)$。并查集写法额外需要 $O(n)$ 的父数组（路径压缩 + 按秩合并时单次均摊 $O(\alpha(n))$，总复杂度 $O(n\,\alpha(n))$，实践中视作 $O(n)$）。

## 7. 参考代码

### C++（BFS）

```cpp
class Solution {
public:
    int reachableNodes(int n, vector<vector<int>>& edges, vector<int>& restricted) {
        vector<vector<int>> g(n);
        for (auto& e : edges) {
            g[e[0]].push_back(e[1]);
            g[e[1]].push_back(e[0]);
        }
        vector<bool> ban(n, false), vis(n, false);
        for (int v : restricted) ban[v] = true;

        queue<int> q;
        q.push(0);
        vis[0] = true;
        int ans = 0;
        while (!q.empty()) {
            int u = q.front(); q.pop();
            ++ans;
            for (int v : g[u]) {
                if (!vis[v] && !ban[v]) {
                    vis[v] = true;
                    q.push(v);
                }
            }
        }
        return ans;
    }
};
```

### C++（并查集）

```cpp
class Solution {
public:
    vector<int> fa;
    int find(int x) {
        while (fa[x] != x) x = fa[x] = fa[fa[x]];
        return x;
    }
    int reachableNodes(int n, vector<vector<int>>& edges, vector<int>& restricted) {
        vector<bool> ban(n, false);
        for (int v : restricted) ban[v] = true;
        fa.resize(n);
        iota(fa.begin(), fa.end(), 0);
        for (auto& e : edges) {
            if (!ban[e[0]] && !ban[e[1]]) fa[find(e[0])] = find(e[1]);
        }
        int root0 = find(0), ans = 0;
        for (int i = 0; i < n; ++i) ans += (find(i) == root0);
        return ans;
    }
};
```

### Python（BFS，迭代防爆栈）

```python
class Solution:
    def reachableNodes(self, n: int, edges: List[List[int]], restricted: List[int]) -> int:
        g = [[] for _ in range(n)]
        for a, b in edges:
            g[a].append(b)
            g[b].append(a)
        ban = set(restricted)
        vis = [False] * n
        vis[0] = True
        q = deque([0])
        ans = 0
        while q:
            u = q.popleft()
            ans += 1
            for v in g[u]:
                if not vis[v] and v not in ban:
                    vis[v] = True
                    q.append(v)
        return ans
```

## 8. 边界情况与易错点

1. **递归爆栈**：$n \le 10^5$，链形树深度 $10^5$。Python 递归 DFS 直接 `RecursionError`（默认上限 1000）；C++ 递归也逼近默认栈深。**必须用 BFS 或显式栈**，赛场上这题最经典的 WA/RE 就是递归写挂。
2. **受限点查询写法**：`v in restricted`（列表）是 $O(n)$ 查询，整体 $O(n^2)$ 会 TLE；先转 `ban` 布尔数组或哈希集合。
3. **答案保底为 1**：节点 $0$ 不受限且一定计入，最小答案就是 1（如 $n=4$、`restricted=[1]`、$1$ 是唯一出口的链）。不要把起点漏数。
4. **双向建边**：无向边只加单向，遍历会提前断掉，答案是错误的小值。
5. **并查集版统计**：不能只看 `size[find(0)]`——受限点虽不参与合并但仍占着下标，答案必须逐点 `find(i) == find(0)` 计数；合并时两端**任一**受限都跳过，让受限点彻底孤立。
6. **`vis` 与 `ban` 缺一不可**：只判 `ban` 会把父节点再入队，队列指数膨胀；只判 `vis` 不判 `ban` 会把受限点放进来，答案偏大。
7. **`edges` 为空**：约束下 $n \ge 2$ 恒有 $n - 1 \ge 1$ 条边，但树遍历模板要保证空邻接表也自然工作（BFS 出队 $0$ 后直接结束，返回 1）。
