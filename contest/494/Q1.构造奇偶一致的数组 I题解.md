# LeetCode 构造奇偶一致的数组 I 题解

## 1. 题目概述

- **标题 / 题号**：构造奇偶一致的数组 I（#3875，easy）
- **链接**：https://leetcode.cn/problems/construct-uniform-parity-array-i/
- **来源**：LeetCode 第 494 场周赛 Q1
- **难度**：简单
- **标签**：数组、数学

**题意**：给定长度为 $n$ 的数组 `nums1`，其中整数互不相同。需要构造长度为 $n$ 的数组 `nums2`，使其元素**全为奇数或全为偶数**。每个下标 $i$ 必须**二选一**（顺序不限）：

- `nums2[i] = nums1[i]`（保留原值）；
- `nums2[i] = nums1[i] - nums1[j]`，其中 $j \ne i$（减去另一个元素，$j$ 任选）。

若能构造出满足条件的数组返回 `true`，否则返回 `false`。

**约束**：

- $1 \le n \le 100$
- $1 \le nums1[i] \le 100$
- 所有整数互不相同

> 💡 两个关键点藏在题面里：**减法结果可以为负**（示例 1 出现 $-1$，说明不要求非负）；**同一个 $j$ 可以被多个下标重复使用**（题面只说 $j \ne i$，未限制 $j$ 互异）。这两点正是本题恒有解的前提。

## 2. 示例

**示例 1**

```text
输入：nums1 = [2,3]
输出：true
解释：nums2[0] = nums1[0] - nums1[1] = 2 - 3 = -1（奇数）
      nums2[1] = nums1[1] = 3（奇数）
      nums2 = [-1, 3]，全为奇数。
```

**示例 2**

```text
输入：nums1 = [4,6]
输出：true
解释：nums2 = [4, 6]，全为偶数（全部保留原值）。
```

**示例 3（自制，覆盖混合情况）**

```text
输入：nums1 = [2,4,5]
输出：true
解释：奇数 5 保留；两个偶数都减去奇数 5（偶−奇=奇）：
      nums2 = [2-5, 4-5, 5] = [-3, -1, 5]，全为奇数。
```

## 3. 解题思路

### 3.1 暴力思路

每个下标有 $n$ 种选法（1 种保留 + $n-1$ 种减法），全体组合共 $n^n$ 种，逐一检查每种组合是否全奇/全偶。$n = 100$ 时是天文数字，不可行。

**第一次化简——只看奇偶**：目标只关心奇偶性，具体数值无关紧要，因此只需知道每个下标能取到哪些**奇偶值**。

**第二次化简——选择互相独立**：`nums1` 全程不变，且 $j$ 可重复使用，一个下标选什么完全不影响其他下标可选什么。设 $a_i$ 为 `nums1[i]`、$p_i = a_i \bmod 2$，则每个下标的可达奇偶集合为

$$S_i = \{p_i\} \cup \{\,(a_i - a_j) \bmod 2 : j \ne i\,\} = \{p_i\} \cup \{p_i \oplus p_j : j \ne i\}$$

答案为 `true` 当且仅当存在公共奇偶值 $t \in \bigcap_i S_i$（全体取奇或全体取偶）。这一步把复杂度降到 $O(n^2)$，已经可以通过。

### 3.2 核心观察：答案恒为 true

对奇偶分布做分类讨论，会发现三种情况**全部可行**：

![分类讨论：三种奇偶分布都能构造](images/uniform_parity_i_concept.svg)

- **全偶**（含 $n=1$ 且元素为偶）：全部保留，`nums2` 全偶；
- **全奇**（含 $n=1$ 且元素为奇）：全部保留，`nums2` 全奇；
- **混合**（至少一奇一偶）：**奇数全部保留，每个偶数减去任意一个奇数**。由「偶 $-$ 奇 $=$ 奇」，`nums2` 全奇。

三种情况穷尽了所有输入，因此答案恒为 `true`——这本质上是一道**构造性证明题**，提交代码只需一行 `return true`。

### 3.3 算法流程

```text
输入 nums1
  ├─ 全偶 → 全部保留原值 → nums2 全偶 ✓
  ├─ 全奇 → 全部保留原值 → nums2 全奇 ✓
  └─ 混合 → 奇数保留、偶数减去任一奇数 → nums2 全奇 ✓
输出 true
```

### 3.4 示例演算

以混合情况 `nums1 = [2, 4, 5]` 为例走一遍构造：

| 下标 i | nums1[i] | 奇偶 | 选择 | nums2[i] | 奇偶 |
|--------|----------|------|------|----------|------|
| 0 | 2 | 偶 | $2 - 5$（减奇数 5） | $-3$ | 奇 |
| 1 | 4 | 偶 | $4 - 5$（减奇数 5） | $-1$ | 奇 |
| 2 | 5 | 奇 | 保留 $5$ | $5$ | 奇 |

`nums2 = [-3, -1, 5]` 全奇 ✓。注意下标 0、1 共用了同一个 $j = 2$（元素 5），这是允许的。

![示例演算：混合情况构造全奇数组](images/uniform_parity_i_example.svg)

## 4. 算法细节

1. **奇偶运算规则**：$a - b \equiv a + b \pmod 2$，差的奇偶由两者是否同奇偶决定——同奇偶相减得偶，异奇偶相减得奇。
2. **可达奇偶集合**：$S_i = \{p_i\} \cup \{p_i \oplus p_j : j \ne i\}$，其中 $p_k = nums1[k] \bmod 2$。保留永远可行（$p_i \in S_i$），减法则能翻转奇偶（当且仅当存在异奇偶的 $j$）。
3. **独立性是关键**：$j$ 可重复使用，所以混合情况下每个偶数都能各自找到奇数作减数；若 $j$ 要求互异，就变成需要 Hall 定理分析的匹配问题。
4. **实现取舍**：分类讨论的结论是恒真，提交 `return true` 即可。若不放心，可写 $O(n^2)$ 的可达集合交版本做对拍验证。

## 5. 正确性证明

**引理 1**（减法奇偶规则）：对整数 $a$、$b$，$a - b$ 为奇数当且仅当 $a$、$b$ 奇偶性不同。

**证明**：模 2 意义下 $-b \equiv b$，故 $a - b \equiv a + b \pmod 2$。若 $a$、$b$ 同奇偶，则 $a + b$ 为偶；否则 $a + b$ 为奇。∎

**引理 2**（混合情况的可执行性）：若 `nums1` 中既有奇数又有偶数，则对任意偶数下标 $i$，存在奇数下标 $j$ 满足 $j \ne i$。

**证明**：混合保证存在奇数 `nums1[j]`。若 $i$ 为偶数下标，则 `nums1[i]` 为偶而 `nums1[j]` 为奇，二者必为不同元素、不同下标，故 $j \ne i$。∎

**定理**：对任意满足约束的输入，答案均为 `true`。

**证明**：按 `nums1` 的奇偶分布分类：

- **所有元素同奇偶**（含 $n = 1$ 的情形）：每个下标都选保留，得 `nums2 = nums1`，其元素奇偶性一致，合法。
- **既有奇数又有偶数**：奇数下标选保留，得奇数；偶数下标 $i$ 由引理 2 取奇数下标 $j$，选 `nums2[i] = nums1[i] - nums1[j]`，由引理 1 该值为奇数。故 `nums2` 全奇，合法。

两类情况覆盖所有输入且均给出合法构造，故答案恒为 `true`。∎

## 6. 复杂度分析

- **时间复杂度**：$O(1)$，直接返回；即使显式构造 `nums2` 也仅 $O(n)$。
- **空间复杂度**：$O(1)$，无需额外空间。

附：显式构造 `nums2` 的验证版本（本地对拍用，佐证证明中的构造）：

```python
def construct(nums1: list[int]) -> list[int]:
    odd = next((x for x in nums1 if x % 2 == 1), None)
    if odd is None or all(x % 2 == 0 for x in nums1):
        return nums1[:]  # 全偶或全奇（含 n=1）：直接保留
    # 混合：奇数保留，偶数减去任一奇数（偶−奇=奇）
    return [x if x % 2 == 1 else x - odd for x in nums1]
```

## 8. 边界情况与易错点

1. **n = 1**：不存在 $j$，只能保留原值；单元素数组天然「全奇或全偶」，仍返回 `true`，勿特判为 `false`。
2. **减法结果为负**：示例 1 的 $-1$ 表明允许负数，不要画蛇添足加绝对值或非负校验（那正是 Q2 的限制）。
3. **nums2 元素可重复**：如 `[1, 1, 3]` 合法，题目只要求奇偶一致，不要求互不相同。
4. **j 可重复使用**：多个下标可以减同一个 `nums1[j]`，这是混合情况构造成立的前提，也是本题与「匹配问题」的分界线。
5. **思维陷阱**：把签到题想复杂（状压 DP、二分图匹配）是最容易踩的坑——「只看奇偶 + 各下标独立」两步就能把问题化没。比赛时应先用小样例快速验证「恒真」猜想，再放心提交一行代码。
