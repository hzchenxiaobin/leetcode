# LeetCode 使两个整数相等的数位操作 题解

## 1. 题目概述

- **标题 / 题号**：使两个整数相等的数位操作（#3377，medium）
- **链接**：https://leetcode.cn/problems/digit-operations-to-make-two-integers-equal/
- **来源**：LeetCode 第 145 场双周赛 Q3
- **难度**：中等
- **标签**：图、最短路、堆（优先队列）、数学、数论

**题意**：给定两个**数位数目相同**的整数 $n$ 与 $m$。可以任意次执行：

- 选中 $n$ 的某一位数字，若它**不是 9**，把它**加 1**；
- 选中 $n$ 的某一位数字，若它**不是 0**，把它**减 1**。

任意时刻（包括起点与终点）这个数都**不能是质数**。一次完整变换的**代价**是过程中经过的**所有**数值之和（含起点、含终点）。求把 $n$ 变成 $m$ 的最小代价，做不到返回 $-1$。

**约束**：

- $1 \le n, m < 10^4$
- $n$ 与 $m$ 的数位数目相同

> ⚠️ **建模关键（务必看）**：题面保证 $n$ 与 $m$ 数位数目相同，实际操作中首位若从 1 减到 0 会丢掉最高位、数位数目改变，这已超出题面讨论的范围。示例 2（$n = 4, m = 8$ 输出 $-1$）明确说明**只能在「与 $n$ 数位相同的数」之间移动**：数字 4 的邻居只有 3 和 5，都是质数，因此无解；若允许首位变 0，$4 \to 14 \to 24 \to \cdots \to 8$ 就能走通，答案不会是 $-1$。实现中必须把状态限制在 $[10^{d-1},\,10^{d}-1]$。

## 2. 示例

**示例 1**

```text
输入：n = 10, m = 12
输出：85
解释：10 → 20 → 21 → 22 → 12，五步数值分别为 10、20、21、22、12，
      20 / 21 / 22 / 12 均为合数，代价 10 + 20 + 21 + 22 + 12 = 85。
```

**示例 2**

```text
输入：n = 4, m = 8
输出：-1
解释：4 只有一位。把这一位 +1 得 5（质数，禁止），-1 得 3（质数，禁止），
      所有邻居都被封死，无法移动，故无解。
```

**示例 3**

```text
输入：n = 6, m = 2
输出：-1
解释：6 → 5 是质数、6 → 7 是质数，且目标 2 本身就是质数。
      注意「终点也不能是质数」是硬约束，即使能走通也不允许以质数收尾。
```

**示例 4（自造，考察起点就是质数）**

```text
输入：n = 13, m = 12
输出：-1
解释：起点 13 是质数，题目要求「一开始 n 不能是质数」，直接无解。
```

## 3. 解题思路

### 3.1 暴力思路

每一步有至多 $8$ 种操作（$d$ 位各 $\pm 1$），路径长度没有上界，直接 DFS 会无穷展开；即使限定「不重复经过某个数」，路径数也随位数指数爆炸（$d$ 位数最多 $9 \times 10^{d-1}$ 个状态，路径数远超阶乘）。

注意到这不是「求步数最少」而是「求**代价**最少」——每一步的代价是落到的新数值，代价非负且随数值增大而增大，天然适合**最短路**框架。所以真正的建模是把「状态 + 转移 + 边权」写清楚。

### 3.2 核心观察：把状态看成图上的点，边权是「落到的新值」

![把每个数值当成节点：一步数位操作是一条边，边权是目标节点的值](images/bw145_q3_graph_model.svg)

**观察 1（状态就是当前数值）**：操作只依赖「当前数值的各位数字」，与历史无关，因此状态空间就是 $d$ 位整数集合 $V = [10^{d-1}, 10^d - 1]$；其中**质数节点被删除**（不可停留）。

**观察 2（有向边与边权）**：从 $u$ 出发，对每个位权 $p \in \{1, 10, \dots, 10^{d-1}\}$，若该位数字 $<9$ 则可到 $v = u + p$，若 $>0$ 则可到 $v = u - p$（且 $v$ 必须仍在 $V$ 内、非质数）。边权取 $w(u \to v) = v$，因为「代价 = 途径所有数值之和」里新增的正是 $v$ 这一项。

**观察 3（起点要单独计入）**：代价包含起点，所以把 Dijkstra 的初始距离设为 $dist[n] = n$，而不是 $0$。这样 $dist[v]$ 就直接等于「从 $n$ 走到 $v$ 的最小代价（含两端）」，答案即 $dist[m]$。

**观察 4（无解的三种情形）**：起点 $n$ 是质数；终点 $m$ 是质数（不可停留）；$m$ 与 $n$ 不在同一连通块（包括被质数完全封死的孤立点，如示例 2 的 4）。

### 3.3 算法流程

![算法流程：筛质数 → 建隐式图 → 堆优化 Dijkstra](images/bw145_q3_flow.svg)

```text
1. d = n 的数位个数；low = 10^(d-1)，high = 10^d - 1
2. 埃氏筛求 [0, high] 内的质数表 isPrime
3. if isPrime[n]: return -1                      // 起点非法
4. dist[low..high] = INF；dist[n] = n；堆中放 (n, n)
5. while 堆非空:
       弹出 (d_u, u)；若 d_u > dist[u] 则跳过（惰性删除）
       若 u == m: return d_u
       for p in {1, 10, ..., 10^(d-1)}:
            digit = (u / p) % 10
           for delta in {-1, +1}:
               v = u + delta * p
               if v 越界 [low, high] 或 isPrime[v]: continue
               if d_u + v < dist[v]: 松弛并入堆
6. return -1
```

注意图是**隐式**的（不显式存邻接表），$d \le 4$ 时每个点最多 8 条出边，边数 $O(V)$，堆优化 Dijkstra 足够。

### 3.4 示例演算

![示例 1 的走查：10 → 20 → 21 → 22 → 12，代价 85](images/bw145_q3_walkthrough.svg)

$n = 10$，$m = 12$（都是 2 位数，$V = [10, 99]$）。

| 步 | 当前值 | 操作 | 新值 | 新值是否质数 | 累计代价 |
|----|--------|------|------|--------------|----------|
| 0 | 10 | —（起点） | — | 否（$2 \times 5$） | 10 |
| 1 | 10 | 十位 $1 \to 2$ | 20 | 否 | 30 |
| 2 | 20 | 个位 $0 \to 1$ | 21 | 否（$3 \times 7$） | 51 |
| 3 | 21 | 个位 $1 \to 2$ | 22 | 否（$2 \times 11$） | 73 |
| 4 | 22 | 十位 $2 \to 1$ | 12 | 否 | **85** |

为什么不能更便宜？任何一步都要「加一个 $\ge 10$ 的新值」，而 10 的邻居只有 20（11、9 中 11 是质数、9 不是两位数）；20 的邻居里能接近终点的只有 21/30；走到 12 至少需要 4 步，且路径上必然出现 20、21、22 这样的中间值，累计和的下界正好是 85。Dijkstra 在弹出 12 时立刻返回，保证了最优性。

## 4. 算法细节

1. **数位枚举用位权乘除，不用字符串**：`p = 1, 10, 100, 1000`，`digit = (u / p) % 10`，`v = u ± p`。避免字符串拼接带来的额外开销与错误。
2. **越界与质数一起判**：`if (v < low || v > high) continue; if (isPrime[v]) continue;`。$low$ 的检查同时承担「首位不为 0」的职责。
3. **筛法上界**：只需筛到 $high$，而 $high \le 9999$，埃氏筛 $O(high \log\log high)$ 可忽略。
4. **起终点预判**：`isPrime[n]` 直接返回 $-1$；终点 $m$ 若为质数，它根本不在图里，Dijkstra 自然返回 $-1$（无需额外判断，但显式判断能省一次搜索）。
5. **惰性删除**：堆里可能残留旧距离，弹出时比较 `d > dist[u]` 跳过，这是堆优化 Dijkstra 的标准写法。
6. **`dist` 类型**：单条路径代价上界约（点数 $\times$ 最大值）$\approx 9000 \times 9999 \approx 9 \times 10^7$，`int` 足够；用 `long long` 更保险，返回时强转 `int`。
7. **答案包含两端**：这是本题最容易写错的地方。`dist[n] = n` 与「松弛时加 `v`」两者配合，恰好让路径和包含起点与终点；若把 `dist[n]` 初始化为 0，会漏掉 $n$。

## 5. 正确性证明

**引理 1（状态空间封闭）**：若只考虑 $d$ 位数（$[10^{d-1}, 10^d-1]$），则一次合法操作后的值仍是 $d$ 位数；反之题面语义下所有中间值都是 $d$ 位数。

**证明**：位权 $p \le 10^{d-1}$ 的位置加/减 1 只改变该位数字，最高位（$p = 10^{d-1}$）若为 1 且执行减 1，得到 $< 10^{d-1}$ 的数，会被 `v < low` 过滤——这正是「不允许丢失最高位」的实现。其余位置的加减不会改变量级，结果仍落在 $[10^{d-1}, 10^d-1]$。示例 2 说明题面确实要求保持数位数目（否则 $4 \to 8$ 有解）。∎

**引理 2（操作与边一一对应）**：对 $u, v \in V$，$u$ 能一步变成 $v$ 当且仅当存在位权 $p$ 使 $|u - v| = p$ 且 $v$ 非质数。

**证明**：一步操作只改一位，且改动量恰为一个位权 $p$，故 $|u-v| = p$；数字范围 $[0,9]$ 的约束等价于「该位加 1 不越过 9 / 减 1 不越过 0」，在数值上就是 $u + p \le 10^d - 1$ 与 $u - p \ge 10^{d-1}$（该项已由 $v \in V$ 保证）。此外 $u$ 本身必须非质数（否则不在图中、不能作为状态）。∎

**引理 3（路径代价 = 数值和）**：设操作序列为 $u_0 = n, u_1, \dots, u_r = m$，则这次变换的代价为 $\sum_{i=0}^{r} u_i$；在图上对应路径的权为 $\sum_{i=1}^{r} w(u_{i-1}, u_i) = \sum_{i=1}^r u_i$，加上初始距离 $n$ 后两式相等。

**证明**：题面定义代价为「过程经过的所有值之和」；图上每条边权是目标值 $u_i$，故路径权和 $\sum_{i=1}^r u_i$，加上初始化时已经计入的起点 $u_0 = n$，恰为 $\sum_{i=0}^r u_i$。∎

**定理**：算法返回的值等于把 $n$ 变成 $m$ 的最小代价（无解时为 $-1$）。

**证明**：若 $n$ 是质数，由引理 1 的说明（起点也不能是质数）无解，返回 $-1$ 正确。否则由引理 2，所有合法单步操作与图中的边一一对应，由引理 3，一次变换的代价等于对应路径的权和；于是「最小代价变换」$\iff$「最小权路径」，Dijkstra 在非负边权（$w = v > 0$）下求得的最短路权即为最小代价，而答案的 $dist[m] = n + $ 最小路径权，与引理 3 的公式一致。若 $m$ 不可达（含 $m$ 为质数、$m$ 与 $n$ 不同块），返回 $-1$ 亦正确。∎

## 6. 复杂度分析

- **筛质数**：$O(10^d \log \log 10^d)$，$d \le 4$ 时可视为常数（不到 $10^4$）。
- **建图**：隐式建图，不额外存储；每个节点最多 $2d \le 8$ 条出边，故 $|E| = O(d \cdot 10^d)$。
- **Dijkstra**：$O((|V| + |E|) \log |V|)$，其中 $|V| \le 9000$（4 位数）或 $90$（2 位数），实测远小于时限。
- **空间**：$O(10^d)$ 的 `dist` 与质数表，即常数级（$\le 10^4$）。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <queue>
#include <utility>
#include <functional>

using namespace std;

class Solution {
public:
    int minOperations(int n, int m) {
        int digits = 1, high = 9;
        while (high < n) {
            digits++;
            high = high * 10 + 9;
        }
        int low = 1;
        for (int t = 1; t < digits; t++) low *= 10;

        vector<char> isPrime(high + 1, 1);
        isPrime[0] = isPrime[1] = 0;
        for (int i = 2; i * i <= high; i++)
            if (isPrime[i])
                for (int j = i * i; j <= high; j += i) isPrime[j] = 0;
        if (isPrime[n]) return -1;

        const long long INF = (long long)4e18;
        vector<long long> dist(high + 1, INF);
        priority_queue<pair<long long, int>, vector<pair<long long, int>>, greater<pair<long long, int>>> pq;
        dist[n] = n;
        pq.push({n, n});
        while (!pq.empty()) {
            auto [d, u] = pq.top();
            pq.pop();
            if (d > dist[u]) continue;
            if (u == m) return (int)d;
            for (int p = 1; p <= high; p *= 10) {
                int digit = (u / p) % 10;
                for (int delta = -1; delta <= 1; delta += 2) {
                    int nd = digit + delta;
                    if (nd < 0 || nd > 9) continue;
                    int v = u + delta * p;
                    if (v < low || v > high) continue;
                    if (isPrime[v]) continue;
                    if (d + v < dist[v]) {
                        dist[v] = d + v;
                        pq.push({dist[v], v});
                    }
                }
            }
        }
        return -1;
    }
};
```

### Python

```python
import heapq

class Solution:
    def minOperations(self, n: int, m: int) -> int:
        digits = len(str(n))
        low = 10 ** (digits - 1)
        high = 10 ** digits - 1

        is_prime = [True] * (high + 1)
        is_prime[0] = is_prime[1] = False
        for i in range(2, int(high ** 0.5) + 1):
            if is_prime[i]:
                for j in range(i * i, high + 1, i):
                    is_prime[j] = False

        if is_prime[n]:
            return -1

        INF = float("inf")
        dist = [INF] * (high + 1)
        dist[n] = n
        pq = [(n, n)]
        while pq:
            d, u = heapq.heappop(pq)
            if d > dist[u]:
                continue
            if u == m:
                return d
            p = 1
            while p <= high:
                digit = (u // p) % 10
                for delta in (-1, 1):
                    nd = digit + delta
                    if 0 <= nd <= 9:
                        v = u + delta * p
                        if low <= v <= high and not is_prime[v] and d + v < dist[v]:
                            dist[v] = d + v
                            heapq.heappush(pq, (dist[v], v))
                p *= 10
        return -1
```

## 8. 边界情况与易错点

1. **起点就是质数**：立即 $-1$，不要先跑 Dijkstra（示例 4）。
2. **终点是质数**：质数节点不在图中，不可作为路径终点。示例 3 的 $m = 2$ 就是这种情况。
3. **答案是「值和」而不是「步数」**：`dist` 初始化为 $n$、边权为目标值，两者缺一不可。把边权写成 1 会退化成 BFS 求步数。
4. **数位数目必须保持**：`v < low` 的过滤不能省，否则 $4 \to 14$ 这类「凭空长位」的边会出现，示例 2 会算出一个有限值。
5. **越界与数字范围**：某位是 9 时不能加、是 0 时不能减；用 `nd < 0 || nd > 9` 判断，或用 `v` 的范围判断都可以，但两者要一致（推荐都用 `nd`）。
6. **`9` 与 `0` 的位边界**：处理 4 位数时 `p` 循环上界到 $1000$ 即可，写成 `p <= high` 也正确（`p = 10000` 时 `digit = 0`，只会产生非法边，不影响正确性，但会浪费循环）。
7. **不可达时返回 $-1$**：堆空后必须返回 $-1$，不要直接返回 `dist[m]`（可能是 `INF` 截断后的垃圾值）。
8. **质数定义**：$0$ 与 $1$ 都不是质数，但本题 $n \ge 1$，且 $d$ 位数下 $1$ 不会出现（$d = 1$ 且 $n = 1$ 时是合法起点）。
