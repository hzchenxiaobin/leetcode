# LeetCode 到最近的人的最大距离 题解

## 1. 题目概述

- **标题 / 题号**：到最近的人的最大距离（#849，medium）
- **链接**：https://leetcode.cn/problems/maximize-distance-to-closest-person/
- **来源**：LeetCode 第 88 场周赛 Q2
- **难度**：中等
- **标签**：数组

**题意**：`seats` 表示一排座位，`seats[i] = 1` 表示第 $i$ 个座位有人，`seats[i] = 0` 表示空位（下标从 0 开始）。保证至少有一个空位、至少有一人。亚历克斯要坐到一个**空位**上，使他与**最近的人**之间的距离最大化，返回这个最大距离。

**约束**：

- $2 \le seats.length \le 2 \times 10^4$
- `seats[i]` 为 0 或 1
- 至少一个空位，至少一人

## 2. 示例

**示例 1**

```text
输入：seats = [1,0,0,0,1,0,1]
输出：2
解释：坐在下标 2 时空位两侧最近的人分别是下标 0 与 4，距离都是 2；
      坐在其余空位（下标 1、3、5）时最近距离都是 1。故答案为 2。
```

**示例 2**

```text
输入：seats = [1,0,0,0]
输出：3
解释：右边没有人，坐在最后一个座位（下标 3）离下标 0 的人最远，距离 3。
```

**示例 3**

```text
输入：seats = [0,1]
输出：1
解释：左边没有人，坐在下标 0 时距离 1。
```

## 3. 解题思路

### 3.1 暴力思路

枚举每个空位 $i$，再扫一遍数组找到离它最近的人，取最小值；最后对所有空位取最大值。复杂度 $O(n^2)$，$n = 2 \times 10^4$ 时约 $4 \times 10^8$ 次比较，Python 下必然超时，C++ 也很勉强。

观察暴力中的浪费：对每个空位都重新扫一遍找最近的人。其实空位只分三种「处境」，每种的最近人距离都有**闭式公式**。

### 3.2 核心观察：空位只有三种处境

![空位只有三种处境：最左段、两人之间、最右段](images/wc88_q2_three_gap_concept.svg)

设第一个有人的座位为 $p$、最后一个有人的座位为 $q$。把所有空位按所在区段分类：

1. **最左段**（下标 $0 \sim p-1$，左边没人）：最近的人就是 $p$，坐在最左边 $x=0$ 时距离 $p$ 最大，答案候选为 $p$。
2. **中间段**（两个相邻的人 $a < b$ 之间，$b - a \ge 2$）：座位 $x \in (a,b)$ 的最近距离是 $\min(x-a,\ b-x)$，在**中点**处最大，候选为

$$\left\lfloor \frac{b-a}{2} \right\rfloor$$

3. **最右段**（下标 $q+1 \sim n-1$，右边没人）：最近的人是 $q$，坐在最右边 $x=n-1$ 时距离 $n-1-q$ 最大。

三类区段互不重叠，且每个空位必属于其中之一，所以答案就是三类候选的**最大值**。一次线性扫描即可同时得到全部候选：维护「上一个有人的下标 `prev`」，遇到人时就算中间段，扫描结束后补算最右段。

### 3.3 算法流程

![一次扫描：遇人就算间距，最后补上最右段](images/wc88_q2_scan_flow.svg)

```text
1. ans = 0，prev = -1
2. for i = 0 .. n-1:
3.     若 seats[i] == 0：继续
4.     若 prev == -1：ans = max(ans, i)              // 最左段，i 就是第一个人
5.     否则：ans = max(ans, (i - prev) / 2)           // 中间段
6.     prev = i
7. ans = max(ans, n - 1 - prev)                      // 最右段
8. 返回 ans
```

### 3.4 示例演算

![示例演算：seats = [1,0,0,0,1,0,1]](images/wc88_q2_example_walkthrough.svg)

| 步骤 | $i$ | `seats[i]` | `prev` | 候选距离 | `ans` |
|------|-----|------------|--------|----------|-------|
| 1 | 0 | 1 | -1 → 0 | 最左段：0 | 0 |
| 2 | 4 | 1 | 0 → 4 | $(4-0)/2 = 2$（中间段） | 2 |
| 3 | 6 | 1 | 4 → 6 | $(6-4)/2 = 1$（中间段） | 2 |
| 4 | 收尾 | — | 6 | $7-1-6 = 0$（最右段） | 2 |

答案为 2。对示例 2 `[1,0,0,0]`：扫描到下标 0 时 `prev` 从 -1 变为 0，收尾算最右段 $4-1-0 = 3$，答案为 3。对示例 3 `[0,1]`：扫描到下标 1 时 `prev == -1`，最左段候选为 $1$，答案为 1。

## 4. 算法细节

1. **`prev = -1` 表示左边还没出现过人**：此时第一个遇到的 `1` 下标 $i$ 就是最左段的长度，候选距离为 $i$（不是 $i/2$）。
2. **中间段用 `(i - prev) / 2`**：`i - prev` 是两人之间下标的差，最优距离是它的一半下取整。C++ 整数除法自动下取整；Python 用 `//`。
3. **最右段用 `n - 1 - prev`**：`prev` 是最后一个人的下标，坐在 $n-1$ 处的距离就是这段长度；不要误写成 `(n-1-prev)/2`。
4. **只在遇到 `1` 时更新 `prev`**：空位不改变 `prev`，保证 `prev` 始终是「上一个有人」的位置。
5. **`ans` 初值 0**：题目保证至少一个空位，一定会产生至少一个候选；初值 0 安全。
6. **扫描结束别忘了收尾**：最右段没有任何「下一个人」触发计算，必须在循环外补一次 `max`，这是最常见的漏判。
7. **数学等价写法**：中间段长度 $L = b-a-1$，最优距离为 $\lceil L/2 \rceil = \lfloor (L+1)/2 \rfloor$，与 $\lfloor (b-a)/2 \rfloor$ 一致。

## 5. 正确性证明

**引理 1（中间段的最优解）**：设 $a < b$ 是两个相邻的有人的座位，$b - a \ge 2$。则在所有空位 $x \in (a,b)$ 中，到最近的人的距离最大值为 $\lfloor (b-a)/2 \rfloor$，且在中点处取到。

**证明**：对 $x \in (a,b)$，最近的人只可能是 $a$ 或 $b$（区间内没有其他人），距离为 $d(x) = \min(x-a,\ b-x)$。函数 $x-a$ 递增、$b-x$ 递减，故 $d(x)$ 在 $x-a \le b-x$ 时递增、之后递减，最大值在两段交界处取得，即 $x \approx (a+b)/2$。由于 $x$ 必须是整数，最大值为 $\lfloor (b-a)/2 \rfloor$（取 $x = \lfloor (a+b)/2 \rfloor$ 即可达到）。∎

**引理 2（边界段的最优解）**：设第一个有人的座位为 $p$、最后一个为 $q$。

- 最左段空位 $x \in [0, p-1]$ 的最近距离为 $p - x$，最大值为 $p$（在 $x=0$ 取到）；
- 最右段空位 $x \in [q+1, n-1]$ 的最近距离为 $x - q$，最大值为 $n-1-q$（在 $x=n-1$ 取到）。

**证明**：最左段内 $x < p$，$p$ 是唯一可能最近的人（其余人都在 $p$ 右侧，距离更远），距离为 $p-x$，随 $x$ 减小而增大；最右段对称。∎

**引理 3（分类完备）**：每个空位恰好属于最左段、某个中间段、最右段三者之一。

**证明**：设空位为 $x$。若 $x < p$ 则属于最左段；若 $x > q$ 则属于最右段；否则 $p \le x \le q$ 且 $x$ 不是人，故存在相邻的有人座位 $a < x < b$（取 $x$ 左侧最近的人与右侧最近的人），属于中间段。三类互不重叠。∎

**定理**：算法返回的是亚历克斯到最近的人的最大距离。

**证明**：

- **上界**：任取空位 $x$，由引理 3 它属于某一类；由引理 1、2，该类的候选值不小于 $x$ 处的最近距离。故真实答案不超过三类候选的最大值。
- **可达**：三类候选各自都有对应的空位可以达到（引理 1、2 的取等点），这些空位合法，故最大值是可达的。

两者合起来即得结论。算法对每个中间段恰好计算一次（每遇到一个 `1` 与 `prev` 配对）、最左段与最右段各计算一次，因此返回值与上述最大值一致。∎

## 6. 复杂度分析

- **时间**：$O(n)$。一次线性扫描，每个位置做常数次比较与算术运算。
- **空间**：$O(1)$。只用了 `ans`、`prev`、`i` 三个整型变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maxDistToClosest(vector<int>& seats) {
        int n = (int)seats.size();
        int ans = 0, prev = -1;
        for (int i = 0; i < n; i++) {
            if (seats[i] == 1) {
                if (prev == -1) ans = max(ans, i);
                else ans = max(ans, (i - prev) / 2);
                prev = i;
            }
        }
        ans = max(ans, n - 1 - prev);
        return ans;
    }
};
```

### Python

```python
class Solution:
    def maxDistToClosest(self, seats: list[int]) -> int:
        n = len(seats)
        ans = 0
        prev = -1
        for i in range(n):
            if seats[i] == 1:
                if prev == -1:
                    ans = max(ans, i)
                else:
                    ans = max(ans, (i - prev) // 2)
                prev = i
        ans = max(ans, n - 1 - prev)
        return ans
```

## 8. 边界情况与易错点

1. **只有一个人**：最左段与最右段同时存在，答案取两者较大。如 `[0,0,1,0,0]`：最左段 2、最右段 2，答案为 2。
2. **两个人相邻**：`b - a = 1`，中间没有空位，`(i-prev)/2 = 0` 不影响答案。
3. **首段为 0**：第一个座位就有人，`prev` 直接置 0，候选为 0，正确。
4. **尾段为 0**：最后一个人就在末尾，收尾候选 $n-1-prev = 0$。
5. **首尾段被误当成中间段**：若在 `prev == -1` 时也套用 `(i-prev)/2`，会把最左段距离算成一半，例如示例 3 的 `[0,1]` 会算成 0 而不是 1。
6. **`n = 2`**：可能是 `[1,0]`（答案 1）或 `[0,1]`（答案 1），都走最左/最右段分支。
7. **别漏收尾**：最右段没有「下一个人」触发，循环外必须补 `max(ans, n-1-prev)`。
8. **返回值是距离而不是下标**：题目要求最大距离，若要输出座位下标，需要在取最大时同时记录位置。
