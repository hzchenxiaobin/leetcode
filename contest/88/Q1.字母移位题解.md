# LeetCode 字母移位 题解

## 1. 题目概述

- **标题 / 题号**：字母移位（#848，medium）
- **链接**：https://leetcode.cn/problems/shifting-letters/
- **来源**：LeetCode 第 88 场周赛 Q1
- **难度**：中等
- **标签**：数组、字符串、前缀和

**题意**：给定小写字母串 `s` 与等长整数数组 `shifts`。对每个 $i$，把 `s` 的**前 $i+1$ 个字母**各移位 `shifts[i]` 次（`shift('a')='b'`，`'z'` 之后回到 `'a'`）。所有移位依次叠加，返回最终字符串。

**约束**：

- $1 \le s.length \le 10^5$
- `shifts.length == s.length`
- $0 \le shifts[i] \le 10^9$

> 💡 单个 `shifts[i]` 可达 $10^9$，全部叠加可达 $10^{14}$，必须用 64 位整数（或每步对 26 取模）。

## 2. 示例

**示例 1**

```text
输入：s = "abc", shifts = [3,5,9]
输出："rpl"
解释：
  移 3 次前 1 个字母：abc → dbc
  移 5 次前 2 个字母：dbc → igc
  移 9 次前 3 个字母：igc → rpl
```

**示例 2**

```text
输入：s = "aaa", shifts = [1,2,3]
输出："gfd"
解释：后缀和分别为 6、5、3，a 移 6 次得 g，移 5 次得 f，移 3 次得 d。
```

**补充示例**

```text
输入：s = "z", shifts = [26]
输出："z"
解释：26 次移位是完整的一圈，字母不变。
```

## 3. 解题思路

### 3.1 暴力思路

严格按定义模拟：对每个 $i$，遍历前 $i+1$ 个字母并逐个移位。总操作次数

$$\sum_{i=0}^{n-1}(i+1) = \frac{n(n+1)}{2}$$

当 $n = 10^5$ 时约为 $5 \times 10^9$，必然超时。而且每个字母单次还要移动 `shifts[i]` 次，更是不可行。

### 3.2 核心观察：每个字母的总移位是一个后缀和

![每个字母的总移位 = 从它开始的后缀和](images/wc88_q1_suffix_sum_concept.svg)

换个角度看：操作 $i$ 覆盖下标 $0 \sim i$ 的**前缀**。对某个固定字母 $j$ 而言，它被哪些操作覆盖？

$$j \text{ 被操作 } i \text{ 覆盖} \iff j \le i$$

因此字母 $j$ 的**累计移位次数**为

$$S[j] = \sum_{i=j}^{n-1} shifts[i]$$

这正是数组 `shifts` 的**后缀和**。从右往左扫一遍即可在 $O(n)$ 内求出所有 $S[j]$，再对每个字母做一次移位即可。

由于字母表是长度 26 的循环，实际只需保留 $S[j] \bmod 26$，可以在累加过程中随时取模，避免大数累积。

### 3.3 算法流程

![算法流程：从右往左累加后缀和，同步移位当前字母](images/wc88_q1_suffix_scan_flow.svg)

```text
1. total = 0
2. for i = n-1 downto 0:
3.     total = (total + shifts[i]) % 26      // 后缀和（只需模 26）
4.     s[i] = chr((ord(s[i]) - ord('a') + total) % 26 + ord('a'))
5. 返回 s
```

### 3.4 示例演算

![示例演算：s = "abc"，shifts = [3,5,9]](images/wc88_q1_example_walkthrough.svg)

对 `s = "abc"`、`shifts = [3,5,9]`，从右往左：

| 步骤 | $i$ | `shifts[i]` | `total`（后缀和 mod 26） | 原字母 | 移后 |
|------|-----|-------------|--------------------------|--------|------|
| 1 | 2 | 9 | 9 | c | l |
| 2 | 1 | 5 | 14 | b | p |
| 3 | 0 | 3 | 17 | a | r |

为什么 `b` 是 14？因为操作 1 与操作 2 都覆盖 `b`，$5 + 9 = 14$。为什么 `a` 是 17？三个操作都覆盖它，$3 + 5 + 9 = 17$。最终结果 `"rpl"`。

## 4. 算法细节

1. **后缀和递推**：从右往左时 `total` 天然就是 $S[i]$，不需要先存整个数组；顺序反过来则要用前缀和减去某段，反而更绕。
2. **边累加边取模**：`total = (total + shifts[i]) % 26`，让 `total` 始终小于 26，C++ 中连 `long long` 都不会溢出；若先累加再取模，最坏 $10^{14}$ 仍在 `long long` 内，但 `int` 一定溢出。
3. **字符运算**：`(c - 'a' + total) % 26` 把字母映射到 $0 \sim 25$ 再加回 `'a'`；`total` 本身已经取过模，非负，不存在负数取模问题。
4. **原地修改**：C++ 按值传入 `string s`（拷贝一份）后原地改写，返回它即可，额外空间是 $O(1)$（不计返回值）；Python 字符串不可变，先转成 `list`，最后 `join`。
5. **`shifts` 与 `s` 等长**：题目保证，不需要做长度对齐或补零。
6. **无需排序 / 离线**：操作顺序不影响最终结果（加法可交换），因此可以直接求后缀和。

## 5. 正确性证明

**引理 1（覆盖关系）**：操作 $i$ 作用于字母 $j$ 当且仅当 $j \le i$。

**证明**：操作 $i$ 作用于 `s` 的前 $i+1$ 个字母，即下标 $0,1,\dots,i$。∎

**引理 2（累计移位公式）**：字母 $j$ 的累计移位次数为 $S[j] = \sum_{i=j}^{n-1} shifts[i]$。

**证明**：由引理 1，字母 $j$ 被操作 $i$ 覆盖当且仅当 $i \ge j$。对所有覆盖它的操作求和，即得 $\sum_{i=j}^{n-1} shifts[i]$。∎

**引理 3（模 26 不改变结果）**：对任意整数 $k \ge 0$，字母 $c$ 移位 $k$ 次与移位 $k \bmod 26$ 次结果相同。

**证明**：字母表长度 26，移位是 $\mathbb{Z}_{26}$ 上的加法；$k$ 与 $k \bmod 26$ 在 $\mathbb{Z}_{26}$ 中同余，作用结果相同。∎

**定理**：算法返回的正是所有移位叠加后得到的字符串。

**证明**：算法中第 3 步维护的 `total` 恰为 $S[i]$ 对 26 取模（归纳：初始 0；每次加上 `shifts[i]` 并取模）；第 4 步把字母 $i$ 移位 `total` 次。由引理 2、3，这与「叠加全部操作后字母 $i$ 的位置」完全一致。对所有 $i$ 成立，故输出字符串正确。∎

## 6. 复杂度分析

- **时间**：$O(n)$。一次从右往左的线性扫描，每个字母做常数次算术运算。
- **空间**：$O(1)$ 额外空间（不计返回的新字符串）。C++ 在传入的副本上原地修改；Python 需要 $O(n)$ 的列表存放字符，属于实现细节。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    string shiftingLetters(string s, vector<int>& shifts) {
        long long total = 0;
        for (int i = (int)s.size() - 1; i >= 0; i--) {
            total = (total + shifts[i]) % 26;
            s[i] = (char)('a' + (s[i] - 'a' + total) % 26);
        }
        return s;
    }
};
```

### Python

```python
class Solution:
    def shiftingLetters(self, s: str, shifts: list[int]) -> str:
        res = list(s)
        total = 0
        for i in range(len(s) - 1, -1, -1):
            total = (total + shifts[i]) % 26
            res[i] = chr((ord(res[i]) - ord('a') + total) % 26 + ord('a'))
        return ''.join(res)
```

## 8. 边界情况与易错点

1. **`shifts[i] = 10^9`**：先对 26 取模再累加最稳；若直接累加再移位，`total` 会到 $10^{14}$，`int` 溢出。
2. **完整圈数**：`shifts[i]` 是 26 的倍数时字母不变，如补充示例；取模后 `total` 为 0，自然正确。
3. **单字符**：$n = 1$ 时循环执行一次，`total = shifts[0] % 26`，结果正确。
4. **`'z'` 回绕**：`(c - 'a' + total) % 26` 会在 26 处回绕，不要写成 `c + total` 后直接转字符（会越过 `'z'`）。
5. **负数取模**：本题 `total` 非负，不涉及；若未来允许负移位，要写成 `(x % 26 + 26) % 26`。
6. **返回值**：C++ 返回修改后的副本，不要返回输入引用；Python 必须 `join` 成 `str`，返回 `list` 会判错。
7. **不要按操作顺序真的去改前缀**：这是 $O(n^2)$ 的根源；后缀和是唯一正确的降维方式。

- 若操作改成「对区间 $[l_i, r_i]$ 移位」，单个字母的累计移位就变成「覆盖它的区间权值和」，用差分数组 $O(n + m)$ 解决。

- 若字母表不是 26 而是任意 $k$，公式完全不变，把 26 换成 $k$ 即可。
