# LeetCode 喧闹和富有 题解

## 1. 题目概述

- **标题 / 题号**：喧闹和富有（#851，medium）
- **链接**：https://leetcode.cn/problems/loud-and-rich/
- **来源**：LeetCode 第 88 场周赛 Q3
- **难度**：中等
- **标签**：深度优先搜索、图、拓扑排序、数组、有向无环图

**题意**：$n$ 个人编号 $0 \sim n-1$，各有不同数目的钱和安静值 `quiet[i]`。`richer[i] = [a, b]` 表示 $a$ 比 $b$ **更有钱**（关系可传递，且数据逻辑自洽、不会成环）。对每个人 $x$，求在所有「钱**肯定不少于** $x$」的人中，`quiet` 值最小的人 $y$，即 `answer[x] = y`。

**约束**：

- $n = quiet.length$，$1 \le n \le 500$
- $0 \le quiet[i] < n$，且所有 `quiet` 值**互不相同**
- $0 \le richer.length \le n(n-1)/2$，数对互不相同，$a_i \ne b_i$，关系逻辑自洽（无环）

## 2. 示例

**示例 1**

```text
输入：richer = [[1,0],[2,1],[3,1],[3,7],[4,3],[5,3],[6,3]], quiet = [3,2,5,4,6,1,7,0]
输出：[5,5,2,5,4,5,6,7]
解释：answer[0] = 5：5 比 3 富、3 比 1 富、1 比 0 富，链上最安静的是 5（quiet = 1）；
      answer[7] = 7：能确定比 7 富的只有 3 一条链，但 7 自己的 quiet = 0 最小。
```

**示例 2**

```text
输入：richer = [], quiet = [0]
输出：[0]
解释：只有一个人，答案就是他自己。
```

**补充示例**

```text
输入：richer = [[0,1]], quiet = [0,1]
输出：[0,0]
解释：0 比 1 富。1 的候选是 {1, 0}，quiet 分别为 1 和 0，故 answer[1] = 0。
```

## 3. 解题思路

### 3.1 暴力思路

把 `richer` 看成一个有向图：边 $a \to b$ 表示 $a$ 比 $b$ 富。对每个人 $x$，从 $x$ 出发沿**反向边**（即「谁比我有钱」）做一次 DFS/BFS，收集所有祖先，再在其中取 `quiet` 最小者。

复杂度 $O(n(n+m))$：$n = 500$、$m$ 最大约 $1.2 \times 10^5$ 时约 $6 \times 10^7$，能过但很浪费——大量祖先集合被不同人**重复遍历**。例如一条长链上，每个人的祖先集合几乎相同，却各算了一遍。

### 3.2 核心观察：祖先的答案可以沿边合并

![把 richer 看成 DAG：answer 沿「反图」向上合并](images/wc88_q3_richer_dag_concept.svg)

「钱不少于 $x$」的人 = 图里所有**能走到 $x$ 的节点**，再加上 $x$ 自己。记这个集合为 $A(x)$。

若用 `rich[x]` 表示「直接比 $x$ 有钱的人」的集合（即反图中的直接前驱），则

$$A(x) = \{x\} \cup \bigcup_{a \in rich[x]} A(a)$$

也就是说，$x$ 的候选集合完全由它的**直接前驱**的候选集合拼成。于是可以定义

$$\text{dfs}(x) = \arg\min_{y \in A(x)} quiet[y]$$

递归地：

$$\text{dfs}(x) = \arg\min\big(\{x\} \cup \{\text{dfs}(a) : a \in rich[x]\}\big)$$

- 因为 $A(a) \subseteq A(x)$，所以 $A(a)$ 中 `quiet` 最小的那个就是整个 $A(a)$ 对 $x$ 的「代表」，其余元素不必再看；
- 图是 **DAG**，递归无环，可以直接记忆化：每个节点只计算一次。

这样每个节点只访问自己的直接前驱，总代价与边数同阶。

### 3.3 算法流程

![记忆化 DFS：每个节点只算一次，沿边合并答案](images/wc88_q3_memo_dfs_flow.svg)

```text
1. 建反图：对每条 [a, b]，把 a 放进 rich[b]（a 是 b 的直接前驱）
2. ans[] 全部置 -1（表示未计算）
3. dfs(u):
4.     若 ans[u] != -1：返回 ans[u]              // 记忆化
5.     ans[u] = u                                 // 至少包含自己
6.     对每个 a in rich[u]：
7.         cand = dfs(a)
8.         若 quiet[cand] < quiet[ans[u]]：ans[u] = cand
9.     返回 ans[u]
10. 对每个 u 调用 dfs(u)，返回 ans
```

### 3.4 示例演算

![示例演算：quiet = [3,2,5,4,6,1,7,0] 的逐点答案](images/wc88_q3_example_walkthrough.svg)

反图 `rich[]` 与计算结果：

| $x$ | `rich[x]`（直接更富） | 候选与 `quiet` | `answer[x]` |
|-----|----------------------|----------------|-------------|
| 0 | {1} | 1 → 5（`q=1`），比 `q0=3` 小 | 5 |
| 1 | {2, 3} | `q2=5`、`q3=4`；`dfs(3)=5`（`q=1`） | 5 |
| 2 | {} | 只有自己 `q=5` | 2 |
| 3 | {4, 5, 6} | `q4=6`、`q5=1`、`q6=7` → 5 | 5 |
| 4 | {} | 自己 `q=6` | 4 |
| 5 | {} | 自己 `q=1`，最小 | 5 |
| 6 | {} | 自己 `q=7` | 6 |
| 7 | {3} | `dfs(3)=5`（`q=1`），但 `q7=0` 更小 | 7 |

注意 `dfs(3) = 5` 而不是 3：3 的祖先里 5 最安静。而 7 虽然「能确定比它富」的祖先只有 3、4、5、6，但 7 自己的 `quiet = 0` 已经最小，所以答案是 7。

## 4. 算法细节

1. **边的方向**：`richer[i] = [a, b]` 表示 $a$ 比 $b$ 富，边应建成 $a \to b$；而我们需要「谁比我富」，所以用**反图**：`rich[b].push_back(a)`。方向写反是最常见的错误。
2. **记忆化数组兼作结果数组**：`ans[u] == -1` 表示未计算，计算完成后直接存答案，既省空间又避免二次遍历。
3. **先把自己放进答案**：`ans[u] = u` 再合并前驱，保证「钱不少于 $x$」包含 $x$ 自己（示例 2、7 都依赖这一点）。
4. **`quiet` 互不相同**：题目保证，所以「最小者」唯一，不需要处理并列；若存在并列，任一最小者都满足题意，但需要额外的 tie-break 规则。
5. **递归深度**：图是 DAG，最长链不超过 $n = 500$。C++ 递归深度 500 没问题；Python 默认递归限制约 1000，也够，但保险起见设 `sys.setrecursionlimit(10000)`。
6. **迭代写法**：也可以按拓扑序（从最富到最穷）递推：先算所有入度为 0 的节点（没人比它富），再沿边把答案推给后继，`ans[b] = argmin(quiet, ans[b], ans[a])`。与递归完全等价，适合不想写递归的场合。
7. **不会重复访问**：DAG 上每个节点只递归一次，记忆化后总访问边数等于边数。

## 5. 正确性证明

**引理 1（祖先集 = 钱不少于的人）**：在 DAG 中，$y \in A(x)$（存在路径 $y \to \cdots \to x$，或 $y = x$）当且仅当「$y$ 的钱肯定不少于 $x$」。

**证明**：

- （$\Rightarrow$）路径上每条边 $u \to v$ 表示 $u$ 比 $v$ 富，由传递性，$y$ 比 $x$ 富（或 $y = x$），故 $y$ 的钱不少于 $x$。
- （$\Leftarrow$）若 $y$ 的钱肯定不少于 $x$，由题目「逻辑自洽」的语义，$y \ne x$ 时必然存在一条从 $y$ 到 $x$ 的富有着链（否则无法由已知关系确定），即路径存在；$y = x$ 时取空路径。

∎

**引理 2（集合递推）**：$A(x) = \{x\} \cup \bigcup_{a \in rich[x]} A(a)$。

**证明**：任取 $y \in A(x)$，$y \ne x$ 时存在路径 $y \to \cdots \to x$，取其最后一条边 $a \to x$，则 $a \in rich[x]$ 且 $y \in A(a)$；反向包含显然。∎

**引理 3（dfs 正确性）**：对每个节点 $x$，`dfs(x)` 返回 $A(x)$ 中 `quiet` 最小的节点。

**证明**：对 DAG 做结构归纳（按拓扑序从「最富」到「最穷」，或等价地按递归深度）。设 $x$ 的所有直接前驱 $a$ 都已满足结论。由引理 2，

$$\min_{y \in A(x)} quiet[y] = \min\left(quiet[x],\ \min_{a \in rich[x]} \min_{y \in A(a)} quiet[y]\right) = \min\left(quiet[x],\ \min_{a} quiet[\text{dfs}(a)]\right)$$

而算法正是先令 `ans[x] = x`，再对每个 $a$ 用 `dfs(a)` 的 `quiet` 与当前最优比较，故返回的正是该最小值对应的节点；`quiet` 互不相同保证唯一。∎

**定理**：算法返回的数组满足 `answer[x] = ` $A(x)$ 中 `quiet` 最小的节点。

**证明**：对每个 $x$ 调用 `dfs(x)`，由引理 3 即得；记忆化只复用已算好的正确结果，不改变取值。∎

## 6. 复杂度分析

- **时间**：$O(n + m)$。建反图 $O(m)$；每个节点被 `dfs` 计算一次，计算时遍历其直接前驱，所有节点合计遍历每条边一次，故总代价 $O(n + m)$。
- **空间**：$O(n + m)$。反图存储 $m$ 条边；`ans` 数组 $O(n)$；递归栈最坏 $O(n)$。

## 7. 参考代码

### C++

```cpp
class Solution {
    vector<int> ans;
    vector<vector<int>> rich;
    vector<int> q;

    int dfs(int u) {
        if (ans[u] != -1) return ans[u];
        ans[u] = u;
        for (int v : rich[u]) {
            int cand = dfs(v);
            if (q[cand] < q[ans[u]]) ans[u] = cand;
        }
        return ans[u];
    }

public:
    vector<int> loudAndRich(vector<vector<int>>& richer, vector<int>& quiet) {
        int n = (int)quiet.size();
        q = quiet;
        rich.assign(n, {});
        for (auto& e : richer) rich[e[1]].push_back(e[0]);
        ans.assign(n, -1);
        for (int i = 0; i < n; i++) dfs(i);
        return ans;
    }
};
```

### Python

```python
import sys

class Solution:
    def loudAndRich(self, richer: list[list[int]], quiet: list[int]) -> list[int]:
        n = len(quiet)
        rich = [[] for _ in range(n)]
        for a, b in richer:
            rich[b].append(a)          # a 比 b 有钱：b 的直接前驱是 a
        ans = [-1] * n
        sys.setrecursionlimit(10000)

        def dfs(u: int) -> int:
            if ans[u] != -1:
                return ans[u]
            ans[u] = u
            for v in rich[u]:
                cand = dfs(v)
                if quiet[cand] < quiet[ans[u]]:
                    ans[u] = cand
            return ans[u]

        for i in range(n):
            dfs(i)
        return ans
```

## 8. 边界情况与易错点

1. **边的方向写反**：`richer[i] = [a, b]` 要存成 `rich[b] ← a`；若存成 `rich[a] ← b`，就会把「更穷的人」当成祖先，答案全错。
2. **忘记包含自己**：示例 2（只有一个人）与示例 1 的 7 都依赖「自己也是候选」，必须先 `ans[u] = u`。
3. **递归爆栈**：$n = 500$ 的链在 Python 中深度 500，默认限制 1000 够用，但 recursive 调用中还嵌套其他帧，建议显式调高限制。
4. **误以为有环**：题目保证逻辑自洽（DAG），因此不需要判环；若数据有环，这个问题本身就没有定义。
5. **`quiet` 并列**：题目保证互不相同；若改题不保证，需要规定 tie-break，否则答案不唯一。
6. **答案存 `-1` 与「未计算」混淆**：节点编号从 0 开始，用 `-1` 作哨兵安全。
7. **重复边**：题目保证 `richer` 中数对互不相同，无需去重；即使有重复，算法也只会多比较一次，不影响正确性。
8. **`n = 1` 且 `richer = []`**：直接返回 `[0]`。

**延伸思考**：

- 若要求输出**具体是哪条链**上的最安静者（路径本身），记忆化时额外记录来源节点即可。
- 若 `quiet` 存在并列，可改为返回编号最小者，比较条件加上 `(quiet[cand], cand) < (quiet[ans], ans)`。
- 若图不是 DAG（存在「互相更有钱」的矛盾），需要先判环；一旦有环，问题语义不成立，应先报错。
- 若 `n` 放大到 $10^5$，$O(n+m)$ 的 DFS 仍然可用，但要注意递归深度，改用迭代拓扑排序。
