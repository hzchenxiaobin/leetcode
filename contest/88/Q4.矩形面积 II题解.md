# LeetCode 矩形面积 II 题解

## 1. 题目概述

- **标题 / 题号**：矩形面积 II（#850，hard）
- **链接**：https://leetcode.cn/problems/rectangle-area-ii/
- **来源**：LeetCode 第 88 场周赛 Q4
- **难度**：困难
- **标签**：线段树、数组、有序集合、扫描线

**题意**：给定若干个**轴对齐**矩形，`rectangles[i] = [x1, y1, x2, y2]` 中 $(x_1,y_1)$ 是左下角、$(x_2,y_2)$ 是右上角。求所有矩形并集覆盖的**总面积**，重叠区域只算一次。答案可能很大，返回其对 $10^9+7$ 取模的结果。

**约束**：

- $1 \le rectangles.length \le 200$
- $0 \le x_1, y_1, x_2, y_2 \le 10^9$，$x_1 \le x_2$，$y_1 \le y_2$
- 所有矩形面积不为 0

## 2. 示例

**示例 1**

```text
输入：rectangles = [[0,0,2,2],[1,0,2,3],[1,0,3,1]]
输出：6
解释：x ∈ [0,1) 只有 A 覆盖（面积 2）；x ∈ [1,2) 三个矩形覆盖 y ∈ [0,3]（面积 3）；
      x ∈ [2,3) 只有 C 覆盖（面积 1）。合计 2 + 3 + 1 = 6。
```

**示例 2**

```text
输入：rectangles = [[0,0,1000000000,1000000000]]
输出：49
解释：单个矩形面积 10^9 × 10^9 = 10^18，对 10^9+7 取模得 49。
```

**补充示例**

```text
输入：rectangles = [[0,0,2,2],[1,1,3,3]]
输出：7
解释：两个 2×2 的矩形重叠 1×1，并集面积 4 + 4 - 1 = 7。
```

## 3. 解题思路

### 3.1 暴力思路

两条常见的死路：

1. **容斥原理**：枚举所有矩形子集，奇加偶减。子集数 $2^{200}$，完全不可行。
2. **网格离散化**：直接把平面按单位长度打成格子，再逐格标记。坐标可达 $10^9$，格子数是 $10^{18}$ 级别，同样不可行。

问题的难点在于「重叠区域只算一次」。但注意：矩形是**轴对齐**的，这让「沿一个轴切片」变得非常自然。

### 3.2 核心观察：按 x 切成条带，条带内覆盖关系不变

![扫描线 + 坐标压缩：按 x 切成竖条带，逐条求 y 覆盖长度](images/wc88_q4_sweep_slab_concept.svg)

把所有矩形的 $x_1, x_2$ 收集起来排序去重，得到至多 $2n$ 个坐标，相邻两个坐标之间形成一个**竖条带** $[x_k, x_{k+1})$。关键事实：

> 在同一个条带内部，**覆盖它的矩形集合完全不变**。

因为矩形的左右边界都落在这些坐标点上，条带内部不可能有矩形的边。于是条带内的并集形状就是「若干个 $y$ 区间的并」乘以该条带的宽度，面积可写成

$$\text{area} = \sum_{k} (x_{k+1} - x_k) \times \operatorname{len}\Big(\bigcup_{i:\ \text{rect}_i \text{ 覆盖条带 } k} [y_{i1}, y_{i2}]\Big)$$

「覆盖条带 $k$」的判定：$x_{i1} \le x_k$ 且 $x_{k+1} \le x_{i2}$，即矩形横跨整个条带。

每个条带最多 $n$ 个 $y$ 区间，排序后一次线性合并即可求出并长度。

![条带内求 y 区间并：排序后一次线性合并](images/wc88_q4_merge_y_intervals.svg)

### 3.3 算法流程

```text
1. 收集所有 x1、x2，排序去重得到 xs[0..m-1]
2. ans = 0
3. for k = 0 .. m-2:
4.     xl = xs[k]，xr = xs[k+1]
5.     segs = []                                  // 收集横跨该条带的矩形的 y 区间
6.     for 每个矩形 r：
7.         若 r.x1 <= xl 且 xr <= r.x2：segs.push([r.y1, r.y2])
8.     若 segs 为空：跳过（该条带无人覆盖）
9.     按 y1 升序排序 segs
10.    ylen = 合并后的总长度（见下）
11.    ans = (ans + (xr - xl) * ylen) mod (1e9+7)
12. 返回 ans
```

**区间合并**（排序后一次扫描）：

```text
cur = segs[0]，ylen = 0
for 每个 seg in segs[1..]:
    若 seg.l > cur.r：ylen += cur.r - cur.l，cur = seg
    否则：cur.r = max(cur.r, seg.r)
ylen += cur.r - cur.l
```

### 3.4 示例演算

![示例演算：三个矩形并集面积 = 2 + 3 + 1 = 6](images/wc88_q4_example_walkthrough.svg)

示例 1 的三个矩形：$A=[0,0,2,2]$、$B=[1,0,2,3]$、$C=[1,0,3,1]$。$x$ 坐标去重后为 $0,1,2,3$，形成三个条带：

| $x$ 条带 | 宽度 | 覆盖的矩形 | $y$ 区间并 | 并长度 | 面积 |
|----------|------|------------|------------|--------|------|
| $[0,1)$ | 1 | A | $[0,2]$ | 2 | 2 |
| $[1,2)$ | 1 | A, B, C | $[0,3]$ | 3 | 3 |
| $[2,3)$ | 1 | C | $[0,1]$ | 1 | 1 |
| 合计 | | | | | **6** |

以 $[1,2)$ 条带为例：A、B、C 都横跨它，$y$ 区间分别是 $[0,2]$、$[0,3]$、$[0,1]$，排序后合并为 $[0,3]$，长度 3，乘以宽度 1 得面积 3。

## 4. 算法细节

1. **坐标压缩**：只保留矩形的 $x_1, x_2$ 作为切分点。条带内部没有矩形的竖直边，因此覆盖关系恒定——这是整个算法成立的基础。
2. **覆盖判定**：`r.x1 <= xl && xr <= r.x2`。因为 $xl, xr$ 都是压缩后的坐标，这个条件等价于「矩形横跨整个条带」，不会出现部分覆盖。
3. **`y` 区间合并**：排序后维护 `cur = [cl, cr]`；若下一段起点 `> cr` 则结算并另起一段，否则只需把 `cr` 扩展到 `max(cr, y2)`（注意不能直接赋值为 `y2`，因为下一段可能完全被当前段包含）。
4. **64 位与取模**：单个条带面积可达 $10^9 \times 10^9 = 10^{18}$，必须用 `long long`；每一步先分别对宽度、长度取模再相乘，避免中间乘积溢出。
5. **复杂度**：条带数 $m-1 \le 2n-1$；每个条带收集区间 $O(n)$、排序 $O(n \log n)$、合并 $O(n)$。总计 $O(n^2 \log n)$，$n = 200$ 时约 $400 \times 200 \times 8 \approx 6.4 \times 10^5$ 次操作，非常宽裕。
6. **线段树优化**：把 $y$ 坐标也压缩，用线段树维护「被覆盖长度」，扫描线沿 $x$ 移动时只需在 $O(\log n)$ 内更新一条边，总复杂度可降到 $O(n \log n)$。本题 $n \le 200$，没必要上树，但这是该题的标准进阶做法。
7. **空条带**：相邻条带可能落在两个互不相交的矩形之间（例如矩形 $[0,10]$ 与 $[20,30]$ 之间的 $[10,20)$），此时没有矩形横跨，`segs` 为空，必须跳过，否则 `segs[0]` 越界。

## 5. 正确性证明

**引理 1（条带内覆盖关系恒定）**：设 $x_k, x_{k+1}$ 是排序去重后的相邻 $x$ 坐标，则对任意 $x \in (x_k, x_{k+1})$，覆盖 $x$ 的矩形集合与 $x$ 的取值无关。

**证明**：对任意矩形 $r$，它覆盖 $x$ 当且仅当 $r.x_1 \le x \le r.x_2$。而 $r.x_1, r.x_2$ 都属于坐标集合，故不存在落在开区间 $(x_k, x_{k+1})$ 内部的矩形边界。于是对区间内所有 $x$，$r.x_1 \le x$ 与 $x \le r.x_2$ 的真假都不变，覆盖关系恒定。∎

**引理 2（条带面积公式）**：条带 $[x_k, x_{k+1})$ 上的并集面积等于 $(x_{k+1}-x_k) \times \operatorname{len}(Y_k)$，其中 $Y_k$ 是「横跨该条带的矩形」的 $y$ 区间并。

**证明**：并集与条带的交为 $\{(x,y) : x \in [x_k,x_{k+1}),\ y \in Y_k\}$（由引理 1，$y$ 是否被覆盖与 $x$ 无关）。这是矩形 $[x_k,x_{k+1}) \times Y_k$，面积为宽度乘以 $Y_k$ 的测度。∎

**引理 3（区间合并正确）**：排序后的线性合并算法求出的 `ylen` 等于 $Y_k$ 的总长度。

**证明**：排序后区间按起点递增。维护当前合并段 $[cl, cr]$，它始终等于已处理区间的并的某个连通分量。若下一段起点 $> cr$，说明它与当前分量不交（且之后所有段起点更大，也不会相交），可以结算；否则两段相交或相接，并的右端点变为 $\max(cr, y_2)$。扫描结束时结算最后一段，各分量长度之和即为并的总长度。∎

**定理**：算法返回的取模结果等于所有矩形并集面积对 $10^9+7$ 取模。

**证明**：由引理 1，全部 $x$ 坐标把平面切成互不重叠的条带，且并集在每个条带上的部分如引理 2 所述；对所有条带求和即得并集总面积（条带外的 $x$ 不属于任何矩形，面积为 0）。算法对每个条带恰好计算一次，由引理 2、3 得到该条带的精确面积；对整数面积求和再取模，与逐项取模再求和结果相同（模运算与加法、乘法兼容）。故返回值正确。∎

## 6. 复杂度分析

- **时间**：$O(n^2 \log n)$。坐标收集与排序 $O(n \log n)$；至多 $2n-1$ 个条带，每个条带扫描 $n$ 个矩形（$O(n)$）、排序至多 $n$ 个区间（$O(n \log n)$）、线性合并（$O(n)$），故总计 $O(n^2 \log n)$。
- **空间**：$O(n)$。`xs` 数组 $O(n)$，每个条带的 `segs` 至多 $n$ 个区间。若改用线段树，空间为 $O(n)$ 的树 + $O(n)$ 的 $y$ 坐标。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int rectangleArea(vector<vector<int>>& rectangles) {
        const long long MOD = 1000000007LL;
        vector<long long> xs;
        for (auto& r : rectangles) {
            xs.push_back(r[0]);
            xs.push_back(r[2]);
        }
        sort(xs.begin(), xs.end());
        xs.erase(unique(xs.begin(), xs.end()), xs.end());
        long long ans = 0;
        for (size_t i = 0; i + 1 < xs.size(); i++) {
            long long xl = xs[i], xr = xs[i + 1];
            vector<pair<long long, long long>> segs;
            for (auto& r : rectangles) {
                if (r[0] <= xl && xr <= r[2]) segs.push_back({r[1], r[3]});
            }
            if (segs.empty()) continue;
            sort(segs.begin(), segs.end());
            long long ylen = 0, cl = segs[0].first, cr = segs[0].second;
            for (size_t k = 1; k < segs.size(); k++) {
                if (segs[k].first > cr) {
                    ylen += cr - cl;
                    cl = segs[k].first;
                    cr = segs[k].second;
                } else if (segs[k].second > cr) {
                    cr = segs[k].second;
                }
            }
            ylen += cr - cl;
            ans = (ans + (xr - xl) % MOD * (ylen % MOD)) % MOD;
        }
        return (int)ans;
    }
};
```

### Python

```python
class Solution:
    def rectangleArea(self, rectangles: list[list[int]]) -> int:
        MOD = 10**9 + 7
        xs = sorted({x for r in rectangles for x in (r[0], r[2])})
        ans = 0
        for i in range(len(xs) - 1):
            xl, xr = xs[i], xs[i + 1]
            if xl == xr:
                continue
            segs = []
            for x1, y1, x2, y2 in rectangles:
                if x1 <= xl and xr <= x2:
                    segs.append((y1, y2))
            if not segs:
                continue
            segs.sort()
            ylen = 0
            cl, cr = segs[0]
            for y1, y2 in segs[1:]:
                if y1 > cr:
                    ylen += cr - cl
                    cl, cr = y1, y2
                elif y2 > cr:
                    cr = y2
            ylen += cr - cl
            ans = (ans + (xr - xl) * ylen) % MOD
        return ans
```

## 8. 边界情况与易错点

1. **`long long` 溢出**：面积最大 $10^{18}$，`int` 必然溢出（示例 2 的输出 49 就是模运算的结果）。C++ 中宽度、长度乘之前先取模，或确保用 `long long`。
2. **模运算时机**：`ans` 每加一条带就取模，不要等最后；但取模**不能**在合并区间内部做（那里是真实长度，不涉及面积）。
3. **完全包含的矩形**：若某矩形被另一个矩形完全包住，它的 $y$ 区间会被合并「吸收」；注意 `cur.r = max(cur.r, y2)` 不能写成 `cur.r = y2`，否则会被较小的右端点截断。
4. **共享边界**：两个矩形正好共边（如 $[0,1]$ 与 $[1,2]$）不重叠，它们之间的条带宽度为 0 或只在边界相接，不会重复计面积；压缩坐标天然处理。
5. **零面积矩形**：题面保证不会出现（$x_1 \le x_2$ 且面积非 0）；代码对 `xl == xr` 也做了跳过，双保险。
6. **条带无覆盖**：某些条带可能没有矩形横跨（例如只被矩形「部分覆盖」的条带），此时 `segs` 为空必须跳过，否则 `segs[0]` 越界。
7. **只用一个条带的端点为矩形边界**：不要用 $0$ 到 $10^9$ 的全程扫描，那样条带数是 $10^9$ 级别。
8. **答案取模后用 `int` 返回**：取模后小于 $10^9+7$，不会溢出 `int`。
9. **`x` 与 `y` 不要写反**：覆盖判定用 $x$ 坐标，合并用 $y$ 区间；行列颠倒会得到错误的面积。

**延伸思考**：

- 用线段树维护「$y$ 被覆盖的总长度」，扫描线沿 $x$ 推进时只在矩形进入/离开时更新，可把复杂度降到 $O(n \log n)$；这是 $n$ 放大到 $10^5$ 时的必选做法。
- 若要求并集**周长**，扫描线需要同时维护「覆盖段数」与「端点是否被覆盖」（LC 850 的姊妹题 LC 391 / 天际线）。
- 若矩形带权（每次覆盖贡献不同权重），则不能简单合并，而要在每个条带内做加权区间并，需要更复杂的数据结构。
- 三维版本（长方体并体积）可用同样的「按 $x$ 切片 + 二维面积并」思路，复杂度再升一维。
