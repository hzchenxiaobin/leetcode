# LeetCode 十六进制和三十六进制转化 题解

## 1. 题目概述

- **标题 / 题号**：十六进制和三十六进制转化（#3602，easy）
- **链接**：https://leetcode.cn/problems/hexadecimal-and-hexatrigesimal-conversion/
- **来源**：LeetCode 第 160 场双周赛 Q1
- **难度**：简单
- **标签**：数学、字符串

**题意**：给定整数 $n$。把 $n^2$ 转成**十六进制**表示、把 $n^3$ 转成**三十六进制**表示，两者**直接拼接**成一个字符串返回。

- 十六进制：数字 `0-9` 与大写字母 `A-F` 表示 $0\sim15$；
- 三十六进制：数字 `0-9` 与大写字母 `A-Z` 表示 $0\sim35$。

**约束**：

- $1 \le n \le 1000$

> 💡 签到题：写一个通用 `toBase(x, base)`，再调用两次即可。注意 $n^3$ 最大 $10^9$，虽然能放进 `int`，但用 `long long` 更省心。

## 2. 示例

**示例 1**

```text
输入：n = 13
输出："A91P1"
解释：n² = 169 = (10×16) + 9 -> "A9"；n³ = 2197 = 1×36² + 25×36 + 1 -> "1P1"；拼接得 "A91P1"。
```

**示例 2**

```text
输入：n = 36
输出："5101000"
解释：n² = 1296 = 5×16² + 1×16 + 0 -> "510"；n³ = 46656 = 1×36³ -> "1000"；拼接得 "5101000"。
```

**示例 3（自造）**

```text
输入：n = 10
输出："64RS"
解释：n² = 100 = 6×16 + 4 -> "64"；n³ = 1000 = 27×36 + 28 -> "RS"（27 -> 'R'，28 -> 'S'）。
```

> 💡 第三例说明「三十六进制未必比十六进制短」：$1000$ 的十六进制是 `"3E8"`，三十六进制才是 `"RS"`。位数只由进制大小与数值共同决定，手算时务必先确认最高位的位权。

## 3. 解题思路

### 3.1 暴力思路

可以直接用 `sprintf("%X", n*n)` 与手写三十六进制；但为了两段风格一致、方便复核，统一写成 `toBase(x, base)` 更清爽。暴力「查表枚举所有 $36$ 的幂」也没问题（$n^3 \le 10^9 < 36^6$），但短除法更短、更通用。

### 3.2 核心观察：短除法（除基取余，逆序排列）

![两次进制转换：n² 转十六进制、n³ 转三十六进制](images/bw160_q1_base_conv.svg)

任意进制转换的标准做法：

$$x = d_k \cdot b^k + d_{k-1}\cdot b^{k-1} + \cdots + d_1 \cdot b + d_0$$

从低位到高位：$d_0 = x \bmod b$，然后 $x \leftarrow \lfloor x / b \rfloor$，重复直到 $x = 0$。得到的余数序列是**低位在前**，最后反向即为答案。

数字字符表只需一份：`"0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ"`，下标 $0\sim35$ 恰好覆盖两种进制。

### 3.3 算法流程

![示例演算](images/bw160_q1_example_walk.svg)

```text
1. a = n * n，b = n * n * n            # 用 long long
2. return toBase(a, 16) + toBase(b, 36)
3. toBase(x, base):
       if x == 0: return "0"
       s = ""
       while x > 0:
           s += DIG[x % base]
           x /= base
       reverse(s)
       return s
```

### 3.4 示例演算

| $n$ | $n^2$ / 十六进制 | $n^3$ / 三十六进制 | 答案 |
|-----|------------------|--------------------|------|
| 13 | $169 = 10\times16 + 9 \to$ `"A9"` | $2197 = 1\times36^2 + 25\times36 + 1 \to$ `"1P1"` | `"A91P1"` |
| 36 | $1296 = 5\times16^2 + 1\times16 + 0 \to$ `"510"` | $46656 = 1\times36^3 \to$ `"1000"` | `"5101000"` |

第二个例子特别能说明「余数为 $0$ 也要写 `0`」：$36^3$ 的三十六进制是 `"1000"`（三个 $0$），不是 `"1"`；短除法会把三个 $0$ 的余数都产生出来，不会漏。

## 4. 算法细节

1. **字符表**：`"0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ"` 共 36 个字符，下标即数值，两种进制共用。
2. **$x = 0$ 的边界**：短除法循环进不去，必须显式返回 `"0"`。本题 $n \ge 1$ 不会触发，但作为通用函数应当处理。
3. **逆序**：余数是从低位到高位产生的，必须 `reverse`；C++ 用 `std::reverse`，Python 用 `"".join(reversed(s))` 或 `s[::-1]`。
4. **整数类型**：$n \le 1000$，$n^3 \le 10^9$ 恰好不超过 `int` 上限，但 `n*n*n` 在 `int` 下计算中间值也可能溢出（若改成 $n = 10^5$），统一用 `long long` 最安全。
5. **不要用 `itoa` / `sprintf("%X")` 混搭**：大写十六进制可以用 `%X`，但三十六进制没有标准格式符，手写才能保证两段一致。
6. **拼接顺序**：先十六进制（$n^2$）后三十六进制（$n^3$），顺序反了就是另一个答案。
7. **`int` 与 `long long` 的除法**：`x % base` 与 `x / base` 都用整数运算，别写成浮点。

## 5. 正确性证明

**引理 1（短除法的正确性）**：设 $x \ge 1$、$b \ge 2$。短除法产生的余数序列反向排列后，等于 $x$ 在 $b$ 进制下的标准表示。

**证明**：对 $x$ 归纳。$x < b$ 时短除法产生唯一余数 $x$，反向即 `DIG[x]`，正确。设 $x \ge b$，令 $x = qb + r$（$0 \le r < b$），则短除法先输出 `DIG[r]`，再对 $q$ 递归。由归纳假设 $q$ 的表示为 $d_k\cdots d_0$，于是 $x = qb + r = (d_k b^k + \cdots + d_0)b + r = d_k b^{k+1} + \cdots + d_0 b + r$，其标准表示正是 $d_k \cdots d_0 r$，而短除法的输出反向排列后恰为此串。∎

**引理 2（字符映射无歧义）**：对 $0 \le d < 36$，`DIG[d]` 唯一确定；十六进制只用到 $d < 16$（即 `0-9A-F`），三十六进制用到 $d < 36$（即 `0-9A-Z`）。

**证明**：字符表长度 36，下标与字符一一对应；十六进制每位的余数 $< 16$，落在 `0-9A-F` 区间内，与题目对十六进制的定义一致；三十六进制每位的余数 $< 36$，覆盖 `0-9A-Z`。∎

**定理**：算法返回值为 $n^2$ 的十六进制表示与 $n^3$ 的三十六进制表示的直接拼接。

**证明**：由引理 1，`toBase(n*n, 16)` 返回 $n^2$ 的十六进制串，`toBase(n*n*n, 36)` 返回 $n^3$ 的三十六进制串；由引理 2，两者的每一位字符都符合题目对该进制的定义。字符串加法即拼接，故返回值为题目所求。∎

## 6. 复杂度分析

- **时间**：$O(\log_{16} n^2 + \log_{36} n^3) = O(\log n)$。$n \le 1000$ 时最多十几位，常数级。
- **空间**：$O(\log n)$ 存放结果字符串（最多 3 + 4 位，本题实际不超过 10 个字符）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    string concatHex36(int n) {
        long long a = 1LL * n * n;        // n^2 -> 十六进制
        long long b = 1LL * n * n * n;    // n^3 -> 三十六进制
        return toBase(a, 16) + toBase(b, 36);
    }

private:
    string toBase(long long x, int base) {
        static const char* DIG = "0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ";
        if (x == 0) return "0";
        string s;
        while (x > 0) {
            s.push_back(DIG[x % base]);
            x /= base;
        }
        reverse(s.begin(), s.end());
        return s;
    }
};
```

### Python

```python
class Solution:
    def concatHex36(self, n: int) -> str:
        DIG = "0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ"

        def to_base(x: int, base: int) -> str:
            if x == 0:
                return "0"
            s = []
            while x > 0:
                s.append(DIG[x % base])
                x //= base
            return "".join(reversed(s))

        return to_base(n * n, 16) + to_base(n * n * n, 36)
```

## 8. 边界情况与易错点

1. **$n = 1$**：$n^2 = 1 \to$ `"1"`，$n^3 = 1 \to$ `"1"`，答案为 `"11"`，不要因为「值太小」而特判。
2. **余数为 0 的位**：$36^3$ 的三十六进制是 `"1000"`，短除法不会漏掉中间的 0（每个 0 都会产生一次余数）。
3. **忘记 `reverse`**：直接顺序拼接会得到低位在前的结果（如把 `"A9"` 写成 `"9A"`）。
4. **十六进制字母大小写**：题目要求大写 `A-F`，字符表已是大写。
5. **$n^3$ 的类型**：$n = 1000$ 时 $n^3 = 10^9$，`int` 刚好；但 `n*n*n` 的中间结果在某些写法下可能先乘出更大值，统一 `long long`。
6. **拼接顺序**：先 $n^2$ 的十六进制，再 $n^3$ 的三十六进制，反了就错。
7. **`x == 0`**：通用函数要返回 `"0"`；本题虽不触发，但删掉这行会让函数在 $x = 0$ 时返回空串。
8. **空格与标点**：返回值是纯字符串，不要带引号或空格。
