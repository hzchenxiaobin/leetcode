# LeetCode 有向图中到达终点的最少时间 题解

## 1. 题目概述

- **标题 / 题号**：有向图中到达终点的最少时间（#3604，medium）
- **链接**：https://leetcode.cn/problems/minimum-time-to-reach-destination-in-directed-graph/
- **来源**：LeetCode 第 160 场双周赛 Q3
- **难度**：中等
- **标签**：图、最短路、堆（优先队列）

**题意**：给定 $n$ 个节点的有向图，边 $i$ 为 $[u_i, v_i, \text{start}_i, \text{end}_i]$，表示这条边**只能在整数时刻 $t \in [\text{start}_i, \text{end}_i]$** 使用。你在时刻 $0$ 位于节点 $0$。

每个时间单位可以：**原地等待**，或在满足窗口时**沿某条出边移动**（耗时 1 个时间单位，到达时刻为出发时刻 $+1$）。求到达节点 $n-1$ 的**最少时间**；不可达返回 $-1$。

**约束**：

- $1 \le n \le 10^5$，$0 \le \text{edges.length} \le 10^5$
- $u_i \ne v_i$，$0 \le \text{start}_i \le \text{end}_i \le 10^9$

> 💡 与普通最短路的关键差别：**边的可用性依赖当前时刻**，因此「最早到达」这个状态就足够了（越早越好），Dijkstra 依然适用。

## 2. 示例

**示例 1**

```text
输入：n = 3, edges = [[0,1,0,1],[1,2,2,5]]
输出：3
解释：t=0 走 0->1（窗口 [0,1]），t=1 到达 1；等至 t=2 再走 1->2（窗口 [2,5]），t=3 到达 2。
```

**示例 2**

```text
输入：n = 4, edges = [[0,1,0,3],[1,3,7,8],[0,2,1,5],[2,3,4,7]]
输出：5
解释：t=0 等到 t=1，走 0->2（窗口 [1,5]）到 t=2；等至 t=4 走 2->3（窗口 [4,7]），t=5 到达 3。
```

**示例 3**

```text
输入：n = 3, edges = [[1,0,1,3],[1,2,3,5]]
输出：-1
解释：节点 0 没有任何出边，永远走不出去。
```

## 3. 解题思路

### 3.1 暴力思路

把「在哪个节点、第几秒」作为状态做 BFS：状态数 $n \times T$，其中 $T$ 可达 $10^9$，空间与时间都爆炸。即便只保留「到达某节点的所有时刻」，也会随等待时间无限膨胀。

### 3.2 核心观察：只需记录「最早到达时刻」

![每条边是一个时间窗：早到就等，迟到就错过](images/bw160_q3_time_window.svg)

- 若在时刻 $t_1$ 就能到达节点 $u$，那么在 $t_2 > t_1$ 到达 $u$ **永远不会更好**：多等的时间里你什么也没做，而所有边只要求「不早于 start」，早到只需原地等待即可，等待是免费的（除了时间本身）。
- 因此对每个节点维护**最早到达时刻** `dist[u]`，与经典最短路同构。
- 从 $u$（时刻 $t$）经边 $(u,v,s,e)$：
  - 若 $t > e$：这条边已经过期，不能用；
  - 否则出发时刻 $= \max(t, s)$（早到就等到 $s$），到达时刻 $= \max(t, s) + 1$。
- 边权非负（时间只会增加），且每一步的「新到达时刻」随 $t$ 单调不减 $\Rightarrow$ Dijkstra 正确。

### 3.3 算法流程

![Dijkstra 流程](images/bw160_q3_dijkstra.svg)

```text
1. n == 1 ? 返回 0
2. 建邻接表：adj[u] 存 (v, start, end)
3. dist[0] = 0，其余 +inf；小根堆放 (0, 0)
4. while 堆非空：
       弹出 (t, u)；若 t > dist[u] 则跳过（过期状态）
       若 u == n-1：返回 t
       对每条出边 (v, s, e)：
           若 t > e：跳过（窗口已关闭）
           nt = max(t, s) + 1
           若 nt < dist[v]：更新并入堆
5. 堆空仍未到达：返回 -1
```

### 3.4 示例演算

![示例 2 的时刻表](images/bw160_q3_example_walk.svg)

示例 2：$n=4$，边为 $(0,1,[0,3])$、$(1,3,[7,8])$、$(0,2,[1,5])$、$(2,3,[4,7])$。

| 时刻 | 位置 | 动作 | 说明 |
|------|------|------|------|
| 0 | 0 | 等待 | 边 $0\to2$ 的窗口 $[1,5]$ 尚未开启 |
| 1 | $0\to2$ | 通行 | 到达 $t=2$ |
| 2 | 2 | 等待 | 边 $2\to3$ 的窗口 $[4,7]$ |
| 4 | $2\to3$ | 通行 | 到达 $t=5$，即终点 |

另一条路 $0\to1\to3$：$t=1$ 到达节点 1，再等 $1\to3$ 的窗口 $[7,8]$，最早 $t=8$ 才能到，显然更差。

## 4. 算法细节

1. **为什么不必考虑「等待更久再走」**：从 $u$ 出发的最早可行时刻就是 $\max(t,s)$，多等只会让到达更晚，不会带来收益（边没有容量限制）。
2. **过期边的判断**：`t > e` 才跳过；`t == e` 时仍可用（可以理解为在 $e$ 这一秒出发，$e+1$ 到达）。这是最容易差一的地方。
3. **`n == 1`**：起点就是终点，答案 0，需要特判（否则 Dijkstra 的 `u == n-1` 会返回 0，其实也对，但显式特判更清晰）。
4. **`dist` 类型**：时刻可到 $10^9+1$，`long long` 或足够大的 `int`；用 `LLONG_MAX/4` 作哨兵避免加法溢出。
5. **堆的懒惰删除**：`if (t != dist[u]) continue;` 即可，无需 `decrease-key`。
6. **重边**：同一对 $(u,v)$ 可能有多条窗口不同的边，全部保留即可，Dijkstra 会自动挑最优的。
7. **自环**：题目保证 $u_i \ne v_i$，无需处理。
8. **答案范围**：$1 \le n \le 10^5$，答案最大约 $10^9 + 1$，`int` 足够，但内部用 `long long` 更稳。

## 5. 正确性证明

**引理 1（最早到达的支配性）**：若能在时刻 $t_1$ 到达节点 $u$，则对任意 $t_2 \ge t_1$，从 $(u, t_2)$ 出发能走出的任何后续路径，都可以从 $(u, t_1)$ 出发通过「在 $u$ 原地等待 $t_2 - t_1$ 秒」复现，最终到达时刻不更晚。

**证明**：等待不改变节点位置、也不消耗除时间以外的资源；在 $(u,t_1)$ 等到 $t_2$ 后，状态与 $(u,t_2)$ 完全相同，后续可复现同一串操作。∎

**引理 2（松弛公式正确）**：从节点 $u$ 在时刻 $t$ 出发，经边 $(u,v,s,e)$ 的最早到达时刻为

$$\text{arrive} = \begin{cases}\max(t, s) + 1, & t \le e \\ +\infty, & t > e\end{cases}$$

**证明**：若 $t > e$，窗口已过，不能在窗口内出发（题目要求出发时刻 $\in [s,e]$），边不可用。若 $t \le e$：出发时刻 $\tau$ 需满足 $\tau \ge t$（不能早于到达）且 $\tau \in [s,e]$，最小的可行 $\tau = \max(t,s)$（需验证 $\max(t,s) \le e$：由 $t \le e$ 且 $s \le e$ 得 $\max \le e$）。移动耗时 1，故到达 $\max(t,s)+1$。∎

**引理 3（Dijkstra 适用性）**：定义「到达时刻」为距离，则松弛满足：若 $t_1 \le t_2$，则从 $t_1$ 松弛出的到达时刻不大于从 $t_2$ 松弛出的到达时刻。即距离函数关于时间单调不减。

**证明**：$\max(t,s)+1$ 关于 $t$ 单调不减，且 $t>e$ 的不可用情形在 $t$ 更大时更不会变好。∎

**定理**：算法返回到达节点 $n-1$ 的最少时间（不可达为 $-1$）。

**证明**：由引理 1，只需保留每个节点的最早到达时刻，状态空间为 $n$ 个节点；由引理 2 松弛正确、由引理 3 距离单调（边权非负且先进先出性质成立），Dijkstra 的「每次取出未确定节点中 dist 最小者即为其最终最短路」论证完全适用，故 `dist[n-1]` 为最少时间。若堆空仍不可达，说明不存在任何可行路径，$-1$ 正确。∎

## 6. 复杂度分析

- **时间**：$O((n + E)\log n)$。每条边最多松弛一次（有效时），每次入堆 $O(\log V)$，堆操作总数 $O(E)$。$n, E \le 10^5$。
- **空间**：$O(n + E)$。邻接表 $O(E)$，`dist` 与堆 $O(n + E)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minTime(int n, vector<vector<int>>& edges) {
        if (n == 1) return 0;
        vector<vector<array<long long, 3>>> adj(n);   // 邻接表：{to, start, end}
        for (auto& e : edges) {
            adj[e[0]].push_back({(long long)e[1], (long long)e[2], (long long)e[3]});
        }

        const long long INF = LLONG_MAX / 4;
        vector<long long> dist(n, INF);
        priority_queue<pair<long long, int>, vector<pair<long long, int>>, greater<>> pq;
        dist[0] = 0;
        pq.push({0, 0});
        while (!pq.empty()) {
            auto [t, u] = pq.top();
            pq.pop();
            if (t != dist[u]) continue;
            if (u == n - 1) return (int)t;
            for (auto& e : adj[u]) {
                long long v = e[0], s = e[1], en = e[2];
                if (t > en) continue;                  // 已经错过这条边的时间窗
                long long nt = max(t, s) + 1;          // 必要时原地等到 s 再走
                if (nt < dist[v]) {
                    dist[v] = nt;
                    pq.push({nt, (int)v});
                }
            }
        }
        return dist[n - 1] >= INF ? -1 : (int)dist[n - 1];
    }
};
```

### Python

```python
import heapq


class Solution:
    def minTime(self, n: int, edges: list[list[int]]) -> int:
        if n == 1:
            return 0
        adj = [[] for _ in range(n)]          # 邻接表：(to, start, end)
        for u, v, s, e in edges:
            adj[u].append((v, s, e))

        INF = float("inf")
        dist = [INF] * n
        dist[0] = 0
        pq = [(0, 0)]
        while pq:
            t, u = heapq.heappop(pq)
            if t != dist[u]:
                continue
            if u == n - 1:
                return t
            for v, s, e in adj[u]:
                if t > e:                      # 已经错过这条边的时间窗
                    continue
                nt = max(t, s) + 1             # 必要时原地等到 s 再走
                if nt < dist[v]:
                    dist[v] = nt
                    heapq.heappush(pq, (nt, v))
        return -1 if dist[n - 1] == INF else dist[n - 1]
```

## 8. 边界情况与易错点

1. **`n == 1`**：起点即终点，返回 0；若不特判，Dijkstra 弹出 $(0,0)$ 时 `u == n-1` 也会返回 0，但显式处理更清楚。
2. **`t == e` 仍可通行**：窗口是闭区间，`t > e` 才过期；写成 `t >= e` 会漏掉「恰好最后一秒出发」的路径。
3. **早到要等**：`nt = max(t, s) + 1`，别写成 `t + 1` 或 `s + 1`。
4. **节点 0 无出边**：如示例 3，堆空后返回 `-1`，不要返回 0 或 `INF`。
5. **`dist` 哨兵溢出**：C++ 用 `LLONG_MAX/4`，直接 `LLONG_MAX` 做加法会溢出成负数。
6. **重边与多窗口**：同一对节点间可能有多条边，保留全部，Dijkstra 自动选最优。
7. **`start > end`？** 题目保证 $0 \le \text{start} \le \text{end}$，无需处理非法窗口。
8. **`edges` 为空**：$n > 1$ 时不可达，返回 $-1$。
