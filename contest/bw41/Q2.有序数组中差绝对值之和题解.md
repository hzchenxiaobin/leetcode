# LeetCode 有序数组中差绝对值之和 题解

## 1. 题目概述

- **标题 / 题号**：有序数组中差绝对值之和（#1685，medium）
- **链接**：https://leetcode.cn/problems/sum-of-absolute-differences-in-a-sorted-array/
- **来源**：LeetCode 第 41 场双周赛 Q2
- **难度**：中等
- **标签**：数组、数学、前缀和

**题意**：给定**非递减**有序整数数组 `nums`，返回等长数组 `result`，其中

$$result[i] = \sum_{j \ne i} |nums[i] - nums[j]|$$

**约束**：

- $2 \le n \le 10^5$
- $1 \le nums[i] \le 10^4$

**关键在于"有序"**：它让每个绝对值都能去掉绝对值符号，从而用前缀和把整体复杂度做到 $O(n)$。

## 2. 示例

**示例 1**

```text
输入：nums = [2,3,5]
输出：[4,3,5]
解释：result[0] = |2-2|+|2-3|+|2-5| = 0+1+3 = 4
      result[1] = |3-2|+|3-3|+|3-5| = 1+0+2 = 3
      result[2] = |5-2|+|5-3|+|5-5| = 3+2+0 = 5
```

**示例 2**

```text
输入：nums = [1,4,6,8,10]
输出：[24,15,13,15,21]
```

**示例 3（重复元素边界补充）**

```text
输入：nums = [7,7,7,7]
输出：[0,0,0,0]
解释：所有元素相同，任意两元素差的绝对值为 0。
```

## 3. 解题思路

### 3.1 暴力思路

对每个 $i$ 遍历所有 $j$ 累加 $|nums[i]-nums[j]|$：$O(n^2)$，$n = 10^5$ 时约 $10^{10}$ 次操作，必然超时。瓶颈在于绝对值符号迫使我们"逐对"计算——突破口是利用**有序性**把绝对值拆开。

### 3.2 核心观察：有序 ⇒ 绝对值按左右两段展开

![核心观察：以 i 为界拆成左右两段](images/bw41_q2_split_concept.svg)

数组非递减，于是对固定 $i$：

- 左边的 $i$ 个数（下标 $0..i-1$）都 $\le nums[i]$，绝对值 $|nums[i]-nums[j]| = nums[i]-nums[j]$；
- 右边的 $n-1-i$ 个数（下标 $i+1..n-1$）都 $\ge nums[i]$，绝对值 $= nums[j]-nums[i]$。

两条单调性让绝对值符号全部消失，$result[i]$ 变成**纯线性组合**：

$$result[i] = \underbrace{nums[i]\cdot i - \mathrm{leftSum}(i)}_{\text{左边贡献}} + \underbrace{\mathrm{rightSum}(i) - nums[i]\cdot (n-1-i)}_{\text{右边贡献}}$$

其中 $\mathrm{leftSum}(i) = \sum_{j<i} nums[j]$、$\mathrm{rightSum}(i) = \sum_{j>i} nums[j]$。三个量都能用**前缀和** $O(1)$ 得到。

### 3.3 算法流程：一遍扫描维护左右和

![算法流程：一次遍历，leftSum/rightSum 滚动更新](images/bw41_q2_prefix_flow.svg)

```text
1. left = 0，right = sum(nums)
2. i 从 0 到 n-1：
       right -= nums[i]                # right 现在是 nums[i+1..n-1] 之和
       result[i] = nums[i]*i - left + right - nums[i]*(n-1-i)
       left  += nums[i]                # left 变成 nums[0..i] 之和，供下一轮用
3. 返回 result
```

不需要显式的前缀和数组——`left`/`right` 两个滚动变量足够，空间降到 $O(1)$（不含输出）。

### 3.4 示例演算

![示例演算：nums=[1,4,6,8,10] 的逐行计算](images/bw41_q2_walkthrough.svg)

以示例 2 为例（$n=5$，总和 $29$）：

| $i$ | $nums[i]$ | left（前缀和） | right（后缀和） | $nums[i]\cdot i - \text{left}$ | $\text{right} - nums[i]\cdot(n-1-i)$ | result |
|-----|-----------|----------------|------------------|-------------------------------|--------------------------------------|--------|
| 0 | 1 | 0 | 28 | $0-0=0$ | $28-4=24$ | **24** |
| 1 | 4 | 1 | 24 | $4-1=3$ | $24-12=12$ | **15** |
| 2 | 6 | 5 | 18 | $12-5=7$ | $18-12=6$ | **13** |
| 3 | 8 | 11 | 10 | $24-11=13$ | $10-4=6$ | **15** |
| 4 | 10 | 19 | 0 | $40-19=21$ | $0-0=0$ | **21** |

与期望输出 $[24,15,13,15,21]$ 完全一致。注意结果**左右对称**——这并非巧合：$result$ 本质是"每个点到其它所有点的距离和"，对称性由 $|x-y|$ 的对称性保证。

## 4. 算法细节

1. **先减后加的顺序**：进入第 $i$ 轮时先执行 `right -= nums[i]`，保证公式里的 right 恰是 $nums[i+1..n-1]$ 之和；离开时 `left += nums[i]`，下一轮的 left 恰是 $nums[0..i-1]$ 之和。两个更新的位置一前一后，写反就差一个 $nums[i]$。
2. **用总和初始化 right**：`right = sum(nums)`，避免再扫一遍求后缀和数组，把辅助空间从 $O(n)$ 压到 $O(1)$。
3. **溢出分析**：$n \le 10^5$，$nums[i] \le 10^4$。$nums[i] \cdot i \le 10^4 \cdot 10^5 = 10^9$，贴着 `int` 上界（约 $2.1 \times 10^9$）；leftSum $\le 10^9$ 同理。result 单项虽然 $\le 10^9$ 量级，但**中间项** $nums[i]\cdot i$ 与 left 的组合已接近上界，稳妥起见 C++ 用 `long long` 计算再转回 `int`。
4. **重复元素无需处理**：$nums[j] \le nums[i]$（$j<i$）在相等时同样成立，公式对重复元素天然正确（见示例 3，全部为 0）。
5. **也可用显式前缀和数组**：`pre[i] = pre[i-1] + nums[i]`，则 $\mathrm{leftSum}(i) = pre[i-1]$、$\mathrm{rightSum}(i) = pre[n-1] - pre[i]$。滚动变量版只是它的常数优化。

## 5. 正确性证明

**引理 1（有序性去绝对值）**：设 `nums` 非递减，则对任意 $i$ 与 $j < i$ 有 $|nums[i] - nums[j]| = nums[i] - nums[j]$；对 $j > i$ 有 $|nums[i] - nums[j]| = nums[j] - nums[i]$。

**证明**：非递减意味着 $j < i \Rightarrow nums[j] \le nums[i]$，故 $nums[i] - nums[j] \ge 0$，绝对值等于自身；$j > i$ 时对称。∎

**引理 2（线性展开公式）**：对每个 $i$，

$$\sum_{j \ne i} |nums[i]-nums[j]| = \big(nums[i]\cdot i - \textstyle\sum_{j<i} nums[j]\big) + \big(\textstyle\sum_{j>i} nums[j] - nums[i]\cdot(n-1-i)\big).$$

**证明**：由引理 1，左边 $= \sum_{j<i}(nums[i]-nums[j]) + \sum_{j>i}(nums[j]-nums[i])$。第一部分提出公因子：$\sum_{j<i} nums[i] - \sum_{j<i} nums[j] = nums[i] \cdot i - \sum_{j<i} nums[j]$（左侧恰有 $i$ 个 $j$）。第二部分同理，恰有 $n-1-i$ 个 $j$。∎

**定理**：算法返回的数组满足题意，且每个元素恰为 $\sum_{j \ne i} |nums[i]-nums[j]|$。

**证明**：对循环不变式归纳：第 $i$ 轮执行 `right -= nums[i]` 后，`left` $= \sum_{j<i} nums[j]$ 且 `right` $= \sum_{j>i} nums[j]$。$i=0$ 时 left $=0$、right $=$ 总和 $-nums[0]$ 成立。设第 $i$ 轮成立，则该轮按引理 2 的公式计算 result[i] 正确；轮末 `left += nums[i]` 使第 $i+1$ 轮的 left $= \sum_{j<i+1} nums[j]$，right 不变且恰为 $\sum_{j>i+1} nums[j]$，不变式保持。故每个 result[i] 均正确。∎

## 6. 复杂度分析

- **时间**：$O(n)$。一次求和初始化 + 一次主循环，每轮 $O(1)$ 次加减乘。
- **空间**：$O(1)$ 辅助空间（输出数组不计入）。若采用显式前缀和数组则为 $O(n)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> getSumAbsoluteDifferences(vector<int>& nums) {
        int n = nums.size();
        vector<int> ans(n);
        long long left = 0;                        // nums[0..i-1] 之和
        long long right = 0;                       // nums[i+1..n-1] 之和
        for (int x : nums) right += x;
        for (int i = 0; i < n; ++i) {
            right -= nums[i];
            // 左边 i 个数都比 nums[i] 小，右边 n-1-i 个数都不小于它
            long long cur = (long long)nums[i] * i - left
                          + right - (long long)nums[i] * (n - 1 - i);
            ans[i] = (int)cur;
            left += nums[i];
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def getSumAbsoluteDifferences(self, nums: list[int]) -> list[int]:
        n = len(nums)
        ans = [0] * n
        left = 0                       # nums[0..i-1] 之和
        right = sum(nums)              # nums[i..n-1] 之和
        for i, x in enumerate(nums):
            right -= x
            ans[i] = x * i - left + right - x * (n - 1 - i)
            left += x
        return ans
```

> 💡 两份代码均通过全部官方示例（`[4,3,5]`、`[24,15,13,15,21]`）及 3000 组随机有序数组与 $O(n^2)$ 暴力对拍（含全相同元素、单侧极值），`mismatch = 0`。

## 8. 边界情况与易错点

1. **$n = 2$**：result 两个元素相等且都等于 $|nums[0]-nums[1]|$。公式自动成立，无需特判。
2. **全相同元素**：所有绝对值为 0，公式给 0 ✓（左贡献 $x\cdot i - x\cdot i = 0$，右贡献同）。
3. **溢出**：$nums[i] \cdot i$ 最高 $10^9$，C++ `int` 乘法在 $nums[i]=10^4, i=10^5-1$ 时得到 $999\,990\,000 < 2^{31}-1$，看似安全；但 $left$ 可达 $10^9$，二者相减虽不会溢出，用 `long long` 中转能彻底排除隐患（乘法 `(long long)nums[i] * i` 的强转必须在乘法前）。
4. **left/right 更新时机**：`right -= nums[i]` 必须在用公式**之前**，`left += nums[i]` 必须在**之后**，颠倒是最高频的 WA 点。
5. **别忘"非递减"≠"严格递增"**：相等元素落在哪一段都不影响公式（引理 1 对 $\le$ 成立），不需要去重或分段。
6. **别用排序哈希映射**：题目直接给有序数组，无需再排；若输入无序才需先排（并按值处理重复），本题不存在该情形。
