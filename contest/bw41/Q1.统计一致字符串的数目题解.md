# LeetCode 统计一致字符串的数目 题解

## 1. 题目概述

- **标题 / 题号**：统计一致字符串的数目（#1684，easy）
- **链接**：https://leetcode.cn/problems/count-the-number-of-consistent-strings/
- **来源**：LeetCode 第 41 场双周赛 Q1
- **难度**：简单
- **标签**：位运算、数组、哈希表、字符串、计数

**题意**：给定一个由**互不相同**的小写字母组成的字符串 `allowed`（即一个"合法字符集"）和一个字符串数组 `words`。若某字符串的**每一个**字符都出现在 `allowed` 中，则称它是一致字符串。统计 `words` 中一致字符串的数目。

**约束**：

- $1 \le allowed.length \le 26$，`allowed` 中字符互不相同
- $1 \le words.length \le 10^4$
- $1 \le words[i].length \le 10$
- 所有字符串只含小写英文字母

## 2. 示例

**示例 1**

```text
输入：allowed = "ab", words = ["ad","bd","aaab","baa","badab"]
输出：2
解释："aaab" 与 "baa" 只含字符 'a'、'b'，是一致字符串；
      "ad"、"bd"、"badab" 都出现了 'd'，不是。
```

**示例 2**

```text
输入：allowed = "cad", words = ["cc","acd","b","ba","bac","bad","ac","d"]
输出：4
解释："cc"、"acd"、"ac"、"d" 是一致字符串；含 'b' 的四个都不是。
```

**示例 3（边界补充）**

```text
输入：allowed = "a", words = ["a", "aa", "aaa", "ab"]
输出：3
解释：前三个只含 'a'；"ab" 含 'b' 不一致。
```

## 3. 解题思路

### 3.1 暴力思路

对每个 `word` 的每个字符，都到 `allowed` 里线性扫一遍判断是否存在。最坏 $O(|words| \cdot |word| \cdot |allowed|) \approx 10^4 \cdot 10 \cdot 26 = 2.6 \times 10^6$，本题规模下其实也能过。但把 `allowed` 换成哈希集合（或位掩码）后单次判断降到 $O(1)$，代码更短、更快，也是这题真正想考的"签到最优路径"。

### 3.2 核心观察：字符集是"子集关系"，26 个字母恰好装进一个整数

![核心观察：allowed 压缩成 26 位掩码](images/bw41_q1_bitmask_concept.svg)

`allowed` 至多 26 个互不相同的字母，而一个 `int` 恰好有 32 位——**用第 $c-{\tt 'a'}$ 位表示字母 $c$ 是否出现**，整个字符集就压成一个整数 `mask`。判断"word 的每个字符都在 allowed 中"，等价于判断"word 自身的字符集掩码 `m` 是 `mask` 的子集"，一条位运算即可：

$$m \,\&\, {\sim}mask = 0 \iff m \subseteq mask$$

即 word 用到的位，allowed 全部都有。逐字符判断 `((mask >> (c-'a')) & 1) == 1` 是它的展开形式，两者等价。

### 3.3 算法流程

![算法流程：建掩码、逐词检查](images/bw41_q1_algorithm_flow.svg)

```text
1. mask = 0；对 allowed 的每个字符 c：mask |= 1 << (c - 'a')
2. ans = 0
3. 对每个 word：
       ok = true
       对 word 的每个字符 c：
            若 ((mask >> (c - 'a')) & 1) == 0：ok = false，跳出
       ans += ok
4. 返回 ans
```

### 3.4 示例演算

以示例 2 为例：`allowed = "cad"`，`mask = {c, a, d}` = 二进制 `...0001101`（'a' 位、'c' 位、'd' 位为 1）。

| word | 字符集 | 是否 ⊆ {a,c,d} | 说明 |
|------|--------|----------------|------|
| "cc" | {c} | ✓ | 计入 |
| "acd" | {a,c,d} | ✓ | 计入 |
| "b" | {b} | ✗ | 'b' 位不在 mask |
| "ba" | {a,b} | ✗ | 'b' 位不在 mask |
| "bac" | {a,b,c} | ✗ | 'b' 位不在 mask |
| "bad" | {a,b,d} | ✗ | 'b' 位不在 mask |
| "ac" | {a,c} | ✓ | 计入 |
| "d" | {d} | ✓ | 计入 |

共 $4$ 个，返回 4。✓

## 4. 算法细节

1. **掩码构建**：`mask |= 1 << (c - 'a')`。`allowed` 字符互不相同，不需要担心重复置位；即便重复，`|=` 也幂等。
2. **两种判断写法**：
   - 逐字符法：遇到第一个非法字符立刻 `break`，平均情形更快（很多 word 在第一个字符就被否决）；
   - 整词掩码法：先把 word 压成 `m` 再判 `m & ~mask == 0`，必须扫完整个 word，但代码最短。两者复杂度同阶。
3. **位优先级陷阱**（C++）：`mask >> (c - 'a') & 1` 中 `>>` 优先级高于 `&`，结果正确，但更稳妥的写法是显式加括号 `(mask >> (c - 'a')) & 1`，避免读代码的人犹豫。
4. **`~mask` 的类型**（C++）：`mask` 是 `int` 时 `~mask` 高位全 1，`m & ~mask` 仍正确（m 高位本来就是 0），不必担心符号位。
5. **为什么不用 `set`**：`unordered_set<char>` 单次判断是 $O(1)$ 但常数大（哈希、缓存不友好）；位掩码是一次寄存器 AND，快一个量级。26 个字母的集合场景，位掩码永远是首选。

## 5. 正确性证明

**引理 1（掩码与集合的对应）**：设 $\mathrm{bit}(x) = \{c : x \text{ 的第 } c \text{ 位为 } 1\}$。按第 3.3 节构建的 `mask` 满足 $\mathrm{bit}(mask) = \mathrm{set}(allowed)$；同理 word 的掩码 `m` 满足 $\mathrm{bit}(m) = \mathrm{set}(word)$。

**证明**：`mask` 初值为 0（$\mathrm{bit}(0) = \varnothing$）；对字符 $c$ 执行 `mask |= 1 << (c-'a')` 恰把 $c$ 加入 $\mathrm{bit}(mask)$，且不影响其它位。归纳即得。∎

**引理 2（子集判定的位运算刻画）**：对非负整数 $m, mask$，$m \,\&\, {\sim}mask = 0 \iff \mathrm{bit}(m) \subseteq \mathrm{bit}(mask)$。

**证明**：$m \,\&\, {\sim}mask$ 的第 $c$ 位为 1 当且仅当 $m$ 的第 $c$ 位为 1 且 $mask$ 的第 $c$ 位为 0，即 $c \in \mathrm{bit}(m) \setminus \mathrm{bit}(mask)$。故 $m \,\&\, {\sim}mask = 0$ 当且仅当 $\mathrm{bit}(m) \setminus \mathrm{bit}(mask) = \varnothing$，即子集关系成立。∎

**定理**：算法返回的正是 `words` 中一致字符串的个数。

**证明**：word 是一致字符串 $\iff$ $\mathrm{set}(word) \subseteq \mathrm{set}(allowed)$（一致性的定义逐字符展开）。由引理 1、2，逐字符判断 `((mask >> (c-'a')) & 1) == 1` 对所有字符成立 $\iff$ $\mathrm{bit}(m) \subseteq \mathrm{bit}(mask) \iff$ 一致字符串。算法对每个 word 独立判定并计数，互不干扰，故计数正确。∎

## 6. 复杂度分析

- **时间**：$O(|allowed| + \sum_i |words_i|)$。建掩码线性扫一次 `allowed`；每个 word 逐字符检查，每个字符 $O(1)$。总量 $\le 26 + 10^4 \cdot 10 \approx 10^5$。
- **空间**：$O(1)$。只用了常数个整数变量（mask、循环变量），不随输入规模增长。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int countConsistentStrings(string allowed, vector<string>& words) {
        int mask = 0;                              // allowed 集合的位掩码
        for (char c : allowed) mask |= 1 << (c - 'a');
        int ans = 0;
        for (const string& w : words) {
            bool ok = true;
            for (char c : w) {
                if (((mask >> (c - 'a')) & 1) == 0) { ok = false; break; }
            }
            ans += ok;                             // 布尔转 0/1 累加
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def countConsistentStrings(self, allowed: str, words: list[str]) -> int:
        mask = 0
        for c in allowed:
            mask |= 1 << (ord(c) - ord('a'))
        ans = 0
        for w in words:
            m = 0
            for c in w:
                m |= 1 << (ord(c) - ord('a'))
            if m & ~mask == 0:                  # word 的字符集是 allowed 的子集
                ans += 1
        return ans
```

> 💡 两份代码均通过全部官方示例（`2`、`7`、`4`）及 3000 组随机数据与哈希集合暴力实现对拍，`mismatch = 0`。

## 8. 边界情况与易错点

1. **`allowed` 单字符**：mask 只有一个位，任何含其它字母的 word 都被否决，无需特判。
2. **空 word 不存在**：约束保证 $|words_i| \ge 1$；若平台放宽到空串，空串字符集为空集，是任何集合的子集，应计入（两份代码天然如此）。
3. **位运算优先级**（C++）：`mask >> k & 1` 可行但建议加括号；`1 << (c - 'a')` 中 `c - 'a'` 必须先算，漏括号会变成 `1 << c - 'a'`（`<<` 优先级高于 `-`，等价 `(1 << c) - 'a'`，直接错）。
4. **别把"字符互不相同"想复杂**：它只保证 mask 每位至多置一次，不影响算法；就算题目允许重复字符，`|=` 也幂等。
5. **Python 的 `~mask`**：Python 整数无限位，`m & ~mask` 中 `~mask` 负数补码高位全 1，但 `m` 高位全 0，结果正确且非负。
