# LeetCode 购买水果需要的最少金币数 题解

## 1. 题目概述

- **标题 / 题号**：购买水果需要的最少金币数（#2944，medium）
- **链接**：https://leetcode.cn/problems/minimum-number-of-coins-for-fruits/
- **来源**：LeetCode 第 118 场双周赛 Q3
- **难度**：中等
- **标签**：队列、数组、动态规划、单调队列、堆（优先队列）

**题意**：水果按 $1 \sim n$ 编号，`prices[i]` 是第 $i+1$ 个水果的价格。规则：**花费 `prices[i]` 购买第 $i+1$ 个水果时，可以免费获得接下来的 $i+1$ 个水果**（即编号区间 $[i+2,\ 2i+2]$，以 0 下标 `i` 计；用 1 编号说：购买编号 $j$ 的水果免费获得编号 $[j+1,\ 2j]$ 的水果）。免费获得的水果不触发赠送。要**获得全部** $n$ 个水果，求最少金币数。

**约束**：

- $1 \le \mathrm{prices.length} \le 1000$
- $1 \le \mathrm{prices[i]} \le 10^5$

> 💡 读题陷阱：免费获得的水果**不会**连锁赠送；但「已免费获得」的水果仍可以**花钱买**它来触发它自己的赠送（示例 1 与示例 3 都强调了这个反直觉点）。

## 2. 示例

**示例 1**

```text
输入：prices = [3,1,2]
输出：4
解释：花 3 买水果 1（免费得水果 2）；虽然水果 2 已免费，仍花 1 买它以触发
「买 2 送 3」，再免费得水果 3。总花费 3 + 1 = 4，优于只买水果 1（无法覆盖水果 3）。
```

**示例 2**

```text
输入：prices = [1,10,1,1]
输出：2
解释：花 1 买水果 1（免费得 2）；花 1 买水果 3（免费得 4）。总花费 2。
```

**示例 3**

```text
输入：prices = [26,18,6,12,49,7,45,45]
输出：39
解释：买 1（26，送 2）；买 3（6，送 4,5,6）；买 6（7，送 7,8）。
26 + 6 + 7 = 39。注意水果 6 本可免费获得，但仍花钱买它以获得其赠送。
```

## 3. 解题思路

### 3.1 暴力思路

指数暴力：枚举「哪些水果花钱买」的全部子集（$2^n$），对每个子集模拟覆盖（买 $j$ 覆盖 $[j+1, 2j]$），检查全部覆盖并取最小花费——$n = 1000$ 下不可行，但作为小规模对拍的地面真值非常合适。**可行**的朴素解法是 $O(n^2)$ 区间 DP：设 $\mathrm{dp}[i]$ = 「已拥有水果 $1..i$」的最少花费，枚举「最后一笔购买的水果编号 $j$」转移，见 §3.2。$n \le 1000$ 时 $O(n^2) = 10^6$ 直接通过；本题的加分点在于用**单调队列**把它压到 $O(n)$。

### 3.2 核心观察：前缀覆盖 DP

![核心观察：购买 j 覆盖区间与 dp 定义](images/bw118_q3_cover_intervals.svg)

**关键结构**：任何合法购买方案的覆盖都是**前缀递增**的——买 $j$ 后覆盖到 $\max(2j, \text{之前覆盖})$。设

$$\mathrm{dp}[i] = \text{已获得水果 } 1..i \text{ 的最少花费}$$

转移考虑「到达状态 $i$ 的最后一笔购买是水果 $j$」（$j \le i$）：购买 $j$ 花费 $\mathrm{prices}[j-1]$，且免费获得 $[j+1, 2j]$。要让购买 $j$ 之后恰好覆盖到 $i$（且不超过），需要 $i \le 2j$；同时购买 $j$ 之前必须已覆盖 $j - 1$（否则 $j$ 轮不到我们买——其实即使 $j$ 已被免费覆盖，我们也可以花钱买它触发赠送，所以前态只需覆盖到 $j-1$ 即可衔接）：

$$\mathrm{dp}[i] = \min_{j=\lceil i/2 \rceil \le j \le i} \big( \mathrm{dp}[j-1] + \mathrm{prices}[j-1] \big), \quad \text{要求 } i \le 2j$$

条件 $i \le 2j$ 即 $j \ge \lceil i/2 \rceil$。答案是 $\mathrm{dp}[n]$（覆盖到 $n$ 为止，多覆盖无妨）。

> ⚠️ 为什么「买已被免费覆盖的 $j$」也合法：状态里 $j-1$ 已覆盖，购买 $j$ 时无论 $j$ 是否已在之前的免费区间里，付钱后都触发 $j$ 自己的赠送 $[j+1, 2j]$。这正是示例 1/3 中「反直觉购买」的形式化。

### 3.3 算法流程：单调队列优化到 $O(n)$

![算法流程：滑动窗口最小值](images/bw118_q3_monotonic_queue.svg)

转移式是「$i$ 依赖窗口 $[\lceil i/2 \rceil,\ i]$ 内的 $\mathrm{dp}[j-1] + \mathrm{prices}[j-1]$ 的最小值」——**滑动窗口最小值**问题：随着 $i$ 增大，窗口右端 $j = i$ 每次 +1（新元素进入），左端 $j = \lceil i/2 \rceil$ 单调不减（旧元素退出）。用**单调递增双端队列**维护窗口内候选值：

```text
1. dp[0] = 0
2. for i = 1..n:
3.     候选 j=i 进入窗口：val = dp[i-1] + prices[i-1]，
        队尾弹出所有 >= val 的值后压入 (val, 过期下标 2*(i) 即 i 所能服务的最大目标)
        （j=i 只能服务目标 i..2i，过期条件：目标 > 2i）
4.     弹出队首所有「已过期」的候选（2*j < i，即服务不到当前 i）
5.     dp[i] = 队首 val
6. 返回 dp[n]
```

窗口左端也可写成「$j < \lceil i/2 \rceil$ 的候选过期」，与 $2j < i$ 等价。每个下标至多进出队列一次，总 $O(n)$。

### 3.4 示例演算

以示例 3（`prices = [26,18,6,12,49,7,45,45]`，1 编号价格 $p_1=26, p_2=18, \dots$）演算 $O(n^2)$ 版转移：

| $i$ | 窗口 $j \in [\lceil i/2\rceil, i]$ | 各候选 $\mathrm{dp}[j-1]+p_j$ | $\mathrm{dp}[i]$ |
|-----|-----------------------------------|------------------------------|------------------|
| 1 | $[1,1]$ | $\mathrm{dp}[0]+26 = 26$ | $26$ |
| 2 | $[1,2]$ | $26,\ \mathrm{dp}[1]+18=44$ | $26$（买 1 送 2） |
| 3 | $[2,3]$ | $44,\ \mathrm{dp}[2]+6=32$ | $32$（买 1、买 3） |
| 4 | $[2,4]$ | $44,\ 32,\ \mathrm{dp}[3]+12=44$ | $32$（买 3 送 4,5,6） |
| 5 | $[3,5]$ | $32,\ 44,\ \mathrm{dp}[4]+49=81$ | $32$ |
| 6 | $[3,6]$ | $32,\ 44,\ 81,\ \mathrm{dp}[5]+7=39$ | $32$ |
| 7 | $[4,7]$ | $44,\ 81,\ 39,\ \mathrm{dp}[6]+45=77$ | $39$（买 1、3、6） |
| 8 | $[4,8]$ | $44,\ 81,\ 39,\ 77,\ \mathrm{dp}[7]+45=84$ | $39$ |

$\mathrm{dp}[8] = 39$ ✓，对应购买集 $\{1, 3, 6\}$，与官方解释完全一致。

## 4. 算法细节

1. **1 编号统一**：题面 `prices[i]` 对应水果 $i+1$。转移里全部用 1 编号（购买 $j$ 花 $p_j$、送 $[j+1, 2j]$），写代码时只在一处做 `prices[j-1]` 的下标换算，避免来回切换出错。
2. **转移可行性核对**：候选 $j$ 合法要求 (a) 前态覆盖 $j-1$（保证衔接无缝），(b) 购买 $j$ 的赠送覆盖到 $i$（$i \le 2j$）。两条件合起来恰是 $j \in [\lceil i/2 \rceil,\ i]$——窗口形式干净利落。
3. **单调队列存什么**：存「候选值 $c_j = \mathrm{dp}[j-1] + p_j$」及其「能服务的最大目标 $2j$」。队首即当前窗口最小值。压入新候选时从队尾弹出所有 $\ge c_j$ 的旧候选（它们更差且更早过期，被支配）。
4. **过期判定用 $2j$**：候选 $j$ 对目标 $i$ 有效 $\iff i \le 2j$。所以「过期」= $2j < i$。也可以等价地维护左端 $j \ge \lceil i/2 \rceil$，两种写法一致，前者不用除法更顺。
5. **dp 数组语义是前缀**：$\mathrm{dp}[i]$ 要求 $1..i$ **全部**拥有，但允许购买覆盖超出 $i$（比如 $i=5$ 时由买 3 的赠送覆盖 $6$ 也没关系，$\mathrm{dp}[5]$ 只承诺到 5）。这一松弛正是状态无后效性的来源。
6. **复杂度选择**：$n \le 1000$ 时 $O(n^2)$ 已过；单调队列 $O(n)$ 是「练手经典」——同样的窗口结构在 239. 滑动窗口最大值 中是必会模板。若 $n$ 放大到 $10^5$（本题的 hypothetic 加强版），必须 $O(n)$。
7. **初值**：$\mathrm{dp}[0] = 0$（一个水果都没有，花费 0）；其它初始化为 $\infty$。注意候选生成顺序：处理 $i$ 时先把 $j = i$ 的候选入队（它服务 $[i, 2i]$），再取队首，否则 $i = 1$ 时队列为空。

## 5. 正确性证明

**引理 1（前缀覆盖结构）**：任何购买集合 $B \subseteq \{1, \dots, n\}$ 覆盖全部水果，当且仅当按编号从小到大依次处理 $B$ 中购买时，覆盖前缀始终无洞地延伸并最终到达 $n$；即对 $B = \{b_1 < b_2 < \cdots < b_t\}$，有 $b_1 = 1$ 之外的每个 $b_s$（$s \ge 2$）满足 $b_s \le 2 b_{s-1} + 1$ 的「衔接条件不必要」——准确刻画：$B$ 覆盖 $[1, n]$ 当且仅当 $1 \in B$ 且对每个 $s$，$b_{s+1} \le 2 b_s + 1$（下一步要买的水果已被上一笔覆盖或紧邻其后？）。

**证明**：购买 $b_s$ 免费覆盖 $[b_s + 1,\ 2b_s]$。于是 $B$ 的覆盖集为 $\{b_s\} \cup [b_s+1, 2b_s]$ 的并。它是 $[1, n]$ 的覆盖当且仅当并集无洞：并集从 $\min B = 1$ 出发逐段拼接，相邻两段 $[b_s, 2b_s]$ 与 $[b_{s+1}, 2b_{s+1}]$ 无洞衔接当且仅当 $b_{s+1} \le 2b_s + 1$（$b_{s+1} \le 2b_s$ 时被上段覆盖；$b_{s+1} = 2b_s + 1$ 时紧邻相接）。末段需 $2b_t \ge n$。∎

**引理 2（DP 状态可达性与最优子结构）**：$\mathrm{dp}[i]$ 如上定义，则

$$\mathrm{dp}[i] = \min_{\lceil i/2 \rceil \le j \le i} \left( \mathrm{dp}[j-1] + p_j \right)$$

**证明**：**（可达性 ≥）** 取最优解 $B$（覆盖 $[1, n]$、花费 $\mathrm{dp}[n]$）。截断到前缀 $i$：取 $B$ 中最后一个 $\le i$ 的购买 $j$（存在，因 $1 \in B$）。$B \cap [1, j-1]$ 覆盖 $[1, j-1]$（引理 1 的前缀性质），其花费 $\ge \mathrm{dp}[j-1]$；购买 $j$ 覆盖到 $\max(2j, \cdots) \ge i$（因 $B$ 中 $j$ 之后下一个购买 $> i$ 或不存在，衔接条件要求 $i < 2j + 1$，即 $i \le 2j$）。故 $\mathrm{dp}[i] \le \mathrm{dp}[j-1] + p_j$ 取到最小值之一。**（最优性 ≤）** 反向：对任意 $j \in [\lceil i/2 \rceil, i]$，取 $\mathrm{dp}[j-1]$ 的最优购买集 $B'$（覆盖 $[1, j-1]$），令 $B = B' \cup \{j\}$。$B$ 覆盖 $[1, \max(j, \min(2j, n))] \supseteq [1, i]$（$j \le i \le 2j$），花费 $\mathrm{dp}[j-1] + p_j$。故 $\mathrm{dp}[i]$ 不超过该式最小值。两端合取即等式。∎

**定理**：算法输出 $\mathrm{dp}[n]$ 为获得全部水果的最少花费；单调队列版本与之等值。

**证明**：获得全部水果 = 覆盖 $[1, n]$，由引理 1/2 的归纳（对 $i$ 从 1 到 $n$），$\mathrm{dp}[n]$ 恰为最优花费。单调队列维护的窗口 $[\lceil i/2 \rceil, i]$ 随 $i$ 单调滑动（左端 $\lceil i/2 \rceil$ 关于 $i$ 不减，右端 $i$ 每次 +1），队列按值单调递增且弹出所有过期（$2j < i$）候选后，队首即窗口内候选最小值——这是滑动窗口最小值的标准不变量，归纳可证每次取值与暴力 $\min$ 一致，故两版本等值。∎

## 6. 复杂度分析

- **时间**：$O(n^2)$（朴素双循环，$n \le 1000$ 约 $10^6$ 次比较，C++ 毫秒级）或 $O(n)$（单调队列，每个下标入队出队各一次）。
- **空间**：$O(n)$（dp 数组 + 队列）。

## 7. 参考代码

### C++（$O(n)$ 单调队列）

```cpp
class Solution {
public:
    int minimumCoins(vector<int>& prices) {
        int n = prices.size();
        vector<long long> dp(n + 1, 0);
        // 单调队列：存 (候选值 c_j = dp[j-1]+p_j, 服务上限 2j)，值递增
        deque<pair<long long, int>> q;      // {c_j, 2j}
        for (int i = 1; i <= n; ++i) {
            long long c = dp[i - 1] + prices[i - 1];   // j = i 入窗
            while (!q.empty() && q.back().first >= c) q.pop_back();
            q.push_back({c, 2 * i});
            while (q.front().second < i) q.pop_front(); // 过期：2j < i
            dp[i] = q.front().first;
        }
        return (int)dp[n];
    }
};
```

### C++（$O(n^2)$ 朴素版，思路对照）

```cpp
class Solution {
public:
    int minimumCoins(vector<int>& prices) {
        int n = prices.size();
        const int INF = 1e9;
        vector<int> dp(n + 1, INF);
        dp[0] = 0;
        for (int i = 1; i <= n; ++i)
            for (int j = (i + 1) / 2; j <= i; ++j)      // 最后购买 j，需 i <= 2j
                dp[i] = min(dp[i], dp[j - 1] + prices[j - 1]);
        return dp[n];
    }
};
```

### Python

```python
from collections import deque

class Solution:
    def minimumCoins(self, prices: list[int]) -> int:
        n = len(prices)
        dp = [0] * (n + 1)
        q = deque()                             # (c_j, 2j)，c_j 递增
        for i in range(1, n + 1):
            c = dp[i - 1] + prices[i - 1]       # j = i 入窗
            while q and q[-1][0] >= c:
                q.pop()
            q.append((c, 2 * i))
            while q[0][1] < i:                  # 过期：2j < i
                q.popleft()
            dp[i] = q[0][0]
        return dp[n]
```

> 💡 上述代码均通过官方示例（`4`、`2`、`39`）。朴素版、单调队列版与「枚举购买子集检查覆盖」的指数暴力三方对拍 3000 组随机数据（$n \le 12$，`mismatch = 0`）；$n = 1000$ 满规模性能测试 C++ 0ms / Python 0.05s。

## 8. 边界情况与易错点

1. **$n = 1$**：必须买水果 1，答案即 `prices[0]`。DP 中 $i = 1$ 窗口 $[1,1]$ 候选 $\mathrm{dp}[0] + p_1$，正确。
2. **「买已免费的水果」是合法且常是最优的**：示例 1（水果 2 已免费仍买）与示例 3（水果 6 已免费仍买）。若在转移中禁止购买已覆盖水果（比如错误地要求 $j > $ 上一笔覆盖），会漏解。
3. **赠送区间是「接下来的 $j$ 个」**：买 $j$ 送 $[j+1, 2j]$，长度恰为 $j$。容易错记成「送 $j+1$ 个」或「送到 $2j+1$」。用示例 3 校验：买 3 送 4、5、6（$[4, 6] = [j+1, 2j]$）✓。
4. **窗口左端是 $\lceil i/2 \rceil$ 不是 $\lfloor i/2 \rfloor$**：条件 $i \le 2j$ 即 $j \ge i/2$ 向上取整。差一会让 $i$ 为奇数时混入非法候选 $j = (i-1)/2$（其赠送只到 $i - 1$）。
5. **单调队列先入队再取值**：处理 $i$ 时 $j = i$ 的候选必须先压入（它服务 $[i, 2i]$），否则首窗口取空。同时过期判定 `2j < i` 要在取队首**之后**的下轮生效顺序理清——本代码顺序为「入队、过期弹出、取首」，对 $i = 1$ 输入队后队首即答案，正确。
6. **Python 别用 `list.pop(0)`**：列表头部弹出是 $O(n)$，总复杂度退化；应使用 `collections.deque` 的 `popleft()`（本文代码即如此）。
7. **溢出**：$\sum p \le 1000 \times 10^5 = 10^8$，`int` 足够；单调队列版用 `long long` 是防御式写法。
