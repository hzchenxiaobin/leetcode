# LeetCode 找到最大非递减数组的长度 题解

## 1. 题目概述

- **标题 / 题号**：找到最大非递减数组的长度（#2945，hard）
- **链接**：https://leetcode.cn/problems/find-maximum-non-decreasing-array-length/
- **来源**：LeetCode 第 118 场双周赛 Q4
- **难度**：困难
- **标签**：栈、队列、数组、二分查找、动态规划、前缀和、单调队列、单调栈

**题意**：给定数组 `nums`，每次操作可选一段**连续子数组**，将其替换为该子数组的**和**。可执行任意次操作，求最终能得到的最长**非递减**数组的长度。

**约束**：

- $1 \le \mathrm{nums.length} \le 10^5$
- $1 \le \mathrm{nums[i]} \le 10^5$

> 💡 关键一步是看出「任意次合并」的最终形态 = 原数组的一种**划分**：把 `nums` 切成若干段，每段合并成一个数（段和），要求段和从左到右非递减，最大化段数。所有元素为正保证前缀和严格递增——这是后面一切单调性的基石。

## 2. 示例

**示例 1**

```text
输入：nums = [5,2,2]
输出：1
解释：无论怎么切成 2 段，[5],[2,2]→[5,4] 或 [5,2],[2]→[7,2] 都不非递减；
只能整段合并为 [9]。
```

**示例 2**

```text
输入：nums = [1,2,3,4]
输出：4
解释：已非递减，无需操作。
```

**示例 3**

```text
输入：nums = [4,3,2,6]
输出：3
解释：合并 [3,2] 得 [4,5,6]，非递减。
```

**示例 4（结构补充）**

```text
输入：nums = [5,1,1,1,1,1]
输出：2
解释：合并 [5,1] 得 [6,1,1,1,1]？不非递减。正确切法：[5],[1,1,1,1,1]→[5,5]，
长度 2。此例说明「段和最小化」与「段数最大化」必须同时考虑，贪心切法易翻车。
```

## 3. 解题思路

### 3.1 暴力思路

首先证明问题等价于**划分**：任何操作序列的最终结果是若干不相交连续段的并（操作只会合并、不会拆开，且嵌套操作可交换顺序化归为「按最终段一次合并」）。于是暴力是枚举 $2^{n-1}$ 种切法——不可行。降一档是 $O(n^2)$ DP（见 3.2），$n = 10^5$ 时 $10^{10}$ 仍超时；正解要再用单调性压到 $O(n \log n)$（存在精巧的 $O(n)$ 单调栈变体，本文给出更易写的二分版）。

### 3.2 核心观察一：划分模型与前缀和 DP

![核心观察：划分模型与 dp 定义](images/bw118_q4_partition_dp.svg)

设 $\mathrm{pre}[i] = \sum_{k \le i} \mathrm{nums}[k]$（前缀和）。定义

$$\mathrm{dp}[i] = \text{前缀 } [1, i] \text{ 最多能切成的段数}$$

转移：枚举最后一段 $[j+1, i]$，条件是它的段和**不小于**前一段（以 $j$ 结尾那段）的段和。若同时维护

$$\mathrm{last}[i] = \text{在段数取到 } \mathrm{dp}[i] \text{ 的前提下，最后一段和的最小值}$$

（最小化末段和给后继转移留最大余地），则 $j$ 可作为 $i$ 的前驱当且仅当

$$\mathrm{pre}[i] - \mathrm{pre}[j] \ge \mathrm{last}[j] \iff \mathrm{pre}[j] + \mathrm{last}[j] \le \mathrm{pre}[i]$$

记 $T[j] = \mathrm{pre}[j] + \mathrm{last}[j]$（**门槛**：前缀 $j$ 的末段和加上其右边界，即「接在 $j$ 后面的下一段的左端点至少要累积到 $\mathrm{pre}[i] \ge T[j]$ 才装得下」），则

$$\mathrm{dp}[i] = \max_{j < i,\ T[j] \le \mathrm{pre}[i]} \big( \mathrm{dp}[j] + 1 \big), \qquad \mathrm{last}[i] = \mathrm{pre}[i] - \mathrm{pre}[j^*]$$

朴素实现 $O(n^2)$。

### 3.3 核心观察二：DP 的两个单调性 → 候选表 + 二分

![核心观察：单调候选表与二分查询](images/bw118_q4_monotonic_candidates.svg)

**单调性 A（$\mathrm{dp}$ 不减）**：$\mathrm{dp}[i+1] \ge \mathrm{dp}[i]$。把第 $i$ 个元素并入最优方案的最末段，段数不变（末段和只增，仍是合法划分——合法性只要求非递减，末段变大不会破坏前面的段）。因此**最大化段数**时，取「满足 $T[j] \le \mathrm{pre}[i]$ 的最大 $j$」一定不劣：$j$ 越大 $\mathrm{dp}[j]$ 越大（且由下面的支配关系，$\mathrm{last}$ 也可控）。

**单调性 B（候选支配）**：若 $j_1 < j_2$ 且 $T[j_1] \ge T[j_2]$，则 $j_1$ 被 $j_2$ **完全支配**——$j_2$ 的段数更大（$\mathrm{dp}[j_2] \ge \mathrm{dp}[j_1]$）而门槛不升，任何能用 $j_1$ 的转移都能换成 $j_2$ 且结果不劣。所以只需保留下标递增、$T$ **严格递增**的候选链。

于是维护候选表（栈结构）`cand`（同步存 `Ts`）：

- **插入 $i$**：计算 $T[i]$，从表尾弹出所有 $T \ge T[i]$ 的候选（被 $i$ 支配），再压入 $i$；
- **查询**：给定 $\mathrm{pre}[i]$，在 `Ts` 中**二分**找最大的 $j$ 使 $T[j] \le \mathrm{pre}[i]$；$T[0] = 0$ 恒满足（空前缀），保证查询非空。

每次插入均摊 $O(1)$（每个下标至多被弹出一次），查询 $O(\log n)$，总 $O(n \log n)$。

> ⚠️ 一个著名陷阱：试图用「查询时从栈顶弹掉 $T > \mathrm{pre}[i]$ 的候选」的单调栈版本——**弹出会永久丢失候选**（它们对更靠后的 $i$ 仍可能有效，因为 $\mathrm{pre}[i]$ 单调递增……不对，恰恰因为 $\mathrm{pre}$ 递增，被 $\mathrm{pre}[i]$ 拒绝的候选会被之后所有 $\mathrm{pre}[i'] \ge \mathrm{pre}[i]$ 同样拒绝？——不！查询时不能弹，原因在于**插入新候选会混序**：表尾新压入的候选 $T$ 更小却下标更大，若查询时按栈顶往下弹，弹掉的可能是刚插入的低门槛候选，而它对后续查询是最优的。正确姿势只有「二分查询、不动表」。反例见 §8 第 4 条。）

### 3.4 算法流程

```text
1. pre[0..n] 前缀和
2. cand = [0], Ts = [0]            # 前缀 0：dp=0, last=0, T=0
3. for i = 1..n:
4.     p = upper_bound(Ts, pre[i]) - 1     # 最大的 j: T[j] <= pre[i]
5.     j = cand[p]
6.     dp[i] = dp[j] + 1
7.     last[i] = pre[i] - pre[j]
8.     T[i] = pre[i] + last[i]
9.     从表尾弹出所有 T >= T[i] 的候选，压入 i
10. 返回 dp[n]
```

### 3.5 示例演算

![示例演算：候选表逐位演化](images/bw118_q4_example_walkthrough.svg)

以示例 4（`[5,1,1,1,1,1]`，$\mathrm{pre} = [0,5,6,7,8,9,10]$）演算（$L$ 表 $\mathrm{last}$）：

| $i$ | $\mathrm{pre}[i]$ | 二分命中 $j$ | $\mathrm{dp}[i]$ | $L[i]$ | $T[i]$ | 候选表（下标） |
|-----|------|------|------|------|------|----------------|
| 1 | 5 | 0 | 1 | 5 | 10 | $\{0, 1\}$（$T=0,10$） |
| 2 | 6 | 1（$T[1]=10 > 6$，回退到 0？$T[0]=0 \le 6$）→ $j=0$ | 1 | 6 | 12 | 弹 1（$10 < 12$ 不弹）→ $\{0, 1, 2\}$？ |

停一下——$i=2$ 时 $T[1] = 10 > 6 = \mathrm{pre}[2]$，命中 $j = 0$，$\mathrm{dp}[2] = 1$，$L[2] = 6$，$T[2] = 12$；压入时 $T[1] = 10 < 12$ 不弹出，表为 $\{0, 1, 2\}$（$T = 0, 10, 12$）。继续：

| $i$ | $\mathrm{pre}[i]$ | 命中 $j$ | $\mathrm{dp}[i]$ | $L[i]$ | $T[i]$ | 表（$T$ 序列） |
|-----|------|------|------|------|------|----------------|
| 3 | 7 | 0 | 1 | 7 | 14 | $0,10,12,14$ |
| 4 | 8 | 0 | 1 | 8 | 16 | $0,10,12,14,16$ |
| 5 | 9 | 0 | 1 | 9 | 18 | $0,10,12,14,16,18$ |
| 6 | 10 | 1（$T[1] = 10 \le 10$） | 2 | $10 - 5 = 5$ | 15 | 弹 18（$\ge 15$）→ $0,10,12,14,15$ |

$\mathrm{dp}[6] = 2$ ✓（切法 $[5] \mid [1,1,1,1,1]$，段和 $5, 5$）。此例同时演示了「低门槛老候选（$j=0$）长期服务」与「新候选以更低 $T$ 支配弹栈」两种行为，正是二分不动表的意义所在。

## 4. 算法细节

1. **`last[i]` 的最小化是转移正确性的一部分**：同样段数下末段和越小，$T[i]$ 越小，后继越容易接上。二分命中的 $j$ 是「门槛达标的最大下标」，由单调性 A 它给出最大 $\mathrm{dp}$；若同段数有多个 $j$，命中的 $j$（最大）同时使 $\mathrm{last}[i] = \mathrm{pre}[i] - \mathrm{pre}[j]$ **最小**（$j$ 越大 $\mathrm{pre}[j]$ 越大）——两个优化目标在最大 $j$ 处同时对齐，这是该算法最精妙的一点。
2. **$T[0] = 0$ 的哨兵作用**：空前缀 $\mathrm{dp}[0] = 0$、$\mathrm{last}[0] = 0$、$T[0] = 0$，任何 $\mathrm{pre}[i] \ge 1$ 都能命中它，保证二分不越界、$\mathrm{dp}[i] \ge 1$。
3. **弹栈条件用 $\ge$ 还是 $>$**：弹「$T \ge T[i]$」可以连同相等门槛的旧候选一起弹——相等时旧候选下标更小、段数不更大（单调性 A 取等或更小），被新候选支配（严格来说相等时两者转移能力相同，弹掉无害）；用 $>$ 也正确但表更长。本文用 $\ge$。
4. **为什么查询不能弹表**：插入使表的 $T$ 序保持**严格递增**，但表尾（新候选）的 $T$ 可能远小于表中部候选；若查询时从尾弹出「$T > \mathrm{pre}[i]$」者，会误删未来查询仍需的中部候选吗——不会误删「比 $\mathrm{pre}[i]$ 大」的（$\mathrm{pre}$ 单调递增，它们对后续也全部无效）……真正的问题在**等值与边界**：弹表操作把「结构性存储」当成了「临时缓存」，一旦某次查询弹掉了 $T$ 恰好等于某后续 $\mathrm{pre}[i']$ 的候选（二分用 `upper_bound` 时 $T[j] \le \mathrm{pre}$ 可取等），就永久丢失一个最优转移。反例：`[5,1,1,1,1,1]` 的查询期弹栈版会在 $i \le 5$ 时陆续弹光候选 $\{1,\dots\}$，最终 $\mathrm{dp}[6]$ 只能取 $j=0$，输出 1（正确值 2）。**结论：查询只二分，绝不弹。**
5. **溢出**：$\mathrm{pre}[n] \le 10^5 \times 10^5 = 10^{10}$，`int` 必爆，全程 `long long`。
6. **复杂度的两种实现**：二分版 $O(n \log n)$（本文）；另有 $O(n)$ 单调栈版——它在**插入**时就维护「窗口式」结构并用指针推进替代二分，正确性依赖更强的归纳（弹掉的候选永远不再最优），思路更陡。比赛实践：二分版 15 分钟写对，$O(n)$ 版 5 分钟写错，选前者。

## 5. 正确性证明

**引理 1（划分等价）**：任意操作序列的最终结果对应 `nums` 的一个划分（若干连续段，每段以段和呈现）；反之任何划分都可由操作实现。故「最长非递减数组长度」=「段和非递减的最大划分数」。

**证明**：每次操作把连续区间 $[l, r]$ 替换为其和。对操作总数归纳：最终数组中每个元素是原数组某连续段的和；且这些段两两不相交、并集为全集、按位置排序（操作保持相对顺序）。反之，对给定划分逐段执行一次操作即得（不同段的操作区间互不相交，顺序任意）。∎

**引理 2（$\mathrm{dp}$ 单调性）**：$\mathrm{dp}[i+1] \ge \mathrm{dp}[i]$。

**证明**：取 $[1, i]$ 的最优划分，把第 $i+1$ 个元素并入其最末段。新末段和变大，但其前一段未变、非递减关系仍成立（末段只会更不低于前段），故仍是合法划分，段数不变，即 $\mathrm{dp}[i+1] \ge \mathrm{dp}[i]$。∎

**引理 3（支配与候选表的充分性）**：若 $j_1 < j_2$ 且 $T[j_1] \ge T[j_2]$，则对一切 $i > j_2$，用 $j_2$ 转移不劣于用 $j_1$。

**证明**：$i$ 能用 $j_1$ 转移要求 $T[j_1] \le \mathrm{pre}[i]$，此时 $T[j_2] \le T[j_1] \le \mathrm{pre}[i]$，$j_2$ 也可用；且 $\mathrm{dp}[j_2] + 1 \ge \mathrm{dp}[j_1] + 1$（引理 2）。若两者段数相等，$\mathrm{last}$ 方面 $\mathrm{pre}[i] - \mathrm{pre}[j_2] \le \mathrm{pre}[i] - \mathrm{pre}[j_1]$（$j_2 > j_1$、前缀和递增），末段和更小，给后继留的门槛 $T[i] = \mathrm{pre}[i] + \mathrm{last}[i]$ 更低，后续转移能力只增不减。∎

**定理（算法正确）**：算法返回 $\mathrm{dp}[n]$ = 段和非递减的最大划分数；其中每个 $\mathrm{dp}[i]$ 由「候选表中最大的满足 $T[j] \le \mathrm{pre}[i]$ 的 $j$」最优转移得到。

**证明**：对 $i$ 归纳。**（表的表达力）** 归纳假设：至处理 $i$ 前，所有未被弹出的候选构成集合 $C$，使得对任何「可能成为最优前驱」的 $j$，$C$ 中存在 $j' \ge j$ 且 $T[j'] \le T[j]$（即 $j$ 被代表）。插入 $i$ 时弹出的是被 $i$ 支配的候选（引理 3，$i$ 的 $T$ 更小或相等且下标更大），不变量保持。**（转移最优）** 查询时，最优前驱 $j^*$（满足 $T[j^*] \le \mathrm{pre}[i]$ 且 $\mathrm{dp}[j^*] + 1$ 最大；若并列取 $\mathrm{pre}[j^*]$ 最大者以最小化 $\mathrm{last}$）必然可被表中某个 $j' \ge j^*$、$T[j'] \le T[j^*]$ 代表，而 $T[j'] \le \mathrm{pre}[i]$ 且 $\mathrm{dp}[j'] \ge \mathrm{dp}[j^*]$ 说明 $j'$ 至少与 $j^*$ 同优。又因表中 $T$ 严格递增，二分命中的最大可用人即该 $j'$（命中者下标最大、$\mathrm{dp}$ 不小于其它可用候选，且 $\mathrm{pre}[j']$ 最大使 $\mathrm{last}[i]$ 最小）。故 $\mathrm{dp}[i]$、$\mathrm{last}[i]$ 同时最优。归纳完成，$\mathrm{dp}[n]$ 为答案。∎

## 6. 复杂度分析

- **时间**：$O(n \log n)$。$n$ 次查询（二分 $O(\log n)$）+ $n$ 次插入（每候选至多弹出一次，均摊 $O(1)$）。实测 $n = 10^5$ C++ 3ms / Python 0.06s。
- **空间**：$O(n)$。前缀和、dp、last、T 与候选表各 $O(n)$。
- **对照**：$O(n^2)$ 朴素 DP 在 $n = 10^5$ 下约 $10^{10}$ 次操作，超时约 3 个数量级；$O(n)$ 单调栈变体可再省一个 $\log$，但实现与证明都更易错。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int findMaximumLength(vector<int>& nums) {
        int n = nums.size();
        vector<long long> pre(n + 1, 0);
        for (int i = 0; i < n; ++i) pre[i + 1] = pre[i] + nums[i];

        vector<int> dp(n + 1, 0);
        vector<long long> last(n + 1, 0), T(n + 1, 0);
        vector<int> cand = {0};          // 候选下标，对应 T 严格递增
        vector<long long> Ts = {0};      // 与 cand 同步的门槛 T
        for (int i = 1; i <= n; ++i) {
            // 二分找最大的 j: T[j] <= pre[i]（j=0 的 T=0 恒命中）
            int p = int(upper_bound(Ts.begin(), Ts.end(), pre[i]) - Ts.begin()) - 1;
            int j = cand[p];
            dp[i] = dp[j] + 1;
            last[i] = pre[i] - pre[j];
            T[i] = pre[i] + last[i];
            // i 入表：弹掉被支配候选（T 更大或相等的旧候选）
            while (!Ts.empty() && Ts.back() >= T[i]) {
                Ts.pop_back();
                cand.pop_back();
            }
            cand.push_back(i);
            Ts.push_back(T[i]);
        }
        return dp[n];
    }
};
```

### Python

```python
from bisect import bisect_right

class Solution:
    def findMaximumLength(self, nums: list[int]) -> int:
        n = len(nums)
        pre = [0] * (n + 1)
        for i, v in enumerate(nums):
            pre[i + 1] = pre[i] + v

        dp = [0] * (n + 1)
        last = [0] * (n + 1)
        T = [0] * (n + 1)
        cand = [0]                 # 候选下标，对应 T 严格递增
        Ts = [0]                   # 门槛序列
        for i in range(1, n + 1):
            p = bisect_right(Ts, pre[i]) - 1   # 最大的 j: T[j] <= pre[i]
            j = cand[p]
            dp[i] = dp[j] + 1
            last[i] = pre[i] - pre[j]
            T[i] = pre[i] + last[i]
            while Ts and Ts[-1] >= T[i]:       # 弹掉被支配候选
                Ts.pop()
                cand.pop()
            cand.append(i)
            Ts.append(T[i])
        return dp[n]
```

> 💡 两份代码均通过官方示例（`1`、`4`、`3`）、结构反例 `[5,1,1,1,1,1]`（`2`），与「$O(n^2)$ 双优化 DP」和「枚举 $2^{n-1}$ 种切法的指数暴力」**三方对拍** 5000 组随机数据（$n \le 12$，`mismatch = 0`），另对 $n \le 300$ 的 50 组大随机数据与 $O(n^2)$ 版对拍一致；$n = 10^5$ 满规模 C++ 3ms / Python 0.06s。

## 8. 边界情况与易错点

1. **`long long` 前缀和**：$\mathrm{pre}[n]$ 可达 $10^{10}$，`int` 直接溢出；`T[i] = pre[i] + last[i]` 更大（约 $2 \times 10^{10}$）。
2. **哨兵 $T[0] = 0$ 必须入表**：它保证任何 $\mathrm{pre}[i] \ge 1$ 的查询都命中（至少切成 1 段）。漏掉哨兵则首个查询二分可能返回 $-1$ 越界。
3. **二分用 `upper_bound` 再减 1**：条件是 $T[j] \le \mathrm{pre}[i]$（可取等），`lower_bound` 会漏掉相等候选（相等时 $T[j] = \mathrm{pre}[i]$ 是合法转移：末段和 $\mathrm{last}[j] = \mathrm{pre}[i] - \mathrm{pre}[j] \ge \mathrm{last}[j] \iff T[j] \le \mathrm{pre}[i]$，恰好取等合法）。
4. **查询期弹栈的经典错误**：见 §3.3 提示框与 §3.5 反例 `[5,1,1,1,1,1]`——查询只二分、绝不修改表。错误的弹栈版本在该例输出 1（正确 2）。
5. **弹栈用 $\ge$（而非 $>$）**：相等门槛的旧候选被新候选支配（下标更大、段数不减），弹掉无害且让表更短；若用 $>$，表会保留并列候选，二分仍正确但浪费。
6. **`last` 与 `dp` 必须成对维护**：只记 $\mathrm{dp}$ 不记 $\mathrm{last}$（末段和最小值）会让转移条件无从判断；反过来只贪心地「段和最小」而不锁定最大段数也会错——两者在「最大 $j$」处对齐（§4 第 1 条），缺一不可。
7. **正整数假设**：全正保证 $\mathrm{pre}$ 严格递增，这是单调性 A/B 的前提。若允许 $0$，$\mathrm{pre}$ 非严格递增，引理 3 的支配论证需改为非严格；若允许负数，整个单调结构崩塌，问题难度骤升（需树状数组套线段树等）。
8. **$n = 1$**：单元素自成一段，输出 1。算法中 $i = 1$ 命中哨兵 $j = 0$，$\mathrm{dp}[1] = 1$，正确。
