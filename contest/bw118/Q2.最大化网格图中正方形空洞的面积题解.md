# LeetCode 最大化网格图中正方形空洞的面积 题解

## 1. 题目概述

- **标题 / 题号**：最大化网格图中正方形空洞的面积（#2943，medium）
- **链接**：https://leetcode.cn/problems/maximize-area-of-square-hole-in-grid/
- **来源**：LeetCode 第 118 场双周赛 Q2
- **难度**：中等
- **标签**：数组、排序

**题意**：网格由 $n + 2$ 条水平线与 $m + 2$ 条竖直线构成，形成 $(n+1) \times (m+1)$ 个 $1 \times 1$ 单元格；线从 $1$ 开始编号（水平线 $1..n+2$，竖直线 $1..m+2$）。可从 `hBars`（水平线编号，值域 $[2, n+1]$）与 `vBars`（竖直线编号，值域 $[2, m+1]$）中**删除若干条**（可不删），其余线固定。删除后网格中出现空洞，求能得到的**最大正方形空洞面积**（边长为整数个单元格边长）。

**约束**：

- $1 \le n, m \le 10^9$（网格本身巨大，但可删的线极少）
- $1 \le \mathrm{hBars.length}, \mathrm{vBars.length} \le 100$
- `hBars` 值互不相同、`vBars` 值互不相同
- $2 \le \mathrm{hBars}[i] \le n+1$，$2 \le \mathrm{vBars}[i] \le m+1$

> 💡 破题关键：正方形空洞的边长由「水平方向最大空白高度」与「竖直方向最大空白宽度」的较小值决定，而两个方向**完全独立**——分别求最大空洞，再取小的一方平方。

## 2. 示例

**示例 1**

```text
输入：n = 2, m = 1, hBars = [2,3], vBars = [2]
输出：4
解释：删水平线 2 与竖直线 2，得到 2×2 的正方形空洞。
```

**示例 2**

```text
输入：n = 1, m = 1, hBars = [2], vBars = [2]
输出：4
解释：各删一条线即得 2×2 空洞（原有的 1×1 单元格向上/向右扩一格）。
```

**示例 3**

```text
输入：n = 2, m = 3, hBars = [2,3], vBars = [2,4]
输出：4
解释：删水平线 3 与竖直线 4：水平方向 2、3 连续可删但竖直方向只有 2 或 4 单独可删，
最大边长仍是 2。
```

**示例 4（边界补充）**

```text
输入：n = 3, m = 2, hBars = [4], vBars = [2,3]
输出：4
解释：水平线 4 单独删，竖直线 2、3 连续删，两方向边长分别为 2 与 3，
正方形边长取 min(2,3) = 2，面积 4。若误取 max 会得 9。
```

## 3. 解题思路

### 3.1 暴力思路

枚举 `hBars` 的全部子集（$2^{100}$ 种）与 `vBars` 的全部子集，逐一检查删除后是否形成正方形——显然爆炸。即便只枚举「连续段」也需先排序再扫一遍，其实已经接近正解。突破口在于发现**两个方向的独立性**与**「空洞边长 = 连续删除段长度 + 1」**这两个结构观察，暴力自然坍缩成排序扫描。

### 3.2 核心观察：独立方向 + 连续段 + 「段长 + 1」

![核心观察：连续删除段与边长的关系](images/bw118_q2_consecutive_bars.svg)

**观察一（独立性）**：正方形空洞由上下两条水平线、左右两条竖直线围成。水平方向能删哪些线只影响空洞的高度，竖直方向只影响宽度，二者没有任何耦合。故分别求「水平方向最大空洞高度 $H$」与「竖直方向最大空洞宽度 $W$」，答案为 $\min(H, W)^2$。

**观察二（空洞边长 = 连续可删段长 + 1）**：以水平方向为例。固定不可删的线（编号 $1$ 与 $n+2$，以及 `hBars` 之外的线——注意 `hBars` 值域是 $[2, n+1]$，边界线 $1$ 和 $n+2$ 永远固定）中，相邻两条固定线之间的区域若形成空洞，其高度等于两固定线的编号差。设我们在其中删掉了一段**连续编号**的 $k$ 条可删线，则这段区域上下界的编号差为 $k + 1$。反过来，任何空洞的边界必然是「一条固定线 + 一段连续删除的可删线 + 另一条固定线」，故最大空洞高度 $H = 1 + \max\{k\}$，其中 $k$ 是 `hBars` 排序后**最长连续（编号逐个 +1）段**的长度；一根线都不删时 $k = 0$，$H \ge 1$（原始单元格）。

> ⚠️ 注意 `hBars` 里可能有**不在任何连续段**的孤立值（如示例 3 的 `vBars = [2,4]`，2 与 4 不连续），它们单独成段（$k = 1$，贡献边长 2），不要因为「连不起来」就丢弃。

**观察三（为什么删非连续段无用）**：若删除的线编号不连续，中间留下的固定线会把空洞切成多个小空洞，每个小空洞边长不超过其所在连续子段的贡献——所以只需考察极大连续段。

### 3.3 算法流程

![算法流程：排序找最长连续段](images/bw118_q2_algorithm_flow.svg)

```text
1. 对 hBars、vBars 分别排序
2. 对每个数组求最长"编号连续递增 1"段的长度 k_h、k_v
3. H = k_h + 1, W = k_v + 1        # 段长 + 1 = 空洞边长
4. side = min(H, W)
5. 返回 side * side
```

### 3.4 示例演算

以示例 3（`n = 2, m = 3, hBars = [2,3], vBars = [2,4]`）演算：

| 方向 | 排序后 | 最长连续段 | 段长 $k$ | 空洞边长 $k+1$ |
|------|--------|-----------|----------|-----------------|
| 水平 | `[2,3]` | `[2,3]` | 2 | 3 |
| 竖直 | `[2,4]` | `[2]`（或 `[4]`） | 1 | 2 |

$\mathrm{side} = \min(3, 2) = 2$，面积 $4$ ✓。若两方向都取到连续段 `[2,3]`，边长可达 3，面积 9——这正是「单方向连续段长」与「正方形限制」的博弈点。

再验示例 2（各 1 条线）：两边 $k = 1$，边长均为 2，面积 $4$ ✓。

## 4. 算法细节

1. **排序去重**：题目保证互不相同，直接排序即可；若有重复（防御式编程），先 `unique` 再扫，重复值不影响连续段定义。
2. **连续段扫描**：`cur = a[i] == a[i-1] + 1 ? cur + 1 : 1`，一遍 $O(|A| \log |A|)$。别忘数组为空的情况——约束保证至少 1 个元素，但写通用逻辑时 `if (a.empty()) return 0` 更稳（此时边长至少 1，面积 1）。
3. **「段长 + 1」的由来再强调**：连续段 $[l, r]$（$r - l + 1 = k$）删除后，该区间上下（左右）相邻的**固定线**是 $l - 1$ 与 $r + 1$，编号差 $= (r + 1) - (l - 1) = k + 1$。而 `hBars` 值域 $[2, n+1]$ 保证 $l - 1 \ge 1$、$r + 1 \le n + 2$，即两侧固定线一定存在（正是边界线 $1$ 与 $n+2$ 兜底）。这就是「+1」不越界的结构性保证。
4. **$n, m \le 10^9$ 是烟雾弹**：网格规模巨大，但可删的线至多 100 条且全部落在 $[2, n+1]$，与 $n, m$ 的具体数值无关（只用于保证边界线存在）。答案上界 $(101)^2$ 量级，`int` 足够。
5. **min 而非 max**：正方形要求两方向相等，短板决定边长。常见失误是把两个方向的边长直接相乘（那是最大**矩形**面积）或取 max。
6. **面积 = 边长²**：最后记得平方，别返回边长。

## 5. 正确性证明

**引理 1（空洞边界结构）**：删除一组线后，任何极大空白矩形（空洞）的上边界、下边界（水平方向）分别是某两条**未删除**的水平线 $p < q$，且编号区间 $(p, q)$ 内的水平线全部被删除；其高度为 $q - p$。

**证明**：空白区域由未被删除的线围成。取其最上方的一条水平线 $p$ 与最下方的一条水平线 $q$（空白区域内不含任何未删水平线，否则该线把区域切开）。空白区域内的高度由线 $p$ 与线 $q$ 之间的距离决定，即 $q - p$（相邻编号线间距为 1 个单元格边长）。∎

**引理 2（连续段刻画）**：设 $S$ 为可删水平线集合，删除子集 $D \subseteq S$ 后水平方向的最大空洞高度为 $\max_{\text{极大连续段 } [l,r] \subseteq D} \big((r + 1) - (l - 1)\big)$，其中「连续」指 $l, l+1, \dots, r \in D$。特别地，最大高度 $= 1 + \max_D k(D)$，$k(D)$ 为 $D$ 中最长连续段长。

**证明**：由引理 1，空洞高度 $q - p$ 且 $(p, q)$ 内的线全删。$(p, q)$ 内的线要么属于 $S$（可删），要么不属于 $S$（固定、不可删）——后者必须被删，矛盾，故 $(p, q) \subseteq S$，即 $D \supseteq \{p+1, \dots, q-1\}$ 是一个连续段，高度 $q - p = |\{p+1,\dots,q-1\}| + 1 = k + 1$。反之，任取 $D$ 的连续段 $[l, r]$，删除后线 $l - 1$ 与 $r + 1$ 之间无任何水平线（$l-1, r+1$ 未删——若它们属于 $D$，段可延长，与极大性矛盾；若属于 $S \setminus D$，则保留），由 `hBars` 值域知 $l - 1 \ge 1$、$r + 1 \le n+2$ 均为存在的固定线，故得到高度 $(r+1)-(l-1) = k + 1$ 的空洞。两端合取最大值即得。∎

**定理**：最大正方形空洞面积为 $\big(\min(1 + k_h,\ 1 + k_v)\big)^2$，其中 $k_h$、$k_v$ 分别为 `hBars`、`vBars` 排序后最长连续段长度。

**证明**：高度与宽度独立（水平线删除不影响竖直线间距，反之亦然），故可行空洞恰是「水平高度 $h$ 的空白带」与「竖直宽度 $w$ 的空白带」的交集，其中 $h \le H_{\max}$、$w \le W_{\max}$。存在边长 $s$ 的正方形空洞 $\iff$ $s \le H_{\max}$ 且 $s \le W_{\max}$（把两个空白带交在边长 $\min(h, w)$ 的正方形上即可，且空白带位置可任意平移到公共区域）。由引理 2，$H_{\max} = 1 + k_h$、$W_{\max} = 1 + k_v$，故最大 $s = \min(1 + k_h,\ 1 + k_v)$，面积为 $s^2$。∎

## 6. 复杂度分析

- **时间**：$O(H \log H + V \log V)$，$H, V \le 100$，即排序主导的约 200 次比较；扫描为线性。
- **空间**：$O(1)$ 额外（若排序原地；Python `sorted` 需 $O(H + V)$）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int maximizeSquareHoleArea(int n, int m, vector<int>& hBars, vector<int>& vBars) {
        // 求排序后最长"编号连续递增 1"段的长度
        auto longestRun = [](vector<int>& a) -> int {
            if (a.empty()) return 0;
            sort(a.begin(), a.end());
            int best = 1, cur = 1;
            for (size_t i = 1; i < a.size(); ++i) {
                cur = (a[i] == a[i - 1] + 1) ? cur + 1 : 1;
                best = max(best, cur);
            }
            return best;
        };
        int side = min(1 + longestRun(hBars), 1 + longestRun(vBars));
        return side * side;
    }
};
```

### Python

```python
class Solution:
    def maximizeSquareHoleArea(self, n: int, m: int,
                               hBars: list[int], vBars: list[int]) -> int:
        def longest_run(a: list[int]) -> int:      # 最长连续段长度
            if not a:
                return 0
            a = sorted(a)
            best = cur = 1
            for i in range(1, len(a)):
                cur = cur + 1 if a[i] == a[i - 1] + 1 else 1
                best = max(best, cur)
            return best
        side = min(1 + longest_run(hBars), 1 + longest_run(vBars))
        return side * side
```

> 💡 两份代码均通过官方示例（`4`、`4`、`4`）与 2000 组随机数据（$n, m \le 5$，含空段、孤立值、全连续）和**子集枚举暴力**（枚举删除子集、逐线扫描最大空白）的对拍（`mismatch = 0`）。

## 8. 边界情况与易错点

1. **孤立可删线**：单条线也是长度 1 的段，贡献边长 2（把两个相邻单元格合成 $2 \times 2$ 空洞的一维），千万别丢。
2. **min 与 max / 相乘之辨**：正方形边长取两方向的**较小值**；直接相乘得到的是最大矩形面积（如示例 4 补充中 $2 \times 3 = 6 \ne 4$）。
3. **「段长 + 1」易写成「段长」**：连续段 $k$ 条线删除后边长是 $k + 1$，因为两端还有固定线各贡献一格。验证手段：单条线（$k=1$）删掉后空洞边长应为 2 而非 1（示例 2 即此情形）。
4. **$n, m$ 巨大但无用**：不要试图开 $(n+2) \times (m+2)$ 的网格数组（$10^9$ 直接爆内存）；`n, m` 只出现在「保证边界线存在」的语义里。
5. **未排序输入**：`hBars` / `vBars` 不保证有序，先排序再扫连续段；忘记排序会把交错序列误判为多个短段。
6. **两边都要至少 1**：一根线都不删时答案至少 $1$（$1 \times 1$ 单元格本身），公式 $\min(1 + k_h, 1 + k_v) \ge 1$ 天然成立。
7. **重复值**：题面保证无重复；若有，去重后再扫（重复值不延长连续段）。
