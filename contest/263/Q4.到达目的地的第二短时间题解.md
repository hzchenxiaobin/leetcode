# LeetCode 到达目的地的第二短时间 题解

## 1. 题目概述

- **标题 / 题号**：到达目的地的第二短时间（#2045，hard）
- **链接**：https://leetcode.cn/problems/second-minimum-time-to-reach-destination/
- **来源**：LeetCode 第 263 场周赛 Q4
- **难度**：困难
- **标签**：广度优先搜索、图、最短路径、次短路

**题意**：

城市是 $n$ 个节点（$1$ 到 $n$）的**双向连通**无向图，穿过任意一条边都恰好耗时 $\text{time}$ 分钟（**所有边等权**）。每个节点有交通信号灯，每 $\text{change}$ 分钟在绿 / 红之间切换一次，**所有灯同步**；启程时刻 $0$ 全部刚变绿。规则：

- 可以**任意次**经过任意节点（包括 $1$ 和 $n$）；
- 到达节点后**只能在绿灯时离开**：绿灯**必须立即走**（不许等），红灯**必须等到下一个绿灯**。

求从节点 $1$ 到节点 $n$ 的**第二短时间**——严格大于最短时间的所有可达时间中的最小值。

**约束**：

- $2 \le n \le 10^4$
- $n - 1 \le \text{edges.length} \le \min(2 \times 10^4, \ n(n-1)/2)$
- $1 \le \text{time}, \text{change} \le 10^3$
- 图连通，无重边，无自环

> 💡 **审题三钥匙**：① 所有边**等权** $\text{time}$；② 所有灯**同步**——灯色只取决于时刻，与在哪个节点无关；③ 「绿灯必须走、红灯必须等」——出发时刻**没有任何选择权**。三者合起来：**耗时被边数唯一决定**。本题的全部难度都藏在这个结构观察里，看穿之后代码只有 30 行；看不出来，就会陷入「带红绿灯的次短路」这团迷雾。

## 2. 示例

**示例 1**

```text
输入：n = 5, edges = [[1,2],[1,3],[1,4],[3,4],[4,5]], time = 3, change = 5
输出：13

最短：1→4→5（2 条边），全程绿灯，耗时 6 分钟
第二短：1→3→4→5（3 条边），到达节点 4 时 t=6 撞红灯，
        等到 t=10 才能出发，耗时 13 分钟
```

**示例 2**

```text
输入：n = 2, edges = [[1,2]], time = 3, change = 2
输出：11

最短：1→2（1 条边），耗时 3 分钟
第二短：1→2→1→2（3 条边）：0→3，红灯等 1 分钟（4 出发）→7，
        又红灯等 1 分钟（8 出发）→11
注意：图是树（二分图），不存在 2 条边的 1→2 walk——第二短必须走 3 条边
```

```text
输出：15

f(1) = 3（t=0 绿灯出发）
f(3)：0 →(绿，+3)→ 3 →(红，等到 6，+3)→ 9 →(红，等到 12，+3)→ 15
```

## 3. 解题思路

### 3.1 暴力思路

两条朴素路线，各有各的死法：

1. **枚举所有 $1 \to n$ 的路径，逐条模拟红绿灯**：简单路径的数量随图规模**指数爆炸**（$n = 10^4$ 的稠密图连存都存不下）；更致命的是，第二短时间对应的可能根本不是简单路径——示例 2 的最优第二短是 $1 \to 2 \to 1 \to 2$，**重访了起点**，只枚举简单路径会直接漏解。
2. **把红绿灯等待揉进边权，用 Dijkstra 变体直接求「次短时间」**：维护每个节点的 $\text{dist1} / \text{dist2}$ 两档**时间**，按到达时刻从小到大松弛（等待函数非减保证贪心正确）。可行，但要处理「弹出时是否已定型」等细节，且完全没吃到「等权 + 同步灯」的结构红利。

> ⚠️ 瓶颈不在算法框架，在于**没有把问题降维**。等权 + 同步灯意味着：耗时不依赖路径、只依赖边数——先证明这一点，问题就从「图上求次短**时间**」坍缩成「图上求次短**边数**」。

### 3.2 核心观察：同步灯 + 等权 → 耗时 $f(k)$ 只由边数决定

![核心概念：等权边 + 同步红绿灯，耗时只由边数决定](images/wc263_q4_traffic_light_concept.svg)

**观察一（灯色只看时刻）**：所有灯同步切换，时刻 $t$ 的灯色对所有节点一视同仁：

$$\text{灯色}(t) = \begin{cases} \text{绿} & \text{若 } \lfloor t / \text{change} \rfloor \bmod 2 = 0 \\ \text{红} & \text{若 } \lfloor t / \text{change} \rfloor \bmod 2 = 1 \end{cases}$$

**观察二（出发时刻没有选择权）**：规则把「到了怎么办」完全定死——绿灯立即走（出发 = 到达时刻 $t$），红灯等到下一个绿（出发 $= (\lfloor t / \text{change} \rfloor + 1) \times \text{change}$）。合写成出发函数 $g(t)$。**不存在「再等等看」的决策空间**。

**观察三（递推闭合，与节点无关）**：把「到达 → 判灯 → 可能等待 → 走一条边」看作一步。到达时刻 $t$ 经出发函数 $g$ 变成出发时刻，再加等权 $\text{time}$ 得下一步到达时刻：

$$f(0) = 0, \qquad f(k+1) = g(f(k)) + \text{time}$$

转移里**只有时刻、没有节点**。归纳可得：**任何 $k$ 条边的 walk，走完的时刻都恰为 $f(k)$**，与节点序列无关。

**观察四（$f$ 严格递增）**：$g(t) \ge t$ 且 $\text{time} \ge 1$，故 $f(k+1) \ge f(k) + \text{time} > f(k)$。于是**边数序 = 时间序**：不同边数必得不同耗时，且边数多的耗时严格大。

> 💡 **降维完成**：$1 \to n$ 的可达时间集合 $= \{ f(k) : k \in D(n) \}$（$D(n)$ 为可达边数集合）。$f$ 严格递增 ⇒ 最短时间 $= f(\min D(n))$，**第二短时间 $= f(D(n) \text{ 的次小元})$**。求时间 ⇄ 求边数，红绿灯被压缩进 $f$ 的递推里，图论部分只剩「无向等权图求次短边数」。

### 3.3 算法流程：两层 BFS 求边数 + 逐步模拟

![算法流程：两层 BFS 求最短 / 次短边数，再逐步模拟红绿灯](images/wc263_q4_two_tier_bfs_flow.svg)

三步走：

1. **两层 BFS**：对每个节点维护 $\text{dist1}[v]$（最短边数）与 $\text{dist2}[v]$（次短边数）。队列存 $(v, d)$，从 $(1, 0)$ 出发；对邻居 $v$ 以 $nd = d + 1$ 尝试转移——$\text{dist1}[v] = -1$ 则记最短并入队；否则若 $\text{dist1}[v] < nd$ 且 $\text{dist2}[v] = -1$ 则记次短并入队；再否则丢弃。每个节点**最多入队 2 次**，总代价 $O(n + m)$。
2. **取 $k = \text{dist2}[n]$**：第二短边数。它一定存在且 $\in \{L+1, L+2\}$（$L = \text{dist1}[n]$）：$L+2$ **必存在**——在最短路上任取一条边「跨过去再弹回来」即多 2 条边；$L+1$ 可能不存在——若图是二分图（如示例 2 的树），$1$ 到 $n$ 的 walk 边数奇偶被锁死。
3. **模拟 $f(k)$**：$t = 0$ 起循环 $k$ 次：红灯则 $t \leftarrow (\lfloor t/\text{change} \rfloor + 1) \times \text{change}$，再 $t \leftarrow t + \text{time}$。返回 $t$。

> ⚠️ **为什么两层 BFS 是对的？** 直觉：队列按边数非降处理，节点**首次**到达必是最短；节点遇到的**第一个「严格更大」的不同值**必是次短——之后的所有到达都不小于它，被 $\text{dist2}[v] \ne -1$ 挡在门外。严格证明见 §5 引理 4，那里把「可靠（记的都真实存在）」与「完备（前两档不漏）」分开论证。

### 3.4 示例演算

![示例演算：两层 BFS 边数表 + 逐步模拟](images/wc263_q4_walkthrough.svg)

以示例 1（$n=5$, $\text{time}=3$, $\text{change}=5$）为例。

**两层 BFS 求边数**：

| 节点 | dist1（最短） | dist2（次短） |
|------|--------------|--------------|
| 1    | 0            | 2            |
| 2    | 1            | 3            |
| 3    | 1            | 2            |
| 4    | 1            | 2            |
| 5    | 2            | 3            |

$L = \text{dist1}[5] = 2$，$k = \text{dist2}[5] = 3 = L + 1$——三角形 $1\text{-}3\text{-}4$ 提供奇环，奇偶解锁。

**模拟 $f(3)$**：

| 步   | 到达 $t$ | $\lfloor t/5 \rfloor$ | 灯 | 出发 | 走完 |
|------|---------|----------------------|----|------|------|
| 0→1  | 0       | 0                    | 绿 | 0    | 3    |
| 1→2  | 3       | 0                    | 绿 | 3    | 6    |
| 2→3  | 6       | 1                    | 红 | 10   | 13   |

> 💡 **关键一撞在第 3 步**：到达节点 4 时 $t = 6$ 落进红灯段 $[5, 10)$，必须等到 $10$ 才能出发。3 条边 $\times$ 3 分钟 $=$ 9，加等灯 4 分钟 $=$ **13**。而 2 条边的最短路 $f(2) = 6$ 全程绿灯——多走的那条边恰好把到达时刻推进了红灯区。

**对照示例 2**（$n=2$, $\text{time}=3$, $\text{change}=2$）：图是一条边（树 = 二分图），$1 \to 2$ 的 walk 边数只能为奇，$L = 1$，$k = 3 = L + 2$。$f(3) = 0 \to 3 \to (\text{红，等 } 1) \to 7 \to (\text{红，等 } 1) \to 11$，答案 $11$。若忽略奇偶性误取 $k = 2$，会算出 $f(2) = 7 \ne 11$——**二分图奇偶是本题埋的暗桩**。

## 4. 算法细节

1. **转移判定逐条解读**：`dist1[v] == -1` → 首次到达，记最短；`dist1[v] < nd && dist2[v] == -1` → 第二个「严格更大」的不同值，记次短；其余丢弃。**严格小于是精髓**：$nd = \text{dist1}[v]$ 是同层重复到达（换个前驱走到同一层），值相同不构成「第二小」；$\text{dist2}[v]$ 已设时来的更差值也不要。
2. **为什么赋值一次就够，不用像 DP 那样反复更新**：BFS 队列按边数非降处理（§5 引理 4 第 (1) 步），节点遇到的第一个「严格更大的不同值」就是它的次短——后续到达只会更大或相同，被条件自然挡掉。这与 Dijkstra 求次短路时 $\text{dist2}$ 可能被多次松弛不同：等权 BFS 的单调队列把「多次松弛」压缩成了「一次赋值」。
3. **$\text{dist2}[n]$ 永远不是 $-1$**：反弹构造（在最短路上跨一条边再弹回）对任何连通图都造出 $L + 2$ 条边的 walk，所以每个节点都有次短边数，**无需特判**。
4. **等待公式的整数实现**：`if ((t / change) % 2 == 1) t = (t / change + 1) * change;`——非负整数除法即 $\lfloor \cdot \rfloor$；红灯段 $[j \cdot \text{change}, (j+1) \cdot \text{change})$（$j$ 奇）的下一个绿灯起点是 $(j+1) \cdot \text{change}$。边界 $t$ 恰在 $j \cdot \text{change}$ 时属于第 $j$ 段，奇偶按 $j$ 判。
5. **队列的组织**：直接存 `(节点, 边数)` 二元组最省心；也可以按层双队列。注意初始 $(1, 0)$ 对应「走 0 条边、位于起点、时刻 0」，时刻 0 全绿，第一步必然立刻出发。
6. **值域与溢出**：$k \le L + 2 \le n + 1$（最短路是简单路径，$L \le n - 1$），每步等待严格小于 $\text{change}$，故答案 $< (n+1)(\text{time} + \text{change}) \le 10001 \times 2000 \approx 2 \times 10^7$——`int` 足够，全程无溢出考点。

## 5. 正确性证明

记 $D(v) = \{ k : \text{存在从 } 1 \text{ 到 } v 的恰 } k \text{ 条边的 walk} \}$，$d(v) = \min D(v)$，$s(v) = D(v)$ 的次小元。图连通且 $n \ge 2$，节点 $1$ 有邻居，任取一条边反弹得 $0, 2 \in D(1)$；对任意 $v$，沿最短路到 $v$ 再在首条边反弹得 $d(v), d(v) + 2 \in D(v)$。故 $d(v), s(v)$ 对所有节点均有定义。

**引理 1（耗时被边数唯一决定）**：任何 $k$ 条边的 walk 从时刻 0 出发，第 $k$ 步走完的到达时刻恒为 $f(k)$，与 walk 的节点序列无关，其中 $f(0) = 0$，$f(k+1) = g(f(k)) + \text{time}$。

**证明**：对 $k$ 归纳。$k = 0$：出发时（$t = 0$）所有灯刚变绿，必须立即出发，时刻为 $f(0) = 0$。归纳步：设第 $k$ 步到达时刻为 $f(k)$（与序列无关）。第 $k+1$ 步：灯色由 $\lfloor f(k) / \text{change} \rfloor$ 的奇偶决定（观察一，与节点无关）；规则强制出发时刻为 $g(f(k))$（观察二，绿即走、红必等，无第三种选择）；到达时刻 $= g(f(k)) + \text{time}$（等权）。该值只依赖 $f(k)$，与序列无关，且恰为 $f(k+1)$。∎

**引理 2（$f$ 严格递增）**：对一切 $k \ge 0$，$f(k+1) > f(k)$。

**证明**：$g(t) \ge t$（绿灯取 $t$，红灯取更大的下一绿灯起点），$\text{time} \ge 1$，故 $f(k+1) = g(f(k)) + \text{time} \ge f(k) + \text{time} > f(k)$。∎

**推论**：$1 \to n$ 的可达时间集合 $= \{ f(k) : k \in D(n) \}$（引理 1 的双向：任何行程是某长度的 walk 且耗时 $f(\cdot)$；任何 $k \in D(n)$ 的 walk 耗时 $f(k)$）。$f$ 严格递增 ⇒ 最短时间 $= f(d(n))$，第二短时间 $= f(s(n))$。

**引理 3（第二短边数 $\in \{L+1, L+2\}$ 且存在）**：设 $L = d(n)$，则 $s(n)$ 存在且 $L + 1 \le s(n) \le L + 2$。

**证明**：存在性：$n \ge 2$ 且图连通，故 $L \ge 1$，最短路上至少有一条边 $(u, w)$；沿最短路走到 $u$、跨到 $w$、弹回 $u$、继续走到 $n$，得 $L + 2$ 条边的 walk，故 $L + 2 \in D(n)$，$s(n) \le L + 2$。下界：任何 $k \in D(n)$ 有 $k \ge L$（否则与 $L$ 最小矛盾）；$s(n) > L$ 且为整数，故 $s(n) \ge L + 1$。∎

**引理 4（两层 BFS 正确）**：算法终止时对每个节点 $v$：$\text{dist1}[v] = d(v)$，$\text{dist2}[v] = s(v)$。

**证明**：分三步。

**(1) 队列单调**：任何时刻，队列中状态的边数从队首到队尾非降，且最大最小至多相差 1。归纳：初始队列 $\{(1,0)\}$ 满足；弹出队首 $(u, d)$ 后压入的均为 $(v, d+1)$，新队首为 $d$ 或 $d+1$，压入的 $d + 1$ 与队中现存值（$\subseteq \{d, d+1\}$）仍满足非降且跨度 $\le 1$。因此**状态按边数非降的顺序被处理**，且对节点 $v$ 的每次压入都发生在「处理中的层级 $\le $ 本次尝试层级」的时刻——具体地，尝试压入 $(v, k)$ 时，此前对 $v$ 的所有压入层级都 $\le k$。

**(2) 可靠性（记下的都真实存在）**：对压入顺序归纳：初始 $(1, 0)$ 对应长度 0 的平凡 walk；从 $(u, k-1)$ 压入 $(v, k)$ 时，由归纳假设存在 $k-1$ 条边到 $u$ 的 walk，拼接边 $(u, v)$ 得 $k$ 条边到 $v$ 的 walk。故凡被压入的 $(v, k)$ 皆 $k \in D(v)$，特别地 $\text{dist1}[v], \text{dist2}[v] \in D(v)$（若被设置）。

**(3) 完备性（前两档不漏）**：断言：凡满足 $k \le s(v)$ 的可达状态 $(v, k)$ 必被压入。反设有反例，取 $k$ 最小者 $(v, k)$：

- $k = 0$：可达的 0 层状态只有 $(1, 0)$，初始已压入，矛盾。
- $k \ge 1$：$(v, k)$ 可达，故存在边 $(u, v)$ 使 $(u, k-1)$ 可达；由 $k$ 的最小性，$(u, k-1)$ 已被压入，其被弹出时尝试压入 $(v, k)$ 但未遂。未遂意味着 $\text{dist1}[v] \ne -1$ 且（$\text{dist1}[v] \ge k$ 或 $\text{dist2}[v] \ne -1$）。由 (1)，此前对 $v$ 的压入层级均 $\le k$，故 $\text{dist1}[v] \le k$、$\text{dist2}[v] \le k$（若已设置）。
  - 若 $\text{dist1}[v] \ge k$：结合 $\text{dist1}[v] \le k$ 得 $\text{dist1}[v] = k$，而设置 $\text{dist1}[v] = k$ 的那次压入就是 $(v, k)$，与未压入矛盾。
  - 故必是 $\text{dist2}[v] \ne -1$。若 $\text{dist2}[v] = k$，同理矛盾；故 $\text{dist1}[v] < \text{dist2}[v] < k$。由 (2)，$\text{dist1}[v], \text{dist2}[v] \in D(v)$，又 $(v, k)$ 可达给出 $k \in D(v)$，三者两两不同，故 $s(v) \le \text{dist2}[v] < k$，与反例前提 $k \le s(v)$ 矛盾。

  断言得证。于是 $(v, d(v))$ 与 $(v, s(v))$（均满足 $k \le s(v)$）都被压入。由 (2) 与压入规则，$v$ 至多被压入两次（$\text{dist1}$ 一次、$\text{dist2}$ 一次，之后永远被拒）。压入 $(v, k)$ 只发生在处理层级 $k$ 时（弹出 $(u, k-1)$ 触发），而层级按非降顺序处理，$d(v) < s(v)$，故 $(v, d(v))$ 的压入先于 $(v, s(v))$：第一次压入设置 $\text{dist1}[v] = d(v)$（结合 (2)，首次压入层级 $\in D(v)$ 且 $\le d(v)$，只能是 $d(v)$）；$(v, s(v))$ 是后续压入，此刻 $\text{dist1}[v] = d(v) < s(v)$ 且 $\text{dist2}[v] = -1$，压入规则设置 $\text{dist2}[v] = s(v)$。∎

**定理**：算法返回从 $1$ 到 $n$ 的第二短时间。

**证明**：由引理 4，$\text{dist2}[n] = s(n)$；由引理 3，$s(n) \le L + 2 \le n + 1$，模拟循环有限。可达时间集合 $= \{ f(k) : k \in D(n) \}$，$f$ 在其上严格递增（引理 1、引理 2），故第二短时间 $= f(s(n)) = f(\text{dist2}[n])$；模拟的每步「判灯 → 等待 → 加 $\text{time}$」逐位重现递推 $f$，返回值即 $f(\text{dist2}[n])$。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n + m)$。两层 BFS 中每个节点最多被压入 2 次（$\text{dist1}$ 一次、$\text{dist2}$ 一次），也就最多被弹出 2 次，每次弹出扫描其邻接表——每条边最多被两端、各两个状态扫描，共 $\le 4m$ 次。模拟阶段 $O(k)$，$k = \text{dist2}[n] \le L + 2 \le n + 1$，被 BFS 的线性界吸收。
- **空间复杂度**：$O(n + m)$。邻接表 $O(n + m)$；$\text{dist1}, \text{dist2}$ 与队列 $O(n)$（队列同时最多存 $O(n)$ 个二元组）。

> 💡 对比「直接追踪时间的 Dijkstra 式次短路」：等权时同为 $O(n + m)$，但若边权不等则退化为 $O(m \log n)$——本题的降维是等权 + 同步灯**赠予**的，白拿不要浪费。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int secondMinimum(int n, vector<vector<int>>& edges, int time, int change) {
        vector<vector<int>> adj(n + 1);
        for (auto& e : edges) {
            adj[e[0]].push_back(e[1]);
            adj[e[1]].push_back(e[0]);
        }

        // 两层 BFS：dist1[v] / dist2[v] = 1 到 v 的最短 / 次短「边数」
        vector<int> dist1(n + 1, -1), dist2(n + 1, -1);
        dist1[1] = 0;
        queue<pair<int, int>> q;
        q.push({1, 0});

        while (!q.empty()) {
            auto [u, d] = q.front(); q.pop();
            for (int v : adj[u]) {
                int nd = d + 1;
                if (dist1[v] == -1) {                  // 首次到达 → 最短边数
                    dist1[v] = nd;
                    q.push({v, nd});
                } else if (dist1[v] < nd && dist2[v] == -1) {
                    dist2[v] = nd;                     // 第二个「严格更大」的不同值 → 次短
                    q.push({v, nd});
                }
            }
        }

        // 耗时只由边数决定：逐步模拟 k = dist2[n] 条边的红绿灯递推
        int t = 0;
        for (int i = 0; i < dist2[n]; i++) {
            if ((t / change) % 2 == 1)                 // 红灯：必须等到下一个绿灯
                t = (t / change + 1) * change;
            t += time;                                 // 绿灯出发，走一条边
        }
        return t;
    }
};
```

### Python

```python
class Solution:
    def secondMinimum(self, n: int, edges: List[List[int]], time: int, change: int) -> int:
        adj = [[] for _ in range(n + 1)]
        for u, v in edges:
            adj[u].append(v)
            adj[v].append(u)

        # 两层 BFS：dist1[v] / dist2[v] = 1 到 v 的最短 / 次短「边数」
        dist1 = [-1] * (n + 1)
        dist2 = [-1] * (n + 1)
        dist1[1] = 0
        q = deque([(1, 0)])

        while q:
            u, d = q.popleft()
            for v in adj[u]:
                nd = d + 1
                if dist1[v] == -1:                     # 首次到达 → 最短边数
                    dist1[v] = nd
                    q.append((v, nd))
                elif dist1[v] < nd and dist2[v] == -1: # 第二个「严格更大」的不同值 → 次短
                    dist2[v] = nd
                    q.append((v, nd))

        # 耗时只由边数决定：逐步模拟 k = dist2[n] 条边的红绿灯递推
        t = 0
        for _ in range(dist2[n]):
            if (t // change) % 2:                      # 红灯：必须等到下一个绿灯
                t = (t // change + 1) * change
            t += time                                  # 绿灯出发，走一条边
        return t
```

## 8. 边界情况与易错点

1. **把「第二短时间」当成「第二条路径的时间」**：第二短可能对应**非简单 walk**（示例 2 的 $1 \to 2 \to 1 \to 2$ 重访起点），只枚举简单路径必漏；反过来，路径不同但耗时相同（边数相同）只算**一个**值——「第二短」定义在时间值上，不在路径上。
2. **漏算红灯等待**：示例 1 会被错算成 $3 \times 3 = 9$（正确为 13）。反之漏掉「绿灯必须立即走」也不行——若允许自愿等待，出发时刻就有选择权，递推 $f$ 不再封闭，降维论证整体崩塌（规则禁止，恰是本题的仁慈）。
3. **`dist1[v] < nd` 写成 `<=`**：$nd = \text{dist1}[v]$ 是同层重复到达，记入会把「与最短相同的值」误当次短，违反「严格大于」的定义。必须**严格大于**才是「第二个不同的值」。
4. **以为 $k = L + 2$ 恒成立**：二分图（树）里 $L + 1$ 不存在，示例 2 是暗桩；也不能只取 $L + 1$。两层 BFS 的 $\text{dist2}$ 自动二选一，这是它比「手推 $L+1$ 还是 $L+2$」可靠的原因。
5. **担心 $\text{dist2}[n] = -1$**：不会——反弹构造保证任何连通图的每个节点都有次短边数，无需特判（这依赖「可以任意次经过任意节点」的题设）。
6. **溢出**：$k \le n + 1$，答案 $< (n+1)(\text{time} + \text{change}) \le 2 \times 10^7$，`int` 安全；若迁移到更大 $n$ 的场景再换 `long long`。
7. **$n = 2$ 的极小图**：第二短必走 $1 \to 2 \to 1 \to 2$（$k = 3$），是检验「反弹 + 奇偶」的最小用例。
8. **时刻 0 是绿灯**：出发无需等待，`t = 0` 直接进循环；同时注意 $t$ 恰落在 $j \cdot \text{change}$ 时属于第 $j$ 段（半开区间 $[j \cdot \text{change}, (j+1) \cdot \text{change})$），奇偶按 $j$ 判。
9. **混淆「两层 BFS」与「跑两遍 BFS」**：一遍 BFS 跑两次求不出次短（第二遍仍得最短）；次短要求每个节点携带**两档**距离状态，这是一遍遍历内完成的。

**延伸思考**：

1. **边权不等（每条边 $\text{time}_i$ 不同）怎么办**：$f(k)$ 与路径无关性立即失效——同边数不同路耗时可能不同。退化为 Dijkstra 式次短路：$\text{dist1} / \text{dist2}$ 改存**时间**，按到达时刻从小到大松弛，复杂度 $O(m \log n)$。本文的两层 BFS 是等权特例的降维打击。
2. **灯不同步（每节点独立周期）怎么办**：灯色依赖 $(节点, 时刻)$ 二元组，但各节点的等待函数 $g_v(t)$ 仍非减，FIFO 性质保持，最短 / 次短路仍可按时间序 label-setting 求出——只是 $g$ 从全局常数变成节点函数。
3. **推广到第 $k$ 短**：状态扩展为 $(v, i)$（$i$ 表示第 $i$ 短），每节点维护 $k$ 档距离，$k \ll n$ 时仍是线性遍历的常数倍；任意 $k$ 则进入 Eppstein 算法的领地。两层 BFS 是 $k = 2$ 的甜区特例。
4. **要输出第二短路径本身**：BFS 时为两档状态各记一个前驱，从 $(n, \text{次短档})$ 回溯即得——注意次短 walk 含「反弹边」，回溯序列会出现 $u \to w \to u$ 的往返，属正常现象而非 bug。
