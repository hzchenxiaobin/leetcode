# LeetCode 打折购买糖果的最小开销 题解

## 1. 题目概述

- **标题 / 题号**：打折购买糖果的最小开销（#2144，easy）
- **链接**：https://leetcode.cn/problems/minimum-cost-of-buying-candies-with-discount/
- **来源**：LeetCode 第 70 场双周赛 Q1
- **难度**：简单
- **标签**：贪心、数组、排序

**题意**：商店打折：每购买**两个**糖果，商店**免费送**一个糖果。免费糖果的唯一限制：其价格 $\le$ 所购两个糖果价格的**较小值**。给数组 `cost`（`cost[i]` 为第 $i$ 个糖果价格），要获得**所有**糖果，返回最小总开销。

**约束**：

- $1 \le \text{cost.length} \le 100$；
- $1 \le \text{cost[i}] \le 100$。

## 2. 示例

**示例 1**

```text
输入：cost = [1,2,3]
输出：5
解释：购买价格 2 和 3 的糖果，免费获得价格 1 的糖果，总开销 5。
注意不能买 1 和 3 再免费拿 2 —— 免费糖果价格不能超过所购两件的较低价。
```

**示例 2**

```text
输入：cost = [6,5,7,9,2,2]
输出：23
解释：买 9、7 免费拿 6；买 5、2 免费拿 2。总开销 9 + 7 + 5 + 2 = 23。
```

**示例 3**

```text
输入：cost = [5,5]
输出：10
解释：只有两个糖果，都得买，没有免费名额。总开销 10。
```

## 3. 解题思路

### 3.1 暴力思路

$n \le 100$，可以枚举"哪些糖果免费"的所有子集，对每个子集验证能否为每个免费糖果找到两个**价格都不低于它**的已购糖果配对（二分图匹配式的检查），取已购糖果总价最小者——$O(2^n)$ 或带剪枝的指数级，$n = 100$ 不可行，$n \le 7$ 可作对拍基准。这种写法暴露了问题结构：**免费的糖果必须"便宜到能被另外两件罩住"**。要获得所有糖果，免费的总额要尽量大，且免费资格受"两件更贵的已购糖果"约束——这自然引出排序。

### 3.2 核心观察：降序排序后每 3 件一组，组内最便宜者免费

![买二送一：降序排列后每 3 件一组，组内最便宜免费](images/bw70_q1_grouping_model.svg)

两步论证：

1. **免费名额数量固定**：设免费糖果 $f$ 个，则需购买 $n - f$ 个，且每个免费糖果消耗所购糖果中的 2 个"配额"。同一颗已购糖果能否同时给两个免费糖果当"搭档"？题意是"每购买两个糖果，免费送一个"，即**一次优惠由恰好两颗已购糖果触发，且触发关系互不重叠**（一颗糖果不能同时算进两次"买二"）。于是 $2f \le n - f$，即 $f \le \lfloor n/3 \rfloor$，免费名额至多 $\lfloor n/3 \rfloor$ 个。
2. **最贵的 $\lfloor n/3 \rfloor$ 个免费名额给谁**：把糖果降序排成 $c_0 \ge c_1 \ge \cdots \ge c_{n-1}$。取前 3 件一组：买 $c_0, c_1$，免费 $c_2$——免费资格满足（$c_2 \le \min(c_0, c_1)$）；再取接下来的 3 件同理。这样**免费的总价恰为降序序列中下标 $\equiv 2 \pmod 3$ 的那些项**，即每三件中最便宜的一件。直觉：让贵的糖果占用"必须购买"的名额、让相对便宜（但仍尽量贵）的糖果吃掉免费名额，总开销最小。

于是答案 $= \sum_{i \bmod 3 \ne 2} c_i$（降序排列后）。

### 3.3 算法流程

```text
1. 将 cost 降序排序
2. ans = Σ cost[i]，其中 i mod 3 != 2
3. 返回 ans
```

一行循环即可。等价写法：升序排序后跳过 $i \bmod 3 = n \bmod 3$ 相关位置（不推荐，容易绕晕），或每 3 个一组累加前两个。降序 + `i % 3 != 2` 的写法与"买二送一"语义直接对应，最不易错。

### 3.4 示例演算

![演算：cost 为 6,5,7,9,2,2 的降序分组求和](images/bw70_q1_example_walkthrough.svg)

示例 2：降序得 $[9, 7, 6, 5, 2, 2]$。分组：$(9, 7, 6)$ 买 9、7 送 6；$(5, 2, 2)$ 买 5、2 送 2。开销 $9 + 7 + 5 + 2 = 23$，与官方解释一致。示例 3：$n = 2 < 3$，$\lfloor 2/3 \rfloor = 0$ 个免费名额，全部原价购买 $10$。注意 $n \bmod 3$ 余 1 或 2 时，剩下的 1–2 件**凑不出**免费资格（没有足够的已购糖果触发优惠），只能原价买。

## 4. 算法细节

1. **免费名额上限**：$\lfloor n / 3 \rfloor$。证明要点见 §5 引理 1；关键是"每颗已购糖果至多参与一次买二送一"，否则一颗糖重复计数会高估免费名额。
2. **排序方向与取整**：降序后免费位恰为下标 $2, 5, 8, \ldots$；代码里 `i % 3 == 2` 判免费。若升序排序，免费位变成 $n-1-2, n-1-5, \ldots$，下标换算易错，不推荐。
3. **贪心的两组对照**：直觉上"免费的总价最大"与"已购的总价最小"是同一件事（总和固定），但贪心正确性依赖"每个免费名额都由组内两件更贵的糖果触发"这一可行性，见 §5 定理的交换论证。
4. **数值范围**：$n \le 100$、$c_i \le 100$，总和 $\le 10^4$，`int` 无压力。
5. **语言实现**：C++ `sort` + `greater<int>()`；Python `sort(reverse=True)` 后生成器求和，或 `sum(c for i, c in enumerate(cost) if i % 3 != 2)`。

## 5. 正确性证明

**引理 1（免费名额上界）**：任何合法购买方案中，免费糖果数 $f \le \lfloor n / 3 \rfloor$。

**证明**：设已购集合 $B$（$|B| = n - f$），免费集合 $F$（$|F| = f$）。每次"买二送一"由两颗**不同**的已购糖果触发，且按题意一次优惠对应两颗糖（每购买两个送一个），同一颗已购糖果至多属于一次触发对（否则同一笔购买被重复用作两次优惠的依据，超出"每购买两个送一个"的字面与语义）。$f$ 次优惠需要 $2f$ 颗互不重叠的已购糖果，故 $2f \le |B| = n - f$，得 $3f \le n$，即 $f \le \lfloor n/3 \rfloor$。∎

**引理 2（组内免费的可行性）**：降序序列按 3 件一组，每组（$c_{3t} \ge c_{3t+1} \ge c_{3t+2}$）取前两件购买、第三件免费，满足优惠限制。

**证明**：免费件 $c_{3t+2} \le c_{3t+1} = \min(c_{3t}, c_{3t+1})$，价格不超过所购两件的较小值，合法。每组触发的两颗已购糖果互不重叠（组间不相交），满足引理 1 的不重叠要求。∎

**定理（贪心最优）**：降序排序后 $\text{ans} = \sum_{i \bmod 3 \ne 2} c_i$ 为最小总开销。

**证明**：总开销 $= \sum_{i=0}^{n-1} c_i - \sum_{\text{免费}} c_i$（总和固定），故最小化开销等价于**最大化免费糖果的总价**。

先证上界。设任一合法方案的免费集合为 $F$，$|F| = f \le \lfloor n/3 \rfloor$（引理 1）。把每个免费糖果与其触发的两颗已购糖果组成三元组（组间糖互不重叠，共 $f$ 组），组内免费价 $\le$ 两购价，即**免费者是组内最便宜**。将 $F$ 的元素按价降序排为 $x_1 \ge x_2 \ge \cdots \ge x_f$，把包含 $x_1, \ldots, x_t$ 的前 $t$ 个三元组合并观察：组内每颗糖的价格都 $\ge$ 本组免费价 $\ge x_t$（两颗已购 $\ge$ 本组免费价 $x_j \ge x_t$），故共有 $3t$ 颗互不相同的糖果价格 $\ge x_t$。降序序列中至少 $3t$ 项 $\ge x_t$ 意味着第 $3t$ 大的 $c_{3t-1} \ge x_t$（下标从 0 计）。注意 $3t - 1 = 3(t-1) + 2$ 恰是算法第 $t$ 个免费位的下标，于是逐项压制：$x_t \le c_{3t-1}$ 对 $t = 1, \ldots, f$ 成立，求和得

$$\sum_{x \in F} x \;=\; \sum_{t=1}^{f} x_t \;\le\; \sum_{t=1}^{f} c_{3t-1} \;\le\; \sum_{t=1}^{\lfloor n/3 \rfloor} c_{3t-1},$$

末步只是补上非负项。右端正是算法的免费总价（降序下标 $\equiv 2 \pmod 3$ 的全部项）。

再证可达。由引理 2，算法的分组恰好合法，其免费总价等于上述上界。故上界即最大值，对应的开销 $\sum_{i \bmod 3 \ne 2} c_i$ 为最小。∎

**推论**：算法返回值即最小开销。∎

## 6. 复杂度分析

- **时间**：$O(n \log n)$，排序主导；随后一次线性扫描求和 $O(n)$。$n \le 100$ 下可忽略不计。
- **空间**：$O(1)$ 额外空间（原地排序；Python `sort` 原地、生成器求和不建中间列表）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minimumCost(vector<int>& cost) {
        sort(cost.begin(), cost.end(), greater<int>());   // 从贵到便宜排
        int ans = 0;
        for (int i = 0; i < (int)cost.size(); ++i)
            if (i % 3 != 2) ans += cost[i];               // 每 3 件一组，第 3 件免费
        return ans;
    }
};
```

### Python

```python
class Solution:
    def minimumCost(self, cost: List[int]) -> int:
        cost.sort(reverse=True)              # 从贵到便宜排
        return sum(c for i, c in enumerate(cost) if i % 3 != 2)   # 每 3 件一组，第 3 件免费
```

> 💡 两份代码均通过官方示例（`5`、`23`、`10`）以及 1500 组随机输入（$n \le 7$，价格 $\le 10$）与"枚举免费子集 + 二分图式配对验证"暴力的对拍，`mismatch = 0`。

## 8. 边界情况与易错点

1. **$n < 3$**：$\lfloor n/3 \rfloor = 0$，没有免费名额，全部原价。$n = 1$ 时买那一颗；$n = 2$ 时两颗都买（示例 3）。`i % 3 != 2` 的写法自动涵盖，无需特判。
2. **"免费糖果价格 $\le$ 两购较小值"的方向**：是免费的最便宜，不是最贵。若理解反了（免费拿最贵的），会写出升序取 $i\%3==2$ 的错误代码。
3. **免费名额不能共享已购糖果**：一颗已购糖果不能同时给两个免费糖果当"配对"。若允许共享，名额上界会变成 $\lfloor (n-1)/2 \rfloor$，贪心分组也不同——本题按不重叠理解（与官方示例 2 一致：6 个糖果 2 个免费，$2 \times 2 = 4 \le 4$ 恰好用尽）。
4. **排序稳定性无关紧要**：等价糖果互换不影响总和。
5. **别漏买**：题目要求获得**所有**糖果，不存在"放弃购买某些糖果"的选项；最小化的是开销而非数量。
6. **等价格合法**：免费糖果价格可以**等于**两购的较小值（"$\le$"），示例 2 中免费 2 与所购 2 同价合法。
