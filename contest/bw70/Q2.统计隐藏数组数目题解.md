# LeetCode 统计隐藏数组数目 题解

## 1. 题目概述

- **标题 / 题号**：统计隐藏数组数目（#2145，medium）
- **链接**：https://leetcode.cn/problems/count-the-hidden-sequences/
- **来源**：LeetCode 第 70 场双周赛 Q2
- **难度**：中等
- **标签**：数组、前缀和

**题意**：给长度为 $n$ 的整数数组 `differences` 与整数 `lower`、`upper`。隐藏数组 `hidden` 长度为 $n+1$，满足 $\text{hidden}[i+1] - \text{hidden}[i] = \text{differences}[i]$，且所有元素都在闭区间 $[\text{lower}, \text{upper}]$ 内。返回满足条件的隐藏数组**数目**。

**约束**：

- $1 \le n \le 10^5$；
- $-10^5 \le \text{differences}[i] \le 10^5$；
- $-10^5 \le \text{lower} \le \text{upper} \le 10^5$。

## 2. 示例

**示例 1**

```text
输入：differences = [1,-3,4], lower = 1, upper = 6
输出：2
解释：符合要求的隐藏数组有 [3,4,1,5] 与 [4,5,2,6]。
```

**示例 2**

```text
输入：differences = [3,-4,5,1,-2], lower = -4, upper = 5
输出：4
解释：四个隐藏数组分别为 [-3,0,-4,1,2,0]、[-2,1,-3,2,3,1]、[-1,2,-2,3,4,2]、[0,3,-1,4,5,3]。
```

**示例 3**

```text
输入：differences = [4,-7,2], lower = 3, upper = 6
输出：0
解释：不存在满足条件的隐藏数组。
```

## 3. 解题思路

### 3.1 暴力思路

枚举 $\text{hidden}[0] = x$ 的所有可能取值（$x \in [\text{lower}, \text{upper}]$，至多 $2\times10^5 + 1$ 个），对每个 $x$ 依差分递推出整个数组并逐项检查是否越界——单次 $O(n)$，总计 $O(n \cdot (\text{upper} - \text{lower} + 1))$，最坏 $2\times10^{10}$，超时。但暴力揭示了关键结构：**一旦 $x$ 定了，整条数组就定了**（$ \text{hidden}[i] = x + S_i$，$S_i$ 为差分前缀和）；且平移 $x$ 只是让整条折线上下平移。于是问题从"逐个数组验证"坍缩为"数有多少个平移量合法"。

### 3.2 核心观察：定差折线的整体平移 + 极差不变

![关键观察：整条隐藏数组 = 定差折线整体上下平移](images/bw70_q2_prefix_range_model.svg)

设 $S_0 = 0$，$S_i = \sum_{t=0}^{i-1}\text{differences}[t]$（$i \ge 1$）。则 $\text{hidden}[i] = x + S_i$，其中 $x = \text{hidden}[0]$。约束"所有元素都在 $[\text{lower}, \text{upper}]$"等价于：

$$\forall i:\ \text{lower} \le x + S_i \le \text{upper} \iff \text{lower} - S_i \le x \le \text{upper} - S_i$$

对全部 $i$ 取交，令 $S_{\min} = \min_i S_i$、$S_{\max} = \max_i S_i$，得：

$$x \in [\text{lower} - S_{\min},\ \text{upper} - S_{\max}]$$

合法 $x$ 的个数 $= (\text{upper} - S_{\max}) - (\text{lower} - S_{\min}) + 1 = (\text{upper} - \text{lower} + 1) - (S_{\max} - S_{\min})$。注意 $S_{\max} - S_{\min}$ 正是**前缀和序列的极差**——它与 $x$ 无关（平移不变量），只需一遍扫描维护。若上式为负，说明折线的"振幅"比窗口还宽，任何平移都放不下，返回 0。

### 3.3 算法流程

![一遍扫描：维护前缀和的极小 / 极大](images/bw70_q2_algorithm_flow.svg)

```text
1. cur = 0, mn = 0, mx = 0        # S0 = 0 也在极值候选中
2. 对每个 d in differences：
       cur += d
       mn = min(mn, cur), mx = max(mx, cur)
3. ans = (upper − lower + 1) − (mx − mn)
4. 返回 max(ans, 0)
```

**初值必须含 $S_0 = 0$**：`hidden[0] = x` 本身也要落在窗口内，对应约束 $\text{lower} \le x \le \text{upper}$，在公式里由 $S_{\min} \le 0 \le S_{\max}$ 的候选贡献（初值 0 参与极值）保证。漏掉初值会漏掉对首元素的约束。

### 3.4 示例演算

![示例 2 / 3 的前缀和走查表](images/bw70_q2_example_walkthrough.svg)

**示例 1**：前缀和 $0 \to 1 \to -2 \to 2$，$mn = -2$、$mx = 2$、极差 $4$；窗口宽 $6 - 1 + 1 = 6$；答案 $6 - 4 = 2$。对应 $x \in [1 - (-2), 6 - 2] = [3, 4]$，即 $[3,4,1,5]$ 与 $[4,5,2,6]$。

**示例 3**：前缀和 $0 \to 4 \to -3 \to -1$，极差 $4 - (-3) = 7 >$ 窗口宽 $6 - 3 + 1 = 4$，$4 - 7 = -3 < 0$，返回 0——差分里那个 $-7$ 把折线砸得太深，窗口接不住。

## 4. 算法细节

1. **前缀和初值参与极值**：`mn = mx = cur = 0` 起步，循环内先累加再更新极值。若初始化为 `mn = +inf` 忘记纳入 $S_0$，首元素约束丢失，会多算（例如 `differences = [0]`、`[lower, upper] = [1, 1]` 应得 1：唯一数组 $[x, x]$，$x$ 只能是 1）。
2. **公式取负截断**：$ans = \text{upper} - \text{lower} + 1 - (mx - mn)$ 可能是负数（极差超过窗口宽），必须 `max(ans, 0)` 或条件判断，不能直接返回负值。
3. **数据类型**：$S_i$ 的绝对值上界为 $n \times 10^5 = 10^{10}$，超过 32 位 `int`；C++ 必须用 `long long` 累加。窗口宽 $(\text{upper} - \text{lower} + 1) \le 2\times10^5 + 1$ 在 `int` 内，但与极差做减法时统一用 `long long` 最稳。Python 无此虑。
4. **一遍扫描足够**：不需要显式存前缀和数组，滚动维护 `cur/mn/mx` 三个变量即可，空间 $O(1)$。
5. **$n = 1$ 的退化**：`differences` 只有一个元素，前缀和为 $\{0, d_0\}$。极差 $= |d_0|$（若 $d_0$ 与 0 同号取 $|d_0|$，异号……实际 $mn = \min(0, d_0)$、$mx = \max(0, d_0)$，极差 $= |d_0|$）。答案 $= \text{窗口宽} - |d_0|$（非负时）。特殊地 $d_0 = 0$ 时任何 $x$ 都行，答案 = 窗口宽。

## 5. 正确性证明

**引理 1（隐藏数组的参数化）**：对任意 $x$，序列 $\text{hidden}^{(x)}[i] = x + S_i$（$S_i$ 如上定义）是**唯一**满足差分约束且 $\text{hidden}[0] = x$ 的数组；反之每个满足差分约束的数组都形如 $\text{hidden}^{(x)}$。

**证明**：归纳。$\text{hidden}^{(x)}[0] = x + S_0 = x$ ✓。若 $\text{hidden}[i] = x + S_i$，则差分约束强制 $\text{hidden}[i+1] = \text{hidden}[i] + \text{differences}[i] = x + S_i + \text{differences}[i] = x + S_{i+1}$。故差分约束唯一确定序列；反之逐项验证 $\text{hidden}^{(x)}[i+1] - \text{hidden}^{(x)}[i] = S_{i+1} - S_i = \text{differences}[i]$ 成立。∎

**引理 2（合法性等价于区间约束）**：$\text{hidden}^{(x)}$ 的所有元素落在 $[\text{lower}, \text{upper}]$ 当且仅当 $\text{lower} - S_{\min} \le x \le \text{upper} - S_{\max}$。

**证明**："$\forall i: \text{lower} \le x + S_i \le \text{upper}$" $\iff$ "$\forall i: \text{lower} - S_i \le x \le \text{upper} - S_i$"。左半对全体 $i$ 取交，下界为 $\max_i (\text{lower} - S_i) = \text{lower} - \min_i S_i = \text{lower} - S_{\min}$；右半取交为 $\min_i (\text{upper} - S_i) = \text{upper} - S_{\max}$。∎

**定理（计数公式）**：满足条件的隐藏数组数目为 $\max\big((\text{upper} - \text{lower} + 1) - (S_{\max} - S_{\min}),\ 0\big)$。

**证明**：由引理 1，隐藏数组与 $x \in \mathbb{Z}$ 一一对应（不同的 $x$ 给出不同的首元素，故数组不同）；由引理 2，合法 $x$ 恰构成区间 $[\text{lower} - S_{\min},\ \text{upper} - S_{\max}]$ 中的整数。该区间内的整数个数为 $(\text{upper} - S_{\max}) - (\text{lower} - S_{\min}) + 1 = (\text{upper} - \text{lower} + 1) - (S_{\max} - S_{\min})$；若区间为空（上式 $< 0$），个数为 0。故数目为上式与 0 的最大值。∎

## 6. 复杂度分析

- **时间**：$O(n)$。一遍扫描差分数组，每个元素做常数次加减与比较。
- **空间**：$O(1)$。滚动变量 `cur/mn/mx`；不需要前缀和数组（若显式存则 $O(n)$，无必要）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int numberOfArrays(vector<int>& differences, int lower, int upper) {
        long long cur = 0, mn = 0, mx = 0;     // hidden[0] 取 0 时各前缀和的极值
        for (int d : differences) {
            cur += d;
            mn = min(mn, cur);
            mx = max(mx, cur);
        }
        long long ans = (long long)upper - lower + 1 - (mx - mn);
        return ans > 0 ? (int)ans : 0;         // 可行起点 x 的个数，可能为 0
    }
};
```

### Python

```python
class Solution:
    def numberOfArrays(self, differences: List[int], lower: int, upper: int) -> int:
        cur = mn = mx = 0                    # hidden[0] 取 0 时各前缀和的极值
        for d in differences:
            cur += d
            mn = min(mn, cur)
            mx = max(mx, cur)
        ans = upper - lower + 1 - (mx - mn)  # 可行起点 x 的个数，可能为 0
        return ans if ans > 0 else 0
```

> 💡 两份代码均通过官方示例（`2`、`4`、`0`）以及 4000 组随机输入（$n \le 6$，差分 $\in [-5,5]$，随机窗口）与"枚举 $x$ 逐项验证"暴力的对拍，`mismatch = 0`。

## 8. 边界情况与易错点

1. **初值纳入 $S_0 = 0$**：`mn = mx = 0` 必须参与极值更新（首元素也要在窗口内）。错写成 `mn = INT_MAX` 或先加再初始化会把对 `hidden[0]` 的约束丢掉，多算。
2. **负数答案截断**：极差大于窗口宽时公式为负，必须返回 0 而非负数（示例 3）。
3. **C++ 溢出**：前缀和绝对值可达 $10^{10}$，32 位 `int` 溢出；用 `long long` 累加 `cur` 与极值。Python 原生大整数无碍。
4. **$n = 1$ 且 $d = 0$**：极差为 0，答案 = 窗口宽（窗口内每个值都可作唯一元素数组的起点）。这是"约束最松"的情形，验证初值逻辑的好用例。
5. **窗口极窄**：$\text{lower} = \text{upper}$ 时窗口宽为 1，仅当前缀和序列是常数（所有差分为 0）时答案为 1，否则 0。
6. **别把窗口宽算成 $\text{upper} - \text{lower}$**：闭区间包含两端，是 $\text{upper} - \text{lower} + 1$。漏掉 $+1$ 会系统性少 1。
7. **不需要真的构造数组**：返回的是**数目**，任何试图枚举/构造数组的思路都偏离了本题"计数"的本质。
