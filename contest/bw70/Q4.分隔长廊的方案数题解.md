# LeetCode 分隔长廊的方案数 题解

## 1. 题目概述

- **标题 / 题号**：分隔长廊的方案数（#2147，hard）
- **链接**：https://leetcode.cn/problems/number-of-ways-to-divide-a-long-corridor/
- **来源**：LeetCode 第 70 场双周赛 Q4
- **难度**：困难
- **标签**：数学、字符串、动态规划

**题意**：长廊用字符串 `corridor` 表示，`'S'` 是座位、`'P'` 是植物，共 $n$ 个位置。下标 $0$ 左侧与下标 $n-1$ 右侧已各放一个屏风。你还需要在相邻位置缝隙 $i-1$ 与 $i$ 之间（$1 \le i \le n-1$，每缝至多一个）放屏风，把长廊分成若干段，**每段恰有两个座位**（植物数目不限）。两种方案只要有任何一个屏风位置不同即算不同。返回方案数对 $10^9 + 7$ 取模的结果；无方案返回 0。

**约束**：

- $1 \le n \le 10^5$；
- `corridor[i]` 是 `'S'` 或 `'P'`。

## 2. 示例

**示例 1**

```text
输入：corridor = "SSPPSPS"
输出：3
解释：三种方案：SS|PPSPS、SSP|PSPS、SSPP|SPS（竖线为额外屏风）。
```

**示例 2**

```text
输入：corridor = "PPSPSP"
输出：1
解释：只有不放置任何屏风一种方案（恰好 2 个座位成一段）。
```

**示例 3**

```text
输入：corridor = "S"
输出：0
解释：总座位数为奇数，必有一段座位数不是 2，无方案。
```

## 3. 解题思路

### 3.1 暴力思路

每条缝隙独立地"放 / 不放"屏风，共 $2^{n-1}$ 种组合；对每种组合切段、验证每段座位数恰为 2——$O(2^{n-1} \cdot n)$ 指数爆炸，$n \le 12$ 时可作对拍基准。稍有洞察的暴力会想到 DP：$f[i][j]$ 表示前 $i$ 个位置、当前段已积累 $j$ 个座位时的方案数，转移枚举位置 $i$ 处放 / 不放屏风——$O(n)$ 状态、$O(1)$ 转移，能过但状态冗余。真正的突破口是注意到：**屏风的合法位置被座位分布唯一确定到一个"区间"内**，每两个座位之间必有一个强制分隔点，组合计数可以直接闭式算出。

### 3.2 核心观察：座位把长廊切成段，段间恰放一个屏风

![座位定段：从左往右每遇到两个 S 切出一段](images/bw70_q4_segment_model.svg)

设共有 $T$ 个座位，下标为 $s_0 < s_1 < \cdots < s_{T-1}$。

1. **总座位数必须为偶数**（$T$ 偶），否则最后一段凑不满两个，直接返回 0。$T = 0$ 时也返回 0（"每段恰两座"无从满足——没有任何段能合法存在）。
2. **段的划分由座位序决定**：合法方案中，第 $t$ 段（$t$ 从 1 计）必须恰好包含第 $2t-2$ 与第 $2t-1$ 个座位（归纳：第一段的两个座位必是前两个座位，否则第一段含 $\ge 3$ 座或前面有落单座）。于是**段边界固定**：第 $t$ 段与第 $t+1$ 段的分界必须落在第 $2t-1$ 个座位（$s_{2t-1}$）与第 $2t$ 个座位（$s_{2t}$）之间——屏风必须放在这条"缝隙带"里。
3. **缝隙带内恰放一个屏风**：放 0 个则两段并成 4 座段（非法）；放 $\ge 2$ 个则中间产生 0 座段（非法）。$s_{2t-1}$ 与 $s_{2t}$ 之间共有 $s_{2t} - s_{2t-1}$ 条缝隙（含两端缝隙），故该带的选择数为 $s_{2t} - s_{2t-1}$。

**段内部的植物不影响任何选择**：段内的缝隙放了屏风就会把 2 座段拆坏，一律不能放；段间缝隙带则恰好一放。所有带的选择相互独立，乘法原理连乘即总方案数。

### 3.3 算法流程：收集座位下标 + 连乘

![乘法原理：每个"缝隙带"独立选择，方案数连乘](images/bw70_q4_multiplier_model.svg)

```text
1. seats = [所有 'S' 的下标]
2. 若 seats 为空或长度为奇数：返回 0
3. ans = 1
   对 t = 1, 3, 5, …, T−3（步长 2，即奇数下标）：
       ans = ans × (seats[t+1] − seats[t]) mod (10⁹+7)
4. 返回 ans
```

循环枚举的是**偶数对**（第 1–2、3–4、… 个座位）之间的边界：$t$ 取奇数（0 基）时 `seats[t]` 是某段末座位、`seats[t+1]` 是下一段首座位，二者之间的缝隙数恰为 `seats[t+1] - seats[t]`。

### 3.4 示例演算

![示例 1：corridor = "SSPPSPS" 的三种方案](images/bw70_q4_example_walkthrough.svg)

**示例 1** `SSPPSPS`：座位下标 $[0, 1, 4, 6]$，$T = 4$ 偶。唯一的段间边界在 $s_1 = 1$ 与 $s_2 = 4$ 之间：缝隙 1|2、2|3、3|4 共 $4 - 1 = 3$ 条，方案数 $3$——分别对应 `SS|PPSPS`、`SSP|PSPS`、`SSPP|SPS`，与三种排列一致。

**示例 2** `PPSPSP`：座位下标 $[2, 4]$，$T = 2$，没有段间边界，乘积为空即 $1$（不放任何屏风）。

**示例 3** `S`：$T = 1$ 奇，返回 0。

## 4. 算法细节

1. **座位下标数组是全部所需信息**：植物只在"相邻两座位间的距离"里体现（$s_{2t} - s_{2t-1}$ 越大选择越多），无需单独处理。
2. **循环边界的推导**：段间边界位于第 $2t$ 与第 $2t+1$ 个座位（1 基）之间，0 基下标即 `seats[2t-1]` 与 `seats[2t]`。让循环变量 $t$ 直接走 `range(1, len(seats) - 1, 2)`（Python）或 `for (t = 1; t + 1 < T; t += 2)`（C++），覆盖 $t = 1, 3, 5, \ldots, T-3$，共 $T/2 - 1$ 个边界。
3. **取模时机**：每个因子乘完立刻 `% MOD`，防止连乘溢出（C++ `long long` 可撑几个因子但不撑全程；$10^9 \times 10^5$ 已超 `int` 范围）。因子本身 $s_{t+1} - s_t \le n - 1 < 10^9$，单乘在 `long long` 内安全。
4. **$T = 0$ 与 $T = 1$ 的区分**：两者都返回 0，但语义不同（无座位 → 没有任何合法段；一个座位 → 奇数）。判空与判奇都要写。
5. **为什么不用 DP**：DP 的 $f[i][j]$ 里 $j$（当前段已积累座位数）在合法路径上只取 $\{0, 1, 2\}$ 且被座位位置强制驱动，本质就是本文的"逐段推进"；闭式乘积是 DP 收敛后的最简形态。写 DP 也对，但乘法原理版本代码 5 行、零状态。
6. **模运算下无逆元需求**：只乘不除，无需考虑 $10^9+7$ 的逆元。

## 5. 正确性证明

**引理 1（段结构的唯一性）**：任何合法划分中，第 $t$ 段（$t = 1, \ldots, T/2$）恰包含座位 $s_{2t-2}$ 与 $s_{2t-1}$（1 基的第 $2t-1$、$2t$ 个座位），不多不少。

**证明**：归纳。第一段从位置 0 起：若它不含 $s_0$ 则第一段 0 座（屏风在 $s_0$ 左侧），非法；故含 $s_0$。若它还含 $s_1$ 之后的座位，则至少含 3 座或恰含到 $s_1$ 之后某处——座位数要么 $\ge 3$（非法）要么把 $s_1$ 之后的某座位排除在外使下一段起点落在两座位之间。精确论证：第一段的座位集是 $\{s_0, \ldots, s_{j}\}$ 中某前缀（段是连续区间），合法要求 $j + 1 = 2$，即恰含 $s_0, s_1$；若 $j + 1 = 0$ 非法，$j+1 = 1$ 非法（1 座），$j + 1 \ge 3$ 非法（$\ge 3$ 座）。设前 $t$ 段分别含 $\{s_0, s_1\}, \ldots, \{s_{2t-2}, s_{2t-1}\}$，则第 $t+1$ 段从 $s_{2t-1}$ 之后（含 $s_{2t}$）开始的连续区间，同第一段论证其座位集必为从 $s_{2t}$ 起的连续两座 $s_{2t}, s_{2t+1}$。归纳完成。特别地 $T$ 为奇数时最后一段仅 1 座，无合法划分。∎

**引理 2（屏风位置的刻画）**：合法划分 ⇔ 屏风集合 $\mathcal{D}$ 满足：对每个 $t = 1, \ldots, T/2 - 1$，$\mathcal{D}$ 在开区间 $(s_{2t-1}, s_{2t})$ 对应的缝隙带 $\{s_{2t-1}+1, \ldots, s_{2t}\}$（缝隙 $i{-}1|i$ 记为 $i$）中恰含一条缝隙，且 $\mathcal{D}$ 不含其他缝隙。

**证明**：设合法划分的段如引理 1。第 $t$ 段覆盖位置区间 $[a_t, b_t]$（$a_1 = 0$，$b_t + 1 = a_{t+1}$，$b_{T/2} = n - 1$），其中 $s_{2t-2}, s_{2t-1} \in [a_t, b_t]$ 且 $s_{2t-2}$ 是该段第一个座位、$s_{2t-1}$ 是最后一个（段内恰两座）。相邻段 $t$ 与 $t+1$ 间的分界缝隙是 $b_t | b_t + 1$，即缝隙 $b_t + 1$，且 $s_{2t-1} \le b_t < s_{2t}$（$b_t$ 在末座位与下一段首座位之间），故 $b_t + 1 \in [s_{2t-1} + 1, s_{2t}]$，落在所述缝隙带内。每对相邻段恰产生一条这样的分界缝，不同对互不重叠（带与带之间隔着完整的段）；段内部无缝隙（段是连续的，段内任何缝隙两侧同属一段）。两端的固有屏风不在 $\mathcal{D}$ 内。反之，给定满足所述条件的 $\mathcal{D}$：在 $\mathcal{D}$ 与两端固有屏风处切开，得到的每个段夹在相邻两条屏风间，其座位集恰为引理 1 所述的连续两座（带内唯一的屏风把 $\{s_{2t-1}\}$ 与 $\{s_{2t}\}$ 分开，段内不混入相邻段的座位），每段 2 座，合法。∎

**定理（计数公式）**：合法方案数为 $\prod_{t=1}^{T/2 - 1} (s_{2t} - s_{2t-1}) \bmod (10^9 + 7)$；$T = 0$ 或 $T$ 为奇数时为 0。

**证明**：缝隙带 $B_t = [s_{2t-1}+1, s_{2t}]$（缝隙编号）含 $s_{2t} - s_{2t-1}$ 条缝隙，各带互不相交且均含于 $\{1, \ldots, n-1\}$。由引理 2，合法方案与"每个带恰选 1 条缝隙"的选择一一对应（带外的选择固定为不选）。各带选择独立，由乘法原理总数为 $\prod_t |B_t| = \prod_t (s_{2t} - s_{2t-1})$。$T = 0$ 时不存在任何 2 座段，由引理 1 无合法划分；$T$ 奇时同理。取模即得。∎

## 6. 复杂度分析

- **时间**：$O(n)$。一次扫描收集座位下标，随后 $O(T/2)$ 次乘法取模。
- **空间**：$O(T)$ 存座位下标（$T \le n$）；若想压到 $O(1)$，可边扫边维护"当前是第几个座位"与"上一个偶数位座位下标"，只存两个变量——对 $n \le 10^5$ 无必要，保留下标数组更可读。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int numberOfWays(string corridor) {
        const long long MOD = 1000000007LL;
        vector<int> seats;                               // 所有座位的下标
        for (int i = 0; i < (int)corridor.size(); ++i)
            if (corridor[i] == 'S') seats.push_back(i);
        if (seats.empty() || seats.size() % 2 == 1) return 0;   // 无法两两分段
        long long ans = 1;
        // 相邻两段之间（第 2i 个与第 2i+1 个座位之间）必须恰放 1 个屏风，
        // 该处可选位置数 = seats[k+1] - seats[k]
        for (size_t t = 1; t + 1 < seats.size(); t += 2)
            ans = ans * (seats[t + 1] - seats[t]) % MOD;
        return (int)ans;
    }
};
```

### Python

```python
class Solution:
    def numberOfWays(self, corridor: str) -> int:
        MOD = 10 ** 9 + 7
        seats = [i for i, ch in enumerate(corridor) if ch == 'S']   # 所有座位下标
        if not seats or len(seats) % 2:
            return 0
        ans = 1
        # 相邻两段之间（第 2i 个与第 2i+1 个座位之间）必须恰放 1 个屏风，
        # 该处可选位置数 = seats[k+1] - seats[k]
        for t in range(1, len(seats) - 1, 2):
            ans = ans * (seats[t + 1] - seats[t]) % MOD
        return ans
```

> 💡 两份代码均通过官方示例（`3`、`1`、`0`）以及 4000 组随机串（$n \le 12$）与"枚举 $2^{n-1}$ 种缝隙组合逐段验证"暴力的对拍，`mismatch = 0`。

## 8. 边界情况与易错点

1. **$T = 0$（全是植物）**：返回 0，不是 1。没有任何座位意味着任何划分都有 0 座段——除非"不划分"也算？不行：整条长廊本身就是一个 0 座段。判空别漏。
2. **$T$ 为奇数**：返回 0（最后一段单座位）。示例 3 的 `"S"` 是最小情形。
3. **相邻座位紧挨（$s_{2t} = s_{2t-1} + 1$）**：缝隙数 $= 1$，该边界只有一种放法（两座位中间必放），乘积乘 1 不影响——`"SSSS"` 答案 1（`SS|SS` 唯一）。
4. **因子是"下标差"不是"植物数 + 1"的错位**：$s_{2t} - s_{2t-1}$ 恰等于两座位间植物数 + 1，等价表述；但若手滑写成植物数（漏 +1）或写成 $s_{2t} - s_{2t-1} + 1$（多 1）都会错。建议直接记"下标差"。
5. **取模与溢出**：C++ 中 `ans` 用 `long long` 且**每次乘完立即取模**；因子上界 $n - 1 < 10^5$，`long long` 乘积 $< 10^{14}$ 安全。若 `ans` 用 `int` 存而不及时取模，第二次乘法就溢出。
6. **循环边界**：`t` 从 1 开始步长 2、条件 `t + 1 < len(seats)`，共 $T/2 - 1$ 项；写成 `t < len(seats)` 会越界访问 `seats[t+1]`，写成从 0 开始会把段内边界（$s_{2t}$ 与 $s_{2t+1}$ 之间，即段内两座位之间）也算进去——那是不能放屏风的位置。
7. **空串不会出现**（$n \ge 1$），但 `corridor = "P"` 是合法输入（$T = 0$，返回 0）。
8. **模数**：$10^9 + 7$，别写成 $10^9 + 9$ 或 $998244353$ 的肌肉记忆错误。
