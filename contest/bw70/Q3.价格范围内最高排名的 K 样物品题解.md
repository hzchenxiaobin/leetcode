# LeetCode 价格范围内最高排名的 K 样物品 题解

## 1. 题目概述

- **标题 / 题号**：价格范围内最高排名的 K 样物品（#2146，medium）
- **链接**：https://leetcode.cn/problems/k-highest-ranked-items-within-a-price-range/
- **来源**：LeetCode 第 70 场双周赛 Q3
- **难度**：中等
- **标签**：广度优先搜索、数组、矩阵、排序、堆（优先队列）

**题意**：给 $m \times n$ 网格 `grid`：$0$ 是墙（不可通行）、$1$ 是可通行的空格、其他正整数是可通行格内物品的价格。从 `start` 出发，每步走到上下左右相邻格。给定价格区间 `pricing = [low, high]` 与整数 $k$，按以下优先级（从高到低）对**价格在 $[low, high]$ 内**的物品排名：

1. **距离**：从 start 出发的最短路径步数，近者排名高；
2. **价格**：低者优先；
3. **行坐标**：小者优先；
4. **列坐标**：小者优先。

返回排名前 $k$ 的物品坐标（不足 $k$ 个则全返回）。

**约束**：

- $1 \le m, n \le 10^5$ 且 $1 \le m \times n \le 10^5$；
- $0 \le \text{grid}[i][j] \le 10^5$；$\text{grid}[\text{row}][\text{col}] > 0$（起点不是墙）；
- $2 \le \text{low} \le \text{high} \le 10^5$；
- $1 \le k \le m \times n$。

## 2. 示例

**示例 1**

```text
输入：grid = [[1,2,0,1],[1,3,0,1],[0,2,5,1]], pricing = [2,5], start = [0,0], k = 3
输出：[[0,1],[1,1],[2,1]]
解释：候选物品 (0,1)、(1,1)、(2,1)、(2,2) 的距离分别为 1、2、3、4，取最近 3 个。
```

**示例 2**

```text
输入：grid = [[1,2,0,1],[1,3,3,1],[0,2,5,1]], pricing = [2,3], start = [2,3], k = 2
输出：[[2,1],[1,2]]
解释：(2,1) 与 (1,2) 距离同为 2，价格 2 < 3，前者优先。
```

**示例 3**

```text
输入：grid = [[1,1,1],[0,0,1],[2,3,4]], pricing = [2,3], start = [0,0], k = 3
输出：[[2,1],[2,0]]
解释：价格在 [2,3] 内的物品只有 (2,0)、(2,1)，不足 k 个，全部返回。
```

## 3. 解题思路

### 3.1 暴力思路

对每个价格在范围内的格子单独跑一次 BFS/Dijkstra 求到起点的最短距离，再按四关键字排序取前 $k$——单次 BFS $O(mn)$，全体格子共 $O((mn)^2) = 4\times10^{10}$，超时。正确的暴力姿势是"一次 BFS 求全源距离 + 一次排序"：从起点做单源 BFS 得到**所有**格子的最短距离（无权图，BFS 层序即最短），收集范围内物品格，四关键字排序，截前 $k$。这就是正解，复杂度瓶颈只剩排序。

### 3.2 核心观察：BFS 层序 + 元组字典序 = 完整排名

![层序扩散：广度优先搜索一圈圈向外，先到者距离短](images/bw70_q3_bfs_rank_model.svg)

两个观察把问题化到最简：

1. **无权图的最短路用 BFS**：每步代价相同，BFS 按层扩展，格子第一次被访问时的步数就是最短距离，$O(mn)$ 一次拿全。墙（$0$）不进队；物品格与空格（$\ge 1$）都可通行——**物品格是"路过的格子里恰好有货"**，通行性与候选资格是两回事。
2. **四关键字 = 元组字典序**：把每个候选记成四元组 $(dist, price, row, col)$，则"距离近 → 价格低 → 行小 → 列小"的优先级恰好是元组的字典序。C++ 的 `array<int,4>`、Python 的 `tuple` 都天然按字典序比较，一次 `sort` 完成，无需自定义比较器。

**起点本身也可能是候选**：若 $\text{grid}[\text{start}] \in [low, high]$，它距离为 0、排名靠前，必须在 BFS 前单独登记（BFS 只在"扩展邻居"时登记，会漏掉起点自身）。

### 3.3 算法流程

![算法流程：BFS → 收集候选 → 元组排序 → 截取前 k](images/bw70_q3_algorithm_flow.svg)

```text
1. dist[start] = 0，起点入队；若 grid[start] ∈ [low, high]，登记 (0, price, r, c)
2. BFS：出队 (r, c)，向四邻 (nr, nc) 扩展
       越界 / 墙（=0）/ 已访问 → 跳过
       dist[nr][nc] = dist[r][c] + 1，入队
       若 grid[nr][nc] ∈ [low, high] → 登记 (dist, price, nr, nc)
3. 候选数组按元组字典序排序
4. 取前 min(k, 候选数) 个的 (row, col) 输出
```

排序 $O(P \log P)$（$P$ 为候选数 $\le mn$）。若 $k \ll P$，可换 $k$ 容量大根堆做到 $O(P \log k)$；本题规模下直接排序已足够。

### 3.4 示例演算

![示例 2 演算：起点在右下角、价格区间为 2 到 3、取前 2 名](images/bw70_q3_example_walkthrough.svg)

以示例 2 为例（$3\times4$ 网格，墙在 $(0,2)$ 与 $(2,0)$）：从 $(2,3)$ BFS，各格距离如走查图。价格 $\in [2,3]$ 的候选共 4 个：$(2,1)$：$(2, 2, 2, 1)$；$(1,2)$：$(2, 3, 1, 2)$；$(1,1)$：$(3, 3, 1, 1)$；$(0,1)$：$(4, 2, 0, 1)$。排序后前两个是 $(2,1)$（同距离 2 但价格 2 更低）与 $(1,2)$，输出 `[[2,1],[1,2]]`。注意 $(2,2)$ 价格 5 不在范围内——**距离再近也不入候选，但仍可通行**；起点 $(2,3)$ 价格 1 同理不是候选。

## 4. 算法细节

1. **起点的候选登记**：BFS 主循环只处理"出队格的邻居"，起点若不单独登记就会漏掉"站在起点就能买"的情况。约束保证 $\text{grid}[\text{start}] \ge 1$（非墙），当 $\text{low} \ge 2$ 时空格 1 不会成为候选，但判定式统一写 `low <= v <= high` 即可，无需分类讨论。
2. **visited 与 dist 合一**：`dist` 初始化为 $-1$，入队时置数，既是访问标记又是距离值，省一个数组。
3. **墙的判定**：`grid[nr][nc] == 0` 跳过。**墙不阻挡视线但阻挡通行**——BFS 只沿可通行格扩展，墙格的 dist 永远是 $-1$。
4. **元组比较的天然性**：`array<int,4>` / tuple 的默认比较即逐分量字典序，与题目优先级一一对应，**不要**手写比较函数（容易在"价格"与"行列"的次序上出错）。若用 `pair` 嵌套（`pair<int, pair<int, pair<int,int>>>`）也能对但可读性差。
5. **返回坐标而非元组**：排序对象是四元组，输出只取后两分量；先截 `items[:k]` 再取坐标，避免构造无用列表。
6. **堆优化变体**：维护容量 $k$ 的**大根堆**（按元组比较），候选 $P$ 个时 $O(P \log k)$。当 $k$ 与 $P$ 同阶时与排序无差，$k$ 极小时略优；本题 $mn \le 2\times10^5$，`sort` 足够。
7. **多关键字平局的完备性**：四关键字（距离、价格、行、列）中行列保证任意两格不同，故不存在完全并列，排名唯一确定——这也是"元组排序"正确性的前提。

## 5. 正确性证明

**引理 1（BFS 最短距离）**：在所有边权为 1 的图上，从单源 $s$ 出发的 BFS 使每个可达顶点 $v$ 的 `dist[v]` 等于 $s$ 到 $v$ 的最短路径长度；不可达顶点保持 $-1$。

**证明**：对 BFS 层数 $d$ 归纳。$d = 0$：仅源点，dist = 0 正确。设所有层数 $\le d$ 的顶点已取得正确距离且按层序出队。出队第 $d$ 层顶点 $u$ 时，其未访问邻居 $v$ 被赋 $dist[v] = d + 1$：一方面 $s \to u$（长 $d$）加边 $(u,v)$ 给出长 $d+1$ 的路径，故最短路 $\le d+1$；另一方面若存在长 $\le d$ 的 $s \to v$ 路径，则其倒数第二个顶点层数 $\le d - 1$，$v$ 应在处理该顶点时已被赋值 $\le d$，与"未访问"矛盾。故 $dist[v] = d+1$ 精确。归纳成立。墙不可入队，天然排除。∎

**引理 2（候选集完整性）**：物品格 $(r,c)$ 是候选（价格在范围内）当且仅当它在算法第 1、2 步被登记；且登记时的距离分量等于其最短距离。

**证明**：候选资格只由 $\text{grid}[r][c] \in [low, high]$ 决定。起点格在 BFS 前被显式登记；非起点格 $(r,c)$ 被访问（赋 dist）当且仅当从起点可达，此时它在扩展其前驱时按"入队即登记"规则被登记一次，距离分量 = dist[r][c]，由引理 1 为最短距离。不可达格（被墙围死）dist 保持 $-1$，从未登记——但其最短距离本就不存在（不可达），故不遗漏任何有定义的候选。∎

**定理（算法正确）**：算法输出的坐标序列等于按题目四关键字排名的前 $\min(k, P)$ 个物品。

**证明**：候选集与其 $(dist, price, row, col)$ 四元组由引理 2 完整且精确地给出。题目排名规则"距离小优先，其次价格小，其次行小，其次列小"即四元组的字典序：按第一分量比较，相同则按第二分量，依此类推。对四元组数组做字典序排序（`std::sort` 对 `array<int,4>`、Python 对 tuple 均为字典序）得到按排名从高到低的序列；截取前 $\min(k, P)$ 个并输出 $(row, col)$ 分量即所求。∎

## 6. 复杂度分析

- **时间**：$O(mn + P \log P)$，$P \le mn$ 为候选物品数。BFS 访问每格每边常数次 $O(mn)$；排序 $O(P \log P)$。总体 $O(mn \log(mn))$ 上界，$mn \le 2\times10^5$ 下约 $3.5\times10^6$ 次比较，轻松通过。堆优化可到 $O(mn + P \log k)$。
- **空间**：$O(mn)$。`dist` 矩阵与候选四元组数组各 $O(mn)$；队列至多 $O(mn)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<vector<int>> highestRankedKItems(vector<vector<int>>& grid, vector<int>& pricing,
                                            vector<int>& start, int k) {
        int m = (int)grid.size(), n = (int)grid[0].size();
        int low = pricing[0], high = pricing[1];
        int sr = start[0], sc = start[1];
        vector<vector<int>> dist(m, vector<int>(n, -1));
        queue<pair<int, int>> q;
        dist[sr][sc] = 0;
        q.push({sr, sc});
        vector<array<int, 4>> items;                    // (距离, 价格, 行, 列)
        if (low <= grid[sr][sc] && grid[sr][sc] <= high)
            items.push_back({0, grid[sr][sc], sr, sc}); // 起点本身可以是物品
        const int dr[4] = {-1, 1, 0, 0}, dc[4] = {0, 0, -1, 1};
        while (!q.empty()) {
            auto [r, c] = q.front();
            q.pop();
            for (int t = 0; t < 4; ++t) {
                int nr = r + dr[t], nc = c + dc[t];
                if (nr < 0 || nr >= m || nc < 0 || nc >= n) continue;
                if (grid[nr][nc] == 0 || dist[nr][nc] != -1) continue;  // 墙 / 已访问
                dist[nr][nc] = dist[r][c] + 1;
                q.push({nr, nc});
                if (low <= grid[nr][nc] && grid[nr][nc] <= high)
                    items.push_back({dist[nr][nc], grid[nr][nc], nr, nc});
            }
        }
        sort(items.begin(), items.end());               // 四关键字字典序 = 排名
        vector<vector<int>> ans;
        for (int i = 0; i < (int)items.size() && i < k; ++i)
            ans.push_back({items[i][2], items[i][3]});
        return ans;
    }
};
```

### Python

```python
class Solution:
    def highestRankedKItems(self, grid: List[List[int]], pricing: List[int],
                            start: List[int], k: int) -> List[List[int]]:
        m, n = len(grid), len(grid[0])
        low, high = pricing
        sr, sc = start
        dist = [[-1] * n for _ in range(m)]
        dist[sr][sc] = 0
        q = deque([(sr, sc)])
        items = []                                   # (距离, 价格, 行, 列)
        if low <= grid[sr][sc] <= high:
            items.append((0, grid[sr][sc], sr, sc))  # 起点本身可以是物品
        while q:
            r, c = q.popleft()
            for nr, nc in ((r - 1, c), (r + 1, c), (r, c - 1), (r, c + 1)):
                if 0 <= nr < m and 0 <= nc < n and grid[nr][nc] != 0 and dist[nr][nc] == -1:
                    dist[nr][nc] = dist[r][c] + 1
                    q.append((nr, nc))
                    if low <= grid[nr][nc] <= high:
                        items.append((dist[nr][nc], grid[nr][nc], nr, nc))
        items.sort()                                 # 四关键字字典序 = 排名
        return [[r, c] for _, _, r, c in items[:k]]
```

> 💡 两份代码均通过官方三个示例（`[[0,1],[1,1],[2,1]]`、`[[2,1],[1,2]]`、`[[2,1],[2,0]]`）以及 2000 组随机网格（$m, n \le 5$）与"Floyd-Warshall 全源最短路 + 四关键字排序"独立暴力的对拍，`mismatch = 0`。

## 8. 边界情况与易错点

1. **起点是候选**：$\text{grid}[\text{start}] \in [low, high]$ 时起点距离 0 排最前。约束 $\text{low} \ge 2$ 使价格 1 的普通空格（含多数起点）不构成候选，但**价格 $\ge 2$ 的起点格**完全可能，必须在 BFS 外先登记。
2. **范围外物品照常通行**：价格 5 的格子若不在 $[low, high]$ 内，不是候选，但 BFS 必须能踩上去（`grid != 0` 判通行）。把"候选判定"混进"通行判定"是典型 WA。
3. **闭区间端点**：价格范围是 $[low, high]$ 含两端，判定写 `low <= v <= high`，漏等号会丢掉恰好在边界上的物品。
4. **不足 $k$ 个候选**：返回全部（示例 3），切片 `items[:k]` 天然处理，无需特判。
5. **被墙围死的区域**：不可达格 dist 为 $-1$，不是候选（距离无定义）。BFS 的 visited 判定保证它们不被登记。
6. **行列坐标的次序**：四关键字中行在列前——元组 $(dist, price, row, col)$ 的分量顺序必须与题意严格一致；手写比较器时把行、列写反是最隐蔽的 bug（只有平局时暴露）。
7. **同距离同价格的平局**：靠行列分胜负，元组排序自动处理；构造测试时故意放两个"距离价格都相同"的物品可验证。
8. **性能**：不要对每个候选单独 BFS（$O(P \cdot mn)$）；也不要用 Dijkstra（无权图不需要优先队列，BFS 更快更简单）。
