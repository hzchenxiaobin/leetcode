# LeetCode 子矩阵元素加 1 题解

## 1. 题目概述

- **标题 / 题号**：子矩阵元素加 1（#2536，medium）
- **链接**：https://leetcode.cn/problems/increment-submatrices-by-one/
- **来源**：LeetCode 第 328 场周赛 Q2
- **难度**：中等
- **标签**：数组、矩阵、二维差分、前缀和

**题意**：给定正整数 `n`，初始有一个 `n × n`、下标从 0 开始、元素全为 0 的整数矩阵 `mat`。再给定查询数组 `queries`，每个 `queries[i] = [row1i, col1i, row2i, col2i]` 描述一个子矩阵的左上角 `(row1i, col1i)` 与右下角 `(row2i, col2i)`：把所有满足 `row1i <= x <= row2i` 且 `col1i <= y <= col2i` 的 `mat[x][y]` 全部加 1。返回执行完全部查询后的矩阵 `mat`。

**约束**：

- $1 \le n \le 500$
- $1 \le \text{queries.length} \le 10^4$
- $0 \le \text{row1i} \le \text{row2i} < n$
- $0 \le \text{col1i} \le \text{col2i} < n$

> ⚠️ **规模读法**：单次查询最坏覆盖整个矩阵，即 $n^2 = 2.5 \times 10^5$ 个格子；$q = 10^4$ 次查询若逐格累加，最坏 $10^4 \times 2.5 \times 10^5 = 2.5 \times 10^9$ 次操作，必然超时。本题的考点就是把「一次子矩阵加」从 $O(\text{面积})$ 压到 $O(1)$。

## 2. 示例

**示例 1**

```text
输入：n = 3, queries = [[1,1,2,2],[0,0,1,1]]
输出：[[1,1,0],[1,2,1],[0,1,1]]
解释：
- 查询 1：子矩阵 (1,1)~(2,2) 内每格 +1
- 查询 2：子矩阵 (0,0)~(1,1) 内每格 +1
- 两块子矩阵恰好在 (1,1) 重叠，该格被加 2 次
```

**示例 2**

```text
输入：n = 2, queries = [[0,0,1,1]]
输出：[[1,1],[1,1]]
解释：唯一的查询覆盖整个矩阵，每格 +1。
```

**补充用例**

```text
输入：n = 1, queries = [[0,0,0,0]]
输出：[[1]]
解释：1×1 矩阵，查询覆盖唯一的格子。

输入：n = 3, queries = [[0,0,2,2],[0,0,2,2]]
输出：[[2,2,2],[2,2,2],[2,2,2]]
解释：两个一模一样的整矩阵查询完全重叠，每格 = 2。
```

## 3. 解题思路

### 3.1 暴力思路：逐格累加

对每个查询 `[r1,c1,r2,c2]`，双重循环遍历子矩阵内每个格子执行 `mat[x][y] += 1`。单次查询成本 $O\big((r_2-r_1+1)(c_2-c_1+1)\big)$，最坏 $O(n^2)$；$q$ 次查询合计 $O(q \cdot n^2)$，代入上界约 $2.5 \times 10^9$，**超时**。

瓶颈在于「子矩阵整体加」这个操作太贵。注意到所有修改先做完、最后才一次性取答案——这是**离线批量修改**的经典信号，提示用差分把每次修改压成常数个单点标记。

### 3.2 核心观察：二维差分

![二维差分：子矩阵 +1 ⇒ 四个角打标记](images/wc328_q2_diff_concept.svg)

这是一维差分（区间加 → 两端打标记，末尾一次前缀和还原）在二维的直接推广：

> 一次「把子矩阵 $[r_1,r_2] \times [c_1,c_2]$ 整体 $+1$」，等价于在差分数组 $d$ 上做 **4 个单点修改**；全部查询标记完后，对 $d$ 做**一次二维前缀和**即可还原真实矩阵。

对查询 `[r1,c1,r2,c2]`（0-indexed，$r_2, c_2 < n$）：

$$
d[r_1][c_1] \mathrel{+}= 1,\quad
d[r_2{+}1][c_1] \mathrel{-}= 1,\quad
d[r_1][c_2{+}1] \mathrel{-}= 1,\quad
d[r_2{+}1][c_2{+}1] \mathrel{+}= 1
$$

四个标记点：左上角 $+1$、左下角下方 $-1$、右上角右侧 $-1$、右下角对角处 $+1$。

> 💡 **为什么四个角就够？** 二维差分 = 行方向做一次一维差分 × 列方向再做一次一维差分。一维差分里区间 $[l,r]$ 加 1 用 $d[l]{+}{=}1,\ d[r{+}1]{-}{=}1$ 两端打标记；行、列两次「两端打标记」复合起来恰好落在四个角上，符号为 $\{+1,-1,-1,+1\}$（行标记符号 × 列标记符号）。二维前缀和后，贡献恰好填满子矩阵矩形、矩形外全部相消。

### 3.3 算法流程

![算法流程：标记 O(q) → 二维前缀和还原 O(n²)](images/wc328_q2_algorithm_flow.svg)

1. **建差分数组**：$d$ 开 $(n+1) \times (n+1)$、全 0——多出的一行一列专门存放贴边查询的 $r_2{+}1$、$c_2{+}1$ 标记。
2. **逐查询打标记**：每个查询做 4 个单点修改，$O(1)$，共 $q$ 次。
3. **二维前缀和还原**：逐格容斥递推 $\text{mat}[i][j] = d[i][j] + \text{mat}[i{-}1][j] + \text{mat}[i][j{-}1] - \text{mat}[i{-}1][j{-}1]$（越界项按 0），写进 $n \times n$ 答案矩阵。

### 3.4 示例演算

![示例 1 演算：两个查询的标记与还原](images/wc328_q2_example_walkthrough.svg)

以示例 1（$n=3$，`queries = [[1,1,2,2],[0,0,1,1]]`）演示，$d$ 为 $4 \times 4$（行列 $0 \sim 3$）：

- 查询 1 `[1,1,2,2]`：$d[1][1]{+}{=}1,\ d[3][1]{-}{=}1,\ d[1][3]{-}{=}1,\ d[3][3]{+}{=}1$
- 查询 2 `[0,0,1,1]`：$d[0][0]{+}{=}1,\ d[2][0]{-}{=}1,\ d[0][2]{-}{=}1,\ d[2][2]{+}{=}1$

打完标记后 $d$：

| | c0 | c1 | c2 | c3 |
|---|---|---|---|---|
| **r0** | 1 | 0 | −1 | 0 |
| **r1** | 0 | 1 | 0 | −1 |
| **r2** | −1 | 0 | 1 | 0 |
| **r3** | 0 | −1 | 0 | 1 |

二维前缀和后取左上 $3 \times 3$：

| | c0 | c1 | c2 |
|---|---|---|---|
| **r0** | 1 | 1 | 0 |
| **r1** | 1 | **2** | 1 |
| **r2** | 0 | 1 | 1 |

得 `[[1,1,0],[1,2,1],[0,1,1]]` ✓，其中 $(1,1)$ 是两块子矩阵的重叠点，值为 $1+1=2$。

## 4. 算法细节

1. **差分数组为何开 $(n{+}1) \times (n{+}1)$**：查询保证 $r_2, c_2 < n$，故边界标记落在下标 $r_2{+}1 \le n$、$c_2{+}1 \le n$ 处；开到下标 $n$（即 $(n{+}1)$ 大小）刚好放下贴边标记而不越界。还原时只取左上 $n \times n$ 作答案。
2. **还原递推是容斥**：$\text{mat}[i][j] = d[i][j] + \text{mat}[i{-}1][j] + \text{mat}[i][j{-}1] - \text{mat}[i{-}1][j{-}1]$，其中 $\text{mat}[i{-}1][j{-}1]$ 被行、列两个方向各加一次，须减回一次；$i=0$ 或 $j=0$ 时越界项按 0 跳过（等价于矩阵外圈补零）。
3. **就地还原变体**：可省掉答案矩阵，直接在 $d$ 上先按行做一维前缀和（`d[i][j] += d[i][j-1]`）、再按列做一维前缀和（`d[i][j] += d[i-1][j]`），两趟扫描与二维前缀和等价，额外空间降到 $O(1)$。
4. **值域评估**：每格最多被 $q \le 10^4$ 个查询覆盖，答案上限 $10^4$；差分标记有正有负，但前缀和过程不会溢出 32 位 `int`，全程无需 `long long`。

## 5. 正确性证明

记 $\mathbb{1}[P]$ 为条件 $P$ 成立时取 1、否则取 0 的示性函数。

**引理 1**（一维差分）：在数组 $d$ 上仅做 $d[l] \mathrel{+}= 1$ 与 $d[r{+}1] \mathrel{-}= 1$（$l \le r$），则前缀和 $P[x] = \sum_{k \le x} d[k]$ 满足：$P[x] = 1$ 当且仅当 $l \le x \le r$，否则为 0。

**证明**：$P[x] = \mathbb{1}[x \ge l] - \mathbb{1}[x \ge r{+}1]$。当 $x < l$ 时两项皆为 0；当 $l \le x \le r$ 时仅第一项为 1；当 $x \ge r{+}1$ 时两项相消为 0。∎

**引理 2**（四角标记）：对查询 $[r_1, c_1, r_2, c_2]$ 在 $(n{+}1)\times(n{+}1)$ 的 $d$ 上做 §3.2 的四个单点修改，则二维前缀和 $S[i][j] = \sum_{x \le i} \sum_{y \le j} d[x][y]$ 满足：$S[i][j] = 1$ 当且仅当 $r_1 \le i \le r_2$ 且 $c_1 \le j \le c_2$，否则为 0。

**证明**：四个标记点的贡献可按 $i$、$j$ 两个方向分离并因式分解：

$$
S[i][j] = \big(\mathbb{1}[i \ge r_1] - \mathbb{1}[i \ge r_2{+}1]\big) \cdot \big(\mathbb{1}[j \ge c_1] - \mathbb{1}[j \ge c_2{+}1]\big).
$$

由引理 1，第一个因子恰在 $i \in [r_1, r_2]$ 时为 1，第二个因子恰在 $j \in [c_1, c_2]$ 时为 1，故乘积恰在矩形 $[r_1,r_2] \times [c_1,c_2]$ 上取 1、其余处处为 0。∎

**定理**：算法输出的 $\text{mat}[i][j]$ 等于覆盖格子 $(i,j)$ 的查询个数，即正确答案。

**证明**：差分标记线性可加：$q$ 个查询打完标记后的 $d$ 等于各查询标记之和，故由引理 2 与求和的线性性，$S[i][j] = \sum_{k=1}^{q} \mathbb{1}[\text{查询 } k \text{ 覆盖 } (i,j)]$，即覆盖计数。对 $i+j$ 作数学归纳可证还原递推给出 $\text{mat}[i][j] = S[i][j]$（$i=0$ 或 $j=0$ 时跳过越界项对应外圈补零），且算法只计算 $0 \le i, j < n$ 的格子。∎

## 6. 复杂度分析

- **时间复杂度**：$O(q + n^2)$。标记阶段 $q$ 个查询各 $O(1)$，共 $q$ 次单点修改；还原阶段遍历 $n^2$ 个格子。代入 $q = 10^4$、$n = 500$ 约 $2.6 \times 10^5$ 次操作，毫秒级完成，与朴素 $O(q \cdot n^2) \approx 2.5 \times 10^9$ 相差近四个数量级。
- **空间复杂度**：$O(n^2)$。差分数组 $d$ 为 $(n{+}1)^2$，答案矩阵 $n^2$（后者为返回值必需）；采用 §4 的就地还原写法可省去答案矩阵，额外空间降到 $O(1)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<vector<int>> rangeAddQueries(int n, vector<vector<int>>& queries) {
        // (n+1)x(n+1) 差分数组：多出的一行一列存放 r2+1 / c2+1 的边界标记
        vector<vector<int>> d(n + 1, vector<int>(n + 1, 0));
        for (auto& q : queries) {
            int r1 = q[0], c1 = q[1], r2 = q[2], c2 = q[3];
            d[r1][c1]         += 1;
            d[r2 + 1][c1]     -= 1;
            d[r1][c2 + 1]     -= 1;
            d[r2 + 1][c2 + 1] += 1;
        }
        // 二维前缀和还原，直接写入 n x n 答案矩阵（越界项按 0）
        vector<vector<int>> mat(n, vector<int>(n, 0));
        for (int i = 0; i < n; i++)
            for (int j = 0; j < n; j++) {
                mat[i][j] = d[i][j];
                if (i > 0) mat[i][j] += mat[i - 1][j];
                if (j > 0) mat[i][j] += mat[i][j - 1];
                if (i > 0 && j > 0) mat[i][j] -= mat[i - 1][j - 1];
            }
        return mat;
    }
};
```

就地还原写法（两趟一维前缀和，省去答案矩阵）：

```cpp
class Solution {
public:
    vector<vector<int>> rangeAddQueries(int n, vector<vector<int>>& queries) {
        vector<vector<int>> d(n + 1, vector<int>(n + 1, 0));
        for (auto& q : queries) {
            int r1 = q[0], c1 = q[1], r2 = q[2], c2 = q[3];
            d[r1][c1] += 1;         d[r2 + 1][c1] -= 1;
            d[r1][c2 + 1] -= 1;     d[r2 + 1][c2 + 1] += 1;
        }
        for (int i = 0; i <= n; i++)       // 按行做一维前缀和
            for (int j = 1; j <= n; j++)
                d[i][j] += d[i][j - 1];
        for (int j = 0; j <= n; j++)       // 再按列做一维前缀和
            for (int i = 1; i <= n; i++)
                d[i][j] += d[i - 1][j];
        d.resize(n);                       // 截掉最后一行…
        for (auto& row : d) row.resize(n); // …与最后一列
        return d;
    }
};
```

### Python

```python
class Solution:
    def rangeAddQueries(self, n: int, queries: List[List[int]]) -> List[List[int]]:
        # (n+1)x(n+1) 差分数组：多出的一行一列存放 r2+1 / c2+1 的边界标记
        d = [[0] * (n + 1) for _ in range(n + 1)]
        for r1, c1, r2, c2 in queries:
            d[r1][c1] += 1
            d[r2 + 1][c1] -= 1
            d[r1][c2 + 1] -= 1
            d[r2 + 1][c2 + 1] += 1
        # 二维前缀和还原，直接写入 n x n 答案矩阵（越界项按 0）
        mat = [[0] * n for _ in range(n)]
        for i in range(n):
            for j in range(n):
                mat[i][j] = d[i][j]
                if i > 0:
                    mat[i][j] += mat[i - 1][j]
                if j > 0:
                    mat[i][j] += mat[i][j - 1]
                if i > 0 and j > 0:
                    mat[i][j] -= mat[i - 1][j - 1]
        return mat
```

## 8. 边界情况与易错点

1. **差分数组开小**：只开 $n \times n$ 会在贴边查询（$r_2 = n{-}1$ 或 $c_2 = n{-}1$）写 $d[r_2{+}1]$ 或 $d[\cdot][c_2{+}1]$ 时越界，必须开 $(n{+}1) \times (n{+}1)$。
2. **四角符号记错**：$(r_2{+}1, c_2{+}1)$ 处是 $+1$（两个 $-1$ 的「补偿」项），不是 $-1$。口诀：行标记符号 × 列标记符号 = 该角符号。
3. **前缀和漏减容斥项**：$\text{mat}[i{-}1][j{-}1]$ 被行、列两个方向各加一次，必须减回一次，否则重叠区域被重复计数。
4. **$i=0$ / $j=0$ 边界**：递推中的越界项按 0 跳过，等价于矩阵外圈补零，不要访问负下标。
5. **$1 \times 1$ 矩阵**（$n=1$）：查询必为 `[0,0,0,0]`，四个标记落在 $d$ 的 $(0,0),(1,0),(0,1),(1,1)$，还原后 `mat[0][0] = 1`，无需特判。
6. **查询完全重叠**：如补充用例 2，相同查询重复 $q$ 次，差分标记线性叠加天然正确；每格值可达 $10^4$，`int` 足够。
7. **不要过度设计**：本题修改全部离线、最后一次性取答案，静态差分即可；在线做法（二维树状数组，单次 $O(\log^2 n)$）反而更慢更难写，无需使用。
