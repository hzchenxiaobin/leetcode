# LeetCode 数组元素和与数字和的绝对差 题解

## 1. 题目概述

- **标题 / 题号**：数组元素和与数字和的绝对差（#2535，easy）
- **链接**：https://leetcode.cn/problems/difference-between-element-sum-and-digit-sum-of-an-array/
- **来源**：LeetCode 第 328 场周赛 Q1
- **难度**：简单
- **标签**：数组、数学

**题意**：给定一个**正整数**数组 `nums`，定义两个量：

- **元素和**：把每个 `nums[i]` 当作整体相加；
- **数字和**：把每个 `nums[i]` **拆成十进制各位**（重复数位重复计入）再相加。

返回二者的**绝对差**。

**约束**：

- `1 <= nums.length <= 2000`
- `1 <= nums[i] <= 2000`

## 2. 示例

**示例 1**

```text
输入：nums = [1,15,6,3]
输出：9
解释：元素和 = 1 + 15 + 6 + 3 = 25
      数字和 = 1 + (1+5) + 6 + 3 = 16
      |25 − 16| = 9
```

**示例 2**

```text
输入：nums = [1,2,3,4]
输出：0
解释：元素和 = 10，数字和 = 10，|10 − 10| = 0
```

**补充用例**

```text
输入：nums = [2000]
输出：1998
解释：元素和 = 2000，数字和 = 2 + 0 + 0 + 0 = 2，差 = 1998
```

## 3. 解题思路

### 3.1 朴素模拟

本题是典型的周赛签到题：**没有需要枚举或优化的搜索空间**，整个任务就是一次遍历里的两套累加器——一个把 `nums[i]` 整体加进元素和，一个把 `nums[i]` 逐位拆开加进数字和。所谓"暴力"（比如每个数转字符串、对字符 `'0'..'9'` 求和再累加）与"正解"复杂度同阶，唯一的考点是**拆位循环** `% 10` / `/= 10` 的基本功，以及正确处理两个累加器的先后顺序（见 §8 易错点 3）。

### 3.2 核心观察：正整数恒有「元素和 ≥ 数字和」，且差是 9 的倍数

![两条求和路径：整体相加 vs 拆位相加](images/wc328_q1_two_sums_concept.svg)

设 $x$ 的十进制表示为 $x = \sum_i d_i \cdot 10^i$（$d_0$ 为个位），数字和 $s(x) = \sum_i d_i$，则

$$
x - s(x) = \sum_i d_i \cdot (10^i - 1) = d_1 \cdot 9 + d_2 \cdot 99 + d_3 \cdot 999 + \cdots
$$

个位 $d_0 \cdot (10^0 - 1) = 0$ 不产生差，**每一个高位数位贡献一个 9 的倍数**。由此立刻得到两条性质：

1. **非负性**：$x \ge s(x)$ 对一切非负整数成立，等号当且仅当 $x$ 只有个位（一位数）。求和后元素和 $\ge$ 数字和，`abs` 理论上可以省去——但作为防御性写法保留它零成本。
2. **整除性**：$10^i \equiv 1 \pmod 9$ 推出 $x \equiv s(x) \pmod 9$，故每个 $x - s(x)$ 都是 9 的倍数，**答案必为 9 的倍数**（示例 1 的 9、补充用例的 1998、示例 2 的 0 都验证了这一点）。这是提交后自检的好手段。

### 3.3 算法流程

![算法流程：一趟遍历，双累加器并行推进](images/wc328_q1_algorithm_flow.svg)

1. 初始化 `elementSum = 0`、`digitSum = 0`。
2. 遍历每个 `num ∈ nums`：先把 `num` **整体**累加进 `elementSum`；再用 `while (num > 0)` 逐位剥离：`digitSum += num % 10; num /= 10`。
3. 返回 `abs(elementSum - digitSum)`。

### 3.4 示例演算

![示例演算：[1,15,6,3] 双累加器走查](images/wc328_q1_example_walkthrough.svg)

以 `nums = [1,15,6,3]` 为例：

| num | 拆位 | $s(\text{num})$ | $x - s(x)$ | 累计元素和 | 累计数字和 |
|-----|------|-----------------|------------|-----------|-----------|
| 1   | 1    | 1               | 0          | 1         | 1         |
| 15  | 1,5  | 6               | 9          | 16        | 7         |
| 6   | 6    | 6               | 0          | 22        | 13        |
| 3   | 3    | 3               | 0          | 25        | 16        |

答案 = $|25 - 16| = 9$，其中唯一贡献差的是两位数 $15$（$15 - 6 = 9$）✓。

## 4. 算法细节

1. **双累加器一趟完成**：元素和与数字和互不依赖，可在同一次外层遍历里并行累加；先加整体、后拆位（或对副本拆位）。
2. **拆位的两种写法**：算术版 `while (t > 0) { digitSum += t % 10; t /= 10; }`；字符串版 `for (char c : to_string(x)) digitSum += c - '0';`。二者同为 $O(\log_{10} x)$，前者无额外空间。
3. **数据范围安全**：$n \le 2000$、$nums[i] \le 2000$，元素和 $\le 4 \times 10^6$，数字和 $\le 2000 \times 28 = 56000$（单元素最大数字和为 $1999 \to 28$），全程 32 位 `int` 无溢出风险。
4. **`abs` 的取舍**：由 §5 引理 2 知差恒非负，`return elementSum - digitSum` 同样正确；保留 `abs` 是防御性编程，也使代码在题面约束变动时更稳健。

## 5. 正确性证明

**引理 1**（位值分解）：任意非负整数 $x$ 可写成 $x = \sum_{i=0}^{k-1} d_i \cdot 10^i$，其中 $0 \le d_i \le 9$ 为十进制数位，且其数字和为 $s(x) = \sum_{i=0}^{k-1} d_i$。

**证明**：这正是十进制按位展开的定义，拆位循环按 $d_0 = x \bmod 10$、$d_i$ 由 $x / 10^i$ 逐层取模还原，归纳可得循环恰好按 $d_0, d_1, \dots, d_{k-1}$ 顺序各累加一次。∎

**引理 2**（非负性）：对一切非负整数 $x$，有 $s(x) \le x$，且等号成立当且仅当 $x < 10$。

**证明**：由引理 1，$x - s(x) = \sum_i d_i (10^i - 1)$。每个加数 $d_i \ge 0$ 且 $10^i - 1 \ge 0$，故总和 $\ge 0$。等号成立需要每个 $i \ge 1$ 的加数为零，即 $d_i = 0\ (\forall i \ge 1)$，亦即 $x = d_0 < 10$。∎

**引理 3**（整除性）：对一切非负整数 $x$，$9 \mid x - s(x)$。

**证明**：$10 \equiv 1 \pmod 9 \Rightarrow 10^i \equiv 1 \pmod 9 \Rightarrow d_i(10^i - 1) \equiv 0 \pmod 9$，对 $i$ 求和即得。∎

**定理**：算法返回 $\left|\sum_i \text{nums}[i] - \sum_i s(\text{nums}[i])\right|$，且该值等于 $\sum_i \left(\text{nums}[i] - s(\text{nums}[i])\right) \ge 0$，必为 9 的倍数。

**证明**：算法按引理 1 的位值分解对每个元素累加 $s(x)$ 得到数字和，整体累加得到元素和，二者之差逐项改写为 $x - s(x)$ 后由引理 2 非负、由引理 3 为 9 的倍数。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n \log_{10} U)$，其中 $U = \max(\text{nums})$。每个元素的拆位循环至多 $\lfloor \log_{10} 2000 \rfloor + 1 = 4$ 次，总操作数约 $4n \le 8000$，远低于任何时限。
- **空间复杂度**：$O(1)$。仅两个累加器；若采用字符串拆位写法则为 $O(\log_{10} U)$ 的临时字符串。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int differenceOfSum(vector<int>& nums) {
        int elementSum = 0, digitSum = 0;
        for (int num : nums) {
            elementSum += num;          // 先整体累加
            while (num > 0) {           // 再拆位（num 被破坏也无妨）
                digitSum += num % 10;
                num /= 10;
            }
        }
        return abs(elementSum - digitSum);
    }
};
```

字符串拆位写法（等价）：

```cpp
class Solution {
public:
    int differenceOfSum(vector<int>& nums) {
        int elementSum = accumulate(nums.begin(), nums.end(), 0);
        int digitSum = 0;
        for (int x : nums)
            for (char c : to_string(x))
                digitSum += c - '0';
        return abs(elementSum - digitSum);
    }
};
```

### Python

```python
class Solution:
    def differenceOfSum(self, nums: List[int]) -> int:
        element_sum = digit_sum = 0
        for num in nums:
            element_sum += num
            while num:
                digit_sum += num % 10
                num //= 10
        return abs(element_sum - digit_sum)
```

一行流（依赖 `sum` 与生成器）：

```python
class Solution:
    def differenceOfSum(self, nums: List[int]) -> int:
        return abs(sum(nums) - sum(int(c) for x in nums for c in str(x)))
```

## 8. 边界情况与易错点

1. **全一位数**：如 `[1,2,3,4]`，每个 $x - s(x) = 0$，答案为 0，无需特判。
2. **重复数位要重复计入**：`[11,11]` 的数字和是 $1+1+1+1=4$（不是 2），答案 $22-4=18$。**不要**做去重或按集合统计。
3. **拆位破坏循环变量**：`while (num > 0)` 会把 `num` 改成 0，必须**先**把原值累加进元素和（或对副本 `t = num` 拆位）。顺序写反是本题最典型的实现错误。
4. **不要排序 / 不要换序**：加法交换律保证两个和与顺序无关，任何排序都是无意义的额外 $O(n \log n)$。
5. **溢出评估**：本约束下最大元素和 $4 \times 10^6$，`int` 富余；若题面放宽到 $n, \text{nums}[i] \le 10^5$ 量级（元素和 $10^{10}$），C++ 才需要 `long long`。
6. **自检技巧**：由引理 3，答案必须是 9 的倍数（含 0）。若本地跑出 `2011` 这类值，说明拆位或累加写错了。

**延伸思考**：把答案 $\sum_i (x_i - s(x_i))$ 换个视角看——若把所有数字按数位对齐、**不进位**地逐列相加，得到的正是数字和；而标准竖式加法中**每发生一次进位，各数位总和恰好损失 9**（一列减 10、下一列加 1）。因此本题答案恰等于 $9 \times$（把 `nums` 全部加起来时的总进位次数）。进一步地，若允许 `nums[i] = 0`，全部性质不变；若允许负数，非负性（引理 2）失效，`abs` 从防御性写法变为必需。
