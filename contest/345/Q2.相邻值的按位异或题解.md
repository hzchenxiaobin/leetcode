# LeetCode 相邻值的按位异或 题解

## 1. 题目概述

- **标题 / 题号**：相邻值的按位异或（#2683，medium）
- **链接**：https://leetcode.cn/problems/neighboring-bitwise-xor/
- **来源**：LeetCode 第 345 场周赛 Q2
- **难度**：中等
- **标签**：位运算、数组

**题意**：长度为 `n` 的 0/1 数组 `derived` 由某个同样长度的 0/1 **原始数组** `original` 派生：对 `0 <= i < n-1` 有 $derived[i] = original[i] \oplus original[i+1]$，最后一项**环回** $derived[n-1] = original[n-1] \oplus original[0]$。给定 `derived`，判断是否存在能派生出它的合法 `original`；存在返回 `true`，否则返回 `false`。

**约束**：

- `1 <= n <= 10^5`
- `derived[i] ∈ {0, 1}`

## 2. 示例

**示例 1**

```text
输入：derived = [1, 1, 0]
输出：true
解释：original = [0, 1, 0] 满足：
  derived[0] = original[0] ⊕ original[1] = 0 ⊕ 1 = 1
  derived[1] = original[1] ⊕ original[2] = 1 ⊕ 0 = 1
  derived[2] = original[2] ⊕ original[0] = 0 ⊕ 0 = 0
```

**示例 2**

```text
输入：derived = [1, 1]
输出：true
解释：original = [0, 1]，两条方程分别要求
  original[0] ⊕ original[1] = 1 与 original[1] ⊕ original[0] = 1，均成立。
```

**示例 3**

```text
输入：derived = [1, 0]
输出：false
解释：n = 2 时两条方程都等于 original[0] ⊕ original[1]，
  不可能一个等于 1、另一个等于 0。
```

**补充（n = 1）**

```text
输入：derived = [0] → 输出：true   （original = [0] 或 [1] 均可）
输入：derived = [1] → 输出：false  （o0 ⊕ o0 恒为 0）
```

## 3. 解题思路

### 3.1 暴力思路

最直接的做法是枚举 `original` 的全部 $2^n$ 种取值，逐一验证能否派生出 `derived`，复杂度 $O(n \cdot 2^n)$，在 $n \le 10^5$ 下完全不可行。

另一个直觉是"逐个方程迁就"：方程只涉及两个未知量，固定 `original[i]` 后总可以令 $original[i+1] = original[i] \oplus derived[i]$ 让它满足。**问题在于环**：递推 $n-1$ 步之后，还剩一条环回方程 $original[n-1] \oplus original[0] = derived[n-1]$，它已经没有"下一个元素"可调，矛盾恰恰在这里暴露（示例 3 正是如此）。所以必须把整条链当作整体分析。

### 3.2 核心观察：全体异或为零 ⟺ 存在合法 original

以下简记 $o_i = original[i]$、$d_i = derived[i]$。

![derived 是环上边的异或标签](images/wc345_q2_derived_cycle_concept.svg)

把 `original` 看成环上的**节点**，$d_i$ 是相邻两节点连线上的"异或标签"，那么**每个 $o_j$ 恰好是两条边的端点、参与两个方程**。

于是把 $n$ 个方程两边**全部异或**起来：右边每个 $o_j$ 恰好出现两次，由 $x \oplus x = 0$ 两两抵消，总和必为 $0$：

$$\bigoplus_{i=0}^{n-1} d_i \;=\; \bigoplus_{i=0}^{n-1} \big(o_i \oplus o_{(i+1) \bmod n}\big) \;=\; 0$$

即 **`derived` 全体异或为 0 是存在合法 `original` 的必要条件**。

![全体异或成对抵消](images/wc345_q2_xor_cancel.svg)

这个条件同时是**充分的**：令 $o_0 = 0$，按 $o_{i+1} = o_i \oplus d_i$ 链式递推，前 $n-1$ 个方程自动满足；把环回方程整理一下，它恰好等价于"全体异或为 0"。因此：

$$\exists\, original \iff \bigoplus_{i=0}^{n-1} derived[i] = 0$$

> 💡 **位运算直觉**：对 0/1 值而言，全体异或 = **1 的个数的奇偶性**。判据等价于"`derived` 中 1 有偶数个"。示例 1 中 1 有两个 → true；示例 3 中 1 只有一个 → false。

### 3.3 算法流程

**判据版（推荐）**：

1. 累加变量 `x = 0`
2. 遍历数组，`x ^= derived[i]`
3. 返回 `x == 0`

**重建验证版（帮助理解，同样 O(n)）**：

1. 固定 `original[0] = 0`（不失一般性，见 4.3）
2. 对 $i = 0, \dots, n-2$：$original[i+1] = original[i] \oplus derived[i]$
3. 检查环回方程：$original[n-1] \oplus original[0] = derived[n-1]$ 是否成立

### 3.4 示例演算

![链式重建演算](images/wc345_q2_walkthrough.svg)

**derived = [1, 1, 0]（成功）**

| 步骤 | 用到的方程 | 递推 | 当前 original |
|------|-----------|------|--------------|
| 初始化 | — | $o_0 = 0$（自由设定） | $[0]$ |
| $i=0$ | $d_0 = o_0 \oplus o_1 = 1$ | $o_1 = 0 \oplus 1$ | $[0, 1]$ |
| $i=1$ | $d_1 = o_1 \oplus o_2 = 1$ | $o_2 = 1 \oplus 1$ | $[0, 1, 0]$ |
| 环回检查 | $d_2 = o_2 \oplus o_0 = 0$ | $0 \oplus 0 = 0$ ✓ | 合法 |

全体异或 $1 \oplus 1 \oplus 0 = 0$，与"环回检查通过"一致。

**derived = [1, 0]（失败）**

| 步骤 | 递推 | 结果 |
|------|------|------|
| 初始化 | $o_0 = 0$ | $[0]$ |
| $i=0$ | $o_1 = 0 \oplus 1$ | $[0, 1]$ |
| 环回检查 | 需要 $o_1 \oplus o_0 = 0$，实际 $1 \oplus 0 = 1 \ne d_1$ | ✗ 无解 |

此时全体异或 $1 \oplus 0 = 1 \ne 0$，两条途径结论一致。

## 4. 算法细节

1. **GF(2) 线性方程组视角**：本题是 $n$ 个方程、$n$ 个未知量、每个方程恰含两个未知量的线性系统。系数矩阵每列恰有两个 1，全部行相加为零向量，故可解当且仅当右端满足同一个线性约束——全体异或为 0；可解时解空间恰 1 维，**合法 `original` 恰有两个，互为按位取反**。
2. **值域自动保持**：递推 $o_{i+1} = o_i \oplus d_i$ 中 0/1 异或 0/1 仍是 0/1，无需额外校验值域。
3. **固定 $o_0 = 0$ 不失一般性**：异或对整体取反不变（$\lnot x \oplus \lnot y = x \oplus y$），若某个 `original` 合法，其按位取反也合法。$o_0$ 的两种取值只产生这对互补解，合法性与选择无关。
4. **实现**：单个累加变量异或即可，无需真正构造 `original`。

## 5. 正确性证明

以下约定下标按 $\bmod\ n$ 理解，$\bigoplus$ 表示全体异或。

**引理 1（必要性）**：若存在合法 `original`，则 $\bigoplus_{i=0}^{n-1} d_i = 0$。

**证明**：由合法性，每个 $d_i = o_i \oplus o_{(i+1) \bmod n}$。于是

$$\bigoplus_{i=0}^{n-1} d_i = \bigoplus_{i=0}^{n-1} \big( o_i \oplus o_{(i+1) \bmod n} \big)$$

异或满足交换律与结合律，右边可以任意重排。每个 $o_j$ 恰出现两次：在 $d_j$ 中作为左元、在 $d_{(j-1) \bmod n}$ 中作为右元（$o_0$ 的第二次出现正是环回边 $d_{n-1}$ 提供的）。由 $x \oplus x = 0$ 两项相消，总和为 $0$。∎

**引理 2（链式递推的显式解）**：设 $c \in \{0,1\}$，令 $o_0 = c$、$o_{i+1} = o_i \oplus d_i$（$0 \le i \le n-2$），则对一切 $0 \le k \le n-1$ 有 $o_k = c \oplus \bigoplus_{i=0}^{k-1} d_i$，且前 $n-1$ 个方程全部成立。

**证明**：对 $k$ 归纳。$k=0$ 即定义。若结论对 $k$ 成立，则

$$o_{k+1} = o_k \oplus d_k = c \oplus \Big(\bigoplus_{i=0}^{k-1} d_i\Big) \oplus d_k = c \oplus \bigoplus_{i=0}^{k} d_i$$

即结论对 $k+1$ 成立。又每个方程 $d_k = o_k \oplus o_{k+1}$ 就是递推式本身，故前 $n-1$ 个方程成立。∎

**定理**：存在合法 `original` $\iff$ $\bigoplus_{i=0}^{n-1} derived[i] = 0$。

**证明**：必要性即引理 1。反之设全体异或为 0，取 $c = 0$ 按引理 2 构造，前 $n-1$ 个方程成立。对环回方程，需证 $o_{n-1} \oplus o_0 = d_{n-1}$。由引理 2：

$$o_{n-1} \oplus o_0 = \Big(\bigoplus_{i=0}^{n-2} d_i\Big) \oplus 0 = \bigoplus_{i=0}^{n-2} d_i$$

对条件 $\bigoplus_{i=0}^{n-1} d_i = 0$ 两边异或 $d_{n-1}$ 得 $\bigoplus_{i=0}^{n-2} d_i = d_{n-1}$，故环回方程成立，构造合法。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。单次遍历求全体异或，每步一次异或运算。
- **空间复杂度**：$O(1)$。仅需一个累加变量（重建验证版需 $O(n)$ 存 `original`，流式检查则仍为 $O(1)$）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool doesValidArrayExist(vector<int>& derived) {
        int x = 0;
        for (int v : derived) x ^= v;   // 全体异或
        return x == 0;
    }
};
```

### Python

```python
class Solution:
    def doesValidArrayExist(self, derived: List[int]) -> bool:
        x = 0
        for v in derived:               # 全体异或
            x ^= v
        return x == 0
```

## 8. 边界情况与易错点

1. **n = 1**：唯一方程就是环回 $o_0 \oplus o_0 = d_0$，恒等于 0。故 `derived = [0]` → true（`original = [0]` 或 `[1]` 均可），`derived = [1]` → false。异或判据自动覆盖。
2. **n = 2**：两条方程都是 $o_0 \oplus o_1$，故必须 `derived[0] == derived[1]` 才有解；判据 $d_0 \oplus d_1 = 0$ 与之等价。
3. **环回方向**：末方程是 $o_{n-1} \oplus o_0$，不是 $o_{n-1} \oplus o_n$（越界）；重建版实现时这里最容易写错。
4. **局部满足 ≠ 全局满足**：每个方程单独看总能"迁就"出下一项，矛盾只在环回处暴露；只检查前 $n-1$ 个方程会把所有输入误判为 true。
5. **别过度构造**：无需真正建出 `original`，更不要 $2^n$ 枚举或上通用高斯消元（$O(n^3)$ 同样过不了）；一条异或遍历足矣。
6. **奇偶心算**：判据等价于"`derived` 中 1 的个数为偶数"，可用于快速自检。
7. **无溢出风险**：全程只有异或与比较，无累加和溢出问题。
