# LeetCode 找出转圈游戏输家 题解

## 1. 题目概述

- **标题 / 题号**：找出转圈游戏输家（#2682，easy）
- **链接**：https://leetcode.cn/problems/find-the-losers-of-the-circular-game/
- **来源**：LeetCode 第 345 场周赛 Q1
- **难度**：简单
- **标签**：数组、哈希表、模拟

**题意**：`n` 个朋友围坐一圈，按顺时针方向从 `1` 到 `n` 编号。`1` 号起手接球；接下来第 `i` 轮中，持球者把球顺时针传 `i × k` 步。当某个朋友**第 2 次**接到球时游戏立即结束。求所有**从未接到过球**的朋友编号，按升序返回。

**约束**：

- `1 <= k <= n <= 50`
- 数据范围极小，模拟即可，无需担心溢出与效率

## 2. 示例

**示例 1**

```text
输入：n = 5, k = 2
输出：[4, 5]
解释：接球顺序为 1 → 3 → 2 → 3，3 号第 2 次接球，游戏结束。
4、5 号从未接球，是输家。
```

**示例 2**

```text
输入：n = 4, k = 4
输出：[2, 3, 4]
解释：第 1 轮 1 号顺时针传 4 步回到自己（4 % 4 == 0），
1 号第 2 次接球，游戏立即结束，其余人全是输家。
```

**示例 3**

```text
输入：n = 2, k = 1
输出：[]
解释：接球顺序为 1 → 2 → 2（2 号传 2 步绕回自己），
所有人都接过球，没有输家。
```

## 3. 解题思路

### 3.1 暴力思路

签到题，"暴力"即正解：开一个布尔数组记录每个朋友是否接过球，从 `1` 号开始按轮次模拟传球，遇到已接球的人就停，最后扫一遍收集没接球的人。关键只有两处：环上走 `x` 步的**取模公式**，以及游戏**必然终止**的保证。

### 3.2 核心观察：取模跳转 + 接球标记

![转圈游戏示意](images/circular_game_losers_concept.svg)

- **环上定位**：朋友编号是 1-based，顺时针走 `x` 步等价于编号加 `x` 再模 `n`。为避免 `%` 结果为 `0` 的错位，先减 1 转 0-based、取模后加 1 还原：

$$next = \big((cur - 1 + i \times k) \bmod n\big) + 1$$

- **必然终止**：每轮落点都是 `n` 个位置之一。连同起手的 `1` 号，`n + 1` 次"接球事件"由抽屉原理必有重复，因此**至多传 `n` 轮**就有人第 2 次接球，循环 `O(n)` 次必停。
- **无需哈希表**：编号就是 `1..n`，布尔数组即可，比哈希集合更快更省。

### 3.3 算法流程

![算法流程](images/circular_game_losers_flow.svg)

1. 初始化 `received[1] = true`（起手也算接球），`cur = 1`，轮次 `i = 1`。
2. 计算 `next = (cur - 1 + i * k) % n + 1`。
3. 若 `received[next]` 为真 → 第 2 次接球，跳出循环。
4. 否则标记 `received[next] = true`，`cur = next`，`i += 1`，回到第 2 步。
5. 按 `1..n` 顺序扫描，收集所有 `received[x] == false` 的 `x`，天然升序，返回。

### 3.4 示例演算

![示例演算](images/circular_game_losers_walkthrough.svg)

以 `n = 5, k = 2` 走查：

| 轮次 i | 持球者 | 传球距离 | 落点 next | received 集合 |
|--------|--------|----------|-----------|---------------|
| 起手 | 1 号 | — | — | {1} |
| 1 | 1 号 | 1×2 = 2 步 | 3 号 | {1, 3} |
| 2 | 3 号 | 2×2 = 4 步 | 2 号 | {1, 2, 3} |
| 3 | 2 号 | 3×2 = 6 步 | 3 号（重复 ✗） | 游戏结束 |

从未接球的朋友为 `{4, 5}`，答案 `[4, 5]` ✓

> 💡 **附加观察**：第 `i` 轮落点可写成闭式 $\big(k \cdot \tfrac{i(i+1)}{2} \bmod n\big) + 1$（前 `i` 轮共走 `k·(1+2+…+i)` 步），即落点由**三角形数模 n** 决定。本题 `n ≤ 50` 直接模拟更稳，该闭式用于分析落点循环节。

## 4. 算法细节

1. **1-based 取模**：先 `cur - 1` 转 0-based，加偏移取模后 `+1` 还原，避免 `(cur + i*k) % n` 出现 `0` 号的错位 bug。
2. **起手即接球**：`1` 号开局持球算一次接球，必须初始化标记，否则 `1` 可能被误判为输家。
3. **先查后标**：每轮先判断 `received[next]` 是否为真再决定标记或退出；顺序写反会把"第 2 次接球的人"错误标记后继续循环。
4. **终止条件写在循环内**：由抽屉原理循环至多 `n` 次，`while (true)` 不会死循环；也可写成 `for i in 1..n`。
5. **升序收集**：最后按 `x = 1..n` 扫描布尔数组，输出顺序天然升序，无需排序。
6. **数据范围**：`i, k ≤ 50`，`i * k ≤ 2500`，`int` 足够，无溢出风险。

## 5. 正确性证明

**引理 1（落点公式）**：第 `i` 轮传球后，落点为 $\big((cur - 1 + i \cdot k) \bmod n\big) + 1$。

**证明**：环上从编号 `p` 顺时针走 1 步到 `p + 1`（`p < n`），从 `n` 走 1 步回到 `1`，即在 0-based 表示下走 1 步等价于加 1 模 `n`。由归纳法，走 `x` 步等价于 `(p - 1 + x) mod n + 1`。取 `x = i·k` 即得。∎

**引理 2（有限步终止）**：循环至多执行 `n` 轮，必在某轮检测到 `received[next] == true` 而退出。

**证明**：反设前 `n` 轮均未检测到重复。连同起手事件，共产生 `n + 1` 次接球事件，而落点只有 `n` 个可能位置，由抽屉原理存在两次事件落在同一朋友上。考察其中最早的一对重复：后一次事件发生时，该朋友已被标记，算法应在该轮退出，与"前 `n` 轮均未检测到重复"矛盾。∎

**定理**：算法输出恰为所有从未接球的朋友，且严格升序。

**证明**：由引理 1，每轮落点计算与游戏规则一致；算法逐轮标记接球者，标记集合始终等于"截止当前接过球的朋友集合"。由引理 2，循环恰在第 2 次接球发生的那一轮退出，此时标记集合与游戏结束时的接球集合相同。最后按 `1..n` 扫描输出未标记者，恰为从未接球的朋友，且扫描顺序保证升序。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。由引理 2，模拟循环至多 `n` 轮，每轮 `O(1)`；收集答案扫描 `O(n)`。本题 `n ≤ 50`，几乎零开销。
- **空间复杂度**：$O(n)$。布尔数组 `received`（不计返回值）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> circularGameLosers(int n, int k) {
        vector<bool> received(n + 1, false);
        received[1] = true;   // 起手也算接球
        int cur = 1;
        for (int i = 1;; ++i) {
            int next = (cur - 1 + i * k) % n + 1;   // 1-based 取模
            if (received[next]) break;              // 第 2 次接球，结束
            received[next] = true;
            cur = next;
        }
        vector<int> ans;
        for (int x = 1; x <= n; ++x)
            if (!received[x]) ans.push_back(x);     // 升序收集
        return ans;
    }
};
```

### Python

```python
class Solution:
    def circularGameLosers(self, n: int, k: int) -> List[int]:
        received = [False] * (n + 1)
        received[1] = True          # 起手也算接球
        cur, i = 1, 1
        while True:
            nxt = (cur - 1 + i * k) % n + 1   # 1-based 取模
            if received[nxt]:                 # 第 2 次接球，结束
                break
            received[nxt] = True
            cur = nxt
            i += 1
        return [x for x in range(1, n + 1) if not received[x]]
```

## 8. 边界情况与易错点

1. **k = n（传回自己）**：第 1 轮 `i·k % n == 0`，落点仍是 `1` 号，游戏立即结束，输家为 `2..n`（示例 2）。
2. **无输家**：如 `n = 2, k = 1`，接球顺序 `1 → 2 → 2`，所有朋友都接过球，答案为空数组 `[]`，不要误返回 `[1]`。
3. **起手漏标记**：`1` 号开局持球就是一次接球，漏标会把 `1` 错判成输家。
4. **取模错位**：直接 `(cur + i*k) % n` 会得到 0-based 结果，`0` 与 `n` 混淆；必须先减 1 再加 1。
5. **先标后查**：若先 `received[next] = true` 再判重，任何人都会"立即重复"，逻辑完全错误；必须先查再标。
6. **升序要求**：题目要求按升序返回，按 `1..n` 扫描天然有序；若用无序结构收集需最后排序。
7. **死循环担忧**：`while True` 看似危险，但由抽屉原理至多 `n` 轮必停，可放心使用。
