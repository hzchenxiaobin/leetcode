# LeetCode 统计完全连通分量的数量 题解

## 1. 题目概述

- **标题 / 题号**：统计完全连通分量的数量（#2685，medium）
- **链接**：https://leetcode.cn/problems/count-the-number-of-complete-components/
- **来源**：LeetCode 第 345 场周赛 Q4
- **难度**：中等
- **标签**：图、并查集、深度优先搜索、广度优先搜索

**题意**：给定 $n$ 个顶点（编号 $0 \sim n-1$）的无向图与边列表 `edges`，`edges[i] = [ai, bi]` 表示 $a_i$、$b_i$ 间有一条无向边。**连通分量**指子图内任意两点都有路径相通、且没有任何顶点与子图外部共享边；若连通分量中**每对节点之间都直接存在一条边**，则称**完全连通分量**。返回图中完全连通分量的数量。

**约束**：

- $1 \le n \le 50$
- $0 \le \text{edges.length} \le \dfrac{n(n-1)}{2}$
- $0 \le a_i, b_i \le n-1$ 且 $a_i \ne b_i$
- 不存在重复边（简单无向图：无自环、无重边）

> 💡 **关键信号**：判定"每对顶点都有边"不必逐对验证——在**无重边**的前提下，分量内的边与"顶点对"一一对应，只需数一数**边数是否取满** $\binom{k}{2}$。这是一道披着图论外衣的"数数"题，也是本场最友好的 Q4。

## 2. 示例

**示例 1**

```text
输入：n = 6, edges = [[0,1],[0,2],[1,2],[3,4]]
输出：3
解释：{0,1,2} 是三角形（e=3=3×2/2）；{3,4} 单边（e=1=2×1/2）；
      {5} 孤立点（e=0=1×0/2）。三者都完全，答案 3。
```

**示例 2**

```text
输入：n = 6, edges = [[0,1],[0,2],[1,2],[3,4],[3,5]]
输出：1
解释：{0,1,2} 完全；{3,4,5} 虽连通但缺 4–5 这条边（e=2 < 3×2/2），
      不完全。答案 1。
```

**补充示例（孤立点 + 两点分量）**

```text
输入：n = 3, edges = [[0,1]]
输出：2
解释：{0,1} 连通必完全——两点间的路径只能是那条边，e=1=2×1/2；
      {2} 是孤立点，没有任何点对需要满足，也是完全分量。答案 2。
```

## 3. 解题思路

### 3.1 暴力思路：收集分量，逐对查边

按定义直译：先用 DFS/BFS 把每个连通分量的顶点收集到列表 `comp`，再对 `comp` 中**每一对**顶点查邻接矩阵/邻接集，确认两两有边。单个分量为 $O(k^2)$ 次邻接查询，全体分量最坏 $O(n^2 + m)$。

$n \le 50$ 时这已经能过，但它把"判定"做成了**逐对验证**：既没利用"简单图边数有上界"的结构，也难以推广——$n$ 升到 $10^5$ 时 $O(n^2)$ 直接超时，而且代码里嵌着双重循环加短路标志，赛场上又慢又容易写错。

### 3.2 核心观察：完全 ⟺ 边数取满 $\binom{k}{2}$

![完全分量的边数刻画](images/wc345_q4_complete_check_concept.svg)

设某连通分量的顶点集为 $S$，$|S| = k$，其内部边数为 $e(S)$：

1. **分量的边是封闭的**：由定义，分量内的顶点不与外部共享边，所以图中"两端都落在 $S$ 内"的边恰好都属于这个分量，一个不多一个不少；
2. **简单图的上界**：无自环保证每条边对应一个无序点对 $\{u,v\}$（$u \ne v$），无重边保证不同边对应**不同**点对；而 $k$ 个点总共只有 $\binom{k}{2} = \frac{k(k-1)}{2}$ 个点对，故 $e(S) \le \binom{k}{2}$；
3. **取满即完全**：若 $e(S) = \binom{k}{2}$，这 $\binom{k}{2}$ 条边占据 $\binom{k}{2}$ 个互不相同的点对，而点对一共就这么多个——**每个点对都被占据**，即每对顶点间都有边。

于是判定收缩为一个等式：

$$\text{分量完全} \iff e(S) = \frac{k(k-1)}{2}$$

> 💡 换个视角：判定从「$\binom{k}{2}$ 次邻接查询」坍缩成「**数点数、数边数、比一个公式**」——"每对都有"这类**全覆盖型存在性**条件，往往都能用计数刻画，这是周赛值得沉淀的通用套路。

### 3.3 算法流程：并查集按根统计

![并查集按根统计流程](images/wc345_q4_dsu_edge_count_flow.svg)

用**并查集**把每个顶点归入其所在分量，一切统计按"根"聚合：

1. 初始化 `parent[i] = i`；
2. 遍历每条边 `[a, b]`：`union(a, b)`；
3. 遍历每个顶点 `i`：`vcnt[find(i)] += 1`（按根统计点数 $k$）；
4. 遍历每条边 `[a, b]`：`ecnt[find(a)] += 1`（按根统计边数 $e$，**每条边只计一次**）；
5. 对每个根 $r$：若 $ecnt[r] = \binom{vcnt[r]}{2}$，则 `ans++`。

### 3.4 示例演算

![示例 2 的按根统计演算](images/wc345_q4_walkthrough.svg)

以示例 2（$n=6$，`edges=[[0,1],[0,2],[1,2],[3,4],[3,5]]`）走一遍：

| 分量（根） | 点数 $k$ | 边数 $e$ | $\binom{k}{2}$ | 判定 |
|-----------|---------|---------|----------------|------|
| $\{0,1,2\}$（根 0） | 3 | 3 | 3 | $3 = 3$ ✓ 完全 |
| $\{3,4,5\}$（根 3） | 3 | 2 | 3 | $2 \ne 3$ ✗ 不完全 |

边 $[0,1],[0,2],[1,2]$ 归入根 0（$ecnt[0]=3$），边 $[3,4],[3,5]$ 归入根 3（$ecnt[3]=2$）；判定后仅根 0 通过，答案 $1$。示例 1 再补一个孤立点 $\{5\}$：$k=1$，$e=0=\binom{1}{2}$，空真成立判完全，答案 $3$。

## 4. 算法细节

1. **并查集的等价类 = 连通分量**：`union` 只会合并"有边相连"的两类，`find` 不改变分类；全部合并后 `find(x)` 相同 $\iff x, y$ 连通，每个根恰对应一个分量。`find` 用迭代 + 路径减半，避免深递归。
2. **每条边只归账一次**：`ecnt[find(a)]++`——边 $[a,b]$ 两端必同根，`find(a)` 与 `find(b)` 相同，加一次即可。**别对 $a$、$b$ 各加一次**（边数翻倍，把不安全误判成完全）；也别用邻接表逐邻接点统计（无向边存两条弧，会数两次，除非最后除 2）。直接扫原始 `edges` 最不易错。
3. **先合并、后统计**：统计依赖每个点/每条边的**最终归属根**。若边 `union` 边统计，后续合并可能让先前记到"旧根"上的计数作废；务必把两轮统计放在所有 `union` 之后。
4. **非根下标要跳过**：判定循环必须带 `vcnt[r] > 0`（或只对 `find(r) == r` 的根判定）。否则空槽位 $vcnt = ecnt = 0$，而 $0 \times (0-1)/2 = 0$，等式 `0 == 0` 成立，会把**根本不是分量的下标**误判成完全分量——本题最常见的 WA。
5. **度数和视角（等价实现）**：完全 $\iff$ 分量内度数和 $= k(k-1)$（即 $2e$）$\iff$ 每点度数 $= k-1$。按根累加 `deg[find(a)]++`、`deg[find(b)]++`，判定 `deg[r] == vcnt[r] * (vcnt[r] - 1)`，与数边是同一件事的两种记账。
6. **数据规模适配**：$n \le 50$、$m \le 1225$，任何 $O(n^2)$ 内的做法都能过；写 $O(n + m\alpha(n))$ 的并查集版是为了把套路沉淀成可推广的模板（$n$ 上界放开时直接可用）。

## 5. 正确性证明

**引理 1（分量的边封闭性）**：设 $S$ 为某连通分量的顶点集，则图中不存在恰有一端落在 $S$ 内的边；从而该分量的边集恰为图中两端都在 $S$ 内的全部边，记其条数为 $e(S)$。

**证明**：由题面定义，连通分量中"没有任何一个顶点与子图外部的顶点共享边"。若存在边 $(u,v)$ 使 $u \in S$、$v \notin S$，则 $u$ 与外部顶点共享边，与 $S$ 是连通分量矛盾。∎

**引理 2（边数刻画完全性）**：在无自环、无重边的前提下，对连通分量顶点集 $S$（$|S| = k$）：(a) $e(S) \le \binom{k}{2}$；(b) 该分量完全 $\iff e(S) = \binom{k}{2}$。

**证明**：(a) 每条边（无自环）确定一个无序点对 $\{u,v\}$；无重边保证不同边确定不同点对；$S$ 内无序点对恰 $\binom{k}{2}$ 个，故 $e(S) \le \binom{k}{2}$。(b)（⟹）分量完全时每个点对都有边，由 (a) 与无重边，每个点对恰对应一条边，故 $e(S) = \binom{k}{2}$。（⟸）$e(S) = \binom{k}{2}$ 条边确定 $\binom{k}{2}$ 个互不相同的点对，而 $S$ 的点对总数恰为 $\binom{k}{2}$，等势集之间的单射必为双射，故每个点对都被某条边占据，即每对顶点之间都有边，分量完全。∎

**定理**：上述算法返回的 `ans` 等于图中完全连通分量的个数。

**证明**：顶点间"存在路径"是等价关系，其等价类即连通分量（孤立点 $\{i\}$ 亦是）。对 `union` 次数归纳：任一时刻 `find(x) = find(y)` $\iff x, y$ 经已合并的边连通，故全部 `union` 完成后每个根 $r$ 恰对应一个分量 $S_r$。顶点遍历使每点恰计入其根一次，$vcnt[r] = |S_r|$；每条边 $[a,b]$ 两端连通，最终同根，恰使对应 `ecnt` 加 1，由引理 1 有 $ecnt[r] = e(S_r)$。判定循环对每个分量恰应用一次引理 2，计入当且仅当该分量完全；孤立点 $k=1$ 时 $e = 0 = \binom{1}{2}$，判定"完全"，与定义一致（不存在需要满足的点对，条件空真）。对全体分量求和即得 `ans`。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n + m\,\alpha(n))$。初始化 $O(n)$；$m$ 次 `union` 与两轮统计共 $O(n + m)$ 次 `find`，路径压缩下均摊 $O(\alpha(n))$；判定一轮 $O(n)$。$n \le 50$、$m \le 1225$ 时毫秒级。
- **空间复杂度**：$O(n)$。`parent`、`vcnt`、`ecnt` 三个长度为 $n$ 的数组；无需建邻接表/邻接矩阵。

## 7. 参考代码

### C++

```cpp
class Solution {
    vector<int> fa;
    int find(int x) {
        while (fa[x] != x) fa[x] = fa[fa[x]], x = fa[x];  // 路径减半
        return x;
    }
public:
    int countCompleteComponents(int n, vector<vector<int>>& edges) {
        fa.resize(n);
        for (int i = 0; i < n; i++) fa[i] = i;
        for (auto& e : edges) fa[find(e[0])] = find(e[1]);  // 全部 union

        vector<int> vcnt(n), ecnt(n);
        for (int i = 0; i < n; i++) vcnt[find(i)]++;        // 每点归入最终根
        for (auto& e : edges) ecnt[find(e[0])]++;           // 每边只计一次

        int ans = 0;
        for (int r = 0; r < n; r++)
            if (vcnt[r] && ecnt[r] == vcnt[r] * (vcnt[r] - 1) / 2)
                ans++;                                      // 完全 ⟺ e = C(k,2)
        return ans;
    }
};
```

### Python

```python
class Solution:
    def countCompleteComponents(self, n: int, edges: List[List[int]]) -> int:
        fa = list(range(n))

        def find(x: int) -> int:
            while fa[x] != x:
                fa[x] = fa[fa[x]]                           # 路径减半
                x = fa[x]
            return x

        for a, b in edges:
            fa[find(a)] = find(b)                           # 全部 union

        vcnt = [0] * n
        ecnt = [0] * n
        for i in range(n):
            vcnt[find(i)] += 1                              # 每点归入最终根
        for a, _ in edges:
            ecnt[find(a)] += 1                              # 每边只计一次

        return sum(
            vcnt[r] > 0 and ecnt[r] == vcnt[r] * (vcnt[r] - 1) // 2
            for r in range(n)
        )
```

## 8. 边界情况与易错点

1. **空槽误判（本题头号 WA）**：非根下标 $vcnt = ecnt = 0$，而 $0 \times (0-1)/2 = 0$，等式 `0 == 0` 成立——判定必须带 `vcnt[r] > 0` 或只对根判定，否则答案凭空多出一串。
2. **孤立点是完全分量**：$k = 1$，$e = 0 = \binom{1}{2}$，自动判完全；漏掉会少计（示例 1 的节点 5）。
3. **两点分量必完全**：$k = 2$ 连通 $\Rightarrow$ 两点间那条边存在 $\Rightarrow e = 1 = 2 \times 1/2$；"不完全"最小也得到 3 个点缺边。
4. **每条边只计一次**：对 $a$、$b$ 各 `++` 会把 $e$ 翻倍，把不安全误判成完全；用邻接表统计则记得除 2。
5. **先 union 完再统计**：统计混入合并过程会记到中途的旧根上，计数分散且无法恢复。
6. **连通 ≠ 完全**：连通只保证 $e \ge k-1$（有生成树），完全要求 $e$ 取满上界；别把"连通分量"当"完全连通分量"数。
7. **极端输入**：$n = 1$、无边 $\Rightarrow$ 答案 1；全图无边 $\Rightarrow$ 答案 $n$。
8. **溢出**：$n \le 50$ 时 $\binom{50}{2} = 1225$，`int` 毫无压力；若推广到 $n \sim 10^5$，C++ 中 $vcnt[r] \cdot (vcnt[r]-1)/2$ 需换 `long long`。
