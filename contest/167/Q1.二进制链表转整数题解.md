# LeetCode 二进制链表转整数 题解

## 1. 题目概述

- **标题 / 题号**：二进制链表转整数（#1290，简单）
- **链接**：https://leetcode.cn/problems/convert-binary-number-in-a-linked-list-to-integer/
- **来源**：LeetCode 第 167 场周赛 Q1
- **难度**：简单
- **标签**：链表、数学、位运算

**题意**：给定一个非空单链表 `head`，每个结点的值只能是 0 或 1。链表从头到尾恰好是一个二进制数的**高位到低位**（最高位在 `head`），返回该二进制数对应的十进制值。

**约束**：

- 链表不为空
- 结点总数不超过 30
- 每个结点的值只能是 0 或 1
- 由结点数上限可知答案最大为 $2^{30}-1 = 1073741823$，32 位有符号 `int` 足够容纳

## 2. 示例

**示例 1**

```text
输入：head = [1,0,1]
输出：5
解释：(101)₂ = 1×4 + 0×2 + 1×1 = (5)₁₀
```

**示例 2**

```text
输入：head = [0]
输出：0
解释：只有一个 0，表示数字 0。
```

**示例 3（补充，非官方）**

```text
输入：head = [1,1,1,1]
输出：15
解释：(1111)₂ = 8 + 4 + 2 + 1 = 15，用于检查「全 1」边界。
```

## 3. 解题思路

### 3.1 暴力思路

两条朴素路径都能 AC，但各有一处浪费：

- **先收集再求和**：第一趟把每个结点的值存进数组或字符串，第二趟按 $\sum_i v_i \cdot 2^{n-1-i}$ 求和。需要 $O(n)$ 额外空间，且要点两遍。
- **先反转再累加**：把链表反转后从低位往高位算（累加 $v \cdot 2^k$），或者递归到尾部再回溯。前者改动链表结构，后者用 $O(n)$ 递归栈。

题目本质是「读一遍、算一遍」，所以应该能做到一次遍历、$O(1)$ 额外空间。

### 3.2 核心观察：霍纳法则（乘 2 加当前位）

![霍纳法则：从最高位开始乘 2 加当前位](images/wc167_q1_horner.svg)

二进制展开式是

$$(v_0 v_1 \cdots v_{n-1})_2 = v_0 2^{n-1} + v_1 2^{n-2} + \cdots + v_{n-1}.$$

直接照这个公式算需要知道 $n$，而单链表求长度必须多走一趟。把上式**从高位到低位逐步合并**：

$$P_0 = 0,\qquad P_{k+1} = 2 P_k + v_k \quad (0 \le k < n).$$

则 $P_n$ 就是所求的十进制值。这正是**霍纳法则**（Horner's rule）：每读一位，先把已有结果整体乘 2（相当于把已读的所有位左移一格），再把新位放到个位。

关键之处在于：**长度信息被「每次乘 2」隐式地累计进去了**，因此完全不需要预先知道 $n$；状态也只有一个整数 $P$，天然满足 $O(1)$ 额外空间。

### 3.3 算法流程 / 位运算写法

![两种等价写法：算术累加与左移加或](images/wc167_q1_bit_ops.svg)

```text
1. ans = 0，p = head
2. 当 p 不为空：
       ans = ans * 2 + p.val        // 位运算写法：ans = (ans << 1) | p.val
       p = p.next
3. 返回 ans
```

位运算版本的直觉：`ans << 1` 把已读的位整体左移、末位补 0；`p.val` 只有 0 或 1，于是 `(ans << 1) | p.val` 恰好把最低位填成这一位的值。因为左移后末位必定是 0，`| v` 与 `+ v` 完全等价，不会产生进位。

### 3.4 示例演算

![示例演算：head 依次为 1、0、1 的三步走查](images/wc167_q1_walkthrough.svg)

对 `head = [1,0,1]`：

| 步骤 | 结点 v | 移位前 ans | ans × 2 + v | 结果 |
|------|--------|------------|-------------|------|
| 1 | 1 | 0 | 0 × 2 + 1 | 1 |
| 2 | 0 | 1 | 1 × 2 + 0 | 2 |
| 3 | 1 | 2 | 2 × 2 + 1 | 5 |

遍历结束 `ans = 5`，验证 $(101)_2 = 4 + 0 + 1 = 5$。

## 4. 算法细节

1. **循环条件直接用结点**：C++ 写 `for (ListNode* p = head; p; p = p->next)`，Python 写 `while p:`。题目保证链表非空，不必额外特判；即使传入空链表，循环不执行、返回 0 也合理。
2. **先乘后加，顺序不能反**：正确顺序是「旧值乘 2，再加新位」。若写成 `ans = ans + v * 2`，新位会比应有的位置高一格、已读位则整体低一格，结果全错。
3. **位运算优先级**：`<<` 的优先级高于 `|`、低于 `+`，所以 `ans << 1 | v` 与 `(ans << 1) | v` 等价；但 `ans << 1 + v` 会被解析成 `ans << (1 + v)`。**多写一对括号**最稳妥。
4. **整型范围**：$n \le 30$ 时答案最大 $2^{30}-1$，`int` 足够；Python 整数无溢出。若把上限放大到 $10^5$ 位，就必须边算边对 $10^9+7$ 取模，且左移版本会溢出、不再适用。
5. **不要用 `pow(2, k)` 逐位加权**：那需要先求长度，而且 `pow` 返回浮点数，$2^{30}$ 附近一旦出现精度误差就会得到 `1073741823.999…` 之类的值，转 `int` 直接错。
6. **不要改动链表结构**：本题不需要反转，`head` 保持不变，只用独立的遍历指针 `p`；这样写既省事，也避免「反转后忘记恢复」的隐患。

## 5. 正确性证明

**引理 1（每步不变式）**：遍历完前 $k$ 个结点后，`ans` 等于这 $k$ 位组成的二进制数的十进制值，即 $\text{ans} = \sum_{i=0}^{k-1} v_i \, 2^{k-1-i}$。

**证明**：对 $k$ 归纳。$k = 0$ 时 `ans` 初值为 0，空串按定义值为 0，成立。设遍历完前 $k$ 个结点后不变式成立，读入第 $k$ 个结点时执行

$$\text{ans}_{\text{new}} = 2 \sum_{i=0}^{k-1} v_i \, 2^{k-1-i} + v_k = \sum_{i=0}^{k} v_i \, 2^{k-i},$$

这正是前 $k+1$ 位组成的二进制数的值，不变式传递。∎

**引理 2（位运算等价）**：对任意非负整数 $a$ 与 $v \in \{0,1\}$，有 $(a \ll 1) \mid v = 2a + v$。

**证明**：$a \ll 1$ 即 $2a$，其二进制最低位为 0。按位或只可能改动最低位：若 $v = 0$，结果仍是 $2a$；若 $v = 1$，把最低位由 0 置为 1，得到 $2a + 1$。两种情形都等于 $2a + v$。∎

**定理**：算法返回的整数等于链表所表示二进制数的十进制值。

**证明**：设链表共 $n$ 个结点，值为 $v_0, \dots, v_{n-1}$。由引理 1 取 $k = n$，循环结束时 `ans` $= \sum_{i=0}^{n-1} v_i 2^{n-1-i}$，即该二进制数的十进制值。若采用左移写法，由引理 2 每一步的结果都与算术写法相同，故返回值一致。∎

## 6. 复杂度分析

- **时间**：$O(n)$，$n$ 为结点数。每个结点恰好访问一次，循环体内只有常数次算术运算或位运算。
- **空间**：$O(1)$。只维护一个整型变量 `ans` 和一个遍历指针 `p`，与 $n$ 无关；这正是相对「先存数组」写法的优势（递归写法会退化为 $O(n)$ 栈空间，故不采用）。

## 7. 参考代码

### C++

```cpp
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
class Solution {
public:
    int getDecimalValue(ListNode* head) {
        int ans = 0;
        for (ListNode* p = head; p != nullptr; p = p->next) {
            ans = (ans << 1) | p->val;   // 等价于 ans = ans * 2 + p->val
        }
        return ans;
    }
};
```

### Python

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def getDecimalValue(self, head: ListNode | None) -> int:
        ans = 0
        p = head
        while p:
            ans = (ans << 1) | p.val   # 等价于 ans = ans * 2 + p.val
            p = p.next
        return ans
```

## 8. 边界情况与易错点

1. **单个结点 `[0]`**：返回 0。`ans` 初值为 0，`(0 << 1) | 0` 仍为 0，不需要为「全零链表」写特判。
2. **前导零 `[0,0,1]`**：累加过程中前导零只是反复做 `0 * 2 + 0`，最终得到 1，答案正确；若改用「先求长度再加权」，长度算错就会整体错位。
3. **全 1 上限 `[1,1,…,1]`（30 个）**：答案为 $2^{30}-1 = 1073741823$，仍小于 $2^{31}-1$，`int` 不会溢出；若题目把上限放到 31 位以上，就必须改用 `long long`。
4. **把 `|` 误写成 `||`**：`||` 是逻辑或，`(ans << 1) || 1` 只会得到布尔值 1，答案全错——这是位运算写法最常见的手误。
5. **忽略运算符优先级**：`ans << 1 + v` 会被解析成 `ans << (1 + v)`；务必写成 `(ans << 1) | v` 或 `ans * 2 + v`。
6. **空链表**：题目保证非空；即便真的传入空链表，循环体不执行并返回 0，是合理且安全的退化行为，无需抛异常。
