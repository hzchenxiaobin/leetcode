# LeetCode 元素和小于等于阈值的正方形的最大边长 题解

## 1. 题目概述

- **标题 / 题号**：元素和小于等于阈值的正方形的最大边长（#1292，medium）
- **链接**：https://leetcode.cn/problems/maximum-side-length-of-a-square-with-sum-less-than-or-equal-to-threshold/
- **来源**：LeetCode 第 167 场周赛 Q3
- **难度**：中等
- **标签**：数组、二分查找、矩阵、前缀和

**题意**：给定 $m \times n$ 的非负整数矩阵 `mat` 和阈值 `threshold`，在所有**边与矩阵边界平行**的正方形子区域中，找出元素和不超过 `threshold` 的**最大边长**；若一个都没有（连单格都超阈值），返回 0。

**约束**：

- $1 \le m, n \le 300$，矩阵总规模约 $9 \times 10^4$ 个格子
- $0 \le mat[i][j] \le 10^4$（**元素非负**，这是全部单调性论证的来源）
- $0 \le threshold \le 10^5$
- 元素总和最大 $300 \times 300 \times 10^4 = 9 \times 10^8 < 2^{31}-1$，`int` 不溢出

## 2. 示例

**示例 1**

```text
输入：mat = [[1,1,3,2,4,3,2],
            [1,1,3,2,4,3,2],
            [1,1,3,2,4,3,2]], threshold = 4
输出：2
解释：左上角 2×2 区域和为 1+1+1+1 = 4 ≤ 4，所以边长 2 可行；
      任意 3×3 区域和最小为 3×(1+1+3) = 15 > 4，所以边长 3 不可行。
```

**示例 2**

```text
输入：mat = [[2,2,2,2,2],
            [2,2,2,2,2],
            [2,2,2,2,2],
            [2,2,2,2,2],
            [2,2,2,2,2]], threshold = 1
输出：0
解释：单个格子就已经等于 2 > 1，连边长 1 的正方形都不存在。
```

**示例 3**（补充：覆盖 0 元素与「阈值取到 0」的边界）

```text
输入：mat = [[0,0,5],
            [0,0,5]], threshold = 0
输出：2
解释：左侧 2×2 区域元素全为 0，和为 0 ≤ 0，所以边长 2 可行，且已达上界 min(m,n)=2。
```

## 3. 解题思路

### 3.1 暴力思路

直接枚举边长 $L$、左上角 $(r,c)$，再花 $O(L^2)$ 求和：总代价
$$O\Big(mn \cdot \sum_{L=1}^{\min(m,n)} L^2\Big) = O\big(mn \cdot \min(m,n)^3\big),$$
在 $300 \times 300$ 时约 $2.4 \times 10^{10}$，必然超时。即使预处理二维前缀和、把求和降到 $O(1)$，逐边长的枚举仍有 $O(mn \cdot \min(m,n)) \approx 2.7 \times 10^7$ 次查询，能过但仍有大量重复计算。

### 3.2 核心观察：元素非负 ⇒ 边长可行性单调 ⇒ 二分

![二维前缀和与边长单调性](images/wc167_q3_prefix_sum_concept.svg)

关键只有两句话：

1. **前缀和**：令 $pre[i][j]$ 表示左上角 $i \times j$ 个元素之和，则由容斥
$$S(r,c,L) = pre[r][c] - pre[r-L][c] - pre[r][c-L] + pre[r-L][c-L]$$
可以 $O(1)$ 求出以 $(r,c)$ 为**右下角**、边长 $L$ 的子方阵和。
2. **单调性**：因为 $mat[i][j] \ge 0$，大正方形包含它左上角的每个小正方形，所以「大正方形可行」蕴含「小正方形也可行」。即
$$L \text{ 可行} \implies \text{任意 } L' < L \text{ 也可行}$$

于是不必对每个 $L$ 都扫一遍矩阵——**可行性在 $L$ 上单调**，可以二分答案：在 $[0, \min(m,n)]$ 上二分 $L$，用一次 $O(mn)$ 的 `check(L)` 判定「是否存在边长 $L$ 的可行正方形」。

> 💡 单调方向要想清楚：是「大可行 ⇒ 小可行」，等价于「小不可行 ⇒ 大不可行」。暴力枚举里那些无效的 $L$ 全被二分砍掉。

### 3.3 算法流程

![算法流程：前缀和 + 二分答案](images/wc167_q3_binary_search_flow.svg)

1. **预处理**：建 $(m+1)\times(n+1)$ 的前缀和 `pre`（第 0 行、第 0 列全 0）。
2. **二分**：$lo = 0,\ hi = \min(m,n),\ ans = 0$；当 $lo \le hi$ 时取 $mid = \lfloor (lo+hi)/2 \rfloor$。
3. **判定** `check(mid)`：枚举所有右下角 $(i,j)$，$i \in [mid, m],\ j \in [mid, n]$，用容斥 $O(1)$ 求和，一旦某个和 $\le threshold$ 立即返回 `true`。
4. **收缩**：`check` 为真则 $ans \leftarrow mid,\ lo \leftarrow mid+1$；否则 $hi \leftarrow mid-1$。
5. **结束**：$lo > hi$ 时返回 $ans$；若始终没有可行边长，$ans$ 保持 0。

### 3.4 示例演算

以示例 1 为例，$m = 3,\ n = 7$，初始 $lo = 0,\ hi = 3$：

![示例演算：三轮二分](images/wc167_q3_walkthrough.svg)

| 轮次 | mid | `check(mid)` 的依据 | 结果 | lo / hi / ans |
|------|-----|----------------------|------|----------------|
| 1 | 1 | 任意单格 $1 \le 4$ | 可行 | 2 / 3 / 1 |
| 2 | 2 | 左上 $2\times2$ 和为 $4 \le 4$ | 可行 | 3 / 3 / 2 |
| 3 | 3 | 最小 $3\times3$ 和为 $15 > 4$ | 不可行 | 3 / 2 / 2 |

三轮后 $lo = 3 > hi = 2$，返回 $ans = 2$，与官方输出一致。注意第 3 轮只需要确认「不存在」，因此扫完所有 $3\times3$ 位置即可，无需记录最小值。

## 4. 算法细节

1. **前缀和递推**：`pre[i][j] = pre[i-1][j] + pre[i][j-1] - pre[i-1][j-1] + mat[i-1][j-1]`。代码里改用「行内滚动和 `s += mat[i][j]`」再写 `pre[i+1][j+1] = pre[i][j+1] + s`，少一次减法和一次数组访问。
2. **坐标一律用 1-indexed 的 `pre`**：$pre[r][c]$ 对应原矩阵 $[0, r) \times [0, c)$。矩阵下标与 `pre` 下标混用是本题最常见的差一错误来源。
3. **二分区间取 $[0, \min(m,n)]$**：$ans$ 初值 0 覆盖「无解」；`check(0)` 恒真（空区域和为 0），所以 $lo$ 从 0 开始不会引入错误，只是多一轮无意义的 $mid=0$，也可以在 `check` 开头直接 `return true`。
4. **`check` 的枚举顺序**：外层 `i` 从 `L` 到 `m`，内层 `j` 从 `L` 到 `n`，共 $(m-L+1)(n-L+1)$ 个位置，正好一一对应全部 $L \times L$ 子方阵。
5. **提前返回**：只要有一个位置满足条件就 `return true`；判定问的是「存在性」，不关心位置，也不需求最大值。
6. **上界是短边**：正方形边长受 $\min(m,n)$ 约束，写成 $m$ 或 $n$ 会在 `i - L < 0` 处越界；同时也让二分轮数为 $O(\log \min(m,n))$。
7. **求和不用 `long long` 也安全**：$9 \times 10^8 < 2^{31}-1$；但若把约束放大（例如格子到 $10^5$）就必须换 `long long`。
8. **前缀和只建一次**：把建表放在二分外面。若每轮 `check` 内部重建，预处理会被重复 $O(\log \min(m,n))$ 次，常数变差、也掩盖了算法结构。

## 5. 正确性证明

**引理 1（前缀和定义一致）**：对 $0 \le i \le m,\ 0 \le j \le n$，$pre[i][j] = \sum_{a<i,\,b<j} mat[a][b]$。

**证明**：对 $i$ 归纳。$i = 0$ 时 $pre[0][j] = 0$，符合空集。设 $pre[i-1][\cdot]$ 均正确，代码中 $s_j = \sum_{b<j} mat[i-1][b]$，则

$$pre[i][j] = pre[i-1][j] + s_j = \sum_{a<i-1,\,b<j} mat[a][b] + \sum_{b<j} mat[i-1][b] = \sum_{a<i,\,b<j} mat[a][b]$$

∎

**引理 2（容斥公式）**：以 $(r,c)$ 为右下角、边长 $L$ 的子方阵（$1 \le L \le \min(r,c)$）元素和等于
$$S = pre[r][c] - pre[r-L][c] - pre[r][c-L] + pre[r-L][c-L].$$

**证明**：由引理 1，$pre[r][c]$ 是矩形 $[0,r)\times[0,c)$ 的和。减去上方矩形 $[0,r-L)\times[0,c)$ 与左方矩形 $[0,r)\times[0,c-L)$ 后，重叠部分 $[0,r-L)\times[0,c-L)$ 被减了两次，故加回一次，恰好剩下 $[r-L,r)\times[c-L,c)$ 的和。∎

**引理 3（单调性）**：若边长 $L$ 可行（存在和 $\le threshold$ 的 $L\times L$ 子方阵），则任意 $0 \le L' < L$ 也可行。

**证明**：设 $Q$ 是边长为 $L$ 的可行子方阵，取其左上角的 $L' \times L'$ 子方阵 $Q'$。$Q' \subseteq Q$，且所有元素非负，故 $S(Q') \le S(Q) \le threshold$，$Q'$ 可行。∎

**引理 4（`check` 精确）**：`check(L)` 返回 `true` 当且仅当存在边长 $L$ 的可行正方形。

**证明**：$(\Leftarrow)$ 若存在这样的正方形，其右下角 $(r,c)$ 满足 $L \le r \le m,\ L \le c \le n$，必然被两层循环枚举到，由引理 2 算出的和 $\le threshold$，于是返回 `true`。$(\Rightarrow)$ 函数只在算出的和 $\le threshold$ 时返回 `true`，而由引理 2 该值就是某个 $L \times L$ 子方阵的和，故这样的正方形确实存在。∎

**引理 5（二分不变量）**：每轮循环开始时，`ans` 是已验证可行的最大边长，且所有 $< lo$ 的边长都可行、所有 $> hi$ 的边长都不可行。

**证明**：初始 $lo = 0,\ hi = \min(m,n),\ ans = 0$，两个区间为空，成立。取 $mid$：若 `check(mid)` 为真，由引理 3 所有 $< mid$ 的边长可行，令 $ans = mid,\ lo = mid+1$；若为假，由引理 3 的逆否命题所有 $> mid$ 的边长不可行，令 $hi = mid-1$。两种情况不变量均保持。∎

**定理**：算法返回的 $ans$ 就是可行边长的最大值（无可行正方形时为 0）。

**证明**：二分结束时 $lo > hi$，由引理 5，所有 $> hi$ 的边长都不可行，而 $ans \le hi$ 且 $ans$ 已验证可行（$ans = 0$ 时对应空答案，语义正确），故 $ans$ 即最大可行边长。∎

## 6. 复杂度分析

- **时间**：前缀和 $O(mn)$；二分至多 $\lceil \log_2(\min(m,n)+1) \rceil$ 轮，每轮 `check` 最多检查 $(m-L+1)(n-L+1) \le mn$ 个位置、每个 $O(1)$，总时间 $O(mn \log \min(m,n))$，约 $9 \times 10^4 \times 9 \approx 8 \times 10^5$ 次查询。
- **空间**：前缀和数组占 $(m+1)\times(n+1)$ 个整数，即 $O(mn)$，其余变量为常数。`check` 要求任意子方阵和 $O(1)$ 可得，这一步的空间无法压到 $O(1)$，故总空间 $O(mn)$。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int maxSideLength(vector<vector<int>>& mat, int threshold) {
        int m = mat.size(), n = mat[0].size();
        // pre[i][j] = mat[0..i-1][0..j-1] 的元素和，第 0 行/列为哨兵
        vector<vector<int>> pre(m + 1, vector<int>(n + 1, 0));
        for (int i = 0; i < m; i++) {
            int s = 0;                       // 当前行前缀和
            for (int j = 0; j < n; j++) {
                s += mat[i][j];
                pre[i + 1][j + 1] = pre[i][j + 1] + s;
            }
        }
        // 是否存在边长 L、元素和 <= threshold 的子方阵
        auto ok = [&](int L) -> bool {
            if (L == 0) return true;
            for (int i = L; i <= m; i++)
                for (int j = L; j <= n; j++)
                    if (pre[i][j] - pre[i][j - L] - pre[i - L][j] + pre[i - L][j - L] <= threshold)
                        return true;
            return false;
        };
        int lo = 0, hi = min(m, n), ans = 0;
        while (lo <= hi) {
            int mid = (lo + hi) / 2;
            if (ok(mid)) { ans = mid; lo = mid + 1; }
            else hi = mid - 1;
        }
        return ans;
    }
};
```

### Python

```python
from typing import List


class Solution:
    def maxSideLength(self, mat: List[List[int]], threshold: int) -> int:
        m, n = len(mat), len(mat[0])
        # pre[i][j] 表示左上角 i×j 个元素之和
        pre = [[0] * (n + 1) for _ in range(m + 1)]
        for i in range(m):
            row, prev, cur = mat[i], pre[i], pre[i + 1]
            s = 0
            for j in range(n):
                s += row[j]
                cur[j + 1] = prev[j + 1] + s

        def ok(L: int) -> bool:
            if L == 0:
                return True
            for i in range(L, m + 1):
                a, b = pre[i], pre[i - L]
                for j in range(L, n + 1):
                    if a[j] - a[j - L] - b[j] + b[j - L] <= threshold:
                        return True
            return False

        lo, hi, ans = 0, min(m, n), 0
        while lo <= hi:
            mid = (lo + hi) // 2
            if ok(mid):
                ans = mid
                lo = mid + 1
            else:
                hi = mid - 1
        return ans
```

## 8. 边界情况与易错点

1. **全部元素都超阈值**：如示例 2，答案必须是 0；`ans` 初值取 0、不在循环外强行 `return 1`。
2. **`threshold = 0` 且有 0 元素**：0 元素的正方形和恰为 0，算可行；若矩阵全是正数则答案为 0。判定用 `<=` 而不是 `<`。
3. **单行 / 单列矩阵**：$m = 1$ 或 $n = 1$ 时上界 $\min(m,n) = 1$，退化为「是否存在单格 $\le threshold$」，答案是 0 或 1，不要漏掉答案为 1 的情形。
4. **`hi` 取错**：写成 $hi = \max(m,n)$ 会在 $i - L < 0$ 时非法访问；写成 $hi = m + n$ 或 $mn$ 则白跑多轮。
5. **差一错误**：`pre` 是 1-indexed，矩阵是 0-indexed；判定里 `i` 的取值必须是 $[L, m]$（含端点），表示右下角，而不是左上角。
6. **二分死循环**：可行时务必 `lo = mid + 1` 并更新 `ans`，不可行时 `hi = mid - 1`；若写成 `lo = mid` 会死循环。
7. **提前返回的顺序无关**：`ok` 中一旦命中就返回，不需要继续扫描；若先求最小值再比较，复杂度不变但常数更大。
8. **溢出风险**：本题 `int` 够用；若把单格上限改到 $10^5$，前缀和可达 $9 \times 10^9$，必须换 `long long`（Python 无此问题）。
