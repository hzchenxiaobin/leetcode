# LeetCode 含特定字母的最小子序列 题解

## 1. 题目概述

- **标题 / 题号**：含特定字母的最小子序列（#2030，hard）
- **链接**：https://leetcode.cn/problems/smallest-k-length-subsequence-with-occurrences-of-a-letter/
- **来源**：LeetCode 第 261 场周赛 Q4
- **难度**：困难
- **标签**：栈、贪心、单调栈、字符串

**题意**：给定字符串 $s$、整数 $k$、字符 $letter$ 和整数 $repetition$。求 $s$ 中长度**恰好为** $k$ 且 **字典序最小**的子序列，要求其中 $letter$ **至少出现** $repetition$ 次。题目保证 $letter$ 在 $s$ 中的出现次数不少于 $repetition$。

**约束**：

- $1 \le \text{repetition} \le k \le n = |s| \le 5 \times 10^4$
- $s$ 由小写英文字母组成
- $letter$ 是单个小写字母，在 $s$ 中至少出现 $repetition$ 次

> 💡 **审题关键**：① 子序列**保序**但可不连续；② 长度是**恰好** $k$，不是至多；③ $letter$ 是**至少** $repetition$ 次，可以更多；④ 「字典序最小」与「恰好 $k$ 长」叠加，意味着不能只顾贪小字符，还要**留够名额和长度**——这是本题与经典单调栈题的分野。

## 2. 示例

**示例 1**

```text
输入：s = "leet", k = 3, letter = "e", repetition = 1
输出："eet"
解释：4 个满足条件的子序列为 "lee"、"let"、"let"、"eet"，字典序最小的是 "eet"。
```

**示例 2**

输出："ecde"
解释："ecde" 是长度 4 且含至少 2 个 'e' 的字典序最小子序列。
```

**示例 3**

输出："bb"
解释：唯一满足条件的子序列就是 "bb" 本身。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有 $\binom{n}{k}$ 个长度为 $k$ 的子序列，逐一检查 $letter$ 数量后取字典序最小。$n$ 达 $5 \times 10^4$，组合数是天文数字，显然不可行。

退一步的贪心直觉：要让字典序小，就该**尽量让小字符出现在前面**。这正指向**单调栈**——但本题在经典模型上叠了两个硬约束，直接套模板会翻车，必须逐条审视每个弹栈/入栈决策。

### 3.2 核心观察：双约束单调栈

先回忆经典模型（402. 移掉 K 位数字 / 1673. 最具竞争力的子序列）：用栈维护答案，扫描每个字符 $c$，只要**栈顶更大且弹掉后剩余字符仍够填满 $k$ 个**就弹栈。它只有一条**长度约束**。

本题多出「至少 $repetition$ 个 $letter$」，把 $letter$ 变成了**稀缺名额**。记：

- $size$：当前栈长；$cnt$：栈内 $letter$ 的个数；
- $suffix[i]$：$s[i..n-1]$ 中 $letter$ 的个数（可 $O(n)$ 预处理）。

于是得到四条观察：

1. **弹栈要过长度约束**：弹掉栈顶后 $(size-1)+(n-i) \ge k$ 才允许弹，否则最后凑不满 $k$ 个字符。
2. **弹栈还要过字母约束**：若栈顶就是 $letter$，弹掉它之后必须仍有 $cnt - 1 + suffix[i] \ge repetition$，否则 $letter$ 名额不够。等价写法是 $cnt + suffix[i] > repetition$。
3. **非 $letter$ 入栈要「席位预留」**：字符 $c \ne letter$ 想入栈，必须保证入栈后剩下的空位还装得下尚缺的 $letter$，且后缀确实还有这么多 $letter$：$suffix[i] \ge repetition - cnt$ 且 $k - size - 1 \ge repetition - cnt$。任一不满足就只能**跳过 $c$，把席位让给未来的 $letter$**。
4. **$letter$ 一律入栈**（当 $size < k$）：看似激进——若 $letter$ 很大（比如 `'z'`），先压进去岂不亏？不会：观察 3 的席位预留保证了空位，观察 2 的字母约束则负责兜底——一旦后面来了更小的字符、且 $letter$ 名额依然充足，栈顶的 $letter$ 照样会被弹掉；若弹不掉，说明名额已到极限，任何可行解在此处都无法更小。

![双约束单调栈模型：弹栈看长度+字母，入栈看席位预留](images/wc261_q4_dual_constraints_model.svg)

### 3.3 算法流程

1. 预处理 $suffix[i]$（后缀 $letter$ 计数），初始化空栈与 $cnt = 0$。
2. 从左到右扫描 $c = s[i]$：
   - **弹栈循环**：只要栈非空且栈顶 $> c$，检查长度约束与字母约束（仅当栈顶是 $letter$ 时），都通过则弹出（若是 $letter$ 则 $cnt \gets cnt-1$），继续循环。
   - **入栈决策**：若 $size < k$：$c = letter$ 直接入栈（$cnt \gets cnt+1$）；否则做席位检查，两条都通过才入栈，否则跳过 $c$。
3. 扫描结束，栈中内容即为答案。

## 4. 算法细节

### 4.1 后缀计数

$suffix[i]$ 表示 $s[i..n-1]$ 中 $letter$ 的个数，从右往左一遍扫出：$suffix[i] = suffix[i+1] + [s[i] = letter]$。它是字母约束与席位检查的「情报来源」——判断弹掉/入栈后 $letter$ 名额是否还够，只依赖「栈内已有多少 + 后缀还能提供多少」。

### 4.2 弹栈条件推导

栈顶 $t$ 可以弹出，当且仅当**三个条件同时成立**：

1. $t > c$：字典序上有收益，这是弹栈的动机；
2. 长度：$(size - 1) + (n - i) \ge k$——弹掉后，栈加**尚未扫描的字符（含当前 $c$）**仍能凑满 $k$ 个。注意 $n-i$ 是含当前位置的剩余量；
3. 字母：$t \ne letter$，或 $cnt - 1 + suffix[i] \ge repetition$（弹出后，栈内加后缀仍凑得够名额）。代码里写成 $cnt + suffix[i] > repetition$，注意 $suffix[i]$ **包含** $s[i]$ 自身。

### 4.3 入栈条件推导

当 $size < k$ 时：

- **$c = letter$**：直接入栈。入栈消耗一个空位、换来一个名额，量上不亏（见证明中引理 1 的维护）；即使 $letter$ 字典序偏大，后续弹栈的字母约束会正确处置它。
- **$c \ne letter$**：必须同时满足才入栈：
  - 后缀够：$suffix[i] \ge repetition - cnt$（$c$ 不占名额，但未来名额只能靠后缀补）；
  - 空位够：$k - size - 1 \ge repetition - cnt$（入栈 $c$ 后，剩余空位仍装得下缺的名额）。

  两条合并即 $\min(k - size - 1,\ suffix[i]) \ge repetition - cnt$。任何一条不满足时跳过 $c$——此时**任何**以「当前栈 $+\ c$」为前缀的长度 $k$ 子序列都凑不够 $letter$，跳过是唯一选择。

### 4.4 为什么最终栈长恰好是 $k$

「席位预留」使得非 $letter$ 永远不会挤占 $letter$ 的名额；$letter$ 到场时只要 $size < k$ 就必入栈。于是栈不会「提前塞满无关字符」，也不会「名额没凑齐就结束」——形式化论证见下节引理 1。

## 5. 正确性证明

**引理 1（可行性不变量）**：任意时刻（设已处理完位置 $i-1$，即将处理 $s[i]$），记 $size$ 为栈长、$cnt$ 为栈内 $letter$ 数、$suf = suffix[i]$。若

$$size + (n - i) \ge k \quad \text{且} \quad cnt + \min(k - size,\ suf) \ge repetition, \tag{$\ast$}$$

则从当前栈出发，总能继续构造出长度 $k$ 且 $letter$ 数 $\ge repetition$ 的子序列。算法的每一步操作都不破坏 $(\ast)$。

**证明**：对操作逐一验证。

- **初始**（$i=0$，栈空）：$0 + n \ge k$ 由约束 $k \le n$；$0 + \min(k, suffix[0]) \ge repetition$ 由「$letter$ 至少出现 $repetition$ 次」。成立。
- **弹栈**（弹出 $t$）：设弹出前栈长 $size$。长度约束 $(size-1)+(n-i) \ge k$ 恰好保证弹出后第一条不变量。对第二条：若 $t \ne letter$，$cnt$ 不变而 $size$ 减一使 $\min$ 中 $k-size$ 支增一，$(\ast)$ 显然保持；若 $t = letter$，需证 $cnt - 1 + \min(k - size + 1,\ suffix[i]) \ge repetition$——当 $\min$ 取 $suffix[i]$ 支（$suffix[i] \le k - size + 1$）时即字母约束本身；当取 $k - size + 1$ 支（$k - size + 1 \le suffix[i]$）时，弹前 $(\ast)$ 中 $\min(k - size,\ suffix[i]) = k - size$，给出 $cnt + k - size \ge repetition$，而 $cnt - 1 + (k - size + 1) = cnt + k - size$，同样成立。
- **入栈 $c = letter$**：$size' = size+1$，$cnt' = cnt+1$，后续后缀名额 $suffix[i+1] = suffix[i]-1$。则 $cnt' + \min(k - size',\ suffix[i+1]) \ge cnt + 1 + \min(k-size,\ suffix[i]) - 1 \ge repetition$（用 $\min(x-1, y-1) \ge \min(x,y)-1$）；长度两侧同步减一，保持。
- **入栈 $c \ne letter$**：条件 $\min(k - size - 1,\ suffix[i]) \ge repetition - cnt$ 正是 $(\ast)$ 在 $size+1$、$cnt$ 不变下的形式。
- **跳过 $c$**：跳过仅发生在 $c \ne letter$ 且席位检查失败时。栈状态不变，且 $c$ 非 $letter$ 使 $suffix[i+1] = suffix[i]$，故第二条不变量逐字保持。对第一条，只有 $size + (n-i) = k$ 的贴界情形需要担心：若此时跳过发生，席位失败给出 $k - size \le repetition - cnt$，与第二条联立得 $suffix[i] \ge k - size = n - i$；但 $s[i] \ne letter$ 又意味着 $suffix[i] \le n - i - 1$，矛盾——故贴界时席位检查必然通过、不会跳过，第一条保持。

扫描结束时（$i = n$）：第一条给出 $size \ge k$，又入栈操作保证 $size \le k$，故 $size = k$；第二条给出 $cnt \ge repetition$。即**最终栈就是一个可行解**。∎

**引理 2（弹栈的必要性）**：设当前栈为 $S + t$（$t$ 为栈顶），弹栈三条件成立，则任何以 $S + t$ 为前缀的可行解都不是字典序最小的。

**证明**：记 $c = s[i]$，则 $c < t$。设弹出后栈为 $S$（长 $size - 1$）、栈内名额 $cnt$（$t = letter$ 时已减一），令 $r = repetition - cnt$。若 $c \ne letter$ 且 $r > k - size$（空位必须全部留给 $letter$），则 $S + c$ 形态的前缀不可行，属于下述**名额贴界情形**，单独讨论。除此之外，$r \le suffix[i]$ 与 $r \le k - size + [c = letter]$ 均成立：$t = letter$ 时分别由字母约束与弹前 $(\ast)$ 给出，$t \ne letter$ 时由 $(\ast)$ 直接给出。构造 $F' = S + c + Z$，其中 $Z$ 为 $s[i+1..n-1]$ 中的 $k - size$ 个字符（长度条件 $|S| + (n-i) \ge k$ 保证取得到），优先纳入 $letter$。则 $F'$ 可行：

- 长度：$|S| + 1 + (k - size) = k$；
- 名额：$Z$ 中 $letter$ 数可达 $\min(k - size,\ suffix[i+1])$，由 $k - size \ge r - [c = letter]$ 与 $suffix[i+1] = suffix[i] - [c = letter] \ge r - [c = letter]$，得 $F'$ 的 $letter$ 总数 $\ge cnt + [c = letter] + (r - [c = letter]) = repetition$。

而 $F'$ 与任何 $F = S + t + \cdots$ 在前 $|S|$ 位相同、第 $|S|+1$ 位 $c < t$，故 $F' <_{\mathrm{lex}} F$。即以 $S+t$ 打头必非最优。∎

> 💡 **名额贴界的微妙情形**：当 $c \ne letter$ 且空位必须全部留给 $letter$（$r = k - size + 1$）时，$S + c$ 形态的前缀不可行，上面的构造不适用。但此时弹掉的 $letter$ 必然由后缀中的 $letter$ **顶替**（$suffix[i] \ge r$ 保证存在），前缀第 $|S|+1$ 位的**字符值**仍是 $letter$、与 $t$ 相同——弹掉的是「实例」，比较的是「字符值」，栈的前缀值不变而腾出了更靠后的位置。这正是席位检查（引理 3）与字母约束联动的深层含义。

**引理 3（跳过的安全性）**：若席位检查失败（$\min(k - size - 1,\ suffix[i]) < repetition - cnt$），则不存在以「当前栈 $+\ c$」为前缀的可行解。

**证明**：以此前缀的长度 $k$ 子序列中，$letter$ 只能来自栈内（$cnt$ 个）与 $s[i+1..]$（至多 $suffix[i]$ 个），且总位置只有 $k - size - 1$ 个，故 $letter$ 数 $\le cnt + \min(k-size-1,\ suffix[i]) < repetition$，不可行。∎

**定理**：算法输出的栈是字典序最小的可行子序列。

**证明**：由引理 1，输出可行。最优性按标准单调栈贪心论证归纳：引理 2 表明每次弹栈要么让候选前缀严格变小（$S+c+Z$ 可行时），要么前缀字符值不变而由后缀 $letter$ 顶替（贴界情形），两种情形都不会让「以当前栈为前缀延展成最优解」的机会受损；引理 3 表明每次跳过都只排除了不可行的候选；而在「弹无可弹、跳无可跳」处入栈的字符，是不破坏 $(\ast)$（即可行性）前提下所能取得的最靠前最小字符。对位置归纳可知：任何可行解在每一位上都无法比算法的栈更小，故输出即字典序最小。∎

> 💡 **一句话总结**：弹栈条件 = 「弹完仍可行」的精确表达；入栈条件 = 「入完仍可行」的精确表达。**双约束单调栈的所有条件，都是可行性不变量 $(\ast)$ 的守门员**。

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。每个字符至多入栈一次、出栈一次；$suffix$ 预处理线性。$n = 5 \times 10^4$ 轻松通过。
- **空间复杂度**：$O(n)$。栈与后缀计数数组。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    string smallestSubsequence(string s, int k, char letter, int repetition) {
        int n = s.size();
        vector<int> suffix(n + 1, 0);
        for (int i = n - 1; i >= 0; --i)
            suffix[i] = suffix[i + 1] + (s[i] == letter);

        string st;          // 栈（即答案）
        int cnt = 0;        // 栈内 letter 个数
        for (int i = 0; i < n; ++i) {
            char c = s[i];
            // 弹栈：三条件 —— 字典序、长度、字母
            while (!st.empty() && st.back() > c && (int)st.size() + (n - i) > k) {
                if (st.back() == letter && cnt + suffix[i] <= repetition)
                    break;                          // letter 名额告急，禁止再弹
                if (st.back() == letter)
                    --cnt;
                st.pop_back();
            }
            if ((int)st.size() < k) {
                if (c == letter) {
                    st.push_back(c);
                    ++cnt;
                } else if (suffix[i] >= repetition - cnt
                           && k - (int)st.size() - 1 >= repetition - cnt) {
                    st.push_back(c);                // 席位检查通过
                }
                // 否则跳过 c，席位留给 letter
            }
        }
        return st;
    }
};
```

### Python

```python
class Solution:
    def smallestSubsequence(self, s: str, k: int, letter: str, repetition: int) -> str:
        n = len(s)
        suffix = [0] * (n + 1)
        for i in range(n - 1, -1, -1):
            suffix[i] = suffix[i + 1] + (s[i] == letter)

        st = []          # 栈（即答案）
        cnt = 0          # 栈内 letter 个数
        for i, c in enumerate(s):
            while st and st[-1] > c and len(st) + (n - i) > k:
                if st[-1] == letter and cnt + suffix[i] <= repetition:
                    break                              # letter 名额告急
                if st.pop() == letter:
                    cnt -= 1
            if len(st) < k:
                if c == letter:
                    st.append(c)
                    cnt += 1
                elif suffix[i] >= repetition - cnt and k - len(st) - 1 >= repetition - cnt:
                    st.append(c)                       # 席位检查通过
                # 否则跳过 c，席位留给 letter
        return ''.join(st)
```

## 8. 边界情况与易错点

1. **弹栈条件缺一不可**：只写字典序+长度约束（经典模板）会在 $letter$ 名额上翻车——如 $s = \text{"ebe"}$、$k=2$、$letter=\text{'e'}$、$repetition=2$ 时会把必需的 'e' 弹掉、错误输出 "be"；反之加上字母约束却不检查长度，则 $s = \text{"cba"}$、$k=2$、$letter=\text{'a'}$、$repetition=1$ 会把 'b' 也弹掉，最后只剩长度 1 的 "a"，凑不满 $k$。示例演算 $i=4$ 演示了字母约束拦截。
2. **$suffix[i]$ 的口径**：字母约束里用的 $suffix[i]$ **包含** $s[i]$ 自身；而席位检查中 $c \ne letter$，$suffix[i]$ 恰好等于「当前位置之后可用的 $letter$ 数」，两条不要搞混偏移。
3. **严格大于才弹**：$t = c$ 时弹栈没有字典序收益，还可能白白丢掉名额，条件必须写 `st.back() > c`。
4. **letter 无条件入栈 ≠ 随便入**：仅当 $size < k$；其正确性依赖弹栈的字母约束兜底。不要自作聪明给 $letter$ 也加「更小才入」的条件——那会在名额紧张时直接丢掉必需的 $letter$。
5. **非 letter 的席位检查是两条**：只查「后缀 $letter$ 够」不查「空位够」，会在栈被无关字符填满后放不进 $letter$（如 $s=\text{"abz"}$、$k=2$、$letter=\text{'z'}$、$repetition=1$ 时错误输出 "ab"）；反之只查空位不查后缀，会在后缀根本没有 $letter$ 时空欢喜。
6. **`repetition - cnt` 可能为负或零**：两条不等式天然容纳这种情况（负数必然通过），无需特判，但写成 `min(k - size - 1, suffix[i]) >= repetition - cnt` 更能体现本质。
7. **数据规模**：$n \le 5 \times 10^4$，全程 $O(n)$，C++ 用 `string` 当栈、Python 用 `list` 均可；无溢出风险（量级都在 $10^4$ 内）。
