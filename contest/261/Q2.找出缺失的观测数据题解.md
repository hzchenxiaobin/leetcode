# LeetCode 找出缺失的观测数据 题解

## 1. 题目概述

- **标题 / 题号**：找出缺失的观测数据（#2028，medium）
- **链接**：https://leetcode.cn/problems/find-missing-observations/
- **来源**：LeetCode 第 261 场周赛 Q2
- **难度**：中等
- **标签**：数组、数学、构造、模拟

**题意**：共有 $n + m$ 次掷六面骰的观测（点数 $1 \sim 6$），其中 $m$ 次在手（数组 `rolls`），$n$ 次缺失。已知全部 $n + m$ 次投掷的**平均值** `mean`（保证是整数）。返回**任意一组**长度为 $n$、元素在 $[1,6]$ 的缺失观测，使整体平均值恰为 `mean`；不存在答案返回空数组。

**约束**：

- $m = \text{rolls.length}$，$1 \le n, m \le 10^5$
- $1 \le \text{rolls}[i], \text{mean} \le 6$

> 💡 **审题关键**：① `mean` 是**整数** → 总和 $T = \text{mean} \times (n+m)$ 是精确整数，全程整型运算，无浮点；② 答案**不唯一**，返回任意一组 → 这是「**判定 + 构造**」题，不是搜索题；③ 缺失的每个数被夹在 $[1,6]$ → 缺失总和只能落在 $[n, 6n]$，越界即无解。

## 2. 示例

**示例 1**

```text
输入：rolls = [3,2,4,3], mean = 4, n = 2
输出：[6,6]
解释：共 6 次投掷，总和 = 4×6 = 24；已观测和 = 3+2+4+3 = 12，
      缺失和 = 24 − 12 = 12 = 2×6 → 两个骰子都只能是 6。
```

**示例 2**

```text
输入：rolls = [1,5,6], mean = 3, n = 4
输出：[2,3,2,2]
解释：共 7 次投掷，总和 = 3×7 = 21；已观测和 = 12，缺失和 = 9，
      4 个骰子凑 9：[2,3,2,2]、[3,2,2,2]、[1,2,3,3] 等均合法。
```

**示例 3**

```text
输入：rolls = [1,2,3,4], mean = 6, n = 4
输出：[]
解释：总和 = 6×8 = 48；已观测和 = 10，缺失和 = 38 > 6×4 = 24，
      缺失部分全填 6 也追不上，无解。
```

**示例 4**

```text
输入：rolls = [1], mean = 3, n = 1
输出：[5]
解释：总和 = 3×2 = 6；已观测和 = 1，缺失和 = 5 → 单个骰子取 5。
```

## 3. 解题思路

### 3.1 暴力思路

先盘朴素路线：

1. **组合枚举**：缺失的 $n$ 个格子每格 $6$ 种取值，共 $6^n$ 种组合，$n$ 可达 $10^5$，天文数字；DFS 按「剩余和」剪枝，最坏仍是指数级。
2. **背包可行性 DP**：$dp[i][j]$ = 用 $i$ 个骰子能否凑出和 $j$，状态数 $O(n \cdot 6n)$，约 $6 \times 10^{10}$，同样不可行——而且本题**只要任一解**，可行性 DP 属于杀鸡用牛刀。

两条路线的共同误区是**把「凑和」当成搜索问题**。平均值把总和锁死、答案又允许任意，自由度大到连「枚举一个」都不必——先判定，再构造。

### 3.2 核心观察：缺失总和被唯一钉死，可行 ⇔ $n \le M \le 6n$

![核心概念：缺失总和 M 被平均值钉死，可行区间 [n,6n]，商余均摊构造](images/wc261_q2_sum_range_concept.svg)

三步把问题压扁：

1. **平均 → 总和**：$T = \text{mean} \times (n+m)$。`mean` 是整数，整型乘法直算，零浮点。
2. **缺失和是定值**：$M = T - \sum_i \text{rolls}[i]$。无论缺失的 $n$ 个数怎么排，它们的和**必须**恰好等于 $M$——问题从「构造数组」坍缩为「凑一个定值」。
3. **可行性双向夹逼**：$n$ 个 $[1,6]$ 的整数，和最小是 $n$（全 1）、最大是 $6n$（全 6），于是 $M$ 出区间即无解；反过来区间内每个整数都凑得出（无空洞——§5 引理 2 的构造本身就是证明）。故
   $$n \le M \le 6n \iff \text{有解}$$
   $M < n$（全 1 也超支）或 $M > 6n$（全 6 也不够）→ 返回 `[]`。
4. **商余均摊构造**：设 $M = nq + r$（$q = \lfloor M/n \rfloor$，$r = M \bmod n$）。取 $r$ 个 $q+1$、$n-r$ 个 $q$：
   $$r\,(q{+}1) + (n{-}r)\,q = nq + r = M$$
   且每个值天然落在 $[1,6]$（$q \ge 1$ 恒成立；$q = 6$ 时 $r$ 必为 $0$，不会冒出 7，见 §5 引理 2）。

> 💡 **范式提炼**：「用 $n$ 个 $[L, R]$ 内的整数凑定和 $s$」是一族通用模板——判定 $nL \le s \le nR$，构造用商余均摊。1103 分糖果 II、1663 最小字符串都是它的换皮。

### 3.3 算法流程

![算法流程：算缺失和 M，判区间 [n,6n]，商余均摊构造答案](images/wc261_q2_construct_flow.svg)

1. $T \leftarrow \text{mean} \times (n+m)$；
2. $M \leftarrow T - \sum \text{rolls}$（一趟求和）；
3. 若 $M < n$ 或 $M > 6n$：返回 `[]`；
4. $q, r \leftarrow \lfloor M/n \rfloor,\ M \bmod n$；
5. 返回 $r$ 个 $q+1$ 拼 $n-r$ 个 $q$。

### 3.4 示例演算

![示例演算：M=9 经商余均摊得 [3,2,2,2]，附其余三例速览](images/wc261_q2_walkthrough.svg)

以示例 2 `rolls = [1,5,6]`, `mean = 3`, `n = 4` 演算（重点看第 ④⑤ 步的「先判后构」）：

| 步骤 | 计算 | 结果 |
|------|------|------|
| ① 总和 | $\text{mean} \times (n{+}m) = 3 \times 7$ | $T = 21$ |
| ② 已观测和 | $1 + 5 + 6$ | $S = 12$ |
| ③ 缺失和 | $M = 21 - 12$ | $M = 9$ |
| ④ 判定 | $4 \le 9 \le 24$ | ✓ 可构造 |
| ⑤ 商余 | $q = 2$，$r = 1$ | $[3,2,2,2]$ |

验证：$3+2+2+2 = 9 = M$ ✓，整体 $(12+9) \div 7 = 3 = \text{mean}$ ✓。示例 1（$M = 12 = 6n$，$r = 0$ 全取基线 6）、示例 3（$M = 38$ 越上界直接 `[]`）、示例 4（$n = 1$ 退化，$q$ 即答案）见上图三张卡片。

## 4. 算法细节

1. **整型直算，别碰浮点**：`mean` 为整数，$T$、$M$ 全是精确整数。反向操作（先 `sum ÷ (n+m)` 再乘回去）即使整除也纯属埋精度雷。
2. **乘 $n+m$ 不是 $n$**：手滑重灾区。`mean` 是**全部** $n+m$ 个数的平均，写乘法前先默念「谁的平均」。
3. **先判后构**：可行性判定放在构造之前，越界立即返回 `[]`；构造阶段**无需任何值域校验**——$q \ge 1$ 与「$q = 6 \Rightarrow r = 0$」由判定条件自动保证（§5 引理 2），代码里再补一句 `if (v > 6)` 属于没想透。
4. **垫高的位置任选**：前 $r$ 个、后 $r$ 个、间隔着垫都行（题目只要任一解）。本文取「前 $r$ 个 $q+1$」，`[q+1]*r + [q]*(n-r)` 一行收工。
5. **溢出核算**：$n+m \le 2 \times 10^5$、$\text{mean} \le 6$ → $T \le 1.2 \times 10^6$，`int` 放得下；但求和、$6 \times n$ 这类中间量在 C++ 里习惯性上 `long long`，赛场零成本换安稳。
6. **复杂度意识**：求和 $O(m)$ + 构造 $O(n)$ = $O(n+m)$，恰是读入 + 输出的规模，已到下界。

## 5. 正确性证明

记 $T = \text{mean} \cdot (n+m)$，$S = \sum_i \text{rolls}[i]$，$M = T - S$。

**引理 1（必要性）**：若存在合法答案 $a_1, \dots, a_n$（每个 $a_i \in [1,6]$ 且 $\sum a_i = M$），则 $n \le M \le 6n$。

**证明**：对 $1 \le a_i \le 6$ 逐项放缩求和：$n \le \sum_{i=1}^{n} a_i = M \le 6n$。∎

**引理 2（构造合法性）**：若 $n \le M \le 6n$，令 $q = \lfloor M/n \rfloor$、$r = M - nq$，则数组 $A = (\underbrace{q{+}1, \dots, q{+}1}_{r\text{ 个}}, \underbrace{q, \dots, q}_{n-r\text{ 个}})$ 的每个元素在 $[1,6]$ 内，且 $\sum A = M$。

**证明**：**和**：$\sum A = r(q+1) + (n-r)q = nq + r = M$ ✓。**值域**分三段：

- 由 $M \ge n$ 得 $q = \lfloor M/n \rfloor \ge \lfloor n/n \rfloor = 1$，故每个 $q \ge 1$；
- 若 $q \le 5$，则 $q + 1 \le 6$，垫高后的值合法；
- 若 $q = 6$，则 $M \ge 6n$，结合条件 $M \le 6n$ 得 $M = 6n$，故 $r = M - 6n = 0$——数组里根本没有 $q + 1$，不会出现 7。

三段合并，每个元素 $\in [1,6]$。∎

**定理（算法正确）**：合法答案存在时，算法必输出一个合法答案；不存在时，算法输出 `[]`。

**证明**：① 若 $M < n$ 或 $M > 6n$：由引理 1，任何 $n$ 个 $[1,6]$ 的数之和都落在 $[n, 6n]$，不可能等于 $M$，无解；算法此时返回 `[]`，正确。② 若 $n \le M \le 6n$：由引理 2，输出的每个值在 $[1,6]$ 且缺失部分之和为 $M$，于是全部 $n+m$ 个数之和为 $S + M = S + (T - S) = T = \text{mean} \cdot (n+m)$，平均值恰为 `mean`，输出合法。∎

> 💡 **区间无空洞的另一视角（增量法）**：把「全 1 数组」当起点，目标 $M = n + d$（$0 \le d \le 5n$）只需把总量 $d$ 的增量分给 $n$ 个格子、每格增量 $\in [0,5]$。商余分配每格先给 $\lfloor d/n \rfloor$、前 $d \bmod n$ 格多给 1，增量天然 $\le 5$——这正是引理 2，也说明 $[n, 6n]$ 内每个整数都可达，判定条件是**充要**的。

## 6. 复杂度分析

- **时间复杂度**：$O(n + m)$。求 $S$ 一趟 $O(m)$；可行性判定 $O(1)$；构造答案 $O(n)$。$n, m \le 10^5$，总量 $2 \times 10^5$ 级，且线性于输入 + 输出规模，已到下界。
- **空间复杂度**：$O(1)$ 额外空间（不计返回的答案数组；若计输出则为 $O(n)$）。仅用 `T / M / q / r` 等常数个变量。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> missingRolls(vector<int>& rolls, int mean, int n) {
        int m = rolls.size();
        long long T = 1LL * mean * (n + m);          // 全部 n+m 次的总和
        long long S = accumulate(rolls.begin(), rolls.end(), 0LL);
        long long M = T - S;                         // 缺失部分必须凑出的定值
        if (M < n || M > 6LL * n) return {};          // 双向夹逼，越界即无解
        int q = M / n, r = M % n;                    // 商 = 基线，余 = 垫高名额
        vector<int> ans(n, q);
        for (int i = 0; i < r; ++i) ans[i] = q + 1;  // 前 r 格各垫高 1
        return ans;
    }
};
```

### Python

```python
class Solution:
    def missingRolls(self, rolls: List[int], mean: int, n: int) -> List[int]:
        M = mean * (n + len(rolls)) - sum(rolls)   # 缺失部分之和（定值）
        if not n <= M <= 6 * n:                    # 越界任一侧 → 无解
            return []
        q, r = divmod(M, n)                        # 基线 q ＋ 垫高名额 r
        return [q + 1] * r + [q] * (n - r)
```

### Python 备选：逐格贪心版（字典序最小）

```python
class Solution:
    def missingRolls(self, rolls: List[int], mean: int, n: int) -> List[int]:
        M = mean * (n + len(rolls)) - sum(rolls)
        if not n <= M <= 6 * n:
            return []
        ans = []
        for i in range(n):                        # 第 i 格取「后面还兜得住」的最小值
            v = max(1, M - 6 * (n - i - 1))       # 后面 n-i-1 格至多兜走 6*(n-i-1)
            ans.append(v)
            M -= v
        return ans
```

> ⚠️ 备选版从左到右每格取**尽量小**的值（保证剩余和仍落在剩余格子的 $[\,\text{个数},\ 6 \times \text{个数}\,]$ 内），产出**字典序最小**的解——如 $M=9, n=4$ 得 $[1,1,1,6]$。本题答案任意、商余版更短；但附加「最小字典序 / 最小方差」等约束时，只能用这种逐格贪心（1663 套路）。

## 8. 边界情况与易错点

1. **乘错总个数（头号坑）**：`mean × (n+m)` 是全部投掷的总和，写成 `mean × n` 直接全盘崩。先默念「平均是除以 $n+m$ 的」再动笔。
2. **无解要双向判**：`M < n` 与 `M > 6n` 缺一不可。示例 3 演的是上界爆掉；下界爆掉的例子：`rolls = [6,6,6], mean = 1, n = 1`，此时 $T = 10$、$S = 18$、$M = -8 < 1$ → `[]`（观测和都能超过总和）。
3. **别用浮点**：$T$ 用整型乘法直接得到；先 `sum / (n+m)` 再乘回去是给自己埋精度雷。
4. **构造阶段无需校验值域**：$q \ge 1$、$q = 6 \Rightarrow r = 0$ 由判定条件自动保证（§5 引理 2），再补 `if` 属于没想透。
5. **$n = 1$ 退化**：$q = M$、$r = 0$，返回 `[M]`（示例 4）；判定已保证 $M \in [1,6]$，无需特判。
6. **两端点 $M = n$ 与 $M = 6n$**：全 1 / 全 6，$r = 0$，商余公式自然处理，无需特判。
7. **答案顺序无关**：`[3,2,2,2]` 与官方示例的 `[2,3,2,2]` 都对——别对着判题输出纠结顺序。
8. **溢出核算**：$T \le 1.2 \times 10^6$，`int` 足够；C++ 求和与中间量建议 `long long`（`accumulate` 初值给 `0LL`），习惯性防御，几乎零成本。
