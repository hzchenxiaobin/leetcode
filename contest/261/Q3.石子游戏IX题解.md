# LeetCode 石子游戏 IX 题解

## 1. 题目概述

- **标题 / 题号**：石子游戏 IX（#2029，medium）
- **链接**：https://leetcode.cn/problems/stone-game-ix/
- **来源**：LeetCode 第 261 场周赛 Q3
- **难度**：中等
- **标签**：博弈、贪心、数学、计数、数组

**题意**：一行 $n$ 个石子各带价值。Alice 与 Bob 轮流移除任意一颗石子，**Alice 先手**。每次移除后立即判定：

- 若**已移除石子的总和**能被 $3$ 整除，该玩家**立刻输**；
- 若不整除且场上已无剩余石子，**Bob 直接获胜**（即便该回合轮到 Alice）。

双方均采用最优决策，Alice 胜返回 `true`，Bob 胜返回 `false`。

**约束**：

- $1 \le \text{stones.length} \le 10^5$
- $1 \le \text{stones}[i] \le 10^4$

> 💡 **审题关键**：① 输赢只由「已移除之和能否被 $3$ 整除」决定 → **只有 $\text{stones}[i] \bmod 3$ 参与**，$10^4$ 的值域是烟雾弹；② 和 $\equiv r$ 时打出余 $3-r$ 的牌立刻输——这类牌是「**毒牌**」，Alice 的赢法只有一种：**把毒牌塞给 Bob**；③ 「取尽 → Bob 直接获胜」是**非对称规则**：Alice 不能靠耗光石子取胜，「无牌可出者负」的正常博弈直觉在此失效（示例 2 即坑）；④ 开局时和 $\equiv 0$，Alice 打余 $0$ 的牌等于自爆，开局只能打余 $1$ 或余 $2$。

## 2. 示例

**示例 1**

```text
输入：stones = [2,1]
输出：true
解释：Alice 移除任一颗，Bob 移除剩下那颗，总和 = 3 被 3 整除，
      Bob 打出毒牌 → Alice 胜。
```

**示例 2**

```text
输入：stones = [2]
输出：false
解释：Alice 移除唯一石子，总和 = 2 不被 3 整除，但石子已取尽
      → Bob 直接获胜。
```

**示例 3**

```text
输入：stones = [5,1,2,4,3]
输出：false
解释：Bob 总能赢。一种过程：A:1 → B:4 → A:2 → B:3 → A:5，
      总和 = 15 被 3 整除，Alice 打出毒牌 → Bob 胜。
```

**示例 4（自补的边界例）**

```text
输入：stones = [3,1,1]
输出：false
解释：c0 = 1（一颗余 0），c1 = 2，c2 = 0。
      Alice 开余 1：A:1 → B:1 → A 只剩跳板 3 → 取尽，和 = 5 ≢ 0
      → Bob 直接胜。此例是本题最流行的错解翻车点（见 §8）。
```

## 3. 解题思路

### 3.1 暴力思路

最朴素是把每颗石子当独立个体做**极小化极大博弈树**——指数级，$n$ 可达 $10^5$，直接出局。退一步，既然只有余数参与（§1 审题 ①），把局面压缩成 $(c_0, c_1, c_2,\ \text{和} \bmod 3,\ \text{轮到谁})$ 做记忆化 minimax：状态数仍是 $O(c_0 \cdot c_1 \cdot c_2)$ 量级（$10^5$ 三分之后立方级），依旧爆炸。

> 💡 暴力的价值在于**打表**：对 $c_0 + c_1 + c_2 \le 8$ 的全部局面跑 minimax，把 true/false 表按 $(c_0 \bmod 2,\ c_1, c_2)$ 排开，规律肉眼可见——这正是本题的赛场实操路径（先猜闭式，再如 §5 般证明）。

### 3.2 核心观察：分堆 + 唯一安全牌 + 跳板奇偶

![核心概念：按 mod 3 分堆，非零安全牌唯一，余 0 是跳板](images/wc261_q3_mod3_concept.svg)

**第一步：按 $\bmod 3$ 分三堆。** 记 $c_0, c_1, c_2$ 为余 $0, 1, 2$ 的石子数。$10^5$ 颗石子的信息被压成三个计数。

**第二步：安全出牌表。** 设当前已移除和 $\equiv r \in \{1, 2\}$：

| 当前和 $\bmod 3$ | 打余 $0$ | 打余 $1$ | 打余 $2$ |
|---|---|---|---|
| $r = 1$ | 安全（仍 $\equiv 1$） | 安全（$\to 2$） | **毒，输**（$\to 0$） |
| $r = 2$ | 安全（仍 $\equiv 2$） | **毒，输**（$\to 0$） | 安全（$\to 1$） |

两个关键读法：

- **非零安全牌唯一**：和 $\equiv r$ 时恰是余 $r$ 本身（$r + r \equiv -r \not\equiv 0$）；毒牌恰是余 $3 - r$。
- **余 $0$ 是跳板**：不改和的余数、永远安全，只是把出牌权甩给对手——它的全部作用被压缩成**奇偶**。

**第三步：主战线锁死。** Alice 开局只能打余 $a \in \{1, 2\}$（打余 $0$ 自爆）。此后和 $\equiv a$，由安全表，下一张非零安全牌唯一是余 $a$，再下一张唯一是余 $3 - a$……于是**非零牌的打出序列被强制**为

$$a,\ a,\ 3{-}a,\ a,\ 3{-}a,\ a,\ 3{-}a,\ \dots$$

（余 $a$ 占第 $1, 2, 4, 6, \dots$ 位，余 $3-a$ 占第 $3, 5, 7, \dots$ 位）。双方唯一的自由度是**何时垫跳板**——但跳板不推进主战线、不改余数，只消耗一张「安全垫牌」。

**第四步：步数不变量（本题的灵魂）。** 既然每一步要么推进主战线、要么烧一张跳板，那么「场上只剩毒牌」的那一刻，**恰好**打出了 $L$ 张主战线牌（$L$ 由计数唯一决定）与全部 $c_0$ 张跳板——**总数与垫跳板的时机无关**！于是败者 $=$ 第 $L + c_0 + 1$ 步的执子者，只看 $L + c_0$ 的奇偶。跳板何时垫、谁推进主战线，统统不影响结局。

### 3.3 算法流程

![算法流程：一趟计数，按 c0 奇偶套闭式](images/wc261_q3_case_flow.svg)

对「Alice 开局打余 $a$」（记 $b = 3 - a$，$c_a, c_b$ 为对应计数）逐情形分析（证明见 §5）：

| 开局余 $a$ 的条件 | 主战线长度 $L$ | 断粮后剩余非零石 | Alice 结局 |
|---|---|---|---|
| $c_a = 0$ | — | — | 此开局不可用 |
| $1 \le c_a \le c_b$ | $2c_a - 1$ | 余 $b$ 石 $\ge 1$（毒牌） | 胜 $\iff c_0$ 偶 |
| $c_a = c_b + 1$ | $2c_b + 1$ | 无 | 必败（取尽判负） |
| $c_a = c_b + 2$ | $2c_b + 2$ | 无 | 必败（取尽判负） |
| $c_a \ge c_b + 3$ | $2c_b + 2$ | 余 $a$ 石 $\ge 1$（毒牌） | 胜 $\iff c_0$ 奇 |

两种开局取 OR，化简成一行闭式：

$$\boxed{\ \text{Alice 胜} \iff \big(c_0 \text{ 偶} \wedge c_1 \ge 1 \wedge c_2 \ge 1\big) \ \vee\ \big(c_0 \text{ 奇} \wedge |c_1 - c_2| \ge 3\big)\ }$$

> 💡 **为什么 $c_0$ 奇时需要差 $\ge 3$ 而不是 $\ge 2$**：$c_a = c_b + 2$ 时主战线恰好把余 $a$ 也**全部吃光**（$b$ 用 $c_b$ 张 + $a$ 用 $c_b + 2$ 张），场上只剩跳板——毒牌根本不存在，取尽判 Bob 胜。必须再多出至少一张余 $a$（$c_a \ge c_b + 3$），「被逼打毒牌」的结局才成立。

### 3.4 示例演算

![示例演算：三个计数一套闭式，含 [3,1,1] 陷阱](images/wc261_q3_walkthrough.svg)

| 输入 | $(c_0, c_1, c_2)$ | 判定 | 结果 |
|---|---|---|---|
| `[2,1]` | $(0, 1, 1)$ | $c_0$ 偶，两类非零都非空 | `true` |
| `[2]` | $(0, 0, 1)$ | $c_0$ 偶但 $c_1 = 0$ | `false`（取尽） |
| `[5,1,2,4,3]` | $(1, 2, 2)$ | $c_0$ 奇，$\lvert 2-2 \rvert = 0 < 3$ | `false` |
| `[3,1,1]` | $(1, 2, 0)$ | $c_0$ 奇，$\lvert 2-0 \rvert = 2 < 3$ | `false`（陷阱） |

以示例 3 走一遍强制主线（对应上图演算条）：Alice 开余 $1$ → A:1 → B:4 → A:2 → B:3（跳板）→ A:5（毒牌，和 $= 15 \equiv 0$）→ **Alice 输**。$c_0 = 1$ 这张唯一的跳板把「第 5 步打毒牌」的厄运甩回了 Alice——这正是 $c_0$ 奇偶翻转归属的直观体现。

## 4. 算法细节

1. **一趟计数**：只统计 `cnt[s % 3]++`，价值本身丢弃（$1 \le \text{stones}[i] \le 10^4$ 全是烟雾弹）。
2. **直接套闭式**：$c_0$ 偶看「两类非零都非空」，$c_0$ 奇看「差 $\ge 3$」，两个 $O(1)$ 判定收工。
3. **若按开局逐情形写 `check(ca, cb)`**：必须显式拦截 $c_a = c_b + 2$ 这一档（与 $c_a = c_b + 1$ 一起判必败），把「$\ge c_b + 2$ 一锅端」是本题最流行的错法；两种开局 `check(c1,c2) or check(c2,c1)` 镜像复用。
4. **$c_0$ 偶 = 跳板成对抵消**：两张跳板一垫一还，净效果为零，博弈退化为纯 $1$/$2$ 对耗；**$c_0$ 奇 = 多出一张跳板**，会把毒牌归属翻转一次——两种奇偶下获胜条件截然不同，千万别混。
5. **不必实现任何策略模拟**：由步数不变量，Alice 的获胜策略就是「开局选对 + 之后闭眼出安全牌」，代码里只需要计数与判定。

## 5. 正确性证明

以下设 Alice 开局打余 $a \in \{1,2\}$（$c_a \ge 1$），$b = 3 - a$，$L$ 为主战线长度（§3.3 表）。步数从 $1$ 起编号，Alice 执行奇数步。

**引理 1（安全出牌）**：和 $\equiv r \in \{1,2\}$ 时，打余 $r$ 安全（和 $\to 2r \equiv -r \not\equiv 0$），打余 $3-r$ 立刻输（和 $\to 0$），打余 $0$ 安全（和不变）；和 $\equiv 0$（开局）时打余 $0$ 立刻输，打余 $1$ 或 $2$ 安全。

**证明**：对 $r, v \in \{0,1,2\}$ 逐一验证 $(r + v) \bmod 3$ 是否为 $0$，即得上表。∎

**引理 2（主战线锁死）**：在双方不主动打出毒牌的任意对局中，非零牌按序打出的类型序列唯一：第 $1, 2, 4, 6, \dots$ 张为余 $a$，第 $3, 5, 7, \dots$ 张为余 $b$；序列长度 $L$ 与断粮后剩余如 §3.3 表。

**证明**：开局后和 $\equiv a$。归纳：设和 $\equiv r \in \{1,2\}$，由引理 $1$，安全的非零出牌唯一——余 $r$，打出后和 $\equiv 2r$。从 $r = a$ 出发交替得 $r \in a \to b \to a \to b \cdots$（$2a \equiv -a \equiv b$），于是非零牌的位置-类型对应如所述。序列在「下一张所需类型存量耗尽」处截止，数位置即得各行的 $L$ 与剩余：例如 $c_a \le c_b$ 时余 $a$ 牌恰在第 $2c_a$ 位断粮（前 $2c_a - 1$ 位用了 $c_a$ 张 $a$ 与 $c_a - 1 \le c_b$ 张 $b$），故 $L = 2c_a - 1$、余 $b$ 石 $c_b - c_a + 1 \ge 1$；$c_a \ge c_b + 2$ 时余 $b$ 牌在第 $2c_b + 3$ 位断粮，$L = 2c_b + 2$、余 $a$ 石 $c_a - c_b - 2$（为 $0$ 恰当 $c_a = c_b + 2$）。∎

**引理 3（步数不变量）**：若断粮后仍有毒牌存余（表第 $2$ 行：余 $b$ 石 $\ge 1$；第 $5$ 行：余 $a$ 石 $\ge 1$），则无论双方何时垫跳板，**第 $L + c_0 + 1$ 步的执子者**面对「场上非零石全为毒牌」的局面，被迫打出毒牌而输；此前每一步都存在安全着法。故败者恰为第 $L + c_0 + 1$ 步的执子者。

**证明**：跳板不改变和、不推进主战线，故在没人主动寻死的对局里，每一步要么打出主战线的下一张（唯一安全非零牌，引理 1、2），要么消耗一张跳板。于是到「场上只剩毒牌」那一刻，恰有 $L$ 张主战线牌与 $c_0$ 张跳板被打出——**计数与顺序无关**，该时刻即第 $L + c_0 + 1$ 步。此前主战线未断或跳板未空（总出牌数 $< L + c_0$），执子者恒有安全着法；且场上始终留有毒牌，石子不会先被取尽。第 $L + c_0 + 1$ 步的执子者出任何一颗都使和 $\equiv 0$，当场输。胜负归属只依赖 $L + c_0 + 1$ 的奇偶：第 $2$ 行 $L + c_0 + 1 = 2c_a + c_0$，Alice 中招 $\iff c_0$ 奇；第 $5$ 行 $= 2c_b + c_0 + 3$，Alice 中招 $\iff c_0$ 偶。博弈层面：胜方策略为「开局选对，之后只出安全牌」；败方垫跳板不改变计数、主动打毒牌等于当场认输，无从翻盘。∎

**引理 4（取尽结局）**：表第 $3, 4$ 行（$c_a - c_b \in \{1, 2\}$）中，主战线把两类非零牌全部耗光，此后场上只剩跳板；双方都无法逼迫对方打毒牌，游戏必然以取尽收场，且总和 $S \equiv c_1 + 2c_2 \equiv \pm(c_a - c_b) \pmod 3 \not\equiv 0$，触发「取尽判 Bob 胜」。

**证明**：由引理 $2$ 的计数，此两行打完 $L$ 张后余 $a$、余 $b$ 存量均为 $0$，剩余石全为余 $0$，由引理 $1$ 打出恒安全，故此后任何时刻都不存在被逼打毒牌的着法，双方只能把跳板打完，石子取尽。$S$ 的同余式：开余 $1$（$c_a = c_1, c_b = c_2$）时 $S \equiv c_1 + 2c_2 \equiv c_a - c_b$；开余 $2$（$c_a = c_2, c_b = c_1$）时 $S \equiv 2c_a + c_b \equiv -(c_a - c_b)$。$c_a - c_b \in \{1,2\}$ 时两式均 $\not\equiv 0 \pmod 3$。∎

**定理**：Alice 获胜 $\iff$ $\big(c_0$ 偶 $\wedge\, c_1 \ge 1 \wedge c_2 \ge 1\big) \ \vee\ \big(c_0$ 奇 $\wedge\, |c_1 - c_2| \ge 3\big)$。

**证明**：Alice 的开局只有余 $1$、余 $2$ 两种（引理 $1$），她获胜 $\iff$ 某种开局落入 §3.3 表的获胜行（第 $2$、$5$ 行），逐行由引理 $3$、$4$ 定结局：

- $c_0$ 偶：开局 $a$ 获胜 $\iff 1 \le c_a \le c_b$。两种开局取 OR：$(c_1 \ge 1 \wedge c_1 \le c_2) \vee (c_2 \ge 1 \wedge c_2 \le c_1)$。两数中必有较小者，故上式 $\iff c_1 \ge 1 \wedge c_2 \ge 1$。
- $c_0$ 奇：开局 $a$ 获胜 $\iff c_a \ge c_b + 3$。取 OR：$c_1 \ge c_2 + 3 \vee c_2 \ge c_1 + 3 \iff |c_1 - c_2| \ge 3$。

闭式不成立时，两种开局均落入必败行（第 $1, 3, 4$ 行，或奇偶不合的第 $2, 5$ 行），Bob 采用「跟着出安全牌」即可获胜。∎

> 💡 **另一视角**：总和中 $S \equiv c_1 - c_2 \pmod 3$。$c_1 \equiv c_2 \pmod 3$ 时 $S \equiv 0$，游戏**必然**以某人打出毒牌告终，问题只是「谁」——闭式回答的正是这个奇偶问题；而 $c_a - c_b \in \{1, 2\}$ 的开局把博弈推向无人中毒的取尽结局。

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。一趟遍历统计 $c_0, c_1, c_2$；此后的奇偶与大小判定均为 $O(1)$，线性于输入规模，已是下界。
- **空间复杂度**：$O(1)$。仅三个计数变量与常数个中间量（连 DP 表都不需要）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool stoneGameIX(vector<int>& stones) {
        int cnt[3] = {0, 0, 0};
        for (int s : stones) cnt[s % 3]++;      // 只有余数参与
        if (cnt[0] % 2 == 0)
            return cnt[1] > 0 && cnt[2] > 0;    // 跳板成对抵消：两类非零都有
        return cnt[1] - cnt[2] > 2 || cnt[2] - cnt[1] > 2;  // 差 ≥ 3
    }
};
```

### Python

```python
class Solution:
    def stoneGameIX(self, stones: List[int]) -> bool:
        cnt = [0, 0, 0]
        for s in stones:
            cnt[s % 3] += 1
        if cnt[0] % 2 == 0:
            return cnt[1] > 0 and cnt[2] > 0     # c0 偶：两类非零都非空
        return abs(cnt[1] - cnt[2]) >= 3          # c0 奇：差 ≥ 3
```

### Python 备选：按开局逐情形的推导版（与 §5 证明一一对应）

```python
class Solution:
    def stoneGameIX(self, stones: List[int]) -> bool:
        cnt = [0, 0, 0]
        for s in stones:
            cnt[s % 3] += 1
        c0 = cnt[0]

        def check(ca: int, cb: int) -> bool:      # Alice 开局打余 a（b = 3 - a）
            if ca == 0:
                return False                       # 无牌可开
            if ca <= cb:
                return c0 % 2 == 0                 # 决出步 2ca+c0：Bob 中毒 ⇔ c0 偶
            if ca <= cb + 2:
                return False                       # cb+1 / cb+2：非零恰好耗光 → 取尽判负
            return c0 % 2 == 1                     # 决出步 2cb+c0+3：Bob 中毒 ⇔ c0 奇

        return check(cnt[1], cnt[2]) or check(cnt[2], cnt[1])
```

> ⚠️ 备选版必须显式拦截 $c_a = c_b + 2$：把「$c_a \ge c_b + 2$」一锅端成「$c_0$ 奇则胜」，会在 $\lvert c_1 - c_2 \rvert = 2$ 且 $c_0$ 奇的输入上翻车（如 `[3,1,1]`，正确答案 `false`）。

## 8. 边界情况与易错点

1. **$c_a = c_b + 2$ 必败档（头号坑）**：此时主战线恰好把余 $a$ 也全部吃光，场上只剩跳板 → 取尽判 Bob 胜，**与 $c_0$ 奇偶无关**。只区分到「$c_a \ge c_b + 2$ 看奇偶」的错解，在 `[3,1,1]`（$c_0=1, c_1=2, c_2=0$）上会误判 `true`。
2. **「取尽 → Bob 直接获胜」最易漏**：正常博弈「无牌可出者负」的直觉在此失效。示例 2（单颗余 $2$）与 `[3,1,1]` 都是这条规则的直接体现——Alice 唯一的赢法是把毒牌塞给 Bob。
3. **两种开局都要试**（或直接背闭式）：只试开余 $1$ 会漏掉镜像获胜情形，如 $c_0 = 0, c_1 = 2, c_2 = 1$——开余 $1$ 落入 $c_a = c_b + 1$ 必败，开余 $2$ 则胜。
4. **开局打余 $0$ = 自爆**；全部石子余 $0$ 时 Alice 必败（闭式自然给出 `false`，无需特判）。
5. **单侧为空的非零堆**：$c_1 = 0$ 或 $c_2 = 0$ 时，$c_0$ 偶必败；$c_0$ 奇需 $\lvert c_1 - c_2 \rvert \ge 3$——如 `[1,1,1,3]` 为 `true`、`[1,1,3]` 为 `false`，一线之差就在那第三张余 $1$。
6. **$n = 1$ 退化**：单颗石子无论余数几何都是 `false`（取尽或自爆）。
7. **别上博弈 DP**：按计数做状态是 $O(c_0 \cdot c_1 \cdot c_2)$ 爆炸；按石子个体是指数博弈树。本题的全部信息只有三个计数 + 两个奇偶。
8. **别被值域骗**：$1 \le \text{stones}[i] \le 10^4$ 里只有 $\bmod 3$ 的余数参与判定，价值 $5$ 与 $2$ 在博弈中完全等价。
