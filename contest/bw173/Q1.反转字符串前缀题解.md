# LeetCode 反转字符串前缀 题解

## 1. 题目概述

- **标题 / 题号**：反转字符串前缀（#3794，easy）
- **链接**：https://leetcode.cn/problems/reverse-string-prefix/
- **来源**：LeetCode 第 173 场双周赛 Q1
- **难度**：简单
- **标签**：双指针、字符串

**题意**：给定小写字符串 $s$ 与整数 $k$，把 $s$ 的**前 $k$ 个字符**整体反转，其余字符保持原位，返回新字符串。

**约束**：

- $1 \le s.length \le 100$
- $s$ 仅由小写英文字母组成
- $1 \le k \le s.length$

> 💡 签到题的关键是**别手动写循环**：语言内置的反转/切片一步到位，同时注意 $k$ 是**字符数**而不是下标。

## 2. 示例

**示例 1**

```text
输入：s = "abcd", k = 2
输出："bacd"
解释："ab" 反转为 "ba"，拼上未动的 "cd"。
```

**示例 2**

```text
输入：s = "xyz", k = 3
输出："zyx"
解释：k 等于串长，等价于整体反转。
```

**示例 3**

```text
输入：s = "hey", k = 1
输出："hey"
解释：单个字符反转后不变，属于必须返回原串的退化情况。
```

## 3. 解题思路

### 3.1 暴力思路

最直观的写法：把前 $k$ 个字符倒序**追加**到一个新字符串里，再把第 $k$ 位之后的部分原样拼接。这已经是 $O(n)$ 时间、$O(n)$ 空间，对 $n \le 100$ 绰绰有余。真正的"暴力"隐患在实现细节上——手写 `for` 循环时容易把边界写成 `k - 1` 或 `k + 1`，或多拷贝/少拷贝一个字符。因此本题的重点是**用最不容易写错的 API 表达意图**。

### 3.2 核心观察：前缀反转 = 双指针交换一半

![前缀反转：只交换前 k 个字符的首尾配对](images/bw173_q1_prefix_swap.svg)

反转长度为 $k$ 的前缀，只需把第 $0$ 个与第 $k-1$ 个、第 $1$ 个与第 $k-2$ 个……依次交换，直到两个指针相遇。交换的配对数为 $\lfloor k/2 \rfloor$，所以：

- 反转前缀**不会**影响下标 $\ge k$ 的字符；
- $k = 1$ 时配对数为 $0$，什么都不做；
- $k = n$ 时整个串被反转。

这正是 `std::reverse` / `s[:k][::-1]` 的语义，直接调用即可。

### 3.3 算法流程

```text
1. 令 pre = s[0..k-1]，tail = s[k..n-1]
2. 返回 reverse(pre) + tail
```

C++ 里等价写法是 `reverse(s.begin(), s.begin() + k)` 后就地返回 `s`：`s.begin() + k` 指向前缀的**结尾后一位**，正好构成左闭右开区间。

### 3.4 示例演算

![示例演算：k=2 时只交换一对字符](images/bw173_q1_walkthrough.svg)

以 `s = "abcd"`、`k = 2` 为例，指针移动如下：

| 步 | 左指针 | 右指针 | 交换 | 结果 |
|----|--------|--------|------|------|
| 初始 | 0 | 1 | — | `abcd` |
| 1 | 0 | 1 | `a`↔`b` | `bacd` |
| 结束 | 1 | 0 | 指针交错 | `bacd` |

`k = 1` 时初始就有 `left = 0`、`right = 0`，循环体一次都不执行，返回原串；`k = 3` 的 `"xyz"` 则依次交换 `x`↔`z`，得 `"zyx"`。

## 4. 算法细节

1. **区间写法**：C++ `reverse(s.begin(), s.begin() + k)` 的第二个参数是**开区间端点**，所以传 `k` 而不是 `k - 1`。
2. **就地 vs 新建**：C++ 用 `reverse` 就地修改并返回 `s`（题目允许返回新串，就地最省）；Python 用切片 `s[:k][::-1] + s[k:]`，一行完成且不修改入参。
3. **不要用 `k` 当循环上限写错**：如果手写 `for (int i = 0; i < k / 2; i++) swap(s[i], s[k - 1 - i]);`，注意是 `k / 2` 而不是 `(k + 1) / 2`，否则中间字符会被换两次。
4. **字符编码无关**：题面限定小写字母，`std::string` 与 Python `str` 都是单字节/码点一致，反转不会出现半个字符的问题。

## 5. 正确性证明

**引理 1**：对任意 $0 \le i < k$，反转后第 $i$ 个字符等于原串第 $k-1-i$ 个字符。

**证明**：交换过程把 $i$ 与 $k-1-i$ 配对（$0 \le i < \lfloor k/2 \rfloor$），且每对只交换一次，故两者互换；当 $k$ 为奇数时，$i = (k-1)/2$ 与自己配对，保持不变，符合 $k-1-i = i$。∎

**引理 2**：对任意 $i \ge k$，反转后第 $i$ 个字符保持不变。

**证明**：所有交换涉及的右端点最大为 $k-1$，因此下标 $\ge k$ 的位置从未被写入。∎

**定理**：算法输出恰为"前 $k$ 个字符反转、其余不变"的字符串。

**证明**：由引理 1、2，输出串在 $[0, k)$ 上等于原前缀的逆序、在 $[k, n)$ 上等于原后缀；这两部分之并覆盖全部下标且互不重叠，故输出唯一确定，正是题目要求的字符串。∎

## 6. 复杂度分析

- **时间**：$O(n)$。拷贝字符串 $O(n)$，反转前缀 $O(k) \subseteq O(n)$。
- **空间**：$O(n)$（C++ 就地交换只需 $O(1)$ 额外空间，返回 `s` 时有一次拷贝；Python 切片构造新串，$O(n)$）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    string reversePrefix(string s, int k) {
        reverse(s.begin(), s.begin() + k);
        return s;
    }
};
```

### Python

```python
class Solution:
    def reversePrefix(self, s: str, k: int) -> str:
        return s[:k][::-1] + s[k:]
```

## 8. 边界情况与易错点

1. **$k = 1$**：配对数为 $0$，必须原样返回，不能返回空串。
2. **$k = n$**：整体反转，此时 `s.begin() + k == s.end()`，`reverse` 完全合法。
3. **`k` 是长度不是下标**：写成 `s.begin() + k - 1` 会漏掉最后一个字符。
4. **手写循环的上界**：`i < k / 2`，若写成 `i <= k / 2` 会越界交换或把中间字符换两次。
5. **别修改 `k`**：先算 `k` 再动字符串，避免边反转边用被污染的边界。
6. **返回类型是 `string`**：C++ 不要返回 `char*`/`const char*`，Python 不要返回 `list`。
