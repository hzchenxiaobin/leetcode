# LeetCode 统计在矩形格子里移动的路径数目 题解

## 1. 题目概述

- **标题 / 题号**：统计在矩形格子里移动的路径数目（#3797，hard）
- **链接**：https://leetcode.cn/problems/count-routes-to-climb-a-rectangular-grid/
- **来源**：LeetCode 第 173 场双周赛 Q4
- **难度**：困难
- **标签**：数组、动态规划、矩阵、前缀和

**题意**：给定 $n \times m$ 的字符网格（`.` 可用、`#` 阻塞）与整数 $d$。路径从**最后一行**任一可用格出发，到**第一行**任一可用格结束，移动规则：

1. 只能停在可用格上；
2. 每次移动的**欧氏距离** $\le d$；
3. 每次移动要么**留在同一行**（列变化），要么**上移一行**；
4. **不能连续两次留在同一行**：一次"同行移动"之后，下一次移动必须上移一行（除非这就是最后一步）。

求路径总数对 $10^9+7$ 取模。

**约束**：

- $1 \le n, m \le 750$
- $grid[i][j] \in \{'.', '#'\}$
- $1 \le d \le 750$

## 2. 示例

**示例 1**

```text
输入：grid = ["..","#."], d = 1
输出：2
解释：起点只能是 (1,1)。可走：只含 (1,1) 的路径；(1,1) → (0,1)。
      不能走 (1,1) → (0,0)，因为 sqrt(1² + 1²) = √2 > 1。
```

**示例 2**

```text
输入：grid = ["..","#."], d = 2
输出：4
解释：√2 ≤ 2，于是 (1,1) → (0,0) 也可行，另外多出 (1,1)→(0,0) 与 (0,0)→(0,1) 的组合等两条。
```

**示例 3**

```text
输入：grid = ["#"], d = 750
输出：0
解释：最后一行（也是第一行）没有可用格，没有任何起点。
```

**示例 4**

```text
输入：grid = [".."], d = 1
输出：4
解释：四条路径：(0,0)；(0,1)；(0,0)→(0,1)；(0,1)→(0,0)。
      只有一行时，同行移动一次后即结束，不违反“不能连续两次同行”。
```

## 3. 解题思路

### 3.1 暴力思路

把路径看成"从底行到顶行的格子序列"，直接 DFS 枚举所有走法：每个格子可转移到同行的 $O(m)$ 个格子和上一行的 $O(m)$ 个格子，路径数指数级。改成记忆化搜索后每个格子仍要枚举 $O(m)$ 个转移，总复杂度 $O(nm \cdot m) = O(nm^2)$，$750^3 \approx 4.2 \times 10^8$，在 C++ 里勉强但危险，且状态定义稍错就会重复计数。

### 3.2 核心观察：按"上一步是什么移动"分两个状态

![状态设计：上一步上移 → 自由；上一步同行 → 下一步必须上移](images/bw173_q4_state_model.svg)

规则 4 是本题唯一的"记忆"来源：**只关心上一步是不是同行移动**。于是为每个格子 $(r, c)$ 记两个量（从下往上推）：

- $g[r][c]$：从 $(r,c)$ 出发、**下一步任意**（同行或上移，或直接结束）到顶行的路径数；
- $h[r][c]$：从 $(r,c)$ 出发、**下一步必须上移**（上一步是同行移动，或 $r=0$ 只能结束）的路径数。

转移：

$$h[r][c] = \sum_{\substack{(r-1,c')\ \text{可用}\\ 1 + (c-c')^2 \le d^2}} g[r-1][c'] \qquad (r > 0)$$

$$g[r][c] = h[r][c] + \sum_{\substack{(r,c')\ \text{可用},\ c' \ne c\\ \lvert c - c'\rvert \le d}} h[r][c']$$

边界：$r = 0$ 时 $h[0][c] = g[0][c]\big|_{\text{只停不走}} = 1$（到达顶行即结束，同行跳跃仍用它作为终态）。被阻塞格两个值都是 $0$。

**为什么 $g$ 里同行转移的目标用 $h$ 而不是 $g$**：同行移动之后，下一步必须上移，所以后继状态是 $h[r][c']$，这正是规则 4 的编码。

### 3.3 算法流程

![转移的两个窗口都能用前缀和在 O(1) 内求和](images/bw173_q4_transition_window.svg)

两个求和都是**列区间上的连续窗口**：

- 上移窗口半径 $d_v = \lfloor\sqrt{d^2-1}\rfloor$（由 $1 + (c-c')^2 \le d^2$ 解出 $\lvert c-c'\rvert \le \sqrt{d^2-1}$）；
- 同行窗口半径就是 $d$（欧氏距离退化为列差绝对值），但要**排除 $c'=c$（原地不动）**。

因此每行做两次前缀和即可 $O(m)$ 求出整行：

```text
1. dv = floor(sqrt(d^2 - 1))
2. 初始化上一行 g 全 0
3. for r = 0 .. n-1:
       preG = g 的前缀和（上一行的）
       对每个可用列 c：h[c] = r == 0 ? 1 : sum(preG, c-dv, c+dv)
       preH = h 的前缀和
       对每个可用列 c：g[c] = h[c] + (sum(preH, c-d, c+d) − h[c])
       阻塞列 g[c] = 0
4. 返回 sum(g) over 最后一行
```

由于 $g$ 逐行覆盖，只需要保留"上一行"和"本行"两个数组。

### 3.4 示例演算

![演算：grid = ["..","#."], d = 2](images/bw173_q4_walkthrough.svg)

以示例 2（`d = 2`）为例：

| 行 | 列 | $h$ | $g$ | 说明 |
|----|----|-----|-----|------|
| 0 | 0 | 1 | 2 | 可停留，也可跳到 (0,1) 再停 |
| 0 | 1 | 1 | 2 | 镜像同上 |
| 1 | 0 | 0 | 0 | 阻塞 |
| 1 | 1 | 4 | 4 | 上移可到 (0,0)、(0,1)，各 2 条 |

第 1 行只有一列可用，同行窗口内没有别的格子，所以 $g = h = 2 + 2 = 4$，答案 4，与示例一致。注意 $d=2$ 时 $d_v = \lfloor\sqrt{3}\rfloor = 1$，即上移允许列偏移 $-1, 0, 1$；示例 1 的 $d=1$ 则 $d_v = 0$，只能垂直上移。

## 4. 算法细节

1. **$d_v$ 的计算**：$d_v = \lfloor\sqrt{d^2-1}\rfloor$，用整数循环求（`while ((dv+1)^2 <= d*d-1) dv++`），避免浮点误差；$d=1$ 时 $d_v=0$。
2. **两个前缀和不能混用**：$h$ 用的是**上一行** $g$ 的前缀和，$g$ 用的是**本行** $h$ 的前缀和，且本行前缀和必须**整行算完**再查区间（否则右半边的 $h$ 还没算出来）。
3. **同行转移排除原地**：`sum(preH, c-d, c+d) - h[c]`，漏掉这个减法会把"停在原地"计入，示例 4 会从 4 变成 8 以上。
4. **取模与减法**：先 `% MOD` 再 `+MOD` 再 `% MOD`，C++ 中负数取模为负，务必修正。
5. **阻塞格**：$h$、$g$ 都置 0，且不能作为转移的源或目标（前缀和里它们贡献 0，天然被排除）。
6. **答案是最后一行所有可用格的 $g$ 之和**，不是单个格子的值。
7. **整型**：中间量 $< MOD$，两数相减可放 `long long` 或按上面的写法修正；乘只在 $d^2$ 处出现（$750^2$ 在 `int` 范围内，但仍建议用 `1LL*d*d`）。

## 5. 正确性证明

**引理 1（状态完备）**：任何一条合法路径在任意格子 $(r,c)$ 处，其"下一步可用的移动集合"只取决于它是从同行移动还是从上移到达的。

**证明**：规则 3 与规则 4 只涉及"上一步是否同行"这一比特信息；路径的其余历史不影响后续可走性（格子可用性与距离限制都与历史无关）。∎

**引理 2（转移枚举完备且不重）**：$g[r][c]$ 的表达式恰好枚举了从 $(r,c)$ 出发的所有合法首步，且每种首步对应的后续路径与 $h/g$ 一一对应。

**证明**：首步只有三类：结束（仅当 $r=0$，计入 $h[0][c]=1$）、同行到 $(r,c')$、上移到 $(r-1,c')$。同行与上移分别由第二、第一个求和枚举，列条件分别是 $\lvert c-c'\rvert \le d$ 与 $1+(c-c')^2 \le d^2$（即距离 $\le d$）。由于按首步的**终点格子**划分，各类互不相交；同行后下一步必须上移，故续接 $h[r][c']$，上移后续接 $g[r-1][c']$（下一步自由）。∎

**定理**：算法输出的 $\sum_c g[n-1][c]$ 等于题目要求的路径数。

**证明**：对行号 $r$ 归纳：假设第 $r-1$ 行及以上的 $g$ 值均正确，则由引理 1、2 及转移式，$h[r][\cdot]$ 与 $g[r][\cdot]$ 正确。基例 $r=0$：$h[0][c]=1$ 对应"停在顶行结束"，$g[0][c] = 1 + (\text{同行可达的 } h[0][c'])$，与示例 4 的 4 条路径一致。故第 $n-1$ 行的 $g$ 全部正确，对其求和即得所有从底行可用格出发的路径总数。取模不改变计数语义（模运算与加法同态）。∎

## 6. 复杂度分析

- **时间**：$O(nm)$。每行两次前缀和 $O(m)$，两次窗口查询各 $O(m)$；$d_v$ 的计算是 $O(\sqrt{d})$。
- **空间**：$O(m)$。只保留上一行 $g$ 与本行 $h$、$g$ 及两个前缀和数组，共 $O(m)$；不随 $n$ 增长。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int numberOfRoutes(vector<string>& grid, int d) {
        const int MOD = 1000000007;
        int n = grid.size(), m = grid[0].size();
        // 竖直移动允许的列偏移上限: 1 + dc^2 <= d^2
        long long limit = 1LL * d * d - 1;
        int dv = 0;
        while ((long long)(dv + 1) * (dv + 1) <= limit) dv++;

        vector<long long> h(m, 0), g(m, 0);       // 当前行 / 上一行
        vector<long long> preG(m + 1, 0), preH(m + 1, 0);
        for (int r = 0; r < n; r++) {
            // h[c]: 下一步必须向上（或在此结束）
            for (int c = 0; c < m; c++) {
                if (grid[r][c] == '#') { h[c] = 0; continue; }
                if (r == 0) { h[c] = 1; continue; }
                int lo = max(0, c - dv), hi = min(m - 1, c + dv);
                h[c] = ((preG[hi + 1] - preG[lo]) % MOD + MOD) % MOD;
            }
            // 本行 h 的前缀和（必须先整行算完再查区间）
            preH[0] = 0;
            for (int c = 0; c < m; c++) preH[c + 1] = (preH[c] + h[c]) % MOD;
            for (int c = 0; c < m; c++) {
                if (grid[r][c] == '#') { g[c] = 0; continue; }
                int lo = max(0, c - d), hi = min(m - 1, c + d);
                long long stay = (preH[hi + 1] - preH[lo]) % MOD;
                stay = ((stay - h[c]) % MOD + MOD) % MOD;  // 排除原地不动
                g[c] = (h[c] + stay) % MOD;
            }
            // 用 g 重建上一行（本轮结果即下一轮 r+1 的“上一行”）
            preG[0] = 0;
            for (int c = 0; c < m; c++) preG[c + 1] = (preG[c] + g[c]) % MOD;
        }
        long long ans = 0;
        for (int c = 0; c < m; c++) ans = (ans + g[c]) % MOD;
        return (int)ans;
    }
};
```

### Python

```python
class Solution:
    def numberOfRoutes(self, grid: list[str], d: int) -> int:
        MOD = 10 ** 9 + 7
        n, m = len(grid), len(grid[0])
        dv = 0
        limit = d * d - 1
        while (dv + 1) * (dv + 1) <= limit:
            dv += 1

        g = [0] * m          # 上一行（r-1）的解
        for r in range(n):
            pre_g = [0] * (m + 1)
            for c in range(m):
                pre_g[c + 1] = (pre_g[c] + g[c]) % MOD
            h = [0] * m
            for c in range(m):
                if grid[r][c] == '#':
                    continue
                if r == 0:
                    h[c] = 1
                else:
                    lo = max(0, c - dv)
                    hi = min(m - 1, c + dv)
                    h[c] = (pre_g[hi + 1] - pre_g[lo]) % MOD
            pre_h = [0] * (m + 1)
            ng = [0] * m
            for c in range(m):
                pre_h[c + 1] = (pre_h[c] + h[c]) % MOD
            for c in range(m):
                if grid[r][c] == '#':
                    continue
                lo = max(0, c - d)
                hi = min(m - 1, c + d)
                stay = (pre_h[hi + 1] - pre_h[lo] - h[c]) % MOD
                ng[c] = (h[c] + stay) % MOD
            g = ng
        return sum(g) % MOD
```

## 8. 边界情况与易错点

1. **$d=1$**：$d_v=0$，上移只能同列；若写成 $\lfloor\sqrt{d^2}\rfloor = 1$ 就会多算对角上移，示例 1 会变成 4。
2. **只有一行**：$r=0$ 全是 $h=1$，$g = 1 + $同行可达数，示例 4 得 4，不能因为"无法上移"而返回 0。
3. **阻塞格**：必须同时清空 $h$ 与 $g$，否则它会被前缀和带进别处的转移。
4. **原地不动**：同行窗口必须减去 $h[c]$；`c' = c` 不是"移动到另一个可用单元格"。
5. **前缀和顺序**：先算完整行 $h$ 再做 $g$ 的区间查询，否则右侧列读到 0（这是最容易写错、且本地样例里"有时对有时错"的坑）。
6. **负取模**：C++ 里 `(a - b) % MOD` 可能为负，统一用 `((x % MOD) + MOD) % MOD`。
7. **答案求和范围**：只累加最后一行的可用格；把整个 $g$ 数组求和会重复计数。
8. **`d` 可能大于 $m$**：窗口 `lo/hi` 要用 `max/min` 夹住，否则越界。
