# LeetCode 不同元素和至少为 K 的最短子数组长度 题解

## 1. 题目概述

- **标题 / 题号**：不同元素和至少为 K 的最短子数组长度（#3795，medium）
- **链接**：https://leetcode.cn/problems/minimum-subarray-length-with-distinct-sum-at-least-k/
- **来源**：LeetCode 第 173 场双周赛 Q2
- **难度**：中等
- **标签**：数组、哈希表、滑动窗口

**题意**：给定整数数组 `nums` 与整数 $k$，求一个**连续非空子数组**的最小长度，使得子数组中**不同值之和**（每个不同的值只累加一次）$\ge k$；不存在则返回 $-1$。

**约束**：

- $1 \le nums.length \le 10^5$
- $1 \le nums[i] \le 10^5$
- $1 \le k \le 10^9$

> ⚠️ 注意 $k$ 可以远大于单个元素：最长情况下窗口内不同值之和可达 $10^5 \times 10^5 = 10^{10}$，**必须用 64 位整数**（C++ `long long`，Python 无需处理）。

## 2. 示例

**示例 1**

```text
输入：nums = [2,2,3,1], k = 4
输出：2
解释：[2,3] 的不同元素为 {2,3}，和为 5 ≥ 4；长度 1 的窗口不同元素和最多为 3 < 4。
```

**示例 2**

```text
输入：nums = [3,2,3,4], k = 5
输出：2
解释：[3,2] 的不同元素和为 5，恰好达标；重复的 3 不重复计数。
```

**示例 3**

```text
输入：nums = [5,5,4], k = 5
输出：1
解释：单个 [5] 的不同元素和已是 5 ≥ k。
```

## 3. 解题思路

### 3.1 暴力思路

枚举左右端点 $l \le r$，用哈希表统计区间内的不同值并求和，复杂度 $O(n^2)$。$n = 10^5$ 时是 $10^{10}$ 次操作，必然超时。但暴力揭示了一个有用的性质：**每个区间只有"不同值集合"这一份信息**，而集合只随区间扩张单调增。

### 3.2 核心观察：固定右端点后，不同元素和对左端点单调

![滑动窗口：维护不同值计数与不同元素和](images/bw173_q2_window_model.svg)

固定右端点 $r$，定义

$$f(l) = \sum_{v \in \text{distinct}(nums[l..r])} v$$

于是有：

- **单调性**：$f(l)$ 随 $l$ 增大而**不增**（区间变短，不同值集合只会缩小）；
- **可增量维护**：右端点右移时，若 `nums[r]` 是新值就加上它；左端点右移时，只有当该值在窗口内**计数降为 0** 时才减去它。

由于 $f$ 关于 $l$ 单调不增，"满足 $f(l) \ge k$ 的最小长度"就等价于"满足条件的**最大** $l$"，可以双指针一趟扫完。

### 3.3 算法流程

![算法流程：扩张右端、能缩就缩、随时更新答案](images/bw173_q2_algorithm_flow.svg)

```text
1. cnt = 空哈希表；sum = 0；l = 0；ans = ∞
2. for r = 0 .. n-1:
       cnt[nums[r]] += 1；若这是首次出现，sum += nums[r]
       while sum - (cnt[nums[l]] == 1 ? nums[l] : 0) >= k:
           移除 nums[l]：cnt 减 1，计数归 0 时 sum 减去该值；l += 1
       if sum >= k: ans = min(ans, r - l + 1)
3. 返回 ans（若从未更新则返回 -1）
```

**关键点**：`while` 的条件是"**放弃左端点后仍然达标**"，因此循环结束后 $[l, r]$ 是**以 $r$ 结尾的最短达标窗口**。`l` 只增不减，总移动次数 $O(n)$。

### 3.4 示例演算

![示例演算：nums = [2,2,3,1], k = 4 的窗口变化](images/bw173_q2_walkthrough.svg)

| $r$ | 加入 | 窗口 $[l,r]$ | 不同元素和 | 收缩过程 | 当前最短 |
|-----|------|--------------|------------|----------|----------|
| 0 | 2 | [0,0] | 2 | 放弃 2 后为 0 < 4，不缩 | — |
| 1 | 2 | [0,1] | 2 | 同上 | — |
| 2 | 3 | [0,2] | 5 | 放弃 2 后为 3 < 4，不缩 | 3 |
| 3 | 1 | [0,3] | 6 | 依次放弃 2、2、3：剩 {1} 和 = 1 < 4 时停止 | 2 |

第 3 步收缩到 `[2,3] = [3,1]` 时不同元素和为 4，长度 2，因此答案为 2。注意示例 1 的官方解释给出 `[2,3]`，而 `[3,1]` 同样达标，最短长度一致——本题只问长度，不问具体区间。

## 4. 算法细节

1. **计数与求和分离**：`sum` 维护"不同元素之和"，`cnt[x]` 维护窗口内 $x$ 的出现次数，两者必须同步更新，否则会把重复元素重复计入。
2. **收缩判定要"预判"**：`while` 里先用"假设移除左端点后的和"判断，而不是先移除再判断，否则会丢掉合法的最短窗口（例如 `[5]` 恰好等于 $k$ 时会缩成空窗口）。
3. **64 位整型**：$k \le 10^9$ 但窗口不同元素和可达 $10^{10}$，C++ 必须 `long long`，否则溢出后比较结果不可信。
4. **哈希表 vs 桶**：$nums[i] \le 10^5$，可以开 `vector<int> cnt(100001)`，比 `unordered_map` 更快；Python 用 `defaultdict(int)` 即可。
5. **`l` 单调不回退**：这是双指针 $O(n)$ 的核心，若允许 `l` 回退则退化为 $O(n^2)$。
6. **答案初值**：用 $n+1$（或 `INT_MAX`）作为"无解"哨兵，最后统一判断。

## 5. 正确性证明

**引理 1（单调性）**：固定 $r$，$f(l)$ 关于 $l$ 单调不增。

**证明**：$l_1 < l_2$ 时，区间 $[l_2, r] \subseteq [l_1, r]$，其不同值集合是不超过原集合的子集，且所有元素为正，故 $f(l_2) \le f(l_1)$。∎

**引理 2（收缩的正确性）**：对固定的 $r$，算法结束时 `l` 是使 $f(l) \ge k$ 成立的最大左端点（若存在）。

**证明**：算法只在"移除 `nums[l]` 后仍达标"时才执行 `l++`，因此结束时要么 $l = r$ 且 $f(l) < k$（此时所有左端点都不达标，窗口无解），要么 $f(l) \ge k$ 而 $f(l+1) < k$（若 $l < r$）。结合引理 1 的单调性，"$\ge k$"的解集是形如 $[0, l^*]$ 的前缀，故 $l = l^*$ 即为最大左端点。∎

**引理 3（跨 $r$ 的正确性）**：算法不会漏掉任何以 $r' < r$ 结尾的最优窗口。

**证明**：每个 $r'$ 都在其自己的迭代中处理，并当轮更新 `ans`；后续迭代中 `l` 只增，不影响历史答案。∎

**定理**：算法返回的长度等于所有满足"不同元素和 $\ge k$"的子数组长度的最小值；不存在时返回 $-1$。

**证明**：由引理 2，对每个 $r$，`[l, r]` 是以 $r$ 结尾的**最短**达标窗口（长度最小）；由引理 3，算法对全部 $r$ 都做了这样的判断，故 `ans` 取遍所有右端点的最短达标长度并取最小，即为全局最小值。所有窗口都不达标时 `ans` 保持哨兵值，返回 $-1$。∎

## 6. 复杂度分析

- **时间**：$O(n)$。右指针前进 $n$ 次；左指针 `l` 从 $0$ 单调走到 $n$，总移动不超过 $n$ 次；每次哈希表操作均摊 $O(1)$。
- **空间**：$O(D)$，$D$ 为不同值的个数，$D \le \min(n, 10^5)$；用桶数组时是 $O(\max nums)$ 的定长空间。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minLength(vector<int>& nums, int k) {
        int n = nums.size();
        unordered_map<int, int> cnt;
        long long sum = 0;
        int ans = INT_MAX;
        int l = 0;
        for (int r = 0; r < n; r++) {
            if (cnt[nums[r]]++ == 0) sum += nums[r];
            while (sum - (cnt[nums[l]] == 1 ? nums[l] : 0) >= k) {
                if (--cnt[nums[l]] == 0) sum -= nums[l];
                l++;
            }
            if (sum >= k) ans = min(ans, r - l + 1);
        }
        return ans == INT_MAX ? -1 : ans;
    }
};
```

### Python

```python
class Solution:
    def minLength(self, nums: list[int], k: int) -> int:
        from collections import defaultdict
        n = len(nums)
        cnt = defaultdict(int)
        window_sum = 0
        ans = n + 1
        l = 0
        for r in range(n):
            if cnt[nums[r]] == 0:
                window_sum += nums[r]
            cnt[nums[r]] += 1
            while window_sum - (nums[l] if cnt[nums[l]] == 1 else 0) >= k:
                cnt[nums[l]] -= 1
                if cnt[nums[l]] == 0:
                    window_sum -= nums[l]
                l += 1
            if window_sum >= k:
                ans = min(ans, r - l + 1)
        return -1 if ans == n + 1 else ans
```

## 8. 边界情况与易错点

1. **单元素恰好达标**：如 `nums = [5], k = 5`，`while` 的条件必须用"移除后是否仍达标"来判断，否则会把窗口缩空导致返回 $-1$。
2. **重复元素不重复计数**：`[2,2,3]` 的不同元素和是 5 而不是 7，计数降到 0 才能从 `sum` 里减。
3. **全部元素之和仍不足 $k$**：例如 `nums = [1,1,1], k = 100`，返回 $-1$。
4. **溢出**：$k$ 最大 $10^9$，但窗口内不同元素和最大 $10^{10}$，C++ 用 `long long`，比较时不要与 `int` 混用。
5. **`cnt[nums[l]]` 的访问**：C++ 用 `unordered_map` 时 `cnt[x]` 会插入 0 值键，注意 `sum` 的更新只在"原本为 0 / 减到 0"时发生。
6. **`l` 越过 `r`**：本算法中 `l <= r` 恒成立（`while` 条件保证移除后仍需达标），但仍建议用 `l < r` 的等价写法自查一遍。
