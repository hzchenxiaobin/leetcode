# LeetCode 递枕头 题解

## 1. 题目概述

- **标题 / 题号**：递枕头（#2582，easy）
- **链接**：https://leetcode.cn/problems/pass-the-pillow/
- **来源**：LeetCode 第 335 场周赛 Q1
- **难度**：简单
- **标签**：数学、模拟

**题意**：$n$ 个人站成一排，按 $1 \sim n$ 编号，$1$ 号最初拿着枕头并向右传递。每过一秒，枕头移动到相邻的人手中；一旦到达**队首（$1$ 号）或队尾（$n$ 号）**，传递方向**反转**。求 `time` 秒后拿着枕头的人的编号。

**约束**：

- $2 \le n \le 1000$
- $1 \le \text{time} \le 1000$

> 💡 官方在题面注明：本题与 [3178. 找出 K 秒后拿着球的孩子](https://leetcode.cn/problems/find-the-child-who-has-the-ball-after-k-seconds/)（第 401 场周赛 Q1）**完全一致**，只是把球换成枕头、编号从 $0$ 起数改成 $1$ 起数。"折返 + 取周期"的套路直接复用，两题答案恰差一个 $+1$ 平移。

## 2. 示例

**示例 1**

```text
输入：n = 4, time = 5
输出：2
解释：传递序列为 1 → 2 → 3 → 4 → 3 → 2（每秒一步），
      第 3 秒枕头抵达队尾 4 号后折返，第 5 秒末在 2 号手中。
```

**示例 2**

```text
输入：n = 3, time = 2
输出：3
解释：1 → 2 → 3。time < n，枕头还在去程，
      第 2 秒末恰好传到队尾 3 号手中。
```

**示例 3（time 很大，跨多个周期）**

```text
输入：n = 2, time = 1000
输出：1
解释：周期 T = 2(2−1) = 2，r = 1000 mod 2 = 0 < n，
      枕头恰回到 1 号手中。奇数秒在 2 号、偶数秒在 1 号。
```

## 3. 解题思路

### 3.1 暴力思路：按秒模拟

维护当前位置 `pos` 与方向 `d`（$+1$ 向右、$-1$ 向左），每秒走一步，到达端点就调头：

```python
pos, d = 1, 1
for _ in range(time):
    pos += d
    if pos == 1 or pos == n:
        d = -d
return pos
```

- 时间 $O(\text{time})$、空间 $O(1)$。本题 $\text{time} \le 1000$，**模拟就是最稳的签到写法**，两分钟写完零风险。
- 但"往返折叠"套路的价值在大数据场景：一旦 $\text{time} \le 10^{18}$（同款换皮题 3178 的进阶考察方向），逐秒模拟直接超时，必须挖出运动规律做 $O(1)$ 计算。

### 3.2 核心观察：周期 $2(n-1)$ + 折返折叠

![核心观察：折返周期模型](images/pillow_pass_bounce_model.svg)

枕头的运动就是**弹球/三角波**：去程 $n-1$ 秒从 $1$ 走到 $n$，回程 $n-1$ 秒从 $n$ 走回 $1$，合计

$$T = 2(n-1) \text{ 秒}$$

回到"位置 $1$ + 方向向右"的**初始状态**，此后逐秒重复。因此答案只取决于余数 $r = \text{time} \bmod 2(n-1)$：

- $r < n$：枕头还在去程（含恰好抵达队尾的 $r = n-1$），从 $1$ 号向右走了 $r$ 步，答案为 $r + 1$；
- $r \ge n$：枕头已折返，等价于从队尾 $n$ 往回走 $r-(n-1)$ 步，答案为 $n - (r-(n-1)) = 2(n-1) - r + 1$。

与 0 编号版（3178）对照：两支公式都恰好**整体 $+1$**，正是编号平移的体现。

### 3.3 算法流程：取模 + 一次比较 + 平移

![O(1) 公式流程](images/pillow_pass_formula_flow.svg)

1. 计算周期 $period = 2(n-1)$；
2. 取余数 $r = \text{time} \bmod period$；
3. 若 $r < n$ 返回 $r + 1$，否则返回 $period - r + 1$。

两个分支可以合并成 $\min(r,\ 2(n-1)-r) + 1$；比赛现场写显式分支最不易错。

### 3.4 示例演算

![示例走查：n=4, time=5](images/pillow_pass_walkthrough.svg)

以 $n = 4,\ \text{time} = 5$ 为例，$period = 6$，一个周期内持枕头的人如下：

| $t$ | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
|-----|---|---|---|---|---|---|---|
| 位置 | 1 | 2 | 3 | 4 | 3 | **2** | 1 |
| 下一秒方向 | → | → | → | ← | ← | ← | → |

$r = 5 \bmod 6 = 5 \ge n = 4$，已折返，$ans = 6 - 5 + 1 = 2$，与示例 1 一致。再验一例：$n = 3,\ \text{time} = 2$，$period = 4$，$r = 2 < 3$，$ans = 2 + 1 = 3$ ✓。

## 4. 算法细节

1. **周期为什么是 $2(n-1)$ 而不是 $2n$**：端点反转意味着去程 $1 \to n$ 需要 $n-1$ 秒、回程再 $n-1$ 秒，端点各只"经过"一次。$t = 2(n-1)$ 时（位置, 方向）与 $t = 0$ 完全一致，这是能对 `time` 直接取模的依据。
2. **余数分段**：$r \in [0, 2(n-1))$。$r < n$ 覆盖整个去程（含恰好在队尾的 $r = n-1$，此时两个分支公式取值相同，均为 $n$）；$r \ge n$ 为折返段。
3. **1 编号的 $+1$ 平移**：去程"从 $1$ 走 $r$ 步"得到 $r+1$ 而非 $r$；折返支 $2(n-1)-r+1$ 同理。这是本题相对 0 编号版唯一的"新意"，也是最易翻车点。
4. **免分支合并**：$ans = \min(r,\ 2(n-1)-r) + 1$，两段折线关于 $r = n-1$ 对称。
5. **数据类型**：$n, \text{time} \le 1000$，`int` 绰绰有余；推广到 $\text{time} \le 10^{18}$ 时换 `long long`（Python 天然大数），公式不变。

## 5. 正确性证明

**引理 1（首周期轨迹）**：对 $0 \le t \le 2(n-1)$，有 $\text{pos}(t) = t + 1$（当 $t \le n-1$），$\text{pos}(t) = 2(n-1) - t + 1$（当 $t \ge n-1$）。

**证明**：归纳去程：$t < n-1$ 时枕头尚未到达任何端点，方向保持向右，每秒位置 $+1$，故 $\text{pos}(t) = t + 1$。$t = n-1$ 时枕头到达队尾 $n$，方向翻转向左；随后每秒位置 $-1$，对 $n-1 \le t \le 2(n-1)$ 有 $\text{pos}(t) = n - (t - (n-1)) = 2(n-1) - t + 1$。两式在 $t = n-1$ 处均取值 $n$，衔接无跳变。∎

**引理 2（周期复原）**：对一切 $t \ge 0$，$\text{pos}(t + 2(n-1)) = \text{pos}(t)$。

**证明**：由引理 1，$t = 2(n-1)$ 时枕头位于 $1$ 号，且该秒末在队首发生翻转、方向变为向右——与 $t = 0$ 时的（位置, 方向）完全相同。传递规则是确定性的：下一秒的状态只由当前（位置, 方向）决定。因此从 $t = 2(n-1)$ 起的运动与从 $t = 0$ 起逐秒相同，对 $t$ 归纳即得结论。∎

**定理**：`time` 秒后持枕头的人的编号为

$$\text{ans} = \begin{cases} r + 1, & r < n \\ 2(n-1) - r + 1, & r \ge n \end{cases} \quad\text{其中 } r = \text{time} \bmod 2(n-1).$$

**证明**：写 $\text{time} = q \cdot 2(n-1) + r$，$0 \le r < 2(n-1)$。对 $q$ 归纳：$q = 0$ 时即引理 1；设 $q$ 成立，则第 $q \cdot 2(n-1)$ 秒的状态与初始状态相同，由引理 2 的确定性论证，再经过 $r$ 秒的位置等于 $\text{pos}(r)$。故 $\text{pos}(\text{time}) = \text{pos}(r)$，代入引理 1 的分段公式即得。∎

## 6. 复杂度分析

- **时间复杂度**：$O(1)$。一次取模、一次比较、至多一次减法与一次加法。
- **空间复杂度**：$O(1)$。仅常数个变量。
- 模拟解法为 $O(\text{time})$ 时间、$O(1)$ 空间，本题约束下同样通过；$O(1)$ 公式的价值在于 `time` 高达 $10^{18}$ 时依然成立。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int passThePillow(int n, int time) {
        int period = 2 * (n - 1);
        int r = time % period;
        return r < n ? r + 1 : period - r + 1;
    }
};
```

### Python

```python
class Solution:
    def passThePillow(self, n: int, time: int) -> int:
        period = 2 * (n - 1)
        r = time % period
        return r + 1 if r < n else period - r + 1
```

## 8. 边界情况与易错点

1. **$n = 2$（最小 $n$）**：周期为 $2$，$r = \text{time} \bmod 2 \in \{0, 1\}$，恒有 $r < n$，$ans = r + 1$。奇数秒枕头在 $2$ 号、偶数秒在 $1$ 号，公式无需特判。
2. **`time` 恰为周期整数倍**：$r = 0 \Rightarrow ans = 1$，枕头恰好回到起点，符合直觉。
3. **忘写 $+1$（本题头号易错点）**：这是 1 编号题，直接照抄 0 编号公式返回 $r$ 或 $period - r$ 会整体少 $1$——如 $n=4,\ \text{time}=5$ 会算出 $1$ 而非正确答案 $2$。交前务必用示例 1 自查。
4. **必须先取模**：直接套 $2(n-1) - \text{time} + 1$ 而不取模，当 `time` 超过一个周期会得到非正数。
5. **周期别写成 $n$ 或 $2n$**：以 $n=4,\ \text{time}=5$ 为反例，按 $2n = 8$ 得 $r = 5$、$ans = 8 - 5 + 1 = 4$，并非正确答案 $2$；按 $n = 4$ 得 $r = 1$、$ans = 2$ 碰巧对，但换成 $n = 4,\ \text{time} = 6$ 就会算出 $3$（正确答案 $1$）。
6. **模拟时先移动再翻转**：`pos += d` 之后再判端点翻 `d`；顺序写反枕头会卡在端点来回抖动，用 $n=3$ 手玩前 5 秒即可自查。
