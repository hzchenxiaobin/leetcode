# LeetCode 分割数组使乘积互质 题解

## 1. 题目概述

- **标题 / 题号**：分割数组使乘积互质（#2584，hard）
- **链接**：https://leetcode.cn/problems/split-the-array-to-make-coprime-products/
- **来源**：LeetCode 第 335 场周赛 Q3
- **难度**：困难
- **标签**：数组、哈希表、数学、数论、质因数分解

**题意**：给定长度为 $n$、下标从 0 开始的整数数组 `nums`。在下标 $i$（$0 \le i \le n-2$）处分割数组，若前 $i+1$ 个元素的乘积与剩余元素的乘积**互质**（$\gcd = 1$），则该分割**有效**。返回**最小**的有效分割下标 $i$；不存在则返回 $-1$。

**约束**：

- $1 \le n \le 10^4$
- $1 \le \text{nums}[i] \le 10^6$

> 📚 本题在本仓库另有[每日题解 2584](../../solution/2501-2600/2584_分割数组使乘积互质.md)：以「互质 ⟺ 质因子集不相交」+ [763. 划分字母区间](https://leetcode.cn/problems/partition-labels/) 同构的右边界推进为主线，含面试问答；本篇侧重赛时切入路径、**质数「封锁带」刻画 + 按起点聚合的一次扫描**，以及逐条引理的完整证明。

> 💡 **赛时定位**：本场 Q3、Q4 双双挂困难（少见），Q3 是第一道坎。「乘积」「互质」两个关键词应立刻条件反射到**质因数域**——乘积级的问题几乎都要降维到质数层面处理。剩下的工程问题只有一个：怎么把「每个质数不得跨过分割线」这堆约束组织成一次线性扫描。


## 3. 解题思路

### 3.1 暴力思路：直接算乘积再 gcd

对每个 $i \in [0, n-2]$ 计算前缀积与后缀积、求 gcd：

1. **溢出**：乘积可达 $(10^6)^{10^4} = 10^{60000}$，约 6 万位十进制数字，远超 `long long`（$\approx 9.2 \times 10^{18}$，约 $10^{19}$），C++ 根本存不下；
2. **大数 gcd 也救不了**：即便 Python 能表示大整数，单次 gcd 的代价与位数线性相关，$O(n)$ 次大数 gcd 合计天文数字级的操作，必然超时。

退一步，先分解质因数、再对每个分割点逐一检查「是否有质数两侧都出现」：设 $P$ 为整个数组出现过的不同质数总数（$n\omega \le 7 \times 10^4$），逐点独立检查是 $O(n \cdot P) \approx 7 \times 10^8$，依然不可接受。瓶颈不在分解，而在**逐分割点独立检查**——必须把所有质数的约束**一次性**组织成可线性扫描的结构。

### 3.2 核心观察：质数的出现区间是「封锁带」

![核心观察：质数出现区间像封锁带，压住的剪刀位全部无效](images/coprime_split_prime_intervals.svg)

由**唯一分解定理**，两个乘积互质 $\iff$ **没有公共质数**（重数无关：$4 = 2^2$、$8 = 2^3$ 都只贡献「质数 2 出现」）。于是分割 $i$ 有效 $\iff$ **每个质数的全部出现位置都落在分割线同一侧**。对每个质数 $p$，只需关心两个量：

$$\text{first}[p] = p \text{ 整除某元素的最小下标}, \qquad \text{last}[p] = p \text{ 整除某元素的最大下标}$$

分割 $i$ **无效** $\iff$ 存在 $p$ 使 $\text{first}[p] \le i < \text{last}[p]$——剪刀落在质数 $p$ 的封锁带 $[\text{first}[p], \text{last}[p]]$ **内部**。两个直接推论：

1. **单格质数不封锁**：$\text{first}[p] = \text{last}[p]$ 的质数（如示例 1 的 7，只在下标 1 出现）不封锁任何分割点——怎么剪都在同一侧；
2. **约束只与区间有关**：质数在区间内部出现多少次、以什么幂次出现，统统无关紧要，问题化归为**一维区间覆盖**。

> 💡 这幅画面与 [763. 划分字母区间](https://leetcode.cn/problems/partition-labels/) 同构（字母 ↔ 质数，「同一字母同一段」↔「同一质数同侧」）。每日题解正是从这条线切入；本篇换一个对实现更友好的组织方式——**按起点聚合 + 一次扫描**，扫描阶段完全不再碰质因数。

### 3.3 算法流程：first/last + startMax + reach 一次扫描

![算法流程：SPF 筛、记录 first/last、按起点聚合 startMax、reach 扫描判定](images/coprime_split_algo_flow.svg)

定义 $R(i) = \max\{\,\text{last}[p] : \text{first}[p] \le i\,\}$（空集取 $-1$），则分割 $i$ 有效 $\iff R(i) \le i$（引理 2 证明）。关键是 $R$ 随 $i$ 右移**只增不减**，且增量只来自「起点恰为 $i$」的质数——把质数按起点分桶：

$$\text{startMax}[j] = \max\{\, \text{last}[p] : \text{first}[p] = j \,\}$$

从左往右扫 $i = 0 \dots n-2$，维护 $\text{reach} = \max(\text{reach}, \text{startMax}[i])$，**首个 $\text{reach} \le i$ 的位置即答案**；扫完未命中则返回 $-1$。

1. **SPF 筛**：埃氏变体求 $[2, \max(\text{nums})]$ 的最小质因子表，之后单个元素 $O(\omega)$ 次查表即可分解（$\omega \le 7$，见 §6）；
2. **一遍分解**：对每个 $j$ 提取 $\text{nums}[j]$ 的不同质数，更新 $\text{first}[p] / \text{last}[p]$；
3. **按起点聚合**：$\text{startMax}[\text{first}[p]] \gets \max(\cdot, \text{last}[p])$；
4. **一次扫描**：$i$ 从 $0$ 到 $n-2$，$\text{reach} \gets \max(\text{reach}, \text{startMax}[i])$，$\text{reach} \le i$ 即返回 $i$。

> 💡 **与「两遍扫描 + 边扫边分解」的差别**（每日题解的做法）：那边第二遍扫描时要把每个 $\text{nums}[i]$ **重新分解**一遍来拉入 $\text{last}[p]$；本篇把质数按起点预聚合后，扫描阶段只做数组下标运算，**不再触碰质因数**。两者判定条件完全等价（$\text{reach} \equiv \text{maxLast}$），分解贵、扫描便宜的语言（如 Python）里本篇写法更划算。

### 3.4 示例演算

![示例 1 演算：startMax 聚合与 reach 扫描，i=2 首次闭合](images/coprime_split_walkthrough.svg)

以示例 1 走查（分解：$4{\to}\{2\}$、$7{\to}\{7\}$、$8{\to}\{2\}$、$15{\to}\{3,5\}$、$3{\to}\{3\}$、$5{\to}\{5\}$）：

| 质数 $p$ | 封锁带 $[\text{first}, \text{last}]$ | 聚合贡献 |
|------|------|------|
| 2 | $[0, 2]$ | $\text{startMax}[0] = 2$ |
| 7 | $[1, 1]$ | $\text{startMax}[1] = 1$ |
| 3 | $[3, 4]$ | $\text{startMax}[3] = 4$ |
| 5 | $[3, 5]$ | $\text{startMax}[3] = \max(4, 5) = 5$ |

扫描（$\text{reach}$ 初值 $-1$）：

| $i$ | startMax[i] | reach（更新后） | reach ≤ i ? | 动作 |
|-----|-------------|-----------------|-------------|------|
| 0 | 2 | $\max(-1, 2) = 2$ | $2 \le 0$ ✗ | 右移 |
| 1 | 1 | $\max(2, 1) = 2$ | $2 \le 1$ ✗ | 右移 |
| 2 | −1 | $\max(2, -1) = 2$ | $2 \le 2$ ✓ | **返回 2** |

$i=2$ 时，起点 $\le 2$ 的质数 $\{2, 7\}$ 的 last 均已收进前缀；后缀质数 $\{3, 5\}$ 与之不相交，$\gcd(224, 225) = 1$。示例 2 则相反：3、5 两条封锁带从下标 2 一直伸到 4、5，$\text{reach}$ 始终压过 $i$，扫完 $n-2$ 仍未闭合，返回 $-1$。

## 4. 算法细节

1. **SPF 筛的写法与上界**：`spf` 初始化为 `iota`（每个数指向自身），外层 $i$ 只需到 $\sqrt{M}$，内层从 $i^2$ 步进 $i$ 且仅在 `spf[j] == j` 时写入——保证写入的恒为最小质因子。上界取 $M = \max(\text{nums})$ 而非写死 $10^6$，全小数用例省时省内存；循环条件 `(long long)i * i <= maxV` 防边界溢出（$\sqrt{10^6} = 1000$ 时恰好贴着 int 上限，显式转换更稳）。
2. **first「未见才写」、last「永远覆盖」**：$j$ 递增扫描，`first[p]` 只在该质数首次出现时写入；`last[p] = j` 每次出现都覆盖，扫描结束自然是最末下标。两者都不需要 min/max 调用。
3. **同一质数的重幂只记一次出现**：内层 `while (x % p == 0) x /= p;` 把 $p$ 的幂次除干净再找下一个质数。$12 = 2^2 \times 3$ 对质数 2 只产生一次「出现在下标 $j$」的事件（对 first/last 语义重复写本也无害，但这层循环是分解推进的必要步骤）。
4. **同起点多质数取 max**：$15 = 3 \times 5$ 让 3、5 都从下标 3 出发，`startMax[3] = max(4, 5) = 5`——封锁带能伸多远只由**伸得最远**的质数决定，必须显式 max，不能「后写覆盖」。
5. **扫描上界是 $n-2$**：`for (i = 0; i < n - 1; ++i)` 即 $i \le n-2$，保证后缀非空（题意 $i \le n-2$）；$n = 1$ 时循环体不执行，直接返回 $-1$。
6. **`reach` 初值 $-1$ 对应「空集取 $-1$」**：全 1 数组没有任何质数，$R(i) = -1 \le i$ 恒成立，$i = 0$ 直接返回——数学定义与工程初值严格对应，无需特判。
7. **差分封锁的等价实现**：把封锁带显式铺到分割点维度——`diff[first[p]] += 1; diff[last[p]] -= 1`，则前缀和恰好数出「起点 $\le i$ 且 $\text{last} > i$」的质数个数，为 0 的首个 $i \in [0, n-2]$ 即答案。与 reach 法一一对应，见延伸思考。

## 5. 正确性证明

**引理 1（互质的质数刻画）**：记 $A_i = \prod_{k=0}^{i} \text{nums}[k]$，$B_i = \prod_{k=i+1}^{n-1} \text{nums}[k]$。则 $\gcd(A_i, B_i) > 1 \iff$ 存在质数 $p$ 同时整除某 $\text{nums}[j_1]$（$j_1 \le i$）与某 $\text{nums}[j_2]$（$j_2 > i$）。

**证明**：（⇐）若这样的 $p$ 存在，则 $p \mid A_i$ 且 $p \mid B_i$，故 $p \mid \gcd(A_i, B_i)$，得 $\gcd(A_i, B_i) \ge p > 1$。（⇒）若 $\gcd(A_i, B_i) > 1$，取其任一质因子 $p$。由 $p \mid A_i$ 与欧几里得引理（质数整除乘积必整除某因子），$p$ 整除某个 $\text{nums}[j_1]$（$j_1 \le i$）；同理 $p$ 整除某个 $\text{nums}[j_2]$（$j_2 > i$）。∎

**引理 2（封锁带刻画）**：分割 $i$ 有效 $\iff$ 不存在质数 $p$ 满足 $\text{first}[p] \le i < \text{last}[p]$ $\iff$ $R(i) \le i$，其中 $R(i) = \max\{\text{last}[p] : \text{first}[p] \le i\}$（空集取 $-1$）。

**证明**：先证第一式。由引理 1，分割 $i$ 无效 $\iff$ 存在 $p$ 与下标 $j_1 \le i < j_2$ 使 $p$ 整除 $\text{nums}[j_1], \text{nums}[j_2]$。而「存在 $p$ 的出现下标 $\le i$」$\iff$ $\text{first}[p] \le i$（first 是出现下标的最小值），「存在 $p$ 的出现下标 $> i$」$\iff$ $\text{last}[p] > i$（last 是最大值），故无效 $\iff$ 存在 $p$：$\text{first}[p] \le i$ 且 $\text{last}[p] > i$，取否定即得。再证第二式：若 $R(i) \le i$，则所有 $\text{first}[p] \le i$ 的 $p$ 均有 $\text{last}[p] \le R(i) \le i$，第一式的坏质数不存在；反之若存在 $p$ 使 $\text{first}[p] \le i < \text{last}[p]$，则该 $p$ 参与 $R(i)$ 的取 max 且贡献 $> i$，得 $R(i) > i$。∎

**引理 3（reach 的增量正确性）**：扫描到位置 $i$ 并执行 $\text{reach} \gets \max(\text{reach}, \text{startMax}[i])$ 之后，$\text{reach} = R(i)$。

**证明**：对 $i$ 归纳。$i = 0$：初值 $\text{reach} = -1$，执行后 $\text{reach} = \max(-1, \text{startMax}[0])$。若无质数以 0 为起点，则 $\text{startMax}[0] = -1$（默认值），$\text{reach} = -1 = R(0)$（空集）；否则 $\text{reach} = \max\{\text{last}[p] : \text{first}[p] = 0\}$，而 $R(0)$ 的候选集恰为起点为 0 的质数（$\text{first}[p] \ge 0$ 恒成立），成立。设位置 $i-1$ 后 $\text{reach} = R(i-1)$。位置 $i$ 时，$\{\,p : \text{first}[p] \le i\,\} = \{\,p : \text{first}[p] \le i-1\,\} \uplus \{\,p : \text{first}[p] = i\,\}$（不相交并），故

$$R(i) = \max\bigl(R(i-1),\ \max\{\text{last}[p] : \text{first}[p] = i\}\bigr) = \max\bigl(R(i-1),\ \text{startMax}[i]\bigr)$$

程序执行同样的 max 操作，归纳成立。∎

**定理**：算法返回 $[0, n-2]$ 中最小的有效分割下标；不存在时返回 $-1$。

**证明**：算法按 $i = 0, 1, \dots, n-2$ 升序扫描。由引理 3，每一步判定条件 $\text{reach} \le i$ 即引理 2 的有效性判定 $R(i) \le i$，故算法命中的每个 $i$ 都有效，且第一个命中者恰为最小有效下标。若循环结束未命中，则 $[0, n-2]$ 内无有效分割；又题意只允许 $i \le n-2$（$i \ge n-1$ 时后缀为空，不构成分割），故返回 $-1$ 正确。∎

## 6. 复杂度分析

- **时间复杂度**：$O(M \log\log M + n\omega)$，其中 $M = \max(\text{nums}) \le 10^6$，$\omega$ 为单元素不同质因子个数。SPF 筛 $O(M \log\log M)$ 为主导（约几百万次标记）；因 $2 \times 3 \times 5 \times 7 \times 11 \times 13 \times 17 = 510510 \le 10^6 < 9699690 = $ 8 个最小质数之积，故 $\omega \le 7$，分解 + 聚合 + 扫描合计 $O(n\omega) \le 7 \times 10^4$。
- **空间复杂度**：$O(M)$——C++ 的 `spf` 与 `first`/`last` 数组合计约 12 MB（`int` $\times 3 \times 10^6$），远低于常规限制；Python 用 `dict` 存 first/last，只占 $O(n\omega)$。
- **对照**：暴力大数 gcd 不可行（§3.1）；逐分割点独立检查质数为 $O(nP)$，$P \le n\omega \le 7 \times 10^4$，约 $7 \times 10^8$；本解法把「逐点检查」折叠成一次 $O(n)$ 扫描，扫描阶段零质因数操作。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int findValidSplit(vector<int>& nums) {
        int n = nums.size();
        int maxV = *max_element(nums.begin(), nums.end());
        // ① SPF 筛：spf[x] = x 的最小质因子
        vector<int> spf(maxV + 1);
        iota(spf.begin(), spf.end(), 0);
        for (int i = 2; (long long)i * i <= maxV; ++i)
            if (spf[i] == i)
                for (int j = i * i; j <= maxV; j += i)
                    if (spf[j] == j) spf[j] = i;
        // ② 分解每个元素，记录每个质数的 first / last
        vector<int> first(maxV + 1, -1), last(maxV + 1, -1);
        for (int j = 0; j < n; ++j) {
            int x = nums[j];
            while (x > 1) {
                int p = spf[x];
                if (first[p] < 0) first[p] = j;   // 首次出现才写
                last[p] = j;                      // j 递增，覆盖写即最末
                while (x % p == 0) x /= p;        // 去掉全部重幂
            }
        }
        // ③ 按起点聚合：startMax[j] = 以 j 为起点的封锁带最远右端
        vector<int> startMax(n, -1);
        for (int p = 2; p <= maxV; ++p)
            if (first[p] >= 0)
                startMax[first[p]] = max(startMax[first[p]], last[p]);
        // ④ 一次扫描：首个 reach <= i 即最小有效分割
        int reach = -1;
        for (int i = 0; i < n - 1; ++i) {
            reach = max(reach, startMax[i]);
            if (reach <= i) return i;
        }
        return -1;
    }
};
```

### Python

```python
from math import isqrt
from typing import List


class Solution:
    def findValidSplit(self, nums: List[int]) -> int:
        n = len(nums)
        max_v = max(nums)
        # ① SPF 筛
        spf = list(range(max_v + 1))
        for i in range(2, isqrt(max_v) + 1):
            if spf[i] == i:
                for j in range(i * i, max_v + 1, i):
                    if spf[j] == j:
                        spf[j] = i
        # ② 分解每个元素，记录每个质数的 first / last
        first, last = {}, {}
        for j, x in enumerate(nums):
            while x > 1:
                p = spf[x]
                if p not in first:
                    first[p] = j
                last[p] = j
                while x % p == 0:
                    x //= p
        # ③ 按起点聚合
        start_max = [-1] * n
        for p, f in first.items():
            start_max[f] = max(start_max[f], last[p])
        # ④ 一次扫描：首个 reach <= i 即最小有效分割
        reach = -1
        for i in range(n - 1):
            reach = max(reach, start_max[i])
            if reach <= i:
                return i
        return -1
```

> 💡 两版均对拍验证：官方双示例、全 1、$n=1$、$[2,3,2]$（同质数首尾呼应）、$[999983,2,999983]$（大质数）等边界，以及 2 万组随机小数组对大数 gcd 暴力，全部一致。

## 8. 边界情况与易错点

1. **`nums[i] = 1` 无质因子**：不更新任何 first/last、不封锁任何分割点；全 1 数组答案为 0。判定必须用 $\text{reach} \le i$ 而非 $==$——`nums[i] = 1` 时 reach 不增，可能严格小于 $i$（如 $[1,2]$ 在 $i=0$：前缀积 1、后缀积 2，$\gcd = 1$，应用 $\le$ 才能正确返回 0）。
2. **扫描上界 $n-2$**：写成 `i < n` 会把「整个数组当左半、空后缀」也判进去；$n = 1$ 时应直接 $-1$。
3. **同元素重幂**：$12 = 2^2 \times 3$ 对质数 2 只算一次出现；内层 `while` 必须把 $p$ 的幂除干净，否则分解循环无法推进到下一个质数。
4. **筛上界取 $\max(\text{nums})$ 且防 $M=1$**：全 1 时筛循环、聚合循环自然为空，`spf` 数组只有 2 个元素，无需特判；C++ 中 `(long long)i * i` 防止上界贴边时的溢出隐患。
5. **同起点多质数必须显式 max**：`15 = 3 × 5` 同起点 3，「后写覆盖」碰巧能对（若按 last 递增遍历），但遍历顺序不保证，写成覆盖是潜伏 bug。
6. **别把「乘积互质」误当「逐元素互质」**：只要求前缀**质数集合**与后缀**质数集合**不相交，前缀内部共享质数完全合法（示例 1 前缀 $4 \times 7 \times 8$ 内部就有两个 2 的幂）。
7. **C++ 内存布局**：`spf`/`first`/`last` 各 $M+1$ 个 `int`，$M = 10^6$ 时约 12 MB；若卡内存可把 first/last 换成 `unordered_map`（不同质数至多 $7 \times 10^4$ 个），`spf` 换成对每个元素 $O(\sqrt{M})$ 试除（总 $10^7$，时间换空间）。
