# LeetCode 二叉树中的第K大层和 题解

## 1. 题目概述

- **标题 / 题号**：二叉树中的第K大层和（#2583，medium）
- **链接**：https://leetcode.cn/problems/kth-largest-sum-in-a-binary-tree/
- **来源**：LeetCode 第 335 场周赛 Q2
- **难度**：中等
- **标签**：树、广度优先搜索（BFS）、二叉树、排序

**题意**：给一棵二叉树的根节点 `root` 和一个正整数 `k`。**层和**指**同一层**（到根节点距离相同）上节点值的总和。返回树中**第 `k` 大**的层和（层和可以相同，按多重集排名）；若树的层数少于 `k`，返回 `-1`。

**约束**：

- 树中节点数 $2 \le n \le 10^5$
- $1 \le \text{Node.val} \le 10^6$
- $1 \le k \le n$

> 📚 本题在本仓库另有[每日题解 2583](../../solution/2501-2600/2583_二叉树中的第K大层和.md)：含小顶堆 Top-K 流式优化与面试问答；本篇侧重赛时切入路径、BFS「按层切批」的正确性证明与边界复盘。

> 💡 **赛时定位**：Q2 是一副双模板拼盘——题面的「层」字应条件反射出 **BFS 的 `while + for(size)` 骨架**（[102. 二叉树的层序遍历](https://leetcode.cn/problems/binary-tree-level-order-traversal/)），「第 k 大」应条件反射出**排序 / Top-K**。两块都是肌肉记忆，唯一的拼接坑是层和要用 `long long`。定位清楚后 5 分钟内可 AC，把时间留给 Q3/Q4。

## 3. 解题思路

### 3.1 暴力思路：收集层和后重复线性选最大

先用任意遍历把每层节点值累加成数组 `sums`（长度为 $L$，即层数），再求第 $k$ 大：朴素做法是重复 $k$ 轮，每轮线性扫描 `sums` 找当前最大并标记删除，合计 $O(k \cdot L)$。

问题在于 $k$ 与 $L$ 都可接近 $n$：树退化成链时 $L = n = 10^5$，最坏 $O(n^2) = 10^{10}$ 必然超时。瓶颈不在「收集层和」而在「选第 k 大」——这一步有排序 $O(L \log L)$ 与小顶堆 $O(L \log k)$ 两条成熟快路，本题选更短更稳的排序。

### 3.2 核心观察：层和是「按层聚合」的量，BFS 天然一层一批

![核心观察：二叉树按层切批求层和](images/kth_level_sum_layers_concept.svg)

「层」由**到根的距离**定义，恰好对应 BFS 的**入队批次**：`while + for(size)` 模板每轮先快照 `size = q.size()`，把这一层节点全部出队、累加出 `levelSum`，同时把子节点压到队尾成为下一批。于是两步解决问题：

1. **逐层求和**：`levelSum` 在本层 `for` 循环内累加，轮末追加进 `sums`；每个节点恰好进队、出队各一次，收集总代价 $O(n)$。
2. **排序取第 k**：`sums` 长为 $L$，降序排序后第 $k$ 大即下标 $k-1$；若 $L < k$ 则返回 `-1`。

> 💡 **为什么首选 BFS 而不是 DFS？** DFS 传 `depth` 也能做（`sums[depth] += val`），但要按深度动态扩容数组；BFS 的队列天然就是「当前层」的容器，`levelSum` 就地累加、轮末结算，与「层」的语义严丝合缝。更重要的是这副骨架直接迁移到右视图、锯齿遍历、最短步数等一整族题，值得形成肌肉记忆。

> ⚠️ **拼接点唯一的坑——溢出**：满层节点数可达 $\lceil n/2 \rceil \approx 5 \times 10^4$，每个值 $\le 10^6$，单层和上界约 $5 \times 10^{10}$，**超出 32 位 `int`**（约 $2.1 \times 10^9$）。`levelSum`、`sums` 与返回值全链路必须 `long long`（Python 天然大整数）。这是本题赛时最高的 WA 点。

### 3.3 算法流程

![算法流程：BFS 收集层和、判层数、降序取第 k](images/kth_level_sum_algo_flow.svg)

1. 初始化 `queue = [root]`，`sums = []`；
2. `while` 队列非空：快照 `size`，`for` 循环出队本层 `size` 个节点累加 `levelSum`、非空孩子入队；轮末 `sums.append(levelSum)`；
3. 若 `len(sums) < k`，返回 `-1`（层数不足）；
4. `sums` 降序排序，返回 `sums[k-1]`。

### 3.4 示例演算

![示例演算：四轮 BFS 收集层和并降序取第 2 大](images/kth_level_sum_bfs_walkthrough.svg)

以示例 1（`k = 2`）走查，`sums` 逐轮生长：

| 轮次 | 队列快照 | levelSum | sums（追加后） |
|------|----------|----------|----------------|
| L1 | [5] | 5 | [5] |
| L2 | [8, 9] | 17 | [5, 17] |
| L3 | [2, 1, 3, 7] | 13 | [5, 17, 13] |
| L4 | [4, 6] | 10 | [5, 17, 13, 10] |

BFS 结束后 `len(sums) = 4 ≥ k = 2`；降序得 `[17, 13, 10, 5]`，返回 `sums[1] = 13`。注意 L2 出队 8、9 时，2、1、3、7 依次入队，下一轮队列恰好是 `[2,1,3,7]`——这就是 `size` 快照「按层切批」的效果，`levelSum` 不会与下一层混淆。

## 4. 算法细节

1. **`size` 快照是切批的唯一开关**：进入 `for` 前保存 `size = q.size()`，循环内入队的子节点只追加到队尾、不参与本轮。若上限误写成 `i < q.size()`，队列边出边进，一轮会吞掉下一层，层和、层数全错。
2. **`levelSum` 的结算时机**：`for` 之前清零、`for` 之内累加、`for` 之后追加——三个动作都锚定「本层」，与队列批次严格对齐。
3. **判层数必须在收集完之后**：`len(sums) < k` 要在 `while` 循环外、排序前判断；边收集边判会漏掉最后一层。
4. **溢出的定量分析**：$n \le 10^5$、$\text{val} \le 10^6$，单层和不超过全部节点值之和的上界 $10^{11}$；`long long`（约 $9.2 \times 10^{18}$）有 7 个数量级余量。C++ 中 `levelSum += node->val` 右侧自动提升到 `long long`，安全。
5. **DFS 等价写法**：递归带深度 `dfs(node, d)`，`sums` 按 `d` 扩容并累加，复杂度同为 $O(n + L\log L)$。赛时选更熟的那副骨架即可，本题两者无本质差别。

## 5. 正确性证明

**引理 1（按层切批）**：把到根距离为 $d$ 的节点集合记为第 $d$ 层 $L_d$（$d$ 从 1 起）。算法第 $d$ 轮 `while` 迭代开始时，队列中的元素恰好是 $L_d$ 的全部节点。

**证明**：对 $d$ 归纳。$d = 1$ 时队列初值为 `[root]`，而 $L_1 = \{\text{root}\}$，成立。设第 $d$ 轮开始时成立。轮内 `for` 恰执行 $|L_d| = \text{size}$ 次，每次出队一个第 $d$ 层节点，并把它的非空孩子追加到队尾。每个非根节点的父节点唯一，故第 $d+1$ 层的节点恰是本轮出队节点的非空孩子的全体，且每个最多被追加一次。`for` 结束时第 $d$ 层节点全部出队，队列中剩余的恰好是 $L_{d+1}$ 的全部节点。∎

**引理 2（终止与层和完备）**：每个节点恰被入队一次；BFS 在恰 $L$ 轮后终止（$L$ 为树的层数），且 `sums[d-1]` 等于第 $d$ 层节点值之和。

**证明**：根只在初始化时入队；任一非根节点 $v$ 的父节点唯一，仅当父节点出队时 $v$ 被追加一次，此后不再入队。故总入队次数为 $n$，每轮至少出队一个节点，循环必然终止。又由引理 1，第 $d$ 轮出队的恰为 $L_d$ 的全部节点，而各层节点构成 $n$ 个节点的划分，故轮数恰为层数 $L$。第 $d$ 轮的 `levelSum` 从 0 起对 $L_d$ 的每个节点值累加一次，即 `sums[d-1]` 为该层层和。∎

**定理**：记全部层和构成的多重集 $S = \{s_1, \dots, s_L\}$。算法在 $L < k$ 时返回 $-1$，否则返回 $S$ 降序排列的第 $k$ 个元素。

**证明**：由引理 2，`sums` 是 $S$ 的一个排列且 `len(sums) = L`。若 $L < k$，分支条件命中，返回 `-1`，符合题意。否则降序排序得 `sums'`，满足 $\text{sums'}[0] \ge \text{sums'}[1] \ge \dots \ge \text{sums'}[L-1]$，这恰是 $S$ 的一个降序排列，其第 $k$ 个元素位于下标 $k-1$；层和相同时它们在降序序列中相邻、各占一个名次，多重集排名语义自动满足。故返回值即第 $k$ 大层和。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n + L \log L)$。BFS 中每个节点恰入队、出队各一次，收集层和 $O(n)$；对 $L$ 个层和排序 $O(L \log L)$。由 $L \le n$ 得整体上界 $O(n \log n)$，$n = 10^5$ 时约 $1.7 \times 10^6$ 次比较，远低于周赛时限。
- **空间复杂度**：$O(n)$。队列最宽时约存 $\lceil n/2 \rceil$ 个节点（满二叉树最宽层），`sums` 存 $L \le n$ 个 `long long`。
- **对照**：暴力选最大 $O(k \cdot L)$，链状树下退化为 $O(n^2)$；小顶堆 Top-K 为 $O(n + L \log k)$、空间 $O(k)$，是 $k \ll L$ 时的流式优化（见延伸思考）。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long kthLargestLevelSum(TreeNode* root, int k) {
        vector<long long> sums;                     // 层和列表，务必 long long
        queue<TreeNode*> q;
        q.push(root);
        while (!q.empty()) {
            int size = q.size();                    // ① 本层节点数快照
            long long levelSum = 0;
            for (int i = 0; i < size; ++i) {        // ② 只处理本层 size 个
                TreeNode* node = q.front();
                q.pop();
                levelSum += node->val;              // ③ 本层累加
                if (node->left)  q.push(node->left);
                if (node->right) q.push(node->right);
            }
            sums.push_back(levelSum);               // ④ 一层一个和
        }
        if ((int)sums.size() < k) return -1;        // ⑤ 层数不足 k
        sort(sums.begin(), sums.end(), greater<long long>());  // ⑥ 降序
        return sums[k - 1];                         // ⑦ 第 k 大 = 下标 k-1
    }
};
```

### Python

```python
from collections import deque
from typing import Optional


class Solution:
    def kthLargestLevelSum(self, root: Optional[TreeNode], k: int) -> int:
        sums = []
        q = deque([root])
        while q:
            size = len(q)              # 本层节点数快照
            level_sum = 0
            for _ in range(size):      # 只处理本层 size 个
                node = q.popleft()
                level_sum += node.val
                if node.left:
                    q.append(node.left)
                if node.right:
                    q.append(node.right)
            sums.append(level_sum)
        if len(sums) < k:              # 层数不足 k
            return -1
        sums.sort(reverse=True)        # 降序
        return sums[k - 1]             # 第 k 大 = 下标 k-1
```

## 8. 边界情况与易错点

1. **`int` 溢出（头号 WA 点）**：单层和可达约 $5 \times 10^{10}$，`levelSum`、`sums`、返回值全链路 `long long`；Python 无此虑。
2. **`for` 上限用快照 `size`**：写成 `i < q.size()` 会在循环内吞掉刚入队的下一层，层和、层数双错（见 §4.1）。
3. **层数不足 `k` 并不罕见**：$k \le n$ 但宽树的 $L \approx \log_2 n$——$n = 10^5$ 的满二叉树只有 17 层，$k = 18$ 即返回 `-1`。判层数要放在收集完所有层和之后。
4. **方向与下标**：「第 $k$ **大**」是降序排名，降序排后取下标 $k-1$，等价于升序排后取下标 $L-k$。别把第 $k$ 大当第 $k$ 小。
5. **空孩子不入队**：`node->left / right` 判空再入队，`null` 不占层、不计和；约束 $n \ge 2$ 保证 `root` 非空，无需特判。
6. **层和允许并列**：「不一定不同」意味着多重集排名——两个层和相同时占两个名次，排序法天然正确，无需去重。
