# LeetCode 服务中心的最佳位置 题解

## 1. 题目概述

- **标题 / 题号**：服务中心的最佳位置（#1515，hard）
- **链接**：https://leetcode.cn/problems/best-position-for-a-service-centre/
- **来源**：LeetCode 第 197 场周赛 Q4
- **难度**：困难
- **标签**：几何、数学、凸优化、梯度下降、数值方法

**题意**：给定平面上 $n$ 个客户的位置 `positions[i] = [xi, yi]`，为服务中心选一个**实数**坐标 $[x_{\text{centre}}, y_{\text{centre}}]$，使它到所有客户的**欧几里得距离之和最小**，返回这个最小和：

$$f(x, y) = \sum_{i=1}^{n} \sqrt{(x - x_i)^2 + (y - y_i)^2}$$

与真实值误差在 $10^{-5}$ 之内即判正确。

**约束**：

- $1 \le n \le 50$，$0 \le x_i, y_i \le 100$（整数坐标）
- 客户位置**可以重复**，未按任何顺序给出

> 💡 使 $\sum d_i$ 最小的点在计算几何里叫**几何中位数**（geometric median，即 Fermat–Weber 点）。它是「中位数」在二维欧几里得度量下的推广：$n \ge 3$ 且点不全共线时**没有闭式解**，只能数值迭代。本题作为 Q4 考的正是：识别目标函数的**凸结构**，写一个能收敛到 $10^{-5}$ 精度的迭代算法。

## 2. 示例

**示例 1**

```text
输入：positions = [[0,1],[1,0],[1,2],[2,1]]
输出：4.00000
解释：4 个客户构成菱形，中心选 (1, 1) 到每个客户距离均为 1，总和 4，为最小值。
```

**示例 2**

```text
输入：positions = [[1,1],[3,3]]
输出：2.82843
解释：两点连线段上任一点都是最优中心，最小距离和 = 两点间距 = 2√2 ≈ 2.82843。
```

**示例 3（自构造，用于 §3.4 演算）**

```text
输入：positions = [[0,0],[0,0],[10,0]]
输出：10.00000
解释：两个客户叠在 (0,0)，一个在 (10,0)。最优中心恰是数据点 (0,0)——「多数派」位置，

```

## 3. 解题思路

### 3.1 暴力思路：枚举格点？

服务中心坐标是**连续实数**，无法枚举。退而求其次枚举 $[0,100]^2$ 内的整数格点：$10^4$ 个候选 $\times\ O(n)$ 求距离和 $= 5 \times 10^5$ 次浮点运算，量级完全可行——但只保证**整数最优**。而几何中位数一般不是整数点（$n \ge 3$ 不共线时通常连有理数都不是），格点最优与真实最优的差距是 $O(\text{格距})$ 量级，远超 $10^{-5}$ 容差。

> 💡 转换视角：这不是离散搜索问题，而是**连续凸优化**问题。正确姿势是识别 $f$ 的凸性，然后让迭代算法自己"滑"到最低点。周赛现场两类主流写法：**嵌套三分搜索**（对 $x$、$y$ 各三分一次，利用 $g(x)=\min_y f(x,y)$ 仍凸）与**梯度下降**。本篇主推后者——它把本题变成一道纯"物理题"，代码更短，且能顺带处理最优解落在数据点上的奇点情形（三分法对此也要额外小心）。三分版详见文末引用的 daily 题解。

### 3.2 核心观察：凸函数 + 「单位拉力」的物理图像

![核心观察：每个客户以等大的力拉中心，合力为零处即全局最优](images/1515_gradient_force_concept.svg)

**观察一：$f$ 是凸函数。** 每个 $d_i(z) = \|z - p_i\|$ 是范数与平移的复合，天然凸；凸函数之和仍凸。凸性是全局的"免死金牌"：**没有局部陷阱**，任何"只下山"的走法都必然收敛到全局最优（证明见 §5 引理 1、2）。

**观察二：梯度是"单位拉力的合力"。** 对 $f$ 求梯度：

$$\nabla f(z) \ =\ \sum_{i=1}^{n} \frac{z - p_i}{\|z - p_i\|}$$

每一项是**模长恒为 1** 的单位向量，方向从客户 $p_i$ 指向 $z$。于是 $-\nabla f(z)$ 就是"全体客户各自以**大小恒为 1** 的力把中心拉向自己"的**合力**（注意：力的大小与距离无关！）。合力为零处即平衡点，也就是几何中位数。

**与质心的本质区别**：

| | 质心（坐标均值） | 几何中位数（本题） |
|------|------|------|
| 最小化 | $\sum d_i^2$ | $\sum d_i$ |
| 单个客户的"拉力" | $\propto$ 距离（弹簧 / 胡克定律） | 恒为 $1$（绳索拖拽） |
| 解 | 闭式解 $(\bar{x}, \bar{y})$ | $n \ge 3$ 一般**无闭式解** |
| 抗离群点 | 差（平方放大远点影响） | 好（每个点只贡献固定 $1$ 份拉力） |

> ⚠️ **奇点**：当 $z$ 恰好与某个客户重合时，$d_i = 0$，梯度项 $0/0$ 无定义。这不是边界 case 而是本题**必考**的坑：示例 3 的最优解就恰在数据点上。处理方式见 §3.3 与 §5 引理 4 的「多数派判定」。

### 3.3 算法流程：负梯度 + 步长失败减半

![梯度下降算法流程图](images/1515_gradient_descent_flow.svg)

1. **初始化**：$z \leftarrow$ 质心（凸包内、离最优近），步长 $step \leftarrow 100$（坐标域直径量级）；
2. **计算合力**：$g = \sum_i (z - p_i)/d_i$，跳过 $d_i < \varepsilon$ 的重合客户（防 $0/0$）；
3. **试探**：若 $\|g\| < \varepsilon$ 直接结束；否则走试探点 $z' = z - step \cdot \hat g$；
4. **接受或减半**：若 $f(z') < f(z)$ 则接受（$z \leftarrow z'$）；否则 $step \leftarrow step/2$；
5. **终止**：$step < \varepsilon$ 时返回 $f(z)$。

两个关键设计：

- **「失败减半」是灵魂**。凸函数沿负梯度方向保证"方向正确"，但不保证"步长正确"——步子迈大了会跨过谷底、$f$ 反弹（见 §3.4 第 1、3 轮的反例）。固定步长会在谷底两侧永久震荡；减半机制让步长自动适配地形，同时在数据点奇点处**恰好把迭代钉在最优点上**。
- **跳过重合客户**不只是防除零。设当前点与某客户重合、重合客户共 $|J|$ 个、其余客户的合力为 $W$，则：跳过 $J$ 后计算的"梯度"恰是 $W$，试探方向恰为 $-W$。若 $\|W\| \le |J|$（拉不过多数派），试探必失败、步长一路减半、迭代停在原地——而引理 4 恰好证明此时**该数据点就是全局最优**；若 $\|W\| > |J|$，$-W$ 方向小步必降，减半后必被接受、离开该点。算法无需任何显式特判。

### 3.4 示例演算

![示例演算：重复点情形下梯度下降的轨迹与奇点处理](images/1515_gd_walkthrough.svg)

取示例 3：`positions = [[0,0],[0,0],[10,0]]`。由对称性迭代始终在 $x$ 轴上，$f(x) = 2|x| + |x - 10|$，在 $0 < x < 10$ 内梯度恒为 $+1$（两份 $+1$ 拉向左，一份 $-1$ 拉向右）。质心 $10/3 \approx 3.33$ 起步，$step$ 从 100 减半到 2 后开始正常前进：

| 轮次 | 当前 $x$ | $f(x)$ | $step$ | 试探点 | $f(\text{试探点})$ | 动作 |
|------|---------|--------|--------|--------|-------------------|------|
| 0 | $3.33$ | $13.33$ | $2$ | $1.33$ | $11.33$ | ✓ 接受 |
| 1 | $1.33$ | $11.33$ | $2$ | $-0.67$ | $12.00$ | ✗ 失败，$step$ 减半为 $1$ |
| 2 | $1.33$ | $11.33$ | $1$ | $0.33$ | $10.33$ | ✓ 接受 |
| 3 | $0.33$ | $10.33$ | $1$ | $-0.67$ | $12.00$ | ✗ 减半为 $0.5$ |
| 4 | $0.33$ | $10.33$ | $0.5$ | $-0.17$ | $10.50$ | ✗ 减半为 $0.25$ |
| 5 | $0.33$ | $10.33$ | $0.25$ | $0.08$ | $10.08$ | ✓ 接受 |
| ⋮ | $\to 0^+$ | $\to 10$ | $\to 0$ | — | — | 每次接受后步长即失效，指数逼近 $(0,0)$ |
| 终 | $\approx 0$ | $\approx 10$ | $< \varepsilon$ | — | — | 停在 $(0,0)$，返回 $10$ |

> 💡 第 1 轮与第 3 轮的失败演示了**为什么必须减半**：跨过 $x=0$ 后 $2|x|$ 项反噬，$f$ 不降反升；固定 $step=2$ 会在 $1.33 \leftrightarrow -0.67$ 之间永久震荡。终点 $x=0$ 处 $d=0$ 奇点被触发：跳过两个重合客户后剩余合力 $W = (0-10)/10 = -1$（指向 $-x$ 方向的拉力即 $+1$……即 $\|W\| = 1$），而 $\|W\| = 1 \le |J| = 2$——多数派判定成立，$(0,0)$ 就是全局最优，减半机制让迭代恰好钉死于此。全程无需任何特判代码。

## 4. 算法细节

1. **起点选质心**：质心必在数据凸包内、离最优点近（实践几十步内收敛），且它本身是「最小化 $\sum d_i^2$」的最优解，给 $f$ 提供了一个不错的初始上界。
2. **梯度每项模长恒为 1**：$(z - p_i)/d_i$ 是单位向量，梯度大小只取决于客户分布的**方向均衡度**，与绝对距离无关——数值上天然稳定，不存在大数吃小数。
3. **奇点跳过阈值**：$d_i < \varepsilon$ 时跳过该项。跳过只影响梯度、不影响 $f$ 的求值（$f$ 始终用全部客户计算）；阈值与步长终止阈值共用 $\varepsilon = 10^{-9}$，其影响并入整体误差界（§5 定理）。
4. **步长只减不增**：初始 $100$（坐标域直径），失败减半，$< \varepsilon$ 终止。不做"接受后放大步长"的启发式——凸函数上减半已足够快，且单调的步长序列让终止与精度都好分析。
5. **精度换算**：终止后即使继续迭代，剩余总位移不超过 $\sum_k \varepsilon/2^k = 2\varepsilon$；由 §5 引理 1 的 $n$-Lipschitz 性质，答案误差 $\le 2n\varepsilon = 10^{-7} \ll 10^{-5}$。$\varepsilon$ 不能放宽到 $10^{-4}$ 量级（$2n\varepsilon = 10^{-2}$，超容差）。
6. **防御性迭代上限**：循环加 `it < 100000` 上限。理论上 $f$ 每次接受严格下降、浮点下可能极慢收敛，上限纯防御；实践几十步即收敛。
7. **实现**：距离统一用 `hypot`（C++）/ `math.hypot`（Python），比手写 `sqrt(dx*dx+dy*dy)` 数值更稳。
8. **梯度零判断必须在除法之前**：$\|g\| = 0$ 时 $gx/\|g\|$ 是 $0/0 = \text{NaN}$。对称输入（如示例 1）在质心处梯度**精确**为零，先判断后除法。

## 5. 正确性证明

**引理 1（凸性与 Lipschitz 连续）**：$f$ 是 $\mathbb{R}^2$ 上的凸函数，且对任意 $u, v$ 有 $|f(u) - f(v)| \le n\|u - v\|$。

**证明**：对每个 $i$ 与 $\lambda \in [0, 1]$，

$$d_i(\lambda u + (1-\lambda)v) = \|\lambda(u - p_i) + (1-\lambda)(v - p_i)\| \le \lambda d_i(u) + (1-\lambda) d_i(v)$$

（范数的三角不等式与正齐次性），对 $i$ 求和即得凸性。Lipschitz 性由反向三角不等式 $|d_i(u) - d_i(v)| \le \|u - v\|$ 对 $i$ 求和即得。∎

**引理 2（一阶充要条件）**：设 $z$ 不与任何客户重合（$f$ 在 $z$ 处可微），则 $z$ 是全局最优 $\iff \nabla f(z) = 0$。

**证明**：（⟸）凸函数一阶条件 $f(y) \ge f(z) + \nabla f(z)^{\top}(y - z)$ 对一切 $y$ 成立；若 $\nabla f(z) = 0$ 则 $f(y) \ge f(z)$ 对一切 $y$ 成立。（⟹）若 $g = \nabla f(z) \ne 0$，考察 $\phi(t) = f(z - tg)$，则 $\phi'(0) = -\|g\|^2 < 0$，由导数定义存在小 $t > 0$ 使 $\phi(t) < \phi(0)$，故 $z$ 非最优。∎

**引理 3（数据点处的方向导数）**：设 $p$ 为某客户位置，$J = \{i : p_i = p\}$（重合客户集合），$W = \sum_{i \notin J} \frac{p - p_i}{\|p - p_i\|}$ 为其余客户的单位拉力和。则 $f$ 在 $p$ 处沿单位向量 $u$ 的方向导数为 $D_u f = |J| + W^{\top} u$。

**证明**：$i \in J$ 的项 $d_i(p + tu) = \|t u\| = t$（$t > 0$），方向导数为 $1$，共贡献 $|J|$；$i \notin J$ 的项 $d_i$ 在 $p$ 处可微，方向导数为 $\frac{(p - p_i)^{\top} u}{\|p - p_i\|}$。线性相加即得。∎

**引理 4（多数派判定）**：沿引理 3 的记号，数据点 $p$ 是全局最优 $\iff \|W\| \le |J|$。

**证明**：凸函数在 $p$ 处最优 $\iff$ 一切方向导数非负（凸分析标准刻画，由凸性沿射线 $p + tu$ 的差商单调逼近方向导数可得）。由引理 3，$\min_{\|u\| = 1} D_u f = |J| - \|W\|$（取 $u$ 反向于 $W$ 时达到），故最优 $\iff |J| - \|W\| \ge 0$。∎

> 💡 引理 4 是「中位数的多数派本质」在二维的推广：一维时 $\|W\| = |\text{左侧点数} - \text{右侧点数}|$，判定式即「中位数处的重数不小于两侧点数差」——正是排序取中位数的那个中位数。

**引理 5（必接受步长存在）**：设当前点 $z$，则：
(a) 若 $z$ 不与任何客户重合且 $\nabla f(z) \ne 0$，存在 $s_0 > 0$ 使一切 $0 < s \le s_0$ 的试探点 $z - s\hat g$ 满足 $f(z - s\hat g) < f(z)$；
(b) 若 $z$ 与客户重合（记号同引理 3、4）且 $\|W\| > |J|$，存在 $s_0 > 0$ 使沿 $-W$ 方向的小步试探必被接受。

**证明**：(a) $\phi(s) = f(z - s\hat g)$ 在 $s = 0$ 处可微且 $\phi'(0) = -\|\nabla f(z)\| < 0$，由导数定义取 $s_0$ 使 $s \le s_0$ 时 $\phi(s) < \phi(0)$。(b) 由引理 3，沿 $u = -W/\|W\|$ 的方向导数 $D_u f = |J| - \|W\| < 0$，同理存在小步严格下降；而算法跳过 $J$ 后计算的梯度恰为 $W$，试探方向恰为 $-W/\|W\|$——算法自动走向正确的方向。∎

**定理（正确性与精度）**：算法返回值 $\hat f$ 满足 $|\hat f - f^*| \le 2n\varepsilon + \varepsilon D$，其中 $\varepsilon$ 为步长终止阈值，$D$ 为迭代可能达到的区域的直径。取 $\varepsilon = 10^{-9}$、$n \le 50$、$D < 10^4$（由 $f(z) \le f(\text{质心}) \le 50 \times 142$ 限制 $z$ 离数据包围盒不超过约 $7.1 \times 10^3$），误差 $\le 10^{-7} + 10^{-5} \cdot 10^{-4} < 10^{-5}$，通过判定。

**证明**：**（单调性）** 只有使 $f$ 严格下降的移动才被接受，故 $f(z_k)$ 单调不增。

**（终止情形一：梯度归零提前结束）** 若因 $\|g\| < \varepsilon$ 提前结束：当无跳过时 $g = \nabla f(z)$，由凸性 $f(z) - f^* \le \|\nabla f(z)\| \cdot \|z - z^*\| \le \varepsilon D$；当跳过了重合客户时 $g = W$，$\|W\| < \varepsilon < 1 \le |J|$，由引理 4，$z$（即该数据点）已是全局最优。

**（终止情形二：步长耗尽）** 设想在终止后继续运行算法（步长从 $\varepsilon$ 起继续减半），得到迭代点列，其任意聚点 $\bar z$ 满足 $\|z_{\text{终止}} - \bar z\| \le \sum_k \varepsilon / 2^k = 2\varepsilon$。断言 $f(\bar z) = f^*$：若 $\bar z$ 处引理 5 (a) 或 (b) 的前提成立，则存在必接受步长 $s_0$；由方向导数对位置的连续依赖，$\bar z$ 的 $2\varepsilon$-邻域内必接受步长有正的下界，于是算法一旦进入该邻域且步长降至该下界以下就会继续接受移动、离开邻域，与 $\bar z$ 是聚点矛盾。故 $\bar z$ 处要么可微且梯度为零（引理 2 ⟹ 最优），要么是重合数据点且 $\|W\| \le |J|$（引理 4 ⟹ 最优）。结合引理 1 的 Lipschitz 性，$f(z_{\text{终止}}) - f^* \le f(z_{\text{终止}}) - f(\bar z) \le 2n\varepsilon$。∎

> ⚠️ 工程注记：跳过阈值 $d_i < \varepsilon$ 意味着「重合」在 $10^{-9}$ 精度下判定，由此引入的方向误差与 $2\varepsilon$ 位移同量级，已并入上述界中；全部阈值（步长、跳过、梯度）统一取 $10^{-9}$ 即为此故。

## 6. 复杂度分析

- **时间复杂度**：每轮循环 $O(n)$（梯度一遍扫描 + 两处 $f$ 求值）；步长减半至多 $\lceil \log_2(100/10^{-9}) \rceil \approx 37$ 次连续发生，接受步实践为几十次（凸函数上负梯度 + 线搜索收敛极快），总操作数实际 $\ll 10^4 \cdot n$；防御上限 $10^5$ 轮 $\times\ n = 5 \times 10^6$ 次浮点运算，远低于时限。
- **空间复杂度**：$O(1)$。只维护当前点、梯度、步长等常数个变量，不建任何辅助结构。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    double getMinDistSum(vector<vector<int>>& positions) {
        int n = positions.size();
        auto distSum = [&](double x, double y) {
            double s = 0;
            for (auto& p : positions) s += hypot(x - p[0], y - p[1]);
            return s;
        };

        double x = 0, y = 0;                       // 质心作起点
        for (auto& p : positions) { x += p[0]; y += p[1]; }
        x /= n; y /= n;

        const double EPS = 1e-9;
        double step = 100.0;                       // 坐标域直径量级
        for (int it = 0; it < 100000 && step >= EPS; ++it) {
            double gx = 0, gy = 0;
            for (auto& p : positions) {
                double d = hypot(x - p[0], y - p[1]);
                if (d < EPS) continue;             // 奇点：跳过重合客户
                gx += (x - p[0]) / d;              // 单位拉力，模长恒为 1
                gy += (y - p[1]) / d;
            }
            double g = hypot(gx, gy);
            if (g < EPS) break;                    // 合力为零：平衡点（防 0/0）
            double nx = x - step * gx / g;
            double ny = y - step * gy / g;
            if (distSum(nx, ny) < distSum(x, y)) {
                x = nx; y = ny;                    // 接受：沿负梯度走 step
            } else {
                step /= 2;                         // 失败：步长减半
            }
        }
        return distSum(x, y);
    }
};
```

### Python

```python
import math

class Solution:
    def getMinDistSum(self, positions: List[List[int]]) -> float:
        def dist_sum(x, y):
            return sum(math.hypot(x - px, y - py) for px, py in positions)

        n = len(positions)
        x = sum(p[0] for p in positions) / n       # 质心作起点
        y = sum(p[1] for p in positions) / n

        EPS = 1e-9
        step = 100.0
        for _ in range(100000):
            if step < EPS:
                break
            gx = gy = 0.0
            for px, py in positions:
                d = math.hypot(x - px, y - py)
                if d < EPS:                        # 奇点：跳过重合客户
                    continue
                gx += (x - px) / d                 # 单位拉力，模长恒为 1
                gy += (y - py) / d
            g = math.hypot(gx, gy)
            if g < EPS:                            # 合力为零：平衡点（防 0/0）
                break
            nx = x - step * gx / g
            ny = y - step * gy / g
            if dist_sum(nx, ny) < dist_sum(x, y):
                x, y = nx, ny                      # 接受
            else:
                step /= 2                          # 失败：步长减半
        return dist_sum(x, y)
```

> 💡 快速自测：示例 1、2 的质心处梯度**精确**为零，算法一步不挪直接返回 $4.0$ 与 $2\sqrt2$；示例 3 按演算表收敛到 $(0,0)$ 返回 $10.0$；单点输入返回 $0$。

## 8. 边界情况与易错点

1. **单点 / 全部客户重合**：质心即该点，梯度（跳过后）为零，直接返回 $0$。无需特判。
2. **两个客户**：整条线段都是最优解（解不唯一），质心（中点）在线段上、梯度为零，一步到位。算法只需返回值正确，不依赖解的唯一性。
3. **质心恰与某数据点重合**（如 `[[0,0],[1,1],[2,2]]` 的质心 $= (1,1)$）：开局即在奇点。跳过 $(1,1)$ 后剩余两点合力为零 → 梯力为零 → 直接返回 $2\sqrt2$，恰为最优（一维中位数 = 中间点）。仍是零特判通过。
4. **忘记奇点跳过**：$d = 0$ 时 $0/0 = \text{NaN}$，一个 NaN 污染全程，返回 NaN。这是本题最普遍的 WA 形态。
5. **梯度零判断放在除法之后**：`gx / g` 在 $g = 0$ 时算出 NaN，判断 `g < EPS` 永远为假（NaN 比较恒假），同样炸掉。先判断后除法。
6. **固定步长不减半**：会在谷底两侧永久震荡（§3.4 第 1、3 轮反例），答案卡在 $O(step)$ 误差上，无法满足 $10^{-5}$。
7. **失败时直接退出而非减半**：过早停在大误差处。失败的正确语义是「步子太大」而非「已到最优」。
8. **接受条件写成 $\le$**：$f$ 相等时原地接受、永不触发减半，配合大步长可能死循环；必须严格 $<$，让平局走减半通道退出。
9. **$\varepsilon$ 取太松**：如 $10^{-4}$，则残余位移 $2\varepsilon$、答案误差可达 $2n\varepsilon = 10^{-2}$，超容差。取 $10^{-9}$ 时答案误差 $\le 10^{-7}$，余量充足。
10. **浮点安全**：坐标与 $d_i$ 均 $\le 142$，$f \le 50 \times 142 < 10^4$，`double` 的 $10^{-16}$ 相对精度下累计误差 $\ll 10^{-5}$，无需 `long double`。
