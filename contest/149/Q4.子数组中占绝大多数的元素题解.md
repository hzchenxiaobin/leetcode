# LeetCode 子数组中占绝大多数的元素 题解

## 1. 题目概述

- **标题 / 题号**：子数组中占绝大多数的元素（#1157，hard）
- **链接**：https://leetcode.cn/problems/online-majority-element-in-subarray/
- **来源**：LeetCode 第 149 场周赛 Q4
- **难度**：困难
- **标签**：设计、线段树、树状数组、数组、二分查找、摩尔投票算法、分块

**题意**：实现 `MajorityChecker`：构造时给定 $arr$，之后反复询问 `query(left, right, threshold)`，若 $arr[left..right]$ 中某元素出现次数 $\ge threshold$ 则返回它，否则返回 $-1$。所有询问都满足 $2 \times threshold > right-left+1$，即目标是**严格多数**。

**约束**：

- $1 \le \lvert arr \rvert \le 2\times10^4$，$1 \le arr[i] \le 2\times10^4$
- $0 \le left \le right < \lvert arr \rvert$，$threshold \le right-left+1$ 且 $2 \times threshold > right-left+1$（严格多数，答案唯一）
- `query` 调用次数最多 $10^4$

## 2. 示例

**示例 1（官方）**

```text
输入：["MajorityChecker","query","query","query"]
     [[[1,1,2,2,1,1]],[0,5,4],[0,3,3],[2,3,2]]
输出：[null,1,-1,2]
解释：query(0,5,4) → 1 出现 4 次 ≥ 4，返回 1 ｜ query(2,3,2) → 2 出现 2 次 ≥ 2
     query(0,3,3) → 1、2 各出现 2 次 < 3，返回 -1
```

**示例 2（补充：候选在、次数不够）**

```text
输入：["MajorityChecker","query","query"]
     [[[1,1,2,2,1,1]],[1,4,3],[4,5,2]]
输出：[null,-1,1]
解释：query(1,4,3) → 子数组 1 2 2 1，1 与 2 各 2 次 < 3，返回 -1
     query(4,5,2) → 子数组 1 1，值 1 出现 2 次 ≥ 2，返回 1
```

## 3. 解题思路

### 3.1 暴力思路

每次询问扫一遍 $[left,right]$ 统计频次：单次 $O(len)$，最坏 $10^4\times2\times10^4 = 2\times10^8$，C++ 勉强、Python 必然超时，且完全没用上「$threshold$ 是严格多数」这一强条件。官方提示给了**随机采样**：答案若存在，占比 $>1/2$，随机取 $k$ 个位置、逐个用出现位置表校验，漏判概率不超过 $2^{-k}$。它优雅但不是确定性算法，$k$ 次全部落空时仍需兜底。下面给确定性的线段树做法。

### 3.2 核心观察：摩尔投票的 (cand, k) 可以合并

![摩尔投票的抵消与候选不变量](images/wc149_q4_boyer_moore_pair.svg)

摩尔投票把「找众数」变成「**两两抵消**」：维护候选 `cand` 与计数 `k`，同值加一、异值减一，减到零换候选。关键在于这个摘要是**可合并**的——$(c,k)$ 表示「区间内两两抵消后，还剩 $k$ 个 $c$ 无法配对」，两段摘要合并时让剩余元素继续互相抵消即可：

$$
\text{merge}\big((c_1,k_1),(c_2,k_2)\big)=\begin{cases}
(c_2,k_2)\ \text{或}\ (c_1,k_1) & k_1=0\ \text{或}\ k_2=0\\
(c_1,k_1+k_2) & c_1=c_2\\
(c_1,k_1-k_2) & c_1\ne c_2,\ k_1>k_2\\
(c_2,k_2-k_1) & c_1\ne c_2,\ k_2>k_1\\
(\varnothing,0) & c_1\ne c_2,\ k_1=k_2
\end{cases}
$$

于是用**线段树**：每个结点存自己区间的 $(cand,k)$，父结点由左右儿子 merge 得到；询问时把 $[left,right]$ 拆成 $O(\log n)$ 个整结点依次 merge，即得区间候选。

候选为什么可信？因为**严格多数抵消不完**。设 $x$ 出现 $cnt(x)$ 次、区间长 $len$ 且 $cnt(x) > len/2$；每次抵消消耗一个 $x$ 和一个非 $x$，而非 $x$ 总共只有 $len-cnt(x)$ 个，故剩余 $cnt(x) - (len - cnt(x)) = 2\,cnt(x) - len > 0$ 个 $x$，最后残留必全为 $x$，候选必为 $x$。

### 3.3 算法流程

![线段树建树、查询合并与二分校验](images/wc149_q4_segment_tree_flow.svg)

1. **建位置表**：`pos[v]` 存值 $v$ 的全部出现下标（天然升序），用于最终计数。
2. **建线段树**：叶子存 $(arr[i],1)$，内部结点由两儿子 merge，共 $O(n)$ 次 merge。
3. **查询拆分**：迭代式线段树，$lo=left+sz$、$hi=right+sz+1$；左累加器把结点**并在后面**，右累加器把结点**并在前面**，最后 merge 两侧累加器。
4. **候选校验**：候选为 $\varnothing$ 直接返回 $-1$；否则在 `pos[cand]` 上两次二分得到精确出现次数 $cnt$，返回 $cnt\ge threshold$ 时的候选，否则 $-1$。

### 3.4 示例演算

![官方示例三组询问的走查](images/wc149_q4_walkthrough.svg)

$arr=[1,1,2,2,1,1]$，$pos[1]=[0,1,4,5]$、$pos[2]=[2,3]$。各层摘要：$[0,2)\to(1,2)$、$[2,3)\to(2,1)$、$[4,6)\to(1,2)$，故 $[0,3)\to(1,1)$、$[3,6)\to(1,1)$、根 $[0,6)\to(1,2)$。

| 询问 | 合并结果 | 候选 | 候选出现次数 | 返回 |
|------|----------|------|--------------|------|
| $(0,5,4)$ | 根 $(1,2)$ | $1$ | $4 \ge 4$ | $1$ |
| $(0,3,3)$ | $(1,1)$ | $1$ | $2 < 3$ | $-1$ |
| $(2,3,2)$ | $(2,2)$ | $2$ | $2 \ge 2$ | $2$ |

第 2 行正是本题的陷阱：候选 $1$ 是抵消给出的，但在 $[0,3]$ 里只有 $2$ 个，够不到 $threshold=3$，所以**候选必须再数一遍**。

## 4. 算法细节

1. **merge 写成纯函数**：输入 $(c_1,k_1,c_2,k_2)$ 输出合并结果，建树与询问共用，避免两处逻辑不一致；空摘要用 $(0,0)$，因 $arr[i]\ge 1$，$0$ 是安全哨兵。
2. **线段树对齐到 2 的幂**：`sz` 取不小于 $n$ 的最小 2 的幂，叶子在 $[sz,sz+n)$，其余叶子为 $(0,0)$，区间拆分不做越界判断。
3. **左右累加器顺序不能混**：merge 不满足交换律与结合律，左半段必须「累加器在前、结点在后」，右半段必须「结点在前、累加器在后」。
4. **校验用两次二分**：`upper_bound(pos,right) - lower_bound(pos,left)` 即精确计数，$O(\log n)$；即使候选是假的也只多花一次二分。
5. **不要用前缀计数代替**：值域 $2\times10^4$、$n=2\times10^4$，逐值前缀和是 $O(nV)$ 空间，会爆；位置表 + 二分只需 $O(n)$。
6. **阈值条件只保证唯一性**：$2\cdot threshold>len$ 意味着两个不同元素不可能都达标（否则总和 $>len$），故答案唯一，返回任意合法元素即可。

## 5. 正确性证明

**引理 1（唯一性）**：若区间中存在出现次数 $\ge threshold$ 的元素，则它唯一。

**证明**：设 $x\ne y$ 都出现至少 $threshold$ 次，则 $len \ge cnt(x)+cnt(y) \ge 2\,threshold > len$，矛盾。∎

**引理 2（merge 就是抵消）**：若 $(c_1,k_1)$、$(c_2,k_2)$ 分别是两个不交多重集合 $S_1,S_2$ 的抵消残留，则 merge 的结果是 $S_1\cup S_2$ 的合法抵消残留。

**证明**：$k_1=0$ 或 $k_2=0$ 时并集残留即另一侧；$c_1=c_2$ 时同类剩余无法互消，合并计数；$c_1\ne c_2$ 时把两侧剩余配对消掉 $\min(k_1,k_2)$ 对，剩余 $\lvert k_1-k_2\rvert$ 个较大者，恰为 merge 输出。每对都是不同值，故整体是合法抵消序列。∎

**引理 3（严格多数幸存）**：设 $cnt(x) > \lvert S\rvert/2$，则对 $S$ 的**任意**合法抵消序列，结束时残留元素全为 $x$，候选必为 $x$。

**证明**：一次抵消消灭一个 $x$ 和一个非 $x$，被消灭的 $x$ 不超过非 $x$ 总数 $\lvert S\rvert-cnt(x)$，剩余 $x$ 至少 $2\,cnt(x)-\lvert S\rvert>0$；残留若含两个不同值则还能继续抵消，与序列结束矛盾。∎

**引理 4（结点摘要正确）**：每个线段树结点存的 $(cand,k)$ 是其覆盖区间的合法抵消残留。

**证明**：对树高归纳。叶子是单元素，$(arr[i],1)$ 显然合法；内部结点由两儿子摘要 merge 得到，由引理 2 仍合法。∎

**引理 5（计数精确）**：`upper_bound(pos[cand],right) - lower_bound(pos[cand],left)` 等于 `cand` 在 $[left,right]$ 中的出现次数。

**证明**：`pos[cand]` 升序存放全部出现下标，`lower_bound` 指向首个 $\ge left$、`upper_bound` 指向首个 $>right$，二者之间恰为落在区间内的全部出现位置。∎

**定理**：`query(left,right,threshold)` 返回值正确：存在合法元素时返回它，否则返回 $-1$。

**证明**：由引理 4，询问合并出的摘要是区间多重集合的合法抵消残留。若存在出现 $\ge threshold$ 次的元素 $x$，则 $cnt(x)\ge threshold>len/2$，由引理 3 得候选 $=x$，再由引理 5 知计数精确，故返回 $x$（引理 1 保证不会返回别的元素）。若不存在这样的元素，则候选要么为 $\varnothing$（返回 $-1$），要么计数 $<threshold$（返回 $-1$），均与正确输出一致。∎

## 6. 复杂度分析

- **时间**：建位置表与建树各 $O(n)$；单次 `query` 为 $O(\log n)$ 次 merge + $O(\log n)$ 区间拆分 + 一次 $O(\log n)$ 二分计数，即 $O(\log n)$。总计 $O(n+q\log n)$，$q\le10^4$。
- **空间**：线段树 $2\cdot sz=O(n)$ 个摘要，位置表存 $n$ 个下标，合计 $O(n)$。

## 7. 参考代码

### C++

```cpp
#include <vector>
#include <unordered_map>
#include <algorithm>
using namespace std;

class MajorityChecker {
public:
    MajorityChecker(vector<int>& arr) {
        n = (int)arr.size();
        for (int i = 0; i < n; i++) pos[arr[i]].push_back(i);
        sz = 1;
        while (sz < n) sz <<= 1;                    // 对齐到 2 的幂
        cand.assign(2 * sz, 0);
        cnt.assign(2 * sz, 0);
        for (int i = 0; i < n; i++) { cand[sz + i] = arr[i]; cnt[sz + i] = 1; }
        for (int i = sz - 1; i >= 1; i--) {
            int c, k;
            mergePair(cand[2 * i], cnt[2 * i], cand[2 * i + 1], cnt[2 * i + 1], c, k);
            cand[i] = c; cnt[i] = k;
        }
    }

    int query(int left, int right, int threshold) {
        int lo = left + sz, hi = right + sz + 1;
        int lc = 0, lk = 0, rc = 0, rk = 0, c, k;
        while (lo < hi) {
            if (lo & 1) { mergePair(lc, lk, cand[lo], cnt[lo], c, k); lc = c; lk = k; lo++; }
            if (hi & 1) { hi--; mergePair(cand[hi], cnt[hi], rc, rk, c, k); rc = c; rk = k; }
            lo >>= 1; hi >>= 1;
        }
        mergePair(lc, lk, rc, rk, c, k);
        if (c == 0) return -1;                      // 空候选，必无多数
        const vector<int>& p = pos[c];
        long long times = upper_bound(p.begin(), p.end(), right)
                        - lower_bound(p.begin(), p.end(), left);
        return times >= threshold ? c : -1;
    }

private:
    int n, sz;
    vector<int> cand, cnt;
    unordered_map<int, vector<int>> pos;

    static void mergePair(int c1, int k1, int c2, int k2, int& c, int& k) {
        if (k1 == 0) { c = c2; k = k2; return; }
        if (k2 == 0) { c = c1; k = k1; return; }
        if (c1 == c2) { c = c1; k = k1 + k2; return; }
        if (k1 > k2) { c = c1; k = k1 - k2; return; }
        if (k2 > k1) { c = c2; k = k2 - k1; return; }
        c = 0; k = 0;
    }
};
```

### Python

```python
from bisect import bisect_left, bisect_right


class MajorityChecker:

    def __init__(self, arr: list[int]):
        self.pos = {}                              # 值 -> 升序出现下标
        for i, v in enumerate(arr):
            self.pos.setdefault(v, []).append(i)
        size = 1
        while size < len(arr):
            size <<= 1
        self.size = size
        self.cand = [0] * (2 * size)               # 0 是哨兵，arr[i] >= 1
        self.cnt = [0] * (2 * size)
        for i, v in enumerate(arr):
            self.cand[size + i] = v
            self.cnt[size + i] = 1
        for i in range(size - 1, 0, -1):
            self.cand[i], self.cnt[i] = self._merge(
                self.cand[2 * i], self.cnt[2 * i],
                self.cand[2 * i + 1], self.cnt[2 * i + 1])

    @staticmethod
    def _merge(c1, k1, c2, k2):
        if k1 == 0: return c2, k2
        if k2 == 0: return c1, k1
        if c1 == c2: return c1, k1 + k2
        if k1 > k2: return c1, k1 - k2
        if k2 > k1: return c2, k2 - k1
        return 0, 0

    def query(self, left: int, right: int, threshold: int) -> int:
        lo, hi = left + self.size, right + self.size + 1
        lc = lk = rc = rk = 0
        while lo < hi:
            if lo & 1:
                lc, lk = self._merge(lc, lk, self.cand[lo], self.cnt[lo])
                lo += 1
            if hi & 1:
                hi -= 1
                rc, rk = self._merge(self.cand[hi], self.cnt[hi], rc, rk)
            lo >>= 1
            hi >>= 1
        cand, _ = self._merge(lc, lk, rc, rk)
        if cand == 0:
            return -1
        p = self.pos[cand]
        times = bisect_right(p, right) - bisect_left(p, left)
        return cand if times >= threshold else -1
```

## 8. 边界情况与易错点

1. **候选为 $\varnothing$ 时不要查位置表**：应直接返回 $-1$；否则 Python 会抛 `KeyError`，C++ 中 `pos[0]` 会顺手插入空表。
2. **单元素区间**：$left=right$ 时 $threshold=1$，候选即 $arr[left]$、计数为 $1$，注意区间拆分不要漏掉这个结点。
3. **候选存在但次数不够**：如示例 2 的 $(1,4,3)$，必须靠计数校验返回 $-1$，绝不能「有候选就返回候选」——这是本题最常见的 WA。
4. **merge 的左右顺序**：右半段结点必须并到右累加器**前面**；混着并虽然严格多数仍幸存（引理 3 对任意顺序成立），但非多数区间上的候选会变，调试图省事容易误判。
5. **`threshold` 等于区间长度**：只有「区间元素全相同」才成立，计数判断自然覆盖；若 $arr[i]$ 允许 $0$，$(0,0)$ 哨兵会与真实值 $0$ 混淆，应改用 $-1$（本题 $arr[i]\ge1$，安全）。
