# LeetCode 边积分最高的节点 题解

## 1. 题目概述

- **标题 / 题号**：边积分最高的节点（#2374，medium）
- **链接**：https://leetcode.cn/problems/node-with-highest-edge-score/
- **来源**：LeetCode 第 306 场周赛 Q2
- **难度**：中等
- **标签**：图、数组、计数（桶统计）

**题意**：给定 $n$ 个节点的有向图，每个节点**恰有一条出边**，由数组 $edges$ 表示：节点 $i$ 指向节点 $edges[i]$。节点 $v$ 的**边积分**定义为所有指向 $v$ 的边的**源点编号之和**。返回边积分最高的节点；若多个节点并列，返回编号最小者。

**约束**：

- $n = edges.length$，$2 \le n \le 10^5$
- $0 \le edges[i] < n$
- $edges[i] \neq i$（无自环）

> 💡 **审题关键**：两点。① 边积分是**源点编号之和**，不是入度（边数）——看错这一点会写出"数入度"的错误代码；② "每个节点恰有一条出边"意味着全图**恰好 $n$ 条边**，统计这 $n$ 条边的归属即可，不需要建图、DFS 或任何图论重武器。

## 2. 示例

**示例 1**

```text
输入：edges = [1,0,0,0,0,7,7,5]
输出：7
解释：score[0] = 1+2+3+4 = 10，score[5] = 7，score[7] = 5+6 = 11，
      其余节点积分为 0。节点 7 积分最高，返回 7。
```

**示例 2**

```text
输入：edges = [2,0,0,2]
输出：0
解释：score[0] = 1+2 = 3，score[2] = 0+3 = 3，两者并列，返回编号较小的 0。
```

**示例 3**（覆盖 $n = 2$ 的最小规模）

```text
输入：edges = [1,0]
输出：0
解释：节点 1 指向 0，score[0] = 1；节点 0 指向 1，score[1] = 0。返回 0。
```

## 3. 解题思路

### 3.1 暴力思路：按目标逐个统计

按定义，对每个节点 $v$ 把 $edges$ 整个扫一遍，累加所有满足 $edges[i] = v$ 的 $i$：$O(n^2) \approx 10^{10}$，在 $n = 10^5$ 下必然超时。痛点在于**按目标找源点**：同一个数组被反复扫描 $n$ 次，而每条边其实只会被"它的目标"关心一次。

### 3.2 核心观察：反向定义，正向实现

![核心观察：每条出边把源点编号丢进目标积分桶](images/edge_score_bucket_concept.svg)

**视角切换**：与其对每个目标 $v$ 去找所有前驱，不如让每条边"自己报名"——边 $i \to edges[i]$ 对 $score[edges[i]]$ 的贡献恰好是 $i$。全图只有 $n$ 条边，每条边只产生一次贡献：

$$score[v] \;=\; \sum_{i :\, edges[i] = v} i$$

因此**正向遍历一遍数组**，执行 `score[edges[i]] += i`，即可在 $O(n)$ 内得到所有节点的积分。这是**桶计数**的标准套路：值域 $[0, n)$ 连续且不大，直接开数组当桶，连哈希表都不需要。

> 💡 **一句话**：题面按"目标"定义积分，代码按"源点"实现累加——每个源点把自己的编号丢进目标的桶里。

### 3.3 算法流程

| 步骤 | 操作 | 说明 |
|------|------|------|
| ① 开桶 | `score` 数组初始化为 0（C++ 用 `long long`） | 值域 $[0,n)$，数组即桶 |
| ② 桶累加 | $i$ 从 $0$ 到 $n-1$：`score[edges[i]] += i` | 每条边恰贡献一次，共 $n$ 次累加 |
| ③ 取答案 | $i$ 从 $0$ 到 $n-1$ 扫描，仅当 `score[i] > score[ans]` 时更新 `ans` | 正序 + **严格大于** → 并列自动取小编号 |

### 3.4 示例演算

![示例演算：桶累加与并列取小](images/edge_score_walkthrough.svg)

**示例 1**（$edges = [1,0,0,0,0,7,7,5]$）：$i = 1 \ldots 4$ 四条边全部落进桶 0，$score[0] = 10$；$i = 5, 6$ 落进桶 7，$score[7] = 11$；$i = 7$ 落进桶 5，$score[5] = 7$；$i = 0$ 落进桶 1 但贡献为 $0$。最大积分 $11$ 在节点 $7$。**示例 2**（$edges = [2,0,0,2]$）：$score[0] = 1+2 = 3$ 与 $score[2] = 0+3 = 3$ 并列，正序扫描 + 严格大于保证返回编号较小的 $0$。

## 4. 算法细节

1. **数据结构选择**：值域 $[0, n)$ 连续且 $n \le 10^5$，直接用长度 $n$ 的数组做桶，访问 $O(1)$ 且无哈希开销；只有值域稀疏（如编号达 $10^9$）时才需要哈希表。
2. **积分上界与溢出**：单个节点的积分最多是其余 $n-1$ 个编号之和，上界 $\frac{n(n-1)}{2} \approx 5 \times 10^9$，超过 `int` 上界（$\approx 2.1 \times 10^9$）——C++ 必须用 `long long`，Python 天然大数无此虑。这是本题**最高频的 WA 原因**。
3. **并列取小的实现**：正序扫描 + `score[i] > score[ans]` 才更新。若倒序扫描配 `>=`，会取到**最大**编号，与题意正好相反。
4. **无需建图**：出度恒为 1 的"图"本质是一张函数表 $f(i) = edges[i]$，问题即统计 $f$ 各反像集合的元素和，一次线性扫描足够。

## 5. 正确性证明

**引理 1（累加不变式）**：循环结束后，$score[v] = \sum_{i:\, edges[i]=v} i$ 对所有 $v \in [0, n)$ 成立。

**证明**：循环对每个 $i \in [0, n)$ 恰执行一次 `score[edges[i]] += i`，不重不漏。整数加法满足交换律与结合律，累加顺序不影响结果；故 $score[v]$ 的终值恰为所有满足 $edges[i] = v$ 的 $i$ 之和，即节点 $v$ 的边积分定义。∎

**引理 2（并列取小）**：正序扫描并仅当 $score[i] > score[ans]$ 时更新，最终 $ans$ 是积分最大者中编号最小的节点。

**证明**：对扫描进度归纳。设已扫完 $[0, k]$，$ans$ 是 $[0, k]$ 中积分最大者的最小编号。考察 $i = k+1$：若 $score[k+1] > score[ans]$，则 $k+1$ 严格超过此前所有节点，成为唯一最大者，更新后仍成立；若 $score[k+1] = score[ans]$，不更新，$ans$ 保持较小编号且积分仍为最大；若 $score[k+1] < score[ans]$，不变。三种情况均维持归纳不变式。∎

**定理**：算法返回边积分最高的节点，且并列时返回编号最小者。

**证明**：由引理 1，`score` 数组与各节点边积分完全一致；由引理 2，在积分正确的前提下选取规则返回最大积分的最小编号。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。步骤②桶累加一次线性遍历，步骤③扫描取最大又一次线性遍历，共约 $2n$ 次数组访问。
- **空间复杂度**：$O(n)$。仅一个长度 $n$ 的 `score` 数组（不计返回值）。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int edgeScore(vector<int>& edges) {
        int n = edges.size();
        vector<long long> score(n, 0);  // 积分上界 ~5e9，必须 long long
        for (int i = 0; i < n; i++) {
            score[edges[i]] += i;       // 边 i -> edges[i] 贡献编号 i
        }
        int ans = 0;
        for (int i = 1; i < n; i++) {
            if (score[i] > score[ans]) {  // 严格大于：并列时保留小编号
                ans = i;
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def edgeScore(self, edges: List[int]) -> int:
        n = len(edges)
        score = [0] * n
        for i, target in enumerate(edges):
            score[target] += i          # 每条出边贡献源点编号 i
        ans = 0
        for i in range(1, n):
            if score[i] > score[ans]:   # 严格大于：并列取小编号
                ans = i
        return ans
```

## 8. 边界情况与易错点

1. **C++ 溢出**（最高频 WA）：积分上界 $\frac{n(n-1)}{2} \approx 5 \times 10^9$ 超 `int`，`score` 必须开 `long long`；源点编号 $i$ 与返回值本身不会溢出。
2. **题意看错**：边积分是**源点编号之和**，不是入度。数入度会把示例 1 算成"节点 0 入度 4 最大"，返回错误答案。
3. **并列方向**：必须正序扫描 + 严格大于（取小）；倒序 + 大于等于会取到最大编号，示例 2 即为并列用例，方向反了直接 WA。
4. **积分为 0 的节点是合法候选**：如示例 1 的节点 1 积分为 0。初始 `ans = 0` 从头扫描即可自然覆盖，无需为"零积分"做任何特判。
5. **最小规模** $n = 2$：如 $edges = [1,0]$，$score = [1, 0]$，答案 0，算法自然处理。
6. **自环**：题目保证 $edges[i] \neq i$；即便存在自环，"把 $i$ 加进 $score[i]$"的桶累加依然正确，算法无需改动。
