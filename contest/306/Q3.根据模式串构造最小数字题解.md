# LeetCode 根据模式串构造最小数字 题解

## 1. 题目概述

- **标题 / 题号**：根据模式串构造最小数字（#2375，medium）
- **链接**：https://leetcode.cn/problems/construct-smallest-number-from-di-string/
- **来源**：LeetCode 第 306 场周赛 Q3
- **难度**：中等
- **标签**：贪心、栈、字符串、回溯

**题意**：给定长度为 $n$ 的模式串 $pattern$，只含 'I'（上升）和 'D'（下降）两种字符。要求构造长度为 $n+1$ 的数字串 $num$，使得：数字取自 '1'~'9' 且**每个至多使用一次**；$pattern[i] = $ 'I' 时 $num[i] < num[i+1]$，$pattern[i] = $ 'D' 时 $num[i] > num[i+1]$。返回**字典序最小**的 $num$。

**约束**：

- $1 \le pattern.length \le 8$
- $pattern$ 只包含字符 'I' 和 'D'

> 💡 **审题关键**：三点。① 串长 $n+1 \le 9$ 而可用数字恰好是 9 个，"互不相同"约束恰好卡在临界——这是本题能被一遍贪心构造的根本原因；② 题面说"至多使用一次"，并不要求用满 9 个数字，但**字典序最小的解必然恰好使用 $1 \sim n+1$**（§5 引理 1 的秩替换论证）；③ $n \le 8$ 意味着回溯暴力也能过，但正解是 $O(n)$ 贪心 + 栈，这才是值得沉淀的套路。

## 2. 示例

**示例 1**

```text
输入：pattern = "IIIDIDDD"
输出："123549876"
解释：下标 0,1,2,4 处需 num[i] < num[i+1]；下标 3,5,6,7 处需 num[i] > num[i+1]。
      注意 "123414321" 不可行：数字 '1' 使用了两次。
```

**示例 2**

```text
输入：pattern = "DDD"
输出："4321"
解释：连续 3 个 'D' 要求 4 个数字严格递减，最小只能是 4,3,2,1。
```

**示例 3**（覆盖尾部为 'I' 的情况）

```text
输入：pattern = "DDDII"
输出："432156"
解释：前 4 位严格递减用 1~4，随后两个 'I' 重启，依次接 5、6。
```

## 3. 解题思路

### 3.1 暴力思路：回溯枚举

按位从左到右填数字，每位从小到大尝试 $1 \sim 9$ 中未使用、且与上一位满足 I/D 大小关系的数字，第一个完整方案即为字典序最小解：

```python
def smallestNumber(pattern):
    n, used, path = len(pattern), [False] * 10, []
    def dfs(i):
        if i == n + 1:
            return True
        for d in range(1, 10):          # 从小到大尝试 → 首个完整解即字典序最小
            if used[d]:
                continue
            if i and ((pattern[i-1] == 'I') != (int(path[-1]) < d)):
                continue
            used[d], _ = True, path.append(str(d))
            if dfs(i + 1):
                return True
            path.pop(); used[d] = False
        return False
    dfs(0)
    return ''.join(path)
```

状态数上界是排列数 $A(9, 9) = 362880$，$n \le 8$ 下毫无压力。但这是**数据范围保底**而非算法洞察：把 $n$ 放大到 $10^5$ 就原形毕露，而且比赛时写回溯的调试成本反而更高。本题真正的结构在约束的**局部性**上。

### 3.2 核心观察：连续 'D' 段 = 一段连续数字整体反转

![核心观察：D 连续段对应连续数字段整体反转](images/di_string_block_concept.svg)

把 $num$ 的 $n+1$ 个位置按 'I' 切开：**每个 'I' 是"重启点"**，位置被切成若干块，块内相邻约束全是 'D'（严格递减），块与块之间只有一个 'I' 约束。

- **块内**：长为 $s$ 的块需要 $s$ 个互不相同、严格递减的数字。"尽量用小数字"的贪心直觉是：第 $t$ 块恰好分到**连续区间** $[S+1, \, S+s]$（$S$ 为前面各块长度之和），**整段倒序**填入。
- **块间**：第 $t$ 块的结尾是 $S+1$，第 $t+1$ 块的开头是 $S+s+1$，'I' 约束 $S+1 < S+s+1$ **天然成立**，块与块之间互不干扰。

于是一个惊人的简洁结论出现了：**从 "123…(n+1)" 出发，把每个极大 'D' 段对应的数字段整体反转，就是答案**。示例 1 中反转 $[4,5]$ 和 $[6,7,8,9]$ 两段，即得 `123549876`。

### 3.3 算法流程：栈模拟

![算法流程：顺序压栈，遇 'I' 或末尾才整栈弹出](images/di_string_stack_flow.svg)

"整段倒序"用**栈**实现最优雅：顺序 push $1, 2, \ldots, n+1$；遇到 'I'（或到达末尾）就把栈里所有数字弹出接到答案尾部。

- 'D' 就继续压栈——压栈是升序，**弹出天然降序**，正好完成段反转；
- 每个 'I' 触发一次"清空"，滞留在栈里的恰好是当前块的连续区间；
- 循环必须跑到 $i = n$：最后一个数字入栈后靠 $i == n$ 触发收尾弹出。

### 3.4 示例演算

![示例演算：IIIDIDDD 的逐步栈状态](images/di_string_walkthrough.svg)

对 $pattern = $ `IIIDIDDD` 逐步走查：前三个 'I' 各自立即弹出 1、2、3；随后 'D' 让 4 滞留，'I' 弹出 `5 4`；后三个 'D' 让 6、7、8 依次滞留，末尾压入 9 后整栈弹出 `9 8 7 6`。拼接得 `123549876`，与预期一致。

## 4. 算法细节

1. **块分解的精确定义**：设极大 'D' 段为 $pattern[l..r]$（两端要么越界要么是 'I'），它约束的位置区间是 $[l, \, r+1]$，反转的正是数字段 $num[l..r+1]$。相邻两个 'D' 段之间必然隔着 'I'，对应的位置区间互不重叠，**反转顺序无关**。
2. **为什么恰好是连续区间**：块内需要 $s$ 个互异递减数字，且前面所有块已经用掉了 $\{1, \ldots, S\}$；若块内出现"跳档"（某数字 $> S+s$），由于字典序优先看块内靠前位置，跳档只会让答案变大。严格论证见 §5 定理的鸽笼推理。
3. **栈与段反转的等价性**：栈中滞留的数字恰好是"自上次清空以来压入的连续区间"，且栈底小、栈顶大；整栈弹出的序列就是该区间倒序——与 §3.2 的块构造逐字符相同。
4. **末尾 flush 的触发**：条件是 $i == n$ **或** $pattern[i] = $ 'I'。漏掉 $i == n$ 是最常见 WA：`"DDD"` 的答案全在栈里，不收尾就输出空串。
5. **赛况提示**：本题贪心证明不长（见 §5），但赛场上一时证不出来也可以先信直觉交代码；$n \le 8$ 的回溯是天然的兜底方案。

## 5. 正确性证明

记块分解为 $B_1, \ldots, B_m$（按 'I' 切开），第 $t$ 块 $B_t = [a_t, b_t]$，长度 $s_t = b_t - a_t + 1$，前缀和 $S_t = s_1 + \cdots + s_t$（$S_0 = 0$）。**构造 $C$** 定义为：位置 $j \in B_t$ 时 $C[j] = S_t - (j - a_t)$，即第 $t$ 块从左到右填 $S_t, S_t - 1, \ldots, S_{t-1}+1$。

**引理 1（最优解用满 $1 \sim n+1$）**：字典序最小的可行解 $num^\ast$ 恰好使用数字集合 $\{1, 2, \ldots, n+1\}$。

**证明**：任取可行串 $num$，其 $n+1$ 个数字互不相同，设从小到大为 $d_1 < d_2 < \cdots < d_{n+1}$，作**秩映射** $\varphi(d_k) = k$。$\varphi$ 严格递增，故所有严格不等式（无论 'I' 还是 'D' 方向）在映射后保持，且像互异，$\varphi(num)$ 仍可行。又因 $n+1$ 个互异正整数中第 $k$ 小者 $d_k \ge k$，故 $\varphi(num)$ 每一位 $\le$ 原串对应位；若 $num$ 使用的不是 $\{1, \ldots, n+1\}$，则存在 $d_k > k$，在第一个出现差异的位置上 $\varphi(num)$ 严格更小，即 $\varphi(num) < num$。于是不是 $\{1, \ldots, n+1\}$ 的可行串不可能字典序最小。∎

**引理 2（构造可行）**：$C$ 是满足所有 I/D 约束的合法串。

**证明**：块 $B_t = [a, b]$ 内部相邻位置约束全为 'D'，而 $C[a] > C[a+1] > \cdots > C[b]$（连续递减），满足。位置 $i$ 处 $pattern[i] = $ 'I' 意味着 $i$ 是某块 $B_t$ 的终点 $b$、$i+1$ 是下一块起点，此时 $C[i] = S_{t-1}+1$，$C[i+1] = S_t + 1 = S_{t-1} + s_t + 1 \ge S_{t-1} + 2 > C[i]$，满足。全体数字恰为 $\{1, \ldots, n+1\}$，互异且都在 '1'~'9' 内（$n + 1 \le 9$）。∎

**引理 3（栈实现 = 构造 $C$）**：§3.3 的栈算法输出恰为 $C$。

**证明**：对循环轮数归纳。设当前已输出 $S$ 个字符（恰为 $C$ 的前 $S$ 位，且栈为空），本轮及后续连续 'D' 轮依次压入 $S+1, S+2, \ldots$，栈中自底向顶递增；当遇 'I' 或 $i = n$ 清栈时，设共压入了 $s$ 个，弹出序列为 $S+s, S+s-1, \ldots, S+1$，正是新块（长 $s$）按构造 $C$ 的填法。归纳成立。∎

**定理（最优性）**：对任意可行串 $O$（数字互异，取自 1~9），均有 $C \le O$（字典序）。

**证明**：反证。设 $O < C$，取第一个 $O[i] \ne C[i]$ 的位置 $i$，则 $O[i] < C[i]$。设 $i$ 所在块为 $B_t = [a, b]$（$a \le i \le b$）。

1. **前缀占位**：$C$ 的前 $a$ 位是前 $t-1$ 块的拼接，数字集合恰为 $\{1, \ldots, a\}$（因 $S_{t-1} = a$）。由首异位在 $i \ge a$，$O$ 的前 $a$ 位与之相同，故 $O$ 已用掉 $\{1, \ldots, a\}$，后面不能再出现。
2. **链式上界**：$[i, b]$ 内每对相邻位置都是 'D'，故 $O[i] > O[i+1] > \cdots > O[b]$，互异整数链给出 $O[j] \le O[i] - (j - i)$ 对所有 $j \in [i, b]$。代入 $O[i] \le C[i] - 1 = (b+1) - (i - a) - 1$ 得 $O[j] \le b + a - j \le b + a - i$。
3. **鸽笼**：$O[i..b]$ 是 $b - i + 1$ 个互异数字，每个都 $\le b + a - i$，又不能取 $\{1, \ldots, a\}$，只能落在 $\{a+1, \ldots, b+a-i\}$ 中——只有 $b - i$ 个候选，装不下 $b - i + 1$ 个互异数字，矛盾。∎

由引理 2 与定理，$C$ 可行且不大于任何可行串，即字典序最小；由引理 3，栈算法正确输出 $C$。

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。$n+1$ 个数字各经历一次 push、一次 pop，加上 $n$ 次模式字符判断，总计约 $3n$ 次基本操作。
- **空间复杂度**：$O(n)$。栈与答案串各存 $n+1$ 个字符（不计返回值则栈深 $\le n+1$）。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    string smallestNumber(string pattern) {
        int n = pattern.size();
        string ans, st;                     // st 直接用 string 当字符栈
        for (int i = 0; i <= n; i++) {      // 注意 i 要跑到 n（含末尾收尾）
            st.push_back('1' + i);          // 顺序压入 1..n+1
            if (i == n || pattern[i] == 'I') {
                while (!st.empty()) {        // 整栈弹出 = 当前 'D' 段反转
                    ans += st.back();
                    st.pop_back();
                }
            }
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def smallestNumber(self, pattern: str) -> str:
        n = len(pattern)
        ans, st = [], []
        for i in range(n + 1):              # i 跑到 n：末尾触发最后一次弹出
            st.append(str(i + 1))           # 顺序压入 1..n+1
            if i == n or pattern[i] == 'I': # 'D' 时滞留，'I'/末尾时清栈
                while st:
                    ans.append(st.pop())
        return ''.join(ans)
```

**等价写法（直接反转 'D' 段）**：

```python
class Solution:
    def smallestNumber(self, pattern: str) -> str:
        n = len(pattern)
        num = list('123456789'[:n + 1])     # 初始 1..n+1
        i = 0
        while i < n:
            if pattern[i] == 'D':           # 找极大 'D' 段 [i, j-1]
                j = i
                while j < n and pattern[j] == 'D':
                    j += 1
                num[i:j + 1] = num[i:j + 1][::-1]   # 对应数字段反转
                i = j
            else:
                i += 1
        return ''.join(num)
```

## 8. 边界情况与易错点

1. **末尾忘记清栈**（最高频 WA）：循环条件必须是 `i <= n` / `range(n + 1)`，且 `i == n` 要触发弹出。`"DDD"` 的答案 `4321` 全部滞留在栈中，不收尾就输出空串。
2. **误以为要用满 9 个数字**："至多使用一次"不等于"使用全部"；答案只用前 $n+1$ 个数字（引理 1）。反过来，若误以为可以重复使用，`"IIIDIDDD"` 会得出 `121212…` 之类的错误答案。
3. **回溯写法的字典序保证**：每层必须**从小到大**尝试数字，这样搜到的第一个完整解才是字典序最小；同时剪枝只需检查与前一位的大小关系，不要漏判 `>=` / `<=`（相等即违反互异）。
4. **最小规模** $n = 1$：`"I"` → `12`，`"D"` → `21`，栈算法自然覆盖，无需特判。
5. **全 'D'**：`"DDDDDDDD"` → `987654321`。此时一块占满全部 9 个位置，首数字被迫是 9——这也是引理 1 的极端体现。
6. **'D' 段的反转区间**：极大 'D' 段 $pattern[l..r]$ 反转的是 $num[l..r+1]$（**右端点多一位**），因为 $r+1$ 位置也被最后一条 'D' 约束着，写反转版本时区间端点易错。
7. **栈内元素顺序**：弹出的顺序是"栈顶先出"（大数字在前），不要误以为是压入顺序；这正是 'D' 段递减的来源。
