# LeetCode 统计特殊整数 题解

## 1. 题目概述

- **标题 / 题号**：统计特殊整数（#2376，hard）
- **链接**：https://leetcode.cn/problems/count-special-integers/
- **来源**：LeetCode 第 306 场周赛 Q4
- **难度**：困难
- **标签**：数位 DP、组合数学、动态规划、位运算

**题意**：若一个正整数的**每一个数位两两互不相同**（如 $123$、$907$），称它为**特殊整数**。给定正整数 $n$，返回 $[1, n]$ 中特殊整数的数目。

**约束**：

- $1 \le n \le 2 \times 10^9$（十进制最多 $10$ 位）

> 💡 **审题关键**：三点。① $n$ 高达 $2 \times 10^9$，逐个枚举判重必然超时，但十进制**位数 $L \le 10$**——把枚举对象从「数」换成「数位串」，状态空间瞬间坍缩；② 数字只有 $0 \sim 9$ 共 $10$ 种，「互不相同」意味着**每一位的合法取值只由「上界」与「已用数字集合」两重约束决定**，后者天然压成 10 位 bitmask；③ $[1, n]$ 计数是数位 DP 的标准形态：按位数分层 + 贴上界分组。本题是本场周赛的收官困难题，也是数位 DP 的教科书案例。

## 3. 解题思路

### 3.1 暴力思路：线性枚举判重

枚举 $x \in [1, n]$，检查十进制各位是否互异（用集合或位掩码）：时间 $O(n \log n)$，$n = 2\times10^9$ 时约 $2\times10^{10}$ 次基本操作，必然超时。而且这个暴力**没有任何可剪枝的缝隙**——判重是逐数独立的。出路只有一个：不再枚举「数」，改为枚举「数位串」，让上界 $n$ 直接参与构造过程。

### 3.2 核心观察：按位数分层 + 贴上界分组

![核心观察：按位数分层，短位纯排列，同位贴上界](images/count_special_integers_layers_concept.svg)

设 $n$ 的十进制串为 $s$，长度 $L$。把 $[1, n]$ 的特殊数按**位数**切成互斥的两部分：

**第一部分（位数 $k < L$）**：位数不足 $L$ 的正整数必然 $< n$，其特殊数个数**与 $n$ 的具体数值无关**。恰好 $k$ 位的特殊数：首位 $9$ 种（$1 \sim 9$，不能有前导零），第 $2$ 位 $9$ 种（$0 \sim 9$ 去掉首位），第 $3$ 位 $8$ 种……由乘法原理：

$$\#\{\text{恰 } k \text{ 位特殊数}\} = 9 \times A(9,\ k-1), \qquad A(m, j) = m\,(m-1)\cdots(m-j+1)$$

例如 $k = 1, 2, 3$ 时分别为 $9$、$81$、$648$ 个。

**第二部分（位数 $= L$ 且 $\le n$）**：把这类数按「**与 $s$ 第一个不同的位置**」分组。若某数前 $i$ 位与 $s$ 完全相同、第 $i$ 位填了 $x < s[i]$，则它**已在第 $i$ 位严格小于 $n$**——后面 $L - i - 1$ 位不再受上界约束，只要互异、随意填。前缀已用掉 $i + 1$ 个互异数字，后缀方案数恰为排列数：

$$A(\,10 - i - 1,\ L - i - 1\,)$$

每个 $L$ 位数与 $s$ 的第一个不同位置唯一，所以**组与组互斥**；每组内部按「后缀 = 从剩余数字池选排列」一一对应计数。整个问题被压缩成至多 $10 \times 10$ 量级的组合运算。

### 3.3 算法流程：逐位贴上界 + used 掩码

![算法流程：短位数求和，贴上界逐位枚举，掩码判重截断](images/count_special_integers_digitdp_flow.svg)

1. 预处理排列数表 $P[m][k] = A(m, k)$（$m, k \le 10$，共 $121$ 个值）。
2. **短位数求和**：$k$ 从 $1$ 到 $L-1$，累加 $9 \cdot P[9][k-1]$。
3. 从高位到低位扫 $s$，维护已用数字掩码 $\text{used}$：
   - 第 $i$ 位枚举 $x \in [\,\text{首位} ? 1 : 0,\ s[i]\,)$ 且 $x \notin \text{used}$，累加 $P[10-i-1][\,L-i-1\,]$；
   - 若 $s[i] \in \text{used}$：**前缀已出现重复数字**，以 $s[0..i]$ 为前缀的数（含 $n$ 本身）全都不特殊，直接 `return ans`；
   - 否则 $\text{used} \mathrel{|}= 1 \ll s[i]$，进入下一位。
4. 主循环完整跑完说明 $n$ 自身各位互异，`ans += 1` 后返回。

### 3.4 示例演算：n = 135

![示例演算：n=135 的逐步分组与掩码变化](images/count_special_integers_walkthrough.svg)

- **短位数**：$9 + 81 = 90$；
- $i = 0$（$s[0] = 1$）：$x \in [1, 1) = \varnothing$，无贡献；$\text{used} = \{1\}$；
- $i = 1$（$s[1] = 3$）：$x \in \{0, 2\}$，各贡献 $A(8, 1) = 8$，共 $+16$（即 $10\square$、$12\square$ 各 8 个）；
- $i = 2$（$s[2] = 5$）：$x \in \{0, 2, 4\}$（$1$、$3$ 已用被挡），各贡献 $A(7, 0) = 1$，共 $+3$（$130$、$132$、$134$）；
- 循环跑满：$135$ 本身互异，$+1$。

合计 $90 + 16 + 3 + 1 = 110$。注意 $131$ 恰在 $i = 2$ 处被掩码挡下（末位 $1$ 与首位重复）。

## 4. 算法细节

1. **排列数表**：$P[m][k] = A(m, k) = \dfrac{m!}{(m-k)!}$，用 $P[m][k] = P[m][k-1] \times (m - k + 1)$ 递推，边界 $P[m][0] = 1$；当 $k > m$ 时保持 $0$（乘到 $0$ 因子），公式自动处理「位数超过数字种数必不特殊」。
2. **首位从 $1$ 开始**：第 $0$ 位枚举 $x \in [1, s[0])$ 而非 $[0, s[0])$。否则 $0$ 开头的「$L$ 位数」实际是更短的数，会与第一部分**重复计数**。这正是数位 DP 中**前导零**的处理（若用记忆化模板，对应 `is_num` 标志）。
3. **截断（break）的含义**：一旦 $s[i] \in \text{used}$，任何以 $s[0..i]$ 为前缀的 $L$ 位数中数字 $s[i]$ 至少出现两次，全都不特殊——既包括 $n$，也包括所有比 $n$ 更接近上界的数；而比它们小的同长数已在更靠前的位置被枚举个数，所以直接 `return ans`，**末尾不再 +1**。
4. **末尾 +1 的条件**：主循环未被截断地跑完 $\iff$ $n$ 的 $L$ 个数字两两互异 $\iff$ $n$ 本身是特殊数。
5. **两种等价写法**：公式版相当于把记忆化数位 DP 手工展开；§7 附上通用模板 `dp(i, mask, tight, is_num)`，状态含义：当前填到第 $i$ 位、已用数字集合、是否仍贴着上界、是否已开始填数。两版对拍一致（见 §5 定理后的说明）。

## 5. 正确性证明

记 $A(m, j)$ 为从 $m$ 个不同元素中选 $j$ 个排成一列的排列数，$A(m, 0) = 1$。

**引理 1（短位数公式）**：恰好 $k$ 位（$1 \le k \le 10$）的特殊正整数恰有 $9\,A(9, k-1)$ 个。

**证明**：首位取值于 $\{1, \ldots, 9\}$ 共 $9$ 种（排除前导零）；设前 $t - 1$ 位已两两互异，则第 $t$ 位可取 $0 \sim 9$ 中除这 $t-1$ 个数字外的 $10 - (t-1) = 11 - t$ 种。由乘法原理，总个数为
$$9 \prod_{t=2}^{k} (11 - t) \;=\; 9 \prod_{j=1}^{k-1} (10 - j) \;=\; 9\,A(9, k-1).$$
当 $k > 10$ 时连乘积中出现因子 $0$，公式给出 $0$（10 个数字装不进 11 个互异位置，鸽笼原理）。∎

**引理 2（分组计数）**：设前缀 $s[0..i-1]$ 各位互异，已用集合 $U$（$|U| = i$）。固定第 $i$ 位填 $x \notin U$（若 $i = 0$ 还要求 $x \ge 1$），则「前缀为 $s[0..i-1]x$、总长 $L$、各位互异」的数的个数恰为 $A(10 - i - 1,\ L - i - 1)$；且这些数全部 $< n$ 当且仅当 $x < s[i]$。

**证明**：前缀已确定 $i + 1$ 个互异数字，剩余 $L - i - 1$ 个位置须从 $10 - (i+1)$ 个未用数字中**无重复地**取值。每个这样的数与「长度为 $L - i - 1$、取值于 $10 - i - 1$ 元集合的单射序列」一一对应（逐位读出即得，反之亦然），后者个数即排列数 $A(10-i-1,\ L-i-1)$。大小关系：同长十进制数逐位比较，前 $i$ 位相同、第 $i$ 位 $x < s[i]$ 当且仅当整串 $< n$。∎

**引理 3（重复前缀截断）**：若扫到第 $j$ 位时 $s[j] \in U_j$（$s[0..j]$ 内出现重复），则：① 不存在以 $s[0..j]$ 为前缀的特殊数；② 所有 $L$ 位、$\le n$、不以 $s[0..j]$ 为前缀的特殊数，均已在第 $0 \sim j-1$ 位的枚举中被完整计数。

**证明**：① 以 $s[0..j]$ 为前缀的数中数字 $s[j]$ 至少出现两次，不特殊。② 任取 $L$ 位特殊数 $m \le n$，设 $m$ 与 $s$ 第一个不同位为 $p$（若不存在则 $m = n$）。因 $m$ 不以 $s[0..j]$ 为前缀，必有 $p < j$ 或 $m = n$。若 $m = n$：$n$ 含重复前缀 $s[0..j]$，不特殊，与 $m$ 特殊矛盾，故 $p < j$。由 $m \le n$ 得 $m[p] \le s[p]$；又 $m[p] \ne s[p]$，故 $m[p] < s[p]$，即 $m$ 恰落入第 $p$ 位的某个枚举组 $x = m[p]$。注意 $p < j$ 意味着前缀 $s[0..p-1] \subseteq s[0..j-1]$ 互异，循环能推进到第 $p$ 位；且 $m$ 特殊保证 $m[p] \notin \{m[0..p-1]\} = U_p$，故该组被枚举到；引理 2 的计数 $A(10-p-1, L-p-1)$ 恰包含 $m$ 的后缀。∎

**定理（主计数）**：算法返回值等于 $[1, n]$ 中特殊整数的个数。

**证明**：按位数划分，$[1, n]$ 的特殊数 = 「位数 $< L$」∪「位数 $= L$」。前者由引理 1 逐层计数，且位数 $< L$ 的数确实全部 $< n$（位数少则值小）。后者中，每个 $L$ 位特殊数 $m \le n$：若 $m = n$，当且仅当主循环无截断时被「末尾 +1」计入（截断时由引理 3 ① 知 $m$ 不特殊，不计入是对的）；若 $m < n$，设第一个不同位为 $p$，则 $m[p] < s[p]$，$m$ 恰被第 $p$ 位、$x = m[p]$ 的枚举组计数一次（引理 2、引理 3 ②）。各枚举组按「第一个不同位 + 该位取值」划分，互斥且不漏（截断后，由引理 3 ②，未枚举的组内本就无特殊数）。三部分相加即所求。∎

> 💡 **模板等价性**：§7 的记忆化版本中，`tight = true` 的转移对应「贴前缀」，`tight = false` 后的子问题 $dp(i, \text{mask}, \text{false}, \text{true})$ 只依赖剩余位数与 $|\text{mask}|$，其值恰为 $A(10 - i - 1, L - i - 1)$——公式版就是把这层记忆化显式写成排列数。

## 6. 复杂度分析

- **时间复杂度**：$O(D^2)$，其中 $D = L \le 10$ 为十进制位数。排列表 $O(D^2)$；主循环 $D$ 位、每位枚举至多 $10$ 个 $x$，每位一次 $O(1)$ 查表，共 $O(10D)$。对 $n \le 2 \times 10^9$ 实际运算量不足千次。
- **空间复杂度**：$O(D^2)$（121 个排列数值）；若现场计算排列数则 $O(1)$。记忆化模板版为 $O(2^{10} \cdot D)$ 个状态，同样可忽略不计。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int countSpecialIntegers(int n) {
        string s = to_string(n);
        int L = s.size();

        long long P[11][11] = {};              // P[m][k] = A(m, k)
        for (int m = 0; m <= 10; m++) {
            P[m][0] = 1;
            for (int k = 1; k <= m; k++) P[m][k] = P[m][k - 1] * (m - k + 1);
        }

        long long ans = 0;
        for (int k = 1; k < L; k++)            // 位数 < L：纯排列数
            ans += 9 * P[9][k - 1];

        int used = 0;                          // 已用数字 bitmask
        for (int i = 0; i < L; i++) {
            int d = s[i] - '0';
            for (int x = (i == 0 ? 1 : 0); x < d; x++)   // 首位从 1 起：无前导零
                if (!((used >> x) & 1))
                    ans += P[10 - i - 1][L - i - 1];     // 后缀自由排列
            if ((used >> d) & 1)               // 前缀重复：n 及更长前缀全废
                return (int)ans;
            used |= 1 << d;                    // 贴住 s[i] 继续走
        }
        return (int)(ans + 1);                 // n 本身互异
    }
};
```

### Python

```python
class Solution:
    def countSpecialIntegers(self, n: int) -> int:
        s = str(n)
        L = len(s)

        def A(m, k):                           # 排列数 m·(m−1)⋯(m−k+1)
            r = 1
            for j in range(k):
                r *= m - j
            return r

        ans = 0
        for k in range(1, L):                  # 位数 < L：纯排列数
            ans += 9 * A(9, k - 1)

        used = 0
        for i, ch in enumerate(s):             # 位数 = L：贴上界逐位分组
            d = int(ch)
            for x in range(1 if i == 0 else 0, d):   # 首位从 1 起
                if not (used >> x) & 1:
                    ans += A(10 - i - 1, L - i - 1)  # 后缀自由排列
            if (used >> d) & 1:                # 前缀重复：直接收工
                return ans
            used |= 1 << d
        return ans + 1                         # n 本身互异
```

**等价写法（通用数位 DP 模板，记忆化）**：

```python
from functools import lru_cache

class Solution:
    def countSpecialIntegers(self, n: int) -> int:
        s = str(n)

        @lru_cache(None)
        def dp(i, mask, tight, is_num):
            if i == len(s):
                return 1 if is_num else 0      # 填过数字才算一个正整数
            res = 0
            if not is_num:                     # 跳过当前位：继续留作前导零
                res += dp(i + 1, mask, False, False)
            lo = 0 if is_num else 1            # 首个真实数字不能是 0
            hi = int(s[i]) if tight else 9
            for d in range(lo, hi + 1):
                if mask >> d & 1:              # 与前面数位重复
                    continue
                res += dp(i + 1, mask | (1 << d), tight and d == hi, True)
            return res

        return dp(0, 0, True, False)
```

## 8. 边界情况与易错点

1. **前导零（最高频错误）**：第 $0$ 位的枚举区间必须是 $[1, s[0])$ 而非 $[0, s[0])$，否则形如 `0xx` 的串实为 $2$ 位数，与短位数部分重复计数。模板版中由 `lo = 0 if is_num else 1` + 跳过转移共同处理。
2. **忘记末尾 +1**：主循环跑满后 $n$ 本身互异，要 `ans += 1`（示例 3 漏掉会得 109）。
3. **截断后错误 +1**：`return ans` 直接返回，截断意味着 $n$ 及同前缀的数全不特殊，此时 +1 必错（示例 4 的 $n = 100$：第 2 位的 $0$ 已用过）。
4. **排列数下标写反**：查表是 $P[\,10 - i - 1\,][\,L - i - 1\,]$——两个参数分别是「剩余可用数字个数」「剩余位置数」，顺序颠倒在 $L = i + 1$ 等处会静默出错（部分值恰好相同）。
5. **位数超过 10 的上界**：$n = 2\times10^9$ 时 $L = 10$，$i = 0$ 处查 $P[9][9] = 362880$ 正确；若上界放大到 $10^{18}$，$L > 10$ 的层由排列数的 $0$ 因子自动归零，公式仍然成立，但短位数循环要跑到 $\min(L - 1, 10)$ 之外也无妨（乘积为 $0$）。
6. **最小规模**：$n = 1$ 时 $L = 1$，短位数循环不执行，主循环 $x \in [1,1)$ 为空，末尾 +1 得 $1$，正确。
7. **C++ 中间量溢出**：答案最大约 $8.9 \times 10^6$（$n$ 取 $10^{10} - 1$ 时的全体特殊数），`int` 足够；但 `9 * P[9][k-1]` 与排列表本身建议用 `long long`，避免 `$9 \times 362880$` 一类中间乘积踩 32 位边界的心智负担。

**延伸思考**：

- **区间询问**：若改为统计 $[L, R]$ 内的特殊数，用前缀相减 $f(R) - f(L-1)$ 即可，单次查询仍是 $O(D^2)$。
- **放宽互异约束**：若允许「至多一对数字重复一次」，状态需从「已用集合」升级为「出现次数向量」，直接记忆化会爆炸（$11^{10}$），需要按多重集组合分类计数——这是更进阶的组合数位 DP。
- **进制推广**：$k$ 进制下数字池变为 $k$ 个，公式同构地变为 $(k-1)\,A(k-1, \cdot)$ 与 $A(k - i - 1, \cdot)$；当位数超过 $k$ 时鸽笼自动归零。
- **模板沉淀**：`dp(i, mask, tight, is_num)` 四状态模板可通吃一大类「数位带约束」的计数题（不含某数字、数位和限制、重复数字等），值得作为周赛常备板子。
