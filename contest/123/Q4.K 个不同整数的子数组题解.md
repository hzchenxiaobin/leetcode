# LeetCode K 个不同整数的子数组 题解

## 1. 题目概述

- **标题 / 题号**：K 个不同整数的子数组（#992，hard）
- **链接**：https://leetcode.cn/problems/subarrays-with-k-different-integers/
- **来源**：LeetCode 第 123 场周赛 Q4
- **难度**：困难
- **标签**：数组、哈希表、计数、滑动窗口

**题意**：给定正整数数组 `nums` 和整数 $k$，统计「不同整数个数**恰好**为 $k$」的连续子数组数目。

**约束**：

- $1 \le nums.length \le 2 \times 10^4$
- $1 \le nums[i], k \le nums.length$

> 💡 「恰好 $k$ 个」不能直接用普通滑窗维护：窗口内不同整数数量在左右指针都单向移动时**不是单调的**（右移可能增大，左移可能减小），无法用一个窗口同时锁定「上界」和「下界」。经典技巧是把它拆成两个「至多」问题之差。

## 2. 示例

**示例 1**

```text
输入：nums = [1,2,1,2,3], k = 2
输出：7
解释：恰好含 2 个不同整数的子数组为
      [1,2]、[2,1]、[1,2]、[2,3]、[1,2,1]、[2,1,2]、[1,2,1,2]。
```

**示例 2**

```text
输入：nums = [1,2,1,3,4], k = 3
输出：3
解释：[1,2,1,3]、[2,1,3]、[1,3,4]。
```

## 3. 解题思路

### 3.1 暴力思路

枚举所有子数组（$O(n^2)$ 个），用哈希表增量维护不同整数个数，逐个判断是否等于 $k$。$n = 2 \times 10^4$ 时是 $4 \times 10^8$ 次操作，超时。这提示需要 $O(n)$ 或 $O(n \log n)$。

### 3.2 核心观察：恰好 = 至多 − 至多少一个

![恰好 K 个 = 至多 K 个 − 至多 K−1 个](images/wc123_q4_atmost_diff.svg)

定义 $f(m)$ 为「不同整数个数 $\le m$」的子数组数量。由于

$$\{\text{不同整数} \le k-1\} \subseteq \{\text{不同整数} \le k\},$$

二者的差集恰为「不同整数个数**恰好**等于 $k$」的子数组集合，于是

$$\text{answer} = f(k) - f(k-1).$$

而 $f(m)$ 是标准的**至多型滑窗**，可以在 $O(n)$ 内求出。

**为什么「恰好」不能直接滑窗？** 因为固定右端点时，「不同整数个数」关于左端点是单调的（左端点越靠左、种类越多），这个单调性可以支撑「至多」的滑窗；但「恰好等于 $k$」对应的是一段**区间**的左端点，需要两个指针同时维护上下界，实现复杂且易错，不如两次「至多」相减干净。

### 3.3 算法流程

![右端固定时合法左端点是一段连续区间](images/wc123_q4_window_count.svg)

求 $f(m)$ 的滑窗：

```text
1. cnt = 空哈希表，left = 0，res = 0
2. for right in 0..n-1:
       cnt[nums[right]] += 1
       while len(cnt) > m:
           cnt[nums[left]] -= 1
           若 cnt[nums[left]] == 0: 从 cnt 中删除该键
           left += 1
       res += right - left + 1
3. 返回 res
```

- `cnt` 维护窗口 `[left, right]` 内每个值的出现次数，`len(cnt)` 即不同整数个数；
- `while` 保证窗口内种类数不超过 $m$，且 `left` 是**满足条件的最大（最靠右）**左端点；
- 以 `right` 结尾、满足条件的子数组恰有 `right - left + 1` 个（起点取 `left..right`）。

答案即 `atMost(k) - atMost(k-1)`。注意 $m = 0$ 时返回 0（`k = 1` 时会用到 `atMost(0)`）。

### 3.4 示例演算

![示例 1 的两个 atMost 与相减](images/wc123_q4_walkthrough.svg)

对 `nums = [1,2,1,2,3]`、$k = 2$：

| `right` | 窗口（$m=2$） | `left` | 贡献 |
|---------|---------------|--------|------|
| 0 | $[1]$ | 0 | 1 |
| 1 | $[1,2]$ | 0 | 2 |
| 2 | $[1,2,1]$ | 0 | 3 |
| 3 | $[1,2,1,2]$ | 0 | 4 |
| 4 | $[2,3]$ | 3 | 2 |

$f(2) = 1+2+3+4+2 = 12$。同理 $f(1) = 1+1+1+1+1 = 5$（种类 $\le 1$ 只能是单个元素，因为相邻元素都不相同）。于是恰好 2 个不同整数 $= 12 - 5 = 7$，与题面一致。

## 4. 算法细节

1. **计数降到 0 必须删键**：区分「种类数」与「元素个数」，`len(cnt)` 只反映种类数；若忘记删除 0 计数，`while` 会死循环。
2. **`atMost(0)` 的处理**：`k = 1` 时需要 $f(0) = 0$；实现上把 `limit <= 0` 直接返回 0，或让循环自然得出 0（两种写法结果相同，前者更省）。
3. **贡献公式**：`res += right - left + 1`，这是「以 right 结尾的子数组数量」，不是「窗口长度」的别称——两者数值相同但含义不同，理解成前者才能解释为什么这样累加不重不漏。
4. **`left` 不对齐到窗口内所有值都出现**：本题只要求种类不超过 $m$，不要求每种都出现，所以不能像「最小覆盖子串」那样约束左端。
5. **两次独立扫描**：$f(k)$ 与 $f(k-1)$ 各自重置 `cnt` 与 `left`，不要共用状态。
6. **数值范围**：答案最大约 $n(n+1)/2 \approx 2 \times 10^8$，`int` 足够（C++ 中最大约 $2.1 \times 10^9$）。

## 5. 正确性证明

固定 $m$，记 $g_m(\text{right})$ 为「以 `right` 结尾且不同整数个数 $\le m$ 的子数组个数」。
记 $L_m(\text{right})$ 为满足「`nums[L..right]` 中不同整数个数 $\le m$」的**最小**起点（即最靠左的合法起点；若都不合法则不存在）。

**引理 1（合法性关于起点单调）**：固定 `right`，若 `nums[L..right]` 中不同整数个数 $\le m$，则对任意 $L' \in [L, \text{right}]$，`nums[L'..right]` 中不同整数个数也 $\le m$。

**证明**：`nums[L'..right]` 是 `nums[L..right]` 的子集（元素集合意义下），其不同整数集合是后者的子集，故元素个数不超过后者，即 $\le m$。∎

**引理 2（贡献公式）**：固定 `right`，合法起点恰为区间 $[L_m(\text{right}), \text{right}]$，故 $g_m(\text{right}) = \text{right} - L_m(\text{right}) + 1$（当存在合法起点时）。

**证明**：由 $L_m$ 的定义，`nums[L_m..right]` 合法；由引理 1，所有 $L' \ge L_m$ 也合法；而 $L' < L_m$ 按定义不合法。故合法起点集合正是 $[L_m, \text{right}]$，共 $\text{right} - L_m + 1$ 个。∎

**引理 3（滑窗不变式）**：算法在对每个 `right` 执行完 `while` 后，`left` 恰好等于 $L_m(\text{right})$（若不存在合法起点，则 `left = right + 1`）。

**证明**：对 `right` 归纳。设 `right-1` 时不变式成立。加入 `nums[right]` 后，窗口种类数可能变为 $m+1$。`while` 循环不断右移 `left`，直到种类数回到 $\le m$；由于每次只移除最左元素，第一次满足条件的 `left` 就是使窗口合法的**最小**起点，即 $L_m(\text{right})$。另一方面，$L_m(\text{right}) \ge L_m(\text{right}-1)$：若 $[L, \text{right}]$ 合法，则由引理 1 的对称形式，$[L, \text{right}-1]$ 也合法，故 $L \ge L_m(\text{right}-1)$。因此 `left` 从 $L_m(\text{right}-1)$ 出发向右移动即可，不会漏掉更靠右的解。∎

**引理 4（两个至多之差）**：$\{\text{不同整数恰为 } k\} = \{\le k\} \setminus \{\le k-1\}$。

**证明**：设子数组的不同整数个数为 $c$。$c \le k$ 且 $c \not\le k-1$ $\iff$ $c \le k$ 且 $c > k-1$ $\iff$ $c = k$（整数）。∎

**定理**：算法返回的子数组个数恰为「不同整数个数等于 $k$」的子数组数。

**证明**：由引理 3，`atMost(m)` 在每一步累加的正是 $g_m(\text{right})$，故其返回值等于 $f(m) = \sum_{\text{right}} g_m(\text{right})$，即种类数 $\le m$ 的子数组总数（每个子数组由其右端点唯一确定，不重不漏）。由引理 4，$f(k) - f(k-1)$ 恰为种类数等于 $k$ 的子数组数，即所求。∎

## 6. 复杂度分析

- **时间**：$O(n)$。每次 `atMost` 中 `right` 前进 $n$ 次，`left` 总共也最多前进 $n$ 次，循环体均摊 $O(1)$（哈希表操作期望 $O(1)$）。两次 `atMost` 相加仍为 $O(n)$。
- **空间**：$O(D)$，$D$ 为不同整数个数（$\le n$），即哈希表的大小；不计输入输出。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int subarraysWithKDistinct(vector<int>& nums, int k) {
        return atMost(nums, k) - atMost(nums, k - 1);
    }

private:
    int atMost(vector<int>& nums, int limit) {
        if (limit <= 0) return 0;
        unordered_map<int, int> cnt;
        int res = 0;
        int left = 0;
        int n = nums.size();
        for (int right = 0; right < n; right++) {
            cnt[nums[right]]++;
            while ((int)cnt.size() > limit) {
                if (--cnt[nums[left]] == 0) cnt.erase(nums[left]);
                left++;
            }
            res += right - left + 1;
        }
        return res;
    }
};
```

### Python

```python
class Solution:
    def subarraysWithKDistinct(self, nums: list[int], k: int) -> int:
        def at_most(limit: int) -> int:
            if limit <= 0:
                return 0
            cnt = {}
            res = 0
            left = 0
            for right, x in enumerate(nums):
                cnt[x] = cnt.get(x, 0) + 1
                while len(cnt) > limit:
                    y = nums[left]
                    cnt[y] -= 1
                    if cnt[y] == 0:
                        del cnt[y]
                    left += 1
                res += right - left + 1
            return res

        return at_most(k) - at_most(k - 1)
```

## 8. 边界情况与易错点

1. **`k = 1`**：此时需要 `atMost(0)`，必须返回 0（空窗口没有合法子数组），否则会把单元素子数组重复计算。
2. **忘记删除 0 计数**：`len(cnt)` 会虚高，`while` 条件永远成立导致死循环或答案错误。
3. **贡献写成窗口长度**：`right - left + 1` 就是窗口长度，但它是「以 `right` 结尾的合法子数组数」，含义要清楚，否则容易在外层再乘一次。
4. **`left` 越界**：`while` 中先减计数再前进，顺序不能反，否则会减错元素。
5. **数组全相同**：如 `[1,1,1]`、$k=1$，答案应为 $6$（所有子数组），检查滑窗时 `left` 恒为 0。
6. **`k` 大于不同整数总数**：答案为 0，$f(k) = f(k-1)$ 相减自然得 0。
7. **两次扫描状态污染**：`cnt` 与 `left` 必须在每次 `atMost` 内部重新初始化。
8. **答案类型**：$n = 2\times 10^4$ 时答案约 $2\times 10^8$，`int` 够用；若 $n$ 更大需换 `long long`。
