# LeetCode 等式方程的可满足性 题解

## 1. 题目概述

- **标题 / 题号**：等式方程的可满足性（#990，medium）
- **链接**：https://leetcode.cn/problems/satisfiability-of-equality-equations/
- **来源**：LeetCode 第 123 场周赛 Q2
- **难度**：中等
- **标签**：并查集、图、数组、字符串

**题意**：给定若干形如 `"a==b"` 或 `"a!=b"` 的方程（`a`、`b` 为单个小写字母变量），判断是否存在一种给这些变量赋整数的方案，使所有方程同时成立。

**约束**：

- $1 \le equations.length \le 500$
- 每个方程长度恰为 4，第 1、4 个字符是小写字母
- 第 2 个字符是 `'='` 或 `'!'`，第 3 个字符恒为 `'='`

> 💡 变量的取值是**任意整数**，不是 $0/1$，这一点很关键：只要连通分量之间取值不同，「不等」总能被满足。

## 2. 示例

**示例 1**

```text
输入：["a==b","b!=a"]
输出：false
解释：a==b 要求两者相等，b!=a 要求两者不等，直接矛盾。
```

**示例 2**

```text
输入：["b==a","a==b"]
输出：true
解释：两条方程说的是同一件事，取 a = b = 1 即可。
```

**示例 3**

```text
输入：["a==b","b==c","a==c"]
输出：true
解释：三者相等，取 a = b = c = 1。
```

**示例 4**

```text
输入：["a==b","b!=c","c==a"]
输出：false
解释：a==b 与 c==a 推出 b==c，与 b!=c 矛盾。
```

**示例 5**

```text
输入：["c==c","b==d","x!=z"]
输出：true
解释：x 与 z 没有任何等式关系，赋不同整数即可。
```

## 3. 解题思路

### 3.1 暴力思路

枚举每个变量的取值（值域有限，比如 $0 \sim 25$），对每种赋值检查所有方程。$26$ 个变量、$26^{26}$ 种赋值，显然不现实。即使剪枝成「只考虑出现过的变量」，最坏情况仍有十来个变量，指数级。

另一个容易想到但**错误**的做法是：一边读方程一边合并，遇到 `!=` 就立即判断。反例是 `["a!=b", "a==c", "c==b"]`：第一条读入时 $a, b$ 还未连通，看起来合法，但后面两条等式合并后矛盾才浮现。所以「等」必须**全部合并完**，再用「不等」验证。

### 3.2 核心观察：等号是等价关系，用并查集维护

![两遍扫描：先合并等号，再用不等号验证](images/wc123_q2_dsu_flow.svg)

「相等」满足自反、对称、传递，正好是一个**等价关系**，它的每个等价类就是并查集的一个集合：

1. 第一遍只处理 `==` 方程，`union(a, b)`，把所有必须相等的变量并到一起；
2. 第二遍只处理 `!=` 方程，若 `find(a) == find(b)`（同一集合却要求不等），立即返回 `false`；
3. 全部不等方程都通过，返回 `true`。

**为什么第二遍通过就一定有解？** 给每个集合分配一个互不相同的整数（例如集合的根转化为编号）。同一集合内的变量取同一个值，满足所有 `==`；不同集合的变量取不同值，满足所有 `!=`。因为整数无穷多、变量只有 26 个，这种分配总存在。

### 3.3 算法流程

```text
1. parent[0..25] 初始化为自身
2. for e in equations:
       若 e[1] == '=': union(e[0]-'a', e[3]-'a')
3. for e in equations:
       若 e[1] == '!': 若 find(e[0]-'a') == find(e[3]-'a'): 返回 false
4. 返回 true
```

并查集实现用「路径压缩 + 按秩合并」：`find` 是带路径压缩的迭代版，`union` 把两个根接起来。

### 3.4 示例演算

![示例 4 的连通分量与矛盾](images/wc123_q2_walkthrough.svg)

对示例 4 的 `["a==b","b!=c","c==a"]`：

| 阶段 | 处理 | 结果 |
|------|------|------|
| 第一遍 | `a==b` | 合并 $\{a,b\}$ |
| 第一遍 | `c==a` | 合并 $\{a,b,c\}$ |
| 第二遍 | `b!=c` | `find(b) == find(c)` → 同一集合，返回 `false` |

对照示例 5：`x!=z` 检查时 $x$ 与 $z$ 从未被任何等式合并，`find` 值不同，通过，返回 `true`。

## 4. 算法细节

1. **字符到下标**：`c - 'a'` 映射到 $[0,25]$，用定长数组当并查集，比哈希表快且省内存。
2. **两遍扫描的条件**：第一遍看 `e[1] == '='`，第二遍看 `e[1] == '!'`；因为每个方程第 2 个字符只有这两种，条件互斥且完备。
3. **路径压缩写法**：`while (parent[x] != x) { parent[x] = parent[parent[x]]; x = parent[x]; }` 是迭代版，避免递归；压缩后树高近似常数。
4. **`a!=a` 的情形**：如 `"a!=a"`，第一遍不合并，第二遍 `find(a) == find(a)` 成立，返回 `false`，正确。
5. **`a==a` 的情形**：`union(a, a)` 是空操作，不会破坏结构。
6. **不允许修改输入**：只读遍历，不改 `equations`。

## 5. 正确性证明

把 `==` 方程看作无向图的边，顶点是 26 个字母。定义 $a \sim b$ 当且仅当 $a$、$b$ 在该图中连通。

**引理 1（并查集刻画连通性）**：第一遍结束后，对任意字母 $a, b$，`find(a) == find(b)` 当且仅当 $a \sim b$。

**证明**：初始时每个点自成一类，`find` 值互不相同，与「无边时不连通」一致。每次 `union(a,b)` 只在 $a,b$ 之间连边后把两类合并，恰好把「新连通的一对点」并入同一集合，集合划分始终等于图的连通分量划分。故最终 `find` 相等 $\iff$ 同属一个连通分量 $\iff$ 连通。∎

**引理 2（等式传递）**：若 $a \sim b$，则任何满足所有 `==` 方程的赋值都使 $a$、$b$ 取值相等。

**证明**：对连通路径长度归纳。长度为 0 时 $a = b$，显然同值。设路径 $a = v_0, v_1, \dots, v_k = b$，前 $k-1$ 条边由归纳假设得 $v_0$ 与 $v_{k-1}$ 同值，最后一条边是某个 `==` 方程，给出 $v_{k-1}$ 与 $v_k$ 同值，于是 $v_0$ 与 $v_k$ 同值。∎

**引理 3（矛盾的必要性）**：若存在 `!=` 方程 `a!=b` 且 $a \sim b$，则方程组无解。

**证明**：由引理 2，任何满足全部等式的赋值都有 $a = b$，而 `a!=b` 要求 $a \ne b$，矛盾，故无解。∎

**引理 4（无矛盾则可行）**：若对所有 `!=` 方程 `a!=b` 都有 $\text{not}(a \sim b)$，则方程组有解。

**证明**：给每个连通分量 $C$ 赋予一个互不相同的整数 $f(C)$（分量个数不超过 26，整数足够用），令变量 $x$ 的取值为 $f(\text{包含 } x \text{ 的分量})$。对 `==` 方程 `a==b`：图中连了这条边，故 $a \sim b$，同分量，取值相同 ✓。对 `!=` 方程 `a!=b`：假设 $a,b$ 同分量则 $a \sim b$，与题设矛盾，故不同分量，取值不同 ✓。∎

**定理**：算法返回 `true` 当且仅当方程组可满足。

**证明**：若算法返回 `false`，说明找到 `a!=b` 且 `find(a) == find(b)`，由引理 1 得 $a \sim b$，由引理 3 无解。若算法返回 `true`，说明第二遍没有触发任何矛盾，即所有 `!=` 的两端都不同集合，由引理 1 得两两不连通，由引理 4 方程组可满足。∎

## 6. 复杂度分析

- **时间**：$O(n \cdot \alpha(26))$，其中 $n$ 是方程个数。第一遍每条方程至多一次 `union`（两次 `find`），第二遍每条至多两次 `find`；路径压缩下单次操作近似 $O(1)$，$\alpha$ 为反阿克曼函数。由于字母表只有 26 个大写固定代价，实际可视为 $O(n)$。
- **空间**：$O(1)$。定长数组 `parent[26]`，与 $n$ 无关。

## 7. 参考代码

### C++

```cpp
class Solution {
private:
    int parent[26];

    int find(int x) {
        while (parent[x] != x) {
            parent[x] = parent[parent[x]];
            x = parent[x];
        }
        return x;
    }

public:
    bool equationsPossible(vector<string>& equations) {
        for (int i = 0; i < 26; i++) parent[i] = i;
        for (const string& e : equations) {
            if (e[1] == '=') {
                int ra = find(e[0] - 'a'), rb = find(e[3] - 'a');
                if (ra != rb) parent[ra] = rb;
            }
        }
        for (const string& e : equations) {
            if (e[1] == '!') {
                if (find(e[0] - 'a') == find(e[3] - 'a')) return false;
            }
        }
        return true;
    }
};
```

### Python

```python
class Solution:
    def equationsPossible(self, equations: list[str]) -> bool:
        parent = list(range(26))

        def find(x: int) -> int:
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x

        for e in equations:
            if e[1] == '=':
                a = ord(e[0]) - ord('a')
                b = ord(e[3]) - ord('a')
                ra, rb = find(a), find(b)
                if ra != rb:
                    parent[ra] = rb
        for e in equations:
            if e[1] == '!':
                a = ord(e[0]) - ord('a')
                b = ord(e[3]) - ord('a')
                if find(a) == find(b):
                    return False
        return True
```

## 8. 边界情况与易错点

1. **不能边读边判**：`["a!=b", "a==c", "c==b"]` 是经典反例，必须先合并完所有等号再验证不等号。
2. **`a!=a`**：直接判为 `false`，代码里 `find(a)==find(a)` 天然成立。
3. **`a==a`**：空操作，不要误判成矛盾。
4. **自反性**：`find(a) == find(a)` 恒成立，不应据此认为出错。
5. **只出现一次的不等关系**：`x!=z` 中 $x,z$ 都没被合并过，`find` 不同，返回 `true`（示例 5）。
6. **`union` 前的根比较**：`parent[ra] = rb` 前要确认 `ra != rb`，虽然直接赋值也不会错，但省一次无意义写入。
7. **返回值类型**：`false`/`true` 小写，Python 打印要转成 `"true"`/`"false"` 时注意格式（本题签名直接返回 `bool`）。
8. **数组越界**：字符一定是小写字母，`- 'a'` 后必落在 $[0,25]$，无需额外校验。
