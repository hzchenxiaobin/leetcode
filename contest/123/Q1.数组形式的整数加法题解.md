# LeetCode 数组形式的整数加法 题解

## 1. 题目概述

- **标题 / 题号**：数组形式的整数加法（#989，easy）
- **链接**：https://leetcode.cn/problems/add-to-array-form-of-integer/
- **来源**：LeetCode 第 123 场周赛 Q1
- **难度**：简单
- **标签**：数组、数学

**题意**：整数 $num$ 以「数组形式」给出——数组按下标从左到右依次是它的十进制各位（最高位在前，无前导零）。给定这个数组 `num` 与整数 $k$，返回 $num + k$ 的数组形式。

**约束**：

- $1 \le num.length \le 10^4$
- $0 \le num[i] \le 9$
- `num` 不含前导零（$0$ 本身除外）
- $1 \le k \le 10^4$

> ⚠️ 注意：`num` 的长度可达 $10^4$ 位，**远超** 64 位整数范围（约 19 位十进制），所以「把数组转成整数再相加」在 C++ 里必然溢出。必须逐位模拟竖式加法。

## 2. 示例

**示例 1**

```text
输入：num = [1,2,0,0], k = 34
输出：[1,2,3,4]
解释：1200 + 34 = 1234
```

**示例 2**

```text
输入：num = [2,7,4], k = 181
输出：[4,5,5]
解释：274 + 181 = 455，最高位发生进位后长度不变。
```

**示例 3**

```text
输入：num = [2,1,5], k = 806
输出：[1,0,2,1]
解释：215 + 806 = 1021，结果比 num 多一位，进位把长度撑长了。
```

## 3. 解题思路

### 3.1 暴力思路

把数组按权展开成整数：$num = \sum num[i] \cdot 10^{L-1-i}$，加上 $k$ 再转回数组。朴素写法是 $O(L)$ 的，但**会溢出**：$L = 10^4$ 时这个数有上万位，`long long` 只能存 19 位。若改成手写大整数加法，那还不如直接逐位模拟——这正是题目要的解法。

另一种「笨」模拟是：每次加 1，重复 $k$ 次，复杂度 $O(kL) = 10^8$，显然不可取。

### 3.2 核心观察：从低位对齐，进位单独存

![从低位对齐：num 末尾对 k 的个位](images/wc123_q1_carry_alignment.svg)

竖式加法的三条规则可以直接翻译成循环：

1. **对齐**：数组的最高位在左、个位在右，所以从 `i = L-1` 往左走；$k$ 的当前位用 $k \bmod 10$ 取，取完 $k \gets \lfloor k/10 \rfloor$。
2. **逐位求和**：$s = carry + (\text{num 的第 } i \text{ 位}) + (k \bmod 10)$。
3. **写位与进位**：当前位写 $s \bmod 10$，新进位 $carry = \lfloor s / 10 \rfloor$。

因为低位先算，答案数组是**逆序**生成的，最后整体反转即可（`reserve` + `reverse`，避免每次前插的 $O(L^2)$）。

循环条件写成「`i >= 0` **或** `k > 0` **或** `carry`」：

- `i >= 0` 处理 `num` 还有位的情形；
- `k > 0` 处理 `num` 已耗尽但 $k$ 还有高位的情形（如 `num = [0], k = 10000`）；
- `carry > 0` 处理两边都耗尽但还有进位的情形（如 `[9,9] + 1`）。

三者用 `||` 串起来，所有退化情形一次覆盖，一个特判都不用写。

### 3.3 算法流程

```text
1. i = len(num) - 1，carry = 0，res = []
2. while i >= 0 或 k > 0 或 carry > 0:
       a = (i >= 0) ? num[i] : 0
       s = carry + a + k % 10
       res.push_back(s % 10)
       carry = s / 10
       k /= 10
       i -= 1
3. 若 res 为空（num=[0], k=0 的退化输入），补一个 0
4. reverse(res) 后返回
```

### 3.4 示例演算

![示例 3 的逐位走查](images/wc123_q1_walkthrough.svg)

对 `num = [2,1,5]`、$k = 806$：

| 步 | `num` 位 | $k$ 个位 | 进位入 | 和 → 写入 | 进位出 |
|----|----------|----------|--------|-----------|--------|
| 1 | 5 | 6 | 0 | 11 → 写 1 | 1 |
| 2 | 1 | 0 | 1 | 2 → 写 2 | 0 |
| 3 | 2 | 8 | 0 | 10 → 写 0 | 1 |
| 4 | — | — | 1 | 1 → 写 1 | 0 |

`res` 依次写入 $1, 2, 0, 1$（低位在前），反转得 $[1,0,2,1]$，即 $1021 = 215 + 806$ ✓。

## 4. 算法细节

1. **为什么不用 `long long`**：$10^4$ 位的数字需要约 $3.3 \times 10^4$ 个二进制位，任何内置整型都不够。
2. **`k % 10` 与 `k /= 10` 配对**：先取低位再加，取完立刻右移，保证每一轮读到的都是「当前最低位」。
3. **`num[i]` 的下标安全**：`i` 可能先到 $-1$，用 `(i >= 0 ? num[i] : 0)` 兜住，C++ 里不要写 `num[i]` 越界访问。
4. **反转一次即可**：结果长度最多 $L+1$（进位多一位），`reverse` 是 $O(L)$；若用 `insert(begin(), x)` 前插，则是 $O(L^2)$。
5. **不修改输入**：只读取 `num`，返回新数组；`k` 是传值参数，可以直接自除。
6. **空结果兜底**：题面保证 $k \ge 1$，循环至少执行一次，理论上 `res` 不会为空；但加一行兜底不影响正确性，也不增加复杂度。

## 5. 正确性证明

记 $L = num.length$，`num` 表示的整数为 $N = \sum_{i=0}^{L-1} num[i] \cdot 10^{L-1-i}$。

**引理 1（位权对齐）**：第 $t$ 轮（从 $t = 0$ 开始）迭代读取的 `num` 位是 `num[L-1-t]`（若越界视为 0），读取的 $k$ 位是 $k$ 的十进制第 $t$ 位（若越界视为 0）。

**证明**：初始 $i = L-1$，每轮末尾 `i -= 1`，故第 $t$ 轮 $i = L-1-t$，恰好是 $N$ 的 $10^t$ 位。$k$ 初始为原值，每轮末尾执行 `k /= 10`（整除），故第 $t$ 轮开始时 $k = \lfloor k_0 / 10^t \rfloor$，其 `k % 10` 恰为第 $t$ 位。∎

**引理 2（不变式）**：设进入第 $t$ 轮时 `carry = c`，则在第 $t$ 轮之前写出的 $t$ 个低位数字恰为 $N + k_0$ 的低 $t$ 位，且

$$N + k_0 = \bigl(\text{已写出的低位部分}\bigr) + c \cdot 10^{t} + 10^{t} \cdot \bigl(\text{尚未处理的高位部分}\bigr).$$

**证明**：对 $t$ 归纳。$t = 0$ 时未写出任何位、$c = 0$，等式为恒等。设第 $t$ 轮成立，本轮取 $a = $ 第 $t$ 位、$b = $ $k_0$ 的第 $t$ 位，计算 $s = c + a + b$，写出 $s \bmod 10$，新进位 $c' = \lfloor s/10 \rfloor$。于是

$$c \cdot 10^t + (a + b)\cdot 10^t = s \cdot 10^t = (s \bmod 10)\cdot 10^t + c' \cdot 10^{t+1},$$

即本轮的「当前位贡献」被拆成「写出的数字」与「向更高位的进位」，不变式在 $t+1$ 轮继续成立。∎

**定理**：算法返回的数组恰为 $N + k_0$ 的十进制数组形式。

**证明**：循环终止时 `i < 0`、$k = 0$、$c = 0$ 同时成立。由引理 2，此时 $N + k_0$ 已被完整写成若干位数字，且没有未处理的进位，故 `res` 反转后正是 $N + k_0$ 的各位（最高位不为 0，因为在最后一次「有效」轮次中写入的位来自非零的和）。由引理 1，每一位的取法正确。∎

## 6. 复杂度分析

- **时间**：$O(L + \log_{10} k)$，即 $O(\max(L, \log k))$。循环轮数等于结果位数，每轮常数次算术运算；反转 $O(L)$。
- **空间**：$O(L)$，用于存放结果（不计输入输出）。没有额外的中间大整数。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    vector<int> addToArrayForm(vector<int>& num, int k) {
        vector<int> res;
        int i = (int)num.size() - 1;
        int carry = 0;
        while (i >= 0 || k > 0 || carry) {
            int s = carry + (i >= 0 ? num[i] : 0) + k % 10;
            res.push_back(s % 10);
            carry = s / 10;
            k /= 10;
            i--;
        }
        if (res.empty()) res.push_back(0);
        reverse(res.begin(), res.end());
        return res;
    }
};
```

### Python

```python
class Solution:
    def addToArrayForm(self, num: list[int], k: int) -> list[int]:
        i = len(num) - 1
        carry = 0
        res = []
        while i >= 0 or k > 0 or carry:
            s = carry + (num[i] if i >= 0 else 0) + k % 10
            res.append(s % 10)
            carry = s // 10
            k //= 10
            i -= 1
        if not res:
            res.append(0)
        res.reverse()
        return res
```

## 8. 边界情况与易错点

1. **进位撑长**：`[9,9] + 1 = [1,0,0]`，循环条件里的 `carry` 保证最高位的进位不会丢。
2. **`k` 比 `num` 长**：`num = [0], k = 10000` → `[1,0,0,0,0]`，靠 `k > 0` 继续循环（示例 3 是同类情形）。
3. **`num` 比 `k` 长**：`k` 耗尽后 `k % 10` 恒为 0，自然退化为「加 0」，无需特判。
4. **全零**：`num = [0], k = 0`（题面保证 $k \ge 1$，但健壮性代码会走到）应返回 `[0]` 而不是 `[]`。
5. **前导零**：结果最高位不会是 0，因为只有 `s > 0` 才会写非零位；不要在反转后再去「去掉前导零」，那会误删 `[0]`。
6. **前插退化**：用 `res.insert(res.begin(), d)` 会变成 $O(L^2)$，$10^4$ 位时明显变慢。
7. **越界**：C++ 中 `num[i]` 在 `i < 0` 时是未定义行为，必须用三元表达式兜住。
8. **类型**：单轮最大和是 $9 + 9 + 1 = 19$，`int` 足够，但若把 $k$ 换成 $10^{18}$ 量级的参数，需要用 `long long` 并在每位上取模。
