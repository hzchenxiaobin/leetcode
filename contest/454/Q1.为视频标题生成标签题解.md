# LeetCode 为视频标题生成标签 题解

## 1. 题目概述

- **标题 / 题号**：为视频标题生成标签（#3582，easy）
- **链接**：https://leetcode.cn/problems/generate-tag-for-video-caption/
- **来源**：LeetCode 第 454 场周赛 Q1
- **难度**：简单
- **标签**：字符串、模拟

**题意**：给定视频标题字符串 `caption`，按顺序执行三步操作生成一个**有效标签**：① 把所有单词拼成一个**驼峰串**并在最前面加 `#`——第一个单词整体小写，其余单词首字母大写、首字母之后的字符全部小写；② 删除所有非英文字母的字符，但保留第一个字符 `#`；③ 把结果截断为**最多 100 个字符**。返回生成的标签。

**约束**：

- `1 <= caption.length <= 150`
- `caption` 仅由英文字母和 `' '` 组成

## 2. 示例

**示例 1**

```text
输入：caption = "Leetcode daily streak achieved"
输出："#leetcodeDailyStreakAchieved"
解释：除了 "leetcode" 以外的所有单词的首字母需要大写；
      注意首词 "Leetcode" 的首字母也被转成了小写。
```

**示例 2**

```text
输入：caption = "can I Go There"
输出："#canIGoThere"
解释：除了 "can" 以外的所有单词的首字母需要大写。
```

**示例 3**

```text
输入：caption = "hhh…h"（101 个 'h'）
输出："#hhh…h"（'#' + 99 个 'h'，共 100 个字符）
解释：第一个单词长度为 101，加上 '#' 共 102 个字符，超过 100，
      需要从末尾截去最后 2 个字符。
```

## 3. 解题思路

### 3.1 暴力思路

签到题。题面已经把操作步骤列成了清单，直接**按三步顺序模拟**即可：分词 → 逐词大小写变换并拼接 → 截断。数据规模 $n \le 150$，一次线性扫描毫无压力，模拟本身就是最优解。

### 3.2 核心观察：三条规则 + 一个空操作

![驼峰拼接规则：首词全小写，其余词首字母大写](images/wc454_q1_camel_rule.svg)

1. **驼峰规则的细节**：定义说“除第一个单词外，其余单词的首字母大写，且**每个单词**的首字母之后的字符必须是小写”。结合示例 1（`Leetcode → leetcode`）可知：**首词整体转小写（含首字母）**；其余单词首字母大写、剩余字母**强制**小写——单词内部的大写也会被压平（示例 2 中 `Go → Go` 恰好不变，但 `GOLD → Gold` 会变）。
2. **步骤②在本题约束下是空操作**：`caption` 只含字母和空格，分词拼接后串里只剩字母和 `#`，没有任何字符可删。这一步考察的是“读题后确认无需实现”，不必写过滤逻辑。
3. **截断的 100 个字符含 `#`**：整个标签（含开头的 `#`）最多 100 个字符，即字母部分至多 99 个。`caption` 长度可达 150，`#` + 150 个字母 = 151 > 100，所以截断是**真实会触发**的分支，不能漏。

> 💡 三步必须**严格按题面顺序**理解：先拼驼峰、再谈删字符、最后才截断。顺序在本题约束下不影响结果，但读题时不要把“截断 100”误读成“单词各自截断”。

### 3.3 算法流程

![三步流水线：拼驼峰、去非字母、截断 100](images/wc454_q1_pipeline.svg)

```text
1. words = caption 按空白分词（自动跳过空串）
2. tag = "#"
3. 对第 i 个单词 w（下标从 0 开始）：
     i == 0 : tag += w 整体转小写
     i >  0 : tag += 大写(w[0]) + w[1:] 整体转小写
4. 若 len(tag) > 100：tag 只保留前 100 个字符
5. 返回 tag
```

### 3.4 示例演算

**示例 2：`caption = "can I Go There"`**

| 单词 | 角色 | 变换 | 结果 |
|------|------|------|------|
| can | 首词 | 整词转小写 | can |
| I | 第 2 词 | 首字母大写 | I |
| Go | 第 3 词 | 首字母大写 + 其余小写 | Go |
| There | 第 4 词 | 首字母大写 + 其余小写 | There |

拼接得 `"#" + "can" + "I" + "Go" + "There"` = `#canIGoThere`，长度 12 ≤ 100，无需截断。✓

**示例 3：101 个 `h`**：拼接结果为 `#` + 101 个 `h` 共 102 个字符，超过 100，截去末尾 2 个，得 `#` + 99 个 `h`。✓

## 4. 算法细节

1. **分词**：Python 无参 `caption.split()` 按任意连续空白切分并自动丢弃空串；C++ 用 `istringstream >> w` 逐词读取，天然跳过空白。二者都能正确处理首尾空格与连续空格，**不要**手动按单个空格切分（会产生空“单词”）。
2. **首词**：整词 `lower()` / 逐字符 `tolower`，首字母也要小写。
3. **非首词**：`w[0].upper() + w[1:].lower()`。单词长度为 1 时 `w[1:]` 为空串，天然安全。
4. **截断**：`tag[:100]` / `tag.resize(100)`，`#` 计入 100 之内；长度不足 100 时保持原样。
5. **步骤②不实现**：见 3.2 第 2 点。若要写出对“含标点数字”输入的鲁棒版本，可在拼接完成后统一过滤非字母并保住首字符 `#`。

## 5. 正确性证明

**引理 1**：分词拼接得到的中间串 $S$ 满足：$S[0]$ 为字符 `#`，且 $S$ 的其余字符全为英文字母。

**证明**：`caption` 仅由字母与空格组成；分词按空白切分并丢弃空段，故每个单词只含字母；大小写变换不改变字符类别；拼接只在最前附加 `#`。∎

**推论**：步骤②（删除非字母、保留 `#`）不改变 $S$，是空操作。

**定理**：算法输出恰为对 `caption` 依次执行三步操作得到的标签。

**证明**：步骤①由算法第 2~3 行逐词变换实现，与驼峰定义逐字对应——首词整体小写（示例 1 表明首词首字母也须小写），其余单词首字母大写、剩余字母小写。步骤②由引理 1 为空操作。步骤③取 $S$ 的前 $\min(100, |S|)$ 个字符，恰为“截断为最多 100 个字符”。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$，其中 $n = |\mathrm{caption}| \le 150$。分词、逐字符变换、截断各是一次线性扫描。
- **空间复杂度**：$O(n)$。存放结果串（至多 151 个字符，截断后不超过 100 个）。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    string generateTag(string caption) {
        string tag = "#";
        istringstream in(caption);
        string w;
        bool first = true;
        while (in >> w) {
            if (first) {
                for (char c : w) tag += tolower(c);
                first = false;
            } else {
                tag += toupper(w[0]);
                for (int i = 1; i < (int)w.size(); i++) tag += tolower(w[i]);
            }
        }
        if (tag.size() > 100) tag.resize(100);
        return tag;
    }
};
```

### Python

```python
class Solution:
    def generateTag(self, caption: str) -> str:
        parts = ["#"]
        for i, w in enumerate(caption.split()):
            if i == 0:
                parts.append(w.lower())
            else:
                parts.append(w[0].upper() + w[1:].lower())
        return "".join(parts)[:100]
```

## 8. 边界情况与易错点

1. **首词首字母也要小写**：`Leetcode → leetcode`，最常见的 WA 是把首词原样保留。
2. **非首词的后续字母强制小写**：`GOLD`（非首词）→ `Gold`，词内大写必须压平。
3. **截断含 `#`**：最多 100 个字符是**整个标签**，字母至多 99 个；示例 3 中 101 个 `h` 被截成 99 个。
4. **连续空格 / 首尾空格**：约束未排除，`split()` 与 `istringstream` 均能处理，别按单空格手动切分。
5. **单字母单词**：非首词 `I → I`，首词 `I → i`；`w[1:]` 为空不报错。
6. **超长输入忘记截断**：`caption` 可达 150 字符，`1 + 150 > 100`，不截断必然 WA。
7. **全空格输入**（题目未明确排除）：分词后无单词，结果为 `"#"`，上述实现自然成立。
