# LeetCode 得到目标值的最少行动次数 题解

## 1. 题目概述

- **标题 / 题号**：得到目标值的最少行动次数（#2139，medium）
- **链接**：https://leetcode.cn/problems/minimum-moves-to-reach-target-score/
- **来源**：LeetCode 第 276 场周赛 Q2
- **难度**：中等
- **标签**：贪心、数学

**题意**：整数游戏从 $1$ 开始，目标是 `target`。每次行动可二选一：**递增**（$x \to x+1$，次数不限）或**加倍**（$x \to 2x$，**至多** `maxDoubles` 次）。返回从 $1$ 得到 `target` 的最少行动次数。

**约束**：

- $1 \le \text{target} \le 10^9$
- $0 \le \text{maxDoubles} \le 100$

> 💡 约束的「甜区」一眼定方向：$\text{target} \le 10^9$ 直接排除正向 BFS / DP（值域状态爆炸）；$\text{maxDoubles} \le 100$ 暗示**翻倍是稀缺资源**，复杂度应当与它挂钩、而与 `target` 无关。两相结合，「反向倒推 + 末尾一次性累加」几乎是唯一自然的落点。

> 💡 本题在本仓库另有[每日题解 2139](../../solution/2101-2200/2139_得到目标值的最小移动次数.md)：主线同为「反向贪心 + 末尾累加」。本篇按**周赛复盘视角**展开：给出基于强归纳的完整正确性证明（引理-定理结构）、二进制视角（÷2 = 右移、奇数 −1 = 清最低位 1）与配额充足时的闭式、循环步数上界 $2D+1$ 的推导，以及「正向贪心为何不可行」的赛场翻车点。同场 Q1（#2138 定长切片）已另行成文，Q3（#2140 倒序线性 DP）与 Q4（#2141 二分答案 + 贪心验证）是本场后两题。

## 2. 示例

**示例 1**

```text
输入：target = 5, maxDoubles = 0
输出：4
解释：配额为 0，翻倍不可用，只能 1 → 2 → 3 → 4 → 5，共 4 步递增。
```

**示例 2**

```text
输入：target = 19, maxDoubles = 2
输出：7
解释：1 →(+1)→ 2 →(+1)→ 3 →(+1)→ 4 →(×2)→ 8 →(+1)→ 9 →(×2)→ 18 →(+1)→ 19，
      5 次递增 + 2 次加倍 = 7 步。
```

**示例 3**

```text
输入：target = 10, maxDoubles = 4
输出：4
解释：1 →(+1)→ 2 →(×2)→ 4 →(+1)→ 5 →(×2)→ 10，1 次递增 + 3 次加倍 = 4 步。
      注意配额只用了 3 次（至多可用 4 次）——「至多」不必用满。
```

三个示例恰好覆盖配额的三种状态：**耗尽**（$D=0$）、**不足**（$D=2 < \lfloor\log_2 19\rfloor = 4$）、**充足**（$D=4 \ge \lfloor\log_2 10\rfloor = 3$）。

## 3. 解题思路

### 3.1 暴力思路：正向 BFS / DP

从 $1$ 出发，状态 $(x, d)$（当前值、已用翻倍数）转移到 $(x+1, d)$ 或 $(2x, d+1)$，BFS 求最短路。但值域 $10^9$ 使状态空间爆炸、纯递增路径长度也达 $10^9$，完全不可行；正向 DP 表 $f[x][d]$ 同样开不出来。

退一步做**正向贪心**也不行：站在偶数 $x$ 面前，「现在翻倍还是继续 +1」是全局决策——翻倍用早了（在小数上翻倍）收益低、浪费配额；想留到后面的大数，又不知道后面还有没有更大的机会。每一步的选择依赖整条后续路径（**后效性**），局部信息不足以判断。

### 3.2 核心观察：反向倒推，用「偶数判定」代替「时机决策」

![核心观察：反向倒推，用偶数判定代替时机决策](images/2139_minmoves_backward_concept.svg)

把操作反过来做：$x \to x+1$ 的逆是 $x \to x-1$（总可逆），$x \to 2x$ 的逆是 $x \to x/2$（**仅偶数可逆**）。问题转化为：**从 `target` 出发，用「−1」与「÷2（至多 D 次）」回到 1 的最少步数**。

反向之后，每一步的判据**唯一确定**：

- $x$ 为偶数且配额 $> 0$：执行 $\div 2$——一步把数减半，必然不劣于逐个 $-1$（严格证明见 §5）；
- $x$ 为奇数（或配额已尽）：只能 $-1$。

**为什么翻倍要留给大数？** 在值 $v$ 上翻倍：$\times 2$ 花 $1$ 步，效果等价于 $v$ 次 $+1$，净省 $v - 1$ 步；收益随 $v$ 线性递增。反向倒推时 $\div 2$ 天然发生在当前**最大**的数上——逆着看回去，正是「把配额花在正向链上最大的可翻倍位置」。于是「正向难判的时机选择」转化为「反向机械的偶数判定」，无需搜索、无需 DP。

### 3.3 算法流程

![算法流程：反向贪心与末尾一次性累加](images/2139_minmoves_greedy_flow.svg)

1. `moves = 0`；
2. 循环：当 `target > 1` **且** `maxDoubles > 0`——
   - `target` 为偶数：`target ÷= 2`，`maxDoubles -= 1`；
   - 否则：`target -= 1`；
   - `moves += 1`；
3. 退出后 `moves += target - 1`，返回。

第 3 步是**必须**的收尾而非锦上添花：循环退出只可能因配额耗尽（剩余 `target − 1` 步全是 +1 的逆）或已到 1（加 0，不影响结果）。若省掉它、循环条件只查 `target > 1`，配额尽后逐位 $-1$，最坏 $10^9$ 次迭代必然超时；有了它，最坏情况一次减法出答案。

### 3.4 示例演算

![示例演算：target=19, maxDoubles=2 的完整倒推与正向验证](images/2139_minmoves_walkthrough.svg)

以**示例 2** `target = 19, maxDoubles = 2` 走查：

| 步 | target | 配额 | 奇偶 | 操作 | moves |
|----|--------|------|------|------|-------|
| 初始 | 19 | 2 | 奇 | — | 0 |
| 1 | 18 | 2 | 奇 | $-1$ | 1 |
| 2 | 9 | 1 | 偶 | $\div 2$（d: 2→1） | 2 |
| 3 | 8 | 1 | 奇 | $-1$ | 3 |
| 4 | 4 | 0 | 偶 | $\div 2$（d: 1→0） | 4 |
| 退出 | — | 0 | — | $+\!= 4 - 1 = 3$ | **7** |

正向验证：$1 \to 2 \to 3 \to 4 \xrightarrow{\times 2} 8 \to 9 \xrightarrow{\times 2} 18 \to 19$，共 7 步 ✓。两个 $\div 2$ 逆看回去对应在 $4$、$9$ 处翻倍——恰是链上最大的可翻倍位置。

**示例 1**（$D = 0$）：循环零次，直接 `moves += 5 - 1 = 4`。
**示例 3**（$D = 4$，配额充足）：$10 \xrightarrow{\div 2} 5 \xrightarrow{-1} 4 \xrightarrow{\div 2} 2 \xrightarrow{\div 2} 1$，共 4 步，配额还剩 1 次未用。

## 4. 算法细节

1. **循环条件双检查**：`target > 1` 与 `maxDoubles > 0` 缺一不可。漏前者时 `target = 1` 会被继续 $-1$ 到 0；漏后者则配额被用超（WA 而非 TLE）。
2. **末尾一次性累加**：把「配额尽后纯递增」的剩余距离用 $O(1)$ 算术一次算清，将最坏 $O(\text{target})$ 的循环压成 $O(D)$。这是本题从「能过」到「优雅」的分水岭。
3. **循环步数上界 $2D + 1$**：$-1$ 只发生在奇数上，而**奇数 $-1$ 后必变偶数**，下一步（若循环继续）必为 $\div 2$。故配额未尽期间两类操作严格交替，$-1$ 的次数 $\le \div 2$ 的次数 $+ 1 \le D + 1$，循环体至多 $2D + 1 \le 201$ 次。
4. **二进制视角**：$\div 2$ = 二进制右移一位；奇数 $-1$ = 清除最低位的 1。配额充足（$D \ge \lfloor\log_2 \text{target}\rfloor$）时，答案是闭式 $(\mathrm{bitlen}(\text{target}) - 1) + (\mathrm{popcount}(\text{target}) - 1)$：前者把 `target` 右移回 1，后者清掉途中所有低位 1。验证：示例 3 中 $10 = (1010)_2$，$L = 4, P = 2$，答案 $= 3 + 1 = 4$ ✓。而示例 1、2 配额不足，闭式分别给出 $3$、$6$，均小于真解 $4$、$7$——**闭式只在配额充足时成立，反向模拟才是一般解**。这也正是与 [991. 坏了的计算器](https://leetcode.cn/problems/broken-calculator/) 的连接点：991 是配额无穷的版本，答案恒为该闭式。
5. **正向公式视角**：设某方案在值 $v_1 < v_2 < \cdots < v_k$（$k \le D$，$v_i$ 为翻倍发生时的值）处翻倍，归纳可证终值 $= 1 + A + \sum_i v_i$（$A$ 为 +1 次数），故总步数 $= (T - 1) - \sum_i (v_i - 1)$。于是**最小化步数 = 最大化 $\sum (v_i - 1)$**——这是「翻倍留给大数、尽量用满」的量化表达；反向贪心给出的正是满足可达性约束下该和的最大化安排。
6. **溢出审计**：循环部分 $\le 201$；末尾累加 $\le 10^9 - 1$；总和 $< 10^9 + 201 < 2^{31} - 1$，`int` 安全。若变体把上界放宽到 $10^{18}$，C++ 须换 `long long`（Python 无碍）。

## 5. 正确性证明

记 $f(x, d)$ 为从值 $x$、剩余配额 $d$ 出发回到 1 的最少步数，$g(x, d)$ 为反向贪心的步数。由操作序列的任何后缀仍是其后缀起点状态的合法方案，且最优方案的后缀必为该状态的最优方案（**最优子结构**）。

**引理 1（先减后走，不劣）**：对 $x > 1$、$0 \le t \le x - 1$，有 $f(x, d) \le t + f(x - t, d)$。

**证明**：右边对应「先执行 $t$ 次 $-1$ 到 $x - t$，再接 $x-t$ 处的最优方案」，是一条合法方案；最优值不超过任何合法方案的步数。∎

**引理 2（首步唯一）**：若 $x > 1$ 且（$x$ 为奇数或 $d = 0$），则 $f(x, d) = 1 + f(x - 1, d)$。

**证明**：$\div 2$ 需要 $x$ 为偶数且 $d > 0$，二者至少其一不满足时首步只能 $-1$。∎

**定理（反向贪心最优）**：对一切 $x \ge 1$、$d \ge 0$，有 $g(x, d) = f(x, d)$。

**证明**：对 $x$ 强归纳。$x = 1$ 时两者皆为 0。设 $x > 1$，分两种情形：

- **情形 A（$x$ 奇或 $d = 0$）**：贪心执行 $-1$。由引理 2 与归纳假设（$x - 1 < x$）：
  $$g(x, d) = 1 + g(x-1, d) = 1 + f(x-1, d) = f(x, d).$$

- **情形 B（$x$ 偶且 $d > 0$）**：贪心执行 $\div 2$，由归纳假设（$x/2 < x$）得 $g(x, d) = 1 + f(x/2, d-1)$，只需证 $f(x, d) \ge 1 + f(x/2, d-1)$。取最优方案 $S$：
  - **$S$ 首步 $\div 2$**：由最优子结构，$f(x, d) = 1 + f(x/2, d-1)$，取等。
  - **$S$ 首步 $-1$ 且后续存在 $\div 2$**：设首个 $\div 2$ 之前共有 $a \ge 1$ 次 $-1$。首个 $\div 2$ 作用于偶数 $x - a$，而 $x$ 为偶数，故 $a$ 为**偶数**，即 $a \ge 2$。由最优子结构：
    $$f(x, d) = a + 1 + f\big(\tfrac{x-a}{2},\, d-1\big).$$
    另一方面从 $x/2$ 出发先执行 $a/2$ 次 $-1$ 恰到 $\frac{x-a}{2}$（因 $\frac{x}{2} - \frac{a}{2} = \frac{x-a}{2}$），由引理 1：
    $$f\big(\tfrac{x}{2},\, d-1\big) \le \tfrac{a}{2} + f\big(\tfrac{x-a}{2},\, d-1\big).$$
    两式相减得 $f(x, d) - f(\frac{x}{2}, d-1) \ge (a + 1) - \frac{a}{2} = 1 + \frac{a}{2} \ge 1$，即所证。
  - **$S$ 全程无 $\div 2$**：$f(x, d) = x - 1$；而 $f(x/2, d-1) \le x/2 - 1$（全 $-1$ 方案），故 $f(x, d) \ge x/2 \ge 1 + f(x/2, d-1)$（用到 $x \ge 2$）。

  三种情况皆有 $f(x, d) \ge g(x, d)$；又 $g$ 本身是合法方案，$f(x, d) \le g(x, d)$，故相等。∎

**推论 1（末尾累加正确）**：循环退出时（$x = 1$ 或 $d = 0$），剩余最少步数恰为 $x - 1$。

**证明**：$d = 0$ 时反复应用引理 2 得 $f(x, 0) = x - 1$；$x = 1$ 时 $x - 1 = 0$ 亦真。∎

**推论 2（循环步数上界）**：循环体至多执行 $2D + 1$ 次。

**证明**：见 §4.3——$-1$ 仅发生在奇数，奇数 $-1$ 后变偶，下一步（若继续）必 $\div 2$，二者严格交替，$-1$ 次数 $\le \div 2$ 次数 $+ 1 \le D + 1$。∎

> 💡 情形 B 中「$a$ 必为偶数」是整个证明的枢纽：$x$ 偶、首个 $\div 2$ 的作用数 $x - a$ 偶，两者之差 $a$ 为偶数，从而 $a \ge 2$——这保证「先减半再走 $a/2$ 步」严格不长于「先走 $a$ 步再减半」。这正是「偶数且有余量时 ÷2 永不吃亏」的组合本质。

## 6. 复杂度分析

- **时间复杂度**：$O(\text{maxDoubles})$。由推论 2，循环体至多 $2D + 1 \le 201$ 次；末尾累加是一次 $O(1)$ 算术。**与 target 无关**——`target = 1e9, maxDoubles = 0` 的最坏输入只做一次减法。
- **空间复杂度**：$O(1)$，仅常数个整型变量。
- **对照**：不做末尾累加的朴素反向模拟是 $O(\text{target})$，最坏 $10^9$ 次迭代超时；正向 BFS / DP 连状态空间都开不出来。$D \le 100$ 的小上界是复杂度的锚点，也是本题的命题提示。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minMoves(int target, int maxDoubles) {
        int moves = 0;
        while (target > 1 && maxDoubles > 0) {
            if (target % 2 == 0) {
                target /= 2;
                maxDoubles--;
            } else {
                target--;
            }
            moves++;
        }
        return moves + target - 1;   // 配额尽或已到 1：剩余 +1 一次算清
    }
};
```

### Python

```python
class Solution:
    def minMoves(self, target: int, maxDoubles: int) -> int:
        moves = 0
        while target > 1 and maxDoubles > 0:
            if target % 2 == 0:
                target //= 2          # 整除：用 /= 会变成浮点，1e9 级丢精度
                maxDoubles -= 1
            else:
                target -= 1
            moves += 1
        return moves + target - 1
```

> 💡 两处实现细节：①循环条件必须**同时**检查 `target > 1` 与 `maxDoubles > 0`（§8.1/§8.4）；②Python 用 `//=` 整除，`/=` 会让 `target` 变 `float`，后续 `% 2` 判据与大数精度同时失守。

## 8. 边界情况与易错点

1. **漏末尾累加（最高频 TLE）**：循环条件只写 `target > 1`、把配额检查放循环体内，配额尽后逐位 $-1$——`target = 1e9, maxDoubles = 0` 时 $10^9$ 次迭代超时。修法：条件双检查 + 末尾 `moves += target - 1`。
2. **正向贪心 WA 反例**：「逢偶就翻倍」在 `target = 19, maxDoubles = 2` 上会在 $2$、$4$ 处用掉配额，还需 15 次 +1，共 17 步；最优 7 步（在 $4$、$9$ 处翻倍）。小数上翻倍浪费配额，且正向无局部判据。
3. **÷2 前忘查配额**：见偶数就 ÷2，配额用超。`target = 8, maxDoubles = 1`：正确 4 步（$1\to2\to3\to4\xrightarrow{\times2}8$），违规做法得 3 步（实际用了 3 次翻倍）。
4. **`target = 1`**：答案 0。循环条件 `target > 1` 保证不进入；若写成先操作后判断，$1$ 会被 $-1$ 成 $0$ 进而跑飞。
5. **「至多」不是「恰好」**：配额不必用满（示例 3 剩 1 次）；也不要因「怕浪费」而在小数上强行翻倍（同 2）。
6. **起点是 1 不是 0**：纯递增是 `target − 1` 步；把 `target` 当答案是低级但高发的读题失误。
7. **Python 整除**：`//` 而非 `/`，理由见 §7 的提示框。
8. **溢出审计**：`moves + target - 1 < 10^9 + 201 < 2^31 - 1`，`int` 安全；变体上界 $10^{18}$ 时 C++ 须 `long long`。
